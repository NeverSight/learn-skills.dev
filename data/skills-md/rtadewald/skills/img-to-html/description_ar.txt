أعد إنشاء نموذج تخطيطي لواجهة المستخدم (صورة) كـ HTML + CSS + JS ثابتة (بدون إطار عمل)، على مراحل مع موافقة المستخدم: مخطط سلكي ASCII مكتوب مع خطة → خلفية كاملة → مكونات مع خطوط → الأصول المتبقية → المراجعة النهائية. استخدم هذا عندما يذكر المستخدم img-to-html أو يطلب إعادة إنشاء نموذج تخطيطي لواجهة المستخدم كـ HTML.
