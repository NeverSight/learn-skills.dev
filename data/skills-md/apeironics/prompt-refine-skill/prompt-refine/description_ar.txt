يعيد هيكلة موجه اللغة الطبيعية للمستخدم بشكل صامت إلى التنسيق الذي يتعامل معه النموذج الذي يشغل هذه المهارة حاليًا بشكل أفضل، ثم يجيب. عند التنشيط، يحدد عائلة النماذج التي تنفذه (Claude، أو GPT، أو Gemini، أو Llama، أو DeepSeek، أو Mistral، أو Qwen، أو Grok، أو Perplexity، أو Kimi، أو GLM، أو Command، أو Nova، أو Phi) ويقوم بتحميل الإستراتيجية الرسمية لذلك النموذج - لذا يتطابق التحسين دائمًا مع النموذج الذي يقوم بتشغيله بالفعل. التنشيط باستخدام /prompt-fine. يُستخدم عندما يريد المستخدمون الحصول على إجابات أفضل دون تعلم الهندسة السريعة.
