Úsalo cuando el usuario entregue una página HTML terminada (un archivo, un pegado, una exportación de diseñador o IA) para recrearla en WordPress, en cualquier constructor: Elementor, Divi, Bricks, Gutenberg, Breakdance, Oxygen, Beaver Builder o WPBakery. Una llamada Respira Exhale la escribe como elementos nativos y editables del constructor que se asemejan al archivo; esta habilidad cubre la entrada, la llamada, las opciones y la verificación.  

Por favor, responde siempre en el idioma del usuario.
