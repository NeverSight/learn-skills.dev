Usa quando costruisci manualmente una pagina Elementor con respira_build_page: a partire da un brief, uno screenshot, un mockup o un design devi tradurlo in impostazioni di Elementor. Include il modello, gli stili che Elementor non eredita mai, la lettura dei valori calcolati del design invece di indovinare, pulsanti, spaziatura, mobile e il controllo del rendering. Per un file HTML completato, usa invece html-to-page.
