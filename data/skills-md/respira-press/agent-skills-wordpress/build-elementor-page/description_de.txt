Verwenden Sie dies, wenn Sie eine Elementor‑Seite manuell mit respira_build_page erstellen: Aus einem Briefing, einem Screenshot, einem Mockup oder einem Design müssen Sie diese in Elementor‑Einstellungen umsetzen. Deckt das Template, die Stile, die Elementor nie übernimmt, das Auslesen der berechneten Werte eines Designs anstelle von Schätzungen, Buttons, Abstände, Mobile und die Kontrolle der Darstellung ab. Für eine fertige HTML‑Datei verwenden Sie stattdessen html-to-page.
