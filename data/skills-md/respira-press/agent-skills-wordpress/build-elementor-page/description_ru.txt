Используйте при ручном создании страницы Elementor с помощью respira_build_page: из брифа, скриншота, мокапа или дизайна вы должны преобразовать его в настройки Elementor. Охватывает шаблон, стили, которые Elementor никогда не наследует, чтение вычисленных значений дизайна вместо угадывания, кнопки, отступы, мобильную версию и проверку рендеринга. Для готового HTML‑файла используйте html-to-page.
