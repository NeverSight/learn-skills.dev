Utilisez‑le lors de la création manuelle d’une page Elementor avec respira_build_page : à partir d’un brief, d’une capture d’écran, d’une maquette ou d’un design, vous devez reformuler en paramètres Elementor. Cela couvre le modèle, les styles qu’Elementor n’hérite jamais, la lecture des valeurs calculées d’un design au lieu de deviner, les boutons, les espacements, le mobile et la vérification du rendu. Pour un fichier HTML terminé, utilisez html-to-page.
