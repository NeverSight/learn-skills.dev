Utilisez lorsque l'utilisateur dit « convert this html to breakdance » ou « paste html into breakdance », ou possède un export Webflow, Framer, CodePen ou un ancien export statique à intégrer dans un site Breakdance. Convertit le HTML et le CSS bruts en nœuds EssentialElements natifs dans _breakdance_data, en mappant les couleurs, la typographie et les espacements aux Variables Breakdance, et en refusant les types d'éléments que Breakdance ne rendrait pas.
