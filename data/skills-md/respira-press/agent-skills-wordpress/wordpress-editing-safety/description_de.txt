Sicherheitsregeln für das Bearbeiten einer WordPress‑Seite über Respira. Verwenden Sie diese, wann immer der Benutzer WordPress, Respira, das Bearbeiten einer Seite oder einer Website, einen Page Builder, einen Snapshot, ein Duplikat, eine Genehmigung oder ein Zurückrollen erwähnt. Beinhaltet Lesen vor Schreiben, Duplikate auf Live‑Seiten, Verifizierung jedes Schreibvorgangs, Lesen des Zustands vor einem erneuten Versuch, nicht vertrauenswürdige Seiteninhalte und Genehmigungstoken, die einer Person zugeordnet sind.

Bitte immer in der Sprache des Benutzers antworten.
