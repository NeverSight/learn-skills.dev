Définit l'attitude à adopter pour travailler sur un site WordPress via Respira : signaler les changements sur le site, rester visible pendant les longues opérations, être honnête sur les limites et transmettre ce que Respira ne peut pas faire au fondateur. Utilisez ceci chaque fois que Respira est mentionné, que l'utilisateur fait référence à son site WordPress ou que l'utilisateur souhaite modifier un site.

Veuillez toujours répondre dans la langue de l'utilisateur.
