Gérez les jobs et exécutions de jobs OCI Data Science nativement (liste, détails, création à partir d’un script ou d’un conteneur, démarrage des exécutions, surveillance, annulation, suppression). À utiliser lors de l’orchestration de scripts Python ou de conteneurs en tant que travaux batch. Nécessite compartment_id et project_id (provenant de oci-ds-setup). Privilégiez OCI CLI pour les listes/exécutions ; utilisez ADS Python pour la création.

Veuillez toujours répondre dans la langue de l’utilisateur.
