Управляйте развертываниями моделей OCI Data Science нативно (список, получение, создание из модели каталога, активация, деактивация, удаление). Используйте для обслуживания моделей через управляемый HTTPS‑эндпоинт. Требуются compartment_id и project_id; для создания нужен model_id. Для создания предпочтительно использовать ADS Python; для операций жизненного цикла — OCI CLI.
