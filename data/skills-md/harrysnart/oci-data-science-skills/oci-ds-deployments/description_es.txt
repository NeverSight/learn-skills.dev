Administre implementaciones de modelos de OCI Data Science de forma nativa (listar, obtener, crear a partir de un modelo del catálogo, activar, desactivar, eliminar). Úselo para servir modelos detrás de un endpoint HTTPS gestionado. Requiere compartment_id y project_id; la creación requiere model_id. Prefiera ADS Python para la creación; use OCI CLI para operaciones del ciclo de vida.
