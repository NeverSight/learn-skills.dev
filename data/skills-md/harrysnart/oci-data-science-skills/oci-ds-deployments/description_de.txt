Verwalten Sie OCI Data Science Modellbereitstellungen nativ (auflisten, abrufen, aus Katalogmodell erstellen, aktivieren, deaktivieren, löschen). Verwenden Sie sie, um Modelle hinter einem verwalteten HTTPS‑Endpunkt bereitzustellen. Erfordert compartment_id und project_id; für die Erstellung wird model_id benötigt. Bevorzugen Sie ADS Python für die Erstellung; nutzen Sie OCI CLI für Lebenszyklus‑Operationen.
