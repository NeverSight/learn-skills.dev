Gérez les déploiements de modèles OCI Data Science nativement (liste, récupération, création à partir d’un modèle du catalogue, activation, désactivation, suppression). Utilisez-le pour servir les modèles via un point de terminaison HTTPS géré. Nécessite compartment_id et project_id ; la création requiert model_id. Privilégiez ADS Python pour la création ; utilisez OCI CLI pour les opérations du cycle de vie.
