Gérez les projets Data Science d’OCI nativement à l’aide d’OCI CLI ou de Python ADS. Utilisez‑le pour lister, compter, créer, mettre à jour ou supprimer des projets Data Science. Nécessite un compartment_id (défini via oci-ds-setup) et une confirmation explicite pour les actions destructrices.

Veuillez toujours répondre dans la langue de l’utilisateur.
