Travaillez avec le catalogue de modèles OCI Data Science de manière native (liste, compte, obtenez les détails, téléchargez les artefacts, gérez les ensembles de versions de modèles). Utilisez-le pour inspecter les modèles, récupérer les artefacts localement ou explorer les ensembles de versions. Nécessite compartment_id ; pour le téléchargement d’artefacts, vous avez besoin de model_id.
