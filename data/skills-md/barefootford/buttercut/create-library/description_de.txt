Erstellen Sie eine neue ButterCut-Bibliothek. Sammeln Sie Bibliotheksinformationen (Name, Aufnahmestandort, Sprache, Korrekturlesen von Transkripten) und stellen Sie die Bibliothek auf. Wird verwendet, wenn der Benutzer eine * * neue * * Bibliothek starten möchte. Bibliotheken sind Container mit Filmmaterial und Filmmaterialanalyse (Transkripte, Kontaktbögen usw.). Benutzer können Bibliotheken auch als "Projekte" oder ähnlich bezeichnen. Bitten Sie sie, zu bestätigen, ob sie eine neue Bibliothek (Filmmaterialcontainer) oder nur einen neuen Schnitt (Rohschnitt, Auswahl usw.) wünschen, wenn sie sich nicht sicher sind.
