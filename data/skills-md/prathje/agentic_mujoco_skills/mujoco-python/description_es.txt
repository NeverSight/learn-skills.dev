Guía para construir y controlar simulaciones de física MuJoCo en Python. Usa esta habilidad siempre que el usuario quiera: crear o ejecutar una simulación MuJoCo, cargar un modelo MJCF/XML, avanzar la física, renderizar fotogramas o tomar capturas de pantalla (fuera de pantalla o con el visor), leer sensores o posiciones de articulaciones, controlar articulaciones o actuadores, configurar la cámara, cambiar banderas de visualización o grupos de geometrías, o ajustar la configuración del solucionador/integrador. También se debe activar cuando el usuario mencione mujoco, mjcf, simulación humanoide, simulación de robot en mujoco o renderizado de física con mujoco — incluso si no dice "MuJoCo" explícitamente pero describe tareas como "simular un robot", "renderizar una escena física" o "leer ángulos de las articulaciones de la simulación".
