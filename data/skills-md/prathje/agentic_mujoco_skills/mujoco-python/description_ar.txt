دليل لبناء والتحكم في محاكيات فيزياء MuJoCo باستخدام بايثون. استخدم هذه القدرة كلما أراد المستخدم: إنشاء أو تشغيل محاكاة MuJoCo، تحميل نموذج MJCF/XML، تقدم الفيزياء خطوةً خطوة، عرض الإطارات أو التقاط لقطات شاشة (خارج الشاشة أو عبر العارض)، قراءة المستشعرات أو مواضع المفاصل، التحكم في المفاصل أو المشغلات، ضبط الكاميرا، تغيير علمات التصور أو مجموعات الهندسة، أو تعديل إعدادات المُحلل/المكامل. كما يجب تفعيلها عندما يذكر المستخدم mujoco أو mjcf أو محاكاة الإنسان الآلي أو محاكاة الروبوت في mujoco أو عرض الفيزياء باستخدام mujoco — حتى وإن لم يذكر "MuJoCo" صراحةً ولكن وصف مهام مثل "محاكاة روبوت"، "عرض مشهد فيزياء"، أو "قراءة زوايا المفاصل من المحاكاة".
