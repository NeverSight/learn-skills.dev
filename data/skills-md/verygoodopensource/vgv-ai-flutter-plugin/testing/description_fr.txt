Meilleures pratiques pour les tests unitaires Dart, les tests de widgets Flutter et les tests de fichiers golden, couvrant la nomination des groupes et des tests, le cycle de vie setUp et l'isolation, le moquage avec package:mocktail, et l'aide partagée pumpApp. Utilisez‑les lors de l'écriture, de la modification ou de la révision de tests, golden inclus, qui utilisent package:test, package:flutter_test, package:mocktail ou package:bloc_test. Utilisez‑les aussi lorsqu'aucun package n’est nommé : « ajouter un test golden pour mon widget AppButton », « écrire un test golden », golden, matchesGoldenFile, le marquage ou la mise à jour des golden, l’écriture d’un test unitaire ou de widget, ou l’ajout d’un helper de test ou d’un mock. Une demande de test golden ou widget en une seule ligne est dans le périmètre, y compris sous « Dart code only » ; un widget dans un package UI appartient au package UI. Utilisez‑les également lorsque la demande porte sur ce que ces normes interdisent : package:mockito, un tag de test chaîne brute au lieu de TestTag, un pumpWidget(MaterialApp(...)) en ligne, vérifier le padding, la couleur ou la taille de police dans un test de widget, ou un état partagé entre les tests. Ces demandes sont dans le périmètre, pas exclues.
