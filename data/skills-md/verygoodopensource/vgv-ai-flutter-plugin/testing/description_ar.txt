أفضل الممارسات لاختبارات وحدة Dart، اختبارات مكوّنات Flutter، واختبارات ملفات الجولدن، تشمل تسمية المجموعات والاختبارات، دورة حياة setUp والعزل، المحاكاة باستخدام package:mocktail، والمساعد المشترك pumpApp. استخدمها عند كتابة أو تعديل أو مراجعة الاختبارات، بما في ذلك الجولدن، التي تستخدم package:test، package:flutter_test، package:mocktail، أو package:bloc_test. استخدمها أيضًا عندما لا يُذكر أي حزمة: "أضف اختبار جولدن لعنصر AppButton"، "اكتب اختبار جولدن"، جولدن، matchesGoldenFile، وضع العلامات أو تحديث الجولدن، كتابة اختبار وحدة أو اختبار مكوّن، أو إضافة مساعد اختبار أو mock. طلب اختبار جولدن أو مكوّن سطر واحد يقع ضمن النطاق، بما في ذلك تحت "Dart code only"؛ مكوّن في حزمة UI هو الخاص بحزمة ui-package. استخدمها أيضًا عندما يطلب الطلب ما تحظر هذه المعايير: package:mockito، وسم اختبار كسلسلة نصية خام بدلاً من TestTag، inline pumpWidget(MaterialApp(...))، التحقق من padding أو color أو حجم الخط في اختبار مكوّن، أو مشاركة الحالة بين الاختبارات. هذه الطلبات ضمن النطاق، وليست خارجًا.
