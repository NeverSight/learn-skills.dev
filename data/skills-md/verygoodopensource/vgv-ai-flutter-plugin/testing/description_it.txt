Migliori pratiche per i test unitari Dart, i test dei widget Flutter e i test dei file golden, includendo la denominazione di gruppi e test, il ciclo di vita setUp e l'isolamento, il mocking con package:mocktail e l'helper condiviso pumpApp. Usalo quando scrivi, modifichi o revisioni test, inclusi i golden, che utilizzano package:test, package:flutter_test, package:mocktail o package:bloc_test. Usalo anche quando non viene indicato alcun pacchetto: "add a golden test for my AppButton widget", "write a goldens test", goldens, matchesGoldenFile, taggare o aggiornare goldens, scrivere un test unitario o widget, o aggiungere un helper di test o mock. Una richiesta di test golden o widget in una sola riga è nel campo di applicazione, inclusa sotto "Dart code only"; un widget in un pacchetto UI è del pacchetto UI. Usalo anche quando la richiesta chiede ciò che questi standard vietano: package:mockito, un tag di test stringa grezza invece di TestTag, un pumpWidget(MaterialApp(...)) inline, asserire padding, colore o dimensione del font in un test widget, o stato condiviso tra i test. Queste richieste sono nel campo di applicazione, non fuori.
