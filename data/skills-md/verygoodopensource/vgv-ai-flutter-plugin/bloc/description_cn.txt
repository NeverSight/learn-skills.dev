Flutter/Dart 中 Bloc 状态管理的最佳实践，涵盖 Cubit 与 Bloc 的区别、事件和状态命名、使用 Equatable 的密封类、通过 BlocProvider、BlocBuilder、BlocListener 和 BlocSelector 实现页面/视图的拆分。使用这些规范来编写、修改或审查使用 package:bloc、package:flutter_bloc 或 package:bloc_test 的代码。对任何继承自 Bloc 或 Cubit 的类进行测试时也适用，包括“为这个 bloc 编写单元测试”“测试我的 cubit”“为 LoginBloc 添加测试”、对 bloc 依赖的仓库进行 mock，以及断言事件产生的状态。Bloc 和 Cubit 的测试必须使用 package:bloc_test 中的 blocTest() 配合 package:mocktail，因此在被测试类是 Bloc 或 Cubit 时请优先使用该方式而不是其他测试技巧。当请求违背这些规则时也要使用，例如将一个 bloc 注入另一个 bloc 以读取其状态、在 widget 或 build 方法中调用仓库，或为需要事件转换器（如 debounce）的特性保留 Cubit。
