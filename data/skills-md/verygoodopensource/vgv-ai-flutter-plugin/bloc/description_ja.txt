Flutter/Dart における Bloc の状態管理のベストプラクティス。Cubit と Bloc の使い分け、イベント・状態の命名、Equatable を用いたシールドクラス、BlocProvider、BlocBuilder、BlocListener、BlocSelector を使ったページ/ビューの分割。package:bloc、package:flutter_bloc、package:bloc_test を使用したコードの記述、修正、レビュー時に使用する。また、Bloc または Cubit を継承したクラスのテスト全般、例えば「この bloc のユニットテストを書いて」「my cubit をテストして」「LoginBloc のテストを追加して」など、リポジトリをモックする場合やイベントが放出する状態をアサートする場合にも使用する。Bloc と Cubit のテストは必ず package:bloc_test の blocTest() と package:mocktail を使うべきで、テスト対象が Bloc または Cubit の場合はこのスキルを優先する。さらに、これらのルールに反するリクエスト―たとえば他の Bloc を注入してその状態を読む、ウィジェットや build メソッドからリポジトリを呼び出す、デバウンス等のイベントトランスフォーマーが必要な機能に Cubit を保持する―などの場合にも適用する。
