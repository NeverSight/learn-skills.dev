Aggiungi effetti sonori gratuiti CC0 a un’app web o a un gioco senza una chiave API, usando l’API SFXMint (ruoli sonori, set raggruppati per evento, ricerca) e URL MP3/WAV hotlinkabili permanenti. Con una chiave API SFXMint può anche generare un suono che la libreria non possiede. Usalo quando l’utente chiede di aggiungere suoni, feedback audio o suoni UI a un’app, desidera suoni di click / notifica / successo / errore / avviso, effetti sonori di gioco (moneta, salto, colpo, esplosione, potenziamento, game over), ambienti (pioggia, foresta, drone), suono su un video o animazione guidata da codice (Remotion, motion graphics), o chiede dove ottenere effetti sonori gratuiti per un’app, gioco, video, prototipo o demo. Non è destinato a musica, voce o parlato.

Rispondi sempre nella lingua dell’utente.
