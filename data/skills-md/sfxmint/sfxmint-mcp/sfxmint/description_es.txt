Añade efectos de sonido gratuitos CC0 a una aplicación web o juego sin necesidad de una clave API, usando la API de SFXMint (roles de sonido, conjuntos agrupados por evento, búsqueda) y URLs permanentes hotlinkeables en MP3/WAV. Con una clave API de SFXMint también puede generar un sonido que no tenga la biblioteca. Úsalo cuando el usuario solicite añadir sonidos, retroalimentación de audio o sonidos de UI a una aplicación, quiera sonidos de clic / notificación / éxito / error / alerta, efectos de sonido de juego (moneda, salto, golpe, explosión, potenciador, fin de juego), ambiente (lluvia, bosque, dron), sonido en un video o animación impulsado por código (Remotion, motion graphics), o pregunte dónde obtener efectos de sonido gratuitos para una aplicación, juego, video, prototipo o demo. No es para música, voz o discurso.
