أضف مؤثرات صوتية مجانية بترخيص CC0 إلى تطبيق ويب أو لعبة دون الحاجة إلى مفتاح API، باستخدام واجهة SFXMint (أدوار الصوت، مجموعات مُنظمة حسب الحدث، بحث) وروابط MP3/WAV دائمة قابلة للتوصيل المباشر. باستخدام مفتاح API الخاص بـ SFXMint يمكنه أيضًا إنشاء صوت غير موجود في المكتبة. استخدم ذلك عندما يطلب المستخدم إضافة أصوات أو تغذية صوتية أو أصوات واجهة المستخدم إلى تطبيق، أو يريد أصوات نقر/إشعار/نجاح/خطأ/تنبيه، أو مؤثرات صوتية للعبة (عملة، قفزة، ضرب، انفجار، تعزيز، انتهاء اللعبة)، أو خلفيات صوتية (مطر، غابة، طنين)، أو صوت على فيديو أو رسوم متحركة يُنتج عبر الكود (Remotion، الرسوم المتحركة)، أو عندما يسأل عن مكان الحصول على مؤثرات صوتية مجانية لتطبيق أو لعبة أو فيديو أو نموذج أولي أو عرض تجريبي. ليس للموسيقى أو الصوت أو الكلام.
