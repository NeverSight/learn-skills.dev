API 키 없이도 SFXMint API(사운드 역할, 이벤트별로 그룹화된 세트, 검색)와 영구적인 핫링크 MP3/WAV URL을 사용하여 웹 앱이나 게임에 무료 CC0 사운드 효과를 추가하세요.
