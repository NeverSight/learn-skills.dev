Публичный интерфейс для ручного обзора: контракт поверхности, мост и локальный хост для «когда нет плагина», позволяющие любой странице обзора Skill быть встроенной в боковую панель DSH и работать нормально даже без DSH. Вызывается всеми Skill, включающими шаг обзора, **не вызывается напрямую пользователем**. Единственный случай, когда вы будете использовать его напрямую, — это когда у вас уже есть `review-surface.json` и вы хотите проверить его самостоятельно, либо запустить эту поверхность обзора без DSH.
