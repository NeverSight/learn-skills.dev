Öffentliche Schnittstelle für manuelle Überprüfung: ein Surface‑Contract + eine Bridge + ein nativer Host für den Fall, dass kein Plugin vorhanden ist, sodass die Review‑Seite jeder Skill an die DSH‑Seitenleiste angehängt und auch ohne DSH normal ausgeführt werden kann. Sie wird von allen Skills aufgerufen, die einen Review‑Schritt enthalten, **nicht direkt vom Nutzer ausgelöst**. Es gibt nur einen Fall, in dem Sie sie direkt verwenden: Sie besitzen bereits eine `review-surface.json` und möchten sie eigenständig validieren, oder Sie möchten diese Review‑Surface ohne DSH ausführen.
