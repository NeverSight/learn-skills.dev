Public seam for manual review: a surface contract + a bridge + a local host “when there’s no plugin,” allowing any Skill’s review page to be attached to the DSH sidebar and to run normally even without DSH. It is called by all Skills that include a review step, **not triggered directly by the user**. The only situation where you use it directly is when you already have a `review-surface.json` and want to validate it on its own, or run that review page without DSH.
