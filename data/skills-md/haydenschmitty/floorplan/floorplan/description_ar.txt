ارسم مخططًا أرضيًا لقاعدة شفرة التطبيق (مستودع واحد أو عدة مستودعات جنبًا إلى جنب)، خريطة تفاعلية على شكل عقد حيث لكل نظام فرعي، وحدة، ملف ومسار HTTP اسمًا قابلًا للقراءة من قبل البشر ووصفًا سطرًا واحدًا، متصلة بالاستيرادات والمكالمات HTTP بينها، على مستويات تكبير متعددة. يتم حفظه كملف floorplan/index.html مستقل داخل قاعدة الشفرة. استخدمه كلما أراد المستخدم تصورًا أو رسم خريطة أو تخطيطًا أو توثيقًا أو الحصول على نظرة معمارية عامة لقاعدة الشفرة أو المستودع أو المونوروبو، وفهم كيفية عمل تطبيقه أو ارتباطه تحت الغطاء، والانضمام إلى شفرة غير مألوفة، ورؤية كيفية تواصل الواجهة الأمامية مع الخلفية، أو تحديث مخطط أرضي موجود، حتى لو لم يذكر كلمة "visualize".
