Tracez un plan d’étage du code d’une application (un dépôt ou plusieurs côte à côte), une carte interactive en graphe de nœuds où chaque sous‑système, module, fichier et route HTTP possède un nom lisible par l’homme et une description d’une ligne, reliés par les importations et les appels HTTP entre eux, à plusieurs niveaux de zoom. Il est enregistré sous forme d’un fichier autonome floorplan/index.html dans le dépôt. Utilisez‑le chaque fois que l’utilisateur veut visualiser, cartographier, diagrammer, documenter ou obtenir une vue d’ensemble architecturale d’un codebase, repo ou monorepo, comprendre comment son appli fonctionne ou est connectée en interne, s’initier à du code inconnu, voir comment le frontend parle au backend, ou mettre à jour un plan d’étage existant, même s’il ne dit pas « visualiser ».
