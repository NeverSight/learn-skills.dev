Zeichne einen Grundriss des Codebasisses einer Anwendung (ein Repository oder mehrere nebeneinander), eine interaktive Knoten‑Graph‑Karte, bei der jedes Subsystem, Modul, jede Datei und jede HTTP‑Route einen menschengelesenen Namen und eine einzeilige Beschreibung hat, verbunden durch die Importe und HTTP‑Aufrufe zwischen ihnen, auf mehreren Zoomstufen. Sie wird als eigenständige floorplan/index.html im Codebasisspeicher abgelegt. Verwende sie immer, wenn der Benutzer visualisieren, kartieren, diagrammieren, dokumentieren oder einen architektonischen Überblick über ein Codebase, Repository oder Monorepo erhalten möchte, verstehen will, wie seine Anwendung intern funktioniert oder verbunden ist, sich in unbekannten Code einarbeiten möchte, sehen will, wie das Frontend mit dem Backend kommuniziert, oder einen bestehenden Grundriss aktualisieren möchte, selbst wenn er nicht das Wort „visualisieren“ verwendet.
