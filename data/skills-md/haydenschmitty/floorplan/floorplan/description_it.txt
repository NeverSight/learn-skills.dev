Disegna una planimetria del codebase di un'app (un repository o più affiancati), una mappa interattiva a grafo di nodi in cui ogni sottosistema, modulo, file e rotta HTTP hanno un nome leggibile dall'uomo e una descrizione in una sola riga, collegati dagli import e dalle chiamate HTTP tra di loro, a diversi livelli di zoom. Viene salvata come un file floorplan/index.html autonomo nel repository. Usala ogni volta che l'utente vuole visualizzare, mappare, diagrammare, documentare o ottenere una panoramica architettonica di un codebase, repository o monorepo, capire come funziona l'app o come è collegata internamente, fare onboarding su codice non familiare, vedere come il frontend comunica con il backend o aggiornare una planimetria esistente, anche se non dice "visualizzare".
