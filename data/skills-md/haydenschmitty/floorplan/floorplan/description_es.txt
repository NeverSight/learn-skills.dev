Dibuja un plano de la base de código de una aplicación (un repositorio o varios lado a lado), un mapa interactivo de grafo de nodos donde cada subsistema, módulo, archivo y ruta HTTP tenga un nombre legible y una descripción de una línea, conectados por las importaciones y llamadas HTTP entre ellos, a varios niveles de zoom. Se guarda como un archivo independiente floorplan/index.html en la base de código. Utilízalo siempre que el usuario quiera visualizar, mapear, diagramar, documentar o obtener una visión arquitectónica de una base de código, repo o monorepo, entender cómo funciona o está conectado su aplicación bajo el capó, incorporarse a código desconocido, ver cómo el frontend se comunica con el backend, o actualizar un plano existente, incluso si no dice "visualizar".
