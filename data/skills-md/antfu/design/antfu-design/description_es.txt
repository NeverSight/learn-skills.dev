Úselo al crear o rediseñar interfaces de usuario de Vue 3 de estilo devtools con @ antfu/design: cableado del preajuste UnoCSS componible, utilizando el vocabulario de token semántico (bg-base, color-base, badge-color- *, color-scale- *), eligiendo primitivas prefijadas (DisplayBadge, ActionButton, DisplayFilePath, OverlayModal,...) y manteniendo el contraste claro/oscuro y las reglas "anti-slop". Alcánzalo siempre que generes o revises la interfaz de usuario en un proyecto que depende de @antfu/design.
