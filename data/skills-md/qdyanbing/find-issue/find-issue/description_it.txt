Ispeziona un repository di codice locale per trovare bug reali, osservabili dagli utenti. Traccia il comportamento pubblico attraverso il codice in runtime, escludi i comportamenti intenzionali e le issue o pull request già segnalate su GitHub, costruisci e verifica in modo indipendente una riproduzione pubblica minima, e scrivi una bozza Markdown pronta per una issue che rimane non verificata finché un umano non la conferma. Usa quando ti viene chiesto di scansionare il codice alla ricerca di bug, trovare candidati di issue di alto valore, convalidare un difetto sospetto, produrre Markdown pronto per una issue con un link di riproduzione, o registrare un non‑issue segnalato dall’utente in not‑issues.md.
