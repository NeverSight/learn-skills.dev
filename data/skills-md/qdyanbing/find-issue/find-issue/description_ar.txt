افحص مستودع الشيفرة المحلي للعثور على أخطاء حقيقية يمكن للمستخدم ملاحظتها. تتبع سلوك البرنامج العام عبر الشيفرة أثناء التشغيل، واستبعد السلوك المقصود والقضايا أو طلبات السحب الموجودة على GitHub، وأنشئ نسخة إنتاجية عامة مصغرة وتحقق منها بصورة مستقلة، واكتب مسودة بصيغة Markdown جاهزة للإصدار تظل غير مؤكدة حتى يؤكدها إنسان. استخدمها عندما يُطلب منك فحص الكود للعثور على أخطاء، أو تحديد مرشحات قضايا ذات قيمة عالية، أو التحقق من عيب مشتبه به، أو إنتاج Markdown جاهز للإصدار مع رابط لإعادة الإنتاج، أو تسجيل مسألة تم تمييزها من قبل المستخدم كغير قضية في ملف not-issues.md. يرجى دائمًا الرد بلغة المستخدم.
