Contrôlez et intégrez l’instance OmniRoute de l’utilisateur (passerelle/routeur IA auto‑hébergé). Utilisez‑le chaque fois que l’utilisateur pose des questions sur OmniRoute, le routage du trafic IA, les fournisseurs, les modèles, les clés API, les combinaisons, les quotas, l’utilisation, le coût, la compression, les outils MCP, ou qu’il souhaite un agent (Claude, Codex, OpenClaw, Hermès, OpenCode, etc.) dirigé vers OmniRoute ou géré à travers celui‑ci. Donnez à tout agent un contrôle complet en lecture/ modification de la passerelle au nom de l’utilisateur via les interfaces CLI + REST + MCP.

Veuillez toujours répondre dans la langue de l’utilisateur.
