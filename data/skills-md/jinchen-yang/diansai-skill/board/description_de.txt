Taskboard — holt den neuesten Fortschritt ab, beansprucht fertig gestellte Aufgaben, die dieser Spur zugewiesen sind, markiert sie nach dem Abschluss als erledigt und leitet die Arbeit automatisch an nachgelagerte Spuren weiter. Wird verwendet, wenn der Benutzer sagt „board / task board / what should I do / claim task / sync progress / mark complete“. Basierend auf Git + Board/Datei‑Zusammenarbeit mit automatischer Übergabe zwischen den Spuren.
