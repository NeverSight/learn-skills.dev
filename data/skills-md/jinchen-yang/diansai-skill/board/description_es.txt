Tablero de tareas — obtener el progreso más reciente, reclamar las tareas listas asignadas a este carril, completarlas, marcarlas como hechas y transferir automáticamente el trabajo a los carriles posteriores. Se usa cuando el usuario dice “tablero / tablero de tareas / qué debo hacer / reclamar tarea / sincronizar progreso / marcar completo”. Construido sobre git más colaboración de tablero/archivo, con traspaso automático entre carriles.
