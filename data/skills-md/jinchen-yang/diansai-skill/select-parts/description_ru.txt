Выбирайте компоненты из списка деталей организатора в соответствии с требованиями и формируйте спецификацию (BOM) / единый закупочный заказ. Используйте это, когда пользователь помещает список деталей в inputs/partslist/ и запрашивает «выбор компонентов/выбор типа/генерацию BOM/генерацию списка покупок». Сначала разберите список деталей (мультимодальный), затем подберите компоненты, ориентируясь на требования из design/solution.md плюс спецификации выводов / наградный опыт в базе знаний; для отсутствующих в списке элементов используйте jlc_search для мгновенного поиска. Сформируйте design/bom.csv, который требует человеческого утверждения.

Пожалуйста, всегда отвечайте на языке пользователя.
