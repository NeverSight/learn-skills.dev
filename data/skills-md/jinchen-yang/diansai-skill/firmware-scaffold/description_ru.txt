Создайте скелет прошивки для контрольного канала (4‑слойная архитектура + планирование по временным квантам + конечный автомат + PID + VOFA + протокол K230). Используйте его, когда пользователь хочет «создать скелет прошивки/инженерный скелет», «собрать фреймворк прошивки» или «создать проект MSPM0/STM32». Переиспользуйте слоистость и планирование из Knowledge Base 08; данные выводов берутся из `contracts/pinmap.yaml`, а приём кадров K230 использует `contracts/protocol.h`. Параметры управления являются заполнительными и требуют настройки, а инициализацию периферии необходимо проверять вручную.
