Orcaが管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、成果物、スキル共有、作業ツリーコメント、そしてOrcaの組み込みブラウザを `orca` CLI で操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、純粋な git worktree やアドホック PTY、Computer Use よりもこれを優先します。CLI、ファイルシステム、API では実行できない可視ウィンドウの GUI 操作が必要な場合に限り、Computer Use を使用してください。
