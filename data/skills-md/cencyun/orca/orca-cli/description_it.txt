Gestisci i worktree gestiti da Orca, i contesti di cartelle, i terminali, i repository, le automazioni, gli artifact, la condivisione di competenze, i commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Usalo quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferiscilo rispetto al semplice git worktree, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Utilizza Computer Use solo quando è necessaria il controllo di una finestra visibile che la CLI, il filesystem o un'API non possono gestire.

Rispondi sempre nella lingua dell'utente.
