إنشاء وتحرير وتحليل شامل لجداول البيانات مع دعم الصيغ، والتنسيق، وتحليل البيانات، والتصوير البصري. عندما يحتاج كلود إلى العمل مع جداول البيانات (.xlsx، .xlsm، .csv، .tsv، إلخ) لـ: (1) إنشاء جداول بيانات جديدة مع الصيغ والتنسيق، (2) قراءة أو تحليل البيانات، (3) تعديل جداول البيانات الموجودة مع الحفاظ على الصيغ، (4) تحليل البيانات وتصويرها في جداول البيانات، أو (5) إعادة حساب الصيغ. يرجى دائمًا الرد بلغة المستخدم.
