Steuert einen VDS-Server (Vibe Decision Studio) über die Befehlszeile mit vds-cli. Verwenden Sie diesen Skill immer dann, wenn der Benutzer „vds“ oder „vds-cli“ erwähnt oder von einem Terminal aus etwas mit einer VDS-Organisation tun möchte: VDS-Skills, Agenten, Threads/Chats, Konnektoren, Dateien, Ordner, Mitglieder, Rollen oder Modelle auflisten oder überprüfen; einen Skill erstellen (aus Text, GitHub, einem Upload oder dem Marktplatz) oder einen Skill archivieren, umbenennen oder seinen Umfang ändern; Chatten Sie mit einem VDS-Agenten, lesen Sie ein Transkript oder laden Sie eine Lieferung herunter; Ändern Sie die Zugriffskontrolle für einen Skill, einen Agenten, einen Connector oder einen Thread. Melden Sie sich bei einer lokalen, Staging- oder privaten VDS-Bereitstellung an. VDS-Organisation oder -Umgebung wechseln. Verwenden Sie es auch, wenn ein VDS-Endpunkt aufgerufen werden muss, Sie aber nicht sicher sind, welcher Befehl vorhanden ist – die CLI erstellt ihre Befehle vom Server, also raten Sie nie. Zu den Auslösern gehören „Skill auf VDS veröffentlichen“, „VDS-Berechtigungen“, „VDS-Organisation wechseln“ und „Bei lokalem VDS anmelden“, in welcher Sprache auch immer der Benutzer sie schreibt.
