Drives a VDS (Vibe Decision Studio) server from the command line with vds-cli. Use this skill whenever the user mentions "vds" or "vds-cli", or wants to do anything with a VDS organization from a terminal: list or inspect VDS skills, agents, threads/chats, connectors, files, folders, members, roles or models; create a skill (from text, GitHub, an upload or the marketplace), or archive, rename or re-scope one; chat with a VDS agent, read a transcript or download a deliverable; change access control on a skill, agent, connector or thread; log in to a local, staging or private VDS deployment; switch VDS org or environment. Also use it when a VDS endpoint needs calling but you are unsure which command exists — the CLI builds its commands from the server, so never guess. Triggers include "publish skill to VDS", "VDS permissions", "switch VDS org" and "login to local VDS", in whatever language the user writes them.
