يقوم بتشغيل خادم VDS (Vibe Decision Studio) من سطر الأوامر باستخدام vds-cli. استخدم هذه المهارة عندما يذكر المستخدم "vds" أو "vds-cli"، أو يريد القيام بأي شيء مع مؤسسة VDS من محطة طرفية: قم بإدراج أو فحص مهارات VDS أو الوكلاء أو المواضيع/المحادثات أو الموصلات أو الملفات أو المجلدات أو الأعضاء أو الأدوار أو النماذج؛ إنشاء مهارة (من نص أو GitHub أو تحميل أو من السوق)، أو أرشفة مهارة أو إعادة تسميتها أو إعادة نطاقها؛ الدردشة مع وكيل VDS، أو قراءة النص أو تنزيل التسليم؛ تغيير التحكم في الوصول إلى مهارة أو وكيل أو موصل أو خيط؛ تسجيل الدخول إلى نشر VDS محلي أو مرحلي أو خاص؛ قم بتبديل مؤسسة VDS أو البيئة. استخدمه أيضًا عندما تحتاج نقطة نهاية VDS إلى الاتصال ولكنك غير متأكد من الأمر الموجود — تقوم واجهة سطر الأوامر (CLI) ببناء أوامرها من الخادم، لذا لا تخمن أبدًا. تتضمن المشغلات "مهارة النشر إلى VDS"، و"أذونات VDS"، و"تبديل VDS org" و"تسجيل الدخول إلى VDS المحلي"، بأي لغة يكتبها المستخدم.
