Scrivi test che fissano il comportamento reale invece dei dettagli di implementazione, dei valori di configurazione o di campioni fortunati. Usali quando aggiungi test per un nuovo comportamento, scrivi un test di regressione, sistemi un test fragile o instabile, rivedi una diff di test o quando un test si rompe dopo un refactoring o una modifica di configurazione che non ha cambiato il comportamento.
