Prüfe die Entscheidungen, die ein implementierender Agent getroffen hat, nicht dessen Diff – ein reines Audit, das den Verlauf der Sitzung in ein Entscheidungs‑Ledger überträgt, keinen Code ändert und einen unbeaufsichtigten Lauf niemals blockiert. Funktionsfähiger Code enthält weiterhin eine Architektur, die der Benutzer nie ausgewählt hat; bringe sie ans Licht, weil zukünftige Arbeiten sie erben. Verwende es, wenn der Benutzer die Entscheidungen der KI, die in seinem Auftrag getroffen wurden, überprüfen möchte, bevor AI‑implementierte Arbeit zusammengeführt oder committet wird, beim Integrieren eines delegierten Subagents‑Durchlaufs oder wenn ein Fix „funktioniert“, aber möglicherweise nur ein punktueller Fix ist.
