Portiere ein Feature aus einem bestehenden Repository, indem du den tatsächlichen Code kopierst und die Kopie bearbeitest, sodass dessen Fehlerbehebungen und Verhaltensnuancen erhalten bleiben. Verwende dies, wenn du aufgefordert wirst, ein bestehendes Feature zu kopieren oder zu portieren (insbesondere eine exakte Kopie), wenn du es in ein anderes Framework oder einen anderen Host überführst oder wenn eine frühere Neuimplementierung das Upstream‑Verhalten verpasst hat.
