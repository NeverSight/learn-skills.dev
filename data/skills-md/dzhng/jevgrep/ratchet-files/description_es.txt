Tamaño de archivo origen de Ratchet para que cada archivo sea lo suficientemente pequeño como para que un agente lo lea completo: encuentra cada archivo que supera el presupuesto de tokens, divide los archivos sobrantes por concepto y configura el ratchet de pre‑commit que impide que crezcan. Úsalo cuando un commit se bloquee porque un archivo supera el presupuesto de tamaño, cuando se solicite encontrar o dividir archivos sobredimensionados/largos/monolíticos, cuando el archivo que necesitas modificar sea demasiado grande para leerlo de una sola vez, o cuando se pida añadir un límite de tamaño de archivo o un gancho a un repositorio o reparar la cobertura del hook de commit en varios worktrees.
