Verwenden Sie die lokale Codex‑CLI als unabhängigen zweiten Agenten. Zwei Zweige — (1) führen Sie proaktiv `codex review` für eine zweite Meinung aus, nachdem Sie eine substanzielle Änderung abgeschlossen haben, bevor Sie sie als erledigt präsentieren oder committen; (2) delegieren Sie eine klar definierte Implementierungsaufgabe über `codex exec`, NUR wenn der Benutzer ausdrücklich verlangt, dass Codex sie ausführt. Außerdem wird erklärt, wie man Codex anfordert.
