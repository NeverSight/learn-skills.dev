قم بإنشاء لوحة تحكم حية للإنسان لأي شيء يشير إليه — تطبيق يعمل على هذه الآلة، حاويات، قاعدة بيانات، مجموعة Kubernetes، نشر على AWS أو Azure أو Google Cloud — في لوحة Herdr بجوارك: اكتشف ما يجري تشغيله وما هي البيانات الموجودة، ابدأ جمع البيانات الحية، وقم بإنشاء اللوحات التي يتحقق منها مهندس النظام (CPU، الذاكرة، الإدخال/الإخراج، معدل الطلبات، الأخطاء، زمن الاستجابة، حمل قاعدة البيانات)، دون أن ترى قيم البيانات الحقيقية. استخدم ذلك عندما يطلب الإنسان تصورًا أو مراقبة أو مشاهدة أو رسمًا بيانيًا أو "أرني" شيئًا، أو يطلب لوحة تحكم، أو يلصق رابط نشر أو خط أنابيب، أو يريد التحقق من حدوث رسائل السجل الصحيحة. واستخدمه أيضًا عندما تكون أدوات dashr MCP متصلة.
