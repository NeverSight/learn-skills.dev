Databricks AI Runtime، أوامر CLI `databricks air` لتقديم وإدارة عبء التدريب على وحدات معالجة الرسومات (GPU) على حوسبة Databricks بدون خادم. استخدم لـ: كتابة وتقديم ملف YAML لعمل `databricks air`، تمرير المعاملات الفائقة والسرية، فحص حالة التشغيل، سرد/إلغاء عمليات التشغيل، تدفق سجلات التشغيل ومراقبة تقدمه، إعداد صورة Docker مخصصة، وتكوين البيئة.

الرجاء دائمًا الرد بلغة المستخدم.
