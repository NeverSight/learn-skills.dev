Usare quando si interroga o si chiama modelli di base a consumo per token, o quando si creano, aggiornano, elencano o interrogano i servizi Unity Gateway (chiamato anche Unity AI Gateway), inclusi i servizi di provider di modelli, i servizi MCP, i servizi system.ai e i nomi di servizio a tre parti di Unity Catalog (catalog.schema.service). Usare anche per gestire i budget di spesa e gli avvisi di utilizzo su Unity Gateway, e per migrare dall'AI Gateway legacy. Usare inoltre quando un carico di lavoro con permessi dell'endpoint Model Serving (ad esempio CAN_QUERY) riceve PERMISSION_DENIED interrogando un nome di modello a tre parti, poiché l'accesso all'endpoint di serving non garantisce l'accesso a un servizio Unity Gateway. Non per configurare l'AI Gateway legacy sugli endpoint Model Serving; usare databricks-model-serving per questo.
