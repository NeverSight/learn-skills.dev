Используйте при запросе или вызове моделей‑фундаметалов с оплатой за токен, а также при создании, обновлении, перечислении или запросе сервисов Unity Gateway (также называемого Unity AI Gateway), включая сервисы поставщиков моделей, сервисы MCP, сервисы system.ai и сервисы Unity Catalog в трёхчастном формате (catalog.schema.service). Также используйте для управления бюджетами расходов и оповещениями об использовании в Unity Gateway, а также для миграции с устаревшего AI Gateway. Используйте, когда рабочая нагрузка с правами доступа к конечной точке Model Serving (например, CAN_QUERY) получает PERMISSION_DENIED при запросе модели в трёхчастном имени, поскольку доступ к конечной точке обслуживания не предоставляет доступ к сервису Unity Gateway. Не используйте для настройки устаревшего AI Gateway на конечных точках Model Serving; для этого используйте databricks-model-serving.
