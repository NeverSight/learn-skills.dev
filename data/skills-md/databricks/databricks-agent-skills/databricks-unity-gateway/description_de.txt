Verwenden Sie dies, wenn Sie Pay-per-Token‑Foundation‑Modelle abfragen oder aufrufen oder wenn Sie Unity‑Gateway‑Dienste (auch Unity AI Gateway genannt) erstellen, aktualisieren, auflisten oder abfragen, einschließlich Model‑Provider‑Dienste, MCP‑Dienste, system.ai‑Dienste und dreiteilige Unity‑Catalog‑Dienstnamen (catalog.schema.service). Verwenden Sie es auch zur Verwaltung von Ausgabenbudgets und Nutzungswarnungen im Unity‑Gateway sowie für die Migration vom Legacy‑AI‑Gateway. Außerdem verwenden Sie es, wenn ein Workload mit Model‑Serving‑Endpunkt‑Berechtigungen (z. B. CAN_QUERY) beim Abfragen eines dreiteiligen Modellnamens PERMISSION_DENIED erhält, da der Zugriff auf den Serving‑Endpunkt keinen Zugriff auf einen Unity‑Gateway‑Dienst gewährt. Nicht zur Konfiguration des Legacy‑AI‑Gateways auf Model‑Serving‑Endpunkten verwenden; hierfür databricks-model-serving nutzen.
