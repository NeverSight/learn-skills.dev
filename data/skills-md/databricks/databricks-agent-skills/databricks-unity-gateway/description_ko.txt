Pay‑per‑token 기반 파운데이션 모델을 쿼리하거나 호출할 때, 또는 Unity Gateway(또는 Unity AI Gateway) 서비스를 생성·수정·목록 조회·쿼리할 때 사용합니다. 여기에는 모델 제공자 서비스, MCP 서비스, system.ai 서비스, 그리고 세 부분으로 구성된 Unity Catalog 서비스 이름(catalog.schema.service)도 포함됩니다. 또한 Unity Gateway에서 비용 예산 및 사용량 알림을 관리하고, 레거시 AI Gateway에서 마이그레이션할 때에도 사용합니다. 모델 서빙 엔드포인트 권한(예: CAN_QUERY)을 가진 워크로드가 세 부분 모델 이름을 쿼리할 때 PERMISSION_DENIED 오류가 발생하는 경우에도 사용합니다. 이는 서빙 엔드포인트 접근이 Unity Gateway 서비스에 대한 접근 권한을 부여하지 않기 때문입니다. 레거시 AI Gateway를 모델 서빙 엔드포인트에 설정하는 경우에는 사용하지 말고, 이를 위해서는 databricks-model‑serving을 사용하십시오.
