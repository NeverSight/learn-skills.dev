従量課金型（pay‑per‑token）基盤モデルをクエリしたり呼び出したりする場合、または Unity Gateway（Unity AI Gateway とも呼ばれる）サービスを作成、更新、一覧表示、クエリする場合に使用します。対象にはモデルプロバイダーサービス、MCP サービス、system.ai サービス、および 3 部構成の Unity Catalog サービス名（catalog.schema.service）も含まれます。さらに、Unity Gateway の支出予算や使用アラートの管理、レガシー AI Gateway からの移行にも使用します。また、Model Serving エンドポイント権限（例：CAN_QUERY）を持つワークロードが 3 部構成のモデル名をクエリした際に PERMISSION_DENIED が返される場合にも使用します。これは、サービングエンドポイントへのアクセスが Unity Gateway サービスへのアクセス権を付与しないためです。レガシー AI Gateway を Model Serving エンドポイントで構成するためのものではなく、その場合は databricks-model-serving を使用してください。
