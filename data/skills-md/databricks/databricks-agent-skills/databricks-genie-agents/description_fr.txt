Créez, gérez et interrogez Databricks Genie Agents — des agents en langage naturel organisés et par données (anciennement Genie Spaces) : créez, exportez/importez, migrez entre les espaces de travail et posez des questions à un agent *spécifique* via l'API Conversation. Pour des questions générales sur les données ou pour trouver des données dans votre espace de travail, utilisez plutôt les statistiques-découverte des données (Genie One).
