Databricks Sandbox: вычисления по запросу без серверов для запуска недоверенного или сгенерированного агентом кода и фоновых задач. Создавайте/запускайте/останавливайте/удаляйте песочницы, выполняйте команды (синхронный execute_command_sync во всех SDK; потоковый execute_command только в Python SDK), а также управляйте файлами через SDK Databricks (Python, Java, Go, JavaScript). Используйте для Databricks Sandbox, безсерверных сред выполнения кода или сред выполнения кодирующих агентов.
