Databricks Sandbox : calcul sans serveur à la demande pour exécuter du code non fiable ou généré par un agent ainsi que des tâches en arrière-plan. Créez/démarrez/arrêtez/supprimez des sandbox, exécutez des commandes (execute_command_sync synchronisé dans tous les SDK ; execute_command en streaming uniquement dans le SDK Python) et gérez les fichiers via le SDK Databricks (Python, Java, Go, JavaScript). Utilisez‑le pour Databricks Sandbox, les environnements d’exécution de code sans serveur ou les runtimes d’agents de codage.
