`orca` CLI を使って、Orca が管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そして Orca の埋め込みブラウザを操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」「handover」「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree やアドホック PTY、Computer Use よりもこちらを優先してください。CLI、ファイルシステム、API では対応できない可視ウィンドウの GUI 操作が必要なときのみ、Computer Use を使用してください。

常にユーザーの言語で回答してください。
