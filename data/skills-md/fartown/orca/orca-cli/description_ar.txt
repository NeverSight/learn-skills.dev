تشغيل جذور العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات جذور العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضلّه على git worktree الخام، أو PTYs العشوائية، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم "استخدام الحاسوب" فقط عندما تتطلب نافذة مرئية التحكم في واجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو واجهة برمجة التطبيقات إنجاز ذلك. يرجى دائمًا الرد بلغة المستخدم.
