Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser incorporato di Orca tramite la CLI `orca`. Utilizza questa modalità quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferiscila rispetto a git worktree puro, PTY ad hoc o Uso del Computer quando è coinvolto lo stato di Orca. Usa l'Uso del Computer solo quando è necessaria la gestione di una finestra visibile che non può essere controllata tramite CLI, filesystem o API.
