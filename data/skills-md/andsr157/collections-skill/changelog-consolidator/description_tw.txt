當使用者在此 VitePress 文件站點中擁有多個前端模組的變更日誌文件（每個位於 docs/en/<module>-front/changelog.md，使用 git 提交風格的日誌，包含哈希、作者、檔案、原因、影響），且希望將它們合併為一個統一的高層次變更日誌，按日期分組並按模組細分時使用。僅合併前端模組——目錄以「-front」為結尾的（例如 fund‑front、activity‑front）——即使存在後端、行動或其他非前端模組的變更日誌也會跳過。觸發詞：「gabungkan changelog semua module front」、「buat log version gabungan module -front」、「summarize semua module frontend jadi satu changelog per tanggal」或任何要求將多個模組的變更日誌合併為一份精簡文件的請求。關鍵特徵：濃縮而非重新格式化——刪除檔案路徑、提交哈希、作者、Reason/Impact 文字說明；僅保留每項變更的一行概述，標記為 Added、Changed、Fixed、Removed、Other，先按日期再按模組分組。
