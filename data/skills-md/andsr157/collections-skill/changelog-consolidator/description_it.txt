Usa quando l'utente ha documenti di changelog provenienti da più moduli frontend in questo sito di documentazione VitePress (ognuno sotto docs/en/<module>-front/changelog.md, log in stile git‑commit con hash/autore/file/razionale/impatto) e desidera unirli in UN unico changelog consolidato a livello alto, raggruppato per data con una suddivisione per modulo. Consolidare solo i moduli frontend — directory che terminano con il suffisso “-front” (es. fund-front, activity-front) — ignorando backend, mobile o altri moduli non front anche se i loro changelog sono presenti. Trigger: “gabungkan changelog semua module front”, “buat log version gabungan module -front”, “summarize semua module frontend jadi satu changelog per tanggal”, o qualsiasi richiesta di unire più changelog per‑modulo in un unico documento condensato. Caratteristica chiave: condensazione, non riformattazione — eliminare percorsi dei file, hash dei commit, autori, testi Reason/Impact; mantenere solo una sintesi in una riga per modifica, etichettata Added/Changed/Fixed/Removed/Other, raggruppata per data poi per modulo.

Rispondi sempre nella lingua dell'utente.
