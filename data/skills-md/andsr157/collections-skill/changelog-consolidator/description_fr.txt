À utiliser lorsque l'utilisateur possède des documents de journal des modifications provenant de plusieurs modules frontend dans ce site de documentation VitePress (chacun situé sous docs/en/<module>-front/changelog.md, journaux de style git‑commit avec hash/auteur/fichier/raison/impact) et veut les fusionner en UN journal des modifications consolidé, de haut niveau, groupé par date avec un détail par module. Ne consolide que les modules frontend — les répertoires se terminant par le suffixe « -front » (par ex. fund-front, activity-front) — en ignorant les modules backend, mobile ou autres modules non‑front même si leurs journaux existent. Déclencheurs : « gabungkan changelog semua module front », « buat log version gabungan module -front », « summarize semua module frontend jadi satu changelog per tanggal », ou toute demande de fusion de plusieurs journaux de modifications par module en un seul document condensé. Caractéristique principale : condensation, pas de reformatage — supprimer les chemins de fichiers, les hachages de commit, les auteurs, le texte Reason/Impact ; ne garder qu’une seule ligne résumant chaque changement, balisée Added/Changed/Fixed/Removed/Other, groupée par date puis par module.

Veuillez toujours répondre dans la langue de l'utilisateur.
