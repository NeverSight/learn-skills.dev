Usa correttamente le librerie di effetti UI di Libraries.dev e individua dove inserirle in un progetto. Copre Border beam (border-beam), Thinking orbs (thinking-orbs), Gooey (liquid-gooey), Voice (voice-glow), Bot avatars (bot-avatars), Liquid metal (metal-fx) e Image (img-fx). Utilizza queste librerie quando aggiungi uno stato di pensiero o caricamento dell'IA, un bordo luminoso o animato attorno a un input o a una card, un visualizzatore di voce o microfono, un avatar animato di bot o agente, un pulsante o badge in metallo liquido, un segnaposto o rivelazione di generazione immagine, un blob appiccicoso o un menu liquido, o quando l'utente menziona libraries.dev o uno di questi pacchetti. Inoltre "review my project for libraries.dev", "where could I use these effects", e i comandi libraries reveal, libraries review, libraries apply.
