Сделайте так, будто любой UI генерируется AI‑агентом. Пунктирный каркас рисуется из собственной структуры элемента (контур, блоки, строки текста, пути иконок, с направляющими, угловыми ручками и метками размеров), затем реальный UI раскрывается за сканирующей линией с плавным исчезанием и замедлением. Два режима: skeleton и skeleton + generation texts (журнал агента, записываемый CSS‑motion и строка шага). Один рантайм без зависимостей, работающий с любой средой (vanilla, React, Next.js, Vue, Svelte). Используйте, когда пользователь запрашивает «анимацию генерации», «AI генерирует UI», «агент собирает компонент», «встроенную анимацию», «от каркаса к раскрытию UI», «генерацию скелета», «пунктирный каркас», «точки‑матрица», «сделать как будто сгенерировано», «футуристическое раскрытие», «генеративную загрузку UI», или для AI‑продукта, показывающего построение вывода. Также команды transitions generate, transitions generate texts и transitions generate preview.
