Lass jede Benutzeroberfläche so erscheinen, als würde ein KI‑Agent sie generieren. Ein gepunkteter Wireframe wird aus der eigenen Struktur des Elements (Umrisse, Kästen, Textzeilen, Symbolpfade, mit Hilfslinien, Eckgriffen und Größenangaben) gezeichnet, dann wird die eigentliche UI hinter einer Scan‑Linie mit einem sanften Fade‑Out enthüllt. Zwei Modi: Skeleton und Skeleton + Generierungstexte (ein Agenten‑Log, das Schreiben des Motion‑CSS und eine Schritt‑Zeile). Eine abspielfähige Laufzeit ohne Abhängigkeiten, die mit jedem Framework funktioniert (Vanilla, React, Next.js, Vue, Svelte). Verwenden, wenn der Benutzer nach einer „Generierungsanimation“, „AI generiert die UI“, „Agent baut die Komponente“, „eingebaute Animation“, „Wireframe‑zu‑UI‑Enthüllung“, „Skeleton‑Generierung“, „gepünkteter Wireframe“, „Matrix‑Dots“, „wie generiert aussehen“, „futuristische Enthüllung“, „generatives UI‑Loading“ fragt oder für ein KI‑Produkt, das seine Ausgabe beim Aufbau zeigen soll. Außerdem die Befehle transitions generate, transitions generate texts und transitions generate preview.
