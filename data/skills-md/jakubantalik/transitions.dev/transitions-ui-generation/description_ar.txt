اجعل أي واجهة مستخدم تظهر كما لو أن وكيلًا ذكيًا (AI) يقوم بإنشائها. يتم رسم إطار سلكي منقط استنادًا إلى بنية العنصر نفسها (الحد الخارجي، الصناديق، سطور النص، مسارات الأيقونات، مع الأدلة، مقابض الزوايا وعلامات الحجم)، ثم تُكشف الواجهة الحقيقية خلف خط مسح مع تلاشي بانخفاض سلس. وضعان: الهيكل العظمي والهيكل العظمي + نصوص التوليد (سجل الوكيل، كتابة CSS للحركة، وسطر خطوة). وقت تشغيل خالٍ من الاعتماديات يعمل مع أي إطار عمل (فانيلا، React، Next.js، Vue، Svelte). يُستخدم عندما يطلب المستخدم "رسوم توليد"، "AI يولد الواجهة"، "الوكيل يبني المكوّن"، "رسوم داخلية"، "كشف الإطار السلكي إلى الواجهة"، "توليد هيكل عظمي"، "إطار سلكي منقط"، "نقاط المصفوفة"، "اجعلها تبدو مولَّدة"، "كشف مستقبلي"، "تحميل واجهة مولَّدة"، أو لمنتج AI يجب أن يُظهر مخرجاته تُبنى. أيضًا الأوامر: transitions generate، transitions generate texts و transitions generate preview.
