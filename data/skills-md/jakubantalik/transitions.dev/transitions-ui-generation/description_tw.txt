讓任何 UI 看起來彷彿是由 AI 代理生成的。從元素自身的結構（輪廓、方框、文字行、圖示路徑，並包含導引線、角落控制點與尺寸標籤）繪製出點狀線框，之後真實 UI 會在掃描線後方以平滑緩出淡入的方式顯現。提供兩種模式：骨架模式與骨架加生成文字模式（包括代理日誌、正在編寫的 motion CSS 以及步驟線）。一個無任何相依的執行環境，能相容於所有框架（原生、React、Next.js、Vue、Svelte）。當使用者要求「生成動畫」、「AI 生成 UI」、「代理構建元件」、「內建動畫」、「線框到 UI 揭露」、「骨架生成」、「點狀線框」、「矩陣點」、「讓它看起來是生成的」、「未來感揭露」、「生成式 UI 載入」等情境，或是 AI 產品需要展示輸出過程時，皆可使用。此外還有指令 transitions generate、transitions generate texts 與 transitions generate preview。
