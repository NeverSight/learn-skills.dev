任意の UI を、AI エージェントが生成しているかのように見せます。要素自身の構造（アウトライン、ボックス、テキスト行、アイコンパス、ガイド、コーナーハンドル、サイズラベル）から点線のワイヤーフレームが描かれ、その後スキャンラインと滑らかなイーズアウトフェードで実際の UI が背後から現れます。モードは「スケルトン」と「スケルトン＋生成テキスト」（エージェントログ、モーション CSS の記述、ステップライン）の 2 種類があります。フレームワークに依存しないランタイムで、Vanilla、React、Next.js、Vue、Svelte などあらゆる環境で動作します。「生成アニメーション」や「AI が UI を生成している」「エージェントがコンポーネントを構築している」「ビルトインアニメーション」「ワイヤーフレームから UI のリビール」「スケルトン生成」「点線ワイヤーフレーム」「マトリックスドット」「生成されたように見せる」「未来的リビール」「ジェネレーティブ UI ローディング」などのリクエスト、または AI 製品が出力を構築している様子を示す場合に使用してください。また、コマンド `transitions generate`、`transitions generate texts`、`transitions generate preview` も利用可能です。
