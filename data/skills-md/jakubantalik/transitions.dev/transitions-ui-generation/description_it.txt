Fai apparire qualsiasi UI come se un agente IA la stesse generando. Un wireframe puntinato viene disegnato a partire dalla struttura dell'elemento (contorno, riquadri, linee di testo, percorsi delle icone, con guide, maniglie d'angolo e etichette di dimensione), poi la UI reale viene rivelata dietro una linea di scansione con una dissolvenza su un'uscita morbida. Due modalità, skeleton e skeleton + testi di generazione (un log dell'agente, il CSS di movimento che viene scritto e una riga di passo). Un runtime senza dipendenze che funziona con qualsiasi framework (vanilla, React, Next.js, Vue, Svelte). Da usare quando l'utente richiede un “animation di generazione”, “AI che genera la UI”, “agente che costruisce il componente”, “animazione integrata”, “wireframe a rivelazione UI”, “generazione skeleton”, “wireframe puntinato”, “punti matrix”, “far sembrare generato”, “rivelazione futuristica”, “caricamento UI generativa”, o per un prodotto IA che deve mostrare la costruzione del suo output. Anche i comandi transitions generate, transitions generate texts e transitions generate preview.
