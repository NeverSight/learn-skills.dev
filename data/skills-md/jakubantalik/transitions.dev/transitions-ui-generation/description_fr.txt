Faites en sorte que n'importe quelle interface utilisateur apparaisse comme si un agent IA la générait. Un filaire ponctué est dessiné à partir de la propre structure de l'élément (contour, boîtes, lignes de texte, chemins d'icônes, avec guides, poignées d'angle et étiquettes de taille), puis l'interface réelle est révélée derrière une ligne de balayage avec un fondu sur un easing‑out doux. Deux modes, squelette et squelette + textes de génération (un journal d'agent, le CSS de mouvement écrit et une ligne d’étape). Un runtime sans dépendance qui fonctionne avec n’importe quel framework (vanilla, React, Next.js, Vue, Svelte). À utiliser lorsque l'utilisateur demande une « animation de génération », « IA générant l’UI », « agent construisant le composant », « animation intégrée », « filaire à révélation UI », « génération de squelette », « filaire ponctué », « points matriciels », « faire paraître généré », « révélation futuriste », « chargement UI génératif », ou pour un produit IA qui doit montrer sa sortie en cours de construction. Les commandes : transitions generate, transitions generate texts et transitions generate preview.
