生データまたは説明から、洗練された本番グレードのスタンドアロン HTML データ分析レポートとダッシュボードを構築します。ユーザーがデータ レポート、分析ダッシュボード、ビジネス分析ページ、KPI サマリー、または複数セクションのデータ視覚化ドキュメントの作成を要求するときは常に、このスキルを使用します。また、「レポートの作成」、「このデータの視覚化」、「データのダッシュボード」、「分析 HTML」、「退货分析」、「数据报告」、「仪表盘」、「可視化报告」もトリガーします。このスキルは、ユーザーへのインタビュー、ビジュアル スタイルの選択、ECharts を使用したグラフの生成、アニメーションとインタラクションを備えた単一の自己完結型 HTML ファイルの配信など、ワークフロー全体をカバーします。常にこのスキルを使用してください。データ レポートを最初から設計しないでください。
