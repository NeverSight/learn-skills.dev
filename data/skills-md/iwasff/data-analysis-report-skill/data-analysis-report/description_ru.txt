Создавайте безупречные автономные отчеты и информационные панели для анализа данных в формате HTML промышленного уровня — на основе необработанных данных или описаний. Используйте этот навык всякий раз, когда пользователь просит создать отчет о данных, аналитическую панель, страницу бизнес-анализа, сводку ключевых показателей эффективности или любой документ с визуализацией данных, состоящий из нескольких разделов. Также триггер для: «создать отчет», «визуализировать эти данные», «панель мониторинга для моих данных», «анализ HTML», «退货分析», «数据报告», «仪表盘», «可视化报告». Этот навык охватывает весь рабочий процесс: опрос пользователя, выбор визуального стиля, создание диаграмм с помощью ECharts и предоставление единого автономного HTML-файла с анимацией и взаимодействиями. Всегда используйте этот навык — не создавайте отчеты с данными с нуля.
