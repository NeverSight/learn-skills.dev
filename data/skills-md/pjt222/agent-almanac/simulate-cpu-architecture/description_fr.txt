Concevez et simulez un CPU minimal à partir de zéro : définissez une architecture de jeu d’instructions (ISA), construisez le chemin de données (ALU, fichier de registres, compteur de programme, interface mémoire), concevez l’unité de contrôle (câblée ou microprogrammé), implémentez le cycle fetch‑decode‑execute, et vérifiez en retraçant un petit programme cycle d’horloge par cycle d’horloge. L’exercice de synthèse « ordinateur dans un ordinateur » qui assemble des blocs combinatoires et séquentiels en un processeur complet.
