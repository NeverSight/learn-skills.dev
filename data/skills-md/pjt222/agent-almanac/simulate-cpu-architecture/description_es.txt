Diseña y simula una CPU mínima desde cero: define una arquitectura de conjunto de instrucciones (ISA), construye la ruta de datos (ALU, banco de registros, contador de programa, interfaz de memoria), diseña la unidad de control (cableada o microprogramada), implementa el ciclo de búsqueda‑decodificación‑ejecución y verifica trazando un programa pequeño ciclo a ciclo. El proyecto final “computer inside a computer” que combina bloques combinacionales y secuenciales en un procesador completo.
