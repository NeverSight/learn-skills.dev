Progetta e simula una CPU minimale da zero: definisci un'architettura di set di istruzioni (ISA), costruisci il datapath (ALU, file dei registri, program counter, interfaccia di memoria), progetta l'unità di controllo (hardwired o microprogrammata), implementa il ciclo fetch‑decode‑execute e verifica tracciando un piccolo programma ciclo di clock per ciclo di clock. L’esercizio finale “computer dentro un computer” che combina blocchi combinatori e sequenziali in un processore completo.
