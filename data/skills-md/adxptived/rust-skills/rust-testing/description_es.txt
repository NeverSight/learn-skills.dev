Pruebas de óxido: pruebas unitarias, pruebas de integración, pruebas de propiedades, puntos de referencia. Utilice esta habilidad cuando:
- El usuario escribe pruebas con #[test], #[tokio::test] o módulos de prueba
- El usuario pregunta sobre la organización de la prueba, los ayudantes de la prueba o los accesorios.
- El usuario implementa pruebas basadas en propiedades con proptest o quickcheck
- El usuario escribe puntos de referencia con criterio.
- El usuario se burla de los rasgos con Mockall o usa dobles de prueba.
- El usuario pregunta sobre las pruebas de instantáneas con insta.
- El usuario prueba el código asíncrono o las tareas de Tokio
- El usuario pregunta sobre cobertura, aislamiento de prueba o configuración de CI
Activador para cualquier pregunta de prueba de Rust.
