Test di ruggine: test unitari, test di integrazione, test di proprietà, benchmark. Usa questa abilità quando:
- L'utente scrive test con #[test], #[tokio::test] o moduli di test
- L'utente chiede informazioni sull'organizzazione del test, sugli aiutanti del test o sugli impianti
- L'utente implementa test basati sulle proprietà con proptest o quickcheck
- L'utente scrive benchmark con criterio
- L'utente prende in giro i tratti con mockall o utilizza i doppi di test
- L'utente chiede informazioni sul test degli snapshot con insta
- L'utente testa il codice asincrono o le attività Tokio
- L'utente chiede informazioni sulla copertura, sull'isolamento del test o sulla configurazione CI
Attiva per qualsiasi domanda sul test della ruggine.
