Тестирование на ржавчину — юнит-тесты, интеграционные тесты, тесты свойств, бенчмарки. Используйте этот навык, когда:
- Пользователь пишет тесты с помощью #[test], #[tokio::test] или тестовых модулей.
- Пользователь спрашивает об организации тестирования, помощниках по тестированию или приспособлениях.
- Пользователь реализует тестирование на основе свойств с помощью proptest или быстрой проверки.
- Пользователь пишет тесты с критерием
- Пользователь имитирует черты с помощью макета или использует тестовые двойники.
- Пользователь спрашивает о тестировании снимков с помощью Insta.
- Пользователь тестирует асинхронный код или задачи Tokio.
- Пользователь спрашивает о покрытии, изоляции тестирования или конфигурации CI.
Триггер для любого вопроса о тестировании Rust.
