اختبار الصدأ - اختبارات الوحدة، اختبارات التكامل، اختبارات الملكية، المعايير. استخدم هذه المهارة عندما:
- يكتب المستخدم الاختبارات باستخدام وحدات #[test] أو #[tokio::test] أو وحدات اختبار
- يسأل المستخدم عن تنظيم الاختبار، أو مساعدي الاختبار، أو التركيبات
- يقوم المستخدم بتنفيذ الاختبار القائم على الخاصية باستخدام Proptest أو QuickCheck
- يكتب المستخدم المعايير مع المعيار
- يسخر المستخدم من السمات باستخدام صور وهمية أو يستخدم اختبارًا مزدوجًا
- يسأل المستخدم عن اختبار اللقطات باستخدام insta
- يقوم المستخدم باختبار الكود غير المتزامن أو مهام Tokio
- يسأل المستخدم عن التغطية أو عزل الاختبار أو تكوين CI
قم بتشغيل أي سؤال يتعلق باختبار الصدأ.
