Rosttests – Unit-Tests, Integrationstests, Eigenschaftstests, Benchmarks. Verwenden Sie diese Fähigkeit, wenn:
– Der Benutzer schreibt Tests mit #[test], #[tokio::test] oder Testmodulen
- Benutzer fragt nach Testorganisation, Testhelfern oder Vorrichtungen
- Der Benutzer implementiert eigenschaftsbasierte Tests mit Proptest oder Quickcheck
- Benutzer schreibt Benchmarks mit Kriterium
- Der Benutzer verspottet Merkmale mit Mockall oder verwendet Testdoppel
– Benutzer fragt nach Snapshot-Tests mit Insta
- Benutzer testet asynchronen Code oder Tokio-Aufgaben
– Der Benutzer fragt nach Abdeckung, Testisolation oder CI-Konfiguration
Auslöser für jede Rust-Testfrage.
