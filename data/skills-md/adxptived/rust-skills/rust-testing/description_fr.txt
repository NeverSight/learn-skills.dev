Tests de rouille – tests unitaires, tests d'intégration, tests de propriétés, benchmarks. Utilisez cette compétence lorsque :
- L'utilisateur écrit des tests avec #[test], #[tokio::test] ou des modules de test
- L'utilisateur pose des questions sur l'organisation des tests, les aides aux tests ou les appareils.
- L'utilisateur implémente des tests basés sur les propriétés avec proptest ou quickcheck
- L'utilisateur écrit des benchmarks avec critère
- L'utilisateur se moque des traits avec mockall ou utilise des doubles de test
- L'utilisateur pose des questions sur les tests d'instantanés avec Insta
- L'utilisateur teste le code asynchrone ou les tâches Tokio
- L'utilisateur pose des questions sur la couverture, l'isolement des tests ou la configuration du CI
Déclencheur pour toute question de test Rust.
