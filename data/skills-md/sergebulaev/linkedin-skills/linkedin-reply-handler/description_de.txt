Entwerfen Sie eine Antwort auf einen LinkedIn‑Kommentar anhand seiner URL oder erfassen Sie einen gesamten Thread anhand der Beitrags‑URL und erstellen Sie in einem Durchgang Antworten für alle Kommentare, die es wert sind, beantwortet zu werden. Verwenden Sie es zum Beantworten eines Kommentars, zum Folgen einer Autoren‑Antwort oder zum Bereinigen aller Kommentare eines Beitrags. Ermittelt das korrekte parentComment (LinkedIn flacht Threads auf 2 Ebenen ab), filtert niedrigwertige Kommentare vor einem Sweep und veröffentlicht nach Freigabe über Publora. Nicht für Kommentare der ersten Ebene geeignet (verwenden Sie linkedin-comment-drafter).
