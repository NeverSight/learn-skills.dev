Exploitez les arbres de travail gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires d'arbre de travail et le navigateur intégré d'Orca via la CLI `orca`. Utilisez‑le lorsque l'utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Préférez‑le aux arbres de travail Git bruts, aux PTY ad hoc ou à l'Utilisation de l'ordinateur lorsqu'un état Orca est impliqué. N'utilisez l'Utilisation de l'ordinateur que lorsqu'une fenêtre visible nécessite un contrôle GUI qu'une CLI, le système de fichiers ou une API ne peuvent assurer.
