Orcaが管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そしてOrcaの組み込みブラウザを `orca` CLI で操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関係する場合は、生の git worktree、臨時 PTY、あるいは Computer Use よりもこちらを優先します。GUI 操作が必要で CLI、ファイルシステム、API だけでは実行できない可視ウィンドウがある場合にのみ、Computer Use を使用してください。
