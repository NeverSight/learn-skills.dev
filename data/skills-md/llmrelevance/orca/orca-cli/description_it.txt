Operare worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Utilizzarlo quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferirlo rispetto a un worktree git grezzo, PTY ad hoc o uso del computer quando è coinvolto lo stato di Orca. Usare l'uso del computer solo quando una finestra visibile richiede il controllo GUI che una CLI, il filesystem o un'API non possono fare.

Rispondi sempre nella lingua dell'utente.
