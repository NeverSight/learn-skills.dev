Adatta un'app React Native o Expo a iPhone Duo, il primo iPhone pieghevole di Apple — margini di area sicura asimmetrici, gestione del ridimensionamento e modalità per esporre le API della regione riservata iOS 27.1 e della cerniera tramite un modulo nativo. Da utilizzare quando un'app iOS basata su React Native, Expo o JavaScript ha bisogno del supporto per iPhone pieghevole.
