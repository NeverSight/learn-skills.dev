تكييف تطبيق React Native أو Expo ليعمل على iPhone Duo، أول هاتف قابل للطي من Apple — حدود المنطقة الآمنة غير المتناظرة، معالجة تغيير الحجم، وكيفية إتاحة واجهات برمجة التطبيقات للمنطقة المحجوزة والمحور في iOS 27.1 عبر وحدة نيتيف. يُستخدم عندما يحتاج تطبيق iOS مبني بـ React Native أو Expo أو جافاسكريبت إلى دعم هواتف iPhone القابلة للطي.
