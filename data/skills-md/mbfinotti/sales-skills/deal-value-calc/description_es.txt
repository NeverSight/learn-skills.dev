Construye el ROI y el caso de negocio para una transacción: impulsores de valor, inversión total, ROI, retorno, tres escenarios (conservador primero) y un caso de una página que el campeón pueda reenviar. El comprador proporciona cada suposición, cada número etiquetado como provisto por el comprador, referencia de mercado o asumido por el representante, y ninguno es inventado. Cubre B2B y B2C de alto ticket. Úsalo siempre que el usuario mencione ROI, caso de negocio, período de retorno, TCO, costo de no hacer nada, “justificar el precio” o la aprobación del CFO, incluso sin la palabra valor. NO lo uses para refutaciones de precio (mbfinotti/sales-skills@sales-objection-handling) ni para planificación de descuentos (mbfinotti/sales-skills@negotiation-concession-planner).
