Определить критерии подбора креаторов и создать бриф для поиска, используемый для составления короткого списка кандидатов‑инфлюенсеров и креаторов — взвешенные критерии соответствия аудитории, качества вовлечённости, согласованности ниши и безопасности бренда, отсева по критическим пунктам, а также шаблон оценочного ранжированного короткого списка с доказательствами для каждой оценки. Охватывает B2C‑кампании брендов и B2B‑программы для креаторов и лидеров мнений. Использовать каждый раз, когда пользователь упоминает поиск креаторов, проверку инфлюенсеров, соответствие аудитории, короткие списки креаторов или решение, к каким креаторам обратиться, даже если они не используют слово «поиск». Выполняется до любого контакта. НЕ использовать для написания самого сообщения‑презентации — вместо этого использовать mbfinotti/partnerships-skills@influencer-outreach.
