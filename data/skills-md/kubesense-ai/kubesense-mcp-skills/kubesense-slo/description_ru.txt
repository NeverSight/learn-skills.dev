Создавайте, читайте и управляйте целевыми уровнями обслуживания (SLO) KubeSense через REST API — SLIs по количеству (by_count), по временному срезу (time_slice) и времени доступности оповещения (alert‑uptime), бюджеты ошибок, оповещения о скорости расхода и группировку — и переводите SLO из Datadog в эквивалентные SLO KubeSense. Охватывается точный набор данных POST /api/slo, форма конфигурации запроса good/total, которую она делит с правилами оповещений, и подводные камни, из‑за которых хранилище SLO сохраняется корректно, но затем ничего не оценивает.
