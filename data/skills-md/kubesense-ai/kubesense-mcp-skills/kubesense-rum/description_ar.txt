جمع وقراءة بيانات مراقبة المستخدم الفعلية (RUM) عبر KubeSense MCP — الجلسات، المشاهدات، الإجراءات، الأخطاء، الموارد والمهام الطويلة من المتصفحات وتطبيقات الجوال. يغطي إشارات rum_<type>، كتالوج الحقول حسب نوع الحدث، الحقول التي تقبل LIKE أو group‑by، الفترات الزمنية بالنانوثانية وتوائمها _ms/_s، أعلام الميزات والسمات، وشكل لوحة التحكم. العدّات، المعدلات والنسب المئوية باستخدام analyze‑telemetry، والصفوف الخام باستخدام search‑rum. لا يوجد تنبيهات، ولا SQL ولا SPL لــ RUM.
