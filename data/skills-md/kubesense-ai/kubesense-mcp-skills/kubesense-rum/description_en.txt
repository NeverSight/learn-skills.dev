Aggregate and read real user monitoring (RUM) data via KubeSense MCP — sessions, views, actions, errors, resources and long tasks from browser and mobile apps. Covers the rum_<type> signals, the per-event-type field catalog, which fields accept LIKE or group-by, nanosecond durations and their _ms/_s twins, feature flags and attributes, and the dashboard panel shape. Counts, rates and percentiles with analyze-telemetry, raw rows with search-rum. There is no alerting, SQL or SPL for RUM.
