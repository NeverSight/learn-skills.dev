Triaje, validación y escalada de gravedad del informe de recompensas por errores. Se usa cuando el usuario proporciona un informe de recompensas por errores para validar, quiere verificar si un hallazgo es susceptible de envío, necesita escalar la gravedad para obtener el pago máximo o dice 'clasificar esto', 'validar este informe', 'escalar esto', 'es este susceptible de envío', 'verificar este informe de recompensas', 'recompensa máxima' o 'se aceptará esto'.
