Automatiza la refactorización de cargas de trabajo de Python en Alibaba Cloud (OSS V1/V2, SLS, OpenAPI genérico) de AccessKey/SecretKey de largo plazo a credenciales STS de corto plazo sin AK de IDaaS. Úselo cuando un desarrollador solicite integrar/onboard IDaaS 无AK, eliminar AK/SK codificados o convertir código Python en la nube a proveedores de credenciales PAM de IDaaS.
