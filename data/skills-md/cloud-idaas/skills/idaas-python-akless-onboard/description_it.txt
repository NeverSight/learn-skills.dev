Automatizza il refactoring dei carichi di lavoro Python su Alibaba Cloud (OSS V1/V2, SLS, OpenAPI generico) passando da AccessKey/SecretKey a lungo termine a credenziali STS a breve termine senza AK fornite da IDaaS. Da utilizzare quando uno sviluppatore richiede di introdurre/integrate IDaaS senza AK, rimuovere gli AK/SK hard‑coded o convertire il codice cloud Python in provider di credenziali PAM di IDaaS.
