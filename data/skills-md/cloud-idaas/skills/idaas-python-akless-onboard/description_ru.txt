Автоматизирует рефакторинг Python‑приложений для Alibaba Cloud (OSS V1/V2, SLS, общий OpenAPI) с долгосрочных AccessKey/SecretKey на краткосрочные STS‑учётные данные без AK в IDaaS. Используйте, когда разработчик просит подключить/интегрировать IDaaS 无AK, удалить жёстко закодированные AK/SK или преобразовать Python‑код облака к провайдерам учётных данных IDaaS PAM.
