Automatise le refactoring des charges de travail Python sur Alibaba Cloud (OSS V1/V2, SLS, OpenAPI générique) du AccessKey/SecretKey à long terme vers des identifiants STS à court terme sans AK d'IDaaS. Utilisez-le lorsqu'un développeur demande d'intégrer IDaaS sans AK, de supprimer les AK/SK codés en dur, ou de convertir le code cloud Python en fournisseurs d'identifiants PAM d'IDaaS.
