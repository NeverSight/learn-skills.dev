استخدم عندما تقوم ببناء واجهة مستخدم لتطبيق Hono باستخدام hono/jsx — الصفحات، التخطيطات، النماذج، والأجزاء التفاعلية — المُعالجة على الخادم عبر jsxRenderer، المطوَّرة والمبنية بـ Vite، مع مكوّنات العميل عبر hono/jsx/dom. يتم التفعيل عندما يحتوي tsconfig على jsxImportSource "hono/jsx"، أو يستورد الكود أحد الحزم التالية: 'hono/jsx'، 'hono/jsx/dom'، 'hono/jsx-renderer' أو 'vite-ssr-components'، أو عندما يطلب المستخدم صفحة أو شاشة أو تخطيط أو نموذج في مشروع Hono. لا تستخدم React أبداً.  

يرجى دائماً الرد بلغة المستخدم.
