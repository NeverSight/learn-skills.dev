تشغيل شجرات العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والآتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر سطر الأوامر `orca`. استخدم ذلك عندما يذكر المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل ذلك على شجرة git العادية، أو PTY موقتة، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم "Computer Use" فقط عندما تحتاج نافذة مرئية إلى تحكم رسومي لا يمكن لسطر الأوامر أو نظام الملفات أو الـ API القيام به.
