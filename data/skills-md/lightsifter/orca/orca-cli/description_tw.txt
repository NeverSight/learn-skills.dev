操作 Orca 管理的工作樹、資料夾上下文、終端機、儲存庫、自動化、產物、技能分享、工作樹註解，以及 Orca 內嵌瀏覽器，皆透過 `orca` CLI。當使用者說「$orca-cli」或「Orca worktree」或「child worktree」或「spawn codex/claude in a worktree」或「read/wait/send Orca terminal」或「handoff」/「handover」/「give this to another agent」或「Orca browser」或「orca artifacts」或「share skills」時，即使用此方式。涉及 Orca 狀態時，請優先使用此方式，而非原始 git worktree、臨時 PTY 或 Computer Use。僅在需要控制可見視窗且 CLI、檔案系統或 API 無法完成時，才使用 Computer Use。
