`orca` CLI を使用して、Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザーを操作します。ユーザーが「$orca‑cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関与する場合は、生の git worktree、臨時の PTY、またはコンピュータ使用（Computer Use）よりもこれを優先してください。CLI、ファイルシステム、API では対応できない可視ウィンドウの GUI 制御が必要なときにだけ Computer Use を使用してください。常にユーザーの言語で回答してください。
