Verwende von Orca verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repos, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaumkommentare und den integrierten Browser von Orca über das `orca`‑CLI. Nutze es, wenn der Benutzer „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“ sagt. Bevorzuge es gegenüber rohem Git‑Worktree, ad‑hoc PTYs oder Computer‑Use, wenn Orca‑Zustand involviert ist. Verwende Computer‑Use nur, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die ein CLI, Dateisystem oder eine API nicht leisten kann.
