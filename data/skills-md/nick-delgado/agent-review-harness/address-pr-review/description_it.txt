Correggi le osservazioni di codice di una revisione PR di un agente. Legge il rapporto di revisione pubblicato dalla skill review-agent-pr come commento su una pull request di GitHub, corregge le osservazioni contrassegnate con "Fix now" sul ramo PR, applica le decisioni del proprietario, chiede al proprietario una sola volta tutto ciò che non può fare nell'ambito della PR, e risponde sulla PR con quanto è stato fatto per ciascuna osservazione. Usalo quando ti viene chiesto di affrontare, correggere, risolvere o rispondere al rapporto di revisione o alle osservazioni di revisione su una PR.

Rispondi sempre nella lingua dell'utente.
