Corriger les constats de code d’un examen d’agent PR. Lit le rapport de révision que la compétence review-agent-pr a publié en commentaire sur une pull request GitHub, corrige les constats marqués « Fix now » sur la branche PR, applique les décisions du propriétaire, demande une fois au propriétaire tout ce qu’il n’a pas pu faire dans le cadre de la PR, et répond sur la PR avec ce qui a été fait pour chaque constat. Utilisez‑le lorsqu’on vous demande d’aborder, de corriger, de résoudre ou de répondre au rapport de révision ou aux constats de révision sur une PR.
