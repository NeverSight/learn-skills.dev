حوّل نتائج مراجعات طلبات السحب (PR) للعديد من الوكلاء إلى طلب سحب موحد يُحسّن إعداد الوكيل في المشروع. يقرأ مسألة التتبع حيث تُسجِّل مهارة review-agent-pr سبب إنتاج الوكلاء لكل نتيجة، يحسب الأسباب المتكررة عبر المراجعات، يختار التغييرات المقترحة في الوثائق والمهارات والتعليمات والاختبارات وفحوصات CI التي تستحق التنفيذ، يتحقق منها مقابل الشيفرة الحالية، ويفتح طلب سحب واحد بعد موافقة المستخدم على الاختيار. يُستخدم عندما يُطلب تحسين أو تحديث أو إصلاح عملية الوكيل أو التعليمات أو المهارات بناءً على نتائج المراجعة، أو للتعامل مع مسألة تتبع عملية الوكيل.

يرجى دائماً الرد بلغة المستخدم.
