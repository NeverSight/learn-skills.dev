Преобразуйте выводы нескольких проверок PR‑агентов в один пакетный pull request, который улучшит настройку агентов проекта. Читает задачу‑отслеживание, где навык review-agent-pr фиксирует, почему агенты сделали каждое замечание, подсчитывает, какие причины повторяются в разных проверках, выбирает предлагаемые изменения в документацию, навыки, подсказки, тесты и проверки CI, которые стоит выполнить, сопоставляет их с текущим кодом и открывает один PR после одобрения выбора пользователем. Используйте, когда просят улучшить, обновить или исправить процесс агентов, инструкции или навыки на основе выводов проверок, либо действовать по задаче‑отслеживанию процесса агентов. Пожалуйста, всегда отвечайте на языке пользователя.
