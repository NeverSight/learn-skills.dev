Wandle die Ergebnisse mehrerer Agent‑PR‑Reviews in einen zusammengefassten Pull Request um, der das Agenten‑Setup des Projekts verbessert. Liest das Tracking‑Issue, in dem die review‑agent‑pr‑Fähigkeit protokolliert, warum Agenten jede Erkenntnis erzeugt haben, ermittelt, welche Ursachen sich über mehrere Reviews wiederholen, wählt die vorgeschlagenen Änderungen an Dokumentation, Fähigkeiten, Eingabeaufforderungen, Tests und CI‑Checks aus, die sinnvoll sind, prüft sie gegenüber dem aktuellen Code und eröffnet einen einzelnen Pull Request, nachdem der Nutzer die Auswahl genehmigt hat. Verwende es, wenn du gebeten wirst, den Agentenprozess, Anweisungen oder Fähigkeiten anhand von Review‑Ergebnissen zu verbessern, zu aktualisieren oder zu korrigieren, oder um auf das Tracking‑Issue des Agentenprozesses zu reagieren. Bitte antworte stets in der Sprache des Benutzers.
