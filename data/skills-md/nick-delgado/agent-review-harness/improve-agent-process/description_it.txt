Trasforma i risultati di diverse revisioni PR degli agenti in un'unica pull request batchata che migliori la configurazione dell'agente del progetto. Legge la issue di tracciamento dove la skill review‑agent‑pr registra perché gli agenti hanno prodotto ogni risultato, conta quali cause si ripetono tra le revisioni, seleziona le modifiche proposte a documenti, skill, prompt, test e controlli CI che valgono la pena realizzare, le confronta con il codice attuale e apre una singola PR dopo che l'utente approva la selezione. Usa questo quando ti viene chiesto di migliorare, aggiornare o correggere il processo dell'agente, le istruzioni o le skill dai risultati della revisione, o per agire sulla issue di tracciamento del processo dell'agente.

Rispondi sempre nella lingua dell'utente.
