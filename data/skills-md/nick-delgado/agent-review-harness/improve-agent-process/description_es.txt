Convierte los hallazgos de varias revisiones de PR de agentes en una única solicitud de extracción agrupada que mejore la configuración del agente del proyecto. Lee el issue de seguimiento donde la habilidad review-agent-pr registra por qué los agentes produjeron cada hallazgo, cuenta qué causas se repiten en las revisiones, selecciona los cambios propuestos a la documentación, habilidades, indicaciones, pruebas y verificaciones CI que valen la pena, los verifica contra el código actual y abre una única PR después de que el usuario apruebe la selección. Úsalo cuando se solicite mejorar, actualizar o corregir el proceso del agente, sus instrucciones o habilidades a partir de los hallazgos de la revisión, o para actuar sobre el issue de seguimiento del proceso del agente.
