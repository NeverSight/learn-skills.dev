Transformez les résultats de plusieurs revues de PR d’agent en une seule pull request groupée qui améliore la configuration de l’agent du projet. Lit le ticket de suivi où la compétence review‑agent‑pr consigne pourquoi les agents ont produit chaque constat, compte les causes qui se répètent à travers les revues, sélectionne les changements proposés aux documents, compétences, prompts, tests et contrôles CI qui méritent d’être faits, les compare au code actuel, et ouvre une PR unique après que l’utilisateur ait approuvé la sélection. Utilisez‑le lorsqu’on vous demande d’améliorer, de mettre à jour ou de corriger le processus d’agent, les instructions ou les compétences à partir des constatations de revue, ou pour agir sur le ticket de suivi du processus d’agent.

Veuillez toujours répondre dans la langue de l’utilisateur.
