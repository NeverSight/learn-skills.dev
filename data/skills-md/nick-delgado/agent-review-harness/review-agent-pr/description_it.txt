Revisione approfondita multi‑revisore di una pull request di GitHub prodotta da un agente di codifica AI. Avvia revisori specialisti in parallelo (standard documentati, code smell, allineamento alla specifica, adeguatezza dei test), verifica ogni riscontro e pubblica un unico report supportato da evidenze come commento della PR, distinguendo ciò che l’agente deve correggere da ciò che richiede la decisione del proprietario. Analizza inoltre perché l’agente ha generato ciascun problema e registra le cause e le proposte di miglioramento per la documentazione del progetto, i prompt, le competenze e i test in una issue di tracciamento. Da usare quando si richiede di revisionare, auditare o valutare una PR o un branch scritto da un agente AI, o per scoprire perché l’output di un agente è andato storto. Esegue anche una verifica più economica di una PR già revisionata, controllando solo le modifiche successive e lo stato di ciascun riscontro precedente, quando viene chiesto di ricontrollare una PR.
