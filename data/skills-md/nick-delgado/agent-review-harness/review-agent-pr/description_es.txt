Revisión exhaustiva de múltiples revisores de un pull request de GitHub generado por un agente de codificación de IA. Ejecuta revisores especializados en paralelo (estándares documentados, olores de código, alineación con la especificación, adecuación de pruebas), verifica cada hallazgo y publica un informe respaldado por evidencia como comentario del PR que separa lo que el agente debe corregir de lo que requiere la decisión del propietario. Además analiza por qué el agente produjo cada problema y registra las causas y mejoras propuestas en la documentación del proyecto, los prompts, las habilidades y las pruebas en un issue de seguimiento. Úsalo cuando se solicite revisar, auditar o evaluar un PR o rama escrito por un agente de IA, o para averiguar por qué la salida del agente falló. También realiza una verificación más económica de un PR que ya fue revisado, verificando solo lo que cambió desde entonces y el estado de cada hallazgo anterior, cuando se pida volver a revisar un PR.
