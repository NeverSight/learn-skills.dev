مراجعة شاملة متعددة المراجعين لطلب سحب (Pull Request) على GitHub تم إنشاؤه بواسطة وكيل برمجة ذكي. يقوم بتشغيل مراجعين متخصصين متوازنين (معايير موثقة، رائحة الكود، توافق المواصفات، كفاية الاختبارات)، يتحقق من كل نتيجة، وينشر تقريرًا موثقًا بالأدلة كتعليق على طلب السحب يفرق بين ما يجب على الوكيل تصحيحَه وما يتطلب قرار المالك. كما يحلل لماذا أنتج الوكيل كل مشكلة ويسجل الأسباب والتحسينات المقترحة لوثائق المشروع، والمطالبات، والمهارات، والاختبارات في قضية تتبع. يُستخدم عند الطلب لمراجعة، تدقيق أو تقييم طلب سحب أو فرع مكتوب بواسطة وكيل ذكي، أو لمعرفة سبب حدوث خطأ في مخرجات الوكيل. كما يُجري فحصًا إعيديًا أقل تكلفة لطلب سحب تم مراجعته مسبقًا، للتحقق فقط مما تغير منذ ذلك الحين وما حدث لكل نتيجة سابقة، عند طلب إعادة الفحص. يرجى دائمًا الرد بلغة المستخدم.
