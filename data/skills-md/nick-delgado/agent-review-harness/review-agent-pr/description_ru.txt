Тщательный многоэкспертный обзор pull request на GitHub, выполненный ИИ‑агентом по кодированию. Параллельно работают специализированные рецензенты (по документированным стандартам, «запахам» кода, соответствию спецификации, адекватности тестов), проверяют каждое замечание и публикуют один подкреплённый доказательствами отчёт в виде комментария к PR, в котором разделяют то, что агент должен исправить, и то, что требует решения владельца. Также анализирует, почему агент возникли каждое из замечаний, и фиксирует причины и предлагаемые улучшения в документацию проекта, подсказки, навыки и тесты в отслеживающем issue. Используется при запросе обзора, аудита или оценки PR или ветки, написанной ИИ‑агентом, или для выяснения причин ошибок вывода агента. Кроме того, выполняет более экономичный повторный чек PR, уже ранее проверенного, проверяя только изменения с момента последней проверки и текущий статус каждого предыдущего замечания, когда требуется повторная проверка PR.
