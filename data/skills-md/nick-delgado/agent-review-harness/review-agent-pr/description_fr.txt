Examen approfondi multirelecteur d’une pull request GitHub produite par un agent de codage IA. Met en place des réviseurs spécialistes parallèles (normes documentées, mauvaises pratiques de code, alignement avec les spécifications, adéquation des tests), vérifie chaque constatation et publie un rapport étayé par des preuves sous forme de commentaire PR qui sépare ce que l’agent doit corriger de ce qui nécessite la décision du propriétaire. Analyse également pourquoi l’agent a généré chaque problème et consigne les causes ainsi que les améliorations proposées pour la documentation du projet, les prompts, les compétences et les tests dans un ticket de suivi. À utiliser lorsqu’on demande d’examiner, d’auditer ou d’évaluer une PR ou une branche rédigée par un agent IA, ou pour découvrir pourquoi la sortie d’un agent a échoué. Effectue également une re‑vérification moins coûteuse d’une PR déjà examinée, vérifiant uniquement les modifications depuis et l’état de chaque constatation antérieure, lorsqu’on demande de revérifier une PR.
