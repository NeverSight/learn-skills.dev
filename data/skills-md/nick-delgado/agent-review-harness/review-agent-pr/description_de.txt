Gründliche Mehrfach‑Reviewer‑Prüfung eines GitHub‑Pull‑Requests, der von einem KI‑Coding‑Agent erstellt wurde. Führt parallele Fach‑Reviewer (dokumentierte Standards, Code Smells, Spezifikations‑Übereinstimmung, Testabdeckung) aus, verifiziert jede Feststellung und postet einen evidenzbasierten Bericht als PR‑Kommentar, der trennt, was der Agent korrigieren muss, von dem, was die Entscheidung des Besitzers erfordert. Analysiert zudem, warum der Agent jedes Problem erzeugt hat, und protokolliert Ursachen sowie vorgeschlagene Verbesserungen für die Projektdokumentation, Prompts, Skills und Tests in einem Tracking‑Issue. Wird eingesetzt, wenn ein PR oder Branch, der von einem KI‑Agent geschrieben wurde, geprüft, auditiert oder bewertet werden soll, oder um herauszufinden, warum die Ausgabe des Agenten fehlerhaft war. Führt außerdem bei Bedarf eine günstigere Nachprüfung eines bereits geprüften PR durch, indem nur das seitdem geänderte geprüft wird und der aktuelle Stand früherer Befunde ermittelt wird.
