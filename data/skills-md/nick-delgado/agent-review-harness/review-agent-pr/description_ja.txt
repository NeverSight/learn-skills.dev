AI コーディングエージェントが作成した GitHub プルリクエストに対する徹底的なマルチレビュー。文書化された標準、コードスメル、仕様適合、テストの十分性など、専門分野ごとのレビュアーを並行して実行し、すべての指摘を検証し、エビデンスに基づくレポートを PR コメントとして一括投稿する。エージェントが修正すべき点とオーナーの判断が必要な点を分けて示す。また、エージェントが各問題を生成した理由を分析し、原因とプロジェクトのドキュメント、プロンプト、スキル、テストへの改善提案を追跡イシューに記録する。AI エージェントが書いた PR やブランチのレビュー、監査、評価、あるいはエージェントの出力が失敗した原因を調べる際に使用する。以前にレビュー済みの PR を再チェックする際は、変更点と以前の指摘の現状だけを確認する安価な再チェックも実行できる。
