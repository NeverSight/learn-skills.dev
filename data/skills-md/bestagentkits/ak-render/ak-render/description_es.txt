Muestra un plan, informe, resumen, revisión de diferencias, panel, explicativo o comparación como una única página HTML pulida y sin conexión. Escribe una especificación corta de página en YAML y compílala con la CLI ak-render (paquete npm @bestagentkits/render) en lugar de escribir manualmente HTML, CSS o JavaScript. Úsalo cuando el usuario solicite un informe HTML, una página visual o compartible, una actualización de estado, un resumen de revisión de código, un panel de KPIs, una línea de tiempo, una lista de verificación o una revisión de riesgos, o cuando un resultado extenso se lea mejor como una página que como texto de terminal.
