Mostra un piano, un report, un riepilogo, una revisione delle differenze, un dashboard, una spiegazione o un confronto in una singola pagina HTML offline rifinita. Scrivi una breve specifica della pagina in YAML e compilandola con il CLI ak-render (pacchetto npm @bestagentkits/render) invece di scrivere manualmente HTML, CSS o JavaScript. Usa questa modalità quando l'utente richiede un report HTML, una pagina visuale o condivisibile, un aggiornamento di stato, un riepilogo di revisione del codice, un dashboard KPI, una timeline, una checklist o una revisione dei rischi, o quando un risultato lungo risulta più leggibile come pagina anziché come testo nel terminale.

Rispondi sempre nella lingua dell'utente.
