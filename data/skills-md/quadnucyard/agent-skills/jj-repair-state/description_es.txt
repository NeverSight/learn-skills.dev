Diagnosticar y reparar una operación de Jujutsu (jj) o un estado de copia de trabajo corruptos en un repositorio Git colocalizado. Úselo cuando jj informe de confirmaciones o árboles Git faltantes, de desajustes entre operation-head y checkout-operation, de instantáneas de la copia de trabajo fallidas o de solicitudes para conservar confirmaciones Git accesibles mientras se reparan los metadatos de jj.
