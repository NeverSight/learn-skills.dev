Entwerfen Sie Softwarefunktionen und verwandeln Sie Anforderungen in umsetzbare, schrittweise Implementierungspläne, indem Sie die Aufschlüsselung der Funktionen, die Architektur, wichtige Datentypen und Risiken in einfacher Sprache besprechen, wobei Sie Entscheidungen, die von den Nutzern bestätigt wurden, Prioritäten für Funktionen, evidenzbasierte Sicherheit und effektive Tests berücksichtigen. Verwenden Sie diese Methode, wenn Sie eine neue Funktion planen, ein bestehendes Verhalten erweitern, ein bestehendes System neu gestalten oder einen Vorschlag in überprüfbare Umsetzungsschritte unterteilen.
