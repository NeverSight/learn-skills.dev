Revise los planes de funcionalidades para comprobar que haya límites y dependencias claros de las funcionalidades, capas verticales procesables, crecimiento gradual de las funcionalidades que interactúan, «commits» pequeños y verificables, complejidad del diseño, alcance completo y validación efectiva; rechace los planes que no se puedan revisar con una solicitud de reescritura. Úselo para auditar un plan de funcionalidades existente o evaluar el grado de preparación para la implementación, en lugar de crear un plan o revisar el código implementado.
