Überprüfen Sie Funktionspläne auf klare Funktionsgrenzen und -abhängigkeiten, umsetzbare vertikale Slices, inkrementelles Wachstum interagierender Funktionen, kleine überprüfbare Commits, Designkomplexität, vollständigen Umfang und effektive Validierung. Lehnen Sie nicht überprüfbare Pläne mit einer Aufforderung zur Überarbeitung ab. Verwenden Sie diese Methode, um einen bestehenden Funktionsplan zu prüfen oder die Umsetzungsreife zu bewerten, anstatt einen Plan zu erstellen oder implementierten Code zu überprüfen.
