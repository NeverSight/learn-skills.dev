Usar cuando el usuario quiere un video creado, editado o finalizado: un video de lanzamiento o promocional, una demo de producto, un explicativo, un tráiler o teaser, un tutorial o recorrido, una grabación de pantalla convertida en demo, un corto para redes sociales, reel, TikTok o YouTube Short, una presentación de fotos, un gráfico animado o historia de datos, motion graphics o animación, una intro, outro o sting de logotipo animado, lower thirds, un audiograma, video musical; subtítulos o leyendas para un video; una voz en off o narración; música o efectos de sonido para un video; una miniatura o fotograma de póster del video; ediciones de metraje como cortar los “ums”, eliminar silencios, ajustar un “talking head”, clips de podcast o entrevista; reencuadrar a vertical; volver a grabar la voz o subtitular un video en otro idioma; convertir un repositorio, sitio web, pull request o changelog en un video; o cuando escriben /showtime. No es para editar imágenes fijas, escribir una leyenda para una publicación de foto, o código no relacionado con un video.
