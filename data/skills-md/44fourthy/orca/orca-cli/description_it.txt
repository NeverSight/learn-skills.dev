Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di abilità, commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Utilizza quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferiscila rispetto a un worktree git raw, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Usa Computer Use solo quando una finestra visibile richiede il controllo GUI che una CLI, il filesystem o l'API non possono fare.
