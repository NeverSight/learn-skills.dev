تشغيل شجرات العمل التي يديرها Orca، وسياقات المجلد، والطرفيات، والمستودعات، والأتمتة، والقطع الأثرية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر واجهة سطر الأوامر `orca`. استخدمها عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضلها على شجرة git العادية، أو PTYs المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متورطة. استخدم استخدام الكمبيوتر فقط عندما تحتاج نافذة مرئية إلى تحكم GUI لا يمكن لسطر الأوامر أو نظام الملفات أو API تنفيذه.  

يرجى دائمًا الرد بلغة المستخدم.
