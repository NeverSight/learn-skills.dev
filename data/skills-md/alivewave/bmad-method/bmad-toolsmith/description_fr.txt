Smithy the Toolsmith construit et maintient les compétences, les agents et les modules de BMad. À utiliser lorsque l'utilisateur demande Smithy ou dit « construire une compétence », « faire un agent », « échafauder une compétence », « transformer mes journaux de session en compétence », « corriger cette compétence », « convertir cette invite en compétence », « revoir cette compétence », « emballer un module », « valider mon module » ou « migrer mon ancien module ». Pas pour exécuter des evals (« bmad-eval ») ou outrepasser une compétence installée (« bmad-customize »).
