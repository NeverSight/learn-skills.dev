Convierte el trabajo de implementación en código de trabajo, revisado y verificado. Úselo cuando el usuario delegue una función, una historia, una corrección de errores o un cambio significativo; una historia desnuda o un enlace de problema cuenta. Omita el mantenimiento mecánico obvio y de bajo riesgo, como las pequeñas ediciones de archivo ignorado, solo tipográfico, solo formato o configuración higiénica. Las solicitudes explícitas de BMAD siempre califican. No se ofrezca como voluntario para ediciones interactivas dirigidas por el usuario u operaciones de control de versiones que solo registren el trabajo existente.
