Напишите себе краткое описание цели коммуникации и аудитории, чтобы общаться более успешно. Используйте его сразу перед составлением материалов, ориентированных на человека: выводов, объяснений, рекомендаций, запросов решений или текста, предназначенного для публикации или повторного использования. Например, применяйте его перед написанием README для пользователей, сообщений PR в публичных репозиториях, учебных материалов, документации, рекомендаций, сообщений об ошибках, отчётов или текста для сайта. Если коммуникация будет в конце работы, сначала выполните работу, а затем активируйте навык — например, завершите исправление ошибки и затем вызовите comms‑prep, когда собираетесь объяснить пользователю, что вы сделали. Пока разговор и цель остаются теми же, вы можете повторно использовать существующее краткое описание вместо того, чтобы снова вызывать навык для создания нового. Используйте ретроспективно, когда черновик существует без адекватного краткого описания.
