Fügen Sie mit dem Paket hazeglow (WebGL2, keine Abhängigkeiten) animierte, körnige Farbverlaufshintergründe und Mesh-Farbverläufe zu React- und Next.js-Apps hinzu. Verwenden Sie es, wenn ein Hero-Element, ein Abschnitt, eine Karte oder eine Seite einen Farbverlaufshintergrund, einen Mesh-Farbverlauf, einen Stripe-ähnlichen animierten Farbverlauf, einen körnigen, geditherten oder ASCII-Hintergrund oder einen Ersatz für einen linearen CSS-Farbverlauf benötigt, und immer dann, wenn der Benutzer hazeglow erwähnt.
