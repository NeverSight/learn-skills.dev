以 Open Software 的方式开展设计工作。适用于在 OS 仓库（os-june、os-scribe、os-marketing-page、os-platform）中构建、重新设计或打磨任何 UI 界面；当功能在实现前或实现过程中需要视觉设计决策；在审查界面工作以符合内部审美时；或有人要求“启动设计”“为该功能设计”“让它看起来像我们的”“让它感觉更好”或希望运用 Open Software 的设计感性时。安装后可调度专业设计技能（impeccable、emil-design-eng、make-interfaces-feel-better、transitions-dev、mobbin），但即使没有这些也能完全自给自足。它所坚持的核心原则——从仓库已有的 design-system 区块中组合，而不是创造新块；追求安静、低调、优雅，而非喧闹。
