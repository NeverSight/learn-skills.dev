Open Software流で、デザインを前面に出した作業を立ち上げよう。OSリポジトリ（os‑june、os‑scribe、os‑marketing‑page、os‑platform）内の UI 表面を構築・再設計・磨き上げるとき、機能の実装前後に視覚的デザインの判断が必要なとき、インターフェース作業を社内の趣向でレビューするとき、あるいは「デザインを立ち上げて」「この機能をデザインして」「自社らしく感じさせて」「もっと良く感じさせて」などと依頼されたとき、Open Software のデザイン感性を適用したいときに使用する。インストールされている場合は、専門的なデザインスキル（impeccable、emil‑design‑eng、make‑interfaces‑feel‑better、transitions‑dev、mobbin）を連携させるが、これらがなくても完全に自立して機能する。強制するコアコミットメントは、リポジトリの既存デザインシステムブロックから構成し、新たに作り出さないこと、そして騒がしいよりも静かで繊細かつエレガントであること。
