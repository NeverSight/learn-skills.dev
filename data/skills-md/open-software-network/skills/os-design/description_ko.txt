Open Software 방식으로 디자인을 구축합니다. OS 레포(os-june, os-scribe, os-marketing-page, os-platform)에서 UI 표면을 만들거나 재설계하거나 다듬을 때, 기능 구현 전·중에 시각적 디자인 결정을 내려야 할 때, 인터페이스 작업을 하우스 취향에 맞게 검토할 때, 혹은 누군가가 “디자인을 세팅해줘”, “이 기능을 디자인해”, “우리 스타일로 만들어”, “더 좋게 만들어” 라고 요청하거나 Open Software 디자인 감성을 적용하고 싶을 때 사용합니다. 설치 시에는 전문 디자인 스킬(impeccable, emil‑design‑eng, make‑interfaces‑feel‑better, transitions‑dev, mobbin)을 조정하지만, 이들 없이도 완전히 자립적으로 동작합니다. 핵심 약속은 – 새로운 블록을 창조하기보다는 레포의 기존 design‑system 블록을 조합하고, 시끄럽기보다 조용하고 은은하며 우아함을 추구한다는 점입니다.
