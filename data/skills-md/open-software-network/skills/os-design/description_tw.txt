以 Open Software 的方式啟動以設計為核心的工作。適用於在 OS 倉庫（os-june、os-scribe、os-marketing-page、os-platform）中構建、重新設計或打磨任何 UI 介面時，當功能在實作前或實作過程中需要視覺設計決策，當審查介面作品以符合內部品味，或有人要求「啟動設計」──「設計此功能」──「讓它感覺像我們的」──「讓它感覺更好」──或希望套用 Open Software 的設計感性時使用。安裝後能協調專業設計技能（impeccable、emil-design-eng、make-interfaces-feel-better、transitions-dev、mobbin），但即使未安裝亦能完全自行運作。它所堅持的核心原則──從倉庫現有的 design‑system 模塊組合，而非自行創建新模塊；以及以寧靜、細緻、優雅取代吵雜。
