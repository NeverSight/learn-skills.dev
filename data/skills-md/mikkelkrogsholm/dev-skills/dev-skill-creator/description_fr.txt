Créez une nouvelle compétence de documentation technologique pour la bibliothèque dev‑skills. Utilisez‑la lors de l’ajout d’une compétence pour une technologie spécifique (par ex. : bun, hono, react, prisma, stripe, rustfs) qui renvoie à la documentation officielle et inclut des bonnes pratiques sélectionnées. Gère trois types de sources de documentation : URL llms.txt, dépôt GitHub ou site Web de documentation. Chaque compétence est légère et indépendante de l’agent : une description déclencheuse + un pointeur vers la documentation en direct + une petite couche curatée de pièges intemporels.
