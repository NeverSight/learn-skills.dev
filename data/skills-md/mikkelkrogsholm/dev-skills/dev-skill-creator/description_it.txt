Crea una nuova skill di documentazione tecnologica per la libreria dev-skills. Usala quando aggiungi una skill per una tecnologia specifica (ad esempio, bun, hono, react, prisma, stripe, rustfs) che collega alla documentazione ufficiale e include le best practice curate. Gestisce tre tipi di sorgenti di documentazione: URL llms.txt, repository GitHub o sito web della documentazione. Ogni skill è leggera e indipendente dall'agente: una descrizione di attivazione + un puntatore ai documenti live + un piccolo strato curato di problematiche evergreen.
