Monaco Editor — l’éditeur de code qui alimente VS Code, pour le navigateur. Utilisez‑le lors de l’intégration de Monaco Editor dans React, de la configuration d’instances d’éditeur, de l’ajout de langages / thèmes personnalisés, de la gestion des événements de l’éditeur ou du dépannage de Monaco dans les configurations Vite / bundlers. Récupérez la documentation en direct pour des informations à jour.
