OpenObserve (O2) — plataforma de observabilidad de código abierto para logs, métricas, trazas, dashboards, alertas y monitoreo de usuarios reales. Úsela al configurar OpenObserve (Docker, binario, Kubernetes), al ingerir logs/métricas/trazas mediante la API HTTP, OpenTelemetry, Fluent Bit, Vector o Prometheus remote_write, al configurar streams y organizaciones, al crear dashboards, al establecer alertas, al integrar con el OTEL Collector o al migrar desde Elasticsearch, Datadog o el stack Grafana/Loki/Prometheus. Obtenga la documentación en vivo para detalles actualizados.
