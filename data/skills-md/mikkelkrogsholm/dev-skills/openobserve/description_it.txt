OpenObserve (O2) — piattaforma di osservabilità open-source per log, metriche, tracce, dashboard, avvisi e Real User Monitoring. Usala quando configuri OpenObserve (Docker, binario, Kubernetes), ingestendo log/metriche/tracce tramite API HTTP, OpenTelemetry, Fluent Bit, Vector o Prometheus remote_write, configurando stream e organizzazioni, creando dashboard, impostando avvisi, integrandola con OTEL Collector o migrando da Elasticsearch, Datadog o dallo stack Grafana/Loki/Prometheus. Recupera la documentazione live per dettagli aggiornati.
