إنشاء اتفاقية معالجة بيانات (DPA) متوافقة مع نظام GDPR لمشروع. استخدمها عندما يُطلب إنشاء أو توليد أو كتابة اتفاقية معالجة بيانات أو DPA. تقوم بمسح المشروع تلقائيًا لتحديد جميع المعالجات الفرعية (الخدمات الطرفية التي تتعامل مع البيانات الشخصية)، ثم تُولّد اتفاقية DPA بسيطة تتوافق مع المادة 28 وتغطي تدفقات البيانات الفعلية — دون مبالغات في الالتزام ولا نصوص غير ضرورية. تعمل مع أي لغة أو إطار عمل.
