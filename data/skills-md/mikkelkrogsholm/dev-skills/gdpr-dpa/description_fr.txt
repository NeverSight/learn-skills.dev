Générez un contrat de traitement des données (DPA) conforme au RGPD pour un projet. Utilisez-le lorsqu’on vous demande de créer, générer ou rédiger un DPA ou un accord de traitement des données. Analysez de façon autonome le projet afin d’identifier tous les sous‑traitants (services tiers qui traitent des données personnelles), puis générez un DPA minimal conforme à l’article 28 couvrant les flux de données réels — pas de théâtre de conformité, pas de texte superflu inutile. Fonctionne avec n’importe quel langage ou cadre.
