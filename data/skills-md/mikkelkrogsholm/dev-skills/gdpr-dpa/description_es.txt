Genera un Acuerdo de Tratamiento de Datos (DPA) compatible con el RGPD para un proyecto. Utilízalo cuando se solicite crear, generar o redactar un DPA o acuerdo de tratamiento de datos. Escanea de forma autónoma el proyecto para identificar todos los subencargados (servicios externos que manejan datos personales) y, a continuación, genera un DPA mínimo que cumpla con el artículo 28, cubriendo los flujos de datos reales — sin teatro de cumplimiento, sin documentación innecesaria. Funciona con cualquier lenguaje o framework.

Por favor, responde siempre en el idioma del usuario.
