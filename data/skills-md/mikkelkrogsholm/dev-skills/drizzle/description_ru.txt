Drizzle ORM — лёгкий, ориентированный на TypeScript SQL ORM с определением схемы в коде и построителем запросов без внешних зависимостей. Используйте его при работе с Drizzle ORM или при вопросах о её определении схемы, миграциях, построителе запросов, связях и интеграции с базами данных, такими как PostgreSQL, MySQL или SQLite. Получайте актуальную живую документацию для самых свежих сведений.
