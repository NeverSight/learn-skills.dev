Drizzle ORM — ORM SQL خفيف الوزن يركز على TypeScript مع المخطط ككود ومُنشئ استعلامات بدون أي تبعيات. استخدمه عند العمل بـ Drizzle ORM أو عند الاستفسار عن تعريف المخطط، والهجرات، ومُنشئ الاستعلامات، والعلاقات، أو التكامل مع قواعد البيانات مثل PostgreSQL، MySQL، أو SQLite. احصل على الوثائق الحية للحصول على أحدث التفاصيل.
