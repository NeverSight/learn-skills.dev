قم بتحسين تقطيع JavaScript للإنتاج، وتحميل المسار الأولي، والتنقل المتكرر للعميل في Next.js 16.3.0 أو الأحدث في مستودعات App Router التي تم إنشاؤها باستخدام Turbopack. يُستخدم عندما يُطلب منك ضبط تقطيع Turbopack التجريبي، أو تقليل JavaScript المهم، أو مقارنة سلوك التقطيع. تقديم المتغيرات المقاسة للموافقة عليها قبل الاحتفاظ بالتغيير.
