Когда пользователь хочет планировать или оптимизировать платные кампании по привлечению пользователей. Также используйте, когда пользователь упоминает «Apple Search Ads», «привлечение пользователей», «платные рекламные объявления», «UA», «рекламная кампания», «кампания по установке», «реклама в Facebook для приложений», «реклама в TikTok» или «стоимость за установку». Для органического роста см. aso-audit. Для UA, специфичного для запуска, см. app-launch.
