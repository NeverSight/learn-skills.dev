Lorsque l'utilisateur souhaite analyser les données réelles de performance de son application provenant d'App Store Connect — téléchargements réels, revenus, achats intégrés, abonnements, essais ou découpages par pays synchronisés via Appeeky Connect. Utilisez cela lorsque l'utilisateur demande « mes téléchargements », « mes revenus », « comment mon application se comporte », « données ASC », « ventes et tendances », « mes chiffres d'abonnement », « métriques App Store Connect », ou veut comparer des périodes ou les principaux marchés. Pour les estimations d’applications tierces, voir app-analytics. Pour une analyse approfondie des abonnements, voir monetization-strategy.

Veuillez toujours répondre dans la langue de l'utilisateur.
