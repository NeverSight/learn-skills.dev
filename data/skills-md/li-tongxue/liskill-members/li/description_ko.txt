리의 숏비디오 방법 메인 엔트리: 11단계 “한 단계, 한 스킬” 숏비디오 워크플로우를 따라, 먼저 사용자에게 현재 어느 단계에 있는지 묻습니다(자료 없음 / 자료 있음 / 주제 있음 / 스크립트 있음). 그 다음 해당 스킬로 진행하고, 콘텐츠 카드를 사용해 각 단계의 결과를 완전한 하나의 작품으로 연결합니다. 사용자가 “리의 스킬”, “리 호출”, 혹은 “리의 방법 사용”이라고 말하거나, 명시적으로 리를 부르고, 어떤 스킬을 사용해야 할지 모를 때, 처음부터 끝까지 작품을 만들도록 안내받고 싶을 때, 또는 작업에 여러 능력이 함께 필요할 때는 이 접근 방식을 사용합니다; 단일 비즈니스 스킬이 명확히 식별된 경우에는 해당 스킬을 직접 사용합니다.

항상 사용자의 언어로 응답하세요.
