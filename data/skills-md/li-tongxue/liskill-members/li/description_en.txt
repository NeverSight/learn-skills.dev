Lee's short‑video method main entry: follow the 11‑step “one step, one skill” short‑video workflow, first ask the user which step they’re at (no material / have material / have a topic / have a script), then proceed to the corresponding skill, and use a content card to link the results of each step into a complete piece. When the user says “Lee’s skill,” “invoke Lee,” or “use Lee’s method,” explicitly calls on Lee, doesn’t know which skill to use, wants to be guided from start to finish to create a piece, or a task requires multiple abilities working together, use this approach; if a single business skill is clearly identified, use that skill directly.
