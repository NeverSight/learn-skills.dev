Trova articoli accademici da un massimo di 8 fonti (OpenAlex / Semantic Scholar / CrossRef / PubMed / arXiv per l'inglese, OpenReview per i venue di IA, più recupero nativo cinese tramite NSSD 国家哲社文献中心 + yiigle 中华医学期刊) con profondità regolabile — Scansione rapida (5 min) o preparazione audit (3 h). Usa quando l'utente desidera trovare articoli, eseguire una ricerca bibliografica, raccogliere riferimenti, delimitare un argomento di ricerca, cercare letteratura in lingua cinese / 中文原生文献 (中文文献/中文核心/CSSCI/C刊/国内研究/国内文献/中华××期刊/心理学报/经济研究), oppure filtrare i risultati per livello di rivista (中科院分区/一区/几区, Q1, quartile JCR/SJR, 影响因子/impact factor, 期刊分区, 顶刊/top journal, “按分区筛”), oppure esportare strategie di ricerca pronte per incollare / 检索式 per database esterni (PubMed / WOS / Scopus / Embase / 知网 CNKI / 万方 / SinoMed — “写检索式”, “导出检索式”, “WOS 检索式”, “知网专业检索”, “search strategy”, “boolean search strategy”). Si attiva sui verbi di ricerca (“find papers”, “literature search”, “papers about X”), sui tipi di revisione (“scoping review”, “systematic review”, “SR prep”, “literature review”, “lit review”, “help me write a lit review”), o sui termini cinesi (“找文献”, “找论文”, “论文搜索”, “学术检索”, “文献检索”, “文献综述”, “综述前期”, “求文献”, “中文文献”, “中文核心”, “CSSCI”, “C刊”, “国内研究”, “找中文的”). Produce un report Shadcn HTML + BibTeX/RIS/CSV + log PRISMA‑S. NON usare per: spiegazioni concettuali (“what is X” / “X 是什么”, es. “影响因子怎么算”), scrittura (“帮我写” / “help me write a paragraph”), interpretazione di un singolo articolo o download PDF con metadati (usa paper‑downloader‑portable), o quando l'utente possiede già un set di letteratura (usa literature‑set‑review).
