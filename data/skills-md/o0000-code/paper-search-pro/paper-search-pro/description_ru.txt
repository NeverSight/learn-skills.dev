Найдите академические статьи в до 8 источниках (OpenAlex / Semantic Scholar / CrossRef / PubMed / arXiv — для английского; OpenReview — для AI‑конференций; плюс нативный поиск китайской литературы через NSSD 国家哲社文献中心 + yiigle 中华医学期刊) с регулируемой глубиной — от быстрого обзора (5 минут) до подготовки аудита (3 часа).  

Используйте, когда пользователь хочет:  

- найти статьи,  
- провести поиск литературы,  
- собрать ссылки,  
- охватить исследовательскую тему,  
- искать материалы на китайском языке / 中文原生 literature (中文文献、中文核心、CSSCI、C刊、国内研究、国内文献、中华××期刊、心理学报、经济研究),  
- отфильтровать результаты по уровню журналов (中科院分区/一区/几区, Q1, квартиль JCR/SJR, 影响因子/impact factor, 期刊分区,顶刊/top journal, “按分区筛”),  
- экспортировать готовые к вставке профессиональные поисковые стратегии / 检索式 для внешних баз (PubMed / WOS / Scopus / Embase / 知网 CNKI / 万方 / SinoMed — «写检索式», «导出检索式», «WOS 检索式», «知网专业检索», «search strategy», «boolean search strategy»).  

Запуск происходит при глаголах поиска («find papers», «literature search», «papers about X»), типах обзоров («scoping review», «systematic review», «SR prep», «literature review», «lit review», «help me write a lit review») и китайских запросах («找文献», «找论文», «论文搜索», «学术检索», «文献检索», «文献综述», «综述前期», «求文献», «中文文献», «中文核心», «CSSCI», «C刊», «国内研究», «找中文的»).  

Выдаёт отчет Shadcn HTML + BibTeX/RIS/CSV + журнал PRISMA‑S.  

Не используйте для: объяснения концепций («what is X» / «X 是什么», напр. «影响因子怎么算»), написания текста («帮我写», «help me write a paragraph»), интерпретации отдельной статьи или скачивания PDF с метаданными (для этого — paper‑downloader‑portable), а также когда у пользователя уже есть набор литературы (используйте literature‑set‑review).  

Пожалуйста, всегда отвечайте на языке пользователя.
