تصحيح نقاط التوقف عن بُعد في Java. يستخدم عميل JDI داخلي (ملف جَرّ مُدمج دون تبعيات، وضع خادم HTTP، بدون اعتماد على tmux/ sleep) للاتصال بمنفذ JDWP الخاص بـ JVM عن بُعد؛ يقوم الذكاء الاصطناعي تلقائيًا بتعيين نقاط التوقف، وجمع مكدسات الاستدعاء والمتغيرات المحلية، وتقييم التعبيرات، والتنقل خطوة بخطوة لتحديد السبب الجذري. مقارنةً بـ jdb: SUSPEND_EVENT_THREAD يجمد الخيط الذي تم ضربة فقط بدلاً من جميع JVM، التفاعل يتم عبر JSON منظم، وضربة نقطة التوقف تُعيد تلقائيًا المكدس + المتغيرات المحلية. استخدمه عندما تكون الكلمات المفتاحية: "java远程debug"، "远程debug"، "远程断点调试"، "断点调试"، "JDI调试"، "jdwp调试"، "attach jvm"، "设断点"، "java remote debug"، "remote debug"، "breakpoint debug"، "remote breakpoint debugging"، "JDI debug"، "jdwp debug"، "set breakpoint".
