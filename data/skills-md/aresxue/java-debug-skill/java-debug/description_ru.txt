Удалённая отладка Java с точками останова. Используется собственный клиент JDI (fat‑jar без зависимостей, режим HTTP‑сервера, без зависимости от tmux/sleep) для подключения к JDWP‑порту удалённой JVM; ИИ самостоятельно ставит точки останова, собирает стеки вызовов и локальные переменные, вычисляет выражения и пошагово исполняет, чтобы найти причину проблемы. По сравнению с jdb: SUSPEND_EVENT_THREAD замораживает только поток, где произошёл перехват, а не всю JVM, взаимодействие происходит в виде структурированного JSON, и при срабатывании точки останова автоматически возвращаются стек и локальные переменные. Применяется, когда: "java远程debug", "远程debug", "远程断点调试", "断点调试", "JDI调试", "jdwp调试", "attach jvm", "设断点", "java remote debug", "remote debug", "breakpoint debug", "remote breakpoint debugging", "JDI debug", "jdwp debug", "set breakpoint".
