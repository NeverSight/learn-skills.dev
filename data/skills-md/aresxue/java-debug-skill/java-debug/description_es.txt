Depuración remota de puntos de interrupción en Java. Utiliza un cliente JDI interno (jar gordo sin dependencias, modo servidor HTTP, sin dependencia de tmux/sleep) para conectarse al puerto JDWP de una JVM remota; la IA establece puntos de interrupción de forma autónoma, recopila pilas de llamadas y variables locales, evalúa expresiones y avanza paso a paso para localizar la causa raíz. En comparación con jdb: SUSPEND_EVENT_THREAD congela solo el hilo que alcanza el punto de interrupción en lugar de toda la JVM, la interacción es JSON estructurado, y al producirse un punto de interrupción se devuelven automáticamente la pila y las variables locales.
