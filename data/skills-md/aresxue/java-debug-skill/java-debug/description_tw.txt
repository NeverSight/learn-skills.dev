Java 遠端斷點除錯。使用自製的 JDI 客戶端（零依賴胖 JAR、HTTP 伺服器模式，無 tmux / sleep 依賴）連接到遠端 JVM 的 JDWP 埠；AI 能自主設定斷點、收集呼叫堆疊與區域變數、評估表達式，並單步執行以找出根本原因。與 jdb 相比：SUSPEND_EVENT_THREAD 只凍結觸發的執行緒而非整個 JVM，互動採用結構化 JSON，斷點命中時會自動回傳堆疊與區域變數。使用時機：\"java遠程debug\"、\"遠程debug\"、\"遠程斷點偵錯\"、\"斷點偵錯\"、\"JDI偵錯\"、\"jdwp偵錯\"、\"attach jvm\"、\"設斷點\"、\"java remote debug\"、\"remote debug\"、\"breakpoint debug\"、\"remote breakpoint debugging\"、\"JDI debug\"、\"jdwp debug\"、\"set breakpoint\"。
