Java remote breakpoint debugging. Uses an in-house JDI Client (zero-dependency fat jar, HTTP server mode, no tmux/sleep dependency) to attach to a remote JVM's JDWP port; the AI autonomously sets breakpoints, collects call stacks and local variables, evaluates expressions, and single-steps to locate the root cause. Compared with jdb: SUSPEND_EVENT_THREAD freezes only the hit thread instead of the whole JVM, interaction is structured JSON, and a breakpoint hit automatically returns stack + locals.
