Débogage à distance avec points d’arrêt Java. Utilise un client JDI interne (jar « fat » sans dépendance, mode serveur HTTP, aucune dépendance tmux/sleep) pour se connecter au port JDWP d’une JVM distante ; l’IA place automatiquement des points d’arrêt, collecte les piles d’appels et les variables locales, évalue les expressions et effectue des pas simples pour localiser la cause profonde. Comparé à jdb : SUSPEND_EVENT_THREAD gèle uniquement le thread concerné au lieu de toute la JVM, l’interaction se fait en JSON structuré, et un point d’arrêt atteint renvoie automatiquement la pile + les locales. À utiliser lorsque : « java远程debug », « 远程debug », « 远程断点调试 », « 断点调试 », « JDI调试 », « jdwp调试 », « attach jvm », « 设断点 », « java remote debug », « remote debug », « breakpoint debug », « remote breakpoint debugging », « JDI debug », « jdwp debug », « set breakpoint ».
