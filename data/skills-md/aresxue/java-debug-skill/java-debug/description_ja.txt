Java リモートブレークポイントデバッグ。社内製の JDI クライアント（依存関係ゼロの fat jar、HTTP サーバーモード、tmux / sleep 依存なし）を使用してリモート JVM の JDWP ポートにアタッチし、AI が自律的にブレークポイントを設定し、コールスタックとローカル変数を収集し、式を評価し、シングルステップで根本原因を特定します。jdb と比較すると、SUSPEND_EVENT_THREAD は JVM 全体ではなくヒットしたスレッドだけを凍結し、やり取りは構造化された JSON で行われ、ブレークポイントがヒットすると自動的にスタックとローカル変数が返されます。使用例: "java远程debug", "远程debug", "远程断点调试", "断点调试", "JDI调试", "jdwp调试", "attach jvm", "设断点", "java remote debug", "remote debug", "breakpoint debug", "remote breakpoint debugging", "JDI debug", "jdwp debug", "set breakpoint".
