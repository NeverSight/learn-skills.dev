Debug remoto di breakpoint Java. Usa un client JDI interno (jar “fat” a zero dipendenze, modalità server HTTP, senza dipendenze tmux/sleep) per collegarsi alla porta JDWP di una JVM remota; l'IA imposta autonomamente i breakpoint, raccoglie stack di chiamata e variabili locali, valuta espressioni e avanza passo passo per individuare la causa radice. Confrontato con jdb: SUSPEND_EVENT_THREAD congela solo il thread interessato invece dell'intera JVM, l'interazione è JSON strutturato, e un breakpoint colpito restituisce automaticamente stack + locali.
