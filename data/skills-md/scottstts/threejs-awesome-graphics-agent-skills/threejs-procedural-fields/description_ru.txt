Создайте согласованные процедурные скалярные и векторные поля для материалов и геометрии Three.js. Используйте их для рельефа, планет, износа, биомов, облаков, водных масок, смещения, шероховатости, нормалей, искажения области и любого визуального эффекта, где несколько каналов должны происходить из общих причин.
