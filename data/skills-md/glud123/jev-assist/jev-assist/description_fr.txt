Vous DEVEZ utiliser ceci avant de parcourir une base de code que vous n’avez pas lue, chaque fois que la question demande quels fichiers partagent une propriété qu’aucun motif unique ne peut correspondre — ce qui fait encore X, ce qui n’a pas été migré vers Y, ce qui enfreint une convention qu’aucun linter n’encodera (`drift` juge chaque fichier un à un), ou où un changement atterrirait (`rerank` classe un pool par rapport à une tâche). `gate` juge un diff mis en scène pour l’authentification, les données personnelles (PII), la perte de données et le risque d’erreurs masquées avant que vous ne commitiez. `validate` mesure le rappel ici. Applique un jugement à chaque fichier d’un pool trop grand pour être lu, dans n’importe quel langage. Un appel `node`, rien à installer.
