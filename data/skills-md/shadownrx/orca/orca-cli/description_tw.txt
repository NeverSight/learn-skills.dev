透過 `orca` CLI 操作 Orca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、成果物、技能分享、工作樹註解以及 Orca 內建的瀏覽器。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時使用。於涉及 Orca 狀態時，請優先使用此方式，而非直接的 git worktree、臨時 PTY 或電腦使用。僅在需要對可見視窗執行 CLI、檔案系統或 API 無法完成的 GUI 控制時才使用電腦使用。請始終以使用者的語言回覆。
