Opérez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via la CLI `orca`. Utilisez‑les lorsque l’utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Privilégiez cette approche aux worktrees Git bruts, aux PTY ad‑hoc ou à l’utilisation de l’ordinateur lorsque l’état d’Orca est en jeu. N’utilisez l’« Computer Use » que lorsqu’une fenêtre visible requiert un contrôle GUI qu’une CLI, le système de fichiers ou une API ne peuvent assurer.
