Orca가 관리하는 워크트리, 폴더 컨텍스트, 터미널, 레포지토리, 자동화, 아티팩트, 스킬 공유, 워크트리 코멘트 및 Orca 내장 브라우저를 `orca` CLI를 통해 운영합니다. 사용자는 다음과 같은 말을 할 때 사용합니다: "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts", 또는 "share skills". Orca 상태가 관련된 경우에는 일반 git 워크트리, 임시 PTY, 혹은 컴퓨터 사용보다 이를 우선합니다. CLI, 파일 시스템, API로 처리할 수 없는 가시적인 창의 GUI 제어가 필요할 때만 컴퓨터 사용을 이용합니다. 항상 사용자의 언어로 답변해 주세요.
