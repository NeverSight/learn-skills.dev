Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Usalo quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferiscilo rispetto al puro git worktree, PTY ad hoc o all’uso del computer quando è coinvolto lo stato di Orca. Utilizza Computer Use solo quando è necessaria l’interazione con una finestra visibile che richiede il controllo GUI, impossibile da gestire con CLI, filesystem o API. Per favore rispondi sempre nella lingua dell'utente.
