Questa competenza dovrebbe essere utilizzata quando l'utente chiede “where should I put this”, “can X import from Y”, “Angular folder structure”, menziona l'isolamento delle funzionalità, il posizionamento del lazy loading, violazioni di dipendenza, audit dell'architettura, dipendenza circolare, ciclo di import, file barrel, dimensione del bundle, prestazioni del caricamento iniziale, posizionamento del signal store, gestione dello stato, o quando si creano/spostano componenti Angular, servizi o moduli tra cartelle. Da usare anche durante la revisione di PR per la conformità architetturale, lo scaffolding di nuove funzionalità o la configurazione di eslint‑boundaries. Consulente di architettura enterprise Angular per decisioni di posizionamento, regole di dipendenza, pattern di isolamento e verifica architetturale.

Rispondi sempre nella lingua dell'utente.
