Diseñe e implemente interfaces frontales profesionales, pulidas y de aspecto oficial utilizando Tailwind CSS último/v4, JavaScript/TypeScript, React/Next.js y prácticas modernas de sistemas de diseño. Utilice esta habilidad cuando el usuario solicite diseño de interfaz de usuario, páginas de destino, paneles, interfaces SaaS, paneles de administración, formularios, tablas, diseños responsivos, interfaz de usuario multilingüe RTL/LTR, interfaces en árabe, pulido visual, rediseños, sistemas de componentes, clases Tailwind, tokens de diseño o mejoras solo en la interfaz. Se centra exclusivamente en la presentación del frontend, la calidad de la experiencia de usuario, la accesibilidad, el comportamiento responsivo, los primeros tokens CSS de Tailwind v4, el estilo visual formal y la composición de componentes listos para producción. No utilice esta habilidad para trabajos de backend, bases de datos, API, DevOps o arquitectura de servidor.
