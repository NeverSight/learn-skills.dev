Progetta e implementa interfacce frontend professionali, raffinate e dall'aspetto ufficiale utilizzando Tailwind CSS latest/v4, JavaScript/TypeScript, React/Next.js e le moderne pratiche del sistema di progettazione. Utilizza questa competenza quando l'utente richiede progettazione dell'interfaccia utente, pagine di destinazione, dashboard, interfacce SaaS, pannelli di amministrazione, moduli, tabelle, layout reattivi, interfaccia utente multilingue RTL/LTR, interfacce arabe, perfezionamento visivo, riprogettazioni, sistemi di componenti, classi Tailwind, token di progettazione o miglioramenti solo frontend. Si concentra esclusivamente sulla presentazione del frontend, sulla qualità UX, sull'accessibilità, sul comportamento reattivo, sui token CSS-first di Tailwind v4, sullo stile visivo formale e sulla composizione dei componenti pronti per la produzione. Non utilizzare questa competenza per lavori di backend, database, API, DevOps o architettura del server.
