قم بتصميم وتنفيذ واجهات أمامية احترافية ومصقولة وذات مظهر رسمي باستخدام Tailwind CSS الأحدث/الإصدار 4 وJavaScript/TypeScript وReact/Next.js وممارسات نظام التصميم الحديثة. استخدم هذه المهارة عندما يطلب المستخدم تصميم واجهة المستخدم، أو الصفحات المقصودة، أو لوحات المعلومات، أو واجهات SaaS، أو لوحات الإدارة، أو النماذج، أو الجداول، أو التخطيطات سريعة الاستجابة، أو واجهة المستخدم متعددة اللغات RTL/LTR، أو الواجهات العربية، أو التحسين المرئي، أو إعادة التصميم، أو أنظمة المكونات، أو فئات Tailwind، أو رموز التصميم، أو تحسينات الواجهة الأمامية فقط. يركز حصريًا على العرض التقديمي للواجهة الأمامية، وجودة تجربة المستخدم، وإمكانية الوصول، والسلوك سريع الاستجابة، ورموز Tailwind v4 CSS الأولى، والأسلوب المرئي الرسمي، وتكوين المكونات الجاهزة للإنتاج. لا تستخدم هذه المهارة في أعمال الواجهة الخلفية أو قاعدة البيانات أو واجهة برمجة التطبيقات (API) أو DevOps أو بنية الخادم.
