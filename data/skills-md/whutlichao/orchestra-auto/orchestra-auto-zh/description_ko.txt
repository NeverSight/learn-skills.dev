Orca를 사용하여 감독된 작업자를 조정하고, 권한이 부여된 개발 또는 계획 작업을 수용 및 자동 병합 단계까지 진행합니다. 사용자가 작업 할당을 요청하거나 여러 작업을 감독하거나 Orca 작업자를 사용할 때 적용됩니다; 조정자는 계획, 커뮤니케이션 및 수용을 담당하고, 작업자는 편집, 제출 및 PR 생성을 담당합니다. 게이트 승인이 이루어진 후, 조정자는 각 항목에 대한 사용자 확인 없이 자동으로 병합합니다. 또한 전체 티켓 맵을 `implement‑spec`에 전달하여 장기 구현에 활용하거나, 통합 PR의 Merge Danger를 사용해 자동 병합과 인간 병합 중 선택하거나, 워크플로 오류 후 레트로가 필요한 시나리오에도 적용됩니다. 사용자가 Orca 오케스트레이션, 작업자 작업 할당, 워크트리 격리, 게이트 수용 또는 PR 자동 병합을 언급하는 경우에도 적용됩니다. 순수한 Q&A와 이 스킬을 읽기, 검토, 수정하는 행위는 오케스트레이션을 트리거하지 않습니다.
