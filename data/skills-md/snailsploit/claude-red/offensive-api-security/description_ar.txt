منهجية شاملة لاختبار أمان واجهات برمجة التطبيقات تغطي أسطح هجوم REST و gRPC و WebSocket. تتناول جميع نقاط OWASP API Security Top 10 لعام 2023 بما في ذلك BOLA/IDOR، كسر المصادقة، الإفراط في كشف البيانات، تجاوز حدود المعدل، BFLA، التعيين الجماعي، SSRF، وسوء تكوين الأمان. تشمل هجمات مخصصة لـ REST مثل التلاعب بأفعال HTTP، تغيير نوع المحتوى، وتلويث المعاملات. تغطي استغلال gRPC عبر اعتراض protobuf، تعداد واجهة الانعكاس، وحقن البيانات الوصفية. تتناول ثغرات WebSocket بما في ذلك تجاوز الأصل، حقن الرسائل، واختطاف WebSocket عبر المواقع. توفر إرشادات حول الأدوات مثل Burp Suite، Postman، grpcurl، websocat، و mitmproxy. كل تقنية تتضمن توقيعات كشف ومؤشرات دفاعية لتفهم ما يتركه اختبارك من بقايا. صممت للاختبارات الاختراقية المصرَّح بها ضد البُنى المعتمدة على واجهات برمجة التطبيقات.
