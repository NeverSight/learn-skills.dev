REST, gRPC 및 WebSocket 공격 표면을 포괄하는 API 보안 테스트 방법론. OWASP API Security Top 10 2023 전체를 다루며 BOLA/IDOR, 인증 취약, 과도한 데이터 노출, 속도 제한 우회, BFLA, 대량 할당, SSRF 및 보안 구성 오류를 포함합니다. HTTP 메서드 변조, 콘텐츠 타입 전환, 파라미터 오염과 같은 REST 전용 공격도 포함합니다. protobuf 가로채기, 리플렉션 API 열거, 메타데이터 주입을 통한 gRPC 악용도 다룹니다. 원본 우회, 메시지 삽입, 교차 사이트 WebSocket 하이재킹 등 WebSocket 취약점도 포괄합니다. Burp Suite, Postman, grpcurl, websocat, mitmproxy에 대한 도구 사용 안내를 제공합니다. 각 기법마다 탐지 시그니처와 방어 지표를 포함해 테스트 시 남는 아티팩트를 이해할 수 있도록 합니다. API 중심 아키텍처에 대한 권한 있는 침투 테스트 수행을 위해 설계되었습니다.
