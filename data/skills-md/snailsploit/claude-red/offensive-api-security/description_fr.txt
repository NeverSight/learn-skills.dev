Méthodologie complète de tests de sécurité des API couvrant les surfaces d'attaque REST, gRPC et WebSocket. Couvre l'intégralité du OWASP API Security Top 10 2023, incluant BOLA/IDOR, authentification brisée, exposition excessive de données, contournement de la limitation de débit, BFLA, attribution massive, SSRF et mauvaise configuration de sécurité. Inclut les attaques spécifiques à REST telles que la falsification de verbes HTTP, le changement de type de contenu et la pollution des paramètres. Couvre l'exploitation de gRPC via l'interception de protobuf, l'énumération de l’API de réflexion et l’injection de métadonnées. Traite les vulnérabilités WebSocket incluant le contournement d'origine, l’injection de messages et le détournement de WebSocket inter‑sites. Fournit des directives d’outils pour Burp Suite, Postman, grpcurl, websocat et mitmproxy. Chaque technique comprend des signatures de détection et des indicateurs défensifs afin que vous compreniez quels artefacts votre test laisse derrière lui. Conçue pour des missions de test d’intrusion autorisées contre des architectures pilotées par API.
