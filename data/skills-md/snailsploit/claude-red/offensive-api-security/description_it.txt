Metodologia completa di testing della sicurezza delle API che copre le superfici di attacco REST, gRPC e WebSocket. Affronta l'intero OWASP API Security Top 10 2023, inclusi BOLA/IDOR, autenticazione compromessa, esposizione eccessiva dei dati, bypass del rate limiting, BFLA, assegnazione di massa, SSRF e configurazione errata della sicurezza. Include attacchi specifici per REST come manipolazione dei verbi HTTP, cambiamento del tipo di contenuto e inquinamento dei parametri. Copre lo sfruttamento di gRPC tramite intercettazione di protobuf, enumerazione delle API di reflection e iniezione di metadata. Affronta le vulnerabilità dei WebSocket, includendo bypass dell'origine, iniezione di messaggi e hijacking cross‑site dei WebSocket. Fornisce indicazioni sugli strumenti per Burp Suite, Postman, grpcurl, websocat e mitmproxy. Ogni tecnica include firme di rilevazione e indicatori difensivi affinché tu comprenda quali artefatti lascia il tuo testing. Progettata per engagement di penetration testing autorizzati su architetture basate su API.
