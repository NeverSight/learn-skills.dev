REST、gRPC、WebSocket の攻撃対象を網羅した包括的な API セキュリティテスト手法。OWASP API Security Top 10 2023 全項目に対応し、BOLA/IDOR、認証破損、過剰データ露出、レートリミット回避、BFLA、マスアサインメント、SSRF、セキュリティ設定ミスを含む。REST 固有の攻撃として HTTP メソッド改ざん、コンテンツタイプ切替、パラメータ汚染を取り上げる。gRPC では protobuf のインターセプト、リフレクション API の列挙、メタデータ注入を通じた悪用をカバー。WebSocket の脆弱性としてオリジン回避、メッセージ注入、クロスサイト WebSocket ハイジャックに対応。Burp Suite、Postman、grpcurl、websocat、mitmproxy のツール活用ガイダンスを提供。各手法には検知シグネチャと防御指標を示し、テストが残すアーティファクトを把握できるようにする。API 主導のアーキテクチャに対する認可されたペネトレーションテストの案件向けに設計。
