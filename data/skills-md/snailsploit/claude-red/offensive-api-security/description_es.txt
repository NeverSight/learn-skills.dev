Metodología integral de pruebas de seguridad de APIs que cubre superficies de ataque REST, gRPC y WebSocket. Aborda el Top 10 de Seguridad de APIs OWASP 2023 completo, incluyendo BOLA/IDOR, autenticación rota, exposición excesiva de datos, evasión de limitación de velocidad, BFLA, asignación masiva, SSRF y configuración de seguridad incorrecta. Incluye ataques específicos de REST como manipulación de verbos HTTP, cambio de content‑type y contaminación de parámetros. Cubre la explotación de gRPC a través de intercepción de protobuf, enumeración de API de reflexión e inyección de metadatos. Trata vulnerabilidades de WebSocket que incluyen eludir el origen, inyección de mensajes y secuestro de WebSocket entre sitios. Proporciona orientación de herramientas para Burp Suite, Postman, grpcurl, websocat y mitmproxy. Cada técnica incluye firmas de detección e indicadores defensivos para que comprendas qué artefactos deja tu prueba. Diseñada para compromisos de pruebas de penetración autorizadas contra arquitecturas impulsadas por APIs.
