Всеобъемлющая методология тестирования безопасности API, охватывающая поверхности атак REST, gRPC и WebSocket. Охватывает весь список OWASP API Security Top 10 2023, включая BOLA/IDOR, уязвимости в аутентификации, избыточную утечку данных, обход ограничения частоты запросов, BFLA, массовое назначение, SSRF и ошибки конфигурации безопасности. Включает специфические атаки на REST, такие как манипуляция HTTP‑методами, переключение типа контента и загрязнение параметров. Охватывает эксплуатацию gRPC через перехват protobuf, перечисление рефлексивного API и внедрение метаданных. Учитывает уязвимости WebSocket, включая обход проверок origin, внедрение сообщений и кражу WebSocket‑соединений между сайтами. Предоставляет рекомендации по использованию инструментов Burp Suite, Postman, grpcurl, websocat и mitmproxy. Каждый прием сопровождается сигнатурами обнаружения и индикаторами защиты, чтобы вы понимали, какие артефакты оставляет ваше тестирование. Разработано для авторизованных заданий поpenetration testing в архитектурах, построенных на API.
