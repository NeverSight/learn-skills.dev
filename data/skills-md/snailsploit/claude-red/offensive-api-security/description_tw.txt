綜合性的 API 安全測試方法，涵蓋 REST、gRPC 與 WebSocket 的攻擊面。針對 OWASP API Security Top 10 2023 全部項目，包括 BOLA/IDOR、驗證失效、過度資料洩漏、速率限制繞過、BFLA、大量指派、SSRF 與安全配置錯誤。包含 REST 專屬攻擊，如 HTTP 動詞篡改、Content‑Type 切換與參數污染。涵蓋透過 protobuf 截取、反射 API 列舉與 metadata 注入的 gRPC 利用。處理 WebSocket 弱點，包括來源繞過、訊息注入與跨站 WebSocket 劫持。提供 Burp Suite、Postman、grpcurl、websocat 與 mitmproxy 等工具的使用指引。每項技術皆附檢測簽名與防禦指標，讓您了解測試會留下何種痕跡。此方法專為授權的 API 為中心之滲透測試任務設計。
