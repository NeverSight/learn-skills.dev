منهجية هجوم أمان السحابة تغطي AWS و Azure و GCP. تشمل جمع الاعتماديات (IMDS، ~/.aws، متغيرات البيئة، أسرار CI المتسربة، أدوار المثيلات)، الاستطلاع باستخدام أدوات مخصصة للسحابة (pacu، ScoutSuite، Prowler، ROADtools، gcp_enum)، مسارات تصعيد الامتيازات (IAM PassRole، سلاسل AssumeRole، تغيير امتيازات Lambda/Functions، Azure Owner-on-self، GCP serviceAccountTokenCreator)، تقنيات الاستمرارية (إنشاء مستخدم/مفتاح IAM، تسجيل تطبيق AAD، إنشاء مفتاح حساب خدمة GCP، باب خلفي في EventBridge/Logic Apps)، استخراج البيانات (S3/Blob/GCS، مشاركة اللقطة، استخراج من RDS/CosmosDB/Cloud SQL)، التحرك الجانبي الأصلي للسحابة (افتراض عبر حسابات متعددة، Azure AD متعدد المستأجرين، هيكلية مشروع GCP)، هجمات بدون خادم (متغيرات بيئة Lambda، اختطاف الطبقة، Step Functions)، Kubernetes على السحابة (مسارات خاصة بـ EKS/AKS/GKE إلى العقد وبيانات AWS التعريفية)، وتجنب أنظمة إدارة وضع السحابة (CSPM) (نقاط عمياء في CloudTrail، كتم GuardDuty، تشكيل قواعد Sentinel). يُستخدم عندما يكون نطاق المهمة حسابات سحابة، أو عندما تكون قد سرقت بيانات الاعتماد السحابية، أو عند تقييم وضع السحابة.
