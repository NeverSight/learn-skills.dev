Методология атак на облачную безопасность, охватывающая AWS, Azure и GCP. Включает сбор учётных данных (IMDS, ~/.aws, переменные окружения, утекшие CI‑секреты, роли инстансов), перечисление с помощью облачных инструментов (pacu, ScoutSuite, Prowler, ROADtools, gcp_enum), пути повышения привилегий (IAM PassRole, цепочки AssumeRole, переключения привилегий Lambda/Functions, Azure Owner‑on‑self, GCP serviceAccountTokenCreator), техники удержания (создание IAM‑пользователя/ключа, регистрация приложений AAD, создание ключей сервисных аккаунтов GCP, бекдоры EventBridge/Logic Apps), эксфильтрацию данных (S3/Blob/GCS, совместное использование снимков, эксфильтрация RDS/CosmosDB/Cloud SQL), нативное боковое перемещение в облаке (assume между аккаунтами, мульти‑тенант Azure AD, иерархия проектов GCP), атаки на serverless (переменные окружения Lambda, перехват слоя, Step Functions), Kubernetes в облаке (специфические пути для EKS/AKS/GKE к узлам и метаданным AWS) и обход CSPM (слепые зоны CloudTrail, отключение GuardDuty, настройка правил Sentinel). Применять, когда область охвата проекта — облачные аккаунты, когда вы получили облачные учётные данные, либо при оценке облачной позиции.
