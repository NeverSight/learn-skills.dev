Description dense couvrant l'usurpation ARP, le poisonnage LLMNR/NBT‑NS/mDNS, le poisonnage DNS, les attaques MITM, le saut de VLAN, les attaques DHCP, le contournement 802.1X/NAC, les attaques IPv6. Outils : Bettercap, Responder, mitm6, Ettercap, Wireshark. MITRE T1557, T1040. À utiliser lors d'évaluations de réseaux internes ou de tests de la surface d'attaque des couches 2/3.
