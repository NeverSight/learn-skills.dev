Java、PHP、.NET、Python、Node.js、Ruby にまたがる安全でないデシリアライズの悪用。ysoserial / phpggc / ysoserial.net を用いたガジェットチェーン構築、ObjectInputStream と BinaryFormatter のシンク特定、pickle の __reduce__ を利用した RCE、phar:// ラッパーの悪用、Jackson のポリモーフィック型付け、Json.NET の TypeNameHandling、ViewState の改ざん、node-serialize の IIFE インジェクション、Ruby の Marshal.load および YAML.load ガジェット、Spring/Hibernate/Laravel/Symfony 向けのフレームワーク固有チェーン、Kubernetes の Admission Webhook やメッセージキューコンシューマーなどの最新攻撃対象、エンコード層や Content-Type 操作による WAF バイパス、serialVersionUID/JMX/RMI ベクトルを網羅。デシリアライズシンクが関与する案件、クッキーやリクエストボディにシリアライズデータが含まれるケース、ガジェットチェーンの開発、マジックメソッドの乱用、ysoserial ペイロード生成、または対象アプリケーションのマッシュアリング／アンマッシュアリングロジックのレビューが必要なときに起動します。
