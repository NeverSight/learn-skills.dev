针对网络服务和移动应用的 TLS/SSL 实现及配置错误进行审计和利用的综合方法论。涵盖协议降级攻击，包括针对 SSLv3 CBC 填充的 POODLE（CVE-2014-3566）、利用 SSLv2 导出密码解密 TLS 会话的跨协议攻击 DROWN（CVE-2016-0800）以及强制 RSA 导出级密钥交换的 FREAK（CVE-2015-0204）。涉及利用 TLS 1.0 中 CBC IV 可预测性的 BEAST（CVE-2011-3389）、针对 TLS 级别和 HTTP 级别压缩的 CRIME（CVE-2012-4929）和 BREACH，以及针对 OpenSSL 的内存泄露漏洞 Heartbleed（CVE-2014-0160）。涵盖针对主机名验证或链验证不当的应用程序的证书验证绕过技术，使用 Frida 和 Objection 对移动应用进行拦截的证书固定绕过，通过 NTP 操作和子域名利用进行 HSTS 绕过，针对非幂等端点的 TLS 1.3 0-RTT 重放攻击，包含客户端证书窃取和中继的双向 TLS（mTLS）身份验证攻击，以及用于侦察的证书透明度日志监控。主要工具包括用于全面 TLS 审计的 testssl.sh、用于 Python 集成扫描的 sslyze、用于快速密码套件枚举的 sslscan，以及用于大规模高速 TLS 探测的 tlsx。对应 CWE-295（证书验证不当）、CWE-319（敏感信息明文传输）和 CWE-757（协商期间选择了不够安全的算法）。
