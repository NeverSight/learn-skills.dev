Методика написания отчётов по тестированию на проникновение и Red Team. Охватывает структуру исполнительного резюме (ориентированный на риск нарратив для нетехнических читателей), формат технической находки (заголовок, степень тяжести, затронутый охват, объяснение, шаги воспроизведения, влияние, рекомендации по исправлению, ссылки), оценку CVSS v3.1 / v4.0 с обоснованием вектора, рейтинг риска OWASP, гигиену доказательств (редактирование учётных данных, хеширование клиентских данных, отметка времени каждого действия), управление скриншотами и артефактами PoC, построение цепочек находок, документирование объёма / ограничений / предположений, доказательства повторного тестирования и отслеживание исправлений, форматы поставляемых материалов (PDF, DOCX, HTML, JSON для интеграции в SIEM), разделение клиентских, заказных и поставляемых документов, а также типичные ошибки в отчётах (избыточная оценка по CVSS, подрыв роли триажера, отсутствие «что из этого следует»). Используется в конце задания при подготовке итогового документа, при переработке черновика для повышения читаемости руководством или при создании переиспользуемого шаблона отчёта для консалтинговой практики.
