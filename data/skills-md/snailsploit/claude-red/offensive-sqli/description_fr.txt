Compétence de test d’injection SQL pour les évaluations de sécurité offensive et la chasse aux bug bounties. Couvre les injections basées sur les erreurs, les injections UNION, les injections aveugles booléennes/temps, hors bande, de seconde ordre, NoSQL, GraphQL, WebSocket et les injections SQL utilisant des opérateurs JSON. Inclut les techniques de contournement de WAF, l’exploitation spécifique aux bases de données (MySQL, MSSQL, PostgreSQL, Oracle), les vecteurs d’attaque cloud‑native, le suivi des CVE ORM et l’automatisation avec SQLmap. À utiliser lors des tests d’injection SQL d’applications web, de l’énumération de bases de données, de l’élévation de privilèges via SQLi, ou de l’évaluation des vecteurs d’injection dans les API et les piles technologiques modernes.
