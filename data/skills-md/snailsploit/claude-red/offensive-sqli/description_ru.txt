Навык тестирования SQL‑инъекций для атакующего аудита безопасности и охоты на баунти. Охватывает error‑based, UNION‑based, boolean/time‑based blind, out‑of‑band, second‑order, NoSQL, GraphQL, WebSocket и JSON‑operator SQLi. Включает техники обхода WAF, эксплуатацию, специфичную для СУБД (MySQL, MSSQL, PostgreSQL, Oracle), облачно‑нативные пути атаки, отслеживание CVE в ORM и автоматизацию с помощью SQLmap. Применяется при проведении тестирования SQL‑инъекций веб‑приложений, перечислении баз данных, повышении привилегий через SQLi или оценке вектор­ов инъекций в API и современных стеках.
