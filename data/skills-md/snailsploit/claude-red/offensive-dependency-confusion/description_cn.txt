针对所有主要包生态系统的依赖混淆和命名空间攻击的深度进攻方法论。涵盖利用公共与私有作用域包之间差距的 npm 作用域混淆，以及 .npmrc 配置错误导致注册表映射未能仅锁定内部作用域的情况。涉及通过 --extra-index-url 解析顺序进行的 PyPI 命名空间攻击、在未提供明确指令的情况下配置多个包源时的 NuGet 源优先级利用、Maven 与 Gradle 仓库顺序导致的构件解析按顺序遍历仓库、通过 GOPROXY 配置错误进行的 Go 模块代理滥用、Ruby gems 命名空间抢注，以及 Docker 镜像标签混淆导致的非限定镜像引用问题。提供完整的概念验证方法，使用安全回调，包括通过 interactsh 或 Burp Collaborator 的 DNS 金丝雀以及不携带破坏性负载的 HTTP 信标。涵盖用于发现内部包名称的侦察技术，如 GitHub 仓库分析、错误信息收集、JavaScript 源映射提取、锁文件解析、包含内部工具的招聘信息以及包清单检查。直接引用并在 Alex Birsan 2021 年奠基性的依赖混淆研究基础上进行扩展。每个生态系统章节均包含特定注册表的利用机制、配置漏洞以及用于报告的防御对策。
