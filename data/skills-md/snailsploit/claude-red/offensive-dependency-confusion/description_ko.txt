의존성 혼란 및 네임스페이스 공격에 대한 모든 주요 패키지 생태계 전반의 심층 공격 방법론. npm 스코프 혼란을 이용하여 공개 스코프와 비공개 스코프 패키지 사이의 격차와 .npmrc 잘못된 구성으로 레지스트리 매핑이 내부 스코프만을 고정하지 못하는 경우를 다룸. PyPI 네임스페이스 공격을 --extra-index-url 해석 순서를 통해, 여러 패키지 소스가 명확한 지시 없이 구성된 경우 NuGet 피드 우선순위 활용, Maven 및 Gradle 저장소 순서에서 아티팩트 해석이 저장소를 순차적으로 탐색하는 방식, GOPROXY 오설정으로 인한 Go 모듈 프록시 남용, Ruby gems 네임스페이스 스쿼팅, 그리고 비자격 이미지 참조가 있는 Docker 이미지 태그 혼란을 포함. 파괴적인 페이로드 없이 DNS 카나리(interactsh 또는 Burp Collaborator 사용)와 HTTP 비콘을 이용한 안전한 콜백을 포함한 완전한 개념 증명 방법론 제공. 내부 패키지 이름을 찾기 위한 정찰 기법으로 GitHub 저장소 분석, 오류 메시지 수집, JavaScript 소스맵 추출, lock 파일 파싱, 내부 도구를 언급한 채용 공고, 패키지 매니페스트 검사를 다룸. Alex Birsan의 2021년 의존성 혼란 연구를 직접 인용하고 이를 기반으로 확장. 각 생태계 섹션마다 레지스트리별 활용 메커니즘, 구성 취약점, 그리고 대응 보고를 위한 방어 대책을 포함.
