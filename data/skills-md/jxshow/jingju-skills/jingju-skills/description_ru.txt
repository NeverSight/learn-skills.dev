Навыки Jing Ju. Используется для начала с запросов о настройках сюжета и жанре романа, создания полных планов сценариев, настроек персонажей, подсказок для согласованности персонажей, разработки раскадровки, текстовых подсказок для изображений, дополнительных параметров генерации для ComfyUI, подсказок для преобразования изображения в видео и, при желании, окончательной генерации видео с помощью локальных видеомоделей/API. Подходит пользователям, желающим создавать комикс‑драмы, динамические комиксы, драматические постановки с гуманоидной симуляцией, комментарийные драмы, раскадровки коротких AI‑драм, справочные изображения персонажей, подсказки для изображения‑в‑видео или рабочие процессы пакетного производства.
