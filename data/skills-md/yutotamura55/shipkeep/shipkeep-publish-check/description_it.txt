Usalo prima di rendere pubblico un repository Git, o quando esamini un repository già pubblico, per trovare segreti e dati personali in qualsiasi punto della sua cronologia e per verificare i file e le impostazioni necessari alla pubblicazione (licenza, README, SECURITY.md, gestione dei file .env, scansione dei segreti su GitHub, segnalazione delle vulnerabilità, avvisi di Dependabot e permessi dei token di Actions).
