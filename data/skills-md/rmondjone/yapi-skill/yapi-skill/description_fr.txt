Récupérez automatiquement les définitions d’interface depuis la plateforme Yapi et renvoyez le JSON brut au LLM. Lorsque l’utilisateur invoque `yapi-skill`, ou demande les définitions d’interface backend, consulte la documentation Yapi ou interroge les champs d’interface, cette COMPÉTENCE doit être utilisée. Flux de travail : localiser et charger la configuration YAPI depuis le fichier .env → utiliser Bash pour exécuter le script intégré `scripts/yapi_fetch.py` de la COMPÉTENCE afin d’appeler l’API publique de Yapi → formater la sortie JSON brute du script et la renvoyer. Même si l’utilisateur ne dit pas explicitement « use yapi-skill », tant que le but est d’obtenir les définitions d’interface depuis Yapi pour implémenter/déboguer du code, cette COMPÉTENCE doit être utilisée, et la substitution par l’outil yapi-mcp MCP est interdite.

Veuillez toujours répondre dans la langue de l’utilisateur.
