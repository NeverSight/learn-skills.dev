Automatisches Abrufen von API‑Definitionen von der Yapi‑Plattform und Rückgabe des rohen JSON an das LLM. Wenn ein Benutzer `yapi-skill` aufruft, die Backend‑API‑Definition anfordert, die Yapi‑API‑Dokumentation anzeigt oder API‑Felder abfragt, muss dieser SKILL verwendet werden. Ablauf: YAPI‑Konfiguration aus .env finden und laden → das integrierte `scripts/yapi_fetch.py` im SKILL über Bash ausführen, um Yapis offene API aufzurufen → die rohe JSON‑Ausgabe des Skripts von Yapi formatieren und zurückgeben. Auch wenn der Benutzer nicht ausdrücklich „use yapi-skill“ sagt, muss dieser SKILL eingesetzt werden, sobald das Ziel darin besteht, API‑Definitionen von Yapi zum Implementieren/Debuggen von Code zu erhalten; die Verwendung des yapi-mcp MCP‑Tools als Ersatz ist untersagt.

Bitte immer in der Sprache des Benutzers antworten.
