Автоматически получать определения интерфейсов с платформы Yapi и возвращать сырой JSON в LLM. Когда пользователь вызывает `yapi-skill`, запрашивает определения бэкенд‑интерфейсов, просматривает документацию API Yapi или запрашивает поля интерфейса, этот СКИЛЛ должен использоваться. Рабочий процесс: найти и загрузить конфигурацию YAPI из файла .env → выполнить встроенный в СКИЛЛ скрипт `scripts/yapi_fetch.py` через Bash для вызова публичного API Yapi → обработать вывод скрипта (сырой JSON Yapi) и вернуть его. Даже если пользователь явно не говорит «использовать yapi‑skill», при условии, что цель — получить определения интерфейсов из Yapi для реализации/отладки кода, этот СКИЛЛ обязателен, а инструмент yapi‑mcp MCP запрещён в качестве замены.

Пожалуйста, всегда отвечайте на языке пользователя.
