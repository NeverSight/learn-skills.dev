Recupera automaticamente le definizioni API dalla piattaforma Yapi e restituisce il JSON grezzo al LLM. Quando l'utente invoca `yapi-skill`, richiede definizioni API backend, visualizza la documentazione API di Yapi o interroga i campi API, questa SKILL deve essere utilizzata. Flusso di lavoro: individua e carica la configurazione YAPI da .env → esegui lo script integrato `scripts/yapi_fetch.py` della SKILL via Bash per chiamare l'API pubblica di Yapi → organizza l'output JSON grezzo dello script e restituiscilo. Anche se l'utente non dice esplicitamente “usa yapi-skill”, finché l'obiettivo è ottenere le definizioni API da Yapi per implementare o fare debug del codice, questa SKILL deve essere usata, e lo strumento yapi-mcp MCP è proibito come sostituto.

Rispondi sempre nella lingua dell'utente.
