جلب تعريفات واجهة برمجة التطبيقات تلقائيًا من منصة Yapi وإرجاع JSON الخام إلى نموذج اللغة الكبيرة (LLM). عندما يستدعي المستخدم `yapi-skill`، أو يطلب تعريف واجهة برمجة التطبيقات الخلفية، أو يطلع على وثائق Yapi API، أو يستعلم عن حقول API، يجب استخدام هذه المهارة. سير العمل: تحديد موقع ملف إعدادات YAPI وتحميله من .env → تنفيذ السكربت المدمج `scripts/yapi_fetch.py` باستخدام Bash لاستدعاء واجهة برمجة التطبيقات المفتوحة لـ Yapi → تنظيم مخرجات JSON الخام من Yapi وإرجاعها. حتى إذا لم يذكر المستخدم صراحةً "استخدم yapi-skill"، طالما أن الهدف هو الحصول على تعريفات API من Yapi لتنفيذ أو تصحيح الكود، يجب استخدام هذه المهارة، ويُمنع استخدام أداة yapi-mcp MCP كبديل. يرجى دائمًا الرد بلغة المستخدم.
