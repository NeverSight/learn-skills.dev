Recupera automáticamente las definiciones de API desde la plataforma Yapi y devuelve el JSON sin procesar al LLM. Cuando un usuario invoque `yapi-skill`, o solicite obtener definiciones de API del backend, ver la documentación de la API de Yapi, o consultar campos de la API, esta HABILIDAD debe ser utilizada. Flujo de trabajo: localizar y cargar la configuración de YAPI desde .env → ejecutar el `scripts/yapi_fetch.py` incorporado de la HABILIDAD usando Bash para llamar a la API abierta de Yapi → organizar la salida JSON sin procesar del script y devolverla. Incluso si el usuario no dice explícitamente “usar yapi-skill”, siempre que el objetivo sea recuperar definiciones de API de Yapi para implementar o depurar código, esta HABILIDAD debe ser usada, y la herramienta yapi-mcp MCP está prohibida como sustituto.

Por favor, responda siempre en el idioma del usuario.
