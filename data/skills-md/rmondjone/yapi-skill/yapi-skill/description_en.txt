Automatically fetch API definitions from the Yapi platform and return the raw JSON to the LLM. When a user invokes `yapi-skill`, or requests to obtain backend API definitions, view Yapi API documentation, or query API fields, this SKILL must be used. Workflow: locate and load the YAPI configuration from .env → execute the SKILL’s built‑in `scripts/yapi_fetch.py` using Bash to call Yapi’s open API → organize the raw JSON output from the script and return it. Even if the user does not explicitly say “use yapi-skill”, as long as the goal is to retrieve API definitions from Yapi to implement or debug code, this SKILL must be used, and the yapi-mcp MCP tool is prohibited as a substitute.
