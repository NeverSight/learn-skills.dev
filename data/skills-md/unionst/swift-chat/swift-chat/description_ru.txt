Добавьте в iOS‑приложение чат‑экран, точно повторяющий iMessage, с помощью Swift Chat — бесплатного пакета SwiftUI от Union St. Используйте, когда пользователь запрашивает чат‑интерфейс, экран сообщений, вид разговора, поток AI‑ассистента, пузырьки в стиле iMessage, индикаторы набора, подтверждения прочтения или панель ввода чата в SwiftUI. Описывается установка, API Chat и Message, каждый модификатор, вложения, стиль ассистента для AI‑потоков и наиболее частые ошибки агентов.
