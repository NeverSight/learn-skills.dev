Revisa un problema de GitHub de la misma manera que/code-review revisa un PR. Obtiene el problema con la CLI de gh, compara el informe con la base de código actual, busca duplicados y correcciones anteriores, califica la integridad, asigna gravedad y escribe un informe de clasificación más un borrador de respuesta. La publicación de comentarios o etiquetas es solo opcional. Úselo cuando el usuario solicite verificar, clasificar, validar o revisar un problema de GitHub.
