Examinez un problème GitHub de la même manière /code-review examine une RP. Récupère le problème avec l'interface de ligne de commande gh, vérifie le rapport par rapport à la base de code actuelle, recherche les doublons et les corrections antérieures, note l'exhaustivité, attribue la gravité et rédige un rapport de triage ainsi qu'une ébauche de réponse. La publication de commentaires ou d'étiquettes est facultative uniquement. À utiliser lorsque l'utilisateur demande de vérifier, trier, valider ou examiner un problème GitHub.
