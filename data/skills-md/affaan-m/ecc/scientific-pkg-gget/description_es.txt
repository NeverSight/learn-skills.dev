gget flujo de trabajo de CLI y Python para consultas rápidas de bases de datos genómicas, búsqueda de secuencias, búsquedas de estilo Blast, comprobaciones de enriquecimiento y registros de evidencia bioinformática reproducibles. Se utiliza cuando una tarea necesita una búsqueda bioinformática rápida en bases de datos de referencia genómica con el paquete gget CLI o Python.
