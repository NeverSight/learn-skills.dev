قم بتحسين معدل نجاح التخزين المؤقت لمطالبات LLM لتقليل تكاليف الـ API وتحسين زمن الاستجابة. يحلل بنية المطالبة، يحدد المحتوى القابل للتخزين المؤقت مقابل غير القابل، ويوصي بإعادة الهيكلة لتعظيم إعادة استخدام التخزين المؤقت. يتم التفعيل عندما: يذكر المستخدم “prompt cache”، “cache hit rate”، “reduce LLM cost”، “optimize token usage”، “cheaper LLM calls”، أو يسأل عن استراتيجيات التخزين المؤقت للمطالبات لـ OpenAI/Anthropic/مزودين آخرين. لا يتم التفعيل عندما: يرغب المستخدم فقط في تحسين جودة مطالبة واحدة (استخدم prompt-optimizer بدلاً من ذلك)، أو يسأل عن بنية تخزين مؤقت عامة.
