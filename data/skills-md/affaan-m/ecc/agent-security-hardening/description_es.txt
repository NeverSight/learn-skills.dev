Guía de fortalecimiento de la seguridad para marcos de agentes de IA que procesan contenido no confiable, invocan herramientas, escriben archivos de espacio de trabajo, administran identificadores de tiempo de ejecución o manejan credenciales. Utilícelo al crear o revisar el tiempo de ejecución de un agente, un trabajador autónomo, una puerta de enlace de herramientas, un servicio de memoria o una implementación de agente multiusuario. No lo utilice para seguridad general de aplicaciones web o pruebas ofensivas.
