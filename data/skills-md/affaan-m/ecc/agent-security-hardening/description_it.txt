Linee guida per l’indurimento della sicurezza dei framework di agenti IA che elaborano contenuti non attendibili, invocano strumenti, scrivono file nello spazio di lavoro, gestiscono identificatori di runtime o maneggiano credenziali. Da utilizzare nella costruzione o revisione di un runtime agente, worker autonomo, gateway di strumenti, servizio di memoria o distribuzione di agenti multi‑tenant. Non utilizzare per la sicurezza generale delle applicazioni web o per test offensivi.
