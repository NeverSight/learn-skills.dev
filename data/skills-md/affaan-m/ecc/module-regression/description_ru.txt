Управляйте кросс‑модульной регрессией в больших репозиториях с помощью реестра REGRESSION.md, который фиксирует downstream‑потребителей каждого модуля и команду приёма исполняемого файла. После изменения запустите изменённый модуль и все затронутые downstream‑команды, используя наблюдаемые коды возврата в качестве доказательства регрессии согласно политике доставки проекта. Применяется для модульной регрессии, реестров регрессии, аудитов воздействия, проверки downstream и изменений, при которых модификация A может сломать B.
