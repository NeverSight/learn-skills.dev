Installieren und betreiben Sie Everything Claude Code (ECC) auf dem DeepSeek-Kabelbaum (DSH): native Skill-Roots (~/.dsh/skills, .agents/skills), die @ deepseek-ai/dsh-hooks-claude-code-Brücke für Befehlshooks, Bare-Insert-Patch-Montage, Generatornutzung, Event-Support-Limits und Update-Workflow. Verwenden Sie diese Option, wenn Sie ECC auf dem DeepSeek-Kabelbaum einrichten, ECC-Hooks in ein DSH-Profil verdrahten oder debuggen, warum ECC-Fähigkeiten oder -Hooks in einer DSH-Sitzung nicht angezeigt werden.
