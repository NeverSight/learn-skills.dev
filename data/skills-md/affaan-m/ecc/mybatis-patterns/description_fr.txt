Modèles MyBatis et MyBatis-Spring pour la conception du mappeur, le XML et le SQL d'annotation, le mappage des résultats, la sécurité SQL dynamique, les transactions, le traitement par lots, la pagination et les performances de requête. À utiliser lors de la création ou de la révision du code de persistance Java avec des applications héritées basées sur MyBatis, Spring Boot, MyBatis-Spring ou MyBatis.
