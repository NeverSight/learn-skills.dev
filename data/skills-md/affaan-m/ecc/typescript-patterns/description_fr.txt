Modèles TypeScript pour un code strict, sécurisé et maintenable dans les applications TypeScript et JavaScript modernes. Couvre la configuration stricte du compilateur, la conception de type, le rétrécissement, les unions discriminées, les génériques, la gestion des asynchrones et des erreurs, les limites des modules, l'hygiène des dépendances et les tests au niveau du type. À utiliser lors de l'écriture ou de la révision de code TypeScript ou JavaScript.
