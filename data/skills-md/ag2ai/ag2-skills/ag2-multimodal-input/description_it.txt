Usalo quando l'utente vuole che l'agente elabori input non testuali — descrivere una foto, trascrivere l'audio, riassumere un PDF, analizzare un video. Copre la matrice di supporto per provider, i quattro modi per fornire dati (URL / percorso / byte / file_id), YouTube specifico di Gemini + risoluzione media + clipping, dettaglio immagine di OpenAI, cache dei prompt di Anthropic sugli allegati, e `FilesAPI` per il ciclo di vita del caricamento.
