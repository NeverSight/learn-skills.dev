Отправляйте изображения, аудио, видео или документы в `Agent` AG2 вместе с текстом. Передавайте `ImageInput`, `AudioInput`, `VideoInput` или `DocumentInput` в качестве позиционных аргументов в `agent.ask(...)`. Используйте, когда пользователь хочет, чтобы агент обработал ввод, отличный от текста — описал фото, расшифровал аудио, сделал резюме PDF, проанализировал видео. Охватывает матрицу поддержки провайдеров, четыре способа получения данных (URL / путь / байты / file_id), специфичные для Gemini функции YouTube + разрешение медиа + обрезка, детализацию изображений OpenAI, кэширование подсказок Anthropic для вложений и `FilesAPI` для жизненного цикла загрузки.

Пожалуйста, всегда отвечайте на языке пользователя.
