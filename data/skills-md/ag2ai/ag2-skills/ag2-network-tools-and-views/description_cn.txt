塑造 AG2 网络代理的感知范围以及其 LLM 可以执行的操作。涵盖通过 `NetworkPlugin` 自动注入的五个面向 LLM 的工具（`delegate`、`peers`、`channels`、`tasks`、`context`）以及适配器拥有的 `say`；通过 `agent_client.on_envelope(callback)` 替换默认处理器（网关、无头工作者）；`ViewPolicy` 协议及内置的 `FullTranscript`、`WindowedSummary(recent_n=N)`、`NamedWindowedSummary(recent_n=N)` 视图，并介绍如何编写自定义视图；通过技能 markdown 进行对等发现（`skill_md=`、`parse_skill_frontmatter`、`hub.set_skill`）；`Envelope` 传输格式及 `EV_*` 事件分类（`EV_TEXT`、`EV_PACKET`、`EV_CHANNEL_*`、`EV_EXPECTATION_VIOLATED`、`EV_TASK_CANCEL_REQUEST`、`EV_TASK_CANCELLED`）、`audience` 与 `visible_to` 语义、`Priority`、`causation_id`，以及如何使用 `agent_client.send_envelope(...)` 发送带自定义事件类型的原始 Envelope。适用于用户想要自定义 LLM 的网络表面、编写自定义 Envelope 处理器、构建网关/无头工作者或实现对等发现的场景。
