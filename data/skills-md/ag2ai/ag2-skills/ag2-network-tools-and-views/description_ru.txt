Формируйте, что воспринимает сетевой агент AG2 и какие действия может выполнять его LLM. Охватывает пять автоматически внедрённых инструментов, ориентированных на LLM, поставляемых через `NetworkPlugin` (`delegate`, `peers`, `channels`, `tasks`, `context`) и инструмент `say`, принадлежащий адаптеру; замену обработчика по умолчанию на `agent_client.on_envelope(callback)` (шлюзы, безголовые рабочие процессы); протокол `ViewPolicy` с встроенными представлениями `FullTranscript`, `WindowedSummary(recent_n=N)` и `NamedWindowedSummary(recent_n=N)` а также инструкциями по созданию собственного представления; обнаружение пиров через markdown навыков (`skill_md=`, `parse_skill_frontmatter`, `hub.set_skill`); формат сообщения `Envelope` с таксономией событий `EV_*` (`EV_TEXT`, `EV_PACKET`, `EV_CHANNEL_*`, `EV_EXPECTATION_VIOLATED`, `EV_TASK_CANCEL_REQUEST`, `EV_TASK_CANCELLED`), семантикой `audience` и `visible_to`, параметрами `Priority`, `causation_id` и способом отправки сырых конвертов с пользовательскими типами событий через `agent_client.send_envelope(...)`. Используйте, когда пользователь хочет настроить сетевой интерфейс LLM, написать собственный обработчик конвертов, построить шлюз/безголовый воркер или настроить обнаружение пиров.
