形塑 AG2 網路代理感知的內容以及其 LLM 可執行的操作。涵蓋透過 `NetworkPlugin` 自動注入的五個面向 LLM 的工具（`delegate`、`peers`、`channels`、`tasks`、`context`），以及由 adapter 擁有的 `say`；將預設處理程式替換為 `agent_client.on_envelope(callback)`（用於 gateway、無頭工作者）；`ViewPolicy` 協定，內建 `FullTranscript`、`WindowedSummary(recent_n=N)`、`NamedWindowedSummary(recent_n=N)` 檢視，以及如何撰寫自訂檢視；透過技能 Markdown 進行 peer 發現（`skill_md=`、`parse_skill_frontmatter`、`hub.set_skill`）；`Envelope` 傳輸格式，包含 `EV_*` 事件分類（`EV_TEXT`、`EV_PACKET`、`EV_CHANNEL_*`、`EV_EXPECTATION_VIOLATED`、`EV_TASK_CANCEL_REQUEST`、`EV_TASK_CANCELLED`）、`audience` 與 `visible_to` 語意、`Priority`、`causation_id`，以及如何使用 `agent_client.send_envelope(...)` 以自訂事件類型傳送原始 envelope。適用於使用者想要自訂 LLM 的網路介面、撰寫自訂 envelope 處理程式、構建 gateway／無頭工作者，或連接 peer 發現的情境。
