Créez un canal `workflow` du réseau AG2 — l’adaptateur N‑parties orchestré, piloté par un `TransitionGraph` déclaratif. Utilisez‑le lorsque l'utilisateur a besoin de transferts conditionnels, de pipelines multi‑étapes, d’un routage sensible au contexte, de boucles de rétroaction, ou qu’il migre depuis le modèle classique `GroupChat` + `Agent.handoffs`. Couvre `TransitionGraph` ; les usines `TransitionGraph.sequence(...)` / `.round_robin(...)` ; les cibles intégrées (`AgentTarget`, `RoundRobinTarget`, `StayTarget`, `RevertToInitiatorTarget`, `TerminateTarget`) ; les conditions intégrées (`Always`, `FromSpeaker`, `ToolCalled`, `ContextEquals`) ; le type de retour `Handoff` pour le routage dynamique ; le contexte limité au canal via `set_context` ; `register_target` / `register_condition` pour des sous‑classes personnalisées ; le modèle d’exécution par paquets et l’exigence d’outil idempotent ; huit modèles de cookbook (pipeline, hiérarchique, escalade, boucle de rétroaction, triage, et plus) ; et la migration côte à côte depuis le `GroupChat` classique. Chargez‑le après `ag2-network-quickstart`.
