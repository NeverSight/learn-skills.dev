Utilisez‑le lors de l’écriture, de la révision ou de la refactorisation de code Go. Il fournit les meilleures pratiques de production pour Go, couvrant la gestion des erreurs, la concurrence, la dénomination, les tests, les performances, les génériques, les itérateurs et les pièges courants. Tiré du Guide de style Go de Google, du Guide de style Go d’Uber, d’Effective Go et des Commentaires de revue de code Go. Mis à jour pour Go 1.25.
