Wird beim Schreiben, Überprüfen oder Refaktorieren von Go-Codes verwendet. Bietet Best Practices für die Produktion von Go, die Fehlerbehandlung, Parallelität, Benennung, Tests, Leistung, Generika, Iteratoren und häufige Fallstricke abdecken. Aus Google Go Style Guide, Uber Go Style Guide, Effective Go und Go Code Review Comments. Aktualisiert für Go 1.25.
