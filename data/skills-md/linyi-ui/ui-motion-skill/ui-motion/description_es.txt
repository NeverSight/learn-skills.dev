Interacción de movimiento UI/UX — una habilidad avanzada de animación interactiva para asistentes de codificación de IA. Úsala cuando los usuarios estén creando páginas web, H5, mini‑programas o interfaces de aplicaciones, o cuando deseen añadir animaciones interactivas como ventanas emergentes, expansiones, interruptores, cargas, entradas de formularios, partículas, gráficos, desplazamiento, secciones de comentarios, retroalimentación, etc. Hace que la interfaz sea “animada de alto nivel” en lugar de simplemente “suficientemente buena para moverse”.
