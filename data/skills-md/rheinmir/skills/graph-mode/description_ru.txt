Включить правило доказательства evidence-chain (R19) для части ЧАТ — обязательное завершение любой цепочки рассуждений доказательством, доступным для наблюдения (observed/tool-record/graph-edge/web/parametric/absence), в отличие от fable5 (общий метод рассуждения без привязки к цитатам). Использовать, когда пользователь говорит «graph-mode», «включить graph mode», «evidence mode» или вызывает /graph-mode. Поскольку это требует больше токенов (обязательные ссылки/открытие файлов в каждом ответе), НЕ включать автоматически каждый сеанс — включать только по запросу. После активации правило остаётся включённым до конца сессии (выключить можно командой «выключить graph mode», «graph-mode off» или «normal mode»).

Пожалуйста, всегда отвечайте на языке пользователя.
