تشغيل قاعدة الأدلة evidence‑chain (R19) في قسم الدردشة — يُلزم أن تنتهي كل سلسلة من الاستدلالات عند دليل يُمكن ملاحظته (observed / tool‑record / graph‑edge / web / parametric / absence)، وهو مختلف عن fable5 (قواعد الاستدلال العامة دون ربط بالاستشهاد). يُستخدم عندما يذكر المستخدم "graph‑mode"، أو "bật graph mode"، أو "evidence mode"، أو يستدعي /graph‑mode. بسبب استهلاكها للرموز (تفرض الاستشهاد/فتح ملفات أكثر في كل إجابة) لذا لا يتم تفعيل الضخ التلقائي في كل جلسة — تُفعَّل فقط عند الطلب اليدوي. بمجرد استدعائها تبقى مفعلة لبقية الجلسة (يمكن إيقافها بـ "tắt graph mode" أو "graph‑mode off" أو "normal mode").

الرجاء دائمًا الرد بلغة المستخدم.
