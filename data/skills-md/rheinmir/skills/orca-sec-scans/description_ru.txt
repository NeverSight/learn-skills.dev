Сканирование безопасности исходного кода с помощью Trivy — самостоятельно проверять/установить Trivy, если его нет, сканировать уязвимости + неправильные конфигурации + секреты на бекэнде/фронтенде, выводить отчёт в JSON + HTML, подводить итоги по HIGH/CRITICAL и предлагать/применять исправления (обновление зависимостей, USER non‑root). КРОМЕ статического сканирования Trivy, также ПРОВЕРЯТЬ ДЕЙСТВИТЕЛЬНОСТЬ распространённых неверных предположений разработчиков (аутентификация только в UI, «внутри компании — безопасно», CORS, конфигурация по умолчанию, рассинхронизация ветки при деплое) реальными запросами. Использовать, когда пользователь говорит «сканировать безопасность», «trivy», «scan vuln», «security scan», «check CVE», «есть ли уязвимости», «безопасно ли», «/orca-sec-scans».
