Escaneo de seguridad del código fuente con Trivy — verifica/instala Trivy si no está presente, escanea vulnerabilidades + configuraciones erróneas + secretos en backend/frontend, genera informe JSON + HTML, resume HIGH/CRITICAL y propone/aplica correcciones (actualizar dependencias, USER non-root). Además del escaneo estático con Trivy, también verifica activamente las suposiciones predeterminadas o erróneas del desarrollador (auth solo en UI, “interno debería ser seguro”, CORS, configuración por defecto, divergencia de rama de despliegue) mediante solicitudes reales. Se usa cuando el usuario dice “escaneo de seguridad”, “trivy”, “scan vuln”, “security scan”, “check CVE”, “¿hay vulnerabilidades?”, “¿está seguro?”, “/orca-sec-scans”.
