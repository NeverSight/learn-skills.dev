Создайте ISSUE с полной предысторией в локальный ledger (черновик), чтобы другой разработчик мог вытащить её и обработать где‑угодно через /fdk, не затрагивая другие ветки/проекты; автоматически зеркальте её в удалённый трекер, если он есть (GitHub через gh / GitLab через glab / Gitea через tea) — ledger является источником правды. Используется для feature‑gap, tech‑debt, foundation, архитектурных вопросов (KHÁC orca‑issue = инцидент/баг с первым воспроизведением). Включает шаблон контекста + назначение владельца + диспетчеризацию агента. Триггер: «raise issue», «tạo issue», «ghi issue», «mở issue», «log gap này», «issue để dev khác làm», «/raise-issue».
