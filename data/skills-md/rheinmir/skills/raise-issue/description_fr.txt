Créer une ISSUE complète avec le contexte dans le ledger local (brouillon) afin que d’autres développeurs puissent la récupérer via /fdk et la traiter n’importe où sans toucher à d’autres branches ou projets ; se synchroniser automatiquement avec le tracker distant si disponible (GitHub via gh / GitLab via glab / Gitea via tea) — le ledger est la source de vérité. Utilisé pour les écarts de fonctionnalités, la dette technique, les fondations, les questions d’architecture (un ORCA‑issue = incident/bug reproduit‑premièrement). Comprend un modèle de contexte + assignation du propriétaire + agent de dispatch. Déclencheurs : « raise issue », « tạo issue », « ghi issue », « mở issue », « log gap này », « issue pour que d’autres devs le fassent », « /raise-issue ».
