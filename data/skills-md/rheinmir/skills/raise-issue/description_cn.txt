在本地 ledger（草稿）中提出一个完整背景的 ISSUE，以便其他开发者通过 /fdk 任意地点 pull 来处理，而不影响其他分支/项目；如果有远程 tracker（GitHub 用 gh / GitLab 用 glab / Gitea 用 tea），自行镜像到远程——ledger 是真实来源。用于 feature‑gap、技术债、基础设施、架构问题（区别于 orca‑issue = 事故/优先复现的 bug）。包括模板上下文 + 分配所有者 + 派发代理。触发词：'raise issue'、'tạo issue'、'ghi issue'、'mở issue'、'log gap này'、'issue để dev khác làm'、'/raise-issue'。
