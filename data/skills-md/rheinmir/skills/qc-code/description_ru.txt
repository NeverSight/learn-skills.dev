Обзор кода в стиле SENIOR с 10‑летним опытом — четыре категории: security, performance, naming, logic; по каждой категории выставляется ОЦЕНКА/10 + САМЫЙ СЕРЬЁЗНЫЙ ОШИБКА + СПОСОБ ИСПРАВЛЕНИЯ, затем вывод: PASS‑переходим‑к‑следующему или НУЖНО‑ИСПРАВИТЬ. Категория logic ищет баги (null/пустой/отрицательный/overflow, off‑by‑one, race) и генерирует тест‑кейсы, воспроизводящие каждый баг (именовать qc‑*), эти тесты автоматически запускаются через фиксированный хук (0‑токен, без LLM). Вызывается, когда пользователь говорит «qc code», «review code», «soi code», «чемдеть код», «проверка качества кода», «/qc‑code». Отдельно /orca‑sec‑scans (Trivy сканирует СТАТУС — уязвимости/миссконфиги/секреты) и встроенный /code‑review (общий обзор): qc‑code — это формат senior с четырьмя пунктами, оценкой, вердиктом + генерацией тестов‑воспроизведений. По умолчанию обзор текущего DIFF; при необходимости указывается файл.
