Revue de code style SENIOR 10 ans — quatre axes : sécurité · performance · nomenclature · logique, chaque axe attribue UNE NOTE/10 + L’ERREUR LA PLUS GRAVE + COMMENTAIRE DE CORRECTION, suivi d’une conclusion PASS‑pour‑l’étape suivante ou À‑CORRIGER. L’axe logique recherche les bugs (null/vide/négatif/overflow, off‑by‑one, race) et GÈNE un cas de test reproduisant chaque bug (nommé qc‑*), ces tests s’exécutent automatiquement via un hook prédéfini (0‑token, sans LLM). Déclencher lorsque l’utilisateur dit « qc code », « review code », « inspecter le code », « noter le code », « vérifier la qualité du code », « /qc‑code ». DIFFÉRENT DE /orca‑sec‑scans (Trivy scanne LES VULNÉRABILITÉS — vuln/misconfig/secret) et de /code‑review intégré (revue générale) : qc‑code est le format senior à quatre axes notation‑verdict + génération de tests de reproduction. Par défaut, revue du DIFF actuel ; spécifier le fichier si besoin.
