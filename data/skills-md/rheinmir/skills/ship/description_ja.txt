PUSH/RELEASE/PR/MR を確定するワークフロー — ユーザーが「release」「push」「ship」「lên release」「mở PR」「tạo MR」と呼びかけたときに起動します。プッシュする前に条件チェックリストを実行します： (1) medic --ci（ヘルスチェック：law bite/drift/docs/code/eval）、 (2) diff に新機能がある場合は本番リモートで UAT /fdk-uat を実施（release/pr/mr のみ対象、medic --ci は curl 経路を証明できません）、 (3) git がクリーンであること（scratchpad/ephemeral はトラッキングしない）、 (4) selftest、 (5) 最も近いタグからのバージョンを x.x.x+1 に設定（リリースレベルのみ）、 (6) パッチノート／PR 本文は正直に記述（Added/Fixed/Removed/Known-limitations、誇張しない）。5 つのモードをサポートします：'ship push' = タグなしでプッシュのみ；'ship release' = プッシュ + タグ vX.Y.Z + リリースノート；'ship pr' = ブランチをプッシュ + gh pr create（GitHub）；'ship mr' = ブランチをプッシュ + glab mr create（GitLab）；'ship merge' = リモート上のリポジトリの受信 PR/MR を列挙し、ブランチを取得、gate+テストを実行し、テストが緑（成功）ならマージ。副作用ステップの前に承認待ちで STOP。トリガー：/ship、'release'、'push'、'ship'、'mở PR'、'tạo MR'、'ship pr'、'ship mr'、'ship merge'、'gom PR về merge'、'merge PR nếu test xanh'、'chuẩn bị push'、'lên release'、'checklist trước push'、'đủ điều kiện push chưa'。
