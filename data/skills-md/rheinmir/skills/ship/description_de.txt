Unterstützt werden 5 Stufen: “ship push” = nur push ohne Tag; “ship release” = push + Tag vX.Y.Z + Release‑Notes; “ship pr” = Branch push + gh pr create (GitHub); “ship mr” = Branch push + glab mr create (GitLab); “ship merge” = Auflisten der eingehenden PR/MR des Repos nach Remote, Branch holen, Gate + Test ausführen, nur mergen, wenn GRÜN. STOP wartet auf Genehmigung vor dem Side‑Effect‑Schritt.
