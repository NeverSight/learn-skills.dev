Flujo de trabajo para cerrar PUSH/RELEASE/PR/MR — se invoca cuando el usuario menciona “release”, “push”, “ship”, “lên release”, “mở PR” o “tạo MR”. Ejecuta una LISTA DE VERIFICACIÓN de condiciones ANTES de empujar: (1) medic --ci (puerto de salud: ley de mordida/drift/docs/code/eval), (2) UAT /fdk-uat a través del remoto real si el diff tiene nueva capacidad (solo release/pr/mr, medic --ci no puede demostrar la ruta curl), (3) git limpio (scratchpad/ephemeral no rastreados), (4) selftest, (5) versión x.x.x+1 a partir de la etiqueta más reciente (solo nivel release), (6) notas de parche/cuerpo del PR honestas (Added/Fixed/Removed/Known‑limitations, NO exagerar). Soporta 5 niveles: “ship push” = solo push sin etiqueta; “ship release” = push + etiqueta vX.Y.Z + notas de lanzamiento; “ship pr” = push de rama + gh pr create (GitHub); “ship mr” = push de rama + glab mr create (GitLab); “ship merge” = listar PR/MR ENTRANTES del repositorio por remote, traer la rama, ejecutar gate+test, solo merge si VERDE. STOP espera autorización antes del paso de efectos secundarios. Disparadores: /ship, “release”, “push”, “ship”, “mở PR”, “tạo MR”, “ship pr”, “ship mr”, “ship merge”, “gom PR về merge”, “merge PR si test verde”, “preparar push”, “lên release”, “checklist antes del push”, “¿cumple con las condiciones para push?”.
