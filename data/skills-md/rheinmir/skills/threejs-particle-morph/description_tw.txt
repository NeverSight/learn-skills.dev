Particle cloud Three.js（THREE.Points + BufferGeometry）從隨機位置聚合成圖像/標誌，隨著頁面捲動的進度——從隱藏的 canvas 取樣像素作為目標座標，根據捲動進行位置插值（lerp）。當用戶說「particle image」、「粒子聚合成圖像」、「three.js particle scroll」、「point cloud morph」、「particle cloud 依捲動變形」或輸入 /threejs-particle-morph 時呼叫。不同於 `skills/blur`（那是使用 GLSL 徑向模糊的 shader 在單一平面上將圖像轉換為另一張圖像——此處的 particle cloud 為離散點雲變形為圖像，渲染技術完全不同——使用 PointsMaterial / BufferGeometry，而非在 PlaneGeometry 上的 ShaderMaterial）。
