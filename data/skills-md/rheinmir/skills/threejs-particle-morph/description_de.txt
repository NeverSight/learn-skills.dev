Particle-Cloud Three.js (THREE.Points + BufferGeometry) konvergiert von zufälligen Positionen zu einem Bild/Logo basierend auf dem Scrollfortschritt — Pixel vom versteckten Canvas werden als Zielkoordinaten verwendet, Position wird per Lerp dem Scrollen angepasst. Aufruf, wenn der Nutzer sagt „particle image“, „hạt hội tụ thành ảnh“, „three.js particle scroll“, „point cloud morph“, „particle cloud biến hình theo scroll“ oder /threejs-particle-morph. ANDERES `skills/blur` (das ist ein GLSL‑Radial‑Blur‑Shader, das BILD auf ein anderes Bild auf einer Ebene überträgt — dies ist eine diskrete Particle‑Cloud, die zu einem Bild morphgt, eine völlig andere Rendering‑Technik — PointsMaterial/BufferGeometry, nicht ShaderMaterial auf PlaneGeometry).
