overstack フレームワークの総合ヘルスゲート／最終防衛ライン — /medic（または CLI の `medic`）を入力して、システムが 1 つのコマンドで健全であることを証明する：ルールがまだ咬んでいるか（harness‑doctor fire‑drill）、バリデータがドリフトしないか、ドキュメントがディスクと合致しているか、コードがコンパイルできるか、評価がリグレッションしないか、バックストップ Git が生きているか。Hub は 1 つの名前で — サブコマンドを覚える代わりに範囲を記述する（`medic` = all・`medic rules`・`medic docs eval`）。コミット/PR の前、プルやマシン変更後、あるルールがもうブロックしなくなったと疑うとき、またはスキル／ルール／ジェネレータを追加したときに使用する（忘れたフェンスがあれば medic が自動で警告）。トリガー：/medic、"medic"、"chạy medic"、"hệ còn khoẻ không"、"rà luật có cắn không"、"cổng phòng thủ cuối"、"health gate"、"last line of defense".
