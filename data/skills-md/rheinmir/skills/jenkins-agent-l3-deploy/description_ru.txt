Разверните приложение docker-compose через Jenkins INBOUND AGENT, работающий на целевом сервере (без SSH от контроллера), с укреплением Docker‑secrets уровня “L3” — секреты во время выполнения находятся в tmpfs и никогда не появляются в `docker inspect` и не попадают в `.env`. Используйте, когда пользователь хочет: “deploy via jenkins agent”, “no-ssh deploy”, “agent thay vì ssh”, “docker secrets L3”, “ẩn secret khỏi docker inspect”, “secret không nằm trên đĩa”, либо собирает Jenkins pipeline, который развёртывает docker-compose на Linux‑хосте. Содержит подводные камни, полученные из реального 1:1 запуска (Java 21, права секретов 0444, файл‑credential 0400, пользователь агента нуждается в docker+sudo).
