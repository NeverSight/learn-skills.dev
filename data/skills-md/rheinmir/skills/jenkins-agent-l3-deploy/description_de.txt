Ein Docker‑Compose‑App über einen Jenkins INBOUND AGENT bereitstellen, der auf dem Zielserver läuft (kein SSH vom Controller), mit Docker‑Secrets‑Härtung „L3“ – Laufzeit‑Secrets befinden sich auf tmpfs und erscheinen weder in `docker inspect` noch in `.env`. Verwenden, wenn der Benutzer will: „deploy via jenkins agent“, „no-ssh deploy“, „agent thay vì ssh“, „docker secrets L3“, „ẩn secret khỏi docker inspect“, „secret không nằm trên đĩa“, oder eine Jenkins‑Pipeline erstellt, die Docker‑Compose auf einem Linux‑Host bereitstellt. Enthält die Fallstricke, die aus einem realen 1:1‑Durchlauf gelernt wurden (Java 21, 0444‑Secret‑Berechtigungen, 0400‑Datei‑Credential, Agent‑Benutzer benötigt docker + sudo).
