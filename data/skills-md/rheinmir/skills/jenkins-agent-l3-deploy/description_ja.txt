Jenkins INBOUND AGENT がターゲットサーバ上で動作する環境で、Docker‑compose アプリをデプロイします（コントローラからの SSH は使用しません）。Docker‑secrets の「L3」ハーデニングを適用し、実行時シークレットは tmpfs 上に保持され、`docker inspect` や `.env` ファイルに一切現れません。以下のようなケースで使用します：「deploy via jenkins agent」「no-ssh deploy」「agent thay vì ssh」「docker secrets L3」「ẩn secret khỏi docker inspect」「secret không nằm trên đĩa」または、Linux ホストへ docker‑compose をデプロイする Jenkins パイプラインを構築している場合です。実際の 1:1 実行で得た注意点を組み込みました（Java 21、シークレット権限 0444、ファイルクレデンシャルは 0400、エージェントユーザーは docker と sudo が必要）。
