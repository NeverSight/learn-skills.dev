Distribuisci un’app docker‑compose tramite un JENKINS INBOUND AGENT in esecuzione sul server di destinazione (senza SSH dal controller), con hardening Docker‑secrets “L3” — i segreti a runtime vivono su tmpfs e non appaiono mai in `docker inspect` né in `.env`. Da usare quando l’utente desidera: “deploy via jenkins agent”, “no-ssh deploy”, “agent thay vì ssh”, “docker secrets L3”, “ẩn secret khỏi docker inspect”, “secret không nằm trên đĩa”, o sta configurando una pipeline Jenkins che distribuisce docker‑compose su un host Linux. Include le insidie apprese da un’esecuzione reale 1:1 (Java 21, permessi segreto 0444, credenziali file 0400, l’utente agente necessita di docker+sudo).
