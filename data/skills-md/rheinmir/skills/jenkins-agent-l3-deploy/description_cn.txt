通过在目标服务器上运行的 Jenkins INBOUND AGENT（控制器不使用 SSH）部署 docker‑compose 应用，采用 Docker‑secrets “L3” 加固——运行时的 secret 存放在 tmpfs，永远不会出现在 `docker inspect` 或 `.env` 中。当用户需要以下场景时使用：“通过 jenkins agent 部署”、 “无 SSH 部署”、 “agent thay vì ssh”、 “docker secrets L3”、 “隐藏 secret 不出现在 docker inspect”、 “secret 不在磁盘上”，或正在编写将 docker‑compose 部署到 Linux 主机的 Jenkins 流水线。包括从实际 1:1 运行中总结的坑点（Java 21、0444 secret 权限、0400 文件凭证、agent 用户需要 docker+sudo）。
