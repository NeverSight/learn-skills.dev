Déployer une application docker-compose via un AGENT JENKINS INBOUND s'exécutant sur le serveur cible (pas de SSH depuis le contrôleur), avec un durcissement Docker‑secrets « L3 » — les secrets d'exécution résident sur tmpfs et n’apparaissent jamais dans `docker inspect` ni dans `.env`. À utiliser lorsque l'utilisateur veut : « deploy via jenkins agent », « no‑ssh deploy », « agent thay vì ssh », « docker secrets L3 », « ẩn secret khỏi docker inspect », « secret không nằm trên đĩa », ou qu’il crée un pipeline Jenkins déployant docker‑compose sur un hôte Linux. Encode les gotchas tirés d’une vraie exécution 1 : 1 (Java 21, perms secret 0444, fichier‑credential 0400, l’utilisateur agent nécessite docker + sudo).
