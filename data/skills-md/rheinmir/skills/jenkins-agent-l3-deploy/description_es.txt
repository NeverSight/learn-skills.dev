Despliegue una aplicación docker‑compose a través de un AGENTE INBOUND de Jenkins que se ejecuta en el servidor de destino (sin SSH desde el controlador), con endurecimiento Docker‑secrets “L3”: los secretos en tiempo de ejecución viven en tmpfs y nunca aparecen en `docker inspect` ni en `.env`. Úselo cuando el usuario quiera: “deploy via jenkins agent”, “no-ssh deploy”, “agent thay vì ssh”, “docker secrets L3”, “ẩn secret khỏi docker inspect”, “secret không nằm trên đĩa”, o esté construyendo una canalización de Jenkins que despliegue docker‑compose en un host Linux. Incluye los problemas aprendidos de una ejecución real 1:1 (Java 21, permisos de secreto 0444, credencial de archivo 0400, el usuario del agente necesita docker+sudo).
