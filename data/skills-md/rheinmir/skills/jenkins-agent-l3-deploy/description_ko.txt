대상 서버에서 실행되는 Jenkins INBOUND AGENT를 통해 docker‑compose 애플리케이션을 배포합니다(컨트롤러에서 SSH 사용 안 함). Docker‑secrets “L3” 하드닝을 적용하여 런타임 시크릿은 tmpfs에 저장되고 `docker inspect`나 `.env`에 절대 나타나지 않게 합니다. 다음과 같은 경우에 사용합니다: “deploy via jenkins agent”, “no-ssh deploy”, “agent thay vì ssh”, “docker secrets L3”, “ẩn secret khỏi docker inspect”, “secret không nằm trên đĩa”, 혹은 Jenkins 파이프라인을 구성해 Linux 호스트에 docker‑compose를 배포하려는 경우. 실제 1:1 실행에서 얻은 주의사항을 포함합니다(Java 21, 0444 시크릿 권한, 0400 파일‑credential, agent 사용자에게 docker + sudo 권한 필요).
