在目標伺服器上以 Jenkins INBOUND AGENT（不透過控制端 SSH）部署 docker‑compose 應用，並使用 Docker‑secrets 「L3」加固——執行時的密鑰存放於 tmpfs，永不出現在 `docker inspect` 或 `.env` 中。適用於使用者想要「透過 jenkins agent 部署」「不使用 SSH 部署」「agent 而非 ssh」「docker secrets L3」「隱藏 secret 免於 docker inspect」「secret 不落在磁碟上」或正在編寫 Jenkins pipeline，以在 Linux 主機上部署 docker‑compose。內容包含從真實 1:1 實作中學到的注意事項（Java 21、密鑰權限 0444、檔案憑證 0400、agent 用戶必須具備 docker 與 sudo 權限）。
