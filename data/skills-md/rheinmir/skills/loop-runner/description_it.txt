Deterministico driver di ciclo agente con guardrails — avvolgere ogni passo con proponi → verifica‑deterministica → (critica → revisione) e imporre guardie di terminazione rigide (max_iter, budget di tempo reale, nessun progresso via hash di stato, escalation a umano). Il ciclo di controllo + guardie + rilevamento di progresso sono deterministici; il passo LLM di critica/revisione è l’adattatore quarantinato. Attivare quando un ciclo di correzione dell’agente non deve girare all’infinito e non deve poter argomentare per aggirare un test fallito.
