Style de conception Supademo pour la visite produit intégrée (utilisé avec la compétence tour‑guide — composant de base sans dépendance) : clignotement hotspot pulse, carte d’infobulle, compteur d’étapes + boutons de navigation, barre de progression, jetons de thème — transformé en recette Tailwind/CSS prête à l’emploi. Déclencheur : « /tour-guide-supademo », « tour de type Supademo », « style supademo », « blinker hotspot ». Convention : le style distillé d’un autre produit sera une compétence séparée /tour‑guide‑<nom>.
