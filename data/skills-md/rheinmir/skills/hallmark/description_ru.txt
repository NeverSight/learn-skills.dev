Стандартный дизайн‑платформа overstack (anti‑AI‑slop) — вся UI базируется на ней: создание новых страниц, аудит, редизайн, извлечение дизайна из URL/скриншота, и ЗАКРЕПЛЕНИЕ СИСТЕМЫ ДИЗАЙНА ДЛЯ ВСЕХ ЭКРАНОВ через design.md (запуск `hallmark redesign` всего приложения один раз → генерируется design.md в корне проекта → все последующие экраны используют одну и ту же систему токенов/типов/мошн, а не каждый экран по‑своему). Вызывается, когда пользователь говорит: «дизайн», «интерфейс», «делать UI/landing page/новое приложение», «redesign», «audit design», «design system», «синхронизация интерфейса между экранами», «закрепить систему дизайна», «почему эта страница выглядит AI‑generated», либо обращается напрямую к hallmark / использует глаголы build·audit·redesign·study. При работе с UI без уверенности, что использовать → использовать этот скилл (он является платформой, остальные скиллы‑вкусы — это надстройки).
