Plateforme de design par défaut d'overstack (anti‑AI‑slop) — toute l’UI repose sur elle : création de nouvelles pages, audit, redesign, extraction de design depuis URL/capture d’écran, et VERROUILLAGE DU SYSTÈME DE DESIGN À TRAVERS LES ÉCRANS via design.md (exécuter `hallmark redesign` sur toute l’application une fois → génère design.md à la racine du projet → tous les écrans suivants utilisent le même système de tokens/types/motions, pas un style différent par écran). Déclencher lorsque l’utilisateur dit : « design », « interface », « créer UI/landing page/nouvelle app », « redesign », « audit design », « design system », « synchroniser les interfaces entre les écrans », « verrouiller le système de design », « pourquoi cette page a l’air générée par IA », ou mentionne explicitement hallmark / utilise le verbe build·audit·redesign·study. Si on touche à l’UI sans être sûr de quoi utiliser → utiliser cette compétence (c’est la plateforme, les autres compétences de goût sont des saveurs au‑dessus).
