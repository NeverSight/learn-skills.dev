Plataforma de diseño predeterminada de overstack (anti-AI-slop) — toda la UI se basa en ella: crear (build) una nueva página, auditoría, rediseño, extraer el diseño a partir de URL/captura de pantalla, y BLOQUEAR EL SISTEMA DE DISEÑO A TRAVÉS DE LAS PANTALLAS mediante design.md (ejecutar `hallmark redesign` en toda la app una vez → generar design.md en la raíz del proyecto → todas las pantallas posteriores siguen el mismo sistema de tokens/tipos/motion, no cada pantalla con un estilo diferente). Se invoca cuando el usuario dice: “diseño”, “interfaz”, “hacer UI/página de aterrizaje/app nuevo”, “redesign”, “audit design”, “design system”, “sincronizar la interfaz entre pantallas”, “bloquear el sistema de diseño”, “por qué esta página parece generada por IA”, o menciona directamente hallmark / usa los verbos build·audit·redesign·study. Si se trata de tocar la UI sin estar seguro de qué usar → utilizar esta habilidad (es la plataforma, las demás habilidades son sabores adicionales).
