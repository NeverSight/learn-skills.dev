Piattaforma di design predefinita di overstack (anti-AI-slop) — tutte le UI si basano su di essa: costruire nuove pagine, audit, redesign, estrarre il design da URL/screenshot, e BLOCCARE IL SISTEMA DI DESIGN PER TUTTE LE SCHERMATE tramite design.md (eseguire `hallmark redesign` per tutta l'app una volta → genera design.md nella radice del progetto → tutte le schermate successive utilizzano lo stesso sistema di token/type/motion, non ogni schermata con uno stile diverso). Invocare quando l'utente dice: “design”, “interfaccia”, “creare UI/landing page/app nuova”, “redesign”, “audit design”, “design system”, “sincronizzare le interfacce tra le schermate”, “bloccare il sistema di design”, “perché questa pagina sembra generata da AI”, oppure invocare esplicitamente hallmark / usare i verbi build·audit·redesign·study. Se si tocca l'UI senza sapere cosa usare → utilizzare questa skill (è la piattaforma, le altre skill taste sono i flavour sopra).
