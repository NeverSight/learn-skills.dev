Извлечь существующую систему дизайна проекта — из кода (цветовые токены, шкала размеров, компоненты) или из URL работающего сайта — в ОДНУ HTML‑страницу‑справочник в стиле Figma UI kit: основы + компоненты по группам + шаблоны для мобильных/десктопных экранов, изменить палитру/яркость/форму, скопировать токены/HTML/hex. Значения получаются запуском реальной функции токенов (или считыванием реальных стилей с помощью Playwright), а не ручным вводом; есть цикл ОБОРОТ ПОИСКА, автоматически переходящий по ссылкам + нажимает открыть скрытые разделы, убирает дубли по подписи, останавливается при достижении согласованности, и контрольный шлюз требует, чтобы каждый найденный паттерн присутствовал в наборе (не останавливается на «скелете»). Стандартный образец вывода: references/ui-kit-reference.html. Отличие hallmark (создание/изменение нового дизайна): этот навык лишь КОПИРУЕТ существующую систему, без творчества.
