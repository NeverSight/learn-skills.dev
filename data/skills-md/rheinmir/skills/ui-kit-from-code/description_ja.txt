あるプロジェクトの既存デザインシステムを、コード（カラー トークン、サイズスケール、コンポーネント）または稼働中のサイトの URL から、Figma UI キット形式の HTML リファレンスページに変換する――基礎要素 + グループ別コンポーネント + モバイル/デスクトップのサンプル画面、パレット/明度/形状の変更、トークン/HTML/hex のコピー。値は実際のトークン関数を実行（または Playwright で実際のスタイルを読み取る）ことで取得し、手入力はしない。リンクをたどり自動で探索し、非表示部分を開く操作を行い、署名に基づいて重複を除去し、安定するまで続け、最終的に検出されたすべてのパターンがキットに含まれることを保証する（骨格だけで止まらない）。標準出力例: references/ui-kit-reference.html。他のハイライト（新規デザイン構築/変更）: このスキルは既存システムをコピーするだけで、創作は行わない。ユーザーが「ui kit」「figma ui kit bằng html」「bóc design system ra」「trang tham chiếu component」「design token page」「component gallery」「style guide từ code」「bóc trang này ra html kit」「làm giàu kit」または /ui-kit-from-code と言ったときに呼び出す。
