抽取一個專案現有的設計系統——從程式碼（顏色 token、尺寸尺度、元件）或從正在運行的網站 URL，生成一個 HTML 參考頁面，類似 Figma UI kit：基礎樣式 + 分組元件 + 手機/桌面樣板頁面，調整調色盤/亮暗/形狀，複製 token/HTML/十六進位碼。數值須透過執行真實的 token 函式（或使用 Playwright 讀取真實樣式）取得，而非手動輸入；具備自動探索環節，依照連結逐步點開隱藏部分，依簽名去除重複，完成時停止，且驗證門檻要求所有找到的模式都必須出現在套件中（不只停留在骨架階段）。標準輸出範本：references/ui-kit-reference.html。其他標誌（製作/改變新設計）：此技能僅複製現有系統，不會創作。當使用者說「ui kit」、「figma ui kit 用 html」、「拆解 design system」、「元件參考頁面」、「design token page」、「component gallery」、「從程式碼產生 style guide」、「把這頁拆成 html kit」、「豐富 kit」或 /ui-kit-from-code 時即呼叫此功能。
