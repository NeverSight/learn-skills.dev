تأثير تمرير الصفحة باستخدام CSS فقط عبر واجهة برمجة تطبيقات الرسوم المتحركة المدفوعة بالتمرير في CSS الأصلية (animation-timeline scroll()/view()، animation-range) — بلا جافاسكريبت. يُستدعى عند قول المستخدم "css scroll driven animation"، "animation-timeline"، "scroll animation không js"، "css thuần cuộn trang"، "scroll-driven CSS"، أو /css-scroll-driven-native. مختلف عن `skills/scroll-effects` (الذي يستخدم IntersectionObserver بجافاسكريبت، يعمل على جميع المتصفحات الحديثة) — هذه المهارة لا تستخدم جافاسكريبت لكن المتصفح لم يدعمها بالكامل بعد (Firefox/Safari لا يزالان بحاجة إلى تمكين عبر علم/إصدار تجريبي)، تُستخدم كتحسين تدريجي فوق scroll‑effects، ولا تُستبدل عندما يكون من الضروري تشغيلها على جميع المتصفحات.
