네이티브 CSS Scroll-Driven Animations API (animation-timeline scroll()/view(), animation-range)를 이용한 순수 CSS 페이지 스크롤 효과 — JavaScript 전혀 사용하지 않음. 사용자가 “css scroll driven animation”, “animation-timeline”, “scroll animation không js”, “css thuần cuộn trang”, “scroll-driven CSS” 혹은 /css-scroll-driven-native 라고 말하면 호출됩니다. `skills/scroll-effects`와는 다릅니다 (그것은 IntersectionObserver JS를 사용하여 모든 최신 브라우저에서 동작) — 이 스킬은 JS를 전혀 사용하지 않지만 브라우저가 아직 충분히 지원하지 않습니다 (Firefox/Safari는 아직 플래그/롤아웃 단계). scroll-effects 위에 프로그레시브 엔핸스먼트로 사용하고, 모든 브라우저에서 확실히 동작해야 할 경우 대체하지 않습니다.
