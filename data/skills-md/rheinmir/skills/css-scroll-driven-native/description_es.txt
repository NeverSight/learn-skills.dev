Efecto de desplazamiento de página puro CSS mediante la API nativa de animaciones impulsadas por scroll de CSS (animation-timeline scroll()/view(), animation-range) — CERO JavaScript. Se invoca cuando el usuario dice "css scroll driven animation", "animation-timeline", "scroll animation không js", "css thuần cuộn trang", "scroll-driven CSS", o /css-scroll-driven-native. DIFERENTE de `skills/scroll-effects` (que usa IntersectionObserver JS, funciona en TODOS los navegadores modernos) — esta habilidad no usa JS pero el navegador AÚN NO la soporta completamente (Firefox/Safari todavía están detrás de una bandera/implementación), se usa como mejora progresiva sobre scroll‑effects, no sustituye cuando se necesita que funcione en todos los navegadores.
