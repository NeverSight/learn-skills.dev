通过原生 CSS 滚动驱动动画 API（animation‑timeline、scroll()/view()、animation‑range）的纯 CSS 页面滚动效果 — 零 JavaScript。  
当用户说 “css scroll driven animation”、 “animation‑timeline”、 “scroll animation 不用 js”、 “纯 css 页面滚动”、 “scroll‑driven CSS”，或输入 /css‑scroll‑driven‑native 时触发。  
区别于 `skills/scroll-effects`（使用 IntersectionObserver JS，兼容所有现代浏览器）——此技能 0 JS，但浏览器尚未完全支持（Firefox/Safari 仍在标志/推出阶段），用于在 scroll‑effects 之上进行渐进增强，而在需要在所有浏览器都可靠运行时不替代它。
