純 CSS 捲動頁面效果透過原生 CSS Scroll‑Driven Animations API（animation‑timeline、scroll()/view()、animation‑range）——完全不使用 JavaScript。當使用者說「css scroll driven animation」、「animation‑timeline」、「scroll animation 不使用 js」、「純 css 捲動頁面」、「scroll‑driven CSS」或 /css‑scroll‑driven‑native 時觸發。不同於 `skills/scroll‑effects`（那個使用 IntersectionObserver JavaScript，能在所有現代瀏覽器上執行）——此技能 0 JS，但瀏覽器尚未完全支援（Firefox / Safari 仍需開啟旗標或逐步推出），可作為 scroll‑effects 之上的漸進增強，無法取代在所有瀏覽器上必須保證執行的情況。
