Эффект прокрутки страницы, реализованный полностью на CSS с помощью нативного API CSS Scroll-Driven Animations (animation-timeline scroll()/view(), animation-range) — НОЛЬ JavaScript. Вызывается, когда пользователь говорит «css scroll driven animation», «animation-timeline», «scroll animation без js», «чистый css прокрутка», «scroll-driven CSS» или вводит /css-scroll-driven-native. Отличается от `skills/scroll-effects` (там используется IntersectionObserver на JavaScript и работает во ВСЕХ современных браузерах) — этот навык не использует JS, но браузеры ещё полностью его не поддерживают (Firefox/Safari находятся за флагом/в процессе rollout), используется как progressive enhancement поверх scroll-effects и не заменяет его, когда нужен надёжный кросс‑браузерный запуск.
