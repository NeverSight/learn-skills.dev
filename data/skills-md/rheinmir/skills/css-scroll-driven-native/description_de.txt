Pure CSS-Scroll-Effekt über die native CSS Scroll-Driven Animations API (animation-timeline scroll()/view(), animation-range) — KEIN JavaScript. Aufgerufen, wenn der Benutzer „css scroll driven animation“, „animation-timeline“, „scroll animation không js“, „css thuần cuộn trang“, „scroll-driven CSS“ oder /css-scroll-driven-native nennt. Anders als `skills/scroll-effects` (das IntersectionObserver JavaScript nutzt und in ALLEN modernen Browsern läuft) — diese Fähigkeit verwendet kein JavaScript, aber die Browser unterstützen sie noch nicht vollständig (Firefox/Safari sind noch hinter einer Flag/Einführungsphase), sie wird als progressive Enhancement über scroll-effects verwendet, ersetzt sie nicht, wenn eine sichere Ausführung in allen Browsern erforderlich ist.
