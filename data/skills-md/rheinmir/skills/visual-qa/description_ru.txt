Закрытый самостоятельный визуальный QA‑процесс для локального SPA (приложения, созданного /br, или любого веб‑приложения): снимок headless каждого маршрута → BASELINE pixel‑diff (выявление нежелательных изменений) → неизменная проверка машины (соответствие дизайну) → агент ПРОЧИТЫВАЕТ все изображения согласно рубрике → FINDINGS.md → исправление → повторный снимок → проходит только если и машина, и глаз считают его чистым. Использовать при изменении темы/UI/ребрендинге, когда расширение MCP не может захватить localhost, или когда требуется контролировать UI для фрейма. Триггер: «qa thị giác», «visual qa», «route‑shots», «screenshot từng route», «kiểm giao diện», «baseline diff», «UI có regression không», «test giao diện headless», «/visual‑qa».
