Principes pour écrire, refactoriser et relire du code React afin d&#39;en garantir la maintenabilité : éviter l&#39;abstraction prématurée (le « composant démon »), maintenir la clarté du flux de données et placer l&#39;état et les effets au bon endroit. À utiliser lors de l&#39;écriture ou de la refactorisation d&#39;un composant ou d&#39;un hook React, pour décider d&#39;extraire ou de réutiliser un élément, pour évaluer la maintenabilité du code React, pour utiliser `useEffect`, pour choisir l&#39;emplacement de l&#39;état ou pour démêler les problèmes de transmission de props et de sur-abstraction.
