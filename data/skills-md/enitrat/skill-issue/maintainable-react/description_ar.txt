مبادئ كتابة وإعادة هيكلة ومراجعة كود React بحيث يظل قابلاً للصيانة — مقاومة التجريد المبكر (المكوّن "الشيطاني")، الحفاظ على وضوح تدفق البيانات، ووضع الحالة والآثار في المكان المناسب. يُستَخدم عند كتابة أو إعادة هيكلة مكوّن أو Hook في React، أو عند اتخاذ قرار باستخراجه أو إعادة استخدامه، أو عند مراجعة React من حيث الصيانة، أو عند اللجوء إلى useEffect، أو اختيار مكان وجود الحالة، أو فك تشابك تمرير الخصائص المفرط (prop drilling) والتجريد الزائد.
