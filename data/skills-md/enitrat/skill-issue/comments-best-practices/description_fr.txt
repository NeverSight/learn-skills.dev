Guide pour décider quand conserver, écrire, réécrire ou supprimer les commentaires de code et le JSDoc. À utiliser lors de la rédaction de nouveaux commentaires, de la révision des commentaires dans une PR ou du nettoyage des commentaires dans le code existant. Déclencheur pour « devrais‑je commenter ceci », « réviser ces commentaires », « ce commentaire est‑il nécessaire », « nettoyer les commentaires », « écrire du JSDoc », « documenter cette fonction ».
