Vocs（vocs.dev）上のパブリックライブラリ向けに、包括的で高品質な SDK ドキュメントを書くためのルールとパターン。ドキュメント構成、ナラティブトーン、ユーザーガイド、API リファレンス、そして Vocs のエージェントが読み取れる出力（llms.txt、Markdown ルート、MCP）をカバーします。使用シーン：① パブリック SDK／ライブラリのドキュメントを執筆またはレビューする時、② フック／関数／クラスの API リファレンスページを作成する時、③ 入門ガイドやチュートリアルを書く時、④ ドキュメントサイトをゼロから構築する時、⑤ ドキュメントの品質と一貫性をレビューする時、⑥ SDK 用の Vocs ドキュメントサイトを設定または構成する時。
