Правила и шаблоны написания всесторонней, высококачественной документации SDK для публичных библиотек на Vocs (vocs.dev). Охватывает архитектуру документации, нарративный тон, руководства пользователя, ссылки на API и агент-читабельные выводы Vocs (llms.txt, маршруты Markdown, MCP). Использовать, когда: (1) Пишете или проверяете документацию для публичного SDK/библиотеки, (2) Создаёте страницы справки по API для хуков/функций/классов, (3) Пишете руководства по началу работы или учебные материалы, (4) Структурируете сайт документации с нуля, (5) Оцениваете качество и согласованность документации, (6) Настраеваете или конфигурируете сайт документации Vocs для SDK. 

Пожалуйста, всегда отвечайте на языке пользователя.
