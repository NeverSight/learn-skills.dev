Reglas y patrones para redactar documentación completa y de alta calidad para SDK de bibliotecas públicas en Vocs (vocs.dev). Cubre la arquitectura de la documentación, el tono narrativo, guías de usuario, referencias de API y las salidas legibles por agentes de Vocs (llms.txt, rutas Markdown, MCP). Uso cuando: (1) Redactar o revisar documentación para un SDK/biblioteca pública, (2) Crear páginas de referencia de API para hooks/funciones/clases, (3) Escribir guías de introducción o tutoriales, (4) Estructurar un sitio de documentación desde cero, (5) Revisar la calidad y consistencia de la documentación, (6) Configurar o instalar un sitio de documentación Vocs para un SDK.
