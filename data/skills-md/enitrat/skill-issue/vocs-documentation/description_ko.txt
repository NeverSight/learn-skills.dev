Vocs(vocs.dev)에서 공개 라이브러리를 위한 포괄적이고 고품질 SDK 문서를 작성하기 위한 규칙 및 패턴. 문서 구조, 내러티브 톤, 사용자 가이드, API 레퍼런스, 그리고 Vocs의 에이전트가 읽을 수 있는 출력물(llms.txt, Markdown 라우트, MCP)을 다룸. 사용 상황: (1) 공개 SDK/라이브러리 문서를 작성하거나 검토할 때, (2) 훅/함수/클래스에 대한 API 레퍼런스 페이지를 만들 때, (3) 시작 가이드나 튜토리얼을 작성할 때, (4) 문서 사이트를 처음부터 구조화할 때, (5) 문서 품질 및 일관성을 검토할 때, (6) SDK를 위한 Vocs 문서 사이트를 설정하거나 구성할 때.

항상 사용자의 언어로 응답해 주세요.
