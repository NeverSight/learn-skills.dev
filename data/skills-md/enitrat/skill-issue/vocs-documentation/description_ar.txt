قواعد وأنماط لكتابة وثائق SDK شاملة وعالية الجودة للمكتبات العامة على Vocs (vocs.dev). يغطي بنية الوثائق، النبرة السردية، أدلة المستخدم، مراجع API، والمخرجات القابلة للقراءة من قبل وكيل Vocs (llms.txt، مسارات Markdown، MCP). يُستخدم عندما: (1) كتابة أو مراجعة وثائق SDK/مكتبة عامة، (2) إنشاء صفحات مرجع API للهوكس/الدوال/الفئات، (3) كتابة أدلة البدء أو الدروس التعليمية، (4) هيكلة موقع وثائق من الصفر، (5) مراجعة جودة الوثائق واتساقها، (6) إعداد أو تكوين موقع وثائق Vocs لـ SDK.

يرجى دائماً الرد بلغة المستخدم.
