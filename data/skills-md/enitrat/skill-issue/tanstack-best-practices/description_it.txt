Pratiche consigliate per costruire librerie di hook con TanStack Query. Usare quando: (1) si scrivono hook useQuery/useMutation che avvolgono funzioni asincrone di recupero dati, (2) si progetta lo schema delle chiavi di query e i sistemi di identità della cache, (3) si costruiscono factory di opzioni di query indipendenti dal framework, (4) si implementano pattern di invalidazione della cache (invalidate vs remove vs setQueryData), (5) si incapsula TanStack Query in una libreria a più livelli (azioni core, opzioni di query, hook del framework), (6) si gestiscono valori non serializzabili (bigint, istanze di classi) nelle chiavi di query, (7) si collegano store esterni (zustand, signals) con la reattività di TanStack Query. Derivato dall’architettura di produzione di wagmi (hook Ethereum per React/Vue/Solid).
