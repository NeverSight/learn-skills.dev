TanStack Query を使用したフックライブラリ構築のベストプラクティス。使用シーン: (1) async データ取得関数をラップする useQuery / useMutation フックを書くとき、(2) クエリキー スキーマとキャッシュ識別システムを設計するとき、(3) フレームワーク非依存のクエリオプションファクトリを構築するとき、(4) キャッシュ無効化パターンを実装するとき（invalidate vs remove vs setQueryData）、(5) TanStack Query を多層ライブラリでラップするとき（コアアクション → クエリオプション → フレームワークフック）、(6) クエリキーにおける非シリアライズ可能な値（bigint、クラスインスタンス）を扱うとき、(7) 外部ストア（zustand、signals）と TanStack Query のリアクティビティを橋渡しするとき。wagmi のプロダクションアーキテクチャ（React/Vue/Solid Ethereum フック）に由来。
