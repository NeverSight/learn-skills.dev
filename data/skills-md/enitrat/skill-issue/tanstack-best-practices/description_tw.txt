使用 TanStack Query 構建 hook 函式庫的最佳實踐。適用情境包括：(1) 編寫包裝非同步資料抓取函式的 useQuery / useMutation hook，(2) 設計 query key 架構與快取識別系統，(3) 建構與框架無關的 query options 工廠，(4) 實作快取失效模式（invalidate、remove、setQueryData 的差異），(5) 在多層級函式庫中封裝 TanStack Query（從核心 actions 到 query options 再到框架 hook），(6) 在 query key 中處理不可序列化的值（bigint、類別實例），(7) 將外部 store（zustand、signals）與 TanStack Query 的反應式結合。內容取材自 wagmi 的投入使用架構（React / Vue / Solid 以太坊 hooks）。
