Utiliser comme portail de qualité UI/UX pour le travail frontal qui affecte matériellement les surfaces des produits Web : conception/construction/refonte/révision/polissage/refactorisation de pages ou de systèmes de composants, captures d'écran/critiques UX, sauvetage d'interface utilisateur d'apparence GPT/Codex, choix de pile ou de fondation d'interface utilisateur, modèles shadcn/Tailwind/table/formulaire, chargement/vide/erreur/mobile/états d'accessibilité ou installation de documents de gouvernance frontend tels que DESIGN.md, FRONTEND_CONTRACT.md, PAGE_BRIEF.md et normes visuelles d'assurance qualité. Déclenchez légèrement pour de petits ajustements sensibles à l’interface utilisateur à l’aide de la petite porte de changement. Coordonner avec les compétences de mise en œuvre visuelle lorsqu'on lui demande de créer une interface soignée ; cette compétence fournit la cognition du produit, le jugement UX, les garde-fous et la vérification. Ignorez les modifications pures du backend/API/données/modèle, les tests sans surface d'interface utilisateur, les renommages mécaniques, les tâches de dépendance ou les modifications qui n'affectent pas la mise en page, l'interaction, la copie, le comportement visuel, l'accessibilité ou les règles frontales.
