Lösen Sie leicht aus, um kleine UI-empfindliche Änderungen mithilfe des Tiny-Change-Gate vorzunehmen. Koordinieren Sie die Fähigkeiten zur visuellen Umsetzung, wenn Sie aufgefordert werden, eine ausgefeilte Benutzeroberfläche zu erstellen. Diese Fähigkeit bietet Produkterkennung, UX-Beurteilung, Leitplanken und Verifizierung. Überspringen Sie reine Backend-/API-/Daten-/Modelländerungen, Tests ohne UI-Oberfläche, mechanische Umbenennungen, Abhängigkeitsaufgaben oder Bearbeitungen, die sich nicht auf Layout, Interaktion, Kopie, visuelles Verhalten, Zugänglichkeit oder Frontend-Regeln auswirken.
