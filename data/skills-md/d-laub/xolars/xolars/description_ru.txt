Используйте, когда пишете или изменяете код Python, импортирующий `xolars` — сочетая Dataset из xarray с Polars‑фреймами по измерениям, создавая контейнер `Xolars`, выбирая данные с помощью isel/sel или выполняя циклы zarr+parquet через write/open. Пропускайте для обычных задач с xarray или Polars, которые не затрагивают класс `Xolars`.
