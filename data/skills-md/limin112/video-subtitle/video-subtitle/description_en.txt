The complete workflow for adding subtitles to any video—use whisper.cpp for local speech recognition (with per‑sentence real timestamps) → Claude reads through and corrects recognition errors (homophones/proper nouns) → generate an SRT file → use ffmpeg with libass to burn hard subtitles into the video. It also supports automatically translating pure English or foreign‑language videos and adding bilingual subtitles (“foreign original text + Chinese”) with Claude translating sentence by sentence. Font size, font, black‑background white‑text, and bilingual style are all customizable and can be reused for different videos.
