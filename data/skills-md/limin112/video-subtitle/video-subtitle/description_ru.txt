Полный рабочий процесс добавления субтитров к любому видео — использовать whisper.cpp для локального распознавания аудио (с реальными тайм‑стампами для каждого предложения) → Claude просматривает и исправляет ошибки распознавания (омофоны/имена собственные) → генерировать файл SRT → использовать ffmpeg с libass для встраивания жёстких субтитров в видео. Также поддерживается автоматический перевод видео полностью на английском/иностранном языке и добавление двуязычных субтитров, отображающих «оригинал на иностранном языке + китайский» (Claude переводит предложение за предложением). Размер шрифта, тип шрифта, черный фон с белым текстом и стили двуязычных субтитров настраиваются и могут быть использованы повторно для разных видео. Это используется, когда пользователи хотят «добавить субтитры к видео», «распознать аудио видео для создания субтитров», «конвертировать видео в субтитры», «китайско‑английские двуязычные субтитры / двуязычные субтитры», «английское видео с китайскими субтитрами», «вставка субтитров / жёсткие субтитры / встроенные субтитры», «извлечь субтитры», «вставить субтитры», «двуязычные субтитры» или «видео‑субтитры».
