透過 `orca` CLI 操作 Orca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、產物、技能分享、工作樹註解，以及 Orca 內嵌的瀏覽器。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時，請使用此方式。相較於直接使用 git worktree、臨時 PTY 或 Computer Use，若牽涉到 Orca 狀態，請優先使用 `orca` CLI。只有在需要控制可見視窗的 GUI、而 CLI、檔案系統或 API 無法完成時，才使用 Computer Use。
