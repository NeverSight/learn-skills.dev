Creación de una página web sencilla con un solo clic y publicación en el Salón de Exposiciones de Huawei Cloud Developer Works (CodeArts ACP genera la página → túnel de desarrollo → repositorio GitCode → portada/introducción/detalles → enviar actividad en curso). Se utiliza cuando los usuarios hacen referencia al Salón de Exposiciones de Huawei Cloud Developer Works, publican obras en Huawei Cloud, envían a la galería, presentan actividades de desafío, generan páginas web con CodeArts ACP y las ponen en línea, o publican páginas de demostración en el salón de exposiciones de Huawei Cloud. Todo el proceso se ejecuta automáticamente, requiriendo que el usuario abra un enlace del navegador solo una vez durante la autorización OAuth de GitCode. Disparadores: Salón de Exposiciones de Huawei Cloud Works, publicación de obras en Huawei Cloud, publicación en galería, actividad de desafío, página web CodeArts, hcloud STS, publicación en GitCode.
