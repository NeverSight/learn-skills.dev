Erstelle mit einem Klick eine einfache Webseite und veröffentliche sie im Huawei Cloud Developer Works Ausstellungshalle (CodeArts ACP erzeugt die Seite → Entwicklungstunnel → GitCode‑Repository → Cover/Einleitung/Details → laufende Aktivität einreichen). Wird verwendet, wenn Nutzer sich auf die Huawei Cloud Developer Works Ausstellungshalle beziehen, Arbeiten auf Huawei Cloud veröffentlichen, Galerieneinreichungen, Challenge‑Aktivitätseinreichungen, Webseiten mit CodeArts ACP generieren und auflisten oder Demo‑Seiten in der Huawei Cloud Ausstellungshalle veröffentlichen. Der gesamte Prozess läuft automatisch ab, und der Nutzer muss nur einmal einen Browser‑Link für die GitCode‑OAuth‑Autorisation öffnen. Auslöser: Huawei Cloud Works Ausstellungshalle, Huawei Cloud Veröffentlichungen, Galerie‑Veröffentlichungen, Challenge‑Aktivität, CodeArts‑Webseite, hcloud STS, GitCode‑Veröffentlichung.
