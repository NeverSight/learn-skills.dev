Создайте простую веб‑страницу в один клик и опубликуйте её в выставочном зале Huawei Cloud Developer Works (CodeArts ACP → генерация страницы → туннель разработки → репозиторий GitCode → обложка/введение/подробности → отправка в текущую активность). Предназначено для пользователей при упоминании выставочного зала Huawei Cloud Developer Works, публикации работ в Huawei Cloud, подачи галерейных заявок, участия в конкурсных активностях, генерации веб‑страниц с помощью CodeArts ACP и их размещения онлайн, либо публикации демонстрационных страниц в шоу‑руме Huawei Cloud. Весь процесс выполняется автоматически; только во время OAuth‑авторизации GitCode пользователю необходимо один раз открыть ссылку в браузере. Триггеры: выставочный зал Huawei Cloud Works, публикация работ в Huawei Cloud, публикация в галерее, конкурсная активность, веб‑страница CodeArts, hcloud STS, публикация в GitCode.
