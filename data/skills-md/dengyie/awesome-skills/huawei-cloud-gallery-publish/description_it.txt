Creare una semplice pagina web con un clic e pubblicarla nella Hall delle Esposizioni di Huawei Cloud Developer Works (CodeArts ACP genera pagina → tunnel di sviluppo → repository GitCode → copertina/introduzione/dettagli → invio attività in corso). Utilizzato quando gli utenti menzionano la Hall delle Esposizioni di Huawei Cloud Developer Works, pubblicano opere su Huawei Cloud, inviano gallerie, partecipano a sfide, generano pagine web con CodeArts ACP e le mettono online, o pubblicano una pagina demo nella Hall delle Esposizioni di Huawei Cloud. Completamente automatizzato, richiedendo all'utente di aprire il link del browser una sola volta durante l'autorizzazione OAuth di GitCode. Attivatori: Hall delle Esposizioni di Huawei Cloud Works, pubblicazione di opere su Huawei Cloud, pubblicazione in galleria, attività di sfida, pagina web CodeArts, hcloud STS, pubblicazione su GitCode.
