ワンクリックで簡単なウェブページを作成し、Huawei Cloud デベロッパーショーケースに公開します（CodeArts ACP がページを生成 → 開発トンネル → GitCode リポジトリ → カバー／サマリー／詳細 → 進行中のアクティビティへ提出）。ユーザーが Huawei Cloud デベロッパーショーケースを参照する際、Huawei Cloud に作品を公開する際、ギャラリーへの応募、チャレンジ活動への応募、CodeArts ACP でウェブページを生成して一覧に掲載する際、またはデモページを Huawei Cloud 展示ホールに公開する際に使用します。全プロセスは自動で実行され、ユーザーは GitCode の OAuth 認証のためにブラウザリンクを一度だけ開くだけで済みます。トリガー: Huawei Cloud ショーケース、Huawei Cloud 作品公開、ギャラリー公開、チャレンジ活動、CodeArts ウェブページ、hcloud STS、GitCode 公開。
