Création d’une page web simple en un clic et publication dans le Hall d’exposition des travaux Huawei Cloud Developer Works (CodeArts ACP génère la page → tunnel de développement → dépôt GitCode → couverture/présentation/détails → soumission à l’activité en cours). Utilisé lorsque les utilisateurs évoquent le Hall d’exposition des travaux Huawei Cloud Developer Works, la publication d’œuvres sur Huawei Cloud, les soumissions à la galerie, les soumissions aux activités de défi, la génération de pages web par CodeArts ACP et leur inscription, la publication de pages de démonstration dans le hall d’exposition de Huawei Cloud. L’ensemble du processus est entièrement automatisé, ne nécessitant que l’ouverture d’un lien de navigateur une seule fois lors de l’autorisation OAuth de GitCode. Déclencheurs : Hall d’exposition des travaux Huawei Cloud, publication d’œuvres sur Huawei Cloud, publication de galerie, activité de défi, page web CodeArts, hcloud STS, publication GitCode.
