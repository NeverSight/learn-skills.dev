Beginnen Sie hier, wenn eine Sicherheitsanfrage vage ist und noch keine spezifische Fähigkeit passt. Stellen Sie zwei oder drei Fragen zu dem, was Sie haben (Quellcode, eine Live‑Website, ein Cloud‑Setup, Protokolle, eine verdächtige Datei, eine Anforderung eines Auditors) und zu dem, was gerade passiert (Entwicklung, Auslieferung, ein aktueller Vorfall, eine Compliance‑Frist), und leiten Sie dann in der richtigen Reihenfolge an die passende(n) Fähigkeit(en) aus diesem Katalog weiter. Es führt selbst keine Audits durch. Verwenden Sie es, wenn der Nutzer Dinge sagt wie „mach das sicher“, „ist das sicher“, „wo fange ich mit Sicherheit an“, „welche Sicherheitsfähigkeit soll ich nutzen“, „Sicherheitscheck“, „was überprüfen wir“, „sichere mein Startup“ oder „hilf mir mit Sicherheit“, ohne ein Framework, ein Ziel oder ein Tool zu nennen. Wenn die Anfrage bereits ein genanntes Element enthält (OWASP, ein CVE, eine Workflow‑Datei, SOC 2, eine Phishing‑E‑Mail, ein eingefügtes Ergebnis), verwenden Sie stattdessen direkt diese Fähigkeit. Bitte antworten Sie immer in der Sprache des Benutzers.
