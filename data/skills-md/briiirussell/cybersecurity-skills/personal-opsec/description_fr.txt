Auditez la configuration de sécurité d’une personne — le fondateur ou l’opérateur qui détient les clés du système — et produisez un rapport de lacunes priorisé. Parcourez la checklist de sécurité numérique à 15 contrôles de Karpathy, ajoutez les vérifications de récupération de compte, de swap SIM, de registre et de clé matérielle, et couvrez l’ère des agents IA : les tokens que vos agents de codage peuvent lire, la confiance du serveur MCP, l’injection d’invite dans l’assistant de boîte de réception, l’exposition du presse‑papiers. Utilisez‑le lorsque l’utilisateur mentionne « opsec personnel », « audit de sécurité personnel », « sécuriser mes propres comptes », « sécurité du fondateur », « checklist de sécurité de Karpathy », « suis‑je sécurisé », « clé matérielle », « YubiKey », « swap SIM », « code PIN de port‑out », « FileVault », « BitLocker », « gestionnaire de mots de passe », « codes de récupération », « verrou du registre », « ce que mon agent IA peut voir », « clés API sur mon ordinateur portable », « confiance MCP », ou souhaite renforcer ses propres comptes et son appareil.
