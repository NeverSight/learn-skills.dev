Répondez à une vague de CVE sur l’ensemble d’un portefeuille d’applications en une seule fois : inventoriez chaque dépôt ainsi que le projet et le domaine de la plateforme qu’il sert réellement, trouvez la vraie branche de production, repérez les déploiements manuels obsolètes, déterminez quelles applications sont concernées, mitigez, appliquez les correctifs, déployez et confirmez la mise en production. Utilisez‑le lorsque l’utilisateur mentionne « patch sweep », « patch all my apps », « fleet-wide CVE », « are any of my apps affected », « Next.js RCE across all projects », « Rails CVE on all our Heroku apps », « patch every repo », « CVE wave », « security release across the fleet », « which of our sites run the vulnerable version », « mass dependency update », ou lorsqu’il possède plus d’une poignée d’applications à corriger contre les mêmes avis de sécurité.
