SOC 2、ISO/IEC 27001:2022、NIST SP 800‑53 Rev.5 / FedRAMP のコントロールレベルの監査準備。監査のスコープを設定（基準またはベースライン、対象システム、期間、Type 1 と Type 2 の区別）し、コントロールインベントリを構築、各コントロールごとに証拠要求を作成（成果物、所有者、サンプル、テスト方法）、リポジトリや設定が示す内容をテスト（CC8.1 / A.8.32 / ブランチ保護による CM‑3 変更管理）し、技術的チェックは所有部門に委譲、コントロールマトリックスを用いた共有成果形式でコントロールギャップを記録する。ユーザーが「SOC 2」「SOC 2 Type 2」「Trust Services Criteria」「ISO 27001」「ISMS」「Statement of Applicability」「Annex A controls」「NIST 800‑53」「FedRAMP」「FedRAMP 20x」「SSP」「POA&M」「control matrix」「evidence request list」「PBC list」「audit readiness」「control testing」などに言及したり、外部監査人や査定者に備えている場合に使用する。
