اكتب وشغّل أداة فحص عشوائي، وحواجز الفحص العشوائي، واختبارات قائمة على الخصائص للكود الذي يتعامل مع البايتات غير الموثوقة (محللات الملفات والحزم بلغة C أو C++ أو Rust أو Go أو Python أو JS، والمُفكّك، والمُسلسل، والمُسلسل العكسي، وتحليل الرموز والرؤوس، وآلات حالة البروتوكول)، ثم قم بتقليل الأخطاء، وإزالة التكرار، وتصنيف التعطلات إلى نتائج مؤكدة مع اختبارات تراجع. يغطي libFuzzer وcargo‑fuzz والفحص العشوائي الأصلي في Go وAtheris وJazzer.js وJazzer وHypothesis وfast‑check وproptest ومجموعات البذور والقواميس وبنايات المساند، والفحص العشوائي في بيئة التكامل المستمر باستخدام ClusterFuzzLite أو OSS‑Fuzz. استخدمه عندما يذكر المستخدم “fuzzing”، “fuzz harness”، “fuzz target”، “libFuzzer”، “cargo fuzz”، “go test -fuzz”، “Atheris”، “Jazzer”، “الاختبار القائم على الخصائص”، “اختبار خاصية Hypothesis”، “fast‑check”، “proptest”، “seed corpus”، “قائمة فحص عشوائي”، “تقرير AddressSanitizer”، “ملفات تعطل الفاحص”، “تقليل مدخل التعطل”، “ClusterFuzzLite”، “OSS‑Fuzz”، أو يرغب في فحص محلّله.
