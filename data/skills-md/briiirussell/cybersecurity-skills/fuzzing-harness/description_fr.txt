Écrivez et exécutez un fuzzer, des harness de fuzzing et des tests basés sur les propriétés pour le code qui traite des octets non fiables (analyseurs de fichiers et de paquets en C, C++, Rust, Go, Python ou JS, décodeurs, sérialiseurs, désérialiseurs, analyse de tokens et d’en‑têtes, machines d’état de protocole), puis minimisez, dédupliquez et triez les plantages en découvertes vérifiées avec des tests de régression. Couvre libFuzzer, cargo‑fuzz, le fuzzing natif Go, Atheris, Jazzer.js et Jazzer, Hypothesis, fast‑check et proptest, les corpus de graines et les dictionnaires, les builds de sanitizer, et le fuzzing CI avec ClusterFuzzLite ou OSS‑Fuzz. Utilisez‑le lorsque l’utilisateur mentionne « fuzzing », « harness de fuzz », « cible de fuzz », « libFuzzer », « cargo fuzz », « go test -fuzz », « Atheris », « Jazzer », « test basé sur les propriétés », « test de propriété Hypothesis », « fast‑check », « proptest », « corpus de graines », « dictionnaire de fuzzing », « rapport AddressSanitizer », « fichiers de plantage du fuzzer », « minimiser une entrée de plantage », « ClusterFuzzLite », « OSS‑Fuzz », ou souhaite fuzzifier son analyseur.
