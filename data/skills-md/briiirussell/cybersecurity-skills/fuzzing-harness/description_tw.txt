為處理不可信位元組的程式碼（如 C、C++、Rust、Go、Python 或 JS 中的檔案與封包解析器、解碼器、序列化器、反序列化器、令牌與標頭解析、協議狀態機）撰寫並執行 fuzz 測試程式、fuzz harness 與基於屬性的測試，然後將崩潰最小化、去除重複並分類為可驗證的發現，並附帶回歸測試。涵蓋 libFuzzer、cargo‑fuzz、Go 原生 fuzz、Atheris、Jazzer.js 與 Jazzer、Hypothesis、fast‑check 與 proptest、種子語料庫與字典、sanitizer 構建，以及使用 ClusterFuzzLite 或 OSS‑Fuzz 的 CI fuzz。當使用者提及「fuzzing」「fuzz harness」「fuzz target」「libFuzzer」「cargo fuzz」「go test -fuzz」「Atheris」「Jazzer」「property‑based testing」「Hypothesis property test」「fast‑check」「proptest」「seed corpus」「fuzzing dictionary」「AddressSanitizer report」「fuzzer crash files」「minimize a crash input」「ClusterFuzzLite」「OSS‑Fuzz」或想要 fuzz 他們的解析器時使用。
