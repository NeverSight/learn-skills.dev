Проверяйте исходный код на C, C++ и Rust на наличие ошибок безопасного обращения с памятью: чтения и записи за границами, переполнение или усечение целых чисел, приводящее к размеру, использование после освобождения и двойное освобождение, уязвимости формата строк, неинициализированную память, корректность небезопасного кода Rust, границы FFI, парсеры недоверенного ввода и оставшиеся в памяти секреты. Также проверяйте флаги усиления компилятора и рекомендуйте санитайзеры, формируйте отчёты в формате shared findings.json. Применяйте, когда пользователь упоминает «native code review», «C code review», «C++ security review», «memory safety review», «buffer overflow», «use-after-free», «double free», «format string bug», «integer overflow», «uninitialized memory», «unsafe Rust», «is this unsafe block sound», «FFI boundary», «Miri», «AddressSanitizer», «checksec», «FORTIFY_SOURCE», «hardening flags», «explicit_bzero» или «zeroize».
