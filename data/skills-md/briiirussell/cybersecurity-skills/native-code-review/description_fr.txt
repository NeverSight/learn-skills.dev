Examinez le code source C, C++ et Rust à la recherche de bugs de sécurité mémoire : lectures et écritures hors limites, débordement ou troncature d’entier qui alimente une taille, use‑after‑free et double libération, chaînes de format, mémoire non initialisée, sûreté du code unsafe Rust, frontières FFI, analyseurs d’entrées non fiables et secrets laissés en mémoire. Vérifie également les drapeaux de durcissement du compilateur et recommande des outils de débogage, puis rapporte les résultats au format partagé findings.json. Utilisez ceci lorsque l’utilisateur évoque « native code review », « C code review », « C++ security review », « memory safety review », « buffer overflow », « use-after-free », « double free », « format string bug », « integer overflow », « uninitialized memory », « unsafe Rust », « is this unsafe block sound », « FFI boundary », « Miri », « AddressSanitizer », « checksec », « FORTIFY_SOURCE », « hardening flags », « explicit_bzero » ou « zeroize ».
