Agents IA intégrés Base44 : configurations d'agents JSON sous base44/agents/ avec outils d'entité, de fonction backend ou de route serveur, canaux WhatsApp et Telegram, le SDK des agents pour les interfaces de conversation, et agents de code (une boucle d'agent que l'application exécute sur la passerelle IA). Utilisez-les lorsque l'application a besoin d'un assistant conversationnel ou d'une IA programmable.
