وكلاء الذكاء الاصطناعي داخل التطبيق Base44: تكوينات الوكلاء بصيغة JSON تحت المجلد base44/agents/ مع أدوات الكيان أو وظائف الخلفية أو مسارات الخادم، قنوات WhatsApp وTelegram، مجموعة تطوير الوكلاء (SDK) لواجهات المحادثة، ووكلاء الشيفرة (حلقة وكيل يديرها التطبيق عبر بوابة الذكاء الاصطناعي). يُستخدم عندما يحتاج التطبيق إلى مساعد محادثة أو ذكاء اصطناعي قابل للبرمجة.
