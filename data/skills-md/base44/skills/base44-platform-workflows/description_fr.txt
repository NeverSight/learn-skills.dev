Flux de travail Base44 : processus automatisés déclenchés par des triggers, définis comme des fichiers CNCF Serverless Workflow sous base44/workflows/ (triggers planifiés, entité, connecteur, agent intégré, authentification, publication et paiement ; étapes d’appel, d’attente et de commutation ; expressions jq), avec le guide complet d’authoring, ainsi que le pipeline d’automatisations legacy pour les applications antérieures aux workflows. À utiliser pour tout « quand X se produit, faire Y » ou « toutes les N heures, faire Y ».
