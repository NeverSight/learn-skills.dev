Integrazioni integrate di Base44 nel client SDK: InvokeLLM, SendEmail, caricamento di file (pubblici e privati), URL firmati, estrazione dati e generazione di immagini, con lo schema di input di ogni endpoint Core, oltre al tracciamento degli eventi di analytics. Da utilizzare quando una funzionalità richiede IA, email, file o analytics senza un servizio di terze parti.
