Code côté serveur Base44 : fonctions backend (gestionnaires HTTP dans base44/functions/<name>/entry.ts sur Cloudflare Workers) pour les applications SPA Vite, ou fonctions serveur et routes serveur TanStack Start. Secrets, SDK Base44 sur le serveur, authentification et rôle de service, webhooks, gestionnaires réservés aux administrateurs, invocation depuis le frontend, tests et table de modèles InvokeLLM. À utiliser lorsque l’application a besoin d’API externes, d’une logique privilégiée ou de travaux planifiés.
