كود الخادم لBase44: وظائف الخلفية (معالجات HTTP في base44/functions/<name>/entry.ts على Cloudflare Workers) لتطبيقات Vite SPA، أو وظائف خادم TanStack Start ومسارات الخادم. الأسرار، Base44 SDK على الخادم، المصادقة ودور الخدمة، webhooks، معالجات خاصة بالمسؤول فقط، استدعاء الواجهة الأمامية، الاختبار، وجدول نموذج InvokeLLM. يُستخدم عندما يحتاج التطبيق إلى واجهات برمجة تطبيقات خارجية أو منطق متميز أو عمل مجدول.
