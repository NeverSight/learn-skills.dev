Gestion d'un espace de travail Cargo complet en tant que code — déclarer les connecteurs, modèles, scénarios, outils, agents, serveurs MCP, segments, contexte, dossiers, fichiers, workers et applications en TypeScript, puis les réconcilier avec `cargo-ai project` (init → types → plan → deploy), de la même façon que vous utilisez Pulumi ou l'AWS CDK. Déclencheurs : « as code », « in git », « version-controlled », « reproducible », « Terraform for Cargo », « set up a whole workspace », « staging and production », « deploy the workspace from CI », « review this in a PR », « cargo.state.json », « scaffold from a template », « is there a cookbook for this », « start from a cookbook ». Les compétences avec un exemple CDK (construction TAM, scoring de compte, sourcing de contacts, routage, IA SDR, cockpit rep) résident dans gtm‑skills ; menu dans references/cookbooks.md. Ignorer lorsque : il s'agit d'une opération ponctuelle, d'une lecture ou d'une requête ad‑hoc — utilisez la compétence de capacité correspondante.
