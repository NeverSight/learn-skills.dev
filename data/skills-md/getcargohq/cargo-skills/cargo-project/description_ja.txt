Cargo ワークスペース全体をコードとして管理します — コネクタ、モデル、プレイ、ツール、エージェント、MCP サーバー、セグメント、コンテキスト、フォルダー、ファイル、ワーカー、アプリを TypeScript で宣言し、`cargo-ai project`（init → types → plan → deploy）で調整します。Pulumi や AWS CDK を実行する方法と同様です。

トリガー: 「as code」「in git」「version-controlled」「reproducible」「Terraform for Cargo」「set up a whole workspace」「staging and production」「deploy the workspace from CI」「review this in a PR」「cargo.state.json」「scaffold from a template」「is there a cookbook for this」「start from a cookbook」。

CDK の例（TAM ビルディング、アカウントスコアリング、コンタクトソーシング、ルーティング、AI SDR、レップコックピット）を含むスキルは gtm-skills にあります。メニューは references/cookbooks.md にあります。

スキップすべきケース: 一度きりの操作、読み取り、またはアドホックなクエリの場合 — 該当する機能スキルを使用してください。
