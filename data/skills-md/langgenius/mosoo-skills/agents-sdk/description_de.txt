Erstellen Sie KI-Agenten auf Cloudflare Workers mithilfe des Agents SDK. Laden Sie es, wenn Sie zustandsbehaftete Agenten, dauerhafte Workflows, Echtzeit-WebSocket-Apps, geplante Aufgaben, MCP-Server, Chat-Anwendungen, Sprachagenten oder Browserautomatisierung erstellen. Umfasst die Agent-Klasse, das Zustandsmanagement, aufrufbare RPCs, Workflows, dauerhafte Ausführung, Warteschlangen, Wiederholungsversuche, Beobachtbarkeit und React-Hooks. Bevorzugt das Abrufen von Informationen aus Cloudflare-Dokumenten gegenüber vorab erlerntem Wissen.
