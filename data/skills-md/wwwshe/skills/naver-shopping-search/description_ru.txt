Навык поиска Naver Shopping. Поиск использует API с параметром sort=sim (или date, если требуется новейшее); для сортировки по цене агент сортирует полученный список без указания asc/dsc. Поддерживает фильтры и постобработку, например «Только Naver Pay». Пожалуйста, всегда отвечайте на языке пользователя.
