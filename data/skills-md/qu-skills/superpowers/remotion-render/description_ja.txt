React/Remotion コンポーネントコードから inference.sh を通じてビデオをレンダリングします。TSX コードを渡して、MP4 を取得します。すべての Remotion API に対応しています：useCurrentFrame、useVideoConfig、spring、interpolate、AbsoluteFill、Sequence。解像度、FPS、長さ、コーデックは設定可能です。利用例：プログラムによる動画生成、アニメーション画像、モーションデザイン、データ駆動型動画、React アニメーションを動画に変換すること。トリガー：remotion、コードからビデオをレンダリング、tsx からビデオ、react ビデオ、プログラム的ビデオ、remotion レンダー、コードからビデオ、アニメーションビデオ、モーショングラフィックコード、react アニメーションビデオ
