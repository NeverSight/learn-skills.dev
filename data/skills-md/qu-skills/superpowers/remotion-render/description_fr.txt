Rendre des vidéos à partir du code de composants React/Remotion via inference.sh. Fournissez du code TSX, obtenez un MP4. Prise en charge de toutes les API Remotion : useCurrentFrame, useVideoConfig, spring, interpolate, AbsoluteFill, Sequence. Résolution, FPS, durée et codec configurables. Utilisation pour : génération vidéo programmatique, graphiques animés, conception motion, vidéos basées sur les données, animations React en vidéo. Déclencheurs : remotion, rendu vidéo à partir du code, tsx en vidéo, vidéo react, vidéo programmatique, rendu remotion, code en vidéo, vidéo animée, code de graphismes animés, vidéo d’animation react.
