Exécutez du code Python dans un environnement sandbox sécurisé via [inference.sh](https://inference.sh). Préinstallés : NumPy, Pandas, Matplotlib, requests, BeautifulSoup, Selenium, Playwright, MoviePy, Pillow, OpenCV, trimesh et plus de 100 bibliothèques. Utilisez‑le pour : le traitement de données, le web‑scraping, la manipulation d’images, la création de vidéos, le traitement de modèles 3D, la génération de PDF, les appels d’API, les scripts d’automatisation. Déclencheurs : python, exécuter du code, lancer un script, web‑scraping, analyse de données, traitement d’images, montage vidéo, modèles 3D, automatisation, pandas, matplotlib.
