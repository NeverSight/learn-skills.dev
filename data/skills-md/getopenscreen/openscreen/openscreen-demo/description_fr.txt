Créez une vidéo soignée d’une application ou d’une fonctionnalité avec les outils MCP d’OpenScreen, depuis le storyboard jusqu’à l’enregistrement, le montage et l’exportation, puis joignez‑la à une pull request ou rédigez un post sur X. Utilisez‑le lorsque l’utilisateur demande une démo, une vidéo de démo, un enregistrement d’écran, une vidéo produit, un clip de lancement, une vidéo pour X/Twitter, LinkedIn ou un README, ou pour montrer une modification dans une pull request (« ajouter une vidéo à la PR », « montrer la fonctionnalité aux reviewers »). Utilisez‑le également pour configurer OpenScreen pour un agent, et pour poursuivre une démonstration d’OpenScreen dans une nouvelle session. Veuillez toujours répondre dans la langue de l'utilisateur.
