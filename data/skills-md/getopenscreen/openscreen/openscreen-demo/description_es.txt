Haz un video pulido de una app o una característica con las herramientas MCP de OpenScreen, desde el guion gráfico hasta la grabación, edición y exportación, y luego adjúntalo a una pull request o redacta una publicación en X. Utilízalo cuando el usuario solicite una demo, un video de demo, una grabación de pantalla, un video de producto, un clip de lanzamiento, un video para X/Twitter, LinkedIn o un README, o para mostrar un cambio en una pull request («añadir un video al PR», «mostrar la característica a los revisores»). También úsalo para configurar OpenScreen para un agente y para continuar una demo de OpenScreen en una nueva sesión.
