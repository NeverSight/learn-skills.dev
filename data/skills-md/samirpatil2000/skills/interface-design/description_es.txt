Construye interfaces de usuario elaboradas e intencionadas para tableros, paneles de administración, aplicaciones SaaS, herramientas, páginas de configuración e interfaces de datos. Úsala al desarrollar un producto interactivo — NO páginas de marketing, páginas de destino o campañas (redirige esas a frontend-design). Se activa en: tablero, panel de administración, UI de la aplicación, página de configuración, tabla de datos, interfaz SaaS, UI de herramienta, navegación lateral, vista de métricas.
