Используйте разработку через тестирование для функций, изменяющих поведение или исправлений, а также всякий раз, когда пользователь упоминает TDD, «сначала тестирование», «красно-зеленый рефакторинг», трассирующие маркеры, интеграционные тесты или тесты поведения общедоступного интерфейса. Пропускайте операции только для документов, переименования только пути, только форматирования или чисто механических операций, если это явно не требуется.
