Fournit les dernières recommandations pour créer ou modifier des applications LLM à l’aide des bibliothèques open source LangChain : Deep Agents, LangGraph et LangChain, y compris la manière dont les bibliothèques s’intègrent le mieux les unes aux autres. La pile évolue rapidement, il est donc important de vérifier ses connaissances préalables par rapport à ces recommandations. Aborde également les cas où Managed Deep Agents est adapté.
