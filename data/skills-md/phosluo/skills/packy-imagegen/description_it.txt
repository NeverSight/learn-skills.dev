Genera immagini raster con il punto finale immagine gpt-image-2.5-flare di PackyAPI e salva localmente file PNG o JPEG verificati. Utilizza quando l'agente deve creare un'immagine tramite PackyAPI, o quando gli utenti menzionano PackyAPI, gpt-image-2.5-flare, gpt-image-2.5-sunburst, gpt-image-2, un token image-group o l'API di disegno Packy.

Rispondi sempre nella lingua dell'utente.
