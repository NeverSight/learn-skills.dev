Сводный отчёт Suite — распределить задачи между стандартными аудиторами UX (юзабилити, доступность, пользовательские сценарии) для одной цели, с возможностью опционального включения веб‑производительности, нормализовать все результаты в общий контракт .ux/audits и сформировать единый комбинированный go/no‑go сводный отчёт. Использовать для «полного UX‑аудита», «аудит всего», «ux‑audit».
