إعداد جلسات مستقلة للقائد والعامل باستخدام مراسلات أصيلة عبر Codex أو Claude Code بين الجلسات، أو، عندما يختار المالك المشاركة، إرشادات وكيل herdr بحيث يمكن لأي مزيج من أنواع الوكلاء (Claude Code، Codex، Gemini، opencode، …) تشكيل فريق واحد. استخدم ذلك لبدء قائد يقتصر على التنسيق فقط، يعتمد على الإيصالات، يوضح هدف المالك، يخطط حزم العمل في دفتر الفريق ويقودها إلى الإغلاق؛ انضم يدويًا إلى عامل؛ فوض العمل؛ عالج إقرارات الانضمام/التكليف/المراجعة الأصيلة؛ أو قم بتصحيح رسائل الزملاء، بما في ذلك التواصل المباشر P2P بين العاملين والمراجعة المستقلة. يجب على القادة ألا يبرمجوا أبدًا، أو ينفذوا اختبارات، أو يقوموا بالمراجعة، أو يجريوا استبيانات، أو يستمعوا، أو يتولى عمل العامل. يتطلب أدوات جلسة أصيلة حقيقية أو وسيلة نقل herdr يختارها المالك، وليس صناديق البريد أو وكلاء فرعيين بديلين.
