ネイティブ Codex または Claude Code のクロスセッションメッセージングで、独立した Leader と Worker のセッションをブートストラップし、所有者がオプトインした場合は herdr エージェントプロンプトを使用して、Claude Code、Codex、Gemini、opencode など任意のエージェント種別の組み合わせで 1 つのチームを形成できるようにします。これを利用して、所有者の目標を明確化し、チーム元帳に作業パッケージを計画して完了まで導く、厳格な調整専用・受領駆動型 Leader を開始したり、Worker を手動で参加させたり、作業を委任したり、ネイティブな参加・割り当て・レビューの確認を処理したり、Peer メッセージ（直接の Worker‑to‑Worker P2P や独立レビューを含む）をデバッグしたりできます。Leader は決してコードを書いたり、テストを実行したり、レビューを行ったり、ポーリングしたり、リスニングしたり、Worker の作業を引き継いだりしてはなりません。実際のネイティブセッションツールまたは所有者が選択した herdr トランスポートが必要であり、ファイル受信箱や代替サブエージェントは使用できません。
