네이티브 Codex 또는 Claude Code 크로스 세션 메시징으로 독립적인 Leader와 Worker 세션을 부트스트랩하고, Owner가 동의할 경우 herdr 에이전트 프롬프트를 사용하여 Claude Code, Codex, Gemini, opencode 등 다양한 에이전트 유형이 하나의 팀을 구성할 수 있습니다. 이를 사용하여 순수 조정만을 수행하고 영수증 기반인 Leader를 시작할 수 있습니다. 이 Leader는 Owner의 목표를 명확히 하고, 팀 원장에 작업 패키지를 계획하여 완료까지 이끌며; Worker를 수동으로 합류시키고; 작업을 위임하고; 네이티브 join/assignment/review 확인을 처리하거나; 직접 Worker 간 P2P 및 독립 검토를 포함한 피어 메시지를 디버그합니다. Leader는 절대로 코딩을 하거나, 테스트를 실행하거나, 리뷰를 수행하거나, 폴링하거나, 청취하거나, Worker의 작업을 대신 수행해서는 안 됩니다. 실제 네이티브 세션 도구 또는 Owner가 선택한 herdr 전송 수단이 필요하며, 파일 인박스나 대체 서브에이전트를 사용할 수 없습니다.
