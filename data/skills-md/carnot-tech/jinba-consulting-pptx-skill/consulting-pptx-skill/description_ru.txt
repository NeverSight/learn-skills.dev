Навык для создания слайдов исполнительного уровня, соответствующих спецификациям дизайна слайдов в slide‑rules.md. Спецификации извлекаются пошагово только для нужных разделов с помощью scripts/rules.py, а набор собирается из компонентов (20 типов, перечисленных new_deck.py --list), которые проверены на соответствие этим спецификациям, завершаясь автоматическими проверками в check_deck.py и check_layout.mjs с результатом FAIL 0. При получении существующего файла PowerPoint и только когда запрашивается вставка страницы в PPTX, страница создаётся непосредственно на мастер‑слайде этого файла (slide‑rules §8.7). Примеры триггеров: «Создать слайд консалтингового уровня», «Использовать набор, соответствующий спецификациям», «Добавить страницу в этот pptx в том же формате».
