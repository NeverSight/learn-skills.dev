L'abilità di creare slide di qualità per riunioni esecutive si basa sulle specifiche di progettazione della slide contenute in slide‑rules.md. Per ogni fase, le sezioni necessarie delle specifiche vengono recuperate con scripts/rules.py, poi assemblate usando componenti verificati per soddisfare le specifiche (i 20 tipi elencati da new_deck.py --list). Il risultato viene finalizzato con controlli automatici tramite check_deck.py e check_layout.mjs, ottenendo un risultato FAIL 0. Quando viene fornito un file PowerPoint esistente e si richiede di inserire pagine in formato PPTX, le pagine vengono assemblate direttamente sul master di quel file (slide‑rules §8.7). Esempi di trigger: “Crea una slide di qualità consulenziale”, “Usa un deck che segue le specifiche”, “Aggiungi una pagina a questo pptx nello stesso formato.”
