slide‑design 가이드라인인 slide‑rules.md를 핵심으로 삼아, 이는 관리 회의 수준의 슬라이드를 만드는 기술입니다. 가이드라인은 각 단계에서 필요한 섹션만 scripts/rules.py 로 가져오고, 슬라이드는 new_deck.py --list에 나열된 20가지 타입의 구성 요소 중 가이드라인을 충족한 것들로 조합한 뒤, check_deck.py와 check_layout.mjs 의 머신 체크를 거쳐 FAIL 0을 달성합니다. 기존 PowerPoint 파일을 받아 PPTX에 삽입할 페이지를 요청받으면, 페이지는 해당 파일의 마스터 위에 직접 구축됩니다(slide‑rules §8.7). 트리거 예시: “컨설팅‑품질 슬라이드 만들기”, “가이드라인을 따르는 덱 사용”, “같은 형식으로 이 pptx에 페이지 추가”.
