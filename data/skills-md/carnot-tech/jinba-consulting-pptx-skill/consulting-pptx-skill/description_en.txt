With slide‑design specifications (slide‑rules.md) at its core, this is a skill for creating executive‑meeting‑quality slides. The specifications are pulled by scripts/rules.py for only the sections needed at each stage, assembled from components (the 20 types listed by new_deck.py --list) that have been verified to meet the specs, and finalized with machine checks (check_deck.py, check_layout.mjs) that produce a FAIL 0 result. When given an existing PowerPoint file and asked to insert pages as a PPTX, the pages are directly assembled onto the master of that file (slide‑rules §8.7) only in that case. Example triggers: “Create a consulting‑quality slide,” “Use a deck that follows the specifications,” “Add a page to this PPTX in the same format.”
