Una habilidad para crear diapositivas de calidad ejecutiva centradas en las directrices de diseño de diapositivas en slide‑rules.md. Las directrices se recuperan en cada etapa mediante scripts/rules.py solo para las secciones necesarias, y las diapositivas se ensamblan a partir de componentes (20 tipos enumerados por new_deck.py --list) que han sido verificados para cumplir con las directrices, para luego finalizarse con los controles automáticos check_deck.py y check_layout.mjs pasando con FAIL 0. Cuando se proporciona un archivo PowerPoint existente y se solicita insertar una página en PPTX, se ensambla directamente sobre el máster de ese archivo únicamente (slide‑rules §8.7). Disparadores de ejemplo: “Crear una diapositiva de calidad de consultoría”, “con una presentación que siga las directrices”, “añadir una página a este pptx en el mismo formato”.
