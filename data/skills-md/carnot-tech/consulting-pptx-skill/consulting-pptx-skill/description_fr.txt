La spécification de conception de diapositives slide‑rules.md (issue d’analyses pratiques, environ 80 éléments de canon) est le cœur, une compétence pour créer des diapositives de qualité pour les réunions de direction. Avant de créer, lisez la spécification, copiez les parties appropriées de la collection de parties HTML (basique 27 + additionnelles 35 = 62 types), assemblez‑les, ajustez‑les selon la spécification sans être limité par le modèle, et terminez avec le rapport de vérification machine de check_deck.py indiquant FAIL 0. Le catalogue de modèles est un carnet d’idées de mise en page, pas quelque chose à reproduire. Exemples de déclencheurs : « Créer une diapositive de qualité conseil », « Utiliser un deck qui suit la spécification », « Choisir dans le catalogue de modèles ».
