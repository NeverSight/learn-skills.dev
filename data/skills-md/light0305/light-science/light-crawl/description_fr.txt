Créez, déboguez et exploitez une acquisition de données Web/d'applications reproductible, y compris les transferts d'ensembles de données de recherche. À utiliser pour l'extraction répétée, la pagination, les sites rendus en JS ou bloqués, les API signées et les robots d'indexation vérifiables ou reprenables. Acheminez entre HTTP/API, Scrapling, inspection à l'exécution et analyse d'applications packagées selon les besoins des preuves ; les recherches ordinaires sur une seule page n'ont pas besoin d'un robot d'indexation.
