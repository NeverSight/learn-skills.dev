Cree, depure y gestione la adquisición reproducible de datos web/de aplicaciones, incluidas las transferencias de conjuntos de datos de investigación. Úselo para extracciones repetidas, paginación, sitios renderizados con JS o bloqueados, API firmadas y rastreadores verificables o reanudables. Enrute entre HTTP/API, Scrapling, inspección en tiempo de ejecución y análisis de aplicaciones empaquetadas según lo requieran las pruebas; las búsquedas ordinarias de una sola página no necesitan un rastreador.
