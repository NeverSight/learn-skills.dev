Préparer, réviser et vérifier les documents d'enregistrement des droits d'auteur des logiciels chinois à partir de logiciels réels : descriptions de fonctions, dépôts de code source traçables, manuels de logiciels, feuilles de calcul d'application facultatives et réponses de correction. Utiliser pour 软著、软件著作权申请材料、源程序鉴别材料、软著说明书、申请表填报辅助、 材料补正 et les mises à jour de version. Prend en charge les scripts de recherche, les outils CLI, les bibliothèques, les services, les applications de bureau et Web ; la documentation de code ordinaire et la rédaction de brevets n'ont pas besoin de cette compétence.
