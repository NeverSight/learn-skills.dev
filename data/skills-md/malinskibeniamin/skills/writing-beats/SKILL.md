---
name: writing-beats
description: Build article beat by beat from raw material with user-chosen pivots.
disable-model-invocation: true
---

Input is Markdown raw material. If output path missing, ask once.

1. Offer 2-3 starting beats; user picks.
2. Write only that beat.
3. Re-read article from disk.
4. Offer 2-3 next beats; repeat to natural end.

A beat is one journey move: scene, point, question, aside, twist. Split if it needs many sections.

Append one at a time; never write ahead. Re-read before writes to preserve edits. Leftovers are fine. Rewrite/go back/cut edits only the named beat.
