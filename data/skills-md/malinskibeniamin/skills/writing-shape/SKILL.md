Input pile is read-only; article is separate. If output path missing, ask once.

## Loop

1. Read pile fully.
2. Draft 2-3 openings with distinct thesis/angle; user picks/hybridizes.
3. Grow one paragraph/block at a time; ask what reader needs next.
4. Argue format: prose/list/callout/table/quote/code.
5. Append agreed block; re-read article before each write.
6. Continue until user says done.

Push back: what does this do for reader; what breaks if cut; did opening promise drift; split two-job sentences. Mine pile as quarry, not script. Missing evidence/example: name gap, ask, or cut.
