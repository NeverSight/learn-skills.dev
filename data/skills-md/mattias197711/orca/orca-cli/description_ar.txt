تشغيل شجرات العمل التي يديرها Orca، وسياقات المجلدات، والأطراف الطرفية، والمستودعات، والأتمتة، والملفات الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر أوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على شجرة git العادية، أو PTYs العشوائية، أو استخدام الكمبيوتر عندما تكون حالة Orca متضمنة. استخدم "Computer Use" فقط عندما تكون هناك حاجة للتحكم في واجهة رسومية في نافذة مرئية لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به.
