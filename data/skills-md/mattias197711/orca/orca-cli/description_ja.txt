`orca` CLI を使用して、Orca が管理するワークツリー、フォルダコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、および Orca の埋め込みブラウザを操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」「handover」「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関係する場合は、純粋な git worktree や臨時の PTY、Computer Use よりもこちらを優先してください。CLI、ファイルシステム、API では対処できない可視ウィンドウの GUI 操作が必要なときのみ、Computer Use を使用します。
