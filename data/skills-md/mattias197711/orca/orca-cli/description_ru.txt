Работайте с управляемыми Orca рабочими деревьями, контекстами папок, терминалами, репозиториями, автоматизацией, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Используйте, когда пользователь говорит "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" или "share skills". Предпочитайте его вместо чистого git worktree, произвольных PTY или Computer Use, когда задействовано состояние Orca. Используйте Computer Use только тогда, когда требуется управлять видимым окном GUI, что нельзя сделать через CLI, файловую систему или API.
