透過 `orca` CLI 操作由 Orca 管理的工作樹、資料夾情境、終端機、儲存庫、自動化、成果物、技能分享、工作樹註解，以及 Orca 內嵌的瀏覽器。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時，請使用此方式。當涉及 Orca 狀態時，請優先採用此方式，而非直接使用 git 工作樹、臨時 PTY 或電腦使用。僅在需要可見視窗之 GUI 控制，且 CLI、檔案系統或 API 無法完成時，才使用電腦使用。

請始終以使用者的語言回覆。
