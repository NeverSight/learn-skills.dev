Wird immer dann verwendet, wenn ein Agent eine GitHub-Pull-Anforderung erstellt, aktualisiert, überprüft oder vervollständigt. Erkennen Sie, ob Robin im Repository installiert ist. Wenn dies der Fall ist, führen Sie die PR automatisch durch eine begrenzte Überprüfung, verifizierte Korrektur, Antwort, Thread-Auflösung, erneute Überprüfung, autorisierte Zusammenführung und Bereinigungsschleife, ohne dass der Benutzer Robin erwähnen muss. Auch für explizite Robin-Anfragen, PR-Feedback-Triage, ungelöste Review-Threads oder Warten auf PR-Checks verwenden.
