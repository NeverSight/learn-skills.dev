Converti o assisti la conversione dei resource pack di Minecraft Java Edition in resource pack di Bedrock Edition per la versione 1.21.x. Utilizza per l’ispezione dei pack Java, scegliendo Thunder o Geyser PackConverter per pack semplici, JE2BE per pack orientati PBR o RTX, eseguendo l’assistente di conversione incluso, producendo output .mcpack, segnalando asset esclusivi di Java non supportati e pianificando correzioni manuali per Bedrock.
