Compétence de développement full‑stack de mods Minecraft pour NeoForge (1.21+) et Fabric (1.21+). Crée la structure de nouveaux mods, ajoute des blocs, objets, entités, recettes, commandes, interfaces graphiques, dimensions et génération de données personnalisés. Maîtrise le système NeoForge DeferredRegister + bus d’événements ainsi que le système Fabric Registry + ModInitializer. À utiliser lorsque l’utilisateur demande de créer un mod Minecraft, d’ajouter une fonctionnalité à un mod existant, de corriger un bug de mod, de générer des assets/données JSON ou de migrer entre les plateformes de modding. Privilégier NeoForge sauf si l’utilisateur spécifie Fabric ou Multiloader.

Veuillez toujours répondre dans la langue de l’utilisateur.
