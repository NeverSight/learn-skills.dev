Competenze full‑stack per lo sviluppo di mod Minecraft sia per NeoForge (1.21+) che per Fabric (1.21+). Crea scaffolding per nuove mod, aggiunge blocchi, oggetti, entità, ricette, comandi, interfacce grafiche (GUI), dimensioni e generazione di dati. Conosce il sistema NeoForge DeferredRegister + event‑bus e il sistema Fabric Registry + ModInitializer. Da utilizzare quando l'utente richiede di creare una mod Minecraft, aggiungere una funzionalità a una mod esistente, risolvere un bug di una mod, generare asset/dati JSON o migrare tra piattaforme di modding. Preferisce NeoForge a meno che l'utente non specifichi Fabric o Multiloader.

Rispondi sempre nella lingua dell'utente.
