NeoForge（1.21+）と Fabric（1.21+）の両方に対応したフルスタックのMinecraftモッド開発スキル。新しいモッドの土台を構築し、カスタムブロック、アイテム、エンティティ、レシピ、コマンド、GUI、ディメンション、およびデータ生成を追加。NeoForge の DeferredRegister と event‑bus システム、Fabric の Registry と ModInitializer システムを熟知。ユーザーがMinecraftモッドの作成、既存モッドへの機能追加、バグ修正、JSON アセット/データ生成、またはプラットフォーム間の移行を要求したときに使用する。ユーザーが Fabric またはマルチローダーを指定しない限り、NeoForge を優先する。
