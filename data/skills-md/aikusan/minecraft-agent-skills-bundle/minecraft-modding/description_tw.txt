同時具備 NeoForge（1.21+）與 Fabric（1.21+）的全端 Minecraft 模組開發技能。能快速搭建新模組，並添加自訂方塊、物品、實體、合成配方、指令、GUI、維度以及資料生成。熟悉 NeoForge 的 DeferredRegister + 事件總線系統以及 Fabric 的 Registry + ModInitializer 系統。當使用者要求製作 Minecraft 模組、為現有模組新增功能、修復模組錯誤、產生 JSON 資產/資料，或在不同模組平台間遷移時使用。除非使用者特別指定 Fabric 或 Multiloader，否則優先選擇 NeoForge。請始終以使用者的語言回覆。
