Faites fonctionner Minecraft Bedrock Dedicated Server pour 1.21.x. Utiliser pour la planification de l'installation et de la mise à jour BDS, la mise en réseau UDP, server.properties, allowlist.json, permissions.json, les dossiers mondiaux, le déploiement resource_packs et behavior_packs, la sauvegarde/restauration, la gestion des Docker ou des services, le triage des journaux et la réponse aux incidents. Choisissez cette option pour l'administration du serveur Bedrock plutôt que pour les opérations Java Paper/Purpur ou le développement de modules complémentaires Bedrock.
