Escribe pruebas automatizadas para mods y plugins de Minecraft para la versión 1.21.x. Incluye GameTests de NeoForge (@GameTest annotation, aserciones de GameTestHelper, organización de la estructura de pruebas), pruebas de juego de Fabric (fabric-gametest-api-v1), pruebas unitarias de lógica no relacionada con Minecraft usando JUnit 5, MockBukkit para pruebas de plugins Paper/Bukkit (servidor simulado, jugador simulado, despacho de eventos, verificación de inventarios), pruebas de integración con un servidor de pruebas mediante Gradle, y flujos de trabajo CI de GitHub Actions que ejecutan GameTests sin interfaz gráfica. Contiene patrones para simular registros, probar manejadores de eventos, probar comandos y desarrollo guiado por pruebas (TDD) para proyectos de Minecraft. Usa este contenido cuando el usuario pregunte sobre pruebas de mods o plugins de Minecraft, escritura de GameTests, configuración de MockBukkit o configuración de CI para proyectos de Minecraft.
