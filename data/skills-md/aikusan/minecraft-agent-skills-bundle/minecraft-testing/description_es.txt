Escribe pruebas automatizadas para mods y plugins de Minecraft para la versión 1.21.x. Cubre los GameTests de NeoForge (anotación @GameTest, aserciones de GameTestHelper, ubicación de la estructura de pruebas), pruebas de juego de Fabric (fabric‑gametest‑api‑v1), pruebas unitarias de lógica no relacionada con Minecraft con JUnit 5, MockBukkit para pruebas de plugins de Paper/Bukkit (servidor simulado, jugador simulado, despacho de eventos, verificación de inventario), pruebas de integración con un servidor de pruebas mediante Gradle y flujos de trabajo CI de GitHub Actions que ejecutan los GameTests sin cabeza. Incluye patrones para simular registros, probar manejadores de eventos, probar comandos y desarrollo guiado por pruebas para proyectos de Minecraft. Úsalo cuando el usuario pregunte sobre pruebas de mods o plugins de Minecraft, escritura de GameTests, configuración de MockBukkit o configuración de CI para proyectos de Minecraft.
