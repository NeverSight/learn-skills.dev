اكتب اختبارات آلية لتعديلات ماينكرافت والإضافات للنسخة 1.21.x. تشمل اختبارات NeoForge GameTests (ت anotasi @GameTest، تأكيدات GameTestHelper، موضع هيكل الاختبار)، اختبارات Fabric game (fabric-gametest-api-v1)، اختبار الوحدات للمنطق غير المتعلق بماينكرافت باستخدام JUnit 5، MockBukkit لاختبار إضافات Paper/Bukkit (خادم مزيّف، لاعب مزيّف، إرسال الأحداث، فحص الجرد)، اختبار التكامل مع خادم اختبار عبر Gradle، وسير عمل CI على GitHub Actions لتشغيل GameTests بدون واجهة مستخدم. تشمل الأنماط محاكاة السجلات، اختبار معالجات الأحداث، اختبار الأوامر، وتطوير مبني على الاختبار لمشاريع ماينكرافت. استخدم هذا المحتوى عندما يسأل المستخدم عن اختبار تعديلات ماينكرافت أو الإضافات، كتابة GameTests، إعداد MockBukkit، أو تكوين CI لمشاريع ماينكرافت.
