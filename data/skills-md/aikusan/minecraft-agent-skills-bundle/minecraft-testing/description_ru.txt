Пишите автоматические тесты для модов и плагинов Minecraft версии 1.21.x. Охватывает GameTests NeoForge (аннотация @GameTest, утверждения GameTestHelper, размещение структуры тестов), игровые тесты Fabric (fabric‑gametest‑api‑v1), модульное тестирование нелогики Minecraft с JUnit 5, MockBukkit для тестирования плагинов Paper/Bukkit (мок‑сервер, мок‑игрок, отправка событий, проверка инвентаря), интеграционное тестирование с тестовым сервером через Gradle и CI‑рабочие процессы GitHub Actions, запускающие GameTests в безголовом режиме. Включает шаблоны мокирования реестров, тестирования обработчиков событий, тестирования команд и разработку через тестирование (TDD) для проектов Minecraft. Используйте, когда пользователь спрашивает о тестировании модов или плагинов Minecraft, написании GameTests, настройке MockBukkit или конфигурации CI для Minecraft‑проектов.
