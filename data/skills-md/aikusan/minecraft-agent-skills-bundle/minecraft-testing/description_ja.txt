1.21.x 用の Minecraft mod とプラグインの自動テストを書きます。NeoForge の GameTests（@GameTest アノテーション、GameTestHelper アサーション、テスト構造の配置）や Fabric のゲームテスト（fabric‑gametest‑api‑v1）、JUnit 5 を使用した Minecraft 以外のロジックのユニットテスト、Paper/Bukkit プラグインのテストのための MockBukkit（モックサーバー、モックプレイヤー、イベントディスパッチ、インベントリチェック）、Gradle を介したテストサーバーでの統合テスト、そして GameTests をヘッドレスで実行する GitHub Actions CI ワークフローを網羅しています。レジストリのモック、イベントハンドラのテスト、コマンドのテスト、Minecraft プロジェクトのテスト駆動開発のパターンも含みます。ユーザーが Minecraft の mod やプラグインのテスト、GameTest の作成、MockBukkit の設定、または Minecraft プロジェクトの CI 設定について質問したときに使用してください。
