Écrire des tests automatisés pour les mods et plugins Minecraft pour la version 1.21.x. Couvre les GameTests NeoForge (annotation @GameTest, assertions GameTestHelper, placement de la structure de test), les tests de jeu Fabric (fabric‑gametest‑api‑v1), les tests unitaires de la logique non‑Minecraft avec JUnit 5, MockBukkit pour les tests de plugins Paper/Bukkit (serveur mock, joueur mock, dispatch d’événements, vérification d’inventaire), les tests d’intégration avec un serveur de test via Gradle, et les workflows CI GitHub Actions qui exécutent les GameTests en mode headless. Inclut des modèles pour moquer les registres, tester les gestionnaires d’événements, tester les commandes, et le développement dirigé par les tests pour les projets Minecraft. À utiliser lorsque l’utilisateur demande des informations sur les tests de mods ou plugins Minecraft, la rédaction de GameTests, la mise en place de MockBukkit ou la configuration de CI pour des projets Minecraft.
