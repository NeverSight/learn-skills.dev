استخدم عند بناء روبوتات واتساب أو وكلاء الذكاء الاصطناعي على واجهة Meta Cloud API — تحقق GET للويب هوك، التحقق من توقيع HMAC‑SHA256، تحليل حمولات الرسائل المتداخلة باستخدام Pydantic، إرسال رسائل نصية/قوالب/تفاعلية/وسائط، توجيه النوايا إلى الوكلاء المتخصصين، آلة حالة جلسة Redis (IDLE→GREETED→COLLECTING_INFO→RESOLVED)، توزيع غير متزامن عبر Kafka، وأكواد الأخطاء في الإنتاج (131030، 131047، 130429).
