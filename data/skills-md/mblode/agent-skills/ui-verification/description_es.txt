Ejecuta sondeos de navegador con alcance para foco, objetivos alcanzados, desbordamiento, temas, errores de solicitud y atribución de rendimiento, con evidencia vinculada a los ID de las reglas de la interfaz de usuario. Úselo cuando se le solicite "verificar esto en el navegador", "reproducir este hallazgo" o "verificar la solución". Para auditorías de origen y gravedad, utilice ui-design; las métricas de campo requieren RUM o CrUX.
