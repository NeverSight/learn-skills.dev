Exécute des sondes de navigateur étendues pour le focus, les cibles atteintes, le débordement, les thèmes, les échecs de requête et l'attribution des performances, avec des preuves liées aux ID de règle de l'interface utilisateur. À utiliser lorsqu'on vous demande de « vérifier cela dans le navigateur », de « reproduire ce résultat » ou de « vérifier le correctif ». Pour les audits de sources et la gravité, utilisez ui-design ; les métriques de terrain nécessitent RUM ou CrUX.
