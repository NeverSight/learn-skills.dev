Esegue sonde del browser con ambito per focus, obiettivi raggiunti, overflow, temi, richieste non riuscite e attribuzione delle prestazioni, con prove collegate agli ID delle regole dell'interfaccia utente. Utilizzare quando viene richiesto di "verificare questo nel browser", "riprodurre questo risultato" o "controllare la correzione". Per i controlli delle fonti e la gravità utilizzare ui-design; le metriche sul campo richiedono RUM o CrUX.
