Réduit le temps d'attente entre le push et le vert en mesurant le chemin critique du pipeline à partir des horodatages d'exécution, puis en fractionnant, sharding, simplifiant la configuration et en partageant l'état du module de test, avec un registre avant/après. À utiliser lorsqu'on vous demande « accélérer le CI », « le CI est lent », « pourquoi une PR prend 15 minutes », « le CI est le goulot d'étranglement », ou lorsque les agents fusionnent plus vite que les vérifications ne se terminent. Pour un build rouge, utilisez pr‑babysitter ; pour le pipeline d'un nouveau paquet, utilisez scaffold‑cli. Veuillez toujours répondre dans la langue de l'utilisateur.
