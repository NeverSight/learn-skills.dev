Reduce el tiempo de espera desde el push hasta el verde al medir la ruta crítica del pipeline a partir de las marcas de tiempo de ejecución, luego dividir, fragmentar, recortar la configuración y compartir el estado del módulo de pruebas, con un registro antes/después. Úsalo cuando te pidan "acelerar CI", "CI es lento", "¿por qué un PR tarda 15 minutos?", "CI es el cuello de botella", o cuando los agentes fusionan más rápido de lo que terminan las verificaciones. Para una compilación roja usa pr-babysitter; para el pipeline de un paquete nuevo usa scaffold-cli.
