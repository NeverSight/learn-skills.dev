Kürzt die Wartezeit vom Push bis zum Grünen, indem der kritische Pfad einer Pipeline anhand von Laufzeitstempeln gemessen wird, dann aufgeteilt, geshardet, das Setup gekürzt und der Testmodul‑Status geteilt wird, mit einem Vorher‑/Nachher‑Protokoll. Verwenden Sie es, wenn nach „CI beschleunigen“, „CI ist langsam“, „warum dauert ein PR 15 Minuten“, „CI ist der Flaschenhals“ gefragt wird oder wenn Agenten schneller zusammenführen als die Checks fertig sind. Für einen roten Build verwenden Sie pr‑babysitter; für die Pipeline eines neuen Pakets verwenden Sie scaffold‑cli.
