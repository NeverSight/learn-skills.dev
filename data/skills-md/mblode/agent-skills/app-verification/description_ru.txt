Создаёт и поддерживает собственный набор проверок продукта внутри его репозитория, CLI‑команду verify, команду doctor, изоляцию per‑worktree, карту функций, написанную с точки зрения пользователя, стартовые данные и передачу багов по принципу «воспроизвести сначала». Используйте, когда просят «собрать набор проверок», «добавить команду doctor», «дать агентам способ проверить это приложение», «доказать, что все функции работают» или «воспроизвести этот баг‑репорт». Для единичных браузерных проверок по фиксированному каталогу правил UI используйте ui‑verification; для проверок границ модулей и правил lint по всему репозиторию — codebase‑architecture.
