Élimine les tests de faible valeur jusqu'à atteindre un objectif mesuré tout en maintenant la couverture, et bloque les nouveaux tests avant qu'ils ne soient intégrés. Utilisez‑le lorsqu’on vous demande « remove useless tests », « prune the test suite », « we have too many tests », « agents keep writing pointless tests », « cut 20% of tests without losing coverage », « audit these tests » ou « should this test exist ». Pour un pipeline lent, utilisez ci‑speedup ; pour examiner un diff, utilisez tidy.
