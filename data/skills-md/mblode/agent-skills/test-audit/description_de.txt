Schneidet niedrigwertige Tests auf ein festgelegtes Ziel zurück, während die Abdeckung erhalten bleibt, und prüft neue Tests, bevor sie übernommen werden. Verwenden Sie es, wenn Sie aufgefordert werden, „unnötige Tests entfernen“, „den Testsatz kürzen“, „wir haben zu viele Tests“, „Agenten schreiben sinnlose Tests“, „20 % der Tests reduzieren, ohne Abdeckung zu verlieren“, „diese Tests prüfen“ oder „sollte dieser Test existieren“. Für eine langsame Pipeline verwenden Sie ci-speedup; zum Überprüfen eines Diff verwenden Sie tidy.

Bitte antworten Sie immer in der Sprache des Benutzers.
