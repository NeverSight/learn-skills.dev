實施代理可用性於公共網站與文件，資料來源可包括 Mintlify Agent Score、AFDocs、Is Agentic、Is It Agent Ready，或 url-discovery-bench 報告，亦或是代理在猜測 URL 時產生 404 錯誤的伺服器日誌。於以下情況使用：被要求「使此代理可用」(make this agent‑ready)、「提升 Agent Score」(improve Agent Score)、「修復 llms.txt 覆蓋率」(fix llms.txt coverage)、「代理在我們的文件上持續 404」(agents keep 404ing on our docs) 或貼上的分數卡作為簡報時。文件文字使用 ghostwriter；CLI/SDK 可用性使用 dx‑audit；代理產品 UX 使用 ax‑audit；爬蟲政策、Next.js Markdown 路由與 AEO 測量則使用 seo。請始終以使用者的語言回覆。
