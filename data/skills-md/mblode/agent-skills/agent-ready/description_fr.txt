Met en œuvre la préparation des agents sur les sites publics et la documentation à partir de Mintlify Agent Score, AFDocs, Is Agentic, Is It Agent Ready, ou des rapports url‑discovery‑bench, ou à partir des journaux serveur d’agents obtenant des 404 sur des URL devinées. Utilisez‑le lorsqu’on vous demande « rendre cela compatible avec les agents », « améliorer le Agent Score », « corriger la couverture de llms.txt », « les agents reçoivent des 404 sur notre documentation », ou lorsqu’une carte de score collée constitue le brief. Pour la rédaction de la documentation, utilisez ghostwriter ; pour l’ergonomie CLI/SDK, utilisez dx‑audit ; pour l’UX produit agentique, utilisez ax‑audit ; pour la politique de crawl, les routes markdown Next.js et la mesure AEO, utilisez seo.

Veuillez toujours répondre dans la langue de l’utilisateur.
