Реализует готовность агента на публичных сайтах и в документации из Mintlify Agent Score, AFDocs, Is Agentic, Is It Agent Ready или отчётов url‑discovery‑bench, а также из журналов сервера, где агенты получают 404 на угадываемых URL. Используйте, когда просят «сделать этот агент готовым», «улучшить Agent Score», «исправить покрытие llms.txt», «агенты продолжают получать 404 на наших документах», или когда вставленная табель оценки является брифом. Для текстов документации используйте ghostwriter; для удобства CLI/SDK — dx‑audit; для UX агентного продукта — ax‑audit; для политики сканеров, маршрутов markdown в Next.js и измерения AEO используйте seo.

Пожалуйста, всегда отвечайте на языке пользователя.
