يُنفّذ جاهزية الوكيل على المواقع العامة والوثائق باستخدام تقارير Mintlify Agent Score، AFDocs، Is Agentic، Is It Agent Ready، أو تقارير url-discovery-bench، أو من سجلات الخادم التي تُظهر حصول الوكلاء على خطأ 404 عند عناوين URL المتوقعة. استخدمه عندما يُطلب “جعل هذا جاهزًا للوكيل”، “تحسين Agent Score”، “إصلاح تغطية llms.txt”، “الوكلاء يستمرون في ظهور خطأ 404 في وثائقنا”، أو عندما تكون بطاقة النقاط الملصقة هي المتطلبات. للنصوص الوثائقية استعمِل ghostwriter؛ لتجربة CLI/SDK استعمِل dx-audit؛ لتجربة المستخدم للمنتج الوكيل استعمِل ax-audit؛ لسياسة الزاحف، مسارات markdown في Next.js، وقياس AEO استعمِل seo. يرجى دائمًا الرد بلغة المستخدم.
