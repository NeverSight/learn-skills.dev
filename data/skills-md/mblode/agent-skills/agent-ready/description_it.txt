Implementa la prontezza dell'agente su siti pubblici e documenti da Mintlify Agent Score, AFDocs, Is Agentic, Is It Agent Ready, o rapporti di url-discovery-bench, o dai log del server di agenti che generano 404 su URL indovinati. Usalo quando ti chiedono di "make this agent-ready", "improve Agent Score", "fix llms.txt coverage", "agents keep 404ing on our docs", o quando una scheda di valutazione incollata è il brief. Per la prosa dei documenti usa ghostwriter; per l'ergonomia CLI/SDK usa dx-audit; per l'UX del prodotto agentico usa ax-audit; per la politica del crawler, le rotte markdown di Next.js e la misurazione AEO usa seo.

Rispondi sempre nella lingua dell'utente.
