Implementa la preparación de agentes en sitios públicos y documentos a partir de Mintlify Agent Score, AFDocs, Is Agentic, Is It Agent Ready, o informes de url-discovery-bench, o de los registros del servidor de agentes que reciben 404 en URLs adivinadas. Utilízalo cuando se solicite "make this agent-ready", "improve Agent Score", "fix llms.txt coverage", "agents keep 404ing on our docs", o cuando una tarjeta de puntuación pegada sea el resumen. Para la prosa de documentos usa ghostwriter; para la ergonomía de CLI/SDK usa dx-audit; para la UX de producto agentic usa ax-audit; para la política de rastreadores, rutas markdown de Next.js y la medición AEO usa seo.
