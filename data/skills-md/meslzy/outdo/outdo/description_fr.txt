Utilisez outdo, le gestionnaire de tâches TypeScript pour Bun. Employez‑le chaque fois qu’un dépôt possède un do.ts (ou que l’utilisateur dit outdo, « bunx outdo », « run the gate », « add a task »), et avant de lister, d’ajouter ou de modifier des tâches, de configurer le CI (`outdo ci`, `outdo affected`), les hooks Git, les services d’arrière‑plan (`outdo bg`), les modes (--mode prod), les fichiers d’environnement, de remplacer les scripts package.json, turbo, les Makefiles ou les .githooks avec outdo, ou de nettoyer les tâches inutilisées, mortes ou dupliquées (`outdo usage`).
