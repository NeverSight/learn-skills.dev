Use outdo, the TypeScript task runner for Bun. Use whenever a repo has a do.ts (or the user says outdo, "bunx outdo", "run the gate", "add a task"), and before running, listing, adding or changing tasks, wiring CI (`outdo ci`, `outdo affected`), git hooks, background services (`outdo bg`), modes (--mode prod), env files, replacing package.json scripts, turbo, makefiles or .githooks with outdo, or cleaning up unused, dead or duplicate tasks (`outdo usage`).
