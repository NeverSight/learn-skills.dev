Usa outdo, il task runner TypeScript per Bun. Usalo ogni volta che un repository ha un do.ts (o l'utente dice outdo, “bunx outdo”, “run the gate”, “add a task”), e prima di eseguire, elencare, aggiungere o modificare i task, collegare la CI (`outdo ci`, `outdo affected`), i hook Git, i servizi in background (`outdo bg`), le modalità (--mode prod), i file .env, sostituire gli script di package.json, turbo, i makefile o i .githooks con outdo, o pulire i task inutilizzati, morti o duplicati (`outdo usage`).  

Per favore rispondi sempre nella lingua dell'utente.
