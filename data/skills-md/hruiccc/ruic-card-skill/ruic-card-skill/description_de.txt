Generieren Sie interaktive holografische 3D-Sammelkarten-Websites aus einer Benutzerbeschreibung oder einem Referenzbild mithilfe von mehrschichtigen Grafiken, Blender und Three.js. Beinhaltet projektlokale Blender-Installation, wiederverwendbare Parallax-Materialien und Browser-Überprüfung. Verwenden Sie diese Option, wenn der Benutzer eine Karte, eine Karte, eine 3D-Karte, eine holografische Sammelkartenseite oder eine bearbeitbare Kartenmischung anfordert.
