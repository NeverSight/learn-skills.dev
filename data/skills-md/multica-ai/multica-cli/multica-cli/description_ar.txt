يُستخدم عندما يحتاج وكيل ترميز محلي (Codex أو Claude Code أو Cursor أو ما شابه) إلى تشغيل Multica من خلال واجهة سطر الأوامر "multica" المصادق عليها: قراءة أو تحديث المشكلات أو التعليقات أو بيانات التعريف أو التصنيفات أو الخصائص المخصصة أو المشتركين أو المشاريع أو الوكلاء أو الفرق أو أوقات التشغيل أو اتفاقيات إعادة الشراء أو المهارات أو الطيار الآلي أو المرفقات أو حالة مساحة العمل؛ قضايا البحث؛ فحص أو إلغاء تشغيل الوكيل؛ الرد على مشكلة Multica من وكيل خارجي؛ خلق أو فرز القضايا؛ التحقق من طلبات السحب المرتبطة؛ أو التعامل بأمان مع الآثار الجانبية لذكر/حالة Multica دون الاعتماد على وقت تشغيل الوكيل المستضاف لـ Multica.
