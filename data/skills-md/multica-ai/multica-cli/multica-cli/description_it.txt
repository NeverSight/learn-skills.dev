Da utilizzare quando un agente di codifica locale (Codex, Claude Code, Cursor o simili) deve utilizzare Multica tramite la CLI "multica" autenticata: leggere o aggiornare problemi, commenti, metadati, etichette, proprietà personalizzate, abbonati, progetti, agenti, squadre, runtime, repository, competenze, autopiloti, allegati o stato dell'area di lavoro; problemi di ricerca; ispezionare o annullare le esecuzioni dell'agente; rispondere a un problema Multica da un agente esterno; creazione o valutazione di problemi; controllare le richieste pull collegate; o gestire in modo sicuro gli effetti collaterali di menzione/stato di Multica senza fare affidamento sul runtime dell'agente ospitato da Multica.
