À utiliser lorsqu'un agent de codage local (Codex, Claude Code, Cursor ou similaire) doit faire fonctionner Multica via la CLI « multica » authentifiée : lecture ou mise à jour de problèmes, commentaires, métadonnées, étiquettes, propriétés personnalisées, abonnés, projets, agents, équipes, environnements d'exécution, dépôts, compétences, pilotes automatiques, pièces jointes ou état de l'espace de travail ; problèmes de recherche ; inspecter ou annuler les exécutions d'agent ; répondre à un problème Multica provenant d'un agent externe ; créer ou trier des problèmes ; vérifier les demandes d'extraction liées ; ou gérer en toute sécurité les effets secondaires des mentions/statuts Multica sans compter sur le runtime de l'agent hébergé Multica.
