Scaffold a new project as the Tech Lead would in Sprint 0, after the task breakdown and before coding standards are written. Grills on folder structure, architectural patterns, commit hooks, tooling, the test harness, and stubs, then executes the scaffold: directory layout, local tooling config, pre-commit hooks, a test harness with one e2e smoke flow, and endpoint/page stubs that return mock responses so frontend and backend can build in parallel from day one. On a running project it audits first and adds only what is missing. Use when the user wants to set up, bootstrap, or scaffold a project, add a test or e2e harness, stand up the repo skeleton, do Sprint 0, or asks to "set up the project".
