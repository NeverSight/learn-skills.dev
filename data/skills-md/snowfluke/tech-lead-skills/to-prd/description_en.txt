Add a feature or change request to a project that is already running. Turns the latest grill-me decision log, or the conversation, into new user stories and acceptance criteria, continuing the US and AC numbering, in docs/business/ in us-ac-formatter's format or in the project's older business docs in their own layout and language. Asks only for what the acceptance criteria need and the input lacks, lists the specs the change touches, and opens a parent GitHub issue that links it all. Use when the user wants a PRD, wants to add a feature mid-project, or asks to turn a discussion into stories. Hands off to to-issues.
