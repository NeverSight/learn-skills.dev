The tech lead's review of a pull request against the project's own coding standards and review checklist, in any language. Discovers the repo's standards docs, checks out the PR branch in an isolated git worktree, runs the project's test / lint / format / type-check gates, proves each finding, then posts a review in a fixed, script-checked format that stays identical across rounds. Also audits commits pushed straight to a branch, as a range from a given commit or as one author's commits in it, with the rounds kept in a GitHub issue. Use when the user asks to review a PR, review a branch, re-review a PR after changes, review commits on main, review an author's commits since a hash, or do code review.
