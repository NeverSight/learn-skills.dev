Guide d'expert pour les applications Rails SQLite-per-tenant utilisant la gem Basecamp activerecord‑tenanted. À utiliser lors de l’ajout de multi‑location, de bases de données par locataire, de GlobalRecord, d’ApplicationRecord.with_tenant, de Current.tenant, de Current.account, de permutation de shards, de db/global_migrate ou de SQLite par locataire. Ne pas utiliser pour la portée de lignes de type Nebula acts_as_tenant ou la location par même base de données de type Fizzy.
