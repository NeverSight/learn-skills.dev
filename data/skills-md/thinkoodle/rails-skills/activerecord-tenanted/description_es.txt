Guía experta para aplicaciones Rails con SQLite por inquilino usando el gem activerecord-tenanted de Basecamp. Úsela al agregar multialquiler, bases de datos de inquilinos, GlobalRecord, ApplicationRecord.with_tenant, Current.tenant, Current.account, intercambio de fragmentos, db/global_migrate o SQLite por inquilino. No la utilice para la segmentación de filas estilo Nebula acts_as_tenant ni para la tenencia de ruta de misma base de datos de Fizzy.
