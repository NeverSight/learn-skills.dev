Guía experta para Active Storage con activerecord-tenanted. Úsala cuando los blobs devuelvan 404 después de guardarse, cargas Lexxy/Trix, cargas directas, IDs de blob firmados por el inquilino, redirecciones rails/active_storage, o “Cannot generate a Blob key without a tenant”. Requiere la habilidad activerecord-tenanted. No es para Active Storage de base de datos única.
