إرشادات خبراء لـ Active Storage مع activerecord-tenanted. يُستخدم عندما تظهر كائنات (blobs) خطأ 404 بعد الحفظ، أو تحميلات Lexxy/Trix، أو التحميلات المباشرة، أو معرفات blobs موقعة من قبل المستأجر، أو عمليات إعادة توجيه rails/active_storage، أو الرسالة "Cannot generate a Blob key without a tenant". يتطلب مهارة activerecord-tenanted. ليس مخصصًا لتخزين Active Storage بقاعدة بيانات واحدة.
