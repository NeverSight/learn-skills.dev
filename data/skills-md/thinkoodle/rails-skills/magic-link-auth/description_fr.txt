Guide expert pour l'authentification sans mot de passe par code e‑mail dans Rails — le modèle token/code de 37signals utilisé par Basecamp, Fizzy et des applications comme Herald. À utiliser lors de l’ajout de connexion, d’inscription, de liens magiques, de codes à usage unique, OTP, codes de vérification, jetons de session, jetons d’authentification en attente, jetons d’accès personnel, authentification API Bearer, connexion sans mot de passe ou pour remplacer Devise/has_secure_password. N’utilisez pas le générateur de mots de passe de Rails 8 pour ce flux.  

Veuillez toujours répondre dans la langue de l’utilisateur.
