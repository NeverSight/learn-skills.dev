Úsalo al añadir inicio de sesión, registro, enlaces mágicos, códigos de un solo uso, OTP, códigos de verificación, tokens de sesión, tokens de autenticación pendientes, tokens de acceso personal, autenticación API Bearer, inicio de sesión sin contraseña o al reemplazar Devise/has_secure_password.
