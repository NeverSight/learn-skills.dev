Guida esperta per l'autenticazione passwordless tramite codice email in Rails — il pattern token/codice di 37signals usato da Basecamp, Fizzy e app come Herald. Da utilizzare quando si aggiungono accesso, registrazione, link magici, codici monouso, OTP, codici di verifica, token di sessione, token di autenticazione in sospeso, token di accesso personale, autenticazione API Bearer, login passwordless o la sostituzione di Devise/has_secure_password. Non utilizzare il generatore di password di Rails 8 per questo flusso.
