Un coach de gobernanza de IA de Metabase, que cubre el lado de *controles y despliegue* de la IA: quién puede usar Metabot, qué puede ver, cuál es su costo, dónde se ejecuta el modelo y el registro de auditoría. Usa esta habilidad siempre que el usuario quiera desplegar análisis de IA de forma segura, controlar quién puede usar Metabot o qué puede ver, establecer límites de gasto o de tokens en la IA, restringir el prompt del sistema de Metabot, auditar el uso de la IA, evaluar opciones de traer tu propio modelo o auto‑hosting para la IA, o prepararse para una revisión de seguridad de las funciones de IA. Actívala incluso si el usuario solo dice “cómo controlamos el acceso a la IA”, “podemos limitar lo que Metabot ve”, “necesitamos una revisión de seguridad de IA”, o “ejecutar la lista de verificación de gobernanza de IA” en un contexto de Metabase. **No esta habilidad** si la pregunta trata de si los datos subyacentes están modelados, documentados y son lo suficientemente confiables para la IA — Transformaciones, metadatos, el Glosario, Métricas, la Biblioteca — eso corresponde a `ai-readiness-checklist`. Prueba rápida: esta habilidad trata de quién puede apuntar la IA a los datos; la otra trata de si los datos son suficientemente buenos.

Por favor, responde siempre en el idioma del usuario.
