Un coach de gouvernance IA pour Metabase, couvrant le côté *contrôles et déploiement* de l’IA : qui peut utiliser Metabot, ce qu’il peut voir, quels sont les coûts, où le modèle s’exécute et la trace d’audit. Utilisez cette compétence chaque fois que l’utilisateur veut déployer des analyses IA en toute sécurité, contrôler qui peut utiliser Metabot ou ce qu’il peut voir, définir des limites de dépenses ou de jetons pour l’IA, restreindre l’invite système de Metabot, auditer l’usage de l’IA, évaluer les options d’apport de votre propre modèle ou d’auto‑hébergement pour l’IA, ou préparer une révision de sécurité des fonctionnalités IA. Déclenchez‑la même si l’utilisateur se contente de dire « comment contrôler l’accès à l’IA », « peut‑on limiter ce que voit Metabot », « nous avons besoin d’une révision de sécurité IA », ou « exécuter la checklist de gouvernance IA » dans un contexte Metabase. **Pas cette compétence** si la question porte sur la fiabilité, la modélisation ou la documentation des données sous‑jacentes pour l’IA — Transformations, métadonnées, Glossaire, Métriques, Bibliothèque — c’est le `ai‑readiness‑checklist`. Test approximatif : cette compétence porte sur qui a le droit de diriger l’IA vers les données ; l’autre porte sur la qualité des données.
