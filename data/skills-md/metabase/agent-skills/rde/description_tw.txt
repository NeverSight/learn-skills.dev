在任何公司技術堆疊的核心使用 Metabase 的專業資料工程：探索並分析原始資料倉儲表格、根據 Metabase 轉換並以轉換測試釘住的方式建立乾淨的表格、構建語意層（模型、指標、度量、分段、元資料），設計儀表板，以經過驗證的數字回答問題，與參考資料對帳，安全地變更已交付的定義。用於資料工作，而非僅僅一條 `mb` 指令（`metabase-cli`）：「了解我的資料」「為此原始結構建模」「為 X 設置分析」「建立資料模型」「正式定義每月經常性收入（MRR）／活躍客戶」「構建語意層」「從原始表格到儀表板」「這個數字與財務相符嗎」「我們的數字好像不對」「兩張卡片的結果不一致」「測試此轉換」「為什麼此轉換在 X 情況下錯誤」「讓 Metabot 回答關於 X 的問題」「說明這個表格」「更改此定義」「打造資料應用程式」「捐贈者保留」「活動出席」「季度董事會報告」「成為我的資料工程師／分析師」.
