Costruisci o modifica un’app dati Metabase su una macchina rde: stabilisce cosa le competenze `metabase-data-app-*` richiedono dall’impostazione locale (il repository remote‑sync, l’URL di Metabase, la chiave API che rde memorizza, come l’app accede a Metabase), si assicura che tutto ciò che l’app legge sia contenuto della Libreria già sincronizzato in quel repository, conferma ogni passaggio di sincronizzazione con l’utente e consegna la costruzione a loro. Usa solo quando un’app è richiesta esplicitamente: “costruiscimi un’app per X”, “crea un’app dati”, “realizza uno strumento interno / portale in Metabase”, “aggiungi una pagina / un modulo / un filtro alla mia app dati”. Un cruscotto, una domanda o una metrica non sono un’app; questi restano nella competenza `rde`.

Rispondi sempre nella lingua dell’utente.
