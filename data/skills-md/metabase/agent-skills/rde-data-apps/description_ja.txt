rde マシン上で Metabase データアプリを構築または変更する：`metabase-data-app-*` スキルがローカル環境から必要とするもの（リモート同期リポジトリ、Metabase の URL、rde が保存する API キー、アプリが Metabase にアクセスする方法）を決定し、アプリが読み取るすべてがそのリポジトリにすでに同期されたライブラリコンテンツであることを確認し、同期の各ステップをユーザーに確認し、ビルドを引き継ぐ。アプリが明示的に要求された場合にのみ使用する：「X 用のアプリを作って」「データアプリを作成して」「Metabase で内部ツール／ポータルを作って」「私のデータアプリにページ／フォーム／フィルターを追加して」など。ダッシュボード、クエリ、指標はアプリではなく、これらは `rde` スキルに残ります。
