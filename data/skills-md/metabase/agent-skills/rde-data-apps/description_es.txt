Construir o cambiar una aplicación de datos de Metabase en una máquina rde: determina lo que las habilidades `metabase-data-app-*` necesitan de la configuración local (el repositorio de sincronización remota, la URL de Metabase, la clave API que rde almacena, cómo la aplicación se conecta a Metabase), se asegura de que todo lo que la aplicación lee sea contenido de la Biblioteca ya sincronizado en ese repositorio, confirma cada paso de sincronización con el usuario y entrega la construcción al usuario. Úsala solo cuando se solicite explícitamente una aplicación: "construye una aplicación para X", "crea una aplicación de datos", "haz una herramienta interna / portal en Metabase", "añade una página / un formulario / un filtro a mi aplicación de datos". Un panel, una pregunta o una métrica no son una aplicación; esos permanecen con la habilidad `rde`.

Por favor, siempre responde en el idioma del usuario.
