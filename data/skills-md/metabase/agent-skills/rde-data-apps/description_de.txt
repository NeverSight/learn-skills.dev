Erstelle oder ändere eine Metabase‑Daten‑App auf einer rde‑Maschine: klärt, was die `metabase-data-app-*`‑Skills vom lokalen Setup benötigen (das Remote‑Sync‑Repository, die Metabase‑URL, den API‑Schlüssel, den rde speichert, wie die App Metabase erreicht), stellt sicher, dass alles, was die App einliest, bereits als Bibliotheksinhalt in dieses Repository synchronisiert ist, bestätigt jeden Synchronisationsschritt mit dem Benutzer und übergibt den Build an ihn. Verwende dies nur, wenn ausdrücklich nach einer App gefragt wird: „Erstelle mir eine App für X“, „Erstelle eine Daten‑App“, „Mache ein internes Tool/Portal in Metabase“, „Füge meiner Daten‑App eine Seite/ein Formular/einen Filter hinzu“. Ein Dashboard, eine Frage oder eine Kennzahl ist keine App; diese bleiben beim `rde`‑Skill.
