Construisez ou modifiez une application de données Metabase sur une machine rde : détermine ce dont les compétences `metabase-data-app-*` ont besoin dans la configuration locale (le dépôt de synchronisation à distance, l’URL de Metabase, la clé API que rde stocke, la façon dont l’application atteint Metabase), s’assure que tout ce que l’application lit provient du contenu de la Bibliothèque déjà synchronisé dans ce dépôt, confirme chaque étape de synchronisation avec l’utilisateur, et remet la construction entre ses mains. N’utilisez cela que lorsqu’une application est demandée explicitement : « construisez‑moi une application pour X », « créez une application de données », « créez un outil interne / portail dans Metabase », « ajoutez une page / un formulaire / un filtre à mon application de données ». Un tableau de bord, une question ou une métrique n’est pas une application ; ceux‑ci restent sous la compétence `rde`.

Veuillez toujours répondre dans la langue de l’utilisateur.
