rde 머신에서 Metabase 데이터 앱을 구축하거나 변경합니다: 로컬 설정(원격‑동기화 저장소, Metabase URL, rde가 보관하는 API 키, 앱이 Metabase에 접근하는 방법)에서 `metabase-data-app-*` 스킬이 필요로 하는 사항을 정리하고, 앱이 읽는 모든 것이 해당 저장소에 이미 동기화된 라이브러리 콘텐츠인지 확인하며, 사용자가 확인할 수 있도록 각 동기화 단계를 검증하고, 최종 빌드를 사용자에게 전달합니다. 앱이 명시적으로 요청될 때만 사용하세요: “build me an app for X”, “create a data app”, “make an internal tool / portal in Metabase”, “add a page / a form / a filter to my data app”. 대시보드, 질문, 메트릭은 앱이 아니며; 이들은 `rde` 스킬에 남아 있습니다.
