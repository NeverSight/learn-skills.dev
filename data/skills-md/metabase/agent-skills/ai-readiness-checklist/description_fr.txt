Un coach de préparation à l’IA pour Metabase, couvrant les *bases de données* qui rendent les réponses d’IA fiables : modélisation avec les Transformations, les métadonnées de tables et de champs, le Glossaire, les Métriques enregistrées, et la désignation du contenu canonique. Utilisez cette compétence chaque fois que l’utilisateur veut vérifier si ses données sont prêtes pour l’IA, préparer les données sous‑jacentes pour Metabot ou le serveur Metabase MCP, parcourir une checklist de préparation à l’IA, ou auditer sa modélisation de données/métadonnées/métriques avant d’activer les fonctionnalités d’IA. déclenchez‑la même si l’utilisateur dit simplement « mes données sont‑elles prêtes pour l’IA ? », « préparons Metabot », ou « exécuter la checklist de préparation à l’IA » dans un contexte Metabase. **Cette compétence n’est pas** à utiliser si la question porte sur le contrôle de qui peut utiliser l’IA, la limitation des dépenses d’IA, la restriction de ce que Metabot peut voir, l’audit de l’usage de l’IA, ou le passage d’une revue de sécurité — c’est `ai-governance-checklist`. Test approximatif : cette compétence porte sur la qualité des données ; l’autre porte sur qui peut pointer l’IA vers elles.

Veuillez toujours répondre dans la langue de l’utilisateur.
