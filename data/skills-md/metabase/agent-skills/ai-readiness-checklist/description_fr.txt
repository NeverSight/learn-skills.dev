Un coach de préparation à l'IA Metabase, couvrant les *préparatifs de données* qui rendent les réponses d'IA fiables : modélisation avec les Transformations, les métadonnées de tables et de champs, le Glossaire, les métriques sauvegardées, et le marquage du contenu canonique. Utilisez cette compétence chaque fois que l'utilisateur veut vérifier si ses données sont prêtes pour l'IA, préparer les données sous‑jacent pour Metabot ou le serveur Metabase MCP, parcourir une checklist de préparation à l'IA, ou auditer sa modélisation de données/métadonnées/métriques avant d'activer les fonctionnalités d'IA. Activez‑la même si l'utilisateur dit simplement « mes données sont‑elles prêtes pour l'IA ? », « préparons Metabot », ou « exécuter la checklist de préparation à l'IA » dans un contexte Metabase. **Pas cette compétence** si la question porte sur le contrôle de qui peut utiliser l'IA, la limitation des dépenses d'IA, la restriction de ce que Metabot peut voir, l'audit de l'utilisation de l'IA, ou la validation d'une revue de sécurité — c’est `ai-governance-checklist`. Test sommaire : cette compétence porte sur la qualité des données ; l’autre porte sur qui a le droit d’y appliquer l’IA.
