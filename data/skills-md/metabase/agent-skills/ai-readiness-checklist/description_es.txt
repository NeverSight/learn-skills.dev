Un entrenador de preparación de IA para Metabase, que cubre la *base de datos* que hace que las respuestas de IA sean confiables: modelado con Transformaciones, metadatos de tablas y campos, el Glosario, Métricas guardadas y la marcación de contenido canónico. Usa esta habilidad siempre que el usuario quiera comprobar si sus datos están listos para IA, preparar los datos subyacentes para Metabot o el servidor Metabase MCP, seguir una lista de verificación de preparación para IA o auditar su modelado de datos/metadatos/métricas antes de activar las funciones de IA. Actívala incluso si el usuario solo dice “¿están mis datos listos para IA?”, “configurémonos para Metabot” o “ejecuta la lista de verificación de preparación para IA” en un contexto de Metabase. **No esta habilidad** si la pregunta trata sobre controlar quién puede usar IA, limitar el gasto en IA, restringir lo que Metabot puede ver, auditar el uso de IA o pasar una revisión de seguridad — esa es `ai-governance-checklist`. Prueba rápida: esta habilidad se trata de si los datos son suficientemente buenos; la otra se trata de quién puede apuntar IA a ellos. 

Por favor, responde siempre en el idioma del usuario.
