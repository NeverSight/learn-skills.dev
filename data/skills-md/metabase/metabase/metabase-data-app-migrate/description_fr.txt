Migrez une application de données Metabase existante que Metabase marque comme obsolète (sa version `data_app.yaml' est inférieure à la version du contrat d'application de données, aux compétences installées et à la cible du SDK) vers la version actuelle, une mise à niveau à la fois, avec une procédure de reprise. À utiliser lorsque Metabase affiche une application comme obsolète, que « npm run typecheck » ou « npm run build » échoue après une mise à niveau du SDK, ou que la « version » d'une application existante est derrière celle que les compétences installées visent. Pas pour créer une application.
