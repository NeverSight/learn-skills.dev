Перенести существующее приложение данных Metabase, которое Metabase помечает как устаревшее (его `data_app.yaml` `version` ниже версии контракта data‑app, на которую нацелены установленные навыки и SDK), на текущую версию, по одному обновлению за раз, с возможностью возобновления процедуры. Используйте, когда Metabase показывает приложение как устаревшее, `npm run typecheck` или `npm run build` завершаются с ошибкой после обновления SDK, либо `version` существующего приложения отстаёт от версии, на которую нацелены установленные навыки. Не предназначено для создания приложения. Пожалуйста, всегда отвечайте на языке пользователя.
