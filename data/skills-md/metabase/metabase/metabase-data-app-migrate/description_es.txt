Migrar una aplicación de datos Metabase existente que Metabase marca como obsoleta (su `versión`'data_app.yaml ` está por debajo de la versión del contrato de la aplicación de datos, las habilidades instaladas y el objetivo del SDK) a la versión actual, una actualización a la vez, con un procedimiento reanudable. Se usa cuando Metabase muestra una aplicación como obsoleta, `npm run typecheck` o `npm run build` falla después de una actualización de SDK, o la `versión` de una aplicación existente está detrás de la del objetivo de habilidades instalado. No es para crear una aplicación.
