Migra un'app dati Metabase esistente che Metabase segnala come Obsoleta (il suo `data_app.yaml` `version` è inferiore alla versione del contratto data‑app a cui puntano le skill installate e l'SDK) alla versione corrente, un aggiornamento alla volta, con una procedura riprendibile. Usala quando Metabase mostra un'app come Obsoleta, `npm run typecheck` o `npm run build` falliscono dopo un aggiornamento dell'SDK, o la `version` di un'app esistente è inferiore a quella a cui puntano le skill installate. Non è destinata alla creazione di un'app.
