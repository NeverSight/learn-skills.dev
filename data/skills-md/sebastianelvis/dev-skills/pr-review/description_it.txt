Utilizza questa competenza per una revisione sistematica della richiesta pull GitHub di un'altra persona. Attivazione su "revisione PR 123", "è sicuro unire questo PR", "controlla il design di questo PR", "questo infrange il protocollo" o "questo risolve il problema". Controllare il problema, l'architettura, la conformità del protocollo, la causa principale, la necessità, la correttezza, la sicurezza e le regole del progetto. Richiedere all'utente di confermare la specifica, il problema e l'approccio prima di una revisione dettagliata. NON utilizzare per un differenziale locale non vincolato, una descrizione PR o un controllo della lanugine.
