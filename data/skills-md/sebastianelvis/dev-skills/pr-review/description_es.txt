Utilice esta habilidad para una revisión sistemática de la solicitud de extracción de GitHub de otra persona. Activar en "revisar PR 123", "es seguro fusionar esto", "verificar el diseño de este PR", "esto rompe el protocolo" o "esto resuelve el problema". Verifique el problema, la arquitectura, la conformidad del protocolo, la causa raíz, la necesidad, la corrección, la seguridad y las reglas del proyecto. Exija que el humano confirme la especificación, el problema y el enfoque antes de una revisión detallada. NO lo use para una diferencia local no confirmada, una descripción de PR o una verificación de pelusa.
