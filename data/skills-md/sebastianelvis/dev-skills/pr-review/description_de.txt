Nutzen Sie diesen Skill für eine systematische Überprüfung des GitHub Pull Requests einer anderen Person. Auslöser bei „PR 123 überprüfen“, „Ist die Zusammenführung sicher“, „Überprüfen Sie das Design dieser PR“, „Verletzt dies das Protokoll“ oder „Löst dies das Problem“. Überprüfen Sie das Problem, die Architektur, die Protokollkonformität, die Grundursache, die Notwendigkeit, die Richtigkeit, die Sicherheit und die Projektregeln. Fordern Sie den Menschen auf, die Spezifikation, das Problem und den Ansatz vor einer detaillierten Überprüfung zu bestätigen. NICHT für einen nicht festgeschriebenen lokalen Diff, eine PR-Beschreibung oder eine Flusenprüfung verwenden.
