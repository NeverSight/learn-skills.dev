Cree o actualice un conjunto de diagramas de sistema basados ​​en evidencia desde un repositorio de software. Utilice esta habilidad para solicitudes para visualizar arquitectura, componentes, actores, modelos de datos o esquemas de bases de datos. Úselo para historias de usuarios, flujos de datos, flujos de control o flujos de trabajo de subsistemas. Úselo para planificar las cifras necesarias o actualizar diagramas después de cambios de código. Úselo para generar TikZ editable y salidas de imágenes estándar. NO lo utilice para gráficos, paneles, maquetas de interfaz, diagramas de clases, diagramas de secuencia de una sola llamada ni ilustraciones decorativas.
