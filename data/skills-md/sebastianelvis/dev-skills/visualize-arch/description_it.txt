Crea o aggiorna una serie di diagrammi di sistema basati sull'evidenza da un repository software. Utilizza questa competenza per le richieste di visualizzazione di architettura, componenti, attori, modelli di dati o schemi di database. Usalo per storie utente, flussi di dati, flussi di controllo o flussi di lavoro di sottosistemi. Usalo per pianificare le figure necessarie o aggiornare i diagrammi dopo le modifiche al codice. Usalo per generare TikZ modificabili e output di immagini standard. NON utilizzarlo per grafici, dashboard, modelli di interfaccia, diagrammi di classe, diagrammi di sequenza a chiamata singola o illustrazioni decorative.
