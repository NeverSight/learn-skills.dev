Créez ou mettez à jour un ensemble de diagrammes système fondés sur des preuves à partir d'un référentiel de logiciels. Utilisez cette compétence pour les requêtes visant à visualiser l'architecture, les composants, les acteurs, les modèles de données ou les schémas de base de données. Utilisez-le pour les user stories, les flux de données, les flux de contrôle ou les workflows de sous-systèmes. Utilisez-le pour planifier les figures nécessaires ou actualiser les diagrammes après des modifications de code. Utilisez-le pour générer des sorties TikZ modifiables et des images standard. Ne l'utilisez PAS pour des graphiques, des tableaux de bord, des maquettes d'interface, des diagrammes de classes, des diagrammes de séquence d'un appel ou des illustrations décoratives.
