ユーザーが現在のブランチの GitHub プル リクエストのタイトルまたは説明を生成、書き込み、下書き、更新、タイトル変更、または調整するように要求する場合に使用します。これには、「PR の説明を書く」、「PR を更新する」、「レビューのためにこのブランチを要約する」、「PR テンプレートと一致させる」、または「本文を再生成する」などの表現が含まれます。ベース ブランチ (コミット履歴ではなく最終状態) に対して「git diff」を分析するため、追加して削除する作業が省略され、製造が回避されます。変更ログ、リリースノート、問題コメントの概要、または自由形式のコードレビューについてはスキップしてください。
