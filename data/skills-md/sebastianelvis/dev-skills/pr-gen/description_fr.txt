À utiliser lorsque l'utilisateur demande de générer, d'écrire, de rédiger, d'actualiser, de retitrer ou d'aligner un titre ou une description de demande de tirage GitHub pour la branche actuelle, y compris des expressions telles que « écrire la description du PR », « mettre à jour le PR », « résumer cette branche pour examen », « correspondre à notre modèle de PR » ou « régénérer le corps ». Analyse `git diff` par rapport à la branche de base (état final, pas historique de validation) afin que le travail ajouté puis supprimé soit omis et que la fabrication soit évitée. Ignorez les journaux de modifications, les notes de version, les résumés de commentaires sur les problèmes ou la révision ouverte du code.
