Da utilizzare quando l'utente chiede di generare, scrivere, creare una bozza, aggiornare, rinominare o allineare un titolo o una descrizione di GitHub Pull Request per il ramo corrente, comprese frasi come "scrivi la descrizione PR", "aggiorna il PR", "riassumi questo ramo per la revisione", "corrisponde al nostro modello PR" o "rigenera il corpo". Analizza `git diff` rispetto al ramo base (stato finale, non cronologia dei commit) in modo che il lavoro aggiunto e poi rimosso venga omesso e la fabbricazione venga evitata. Salta per log delle modifiche, note di rilascio, riepiloghi dei commenti sui problemi o revisione del codice a tempo indeterminato.
