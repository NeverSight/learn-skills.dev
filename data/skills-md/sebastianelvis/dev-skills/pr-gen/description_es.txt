Úselo cuando el usuario solicite generar, escribir, redactar, actualizar, retitular o alinear un título o descripción de GitHub Pull Request para la rama actual, incluidas frases como "escribir la descripción del PR", "actualizar el PR", "resumir esta rama para su revisión", "coincidir con nuestra plantilla de PR" o "regenerar el cuerpo". Analiza `git diff` con respecto a la rama base (estado final, no historial de confirmaciones), por lo que se omite el trabajo agregado y luego eliminado y se evita la fabricación. Omita los registros de cambios, las notas de la versión, los resúmenes de comentarios de problemas o la revisión de código abierto.
