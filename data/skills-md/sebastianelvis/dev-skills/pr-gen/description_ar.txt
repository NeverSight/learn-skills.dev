يُستخدم عندما يطلب المستخدم إنشاء عنوان أو وصف طلب سحب GitHub للفرع الحالي أو كتابته أو صياغته أو تحديثه أو إعادة تسميته أو محاذاته - بما في ذلك عبارات مثل "اكتب وصف العلاقات العامة" أو "تحديث العلاقات العامة" أو "تلخيص هذا الفرع للمراجعة" أو "مطابقة قالب العلاقات العامة الخاص بنا" أو "تجديد النص الأساسي". يحلل `git diff` مقابل الفرع الأساسي (الحالة النهائية، وليس سجل الالتزام) بحيث يتم حذف العمل المضاف ثم المحذوف وتجنب التصنيع. انتقل إلى سجلات التغيير أو ملاحظات الإصدار أو ملخصات تعليقات الإصدار أو مراجعة التعليمات البرمجية المفتوحة.
