Instrumenter une application IA avec le traçage HoneyHive. Utilisez-le lorsque l'utilisateur souhaite ajouter de l'observabilité, capturer des traces, configurer le SDK, configurer les exportateurs ou connecter une instrumentation compatible OpenTelemetry pour un agent, un pipeline RAG ou une application LLM. Se déclenche sur des expressions telles que « add tracing », « instrument my app », « wire up HoneyHive », « set up the SDK », « capture spans », « OTEL exporter », ou toute mention de `HoneyHiveTracer.init`, `@honeyhive/api-client`, `client.sessions.startSession`, `client.events.createEvent`, ou des instrumentateurs `OpenInference`/`Traceloop` ciblant HoneyHive. Veuillez toujours répondre dans la langue de l'utilisateur.
