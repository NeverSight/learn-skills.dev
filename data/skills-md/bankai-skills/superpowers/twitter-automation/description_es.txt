Automatiza Twitter/X con publicación, interacción y gestión de usuarios mediante la CLI inference.sh. Aplicaciones: x/post-tweet, x/post-create (con medios), x/post-like, x/post-retweet, x/dm-send, x/user-follow. Capacidades: publicar tuits, programar contenido, dar me gusta a publicaciones, retuitear, enviar mensajes directos, seguir usuarios, obtener perfiles. Uso para: automatización de redes sociales, programación de contenidos, bots de interacción, crecimiento de audiencia, API de X. Disparadores: API de twitter, API de X, automatización de tuits, publicar en twitter, bot de twitter, automatización de redes sociales, automatización de X, programador de tuits, integración de twitter, publicar tuit, publicación en twitter, publicación X, enviar tuit.
