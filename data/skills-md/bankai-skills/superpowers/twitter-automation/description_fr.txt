Automatisez Twitter/X avec la publication, l’engagement et la gestion des utilisateurs via l’interface en ligne de commande inference.sh. Applications : x/post-tweet, x/post-create (avec média), x/post-like, x/post-retweet, x/dm-send, x/user-follow. Capacités : publier des tweets, programmer du contenu, aimer les publications, retweeter, envoyer des DM, suivre des utilisateurs, obtenir des profils. Utilisations : automatisation des réseaux sociaux, planification de contenu, bots d’engagement, croissance d’audience, API X. Déclencheurs : API Twitter, API X, automatisation de tweet, publier sur Twitter, bot Twitter, automatisation des médias sociaux, automatisation X, planificateur de tweets, intégration Twitter, publier un tweet, publication Twitter, publication X, envoyer un tweet.
