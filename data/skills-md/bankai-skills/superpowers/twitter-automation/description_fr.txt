Automatisez Twitter/X avec la publication, l'engagement et la gestion des utilisateurs via l'interface en ligne de commande inference.sh. Applications : x/post-tweet, x/post-create (avec médias), x/post-like, x/post-retweet, x/dm-send, x/user-follow. Fonctionnalités : publier des tweets, planifier du contenu, aimer des publications, retweeter, envoyer des DM, suivre des utilisateurs, obtenir des profils. Utilisations : automatisation des réseaux sociaux, planification de contenu, bots d'engagement, développement d'audience, API X. Déclencheurs : API twitter, API x, automatisation de tweet, publier sur twitter, bot twitter, automatisation des réseaux sociaux, automatisation x, planificateur de tweet, intégration twitter, publier tweet, post twitter, post x, envoyer tweet
