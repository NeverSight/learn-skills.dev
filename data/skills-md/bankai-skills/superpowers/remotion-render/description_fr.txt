Rendez des vidéos à partir du code de composants React/Remotion via inference.sh. Fournissez du code TSX, obtenez du MP4. Prend en charge toutes les API de Remotion : useCurrentFrame, useVideoConfig, spring, interpolate, AbsoluteFill, Sequence. Résolution, FPS, durée et codec configurables. À utiliser pour : génération de vidéos programmatique, graphiques animés, design de motion, vidéos basées sur les données, animations React en vidéo. Déclencheurs : remotion, rendu vidéo depuis le code, tsx en vidéo, vidéo React, vidéo programmatique, rendu remotion, code en vidéo, vidéo animée, code de graphiques animés, vidéo d’animation React.
