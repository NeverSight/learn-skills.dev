Веб‑поиск и извлечение контента с Tavily и Exa через CLI inference.sh. Приложения: Tavily Search, Tavily Extract, Exa Search, Exa Answer, Exa Extract. Возможности: поиск на основе ИИ, извлечение контента, прямые ответы, исследования. Использование: исследования, RAG‑конвейеры, проверка фактов, агрегация контента, агенты. Триггеры: веб‑поиск, tavily, exa, search api, извлечение контента, исследование, поиск в интернете, AI‑поиск, помощник поиска, веб‑скрейпинг, rag, альтернатива Perplexity.
