Automatisation du navigateur pour les agents IA via inference.sh. Naviguez sur les pages Web, interagissez avec les éléments à l'aide de @e refs, prenez des captures d'écran, enregistrez des vidéos. Capacités : grattage Web, remplissage de formulaires, clic, saisie, glisser-déposer, téléchargement de fichiers, exécution JavaScript. Utilisation pour : l'automatisation Web, l'extraction de données, les tests, la navigation des agents, la recherche. Déclencheurs : navigateur, automatisation Web, gratter, naviguer, cliquer, remplir le formulaire, capture d'écran, naviguer sur le Web, dramaturge, navigateur sans tête, agent Web, surfer sur Internet, enregistrer une vidéo
