Exécutez du code Python dans un environnement sécurisé et sandboxé via [inference.sh](https://inference.sh). Préinstallés : NumPy, Pandas, Matplotlib, requests, BeautifulSoup, Selenium, Playwright, MoviePy, Pillow, OpenCV, trimesh et plus de 100 bibliothèques. Utilisez‑le pour : le traitement des données, le scraping web, la manipulation d’images, la création de vidéos, le traitement de modèles 3D, la génération de PDF, les appels d’API, les scripts d’automatisation. Déclencheurs : python, exécuter du code, exécuter un script, scraping web, analyse de données, traitement d’images, montage vidéo, modèles 3D, automatisation, pandas, matplotlib.
