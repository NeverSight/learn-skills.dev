يستخدم Chrome DevTools MCP لفحص ملفات تعريف الارتباط وتصحيح أخطائها واختبارها وحالة الجلسة ومشكلات المصادقة والامتثال لموافقة ملفات تعريف الارتباط. يُستخدم عند تشخيص أخطاء 401/403، أو عمليات إعادة توجيه المصادقة، أو انتهاء صلاحية الجلسة، أو مشكلات رأس ملف تعريف الارتباط/مجموعة ملفات تعريف الارتباط، أو توافق موافقة شعار ملف تعريف الارتباط، أو تحذيرات ملفات تعريف الارتباط/SameSite/ملفات تعريف الارتباط المقسمة لجهة خارجية.
