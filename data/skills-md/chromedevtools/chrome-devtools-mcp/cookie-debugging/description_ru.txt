Использует Chrome DevTools MCP для проверки, отладки и тестирования файлов cookie, состояния сеанса, проблем аутентификации и соблюдения требований согласия на использование файлов cookie. Используйте при диагностике ошибок 401/403, перенаправления аутентификации, истечения срока действия сеанса, проблем с заголовками Cookie/Set-Cookie, соответствия согласия баннера cookie или предупреждений сторонних файлов cookie/SameSite/Partitioned cookie.
