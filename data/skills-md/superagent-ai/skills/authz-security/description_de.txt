Überprüfe den Anwendungscode auf fehlerhafte Autorisierung — IDOR / Broken Object Level Authorization (OWASP API1), Broken Function Level Authorization (API5), Mass Assignment (API3), Lücken in der Multi‑Tenant‑Isolation und Privilegieneskalation. Liest Routen, Controller, Resolver und Datenmodelle offline und meldet das fehlende Eigentümer‑/Rollen‑Check an Datei:Zeile mit einer framework‑konformen Korrektur. Keine laufende Anwendung, keine Zugangsdaten, keine Werkzeuge. Auslöser beim Überprüfen von Endpunkten/Handlern, beim Auditing eines PR‑Diffs, das Routen hinzufügt oder ändert, beim Härten einer Multi‑Tenant‑SaaS oder wenn der Nutzer fragt: „Ist dieser Endpunkt autorisiert?“, „Kann ein Nutzer auf die Daten eines anderen Nutzers zugreifen?“, „IDOR“, „BOLA“ oder „fehlerhafte Zugriffskontrolle“.
