Verifica l'Infrastructure-as-Code per individuare configurazioni di sicurezza errate prima del rilascio — Terraform (.tf/.tfvars/.hcl), CloudFormation/SAM (YAML/JSON), manifest Kubernetes e Helm, e Docker / Docker Compose. Legge l'IaC offline e segnala ogni configurazione errata con file:riga, indicando la gravità (P0–P3) e fornendo uno snippet corretto. Un scanner senza dipendenze effettua il primo passaggio ad alto richiamo; il modello aggiunge valutazione del raggio d'azione e giudizio cross‑resource. Nessuna credenziale cloud, nessun terraform apply, nessun pip install. Si attiva quando si revisiona un piano Terraform prima dell'applicazione, si controllano i manifest K8s/Helm o un Dockerfile prima del deploy, si verifica CloudFormation per bucket S3 pubblici o gruppi di sicurezza aperti, si esegue una revisione di sicurezza pre‑deployment o di conformità (SOC‑2 / PCI‑DSS / ISO‑27001), o quando l'utente chiede “auditare questo Terraform”, “questo bucket S3 è pubblico?”, “questo gruppo di sicurezza è aperto a internet?”, “questo contenitore gira come root?”, “qual è il raggio d'azione se questa infrastruttura è sbagliata?” o “esegui una scansione di sicurezza IaC”.
