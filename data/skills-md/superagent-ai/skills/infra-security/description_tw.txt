在上線前審核基礎設施即代碼 (Infrastructure-as-Code) 的安全錯誤配置 — Terraform (.tf/.tfvars/.hcl)、CloudFormation/SAM (YAML/JSON)、Kubernetes 與 Helm 清單、以及 Docker / Docker Compose。離線讀取 IaC，並於 file:line 位置報告每一個錯誤配置，附上嚴重程度 (P0–P3) 以及修正片段。無相依性的掃描器執行高召回率的第一輪掃描；模型則加入衝擊範圍及跨資源判斷。無需雲端憑證、無需 terraform apply、無需 pip install。可於審查 Terraform 計畫、在部署前審核 K8s/Helm 清單或 Dockerfile、檢查 CloudFormation 中的公開 S3 bucket 或開放的安全群組、進行部署前或合規 (SOC‑2 / PCI‑DSS / ISO‑27001) 安全檢查，或當使用者詢問「審核這個 Terraform」、「這個 S3 bucket 會公開嗎？」、「這個安全群組對網際網路開放嗎？」、「這個容器是以 root 身份執行嗎？」、「如果此基礎設施錯誤，衝擊範圍多大？」或「執行 IaC 安全掃描」時觸發。
