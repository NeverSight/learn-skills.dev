تدقيق البنية التحتية ككود للعثور على الأخطاء الأمنية قبل نشرها — Terraform (.tf/.tfvars/.hcl)، CloudFormation/SAM (YAML/JSON)، ملفات تعريف Kubernetes و Helm، و Docker / Docker Compose. يقرأ الـ IaC دون اتصال ويُبلّغ عن كل خطأ أمان في الشكل file:line مع مستوى الخطورة (P0–P3) ومقتطف مصحح. الممسح الخالي من الاعتماديات يقوم بالمسح الأول عالي الاسترجاع؛ النموذج يضيف تقدير نطاق الضرر وحكم عبر الموارد. لا تحتاج إلى بيانات اعتماد سحابية، ولا تشغيل terraform apply، ولا تثبيت pip. يُفعَّل عند مراجعة خطة Terraform قبل التنفيذ، التدقيق في ملفات K8s/Helm أو Dockerfile قبل النشر، فحص CloudFormation للبحث عن دلاء S3 عامة أو مجموعات أمان مفتوحة، إجراء مراجعة أمان قبل النشر أو للامتثال (SOC‑2 / PCI‑DSS / ISO‑27001)، أو عندما يطرح المستخدم سؤالًا مثل "تدقيق هذا الـ Terraform"، "هل هذا الدلو S3 عامًا؟"، "هل مجموعة الأمان هذه مفتوحة للإنترنت؟"، "هل الحاوية تعمل كجذر؟"، "ما هو نطاق الضرر إذا كانت هذه البنية التحتية خاطئة؟"، أو "تشغيل فحص أمان IaC".
