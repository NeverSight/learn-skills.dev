Auditieren von Infrastruktur‑als‑Code auf Sicherheitsfehlkonfigurationen, bevor es ausgeliefert wird – Terraform (.tf/.tfvars/.hcl), CloudFormation/SAM (YAML/JSON), Kubernetes‑ & Helm‑Manifeste sowie Docker / Docker‑Compose. Liest das IaC offline und meldet jede Fehlkonfiguration mit Datei:Zeile, einer Schwere (P0–P3) und einem korrigierten Snippet. Ein abhängigkeitsloser Scanner führt den hoch‑Recall‑Erstdurchlauf aus; das Modell ergänzt Bewertung des Schadensradius und übergreifende Ressourcen‑Beurteilung. Keine Cloud‑Anmeldedaten, kein terraform apply, kein pip install. Ausgelöst wird es beim Durchsehen eines Terraform‑Plans vor dem Apply, beim Auditen von K8s/Helm‑Manifeste​n oder einer Dockerfile vor dem Deploy, beim Prüfen von CloudFormation auf öffentliche S3‑Buckets oder offene Security‑Groups, bei einer Vor‑Deployment‑ oder Compliance‑Überprüfung (SOC‑2 / PCI‑DSS / ISO‑27001) oder wenn der Benutzer fragt: „prüfe dieses Terraform“, „Ist dieser S3‑Bucket öffentlich?“, „Ist diese Sicherheitsgruppe für das Internet offen?“, „Läuft dieser Container als root?“, „Wie groß wäre der Schadensradius, wenn diese Infrastruktur falsch ist?“, oder „Führe einen IaC‑Sicherheits‑Scan durch“.
