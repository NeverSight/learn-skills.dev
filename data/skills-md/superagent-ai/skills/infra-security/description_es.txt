Audita la Infraestructura como Código en busca de configuraciones erróneas de seguridad antes de que se implemente: Terraform (.tf/.tfvars/.hcl), CloudFormation/SAM (YAML/JSON), manifiestos de Kubernetes y Helm, y Docker / Docker Compose. Lee el IaC sin conexión y reporta cada error de configuración en archivo:línea con una gravedad (P0–P3) y un fragmento corregido. Un escáner sin dependencias realiza la primera pasada de alta recuperación; el modelo añade la evaluación del radio de explosión y el juicio entre recursos. No necesita credenciales de nube, ni ejecutar terraform apply, ni instalar pip. Se activa al revisar un plan de Terraform antes de aplicarlo, al auditar manifiestos K8s/Helm o un Dockerfile antes del despliegue, al comprobar CloudFormation en busca de bucket S3 públicos o grupos de seguridad abiertos, al realizar una revisión de seguridad previa al despliegue o de cumplimiento (SOC-2 / PCI-DSS / ISO-27001), o cuando el usuario pregunta "audita este Terraform", "¿este bucket S3 es público?", "¿este grupo de seguridad está abierto a Internet?", "¿este contenedor se ejecuta como root?", "¿cuál es el radio de explosión si esta infraestructura está equivocada?" o "ejecuta un escaneo de seguridad de IaC".
