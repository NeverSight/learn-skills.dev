インフラストラクチャー・コード（IaC）を出荷前にセキュリティのミスコンフィギュレーションについて監査する — Terraform（.tf/.tfvars/.hcl）、CloudFormation/SAM（YAML/JSON）、Kubernetes および Helm マニフェスト、そして Docker / Docker Compose。IaC をオフラインで読み取り、各ミスコンフィギュレーションをファイル:行番号で報告し、重大度（P0–P3）と修正スニペットを提示する。依存関係のないスキャナーが高リコールの一次スキャンを行い、モデルがブラスト・ラディウスとリソース横断的な判断を加える。クラウド認証情報は不要、terraform apply も不要、pip インストールも不要。Terraform のプランを適用前にレビューする時、K8s/Helm マニフェストや Dockerfile をデプロイ前に監査する時、CloudFormation でパブリック S3 バケットやオープンなセキュリティグループをチェックする時、デプロイ前やコンプライアンス（SOC-2 / PCI-DSS / ISO-27001）セキュリティレビューを行う時、またはユーザーが「この Terraform を監査して」「この S3 バケットは公開されているか？」「このセキュリティグループはインターネットに開いているか？」「このコンテナは root で実行されているか？」「このインフラが間違っていた場合のブラスト・ラディウスは？」「IaC のセキュリティスキャンを実行して」と尋ねた時にトリガーされる。
