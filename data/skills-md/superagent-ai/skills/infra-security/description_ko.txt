배포 전에 인프라스트럭처‑코드(IaC)를 감사하여 보안 잘못된 구성을 찾아냅니다 — Terraform(.tf/.tfvars/.hcl), CloudFormation/SAM(YAML/JSON), Kubernetes 및 Helm 매니페스트, Docker/Docker Compose를 지원합니다. IaC를 오프라인으로 읽고 파일:라인 위치와 심각도(P0–P3) 및 수정된 코드 조각을 보고합니다. 의존성이 없는 스캐너가 높은 재현율의 1차 검사를 수행하고, 모델이 블라스트‑라디우스와 리소스 간 판단을 추가합니다. 클라우드 자격증명 없이, terraform apply 없이, pip install 없이 동작합니다. Terraform 플랜을 적용 전에 검토할 때, K8s/Helm 매니페스트나 Dockerfile을 배포 전에 감사할 때, CloudFormation에서 공개 S3 버킷이나 오픈 보안 그룹을 확인할 때, 사전 배포 또는 SOC‑2 / PCI‑DSS / ISO‑27001 같은 규정 준수 보안 검토를 할 때, 또는 사용자가 “이 Terraform을 감사해줘”, “이 S3 버킷이 공개돼 있나요?”, “이 보안 그룹이 인터넷에 열려 있나요?”, “이 컨테이너가 루트 권한으로 실행되고 있나요?”, “이 인프라가 잘못되면 블라스트 라디우스는 얼마나 될까요?”, “IaC 보안 스캔을 실행해줘” 라고 물을 때 트리거됩니다.
