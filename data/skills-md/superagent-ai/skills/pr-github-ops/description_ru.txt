Применяйте это каждый раз, когда необходимо прокомментировать найденные проблемы сканирования PR, управлять метками PR Superagent, завершать выполнение GitHub check run или избегать публикации находок в виде обычных комментариев в ветке PR. Триггер для любой передачи сканирования sandbox PR Superagent, отвечающей за побочные эффекты GitHub через gh.
