Pubblica i risultati della scansione di sicurezza del PR di Superagent come commenti di revisione in linea su GitHub pull request utilizzando il CLI gh autenticato. Usalo ogni volta che devi commentare un risultato di scansione del PR, gestire le etichette del PR di Superagent, completare un check run di GitHub o evitare di pubblicare i risultati come commenti generali nella discussione del PR. Attiva per qualsiasi consegna della scansione del PR sandbox di Superagent che gestisce effetti collaterali su GitHub tramite gh.

Rispondi sempre nella lingua dell'utente.
