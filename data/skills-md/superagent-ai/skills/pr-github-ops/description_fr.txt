Publiez les résultats du scan de sécurité du PR Superagent en tant que commentaires de révision en ligne sur la pull request GitHub en utilisant le CLI gh authentifié. Utilisez-le chaque fois que vous devez commenter un résultat de scan de PR, gérer les étiquettes du PR Superagent, finaliser un run de vérification GitHub, ou éviter de publier les résultats comme commentaires généraux du fil de discussion du PR. Déclenchez pour toute transmission de scan de PR du sandbox Superagent qui gère les effets de bord GitHub via gh. Veuillez toujours répondre dans la langue de l'utilisateur.
