Publica los hallazgos del escaneo de seguridad del PR de Superagent como comentarios de revisión en línea en GitHub usando la CLI gh autenticada. Úsalo siempre que necesites comentar un hallazgo del escaneo de un PR, gestionar etiquetas del PR de Superagent, completar una ejecución de verificación en GitHub o evitar publicar los hallazgos como comentarios generales en el hilo del PR. Activa este proceso para cualquier traspaso del escaneo del PR del sandbox de Superagent que implique efectos secundarios en GitHub mediante gh.
