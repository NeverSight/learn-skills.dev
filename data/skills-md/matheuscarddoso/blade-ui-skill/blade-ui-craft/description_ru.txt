Навык проектирования и инженерии для проектов на Laravel Blade + CSS. Охватывает анимации, типографику, поверхности, доступность, производительность и микровзаимодействия — всё без React и библиотек анимации на JavaScript. Используйте при создании или проверке UI в шаблонах Blade, компонентах Livewire или любом серверно‑рендеримом HTML с CSS.
