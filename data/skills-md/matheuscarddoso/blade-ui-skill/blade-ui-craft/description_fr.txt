Compétence d’ingénierie du design pour les projets Laravel Blade + CSS. Couvre les animations, la typographie, les surfaces, l’accessibilité, les performances et les micro‑interactions — le tout sans React ni bibliothèques d’animation JavaScript. À utiliser lors de la création ou de la révision d’interfaces UI dans les templates Blade, les composants Livewire ou tout HTML rendu côté serveur avec CSS.
