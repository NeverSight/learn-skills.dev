Utilisez la CLI put.io en tant que consommateur pour l’authentification put.io, les fichiers, les téléchargements, les transferts, le stockage cloud et les appels SDK exposés via la CLI. À utiliser uniquement pour l'interaction en ligne de commande avec put.io ou lorsque l'utilisateur demande explicitement la CLI putio. Ne pas utiliser pour des CLI non liées, des travaux génériques sur TypeScript ou SDK, une inspection put.io basée sur un navigateur ou le développement du référentiel CLI lui-même.
