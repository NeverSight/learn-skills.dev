قم بتشغيل put.io CLI كمستهلك لمصادقة put.io والملفات والتنزيلات والتحويلات والتخزين السحابي ومكالمات SDK المكشوفة من خلال CLI. يُستخدم فقط لتفاعل سطر الأوامر مع put.io أو عندما يطلب المستخدم صراحةً putio CLI. لا تستخدمه مع واجهات سطر الأوامر (CLI) غير ذات الصلة، أو عمل TypeScript أو SDK العام، أو فحص put.io القائم على المستعرض، أو تطوير مستودع سطر الأوامر نفسه.
