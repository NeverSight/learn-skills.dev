Используйте CLI put.io в качестве потребителя для аутентификации put.io, файлов, загрузок, передач, облачного хранилища и вызовов SDK, предоставляемых через CLI. Используйте только для взаимодействия с put.io через командную строку или когда пользователь явно запрашивает putio CLI. Не используйте для несвязанных интерфейсов командной строки, общих работ TypeScript или SDK, проверки put.io на основе браузера или разработки самого репозитория CLI.
