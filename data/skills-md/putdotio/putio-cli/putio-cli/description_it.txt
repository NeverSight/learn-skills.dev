Operare il CLI di put.io come consumatore per l'autenticazione di put.io, file, download, trasferimenti, archiviazione cloud e chiamate SDK esposte tramite il CLI. Usare solo per l'interazione da linea di comando con put.io o quando l'utente richiede esplicitamente il CLI di put.io. Non utilizzare per CLI non correlati, lavoro generico TypeScript o SDK, ispezione di put.io basata su browser o sviluppo del repository del CLI stesso.

Per favore, rispondi sempre nella lingua dell'utente.
