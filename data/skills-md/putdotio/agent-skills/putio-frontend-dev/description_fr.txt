Développez ou examinez les applications destinées aux utilisateurs finaux et les packages frontend partagés appartenant à put.io, y compris l’interface utilisateur, l’état, les tests, la documentation, les bancs de test et la livraison. Utilisez cela uniquement pour le travail dans un dépôt frontend de put.io ou pour des demandes explicites concernant les conventions frontend de put.io. N’utilisez pas cela pour des travaux frontend non liés, l’inspection put.io uniquement via le navigateur, le travail sur le SDK ou le client API, ou les opérations autonomes du consommateur CLI putio ; la configuration d’authentification du banc de test frontend reste dans le périmètre.

Veuillez toujours répondre dans la langue de l’utilisateur.
