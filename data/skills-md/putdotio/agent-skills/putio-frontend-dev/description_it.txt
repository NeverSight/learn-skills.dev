Sviluppa o revisiona le applicazioni per l'utente finale e i pacchetti frontend condivisi di proprietà di put.io, inclusi UI, stato, test, documentazione, harness di test e consegna. Utilizza solo per lavori in un repository frontend di put.io o per richieste esplicite riguardanti le convenzioni frontend di put.io. Non utilizzare per lavori frontend non correlati, ispezioni put.io solo browser, lavoro su SDK o client API, o operazioni autonome del consumatore CLI di putio; la configurazione di autenticazione del test‑harness frontend rimane in ambito. Per favore rispondi sempre nella lingua dell'utente.
