Desarrollar o revisar aplicaciones de usuario final y paquetes frontend compartidos propiedad de put.io, incluyendo interfaz de usuario, estado, pruebas, documentos, arneses de prueba y entrega. Úselo solo para trabajar en un repositorio de frontend de put.io o para solicitudes explícitas de convenciones de frontend de put.io. No lo use para trabajos de frontend no relacionados, inspección put.io solo para navegador, trabajo de cliente SDK o API u operaciones de consumidor putio CLI independientes; la configuración de autenticación de arnés de prueba de frontend permanece dentro del alcance.
