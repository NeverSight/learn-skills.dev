قم بتشغيل شجرة العمل التي يديرها Orca، وسياقات المجلد، والطرفيات، والمستودعات، والأتمتة، والمواد، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المتضمن من خلال سطر أوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل ذلك على شجرة git الخام، أو PTYs العشوائية، أو استخدام الكمبيوتر عندما تكون حالة Orca مشاركة. استخدم استخدام الكمبيوتر فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة مستخدم لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به. يرجى الاستمرار في الرد بلغة المستخدم دائمًا.
