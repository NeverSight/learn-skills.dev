Submit GPU jobs on behalf of the user to JPUShare (share.jedutools.io), receive status, logs, and results, and upload and download files to the lab’s storage space. It does not handle key issuance, lab enrollment, or administrator functions. It is used when the user asks for JPUShare tasks, storage space, GPU server, or queue, such as “Upload a job to JPUShare,” “Get the GPU job result,” “Upload to JPUShare storage space,” “Tell me the GPU server status.” The user’s API key issued on the web (environment variable JPUSHARE_API_KEY) is required.
