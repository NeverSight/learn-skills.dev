JPUShare (share.jedutools.io) invia lavori GPU per conto dell'utente, riceve lo stato, i log e i risultati, e carica e scarica file nello spazio di archiviazione del laboratorio. Non gestisce l’emissione delle chiavi, l’appartenenza al laboratorio o le funzioni di amministratore. Viene utilizzato quando l'utente richiede compiti JPUShare, spazio di archiviazione, server GPU o coda, ad esempio “Carica il lavoro su JPUShare”, “Ottieni il risultato del lavoro GPU”, “Carica su JPUShare storage” o “Fammi sapere lo stato del server GPU”. L'utente ha bisogno della chiave API rilasciata sul web (variabile d'ambiente JPUSHARE_API_KEY).

Per favore rispondi sempre nella lingua dell'utente.
