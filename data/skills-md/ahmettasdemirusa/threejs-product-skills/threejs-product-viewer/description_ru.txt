Создайте интерактивный 3D‑просмотрщик продукта для веб‑сайта с помощью three.js. Просмотрщик загружает модель glTF/GLB, автоматически задаёт кадр, освещает её как в студии и позволяет покупателям вращать и масштабировать её. Используйте, когда пользователь хочет увидеть продукт в 3D, «показать наш продукт в 3D», нужен просмотрщик GLB/glTF, страница продукта на three.js, 3D‑модель для электронной commerce или вращающаяся модель мебели, обуви, бутылок, электроники, шкафов или любого физического продукта. Включён проверенный стартовый шаблон. Для вариантов цвета/материалов см. product-configurator; для встраивания без кода с AR см. model-viewer-ar.
