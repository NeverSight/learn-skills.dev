Orca が管理するワークツリー、フォルダー コンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリー コメント、および Orca の組み込みブラウザを「orca」CLI を通じて操作します。ユーザーが「$orca-cli」、「Orca ワークツリー」、「子ワークツリー」、「ワークツリー内のコーデックス/クロードの生成」、「Orca ターミナルの読み取り/待機/送信」、「ハンドオフ」/「ハンドオーバー」/「これを別のエージェントに渡す」、「Orca ブラウザ」、「Orca アーティファクト」、または「スキルの共有」を言うときに使用します。 Orca 状態が関係する場合は、生の git worktree、アドホック PTY、またはコンピューターの使用よりも優先されます。コンピューターを使用 OS レベルの制御が必要な外部 Windows またはデスクトップ UI にのみ使用し、外部ページには Playwright または CDP を使用します。
