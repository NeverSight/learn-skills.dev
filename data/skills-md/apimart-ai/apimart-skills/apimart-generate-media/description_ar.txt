اكتشف نماذج الصور والفيديو في APIMart، واقرأ توثيق Markdown الحي لكل نموذج ومخطط التوافق، وحمّل صورًا مرجعية محلية، وقدّم طلبات تحويل النص إلى صورة أو نص إلى فيديو أو صورة إلى فيديو، وتحقق من المهام غير المتزامنة عبر عميل API المحلي المدمج لـ APIMart. استخدمه عندما يرغب المستخدم في العثور على نموذج وسائط APIMart، ومعرفة المعلمات المدعومة بدقة، أو تحميل صورة للتوليد، أو إنشاء أو تعديل صور أو فيديوهات، أو استئناف مهمة توليد في APIMart.
