Guida e debugga i Mini Program di WeChat tramite un runtime JavaScript batch veloce con sessioni di automazione persistenti, snapshot semantici di WXML, riferimenti agli elementi, attese, log, screenshot, chiamate API wx e strumenti ufficiali wechatide. Utilizzalo quando un agente deve ispezionare o gestire un Mini Program, riprodurre bug, convalidare i flussi UI o raccogliere prove a runtime.
