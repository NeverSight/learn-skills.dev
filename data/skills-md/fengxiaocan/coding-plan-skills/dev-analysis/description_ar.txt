قم بتحليل وظائف الشيفرة المحددة وتوليد وثيقة مواصفات وظيفية قابلة للصيانة على المدى الطويل. استخدم ذلك عندما يُدخل المستخدم /dev-analysis أو يطلب صراحةً تحليل دالة أو وحدة أو سلسلة استدعاءات أو تدفق بيانات وإنشاء وثائق. هو مسؤول فقط عن فهم الشيفرة، شرح الشيفرة، وإخراج الوثيقة، ولا يجب أن يقوم بتحليل الأخطاء، تحليل المخاطر، تقييم الدين الفني، تقييم جودة الشيفرة، اقتراحات إعادة الهيكلة، أو نصائح التحسين.

يرجى دائمًا الرد بلغة المستخدم.
