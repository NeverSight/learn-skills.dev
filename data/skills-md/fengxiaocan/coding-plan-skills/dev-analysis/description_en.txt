Analyze the specified code functionality and generate a maintainable functional specification document for long-term use. Use this when the user enters /dev-analysis or explicitly requests analysis of a feature, module, call chain, data flow, and documentation consolidation. It is only responsible for understanding the code, explaining the code, and outputting the document; it is prohibited from performing bug analysis, risk analysis, technical debt assessment, code quality evaluation, refactoring suggestions, or optimization recommendations.
