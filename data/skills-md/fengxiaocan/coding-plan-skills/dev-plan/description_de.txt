Entwicklungsplanungsprozess für neue Funktionen und neue Anforderungen. Wird verwendet, wenn ein Benutzer die Implementierung einer Funktion, den Bau eines neuen Moduls, das Hinzufügen von Fähigkeiten oder die Initiierung einer Entwicklungsaufgabe anfordert. Eine strukturierte Anforderungserfassung und -planung muss durchgeführt werden, bevor Code geschrieben wird. Ausgelöst wird der Prozess durch den Befehl /dev-plan.

Bitte immer in der Sprache des Benutzers antworten.
