Decompilazione e analisi inversa dei pacchetti di installazione Android (APK/XAPK) e delle librerie di dipendenza Java/Android (JAR/AAR). Utilizzato per la rilevazione automatica delle impronte dei pacchetti, il controllo e l'installazione delle dipendenze ambientali, la decompilazione multi‑engine (jadx/vineflower), l'analisi dell'architettura e del manifest, il recupero dell'oscuramento Kotlin, il tracciamento delle catene di chiamata, l'estrazione delle interfacce API e la generazione di report di reverse engineering. Da utilizzare quando l'utente inserisce /dev-decompile o richiede esplicitamente di decompilare un APK, analizzare la struttura del pacchetto Android, estrarre le interfacce API di rete, recuperare codice offuscato, tracciare le catene di chiamata o eseguire un'analisi di reverse engineering.
