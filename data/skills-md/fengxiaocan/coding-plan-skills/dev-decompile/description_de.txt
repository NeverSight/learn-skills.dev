Dekompiliere und reverse‑engineere Android-Installationspakete (APK/XAPK) sowie Java/Android‑Abhängigkeitsbibliotheken (JAR/AAR). Wird verwendet für die automatisierte Ausführung von Paketsignatur‑Erkennung, Umgebung‑Abhängigkeitsprüfung und‑Installation, Multi‑Engine‑Dekompilierung (jadx/vineflower), Architektur‑ und Manifest‑Analyse, Wiederherstellung von Kotlin‑Obfuskation, Aufrufketten‑Verfolgung, API‑Schnittstellen‑Extraktion sowie die Erstellung von Reverse‑Engineering‑Berichten. Wird eingesetzt, wenn der Benutzer /dev‑decompile eingibt oder ausdrücklich das Dekompilieren eines APKs anfordert, die Android‑Paketstruktur analysiert, Netzwerk‑API‑Schnittstellen extrahiert, obfuskierten Code wiederherstellt, Aufrufketten verfolgt oder eine Reverse‑Engineering‑Analyse durchführt.
