إلغاء تجميع وتحليل عكسي لحزم تثبيت أندرويد (APK/XAPK) ومكتبات الاعتماد Java/Android (JAR/AAR). تُستخدم لتنفيذ تلقائي لاكتشاف بصمة الحزمة، فحص واعتماد البيئة وتثبيتها، إلغاء التجميع متعدد المحركات (jadx/vineflower)، تحليل البنية والمانيفست، استعادة إخفاء كوتلن، تتبع سلاسل الاستدعاءات، استخراج واجهات برمجة التطبيقات (API)، وتوليد تقارير الهندسة العكسية. عندما يدخل المستخدم /dev‑decompile أو يطلب صراحة إلغاء تجميع APK، أو تحليل بنية حزمة أندرويد، أو استخراج واجهات برمجة التطبيقات الشبكية، أو استعادة الكود المشفر، أو تتبع سلاسل الاستدعاءات، أو إجراء تحليل هندسة عكسية، يجب استخدام ذلك.
