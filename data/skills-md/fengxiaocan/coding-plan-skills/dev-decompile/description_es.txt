Descompilar y analizar inversamente paquetes de instalación de Android (APK/XAPK) y bibliotecas de dependencias Java/Android (JAR/AAR). Se usa para la ejecución automática de detección de huellas de paquetes, detección e instalación de dependencias del entorno, descompilación multiengine (jadx/vineflower), análisis de arquitectura y manifiesto, restauración de ofuscación en Kotlin, trazado de cadenas de llamadas, extracción de interfaces de API y generación de informes de ingeniería inversa. Cuando el usuario ingrese /dev-decompile o solicite explícitamente descompilar un APK, analizar la estructura del paquete Android, extraer interfaces de API de red, restaurar código ofuscado, trazar cadenas de llamadas o realizar un análisis de ingeniería inversa, se debe utilizar esto. Siempre responda en el idioma del usuario.
