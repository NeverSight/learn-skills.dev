Décompilation et analyse inverse des paquets d’installation Android (APK/XAPK) et des bibliothèques de dépendances Java/Android (JAR/AAR). Utilisé pour l’exécution automatisée de la détection d’empreinte de paquets, la vérification et l’installation des dépendances d’environnement, la décompilation multi‑moteur (jadx/vineflower), l’analyse de l’architecture et du manifeste, la restauration de l’obfuscation Kotlin, le suivi des chaînes d’appels, l’extraction d’interfaces API et la consolidation de rapports d’ingénierie inverse. Il est employé lorsque l’utilisateur saisit /dev‑decompile ou demande explicitement de décompiler un APK, d’analyser la structure du paquet Android, d’extraire les interfaces API réseau, de restaurer le code obfusqué, de tracer les chaînes d’appels ou d’effectuer une analyse d’ingénierie inverse.
