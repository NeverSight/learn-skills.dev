Decompile and reverse‑analyze Android installation packages (APK/XAPK) and Java/Android dependency libraries (JAR/AAR). Used for automated package fingerprint detection, environment dependency checking and installation, multi‑engine decompilation (jadx/vineflower), architecture and manifest analysis, Kotlin obfuscation restoration, call‑chain tracing, API interface extraction, and accumulation of reverse‑engineering reports. Apply this when the user inputs /dev-decompile or explicitly requests decompiling an APK, analyzing an Android package structure, extracting network API interfaces, restoring obfuscated code, tracing call chains, or performing reverse‑engineering analysis.
