Android 설치 패키지(APK/XAPK) 및 Java/Android 의존성 라이브러리(JAR/AAR)의 디컴파일 및 역분석. 자동화된 패키지 지문 감지, 환경 의존성 감지 및 설치, 다중 엔진 디컴파일(jadx/vineflower), 아키텍처 및 매니페스트 분석, Kotlin 난독화 복원, 호출 체인 추적, API 인터페이스 추출 및 역공학 보고서 통합에 사용됩니다. 사용자가 /dev‑decompile을 입력하거나 APK를 디컴파일하고 Android 패키지 구조를 분석하며 네트워크 API 인터페이스를 추출하고 난독화된 코드를 복원하거나 호출 체인을 추적하거나 역공학 분석을 수행하려는 경우에 사용해야 합니다.
