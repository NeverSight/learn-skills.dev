Folgen Sie dem Android UI/UX-Design- und Implementierungsworkflow, der dem modernen Designstil und den einheitlichen Designsystem-Spezifikationen von Google Stitch entspricht. Verwenden Sie es, wenn Benutzer das Erstellen von Android-Seiten, das Refactoring der Benutzeroberfläche, das Kapseln gemeinsamer Komponenten, das Schreiben von Compose-Schnittstellen, das Optimieren von Interaktionsgrafiken oder das Überprüfen von Android-Schnittstellenspezifikationen anfordern. Ausgelöst durch den Befehl/dev-android-stitch-design.
