Erstelle ein Entwicklungs‑Change‑Log‑Dokument, nachdem eine Aufgabe abgeschlossen ist. Verwende dies, wenn der Benutzer eine Zusammenfassung der Änderungen anfordert, ein CHANGELOG schreiben oder Änderungen nach Abschluss einer Entwicklungsaufgabe dokumentieren möchte. Ausgelöst durch den Befehl /dev-change. Bitte immer in der Sprache des Benutzers antworten.
