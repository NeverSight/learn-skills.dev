Staging automatico delle modifiche al codice, generazione di messaggi di commit standardizzati, commit locale e push sicuro verso i rami remoti come flusso di lavoro di commit automatizzato. Utilizzato quando l'utente richiede di effettuare il commit del codice, git commit, push del codice, salvare i progressi attuali o sincronizzare con il repository remoto. Attivato dal comando /dev-commit.
