Un flujo de trabajo de commits automatizado que prepara automáticamente los cambios de código, genera mensajes de commit estandarizados, realiza el commit localmente y empuja de forma segura a la rama remota. Se utiliza cuando el usuario solicita hacer commit de código, git commit, empujar código, guardar el progreso actual o sincronizar con el repositorio remoto. Se activa con el comando /dev-commit.
