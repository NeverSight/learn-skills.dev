Mettre automatiquement en scène les modifications de code, générer des messages de commit standardisés, committer localement et pousser en toute sécurité vers la branche distante dans le cadre d’un workflow de commit automatisé. Utilisé lorsque l’utilisateur demande de committer du code, d’exécuter git commit, de pousser le code, d’enregistrer la progression actuelle ou de synchroniser avec le dépôt distant. Déclenché par la commande /dev-commit.
