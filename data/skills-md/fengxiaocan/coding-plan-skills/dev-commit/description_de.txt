Automatisches Stagen von Codeänderungen, Erzeugen standardisierter Commit‑Nachrichten, lokales Committen und sicheres Pushen zu Remote‑Branches als automatisierter Commit‑Workflow. Es wird verwendet, wenn der Benutzer das Committen von Code, git commit, das Pushen von Code, das Speichern des aktuellen Fortschritts oder das Synchronisieren mit dem Remote‑Repository anfordert. Ausgelöst durch den Befehl /dev-commit. Bitte immer in der Sprache des Benutzers antworten.
