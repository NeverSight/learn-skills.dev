Автоматически индексировать изменения кода, генерировать стандартизированные сообщения коммита и выполнять локальный коммит с безопасным пушем в удалённые ветки в рамках автоматизированного рабочего процесса коммита. Используется, когда пользователь запрашивает коммит кода, git commit, пуш кода, сохранение текущего прогресса или синхронизацию с удалённым репозиторием. Активируется командой /dev-commit.
