Un processus d’entretien de débogage structuré pour la correction de bugs et le dépannage. Utilisé lorsqu’un utilisateur demande des corrections de bugs, une investigation d’erreurs, un diagnostic de plantage ou une résolution de problème. Les informations doivent être recueillies étape par étape avant toute modification du code. Activé par la commande /dev-fix.

Veuillez toujours répondre dans la langue de l’utilisateur.
