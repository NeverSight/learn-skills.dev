Структурированный процесс интервью по отладке для исправления ошибок и устранения неполадок. Используется, когда пользователь запрашивает исправление багов, расследование ошибок, диагностику сбоев или решение проблемы. Информация должна собираться пошагово перед внесением каких‑либо изменений в код. Активируется командой /dev-fix.
