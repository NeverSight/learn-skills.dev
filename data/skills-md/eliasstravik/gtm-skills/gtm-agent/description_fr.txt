Se déclenche lorsqu’un utilisateur demande à déployer, configurer, mettre en marche, connecter, vérifier, réparer ou mettre à jour le GTM Agent (l’agent Slack qui exécute ces compétences sur Vercel) pour une organisation, avec des formulations telles que « mettre le gtm‑agent en marche pour Acme », « déployer le GTM agent sur notre Slack », « connecter le projet de workflow pour Acme », « vérifier le déploiement d’Acme » ou « mettre à jour notre GTM agent ». Possède le projet Vercel de l’agent, son connecteur Slack, le projet de workflow, ainsi que le câblage entre eux et le référentiel du workspace. Ne concerne pas le workspace, les ICP, les personas, les vérifications d’adéquation ou les workflows eux‑mêmes, qui appartiennent à gtm‑workspace, gtm‑icp, gtm‑persona, gtm‑qualify‑prospects et gtm‑workflow.
