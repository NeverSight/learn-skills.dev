Se activa cuando un usuario solicita desplegar, configurar, poner en marcha, conectar, verificar, reparar o actualizar GTM Agent (el agente de Slack que ejecuta estas habilidades en Vercel) para una organización, con expresiones como “poner gtm-agent en funcionamiento para Acme”, “desplegar el agente GTM en nuestro Slack”, “conectar el proyecto de flujo de trabajo para Acme”, “verificar el despliegue de Acme” o “actualizar nuestro agente GTM”. Posee el proyecto Vercel del agente, su conector de Slack, el proyecto de flujo de trabajo y el cableado entre ellos y el repositorio del espacio de trabajo. No es para el espacio de trabajo, ICPs, personas, verificaciones de ajuste o los propios flujos de trabajo, que pertenecen a gtm-workspace, gtm-icp, gtm-persona, gtm-qualify-prospects y gtm-workflow.
