يتم التفعيل عندما يطلب المستخدم نشر أو إعداد أو تشغيل أو ربط أو فحص أو إصلاح أو ترقية عميل GTM (عامل Slack الذي ينفذ هذه المهام على Vercel) لمنظمة ما، بصياغة مثل "تشغيل gtm-agent لـ Acme"، "نشر عميل GTM إلى Slack الخاص بنا"، "ربط مشروع سير العمل لـ Acme"، "فحص نشر Acme"، أو "ترقية عميل GTM الخاص بنا". يمتلك مشروع Vercel الخاص بالعميل، موصل Slack، مشروع سير العمل، والربط بينهما ومستودع مساحة العمل. لا يتعلق بمساحة العمل، أو ICPs، أو الشخصيات، أو فحوص الملاءمة، أو سير العمل نفسه، التي تعود إلى gtm-workspace، gtm-icp، gtm-persona، gtm-qualify-prospects، وgtm-workflow.
