Revisiona il codice Rust esistente per idiomaticità, progettazione dell'API, gestione degli errori, sicurezza e manutenibilità, e produce un rapporto prioritizzato in cui ogni riscontro cita la regola violata e fornisce una correzione concreta. Usa questo ogni volta che l'utente chiede di revisionare, auditare, criticare, valutare o “controllare” codice Rust, un crate, un modulo, un file .rs, un diff o una pull request, o chiede cosa c'è di sbagliato nel loro Rust o come renderlo più idiomatico, anche se non utilizza la parola “review”. È associato alla skill rust‑best‑practices, che copre la scrittura di nuovo codice.

Rispondi sempre nella lingua dell'utente.
