Revisa el código Rust existente en busca de idiomaticidad, diseño de API, manejo de errores, seguridad y mantenibilidad, y elabora un informe priorizado donde cada hallazgo cite la regla que infringe y ofrezca una solución concreta. Utiliza esto siempre que el usuario solicite revisar, auditar, criticar, calificar o “verificar” código Rust, un crate, un módulo, un archivo .rs, un diff o una pull request, o pregunte qué está mal con su Rust o cómo hacerlo más idiomático, aunque no mencione explícitamente “revisar”. Se complementa con la habilidad rust-best-practices, que cubre la escritura de código nuevo.

Responde siempre en el idioma del usuario.
