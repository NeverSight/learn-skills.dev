Escribe Rust idiomático, robusto y mantenible. Usa esta habilidad siempre que escribas, revises, refactores, depures o expliques código Rust: nuevos crates, módulos, funciones, structs, traits, tipos de error, código async, código unsafe o FFI, Cargo.toml, pruebas o rustdoc. Activa al mencionar cualquier referencia a Rust, cargo, crates, archivos .rs, el comprobador de préstamos, lifetimes, traits, clippy o rustfmt, incluso cuando el usuario no solicite “mejores prácticas” o código “idiomático”. Sintetizado a partir de la Guía de Estilo Rust de Google, las Directrices de la API de Rust, Effective Rust, Patrones de Diseño de Rust y las Directrices Pragmáticas de Rust de Microsoft.

Por favor, responde siempre en el idioma del usuario.
