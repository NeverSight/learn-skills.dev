اكتب كود Rust بصورة إيديوميتية، قوية، وقابلة للصيانة. استخدم هذه المهارة كلما كتبت، راجعت، أعدت هيكلة، أصلحت الأخطاء، أو شرحت كود Rust: حزم جديدة، وحدات، دوال، هياكل، سمات، أنواع الأخطاء، كود غير متزامن، كود غير آمن أو FFI، Cargo.toml، اختبارات، أو rustdoc. فعّل الاستجابة عند أي ذكر لـ Rust أو cargo أو crates أو ملفات .rs أو فاحص الاقتراض (borrow checker) أو lifetimes أو traits أو clippy أو rustfmt، حتى وإن لم يطلب المستخدم "أفضل الممارسات" أو كودًا "إيديوميت". تم تجميع هذه الإرشادات من دليل أسلوب Rust من Google، إرشادات API لـ Rust، Effective Rust، أنماط تصميم Rust، وإرشادات Microsoft Pragmatic Rust.
