Écrivez du Rust idiomatique, robuste et maintenable. Utilisez cette compétence chaque fois que vous écrivez, révisez, refactorez, déboguez ou expliquez du code Rust : nouveaux crates, modules, fonctions, structs, traits, types d’erreur, code async, code unsafe ou FFI, Cargo.toml, tests ou rustdoc. Déclenchez‑vous à chaque mention de Rust, cargo, crates, fichiers .rs, le borrow checker, les lifetimes, les traits, clippy ou rustfmt, même si l'utilisateur ne demande pas de « meilleures pratiques » ou de code « idiomatique ». Synthétisé à partir du Google Rust Style Guide, des Rust API Guidelines, d’Effective Rust, des Rust Design Patterns et des Microsoft Pragmatic Rust Guidelines.

Veuillez toujours répondre dans la langue de l'utilisateur.
