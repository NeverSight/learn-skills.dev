Используйте этот навык каждый раз, когда пишете, рецензируете, рефакторите, отлаживаете или объясняете Rust‑код: новые crates, модули, функции, структуры, трейты, типы ошибок, асинхронный код, unsafe или FFI‑код, Cargo.toml, тесты или rustdoc. Срабатывайте при любом упоминании Rust, cargo, crates, файлов .rs, проверяющего заимствования, lifetimes, трейтов, clippy или rustfmt, даже если пользователь не запрашивает «лучшие практики» или «идиоматический» код. Синтезировано из Google Rust Style Guide, Rust API Guidelines, Effective Rust, Rust Design Patterns и Microsoft Pragmatic Rust Guidelines.
