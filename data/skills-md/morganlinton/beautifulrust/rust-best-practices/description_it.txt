Scrivi Rust idiomatico, robusto e manutenibile. Usa questa competenza ogni volta che scrivi, rivedi, refattorizzi, fai debugging o spieghi codice Rust: nuovi crate, moduli, funzioni, struct, trait, tipi di errore, codice async, unsafe o FFI, Cargo.toml, test o rustdoc. Attiva il trigger su qualsiasi menzione di Rust, cargo, crate, file .rs, il borrow checker, lifetimes, trait, clippy o rustfmt, anche quando l'utente non richiede “best practices” o codice “idiomatico”. Sintetizzato dalla Google Rust Style Guide, dalle Rust API Guidelines, da Effective Rust, dai Rust Design Patterns e dalle Microsoft Pragmatic Rust Guidelines.

Rispondi sempre nella lingua dell'utente.
