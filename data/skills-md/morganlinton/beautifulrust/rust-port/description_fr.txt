Porter du code depuis C, C++, Python, Go, JavaScript ou TypeScript vers du Rust idiomatique tout en conservant le comportement d'origine : ownership au lieu de gestion manuelle de la mémoire, Result à la place des codes d’erreur et des exceptions, enums au lieu d’entiers de drapeaux et de chaînes magiques, et des tests qui prouvent que le port correspond. Utilisez cela chaque fois que l’utilisateur demande de porter, traduire, convertir, migrer ou réécrire du code en Rust (« réécrire ceci en Rust », « à quoi cela ressemblerait en Rust », « déplacer ce module vers Rust »), même s’il ne dit pas « porter ». S’associe avec la compétence rust-best-practices, qui couvre le style du code cible.

Veuillez toujours répondre dans la langue de l’utilisateur.
