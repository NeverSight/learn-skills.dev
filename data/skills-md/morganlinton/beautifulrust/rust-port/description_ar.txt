انقل الكود من C أو C++ أو Python أو Go أو JavaScript أو TypeScript إلى Rust بأسلوبه الأصلي مع الحفاظ على السلوك نفسه: الملكية بدلاً من إدارة الذاكرة يدوياً، Result بدلاً من رموز الأخطاء والاستثناءات، enums بدلاً من الأعداد التي تمثل علامات أو السلاسل السحرية، واختبارات تثبت أن النقل يطابق الأصل. استخدم هذا كلما طلب المستخدم نقل، ترجمة، تحويل، ترحيل أو إعادة كتابة الكود إلى Rust ("أعد كتابة هذا بـ Rust"، "كيف سيبدو هذا بـ Rust"، "انقل هذه الوحدة إلى Rust")، حتى لو لم يذكر كلمة "نقل". يتكامل مع مهارة rust‑best‑practices التي تغطي نمط الكود المستهدف.
