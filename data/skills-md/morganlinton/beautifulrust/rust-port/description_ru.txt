Перенесите код из C, C++, Python, Go, JavaScript или TypeScript в идиоматичный Rust, сохраняющий оригинальное поведение: владение вместо ручного управления памятью, Result вместо кодов ошибок и исключений, enum вместо флаговых целочисленных значений и магических строк, а также тесты, доказывающие, что перенос соответствует оригиналу. Используйте это каждый раз, когда пользователь просит портировать, переводить, конвертировать, мигрировать или переписать код на Rust («перепиши это на Rust», «как это будет выглядеть в Rust», «перенеси этот модуль в Rust»), даже если он не использует слово «порт». Сочетается с навыком rust‑best‑practices, который покрывает стиль целевого кода.

Всегда отвечайте на языке пользователя.
