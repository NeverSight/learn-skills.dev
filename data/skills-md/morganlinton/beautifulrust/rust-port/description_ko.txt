C, C++, Python, Go, JavaScript 또는 TypeScript의 코드를 원본 동작을 유지하는 관용적인 Rust로 포팅합니다: 수동 메모리 대신 소유권, 오류 코드와 예외 대신 Result, 플래그 정수와 매직 문자열 대신 열거형, 그리고 포팅이 일치함을 증명하는 테스트를 포함합니다. 사용자가 코드를 Rust로 포팅, 번역, 변환, 마이그레이션, 재작성(예: “Rust로 다시 쓰기”, “Rust에서는 어떻게 보일까”, “이 모듈을 Rust로 옮기기”)을 요청할 때마다 이 지침을 사용합니다. 사용자가 “port”라는 단어를 쓰지 않아도 적용됩니다. rust-best-practices 스킬과 함께 사용되어 목표 코드의 스타일을 다룹니다.

항상 사용자의 언어로 응답하세요.
