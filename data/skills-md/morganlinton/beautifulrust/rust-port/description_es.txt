Portar código de C, C++, Python, Go, JavaScript o TypeScript a Rust idiomático que conserve el comportamiento original: ownership en lugar de gestión manual de memoria, Result en lugar de códigos de error y excepciones, enums en lugar de enteros de banderas y cadenas mágicas, y pruebas que demuestren que la portación coincide. Usa esto siempre que el usuario solicite portar, traducir, convertir, migrar o reescribir código en Rust ("rewrite this in Rust", "what would this look like in Rust", "move this module to Rust"), incluso si no dice "port". Se combina con la habilidad rust-best-practices, que cubre el estilo del código objetivo.

Por favor, responde siempre en el idioma del usuario.
