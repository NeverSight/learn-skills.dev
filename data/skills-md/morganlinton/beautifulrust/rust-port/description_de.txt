Portiere Code von C, C++, Python, Go, JavaScript oder TypeScript in idiomatisches Rust, das das ursprüngliche Verhalten beibehält: Ownership anstelle von manueller Speicherverwaltung, Result anstelle von Fehlercodes und Ausnahmen, Enums anstelle von Flag‑Ints und magischen Strings und Tests, die beweisen, dass die Portierung übereinstimmt. Verwende dies immer, wenn der Nutzer bittet, Code nach Rust zu portieren, zu übersetzen, zu konvertieren, zu migrieren oder umzuschreiben („rewrite this in Rust“, „what would this look like in Rust“, „move this module to Rust“), selbst wenn er nicht „port“ sagt. Ergänzt die rust-best-practices‑Fähigkeit, die den Stil des Zielcodes abdeckt.

Bitte antworte stets in der Sprache des Nutzers.
