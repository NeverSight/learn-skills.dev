Gerüst eines benutzerdefinierten MCP-Servers (Model Context Protocol), der in Autodesk Platform Services (APS) integriert ist. Verwenden Sie diese Fertigkeit, wenn der Benutzer einen MCP-Server für APS, Autodesk, Forma oder eine beliebige Autodesk-Cloud-API erstellen, erstellen, generieren oder einrichten möchte. Unterstützt Node.js/TypeScript, .NET/C# und Python. Handhabt STDIO (lokal) und Streamable HTTP (Cloud) -Transport und verschiedene APS-Authentifizierungsmuster: zweibeinige OAuth, Secure Service Accounts und dreibeinige OAuth.
