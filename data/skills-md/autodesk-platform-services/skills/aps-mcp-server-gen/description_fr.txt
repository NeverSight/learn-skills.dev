Échafaudage d'un serveur MCP (Model Context Protocol) personnalisé qui s'intègre à Autodesk Platform Services (APS). Utilisez cette compétence lorsque l'utilisateur souhaite créer, générer ou configurer un serveur MCP pour APS, Autodesk, Forma ou toute API cloud Autodesk. Prend en charge Node.js/TypeScript, .NET/C# et Python. Gère le transport STDIO (local) et Streamable HTTP (cloud), et divers modèles d'authentification APS : OAuth à 2 pattes, comptes de service sécurisés et OAuth à 3 pattes.
