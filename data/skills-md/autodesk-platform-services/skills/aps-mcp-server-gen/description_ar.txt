قم بإنشاء خادم MCP (بروتوكول سياق النموذج) مخصص يتكامل مع خدمات منصة Autodesk (APS). استخدم هذه المهارة عندما يرغب المستخدم في بناء أو إنشاء أو توليد أو إعداد خادم MCP لـ APS أو Autodesk أو Forma أو أي واجهة برمجة تطبيقات سحابية من Autodesk. يدعم Node.js/TypeScript و .NET/C# و Python. يتعامل مع نقل STDIO (محلي) و HTTP القابل للبث (سحابي) ومجموعة متنوعة من أنماط مصادقة APS: OAuth ذو الطرفين، حسابات الخدمة الآمنة، و OAuth ذو الثلاثة أطراف.
