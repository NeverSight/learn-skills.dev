Создайте каркас пользовательского сервера MCP (Model Context Protocol), интегрирующегося с Autodesk Platform Services (APS). Используйте эту возможность, когда пользователь хочет построить, создать, сгенерировать или настроить сервер MCP для APS, Autodesk, Forma или любого облачного API Autodesk. Поддерживает Node.js/TypeScript, .NET/C# и Python. Обрабатывает транспорт через STDIO (локально) и потоковый HTTP (в облаке), а также различные схемы аутентификации APS: 2‑ступенчатый OAuth, защищённые сервисные аккаунты и 3‑ступенчатый OAuth.

Пожалуйста, всегда отвечайте на языке пользователя.
