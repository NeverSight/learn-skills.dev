Genera lo scheletro di un server MCP (Model Context Protocol) personalizzato che si integra con i Autodesk Platform Services (APS). Usa questa funzionalità quando l'utente vuole costruire, creare, generare o impostare un server MCP per APS, Autodesk, Forma o qualsiasi API cloud di Autodesk. Supporta Node.js/TypeScript, .NET/C# e Python. Gestisce il trasporto STDIO (locale) e HTTP streamabile (cloud), e vari schemi di autenticazione APS: OAuth a due gambe, Account di Servizio Sicuri e OAuth a tre gambe.

Rispondi sempre nella lingua dell'utente.
