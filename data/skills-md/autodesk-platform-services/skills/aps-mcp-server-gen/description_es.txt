Scaffold un servidor MCP (Model Context Protocol) personalizado que se integra con Autodesk Platform Services (APS). Utilice esta habilidad cuando el usuario desee crear, crear, generar o configurar un servidor MCP para APS, Autodesk, Forma o cualquier API de nube de Autodesk. Admite Node.js/TypeScript, .NET/C# y Python. Maneja el transporte STDIO (local) y Streamable HTTP (nube), y varios patrones de autenticación APS: OAuth de 2 patas, cuentas de servicio seguras y OAuth de 3 patas.
