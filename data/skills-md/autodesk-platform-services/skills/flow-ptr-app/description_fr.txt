Guide pour le développement d'une nouvelle application de suivi de la production de flux (FPTR) /boîte à outils ShotGrid (sgtk) selon une approche axée sur les spécifications. Déclencheurs activés : créez une nouvelle application FPTR, une nouvelle application de suivi de la production de flux, une nouvelle application Toolkit, une application tk-multi-starter, un développement d'application sgtk, une application tank install_app, une application tank switch_app, une configuration de pipeline de bac à sable dev, une application ShotGrid Toolkit.
