Guía para desarrollar una nueva aplicación de seguimiento de producción de flujo (FPTR) / ShotGrid Toolkit (sgtk) siguiendo un enfoque basado en especificaciones. Se activa: crea una nueva aplicación FPTR, una nueva aplicación de seguimiento de producción de flujo, una nueva aplicación Toolkit, tk-multi-starterapp, desarrollo de aplicaciones sgtk, tank install_app, tank switch_app, configuración de tuberías de sandbox de desarrollo, aplicación ShotGrid Toolkit.
