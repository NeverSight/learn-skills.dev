Скелет проекта Agentic ObjectARX для AutoCAD 2027 / Visual Studio 2026. Заменяет сломанный мастер .vsz VsWizardEngine скриптом PowerShell, который генерирует идентичные C++‑файлы проекта. Работает с новыми проектами ARX/DBX/CRX и мастерами классов дополнений (Jig, Reactors, Custom Object, MFC, .NET Wrapper, COM Wrapper, Dynamic Property).
