Struttura di progetto Agentic ObjectARX per AutoCAD 2027 / Visual Studio 2026. Sostituisce il wizard .vsz VsWizardEngine danneggiato con uno script PowerShell che genera file di progetto C++ identici. Funziona per nuovi progetti ARX/DBX/CRX e wizard di classi aggiuntive (Jig, Reattori, Oggetto personalizzato, MFC, Wrapper .NET, Wrapper COM, Proprietà dinamica).
