Genere una Acción Roboto funcional y verificada a partir de una descripción en lenguaje natural de un trabajo de procesamiento de datos. Use esta habilidad siempre que el usuario quiera crear, construir o estructurar una Acción Roboto, incluso si solo describe la tarea ("etiquetar cada conjunto de datos cuyos registros mencionen X", "extraer video de estos rosbags") sin decir "acción". Cubre la descomposición de requisitos, una entrevista para resolver ambigüedades (omitida con --yolo), la generación de la estructura, la implementación y la verificación mediante una invocación de prueba local. No es para desplegar o invocar acciones que ya existen, ni para preguntas generales sobre el SDK de Roboto.

Por favor, responda siempre en el idioma del usuario.
