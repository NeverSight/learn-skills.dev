Создайте работающий, проверенный Roboto Action на основе описания задачи обработки данных на естественном языке. Используйте эту возможность каждый раз, когда пользователь хочет создать, построить или набросать Roboto Action, даже если он лишь описывает задачу («пометить каждый набор данных, в логах которого упоминается X», «извлечь видео из этих rosbags») без упоминания слова «action». Охватывает разложение требований, интервью для разрешения неоднозначностей (пропускается при параметре --yolo), создание шаблона, реализацию и проверку посредством локального сухого прогона. Не предназначено для развёртывания или вызова уже существующих действий, а также не относится к общим вопросам SDK Roboto.

Пожалуйста, всегда отвечайте на языке пользователя.
