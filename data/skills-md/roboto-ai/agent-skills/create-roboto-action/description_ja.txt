データ処理ジョブの自然言語記述から、動作する検証済みの Roboto Action を生成します。ユーザーが Roboto Action を作成、構築、またはスキャフォールドしたいときは、たとえ「action」と言及せずにタスクだけ（例：「X がログに記載されたすべてのデータセットにタグ付けする」「これらの rosbag からビデオを抽出する」）を説明した場合でも、このスキルを使用します。要件分解、曖昧さ解消のインタビュー（--yolo オプション下ではスキップ）、スキャフォールディング、実装、そしてローカルでのドライラン実行による検証を含みます。既存のアクションをデプロイまたは呼び出すこと、または一般的な Roboto SDK に関する質問には使用しません。常にユーザーの言語で応答してください。
