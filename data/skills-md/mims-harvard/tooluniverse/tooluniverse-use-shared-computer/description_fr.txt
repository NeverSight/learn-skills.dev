Utilisez des outils qui s’exécutent sur l’ordinateur d’un collègue (par exemple, des modèles sur le GPU de son laboratoire) ou des outils publiés par d’autres scientifiques, via ToolUniverse. Couvre l’utilisation d’un code de partage commençant par TU-SHARE-, la recherche des outils et leur exécution. À utiliser lorsque l'utilisateur dispose d'un code TU-SHARE- ou d'une invitation, qu'il dit « utiliser le modèle de mon collègue », « exécuter l'outil sur le GPU du laboratoire », ou qu'il demande quels outils partagés ou communautaires sont disponibles.
