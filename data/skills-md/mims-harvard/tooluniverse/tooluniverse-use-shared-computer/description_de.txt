Verwenden Sie Tools, die auf dem Computer eines Kollegen ausgeführt werden (z. B. Modelle auf seiner Labor-GPU), oder Tools, die andere Wissenschaftler über ToolUniverse veröffentlicht haben. Behandelt das Einlösen eines Freigabecodes, der mit TU-SHARE- beginnt, das Auffinden der Tools und deren Ausführung. Verwenden Sie diese Option, wenn der Benutzer über einen TU-SHARE-Code oder eine Einladung verfügt, „das Modell meines Kollegen verwenden“ oder „das Tool auf der GPU des Labors ausführen“ angibt oder fragt, welche gemeinsam genutzten Tools oder Community-Tools verfügbar sind.
