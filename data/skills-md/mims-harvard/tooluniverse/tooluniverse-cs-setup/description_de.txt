Installieren oder aktualisieren Sie ToolUniverse in Claude Science – erstellen Sie die Conda-Umgebung, installieren Sie das ToolUniverse-Pip-Paket und (er)stellen Sie die ToolUniverse-Research-Skill, indem Sie die aktuelle Workflow-Bibliothek von GitHub abrufen. Verwenden Sie diese Option für die Ersteinrichtung, das Upgrade der ToolUniverse-Version, die Aktualisierung der gebündelten Workflows nach einer Upstream-Version oder die Neuinstallation auf einem neuen Computer.
