Instale o actualice ToolUniverse en Claude Science: cree el entorno conda, instale el paquete pip de ToolUniverse y (re)compile la habilidad tooluniverse-research obteniendo la biblioteca de flujos de trabajo actual de GitHub. Úsalo para la configuración inicial, para actualizar la versión de ToolUniverse, para actualizar los flujos de trabajo incluidos después de una versión anterior o para reinstalarlo en un equipo nuevo.
