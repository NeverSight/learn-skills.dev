Implementiert das Syncfusion .NET MAUI TimePicker (SfTimePicker)-Steuerelement. Verwenden Sie es bei der Implementierung von Zeitauswahl, TimePicker‑Steuerelementen oder einer Zeiteingabe‑UI in .NET MAUI. Dieses Feature deckt Installation, Konfiguration, Zeitformate (14 vordefinierte Formate), Picker‑Modi (Dialog/RelativeDialog), Intervalle, Zeitbeschränkungen, Schleifen, Ereignisse und Anpassungen ab.
