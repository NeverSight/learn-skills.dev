Реализует элемент управления Syncfusion .NET MAUI TimePicker (SfTimePicker). Используется при реализации выбора времени, элементов управления выбора времени или пользовательского интерфейса ввода времени в .NET MAUI. Этот навык охватывает установку, конфигурацию, форматы времени (14 предопределённых форматов), режимы выбора (Dialog/RelativeDialog), интервалы, ограничения времени, зацикливание, события и настройку.
