Implementa el Splitter de cuadrícula de Syncfusion® .NET MAUI (SfGridSplitter), permitiendo la creación de diseños multi‑paneles redimensionables y colapsables en aplicaciones .NET MAUI. Úsalo para crear diseños de panel de control, interfaces de espacio de trabajo o aplicaciones de vista dividida que requieran gestión dinámica de paneles, funcionalidad de arrastrar‑para‑redimensionar y control programático.
