Implementa lo Splitter a Griglia Syncfusion® per .NET MAUI (SfGridSplitter), consentendo la creazione di layout multi‑pannello ridimensionabili e comprimibili nelle applicazioni .NET MAUI. Usalo per costruire layout di dashboard, interfacce di workspace o applicazioni split‑view che richiedono una gestione dinamica dei pannelli, funzionalità di trascinamento per il ridimensionamento e controllo programmatico.
