Implementiert den Syncfusion® .NET MAUI Grid Splitter (SfGridSplitter) und ermöglicht die Erstellung von skalierbaren und zusammenklappbaren Mehrpaneel‑Layouts in .NET MAUI‑Anwendungen. Verwenden Sie ihn zum Erstellen von Dashboard‑Layouts, Workspace‑Oberflächen oder Split‑View‑Anwendungen, die ein dynamisches Paneel‑Management, Drag‑to‑Resize‑Funktionalität und programmatische Steuerung erfordern.
