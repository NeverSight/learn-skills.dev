Реализует Splitter сетки Syncfusion® .NET MAUI (SfGridSplitter), позволяя создавать изменяемые в размере и сворачиваемые многопанельные макеты в приложениях .NET MAUI. Используйте его для построения панелей приборных панелей, интерфейсов рабочих пространств или приложений с разделённым представлением, которым требуется динамическое управление панелями, функция перетаскивания для изменения размера и программный контроль.
