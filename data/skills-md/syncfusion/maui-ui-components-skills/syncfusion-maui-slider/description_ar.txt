تنفّذ عنصر التحكم Syncfusion .NET MAUI Slider (SfSlider). يُستخدم عند العمل مع أشرطة التمرير، اختيار القيم الرقمية، أو عناصر التحكم التفاعلية للقيمة. تغطي هذه المهارة التثبيت، تكوين المسار، التسميات مع التنسيق، العلامات والفواصل، تلميحات الأدوات، تخصيص المقبض، الاختيار المتقطع باستخدام StepSize، التحديثات المؤجلة، وتأثير LiquidGlass.
