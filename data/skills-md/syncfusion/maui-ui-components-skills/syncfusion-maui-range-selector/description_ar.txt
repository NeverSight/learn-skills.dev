ينفّذ مكوّن محدّد النطاق Syncfusion .NET MAUI (SfRangeSelector). يُستخدم عند العمل مع اختيار النطاق مع المخططات المدمجة، إدخال النطاق الرقمي، خصائص RangeStart/RangeEnd، تخصيص المسار، أو تنسيق المقبض في .NET MAUI. يغطي تكوين أداة التلميح، تنسيق العلامات، الفواصل/الخطوط، أوضاع الاختيار، الأحداث، وإدراج SfCartesianChart داخل عنصر التحكم بالنطاق.
