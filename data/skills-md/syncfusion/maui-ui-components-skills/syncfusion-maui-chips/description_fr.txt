Implémente les puces Syncfusion .NET MAUI (SfChip ou SfChipGroup). À utiliser lors de la manipulation de puces, d’étiquettes, de contrôles d’étiquettes, de puces de sélection, de puces d’entrée ou de puces de filtrage dans les applications .NET MAUI. Couvre les types de puces, la personnalisation des puces, les événements de puces, la sélection de puces, les groupes de puces, la suppression de puces, les puces avec bouton de fermeture et la liaison de données des puces.
