將 Syncfusion EJ2 React 元件遷移至 Syncfusion Pure React 元件。當使用者擁有 EJ2 React 參考檔案（例如 `@syncfusion/ej2-react-buttons`、`ButtonComponent`、`cssClass`、未加前綴的事件屬性、`<Inject services=[...]/>`、`<XxxDirective>` 模式、類別元件的生命週期方法，或 `enableRtl`/`enableMask`/`e-flat`/`e-success` 風格屬性）且希望將它們轉換為新的 `@syncfusion/react-*` 套件時使用。無論目標元件位於不同套件或保持相同顯示名稱，只要使用者程式碼引用了這些模式，都應套用此技巧。
