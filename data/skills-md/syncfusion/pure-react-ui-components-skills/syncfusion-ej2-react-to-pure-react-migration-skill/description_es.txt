Migrar componentes Syncfusion EJ2 React a componentes Syncfusion Pure React. Utilizar cuando un usuario tiene archivos de referencia EJ2 React (p. ej. `@syncfusion/ej2-react-buttons`, `ButtonComponent`, `cssClass`, propiedades de eventos sin prefijo, `<Inject services=[...]/>`, patrones `<XxxDirective>`, métodos del ciclo de vida de componentes de clase o propiedades de estilo `enableRtl`/`enableMask`/`e-flat`/`e-success`) y desea convertirlos a los nuevos paquetes `@syncfusion/react-*`. Aplicar esta habilidad siempre que el código del usuario haga referencia a estos patrones, incluso si el componente de destino se encuentra en un paquete diferente o conserva el mismo nombre visible.
