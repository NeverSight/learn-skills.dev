ترحيل مكونات Syncfusion EJ2 React إلى مكونات Syncfusion Pure React. استخدم هذا عندما يكون لدى المستخدم ملفات مرجعية لـ EJ2 React (مثل `@syncfusion/ej2-react-buttons`، `ButtonComponent`، `cssClass`، خصائص الأحداث غير المسبقّة، أنماط `<Inject services=[...]/>`، `<XxxDirective>`، أساليب دورة حياة المكوّنات ذات الفئة، أو خصائص النمط `enableRtl`/`enableMask`/`e-flat`/`e-success`) ويريد تحويلها إلى الحزم الجديدة `@syncfusion/react-*`. طبّق هذه المهارة كلما أشار كود المستخدم إلى هذه الأنماط، حتى لو كان المكوّن المستهدف موجودًا في حزمة مختلفة أو يحتفظ بنفس اسم العرض.

يرجى الرد دائمًا بلغة المستخدم.
