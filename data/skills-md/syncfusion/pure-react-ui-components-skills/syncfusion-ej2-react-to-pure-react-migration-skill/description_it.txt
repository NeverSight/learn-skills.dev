Migrare i componenti Syncfusion EJ2 React in componenti Syncfusion Pure React. Usare quando un utente ha file di riferimento EJ2 React (ad esempio `@syncfusion/ej2-react-buttons`, `ButtonComponent`, `cssClass`, proprietà evento senza prefisso, `<Inject services=[...]/>`, pattern `<XxxDirective>`, metodi del ciclo di vita dei componenti di classe, o proprietà di stile come `enableRtl`/`enableMask`/`e-flat`/`e-success`) e desidera convertirli nei nuovi pacchetti `@syncfusion/react-*`. Applicare questa competenza ogni volta che il codice dell'utente fa riferimento a questi pattern, anche se il componente di destinazione si trova in un pacchetto diverso o mantiene lo stesso nome visuale.
