将 Syncfusion EJ2 React 组件迁移到 Syncfusion Pure React 组件。当用户拥有 EJ2 React 引用文件（例如 `@syncfusion/ej2-react-buttons`、`ButtonComponent`、`cssClass`、未加前缀的事件属性、`<Inject services=[...]/>`、`<XxxDirective>` 模式、类组件生命周期方法，或 `enableRtl`/`enableMask`/`e-flat`/`e-success` 样式属性）并希望将它们转换为新的 `@syncfusion/react-*` 包时使用。每当用户代码引用这些模式时，都应应用此技巧，即使目标组件位于不同的包中或保持相同的显示名称。
