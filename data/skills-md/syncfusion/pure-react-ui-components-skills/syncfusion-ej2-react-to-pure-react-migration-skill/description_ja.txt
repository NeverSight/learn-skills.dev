Syncfusion EJ2 React コンポーネントを Syncfusion Pure React コンポーネントに移行します。ユーザーが EJ2 React の参照ファイル（例: `@syncfusion/ej2-react-buttons`、`ButtonComponent`、`cssClass`、プレフィックスなしのイベントプロップ、`<Inject services=[...]/>`、`<XxxDirective>` パターン、クラスコンポーネントのライフサイクルメソッド、または `enableRtl`、`enableMask`、`e-flat`、`e-success` スタイルプロップ）を持ち、新しい `@syncfusion/react-*` パッケージに変換したい場合に使用します。ユーザーコードがこれらのパターンを参照している限り、宛先コンポーネントが別パッケージにあっても、表示名が同じでも、このスキルを適用してください。
