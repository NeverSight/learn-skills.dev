Migriere Syncfusion EJ2 React‑Komponenten zu Syncfusion Pure React‑Komponenten. Verwende dies, wenn ein Benutzer EJ2‑React‑Referenzdateien hat (z. B. `@syncfusion/ej2-react-buttons`, `ButtonComponent`, `cssClass`, nicht vorangestellte Ereignis‑Props, `<Inject services=[...]/>`, `<XxxDirective>`‑Muster, Klassenkomponenten‑Lebenszyklus‑Methoden oder `enableRtl`/`enableMask`/`e‑flat`/`e‑success`‑Stil‑Props) und sie in die neuen `@syncfusion/react-*`‑Pakete umwandeln möchte. Wende diese Fähigkeit immer dann an, wenn der Benutzer‑Code diese Muster referenziert, selbst wenn die Zielkomponente in einem anderen Paket liegt oder denselben Anzeigenamen behält.

Bitte immer in der Sprache des Benutzers antworten.
