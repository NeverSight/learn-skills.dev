Migrez les composants Syncfusion EJ2 React vers les composants Syncfusion Pure React. Utilisez‑le lorsqu’un utilisateur possède des fichiers de référence EJ2 React (par exemple `@syncfusion/ej2-react-buttons`, `ButtonComponent`, `cssClass`, des propriétés d’événement non préfixées, les modèles `<Inject services=[...]/>`, `<XxxDirective>`, les méthodes du cycle de vie des composants de classe, ou les propriétés de style `enableRtl`/`enableMask`/`e-flat`/`e-success`) et souhaite les convertir vers les nouveaux packages `@syncfusion/react-*`. Appliquez cette compétence chaque fois que le code de l’utilisateur fait référence à ces modèles, même si le composant de destination se trouve dans un package différent ou conserve le même nom d’affichage. Veuillez toujours répondre dans la langue de l'utilisateur.
