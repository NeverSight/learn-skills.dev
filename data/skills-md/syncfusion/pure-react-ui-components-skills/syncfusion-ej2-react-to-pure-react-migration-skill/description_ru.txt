Перенести компоненты Syncfusion EJ2 React в чистые React‑компоненты Syncfusion. Применять, когда у пользователя есть ссылки на файлы EJ2 React (например, `@syncfusion/ej2-react-buttons`, `ButtonComponent`, `cssClass`, свойства событий без префикса, шаблоны `<Inject services=[...]/>`, `<XxxDirective>`, методы жизненного цикла class‑компонентов или свойства стиля `enableRtl`/`enableMask`/`e-flat`/`e-success`) и он хочет преобразовать их в новые пакеты `@syncfusion/react-*`. Применяйте этот навык каждый раз, когда код пользователя содержит такие шаблоны, даже если целевой компонент находится в другом пакете или сохраняет то же отображаемое имя. Пожалуйста, всегда отвечайте на языке пользователя.
