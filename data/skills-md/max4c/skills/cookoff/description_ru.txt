Автоматически подготовьте план, спецификацию или заявку, запустив Claude и Codex в качестве пар допрашивающий/ответчик вместо опроса пользователя. Два режима — ретрансляционный (переключение между Клодом и Кодексом) и параллельный (два замененных потока объединены в одну спецификацию). Создает предварительно разжеванный артефакт, в котором пользователь только просматривает результат, а не сидит на собеседовании. Используйте этот навык всякий раз, когда пользователь говорит «приготовить», «предварительно приготовить на гриле», «приготовь это на гриле по кодексу», «двойной гриль», «приготовь на гриле без меня», «запусти меня на гриле с помощью кодекса», «перекрестный допрос этого плана» или хочет, чтобы работа по устранению неоднозначности была выполнена автономно, прежде чем он проверит. Также используйте, когда у пользователя есть план/спецификация/PRD, который обычно проходит через max:grill-me, но явно хочет пропустить собеседование. Поддерживает `--to-tickets` для выдачи подготовленной спецификации в качестве билетов агента Dahso, готовых для `/go`, и `--to-tickets --go` для прямой цепочки к `dahso:go` без паузы проверки.
