自動「烤」計畫、規格或工單，透過將 Claude 與 Codex 作為審訊者/回答者配對，而非與使用者面談。提供兩種模式——傳遞模式（Claude 與 Codex 之間的迭代往返）以及平行模式（兩條互換的訊流合併為單一規格）。產出事先「已咀嚼」的成果，使用者只需檢閱結果，無需參與訪談。當使用者說「cookoff」、「pre-grill this」、「have codex grill it」、「dual grill」、「grill this without me」、「run grill-me with codex」、 「cross-examine this plan」或希望在他們審閱前自行完成模糊度解決工作時，就使用此技能。亦在使用者擁有本應經過 max:grill‑me 的計畫／規格／PRD，但明確表示想跳過自行面談時使用。支持 `--to-tickets` 參數，將烤好的規格輸出為 Dahso Agent Tickets，供 `/go` 使用；以及 `--to-tickets --go`，直接鏈接至 `dahso:go`，不需審閱暫停。
