Eine Grillsitzung, die einen Plan anhand des dokumentierten Domänenmodells des Projekts einem Stresstest unterzieht – die unscharfe Terminologie schärft, sie mit dem vorhandenen Glossar vergleicht, sie mit dem Code vergleicht und die Dokumentation (CONTEXT.md, ADRs) inline aktualisiert, während sich Entscheidungen herauskristallisieren. Die domänenbewusste Variante von grill-me – verwenden Sie diese stattdessen, wenn das Repo über ein CONTEXT.md-Glossar oder docs/adr/decision-Datensätze verfügt (oder verfügen sollte). Zu den Auslösern gehören „Überprüfen Sie dies mit Dokumenten“, „Testen Sie dies anhand unseres Domänenmodells“, „Passt dies zu unserer Sprache“, „Überprüfen Sie dies anhand unseres Glossars“, „Überprüfen Sie dies und aktualisieren Sie die Dokumente“ oder immer dann, wenn ein nicht trivialer Plan mit den dokumentierten Entscheidungen des Projekts in Einklang gebracht werden muss.
