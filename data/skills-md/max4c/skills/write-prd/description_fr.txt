Transformez une idée vague en un PRD concret grâce à une interview utilisateur, à l’exploration du code et à une rédaction socratique. Il passe par la porte d’ambiguïté « grill‑me » avant de sortir. Utilisez‑le lorsque l’utilisateur veut rédiger un PRD, spécifier une fonctionnalité, transformer la transcription d’une réunion en plan, ou dit « write‑prd », « write a PRD », « spec this out », « let's PRD this », « turn this into a spec ». Il est également invoqué par des orchestrateurs de workflow comme bugbook:flow pour produire la phase de spécification d’un workflow plus large.

Veuillez toujours répondre dans la langue de l’utilisateur.
