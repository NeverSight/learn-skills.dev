يُستخدم عند إنشاء "زجاج سائل" شفاف أو واجهة مستخدم للشكل الزجاجي على الويب باستخدام CSS - لوحات أو بطاقات أو أشرطة تنقل أو أزرار أو نماذج متجمدة/غير واضحة تعمل على تشويش ما خلفها وتلوينه. يتم تشغيلها على `backdrop-filter`، أو `blur()`، أو الزجاج المصنفر، أو الأسطح الشفافة/الأكريليكية، أو الزجاج بنمط Apple أو iOS-26 على الويب، أو لوحات المعلومات الداكنة ذات الخلفيات المحيطة المتوهجة، أو نقل مظهر iOS Liquid Glass إلى HTML/CSS/Tailwind. يغطي Vanilla CSS وTailwind v4 وReact. يتم تشغيله حتى لو لم يقل المستخدم "الشكل الزجاجي" — "البطاقة المتجمدة" و"اللوحة الشفافة غير الواضحة" و"شريط التنقل الزجاجي" و"الرأس غير الواضح الشفاف" جميعها مؤهلة. ليس مخصصًا لنظام التشغيل iOS/SwiftUI الأصلي (استخدم "تصميم الزجاج السائل").
