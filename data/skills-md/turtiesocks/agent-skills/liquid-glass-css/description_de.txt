Verwenden Sie diese Option, wenn Sie eine durchscheinende „Flüssigglas“- oder Glassmorphismus-Benutzeroberfläche im Web mit CSS erstellen – mattierte/unscharfe Bedienfelder, Karten, Navigationsleisten, Schaltflächen oder Modalitäten, die das, was sich dahinter befindet, verwischen und einfärben. Löst auf „Backdrop-Filter“, „Blur()“, Milchglas, durchscheinenden/Acryloberflächen, Glas im Apple-Stil oder iOS-26-Stil im Web, dunklen Dashboards mit leuchtenden Umgebungshintergründen oder der Portierung eines iOS-Liquid-Glass-Looks auf HTML/CSS/Tailwind aus. Deckt Vanilla CSS, Tailwind v4 und React ab. Wird auch dann ausgelöst, wenn der Benutzer nicht „Glasmorphismus“ sagt – „gefrostete Karte“, „verschwommenes transparentes Panel“, „Glas-Navigationsleiste“ und „durchsichtiger verschwommener Header“ sind alle geeignet. Nicht für natives iOS/SwiftUI (verwenden Sie „Liquid-Glass-Design“).
