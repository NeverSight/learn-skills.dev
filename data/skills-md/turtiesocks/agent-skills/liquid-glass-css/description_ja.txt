CSS を使用して Web 上に半透明の「液体ガラス」またはグラスモーフィズム UI を構築する場合に使用します。つまり、背後にあるものをぼかしたり色付けしたつや消し/ぼやけたパネル、カード、ナビゲーションバー、ボタン、モーダルなどです。 「backdrop-filter」、「blur()」、すりガラス、半透明/アクリル表面、Web 上の Apple スタイルまたは iOS 26 スタイルのガラス、輝くアンビエント背景のある暗いダッシュボード、または iOS 液体ガラスの外観の HTML/CSS/Tailwind への移植でトリガーされます。バニラ CSS、Tailwind v4、React をカバーします。ユーザーが「glassmorphism」と言わなくてもトリガーされます。「つや消しカード」、「ぼやけた透明パネル」、「ガラス製ナビゲーションバー」、「ぼやけたシースルーヘッダー」はすべて対象となります。ネイティブ iOS/SwiftUI には対応していません (`liquid-glass-design` を使用してください)。
