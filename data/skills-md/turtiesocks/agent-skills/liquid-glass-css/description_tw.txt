當使用 CSS 在網路上建立半透明「液體玻璃」或玻璃形態 UI 時使用 - 磨砂/模糊面板、卡片、導覽列、按鈕或模態，對它們後面的內容進行模糊和著色。在「backdrop-filter」、「blur()」、磨砂玻璃、半透明/丙烯酸表面、Web 上的 Apple 風格或 iOS-26 風格玻璃、具有發光環境背景的深色儀表板或將 iOS 液體玻璃外觀移植到 HTML/CSS/Tailwind 上觸發。涵蓋原生 CSS、Tailwind v4 和 React。即使使用者沒有說「玻璃形狀」也會觸發——「磨砂卡片」、「模糊透明面板」、「玻璃導航列」、「透明模糊標題」都符合資格。不適用於本機 iOS/SwiftUI（使用「liquid-glass-design」）。
