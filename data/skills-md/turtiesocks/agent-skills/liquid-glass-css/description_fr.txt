À utiliser lors de la création d'une interface utilisateur translucide en « verre liquide » ou en morphisme de verre sur le Web avec CSS : panneaux, cartes, barres de navigation, boutons ou modaux givrés/flou qui brouillent et teintent ce qui se trouve derrière eux. Se déclenche sur `backdrop-filter`, `blur()`, verre dépoli, surfaces translucides/acryliques, verre de style Apple ou iOS-26 sur le Web, tableaux de bord sombres avec arrière-plans ambiants brillants ou portage d'un look iOS Liquid Glass vers HTML/CSS/Tailwind. Couvre le CSS Vanilla, Tailwind v4 et React. Déclenchez même si l'utilisateur ne dit pas "glassmorphisme" - "carte givrée", "panneau transparent flou", "barre de navigation en verre", "en-tête flou transparent" sont tous admissibles. Pas pour iOS/SwiftUI natif (utilisez « liquid-glass-design »).
