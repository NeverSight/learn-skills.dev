Da utilizzare durante la creazione di un'interfaccia utente traslucida in "vetro liquido" o glassmorphism sul Web con CSS: pannelli, schede, barre di navigazione, pulsanti o elementi modali smerigliati/sfocati che sfocano e colorano ciò che c'è dietro. Si attiva su `filtro di sfondo`, `sfocatura()`, vetro smerigliato, superfici traslucide/acriliche, vetro in stile Apple o iOS-26 sul Web, dashboard scuri con sfondi ambientali luminosi o conversione di un aspetto di vetro liquido iOS in HTML/CSS/Tailwind. Copre CSS vanilla, Tailwind v4 e React. Si attiva anche se l'utente non dice "glassmorphism": "carta smerigliata", "pannello trasparente sfocato", "barra di navigazione in vetro", "intestazione sfocata trasparente" sono tutte valide. Non per iOS/SwiftUI nativo (usa `liquid-glass-design`).
