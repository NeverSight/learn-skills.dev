当使用 CSS 在网络上构建半透明“液体玻璃”或玻璃形态 UI 时使用 - 磨砂/模糊面板、卡片、导航栏、按钮或模态，对它们后面的内容进行模糊和着色。在“backdrop-filter”、“blur()”、磨砂玻璃、半透明/丙烯酸表面、Web 上的 Apple 风格或 iOS-26 风格玻璃、具有发光环境背景的深色仪表板或将 iOS 液体玻璃外观移植到 HTML/CSS/Tailwind 上触发。涵盖原生 CSS、Tailwind v4 和 React。即使用户没有说“玻璃形态”也会触发——“磨砂卡片”、“模糊透明面板”、“玻璃导航栏”、“透明模糊标题”都符合条件。不适用于本机 iOS/SwiftUI（使用“liquid-glass-design”）。
