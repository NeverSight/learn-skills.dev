تشغيل شجر العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والمواد، ومشاركة المهارات، وتعليقات شجر العمل، والمتصفح المدمج في Orca عبر سطر أوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على شجرة git الخام، أو PTYs العارضة، أو استخدام الكمبيوتر عندما تكون حالة Orca متضمنة. استخدم "استخدام الكمبيوتر" فقط عندما تكون هناك نافذة مرئية تحتاج إلى التحكم في واجهة GUI ولا يمكن لسطر الأوامر أو نظام الملفات أو API القيام بذلك. يرجى الرد دائمًا بلغة المستخدم.
