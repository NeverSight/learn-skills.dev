Orca‑verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Kompetenzteilung, Arbeitsbaum‑Kommentare und Orcas integrierten Browser über das `orca`‑CLI bedienen. Verwenden Sie es, wenn der Nutzer „$orca‑cli“, „Orca‑Arbeitsbaum“, „Child‑Arbeitsbaum“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca‑Browser“, „orca artifacts“ oder „share skills“ sagt. Bevorzugen Sie es gegenüber rohem Git‑Arbeitsbaum, ad‑hoc‑PTYs oder Computer‑Use, wenn Orca‑Zustand involviert ist. Setzen Sie Computer‑Use nur ein, wenn ein sichtbares Fenster GUI‑Steuerung erfordert, die ein CLI, das Dateisystem oder eine API nicht leisten kann.
