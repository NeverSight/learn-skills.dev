Operare i worktree gestiti da Orca, i contesti di cartelle, i terminali, i repository, le automazioni, gli artefatti, la condivisione di competenze, i commenti sui worktree e il browser integrato di Orca tramite il CLI `orca`. Usare quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferirlo rispetto a un git worktree grezzo, PTY ad hoc o Uso del Computer quando è coinvolto lo stato di Orca. Usare l'Uso del Computer solo quando una finestra visibile richiede un controllo GUI che né CLI, né filesystem, né API possono fornire.

Rispondere sempre nella lingua dell'utente.
