Sviluppa, firma, distribuisci e verifica le app autonome OpenHarmony le cui API o permessi possono richiedere `hos_system_app`, un APL elevato, ACL/provisioning o un'API di sistema Full SDK. Usa per ispezioni privilegiate o controllo di altre app o dello stato protetto del dispositivo e per gli errori `Not System App`, quindi verifica i requisiti rispetto ai metadati SDK esatti. Per le capacità pubbliche di app ordinarie utilizza `ohos-app-dev`; per i componenti dell’albero sorgente OHOS utilizza `ohos-system-dev`.

Rispondi sempre nella lingua dell'utente.
