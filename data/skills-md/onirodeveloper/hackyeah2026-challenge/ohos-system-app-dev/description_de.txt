Entwickeln, signieren, bereitstellen und prüfen Sie eigenständige OpenHarmony‑Apps, deren APIs oder Berechtigungen möglicherweise `hos_system_app`, ein erhöhtes APL, ACL/Provisionierung oder eine Full‑SDK‑System‑API erfordern. Verwenden Sie sie für privilegierte Inspektion oder Kontrolle anderer Apps bzw. geschützten Gerätezustands sowie für `Not System App`‑Fehler und überprüfen Sie anschließend die Anforderungen anhand der genauen SDK‑Metadaten. Für öffentliche, gewöhnliche App‑Funktionen nutzen Sie `ohos-app-dev`; für OHOS‑Quellbaum‑Komponenten verwenden Sie `ohos-system-dev`.
