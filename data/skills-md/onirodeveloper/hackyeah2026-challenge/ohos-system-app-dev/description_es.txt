Desarrolla, firma, despliega y verifica aplicaciones independientes de OpenHarmony cuyas APIs o permisos puedan requerir `hos_system_app`, un APL elevado, ACL/provisionamiento o una API del sistema completa del SDK. Úsalo para inspección privilegiada o control de otras aplicaciones o del estado protegido del dispositivo y para fallos de `Not System App`; luego verifica los requisitos con los metadatos exactos del SDK. Para capacidades públicas de aplicaciones ordinarias usa `ohos-app-dev`; para componentes del árbol de código fuente de OHOS usa `ohos-system-dev`.
