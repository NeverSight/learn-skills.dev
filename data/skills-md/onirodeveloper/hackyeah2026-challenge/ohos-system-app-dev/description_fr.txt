Développer, signer, déployer et vérifier des applications OpenHarmony autonomes dont les API ou les autorisations peuvent nécessiter « HOS_System_app », une APL élevée, une ACL/provisioning ou une API système SDK complète. Utilisez-le pour l'inspection ou le contrôle privilégiés d'autres applications ou de l'état de l'appareil protégé et pour les défaillances « Not System App », puis vérifiez les exigences par rapport aux métadonnées SDK exactes. Pour les capacités publiques des applications ordinaires, utilisez « ohos-app-dev » ; pour les composants de l'arbre source OHOS, utilisez « ohos-system-dev ».
