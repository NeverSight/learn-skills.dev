Développez, signez, déployez et vérifiez des applications autonomes OpenHarmony dont les API ou les autorisations peuvent nécessiter `hos_system_app`, un APL élevé, ACL/approvisionnement ou une API système Full SDK. Utilisez-les pour l’inspection privilégiée ou le contrôle d’autres applications ou de l’état protégé de l’appareil et pour les échecs `Not System App`, puis vérifiez les exigences par rapport aux métadonnées exactes du SDK. Pour les capacités publiques d’applications ordinaires, utilisez `ohos-app-dev` ; pour les composants de l’arborescence source OHOS, utilisez `ohos-system-dev`.
