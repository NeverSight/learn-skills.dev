Разрабатывайте, подписывайте, развертывайте и проверяйте самостоятельные приложения OpenHarmony, чьи API или разрешения могут требовать `hos_system_app`, повышенный APL, ACL/провизию или системный API полного SDK. Используйте их для привилегированного инспектирования или управления другими приложениями или защищённым состоянием устройства и при ошибках `Not System App`, затем проверяйте требования по точным метаданным SDK. Для публичных возможностей обычных приложений используйте `ohos-app-dev`; для компонентов исходного дерева OHOS — `ohos-system-dev`.

Пожалуйста, всегда отвечайте на языке пользователя.
