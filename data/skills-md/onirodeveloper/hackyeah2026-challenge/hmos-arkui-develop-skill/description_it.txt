Assistente di sviluppo ArkUI per il lavoro UI su HarmonyOS. Utilizza hmos-arkts-knowledge-retriever per l'evidenza delle API e fornisce vincoli di codifica e riferimenti alle migliori pratiche.  
Attiva quando:  
(1) L'utente richiede una pagina o un componente ArkUI  
(2) L'utente richiede modifiche a un progetto .ets esistente  
(3) L'utente fornisce un errore o uno screenshot e richiede una correzione ArkUI  
(4) L'utente menziona HarmonyOS/ArkUI/ArkTS/.ets  
(5) L'utente richiede lavoro UI eseguibile che coinvolga stato, componenti o layout  

Collaborazione con hmos-arkui-mvvm-pattern:  
- Per decisioni di architettura, caricare prima hmos-arkui-mvvm-pattern, quindi seguire le sue indicazioni durante la generazione del codice.  
- Il pattern mvvm produce il piano architetturale; questa skill ricerca le API, genera il codice e verifica la compilazione.  
- La generazione del codice è guidata da questa skill; la rifattorizzazione dell'architettura è guidata dal pattern mvvm.  

Rispondi sempre nella lingua dell'utente.
