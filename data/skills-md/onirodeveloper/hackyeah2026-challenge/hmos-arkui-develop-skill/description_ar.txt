مساعد تطوير ArkUI لعمل واجهة مستخدم HarmonyOS. يستخدم hmos-arkts-knowledge-retriever لأدلة API ويوفر قيود الترميز وإشارات لأفضل الممارسات.  
التفعيل عندما:  
(1) يطلب المستخدم صفحة أو مكوّن ArkUI  
(2) يطلب المستخدم تغييرات على مشروع .ets موجود  
(3) يقدم المستخدم خطأً أو لقطة شاشة ويطلب إصلاح ArkUI  
(4) يذكر المستخدم HarmonyOS/ArkUI/ArkTS/.ets  
(5) يطلب المستخدم عمل واجهة قابلة للتنفيذ تشمل الحالة أو المكونات أو التخطيط  

التعاون مع hmos-arkui-mvvm-pattern:  
- لاتخاذ قرارات البنية،حمّل hmos-arkui-mvvm-pattern أولاً، ثم اتبع إرشاداته أثناء إنشاء الكود.  
- ينتج mvvm-pattern خطة البنية؛ هذه المهارة تبحث في الـ APIs، تُنشئ الكود، وتتحقق من تجميعه.  
- إنشاء الكود يقوده هذه المهارة؛ وإعادة هيكلة البنية يقودها mvvm-pattern.  

يرجى دائمًا الرد بلغة المستخدم.
