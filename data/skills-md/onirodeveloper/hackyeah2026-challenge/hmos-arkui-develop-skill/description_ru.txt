Помощник разработки ArkUI для работы с пользовательским интерфейсом HarmonyOS. Использует hmos-arkts-knowledge-retriever для получения доказательств API и предоставляет ограничения кодирования и ссылки на лучшие практики.  
Срабатывает, когда:  
(1) Пользователь запрашивает страницу или компонент ArkUI  
(2) Пользователь запрашивает изменения в существующем проекте .ets  
(3) Пользователь предоставляет ошибку или скриншот и просит исправить ArkUI  
(4) Пользователь упоминает HarmonyOS/ArkUI/ArkTS/.ets  
(5) Пользователь запрашивает исполняемую работу UI, связанную с состоянием, компонентами или макетом  

Сотрудничество с hmos-arkui-mvvm-pattern:  
- Для решений по архитектуре сначала загрузите hmos-arkui-mvvm-pattern, затем следуйте его рекомендациям при генерации кода.  
- mvvm-pattern создает план архитектуры; этот навык ищет API, генерирует код и проверяет компиляцию.  
- Генерацией кода руководит этот навык; рефакторинг архитектуры — mvvm-pattern.  

Пожалуйста, всегда отвечайте на языке пользователя.
