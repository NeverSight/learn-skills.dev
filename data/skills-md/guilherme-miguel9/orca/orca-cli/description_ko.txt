`orca` CLI를 통해 Orca가 관리하는 작업 트리, 폴더 컨텍스트, 터미널, 레포지토리, 자동화, 아티팩트, 스킬 공유, 작업 트리 코멘트 및 Orca 내장 브라우저를 운영합니다. 사용자가 “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts”, 또는 “share skills”라고 말할 때 이를 사용하십시오. Orca 상태가 관련된 경우 원시 git worktree, 임시 PTY, 혹은 Computer Use보다 이를 우선합니다. CLI, 파일 시스템, API로 처리할 수 없는 눈에 보이는 창의 GUI 제어가 필요할 때만 Computer Use를 사용합니다.
