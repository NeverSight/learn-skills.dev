Operar los worktrees gestionados por Orca, contextos de carpetas, terminales, repositorios, automatizaciones, artefactos, intercambio de habilidades, comentarios de worktree y el navegador integrado de Orca a través del CLI `orca`. Utilizar cuando el usuario diga "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferirlo sobre un worktree git puro, PTY ad hoc o Uso de la Computadora cuando esté involucrado el estado de Orca. Utilizar Uso de la Computadora solo cuando una ventana visible requiera control GUI que la CLI, el sistema de archivos o la API no puedan hacer.
