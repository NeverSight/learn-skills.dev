تشغيل أشجار العمل المُدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، ومستودعات الأكواد، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر سطر أوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، أو "Orca worktree"، أو "child worktree"، أو "spawn codex/claude in a worktree"، أو "read/wait/send Orca terminal"، أو "handoff" / "handover" / "give this to another agent"، أو "Orca browser"، أو "orca artifacts"، أو "share skills". يفضل ذلك على استخدام شجرة عمل git الخام، أو PTYs المؤقتة، أو Computer Use عندما تكون حالة Orca متضمنة. استخدم طريقة Computer Use فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو الـ API القيام بذلك. يرجى دائمًا الرد بلغة المستخدم.
