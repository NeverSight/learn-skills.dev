Utilisez lorsqu'on vous demande ce qu'une exécution d'agent-qa a fait, pourquoi une étape a réussi ou échoué, ce que les captures d'écran, la console ou le réseau d'une exécution ont montré, quel agent de connaissances-qa a appris ou servi, d'où vient un enregistrement de connaissances ou quelles exécutions existent. Lit les exécutions, les preuves et les connaissances via les outils MCP agent-qa ou la CLI agent-qa avec --json, jamais via les fichiers .agent-qa, SQLite ou les fichiers d'index.
