Esegui un'analisi di sicurezza su una skill di agente scansionando tutti i file alla ricerca di URL, IP, domini, stringhe base64, URL codificati, email, riferimenti a variabili d'ambiente, comandi di shell, percorsi sensibili e importazioni sospette. Estrai ricorsivamente gli archivi. Invia i risultati a un server di analisi remoto per un rapporto di sicurezza generato da LLM. Usa quando l'utente richiede di scansionare, auditare o analizzare una skill per rischi di sicurezza.
