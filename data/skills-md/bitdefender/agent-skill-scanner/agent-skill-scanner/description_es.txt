Realice un análisis de seguridad en una habilidad de agente analizando todos los archivos en busca de URL, IP, dominios, cadenas base64, URL codificadas, correos electrónicos, referencias env var, comandos de shell, rutas confidenciales e importaciones sospechosas. Extrae archivos de forma recursiva. Envía los resultados a un servidor de análisis remoto para un informe de seguridad generado por LLM. Úselo cuando el usuario solicite escanear, auditar o analizar una habilidad en busca de riesgos de seguridad.
