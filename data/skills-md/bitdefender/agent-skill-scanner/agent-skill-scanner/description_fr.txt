Effectuez une analyse de sécurité sur une compétence d'agent en analysant tous les fichiers à la recherche d'URL, d'adresses IP, de domaines, de chaînes base64, d'URL codées, d'e-mails, de références env var, de commandes shell, de chemins sensibles et d'importations suspectes. Extrait de manière récursive les archives. Soumet les résultats à un serveur d'analyse distant pour un rapport de sécurité généré par LLM. À utiliser lorsque l'utilisateur demande de numériser, d'auditer ou d'analyser une compétence pour les risques de sécurité.
