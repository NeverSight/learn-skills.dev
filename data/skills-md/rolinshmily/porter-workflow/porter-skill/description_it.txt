Pipeline automatizzata di localizzazione video per YouTube, X/Twitter, Instagram, TikTok e Bilibili. Scarica un video, produce sottotitoli bilingue o solo cinesi e incorpora un video pronto per la pubblicazione. Usala ogni volta che l'utente chiede di scaricare un video, generare o tradurre sottotitoli, trascrivere l'audio, creare una versione con sottotitoli cinesi (熟肉) o localizzare media in streaming. Richiede Python >=3.11 e FFmpeg con libass. La trascrizione richiede una chiave API Whisper compatibile con OpenAI o il CLI VideoCaptioner; la traduzione non richiede chiave.  

Rispondi sempre nella lingua dell'utente.
