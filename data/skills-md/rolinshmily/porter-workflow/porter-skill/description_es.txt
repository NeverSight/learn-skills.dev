Canal de localización automática de videos para YouTube, X/Twitter, Instagram, TikTok y Bilibili. Descarga un video, genera subtítulos bilingües o solo en chino y crea un video listo para publicar. Utilízalo siempre que el usuario solicite descargar un video, generar o traducir subtítulos, transcribir audio, hacer una versión subtitulada en chino (熟肉) o localizar contenido multimedia. Requiere Python >=3.11 y FFmpeg con libass. La transcripción necesita una clave API de Whisper compatible con OpenAI o la CLI VideoCaptioner; la traducción no requiere clave.

Por favor, responde siempre en el idioma del usuario.
