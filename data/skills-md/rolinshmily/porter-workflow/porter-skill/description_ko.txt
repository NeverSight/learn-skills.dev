YouTube, X/Twitter, Instagram, TikTok 및 Bilibili용 자동 영상 현지화 파이프라인입니다. 영상을 다운로드하고, 이중언어 또는 중국어 전용 자막을 생성하며, 공개 준비가 된 영상을 인코딩합니다. 사용자가 영상을 다운로드하거나, 자막을 생성·번역하거나, 오디오를 전사하거나, 중국어 자막(熟肉) 버전을 만들거나, 스트리밍 미디어를 현지화하고자 할 때 언제든지 사용할 수 있습니다. Python >= 3.11 및 libass가 포함된 FFmpeg가 필요합니다. 전사에는 OpenAI 호환 Whisper API 키 또는 VideoCaptioner CLI가 필요하고, 번역에는 키가 필요하지 않습니다.
