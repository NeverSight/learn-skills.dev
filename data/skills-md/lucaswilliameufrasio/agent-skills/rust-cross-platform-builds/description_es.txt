Acelerar y reforzar las compilaciones de versiones de Rust para un sistema operativo o una arquitectura de CPU diferentes. Utilícelo siempre que una implementación de ARM64/contenedor tarde mucho tiempo en compilar Rust en QEMU, el usuario mencione Zig o cargo-zigbuild, un enlazador cruzado/sysroot, la compatibilidad con glibc o solicite una comparación de los tiempos de compilación, incluso si solo pide que la implementación sea más rápida.
