Beschleunigen und härten Sie Rust-Release-Builds für ein anderes Betriebssystem oder eine andere CPU-Architektur. Verwenden Sie diese Option, wenn bei einer ARM64-/Container-Bereitstellung lange Zeit für die Kompilierung von Rust unter QEMU benötigt wird, der Benutzer Zig oder cargo-zigbuild, einen Cross-Linker/Sysroot, die glibc-Kompatibilität erwähnt oder um einen Vergleich der Build-Zeiten bittet – auch wenn er nur darum bittet, die Bereitstellung zu beschleunigen.
