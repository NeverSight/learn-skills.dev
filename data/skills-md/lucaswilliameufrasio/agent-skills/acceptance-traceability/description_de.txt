Wandeln Sie eine Anfrage, ein Problem oder eine Spezifikation in beobachtbare Abnahmekriterien um und ordnen Sie jedes Kriterium den Nachweisen für die Implementierung und Verifizierung zu. Verwenden Sie diese Methode, wenn Sie eine Lieferung planen, prüfen, ob eine Funktion die Anforderung erfüllt, Änderungen des Umfangs überprüfen oder einen durch Nachweise belegten Lieferbericht erstellen. Unterscheiden Sie zwischen implementierten, verifizierten, blockierten und ausgeschlossenen Arbeiten; grüne Builds allein belegen keine Abnahme. Erfinden Sie keine Produktentscheidungen oder -genehmigungen.
