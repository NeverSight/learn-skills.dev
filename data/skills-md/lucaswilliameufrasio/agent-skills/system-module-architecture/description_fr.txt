Planifier et concevoir des systèmes logiciels complets dans n'importe quel domaine ou contexte, y compris les produits destinés aux clients, les outils internes, le Web, les applications mobiles et les API. À utiliser avant de lancer un système, un domaine de fonctionnalités, un workflow ou une extension majeure, et pas uniquement pour les revues d'architecture. Commencez par les utilisateurs, les tâches et les parcours de bout en bout ; déduisez-en les écrans, les modules, les contrats et les tranches d’implémentation. Évitez les écrans tout-en-un et l’architecture centrée sur les pages.
