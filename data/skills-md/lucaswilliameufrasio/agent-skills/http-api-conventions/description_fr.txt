Concevoir, implémenter ou examiner des API HTTP/JSON. À utiliser pour les contrats de requête/réponse, la validation, la gestion des erreurs, la pagination, l'authentification ou la mise en cache. Appliquer des formats de transmission cohérents, omettre les valeurs absentes au lieu d'encoder null, des codes d'erreur spécifiques, une sémantique de statut précise et des limites sécurisées.
