Planen und führen Sie eine sichere Git-Bereitstellung durch – von der Vorbereitung des Branches über Commit, Push, Pull-Anfrage, CI bis hin zur Übergabe des Releases. Verwenden Sie diese Vorgehensweise, wenn Sie aufgefordert werden, eine Funktion/einen Fix bereitzustellen, einen Commit oder einen PR vorzubereiten, eine Reihe von Änderungen freizugeben oder auf Review-Kommentare zum eigenen Pull Request des Autors/der Autorin zu reagieren. Machen Sie sich mit dem Workflow des Repositorys vertraut, anstatt von bestimmten Zweignamen, Ticket-Systemen oder Merge-Richtlinien auszugehen.
