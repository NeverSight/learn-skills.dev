Préparez des importations de données existantes reproductibles et des hooks de prédéploiement qui préservent les enregistrements opérationnels existants. À utiliser pour les importations de stockage d'objets vers une base de données, les commandes de migration pouvant être réexécutées, les politiques de gestion des conflits et la vérification des importations bloquant le déploiement sans exécuter d'opérations à distance non autorisées.
