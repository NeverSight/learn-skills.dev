Diagnostizieren und verbessern Sie die Anwendungsleistung oder Ressourceneffizienz mithilfe von Messdaten. Wenden Sie diese Vorgehensweise immer dann an, wenn der Benutzer angibt, dass eine App/API langsam ist, eine Verschlechterung der Leistung oder einen Engpass meldet, um die Optimierung/Feinabstimmung des Codes bittet oder einen höheren Durchsatz oder eine geringere Latenz, CPU-Auslastung, Speicherauslastung oder Kosten wünscht – selbst wenn er vor der Bereitstellung eines Profils eine bestimmte Codeänderung wünscht. Reproduzieren Sie die Workload, lokalisieren Sie den Engpass, ändern Sie jeweils eine Ursache und überprüfen Sie vergleichbare Durchläufe.
