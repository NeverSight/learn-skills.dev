Wählen, validieren oder aktualisieren Sie die Version eines Projekts gemäß Semantic Versioning 2.0.0. Verwenden Sie diese Option, wenn ein Benutzer darum bittet, eine Paket-/Anwendungsversion zu aktualisieren, freizugeben, zu taggen, zu veröffentlichen oder zu ändern, und wenn für einen Release-Plan eine kompatibilitätsbasierte Versionsempfehlung erforderlich ist.
