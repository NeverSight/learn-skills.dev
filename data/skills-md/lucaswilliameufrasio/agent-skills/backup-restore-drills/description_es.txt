Diseñar, implementar, revisar o probar de forma segura la copia de seguridad y la restauración de las aplicaciones. Utilícelo para archivos cifrados, coherencia de bases de datos/objetos, kits de recuperación, simulacros de recuperación ante desastres, afirmaciones de RPO/RTO o para comprobar si un comando de copia de seguridad correcto realmente demuestra la capacidad de recuperación. Separe los simulacros aislados de las restauraciones destructivas o en tiempo real, que requieren una aprobación explícita.
