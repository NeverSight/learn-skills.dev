Démêlez les bases de code existantes en identifiant les couplages cachés, les dépendances inutiles et les éléments superflus, puis en effectuant un refactoring par tranches vérifiées et préservant le comportement. À utiliser lorsqu'il est demandé de démêler un projet, de réduire le coût des modifications entre modules, de supprimer les cas particuliers d'architecture ou d'effectuer un nettoyage structurel. Fonctionne avec tous les langages, frameworks, systèmes de compilation, dépendances et packages ; découvrez la pile et les contrats réels au lieu d’imposer une architecture préférée.
