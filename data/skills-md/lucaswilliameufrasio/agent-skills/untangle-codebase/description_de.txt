Entwirren Sie vorhandene Codebasen, indem Sie versteckte Kopplungen, unnötige Abhängigkeiten und überflüssigen Code aufspüren und anschließend in verifizierten, verhaltenserhaltenden Abschnitten refaktorieren. Verwenden Sie diese Methode, wenn Sie aufgefordert werden, ein Projekt zu entwirren, die Kosten für Änderungen über mehrere Module hinweg zu senken, architektonische Sonderfälle zu beseitigen oder eine strukturelle Bereinigung durchzuführen. Funktioniert sprachen-, Framework-, Build-System-, Abhängigkeits- und Paket-übergreifend; ermittelt den tatsächlichen Stack und die tatsächlichen Verträge, anstatt eine bevorzugte Architektur vorzugeben.
