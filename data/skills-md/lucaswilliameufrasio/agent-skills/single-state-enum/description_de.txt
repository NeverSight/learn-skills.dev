Steuert den UI-Status (Modale, Sheets, Drawer, Tabs, Schritte, Ansichtsmodi) mit einem einzigen State, der eine diskriminierte Vereinigung/einen Enum enthält, anstelle von vielen unabhängigen Boolean-Werten, Nullwerten und Strings. Gilt für jedes Frontend – Svelte ($state), Vue (ref), React (useState) und Flutter/Dart –, um Dialoge, Overlays und mehrstufige Abläufe konsistent und einfach zu warten zu halten. Verwenden Sie es immer dann, wenn Sie einen Zustand für ein Modal, einen Dialog, eine Bestätigung, einen Assistenten, eine Registerkarte oder einen Ansichtsmodus hinzufügen oder überprüfen.
