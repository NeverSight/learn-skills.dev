Controla el estado de la interfaz de usuario (modales, hojas, cajones, pestañas, pasos, modos de visualización) con un único estado que contiene una unión discriminada / enumeración en lugar de muchos booleanos, valores nulos y cadenas independientes. Se aplica a cualquier frontend (Svelte [$state], Vue [ref], React [useState] y Flutter/Dart) para que los cuadros de diálogo, las superposiciones y los flujos de varios pasos sean coherentes y fáciles de mantener. Úselo siempre que añada o revise cualquier estado de modal, diálogo, confirmación, asistente, pestaña o modo de visualización.
