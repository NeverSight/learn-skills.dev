Entwerfen, implementieren oder überprüfen Sie Worker, Testrunner, Evaluatoren und Plugin-Hosts, die weniger vertrauenswürdige Befehle oder Codes ausführen. Verwenden Sie sie für die Isolierung von Subprozessen/Browsern, bereinigte Umgebungen, Dateisystem-/Netzwerkgrenzen, Ressourcenbudgets, Abbrüche, die Bereinigung von Prozessbäumen und die sichere Weitergabe von Ergebnissen. Ein Timeout oder ein Rootless-Container allein stellt keine Sandbox dar.
