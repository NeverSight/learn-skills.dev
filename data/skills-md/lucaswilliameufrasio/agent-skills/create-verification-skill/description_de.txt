Erstellen oder passen Sie eine projektlokale Skill an, die die tatsächlichen Benutzer-Workflows einer Anwendung steuert und Nachweise dafür erfasst, dass sie funktionieren. Verwenden Sie diese Option, wenn einer App ein wiederholbarer, für Agenten lesbarer Verifizierungspfad fehlt, wenn Sie Smoke-Workflows für Browser/CLI/API einrichten oder wenn ein Team eine gepflegte Funktionsübersicht wünscht. Überprüfen und verwenden Sie das vorhandene Harness des Ziel-Repositorys wieder. Gehen Sie nicht davon aus, dass Cursor vorhanden ist, fordern Sie Playwright nicht an und installieren Sie keine Abhängigkeiten ohne Genehmigung.
