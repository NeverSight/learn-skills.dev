Cree o adapte una habilidad local del proyecto que impulse los flujos de trabajo reales de los usuarios de una aplicación y registre pruebas de que funcionan. Úsela cuando una aplicación carezca de una ruta de verificación repetible y legible por los agentes, cuando configure flujos de trabajo de prueba de humo para navegadores/CLI/API o cuando un equipo quiera disponer de un mapa de funcionalidades actualizado. Inspeccione y reutilice el «harness» existente del repositorio de destino; no dé por sentado que se va a usar Cursor, no exija Playwright ni instale dependencias sin aprobación.
