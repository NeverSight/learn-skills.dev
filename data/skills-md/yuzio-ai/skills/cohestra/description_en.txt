Initialize the project collaboration context with `init`, then execute the specified stages according to **need**, **design**, **code**, **review**, **fix**, and **validate**. Use **verify** to check inter‑stage deviations, or use **report** to read‑only summarize the project task status and any remaining issues. The six stages can start from any point; if a stage lacks a `.cohestra` file, it will first prompt and initialize, while **report** does not initialize or write. The task README Front Matter provides a machine‑readable contract; merely discussing the process does not trigger execution.
