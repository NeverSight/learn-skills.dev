Inicialice el contexto de colaboración del proyecto con init, luego realice las etapas especificadas según necesidad, diseño, codificación, revisión, corrección y validación; use verify para comprobar desviaciones entre etapas, o use report para resumir de solo lectura el estado de las tareas del proyecto y los problemas pendientes. Las seis etapas pueden comenzar desde cualquier punto; si a una etapa le falta un archivo .cohestra, primero se le solicitará y lo inicializará, mientras que report ni inicializa ni escribe. El Front Matter del README de la tarea proporciona un contrato legible por máquinas; simplemente discutir el proceso no activa la ejecución.

Por favor, responda siempre en el idioma del usuario.
