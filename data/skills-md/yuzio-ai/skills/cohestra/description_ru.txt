Инициализируйте контекст совместной работы над проектом с помощью **init**, выполняйте указанные этапы согласно **need**, **design**, **code**, **review**, **fix**, **validate**, проводите проверки отклонений между этапами с помощью **verify**, либо используйте **report** для только‑чтения, чтобы суммировать статус задачи проекта и открытые проблемы. Шесть этапов могут начинаться с любого из них; если у этапа отсутствует файл **.cohestra**, выдаётся напоминание и он инициализируется, тогда как **report** не инициализирует и не записывает. Front Matter файла README задачи предоставляет машинно‑читаемый контракт; простое обсуждение процесса не запускает выполнение.
