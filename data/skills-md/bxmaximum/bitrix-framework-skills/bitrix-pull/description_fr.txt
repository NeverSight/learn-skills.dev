Couvre le module Pull - envoi d'événements en temps réel aux utilisateurs/canaux à partir de PHP, aperçu de l'abonnement JS, surveillance des balises, quand utiliser Pull vs Messenger vs agents, lien vers BitrixVue. Appliqué pour les mises à jour en direct de l'interface utilisateur, les notifications et les écrans collaboratifs. Termes clés : pull, Bitrix\Pull\Event, CPullWatch, CPullChannel, BX.PULL.subscribe, extendWatch, serveur de file d'attente, push.
