Модуль Covers Pull — отправка событий в реальном времени пользователям/каналам из PHP, обзор подписки JS, теги просмотра, когда использовать Pull, Messenger или агенты, ссылка на BitrixVue. Применяется для живых обновлений пользовательского интерфейса, уведомлений и совместных экранов. Ключевые термины — pull, Bitrix\Pull\Event, CPullWatch, CPullChannel, BX.PULL.subscribe, ExtendWatch, сервер очереди, push.
