أنشئ مخططات على نمط بنية السحابة لتكدسات التقنية، والهياكل النظامية، وتصاميم البنية التحتية، وتوبولوجيات الخدمات — مع شعارات العلامات التجارية الحقيقية، وحاويات مجمّعة، وأسهم عمودية نظيفة — يتم تسليمها كملف HTML مستقل، أو صورة PNG، أو مكوّن React/TSX، أو كأداة حية. استخدم هذه المهارة كلما طلب المستخدم مخطط بنية/نظام/تكدس/بنية تحتية، أو نظرة عامة على تكدس التقنية، أو توبولوجيا خدمة، أو مخطط على نمط مزود سحابي، أو أراد ترتيب شعارات التقنية في صورة توضح كيفية ارتباط خدماته — بأي لغة، حتى لو لم يذكر تنسيق الإخراج، وحتى لو لم تكن الأدوات المتضمنة خدمات سحابية.

يرجى دائمًا الرد بلغة المستخدم.
