inference.sh를 사용하여 React/Remotion 컴포넌트 코드에서 동영상을 렌더링합니다. TSX 코드를 전달하면 MP4를 얻을 수 있습니다. 모든 Remotion API를 지원합니다: useCurrentFrame, useVideoConfig, spring, interpolate, AbsoluteFill, Sequence. 해상도, FPS, 재생 시간, 코덱을 설정할 수 있습니다. 사용 사례: 프로그래밍 방식 비디오 생성, 애니메이션 그래픽, 모션 디자인, 데이터 기반 비디오, React 애니메이션을 비디오로 변환. 트리거: remotion, 코드에서 비디오 렌더링, tsx를 비디오로, react 비디오, 프로그래밍 비디오, remotion 렌더, 코드에서 비디오, 애니메이션 비디오, 모션 그래픽 코드, react 애니메이션 비디오.
