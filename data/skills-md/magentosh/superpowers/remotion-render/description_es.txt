Renderiza videos a partir de código de componentes React/Remotion mediante inference.sh. Pasa código TSX, obtén MP4. Compatibilidad con todas las API de Remotion: useCurrentFrame, useVideoConfig, spring, interpolate, AbsoluteFill, Sequence. Resolución, FPS, duración y códec configurables. Uso para: generación de video programática, gráficos animados, diseño de motion, videos basados en datos, animaciones React a video.
