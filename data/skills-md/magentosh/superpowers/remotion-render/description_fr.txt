Rendre des vidéos à partir du code de composants React/Remotion via inference.sh. Fournissez du code TSX, obtenez du MP4. Prend en charge toutes les API Remotion : useCurrentFrame, useVideoConfig, spring, interpolate, AbsoluteFill, Sequence. Résolution, FPS, durée et codec configurables. Utilisez‑le pour : génération de vidéos programmatique, graphiques animés, design motion, vidéos basées sur les données, animations React en vidéo. Déclencheurs : remotion, rendu vidéo à partir du code, tsx vers vidéo, vidéo react, vidéo programmatique, rendu remotion, code vers vidéo, vidéo animée, code de motion graphics, vidéo d’animation react.
