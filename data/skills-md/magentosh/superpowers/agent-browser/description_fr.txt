Automatisation de navigateur pour les agents IA via inference.sh. Naviguez sur les pages Web, interagissez avec les éléments à l'aide des références @e, prenez des captures d'écran, enregistrez des vidéos. Capacités : extraction de données Web, remplissage de formulaires, clics, saisie, glisser‑déposer, téléchargement de fichiers, exécution de JavaScript. Utilisations : automatisation Web, extraction de données, tests, navigation d'agents, recherche. Déclencheurs : navigateur, automatisation Web, extraction, navigation, clic, remplissage de formulaire, capture d'écran, navigation Web, Playwright, navigateur sans tête, agent Web, surfer sur Internet, enregistrement vidéo.
