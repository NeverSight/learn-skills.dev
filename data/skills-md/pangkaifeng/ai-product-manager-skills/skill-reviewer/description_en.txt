Skill review / Skill audit: Use when a user wants to inspect, review, or optimize a Codex/Agent Skill or SKILL.md. It can be invoked in Chinese with phrases such as “Help me review this Skill,” “Check this SKILL.md,” “Is this capability suitable to become a Skill,” “Optimize the Skill trigger description,” “See if this Skill has any issues.” The focus is on checking trigger boundaries, input and output, workflow thresholds, tool boundaries, context budget, resource segmentation, evaluation readiness, and governance risks.
