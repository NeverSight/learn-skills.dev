Skill-Review / Skill-Audit: Wird verwendet, wenn ein Benutzer eine Codex/Agent‑Skill oder SKILL.md prüfen, überprüfen oder optimieren möchte. Kann auf Chinesisch aufgerufen werden: „Help me review this Skill“, „Check this SKILL.md“, „Is this capability suitable to be made into a Skill“, „Optimize the Skill trigger description“, „See if this Skill has any issues“. Fokus liegt auf der Überprüfung von Trigger‑Grenzen, Ein- und Ausgaben, Workflow‑Schwellenwerten, Tool‑Grenzen, Kontextbudget, Ressourcenaufteilung, Evaluationsbereitschaft und Governance‑Risiken. Bitte immer in der Sprache des Benutzers antworten.
