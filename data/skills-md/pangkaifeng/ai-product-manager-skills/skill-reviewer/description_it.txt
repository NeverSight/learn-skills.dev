Revisione delle competenze / Audit delle competenze: usalo quando un utente desidera ispezionare, rivedere o ottimizzare una Skill Codex/Agent o un file SKILL.md. Può essere invocato in cinese con frasi come “Aiutami a rivedere questa Skill”, “Controlla questo SKILL.md”, “Questa capacità è adatta a diventare una Skill?”, “Ottimizza la descrizione del trigger della Skill”, “Verifica se questa Skill presenta problemi”. L’attenzione è rivolta al controllo dei limiti dei trigger, input e output, soglie del flusso di lavoro, limiti degli strumenti, budget di contesto, segmentazione delle risorse, prontezza alla valutazione e rischi di governance.

Per favore, rispondi sempre nella lingua dell'utente.
