Governance del ciclo di vita delle Skill / giudizio di consolidamento delle capacità: utilizzato quando un utente vuole creare, importare, unire, pubblicare, aggiornare, deprecare, ritirare o eliminare una Skill riutilizzabile, o decidere se inserirla in un repository pubblico unificato, in un progetto, in un Agent locale o in Multica. Può essere invocato in cinese con frasi come “Aiutami a creare una Skill”, “Trasforma questo processo in una Skill”, “Importa questa Skill da GitHub”, “Dove dovrebbe essere collocata questa Skill”, “Pubblica la Skill su più Agent”. Quando si sta solo revisionando un SKILL.md esistente, usare skill‑reviewer invece.
