Skill‑Lebenszyklus‑Governance / Urteil über die Ablagerung von Fähigkeiten: Wird verwendet, wenn ein Benutzer eine wiederverwendbare Skill erstellen, importieren, zusammenführen, veröffentlichen, aktualisieren, veralten lassen, stilllegen oder löschen möchte oder entscheiden will, ob sie in einem einheitlichen öffentlichen Repository, einem Projekt, einem lokalen Agenten oder Multica abgelegt werden soll. Sie kann auf Chinesisch mit Befehlen wie „Help me create a Skill“, „Solidify this process into a Skill“, „Import this GitHub Skill“, „Where should this Skill go“, „Publish the Skill to multiple Agents“ aufgerufen werden. Wenn nur ein vorhandenes SKILL.md geprüft wird, stattdessen skill‑reviewer verwenden.

Bitte immer in der Sprache des Benutzers antworten.
