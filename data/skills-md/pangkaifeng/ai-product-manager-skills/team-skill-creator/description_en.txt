Skill lifecycle governance / capability consolidation judgment: Used when a user wants to create, import, merge, publish, update, deprecate, retire, or delete a reusable Skill, or decide whether it should go into a unified public repository, a project, a local Agent, or Multica. It can be invoked in Chinese with phrases such as “Help me create a Skill,” “Turn this process into a Skill,” “Import this GitHub Skill,” “Where should this Skill be placed,” “Publish the Skill to multiple Agents.” When only reviewing an existing SKILL.md, use skill‑reviewer instead.
