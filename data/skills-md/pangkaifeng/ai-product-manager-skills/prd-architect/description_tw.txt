PRD 架構師 / 需求文件草擬：當使用者想要將產品構想、需求草案、腦力激盪輸出或功能規格整理成 PRD 時使用。可用中文呼叫的指令包括：「幫我寫 PRD」、「幫我選擇 PRD 模板」、「把這個需求整理成 PRD」、「判斷是使用輕量 PRD 還是標準 PRD」、「新增可編輯的 Draw.io 核心流程圖」、「在 PRD 中加入架構圖」。系統會依需求從 PRD‑lite、PRD‑standard 或 PRD‑ai‑native 中選取相應的模板資產，並在需要時載入模型交付、Draw.io 圖表或開發交付附錄；頁面型 PRD 會自動產生符合專案 UI 的 HTML、關鍵截圖與文字證據。此功能不適用於直接編程、純 UI 設計或審核已完成的 PRD。

請始終以使用者的語言回應。
