Can be invoked in Chinese with: “Help me write a PRD,” “Help me choose a PRD template,” “Organize this requirement into a PRD,” “Determine whether to use a lightweight PRD or a standard PRD,” “Add an editable Draw.io core flowchart,” “Add an architecture diagram to the PRD.” It will select one template asset from PRD‑lite, PRD‑standard, or PRD‑ai‑native as needed, and load mockup handoff, Draw.io diagrams, or development handoff appendices when required; page‑type PRDs automatically generate project UI‑aligned HTML, key screenshots, and textual evidence. Not intended for direct coding, pure UI drawing, or reviewing an already written PRD.
