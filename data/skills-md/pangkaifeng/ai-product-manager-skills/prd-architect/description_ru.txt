PRD‑архитектор / составление документа требований: используется, когда пользователь хочет оформить идею продукта, черновик требований, результаты мозгового штурма или функциональную спецификацию в виде PRD. Может быть вызван на китайском с помощью фраз: «Help me write a PRD», «Help me choose a PRD template», «Organize this requirement into a PRD», «Determine whether to use a lightweight PRD or a standard PRD», «Add an editable Draw.io core flowchart», «Add an architecture diagram to the PRD». Система выберет один из шаблонов PRD‑lite, PRD‑standard или PRD‑ai‑native по необходимости и загрузит макет передачи, диаграммы Draw.io или приложения для передачи разработки, когда это требуется; PRD‑страницы автоматически генерируют HTML, ключевые скриншоты и текстовые доказательства, согласованные с пользовательским интерфейсом проекта. Не предназначено для прямого кодирования, чистого UI‑дизайна или проверки уже написанного PRD.
