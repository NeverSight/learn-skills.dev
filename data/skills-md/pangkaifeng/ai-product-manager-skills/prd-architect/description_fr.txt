Architecte PRD / Rédaction de document d'exigences : utilisé lorsqu'un utilisateur souhaite organiser une idée de produit, un brouillon d'exigences, le résultat d'une séance de brainstorming ou une spécification fonctionnelle en un PRD. Peut être invoqué en chinois avec des commandes telles que « Aide‑moi à rédiger un PRD », « Aide‑moi à choisir un modèle de PRD », « Organise cette exigence dans un PRD », « Détermine s'il faut utiliser un PRD léger ou un PRD standard », « Ajoute un diagramme de flux principal modifiable sur Draw.io », « Ajoute un diagramme d'architecture au PRD ». Il sélectionnera, selon les besoins, un modèle parmi PRD‑lite, PRD‑standard ou PRD‑ai‑native, et chargera les livrables de maquette, les diagrammes Draw.io ou les annexes de transfert de développement lorsqu'ils sont requis ; les PRD de type page génèrent automatiquement du HTML aligné sur l’UI du projet, les captures d’écran clés et des preuves textuelles. Ce n’est pas destiné à la programmation directe, aux maquettes UI pures, ni à la révision d’un PRD déjà rédigé. Veuillez toujours répondre dans la langue de l'utilisateur.
