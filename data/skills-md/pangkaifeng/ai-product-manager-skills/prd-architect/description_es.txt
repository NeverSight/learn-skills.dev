Arquitecto PRD / Redacción de Documentos de Requerimientos: Se usa cuando un usuario desea organizar una idea de producto, un borrador de requerimientos, resultados de lluvia de ideas o una especificación funcional en un PRD. Puede invocarse en chino con frases como “Help me write a PRD”, “Help me choose a PRD template”, “Organize this requirement into a PRD”, “Determine whether to use a lightweight PRD or a standard PRD”, “Add an editable Draw.io core flowchart”, “Add an architecture diagram to the PRD”. Seleccionará una plantilla de los activos PRD‑lite, PRD‑standard o PRD‑ai‑native y la cargará bajo demanda, y cuando sea necesario cargará entregas de maquetas, diagramas Draw.io o anexos de entrega de desarrollo; los PRD de tipo página generan automáticamente HTML alineado con la UI del proyecto, capturas de pantalla clave y evidencia textual. No está destinado a codificación directa, diseño UI puro o revisión de un PRD ya escrito.

Por favor, siempre responda en el idioma del usuario.
