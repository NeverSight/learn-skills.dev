PRDアーキテクト／要件ドキュメント作成: ユーザーが製品アイデア、要件草案、ブレインストーミング結果、または機能仕様をPRDにまとめたいときに使用します。中国語で呼び出すことができます: 「Help me write a PRD」「Help me choose a PRD template」「Organize this requirement into a PRD」「Determine whether to use a lightweight PRD or a standard PRD」「Add an editable Draw.io core flowchart」「Add an architecture diagram to the PRD」。必要に応じて、PRD-lite、PRD-standard、またはPRD-ai-native のテンプレート資産を選択し、モックアップハンドオフ、Draw.io 図、または開発ハンドオフ付録をロードします。ページタイプのPRDは、プロジェクトの UI に合わせた HTML、主要なスクリーンショット、およびテキスト証拠を自動的に生成します。直接コーディング、純粋な UI 描画、または既に書かれた PRD のレビューには使用しません。

必ずユーザーの言語で回答してください。
