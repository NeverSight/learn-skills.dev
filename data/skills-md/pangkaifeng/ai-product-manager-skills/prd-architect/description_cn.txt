PRD 架构师/需求文档起草：用于用户想将产品概念、需求草案、头脑风暴结果或功能规范整理成 PRD 时。可用中文召唤的指令包括：“帮我写 PRD”，“帮我选择 PRD 模板”，“把这个需求整理成 PRD”，“判断是使用轻量级 PRD 还是标准 PRD”，“添加可编辑的 Draw.io 核心流程图”，“在 PRD 中添加架构图”。系统会根据需要从 PRD‑lite、PRD‑standard 或 PRD‑ai‑native 中选择相应的模板资产，并在需要时加载模型交付、Draw.io 图表或开发交付附录；页面型 PRD 会自动生成与项目 UI 对齐的 HTML、关键截图和文字证据。此功能不用于直接编写代码、纯 UI 绘制或审阅已有的 PRD。
