Design brainstorming / pre‑implementation solution calibration: Use this when a user wants to take an already roughly formed idea, functional direction, or product issue and, before writing a PRD, creating a mockup, or entering a development plan, first compare solutions, confirm trade‑offs, align UI/visual constraints, and converge into an actionable design specification. It can be invoked in Chinese with commands such as “先脑暴一下方案” (let’s brainstorm the solution first), “先不要写 PRD，帮我设计几种路径” (don’t write the PRD yet, help me design several paths), “参考 brainstorming 把这个需求变成设计 spec” (use brainstorming to turn this requirement into a design spec), or “实现前先讨论设计” (discuss the design before implementation). When the problem is not yet clearly defined, use **ai‑collaboration‑calibration**; for stress‑testing an existing solution, use **grill‑me**; when directly writing a PRD, use **prd‑architect**; and when grill‑me returns precise design gaps, this skill outputs only the **Design Delta**.
