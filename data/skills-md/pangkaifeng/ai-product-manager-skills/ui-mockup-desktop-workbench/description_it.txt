Allineamento della consegna UI ad alta fedeltà dal PRD / mockup UI per workstation desktop: quando l'utente dispone già di un PRD, specifiche UI, un percorso reale di progetto front‑end, screenshot o un inventario dello stato delle pagine, estrarre prima la struttura UI, il modello di stato e il layout ASCII dal PRD, quindi usarli per mockup ad alta fedeltà, l'anteprima nativa del progetto o il passaggio allo sviluppo. Prioritizzare la generazione del percorso/componente dell'anteprima nativa del progetto; generare HTML autonomo solo quando si tratta di conferma di concetto preliminare o quando non è possibile accedere a un progetto reale. Deve includere artefatti della fase strutturale, contratto dello schermo, mappa dei componenti, note di implementazione, screenshot/risultati di validazione e il confine di migrazione tra HTML/anteprima.
