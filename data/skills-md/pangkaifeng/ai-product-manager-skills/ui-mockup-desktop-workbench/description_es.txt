PRD a alineación de entrega UI de alta fidelidad / Mockup UI de estación de trabajo de escritorio: Cuando el usuario ya cuenta con un PRD, especificaciones UI, una ruta de proyecto front‑end real, capturas de pantalla o un inventario de estados de página, primero debe extraer la estructura UI, el modelo de estado y el diseño ASCII del PRD, y luego usarlo para un mockup de alta fidelidad, una vista previa nativa del proyecto o la entrega para desarrollo. Priorizar la salida de la ruta/componente de vista previa nativa del proyecto; solo generar HTML independiente cuando solo se dispone de una confirmación de concepto temprana o cuando no sea posible la integración con un proyecto real. Debe incluir artefactos de etapa estructural, contrato de pantalla, mapa de componentes, notas de implementación, capturas de pantalla/resultados de validación y los límites de migración del HTML/vista previa.
