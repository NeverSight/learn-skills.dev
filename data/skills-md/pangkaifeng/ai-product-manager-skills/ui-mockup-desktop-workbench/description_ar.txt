التوافق بين PRD وتسليم واجهة المستخدم عالية الدقة / نموذج واجهة المستخدم لمحطة عمل سطح المكتب: عندما يكون لدى المستخدم بالفعل PRD، ومواصفات واجهة المستخدم، ومسار مشروع الواجهة الأمامية الحقيقي، ولقطات شاشة، أو جرد لحالات الصفحات، قم أولاً باستخراج بنية الواجهة، نموذج الحالة، وتخطيط ASCII من PRD، ثم استخدمها للنماذج عالية الدقة، المعاينة الأصلية للمشروع، أو تسليم التطوير. الأولوية لإخراج مسار/مكوّن المعاينة الأصلية للمشروع؛ قم بإخراج HTML مستقل فقط عند التعامل مع تأكيد مفهوم مبكر أو عندما لا يمكن الوصول إلى مشروع حقيقي. يجب تضمين مخرجات مرحلة الهيكلية، عقدة الشاشة، خريطة المكوّنات، ملاحظات التنفيذ، لقطات الشاشة/نتائج التحقق، وحدود الانتقال بين HTML/المعاينة.
