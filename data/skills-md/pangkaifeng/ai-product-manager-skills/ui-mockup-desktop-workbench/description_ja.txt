PRD とハイフィデリティ UI 配信／デスクトップワークステーション UI モックアップの整合: ユーザーがすでに PRD、UI 仕様、実際のフロントエンドプロジェクトパス、スクリーンショット、またはページステートインベントリを所有している場合、まず PRD から UI 構造、ステートモデル、ASCII レイアウトを抽出し、ハイフィデリティモックアップ、プロジェクトのネイティブプレビュー、または開発引き渡しへ移行する際にそれらを使用しなければなりません。プロジェクトのネイティブプレビューのルート/コンポーネントの出力を優先し、早期概念のみが確認された場合や実プロジェクトにアクセスできない場合に限り、単体 HTML を出力してください。構造フェーズのアーティファクト、画面契約、コンポーネントマップ、実装メモ、スクリーンショット／検証結果、HTML／プレビューの移行境界を必ず含めること。
