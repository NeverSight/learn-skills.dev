Úsese cuando un usuario inicia un nuevo proyecto o trabaja en varios espacios de trabajo del repositorio y necesita escanear el producto, los usuarios, los flujos de trabajo del negocio, la arquitectura técnica, los límites del repositorio, el lenguaje del dominio, los puntos de entrada de lectura y los obstáculos históricos, para luego generar o mantener de forma continua un PROJECT_CONTEXT.md global. Es adecuado para usuarios que dicen: «Primero, echa un vistazo integral al proyecto y consolida el contexto», «Crea un documento de contexto para este proyecto» o «Actualiza este obstáculo en el contexto del proyecto». No es para redactar un único PRD, gestión pura de directorios o una implementación de código aislada.
