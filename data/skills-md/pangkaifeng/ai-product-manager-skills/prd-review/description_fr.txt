Revue PRD / Revue des exigences : utilisez ceci lorsque l'utilisateur possède déjà un brouillon de PRD, un document de passation, un document d'exigences ou une proposition produit et doit identifier les lacunes, les conflits, les points infaisables et les points non testables du point de vue du chef de produit, du développement et des tests. Il peut être invoqué en chinois avec des phrases telles que « Aide‑moi à réviser le PRD », « Trouve les problèmes du point de vue du développement et des tests », « Ce document d'exigences peut‑il être transmis au développement ? », « Aide‑moi à rédiger des révisions pour le PRD », « Vérifie si les diagrammes du PRD sont manquants ou non modifiables ». Il n’est pas destiné à générer un PRD à partir de zéro, à écrire du code directement, ou à effectuer des tests de stress Q&A de la solution mature derrière le PRD ; pour les tests de stress de solution, utilisez grill‑me.

Veuillez toujours répondre dans la langue de l'utilisateur.
