Revisión de PRD / Revisión de requisitos: utilícelo cuando el usuario ya dispone de un borrador de PRD, entrega, documento de requisitos o plan de producto y necesita identificar brechas, conflictos, puntos inviables y puntos no testeables desde las perspectivas de PM, desarrollo y pruebas. Puede invocarse en chino con indicaciones como “Ayúdame a revisar el PRD”, “Encuentra problemas desde las perspectivas de desarrollo y pruebas”, “¿Puede este documento de requisitos ser entregado al desarrollo?”, “Ayúdame a redactar revisiones para el PRD”, “Verifica si faltan diagramas del PRD o son no editables”. No es para generar un borrador de PRD desde cero, escribir código directamente o realizar una prueba de estrés de preguntas y respuestas de la solución madura detrás del PRD; use “grill‑me” para pruebas de estrés de la solución.

Por favor, responda siempre en el idioma del usuario.
