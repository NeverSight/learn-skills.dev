Build, change, run and publish a Teable app (an App Builder app, Next.js on Teable data) from this machine with the `teable` CLI instead of the in-app chat. Use when the user wants to create a Teable app, work on an existing one locally, push a new version, publish it, roll back, or react to table-schema changes and named-query repairs. Covers project (base) resolution, `teable app init|clone|pull|push|publish`, the local dev loop and the platform rules the checkout must follow.
