Импортируйте HTML или веб‑страницу в Figma с помощью собственного конвертера import_html от FigCraft. Используйте, когда: html → figma, импорт html, импорт веб‑страницы, захват статической страницы, преобразование HTML в редактируемые слои Figma. Для пиксельно‑точного живого захвата веб‑страницы используйте официальную функцию Figma MCP generate_figma_design в качестве визуального референса, когда она доступна.
