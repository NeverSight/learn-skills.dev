استيراد HTML أو صفحة ويب إلى Figma باستخدام محول import_html الأصلي الخاص بـ FigCraft. يُستعمل عند: تحويل HTML إلى Figma، استيراد HTML، استيراد صفحة ويب، التقاط صفحة ثابتة، تحويل HTML إلى طبقات Figma قابلة للتحرير. للحصول على التقاط ويب مباشر بدقة بيكسل مثالية، استخدم أداة Figma MCP الرسمية generate_figma_design كمرجع بصري عندما تكون متاحة.
