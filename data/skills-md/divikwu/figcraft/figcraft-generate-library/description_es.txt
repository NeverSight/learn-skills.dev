Construir o actualizar el propio sistema de diseño en Figma — variables/tokens, bibliotecas de componentes, tematización (modos claro/oscuro), documentación de fundamentos. Úsalo al crear el sistema, no solo al utilizarlo. Disparadores: “construir biblioteca de componentes”, “crear tokens de diseño”, “configurar tematización”, “conciliar código y Figma”. Utiliza las herramientas declarativas de FigCraft — no se requiere use_figma. NO lo uses para ensamblar pantallas a partir de un sistema existente (utiliza figcraft-generate-design).
