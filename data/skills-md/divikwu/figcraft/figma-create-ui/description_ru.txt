Создавайте UI в Figma, используя декларативные инструменты FigCraft (create_frame, create_text, create_component). Применяйте, когда: create/design/build/make + Figma/UI/экран/страница/компонент/кнопка/вариант БЕЗ существующей системы дизайна. ВАЖНО: используйте create_frame для экранов, create_component — для переиспользуемых компонентов. Никогда не используйте use_figma для создания UI. НЕ используйте при сборке экранов из существующей системы дизайна (используйте figcraft-generate-design) или при построении полной системы дизайна (используйте figcraft-generate-library).

Пожалуйста, всегда отвечайте на языке пользователя.
