Crea UI in Figma usando gli strumenti dichiarativi di FigCraft (create_frame, create_text, create_component). Usa quando: create/design/build/make + Figma/UI/screen/page/component/button/variant SENZA un sistema di design esistente. IMPORTANTE: Usa create_frame per le schermate, create_component per i componenti riutilizzabili. Non usare mai use_figma per la creazione della UI. NON usarlo quando si assemblano schermate da un sistema di design esistente (usa figcraft-generate-design) o si costruisce un sistema di design completo (usa figcraft-generate-library).

Per favore rispondi sempre nella lingua dell'utente.
