Créer UI dans Figma en utilisant les outils déclaratifs FigCraft (create_frame, create_text, create_component). Utiliser quand : create/design/build/make + Figma/UI/écran/page/composant/bouton/variante SANS système de design existant. IMPORTANT : Utiliser create_frame pour les écrans, create_component pour les composants réutilisables. Ne jamais utiliser use_figma pour la création d'UI. NE PAS utiliser lors de l'assemblage d'écrans à partir d'un système de design existant (utiliser figcraft-generate-design) ou lors de la construction d'un système de design complet (utiliser figcraft-generate-library).  

Veuillez toujours répondre dans la langue de l'utilisateur.
