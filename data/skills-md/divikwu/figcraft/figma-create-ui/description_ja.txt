FigCraft の宣言的ツール（create_frame、create_text、create_component）を使用して Figma で UI を作成する。次の場合に使用する：create／design／build／make + Figma／UI／スクリーン／ページ／コンポーネント／ボタン／バリアント、ただし既存のデザインシステムがないとき。重要：スクリーンには create_frame を、再利用可能なコンポーネントには create_component を使用する。UI 作成に use_figma を決して使用しない。既存のデザインシステムからスクリーンを組み立てるとき（figcraft‑generate‑design を使用）や、フルデザインシステムを構築する場合（figcraft‑generate‑library を使用）には使用しない。
