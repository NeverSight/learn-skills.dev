Crea UI en Figma usando las herramientas declarativas de FigCraft (create_frame, create_text, create_component). Úsalo cuando: create/design/build/make + Figma/UI/pantalla/página/componente/botón/variante SIN un sistema de diseño existente. IMPORTANTE: Usa create_frame para pantallas, create_component para componentes reutilizables. Nunca uses use_figma para crear UI. NO lo uses al ensamblar pantallas de un sistema de diseño existente (usa figcraft-generate-design) o al construir un sistema de diseño completo (usa figcraft-generate-library).

Por favor, responde siempre en el idioma del usuario.
