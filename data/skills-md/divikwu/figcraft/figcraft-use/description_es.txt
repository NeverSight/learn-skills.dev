**REQUISITO OBLIGATORIO** — DEBES invocar esta habilidad ANTES de cada llamada a la herramienta `use_figma`. NUNCA llames a `use_figma` directamente sin cargar primero esta habilidad. Activa la habilidad siempre que el usuario quiera realizar una acción de escritura o una lectura única que requiera ejecución de JavaScript en el contexto del archivo Figma — por ejemplo, crear/editar/eliminar nodos, configurar variables o tokens, construir componentes y variantes, modificar autolayout o rellenos, vincular variables a propiedades, o inspeccionar la estructura del archivo programáticamente.
