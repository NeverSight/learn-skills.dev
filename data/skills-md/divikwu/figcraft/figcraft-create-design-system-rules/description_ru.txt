Генерирует пользовательские правила системы дизайна для кодовой базы пользователя. Используется, когда пользователь говорит «create design system rules», «generate rules for my project», «set up design rules», «customize design system guidelines» или хочет установить проектные конвенции для рабочих процессов Figma-to-code. Требуется подключение к серверу Figma MCP.

Пожалуйста, всегда отвечайте на языке пользователя.
