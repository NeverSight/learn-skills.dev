Создайте новый пустой файл Figma. Используйте, когда пользователь хочет создать новый дизайн Figma или файл FigJam, или когда вам нужен новый файл перед вызовом use_figma. Обрабатывает разрешение плана через whoami при необходимости. Использование — /figcraft-create-new-file [editorType] [fileName] (например, /figcraft-create-new-file figjam My Whiteboard)

Пожалуйста, всегда отвечайте на языке пользователя.
