Checkliste, bevor ein Commit durchgeführt wird: Überprüfen und aktualisieren Sie das ursprüngliche Ticket oder die ursprüngliche Aufgabe, führen Sie Tests und Fusseln durch und Commit, wenn Sie dazu aufgefordert werden. Wird verwendet, wenn der Benutzer darum bittet, einen Commit vorzubereiten, sich auf einen Commit vorzubereiten oder Änderungen zu übernehmen.
