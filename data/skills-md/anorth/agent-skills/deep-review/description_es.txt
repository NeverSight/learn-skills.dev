Revisión profunda y temática de un diff: el flujo de revisión-diff y sus lentes estándar, más un subagente de revisión barato por tema, utilizando preferencias distintivas destiladas de las revisiones públicas de GitHub de Alex North (nomenclatura, forma de API, errores, pruebas, acoplamiento y temas relacionados). Necesita la habilidad de revisión-diff. Úselo cuando el usuario solicite una revisión profunda, una revisión temática o una revisión de estilo norte.
