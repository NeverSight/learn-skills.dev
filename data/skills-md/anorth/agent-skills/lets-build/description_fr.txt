Construisez à partir d'un ticket ou d'une tâche écrite, en collaborant avec l'utilisateur : concevez-le d'abord avec lui s'il n'est pas prêt, puis construisez-le avec l'utilisateur dans la boucle. À utiliser lorsque l'utilisateur dit de construire, de construire ensemble ou demande de construire à partir d'un ticket ou d'une description de tâche.
