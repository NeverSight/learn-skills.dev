Risolvi quale modello utilizza un subagente tra tre livelli (economico, standard, potente), elencati nei valori predefiniti di questa abilità o nel file ~/.agents/model-tiers.md dell'utente, e corrispondenti a ciò che offre l'infrastruttura. Usa quando un'abilità indica di avviare un subagente su un livello, quando si scelgono modelli per revisori o verificatori, o quando l'utente richiede di configurare o modificare i livelli dei modelli.

Per favore, rispondi sempre nella lingua dell'utente.
