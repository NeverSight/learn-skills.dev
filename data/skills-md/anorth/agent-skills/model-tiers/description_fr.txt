Résout le modèle sur lequel un sous-agent s'exécute à partir de trois niveaux (bon marché, standard, fort), répertorié dans les valeurs par défaut de cette compétence ou les ~/.agents/model-tiers.md de l'utilisateur, et adapté à ce que le harnais offre. À utiliser lorsqu'une compétence dit de générer un sous-agent sur un niveau, lors du choix de modèles pour les réviseurs ou les vérificateurs, ou lorsque l'utilisateur demande de configurer ou de modifier des niveaux de modèles.
