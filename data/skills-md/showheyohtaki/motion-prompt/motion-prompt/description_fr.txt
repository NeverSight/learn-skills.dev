Motion Prompt (showheyohtaki.github.io/motion-prompt) est une bibliothèque numérotée de noms pour les mouvements de motion‑graphics, les déplacements de caméra et les transitions, les composants d’interface utilisateur, les effets de page d’atterrissage et du web, ainsi que les looks et éclairages photographiques, chacun accompagné d’un exemple animé, d’une spécification de ses durées et de son easing, et d’un code Canvas 2D sans dépendance.  
Utilisation principale : ouvrir la galerie pour l’utilisateur avec la commande « pick », lui permettre de cocher ce qu’il souhaite, récupérer ses sélections, puis reconstruire exactement ces éléments dans le projet (Canvas, Remotion, CSS/SVG/Lottie, After Effects) ou les transformer en invites pour des modèles vidéo ou image.  
À utiliser lorsque l’utilisateur veut voir ou choisir dans la bibliothèque, par ex. « ouvrir la bibliothèque motion‑prompt », « montre‑moi la liste », « quels mouvements existent ? », « je ne connais pas le nom, laisse‑moi choisir », « motion-prompt のライブラリ出して », « 一覧見せて », « どんな演出がある？ », « 分からないから選びたい » ; lorsqu’il colle des sélections copiées depuis la galerie ; ou lorsqu’il indique des numéros d’éléments, par ex. « utilise #012 et #045 », « 今のタイトルを #005 に差し替えて ».  
Veuillez toujours répondre dans la langue de l’utilisateur.
