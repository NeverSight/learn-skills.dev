在不重新樣式化網站的情況下，為網站加入由 GSAP 驅動的 WebGL，使用每個文件共用的 OGL 渲染器與畫布。影像平面會追蹤每張 img，實作懸停鏡頭、滾動速度波、擦除、故障、溶解、像素化與漣漪效果。框架視圖會在元素的盒子內繪製：相機在 3D 螺旋圖像中飛行、GPU 粒子在形狀之間變形、液態圖像，以及液態金屬滴落成文字或沿頁面流下。GSAP 會對著色器的 uniform 進行 tween。實際的 img，或作為視圖的海報 img，保留為可存取的內容，且在缺少 WebGL、上下文遺失、圖像缺乏 CORS，或減少動態效果時作為備援。可用於 WebGL 圖像效果、著色器懸停、3D 捲動飛行、粒子變形、液態懸停、uniform tween，或在不同路由間保持畫布持續運行。搭配相應的 GSAP 框架技能以處理生命週期時序。不適用於 glTF 模型、物理、僅 DOM 的效果（請使用 animaxxing）、品牌相關或 GSAP API 問題。
