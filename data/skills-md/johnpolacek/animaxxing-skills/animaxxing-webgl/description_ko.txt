GSAP 기반 WebGL을 사이트에 추가하되 스타일을 다시 적용하지 않고 문서당 하나의 공유 OGL 렌더러와 캔버스를 사용합니다. 이미지 플레인은 각 img를 추적하여 호버 렌즈, 스크롤 속도 파동, 와이프, 글리치, 디졸브, 픽셀화, 리플 효과를 구현합니다. 프레임된 뷰는 요소의 박스 안에 그리며, 3D 나선형 이미지 속을 비행하는 카메라, 형태 사이를 변형하는 GPU 파티클, 액체 이미지, 그리고 단어로 녹거나 페이지 위로 흐르는 액체 금속 방울을 포함합니다. GSAP은 셰이더 유니폼을 트윈합니다. 실제 img 또는 뷰용 포스터 img는 접근 가능한 콘텐츠이며, WebGL이 없거나 컨텍스트가 손실되었거나 이미지에 CORS가 없거나 움직임이 감소된 경우의 대체 역할을 합니다. WebGL 이미지 효과, 셰이더 호버, 3D 스크롤 비행, 파티클 변형, 액체 호버, 유니폼 트윈, 혹은 라우트 전환 시 캔버스를 유지하는 용도로 사용합니다. 라이프사이클 타이밍을 위한 일치하는 GSAP 프레임워크 스킬과 함께 사용하십시오. glTF 모델, 물리, DOM 전용 효과(animaxxing 사용), 브랜딩, GSAP API 질문에는 적합하지 않습니다.
