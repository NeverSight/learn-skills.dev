Añade WebGL impulsado por GSAP a un sitio sin volver a estilizarlo, usando un único renderizador OGL y canvas compartido por documento. Los planos de imagen siguen a cada img para una lente de hover, ola de velocidad de desplazamiento, barrido, glitch, disolución, pixelado y ondulación. Las vistas enmarcadas se dibujan dentro del cuadro de un elemento: un vuelo de cámara a través de una espiral 3D de imágenes, partículas de GPU que se transforman entre formas, una imagen líquida y gotas de metal líquido que se funden en una palabra o se derraman por una página. GSAP anima los uniformes de los shaders. La img real, o una img póster para una vista, permanece como contenido accesible y como alternativa cuando falta WebGL, el contexto se pierde, una imagen carece de CORS o se reduce el movimiento. Úsalo para efectos de imagen WebGL, hover de shader, vuelos 3D en scroll, morfologías de partículas, hover líquido, animaciones de uniformes o mantener un canvas activo entre rutas. Combínalo con la habilidad del framework GSAP correspondiente para la sincronización del ciclo de vida. No es para modelos glTF, física, efectos solo DOM (usa animaxxing), branding o preguntas sobre la API de GSAP.
