Добавьте WebGL, управляемый GSAP, на сайт без изменения стилей, используя один общий OGL‑рендерер и canvas на документ. Плоскости изображений отслеживают каждый img для создания эффекта лупы при наведении, волны, зависящей от скорости скролла, стирания, глитча, растворения, пикселизации и ряби. Обрезанные представления рисуются в пределах коробки элемента: полёт камеры сквозь 3‑мерную спираль изображений, частицы GPU, трансформирующиеся между формами, жидкое изображение и капли жидкого металла, которые расплавляются в слово или стекают по странице. GSAP анимирует uniform‑переменные шейдеров. Исходный img или постер‑изображение для представления остаются доступным контентом и резервом, когда WebGL отсутствует, контекст потерян, изображение не имеет CORS или движение ограничено. Используйте для WebGL‑эффектов изображений, шейдерного hover, 3‑мерных полётов при скролле, морфинга частиц, жидкого hover, анимации uniform‑ов или поддержания canvas живым между роутами. Сочетайте с соответствующим навыком GSAP‑framework для тайминга жизненного цикла. Не предназначено для моделей glTF, физики, эффектов только в DOM (используйте animaxxing), брендинга или вопросов по API GSAP.
