在不重新样式化站点的情况下，向站点添加由 GSAP 驱动的 WebGL，每个文档使用一个共享的 OGL 渲染器和画布。图像平面跟踪每个 img，实现悬停透镜、滚动速度波浪、擦除、故障、溶解、像素化和涟漪效果。框架视图在元素的盒子内绘制：相机在 3D 螺旋图像中飞行、GPU 粒子在形状之间变形、液体图像以及液态金属滴滴融化成文字或沿页面倾泻。GSAP 对 shader uniform 进行 tween。真实的 img，或视图的海报 img，保持为可访问内容，并在缺少 WebGL、上下文丢失、图像缺少 CORS 或降低运动时作为回退。用于 WebGL 图像效果、shader 悬停、3D 滚动飞行、粒子变形、液体悬停、uniform tween，或在路由之间保持 canvas 活动。与匹配的 GSAP 框架技能配合使用以实现生命周期定时。不要用于 glTF 模型、物理、仅 DOM 效果（使用 animaxxing）、品牌或 GSAP API 问题。
