أضف WebGL المدفوع بـ GSAP إلى موقع دون إعادة تنسيقه، باستخدام مُصنِّف OGL مشترك واحد وكانفاس واحد لكل مستند. تتعقب طائرات الصور كل img لتطبيق عدسة تحويم، وموجة بسرعة التمرير، ومسح، وتشويش، وتذويب، وتبكسيل، وتموج. تُرَسَمُ العروض المؤطرة داخل صندوق العنصر: رحلة كاميرا عبر حلزون ثلاثي الأبعاد من الصور، وجسيمات GPU تتحول بين الأشكال، وصورة سائلة، وقطرات معدن سائل تذوب لتشكل كلمة أو تتساقط على الصفحة. يقوم GSAP بتحريك قيم uniform للـ shader. تبقى الصورة الحقيقية، أو صورة الملصق للعرض، هي المحتوى القابل للوصول والبديل في حال غياب WebGL، أو فقدان السياق، أو عدم وجود CORS للصورة، أو تقليل الحركة. استخدمها لتأثيرات صور WebGL، والتحويم بالـ shader، ورحلات التمرير ثلاثية الأبعاد، وتحولات الجسيمات، والتحويم السائل، وتحريك uniform، أو إبقاء الـ canvas حيًا عبر المسارات. ربطها مع مهارة إطار العمل المتطابقة لـ GSAP لتوقيت دورة الحياة. ليست مخصصة لنماذج glTF، أو الفيزياء، أو تأثيرات DOM فقط (استخدم animaxxing)، أو العلامة التجارية، أو أسئلة واجهة برمجة تطبيقات GSAP.
