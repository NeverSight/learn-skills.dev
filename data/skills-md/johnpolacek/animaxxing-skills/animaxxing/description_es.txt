Construye movimiento con GSAP sin restilizar, ya sea como efectos individuales o con el tratamiento completo: para “estamos animando”, cada elemento entra desde una página en blanco, se mantiene y sale. Texto: dividir, mezclar, glitch, máquina de escribir y entradas habladas, titulares dispersos, ondas de letras, texto en una ruta, contadores ascendente, odómetros. Desplazamiento: revelaciones, raspado, paralaje, escenas fijadas, apilamiento de tarjetas, zoom‑through, recorridos horizontales, puntos de referencia, desplazamiento suave, paginación. Puntero: magnético, inclinación, focos, rellenos direccionales, ondas al presionar, sacudidas, seguidores de cursor, rastros de imagen, proximidad, rodillos de etiquetas, subrayados, efectos de peso al pasar. Arrastre: lanzar pistas, bucles infinitos, pilas de tarjetas, listas ordenables, deslizar para descartar. También cubiertas de página, efectos de impresión, transformaciones Flip, menús, diálogos, pestañas, botones de estado, efectos de medios y SVG, marquesinas, CustomEase, sonido, confeti, partículas y hover atrapado al tocar. Además busca una sensación: premium, calmada, juguetona. Combínalo con la habilidad correspondiente del framework GSAP. No es para rediseño visual, enrutamiento o preguntas de la API de GSAP.
