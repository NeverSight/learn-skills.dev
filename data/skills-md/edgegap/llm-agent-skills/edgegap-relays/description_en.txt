Edgegap Relays (Smart Relays, Distributed Relay) for host/client games: one player hosts, friends join with a code, and traffic goes through an Edgegap relay near them, so nobody port forwards and NAT or firewalls stop mattering. Load this once the developer has chosen peer-to-peer or a listen server over a dedicated server, before using edgegap_create_relay_session or any relay API. Emulator-tested, not yet on a live Edgegap relay; points to the LightNet relay deployment verified on Edgegap. Ships a relay transport for raw-UDP netcodes (relay protocol plus reliable fragmented and unreliable ordered channels), a lobby service that keeps the relay token off players' machines, an offline relay emulator, and fixes for relay pitfalls: relay vs API token, server vs client port, IP authorization, 1200-byte MTU, clients only reach the host. Use for "relay for my P2P game", "join by code without port forwarding", "replace Unity Relay or Steam P2P with Edgegap", or a custom relay transport.
