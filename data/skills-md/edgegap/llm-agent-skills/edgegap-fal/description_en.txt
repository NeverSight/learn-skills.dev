fal.ai + Edgegap: build a browser game with fal Agent (fal.ai, the media-generation agent) and make it online multiplayer on Edgegap with a matchmaker and one authoritative server per match, keeping solo play. Load this when someone says they made, or wants to make, a game with fal, fal.ai or fal Agent and wants Find Match, online play with friends, or real servers, or asks how to prompt fal Agent for game code that can go online. It has the fal Agent prompt that puts the rules in one DOM-free file the server can run, how to get the code and generated art out of a fal chat into a repo, the edgegap-threejs templates wired to that rules file, a GitHub Actions image build that Edgegap can pull, the dashboard path when the agent has no Edgegap API token, a GitHub Pages page, end-to-end tests, and clean-up so nothing runs non-stop. Worked example: netcode-sample-fal-orb-arena, verified on Edgegap. Games from other AI tools: edgegap-vibe-coded; a Node server already written: edgegap-threejs.
