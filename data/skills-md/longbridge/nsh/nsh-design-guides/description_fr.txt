Les guides de conception normatifs pour les applications Native Shell (NSH). Lire avant de concevoir ou de modifier tout écran, mise en page, espacement, hiérarchie visuelle, couleur, densité, choix de composant, état d’interaction, superposition, animation, vue riche en données ou texte d’interface dans une application NSH, en TSX ou Rust, et avant d’examiner le travail UI pour la qualité du design. Utiliser également lorsqu’on demande quelles sont les règles de conception, ou si une décision UI les respecte.
