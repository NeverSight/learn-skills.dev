Le Guide di progettazione normative per le app Native Shell (NSH). Leggi prima di progettare o modificare qualsiasi schermo, layout, spaziatura, gerarchia visiva, colore, densità, scelta dei componenti, stato di interazione, overlay, motion, vista o copia di interfaccia con molti dati in un’app NSH, in TSX o Rust, e prima di revisionare il lavoro UI per la qualità del design. Usale anche quando ti chiedono quali sono le regole di progettazione o se una decisione UI le segue.
