دليل التصميم المعياري لتطبيقات Native Shell (NSH). اقرأه قبل تصميم أو تعديل أي شاشة أو تخطيط أو تباعد أو تسلسل بصري أو لون أو كثافة أو اختيار مكوّن أو حالة تفاعل أو طبقة تغطية أو حركة أو عرض كثيف بالبيانات أو نسخة واجهة في تطبيق NSH، سواءً كان بـ TSX أو Rust، وقبل مراجعة عمل واجهة المستخدم لجودة التصميم. استخدمه أيضًا عندما يُسأل عن قواعد التصميم أو ما إذا كان قرار واجهة المستخدم يتبعها.
