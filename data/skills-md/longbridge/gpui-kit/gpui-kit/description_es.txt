Cómo crear aplicaciones de escritorio con GPUI Kit, el marco Rust publicado como caja gpui-kit (GPUI más gpui_kit::component, gpui_kit::base, gpui_kit::assets). Úselo al configurar una aplicación gpui-kit, elegir o usar un componente (botón, entrada, selección, cuadro de diálogo, hoja, pestañas, barra lateral, lista, tabla de datos, árbol, gráfico, etc.), manejar el estado del componente, temas o superposiciones de ventanas, y para la mecánica de GPUI: acciones y combinaciones de teclas, tareas asíncronas, contextos, elementos personalizados, entidades, eventos, enfoque, estado global, diseño y estilo, ElementId y pruebas. Contiene las Guías de codificación normativas: léalas antes de cualquier decisión sobre arquitectura, propiedad estatal, API pública, denominación o prueba. Se combina con la habilidad gpui-kit-design-guides para las Guías de diseño.
