كيفية إنشاء تطبيقات سطح المكتب باستخدام مجموعة GPUI، تم نشر إطار عمل Rust كصندوق gpui-kit (GPUI plus gpui_kit::component, gpui_kit::base, gpui_kit::assets). يُستخدم عند إعداد تطبيق gpui-kit، أو اختيار مكون أو استخدامه (زر، أو إدخال، أو تحديد، أو مربع حوار، أو ورقة، أو علامات تبويب، أو شريط جانبي، أو قائمة، أو DataTable، أو شجرة، أو مخطط، وما إلى ذلك)، أو التعامل مع حالة المكون، أو السمات، أو تراكبات النوافذ، ولآليات GPUI: الإجراءات وارتباطات المفاتيح، والمهام غير المتزامنة، والسياقات، والعناصر المخصصة، والكيانات، والأحداث، والتركيز، والحالة العامة، والتخطيط والتصميم، وElementId، والاختبارات. يحمل أدلة الترميز المعيارية: اقرأها قبل أي قرار يتعلق بالهندسة المعمارية أو ملكية الدولة أو واجهة برمجة التطبيقات العامة أو التسمية أو الاختبار. يقترن بمهارة gpui-kit-design-guides لأدلة التصميم.
