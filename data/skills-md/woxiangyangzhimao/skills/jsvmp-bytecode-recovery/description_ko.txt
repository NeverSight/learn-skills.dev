JSVMP/VMP 가상 머신 보호 역공학 방법론 — 원래 로직을 바이트코드로 컴파일하고 AST로 직접 복원할 수 없는 대형 배열 + 인터프리터 + 디스패치 루프와 같은 어려운 경우(예: Douyin a_bogus, Geetest 4 w, Ruishu, Ctrip 등)를 다룰 때는 코드를 무작정 삭제하거나 환경을 강제로 패치하기보다 “먼저 인터프리터를 찾고 → 연산 코드를 기록하도록 계측하고 → 디스어셈블하고 → 목표 경로를 재구성한다”는 체계적인 절차를 사용한다. 트리거 키워드: “JSVMP”, “virtual machine protection”, “vmp”, “bytecode”, “opcode”, “large‑array interpreter”, “a_bogus”, “w parameter”, “dispatch loop”, “switch interpreter”, “cannot strip this code”. 대상 암호화 로직이 VM 바이트코드이며 AST 디오브퓨스케이션이 효과가 없다고 확인된 경우에 사용한다. 범위: VM 바이트코드 복원 방법론만 다루며, 알고리즘을 복구한 후에는 param‑encryptor에 전달한다; 순수 계산을 포기하고 환경 패치로 전환하기로 하면 env‑patcher에 전달한다.
