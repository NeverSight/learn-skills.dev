JSVMP/VMP バーチャルマシン保護のリバースエンジニアリング手法 — 大規模配列＋インタプリタ＋ディスパッチループで元のロジックをバイトコードに変換し、AST だけでは直接復元できないハードケース（例：Douyin の a_bogus、Geetest の 4 w、Ruishu、Ctrip など）に直面した場合は、盲目的にコードを除去したり環境を総当たりで解析したりするのではなく、 「まずインタプリタを特定 → オペコード記録用に計測 → 逆アセンブル → 目的パスを再構築」 という disciplined なプロセスでリバースエンジニアリングを行う。トリガーキーワード: “JSVMP”, “virtual machine protection”, “vmp”, “bytecode”, “opcode”, “large‑array interpreter”, “a_bogus”, “w parameter”, “dispatch loop”, “switch interpreter”, “cannot strip this code”。対象の暗号化ロジックが VM バイトコードであり、AST デオブフスケーションが効果がないと確認された場合に適用する。範囲: VM バイトコードの復旧手法のみを扱い、アルゴリズムを再構築したら param‑encryptor に渡す。純粋な計算を放棄して環境パッチに切り替える場合は env‑patcher に引き渡す。
