キャッシュルールがビルドに失敗する原因となる Java のチェック――Java、Spring Boot、ArchUnit、Error Prone、Jackson、Maven、JUnit、Testcontainers、Toxiproxy の各ディレクティブをどのツールが強制するか――に加えて、キャッシュエンジンの選択（名前で禁止された Redis 7.4 から 7.8 を含む Valkey）、一度きりのゲート配線、そしてこのツールチェーンがチェックを配置できない名前付きギャップがあります。キャッシュ、メモ、ロードキャッシュ、キャッシュアノテーション、期限、またはキャッシュエンジンを追加する前に、必ずキャッシュスキルと一緒に Java リポジトリにロードしてください。ここにあるエンジン選択以外のすべてのチェックは、キャッシュスキル内に存在するディレクティブ ID に紐付けられています。
