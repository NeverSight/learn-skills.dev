Проверки Java, вызывающие провал правил кэширования при сборке — какой инструмент применяется к каждой директиве в Java, Spring Boot, ArchUnit, Error Prone, Jackson, Maven, JUnit, Testcontainers и Toxiproxy — плюс выбор движка кэша (Valkey, при этом Redis 7.4‑7.8 запрещён по названию), однократное подключение шлюза и именованные пробелы, где эта цепочка инструментов не может разместить проверку. ВСЕГДА загружайте в репозиторий Java вместе с навыком кэширования, прежде чем добавлять кэш, мемо, загрузочный кэш, аннотацию кэширования, истечение срока или движок кэша. Каждая проверка здесь, кроме выбора движка, привязана к идентификатору директивы, который находится в навыке кэширования.
