Include il caso pratico di questo set di competenze: Java con Spring Boot Web MVC, jOOQ e PostgreSQL, con i perdenti a livello di linguaggio — C#/.NET, Kotlin, Go e TypeScript, ognuno con il motivo per cui ha perso — più il verdetto su ogni configurazione che un'organizzazione può assemblare a partire dalle scelte di stack — uno stack secondario accanto al primo, un secondo linguaggio all'interno di un repository, e un candidato rifiutato che arriva comunque come dipendenza.
