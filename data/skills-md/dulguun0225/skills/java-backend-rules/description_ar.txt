دستور المنصة للواجهة الخلفية للجاڤا باستخدام Spring Boot Web MVC، jOOQ وPostgreSQL — القواعد التي تُلزم كل سطر من الكود في المستودع، كل منها ببوابة بناء مسماة. Reactive WebFlux، JPA وHibernate، Spring Data JDBC وعائلة JdbcTemplate، عمليات CRUD المرتبطة بسجلات jOOQ، سلاسل SQL العادية، DSLContext القابل للحقن، مجمعات الخيوط الثابتة لمعالجة الطلبات، StructuredTaskScope، إشارة إضافية (semaphore) على مجموعة الاتصالات، قراءات الوقت الحقيقي في كود النطاق، حدود الطول `octet_length` و`varchar(n)` في عمليات الترحيل، `create trigger` و`create function` في عمليات الترحيل، وتعليقات Spring الصامتة وقت التنفيذ — حقن الحقول، @Transactional، @Scheduled، @Async، @Cacheable — محظورة بالاسم، كل منها مع فحص يُفشل البناء. احمِل دائمًا قبل كتابة استعلام، أو معاملة، أو توسيع داخل الطلب، أو ترحيل Flyway، أو مهمة مجدولة، أو اختبار على هذه المجموعة، قبل اختيار مكتبة للثبات، أو التزامن، أو JSON أو الفحص من null، وقبل إنشاء ملف بناء أو تثبيت نسخة Java أو Spring Boot لمستودع جديد.
