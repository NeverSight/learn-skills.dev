Spring Boot Web MVC、jOOQ、PostgreSQL を使用した Java バックエンドのプラットフォーム憲法 — リポジトリ内のすべてのコード行を束縛する規則で、各々に名前付きビルドゲートがあります。Reactive WebFlux、JPA と Hibernate、Spring Data JDBC と JdbcTemplate 系列、jOOQ の attached‑record CRUD、プレーン SQL 文字列、注入可能な DSLContext、リクエスト処理用の固定スレッドプール、StructuredTaskScope、コネクションプール上の余分なセマフォ、ドメインコード内の実時間読み取り、マイグレーションにおける `octet_length` と `varchar(n)` の長さ制限、マイグレーションにおける `create trigger` と `create function`、そして実行時に静かな Spring アノテーション――フィールドインジェクション、@Transactional、@Scheduled、@Async、@Cacheable――は名前で禁止されており、ビルドを失敗させるチェックがそれぞれ設定されています。 このスタック上でクエリ、トランザクション、リクエスト内のファンアウト、Flyway マイグレーション、スケジュールタスク、テストを書く前には必ずロードし、永続化、並行性、JSON、または null 安全性ライブラリを選択する前にも、そして新しいリポジトリ用にビルドファイルを作成したり Java や Spring Boot のバージョンを固定したりする前にもロードしてください。
