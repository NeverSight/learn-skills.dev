La constitución de la plataforma para un backend Java en Spring Boot Web MVC, jOOQ y PostgreSQL — las reglas que vinculan cada línea de código en el repositorio, cada una con una puerta de compilación nombrada. Reactive WebFlux, JPA y Hibernate, Spring Data JDBC y la familia JdbcTemplate, el CRUD de registros adjuntos de jOOQ, cadenas SQL planas, un DSLContext inyectable, pools de hilos fijos para el trabajo de solicitudes, StructuredTaskScope, un semáforo extra sobre el pool de conexiones, lecturas de reloj de pared en el código de dominio, `octet_length` y los límites de longitud `varchar(n)` en migraciones, `create trigger` y `create function` en migraciones, y las anotaciones silenciosas en tiempo de ejecución de Spring — inyección de campos, @Transactional, @Scheduled, @Async, @Cacheable — están prohibidas por nombre, cada una con la verificación que falla la compilación. SIEMPRE cargue antes de escribir una consulta, una transacción, una expansión dentro de la solicitud, una migración Flyway, una tarea programada o una prueba en esta pila, antes de elegir una biblioteca de persistencia, concurrencia, JSON o nulidad para ella, y antes de crear un archivo de compilación o fijar la versión de Java o Spring Boot para un nuevo repositorio.
