Spring Boot Web MVC, jOOQ, PostgreSQL 기반 Java 백엔드에 대한 플랫폼 헌법 — 레포지토리의 모든 코드 라인을 묶는 규칙이며, 각각 이름이 지정된 빌드 게이트가 있다. Reactive WebFlux, JPA와 Hibernate, Spring Data JDBC 및 JdbcTemplate 계열, jOOQ의 attached‑record CRUD, 순수 SQL 문자열, 주입 가능한 DSLContext, 요청 작업을 위한 고정 스레드 풀, StructuredTaskScope, 커넥션 풀 위에 추가된 세마포어, 도메인 코드에서의 실시간(벽시계) 읽기, 마이그레이션에서의 `octet_length`와 `varchar(n)` 길이 제한, 마이그레이션에서의 `create trigger`와 `create function`, 그리고 런타임에 조용한 Spring 어노테이션 — 필드 인젝션, @Transactional, @Scheduled, @Async, @Cacheable — 은 이름 그대로 금지되며, 각각 빌드를 실패하게 하는 체크가 있다. 이 스택에서 쿼리, 트랜잭션, 요청 내부 팬아웃, Flyway 마이그레이션, 스케줄러 작업 또는 테스트를 작성하기 전에 항상 로드하고, 이를 위해 영속성, 동시성, JSON 또는 널 가능성 라이브러리를 선택하기 전, 그리고 새로운 레포에 빌드 파일을 만들거나 Java 혹은 Spring Boot 버전을 고정하기 전에도 반드시 로드한다.
