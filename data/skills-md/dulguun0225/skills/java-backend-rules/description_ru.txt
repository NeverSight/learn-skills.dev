Конституция платформы для Java‑бэкенда на Spring Boot Web MVC, jOOQ и PostgreSQL — правила, связывающие каждую строку кода в репозитории, каждая со своим именованным билдинг‑гейтом. Reactive WebFlux, JPA и Hibernate, Spring Data JDBC и семейство JdbcTemplate, CRUD‑операции jOOQ с attached‑record, строки plain‑SQL, внедряемый DSLContext, фиксированные пулы потоков для обработки запросов, StructuredTaskScope, дополнительный семафор над пулом соединений, измерения реального времени в доменном коде, ограничения `octet_length` и `varchar(n)` в миграциях, `create trigger` и `create function` в миграциях, а также тихие во время выполнения аннотации Spring — field injection, @Transactional, @Scheduled, @Async, @Cacheable — запрещены по имени, каждая с проверкой, проваливающей сборку. ВСЕГДА загружайте перед написанием запроса, транзакции, фан‑аута внутри запроса, миграции Flyway, запланированной задачи или теста в этом стеке, перед выбором библиотеки для работы с persistence, concurrency, JSON или null‑safety, и перед созданием файла сборки или фиксированием версии Java или Spring Boot для нового репозитория.
