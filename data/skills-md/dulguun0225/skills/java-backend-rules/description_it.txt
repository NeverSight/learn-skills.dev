La costituzione della piattaforma per un backend Java su Spring Boot Web MVC, jOOQ e PostgreSQL — le regole che vincolano ogni riga di codice nel repository, ciascuna con un gate di build nominato. Reactive WebFlux, JPA e Hibernate, Spring Data JDBC e la famiglia JdbcTemplate, il CRUD di record collegati di jOOQ, stringhe plain‑SQL, un DSLContext iniettabile, pool di thread fissi per il lavoro di request, StructuredTaskScope, un semaforo extra sul pool di connessioni, letture dell’orologio reale nel codice di dominio, limiti di lunghezza `octet_length` e `varchar(n)` nelle migrazioni, `create trigger` e `create function` nelle migrazioni, e le annotazioni silenziose di Spring a runtime — injection di campo, @Transactional, @Scheduled, @Async, @Cacheable — sono vietate per nome, ognuna con il controllo che fa fallire la build.
