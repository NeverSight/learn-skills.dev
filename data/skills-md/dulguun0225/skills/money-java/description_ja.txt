Java のチェックは、マネーのルールがビルドに失敗する原因です — どのツールが Java、Spring Boot MVC、Jackson、jOOQ、PostgreSQL、Flyway、Testcontainers の各ディレクティブを強制し、さらに一度だけのゲート配線と手作りのマネー型決定を行うかを示します。マネー、money‑api、money‑storage のスキルとともに Java リポジトリを常にロードし、マネー型、マネーフィールド、丸めステップ、マネーエンドポイント、マネーカラム、マイグレーション、または金額を取得するクエリを追加する前に行ってください。ここにあるすべてのチェックは、これら 3 つのスキルに存在するディレクティブ ID に紐付けられています。
