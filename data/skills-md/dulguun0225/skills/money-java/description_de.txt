Die Java‑Checks, die die Money‑Regeln zum Fehlschlagen des Builds führen — welches Tool setzt jede Direktive für Java, Spring Boot MVC, Jackson, jOOQ, PostgreSQL, Flyway und Testcontainers durch, plus die einmalige Gate‑Verdrahtung und die selbst erstellte Money‑Typ‑Entscheidung.  
LADEN SIE IMMER ein Java‑Repository zusammen mit den Skills money, money‑api und money‑storage, bevor Sie einen Money‑Typ, ein Money‑Feld, einen Rundungsschritt, einen Money‑Endpoint, eine Money‑Spalte, eine Migration oder eine Abfrage, die einen Betrag liest, hinzufügen.  
Jeder Check hier ist an eine Direktiven‑ID gekoppelt, die in diesen drei Skills existiert.
