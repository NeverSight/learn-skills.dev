Les vérifications Java qui font échouer les règles monétaires lors du build — quel outil applique chaque directive sur Java, Spring Boot MVC, Jackson, jOOQ, PostgreSQL, Flyway et Testcontainers, ainsi que le câblage ponctuel du gate et la décision du type monétaire fait maison. TOUJOURS charger un dépôt Java aux côtés des compétences money, money‑api et money‑storage, avant d’ajouter un type monétaire, un champ monétaire, une étape d’arrondi, un endpoint monétaire, une colonne monétaire, une migration ou une requête qui lit un montant. Chaque vérification ici est liée à un identifiant de directive qui réside dans ces trois compétences.
