Las verificaciones de Java que hacen que las reglas de dinero fallen la compilación — qué herramienta aplica cada directiva en Java, Spring Boot MVC, Jackson, jOOQ, PostgreSQL, Flyway y Testcontainers, además del cableado de puerta única y la decisión de tipo de dinero hecha a mano. SIEMPRE cargue en un repositorio Java junto con las habilidades money, money-api y money-storage, antes de añadir un tipo de dinero, un campo de dinero, un paso de redondeo, un endpoint de dinero, una columna de dinero, una migración o una consulta que lea una cantidad. Cada verificación aquí está asociada a un id de directiva que vive en esas tres habilidades.
