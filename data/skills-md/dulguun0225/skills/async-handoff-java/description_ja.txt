ビルドを失敗させる非同期ハンドオフ規則を作る Java のチェック – どのツールが Java、Spring Boot、Spring for Apache Kafka、ArchUnit、Error Prone、Jackson、jOOQ、Flyway、Maven、JUnit、jqwik、Testcontainers、Toxiproxy の各ディレクティブを実施するか – に加えて、ブローカー選択（KRaft モードの Apache Kafka、名前で禁止されている Redpanda と AutoMQ）、アウトボックスライブラリ選択、一度限りのゲート配線、そしてこのツールチェーンがチェックを配置できない名前付きギャップがあります。メッセージを公開したり、キューやブローカークライアント、インプロセスイベントバス、エグゼキュータの submit、@Async または @Scheduled タスク、ポーリングテーブル、アウトバウンド Webhook を追加する前に、必ず async‑handoff スキルと共に Java リポジトリをロードしてください。ここにあるチェックのうちブローカーとアウトボックスの選択を除くすべては、async‑handoff に存在するディレクティブ ID に紐付けられています；複合形チェックは shapes.md にあります。
