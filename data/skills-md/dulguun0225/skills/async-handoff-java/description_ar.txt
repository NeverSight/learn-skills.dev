فحوصات Java التي تجعل قواعد التسليم غير المتزامن تفشل في البناء — أي أداة تفرض كل توجيه على Java، Spring Boot، Spring for Apache Kafka، ArchUnit، Error Prone، Jackson، jOOQ، Flyway، Maven، JUnit، jqwik، Testcontainers وToxiproxy — بالإضافة إلى اختيار الوسيط (Apache Kafka في وضع KRaft، مع حظر Redpanda وAutoMQ بالاسم)، واختيار مكتبة outbox، وربط البوابة لمرة واحدة، والفجوات المسماة حيث لا يمكن لسلسلة الأدوات هذه استضافة أي فحص. احمِل دائمًا مستودع Java إلى جانب مهارة async-handoff، قبل نشر رسالة، أو إضافة طابور أو عميل وسيط، أو حافلة أحداث داخلية، أو تقديم تنفيذ، أو مهمة @Async أو @Scheduled، أو جدول مستطلع، أو ويب هوك صاعد. كل فحص هنا باستثناء اختيارات الوسيط وoutbox يرتبط بهوية توجيه موجودة في async-handoff؛ فحوصات الشكل المركب موجودة في shapes.md.
