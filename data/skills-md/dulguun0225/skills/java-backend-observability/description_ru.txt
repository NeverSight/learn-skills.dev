Логирование, метрики и правила оповещений для Java‑бэкенда на Spring Boot, развернутой системы, за которой никто не следит между инцидентами, — единый типизированный фасад логирования с доменными типами, нечитаемыми по типу, каталоги событий и метрик, проверяемые компилятором, поля корреляции, устанавливаемые видимыми обёртками и явно фиксируемые при каждом форке виртуального потока, ограниченная кардинальность меток метрик и реализованные правила оповещений, каждое из которых содержит тестовое срабатывание. Путь -javaagent с внедрением байт‑кода, сырые API логгера с произвольными сообщениями, очистка PII с помощью регулярных выражений в конвейере, метки метрик per‑user или per‑request, дашборды как основной интерфейс и непроверенные правила оповещений запрещены по названиям, каждое с проверкой, которая проваливает сборку.
