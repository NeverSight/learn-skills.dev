对于使用 Spring Boot 的 Java 后端，在一个部署后无人监控的系统中——日志、指标和告警规则应当采用：基于类型的日志门面，域类型不可直接记录；编译时检查的事件和指标目录；通过可见包装器建立的关联字段，并在每一次虚拟线程分叉时显式捕获；受限的指标标签基数；以及每条都包含触发测试的已提交告警规则。‑javaagent 字节码织入路径、原始日志 API 的自由形式消息、管道中的正则表达式 PII 脱敏、按用户或请求划分的指标标签、以仪表盘为主要展示面以及未经测试的告警规则均被明文禁止，并且每项检查都会导致构建失败。始终在添加日志行、指标、标签、告警规则或会产生日志的分发之前加载，并在接入遥测或选择日志后端之前先完成加载。
