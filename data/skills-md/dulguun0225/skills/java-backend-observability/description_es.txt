El registro, las métricas y las reglas de alerta para un backend Java en Spring Boot, para un sistema desplegado que nadie vigila entre incidentes — una fachada de registro tipada con tipos de dominio no registrables por tipo, catálogos de eventos y métricas verificados en tiempo de compilación, campos de correlación establecidos por envoltorios visibles y capturados explícitamente en cada bifurcación de hilo virtual, cardinalidad limitada de etiquetas de métricas y reglas de alerta comprometidas que cada una lleva una prueba de disparo. La ruta de -javaagent de tejido de bytecode, las API de registro crudo con mensajes libres, el borrado de PII mediante expresiones regulares en la canalización, etiquetas de métricas por usuario o por solicitud, los tableros como superficie primaria y las reglas de alerta no probadas están prohibidas por nombre, cada una con la comprobación que falla la compilación. SIEMPRE cargue antes de agregar una línea de registro, una métrica, una etiqueta, una regla de alerta o una difusión que registre, y antes de cablear la telemetría o elegir un backend de registro.
