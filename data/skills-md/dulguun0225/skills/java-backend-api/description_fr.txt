Règles de contrat HTTP pour un backend Java sous Spring Boot Web MVC. Charger avant d'ajouter ou de modifier un point de terminaison, un champ de requête ou de réponse, un paramètre de liste ou de pagination, une forme d'erreur, un curseur ou la version de l'API, et avant de brancher les étapes de génération du contrat, de lint, de diff ou de fuzz.
