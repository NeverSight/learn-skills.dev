استخدمه عندما يرغب المستخدم في إكمال يومية أو للاسترخاء، أو طلب مراجعة يومية لكبير الأركان أو مراجعة أسبوعية أو ربع سنوية، أو طلب إعداد، أو قائمة، أو إضافة، أو تحديث، أو إزالة خرائط مصدر كبير الأركان، أو الموافقة على إجراءاتvisible لكبير الأركان، أو استئنافها أو اتخاذ قرارات بشأنها، أو عندما يتطلب سير عمل آخر السياق الحالي لكبير الأركان عبر المصادر. لا تستخدمه للملخصات الصباحية، أو تخطيط بداية اليوم، أو تصنيف المهام التي تحتاج انتباهًا في نفس اليوم، أو لإنشاء مهام منفصلة، أو كتابة مسألة، أو معالجة البريد الإلكتروني، أو تعديل التقويم، أو تحليل الصحة، أو تحضير الاجتماعات، أو تخطيط المشاريع.

يرجى دائمًا الرد بلغة المستخدم.
