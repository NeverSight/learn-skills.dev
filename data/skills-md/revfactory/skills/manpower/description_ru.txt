ИИ подсказывает измерение уровня навыков и анализ роста. Анализирует запросы пользователей из журналов сеансов Claude Code для расчета оценок по восьми осям компетенций и визуализирует их с помощью радиолокационной диаграммы и еженедельных тенденций роста. Триггеры: /manpower, измерение навыков ИИ, оперативный анализ, компетентность ИИ, уровень квалификации, рабочая сила, квалификация ИИ, способность подсказки, анализ использования ИИ.
