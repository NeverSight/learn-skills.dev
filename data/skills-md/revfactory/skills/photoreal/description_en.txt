Prompt design skills for creating realistic photos without an AI feel, especially portrait photos. It provides layers of instructions, assembly rules, and a post‑generation checklist that make the result look like an SNS snap taken with a smartphone, counteracting the advertising‑style perfection that image models are naturally inclined toward. Use this skill whenever terms like “realistic,” “photo‑like,” “like a photograph,” “real photo,” “no AI trace,” “not AI‑like,” “like a real person,” “authentic presence,” “SNS photo,” “selfie,” “snap photo,” “portrait,” “profile picture,” “daily photo,” or “real‑photo prompt” appear, and in any case where a photo‑style image featuring a person is being generated. Even if the user doesn’t explicitly use the word “realistic,” if the request is for the output to look like a taken photograph, this applies. The actual image generation is handled by image‑generation tools such as codex‑image; this skill creates the prompt. Requests for non‑photo styles like illustration, anime, 3D render, logo, or diagram are excluded.
