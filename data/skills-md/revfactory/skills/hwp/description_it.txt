Utilizza questa abilità ogni volta che l'utente desidera eseguire qualsiasi operazione con file HWP o HWPX. Ciò include la lettura o l'estrazione di testo/tabelle/immagini da file HWP, la conversione di HWP in markdown o altri formati, la creazione di file HWPX da markdown/testo, l'analisi dei formati binari HWP (OLE2/CFB) o HWPX (ZIP/XML) e la gestione dell'elaborazione dei documenti coreani. Se l'utente menziona un file .hwp o .hwpx o chiede informazioni sull'elaborazione del file 한글 문서, utilizza questa abilità.
