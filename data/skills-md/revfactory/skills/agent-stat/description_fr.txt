Une compétence qui conçoit et crée des agents à l'aide d'une architecture à trois couches (Role·Trait Vector·Policy). Il définit quantitativement les tendances comportementales d'un agent avec un vecteur de traits à huit axes (affirmation de soi · enracinement · planification · sociabilité · coopération · propension au risque · affinité avec les outils · réflexivité), convertit chaque valeur d'axe en politiques comportementales concrètes et génère un fichier de définition `.claude/agents/{name}.md`. Lorsqu'une demande est faite pour créer un nouvel agent ou pour définir/ajuster ses tendances comportementales, telles que « créer un agent », « concevoir un agent », « statistiques d'agent/statistiques de roulement », « vecteur de traits », « définir la disposition de l'agent », « créer un réviseur/chercheur/agent de construction », « définir la politique de comportement de l'agent », « feuille de caractère de l'agent », « régler les statistiques de l'agent », « changer la personnalité de l'agent », etc. – cette compétence doit être utilisée. Cependant, si la demande implique l'assemblage de l'ensemble de l'architecture de l'équipe, de l'orchestrateur et des compétences de liaison, dirigez l'utilisateur vers `/harness:harness` ; si la demande consiste à inspecter ou à améliorer un agent existant via une conversation, dirigez-le vers `/agent-1on1`.
