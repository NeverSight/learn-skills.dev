A skill for designing and creating agents using a three‑layer architecture (Role · Trait Vector · Policy). It quantitatively sets an agent’s behavioral tendencies with an eight‑axis trait vector (leadership, groundedness, planning, sociability, cooperativeness, risk inclination, tool inclination, reflection), converts the values on each axis into concrete action policies (Policy), and generates a definition file `.claude/agents/{name}.md`. When a request is made to create a new agent or to define and adjust its behavior—e.g., “make an agent,” “design an agent,” “agent stats / roll stats,” “trait vector,” “set agent tendency,” “create reviewer/researcher/builder agent,” “define agent action policy,” “agent character sheet,” “tune agent stats,” “change agent personality,” etc.—this skill must be used. However, composing the entire team architecture, orchestrator, and connection skills together is handled via `/harness:harness`, and reviewing or improving an existing agent through conversation is directed to `/agent-1on1`.
