Навык генерации изображений с использованием встроенного инструмента image_generation в интерфейсе командной строки OpenAI Codex («codex exec»). Поддерживает одиночную, пакетную и параллельную генерацию. Ключевым преимуществом является **до 5 изображений, создаваемых параллельно одновременно** (скорость в 2,4–2,85 раза по сравнению с измеренным последовательным выполнением). Аутентификация осуществляется через ChatGPT OAuth, поэтому отдельный код вызова OPENAI_API_KEY не требуется. Сценарий использования: когда пользователь упоминает «изображение кодекса», «генерация изображений кодекса», «кодовое изображение», «параллельное создание изображений», «несколько изображений одновременно», «изображение N одновременно», «пакетное создание изображений», «параллельное создание изображений», «изображение кодекса» и т. д., или любой случай, когда необходимо быстро создать более трех изображений одновременно. Однако для простых одиночных изображений, выходных изображений с высоким разрешением (2K+), точного редактирования маскирования или композиции из нескольких ссылок более подходящим является навык `gpt-image2` или `gemini-3-pro-imagegen`. Прямые вызовы веб-сайта/приложения ChatGPT или API OpenAI выходят за рамки этого навыка.
