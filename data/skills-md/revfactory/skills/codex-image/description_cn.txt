使用 OpenAI Codex CLI 的内置“image_ Generation”工具（“codex exec”）生成图像的技能。支持单次、批量、并行生成。关键优势是**同时并行生成最多 5 个图像**（与测得的串行执行速度相比，速度为 2.4–2.85 倍）。通过 ChatGPT OAuth 进行身份验证，因此不需要单独的 OPENAI_API_KEY 调用代码。使用场景：当用户提及“codex image”、“codex imagegen”、“codex 미지 생성”、“并行图像生成”、“一次生成多个图像”、“一次生成 N 个图像”、“批量图像生成”、“imagegen 并行”、“codex 图片”等，或者任何需要同时快速创建三个以上图像的情况。然而，对于简单的单图像、高分辨率 (2K+) 输出、精确的遮罩编辑或多参考合成，“gpt-image2”或“gemini-3-pro-imagegen”技能更合适。直接调用 ChatGPT Web/应用程序或 OpenAI API 超出了本技能的范围。
