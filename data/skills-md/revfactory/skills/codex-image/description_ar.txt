مهارة تنشئ الصور باستخدام أداة `image_generator` المدمجة في OpenAI Codex CLI (`codex exec`). يدعم الجيل الفردي والدفعي والمتوازي. القوة الأساسية هي **التوليد المتوازي المتزامن لما يصل إلى 5 صور** (2.4–2.85× أسرع من الجيل التسلسلي المُقاس). تتم المصادقة عبر ChatGPT OAuth، لذلك ليست هناك حاجة إلى رمز اتصال OPENAI_API_KEY منفصل. متى يتم الاستخدام: عندما يذكر المستخدم عبارات مثل "صورة تحتوي على مخطوطة"، أو "مخطوطة مخطوطة"، أو "مخطوطة مخطوطة"، أو "إنشاء صور متوازية"، أو "صور متعددة في وقت واحد"، أو "عدد N من الصور في وقت واحد"، أو "إنشاء مجموعة صور دفعة واحدة"، أو "imagegen متوازي"، أو "مخطوطة مخطوطة"، وما إلى ذلك، أو أي حالة تحتاج إلى إنشاء ثلاث صور أو أكثر بسرعة في نفس الوقت. ومع ذلك، بالنسبة للصور الفردية البسيطة، أو الصور عالية الدقة (2K+)، أو تعديلات الإخفاء الدقيقة، أو التركيب متعدد المراجع، فإن مهارة `gpt-image2` أو `gemini-3-pro-imagegen` تكون أكثر ملاءمة. يعد استخدام الويب/التطبيق ChatGPT أو الاتصال مباشرة بـ OpenAI API خارج نطاق هذه المهارة.
