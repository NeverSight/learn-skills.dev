Compétence qui génère des images à l'aide de l'outil `image_generation` intégré de la CLI OpenAI Codex (`codex exec`). Prend en charge la génération unique, par lots et parallèle. La force du noyau est **jusqu'à 5 images générées en parallèle simultanément** (2,4 à 2,85 fois plus rapide que la génération en série mesurée). Authentifié via ChatGPT OAuth, aucun code d'appel OPENAI_API_KEY distinct n'est donc requis. Quand l'utiliser : lorsque l'utilisateur mentionne « codex 로 이미지 », « codex imagegen », « codex 이미지 생성 », « 병렬 이미지 생성 », « 여러 장 이미지 동시 », « 이미지 N장 한번에 », « 배치 이미지 생성 », « imagegen 병렬 », « codex 그림 », etc., ou tout cas où trois images ou plus doivent être créées rapidement en même temps. Cependant, les tâches simples d'image unique, haute résolution (2K+), d'édition de masquage précise ou de composition multi-références sont mieux adaptées aux compétences « gpt-image2 » ou « gemini-3-pro-imagegen ». Les appels directs vers le Web/l'application ChatGPT ou l'API OpenAI n'entrent pas dans le cadre de cette compétence.
