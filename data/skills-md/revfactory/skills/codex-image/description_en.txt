Skill that generates images using the built-in `image_generation` tool of the OpenAI Codex CLI (`codex exec`). Supports single, batch, and parallel generation. The key strength is **up to 5 images generated in parallel simultaneously** (2.4–2.85× speed compared to measured serial execution). Authenticated via ChatGPT OAuth, so no separate OPENAI_API_KEY call code is needed. Usage scenario: when the user mentions “codex image,” “codex imagegen,” “codex 이미지 생성,” “parallel image generation,” “multiple images at once,” “image N at once,” “batch image generation,” “imagegen parallel,” “codex picture,” etc., or any case where more than three images need to be created quickly at the same time. However, for simple single images, high‑resolution (2K+) outputs, precise masking edits, or multi‑reference composition, the `gpt-image2` or `gemini-3-pro-imagegen` skill is more appropriate. Direct calls to the ChatGPT web/app or the OpenAI API are outside the scope of this skill.
