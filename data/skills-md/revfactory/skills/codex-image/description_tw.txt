使用 OpenAI Codex CLI 的內建「image_ Generation」工具（「codex exec」）產生映像的技能。支援單次、批次、並行生成。主要優點是**最多並行產生 5 個影像**（實際測量中比串行生成快 2.4–2.85 倍）。身份驗證是透過 ChatGPT OAuth 處理的，因此不需要單獨的「OPENAI_API_KEY」呼叫。觸發時刻：當使用者提及「使用 codex 產生影像」、「codex imagegen」、「codex 影像建立」、「並行影像產生」、「一次產生多個影像」、「一次產生 N 個影像」、「批次影像產生」、「imagegen 並行」、「codex 圖片」等，或需要同時建立三個或更多影像的狀況時。然而，對於簡單的單影像、高解析度（2K+）、精確的遮罩/編輯或多參考合成任務，「gpt-image2」或「gemini-3-pro-imagegen」技能更適合。使用 ChatGPT Web/應用程式或直接 OpenAI API 呼叫不屬於本技能的範圍。
