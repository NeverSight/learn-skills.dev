OpenAI Codex CLI (`codex exec`) の組み込み `image_generation` ツールを使用してイメージを生成するスキル。単一、バッチ、および並列生成をサポートします。主な強みは、**最大 5 つの画像を並列生成** (測定された連続生成よりも 2.4 ～ 2.85 倍高速) であることです。 ChatGPT OAuth で認証されるため、個別の `OPENAI_API_KEY` 呼び出しコードは必要ありません。使用する場合: ユーザーが「コーデックス付きの画像」、「コーデックス imagegen」、「コーデックス 이미지 생성」、「並列画像生成」、「一度に複数の画像」、「一度に N 個の画像」、「バッチ画像生成」、「imagegen 並列」、「コーデックス画像」などに言及したとき、または 3 つ以上の画像を同時に素早く作成する必要がある状況。ただし、単純な単一画像、高解像度 (2K+)、正確なマスキング編集、または複数参照合成の場合は、「gpt-image2」または「gemini-3-pro-imagegen」スキルの方が適しています。 ChatGPT Web/アプリまたは OpenAI API への直接呼び出しは、このスキルの範囲外です。
