Rendez des vidéos à partir du code de composants React/Remotion via inference.sh. Fournissez du code TSX, obtenez du MP4. Prend en charge toutes les API Remotion : useCurrentFrame, useVideoConfig, spring, interpolate, AbsoluteFill, Sequence. Résolution, FPS, durée et codec configurables. À utiliser pour : génération de vidéos programmatiques, graphiques animés, design de motion, vidéos basées sur les données, animations React vers vidéo. Déclencheurs : remotion, rendre vidéo à partir du code, tsx en vidéo, vidéo react, vidéo programmatique, rendu remotion, code en vidéo, vidéo animée, code de graphiques en mouvement, vidéo d’animation react.
