Выполняйте Python‑код в безопасной изолированной среде через [inference.sh](https://inference.sh). Предустановлены: NumPy, Pandas, Matplotlib, requests, BeautifulSoup, Selenium, Playwright, MoviePy, Pillow, OpenCV, trimesh и более 100 других библиотек. Используйте для: обработки данных, веб‑скрапинга, манипуляции изображениями, создания видео, обработки 3D‑моделей, генерации PDF, вызовов API, автоматизационных скриптов. Триггеры: python, выполнить код, запустить скрипт, веб‑скрапинг, анализ данных, обработка изображений, видеомонтаж, 3D‑модели, автоматизация, pandas, matplotlib.
