Automatisation du navigateur pour les agents IA via inference.sh. Naviguez sur des pages web, interagissez avec les éléments à l'aide des références @e, prenez des captures d'écran, enregistrez des vidéos. Fonctionnalités : extraction de données web, remplissage de formulaires, clics, saisie, glisser‑déposer, téléchargement de fichiers, exécution de JavaScript. Utilisations : automatisation web, extraction de données, tests, navigation d'agents, recherche. Déclencheurs : navigateur, automatisation web, extraction, navigation, clic, remplir formulaire, capture d'écran, navigation web, playwright, navigateur sans tête, agent web, surfer sur internet, enregistrement vidéo.
