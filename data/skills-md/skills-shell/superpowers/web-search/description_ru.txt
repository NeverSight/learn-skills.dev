Веб‑поиск и извлечение контента с помощью Tavily и Exa через CLI inference.sh. Приложения: Tavily Search, Tavily Extract, Exa Search, Exa Answer, Exa Extract. Возможности: поиск на основе ИИ, извлечение контента, прямые ответы, исследования. Использовать для: исследований, пайплайнов RAG, проверки фактов, агрегации контента, агентов. Триггеры: веб‑поиск, tavily, exa, search api, извлечение контента, исследование, интернет‑поиск, ai search, помощник поиска, веб‑скрапинг, rag, альтернатива Perplexity.
