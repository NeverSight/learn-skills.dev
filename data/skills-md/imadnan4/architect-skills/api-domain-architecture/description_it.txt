Come progettare le API attorno ai BUSINESS DOMAINS, non alle tabelle del database. Da utilizzare quando si progettano endpoint REST/GraphQL/gRPC/WebSocket, comandi vs risorse, autenticazione, validazione, idempotenza, paginazione, versionamento, contratti di errore, caching, limiti di velocità.

Per favore rispondi sempre nella lingua dell'utente.
