Activez ou désactivez un rappel de maintien périodique ou ponctuel pour la session d’agent de codage en cours (Claude Code, Codex CLI ou Grok Build), ajustez sa fréquence ou indiquez s’il est activé. Le rappel est un message du type « [HH:MM:SS] Rappel automatisé : continuez à travailler … » qu’un travail d’arrière‑plan du système d’exploitation (launchd / timer systemd / cron / Planificateur de tâches Windows) insère dans les terminaux d’agent ayant accepté, toutes les 61 minutes par défaut. Utilisez‑le avec « /session-nudge on|off|enable|disable|status », « nudge every 20 minutes », « nudge once at 2:01 AM », « turn the nudge off here », « 别给这个 session 发 nudge », « 每半小时 nudge 一次 », « 给那个 codex 窗口开 nudge », « nudge my grok window too », ainsi que lors de la configuration du rappel ou de son test sur une nouvelle machine. Les sessions sont désactivées par défaut.
