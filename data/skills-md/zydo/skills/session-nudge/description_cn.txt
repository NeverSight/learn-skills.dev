为当前的编码代理会话（Claude Code、Codex CLI 或 Grok Build）打开或关闭周期性或一次性的保活 nudge，设置其频率，或显示其是否已开启。该 nudge 是一条 “[HH:MM:SS] Automated nudge: continue working …” 消息，由后台操作系统任务（launchd / systemd timer / cron / Windows 任务计划程序）默认每 61 分钟向已同意的代理终端输入。可用于 “/session-nudge on|off|enable|disable|status”、 “nudge every 20 minutes”、 “nudge once at 2:01 AM”、 “turn the nudge off here”、 “别给这个 session 发 nudge”、 “每半小时 nudge 一次”、 “给那个 codex 窗口开 nudge”、 “nudge my grok window too”，以及在新机器上设置或测试 nudge 时使用。会话默认关闭。
