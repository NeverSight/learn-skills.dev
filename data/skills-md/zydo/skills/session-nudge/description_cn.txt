为当前的编码代理会话（Claude Code、Codex CLI 或 Grok Build）打开或关闭周期性或一次性的保持活跃提示，设置其频率，或显示其状态。提示是一条“[HH:MM:SS] 自动提示：继续工作 …”的消息，由后台操作系统任务（launchd / systemd timer / cron / Windows 任务计划程序）默认每 61 分钟向已同意的代理终端输出。可用于“/session-nudge on|off|enable|disable|status”、“每 20 分钟提示一次”、“在凌晨 2:01 提示一次”“在此关闭提示”“别给这个 session 发 nudge”“每半小时 nudge 一次”“给那个 codex 窗口开 nudge”“nudge my grok window too”，以及在新机器上设置或测试提示时使用。会话默认关闭提示。请始终使用用户的语言回复。
