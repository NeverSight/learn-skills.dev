Schalten Sie einen periodischen oder einmaligen Keepalive‑Nudge für die aktuelle Coding‑Agent‑Session (Claude Code, Codex CLI oder Grok Build) ein oder aus, stellen Sie dessen Tempo ein oder zeigen Sie an, ob er aktiv ist. Der Nudge ist eine „[HH:MM:SS] Automated nudge: continue working …“‑Nachricht, die ein Hintergrund‑OS‑Job (launchd / systemd‑Timer / cron / Windows Task Scheduler) in aktivierte Agent‑Terminals schreibt, standardmäßig alle 61 Minuten. Verwenden Sie für „/session-nudge on|off|enable|disable|status“, „nudge every 20 minutes“, „nudge once at 2:01 AM“, „turn the nudge off here“, „别给这个 session 发 nudge“, „每半小时 nudge 一次“, „给那个 codex 窗口开 nudge“, „nudge my grok window too“ und beim Einrichten oder Testen des Nudges auf einem neuen Rechner. Sessions sind standardmäßig ausgeschaltet.
