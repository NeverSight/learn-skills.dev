將當前編程代理（Claude Code、Codex CLI 或 Grok Build）會話的周期性或一次性保活提示（nudge）開啟或關閉，設定其頻率，或顯示其狀態。此 nudge 是一條「[HH:MM:SS] Automated nudge: continue working …」訊息，由背景作業系統（launchd / systemd 計時器 / cron / Windows 工作排程）輸入到已同意的代理終端，每 61 分鐘觸發一次（預設值）。可用於「/session-nudge on|off|enable|disable|status」、
「nudge every 20 minutes」、
「nudge once at 2:01 AM」、
「turn the nudge off here」、
「别给这个 session 发 nudge」、
「每半小时 nudge 一次」、
「给那个 codex 窗口开 nudge」、
「nudge my grok window too」以及在新機器上設定或測試 nudge 時使用。會話預設為關閉。
