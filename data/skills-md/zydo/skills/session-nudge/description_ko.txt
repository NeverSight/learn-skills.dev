현재 코딩 에이전트 세션(Claude Code, Codex CLI 또는 Grok Build)에 대해 주기적이거나 일회성 keepalive nudge를 켜거나 끌 수 있으며, 속도를 설정하거나 켜져 있는지 확인할 수 있습니다. nudge는 “[HH:MM:SS] Automated nudge: continue working …” 형식의 메시지로, 백그라운드 OS 작업(launchd / systemd 타이머 / cron / Windows 작업 스케줄러)이 기본적으로 61분마다 동의한 에이전트 터미널에 입력합니다. “/session-nudge on|off|enable|disable|status”, “nudge every 20 minutes”, “nudge once at 2:01 AM”, “turn the nudge off here”, “别给这个 session 发 nudge”, “每半小时 nudge 一次”, “给那个 codex 窗口开 nudge”, “nudge my grok window too”와 같은 경우에 사용하고, 새 머신에서 nudge를 설정하거나 테스트할 때도 사용합니다. 세션은 기본적으로 꺼져 있습니다.
