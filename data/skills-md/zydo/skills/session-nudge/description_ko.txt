현재 코딩 에이전트 세션(Claude Code, Codex CLI 또는 Grok Build)에서 주기적이거나 일회성 keepalive nudge를 켜거나 끄고, 속도를 설정하거나 켜져 있는지 확인합니다. nudge는 백그라운드 OS 작업(launchd / systemd 타이머 / cron / Windows 작업 스케줄러)이 선택한 에이전트 터미널에 기본값으로 61분마다 입력하는 “[HH:MM:SS] Automated nudge: continue working …” 메시지입니다. “/session-nudge on|off|enable|disable|status”, “nudge every 20 minutes”, “nudge once at 2:01 AM”, “turn the nudge off here”, “别给这个 session 发 nudge”, “每半小时 nudge 一次”, “给那个 codex 窗口开 nudge”, “nudge my grok window too”와 같이 사용하고, nudge를 새 머신에 설정하거나 테스트할 때 활용합니다. 세션은 기본적으로 꺼져 있습니다.
