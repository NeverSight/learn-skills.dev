Turn a periodic or one-time keepalive nudge on or off for the current coding-agent session (Claude Code, Codex CLI or Grok Build), set its pace, or show whether it is on. The nudge is a "[HH:MM:SS] Automated nudge: continue working ..." message that a background OS job (launchd / systemd timer / cron / Windows Task Scheduler) types into opted-in agent terminals, every 61 minutes by default. Use for "/session-nudge on|off|enable|disable|status", "nudge every 20 minutes", "nudge once at 2:01 AM", "turn the nudge off here", "别给这个 session 发 nudge", "每半小时 nudge 一次", "给那个 codex 窗口开 nudge", "nudge my grok window too", and when setting the nudge up or testing it on a new machine. Sessions are off by default.
