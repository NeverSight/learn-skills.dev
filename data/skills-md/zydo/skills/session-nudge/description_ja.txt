現在のコーディングエージェント セッション（Claude Code、Codex CLI、または Grok Build）に対して、定期的または一回限りのキープアライブ nudge をオンまたはオフにしたり、間隔を設定したり、オンかどうかを表示したりします。nudge とは、"[HH:MM:SS] Automated nudge: continue working ..." というメッセージで、バックグラウンドの OS ジョブ（launchd / systemd タイマー / cron / Windows Task Scheduler）がオプトインされたエージェント端末にデフォルトで 61 分ごとに入力します。以下のような場合に使用します："/session-nudge on|off|enable|disable|status"、"nudge every 20 minutes"、"nudge once at 2:01 AM"、"turn the nudge off here"、"别给这个 session 发 nudge"、"每半小时 nudge 一次"、"给那个 codex 窗口开 nudge"、"nudge my grok window too"、そして nudge を設定したり新しいマシンでテストしたりする時。セッションはデフォルトでオフです。
