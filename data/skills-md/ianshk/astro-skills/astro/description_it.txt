Abilità per la creazione di siti statici con il framework web Astro. Aiuta a creare componenti e pagine Astro, configurare collezioni di contenuti, ottimizzare le immagini, impostare la SEO e distribuire build statiche. Da utilizzare quando l'utente deve lavorare con Astro, menziona file .astro, chiede della generazione di siti statici (SSG), dell'architettura islands, delle collezioni di contenuti o del deployment di un progetto Astro.
