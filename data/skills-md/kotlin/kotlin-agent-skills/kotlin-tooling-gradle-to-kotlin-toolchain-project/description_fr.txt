Charge lors de la migration ou de la conversion d’un projet Gradle Kotlin complet (build.gradle(.kts), wrapper, libs.versions.toml, buildSrc) vers le Kotlin Toolchain, y compris la réécriture du CI et le remplacement des plugins Gradle qui n’ont pas d’équivalent natif dans le Toolchain. Ignorer pour le portage d’un seul plugin Gradle ou les travaux généraux sur le Toolchain une fois Gradle supprimé.
