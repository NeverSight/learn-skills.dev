قم بالتحميل عند تأليف أو كتابة أو تصميم مكون إضافي محلي لـ Kotlin Toolchain لتوسيع البناء التعريفي من خلال إنشاء التعليمات البرمجية أو معالجة وقت البناء أو التحقق المخصص أو التعبئة التي لا يمكن لـ Module.yaml التعبير عنها، أو عند الرجوع إلى @TaskAction أو @Configurable أو plugin.yaml أو jvm/amper-plugin. تخطي لترقية مكون Gradle الإضافي الحالي.
