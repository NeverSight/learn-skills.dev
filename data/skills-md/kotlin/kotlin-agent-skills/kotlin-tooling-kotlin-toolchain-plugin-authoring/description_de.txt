Wird geladen, wenn ein lokales Kotlin Toolchain-Plugin erstellt, geschrieben oder entworfen wird, um den deklarativen Build um Codegenerierung, Verarbeitung zur Buildzeit, benutzerdefinierte Überprüfung oder Verpackung zu erweitern, die module.yaml nicht ausdrücken kann, oder wenn auf @TaskAction, @Configurable,plugin.yaml oder jvm/amper-plugin verwiesen wird. Überspringen, um ein vorhandenes Gradle-Plugin zu portieren.
