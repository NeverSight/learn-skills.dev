Caricare quando si effettua il porting, la conversione o la ri‑implementazione di un singolo plugin Gradle come plugin locale Kotlin Toolchain, o quando si mappano i concetti del plugin Gradle (Task, Extension, project.version, dependsOn, proprietà -P, afterEvaluate) agli analoghi di Toolchain. Ignora per la migrazione di un intero progetto Gradle o per la creazione di un plugin da zero.
