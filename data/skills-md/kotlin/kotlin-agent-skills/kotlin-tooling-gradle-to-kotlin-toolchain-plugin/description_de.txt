Lade, wenn ein einzelnes Gradle‑Plugin als lokales Kotlin‑Toolchain‑Plugin portiert, konvertiert oder neu implementiert wird, oder wenn Gradle‑Plugin‑Konzepte (Task, Extension, project.version, dependsOn, -P‑Eigenschaften, afterEvaluate) auf Toolchain‑Entsprechungen abgebildet werden. Überspringen bei der Migration eines gesamten Gradle‑Projekts oder beim Schreiben eines Plugins von Grund auf.
