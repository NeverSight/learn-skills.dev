Загружать при сборке, запуске, тестировании, упаковке, линтинге или настройке проекта Kotlin/Java с использованием Kotlin Toolchain (унифицированного CLI от JetBrains, ранее Amper), при создании нового или «зеленого поля» проекта Kotlin, либо когда в репозитории присутствуют файлы project.yaml, module.yaml или обертка ./kotlin. Пропускать для существующих проектов Gradle/Maven.
