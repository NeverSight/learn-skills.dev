Применяет пользовательские настройки Git: ветвление от удалённого по умолчанию, использовать merge вместо rebase для обычных веток, при выборе применять нативные стеки GitHub, никогда не делать amend и выполнять squash‑merge запросов на слияние. Использовать при ветвлении, синхронизации, коммите, пуше или слиянии в репозиториях пользователя.
