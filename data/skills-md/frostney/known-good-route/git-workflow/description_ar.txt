يطبق الإعدادات الافتراضية لـ git للمستخدم: إنشاء الفروع من الإعداد الافتراضي للمستودع البعيد، دمج بدلاً من إعادة التأسيس للفروع العاديّة، استخدام مكدسات GitHub الأصلية عند الاختيار، عدم تعديل أي شيء أبداً، ودمج طلبات السحب بطريقة squash‑merge. يُستَخدم ذلك عند إنشاء الفروع أو المزامنة أو الالتزام أو الدفع أو الدمج في مستودعات المستخدم.
