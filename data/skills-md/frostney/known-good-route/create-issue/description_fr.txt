Étudie et crée un problème GitHub aligné sur le projet à partir d'un slogan ou d'une courte description, en utilisant le modèle, les preuves et les étiquettes du référentiel ; affiche d'abord un brouillon uniquement lorsqu'on le lui demande. À utiliser lorsqu'on vous demande de classer, d'ouvrir ou de créer un problème GitHub, ou lorsque l'utilisateur exécute /crée un problème.
