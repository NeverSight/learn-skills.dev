Ramène le code existant en conformité avec le jeu de règles des principes : audite le périmètre nommé, regroupe les constats dans un plan de tranches ordonné, attend l’approbation, puis applique les tranches approuvées une à une avec le seuil d’acceptation du projet en vert et un commit par tranche.

N’utilisez cela que lorsque l’utilisateur demande explicitement de réaligner, refactoriser ou corriger une base de code par rapport aux règles — « réaligner ce package aux principes », « corriger les violations de règles dans apps/api ». Pas pour un travail de code ordinaire, une modification unique ou une évaluation en lecture seule : ces cas utilisent la compétence tenets ou tenets‑audit.

Veuillez toujours répondre dans la langue de l’utilisateur.
