Produce un rapporto di conformità classificato per gravità per un intero repository, un pacchetto o un sottoalbero denominato, misurato rispetto al set di regole di ingegneria Tenets e alla guida del progetto, con ogni risultato associato a un ancoraggio di regola e a una posizione del file.

Usalo solo quando l'utente chiede esplicitamente di auditare o valutare un codebase rispetto alle regole — “audit this repo”, “check compliance”, “how aligned is this package”. Non per lavori di codice ordinari, modifiche a file singoli, revisione di un diff o risposta a una domanda sulle regole: questi caricano la skill Tenets.

Per favore rispondi sempre nella lingua dell'utente.
