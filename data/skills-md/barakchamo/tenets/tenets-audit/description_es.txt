Genera un informe de cumplimiento clasificado por severidad para todo un repositorio, un paquete o un subárbol nombrado, medido contra el conjunto de reglas de ingeniería Tenets y la guía del proyecto, con cada hallazgo citado a un ancla de regla y una ubicación de archivo.

Úsese solo cuando el usuario solicite explícitamente auditar o evaluar una base de código contra las reglas — "audit this repo", "check compliance", "how aligned is this package". No es para trabajo de código ordinario, ediciones de un solo archivo, revisión de un diff o responder a una pregunta de reglas: esas cargan la habilidad Tenets.

Por favor, siempre responda en el idioma del usuario.
