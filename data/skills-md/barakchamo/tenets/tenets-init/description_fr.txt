Définit un référentiel pour l'ensemble de règles des principes : écrit le guide de projet pré-rempli à partir du
référentiel, l'enregistre dans tenets.json, épingle le mandat de routage dans AGENTS.md, et offre le
cales de commande par harnais.

À utiliser uniquement lorsque l'utilisateur demande explicitement de configurer ou de réinitialiser l'ensemble de règles des principes dans un
référentiel, ou exécute /tenets-init. Pas pour le travail de code ordinaire ou l'édition d'un guide existant à la main.
