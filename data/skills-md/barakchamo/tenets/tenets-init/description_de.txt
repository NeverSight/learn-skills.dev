Richtet ein Repository für das Regelwerk ein: schreibt den Projektleitfaden vorausgefüllt aus dem
repository, zeichnet es in tenets.json auf, pinnt das Routing-Mandat in AGENTS.md und bietet die
befehlsscheiben pro Gurtzeug.

Nur verwenden, wenn der Benutzer explizit darum bittet, den Regelsatz für Grundsätze in einem
repository oder runs /tenets-init. Nicht für gewöhnliche Codearbeiten oder das Bearbeiten einer vorhandenen Anleitung von Hand.
