Configura un repository per il set di regole Tenets: scrive la guida del progetto pre‑compilata dal repository, la registra in tenets.json, fissa il mandato di routing in AGENTS.md e offre gli shim dei comandi per ogni harness.

Usare solo quando l'utente richiede esplicitamente di impostare o reinizializzare il set di regole Tenets in un repository, o esegue /tenets-init. Non è destinato al lavoro di codice ordinario o alla modifica manuale di una guida esistente.

Rispondi sempre nella lingua dell'utente.
