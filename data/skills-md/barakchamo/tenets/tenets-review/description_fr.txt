Produit un examen classé par gravité d’une pull request, d’une branche ou de l’arbre de travail non commité par rapport au jeu de règles d’ingénierie des principes, ainsi qu’un audit d’intention comparant ce que le plan actif indiquait à ce que le diff réalise réellement.

À n’utiliser que lorsque l’utilisateur demande explicitement de réviser les changements par rapport aux règles — « revoir cette PR », « revoir mon diff par rapport aux principes », « ai‑je construit ce que le plan disait ». Pas pour le travail de code ordinaire, l’écriture de code ou l’audit d’une base de code complète : ces cas chargent la compétence tenets ou tenets‑audit.

Veuillez toujours répondre dans la langue de l’utilisateur.
