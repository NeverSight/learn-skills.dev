Conjunto genérico de reglas de ingeniería para monorepos, vinculado a cada ecosistema por un perfil de lenguaje (TypeScript incluido): manejo tipado de errores con Result, invariantes y la esclusa, esquemas de frontera, módulos profundos y flujo de control limitado, TDD conductual con ejemplos primero, contratos de documentación, límites de espacio de trabajo, marco de decisiones, entrega de cambios, modelado de datos/estado y disciplina de tiempo de ejecución serverless.

Usar al escribir, revisar, refactorizar, renombrar o probar cualquier código fuente — TypeScript incluido; manejar errores o escribir bloques catch; crear archivos fuente o exportaciones; diseñar funciones o APIs públicas; añadir dependencias o espacios de trabajo; elegir arquitectura, almacenamiento o herramientas; hacer commit o desplegar; modelar, cachear o migrar datos; escribir manejadores de peticiones, colas y trabajos; capturar aprendizajes o descubrimientos no evidentes; o decidir dónde debe residir el código, los datos o el conocimiento.
