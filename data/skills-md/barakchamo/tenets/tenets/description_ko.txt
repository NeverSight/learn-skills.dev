각 언어 프로필(TypeScript 포함)로 각 생태계에 바인딩된 모노레포용 일반 엔지니어링 규칙 집합: 불변성 및 에어록이 있는 타입된 Result 오류 처리, 경계 스키마, 깊은 모듈과 제한된 제어 흐름, 예제 우선 행동 기반 TDD, 문서 계약, 워크스페이스 경계, 의사결정 프레임워크, 변경 전달, 데이터·상태 모델링, 그리고 서버리스 런타임 규율.

소스 코드를 작성, 검토, 리팩터링, 이름 변경 또는 테스트할 때 사용하세요 — TypeScript 포함; 오류를 처리하거나 catch 블록을 작성할 때; 소스 파일이나 내보내기를 만들 때; 함수나 공개 API를 설계할 때; 의존성이나 워크스페이스를 추가할 때; 아키텍처, 스토리지, 도구를 선택할 때; 커밋하거나 배포할 때; 데이터 모델링, 캐싱, 마이그레이션을 할 때; 요청 핸들러, 큐, 작업을 작성할 때; 학습 내용이나 명확하지 않은 발견을 기록할 때; 혹은 코드, 데이터, 지식이 어디에 위치해야 할지 결정할 때.
