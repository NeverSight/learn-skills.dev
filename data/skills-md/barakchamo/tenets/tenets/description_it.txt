Regole ingegneristiche generiche per monorepo, vincolate a ciascun ecosistema da un profilo linguistico (TypeScript incluso): gestione degli errori typed Result con invarianti e “airlock”, schemi di confine, moduli profondi e flusso di controllo limitato, TDD comportamentale basato su esempi, contratti di documentazione, confini dello spazio di lavoro, quadro decisionale, consegna delle modifiche, modellazione di dati/stato e disciplina di runtime serverless.  

Usa queste regole quando scrivi, rivedi, refattorizzi, rinomini o testi qualsiasi codice sorgente — TypeScript compreso; gestisci errori o scrivi blocchi catch; crei file sorgente o esportazioni; definisci funzioni o API pubbliche; aggiungi dipendenze o workspace; scegli architettura, storage o strumenti; effettui commit o shipping; modelli, cache o migri dati; scrivi handler di richieste, code e job; catturi apprendimenti o scoperte non ovvie; o decidi dove codice, dati o conoscenza debbano risiedere.
