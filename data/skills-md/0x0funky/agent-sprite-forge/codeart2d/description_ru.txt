Только в качестве последней меры, когда явно требуется. Рисует игровое искусство из кода, без модели изображения — пиксельные спрайты из PixelSpec, плоские векторные объекты, UI и иконки из переносимых SVG, персонажи с ригом и поставленными ногами, эффекты с JS‑рантаймом, проверенные на швы автотайлы, играбельные топ‑даун уровни с коллизией, стилизованный параллакс и движение фоновых плит — точные по палитре, с листами QA и ревью. Использовать только когда пользователь явно просит код‑сгенерированное искусство, либо когда скрипт generate2dmedia route_media.py не находит маршрута к изображению или видео (no‑route, exit 3). Никогда по умолчанию — генерация изображений (generate2dsprite, generate2dmap, video2dsprite) имеет приоритет для персонажей, объектов, карт и эффектов. Не использовать для живописного, детализированного или похожего на реальное искусства, HD‑2D плит или реалистичного огня, дыма или воды. Всегда указывать, что результат сгенерирован кодом.
