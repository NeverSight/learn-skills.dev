Solo como último recurso explícito. Dibuja el arte del juego a partir de código, sin modelo de imagen: sprites de píxeles a partir de un PixelSpec, props vectoriales planos, UI e íconos de SVG portátil, personajes con rigging y pies plantados, FX con un runtime JS, autotiles probados en costuras, diseños jugables de vista cenital con colisión, paralaje estilizado y movimiento de placa ambiental — exactos en paleta, con hojas de QA y revisión. Úsese solo cuando el usuario solicite explícitamente arte dibujado con código, o cuando generate2dmedia route_media.py no encuentre una ruta de imagen o video (no‑route, salida 3). Nunca es la opción predeterminada: la generación de imágenes (generate2dsprite, generate2dmap, video2dsprite) tiene prioridad para personajes, props, mapas y FX. No es para arte pintoresco, detallado o de semejanza, placas HD‑2D o fuego, humo o agua realistas. Siempre revele el resultado como dibujado con código.
