إدارة بنية تحتية سحابة Spice.ai كرمز باستخدام Terraform أو OpenTofu باستخدام مزود spiceai/spiceai. استخدم هذه المهارة كلما أراد المستخدم كتابة تكوينات Terraform/OpenTofu لمشاريع Spice (موفر `spiceai_app`)، النشرات، الأسرار، أو أعضاء المؤسسة، استيراد موارد Spice.ai الموجودة إلى حالة Terraform، إعداد مصادقة OAuth للمزود، أو استخدام مصادر بيانات Terraform للمناطق وصور الحاويات. استخدمها أيضًا عندما يذكر المستخدم "terraform" و "spice" معًا، أو يرغب في بنية ككود (IaC) لبنيتهم التحتية في سحابة Spice.ai. للإدارة المباشرة عبر API دون Terraform، راجع السحابة.
