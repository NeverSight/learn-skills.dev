Administre la infraestructura de Spice.ai Cloud como código con Terraform o OpenTofu usando el proveedor spiceai/spiceai. Use esta habilidad siempre que el usuario quiera escribir configuraciones de Terraform/OpenTofu para proyectos Spice (el `spiceai_app` del proveedor), implementaciones, secretos o miembros de la organización, importar recursos existentes de Spice.ai al estado de Terraform, configurar la autenticación OAuth para el proveedor, o utilizar fuentes de datos de Terraform para regiones e imágenes de contenedor. También úsela cuando el usuario mencione “terraform” y “spice” juntos, o desee IaC para su infraestructura de Spice.ai Cloud. Para la gestión directa de la API sin Terraform, consulte cloud.

Por favor, responda siempre en el idioma del usuario.
