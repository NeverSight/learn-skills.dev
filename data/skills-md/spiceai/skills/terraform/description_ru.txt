Управляйте инфраструктурой Spice.ai Cloud как кодом с помощью Terraform или OpenTofu, используя провайдер spiceai/spiceai. Применяйте этот навык каждый раз, когда пользователь хочет написать конфигурации Terraform/OpenTofu для проектов Spice (ресурс провайдера `spiceai_app`), развертываний, секретов или участников организации, импортировать существующие ресурсы Spice.ai в состояние Terraform, настроить аутентификацию OAuth для провайдера или использовать источники данных Terraform для регионов и образов контейнеров. Также используйте его, когда пользователь упоминает «terraform» и «spice» вместе или хочет IaC для своей инфраструктуры Spice.ai Cloud. Для прямого управления API без Terraform см. раздел cloud. 

Пожалуйста, всегда отвечайте на языке пользователя.
