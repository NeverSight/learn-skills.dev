Gestisci l'infrastruttura Cloud di Spice.ai come codice con Terraform o OpenTofu usando il provider spiceai/spiceai. Usa questa capacità ogni volta che l'utente vuole scrivere configurazioni Terraform/OpenTofu per progetti Spice (l'`spiceai_app` del provider), distribuzioni, segreti o membri dell'organizzazione, importare risorse esistenti di Spice.ai nello stato di Terraform, configurare l'autenticazione OAuth per il provider, o utilizzare le sorgenti dati Terraform per regioni e immagini di container. Utilizzala anche quando l'utente menziona "terraform" e "spice" insieme, o desidera IaC per la loro infrastruttura Cloud di Spice.ai. Per la gestione diretta via API senza Terraform, consulta cloud. Rispondi sempre nella lingua dell'utente.
