Подключите Spice к источникам данных и выполняйте запросы к ним с помощью федеративного SQL — включая наборы данных, каталоги, представления и записи. Используйте этот навык, когда пользователь хочет настроить федеративные запросы между несколькими источниками, создать представления, настроить каталоги (Unity Catalog, Databricks, Iceberg), записать данные с помощью INSERT INTO или понять, как работает федерация запросов в Spice. Этот навык сосредоточен на уровне федерации — кросс‑источниковые соединения, представления, каталоги и запись данных. Для настройки отдельных коннекторов источников данных (параметры PostgreSQL, форматы файлов S3 и т.д.) см. раздел «коннекторы».
