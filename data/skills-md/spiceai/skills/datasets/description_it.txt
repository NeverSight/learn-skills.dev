Collega Spice alle fonti dati e interroga tra di esse con SQL federato — includendo dataset, cataloghi, visualizzazioni e scritture. Usa questa competenza ogni volta che l'utente desidera impostare query federate su più fonti, creare visualizzazioni, configurare cataloghi (Unity Catalog, Databricks, Iceberg), scrivere dati con INSERT INTO o comprendere come funziona la federazione delle query di Spice. Questa competenza si concentra sul livello di federazione — join tra fonti, visualizzazioni, cataloghi e scritture di dati. Per configurare i connettori delle singole fonti dati (parametri PostgreSQL, formati di file S3, ecc.), vedi connettori.  

Rispondi sempre nella lingua dell'utente.
