Conecta Spice a fuentes de datos y consulta a través de ellas con SQL federado — incluidos conjuntos de datos, catálogos, vistas y escrituras. Usa esta habilidad siempre que el usuario quiera configurar consultas federadas entre múltiples fuentes, crear vistas, configurar catálogos (Unity Catalog, Databricks, Iceberg), escribir datos con INSERT INTO o entender cómo funciona la federación de consultas de Spice. Esta habilidad se centra en la capa de federación — uniones entre fuentes, vistas, catálogos y escrituras de datos. Para configurar conectores de fuentes de datos individuales (parámetros de PostgreSQL, formatos de archivo S3, etc.), consulta los conectores.
