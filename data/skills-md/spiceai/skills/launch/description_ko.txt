Spice.ai 프로젝트를 Spice.ai Cloud에서 처음부터 끝까지 일반 언어 시나리오로 시작합니다. 사용자를 장치 코드로 Spice.ai Cloud에 로그인시키고(가입 포함), 사용자의 소스와 모델에 대한 spicepod을 설계하고, 이를 배포합니다(도우미를 사용하거나 GitHub 저장소에서 Spice Cloud 관리 MCP 서버를 통해). 배포가 행(row)을 제공하고, 모델 응답 및 MCP 도구 호출을 수행함을 증명합니다. 이후 모니터와 알림을 추가하고, 알림 훈련을 실행한 뒤, 운용 절차서와 에이전트 연결 스니펫을 전달합니다. 데모, PoC, 그린필드 프로덕션 프로젝트에 활용하십시오—예: “Snowflake, Postgres, S3 데이터를 OpenAI와 연결된 에이전트에 제공”, “MySQL과 Postgres를 하나의 SQL 엔드포인트로 연합”, “내일을 위한 Spice 데모를 Cloud에 띄우기”, “알림 기능과 함께 이 spicepod을 Spice Cloud에 배포”, “우리 Spice PoC를 프로덕션 준비 상태로 만들기”, “Spice Cloud에 가입하기” 등—그리고 새로운 Spice 배포가 반드시 동작하고 운영 가능하도록, 단순히 설정만 되는 것이 아니라 반드시 작동하도록 합니다. 번들 스크립트/spice-launch.sh를 포함합니다. 로컬 전용 최초 실행은 setup을 사용하고, 일회성 Cloud API 호출은 cloud를 사용하십시오.
