プレーンな言語シナリオから、Spice.ai Cloud 上で Spice.ai プロジェクトをエンドツーエンドで起動します。デバイスコード（サインアップ含む）でユーザーを Spice.ai Cloud にサインインさせ、ユーザーのデータソースとモデル用に Spicepod を設計し、（ヘルパーを使うか、GitHub リポジトリから Spice Cloud 管理 MCP サーバー経由で）デプロイします。そして、デプロイが行データ、モデルの回答、MCP ツール呼び出しを提供できることを実証します。その後、モニターとアラートを追加し、アラート・ドリルを実行し、ランブックとエージェント接続スニペットを引き渡します。デモ、POC、グリーンフィールドの本番プロジェクトに活用してください — 「Snowflake、Postgres、S3 のデータを OpenAI と連携させてエージェントに提供する」「MySQL と Postgres を 1 つの SQL エンドポイントに統合する」「明日のために Cloud 上で Spice デモを立ち上げる」「この Spicepod をアラート付きで Spice Cloud にデプロイする」「Spice の POC を本番対応にする」「Spice Cloud にサインアップして」など、また新しい Spice デプロイが単なる設定で終わらず実際に機能し運用可能である必要があるすべてのケースで使用できます。scripts/spice-launch.sh をバンドルしています。ローカルのみの初回実行は setup を、クラウド API の単発呼び出しは cloud を使用してください。
