Lanza un proyecto de Spice.ai en Spice.ai Cloud de extremo a extremo a partir de un escenario en lenguaje natural. Inicia sesión del usuario en Spice.ai Cloud con un código de dispositivo (registro incluido), diseña el spicepod para las fuentes y modelos del usuario, lo despliega (con su asistente, o a través del servidor MCP de gestión de Spice Cloud desde un repositorio de GitHub) y demuestra que el despliegue sirve filas, respuestas de modelo y llamadas a herramientas MCP. Luego agrega monitores y alertas, realiza un simulacro de alerta y entrega un runbook y fragmentos de conexión de agente. Úsalo para demostraciones, pruebas de concepto y proyectos de producción greenfield — “servir nuestros datos de Snowflake, Postgres y S3 a agentes con OpenAI”, “federar nuestro MySQL y Postgres en un único endpoint SQL”, “levantar una demo de Spice en Cloud para mañana”, “desplegar este spicepod en Spice Cloud con alertas”, “hacer que nuestra prueba de concepto de Spice esté lista para producción”, “regístrame en Spice Cloud” — y siempre que un nuevo despliegue de Spice deba funcionar y ser operable, no solo configurado. Incluye los scripts/spice-launch.sh. Para una primera ejecución solo local usa setup; para llamadas API puntuales al Cloud usa cloud.
