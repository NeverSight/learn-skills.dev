在 Spice.ai Cloud 上從純文字情境端到端啟動 Spice.ai 專案。它使用裝置代碼（包含註冊）將使用者登入 Spice.ai Cloud，為使用者的資料來源與模型設計 spicepod，部署它（使用其輔助工具，或透過 Spice Cloud 管理 MCP 伺服器從 GitHub 倉庫部署），並證明部署能提供資料列、模型回應與 MCP 工具呼叫。接著加入監控與警示，執行警示演練，並交付操作手冊與代理連線程式碼片段。可用於示範、概念驗證（POC）以及全新產品化專案——「將我們的 Snowflake、Postgres 與 S3 資料提供給 OpenAI 代理」、「在單一 SQL 端點聯合 MySQL 與 Postgres」、「為明天在 Cloud 上啟動 Spice 示範」、「將此 spicepod 部署到 Spice Cloud 並啟用警示」、「讓我們的 Spice POC 具備生產環境就緒性」、「幫我註冊 Spice Cloud」——以及每當新的 Spice 部署必須正常運作且可管理時，而不僅是設定完成。包含腳本 bundles/scripts/spice-launch.sh。首次本機執行請使用 setup；一次性 Cloud API 呼叫請使用 cloud。
