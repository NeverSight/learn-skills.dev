Avvia un progetto Spice.ai su Spice.ai Cloud end‑to‑end a partire da uno scenario in linguaggio naturale. Accede l'utente a Spice.ai Cloud con un codice dispositivo (registrazione inclusa), progetta lo spicepod per le fonti e i modelli dell'utente, lo distribuisce (con il suo helper o tramite il server di gestione MCP di Spice Cloud da un repository GitHub) e dimostra che l'implementazione fornisce righe, risposte dei modelli e chiamate agli strumenti MCP. Poi aggiunge monitor e avvisi, esegue un drill di allerta e consegna un runbook e snippet di connessione per l'agente. Usalo per dimostrazioni, POC e progetti di produzione greenfield — “servire i nostri dati Snowflake, Postgres e S3 agli agenti con OpenAI”, “federare i nostri MySQL e Postgres in un unico endpoint SQL”, “avviare una demo Spice su Cloud per domani”, “distribuire questo spicepod su Spice Cloud con avvisi”, “rendere il nostro POC Spice pronto per la produzione”, “iscrivimi a Spice Cloud” — e ogni volta che un nuovo deployment Spice deve funzionare e essere operabile, non solo configurato. Include gli script scripts/spice-launch.sh. Per una prima esecuzione solo locale usa setup; per chiamate API Cloud occasionali usa cloud.
