Lancez un projet Spice.ai sur Spice.ai Cloud de bout en bout à partir d’un scénario en langage naturel. Il connecte l’utilisateur à Spice.ai Cloud avec un code appareil (inscription incluse), conçoit le spicepod pour les sources et modèles de l’utilisateur, le déploie (avec son assistant, ou via le serveur de gestion MCP de Spice Cloud depuis un dépôt GitHub), et prouve que le déploiement fournit des lignes, des réponses de modèle et des appels d’outils MCP. Il ajoute ensuite des moniteurs et des alertes, effectue un exercice de déclenchement d’alerte, et transmet un runbook ainsi que des extraits de connexion d’agent. Utilisez‑le pour des démos, des POC et des projets de production greenfield — « servir nos données Snowflake, Postgres et S3 aux agents avec OpenAI », « fédérer nos MySQL et Postgres en un seul point d’accès SQL », « déployer une démo Spice sur le cloud pour demain », « déployer ce spicepod sur Spice Cloud avec alertes », « rendre notre POC Spice prêt pour la production », « inscrivez‑moi à Spice Cloud » — et chaque fois qu’un nouveau déploiement Spice doit fonctionner et être opérable, pas seulement configuré. Regroupe scripts/spice-launch.sh. Pour un premier lancement uniquement local utilisez setup ; pour des appels API Cloud ponctuels utilisez cloud.
