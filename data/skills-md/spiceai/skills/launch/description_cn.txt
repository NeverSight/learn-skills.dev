从纯语言场景端到端启动 Spice.ai 项目于 Spice.ai Cloud。它使用设备码（包括注册）让用户登录 Spice.ai Cloud，为用户的来源和模型设计 spicepod，部署它（使用其助手，或通过 GitHub 仓库的 Spice Cloud 管理 MCP 服务器），并验证部署能够提供行数据、模型答案和 MCP 工具调用。随后添加监控和警报，进行警报演练，并交付运行手册和代理连接代码片段。可用于演示、概念验证和全新生产项目——“使用 OpenAI 为我们的 Snowflake、Postgres 和 S3 数据提供给代理”，“在一个 SQL 端点统一我们的 MySQL 和 Postgres”，“为明天在云上快速启动 Spice 演示”，“将此 spicepod 部署到 Spice Cloud 并启用警报”，“让我们的 Spice POC 达到生产就绪状态”，“帮我注册 Spice Cloud”——以及每当需要新的 Spice 部署不仅仅是配置，而是可正常工作和可运维时。捆绑 scripts/spice-launch.sh。首次仅本地运行使用 setup；一次性 Cloud API 调用使用 cloud。
