Запустите проект Spice.ai в Spice.ai Cloud от начала и до конца, исходя из простого сценария на естественном языке. Он выполняет вход пользователя в Spice.ai Cloud с помощью кода устройства (включая регистрацию), проектирует spicepod для источников и моделей пользователя, развертывает его (с помощью вспомогательного инструмента или через сервер управления MCP Spice Cloud из репозитория GitHub) и демонстрирует, что развертывание обслуживает строки, ответы моделей и вызовы инструментов MCP. Затем добавляются мониторы и оповещения, проводится учёное учение по тревоге и предоставляются фрагменты кода runbook и подключения агента. Используйте для демонстраций, проверочных концепций и «зелёных» производственных проектов — «обслуживаем наши данные в Snowflake, Postgres и S3 агентами OpenAI», «объединяем наш MySQL и Postgres в одну точку доступа SQL», «поднимаем демонстрацию Spice в Cloud к завтрашнему дню», «разворачиваем этот spicepod в Spice Cloud с оповещениями», «делаем наш Spice POC готовым к продакшену», «зарегистрировать меня в Spice Cloud» — и каждый раз, когда новое развертывание Spice должно работать и быть управляемым, а не просто сконфигурированным. В комплекте скрипты/spice-launch.sh. Для первого локального запуска используйте setup; для разовых вызовов Cloud API — cloud.
