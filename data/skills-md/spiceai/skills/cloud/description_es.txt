Administre los recursos de Spice.ai Cloud a través de Spice Cloud, la API de Gestión y el servidor MCP de gestión (https://api.spice.ai/mcp) — proyectos, bifurcaciones de proyectos, implementaciones, monitores, reacciones de datos, secretos, claves API y miembros de la organización. Úselo para el ciclo de vida de proyectos en la nube (incluyendo bifurcar, copiar o mover a otra región o clúster), implementaciones (incluyendo desde un repositorio de GitHub), registros de instancias, conectar un agente a Spice Cloud mediante MCP, crear o actualizar alertas, destinos de notificación, desactivar monitores, solución de problemas de alertas, contexto de organización, regiones y automatización de infraestructura. Utilice SQL, búsqueda, chat o SDK para datos en tiempo de ejecución y APIs de inferencia, y Terraform para infraestructura como código.
