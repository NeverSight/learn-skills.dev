Gérez les ressources de Spice.ai Cloud via Spice Cloud, l’API de gestion et le serveur MCP de gestion (https://api.spice.ai/mcp) — projets, fourches de projets, déploiements, moniteurs, réactions de données, secrets, clés API et membres de l’organisation. Utilisez-le pour le cycle de vie des projets Cloud (y compris la fourche, la copie ou le déplacement vers une autre région ou un autre cluster), les déploiements (y compris depuis un dépôt GitHub), les journaux d’instance, la connexion d’un agent à Spice Cloud via MCP, la création ou la mise à jour d’alertes, les destinations de notification, la désactivation des moniteurs, le dépannage des alertes, le contexte organisationnel, les régions et l’automatisation de l’infrastructure. Utilisez SQL, la recherche, le chat ou le SDK pour les données d’exécution et les API d’inférence, et Terraform pour l’infrastructure en tant que code.
