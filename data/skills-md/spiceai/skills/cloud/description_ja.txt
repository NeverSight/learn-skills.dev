Spice.ai Cloud のリソースは、spice cloud、Management API、そして管理 MCP サーバー (https://api.spice.ai/mcp) を通じて管理します — プロジェクト、プロジェクトフォーク、デプロイメント、モニター、データリアクション、シークレット、API キー、組織メンバー。クラウドプロジェクトのライフサイクル（フォーク、コピー、別リージョンやクラスターへの移動を含む）やデプロイメント（GitHub リポジトリからのものを含む）、インスタンスログ、MCP 経由でエージェントを Spice Cloud に接続、アラートの作成・更新、通知先、モニターの無効化、アラートのトラブルシューティング、組織コンテキスト、リージョン、インフラ自動化に使用します。ランタイムデータおよび推論 API には SQL、検索、チャット、または SDK を、インフラストラクチャをコードとして管理するには Terraform を使用してください。
