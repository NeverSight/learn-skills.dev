إدارة موارد Spice.ai Cloud عبر Spice Cloud، واجهة برمجة التطبيقات الإدارية، وخادم MCP الإداري (https://api.spice.ai/mcp) — المشاريع، فروع المشاريع، عمليات النشر، المراقبين، ردود الفعل على البيانات، الأسرار، مفاتيح API، وأعضاء المنظمة. استخدمها لدورة حياة مشروع السحابة (بما في ذلك الفَرْع، النسخ، أو النقل إلى منطقة أو عنقود آخر)، عمليات النشر (بما في ذلك من مستودع GitHub)، سجلات المثيل، ربط وكيل بـ Spice Cloud عبر MCP، إنشاء أو تحديث التنبيهات، وجهات الإشعار، تعطيل المراقبين، استكشاف مشاكل التنبيهات، سياق المنظمة، المناطق، وأتمتة البنية التحتية. استخدم SQL أو البحث أو الدردشة أو SDK لواجهات برمجة تطبيقات البيانات في وقت التشغيل والاستدلال، و Terraform للبنية التحتية ككود.
