Управляйте ресурсами Spice.ai Cloud через Spice Cloud, Management API и сервер управления MCP (https://api.spice.ai/mcp) — проекты, форки проектов, развертывания, мониторы, реактивные данные, секреты, API‑ключи и участников организации. Используйте для жизненного цикла облачных проектов (включая форк, копирование или перемещение в другой регион или кластер), развертываний (включая из репозитория GitHub), журналов экземпляров, подключения агента к Spice Cloud через MCP, создания или обновления оповещений, пунктов назначения уведомлений, отключения мониторов, устранения неполадок оповещений, контекста организации, регионов и автоматизации инфраструктуры. Используйте SQL, поиск, чат или SDK для данных во время выполнения и API вывода, а также Terraform для инфраструктуры как кода.
