Gestisci le risorse di Spice.ai Cloud tramite Spice Cloud, l'API di Management e il server MCP di gestione (https://api.spice.ai/mcp) — progetti, fork di progetti, deployment, monitor, reazioni sui dati, segreti, chiavi API e membri dell'organizzazione. Utilizzalo per il ciclo di vita dei progetti Cloud (inclusi fork, copia o spostamento in un'altra regione o cluster), i deployment (inclusi da un repository GitHub), i log delle istanze, la connessione di un agente a Spice Cloud tramite MCP, la creazione o l'aggiornamento di avvisi, le destinazioni di notifica, la disabilitazione dei monitor, la risoluzione dei problemi di avviso, il contesto dell'organizzazione, le regioni e l'automazione dell'infrastruttura. Usa SQL, ricerca, chat o SDK per i dati in tempo reale e le API di inferenza, e Terraform per l'infrastruttura come codice.
