Spice.ai Cloud 리소스는 spice cloud, Management API 및 관리 MCP 서버(https://api.spice.ai/mcp)를 통해 관리합니다 — 프로젝트, 프로젝트 포크, 배포, 모니터, 데이터 반응, 시크릿, API 키 및 조직 구성원. 클라우드 프로젝트 라이프사이클(포크, 복사 또는 다른 지역이나 클러스터로 이동 포함), 배포(GitHub 저장소에서 포함), 인스턴스 로그, MCP를 통한 에이전트 연결, 알림 생성 또는 업데이트, 알림 대상 지정, 모니터 비활성화, 알림 문제 해결, 조직 컨텍스트, 지역 및 인프라 자동화에 사용합니다. 런타임 데이터 및 추론 API를 위해 SQL, 검색, 채팅 또는 SDK를 사용하고, 인프라를 코드로 관리하기 위해 Terraform을 사용합니다.
