Crear y configurar manifiestos Spicepod (spicepod.yaml) — el archivo de configuración central para aplicaciones Spice. Usa esta habilidad siempre que el usuario quiera crear un nuevo spicepod.yaml desde cero, comprender la estructura general de spicepod y las secciones disponibles, configurar ajustes de tiempo de ejecución (puertos, caché, telemetría/observabilidad), montar una aplicación Spice completa que combine conjuntos de datos + modelos + búsqueda, o entender los modelos de despliegue y casos de uso. Esta es la habilidad de "pegamento" que muestra cómo todos los componentes de Spice encajan en un solo manifiesto. Para detalles sobre secciones específicas (conjuntos de datos, modelos, búsqueda, etc.), consulta las habilidades dedicadas.  

Por favor, responde siempre en el idioma del usuario.
