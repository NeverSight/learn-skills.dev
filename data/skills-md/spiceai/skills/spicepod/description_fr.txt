Créer et configurer les manifestes Spicepod (spicepod.yaml) — le fichier de configuration central pour les applications Spice. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer un nouveau spicepod.yaml à partir de zéro, comprendre la structure globale du spicepod et les sections disponibles, configurer les paramètres d'exécution (ports, mise en cache, télémétrie/observabilité), mettre en place une application Spice complète combinant ensembles de données + modèles + recherche, ou comprendre les modèles de déploiement et les cas d’utilisation. C’est la compétence «colle» qui montre comment tous les composants Spice s’assemblent dans un seul manifeste. Pour des détails sur les sections spécifiques (ensembles de données, modèles, recherche, etc.), consultez les compétences dédiées.

Veuillez toujours répondre dans la langue de l'utilisateur.
