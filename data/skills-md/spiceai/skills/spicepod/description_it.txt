Crea e configura i manifesti Spicepod (spicepod.yaml) — il file di configurazione centrale per le applicazioni Spice. Usa questa competenza ogni volta che l'utente vuole creare un nuovo spicepod.yaml da zero, comprendere la struttura complessiva dello spicepod e le sezioni disponibili, configurare le impostazioni di runtime (porte, caching, telemetria/osservabilità), impostare un'applicazione Spice completa combinando set di dati + modelli + ricerca, o comprendere i modelli di distribuzione e i casi d'uso. Questa è la competenza “collante” che mostra come tutti i componenti di Spice si integrano in un unico manifesto. Per dettagli sulle sezioni specifiche (set di dati, modelli, ricerca, ecc.), consulta le competenze dedicate. Rispondi sempre nella lingua dell'utente.
