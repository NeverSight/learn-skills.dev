Start new projects and keep them up to date with first-commit workspace kits (project template + dependencies + agent skills + MCP servers + AGENTS.md rules, installed by `npx create-first-commit`). Use when the user wants to create a new app, landing, SaaS, API, mobile app or browser extension, or to add a library such as Sentry, PostHog, Stripe or Better Auth to an existing project, or when the project has a kits.lock file.
