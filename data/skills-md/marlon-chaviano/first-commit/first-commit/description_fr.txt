Lancez de nouveaux projets et maintenez-les à jour grâce aux kits d'espace de travail first-commit (modèle de projet + dépendances + compétences des agents + serveurs MCP + règles AGENTS.md, installés par `npx create-first-commit`). À utiliser lorsque l'utilisateur souhaite créer une nouvelle application, une page d'accueil, un SaaS, une API, une application mobile ou une extension de navigateur, ou ajouter une bibliothèque telle que Sentry, PostHog, Stripe ou Better Auth à un projet existant, ou lorsque le projet contient un fichier kits.lock.
