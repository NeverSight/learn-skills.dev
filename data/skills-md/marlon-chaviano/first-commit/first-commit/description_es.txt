Inicia nuevos proyectos y mantenlos actualizados con los kits de espacio de trabajo de first-commit (plantilla de proyecto + dependencias + habilidades de los agentes + servidores MCP + reglas AGENTS.md, instalados mediante «npx create-first-commit»). Úsalo cuando el usuario quiera crear una nueva aplicación, una página de inicio, un SaaS, una API, una aplicación móvil o una extensión de navegador, o cuando quiera añadir una biblioteca como Sentry, PostHog, Stripe o Better Auth a un proyecto existente, o cuando el proyecto tenga un archivo kits.lock.
