Starten Sie neue Projekte und halten Sie sie mit First-Commit-Workspace-Kits auf dem neuesten Stand (Projektvorlage + Abhängigkeiten + Agent-Skills + MCP-Server + AGENTS.md-Regeln, installiert mit `npx create-first-commit`). Verwenden Sie diese Option, wenn der Benutzer eine neue App, eine Landingpage, eine SaaS-Lösung, eine API, eine mobile App oder eine Browsererweiterung erstellen möchte oder eine Bibliothek wie Sentry, PostHog, Stripe oder Better Auth zu einem bestehenden Projekt hinzufügen möchte, oder wenn das Projekt eine kits.lock-Datei enthält.
