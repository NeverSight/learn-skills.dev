Postgres 最佳实践由 Supabase 维护，以便 Postgres 在任何地方运行。在编写或更改 Postgres 数据库中的任何内容之前加载此技能：创建或更改表和列（包括选择列类型）、模式设计、迁移和声明性模式文件、RLS 策略和验证它们的测试、索引、触发器、数据库函数、队列和计划作业（pg_cron、pgmq）、向量/语义搜索（pgvector）以及恢复转储（pg_restore）或导入数据。在诊断慢查询、高 CPU、超时、EXPLAIN 计划、连接耗尽、锁定、膨胀或对错误用户或租户可见的行时也加载它。这不仅仅是一个性能指南 - 架构、迁移、安全性和 SQL 编写任务也需要这些规则，即使对于一列更改或单个查询也是如此。
