Mejores prácticas de Postgres mantenidas por Supabase, para que Postgres se ejecute en cualquier lugar. Cargue esta habilidad ANTES de escribir o cambiar cualquier cosa que se encuentre en una base de datos Postgres: crear o alterar tablas y columnas (incluida la elección de tipos de columnas), diseño de esquemas, migraciones y archivos de esquemas declarativos, políticas RLS y las pruebas que las verifican, índices, activadores, funciones de bases de datos, colas y trabajos programados (pg_cron, pgmq), búsqueda vectorial/semántica (pgvector) y restauración de volcados (pg_restore) o importación de datos. Cárguelo también cuando diagnostique consultas lentas, CPU alta, tiempos de espera, planes EXPLAIN, agotamiento de la conexión, bloqueo, hinchazón o filas visibles para el usuario o inquilino incorrecto. Esta no es solo una guía de rendimiento: las tareas de creación de esquemas, migración, seguridad y SQL también necesitan estas reglas, incluso para un cambio de una columna o una sola consulta.
