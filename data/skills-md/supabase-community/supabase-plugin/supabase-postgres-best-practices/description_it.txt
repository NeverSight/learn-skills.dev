Le migliori pratiche di Postgres gestite da Supabase, per Postgres in esecuzione ovunque. Carica questa competenza PRIMA di scrivere o modificare qualsiasi cosa si trovi in ​​un database Postgres: creazione o modifica di tabelle e colonne (inclusa la scelta dei tipi di colonne), progettazione di schemi, migrazioni e file di schema dichiarativi, policy RLS e test che le verificano, indici, trigger, funzioni del database, code e lavori pianificati (pg_cron, pgmq), ricerca vettoriale/semantica (pgvector) e ripristino di dump (pg_restore) o importazione di dati. Caricalo anche durante la diagnosi di query lente, CPU elevata, timeout, piani EXPLAIN, esaurimento della connessione, blocco, rigonfiamento o righe visibili all'utente o al tenant sbagliato. Questa non è solo una guida alle prestazioni: anche le attività di schema, migrazione, sicurezza e creazione SQL necessitano di queste regole, anche per una modifica di una colonna o una singola query.
