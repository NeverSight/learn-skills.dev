أفضل ممارسات Postgres التي تحتفظ بها Supabase لتشغيل Postgres في أي مكان. قم بتحميل هذه المهارة قبل كتابة أو تغيير أي شيء موجود في قاعدة بيانات Postgres: إنشاء أو تغيير الجداول والأعمدة (بما في ذلك اختيار أنواع الأعمدة)، وتصميم المخطط، وعمليات الترحيل وملفات المخطط التعريفي، وسياسات RLS والاختبارات التي تتحقق منها، والفهارس، والمشغلات، ووظائف قاعدة البيانات، وقوائم الانتظار والوظائف المجدولة (pg_cron، pgmq)، والبحث المتجه/الدلالي (pgvector)، واستعادة عمليات التفريغ (pg_restore) أو الاستيراد data. قم أيضًا بتحميله عند تشخيص الاستعلامات البطيئة، أو وحدة المعالجة المركزية العالية، أو المهلات، أو شرح الخطط، أو استنفاد الاتصال، أو القفل، أو الانتفاخ، أو الصفوف المرئية للمستخدم أو المستأجر الخطأ. هذا ليس مجرد دليل أداء - تحتاج مهام المخطط والترحيل والأمان وتأليف SQL إلى هذه القواعد أيضًا، حتى بالنسبة لتغيير عمود واحد أو استعلام واحد.
