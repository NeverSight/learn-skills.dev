Postgres のベスト プラクティスは Supabase によって維持されており、どこでも Postgres を実行できます。 Postgres データベースに存在するものを作成または変更する前にこのスキルをロードしてください: テーブルと列の作成または変更 (列タイプの選択を含む)、スキーマ設計、移行と宣言型スキーマ ファイル、RLS ポリシーとそれらを検証するテスト、インデックス、トリガー、データベース関数、キューとスケジュールされたジョブ (pg_cron、pgmq)、ベクトル/セマンティック検索 (pgvector)、およびダンプの復元 (pg_restore)データをインポートしています。また、遅いクエリ、高 CPU 使用率、タイムアウト、EXPLAIN プラン、接続の枯渇、ロック、肥大化、または間違ったユーザーまたはテナントに表示される行を診断するときにもロードします。これは単なるパフォーマンス ガイドではありません。スキーマ、移行、セキュリティ、SQL 作成タスクにも、1 列の変更や単一のクエリであっても、これらのルールが必要です。
