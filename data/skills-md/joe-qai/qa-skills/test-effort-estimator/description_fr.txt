Cette compétence doit être utilisée lorsque les utilisateurs doivent estimer l’effort de test à partir des exigences du produit. Elle analyse les exigences, découpe les tâches, estime l’effort de test (conception des cas, première exécution, retest, régression) et exporte les résultats vers Excel.

Veuillez toujours répondre dans la langue de l’utilisateur.
