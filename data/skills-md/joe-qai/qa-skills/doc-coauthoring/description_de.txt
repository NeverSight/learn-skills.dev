Führen Sie die Benutzer durch einen strukturierten Workflow zur gemeinsamen Erstellung von Dokumentationen. Wird verwendet, wenn der Benutzer Dokumentationen, Vorschläge, technische Spezifikationen, Entscheidungsdokumente oder ähnliche strukturierte Inhalte schreiben möchte. Dieser Workflow hilft Benutzern, den Kontext effizient zu übertragen, Inhalte durch Iteration zu verfeinern und zu überprüfen, ob das Dokument für die Leser funktioniert. Wird ausgelöst, wenn der Benutzer das Schreiben von Dokumenten, das Erstellen von Vorschlägen, das Erstellen von Spezifikationen oder ähnliche Dokumentationsaufgaben erwähnt.
