Проведите пользователей через структурированный рабочий процесс совместного создания документации. Используйте, когда пользователь хочет написать документацию, предложения, технические спецификации, документы с решениями или аналогичный структурированный контент. Этот рабочий процесс помогает пользователям эффективно передавать контекст, улучшать содержание через итерации и проверять, насколько документ удобен для читателей. Срабатывает, когда пользователь упоминает написание документов, создание предложений, составление технических заданий или аналогичные задачи по документации.

Пожалуйста, всегда отвечайте на языке пользователя.
