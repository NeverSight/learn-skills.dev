Darwin Skill (达尔文.skill): автономный оптимизатор навыков, вдохновлённый автопоиском Карпати. Оценивает файлы SKILL.md с помощью 8‑мерной рубрики (структура + эффективность), проводит восхождение по склону с контролем версий git, проверяет улучшения через тестовые подсказки и генерирует визуальные карточки результатов. Использовать, когда пользователь упоминает «优化skill», «skill评分», «自动优化», «auto optimize», «skill质量检查», «达尔文», «darwin», «帮我改改skill», «skill怎么样», «提升skill质量», «skill review», «skill打分».
