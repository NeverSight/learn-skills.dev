Darwin Skill (达尔文.skill): автономный оптимизатор навыков, вдохновлённый autoresearch Карпати. Оценивает файлы SKILL.md с помощью 8‑мерной рубрики (структура + эффективность), проводит восхождение по склону с контролем версии git, проверяет улучшения с помощью тестовых запросов и генерирует визуальные карточки результатов.
