Full‑Stack‑Entwicklungsumgebungs‑Konfigurator. Er erkennt, wählt aus und installiert verschiedene Entwicklungs‑Runtimes und Performance‑Testing‑Tools und erzeugt Scaffold‑Code für neue Projekte. Diese Fähigkeit wird ausgelöst, wenn der Benutzer „create development environment“, „initialize project“, „set up development stack“, „install Python/Node/Go/Java/JMeter/Locust“, „create backend project“, „create frontend project“, „configure full‑stack environment“, „new Django project“, „new Vue project“, „new Next.js project“, „set up Java Spring project“, „set up Go Web project“, „performance testing environment“, „load‑testing tool installation“, „environment switch“, „dev‑env“ oder „setup env“ erwähnt. Auch wenn der Benutzer nicht explizit „environment“ oder „scaffold“ sagt, sollte jede Absicht, eine Entwicklungsumgebung einzurichten oder einen Tech‑Stack für ein neues Projekt zu initialisieren, diese Fähigkeit auslösen.
