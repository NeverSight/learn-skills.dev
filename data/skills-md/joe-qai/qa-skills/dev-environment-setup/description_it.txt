Configuratore di ambiente di sviluppo full‑stack. Rileva, seleziona e installa vari runtime di sviluppo e strumenti di test delle prestazioni, e genera codice di scaffolding per nuovi progetti. Questa skill viene attivata quando l'utente menziona “create development environment”, “initialize project”, “set up development stack”, “install Python/Node/Go/Java/JMeter/Locust”, “create backend project”, “create frontend project”, “configure full‑stack environment”, “new Django project”, “new Vue project”, “new Next.js project”, “set up Java Spring project”, “set up Go Web project”, “performance testing environment”, “load‑testing tool installation”, “environment switch”, “dev‑env” o “setup env”. Anche se l'utente non dice esplicitamente “environment” o “scaffold”, qualsiasi intento di configurare un ambiente di sviluppo o di inizializzare uno stack tecnologico per un nuovo progetto dovrebbe attivare questa skill.
