مكوّن تكوين بيئة التطوير المتكامل. يُستخدم لاكتشاف واختيار وتثبيت مختلف أطر تشغيل التطوير وأدوات اختبار الأداء، وتوليد شيفرة هيكلية للمشاريع الجديدة. يتم تفعيل هذه المهارة عندما يذكر المستخدم “إنشاء بيئة تطوير”، “تهيئة مشروع”، “إعداد مجموعة تطوير”، “تثبيت Python/Node/Go/Java/JMeter/Locust”، “إنشاء مشروع خلفي”، “إنشاء مشروع أمامي”، “تكوين بيئة متكامل كامل”، “مشروع Django جديد”، “مشروع Vue جديد”، “مشروع Next.js جديد”، “إعداد مشروع Java Spring”، “إعداد مشروع ويب Go”، “بيئة اختبار الأداء”، “تثبيت أداة اختبار التحميل”، “تبديل البيئة”، “dev‑env”، “setup env”. حتى إذا لم يذكر المستخدم صراحةً كلمة “بيئة” أو “هيكلية”، طالما أن النية تتعلق بإعداد بيئة تطوير أو تهيئة مجموعة تكنولوجيا لمشروع جديد، يجب تفعيل هذه المهارة.
