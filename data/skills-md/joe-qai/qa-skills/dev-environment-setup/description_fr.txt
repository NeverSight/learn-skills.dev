Configurateur d'environnement de développement full‑stack. Il sert à détecter, sélectionner et installer divers runtimes de développement et outils de tests de performance, ainsi qu'à générer du code de scaffolding pour de nouveaux projets. Cette compétence se déclenche lorsque l'utilisateur mentionne « create development environment », « initialize project », « set up development stack », « install Python/Node/Go/Java/JMeter/Locust », « create backend project », « create frontend project », « configure full-stack environment », « new Django project », « new Vue project », « new Next.js project », « set up Java Spring project », « set up Go Web project », « performance testing environment », « load testing tool installation », « environment switching », « dev‑env » ou « setup env ». Même si l'utilisateur ne dit pas explicitement « environment » ou « scaffold », tant que l'intention consiste à mettre en place l'environnement de développement d'un nouveau projet ou à initialiser une pile technologique, cette compétence doit être déclenchée.
