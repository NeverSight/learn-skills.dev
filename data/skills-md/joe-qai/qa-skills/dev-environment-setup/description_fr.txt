Configurateur d'environnement de développement full‑stack. Il détecte, sélectionne et installe divers environnements d'exécution de développement et outils de test de performance, et génère du code de base pour de nouveaux projets. Cette compétence est déclenchée lorsque l'utilisateur mentionne « créer un environnement de développement », « initialiser le projet », « configurer la pile de développement », « installer Python/Node/Go/Java/JMeter/Locust », « créer un projet backend », « créer un projet frontend », « configurer un environnement full‑stack », « nouveau projet Django », « nouveau projet Vue », « nouveau projet Next.js », « configurer un projet Java Spring », « configurer un projet Go Web », « environnement de test de performance », « installation d'outil de test de charge », « changement d'environnement », « dev‑env » ou « setup env ». Même si l'utilisateur ne dit pas explicitement « environnement » ou « scaffold », toute intention de mettre en place un environnement de développement ou d'initialiser une pile technologique pour un nouveau projet doit déclencher cette compétence. Veuillez toujours répondre dans la langue de l'utilisateur.
