Usa questa abilità ogni volta che l'utente vuole fare qualcosa con i file PDF. Ciò include leggere o estrarre testo/tabelle dai PDF, combinare o unire più PDF in uno solo, separare i PDF, ruotare le pagine, aggiungere filigrane, creare nuovi PDF, compilare moduli PDF, crittografare/decrittografare PDF, estrarre immagini e fare OCR su PDF scansionati per renderli ricercabili. Se l'utente menziona un file .pdf o chiede di produrne uno, usa questa abilità.

Rispondi sempre nella lingua dell'utente.
