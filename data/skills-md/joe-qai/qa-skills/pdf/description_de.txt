Verwende diese Fähigkeit, wann immer der Benutzer etwas mit PDF‑Dateien machen möchte. Dazu gehören das Lesen oder Extrahieren von Text/Tabellen aus PDFs, das Kombinieren oder Zusammenführen mehrerer PDFs zu einer Datei, das Aufteilen von PDFs, das Drehen von Seiten, das Hinzufügen von Wasserzeichen, das Erstellen neuer PDFs, das Ausfüllen von PDF‑Formularen, das Verschlüsseln/Entschlüsseln von PDFs, das Extrahieren von Bildern und die OCR von gescannten PDFs, um sie durchsuchbar zu machen. Wenn der Benutzer eine .pdf‑Datei erwähnt oder bittet, eine zu erstellen, benutze diese Fähigkeit.

Bitte antworte immer in der Sprache des Benutzers.
