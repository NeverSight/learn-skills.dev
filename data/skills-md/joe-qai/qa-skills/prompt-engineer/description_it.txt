Scrive, rifattorizza e valuta i prompt per LLM — generando template di prompt ottimizzati, schemi di output strutturati, rubriche di valutazione e suite di test. Da utilizzare quando si progettano prompt per nuove applicazioni LLM, si rifattorizzano prompt esistenti per migliorare l'accuratezza o l'efficienza dei token, si implementano chain-of-thought o apprendimento few-shot, si creano prompt di sistema con personas e guardrails, si costruiscono schemi JSON/chiamate di funzione, o si sviluppano framework di valutazione dei prompt per misurare e migliorare le prestazioni del modello.
