يكتب، يعيد هيكلة، ويقيم الإرشادات (المطالبات) لنماذج اللغة الكبيرة — ويولد قوالب إرشادات محسّنة، مخططات مخرجات مُنظمة، معايير تقييم، ومجموعات اختبار. يُستخدم عند تصميم الإرشادات لتطبيقات جديدة لنماذج اللغة الكبيرة، أو إعادة هيكلة الإرشادات الحالية لتحسين الدقة أو كفاءة الرموز، أو تنفيذ سلاسل التفكير أو التعلم القليل العينة، أو إنشاء إرشادات نظام مع شخصيات وإرشادات أمان، أو بناء مخططات JSON/استدعاء الوظائف، أو تطوير أطر تقييم الإرشادات لقياس وتحسين أداء النموذج.
