Utilisez cette compétence chaque fois qu’un fichier de feuille de calcul est l’entrée ou la sortie principale. Cela signifie toute tâche où l’utilisateur souhaite : ouvrir, lire, modifier ou réparer un fichier .xlsx, .xlsm, .csv ou .tsv existant (par exemple, ajouter des colonnes, calculer des formules, mettre en forme, créer des graphiques, nettoyer des données désordonnées) ; créer une nouvelle feuille de calcul à partir de zéro ou à partir d’autres sources de données ; ou convertir entre des formats de fichiers tabulaires. Déclenchez surtout lorsque l’utilisateur fait référence à un fichier de feuille de calcul par son nom ou son chemin — même de manière informelle (comme « le xlsx dans mes téléchargements ») — et veut quelque chose de fait avec ou produit à partir de celui‑ci. Déclenchez également pour nettoyer ou restructurer des fichiers de données tabulaires désordonnés (lignes mal formées, en‑têtes mal placés, données parasites) en feuilles de calcul correctes. Le livrable doit être un fichier de feuille de calcul. NE déclenchez pas lorsque le livrable principal est un document Word, un rapport HTML, un script Python autonome, un pipeline de base de données ou une intégration API Google Sheets, même si des données tabulaires sont impliquées.
