استخدم هذه المهارة في أي وقت يكون ملف جدول البيانات هو الإدخال أو الإخراج الأساسي. يعني ذلك أي مهمة يريد المستخدم فيها: فتح، قراءة، تعديل، أو إصلاح ملف .xlsx أو .xlsm أو .csv أو .tsv موجود (مثلاً إضافة أعمدة، حساب صيغ، تنسيق، رسم مخططات، تنظيف البيانات الفوضوية)؛ إنشاء جدول بيانات جديد من الصفر أو من مصادر بيانات أخرى؛ أو التحويل بين صيغ الملفات الجدولية. يتم التفعيل خصوصاً عندما يشير المستخدم إلى ملف جدول بيانات بالاسم أو المسار — حتى بشكل عابر (مثل «ملف xlsx في التنزيلات») — ويرغب في القيام بعمل ما على الملف أو إنتاج شيء منه. كما يُفعل عندما يُطلب تنظيف أو إعادة هيكلة ملفات البيانات الجدولية الفوضوية (صفوف غير صحيحة، رؤوس موضعها غير مناسب، بيانات غير مرغوب فيها) إلى جداول بيانات سليمة. يجب أن يكون المخرَج النهائي ملف جدول بيانات. لا تُفعَّل عندما يكون المخرَج الأساسي مستند Word أو تقرير HTML أو سكريبت Python مستقل أو خط أنابيب قاعدة بيانات أو دمج مع API لجوجل شيتس، حتى وإن كانت البيانات جدولية.
