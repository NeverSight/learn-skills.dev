在电子表格文件是主要输入或输出时使用此技能。这意味着任何用户想要：打开、读取、编辑或修复已有的 .xlsx、.xlsm、.csv 或 .tsv 文件的任务（例如，添加列、计算公式、格式化、绘图、清理杂乱数据）；从头创建新电子表格或从其他数据源创建；或在表格文件格式之间转换。尤其在用户提及电子表格文件的名称或路径时触发——即使是随意提到（比如“下载文件夹里的那个 xlsx”）——并希望对其进行操作或从中生成内容时也应触发。对清理或重构杂乱的表格数据文件（行格式错误、标题错位、垃圾数据）为正规电子表格也应触发。交付物必须是电子表格文件。若主要交付物是 Word 文档、HTML 报告、独立的 Python 脚本、数据库管道或 Google Sheets API 集成，即使涉及表格数据，也不要触发。
