Generar automáticamente documentos de casos de prueba estructurados a partir de documentos de requisitos, PRD o especificaciones de interfaz. Por defecto, emplear estrategias comunes de diseño de casos de prueba (positivos, negativos, valores límite, clases de equivalencia, etc.); cuando el usuario hace referencia a una plantilla de Excel/Word, cargar la plantilla desde los recursos, y cuando se mencionan estándares especializados como criterios de interfaz, rendimiento o funcionales, cargar las especificaciones correspondientes de las referencias. Es adecuado para diseñar casos de prueba funcionales, de interfaz, de rendimiento y candidatos a automatización a partir de diversos tipos de documentación.
