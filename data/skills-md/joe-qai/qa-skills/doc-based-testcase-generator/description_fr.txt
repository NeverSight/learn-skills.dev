Générer automatiquement des documents de cas de test structurés à partir de documents d'exigences, de PRD ou de spécifications d'interface. Par défaut, il utilise des stratégies générales de conception de cas de test (positif, négatif, valeurs limites, classes d'équivalence, etc.) ; lorsque l'utilisateur mentionne un modèle Excel/Word de référence, le modèle est chargé depuis les ressources, et lorsque des normes spécialisées telles que l'interface, la performance ou fonctionnelle sont référencées, la description correspondante est chargée depuis les références. Cela convient à la conception de cas de test fonctionnels, d'interface, de performance et d'automatisation à partir de divers documents.
