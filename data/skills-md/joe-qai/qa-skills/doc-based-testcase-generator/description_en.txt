Automatically generate structured test case documents based on requirement documents, PRDs, or interface specifications. By default, employ common test case design strategies (positive, negative, boundary values, equivalence classes, etc.); when the user references an Excel/Word template, load the template from assets, and when specialized standards such as interface, performance, or functional criteria are mentioned, load the corresponding specifications from references. Suitable for designing functional, interface, performance, and automation candidate test cases from various types of documentation.
