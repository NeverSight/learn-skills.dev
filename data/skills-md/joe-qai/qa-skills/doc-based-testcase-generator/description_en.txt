Automatically generate structured test case documents based on requirement documents, PRDs, or interface specifications. By default, it employs general test case design strategies (positive, negative, boundary values, equivalence classes, etc.); when the user mentions a reference Excel/Word template, the template is loaded from assets, and when specialized standards such as interface, performance, or functional are referenced, the corresponding description is loaded from references. This is suitable for designing functional, interface, performance, and automation candidate test cases from various documents.
