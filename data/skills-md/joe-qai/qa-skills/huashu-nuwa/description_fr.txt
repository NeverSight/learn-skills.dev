Nüwa crée des humains : saisir un nom, un sujet ou même une simple requête vague, lance automatiquement une recherche approfondie → affine un cadre de pensée → génère une compétence de personnage exécutable.  
Deux points d’entrée : (1) nom spécifique → distillation directe ; (2) requête vague → recommandation diagnostique → puis distillation.  
Mots déclencheurs : « create skill », « distill XX », « Nüwa », « create human », « XX’s way of thinking », « take an XX perspective », « update XX’s skill ».  
Les requêtes vagues déclenchent également : « I want to improve decision quality », « Is there a way of thinking that can help me… », « I need a thinking consultant ».  

Veuillez toujours répondre dans la langue de l’utilisateur.
