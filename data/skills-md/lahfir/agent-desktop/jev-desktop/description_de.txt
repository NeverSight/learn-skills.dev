Steuern Sie eine Desktop-Anwendung anhand eines einfachen Sprachziels oder erledigen Sie jeweils eine Absicht, ohne jemals den Accessibility‑Tree zu lesen. Verwenden Sie es, wenn Sie eine Desktop‑App automatisieren und einen 150‑Elemente‑JSON‑Baum aus Ihrem Kontext heraushalten möchten. Übergeben Sie `run.mjs` ein komplettes Ziel, und es beobachtet, entscheidet und handelt, bis das Ziel erreicht ist; übergeben Sie `act.mjs` einen einzelnen Schritt, wenn Sie den Plan selbst behalten wollen. Es behandelt, welches Element, welche Operation, wann man tiefer schauen sollte und wann man stoppen sollte.
