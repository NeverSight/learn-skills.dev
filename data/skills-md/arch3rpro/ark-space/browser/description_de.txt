Navigieren und interagieren Sie mit einer Website durch eine eigene, begrenzte ArkSpace-Browsersitzung. Wird verwendet, wenn eine Aufgabe einen dynamischen Seitenstatus, Klicks, das Ausfüllen von Formularen, das Scrollen, die Paginierung oder einen Zugänglichkeits-Snapshot anstelle des normalen Abrufs im öffentlichen Web erfordert.
