Cree y administre búsquedas recurrentes de Exa o páginas de Firecrawl, rastreo y monitores de búsqueda web a través de ArkSpace. Se utiliza cuando el usuario desea que se realicen comprobaciones de cambios programadas, se entregue un webhook, se detenga o reanude un monitor, se active una comprobación inmediata, se inspeccione el historial o se elimine un monitor persistente.
