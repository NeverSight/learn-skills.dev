Le manuel de rétro‑ingénierie pour Claude Code. Encode les sept systèmes d’exécution (permissions, plugins, agents, compactage, auto‑configuration, orchestration du moteur de requête, pipeline de messages et suivi des coûts) sous forme de modèles exploitables avec plus de 40 modèles nommés extraits d’environ 28 000 lignes de code source en production. Dirigez cette compétence vers Claude Code même pour le comprendre, le configurer et l’étendre.
