# 小红书爆款笔记生成器

> ⚠️ **身份定位**: 本 Skill 融合「8 种内容框架」与「标题优化系统」，结合 AI 味检测、关键词密度计算、合规自检三重质检。用户提供产品/卖点/人群信息后，先输出 5-8 个匹配框架的优化标题，再生成 5 篇可直接复制发布的小红书完整笔记。

---

## 买点思维：生成前必经分析

本节为独立的买点执行规范，供当前 Skill 直接分析与生成使用；不依赖外部理论文档，不作为学术定律、平台规则或效果保证。下列规则优先于本文后续模板中与之冲突的随机选框架、强情绪、结果承诺和强转化要求；其余原有交付与质检保留。

1. 从已有上下文提取赛道、细分品类、具体产品/服务或内容主题、账号身份、目标及限制。区分可核实事实、材料支持的需求、待验证假设与缺失；已有信息不重复问，仅追问影响当前交付的缺项。
2. 按当前品类分析消费人群的具体任务、使用/决策时刻、预算与条件限制、顾虑或审美偏好。年龄性别不是需求依据；不得把其他品类的需求直接换名套入。不同人群/场景分别形成候选，不笼统写“所有女性”“高端人群”。
3. 对候选完成五问：谁需要 → 何时需要 → 纠结或期待什么 → 产品事实/内容呈现带来什么价值 → 凭什么相信。先识别信息决策、视觉审美或组合路径，再确定核心买点；纯审美内容可只说明欣赏/参考价值，不强造购买理由。
4. 生成前形成简短的“买点分析表”：`编号｜赛道/品类｜人群与场景｜顾虑/期待｜产品事实或画面｜核心买点/内容价值｜依据及需求证据状态｜适用限制/缺口｜观察反馈`。材料支持、待验证假设、缺失分开标记；不能将假设写成客户原话、真实经历或功能结论。
5. 选题、标题、正文复用同一编号与买点说明；下游已有分析直接复用，事实或人群改变时只更新受影响项。每条内容优先回应一个主要问题。买点分析是创作依据，不要求最终文案机械填满五问。

### 跨品类适配与真实性边界

- 商品：把已核实的功能、尺寸、材质或参数连接到使用任务，说明适用条件；参数不直接等于效果。
- 服务/教育：围绕选择、过程和实际交付消除不确定性，不能扩大为必然结果。
- 个人 IP：使用真实判断、作品、经历解释关注/信任理由，不捏造“我用过”“客户说”；关注不等于购买。
- 穿搭、家居、摄影、旅行等视觉内容：分析目标用户的风格与效果参考需求，具体安排构图、光线、色彩、比例或对比条件；没有素材只给视觉方案，不声称已看见效果。
- 反馈按目标选择：教程观察保存与实际使用，审美观察风格反馈与分享，服务观察咨询匹配度；流量、私信与成交分别判断，不虚构权重、阈值或转化率。

### 买点交付检查

逐条核对：人群场景是否具体；选择理由是否连接事实；证据状态是否准确；承诺是否能由正文/素材兑现；是否适配账号身份；是否强造焦虑或购买意图。未通过只修对应项；事实缺失则补问或交付明确标注的候选方向，不交付虚构成稿。此项加入原有质检，不能替代 AI 味、合规和格式检查。

## 五种爆款文案框架

| 框架 | 结构 | 适用场景 | 开篇钩子模板 |
|------|------|---------|------------|
| **痛点共鸣型** | 痛点场景 → 共鸣金句 → 解决方案 → 产品引入 → 效果展示 | 美妆、护肤、健康、家居 | "XX 困扰 X 年，直到我..." |
| **测评对比型** | 测评说明 → 逐个产品 → 对比表格 → 总结推荐 | 数码、美妆、美食、高客单价 | "花了 XXXX 测了 X 款，结论是..." |
| **故事种草型** | 个人经历 → 发现过程 → 使用体验 → 真心推荐 | 穿搭、旅行、家居、情感体验 | "上周差点社死，幸亏..." |
| **干货教程型** | 问题引入 → 步骤拆解 → 技巧提示 → 工具推荐 | 学习、职场、手工、方法论 | "千万别再 XX 了！90% 的人都错了" |
| **清单盘点型** | 开篇悬念 → 清单列表 → 每项详解 → 彩蛋收尾 | 书单、影单、好物、工具选购 | "X 个 XX 必囤清单，新手照抄" |

> **扩展结构**（用户可指定，或在以上 5 种基础上叠加使用）：
> - **反常识纠错型**：教育成本高的新品类 — "千万别再 XX 了！90% 的人都错了"
> - **沉浸场景型**：食品/家居/服饰 — "周日下午 3 点，我做了一件..."
> - **情绪价值型**：个护/治愈系 — "成年人最该有的小事是..."

## 第 1 步：信息收集

从用户输入提取 6 项核心信息，**缺任一必填项必须追问**，禁止自行假设产品卖点：

| 字段 | 必填 | 示例 |
|------|------|------|
| 产品/服务 | ✅ | 某品牌烟酰胺精华液 |
| 核心卖点 | ✅ | 2% 烟酰胺 + 敏感肌可用 |
| 目标人群 | ✅ | 25-35 岁敏感肌女性 |
| 价格带 | 选填 | 200-300 元 |
| 用户指定选题 | 选填 | "换季泛红怎么办" |
| 已有选题/标题/大纲 | 选填 | 用户是否有已拟好的选题、标题或大纲 |

追问话术示例（第一轮，合并在一轮问完）：
> "为了写出更精准的笔记，再补充 2 个信息：产品的核心卖点是什么？目标人群是谁（年龄/性别/使用场景）？另外，你目前有没有已经拟好的选题、标题或者大纲？如果有的话请直接发给我，我会在此基础上优化和扩展。"

**关于已有选题/标题/大纲的处理规则：**
- 用户有完整标题 → 在生成时优先使用该标题作为一篇笔记的标题，在此基础上扩展正文
- 用户有选题方向（如"想写换季护肤"）→ 围绕该选题方向生成 5 篇笔记
- 用户有大纲 → 基于大纲结构填充内容，保留用户规划的逻辑框架
- 用户无任何准备 → 按正常流程从 0 生成

## 第 2 步：关键词策略

构建 **三层关键词体系**：

1. **核心词**（1-2 个）：产品/品类大词，如"烟酰胺精华"
2. **场景词**（2-3 个）：使用情境，如"换季泛红""熬夜急救"
3. **长尾词**（2-3 个）：搜索意图词，如"敏感肌精华推荐""平价烟酰胺"

总计 5-8 个关键词，目标密度 **5%-8%**（上限收紧到 8%，避免堆砌感）。

## 第 3 步：框架匹配与 5 篇规划

### 框架选择逻辑（5 篇笔记的规划策略）

| 用户输入 | 生成策略 | 5 篇如何分配 |
|---------|---------|------------|
| **指定了框架**（如"框架：痛点共鸣"） | 在**该框架下换角度**，生成 5 篇 | 5 篇同一框架，每篇一个不同切入点（如：场景切入 / 人群切入 / 时间线切入 / 对比切入 / 情感切入） |
| **未指定框架** | 按买点与现有证据从内置框架池中选适配框架，优先 5 个不同框架；不足时复用适配框架换人群/场景角度，不为凑框架编造故事或测评 | 5 篇回应不同场景或主要问题，框架服从买点与证据 |
| **指定了选题/标题/大纲** | 在用户提供的框架上扩展 | 框架逻辑同上，但保留用户的标题或大纲作为其中一篇的核心骨干 |

**框架池**（5 种主框架 + 3 种扩展结构）：

| 编号 | 框架 | 结构 | 适用场景 |
|------|------|------|---------|
| F1 | 痛点共鸣型 | 痛点场景 → 共鸣金句 → 解决方案 → 产品引入 → 效果展示 | 美妆、护肤、健康、家居 |
| F2 | 测评对比型 | 测评说明 → 逐个产品 → 对比表格 → 总结推荐 | 数码、美妆、美食、高客单价 |
| F3 | 故事种草型 | 个人经历 → 发现过程 → 使用体验 → 真心推荐 | 穿搭、旅行、家居、情感体验 |
| F4 | 干货教程型 | 问题引入 → 步骤拆解 → 技巧提示 → 工具推荐 | 学习、职场、手工、方法论 |
| F5 | 清单盘点型 | 开篇悬念 → 清单列表 → 每项详解 → 彩蛋收尾 | 书单、影单、好物、工具选购 |
| F6 | 反常识纠错型 | 错误认知 → 正确做法 → 为什么错 → 正确执行 | 教育成本高的新品类 |
| F7 | 沉浸场景型 | 场景描写 → 行为展开 → 产品自然出现 → 体验总结 | 食品、家居、服饰 |
| F8 | 情绪价值型 | 情绪铺垫 → 转折触发 → 治愈时刻 → 温暖收尾 | 个护、治愈系、生活方式 |

### 同一框架下 5 个不同角度的示例（指定框架时参考）

以「痛点共鸣型」为例，5 篇的分角度方案：

| 篇 | 角度 | 切入点 |
|----|------|--------|
| 篇 1 | 场景切入 | 从具体生活场景出发（加班熬夜/换季过敏/产后恢复） |
| 篇 2 | 人群切入 | 针对特定人群的细分痛点（学生党/上班族/宝妈） |
| 篇 3 | 时间线切入 | 从"以前踩坑→现在找到方法"的纵向对比 |
| 篇 4 | 对比切入 | "用 A 方法 vs 用 B 方法"的横向效果差异 |
| 篇 5 | 情感切入 | 从情绪低谷到被产品治愈的心理历程 |

### 风格切换

| 用户指定 | 调整方向 |
|---------|---------|
| 风格：温柔 | 语气柔和，多用"可以试试""慢慢来"，避免强硬断言 |
| 风格：酷炫 | 语气直接，多用"绝了""闭眼入""冲"，短句为主 |
| 风格：简约 | 克制修饰，每段 2-3 句，突出信息效率 |
| 风格：奢华 | 精致描述，突出质感/体验/仪式感 |
| 未指定 | 根据品类和框架自动匹配中性风格 |

## 第 4 步：标题优化（5-8 个候选标题 + 框架匹配）

在生成完整笔记之前，先输出 5-8 个优化标题。每个标题匹配一个内容框架，标题控制在 20 字以内，不改变用户原意，不出现表情符号。

### 标题优化规则

| 规则 | 说明 |
|------|------|
| 标题数量 | 5-8 个，覆盖不同框架类型 |
| 字数限制 | 严格 ≤20 汉字，含标点，不含 emoji |
| 原意保留 | 不歪曲用户的产品/卖点/人群信息，保留核心关键词 |
| 框架匹配 | 每个标题标注对应的框架类型，确保与正文结构一致 |
| 标题张力 | 从已确认的买点出发，清楚呈现具体场景、选择问题或审美价值；对比、数字和悬念仅在有依据且正文可兑现时使用，不强凑两项，不强加结果承诺 |

### 框架→标题对应的匹配逻辑

| 框架 | 标题方向 | 示例 |
|------|---------|------|
| 痛点共鸣型 | 指向具体痛点场景，用情绪词引发共鸣 | 运动时耳机老掉？试过这款就回不去了 |
| 测评对比型 | 暗示横向对比或评测结论，用数字/结果钩子 | 测了五款运动耳机，只有这款跑十公里不掉 |
| 故事叙事型 | 用时间线或个人经历开头，制造代入感 | 健身八年换过五副耳机，最后还是选了它 |
| 干货教程型 | 用方法/步骤/指南类关键词，降低认知成本 | 运动耳机选购三步法，照着买不踩坑 |
| 清单盘点型 | 用数字+盘点类关键词，制造完整感 | 健身老手的五款平价运动耳机红黑榜 |
| 反常识纠错型 | 用"别再""误区""90% 的人都"制造冲突 | 运动耳机别只看价格，这个指标更重要 |
| 沉浸场景型 | 用具体的场景/时间/动作开头，营造画面感 | 每周二晚上的健身房，耳机是我的入场券 |
| 情绪价值型 | 用情绪金句或治愈感关键词，降低攻击性 | 戴上它去健身的那天，我找到了运动的节奏 |

### 标题→5 篇笔记的映射规则

## 第 6 步：AI 味修正

本步执行AI味检测、改写与交付门槛。框架及标题表达遵循前述买点适配规则；其余默认5篇、标题候选、篇幅、段落、关键词密度、封面、标签、评论钩子与合规流程均保持原规则；不能以去AI味为由减少篇数、更换框架或放宽格式。若原规则与自然表达暂时难以同时满足，报告未通过，不擅自改规则。

### 检测依据

先完整读取本包随附的 [AI味检测参考](references/ai-style-check.md)，按其中的检测框架执行，再按本步改写和复检。参考来自 `xhs-ai-check` 的检测规则，已经随本包分发，不依赖作者电脑的安装路径。无法读取则标记检测未完成，不交付成稿。

检测器判断文风，不鉴定作者身份，不代替AI标识或原有合规检查。参考中的“优化后版本”只用于内部修订，不得绕过本步门槛提前展示。

### 六类检测与对应改写

| 类别 | 检查与修改原则 |
|------|----------------|
| 连接与论述腔 | 检查固定连接词、翻译腔、说明书腔；按上下文改写，不机械禁词 |
| 抽象与夸张 | 删除无信息的修饰、抽象结论与空泛承诺，保留具体可支持的信息 |
| 人称与语气 | 保留用户语气；不能把品牌介绍改成“我用过”，不能捏造用户经历 |
| 结构与节奏 | 在原框架、篇幅和段落要求内消除句式过齐、平均用力、重复金句与万能升华；不自创替代框架 |
| 口语与互动 | 不靠堆“真的、家人们、谁懂啊”制造人味；原有评论钩子保留，改为与正文相关的自然提问 |
| 细节与真实性 | 只用用户确认或有来源的时间、地点、价格、动作和感受；缺少事实先追问，不为显真实而编造 |

### 修订与最终复检

内部草稿 → 逐篇检测 → 仅修改失败篇的问题段落 → 完成原第7、8步 → 重新检测最终完整版本。标题、关键词或合规措辞发生任何修改，旧AI味结论即失效。整批另查重复开头、同一话术与套模版感，同时维持原框架分配规则。

每篇记录版本、风险等级（低/中/高）、问题组件与原句、修改动作、六类检出/修正情况、未解决项。没有问题不硬找；不能用删词数量或凭空打分代替判断。少于3句的组件只做局部判断，整篇结论基于完整笔记。

交付须同时满足：最终版本AI味风险为低，无未解决的明显模板腔、空话或伪口语；无为改写而捏造的事实；原有格式、关键词、框架和合规要求全部满足。默认5篇全部通过才交付，不以一篇通过代替整批通过。

未通过时只报告卡点及最少需要补充的信息，不展示失败草稿、可复制替代稿或检测器的“优化后版本”。连续3轮仍未通过，暂停本轮生成并保留待修状态；补充事实后继续。不得降低门槛或无限自改，不承诺平台审核通过。

## 第 7 步：关键词密度计算

**公式**：`关键词总出现次数 ÷ 正文总字数 × 100%`

- **低于 5%**：在标题/小标题/结尾 CTA 处自然补足
- **高于 8%**：替换部分为同义表达（"精华" ↔ "精华液" ↔ "这瓶"）
- 达标后记录最终密度值，标注每个关键词出现次数

---

## 第 8 步：合规检查

逐篇排查以下红线词库：

| 类别 | 示例 | 合规替换方向 |
|------|------|------------|
| 绝对化用语 | 第一、最、唯一、顶级、国家级、永久 | 去掉程度词，改为"我用过中"/"个人觉得" |
| 医疗承诺 | 治愈、根治、疗效、医用级 | 改为"改善""感觉""个人体验" |
| 投资金融 | 稳赚、保本、暴富 | 不生成此类内容 |
| 竞品贬低 | "某品牌不如..." | 改为"和我之前用的相比" |
| 虚假承诺 | 100%有效、立刻见效 | 改为"坚持用了一段时间后" |

发现风险表达 → 按完整语境检查实质承诺并修正，在质检报告中标注。不得通过添加“个人觉得”“我用过”或“改善”伪造经历或保留无依据的效果；无法支持时删除承诺或补问。

|---------|---------|
