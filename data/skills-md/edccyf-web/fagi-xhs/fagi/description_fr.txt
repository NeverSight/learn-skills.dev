Commandes déclencheurs : /fagi, /fagi beginner guide, Xiaohongshu operations, write Xiaohongshu, Xiaohongshu strategy, Xiaohongshu keyword, Xiaohongshu title, Xiaohongshu note, Xiaohongshu compliance, Xiaohongshu data review, Xiaohongshu benchmark analysis, competitor account research, « analyze this influencer », « help me create Xiaohongshu », « can I post ».  
FAGI = Fusion Agent Group Intelligence. Huit agents spécialistes coordonnés via un point d’entrée unique : recherche de mots‑clés, stratégie double compte, optimisation de titres, rédaction de notes, vérification de conformité, pré‑vérification de publication, revue de données, analyse concurrentielle.
