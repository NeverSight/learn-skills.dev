# 小红书关键词规划工具

> ⚠️ **身份定位**: 纯关键词规划工具。基于 10 维分类体系输出结构化关键词矩阵，**必须启用搜索量验证**，输出格式为 **Excel (.xlsx) + Markdown 双格式**。用户对话环节新增**账号阶段采集**，据此输出关键词部署策略。不含内容策略和笔记生成。

**自动分流边界**：本 skill 的竞品模式保留 D7 搜索词、搜索量与关键词部署研究。若用户要账号定位、代表笔记、内容逻辑或可借鉴做法，使用 `fagi-xhs-competitor-analyzer`；只有「竞品分析」而上下文不明时，先区分账号内容研究与搜索词研究。显式指定本 skill 时遵循其关键词范围，不能静默改换。


## 本地提速路径（保持现有交付要求）

- 复用本轮已确认信息，仅追问缺项。按目标路径读取必要参考；一次研究后保留一个 `keyword_data.json`，不要分别重新构思 Markdown 表和 Excel 表。
- 按 [本地装配数据格式](references/local-pipeline.md) 填入候选词和语义判断得到的词根，先执行 `python3 scripts/render_report.py keyword_data.json roots.json --prepare`。该步骤只合并完全相同的词根请求，不自动猜词根、不丢弃跨维度词。
- 全流程/竞品模式仍按第 4 步验证搜索量：同轮同平台同地域同统计窗口的同一词根只查一次，记录来源与时间。若工具提供批量接口可批量查；浏览器仅按真实支持的操作执行。跨次运行的旧记录不能冒充本次验证，配额不足明确待验证。搜索失败只补查失败词根，不重查已成功部分。
- 将验证记录写回同一个 JSON。运行 `python3 scripts/render_report.py keyword_data.json 报告.md --xlsx 矩阵.xlsx`，同进程一次生成原有 3 个 Sheet 和 Markdown。脚本复用词根量并标明「词根量」，不冒充派生词独立搜索量。
- 脚本返回缺项时仅修缺项，再运行装配；原有行业分析、10 维覆盖、搜索意图/策略评级/账号分配、竞品分析和部署策略仍须完成。语义相关性与来源可信度继续人工核验；脚本不调用模型，也不生成虚构搜索数据。

## 第 1 步：信息收集 + 目标确认（含竞品/品牌词/账号阶段/目标路径）

从用户输入提取 **7 项核心信息**，缺必填项须追问，合并在一轮问完：

| 字段 | 必填 | 示例 |
|------|------|------|
| 行业/品类 | ✅ | 原创木作 / 宠物护理 |
| 目标人群 | ✅ | 25-40 岁有审美追求的消费者 |
| 品牌名（如有） | 选填 | 筱超 |
| 竞品/对标品牌 | 建议提供 | 苏州博物馆、本色图书馆 |
| 地域（本地化业务） | 选填 | 全国 / 重庆 |
| **当前账号阶段** | ✅ | 新号起号期 / 成长期 / 成熟期 |
| **你想走到哪一步？** | ✅ | A) 全流程 / B) 只要关键词矩阵 / C) 只要竞品关键词分析 |
| 已有关键词方向 | 选填 | "想做木作送礼方向" |

### 账号阶段定义

| 阶段 | 特征 | 关键词策略重心 |
|------|------|--------------|
| **新号起号期** | 粉丝 < 1000，账号权重低 | 低竞争长尾词优先（D8/D9），避高流量红海词，每天 1 篇稳定输出 |
| **成长期** | 粉丝 1000-10000，有基础权重 | 痛点词（D3）+ 场景词（D2）并重，开始布局风格词（D6），日更 1-2 篇 |
| **成熟期** | 粉丝 > 10000，品牌心智形成 | 品牌词（D1）+ 竞品拦截词（D7）+ 决策指南词（D10）全力覆盖，保持日更 1 篇+评论区引导 |

### 目标路径定义

| 选项 | 覆盖步骤 | 适合场景 | 交付物 |
|------|---------|---------|--------|
| **A) 全流程** | 第 2 步 → 第 3 步 → 第 4 步 → 第 5 步 → 第 6 步 → 第 7 步 | 从 0 开始，需要完整关键词+竞品+策略 | 完整关键词矩阵 + 竞品分析报告 + 部署策略 |
| **B) 只要关键词矩阵** | 跳至第 3 步 → 第 4 步 → 第 5 步 → 第 7 步 | 已有方向，只要关键词词包 | 关键词矩阵 Excel + Markdown |
| **C) 只要竞品关键词分析** | 第 2 步 → D7 维度深挖 → 竞品报告 | 已有竞品名，只想研究搜索词与竞品拦截词 | 竞品拦截词矩阵 + 竞品对标报告 |

## 第 4 步：搜索量验证

**本步骤在全流程和竞品分析模式下为内置必做步骤。** 如果用户选择 B) 只要关键词矩阵，则跳过此步骤。
无论用户是否主动要求，全流程和竞品分析模式都必须在关键词推导后执行搜索量验证。

### 4.1 词根优先策略

从 60-100 个派生词中提炼 10-20 个词根，只验证词根：

| 词根 | 覆盖的派生词 |
|------|------------|
| 木作 | 原创木作、手工木作、木作定制、木作礼物 |
| 手作 | 手作礼物、手作推荐、手作摆件 |
| 原创 | 原创设计、原创品牌、原创手作 |

### 4.2 验证流程

1. 打开 `https://dso100.com/KeywordDouyin/XhssearchWord`
2. 选择「小红书」Tab，确认「单个」模式
3. 逐个输入词根 → 点击「挖掘」→ 记录月搜索量、竞争度、相关记录数
4. 遇到会员弹窗点击「残忍离开」

### 4.3 判定矩阵

| 词根月搜索量 | 判定 | 处理 |
|------------|------|------|
| > 5,000 | 有效 | 保留所有派生词，标记为 T1 高置信 |
| 1,000-5,000 | 小众但有效 | 保留，标记为 T2 已验证 |
| 100-1,000 | 边缘 | 审查该维度，标记为 T3 待观察 |
| < 100 或 0 | 无效 | 移除该词根及所有派生词 |

### 4.4 置信度分级

| 层级 | 标准 | 用途 |
|-----|------|------|
| T1 高置信 | 词根量 > 5,000 + 搜索建议确认 | 优先嵌入标题和标签 |
| T2 已验证 | 词根量 1,000-5,000 | 正文中使用 |
| T3 待观察 | 词根量 < 1,000 或未验证 | 使用前需二次确认 |

### 4.5 DSO100 附带收获

关注分词面板、蓝海词 Tab、相关词 Tab，发现新的词根加回框架，更新关键词矩阵。

### 5.1 交叉组合

| 组合方式 | 示例 |

| 星级 | 标准（结合搜索量） | 处理建议 |

## 第 6 步：关键词部署策略

### 6.1 各阶段部署策略

#### 新号起号期策略

| 维度 | 部署动作 | 每周发布频率 | 预期效果 |
|------|---------|------------|---------|
| D8 长尾词 | 主攻低竞争长尾词，标题前置长尾关键词 | 3-4 篇/周 | 快速获得初始搜索流量 |
| D9 属性词 | 铺设材质/预算类属性词内容 | 2 篇/周 | 拦截细分人群搜索 |
| D3 痛点词 | 选择 1-2 个高共鸣痛点做爆款尝试 | 1 篇/周 | 培养账号辨识度 |
| **避坑** | 不要碰 D1 品牌词（搜索量不够）和 D7 竞品词（无流量基础） | — | — |

**新号期执行清单：**
- [ ] 优先发 D8 长尾词内容，标题前 5 字锁定核心长尾词
- [ ] 正文自然嵌入同维度 2-3 个相关词
- [ ] 评论区由作者主动置顶 1 条含关键词的引导评论
- [ ] 发布后 12 小时检查笔记是否被收录（搜索完整标题）

#### 成长期策略

| 维度 | 部署动作 | 每周发布频率 | 预期效果 |
|------|---------|------------|---------|
| D2 场景词 | 主力覆盖高频场景词 | 2-3 篇/周 | 扩大流量入口 |
| D3 痛点词 | 持续输出痛点内容，形成系列 | 2 篇/周 | 建立信任和共鸣 |
| D6 风格词 | 开始布局风格×空间组合 | 1 篇/周 | 吸引审美偏好人群 |
| D10 决策词 | 开始铺设选购指南类内容 | 1 篇/周 | 拦截决策阶段流量 |

**成长期执行清单：**
- [ ] D2+D3 为主力，每周至少 4 篇场景/痛点内容
- [ ] D6 风格词可做 2-3 篇爆款尝试
- [ ] 关注评论区热门话题，作为下一条笔记选题来源
- [ ] 定期检查搜索量数据，淘汰无效词根

#### 成熟期策略

| 维度 | 部署动作 | 每周发布频率 | 预期效果 |
|------|---------|------------|---------|

**成熟期执行清单：**
- [ ] D1+D7 为主力，每周至少 4 篇品牌/竞品内容
- [ ] D10 深度内容可作为系列连载

## 第 7 步：输出关键词矩阵（Excel + Markdown）

### 7.1 Excel 生成（分模式）

根据第 1 步用户选择的目标路径，使用不同命令生成 Excel：

**A) 全流程模式：**
```bash
python3 scripts/export_xlsx.py keywords_data.json 关键词矩阵.xlsx --stage <账号阶段> --brand <品牌名> --mode full
```

**B) 关键词矩阵模式：**
```bash
python3 scripts/export_xlsx.py keywords_data.json 关键词矩阵.xlsx --stage <账号阶段> --brand <品牌名> --mode keywords
```

**C) 竞品分析模式：**
```bash
python3 scripts/export_xlsx.py keywords_data.json 竞品分析.xlsx --stage <账号阶段> --brand <品牌名> --mode competitive
```

**--stage 参数必须传入**（新号起号期 / 成长期 / 成熟期），否则部署策略 Sheet 内容为空。
**--mode 参数**控制输出哪些内容：

| 模式 | Sheet 1 | Sheet 2 | Sheet 3 |
|------|---------|---------|---------|
| full | 维度汇总 | 关键词矩阵（10 维全） | 部署策略（含优先级/清单/日历） |
| keywords | 维度汇总 | 关键词矩阵（10 维全） | 部署策略（含优先级/清单/日历） |
| competitive | 竞品维度汇总 | 仅 D7 竞品拦截词矩阵 | 竞品对标分析策略 |
