Xiaohongshu Keyword-Planungs-Tool. 10‑dimensionale Keyword-Matrix + Suchvolumen‑Verifizierung + Kontenphasen‑Deployment. Nachdem der Nutzer eine Branche/Kategorie angegeben hat, kann der komplette Workflow ausgeführt werden (Keyword → Audit → Wettbewerber → Deploy‑Strategie) oder nur die Keyword-Matrix bzw. nur die Wettbewerber‑Keyword‑Analyse durchgeführt werden. Gibt eine strukturierte Keyword-Matrix mit Suchverifizierung (sowohl im Excel‑ als auch im Markdown‑Format) aus, ergänzt durch Suchintention, Suchvolumen, Strategiebewertung, Kontenzuweisung und Deploy‑Strategie. Trigger-Wörter: Xiaohongshu‑Keyword, Keyword‑Planung, Xiaohongshu‑SEO‑Keyword, Keyword‑Matrix, Xiaohongshu‑Wortbibliothek, Xiaohongshu‑Suchbegriffe.
