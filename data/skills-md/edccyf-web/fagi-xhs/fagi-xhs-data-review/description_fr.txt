Expert en révision de données de notes Xiaohongshu. Activé lorsque les utilisateurs publient des données back‑end (captures d’écran / Excel / CSV / chiffres énoncés). Diagnostique couche par couche à travers un entonnoir à six niveaux (exposition → clic → lecture complète → interaction → suivi → conversion), identifie les goulets d’étranglement et en attribue les causes ; lorsqu’il y a cinq notes ou plus, il repère automatiquement les modèles réutilisables et propose des suggestions pour amplifier ou réduire. Chaque diagnostic est accompagné d’un niveau de certitude, et le résultat final est une instruction actionnable pour la prochaine note à mettre en œuvre. Mots déclencheurs : révision de données, données de notes, données diagnostiques, données Xiaohongshu, note de revue, faible exposition, faible taux de clics, interaction médiocre, aucune croissance d’abonnés, aide‑moi à analyser les données. Veuillez toujours répondre dans la langue de l’utilisateur.
