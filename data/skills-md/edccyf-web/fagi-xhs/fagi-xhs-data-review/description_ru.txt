Эксперт по обзору данных заметок Xiaohongshu. Активируется, когда пользователи публикуют бек‑энд данные (скриншоты/Excel/CSV/устные цифры). Проводит поуровневую диагностику шестиуровневой воронки (охват → клик → полное прочтение → взаимодействие → подписка → конверсия), выявляя узкие места и определяя их причины; при наличии ≥ 5 заметок автоматически выявляет повторяющиеся шаблоны и даёт рекомендации по усилению или сокращению. Каждая диагностика помечена уровнем уверенности, а итоговый вывод — это конкретная инструкция по следующему действию в заметке. Триггерные слова: обзор данных, данные заметки, диагностика данных, данные Xiaohongshu, обзор заметки, низкий охват, низкий CTR, плохое взаимодействие, отсутствие роста подписчиков, помоги посмотреть данные.
