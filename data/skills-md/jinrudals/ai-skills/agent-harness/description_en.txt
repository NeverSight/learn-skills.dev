Designs a harness for a project — a team of specialist agents plus the skills each agent follows — from a one-sentence domain description. Use when the user asks to "build a harness for this project", "design an agent team", "set up an automation system for <domain>", or wants to restructure/extend an existing harness. Also use for maintenance requests on an existing harness: "audit the harness", "check harness status", "sync agents and skills". Use the `agent-harness-evolve` skill for retrospectives and feedback-driven improvement of a harness that is already running. Works with any coding agent that can delegate work to a subagent — it does not assume any single vendor's orchestration API.
