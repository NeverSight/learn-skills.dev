Создаёт каркас для проекта — команду специализированных агентов плюс навыки, которыми каждый агент владеет — на основе однострочного описания области. Используется, когда пользователь просит «build a harness for this project», «design an agent team», «set up an automation system for <domain>» или хочет реорганизовать/расширить существующий каркас. Также применяется для запросов обслуживания существующего каркаса: «audit the harness», «check harness status», «sync agents and skills». Используйте навык `agent-harness-evolve` для ретроспектив и улучшения каркаса на основе обратной связи, когда он уже работает. Работает с любым кодирующим агентом, который может делегировать работу субагенту — не предполагает использование API оркестрации от какого‑то одного поставщика.  

Пожалуйста, всегда отвечайте на языке пользователя.
