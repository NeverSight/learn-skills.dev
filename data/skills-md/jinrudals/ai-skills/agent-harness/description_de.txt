Entwirft ein Harness für ein Projekt — ein Team von Fachagenten plus die Fähigkeiten, denen jeder Agent folgt — aus einer ein‑Satz‑Domänenbeschreibung. Verwenden Sie es, wenn der Benutzer bittet, „ein Harness für dieses Projekt zu bauen“, „ein Agententeam zu designen“, „ein Automatisierungssystem für <Domäne> einzurichten“ oder ein bestehendes Harness umstrukturieren/erweitern möchte. Auch für Wartungsanfragen zu einem bestehenden Harness verwenden: „Harness auditieren“, „Harness‑Status prüfen“, „Agenten und Fähigkeiten synchronisieren“. Verwenden Sie die `agent-harness-evolve`‑Fähigkeit für Retrospektiven und feedbackgesteuerte Verbesserungen eines bereits laufenden Harness. Funktioniert mit jedem Programmier‑Agent, der Arbeit an einen Sub‑Agent delegieren kann – es wird keine einzelne Anbieter‑Orchestrierungs‑API vorausgesetzt.

Bitte immer in der Sprache des Benutzers antworten.
