프로젝트용 하네스를 설계합니다 — 전문 에이전트 팀과 각 에이전트가 수행할 기술을 한 문장의 도메인 설명에서 도출합니다. 사용자는 “이 프로젝트에 대한 하네스를 구축해 주세요”, “에이전트 팀을 설계해 주세요”, “<도메인>에 대한 자동화 시스템을 설정해 주세요”와 같이 요청하거나 기존 하네스를 재구성/확장하고 싶을 때 사용합니다. 또한 기존 하네스에 대한 유지보수 요청, 예를 들어 “하네스 감사를 해 주세요”, “하네스 상태를 확인해 주세요”, “에이전트와 기술을 동기화해 주세요”와 같은 경우에도 사용합니다. 실행 중인 하네스를 회고하고 피드백 기반으로 개선하기 위해서는 `agent-harness-evolve` 스킬을 활용합니다. 작업을 하위 에이전트에 위임할 수 있는 모든 코딩 에이전트와 호환되며, 특정 벤더의 오케스트레이션 API에 의존하지 않습니다.
