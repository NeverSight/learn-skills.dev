Conçoit un harnais pour un projet — une équipe d’agents spécialistes plus les compétences que chaque agent suit — à partir d’une description de domaine en une phrase. À utiliser lorsque l’utilisateur demande de « construire un harnais pour ce projet », « concevoir une équipe d’agents », « mettre en place un système d’automatisation pour <domaine> », ou souhaite restructurer/étendre un harnais existant. À utiliser également pour les demandes de maintenance sur un harnais existant : « auditer le harnais », « vérifier l’état du harnais », « synchroniser les agents et les compétences ». Utilisez la compétence `agent-harness-evolve` pour les rétrospectives et l’amélioration guidée par les retours d’un harnais déjà en fonctionnement. Fonctionne avec tout agent de codage capable de déléguer le travail à un sous‑agent — il ne repose sur aucune API d’orchestration propre à un fournisseur.  

Veuillez toujours répondre dans la langue de l’utilisateur.
