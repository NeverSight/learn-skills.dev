Diseña un arnés para un proyecto — un equipo de agentes especializados más las habilidades que sigue cada agente — a partir de una descripción de dominio de una sola frase. Úsalo cuando el usuario solicite “construir un arnés para este proyecto”, “diseñar un equipo de agentes”, “configurar un sistema de automatización para <dominio>”, o quiera reestructurar/ampliar un arnés existente. También se emplea para solicitudes de mantenimiento de un arnés existente: “auditar el arnés”, “verificar el estado del arnés”, “sincronizar agentes y habilidades”. Utiliza la habilidad `agent-harness-evolve` para retrospectivas y mejoras impulsadas por retroalimentación de un arnés que ya está en funcionamiento. Funciona con cualquier agente de codificación que pueda delegar trabajo a un subagente — no asume la API de orquestación de ningún proveedor único.
