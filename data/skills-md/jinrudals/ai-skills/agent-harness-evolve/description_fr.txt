Compétence d’évolution du harnais. Collecte et généralise les retours sur les résultats d’un harnais en cours d’exécution, les reflète dans les agents/compétences/l’orchestrateur, et met à jour le journal des modifications en capturant le delta par rapport à la configuration originale du harnais. Utilisez toujours cette compétence pour les demandes d’amélioration basées sur le suivi d’un harnais existant — « rétrospecter le harnais », « faire évoluer le harnais », « incorporer ce retour dans le harnais », « améliorer le harnais », « les résultats étaient décevants, corrigez le harnais », « appliquer ce retour au harnais », « résumer les leçons apprises du harnais ». Concevoir un nouveau harnais, redessiner sa structure ou ajouter des agents relève de la compétence `agent-harness`, pas de celle-ci.

Veuillez toujours répondre dans la langue de l’utilisateur.
