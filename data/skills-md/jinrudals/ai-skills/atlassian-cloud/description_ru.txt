Используйте для работы с Atlassian Cloud — Jira Cloud, Confluence Cloud (지라/컨플루언스 클라우드) — когда сервер MCP не настроен. Охватывает полный CRUD (включая удаление) для задач/страниц, поиск JQL/CQL, вложения и макросы Confluence любого типа (встроенные или установленные из Marketplace), всё через прямые REST‑вызовы без сторонних зависимостей. Триггерные слова — Jira, Confluence, Atlassian Cloud, atlassian.net, JQL, CQL, PROJ‑123, macro, attachment, 지라, 컨플루언스, 아틀라시안 클라우드, 매크로, 첨부파일. Для работы с Bitbucket Cloud используйте отдельный навык bitbucket‑cloud. Пожалуйста, всегда отвечайте на языке пользователя.
