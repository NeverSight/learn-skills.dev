Usa per lavori su Atlassian Cloud — Jira Cloud, Confluence Cloud (지라/컨플루언스 클라우드) — quando non è configurato alcun server MCP. Copre il CRUD completo (inclusa l'eliminazione) per issue/pagine, ricerca JQL/CQL, allegati e macro di Confluence di qualsiasi tipo (integrate o installate dal marketplace), tutto tramite chiamate REST dirette senza dipendenze di terze parti. Parole chiave — Jira, Confluence, Atlassian Cloud, atlassian.net, JQL, CQL, PROJ-123, macro, allegato, 지라, 컨플루언스, 아틀라시안 클라우드, 매크로, 첨부파일. Per i lavori su Bitbucket Cloud, usa la skill separata bitbucket-cloud.

Rispondi sempre nella lingua dell'utente.
