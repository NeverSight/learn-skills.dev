Utilisez pour le travail sur Atlassian Cloud — Jira Cloud, Confluence Cloud (지라/컨플루언스 클라우드) — lorsqu'aucun serveur MCP n'est configuré. Couvre l'intégralité des opérations CRUD (y compris la suppression) pour les tickets/pages, les recherches JQL/CQL, les pièces jointes, et les macros Confluence de tout type (intégrées ou installées depuis la marketplace), le tout via des appels REST directs sans aucune dépendance tierce. Mots déclencheurs — Jira, Confluence, Atlassian Cloud, atlassian.net, JQL, CQL, PROJ-123, macro, attachment, 지라, 컨플루언스, 아틀라시안 클라우드, 매크로, 첨부파일. Pour le travail sur Bitbucket Cloud, utilisez la compétence bitbucket-cloud séparée à la place.
