Проверка позиций по запросу через API DataForSEO SERP. Получает актуальные органические позиции Google для домена по произвольному списку ключевых слов. Отмечает каждую как выигрышную / первая страница / близкую / не ранжируемую, указывая одну приоритетную следующую рекомендацию для каждого ключевого слова.
