Planifie le port d’une application GitHub existante vers une application Cursor Origin. À utiliser lorsque la tâche consiste à transférer une application GitHub vers Origin ou à comparer ce qu’elle utilise avec l’API Origin. Lit les besoins de l’application à partir de son code, les mappe sur la spécification Origin en direct et rédige un briefing de portage avec des retours pour Cursor. Phase de planification uniquement.
