Planifie le port d'une application GitHub existante vers une application Cursor Origin. À utiliser lorsque la tâche consiste à amener une application GitHub à Origin ou à comparer ce qu'elle utilise avec l'API Origin. Lit les besoins de l'application à partir de son code, les mappe sur la spécification Origin en direct et rédige un brief de portage avec des commentaires pour Cursor. Planification uniquement.
