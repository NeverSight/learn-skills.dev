Créer des commits git selon les conventions du projet — analyser, scinder, mettre en scène, rédiger le message. Utilisez‑le lorsque l’utilisateur demande de committer, de valider les changements ou dit « commit and MR » pour l’étape de commit. Chargez avant de mettre en scène ou de committer quoi que ce soit.

Veuillez toujours répondre dans la langue de l’utilisateur.
