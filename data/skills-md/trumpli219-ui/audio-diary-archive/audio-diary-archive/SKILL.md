# 音频日记归档

## 触发条件

在已进入本技能的对话中发送 `1`，或提到「归档音频/录音」「整理录音」「音频归档」时执行。

仅支持 Windows。优先执行本技能目录下的 `scripts/archive.ps1`；安装不会自动归档或清理文件。

数字快捷指令：`1` 归档，`2` 自检，`3` 请求清理（仍需确认具体文件）。

## WorkBuddy / Codex / Claude Code 执行方式

- 使用当前加载的本技能目录作为基准，定位 `scripts/archive.ps1` 和 `scripts/config.txt`。不要假设技能在当前工作目录，也不要硬编码 `.workbuddy`、`.codebuddy` 或某台电脑的安装路径。
- 本地 Windows 会话才能执行归档。若当前为云端会话、macOS 或无法访问用户的录音设备，说明缺少的本地环境，不报告归档成功。
- 首次运行先读取配置，确认用户的目标目录，再用当前工具提供的本地命令执行能力运行 PowerShell 脚本。带空格的脚本绝对路径须加引号；在 PowerShell 中可使用 `& "实际技能目录\scripts\archive.ps1"`。
- 若用户仅要求安装或检查技能是否加载，只检查文件可读性，不启动归档或清理。
- 脚本执行受 WorkBuddy 或其他宿主的权限控制；需要批准时使用宿主的批准流程，不修改系统策略来绕过限制。

## 路径（首次使用前必须确认）

- 源目录：U盘里的 `RECORDER` 文件夹（盘符会变，**必须自动探测**，见下）
- 目标根目录：学员自己的音频日记库目录（**首次使用先问用户，将路径写入本技能的 `scripts/config.txt`；不要猜测目标盘符**）
- 文件名格式：`Note-YYYYMMDDHHMMSS.mp3`

## 盘符自动探测（重要）

U盘盘符不固定（实测会在 `E:` / `H:` 间变化）。**所有涉及 U盘的步骤
（扫描/复制/删除/弹出）都必须先自动探测盘符**，不要硬编码：

```powershell
$usb = $null; $usbLetter = $null
foreach ($l in @("E:","F:","G:","H:","I:","J:","K:","L:")) {
    if (Test-Path "$l\RECORDER") { $usb = "$l\RECORDER"; $usbLetter = $l.TrimEnd(':'); break }
}
if (-not $usb) { Write-Output "未找到U盘RECORDER文件夹"; exit }
```

后续用 `$usb` 作为源路径，`$usbLetter` 作为弹出盘符。

## 执行流程

### 1. 扫描源文件

```
Get-ChildItem "$usb\*.mp3"
```

- 若无文件，报告「没有待归档的音频文件」并结束
- 有文件则按文件名中的日期分组

### 2. 创建目标文件夹

从文件名提取年月日（`Note-YYYYMMDDHHMMSS.mp3` → `YYYY年M月\D日`），
在目标根目录下创建对应文件夹（不存在才创建）。

用 `cmd /c "mkdir <路径>"` 创建（避免 PowerShell 中文编码问题）。

### 3. 复制文件

将每个 mp3 **复制**（非移动）到对应日期文件夹，保留原文件名不变。

用 `cmd /c "copy"` 执行，源文件为权威版本（目标已存在同名则覆盖）。

### 4. 校验

复制完成后逐文件校验：
- 目标文件是否存在
- 目标文件大小与源文件是否一致
- 文件名日期与所在文件夹是否匹配（跨日错放检查）

### 5. 报告

输出：归档文件数、按日期分组明细、校验是否通过、源文件保留情况。

### 6. 清理源文件（可选，需用户确认）

用户确认后，删除 U盘上已归档的文件：

1. 逐文件对比：源文件名在目标目录中是否存在且大小一致
2. 只删除本地确认有副本的文件
3. **不删除**本地无对应副本的文件
4. 删除成功后**自动弹出U盘**（见步骤 7）

触发词：「删除U盘文件」「清理U盘」「确认删除源文件」

⚠️ U盘删除不进回收站，务必在用户明确确认后执行。
若删除被系统策略拦截，停止并说明原因，不提供绕过策略或删除全部 mp3 的命令。只可对已逐项校验且经用户确认的文件执行清理。

### 7. 自动弹出U盘

删除 U盘文件成功后，**自动弹出（安全移除）U盘**：

```powershell
$shell = New-Object -comObject Shell.Application
$item = $shell.Namespace(17).ParseName($usbLetter + ":")
if ($item) { $item.InvokeVerb("Eject") }
```

判定成功：执行后 `Test-Path "$usb"` 返回 False。
若因文件仍被占用弹出失败，提示稍候重试（重新执行步骤 7），不强制反复重试。

## 注意事项

- 归档始终用**复制**而非移动，确保源文件安全
- 文件夹创建用 `cmd /c "mkdir"`，文件操作用 `cmd /c "copy"`（避免中文路径编码问题）
- 复制后必须校验文件大小一致性
- 清理源文件前必须逐文件对比确认本地副本完整
- U盘删除不进回收站，需用户明确确认
- 删除成功后必须自动弹出U盘（步骤 7）
- 所有 U盘操作使用探测到的盘符，不硬编码盘符
- 文件名日期提取用 `Note-(\d{4})(\d{2})(\d{2})\d{6}\.mp3`
