Describe pages that do not exist yet as structured text blueprints agents can implement directly — a directory tree mirroring routes, per-page YAML layout trees whose nodes are real shadcn/ui (or other declared library) component names, navigation actions, and dialog/sheet/drawer behavior. Use for a new app, a new module or batch of pages in an existing app, or a major restructuring of page layout or flow, when the user wants a text prototype, low-fidelity wireframe, or "what goes where" description before building UI; also for greybox previews and for checking a fresh implementation against its blueprint. Not for incremental changes to pages that already exist in code, visual branding, pixel mockups, or design-tool files.
