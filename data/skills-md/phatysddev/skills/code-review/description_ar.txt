راجع تغيّر تنفيذ واحد مقابل مهمّته Phat، ومواصفات الميزة، ومعايير القبول، ومعايير هندسة المستودع، وأي دليل نموذج أولي مقبول. في الوضع المستقل أو النهائي، سجّل دليل/حالة المهمة المدعومة؛ وفي الوضع المفوض، قدّم تقريرًا للقراءة فقط للجهة الأصلية. استخدم ذلك بعد تنفيذ المهمة أو عند مراجعة شجرة العمل أو التغيّر المرحلي أو الالتزام أو الفرع. يرجى دائمًا الرد بلغة المستخدم.
