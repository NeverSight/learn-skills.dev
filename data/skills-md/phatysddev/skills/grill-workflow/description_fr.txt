Clarifier le produit, le domaine, la portée, les contraintes, les règles métier et les décisions technologiques grâce à des ensembles de questions dépendants. Lire d'abord le référentiel, poser toutes les questions utiles dont les prérequis sont déjà connus dans chaque ensemble, et utiliser les réponses pour former les ensembles suivants. Utiliser lorsque le projet ou la fonctionnalité est ambigu et n'est pas prêt pour la spécification. Lorsque les décisions sont stables, recommander exactement une prochaine compétence sans l'invoquer.

Veuillez toujours répondre dans la langue de l'utilisateur.
