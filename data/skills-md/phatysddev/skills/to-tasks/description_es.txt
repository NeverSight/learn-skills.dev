Descompón una especificación de funcionalidad lista en tareas pequeñas, listas para implementar y estructuradas como rebanadas verticales, con cobertura completa de criterios de aceptación, dependencias explícitas, contexto preparado para la sesión y verificación concreta. Úsalo cuando una especificación lista sea demasiado amplia para una única sesión de implementación enfocada o necesite ítems de trabajo duraderos para la implementación y revisión.
