À utiliser lorsque l'utilisateur a besoin de comprendre la structure du code source existant, de localiser les implémentations fonctionnelles, de tracer les chaînes d'appels/flux de données et d'évaluer les points de refactorisation. Scénarios déclencheurs : lecture du code source, revue de code, compréhension du fonctionnement du code, localisation de l'implémentation des fonctionnalités, analyse des chaînes d'appels, analyse des flux de données, revue d'architecture, lecture de rapport, aperçu du système, analyse pré‑refactorisation.
