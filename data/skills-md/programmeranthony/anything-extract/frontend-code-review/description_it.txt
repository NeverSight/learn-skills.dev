Guida la revisione della struttura, della manutenibilità, delle prestazioni e della coerenza del codice frontend (ad esempio, Next.js, React, TypeScript, Tailwind) in un progetto, sulla base di un elenco di controllo delle regole stabilito. Applicabile alle revisioni richieste dagli utenti di file .tsx, .ts, .js, .jsx o di pagine e componenti all'interno della directory frontend. Non destinato al codice backend (ad esempio, .py).
