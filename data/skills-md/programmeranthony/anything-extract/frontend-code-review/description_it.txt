Guida per la revisione della struttura, della manutenibilità, delle prestazioni e della coerenza del codice front-end (Next.js/React/TypeScript/Tailwind, ecc.) all'interno di un progetto, sulla base di un insieme di regole stabilito. Applicabile alle richieste degli utenti di rivedere file front-end .tsx/.ts/.js/.jsx o pagine e componenti all'interno della directory front-end. Non destinato al codice back-end (ad esempio, .py).
