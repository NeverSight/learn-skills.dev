Orientación para revisar la estructura, la capacidad de mantenimiento, el rendimiento y la coherencia del código front-end (Next.js/React/TypeScript/Tailwind, etc.) dentro de un proyecto, en función de un conjunto de reglas establecido. Aplicable a las solicitudes de los usuarios para revisar archivos o páginas de front-end .tsx/.ts/.js/.jsx y componentes dentro del directorio de front-end. No está destinado al código back-end (por ejemplo, .py).
