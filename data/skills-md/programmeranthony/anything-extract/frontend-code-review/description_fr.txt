Guider l'examen du code frontend (par exemple, Next.js, React, TypeScript, Tailwind) dans un projet pour en vérifier la structure, la maintenabilité, les performances et la cohérence, sur la base d'une liste de contrôle de règles établie. Applicable aux demandes des utilisateurs visant à examiner les fichiers ou les pages et composants .tsx, .ts, .js, .jsx dans le répertoire frontend. Non destiné au code backend (par exemple, .py).
