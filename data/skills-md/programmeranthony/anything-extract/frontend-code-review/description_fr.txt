Conseils pour examiner la structure, la maintenabilité, les performances et la cohérence du code front-end (Next.js/React/TypeScript/Tailwind, etc.) au sein d'un projet, sur la base d'un ensemble de règles établies. Applicable aux demandes des utilisateurs visant à examiner les fichiers frontaux .tsx/.ts/.js/.jsx ou les pages et composants du répertoire frontal. Non destiné au code back‑end (par exemple, .py).
