Compétence pour éliminer les expressions qui donnent une « odeur d'IA » aux textes coréens générés par l'IA et les peaufiner afin qu'ils sonnent naturellement comme s'ils avaient été écrits par un humain. Doit être utilisée chaque fois que l'utilisateur mentionne des termes tels que « humaniseur coréen », « éliminer l'odeur d'IA », « écrire comme une personne », « polir naturellement », « corriger le ton de la traduction », « enlever l'odeur d'IA coréenne », « humaniser le coréen », etc. Elle s'applique à tous les textes coréens générés par l'IA destinés aux médias externes (e‑mail, LinkedIn, blogs, scripts YouTube, newsletters, copies marketing). L'objectif est d'affiner l'expression sans changer le sens. La sortie doit être un document Markdown avec deux sections : texte corrigé sous `Humanized` et `Major Changes (jusqu'à 5)`. Ne pas l'utiliser pour les textes anglais, les simples corrections de fautes de frappe, les mémos internes/documentation technique/documents juridiques.

Veuillez toujours répondre dans la langue de l'utilisateur.
