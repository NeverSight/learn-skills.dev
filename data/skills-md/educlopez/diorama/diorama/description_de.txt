Erstelle kleine animierte 3D‑Welten für das Web (isometrische Kamera, Blöcke auf einer abgerundeten Basis, weiche Schatten, kleine Fahrzeuge und sich bewegende Personen) in einem von sechs einstellbaren Themen: Toy (pastellfarbene Blöcke, warme Sonne), Soft, Mono (ein Akzent, der Rest Tönungen von Tinte), Line (eine hauchdünne Zeichnung, weiße Füllungen und Tintenkanten, bei Bedarf von Hand), Print (flache Töne und Tinte, eine gedruckte Illustration) und Night. Eine Hero‑Szene für eine Landing‑Page, eine kartengroße Illustration für Dokumentationen oder einen Blog, oder eine Mini‑Figur für jede kleine Stelle (ein leerer Zustand, ein Feature in einer Liste, ein 404). Verwende dies, wann immer jemand nach einer 3D‑Illustration, einer isometrischen Szene, einer Low‑Poly‑ oder „Toy‑Town“-Animation, einer monochromen oder Line‑Art‑3D‑Figur, einer handgezeichneten oder skizzierten Figur eines Objekts mit ein wenig Leben, einer leeren/blanken‑Zustands‑Illustration, einer Illustration, die auf Hover oder Tap reagiert, einer kleinen spielähnlichen SVG‑Welt fragt, selbst wenn nie „3D“ oder „isometrisch“ gesagt wird. Liefert eine eigenständige HTML‑Datei, die SVG ohne Abhängigkeiten rendert (kein three.js, kein WebGL, kein Canvas), in einem Headless‑Browser geprüft wird und in React eingefügt werden kann. Für texturiertes Terrain, artikulierte Erzähl‑Szenen oder einen Pixel‑Finish verwende die separate Fähigkeit diorama‑worlds; für ditherte Pixel‑Art‑Miniaturen ohne three.js verwende diorama‑pixel.
