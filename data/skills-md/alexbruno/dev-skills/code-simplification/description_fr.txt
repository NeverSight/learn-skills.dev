Simplifier le code pour le rendre plus lisible, plus clair et plus direct pour les humains, sans modifier son comportement. Utilisez cette compétence après avoir implémenté une fonctionnalité, lors d’un remaniement ou lorsque vous répondez aux commentaires d’une revue de code, en particulier lorsque le code semble sur-conçu, profondément imbriqué ou qu’il prend des détours inutiles pour effectuer des tâches simples.
