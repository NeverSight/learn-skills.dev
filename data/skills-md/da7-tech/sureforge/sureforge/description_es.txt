Flujo de trabajo de control de calidad para tareas complejas de varios pasos que necesitan investigación, aclaración, un plan verificable, revisión independiente y entrega respaldada por evidencia. Úselo para implementaciones sustanciales, estudios de decisiones, entregables de múltiples archivos y comprobaciones visuales o de documentos exhaustivas, o cuando el usuario solicite explícitamente usar SureForge. Reduzca la escala para tareas pequeñas; no lo active automáticamente para preguntas casuales, búsquedas simples o ediciones triviales.
