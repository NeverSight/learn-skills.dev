Creare, convertire, leggere e modificare documenti Office localmente con la riga di comando di IeumOffice. Costruire una nuova presentazione (pptx) a partire da un brief tramite una scaletta verificata, specifiche per pagina e pipeline di rendering, un nuovo foglio elettronico (xlsx) da dati CSV o JSON con formule, un nuovo documento Word (docx) da Markdown o HTML, un documento Hangul (hwp / hwpx) o un PDF; convertire tra pdf, docx, odt, xlsx, pptx, md, html e csv, e un PDF in Markdown o EPUB; leggere la struttura e il testo di un file esistente (inclusi i propri docx / odt / xlsx / pptx / pdf / hwp dell'utente come materiale di origine) e applicare modifiche strutturate, documenti Hangul inclusi; leggere pagine PDF scansionate con IA e tradurre un intero PDF in un PDF tradotto, Markdown o EPUB, oppure un libro EPUB in un EPUB tradotto o bilingue. Utilizzare ogni volta che l'utente richiede un deck di slide, una presentazione, un foglio di calcolo, una cartella di lavoro, un report, un documento Word o qualsiasi file Office reale, una conversione di formato, una riscrittura di parte di un documento esistente, o desidera il risultato aperto nell'editor di IeumOffice. I documenti sono elaborati localmente; solo ricerca, immagine, media, read‑url, pdf ai‑read, pdf translate e epub translate inviano dati fuori dalla macchina (read‑url invia l’indirizzo fornito al sito; gli altri inviano al provider configurato in IeumOffice). Si prega di rispondere sempre nella lingua dell'utente.
