Erstellen, konvertieren, lesen und bearbeiten Sie Office‑Dokumente lokal mit der Befehlszeile von IeumOffice. Erstellen Sie eine neue Präsentation (pptx) aus einem Briefing über ein geprüftes Outline, per‑Seiten‑Spezifikation und Render‑Pipeline, eine neue Tabellenkalkulation (xlsx) aus CSV‑ oder JSON‑Daten mit Formeln, ein neues Word‑Dokument (docx) aus Markdown oder HTML, ein Hangul‑Dokument (hwp / hwpx) oder ein PDF; konvertieren Sie zwischen pdf, docx, odt, xlsx, pptx, md, html und csv sowie ein PDF zu Markdown oder EPUB; lesen Sie die Struktur und den Text einer bestehenden Datei (einschließlich der eigenen docx / odt / xlsx / pptx / pdf / hwp des Benutzers als Quellmaterial) und wenden Sie strukturierte Änderungen darauf an, Hangul‑Dokumente eingeschlossen; lesen Sie gescannte PDF‑Seiten mit KI und übersetzen ein ganzes PDF in ein übersetztes PDF, Markdown oder EPUB, oder ein EPUB‑Buch in ein übersetztes oder zweisprachiges EPUB. Verwenden Sie dies immer, wenn der Nutzer nach einem Slide‑Deck, einer Präsentation, einer Tabellenkalkulation, einer Arbeitsmappe, einem Bericht, einem Word‑Dokument oder irgendeiner echten Office‑Datei, einer Formatkonvertierung, einer Umschreibung eines Teils eines vorhandenen Dokuments fragt oder das Ergebnis im IeumOffice‑Editor geöffnet haben möchte. Dokumente werden lokal verarbeitet; nur Suche, Bild, Medien, read‑url, pdf‑ai‑read, pdf‑translate und epub‑translate senden Daten vom Rechner weg (read‑url sendet die übergebene Adresse an die entsprechende Seite; der Rest sendet an den in IeumOffice konfigurierten Anbieter).

Bitte antworten Sie immer in der Sprache des Benutzers.
