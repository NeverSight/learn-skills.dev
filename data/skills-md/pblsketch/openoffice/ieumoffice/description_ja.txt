IeumOffice のコマンドラインを使用して、Office 文書をローカルで作成、変換、読み取り、編集できます。チェック済みのアウトライン、ページごとの仕様、レンダーパイプラインを経てブリーフから新しいプレゼンテーション（pptx）を作成したり、CSV や JSON データと数式から新しいスプレッドシート（xlsx）を作成したり、Markdown や HTML から新しい Word 文書（docx）を作成したり、ハングル文書（hwp / hwpx）や PDF を作成したりできます。pdf、docx、odt、xlsx、pptx、md、html、csv 間の相互変換や、PDF を Markdown または EPUB に変換することも可能です。既存ファイル（ユーザー自身の docx / odt / xlsx / pptx / pdf / hwp も含む）の構造とテキストを読み取り、構造化された編集を適用できます（ハングル文書も対象）。AI を使用してスキャンされた PDF ページを読み取り、PDF 全体を翻訳 PDF、Markdown、または EPUB に変換したり、EPUB 書籍を翻訳版やバイリンガル版の EPUB に変換したりできます。スライドデッキ、プレゼンテーション、スプレッドシート、ワークブック、レポート、Word 文書、または実際の Office ファイルが必要なとき、フォーマット変換や既存文書の一部の書き換えが必要なとき、結果を IeumOffice エディタで開きたいときに使用してください。文書はローカルで処理されます。データが外部に送信されるのは、検索、画像、メディア、read‑url、pdf ai‑read、pdf translate、epub translate のみです（read‑url は指定されたアドレスをそのサイトへ送信し、残りは IeumOffice に設定されたプロバイダーへ送信します）。
