使用 IeumOffice 的命令列在本機建立、轉換、閱讀與編輯 Office 文件。從簡報說明書透過檢查過的大綱、每頁規格與渲染管線建立新的簡報 (pptx)，從 CSV 或 JSON 資料（含公式）建立新的試算表 (xlsx)，從 Markdown 或 HTML 建立新的 Word 文件 (docx)，建立韓文文件 (hwp / hwpx) 或 PDF；在 pdf、docx、odt、xlsx、pptx、md、html 與 csv 之間互相轉換，並支援 PDF 轉 Markdown 或 EPUB；讀取現有檔案的結構與文字（包括使用者自己的 docx / odt / xlsx / pptx / pdf / hwp 作為來源素材），對其套用結構化編輯，亦支援韓文文件；使用 AI 讀取掃描的 PDF 頁面，將整本 PDF 翻譯成已翻譯的 PDF、Markdown 或 EPUB，或將 EPUB 書籍翻譯成翻譯版或雙語版 EPUB。當使用者要求投影片檔、簡報、試算表、工作簿、報告、Word 文件或任何正式的 Office 檔案、格式轉換、對現有文件的部份重寫，或希望結果在 IeumOffice 編輯器中開啟時，都可使用此功能。文件皆在本機處理；只有搜尋、影像、媒體、read‑url、pdf ai‑read、pdf translate 與 epub translate 會將資料傳出機器（read‑url 會將提供的網址傳送至該網站；其餘則傳送至 IeumOffice 設定的提供者）。
