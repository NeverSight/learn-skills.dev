创建、转换、读取并本地编辑 Office 文档，使用 IeumOffice 的命令行。通过已检查的大纲、逐页规格和渲染管线，从简报构建新的演示文稿（pptx），从 CSV 或 JSON 数据及公式创建新的电子表格（xlsx），从 Markdown 或 HTML 创建新的 Word 文档（docx），或创建 Hangul 文档（hwp / hwpx）或 PDF；在 pdf、docx、odt、xlsx、pptx、md、html 和 csv 之间进行转换，PDF 转 Markdown 或 EPUB；读取现有文件的结构和文本（包括用户自己的 docx / odt / xlsx / pptx / pdf / hwp 作为源材料），并对其执行结构化编辑，Hangul 文档亦在支持范围内；使用 AI 读取扫描的 PDF 页面，并将整个 PDF 翻译成翻译后的 PDF、Markdown 或 EPUB，或将 EPUB 书籍翻译成翻译版或双语版 EPUB。每当用户需要幻灯片、演示文稿、电子表格、工作簿、报告、Word 文档或任何真实的 Office 文件、格式转换、对现有文档部分进行改写，或希望在 IeumOffice 编辑器中打开结果时，都可使用本功能。文档在本地处理；仅搜索、图像、媒体、读取 URL、PDF AI 阅读、PDF 翻译和 EPUB 翻译会将数据发送出机器（read‑url 将给定的地址发送到对应站点；其余会发送至 IeumOffice 配置的提供商）。
