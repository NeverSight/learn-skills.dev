Créez, convertissez, lisez et modifiez des documents Office localement avec la ligne de commande d’IeumOffice. Construisez une nouvelle présentation (pptx) à partir d’un brief via un plan vérifié, une spécification page par page et un pipeline de rendu, une nouvelle feuille de calcul (xlsx) à partir de données CSV ou JSON avec des formules, un nouveau document Word (docx) à partir de Markdown ou HTML, un document Hangul (hwp / hwpx) ou un PDF ; convertissez entre pdf, docx, odt, xlsx, pptx, md, html et csv, ainsi qu’un PDF en Markdown ou EPUB ; lisez la structure et le texte d’un fichier existant (y compris les propres docx / odt / xlsx / pptx / pdf / hwp de l’utilisateur comme matériau source) et appliquez‑lui des modifications structurées, documents Hangul inclus ; lisez les pages PDF scannées avec l’IA et traduisez un PDF complet en PDF traduit, Markdown ou EPUB, ou un livre EPUB en EPUB traduit ou bilingue. Utilisez‑le chaque fois que l’utilisateur demande un diaporama, une présentation, une feuille de calcul, un classeur, un rapport, un document Word ou tout autre vrai fichier Office, une conversion de format, une réécriture d’une partie d’un document existant, ou souhaite que le résultat soit ouvert dans l’éditeur IeumOffice. Les documents sont traités localement ; seules les fonctions recherche, image, média, read‑url, pdf ai‑read, pdf translate et epub translate envoient des données hors de la machine (read‑url envoie l’adresse qui lui est fournie à ce site ; les autres envoient les données au fournisseur configuré dans IeumOffice).
