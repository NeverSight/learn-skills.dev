Crea, convierte, lee y edita documentos de Office localmente con la línea de comandos de IeumOffice. Construye una nueva presentación (pptx) a partir de un brief mediante un esquema revisado, especificaciones por página y pipeline de renderizado; una nueva hoja de cálculo (xlsx) a partir de datos CSV o JSON con fórmulas; un nuevo documento Word (docx) a partir de Markdown o HTML; un documento Hangul (hwp / hwpx) o un PDF; convierte entre pdf, docx, odt, xlsx, pptx, md, html y csv, y un PDF a Markdown o EPUB; lee la estructura y el texto de un archivo existente (incluyendo los propios docx / odt / xlsx / pptx / pdf / hwp del usuario como material fuente) y aplica ediciones estructuradas, incluidos los documentos Hangul; lee páginas PDF escaneadas con IA y traduce un PDF completo a un PDF traducido, Markdown o EPUB, o un libro EPUB a un EPUB traducido o bilingüe. Úsalo siempre cuando el usuario solicite una presentación de diapositivas, presentación, hoja de cálculo, cuaderno, informe, documento Word o cualquier archivo real de Office, una conversión de formato, una reescritura de parte de un documento existente, o quiera que el resultado se abra en el editor de IeumOffice. Los documentos se procesan localmente; solo búsqueda, imagen, multimedia, read‑url, pdf ai‑read, pdf translate y epub translate envían datos fuera de la máquina (read‑url envía la dirección que se le da a ese sitio; el resto envía al proveedor configurado en IeumOffice).
