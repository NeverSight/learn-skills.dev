Utilice SymPy para probar o refutar una identidad algebraica de autoría propia, una derivada, un límite, un signo estático comparativo o una forma cerrada. Utilícelo cuando la manipulación simbólica exacta pueda resolver el reclamo. Para barridos de parámetros o demostración de teoremas completos, use $numical-check o $lean-check.
