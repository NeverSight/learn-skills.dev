Photo location identification (look at the image to find the place / internet tracing / image search / infer shooting time). Given one or several photos, first use a single command to complete metadata extraction, OCR, reverse image search (intake.py), record clues and candidates onto a candidate board (board.py) which the script ranks and provides the next step; use clues.py for lookup table clues; satellite images and street views are both "machine sorts first, human looks only at the top few" (sat_scan.py, match.py); each conclusion is checked against real data, output coordinates + error radius, evidence image, and tiered confidence. Geolocate or chronolocate a photo with tool‑verified reasoning — EXIF, OCR, reverse image search (Baidu/Yandex), lookup tables (plates, area codes, calling codes, driving side, territories), candidate board with likelihood ranking, sun and shadow math, OSM Overpass, CLIP‑ranked satellite scan, DINOv2+SIFT‑ranked street view matching, DEM skyline rendering. Use when the user shares a photo and asks 这是哪 / 在哪拍的 / 帮我定位这张照片 / 网络迷踪 / 几点拍的 / where was this taken / geolocate this.
