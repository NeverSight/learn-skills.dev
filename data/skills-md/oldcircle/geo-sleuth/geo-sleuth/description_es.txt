Identificación de la ubicación de una foto (mirar la imagen para encontrar el lugar / rastreo en internet / búsqueda de imágenes / inferir la hora de disparo). Dada una o varias fotos, primero usa un solo comando para completar la extracción de metadatos, OCR, búsqueda inversa de imágenes (intake.py), registra pistas y candidatos en un tablero de candidatos (board.py) que el script clasifica y proporciona el siguiente paso; usa clues.py para pistas de tablas de consulta; las imágenes satelitales y vistas de calle son ambas “la máquina ordena primero, el humano mira solo las primeras” (sat_scan.py, match.py); cada conclusión se verifica contra datos reales, se devuelven coordenadas + radio de error, imagen de evidencia y confianza por niveles. Geolocaliza o cronolocaliza una foto con razonamiento verificado por herramientas — EXIF, OCR, búsqueda inversa de imágenes (Baidu/Yandex), tablas de consulta (matrículas, códigos de área, códigos de marcación, lado de conducción, territorios), tablero de candidatos con ranking de probabilidad, cálculo de sol y sombra, OSM Overpass, escaneo satelital clasificado por CLIP, coincidencia de vista de calle clasificada por DINOv2+SIFT, renderizado de horizonte DEM. Úsalo cuando el usuario comparta una foto y pregunte 这是哪 / 在哪拍的 / 帮我定位这张照片 / 网络迷踪 / 几点拍的 / where was this taken / geolocate this.

Por favor, siempre responde en el idioma del usuario.
