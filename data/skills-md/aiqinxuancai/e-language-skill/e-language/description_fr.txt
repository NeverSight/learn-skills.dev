Guide complet de développement de projets Easy Language (EPL/易语言) pour comprendre, générer, éditer, réviser, déboguer, compiler et migrer les projets .e/.ec ainsi que leurs espaces de travail texte non empaquetés. À utiliser lors du travail avec la syntaxe 易语言, les points d’entrée du programme (_启动子程序 / _启动窗口), la vérification de la console de sortie standard, e‑packager src/*.txt ou XML de fenêtre, outils AutoLinker MCP, configurations de construction de projet AutoLinker, compilation en ligne de commande sans interface d’AutoLinker de fichiers .e arbitraires sur disque, assemblages/classes/sous‑routines, modules et bibliothèques de support, compilation BlackMoon/黑月, classes/interfaces BlackMoon/黑月, mise en page Masonry, ressources RC, interface utilisateur Win32 en code pur, composants/événements Windows, déclarations DLL, types de données personnalisés, rappels de méthodes de classe et trampolines de rappel x86 dynamiques, fenêtres à plusieurs couches, dessin GDI/GDI+, code inséré ou code machine x86/assembleur intégré, erreurs de compilation ou conversions entre 易语言 et d’autres langages.
