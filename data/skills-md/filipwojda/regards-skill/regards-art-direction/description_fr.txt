Direction artistique pour les sites web à partir de recherches en direct sur regards.design, un index sélectionné à la main de sections de sites réels, recherchables par apparence. Un dérivé de tasteskill v2 (MIT, Leonxlnx) qui conserve son inventaire, test d’idée, images en collection ouverte, inspecteur de navigateur réel et boucle de visualisation‑et‑correction, et remplace le lot de 20 directions fixes par une recherche de vraies sections pour ce brief unique. Utilisez‑le chaque fois que vous concevez, reconcevez, restylez, peaufinez ou examinez une page d’atterrissage, un site marketing, un portfolio, une page produit, une page unique, une page d’accueil ou toute page web publique, quel que soit le stack, et lorsque l’utilisateur dit qu’une page semble générique, templatisée, « AI‑made » ou comme toutes les autres. Nécessite le serveur MCP de regards.design pour l’étape de recherche. Pas pour les tableaux de bord ou les écrans d’application.
