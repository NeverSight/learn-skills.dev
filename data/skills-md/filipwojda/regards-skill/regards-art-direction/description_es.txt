Dirección de arte para sitios web a partir de investigación en vivo en regards.design, un índice seleccionado manualmente de secciones reales de sitios web buscables por apariencia. Un fork de tasteskill v2 (MIT, Leonxlnx) que mantiene su inventario, prueba de ideas, imágenes de colección abierta, inspector de navegador real y bucle de observar‑y‑corregir, y reemplaza el conjunto de 20 direcciones fijas con una búsqueda de secciones reales para este breve objetivo. Úsalo siempre que diseñes, rediseñes, replantees, pulas o revises una página de aterrizaje, sitio de marketing, portafolio, página de producto, one‑pager, hero o cualquier página web de cara al público, en cualquier stack, y cuando el usuario diga que una página se ve genérica, plantillada, “hecha por IA” o como cualquier otro sitio. Necesita el servidor MCP de regards.design para el paso de investigación. No es para paneles de control ni pantallas de aplicaciones.
