Créez une action de soumission personnalisée pour le widget Formulaire d’Elementor Pro (envoi vers un CRM, publication sur un webhook, écriture dans une table personnalisée, déclenchement d’un effet secondaire). À utiliser lorsque l’utilisateur souhaite ajouter une nouvelle action « Après soumission » aux formulaires d’Elementor Pro.

Veuillez toujours répondre dans la langue de l’utilisateur.
