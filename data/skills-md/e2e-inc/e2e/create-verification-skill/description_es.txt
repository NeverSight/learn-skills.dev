Genera una<app> habilidad de verificación local del proyecto sobre e2e, para que cualquier agente de codificación pueda iniciar la aplicación, comprobar que vale la pena conducirla, ejercer una función de la forma en que lo hace un usuario, mantener pruebas y corregir errores. Escribe la habilidad, un mapa de funciones con una carta de exploración por función, y lo demuestra una vez. Usar para /create-verification-skill, "hacer una habilidad de verificación para este repositorio", o cuando un proyecto no tiene una forma programada de probar el comportamiento de la interfaz de usuario.
