Generieren Sie eine projektlokale<app> Verifizierungsfähigkeit zusätzlich zu e2e, damit jeder Codierungsagent die App starten, überprüfen kann, ob es sich lohnt zu fahren, eine Funktion so ausüben kann, wie es ein Benutzer tut, Beweise aufbewahren und Fehler beheben kann. Schreibt die Fertigkeit, eine Feature-Karte mit einer Erkundungs-Charta pro Feature, und beweist sie einmal. Verwenden Sie für /create-verification-skill, "make a verification skill for this repo" oder wenn ein Projekt keine skriptbasierte Möglichkeit hat, das Verhalten der Benutzeroberfläche nachzuweisen.
