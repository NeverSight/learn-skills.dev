Operare worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser incorporato di Orca tramite la CLI `orca`. Utilizzarla quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferirla rispetto a un semplice git worktree, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Usare Computer Use solo per finestre esterne o interfacce desktop che richiedono controllo a livello di sistema operativo, e Playwright o CDP per pagine esterne.
