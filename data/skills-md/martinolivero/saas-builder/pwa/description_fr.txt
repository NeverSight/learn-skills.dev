Cette compétence doit être utilisée lorsqu’on transforme une application web en Progressive Web App — la rendre installable, fonctionner hors ligne, mettre en cache les ressources ou envoyer des notifications push. Les phrases déclenchantes incluent « make it a PWA », « installable app », « work offline », « offline mode », « service worker », « web push », « push notifications », « add to home screen », « app manifest », « cache assets », « make it feel like a native app ». Elle configure vite-plugin-pwa avec la bonne stratégie de mise en cache et évite le piège du service worker obsolète.

Veuillez toujours répondre dans la langue de l'utilisateur.
