Pushes the current branch, waits for the whole CI pipeline, then fixes every failing job and every valid pull request review comment (from people or review bots) locally as one batch, pushes once, replies to each review thread and resolves the ones its fixes address, and repeats until CI is green with no open threads it can settle. GitHub and GitHub Actions are the worked adapter; other providers need their commands in the settings. Use when the user asks to "fix CI", "get CI green", "get the checks passing", "wait for CI and fix it", "address the review comments" or "resolve the PR comments" on the current branch. Not for reviewing someone else's PR (use your review process) or for an independent second review (second-opinion-review).
