WeChat Work PPT capability. Three types of functions: (1) Create PPT — generate an online presentation based on a topic, outline, document, or reference material; (2) Edit online PPT; (3) Import PPT — import a local .ppt/.pptx as a WeChat Work online document. Creation and editing always operate on WeChat Work online slide documents, delivered as online document links. When the user mentions phrases such as “make a PPT,” “generate a presentation,” “write a report PPT,” “convert this document to PPT,” “make a few pages following this template,” “change the title on slide 3,” “replace the chart data on this slide,” “add a summary slide,” “change the cover color scheme,” “import PPT,” or provides a local .ppt/.pptx to be imported, this capability is triggered. Any page‑level modifications added after a PPT has already been generated in this session (e.g., “add an image to slide 2,” “reorder these slides”) also go through this capability. If the task is only to read/parse the content of a local PPT file (without editing), use wecomcli‑media instead.
