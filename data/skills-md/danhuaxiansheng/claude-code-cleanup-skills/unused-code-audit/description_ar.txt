أثبت ما إذا كان الدليل أو الملف أو الرمز المصدر أو الدالة أو المكوّن أو الثابت أو الخطاف أو النوع أو المساعد المعطى «ليس له مستهلكون حقيقيون»، ثم قرّر ما إذا كان ينبغي حذفه. يُستَخدم ذلك لتنظيف الكود الميت، واكتشاف الكود غير المستعمل، وتدقيق الصادرات غير المستخدمة، وفحوصات أمان الحذف، والبحث عن المستهلكين؛ أجب فقط بخصوص علاقات الاستهلاك وسلامة الحذف، دون الحكم ما إذا كان الشيء «ما زال يُستَخدم لكنه ضروري». بالنسبة لمثل هذه الأسئلة، استخدم necessary‑code‑audit.
