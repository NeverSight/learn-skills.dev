تحقَّق مما إذا كان الدليل أو الملف أو الرمز المُصدَّر أو الدالة أو المكوِّن أو الثابت أو الـ hook أو النوع أو المساعد لا يمتلك «مستهلكين حقيقيين»، ثم قرّر ما إذا كان يجب حذفه. يُستخدم ذلك لتنظيف الكود الميت، واكتشاف الكود غير المُستَعمَل، وتدقيق الصادرات غير المستخدمة، وفحص سلامة الحذف، والبحث عن المستهلكين؛ قدِّم إجابة فقط بخصوص علاقات الاستهلاك وسلامة الحذف، ولا تقيم ما إذا كان شيء لا يزال مُستَعمَلًا ضروريًا. لهذه الأسئلة استخدم تدقيق الكود الضروري.

يرجى دائمًا الرد بلغة المستخدم.
