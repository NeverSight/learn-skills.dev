Prove whether a given directory, file, exported symbol, function, component, constant, hook, type, or helper has “no real consumers,” then decide whether to delete it. This is used for dead‑code cleanup, unused‑code detection, unused‑export auditing, deletion safety checks, and consumer searching; only answer regarding consumption relationships and deletion safety, without judging whether something “is still used but necessary.” For such questions, use necessary‑code‑audit.
