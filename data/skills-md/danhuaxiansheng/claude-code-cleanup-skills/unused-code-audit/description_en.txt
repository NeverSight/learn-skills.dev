Prove whether a directory, file, exported symbol, function, component, constant, hook, type, or helper has “no real consumers”, and then decide whether to delete it. It is used for dead‑code cleanup, unused‑code detection, unused‑export audit, deletion safety checks, and consumer search; only answer regarding consumption relationships and deletion safety, and do not assess whether something that is still used is necessary. For such questions use necessary‑code‑audit.
