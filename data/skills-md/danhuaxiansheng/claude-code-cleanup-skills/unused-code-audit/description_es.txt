Demuestre si un directorio, archivo, símbolo exportado, función, componente, constante, gancho, tipo o ayudante determinado no tiene "consumidores reales" y luego decida si desea eliminarlo. Esto se utiliza para la limpieza decódigo muerto, la detección de código no utilizado, la auditoría de exportación no utilizada, los controles de seguridad de eliminación y la búsqueda de consumidores; solo responda con respecto a las relaciones de consumo y la seguridad de eliminación, sin juzgar si algo "todavía se usa pero es necesario." Para tales preguntas, use la auditoría de código necesaria.
