Demuestra si un directorio, archivo, símbolo exportado, función, componente, constante, hook, tipo o helper “no tiene consumidores reales”, y luego decide si eliminarlo. Se utiliza para la limpieza de código muerto, detección de código no usado, auditoría de exportaciones no utilizadas, verificaciones de seguridad al eliminar y búsqueda de consumidores; responde únicamente sobre las relaciones de consumo y la seguridad de la eliminación, y no evalúes si algo que todavía se usa es necesario. Para esas preguntas utiliza auditoría‑de‑código‑necesario.
