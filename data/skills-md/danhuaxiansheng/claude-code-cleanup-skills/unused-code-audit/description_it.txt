Dimostra se una directory, un file, un simbolo esportato, una funzione, un componente, una costante, un hook, un tipo o un helper non ha “veri consumatori”, e poi decidi se eliminarlo. Viene usato per la pulizia del codice morto, la rilevazione di codice inutilizzato, l’audit di esportazioni inutilizzate, i controlli di sicurezza dell'eliminazione e la ricerca di consumatori; rispondi solo riguardo alle relazioni di consumo e alla sicurezza dell'eliminazione, e non valutare se qualcosa che è ancora in uso è necessario. Per tali domande usa necessary‑code‑audit.

Rispondi sempre nella lingua dell'utente.
