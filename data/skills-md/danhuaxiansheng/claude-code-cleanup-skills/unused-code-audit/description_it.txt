Dimostra se una directory, file, simbolo esportato, funzione, componente, costante, hook, tipo o helper “non ha consumatori reali”, poi decidi se eliminarlo. Questo è utilizzato per la pulizia del codice morto, il rilevamento del codice inutilizzato, l’audit delle esportazioni inutilizzate, i controlli di sicurezza dell’eliminazione e la ricerca dei consumatori; rispondi solo riguardo alle relazioni di consumo e alla sicurezza dell’eliminazione, senza giudicare se qualcosa “è ancora usato ma necessario”. Per tali domande, usa **necessary‑code‑audit**.
