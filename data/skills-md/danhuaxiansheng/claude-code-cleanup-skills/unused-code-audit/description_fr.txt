Montrez si un répertoire, un fichier, un symbole exporté, une fonction, un composant, une constante, un hook, un type ou un helper n’a « aucun vrai consommateur », puis décidez s’il faut le supprimer. Cela sert au nettoyage du code mort, à la détection du code inutilisé, à l’audit des exportations inutilisées, aux vérifications de sécurité de la suppression et à la recherche de consommateurs ; répondez uniquement concernant les relations de consommation et la sécurité de la suppression, et n’évaluez pas si quelque chose qui est encore utilisé est nécessaire. Pour ces questions, utilisez l’audit de code nécessaire. Veuillez toujours répondre dans la langue de l'utilisateur.
