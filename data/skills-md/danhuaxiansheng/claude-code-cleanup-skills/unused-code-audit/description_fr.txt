Prouvez si un répertoire, un fichier, un symbole exporté, une fonction, un composant, une constante, un crochet, un type ou un assistant n'a « aucun consommateur réel », puis décidez de le supprimer ou non. Ceci est utilisé pour le nettoyage decode mort, la détection de code inutilisé, l'audit d'exportation inutilisé, les contrôles de sécurité de suppression et la recherche de consommateurs ; ne répondez qu'en ce qui concerne les relations de consommation et la sécurité de suppression, sans juger si quelque chose est toujours utilisé mais nécessaire. » Pour de telles questions, utilisez le code‑audit nécessaire.
