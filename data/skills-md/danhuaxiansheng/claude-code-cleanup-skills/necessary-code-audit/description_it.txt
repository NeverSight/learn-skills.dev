Verifica se il “codice ancora in uso da parte dei consumatori” deve realmente rimanere, concentrandoti su wrapper/facciate, strati di compatibilità, API pubbliche obsolete, rami difensivi, fallback, valori predefiniti, configurazione, sorgenti duplicate e punti di estensione speculativi. Usalo per codice che è utilizzato ma non è sufficientemente necessario, pulizia della compatibilità legacy, wrapper privi di senso, rimozione di codice difensivo, pulizia senza requisiti di compatibilità, verifiche approfondite della necessità e richieste del tipo “questo deve ancora esistere?”; non considerarlo uno strumento di verifica puro di codice inutilizzato/morto. Per favore rispondi sempre nella lingua dell'utente.
