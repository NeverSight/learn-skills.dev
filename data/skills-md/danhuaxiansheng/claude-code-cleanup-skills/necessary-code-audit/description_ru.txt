Аудировать, действительно ли «код, который всё ещё имеет потребителей», необходимо сохранять, сосредотачиваясь на обёртках/фасадах, слоях совместимости, устаревших публичных API, защитных ветках, резервных вариантах, значениях по умолчанию, конфигурациях, дублирующих источниках и гипотетических точках расширения. Применять это к коду, который уже используется, но не является достаточно необходимым, к очистке устаревшей совместимости, бессмысленным обёрткам, удалению защитного кода, очистке без требований к совместимости, глубокой проверке необходимости и запросам типа «нужно ли это всё ещё здесь?». Не рассматривать его как чистый инструмент проверки неиспользуемого/мертвого кода.
