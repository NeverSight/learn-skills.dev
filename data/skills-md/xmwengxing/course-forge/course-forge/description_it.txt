Trasforma documenti di conoscenza o script parlati in corsi/materiali interattivi—pianifica capitoli di sommario, scrivi ed espandi lo script parlato, calcola le ore di lezione; il materiale comprende una fase di presentazione (canvas) + navigazione dei capitoli del sommario + sottotitoli + audio + controlli di riproduzione/pausa/schermo intero + barra di avanzamento del capitolo. Il contenuto di ogni schermata viene rivelato passo passo, include animazione, almeno un’interazione ogni tre schermate, il testo puro è proibito, la narrazione è allineata con visuali/sottotitoli/audio. Processo: avvio del progetto (confermare le ore totali di lezione/durata per sessione) → scrittura dello script (per corsi estesi, procedere dall’avvio → i sub‑agent creano gli script dei capitoli → workflow di design visivo, il testo dello script descrive animazione e interazione) → allineare simultaneamente cinque elementi (script/sommario/tema/asset/modalità di sviluppo) → sviluppare pagine web capitolo per capitolo (capitolo 1 come ancoraggio) → audio TTS opzionale → distribuzione/inserimento (registrazione video opzionale). Le animazioni di default sono animejs + CSS/SVG/Canvas; visuali avanzate possono essere ottenute tramite caricamento progressive‑disclosure di competenze correlate al design o MCP. Questa competenza consolida una metodologia di design + processo di collaborazione, non è vincolata a nessuno stile e può essere riutilizzata per qualsiasi argomento.
