Превращайте документы знаний или устные сценарии в интерактивные курсы/учебные материалы — планируйте главы‑контуры, пишите и расширяйте устный сценарий, рассчитывайте количество учебных часов; учебный материал включает этап презентации (canvas) + навигацию по главам‑контуров + субтитры + аудио + кнопки воспроизведения/паузы/полноэкранного режима + индикатор прогресса главы. Содержание каждого экрана раскрывается постепенно, включает анимацию, минимум одно взаимодействие каждые три экрана, чистый текст запрещён, озвучка согласуется с визуалом/субтитрами/аудио. Процесс: запуск проекта (подтверждение количества учебных часов/длительности одного занятия) → написание сценария (для крупных курсов можно следовать запуску → суб‑агенты создают скрипты глав → рабочий процесс визуального дизайна, текст сценария описывает анимацию и взаимодействие) → согласование пяти элементов одновременно (сценарий/контур/тема/ресурсы/режим разработки) → разработка веб‑страниц глава за главой (глава 1 как якорь) → при желании TTS‑аудио → внедрение/встраивание (видеозапись опциональна). По умолчанию анимации реализуются через animejs + CSS/SVG/Canvas; продвинутые визуалы могут использовать прогрессивное раскрытие для загрузки навыков типа design‑type или MCP. Этот навык оформляет методологию дизайна + workflow сотрудничества, не привязан к какому‑либо стилю и может быть переиспользован для любой темы.
