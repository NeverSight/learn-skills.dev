Verwandle Wissensdokumente oder Voice‑Over‑Skripte in interaktive Kurse/Kursmaterial – plane Gliederungs‑Kapitel, erstelle und erweitere das Voice‑Over‑Skript, berechne die Unterrichtsstunden; das Kursmaterial beinhaltet eine Präsentations‑Stufe (Canvas) + Gliederungs‑Kapitel‑Navigation + Untertitel + Audio + Play/Pause‑/Vollbild‑Steuerung + Kapitel‑Fortschrittsbalken. Der Inhalt jeder Seite wird Schritt für Schritt enthüllt, enthält Animationen, mindestens eine Interaktion pro drei Seiten, reiner Text ist verboten, und das Voice‑Over ist auf die Visuals/Untertitel/Audio abgestimmt. Prozess: Projektstart (Gesamtunterrichtsstunden / Dauer pro Unterrichtseinheit bestätigen) → Voice‑Over‑Skript schreiben (bei großen Kursen über den Start → Sub‑Agent erstellt Kapitel‑für‑Kapitel‑Skripte → visueller Designprozess, Skripttext beschreibt Animation und Interaktion) → gleichzeitig fünf Elemente ausrichten (Skript / Gliederung / Thema / Assets / Entwicklungsmodus) → Webseite Kapitel für Kapitel entwickeln (Kapitel 1 als Anker) → optionales TTS‑Audio → Bereitstellung/Einbettung (Video‑Aufnahme optional). Animationen verwenden standardmäßig animejs + CSS/SVG/Canvas; fortgeschrittene Visuals können progressiv über Design‑Klassen‑Fähigkeiten oder MCP geladen werden. Diese Fähigkeit fasst Design‑Methodik + Kollaborations‑Workflow zusammen, ist an keinen Stil gebunden und kann für jedes Thema wiederverwendet werden.
