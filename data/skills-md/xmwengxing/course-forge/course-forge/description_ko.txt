지식 문서나 구두 스크립트를 인터랙티브한 강좌·코스웨어로 전환한다—목차 섹션을 계획하고, 구두 스크립트를 작성·확장하며, 수업 시간을 계산한다; 코스웨어는 프레젠테이션 단계(캔버스) + 목차 네비게이션 + 자막 + 오디오 + 재생/일시정지/전체 화면 제어 + 섹션 진행 바를 포함한다. 각 화면의 내용은 단계적으로 표시되고, 애니메이션을 포함하며, 세 화면마다 최소 하나의 인터랙션이 있어야 하고, 순수 텍스트는 금지되며, 내레이션은 시각·자막·오디오와 일치한다. 프로세스: 프로젝트 시작(전체 수업 시간·수업당 시간 확인) → 스크립트 작성(대규모 강좌는 프로젝트 시작 → 하위 에이전트가 챕터 스크립트를 생성 → 시각 디자인 워크플로, 스크립트 텍스트가 애니메이션·인터랙션을 설명) → 다섯 요소를 동시에 정렬(스크립트/목차/테마/자산/개발 모드) → 챕터별 웹 페이지 개발(챕터 1을 앵커로) → 선택적 TTS 오디오 → 배포·임베드(비디오 녹화 선택 가능). 애니메이션은 기본적으로 animejs + CSS/SVG/Canvas를 사용하고, 고급 시각 효과는 단계적으로 공개되는 디자인 관련 스킬 또는 MCP로 구현할 수 있다. 이 스킬은 디자인 방법론·협업 워크플로를 통합하며, 특정 스타일에 얽매이지 않고 모든 주제에 재활용 가능하다.
