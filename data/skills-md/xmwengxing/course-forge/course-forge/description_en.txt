Turn knowledge documents or voice scripts into interactive courses/courseware—plan outline sections, write and expand voice scripts, calculate class hours; the courseware includes a presentation stage (canvas) + outline section navigation + subtitles + audio + play/pause/full‑screen controls + chapter progress bar. Each screen’s content is revealed step by step, includes animation, at least one interaction per three screens, pure text is prohibited, voice narration aligns with visuals/subtitles/audio. Process: project initiation (confirm total class hours/duration per class) → voice script writing (large courses can proceed from initiation → sub‑agents produce chapter scripts → visual design process, script text describes animation and interaction) → align five items at once (script/outline/theme/materials/development mode) → develop web pages chapter by chapter (chapter 1 as anchor) → optional TTS audio → deployment/embedding (video recording optional). Animations default to animejs + CSS/SVG/Canvas; advanced visuals can be achieved through progressive disclosure loading design‑type skill or MCP. This skill encapsulates design methodology + collaboration workflow, is not bound to any style, and can be reused for any theme.
