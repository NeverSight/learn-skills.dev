حوّل مستندات المعرفة أو نصوص التعليق الصوتي إلى دورات/مواد تفاعلية — خطط لأقسام المخطط، واكتب وسّع نصوص التعليق الصوتي، احسب ساعات الصف؛ تشمل المادة مرحلة عرض (Canvas) + تنقل بالمخطط + ترجمات + صوت + أزرار تشغيل/إيقاف/ملء الشاشة + شريط تقدّم القسم. يُكشف محتوى كل شاشة خطوة بخطوة، ويشمل تحريكًا، على الأقل تفاعل واحد لكل ثلاث شاشات، لا نص صافي، ويتطابق التعليق الصوتي مع المرئيات/الترجمات/الصوت. العملية: بدء المشروع (تأكيد إجمالي ساعات الصف / مدة كل صف) → كتابة نص التعليق الصوتي (للدورات الكبيرة: بدء → الوكيل الفرعي يُنشئ نصًا لكل فصل → عملية التصميم البصري، نص السيناريو يصف التحريك والتفاعل) → مواءمة خمس عناصر في آن واحد (النص / المخطط / السمة / الأصول / وضع التطوير) → تطوير صفحات الويب فصلًا فصلاً (الفصل 1 كمرساة) → صوت TTS اختياري → النشر/التضمين (تسجيل الفيديو اختياري). الرسوم المتحركة تكون افتراضيًا بـ animejs + CSS/SVG/Canvas؛ ويمكن تحقيق مرئيات متقدمة عبر تحميل تدريجي لمهارات متعلقة بالتصميم أو MCP. هذه المهارة تُجسد منهجية التصميم + سير عمل التعاون، ولا ترتبط بأي نمط معين، ويمكن إعادة استخدامها لأي موضوع.
