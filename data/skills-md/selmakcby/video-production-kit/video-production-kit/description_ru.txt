Навык редактирования и упаковки YouTube‑видео. Создаёт список нарезок, субтитры (SRT), описание, временные метки глав и контент для социальных сетей из длинной необработанной видеозаписи. Знает, как извлекать аудио из сегментов на таймлайнах CapCut для Mac. Основан на ffmpeg + Whisper Turbo.

ТРИГГЕР для вызова этого навыка:
- пользователь запрашивает транскрипт / субтитры / SRT / список нарезок / описание для YouTube / временную метку главы / X‑thread / подпись для Instagram.
- упоминается CapCut, таймлайн, файл draft_info.json, необработанная запись, редакция видео.
- предоставлен файл .mov / .mp4 и требуется выходной результат.

Пожалуйста, всегда отвечайте на языке пользователя.
