Prove whether one file, function, endpoint, job, flag branch or package is really dead before deleting it. Runs the DEAD checks (Direct callers, Every other way in, Anyone outside, Data from production), checks the story in git history, has a fresh context argue that it's still used, then gives a verdict of DEAD, ALIVE or NOT PROVEN. Deletes only on a DEAD verdict and the user's yes, one item per commit. Use when the user asks "is this dead", "can I delete X", "is X still used", or wants to remove code safely.
