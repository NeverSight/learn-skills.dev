Использовать для «как работает X», обзоров кода перед изменением чего‑либо и вопросов о размещении/владении/уровне («где это должно находиться», «какой пакет это владеет», «это правильный уровень»). Объясняет архитектуру подсистем, поток выполнения, ментальные модели при вводе в курс. Использовать «почему» для мотивации.
