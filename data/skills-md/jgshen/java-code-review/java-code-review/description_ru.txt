Инструмент проверки кода Java, который проверяет стандарты кода на основе Руководства по разработке Java на Alibaba. Он срабатывает, когда пользователь говорит «проверить код», «проверить стандарты кода», «проверка кода», «проверка кода», «стандартная проверка», «проверить этот код», «проверить, соответствует ли этот код стандартам Alibaba» или отправить код Java на проверку. Он подходит для PR-проверок, проверок перед фиксацией или ежедневных проверок кода.
