Java-Code-Überprüfungstool, das Codestandards auf der Grundlage des Java-Entwicklungshandbuchs von Alibaba überprüft. Es wird ausgelöst, wenn der Benutzer „Code überprüfen“, „Codestandards prüfen“, „Codeüberprüfung“, „Codeinspektion“, „Standardüberprüfung“, „Diesen Code überprüfen“, „Überprüfen, ob dieser Code den Alibaba-Standards entspricht“ sagt oder Java-Code zur Überprüfung einreicht. Geeignet für PR-Überprüfungen, Pre-Commit-Prüfungen oder routinemäßige Codeüberprüfungen.
