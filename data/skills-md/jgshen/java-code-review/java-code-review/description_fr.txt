Outil de révision de code Java, basé sur le manuel de développement Java d'Alibaba pour vérifier les normes du code. Il est déclenché lorsque l'utilisateur dit « réviser le code », « vérifier les normes du code », « révision du code », « vérification du code », « révision standard », « réviser ce code », « vérifier si ce code est conforme aux normes Alibaba » ou soumet du code Java pour inspection. Convient pour la révision des relations publiques, les vérifications préalables à l'engagement ou les révisions de code de routine.
