Créez un package de configuration de robot MoveIt Pro (simulé, simulé ou physique) à partir des ressources disponibles (URDF, CAD, STL) et vérifiez qu'il se construit, se lance et se comporte correctement. À utiliser lorsque l'utilisateur souhaite afficher un nouveau robot dans MoveIt Pro, ajouter une couche sim/physique à une configuration existante ou déboguer une configuration qui ne sera pas construite, lancée ou ne se comportera pas correctement.
