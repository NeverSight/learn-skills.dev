Übersetzen Sie Zeichenketten in Xcode-Zeichenkettenkataloge (.xcstrings-Dateien). Verwenden Sie lieber die Fähigkeit "xcode-integration:translation-coordinator" für die Aufgabenkoordination. Verwenden Sie diese Fertigkeit, wenn Sie einzelne Zeichenfolgen übersetzen oder mit Zeichenfolgenkatalogen arbeiten. Sollte nur aktiviert werden, wenn eine einzelne Zeichenkette oder eine kleine Menge bekannter Zeichenkettenschlüssel übersetzt wird. Die Fähigkeit "Übersetzungskoordinator" sollte für alles andere verwendet werden.
