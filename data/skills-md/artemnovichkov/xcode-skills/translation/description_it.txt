Traduci le stringhe nei Cataloghi di Stringhe di Xcode (.xcstrings). È preferibile utilizzare la skill `xcode-integration:translation-coordinator` per il coordinamento dei compiti. Usa questa skill quando traduci stringhe individuali o lavori con i Cataloghi di Stringhe. Deve essere attivata solo quando si traduce una singola stringa o un piccolo gruppo di chiavi di stringa conosciute. La skill `translation-coordinator` dovrebbe essere usata per tutto il resto.

Per favore rispondi sempre nella lingua dell'utente.
