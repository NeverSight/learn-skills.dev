Úsese cuando el diseño de una aplicación debe adaptarse a una ventana que cambia de tamaño mientras la aplicación se ejecuta, o cuando la aplicación debe admitir más de una ventana. Esto incluye que se solicite hacer que la aplicación sea redimensionable o que admita una ventana redimensionable, un diseño que se rompe o no se adapta al cambiar el tamaño de la ventana, y la preparación o optimización de la aplicación para el iPhone Duo plegable, la multitarea en pantalla dividida o Stage Manager. Moderniza la aplicación reemplazando las API heredadas de estado compartido por alternativas adecuadas al contexto: mainScreen, interfaceOrientation, userInterfaceIdiom, el ciclo de vida de la aplicación y de la escena, y los márgenes de área segura.
