アプリのレイアウトが実行中にサイズが変わるウィンドウに適応する必要がある場合、またはアプリが複数ウィンドウをサポートしなければならない場合に使用します。これには、アプリをリサイズ可能にする、またはリサイズ可能なウィンドウをサポートするよう求められるケース、ウィンドウのサイズ変更時にレイアウトが崩れる・適応しないケース、そして折りたたみ式 iPhone Duo、スplit‑screen マルチタスク、Stage Manager に向けてアプリを準備・最適化する場合が含まれます。レガシーな共有状態 API を、コンテキストに適した代替手段（mainScreen、interfaceOrientation、userInterfaceIdiom、application と scene のライフサイクル、safe area inset）に置き換えてアプリをモダナイズします。
