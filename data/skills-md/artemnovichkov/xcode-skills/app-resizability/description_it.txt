Usa quando il layout di un'app deve adattarsi a una finestra che cambia dimensione durante l'esecuzione dell'app, o quando un'app deve supportare più di una finestra. Ciò include richieste di rendere un'app ridimensionabile o di supportare una finestra ridimensionabile, un layout che si rompe o non si adatta quando la finestra viene ridimensionata, e la preparazione o ottimizzazione di un'app per l'iPhone Duo pieghevole, il multitasking split‑screen o Stage Manager. Modernizza l'app sostituendo le API legacy di stato condiviso con alternative contestualmente appropriate: mainScreen, interfaceOrientation, userInterfaceIdiom, ciclo di vita dell'applicazione e della scena, e i margini dell’area sicura.
