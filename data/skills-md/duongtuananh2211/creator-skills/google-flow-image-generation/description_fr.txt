Créer une image avec Google Flow (flow.google.com) via Claude dans Chrome — recevoir le prompt, confirmer le format de l’image (paysage ou portrait), ouvrir le projet Flow déjà configuré (ou créer un nouveau projet et enregistrer l’ID), générer l’image, la télécharger puis déplacer l’image depuis ~/Downloads vers le répertoire du projet. Utiliser cette compétence chaque fois que l’utilisateur veut créer/générer/dessiner une image avec Google Flow, Flow, Imagen ou Nano Banana dans le navigateur, ou dire des phrases comme « créer une image avec Flow », « générer une image pour ce projet », « faire une vignette/image d’illustration avec Flow », « generate an image in Google Flow », même s’il ne fournit qu’un prompt décrivant l’image et mentionne Flow. Ne pas utiliser pour créer des vidéos dans Flow ou créer des images via API/code.
