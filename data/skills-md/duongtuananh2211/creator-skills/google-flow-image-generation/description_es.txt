Crear imágenes con Google Flow (flow.google.com) a través de Claude en Chrome: recibir el prompt, confirmar si el marco de la imagen es horizontal o vertical, abrir el proyecto Flow ya configurado (o crear un proyecto nuevo y guardar el ID), generar la imagen, descargarla y luego mover la imagen desde ~/Downloads a la carpeta del proyecto. Utiliza esta habilidad siempre que el usuario quiera crear/generar/dibujar una imagen con Google Flow, Flow, Imagen o Nano Banana en el navegador, o diga frases como “crear imagen con flow”, “generar imagen para este proyecto”, “hacer miniatura/imagen ilustrativa con Flow”, “generate an image in Google Flow”, incluso cuando solo proporcione un prompt que describa la imagen y mencione Flow. No usar para crear video en Flow ni para generar imágenes mediante API/código.
