Создавать изображения с помощью Google Flow (flow.google.com) через Claude в Chrome — получать prompt, подтверждать горизонтальный или вертикальный формат изображения, открывать настроенный проект Flow (или создавать новый проект и сохранять id), генерировать изображение, загружать его и перемещать файл из ~/Downloads в папку проекта. Использовать этот навык каждый раз, когда пользователь хочет создать/сгенерировать/нарисовать изображение с помощью Google Flow, Flow, Imagen или Nano Banana в браузере, или произнести такие фразы, как «создать изображение с Flow», «сгенерировать изображение для этого проекта», «сделать thumbnail/иллюстрацию с помощью Flow», «generate an image in Google Flow», даже если они лишь предоставляют prompt описания изображения и упоминают Flow. Не использовать для создания видео в Flow или создания изображений через API/код.
