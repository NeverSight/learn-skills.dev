Google Flow (flow.google.com)를 Chrome에서 Claude를 통해 이미지 생성 — 프롬프트를 받아 가로 또는 세로 이미지 프레임을 확인하고, 구성된 Flow 프로젝트를 열거나(또는 새 프로젝트를 만들고 ID를 저장) 이미지를 생성한 뒤 다운로드하고 ~/Downloads에서 프로젝트 폴더로 옮긴다. 사용자가 브라우저에서 Google Flow, Flow, Imagen 또는 Nano Banana로 이미지 생성·그리기를 원할 때마다 또는 “flow로 이미지 만들기”, “이 프로젝트에 이미지 생성”, “Flow로 썸네일·삽화 만들기”, “generate an image in Google Flow”와 같은 문장을 말할 때 이 스킬을 사용한다. 이미지 설명 프롬프트만 제공하고 Flow를 언급하는 경우에도 적용한다. Flow에서 비디오를 만들거나 API·코드로 이미지를 생성하는 데는 사용하지 않는다.
