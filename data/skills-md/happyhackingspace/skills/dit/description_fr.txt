Classifiez les pages HTML, les formulaires et les champs à l’aide de l’apprentissage automatique. Utilisez-le lorsque l’utilisateur doit détecter les types de pages (connexion, erreur, captcha), identifier les types de formulaires (connexion, recherche, inscription) ou classer les champs de formulaire (nom d’utilisateur, mot de passe, e‑mail) à partir du contenu HTML ou des URL.

Veuillez toujours répondre dans la langue de l’utilisateur.
