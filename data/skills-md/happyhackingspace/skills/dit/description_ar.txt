صنّف صفحات HTML والنماذج والحقول باستخدام تعلم الآلة. استخدمه عندما يحتاج المستخدم إلى اكتشاف أنواع الصفحات (تسجيل الدخول، خطأ، كابتشا)، وتحديد أنواع النماذج (تسجيل الدخول، بحث، تسجيل)، أو تصنيف حقول النماذج (اسم المستخدم، كلمة المرور، البريد الإلكتروني) من محتوى HTML أو عناوين URL.

يرجى دائمًا الرد بلغة المستخدم.
