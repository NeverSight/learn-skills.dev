تشغيل شجرات العمل المُدارة بواسطة Orca، وسياقات المجلدات، والمحطات الطرفية، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر سطر الأوامر `orca`. يُستخدم عندما يقول المستخدم "$orca-cli"، "شجرة عمل Orca"، "شجرة عمل فرعية"، "إطلاق codex/claude في شجرة عمل"، "قراءة/انتظار/إرسال محطة Orca"، "تسليم" / "نقل" / "إعطاء هذا إلى وكيل آخر"، "متصفح Orca"، "قطع Orca الفنية"، أو "مشاركة المهارات". يفضَّل هذا على أوامر git العادية، أو PTY مؤقتة، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. يُستَخدم استخدام الحاسوب فقط عندما يتطلب الأمر نافذة مرئية للتحكم في واجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو API القيام بذلك. يرجى دائمًا الرد بلغة المستخدم.
