Converti immagini statiche (diapositive, poster, infografiche) in file PowerPoint modificabili. Pipeline: OCR rileva il testo → la maschera di testo CV classica rileva i pixel d’inchiostro → mask‑clip effettua l’AND con le bbox OCR (preserva le illustrazioni) → LAMA ricostruisce lo sfondo pulito → python‑pptx assembla caselle di testo modificabili con font auto‑scalati e colori rilevati. Attiva su “convert image to pptx”, “make slide editable”, “image to powerpoint”, “extract text from slide as editable”, “reconstruct slide”, o quando l’utente ha un’immagine di diapositiva/poster e vuole un file .pptx modificabile.
