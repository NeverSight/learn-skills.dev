Обратный инжиниринг серверного протокола из игрового клиента (установочный пакет/APK/IPA/EXE или dump.cs, lua, usmap, захват пакетов и т.д.) и создание развертываемого сервера. Включает диспетчеризацию чтения путей, принципиальный слой (примеры: три элемента / протокол пакетов / таблица протокола / исходный код горячего обновления), дорожную карту из четырёх фаз (workflow‑roadmap: статический анализ → создание инструментов + цепочка входа → перенаправление → цикл патчей → итерация манифеста), селектор обратного инжиниринга из 11 методов (включая маршрут «inline‑server»), извлекатель списка интерфейсов (tools/), шаблон спецификации протокола (protocol.spec.yaml), точечное переписывание на уровне проводов (может работать без полной схемы), аудит источника клиентских адресов, трёхосевая система состояния и приёмки, чек‑лист релизных операций, трекер прогресса (TRACKER.md), шаблоны цепочки входа и списка функций. Охватывает: вход в аккаунт и регистрацию, подбор комнат, бой, выпадание лута, гача, пополнение и почту, развертывание (локальное/сервер/Termux/Windows), интеграцию клиента, замкнутую проверку; поддерживает Unity (IL2CPP/Mono/Lua), Unreal (UE4/UE5), Cocos2d‑x/Cocos Creator (JS/Lua hot‑update), C#, AS3, Java, JS и другие клиенты; включает руководство по лайв‑операциям после входа на сервер; и включает подход «inline server» (синтез ответов внутри процесса клиента, синтез объектов во время выполнения и обнаружение полей, повторное использование состояния входа SDK платформы и двухэтапный доступ для каталогового сервера/зонального сервера).
