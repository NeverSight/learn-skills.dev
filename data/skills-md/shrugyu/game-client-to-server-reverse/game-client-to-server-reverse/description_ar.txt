عكس هندسة بروتوكول الخادم من عميل اللعبة (package/APK/IPA/EXE أو dump.cs، lua، usmap، التقاط الحزم، إلخ) وإعادة إنتاج خادم قابل للنشر. يشمل توجيه قراءة المسار، طبقة المبدأ (المقدمة: ثلاثة عناصر / بروتوكول الحزمة / جدول البروتوكول / مصدر التحديث السريع)، خارطة طريق بأربع مراحل (خارطة عمل: تحليل ثابت → بناء الأدوات + سلسلة تسجيل الدخول → إعادة توجيه → حلقة التصحيح → تكرار البيان)، محدد عكس الهندسة بـ 11 طريقة (بما في ذلك مسار الخادم المدمج)، مستخرج بيان الواجهة (tools/)، قالب مواصفات البروتوكول (protocol.spec.yaml)، إعادة كتابة مستهدفة على مستوى السلك (يمكن تشغيلها دون مخطط كامل)، تدقيق مصدر عنوان العميل، نظام حالة وقبول ثلاثي المحاور، قائمة مراجعة عمليات الإصدار، متعقب التقدم (TRACKER.md)، سلسلة تسجيل الدخول وقالب قائمة الميزات. يغطي: تسجيل الدخول/التسجيل للحساب، مطابقة الغرف، القتال، سقوط الغنائم، الجاتشا، الشحن والبريد، النشر (محلي/خادم/Termux/Windows)، تكامل العميل، التحقق ذي الحلقة المغلقة؛ ويدعم Unity (IL2CPP/Mono/Lua)، Unreal (UE4/UE5)، Cocos2d‑x/Cocos Creator (JS/Lua تحديث ساخن)، C#، AS3، Java، JS وغيرها من العملاء؛ يتضمن دليل عمليات مباشر بعد دخول الخادم؛ ويتضمن أيضًا مسار “الخادم المدمج” (توليد الاستجابات داخل عملية العميل، توليد كائنات وقت التشغيل واكتشاف الحقول، إعادة استخدام حالة تسجيل الدخول لتطبيق منصة SDK، وإدخال من مرحلتين لخوادم الدليل/خوادم المنطقة).
