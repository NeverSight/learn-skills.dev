Reverse‑engineer das Serverprotokoll aus dem Spielclient (Installationspaket/APK/IPA/EXE oder dump.cs, lua, usmap, Paketmitschnitt usw.) und reproduziere einen deploybaren Server. Enthält Pfadlesende Dispatch, die Prinzipschicht (Primer: drei Elemente / Paketprotokoll / Protokolltabelle / Hot‑Update‑Quelle), eine vierstufige Roadmap (Workflow‑Roadmap: statische Analyse → Tool‑Erstellung + Login‑Kette → Umleitung → Patch‑Zyklus → Manifest‑Iteration), einen 11‑Methoden‑Reverse‑Engineering‑Selektor (einschließlich einer Inline‑Server‑Route), einen Interface‑Manifest‑Extraktor (tools/), eine Protokoll‑Spezifikation‑Vorlage (protocol.spec.yaml), Wire‑Level‑gezieltes Umschreiben (kann ohne passendes Schema laufen), eine Überprüfung der Client‑Adress‑Quelle, ein Drei‑Achsen‑Status‑ und Akzeptanzsystem, Checklisten für Bereitstellung und Betrieb, Fortschritts‑Checkliste (TRACKER.md), Login‑Kette und Feature‑Listen‑Vorlage. Deckt ab: Konto‑Login/Registrierung, Raum‑Matchmaking, Kampf, Beute‑Drops, Gacha, Aufladung und Mail, Bereitstellung (lokal/Server/Termux/Windows), Client‑Integration, geschlossener‑Kreis‑Verifikation; unterstützt Unity (IL2CPP/Mono/Lua), Unreal (UE4/UE5), Cocos2d‑x/Cocos Creator (JS/Lua Hot‑Update), C#, AS3, Java, JS und andere Clients; enthält ein Handbuch für Live‑Operationen nach Server‑Einstieg; und beinhaltet zudem einen „Inline‑Server“-Ansatz (Synthese von Antworten innerhalb des Client‑Prozesses, Laufzeit‑Objektsynthese und Feldermittlung, Wiederverwendung des Plattform‑SDK‑Login‑Status und zweistufige Zulassung für Verzeichnis‑Server/Zone‑Server).
