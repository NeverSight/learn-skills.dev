게임 클라이언트(설치 파일/APK/IPA/EXE 또는 dump.cs, Lua, usmap, 패킷 캡처 등)에서 서버 프로토콜을 리버스 엔지니어링하고 배포 가능한 서버를 재구성합니다. 읽기 경로 배포, 원리 계층(프라이머: 세 요소 / 패킷 프로토콜 / 프로토콜 테이블 / 핫리로드 소스 코드)을 포함하며, 4단계 로드맵(워크플로우 로드맵: 정적 분석 → 빌드 도구 + 로그인 체인 → 리다이렉션 → 패치 루프 → 매니페스트 반복)을 제공합니다. 11가지 리버스 엔지니어링 방법 선택자(인라인 서버 경로 포함), 인터페이스 목록 추출기(tools/), 프로토콜 명세 템플릿(protocol.spec.yaml), 와이어 레벨 타깃 리라이팅(전체 스키마 없이 실행 가능), 클라이언트 주소 소스 감사, 3축 상태 및 수용 시스템, 배포·운영 체크리스트, 진행 상황 트래커(TRACKER.md), 로그인 체인 및 기능 목록 템플릿을 포함합니다. 계정 로그인/회원가입, 룸 매칭, 전투, 전리품 드랍, 가챠, 충전 및 메일, 배포(로컬/서버/Termux/Windows), 클라이언트 통합, 클로즈드 루프 검증을 다루며, Unity(IL2CPP/Mono/Lua), Unreal(UE4/UE5), Cocos2d‑x/Cocos Creator(JS/Lua 핫업데이트), C#, AS3, Java, JS 등 다양한 클라이언트를 지원합니다. 서버 진입 후 라이브 운영 매뉴얼을 제공하고, “인라인 서버” 경로(클라이언트 프로세스 내에서 응답 합성, 런타임 객체 합성 및 필드 탐색, 플랫폼 SDK 로그인 상태 재사용, 디렉터리 서버/지역 서버에 대한 2단계 입장)를 포함합니다.
