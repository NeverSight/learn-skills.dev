Move running Claude Code sessions in herdr-app (hc) or herdr terminals, on this machine and on the machines hc is connected to, onto the newest installed claude binary. A running process cannot swap its executable, so each stale idle session is exited and resumed with `claude --resume <session>` in the same terminal, keeping the conversation. Dry run first, restart only on the user's go. Use when the user types /herdr-reload, or asks to get their herdr panes / running Claude sessions onto the latest Claude Code version after an update.
