افحص وشغِّل Inngest Cloud من خلال اتصال OAuth MCP الخاص به. استخدمه للتطبيقات والوظائف المنشورة، والعمليات الفاشلة أو البطيئة، والتتبعات، والأحداث، والبيئات، والجلسات، والتجارب، والرؤى. يفضَّل هذا للعمليات السحابية عندما تكون أدوات MCP متاحة؛ استخدم مهارات CLI أو REST للمهام الصريحة في الطرفية أو HTTP.
