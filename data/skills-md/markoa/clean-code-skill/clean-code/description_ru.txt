Стандарты инженерии чистого кода для написания, рефакторинга и рецензирования кода на любом языке программирования. Используйте их всякий раз, когда пользователь просит написать чистый код, следовать принципам чистого кода, провести рефакторинг ради ясности, улучшить названия, уменьшить сложность или дублирование, разделить ответственности, ужесточить обработку ошибок, работать по принципу тест‑первый или заниматься TDD, либо иным образом повысить качество, читаемость и поддерживаемость кода. Применяйте эти правила по умолчанию при создании или изменении кода для пользователя, заботящегося о качестве.

Пожалуйста, всегда отвечайте на языке пользователя.
