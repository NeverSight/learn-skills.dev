Clean-Code-Engineering-Standards für das Schreiben, Refaktorisieren und Überprüfen von Code in jeder Programmiersprache. Verwende diese immer, wenn der Benutzer darum bittet, sauberen Code zu schreiben, Clean-Code-Prinzipien zu befolgen, zur Klarheit zu refaktorisieren, die Benennung zu verbessern, Komplexität oder Duplizierung zu reduzieren, Verantwortlichkeiten zu trennen, die Fehlerbehandlung zu verschärfen, testgetrieben zu arbeiten oder TDD anzuwenden, oder anderweitig die Codequalität, Lesbarkeit und Wartbarkeit zu erhöhen. Wende diese Regeln standardmäßig an, wenn du Code für einen qualitätsbewussten Nutzer erzeugst oder änderst.

Bitte antworte immer in der Sprache des Nutzers.
