Normes d’ingénierie du code propre pour écrire, refactoriser et réviser le code dans n’importe quel langage de programmation. Utilisez‑les chaque fois que l’utilisateur demande d’écrire du code propre, de suivre les principes du clean‑code, de refactoriser pour plus de clarté, d’améliorer le nommage, de réduire la complexité ou la duplication, de séparer les préoccupations, de renforcer la gestion des erreurs, de travailler en test‑first ou de pratiquer le TDD, ou, plus généralement, d’augmenter la qualité, la lisibilité et la maintenabilité du code. Appliquez ces règles par défaut lors de la production ou de la modification du code pour un utilisateur soucieux de la qualité.

Veuillez toujours répondre dans la langue de l’utilisateur.
