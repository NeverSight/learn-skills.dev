Standard di ingegneria del clean‑code per scrivere, rifattorizzare e revisionare il codice in qualsiasi linguaggio di programmazione. Usa questi standard ogni volta che l'utente chiede di scrivere codice pulito, seguire i principi del clean‑code, rifattorizzare per chiarezza, migliorare la denominazione, ridurre la complessità o la duplicazione, separare le preoccupazioni, rafforzare la gestione degli errori, lavorare con approccio test‑first o fare TDD, o altrimenti aumentare la qualità, la leggibilità e la manutenibilità del codice. Applica queste regole di default quando produci o modifichi codice per un utente attento alla qualità.

Rispondi sempre nella lingua dell'utente.
