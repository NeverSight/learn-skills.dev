Utiliza esto en repositorios de código siempre que un agente necesite ejecutar comandos de terminal, inspeccionar archivos, buscar código, ver el estado o los diffs de Git, ejecutar compilaciones, pruebas, linters, verificaciones de tipos, gestores de paquetes, registros, Docker, Kubernetes o comandos de bases de datos. Esta habilidad hace que el agente prefiera los envoltorios RTK para reducir la salida ruidosa de los comandos y ahorrar tokens de contexto. No lo uses para conversaciones que no sean de codificación.

Por favor, responde siempre en el idioma del usuario.
