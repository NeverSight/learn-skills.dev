Utilisez ceci dans les dépôts de code chaque fois qu’un agent doit exécuter des commandes terminal, inspecter des fichiers, rechercher du code, afficher le statut Git ou les diff, lancer des builds, des tests, des linters, des vérifications de type, des gestionnaires de paquets, des journaux, Docker, Kubernetes ou des commandes de base de données. Cette compétence fait que l’agent préfère les wrappers RTK afin de réduire le bruit des sorties de commande et d’économiser des jetons de contexte. Ne pas l’utiliser pour des conversations non‑codées.

Veuillez toujours répondre dans la langue de l’utilisateur.
