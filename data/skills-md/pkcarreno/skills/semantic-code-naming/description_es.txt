Aplica reglas de gramática semántica, nombres basados en la intención y patrones estructurales (como Acción, Alto Contexto, Bajo Contexto o A/HC/LC) a variables, funciones y clases. Utiliza esta habilidad al escribir nuevo código, refactorizar identificadores o revisar código para su legibilidad. No uses esta habilidad para verificaciones de formato, sangrado o linters de mayúsculas/minúsculas.
