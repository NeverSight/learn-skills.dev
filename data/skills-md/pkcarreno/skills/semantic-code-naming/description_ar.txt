تطبيق قواعد النحو الدلالية، وتسمية مستندة إلى النية، والأنماط الهيكلية (مثل الإجراء، السياق العالي، السياق المنخفض أو A/HC/LC) على المتغيّرات، والدوال، والفئات. استخدم هذه المهارة عند كتابة شفرة جديدة، أو إعادة هيكلة المعرفات، أو مراجعة الشفرة لضمان قابليتها للقراءة. لا تستخدم هذه المهارة لفحص التنسيق، أو المسافات البادئة، أو أدوات فحص الأحرف.
