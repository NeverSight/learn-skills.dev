Guide pour écrire un code correct pour le SDK Python de Bright Data. Utilisez toujours cette compétence lorsque vous écrivez, modifiez, déboguez ou examinez du code Python qui utilise le package brightdata-sdk, effectue des importations depuis brightdata ou interagit avec les API de Bright Data. Utilisez-la lorsque l'utilisateur demande d'extraire des données de sites Web, d'effectuer des recherches sur Google/Bing, d'accéder à des ensembles de données ou d'automatiser des navigateurs via Bright Data en Python.
