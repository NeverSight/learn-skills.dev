Utilisez lorsque l'utilisateur veut qu’une URL connue soit renvoyée en tant que contenu : « donne‑moi cette page », lis cet article, cette page en markdown, sauvegarde le HTML brut, prends une capture d’écran de cette page, ou le texte de la page pour un index RAG ou le contexte d’un modèle. Also lorsqu’une simple récupération d’une URL renvoie bloquée ou mise en défi au lieu de la vraie page : un 403 ou un autre code d’erreur, un CAPTCHA, un mur anti‑bots, ou un corps de réponse vide. Enveloppe Bright Data Web Unlocker, de sorte qu’une page bloquée revienne quand même. Ce n’est pas pour enregistrer ou récupérer de nombreuses pages d’un site (utilisez « scrape »), ni pour une requête de recherche sans URL (utilisez « search »), ni pour piloter un navigateur avec votre propre code Playwright, Puppeteer ou Selenium (utilisez « browser »), ni pour les coûts ou crédits (utilisez « billing »), ni pour les échecs d’authentification ou de KYC (utilisez « agent‑onboarding »).
