Используйте, когда пользователь хочет получить одну известную URL‑страницу в виде содержимого: «получите мне эту страницу», прочитайте эту статью, эту страницу в markdown, сохраните сырой HTML, сделайте скриншот этой страницы или извлеките текст страницы для индекса RAG или контекста модели. Также когда простой запрос к URL возвращает блокировку или вызов подтверждения вместо реальной страницы: 403 или другой статус ошибки, CAPTCHA, бот‑защита или пустой ответ. Оборачивает Bright Data Web Unlocker, поэтому заблокированная страница всё равно возвращается. Не предназначено для выгрузки записей или множества страниц с сайта (используйте scrape), не для поискового запроса без URL (используйте search), не для управления браузером с помощью собственного кода Playwright, Puppeteer или Selenium (используйте browser), не для вопросов стоимости или кредитов (используйте billing), не для ошибок аутентификации или KYC (используйте agent‑onboarding).
