Usa quando l'utente desidera un URL noto restituito come contenuto: “prendi questa pagina”, leggi questo articolo, questa pagina in markdown, salva l'HTML grezzo, fai uno screenshot di questa pagina o il testo della pagina per un indice RAG o per il contesto di un modello. Anche quando un semplice fetch di un URL ritorna bloccato o sfidato invece della pagina reale: un 403 o un altro stato di errore, un CAPTCHA, un muro anti‑bot o un corpo vuoto. Utilizza Bright Data Web Unlocker, così una pagina bloccata viene comunque restituita. Non per record o molte pagine di dati da un sito (usa scrape), non per una query di ricerca senza URL (usa search), non per guidare un browser con il tuo codice Playwright, Puppeteer o Selenium (usa browser), non per costi o crediti (usa billing), non per fallimenti di autenticazione o KYC (usa agent‑onboarding).

Per favore rispondi sempre nella lingua dell'utente.
