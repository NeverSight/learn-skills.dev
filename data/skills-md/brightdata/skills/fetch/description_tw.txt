使用情況：使用者想要取得單一已知 URL 的內容，例如「給我這個頁面」或「讀取這篇文章」或「將此頁面以 Markdown 形式呈現」或「儲存原始 HTML」或「截圖此頁面」或「取得頁面文字以供 RAG 索引或模型上下文使用」。也適用於單純抓取 URL 時遭到阻擋或挑戰，未能取得真正的頁面：如 403 或其他錯誤狀態、CAPTCHA、機器人牆，或回傳空白內容。此功能包裝了 Bright Data Web Unlocker，即使頁面被阻擋仍能回傳。**不**用於從站點記錄多頁資料（請使用 scrape），**不**用於沒有 URL 的搜尋查詢（請使用 search），**不**用於自行使用 Playwright、Puppeteer 或 Selenium 程式碼驅動瀏覽器（請使用 browser），**不**用於成本或額度相關問題（請使用 billing），**不**用於驗證或 KYC 失敗（請使用 agent‑onboarding）。
