Úsese cuando el usuario desea que se devuelva el contenido de una URL conocida: “get me this page”, leer este artículo, esta página como markdown, guardar el HTML sin procesar, capturar una captura de pantalla de esta página, o el texto de la página para un índice RAG o el contexto de un modelo. También cuando una solicitud simple a una URL regresa bloqueada o con desafío en lugar de la página real: un 403 u otro código de error, un CAPTCHA, una pared anti‑bot o un cuerpo vacío. Envuelve Bright Data Web Unlocker, por lo que una página bloqueada aún se devuelve. No se trata de registros o de muchas páginas de datos de un sitio (use “scrape”), no es una consulta de búsqueda sin URL (use “search”), no es controlar un navegador con su propio código de Playwright, Puppeteer o Selenium (use “browser”), no es respecto a costos o créditos (use “billing”), ni a fallos de autenticación o KYC (use “agent‑onboarding”).
