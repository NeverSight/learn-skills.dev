当用户想要获取单个已知 URL 的内容时使用：如“给我这个页面”、读取文章、将页面以 Markdown 形式读取、保存原始 HTML、对页面截图，或获取页面文本用于 RAG 索引或模型上下文。同样适用于普通获取 URL 时返回被阻止或受到挑战而不是实际页面的情况：例如 403 或其他错误状态、CAPTCHA、机器人墙，或空的响应体。该功能包装了 Bright Data Web Unlocker，即使页面被阻止也能返回。不要用于从站点获取记录或多页数据（请使用 scrape），不要用于没有 URL 的搜索查询（请使用 search），不要用于自行使用 Playwright、Puppeteer 或 Selenium 编写的浏览器驱动代码（请使用 browser），不要用于费用或信用查询（请使用 billing），不要用于身份验证或 KYC 失败（请使用 agent‑onboarding）。
