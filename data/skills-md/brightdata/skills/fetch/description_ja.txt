ユーザーが特定の URL の内容を取得したいときに使用します：「このページを取得して」、この記事を読む、このページを Markdown で取得、RAW HTML を保存、ページのスクリーンショットを撮る、または RAG インデックスやモデルコンテキスト用のページテキストを取得します。また、URL を単純に取得しようとしてブロックやチャレンジ（403 やその他のエラー、CAPTCHA、ボットウォール、空の本文など）に遭遇した場合にも使用します。Bright Data Web Unlocker をラップしているため、ブロックされたページでも取得できます。サイトから多数のレコードやページデータを取得する場合は「scrape」を、URL のない検索クエリは「search」を、Playwright、Puppeteer、Selenium など自前のコードでブラウザを操作する場合は「browser」を、費用やクレジットに関することは「billing」を、認証や KYC の失敗は「agent-onboarding」を使用してください。
