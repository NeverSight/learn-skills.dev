Le serveur MCP de Bright Data, la couche d'outils qui donne à un agent LLM un accès web en direct sans shell. À utiliser lorsque l’on intègre les outils Bright Data dans une application IA ou un cadre d’agents qui sélectionne ses outils à l’exécution, lors de la connexion de Claude, Cursor ou d’un autre client MCP à Bright Data, lorsqu’on choisit quels outils ou groupes MCP activer, ou lorsque l’utilisateur dit MCP. Couvre le serveur distant hébergé sur mcp.brightdata.com et le paquet auto‑hébergé local @brightdata/mcp, ainsi que l’outil vers lequel chaque tâche doit être dirigée. Ce n’est pas pour l’agent qui exécute la tâche lui‑même depuis un shell, qui est brightdata‑cli. Ce n’est pas pour du code répété fixe dans une application, qui est brightdata‑sdk. Ce n’est pas pour les problèmes d’installation ou d’authentification, qui relèvent de agent‑onboarding.
