El servidor MCP de Bright Data, la capa de herramientas que le brinda a un agente LLM acceso web en tiempo real sin shell. Úselo al integrar las herramientas de Bright Data en una aplicación de IA o marco de agente que seleccione sus herramientas en tiempo de ejecución, al conectar Claude, Cursor u otro cliente MCP a Bright Data, al elegir qué herramientas o grupos MCP activar, o cuando el usuario dice MCP. Cubre el servidor remoto alojado en mcp.brightdata.com y el paquete local autoalojado @brightdata/mcp, y a qué herramienta debe enviarse cada trabajo. No es para el agente que ejecuta el trabajo directamente desde un shell, que es brightdata-cli. No es para código fijo y repetido en una aplicación, que es brightdata-sdk. No es para problemas de instalación o autenticación, que es agent‑onboarding.
