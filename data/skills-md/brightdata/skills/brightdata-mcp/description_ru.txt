Сервер MCP от Bright Data, слой инструментов, предоставляющий агенту LLM живой доступ к вебу без оболочки. Используется при интеграции инструментов Bright Data в AI‑приложение или фреймворк агента, который выбирает инструменты во время выполнения, при подключении Claude, Cursor или другого клиента MCP к Bright Data, при выборе, какие инструменты или группы MCP включить, или когда пользователь говорит «MCP». Охватывает удалённый сервер, размещённый на mcp.brightdata.com, и локальный самохостинговый пакет @brightdata/mcp, а также определяет, к какому инструменту должно быть направлено каждое задание. Не предназначено для агента, выполняющего задание непосредственно из оболочки — это brightdata-cli. Не для фиксированного повторяющегося кода в приложении — это brightdata-sdk. Не для проблем установки или аутентификации — это agent-onboarding.
