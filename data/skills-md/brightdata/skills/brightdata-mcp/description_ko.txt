Bright Data의 MCP 서버는 셸 없이 LLM 에이전트에게 실시간 웹 접근을 제공하는 툴 레이어입니다. Bright Data 도구를 AI 앱이나 런타임에 도구를 선택하는 에이전트 프레임워크에 연결할 때, Claude, Cursor 또는 다른 MCP 클라이언트를 Bright Data에 연결할 때, 어떤 MCP 도구나 그룹을 활성화할지 선택할 때, 혹은 사용자가 “MCP”라고 말할 때 사용합니다. mcp.brightdata.com에 호스팅된 원격 서버와 @brightdata/mcp 패키지로 자체 호스팅하는 로컬 서버, 그리고 각 작업이 라우팅될 도구를 다룹니다. 셸에서 작업을 직접 수행하는 에이전트인 brightdata‑cli용이 아니며, 앱의 고정 반복 코드용인 brightdata‑sdk용도 아닙니다. 설치나 인증 문제에 대한 것은 agent‑onboarding에 해당합니다.
