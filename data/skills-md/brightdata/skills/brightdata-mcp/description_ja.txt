Bright Data の MCP サーバーは、シェルを使わずに LLM エージェントにリアルタイムのウェブアクセスを提供するツール層です。実行時にツールを選択する AI アプリやエージェントフレームワークに Bright Data ツールを組み込むとき、Claude、Cursor、または他の MCP クライアントを Bright Data に接続するとき、どの MCP ツールやグループを有効にするか選択するとき、あるいはユーザーが「MCP」と言ったときに使用します。リモートサーバー（mcp.brightdata.com）とローカルの自己ホスト型 @brightdata/mcp パッケージ、および各ジョブがルーティングすべきツールを対象としています。シェルからジョブを実行するエージェント向けではなく（brightdata-cli）、アプリ内で固定的に繰り返し使用するコード向けでもなく（brightdata-sdk）、インストールや認証の問題向けでもありません（agent-onboarding）。
