Der MCP‑Server von Bright Data, die Werkzeugebene, die einem LLM‑Agent Live‑Webzugriff ohne Shell ermöglicht. Verwenden Sie ihn, wenn Sie Bright‑Data‑Tools in eine KI‑App oder ein Agenten‑Framework integrieren, das seine Werkzeuge zur Laufzeit auswählt, wenn Sie Claude, Cursor oder einen anderen MCP‑Client mit Bright Data verbinden, wenn Sie entscheiden, welche MCP‑Tools oder -Gruppen aktiviert werden sollen, oder wenn der Benutzer „MCP“ sagt. Er umfasst den Remote‑Server, der unter mcp.brightdata.com gehostet wird, sowie das lokal selbstgehostete @brightdata/mcp‑Paket und legt fest, zu welchem Tool jeder Job geroutet werden soll. Nicht für den Agenten, der die Aufgabe selbst aus einer Shell ausführt – das ist brightdata-cli. Nicht für fest codierten wiederholten Code in einer App – das ist brightdata-sdk. Nicht für Installations‑ oder Authentifizierungs‑Probleme – das ist agent‑onboarding.
