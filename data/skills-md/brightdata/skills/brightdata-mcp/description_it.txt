Il server MCP di Bright Data, lo strato di strumenti che fornisce a un agente LLM l'accesso web in tempo reale senza shell. Da utilizzare quando si integrano gli strumenti di Bright Data in un'app AI o in un framework di agenti che seleziona i suoi strumenti a runtime, quando si collega Claude, Cursor o un altro client MCP a Bright Data, quando si sceglie quali strumenti o gruppi MCP attivare, o quando l'utente dice MCP. Copre il server remoto ospitato su mcp.brightdata.com e il pacchetto locale auto‑ospitato @brightdata/mcp, nonché a quale strumento deve essere indirizzato ciascun job. Non è destinato all'agente che esegue il lavoro stesso da una shell, che è brightdata-cli. Non è per codice fisso e ripetuto in un'app, che è brightdata-sdk. Non è per problemi di installazione o autenticazione, che è agent-onboarding.
