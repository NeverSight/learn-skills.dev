استخدم عندما يكون لدى المستخدم بالفعل أتمتة للمتصفح ويريد إلغاء حظرها أو تشغيلها في السحابة: Playwright أو Puppeteer أو Selenium أو أي برنامج تشغيل آخر، أو سكريبت بلا رأس يتم حظره أو اكتشافه أو تقييده محليًا، أو ذكاءً اصطناعيًا يستخدم الكمبيوتر للنقر بنفسه ويحتاج إلى مكان للنقر. كما يُستَخدم للطلبات التي تذكر CDP أو connectOverCDP أو browserWSEndpoint أو WebDriver عن بُعد أو نقطة نهاية WebSocket للمتصفح أو واجهة برمجة تطبيقات المتصفح. ليس لبناء أداة استخراج للبيانات لهم (استخدم scrape)، ولا لصفحة واحدة كـ markdown أو HTML أو لقطة شاشة (استخدم fetch)، ولا لاستعلام بحث (استخدم search).

يرجى دائمًا الرد بلغة المستخدم.
