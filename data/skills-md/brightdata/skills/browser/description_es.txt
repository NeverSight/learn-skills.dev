Úsese cuando el usuario ya tenga automatización de navegador y quiera que se desbloquee o se ejecute en la nube: Playwright, Puppeteer, Selenium u otro driver, un script headless que se bloquea, se detecta o tiene limitación de velocidad localmente, o una IA de uso de computadora que hace clic por sí misma y necesita un lugar donde hacer clic. También para solicitudes que mencionen CDP, connectOverCDP, browserWSEndpoint, un WebDriver remoto, un endpoint WebSocket del navegador o la API del navegador. No es para construir el scraper para ellos (use scrape), no es para una sola página como markdown, HTML o una captura de pantalla (use fetch), no es para una consulta de búsqueda (use search).

Por favor, responda siempre en el idioma del usuario.
