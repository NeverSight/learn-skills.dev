Récupérez les profils Instagram, les publications, les reels et les commentaires sous forme de JSON via l'API Bright Data Scraper. Utilisez-le lorsque l'utilisateur demande des données Instagram – les abonnés ou la bio d'un compte, les likes et commentaires d'une publication, les publications ou reels récents d'un compte, les commentaires d'une publication – ou prononce les termes « instagram scraper », « instagram api », « instagram data ». Gère les itinéraires entre le CLI (`bdata pipelines run` avec les identifiants de jeux de données Instagram), le SDK Python (`client.search.instagram.*` et `client.scrape.instagram.*`), et les outils MCP scraper. Inclut les coûts en crédits, le délai d'expiration des reels, les valeurs `post_type` fonctionnelles, ainsi que les cas d’erreur‑ligne que l’API renvoie comme succès.
