Скрапить профили Instagram, посты, Reels и комментарии в формате JSON через API Bright Data Scraper. Использовать, когда пользователь запрашивает любые данные Instagram — подписчики или биография аккаунта, лайки и комментарии к посту, последние посты или Reels аккаунта, комментарии к посту — или говорит «instagram scraper», «instagram api», «instagram data». Маршруты между CLI (`bdata pipelines run` с идентификаторами наборов данных Instagram), Python SDK (`client.search.instagram.*` и `client.scrape.instagram.*`) и инструментами MCP scraper. Содержит информацию о затратах кредитов, тайм‑ауте Reels, значениях `post_type`, которые работают, и случаях ошибок‑строк, которые API возвращает как успех.
