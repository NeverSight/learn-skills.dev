Raspa perfiles, publicaciones, reels y comentarios de Instagram como JSON a través de la API de Bright Data Scraper. Usa cuando el usuario solicite cualquier dato de Instagram: los seguidores o la biografía de una cuenta, los likes y comentarios de una publicación, las publicaciones recientes o reels de una cuenta, los comentarios en una publicación, o diga "instagram scraper", "instagram api", "instagram data". Rutas entre la CLI (`bdata pipelines run` con los IDs de conjuntos de datos de Instagram), el SDK de Python (`client.search.instagram.*` y `client.scrape.instagram.*`), y las herramientas de raspado MCP. Incluye los costos de crédito, el tiempo de espera de los reels, los valores `post_type` que funcionan y los casos de filas de error que la API devuelve como éxito.
