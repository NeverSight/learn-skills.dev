قم باستخلاص ملفات تعريف Instagram، المنشورات، الريلز والتعليقات كملف JSON عبر واجهة برمجة التطبيقات Bright Data Scraper. استخدم ذلك عندما يطلب المستخدم أي بيانات Instagram - متابعين الحساب أو السيرة الذاتية، إعجابات وتعليقات منشور، المنشورات أو الريلز الحديثة لحساب، التعليقات على منشور - أو يذكر "instagram scraper"، "instagram api"، "instagram data". يربط بين سطر الأوامر (CLI) (`bdata pipelines run` مع معرفات مجموعة بيانات Instagram)، وSDK بايثون (`client.search.instagram.*` و `client.scrape.instagram.*`)، وأدوات MCP scraper. يتضمن تكاليف الائتمان، مهلة الريلز، قيم `post_type` التي تعمل، وحالات الصفوف الأخطاء التي تُرجعها الواجهة كنجاح.
