Bright Data Scraper API を通じて、Instagram のプロフィール、投稿、リール、コメントを JSON 形式でスクレイピングします。ユーザーが Instagram データ（アカウントのフォロワーやバイオ、投稿のいいねやコメント、アカウントの最新投稿やリール、投稿へのコメントなど）を求める場合、または「instagram scraper」「instagram api」「instagram data」と言ったときに使用します。CLI（`bdata pipelines run` と Instagram データセット ID を使用）、Python SDK（`client.search.instagram.*` と `client.scrape.instagram.*`）、MCP スクレイパーツール間のルーティングを行います。クレジットコスト、リールのタイムアウト、利用可能な `post_type` の値、API が成功として返すエラーロウケースを含みます。

常にユーザーの言語で応答してください。
