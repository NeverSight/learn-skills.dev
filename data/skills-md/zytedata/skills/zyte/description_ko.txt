Zyte 계정 작업 중 Zyte MCP 도구가 없는 경우: 자격 증명(설정, 로그인, API 키 발급 또는 차단된 사이트); 프로젝트를 Scrapy Cloud에 배포하거나 푸시하고, 작업의 전체 아이템, 로그 또는 요청을 파일에 저장하기(Zyte MCP 결과는 잘림); Zyte API 요금제 가격(플랜, 단계, 할인, 약정, 무료 크레딧); docs.zyte.com의 문서에서 Zyte 제품 또는 계정/청구와 관련된 사용 방법 및 문서 질문. Scrapy Cloud 작업, 기록된 사용량 및 웹사이트별 가격은 Zyte MCP 도구입니다; 이 도구가 없을 때만 이 기술을 사용하여 사용자가 Zyte MCP에 연결하는 방법을 알려 주세요. 로컬에서 스파이더를 작성·디버깅하는 용도(scrapy‑extra)로는 사용하지 마세요.
