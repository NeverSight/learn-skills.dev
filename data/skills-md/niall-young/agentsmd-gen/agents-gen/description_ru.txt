Обязательный контроль жизненного цикла AGENTS.md для прямых запросов на создание, обновление, организацию, аудит или исправление файлов проекта AGENTS.md и для каждой задачи реализации, которая создаёт, изменяет, переименовывает или удаляет файлы проекта. Создайте минимальный корень, дайте независимым подпроектам ограниченные инструкции, направляйте условные рекомендации через обнаруживаемые .agent-guides и сообщайте «не изменено», когда нет долговременного воздействия инструкций. Пропускайте чисто обсуждения, исследования, планирование и другие задачи только для чтения.
