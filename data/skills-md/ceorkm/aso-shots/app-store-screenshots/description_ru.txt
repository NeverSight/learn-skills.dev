Преобразуйте оригинальные скриншоты приложения в высокоэффективные наборы скриншотов для App Store (и Google Play). Используйте, когда пользователь хочет получить скриншоты для App Store, изображения для листинга магазина, дизайн скриншотов или макеты для приложения, либо хочет воссоздать понравившийся стиль скриншотов. Пишет тексты, предлагает 3 направления стиля, генерирует ресурсы с помощью ИИ (Codex или API изображений), собирает набор в HTML и экспортирует готовые к размещению PNG‑файлы.
