Trasforma gli screenshot grezzi di un'app in set di screenshot ad alta conversione per App Store (e Google Play). Da utilizzare quando l'utente desidera screenshot per App Store, immagini per la presentazione in store, design o mockup di screenshot per un'app, o vuole ricreare uno stile di screenshot che gli piace. Scrive il testo, offre 3 direzioni di stile, genera risorse con IA (Codex o un'API di immagini), costruisce il set in HTML ed esporta PNG pronti per lo store.
