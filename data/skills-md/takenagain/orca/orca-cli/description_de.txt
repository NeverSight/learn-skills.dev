Betreiben Sie Orca‑verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaum‑Kommentare und den integrierten Browser von Orca über die `orca`‑CLI. Verwenden Sie sie, wenn der Benutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzugen Sie dies gegenüber rohen Git‑Arbeitsbäumen, ad‑hoc‑PTSes oder Computer‑Use, wenn Orca‑Zustand beteiligt ist. Nutzen Sie Computer‑Use nur, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die ein CLI, Dateisystem oder eine API nicht leisten kann.

Bitte immer in der Sprache des Benutzers antworten.
