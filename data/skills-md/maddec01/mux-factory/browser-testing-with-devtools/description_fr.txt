Tests dans de vrais navigateurs via Chrome DevTools MCP. Utilisez‑le lors de la création ou du débogage de tout ce qui s’exécute dans un navigateur. Utilisez‑le lorsque vous devez inspecter le DOM, capturer les erreurs de la console, analyser les requêtes réseau, profiler les performances ou vérifier le rendu visuel avec des données d'exécution réelles. Nécessite que le serveur chrome‑devtools MCP soit configuré.
