Führt mehrdimensionale Code‑Reviews durch. Verwenden Sie es, bevor Sie eine Änderung zusammenführen. Verwenden Sie es, wenn Sie Code überprüfen, der von Ihnen selbst, einem anderen Agenten oder einem Menschen geschrieben wurde. Verwenden Sie es, wenn Sie die Code‑Qualität über mehrere Dimensionen hinweg beurteilen müssen, bevor sie in den Hauptzweig gelangt. Verwenden Sie es, wenn Sie gebeten werden, einen Diff oder einen Pull‑Request zu prüfen, selbst wenn der Diff inline eingefügt ist.

Bitte antworten Sie immer in der Sprache des Benutzers.
