Depuración sistemática de solo lectura: demostrar la causa raíz de un error, fallo de prueba o comportamiento inesperado a partir de evidencia del código/fuente o en tiempo de ejecución, más un contexto opcional exacto del proyecto, issue o PR de GitHub, y luego devolver la evidencia y una solución mínima propuesta. Depurar nunca modifica el estado de GitHub ni del repositorio.
