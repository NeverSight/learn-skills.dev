Configurer une machine Mac (Apple silicon) sans écran, Linux ou Windows via SSH, étape par étape, depuis « un compte admin avec un mot de passe et SSH activé » jusqu’à une machine configurée avec SSH uniquement par clé, connexion automatique, paramètres d’absence de mise en veille et Tailscale optionnel – sur un Mac avec Determinate Nix et nix‑darwin, sur Linux avec un module NixOS (installation de NixOS avec nixos‑anywhere si l’utilisateur le souhaite) ou un script neutre pour les distributions Debian, Ubuntu et Fedora, sur Windows 11 ou Windows Server avec une configuration PowerShell réexécutable – puis redémarrer la machine et vérifier qu’elle revient en ligne. Utilisez‑le lorsque l’utilisateur veut installer, configurer, mettre à jour ou vérifier un Mac mini sans écran, un serveur Linux, un PC Windows ou tout autre appareil accessible uniquement via SSH. Le mot de passe admin reste dans le coffre secret de l’utilisateur (Automic Vault, 1Password, Bitwarden, toute commande, ou un fichier d’environnement privé) ; vous ne mentionnez jamais le coffre, uniquement l’entrée du coffre.

Veuillez toujours répondre dans la langue de l'utilisateur.
