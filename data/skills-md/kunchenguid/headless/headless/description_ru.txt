Настройте безголовый Mac (Apple silicon), Linux или Windows‑машину через SSH, шаг за шагом, начиная с «учётной записи администратора с паролем и включённым SSH» и заканчивая сконфигурированной системой с доступом только по ключу, автоматическим входом, режимом «не спит» и при желании Tailscale — на Mac с Determinate Nix и nix-darwin, на Linux с модулем NixOS (устанавливая NixOS через nixos‑anywhere, если пользователь хочет) или нейтральным скриптом для Debian, Ubuntu и Fedora, на Windows 11 или Windows Server с переисполняемой конфигурацией PowerShell — затем перезагрузите её и проверьте, что она вернулась в рабочее состояние. Используйте, когда пользователь хочет установить, настроить, обновить или проверить безголовый Mac mini, Linux‑сервер, Windows‑ПК или другую машину, к которой он имеет доступ только по SSH. Пароль администратора хранится в безопасном хранилище пользователя (Automic Vault, 1Password, Bitwarden, любая команда или приватный файл .env); вы упоминаете только название записи в этом хранилище.
