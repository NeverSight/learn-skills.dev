Configura una macchina headless Mac (Apple silicon), Linux o Windows via SSH, passo dopo passo, da «un account amministratore con password e SSH attivo» a una macchina configurata con SSH solo con chiave, accesso automatico, impostazioni di non sospensione e Tailscale opzionale — su un Mac con Determinate Nix e nix-darwin, su Linux con un modulo NixOS (installando NixOS con nixos‑anywhere se l'utente lo desidera) o con uno script neutro per distribuzioni per Debian, Ubuntu e Fedora, su Windows 11 o Windows Server con una configurazione PowerShell ri‑eseguibile — poi riavviala e conferma che torni online. Usalo quando l'utente vuole installare, configurare, aggiornare o verificare un Mac mini headless, un server Linux, un PC Windows o qualsiasi altra macchina accessibile solo tramite SSH. La password amministratore rimane nel deposito segreto dell'utente (Automic Vault, 1Password, Bitwarden, qualsiasi comando o un file env privato); devi indicare solo il nome della voce nel deposito.  

Rispondi sempre nella lingua dell'utente.
