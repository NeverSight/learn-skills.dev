Configura una Mac sin cabeza (Apple silicon), una máquina Linux o Windows a través de SSH, paso a paso, desde “una cuenta de administrador con contraseña y SSH activado” hasta una máquina configurada con SSH solo por clave, inicio de sesión automático, ajustes de nunca dormir y Tailscale opcional: en una Mac con Determinate Nix y nix-darwin, en Linux con un módulo NixOS (instalando NixOS con nixos‑anywhere si el usuario lo desea) o un script neutral para distribuciones para Debian, Ubuntu y Fedora, en Windows 11 o Windows Server con una configuración PowerShell reejecutable; luego reinícialo y confirma que vuelve. Úsalo cuando el usuario quiera configurar, actualizar o verificar una Mac mini sin cabeza, un servidor Linux, un PC con Windows u otra máquina a la que solo acceda mediante SSH. La contraseña de administrador permanece en el almacén secreto del usuario (Automic Vault, 1Password, Bitwarden, cualquier comando o un archivo .env privado); solo mencionarás la entrada del almacén. Por favor, responde siempre en el idioma del usuario.
