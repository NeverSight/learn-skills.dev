إعداد جهاز ماك بدون شاشة (Apple silicon) أو لينكس أو ويندوز عبر SSH، خطوة بخطوة، بدءًا من "حساب مدير بكلمة مرور وSSH مفعَّل" إلى جهاز مُكوَّن يحتوي على SSH باستخدام المفاتيح فقط، تسجيل الدخول التلقائي، إعدادات عدم السكون، وإضافة Tailscale اختيارية — على ماك باستخدام Determinate Nix وnix-darwin، وعلى لينكس باستخدام وحدة NixOS (تثبيت NixOS عبر nixos-anywhere إذا أراد المستخدم) أو سكربت محايد للتوزيعات لـ Debian وUbuntu وFedora، وعلى Windows 11 أو Windows Server باستخدام تكوين PowerShell يمكن إعادة تشغيله — ثم إعادة تشغيل الجهاز والتأكد من عودته. استخدم هذا عندما يرغب المستخدم في إعداد أو تهيئة أو تحديث أو فحص ماك ميني بدون شاشة، خادم لينكس، حاسوب ويندوز أو أي جهاز آخر لا يمكن الوصول إليه إلا عبر SSH. تظل كلمة مرور المدير مخزنة في مخزن الأسرار الخاص بالمستخدم (Automic Vault، 1Password، Bitwarden، أي أمر، أو ملف بيئي خاص)؛ أنت فقط تذكر اسم الإدخال في المخزن.  

الرجاء الرد دائمًا بلغة المستخدم.
