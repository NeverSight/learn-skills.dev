Trouvez les animations dont une interface n’a pas besoin et supprimez‑les — le mouvement lors des actions clavier, les surfaces à haute fréquence, les données fonctionnelles et les décorations inutiles — puis nettoyez ce qu’elles laissent derrière. Modifiez le code, mais uniquement pour soustraire ; il n’ajoute jamais et ne retouche jamais le mouvement. Utilisez cela lorsque l’utilisateur dit que l’application « paraît lente », « a trop d’animation », « est sur‑animée », veut « diminuer le mouvement », ou demande quelles animations supprimer. Pour repérer les endroits qui devraient être animés, utilisez find‑animation‑opportunities ; pour corriger les animations qui doivent rester, utilisez improve‑animations ou review‑animations.
