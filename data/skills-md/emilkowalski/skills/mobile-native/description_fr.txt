Faire qu’une application web se sente native sur un téléphone — les petits correctifs CSS et méta‑tags qui distinguent « un site web dans un navigateur » d’une chose qui semble installée. Couvre les états hover persistants, les flashs de surbrillance au tap, le bug du 100 vh, les champs qui zooment la page, les tapotements lents, le pull‑to‑refresh qui détourne le défilement, le contenu sous l’encoche, le long‑press qui sélectionne le texte des boutons, les carrousels qui défilent dans la mauvaise direction, les barres d’état incohérentes, et la règle de tester sur du matériel réel. À utiliser lorsqu’une application web est développée ou évaluée sur mobile, lorsqu’un élément « fonctionne dans Chrome mais paraît mal sur mon téléphone », lors de la création d’une PWA, d’une feuille de bas de page, d’un carrousel, d’une mise en page plein écran ou de toute interaction tactile. Pour le mouvement lui‑même, utilisez animate ; pour React Native, utilisez animate‑expo.
