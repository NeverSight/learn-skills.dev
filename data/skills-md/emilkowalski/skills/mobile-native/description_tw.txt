讓 Web 應用在手機上感覺像原生應用 — 那些微小的 CSS 與 meta 標籤修正，將「瀏覽器中的網站」與感覺已安裝的體驗區分開來。包括黏性 hover 狀態、點擊時的高亮閃爍、100vh 錯誤、輸入框導致頁面縮放、點擊延遲、下拉刷新劫持捲動、內容被凹槽遮擋、長按選取按鈕文字、輪播方向錯誤、狀態列不匹配，以及必須在真機上測試的規則。適用於在行動裝置上構建或審核 Web 應用、遇到「在 Chrome 正常但在手機上感覺不對勁」的情況、打造 PWA、底部抽屜、輪播、全螢幕布局或任何觸控互動時。若要製作動畫本身請使用 animate；若是 React Native 請使用 animate‑expo。
