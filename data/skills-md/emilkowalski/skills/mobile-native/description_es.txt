Haz que una aplicación web se sienta nativa en un teléfono — los pequeños ajustes de CSS y meta‑etiquetas que separan “un sitio web en un navegador” de algo que parece instalado. Cubre estados hover pegajosos, destellos de resaltado al tocar, el bug del 100 vh, entradas que hacen zoom en la página, toques con retraso, pull‑to‑refresh que secuestra el desplazamiento, contenido bajo la muesca, pulsación larga que selecciona el texto del botón, carruseles que se desplazan en sentido incorrecto, barras de estado desincronizadas y la regla de probar en hardware real. Úsalo cuando se está construyendo o revisando una aplicación web para móvil, cuando algo “funciona en Chrome pero se siente extraño en mi teléfono”, al crear una PWA, una hoja inferior, un carrusel, un diseño a pantalla completa o cualquier interacción táctil. Para la animación en sí usa animate; para React Native usa animate‑expo.
