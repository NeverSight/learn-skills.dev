Mantén las animaciones web dentro del presupuesto de fotogramas — anima solo propiedades de composición, mantiene el movimiento fuera del hilo principal cuando la página está ocupada y encuentra la causa cuando una animación pierde fotogramas. Cubre la canalización de layout/pintado/composición, cambios de propiedad más baratos, CSS vs WAAPI vs requestAnimationFrame, la ruta acelerada por hardware de Framer Motion, el re‑renderizado de React por fotograma, la recalculación de variables CSS heredadas, el coste del desenfoque y cuándo `will-change` realmente ayuda. Úsalo cuando una animación sea entrecortada, entrecortante, se tropiece o pierda fotogramas; al elegir qué propiedad animar; al decidir entre animación CSS y JS por motivos de rendimiento; o al recurrir a `will-change` o capas GPU. Para elegir easing, duración o si animar o no, usa animate; para revisar el movimiento en su conjunto, usa review-animations.
