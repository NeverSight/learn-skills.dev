Gardez les animations Web dans le budget de trame — animez uniquement les propriétés de composition, maintenez le mouvement hors du fil principal lorsque la page est occupée, et identifiez la cause lorsqu’une animation perd des images. Couvre le pipeline mise en page / peinture / composition, les échanges de propriétés moins coûteux, CSS vs WAAPI vs requestAnimationFrame, le chemin matériel accéléré de Framer Motion, le re‑rendering de React image par image, le recalcul des variables CSS héritées, le coût du flou, et les cas où `will-change` est réellement utile. Utilisez‑le lorsqu’une animation est saccadée, hachée, saccade ou perd des images ; lors du choix de la propriété à animer ; lors du choix entre animation CSS et JS pour des raisons de performance ; ou lorsque vous avez recours à `will-change` ou aux calques GPU. Pour choisir l’easing, la durée ou décider d’animer ou non, utilisez animate ; pour passer en revue le mouvement dans son ensemble, utilisez review-animations.
