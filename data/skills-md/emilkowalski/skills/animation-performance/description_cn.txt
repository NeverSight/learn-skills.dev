保持网页动画在帧预算内——仅对合成层属性进行动画，在页面繁忙时让动画脱离主线程，并在动画掉帧时找出原因。内容涵盖布局/绘制/合成流水线、成本更低的属性切换、CSS 与 WAAPI 与 requestAnimationFrame 的对比、Framer Motion 的硬件加速路径、React 每帧重新渲染、继承的 CSS 变量重新计算、模糊的开销，以及 `will-change` 真正起作用的情形。适用于动画卡顿、断断续续、抖动或掉帧时；选择动画属性时；在性能角度决定使用 CSS 还是 JS 动画时；或在考虑使用 `will-change` 或 GPU 层时。选择缓动、持续时间或是否进行动画时使用 animate；整体审视运动时使用 review-animations。请始终使用用户的语言回复。
