حافظ على أن تكون الرسوم المتحركة على الويب ضمن ميزانية الإطار — حرّك الخصائص التي تُدمج فقط، أبقِ الحركة خارج الخيط الرئيسي عندما تكون الصفحة مشغولة، وابحث عن السبب عندما تسقط الإطارات في الرسوم المتحركة. يغطي خط أنابيب التخطيط/الرسم/الدمج، تبديل الخصائص الأرخص، CSS مقابل WAAPI مقابل requestAnimationFrame، مسار Framer Motion المعتمد على العتاد، إعادة تصيير React لكل إطار، إعادة حساب المتغيّر الموروث في CSS، تكلفة الضبابية، ومتى يكون `will-change` مفيدًا فعليًا. استخدمه عندما تكون الرسوم المتحركة متعثرة، متقطعة، تتقفل، أو تسقط إطارات؛ عند اختيار أي خاصية لتحريكها؛ عند اتخاذ قرار بين الرسوم المتحركة بـ CSS أو JavaScript من منظور الأداء؛ أو عند اللجوء إلى `will-change` أو طبقات GPU. لاختيار التسارع الزمني، المدة، أو ما إذا كان ينبغي التحريك على الإطلاق استخدم animate؛ لمراجعة الحركة ككل استخدم review-animations.
