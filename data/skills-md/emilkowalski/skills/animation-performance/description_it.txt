Mantieni le animazioni web entro il budget di fotogrammi — anima solo le proprietà composite, tieni il movimento fuori dal thread principale quando la pagina è occupata e individua la causa quando un'animazione perde fotogrammi. Copre la pipeline layout/pittura/composite, scambi di proprietà più economici, CSS vs WAAPI vs requestAnimationFrame, il percorso accelerato dall'hardware di Framer Motion, il re‑render di React per fotogramma, il ricalcolo delle variabili CSS ereditate, il costo della sfocatura e quando `will-change` aiuta davvero. Usalo quando un'animazione è traballante, scattosa, si blocca o perde fotogrammi; quando scegli quale proprietà animare; quando decidi tra animazione CSS e JS per ragioni di prestazioni; o quando ricorri a `will-change` o ai layer GPU. Per scegliere easing, durata o se animare affatto usa **animate**; per rivedere il motion nel suo complesso usa **review-animations**.
