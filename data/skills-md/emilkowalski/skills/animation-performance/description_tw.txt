保持網頁動畫在框架預算內 — 動畫僅限於合成層的屬性，當頁面忙碌時將運動保持在非主執行緒，並找出動畫掉幀的原因。涵蓋布局/繪製/合成管線、較低成本的屬性交換、CSS vs WAAPI vs `requestAnimationFrame`、Framer Motion 的硬體加速路徑、React 每幀重新渲染、繼承的 CSS 變數重新計算、模糊效能成本，以及何時 `will-change` 真正有幫助。當動畫卡頓、斷斷續續、抖動或掉幀時使用；在選擇要動畫的屬性時使用；在基於效能考量決定使用 CSS 還是 JS 動畫時使用；或在考慮使用 `will-change` 或 GPU 層時使用。若要選擇緩動函式、持續時間，或是否要執行動畫，使用 **animate**；若要整體檢視動畫，使用 **review-animations**。
