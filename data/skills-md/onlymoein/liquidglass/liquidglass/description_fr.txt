Créez des interfaces utilisateur React avec @onlymoein/liquidglass, une bibliothèque de composants en verre de style iOS 27 pour le Web (et @onlymoein/liquidglass-native pour React Native et Expo). À utiliser lorsqu’un projet importe @onlymoein/liquidglass ou liquidglass-native, lorsqu’une interface utilisateur de style iOS ou « liquid glass » est demandée dans React, ou lorsque les composants en verre ne s’affichent pas correctement, ne se déforment pas, n’apparaissent pas ou ralentissent une page.
