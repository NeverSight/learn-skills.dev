Cree interfaces de usuario de React con @onlymoein/liquidglass, una biblioteca de componentes de cristal al estilo de iOS 27 para la web (y @onlymoein/liquidglass-native para React Native y Expo). Úselo cuando un proyecto importe @onlymoein/liquidglass o liquidglass-native, cuando se solicite una interfaz de usuario de estilo iOS o «vidrio líquido» en React, o cuando los componentes de vidrio tengan un aspecto incorrecto, no se curven, no aparezcan o ralenticen una página.
