Utilisez cela lorsque l'utilisateur est un membre standard (non VIP) de Jimeng sans le CLI dreamina et a besoin d’image‑à‑image sur jimeng.jianying.com. opencli jimeng n’a pas de sous‑commande image2image ; seules les commandes generate, history, new et workspaces sont autorisées. Associez-le à dreamina‑prompt‑image2image pour les invites d’édition, le téléchargement manuel de référence sur l’interface web de Jimeng dans la même session de navigateur, et utilisez l’historique d’opencli pour la vérification. N’invoquez jamais les compétences d’exécution de dreamina ou de jimeng‑cli.  

Veuillez toujours répondre dans la langue de l’utilisateur.
