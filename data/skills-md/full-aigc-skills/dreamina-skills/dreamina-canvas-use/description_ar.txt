استخدم هذا عندما يطلب المستخدم صور Dream أو مقاطع فيديو أو صوت أو موسيقى لكنه لا يحدد إجراءً ملموسًا: اختر وقم بتسليم المراحل حسب الحاجة ضمن القدرات التسع لواجهة سطر أوامر Canvas أو سير عمل الإنتاج الفيديوي الاحترافي؛ تعامل فقط مع التوجيه وتقرير دورة الحياة، دون نسخ مواصفات الأوامر.
