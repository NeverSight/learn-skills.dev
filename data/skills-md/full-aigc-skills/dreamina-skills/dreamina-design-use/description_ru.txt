Когда пользователь просто говорит «создать картинку / создать видео / добавить аудио», то есть делает запрос на создание сна без указания входной точки, используйте следующее: проведите триаж и передачу между девятью точками входа Canvas CLI, навыком создания Prompt и навыком видеопроекта; выполняйте только маршрутизацию, не копируя спецификации команд. Используйте dreamina‑canvas‑use для сквозной оркестрации Canvas и отчётности о жизненном цикле.
