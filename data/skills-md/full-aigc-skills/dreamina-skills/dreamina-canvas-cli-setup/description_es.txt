Se utiliza cuando el usuario desea instalar, actualizar o verificar el CLI de dreamina-canvas — menciona 安装即梦画布, 安装 dreamina-canvas, comando no encontrado, PATH, 升级 CLI, o solicita el comando de instalación rápida para macOS / Linux / Windows PowerShell / Windows CMD. Ejecuta el instalador oficial para el sistema operativo actual, verifica la disponibilidad (--help / version / schema), soluciona problemas de PATH y luego pasa a la Skill de autorización. La instalación modifica la máquina del usuario y siempre requiere autorización explícita primero.
