ユーザーが dreamina-canvas CLI のインストール、更新、または検証を希望する場合に使用します — 「安装即梦画布」や「安装 dreamina-canvas」「command not found」「PATH」「升级 CLI」などに言及する場合、または macOS / Linux / Windows PowerShell / Windows CMD 用のクイックスタートインストールコマンドを求める場合。現在の OS 用の公式インストーラを実行し、利用可能かどうか（--help / version / schema）を検証し、PATH のトラブルシューティングを行った後、認可スキルに引き継ぎます。インストールはユーザーのマシンを変更し、常に事前に明示的な認可が必要です。
