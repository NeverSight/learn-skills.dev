صمم أو نفّذ أو أعد التصميم أو راجع بصريًا تجارب الواجهة الأمامية عندما تكون المهمة تتعلق فعليًا بالهرمية البصرية أو التخطيط أو السلوك المتجاوب أو تصميم التفاعل. لا تستخدم ذلك للبرمجة الخلفية أو واجهات برمجة التطبيقات أو البنية التحتية أو منطق الواجهة الأمامية دون تأثير تصميمي جوهري.

يرجى دائمًا الرد بلغة المستخدم.
