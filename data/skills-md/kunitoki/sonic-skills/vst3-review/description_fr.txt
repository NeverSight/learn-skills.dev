Examine les implémentations de plugins VST3 pour la conformité aux spécifications, la compatibilité avec l'hôte et la correction. À utiliser lorsqu'un utilisateur demande à examiner un plugin VST3, vérifier les agencements de bus, auditer la gestion des paramètres ou vérifier que son rappel process() est sûr. Se déclenche sur des phrases comme « review my VST3 plugin », « check VST3 bus arrangement », « is my VST3 process safe », « audit my IAudioProcessor », ou lorsqu’on voit IComponent, IAudioProcessor, IEditController, ProcessData ou les types du namespace Vst:: dans le code.

Veuillez toujours répondre dans la langue de l'utilisateur.
