Prüfen Sie agentgenerierten Code im Hinblick auf Lesbarkeit, Wartbarkeit und sichere Modifizierbarkeit für Junior‑Softwareingenieure. Verwenden Sie diese Prüfung immer, wenn Codex Code ändert, Code prüft, Diffs begutachtet oder Implementierungspläne bewertet, die von einem Agenten erstellt wurden; nach Codeänderungen führen Sie die Prüfung in einer Schleife aus, bis alle Befunde behoben sind oder insgesamt 10 Prüfungsdurchläufe abgeschlossen wurden. Stellen Sie sicher, dass das Ergebnis einfach, intuitiv, lokal verständlich, leicht zu debuggen, explizit im Kontrollfluss, angemessen abstrahiert und von einem einigermaßen fähigen neuen Teammitglied ohne versteckten Kontext erklärbar ist.

Bitte antworten Sie immer in der Sprache des Benutzers.
