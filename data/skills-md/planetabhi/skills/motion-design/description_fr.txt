Chargez cette compétence lors de l'ajout ou de la révision des animations d’interface Web telles que les animations, les transitions, les entrées et sorties, les effets au survol, les modaux, les listes déroulantes, les toasts, les transitions de pages et les micro‑interactions. Se déclenche sur « animate », « add a transition », « make it move », « motion », « fade », « slide », « stagger », « open and close ». Génère du CSS sans dépendances, Baseline‑first, agnostique de tout framework, en utilisant les API Web Animations et View Transitions lorsqu’elles sont utiles.
