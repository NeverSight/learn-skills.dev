Utilisez chaque fois que l'utilisateur souhaite créer, étendre, déboguer, tester, valider, charger localement, empaqueter ou publier un plugin OpenPets ; travailler avec le SDK de plugins OpenPets v3, le manifeste du plugin, les autorisations du plugin, le bac à sable, l'interface du plugin, le stockage, les horaires, les ressources ou le développement de plugins local. Utilisez également pour installer ou configurer OpenPets, les animaux, les intégrations optionnelles d'agent de codage ou les contrôles MCP locaux. Priorisez l'expérience d'auteur de plugins « local‑first » ; les intégrations d'agent sont optionnelles.
