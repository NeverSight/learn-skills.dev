Usa ogni volta che l'utente vuole costruire, estendere, fare debug, testare, validare, caricare localmente, impacchettare o pubblicare un plugin OpenPets; lavorare con l'SDK Plugin OpenPets v3, il manifesto del plugin, i permessi del plugin, la sandbox, l'interfaccia UI del plugin, lo storage, le programmazioni, le risorse o lo sviluppo locale del plugin. Usa anche per installare o configurare OpenPets, gli animali, integrazioni opzionali con coding-agent o controlli MCP locali. Dai priorità all'esperienza di authoring del plugin incentrata sul locale; le integrazioni con gli agenti sono opzionali.

Per favore rispondi sempre nella lingua dell'utente.
