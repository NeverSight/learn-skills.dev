Используется при чтении или обновлении контента Weaverse программно — получении проектов/страниц/настроек темы, массовом редактировании содержимого страниц, загрузке текста, сгенерированного ИИ, удалении страниц или загрузке медиа‑файлов в Shopify для использования в Weaverse. Срабатывает при запросах на обновление проекта Weaverse через API, передаче контента в живой проект, выполнении массовых правок содержимого или загрузке изображений/ресурсов в Shopify из автоматизации.
