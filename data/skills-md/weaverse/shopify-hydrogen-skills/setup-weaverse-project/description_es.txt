Configura una nueva tienda Weaverse Hydrogen localmente a partir de un tema de Weaverse. Inicia una vista previa de una tienda de demostración en vivo antes de solicitar cualquier credencial, y luego conviértela en la propia del comerciante: instala la aplicación Hydrogen, vincula la tienda, extrae las credenciales de Storefront, envía el repositorio a GitHub, configura el MCP de Weaverse para ediciones de página en tiempo real e instala el paquete completo shopify-hydrogen-skills.
