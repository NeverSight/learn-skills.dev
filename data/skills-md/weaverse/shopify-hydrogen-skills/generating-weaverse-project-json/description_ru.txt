Используется при генерации экспортного JSON проекта Weaverse для импорта в редактор Weaverse. Срабатывает по запросам на создание, сборку или генерацию JSON‑файла проекта Weaverse из миграции сайта, дизайн‑спецификации, описания макета страницы или существующего экспорта. Также используется при преобразовании планов секций в импортируемые данные проекта и страниц.
