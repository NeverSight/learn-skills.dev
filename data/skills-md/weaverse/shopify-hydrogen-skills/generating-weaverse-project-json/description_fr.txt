Utilisez‑le lors de la génération d’un export JSON de projet Weaverse pour l’importation dans l’éditeur Weaverse. Il se déclenche à la demande de création, de construction ou de production d’un fichier JSON de projet Weaverse à partir d’une migration de site, d’une spécification de conception, d’une description de mise en page ou d’une exportation existante. Utilisez‑le également lors de la conversion de plans de sections en données de projet et de pages importables.
