Diagnostica fallos de GitHub Actions y atribuye tiempo y costo de CI usando el CLI `sling` de StarSling. Invócalo ANTES de usar `gh` o de obtener cualquier registro siempre que el usuario pregunte por qué falló un trabajo o una ejecución, qué hizo que una ejecución fuera lenta, sobre minutos de runner o costo de CI, solicite re‑ejecutar o cancelar una ejecución, o pegue una URL de GitHub Actions — `sling` devuelve causas de falla clasificadas por el servidor y atribución de coste que la búsqueda en logs no detecta; los cambios de estado se encaminan a `gh`. No es para auditorías a nivel de repositorio de archivos de workflow (ci-score, ci-speedup, ci-secure), escribir YAML de workflow, o CI que no sea GitHub Actions.
