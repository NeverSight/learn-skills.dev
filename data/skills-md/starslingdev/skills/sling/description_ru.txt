Диагностирует сбои GitHub Actions и определяет время и стоимость CI с помощью CLI `sling` от StarSling. Вызывайте это ПЕРЕД использованием `gh` или получением любых логов, когда пользователь спрашивает, почему задание или запуск завершились неудачей, что замедлило запуск, о минутах runner’ов или стоимости CI, просит пере‑запустить или отменить запуск, либо вставляет URL GitHub Actions — `sling` возвращает классифицированные сервером причины сбоя и атрибуцию стоимости, которые упускает простое поиск по логам; изменения состояния направляются в `gh`. Не предназначено для аудита репозитория по файлам workflow (ci‑score, ci‑speedup, ci‑secure), написания YAML‑файлов workflow или CI, не связанного с GitHub Actions.
