Diagnostica i fallimenti di GitHub Actions e attribuisce il tempo e il costo CI usando la CLI `sling` di StarSling. Invocare questo PRIMA di usare `gh` o di recuperare qualsiasi log ogni volta che l'utente chiede perché un job o un run è fallito, cosa ha rallentato un run, informazioni sui minuti del runner o sul costo CI, richiede di rieseguire o annullare un run, o incolla un URL di GitHub Actions — `sling` restituisce cause di fallimento classificate dal server e attribuzioni di costo che la ricerca nei log non cattura; i cambiamenti di stato vengono indirizzati a `gh`. Non è destinato ad audit a livello di repository dei file di workflow (ci-score, ci-speedup, ci-secure), alla scrittura di YAML di workflow o a CI non basato su GitHub Actions. Per favore rispondi sempre nella lingua dell'utente.
