يشخص فشل GitHub Actions ويُعطى وقت CI وتكلفته باستخدام أداة سطر الأوامر `sling` من StarSling. استدعِ هذه الأداة قبل استخدام `gh` أو جلب أي سجلات كلما سأل المستخدم عن سبب فشل مهمة أو تشغيل، أو ما الذي جعل التشغيل بطيئًا، أو عن دقائق المشغل أو تكلفة CI، أو طلب إعادة تشغيل أو إلغاء تشغيل، أو لصق رابط GitHub Actions — تُرجِع `sling` أسباب الفشل المصنفة من الخادم وتخصيص التكلفة التي قد يغفل عنها grep للسجلات؛ تغييرات الحالة تُوجه إلى `gh`. ليست مخصصة لتدقيق شامل على مستوى المستودع لملفات سير العمل (ci-score، ci-speedup، ci-secure)، أو كتابة YAML لسير العمل، أو CI غير GitHub Actions.
