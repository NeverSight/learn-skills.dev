Audita los flujos de trabajo de GitHub Actions de un repositorio para detectar oportunidades de optimización de CI — cachés faltantes, configuración redundante, preparación basada en sleep, trabajos de prueba largos sin dividir, checkout de historial completo, variables de entorno muertas, configuración incorrecta de caché de compilación y ~60 patrones más en caché, redundancia, paralelización, ejecución condicional, alcance de disparadores y fallos ocultos. Usar cuando: (1) analizando el CI de un repositorio en busca de oportunidades de optimización, (2) generando un informe priorizado con ahorros medidos en tiempo real y minutos de ejecutor, (3) reauditoría después de cambios de CI ascendentes. No activar para: ayuda general de configuración de CI, escritura de nuevos flujos de trabajo desde cero, sistemas de CI que no sean GitHub Actions, o auditorías de seguridad/postura — use `ci-secure` para esos casos.
