Аудитирует рабочие процессы GitHub Actions репозитория на предмет возможностей оптимизации CI — отсутствующие кэши, избыточные настройки, готовность, основанная на задержках (sleep), длительные тестовые задачи без шардинга, полный клон истории, «мёртвые» переменные окружения, неверная конфигурация кэша сборки и около 60 других шаблонов, связанных с кэшированием, избыточностью, параллелизмом, условным выполнением, областью триггеров и скрытыми сбоями. Используйте, когда: (1) анализируете CI репозитория в поиске возможностей оптимизации, (2) формируете приоритетный отчёт с измерёнными экономиями реального времени и минут раннера, (3) повторно проводите аудит после изменений в CI верхнего уровня. Не используйте для: общей помощи с настройкой CI, написания новых рабочих процессов с нуля, систем CI, не основанных на GitHub Actions, или аудитов безопасности/постуры — для этого используйте `ci-secure`.
