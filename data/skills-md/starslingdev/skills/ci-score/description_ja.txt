リポジトリの GitHub Actions 設定を CI ベストプラクティスに照らし合わせて評価します（CI スコア：リポジトリ固有の workflow YAML から算出された 11 項目の合否判定）。不足している箇所ごとに具体的な修正案を提示し、インパクトとリスクで順位付けし、すべてに即時適用オプションと貼り付け可能なエージェントプロンプトを付与します。利用シーン: (1) ユーザーが CI の評価・スコア付けやベストプラクティスに基づく CI 設定の監査を求めたとき（例: 「grade my CI」「CI score」「CI best practices audit」「how healthy is my CI config」）、(2) ワークフロー変更後に再評価したいとき。対象リポジトリのローカルチェックアウトが必要です。以下の場合はトリガーしません: CI の速度、コスト、実時間の監査、 「why is CI slow」 等の最適化機会分析（この場合は ci‑speedup を使用）、セキュリティ監査や姿勢レビュー（ci‑score はセキュリティ監査ではなく、リブリックチェックのうち action pinning と OIDC token scoping の 2 項目がセキュリティに関係するだけです）、新規ワークフローの作成、GitHub Actions 以外の CI。

常にユーザーの言語で応答してください。
