Califica la configuración de GitHub Actions de un repositorio según las mejores prácticas de CI (el CI Score: once hechos de configuración de pasa/falla calculados a partir del YAML del workflow del propio repositorio) y devuelve correcciones concretas para cada brecha, clasificadas por impacto y riesgo, cada una con una opción de aplicar ahora y un prompt de agente que se puede pegar. Úsalo cuando: (1) el usuario solicite calificar o puntuar su CI, o auditar la configuración de CI frente a las mejores prácticas ("grade my CI", "CI score", "CI best practices audit", "how healthy is my CI config"); (2) se requiera re‑puntuar después de cambios en el workflow. Requiere una copia local del repositorio objetivo. NO lo actives para: auditorías de velocidad, costo o tiempo de ejecución de CI, preguntas como "why is CI slow" o análisis de oportunidades de optimización (usa ci‑speedup); auditorías de seguridad o revisión de postura (ci‑score no es una auditoría de seguridad — exactamente dos verificaciones del rubro, el fijado de acciones y el alcance del token OIDC, son relacionadas con seguridad); crear nuevos workflows desde cero; CI que no sea GitHub Actions.

Por favor, responde siempre en el idioma del usuario.
