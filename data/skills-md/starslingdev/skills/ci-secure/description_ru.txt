Сканирует рабочие процессы GitHub Actions репозитория на предмет десяти критических векторов атак CI/CD — внедрение шаблонов, выполнение кода форка с привилегиями (pwn‑запросы), отравление кэша, поддельные SHA действий, утечки секретов, захват GITHUB_ENV, недоверенные триггеры записи токенов, учетные данные в кэшах/артефактах, непроверенное удалённое выполнение кода (curl|bash и изменяемый fetch‑and‑run), а также скрипты установки зависимостей, запускаемые в задаче, содержащей секреты — сообщает о каждом обнаружении с простым описанием сценария атаки, плюс проверки конфигурации «пройдено/не пройдено», и исправляет выбранные находки с помощью субагентов для каждого обнаружения. Преднамеренно НЕ является полным — проверяются только критические цепочки эксплойтов (references/why‑these‑ten.md). Использовать, когда: пользователь просит провести аудит или обзор безопасности CI/CD или GitHub Actions, задаёт вопрос «моя CI безопасна», «аудит моей CI‑безопасности», или использует имена ci-secure / /ci-secure. НЕ использовать для: аудитов скорости, стоимости или реального времени CI («почему CI медленная») — используйте ci-speedup; оценки соответствия лучшим практикам конфигурации CI («оцените мою CI», «CI‑score») — используйте ci-score.

Пожалуйста, всегда отвечайте на языке пользователя.
