يفحص تدفقات عمل GitHub Actions في المستودع بحثًا عن عشرة متجهات هجوم حرجة في CI/CD — حقن القوالب، تنفيذ كود من فرع مع صلاحيات (pwn requests)، تسميم الذاكرة المؤقتة، SHA للخطوات المتزيفة، تسريبات الأسرار، اختطاف GITHUB_ENV، تشغيل غير موثوق لتوكن الكتابة، بيانات الاعتماد في الذاكرة المؤقتة/المخرجات، تنفيذ كود بعيد غير مُتحقق (curl | bash و fetch‑and‑run القابل للتغيير)، وسكريبتات تثبيت التبعيات التي تُنفَّذ في مهمة تحمل أسرار — يُصدر تقريرًا لكل العثور مع سيناريو مهاجم بلغة إنجليزية مبسطة، بالإضافة إلى فحوصات تهيئة مرور/فشل، ويُصلح الاكتشافات المختارة عبر وكلاء فرعيين لكل اكتشاف. هذا ليس شاملًا عمدًا — فقط فحوصات سلاسل الاستغلال الحرجة (المراجع/why‑these‑ten.md). يُستخدم عندما: يطلب المستخدم تدقيق أو مراجعة وضع أمان CI/CD أو GitHub Actions، "هل CI الخاص بي آمن"، "تدقيق أمان CI الخاص بي"، أو يُذكر ci-secure / /ci-secure. لا يُفعَّل عند: سرعة CI، التكلفة، أو تدقيقات الوقت الفعلي ("لماذا CI بطيء") — استخدم ci-speedup؛ تقييم أفضل ممارسات تكوين CI ("قيم CI الخاص بي"، "درجة CI") — استخدم ci-score.
