掃描儲存庫的 GitHub Actions 工作流程，檢測十項關鍵 CI/CD 攻擊向量──模板注入、以特權執行的分支程式碼（pwn 請求）、快取投毒、冒名行動 SHA、機密洩漏、GITHUB_ENV 劫持、寫入令牌的不受信任觸發、快取/產出物中的憑證、未驗證的遠端程式碼執行（curl│bash 以及可變的 fetch‑and‑run），以及在持有機密的工作中執行的相依性安裝腳本──對每項發現提供通俗英文的攻擊者情境說明，並執行通過/失敗的設定衛生檢查，此外還能透過每項發現的子代理程式修復選定的問題。刻意不求全──僅檢查關鍵的利用鏈（參考 why‑these‑ten.md）。使用時機：使用者要求審計或檢視 CI/CD 或 GitHub Actions 安全姿態、詢問「我的 CI 安全嗎」、「審計我的 CI 安全」或提到 ci‑secure / /ci‑secure。不要在以下情況觸發：CI 執行速度、成本或實際耗時的審計（如「為什麼 CI 慢」）──改用 ci‑speedup；CI 設定最佳實踐評分（如「給我的 CI 打分」或「CI 分數」）──改用 ci‑score。
