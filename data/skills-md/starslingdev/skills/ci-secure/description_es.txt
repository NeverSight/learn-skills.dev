Escanea los flujos de trabajo de GitHub Actions de un repositorio en busca de los diez vectores críticos de ataque en CI/CD: inyección de plantillas, ejecución de código bifurcado con privilegios (pwn requests), envenenamiento de caché, SHA de acciones impostoras, filtraciones de secretos, secuestro de GITHUB_ENV, disparadores no confiables de write‑token, credenciales en cachés/artifacts, ejecución de código remoto no verificado (curl|bash y fetch‑and‑run mutable), y scripts de instalación de dependencias que se ejecutan en un trabajo que contiene secretos — informa cada hallazgo con un escenario de atacante en lenguaje sencillo, más verificaciones de higiene de configuración de aprobado/rechazado, y corrige los hallazgos seleccionados mediante subagentes por hallazgo. Deliberadamente NO es exhaustivo — solo verifica las cadenas críticas de explotación (referencias/why‑these‑ten.md). Úselo cuando: el usuario solicite auditar o revisar la postura de seguridad de CI/CD o GitHub Actions, “¿mi CI es seguro?”, “audita la seguridad de mi CI”, o mencione ci-secure / /ci-secure. NO se active para: velocidad de CI, costo o auditorías de tiempo de ejecución (“¿por qué CI es lento?”) — use ci‑speedup; calificación de mejores prácticas de configuración de CI (“califica mi CI”, “puntuación CI”) — use ci‑score.

Por favor, responda siempre en el idioma del usuario.
