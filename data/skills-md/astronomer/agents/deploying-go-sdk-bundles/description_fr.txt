Construit, empaquette et déploie les bundles compilés du SDK Go d’Airflow afin que l’ExecutableCoordinator puisse les exécuter. À utiliser lorsque l’utilisateur souhaite compiler un bundle de tâche Go, pose des questions sur `go build`, `go tool airflow-go-pack`, le bundle exécutable autonome AFBNDL01, l’empaquetage ou l’inspection d’un bundle, le placer sous `executables_root`, la compilation croisée d’un bundle pour les workers, la gestion des versions/étiquettes/pseudo‑versions du module `go-sdk`, ou mettre le bundle sur un worker Airflow (Docker, Kubernetes ou Astro). Pour le code des tâches, voir authoring-go-sdk-tasks ; pour les paramètres du coordinateur partagé, voir configuring-airflow-language-sdks.
