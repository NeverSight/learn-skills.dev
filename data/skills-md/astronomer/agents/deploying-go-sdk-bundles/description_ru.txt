Собирает, упаковывает и развертывает скомпилированные пакеты Airflow Go SDK, чтобы ExecutableCoordinator мог их выполнить. Используйте, когда пользователь хочет скомпилировать пакет Go‑задач, спрашивает о `go build`, `go tool airflow-go-pack`, самодостаточном исполняемом пакете AFBNDL01, упаковке или инспекции пакета, размещении его в `executables_root`, кросс‑компиляции пакета для воркеров, версиях/тегах/псевдо‑версиях модуля `go-sdk` или перемещении пакета на воркер Airflow (Docker, Kubernetes или Astro). Для кода задач см. authoring-go-sdk-tasks; для общих настроек координатора см. configuring-airflow-language-sdks.
