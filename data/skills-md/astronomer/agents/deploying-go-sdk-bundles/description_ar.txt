يبني ويعبّئ وينشر حزم Airflow Go SDK المترجمة بحيث يمكن لـ ExecutableCoordinator تشغيلها. يُستخدم عندما يرغب المستخدم في تجميع حزمة مهمة Go، أو يسأل عن `go build`، `go tool airflow-go-pack`، حزمة التنفيذ المستقلة AFBNDL01، تعبئة أو فحص حزمة، وضعها تحت `executables_root`، تجميع حزمة عبر الأنظمة للعمال، إصدار/علامات/إصدارات كاذبة لوحدة `go-sdk`، أو الحصول على الحزمة على عامل Airflow (Docker، Kubernetes، أو Astro). للشفرة الخاصة بالمهمة راجع authoring-go-sdk-tasks؛ لإعدادات المنسق المشترك راجع configuring-airflow-language-sdks.
