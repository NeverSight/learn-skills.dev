Compila, empaqueta y despliega paquetes compilados del SDK de Go de Airflow para que el ExecutableCoordinator pueda ejecutarlos. Úsalo cuando el usuario quiera compilar un paquete de tareas en Go, pregunte sobre `go build`, `go tool airflow-go-pack`, el paquete ejecutable autónomo AFBNDL01, empaquetar o inspeccionar un paquete, colocarlo bajo `executables_root`, compilar cruzado un paquete para workers, la versionado/etiquetas/pseudoversión del módulo `go-sdk`, o llevar el paquete a un worker de Airflow (Docker, Kubernetes o Astro). Para el código de la tarea consulta authoring-go-sdk-tasks; para la configuración compartida del coordinador consulta configuring-airflow-language-sdks.
