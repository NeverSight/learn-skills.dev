コンパイルされた Airflow Go SDK バンドルをビルド、パック、デプロイし、ExecutableCoordinator がそれらを実行できるようにします。ユーザーが Go タスクバンドルのコンパイルを希望したり、`go build`、`go tool airflow-go-pack`、AFBNDL01 の自己完結型実行可能バンドル、バンドルのパッキングまたは検査、`executables_root` への配置、ワーカー向けのクロスコンパイル、`go-sdk` モジュールのバージョニング／タグ／疑似バージョン、あるいはバンドルを Airflow ワーカー（Docker、Kubernetes、または Astro）に配置する場合に使用します。タスクコードについては authoring-go-sdk-tasks を、共有コーディネーター設定については configuring-airflow-language-sdks を参照してください。常にユーザーの言語で回答してください。
