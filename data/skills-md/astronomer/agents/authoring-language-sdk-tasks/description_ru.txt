Независимая от языка основа для пакетов SDK языка Airflow — реализация логики задач на языке, отличном от Python, при этом DAG остается на Python. Используйте, когда пользователь хочет запустить задачу Airflow на другом языке (Java, Kotlin, Go или других JVM/родных языках), спрашивает, как Python `@task.stub` сочетается с собственным кодом задачи, как идентификаторы задач/DAG должны совпадать на двух сторонах, как данные передаются через XCom в формате JSON или какие языковые SDK существуют. Этот навык владеет общим шаблоном Python-заглушки и концептуальной моделью; для собственного API, сборки и среды выполнения конкретного языка используйте навыки этого языка (например,authoring-java-sdk-tasks,authoring-go-sdk-tasks).
