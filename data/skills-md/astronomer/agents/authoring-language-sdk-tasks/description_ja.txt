Airflow 言語 SDK の言語中立の基盤 — DAG は Python のままで、非 Python 言語でタスク ロジックを実装します。ユーザーが Airflow タスクを別の言語 (Java、Kotlin、Go、またはその他の JVM/ネイティブ言語) で実行したい場合、Python `@task.stub` とネイティブ タスク コードのペアリング方法、タスク/DAG ID が両側でどのように一致する必要があるか、データが XCom を介して JSON として渡される方法、またはどの言語 SDK が存在するかを尋ねる場合に使用します。このスキルは、共有された Python スタブ パターンと概念モデルを所有します。特定の言語のネイティブ API、ビルド、ランタイムについては、その言語のスキル (authoring-java-sdk-tasks、authoring-go-sdk-tasks など) を使用します。
