La base neutre du langage pour les SDK du langage Airflow : implémentez la logique des tâches dans un langage non Python tandis que le DAG reste en Python. À utiliser lorsque l'utilisateur souhaite exécuter une tâche Airflow dans un autre langage (Java, Kotlin, Go ou autres langages JVM/natifs), demande comment le Python `@task.stub` s'associe au code de tâche natif, comment les ID de tâche/DAG doivent correspondre des deux côtés, comment les données passent via XCom en tant que JSON ou quels SDK de langue existent. Cette compétence possède le modèle de stub Python et le modèle conceptuel partagés ; pour l'API, la construction et l'exécution natives d'un langage spécifique, utilisez les compétences de ce langage (par exemple, authoring-java-sdk-tasks, authoring-go-sdk-tasks).
