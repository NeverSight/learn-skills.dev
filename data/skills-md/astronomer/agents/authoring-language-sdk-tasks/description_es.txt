La base independiente del lenguaje para los SDK del lenguaje Airflow: implemente la lógica de tareas en un lenguaje que no sea Python mientras el DAG permanece en Python. Úselo cuando el usuario desea ejecutar una tarea de Airflow en otro idioma (Java, Kotlin, Go u otros JVM/lenguajes nativos), pregunta cómo `@task.stub` de Python se empareja con el código de tarea nativo, cómo los ID de tarea/DAG deben coincidir en los dos lados, cómo pasan los datos a través de XCom como JSON o qué SDK de idioma existen. Esta habilidad posee el patrón Python-stub y el modelo conceptual compartidos; para la API, la compilación y el tiempo de ejecución nativos de un idioma específico, utilice la habilidad de ese idioma (por ejemplo, Authoring-Java-SDK-Tasks, Authoring-GO-SDK-Tasks).
