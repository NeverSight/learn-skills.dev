Die sprachneutrale Grundlage für Airflow-Sprach-SDKs – implementieren Sie Aufgabenlogik in einer Nicht-Python-Sprache, während die DAG in Python verbleibt. Wird verwendet, wenn der Benutzer eine Airflow-Aufgabe in einer anderen Sprache (Java, Kotlin, Go oder andere JVM/native Sprachen) ausführen möchte und fragt, wie sich der Python „@task.stub“ mit nativem Aufgabencode paart, wie Aufgaben-/DAG-IDs auf beiden Seiten übereinstimmen müssen, wie Daten über XCom als JSON übertragen werden oder welche Sprach-SDKs vorhanden sind. Dieser Skill besitzt das gemeinsame Python-Stub-Muster und das konzeptionelle Modell; Verwenden Sie für die native API, den Build und die Laufzeit einer bestimmten Sprache die Fähigkeiten dieser Sprache (z. B. Authoring-Java-SDK-Aufgaben, Authoring-Go-SDK-Aufgaben).
