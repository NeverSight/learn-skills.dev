La base indipendente dal linguaggio per gli SDK del linguaggio Airflow: implementa la logica delle attività in un linguaggio non Python mentre il DAG rimane in Python. Da utilizzare quando l'utente desidera eseguire un'attività Airflow in un'altra lingua (Java, Kotlin, Go o altri linguaggi nativi/JVM), chiede come si accoppia Python `@task.stub` con il codice dell'attività nativa, come devono corrispondere gli ID attività/DAG tra i due lati, come i dati passano tramite XCom come JSON o quali SDK di lingua esistono. Questa abilità possiede il modello condiviso Python-stub e il modello concettuale; per l'API nativa, la build e il runtime di un linguaggio specifico, utilizzare la competenza di quel linguaggio (ad esempio Authoring-Java-sdk-tasks, Authoring-go-sdk-tasks).
