Airflow 언어 SDK를 위한 언어 중립적 기반 — DAG가 Python에 유지되는 동안 Python이 아닌 언어로 작업 논리를 구현합니다. 사용자가 다른 언어(Java, Kotlin, Go 또는 기타 JVM/기본 언어)로 Airflow 작업을 실행하려고 할 때 Python `@task.stub`가 기본 작업 코드와 어떻게 쌍을 이루는지, 작업/DAG ID가 양측에서 어떻게 일치해야 하는지, 데이터가 XCom을 통해 JSON으로 전달되는 방법 또는 어떤 언어 SDK가 존재하는지 묻습니다. 이 기술은 공유 Python-stub 패턴과 개념 모델을 소유합니다. 특정 언어의 기본 API, 빌드 및 런타임의 경우 해당 언어의 기술을 사용합니다(예: 저작-java-sdk-tasks, 저작-go-sdk-tasks).
