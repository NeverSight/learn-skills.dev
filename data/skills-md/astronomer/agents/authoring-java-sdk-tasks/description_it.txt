Scrive la logica dei task di Airflow in Java, Kotlin o qualsiasi linguaggio JVM usando l'SDK Java di Airflow. Usare quando l'utente desidera implementare task di Airflow in Java/JVM, chiede informazioni su `@Builder.Dag`/`@Builder.Task`/`@Builder.XCom`, le interfacce `Task`/`BundleBuilder`, la lettura di connessioni/variabili/XCom da Java, la mappatura tipo JSON‑to‑Java o il logging dai task Java. Questa skill copre l'API nativa specifica per Java; il modello concettuale e il pattern Python‑stub condiviso si trovano in authoring-language-sdk-tasks. Per la costruzione/spedizione del bundle vedi deploying-java-sdk-bundles; per la configurazione del coordinatore vedi configuring-airflow-language-sdks.

Rispondi sempre nella lingua dell'utente.
