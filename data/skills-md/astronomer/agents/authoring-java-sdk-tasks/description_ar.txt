يكتب منطق مهام Airflow بلغة Java أو Kotlin أو أي لغة JVM باستخدام Airflow Java SDK. يُستَخدم عندما يرغب المستخدم في تنفيذ مهام Airflow بلغة Java/JVM، أو يسأل عن `@Builder.Dag`/`@Builder.Task`/`@Builder.XCom`، أو واجهات `Task`/`BundleBuilder`، أو قراءة الاتصالات/المتغيّرات/XComs من Java، أو تحويل JSON إلى أنواع Java، أو سجلات logging من مهام Java. تغطّي هذه المهارة واجهة برمجة التطبيقات الأصلية الخاصة بـ Java؛ أما نمط الـ Python‑stub المشترك والنموذج المفهومي فهما موجودان في authoring-language-sdk-tasks. لبناء/شحن الحزمة راجع deploying-java-sdk-bundles؛ لتكوين المنسق راجع configuring-airflow-language-sdks.

يرجى دائمًا الرد بلغة المستخدم.
