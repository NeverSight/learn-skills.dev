Airflow Java SDK를 사용하여 Java, Kotlin 또는 모든 JVM 언어로 Airflow 작업 로직을 작성합니다. 사용자가 Java/JVM으로 Airflow 작업을 구현하고 싶거나 `@Builder.Dag`/`@Builder.Task`/`@Builder.XCom`, `Task`/`BundleBuilder` 인터페이스, Java에서 연결/변수/XCom을 읽는 방법, JSON‑to‑Java 타입 매핑, 혹은 Java 작업에서 로깅에 대해 질문할 때 사용합니다. 이 스킬은 Java 전용 네이티브 API를 다루며, 공유되는 Python 스텁 패턴 및 개념 모델은 authoring-language-sdk-tasks에 있습니다. 번들을 빌드·배포하려면 deploying-java-sdk-bundles를, 코디네이터 설정을 보려면 configuring-airflow-language-sdks를 참고하십시오.
