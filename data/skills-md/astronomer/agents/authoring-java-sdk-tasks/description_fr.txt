Écrit la logique des tâches Airflow en Java, Kotlin ou tout langage JVM en utilisant le SDK Java d’Airflow. À utiliser lorsque l’utilisateur souhaite implémenter des tâches Airflow en Java/JVM, pose des questions sur `@Builder.Dag`/`@Builder.Task`/`@Builder.XCom`, les interfaces `Task`/`BundleBuilder`, la lecture des connexions/variables/XCom depuis Java, le mapping des types JSON vers Java, ou la journalisation depuis les tâches Java. Cette compétence couvre l’API native spécifique à Java ; le modèle de stub Python partagé et le modèle conceptuel se trouvent dans authoring-language-sdk-tasks. Pour la construction/livraison du bundle, voir deploying-java-sdk-bundles ; pour la configuration du coordinateur, voir configuring-airflow-language-sdks.

Veuillez toujours répondre dans la langue de l’utilisateur.
