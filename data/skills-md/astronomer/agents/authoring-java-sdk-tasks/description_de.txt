Schreibt Airflow‑Aufgabenlogik in Java, Kotlin oder einer anderen JVM‑Sprache mithilfe des Airflow Java SDK. Verwenden Sie dies, wenn der Nutzer Airflow‑Aufgaben in Java/JVM implementieren möchte, Fragen zu `@Builder.Dag`/`@Builder.Task`/`@Builder.XCom`, den Interfaces `Task`/`BundleBuilder`, dem Auslesen von Verbindungen/Variablen/XComs aus Java, der JSON‑zu‑Java‑Typzuordnung oder dem Logging aus Java‑Aufgaben hat. Diese Fähigkeit deckt die Java‑spezifische native API ab; das gemeinsame Python‑Stub‑Muster und das konzeptuelle Modell befinden sich in authoring-language-sdk-tasks. Für das Erstellen/Verteilen des Bundles siehe deploying-java-sdk-bundles; für die Koordinator‑Konfiguration siehe configuring-airflow-language-sdks.

Bitte immer in der Sprache des Benutzers antworten.
