Пишет логику задач Airflow на Java, Kotlin или любом другом JVM‑языке, используя Airflow Java SDK. Используйте, когда пользователь хочет реализовать задачи Airflow на Java/JVM, задаёт вопросы о `@Builder.Dag`/`@Builder.Task`/`@Builder.XCom`, интерфейсах `Task`/`BundleBuilder`, чтении соединений/переменных/XCom из Java, сопоставлении типов JSON‑Java или логировании из Java‑задач. Этот навык охватывает специфичный для Java нативный API; общая Python‑заглушка и концептуальная модель находятся в authoring-language-sdk-tasks. Для сборки/развёртывания бандла см. deploying-java-sdk-bundles; для настройки координатора см. configuring-airflow-language-sdks.  

Пожалуйста, всегда отвечайте на языке пользователя.
