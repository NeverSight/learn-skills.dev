Escribe la lógica de tareas de Airflow en Java, Kotlin o cualquier lenguaje JVM usando el Airflow Java SDK. Úsalo cuando el usuario quiera implementar tareas de Airflow en Java/JVM, pregunte sobre `@Builder.Dag`/`@Builder.Task`/`@Builder.XCom`, las interfaces `Task`/`BundleBuilder`, leer conexiones/variables/XComs desde Java, el mapeo de tipos JSON a Java o registrar logs desde tareas Java. Esta habilidad cubre la API nativa específica de Java; el patrón de stub compartido de Python y el modelo conceptual se encuentran en authoring-language-sdk-tasks. Para construir/desplegar el bundle consulta deploying-java-sdk-bundles; para la configuración del coordinador consulta configuring-airflow-language-sdks. Por favor, responde siempre en el idioma del usuario.
