使用 Airflow Java SDK 用 Java、Kotlin 或任何 JVM 语言编写 Airflow 任务逻辑。当用户想要在 Java/JVM 中实现 Airflow 任务、询问 `@Builder.Dag`/`@Builder.Task`/`@Builder.XCom`、`Task`/`BundleBuilder` 接口、从 Java 读取连接/变量/XCom、JSON 与 Java 类型的映射，或在 Java 任务中进行日志记录时，请使用本技能。本技能覆盖 Java 专属的原生 API；共享的 Python 存根模式和概念模型位于 authoring-language-sdk-tasks。有关构建/发布 Bundle，请参见 deploying-java-sdk-bundles；有关协调器配置，请参见 configuring-airflow-language-sdks。
