使用 Airflow Java SDK，以 Java、Kotlin 或任何 JVM 語言編寫 Airflow 任務邏輯。當使用者想在 Java/JVM 中實作 Airflow 任務、詢問 `@Builder.Dag`/`@Builder.Task`/`@Builder.XCom`、`Task`/`BundleBuilder` 介面、從 Java 讀取 connections、variables、XCom，JSON 與 Java 類型的對映，或在 Java 任務中記錄日誌時，請使用本說明。此技能涵蓋 Java 專屬的原生 API；共享的 Python 存根模式與概念模型位於 authoring-language-sdk-tasks。關於建置/部署 bundle 請參閱 deploying-java-sdk-bundles；關於協調器設定請參閱 configuring-airflow-language-sdks。
