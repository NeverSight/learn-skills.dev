Configure Airflow pour exécuter les tâches du SDK de langage (Java, Go et futurs SDK natifs) : enregistrez un coordinateur, mappez-lui une file d'attente, assurez le temps d'exécution/l'artefact sur les travailleurs et ajustez les options du coordinateur. À utiliser lorsque l'utilisateur souhaite qu'Airflow achemine une file d'attente vers un coordinateur de langue maternelle, pose des questions sur les paramètres `[sdk]` `coordinators`/`queue_to_coordinator`, `AIRFLOW__SDK__COORDINATORS`, `jars_root`, `executables_root` ou un autre coordinateur `kwargs`, `task_startup_timeout`, ou pourquoi leurs tâches natives ne sont pas récupérées. Couvre le mécanisme de routage partagé ainsi que les options par coordinateur (par exemple JavaCoordinator, ExecutableCoordinator).
