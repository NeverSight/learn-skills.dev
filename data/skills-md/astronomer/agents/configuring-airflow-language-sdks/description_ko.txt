언어 SDK 작업(Java, Go 및 향후 기본 SDK)을 실행하도록 Airflow를 구성합니다. 코디네이터를 등록하고, 대기열을 매핑하고, 작업자의 런타임/아티팩트를 확인하고, 코디네이터 옵션을 조정합니다. 사용자가 Airflow가 대기열을 기본 언어 코디네이터로 라우팅하도록 할 때 `[sdk]` `coordinators`/`queue_to_coordinator` 설정, `AIRFLOW__SDK__COORDINATORS`, `jars_root`, `executables_root` 또는 기타 코디네이터 `kwargs`, `task_startup_timeout` 또는 기본 작업이 선택되지 않는 이유에 대해 질문할 때 사용합니다. 공유 라우팅 메커니즘과 코디네이터별 옵션(예: JavaCoordinator, ExecutableCoordinator)을 다룹니다.
