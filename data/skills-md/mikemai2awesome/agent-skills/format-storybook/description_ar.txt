نظّم ونظم ملفات Storybook لتوسيعها باستخدام أنماط مختبرة في ساحة المعركة. استنادًا إلى «A Storybook format that scales with you» لكاسوندرا روبرتس. استخدم هذه المهارة دائمًا عند إنشاء أو تعديل أي ملف قصة في Storybook، أو كتابة ملفات القالب، أو تنظيم مكتبة المكوّنات، أو إعداد اختبارات الانحدار البصري باستخدام Chromatic، أو عندما يسأل المستخدم أي شيء عن Storybook — حتى الأسئلة العارضة حول بنية الملفات، أو التحكمات، أو args، أو كيفية توثيق مكوّن.
