Struttura e organizza i file di Storybook per la scalabilità usando pattern collaudati. Basato su “A Storybook format that scales with you” di Cassondra Roberts. Usa sempre questa competenza quando crei o modifichi qualsiasi file di storia di Storybook, scrivi file di template, organizzi una libreria di componenti, configuri test di regressione visiva con Chromatic, o quando l'utente chiede qualsiasi cosa su Storybook — anche domande informali sulla struttura dei file, i controlli, gli argomenti o su come documentare un componente.

Per favore, rispondi sempre nella lingua dell'utente.
