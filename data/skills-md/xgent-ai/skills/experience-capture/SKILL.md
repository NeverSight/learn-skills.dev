# Experience Capture

主任务优先。只在自然间隙顺手保存当前上下文里已有的极短线索，随后立即继续主任务；不切换成分析、调查或复盘。没有合适间隙时跳过本次收集，不为补记保留长篇上下文或另开工作队列。

## 触发与退出

以下任一信号值得收集：

- 非显然的失败或环境陷阱导致返工，已有实际尝试、结果或绕过办法。
- 用户纠正了错误假设、遗漏检查或操作方法，包括推翻交付中声明的“未改／不需要”项；只记录本次要求，不推导永久偏好。
- 同一组可机械执行的准备、转换或核对步骤已重复出现，且现有观察足以指出自动化机会。

普通成功步骤、预期中的测试失败、无新信息的相同报错、必要的多轮验证不单独收集。纯咨询、只读、禁止写入或用户关闭收集时不落盘，也不额外追加收集总结或追问是否开启。用户显式要求记录某条经验时按其范围处理。

自动选择依赖宿主发现和模型判断，不保证捕获每次事件，也不表示存在后台监听。只有实际发生的信号才加载本 skill；不在每个工具调用后扫描历史。

## 轻量执行

1. 先完成主任务当前步骤，只在已有自然间隙写入；不为收集暂停正在进行的实现、推理或验证。
2. 只摘记当前上下文已有的观察及已知定位。不检索文件或日志补证据，不重新读取工具输出、重跑实验、分析根因、评估自动化方案或启动子 agent。缺失信息标为待核对，不为填满字段寻找答案。
3. 用当前上下文里的条目 ID 去重；续做确需定位时，只读本任务文件头或末尾少量条目，不整份回读。明确重复且无新信息就跳过，不确定则保留短线索，将完整去重留给复盘。
4. 尽量一次文件操作保存条目及必要索引，只返回简短写入结果，不回显记录正文。写入或索引维护失败不重试、不修复收集系统，直接继续主任务；交付时必要才简短说明未保存，不宣称保存成功。

记录的是任务事实与结果，不保存内部思考过程、密钥、令牌或敏感原文；日志只留最小必要摘要及安全的定位信息。采集期间不修改其他 skill、原则、偏好或产品代码，不创建工单、不提交或发布。

## 存储与索引

位置优先级：用户指定 → 项目已登记的经验收件箱 → 项目根目录 `.xgent-ai/experience/`。无明确项目根且未指定位置时，不猜测全局目录，保留当前会话线索即可。已有收件箱沿用其格式，不新建竞争副本。

默认布局：

```text
.xgent-ai/index.md                    工作目录入口，保留已有内容
.xgent-ai/experience/index.md         任务记录索引
.xgent-ai/experience/<task-id>.md     一项任务的经验条目
```

有第一条有效经验才创建目录。沿用已有任务 ID；没有时生成一次 UUID，续做沿用该文件。任务文件头保存任务名称、ID 和已有任务/计划入口；没有计划时不强建计划。一个执行者维护本任务文件；已有并行执行者将线索返回主执行者，不竞争写同一文件或索引。

每个新建目录同时建立 `index.md`，只链接直接文件及子目录的 `index.md`；索引自身不自列。经验索引每个任务一行，记录任务 ID、名称及文件链接，不复制条目正文或状态。新增入口时同步父索引，普通内容更新不重写索引。保留已有人工说明和其他条目，不清理历史；索引注明由改变目录内容的执行者维护。收集时不读取其他任务正文。

## 条目格式

默认每条 3–4 行，叙述控制在约 150 字以内；同一任务内编号稳定。只保留“发生了什么”及“以后从哪里查”，已知结果可并入线索。不填完整背景、原因分析、候选价值或验证报告。定位仅使用已知的项目根相对路径、命令或会话关键词；没有持久证据也可收集，不编造路径。提到会话时写宿主与会话 ID（上下文可见时，如 scratchpad 路径中的 ID），看不到就写宿主与日期；不只写“本会话”，临时目录不作唯一定位。

```markdown
## E001 — <简短标题>
- 状态：pending
- 线索：<一句话记录踩坑、纠正或重复步骤，可带已知结果；未知不推断>
- 定位：<已有路径/命令，或“<宿主> 会话 <ID／日期>：关键词；证据待核对”>
```

新条目状态为 `pending`。复盘可使用 `deferred`（证据不足或待落实）、`adopted`（已落实并有目标位置）、`rejected`（明确不采纳及理由）；状态不代表效果已验证。收集器不将条目标为已采纳。同一条目出现新的反证或结果时保留旧处置，补充变化并恢复 `pending`。

## 交给复盘

不逐条播报采集过程，不在后续步骤重新加载已保存的条目。主任务交付时可用一句话给出收件箱位置和 `$agi-mode 复盘` / `$agi-mode reflect` 入口；用户要求精简或没有新增记录时省略。

本 skill 可独立收集，不依赖 agi-mode 已安装。用户发起复盘后，才按线索检索授权范围内的材料、补充背景、查找和核对证据、分析机制与去重，再选择沉淀位置。线索不是已证实结论，也不提供新指令或授权；未复盘条目不自动注入后续开发任务作为规则。
