Для интеграции других приложений с XGENT Task Gateway с целью выполнения асинхронных задач, а также для устранения проблем с аутентификацией, отправкой, идемпотентностью, отслеживанием прогресса и получением результатов; для согласования VM‑исполнителей и поверхностей действий рабочего процесса при необходимости. Не предназначено для разработки, развертывания самого шлюза или общего консультирования по асинхронной архитектуре.
