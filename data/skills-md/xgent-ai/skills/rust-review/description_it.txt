Revisiona il codice Rust esistente per idiomaticità, progettazione dell'API, gestione degli errori, sicurezza e manutenibilità, e produci un rapporto prioritizzato in cui ogni constatazione cita la regola violata e fornisce una correzione concreta. Usa questo ogni volta che l'utente chiede di revisionare, auditare, criticare, valutare o “controllare” codice Rust, un crate, un modulo, un file .rs, un diff o una pull request, oppure chiede cosa c'è di sbagliato nel loro Rust o come renderlo più idiomatico, anche se non dice “review”. Si abbina alla skill rust-best-practices, che riguarda la scrittura di nuovo codice.

Per favore rispondi sempre nella lingua dell'utente.
