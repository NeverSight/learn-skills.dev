Portiere Code von C, C++, Python, Go, JavaScript oder TypeScript in idiomatisches Rust, das das ursprüngliche Verhalten beibehält: Ownership statt manueller Speicherverwaltung, Result statt Fehlercodes und Ausnahmen, Enums statt Flag‑Ints und Magic‑Strings sowie Tests, die beweisen, dass die Portierung übereinstimmt. Verwende dies immer, wenn der Nutzer bittet, Code zu portieren, zu übersetzen, zu konvertieren, zu migrieren oder in Rust umzuschreiben („rewrite this in Rust“, „what would this look like in Rust“, „move this module to Rust“), selbst wenn er nicht explizit „port“ sagt. Kombiniert mit der rust‑best‑practices‑Fähigkeit, die den Stil des Zielcodes abdeckt.

Bitte immer in der Sprache des Nutzers antworten.
