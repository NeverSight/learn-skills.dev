将 C、C++、Python、Go、JavaScript 或 TypeScript 代码迁移到惯用的 Rust，保持原有行为：使用所有权替代手动内存管理，使用 Result 替代错误码和异常，使用枚举替代标志整数和魔法字符串，并编写测试以证明迁移后的代码匹配原行为。无论用户是要求迁移、翻译、转换、迁移或改写代码（如 “rewrite this in Rust”、 “what would this look like in Rust”、 “move this module to Rust”），都使用此规则，即使他们没有说 “port”。该规则与 rust-best-practices 技能配合，涵盖目标代码的风格。

请始终使用用户的语言作答。
