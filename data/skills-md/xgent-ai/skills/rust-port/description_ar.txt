انقل الكود من C أو C++ أو Python أو Go أو JavaScript أو TypeScript إلى Rust بأسلوبه المألوف مع الحفاظ على السلوك الأصلي: الاعتماد على الملكية بدلاً من إدارة الذاكرة يدويًا، واستخدام Result بدلاً من رموز الأخطاء والاستثناءات، واستخدام enums بدلاً من أعداد العلميات والسلاسل السحرية، وإضافة اختبارات تُثبت أن النقل يطابق الأصل. استخدم هذا كلما طلب المستخدم نقل أو ترجمة أو تحويل أو ترحيل أو إعادة كتابة الكود إلى Rust ("أعد كتابة هذا بـ Rust"، "كيف سيبدو هذا بـ Rust"، "انقل هذه الوحدة إلى Rust")، حتى وإن لم يذكر كلمة "نقل". يتكامل مع مهارة rust‑best‑practices التي تغطي أسلوب الكود المستهدف. يرجى دائمًا الرد بلغة المستخدم.
