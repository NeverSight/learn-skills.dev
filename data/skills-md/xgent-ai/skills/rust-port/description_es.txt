Portar código desde C, C++, Python, Go, JavaScript o TypeScript a Rust idiomático que mantenga el comportamiento original: ownership en lugar de gestión manual de memoria, Result en lugar de códigos de error y excepciones, enums en lugar de enteros de banderas y strings mágicos, y pruebas que demuestren que el puerto coincide. Usa esto siempre que el usuario solicite portar, traducir, convertir, migrar o reescribir código en Rust (“rewriter esto en Rust”, “¿cómo se vería esto en Rust?”, “mover este módulo a Rust”), incluso si no dice “port”. Se combina con la habilidad rust-best-practices, que cubre el estilo del código objetivo.

Por favor, responde siempre en el idioma del usuario.
