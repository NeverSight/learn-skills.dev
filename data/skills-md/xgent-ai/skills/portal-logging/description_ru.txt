Подключите логи/телеметрию приложения к сервису «Логи и мониторинг» портала: настройка коллектора (stdout контейнера / чтение файла / прямой пуш из приложения), идентификация записи (обмен токеном сервис‑аккаунта или долгосрочный ключ доступа), область `observability.ingest`, конечная точка ingest `/svc/observability/v1/ingest/...`, именование потоков типа `app_<your_key>_<stream_name>` и единые соглашения по полям логов во всех приложениях. Для любой задачи, связанной с «хочу, чтобы логи моего сервиса отображались в Логах и мониторинге», «подключить коллектор / fluent‑bit / драйвер логов Docker», «запись лога возвращает 401 / 403 / область пуста», «записано, но не видно в UI / поток не найден», «одна ошибка разбита на десятки записей / нельзя понять, какая из них ошибка», обязательно используйте этот навык в первую очередь — даже если пользователь просто говорит «подключить логи».
