将应用的日志/遥测连接到门户的“日志与监控”服务：收集器接线（容器 stdout / 文件尾部 / 应用内直接推送），写入身份（服务账号令牌交换或长期访问密钥），`observability.ingest` 范围，`/svc/observability/v1/ingest/...` 写入端点，`app_<your_key>_<stream_name>` 流命名以及跨应用的统一日志字段规范。对于任何涉及 “我希望我的服务日志在日志与监控中可见”、 “连接收集器 / fluent‑bit / Docker 日志驱动”、 “日志写入返回 401 / 403 / 范围为空”、 “写入成功但 UI 中没有显示 / 未找到流”、 “单个错误被拆分成数十条记录 / 无法判断哪个是错误” 的任务，请务必首先使用此技能——即使用户仅说 “接入日志”。在将应用的日志或遥测接入门户可观测性服务时使用：收集器设置、写入凭证和范围、流命名、日志字段约定，以及常见的失败情况（范围为空、写入返回 403、查询返回 401、记录永不出现）。
