將應用程式的日誌/遙測連接到平台的「日誌與監控」服務：設定收集器（容器 stdout / 檔案尾端 / 應用內直接輸出）、寫入身分（服務帳戶代幣交換或長期存取金鑰）、`observability.ingest` 範圍、`/svc/observability/v1/ingest/…` ingest 端點、類似 `app_<your_key>_<stream_name>` 的串流命名，以及跨應用程式的統一日誌欄位慣例。對於任何涉及「我想在日誌與監控中看到我的服務日誌」、
「連接收集器 / fluent‑bit / Docker 日誌驅動」、
「寫入日誌返回 401 / 403 / 範圍為空」、
「日誌已寫入但在 UI 中看不到 / 找不到串流」、
「單一錯誤被分割成數十筆條目 / 無法判斷哪一筆是錯誤」的任務，請務必先使用此技能——即使使用者只說「掛接日誌」。在將應用程式的日誌或遙測接入平台可觀測性服務時使用：收集器設定、寫入憑證與範圍、串流命名、日誌欄位慣例，以及常見失敗情況（範圍為空、寫入 403、查詢 401、記錄永不顯示）。
