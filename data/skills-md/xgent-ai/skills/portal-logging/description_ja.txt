アプリのログ/テレメトリをポータルの「Logs and Monitoring」サービスに接続する：コレクタを設定する（コンテナ stdout / ファイル tail / アプリ内直接パブリッシュ）、書き込み認証情報を構成する（サービスアカウントトークン交換または長期アクセスキー）、`observability.ingest` スコープを使用する、データを `/svc/observability/v1/ingest/...` に送信する、ストリーム名は `app_<yourkey>_<streamname>` とし、アプリ間で統一されたログフィールドスキーマに従う。タスクが「サービスのログを Logs and Monitoring に可視化する」「コレクタ / fluent‑bit / Docker ログドライバを接続する」「ログ書き込みが 401 / 403 / 空のスコープで返る」「書き込みは成功するが UI に何も表示されない / ストリームが見つからない」「単一のエラーが何十件ものレコードに分割され、どれがエラーか判別できない」などの場合は、ユーザーが「ログを接続する」だけと言っていても、まずこのスキルを適用してから進めること。
