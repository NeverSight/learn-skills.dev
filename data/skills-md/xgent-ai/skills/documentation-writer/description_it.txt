Scrivi e aggiorna la documentazione tecnica basata sui fatti del codice: README, documentazione API (interfacce HTTP / OpenAPI / riferimenti a librerie e SDK), documentazione dell'architettura, documenti di descrizione del codebase (docs/codebase/ set completo), manuali utente e guide operative. Ogni conclusione può essere ricondotta ai file nel repository e la formulazione deve essere priva di tracce di AI; quando sono necessari diagrammi di architettura, flowchart o diagrammi di sequenza, usa prima la skill archify installata localmente per generare i diagrammi e, se non disponibile, utilizza Mermaid. Ogni volta che un utente richiede di scrivere o aggiornare un README, integrare la documentazione API, generare OpenAPI, scrivere la documentazione dell'architettura, disegnare l'architettura di sistema, organizzare il repository, scrivere la documentazione di onboarding per i nuovi arrivati, redigere manuali utente / istruzioni d'uso / tutorial, o sincronizzare la documentazione dopo modifiche al codice, utilizza questa skill, anche se l'utente non menziona la parola “documentazione”. Usa per README, riferimento API/OpenAPI/SDK, documenti di architettura, documenti di onboarding del codebase, manuali utente, tutorial e guide pratiche, o per sincronizzare la documentazione dopo modifiche al codice. Per favore rispondi sempre nella lingua dell'utente.
