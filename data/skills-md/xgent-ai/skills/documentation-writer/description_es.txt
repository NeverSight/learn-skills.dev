Redactar y actualizar documentación técnica basada en hechos del código: README, documentación de API (interfaces HTTP / OpenAPI / referencias de bibliotecas y SDK), documentación de arquitectura, documentación de descripción del código (docs/codebase/ conjunto completo), manuales de usuario y guías de operación. Cada conclusión puede rastrearse a archivos del repositorio, y la redacción elimina cualquier sesgo de IA; cuando se necesiten diagramas de arquitectura, diagramas de flujo o diagramas de secuencia, si la habilidad archify instalada localmente está disponible, úsela primero para generar los diagramas, de lo contrario recurra a Mermaid. Cada vez que un usuario solicite escribir o actualizar un README, complementar la documentación de API, generar OpenAPI, crear documentación de arquitectura, dibujar la arquitectura del sistema, organizar el repositorio, redactar documentación de incorporación para nuevos miembros, producir manuales de usuario / instrucciones de uso / tutoriales, o sincronizar la documentación después de cambios en el código, esta habilidad debe usarse—incluso si el usuario no menciona explícitamente la palabra “documentación”. Use para READMEs, referencia de API/OpenAPI/SDK, documentos de arquitectura, documentos de incorporación al código, manuales de usuario, tutoriales y guías paso a paso, o sincronizar documentos tras cambios de código.
