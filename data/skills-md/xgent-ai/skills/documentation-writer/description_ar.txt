اكتب وحدث الوثائق التقنية بناءً على حقائق الكود: README، وثائق API (واجهات HTTP / OpenAPI / مراجع المكتبة وSDK)، وثائق الهندسة المعمارية، مستندات وصف قاعدة الشيفرة (docs/codebase/ مجموعة كاملة)، أدلة المستخدم وأدلة التشغيل. يمكن تتبع كل استنتاج إلى الملفات الموجودة في المستودع، ويجب أن تكون الصياغة خالية من طعم الذكاء الاصطناعي؛ عندما تكون هناك حاجة إلى مخططات بنية، مخططات تدفق، أو مخططات تسلسل، استخدم مهارة archify المثبتة محليًا لتوليد المخططات أولاً، وإذا لم تتوفر استخدم Mermaid. كلما طلب المستخدم كتابة أو تحديث README، أو إكمال وثائق API، أو توليد OpenAPI، أو كتابة وثائق الهندسة المعمارية، أو رسم بنية النظام، أو تنظيم المستودع، أو كتابة وثائق التعريف للمستجدين، أو كتابة أدلة المستخدم / تعليمات الاستخدام / الدروس التعليمية، أو مزامنة الوثائق بعد تغييرات الكود، استخدم هذه المهارة، حتى وإن لم يذكر المستخدم كلمة “وثائق”. استخدمها للـ READMEs، ومراجع API/OpenAPI/SDK، ووثائق الهندسة المعمارية، ووثائق تعريف قاعدة الشيفرة للمستجدين، وأدلة المستخدم، والدروس التعليمية وأدلة “كيف‑تفعل”، أو مزامنة الوثائق بعد تغييرات الكود.
