Escáner de seguridad de bases de código impulsado por IA que razona sobre el código como un investigador de seguridad — rastreando flujos de datos, comprendiendo interacciones de componentes y detectando vulnerabilidades que las herramientas de coincidencia de patrones pasan por alto. Usa esta habilidad cuando te pidan escanear código en busca de vulnerabilidades de seguridad, encontrar errores, comprobar inyección SQL, XSS, inyección de comandos, claves de API expuestas, secretos codificados, dependencias inseguras, problemas de control de acceso, o cualquier solicitud como “¿mi código es seguro?”, “revisar problemas de seguridad”, “auditar esta base de código” o “verificar vulnerabilidades”. También utilízala proactivamente para una revisión de seguridad del código modificado antes de un commit o despliegue — especialmente cambios en autenticación, API, base de datos, dependencias o archivos de configuración. Cubre el OWASP Top 10: fallas de inyección, errores de autenticación y control de acceso, exposición de secretos, criptografía débil, configuración de seguridad incorrecta, dependencias inseguras y problemas de lógica empresarial en JavaScript, TypeScript, Python, Java, PHP, Go, Ruby y Rust.
