KI‑gestützter Code‑Basis‑Sicherheits‑Scanner, der Code wie ein Sicherheitsexperte analysiert – verfolgt Datenflüsse, versteht Komponenteninteraktionen und entdeckt Schwachstellen, die Muster‑Matching‑Tools übersehen. Nutze diese Fähigkeit, wenn du aufgefordert wirst, Code auf Sicherheitslücken zu scannen, Bugs zu finden, nach SQL‑Injection, XSS, Befehlsinjektion, exponierten API‑Schlüsseln, fest codierten Geheimnissen, unsicheren Abhängigkeiten, Zugriffssteuerungsproblemen oder ähnlichen Anfragen wie „Ist mein Code sicher?“, „Überprüfung auf Sicherheitsprobleme“, „Audit dieses Code‑Bases“ oder „Nach Schwachstellen suchen“ zu suchen. Verwende sie auch proaktiv für eine Sicherheitsprüfung von geändertem Code vor einem Commit oder Deployment – besonders bei Änderungen an Authentifizierung, API, Datenbank, Abhängigkeiten oder Konfigurationsdateien. Deckt die OWASP Top 10 ab: Injektionsfehler, Authentifizierungs‑ und Zugriffssteuerungsfehler, Offenlegung von Geheimnissen, schwache Kryptografie, Fehlkonfigurationen, unsichere Abhängigkeiten und Geschäftslogik‑Probleme in JavaScript, TypeScript, Python, Java, PHP, Go, Ruby und Rust. Bitte immer in der Sprache des Benutzers antworten.
