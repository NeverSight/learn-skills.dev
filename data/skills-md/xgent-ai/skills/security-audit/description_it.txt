Scanner di sicurezza del codebase alimentato dall'AI che ragiona sul codice come un ricercatore di sicurezza — tracciando i flussi di dati, comprendendo le interazioni tra componenti e catturando vulnerabilità che gli strumenti basati su pattern non rilevano. Usa questa capacità quando ti viene chiesto di scansionare il codice alla ricerca di vulnerabilità di sicurezza, trovare bug, verificare SQL injection, XSS, injection di comandi, chiavi API esposte, segreti hardcoded, dipendenze non sicure, problemi di controllo degli accessi, o qualsiasi richiesta come “il mio codice è sicuro?”, “revisiona per problemi di sicurezza”, “audita questo codebase” o “controlla le vulnerabilità”. Usala anche proattivamente per un controllo di sicurezza del codice modificato prima di un commit o di un deployment — soprattutto per modifiche a autenticazione, API, database, dipendenze o file di configurazione. Copre l'OWASP Top 10: vulnerabilità di injection, bug di autenticazione e controllo degli accessi, esposizione di segreti, crittografia debole, errata configurazione della sicurezza, dipendenze non sicure e problemi di logica di business, per JavaScript, TypeScript, Python, Java, PHP, Go, Ruby e Rust.
