Scanner de sécurité de base de code alimenté par IA qui raisonne sur le code comme un chercheur en sécurité — traçant les flux de données, comprenant les interactions entre composants et détectant les vulnérabilités que les outils de correspondance de motifs manquent. Utilisez cette compétence lorsqu’on vous demande d’analyser le code à la recherche de vulnérabilités de sécurité, de trouver des bugs, de vérifier les injections SQL, XSS, les injections de commandes, les clés API exposées, les secrets codés en dur, les dépendances non sécurisées, les problèmes de contrôle d’accès, ou toute demande telle que « mon code est‑il sécurisé ? », « revue des problèmes de sécurité », « audit de cette base de code » ou « vérification des vulnérabilités ». Utilisez‑la également de façon proactive pour une vérification de sécurité du code modifié avant un commit ou un déploiement — en particulier les changements d’authentification, d’API, de base de données, de dépendances ou de fichiers de configuration. Couvre le OWASP Top 10 : défauts d’injection, bugs d’authentification et de contrôle d’accès, exposition de secrets, cryptographie faible, mauvaise configuration de sécurité, dépendances non sécurisées et problèmes de logique métier, pour JavaScript, TypeScript, Python, Java, PHP, Go, Ruby et Rust.
