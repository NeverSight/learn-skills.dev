AI 驅動的代碼庫安全掃描器，能像安全研究人員一樣推理代碼——追蹤資料流、了解元件交互，捕捉模式匹配工具漏掉的漏洞。當被要求掃描代碼的安全漏洞、尋找錯誤、檢查 SQL 注入、XSS、命令注入、暴露的 API 金鑰、硬編碼密鑰、不安全的相依性、存取控制問題，或任何類似「我的代碼安全嗎？」、「檢查安全問題」、「審核此代碼庫」或「檢測漏洞」的請求時，請使用此技能。也可主動在提交或部署前對變更的代碼進行安全檢查——特別是對認證、API、資料庫、相依性或設定檔的變更。涵蓋 OWASP Top 10：注入缺陷、認證與存取控制漏洞、機密暴露、弱加密、安全配置錯誤、不安全的相依性以及業務邏輯問題，支援 JavaScript、TypeScript、Python、Java、PHP、Go、Ruby 與 Rust。
