Используется для создания или обновления сайтов документации или посадочных страниц с Rustify Docs; посадочная страница должна пройти UI‑цикл для уточнения привлекательности первого экрана и пути конверсии. Не предназначено для разработки фреймворка Rustify или задач, назначенных другим технологиям построения сайтов.
