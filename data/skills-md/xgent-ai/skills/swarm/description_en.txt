Form and command a team of parallel-working agents to complete a task: choose the mechanism (backend sub‑agent / dynamic workflow / agent team), select the team mode, design roles and prompts, then, after confirmation, orchestrate execution and wrap‑up. Whenever a user says “create a team / form a team / start a team to do this / team operation / swarm / multi‑agent collaboration / parallel agents / spawn teammates / run several agents in parallel / product team / requirement review team / audit team / review this PR together,” or runs `/swarm`, or hands over a task that clearly requires multiple people to divide the work (cross‑layer new feature, full‑database audit, hard‑to‑find bug, technology‑selection debate, large‑scale refactoring/migration, requirement design and clarification review), this skill must be used—even if the user didn’t mention the word “team.” It is also used to decide whether the task actually needs a team: often a backend sub‑agent or dynamic workflow is cheaper and faster, and this skill will make that judgment first.
