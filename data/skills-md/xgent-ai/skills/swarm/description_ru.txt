Соберите и управляйте командой параллельно работающих агентов для выполнения задачи: выберите механизм (бэкенд‑подагент / динамический рабочий процесс / команда агентов), определите режим работы команды, разработайте роли и промпты, затем, после подтверждения, организуйте выполнение и подведите итоги. Каждый раз, когда пользователь говорит «создать команду», «сформировать команду», «запустить команду для этого», «операция команды», «рой», «многопользовательское сотрудничество», «параллельные агенты», «создать товарищей», «запустить несколько агентов параллельно», «продуктовая команда», «команда по проверке требований», «аудиторская команда», «просмотреть этот PR вместе», или использует команду `/swarm`, либо передаёт задачу, явно требующую нескольких людей для распределения работы (кросс‑уровневая новая функция, полный аудит базы данных, трудно отслеживаемый баг, дебаты по выбору технологии, масштабный рефакторинг/миграция, проектирование требований и их уточнение), этот навык должен быть задействован — даже если пользователь не упомянул слово «команда». Он также используется для определения, действительно ли задача требует команды: зачастую бэкенд‑подагент или динамический рабочий процесс дешевле и быстрее, и этот навык сначала принимает соответствующее решение.
