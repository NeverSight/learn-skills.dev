Formar y liderar un equipo de agentes que trabajen en paralelo para completar una tarea: elegir el mecanismo (subagente backend / flujo de trabajo dinámico / equipo de agentes), seleccionar el modo del equipo, diseñar roles y prompts, y tras la confirmación orquestar la ejecución y el cierre. Cada vez que un usuario diga “crear un equipo / formar un equipo / iniciar un equipo para hacer esto / operación en equipo / swarm / colaboración multi‑agente / agentes paralelos / generar compañeros de equipo / ejecutar varios agentes en paralelo / equipo de producto / equipo de revisión de requisitos / equipo de auditoría / revisar este PR juntos”, ejecute `/swarm`, o entregue una tarea que claramente requiera varias personas para dividir el trabajo (nueva característica cruzada de capas, auditoría completa de base de datos, error difícil de encontrar, debate de selección tecnológica, refactorización/migración a gran escala, revisión de diseño y aclaración de requisitos), asegúrese de usar esta habilidad—incluso si el usuario no dijo la palabra “equipo”. También se usa para determinar si una tarea realmente necesita un equipo: a menudo un subagente backend o un flujo de trabajo dinámico es más barato y rápido, y esta habilidad hará primero ese juicio. Por favor, siempre responda en el idioma del usuario.
