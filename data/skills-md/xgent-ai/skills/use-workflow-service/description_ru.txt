Используется для определения разделения труда между рабочими процессами и Agent + Skill, а также для интеграции других приложений/сервисов в рабочий процесс через портал; не предназначено для разработки, публикации самого рабочего процесса или простого подключения к исполнителю Task Gateway. Предоставляет рекомендации по выбору, оркестрации и вызову.
