Guía para escribir código Rust idiomático, basada en el manual de mejores prácticas de Apollo GraphQL y en patrones async para Tokio. Usa esta habilidad cuando: (1) escribas código o funciones Rust nuevas, (2) revises o refactores código Rust existente, (3) decidas entre tomar prestado o clonar, o entre diferentes patrones de propiedad, (4) implementes el manejo de errores con tipos Result, (5) optimices el código Rust para rendimiento, (6) escribas pruebas o documentación para proyectos Rust, (7) escribas Rust async con Tokio – tareas, canales, flujos, traits async, apagado elegante, (8) depures código async: deadlocks, runtimes bloqueados, cancelación, límites Send.

Por favor, responde siempre en el idioma del usuario.
