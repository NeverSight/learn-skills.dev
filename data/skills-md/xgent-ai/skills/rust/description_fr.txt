Guide pour écrire du code Rust idiomatique, basé sur le manuel de bonnes pratiques d'Apollo GraphQL ainsi que sur les modèles asynchrones pour Tokio. Utilisez cette compétence lorsque : (1) vous écrivez du nouveau code ou des fonctions Rust, (2) vous passez en revue ou refactorez du code Rust existant, (3) vous devez choisir entre emprunter, cloner ou des schémas de possession, (4) vous implémentez la gestion des erreurs avec les types Result, (5) vous optimisez le code Rust pour les performances, (6) vous rédigez des tests ou de la documentation pour des projets Rust, (7) vous écrivez du Rust asynchrone avec Tokio – tâches, canaux, flux, traits asynchrones, arrêt gracieux, (8) vous déboguez du code asynchrone : interblocages, runtimes bloqués, annulation, contraintes Send.
