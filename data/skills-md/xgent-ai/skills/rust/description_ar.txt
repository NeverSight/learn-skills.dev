دليل لكتابة كود Rust بأسلوب إيديوماتيكي، استنادًا إلى دليل أفضل الممارسات من Apollo GraphQL بالإضافة إلى أنماط async لـ Tokio. استخدم هذه المهارة عندما: (1) كتابة كود Rust أو وظائف جديدة، (2) مراجعة أو إعادة هيكلة كود Rust الحالي، (3) اتخاذ قرار بين الاستعارة مقابل الاستنساخ أو أنماط الملكية، (4) تنفيذ معالجة الأخطاء باستخدام أنواع Result، (5) تحسين كود Rust للأداء، (6) كتابة اختبارات أو توثيق لمشاريع Rust، (7) كتابة Rust غير متزامن باستخدام Tokio – المهام، القنوات، التدفقات، السمات غير المتزامنة، الإغلاق السلس، (8) تصحيح كود async: الأقفال المميتة، تشغيلات محجوبة، الإلغاء، قيود Send.
