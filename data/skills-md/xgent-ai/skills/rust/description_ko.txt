Apollo GraphQL의 베스트 프랙티스 핸드북과 Tokio 비동기 패턴을 기반으로 한 관용적인 Rust 코드 작성 가이드. 이 기술은 다음과 같은 경우에 사용하십시오: (1) 새로운 Rust 코드나 함수를 작성할 때, (2) 기존 Rust 코드를 검토하거나 리팩터링할 때, (3) 빌린(borrowing)과 복제(cloning) 또는 소유권 패턴 중 선택할 때, (4) Result 타입을 사용한 오류 처리를 구현할 때, (5) 성능을 위해 Rust 코드를 최적화할 때, (6) Rust 프로젝트에 대한 테스트나 문서를 작성할 때, (7) Tokio를 사용한 비동기 Rust를 작성할 때 – 작업, 채널, 스트림, 비동기 트레이트, 우아한 종료, (8) 비동기 코드를 디버깅할 때: 데드락, 차단된 런타임, 취소, Send 바운드. 항상 사용자의 언어로 응답해 주세요.
