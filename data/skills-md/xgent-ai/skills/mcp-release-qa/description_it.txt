Verifica un server MCP prima della pubblicazione eseguendo una sessione di protocollo reale, confrontando le capacità operative con il codice sorgente e la documentazione, testando i percorsi di errore e registrando prove riproducibili. Utilizza questa procedura quando distribuisci o revisioni un server MCP, uno strumento, una risorsa, un prompt, un catalogo o un percorso di installazione.
