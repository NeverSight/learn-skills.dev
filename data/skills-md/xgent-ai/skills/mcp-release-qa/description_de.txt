Überprüfen Sie einen MCP‑Server vor der Veröffentlichung, indem Sie eine reale Protokollsitzung durchführen, die Laufzeitfähigkeiten mit Quellcode und Dokumentation vergleichen, Fehlerpfade testen und reproduzierbare Beweise dokumentieren. Verwenden Sie dies, wenn Sie einen MCP‑Server, ein Tool, eine Ressource, einen Prompt, einen Katalog oder einen Installationspfad bereitstellen oder überprüfen.
