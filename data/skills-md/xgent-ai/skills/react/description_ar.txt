دليل كتابة ومراجعة كود React — الخطاطيف، التأثيرات، عمليات إعادة التصيير، وأداء المتصفح. استخدم هذه المهارة عندما: (1) كتابة أو مراجعة مكونات React وخطاطيف مخصصة، (2) كتابة أو تصحيح `useEffect` — تقرير ما إذا كان التأثير مطلوبًا أصلاً، (3) استخدام `useState` للقيم المستندة أو لمزامنة الحالة بين المكونات، (4) تشخيص عمليات إعادة التصيير غير الضرورية، الإغلاقات القديمة، أو مشاكل التخزين المؤقت، (5) إصلاح شلالات جلب البيانات، حالات السباق، أو طلبات مكررة، أو استخدام `use()` مع Suspense، (6) تحسين الرسم، الترطيب، تحميل الموارد، أو جافاسكريبت المسار الساخن، (7) العمل مع المراجع، التركيب، تسريب الخصائص، أو المكونات المتحكم فيها مقابل غير المتحكم فيها، (8) ترقية React 18 إلى 19 — الواجهات التي أُزيلت (`ReactDOM.render`، `findDOMNode`، مراجع السلاسل النصية، السياق القديم)، `forwardRef`، `defaultProps`، واختبارات (`test‑utils`، `act`، حسابات StrictMode)، (9) النماذج والتعديلات باستخدام الإجراءات — `useActionState`، `useFormStatus`، `useOptimistic`.
