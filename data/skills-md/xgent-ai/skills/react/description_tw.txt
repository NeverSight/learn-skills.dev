React 程式碼撰寫與審查指南 — Hook、Effect、重新渲染與瀏覽器效能。使用此技能的情境包括：(1) 撰寫或審查 React 元件與自訂 Hook；(2) 撰寫或除錯 `useEffect` — 判斷是否真的需要 Effect；(3) 使用 `useState` 取得衍生值，或在元件之間同步狀態；(4) 診斷不必要的重新渲染、過時的閉包或 memoization 問題；(5) 修復資料抓取的 waterfall、競爭條件或重複請求，或在 Suspense 中使用 `use()`；(6) 最佳化繪製、hydration、資源載入或熱路徑 JavaScript；(7) 處理 refs、組合、prop drilling，或受控與非受控元件；(8) 從 React 18 升級至 19 — 已移除的 API（`ReactDOM.render`、`findDOMNode`、字串 refs、舊版 context）、`forwardRef`、`defaultProps`，以及測試相關（`test-utils`、`act`、StrictMode 計數）；(9) 使用 Actions 處理表單與變更 — `useActionState`、`useFormStatus`、`useOptimistic`。
