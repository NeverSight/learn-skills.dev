編寫與審查 React 程式碼指南 — 鉤子、effect、重新渲染與瀏覽器效能。使用此技能於以下情況：(1) 編寫或審查 React 元件與自訂鉤子，(2) 編寫或偵錯 `useEffect` —— 判斷是否真的需要 Effect，(3) 使用 `useState` 處理衍生值或在元件間同步狀態，(4) 診斷不必要的重新渲染、陳舊的閉包或記憶化問題，(5) 修復資料抓取的瀑布流、競爭條件或重複請求，或在 Suspense 中使用 `use()`，(6) 優化繪製、hydration、資源載入或熱路徑 JavaScript，(7) 操作 refs、組合、prop drilling，或受控與非受控元件，(8) 從 React 18 升級至 19 —— 已移除的 API（`ReactDOM.render`、`findDOMNode`、字串 refs、舊版 context）、`forwardRef`、`defaultProps` 與測試工具（`test-utils`、`act`、StrictMode 計數），(9) 使用 Actions 的表單與變更 —— `useActionState`、`useFormStatus`、`useOptimistic`。
