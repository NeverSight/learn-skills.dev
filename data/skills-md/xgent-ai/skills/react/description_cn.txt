React 代码编写与审查指南 — 钩子、Effect、重新渲染和浏览器性能。使用此技能的场景包括：（1）编写或审查 React 组件及自定义 Hook，（2）编写或调试 `useEffect` —— 判断是否真的需要 Effect，（3）使用 `useState` 处理派生值或在组件间同步状态，（4）诊断不必要的重新渲染、过时的闭包或记忆化问题，（5）修复数据获取的瀑布流、竞争条件或重复请求，或在 Suspense 中使用 `use()`，（6）优化绘制、hydration、资源加载或热点 JavaScript，（7）使用 refs、组合、属性钻取，或受控与非受控组件的处理，（8）将 React 18 升级到 19 —— 被移除的 API（`ReactDOM.render`、`findDOMNode`、字符串 refs、旧版 context），`forwardRef`、`defaultProps`，以及测试相关（`test-utils`、`act`、StrictMode 计数），（9）使用 Actions 进行表单和变更——`useActionState`、`useFormStatus`、`useOptimistic`。
