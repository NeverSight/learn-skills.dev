Guía para escribir y revisar código React — hooks, efectos, re‑renders y rendimiento del navegador. Usa esta habilidad cuando: (1) escribas o revises componentes React y hooks personalizados, (2) escribas o depures `useEffect` — decidiéndo si un efecto es necesario en absoluto, (3) uses `useState` para valores derivados o sincronizando estado entre componentes, (4) diagnostiques renders innecesarios, cierres obsoletos o problemas de memoización, (5) corrijas cascadas de obtención de datos, condiciones de carrera o solicitudes duplicadas, o uses `use()` con Suspense, (6) optimices el pintado, la hidratación, la carga de recursos o el JavaScript crítico, (7) trabajes con refs, composición, prop drilling o componentes controlados vs. no controlados, (8) actualices de React 18 a 19 — APIs eliminadas (`ReactDOM.render`, `findDOMNode`, refs de cadena, contexto legado), `forwardRef`, `defaultProps` y pruebas (`test-utils`, `act`, recuentos de StrictMode), (9) formularios y mutaciones con Actions — `useActionState`, `useFormStatus`, `useOptimistic`.
