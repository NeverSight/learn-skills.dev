Guide pour écrire et réviser du code React — hooks, effets, re‑renders et performances du navigateur. Utilisez cette compétence lorsque : (1) vous écrivez ou révisez des composants React et des hooks personnalisés, (2) vous écrivez ou déboguez `useEffect` — décidez si un effet est nécessaire ou non, (3) vous utilisez `useState` pour des valeurs dérivées ou pour synchroniser l’état entre les composants, (4) vous diagnostiquez des re‑renders inutiles, des fermetures obsolètes ou des problèmes de mémorisation, (5) vous corrigez des cascades de récupération de données, des conditions de concurrence ou des requêtes en double, ou utilisez `use()` avec Suspense, (6) vous optimisez le paint, l’hydratation, le chargement des ressources ou le JavaScript critique, (7) vous travaillez avec les refs, la composition, le prop drilling ou les composants contrôlés vs non contrôlés, (8) vous migrez de React 18 à 19 — API supprimées (`ReactDOM.render`, `findDOMNode`, refs de chaîne, contexte legacy), `forwardRef`, `defaultProps`, et les tests (`test-utils`, `act`, comptage StrictMode), (9) les formulaires et les mutations avec Actions — `useActionState`, `useFormStatus`, `useOptimistic`.
