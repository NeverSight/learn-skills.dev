Guide pour écrire et examiner le code React — hooks, effets, re‑renders et performances du navigateur. Utilisez cette compétence lorsqu’on : (1) écrit ou révise des composants React et des hooks personnalisés, (2) écrit ou débogue `useEffect` — en décidant si un effet est réellement nécessaire, (3) utilise `useState` pour des valeurs dérivées ou pour synchroniser l’état entre les composants, (4) diagnostique des re‑renders inutiles, des closures obsolètes ou des problèmes de mémoïsation, (5) corrige des cascades de récupération de données, des conditions de course ou des requêtes en double, ou utilise `use()` avec Suspense, (6) optimise le paint, l’hydratation, le chargement des ressources ou le JavaScript critique, (7) travaille avec les refs, la composition, le prop‑drilling ou les composants contrôlés vs non contrôlés, (8) migre de React 18 à 19 — API supprimées (`ReactDOM.render`, `findDOMNode`, références de chaîne, contexte hérité), `forwardRef`, `defaultProps` et les tests (`test-utils`, `act`, comptage StrictMode), (9) gère les formulaires et les mutations avec Actions — `useActionState`, `useFormStatus`, `useOptimistic`.
