Guida per scrivere e revisionare codice React — hook, effetti, render e prestazioni del browser.

Usa questa competenza quando: (1) scrivi o revisioni componenti React e hook personalizzati, (2) scrivi o debugghi `useEffect` — decidendo se un Effect è necessario, (3) utilizzi `useState` per valori derivati o per sincronizzare lo stato tra componenti, (4) diagnostichi render non necessari, chiusure obsolete o problemi di memoizzazione, (5) correggi catene di fetch dei dati, condizioni di gara o richieste duplicate, o usi `use()` con Suspense, (6) ottimizzi paint, hydration, caricamento delle risorse o JavaScript critico, (7) lavori con ref, composizione, prop drilling o componenti controllati vs non controllati, (8) aggiorni React 18 a 19 — API rimosse (`ReactDOM.render`, `findDOMNode`, string refs, legacy context), `forwardRef`, `defaultProps` e test (`test-utils`, `act`, conteggi StrictMode), (9) moduli e mutazioni con Actions — `useActionState`, `useFormStatus`, `useOptimistic`.
