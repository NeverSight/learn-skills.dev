Используется как единый интерфейс /v1 для других приложений, SDK или инструментов программирования, чтобы получить доступ к XGENT LLM Gateway, а также для миграции устаревших вызовов, устранения проблем с учётными данными, обеспечения идемпотентности и восстановления медиа‑задач. Не предназначен для разработки, развертывания или общей оптимизации подсказок самого шлюза.
