Audit and shrink bloated JavaScript/TypeScript test suites (Vitest or Jest) without losing real quality. Use when the user wants to reduce or minimize a test suite, clean up AI-slop or duplicate tests, audit test quality, prune redundant tests, or verify a reduced suite against coverage and mutation-score baselines. Metrics-driven — the bundled CLI measures per-test coverage and runtime and computes the keep/drop plan; never prune tests by gut feeling.
