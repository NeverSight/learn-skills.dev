Prüfen und verkleinern Sie aufgeblähte JavaScript/TypeScript-Testsuiten (Vitest oder Jest), ohne an echter Qualität zu verlieren. Verwenden Sie diese Option, wenn der Benutzer eine Testsuite reduzieren oder minimieren, KI-Slop- oder doppelte Tests bereinigen, die Testqualität überprüfen, redundante Tests beschneiden oder eine reduzierte Suite anhand von Abdeckungs- und Mutationsscore-Baselinewerten überprüfen möchte. Metrikgesteuert — die gebündelte CLI misst die Abdeckung und Laufzeit pro Test und berechnet den Keep/Drop-Plan. Schneiden Sie Tests niemals nach Bauchgefühl ab.
