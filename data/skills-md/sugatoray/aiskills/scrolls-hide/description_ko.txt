이미 설정된 docs/scrolls/ 작업 메모리 폴더를 보이는 상태(스크롤)에서 dotfile‑숨김(.scrolls) 형태로 변환하고, 폴더 이름을 바꾸며 내부 및 SCROLLS.md 안의 경로 참조를 다시 작성하여 아무것도 깨지지 않게 합니다. 사용자가 /scrolls-hide를 실행하거나 스크롤 폴더를 숨기고, dot 하거나, 다시 숨기기를 요청할 때, 프로젝트 메모리 / docs/.scrolls를 다시 숨기거나 scrolls를 .scrolls로 이름을 바꿀 때마다 이 기능을 사용합니다. 이는 기존에 보이게 설정된 프로젝트를 이제는 숨기고 싶을 때의 레트로핏 경로이며—새 프로젝트의 경우 /scrolls-setup 기본값(‑u/--unhide 플래그 없음)이 이미 숨김으로 생성하므로 이 기능이 필요하지 않습니다. 기본적으로 현재 디렉터리 아래의 정확한 위치(docs/scrolls) 하나만 확인하며, -r/--recurse 옵션을 사용하면 전체 디렉터리 트리를 스캔합니다(예: 한 번에 모노레포의 모든 패키지). -p/--path 옵션을 반복해서 특정 위치를 지정하고, -t/--reporoot 옵션으로 현재 서브디렉터리와 무관하게 git 저장소 최상위 수준을 대상으로 하며, -l/--local 옵션으로 현재 디렉터리를 명시적으로 지정하고, DEFAULT_SCROLLS_RELPATH 환경 변수를 사용해 기본 위치를 변경할 수 있습니다. macOS, Linux, Windows(bash 또는 PowerShell)에서 작동합니다. /scrolls-unhide와 반대 작업입니다.
