Convierte una carpeta docs/scrolls/memoria-de-trabajo ya configurada de visible (scrolls) a oculta como archivo de punto (.scrolls), renombrando la carpeta y reescribiendo las referencias de ruta dentro de ella y en SCROLLS.md para que nada se rompa. Usa esto siempre que el usuario ejecute /scrolls-hide, o pida ocultar, dot, o volver a ocultar la carpeta scrolls, regrese a ocultar la memoria del proyecto / docs/.scrolls, o cambie el nombre de scrolls a .scrolls. Este es el camino de adaptación para un proyecto que se configuró visible y ahora quiere que sea oculto; para un proyecto nuevo, la configuración predeterminada de /scrolls-setup (sin la bandera -u/--unhide) ya lo crea oculto y esta habilidad no es necesaria. Por defecto verifica una ubicación exacta (docs/scrolls bajo el directorio actual); admite -r/--recurse para barrer todo el árbol de directorios (p. ej., cada paquete en un monorepo en una sola ejecución), -p/--path repetible para apuntar a ubicaciones específicas, -t/--reporoot para apuntar al nivel superior del repositorio git sin importar en qué subdirectorio estés, -l/--local para apuntar explícitamente al directorio actual, y la variable de entorno DEFAULT_SCROLLS_RELPATH para cambiar la ubicación predeterminada. Funciona en macOS, Linux y Windows (bash o PowerShell). Es lo opuesto a /scrolls-unhide.
