Преобразует уже настроенную папку docs/scrolls/working-memory из видимой (scrolls) в скрытую точкой (.scrolls), переименовывая её и переписывая ссылки на пути внутри неё и в SCROLLS.md, чтобы ничего не сломалось. Используйте это каждый раз, когда пользователь запускает /scrolls-hide, или просит скрыть, «dot», либо повторно скрыть папку scrolls, вернуться к скрытию памяти проекта /docs/.scrolls, или переименовать scrolls в .scrolls. Это ретрофит‑путь для проекта, который был настроен как видимый и теперь хочет его скрыть — для нового проекта /scrolls-setup по умолчанию (без -u/--unhide) уже создаёт его скрытым, и эта функция не нужна. По умолчанию проверяется одно точное местоположение (docs/scrolls в текущем каталоге); поддерживает -r/--recurse для обхода всего дерева каталогов (например, каждый пакет в монорепозитории за один запуск), повторяемый -p/--path для указания конкретных мест, -t/--reporoot для выбора корня git‑репозитория независимо от того, в какой подпапке вы находитесь, -l/--local для явного выбора текущего каталога, а также переменную окружения DEFAULT_SCROLLS_RELPATH для изменения расположения по умолчанию. Работает на macOS, Linux и Windows (bash или PowerShell). Противоположность /scrolls-unhide.
