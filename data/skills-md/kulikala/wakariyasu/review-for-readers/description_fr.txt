Révisez les documents qui seront remis, envoyés ou rendus publics (tels que les README, spécifications, procédures, propositions, réglementations, SKILL.md, etc.) du point de vue d’un lecteur qui ne connaît pas le contexte dans lequel ils ont été rédigés, et corrigez les parties problématiques. Utilisez cette méthode lorsqu’on vous demande de « réviser du point de vue du lecteur », « le regarder avant publication » ou « vérifier qu’il est compréhensible pour les lecteurs novices ». Même si ce n’est pas demandé, appliquez‑la avant de finaliser un document destiné à d’autres. Faites lire le document à un autre agent qui ne connaît pas le contexte, corrigez les problèmes qui apparaissent, puis faites‑le relire à nouveau.

Veuillez toujours répondre dans la langue de l’utilisateur.
