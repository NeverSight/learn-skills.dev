When asked “What’s the current situation?”, “What’s the current status?”, “What are you doing now?”, “How far have you progressed?”, or “What’s left?” (including when the same question is asked in another language), use this. Even if not asked, use it when a piece of work spanning multiple tasks reaches a checkpoint and you need to report, when you pause to ask the user for a decision, or when you need to convey intermediate progress on a long task. Break down the current session’s situation into the current goal, the most recent instruction, a list of tasks (with their states), the latest status, and the decision request (numbered); focus on the key points and answer so that the background and intent are also clear.
