Synthetische Wahrheitskontrollen für Analysepipelines. Verwenden Sie sie, bevor Sie irgendeine statistische Anpassung, einen Solver, ein Audit oder eine Suche an Realdaten durchführen – die Pipeline muss zunächst nachweisen, dass sie eine bekannte, eingepflanzte Antwort wiederherstellen und einen bewusst korrumpierten Input erkennen kann.
