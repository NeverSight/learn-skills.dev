Erstellen, aktualisieren, Vorschau oder Veröffentlichen einer Website oder Web-App mit Annie auf DoAny. Wird verwendet, wenn der Benutzer darum bittet, eine Geschäftsidee in eine DoAny-Website umzuwandeln, eine vorhandene DoAny-Website zu ändern oder einen DoAny-Entwurf von seinem Agenten zu überprüfen oder zu veröffentlichen.
