Crea y previsualiza un sitio web alojado para una empresa a partir de un resumen redactado en un lenguaje sencillo. Úsalo para crear la página de inicio de una nueva empresa, una página de destino, un escaparate de servicios, un portafolio, una tienda en línea o un portal para clientes, así como para actualizar sitios alojados por este creador. Añade reservas, un proceso de pago o cuentas de miembros según sea necesario y automatiza los recordatorios, el seguimiento de los clientes y los informes después del lanzamiento. Sigue la elección del usuario cuando especifique otro alojamiento o solicite editar una base de código existente.
