GSAP + ScrollTrigger（Next.js/React/Tailwind を最初に、任意のスタックに対応可能）で、独自性のある本番品質のアニメーションフロントエンドを構築しましょう。ランディングページ、マーケティングサイト、ヒーローセクション、またはスクロールアニメーションを伴う UI の作成時に使用します。トリガーには「GSAP」「gsap」「ScrollTrigger」「スクロールアニメーション」「スクロールトリガー」「パララックス」「ピン留めセクション」「スティッキースクロール」「水平スクロール」「マルキー」「キネティックタイポグラフィ」「スクロールでのリビール」「カウントアップ」「グラデーションメッシュ」「ガラスモーフィズム」「アニメーションランディングページ」「ヒーローアニメーション」、あるいは cash.app / getduel / magic-receipt / pushapp のようなサイトの構築があります。GSAP の設定、再利用可能なプリミティブ、コピーペースト可能なスクロールパターン、パフォーマンスと prefers‑reduced‑motion、そして参照スクリーンショット付きのデザイン言語カタログを網羅しています。
