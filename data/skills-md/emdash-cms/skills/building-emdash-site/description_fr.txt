Construisez les parties visibles du site d’un projet EmDash CMS sur Astro, y compris le schéma et les données de base, les requêtes de contenu, le rendu Portable Text, les menus, les taxonomies, les widgets et la configuration de déploiement. Utilisez‑le pour le site et le thème EmDash ; utilisez plutôt « creating‑plugins » lorsque la tâche consiste uniquement à créer des plugins.
