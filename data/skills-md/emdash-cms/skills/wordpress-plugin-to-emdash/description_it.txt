Analizza e migra il comportamento dei plugin WordPress, i tipi di post personalizzati, gli shortcode, i flussi di lavoro amministrativi e i dati memorizzati nei punti di estensione attuali di EmDash. Usalo per le migrazioni di plugin WordPress o quando decidi a quale plugin EmDash, schema del sito, seed o codice Astro appartenga il comportamento. Non usarlo per la portabilità di temi visivi senza funzionalità di plugin.
