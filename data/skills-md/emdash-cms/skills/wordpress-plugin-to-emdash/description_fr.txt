Analysez et migrez le comportement des plugins WordPress, les types de contenu personnalisés, les shortcodes, les flux de travail d’administration et les données stockées vers les points d’extension actuels d’EmDash. Utilisez-le pour les migrations de plugins WordPress ou lorsque vous décidez quel comportement doit appartenir à un plugin EmDash, au schéma du site, aux seeds ou au code Astro. N’utilisez pas pour les ports de thèmes visuels dépourvus de fonctionnalité de plugin.
