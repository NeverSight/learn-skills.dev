Audit d'efficacité en une seule passe d'un fichier, d'un diff ou d'un dépôt complet sur les DEUX axes à la fois : code sur‑ingénieur (stdlib réinventée, abstractions inutiles, configuration spéculative) ET prose gonflée (commentaires verbeux, docstrings trop fournis, sections de documentation redondantes). Aucun minimiseur de code pur ni compresseur de prose pur ne réalise les deux en une seule passe. C’est le but. Rapport classé, les économies les plus importantes en premier ; ne modifie rien. À utiliser lorsque l'utilisateur dit « chisle audit », « /chisle-audit », « audit this for bloat », « what can I cut », « review this PR for over-engineering and verbosity ».
