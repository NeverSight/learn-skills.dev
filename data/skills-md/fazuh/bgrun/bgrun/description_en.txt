Use whenever a command must outlive the shell or the agent turn — long builds, downloads, servers, watchers, dev daemons — or when the user says run it in the background, detached, as a daemon, in a service, until reboot, restart it if it fails, mentions nohup, disown, trailing ampersand, systemd-run, background job, or asks about a job bgrun started earlier.
