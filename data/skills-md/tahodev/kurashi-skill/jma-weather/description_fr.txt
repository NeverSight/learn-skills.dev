Récupérez les prévisions météorologiques (météo, probabilité de précipitations, température et prévisions hebdomadaires) à partir du JSON public de l'Agence météorologique japonaise. Il traite des questions sur la météo, la température, la probabilité de précipitations et les prévisions pour demain ou le week-end. Aucune clé API ou connexion n’est requise. Les alertes, avertissements et informations sur les tremblements de terre/tsunami sont exclus (utilisez bosai‑alert).
