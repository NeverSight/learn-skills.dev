إنشاء أو تعديل أو مراجعة أو بناء حزم RPM الخاصة بـ openSUSE — ملفات .spec و .changes، osc / OBS، وسير عمل التعبئة باستخدام Git على src.opensuse.org (Gitea). استخدم ذلك لعملية checkout باستخدام .osc/ أو ملف *.spec؛ عندما يذكر المستخدم osc أو OBS أو rpmbuild أو git-obs أو tea أو rpmlint أو spec-cleaner؛ أو يطلب تحديث أو بناء أو إرسال أو مراجعة أو استنساخ (fork) حزمة، أو التحقق ما إذا كانت الحزم قديمة، أو فتح طلب سحب (pull request) لحزمة.
