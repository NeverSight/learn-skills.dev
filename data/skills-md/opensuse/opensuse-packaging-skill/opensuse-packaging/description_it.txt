Creazione, modifica, revisione o compilazione di pacchetti RPM openSUSE — file .spec e .changes, osc / OBS e il flusso di lavoro di packaging Git su src.opensuse.org (Gitea). Da usare per un checkout .osc/ o un file *.spec; quando l'utente menziona osc, OBS, rpmbuild, git-obs, tea, rpmlint o spec-cleaner; o chiede di aggiornare, compilare, inviare, revisionare o forkare un pacchetto, verificare se i pacchetti sono obsoleti o aprire una pull request di un pacchetto.

Per favore rispondi sempre nella lingua dell'utente.
