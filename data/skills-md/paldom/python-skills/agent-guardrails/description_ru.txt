Устанавливает агентные ограждения в репозиторий Python — хуки Claude Code, шлюз Stop, который подтверждает только то, что принимает pre‑commit, проверенные публичные навыки — и устраняет проблемы с хуками, которые не срабатывают или блокируют. Используйте для «добавить хуки Claude Code», «написать AGENTS.md», «подготовить этот репозиторий к работе агента», «агент постоянно обходил проверки», «агент сообщает, что завершил, но pre‑commit не проходит». Не предназначено для написания конфигурации pre‑commit.
