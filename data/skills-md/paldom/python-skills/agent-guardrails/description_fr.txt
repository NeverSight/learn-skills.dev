Installe des garde-fous agentiques dans un dépôt Python — les hooks Claude Code, une porte Stop qui valide uniquement ce que pre‑commit accepte, des compétences publiques vérifiées — et dépanne les hooks qui ne se déclenchent pas ou qui bloquent. À utiliser pour « ajouter des hooks Claude Code », « rédiger un AGENTS.md », « rendre ce dépôt prêt pour un agent », « l’agent contourne les contrôles », « l’agent indique terminé mais pre‑commit échoue ». Pas destiné à la rédaction du fichier de configuration de pre‑commit.
