Configure la vérification de type statique pour un paquet Python — en choisissant mypy, pyright, basedpyright ou ty, configuration stricte, surcharges par module, inclusion du fichier py.typed — et corrige les erreurs de vérification de type. À utiliser lorsque l'utilisateur dit « add type checking », « set up mypy », « pyright errors », « make this package typed ». Pas pour les échecs de lint ou de formatage, les tests qui échouent, les bugs d'exécution ou le workflow CI qui exécute le vérificateur.

Veuillez toujours répondre dans la langue de l'utilisateur.
