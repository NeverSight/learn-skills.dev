Richtet die statische Typüberprüfung für ein Python‑Paket ein – wählt mypy, pyright, basedpyright oder ty, strenge Konfiguration, pro‑Modul‑Überschreibungen, mit ausgeliefertem py.typed – und behebt Typprüfungsfehler. Verwenden, wenn der Benutzer sagt 'add type checking', 'set up mypy', 'pyright errors', 'make this package typed'. Nicht für Lint‑ oder Formatfehler, fehlgeschlagene Tests, Laufzeitfehler oder den CI‑Workflow, der den Prüfer ausführt.
