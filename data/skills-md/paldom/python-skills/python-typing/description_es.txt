Configura la comprobación de tipos estática para un paquete de Python — eligiendo mypy, pyright, basedpyright o ty, configuración estricta, anulaciones por módulo, enviando py.typed — y corrige errores de verificación de tipos. Úsalo cuando el usuario diga ‘add type checking’, ‘set up mypy’, ‘pyright errors’, ‘make this package typed’. No es para fallas de lint o formato, pruebas fallidas, errores de tiempo de ejecución o el flujo de trabajo de CI que ejecuta el verificador.

Por favor, responde siempre en el idioma del usuario.
