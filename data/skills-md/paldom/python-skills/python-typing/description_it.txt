Imposta il controllo statico dei tipi per un pacchetto Python — scegliendo mypy, pyright, basedpyright o ty, configurazione rigorosa, override per modulo, includendo py.typed — e risolve gli errori di type‑check. Da utilizzare quando l'utente dice “add type checking”, “set up mypy”, “pyright errors”, “make this package typed”. Non per errori di lint o formattazione, test falliti, bug di runtime o il workflow CI che esegue il checker.

Rispondi sempre nella lingua dell'utente.
