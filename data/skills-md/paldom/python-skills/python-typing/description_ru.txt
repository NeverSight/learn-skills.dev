Настраивает статическую проверку типов для пакета Python — выбирает mypy, pyright, basedpyright или ty, строгую конфигурацию, переопределения на уровне модулей, поставку py.typed — и исправляет ошибки проверки типов. Использовать, когда пользователь говорит «add type checking», «set up mypy», «pyright errors», «make this package typed». Не предназначено для ошибок линтинга или форматирования, провалившихся тестов, багов времени выполнения или CI‑процесса, который запускает проверку. Пожалуйста, всегда отвечайте на языке пользователя.
