يقوم بإعداد فحص الأنواع الساكنة لحزمة بايثون — اختيار mypy أو pyright أو basedpyright أو ty، تكوين صارم، تجاوزات لكل وحدة، شحن ملف py.typed — ويصلح أخطاء فحص الأنواع. يُستخدم عندما يقول المستخدم “أضف فحص الأنواع”، “إعداد mypy”، “أخطاء pyright”، “اجعل هذه الحزمة مكتوبة بأنواع”. ليس لأخطاء التدقيق النحوي أو تنسيق الكود، أو الاختبارات الفاشلة، أو أخطاء وقت التشغيل، أو سير عمل CI الذي يشغل الفاحص. يرجى دائمًا الرد بلغة المستخدم.
