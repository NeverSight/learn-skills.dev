Construye la infraestructura de pytest para un paquete de Python — estructura y configuración, puertas de cobertura con fail_under, pruebas basadas en propiedades con Hypothesis, pruebas de mutación para detectar pruebas débiles o manipuladas, ejecuciones multiversión mediante tox, nox o uv. Úsalo para “configurar pytest”, “añadir cobertura”, “probar en múltiples versiones de Python”. No es para escribir pruebas para un solo archivo, arreglar una prueba que falla o el YAML del flujo de trabajo CI.
