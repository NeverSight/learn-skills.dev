يبني بنية تحتية لـ pytest لحزمة بايثون — التخطيط والتكوين، بوابات التغطية مع fail_under، اختبارات Hypothesis القائمة على الخصائص، اختبار الطفرات لاكتشاف الاختبارات الضعيفة أو المستغلة، تشغيل متعدد الإصدارات عبر tox أو nox أو uv. يُستَخدم لـ «إعداد pytest»، «إضافة التغطية»، «الاختبار على إصدارات بايثون متعددة». ليس للاستخدام في كتابة اختبارات لملف واحد، إصلاح اختبار فاشل واحد، أو ملف YAML لسير عمل CI.
