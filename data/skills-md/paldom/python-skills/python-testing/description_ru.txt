Создаёт инфраструктуру pytest для Python‑пакета — структуру и конфигурацию, пороги покрытия с fail_under, property‑based тесты Hypothesis, мутационное тестирование для выявления слабых или подстроенных под агента тестов, запуск на нескольких версиях через tox, nox или uv. Используется для «настроить pytest», «добавить покрытие», «тестировать на разных версиях Python». Не предназначено для написания тестов к одному файлу, исправления единственного падающего теста или CI‑workflow YAML.
