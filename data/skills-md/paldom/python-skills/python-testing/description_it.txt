Costruisce l'infrastruttura pytest per un pacchetto Python — struttura e configurazione, soglie di copertura con fail_under, test basati su proprietà con Hypothesis, testing di mutazione per individuare test deboli o manipolati, esecuzioni multi‑versione tramite tox, nox o uv. Da usare per “configurare pytest”, “aggiungere copertura”, “testare su più versioni di Python”. Non serve per scrivere test per un singolo file, correggere un test che fallisce o per file YAML di workflow CI.
