Configura el empaquetado de una biblioteca Python — metadatos de pyproject.toml, backend de compilación, estructura src, puntos de entrada CLI, lockfiles de uv, dónde van las dependencias de desarrollo (grupos de dependencias vs dependencias opcionales), wheels y sdists. Úsalo para hacer que un proyecto sea instalable, configurar pyproject.toml, construir una wheel, abandonar requirements.txt o cambiar a uv. No es para publicar en PyPI ni para automatización de lanzamientos.
