Configura il packaging per una libreria Python — metadati pyproject.toml, backend di build, struttura src, punti di ingresso CLI, lockfile uv, dove vanno le dipendenze di sviluppo (dependency-groups vs optional-dependencies), wheel e sdist. Da usare per rendere un progetto installabile, impostare pyproject.toml, costruire una wheel, abbandonare requirements.txt o passare a uv. Non per la pubblicazione su PyPI o l’automazione di release.
