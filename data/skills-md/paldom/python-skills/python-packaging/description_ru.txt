Настраивает упаковку для библиотеки Python — метаданные pyproject.toml, backend сборки, layout src, точки входа CLI, lock‑файлы uv, где размещать зависимости разработки (dependency‑groups vs optional‑dependencies), колёса и sdist‑пакеты. Используется для того, чтобы сделать проект устанавливаемым, настроить pyproject.toml, собрать wheel, отказаться от requirements.txt или перейти на uv. Не предназначено для публикации в PyPI или автоматизации релизов.
