Guide le lecteur à travers une pull request d’un collègue afin qu’il comprenne ce qui a changé et pourquoi, couche par couche : un titre court indiquant l’ordre de lecture d’abord, puis chaque partie de la modification avant et après, ensuite les chemins de code, chaque affirmation étant citée et vérifiée. Lecture seule ; ne fait jamais de revue pour des bugs ni de commentaires dans la PR. Utilise‑le pour « walk me through PR #123 », « what did this PR change », « help me understand this PR », « explain this branch's changes ». Utilise « how » pour expliquer le fonctionnement du code existant, et « review‑pr » pour identifier des problèmes. Veuillez toujours répondre dans la langue de l'utilisateur.
