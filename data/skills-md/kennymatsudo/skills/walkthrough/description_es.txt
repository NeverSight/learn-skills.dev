Guía a un lector a través del pull request de un compañero para que entienda qué cambió y por qué, capa por capa: primero un encabezado breve con el orden de lectura, luego cada parte del cambio antes y después, luego las rutas de código, con cada afirmación citada y verificada. Solo lectura; nunca revisa bugs ni publica comentarios en el PR. Usa para "walk me through PR #123", "what did this PR change", "help me understand this PR", "explain this branch's changes". Usa how para cómo funciona el código existente, y review-pr para encontrar problemas.

Por favor, responde siempre en el idioma del usuario.
