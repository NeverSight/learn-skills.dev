Проведите читателя по pull‑request‑у коллеги, чтобы он понял, что изменилось и почему, слой за слоем: сначала короткий заголовок с порядком чтения, затем каждую часть изменения «до» и «после», затем пути кода, при этом каждое утверждение сопровождается ссылкой и проверкой. Только для чтения; никогда не проверяйте баги и не оставляйте комментарии в PR. Используйте для «walk me through PR #123», «what did this PR change», «help me understand this PR», «explain this branch's changes». Используйте how для описания работы существующего кода и review‑pr для поиска проблем.
