Nettoyez les bavures d’IA dans un texte ou du code afin qu’une personne veuille le lire. Prose (docs, READMEs, plans, texte de PR et de commit) : mettez le point principal en premier, éliminez les commentaires méta, l’historique des changements et les reformulations, découpiez les murs de texte, réécrivez les rubriques génériques et corrigez les tournures d’IA sans perdre d’information. Code (diff de branche) : supprimez les tests creux, les abstractions spéculatives, les shim, le gonflage défensif et le code mort sans modifier le comportement. Utilisez pour « unslop », « deslop », « unslop this doc », « make this readable », « clean up the AI slop », ou avant d’enregistrer un document ou le texte d’une PR rédigé par un agent. Ignorez les réponses de chat. Utilisez « trim » uniquement pour éliminer les redondances, et « clean‑up‑comments » pour les commentaires de code.

Veuillez toujours répondre dans la langue de l’utilisateur.
