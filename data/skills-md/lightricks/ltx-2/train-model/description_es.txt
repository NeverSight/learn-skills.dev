Agente de extremo a extremo para entrenar modelos LTX. Sondea el sistema de archivos y la GPU, elige el modo de acondicionamiento correcto según la intención del usuario, prepara el conjunto de datos (escenas, subtítulos, referencias), preprocesa, ajusta automáticamente, inicia y monitorea el entrenamiento. Úselo cuando el usuario desee entrenar, ajustar LoRA o producir de otro modo un modelo LTX personalizado.
