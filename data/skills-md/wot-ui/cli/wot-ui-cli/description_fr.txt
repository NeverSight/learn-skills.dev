Utilisez, déboguez ou maintenez @wot-ui/cli avec le dépôt open-wot. Cela s’applique aux commandes CLI wot, à l’intégration Agent/MCP, aux vérifications doctor/usage/lint, aux requêtes de connaissances sur les composants, aux adaptateurs client, à l’extraction de données hors ligne, aux tests de construction, aux contrôles des packages de diffusion et au développement du dépôt ; si la tâche consiste à créer directement des pages de composants wd‑* ou à expliquer les API des composants, vous devez plutôt utiliser la compétence wot‑ui‑v2.

Veuillez toujours répondre dans la langue de l’utilisateur.
