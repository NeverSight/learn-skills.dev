Usa, debugga o mantieni @wot-ui/cli con il repository open-wot. Si applica ai comandi CLI di wot, all’integrazione Agent/MCP, a doctor/usage/lint, alle query sulla conoscenza dei componenti, al client adapter, all’estrazione dei dati offline, al testing della build, all’ispezione del pacchetto di rilascio e allo sviluppo del repository; se il compito è scrivere direttamente pagine dei componenti wd‑* o spiegare le API dei componenti, dovresti invece usare la skill wot‑ui‑v2.

Per favore, rispondi sempre nella lingua dell’utente.
