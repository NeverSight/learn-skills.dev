Migrieren Sie das Projekt des Benutzers von Wot UI v1 zu v2. Der Benutzer fordert ein Upgrade von wot-design-uni auf @wot-ui/ui, das Ersetzen alter Komponenten/alter APIs, die Migration des Formularvalidierungssystems, die Migration von Icon‑Namen sowie das Beheben von Kompilierungsfehlern, fehlenden Icons und Laufzeitfehlern, die durch Inkompatibilitätsänderungen in v2 verursacht werden.
