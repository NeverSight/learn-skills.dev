Construisez des plugins audio JUCE (VST3, AU, AAX, autonome, LV2) en C++ avec CMake. Couvrant l’ensemble du flux de travail de développement, de la création du projet aux builds multi‑format, y compris le cycle de vie d’AudioProcessor, la gestion des paramètres avec APVTS, les chaînes de modules DSP, les interfaces GUI d’éditeur personnalisées, les interfaces WebView Three.js/GLB, la sérialisation d’état, la sécurité audio en temps réel et le CI/CD multiplateforme. Utilisez cette compétence chaque fois que l’utilisateur mentionne JUCE, plugins audio, plugins VST, plugins AU, effets audio, synthétiseurs, processeurs MIDI, AudioProcessor, AudioProcessorEditor, Projucer, ou souhaite créer un logiciel audio — même s’il se contente de dire « make a plugin » ou « audio plugin ». Cela s’applique également lorsque les utilisateurs travaillent dans une base de code JUCE existante (fichiers tels que PluginProcessor.cpp, PluginEditor.cpp, CMakeLists.txt avec juce_add_plugin), ou enquêtent sur l’utilisation CPU d’un plugin dans un hôte, portent un plugin vers Windows ou Linux, ou signent le code, le notarient ou empaquettent les versions du plugin.
