Costruisci plugin audio JUCE (VST3, AU, AAX, Standalone, LV2) in C++ con CMake. Copre l’intero flusso di lavoro di sviluppo, dalla scaffolding del progetto alle build multi‑formato, includendo il ciclo di vita di AudioProcessor, la gestione dei parametri con APVTS, le catene di moduli DSP, le GUI personalizzate dell’editor, le interfacce WebView Three.js/GLB, la serializzazione dello stato, la sicurezza audio in tempo reale e CI/CD cross‑platform. Usa questa competenza ogni volta che l’utente menziona JUCE, plugin audio, plugin VST, plugin AU, effetti audio, sintetizzatori, processori MIDI, AudioProcessor, AudioProcessorEditor, Projucer, o vuole creare software audio — anche se dice semplicemente “crea un plugin” o “plugin audio”. Vale anche quando gli utenti lavorano su un codice JUCE esistente (file come PluginProcessor.cpp, PluginEditor.cpp, CMakeLists.txt con juce_add_plugin), o stanno indagando sull’uso della CPU di un plugin in un host, portando un plugin su Windows o Linux, o firmando, notarizzando o impacchettando le versioni del plugin.
