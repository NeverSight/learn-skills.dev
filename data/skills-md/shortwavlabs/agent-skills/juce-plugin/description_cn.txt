使用 CMake 在 C++ 中构建 JUCE 音频插件（VST3、AU、AAX、Standalone、LV2）。涵盖从项目脚手架到多格式构建的完整开发工作流，包括 AudioProcessor 生命周期、使用 APVTS 的参数管理、DSP 模块链、自定义编辑器 GUI、Three.js/GLB WebView 接口、状态序列化、实时音频安全性，以及跨平台 CI/CD。每当用户提到 JUCE、音频插件、VST 插件、AU 插件、音频效果、合成器、MIDI 处理器、AudioProcessor、AudioProcessorEditor、Projucer，或想要创建音频软件时，都要使用此技能——即使他们仅说“做一个插件”或“音频插件”。在用户使用已有的 JUCE 代码库（如 PluginProcessor.cpp、PluginEditor.cpp、带有 juce_add_plugin 的 CMakeLists.txt）进行开发，或在宿主中调查插件的 CPU 使用情况、将插件移植到 Windows 或 Linux，或进行代码签名、公证或打包插件发布时，也同样适用。
