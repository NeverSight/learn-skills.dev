JUCE 오디오 플러그인(VST3, AU, AAX, Standalone, LV2)을 C++와 CMake로 빌드합니다. 프로젝트 스캐폴딩부터 다중 포맷 빌드까지 전체 개발 워크플로우를 다루며, AudioProcessor 수명 주기, APVTS를 이용한 파라미터 관리, DSP 모듈 체인, 커스텀 에디터 GUI, Three.js/GLB WebView 인터페이스, 상태 직렬화, 실시간 오디오 안전성, 크로스 플랫폼 CI/CD 등을 포함합니다. 사용자가 JUCE, 오디오 플러그인, VST 플러그인, AU 플러그인, 오디오 이펙트, 신시사이저, MIDI 프로세서, AudioProcessor, AudioProcessorEditor, Projucer를 언급하거나 오디오 소프트웨어를 만들고 싶다고 할 때마다 이 기술을 사용하십시오 — 단순히 “플러그인 만들기” 혹은 “오디오 플러그인”이라고 말해도 적용됩니다. 또한 사용자가 기존 JUCE 코드베이스(예: PluginProcessor.cpp, PluginEditor.cpp, juce_add_plugin이 포함된 CMakeLists.txt)에서 작업 중이거나, 호스트에서 플러그인 CPU 사용량을 조사하거나, 플러그인을 Windows 또는 Linux로 포팅하거나, 코드 서명, 노터라이징 또는 플러그인 릴리스를 패키징하는 경우에도 적용됩니다.
