Google Maps vía CDP — tres modos, todos sin clave (no se necesita clave de Google Places ni Directions API, sin cuota): (1) búsqueda de negocios locales que devuelve resultados estructurados (nombre, puntuación, reseñas, precio, categoría, dirección, horarios, coordenadas, ID del lugar, URL) — los datos que vende la API de Google Places con facturación; (2) --route para direcciones reales (tiempo total + distancia, tráfico actual) para una lista ordenada de lugares, en cualquier modo de viaje (--mode driving|transit|walking|cycling|flights|best, por defecto driving); (3) --optimize para obtener un orden de visita lo más rápido posible (TSP de camino abierto, inicio fijo) cuyas aristas se virtualizan como distancia en línea recta — N búsquedas de lugares en paralelo más una llamada real a direcciones. Úsalo cuando el usuario solicite encontrar negocios locales, obtener direcciones/tiempo entre lugares (por cualquier modo) o planificar el orden de una ruta con múltiples paradas. Requiere browser-harness-js en el PATH y un navegador basado en Chromium en ejecución con depuración remota.
