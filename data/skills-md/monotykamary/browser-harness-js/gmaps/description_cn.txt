通过 CDP 使用 Google 地图 — 三种模式，全部无需密钥（不需要 Google Places 或 Directions API 密钥，无配额限制）：（1）本地商家搜索，返回结构化结果（名称、评分、评论、价格、类别、地址、营业时间、坐标、地点 ID、URL）——即计量式 Google Places API 所提供的数据；（2）--route 用于获取真实路线（总时间 + 距离、实时交通），针对有序的地点列表，支持任意出行模式（--mode driving|transit|walking|cycling|flights|best，默认 driving）；（3）--optimize 用于尽力获取最快的访问顺序（开放路径 TSP，固定起点），其边缘被虚拟为直线距离 — N 个并行地点查询加一次真实路线请求。适用于用户请求查找本地商家、获取地点之间的路线/时间（任意模式），或规划多站点路线顺序。需要在 PATH 中有 browser-harness-js，并运行带远程调试的 Chromium 系浏览器。
