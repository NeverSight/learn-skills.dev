Google Maps 透過 CDP — 三種模式，全部免鑰匙（無 Google Places 或 Directions API 金鑰，無配額）：（1）本地商家搜尋，返回結構化結果（名稱、評分、評論、價格、類別、地址、營業時間、座標、place ID、URL）——即計量的 Google Places API 所販售的資料；（2）--route 用於真實路徑（總時間 + 距離、即時交通），針對有序的地點列表，支援任意旅行模式（--mode driving|transit|walking|cycling|flights|best，預設 driving）；（3）--optimize 用於盡力求最快的拜訪順序（開路徑 TSP，固定起點），其邊緣以直線距離虛擬化——N 個平行的地點查詢加一次真實路徑呼叫。當使用者要求尋找本地商家、取得地點之間的路徑/時間（任意模式）或規劃多站點路線順序時使用。需要在 PATH 中有 browser-harness-js，且執行中的 Chromium 系列瀏覽器開啟遠端偵錯。
