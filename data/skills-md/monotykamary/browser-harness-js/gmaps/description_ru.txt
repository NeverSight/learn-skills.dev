Google Maps через CDP — три режима, все без ключа (без ключа API Google Places или Directions, без квоты): (1) локальный поиск бизнесов, возвращающий структурированные результаты (название, рейтинг, отзывы, цена, категория, адрес, часы работы, координаты, ID места, URL) — данные, которые продаёт измеряемый API Google Places; (2) --route для получения реальных маршрутов (общее время + расстояние, текущий трафик) для упорядоченного списка мест, в любом режиме передвижения (--mode driving|transit|walking|cycling|flights|best, по умолчанию driving); (3) --optimize для получения лучшего приближённого быстрейшего порядка посещения (открытый ТЗП, фиксированный старт), где ребра виртуализированы как прямолинейное расстояние — N параллельных запросов к местам плюс один реальный вызов маршрута. Используйте, когда пользователь запрашивает поиск локальных бизнесов, получение маршрутов/времени между местами (в любом режиме) или планирование маршрута с несколькими остановками. Требуется браузерный harness-js в PATH и запущенный Chromium‑основанный браузер с удалённой отладкой.
