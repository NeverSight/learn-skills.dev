Google Maps via CDP — 3つのモード、すべてキー不要（Google Places や Directions API のキー不要、クォータなし）：(1) ローカルビジネス検索で構造化された結果を返す（名前、評価、レビュー、価格、カテゴリ、住所、営業時間、座標、Place ID、URL）— メーター制の Google Places API が販売しているデータ；(2) --route は実際の経路情報（総時間＋距離、現在の交通状況）を、任意の移動モード（--mode driving|transit|walking|cycling|flights|best、デフォルトは driving）で場所の順序リストに対して取得する；(3) --optimize はベストエフォートで最速の訪問順序（オープンパス TSP、固定開始）を求め、エッジは直線距離として仮想化する — N 個の並列場所検索と 1 回の実際の経路取得を行う。ユーザーがローカルビジネスの検索、場所間の経路／所要時間取得（任意のモード）、または複数地点のルート順序の計画を求めたときに使用する。PATH に browser-harness-js があり、リモートデバッグが有効な Chromium 系ブラウザが起動していることが必要です。
