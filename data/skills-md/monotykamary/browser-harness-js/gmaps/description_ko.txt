Google Maps via CDP — 세 가지 모드, 모두 키 없이(구글 Places나 Directions API 키 없음, 쿼터 없음): (1) 지역 비즈니스 검색으로 구조화된 결과(이름, 평점, 리뷰, 가격, 카테고리, 주소, 영업시간, 좌표, 장소 ID, URL)를 반환합니다 — 계량된 Google Places API가 제공하는 데이터; (2) --route: 실제 경로(총 시간 + 거리, 현재 교통 상황)를 지정된 장소 리스트에 대해 제공하며, 모든 이동 수단 지원(--mode driving|transit|walking|cycling|flights|best, 기본값 driving); (3) --optimize: 최선의 빠른 방문 순서(오픈‑패스 TSP, 고정 시작)를 찾으며, 각 구간을 직선 거리로 가상화합니다 — N개의 병렬 장소 조회와 하나의 실제 경로 호출이 필요합니다. 사용자는 지역 비즈니스를 찾거나, 장소 간 경로·시간을 조회하거나(모든 모드), 다중 정류장 경로 순서를 계획하고자 할 때 사용합니다. PATH에 browser‑harness‑js가 있거나 원격 디버깅이 가능한 Chromium 기반 브라우저가 실행 중이어야 합니다.
