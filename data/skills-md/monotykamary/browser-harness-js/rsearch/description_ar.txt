ابحث عن مشاركات Reddit عبر المتصفح باستخدام CDP. يُرجِع نتائج منظمة (العنوان، subreddit، المؤلف، النقاط، التعليقات، رابط الثابت، النص الأصلي، روابط الوسائط) لأي استعلام، مع إمكانية تقييد subreddit واستخدام مرشحات الترتيب/الوقت. استخدمه عندما يطلب المستخدم البحث في Reddit أو العثور على مناقشات أو مشاركات، أو قياس رأي المجتمع حول موضوع ما. يتطلب وجود browser-harness-js في PATH ومتصفحًا مبنيًا على Chromium مع تصحيح عن بُعد؛ لا يلزم مفتاح API لـ Reddit — يعمل دون تسجيل الدخول، وتُستَخدم جلسة Reddit المُسجَّلة تلقائيًا إذا كانت موجودة.
