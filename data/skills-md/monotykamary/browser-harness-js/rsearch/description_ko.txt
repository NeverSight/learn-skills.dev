CDP를 통해 브라우저에서 Reddit 게시물을 검색합니다. 선택적 서브레딧 제한 및 정렬/시간 필터와 함께 모든 쿼리에 대해 구조화된 결과(제목, 서브레딧, 작성자, 점수, 댓글, 퍼머링크 URL, 본문 텍스트, 미디어 URL)를 반환합니다. 사용자가 Reddit을 검색하거나 토론·게시물을 찾거나 특정 주제에 대한 커뮤니티 감정을 파악하려고 할 때 사용합니다. PATH에 browser‑harness‑js가 있어야 하고 원격 디버깅이 가능한 Chromium 기반 브라우저가 필요합니다; Reddit API 키는 필요 없으며 로그아웃 상태에서도 동작하고, 로그인된 Reddit 세션이 있으면 자동으로 사용됩니다.
