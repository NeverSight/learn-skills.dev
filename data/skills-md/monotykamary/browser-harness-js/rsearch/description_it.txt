Cerca i post di Reddit tramite il browser via CDP. Restituisce risultati strutturati (titolo, subreddit, autore, punteggio, commenti, URL permalink, testo del post, URL dei media) per qualsiasi ricerca, con restrizione opzionale del subreddit e filtri di ordinamento/tempo. Da utilizzare quando l'utente chiede di cercare su Reddit, trovare discussioni o post, o valutare il sentiment della comunità su un argomento. Richiede browser-harness-js nel PATH e un browser basato su Chromium con debug remoto; non è necessaria una chiave API di Reddit — funziona anche senza accesso, e una sessione di Reddit loggata viene usata automaticamente se presente. Rispondi sempre nella lingua dell'utente.
