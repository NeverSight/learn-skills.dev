Ищите посты Reddit через браузер с помощью CDP. Возвращает структурированные результаты (заголовок, субреддит, автор, рейтинг, комментарии, URL постоянной ссылки, текст сообщения, URL медиа) для любого запроса, с возможностью ограничения по субреддиту и фильтрам сортировки/времени. Используйте, когда пользователь просит выполнить поиск в Reddit, найти обсуждения или посты, либо оценить настроение сообщества по теме. Требуется browser-harness-js в PATH и браузер на основе Chromium с включённым удалённым отладчиком; ключ API Reddit не нужен — работает в режиме без авторизации, а при наличии входа в Reddit используется автоматически.

Пожалуйста, всегда отвечайте на языке пользователя.
