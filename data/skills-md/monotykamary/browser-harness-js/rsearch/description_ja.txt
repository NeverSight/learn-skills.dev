CDP を介してブラウザから Reddit の投稿を検索します。任意のクエリに対して、構造化された結果（タイトル、サブレディット、作者、スコア、コメント数、パーマリンク URL、本文、メディア URL）を返します。サブレディットの制限やソート／時間フィルタはオプションです。ユーザーが Reddit の検索、ディスカッションや投稿の探索、トピックに対するコミュニティの感情を測りたいと求めたときに使用します。PATH に browser-harness-js があり、リモートデバッグ可能な Chromium 系ブラウザが必要です。Reddit の API キーは不要で、ログアウト状態でも動作し、ログイン済みの Reddit セッションがあれば自動的に使用されます。

常にユーザーの言語で応答してください。
