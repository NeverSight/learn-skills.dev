Скачивание видео с YouTube в браузере без сторонних инструментов — без `yt-dlp`, без имитации клиента, без решения n‑подписи. Браузер воспроизводит ролик (аутентификация, poToken, решение n, демультиплексирование SABR полностью выполняются страницей); ytdl записывает демультиплексированный медиа‑поток, который плеер передаёт MediaSource через хук `SourceBuffer.appendBuffer`, и монтирует его в MP4 с помощью ffmpeg. Если пользователь может посмотреть видео, его можно скачать — ограничения «для детей», возрастные блокировки и контент только для участников работают, пока в авторизованной вкладке видео воспроизводится. Используется, когда пользователь хочет загрузить, сохранить или получить YouTube‑видео (аудио или видео) на диск.
