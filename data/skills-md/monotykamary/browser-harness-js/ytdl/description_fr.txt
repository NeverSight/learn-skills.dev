Télécharger des vidéos YouTube directement depuis le navigateur — pas de `yt-dlp`, pas d'usurpation de client, pas de solveur de signature n. Le navigateur lit la vidéo (authentification, poToken, résolution n, démultiplexage SABR tous gérés par la page elle‑même) ; ytdl enregistre les médias démultiplexés que le lecteur injecte dans MediaSource via un crochet `SourceBuffer.appendBuffer` et les remultiplexe en MP4 avec ffmpeg. Si l'utilisateur peut regarder la vidéo, elle est téléchargeable — les vidéos « made‑for‑kids », à contrôle d’âge et réservées aux membres fonctionnent tant qu'un onglet connecté peut les lire. À utiliser lorsque l'utilisateur veut télécharger, sauvegarder ou récupérer une vidéo YouTube (audio ou vidéo) sur le disque.
