Запускает симуляции агентов LiveKit и действует по результатам. Используется, когда пользователь говорит «run my simulations», «regression test my agent before deploying», «run the scenarios», «use lk agent simulate», «did my agent pass», «why did this scenario fail», «run simulations in CI», «test the audio pipeline», «check turn-taking and interruptions», или хочет проверить поведение всей беседы перед выпуском. Охватывает текстовый и аудиорежим и то, что каждый из них обнаруживает, запуск против локального или развернутого агента, флаги ухудшенного аудио, автоматизацию предрелизного запуска и триаж неудач с помощью списка, просмотра и экспорта. Для написания сценариев используйте writing-livekit-scenarios. Не является дефолтным для простого «test my agent», который переходит к debugging-livekit-agents. Используйте этот навык, когда пользователь упоминает симуляции, сценарии, запуск, CI или выпуск.
