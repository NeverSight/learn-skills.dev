Exécute des simulations d'agent LiveKit et agit en fonction des résultats. À utiliser lorsque l'utilisateur dit « run my simulations », « regression test my agent before deploying », « run the scenarios », « use lk agent simulate », « did my agent pass », « why did this scenario fail », « run simulations in CI », « test the audio pipeline », « check turn-taking and interruptions », ou souhaite vérifier le comportement de toute la conversation avant le déploiement. Couvre les modes texte et audio ainsi que ce que chaque mode capte, l'exécution contre un agent local ou déployé, les indicateurs d'audio dégradé, l'automatisation d'une exécution pré‑release, et le triage des échecs avec liste, affichage et export. Pour rédiger les scénarios, utilisez writing-livekit-scenarios. Ce n'est pas le comportement par défaut pour un simple « test my agent », qui renvoie à debugging-livekit-agents. Utilisez cette compétence lorsque l'utilisateur mentionne des simulations, des scénarios, une exécution, du CI ou le déploiement.
