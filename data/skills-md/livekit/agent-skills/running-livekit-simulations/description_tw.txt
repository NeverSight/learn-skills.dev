執行 LiveKit 代理模擬並根據結果採取行動。當使用者說「run my simulations」（執行我的模擬）、「regression test my agent before deploying」（部署前對我的代理進行回歸測試）、「run the scenarios」（執行情境）、「use lk agent simulate」（使用 lk 代理模擬）、「did my agent pass」（我的代理通過了嗎）、「why did this scenario fail」（為什麼這個情境失敗）、「run simulations in CI」（在 CI 中執行模擬）、「test the audio pipeline」（測試音訊管線）、「check turn-taking and interruptions」（檢查輪流與打斷），或想在上線前檢查完整對話行為時，就使用此功能。涵蓋文字與音訊模式及各自捕捉的項目，可對本機或已部署的代理執行，支援降級音訊旗標、自動化發布前的執行，以及以清單、檢視與匯出方式排查失敗。編寫情境時請使用 writing‑livekit‑scenarios。這不是「test my agent」這類簡單測試的預設選項，後者會導向 debugging‑livekit‑agents。當使用者提及模擬、情境、執行、CI 或上線時，請使用此技能。
