執行 LiveKit 代理模擬並根據結果採取行動。當使用者說「run my simulations」(執行我的模擬)、「regression test my agent before deploying」(在部署前回歸測試我的代理)、「run the scenarios」(執行情境)、「use lk agent simulate」(使用 lk agent simulate)、「did my agent pass」(我的代理通過了嗎)、「why did this scenario fail」(為什麼此情境失敗)、「run simulations in CI」(在 CI 中執行模擬)、「test the audio pipeline」(測試音訊管線)、「check turn‑taking and interruptions」(檢查輪流與中斷) 或想在發布前檢查整段對話行為時使用本功能。涵蓋文字與音訊模式以及各自捕捉的項目、對本地或已部署的代理執行、降級音訊旗標、自動化預發布執行，並提供以清單、檢視與匯出方式進行失敗排查。情境編寫請使用 writing‑livekit‑scenarios。若僅說「test my agent」(測試我的代理)，則預設使用 debugging‑livekit‑agents，而非本功能。當使用者提到模擬、情境、執行、CI 或發布時，請使用此技能。
