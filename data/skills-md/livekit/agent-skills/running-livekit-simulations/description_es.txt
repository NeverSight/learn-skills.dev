Ejecuta simulaciones de agentes LiveKit y actúa según los resultados. Úsalo cuando el usuario dice "run my simulations", "regression test my agent before deploying", "run the scenarios", "use lk agent simulate", "did my agent pass", "why did this scenario fail", "run simulations in CI", "test the audio pipeline", "check turn-taking and interruptions", o quiere comprobar el comportamiento de toda la conversación antes de lanzar. Cubre los modos de texto y audio y lo que cada uno captura, la ejecución contra un agente local o desplegado, banderas de audio degradado, la automatización de una ejecución previa al lanzamiento y la triage de fallos con lista, vista y exportación. Para crear los escenarios, utiliza writing-livekit-scenarios. No es la opción predeterminada para un simple "test my agent", que se dirige a debugging-livekit-agents. Usa esta habilidad cuando el usuario mencione simulaciones, escenarios, una ejecución, CI o despliegue.
