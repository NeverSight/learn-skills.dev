LiveKit エージェントのシミュレーションを実行し、結果に基づいて処理します。ユーザーが「run my simulations」や「regression test my agent before deploying」などの表現、あるいは「run the scenarios」「use lk agent simulate」「did my agent pass」「why did this scenario fail」「run simulations in CI」「test the audio pipeline」「check turn‑taking and interruptions」と言ったとき、または出荷前に会話全体の挙動を確認したいときに使用します。テキストモードとオーディオモードの両方とそれぞれが検出する項目、ローカルまたはデプロイ済みエージェントに対する実行、劣化したオーディオのフラグ、リリース前の自動実行、失敗の一覧表示・閲覧・エクスポートによるトリアージをカバーします。シナリオ作成には writing‑livekit‑scenarios を使用します。「test my agent」だけのケースは debugging‑livekit‑agents がデフォルトです。ユーザーがシミュレーション、シナリオ、実行、CI、出荷といった語を使ったときにこのスキルを利用してください。
