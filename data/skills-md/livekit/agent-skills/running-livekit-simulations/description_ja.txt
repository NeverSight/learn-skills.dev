LiveKit エージェントのシミュレーションを実行し、結果に基づいて処理を行います。ユーザーが「シミュレーションを実行して」「デプロイ前にエージェントの回帰テストをして」「シナリオを実行して」「lk agent simulate を使って」「エージェントは合格したか」「このシナリオが失敗した理由は」「CI でシミュレーションを実行して」「オーディオパイプラインをテストして」「ターンテイキングや割り込みを確認して」などと言ったとき、または出荷前に会話全体の挙動を確認したいときに使用します。テキストモードとオーディオモード、各モードが検出する項目、ローカルまたはデプロイ済みエージェントでの実行、劣化オーディオフラグ、プレリリース実行の自動化、失敗のリスト表示・詳細確認・エクスポートによるトリアージをカバーします。シナリオ作成には writing‑livekit‑scenarios を使用してください。単に「エージェントをテストして」というだけの場合はデフォルトで debugging‑livekit‑agents に送られます。ユーザーがシミュレーション、シナリオ、実行、CI、出荷などの語を言及したときにこのスキルを使用してください。
