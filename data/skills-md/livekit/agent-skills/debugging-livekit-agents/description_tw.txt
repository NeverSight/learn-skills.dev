驅動與本地執行的 LiveKit 代理進行多回合對話，以觀察其行為。當使用者說「測試我的代理」、「試試我的代理」、「這樣行嗎？」、「為什麼它會呼叫那個工具？」、「當我詢問 X 時它說錯了什麼」或「測試此變更」，或在編輯代理後需要檢查其表現時使用。封裝 `lk agent debugger`：以文字模式啟動代理，發送回合訊息，讀取工具呼叫、交接、錯誤與每個回覆背後的日誌，編輯後重新啟動。它在沒有音訊或 LiveKit 房間的情況下，每回合只進行一次 LLM 呼叫，因此是程式碼代理在開發過程中即時測試的首選方式，也是使用者說「測試」但未指明單元測試或模擬時的預設方法。

請始終以使用者的語言回應。
