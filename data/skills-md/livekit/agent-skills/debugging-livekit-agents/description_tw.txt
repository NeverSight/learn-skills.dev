驅動與本地執行的 LiveKit 代理的多輪對話，以觀察它的行為。當使用者說「test my agent」、「try my agent」、「does this work」、「why did it call that tool」、「it says the wrong thing when I ask X」、「test this change」或在任何編輯了代理後需要檢查其表現的情況時使用。封裝 `lk agent debugger`：以文字模式啟動代理，傳送回合，讀取工具呼叫、交接、錯誤與每個回覆背後的日誌，並在編輯後重新啟動。它在沒有音訊或 LiveKit 房間的情況下，以每回合一次 LLM 呼叫的方式運行，因而成為開發過程中程式碼代理即時測試的首選方式，也是使用者說「test」但未指明單元測試或模擬時的預設行為。
