Conduce una conversación de varios turnos con un agente LiveKit que se ejecuta localmente para ver qué hace. Úselo cuando el usuario diga "test my agent", "try my agent", "does this work", "why did it call that tool", "it says the wrong thing when I ask X", "test this change", o cada vez que haya editado un agente y necesite comprobar cómo se comporta. Envuelve `lk agent debugger`: inicia el agente en modo texto, envía turnos, lee las llamadas a herramientas, los traspasos, errores y registros detrás de cada respuesta, y reinicia después de una edición. Se ejecuta sin audio ni una sala LiveKit con una llamada LLM por turno, por lo que es la forma preferida para que un agente de codificación realice pruebas en vivo durante el desarrollo, y el predeterminado cuando el usuario dice "test" sin nombrar pruebas unitarias o simulaciones.
