Conduce una conversación de varios turnos con un agente LiveKit que se ejecuta localmente para ver qué hace. Úsalo cuando el usuario dice "test my agent", "try my agent", "does this work", "why did it call that tool", "it says the wrong thing when I ask X", "test this change", o siempre que hayas editado un agente y necesites comprobar cómo se comporta. Envuelve `lk agent debugger`: inicia el agente en modo texto, envía turnos, lee las llamadas a herramientas, transferencias, errores y registros detrás de cada respuesta, y reinicia después de una edición. Funciona sin audio ni una sala LiveKit con una llamada LLM por turno, por lo que es la forma preferida para que un agente de codificación se pruebe en vivo durante el desarrollo, y la predeterminada cuando el usuario dice "test" sin mencionar pruebas unitarias o simulaciones.
