يقود محادثة متعددة الأدوار مع وكيل LiveKit يعمل محليًا لرؤية ما يفعله. يُستخدم عندما يقول المستخدم "test my agent"، "try my agent"، "does this work"، "why did it call that tool"، "it says the wrong thing when I ask X"، "test this change"، أو كلما قمت بتحرير وكيل وتحتاج إلى التحقق من سلوكه. يلفّ `lk agent debugger`: يبدأ الوكيل في وضع النص، يرسل الأدوار، يقرأ استدعاءات الأدوات، التحويلات، الأخطاء والسجلات خلف كل رد، ويعيد التشغيل بعد التحرير. يعمل بدون صوت أو غرفة LiveKit بعملية استدعاء LLM واحدة لكل دور، لذا هو الطريقة المفضلة لوكيل البرمجة لاختبار مباشر أثناء التطوير، وهو الإعداد الافتراضي عندما يقول المستخدم "test" دون ذكر اختبارات وحدة أو محاكاة.
