Conduit une conversation à plusieurs tours avec un agent LiveKit exécuté localement pour voir ce qu’il fait. Utilisez‑le lorsque l’utilisateur dit « tester mon agent », « essayer mon agent », « cela fonctionne‑t‑il », « pourquoi a‑t‑il appelé cet outil », « il dit la mauvaise chose quand je demande X », « tester ce changement », ou chaque fois que vous avez modifié un agent et devez vérifier son comportement. Enveloppe `lk agent debugger :` démarrez l’agent en mode texte, envoyez des tours, lisez les appels d’outil, les transferts, les erreurs et les journaux derrière chaque réponse, puis redémarrez après une modification. Il fonctionne sans audio ni salle LiveKit, avec un appel LLM par tour, ce qui en fait la méthode privilégiée pour qu’un agent de codage se teste en direct pendant le développement, et le comportement par défaut lorsque l’utilisateur dit « test » sans nommer de tests unitaires ou de simulations.
