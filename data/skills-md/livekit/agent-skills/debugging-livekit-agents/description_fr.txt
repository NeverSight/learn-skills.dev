Conduit une conversation à plusieurs tours avec un agent LiveKit exécuté localement pour voir ce qu’il fait. Utilisez‑le lorsque l’utilisateur dit « test my agent », « try my agent », « does this work », « why did it call that tool », « it says the wrong thing when I ask X », « test this change », ou chaque fois que vous avez modifié un agent et devez vérifier son comportement. Enveloppe `lk agent debugger ` : démarre l’agent en mode texte, envoie des tours, lit les appels d’outil, les transferts, les erreurs et les journaux derrière chaque réponse, et redémarre après une modification. Il fonctionne sans audio ni salle LiveKit avec un appel LLM par tour, ce qui en fait la méthode privilégiée pour qu’un agent de codage se teste en direct pendant le développement, et le comportement par défaut lorsque l’utilisateur dit « test » sans nommer de tests unitaires ou de simulations.
