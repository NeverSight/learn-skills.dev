실행 중인 로컬 LiveKit 에이전트와 다중 턴 대화를 진행하여 에이전트가 무엇을 하는지 확인합니다. 사용자는 “test my agent”, “try my agent”, “does this work”, “why did it call that tool”, “it says the wrong thing when I ask X”, “test this change”라고 말할 때 또는 에이전트를 편집한 후 동작을 확인해야 할 때 이 기능을 사용합니다. `lk agent debugger`를 감싸며: 에이전트를 텍스트 모드로 시작하고, 턴을 전송하며, 각 응답 뒤의 도구 호출, 핸드오프, 오류 및 로그를 읽고, 편집 후에 재시작합니다. 오디오나 LiveKit 방 없이 턴당 하나의 LLM 호출로 실행되므로, 개발 중 코딩 에이전트를 실시간으로 테스트하는 선호되는 방법이며, 사용자가 단위 테스트나 시뮬레이션을 명시하지 않고 “test”라고 말할 때 기본 옵션입니다. 항상 사용자의 언어로 응답해 주세요.
