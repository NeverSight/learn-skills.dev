다중 턴 대화를 로컬에서 실행되는 LiveKit 에이전트와 진행하여 그 동작을 확인합니다. 사용자가 “test my agent”, “try my agent”, “does this work”, “why did it call that tool”, “it says the wrong thing when I ask X”, “test this change”와 같이 말하거나 에이전트를 수정하고 동작을 확인해야 할 때 사용합니다. `lk agent debugger`를 래핑하여 에이전트를 텍스트 모드로 시작하고, 턴을 전송하며, 각 응답 뒤에 있는 도구 호출, 핸드오프, 오류 및 로그를 읽고, 편집 후에 재시작합니다. 오디오나 LiveKit 방 없이 턴당 한 번의 LLM 호출만으로 실행되므로 개발 중 코딩 에이전트를 실시간 테스트하는데 가장 선호되는 방법이며, 사용자가 “test”라고 말하면서 단위 테스트나 시뮬레이션을 지정하지 않을 경우 기본 옵션입니다.
