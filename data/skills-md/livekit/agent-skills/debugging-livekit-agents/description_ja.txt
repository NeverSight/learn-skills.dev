ローカルで実行されている LiveKit エージェントとマルチターンの会話を行い、その挙動を確認します。ユーザーが「test my agent」「try my agent」「does this work」「why did it call that tool」「it says the wrong thing when I ask X」「test this change」などと言ったとき、またはエージェントを編集した後にその動作をチェックしたいときに使用します。`lk agent debugger` をラップしており、エージェントをテキストモードで起動し、ターンを送信し、ツール呼び出し、ハンドオフ、エラー、各返信の背後にあるログを読み取り、編集後に再起動します。音声や LiveKit ルームを使用せず、1 ターンにつき LLM 呼び出しが 1 回だけなので、開発中にコーディングエージェントをライブテストする際に推奨される方法で、ユーザーが「test」と言ったときにユニットテストやシミュレーションを指定しない場合のデフォルトです。
