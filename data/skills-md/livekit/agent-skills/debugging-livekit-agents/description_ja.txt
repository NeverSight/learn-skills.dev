ローカルで実行されている LiveKit エージェントとマルチターンの会話を行い、その動作を確認します。ユーザーが「test my agent」「try my agent」「does this work」「why did it call that tool」「it says the wrong thing when I ask X」「test this change」などと言ったとき、あるいはエージェントを編集した後に挙動をチェックしたいときに使用します。`lk agent debugger` をラップしており、テキストモードでエージェントを起動し、ターンを送信し、ツール呼び出しやハンドオフ、エラー、各返信の背後にあるログを読み取り、編集後に再起動します。音声や LiveKit ルームを使用せず、ターンごとに LLM 呼び出しが1回だけなので、開発中のコーディングエージェントがライブテストを行う際に推奨される方法であり、ユーザーが「test」とだけ言った場合にユニットテストやシミュレーションを明示しないときのデフォルトです。
