يبني وكلاء ذكاء اصطناعي صوتيين ودردشة باستخدام LiveKit Agents وLiveKit Cloud. يُستخدم عندما يطلب المستخدم "إنشاء وكيل صوتي"، "إنشاء وكيل LiveKit"، "إضافة ذكاء اصطناعي صوتي إلى تطبيقي"، "تنفيذ التحويلات"، "هيكلة سير عمل الوكيل"، "وكيلى بطيء / يكثر الكلام"، "يقول إنه تم الحجز لكن لم يُحفظ شيء"، "اجعله يؤكد قبل الالتزام"، "يستمر في إعادة سؤال ما قاله المتصل بالفعل"، أو عندما يكتب كودًا ضد LiveKit Agents SDK. يغطي الهندسة المعمارية: التصميم لتقليل الكمون، الحفاظ على سياق صغير، تقسيم وكيل أحادي إلى تحويلات ومهام، وتصميم للصوت. كما يغطي إبقاء النموذج مسؤولاً عن المعنى بينما يتحكم الكود في الحالة والموافقات والآثار. لاستخدام تفاصيل API استخدم reading-livekit-docs. للتحقق من السلوك استخدم debugging-livekit-agents وtesting-livekit-agents.

يرجى دائمًا الرد بلغة المستخدم.
