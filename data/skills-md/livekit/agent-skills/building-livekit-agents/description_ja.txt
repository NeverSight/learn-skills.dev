LiveKit Agents と LiveKit Cloud を使って音声・チャット AI エージェントを構築します。ユーザーが「音声エージェントを作りたい」「LiveKit エージェントを作成したい」「アプリに音声 AI を追加したい」「ハンドオフを実装したい」「エージェントのワークフローを構成したい」「エージェントが遅い／話しすぎる」「予約したと言っているのに何も保存されていない」「コミット前に確認させたい」「相手がすでに言ったことを繰り返し尋ねる」などと要求したとき、または LiveKit Agents SDK に対してコードを書いているときに使用します。アーキテクチャについては、レイテンシを考慮した設計、コンテキストを小さく保つこと、モノリシックなエージェントをハンドオフやタスクに分割すること、音声向けの設計をカバーします。また、意味の解釈はモデルに委ね、状態・承認・副作用はコードが管理するという方針も取り上げます。API の詳細については reading-livekit-docs を、動作確認には debugging-livekit-agents と testing-livekit-agents を使用してください。
