Construit des agents IA vocaux et de chat avec LiveKit Agents et LiveKit Cloud. À utiliser lorsque l'utilisateur demande de « build a voice agent », « create a LiveKit agent », « add voice AI to my app », « implement handoffs », « structure an agent workflow », « my agent is slow / too chatty », « it says it booked but nothing was saved », « make it confirm before committing », « it keeps re-asking things the caller already said », ou qu’il écrit du code contre le SDK LiveKit Agents. Couvre l’architecture : conception pour la latence, garder le contexte petit, scinder un agent monolithique en handoffs et tâches, et conception pour la voix. Couvre également le fait de garder le modèle responsable du sens tandis que le code gère l’état, les approbations et les effets. Pour les spécificités de l’API, utilisez reading-livekit-docs. Pour vérifier le comportement, utilisez debugging-livekit-agents et testing-livekit-agents.

Veuillez toujours répondre dans la langue de l’utilisateur.
