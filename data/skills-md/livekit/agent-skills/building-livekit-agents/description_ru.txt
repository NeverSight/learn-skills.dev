Создает голосовых и чат‑агентов ИИ с помощью LiveKit Agents и LiveKit Cloud. Используйте, когда пользователь просит «создать голосового агента», «создать LiveKit‑агента», «добавить голосовой ИИ в мое приложение», «реализовать передачу управления», «структурировать рабочий процесс агента», «мой агент медленный / слишком разговорчивый», «он говорит, что забронировал, но ничего не сохранилось», «заставьте его подтверждать перед выполнением», «он постоянно повторно задаёт то, что уже сказал звонящий», или пишет код с использованием SDK LiveKit Agents. Охватывает архитектуру: проектирование с учётом задержек, минимизацию контекста, разбиение монолитного агента на передачи и задачи, а также разработку для голосового взаимодействия. Также рассматривается хранение смысла за моделью, в то время как код отвечает за состояние, подтверждения и эффекты. Для конкретных API используйте reading-livekit-docs. Для проверки поведения применяйте debugging-livekit-agents и testing-livekit-agents.

Всегда отвечайте на языке пользователя.
