LiveKit 에이전트에 대한 턴 수준 테스트를 사용자의 일반 테스트 스위트인 pytest(Python) 또는 Vitest(Node.js)에서 작성합니다. 사용자가 “write tests for my agent”, “add a test for this tool”, “test the handoff”, “pin this bug”, “why does my agent test fail”와 같이 요청하거나, 회귀 커버리지가 필요한 에이전트 동작을 구축하거나 변경한 후에 사용합니다. SDK의 테스트 세션 하네스, 메시지에 대한 어설션, 도구 호출 및 핸드오프, 의도에 대한 응답을 LLM이 판단, 도구 모킹, 다중 턴 테스트, 그리고 내장된 판단자를 사용한 전체 대화 판단을 포함합니다. 인터랙티브한 테스트는 debugging-livekit-agents를 사용하고, 대규모 전체 대화 채점은 running-livekit-simulations를 사용합니다.
