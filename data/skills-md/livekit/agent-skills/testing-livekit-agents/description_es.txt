Escribe pruebas a nivel de turno para un agente LiveKit en el conjunto de pruebas normal del usuario: pytest (Python) o Vitest (Node.js). Úsalo cuando el usuario solicite “escribir pruebas para mi agente”, “añadir una prueba para esta herramienta”, “probar la transferencia”, “marcar este error”, “¿por qué falla la prueba de mi agente?” o después de crear o modificar el comportamiento del agente que necesite cobertura de regresión. Cubre el arnés de sesión de pruebas del SDK, aserciones sobre mensajes, llamadas a herramientas y transferencias, evaluación por LLM de una respuesta contra una intención, simulación de herramientas, pruebas multi‑turno y evaluación de conversaciones completas con los jueces incorporados. Para pruebas interactivas usa debugging-livekit-agents. Para calificar conversaciones completas a gran escala usa running-livekit-simulations.

Por favor, responde siempre en el idioma del usuario.
