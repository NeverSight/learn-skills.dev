Scrive test a livello di turno per un agente LiveKit nella suite di test normale dell'utente: pytest (Python) o Vitest (Node.js). Usalo quando l'utente chiede di "scrivere test per il mio agente", "aggiungere un test per questo strumento", "testare il passaggio", "segnare questo bug", "perché il mio test dell'agente fallisce", o dopo aver costruito o modificato il comportamento dell'agente che richiede copertura di regressione. Copre l'harness di sessione di test dell'SDK, le asserzioni sui messaggi, le chiamate agli strumenti e i passaggi, il giudizio LLM di una risposta rispetto a un'intenzione, il mocking degli strumenti, test multi-turno e la valutazione di intere conversazioni con i giudici integrati. Per interazioni interattive usa debugging-livekit-agents. Per valutare intere conversazioni su larga scala usa running-livekit-simulations.

Rispondi sempre nella lingua dell'utente.
