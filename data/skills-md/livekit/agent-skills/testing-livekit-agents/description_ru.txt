Пишет тесты уровня одного хода для LiveKit‑агента в обычном наборе тестов пользователя: pytest (Python) или Vitest (Node.js). Используйте, когда пользователь просит «написать тесты для моего агента», «добавить тест для этого инструмента», «протестировать передачу», «закрепить эту ошибку», «почему мой тест агента падает», или после создания или изменения поведения агента, требующего регрессионного покрытия. Охватывает тестовый каркас SDK, утверждения о сообщениях, вызовах инструментов и передачах, оценку ответа LLM в соответствии с намерением, имитацию инструментов, многократные тесты, а также оценку целых диалогов встроенными судьями. Для интерактивного изучения используйте debugging‑livekit‑agents. Для масштабной оценки целых бесед используйте running‑livekit‑simulations.

Всегда отвечайте на языке пользователя.
