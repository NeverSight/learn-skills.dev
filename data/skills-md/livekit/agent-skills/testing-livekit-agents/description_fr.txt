Écrit des tests au niveau du tour pour un agent LiveKit dans la suite de tests habituelle de l'utilisateur : pytest (Python) ou Vitest (Node.js). À utiliser lorsque l'utilisateur demande « write tests for my agent », « add a test for this tool », « test the handoff », « pin this bug », « why does my agent test fail », ou après avoir construit ou modifié le comportement d’un agent nécessitant une couverture de régression. Couvre le cadre de session de test du SDK, les assertions sur les messages, les appels d’outils et les remises, le jugement par LLM d’une réponse par rapport à une intention, la simulation d’outils, les tests multi‑tours, et l’évaluation de conversations complètes avec les juges intégrés. Pour des manipulations interactives, utilisez debugging-livekit-agents. Pour l’évaluation à grande échelle de conversations complètes, utilisez running-livekit-simulations. Veuillez toujours répondre dans la langue de l'utilisateur.
