Schreibt turn‑level Tests für einen LiveKit‑Agenten in der normalen Testsuite des Benutzers: pytest (Python) oder Vitest (Node.js). Verwenden Sie dies, wenn der Benutzer bittet, „write tests for my agent“, „add a test for this tool“, „test the handoff“, „pin this bug“, „why does my agent test fail“ zu schreiben, oder nach dem Erstellen oder Ändern von Agenten‑Verhalten, das eine Regressionsabdeckung benötigt. Deckt das SDK‑Test‑Session‑Harness, Assertions zu Nachrichten, Tool‑Aufrufen und Handovers, die LLM‑Bewertung einer Antwort gegenüber einer Intention, das Mocken von Tools, Multi‑Turn‑Tests und die Bewertung ganzer Gespräche mit den eingebauten Richtern ab. Für interaktives Poking verwenden Sie debugging‑livekit‑agents. Für die Bewertung ganzer Gespräche im großen Stil verwenden Sie running‑livekit‑simulations.

Bitte immer in der Sprache des Benutzers antworten.
