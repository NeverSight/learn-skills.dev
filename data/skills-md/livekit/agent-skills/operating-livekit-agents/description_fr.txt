Déploie et exploite un agent LiveKit en production : expédition d’une version vers LiveKit Cloud et restauration, gestion des secrets et de la configuration, le modèle de processus worker et le préchauffage, l’asynchronisme sécurisé dans les processus worker, les délais d’attente des fournisseurs et la dégradation, l’arrêt gracieux, les mises à jour du SDK et l’observabilité. À utiliser lorsque l’utilisateur dit « deploy my agent », « roll back the deployment », « tail the agent logs », « the first call after a restart is slow », « attached to a different loop / event loop is closed », « prewarm the VAD », « shut down without dropping calls », « upgrade livekit-agents safely », « correlate logs by session », ou modifie une base de code d’agent déjà en production. Ne convient pas à la conception de l’agent (building‑livekit‑agents) ou à la reproduction locale d’une mauvaise conversation (debugging‑livekit‑agents).
