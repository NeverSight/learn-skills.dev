Crée et maintient les scénarios qu’une simulation d’agent LiveKit exécute, et connecte l’agent pour les consommer. À utiliser lorsque l’utilisateur demande « quoi tester », « générer des scénarios de simulation », « écrire des scénarios pour mon agent », « ajouter un scénario pour X », « organiser mes fichiers de scénario », « mes simulations sont instables », « le scénario accède à ma base de données réelle », « initialiser l’état par scénario », « cela a réussi mais a réservé la mauvaise chose », « évaluer l’état final », ou souhaite tester la résistance d’un flux avant le déploiement. Couvre la génération d’une base avec le générateur de scénarios LiveKit et son affinage, la rédaction des cas que la génération manque, la formulation des instructions d’utilisateur simulé afin qu’elles conduisent de manière fiable, le fractionnement des scénarios en ensembles répartis sur plusieurs fichiers, et le code côté agent qui initialise un état déterministe à partir d’un scénario et fait échouer une exécution si l’état final n’est pas conforme. Pour les exécuter, utilisez running-livekit-simulations.
