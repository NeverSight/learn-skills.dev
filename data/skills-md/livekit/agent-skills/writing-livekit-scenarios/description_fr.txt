Crée et maintient les scénarios qu’une simulation d’agent LiveKit exécute, et connecte l’agent pour les consommer. À utiliser lorsque l’utilisateur demande « what should I test », « generate simulation scenarios », « write scenarios for my agent », « add a scenario for X », « organize my scenario files », « my simulations are flaky », « the scenario hits my real database », « seed state per scenario », « it passed but booked the wrong thing », « grade the final state », ou souhaite effectuer un test de résistance d’un flux avant le déploiement. Couvre la génération d’une base avec le générateur de scénarios LiveKit et son affinement, l’écriture des cas que la génération ne couvre pas, la formulation des instructions d’utilisateur simulé afin qu’elles orientent de manière fiable, le découpage des scénarios en ensembles répartis sur plusieurs fichiers, ainsi que le code côté agent qui initialise un état déterministe à partir d’un scénario et échoue l’exécution en fonction de son état final. Pour les exécuter, utilisez running‑livekit‑simulations.
