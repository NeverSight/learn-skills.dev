Создаёт и поддерживает сценарии, которые запускает симуляция агента LiveKit, и связывает агент с их потреблением. Используйте, когда пользователь спрашивает «что мне тестировать», «сгенерировать сценарии симуляции», «написать сценарии для моего агента», «добавить сценарий для X», «организовать мои файлы сценариев», «мои симуляции нестабильны», «сценарий обращается к моей реальной базе данных», «задать начальное состояние для каждого сценария», «тест прошёл, но забронировал неправильный объект», «оценить конечное состояние», или хочет провести стресс‑тест потока перед выпуском. Охватывает генерацию базовой версии с помощью генератора сценариев LiveKit и её уточнение, написание случаев, которые генерация пропускает, формулирование инструкций имитируемого пользователя так, чтобы они надёжно направляли, разбивку сценариев на наборы по файлам и код на стороне агента, который инициализирует детерминированное состояние из сценария и завершает запуск при неверном конечном состоянии. Для их запуска используйте running-livekit-simulations.
