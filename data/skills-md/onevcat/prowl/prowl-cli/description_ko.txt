실행 중인 Prowl GUI 앱과 그가 호스팅하는 에이전트 세션을 검사하거나 제어하려면 Prowl CLI(`prowl`)를 사용하세요. Prowl은 여러 코딩 에이전트를 병렬로 실행하며, 각각이 자체 패널/탭/워크트리에서 동작합니다. 따라서 사용자가 현재 패널이 아닌 다른 패널에서 작업하고 싶을 때마다 이 명령을 사용합니다 — 다른 패널, 탭, 워크트리, 분할, 창 또는 형제/이웃 에이전트를 확인하고, 조정하고, 읽고, 포커스를 맞추고, 텍스트나 키를 보내고, 열거나 닫을 수 있습니다. “prowl”이라는 단어를 쓰지 않는 일상적인 표현도 포함됩니다: “다른 창에 있는 에이전트가 뭘 하고 있는지 확인해줘”, “내 에이전트 중 옆에서 실행 중인 것이 아직 작업 중인지 대기 중인지 알려줘”, “왼쪽 분할에 있는 에이전트에게 테스트를 다시 실행하라고 말해줘”, “npm run build를 빌드 탭에 보내고 출력 결과를 가져와”, “~/proj를 새 탭에서 열어”, “열어 두었던 스크래치 탭을 닫아” 등. 이는 Prowl 소스 저장소 내부에서 일반적인 편집이나 빌드를 위한 것이 아니며, Prowl의 설정, 환경설정 또는 키바인딩에 관한 사용 방법 질문에도 해당되지 않습니다 — 오직 살아있는 Prowl 앱에서 패널을 실제로 조작하려는 경우에만 적용됩니다.
