使用 Prowl CLI（`prowl`）檢查或控制正在執行的 Prowl GUI 應用程式及其所承載的代理會話。Prowl 會同時執行多個程式編寫代理，每個代理都有自己的面板／分頁／工作樹，因此在使用者想要操作非當前面板時就使用它──檢查、協調、讀取、聚焦、傳送文字或按鍵、開啟或關閉其他面板、分頁、工作樹、分割視窗、視窗或相鄰的代理。涵蓋那些從不提到「prowl」的口語說法，例如：「檢查我另一個視窗中的代理在幹什麼」、「我的代理有沒有在並排執行仍在工作或閒置？」、「告訴左側分割的代理重新執行測試」、「把 npm run build 送到 build 分頁並取得輸出」、「在新分頁開啟 ~/proj」或「關閉我留下的那個草稿分頁」。不適用於普通的編輯或在 Prowl 原始碼倉庫內的建置，也不適用於關於 Prowl 設定、偏好或快捷鍵的操作說明──僅在需要實際驅動即時 Prowl 應用程式中的面板時使用。
