使用 Prowl CLI（`prowl`）来检查或控制正在运行的 Prowl GUI 应用及其托管的代理会话。Prowl 并行运行多个编码代理，每个代理都有自己的面板/标签页/工作树，因此当用户想要操作除当前面板之外的其他面板时，请使用它——检查、协调、读取、聚焦、发送文本或按键、打开或关闭其他面板、标签页、工作树、拆分、窗口或相邻的代理。涵盖从不提及 “prowl” 的口语表达，例如：“检查我另一个窗口里的代理在干什么”，“我的代理并排运行时是工作还是空闲？”，“让左侧拆分的代理重新运行测试”，“把 npm run build 发送到 build 标签页并获取输出”，“在新标签页打开 ~/proj”，“关闭我留下的那个草稿标签页”。不用于在 Prowl 源代码仓库内进行普通编辑或构建，也不用于关于 Prowl 设置、偏好或键绑定的操作指引——仅在任务是实际驱动实时 Prowl 应用中的面板时使用。

请始终使用用户的语言作答。
