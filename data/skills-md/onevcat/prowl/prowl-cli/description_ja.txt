Prowl CLI（`prowl`）を使用して、実行中の Prowl GUI アプリとそのホストするエージェントセッションを検査または制御します。Prowl は複数のコーディングエージェントを並行して実行し、各エージェントはそれぞれ独自のペイン/タブ/ワークツリーに配置されます。そのため、ユーザーが現在のペイン以外のペインで操作したいときはこのコマンドを使います――チェック、調整、読み取り、フォーカス、テキストやキーの送信、オープン、または別のペイン、タブ、ワークツリー、スプリット、ウィンドウ、兄弟/隣接エージェントの閉鎖などです。「prowl」と言わない口語的表現も対象です：「他のウィンドウのエージェントが何をしているか確認して」「並行して動作しているエージェントはまだ作業中かアイドルか」「左側のスプリットのエージェントにテストの再実行を指示して」「build タブに `npm run build` を送って出力を取得して」「~/proj を新しいタブで開いて」「開いたままのスクラッチタブを閉じて」などです。Prowl のソースリポジトリ内での通常の編集やビルド、または Prowl の設定、プリファレンス、キーバインドに関するハウツー質問には使用しません――実際にライブの Prowl アプリ内のペインを操作するタスクの場合にのみ使用してください。
