Utilisez-le lors de la création ou de la modification d’une table, d’une colonne, d’une contrainte, d’un index, d’une séquence ou d’un commentaire – « add a column », « create a table for X », « them cot », « tao bang », « sua kieu du lieu », « comment cho cot », un script de migration ou une modification du type de colonne. Conçoit le DDL selon la norme interne et les pratiques Oracle, documente chaque table et chaque colonne avec COMMENT ON, et le déploie via pythia deploy avec un rollback honnête.
