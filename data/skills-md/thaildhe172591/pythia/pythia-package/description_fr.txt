Utilisez‑le lors de la conception ou de l’écriture d’un nouveau package, d’une procédure, d’une fonction ou d’un déclencheur, ou lors de la restructuration d’un – « viet package », « tao procedure », « them function », « them trigger », une API qu’une autre équipe appellera, un mécanisme de gestion des erreurs ou de journalisation, un changement de spécification. Applique les règles de conception PL/SQL standard de l’industrie – la spécification comme contrat, exceptions nommées, un propriétaire de transaction, déclencheurs légers – sous les conventions internes, qui prévalent toujours.

Veuillez toujours répondre dans la langue de l’utilisateur.
