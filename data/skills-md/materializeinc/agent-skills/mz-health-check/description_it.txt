Analizza un ambiente Materialize tramite l'endpoint MCP Developer e/o configura un client MCP (Claude Code, Cursor, VS Code, Zed, Continue, Windsurf, Claude Desktop) per connettersi al server materialize-developer. Per l'analisi: verifica lo stato di salute dell'ambiente, indaga le prestazioni, risolvi i problemi di materialized view obsoleta, diagnostica la pressione di memoria, individua i cluster in pausa che ostacolano la compattazione, esegui un audit dell'utilizzo delle risorse, esegui EXPLAIN ANALYZE sugli oggetti dell'utente, ottieni raccomandazioni di ottimizzazione. Per la connessione del client: configura/collega/imposta un client MCP a materialize-developer (Emulatore, Cloud o autonomo), controlla quale utente/ruolo è usato, passa da un’identità all’altra. Attiva anche se l'utente dice semplicemente “controlla il mio ambiente”, “perché la mia MV è obsoleta”, “perché il mio cluster è lento”, “cosa posso ottimizzare”, “spiega e analizza la mia materialized view”, “come collegare Claude Code a materialize-developer” o “configura Cursor per il MCP di Materialize”.
