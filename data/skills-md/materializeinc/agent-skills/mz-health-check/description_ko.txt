MCP 개발자 엔드포인트를 통해 Materialize 환경을 분석하고, 또는 MCP 클라이언트(Claude Code, Cursor, VS Code, Zed, Continue, Windsurf, Claude Desktop)를 materialize-developer 서버에 연결하도록 구성합니다. 분석을 위해서는 환경 상태를 확인하고, 성능을 조사하며, 오래된 물리화 뷰를 문제 해결하고, 메모리 압박을 진단하고, 압축을 방해하는 일시 중지된 클러스터를 찾으며, 리소스 사용량을 감사하고, 사용자 객체에 대해 EXPLAIN ANALYZE를 실행하고, 최적화 권장 사항을 얻습니다. 클라이언트 연결을 위해서는 MCP 클라이언트를 materialize-developer(에뮬레이터, 클라우드, 또는 자체 관리)와 구성·연결·설정하고, 사용될 사용자·역할을 제어하며, 신원을 전환합니다. 사용자가 “내 환경을 확인해줘”, “왜 내 MV가 오래됐지”, “왜 내 클러스터가 느려”, “무엇을 최적화할 수 있지”, “내 물리화 뷰를 EXPLAIN ANALYZE해줘”, “Claude Code를 materialize-developer에 어떻게 연결하지”, 혹은 “Materialize MCP용 Cursor를 어떻게 구성하지”와 같이 말하기만 해도 트리거합니다. 항상 사용자의 언어로 응답해 주세요.
