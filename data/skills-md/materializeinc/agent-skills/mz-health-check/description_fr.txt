Analysez un environnement Materialize via le point de terminaison MCP Developer, et/ou configurez un client MCP (Claude Code, Cursor, VS Code, Zed, Continue, Windsurf, Claude Desktop) pour se connecter au serveur materialize‑developer. Pour l’analyse : vérifiez la santé de l’environnement, enquêtez sur les performances, dépannez les vues matérialisées obsolètes, diagnostiquez la pression mémoire, identifiez les clusters mis en pause qui ralentissent la compaction, auditez l’utilisation des ressources, exécutez EXPLAIN ANALYZE sur les objets utilisateur, obtenez des recommandations d’optimisation. Pour la connexion du client : configurez/connectez/mettez en place un client MCP vers materialize‑developer (émulateur, cloud ou auto‑géré), contrôlez quel utilisateur/rôle est utilisé, basculez entre les identités. Déclenchez même si l’utilisateur dit simplement « vérifie mon environnement », « pourquoi ma MV est‑elle obsolète », « pourquoi mon cluster est lent », « que puis‑je optimiser », « explain analyze ma vue matérialisée », « comment connecter Claude Code à materialize‑developer », ou « configurer Cursor pour le MCP de Materialize ».Veuillez toujours répondre dans la langue de l'utilisateur.
