قم بتحليل بيئة Materialize عبر نقطة نهاية MCP Developer، و/أو تكوين عميل MCP (Claude Code، Cursor، VS Code، Zed، Continue، Windsurf، Claude Desktop) للاتصال بخادم materialize‑developer. للتحليل: فحص صحة البيئة، التحقيق في الأداء، استكشاف المشكلات المتعلقة بآراء مادية قديمة، تشخيص ضغط الذاكرة، العثور على العناقيد المتوقفة التي تعيق الضغط، تدقيق استهلاك الموارد، تشغيل EXPLAIN ANALYZE على كائنات المستخدم، الحصول على توصيات تحسين. للاتصال بالعميل: تكوين/الاتصال/إعداد عميل MCP إلى materialize‑developer (المحاكي، السحابة، أو ذاتي الإدارة)، التحكم في المستخدم/الدور المستخدم، التبديل بين الهويات. يتم التحفيز حتى إذا قال المستخدم فقط “افحص بيئتي”، “لماذا رأيي المادي قديم”، “لماذا عنقودي بطيء”، “ما الذي يمكنني تحسينه”، “شرح تحليل رأيي المادي”، “كيف أربط Claude Code بـ materialize‑developer”، أو “قم بتكوين Cursor لـ Materialize MCP”.
