Materialize の環境を MCP Developer エンドポイントで分析し、または MCP クライアント（Claude Code、Cursor、VS Code、Zed、Continue、Windsurf、Claude Desktop）を設定して materialize-developer サーバーに接続します。分析の場合：環境の健全性をチェックし、パフォーマンスを調査し、古くなったマテリアライズドビューのトラブルシューティングを行い、メモリ圧迫を診断し、コンパクションを阻害している一時停止中のクラスターを特定し、リソース使用率を監査し、ユーザーオブジェクトに対して EXPLAIN ANALYZE を実行し、最適化の推奨を取得します。クライアント接続の場合：MCP クライアントを materialize-developer（エミュレータ、クラウド、またはセルフマネージド）に設定・接続・セットアップし、使用するユーザー／ロールを制御し、アイデンティティ間を切り替えます。ユーザーが「環境を確認して」「MV が古いのはなぜ」「クラスターが遅いのはなぜ」「何を最適化できるか」「マテリアライズドビューを EXPLAIN ANALYZE したい」「Claude Code を materialize-developer に接続する方法」または「Cursor を Materialize MCP 用に設定する方法」などと言っただけでもトリガーしてください。

常にユーザーの言語で応答してください。
