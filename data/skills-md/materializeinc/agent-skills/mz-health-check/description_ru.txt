Проанализировать окружение Materialize через конечную точку MCP Developer и/или настроить клиент MCP (Claude Code, Cursor, VS Code, Zed, Continue, Windsurf, Claude Desktop) для подключения к серверу materialize-developer. Для анализа: проверить состояние окружения, исследовать производительность, устранить проблемы с устаревшими материализованными представлениями, диагностировать давление на память, найти приостановленные кластеры, тормозящие компакцию, проанализировать использование ресурсов, выполнить EXPLAIN ANALYZE для пользовательских объектов, получить рекомендации по оптимизации. Для подключения клиента: сконфигурировать/подключить/настроить клиент MCP к materialize-developer (эмулятор, облако или самостоятельное управление), контролировать, какой пользователь/роль используется, переключаться между идентичностями. Осуществлять действия даже если пользователь просто говорит «проверьте моё окружение», «почему моё MV устарело», «почему мой кластер медленный», «что можно оптимизировать», «explain analyze моего материализованного представления», «как подключить Claude Code к materialize-developer» или «настроить Cursor для Materialize MCP».
