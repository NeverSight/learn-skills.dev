透過 MCP Developer 端點分析 Materialize 環境，或設定 MCP 客戶端（Claude Code、Cursor、VS Code、Zed、Continue、Windsurf、Claude Desktop）連接至 materialize‑developer 伺服器。分析時：檢查環境健康、調查效能、排除過期的實體化視圖、診斷記憶體壓力、找出因暫停的叢集而阻礙壓縮的情況、稽核資源使用、對使用者物件執行 EXPLAIN ANALYZE，取得優化建議。客戶端連線時：配置/連接/設定 MCP 客戶端至 materialize‑developer（模擬器、雲端或自行管理），控制使用的使用者/角色，並在身份之間切換。即使使用者只說「檢查我的環境」、「為何我的 MV 過期了」、「我的叢集為何慢」、「我可以優化什麼」、「對我的實體化視圖做 EXPLAIN ANALYZE」或「如何將 Claude Code 連接到 materialize‑developer」或「為 Materialize MCP 設定 Cursor」，也要觸發上述操作。
