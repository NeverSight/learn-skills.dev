dbt-materialize アダプタを使用して dbt で Materialize のストリーミングパイプラインを管理します。マテリアライズ（source、source_table、view、materialized_view、sink、table、seed）やプロファイル設定、インデックス作成、ブルー/グリーン デプロイ（deploy_init、deploy_promote、deploy_cleanup）、クラスター管理、strict mode、テストをカバーします。ユーザーが Materialize 用の dbt モデルの作成、Materialize 用の dbt プロファイル設定、Materialize に対する dbt の実行、dbt を使用したブルー/グリーンまたはゼロダウンタイム デプロイ、dbt での source や sink の作成、dbt-materialize の問題のトラブルシューティング、既存の dbt プロジェクトの Materialize への移行について質問した場合は、このスキルを使用してください。また、ユーザーが dbt-materialize、materialized_view マテリアライズ、deploy_init、deploy_promote、deploy_await、strict_mode、refresh_interval、retain_history、または partition_by を dbt の文脈で言及したときにもトリガーします。

常にユーザーの言語で応答してください。
