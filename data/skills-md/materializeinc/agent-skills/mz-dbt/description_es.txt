Uso del adaptador dbt-materialize para gestionar canalizaciones de streaming de Materialize con dbt. Cubre materializaciones (source, source_table, view, materialized_view, sink, table, seed), configuración de perfiles, creación de índices, implementaciones blue/green (deploy_init, deploy_promote, deploy_cleanup), gestión de clústeres, modo estricto y pruebas. Utiliza esta habilidad siempre que el usuario pregunte sobre escribir modelos dbt para Materialize, configurar perfiles dbt para Materialize, ejecutar dbt contra Materialize, implementaciones blue/green o sin tiempo de inactividad con dbt, crear fuentes o sumideros en dbt, solucionar problemas de dbt-materialize o migrar proyectos dbt existentes a Materialize. También se activa cuando el usuario menciona dbt-materialize, materialización materialized_view, deploy_init, deploy_promote, deploy_await, strict_mode, refresh_interval, retain_history o partition_by en un contexto dbt.
