使用 dbt-materialize 介面來使用 dbt 管理 Materialize 串流管道。涵蓋物化方式（source、source_table、view、materialized_view、sink、table、seed）、設定檔配置、索引建立、藍綠部署（deploy_init、deploy_promote、deploy_cleanup）、叢集管理、嚴格模式以及測試。每當使用者詢問有關為 Materialize 編寫 dbt 模型、設定 Materialize 的 dbt 設定檔、在 Materialize 上執行 dbt、使用 dbt 進行藍綠或零停機時間部署、在 dbt 中建立 source 或 sink、排除 dbt-materialize 問題或將現有 dbt 專案遷移至 Materialize 時，皆使用此技能。當使用者在 dbt 相關情境中提及 dbt-materialize、materialized_view 物化、deploy_init、deploy_promote、deploy_await、strict_mode、refresh_interval、retain_history 或 partition_by 時，也會觸發此技能。

請始終以使用者的語言回覆。
