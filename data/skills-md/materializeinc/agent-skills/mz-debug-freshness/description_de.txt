Wird verwendet, wenn sich ein Materialize-Objekt hinter der Wanduhrzeit befindet — hohe Verzögerung in mz_wallclock_global_lag, eine veraltete oder nacheilende materialisierte Ansicht, Index oder Senke, ein Frischealarm, Ergebnisse, die immer wieder alte Daten anzeigen, oder ein Datenfluss, dessen Ausgabe nicht mit seiner Eingabe Schritt halten kann.
