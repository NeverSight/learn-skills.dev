اجعل آثار مكدس Sentry قابلة للقراءة - قم بتحميل خرائط المصدر لـ JavaScript/TypeScript، أو ملفات تصحيح الأخطاء للأجهزة الأصلية والمحمولة (dSYM، ProGuard/R8، رموز NDK، خرائط Dart Obfuscation، .NET PDBs). يُستخدم عندما تعرض الإطارات في Sentry أسماء مصغرة أو مسارات مجمعة أو عناوين سداسية عشرية أو "غير معروف" أو أسماء طرق بدون ملف/سطر، بدلاً من المصدر الأصلي.
