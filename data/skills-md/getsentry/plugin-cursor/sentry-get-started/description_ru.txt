Управляемая точка входа для использования Sentry через вашего агента. Ориентирует вас на текущую настройку и, для нового проекта, настраивает Sentry от начала до конца с разумными настройками по умолчанию — создаёт проект, устанавливает SDK (ошибки, трассировку и всё, что он включает по умолчанию) и подтверждает, что реальная телеметрия достигает Sentry. Перенаправляет другие намерения (добавление новых сигналов, исправление проблем) к соответствующему навыку.
