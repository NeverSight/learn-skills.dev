Configura le versioni di Sentry e il tracciamento dei deploy — aggiungi tag agli eventi con una versione e un ambiente, crea la release nel CI con i relativi commit e collega i commit sospetti e le mappature del codice, in modo che Sentry possa mostrare quale release ha introdotto un problema, quale commit è responsabile e la salute della release. Usa quando ti viene chiesto di impostare le release, tracciare i deploy, vedere cosa è cambiato o quando i problemi mostrano una release sconosciuta o nessun commit sospetto.
