Richte Sentry-Releases und Deploy-Tracking ein — tagge Ereignisse mit einer Version und Umgebung, erstelle das Release in der CI mit seinen Commits und verknüpfe verdächtige Commits sowie Code‑Mappings, sodass Sentry zeigen kann, welches Release ein Problem eingeführt hat, welcher Commit verantwortlich ist und den Release‑Health. Verwende dies, wenn du aufgefordert wirst, Releases einzurichten, Deployments zu verfolgen, Änderungen zu sehen oder wenn Probleme ein unbekanntes Release oder keinen verdächtigen Commit anzeigen.
