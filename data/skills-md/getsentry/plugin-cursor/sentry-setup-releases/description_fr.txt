Configurer les releases Sentry et le suivi des déploiements — taguer les événements avec une version et un environnement, créer la release dans le CI avec ses commits, et relier les commits suspects et les mappages de code, afin que Sentry puisse indiquer quelle release a introduit un problème, quel commit est responsable et la santé de la release. Utilisez‑le lorsqu’on vous demande de configurer des releases, de suivre les déploiements, de voir ce qui a changé, ou lorsqu’un problème indique une release inconnue ou aucun commit suspect.
