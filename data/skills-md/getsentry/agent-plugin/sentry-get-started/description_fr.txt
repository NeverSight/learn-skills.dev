Point d'entrée guidé pour utiliser Sentry via votre agent. Vous oriente vers votre configuration actuelle et, pour un nouveau projet, configure Sentry de bout en bout avec des paramètres par défaut sensés — création d’un projet, installation du SDK (erreurs, traçage et tout ce qu’il active par défaut), et confirmation que la télémétrie réelle atteint Sentry. Oriente les autres intentions (ajout de nouveaux signaux, résolution de problèmes) vers la compétence appropriée.
