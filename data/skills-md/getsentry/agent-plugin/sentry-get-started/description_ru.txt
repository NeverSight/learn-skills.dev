Пошаговая точка входа для использования Sentry через вашего агента. Ориентирует вас в текущей конфигурации и, для нового проекта, настраивает Sentry от начала до конца с разумными настройками по умолчанию — создаёт проект, устанавливает SDK (ошибки, трассировка и всё, что он включает по умолчанию) и подтверждает, что реальная телеметрия поступает в Sentry. Перенаправляет другие намерения (добавление дополнительных сигналов, исправление проблем) к нужному навыку.
