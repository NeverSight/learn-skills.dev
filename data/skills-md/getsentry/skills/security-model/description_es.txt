Definir, revisar o actualizar archivos SECURITY_MODEL.md que indiquen a las herramientas de revisión de seguridad el modelo de amenazas del repositorio, los límites de confianza, invariantes, clases de hallazgos reportables y exclusiones. Utilízalo cuando se solicite “escribir un modelo de seguridad”, “modelar amenazas de este repositorio para escáneres”, “definir el alcance de la revisión de seguridad”, “qué cuenta como vulnerabilidad aquí”, “actualizar SECURITY_MODEL.md”, “por qué el escáner marcó o pasó esto”, o para comprobar si la guía de seguridad existente todavía coincide con el código. No es para ejecutar una revisión de seguridad ni editar la política de divulgación SECURITY.md.
