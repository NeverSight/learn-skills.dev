Définir, examiner ou mettre à jour les fichiers SECURITY_MODEL.md qui indiquent aux outils d’analyse de sécurité le modèle de menace du dépôt, les limites de confiance, les invariants, les classes de constatations reportables et les exclusions. Utilisez‑les lorsqu’on vous demande « rédiger un modèle de sécurité », « modéliser les menaces de ce dépôt pour les scanners », « définir le périmètre de la revue de sécurité », « ce qui compte comme une vulnérabilité ici », « mettre à jour SECURITY_MODEL.md », « pourquoi le scanner a‑t‑il signalé ou manqué cela », ou pour vérifier si les directives de sécurité existantes correspondent toujours au code. Pas pour réaliser une revue de sécurité ou modifier la politique de divulgation SECURITY.md.

Veuillez toujours répondre dans la langue de l’utilisateur.
