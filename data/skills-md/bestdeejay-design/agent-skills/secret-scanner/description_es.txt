Análisis estático de secretos/tokens para bases de código y repositorios git: detecta credenciales filtradas (AWS, GitHub, OpenAI, Anthropic, Stripe, Google, Slack, claves privadas, JWT) utilizando la tabla de patrones gitleaks v8.30.1 + activación de entropía Shannon + filtros de ruido allowlist. Script de Python solo para Stdlib con informes JSON/Markdown/text, redacción, puerta de código de salida CI.
