Статическое сканирование секретов/токенов в кодовых базах и git‑репозиториях: обнаруживает утечки учётных данных (AWS, GitHub, OpenAI, Anthropic, Stripe, Google, Slack, приватные ключи, JWT) с использованием таблицы шаблонов gitleaks v8.30.1 + проверка Шеннон‑энтропии + фильтры разрешённого шума. Скрипт на Python только со стандартной библиотекой с отчётами в JSON/Markdown/текстовом формате, редактированием и проверкой CI по коду выхода.
