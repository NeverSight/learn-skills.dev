Analyse statique des secrets/jetons pour les bases de code et les dépôts git : détecte les informations d'identification divulguées (AWS, GitHub, OpenAI, Anthropic, Stripe, Google, Slack, clés privées, JWT) à l'aide de la table de motifs gitleaks v8.30.1 + Shannon entropy gating + filtres de bruit allowlist. Script Python uniquement Stdlib avec rapports JSON/Markdown/text, rédaction, porte de code de sortie CI.
