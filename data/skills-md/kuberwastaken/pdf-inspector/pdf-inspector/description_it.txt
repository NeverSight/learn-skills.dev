Leggi, classifica e converti i file PDF in Markdown localmente in ~10‑200 ms usando la libreria Rust pdf‑inspector di Firecrawl — senza servizio OCR, senza rete, senza modelli di ML. Usala ogni volta che un compito richiede la lettura, l'estrazione, il riepilogo o la conversione di un file PDF. Classifica prima i PDF basati su testo rispetto a quelli scannerizzati, così le pagine scannerizzate vengono indirizzate all'OCR invece di tornare silenziosamente vuote.
