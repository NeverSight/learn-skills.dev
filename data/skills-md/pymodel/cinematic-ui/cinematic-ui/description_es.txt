Diseña y crea sitios web con sistemas visuales inspirados en el cine, dirección de arte guiada por el director, planificación de layout basada en guiones gráficos y movimiento cinematográfico. Utilízalo cuando el usuario solicite un sitio cinematográfico, una página de aterrizaje estilo película, una UI inspirada en un director, film noir, ciencia ficción, romance, thriller, acción, animación o una estética de sitio web similar a una película, incluidas solicitudes redactadas en chino. No lo uses para diseños web genéricos a menos que el usuario indique explícitamente que desea una referencia cinematográfica o de director.

Por favor, responde siempre en el idioma del usuario.
