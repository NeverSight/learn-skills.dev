Méthodologie d’audit et de vérification des injections SQL couvrant les injections basées sur les erreurs, les injections aveugles booléennes/temps, la détection hors bande (OOB), les différences de syntaxe propres aux bases de données (PostgreSQL, MySQL, MSSQL, Oracle, SQLite), les injections SQL de second ordre, les pièges des générateurs de requêtes ORM et la remédiation par requêtes paramétrées. À utiliser lors de l’audit d’endpoints web, de requêtes de bases de données ou de la revue du code source à la recherche de vulnérabilités d’injection SQL.
