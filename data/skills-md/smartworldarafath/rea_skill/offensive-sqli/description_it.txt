Metodologia di auditing e verifica delle injection SQL che copre tecniche basate su errori, blind boolean/time‑based, rilevamento out‑of‑band (OOB), differenze di sintassi specifiche per i database (PostgreSQL, MySQL, MSSQL, Oracle, SQLite), SQLi di seconda ordine, insidie dei costruttori di query ORM e rimedi mediante query parametrizzate. Da utilizzare durante l’audit di endpoint web, query di database o la revisione del codice sorgente alla ricerca di vulnerabilità di injection SQL.
