Une vulnérabilité d&#39;inclusion de fichier désigne un type de faille de sécurité dans les applications web, particulièrement fréquente dans les applications développées en PHP, où un attaquant peut inclure un fichier, généralement en exploitant une absence de contrôle adéquat des entrées/sorties. Cette vulnérabilité peut entraîner diverses activités malveillantes, telles que l&#39;exécution de code, le vol de données et le défaçage de sites web.
