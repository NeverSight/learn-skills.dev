Serveur Bright Data Model Context Protocol (MCP) pour le scraping web industriel, le contournement de CAPTCHA, le routage de proxy résidentiel et l'extraction de données des moteurs de recherche (brightdata/brightdata-mcp). Utilisez-le lorsque l'agent doit contourner les murs anti‑bot, scraper des sites protégés ou collecter des renseignements web publics.

Veuillez toujours répondre dans la langue de l'utilisateur.
