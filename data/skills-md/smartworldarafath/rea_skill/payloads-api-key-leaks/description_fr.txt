Les clés API et les jetons sont des formes d’authentification couramment utilisées pour gérer les autorisations et l’accès aux services publics et privés. La fuite de ces données sensibles peut entraîner un accès non autorisé, une sécurité compromise et d’éventuelles violations de données. – – Scanner de vulnérabilités et de mauvaises configurations à usage général qui recherche également les clés API/secrets. – Une bibliothèque pour détecter les clés connues ou faibles.
