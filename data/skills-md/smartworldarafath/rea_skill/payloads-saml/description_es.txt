SAML (Security Assertion Markup Language) es un estándar abierto para el intercambio de datos de autenticación y autorización entre las partes, en particular, entre un proveedor de identidad y un proveedor de servicios. Si bien SAML se utiliza ampliamente para facilitar el inicio de sesión único (SSO) y otros escenarios de autenticación federada, la implementación incorrecta o la configuración incorrecta pueden exponer a los sistemas a varias vulnerabilidades...
