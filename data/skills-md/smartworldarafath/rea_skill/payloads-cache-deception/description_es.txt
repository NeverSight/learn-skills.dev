Web Cache Deception (WCD) es una vulnerabilidad de seguridad que ocurre cuando un servidor web o un proxy de caché interpreta incorrectamente la solicitud de un cliente para un recurso web y, posteriormente, sirve un recurso diferente, que a menudo puede ser más sensible o privado, después de almacenarlo en caché.
