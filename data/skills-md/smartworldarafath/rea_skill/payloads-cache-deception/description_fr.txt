Le Web Cache Deception (WCD) est une vulnérabilité de sécurité qui survient lorsqu'un serveur web ou un proxy de mise en cache interprète mal la requête d'un client pour une ressource web et sert ensuite une ressource différente, souvent plus sensible ou privée, après l'avoir mise en cache.
