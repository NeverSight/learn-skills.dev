Web Cache Deception (WCD) è una vulnerabilità di sicurezza che si verifica quando un server web o un proxy di caching interpreta erroneamente la richiesta di un client per una risorsa web e successivamente fornisce una risorsa diversa, spesso più sensibile o privata, dopo averla memorizzata nella cache.
