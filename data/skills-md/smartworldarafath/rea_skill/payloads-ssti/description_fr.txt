L'injection de modèle permet à un attaquant d'inclure du code de modèle dans un modèle existant (ou non). Un moteur de modèle facilite la conception de pages HTML en utilisant des fichiers de modèle statiques qui, au moment de l'exécution, remplacent les variables/espaces réservés par des valeurs réelles dans les pages HTML. - - - - - - - - Un scanner SSTI + CSTI efficace qui utilise de nouveaux polyglottes - Injection et code de modèle côté serveur...
