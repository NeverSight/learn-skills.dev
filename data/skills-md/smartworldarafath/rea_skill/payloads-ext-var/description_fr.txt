La vulnérabilité de modification de variable externe se produit lorsqu’une application Web gère mal les entrées utilisateur, permettant aux attaquants d’écraser des variables internes. En PHP, des fonctions comme extract($_GET), extract($_POST) ou importrequestvariables() peuvent être abusées si elles importent des données contrôlées par l’utilisateur dans l’espace global sans validation appropriée.
