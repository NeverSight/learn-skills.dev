La vulnerabilidad de modificación de variables externas ocurre cuando una aplicación web maneja incorrectamente la entrada del usuario, permitiendo a los atacantes sobrescribir variables internas. En PHP, funciones como extract($GET), extract($POST) o importrequestvariables() pueden ser explotadas si importan datos controlados por el usuario al ámbito global sin la validación adecuada. Esto puede dar lugar a problemas de seguridad como no autorizados…
