GraphQL è un linguaggio di query per le API e un runtime per soddisfare quelle query con dati esistenti. Un servizio GraphQL viene creato definendo tipi e campi su quei tipi, poi fornendo funzioni per ogni campo su ciascun tipo - - - - - - - - - Motore di scripting per interagire con un endpoint GraphQL a scopi di pentesting - Materiale di ricerca sulla sicurezza di GraphQL - Un’estensione Burp per la sicurezza di GraphQL...

Per favore, rispondi sempre nella lingua dell’utente.
