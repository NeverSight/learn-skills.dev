La gestion non sécurisée du code source (SCM) peut entraîner plusieurs vulnérabilités critiques dans les applications et les services Web. Les développeurs s'appuient souvent sur des systèmes SCM tels que Git et Subversion (SVN) pour gérer leurs versions de code source. Cependant, de mauvaises pratiques de sécurité, telles que le fait de laisser des dossiers .git et .svn dans des environnements de production exposés à Internet, peuvent présenter des risques importants.
