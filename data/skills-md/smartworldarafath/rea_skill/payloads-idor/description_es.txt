Las referencias directas inseguras a objetos (IDOR) son una vulnerabilidad de seguridad que ocurre cuando una aplicación permite a los usuarios acceder o modificar directamente objetos (como archivos, registros de bases de datos o URLs) basándose en entradas proporcionadas por el usuario, sin controles de acceso suficientes. Esto significa que si un usuario cambia el valor de un parámetro (como un ID) en una URL o solicitud de API, podría acceder o manipular datos...
