Insecure Direct Object References (IDOR) ist eine Sicherheitslücke, die auftritt, wenn eine Anwendung es Benutzern erlaubt, Objekte (wie Dateien, Datenbankeinträge oder URLs) direkt basierend auf von Benutzern bereitgestellten Eingaben zuzugreifen oder sie zu verändern, ohne ausreichende Zugriffskontrollen. Das bedeutet, dass ein Benutzer, der einen Parameterwert (z. B. eine ID) in einer URL oder API‑Anfrage ändert, möglicherweise auf Daten zugreifen oder diese manipulieren kann…
