Insecure Direct Object References (IDOR) è una vulnerabilità di sicurezza che si verifica quando un’applicazione consente agli utenti di accedere o modificare direttamente oggetti (come file, record di database o URL) basandosi su input forniti dall’utente, senza controlli di accesso sufficienti. Ciò significa che se un utente cambia il valore di un parametro (come un ID) in un URL o in una richiesta API, potrebbe riuscire ad accedere o manipolare i dati...
