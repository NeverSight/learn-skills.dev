Server Side Includes (SSI) sind Direktiven, die in HTML‑Seiten platziert und auf dem Server ausgewertet werden, während die Seiten ausgeliefert werden. Sie ermöglichen das Hinzufügen von dynamisch erzeugtem Inhalt zu einer bestehenden HTML‑Seite, ohne die gesamte Seite über ein CGI‑Programm oder eine andere dynamische Technologie ausliefern zu müssen.
