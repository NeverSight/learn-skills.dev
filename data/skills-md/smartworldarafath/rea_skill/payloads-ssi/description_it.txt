Le Server Side Includes (SSI) sono direttive inserite nelle pagine HTML e valutate sul server durante la loro erogazione. Consentono di aggiungere contenuti generati dinamicamente a una pagina HTML esistente, senza dover servire l’intera pagina tramite un programma CGI o altre tecnologie dinamiche.
