Las directivas Server Side Includes (SSI) se insertan en las páginas HTML y se evalúan en el servidor mientras se sirven las páginas. Permiten añadir contenido generado dinámicamente a una página HTML existente, sin necesidad de servir la página completa mediante un programa CGI u otra tecnología dinámica.
