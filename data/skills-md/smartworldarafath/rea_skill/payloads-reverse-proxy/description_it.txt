Un reverse proxy è un server che si colloca tra i client e i server backend, inoltrando le richieste dei client al server appropriato mentre nasconde l’infrastruttura backend e spesso fornisce bilanciamento del carico o caching. Le misconfigurazioni in un reverse proxy, come controlli di accesso impropri, mancanza di sanitizzazione degli input nelle direttive proxypass o il fidarsi di intestazioni fornite dal client come X-Forwarded-For,...
