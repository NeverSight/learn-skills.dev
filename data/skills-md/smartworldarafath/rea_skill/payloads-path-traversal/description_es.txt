Path Traversal, también conocido como Directory Traversal, es un tipo de vulnerabilidad de seguridad que se produce cuando un atacante manipula variables que hacen referencia a archivos con secuencias "punto-punto-barra (../)" o construcciones similares. Esto puede permitir que el atacante acceda a archivos y directorios arbitrarios almacenados en el sistema de archivos.
