Il Path Traversal, noto anche come Directory Traversal, è un tipo di vulnerabilità di sicurezza che si verifica quando un attaccante manipola variabili che fanno riferimento a file con sequenze “dot‑dot‑slash (../)” o costrutti simili. Questo può consentire all’attaccante di accedere a file e directory arbitrari memorizzati sul file system. Il Directory Traversal Fuzzer: possiamo usare i caratteri per accedere al livello superiore.
