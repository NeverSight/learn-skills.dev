Path Traversal, également connu sous le nom de Directory Traversal, est un type de vulnérabilité de sécurité qui se produit lorsqu'un attaquant manipule des variables qui référencent des fichiers avec des séquences « dot-dot-slash (../) » ou des constructions similaires. Cela peut permettre à l'attaquant d'accéder à des fichiers et répertoires arbitraires stockés sur le système de fichiers.
