# Awesome Hacking Resources

## Overview

This skill integrates **[Awesome Hacking Resources](https://github.com/vitalysim/awesome-hacking-resources)** — a curated collection of hacking and penetration testing resources — into the REA_Skill agent ecosystem.

Covered topics include:
- Learning the skills, YouTube channels, companies, conferences, news
- Reverse engineering, buffer overflow, exploit development
- Privilege escalation (Linux/Windows), OSINT, network scanning/recon
- Malware analysis, AI security / AI red teaming
- Vulnerable web applications, vulnerable OS (Metasploitable, VulnHub)
- Exploits databases, forums, archived conference videos, online communities

- **Authorized use only:** Apply techniques/tools from these resources exclusively against systems you own or have explicit, written permission to test.
- **No third-party targets:** Never target systems you are not authorized to assess.
