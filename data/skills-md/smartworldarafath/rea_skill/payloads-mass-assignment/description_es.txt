Un ataque de asignación masiva es una vulnerabilidad de seguridad que ocurre cuando una aplicación web asigna automáticamente los valores ingresados por el usuario a propiedades o variables de un objeto del programa. Esto puede convertirse en un problema si un usuario puede modificar atributos a los que no debería tener acceso, como los permisos de un usuario o una bandera de administrador.
