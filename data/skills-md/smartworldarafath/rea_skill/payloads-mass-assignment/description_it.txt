Un attacco di assegnazione di massa è una vulnerabilità di sicurezza che si verifica quando un'applicazione web assegna automaticamente i valori di input forniti dall'utente alle proprietà o alle variabili di un oggetto del programma. Ciò può diventare un problema se un utente riesce a modificare attributi a cui non dovrebbe avere accesso, come i permessi di un utente o un flag di amministratore.
