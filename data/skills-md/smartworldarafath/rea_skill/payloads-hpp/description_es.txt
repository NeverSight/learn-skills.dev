La contaminación de parámetros HTTP (HPP) es una técnica de evasión de ataques web que permite a un atacante crear una solicitud HTTP para manipular la lógica web o recuperar información oculta. Esta técnica de evasión se basa en dividir un vector de ataque entre múltiples instancias de un parámetro con el mismo nombre (?param1=valor&param1=valor).
