HTTP Parameter Pollution (HPP) ist eine Web‑Angriffs‑Umgehungstechnik, die es einem Angreifer ermöglicht, eine HTTP‑Anfrage zu erstellen, um Web‑Logiken zu manipulieren oder versteckte Informationen abzurufen. Diese Umgehungstechnik basiert darauf, einen Angriffsvektor auf mehrere Instanzen eines Parameters mit demselben Namen zu verteilen (?param1=value&param1=value).
