HTTP Parameter Pollution (HPP) est une technique d'évasion d'attaque Web qui permet à un attaquant de créer une requête HTTP afin de manipuler les logiques Web ou de récupérer des informations cachées. Cette technique d'évasion est basée sur la division d'un vecteur d'attaque entre plusieurs instances d'un paramètre portant le même nom (?param1=value&param1=value).
