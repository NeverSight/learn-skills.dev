HTTP Parameter Pollution (HPP) è una tecnica di evasione degli attacchi Web che consente a un aggressore di creare una richiesta HTTP al fine di manipolare la logica web o recuperare informazioni nascoste. Questa tecnica di evasione si basa sulla suddivisione di un vettore di attacco tra più istanze di un parametro con lo stesso nome (?param1=value&param1=value).
