Ein Headless‑Browser ist ein Webbrowser ohne grafische Benutzeroberfläche. Er funktioniert genauso wie ein regulärer Browser, etwa Chrome oder Firefox, indem er HTML, CSS und JavaScript interpretiert, tut dies jedoch im Hintergrund, ohne irgendwelche visuellen Darstellungen anzuzeigen.
