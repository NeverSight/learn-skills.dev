Un navegador sin cabeza es un navegador web sin interfaz gráfica de usuario. Funciona igual que un navegador normal, como Chrome o Firefox, interpretando HTML, CSS y JavaScript, pero lo hace en segundo plano, sin mostrar ningún elemento visual.
