Un navigateur sans interface graphique (headless) est un navigateur web dépourvu d&#39;interface utilisateur graphique. Il fonctionne comme un navigateur classique, tel que Chrome ou Firefox, en interprétant le HTML, le CSS et le JavaScript, mais en arrière-plan, sans afficher d&#39;éléments visuels. Les navigateurs sans interface graphique sont principalement utilisés pour les tâches automatisées, comme l&#39;extraction de données web, les tests et l&#39;exécution de scripts.
