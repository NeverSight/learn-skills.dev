Utilícelo para el diseño de la interfaz de usuario y el trabajo de implementación para evitar interfaces genéricas con aspecto de IA. Proporciona reglas antipendientes, una fase de descubrimiento requerida antes de la codificación y orientación para el diseño, la tipografía, el color, el movimiento, la accesibilidad, los paneles, las tablas, las páginas de destino, la tematización y el pulido. Se activa al editar el código de la interfaz de usuario o al revisar y refinar componentes, páginas, pantallas, diseños, animaciones, comportamiento receptivo o sistemas de diseño.
