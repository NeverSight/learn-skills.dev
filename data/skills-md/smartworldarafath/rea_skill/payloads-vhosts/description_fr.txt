Un hôte virtuel (VHOST) est un mécanisme utilisé par les serveurs Web (par exemple, Apache, Nginx, IIS) pour héberger plusieurs domaines ou sous-domaines sur une seule adresse IP. Lors de l'énumération d'un serveur Web, les demandes par défaut ciblent souvent le VHOST principal ou par défaut uniquement. Les hôtes masqués peuvent exposer des fonctionnalités supplémentaires ou des vulnérabilités. Identifier les hôtes virtuels par comparaison de similarité.
