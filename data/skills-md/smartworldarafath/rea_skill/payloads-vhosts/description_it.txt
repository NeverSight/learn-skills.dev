Un Virtual Host (VHOST) è un meccanismo utilizzato dai server web (ad es., Apache, Nginx, IIS) per ospitare più domini o sottodomini su un unico indirizzo IP. Quando si esegue l'enumerazione di un server web, le richieste predefinite spesso puntano solo al VHOST principale o di default.
