Сервер Hyperbrowser Model Context Protocol (MCP) для облачной автоматизации безголового браузера, динамического сканирования SPA, записи сессий и скрытого веб‑скрейпинга (hyperbrowserai/mcp). Используйте, когда агенту требуется рендерить сложные одностраничные приложения на JavaScript, сканировать веб‑сайты или выполнять браузерные агенты.
