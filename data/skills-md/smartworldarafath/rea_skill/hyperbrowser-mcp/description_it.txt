Server Hyperbrowser Model Context Protocol (MCP) per l'automazione di browser headless in cloud, crawling dinamico di SPA, registrazione di sessioni e scraping web stealth (hyperbrowserai/mcp). Da usare quando l'agente deve renderizzare complesse applicazioni JavaScript a pagina singola, eseguire il crawling di siti web o avviare agenti del browser.

Rispondi sempre nella lingua dell'utente.
