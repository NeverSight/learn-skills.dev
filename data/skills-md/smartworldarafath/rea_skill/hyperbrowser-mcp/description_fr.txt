Serveur Hyperbrowser Model Context Protocol (MCP) pour l’automatisation de navigateurs sans tête dans le cloud, le crawling dynamique de SPA, l’enregistrement de sessions et le scraping web furtif (hyperbrowserai/mcp). Utilisez-le lorsque l’agent doit rendre des applications JavaScript monopage complexes, explorer des sites web ou exécuter des agents de navigateur.
