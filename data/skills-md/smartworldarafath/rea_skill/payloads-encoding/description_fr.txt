Le codage et les transformations sont des techniques qui modifient la façon dont les données sont représentées ou transférées sans altérer leur signification fondamentale. Parmi les exemples courants figurent le codage d’URL, le Base64, le codage d’entités HTML et les transformations Unicode. Les attaquants utilisent ces méthodes comme des gadgets pour contourner les filtres d’entrée, éviter les pare‑feu d’applications web ou sortir des routines de désinfection.
