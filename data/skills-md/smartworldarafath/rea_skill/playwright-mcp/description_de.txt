Microsoft Playwright Model Context Protocol (MCP) -Server für lokale Browserautomatisierung, Zugänglichkeits-Snapshot-Navigation, E2E-Tests und Live-Web-Interaktion (microsoft/playwright-mcp). Wird verwendet, wenn der Agent durch Websites navigieren, auf Elemente klicken, Formulare ausfüllen, Tests ausführen oder Live-DOM-Strukturen inspizieren muss.
