Servidor Microsoft Playwright Model Context Protocol (MCP) para la automatización del navegador local, la navegación de instantáneas de accesibilidad, las pruebas de extremo a extremo y la interacción web en tiempo real (microsoft/playwright-mcp). Úselo cuando el agente necesite navegar por sitios web, hacer clic en elementos, completar formularios, ejecutar pruebas o inspeccionar estructuras DOM en tiempo real.
