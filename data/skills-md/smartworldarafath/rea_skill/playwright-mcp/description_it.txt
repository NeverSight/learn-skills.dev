Server Microsoft Playwright Model Context Protocol (MCP) per l'automazione locale del browser, la navigazione di snapshot di accessibilità, i test end‑to‑end e l'interazione web in tempo reale (microsoft/playwright-mcp). Da utilizzare quando l'agente deve navigare i siti web, fare clic sugli elementi, compilare i moduli, eseguire i test o ispezionare le strutture DOM live.

Si prega di rispondere sempre nella lingua dell'utente.
