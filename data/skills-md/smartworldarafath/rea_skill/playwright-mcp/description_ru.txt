Сервер Microsoft Playwright Model Context Protocol (MCP) для локальной автоматизации браузера, навигации по снимкам доступности, сквозного тестирования (E2E) и живого взаимодействия с вебом (microsoft/playwright-mcp). Используйте, когда агенту необходимо навигировать по сайтам, щёлкать элементы, заполнять формы, выполнять тесты или инспектировать живые структуры DOM.
