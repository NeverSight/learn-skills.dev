Les redirections et les transferts non validés sont possibles lorsqu'une application Web accepte une entrée non approuvée qui pourrait amener l'application Web à rediriger la demande vers une URL contenue dans une entrée non approuvée. En modifiant l'entrée d'URL non fiable sur un site malveillant, un attaquant peut lancer avec succès une escroquerie par hameçonnage et voler les informations d'identification de l'utilisateur.
