El contrabando de solicitudes HTTP ocurre cuando varios &quot;elementos&quot; procesan una solicitud, pero difieren en cómo determinan dónde comienza/termina la solicitud. Esta discrepancia puede usarse para interferir con la solicitud/respuesta de otro usuario o para eludir los controles de seguridad.
