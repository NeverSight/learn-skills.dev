SQL Injection (SQLi) è un tipo di vulnerabilità di sicurezza che consente a un attaccante di interferire con le query che un'applicazione invia al suo database. L'SQL Injection è una delle vulnerabilità delle applicazioni web più comuni e gravi, permettendo agli aggressori di eseguire codice SQL arbitrario sul database. Questo può portare ad accessi non autorizzati ai dati, manipolazione dei dati e, in alcuni casi, a una compromissione completa.
