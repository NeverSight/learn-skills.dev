La inyección SQL (SQLi) es un tipo de vulnerabilidad de seguridad que permite a un atacante interferir con las consultas que una aplicación realiza a su base de datos. La inyección SQL es uno de los tipos más comunes y graves de vulnerabilidades de aplicaciones web, lo que permite a los atacantes ejecutar código SQL arbitrario en la base de datos.
