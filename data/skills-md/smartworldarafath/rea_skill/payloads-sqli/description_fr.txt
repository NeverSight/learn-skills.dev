L'injection SQL (SQLi) est un type de vulnérabilité de sécurité qui permet à un attaquant d'interférer avec les requêtes qu'une application effectue sur sa base de données. L'injection SQL est l'un des types de vulnérabilités les plus courants et les plus graves des applications Web, permettant aux attaquants d'exécuter du code SQL arbitraire sur la base de données.
