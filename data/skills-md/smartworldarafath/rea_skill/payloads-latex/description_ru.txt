LaTeX‑инъекция — это тип инъекционной атаки, при которой вредоносный контент вставляется в документы LaTeX. LaTeX широко используется для подготовки и набора документов, особенно в академической среде, для создания высококачественных научных и математических публикаций. Благодаря своим мощным возможностям скриптинга, LaTeX может быть использован злоумышленниками для выполнения произвольных команд, если не применяются надлежащие меры защиты…
