Clickjacking ist eine Art von Web‑Sicherheitslücke, bei der eine bösartige Website einen Benutzer dazu verleitet, auf etwas zu klicken, das von dem abweicht, was der Benutzer wahrnimmt, und dadurch möglicherweise unbeabsichtigte Aktionen ausführt, ohne dass der Benutzer es weiß oder zustimmt. Benutzer werden dazu gebracht, allerlei unbeabsichtigte Aktionen auszuführen, wie beispielsweise das Eingeben des Passworts, das Klicken auf die Schaltfläche „Mein Konto löschen“,…
