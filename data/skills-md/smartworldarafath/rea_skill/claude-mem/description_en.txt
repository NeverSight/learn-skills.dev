Persistent memory compression system for Claude Code and AI coding agents. Compresses conversation transcripts, knowledge graphs, and project context into compact memory snapshots that survive across sessions. Use when you want Claude Code to remember previous work, decisions, and context without re-loading full conversation history. Features transcript-based compression, multi-agent memory sharing, team cowork sessions, and cross-tool support (Cursor, Grok, Windsurf, OMP, Hermes, Pi, and more).
