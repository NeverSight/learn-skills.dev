Оценка безопасности JSON Web Token (JWT), включающая отклонение alg:none, путаницу алгоритмов RS256‑to‑HS256, слабую энтропию секретного ключа HMAC, инъекцию заголовков jwk/jku/x5u, инъекцию путей/SQL в параметр kid, проверку заявок exp/nbf/aud/iss и архитектуру отзыва токенов. Применяется при аудите токенов без состояния.
