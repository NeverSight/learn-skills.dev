La inyección CRLF es una vulnerabilidad de seguridad web que surge cuando un atacante inyecta caracteres inesperados de retorno de carro (CR) ( ) y de salto de línea (LF) ( ) en una aplicación. Estos caracteres se utilizan para señalar el final de una línea y el comienzo de una nueva en protocolos de red como HTTP, SMTP y otros.
