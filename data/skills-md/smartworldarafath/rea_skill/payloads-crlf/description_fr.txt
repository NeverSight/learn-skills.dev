L’injection CRLF est une vulnérabilité de sécurité web qui survient lorsqu’un attaquant injecte des caractères de retour chariot (CR) ( ) et de saut de ligne (LF) ( ) inattendus dans une application. Ces caractères sont utilisés pour signifier la fin d’une ligne et le début d’une nouvelle dans les protocoles réseau comme HTTP, SMTP et d’autres.
