L'Injection LDAP è un attacco usato per sfruttare le applicazioni web che costruiscono istruzioni LDAP basate sull'input dell'utente. Quando un'applicazione non sanifica correttamente l'input dell'utente, è possibile modificare le istruzioni LDAP usando un proxy locale.
