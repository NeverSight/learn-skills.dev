LDAP Injection ist ein Angriff, der verwendet wird, um webbasierte Anwendungen auszunutzen, die LDAP‑Anweisungen basierend auf Benutzereingaben erstellen. Wenn eine Anwendung es versäumt, Benutzereingaben ordnungsgemäß zu bereinigen, ist es möglich, LDAP‑Anweisungen mithilfe eines lokalen Proxys zu manipulieren. LDAP Injection ist eine Schwachstelle, die auftritt, wenn benutzergenerierte Eingaben zum Erstellen von LDAP‑Abfragen verwendet werden, ohne dass sie ordnungsgemäß bereinigt oder escaped werden.
