L'injection LDAP est une attaque utilisée pour exploiter des applications Web qui construisent des instructions LDAP en fonction des entrées de l'utilisateur. Lorsqu'une application ne parvient pas à désinfecter correctement les entrées utilisateur, il est possible de modifier les instructions LDAP à l'aide d'un proxy local.
