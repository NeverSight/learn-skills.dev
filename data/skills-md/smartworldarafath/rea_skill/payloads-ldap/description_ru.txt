LDAP‑инъекция — это атака, используемая для эксплуатации веб‑приложений, которые формируют LDAP‑запросы на основе ввода пользователя. Когда приложение не правильно очищает ввод пользователя, становится возможным изменить LDAP‑запросы с помощью локального прокси.
