La inyección LDAP es un ataque utilizado para explotar aplicaciones web que construyen sentencias LDAP basándose en la entrada del usuario. Cuando una aplicación no logra sanitizar adecuadamente la entrada del usuario, es posible modificar las sentencias LDAP mediante un proxy local.
