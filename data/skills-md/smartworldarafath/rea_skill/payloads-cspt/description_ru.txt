Client-Side Path Traversal (CSPT), иногда также называемый «On-site Request Forgery», — это уязвимость, которую можно использовать как средство для атак CSRF или XSS. Она использует возможность клиентской части выполнять запросы с помощью fetch к URL, в который можно внедрить несколько символов «../». После нормализации эти символы перенаправляют запрос на другой URL, потенциально…
