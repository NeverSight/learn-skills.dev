Client-Side Path Traversal (CSPT), a volte anche definito “On-site Request Forgery”, è una vulnerabilità che può essere sfruttata come strumento per attacchi CSRF o XSS. Sfrutta la capacità del lato client di effettuare richieste usando fetch verso un URL, dove è possibile iniettare più caratteri “../”.
