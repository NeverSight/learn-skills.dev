Una vulnerabilità di perdita ORM si verifica quando informazioni sensibili, come la struttura del database o i dati degli utenti, vengono esposte involontariamente a causa di una gestione scorretta delle query ORM. Questo può accadere se l'applicazione restituisce messaggi di errore grezzi, informazioni di debug o consente agli aggressori di manipolare le query in modi che rivelano i dati sottostanti.
