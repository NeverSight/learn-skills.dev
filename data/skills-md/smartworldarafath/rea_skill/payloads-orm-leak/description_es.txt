Una vulnerabilidad de fuga de ORM ocurre cuando información sensible, como la estructura de la base de datos o datos de usuarios, se expone inadvertidamente debido a un manejo inadecuado de las consultas ORM. Esto puede suceder si la aplicación devuelve mensajes de error sin filtrar, información de depuración o permite a los atacantes manipular consultas de manera que revelen datos subyacentes.
