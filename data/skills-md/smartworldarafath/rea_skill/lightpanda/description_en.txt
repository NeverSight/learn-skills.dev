Headless browser built from scratch for AI agents and automation workflows. 16x lighter and 9x faster than Chromium — 123MB peak memory vs 2GB, 5s vs 46s for 100 pages. Written in Zig, not a Chromium fork or WebKit patch. Use when integrating headless browser automation into AI agent pipelines, web scraping at scale, or any automation needing a lightweight, fast alternative to Puppeteer/Playwright with Chromium. Supports CDP (Chrome DevTools Protocol) for drop-in compatibility.
