Molte applicazioni web consentono all'utente di scaricare contenuti, come modelli per fatture o impostazioni utente, in un file CSV. Molti utenti scelgono di aprire il file CSV in Excel, LibreOffice o OpenOffice. Quando un'applicazione web non valida correttamente il contenuto del file CSV, ciò può portare all'esecuzione del contenuto di una cella o di molte celle.
