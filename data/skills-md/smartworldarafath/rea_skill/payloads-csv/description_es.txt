Muchas aplicaciones web permiten al usuario descargar contenido, como plantillas de facturas o configuraciones de usuario, en un archivo CSV. Muchos usuarios eligen abrir el archivo CSV en Excel, LibreOffice o OpenOffice. Cuando una aplicación web no valida correctamente el contenido del archivo CSV, podría provocar que el contenido de una celda o de muchas celdas sea ejecutado.
