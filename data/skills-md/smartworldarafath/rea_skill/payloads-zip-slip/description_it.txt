La vulnerabilità viene sfruttata utilizzando un archivio appositamente creato che contiene nomi di file con traversal di directory (ad esempio ../../shell.php). La vulnerabilità Zip Slip può colpire numerosi formati di archivio, tra cui tar, jar, war, cpio, apk, rar e 7z. L'attaccante può quindi sovrascrivere file eseguibili e o invocarli da remoto o attendere che il sistema o l'utente li esegua, ottenendo così l'esecuzione di comandi remoti.
