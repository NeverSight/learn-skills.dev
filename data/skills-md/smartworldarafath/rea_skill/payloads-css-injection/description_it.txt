L'iniezione CSS è una vulnerabilità che si verifica quando un'applicazione consente l'inserimento di CSS non attendibile in una pagina web. Questo può essere sfruttato per esfiltrare dati sensibili, come token CSRF o altri segreti, manipolando il layout della pagina o attivando richieste di rete basate sugli attributi degli elementi. Uno strumento per esfiltrare pagine web sconosciute utilizzando Blind CSS. Raccolta di esfiltrazione basata su CSS.
