CSS-Injection ist eine Schwachstelle, die auftritt, wenn eine Anwendung das Einfügen von nicht vertrauenswürdigem CSS in eine Webseite erlaubt. Dies kann ausgenutzt werden, um sensible Daten wie CSRF‑Token oder andere Geheimnisse zu exfiltrieren, indem das Seitenlayout manipuliert oder Netzwerk‑Anfragen basierend auf Attributelementen ausgelöst werden.
