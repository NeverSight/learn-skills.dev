L’injection CSS est une vulnérabilité qui survient lorsqu’une application autorise l’injection de CSS non fiable dans une page Web. Cela peut être exploité pour exfiltrer des données sensibles, telles que des jetons CSRF ou d’autres secrets, en manipulant la mise en page ou en déclenchant des requêtes réseau basées sur les attributs des éléments.
