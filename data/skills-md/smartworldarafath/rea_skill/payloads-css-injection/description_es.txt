La inyección de CSS es una vulnerabilidad que ocurre cuando una aplicación permite que CSS no confiable sea inyectado en una página web. Esto puede explotarse para exfiltrar datos sensibles, como tokens CSRF u otros secretos, manipulando el diseño de la página o activando solicitudes de red basadas en atributos de los elementos. Una herramienta para exfiltrar páginas web desconocidas usando CSS ciego. Colección de exfiltración basada en CSS.
