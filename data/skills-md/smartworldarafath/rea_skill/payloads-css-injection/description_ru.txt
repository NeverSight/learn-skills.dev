CSS‑инъекция — это уязвимость, возникающая, когда приложение позволяет внедрять ненадёжный CSS в веб‑страницу. Её можно использовать для вывода конфиденциальных данных, таких как CSRF‑токены или другие секреты, манипулируя макетом страницы или вызывая сетевые запросы на основе атрибутов элементов. Инструмент для вывода неизвестных веб‑страниц с помощью слепого CSS. Набор методов вывода данных на основе CSS.
