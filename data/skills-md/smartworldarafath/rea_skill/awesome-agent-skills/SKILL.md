# Awesome Agent Skills

A curated collection of official Agent Skills from leading development teams and the community.

> Hand-picked, not AI-slop generated. The most contributed Agent Skills repository, built and maintained together with the community.

## Overview

**Compatible with:** Claude Code, Codex, Antigravity, Gemini CLI, Cursor, GitHub Copilot, OpenCode, Windsurf, and more.

**Skills count:** 1497+ skills across all major domains

## Categories

The collection covers skills for:

- **Frontend & UI** — React, Vue, Next.js, Tailwind, design systems
- **Backend & APIs** — Node.js, Go, Python, REST, GraphQL, gRPC
- **Testing** — Unit, E2E, property-based, visual regression
- **DevOps & Cloud** — CI/CD, Kubernetes, Docker, AWS, GCP, Azure
- **Security** — OWASP, penetration testing, dependency auditing
- **Mobile** — Android (Compose), iOS (SwiftUI), React Native, Flutter
- **AI & ML** — LLM pipelines, RAG, fine-tuning, evaluation
- **Database** — PostgreSQL, MySQL, MongoDB, Redis, ClickHouse
- **Developer Experience** — Code review, documentation, onboarding

## Usage

Browse the repository to find skills relevant to your project domain:

1. Visit [github.com/VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills)
2. Find skills matching your stack or workflow
3. Install via your agent's skill system or copy SKILL.md directly
