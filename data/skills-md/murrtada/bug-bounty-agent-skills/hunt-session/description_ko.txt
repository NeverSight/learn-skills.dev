세션 관리 취약점 탐색 — 세션 고정화(로그인 시 재생성 안 함), 로그아웃·비밀번호 변경·이메일 변경 시 충분하지 않은 무효화, 예측 가능하거나 낮은 엔트로피의 세션 ID, 만료·폐기 없는 JWT-세션, 리프레시 토큰 순환·재사용 감지 누락, OAuth·SSO 세션 연계, 디바이스 결합 세션(DBSC) 다운그레이드, 그리고 쿠키 속성 문제(Secure·HttpOnly·SameSite·__Host-). 실제 두 세션(공격자 A + 피해자 B)으로 검증하고, 200마다 바디 차이점을 확인하며, 절도 체인에 대한 외부 확인(OOB)을 수행한다. 위험도는 중간‑에서‑치명적(고정화→관리자 탈취, 무효화 누락→지속적인 인증 도용).
