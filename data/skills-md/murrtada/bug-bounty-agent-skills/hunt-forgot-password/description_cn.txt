Hunt忘记密码/账户恢复认证缺陷 — 5种不同模式：(1) 通过对有效与无效邮箱返回不同响应进行用户名枚举，(2) 重置令牌直接暴露在 API 响应体中，(3) 重置令牌使用后未被作废（可重放），(4) 密码重置链接可在不同 IP/浏览器上使用（未绑定），(5) 重置请求端点没有速率限制。这些是独立的恢复流程破损认证原语——不同于重置邮件的主机头注入（hunt-host-header）以及完整的 ATO 链路（hunt-ato 将密码重置视为 ATO 路径；在此证明原语，在那里连成链）。检测方法：追踪完整的忘记密码流程，从请求到令牌再到使用；检查有效/无效邮箱的响应差异；在令牌被消费后进行重放测试。风险评级：中至高（枚举=中，令牌重用=高，账户劫持=当与已知邮箱链式时为关键）。请始终使用用户的语言回复。
