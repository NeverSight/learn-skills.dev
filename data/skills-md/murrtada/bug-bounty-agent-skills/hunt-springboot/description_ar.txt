ابحث عن ثغرات Spring Boot الخاصة — نقاط نهاية Actuator (heapdump، env، loggers، mappings، shutdown)، حقن لغة التعبير Spring (SpEL) → تنفيذ أوامر عن بُعد، تنفيذ أوامر عن بُعد عبر وحدة التحكم H2، كشف Jolokia JMX، Spring4Shell (CVE‑2022‑22965)، Spring Cloud Function SPEL (CVE‑2022‑22963)، استخراج بيانات الاعتماد من تفريغ الذاكرة. استخدم ذلك عندما يكون الهدف يشغّل Spring Boot — يتم اكتشافه عبر رأس X‑Application‑Context، /actuator، صفحة الخطأ Whitelabel، أو تتبعات مكدس Java.
