Buscar vulnerabilidades específicas de Spring Boot — puntos finales de Actuator (heapdump, env, loggers, mappings, shutdown), inyección de Spring Expression Language (SpEL) → RCE, RCE en la consola H2, exposición de Jolokia JMX, Spring4Shell (CVE‑2022‑22965), Spring Cloud Function SPEL (CVE‑2022‑22963), extracción de credenciales del volcado de heap. Utilizar cuando el objetivo ejecuta Spring Boot — detectado mediante la cabecera X‑Application‑Context, /actuator, página de error Whitelabel o trazas de pila de Java.
