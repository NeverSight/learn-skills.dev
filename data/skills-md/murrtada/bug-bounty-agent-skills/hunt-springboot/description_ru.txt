Ищите уязвимости, специфичные для Spring Boot — конечные точки Actuator (heapdump, env, loggers, mappings, shutdown), инъекция Spring Expression Language (SpEL) → RCE, RCE через консоль H2, раскрытие Jolokia JMX, Spring4Shell (CVE‑2022‑22965), Spring Cloud Function SPEL (CVE‑2022‑22963), извлечение учётных данных из дампа кучи. Используйте, когда цель работает на Spring Boot — обнаруживается по заголовку X-Application-Context, /actuator, странице Whitelabel Error Page или трассировкам стека Java.
