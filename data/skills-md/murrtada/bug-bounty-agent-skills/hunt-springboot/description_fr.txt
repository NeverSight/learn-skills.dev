Recherche les vulnérabilités spécifiques à Spring Boot — points de terminaison Actuator (heapdump, env, loggers, mappings, shutdown), injection Spring Expression Language (SpEL) → RCE, RCE de la console H2, exposition Jolokia JMX, Spring4Shell (CVE‑2022‑22965), Spring Cloud Function SPEL (CVE‑2022‑22963), extraction d’identifiants à partir du heap dump. À utiliser lorsque la cible exécute Spring Boot — détecté via l’en‑tête X‑Application‑Context, /actuator, la page d’erreur Whitelabel ou les traces de pile Java.
