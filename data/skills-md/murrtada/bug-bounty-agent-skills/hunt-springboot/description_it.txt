Cerca vulnerabilità specifiche di Spring Boot — endpoint Actuator (heapdump, env, loggers, mappings, shutdown), iniezione di Spring Expression Language (SpEL) → RCE, RCE della console H2, esposizione JMX tramite Jolokia, Spring4Shell (CVE‑2022‑22965), Spring Cloud Function SPEL (CVE‑2022‑22963), estrazione delle credenziali da heap dump. Utilizza quando il bersaglio esegue Spring Boot — rilevato tramite intestazione X‑Application‑Context, /actuator, pagina Whitelabel Error o stack trace Java.
