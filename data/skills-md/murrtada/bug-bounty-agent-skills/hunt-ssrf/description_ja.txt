SSRF脆弱性を狩るスキル。AWSメタデータSSRF（HackerOne $25k アナリティクスPDF、Shopify Exchange $25k、Capital One 1億060万件のデータ漏洩、Dropbox/HelloSign $4,913）を含む15件の公開バグバウンティレポートを基に構築、GCPメタデータSSRF（Snapchat $4k）、Azure IMDS SSRF（Azure DevOps $15k チェーン、ChatGPT カスタムアクション MSRC）、DNSリバインディングSSRF（Concrete CMS、GitLab UrlBlocker）、gopherプロトコルを利用したRedis RCE（Yahoo Mail $15k）、リンクプレビューSSRF（Reddit Matrix $6k）、ヘッドレスブラウザPDF生成SSRFチェーンなど。任意のターゲットでSSRFを探索する際に使用—盲目的なケースではOOBコラボレータによる確認が必須。
