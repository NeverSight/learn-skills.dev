Compétence de chasse pour les vulnérabilités de contournement d’authentification. Construite à partir de 12 rapports publics de bug bounty couvrant SAML XSW / parser‑differential (GitHub Enterprise CVE‑2025‑25291/25292), le stripping de signature SAML (Uber, Rocket.Chat, samlify CVE‑2025‑47949), le contournement de l’application des domaines SAML via des caractères de contrôle (HackerOne 2024), la réutilisation d’assertion cross‑IdP sur le portail partenaire (Slack), le contournement SSO de WordPress XMLRPC (Uber), la confusion d’algorithme JWT HS256/RS256 (Jitsi), le saut de validation de signature JWT (Linktree, Newspack), et la confusion d’audience de token (Argo CD CVE‑2023‑22482). Pour la forge autonome de signature/cryptographie JWT (alg:none, confusion de clé, kid/jku) voir hunt‑jwt‑crypto ; cette compétence ne couvre que le JWT dans les chaînes de contournement SSO/SAML/validation de confiance de token. Les attaques au niveau de l’assertion SAML (XSW, injection de commentaire, stripping de signature, XXE‑in‑assertion) sont gérées par hunt‑saml ; cette compétence couvre la taxonomie plus large du contournement d’authentification inter‑protocole. Utilisez‑la lors de la chasse aux contournements d’authentification — voir la matrice Legacy‑Protocol pour les modèles UI brandés vs les points de terminaison hérités.
