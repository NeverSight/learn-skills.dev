针对身份验证绕过漏洞的猎杀技能。基于 12 份公开的漏洞悬赏报告构建，涵盖 SAML XSW / 解析器差异（GitHub Enterprise CVE‑2025‑25291/25292）、SAML 签名剥离（Uber、Rocket.Chat、samlify CVE‑2025‑47949）、通过控制字符绕过 SAML 域强制（HackerOne 2024）、合作门户跨 IdP 断言重用（Slack）、WordPress XMLRPC 绕过 SSO（Uber）、JWT 算法混淆 HS256/RS256（Jitsi）、JWT 签名验证跳过（Linktree、Newspack）以及令牌受众混淆（Argo CD CVE‑2023‑22482）。关于独立的 JWT 签名/加密伪造（alg:none、密钥混淆、kid/jku），请参见 hunt‑jwt‑crypto；本技能仅覆盖在 SSO/SAML/令牌信任绕链中的 JWT。SAML 断言层攻击（XSW、注释注入、签名剥离、断言中的 XXE）归 hunt‑saml 所有；本技能负责更广泛的跨协议身份验证绕过分类。进行身份验证绕过猎杀时使用——请查看 Legacy‑Protocol Matrix 了解品牌 UI 与传统端点模式的区别。
