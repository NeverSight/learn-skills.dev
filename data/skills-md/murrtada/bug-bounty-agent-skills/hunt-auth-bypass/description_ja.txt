認証バイパス脆弱性を対象としたハンティングスキルです。GitHub Enterprise の CVE-2025-25291/25292 に代表される SAML XSW／パーサー差分、Uber、Rocket.Chat、samlify の CVE-2025-47949 による SAML 署名除去、HackerOne 2024 の制御文字による SAML ドメイン強制バイパス、Slack のパートナーポータルにおけるクロス IdP アサーション再利用、Uber の WordPress XMLRPC による SSO バイパス、Jitsi の JWT アルゴリズム混乱 HS256/RS256、Linktree や Newspack の JWT 署名検証スキップ、Argo CD の CVE-2023-22482 によるトークンオーディエンス混乱など、計 12 件の公開バグバウンティレポートを元に構築されています。単体の JWT 署名・暗号偽造（alg:none、キー混乱、kid/jku）については hunt-jwt-crypto を参照してください。本スキルは SSO/SAML/トークン信頼バイパスチェーン内での JWT に限定しています。SAML アサーション層の攻撃（XSW、コメント注入、署名除去、アサーション内 XXE）は hunt-saml が取り扱い、本スキルはより広範な跨プロトコル認証バイパスの分類を対象とします。認証バイパスを狩る際に使用し、ブランド化 UI とレガシーエンドポイントのパターンは Legacy-Protocol Matrix を参照してください。
