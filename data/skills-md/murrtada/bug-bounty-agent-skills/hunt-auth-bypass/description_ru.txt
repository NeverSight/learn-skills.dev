Навыки охоты на уязвимости обхода аутентификации. Создано на основе 12 публичных отчетов о баунти‑ошибках, охватывающих SAML XSW / различие парсеров (GitHub Enterprise CVE‑2025‑25291/25292), удаление подписи SAML (Uber, Rocket.Chat, samlify CVE‑2025‑47949), обход принудительного ограничения домена SAML с помощью управляющих символов (HackerOne 2024), повторное использование утверждений между IdP в партнерском портале (Slack), обход SSO в WordPress XMLRPC (Uber), путаница алгоритмов JWT HS256/RS256 (Jitsi), пропуск проверки подписи JWT (Linktree, Newspack) и путаница аудитории токена (Argo CD CVE‑2023‑22482). Для самостоятельного подделывания подписи/криптографии JWT (alg:none, путаница ключей, kid/jku) см. hunt‑jwt‑crypto; этот навык охватывает JWT только в цепочках обхода SSO/SAML/доверия к токену. Атаки на уровень утверждения SAML (XSW, внедрение комментариев, удаление подписи, XXE‑в‑утверждении) находятся в зоне ответственности hunt‑saml; этот навык охватывает более широкую таксономию кросс‑протокольного обхода аутентификации. Используйте при поиске обходов аутентификации — см. Legacy‑Protocol Matrix для шаблонов «брендовый UI» vs «унаследованные эндпоинты».
