Suche nach Cloud‑/Infrastruktur‑Misconfigurations. AWS: öffentliche S3‑Buckets (s3:GetObject anonym), permissive Bucket‑Policies (PutObjectAcl public‑write), exponiertes CloudFront‑Origin, öffentliche Lambda‑Funktions‑URL, öffentlicher RDS‑Snapshot, IAM‑Anmeldedaten in JS‑Bundles, AWS‑Metadaten über SSRF zugänglich. GCP: öffentliche GCS‑Buckets, exponierte Cloud Run‑Dienste, geleaktes Service‑Account‑JSON. Azure: öffentliche Blob‑Container, exponierte Function App. (Kubernetes/Docker‑Exposition wird von hunt‑k8s verwaltet; CI/CD‑Pipeline‑Angriffe von hunt‑cicd; nach‑Credential IAM‑Escalation von cloud‑iam‑deep.) Erkennung: gezieltes Dorking, Certificate Transparency, Entnahme von Geheimnissen aus JS‑Bundles, Port‑Scan für bekannte Dienst‑Ports. Validierung: tatsächliches Lesen/Schreiben von Daten / RCE. Einsatz beim Suchen von cloud‑nativen Speicher‑ und Compute‑Misconfigurations (S3/GCS/Blob, IMDS‑via‑SSRF, serverlos, öffentliche Managed Services).
