クラウド／インフラの構成ミスをハンティングする。AWS：公開 S3 バケット（s3:GetObject 匿名アクセス）、許容的なバケットポリシー（PutObjectAcl パブリック書き込み）、露出した CloudFront オリジン、公開 Lambda 関数 URL、公開 RDS スナップショット、JS バンドル内の IAM クレデンシャル、SSRF 経由でアクセス可能な AWS メタデータ。GCP：公開 GCS バケット、露出した Cloud Run サービス、漏洩したサービスアカウント JSON。Azure：公開 Blob コンテナ、露出した Function App。（Kubernetes／Docker の露出は hunt‑k8s が担当、CI／CD パイプライン攻撃は hunt‑cicd、認証情報取得後の IAM エスカレーションは cloud‑iam‑deep が担当。）検知：ターゲット型ドーキング、証明書透明性、JS バンドルからのシークレット抽出、既知サービスポートのポートスキャン。検証：実際のデータ読み取り／書き込み／RCE。クラウドネイティブのストレージおよびコンピュートの構成ミス（S3／GCS／Blob、IMDS‑SSRF、サーバーレス、公開マネージドサービス）をハンティングする際に使用する。
