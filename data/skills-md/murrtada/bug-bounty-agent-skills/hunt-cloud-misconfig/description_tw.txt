搜尋雲端/基礎建設錯誤設定。AWS：公開的 S3 桶（s3:GetObject 匿名）、寬鬆的桶政策（PutObjectAcl 公開寫入）、暴露的 CloudFront 原點、公開的 Lambda 函式 URL、公開的 RDS 快照、JS 包中包含 IAM 憑證、透過 SSRF 存取 AWS Metadata。GCP：公開的 GCS 桶、暴露的 Cloud Run 服務、洩漏的服務帳戶 JSON。Azure：公開的 Blob 容器、暴露的 Function App。（Kubernetes/Docker 暴露由 hunt‑k8s 處理；CI/CD 管線攻擊由 hunt‑cicd 處理；憑證取得後的 IAM 升權由 cloud‑iam‑deep 處理。）偵測方式：目標化 dorking、證書透明度、JS 包密鑰抽取、已知服務埠的端口掃描。驗證：實際的資料讀取／寫入／遠端程式碼執行。於搜尋雲原生儲存與運算錯誤設定時使用（S3／GCS／Blob、IMDS 透過 SSRF、無伺服器、公開受管服務）。
