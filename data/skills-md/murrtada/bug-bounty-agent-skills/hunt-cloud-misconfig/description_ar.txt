التنقيب عن أخطاء التهيئة في السحابة/البنية التحتية. AWS: دلاء S3 عامة (s3:GetObject مجهولة)، سياسات دلاء متساهلة (PutObjectAcl كتابة عامة)، أصل CloudFront مكشوف، URL وظيفة Lambda عام، لقطة RDS عامة، بيانات اعتماد IAM في حزم JS، بيانات تعريف AWS قابلة للوصول عبر SSRF. GCP: دلاء GCS عامة، خدمات Cloud Run مكشوفة، ملف JSON حساب الخدمة مسرب. Azure: حاويات blob عامة، Function App مكشوفة. (الكشف عن Kubernetes/Docker يديره hunt‑k8s؛ هجمات خطوط CI/CD يديرها hunt‑cicd؛ تصعيد IAM بعد الحصول على البيانات يديره cloud‑iam‑deep.) الاكتشاف: استهداف dorking، شفافية الشهادات، استخراج أسرار من حزم JS، فحص المنافذ للمنافذ المعروفة. التحقق: قراءة/كتابة فعلية للبيانات / تنفيذ أوامر عن بُعد. الاستخدام عند البحث عن أخطاء تهيئة التخزين والحوسبة السحابية الأصلية (S3/GCS/Blob، IMDS عبر SSRF، الخوادم بدون خوادم، خدمات مدارة عامة).
