Recherche de mauvaises configurations cloud / d’infrastructure. AWS : compartiments S3 publics (s3:GetObject anonyme), politiques de compartiments permissives (PutObjectAcl écriture publique), origine CloudFront exposée, URL de fonction Lambda publique, snapshot RDS public, informations d’identification IAM dans les bundles JS, métadonnées AWS accessibles via SSRF. GCP : compartiments GCS publics, services Cloud Run exposés, JSON de compte de service fuité. Azure : conteneurs blob publics, Function App exposée. (L’exposition Kubernetes/Docker est prise en charge par hunt‑k8s ; les attaques de pipeline CI/CD par hunt‑cicd ; l’élévation IAM post‑credential par cloud‑iam‑deep.) Détection : dorking ciblé, transparence des certificats, extraction de secrets des bundles JS, scan de ports pour les ports de services connus. Validation : lecture/écriture de données réelle / exécution de code à distance. À utiliser lors de la recherche de mauvaises configurations de stockage et de calcul cloud‑native (S3/GCS/Blob, IMDS via SSRF, serverless, services gérés publics).
