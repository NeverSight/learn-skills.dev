Cerca configurazioni errate di cloud / infrastruttura. AWS: bucket S3 pubblici (s3:GetObject anonimo), policy di bucket permissive (PutObjectAcl pubblica‑scrittura), origine CloudFront esposta, URL della funzione Lambda pubblico, snapshot RDS pubblico, credenziali IAM nei bundle JS, metadati AWS accessibili via SSRF. GCP: bucket GCS pubblici, servizi Cloud Run esposti, JSON dell’account di servizio trapelato. Azure: contenitori blob pubblici, Function App esposta. (L’esposizione di Kubernetes/Docker è gestita da hunt‑k8s; gli attacchi alla pipeline CI/CD da hunt‑cicd; l’escalation IAM post‑credenziali da cloud‑iam‑deep.) Rilevamento: dorking mirato, trasparenza dei certificati, estrazione di segreti da bundle JS, scansione di porte per porte di servizio note. Validazione: lettura/scrittura effettiva dei dati / RCE. Da usare quando si cercano configurazioni errate di storage e compute nativi del cloud (S3/GCS/Blob, IMDS‑via‑SSRF, serverless, servizi gestiti pubblici).
