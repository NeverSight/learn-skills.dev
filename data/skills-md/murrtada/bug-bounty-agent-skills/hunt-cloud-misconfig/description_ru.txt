Ищите конфигурационные уязвимости облака/инфраструктуры. AWS: публичные S3‑бакеты (s3:GetObject анонимно), разрешительные политики бакетов (PutObjectAcl public‑write), открытый источник CloudFront, публичный URL функции Lambda, публичный снапшот RDS, IAM‑учётные данные в JS‑бандлах, метаданные AWS доступны через SSRF. GCP: публичные бакеты GCS, открытые сервисы Cloud Run, утекший JSON сервисного аккаунта. Azure: публичные контейнеры blob, открытый Function App. (Экспозиция Kubernetes/Docker принадлежит hunt‑k8s; атаки на конвейер CI/CD — hunt‑cicd; пост‑учётная эскалация IAM — cloud‑iam‑deep.) Обнаружение: целевой dorking, прозрачность сертификатов, извлечение секретов из JS‑бинда, сканирование портов известных сервисов. Проверка: фактическое чтение/запись данных / RCE. Используйте при поиске конфигурационных ошибок в облачных хранилищах и вычислительных сервисах (S3/GCS/Blob, IMDS через SSRF, serverless, публичные управляемые сервисы).
