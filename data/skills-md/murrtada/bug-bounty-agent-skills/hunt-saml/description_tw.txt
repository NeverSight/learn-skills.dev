狩獵 SAML / SSO 攻擊。模式：XML 簽章包裹 (XSW) — 透過重新定位已簽署的元素，在保持簽章有效的同時修改 Assertion；NameID 中的註解注入 (admin@target.com<!--evil-->@attacker.com → 某些解析器會看到 admin@target.com)；簽章剝除（完全移除 Signature 元素，伺服器本應拒絕卻未拒絕）；金鑰混淆（由攻擊者的 IdP 簽署，卻被 SP 接受）；未驗證 audience 限制；重放攻擊（相同 Assertion 在有效期間內被接受兩次）。工具：SAML Raider Burp 擴充套件、samlmagic、手動 XML 操作。偵測：任何 /saml 端點、/Shibboleth.sso、/sso/saml/、Microsoft ADFS 端點。驗證：透過修改後的 NameID 取得帳號控制，透過修改後的 AttributeStatement 注入管理員角色。使用情境：在偵測 SSO 流程時、當 SAML AssertionConsumerService 可達時、在將 IdP 信任鏈接至 SP 冒充時使用。
