SAML / SSO 攻撃をハントする。パターン: XML Signature Wrapping (XSW) — 署名された要素を別の場所に移動して署名を有効なまま Assertion を改ざん、NameID のコメントインジェクション (admin@target.com<!--evil-->@attacker.com → 一部パーサは admin@target.com と見る)、署名除去 (Signature 要素を完全に削除、サーバは拒否すべきだが拒否しない)、鍵混乱 (攻撃者の IdP で署名され、SP が受け入れる)、audience‑restriction が検証されない、リプレイ攻撃 (有効期間内に同じ Assertion が二度受理される)。ツール: SAML Raider Burp 拡張、samlmagic、手動 XML 操作。検出: 任意の /saml エンドポイント、/Shibboleth.sso、/sso/saml/、Microsoft ADFS エンドポイント。検証: 変更された NameID によるアカウント乗っ取り、変更された AttributeStatement による管理者ロール注入。SSO フローのハント時、SAML AssertionConsumerService が到達可能なとき、IdP 信頼を SP なりすましにチェーンする際に使用する。
