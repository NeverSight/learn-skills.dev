狩猎 SAML / SSO 攻击。常见模式：XML Signature Wrapping（XSW）——通过重新定位已签名的元素来修改 Assertion，同时保持签名有效；NameID 中的注释注入（admin@target.com<!--evil-->@attacker.com → 某些解析器只看到 admin@target.com）；签名剥离（完全移除 Signature 元素，服务器本应拒绝但未拒绝）；密钥混淆（由攻击者的 IdP 签名，却被 SP 接受）；未验证受众限制；重放攻击（在有效期窗口内，同一 Assertion 被接受两次）。工具：SAML Raider Burp 扩展、samlmagic、手动 XML 操作。检测方式：任何 /saml 端点、/Shibboleth.sso、/sso/saml/、Microsoft ADFS 端点。验证：通过篡改 NameID 实现账户接管，通过篡改 AttributeStatement 注入管理员角色。使用场景：在狩猎 SSO 流程时、当 SAML AssertionConsumerService 可达时、以及在将 IdP 信任链转向 SP 冒充时使用。
