Caccia attacchi SAML / SSO. Modelli: XML Signature Wrapping (XSW) — modifica l'Assertion mantenendo valida la firma spostando l'elemento firmato, iniezione di commenti nel NameID (admin@target.com<!--evil-->@attacker.com → alcuni parser leggono admin@target.com), rimozione della firma (eliminare completamente l'elemento Signature, il server dovrebbe rifiutare ma non lo fa), confusione delle chiavi (firmato dall'IdP dell'attaccante, accettato dallo SP), audience‑restriction non convalidata, attacco di replay (stesso Assertion accettato due volte entro la finestra di validità). Strumenti: estensione SAML Raider per Burp, samlmagic, manipolazione manuale XML. Rilevamento: qualsiasi endpoint /saml, /Shibboleth.sso, /sso/saml/, endpoint Microsoft ADFS. Convalida: takeover dell'account tramite NameID modificato, iniezione di ruolo admin tramite AttributeStatement modificato. Utilizzare quando si cercano flussi SSO, quando il servizio AssertionConsumerService di SAML è raggiungibile, quando si concatena la fiducia IdP all'impersonificazione SP.
