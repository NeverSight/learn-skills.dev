Suchen nach SAML-/SSO-Angriffen. Muster: XML Signature Wrapping (XSW) – Assertion modifizieren, während die Signatur gültig bleibt, indem das signierte Element verschoben wird, Kommentar‑Injection im NameID (admin@target.com<!--evil-->@attacker.com → einige Parser sehen admin@target.com), Signatur‑Stripping (Signature‑Element vollständig entfernen, Server sollte ablehnen, tut es aber nicht), Schlüssel‑Verwirrung (vom IdP des Angreifers signiert, vom SP akzeptiert), Audience‑Restriction nicht geprüft, Replay‑Attacke (gleiche Assertion wird zweimal innerhalb des Gültigkeitsfensters akzeptiert). Werkzeuge: SAML Raider Burp‑Erweiterung, samlmagic, manuelle XML‑Manipulation. Erkennung: jeder /saml‑Endpunkt, /Shibboleth.sso, /sso/saml/, Microsoft‑ADFS‑Endpunkte. Validierung: Kontenübernahme durch veränderte NameID, Admin‑Rollen‑Injektion durch veränderte AttributeStatement. Einsatz, wenn SSO‑Flüsse gejagt werden, wenn der SAML AssertionConsumerService erreichbar ist, wenn IdP‑Vertrauen zu SP‑Impersonation verkettet wird.
