Ищите атаки SAML / SSO. Шаблоны: XML Signature Wrapping (XSW) — изменение Assertion при сохранении действительной подписи путём перемещения подписанного элемента; инъекция комментариев в NameID (admin@target.com<!--evil-->@attacker.com → некоторые парсеры видят admin@target.com); удаление подписи (полностью убрать элемент Signature, сервер должен отклонить запрос, но не делает); путаница ключей (подписано IdP‑нападающего, но принимается SP); отсутствие проверки audience‑restriction; атака повторного воспроизведения (одно и то же Assertion принимается дважды в течение окна её валидности). Инструменты: расширение SAML Raider для Burp, samlmagic, ручная манипуляция XML. Обнаружение: любой endpoint /saml, /Shibboleth.sso, /sso/saml/, конечные точки Microsoft ADFS. Проверка: захват аккаунта через изменённый NameID, внедрение роли администратора через изменённый AttributeStatement. Применяйте при поиске SSO‑потоков, когда AssertionConsumerService SAML доступен, при цепочкой доверия IdP → имперсонация SP.
