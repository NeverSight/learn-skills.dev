Chasse aux attaques SAML / SSO. Modèles : XML Signature Wrapping (XSW) — modification de l’Assertion tout en conservant la signature valide en déplaçant l’élément signé, injection de commentaire dans NameID (admin@target.com<!--evil-->@attacker.com → certains analyseurs voient admin@target.com), suppression de la signature (suppression totale de l’élément Signature, le serveur devrait rejeter mais ne le fait pas), confusion de clé (signé par l’IdP de l’attaquant, accepté par le SP), restriction d’audience non validée, attaque de rejeu (même Assertion acceptée deux fois dans la fenêtre de validité). Outils : extension SAML Raider pour Burp, samlmagic, manipulation XML manuelle. Détection : tout point d’accès /saml, /Shibboleth.sso, /sso/saml/, points d’accès Microsoft ADFS. Validation : prise de contrôle de compte via NameID altéré, injection de rôle admin via AttributeStatement altéré. Utilisation lors de la chasse aux flux SSO, lorsque le AssertionConsumerService SAML est accessible, lors du chaînage de confiance IdP vers impersonation SP.
