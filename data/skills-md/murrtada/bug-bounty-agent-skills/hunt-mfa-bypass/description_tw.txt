搜尋 MFA / 2FA 繞過 — 7 種不同模式。  
（1）在敏感端點未強制 MFA（例如更改密碼、變更郵箱時接受而不要求 MFA 挑戰）。  
（2）透過直接導向登入後 URL 省略 MFA 步驟。  
（3）MFA 令牌重放（同一代碼被接受兩次）。  
（4）在無速率限制的情況下暴力破解 6 位數 OTP（可在伺服器速度下嘗試 10⁶ 次）。  
（5）OTP 驗證的競態條件。  
（6）透過 /api/me 下載恢復代碼。  
（7）備用驗證因素降級（SMS 驗證且無速率限制）。  

加上攻擊鏈：Cookie 盜取 + 密碼 Oracle + 無升級驗證 = 在無 MFA 挑戰的情況下完成帳號盜用 (ATO)。  

偵測方式：在 Burp 中追蹤認證流程，找出每個狀態轉換，檢查 MFA 是否以中介層統一控制或僅在特定端點實施，檢查 OTP 的熵值以及 OTP 驗證的速率限制。  

驗證方法：攻擊者會話成功達到 MFA 之後的狀態。  

於搜尋認證繞過、MFA 流程及組合原語以導向 ATO 時使用。
