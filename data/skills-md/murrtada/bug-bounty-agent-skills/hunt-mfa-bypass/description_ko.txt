MFA/2FA 우회 탐색 — 7가지 뚜렷한 패턴. (1) 민감한 엔드포인트에서 MFA가 강제되지 않음(비밀번호 변경, 이메일 변경이 MFA 챌린지 없이 허용), (2) 로그인 후 URL로 직접 이동해 MFA 단계 건너뛰기, (3) MFA 토큰 재전송(같은 코드가 두 번 허용), (4) 레이트 제한 없이 6자리 OTP 무차별 대입(서버 속도로 10⁶ 시도), (5) OTP 검증 시 레이스 컨디션, (6) /api/me 를 통한 복구 코드 덤프, (7) 백업 요소 다운그레이드(SMS 요소에 레이트 제한 없음). 추가 체인: 쿠키 탈취 + 비밀번호 오라클 + 스텝업 부재 = MFA 챌린지 없이 ATO. 탐지: Burp에서 인증 흐름을 추적하고 모든 상태 전이를 찾아 MFA가 미들웨어 수준으로 게이트되는지 엔드포인트별인지 확인하고 OTP 엔트로피와 OTP‑validate에 대한 레이트 제한을 검사. 검증: 공격자 세션이 MFA 이후 상태에 도달했는지 확인. 인증 우회, MFA 흐름, ATO를 향한 체이닝 원시 작업을 찾을 때 사용.
