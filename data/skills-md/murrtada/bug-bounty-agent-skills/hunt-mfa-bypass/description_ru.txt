Охота на обход MFA / 2FA — 7 различных шаблонов. (1) MFA не принудительно применяется к чувствительным эндпоинтам (смена пароля, изменение email принимаются без MFA‑проверки), (2) пропуск шага MFA через прямой переход к URL после входа, (3) повторное использование MFA‑токена (один и тот же код принимается дважды), (4) перебор 6‑значного OTP без ограничения скорости (10⁶ попыток на скорости сервера), (5) гонка при проверке OTP, (6) утечка кода восстановления через /api/me, (7) понижение резервного фактора (SMS‑фактор без ограничения скорости). Плюс цепочка: кража cookie + оракул пароля + отсутствие step-up = ATO без MFA‑вызова. Обнаружение: отследить поток аутентификации в Burp, найти каждое переключение состояний, проверить, реализована ли проверка MFA как промежуточное ПО или per‑endpoint, оценить энтропию OTP и ограничение скорости при валидации OTP. Валидация: сессия атакующего достигает состояния после MFA. Использовать при поиске обходов аутентификации, потоков MFA, комбинирования примитивов для ATO.
