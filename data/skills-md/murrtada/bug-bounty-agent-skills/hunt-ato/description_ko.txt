Hunt 계정 탈취 분류체계 — ATO(계정 탈취)까지 9가지 구별된 경로와 체인. 경로: (1) 비밀번호 재설정 결함(호스트‑헤더 인젝션으로 토큰 리다이렉트, 예측 가능/숫자 토큰, Referer 누출, 만료 없음/재사용), (2) 재인증 없이 이메일 변경, (3) OAuth 계정 연동 CSRF, (4) MFA 우회(§ hunt‑mfa‑bypass 참조), (5) 세션 고정, (6) JWT 조작(다른 ID로 토큰 위조; 암호 상세 → hunt‑jwt‑crypto), (7) 단계 상승 없이 비밀번호 변경(로그인 타이밍/길이 오라클과 연계), (8) 소셜 복구/보안 질문 무차별 대입, (9) OAuth redirect_uri에서 SSO 서브도메인 탈취. 체인: 쿠키 탈취 + 비밀번호 오라클 + 단계 상승 없음 = 지속적 ATO; 느슨한 redirect_uri = 인증 코드 탈취; redirect_uri에서 떠도는 CNAME 탈취 = ATO. 검증: 공격자 A의 세션으로 테스트 계정 B를 실제로 탈취함을 시연; OOB/Collaborator를 이용해 블라인드 토큰 누출 단계 확인. ATO 체인을 사냥하거나, 비밀번호 재설정/이메일 변경/MFA/OAuth/세션/JWT를 테스트하거나, 중요 공격으로 연결되는 기본 요소를 체인할 때 사용.
