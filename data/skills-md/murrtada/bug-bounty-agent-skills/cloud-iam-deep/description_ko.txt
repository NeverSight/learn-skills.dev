클라우드 IAM 레드팀 공격 체인 (AWS, Azure, GCP 전반) — 외부 활용 경로와 자격 증명 발견 후 권한 분석에 중점. IAM 열거(aws iam, az role, gcloud iam), STS/AssumeRole 체이닝, Azure Managed Identity 악용(SSRF/유출을 통한), GCP 서비스 계정 JSON 악용, IMDSv1/v2를 이용한 SSRF 공격, K8s ServiceAccount 토큰 보유 시 권한 분석(토큰 발견/클러스터 노출은 hunt‑k8s 담당), role‑trust‑policy confused‑deputy, 크로스‑계정 assume‑role 열거, IAM 권한 상승 패턴(24개 이상 AWS, 8개 이상 Azure, 6개 이상 GCP), 그리고 AWS Cognito Identity Pool 비인증 역할 공격 체인(GetId → GetCredentialsForIdentity → IAM 역할 악용). 탐색 과정에서 자격 증명(키, JSON, 토큰)이 발견되어 그 권한과 상승 방법을 알아야 할 상황을 위해 설계됨. AWS 키 / Azure 비밀 / GCP 서비스 계정 JSON / K8s SA 토큰이 코드 저장소, JS 번들, APK, 침해 데이터, 혹은 SSRF 체인에서 나타날 때 사용.
