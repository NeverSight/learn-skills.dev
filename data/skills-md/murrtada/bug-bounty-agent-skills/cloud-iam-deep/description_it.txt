Catena di attacco red‑team Cloud IAM su AWS, Azure, GCP — incentrata su percorsi di sfruttamento ESTERNI e analisi dei privilegi post‑scoperta delle credenziali. Copre l’enumerazione IAM (aws iam, az role, gcloud iam), concatenamento STS/AssumeRole, abuso di Azure Managed Identity (via SSRF/perdita), abuso del JSON di account di servizio GCP, attacchi IMDSv1/v2 tramite SSRF, analisi dei privilegi del token ServiceAccount di K8s una volta ottenuto (scoperta del token / esposizione del cluster è gestita da hunt‑k8s), policy di trust del ruolo confuso‑deputato, enumerazione cross‑account di assume‑role, pattern di escalation dei privilegi IAM (24+ AWS, 8+ Azure, 6+ GCP) e catena di attacco del ruolo non autenticato di AWS Cognito Identity Pool (GetId → GetCredentialsForIdentity → abuso del ruolo IAM). Realizzata per i casi in cui la ricognizione genera una credenziale (chiave, JSON, token) e occorre sapere cosa concede e come escalarla. Da usare quando una chiave AWS / segreto Azure / JSON di account di servizio GCP / token SA di K8s emerge da un repository di codice, bundle JS, APK, corpus di violazioni o catena SSRF.
