雲端 IAM 紅隊攻擊鏈橫跨 AWS、Azure、GCP —— 專注於外部利用路徑與憑證發現後的權限分析。涵蓋 IAM 列舉（aws iam、az role、gcloud iam）、STS/AssumeRole 連鎖、Azure Managed Identity 濫用（透過 SSRF/洩漏）、GCP 服務帳號 JSON 濫用、IMDSv1/v2 透過 SSRF 的攻擊、K8s ServiceAccount 令牌取得後的權限分析（令牌發現/叢集暴露由 hunt‑k8s 負責）、角色信任策略混淆代理、跨帳戶 assume‑role 列舉、IAM 權限提升模式（24+ AWS、8+ Azure、6+ GCP），以及 AWS Cognito Identity Pool 未驗證角色的攻擊鏈（GetId → GetCredentialsForIdentity → IAM 角色濫用）。此方案針對偵查得到憑證（金鑰、JSON、令牌）時，需了解其授予的權限與提升方式的情境。適用於在程式碼庫、JS 包、APK、洩漏資料或 SSRF 鏈中出現 AWS 金鑰 / Azure 密鑰 / GCP 服務帳號 JSON / K8s SA 令牌時使用。
