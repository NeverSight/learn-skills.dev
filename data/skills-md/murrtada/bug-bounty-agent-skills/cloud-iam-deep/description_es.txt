Cadena de ataque red‑team de Cloud IAM en AWS, Azure y GCP — centrada en vías de explotación EXTERNAS y en el análisis de privilegios después del descubrimiento de credenciales. Cubre enumeración de IAM (aws iam, az role, gcloud iam), encadenamiento STS/AssumeRole, abuso de Azure Managed Identity (mediante SSRF/fuga), abuso de JSON de cuentas de servicio de GCP, ataques IMDSv1/v2 vía SSRF, análisis de privilegios del token ServiceAccount de K8s una vez obtenido (el descubrimiento de tokens / exposición del clúster está bajo hunt‑k8s), policy de confianza de roles confundido‑deputado, enumeración de assume‑role entre cuentas, patrones de escalada de privilegios en IAM (más de 24 en AWS, 8 en Azure, 6 en GCP) y cadena de ataque de rol no autenticado en AWS Cognito Identity Pool (GetId → GetCredentialsForIdentity → abuso de rol IAM). Creado para el caso en que la reconexión produce una credencial (clave, JSON, token) y necesitas saber qué otorga y cómo escalar. Úsalo cuando una clave AWS / secreto de Azure / JSON de cuenta de servicio de GCP / token SA de K8s aparece en un repositorio de código, paquete JS, APK, corpus de brechas o cadena SSRF.
