Облачная IAM‑цепочка атак red‑team в AWS, Azure и GCP — ориентирована на ВНЕШНИЕ пути эксплуатации и анализ привилегий после обнаружения учётных данных. Включает перечисление IAM (aws iam, az role, gcloud iam), цепочку STS/AssumeRole, злоупотребление Azure Managed Identity (через SSRF/утечку), злоупотребление JSON сервисного аккаунта GCP, атаки IMDSv1/v2 через SSRF, анализ привилегий токена ServiceAccount в Kubernetes после его получения (обнаружение токена / раскрытие кластера находится в hunt‑k8s), запутанную роль‑политику доверия, перечисление cross‑account assume‑role, паттерны повышения привилегий IAM (24+ для AWS, 8+ для Azure, 6+ для GCP) и цепочку атак AWS Cognito Identity Pool без аутентификации (GetId → GetCredentialsForIdentity → злоупотребление IAM‑ролью). Создано для случая, когда разведка выдаёт учётные данные (ключ, JSON, токен) и нужно понять, какие права они предоставляют и как их эскалировать. Используйте, когда из репозитория кода, JS‑бандла, APK, набора утечек или цепочки SSRF появляется AWS‑ключ / Azure‑секрет / JSON сервисного аккаунта GCP / токен SA Kubernetes.
