سلسلة هجوم فريق الأحمر لتقنية الهوية والوصول السحابي عبر AWS وAzure وGCP — متركزة على مسارات الاستغلال الخارجية وتحليل الامتيازات بعد اكتشاف الاعتماد. تشمل تعداد هوية الوصول (aws iam، az role، gcloud iam)، ربط STS/AssumeRole، إساءة استخدام هوية Azure المُدارة (عبر SSRF/تسرب)، إساءة استخدام JSON حساب الخدمة في GCP، هجمات IMDSv1/v2 عبر SSRF، تحليل امتيازات رمز ServiceAccount في Kubernetes بمجرد الحصول عليه (اكتشاف الرمز / كشف العنقود مملوك لـ hunt-k8s)، سياسات الثقة للأدوار المتشابكة (confused‑deputy)، تعداد AssumeRole عبر الحسابات المتعددة، أنماط تصعيد الامتيازات في IAM (أكثر من 24 في AWS، أكثر من 8 في Azure، أكثر من 6 في GCP)، وسلسلة هجوم غير موثقة لدور مجموعة هوية AWS Cognito (GetId → GetCredentialsForIdentity → إساءة استخدام دور IAM). صُممت للحالات التي ينتج فيها الاستطلاع اعتمادًا (مفتاح، JSON، رمز) وتحتاج إلى معرفة ما يمنحه وكيفية التصعيد. استخدمها عندما يظهر مفتاح AWS / سر Azure / JSON حساب خدمة GCP / رمز SA في Kubernetes من مستودع شيفرة، حزمة JS، ملف APK، مجموعة خروقات، أو سلسلة SSRF.
