クラウドIAMレッドチームの攻撃チェーン（AWS、Azure、GCP）—外部からの悪用経路と認証情報取得後の権限分析に焦点を当てています。IAM列挙（aws iam、az role、gcloud iam）、STS/AssumeRoleのチェーン、Azure Managed Identityの乱用（SSRF/リーク経由）、GCPサービスアカウントJSONの乱用、IMDSv1/v2へのSSRF攻撃、K8s ServiceAccountトークン取得後の権限分析（トークン発見／クラスター露出はhunt‑k8sが担当）、ロール信頼ポリシーの混乱代理、クロスアカウントAssumeRole列挙、IAM権限昇格パターン（AWS24種以上、Azure8種以上、GCP6種以上）、およびAWS Cognito Identity Poolの未認証ロール攻撃チェーン（GetId → GetCredentialsForIdentity → IAMロール乱用）を含みます。調査で認証情報（キー、JSON、トークン）が取得された際に、その権限が何であるか、どのようにエスカレーションできるかを把握するために作成されました。AWSキー、Azureシークレット、GCPサービスアカウントJSON、K8s SAトークンがコードリポジトリ、JSバンドル、APK、侵害データ、またはSSRFチェーンから見つかった場合に使用してください。
