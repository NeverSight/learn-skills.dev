跨 AWS、Azure、GCP 的云 IAM 红队攻击链——聚焦外部利用路径以及凭证发现后的权限分析。覆盖 IAM 枚举（aws iam、az role、gcloud iam）、STS/AssumeRole 链接、Azure 托管身份滥用（通过 SSRF/泄漏）、GCP 服务账号 JSON 滥用、通过 SSRF 的 IMDSv1/v2 攻击、K8s ServiceAccount 令牌持有后的权限分析（令牌发现/集群暴露由 hunt‑k8s 负责）、角色信任策略混淆代理、跨账户 AssumeRole 枚举、IAM 权限提升模式（24+ 条 AWS、8+ 条 Azure、6+ 条 GCP），以及 AWS Cognito 身份池未认证角色攻击链（GetId → GetCredentialsForIdentity → IAM 角色滥用）。针对情报收集得到凭证（密钥、JSON、令牌）后需要了解其授权范围及提升路径的场景构建。适用于在代码仓库、JS 包、APK、泄漏数据集或 SSRF 链中出现 AWS 密钥、Azure 密钥、GCP 服务账号 JSON 或 K8s SA 令牌时使用。
