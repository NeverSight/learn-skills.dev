Abilità di hunting per vulnerabilità XSS. Costruita a partire da 174 report pubblici di bug bounty. Da utilizzare durante il hunting di XSS su qualsiasi target. Per l’iniezione di markup che riflette HTML grezzo ma NON esegue JavaScript (nessuna esecuzione di `<script>`/event‑handler), vedere hunt‑html‑injection — passare a questo una volta che l’esecuzione di script è possibile.
