Compétence de chasse aux vulnérabilités XSS. Construite à partir de 174 rapports de bug bounty publics. À utiliser lors de la recherche de XSS sur n'importe quelle cible. Pour l'injection de balisage qui reflète du HTML brut mais n'exécute PAS de JavaScript (pas d'exécution de `<script>`/gestionnaires d'événements), voir hunt-html-injection — passez à l'étape suivante ici dès que l'exécution de script est possible.
