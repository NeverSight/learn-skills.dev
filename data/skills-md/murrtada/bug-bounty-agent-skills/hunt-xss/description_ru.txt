Навык охоты на уязвимости XSS. Создан на основе 174 публичных отчётов о баг-баунти. Используйте при поиске XSS на любом объекте. Для внедрения разметки, которое отражает сырой HTML, но НЕ исполняет JavaScript (без выполнения `<script>`/обработчиков событий), см. hunt-html-injection — повышайте уровень здесь, когда исполнение скрипта станет возможным.
