Habilidad de detección para vulnerabilidades XSS. Construida a partir de 174 informes públicos de recompensas por bugs. Úsala al buscar XSS en cualquier objetivo. Para inyección de marcado que refleja HTML sin procesar pero NO ejecuta JavaScript (sin ejecución de `<script>`/manejadores de eventos), consulta hunt-html-injection — escálalo aquí una vez que sea posible la ejecución de scripts.
