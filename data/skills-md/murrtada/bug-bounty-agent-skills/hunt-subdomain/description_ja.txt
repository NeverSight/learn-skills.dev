サブドメインテイクオーバー脆弱性のハンティングスキル。モダンなプロバイダーの指紋情報を含む — Microsoft Azure DevOps の `cloudapp.azure.com` リージョナルプール再発行（ワンクリック OAuth ATO、ワイルドカード `reply_to`、Binary Security）、Zendesk ヘルプデスクのテイクオーバー → メールインターセプト → パスワードリセットチェーン（0xprial の解説）、Vercel の `cname.vercel-dns.com` 削除プロジェクトテイクオーバー、さらに一般的な Fastly CDN サービスの再接続と S3 ダングリングバケットのクッキー範囲テクニック。サブドメインテイクオーバーのハンティング時に使用する — ATO チェーンのプリミティブ（OAuth `redirect_uri`、クッキー ドメイン、メール DNS）に重点を置く。
