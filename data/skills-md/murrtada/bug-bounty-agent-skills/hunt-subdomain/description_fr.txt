Compétence de chasse pour les vulnérabilités de prise de contrôle de sous‑domaine. Inclut les empreintes modernes des fournisseurs — Microsoft Azure DevOps `cloudapp.azure.com` réémission de pool régional (ATO OAuth en 1 clic via le joker `reply_to`, Binary Security), prise de contrôle du help‑desk Zendesk → interception d’e‑mail → chaîne de réinitialisation de mot de passe (analyse 0xprial), prise de contrôle de projet supprimé Vercel `cname.vercel-dns.com`, ainsi que les techniques générales de rattachement du service CDN Fastly et de portée de cookie pour seau S3 abandonné. À utiliser lors de la chasse aux prises de contrôle de sous‑domaine — accent sur les primitives de chaîne ATO (OAuth `redirect_uri`, domaine de cookie, DNS e‑mail).
