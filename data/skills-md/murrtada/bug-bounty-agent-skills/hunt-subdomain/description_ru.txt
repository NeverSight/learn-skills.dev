Навыки охоты на уязвимости захвата поддомена. Включает современные отпечатки провайдеров — повторный выпуск регионального пула Microsoft Azure DevOps `cloudapp.azure.com` (однонажатный OAuth ATO через wildcard `reply_to`, Binary Security), захват службы поддержки Zendesk → перехват электронной почты → цепочка сброса пароля (материал 0xprial), захват удалённого проекта Vercel `cname.vercel-dns.com`, а также общие техники повторного присоединения Fastly CDN и уязвимость «зависший» S3‑бакет с областью cookie. Использовать при поиске захвата поддомена — акцент на примитивы цепочки ATO (OAuth `redirect_uri`, cookie‑domain, email‑DNS).
