مهارة الصيد للثغرات الخاصة بالاستيلاء على النطاقات الفرعية. تشمل بصمات مزودي الخدمة الحديثة — إعادة إصدار مجموعة إقليمية لـ Microsoft Azure DevOps `cloudapp.azure.com` (استيلاء OAuth بنقرة واحدة عبر القالب العام `reply_to`، Binary Security)، استيلاء مركز مساعدة Zendesk → اعتراض البريد الإلكتروني → سلسلة إعادة تعيين كلمة المرور (كتابة 0xprial)، استيلاء مشروع محذوف على Vercel `cname.vercel-dns.com`، بالإضافة إلى تقنيات إعادة ربط خدمة Fastly CDN العامة وتقنيات نطاق ملفات تعريف الارتباط لسلة S3 المعلقة. استخدمها عند صيد الاستيلاء على النطاقات الفرعية — مع التركيز على أساسيات سلسلة الاستيلاء (OAuth `redirect_uri`، نطاق ملفات تعريف الارتباط، DNS البريد الإلكتروني).
