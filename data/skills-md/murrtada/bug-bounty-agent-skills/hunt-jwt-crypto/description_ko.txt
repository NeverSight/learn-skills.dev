JWT 암호화 실패 탐색 — alg:none 서명 제거와 RS256→HS256 키 혼동으로 공격자가 비밀을 알지 못하고도 임의의 신원(예: 관리자)의 토큰을 위조할 수 있습니다. 애플리케이션이 JSON Web Token(Authorization 헤더의 `eyJ...` 베어러 토큰, 쿠키, 또는 로그인 응답)으로 인증할 때 사용하세요. 이 스킬은 JWT 서명/암호 위조(alg:none, 키 혼동, kid/jku 헤더 주입)를 완전하게 다룹니다; hunt-ato는 JWT를 ATO 경로 중 하나로, hunt-auth-bypass는 SSO/SAML 토큰 신뢰를, hunt-api-misconfig는 비암호화 JWT 처리를 다룹니다. 위조된 토큰이 다른 사용자의 데이터나 관리자 전용 엔드포인트에 접근을 허용할 때 매우 중요합니다.
