Cerca fallimenti crittografici di JWT — rimozione della firma con alg:none e confusione di chiavi RS256→HS256 che consentono a un aggressore di forgiare un token per qualsiasi identità (ad es. un amministratore) senza conoscere un segreto. Usa quando l'app si autentica con un JSON Web Token (un token Bearer `eyJ...` nell'intestazione Authorization, un cookie o una risposta di login). Questa abilità CONTROLLA la falsificazione di firma/cripto di JWT (alg:none, confusione di chiavi, iniezione di intestazioni kid/jku); hunt-ato copre JWT come un percorso ATO, hunt-auth-bypass copre la fiducia nei token SSO/SAML, hunt-api-misconfig copre la gestione di JWT non crittografati. È critico quando un token forgiato concede accesso ai dati di un altro utente o a un endpoint riservato agli amministratori.
