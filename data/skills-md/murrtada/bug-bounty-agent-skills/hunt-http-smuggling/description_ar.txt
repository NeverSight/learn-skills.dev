ابحث عن تقنيّات تزوير طلبات HTTP (CL.TE، TE.CL، H2.CL، H2.TE). السبب: الخادم الوكّي الأمامي والخادم الخلفي لا يتفقان على مكان انتهاء طلب واحد وبداية الطلب التالي (عدم توافق في تحليل رؤوس Content‑Length وTransfer‑Encoding). CL.TE: الواجهة الأمامية تستخدم Content‑Length، والخلفية تستخدم Transfer‑Encoding → يمكن التزوير بإرسال Transfer‑Encoding: chunked مع جسم يتطابق مع عدد الـ Content‑Length. TE.CL: العكس. H2.CL: خفض إلى HTTP/2، ثم تزوير Content‑Length إلى الخادم الخلفي الذي يعمل بـ HTTP/1.1. أدوات الكشف: امتداد Burp HTTP Request Smuggler، smuggler.py، h2csmuggler. التأكيد: تقنية تأخير الوقت (GET مزور بمهلة 30 ثانية) — إذا أعادت الواجهة الأمامية استجابة بطيئة للطلب التالي للضحية، فإن التزوير نجح. التحقق: سلسلة تسميم التخزين المؤقت (تزوير طلب يُخزن في الذاكرة المؤقتة للضحية)، سرقة الاعتمادات (تزوير تجاوز X‑Forwarded‑For لالتقاط ملفات تعريف الارتباط للمستخدم التالي)، تجاوز المصادقة (طلب داخلي مزور). أمثلة مدفوعة حقيقية من عمليات نشر CDN الكبرى. يُستخدم عند البحث في برامج المكافآت المدفوعة التي تعمل على مكدسات CDN+origin، وعند استهداف موازن التحميل/تجاوز جدار الحماية WAF.
