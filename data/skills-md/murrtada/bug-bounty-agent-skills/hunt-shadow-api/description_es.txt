Caza sombra / zombie / superficie de API no documentada (OWASP API9 Gestión inadecuada de inventario) — enumerar todo el historial de versiones de la API (rutas v1/v2/beta/legacy, versionado mediante encabezados y subdominios), obtener y comparar cada especificación OpenAPI/Swagger accesible (incluyendo las que solo se pueden encontrar mediante Wayback Machine), y diferenciar de forma conductual versiones antiguas vs. actuales para regresiones de autenticación, límite de velocidad y validación, en lugar de solo diferencias en la forma de la respuesta. Distinto de hunt‑api‑misconfig, que se encarga de la explotación una vez que tienes una especificación o endpoint (asignación masiva, JWT, OData, ataques en cadena Swagger); distinto de hunt‑subdomain, que se encarga del descubrimiento a nivel de host. Esta habilidad controla el inventario de versiones y el flujo de diferencias conductuales. Úsala cuando el objetivo tiene rutas de API versionadas, múltiples especificaciones, un registro de cambios que referencia endpoints obsoletos, o una aplicación móvil cuyas llamadas backend codificadas son más antiguas que la web actual.
