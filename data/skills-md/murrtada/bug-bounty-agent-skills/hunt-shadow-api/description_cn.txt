搜寻影子/僵尸/未文档化的 API 表面（OWASP API9 不当库存管理）——枚举完整的 API 版本历史（v1/v2/beta/legacy 路径，基于 Header 和子域的版本控制），获取并对比所有可访问的 OpenAPI/Swagger 规范（包括只能通过 Wayback Machine 找到的），并在行为上比较旧版与当前版本在认证、速率限制、验证回归方面的差异，而不仅仅是响应结构的差异。此项区别于 hunt‑api‑misconfig，后者在拥有规范或端点后负责利用（如批量赋值、JWT、OData、Swagger 链攻击）；区别于 hunt‑subdomain，后者负责主机层面的发现。此技能负责版本清单和行为差异化的工作流本身。当目标拥有版本化的 API 路径、多个规范、包含已废弃端点的 changelog，或移动应用的硬编码后端调用看起来比当前 Web 应用更旧时使用。
