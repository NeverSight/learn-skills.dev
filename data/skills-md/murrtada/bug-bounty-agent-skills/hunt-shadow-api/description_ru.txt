Искать теневую / зомби / недокументированную поверхность API (OWASP API9 «Неправильное управление инвентаризацией») — перечислить полную историю версий API (пути v1/v2/beta/legacy, версионирование через заголовки и поддомены), получить и сравнить каждый доступный спецификатор OpenAPI/Swagger (включая те, которые можно найти только через Wayback Machine), а также поведенчески сравнить старые и текущие версии на регрессии аутентификации, ограничения частоты запросов и валидации, а не только различия в структуре ответов. Отличается от hunt‑api‑misconfig, который отвечает за эксплуатацию после получения спецификации или эндпоинта (массовое назначение, JWT, OData, атаки цепочки Swagger); отличается от hunt‑subdomain, который занимается обнаружением на уровне хоста. Этот навык отвечает за процесс инвентаризации версий и поведенческого сравнения. Применяется, когда у цели есть версионированные пути API, несколько спецификаций, журнал изменений, ссылающийся на устаревшие эндпоинты, или мобильное приложение, в котором жёстко закодированные вызовы бэкенда выглядят старее, чем у текущего веб‑приложения.
