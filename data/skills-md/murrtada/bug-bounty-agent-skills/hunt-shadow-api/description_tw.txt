搜尋陰影／殭屍／未記錄的 API 表面（OWASP API9 不當清單管理）— 列舉完整的 API 版本歷史（v1/v2/beta/legacy 路徑、基於標頭與子域名的版本化），抓取並比對每個可取得的 OpenAPI/Swagger 規格（包括只能透過 Wayback Machine 找到的），以及在行為層面上比較舊版與當前版的認證、速率限制、驗證回歸，而不僅僅是回應結構的差異。此項目與 hunt‑api‑misconfig 不同，後者在取得規格或端點後負責利用（大量賦值、JWT、OData、Swagger 鏈攻擊）；亦與 hunt‑subdomain 不同，後者負責主機層級的偵測。此技能掌管版本清單與行為差異的工作流程本身。當目標擁有版本化的 API 路徑、多個規格、列出已棄用端點的變更紀錄，或是行動應用程式中硬編碼的後端呼叫看起來較舊於目前的網頁應用程式時，請使用此技能。
