섀도우/좀비/문서화되지 않은 API 표면을 탐색 (OWASP API9 부적절한 인벤토리 관리) — API 전체 버전 히스토리(v1/v2/beta/legacy 경로, 헤더 및 서브도메인 기반 버전 관리)를 열거하고, 접근 가능한 모든 OpenAPI/Swagger 사양을 가져와 차이점을 비교합니다(Wayback Machine에서만 찾을 수 있는 사양 포함). 또한 응답 형태 차이만이 아니라 인증/속도 제한/검증 회귀에 대한 구버전과 현재 버전의 동작 차이를 비교합니다. 이 작업은 사양이나 엔드포인트가 확보된 후 활용하는 hunt‑api‑misconfig(대량 할당, JWT, OData, Swagger 체인 공격)와는 구별되며, 호스트 수준 탐색을 담당하는 hunt‑subdomain과도 구별됩니다. 이 스킬은 버전 인벤토리와 동작 차이 분석 워크플로우 자체를 담당합니다. 대상에 버전이 지정된 API 경로, 다수의 사양, 폐기된 엔드포인트를 언급한 변경 로그, 혹은 현재 웹 앱보다 오래된 백엔드 호출을 하드코딩한 모바일 앱이 있을 때 사용합니다.
