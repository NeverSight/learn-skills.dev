Hunt shadow / zombie / undocumented API surface（OWASP API9 Improper Inventory Management） — API の全バージョン履歴（v1/v2/beta/legacy パス、ヘッダーおよびサブドメインベースのバージョニング）を列挙し、到達可能なすべての OpenAPI/Swagger 仕様（Wayback Machine でしか見つからないものも含む）を取得して差分を取り、単なるレスポンス形状の違いではなく、認証・レートリミット・バリデーションのリグレッションについて古いバージョンと現在のバージョンを挙動的に比較する。hunt‑api‑misconfig（スペックやエンドポイントが入手できた後のマスアサインメント、JWT、OData、Swagger 連鎖攻撃の利用）とは別で、hunt‑subdomain（ホストレベルの発見を担当）とも区別される。このスキルはバージョン在庫管理と挙動差分のワークフロー自体を担う。対象がバージョン管理された API パスや複数の仕様、廃止されたエンドポイントを示す changelog、またはハードコードされたバックエンド呼び出しが現在の Web アプリより古いモバイルアプリを持つ場合に使用する。
