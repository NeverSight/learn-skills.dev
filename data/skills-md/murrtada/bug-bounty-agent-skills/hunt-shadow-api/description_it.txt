Ricerca della superficie API shadow / zombie / non documentata (OWASP API9 Gestione impropria dell'inventario) — enumerare l'intera cronologia delle versioni dell'API (percorsi v1/v2/beta/legacy, versionamento basato su header e subdomain), recuperare e confrontare ogni specifica OpenAPI/Swagger raggiungibile (comprese quelle individuabili solo tramite la Wayback Machine) e confrontare comportamentalmente le versioni vecchie vs. attuali per regressioni di autenticazione, limitazione di velocità e validazione, anziché limitarsi a differenze nella forma della risposta. Distinto da hunt‑api‑misconfig, che gestisce lo sfruttamento una volta ottenuta una specifica o endpoint (mass assignment, JWT, OData, attacchi a catena Swagger); distinto da hunt‑subdomain, che si occupa della scoperta a livello di host. Questa skill gestisce il flusso di lavoro di inventario delle versioni e di diff comportamentale. Da usare quando il bersaglio ha percorsi API versionati, più specifiche, un changelog che fa riferimento a endpoint deprecati, o un’app mobile le cui chiamate backend codificate sembrano più vecchie rispetto a quelle dell’attuale web app.
