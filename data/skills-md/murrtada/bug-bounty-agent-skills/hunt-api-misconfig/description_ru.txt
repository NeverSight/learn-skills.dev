Hunt API — неправильная конфигурация безопасности: массовое присваивание, загрязнение прототипа, подмена HTTP‑метода. Массовое присваивание: отправьте {is_admin:true, role:admin, verified:true} на эндпоинты profile/account/reset — сервер слепо применяет полученные данные. Подделка подписи/криптографии JWT (alg:none, путаница ключей, kid/jku) относится к hunt‑jwt‑crypto; этот навык покрывает только работу с JWT без криптографии. Загрязнение прототипа: инъекция __proto__ при слиянии JSON / Object.assign / lodash _.merge → загрязнённый прототип достигает «sink» (RCE в Node, XSS в браузере). Подмена HTTP‑метода: GET‑обход CSRF, X‑HTTP‑Method‑Override, включённый TRACE. Обнаружение: ответы API с лишними полями, JWT в заголовках (декодировать на jwt.io). Неправильная конфигурация CORS (отражение любого origin, null origin, обход subdomain‑regex, postMessage) относится к hunt‑cors. Используйте при поиске ошибок конфигурации API, массового присваивания, загрязнения прототипа (JWT‑крипто → hunt‑jwt‑crypto).
