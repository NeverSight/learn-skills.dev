تكوين أمان API غير صحيح — التخصيص الجماعي، تلوث النموذج الأولي، تلاعب بأفعال HTTP. التخصيص الجماعي: إرسال {is_admin:true, role:admin, verified:true} على نقاط النهاية profile/account/reset — الخادم يطبقها دون تحقق. تزوير توقيع/تشفير JWT (alg:none، ارتباك المفتاح، kid/jku) مملوك لـ hunt-jwt-crypto؛ هذه المهارة تغطي معالجة JWT غير التشفيرية فقط. تلوث النموذج الأولي: حقن __proto__ في دمج JSON / Object.assign / lodash _.merge → النموذج الأولي الملوث يصل إلى الصرف (RCE في Node، XSS في المتصفح). أفعال HTTP: تجاوز GET لـ CSRF، X-HTTP-Method-Override، تمكين TRACE. الكشف: ردود API تحتوي على حقول إضافية، JWTs في رؤوس الطلب (فك التشفير عبر jwt.io). تكوين CORS غير صحيح (انعكاس أي أصل، أصل null، تجاوز regex للنطاق الفرعي، postMessage) مملوك لـ hunt-cors. استخدم عند البحث عن تكوينات API غير صحيحة، التخصيص الجماعي، تلوث النموذج الأولي (تشفير JWT → hunt-jwt-crypto).
