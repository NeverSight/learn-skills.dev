Desconfiguración de seguridad de la API Hunt — asignación masiva, contaminación de prototipo, manipulación de verbos HTTP. Asignación masiva: envía {is_admin:true, role:admin, verified:true} en los endpoints profile/account/reset — el servidor lo aplica ciegamente. Falsificación de firma/cripto JWT (alg:none, confusión de clave, kid/jku) pertenece a hunt-jwt-crypto; esta habilidad cubre solo el manejo de JWT sin cripto. Contaminación de prototipo: inyección __proto__ en fusión de JSON / Object.assign / lodash _.merge → el prototipo contaminado alcanza el sink (RCE en Node, XSS en el navegador). Verbo HTTP: GET para evadir CSRF, X-HTTP-Method-Override, TRACE habilitado. Detección: respuestas de API con campos extra, JWT en encabezados (decodificar en jwt.io). Desconfiguración CORS (reflect-any-origin, null origin, evadir con expresión regular de subdominio, postMessage) pertenece a hunt-cors. Úsalo al buscar desconfiguraciones de API, asignación masiva, contaminación de prototipo (cripto JWT → hunt-jwt-crypto).
