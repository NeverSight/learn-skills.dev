Hunt API mauvaise configuration de sécurité — affectation massive, pollution de prototype, altération du verbe HTTP. Affectation massive : envoyer {is_admin:true, role:admin, verified:true} sur les points de terminaison profile/account/reset — le serveur l’applique aveuglément. Forgery de signature/crypto JWT (alg:none, confusion de clé, kid/jku) appartient à hunt‑jwt‑crypto ; cette compétence couvre uniquement la manipulation non crypto des JWT. Pollution de prototype : injection __proto__ lors de la fusion JSON / Object.assign / lodash _.merge → le prototype pollué atteint le point d’injection (RCE sous Node, XSS dans le navigateur). Verbe HTTP : contournement CSRF via GET, X‑HTTP‑Method‑Override, TRACE activé. Détection : réponses d’API contenant des champs supplémentaires, JWT dans les en‑têtes (décoder sur jwt.io). La mauvaise configuration CORS (réflexion de n’importe quelle origine, origine null, contournement par regex de sous‑domaine, postMessage) appartient à hunt‑cors. À utiliser lors de la chasse aux mauvaises configurations d’API, affectation massive, pollution de prototype (crypto JWT → hunt‑jwt‑crypto).
