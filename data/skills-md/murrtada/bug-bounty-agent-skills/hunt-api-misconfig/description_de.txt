Hunt API Sicherheits-Misconfiguration — Mass Assignment, Prototype Pollution, HTTP-Verb-Manipulation. Mass Assignment: sende {is_admin:true, role:admin, verified:true} an profile/account/reset Endpunkte — Server wendet blind an. JWT Signatur/Krypto-Fälschung (alg:none, Schlüsselverwirrung, kid/jku) ist Eigentum von hunt-jwt-crypto; diese Fähigkeit deckt nur nicht-cryptografische JWT-Verarbeitung ab. Prototype Pollution: __proto__ Injection beim JSON-Merge / Object.assign / lodash _.merge → verschmutzter Prototyp erreicht den Sink (RCE in Node, XSS im Browser). HTTP-Verb: GET-Bypass-CSRF, X-HTTP-Method-Override, TRACE aktiviert. Erkennung: API-Antworten mit zusätzlichen Feldern, JWTs in Headern (bei jwt.io dekodieren). CORS-Misconfiguration (reflect-any-origin, null origin, Subdomain-RegEx-Bypass, postMessage) ist Eigentum von hunt-cors. Verwenden beim Aufspüren von API-Misconfigs, Mass-Assignment, Prototype Pollution (JWT-Krypto → hunt-jwt-crypto).
