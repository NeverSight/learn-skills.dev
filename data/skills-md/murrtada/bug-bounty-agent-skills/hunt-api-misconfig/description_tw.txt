搜尋 API 安全配置錯誤 — 大量指派、原型污染、HTTP 動詞篡改。大量指派：在 profile/account/reset 端點傳送 {is_admin:true, role:admin, verified:true} —— 伺服器盲目套用。JWT 簽名/加密偽造（alg:none、金鑰混淆、kid/jku）屬於 hunt-jwt-crypto；此技能僅涵蓋非加密 JWT 處理。原型污染：在 JSON 合併 / Object.assign / lodash _.merge 中注入 __proto__ → 被污染的原型傳到 sink（Node 中的 RCE、瀏覽器中的 XSS）。HTTP 動詞：GET 繞過 CSRF、X-HTTP-Method-Override、啟用 TRACE。偵測方式：API 回應中出現額外欄位、標頭中的 JWT（可在 jwt.io 解碼）。CORS 配置錯誤（reflect-any-origin、null origin、子域正則繞過、postMessage）屬於 hunt-cors。於搜尋 API 配置錯誤、大量指派、原型污染時使用（JWT 加密 → hunt-jwt-crypto）。
