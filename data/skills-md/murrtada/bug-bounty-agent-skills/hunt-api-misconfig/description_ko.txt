Hunt API 보안 설정 오류 — 대량 할당, 프로토타입 오염, HTTP 메서드 변조. 대량 할당: profile/account/reset 엔드포인트에 {is_admin:true, role:admin, verified:true} 를 전송 — 서버가 맹목적으로 적용. JWT 서명/암호 위조 (alg:none, 키 혼동, kid/jku)는 hunt-jwt-crypto가 담당; 이 스킬은 비암호화 JWT 처리를 다룸. 프로토타입 오염: JSON 병합 / Object.assign / lodash _.merge에서 __proto__ 주입 → 오염된 프로토타입이 sink에 도달 (Node에서 RCE, 브라우저에서 XSS). HTTP 메서드: GET-우회-CSRF, X-HTTP-Method-Override, TRACE 활성화. 탐지: 추가 필드가 포함된 API 응답, 헤더에 있는 JWT (jwt.io에서 디코드). CORS 설정 오류 (any-origin 반사, null origin, 서브도메인 정규식 우회, postMessage)는 hunt-cors가 담당. API 설정 오류, 대량 할당, 프로토타입 오염을 사냥할 때 사용 (JWT 암호 → hunt-jwt-crypto). 항상 사용자의 언어로 응답해 주세요.
