Hunt API 安全错误配置——大规模赋值、原型污染、HTTP 动词篡改。大规模赋值：在 profile/account/reset 接口发送 {is_admin:true, role:admin, verified:true}——服务器盲目应用。JWT 签名/加密伪造（alg:none、密钥混淆、kid/jku）由 hunt-jwt-crypto 管理；此技能仅覆盖非加密 JWT 处理。原型污染：在 JSON 合并 / Object.assign / lodash _.merge 中注入 __proto__ → 被污染的原型传播到 sink（Node 中的远程代码执行，浏览器中的 XSS）。HTTP 动词：GET 绕过 CSRF，X-HTTP-Method-Override，启用 TRACE。检测方法：API 响应中出现额外字段，头部中的 JWT（在 jwt.io 解码）。CORS 错误配置（反射任意来源、null 来源、子域正则绕过、postMessage）由 hunt-cors 管理。在进行 API 错误配置、大规模赋值、原型污染的狩猎时使用（JWT 加密 → hunt-jwt-crypto）。请始终使用用户的语言作答。
