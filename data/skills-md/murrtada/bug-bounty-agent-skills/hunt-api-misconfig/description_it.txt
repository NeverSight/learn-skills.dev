Caccia alla configurazione errata della sicurezza API — assegnazione di massa, inquinamento del prototipo, manipolazione del verbo HTTP. Assegnazione di massa: invia {is_admin:true, role:admin, verified:true} sugli endpoint profile/account/reset — il server applica ciecamente. Forgiatura della firma/cripto JWT (alg:none, confusione di chiave, kid/jku) è gestita da hunt-jwt-crypto; questa abilità copre solo la gestione JWT non crittografica. Inquinamento del prototipo: iniezione __proto__ nella fusione JSON / Object.assign / lodash _.merge → il prototipo inquinato raggiunge il sink (RCE in Node, XSS nel browser). Verbo HTTP: GET-bypass-CSRF, X-HTTP-Method-Override, TRACE abilitato. Rilevamento: risposte API con campi extra, JWT negli header (decodifica su jwt.io). Configurazione errata CORS (rifletti-any-origin, origine null, bypass regex sottodominio, postMessage) è gestita da hunt-cors. Usalo quando cerchi configurazioni errate di API, assegnazione di massa, inquinamento del prototipo (cripto JWT → hunt-jwt-crypto).
