클릭재킹 탐지 — X-Frame-Options 또는 CSP frame‑ancestors 헤더가 없으면 공격자가 대상 페이지를 보이지 않는 iframe에 삽입해 사용자가 볼 수 없는 버튼을 클릭하도록 속일 수 있습니다 (UI 리드레싱). 대상: 로그인 흐름, 금전 이체, 계정 설정, OAuth 확인 페이지. 페이지를 가져온 뒤 실제 브라우저에서 프레임에 포함되는지 확인하고, 교차 사이트 컨텍스트에서도 민감한 상태 변환 동작이 유지되는지 증명하십시오 (SameSite 쿠키나 프레임버스팅 JavaScript으로 방어할 수 있습니다) — 헤더 부재만으로는 취약점이 아닙니다.
