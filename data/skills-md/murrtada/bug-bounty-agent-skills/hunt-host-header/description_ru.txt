Инъекция заголовка Host — отравление сброса пароля → ATO, отравление веб‑кэша через незащищённые заголовки Host/X-Forwarded-Host, SSRF, основанный на маршрутизации (Host выбирает upstream → облачные метаданные/внутренние сервисы), SSRF/обход ACL через переопределение пути (X-Original-URL/X-Rewrite-URL), отравление redirect_uri/issuer в OAuth, и отравление ссылок с абсолютным URL в электронных письмах. Уровень от высокого до критического, когда достигает ATO или массового отравления кэша. Основано на публичных исследованиях заголовка Host (PortSwigger «Practical web cache poisoning» + James Kettle, а также классический курс по отравлению сброса пароля). Применяется к любой форме «забыли пароль», приложению, обслуживаемому CDN/обратным прокси, конечной точке OAuth/OIDC или функции вставки абсолютного URL в письме.
