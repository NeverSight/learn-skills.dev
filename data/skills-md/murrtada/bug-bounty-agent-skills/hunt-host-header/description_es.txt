Caza de Inyección de Cabecera Host — envenenamiento de restablecimiento de contraseña → ATO, envenenamiento de caché web mediante Host/X-Forwarded-Host sin clave, SSRF basado en enrutamiento (Host escoge upstream → metadatos de nube/servicios internos), SSRF de sobrescritura de ruta/omisión de ACL (X-Original-URL/X-Rewrite-URL), envenenamiento de redirect_uri/issuer en OAuth, y envenenamiento de enlaces URL absolutos en correos electrónicos. De alta a crítica cuando llega a ATO o a un envenenamiento masivo de caché. Basado en investigación pública de cabecera Host (PortSwigger “Practical web cache poisoning” + James Kettle, y la clásica clase de envenenamiento de restablecimiento de contraseña). Aplicable a cualquier flujo de olvido de contraseña, aplicación fronted por CDN/reverse‑proxy, endpoint OAuth/OIDC, o característica de URL absoluta en email.
