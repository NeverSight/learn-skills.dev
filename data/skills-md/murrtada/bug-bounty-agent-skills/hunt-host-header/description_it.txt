Hunt Host Header Injection — avvelenamento del reset password → ATO, avvelenamento della cache web tramite Host/X-Forwarded-Host non indicizzati, SSRF basato su routing (Host sceglie upstream → metadati cloud/servizi interni), SSRF di sovrascrittura percorso/aggiramento ACL (X-Original-URL/X-Rewrite-URL), avvelenamento di redirect_uri/issuer OAuth e avvelenamento di link URL assoluti nelle email. Da alto a critico quando porta a ATO o a un avvelenamento massivo della cache. Basato su ricerche pubbliche sugli header Host (PortSwigger “Practical web cache poisoning” + James Kettle e la classica lezione di password‑reset‑poisoning). Utilizzabile in qualsiasi flusso di password dimenticata, applicazione dietro CDN/proxy inverso, endpoint OAuth/OIDC o funzionalità di URL assoluto nelle email.
