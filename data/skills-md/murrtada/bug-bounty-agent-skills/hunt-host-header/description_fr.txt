Hunt Host Header Injection — empoisonnement de réinitialisation de mot de passe → ATO, empoisonnement du cache web via Host/X-Forwarded-Host non indexé, SSRF basé sur le routage (Host choisit l’amont → métadonnées cloud/services internes), SSRF de contournement de chemin/ACL (X-Original-URL/X-Rewrite-URL), empoisonnement de redirect_uri/issuer OAuth, et empoisonnement de lien URL absolu dans les e‑mails. De haut à critique lorsqu’il conduit à ATO ou à un empoisonnement massif du cache. Basé sur la recherche publique sur les en‑têtes Host (PortSwigger « Practical web cache poisoning » + James Kettle, et la classe classique d’empoisonnement de réinitialisation de mot de passe). Utilisable sur tout flux d’oubli de mot de passe, application frontée par CDN/proxy inverse, point de terminaison OAuth/OIDC, ou fonctionnalité d’URL absolue dans les e‑mails.
