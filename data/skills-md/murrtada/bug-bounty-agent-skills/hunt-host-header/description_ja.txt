Hunt Host Header Injection — パスワードリセット汚染 → ATO、未キー化された Host/X-Forwarded-Host を利用したウェブキャッシュ汚染、ルーティングベースの SSRF（Host が上流を選択 → クラウドメタデータ/内部サービス）、パスオーバーライド SSRF/ACL バイパス（X-Original-URL/X-Rewrite-URL）、OAuth の redirect_uri/issuer 汚染、メール内の絶対 URL リンク汚染。ATO または大規模キャッシュ汚染に至った場合は High から Critical の深刻度。公開された Host ヘッダー研究（PortSwigger の「Practical web cache poisoning」＋ James Kettle、そして古典的なパスワードリセット汚染クラス）を基に構築。Forgot‑password フロー、CDN/リバースプロキシ前面のアプリ、OAuth/OIDC エンドポイント、またはメール内の絶対 URL 機能のいずれでも使用可能。
