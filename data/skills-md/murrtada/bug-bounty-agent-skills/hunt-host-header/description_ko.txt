Hunt Host Header Injection — 비밀번호 재설정 중독 → ATO, 키가 없는 Host/X-Forwarded-Host를 통한 웹 캐시 중독, 라우팅 기반 SSRF (Host가 업스트림을 선택 → 클라우드 메타데이터/내부 서비스), 경로 오버라이드 SSRF/ACL 우회 (X-Original-URL/X-Rewrite-URL), OAuth redirect_uri/issuer 중독, 그리고 이메일 내 절대 URL 링크 중독. ATO나 대규모 캐시 중독에 이를 경우 위험도는 높음에서 치명적. 공개된 Host-header 연구(PortSwigger ‘Practical web cache poisoning’ + James Kettle, 그리고 고전적인 비밀번호 재설정 중독 강의)를 기반으로 함. 비밀번호 찾기 흐름, CDN/리버스 프록시 기반 앱, OAuth/OIDC 엔드포인트, 혹은 이메일 내 절대 URL 기능에 모두 적용 가능.
