صيد حقن رأس المضيف — تسمم إعادة تعيين كلمة المرور → اختراق حسابات (ATO)، تسمم ذاكرة التخزين المؤقت للويب عبر رؤوس Host/X-Forwarded-Host غير المهيأة، SSRF قائم على التوجيه (يختار Host المصدر الأعلى → بيانات سحابة التعريف/الخدمات الداخلية)، SSRF/تجاوز ACL عبر تجاوز المسار (X-Original-URL/X-Rewrite-URL)، تسمم redirect_uri/issuer في OAuth، وتسمم روابط URL مطلق في رسائل البريد الإلكتروني. تصنيف عالي إلى حرج عندما يصل إلى اختراق حسابات أو تسمم تخزين مؤقت جماعي. مبني على أبحاث عامة حول رأس المضيف (PortSwigger “Practical web cache poisoning” + جيمس كيتل، وفئة تسمم إعادة تعيين كلمة المرور الكلاسيكية). يُستخدم في أي تدفق نسيان كلمة مرور، تطبيق أمامه CDN/عكس بروكسي، نقطة نهاية OAuth/OIDC، أو ميزة URL مطلق في البريد الإلكتروني.
