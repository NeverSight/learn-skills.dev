搜尋 Host Header 注入 — 密碼重設投毒 → ATO、透過未加鍵的 Host/X-Forwarded-Host 進行網頁快取投毒、基於路由的 SSRF（Host 選擇上游 → 雲端元資料／內部服務）、路徑覆寫 SSRF／ACL 繞過（X-Original-URL／X-Rewrite-URL）、OAuth redirect_uri／issuer 投毒，以及電子郵件中的絕對 URL 連結投毒。當達成 ATO 或大規模快取投毒時，危害等級從高到危急。此技術建立於公開的 Host‑header 研究（PortSwigger《Practical web cache poisoning》+ James Kettle，以及經典的密碼重設投毒課程）。可用於任何忘記密碼流程、CDN／反向代理前置的應用、OAuth/OIDC 端點，或是電子郵件中的絕對 URL 功能。
