gRPC の脆弱性を狩る — サーバーリフレクションが有効（すべてのサービス・メソッドを列挙）、内部エンドポイントで認証やメタデータ除去が欠如、平文 gRPC を HTTP/2 上で使用、内部エンドポイント情報の露出、proto ファイルの漏洩、gRPC-Web / grpc-gateway のトランスコーディングインジェクション、そして HTTP/2 Rapid Reset DoS（CVE-2023-44487）。対象がポート 50051・443・8443・9090 で HTTP/2 を提供しているとき、grpcurl / grpcui がリフレクションを検出したとき、Envoy や grpc-gateway プロキシがマイクロサービスの前にあるとき、あるいはリコンでマイクロサービスアーキテクチャが判明したときに使用する。
