ابحث عن ثغرات gRPC — تمكين انعكاس الخادم (قائمة بجميع الخدمات/الطرق)، عدم وجود مصادقة / إزالة البيانات الوصفية على نقاط النهاية الداخلية، gRPC نصي عبر HTTP/2، كشف نقاط النهاية الداخلية، تسرب ملفات proto، حقن تحويل الترميز gRPC-Web/grpc-gateway، وهجوم إنكار الخدمة Rapid Reset عبر HTTP/2 (CVE-2023-44487). استخدم ذلك عندما يكشف الهدف عن منفذ 50051 / 443 / 8443 / 9090 مع HTTP/2، عندما يكتشف grpcurl/grpcui الانعكاس، عندما يتوسط Envoy أو وكيل grpc-gateway خدمة مصغرة، أو عندما يكشف الاستطلاع بنية الخدمات المصغرة.
