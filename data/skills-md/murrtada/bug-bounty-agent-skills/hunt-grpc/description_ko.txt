gRPC 취약점 탐색 — 서버 리플렉션 활성화(모든 서비스·메서드 열람), 내부 엔드포인트에서 인증 누락·메타데이터 제거, HTTP/2를 통한 평문 gRPC, 내부 엔드포인트 노출, proto 파일 유출, gRPC-Web·grpc-gateway 트랜스코딩 인젝션, 그리고 HTTP/2 Rapid Reset DoS(CVE-2023-44487). 대상이 HTTP/2와 함께 포트 50051·443·8443·9090을 열어두었을 때, grpcurl·grpcui가 리플렉션을 감지했을 때, Envoy 또는 grpc-gateway 프록시가 마이크로서비스 앞에 있을 때, 또는 탐색 결과 마이크로서비스 아키텍처가 드러났을 때 사용합니다.
