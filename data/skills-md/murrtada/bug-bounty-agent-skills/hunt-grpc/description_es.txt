Caza vulnerabilidades de gRPC — reflexión del servidor habilitada (enumerar todos los servicios/métodos), falta de autenticación / eliminación de metadatos en endpoints internos, gRPC en texto plano sobre HTTP/2, divulgación de endpoints internos, filtración de archivos proto, inyección de transcodificación gRPC-Web/grpc-gateway y DoS por reinicio rápido de HTTP/2 (CVE‑2023‑44487). Utilízalo cuando el objetivo exponga el puerto 50051 / 443 / 8443 / 9090 con HTTP/2, cuando grpcurl/grpcui detecte reflexión, cuando un proxy Envoy o grpc‑gateway esté frente a un microservicio, o cuando el reconocimiento revele una arquitectura de microservicios.
