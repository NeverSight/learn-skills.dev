Recherche de vulnérabilités gRPC — réflexion du serveur activée (énumérer tous les services/méthodes), authentification manquante / suppression des métadonnées sur les points de terminaison internes, gRPC en clair sur HTTP/2, divulgation de points de terminaison internes, fuite de fichiers proto, injection de transcoding gRPC-Web/grpc-gateway, et DoS par Reset rapide HTTP/2 (CVE-2023-44487). Utilisez lorsque la cible expose le port 50051 / 443 / 8443 / 9090 avec HTTP/2, lorsque grpcurl/grpcui détecte la réflexion, lorsqu’un proxy Envoy ou grpc-gateway se trouve devant un microservice, ou lorsqu’une reconnaissance révèle une architecture microservice.
