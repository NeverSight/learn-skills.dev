Suche nach gRPC‑Schwachstellen — Server‑Reflection aktiviert (Alle Dienste/Methoden auflisten), fehlende Authentifizierung bzw. Metadaten‑Entfernung bei internen Endpunkten, Klartext‑gRPC über HTTP/2, Offenlegung interner Endpunkte, Proto‑Datei‑Leck, gRPC‑Web/grpc‑gateway Transkodierungs‑Injektion und HTTP/2 Rapid Reset DoS (CVE‑2023‑44487). Verwenden, wenn das Ziel die Ports 50051 / 443 / 8443 / 9090 mit HTTP/2 offenlegt, wenn grpcurl/grpcui Reflection erkennt, wenn ein Envoy‑ oder grpc‑gateway‑Proxy einen Microservice vorgelagert hat, oder wenn die Reconnaissance eine Microservice‑Architektur aufdeckt.
