Cerca vulnerabilità gRPC — riflessione del server abilitata (elenca tutti i servizi/metodi), autenticazione mancante / rimozione dei metadati negli endpoint interni, gRPC in chiaro su HTTP/2, divulgazione di endpoint interni, perdita di file proto, iniezione di transcoding gRPC‑Web/grpc‑gateway e DoS Rapid Reset HTTP/2 (CVE‑2023‑44487). Utilizza quando il bersaglio espone le porte 50051 / 443 / 8443 / 9090 con HTTP/2, quando grpcurl/grpcui rileva la riflessione, quando un proxy Envoy o grpc‑gateway si trova davanti a un microservizio, o quando la ricognizione rivela un’architettura a microservizi.
