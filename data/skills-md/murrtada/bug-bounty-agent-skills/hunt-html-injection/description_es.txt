Caza de inyección HTML — la entrada suministrada por el usuario se muestra como HTML sin procesar en la respuesta sin sanitización, lo que permite a un atacante inyectar etiquetas HTML arbitrarias (pero no necesariamente JavaScript). Es de menor gravedad que XSS pero permite phishing, manipulación de la UI y recopilación de credenciales mediante formularios inyectados. Úsalo al probar superficies de visualización de texto (resultados de búsqueda, campos de perfil, comentarios, mensajes de error, formularios de retroalimentación). Para marcado que ejecuta JavaScript, pasa a hunt‑xss.
