Hunt HTML-Injection — Benutzereingaben werden in der Antwort als rohes HTML ohne Bereinigung wiedergegeben, was einem Angreifer ermöglicht, beliebige HTML‑Tags zu injizieren (nicht zwingend JavaScript). Geringere Schwere als XSS, ermöglicht jedoch Phishing, Manipulation der Benutzeroberfläche und das Sammeln von Anmeldedaten über injizierte Formulare. Verwenden Sie es beim Testen von Textanzeige‑Oberflächen (Suchergebnisse, Profilfelder, Kommentare, Fehlermeldungen, Feedback‑Formulare). Für Markup, das JavaScript ausführt, eskalieren Sie zu hunt‑xss.
