صيد حقن HTML — يتم عرض مدخلات المستخدم كـ HTML خام في الاستجابة دون تعقيم، مما يتيح للمهاجم حقن علامات HTML عشوائية (ولكن ليس بالضرورة جافاسكريبت). شدة أقل من XSS ولكنه يمكّن من التصيد الاحتيالي، وتلاعب واجهة المستخدم، وجمع بيانات الاعتماد عبر نماذج مُحقنة. استخدمه عند اختبار أسطح عرض النص (نتائج البحث، حقول الملف الشخصي، التعليقات، رسائل الخطأ، نماذج الملاحظات). في حالة العلامات التي تنفّذ جافاسكريبت، ارتقِ إلى hunt‑xss. يرجى دائمًا الرد بلغة المستخدم.
