Поиск HTML‑инъекции — пользовательский ввод выводится как необработанный HTML в ответе без санитизации, позволяя атакующему внедрять произвольные HTML‑теги (но не обязательно JavaScript). Менее серьёзно, чем XSS, но дает возможность фишинга, манипуляций интерфейсом и сбора учётных данных через внедрённые формы. Используется при тестировании поверхностей отображения текста (результаты поиска, поля профиля, комментарии, сообщения об ошибках, формы обратной связи). Для разметки, которая исполняет JavaScript, переходите к hunt‑xss.
