Ищем баги функций LLM/AI — инъекции подсказок, косвенные инъекции, эксфильтрация через использование инструментов/markdown, ASCII‑смuggling, безопасность агентных ИИ (OWASP Agentic Apps 2026, ASI01‑ASI10). Шаблоны: прямая инъекция («ignore previous instructions»), косвенная инъекция через документы/веб‑страницы/электронные письма, которые модель читает, ASCII‑смuggling (блок Unicode Tags U+E0000‑U+E007F, невидимы человеку, декодируются моделью), эксфильтрация через использование инструментов (модель имеет инструменты fetch/browse, атакующий внедряет OOB‑URL, модель выводит историю чата/секреты), эксфильтрация через markdown‑изображения без клика, извлечение системного промпта, IDOR‑через‑ИИ (кросс‑тенантные данные). Цели: чат‑боты, RAG, сумматоры, агентные копилоты, инструменты MCP. Обнаружение: любой endpoint, поддерживающий LLM, загрузка документа, инициирующая обработку ИИ, автономный агент с инструментами. Проверка: OOB/Collaborator‑callback для эксфильтрации, воспроизводимый дословный утечка системного промпта (запустить дважды), проверяемая кросс‑тенантная утечка или RCE. Галлюцинация НЕ считается находкой. Используйте при охоте на функции ИИ, чат‑боты, RAG, агентные системы, MCP.
