LLM/AI 기능 버그 사냥 — 프롬프트 인젝션, 간접 인젝션, 도구 사용/마크다운을 통한 유출, ASCII 스머글링, 에이전트 AI 보안(OWASP Agentic Apps 2026, ASI01-ASI10). 패턴: 직접 인젝션('이전 지시 무시'), 모델이 읽는 문서/웹 페이지/이메일을 통한 간접 인젝션, ASCII 스머글링(Unicode Tags 블록 U+E0000‑U+E007F, 인간에게는 보이지 않으며 모델이 디코딩), 도구 사용 유출(모델에 fetch/browse 도구가 있어 공격자가 OOB URL을 삽입, 모델이 채팅 기록/시크릿을 유출), 마크다운 이미지 제로클릭 유출, 시스템 프롬프트 추출, AI를 통한 IDOR(교차 테넌트 데이터). 대상: 챗봇, RAG, 요약기, 에이전트 코파일럿, MCP 도구. 탐지: LLM 기반 엔드포인트 전부, AI 처리를 트리거하는 문서 업로드, 도구가 있는 자율 에이전트. 검증: 유출을 위한 OOB/협력자 콜백, 그대로 재현 가능한 시스템 프롬프트 누수(두 번 실행), 검증 가능한 교차 테넌트 누수 또는 RCE. 허위 생성은 발견 사항이 아니다. AI 기능, 챗봇, RAG, 에이전트 시스템, MCP를 사냥할 때 사용한다.
