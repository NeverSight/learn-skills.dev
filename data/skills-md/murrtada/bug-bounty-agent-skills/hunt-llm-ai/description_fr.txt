Chasse aux bugs de fonctionnalités LLM/IA — injection d’invite, injection indirecte, exfiltration via utilisation d’outils/markdown, contrebande ASCII, sécurité IA agentique (OWASP Agentic Apps 2026, ASI01‑ASI10). Motifs : injection directe (« ignore previous instructions »), injection indirecte via documents/pages web/e‑mail que le modèle lit, contrebande ASCII (bloc d’étiquettes Unicode U+E0000‑U+E007F, invisible aux humains, décodé par le modèle), exfiltration par utilisation d’outils (le modèle possède un outil fetch/browse, l’attaquant injecte une URL OOB, le modèle exfiltre l’historique de chat/secrets), exfiltration zero‑click d’image markdown, extraction de l’invite système, IDOR via IA (données inter‑locataires). Cibles : chatbots, RAG, résumeurs, copilotes agentiques, outils MCP. Détection : tout endpoint basé sur LLM, upload de documents déclenchant le traitement IA, agent autonome avec outils. Validation : rappel OOB/collaborateur pour exfiltration, fuite d’invite système reproductible à l’identique (exécutée deux fois), fuite vérifiable inter‑locataire ou RCE. La confabulation N’EST PAS une constatation. Utiliser lors de la chasse aux fonctionnalités IA, chatbots, RAG, systèmes agentiques, MCP.
