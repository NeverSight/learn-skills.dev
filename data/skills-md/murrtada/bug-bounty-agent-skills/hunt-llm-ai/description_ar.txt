صيد أخطاء ميزات نماذج اللغة الكبيرة/الذكاء الاصطناعي — حقن المطالبات، الحقن غير المباشر، استخراج البيانات عبر استخدام الأدوات/ماركداون، تهريب ASCII، أمان الذكاء الاصطناعي الوكّالي (OWASP Agentic Apps 2026، ASI01‑ASI10). الأنماط: حقن مباشر (‘تجاهل التعليمات السابقة’)، حقن غير مباشر عبر المستندات/صفحات الويب/البريد الإلكتروني التي يقرأها النموذج، تهريب ASCII (كتل علامات Unicode U+E0000‑U+E007F، غير مرئية للبشر، يفسرها النموذج)، استخراج البيانات عبر استخدام الأدوات (النموذج يمتلك أداة جلب/تصفح، يحقن المهاجم عنوان URL خارجي، يخرج النموذج تاريخ الدردشة/الأسرار)، استخراج صفر‑نقر عبر صور ماركداون، استخراج موجه النظام، IDOR عبر الذكاء الاصطناعي (بيانات بين المستأجرين). الأهداف: روبوتات الدردشة، RAG، ملخصات النصوص، مساعدوك الوكّاليون، أدوات MCP. الاكتشاف: أي نقطة نهاية مدعومة بنموذج لغة كبير، تحميل مستند يُفعل معالجة الذكاء الاصطناعي، وكيل ذاتي مع أدوات. التحقق: استدعاء خارجي/متعاون لاستخراج البيانات، تسريب موجه النظام قابل لإعادة الإنتاج حرفيًا (تشغيل مرتين)، تسريب بين المستأجرين يمكن التحقق منه أو تنفيذ أمر عن بُعد. التخمُّن ليس اكتشافًا. استخدمه عند صيد ميزات الذكاء الاصطناعي، روبوتات الدردشة، RAG، الأنظمة الوكالية، MCP.
