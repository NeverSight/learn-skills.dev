Комплексная методика OSINT для внешних операций red‑team и авторизованных оценок поверхности атаки. Охватывает 5‑ступенчатый конвейер разведки (поиск зацепок, расширение активов, обогащение, анализ экспозиции, отчетность), дисциплину графа активов с 29 типами активов, рубрику тяжести (КРИТИЧЕСКО, ВЫСОКИЙ, СРЕДНИЙ, НИЗКИЙ, ИНФО), рабочие потоки повышения уверенности, планирование времени, правила триажа на уровне активов, тактики, масштабируемые стратегии, сопоставление идентичности и инфраструктуры (Entra/Okta/ADFS/Google/SAML/M365 Teams+SharePoint+OAuth), методология карт API и аутентификации, глубокий анализ JavaScript, поверхностные атаки на мобильные приложения, облачную поверхность атаки, корреляцию нарушений и идентичностей, маркировку обнаруживаемости, проверку с учётом обнаружения (откат, ротация персон), дисциплину валидации только на чтение, обход WAF/CDN + обнаружение источника, приоритизацию уязвимостей (CVE/EPSS/KEV), планирование фишинговой инфраструктуры + разработку предтекста, шаблоны подачи в bug bounty, шаблоны клиентских материалов с переводом риска, расследование групп угроз (включая RU/CN‑повороты), отслеживание криптовалют, форензика изображений/видео, хроно‑геолокацию. Используйте при планировании или проведении разведки против уполномоченных целей, картировании внешней поверхности атаки организации, расследовании лица/субъекта, отслеживании потоков криптовалют, геолокации медиа или выполнении задач по атрибуции.
