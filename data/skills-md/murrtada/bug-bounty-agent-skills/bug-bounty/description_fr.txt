Workflow complet de bug bounty — reconnaissance (énumération de sous‑domaines, découverte d’actifs, fingerprinting, périmètre HackerOne, audit du code source), apprentissage pré‑chasse (rapports divulgués, recherche de stack technologique, cartes mentales, modélisation de menace), chasse aux vulnérabilités (IDOR, SSRF, XSS, contournement d’authentification, CSRF, conditions de concurrence, injection SQL, XXE, upload de fichiers, logique métier, GraphQL, smuggling HTTP, empoisonnement de cache, OAuth, canaux latéraux temporels, OIDC, SSTI, prise de contrôle de sous‑domaine, mauvaise configuration cloud, chaînes ATO, IA agentive), tests de sécurité LLM/IA (IDOR de chatbot, injection de prompt, injection indirecte, smuggling ASCII, canaux d’exfiltration, RCE via outils de code, extraction du prompt système, ASI01‑ASI10), chaînage de bugs A‑vers‑B (IDOR→contournement d’auth, SSRF→métadonnées cloud, XSS→ATO, redirection ouverte→vol OAuth, S3→bundle→secret→OAuth), tables de contournement (contournement IP SSRF, contournement de redirection ouverte, contournement d’upload de fichiers), grep spécifique à chaque langage (pollution de prototype JS, pickle Python, juggling de types PHP, Go template.HTML, Ruby YAML.load, Rust unwrap), et reporting (porte à 7 questions, 4 portes de validation, rédaction au ton humain, modèles par classe de vulnérabilité, CVSS 3.1, génération de PoC, liste toujours rejetée, tableau de chaînes conditionnelles, checklist de soumission). Utilisable pour TOUTE tâche de bug bounty — démarrer une nouvelle cible, faire de la reconnaissance, chasser des vulnérabilités spécifiques, auditer le code source, tester les fonctions IA, valider les découvertes ou rédiger des rapports.
