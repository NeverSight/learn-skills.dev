Buscar divulgación de información NTLM/Negotiate en IIS/SharePoint/Exchange accesibles desde Internet. La captura anónima del desafío NTLM Tipo‑2 filtra el dominio NetBIOS, el bosque DNS interno, el nombre del equipo y la marca de tiempo de AD mediante la estructura AV_PAIRS. Los nombres de host predeterminados de instaladores de Windows (patrón WIN‑XXXXXXXXXXX) indican aprovisionamiento perezoso. Úselo cuando el objetivo anuncie encabezados `WWW-Authenticate: NTLM` o `Negotiate` de forma anónima.
