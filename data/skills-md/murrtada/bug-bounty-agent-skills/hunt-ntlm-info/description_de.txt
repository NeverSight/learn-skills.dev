Jagen Sie NTLM/Negotiate-Informationslecks auf internetfähigen IIS/SharePoint/Exchange. Das Erfassen einer anonymen NTLM Type‑2‑Challenge leakt NetBIOS‑Domäne, internen DNS‑Forest, Rechnernamen, AD‑Zeitstempel über die AV_PAIRS‑Struktur. Standard‑Windows‑Installer‑Hostnamen (Muster WIN-XXXXXXXXXXX) deuten auf schlampige Bereitstellung hin. Verwenden Sie dies, wenn das Ziel anonym `WWW-Authenticate: NTLM` oder `Negotiate`‑Header ausgibt.
