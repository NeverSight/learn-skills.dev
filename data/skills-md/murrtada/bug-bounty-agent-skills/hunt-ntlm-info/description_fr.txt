Recherche de divulgation d’informations NTLM/Negotiate sur les serveurs IIS/SharePoint/Exchange accessibles depuis Internet. La capture anonyme d’un défi NTLM de type 2 révèle le domaine NetBIOS, la forêt DNS interne, le nom de l’ordinateur et l’horodatage AD via la structure AV_PAIRS. Les noms d’hôte Windows‑installer par défaut (modèle WIN‑XXXXXXXXXXX) signalent un provisionnement paresseux. À utiliser lorsque la cible annonce les en‑têtes `WWW‑Authenticate: NTLM` ou `Negotiate` de façon anonyme.
