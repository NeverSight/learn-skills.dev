Entdecke die versteckte Backend‑API einer Single‑Page‑App aus ihrem öffentlichen JS‑Bundle und teste diese API auf fehlerhafte Zugriffskontrolle bzw. fehlende Authentifizierung. Einer der ertragreichsten Web‑Ansätze in der modernen Recon – SPAs übertragen ihre komplette Backend‑Routenkarte an den Browser, und die dahinterliegende API fehlt häufig die Auth‑Middleware, die die Login‑Seite impliziert. Entwickelt aus einem autorisierten Einsatz, bei dem dieser Ansatz eine nicht authentifizierte Finanz‑API fand, die ein ASM‑Scan mit hunderten „Criticals“ völlig übersehen hatte. Verwende es, wann immer ein Ziel eine JavaScript‑intensive SPA (React/Vue/Angular/Next) ausliefert, eine Sub‑Domain wie „app“, „console“, „dashboard“ oder „portal“ besitzt oder irgendein `*api*`‑Host in der Recon auftaucht. Durchgesickerte Build‑Artefakte (Source‑Maps / .env / .git / asset‑manifest) gehören zu hunt‑source‑leak; API‑Version‑Inventar und Verhaltens‑Diffing zu hunt‑shadow‑api; diese Fähigkeit umfasst das Mapping der Backend‑Routen einer laufenden SPA aus ihrem JS‑Bundle und das Testen auf fehlerhafte Zugriffskontrolle bzw. fehlende Authentifizierung.
