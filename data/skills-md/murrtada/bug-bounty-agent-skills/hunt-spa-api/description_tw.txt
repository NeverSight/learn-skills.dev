從公開的 JS 包中發現單頁應用程式（SPA）隱藏的後端 API，然後測試該 API 是否存在存取控制缺陷／缺少驗證。這是現代偵測中收益最高的網路手法之一──SPA 會將全部後端路由圖送到瀏覽器，而其背後的 API 常常缺少登入頁面所暗示的驗證中介層。此手法源於一次授權測試，當時發現了一個未經驗證的金融 API，該 API 完全被 ASM 掃描（報告了數百個「Critical」）所遺漏。每當目標提供以 JS 為主的 SPA（React/Vue/Angular/Next）、「app」/「console」/「dashboard」/「portal」子域名，或在偵測中出現任何 `*api*` 主機時，都可使用此手法。洩露的建置產物（source maps / .env / .git / asset-manifest）屬於 hunt‑source‑leak；API 版本清單與行為差異比對由 hunt‑shadow‑api 負責；此技能負責從實時 SPA 的 JS 包映射後端路由，並測試其存取控制缺陷／缺少驗證。
