Обнаружьте скрытый бекенд‑API одностраничного приложения из его публичного JS‑бандла, а затем протестируйте этот API на наличие нарушений контроля доступа / отсутствия аутентификации. Одно из самых эффективных веб‑приёмов в современной разведке — SPA передают полную карту маршрутов бекенда в браузер, и API за ними часто лишён middleware аутентификации, которой подразумевает страница входа. Разработано в рамках авторизованного задания, где этот приём нашёл неаутентифицированный финансовый API, полностью упущенный сканером ASM, сообщившим о сотнях «Критических» уязвимостей. Применяйте, когда цель обслуживает тяжёлый по JS SPA (React/Vue/Angular/Next), субдомен «app»/«console»/«dashboard»/«portal», или любой хост с `*api*`, обнаруженный в разведке. Утечка артефактов сборки (source maps / .env / .git / asset-manifest) принадлежит hunt-source-leak; инвентаризация версий API и дифференцирование поведения — hunt-shadow-api; этот навык отвечает за построение карты бекенд‑маршрутов живого SPA из его JS‑бандла и тестирование их на нарушения контроля доступа / отсутствие аутентификации.

Пожалуйста, всегда отвечайте на языке пользователя.
