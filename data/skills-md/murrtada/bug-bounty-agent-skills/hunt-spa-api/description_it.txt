Scopri l'API backend nascosta di una single-page app dal suo bundle JS pubblico, poi testa quell'API per controlli di accesso rotti / autenticazione mancante. Uno dei più redditizi approcci web nella recon moderna — le SPA inviano la loro intera mappa delle rotte backend al browser, e l'API che le supporta spesso manca del middleware di autenticazione che la pagina di login implica. Realizzato da un ingaggio autorizzato in cui questo approccio ha trovato un'API finanziaria non autenticata che una scansione ASM che riportava centinaia di “Critical” aveva completamente trascurato. Usalo ogni volta che un obiettivo serve una SPA pesante di JS (React/Vue/Angular/Next), un sottodominio “app”/“console”/“dashboard”/“portal”, o qualsiasi host `*api*` appare nella recon. Gli artefatti di build trapelati (source maps / .env / .git / asset-manifest) sono gestiti da hunt‑source‑leak; l'inventario delle versioni API e il diff comportamentale da hunt‑shadow‑api; questa skill si occupa di mappare le rotte backend di una SPA live dal suo bundle JS e testarle per controlli di accesso rotti / autenticazione mancante.
