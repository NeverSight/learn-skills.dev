Descubre la API oculta del backend de una single‑page‑app a partir de su paquete público de JavaScript y luego prueba esa API en busca de control de acceso roto o autenticación ausente. Es una de las jugadas web de mayor rendimiento en el reconocimiento moderno: las SPA envían su mapa completo de rutas del backend al navegador, y la API detrás de ellas suele carecer del middleware de autenticación que la página de login implica. Creado a partir de un compromiso autorizado donde esta jugada encontró una API financiera no autenticada que un escaneo ASM, que reportaba cientos de “Criticals”, pasó completamente por alto. Úsalo siempre que el objetivo sirva una SPA cargada de JS (React/Vue/Angular/Next), un subdominio de “app”, “console”, “dashboard” o “portal”, o cualquier host que incluya `*api*` aparezca en el reconocimiento. Los artefactos de compilación filtrados (source maps / .env / .git / asset‑manifest) pertenecen a hunt‑source‑leak; el inventario de versiones de la API y el análisis de diferencias de comportamiento a hunt‑shadow‑api; esta habilidad consiste en mapear las rutas del backend de una SPA en vivo a partir de su bundle JS y probarlas por control de acceso roto o falta de autenticación.
