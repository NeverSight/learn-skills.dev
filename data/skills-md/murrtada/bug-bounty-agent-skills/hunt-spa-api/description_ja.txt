シングルページアプリケーション（SPA）の公開JSバンドルから隠れたバックエンドAPIを発見し、そのAPIのアクセス制御の欠如や認証未設定をテストする。現代のリコンで最も効果的な手法の一つで、SPAはバックエンドのルートマップ全体をブラウザに送信するため、ログインページが示唆する認証ミドルウェアが頻繁に欠如している。許可されたエンゲージメントで、この手法により何百もの「Critical」を報告したASMスキャンが完全に見逃した、認証なしの金融APIを発見した事例がある。対象がJS中心のSPA（React/Vue/Angular/Next）を提供している、あるいは「app」「console」「dashboard」「portal」サブドメイン、またはリコンで `*api*` を含むホストが出てきたときに使用する。漏洩したビルドアーティファクト（ソースマップ/.env/.git/asset‑manifest）は hunt‑source‑leak が管理し、API のバージョンインベントリと振る舞いの差分は hunt‑shadow‑api が担当する。本スキルはライブ SPA の JS バンドルからバックエンドルートをマッピングし、アクセス制御の破損や認証の欠如をテストすることを目的とする。
