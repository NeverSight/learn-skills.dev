공개된 JS 번들에서 단일 페이지 애플리케이션(SPA)의 숨겨진 백엔드 API를 찾아낸 다음, 해당 API의 접근 제어 결함·인증 누락을 테스트합니다. 현대 리콘에서 가장 높은 수익을 기대할 수 있는 웹 기법 중 하나로, SPA는 전체 백엔드 라우트 맵을 브라우저에 전달하고, 그 뒤에 있는 API는 로그인 페이지가 암시하는 인증 미들웨어가 종종 누락됩니다. 이 기법은 권한 있는 참여에서 수백 개의 “Critical”을 보고한 ASM 스캔이 완전히 놓친 인증되지 않은 금융 API를 발견한 사례에서 구축되었습니다. 대상이 JS 중심의 SPA(React·Vue·Angular·Next)를 제공하거나 “app”·“console”·“dashboard”·“portal” 서브도메인, 혹은 `*api*` 호스트가 리콘에 나타날 때마다 사용하세요. 누출된 빌드 아티팩트(소스 맵·.env·.git·asset-manifest)는 hunt‑source‑leak이, API 버전 인벤토리와 행동 차이는 hunt‑shadow‑api가 담당합니다. 이 스킬은 라이브 SPA의 JS 번들에서 백엔드 라우트를 매핑하고, 접근 제어 결함·인증 누락을 테스트하는 작업을 수행합니다.
