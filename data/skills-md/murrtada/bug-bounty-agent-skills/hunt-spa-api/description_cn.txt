从公开的 JS 包中发现单页应用（SPA）的隐藏后端 API，然后测试该 API 是否存在访问控制失效或缺少身份验证的问题。这是现代资产勘测中收益最高的 Web 手法之一——SPA 会把完整的后端路由映射发送到浏览器，而这些 API 往往缺少登录页面暗示的认证中间件。该手法来源于一次授权合作，在该合作中发现了一个未认证的金融 API，而 ASM 扫描报告的数百个 “Critical” 完全漏掉了它。每当目标提供一个使用大量 JS 的 SPA（React/Vue/Angular/Next），或拥有 “app”“console”“dashboard”“portal” 子域，或在勘测中出现任何 `*api*` 主机时均可使用。泄漏的构建产物（source maps / .env / .git / asset‑manifest）归 hunt‑source‑leak 所有；API 版本清单和行为差异化归 hunt‑shadow‑api 所有；此技能负责从实时 SPA 的 JS 包映射其后端路由并测试其访问控制失效或缺少认证。
