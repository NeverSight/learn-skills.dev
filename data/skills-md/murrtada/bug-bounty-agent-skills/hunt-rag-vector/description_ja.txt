RAG パイプラインにおけるベクトルストア／埋め込み層の弱点をハント (OWASP LLM08 ベクトルおよび埋め込みの弱点) — セッションやユーザーを跨いで持続する永続的コーパス汚染（1回限りの間接プロンプトインジェクション（hunt-llm-ai が所有）とは異なる）、テナント間ベクトルデータベース IDOR（Pinecone、Weaviate、Chroma、Milvus、Qdrant、pgvector に対する認証なしまたはスコープ外クエリ）、類似検索結果におけるソーステキスト／メタデータ漏洩、そして敵対的埋め込み近接による取得ハイジャック（RAG の「SEO ポイズニング」）。  
対象: 共有ナレッジベースを持つアプリ、チャットボットに供給する文書アップロード機能、または直接アクセス可能なベクトル DB ポートを備えたもの。  
検証方法: 別のクリーンなセッション／アカウントでも汚染された結果が継承されること、またはテナント間アーティファクトが独立して検証可能であることを確認する。妄想は発見として認めず、hunt-llm-ai と同等の基準とする。  
対象が RAG バックエンドである、ベクトル DB ポートを公開している、またはユーザーがアップロードした文書が他ユーザーのクエリで取得される可能性がある場合に使用する。
