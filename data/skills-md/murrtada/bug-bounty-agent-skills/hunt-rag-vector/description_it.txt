Cerca vulnerabilità del vector‑store / strato di embedding nelle pipeline RAG (OWASP LLM08 Vulnerabilità di Vector ed Embedding) — avvelenamento persistente del corpus che sopravvive tra sessioni e utenti (distinto dall’iniezione di prompt indiretta one‑shot, di proprietà di hunt‑llm‑ai), IDOR cross‑tenant del database vettoriale (query non autenticate o non limitate su Pinecone/Weaviate/Chroma/Milvus/Qdrant/pgvector), perdita di testo sorgente/metadati nei risultati di ricerca per similarità e dirottamento del recupero tramite prossimità di embedding avversaria (“avvelenamento SEO” per RAG). Obiettivi: qualsiasi app con una base di conoscenza condivisa, caricamento di documenti che alimentano un chatbot, o una porta del vector‑DB direttamente raggiungibile. Validazione: una seconda sessione/account pulito deve ereditare un risultato avvelenato, o un artefatto cross‑tenant deve essere verificabile in modo indipendente — la confabulazione non è un risultato, gli standard sono gli stessi di hunt‑llm‑ai. Usa quando il bersaglio è basato su RAG, espone una porta vector‑DB, o consente agli utenti di caricare documenti che le query di altri utenti recuperano successivamente.
