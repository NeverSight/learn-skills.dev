Cazar debilidades en la capa de almacén vectorial / incrustación en canalizaciones RAG (OWASP LLM08 Debilidades de Vectores y Embeddings) — envenenamiento persistente del corpus que sobrevive entre sesiones y usuarios (distinto de la inyección indirecta de prompt de un solo disparo, que pertenece a hunt-llm-ai), IDOR de base de datos vectorial entre inquilinos (consultas no autenticadas o sin alcance contra Pinecone/Weaviate/Chroma/Milvus/Qdrant/pgvector), fuga de texto fuente/metadatos en los resultados de búsqueda por similitud y secuestro de recuperación mediante proximidad adversarial de embeddings (“envenenamiento SEO” para RAG). Objetivos: cualquier aplicación con una base de conocimientos compartida, carga de documentos que alimenta un chatbot o un puerto de base de datos vectorial directamente accesible. Validar: una segunda sesión/cuenta limpia debe heredar un resultado envenenado, o un artefacto entre inquilinos debe ser verificable de forma independiente — la confabulación no cuenta como hallazgo, mismo criterio que hunt-llm-ai. Utilizar cuando el objetivo esté respaldado por RAG, exponga un puerto de base de datos vectorial o permita a los usuarios cargar documentos que luego sean recuperados por consultas de otros usuarios.
