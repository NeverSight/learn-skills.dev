استهداف ضعف مخزن المتجهات/طبقة التضمين في خطوط أنابيب RAG (OWASP LLM08 ضعف المتجهات والتضمين) — تسميم مجموعة البيانات المستمر الذي يبقى عبر الجلسات والمستخدمين (مختلف عن حقن المطالبة غير المباشرة ذات اللقطة الواحدة، التي يملكها hunt-llm-ai)، IDOR لقاعدة بيانات المتجهات عبر المستأجرين (استعلامات غير موثقة أو غير محددة النطاق ضد Pinecone/Weaviate/Chroma/Milvus/Qdrant/pgvector)، تسرب النص الأصلي/البيانات الوصفية في نتائج البحث المتشابه، واختطاف الاسترجاع عبر تقارب التضمين العدائي ('تسميم SEO' للـ RAG). الأهداف: أي تطبيق يمتلك قاعدة معرفة مشتركة، أو رفع مستندات تغذي روبوت محادثة، أو منفذ قاعدة بيانات متجهات يمكن الوصول إليه مباشرة. التحقق: يجب أن ترث جلسة/حساب نظيف ثانية النتيجة المسمومة، أو يجب أن يكون عنصر عبر المستأجرين قابلاً للتحقق بشكل مستقل — التخيل ليس اكتشافًا، نفس المستوى كـ hunt-llm-ai. الاستخدام عندما يكون الهدف مدعومًا بـ RAG، أو يكشف عن منفذ قاعدة بيانات متجهات، أو يسمح للمستخدمين برفع مستندات تسترجعها استعلامات مستخدمين آخرين لاحقًا.
