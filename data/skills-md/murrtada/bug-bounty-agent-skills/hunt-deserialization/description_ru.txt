Поиск уязвимых десериализаций — цепочки гаджетов Java (ysoserial), инъекция объектов PHP (phpggc), RCE через Python pickle, .NET BinaryFormatter, Ruby Marshal.load, JNDI/Log4Shell. RCE через десериализацию почти всегда критична. Использовать, когда цель работает на Java, PHP‑сериализации, Python pickle, .NET или Ruby on Rails.
