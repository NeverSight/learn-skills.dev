Ищите уязвимости локального включения файлов (LFI), удалённого включения файлов (RFI) и обхода путей — чтение /etc/passwd, отравление логов → удалённое выполнение кода (RCE), RCE через цепочку фильтров PHP (без загрузки), обёртки php://, data://, zip://, phar://, RFI через allow_url_include, обход директорий с чтением/записью/удалением. Охватывает подтверждение OOB/слепого LFI и дисциплину по ложноположительным результатам. Применяйте при поиске уязвимостей включения файлов или обхода путей в любой цели.
