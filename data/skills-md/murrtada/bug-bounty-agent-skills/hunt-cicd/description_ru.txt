Охота за уязвимостями CI/CD‑конвейера — инъекция рабочих процессов GitHub Actions (pull_request_target Pwnrequest + ${{ }}‑в‑оболочку), отравление самохостового runner‑а, злоупотребление политикой доверия OIDC, удалённое выполнение кода через консоль скриптов Jenkins и CVE‑2024‑23897 (чтение файлов), регистрация runner‑token в GitLab CI, утечка файла состояния Terraform, утечка секретов из артефактов/логов, раскрытие переменных окружения конвейера. Применять, когда цель имеет публичную организацию GitHub/GitLab, открытые CI‑дашборды (Jenkins/TeamCity/Drone/Argo) или доступные артефакты/образы сборки.
