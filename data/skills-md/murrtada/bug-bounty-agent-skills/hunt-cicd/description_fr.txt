Recherche de vulnérabilités des pipelines CI/CD — injection de workflow GitHub Actions (pull_request_target Pwnrequest + ${{ }}‑dans‑shell), empoisonnement de runner auto‑hébergé, abus de politique de confiance OIDC, RCE via la console de script Jenkins et lecture de fichier CVE-2024-23897, enregistrement de jeton de runner GitLab CI, fuite du fichier d’état Terraform, fuite de secrets dans les artefacts/journaux, divulgation de variables d’environnement du pipeline. À utiliser lorsque la cible possède une organisation publique GitHub/GitLab, des tableaux de bord CI exposés (Jenkins/TeamCity/Drone/Argo), ou que les artefacts/images de construction sont accessibles.
