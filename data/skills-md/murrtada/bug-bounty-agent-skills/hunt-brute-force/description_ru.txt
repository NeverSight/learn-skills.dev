Поиск отсутствующего/слабого ограничения скорости — перебор логина, перебор OTP/2FA (пространство ключей 10⁶), перебор токена сброса пароля, credential stuffing, перечисление имён пользователей/почтовых адресов через строки ошибок / коды статуса / различия во времени, слабая политика паролей, отсутствие CAPTCHA (повторное использование токена CAPTCHA / одноразовое использование / обход окна конкуренции → hunt-captcha-bypass), обход ограничения по IP через X-Forwarded-For и прочие заголовки, ReDoS. Различает жёсткую блокировку, мягкое ограничение по IP, внедрение CAPTCHA и тихое «теневое» ограничение (избегает ложно‑отрицательных выводов «нет ограничения скорости»). Уровень от среднего до критического в зависимости от того, до чего дошёл перебор (OTP → ATO = Критично).
