レートリミットの欠如／弱さを検出 — ログイン総当たり、OTP/2FA総当たり（10^6 キースペース）、パスワードリセットトークン総当たり、資格情報詰め込み、エラーメッセージ／ステータスコード／タイミング差異によるユーザー名・メールアドレス列挙、弱いパスワードポリシー、CAPTCHA 未実装（CAPTCHA トークンのリプレイ／単一使用／同時ウィンドウバイパスの詳細 → hunt-captcha-bypass）、X‑Forwarded‑For などを利用した IP ベースのレートリミット回避、ReDoS。ハードロックアウト、ソフト IP スロットリング、CAPTCHA 注入、サイレントシャドウスロットリングを区別し（「レートリミットなし」の誤判定を防止）。ブート対象に応じて中程度から重大（OTP→ATO は重大）となる。
