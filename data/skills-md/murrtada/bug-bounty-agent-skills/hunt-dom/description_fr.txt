Chassez les vulnérabilités DOM côté client — DOM Clobbering (écrasement des globaux JS via injection HTML), détournement de PostMessage (absence de vérification de l’origine), abus de Service Worker (interception des requêtes d’un script même origine), injection/exfiltration CSS (sélecteurs d’attributs → token caractère par caractère via OOB), injection de modèles côté client, dangerouslySetInnerHTML. Fondé sur des recherches publiques nommées : Gareth Heyes / PortSwigger DOM‑clobbering + DOM‑Invader, Michał Bentkowski contournements de DOMPurify clobbering, XSS htmlPrefilter de jQuery (CVE‑2020‑11022 / CVE‑2020‑11023), recherche d0nut sur l’exfiltration CSS. Utilisez‑le lors de la chasse au DOM‑XSS, au contournement d’authentification côté client, ou à l’exfiltration de tokens sans interaction serveur.
