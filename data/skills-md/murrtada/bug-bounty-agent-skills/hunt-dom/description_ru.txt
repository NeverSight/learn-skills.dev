Ищите уязвимости на клиентской стороне DOM — DOM‑clobbering (перезапись глобальных переменных JS через HTML‑инъекцию), hijacking PostMessage (отсутствие проверки origin), злоупотребление Service Worker (перехват запросов скриптом того же происхождения), инъекция/выкачивание CSS (атрибутные селекторы → побайтовый вывод токена через OOB), инъекция шаблонов на клиенте, dangerouslySetInnerHTML. Основано на известных публичных исследованиях: Gareth Heyes / PortSwigger DOM‑clobbering + DOM‑Invader, Michał Bentkowski обходы clobbering в DOMPurify, XSS в jQuery htmlPrefilter (CVE‑2020‑11022 / CVE‑2020‑11023), исследование d0nut по CSS‑exfil. Используйте при поиске DOM‑XSS, обходе аутентификации на клиенте или выкачивании токенов без взаимодействия с сервером.
