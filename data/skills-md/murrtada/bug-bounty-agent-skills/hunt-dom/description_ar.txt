ابحث عن ثغرات DOM على جانب العميل — DOM Clobbering (استبدال المتغيرات العامة في JavaScript عبر حقن HTML)، اختطاف PostMessage (غياب فحص الأصل)، إساءة استخدام Service Worker (اعتراض الطلبات من سكريبت نفس الأصل)، حقن/استخراج CSS (محدّدات السمات → استخراج الرمز حرفًا بحرف عبر OOB)، حقن القوالب على جانب العميل، dangerouslySetInnerHTML. مستند إلى أبحاث عامة مسماة: Gareth Heyes / PortSwigger DOM‑clobbering + DOM‑Invader، Michał Bentkowski تجاوزات DOMPurify clobbering، jQuery htmlPrefilter XSS (CVE‑2020‑11022 / CVE‑2020‑11023)، بحث d0nut حول استخراج CSS. استخدم ذلك عند البحث عن DOM‑XSS، تجاوز المصادقة على جانب العميل، أو استخراج الرموز دون تفاعل من جانب الخادم.
