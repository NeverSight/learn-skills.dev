クライアントサイドの DOM 脆弱性を狩る — DOM クロバリング（HTML インジェクションで JS グローバル変数を書き換える）、PostMessage ハイジャック（オリジンチェックが無い）、Service Worker の悪用（同一オリジンのスクリプトからリクエストをインターセプト）、CSS インジェクション／エクスフィルトレーション（属性セレクタ → OOB でトークン文字を 1 文字ずつ取得）、クライアントサイドテンプレートインジェクション、dangerouslySetInnerHTML。以下の公的研究に基づく：Gareth Heyes / PortSwigger の DOM‑clobbering と DOM‑Invader、Michał Bentkowski の DOMPurify クロバリングバイパス、jQuery htmlPrefilter XSS（CVE‑2020‑11022 / CVE‑2020‑11023）、d0nut の CSS‑exfil 研究。DOM‑XSS、クライアントサイド認証バイパス、サーバー側とやり取りせずにトークンをエクスフィルトレートする際に使用する。
