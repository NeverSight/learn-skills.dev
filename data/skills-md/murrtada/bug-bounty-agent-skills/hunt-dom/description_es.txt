Busca vulnerabilidades del DOM del lado del cliente — DOM Clobbering (sobrescribir variables globales de JS mediante inyección HTML), secuestro de PostMessage (falta de verificación de origen), abuso de Service Worker (interceptar solicitudes de scripts del mismo origen), inyección/exfiltración de CSS (selectores de atributos → token carácter por carácter mediante OOB), inyección de plantillas del lado del cliente, dangerouslySetInnerHTML. Basado en investigaciones públicas con nombre: Gareth Heyes / PortSwigger DOM-clobbering + DOM-Invader, Michał Bentkowski omisiones de bypass en DOMPurify, XSS en jQuery htmlPrefilter (CVE‑2020‑11022 / CVE‑2020‑11023), investigación d0nut sobre exfiltración de CSS. Úsalo al buscar DOM‑XSS, evasión de autenticación del lado del cliente o exfiltración de tokens sin interacción del servidor.
