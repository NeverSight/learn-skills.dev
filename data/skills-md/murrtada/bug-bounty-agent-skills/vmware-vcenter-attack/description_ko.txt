VMware vSphere / vCenter Server 외부 공격 매트릭스 — 버전 지문 확인, 고위험 CVE 체인(CVE-2021-21972 vRealize 인증되지 않은 파일 업로드, CVE-2021-21985 vSAN 플러그인 RCE, CVE-2022-22954 Workspace ONE SSTI, CVE-2023-20887 Aria RCE, CVE-2024-37085 ESXi AD 우회, CVE-2023-34048 vCenter DCERPC OOB 쓰기 APT 이용), 기본 자격 증명, SSO 구성 노출, vmdir LDAP 열거, ESXi Open SLP RCE 이력. 인터넷에 노출된 vCenter / Workspace ONE / Aria 인스턴스에만 적용 — 내부 네트워크 vCenter는 외부 전용 경계에 따라 범위 제외. 포트 443에 vCenter 배너, `/ui` 리다이렉트, `/websso/SAML2/Metadata` 또는 VMware 제품 지문이 확인될 때 사용.
