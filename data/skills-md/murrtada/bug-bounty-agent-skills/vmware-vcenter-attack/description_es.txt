Matriz de ataque externo para VMware vSphere / vCenter Server — identificación de versión, cadena de CVE de alto impacto (CVE-2021-21972 carga no autorizada de archivos en vRealize, CVE-2021-21985 ejecución remota de código en plugin vSAN, CVE-2022-22954 SSTI en Workspace ONE, CVE-2023-20887 RCE en Aria, CVE-2024-37085 bypass de AD en ESXi, CVE-2023-34048 escritura OOB en DCERPC de vCenter explotada por APT), credenciales predeterminadas, divulgación de configuración SSO, enumeración LDAP de vmdir, historial de RCE Open SLP en ESXi. SOLO para instancias de vCenter / Workspace ONE / Aria expuestas a Internet — vCenter de red interna está fuera de alcance según el límite solo externo. Utilizar cuando el reconocimiento muestre el puerto 443 con banner de vCenter, redirección `/ui`, `/websso/SAML2/Metadata` o huellas de productos VMware.
