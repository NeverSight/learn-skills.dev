Matrice d'attaque externe VMware vSphere / vCenter Server — empreinte de version, chaîne de CVE à fort impact (CVE‑2021‑21972 téléchargement de fichier non autorisé dans vRealize, CVE‑2021‑21985 exécution de code à distance via le plugin vSAN, CVE‑2022‑22954 SSTI dans Workspace ONE, CVE‑2023‑20887 exécution de code à distance Aria, CVE‑2024‑37085 contournement AD d’ESXi, CVE‑2023‑34048 écriture hors limites DCERPC de vCenter exploité par APT), identifiants par défaut, divulgation de la configuration SSO, énumération LDAP vmdir, historique d’exécution de code à distance SLP ouvert d’ESXi. UNIQUEMENT pour les instances vCenter / Workspace ONE / Aria exposées à Internet — le vCenter du réseau interne est hors du périmètre selon la limite « external‑only ». Utilisez lorsque la reconnaissance montre le port 443 avec bannière vCenter, redirection `/ui`, `/websso/SAML2/Metadata`, ou des empreintes de produits VMware.
