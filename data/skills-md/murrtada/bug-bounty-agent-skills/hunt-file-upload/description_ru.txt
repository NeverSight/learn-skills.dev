Ищем уязвимости загрузки файлов — удалённое выполнение кода через веб‑оболочку, XSS через SVG/HTML, SSRF через XXE в DOCX, обход путей через имя файла. Таблица обходов (10 техник): двойное расширение (shell.php.jpg, если сервер проверяет только последнее расширение), подмена магических байтов (заголовок PNG у PHP‑скрипта), нулевой байт (shell.php\0.jpg), регистр (PHP, .Php, .pHP), загрузка .htaccess для разрешения выполнения, SVG с < script >, XSS в HTML/SVG, DOCX с внедрённым XXE, ZIP‑Slip (../../../etc/passwd в архиве), полиглот‑файлы. Обнаружение: любые эндпоинты /upload, /avatar, /profile-picture, /attachment, /import. Тест: загрузить PHP/JSP/ASPX‑оболочки, запросить их по прямому URL, проверить ответ. Валидация: реальное выполнение кода (вывод whoami) для RCE; отражённый XSS в URL фотографии профиля. Применять при тестировании функций загрузки файлов, эндпоинтов аватаров/вложений, функций импорта/экспорта, процессоров XML/DOCX/ZIP. Реальные платные примеры.
