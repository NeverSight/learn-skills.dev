Повторно используемый конвейер для обработки writeup’ов баг‑баунти и CVE в библиотеке навыков BB‑OS. Преобразует раскрытые в 2024‑2026 годах отчёты, CVE и рекомендации поставщиков в добавляемые, цитируемые, дедублицированные секции навыков. Используйте в начале новой кампании, когда ландшафт угроз для класса может измениться, после крупного события в экосистеме (волна рекомендаций по Keycloak/Spring/DOMPurify) или каждый раз, когда коллега‑охотник публикует writeup для класса, над которым вы работаете. Дополняет разовые спринты обогащения, делая процесс инжеста повторяемым.
