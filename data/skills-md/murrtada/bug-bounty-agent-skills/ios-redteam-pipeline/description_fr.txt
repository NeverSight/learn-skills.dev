Pipeline red‑team iOS de bout en bout — acquisition d’IPA (extraction depuis l’App Store, TestFlight, sideloading enterprise/ad‑hoc), analyse statique avec class‑dump/Hopper/Ghidra, extraction d’Info.plist + autorisations + secrets du trousseau, mauvaise configuration d’App Transport Security (ATS) + contournement du certificate‑pinning (frida-ios-dump, objection, SSL Kill Switch 2), détournement de schéma d’URL / lien universel, énumération des services exportés, instrumentation runtime avec Frida. Companion du apk‑redteam‑pipeline pour la partie iOS d’un catalogue d’applications mobiles. À utiliser lorsque la cible possède une application iOS (fiche App Store, lien TestFlight, distribution MDM enterprise), lorsqu’une URL d’IPA est hébergée sur un serveur web, ou lorsque le post‑recon mentionne « iOS app » / « mobile app » dans le périmètre accompagné d’un compte développeur Apple.
