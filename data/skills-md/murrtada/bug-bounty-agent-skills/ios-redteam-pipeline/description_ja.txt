エンドツーエンドの iOS レッドチームパイプライン — IPA 取得（App Store からの抽出、TestFlight、エンタープライズ/アドホック サイドロード）、class-dump/Hopper/Ghidra による静的解析、Info.plist + エンタイトルメント + キーチェーンシークレット抽出、App Transport Security (ATS) の設定ミス + 証明書ピンニング回避（frida-ios-dump、objection、SSL Kill Switch 2）、URL スキーム / ユニバーサルリンクのハイジャック、エクスポートされたサービスの列挙、Frida ランタイム計装。モバイルアプリカタログの iOS 側に対応した apk-redteam-pipeline のコンパニオン。対象に iOS アプリ（App Store の掲載、TestFlight リンク、エンタープライズ MDM 配布）がある場合、Web サーバー上で IPA URL が見つかった場合、または事後リコンで「iOS アプリ」／「モバイルアプリ」がスコープに含まれ、Apple デベロッパーアカウントが言及されている場合に使用。
