Tubería de red team de iOS de extremo a extremo — adquisición de IPA (extracción de App Store, TestFlight, carga lateral enterprise/ad‑hoc), análisis estático con class‑dump/Hopper/Ghidra, extracción de Info.plist + permisos + secretos del Keychain, configuración incorrecta de App Transport Security (ATS) + elusión de certificate‑pinning (frida‑ios‑dump, objection, SSL Kill Switch 2), secuestro de URL scheme / Universal Link, enumeración de servicios exportados, instrumentación en tiempo de ejecución con Frida. Complementario a apk‑redteam‑pipeline para el lado iOS de un catálogo de aplicaciones móviles. Úsese cuando el objetivo tiene una aplicación iOS (listado en App Store, enlace TestFlight, distribución enterprise MDM), cuando se encuentra una URL de IPA alojada en un servidor web, o cuando el post‑recon menciona "aplicación iOS" / "aplicación móvil" dentro del alcance junto a una cuenta de desarrollador de Apple.
