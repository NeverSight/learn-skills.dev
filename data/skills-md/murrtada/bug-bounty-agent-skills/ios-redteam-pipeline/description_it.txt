Pipeline red‑team iOS end‑to‑end — acquisizione IPA (estrazione dallo Store, TestFlight, distribuzione enterprise/ad‑hoc), analisi statica con class‑dump/Hopper/Ghidra, estrazione di Info.plist + entitlement + segreti del Keychain, configurazione errata di App Transport Security (ATS) + bypass del certificate‑pinning (frida-ios-dump, objection, SSL Kill Switch 2), hijack di URL‑scheme / Universal Link, enumerazione di servizi esportati, strumentazione runtime con Frida. Compagno del apk‑redteam‑pipeline per la parte iOS di un catalogo di app mobili. Da usare quando il bersaglio possiede un’app iOS (listing su App Store, link TestFlight, distribuzione MDM enterprise), quando viene trovata un’URL IPA ospitata su un server web, o quando nella ricognizione post‑operativa viene citata “iOS app” / “mobile app” nel perimetro insieme a un account sviluppatore Apple.
