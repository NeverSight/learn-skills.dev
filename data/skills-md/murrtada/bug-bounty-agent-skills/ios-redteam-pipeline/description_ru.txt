Полный конвейер для iOS red‑team — получение IPA (извлечение из App Store, TestFlight, enterprise/ad‑hoc sideload), статический анализ с помощью class‑dump/Hopper/Ghidra, извлечение Info.plist + entitlements + секретов из Keychain, неправильная настройка App Transport Security (ATS) + обход привязки сертификатов (frida-ios-dump, objection, SSL Kill Switch 2), перехват URL‑scheme / Universal Link, перечисление экспортированных сервисов, инструментация во время выполнения с Frida. Партнёрский модуль к apk‑redteam‑pipeline для iOS‑части каталога мобильных приложений. Применяется, когда у цели есть iOS‑приложение (листинг в App Store, ссылка TestFlight, распределение через enterprise MDM), когда найден URL IPA, размещённый на веб‑сервере, или когда после разведки в области охвата упоминаются «iOS app» / «mobile app» вместе с учётной записью разработчика Apple.
