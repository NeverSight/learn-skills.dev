Cerca vulnerabilità specifiche di Next.js — esecuzione arbitraria di funzioni tramite Server Actions, bypass dell'autenticazione del Middleware tramite percorsi di asset statici, avvelenamento della cache ISR, SSRF di Image Optimization (/_next/image), perdita di payload RSC, iniezione di getServerSideProps, esposizione della source map, perdita dell'endpoint di debug. Da usare quando il target esegue Next.js 13/14/15 o qualsiasi framework React SSR.
