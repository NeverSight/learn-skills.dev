ابحث عن الثغرات الخاصة بـ Next.js — تنفيذ وظائف عشوائية عبر إجراءات الخادم، تجاوز المصادقة في Middleware عبر مسارات الأصول الثابتة، تسميم ذاكرة التخزين المؤقت ISR، هجوم SSRF على تحسين الصور (/_next/image)، تسريب حمولة RSC، حقن getServerSideProps، كشف خريطة المصدر، تسريب نقطة النهاية للتصحيح. استخدم ذلك عندما يكون الهدف يعمل بـ Next.js 13/14/15 أو أي إطار عمل React للعرض من جانب الخادم.
