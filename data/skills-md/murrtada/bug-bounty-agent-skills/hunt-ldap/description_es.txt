Cubre el conjunto de caracteres especiales de LDAP (* ( ) \ NUL /), contexto de filtro de búsqueda vs inyección DN, balanceo de paréntesis, lógica de filtros AND/OR y exfiltración de userPassword {SSHA}/{CRYPT} en directorios que no son AD. Úsese cuando el objetivo utiliza autenticación LDAP/AD, SSO corporativo con backend de directorio, una API de libreta de direcciones/búsqueda de personas, o almacenes de datos basados en XML consultados con XPath.
