Recherche d'injection LDAP et d'injection XPath — contournement d'authentification, exfiltration aveugle d'attributs caractère par caractère, énumération d'utilisateurs/groupes AD, contournement XPath sur magasin XML. Couvre le jeu de caractères spéciaux LDAP (* ( ) \ NUL /), le contexte de filtre de recherche vs injection DN, l'équilibrage des parenthèses, la logique de filtre AND/OR, et l'exfiltration de userPassword {SSHA}/{CRYPT} sur les annuaires non-AD. À utiliser lorsque la cible utilise l'authentification LDAP/AD, le SSO d'entreprise avec un backend d'annuaire, une API d'annuaire/recherche de personnes, ou des magasins de données XML interrogés avec XPath.
