Hunt LDAP インジェクションと XPath インジェクション — 認証バイパス、ブラインドな文字単位属性抽出、AD ユーザー/グループ列挙、XML ストアの XPath バイパス。LDAP の特殊文字セット (* ( ) \ NUL /)、検索フィルタコンテキスト vs DN インジェクション、括弧のバランス、AND/OR フィルタロジック、{SSHA}/{CRYPT} userPassword の抽出（非 AD ディレクトリ）をカバー。対象が LDAP/AD 認証、ディレクトリバックエンドを持つ企業 SSO、アドレスブック/人物検索 API、あるいは XPath で問い合わせる XML ベースのデータストアを使用している場合に使用。
