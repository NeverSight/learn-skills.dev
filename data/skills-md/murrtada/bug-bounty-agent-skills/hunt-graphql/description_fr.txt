Compétence de chasse aux vulnérabilités GraphQL. Construite à partir de 12 rapports de bug bounty publics couvrant IDOR via node() / GID, IDOR de mutation incluant les fonctionnalités IA/LLM, IDOR inter‑locataire, SSRF via argument, DoS par regroupement, contournement du coût de requête, injection SQL via argument, autorisation d’objet cassée, contournement d’authentification via mutations non limitées, et exposition de données personnelles due à l’absence d’autorisation au niveau du champ. À utiliser lors de la recherche de vulnérabilités GraphQL sur n’importe quelle cible.
