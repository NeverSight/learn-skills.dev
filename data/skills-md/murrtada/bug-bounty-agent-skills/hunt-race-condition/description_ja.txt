レースコンディション脆弱性を狩るスキル。12件の公開バグバウンティレポートを元に構築され、最新の HTTP/2 単一パケット攻撃事例（James Kettle の DEF CON 2023 「Smashing the State Machine」や、RyotaK / Flatt Security の 2024 年 10,000 件リクエストの初期シーケンス同期拡張）を含む。クーポンの二重利用、ギフトカードの二重支出、MFA‑OTP 検証レース、アカウント作成レース、 faucet／暗号トークンの二重ミント、メール認証レース、投票／アップボートのインフレ、パスワードリセットトークンレース、同時リクエストによるレートリミット回避をカバー。レースコンディション、TOCTOU バグ、タイミングによる MFA バイパスを狩る際に使用。
