Навык охоты на уязвимости условий гонки. Создан на основе 12 публичных отчётов о баг‑баунти, включая современные случаи атак с одним пакетом HTTP/2 (James Kettle, DEF CON 2023 «Smashing the State Machine»; RyotaK / Flatt Security, расширение синхронизации первой последовательности при 10 000 запросов, 2024). Охватывает двойное использование купонов, двойное списание подарочных карт, гонку проверки MFA‑OTP, гонку создания аккаунта, двойную эмиссию токенов faucet/криптовалют, гонку активации email, инфляцию голосов/апвойтов, гонку токена сброса пароля, обход ограничения скорости через одновременные запросы. Используйте при поиске условий гонки, уязвимостей TOCTOU, обхода MFA с помощью тайминга.
