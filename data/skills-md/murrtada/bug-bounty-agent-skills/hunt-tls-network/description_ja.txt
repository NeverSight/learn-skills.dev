TLS/SSL と DNS の設定ミスを検出する — HSTS が欠如している（ダウングレード攻撃）、弱い暗号スイート、期限切れ／無効な証明書、mTLS バイパス、SPF/DKIM/DMARC が欠如している（メールなりすまし）、DNS ゾーン転送（AXFR）、ぶら下がり CNAME のサブドメイン乗っ取り、CAA レコード。これらの多くは単体では Info/Low に分類されるが、このスキルはどの発見が実際に価値があるか（受信箱に届いた証拠付きの偽装可能な DMARC、内部ホストを返す AXFR、ぶら下がり CNAME の乗っ取り）と、ベストプラクティス上のノイズとして除外されるか（CAA が欠如、MitM ポジションがない状態での HSTS 欠如）について主観的に判断する。リコン中にインフラの弱点を見つけ、報告前に正直に TRIAGE（優先順位付け）するために使用する。
