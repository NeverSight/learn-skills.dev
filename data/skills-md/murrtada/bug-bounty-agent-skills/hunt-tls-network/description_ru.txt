Ищите уязвимости в TLS/SSL и DNS — отсутствие HSTS (атака отката), слабые наборы шифров, просроченные/недействительные сертификаты, обход mTLS, отсутствие SPF/DKIM/DMARC (подделка электронной почты), передача зоны DNS (AXFR), возможность захвата поддомена через «dangling CNAME», записи CAA. Большую часть из этого можно отнести к категории Инфо/Низкого уровня — этот навык склонен оценивать, какие находки действительно приносят прибыль (подделываемый DMARC с доказательством доставки в почтовый ящик, AXFR, возвращающий внутренние хосты, захват «dangling CNAME»), а какие отклоняются как шум лучших практик (отсутствие CAA, отсутствие HSTS без позиции MitM). Используйте во время разведки для обнаружения слабых мест инфраструктуры и честно ТРИАЖ их перед отчётом.
