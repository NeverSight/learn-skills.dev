Compagnon de l'outillage local pour l’orchestrateur de bug‑bounty — il conserve le même flux de travail complet de bug‑bounty, mais utilisez cette variante lorsque vous devez également savoir où les outils, les listes de mots et les clones sont installés sur la machine locale (jhaddix, SecLists, trufflehog, ffuf, dalfox, ghauri) ; pour un simple orchestration/routage, utilisez la compétence bug‑bounty. Flux de travail couvert — recon (énumération de sous‑domaines, découverte d’actifs, empreinte digitale, périmètre HackerOne, audit de code source), apprentissage pré‑chasse (rapports divulgués, recherche de stack technologique, cartes mentales, modélisation des menaces), chasse aux vulnérabilités (IDOR, SSRF, XSS, contournement d’authentification, CSRF, conditions de course, injection SQL, XXE, téléchargement de fichiers, logique métier, GraphQL, smuggling HTTP, empoisonnement de cache, OAuth, canaux latéraux temporels, OIDC, SSTI, prise de contrôle de sous‑domaine, mauvaise configuration cloud, chaînes ATO, IA agentique), tests de sécurité LLM/IA (IDOR de chatbot, injection de prompt, injection indirecte, smuggling ASCII, canaux d’exfiltration, exécution de code via outils, extraction de prompt système, ASI01‑ASI10), chaînage de bugs A‑à‑B (IDOR→contournement d’auth, SSRF→métadonnées cloud, XSS→ATO, redirection ouverte→vol OAuth, S3→bundle→secret→OAuth), tableaux de contournement (contournement IP SSRF, contournement redirection ouverte, contournement téléchargement de fichiers), grep spécifique au langage (pollution de prototype JS, pickle Python, jonglage de types PHP, Go template.HTML, Ruby YAML.load, Rust unwrap), et reporting (Portail 7 questions, 4 portes de validation, rédaction à ton humain, modèles par classe de vulnérabilité, CVSS 3.1, génération de PoC, liste toujours rejetée, tableau de chaînes conditionnelles, checklist de soumission). Utilisez‑le lorsque vous avez besoin du chemin d’installation local d’un outil / d’une liste de mots / d’un clone pour une chasse, ou comme variante à flux complet lorsqu’on travaille depuis cet ensemble d’outils local ; pour le routage général, utilisez la compétence bug‑bounty. Mots‑déclencheurs en chinois : récompense de bug, test de sécurité, test d’intrusion, recherche de vulnérabilité, collecte d’informations, énumération de sous‑domaines, test XSS, injection SQL, SSRF, audit de sécurité, rapport de vulnérabilité
