Формат отчёта red‑team, ориентированный на клиента — фиксирует структуру «Тема / Наблюдения / Описание / Воздействие / Рекомендации / Доказательство концепции», используемую во внешних red‑team заданиях (не в отчётах платформ bug‑bounty). Другие аудитория, иной тон, иной ритм. Создан на основе авторизованного результата проекта, где 14 обнаружений были упакованы в MD‑файл размером 52 KB и DOCX‑файл 2,2 MB с 16 встроенными скриншотами. Применять, когда задание — «внешний red‑team для корпоративного клиента» (не H1/Bugcrowd/Intigriti), при формировании окончательного отчёта, когда клиент задаёт собственный формат отчёта или при упаковке находок в DOCX/PDF.
