Format de livrable red‑team orienté client — codifie la structure Sujet / Observations / Description / Impact / Recommandation / PoC utilisée pour les missions red‑team externes (pas les rapports de plateformes de bug‑bounty). Public différent, ton différent, cadence différente. Construit à partir d’un livrable d’engagement autorisé où 14 constatations ont été regroupées dans un MD de 52 KB + un DOCX de 2,2 MB avec 16 captures d’écran intégrées. À utiliser lorsque l’engagement est « red‑team externe pour un client d’entreprise » (pas H1/Bugcrowd/Intigriti), lors de la génération du rapport final, lorsque le client a spécifié un format de rapport personnalisé, ou lors de l’empaquetage des constatations en DOCX/PDF.
