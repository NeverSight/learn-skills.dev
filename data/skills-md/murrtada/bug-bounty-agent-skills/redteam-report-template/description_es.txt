Formato de entrega de red team orientado al cliente — codifica la estructura Asunto / Observaciones / Descripción / Impacto / Recomendación / PoC utilizada para compromisos de red team externos (no informes de plataformas de bug bounty). Audiencia diferente, tono diferente, ritmo diferente. Creado a partir de una entrega autorizada de compromiso donde 14 hallazgos se empaquetaron en un MD de 52 KB + un DOCX de 2,2 MB con 16 capturas de pantalla incrustadas. Úselo cuando el compromiso sea “red team externo para un cliente empresarial” (no H1/Bugcrowd/Intigriti), al generar el informe final, cuando el cliente haya especificado un formato de informe personalizado, o al empaquetar los hallazgos en DOCX/PDF.
