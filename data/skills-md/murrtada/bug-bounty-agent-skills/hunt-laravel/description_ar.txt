اكتشاف الثغرات الخاصة بـ Laravel — تسرب وضع التصحيح (APP_DEBUG=true يكشف عن تتبع الأخطاء الكامل + متغيرات البيئة)، وصول غير مصرح به إلى لوحة Laravel Telescope/Horizon، تنفيذ تعليمات برمجية عن بُعد عبر Ignition (CVE-2021-3129)، التلاعب بروابط URL الموقعة، إساءة استخدام عامل الصفّ (Queue Worker)، التعيين الجماعي عبر Eloquent، فك التسلسل عبر ملفات تعريف الارتباط، كشف ملف .env. استخدم عندما يكون الهدف يُشغل Laravel (PHP) — يتم الكشف عنه عبر X-Powered-By، ملفات تعريف جلسة Laravel، أو مسارات /storage/. يرجى دائمًا الرد بلغة المستخدم.
