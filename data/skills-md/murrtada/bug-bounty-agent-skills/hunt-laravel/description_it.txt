Cerca vulnerabilità specifiche di Laravel — perdita di informazioni in modalità debug (APP_DEBUG=true espone stack trace completo + variabili d'ambiente), accesso non autorizzato al dashboard di Laravel Telescope/Horizon, RCE di Ignition (CVE-2021-3129), manipolazione di URL firmati, abuso del Queue Worker, mass assignment tramite Eloquent, deserializzazione tramite cookie, esposizione del file .env. Usa quando il bersaglio esegue Laravel (PHP) — rilevato tramite X-Powered-By, cookie di sessione Laravel o percorsi /storage/.
