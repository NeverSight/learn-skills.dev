Okta を IdP としたレッドチーム攻撃チェーン — テナント探索、ユーザー列挙（複数ベクトル）、認証フロー分析（要素列挙、プッシュ通知疲労、SMS バイパス）、ロックアウトポリシーを伴うパスワードスプレー、Okta 固有のフィッシング手法（キット、FastPass 悪用、OIDC redirect_uri 改ざん）、MFA 列挙、侵害後の管理 API 表面。多くのエンタープライズ組織は Entra ID の代わりに（または併用して）Okta を使用している。エンドポイント、レートリミット、要素フローはすべて異なる。リコンで `<tenant>.okta.com`、`<tenant>.okta-emea.com`、`<tenant>.oktapreview.com`、または Okta IdP を指す autodiscover 形式のレコードが見つかった場合に使用する。
