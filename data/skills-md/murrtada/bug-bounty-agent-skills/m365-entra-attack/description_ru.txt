Microsoft 365 / Entra ID цепочка атак red‑team — текущая реальность 2026 года. Ссылка на код AADSTS, векторы перечисления пользователей (со статусом ужесточения), расчёты Smart Lockout, варианты обхода Conditional Access, поток браузера ROPC + SAML SSO, шаблоны Burp/Playwright. Создано на основе авторизованной работы red‑team, где спрей ROPC выявил уже существующие блокировки и учетные данные, заблокированные CA, плюс корреляция активности внешних атакующих в реальном времени. Используйте для любой атаки на учётные данные M365/Entra, спрея паролей, перечисления пользователей, исследования обхода CA или сценария обнаружения активного атакующего.
