Cadena de ataque de red‑team para Microsoft 365 / Entra ID — realidad actual 2026. Referencia de códigos AADSTS, vectores de enumeración de usuarios (con estado de endurecimiento), cálculo de Smart Lockout, opciones de elusión de Conditional Access, flujo de navegador ROPC + SAML SSO, plantillas Burp/Playwright. Construido a partir de trabajo autorizado de red‑team donde el spray ROPC expuso bloqueos preexistentes y credenciales bloqueadas por CA, además de correlación en tiempo real de actividad de atacantes externos. Úsalo para cualquier ataque de credenciales M365/Entra, spray de contraseñas, enumeración de usuarios, exploración de elusión de CA o escenario de detección de atacante activo.
