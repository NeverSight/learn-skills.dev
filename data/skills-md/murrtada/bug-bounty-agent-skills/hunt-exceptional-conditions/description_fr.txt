Repérer la mauvaise gestion des conditions exceptionnelles — fournir à un point de terminaison des entrées malformées ou inattendues (type incorrect, JSON corrompu, champ surdimensionné, octet nul) et le faire échouer OPEN ou divulguer des informations internes : une trace de pile détaillée / page d’erreur du framework qui révèle les détails de l’ORM, les chemins de fichiers du serveur, les versions des bibliothèques, ou une trace d’erreur du langage. Utiliser sur tout point de terminaison acceptant des entrées (API JSON, formulaires, paramètres de requête).
