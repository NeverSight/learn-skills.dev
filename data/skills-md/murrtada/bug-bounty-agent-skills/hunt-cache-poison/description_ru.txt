Навык охоты на уязвимости кеш‑отравления. Построен на основе 10 публичных баг‑баунти отчётов, включая отравление X-Forwarded-Host, X-HTTP-Method-Override / кеш GCS, отражённый → записанный XSS через кеш, классический Omer‑Gil Web Cache Deception, обход Cloudflare Cache Deception Armor, обман кеша токеном сессии, smuggling hop‑by‑hop в Akamai → серверное отравление edge, и WCD нормализации пути 2024 года от Kettle против Cloudflare/Fastly/GCP. Инъекция Host/X-Forwarded-Host, достигающая логики приложения (отравление ссылки сброса пароля, маршрутизация SSRF, издатель OAuth), принадлежит hunt‑host‑header; этот навык охватывает случай, когда отравленный ответ ЗАКЕШИРОВАН и обслуживается другим пользователям. Используйте при поиске кеш‑отравления, Web Cache Deception, приложений за CDN.
