Habilidad de búsqueda para vulnerabilidades de envenenamiento de caché. Construida a partir de 10 informes públicos de recompensas por bugs, incluyendo envenenamiento X-Forwarded-Host, X-HTTP-Method-Override / caché GCS, XSS reflejado→almacenado vía caché, la clásica Web Cache Deception de Omer‑Gil, bypass de Cloudflare Cache Deception Armor, engaño de caché de token de sesión, smuggling hop‑by‑hop de Akamai → envenenamiento de borde del lado del servidor, y la normalización de rutas WCD 2024 de Kettle contra Cloudflare/Fastly/GCP. La inyección Host/X-Forwarded-Host que llega a la lógica de la aplicación (envenenamiento de enlace de restablecimiento, SSRF de enrutamiento, emisor OAuth) pertenece a hunt‑host‑header; esta habilidad cubre el caso en que la respuesta envenenada está CACHEADA y se sirve a otros usuarios. Úsala al buscar envenenamiento de caché, Web Cache Deception, aplicaciones fronted por CDN.
