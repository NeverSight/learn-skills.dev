キャッシュポイズン脆弱性を対象としたハンティングスキル。X-Forwarded-Host ポイズニング、X-HTTP-Method-Override / GCS キャッシュ、キャッシュ経由の reflected→stored XSS、古典的な Omer‑Gil Web Cache Deception、Cloudflare Cache Deception Armor バイパス、セッショントークン キャッシュデセプション、Akamai の hop-by-hop スマグリング → サーバー側エッジポイズニング、そして Kettle の 2024 年のパス正規化 WCD（Cloudflare/Fastly/GCP 向け）など、10 件の公開バグバウンティレポートを元に構築されています。アプリロジックに到達する Host/X-Forwarded-Host インジェクション（リセットリンクポイズニング、ルーティング SSRF、OAuth 発行者など）は hunt-host-header が担当し、本スキルは、汚染されたレスポンスがキャッシュされ、他のユーザーに提供されるケースを扱います。キャッシュポイズニング、Web Cache Deception、CDN フロントのアプリをハンティングする際に使用してください。
