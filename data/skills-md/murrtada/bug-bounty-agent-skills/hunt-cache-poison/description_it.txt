Abilità di hunting per vulnerabilità di avvelenamento della cache. Costruita a partire da 10 report pubblici di bug bounty, tra cui avvelenamento X-Forwarded-Host, X-HTTP-Method-Override / cache GCS, XSS riflesso→memorizzato tramite cache, classico Web Cache Deception di Omer‑Gil, bypass di Cloudflare Cache Deception Armor, inganno della cache con token di sessione, smuggling hop‑by‑hop di Akamai → avvelenamento edge lato server, e il WCD di normalizzazione del percorso 2024 di Kettle contro Cloudflare/Fastly/GCP. L'iniezione Host/X-Forwarded-Host che raggiunge la logica dell'app (avvelenamento reset‑link, SSRF di routing, emittente OAuth) è gestita da hunt‑host‑header; questa abilità gestisce il caso in cui la risposta avvelenata è CACHEATA e viene servita ad altri utenti. Da usare quando si cerca avvelenamento della cache, Web Cache Deception, applicazioni frontate da CDN.
