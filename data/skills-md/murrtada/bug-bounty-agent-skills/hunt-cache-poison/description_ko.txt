캐시 포이즌 취약점을 탐색하기 위한 스킬. X-Forwarded-Host 포이즌, X-HTTP-Method-Override / GCS 캐시, 캐시를 통한 반사→저장 XSS, 고전적인 Omer‑Gil 웹 캐시 속임수, Cloudflare Cache Deception Armor 우회, 세션 토큰 캐시 속임수, Akamai 홉‑바이‑홉 스머글링 → 서버‑사이드 엣지 포이즌, 그리고 Kettle의 2024 경로 정규화 WCD (Cloudflare/Fastly/GCP 대상) 등을 포함한 10개의 공개 버그 바운티 보고서에서 구축됨. 애플리케이션 로직에 도달하는 Host/X-Forwarded-Host 인젝션(리셋 링크 포이즌, 라우팅 SSRF, OAuth 발급자)은 hunt‑host‑header가 담당하고; 이 스킬은 오염된 응답이 캐시되어 다른 사용자에게 제공되는 경우를 담당함. 캐시 포이즌, 웹 캐시 속임수, CDN‑프론트 앱을 탐색할 때 사용.
