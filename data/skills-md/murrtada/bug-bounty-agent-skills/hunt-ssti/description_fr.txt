Recherche d’injection de template côté serveur (SSTI) sur Jinja2 (Flask/Django), Twig (Symfony), Freemarker (Java), ERB (Rails), Spring, Velocity, Mako, Thymeleaf, Smarty. Les sondes de détection utilisent des expressions mathématiques entre doubles accolades ou accolade-dollar évaluées côté serveur. Une fois le moteur identifié, escalader vers une exécution de code (RCE) via le class‑walker spécifique au moteur, le callback‑registrar ou les modèles d’utilitaire Execute documentés dans les rapports divulgués. Modèles de détection : les messages d’erreur révèlent le moteur, une évaluation vide ou numérique indique le mode d’expression. Cibles : modèles d’e‑mail, générateurs de PDF/rapports, fonctions d’aperçu de CMS, pages d’erreur contenant des entrées utilisateur. Utiliser lors de la chasse à la RCE via le rendu de templates, lorsque le contenu montre des empreintes du moteur, ou lorsqu’on trouve des points de terminaison qui composent des chaînes avec des entrées utilisateur avant le rendu.
