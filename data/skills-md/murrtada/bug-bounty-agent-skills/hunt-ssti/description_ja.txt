Jinja2（Flask/Django）、Twig（Symfony）、Freemarker（Java）、ERB（Rails）、Spring、Velocity、Mako、Thymeleaf、Smarty におけるサーバーサイドテンプレートインジェクション（SSTI）を狩る。検知用プローブはサーバー側で評価される二重波括弧 {{ }} およびドル波括弧 ${} の数式を使用する。エンジンが指紋取得できたら、開示されたレポートに記載されたエンジン固有のクラスウォーカー、コールバックレジスター、または Execute ユーティリティパターンを用いて RCE にエスカレートする。検知パターン：エラーメッセージでエンジンが判明する、空文字や数値の評価結果で式モードが判明する。対象：メールテンプレート、PDF/レポート生成機能、CMS のプレビュー機能、ユーザー入力を含むエラーページ。テンプレートレンダリングによる RCE を狩るとき、コンテンツにエンジンの指紋が見えるとき、レンダリング前にユーザー入力で文字列を組み立てるエンドポイントを見つけたときに使用する。
