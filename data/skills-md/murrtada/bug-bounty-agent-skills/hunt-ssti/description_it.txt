Cerca iniezione di template lato server (SSTI) su Jinja2 (Flask/Django), Twig (Symfony), Freemarker (Java), ERB (Rails), Spring, Velocity, Mako, Thymeleaf, Smarty. I probe di rilevamento usano espressioni matematiche con doppie parentesi graffe e parentesi graffa dollaro valutate sul server. Una volta identificato il motore, scala a RCE tramite i pattern specifici del motore come class-walker, callback-registrar o Execute-utility descritti nei report divulgati. Pattern di rilevamento: i messaggi di errore rivelano il motore, una valutazione vuota o numerica indica la modalità espressione. Obiettivi: template email, generatori PDF/report, funzioni di anteprima CMS, pagine di errore con input dell'utente. Usa quando si ricerca RCE tramite rendering di template, quando il contenuto mostra impronte del motore, o quando si trovano endpoint che concatenano stringhe con input dell'utente prima del rendering.
