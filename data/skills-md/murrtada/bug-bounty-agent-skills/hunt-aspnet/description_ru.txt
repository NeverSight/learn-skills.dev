Ищем специфическую поверхность ASP.NET — десериализация ViewState (только подписанная vs зашифрованная), восстановление machineKey, двойной парсер обхода MAC (антипаттерн), обход request‑validator, раскрытие trace.axd/elmah.axd, сбои ViewState в балансировке нагрузки между узлами, перечисление SafeControl через рефлексию, утечки стека при customErrors mode=Off, классическая поверхность Webforms .asmx/.svc/.aspx. Создано для ферм ASP.NET Webforms + WCF + SharePoint.
