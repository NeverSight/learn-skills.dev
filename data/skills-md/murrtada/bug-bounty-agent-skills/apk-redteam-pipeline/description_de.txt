End-to-End Android-APK-Red-Team-Pipeline — automatisierte APK-Beschaffung (Play Store + apkpure + apkmirror als Fallback), jadx-Dekompilierung, Secret/URL/JWT/Firebase‑Durchsuchung, Extraktion von gepinnten Zertifikaten, Aufzählung exportierter Komponenten, Frida‑Runtime‑Instrumentierungs‑Templates, Intent‑Injection‑Proben. Erstellt aus einem autorisierten externen Red-Team‑Engagement, bei dem 7 APKs manuell bezogen, 4 Download‑Versuche abgebrochen und ein hardcodiertes JWT sowie 30 interne API‑Endpunkte aus einer der Apps wiederhergestellt wurden. Verwendung, wenn das Ziel einen Mobile‑App‑Katalog (Play‑Store‑Entwicklerseite) hat, wenn Sie eine APK‑URL auf einem Web‑Server finden oder wenn die Nach‑Recon‑Phase „mobile app“ im Scope erwähnt.
