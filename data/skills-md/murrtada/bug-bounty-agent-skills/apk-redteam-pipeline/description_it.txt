Pipeline red-team end-to-end per APK Android — acquisizione automatizzata di APK (Play Store + apkpure + fallback su apkmirror), decompilazione con jadx, ricerca di segreti/URL/JWT/Firebase, estrazione di certificati pin, enumerazione dei componenti esportati, modelli di strumentazione runtime Frida, probe di iniezione di intent. Realizzata da un incarico red‑team esterno autorizzato in cui sono stati prelevati manualmente 7 APK, 4 tentativi di download interrotti, e un JWT hardcoded + 30 endpoint API interni sono stati recuperati da una delle app. Da utilizzare quando il bersaglio ha un catalogo di app mobili (pagina sviluppatore del Play Store), quando trovi un URL di APK ospitato su un server web, o quando il post‑recon menziona “app mobile” nell’ambito.
