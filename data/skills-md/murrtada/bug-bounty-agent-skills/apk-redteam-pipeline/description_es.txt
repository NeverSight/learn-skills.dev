Pipeline de red team de extremo a extremo para Android APK: adquisición automatizada de APK (fallback a Play Store + apkpure + apkmirror), decompilación con jadx, búsqueda de secretos/URL/JWT/Firebase, extracción de certificado anclado, enumeración de componentes exportados, plantillas de instrumentación en tiempo de ejecución con Frida, pruebas de inyección de intents. Construido a partir de un compromiso externo autorizado de red team donde se extrajeron manualmente 7 APKs, 4 intentos de descarga fueron truncados y se recuperó un JWT codificado y 30 endpoints de API internos de una de las apps. Úsalo cuando el objetivo tenga un catálogo de apps móviles (página de desarrollador de Play Store), cuando encuentres una URL de APK alojada en un servidor web o cuando el post‑recon mencione “app móvil” dentro del alcance.
