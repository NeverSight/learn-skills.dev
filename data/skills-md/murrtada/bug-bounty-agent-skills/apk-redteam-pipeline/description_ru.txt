Полный конвейер red‑team для Android APK — автоматическое получение APK (Play Store + apkpure + резервный apkmirror), декомпиляция с помощью jadx, поиск секретов/URL/JWT/Firebase, извлечение закреплённого сертификата, перечисление экспортированных компонентов, шаблоны инструментации Frida в режиме выполнения, пробники инъекций Intent. Создан на основе авторизованного внешнего red‑team задания, где 7 APK были получены вручную, 4 попытки загрузки прерваны, а из одного из приложений были извлечены жёстко закодированный JWT и 30 внутренних API‑эндпоинтов. Используйте, когда у цели есть каталог мобильных приложений (страница разработчика в Play Store), когда вы находите URL APK, размещённый на веб‑сервере, или когда в итоговом разведывательном докладе указано «мобильное приложение» в области охвата.
