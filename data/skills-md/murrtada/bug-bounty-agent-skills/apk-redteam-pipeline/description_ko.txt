엔드‑투‑엔드 Android APK 레드팀 파이프라인 — 자동 APK 획득(Play Store + apkpure + apkmirror 대체), jadx 디컴파일, secret/URL/JWT/Firebase 탐색, 핀 인증서 추출, 내보낸 컴포넌트 열거, Frida 런타임 계측 템플릿, 인텐트 삽입 프로브. 허가된 외부 레드팀 참여에서 7개의 APK를 수동으로 가져오고, 4번의 다운로드 시도가 중단되었으며, 하나의 앱에서 하드코딩된 JWT와 30개의 내부 API 엔드포인트를 복구함. 대상이 모바일 앱 카탈로그(Play Store 개발자 페이지)를 보유하고 있거나, 웹 서버에 APK URL이 호스팅된 경우, 혹은 사전 조사 후 범위에 “모바일 앱”이 언급될 때 사용.
