Ricognizione esterna per la superficie di attacco della catena di fornitura del software — candidati al furto di namespace dei pacchetti, vulnerabilità di confusione delle dipendenze, aperture di iniezione di GitHub Actions, esposizione del registro delle immagini container, estrazione di SBOM, perdita di nomi di pacchetti interni e esposizione della configurazione CI/CD. Solo ricognizione e identificazione — le reali pubblicazioni di pacchetti / attacchi di typo‑squatting sono OFFENSIVE ESTERNE e richiedono un esplicito consenso scritto perché possono influire sull’intero ecosistema npm/PyPI. Utilizzare quando il bersaglio ha un’organizzazione GitHub pubblica, quando i loro artefatti di build/SBOM sono raggiungibili, quando le loro immagini Docker sono su Docker Hub/GHCR, o quando trovi nomi di pacchetti interni nei loro bundle JS.
