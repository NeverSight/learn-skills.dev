Externe Aufklärung der Angriffsfläche von Software‑Lieferketten – Kandidaten für Package‑Namespace‑Squatting, Dependency‑Confusion‑Schwachstellen, Injection‑Möglichkeiten in GitHub Actions, Exposition von Container‑Image‑Registries, SBOM‑Mining, Leckage interner Paketnamen und Offenlegung von CI/CD‑Konfigurationen. Nur Aufklärung und Identifizierung – tatsächliche Paketerstellung/Typo‑Squatting‑Angriffe sind EXTERN‑OFFENSIV und erfordern eine ausdrückliche schriftliche Genehmigung, da sie das gesamte npm‑/PyPI‑Ökosystem beeinträchtigen können. Verwenden, wenn das Ziel eine öffentliche GitHub‑Organisation hat, wenn deren Build‑Artefakte/SBOMs erreichbar sind, wenn deren Docker‑Images auf Docker Hub/GHCR liegen oder wenn interne Paketnamen in deren JS‑Bundles gefunden werden.
