استطلاع خارجي لسطح هجوم سلسلة توريد البرمجيات — مرشّحات احتلال مساحة أسماء الحزم، ثغرات ارتباك التبعيات، فرص حقن GitHub Actions، كشف سجل صور الحاويات، استخراج SBOM، تسريب أسماء الحزم الداخلية، وكشف تكوين CI/CD. الاستطلاع والتحديد فقط — نشر الحزم الفعلي/هجمات الاختلال المطبعي هي هجمات خارجية هجومية وتتطلب موافقة مكتوبة صريحة لأنها قد تؤثر على كامل نظام npm/PyPI. استخدمها عندما يكون للهدف منظمة عامة على GitHub، عندما تكون قطع البنية/الـ SBOMs الخاصة بهم قابلة للوصول، عندما تكون صور Docker الخاصة بهم على Docker Hub/GHCR، أو عندما تجد أسماء حزم داخلية في حزم JS الخاصة بهم.
