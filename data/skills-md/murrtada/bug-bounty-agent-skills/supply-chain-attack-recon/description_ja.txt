ソフトウェアサプライチェーンの攻撃対象を外部から偵察する — パッケージ名前空間のスクワッティング候補、依存関係混乱（dependency‑confusion）脆弱性、GitHub Actions のインジェクション機会、コンテナイメージレジストリの露出、SBOM のマイニング、内部パッケージ名の漏洩、CI/CD 設定の露出。偵察と特定のみ — 実際のパッケージ公開／タイポスクワット攻撃は外部攻撃であり、npm/PyPI エコシステム全体に影響を及ぼす可能性があるため、明示的な書面による承認が必要です。対象が公開 GitHub 組織を持っている場合、ビルド成果物・SBOM が取得可能な場合、Docker Hub や GHCR に Docker イメージがある場合、または JS バンドル内に内部パッケージ名が見つかった場合に使用してください。
