Reconnaissance externe pour la surface d'attaque de la chaîne d'approvisionnement logicielle — candidats au squat de namespace de paquets, vulnérabilités de confusion de dépendances, ouvertures d’injection GitHub Actions, exposition du registre d’images de conteneurs, extraction de SBOM, fuite de noms de paquets internes, et exposition de la configuration CI/CD. Reconnaissance et identification UNIQUEMENT — les attaques réelles de publication de paquets / typosquat sont EXTERNES-AGRESSIVES et nécessitent une autorisation écrite explicite car elles peuvent affecter l’ensemble de l’écosystème npm/PyPI. À utiliser lorsque la cible possède une organisation GitHub publique, lorsque leurs artefacts de construction/SBOM sont accessibles, lorsque leurs images Docker sont sur Docker Hub/GHCR, ou lorsqu’on découvre des noms de paquets internes dans leurs bundles JS.
