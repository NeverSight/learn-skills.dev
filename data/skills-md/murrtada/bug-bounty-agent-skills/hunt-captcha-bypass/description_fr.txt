Hunt CAPTCHA Bypass — 6 modèles distincts : (1) le champ CAPTCHA simplement omis de la requête (validation côté serveur absente), (2) le jeton CAPTCHA rejoué à partir d’un défi résolu (pas d’obligation d’utilisation unique), (3) la réponse CAPTCHA acceptée sur un point de terminaison différent de celui où elle a été résolue (pas de liaison à l’action ou à la session), (4) valeurs CAPTCHA statiques ou prévisibles acceptées (ex. « 0 », « null », chaîne vide), (5) CAPTCHA audio/accessibilité trivialement solvable programmatiquement, (6) le CAPTCHA n’est appliqué qu’après N échecs (les N premières requêtes le contournent). Détection : intercepter une soumission de formulaire réussie, supprimer totalement le champ CAPTCHA, rejouer — si cela réussit encore, la validation côté serveur est absente. Sévérité moyenne en isolation ; élevée lorsqu’elle supprime la seule barrière de limitation de débit protégeant un point de terminaison de connexion, d’inscription ou de paiement.
