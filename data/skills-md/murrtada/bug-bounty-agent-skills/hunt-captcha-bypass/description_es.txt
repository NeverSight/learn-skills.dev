Hunt CAPTCHA Bypass — 6 patrones distintos: (1) campo CAPTCHA simplemente omitido en la solicitud (validación del lado del servidor ausente), (2) token CAPTCHA reproducido de un desafío resuelto (sin aplicación de uso único), (3) respuesta CAPTCHA aceptada en un endpoint diferente al que se resolvió (sin vinculación a acción/sesión), (4) valores CAPTCHA estáticos o predecibles aceptados (p. ej. “0”, “null”, cadena vacía), (5) CAPTCHA de audio/accesibilidad resoluble trivialmente de forma programática, (6) CAPTCHA impuesto solo después de N fallos (las primeras N solicitudes lo eluden). Detección: interceptar una presentación de formulario exitosa, eliminar el campo CAPTCHA por completo y volver a enviarla; si sigue teniendo éxito, la validación del lado del servidor está ausente. Severidad media como caso aislado; alta cuando elimina la única barrera de limitación de velocidad que protege un endpoint de inicio de sesión, registro o pago.
