Дисциплина захвата доказательств и редактирования PoC для заявок на баг‑баунти: протокол редактирования cookie (какие поля маскировать, аннотация Preview / скрытие панели Burp / процесс в DevTools), дисциплина черных полос PII (что маскировать в данных других пользователей — имена, email, телефоны, лица — и что можно оставить — имена пользователей, trace‑ID, тела запросов), санитизация HAR‑файлов (фильтры jq для заголовков Cookie/Set-Cookie/Authorization), гигиена скриншотов в Burp Repeater/Intruder (скрывать тело запроса, показывать только таблицу Results для атак с ограничением скорости), шаблоны PoC в консоли Chrome DevTools (включать учётные данные, чтобы cookie не отражались, помеченный console.log), порядок захвата скриншотов, конвенции имён файлов, гигиена ротации после отправки. Использовать ДО любого скриншота PoC, ДО прикрепления HAR или каждый раз при подготовке доказательств с сессионными cookie или PII других пользователей. Совмещается с процессом отчётности в Bugcrowd и написанием отчётов.
