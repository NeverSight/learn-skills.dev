Emule un blob de código sin procesar/shellcode en una CPU virtual (x86/x64/ARM/ARM64) con Unicorn e informe el estado final del registro, el recuento de instrucciones y las escrituras en la memoria. Contenidos: los bytes se ejecutan en una CPU emulada, no en el host (solo memoria; no hay llamadas al sistema del host a menos que esté cableado): la forma segura de "ejecutar" código shell o una función aislada.
