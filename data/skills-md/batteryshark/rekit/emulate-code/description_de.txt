Emulieren Sie einen Rohcode-/Shellcode-Blob auf einer virtuellen CPU (x86/x64/arm/arm64) mit Unicorn und melden Sie den endgültigen Registerstatus, die Anzahl der Anweisungen und die Schreibvorgänge im Speicher. Enthalten: Die Bytes laufen auf einer emulierten CPU, nicht auf dem Host (nur Arbeitsspeicher; keine Host-Syscalls, es sei denn, sie sind verkabelt) — der sichere Weg, Shellcode oder eine isolierte Funktion auszuführen.
