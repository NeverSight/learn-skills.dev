Émulez un blob de code brut/shellcode sur un processeur virtuel (x86/x64/ARM/arm64) avec Unicorn et signalez l'état final du registre, le nombre d'instructions et les écritures en mémoire. Contenu : les octets s'exécutent sur un processeur émulé, pas sur l'hôte (mémoire seule ; aucun appel système d'hôte à moins qu'il ne soit câblé) — le moyen sûr d'exécuter un shellcode ou une fonction isolée.
