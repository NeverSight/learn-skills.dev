Émulez un blob de code brut/shellcode sur un CPU virtuel (x86/x64/arm/arm64) avec Unicorn et rapportez l'état final des registres, le nombre d'instructions et les écritures en mémoire. Contenu : les octets s'exécutent sur un CPU émulé, pas sur l'hôte (mémoire uniquement ; aucun appel système de l'hôte sauf si raccordé) — la façon sûre d'« exécuter » du shellcode ou une fonction isolée.
