Декомпилируйте байткод Python (.pyc / скомпилированные объекты кода) обратно в исходный код с помощью decompyle3. Лучше всего подходит для байткода CPython 3.7‑3.8 (например, извлечённых из PyInstaller полезных нагрузок); честно сообщает, когда версия байткода выходит за пределы диапазона. Статический: читает байткод, никогда его не исполняет.
