Décompilez le bytecode Python (.pyc / objets code compilés) en code source avec decompyle3. Idéal pour le bytecode CPython 3.7‑3.8 (p. ex. les charges utiles extraites de PyInstaller) ; signale honnêtement lorsque la version du bytecode est hors de portée. Statique : lit le bytecode, ne l’exécute jamais.
