Décompiler le bytecode Python (objets de code .pyc / compilés) vers la source avec decompyle3. Idéal pour le bytecode CPython 3.7-3.8 (par exemple, les charges utiles extraites par PyInstaller) ; signale honnêtement lorsque la version du bytecode est hors de portée. Statique : lit le bytecode, ne l'exécute jamais.
