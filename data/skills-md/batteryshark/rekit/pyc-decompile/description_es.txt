Descompila bytecode de Python (.pyc / objetos de código compilado) de vuelta al código fuente con decompyle3. Ideal para bytecode de CPython 3.7‑3.8 (p. ej., cargas útiles extraídas con PyInstaller); informa honestamente cuando la versión del bytecode está fuera de rango. Estático: lee el bytecode, nunca lo ejecuta.
