Descompila el bytecode de Python (.pyc /objetos de código compilado) de vuelta al código fuente con decompyle3. Ideal para código de bytes CPython 3.7-3.8 (por ejemplo, cargas útiles extraídas de PyInstaller); informa honestamente cuando la versión del código de bytes está fuera de rango. Estático: lee el código de bytes, nunca lo ejecuta.
