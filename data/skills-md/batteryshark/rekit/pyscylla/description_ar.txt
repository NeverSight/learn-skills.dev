تفريغ وإعادة محاذاة وإعادة بناء جداول عناوين الاستيراد (Import Address Tables) لتطبيقات Windows PE عبر محول Python الخاص بـ Rekit لمحرك libscylla الخارجي. يدعم تعداد العمليات، التفريغ الحي، البحث/تحليل/إصلاح جداول IAT، جولة شجرة XML الكاملة، ومسح المراجع. يقتصر على Windows؛ يجب إحضار مكتبة libscylla DLL المتوافقة مع المعمارية والالتزام برخصتها GPL‑3.0‑only الأصلية. يعمل ديناميكياً على عملية حية (ReadProcessMemory) لكنه لا ينفّذ الهدف.
