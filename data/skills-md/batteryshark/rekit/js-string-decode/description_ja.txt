JavaScript の定数キー XOR / charCode 文字列難読化を静的にデコードし、下流のスキャナーが隠された文字列（C2 URL、被害者ドメイン、タイムゾーン名、シェルコマンド）を読み取れるようにします。正規表現・ヒューリスティックでデコード箇所を検出します — `String.fromCharCode(x ^ KEY)` や `x ^ KEY` が STATIC なエンコードリテラル（整数配列、文字列、または `\xNN` / `\uNNNN` のバイト列、さらに `Buffer.from(p,"base64")` / `atob(p)` の前処理を含む）に対して適用されているケースです — KEY が小さな整数リテラル、あるいは近くで小さな整数が代入された変数である場合（ベストエフォートの定数伝搬）を解決し、XOR を適用して復元された平文を outdir/decoded-strings.js に書き出し、再スキャンできるようにします。READ-ONLY: バイトを読み取り演算を行うだけで、コードとして解析したり入力を実行したりは決して行いません。
