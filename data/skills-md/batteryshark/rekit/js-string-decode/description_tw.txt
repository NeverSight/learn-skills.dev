在 JavaScript 中靜態解碼常數金鑰 XOR / charCode 字串混淆，使下游掃描器能讀取隱藏的字串（C2 URL、受害者網域、時區名稱、Shell 指令）。使用正則表達式/啟發式方法尋找解碼位置——如 `String.fromCharCode(x ^ KEY)` 或 `x ^ KEY` 應用於靜態編碼的字面值（整數陣列、字串，或 `\xNN`/`\uNNNN` 二進位資料，亦包括 `Buffer.from(p,"base64")`/`atob(p)` 前置轉換），在 KEY 為小整數文字或附近被賦予小整數的變數時（最佳努力的常量傳播）解析 KEY，執行 XOR，並將還原的明文寫入 outdir/decoded-strings.js 供重新掃描。唯讀：只讀取位元組並進行算術運算；絕不將輸入解析為程式碼或執行。
