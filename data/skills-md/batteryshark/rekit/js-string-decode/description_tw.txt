靜態解碼 JavaScript 中使用常數金鑰 XOR / charCode 的字串混淆，使下游掃描器能讀取隱藏的字串（C2 URL、受害者網域、時區名稱、shell 指令）。透過正規表達式/啟發式方法尋找解碼點──在靜態編碼的字面值（整數陣列、字串，或 `\xNN`/`\uNNNN` Blob，亦包括 `Buffer.from(p,"base64")`/`atob(p)` 前置轉換）上套用 `String.fromCharCode(x ^ KEY)` 或 `x ^ KEY`──當 KEY 為小整數字面值或鄰近被賦值為小整數的變數時（盡力常數傳播），解析出 KEY，執行 XOR，並將還原的明文寫入 outdir/decoded-strings.js 以便重新掃描。唯讀：只讀取位元組並執行算術運算；永不將輸入解析為程式碼或執行之。
