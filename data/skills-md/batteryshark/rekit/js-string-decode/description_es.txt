Decodificar estáticamente la ofuscación de cadenas con XOR de clave constante / charCode en JavaScript para que un escáner posterior pueda leer las cadenas ocultas (URLs C2, dominios de víctimas, nombres de zonas horarias, comandos de shell). Encuentra sitios de decodificación con expresiones regulares/heurísticas: un `String.fromCharCode(x ^ KEY)` / `x ^ KEY` aplicado sobre un literal ESTÁTICO codificado (arreglo de enteros, cadena o blob `\xNN`/`\uNNNN`, incluyendo una transformación previa `Buffer.from(p,"base64")`/`atob(p)`) — resuelve la KEY cuando es un literal entero pequeño o una variable a la que se le asigna un entero pequeño cercano (propagación constante de mejor esfuerzo), aplica el XOR y escribe el texto plano recuperado en outdir/decoded-strings.js para volver a escanear.
