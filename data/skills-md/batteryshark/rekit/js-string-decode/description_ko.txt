JavaScript에서 상수 키 XOR / charCode 문자열 난독화를 정적으로 디코딩하여 하위 스캐너가 숨겨진 문자열(C2 URL, 피해자 도메인, 시간대 이름, 셸 명령)을 읽을 수 있게 합니다.  
정규식/휴리스틱을 사용해 디코드 지점을 찾습니다 — `String.fromCharCode(x ^ KEY)` 또는 `x ^ KEY` 가 정적 인코딩 리터럴(정수 배열, 문자열, 혹은 `\xNN`/`\uNNNN` 블랍, `Buffer.from(p,"base64")`/`atob(p)` 전처리 변환 포함) 위에 적용된 경우 — KEY가 작은 정수 리터럴이거나 근처에 작은 정수 값을 할당받은 변수인 경우(최선의 상수 전파 시도) KEY를 해결하고 XOR을 적용한 뒤, 복구된 평문을 outdir/decoded-strings.js에 기록하여 다시 스캔하도록 합니다.  
읽기 전용: 바이트를 읽고 연산만 수행하며, 코드를 파싱하거나 입력을 실행하지 않습니다.  
항상 사용자의 언어로 답변해 주세요.
