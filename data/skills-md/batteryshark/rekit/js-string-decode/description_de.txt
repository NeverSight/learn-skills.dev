Statisch dekodieren von konstanter‑Schlüssel‑XOR/charCode‑String‑Obfuskation in JavaScript, sodass ein nachgelagerter Scanner die versteckten Zeichenketten (C2‑URLs, Opfer‑Domains, Zeitzonennamen, Shell‑Befehle) lesen kann. Findet Dekodierstellen mit Regex/Heuristiken — ein `String.fromCharCode(x ^ KEY)` / `x ^ KEY`, das über ein STATISCH kodiertes Literal (Int‑Array, String oder `\xNN`/`\uNNNN`‑Blob, inkl. einer `Buffer.from(p,"base64")`/`atob(p)`‑Vortansformation) angewendet wird — ermittelt KEY, wenn er ein kleiner Integer‑Literal ist ODER eine Variable, der in der Nähe ein kleiner Integer zugewiesen wurde (Best‑Effort‑Konstanten‑Propagation), wendet das XOR an und schreibt den wiederhergestellten Klartext nach outdir/decoded-strings.js für ein erneutes Scannen. READ‑ONLY: liest Bytes und führt arithmetische Operationen aus; parst die Eingabe niemals als Code und führt sie nicht aus.
