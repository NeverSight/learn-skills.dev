Statisch dekodiert man konstanter‑Schlüssel‑XOR/charCode‑String‑Obfuskation in JavaScript, damit ein nachgelagerter Scanner die versteckten Zeichenketten (C2‑URLs, Opfer‑Domains, Zeitzonennamen, Shell‑Befehle) lesen kann. Findet Dekodierungsstellen mit Regex/Heuristiken – ein `String.fromCharCode(x ^ KEY)` / `x ^ KEY`, das auf ein STATISCH codiertes Literal (Int‑Array, Zeichenkette oder `\xNN`/`\uNNNN`‑Blob, inkl. einer `Buffer.from(p,"base64")`/`atob(p)`‑Vorl‑Transformation) angewendet wird – löst den KEY auf, wenn er ein kleiner Int‑Literal ODER eine nahegelegene Variable ist, die einem kleinen Int zugewiesen ist (Best‑Effort‑Konstanten‑Propagation), wendet das XOR an und schreibt den wiederhergestellten Klartext nach `outdir/decoded-strings.js` für ein erneutes Scannen. READ‑ONLY: liest Bytes und führt arithmetische Operationen aus; parst den Input niemals als Code und führt ihn nicht aus.
