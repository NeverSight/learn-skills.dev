DYNAMIQUE : inspectez le runtime Java d’une application Android autorisée via Frida : listez les classes chargées, énumérez les signatures des méthodes ou installez des hooks en mode observation uniquement qui rapportent les arguments et les valeurs de retour sans les modifier intentionnellement. Utilisez-le pour la découverte à l’exécution lorsque l’analyse statique d’APK/DEX est insuffisante. S’attache à l’application ou la lance sur un dispositif USB compatible Frida BYO ; exécute la cible et est conditionné par le consentement.
