DYNAMIQUE : inspectez le runtime Java d'une application Android autorisée via Frida : listez les classes chargées, énumérez les signatures de méthode ou installez des crochets d'observation uniquement qui rapportent des arguments et renvoient des valeurs sans les modifier intentionnellement. Utiliser pour la découverte à l'exécution lorsque l'analyse statique APK/DEX est insuffisante. Attache ou génère l'application sur un périphérique USB compatible BYO Frida ; exécute la cible et est autorisé.
