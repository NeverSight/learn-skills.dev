DINAMICO: ispeziona il runtime Java di un'app Android autorizzata tramite Frida: elenca le classi caricate, enumera le firme dei metodi o installa hook solo di osservazione che segnalano argomenti e valori di ritorno senza modificarli intenzionalmente. Usalo per la scoperta a runtime quando l'analisi statica di APK/DEX è insufficiente. Si collega o avvia l'app su un dispositivo USB compatibile con Frida BYO; esegue il target ed è soggetto al consenso.
