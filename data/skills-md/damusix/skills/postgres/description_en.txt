PostgreSQL reference (versions 14–18, plus PostgreSQL 19 changes) to consult before writing or changing anything that runs on Postgres. Use for any SQL or database work that touches Postgres, even when the user only asks to build a feature: queries, schemas, DDL, migrations, indexes, constraints, data types, functions, triggers, PL/pgSQL, RLS, and ORM or query-builder code that emits Postgres SQL; reviewing or debugging SQL; EXPLAIN plans; locking, transactions, VACUUM, WAL, partitioning, replication, backup, upgrades, pooling, monitoring, tuning, and security. Also covers JSONB, full-text search, BM25 ranking, message queues, UUIDs, timestamptz, COPY, catalogs, and extensions (pgvector, PostGIS, TimescaleDB, Citus, pg_trgm, pg_cron, pg_partman, pg_textsearch, pgmq). Load it whenever the project uses Postgres (a postgres:// URL, a Postgres driver, .sql files, a migrations folder) and read the matching references before writing SQL, so version differences and known pitfalls are checked first.
