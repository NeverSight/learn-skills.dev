Diseñe y cree sitios web con sistemas visuales inspirados en películas, dirección de arte impulsada por el director, planificación de diseño de guiones gráficos y movimiento cinematográfico. Úselo cuando el usuario solicite un sitio cinematográfico, una página de destino de estilo de película, una interfaz de usuario inspirada en el director, una película negra, una ciencia ficción, un romance, un thriller, una acción, una animación o una estética de sitio web similar a una película, incluidas las solicitudes redactadas en chino. No lo utilice para el diseño web genérico a menos que el usuario quiera explícitamente una referencia de película o director.
