Détecter et corriger les modèles de performance x86/C/C++ à partir du code source ou des sorties de profilage (perf, VTune, flamegraphs). S'exécuter lorsque l'utilisateur demande à optimiser, à examiner les performances ou à écrire du nouveau code SIMD/vectorisé — même sans données de profilage. Se déclencher sur : boucles accumulatrices sérielles, SIMD étroit (xmm/ymm qui pourrait être ymm/zmm), intrinsics _mm*, clusters HITM/cmpxchg, faux partage, absence de restrict ou vzeroupper, thundering‑herd futex_wake/notify_all, symbole chaud dans une bibliothèque système (.so) avec un écart de version, ou toute demande d'écrire une réduction rapide, un produit scalaire ou une fonction distribuée sur le CPU. Modèles : accumulateur sériel, spinlock TTAS, upconversion SIMD (zipper), faux partage, statistiques par CPU, vzeroupper manquant, restrict manquant, cv‑thundering‑herd, mutex‑to‑rwlock, dispatch CPU, mise à jour de version de bibliothèque, CRC32C rapide, algorithmes connus (similarité cosinus, distance de Hamming, distance de Jaccard), tri SIMD (x86‑simd‑sort).
