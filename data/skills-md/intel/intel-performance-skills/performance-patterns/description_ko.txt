소스 코드나 프로파일링 결과(perf, VTune, 플레임그래프)를 통해 x86/C/C++ 성능 패턴을 감지하고 수정합니다. 사용자가 최적화를 요청하거나, 성능 검토를 원하거나, 새로운 SIMD/벡터화 코드를 작성하려 할 때(프로파일링 데이터가 없어도) 호출됩니다. 다음과 같은 경우에 트리거됩니다: 직렬 누산기 루프, 좁은 SIMD(xmm/ymm이지만 ymm/zmm으로 확장 가능), _mm* 인트린식, HITM/cmpxchg 클러스터, false sharing, restrict 또는 vzeroupper 누락, futex_wake/notify_all에 의한 천둥 무리(Thundering Herd), 버전 차이가 있는 시스템 라이브러리(.so) 내부의 핫 심볼, 혹은 빠른 축소(reduction), 내적(dot product), CPU 디스패치 함수 작성을 요청하는 모든 경우. 패턴 예시: 직렬 누산기, TTAS 스핀락, SIMD 업컨버전(지퍼), false sharing, per-CPU 통계, vzeroupper 누락, restrict 누락, cv-thundering-herd, mutex‑to‑rwlock, CPU 디스패치, 라이브러리 버전 업그레이드, 빠른 CRC32C, 알려진 알고리즘(코사인 유사도, 해밍 거리, 자카드 거리), SIMD 정렬(x86-simd-sort).
