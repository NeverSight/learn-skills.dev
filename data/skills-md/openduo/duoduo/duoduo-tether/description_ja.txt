所有者の他の AI アシスタントのうちの 1 つを、テザー チャネルを介して duoduo に接続します。パスキー承認の背後にある MCP サーバーです：ChatGPT や Dots、Grok Bot、Cursor、自己構築エージェント、あるいは Claude Code と Codex を duoduo‑tether CLI を通じて接続します。所有者がアシスタントを接続したいとき、ホストを（ゲートウェイ、トンネル、ファンネル、固定 IP、Worker リレー）として 1 つだけ到達可能にしたいとき、アシスタントに duoduo がメールで委任したタスクを実行させたいとき、接続を取り消したいとき、メールやドアベルを設定したいときに使用します。トリガー：Dots / Grok への接続、ChatGPT を多多に接続、MCP 接続、テザー、パスキー、多多にパブリック IP アドレスを付与。
