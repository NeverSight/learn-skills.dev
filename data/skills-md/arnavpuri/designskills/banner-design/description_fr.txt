Graphiques de bannières pour les canaux détenus : images de bannières héro/section de site web, images d’en‑tête d’e‑mail, bannières d’événements et de conférences, promotions latérales et barres d’annonce, via la génération d’images Flash Gemini 3.1 (par défaut) ou HTML/CSS. Couvre les tailles standard, les ratios et le recadrage Gemini, le placement des CTA, la direction artistique adaptative et les contraintes d’e‑mail. Pour les publicités display/IAB payantes, utilisez ad‑creative‑design ; pour une section codée au‑dessus‑du‑pli, utilisez hero‑section ; pour un modèle d’e‑mail complet, utilisez email‑design. Phrases déclencheuses : « design a banner », « create a website banner », « hero banner image », « email header », « event banner », « promotional banner », « web banner », « sidebar banner », « announcement bar », « Eventbrite banner ».
