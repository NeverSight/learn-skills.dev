Graphiques de bannières pour les canaux détenus : images de bannières héros/section de site Web, images d’en‑tête d’e‑mail, bannières d’événement et de conférence, promotions de maison en barre latérale et barres d’annonce, via la génération d’images Flash Gemini 3.1 (par défaut) ou HTML/CSS. Couvre les tailles standard, les ratios et le recadrage Gemini, le placement des CTA, la direction artistique responsive et les contraintes d’e‑mail. Pour les publicités display payantes/IAB, utilisez ad‑creative‑design ; pour une section codée au‑above‑the‑fold, utilisez hero‑section ; pour un modèle d’e‑mail complet, utilisez email‑design. Phrases déclencheurs : « design a banner », « create a website banner », « hero banner image », « email header », « event banner », « promotional banner », « web banner », « sidebar banner », « announcement bar », « Eventbrite banner ».
