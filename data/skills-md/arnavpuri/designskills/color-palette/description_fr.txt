Générez des palettes de couleurs accessibles : échelles de nuances OKLCH (50‑950), neutres teintés, couleurs sémantiques, vérifications de contraste WCAG, remappages de couleurs pour le mode sombre, dégradés et sortie couleur CSS/Tailwind. Utilisez lorsque la tâche concerne UNIQUEMENT la couleur. Phrases déclencheuses : "color palette", "color scheme", "generate colors", "shade scale", "color tokens", "color system", "accessible colors", "contrast ratio", "semantic colors", "palette from hex". Pour logo + polices + directives utilisez brand-identity ; pour systèmes complets de jetons/composants (espacement, rayon, composants) utilisez design-system ; pour thèmes sombres complets utilisez dark-mode.

Veuillez toujours répondre dans la langue de l'utilisateur.
