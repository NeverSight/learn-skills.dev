Web 和 UI 的排版：模块化字号比例、字体配对、标题层级、可读的正文、流式 clamp() 大小、可变字体、字体加载以及文本效果。当任务涉及字体或文本样式时使用。触发短语：“typography”（排版）、“font pairing”（字体配对）、“type scale”（字号比例）、“heading sizes”（标题尺寸）、“responsive text”（响应式文本）、“font combination”（字体组合）、“text style”（文本样式）、“variable fonts”（可变字体）、“fluid typography”（流体排版）、“google fonts”（Google 字体）、“line height”（行高）、“font loading”（字体加载）。若需要完整的 token 系统（间距、颜色、组件），使用 design-system，它会使用此处定义的比例。
