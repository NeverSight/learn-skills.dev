Typographie pour le web et les interfaces : échelles typographiques modulaires, association de polices, hiérarchie des titres, texte de corps lisible, dimensionnement fluide avec clamp(), polices variables, chargement de polices et effets de texte. Utilisez‑le lorsque la tâche porte sur les polices ou le style de texte. Expressions déclenchantes : « typography », « font pairing », « type scale », « heading sizes », « responsive text », « font combination », « text style », « variable fonts », « fluid typography », « google fonts », « line height », « font loading ». Pour un système complet de jetons (espacement, couleur, composants) utilisez « design‑system », qui consomme l’échelle définie ici.
