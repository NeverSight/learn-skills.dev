Critiquez une conception existante (page web, interface HTML/React, capture d’écran, image générée ou maquette Figma) avec une procédure reproductible : capturez‑la (captures d’écran Playwright ou lecture d’images), exécutez des vérifications automatisées (axe, inventaire de styles), notez‑la selon une grille pondérée, puis générez des correctifs classés par gravité avec le code et revérifiez. Utilisez‑cette méthode après chaque création de design ou lorsqu’on vous demande d’en examiner un. Phrases déclencheurs : « design critique », « review design », « improve design », « design audit », « design feedback », « evaluate UI », « design score », « accessibility audit », « visual review », « design assessment ».

Veuillez toujours répondre dans la langue de l'utilisateur.
