Graphiques organiques pour les réseaux sociaux (publications, stories, carrousels, en‑têtes/couvertures de profil) adaptés à Instagram, X/Twitter, LinkedIn, Facebook, Pinterest et TikTok, avec zones de sécurité propres à chaque plateforme. Utilise par défaut la génération d’images Gemini 3.1 Flash ; HTML/CSS pour les carrousels templatisés. À employer pour le contenu gratuit du fil d’actualité ; pour les publicités payantes, utilisez ad‑creative‑design, pour les bannières site/web‑mail, utilisez banner‑design, pour les miniatures YouTube et les images OG, utilisez thumbnail‑design. Phrases déclencheurs : « create a social media post », « design an Instagram graphic », « make a Twitter image », « LinkedIn post graphic », « social media design », « Instagram story », « carousel design », « social graphic ».
