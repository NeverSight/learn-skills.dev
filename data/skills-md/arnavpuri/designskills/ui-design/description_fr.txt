Modèles d'interface utilisateur de base pour les composants et les écrans d'application : jetons, hiérarchie visuelle, états interactifs, formulaires, navigation, états de retour, accessibilité et règles réactives. Utilisez-les lorsque l'utilisateur demande de « concevoir une UI », « créer un composant », « créer une interface », « styliser un formulaire », « le rendre esthétique », « améliorer le design », « ajouter des états de survol », « le rendre accessible », ou tout autre travail général d'UI. C’est la base sur laquelle les autres compétences UI s’appuient ; privilégiez : landing-page-design pour les pages marketing complètes, hero-section pour le bloc au‑dessus‑du‑pli uniquement, card-design pour les cartes, dashboard-design pour les vues d’administration denses en données, mobile-ui-design pour les écrans tactiles d’abord, dark-mode pour le thématisme, et email-design pour les e‑mails HTML.
