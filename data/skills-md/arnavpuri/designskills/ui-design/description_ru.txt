Основные UI‑шаблоны для компонентов и экранов приложений: токены, визуальная иерархия, интерактивные состояния, формы, навигация, состояния обратной связи, доступность и правила адаптивности. Используйте их, когда пользователь просит «design a UI», «build a component», «create an interface», «style a form», «make it look good», «improve the design», «add hover states», «make it accessible» или любую общую работу с UI. Это база, на которой строятся остальные UI‑навыки; предпочтительно использовать landing-page-design для полноценных маркетинговых страниц, hero-section для единственного блока выше «первого экрана», card-design для карточек, dashboard-design для данных‑насыщенных админских представлений, mobile-ui-design для экранов, ориентированных на сенсорное управление, dark-mode для тем и email-design для HTML‑почты.
