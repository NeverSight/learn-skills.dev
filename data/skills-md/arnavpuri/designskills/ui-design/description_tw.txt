核心 UI 模式，適用於元件與應用程式畫面：tokens、視覺層次、互動狀態、表單、導覽、回饋狀態、可存取性以及響應式規則。當使用者要求「設計 UI」、「建立元件」、「創建介面」、「樣式化表單」、「讓它好看」、「改進設計」、「新增懸停狀態」、「提升可存取性」或任何一般 UI 工作時，請使用此基礎。這是其他 UI 技能構建的基礎；對於完整的行銷頁面請偏好 landing-page-design，僅上方可見區塊請使用 hero-section，卡片請用 card-design，資料密集的管理介面請用 dashboard-design，以觸控為先的螢幕請用 mobile-ui-design，主題化請使用 dark-mode，HTML 電子郵件則用 email-design。

請務必以使用者的語言回覆。
