コンポーネントやアプリ画面の基本的な UI パターン：トークン、ビジュアル階層、インタラクティブな状態、フォーム、ナビゲーション、フィードバック状態、アクセシビリティ、レスポンシブルール。ユーザーが「UI をデザインする」や「コンポーネントを作る」や「インターフェースを作成する」や「フォームのスタイルを整える」や「見た目を良くする」や「デザインを改善する」や「ホバー状態を追加する」や「アクセシビリティを確保する」など、一般的な UI 作業を依頼したときに使用します。これは他の UI スキルが構築される基盤です。フルマーケティングページには landing-page-design、ファーストビューのブロックだけには hero-section、カードには card-design、データが多い管理画面には dashboard-design、タッチファーストの画面には mobile-ui-design、テーマには dark-mode、HTML メールには email-design を優先してください。常にユーザーの言語で回答してください。
