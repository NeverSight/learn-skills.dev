Modèles de sections hero au-dessus du pli (centré, fractionné, vidéo, typographie minimale), techniques d'arrière-plan et performance LCP, avec du code prêt pour la production.  
Utilisez-le lorsque l'utilisateur demande de « créer un hero », « construire une section hero », « concevoir au‑dessus du pli », « créer une bannière hero », « en‑tête de page d’atterrissage », « construire un hero de page d’accueil », ou ne redessine que le haut d’une page.  
Pour une page marketing à plusieurs sections, utilisez landing-page-design (qui utilise cette compétence pour son hero) ; pour une hero statique *image ou graphique de bannière*, utilisez banner-design.  
Veuillez toujours répondre dans la langue de l'utilisateur.
