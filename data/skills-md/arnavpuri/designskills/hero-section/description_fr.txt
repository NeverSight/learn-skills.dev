Modèles de sections hero au‑delà du pli (centré, partagé, vidéo, typographie minimale), techniques d’arrière‑plan et performance LCP, avec du code prêt pour la production. Utilisez‑le lorsque l’utilisateur demande « créer un hero », « construire une section hero », « concevoir au‑delà du pli », « fabriquer une bannière hero », « en‑tête de page d’atterrissage », « construire un hero de page d’accueil », ou ne redessine que le haut d’une page. Pour une page marketing à sections multiples, utilisez landing‑page‑design (qui s’appuie sur cette compétence pour son hero) ; pour une image hero statique *ou un graphique de bannière*, utilisez banner‑design.

Veuillez toujours répondre dans la langue de l’utilisateur.
