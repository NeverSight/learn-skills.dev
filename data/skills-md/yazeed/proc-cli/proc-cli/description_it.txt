Trova, ispeziona e controlla processi e porte con il CLI proc (macOS, Linux, Windows), con output JSON per gli agenti. Usalo al posto di lsof, ps, pgrep, pkill, kill, netstat, pstree o top ogni volta che devi: vedere cosa c’è su una porta o liberarla (EADDRINUSE, “address already in use”, un server di sviluppo che non si avvia); trovare processi per nome, PID, file o directory del progetto; ispezionare un processo (comando, cwd, genitore, tempo di attività, CPU, memoria); fermare, terminare, mettere in pausa, riprendere o attendere i processi; tracciare perché una porta è occupata; trovare processi orfani, bloccati o residui, come server di sviluppo, watcher e browser headless che tu o un altro agente avete avviato; o pulire il lavoro in background prima di completare un’attività. Usalo anche quando l’utente menziona proc, porte, PID, segnali (SIGTERM, SIGKILL, SIGSTOP) o una macchina lenta.
