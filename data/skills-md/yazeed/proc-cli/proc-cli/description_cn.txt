使用 proc CLI（适用于 macOS、Linux、Windows）查找、检查和控制进程与端口，支持 JSON 输出供代理使用。它可替代 lsof、ps、pgrep、pkill、kill、netstat、pstree 或 top，适用于以下情况：查看端口占用情况或释放端口（EADDRINUSE，“地址已被占用”，开发服务器无法启动）；按名称、PID、文件或项目目录查找进程；检查进程信息（命令、工作目录、父进程、运行时间、CPU、内存）；停止、杀死、暂停、恢复或等待进程；追踪端口为何被占用；寻找孤立、卡住或残留的进程，例如你或其他代理启动的开发服务器、监视器和无头浏览器；或者在完成任务前清理后台工作。当用户提及 proc、端口、PID、信号（SIGTERM、SIGKILL、SIGSTOP）或机器运行缓慢时，也请使用它。
