proc CLI（macOS、Linux、Windows）を使用してプロセスやポートを検索、検査、制御できます。エージェント向けに JSON 出力もサポートしています。lsof、ps、pgrep、pkill、kill、netstat、pstree、top の代わりに、次のような場面で利用してください。  

- ポートに何があるか確認したり解放したりする（EADDRINUSE、"address already in use"、起動しない開発サーバなど）  
- 名前、PID、ファイル、プロジェクトディレクトリでプロセスを検索する  
- プロセスを検査する（コマンド、カレントディレクトリ、親プロセス、稼働時間、CPU、メモリ）  
- プロセスを停止、終了、停止、一時停止、再開、または待機させる  
- ポートが占有されている原因を追跡する  
- 孤児化・スタック・残存したプロセス（開発サーバ、ウォッチャ、ヘッドレスブラウザなど）を見つける  
- タスク完了前にバックグラウンド作業をクリーンアップする  

ユーザーが「proc」やポート、PID、シグナル（SIGTERM、SIGKILL、SIGSTOP）または遅いマシンに言及したときにも使用してください。
