ابحث، افحص وتحكم في العمليات والمنافذ باستخدام أداة proc سطر الأوامر (macOS، Linux، Windows)، مع إخراج JSON للوكيل. استخدمها بدلًا من lsof، ps، pgrep، pkill، kill، netstat، pstree أو top كلما احتجت إلى: معرفة ما هو على منفذ ما أو تحريره (EADDRINUSE، “العنوان مستخدم بالفعل”، خادم تطوير لا يبدأ); العثور على العمليات حسب الاسم أو PID أو الملف أو دليل المشروع؛ فحص عملية (الأمر، cwd، العملية الأم، مدة التشغيل، CPU، الذاكرة)؛ إيقاف، قتل، إيقاف مؤقت، استئناف أو الانتظار للعمليات؛ تتبع سبب انشغال المنفذ؛ العثور على العمليات اليتيمة أو العالقة أو المتبقية، مثل خوادم التطوير أو المراقبين أو المتصفحات الرؤوسية التي بدأتها أنت أو وكيل آخر؛ أو تنظيف الأعمال الخلفية قبل إكمال مهمة. استخدمها أيضًا عندما يذكر المستخدم proc أو المنافذ أو الـ PIDs أو الإشارات (SIGTERM، SIGKILL، SIGSTOP) أو جهازًا بطيئًا.
