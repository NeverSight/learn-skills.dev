proc CLI(macOS, Linux, Windows)를 사용하여 프로세스와 포트를 찾고, 검사하고, 제어하세요. 에이전트를 위한 JSON 출력도 제공합니다. lsof, ps, pgrep, pkill, kill, netstat, pstree 또는 top을 대신해 다음과 같은 경우에 사용합니다: 포트에 어떤 것이 연결되어 있는지 확인하거나 포트를 해제하기(EADDRINUSE, “address already in use”, 시작되지 않는 개발 서버); 이름, PID, 파일 또는 프로젝트 디렉터리로 프로세스를 찾기; 프로세스 정보를 검사하기(명령, cwd, 부모, 실행 시간, CPU, 메모리); 프로세스를 중지, 종료, 일시 정지, 재개 또는 대기하기; 포트가 바쁜 이유를 추적하기; 고아, 고정되거나 남아있는 프로세스 찾기(예: 여러분이나 다른 에이전트가 시작한 개발 서버, 워처, 헤드리스 브라우저); 작업을 마치기 전에 백그라운드 작업을 정리하기. 또한 사용자가 proc, ports, PIDs, signals(SIGTERM, SIGKILL, SIGSTOP) 또는 느린 머신을 언급할 때에도 사용하세요.
