Implementa o rivedi i canali della piattaforma Flutter, le API Pigeon, FFI e i build hook, le implementazioni di plugin nativi, le visualizzazioni della piattaforma, i confini add-to-app, l’interoperabilità web e l’integrazione del ciclo di vita nativo. Usa quando Dart deve comunicare con le piattaforme native; indirizza le API dei pacchetti riutilizzabili, la federazione e la prontezza alla pubblicazione verso flutter‑package‑development.
