Découvrez, inspectez, générez ou mettez à jour les clients API Flutter et Dart à partir de contrats Swagger ou OpenAPI. Utilisez‑le lorsque l’inventaire des spécifications, la sélection d’opérations, la génération de client ou la dérive du contrat sont la tâche ; orientez le comportement HTTP ordinaire vers **flutter‑networking** et la connexion ou le cycle de vie du token vers **flutter‑authentication**.
