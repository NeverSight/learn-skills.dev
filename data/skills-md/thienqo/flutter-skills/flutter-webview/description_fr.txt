Implémentez, réparez ou examinez le contenu Web intégré dans Flutter, y compris la politique de navigation, les ponts JavaScript, les cookies, les sessions, les flux de fichiers, les autorisations et le cycle de vie du WebView. Utilisez-le lorsqu’un écran Flutter héberge du contenu Web ; redirigez la connexion OAuth vers flutter-authentication, les itinéraires de l’application vers flutter-navigation, et les audits de menaces larges vers flutter-security.
