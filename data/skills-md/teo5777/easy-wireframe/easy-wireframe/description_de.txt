Generieren Sie Produktprototypen/Seitenfluss-Wireframes sowohl für Mobilformate (App) als auch für PC-Formate (Desktop-Web). Wenn Benutzer Produktprototypen, Wireframes, Seitenflussdiagramme, Interaktionsflüsse, App-Prototypen, Backend-/Managementsystem-Prototypen erstellen oder mehrere Seiten mit Pfeilen zur Anzeige der Klicknavigation gestalten möchten, verwenden Sie dies. Geben Sie eine einzelne HTML-Datei aus: Mobilgeräte verwenden iOS-Standardabmessungen (375 x 812) + Apple HIG-Schriftgrößen, PC verwendet Desktop-Abmessungen (1440 x 900) + dichtere Web-Schriftgrößen; beide im minimalistischen schwarz-weiß-grauen Wireframe-Stil, mit integriertem Anmerkungssystem und ganzseitigem Screenshot-Export.
