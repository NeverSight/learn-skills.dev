Genera prototipi di prodotto/wireframe del flusso di pagine, in due forme: mobile (App) e PC (desktop web). Da utilizzare quando gli utenti desiderano creare prototipi di prodotto, wireframe, diagrammi di flusso di pagine, flussi di interazione, prototipi di app, prototipi di sistemi backend/di gestione e disporre più pagine con frecce che indicano la navigazione tramite clic. Genera un file HTML a file singolo: il dispositivo mobile utilizza la dimensione standard iOS (375×812) + le dimensioni dei caratteri HIG Apple, il PC utilizza la dimensione del desktop (1440×900) + le dimensioni dei caratteri Web più dense; entrambi in uno stile wireframe minimalista bianco-nero-grigio, con sistema di annotazione integrato ed esportazione di screenshot a pagina intera.
