可选的高级管线，用于在 Blockbench 与 Adobe Substance 3D（Designer、Painter 以及 Substance Automation Toolkit 命令行）之间进行交互。仅在用户已安装 Substance 并请求时使用——使用 sbsrender 将 .sbsar 程序材质渲染为 Blockbench 大小的 PBR 贴图，使用 sbscooker 烹饪 .sbs 图形，使用 substance3d_baker 从 Blockbench 导出中烘焙 AO/曲率/法线/位置/ID 贴图，利用 Substance 3D Painter 的远程脚本 HTTP API 为 Blockbench 模型上色并导出 Bedrock MER 或 glTF 贴图，并将结果打包到 texture_set.json。触发关键词包括 Substance、Substance 3D、Substance Designer、Substance Painter、SAT、Substance Automation Toolkit、sbsar、.sbs、sbsrender、sbscooker、sbsmutator、sbsupdater、sbsbaker、substance3d_baker、pysbs、bake AO for Blockbench、Painter export to Blockbench。普通绘画、生成的纹理或派生的法线贴图不需要此管线。
