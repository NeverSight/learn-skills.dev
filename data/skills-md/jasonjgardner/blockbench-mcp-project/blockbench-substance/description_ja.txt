オプションの高度なパイプライン：Blockbench と Adobe Substance 3D（Designer、Painter、そして Substance Automation Toolkit のコマンドライン）間の連携です。ユーザーが Substance をインストールしていて、かつ要求した場合にのみ使用してください — sbsrender を使って .sbsar プロシージャルマテリアルを Blockbench サイズの PBR マップにレンダリングし、sbscooker で .sbs グラフをクックし、substance3d_baker で Blockbench エクスポートから AO／カーブ／ノーマル／ポジション／ID マップをベイクし、Substance 3D Painter のリモートスクリプティング HTTP API を介して Blockbench モデルにペイントし、Bedrock MER または glTF マップをエクスポートし、結果を texture_set.json にパックします。トリガーキーワードは Substance、Substance 3D、Substance Designer、Substance Painter、SAT、Substance Automation Toolkit、sbsar、.sbs、sbsrender、sbscooker、sbsmutator、sbsupdater、sbsbaker、substance3d_baker、pysbs、bake AO for Blockbench、Painter export to Blockbench です。通常のペインティングや生成されたテクスチャ、派生したノーマルマップには必要ありません。
