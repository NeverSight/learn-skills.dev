Pipeline optionnelle et avancée entre Blockbench et Adobe Substance 3D (Designer, Painter et les lignes de commande du Substance Automation Toolkit). À n’utiliser que si l’utilisateur possède Substance installé et le demande — rendre les matériaux procéduraux .sbsar en cartes PBR au format Blockbench avec sbsrender, cuire les graphes .sbs avec sbscooker, baker les cartes AO/curvature/normal/position/ID à partir d’une exportation Blockbench avec substance3d_baker, piloter Substance 3D Painter via son API HTTP de script à distance pour peindre un modèle Blockbench et exporter les cartes Bedrock MER ou glTF, puis empaqueter les résultats dans texture_set.json. S’active sur Substance, Substance 3D, Substance Designer, Substance Painter, SAT, Substance Automation Toolkit, sbsar, .sbs, sbsrender, sbscooker, sbsmutator, sbsupdater, sbsbaker, substance3d_baker, pysbs, bake AO for Blockbench, Painter export to Blockbench. Non requis pour la peinture ordinaire, les textures générées ou les cartes normales dérivées.
