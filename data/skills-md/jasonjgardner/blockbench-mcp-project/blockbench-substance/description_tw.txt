可選的進階管線，用於 Blockbench 與 Adobe Substance 3D（Designer、Painter 以及 Substance Automation Toolkit 指令列）之間的互動。僅在使用者已安裝 Substance 且有此需求時使用——使用 sbsrender 將 .sbsar 程式化材質渲染為 Blockbench 大小的 PBR 貼圖，使用 sbscooker 烹飪 .sbs 圖形，利用 substance3d_baker 從 Blockbench 匯出檔案烘焙 AO、曲率、法線、位置、ID 等貼圖，透過其遠端腳本 HTTP API 控制 Substance 3D Painter 為 Blockbench 模型上色並匯出 Bedrock MER 或 glTF 貼圖，最後將結果打包至 texture_set.json。觸發關鍵詞包括 Substance、Substance 3D、Substance Designer、Substance Painter、SAT、Substance Automation Toolkit、sbsar、.sbs、sbsrender、sbscooker、sbsmutator、sbsupdater、sbsbaker、substance3d_baker、pysbs、bake AO for Blockbench、Painter export to Blockbench。對於一般上色、產生的貼圖或衍生的法線貼圖則不需要此管線。
