Obtén las texturas originales ("vanilla") de Minecraft del repositorio bedrock‑samples de Mojang a través del CDN jsDelivr y aplícalas a modelos de Blockbench, resolviendo los IDs de bloque en archivos por cara, tintando la hierba/hojas/agua en escala de grises, mosaiciando caras grandes, manejando flipbooks e importando el conjunto de texturas PBR vanilla (MERS/normal). Úsalo cuando el usuario solicite texturas vanilla, predeterminadas, originales, reales o precisas de Minecraft, nombre un bloque o material de Minecraft para un modelo (pared de ladrillos, tronco de roble, ladrillos de piedra, bloque de hierba, lana, vidrio), quiera que un modelo coincida con el juego base o necesite mapear un nombre de textura de Bedrock a Java Edition. Funciona para modelos de Bedrock, Java y genéricos.

Por favor, responde siempre en el idioma del usuario.
