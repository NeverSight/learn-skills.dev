jsDelivr CDN을 통해 Mojang의 bedrock‑samples 저장소에서 원본(“바닐라”) Minecraft 텍스처를 가져와 Blockbench 모델에 적용하고, 블록 ID를 면별 파일로 해석하며, 회색조 잔디·잎·물에 색조를 입히고, 큰 면을 타일링하고, 플립북을 처리하며, 바닐라 PBR texture_set(MERS/normal)을 가져옵니다. 사용자가 바닐라, 기본, 원본, 실제 또는 Minecraft‑정확한 텍스처를 요청하거나, 모델에 대한 Minecraft 블록이나 재료(벽돌 벽, 참나무 통, 석재 벽돌, 잔디 블록, 양털, 유리)를 언급하고, 기본 게임과 일치하는 모델을 원하거나, Bedrock 텍스처 이름을 Java Edition에 매핑해야 할 때 사용합니다. Bedrock, Java 및 일반 모델 모두에 적용됩니다.

항상 사용자의 언어로 답변해 주세요.
