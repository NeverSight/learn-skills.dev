Получайте оригинальные («ванильные») текстуры Minecraft из репозитория bedrock‑samples от Mojang через CDN jsDelivr и применяйте их к моделям Blockbench, сопоставляя ID блоков с файлами по отдельным граням, оттеняя чёрно‑белые траву, листья и воду, замощая большие грани, обрабатывая flipbook‑анимации и импортируя ванильный набор PBR‑текстур (MERS/normal). Используйте, когда пользователь запрашивает ванильные, стандартные, оригинальные, «реальные» или точно соответствующие Minecraft текстуры, упоминает блок или материал Minecraft для модели (кирпичная стена, дубовый брус, каменные кирпичи, травяной блок, шерсть, стекло), хочет, чтобы модель соответствовала базовой игре, или нуждается в сопоставлении названия текстуры Bedrock с Java‑версией. Работает с моделями Bedrock, Java и общими.
