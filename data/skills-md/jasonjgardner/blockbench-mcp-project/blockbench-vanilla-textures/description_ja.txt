Mojang の bedrock-samples リポジトリから jsDelivr CDN 経由でオリジナル（「バニラ」）Minecraft テクスチャを取得し、Blockbench モデルに適用します。ブロック ID を面ごとのファイルに解決し、グレースケールの草・葉・水に色付けを行い、大きな面をタイル状に配置し、フリップブックを処理し、バニラの PBR texture_set（MERS/normal）をインポートします。ユーザーが「vanilla」「default」「original」「real」または「Minecraft‑accurate」テクスチャを求めたり、モデルの素材として Minecraft のブロックやマテリアル（例：brick wall、oak log、stone bricks、grass block、wool、glass）を指定したり、ベースゲームと同じ外観のモデルが欲しい場合、または Bedrock のテクスチャ名を Java Edition にマッピングしたい場合に使用します。Bedrock、Java、汎用モデルすべてで動作します。
