Recupera le texture originali ("vanilla") di Minecraft dal repository bedrock‑samples di Mojang tramite la CDN jsDelivr e applicale ai modelli Blockbench, risolvendo gli ID dei blocchi in file per faccia, tinteggiando in scala di grigi erba, foglie e acqua, ripetendo le facce grandi, gestendo i flipbook e importando il texture_set PBR vanilla (MERS/normal). Usalo quando l’utente richiede texture vanilla, di default, originali, reali o fedeli a Minecraft, nomina un blocco o materiale di Minecraft per un modello (muro di mattoni, trave di quercia, mattoni di pietra, blocco d’erba, lana, vetro), desidera che un modello corrisponda al gioco base o ha bisogno di un nome di texture Bedrock mappato alla Java Edition. Funziona per modelli Bedrock, Java e generici.  

Rispondi sempre nella lingua dell’utente.
