Aggiungi effetti di particelle (fumo, fuoco, scintille, magia, bagliore, polvere, neve, gocce, bolle, esplosioni) ai modelli Blockbench con gli strumenti MCP. Copre il JSON delle particelle Bedrock/Snowstorm, preset e controlli di progettazione, localizzatori, fotogrammi chiave delle particelle nelle animazioni, l’anteprima in modalità Animazione di Blockbench e la consegna ai pacchetti risorse Bedrock (client entity particle_effects) e GeckoLib, oltre a soluzioni di fallback per glTF, blocchi Java e target Hytale che non possono contenere particelle. Usalo quando un modello necessita di un emettitore, VFX, effetto di particella, localizzatore, file Snowstorm, fotogramma chiave particle_effects o rifinitura dell’effetto in un prodotto finale.
