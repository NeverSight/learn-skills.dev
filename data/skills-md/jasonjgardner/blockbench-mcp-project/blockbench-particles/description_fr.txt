Ajoutez des effets de particules (fumée, feu, étincelles, magie, lueur, poussière, neige, gouttes, bulles, éclats) aux modèles Blockbench avec les outils MCP. Couvre le JSON des particules Bedrock/Snowstorm, les préréglages et les paramètres de conception, les localisateurs, les images-clés de particules sur les animations, l’aperçu du mode Animate de Blockbench, et la livraison aux packs de ressources Bedrock (particle_effects d’entité client) et GeckoLib, ainsi que des solutions de secours pour les cibles glTF, Java block et Hytale qui ne peuvent pas contenir de particules. Utilisez-le lorsqu’un modèle nécessite un émetteur, un VFX, un effet de particule, un localisateur, un fichier Snowstorm, une image-clé particle_effects ou une finition d’effet dans un livrable.
