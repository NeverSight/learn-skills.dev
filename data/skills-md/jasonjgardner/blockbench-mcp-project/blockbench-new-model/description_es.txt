Inicia un nuevo modelo o escena de Blockbench a partir de un breve formulario de entrada y entrega una escena de Blender lista para renderizar. Pregunta por la calidad, el estilo de textura (PBR 2K/HD/estándar, Minecraft vanilla, Blockbench clásico), la animación (fotogramas clave o física Havok), el tipo de escena (escena, viñeta, habitación isométrica), el sujeto, la carpeta de salida y el preset de render; genera archivos .bbmodel con el servidor sin cabeza Blockbench MCP y agentes paralelos; los importa a Blender; y escribe un render.cmd que renderiza imágenes fijas en cada GPU y las ensambla en un video con FFmpeg. Úsalo cuando el usuario ejecuta /blockbench-new-model o solicita un nuevo modelo de Blockbench entregado como una escena de Blender renderizada o un video.
