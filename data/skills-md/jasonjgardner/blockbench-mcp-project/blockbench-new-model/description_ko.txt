짧은 입력 양식으로 새로운 Blockbench 모델 또는 씬을 시작하고 렌더 준비가 된 Blender 씬을 제공합니다. 품질, 텍스처 스타일(PBR 2K/HD/표준, 바닐라 Minecraft, 클래식 Blockbench), 애니메이션(키프레임 또는 Havok 물리), 씬 유형(씬, 비네트, 아이소메트릭 방), 주제, 출력 폴더 및 렌더 프리셋을 질문합니다; 헤드리스 Blockbench MCP 서버와 병렬 에이전트를 사용해 .bbmodel 파일을 생성하고; 이를 Blender에 가져오며; 모든 GPU에서 정지 이미지를 렌더링하고 FFmpeg으로 비디오를 조립하는 render.cmd를 작성합니다. 사용자는 /blockbench-new-model을 실행하거나 새로운 Blockbench 모델을 렌더링된 Blender 씬 또는 비디오 형태로 제공해 달라고 요청할 때 사용합니다. 항상 사용자의 언어로 답변하십시오.
