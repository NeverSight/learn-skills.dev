Базовый постустановочный набор для домашней лаборатории Proxmox VE. Используется для новых или восстановленных узлов Proxmox, которым следует использовать репозитории без подписки, подавлять всплывающие окна подписки в графическом интерфейсе, проверять обновления APT или повторно применять эти локальные патчи после обновления пакетов.
