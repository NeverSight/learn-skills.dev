Trasforma libri, PDF, slide, documenti, pagine web e testi in una base di conoscenza ancorata alle fonti, con pagine di apprendimento interattivo in HTML e Markdown in inglese o cinese. Usala per apprendimento, riassunti, spiegazioni, revisioni, quiz, mappe relazionali, salvataggio di file metodologici riutilizzabili, recupero o confronto di metodi accumulati e applicazione a un problema reale. Converte il materiale in una base di conoscenza tracciabile e pagine di apprendimento interattivo, supportando cinese e inglese, mappe relazionali, salvataggio/recupero/confronto di metodologie e la loro applicazione; distinguendo tra i dati di base del materiale, le inferenze e la verifica esterna.
