Convierta libros, PDF, diapositivas, documentos, páginas web y texto en una base de conocimientos basada en fuentes, HTML de aprendizaje interactivo y Markdown en inglés o chino. Se utiliza para el aprendizaje, resúmenes, explicaciones, revisión, cuestionarios, mapas de relaciones, guardar archivos de metodología reutilizables, recuperar o comparar métodos acumulados y aplicarlos a un problema real. 将材料转为可追溯知识库与交互学习页，支持中英文、关系图、方法论保存/检索/比较及应用；区分材料依据、推断与外部核验。
