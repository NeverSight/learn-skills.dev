Générez des images originales pour les sites web et les applications (images héro, arrière‑plans, textures, illustrations ponctuelles, og:images, photos de produit, découpes transparentes, retouches d’une image existante) et affichez‑les dans le chat. Utilise la génération d’images intégrée de Codex dans le plan ChatGPT de l’utilisateur lorsque le CLI Codex est connecté (pas de clé API, pas de téléchargement de modèle). En cas de besoin, recourt à FLUX.1‑schnell local sur Apple Silicon, ou à une clé API hébergée. À employer chaque fois qu’un projet nécessite de la vraie imagerie au lieu de photos de stock, de boîtes grises ou d’URL factices, ou lorsque l’utilisateur demande à Claude de « créer une image » ou d’« utiliser Codex pour générer une image ».

Veuillez toujours répondre dans la langue de l’utilisateur.
