Examine et génère du code micro‑frontend selon huit règles de limites tirées de *Building Micro‑Frontends* (O'Reilly), ainsi que des extensions de gouvernance pour la portée des feature‑flags, la stratégie edge, la responsabilité du SSR et les fonctions d’évaluation des limites. À utiliser lorsqu’un utilisateur dit « review my shell code », « is this a boundary violation? », « generate a Module Federation shell », « how do I mount this MFE? », « review my micro‑frontend architecture », « set up event communication between MFEs », « create a new micro‑frontend », « how should we use edge with MFEs? », « where should feature flags live? » ou « how do I enforce boundaries in a monorepo? ». Se charge automatiquement lorsque l’utilisateur colle du code d’intégration shell, une configuration Module Federation, une inscription Single SPA ou des routes Native Federation. Ne s’active pas pour du code au niveau composant dans une seule unité déployée, ni pour des questions génériques sur React, Vue ou Angular sans angle de déploiement inter‑équipes.

Veuillez toujours répondre dans la langue de l’utilisateur.
