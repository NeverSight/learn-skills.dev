Lädt automatisch, wenn der Benutzer Shell‑Integrationscode, Module‑Federation‑Konfiguration, Single‑SPA‑Registrierung oder Native‑Federation‑Routen einfügt. Wird nicht aktiviert für komponentenbezogenen Code innerhalb einer einzigen bereitgestellten Einheit oder für generische React‑, Vue‑ oder Angular‑Fragen ohne teamübergreifenden Bereitstellungs‑Bezug.
