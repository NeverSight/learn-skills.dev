Проверяет и генерирует код микрофронтендов согласно восьми правилам границ из книги Building Micro‑Frontends (O'Reilly), а также расширениям управления для области фич‑флагов, стратегии edge, владения SSR и функций пригодности границ. Используйте, когда пользователь говорит «проверьте мой код оболочки», «это нарушение границы?», «создайте оболочку Module Federation», «как смонтировать этот MFE?», «проверьте мою архитектуру микрофронтенда», «настройте событие коммуникации между MFE», «создайте новый микрофронтенд», «как нам использовать edge с MFE?», «где должны находиться фич‑флаги?», или «как обеспечить соблюдение границ в монорепозитории?». Загружается автоматически, когда пользователь вставляет код интеграции оболочки, конфигурацию Module Federation, регистрацию Single SPA или маршруты Native Federation. Не активируется для кода уровня компонентов в единой развернутой единице или для общих вопросов по React, Vue или Angular без аспекта кросс‑командного развертывания. Пожалуйста, всегда отвечайте на языке пользователя.
