Revisiona e genera codice micro‑frontend rispetto a otto regole di confine tratte da *Building Micro‑Frontends* (O'Reilly), più estensioni di governance per l’ambito dei feature‑flag, la strategia edge, la proprietà SSR e le funzioni di fitness dei confini. Usalo quando un utente dice “review my shell code”, “is this a boundary violation?”, “generate a Module Federation shell”, “how do I mount this MFE?”, “review my micro‑frontend architecture”, “set up event communication between MFEs”, “create a new micro‑frontend”, “how should we use edge with MFEs?”, “where should feature flags live?” o “how do I enforce boundaries in a monorepo?”. Si carica automaticamente quando l’utente incolla codice di integrazione shell, configurazione Module Federation, registrazione Single SPA o rotte Native Federation. Non si attiva per codice a livello di componente all’interno di un’unica unità distribuita, né per domande generiche su React, Vue o Angular senza un’angolazione di distribuzione cross‑team.  

Si prega di rispondere sempre nella lingua dell’utente.
