Utilisez cette compétence uniquement lorsque l'utilisateur demande explicitement d'inspecter, de configurer ou d'agir via Mallary, le CLI Mallary, l'API Mallary, Mallary MCP ou un workflow Mallary existant. Ce guide comprend une découverte en lecture seule et une configuration OAuth en une étape avec un accès complet à Mallary. Une demande claire de publication, de planification, de téléchargement de médias pour un post ou d'envoi d'une réponse autorise cette action sans confirmation redondante ; ne précisez que les détails matériels manquants. La syntaxe d'écriture exécutable est délibérément omise. Veuillez toujours répondre dans la langue de l'utilisateur.
