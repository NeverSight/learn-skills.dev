Usa questa capacità solo quando l'utente chiede esplicitamente di ispezionare, configurare o agire tramite Mallary, il Mallary CLI, l'Mallary API, Mallary MCP o un workflow Mallary esistente. Questa guida include scoperta in sola lettura e configurazione OAuth a un passo con pieno accesso a Mallary. Una richiesta chiara di pubblicare, programmare, caricare media per un post o inviare una risposta autorizza quell'azione senza una conferma ridondante; chiarisci solo i dettagli materiali mancanti. La sintassi scrivibile eseguibile è intenzionalmente omessa.

Rispondi sempre nella lingua dell'utente.
