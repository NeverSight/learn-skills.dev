# UI

- Follow the existing visual language before introducing new patterns.

## Hierarchy

- Make the primary action clear.
- Group related information; reveal secondary details when needed.

## Visual

- Use spacing, alignment, and typography to establish hierarchy before adding containers, borders, or shadows.
- Avoid decorative cards, gradients, badges, and icons without a clear purpose.
- Limit competing font sizes, weights, and accent styles.

## Interaction and copy

- Use familiar controls and make every visible action work.
- Keep interface copy concrete; remove filler and implementation jargon.
