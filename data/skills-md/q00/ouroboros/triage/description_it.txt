Effettua il triage di un batch di risultati di sicurezza grezzi. Verifica che ciascuno sia reale, elimina i duplicati, riordina in base all'exploitabilità derivata e assegna un proprietario. Accetta una directory o un file di output dello scanner e scrive TRIAGE.json + TRIAGE.md ordinati secondo ciò che richiede realmente l'attenzione dell'ingegneria. Usa quando ti viene chiesto di “triage dei risultati”, “validare l'output dello scanner”, “prioritizzare le vulnerabilità” o “rivedere il backlog”. Funziona interattivamente per impostazione predefinita; passa --auto per saltare l'intervista.  

Per favore rispondi sempre nella lingua dell'utente.
