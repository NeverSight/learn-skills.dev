Utilisez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via la CLI `orca`. Employez‑le lorsqu’un utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Privilégiez‑le plutôt qu’un worktree Git brut, des PTY ad hoc ou l’utilisation de l’ordinateur lorsque l’état d’Orca est impliqué. N’utilisez l’option « Computer Use » que lorsqu’une fenêtre visible nécessite un contrôle GUI qu’une CLI, le système de fichiers ou une API ne peuvent assurer.

Répondez toujours dans la langue de l’utilisateur.
