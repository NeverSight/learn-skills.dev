Orcaが管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そしてOrcaの埋め込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree やアドホック PTY、あるいは Computer Use よりもこちらを優先します。CLI、ファイルシステム、API では対応できない可視ウィンドウの GUI 操作が必要なときだけ Computer Use を使用してください。
