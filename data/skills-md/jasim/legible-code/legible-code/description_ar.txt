قم بتشخيص ومعالجة مشاكل وضوح الكود عن طريق إدخال أنواع نطاقية بدلاً من الأنواع الأولية والبوولات، ونقل الإدخال/الإخراج إلى حواف الوحدة، وتسمية مراحل الأنابيب المتوسطة، وإعادة تنظيم الوحدات حول أنواع البيانات بدلًا من الأفعال، وتوحيد المنطق المكرر في تعريف موثوق واحد. استخدم ذلك عند مراجعة طلب سحب، أو تخطيط إعادة هيكلة، أو تصميم وحدة/فاصل، أو عندما يشير المستخدم إلى أن الكود صعب الفهم أو يسأل عن أين يتم تقسيم أو دمج النظام.
