스마트시안 OS(해머 테크놀로지 / 너트폰)의 UI 스타일을 프런트엔드 인터페이스에 사용하십시오: 가벼운 스케우오모피즘, 섬세한 수직 그라디언트, 초박형 스트로크, 부드러운 그림자와 인셋 그림자, 주로 그레이스케일에 저채도 파란색 포인트와 스마트시안 레드 브랜드 컬러. 사용자가 Smartisan, Hammer, Hammer style, Nut OS, Smartisan OS, Luo Yonghao의 스케우오모픽 스타일, “스마트시안 폰 같은 UI” 등을 언급하거나 이 스타일의 웹사이트·컴포넌트·앱 프로토타입을 요청할 때 적용합니다. 웹(HTML/CSS/Tailwind/기타 프런트엔드 프레임워크) 및 Flutter에 적합합니다. 전체 Figma “Smartisan OS UI Kit (Unofficial)”(17페이지, 모든 컴포넌트와 변형)를 포함하며, 추출된 토큰, 컴포넌트 사양, 바로 재사용 가능한 CSS, Tailwind 프리셋, 아이콘 및 참고 스크린샷이 포함되고 실제 Smartisan R2 디바이스에서 검증되었습니다.

항상 사용자의 언어로 응답하십시오.
