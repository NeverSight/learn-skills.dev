使用 Smartisan OS（錘子科技 / 堅果手機）的 UI 風格來設計前端介面：淺色擬物化、細緻的垂直漸層、超薄描邊、柔和陰影與內陰影，主要採用灰階 + 低飽和藍色點綴 + 錘子紅品牌色。當使用者提到 Smartisan、Hammer、Hammer 風格、Nut OS、Smartisan OS、老羅／羅永浩的擬物化風格、「UI 像 Hammer 手機」或請求以此風格製作網頁／元件／應用原型時，請套用此風格。適用於 Web（HTML/CSS/Tailwind/任意前端框架）以及 Flutter。包含完整的 Figma「Smartisan OS UI Kit（非官方）」（17 頁，全部元件與變體），內含提取的 token、元件規格、可直接使用的 CSS、Tailwind 預設、圖示與參考截圖，已在真實的 Smartisan R2 設備上驗證。
