Utilisez le style UI de Smartisan OS (Smartisan Technology / Nutphone) pour les interfaces front‑end : skeuomorphisme léger, dégradés verticaux délicats, contours ultra‑minces, ombres douces et ombres internes, principalement en niveaux de gris + accents bleus à faible saturation + couleur rouge de marque Smartisan. Appliquez cela lorsque l'utilisateur mentionne Smartisan, Hammer, style Hammer, Nut OS, Smartisan OS, le style skeuomorphique de Lao Luo/Luo Yonghao, « UI comme un téléphone Smartisan », ou demande de créer une page web, un composant ou un prototype d’application dans ce style. Convient pour le web (HTML/CSS/Tailwind/ tout framework front‑end) et Flutter. Comprend le kit UI complet Figma « Smartisan OS UI Kit (Non officiel) » (17 pages, tous les composants et variantes) avec les tokens extraits, les spécifications des composants, du CSS directement utilisable, un preset Tailwind, des icônes et captures d’écran de référence, vérifiés sur un vrai dispositif Smartisan R2.  

Veuillez toujours répondre dans la langue de l'utilisateur.
