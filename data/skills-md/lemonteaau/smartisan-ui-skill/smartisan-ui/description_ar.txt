استخدم نمط واجهة المستخدم (UI) لنظام Smartisan OS (تقنية Hammer / هاتف Nut) في الواجهات الأمامية: سكيومورفية خفيفة، تدرجات رأسية دقيقة، حدود فائقة الرقة، ظلال ناعمة وظلال داخلية، معتمداً أساساً على الدرجات الرمادية + لمسات زرقاء منخفضة التشبع + اللون الأحمر الرسمي لعلامة Smartisan. يُطبق هذا النمط عندما يذكر المستخدم Smartisan أو Hammer أو نمط Hammer أو Nut OS أو Smartisan OS أو نمط سكيومورفية لاو لو/لو يونغهاو، أو عبارة “واجهة مثل هاتف Hammer”، أو يطلب نموذج موقع/مكوّن/تطبيق بهذا الأسلوب. مناسب للويب (HTML/CSS/Tailwind/أي إطار عمل للواجهة الأمامية) وFlutter. يتضمن مجموعة أدوات Figma الكاملة “Smartisan OS UI Kit (Unofficial)” (17 صفحة، جميع المكوّنات والمتغيّرات) مع الرموز المستخرجة، مواصفات المكوّنات، CSS جاهز للاستخدام، إعداد Tailwind مسبق، أيقونات، ولقطات مرجعية، تم التحقق منها على جهاز Smartisan R2 الحقيقي.
