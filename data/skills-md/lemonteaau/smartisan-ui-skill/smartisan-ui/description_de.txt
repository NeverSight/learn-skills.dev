Erstelle Front‑End‑Oberflächen im UI‑Stil von Smartisan OS (Hammer Technology / Nut‑Phone): leichter Skewomorphismus, zarte vertikale Farbverläufe, ultradünne Konturen, weiche Schatten und Inset‑Schatten, hauptsächlich Graustufen + blauer Akzent mit niedriger Sättigung + Smartisan‑rote Markenfarbe. Verwende dies, wenn der Nutzer Smartisan, Hammer, Hammer‑Stil, Nut OS, Smartisan OS, Lao Luo/Luo Yonghao’s skuwomorphischen Stil, „UI wie ein Smartisan‑Telefon“ erwähnt oder um einen Website‑/Komponenten‑/App‑Prototypen in diesem Stil bittet. Anwendbar für Web (HTML/CSS/Tailwind/irgendein Front‑End‑Framework) und Flutter. Enthält das komplette Figma‑„Smartisan OS UI Kit (Unofficial)“ (17 Seiten, alle Komponenten und Varianten) mit extrahierten Tokens, Komponentenspezifikationen, sofort einsatzfähigem CSS, Tailwind‑Preset, Icons und Referenz‑Screenshots, alles auf einem echten Smartisan R2‑Gerät verifiziert.
