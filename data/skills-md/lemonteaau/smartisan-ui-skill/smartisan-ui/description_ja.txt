Smartisan OS（Hammer Technology / Nut phone）の UI スタイルを使用してフロントエンドインターフェースを作成する：ライトスキューモーフィズム、繊細な垂直グラデーション、超薄いアウトライン、ソフトシャドウとインセットシャドウ、主にグレースケール＋低彩度ブルーアクセント＋Hammer レッドのブランドカラー。ユーザーが Smartisan、Hammer、Hammer スタイル、Nut OS、Smartisan OS、老羅（羅永浩）のスキューモーフィックスタイル、「Hammer 電話のような UI」などに言及した場合、またはこのスタイルでのウェブサイト／コンポーネント／アプリのプロトタイプを要求した場合に使用する。Web（HTML/CSS/Tailwind／任意のフロントエンドフレームワーク）および Flutter に適用可能。完全な Figma 「Smartisan OS UI Kit（非公式）」（全 17 ページ、すべてのコンポーネントとバリアント）を含み、抽出されたトークン、コンポーネント仕様、直接再利用可能な CSS、Tailwind プリセット、アイコン、参照スクリーンショットがすべて実機の Smartisan R2 で検証されている。
