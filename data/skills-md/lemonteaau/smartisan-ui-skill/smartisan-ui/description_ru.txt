Используйте UI‑стиль Smartisan OS (Hammer Technology / Nut phone) для фронтенд‑интерфейсов: лёгкий скевоморфизм, изящные вертикальные градиенты, ультра‑тонкие контуры, мягкие тени и врезные тени, преимущественно монохромные + низкосатурированный синий акцент + брендовый цвет Hammer‑красный. Применяйте его, когда пользователь упоминает Smartisan, Hammer, стиль Hammer, Nut OS, Smartisan OS, скевоморфный стиль Лао Луо/Roy Hao, «UI как телефон Hammer», или запрашивает прототип сайта/компонента/приложения в этом стиле. Подходит для веба (HTML/CSS/Tailwind/любой фронтенд‑фреймворк) и Flutter. Включает полный Figma‑набор «Smartisan OS UI Kit (Unofficial)» (17 страниц, все компоненты и варианты) с извлечёнными токенами, спецификациями компонентов, готовым к использованию CSS, пресетом Tailwind, иконками и референс‑скриншотами, проверенными на реальном устройстве Smartisan R2.
