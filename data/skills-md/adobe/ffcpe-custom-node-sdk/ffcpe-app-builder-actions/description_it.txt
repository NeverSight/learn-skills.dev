Descrive come implementare azioni personalizzate web e worker OpenWhisk di FFCPE (Firefly Creative Production for Enterprise) utilizzando @adobe/ffcpe-custom-node-core e @adobe/ffcpe-custom-node-app-builder (Hono, mountFfcpeNodeRoutes, createFfcpeNodeWorker, contratto submit/status). Descrive l’aggiunta di azioni ai repository esistenti di Adobe App Builder: file <action-name>.web|worker|entry collocati nella stessa directory, aggiornamenti *.config.yaml e sezione webpack + esbuild-loader per TypeScript con output CommonJS. Da usare durante lo scaffolding o la migrazione di coppie web/worker FFCPE, la correzione di ext.config.yaml / runtimeManifest o il debug di azioni web hono-openwhisk-adapter (web: raw). Dopo il deploy, utilizza aio ffcpe catalog con <action-name>.entry.json collocato accanto (skill in adobe/aio-cli-plugin-ffcpe) per registrare l’azione.
