FFCPE（Firefly Creative Production for Enterprise）のカスタムアクションである Web および Worker の OpenWhisk アクションを、@adobe/ffcpe‑custom‑node‑core と @adobe/ffcpe‑custom‑node‑app‑builder（Hono、mountFfcpeNodeRoutes、createFfcpeNodeWorker、submit/status 契約）を使用して実装する方法を説明しています。既存の Adobe App Builder リポジトリにアクションを追加する手順として、同一ディレクトリに配置した <action‑name>.web、<action‑name>.worker、<action‑name>.entry ファイル、*.config.yaml の更新、そして TypeScript を CommonJS 出力に変換するための webpack + esbuild‑loader のパーシャル設定について解説しています。これらは、FFCPE の Web/Worker ペアをスキャフォールドしたり移行したりする際、ext.config.yaml / runtimeManifest の修正、または hono‑openwhisk‑adapter の Web アクション（web: raw）のデバッグに使用します。デプロイ後は、同じディレクトリに置いた <action‑name>.entry.json を使用して aio ffcpe カタログ（adobe/aio‑cli‑plugin‑ffcpe のスキル）にアクションを登録します。
