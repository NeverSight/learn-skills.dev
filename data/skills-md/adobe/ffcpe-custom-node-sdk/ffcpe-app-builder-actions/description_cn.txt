描述如何使用 @adobe/ffcpe-custom-node-core 和 @adobe/ffcpe-custom-node-app-builder（Hono、mountFfcpeNodeRoutes、createFfcpeNodeWorker、submit/status 合约）实现 FFCPE（Firefly Creative Production for Enterprise）自定义动作的 Web 和 Worker OpenWhisk 动作。说明将动作添加到现有 Adobe App Builder 仓库的方式：共置的 `<action-name>.web|worker|entry` 文件、`*.config.yaml` 更新，以及用于 TypeScript、输出为 CommonJS 的 webpack + esbuild-loader 部分。适用于脚手架或迁移 FFCPE Web/Worker 对、修复 `ext.config.yaml` / `runtimeManifest`，或调试 hono-openwhisk-adapter Web 动作（web: raw）。部署后，使用 `aio ffcpe catalog` 与共置的 `<action-name>.entry.json`（在 adobe/aio-cli-plugin-ffcpe 中的 skills）注册该动作。
