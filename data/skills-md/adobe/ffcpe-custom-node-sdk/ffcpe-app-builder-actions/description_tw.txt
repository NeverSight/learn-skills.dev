說明如何使用 @adobe/ffcpe-custom-node-core 和 @adobe/ffcpe-custom-node-app-builder（Hono、mountFfcpeNodeRoutes、createFfcpeNodeWorker、submit/status 合約）實作 FFCPE（Firefly Creative Production for Enterprise）自訂行動的 web 與 worker OpenWhisk 行動。說明如何將行動加入既有的 Adobe App Builder 倉庫：共置的 <action-name>.web|worker|entry 檔案、*.config.yaml 更新，以及使用 webpack + esbuild-loader 部分來編譯產出 CommonJS 的 TypeScript。適用於腳手架或遷移 FFCPE web/worker 配對、修正 ext.config.yaml / runtimeManifest，或除錯 hono-openwhisk-adapter 的 web 行動（web: raw）。部署完成後，使用 aio ffcpe catalog 搭配共置的 <action-name>.entry.json（在 adobe/aio-cli-plugin-ffcpe 中的 skills）註冊該行動。
