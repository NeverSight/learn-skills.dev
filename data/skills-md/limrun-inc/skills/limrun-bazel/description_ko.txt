Limrun에서 Bazel 작업공간을 빌드하는 기본 방법: `lim bazel setup`와 `bazel build --config=limrun`을 사용해 Limrun의 공유 빌드 플레인에서 iOS와 Android 타깃을 빌드합니다. Linux, Windows, macOS, VM, 컨테이너, CI 등 어떤 환경에서도 조직 전체가 공유하는 하나의 원격 캐시를 활용합니다. 프로젝트가 rules_apple이나 rules_android이 포함된 Bazel 작업공간(MODULE.bazel)이고 사용자가 원격으로 빌드하거나 Limrun 시뮬레이터·에뮬레이터에서 앱을 실행하고, CI에서 Bazel 원격 실행을 설정하거나, 인증·워커·MODULE.bazel 라인 누락 등으로 `--config=limrun` 빌드가 실패할 때 사용합니다. limrun‑xcode‑bazel은 레거시 `lim xcode rbe` 흐름만 지원하므로 워크스페이스가 이미 `lim xcode rbe`를 사용 중이거나 사용자 요청 시에만 사용하십시오. Bazel이 아닌 Android 빌드의 경우 limrun‑gradle를 사용하세요.
