مرجع الاختبار والأداء وإمكانية الوصول وتعدد الخيوط لتطوير تطبيقات ويندوز (WinUI 3 / Windows App SDK). MSTest، xUnit، NUnit، WinAppDriver، Appium، Playwright، اختبار WebView2، شهادة WACK، تحميل جانب MSIX، التكامل المستمر (CI). التحليل Profiling، WPT، WPA، جمع القمامة (GC)، أداء بدء التشغيل، تحسين تخطيط/تحميل XAML، افتراضية ListView/GridView، DispatcherQueue. أتمتة واجهة المستخدم UI Automation، AutomationProperties، أقران الأتمتة، قابلية التشغيل عبر لوحة المفاتيح، سمة التباين العالي، المساعد الصوتي Narrator. DispatcherQueue، DispatcherQueueTimer، نمط غير المتزامن في WinRT، async/await، ConfigureAwait، مجموعة الخيوط، STA/MTA، تجنب التعطل (deadlock)، مهام الخلفية.
