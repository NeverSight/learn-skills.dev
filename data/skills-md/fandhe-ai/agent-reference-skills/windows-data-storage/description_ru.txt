Справочник по работе с файлами, настройками и сохранением данных при разработке приложений Windows (Windows App SDK / WinRT). Классы StorageFile, StorageFolder, IStorageItem, FileIO, PathIO, CachedFileManager, DataReader, DataWriter из Windows.Storage. Локальные и роуминговые настройки с помощью ApplicationData, ApplicationDataContainer, ApplicationDataCompositeValue. Доступ к файлам и разрешения с использованием FileOpenPicker, FileSavePicker, FolderPicker, StorageApplicationPermissions, KnownFolders. Сериализация и постоянное хранение с помощью JsonObject, JsonArray, XmlDocument, SQLite, EF Core.
