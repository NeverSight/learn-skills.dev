Riferimento per il salvataggio di file, impostazioni e dati nello sviluppo di app Windows (Windows App SDK / WinRT). StorageFile, StorageFolder, IStorageItem, FileIO, PathIO, CachedFileManager, DataReader, DataWriter di Windows.Storage. Impostazioni locali e roaming tramite ApplicationData, ApplicationDataContainer e ApplicationDataCompositeValue. Accesso ai file e autorizzazioni con FileOpenPicker, FileSavePicker, FolderPicker, StorageApplicationPermissions e KnownFolders. Serializzazione e persistenza con JsonObject, JsonArray, XmlDocument, SQLite ed EF Core.
