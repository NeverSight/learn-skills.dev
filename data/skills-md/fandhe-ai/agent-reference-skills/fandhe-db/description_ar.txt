مرجع لقاعدة البيانات المتخصصة في الاستعلام المتجهية المبنية بـ Rust، والتي تعمل محليًا أولاً (fandhe‑db) (متوافقة مع بروتوكول سلك PostgreSQL الإصدار 3)، تغطي محرك fandhe‑vector‑db‑engine / خادم fandhe‑vector‑db‑wire‑server. تشمل صيغة USING PLAN / USING OPERATION_ID، وضع الدقة/الاستدعاء، فهرس عكسي HNSW / BM25 / هجين RRF / إعادة ترتيب، استمرارية redb، المستأجر/قواعد أمان الصف (RLS)، نواة SIMD / wgpu، وعقدة خطأ wire_code. يرجى دائمًا الرد بلغة المستخدم.
