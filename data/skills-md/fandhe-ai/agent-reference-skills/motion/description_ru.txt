Библиотека анимаций Motion (ранее Framer Motion) — справочник. React‑компоненты: motion, AnimatePresence, AnimateView, LayoutGroup, LazyMotion, MotionConfig, Reorder. Хуки: useAnimate, useScroll, useSpring, useTransform, useMotionValue, useInView. API на чистом JavaScript: animate, scroll, inView, hover, press, stagger, spring, timeline, motionValue. Версия для Vue (motion‑v): директива v‑motion, composable useScroll и др., ограниченные компоненты Motion+ (Carousel, Cursor, Ticker, Typewriter, AnimateNumber). Переходы / компоновка / перетаскивание / жесты / SVG / анимация прокрутки, доступность, производительность, оптимизация бандла, устранение проблем.
