Motion bibliothèque d'animation (anciennement Framer Motion) – référence. Composants React : motion, AnimatePresence, AnimateView, LayoutGroup, LazyMotion, MotionConfig, Reorder. Hooks : useAnimate, useScroll, useSpring, useTransform, useMotionValue, useInView. API JavaScript vanilla : animate, scroll, inView, hover, press, stagger, spring, timeline, motionValue. Version Vue (motion‑v) : directive v‑motion, composable useScroll, etc., composants exclusifs Motion+ (Carousel, Cursor, Ticker, Typewriter, AnimateNumber). Transitions / layout / drag / gestes / SVG / animations de scroll, accessibilité, performance, optimisation du bundle, dépannage.
