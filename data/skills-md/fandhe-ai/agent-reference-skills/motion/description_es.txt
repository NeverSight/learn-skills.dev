Referencia de la biblioteca de animación Motion (antes Framer Motion). Componentes React: motion, AnimatePresence, AnimateView, LayoutGroup, LazyMotion, MotionConfig, Reorder. Hooks: useAnimate, useScroll, useSpring, useTransform, useMotionValue, useInView. API de JavaScript puro: animate, scroll, inView, hover, press, stagger, spring, timeline, motionValue. Versión Vue (motion-v): directiva v‑motion, composables como useScroll, componentes exclusivos de Motion+ (Carousel, Cursor, Ticker, Typewriter, AnimateNumber). Transiciones, layout, arrastre, gestos, SVG, animaciones de scroll, accesibilidad, rendimiento, optimización del bundle y solución de problemas.
