Motion 動畫庫（舊稱 Framer Motion）參考文件。React 元件包括 motion、AnimatePresence、AnimateView、LayoutGroup、LazyMotion、MotionConfig、Reorder。hooks 有 useAnimate、useScroll、useSpring、useTransform、useMotionValue、useInView。原生 JavaScript API 包含 animate、scroll、inView、hover、press、stagger、spring、timeline、motionValue。Vue 版（motion-v）提供 v-motion 指令、useScroll 等 composable，以及 Motion+ 限定元件（Carousel、Cursor、Ticker、Typewriter、AnimateNumber）。支援 transitions、layout、drag、gestures、SVG、scroll 動畫，並涵蓋可存取性、效能、套件體積優化與疑難排解。
