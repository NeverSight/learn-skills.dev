Motion アニメーションライブラリ（旧称 Framer Motion）のリファレンスです。React コンポーネントには motion、AnimatePresence、AnimateView、LayoutGroup、LazyMotion、MotionConfig、Reorder が含まれます。フックとして useAnimate、useScroll、useSpring、useTransform、useMotionValue、useInView があります。Vanilla JS API では animate、scroll、inView、hover、press、stagger、spring、timeline、motionValue が提供されています。Vue 版（motion‑v）には v-motion ディレクティブ、useScroll などの composable、Motion+ 限定コンポーネント（Carousel、Cursor、Ticker、Typewriter、AnimateNumber）があります。transitions、layout、drag、gestures、SVG、scroll アニメーション、アクセシビリティ、パフォーマンス、バンドル最適化、トラブルシューティングなどもカバーしています。
