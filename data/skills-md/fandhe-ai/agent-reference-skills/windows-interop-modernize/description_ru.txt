Справочник по совместимости и модернизации разработки Windows‑приложений (Win32 / WPF / WinForms). Win32 API, CreateWindowExW, WNDPROC, цикл сообщений, COM (IUnknown, CoCreateInstance, ComPtr), CsWin32, windows-rs, C++/WinRT (winrt::com_ptr, IAsyncOperation, IDL, совместимость ABI), C#/WinRT (cswinrt, ComWrappers, AOT/обрезка, WindowNative), XAML Islands (DesktopWindowXamlSource, DesktopChildSiteBridge, WindowsXamlManager), совместимость WPF/WinForms (HwndHost, HwndSource, WindowsFormsHost, ElementHost), миграция из UWP в Windows App SDK / WinUI 3 (соответствие пространств имён, AppWindow, DispatcherQueue, .NET Upgrade Assistant).
