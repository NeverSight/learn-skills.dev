Riferimento per l'interoperabilità e la modernizzazione dello sviluppo di app Windows (interop Win32 / WPF / WinForms). Win32 API, CreateWindowExW, WNDPROC, ciclo dei messaggi, COM (IUnknown, CoCreateInstance, ComPtr), CsWin32, windows-rs, C++/WinRT (winrt::com_ptr, IAsyncOperation, IDL, interoperabilità ABI), C#/WinRT (cswinrt, ComWrappers, AOT/trimming, WindowNative), XAML Islands (DesktopWindowXamlSource, DesktopChildSiteBridge, WindowsXamlManager), interoperabilità WPF/WinForms (HwndHost, HwndSource, WindowsFormsHost, ElementHost), migrazione da UWP a Windows App SDK / WinUI 3 (mappatura dei namespace, AppWindow, DispatcherQueue, .NET Upgrade Assistant).
