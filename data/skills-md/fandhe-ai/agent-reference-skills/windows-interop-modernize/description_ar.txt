دليل التفاعل وتحديث تطوير تطبيقات Windows (التكامل بين Win32 / WPF / WinForms). Win32 API، CreateWindowExW، WNDPROC، حلقة الرسائل، COM (IUnknown، CoCreateInstance، ComPtr)، CsWin32، windows-rs، C++/WinRT (winrt::com_ptr، IAsyncOperation، IDL، التفاعل مع ABI)، C#/WinRT (cswinrt، ComWrappers، AOT/الاقتطاع، WindowNative)، جزر XAML (DesktopWindowXamlSource، DesktopChildSiteBridge، WindowsXamlManager)، التفاعل بين WPF/WinForms (HwndHost، HwndSource، WindowsFormsHost، ElementHost)، الانتقال من UWP إلى Windows App SDK / WinUI 3 (تطابق أسماء الفضاءات، AppWindow، DispatcherQueue، .NET Upgrade Assistant).
