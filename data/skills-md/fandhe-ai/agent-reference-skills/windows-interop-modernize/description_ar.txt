مرجع التفاعل وتحديث تطوير تطبيقات Windows (التشغيل المتبادل بين Win32 / WPF / WinForms). Win32 API، CreateWindowExW، WNDPROC، حلقة الرسائل، COM (IUnknown، CoCreateInstance، ComPtr)، CsWin32، windows-rs، C++/WinRT (winrt::com_ptr، IAsyncOperation، IDL، التفاعل المتبادل مع ABI)، C#/WinRT (cswinrt، ComWrappers، AOT/التقليص، WindowNative)، XAML Islands (DesktopWindowXamlSource، DesktopChildSiteBridge، WindowsXamlManager)، التفاعل بين WPF/WinForms (HwndHost، HwndSource، WindowsFormsHost، ElementHost)، الانتقال من UWP إلى Windows App SDK / WinUI 3 (تطابق الأسماء، AppWindow، DispatcherQueue، .NET Upgrade Assistant).
