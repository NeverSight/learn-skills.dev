Référence d'interopérabilité et de modernisation du développement d'applications Windows (interopérabilité Win32 / WPF / WinForms). API Win32, CreateWindowExW, WNDPROC, boucle de messages, COM (IUnknown, CoCreateInstance, ComPtr), CsWin32, windows-rs, C++/WinRT (winrt::com_ptr, IAsyncOperation, IDL, interopérabilité ABI), C#/WinRT (cswinrt, ComWrappers, AOT/élagage, WindowNative), XAML Islands (DesktopWindowXamlSource, DesktopChildSiteBridge, WindowsXamlManager), interopérabilité WPF/WinForms (HwndHost, HwndSource, WindowsFormsHost, ElementHost), migration d'UWP vers Windows App SDK / WinUI 3 (mappage d'espaces de noms, AppWindow, DispatcherQueue, .NET Upgrade Assistant).
