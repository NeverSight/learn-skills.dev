Referencia de interoperabilidad y modernización para el desarrollo de aplicaciones Windows (interoperabilidad Win32 / WPF / WinForms). Win32 API, CreateWindowExW, WNDPROC, bucle de mensajes, COM (IUnknown, CoCreateInstance, ComPtr), CsWin32, windows-rs, C++/WinRT (winrt::com_ptr, IAsyncOperation, IDL, interoperabilidad ABI), C#/WinRT (cswinrt, ComWrappers, AOT/recorte, WindowNative), XAML Islands (DesktopWindowXamlSource, DesktopChildSiteBridge, WindowsXamlManager), interoperabilidad WPF/WinForms (HwndHost, HwndSource, WindowsFormsHost, ElementHost), migración de UWP a Windows App SDK / WinUI 3 (mapeo de espacios de nombres, AppWindow, DispatcherQueue, .NET Upgrade Assistant).
