مرجع SDK لوكلاء OpenAI API (developers.openai.com) بلغة Python / TypeScript. يشمل: Agent، Runner، handoffs، guardrails، tracing، الأدوات المدمجة (بحث ويب، بحث في الملفات، استخدام الكمبيوتر، مفسر الكود، توليد الصور)، أدوات الوظائف، مخازن المتجهات، موصلات MCP (بروتوكول سياق النموذج)، وضع الخلفية، تنسيق متعدد الوكلاء، SandboxAgent (بيئة تنفيذ معزولة).
