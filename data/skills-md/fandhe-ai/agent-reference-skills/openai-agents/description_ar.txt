مرجع SDK لوكلاء OpenAI API (developers.openai.com) بلغة Python / TypeScript. الوكيل (Agent)، المشغِّل (Runner)، التحويلات (handoffs)، الضوابط (guardrails)، التتبع (tracing)، الأدوات المدمجة (البحث على الويب، البحث في الملفات، استخدام الحاسوب، مفسِّر الشيفرة، توليد الصور)، أدوات الوظائف (function tools)، مخازن المتجهات (vector stores)، موصلات بروتوكول سياق النموذج (MCP)، الوضع الخلفي (background mode)، تنسيق الوكلاء المتعددين (multi-agent orchestration)، SandboxAgent (بيئة تنفيذ معزولة).
