Better Auth (TypeScript 認証フレームワーク) v1.7 リファレンス。 Autenticación y autorización, registro e inicio de sesión, gestión de sesiones, OAuth, claves de acceso, autenticación de dos factores (2FA / TOTP), SSO / SAML, SCIM, proveedor de OAuth (OAuth 2.1 / OIDC), autorización MCP (@better-auth/mcp), infraestructura (dash / sentinel), plugins (organization, admin, magic-link, anonymous, etc.). betterAuth, createAuthClient, signUp, signIn, getSession. Integración con Next.js, Nuxt, SvelteKit, Hono, Express, Expo, TanStack, Effect。
