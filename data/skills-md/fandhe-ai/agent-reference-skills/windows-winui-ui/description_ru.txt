База UI‑референс для разработки Windows‑приложений (WinUI 3 / XAML). Панели компоновки Grid, StackPanel, Canvas, RelativePanel, SplitView, ScrollViewer; XAML‑разметка x:Bind, x:Name, x:Class, StaticResource, ThemeResource; присоединяемые свойства, свойства‑зависимости; стили и темы Style, ControlTemplate, DataTemplate, VisualStateManager, ResourceDictionary, Acrylic, Mica, SystemBackdrop; привязка данных Binding, INotifyPropertyChanged, ObservableCollection, IValueConverter, DataContext, MVVM; анимации Storyboard, DoubleAnimation, EasingFunction, ThemeTransition, ConnectedAnimation, ImplicitAnimation.
