Windows アプリ開発 (WinUI 3 / XAML) の UI 基盤リファレンスです。レイアウトパネルとしては、グリッド、スタックパネル、キャンバス、相対パネル、スプリットビュー、スクロールビューがあります。XAML マークアップでは x:Bind、x:Name、x:Class、StaticResource、ThemeResource が使われます。添付プロパティ、依存関係プロパティ、スタイル・テーマとしては Style、ControlTemplate、DataTemplate、VisualStateManager、ResourceDictionary、Acrylic、Mica、SystemBackdrop があります。データバインディングでは Binding、INotifyPropertyChanged、ObservableCollection、IValueConverter、DataContext、MVVM が利用されます。アニメーションには Storyboard、DoubleAnimation、EasingFunction、ThemeTransition、ConnectedAnimation、ImplicitAnimation があります。
