Référence des API graphiques et multimédias pour le développement d’applications Windows (DirectX / médias WinRT). Direct2D (ID2D1Factory, ID2D1DeviceContext, ID2D1Bitmap1, ID2D1Effect, ID2D1PathGeometry), DirectWrite (IDWriteFactory, IDWriteTextLayout, DWriteCore), Direct3D 11/12 (D3D11CreateDevice, chaîne d’échange DXGI, HLSL, état du pipeline D3D12), Microsoft.UI.Composition (Compositor, Visual, ExpressionAnimation, InteractionTracker, MicaController), capture caméra et écran (MediaCapture, MediaFrameReader, GraphicsCaptureSession, Windows Studio Effects), lecture audio/vidéo (MediaPlayer, MediaPlaybackSession, AudioGraph, MediaTranscoder, AdaptiveMediaSource).
