Справочник по интегрированным API ОС для разработки приложений Windows (Windows App SDK / WinRT). DeviceInformation, DeviceWatcher, датчики (Accelerometer, Gyrometer, Compass, OrientationSensor, Pedometer, ActivitySensor), Bluetooth LE, USB, Serial, HID, Battery, HttpClient, StreamSocket, WebSocket, BackgroundDownloader/Uploader, NetworkInformation, PointerInput, KeyboardInput, FocusManager, DragAndDrop, IME/TextInput, Calendar, DateTimeFormatter, CurrencyFormatter, ResourceLoader (многоязычность и регионализация), PasswordVault, CryptographicBuffer, WindowsHello/Passkeys, WebAuthenticationBroker, Clipboard, DataTransferManager, Launcher, JumpList, TaskbarManager, SecondaryTile, StartupTask, ProtocolActivation.
