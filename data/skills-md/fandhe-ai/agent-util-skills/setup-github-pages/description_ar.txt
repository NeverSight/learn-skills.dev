قم بإنشاء وتحديث موقع توثيق على GitHub Pages بنفس تصميم **fandhe-frontend**. يتولى كل شيء دفعة واحدة: مولد مواقع ثابتة مبني على Rust، إدارة ملفات Markdown، النشر التلقائي عبر Actions، وإعدادات العلامة التجارية (جدول الموقع في nav.toml). استخدمه للعبارات التالية: “أريد النشر على GitHub Pages”، “إنشاء موقع توثيق”، “نفس تصميم fandhe-frontend”، “تحديث موقع Pages”، “تحديث التصميم إلى أحدث إصدار”. إذا رغبت في النشر على Firebase، استخدم **setup-firebase-hosting**؛ ولملفات HTML منفردة، استخدم **create-html-report**.
