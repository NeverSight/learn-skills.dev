Construisez et mettez à jour un site de documentation GitHub Pages avec le même design que fandhe-frontend. C’est une solution tout‑en‑un qui englobe un générateur de site statique basé sur Rust, la gestion du Markdown, le déploiement automatique via Actions et la configuration de la marque (la table du site dans nav.toml). Utilisez‑le pour « Je veux publier sur GitHub Pages », « créer un site de docs », « même design que fandhe-frontend », « mettre à jour le site Pages » ou « rafraîchir le design ». Si vous voulez publier sur Firebase, utilisez setup‑firebase‑hosting ; pour un rapport HTML ponctuel, utilisez create‑html‑report.
