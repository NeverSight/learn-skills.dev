使用與 fandhe-frontend 相同的設計，建立並更新 GitHub Pages 文件站點。它一次性處理所有工作——從基於 Rust 的靜態站點生成器（SSG）、Markdown 管理、Actions 自動部署，到品牌設定（nav.toml 中的 site 表）。在以下情境使用它：「我想在 GitHub Pages 發布」、「建立文件站點」、「與 fandhe-frontend 相同的設計」、「更新 Pages 站點」、「將設計刷新至最新」。如果想在 Firebase 上發布，請使用 setup-firebase-hosting；若只需單一 HTML 檔案，請使用 create-html-report。
