Создайте и обновляйте сайт документации на GitHub Pages с тем же дизайном, что и fandhe‑frontend. Он выполняет всё в один шаг — от статического генератора на Rust, управления Markdown и автоматического развертывания через Actions до настроек бренда (таблица «site» в nav.toml). Используйте его для «Хочу публиковать на GitHub Pages», «Создать сайт документации», «Тот же дизайн, что у fandhe‑frontend», «Обновить сайт Pages» или «Обновить дизайн до последней версии». Для публикации с Firebase используйте setup‑firebase‑hosting; для единого HTML‑отчёта — create‑html‑report.
