Construye y actualiza un sitio de documentación en GitHub Pages con el mismo diseño que fandhe-frontend. Maneja todo, desde un generador de sitios estáticos basado en Rust, gestión de Markdown, despliegue automático mediante Actions, hasta la configuración de marca (la tabla del sitio en nav.toml). Úsalo para “quiero publicar en GitHub Pages”, “crear un sitio de documentación”, “mismo diseño que fandhe-frontend”, “actualizar el sitio de Pages” y “poner al día el diseño”. Si deseas publicar en Firebase, usa setup-firebase-hosting; para un informe HTML único, usa create-html-report.
