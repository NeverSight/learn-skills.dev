Costruisci e aggiorna un sito di documentazione GitHub Pages con lo stesso design di fandhe‑frontend. Gestisce tutto in un unico passaggio—da un SSG basato su Rust, gestione del Markdown e distribuzione automatica tramite Actions, fino alle impostazioni del brand (la tabella site in nav.toml). Usalo per “Voglio pubblicare su GitHub Pages”, “creare un sito docs”, “stesso design di fandhe‑frontend”, “aggiornare il sito Pages” o “aggiornare il design all’ultima versione”. Se desideri pubblicare su Firebase, utilizza setup‑firebase‑hosting; per un report HTML a pagina singola, utilizza create‑html‑report.
