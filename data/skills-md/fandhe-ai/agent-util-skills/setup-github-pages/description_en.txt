Build and update a GitHub Pages documentation site with the same design as fandhe-frontend. It handles everything in one go, from a Rust‑based SSG, Markdown management, Actions automatic deployment, to brand settings (the site table in nav.toml). Use it for commands like “I want to publish on GitHub Pages,” “Create a docs site,” “Same design as fandhe-frontend,” “Update the Pages site,” “Refresh the design to the latest.” If you want to publish on Firebase, use setup-firebase-hosting; for a one‑off HTML, use create-html-report.
