Andamiaje una nueva habilidad como habilidades/<name>/SKILL.md. Automatiza constantemente todo, desde la comprobación de nombres y ubicaciones duplicados, la creación de SKILL.md, la configuración de enlaces simbólicos, la realización de controles de calidad, hasta el reflejo de CLAUDE.md. Úselo con comandos como "hacer habilidad", "añadir nueva habilidad", "crear habilidad", etc. Para añadir definiciones de agente, consulte create‑agent; para actualizar la documentación, consulte update‑docs.
