Живой тур по новому внедрённому коду. Объединяет /deep-trace, мост vscode-debug-mcp и playwright-cli для запуска целевого приложения в отладочной сессии, управления UI, паузы на отобранных точках останова внутри нового кода и озвучивания «это модальное окно — новое» — сопоставляя каждый момент UI с точным файлом:строкой. Используйте, когда пользователь хочет понять, где и как исполняется код функции, написанный ИИ, в работающем приложении («どの UI / どのロジックで動くのか分からない», «オンボーディングして», «/pr-tour»).
