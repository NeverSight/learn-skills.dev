Générez un site HTML statique de style DeepWiki local qui explique une base de code avec des chapitres numérotés, des diagrammes mermaid qui nomment de vrais symboles, et des citations chemin:ligne. Utilisez‑le lorsqu’on vous demande de créer un DeepWiki, un wiki de base de code, un site d’architecture ou un explicateur visuel de code.

Veuillez toujours répondre dans la langue de l’utilisateur.
