Создайте PR в GitHub для завершённой работы, затем запустите coderabbit‑resolver через проверку, CI, слияние и очистку. Передайте `cli`, чтобы добавить `@coderabbitai ignore` в тело PR и выполнить обзор с помощью CLI CodeRabbit вместо бота GitHub. Используйте, когда пользователь просит создать PR, а затем выполнить разрешение CodeRabbit. Ключевые слова: создать PR, CodeRabbit, слияние, CLI, @coderabbitai ignore.
