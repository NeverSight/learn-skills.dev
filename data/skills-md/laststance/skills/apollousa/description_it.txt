Crea una PR su GitHub per il lavoro completato, quindi esegui coderabbit-resolver attraverso revisione, CI, merge e pulizia. Passa `cli` per inserire `@coderabbitai ignore` nel corpo della PR e revisiona con il CLI di CodeRabbit invece del bot di GitHub. Usa quando: l'utente richiede la creazione di una PR seguita dalla risoluzione con CodeRabbit. Parole chiave: create PR, CodeRabbit, merge, CLI, @coderabbitai ignore.
