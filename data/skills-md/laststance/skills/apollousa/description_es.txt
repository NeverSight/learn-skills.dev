Crea un PR en GitHub para el trabajo completado, luego ejecuta coderabbit-resolver a través de revisión, CI, merge y limpieza. Pasa `cli` para colocar `@coderabbitai ignore` en el cuerpo del PR y revisar con la CLI de CodeRabbit en lugar del bot de GitHub. Úsalo cuando: el usuario solicite la creación de un PR seguida de la resolución con CodeRabbit. Palabras clave: crear PR, CodeRabbit, merge, CLI, @coderabbitai ignore.
