Crea un tour sequenziale passo‑passo di un percorso di codice reale: un albero dei file a sinistra, una freccia di sequenza per ogni clic e le funzioni o i callback che vengono eseguiti in quel passaggio. Per React, mostra anche il componente che chiama l’hook, la gerarchia dei componenti sopra di esso e il percorso di Props o Context. Usa quando l’utente richiede una sequenza che può avanzare un passo alla volta, un albero dei file accanto a un flusso di chiamate, il chiamante dell’hook, o 「ステップで進める」 「ファイルツリー付きのシーケンス」「Props の経路」「Context の受け渡し」.
