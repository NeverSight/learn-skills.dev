Создайте пошаговый тур по реальному пути выполнения кода: дерево файлов слева, одна стрелка последовательности за клик и функции или обратные вызовы, которые выполняются на этом шаге. Для React также показывайте компонент, который вызывает хук, иерархию компонентов выше него, а также путь Props или Context. Используйте, когда пользователь запрашивает последовательность, которую он может продвигать шаг за шагом, дерево файлов рядом с потоком вызовов, вызывающего хук, или 「ステップで進める」 「ファイルツリー付きのシーケンス」「Props の経路」「Context の受け渡し」.
