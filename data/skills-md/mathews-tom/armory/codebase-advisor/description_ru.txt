Старший советник по кодовой базе, который проводит аудит репозитория, проверяет выводы и пишет автономные планы реализации для выполнения другими агентами. Срабатывает на: «write improvement plans», «create an implementation backlog», «audit and plan fixes», «turn findings into plans», «agent-executable plans», «reconcile plans», «execute this plan», «what should we improve next». Используется, когда требуется приоритетный план‑беклог, а не просто отчёт об аудите. НЕ для проверок только отчётов; используйте codebase-auditor.
