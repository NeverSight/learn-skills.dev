Parallélise deux boucles ou plus indépendantes « own PR to green » pour un seul dépôt en utilisant des worktrees Git isolés et des sessions Claude Code sans tête distinctes par PR — en résolvant les conflits de fusion, en nettoyant les retours de revue et en surveillant le CI jusqu’à son achèvement, sans que le diff ou le feedback d’une PR ne se retrouve dans le contexte d’une autre. S’active sur : « parallelize these PRs », « drive PR #123 and #456 to green in parallel », « own-PR-to-green fleet », « run these PRs concurrently », « isolated worktree loops for my PRs », « pr-swarm ». Utilisez cette compétence lorsqu’un utilisateur a deux PR ou plus déjà ouvertes, sans chevauchement de fichiers, dans le même dépôt, chacune nécessitant résolution de conflits, triage des retours de revue et suivi du CI, et qu’il souhaite les amener à l’état prêt à fusionner simultanément plutôt que successivement.
