Parallelisiert zwei oder mehr unabhängige „eigene PR zum Grün“-Schleifen für ein einzelnes Repository mithilfe isolierter Git‑Worktrees und separater headless Claude‑Code‑Sitzungen pro PR — löst Merge‑Konflikte, bereinigt Review‑Feedback und überwacht die CI bis zum Abschluss, ohne dass der Diff oder das Feedback einer PR in den Kontext einer anderen gelangt. Auslöser: „parallelize these PRs“, „drive PR #123 and #456 to green in parallel“, „own‑PR‑to‑green fleet“, „run these PRs concurrently“, „isolated worktree loops for my PRs“, „pr‑swarm“. Verwende diese Fähigkeit, wenn ein Nutzer zwei oder mehr bereits offene, dateidisjunkte Pull‑Requests im selben Repository hat, die jeweils Konfliktlösung, Review‑Feedback‑Triagierung und CI‑Monitoring benötigen und gleichzeitig bis zur Merge‑Bereitschaft gebracht werden sollen, statt nacheinander.
