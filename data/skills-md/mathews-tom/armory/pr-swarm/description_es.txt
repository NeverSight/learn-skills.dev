Paraleliza dos o más bucles independientes de “propia PR a verde” para un solo repositorio usando worktrees de git aislados y sesiones sin cabeza de Claude Code separadas por PR — resolviendo conflictos de fusión, limpiando comentarios de revisión y vigilando CI hasta su finalización sin que el diff o los comentarios de una PR se filtren al contexto de otra. Se activa con: “paralelizar estas PR”, “llevar PR #123 y #456 a verde en paralelo”, “flota propia‑PR‑a‑verde”, “ejecutar estas PR concurrentemente”, “bucles de worktree aislados para mis PR”, “pr‑swarm”. Usa esta habilidad cuando un usuario tiene dos o más pull requests ya abiertos, con archivos disjuntos, en el mismo repositorio, que necesitan resolución de conflictos, triaje de comentarios de revisión y monitorización de CI, y quiere llevarlas a estado listo para merge al mismo tiempo en lugar de una tras otra.
