Параллелизует два и более независимых цикла «своего PR до состояния green» для единого репозитория, используя изолированные рабочие деревья Git и отдельные безголовые сессии Claude Code для каждого PR — решая конфликты слияния, устраняя отзывы ревью и наблюдая за CI до завершения, при этом различия или отзывы одного PR не «просачиваются» в контекст другого. Срабатывает на команды: «parallelize these PRs», «drive PR #123 and #456 to green in parallel», «own-PR-to-green fleet», «run these PRs concurrently», «isolated worktree loops for my PRs», «pr-swarm». Используйте этот навык, когда у пользователя есть два и более уже открытых, не пересекающихся по файлам pull‑request'а в одном репозитории, каждый из которых требует разрешения конфликтов, обработки отзывов ревью и мониторинга CI, и он хочет привести их к готовности к слиянию одновременно, а не последовательно.
