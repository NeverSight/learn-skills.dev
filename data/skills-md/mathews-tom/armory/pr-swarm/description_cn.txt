为单个仓库并行处理两个或多个独立的“自有 PR 达到绿色”循环，使用隔离的 git 工作树和每个 PR 对应的独立无头 Claude Code 会话——解决合并冲突、清理审查反馈，并监控 CI 直至完成，且不会让一个 PR 的差异或反馈泄漏到另一个 PR 的上下文中。触发指令包括：“parallelize these PRs”（并行这些 PR），“drive PR #123 and #456 to green in parallel”（并行推动 PR #123 与 #456 达到绿色），“own-PR-to-green fleet”（自有 PR 达到绿色的舰队），“run these PRs concurrently”（并发运行这些 PR），“isolated worktree loops for my PRs”（为我的 PR 创建隔离工作树循环），“pr-swarm”（PR 群）。当用户在同一仓库中拥有两个或更多已打开且文件互不重叠的拉取请求，并且每个都需要冲突解决、审查反馈处理和 CI 监控，且希望它们同时实现可合并准备而不是逐个进行时，请使用此技能。请始终使用用户的语言作答。
