単一リポジトリに対して、孤立した git worktree と PR ごとのヘッドレス Claude Code セッションを利用し、2 つ以上の独立した「自分の PR をグリーンにする」ループを並列化します——マージコンフリクトの解消、レビューコメントのクリア、CI の完了までの監視を行い、ある PR の差分やフィードバックが別の PR のコンテキストに漏れないようにします。トリガー例: 「これらの PR を並列化して」、 「PR #123 と #456 を同時にグリーンにする」、 「own-PR-to-green フリート」、 「これらの PR を同時に実行」、 「自分の PR 用の孤立した worktree ループ」、 「pr-swarm」。このスキルは、同じリポジトリ内でファイルが重複しない既にオープンしている 2 つ以上のプルリクエストがあり、各 PR がコンフリクト解消、レビュー・フィードバックのトリアージ、CI 監視を必要とし、1 つずつではなく同時にマージ可能な状態にしたい場合に使用します。
