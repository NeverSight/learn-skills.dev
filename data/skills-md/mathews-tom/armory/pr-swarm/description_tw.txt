將單一儲存庫中兩個或多個獨立的「自有 PR 變綠」循環進行平行化，使用隔離的 git worktree 並為每個 PR 建立獨立的無頭 Claude Code 工作階段——解決合併衝突、清除審查回饋，並觀察 CI 執行至完成，且不會讓一個 PR 的差異或回饋洩漏至另一個的上下文中。觸發詞包括：「parallelize these PRs」（平行化這些 PR）、「drive PR #123 and #456 to green in parallel」（同時推動 PR #123 與 #456 變綠）、「own-PR-to-green fleet」（自有 PR 變綠車隊）、「run these PRs concurrently」（同時執行這些 PR）、「isolated worktree loops for my PRs」（我的 PR 隔離 worktree 循環）、「pr-swarm」（PR 群）等。當使用者在同一儲存庫中已有兩個或以上已開啟且檔案不重疊的 pull request，需要進行衝突解決、審查回饋整理與 CI 監控，且想要同時將它們推至可合併的狀態，而不是逐一處理時，請使用此技能。
