Создаёт каркас контекста агента для каждого репозитория, чтобы кодирующие агенты использовали единые правила трекера задач, словарь меток триажа, глоссарий домена, структуру ADR и конвенции передачи. Срабатывает на: «установить контекст проекта», «настроить документы агента», «создать CONTEXT.md», «настроить рабочий процесс агента», «настройка трекера задач агента», «метки триажа», «глоссарий домена для агентов». Используйте, когда репозиторию нужны постоянные файлы контекста до планирования, триажа, отладки, TDD, архитектурного обзора или реализации многопоточных (многоагентных) систем.
