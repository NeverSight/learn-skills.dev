Stellt pro Repository den Agenten‑Kontext bereit, sodass Coding‑Agents dieselben Issue‑Tracker‑Regeln, das Vokabular für Triage‑Labels, das Domänen‑Glossar, das ADR‑Layout und die Übergabekonventionen teilen. Löst aus bei: „Projektkontext einrichten“, „Agentendokumentation konfigurieren“, „CONTEXT.md erstellen“, „Agent‑Workflow einrichten“, „Agent‑Issue‑Tracker einrichten“, „Triage‑Labels“, „Domänen‑Glossar für Agents“. Verwenden, wenn ein Repository dauerhafte Kontextdateien vor Planung, Triage, Debugging, TDD, Architektur‑Review oder Multi‑Agent‑Implementierung benötigt.
