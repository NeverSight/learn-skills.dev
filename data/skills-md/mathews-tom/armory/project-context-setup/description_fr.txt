Prépare le cadre contextuel d'agent par dépôt afin que les agents de codage partagent les mêmes règles du suivi des tickets, le vocabulaire des étiquettes de triage, le glossaire du domaine, la mise en page des ADR et les conventions de transfert. S'active sur : « mettre en place le contexte du projet », « configurer la documentation de l'agent », « créer CONTEXT.md », « configurer le flux de travail de l'agent », « configuration du suivi des tickets de l'agent », « étiquettes de triage », « glossaire du domaine pour les agents ». À utiliser lorsqu'un dépôt a besoin de fichiers contextuels durables avant la planification, le triage, le débogage, le TDD, la revue d'architecture ou la mise en œuvre multi‑agents.
