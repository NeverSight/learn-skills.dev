Auditoría de almacenamiento en disco de solo lectura para un repositorio o la raíz del espacio de trabajo. Mide la huella de los proyectos, identifica dependencias reconstruibles, clasifica los datos locales y las rutas protegidas por Git, y reporta la actividad del proyecto sin modificar archivos. Se activa con: "audit disk space", "storage audit", "find removable build artifacts", "which projects use the most space", "cleanup commands but do not run them", "analyze repository storage", "workspace disk cleanup". Utiliza esta habilidad cuando un desarrollador necesita recomendaciones de recuperación de espacio respaldadas por evidencia pero debe mantener el control de cada eliminación.
