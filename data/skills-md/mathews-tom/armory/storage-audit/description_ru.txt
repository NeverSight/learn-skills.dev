Только чтение аудит дискового хранилища для репозитория или корня рабочего пространства. Измеряет отпечатки проекта, выявляет перестраиваемые зависимости, классифицирует локальные данные и пути, защищённые Git, и сообщает о «живости» проекта без изменения файлов. Срабатывает по запросам: «audit disk space», «storage audit», «find removable build artifacts», «which projects use the most space», «cleanup commands but do not run them», «analyze repository storage», «workspace disk cleanup». Используйте эту возможность, когда разработчику нужны рекомендации по восстановлению места на основе доказательств, но при этом он должен сохранять контроль над каждым удалением.
