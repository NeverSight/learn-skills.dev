Audit de validation pré-soumission pour les articles arXiv couvrant le source TeX, le PDF, les figures, les métadonnées, la bibliographie, l’organisation des fichiers et les analyses d’erreurs courantes. Produit un rapport de réussite/échec avec des corrections spécifiques selon les exigences d’arXiv. Se déclenche sur : « check my arXiv submission », « validate for arXiv », « arXiv preflight », « ready for arXiv », « arxiv check », « arxiv submission readiness ». Companion to manuscript-review (prose), manuscript-provenance (code), arxiv-figures, arxiv-package.
