Usar cuando un usuario proporciona una ruta de repositorio local o una URL remota de Git y pide “enséñame este repositorio”, “explica este código de forma simple”, “muestra cómo funciona este sistema”, “ayúdame a usar este proyecto”, “incórpórame a este repositorio” o “muéstrame cómo construir sobre él”, especialmente cuando el resultado debe ser una guía visual o HTML multipágina. No es para auditorías, referencias de API o diagramas solo de arquitectura.

Por favor, responde siempre en el idioma del usuario.
