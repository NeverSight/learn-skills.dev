Utilisez lorsque qu’un utilisateur fournit un chemin de dépôt local ou une URL Git distante et demande « teach me this repo », « explain this codebase simply », « show how this system works », « help me use this project », « onboard me to this repository », ou « show me how to build on it », en particulier lorsque le résultat doit être un guide visuel ou un guide HTML multipage. Pas pour les audits, les références d’API ou les diagrammes d’architecture uniquement.

Veuillez toujours répondre dans la langue de l’utilisateur.
