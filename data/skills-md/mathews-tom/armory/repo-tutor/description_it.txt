Usa quando un utente fornisce un percorso di repository locale o un URL Git remoto e chiede di “insegnarmi questo repository”, “spiegare semplicemente questa codebase”, “mostrare come funziona questo sistema”, “aiutarmi a usare questo progetto”, “farmi fare onboarding su questo repository” o “mostrami come sviluppare su di esso”, soprattutto quando il risultato dovrebbe essere una guida visiva o HTML multipagina. Non è destinato ad audit, riferimenti API o diagrammi solo di architettura.

Rispondi sempre nella lingua dell'utente.
