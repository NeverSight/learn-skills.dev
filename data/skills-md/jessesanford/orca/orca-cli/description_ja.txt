`orca` CLI を使って、Orca が管理するワークツリー、フォルダーコンテキスト、端末、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザを操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関係する場合は、生の git worktree やアドホック PTY、Computer Use よりもこちらを優先してください。CLI、ファイルシステム、API で実行できない GUI 操作が必要な可視ウィンドウがある場合にのみ、Computer Use を使用します。

常にユーザーの言語で返答してください。
