قم بتشغيل شجرات العمل التي تديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والكيانات، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج من خلال سطر أوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل ذلك على شجرة git العادية، أو PTYs المؤقتة، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم "Computer Use" فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به. يرجى دائمًا الرد بلغة المستخدم.
