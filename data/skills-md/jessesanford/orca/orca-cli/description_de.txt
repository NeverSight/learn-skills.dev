Betreibe von Orca verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaum‑Kommentare und Orcas eingebetteten Browser über die `orca`‑CLI. Verwende es, wenn der Benutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Ziehe es rohen Git‑Worktree, ad‑hoc PTYs oder Computer Use vor, wenn Orca‑Zustand involviert ist. Nutze Computer Use nur, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die eine CLI, das Dateisystem oder eine API nicht ausführen kann.

Bitte immer in der Sprache des Benutzers antworten.
