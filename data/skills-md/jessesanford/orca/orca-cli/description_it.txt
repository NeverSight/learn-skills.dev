Operare worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser integrato di Orca tramite il CLI `orca`. Utilizzare quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferirlo rispetto a git worktree grezzo, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Utilizzare Computer Use solo quando è necessaria una finestra visibile che richiede il controllo GUI che un CLI, file system o API non può fare.
