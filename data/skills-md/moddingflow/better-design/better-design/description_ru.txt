Разрабатывать, улучшать и проверять UI/UX для приложений, веб‑сайтов, нативных интерфейсов и игр: художественное направление, вытекающее из продукта, согласованная визуальная система, хранящаяся в файле проекта DESIGN.md (читайте сначала, создаётся при отсутствии, единственный источник значений интерфейса), измеренная геометрия макета (равные отступы, общие линии выравнивания, контент, центрированный внутри небольших элементов управления, без обрезки и касаний краёв контейнера), каталог паттернов AI‑slop, отвергающих повествование страницы и избыточный вспомогательный текст, живой язык анимаций (отзывы на нажатие, переходы, хореография, уменьшенное движение), ультра‑минималистичный стиль по умолчанию, похожий на Apple, набор подпишиваемых сигнатурных эффектов, понятные действия, доступность, drag‑and‑drop, предусмотренный с самого начала (области броска для каждой загрузки), и реальные состояния (включая скелетные загрузчики и заставку загрузки) без AI‑slop. Использовать для создания интерфейсов, редизайнов, целевых UI‑изменений, полировки анимаций и взаимодействий, планов дизайна и UX‑аудитов; не использовать для задач, связанных исключительно с бекендом.
