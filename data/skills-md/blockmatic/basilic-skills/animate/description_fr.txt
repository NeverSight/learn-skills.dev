Créez une animation à partir de zéro, en prenant les décisions dans l'ordre qui détermine si elle se sent bien — si elle s'anime, quel but, quel outil, quelles propriétés, quelle courbe et quelle durée, comment elle s'interrompt, comment elle sort. Écrit la mise en œuvre. Utilisez-la lorsqu'on vous demande d'animer quelque chose, d'ajouter du mouvement, de faire en sorte qu'un composant se sente vivant ou de créer une transition. Pour critiquer les animations de mouvement existantes, utilisez des animations de révision ; pour auditer une base de code entière, utilisez des animations d'amélioration.
