Используйте при создании шаблонов HTML‑письм с компонентами React, добавлении визуального редактора писем в приложение с помощью визуального редактора React Email, рендеринге писем в HTML или отправке писем через Resend. Охватывает приветственные письма, сброс пароля, уведомления, подтверждения заказов, информационные бюллетени, транзакционные письма и встраиваемый компонент редактора писем.
