À utiliser lors de la création de modèles d'e-mails HTML avec des composants React, de l'ajout d'un éditeur d'e-mails visuel à une application à l'aide de l'éditeur visuel React Email, du rendu d'e-mails en HTML ou de l'envoi d'e-mails avec Resend. Couvre les e-mails de bienvenue, les réinitialisations de mot de passe, les notifications, les confirmations de commande, les bulletins d'information, les e-mails transactionnels et le composant d'éditeur d'e-mail intégrable.
