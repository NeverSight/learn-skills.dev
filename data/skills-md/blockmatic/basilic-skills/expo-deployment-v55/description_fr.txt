Service EAS (payant). Déployez des applications Expo SDK 57 sur les stores avec EAS : construisez et soumettez à l’App Store iOS, au Google Play Store et à TestFlight, configurez les profils de build et de soumission dans eas.json, gérez les versions et les numéros de build des applications, et publiez les métadonnées de l’App Store ainsi que l’ASO. Utilisez-le chaque fois que l’utilisateur souhaite déployer, publier ou livrer une application en production ou sur les stores, prépare un build de production, exécute eas build ou eas submit, envoie sur TestFlight, augmente les numéros de version ou de build, ou configure les métadonnées de la fiche produit du store. Pour déployer un site web Expo ou des routes API, utilisez la compétence eas‑hosting.
