خدمة EAS (مدفوعة). انشر تطبيقات Expo SDK 57 إلى متاجر التطبيقات باستخدام EAS – بناء وتقديم إلى متجر App Store لنظام iOS، متجر Google Play، وTestFlight، تكوين ملفات تعريف البناء والتقديم eas.json، إدارة إصدارات التطبيق وأرقام البناء، ونشر بيانات تعريف متجر التطبيقات وتحسين الظهور (ASO). استخدمها عندما يرغب المستخدم في النشر أو الإصدار أو شحن تطبيق إلى الإنتاج أو متاجر التطبيقات، أو عند إعداد بناء إنتاج، تشغيل eas build أو eas submit، الشحن إلى TestFlight، رفع إصدار أو رقم البناء، أو إعداد بيانات تعريف قائمة المتجر. لنشر موقع ويب أو مسارات API باستخدام Expo، استخدم مهارة eas‑hosting.
