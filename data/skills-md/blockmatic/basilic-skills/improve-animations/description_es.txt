Inspeccione el código de animación y movimiento de una base de código como asesor principal de movimiento, luego produzca una auditoría priorizada y planes de implementación autónomos para que otros agentes (o modelos más baratos) los ejecuten. Solo lectura en el código fuente: planifica mejoras, no las aplica. Se usa cuando el usuario pide "mejorar las animaciones", "auditar el movimiento", "hacer que esta aplicación se sienta mejor" o quiere una hoja de ruta de correcciones de animación en lugar de una revisión de un solo diff.
