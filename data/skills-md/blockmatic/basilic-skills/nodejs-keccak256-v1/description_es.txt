Evita los errores de hash de Ethereum en JavaScript y TypeScript. El sha3-256 de Node es NIST SHA3, no Ethereum Keccak-256, y rompe silenciosamente selectores, firmas, ranuras de almacenamiento y derivación de direcciones. Utilícelo cuando haga hashing para Ethereum en JavaScript o TypeScript, o cuando un selector, firma, ranura de almacenamiento o dirección derivada sea incorrecta.
