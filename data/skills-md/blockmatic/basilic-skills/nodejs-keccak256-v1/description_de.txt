Verhindern Sie Ethereum-Hashing-Fehler in JavaScript und TypeScript. Node's sha3-256 ist NIST SHA3, nicht Ethereum Keccak-256, und unterbricht lautlos Selektoren, Signaturen, Speicherplätze und Adressableitung. Wird beim Hashing für Ethereum in JavaScript oder TypeScript verwendet oder wenn ein Selektor, eine Signatur, ein Speicherplatz oder eine abgeleitete Adresse falsch ist.
