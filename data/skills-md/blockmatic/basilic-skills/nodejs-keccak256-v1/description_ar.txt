تجنّب أخطاء التجزئة في إيثريوم عند العمل بـ JavaScript و TypeScript. تمثل دالة sha3‑256 في Node نسخة NIST SHA3، وليست Keccak‑256 الخاصة بإيثريوم، مما يؤدي إلى كسر المُحدِّدات، والتوقيعات، وخانات التخزين، واستخلاص العناوين بصمت. استخدمها عند التجزئة لإيثريوم في JavaScript أو TypeScript، أو عندما يكون المُحدِّد أو التوقيع أو خانة التخزين أو العنوان المستنتج غير صحيح.
