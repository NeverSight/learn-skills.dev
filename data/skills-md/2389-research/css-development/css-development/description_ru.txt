Обрабатывает разработку CSS и Tailwind — семантическое именование классов, композицию @apply, режим тёмной темы по умолчанию, создание компонентов, рефакторинг inline/utility‑стилей и аудиты CSS. Используйте при работе с CSS, Tailwind, @apply, стилизацией компонентов или тёмным режимом. Доступные поднавыки: css-development:create-component, css-development:refactor, css-development:validate.
