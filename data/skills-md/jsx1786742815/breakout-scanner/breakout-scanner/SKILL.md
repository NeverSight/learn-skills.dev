**统一入口**：用户说「根据战法扫描」时，先判断属于哪个战法，再运行对应脚本取最新数据筛选，输出标的 + 操作注意事项。

## 执行流程（每次调用必须先取最新数据，不用缓存）

1. 识别用户要哪个战法（触发词路由）。
2. 运行对应脚本（实时拉东财数据 + 筛选）：
   ```bash
   # 突破战法
   python scripts/breakout_scanner.py [YYYYMMDD]
   # 低吸战法
   python scripts/pullback_scanner.py [YYYYMMDD]
   # 打板/接力 + 情绪周期（同一脚本，先诊断情绪再给打板候选）
   python scripts/emotion_scanner.py [YYYYMMDD]
   # 75A战法（圆弧底右侧刚抬头）
   python scripts/round75_scanner.py [YYYYMMDD]
   # 断层补涨（资金断层+主线内补涨位；可选第2参数=概念关键词，如"算力"）
   python scripts/gap_scanner.py [YYYYMMDD]
   python scripts/gap_scanner.py [YYYYMMDD] 算力
   ```
3. 输出符合条件的标的 + **每只票的操作注意事项**（买点/止损/目标位/离场信号）。
4. 诚实提示（不做应声虫）：主力资金为负、板块非主线、大盘未站上 MA20、或大盘高位时主动提示风险。
5. **基本面/错杀逻辑推票前必须先核验最新财报（2026-08-24 北新建材教训，强制）**：
   - 触发：推票逻辑涉及"基本面没坏 / 错杀 / 价值低估 / 高股息靠谱"时，**第一步**查最新一期财报，不查不许推。
   - 必查字段：最新营收及同比、归母净利及同比、扣非、分红决策、业绩预告/快报（数据源：东财 F10 财务分析接口 / datacenter 财报接口 / 新浪财经 F10，见 a-stock-data skill 的财报能力）。
   - 判定：净利负增长 / 不分红 / 现金流恶化 = 下跌可能本就是基本面驱动，不是错杀 → **不进"错杀反转"池**；只有"增速不差 + 跌因是资金面"才算错杀。
   - **数据源边界**：战法扫描用的快照接口（clist/ulist 的 PE/PB/股息率）只是东财算好的估值标签，**不含财报明细**（营收/净利/分红都取不到），永远不能替代财报核验。

## 四个战法核心速记

**突破战法**：放量突破（量比≥1.5，<1.3 无量突破 90% 假）→ 收盘站上前高/箱体上沿 → 回踩不破颈线；假突破（放量长上影/次日低开/2日内跌回颈线）立刻走；止损=颈线×0.97；目标=颈线+箱体高度；持有到滞涨。

**低吸战法**：强势股（近20日≥15%）回调缩量（量比<0.7）到 MA5/MA10、不破前低 → 低吸；止损=破 MA20；目标=前高；放量滞涨走。**资金分级（2026-08-20 修订）**：主力流入=正常；**小幅流出+缩量=洗盘观察（保留，看板块联动/事件催化，别一票否决）**；大额流出+放量=出货剔除。**⚠️ 大盘闸门（2026-08-24 4.5年回测落地）**：上证收盘站上 MA20 才允许低吸，跌破=闸门关闭只观察不买——回测弱市2023年低吸胜率仅38.7% vs 牛市2024-25年53-55%，弱市做低吸=慢性失血（脚本已内置 market_gate 检查）。

**打板/接力**：只做最高标/龙头，封单量大（>1亿）、换手健康（3-15%）；买点=首板/二板/龙头首次分歧转一致；卖点=次日竞价弱转强持有、高开不封板就走、破位炸板立即止损。

**情绪周期**：冰点→修复→发酵→高潮→退潮；冰点/修复埋伏龙头，高潮不追只减仓，**退潮期空仓（短线生死线）**。

**75A战法**：低位错杀→缩量圆弧底→右侧刚抬头（距颈线≥10%、MA5≥MA10）抢跑；止损=锅底×0.97；目标=颈线；仓位≤10%；高位圆弧=出货陷阱不碰。

**断层补涨战法**（2026-08-31 紫光股份 +8.53% 实盘验证）：①资金断层识别——主力净流入榜同一板块≥3只抱团=主线（资金只指路不选股）；②主线内选补涨位——**买资金第2-3名+当日涨幅最小(<5%)+贴MA20**（乖离-2%~+3%），买第二不买第一；③结构确认——一阳穿三线或长阳修复（昨收<MA20今收收回）+量比≥1.5；④排雷——ST/主力流出/价≥80/688,300,301排除；上证<MA20 弱市禁用。止损=MA10/破MA20，目标=60日前高，+5%/+10%分批减1/3。**非天天有，无断层空仓。**

## 四战法分工（不混用）
- 突破战法 = 右侧追主升（3-15 天波段，需大盘强）
- 低吸战法 = 回踩埋伏（容错高，适合震荡市/上班族）
- 打板/接力 = 情绪最强、风险最高（需极强情绪周期判断）
- 情绪周期 = 打板的前提诊断，退潮期所有战法都要空仓
- 75A战法 = 圆弧底右侧抢跑（左侧抄底变体，无确认信号、风险最高、仓位最轻≤10%）
- 断层补涨 = 板块资金抱团日的补涨位（先问"钱在哪个板块"再问"板块里买谁"，弱市禁用）
