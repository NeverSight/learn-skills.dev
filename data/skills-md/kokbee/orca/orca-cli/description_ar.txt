قم بتشغيل worktrees التي تديرها Orca، وسياقات المجلدات، والـ terminals، والمستودعات، والأتمتة، والملفات الناتجة (artifacts)، ومشاركة المهارات، وتعليقات worktree، والمتصفح المدمج في Orca عبر سطر الأوامر `orca` CLI. استخدم ذلك عندما يذكر المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على استخدام git worktree الخام، أو PTYs العارضة، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استعمل "استخدام الحاسوب" فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة GUI لا يمكن لسطر الأوامر أو نظام الملفات أو API إنجازه.
