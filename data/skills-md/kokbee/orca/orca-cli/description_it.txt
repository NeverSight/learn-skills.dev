Usare quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferirla rispetto a git worktree puro, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Usare Computer Use solo quando una finestra visibile richiede il controllo GUI che una CLI, filesystem o API non può fare.

Rispondi sempre nella lingua dell'utente.
