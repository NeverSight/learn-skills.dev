Orcaが管理する作業ツリー、フォルダーコンテキスト、端末、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そしてOrcaの組み込みブラウザは、`orca` CLI を通して操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関与している場合は、生の git worktree や臨時の PTY、あるいは Computer Use よりもこれを優先してください。CLI、ファイルシステム、API では対処できない GUI 操作が必要で、可視ウィンドウを制御しなければならない場合のみ Computer Use を使用します。

必ずユーザーの言語で回答してください。
