Toma un ticket de "ready" a una pull request abierta con sus verificaciones de aceptación ejecutadas y el ticket en "in‑review", y después de que alguien lo fusione, ejecuta los pasos post‑merge del ticket y muévelo a "done". Utilízalo cuando alguien solicite implementar, construir o retomar un ticket, o para finalizar un ticket cuya pull request haya sido fusionada.
