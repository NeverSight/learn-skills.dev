تعيين حدود مستودع الواجهة الأمامية والخلفية، وجرد مواقع استدعاء LLM API للموافقة، وتثبيت وتوصيل الحد الأدنى من متصفح ABTO أو التطبيق أو الخادم SDKs، والحفاظ على ارتباط معرف الجهاز وتتبعه، والتوصية بنظام الاشتراك أو الأحداث المخصصة، والتحقق من تكامل ABTO الناتج. يُستخدم لإعداد ABTO، أو التحديثات، أو استكشاف الأخطاء وإصلاحها، أو الاتصال بالبوابة، أو جمع الأحداث، أو وضع المفاتيح، أو عمليات التحقق من التكامل الشامل عبر المتصفح JavaScript، وNode.js، وPython، وFlutter/Dart، وAndroid/Kotlin، وiOS/macOS.
