Mappare i confini del repository frontend e backend, fare l'inventario dei siti di chiamata API LLM per l'approvazione, installare e collegare gli SDK minimi del browser, dell'app o del server ABTO, preservare l'id_dispositivo e la correlazione di traccia, consigliare il sistema di attivazione o eventi personalizzati e verificare l'integrazione ABTO risultante. Da utilizzare per la configurazione ABTO, gli aggiornamenti, la risoluzione dei problemi, le chiamate al gateway, la raccolta di eventi, il posizionamento delle chiavi o i controlli di integrazione end-to-end nel browser JavaScript, Node.js, Python, Flutter/Dart, Android/Kotlin e iOS/macOS.
