تشغيل أشجار العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر سطر الأوامر `orca`. يُستخدم عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". كما يتولى عمل الطرفية لجلسة واحدة: "session"، "sub-agent"، "create a session"، "stop a session"، "fork a session"، "attach to a session"، "worktree session"، واستكشاف الأخطاء وإصلاحها في طرفية الوكيل العالقة أو غير المضبوطة. يُفضَّل عليه استخدام شجرة git الخام، أو PTYs المؤقتة، أو استخدام Computer Use عندما تكون حالة Orca متضمنة. استخدم `orchestration` بدلاً من ذلك لتوزيع عدة وكلاء في وقت واحد أو للإشراف عليهم. استخدم Computer Use فقط عندما تحتاج نافذة مرئية إلى التحكم في الواجهة الرسومية الذي لا يستطيع سطر الأوامر أو نظام الملفات أو API القيام به.
