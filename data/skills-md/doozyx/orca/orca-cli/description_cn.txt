通过 `orca` CLI 操作 Orca 管理的工作树、文件夹上下文、终端、仓库、自动化、制品、技能共享、工作树评论以及 Orca 的内嵌浏览器。当用户说 “$orca-cli”、 “Orca worktree”、 “child worktree”、 “spawn codex/claude in a worktree”、 “read/wait/send Orca terminal”、 “handoff”/“handover”/“give this to another agent”、 “Orca browser”、 “orca artifacts” 或 “share skills” 时使用。它还负责单会话终端工作：“session”、 “sub‑agent”、 “create a session”、 “stop a session”、 “fork a session”、 “attach to a session”、 “worktree session”，以及排查卡住或配置错误的代理终端。涉及 Orca 状态时，优先使用它而不是原始 git 工作树、临时 PTY 或计算机使用。当需要一次性分配多个代理或监管它们时，请改用 `orchestration`。只有在需要对可见窗口进行 GUI 控制且 CLI、文件系统或 API 无法完成时才使用计算机使用。
