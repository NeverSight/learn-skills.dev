Orca가 관리하는 워크트리, 폴더 컨텍스트, 터미널, 저장소, 자동화, 아티팩트, 스킬 공유, 워크트리 댓글, 그리고 Orca의 내장 브라우저를 `orca` CLI를 통해 운영합니다. 사용자는 “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff”/“handover”/“give this to another agent”, “Orca browser”, “orca artifacts”, 또는 “share skills”라고 말할 때 이를 사용합니다. 또한 단일 세션 터미널 작업을 담당합니다: “session”, “sub-agent”, “create a session”, “stop a session”, “fork a session”, “attach to a session”, “worktree session” 및 멈추었거나 잘못 구성된 에이전트 터미널의 문제 해결. Orca 상태가 관련될 때는 일반 git 워크트리, 임시 PTY, 혹은 컴퓨터 사용보다 이를 선호하세요. 여러 에이전트를 한 번에 퍼뜨리거나 감독하려면 대신 `orchestration`을 사용합니다. CLI, 파일 시스템, API로는 제어할 수 없는 가시적인 창의 GUI 제어가 필요할 때만 컴퓨터 사용을 이용하세요.
