Opera los worktrees gestionados por Orca, contextos de carpetas, terminales, repositorios, automatizaciones, artefactos, compartición de habilidades, comentarios de worktree y el navegador incrustado de Orca a través de la CLI `orca`. Utilízalo cuando el usuario diga "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts", o "share skills". También gestiona el trabajo de terminal de sesión única: "session", "sub-agent", "create a session", "stop a session", "fork a session", "attach to a session", "worktree session", y la solución de problemas de un terminal de agente atascado o mal configurado. Préferelo sobre worktree git puro, PTYs ad hoc o Uso de Computadora cuando esté involucrado el estado de Orca. Usa `orchestration` en su lugar para desplegar varios agentes a la vez o supervisarlos. Usa Uso de Computadora solo cuando una ventana visible necesite control GUI que una CLI, el sistema de archivos o una API no puedan realizar.
