操作 Or​ca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、產出、技能分享、工作樹註解，以及 Or​ca 內嵌瀏覽器，皆透過 `orca` CLI 完成。當使用者說出以下任何詞彙時請使用此功能：「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」。此功能同時負責單一會話的終端機工作，例如：「session」、「sub‑agent」、「create a session」、「stop a session」、「fork a session」、「attach to a session」、「worktree session」，以及排除卡住或設定錯誤的代理終端機。若涉及 Or​ca 狀態，請優先使用此方式，而非直接使用 Git 工作樹、臨時 PTY 或一般的 Computer Use。若需要同時佈署多個代理或監督它們，請使用 `orchestration`；僅在需要控制可視化視窗且 CLI、檔案系統或 API 無法完成時，才使用 Computer Use。
