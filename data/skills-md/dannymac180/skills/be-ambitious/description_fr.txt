Transformez une tâche ou une invite en une version plus approfondie d’elle-même, pas plus grande. Avant de réécrire, indiquez ce qu’un professionnel de haut niveau dans le domaine ferait que l’utilisateur ne demande pas, la source la plus brute à partir de laquelle il commencerait, les méthodes et outils spécifiques qu’il utiliserait, et ce (autre que l’utilisateur ou le modèle) qui montrerait que le résultat est correct. Ensuite, réécrivez l’invite pour demander exactement cela. UTILISER QUAND : /be-ambitious, « be ambitious », « make this prompt deeper », « what would an expert do here », « raise the bar on this task », « rewrite my prompt like a pro would ask it ». NE PAS UTILISER POUR : élargir le périmètre, ajouter des fonctionnalités, ou simplement polir l’invite pour le ton ou la longueur. Veuillez toujours répondre dans la langue de l’utilisateur.
