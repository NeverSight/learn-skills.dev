Normes de dépôt et de code de l'équipe UNNC AIM. Couvre la dénomination des dépôts (competition / aim‑academic‑year / reusable), les règles de branches et de Conventional Commits, le comportement Git de l'agent IA (ne jamais committer / pousser sauf si l'utilisateur le demande explicitement dans la tâche en cours ; ne jamais appeler l'interface gh sans permission explicite ; ne jamais ajouter de bandeau AI Co‑Authored‑By ; suggérer un message de commit à la fin d’une tâche modifiant du code), ainsi que les normes de formatage pour Python (autopep8 / PEP 8), C++ (clang‑format / clang‑tidy), TypeScript (Prettier + ESLint, pnpm), Go (gofmt), CMake, et Markdown / YAML / JSON, avec des fichiers de règle canoniques prêts à copier. Utilisez‑les lors de la création ou du nommage d’un dépôt, de la validation d’un nom de package.xml ROS2, de la création d’une branche, de la rédaction d’un message de commit Git, pour toute tâche pouvant impliquer un commit, un push ou l’appel de gh, lors de la composition d’un espace de travail de compétition (sous‑modules Git sous src/), ou lors de la configuration des outils Python, C++ (.clang‑format / setup.cfg / . clang‑tidy), TypeScript (Prettier / ESLint / pnpm) ou Go (gofmt), du style d’un CMakeLists.txt ou des fichiers Markdown / YAML / JSON, ou de l’application de la configuration Git recommandée par l’équipe.
