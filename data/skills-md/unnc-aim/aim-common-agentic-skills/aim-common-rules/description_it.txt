Standard di repository e codice del team UNNC AIM. Copre la denominazione dei repository (competition / aim‑academic‑year / reusable), le regole per i branch e i Conventional Commits, il comportamento git dell’agente AI (mai effettuare commit / push a meno che l’utente non lo richieda esplicitamente nel task corrente; mai chiamare la CLI gh senza permesso esplicito; mai aggiungere un trailer AI Co‑Authored‑By; suggerire un messaggio di commit al termine di un task che modifica il codice) e gli standard di formattazione per Python (autopep8 / PEP 8), C++ (clang‑format / clang‑tidy), TypeScript (Prettier + ESLint, pnpm), Go (gofmt), CMake e Markdown / YAML / JSON, con file di regole canoniche pronti da copiare. Utilizzare quando si crea o si denomina un repository, si valida il nome di un package.xml ROS2, si crea un branch, si scrive un messaggio di commit git, in qualsiasi compito che possa comportare commit, push o chiamata a gh, si compone un workspace per competizioni (git submodule sotto src/), o si configura lo strumento per Python, C++ (.clang‑format / setup.cfg / .clang‑tidy), TypeScript (Prettier / ESLint / pnpm) o Go (gofmt), si stilizza un CMakeLists.txt o file Markdown / YAML / JSON, o si applica la configurazione git consigliata dal team.

Rispondi sempre nella lingua dell'utente.
