مستودع ومعايير الشيفرة لفريق UNNC AIM. يغطي تسمية المستودعات (competition / aim‑academic‑year / reusable)، قواعد الفروع والـ Conventional Commits، سلوك git للوكيل الذكي (عدم تنفيذ commit أو push إلا إذا طلب المستخدم ذلك صراحةً في المهمة الحالية؛ عدم استدعاء أداة gh CLI دون إذن صريح؛ عدم إضافة مقطع AI Co‑Authored‑By؛ اقتراح رسالة commit في نهاية مهمة تعديل الشيفرة)، ومعايير التنسيق للغات Python (autopep8 / PEP 8)، C++ (clang‑format / clang‑tidy)، TypeScript (Prettier + ESLint، pnpm)، Go (gofmt)، CMake، وMarkdown / YAML / JSON، مع ملفات قواعد قانونية جاهزة للنسخ. استخدمها عند إنشاء أو تسمية مستودع، التحقق من اسم package.xml في ROS2، إنشاء فرع، كتابة رسالة commit في git، في أي مهمة قد تشمل commit أو push أو استدعاء gh، تكوين مساحة عمل للمسابقة (submodules git تحت src/)، أو إعداد أدوات Python، C++ (.clang‑format / setup.cfg / clang‑tidy)، TypeScript (Prettier / ESLint / pnpm) أو Go (gofmt)، تنسيق CMakeLists.txt أو ملفات Markdown / YAML / JSON، أو تطبيق إعدادات git الموصى بها من قبل الفريق.
