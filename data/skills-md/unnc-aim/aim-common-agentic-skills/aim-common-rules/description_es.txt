Repositorio y estándares de código del equipo UNNC AIM. Cubre la nomenclatura de repositorios (competition / aim‑academic‑year / reusable), las reglas de ramas y Conventional Commits, el comportamiento de git del agente de IA (nunca hacer commit / push a menos que el usuario lo solicite explícitamente en la tarea actual; nunca llamar al CLI gh sin permiso explícito; nunca añadir un trailer AI Co‑Authored‑By; sugerir un mensaje de commit al final de una tarea que modifique código) y los estándares de formato para Python (autopep8 / PEP 8), C++ (clang‑format / clang‑tidy), TypeScript (Prettier + ESLint, pnpm), Go (gofmt), CMake y Markdown / YAML / JSON, con archivos de reglas canónicos listos para copiar. Úselo al crear o nombrar un repositorio, validar el nombre de un package.xml de ROS2, crear una rama, escribir un mensaje de commit en git, en cualquier tarea que pueda implicar hacer commit, push o llamar a gh, componer un espacio de trabajo de competición (submódulos git bajo src/), o configurar las herramientas de Python, C++ (.clang‑format / setup.cfg / .clang‑tidy), TypeScript (Prettier / ESLint / pnpm) o Go (gofmt), dar estilo a un CMakeLists.txt o archivos Markdown / YAML / JSON, o aplicar la configuración de git recomendada por el equipo.
