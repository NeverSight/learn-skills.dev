hush ladder に対して既存コードのコメントを監査し、hush‑review と同様に直接修正を適用します — 冗長なコメントを削除するために識別子の名前を変更し、コメントがない公開 API には doc コメントを追加し、サイズが大きすぎるコメントを短くし、古くなったコメントを更新または削除します。デフォルトでは現在の diff を対象とし、引数としてパス・ディレクトリ・ブランチ・PR が渡された場合はそれを対象とし、diff がなくターゲットも指定されていない場合はリポジトリ全体にフォールバックします。「hush fix」「fix comments」「clean up comments」「improve existing comments」「/hush-fix」と言ったとき、またはコメント品質の指摘を一覧表示ではなく適用したいときに使用します。
