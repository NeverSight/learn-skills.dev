既存のコードコメントを hush ラダー（rename-over-comment、名前の繰り返しなし、約3行の上限、公開 API のドキュメントカバレッジ、非自明な振る舞いのカバレッジ）に照らし合わせて監査し、何も変更せずに結果を報告します。デフォルトでは現在の diff をレビューし、引数としてパス/ディレクトリ/ブランチ/PR が渡された場合はそれを対象とし、diff がなくターゲットも指定されていない場合はリポジトリ全体にフォールバックします。「hush review」「review comments」「audit comments」「check comment quality」「/hush-review」と言われたとき、または冗長・欠落・古くなったコメントを見つけるがまだ修正はしないと依頼されたときに使用してください。

常にユーザーの言語で応答してください。
