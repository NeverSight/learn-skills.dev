Esamina di default il diff corrente, o un percorso/cartella/branch/PR specificato quando viene passato come argomento, ricorrendo all’intero repository se non c’è diff né obiettivo. Usalo quando l’utente dice “hush review”, “review comments”, “audit comments”, “check comment quality”, “/hush‑review”, o chiede di trovare commenti ridondanti/mancanti/obsoleti senza ancora correggerli.

Rispondi sempre nella lingua dell’utente.
