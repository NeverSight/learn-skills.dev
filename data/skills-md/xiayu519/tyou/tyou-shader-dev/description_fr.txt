Compétences de développement d'effets/shaders 2D pour mini‑jeux sous Cocos Creator 3.8.7. Utilisé pour écrire, réviser et optimiser les effets Cocos, les matériaux, les shaders Sprite/UI, les matériaux d'animation squelettique Spine, les feuilles de sprites/flipbooks, les effets spéciaux 2D, les contraintes de performance WebGL/mini‑jeu, le samplage de textures, la distorsion UV, le bruit, le SDF 2D, la lumière fluide, la dissolution, le flash blanc, le contour, le niveau de gris et d'autres effets liés à Cocos Creator. Il ne couvre clairement pas les shaders 3D, le PBR, les surfaces d'eau, les effets volumétriques, le path tracing, le post‑traitement plein écran, les tampons historiques, la simulation ping‑pong ou les solutions de calcul.
