Auditiere eine Agenten‑Fähigkeit (oder ein Repo/Plugin von Fähigkeiten) auf Sicherheit, bevor du sie installierst oder ihr vertraust. Verwende es immer, wenn der Benutzer eine Fähigkeit, ein Plugin oder dessen Skripte prüfen, begutachten, auditieren oder überprüfen möchte, ob sie sicher sind, fragt „Ist diese Fähigkeit sicher zu installieren“, ein Fähigkeits‑Repo/URL zur Bewertung einfügt oder dabei ist, eine Drittanbieter‑Fähigkeit von GitHub, npx skills oder einem Plugin‑Marktplatz zu installieren. Führt ausschließlich statische Analyse durch (führt das Ziel niemals aus) und meldet Netzwerk‑Ausgänge, Prozessausführung, Zugriff auf Geheimnisse, dynamischen Code, Schreibvorgänge im Dateisystem, Obfuskation, npm‑Installations‑Skripte, MCP‑Server‑Deklarationen, Symlinks, die den Fähigkeits‑Baum verlassen, ausgelieferte Binärdateien, aufgezeichnete Agent‑Transkripte mit undurchsichtigen Denkblöcken und in SKILL.md versteckte Prompt‑Injection‑Anweisungen, gestuft danach, ob der Code automatisch, bei Aufruf oder auf Abruf läuft.
