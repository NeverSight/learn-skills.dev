Überprüfen Sie eine Agenten‑Fähigkeit (oder ein Repository/Plugin von Fähigkeiten) auf Sicherheit, bevor Sie sie installieren oder ihr vertrauen. Verwenden Sie dies immer dann, wenn der Benutzer eine Fähigkeit, ein Plugin oder deren Skripte prüfen, begutachten, auditieren oder überprüfen möchte, ob sie sicher ist, die Frage stellt „Ist diese Fähigkeit sicher zu installieren“, ein Fähigkeits‑Repository/URL zur Bewertung einfügt oder kurz davor steht, eine Drittanbieter‑Fähigkeit von GitHub, npx skills oder einem Plugin‑Marktplatz zu installieren. Führt ausschließlich statische Analyse durch (führt das Ziel nie aus) und meldet Netzwerk‑Egress, Prozessausführung, Zugriff auf Geheimnisse, dynamischen Code, Dateisystem‑Schreibvorgänge, Obfuskation, npm‑Installations‑Skripte, MCP‑Server‑Deklarationen, Symlinks, die den Fähigkeitsbaum verlassen, mitgelieferte Binärdateien, aufgezeichnete Agent‑Transkripte mit undurchsichtigen Reasoning‑Blöcken sowie Prompt‑Injection‑Instruktionen, die in SKILL.md versteckt sind, abgestuft nach dem Zeitpunkt, zu dem der Code automatisch, bei Aufruf oder auf Anfrage ausgeführt wird.
