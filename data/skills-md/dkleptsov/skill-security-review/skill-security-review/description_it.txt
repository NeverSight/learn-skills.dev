Audita una skill di agente (o un repository/plugin di skill) per la sicurezza prima di installarla o di fidarti di essa. Usala ogni volta che l'utente vuole verificare, rivedere, auditare o controllare se una skill, un plugin o i suoi script sono sicuri, chiede “questa skill è sicura da installare”, incolla un repository/URL della skill da valutare, o sta per installare una skill di terze parti da GitHub, npx skills o un marketplace di plugin. Esegue solo analisi statica (mai esegue il target) e segnala traffico di rete in uscita, esecuzione di processi, accesso a segreti, codice dinamico, scritture su filesystem, offuscamento, script di installazione npm, dichiarazioni del server MCP, collegamenti simbolici che escono dall’albero delle skill, binari forniti, trascrizioni registrate dell’agente contenenti blocchi di ragionamento opaci e istruzioni di prompt‑injection nascoste in SKILL.md, classificati in base al fatto che il codice venga eseguito automaticamente, su invocazione o su richiesta.

Rispondi sempre nella lingua dell’utente.
