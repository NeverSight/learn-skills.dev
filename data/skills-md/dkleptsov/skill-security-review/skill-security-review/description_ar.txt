قم بمراجعة مهارة الوكيل (أو مستودع/ملحق المهارات) للتأكد من سلامتها قبل تثبيتها أو الوثوق بها. استخدم ذلك كلما أراد المستخدم التحقق، المراجعة، التدقيق، أو فحص ما إذا كانت مهارة أو ملحق أو سكريبتاته آمنة، أو سأل «هل هذه المهارة آمنة للتثبيت»، أو لصق رابط مستودع/URL لتقييمه، أو كان على وشك تثبيت مهارة طرف ثالث من GitHub أو npx skills أو سوق الملحقات. تُجرى تحليل ثابت فقط (لا يتم تنفيذ الهدف أبداً) وتُبلغ عن خروج الشبكة، تنفيذ العمليات، الوصول إلى الأسرار، الشيفرة الديناميكية، كتابات نظام الملفات، التشويش، سكريبتات تثبيت npm، إعلانات خادم MCP، الروابط الرمزية التي تخرج من شجرة المهارة، الملفات الثنائية المرفقة، النصوص المسجلة للوكيل التي تحمل كتل منطقية غامضة، وتعليمات حقن المطالبة المخفية في SKILL.md، مُصنَّفة حسب ما إذا كان الكود يعمل تلقائيًا، عند الاستدعاء، أو عند الطلب.
