تدقيق مهارة الوكيل (أو مستودع/إضافة المهارات) للسلامة قبل تثبيتها أو الوثوق بها. استخدمها كلما أراد المستخدم فحص، مراجعة، تدقيق، أو التحقق مما إذا كانت مهارة أو إضافة أو سكريبتاتها آمنة، أو سأل «هل هذه المهارة آمنة للتثبيت»، أو لصق رابط مستودع مهارة لتقييمه، أو كان على وشك تثبيت مهارة طرف ثالث من GitHub أو npx skills أو سوق الإضافات. تقوم بالتحليل الساكن فقط (لا تنفذ الهدف أبداً) وتُبلغ عن خروج الشبكة، تنفيذ العمليات، الوصول إلى الأسرار، الكود الديناميكي، كتابة نظام الملفات، الإخفاء، سكريبتات تثبيت npm، إعلانات خادم MCP، الروابط الرمزية التي تغادر شجرة المهارة، الثنائيات المجمَّعة، نصوص الوكيل المسجلة التي تحمل كتلًا من المنطق غير الواضح، وتعليمات حقن المطالبات المخفية في SKILL.md، مصنفة حسب ما إذا كان الكود يعمل تلقائيًا، عند الاستدعاء، أو عند الطلب.
