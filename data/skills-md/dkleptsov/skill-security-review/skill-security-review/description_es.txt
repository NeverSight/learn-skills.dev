Audita una habilidad de agente (o un repositorio/plugin de habilidades) para su seguridad antes de instalarla o confiar en ella. Úsalo siempre que el usuario quiera evaluar, revisar, auditar o comprobar si una habilidad, plugin o sus scripts son seguros, pregunte "¿es segura esta habilidad para instalar?", pegue un repositorio/URL de la habilidad para evaluar, o esté a punto de instalar una habilidad de terceros desde GitHub, npx skills o un mercado de plugins. Ejecuta solo análisis estático (nunca ejecuta el objetivo) y reporta salida de red, ejecución de procesos, acceso a secretos, código dinámico, escrituras en el sistema de archivos, ofuscación, scripts de instalación de npm, declaraciones de servidor MCP, enlaces simbólicos que salen del árbol de la habilidad, binarios incluidos, transcripciones de agente registradas que contienen bloques de razonamiento opacos e instrucciones de inyección de prompts ocultas en SKILL.md, clasificados según si el código se ejecuta automáticamente, bajo invocación o bajo demanda.
