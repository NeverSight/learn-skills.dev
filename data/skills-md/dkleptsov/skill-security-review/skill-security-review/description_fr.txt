Audit d'une compétence d'agent (ou d'un dépôt/plugin de compétences) pour la sécurité avant de l'installer ou d'y faire confiance. À utiliser chaque fois que l'utilisateur souhaite vérifier, examiner, auditer ou contrôler si une compétence, un plugin ou ses scripts sont sûrs, pose la question « cette compétence est‑elle sûre à installer », colle un dépôt/URL de compétence à évaluer, ou est sur le point d'installer une compétence tierce depuis GitHub, npx skills ou un marketplace de plugins. Effectue uniquement une analyse statique (n’exécute jamais la cible) et signale les sorties réseau, l’exécution de processus, l’accès à des secrets, le code dynamique, les écritures sur le système de fichiers, l’obfuscation, les scripts d’installation npm, les déclarations de serveur MCP, les liens symboliques quittant l’arborescence de la compétence, les binaires fournis, les transcriptions d'agent enregistrées contenant des blocs de raisonnement opaques, ainsi que les instructions d’injection de prompts cachées dans SKILL.md, classées selon que le code s’exécute automatiquement, sur appel ou sur demande.

Veuillez toujours répondre dans la langue de l'utilisateur.
