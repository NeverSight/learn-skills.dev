Auditez une compétence d'agent (ou un dépôt/plugin de compétences) pour la sécurité avant de l’installer ou de lui faire confiance. Utilisez‑le chaque fois que l’utilisateur souhaite examiner, réviser, auditer ou vérifier si une compétence, un plugin ou ses scripts sont sûrs, demande « cette compétence est‑elle sûre à installer », colle un dépôt/URL de compétence à évaluer, ou s’apprête à installer une compétence tierce depuis GitHub, npx skills ou un marché de plugins. Effectue uniquement une analyse statique (n’exécute jamais la cible) et rapporte les sorties réseau, l’exécution de processus, l’accès aux secrets, le code dynamique, les écritures sur le système de fichiers, l’obfuscation, les scripts d’installation npm, les déclarations de serveur MCP, les liens symboliques quittant l’arborescence de la compétence, les binaires fournis, les transcriptions d’agent enregistrées contenant des blocs de raisonnement opaques, et les instructions d’injection d’invite cachées dans SKILL.md, classées selon que le code s’exécute automatiquement, à l’invocation ou à la demande.

Veuillez toujours répondre dans la langue de l’utilisateur.
