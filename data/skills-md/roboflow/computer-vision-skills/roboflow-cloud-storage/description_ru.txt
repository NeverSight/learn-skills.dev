Используйте при подключении облачного хранилища (AWS S3 / совместимого с S3 или Google Cloud Storage) к Roboflow для зеркального копирования изображений в рабочее пространство — создание учётных данных хранилища, определение источников данных (конфигураций зеркального бакета), выбор объектов с помощью glob‑правил, проверка доступа и запуск/планирование задач зеркалирования.
