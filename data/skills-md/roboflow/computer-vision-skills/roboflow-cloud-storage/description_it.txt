Usa quando colleghi l'archiviazione cloud (AWS S3 / compatibile S3 o Google Cloud Storage) a Roboflow per replicare le immagini in un workspace — creando credenziali di storage, definendo le sorgenti dati (configurazioni di mirror del bucket), selezionando gli oggetti con regole glob, convalidando l'accesso e avviando/pianificando i job di mirror.
