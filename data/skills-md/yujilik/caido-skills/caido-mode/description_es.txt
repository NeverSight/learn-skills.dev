Integración completa del SDK de Caido para Claude Code. Busca el historial HTTP con HTTPQL, prueba con curl mediante un proxy de Caido (caché de autenticación en archivos de configuración estáticos reutilizables de curl), añade reglas de coincidencia y reemplazo, y organiza los handoffs en sesiones de reproducción nombradas y colecciones, todo a través del cliente oficial @caido/sdk-client. Se recomienda autenticación PAT.
