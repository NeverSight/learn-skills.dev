Полная интеграция Caido SDK для Claude Code. Поиск истории HTTP с помощью HTTPQL, тестирование с curl, проксируемым через Caido (кеширование аутентификации в переиспользуемых статических файлах конфигурации curl), добавление правил соответствия и замены, а также организация передач в именованные сессии воспроизведения и коллекции — всё через официальный @caido/sdk-client. Рекомендуется использовать PAT‑аутентификацию.
