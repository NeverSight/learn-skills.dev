Intégration complète du SDK Caido pour Claude Code. Recherche de l’historique HTTP avec HTTPQL, test avec curl proxyé via Caido (mise en cache de l’authentification dans des fichiers de configuration curl statiques réutilisables), ajout de règles de correspondance et de remplacement, et organisation des transferts en sessions de relecture nommées et collections – le tout via le client officiel @caido/sdk-client. Authentification PAT recommandée.
