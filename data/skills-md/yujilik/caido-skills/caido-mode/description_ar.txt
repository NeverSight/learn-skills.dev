تكامل كامل لـ Caido SDK مع Claude Code. ابحث في سجل HTTP باستخدام HTTPQL، واختبر باستخدام curl عبر وكيل Caido (مع تخزين المصادقة في ملفات إعداد curl الثابتة القابلة لإعادة الاستخدام)، أضف قواعد المطابقة والاستبدال، ونظّم عمليات التسليم في جلسات إعادة تشغيل مسماة ومجموعات—كل ذلك عبر @caido/sdk-client الرسمي. يُنصح باستخدام مصادقة PAT.
