Integrazione completa del Caido SDK per Claude Code. Cerca nella cronologia HTTP con HTTPQL, prova con curl tramite proxy Caido (memorizzando l'autenticazione in file di configurazione curl statici riutilizzabili), aggiungi regole di corrispondenza e sostituzione e organizza i passaggi in sessioni di replay con nome e collezioni, tutto tramite l'official @caido/sdk-client. Si consiglia l'autenticazione PAT.
