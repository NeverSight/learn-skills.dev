Высокоскоростная, детерминированная проверка сквозного UI и верстки CSS без медленных интерактивных кликов в браузере. Сочетает статический дифф CSS из Git, проверки целостности сборочных чанков, безголовую прямую навигацию Playwright и математические утверждения DOM/CSS (getBoundingClientRect, getComputedStyle, проверка попадания elementFromPoint и синтетические нативные события).
