Интегрируйте API потокового видео интерактивного цифрового человека (数字人) Vidu S1 в реальном времени. Используйте это всякий раз, когда пользователь работает с сервисом живых аватаров Vidu — создает сеанс в реальном времени, присоединяется к каналу Aliyun RTC, управляет управляющим WebSocket, обрабатывает повторные попытки NOT_READY, контрольные сигналы, зависания, выставление счетов или клонирование голоса. Активируется при упоминании Vidu S1, vidu live API, 数字人接入, /live/v1/lives, conn_init, live_bot или «接入 vidu 实时数字人». Кодирует неочевидные ошибки протокола, которые ошибочны в общедоступном документе.
