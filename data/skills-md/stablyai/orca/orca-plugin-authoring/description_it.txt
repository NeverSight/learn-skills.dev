Costruisci, esegui il debug, testa e pubblica i plugin Orca end‑to‑end: temi per app, terminale e icone, sintassi, pacchetti lingua, editor personalizzati, pannelli laterali per componenti HTML o TSX, comandi e scorciatoie della palette e comandi Node worker che reagiscono a eventi di workspace e agente. Usalo quando l’utente chiede di creare, modificare, correggere o rilasciare un plugin Orca, aggiungere un pannello, comando, tema, editor o lingua a Orca, o lavora in una cartella con un file orca‑plugin.json. Usa `orca-cli` solo per elencare, abilitare o disabilitare plugin già installati.
