Guida l'interfaccia grafica di una finestra locale visibile tramite `orca computer`: albero di accessibilità, click, digitazione, menu, finestre di dialogo e screenshot in applicazioni native e finestre di browser esterni (Chrome, Edge, Safari) o webview. Preferisci un percorso programmatico (shell, filesystem, git, HTTP, CLI esistenti) ogni volta che può completare il compito. Usa solo quando una finestra visibile necessita di controllo GUI che non è possibile raggiungere. Non utilizzare per il browser integrato di Orca (`orca-cli`).
