Pilote l'interface graphique d'une fenêtre d'application locale visible via `orca computer` : arbre d'accessibilité, clics, saisie, menus, dialogues et captures d’écran dans les applications natives et les fenêtres de navigateurs externes (Chrome, Edge, Safari) ou les webviews. Privilégiez un chemin programmatique (shell, système de fichiers, git, HTTP, CLI existants) chaque fois que cela peut accomplir la tâche. Utilisez‑le uniquement lorsqu'une fenêtre visible nécessite un contrôle GUI que les méthodes précédentes ne peuvent atteindre. Ne l'utilisez pas pour le navigateur intégré d’Orca (`orca-cli`).
