Controla la GUI de una ventana de aplicación local visible mediante `orca computer`: árbol de accesibilidad, clics, escritura, menús, diálogos y capturas de pantalla en aplicaciones nativas y ventanas de navegadores externos (Chrome, Edge, Safari) o webviews. Prefiere una vía programática (shell, sistema de archivos, git, HTTP, CLIs existentes) siempre que pueda completar la tarea. Utilízalo solo cuando una ventana visible requiera control GUI que no pueden alcanzar. No lo uses para el navegador incrustado de Orca (`orca-cli`).
