Claude Code — специализированная настройка пользовательской среды weed‑harness, обрабатывает только терминальный UI (HUD статусной строки) и базовую конфигурацию (регистрация пользовательских хуков: language‑rule, auto‑update). Не устанавливает навыки/плагины. Идемпотентен, поэтому безопасно запускать несколько раз. Триггеры: «/setup», «setup hud», «setup hooks», «register statusLine».

Пожалуйста, всегда отвечайте на языке пользователя.
