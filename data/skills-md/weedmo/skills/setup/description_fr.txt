Configuration exclusive de l'environnement utilisateur Claude Code weed‑harness — ne gère que l'interface terminal (HUD de la statusLine) et la configuration de base (enregistrement des hooks personnalisés : language‑rule, auto‑update). Aucune installation de skill/plugin n’est effectuée. Elle est idempotente, donc l’exécuter plusieurs fois est sans risque. Déclencheurs : « /setup », « setup hud », « setup hooks », « register statusLine ».

Veuillez toujours répondre dans la langue de l’utilisateur.
