Verwenden Sie diese Methode, wenn Sie einen Bildschirm, einen Flow oder eine Komponente entwerfen oder neu gestalten, wenn Sie aufgefordert werden, alle Zustände abzudecken oder fehlende Zustände zu finden, oder bevor Sie einen Bildschirm zur Programmierung übergeben. Verwenden Sie es auch, wenn ein Design nur den Happy Path zeigt, kurze, übersichtliche Beispieldaten verwendet oder von einem einzigen Benutzer ausgeht.
