عرض تجريبي للمنتج وفيديوهات ملاحظات الإصدار دون تسجيل الشاشة. أعد بناء شاشات التطبيق كـ React ثابت من شفرة المصدر، ثم تحكم فيها في Remotion باستخدام مؤشر وكاميرا مبرمجة (lib/components Stage + Cursor). يُستخدم هذا عندما تقوم بإنشاء جولة للمنتج، أو عرض توضيحي للميزة، أو فيديو ملاحظات الإصدار أو سجل التغييرات لتطبيق يمكنك قراءة شفرة المصدر الخاصة به، أو عندما يكون تسجيل Playwright غير ثابت، أو يحتاج إلى بيانات اختبار، أو يصبح قديمًا. تشمل الحالات: عرض تجريبي صناعي، إعادة بناء واجهة المستخدم، فيديو الإصدار، جولة للميزة، عرض تجريبي للمنتج من المصدر، مؤشر مبرمج، تكبير الكاميرا على الواجهة، دون تسجيل الشاشة.
