Video demo del prodotto e di note di rilascio senza registrazione dello schermo. Ricostruisci le schermate dell’app come React statico dal suo codice sorgente, poi guidale in Remotion con un cursore e una telecamera scriptati (lib/components Stage + Cursor). Usalo quando crei un walkthrough del prodotto, una demo di funzionalità, un video di note di rilascio o di changelog per un’app di cui puoi leggere il sorgente, o quando una registrazione Playwright sarebbe instabile, richiede dati di test o diventa obsoleta. I trigger includono demo sintetica, ricostruzione dell’interfaccia, video di rilascio, walkthrough di funzionalità, demo del prodotto dal sorgente, cursore scriptato, zoom della telecamera sull’interfaccia, nessuna registrazione dello schermo.
