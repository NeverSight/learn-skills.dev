화면 녹화 없이 진행하는 제품 데모 및 릴리즈 노트 영상. 앱의 소스 코드를 기반으로 화면을 정적 React 컴포넌트로 재구성한 뒤, Remotion에서 스크립트화된 커서와 카메라(lib/components Stage + Cursor)를 이용해 제어합니다. 소스 코드를 확인할 수 있는 앱의 제품 투어, 기능 데모, 릴리즈 노트 또는 changelog 영상을 만들 때, 혹은 Playwright 녹화가 불안정하거나 테스트 데이터가 필요하거나 시간이 지나 오래된 경우에 사용합니다. 트리거로는 합성 데모, UI 재구성, 릴리즈 영상, 기능 투어, 소스 기반 제품 데모, 스크립트 커서, UI 줌 카메라, 화면 녹화 없음 등이 포함됩니다.
