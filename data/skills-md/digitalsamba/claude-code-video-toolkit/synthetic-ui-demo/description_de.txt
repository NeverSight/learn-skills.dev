Produkt‑Demo‑ und Release‑Notes‑Videos ohne Bildschirmaufnahme. Rekonstruiere die Bildschirme der App als statisches React aus ihrem Quellcode und steuere sie dann in Remotion mit einem geskripteten Cursor und einer Kamera (lib/components Stage + Cursor). Verwende es, wenn du einen Produkt‑Walkthrough, Feature‑Demo, Release‑Notes‑ oder Changelog‑Video für eine App erstellst, deren Quellcode du lesen kannst, oder wenn eine Playwright‑Aufnahme fehlerhaft wäre, Testdaten benötigt werden oder sie veraltet wäre. Auslöser sind synthetische Demo, UI neu bauen, Release‑Video, Feature‑Walkthrough, Produkt‑Demo aus dem Quellcode, geskripteter Cursor, Kamerazoom auf UI, keine Bildschirmaufnahme.
