Видео демонстрации продукта и релизных нот без записи экрана. Восстановите экраны приложения как статические React‑компоненты из его исходного кода, а затем управляйте ими в Remotion с помощью скриптованного курсора и камеры (lib/components Stage + Cursor). Используйте при создании видеопрезентации продукта, демонстрации функции, релизных нот или видео с журналом изменений для приложения, исходный код которого доступен, или когда запись с помощью Playwright будет ненадёжной, потребует тестовых данных или устареет. Триггеры включают синтетическую демонстрацию, перестройку UI, видео релиза, демонстрацию функции, демонстрацию продукта из исходного кода, скриптованный курсор, масштабирование камеры на UI, отсутствие записи экрана.
