Démo de produit et vidéos de notes de version sans enregistrement d’écran. Reconstruisez les écrans de l’application en React statique à partir de son code source, puis pilotez‑les dans Remotion avec un curseur et une caméra scriptés (lib/components Stage + Cursor). Utilisez‑cela pour créer une présentation de produit, une démonstration de fonctionnalité, une vidéo de notes de version ou un changelog pour une application dont le code est accessible, ou lorsque l’enregistrement Playwright serait instable, nécessiterait des données de test ou deviendrait obsolète. Les déclencheurs incluent démo synthétique, reconstruction de l’UI, vidéo de version, présentation de fonctionnalité, démo produit depuis le code source, curseur scripté, zoom de la caméra sur l’UI, sans enregistrement d’écran.
