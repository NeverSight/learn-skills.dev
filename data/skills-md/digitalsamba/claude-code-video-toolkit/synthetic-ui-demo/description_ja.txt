スクリーン録画なしで行うプロダクトデモやリリースノート動画。アプリのソースコードから画面を静的な React に再構築し、Remotion でスクリプト化されたカーソルとカメラ（lib/components の Stage + Cursor）を操作する。ソースが読めるアプリのプロダクトウォークスルー、機能デモ、リリースノートや変更ログ動画を作成する際、または Playwright の録画が不安定でテストデータが必要、あるいは古くなる可能性がある場合に使用する。トリガーは合成デモ、UI の再構築、リリース動画、機能ウォークスルー、ソースからのプロダクトデモ、スクリプト化されたカーソル、UI のカメラズーム、スクリーン録画なしなど。
