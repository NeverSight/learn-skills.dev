Videos de demostración de producto y notas de lanzamiento sin grabación de pantalla. Reconstruye las pantallas de la aplicación como React estático a partir de su código fuente y, a continuación, controla su reproducción en Remotion con un cursor y una cámara programados (lib/components Stage + Cursor). Úsalo al crear un recorrido del producto, una demo de característica, un video de notas de lanzamiento o de registro de cambios para una aplicación cuyo código puedas leer, o cuando una grabación con Playwright sería inestable, necesitaría datos de prueba o se volvería obsoleta. Los disparadores incluyen demo sintética, reconstruir la UI, video de lanzamiento, recorrido de característica, demo de producto desde el código fuente, cursor programado, zoom de cámara en la UI, sin grabación de pantalla.
