التصميم المرئي للفيديوهات – اللون حسب الفعل، مقياس النوع، قواعد المخطط وتخطيط المشاهد بنسبة 16:9 و 9:16، تسليم design.md يمكن لأي مهارة تصميم ملؤه، ونقد ورقة الاتصال للعرض النهائي. يُستخدم عند تصميم أو تحسين مظهر الفيديو (بطاقات العناوين، مشاهد البيانات، الشرائح، لوحة ألوان الفيديو بالكامل)، عندما يكون المشهد عاماً أو مزدحمًا، عند اختيار ألوان للفيديو، أو عندما يطلب /design أو /scene‑review عملًا بصريًا. يعمل بشكل مستقل مع علامة تجارية، أو يتلقى توجيهًا من مصدر تصميم مثل taste‑skill، أو frontend‑design الخاص بـ Anthropic، أو مهارة التصميم الخاصة بالمستخدم.
