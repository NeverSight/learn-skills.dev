Comment les vidéos publiées fonctionnent sur YouTube, et ce qu'il faut en apprendre. Les vues, les likes, les commentaires et les abonnés par vidéo, ainsi que le temps de visionnage, la rétention et les sources de trafic (flux Shorts, recherche, externe) avec la portée Analytics, enregistrés sous forme d'instantanés pour que les tendances s'affichent ; le trafic GitHub à côté pour voir si YouTube envoie des personnes au repo. À utiliser lorsqu'on vous demande comment se porte une vidéo ou la chaîne, quel titre, quelle couverture ou quel genre a fonctionné, s'il faut en faire plus ou pour une vérification hebdomadaire des statistiques.
