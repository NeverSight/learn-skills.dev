Cómo funcionan los vídeos publicados en YouTube y qué aprender de ellos. Vistas, me gusta, comentarios y suscriptores por video, además de tiempo de visualización, retención y fuentes de tráfico (feed de cortos, búsqueda, externo) con el alcance de Analytics, guardado como instantáneas para que se muestren las tendencias; tráfico de GitHub al lado para ver si YouTube envía personas al repositorio. Úselo cuando se le pregunte cómo le está yendo a un video o al canal, qué título, portada o género funcionó, si desea hacer más de algo o para una verificación semanal de estadísticas.
