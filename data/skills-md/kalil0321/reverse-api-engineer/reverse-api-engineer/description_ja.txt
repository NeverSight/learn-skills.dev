reverse-api-engineer CLI を使用して、ウェブサイトのプライベート HTTP API を型付けされた実行可能クライアント（Python、TypeScript、Go など計 7 種類）にリバースエンジニアリングします。ブラウザがタスクを実行し、rae がサイトの実際のネットワークトラフィックを読み取り、モデルがクライアントを生成します。ユーザーがサイトをプログラムから呼び出したいが公開 API がない、または公開 API がブラウザでできることをカバーしていない場合に使用します。公式の API や SDK がすでにタスクをカバーしている場合は省いてください。

常にユーザーの言語で応答してください。
