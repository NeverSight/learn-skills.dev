Обратное проектирование частного HTTP‑API сайта в типизированный, исполняемый клиент (Python, TypeScript, Go и ещё семь) с помощью CLI reverse-api-engineer. Браузер выполняет задачу, пока rae считывает реальный сетевой трафик сайта, затем модель генерирует клиент. Используйте, когда пользователь хочет обращаться к сайту программно, но у него нет публичного API, либо публичный API не покрывает того, что умеет браузер. Пропускайте, если официальное API или SDK уже решают эту задачу.
