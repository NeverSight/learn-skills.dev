Ingénierie inverse de l'API HTTP privée d’un site web en un client typé et exécutable (Python, TypeScript, Go et 7 autres) avec l’outil en ligne de commande reverse‑api‑engineer. Un navigateur exécute la tâche tandis que rae lit le trafic réseau réel du site, puis un modèle génère le client. À utiliser lorsque l’utilisateur veut appeler le site de façon programmatique et qu’il n’existe aucune API publique, ou que l’API publique ne fournit pas ce que le navigateur peut faire. À ignorer lorsqu’une API officielle ou un SDK couvre déjà la tâche.
