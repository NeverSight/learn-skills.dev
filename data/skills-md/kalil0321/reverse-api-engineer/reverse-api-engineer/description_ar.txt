اعكس هندسة واجهة HTTP الخاصة بموقع ويب إلى عميل مكتوب بأنواع قابلة للتنفيذ (Python، TypeScript، Go و7 أخرى) باستخدام أداة سطر الأوامر reverse‑api‑engineer. المتصفح يقوم بالمهمة بينما يقرأ rae حركة الشبكة الحقيقية للموقع، ثم يكتب نموذج العميل. استخدمها عندما يرغب المستخدم في استدعاء الموقع برمجيًا ولا يتوفر له API عام، أو عندما يفتقر API العام إلى ما يستطيع المتصفح القيام به. تجنب استخدامها عندما يغطي API رسمي أو SDK المهمة بالفعل.
