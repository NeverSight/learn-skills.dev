Ingeniería inversa de la API HTTP privada de un sitio web en un cliente tipado y ejecutable (Python, TypeScript, Go y 7 más) con la CLI reverse-api-engineer. Un navegador realiza la tarea mientras rae lee el tráfico de red real del sitio, y luego un modelo escribe el cliente. Úsalo cuando el usuario quiere llamar a un sitio de forma programática y no tiene API pública, o la API pública no ofrece lo que el navegador puede hacer. Evítalo cuando ya exista una API o SDK oficial que cubra la tarea.
