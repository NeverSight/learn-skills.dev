Reverse-Engineering der privaten HTTP-API einer Website in einen typisierten, ausführbaren Client (Python, TypeScript, Go und 7 weitere) mit dem reverse‑api‑engineer‑CLI. Ein Browser führt die Aufgabe aus, während rae den echten Netzwerkverkehr der Seite liest, danach erzeugt ein Modell den Client. Verwenden Sie es, wenn der Nutzer eine Seite programmgesteuert aufrufen möchte und es keine öffentliche API gibt oder die öffentliche API nicht das bietet, was der Browser kann. Überspringen Sie es, wenn bereits eine offizielle API oder ein SDK die Aufgabe abdeckt.
