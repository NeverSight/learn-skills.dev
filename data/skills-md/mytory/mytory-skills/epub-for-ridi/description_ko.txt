RIDI Books나 국내 뷰어에 업로드하기 위해 EPUB을 만들거나 검증·수정할 때 사용합니다. Calibre 변환 후 목차가 “no contents”로 표시되거나, NCX 누락, CSS 제약, 제목‑크기 계층, 왼쪽 정렬 문제 등을 확인·수정할 때 사용합니다; 또한 Pandoc이나 Calibre에서 만든 한국어 EPUB의 인용부호 변환이나 중복 목차를 검증할 때도 사용합니다. 스캔한 PDF에서 굵은 글씨, 부제, 블록 인용 형식을 복원하거나, Calibre DOCX 변환 시 굵은 글씨가 사라질 때 사용합니다. 한국어 EPUB/DOCX에서는 의미 강조(em)를 밑줄로, 강한 강조(strong)를 굵은 글씨로 표시하고, 《》와 〈〉를 이용해 출판물 이름을 처리하도록 사용합니다.
