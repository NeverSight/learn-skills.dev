Compétence d'élite « image‑vers‑code » pour les sites Codex. Pour les projets web où l’aspect visuel est crucial, créez d’abord vous‑même l’image du design et analysez‑la minutieusement, puis construisez le site afin de le reproduire aussi fidèlement que possible. Utilisez cette compétence lorsque vous avez besoin de « conception de page d’atterrissage », « image vers code », « site web visuel », « section hero » ou « mise en œuvre à partir du design ».
