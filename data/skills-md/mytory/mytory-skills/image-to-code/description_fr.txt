Une compétence d'élite de conversion d'image en code pour les sites web, destinée à Codex. Lorsque vous travaillez sur des tâches web visuellement importantes, commencez par créer vous‑même l’image du design et l’analyser en profondeur, puis implémentez le site pour qu’il corresponde le plus fidèlement possible. Utilisez‑la lorsque vous avez besoin de « conception de page d’atterrissage », « code à partir d’une image », « site web visuel », « section héros » ou « implémentation à partir du design ».
