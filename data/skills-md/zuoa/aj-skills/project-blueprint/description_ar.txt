قم بإنشاء مخطط قرار مشروع قابل للتنفيذ لتطبيقات الويب الجديدة أو المبكرة، وSaaS، وAPI، وتطبيقات الهاتف المحمول. استخدمها عندما يذكر المستخدم "التخطيط لمشروع جديد"، أو "توضيح المتطلبات والقيود أولاً"، أو "إنشاء/إكمال PRD، أو SPEC، أو DESIGN، أو ARCHITECTURE، أو SECURITY، أو DEPLOY"، أو "تحديد مجموعة التكنولوجيا الكاملة، أو قاعدة البيانات، أو البرامج الوسيطة، أو نشر السحابة"، أو "التطوير القائم على المواصفات"، أو "جعل Claude/Codex يتبع قواعد المشروع قبل التطوير". قراءة المواد الموجودة أو إجراء مقابلات على مراحل، وتقديم توصيات اختيار قائمة على القيود، وإنتاج مواصفات معيارية يمكن تتبعها واستنتاجات الاستعداد؛ لا تقم بإنشاء رمز عمل أو سقالة كاملة للمشروع. كما أنه مناسب أيضًا لمراجعة مستندات المخططات الموجودة للتعارضات أو العناصر المفقودة أو الجوانب التي لا يمكن التحقق منها، ولكن ليس لتشفير ميزة واحدة بشكل مباشر أو إصلاحات الأخطاء المعزولة أو الأسئلة والأجوبة الفنية البسيطة بدون سياق المشروع.
