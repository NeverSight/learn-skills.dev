قم بإنشاء مخطط قرار مشروع قابل للتنفيذ لتطبيقات الويب الجديدة أو المبكرة، وSaaS، وAPI، وتطبيقات الهاتف المحمول. يجب استخدامه عندما يذكر المستخدم "التخطيط لمشروع جديد"، أو "توضيح المتطلبات والقيود أولاً"، أو "إنشاء/إكمال PRD، أو SPEC، أو التصميم، أو الهندسة المعمارية، أو الأمن، أو النشر"، أو "تحديد مجموعة التكنولوجيا الكاملة، أو قاعدة البيانات، أو البرامج الوسيطة، أو النشر السحابي"، أو "التطوير القائم على المواصفات"، أو "جعل Claude/Codex يلتزم بقواعد المشروع قبل التطوير". قراءة المواد الموجودة أو إجراء مقابلات على مراحل، وتقديم توصيات اختيار قائمة على القيود، وإنشاء مواصفات معيارية يمكن تتبعها واستنتاجات الاستعداد؛ لا تقم بإنشاء رمز عمل أو سقالة كاملة للمشروع. ينطبق أيضًا على تدقيق مستندات المخطط الموجودة للتعارضات أو العناصر المفقودة أو الجوانب التي لا يمكن التحقق منها، ولكنه لا ينطبق بشكل مباشر على ترميز ميزة واحدة أو إصلاحات الأخطاء المعزولة أو الأسئلة والأجوبة الفنية البسيطة التي تفتقر إلى سياق المشروع.
