Cree un plan de decisión de proyecto ejecutable para aplicaciones web, SaaS, API y móviles nuevas o en etapa inicial. Úselo cuando el usuario mencione "planificar un nuevo proyecto", "aclarar primero los requisitos y restricciones", "generar/completar PRD, SPEC, DISEÑO, ARQUITECTURA, SEGURIDAD, IMPLEMENTAR", "determinar la pila tecnológica completa, base de datos, middleware, implementación en la nube", "desarrollo basado en especificaciones" o "hacer que Claude/Codex siga las reglas del proyecto antes del desarrollo". Leer materiales existentes o realizar entrevistas por fases, proporcionar recomendaciones de selección basadas en restricciones y producir especificaciones modulares rastreables y conclusiones de preparación; no genere código comercial ni una estructura de proyecto completa. También es adecuado para auditar documentos planos existentes en busca de conflictos, elementos faltantes o aspectos no verificables, pero no para codificar directamente una sola característica, correcciones de errores aisladas o simples preguntas y respuestas técnicas sin el contexto del proyecto.
