Cree un plan de decisión de proyecto viable para aplicaciones web, SaaS, API y móviles nuevas o en etapa inicial. Úselo cuando el usuario mencione "planificar un nuevo proyecto", "aclarar primero los requisitos y restricciones", "generar/completar PRD, SPEC, DISEÑO, ARQUITECTURA, SEGURIDAD, IMPLEMENTACIÓN", "determinar la pila tecnológica completa, base de datos, middleware, implementación en la nube", "desarrollo basado en especificaciones" o "hacer que Claude/Codex siga las reglas del proyecto antes del desarrollo". Leer materiales existentes o realizar entrevistas por fases, proporcionar recomendaciones de selección de tecnología basadas en restricciones y producir especificaciones modulares rastreables con conclusiones de preparación; no genere código comercial ni una estructura de proyecto completa. También es adecuado para auditar documentos planos existentes en busca de conflictos, omisiones o elementos no verificables, pero no está diseñado para la codificación directa de características individuales, correcciones de errores aisladas o preguntas y respuestas técnicas simples que carezcan del contexto del proyecto.
