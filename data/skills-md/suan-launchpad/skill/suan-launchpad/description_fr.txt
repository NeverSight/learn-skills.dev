Échanger les tokens lancés sur SUAN Agent Launchpad, le protocole de lancement .ai Agent ID sur la BNB Chain (pool de hook PancakeSwap Infinity). À utiliser lorsque l'utilisateur souhaite vérifier, obtenir un devis, acheter ou vendre un token SUAN Agent Launchpad, voir son stade (fenêtre .ai, fenêtre hold‑cap, période fiscale), les fenêtres temporelles ou les frais, ou vérifier une transaction SUAN Agent Launchpad. Construit la transaction et l'exécute avec le Binance Agentic Wallet (`baw contract-call`, mode développeur).
