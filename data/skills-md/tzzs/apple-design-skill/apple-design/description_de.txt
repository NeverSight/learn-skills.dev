Apple Human Interface Guidelines (HIG) Referenz für das Entwerfen oder Überprüfen von UI auf iOS, iPadOS, macOS, watchOS, visionOS, tvOS. Verwenden Sie sie, wenn der Benutzer fragt, wie ein Bildschirm, eine Navigationsstruktur oder Interaktion so gestaltet werden soll, dass sie sich nativ auf einer Apple‑Plattform anfühlt; ob ein Design den Apple‑Richtlinien entspricht; welches System‑Steuerelement in SwiftUI/UIKit zu verwenden ist; wie man eine Farbe, Schrift, Abstand oder Animation festlegt; wie man ein App‑Icon entwirft oder ein SF‑Symbol auswählt; wie man Liquid Glass verwendet; oder wie man für Barrierefreiheit gestaltet – einschließlich, wenn der Benutzer nie „HIG“ oder „Apple Design Guidelines“ sagt.
