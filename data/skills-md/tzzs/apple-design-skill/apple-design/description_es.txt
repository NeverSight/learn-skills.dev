Referencia de las Directrices de Interfaz Humana (HIG) de Apple para diseñar o revisar la UI en iOS, iPadOS, macOS, watchOS, visionOS y tvOS. Utiliza esta referencia cuando el usuario pregunte cómo debe diseñarse una pantalla, una estructura de navegación o una interacción para que se sienta nativa en una plataforma Apple; si un diseño sigue las directrices de Apple; qué control del sistema usar en SwiftUI/UIKit; cómo establecer un color, una tipografía, un espaciado o una animación; cómo diseñar un ícono de aplicación o elegir un SF Symbol; cómo usar Liquid Glass; o cómo diseñar para accesibilidad, incluso cuando el usuario nunca mencione “HIG” o “directrices de diseño de Apple”.
