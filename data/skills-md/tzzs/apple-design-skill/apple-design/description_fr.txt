Référence des Apple Human Interface Guidelines (HIG) pour la conception ou la révision d’interfaces UI sur iOS, iPadOS, macOS, watchOS, visionOS, tvOS. À utiliser lorsque l’utilisateur demande comment un écran, une structure de navigation ou une interaction doivent être conçus pour sembler natifs sur une plateforme Apple ; si une conception suit les directives d’Apple ; quel contrôle système employer dans SwiftUI/UIKit ; comment définir une couleur, une police, un espacement ou une animation ; comment concevoir une icône d’application ou choisir un symbole SF ; comment utiliser Liquid Glass ; ou comment concevoir pour l’accessibilité — y compris lorsque l’utilisateur ne mentionne jamais « HIG » ou « directives de conception Apple ».
