باستخدام واجهة سطر الأوامر الخاصة بـ sharge، يمكنك قراءة موارد التقويم والبحث فيها وعرضها حسب شهر محدد أو نطاق زمني محدد، وإنشاء الأحداث أو تحديثها أو حذفها أو تعديل حالة المهام بشكل هيكلي. يتم استخدامه عندما يذكر المستخدم أحداث التقويم، أو المهام، أو المثيلات المتكررة، أو أشهر التقويم، أو نطاقات وقت الحدث مع الإزاحات، أو معرف التقويم؛ فهو لا يتعامل مع تحليل أوقات اللغة الطبيعية، أو إدارة ملاحظات الفلاش/التسجيلات/محتوى المجلة، أو استنتاج نطاقات المثيلات.
