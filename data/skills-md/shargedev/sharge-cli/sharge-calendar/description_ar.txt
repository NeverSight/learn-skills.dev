استخدم واجهة سطر الأوامر الخاصة بـ sharge لقراءة موارد التقويم والبحث فيها وعرضها حسب شهر أو نطاق زمني محدد، ولإنشاء الأحداث أو تحديثها أو حذفها أو تعديل حالة المهمة بشكل هيكلي. إنه مخصص للحالات التي يذكر فيها المستخدمون أحداث التقويم أو المهام أو المثيلات المتكررة أو أشهر التقويم أو نطاقات وقت الحدث مع الإزاحات أو معرف التقويم؛ ولا يتعامل مع تحليل تواريخ اللغة الطبيعية، أو إدارة ملاحظات الفلاش/التسجيلات/محتوى المجلة، أو استنتاج نطاقات المثيلات.
