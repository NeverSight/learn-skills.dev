Usar la CLI de sharge para leer, buscar y ver recursos del calendario por un mes o rango de tiempo específico, y para crear, actualizar, eliminar eventos de forma estructural o modificar el estado de las tareas pendientes. Se emplea cuando un usuario hace referencia a eventos del calendario, todos, instancias recurrentes, meses del calendario, rangos de tiempo de eventos con compensaciones o una ID de calendario; no maneja el análisis de tiempos en lenguaje natural, la administración de notas/grabaciones/contenido del diario flash ni la inferencia de rangos de instancias.
