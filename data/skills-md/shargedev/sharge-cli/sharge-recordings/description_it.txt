Attraverso la CLI condivisa, puoi elencare e cercare registrazioni su un'unica pagina, visualizzare dettagli approfonditi come trascrizioni, panoramiche ed evidenziazioni e scaricare in modo sicuro i file audio. Viene utilizzato quando un utente menziona una registrazione, un ID di registrazione, un relatore di registrazione, una trascrizione, un riepilogo, un'evidenziazione o un file audio; non gestisce il caricamento, la modifica, l'eliminazione, la ritrascrizione delle registrazioni o la gestione di calendari e diari.
