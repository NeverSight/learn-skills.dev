Utilisez lorsqu’un utilisateur souhaite trouver ou découvrir une compétence Claude Code qui n’est PAS déjà installée — par ex. « existe‑t‑il une compétence pour X », « trouvez‑moi une compétence qui… », « quelles compétences existent pour… », ou « /find-skill <sujet> ». Recherche dans le marketplace officiel des plugins, sur GitHub et dans des listes awesome‑lists sélectionnées les compétences communautaires correspondant à un besoin, élimine celles déjà installées, puis recommande les 5 meilleures avec leurs liens. NE l’utilisez PAS pour créer ou modifier des compétences (c’est la création de compétences), ni pour choisir parmi les compétences que vous avez déjà.

Veuillez toujours répondre dans la langue de l’utilisateur.
