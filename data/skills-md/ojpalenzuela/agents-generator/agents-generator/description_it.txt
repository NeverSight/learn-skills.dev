Genera un AGENTS.md completo e specifico per il progetto, compatibile con lo standard agents.md (più di 60 000 progetti open source). Genera anche file specifici per piattaforma (.cursorrules, istruzioni per Copilot, GEMINI.md) per le piattaforme rilevate. Usalo quando configuri le regole degli agenti IA, crei convenzioni di progetto per Claude Code, Cursor, Copilot, OpenCode o qualsiasi agente che legga AGENTS.md. Supporta tre modalità: completa (AGENTS.md ricco + file di regole di supporto + output multipiattaforma), minimale (un unico AGENTS.md di 30 righe conforme allo standard agents.md) e aggiornamento (diff dell'esistente, rigenera solo le parti modificate). Rileva monorepo per file annidati. Estrae token di design dai file di configurazione. Include scoring di confidenza, blocchi gestiti, audit logging e memoria di stato. Ogni comando e convenzione è derivato dal reale package.json, dai file di configurazione e dalla struttura delle directory del progetto — mai da modelli generici.

Rispondi sempre nella lingua dell'utente.
