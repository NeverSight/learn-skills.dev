Classify an arriving work item and name its next stage, then give one verdict and one next action. Use at the start of a change, when new work arrives, when a spec task looks like the next one, or when it is unclear whether something should be done now. Covers requests, tracker issues, spec tasks, review findings, retro lessons, bug reports, metric targets, and PR comments. Not for doing the work: no diagnosis, design, tasks, code, review, or estimates.
