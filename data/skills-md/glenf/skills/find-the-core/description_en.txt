Drill into the core of a task before executing it, using Simon Sinek's Golden Circle (Why → How → What) fused with the journalist's 5 W's (Who / What / When / Where / Why). Use this whenever the user hands over a task, goal, or project that is vague, broad, high-stakes, or ambiguous — e.g. "help me build X", "I need a plan for Y", "write something about Z", "I want to start a ___" — where charging ahead risks confidently solving the wrong problem. Run a short adaptive interview to surface the real purpose and the missing dimensions, deliver a tight brief, then confirm before proceeding. Do NOT use it on small, crisp, already-specified requests where the goal is obvious — clarity-gathering there just wastes the person's time.
