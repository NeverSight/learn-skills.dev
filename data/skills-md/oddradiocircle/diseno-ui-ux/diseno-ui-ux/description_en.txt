Proceso y criterio para diseñar interfaces y experiencias de usuario (UI/UX) que se vean y se usen como un producto real, con cualquier tecnología (HTML, frameworks web, apps móviles, extensiones de una plataforma, maquetas). Úsalo al diseñar, rediseñar o pulir una pantalla, maqueta, componente, flujo, tablero, formulario o texto de interfaz, y al decidir cómo se ve o se comporta algo. Deja registradas las decisiones de diseño con su porqué. Para revisar un diseño ya hecho con ojo fresco, usa revision-ui-ux.
