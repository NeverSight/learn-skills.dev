Unvoreingenommene Überprüfung eines von jemand anderem erstellten Interface-Designs (UI/UX) anhand von Screenshots und ohne die Erläuterungen des Erstellers. Verwenden Sie es, bevor Sie einen Bildschirm, ein Modell oder eine Komponente der Person, die es angefordert hat, oder einem Kunden zeigen, oder wenn jemand darum bittet, ein Design zu überprüfen, zu kritisieren oder zu prüfen. Es wird eine nach Schweregrad geordnete Liste ausgegeben, wobei jeder Fehler mit seinem Screenshot und seiner Behebung in einer Zeile aufgeführt wird. Funktioniert mit jeder Technologie. Wenden Sie die Kriterien der Skill diseno-ui-ux an.
