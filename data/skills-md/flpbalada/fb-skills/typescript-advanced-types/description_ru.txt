Создавайте читаемые продвинутые типы TypeScript. Используйте их при создании переиспользуемых типовых утилит, дженериков, условных типов, отображаемых типов, типов шаблонных литералов, вспомогательных функций infer, брендинговых типов, проверок типов, функций‑утверждений, типизированных библиотек, API‑клиентов, конфигураций или помощников состояния. Предпочитайте простые типы, пока усложнение не оправдано. Для общих рекомендаций по типизации, повышающей качество кода, используйте typescript‑best‑practices.
