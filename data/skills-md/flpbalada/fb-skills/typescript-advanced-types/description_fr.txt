Concevez des types TypeScript avancés lisibles. Utilisez-les lors de la création d'utilitaires de types réutilisables, de génériques, de types conditionnels, de types mappés, de types littéraux de modèle, d'aides d'inférence, de types brandés, de gardes de type, de fonctions d'assertion, de bibliothèques typées, de clients API, de configurations ou d'aides d'état. Privilégiez les types simples tant que la complexité n'est pas justifiée. Pour des directives générales sur la qualité du typage, utilisez typescript-best-practices. Veuillez toujours répondre dans la langue de l'utilisateur.
