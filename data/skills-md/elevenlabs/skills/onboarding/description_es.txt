Agregar ElevenLabs a un proyecto desde cero. Úsalo cuando el usuario quiera comenzar a usar ElevenLabs, añadir texto a voz, voz a texto, agentes de voz, voz en tiempo real para su propio motor de agente (Speech Engine), efectos de sonido, música, cambio de voz, aislamiento de voz o doblaje en su aplicación, o configurar una cuenta de ElevenLabs o una clave API por primera vez. Maneja el inicio de sesión, la creación de la clave API, la instalación del SDK y una solicitud de prueba de extremo a extremo; el usuario abandona la conversación una vez, para aprobar una página del navegador. No es para arreglar una clave que dejó de funcionar o para colocar una emitida por un administrador (usa setup-api-key).
