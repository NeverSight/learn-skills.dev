Utilice los modelos en tiempo real de ElevenLabs (`eleven_realtime_v1_mini`, `eleven_realtime_v1_max`), los modelos de baja latencia construidos para conversaciones de voz. Úselos cuando el usuario quiera crear un agente ElevenAgents en un modelo en tiempo real o cambiar el modo de voz de un agente existente a Tiempo real, establecer `conversation_config.realtime_model`, elegir entre Realtime Mini y Max, o depurar un agente en Tiempo real que no publique ni transfiera. También úselos al migrar una aplicación de voz construida sobre la API y SDK en tiempo real de OpenAI (`@openai/agents-realtime`, `gpt-realtime`) a la API en tiempo real compatible con OpenAI de ElevenLabs, incluido el mint de `client_secrets`, el transporte WebSocket y el audio después de abandonar WebRTC (cierra con 4001/4003, sin audio). No es para elegir el modelo LLM o TTS de un agente en modo Personalizado, Scribe de reconocimiento de voz en tiempo real, o migrar llamadas de texto de la API de Chat Completions o Responses.
