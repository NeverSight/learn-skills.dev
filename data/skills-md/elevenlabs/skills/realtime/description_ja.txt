ElevenLabs のリアルタイムモデル（`eleven_realtime_v1_mini`、`eleven_realtime_v1_max`）は、音声会話向けに構築された低レイテンシーモデルです。ユーザーがリアルタイムモデル上で ElevenAgents エージェントを作成したい場合、既存エージェントの Voice モードをリアルタイムに切り替える場合、`conversation_config.realtime_model` を設定する場合、Realtime Mini と Max のどちらかを選択する場合、または公開や転送ができないリアルタイムエージェントのデバッグを行う場合に使用します。また、OpenAI の Realtime API と SDK（`@openai/agents-realtime`、`gpt-realtime`）で構築された音声アプリを OpenAI 互換の ElevenLabs Realtime API に移行する際にも使用します。この移行には `client_secrets` の発行、WebSocket トランスポート、WebRTC から離れた後のオーディオ（4001/4003 でクローズ、オーディオなし）も含まれます。Custom モードでエージェントの LLM や TTS モデルを選択する場合、Scribe のリアルタイム音声認識、または Chat Completions や Responses API のテキスト呼び出しの移行には使用しないでください。
