使用 ElevenLabs 实时模型（`eleven_realtime_v1_mini`、`eleven_realtime_v1_max`），这些低延迟模型专为语音对话构建。当用户想在实时模型上创建 ElevenAgents 代理，或将已有代理的语音模式切换为实时，设置 `conversation_config.realtime_model`，在实时 Mini 与 Max 之间选择，或调试无法发布或转移的实时代理时使用。也用于将基于 OpenAI 实时 API 与 SDK（`@openai/agents-realtime`、`gpt-realtime`）构建的语音应用迁移到兼容 OpenAI 的 ElevenLabs 实时 API，包括 `client_secrets` 铸造、WebSocket 传输，以及离开 WebRTC 后的音频（以 4001/4003 关闭，无音频）。不用于在自定义模式下选择代理的 LLM 或 TTS 模型，不用于 Scribe 实时语音转文本，也不用于迁移 Chat Completions 或 Responses API 的文本调用。
