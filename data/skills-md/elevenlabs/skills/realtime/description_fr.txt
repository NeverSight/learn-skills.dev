Utilisez les modèles ElevenLabs Realtime (`eleven_realtime_v1_mini`, `eleven_realtime_v1_max`), les modèles à faible latence conçus pour la conversation vocale. Utilisez-les lorsque l'utilisateur souhaite créer un agent ElevenAgents sur un modèle Realtime ou basculer le mode Voix d'un agent existant en Realtime, définir `conversation_config.realtime_model`, choisir entre Realtime Mini et Max, ou déboguer un agent Realtime qui ne publie pas ou ne transfère pas. Utilisez également lors de la migration d'une application vocale construite sur l'API Realtime et le SDK d'OpenAI (`@openai/agents-realtime`, `gpt-realtime`) vers l'API Realtime compatible OpenAI d'ElevenLabs, y compris la génération de `client_secrets`, le transport WebSocket et l'audio après la sortie de WebRTC (ferme avec 4001/4003, pas d'audio). Ce n'est pas destiné à choisir le modèle LLM ou TTS d'un agent en mode Personnalisé, à la transcription en temps réel de Scribe, ou à la migration des appels texte des API Chat Completions ou Responses.
