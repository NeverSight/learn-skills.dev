Используйте модели ElevenLabs Realtime (`eleven_realtime_v1_mini`, `eleven_realtime_v1_max`) — модели с низкой задержкой, созданные для голосового диалога. Применяйте их, когда пользователь хочет создать агента ElevenAgents на модели Realtime или переключить режим Voice существующего агента на Realtime, установить `conversation_config.realtime_model`, выбрать между Realtime Mini и Max, либо отладить агент Realtime, который не публикуется или не передаёт данные. Также используйте их при миграции голосового приложения, построенного на Realtime API и SDK OpenAI (`@openai/agents-realtime`, `gpt-realtime`), к совместимому с OpenAI ElevenLabs Realtime API, включая генерацию `client_secrets`, транспорт WebSocket и аудио после выхода из WebRTC (закрывается с кодами 4001/4003, без аудио). Не предназначено для выбора LLM или модели TTS агента в режиме Custom, для Scribe realtime speech‑to‑text, или для миграции текстовых вызовов Chat Completions или Responses API.

Пожалуйста, всегда отвечайте на языке пользователя.
