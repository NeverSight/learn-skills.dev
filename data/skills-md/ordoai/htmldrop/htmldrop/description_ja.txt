ローカルの HTML または Markdown アーティファクトを baseurl.ai にアップロードし、共有可能でパスワード付きのプレビュー URL を返します。ユーザーが .html、.htm、.md、または .markdown のローカルファイル（生成したレポートやドキュメントを含む）を公開、共有、ホスト、プレビュー、リンク送付、またはアクセス可能にするよう求めた場合は、常にこの機能を使用してください。また、ワークフローでレンダリング可能なローカルコンテンツが生成され、次の有用なステップが他者が開くことのできる URL になる場合にも使用します。ただし、プロダクション環境へのデプロイや長期的なホスティング、レンダリングできないソースファイルについては、まずローカルの HTML または Markdown アーティファクトを作成しない限り使用しないでください。
