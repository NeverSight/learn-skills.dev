قم بتحميل القطع الفنية المحلية بصيغة HTML أو Markdown إلى baseurl.ai وارجع بعنوان URL للمعاينة قابل للمشاركة ويحمل كلمة مرور. استخدم هذه الميزة كلما طلب المستخدم النشر أو المشاركة أو الاستضافة أو المعاينة أو إرسال رابط أو جعل أي ملف .html أو .htm أو .md أو .markdown محلي متاحًا، بما في ذلك التقارير أو المستندات التي قمت بإنشائها للتو. استخدمها أيضًا عندما ينتج سير العمل محتوى محلي قابل للعرض وتكون الخطوة المفيدة التالية هي الحصول على عنوان URL يمكن لشخص آخر فتحه. لا تستخدمها لنشر الإنتاج أو الاستضافة طويلة الأمد أو ملفات المصدر غير القابلة للعرض ما لم تقم أولاً بإنشاء قطعة فنية محلية بصيغة HTML أو Markdown. يرجى دائمًا الرد بلغة المستخدم.
