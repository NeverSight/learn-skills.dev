Sube artefactos locales de HTML o Markdown a baseurl.ai y devuelve una URL de vista previa compartible y protegida con contraseña. Usa esta habilidad cada vez que el usuario solicite publicar, compartir, alojar, previsualizar, enviar un enlace o hacer accesible cualquier archivo local .html, .htm, .md o .markdown, incluidos los informes o documentos que acabas de generar. También úsala cuando un flujo de trabajo produce contenido local renderizable y el siguiente paso útil es una URL que otra persona pueda abrir. No la uses para implementaciones de producción, alojamiento a largo plazo o archivos fuente no renderizables, salvo que primero crees un artefacto local de HTML o Markdown.

Por favor, responde siempre en el idioma del usuario.
