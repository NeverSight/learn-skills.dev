Sichere Refactoring-Anleitung für Legacy- und vorhandene Codebasen. Verwendung bei der Verbesserung des Designs, ohne das Verhalten zu ändern, beim Erstellen von Nähten um harte Abhängigkeiten, beim Migrieren von Null-/String-/generischen Ausnahmen zu typisierten Fehlerverträgen, beim Extrahieren eines Repositorys aus dem direkten SQL/ORM-Zugriff, beim Einführen von Domänenereignissen in Legacy-Workflows, beim Hinzufügen von Charakterisierungstests, beim Aufteilen großer Klassen oder Methoden, beim Einführen von Wertobjekten, beim Ersetzen von Bedingungswerten oder beim schrittweisen Entwickeln von Code unter Risiko.
