Crea videos verticales cortos (TikTok / Reels / Shorts / 抖音 / 快手 / 小红书) a partir de un tema, un enlace/imagen de producto o un guion que ya hayas escrito. ClipForge ejecuta todo el proceso — guion → metraje → locución → subtítulos → música de fondo → composición — con una ruta gratuita y sin necesidad de clave API (stock gratuito + Edge TTS + FFmpeg local). Úsalo cuando el usuario quiera convertir una idea, producto o narración escrita en un video corto finalizado. Las reglas de corrección del flujo son estrictas; lo creativo queda a tu criterio.
