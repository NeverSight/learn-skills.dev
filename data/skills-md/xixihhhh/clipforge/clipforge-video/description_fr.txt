Créez de courtes vidéos verticales (TikTok / Reels/Shorts//抖音 快手/小红书) à partir d'un sujet, d'un lien produit/d'une image ou d'un script que vous avez déjà écrit. ClipForge exécute le pipeline complet — → sous-titres de → voix off de → séquences de script → composées par → BGM — avec un chemin gratuit, sans clé API (stock gratuit + Edge TTS + FFmpeg local). À utiliser lorsque l'utilisateur souhaite transformer une idée, un produit ou une narration écrite en une courte vidéo terminée. Les règles de correction du pipeline sont difficiles ; tout ce qui est créatif est votre choix.
