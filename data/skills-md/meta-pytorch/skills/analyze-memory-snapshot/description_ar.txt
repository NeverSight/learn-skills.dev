قم بتحليل لقطات ذاكرة PyTorch CUDA من torch.cuda.memory._dump_snapshot() أو torch.cuda.memory._snapshot() أو عناصر Memory_viz. يُستخدم عندما يريد المستخدم فهم استخدام ذاكرة GPU، أو مواقع التخصيص العليا، أو توقيت إلغاء التخصيص، أو OOMs، أو تجزئة المُخصص، أو الذاكرة المؤقتة غير النشطة، أو تسرب الذاكرة، أو الموترات المحتجزة، أو دورات Python المرجعية في أحمال عمل PyTorch. يدعم اختلاف لقطتين من نفس التشغيل لتحديد مواقع التخصيص المتزايدة.
