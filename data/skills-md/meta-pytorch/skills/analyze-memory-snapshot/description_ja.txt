torch.cuda.memory._dump_snapshot()、torch.cuda.memory._snapshot()、またはmemory_vizアーティファクトからのPyTorch CUDAメモリスナップショットを分析します。ユーザーが GPU メモリ使用量、トップ割り当てサイト、割り当て解除のタイミング、OOM、アロケータのフラグメンテーション、非アクティブなキャッシュ メモリ、メモリ リーク、保持されたテンソル、または PyTorch ワークロードの Python 参照サイクルを理解したい場合に使用します。増加する割り当てサイトを特定するために、同じ実行からの 2 つのスナップショットの差分をサポートします。
