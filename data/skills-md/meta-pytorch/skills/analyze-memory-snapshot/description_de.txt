Analysieren Sie PyTorch CUDA-Speicher-Snapshots von Torch.cuda.memory._dump_snapshot(), Torch.cuda.memory._snapshot() oder Memory_viz-Artefakten. Verwenden Sie diese Option, wenn der Benutzer die GPU-Speichernutzung, Top-Zuweisungsstandorte, Freigabezeitpunkt, OOMs, Allokatorfragmentierung, inaktiven zwischengespeicherten Speicher, Speicherlecks, beibehaltene Tensoren oder Python-Referenzzyklen in PyTorch-Workloads verstehen möchte. Unterstützt die Differenzierung zweier Snapshots desselben Laufs, um wachsende Zuordnungsstandorte genau zu bestimmen.
