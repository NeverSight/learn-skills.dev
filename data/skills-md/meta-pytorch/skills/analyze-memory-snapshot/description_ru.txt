Анализируйте снимки памяти CUDA PyTorch, полученные с помощью torch.cuda.memory._dump_snapshot(), torch.cuda.memory._snapshot() или артефактов memory_viz. Используйте, когда нужно понять использование памяти GPU, основные места выделения, время деаллокации, OOM, фрагментацию аллокатора, неактивную кэшированную память, утечки памяти, удерживаемые тензоры или циклы ссылок Python в задачах PyTorch. Поддерживается сравнение (diff) двух снимков из одного запуска для выявления растущих мест выделения.
