Analysez les instantanés de mémoire PyTorch CUDA à partir des artefacts torch.cuda.memory._dump_snapshot(), torch.cuda.memory._snapshot() ou memory_viz. À utiliser lorsque l'utilisateur souhaite comprendre l'utilisation de la mémoire GPU, les principaux sites d'allocation, le timing de désallocation, les MOO, la fragmentation de l'allocateur, la mémoire mise en cache inactive, les fuites de mémoire, les tenseurs conservés ou les cycles de référence Python dans les charges de travail PyTorch. Prend en charge la comparaison de deux instantanés de la même exécution pour identifier les sites d'allocation croissants.
