Создавайте процедурные модели Three.js из объектов‑референсов изображений. Используйте их для оценки возможности реконструкции, планирования процедурного строительства, нативной реализации в коде, а также для получения структуры, готовой к анимации, коллайдерам и разрушениям, из одного или нескольких представлений объекта.
