دليل إدارة شهادات Infisical (PKI) — إصدار، تجديد، إلغاء وتوزيع شهادات X.509. يغطي جميع الأنواع التسعة لسلطات الشهادات (سلطة الجذر/الوسيط الداخلية، ACME بما فيها Let's Encrypt، AWS Private CA، AWS ACM Public CA، Microsoft ADCS، Azure ADCS، DigiCert، Venafi TPP، GoDaddy)، التطبيقات وملفات تعريف الشهادات، جميع طرق التسجيل الأربعة (API، ACME، EST، SCEP)، جميع عمليات المزامنة الـ 12 لـ PKI لدفع الشهادات إلى AWS ACM / Azure Key Vault / Cloudflare / موازنات التحميل، دورة حياة الشهادة والتنبيهات، توقيع الشيفرات باستخدام PKCS#11 و Windows KSP، اكتشاف الشهادات، موصلات HSM، توزيع CRL، وخوارزميات المفاتيح ما بعد الكم ML‑DSA و SLH‑DSA. استخدم هذه المهارة عندما يسأل أحدهم عن: Infisical PKI، سلطة الشهادات، إصدار شهادة TLS، شهادات mTLS، ACME أو Let's Encrypt مع Infisical، تسجيل EST أو SCEP، تجديد الشهادة، الإلغاء، CRL، شهادات توقيع الشيفرات، أو “كيف أدير الشهادات مع Infisical”. تُستَخدم للشهادات X.509/TLS وتوقيع الشيفرات. لا تُستَخدم لشهادات SSH (infisical‑dynamic‑secrets)، ولا لتشفير البيانات بمفتاح مُدار (infisical‑kms). يرجى دائمًا الرد بلغة المستخدم.
