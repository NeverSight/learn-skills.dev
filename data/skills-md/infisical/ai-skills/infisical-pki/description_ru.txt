Руководство по управлению сертификатами Infisical (PKI) — выпуск, продление, отзыв и распределение сертификатов X.509. Охватывает все 9 типов центров сертификации (внутренний корневой/промежуточный CA, ACME, включая Let’s Encrypt, AWS Private CA, AWS ACM Public CA, Microsoft ADCS, Azure ADCS, DigiCert, Venafi TPP, GoDaddy), приложения и профили сертификатов, все 4 метода регистрации (API, ACME, EST, SCEP), все 12 синхронизаций PKI для передачи сертификатов в AWS ACM / Azure Key Vault / Cloudflare / балансировщики нагрузки, жизненный цикл сертификатов и оповещения, подпись кода с PKCS#11 и Windows KSP, обнаружение сертификатов, коннекторы HSM, распространение CRL и постквантовые алгоритмы ключей ML-DSA и SLH-DSA. Используйте эту подсказку, когда кто‑то спрашивает о: Infisical PKI, центре сертификации, выпуске TLS‑сертификата, mTLS‑сертификатах, ACME или Let’s Encrypt с Infisical, регистрации EST или SCEP, продлении сертификата, отзыве, CRL, сертификатах подписи кода, или «как управлять сертификатами с Infisical». Для сертификатов X.509/TLS и подписи кода. Не для SSH‑сертификатов (infisical-dynamic-secrets) и не для шифрования данных управляемым ключом (infisical-kms).
