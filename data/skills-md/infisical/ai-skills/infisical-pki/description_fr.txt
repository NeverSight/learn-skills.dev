Guide de gestion des certificats Infisical (PKI) — émission, renouvellement, révocation et distribution des certificats X.509. Couvre les 9 types d’autorité de certification (CA racine/intermédiaire interne, ACME incluant Let’s Encrypt, AWS Private CA, AWS ACM Public CA, Microsoft ADCS, Azure ADCS, DigiCert, Venafi TPP, GoDaddy), les Applications et les Profils de certificats, les 4 méthodes d’inscription (API, ACME, EST, SCEP), les 12 synchronisations PKI pour pousser les certificats vers AWS ACM / Azure Key Vault / Cloudflare / équilibreurs de charge, le cycle de vie des certificats et les alertes, la signature de code avec PKCS#11 et Windows KSP, la découverte de certificats, les connecteurs HSM, la distribution de CRL, et les algorithmes de clés post‑quantique ML‑DSA et SLH‑DSA. Utilisez cette compétence lorsque quelqu’un demande : Infisical PKI, autorité de certification, émission d’un certificat TLS, certificats mTLS, ACME ou Let’s Encrypt avec Infisical, inscription EST ou SCEP, renouvellement de certificat, révocation, CRL, certificats de signature de code, ou « comment gérer les certificats avec Infisical ». Pour les certificats X.509/TLS et la signature de code. Pas pour les certificats SSH (infisical-dynamic-secrets), ni pour le chiffrement de données avec une clé gérée (infisical‑kms).
