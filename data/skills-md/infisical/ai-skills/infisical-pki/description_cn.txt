Infisical 证书管理（PKI）指南——发行、续订、吊销和分发 X.509 证书。涵盖所有 9 种证书颁发机构类型（内部根/中间 CA、包括 Let's Encrypt 的 ACME、AWS Private CA、AWS ACM 公共 CA、Microsoft ADCS、Azure ADCS、DigiCert、Venafi TPP、GoDaddy），应用程序和证书配置文件，全部 4 种注册方式（API、ACME、EST、SCEP），全部 12 种 PKI 同步用于将证书推送到 AWS ACM / Azure Key Vault / Cloudflare / 负载均衡器，证书生命周期和警报，使用 PKCS#11 和 Windows KSP 的代码签名，证书发现，HSM 连接器，CRL 分发，以及后量子 ML-DSA 和 SLH-DSA 密钥算法。 在有人询问以下内容时使用此技能：Infisical PKI、证书颁发机构、颁发 TLS 证书、mTLS 证书、使用 Infisical 的 ACME 或 Let's Encrypt、EST 或 SCEP 注册、证书续订、吊销、CRL、代码签名证书，或“如何使用 Infisical 管理证书”。适用于 X.509/TLS 证书和代码签名。不适用于 SSH 证书（infisical-dynamic-secrets），也不适用于使用托管密钥加密数据（infisical-kms）。
