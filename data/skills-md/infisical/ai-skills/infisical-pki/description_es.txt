Guía para la gestión de certificados Infisical (PKI) — emisión, renovación, revocación y distribución de certificados X.509. Cubre los 9 tipos de autoridad de certificación (CA raíz/intermedia interna, ACME incluida Let's Encrypt, AWS Private CA, AWS ACM Public CA, Microsoft ADCS, Azure ADCS, DigiCert, Venafi TPP, GoDaddy), aplicaciones y perfiles de certificado, los 4 métodos de inscripción (API, ACME, EST, SCEP), los 12 sincronizaciones PKI para enviar certificados a AWS ACM / Azure Key Vault / Cloudflare / balanceadores de carga, el ciclo de vida del certificado y alertas, firma de código con PKCS#11 y Windows KSP, descubrimiento de certificados, conectores HSM, distribución de CRL y algoritmos de clave postcuánticos ML-DSA y SLH-DSA. Utiliza esta habilidad cuando alguien pregunte sobre: PKI de Infisical, autoridad de certificación, emisión de un certificado TLS, certificados mTLS, ACME o Let's Encrypt con Infisical, inscripción EST o SCEP, renovación de certificado, revocación, CRL, certificados de firma de código, o “cómo gestiono certificados con Infisical”. Para certificados X.509/TLS y firma de código. No es para certificados SSH (infisical-dynamic-secrets), ni para cifrar datos con una clave gestionada (infisical-kms).
