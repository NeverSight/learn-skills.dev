دليل فحص الأسرار في Infisical — الكشف عن بيانات الاعتماد المسربة في شفرة المصدر وأنظمة المطورين. يغطي مصادر البيانات السحابية الثلاث (GitHub عبر اتصال GitHub Radar، GitLab، Bitbucket)، الفحص الكامل مقابل الفحوصات التلقائية للفرق عند الدفع، دورة حياة الاكتشاف والدرجة، أداة سطر الأوامر `infisical scan` لسجل Git، دلائل العمل، التغييرات المرحلية وأنابيب CI، تثبيت خطاف ما قبل الالتزام باستخدام `infisical scan install --pre-commit-hook`، تقليل الضوضاء عبر infisical-scan:ignore، .infisicalignore، حدود الإنتروبيا والقواعد المخصصة، ورموز العسل في AWS كبيانات اعتماد إيهامية تنبه عند الاستخدام. استخدم هذه المهارة عندما يسأل أحدهم عن: فحص أسرار Infisical، العثور على أسرار مسربة في مستودع، فحص سجل Git للبيانات الاعتمادية، فحص الأسرار قبل الالتزام، الإيجابيات الكاذبة في الفحص، أو رموز العسل. ليست لتخزين الأسرار لمنع تسريبها (infisical-setup) أو لتدوير أحدها التي تسربت (infisical-secret-rotation). يتطلب فحص GitHub اتصال تطبيق github‑radar، وليس اتصال GitHub عادي.
