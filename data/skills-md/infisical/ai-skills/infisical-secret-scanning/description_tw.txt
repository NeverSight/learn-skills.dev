Infisical 秘密掃描指南 — 偵測程式碼與開發者系統中洩漏的憑證。涵蓋三種雲端資料來源（透過 GitHub Radar 連線的 GitHub、GitLab、Bitbucket）、完整掃描與推送時自動差異掃描、發現生命週期與嚴重性、`infisical scan` CLI 用於 Git 歷史、工作目錄、暫存變更與 CI 管線、使用 `infisical scan install --pre-commit-hook` 安裝 pre‑commit 鉤子、透過 infisical‑scan:ignore、.infisicalignore、熵門檻與自訂規則降低雜訊，以及作為誘餌的 AWS honey token，使用時會發出警報。當有人詢問以下主題時請使用此技能：Infisical 秘密掃描、在倉庫中尋找洩漏的祕密、掃描 Git 歷史以查找憑證、pre‑commit 秘密掃描、掃描中的誤報或 honey token。此技能不適用於儲存祕密以防止洩漏（infisical-setup）或輪換已洩漏的祕密（infisical-secret-rotation）。GitHub 掃描需使用 github‑radar 應用程式連線，而非普通的 github 連線。
