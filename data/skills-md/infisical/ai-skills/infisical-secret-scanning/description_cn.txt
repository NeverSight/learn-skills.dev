Infisical 密钥扫描指南 — 检测源码和开发者系统中泄漏的凭证。涵盖 3 种云数据源（通过 GitHub Radar 连接的 GitHub、GitLab、Bitbucket），全量扫描 与 推送时的自动差异扫描，发现的生命周期及严重性，`infisical scan` CLI 用于 Git 历史、工作目录、已暂存更改和 CI 流水线，使用 `infisical scan install --pre-commit-hook` 安装 pre‑commit 钩子，通过 infisical-scan:ignore、.infisicalignore、熵阈值和自定义规则进行噪声抑制，以及作为诱饵凭证并在使用时触发警报的 AWS honey token。 当有人询问以下内容时使用此技能：Infisical 密钥扫描、在仓库中查找泄漏的密钥、扫描 Git 历史中的凭证、pre‑commit 密钥扫描、扫描中的误报或 honey token。 不适用于存储密钥以防止泄漏（infisical-setup）或轮换已泄漏的密钥（infisical-secret-rotation）。GitHub 扫描需要 github‑radar 应用连接，而不是普通的 github 连接。
