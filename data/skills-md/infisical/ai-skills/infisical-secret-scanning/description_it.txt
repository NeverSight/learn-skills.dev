Guida per la scansione dei segreti con Infisical — rilevamento di credenziali trapelate nel codice sorgente e nei sistemi degli sviluppatori. Copre le 3 fonti di dati cloud (GitHub tramite una connessione GitHub Radar, GitLab, Bitbucket), scansioni complete vs scansioni differenziali automatiche al push, ciclo di vita e gravità dei segreti, il CLI `infisical scan` per la cronologia Git, le directory di lavoro, le modifiche in staging e le pipeline CI, l'installazione dell'hook pre‑commit con `infisical scan install --pre-commit-hook`, la riduzione del rumore tramite infisical-scan:ignore, .infisicalignore, soglie di entropia e regole personalizzate, e i honey token AWS come credenziali esca che segnalano l'uso. Usa questa competenza quando qualcuno chiede di: scansione dei segreti con Infisical, trovare segreti trapelati in un repository, scansione della cronologia Git per credenziali, scansione dei segreti pre‑commit, falsi positivi nella scansione o honey token. Non è destinata a memorizzare segreti per evitare perdite (infisical-setup) né a ruotare un segreto trapelato (infisical-secret-rotation). La scansione di GitHub richiede una connessione app GitHub Radar, non una connessione GitHub standard.
