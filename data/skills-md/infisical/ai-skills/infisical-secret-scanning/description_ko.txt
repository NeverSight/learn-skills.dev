Infisical 비밀 스캔 가이드 — 소스 코드와 개발자 시스템에서 유출된 자격 증명을 감지합니다. GitHub Radar 연결을 통한 GitHub, GitLab, Bitbucket 등 3개의 클라우드 데이터 소스를 다루며, 전체 스캔과 푸시 시 자동 차이(diff) 스캔, 비밀의 수명 주기와 심각도, Git 히스토리, 작업 디렉터리, 스테이징된 변경 사항 및 CI 파이프라인을 위한 `infisical scan` CLI, `infisical scan install --pre-commit-hook` 로 사전 커밋 훅 설치, infisical-scan:ignore, .infisicalignore, 엔트로피 임계값 및 사용자 정의 규칙을 통한 노이즈 감소, 사용 시 경고가 발생하는 AWS 허니 토큰(위장 자격 증명)을 포함합니다. 이 기능은 다음과 같은 질문이 있을 때 사용하세요: Infisical 비밀 스캔, 레포에서 유출된 비밀 찾기, Git 히스토리에서 자격 증명 스캔, 사전 커밋 비밀 스캔, 스캔의 오탐, 혹은 허니 토큰. 비밀을 저장해 유출을 방지하는 용도(infisical-setup)나 유출된 비밀을 회전시키는 용도(infisical-secret-rotation)에는 사용하지 마세요. GitHub 스캔은 github-radar 앱 연결이 필요하며, 일반 GitHub 연결은 사용할 수 없습니다.
