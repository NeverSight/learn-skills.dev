Guide d'analyse des secrets Infisical — détecter les identifiants divulgués dans le code source et les systèmes des développeurs. Couvre les 3 sources de données cloud (GitHub via une connexion GitHub Radar, GitLab, Bitbucket), les analyses complètes versus les analyses diff automatiques lors du push, le cycle de vie et la gravité des découvertes, le CLI `infisical scan` pour l'historique Git, les répertoires de travail, les modifications en cours et les pipelines CI, l'installation du hook pre‑commit avec `infisical scan install --pre-commit-hook`, la réduction du bruit via infisical‑scan:ignore, .infisicalignore, les seuils d'entropie et les règles personnalisées, ainsi que les honey tokens AWS comme identifiants factices qui déclenchent une alerte lorsqu'ils sont utilisés. Utilisez cette compétence lorsqu’on vous demande : l’analyse des secrets Infisical, la détection de secrets divulgués dans un dépôt, l’analyse de l’historique Git pour des identifiants, l’analyse des secrets en pre‑commit, les faux positifs dans l’analyse ou les honey tokens. Ce n’est pas destiné au stockage de secrets pour les empêcher de fuir (infisical-setup) ou à la rotation d’un secret qui a fuité (infisical-secret-rotation). L’analyse GitHub nécessite une connexion d’application github‑radar, pas une connexion GitHub standard.
