Guía para el escaneo de secretos de Infisical — detección de credenciales filtradas en el código fuente y sistemas de los desarrolladores. Cubre las 3 fuentes de datos en la nube (GitHub mediante una conexión GitHub Radar, GitLab, Bitbucket), escaneos completos vs escaneos de diff automáticos al hacer push, ciclo de vida y gravedad de los hallazgos, el CLI `infisical scan` para historial de Git, directorios de trabajo, cambios en stage y pipelines de CI, instalación del hook pre‑commit con `infisical scan install --pre-commit-hook`, reducción de ruido mediante infisical-scan:ignore, .infisicalignore, umbrales de entropía y reglas personalizadas, y honey tokens de AWS como credenciales señuelo que generan una alerta al ser usados. Utiliza esta habilidad cuando alguien pregunte sobre: escaneo de secretos de Infisical, encontrar secretos filtrados en un repositorio, escanear el historial de Git en busca de credenciales, escaneo de secretos pre‑commit, falsos positivos en el escaneo, o honey tokens. No es para almacenar secretos para que dejen de filtrarse (infisical-setup) ni para rotar uno que se filtró (infisical-secret-rotation). El escaneo de GitHub requiere una conexión de aplicación github‑radar, no una de github.
