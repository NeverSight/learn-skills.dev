Infisical シークレットスキャンガイド — ソースコードや開発者システムに漏れた認証情報を検出します。GitHub（GitHub Radar 接続経由）、GitLab、Bitbucket の 3 つのクラウドデータソースを対象に、フルスキャンとプッシュ時の自動差分スキャン、検出ライフサイクルと深刻度、Git の履歴、作業ディレクトリ、ステージングされた変更、CI パイプライン向けの `infisical scan` CLI、`infisical scan install --pre-commit-hook` による pre‑commit フックのインストール、infisical-scan:ignore、.infisicalignore、エントロピーしきい値やカスタムルールによるノイズ削減、そして使用時に警告を出すデコイ認証情報としての AWS ハニートークンについて説明します。このスキルは、以下の質問に対して使用してください：Infisical シークレットスキャン、リポジトリ内の漏洩したシークレットの検索、認証情報のための git 履歴スキャン、pre‑commit シークレットスキャン、スキャンにおける偽陽性、ハニートークン。シークレットを保存して漏洩を防止する（infisical-setup）や、漏洩したシークレットをローテーションする（infisical-secret-rotation）目的には使用しないでください。GitHub のスキャンには github-radar アプリ接続が必要で、通常の github 接続ではありません。
