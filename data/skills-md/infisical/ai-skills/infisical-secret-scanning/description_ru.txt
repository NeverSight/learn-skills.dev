Руководство по сканированию секретов Infisical — обнаружение утекших учётных данных в исходном коде и системах разработчиков. Охватывает три облачных источника данных (GitHub через подключение GitHub Radar, GitLab, Bitbucket), полные сканирования vs автоматические сканирования diff при push, жизненный цикл находок и их степень серьёзности, CLI `infisical scan` для истории Git, рабочих каталогов, подготовленных изменений и CI‑конвейеров, установку pre‑commit‑хука командой `infisical scan install --pre-commit-hook`, уменьшение шума через `infisical-scan:ignore`, `.infisicalignore`, пороги энтропии и пользовательские правила, а также AWS honey‑токены — поддельные учётные данные, генерирующие тревогу при использовании. Используйте эту инструкцию, когда кто‑то спрашивает о сканировании секретов Infisical, поиске утекших секретов в репозитории, сканировании истории Git на предмет учётных данных, сканировании секретов в pre‑commit, ложных срабатываниях сканирования или honey‑токенах. Не предназначено для хранения секретов, чтобы они перестали утекать (infisical‑setup) или для ротации утекшего секрета (infisical‑secret‑rotation). Сканирование GitHub требует подключения приложения github‑radar, а не обычного github.
