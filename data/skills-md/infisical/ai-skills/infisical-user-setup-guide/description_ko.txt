프로젝트에서 비밀 관리 도구로 Infisical을 사용하는 인터랙티브 설정 가이드입니다. 사용자가 Infisical을 로컬 개발(CLI), Docker 컨테이너(빌드 시 및 실행 시 비밀 주입), CI/CD 파이프라인(GitHub Actions, GitLab CI), Kubernetes(Operator + CRD), 그리고 애플리케이션 코드(모든 9개 SDK: Node.js, Python, Go, Java, .NET, Ruby, PHP, Rust, C++)에 통합하도록 돕습니다. 또한 13가지 머신 아이덴티티 인증 방법(Universal, Token, Kubernetes, GCP, AliCloud, AWS, Azure, TLS Cert, OCI, OIDC, JWT, LDAP, SPIFFE) 중 원하는 것을 선택하고 설정하는 과정을 안내합니다. 다음과 같은 질문이 있을 때마다 이 스킬을 사용하십시오: Infisical 사용, 비밀 주입, infisical run, infisical init, 애플리케이션을 Infisical에 연결, Docker 비밀, Kubernetes 비밀 오퍼레이터, 머신 아이덴티티 설정, SDK 초기화, CI/CD 비밀 주입, 혹은 “내 비밀을 애플리케이션에 어떻게 넣나요?”와 같은 내용. 다만 Kubernetes Operator CRD(infisical‑kubernetes‑operator), 파일에 비밀을 렌더링하는 방법(infisical‑agent), 비밀을 외부로 푸시하는 방법(infisical‑secret‑syncs), 인간 SSO 로그인(infisical‑sso)에는 적용되지 않습니다. 

항상 사용자의 언어로 응답하십시오.
