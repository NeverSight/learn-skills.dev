Guide interactif d'installation pour utiliser Infisical comme outil de gestion des secrets dans vos projets. Aide les utilisateurs à intégrer Infisical dans le développement local (CLI), les conteneurs Docker (injection de secrets au moment de la construction et à l'exécution), les pipelines CI/CD (GitHub Actions, GitLab CI), Kubernetes (Operator + CRDs) et le code applicatif (les 9 SDK : Node.js, Python, Go, Java, .NET, Ruby, PHP, Rust, C++). Présente également le choix et la configuration de l’une des 13 méthodes d’authentification d’identité machine (Universal, Token, Kubernetes, GCP, AliCloud, AWS, Azure, certificat TLS, OCI, OIDC, JWT, LDAP, SPIFFE). Utilisez cette compétence chaque fois que quelqu’un demande : utiliser Infisical, injecter des secrets, infisical run, infisical init, connecter son appli à Infisical, secrets Docker, opérateur de secrets Kubernetes, configuration d’identité machine, initialisation du SDK, injection de secrets CI/CD, ou « comment mettre mes secrets dans mon appli ». Cela ne concerne pas les CRDs de l’opérateur Kubernetes (infisical‑kubernetes‑operator), le rendu de secrets vers des fichiers (infisical‑agent), la synchronisation de secrets vers l’extérieur (infisical‑secret‑syncs) ou la connexion SSO humaine (infisical‑sso).
