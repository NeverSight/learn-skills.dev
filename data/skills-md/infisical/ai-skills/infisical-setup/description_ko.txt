프로젝트에서 비밀 관리 도구로 Infisical을 사용하는 대화형 설정 가이드입니다. 사용자가 Infisical을 로컬 개발(CLI), Docker 컨테이너(빌드 시 및 런타임 비밀 주입), CI/CD 파이프라인(GitHub Actions, GitLab CI), Kubernetes(Operator + CRD), 그리고 애플리케이션 코드(전체 9개 SDK: Node.js, Python, Go, Java, .NET, Ruby, PHP, Rust, C++)에 통합하도록 돕습니다. 또한 13가지 머신 아이덴티티 인증 방법(Universal, Token, Kubernetes, GCP, AliCloud, AWS, Azure, TLS Cert, OCI, OIDC, JWT, LDAP, SPIFFE) 중 선택하고 구성하는 방법을 안내합니다. 다음과 같은 질문이 있을 때마다 이 스킬을 사용하세요: Infisical 사용, 비밀 주입, infisical run, infisical init, 애플리케이션을 Infisical에 연결, Docker 비밀, Kubernetes 비밀 오퍼레이터, 머신 아이덴티티 설정, SDK 초기화, CI/CD 비밀 주입, 또는 “내 비밀을 애플리케이션에 어떻게 전달합니까”. Kubernetes Operator CRD(infisical‑kubernetes‑operator), 파일에 비밀을 렌더링(infisical‑agent), 비밀을 외부로 푸시(infisical‑secret‑syncs), 인간 SSO 로그인(infisical‑sso)에 대해서는 해당되지 않습니다.  
항상 사용자의 언어로 답변하세요.
