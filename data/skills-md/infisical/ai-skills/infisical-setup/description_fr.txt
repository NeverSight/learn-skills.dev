Guide d'installation interactif pour utiliser Infisical comme outil de gestion de secrets dans vos projets. Aide les utilisateurs à intégrer Infisical dans le développement local (CLI), les conteneurs Docker (injection de secrets au moment de la construction et à l'exécution), les pipelines CI/CD (GitHub Actions, GitLab CI), Kubernetes (Opérateur + CRD) et le code applicatif (les 9 SDK : Node.js, Python, Go, Java, .NET, Ruby, PHP, Rust, C++). Passe également en revue le choix et la configuration de l'une des 13 méthodes d'authentification d'identité machine (Universal, Token, Kubernetes, GCP, AliCloud, AWS, Azure, certificat TLS, OCI, OIDC, JWT, LDAP, SPIFFE). Utilisez cette compétence chaque fois que quelqu'un demande : comment utiliser Infisical, injecter des secrets, infisical run, infisical init, connecter son application à Infisical, secrets Docker, opérateur de secrets Kubernetes, configuration d'identité machine, initialisation du SDK, injection de secrets CI/CD, ou « comment mettre mes secrets dans mon application ». Ce guide ne concerne pas les CRD de l'opérateur Kubernetes (infisical‑kubernetes‑operator), le rendu de secrets vers des fichiers (infisical‑agent), la synchronisation de secrets vers l'extérieur (infisical‑secret‑syncs), ni la connexion SSO humaine (infisical‑sso).
