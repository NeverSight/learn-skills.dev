Guide pour créer et gérer les connexions d’application Infisical — les liens authentifiés réutilisables entre Infisical et les services tiers dont dépendent les synchronisations de secrets, les rotations de secrets, les autorités de certificats PKI, les synchronisations PKI et les sources de données d’analyse de secrets. Couvre les 83 types de connexion et leurs méthodes d’authentification exactes (AWS assume‑role vs clé d’accès, GitHub OAuth vs GitHub App vs PAT, Azure OAuth vs client‑secret vs certificat, usurpation de compte de service GCP, etc.), les identifiants gérés par la plateforme, les connexions routées via Gateway pour les réseaux privés, et la rotation des identifiants au niveau de la connexion. Utilisez cette compétence lorsqu’on vous demande : les connexions d’application, connecter Infisical à AWS/GCP/Azure/GitHub, « connexion introuvable » lors de la création d’une synchronisation, quelle méthode d’authentification une connexion nécessite, réutiliser une connexion entre plusieurs synchronisations, ou « comment authentifier Infisical auprès d’un service tiers ». Il s’agit d’Infisical s’authentifiant EN VERS l’extérieur vers un tiers. Pas pour les identités machine, qui sont des charges de travail s’authentifiant DANS Infisical (infisical-setup).
