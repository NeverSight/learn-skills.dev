دليل لإنشاء وإدارة اتصالات تطبيق Infisical — الروابط الموثقة القابلة لإعادة الاستخدام بين Infisical والخدمات الخارجية التي تعتمد عليها مزامنة الأسرار وتدوير الأسرار وسلطات شهادات PKI ومزامنات PKI ومصادر بيانات فحص الأسرار. يغطي جميع الأنواع الـ 83 للاتصالات وطُرق المصادقة الدقيقة الخاصة بها (AWS assume‑role مقابل access‑key، GitHub OAuth مقارنةً بـ GitHub App أو PAT، Azure OAuth مقارنةً بـ client‑secret أو الشهادة، انتحال حساب خدمة GCP، والمزيد)، بيانات الاعتماد التي تُدار من المنصة، الاتصالات الموجهة عبر Gateway للشبكات الخاصة، وتدوير بيانات الاعتماد على مستوى الاتصال. استخدم هذه المهارة عندما يطرح أحدهم سؤالاً حول: اتصالات التطبيقات، ربط Infisical بـ AWS/GCP/Azure/GitHub، "الاتصال غير موجود" عند إنشاء مزامنة، أي طريقة مصادقة يحتاجها الاتصال، إعادة استخدام الاتصال عبر المزامنات، أو "كيف أصادق Infisical على خدمة طرف ثالث". هذا هو مصادقة Infisical باتجاه الخارج إلى طرف ثالث. ليس لهويات الآلات، التي هي أحمال عمل تُصادق إلى داخل Infisical (infisical‑setup).
