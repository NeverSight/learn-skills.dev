Infisical アプリ接続の作成と管理のガイド — Infisical とサードパーティサービス間の再利用可能な認証リンクで、シークレット同期、シークレットローテーション、PKI 証明書認証局、PKI 同期、シークレットスキャン データソースがすべて依存しています。全 83 種類の接続タイプとそれぞれの正確な認証方法（AWS の assume‑role と access‑key、GitHub OAuth と GitHub App と PAT、Azure OAuth と client‑secret と証明書、GCP のサービスアカウントインパーソネーションなど）を網羅し、プラットフォーム管理クレデンシャル、プライベートネットワーク向け Gateway ルーティング接続、接続レベルのクレデンシャルローテーションについても解説しています。次のような質問があったときにこのスキルを使用してください：アプリ接続、Infisical を AWS／GCP／Azure／GitHub に接続する方法、同期作成時の「接続が見つかりません」エラー、接続に必要な認証方法、同期間で接続を再利用する方法、あるいは「Infisical をサードパーティサービスに認証させるにはどうすればよいか」。これは Infisical が外部へ向けて認証するケースです。機械アイデンティティ（ワークロードが Infisical に認証する）については対象外です（infisical‑setup）。
