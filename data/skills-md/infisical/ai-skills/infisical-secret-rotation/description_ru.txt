Руководство по настройке вращения секретов Infisical — автоматическое обновление учётных данных, уже существующих в сторонней системе, через фиксированные интервалы времени с записью новых значений обратно в секреты Infisical. Охватывает все 28 провайдеров вращения (PostgreSQL, MySQL, MSSQL, OracleDB, MongoDB, Redis, секреты пользователей AWS IAM, клиентские секреты Azure/Okta/Auth0, пароли LDAP, локальные учётные записи Unix/Linux и Windows, Cloudflare, Datadog, пары ключей Snowflake, API‑ключи OpenAI/OpenRouter/LiteLLM/Fireworks и многое другое), модели вращения «двухфазное» и «одноступенчатое», интервалы вращения и планирование rotateAtUtc, параметры и secretsMapping, а также схему с двумя пользователями для баз данных SQL. Используйте это умение, когда кто‑то спрашивает о вращении секретов, вращении учётных данных, автоматическом вращении учётных данных, плановом обновлении пароля базы данных, истечении срока действия API‑ключей, rotationInterval или «как автоматически вращать пароль базы данных». Предназначено для изменения СУЩЕСТВУЮЩИХ учётных данных по таймеру. Не предназначено для создания новых эфемерных учётных данных по запросу (infisical-dynamic-secrets) и не для вращения учётных данных App Connection (infisical-app-connections).
