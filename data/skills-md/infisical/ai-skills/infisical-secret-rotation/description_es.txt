Guía para configurar la Rotación de Secretos de Infisical — rotación automática de credenciales que ya existen en un sistema externo en un intervalo fijo, escribiendo los nuevos valores de vuelta en los secretos de Infisical. Cubre los 28 proveedores de rotación (PostgreSQL, MySQL, MSSQL, OracleDB, MongoDB, Redis, secretos de usuarios AWS IAM, secretos de cliente Azure/Okta/Auth0, contraseñas LDAP, cuentas locales Unix/Linux y Windows, Cloudflare, Datadog, pares de claves de Snowflake, claves API de OpenAI/OpenRouter/LiteLLM/Fireworks y más), los modelos de fase dual vs fase única, los intervalos de rotación y la programación rotateAtUtc, los parámetros y secretsMapping, y el patrón de dos usuarios para bases de datos SQL. Usa esta habilidad cuando alguien pregunte sobre: rotación de secretos, rotación de credenciales, rotación automática de credenciales, rotar la contraseña de una base de datos según un horario, expiración de claves API, rotationInterval o “¿cómo rotar mi contraseña de base de datos automáticamente?”. Para cambiar una credencial EXISTENTE en un temporizador. No es para crear credenciales efímeras nuevas por solicitud (infisical-dynamic-secrets), ni para la rotación de credenciales de Conexión de Aplicación (infisical-app-connections).
