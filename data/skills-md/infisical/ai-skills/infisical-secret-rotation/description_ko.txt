Infisical 비밀 회전 구성 가이드 — 기존에 제3자 시스템에 존재하는 자격 증명을 고정된 간격으로 자동 회전시키고, 새로운 값을 Infisical 비밀에 다시 기록합니다. PostgreSQL, MySQL, MSSQL, OracleDB, MongoDB, Redis, AWS IAM 사용자 비밀, Azure/Okta/Auth0 클라이언트 비밀, LDAP 비밀번호, Unix/Linux 및 Windows 로컬 계정, Cloudflare, Datadog, Snowflake 키 쌍, OpenAI/OpenRouter/LiteLLM/Fireworks API 키 등 총 28개의 회전 제공자를 모두 다루며, 듀얼‑페이즈 vs 싱글‑페이즈 회전 모델, 회전 간격 및 rotateAtUtc 스케줄링, 파라미터와 secretsMapping, 그리고 SQL 데이터베이스용 두 사용자 패턴을 설명합니다. 다음과 같은 질문이 있을 때 이 스킬을 사용하세요: 비밀 회전, 자격 증명 회전, 자동 자격 증명 회전, 일정에 따라 데이터베이스 비밀번호 회전, API 키 만료, rotationInterval, 혹은 “데이터베이스 비밀번호를 자동으로 회전시키는 방법”. 타이머에 따라 기존 자격 증명을 변경하는 경우에 사용합니다. 요청 시 새 일회성 자격 증명을 생성하는 경우(infisical-dynamic-secrets)나 앱 연결 자격 증명 회전(infisical-app-connections)에는 사용하지 마세요.
