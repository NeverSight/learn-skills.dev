Guide du portail et du relais Infisical — accéder aux ressources réseau privées (bases de données uniquement en VPC, annuaires sur site, API internes, HSM) depuis Infisical sans aucune règle de pare-feu entrante. Couvre l'architecture passerelle/relais utilisant des tunnels inversés SSH, les ports exacts et les exigences de liste blanche sortante (TCP 2222 vers le relais, TCP 443 vers Infisical, TCP 8443 plateforme‑vers‑relais), le déploiement avec `infisical gateway start` et `infisical gateway systemd`, les relais gérés par Infisical vs auto‑déployés, les pools de passerelles pour haute disponibilité, les contrôles de santé et les intervalles de battement de cœur, et quelles fonctionnalités et types de connexion d’application peuvent être routés via une passerelle. Utilisez cette compétence lorsqu’on vous interroge sur : Infisical Gateway, serveur de relais, accès à une base de données privée depuis Infisical, secrets dynamiques pour une base de données sans point de terminaison public, pools de passerelles, ou « Infisical ne peut pas atteindre ma ressource interne ». Une passerelle n’est pas un substitut à l’auto‑hébergement (infisical-self-host) et n’est pas une connexion d’application (infisical-app-connections) — les ressources privées nécessitent à la fois une passerelle et une connexion.
