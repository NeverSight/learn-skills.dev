Руководство по Infisical Gateway и Relay — доступ к ресурсам частной сети (только VPC‑базы данных, локальные каталоги, внутренние API, HSM) из Infisical без каких‑либо входящих правил firewall. Описывает архитектуру шлюза/ретранслятора с использованием обратных SSH‑туннелей, точные порты и требования к списку разрешённого исходящего трафика (TCP 2222 к ретранслятору, TCP 443 к Infisical, TCP 8443 от платформы к ретранслятору), развертывание с помощью `infisical gateway start` и `infisical gateway systemd`, управляемые Infisical и самостоятельно развернутые ретрансляторы, пуллы шлюзов для высокой доступности, проверки состояния и интервалы сердцебиения, а также какие функции и типы App Connection могут маршрутизироваться через шлюз. Используйте этот навык, когда кто‑то спрашивает о: Infisical Gateway, сервере‑ретрансляторе, доступе к частной базе данных из Infisical, динамических секретах для базы без публичного эндпоинта, пулах шлюзов или «Infisical не может достать мой внутренний ресурс». Шлюз не заменяет самостоятельный хостинг (infisical-self-host) и не является App Connection (infisical-app-connections) — для частных ресурсов нужны и шлюз, и соединение.
