Infisical Gateway 與 Relay 使用指南 — 從 Infisical 在未設定任何入站防火牆規則的情況下，存取私有網路資源（僅限 VPC 的資料庫、內部目錄、內部 API、HSM）。說明透過 SSH 反向通道的 gateway/relay 架構、精確的埠號與外部允許清單需求（至 Relay 的 TCP 2222、至 Infisical 的 TCP 443、平台至 Relay 的 TCP 8443），以及使用 `infisical gateway start` 與 `infisical gateway systemd` 部署的步驟、Infisical 管理的 Relay 與自行部署的 Relay 之差異、Gateway Pool 以提供高可用性、健康檢查與心跳間隔，並列出哪些功能與 App Connection 類型可透過 gateway 轉送。當有人詢問以下主題時請使用此說明：Infisical Gateway、Relay 伺服器、從 Infisical 存取私有資料庫、沒有公開端點的資料庫動態祕密、Gateway Pool，或是「Infisical 無法連到我的內部資源」。Gateway 不是自行託管（infisical‑self‑host）的替代方案，也不是 App Connection（infisical‑app‑connections）的一部份──私有資源必須同時具備 gateway 與連線。
