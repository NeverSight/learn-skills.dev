Guía para el Infisical Gateway y Relay — acceso a recursos de red privados (bases de datos solo VPC, directorios locales, APIs internas, HSM) desde Infisical sin reglas de firewall de entrada. Cubre la arquitectura de gateway/relay usando túneles SSH inversos, puertos exactos y requisitos de lista blanca de egreso (TCP 2222 al relay, TCP 443 a Infisical, TCP 8443 de la plataforma al relay), despliegue con `infisical gateway start` e `infisical gateway systemd`, relays gestionados por Infisical vs autodesplegados, Pools de Gateway para alta disponibilidad, comprobaciones de salud y intervalos de latido, y qué funciones y tipos de Conexión de Aplicación pueden enrutar a través de un gateway. Usa esta habilidad cuando alguien pregunte sobre: Infisical Gateway, servidor de relay, acceso a una base de datos privada desde Infisical, secretos dinámicos para una base de datos sin endpoint público, pools de gateway, o “Infisical no puede alcanzar mi recurso interno”. Un Gateway no sustituye la auto‑hosted (infisical-self-host) y no es una Conexión de Aplicación (infisical-app-connections) — los recursos privados necesitan tanto un gateway como una conexión.
