Guida per Infisical Gateway e Relay — raggiungere risorse di rete private (database solo VPC, directory on‑premise, API interne, HSM) da Infisical senza regole firewall in ingresso. Copre l'architettura gateway/relay che utilizza tunnel SSH inversi, le porte esatte e i requisiti di whitelist di egress (TCP 2222 verso il relay, TCP 443 verso Infisical, TCP 8443 piattaforma‑to‑relay), il deployment con `infisical gateway start` e `infisical gateway systemd`, relay gestiti da Infisical vs relay auto‑distribuiti, Pool di Gateway per alta disponibilità, controlli di stato e intervalli di heartbeat, e quali funzionalità e tipologie di Connessione App possono essere instradate attraverso un gateway. Usa questa competenza quando qualcuno chiede di: Infisical Gateway, server relay, accesso a un database privato da Infisical, segreti dinamici per un database senza endpoint pubblico, pool di gateway, o «Infisical non riesce a raggiungere la mia risorsa interna». Un Gateway non è un sostituto dell'auto‑hosting (infisical-self-host) e non è una Connessione App (infisical-app-connections) — le risorse private necessitano sia di un gateway sia di una connessione.
