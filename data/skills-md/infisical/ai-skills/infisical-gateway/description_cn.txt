Infisical 网关和中继指南 — 从 Infisical 在不使用任何入站防火墙规则的情况下访问私有网络资源（仅限 VPC 的数据库、本地目录、内部 API、HSM）。涵盖使用 SSH 反向隧道的网关/中继架构、精确的端口和出站白名单要求（到中继的 TCP 2222、到 Infisical 的 TCP 443、平台到中继的 TCP 8443），以及使用 `infisical gateway start` 和 `infisical gateway systemd` 部署、Infisical 管理的中继与自行部署的中继、实现高可用性的网关池、健康检查与心跳间隔，并说明哪些功能和应用连接类型可以通过网关进行路由。使用此技能的场景包括：询问 Infisical 网关、中继服务器、从 Infisical 访问私有数据库、为没有公共端点的数据库获取动态密钥、网关池，或出现 “Infisical 无法访问我的内部资源”。网关并非自托管（infisical-self-host）的替代方案，也不是应用连接（infisical-app-connections）——私有资源需要同时拥有网关和连接。
