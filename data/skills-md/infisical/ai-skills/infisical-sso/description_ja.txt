Infisical を ID プロバイダーに接続してヒューマンログインとユーザーのプロビジョニングを行うためのガイドです。Google と GitHub の SSO（無料）、Okta、Azure/Entra ID、JumpCloud、Google、Auth0、Keycloak、PingOne、GitLab、LDAP ログインを含む SAML 2.0 と OIDC（有料）をカバーし、Okta/Azure/JumpCloud/PingOne/PingFederate による SCIM ユーザーおよびグループのプロビジョニング、SAML と OIDC のグループメンバーシップマッピング、SCIM グループと組織ロールのマッピング、必須のメールドメイン検証前提条件、SSO 強制とパスワードサインアップへの影響、/login/admin のブレークグラスポータルについて説明します。このスキルは、以下の質問があったときに使用します：Infisical の SSO、SAML ログイン、OIDC ログイン、Okta または Azure AD との統合、SCIM プロビジョニング、ID プロバイダーのグループを Infisical に同期すること、SSO の強制、または SSO を有効化した後にロックアウトされること。ヒューマンログインとユーザーのプロビジョニング向けです。機械用 ID 認証方法（OIDC や LDAP を使用したワークロード（infisical-setup））やロール・権限管理（infisical-access-control）には使用しないでください。
