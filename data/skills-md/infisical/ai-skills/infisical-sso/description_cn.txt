连接 Infisical 至身份提供商以实现人工登录和用户供应的指南。  
涵盖 Google 和 GitHub SSO（免费）、使用 Okta、Azure/Entra ID、JumpCloud、Google、Auth0、Keycloak、PingOne、GitLab 的 SAML 2.0 与 OIDC（付费）、LDAP 登录、使用 Okta/Azure/JumpCloud/PingOne/PingFederate 的 SCIM 用户和组供应、SAML 与 OIDC 的组成员映射、SCIM 组到组织角色的映射、强制的电子邮件域名验证前提条件、SSO 强制以及其对密码注册的影响，以及 /login/admin 紧急登录门户。  
当有人咨询以下内容时请使用此技能：Infisical SSO、SAML 登录、OIDC 登录、Okta 或 Azure AD 集成、SCIM 供应、将身份提供商的组同步到 Infisical、强制 SSO，或在启用 SSO 后被锁定。  
适用于人工登录和用户供应。  
不适用于机器身份验证方法，包括用于工作负载的 OIDC 和 LDAP（infisical-setup），也不适用于角色和权限（infisical-access-control）。
