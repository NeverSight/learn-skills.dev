تنسيق نقل مُتحكم فيه لصفحة HTML معتمدة أو تطبيق ويب محلي أو واجهة مستخدم منفذة أو عائلة حالات واجهة مستخدم حتمية إلى ملف Figma مُصرَّح به مع التقاط حالات قابل لإعادة الإنتاج، وإنشاء الصفحات أولاً ثم التوجيه، ووضع نهائي في قسم أو إطار، وبنية قابلة للتحرير، واستعادة من توقف الطابور، وخصوصية، وضمان الجودة. استخدم هذا عندما يطلب المستخدم تحويل HTML إلى Figma، أو الكود إلى Figma، أو صفحة ويب إلى Figma، أو 网页转 Figma، أو 代码回写 Figma، أو يرغب في إعادة بناء Figma قابلة للتحرير، أو يحتاج إلى نقل حالات الافتراضي، المختارة، الجارية التحميل، الفارغة، الخطأ، أو تقليل الحركة، أو يحتاج إلى وضع الطبقات المستوردة في قسم أو إطار، أو يبلغ عن مهمة تحويل عالقة في طابور الخادم. يتطلّب وجود تكامل Figma الرسمي المثبت للقراءات أو الكتابات الفعلية؛ هذه المهارة توفِّر سير عمل آمن للمشروع ولا تعيد توزيع مواد Figma. / بموجب الحصول على التفويض، يتم نقل HTML أو صفحة الويب المحلية أو الواجهة المنفذة أو عائلة الحالات الحتمية بشكل قابل للتحكم إلى Figma، مع تثبيت كل حالة على مستوى الصفحة أولاً، ثم وضعها في قسم أو إطار، مع الحفاظ على بنية قابلة للتحرير، واستعادة من توقف الطابور، وفرض حدود الخصوصية وسجلات ضمان الجودة.
