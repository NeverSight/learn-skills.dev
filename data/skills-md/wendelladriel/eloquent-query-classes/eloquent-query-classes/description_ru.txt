Шаблон классов запросов Laravel Eloquent для извлечения важных операций с базой данных в целевые классы. Используйте при рефакторинге повторяющихся запросов Eloquent, разработке объектов запросов, просмотре абстракций, подобных репозиторию, выборе между областями и классами запросов или тестировании сложных запросов Laravel.
