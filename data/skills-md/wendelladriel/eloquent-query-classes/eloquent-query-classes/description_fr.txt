Modèle Laravel Eloquent Query Classes pour extraire des opérations de base de données importantes dans des classes ciblées. À utiliser lors de la refactorisation de requêtes Eloquent répétées, de la conception d'objets de requête, de l'examen d'abstractions de type référentiel, du choix entre les portées et les classes de requêtes ou le test de requêtes Laravel complexes.
