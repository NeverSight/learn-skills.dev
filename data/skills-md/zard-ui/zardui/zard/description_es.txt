Administra los componentes y proyectos de zard/ui — añadiendo, componiendo, estilizando y depurando la UI de Angular construida sobre TailwindCSS v4. Proporciona el contexto del proyecto, la fuente del componente y la API real en lugar de una recordada. Se aplica cuando se trabaja con zard/ui, zard-cli, el registro zard o cualquier proyecto con un components.json que declare un projectType zard. También se activa para “zard-cli init”, “añadir un componente zard” o “configurar zard/ui en un espacio de trabajo Nx”.
