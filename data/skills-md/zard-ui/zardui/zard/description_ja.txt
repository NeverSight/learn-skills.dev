zard/ui コンポーネントとプロジェクトを管理します — 追加、構成、スタイリング、TailwindCSS v4 上に構築された Angular UI のデバッグを行います。プロジェクトのコンテキスト、コンポーネントのソース、そして記憶されたものではなく実際の API を提供します。zard/ui、zard-cli、zard レジストリ、または components.json に zard projectType が宣言されている任意のプロジェクトで適用されます。また、「zard-cli init」や「zard コンポーネントを追加」あるいは「Nx ワークスペースに zard/ui をセットアップ」の際にもトリガーされます。
