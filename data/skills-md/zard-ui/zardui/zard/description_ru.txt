Управляет компонентами и проектами zard/ui — добавлением, комбинированием, стилизацией и отладкой Angular UI, построенного на TailwindCSS v4. Предоставляет контекст проекта, исходный код компонента и реальный API вместо запомненного. Применяется при работе с zard/ui, zard‑cli, реестром zard или любым проектом, содержащим components.json, объявляющим тип проекта zard. Также срабатывает для «zard‑cli init», «добавить компонент zard» или «настроить zard/ui в рабочем пространстве Nx».
