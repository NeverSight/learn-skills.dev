Gère les composants et projets zard/ui — ajout, composition, stylisation et débogage d’une UI Angular construite sur TailwindCSS v4. Fournit le contexte du projet, la source du composant et l’API réelle au lieu d’une API mémorisée. S’applique lorsque vous travaillez avec zard/ui, zard‑cli, le registre zard ou tout projet disposant d’un fichier components.json déclarant un projectType zard. Se déclenche également pour « zard‑cli init », « ajouter un composant zard » ou « configurer zard/ui dans un espace de travail Nx ».
