Verwaltet zard/ui-Komponenten und -Projekte — Hinzufügen, Komponieren, Styling und Debuggen von Angular UI basierend auf TailwindCSS v4. Bietet Projektkontext, Komponentenquelle und die echte API anstelle einer erinnerten API. Gilt für die Arbeit mit zard/ui, zard-cli, der zard-Registrierung oder jedem Projekt mit einem components.json, das einen zard projectType deklariert. Auch Trigger für "zard-cli init", "zard-Komponente hinzufügen" oder "zard/ui in einem Nx-Arbeitsbereich einrichten".
