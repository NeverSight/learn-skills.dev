既存のアート（分割されたパーツの PNG、テクスチャアトラス、または単一のフルキャラクター画像）から 2D キャラクターを Spine のスケルトンアニメーションとしてリグし、アニメーションさせ、Spine 4.2 の .json、.atlas、.png と自己完結型 HTML5 プレビューをエクスポートします。Codex が Spine スケルトンを構築する必要があるとき、パーツをボーン階層に自動配置する際、idle／walk／run／wave／jump／attack などのキー フレームアニメーションやカスタムアニメーションを作成する際、Spine アトラスをパックする際、フルキャラクターをパーツに分解する際、Spine Web Player のプレビューをレンダリングする際、または既存のスケルトンのオフセットや描画順序を修正する際に使用してください。トリガー例: Spine アニメーション、2D リギング、スケルトン／ボーン／カットアウトアニメーション、「このキャラクターをアニメートして」「ウォークサイクルを作って」や、アニメーション対象のキャラクターパーツのアップロード。
