Vérifiez la clarté, la précision, la cohérence et l'ambiguïté des noms de fichiers et des identifiants de code source. À utiliser lorsque l'utilisateur demande d'inspecter ou d'améliorer les noms de fichiers, de modules, de types, de fonctions, de méthodes, de paramètres, d'étiquettes d'argument, de propriétés, de variables, de constantes, de cas d'énumération ou de ressources de code associées. Ne pas utiliser pour une révision générale du code qui n'a pas d'accent sur la dénomination.
