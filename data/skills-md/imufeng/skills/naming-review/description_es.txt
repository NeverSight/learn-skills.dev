Revise los nombres de archivo y los identificadores de código fuente para mayor claridad, precisión, coherencia y ambigüedad. Se utiliza cuando el usuario solicita inspeccionar o mejorar nombres de archivos, módulos, tipos, funciones, métodos, parámetros, etiquetas de argumentos, propiedades, variables, constantes, casos de enumeración o recursos de código relacionados. No lo utilice para una revisión de código general que no tenga un enfoque de nomenclatura.
