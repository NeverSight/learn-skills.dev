إنشاء ومراجعة تطبيقات سطح المكتب متعددة المنصات بلغة Python باستخدام tkinter، ttk، CustomTkinter، PySide6 أو PyQt6. استخدامها للنوافذ، عناصر الواجهة، التخطيطات، الحوارات، شريط النظام، المهام الخلفية، حلقات الأحداث، فصل النموذج‑العرض، إمكانية الوصول، سلوك DPI العالي، الإعدادات، التعبئة باستخدام PyInstaller أو Nuitka، وإصلاح تحديثات واجهة المستخدم غير الآمنة من خيوط العامل.
