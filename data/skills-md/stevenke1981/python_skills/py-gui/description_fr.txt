Construisez et examinez des applications de bureau Python multiplateformes avec tkinter, ttk, CustomTkinter, PySide6 ou PyQt6. Utilisez-les pour les fenêtres, les widgets, les mises en page, les dialogues, la barre d’état système, les tâches en arrière‑plan, les boucles d’événements, la séparation modèle‑vue, l’accessibilité, le comportement haute résolution DPI, les paramètres, l’empaquetage avec PyInstaller ou Nuitka, et la correction des mises à jour d’interface utilisateur non sûres depuis les threads de travail.
