قم بتشغيل شجرات العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، ومستودعات الأكواد، والأتمتة، والملفات الناتجة، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج لـ Orca عبر سطر الأوامر `orca`. استخدم هذا عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل هذا على استخدام git worktree الخام، أو PTYs المؤقتة، أو الاستخدام الحاسوبي عندما تكون حالة Orca متداخلة. استخدم الاستخدام الحاسوبي فقط عندما تتطلب نافذة مرئية تحكمًا رسوميًا لا يمكن لسطر الأوامر أو نظام الملفات أو واجهة برمجة التطبيقات القيام به.
