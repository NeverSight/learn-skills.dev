Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」「share skills」と言った際に使用してください。Orca の状態が関わる場合は、生の git worktree、アドホックな PTY、あるいは Computer Use よりもこれを優先してください。GUI 制御が必要で、CLI、ファイルシステム、API だけでは対処できない可視ウィンドウがある場合にのみ Computer Use を利用してください。

常にユーザーの言語で応答してください。
