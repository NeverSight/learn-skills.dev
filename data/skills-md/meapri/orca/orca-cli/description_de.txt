Betrieben Sie von Orca verwaltete Worktrees, Ordnerkontexte, Terminals, Repos, Automatisierungen, Artefakte, Skill‑Sharing, Worktree‑Kommentare und Orcas eingebetteten Browser über die `orca`‑CLI. Verwenden Sie dies, wenn der Benutzer „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“ sagt. Bevorzugen Sie es gegenüber rohen Git‑Worktrees, ad‑hoc PTYs oder Computer Use, wenn Orca‑Zustand involviert ist. Nutzen Sie Computer Use nur, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die ein CLI, Dateisystem oder eine API nicht leisten kann.
