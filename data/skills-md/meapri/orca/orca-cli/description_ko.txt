Orca가 관리하는 워크트리, 폴더 컨텍스트, 터미널, 레포, 자동화, 아티팩트, 스킬 공유, 워크트리 코멘트 및 Orca의 내장 브라우저를 `orca` CLI를 통해 운영합니다. 사용자가 “$orca‑cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” 또는 “share skills” 라고 말할 때 이 명령을 사용합니다. Orca 상태가 관련된 경우에는 일반 git 워크트리, 임시 PTY, 혹은 컴퓨터 사용보다 이를 우선합니다. 화면에 보이는 창을 GUI로 제어해야 하고 CLI, 파일 시스템, API로는 할 수 없을 때만 컴퓨터 사용을 이용합니다.
