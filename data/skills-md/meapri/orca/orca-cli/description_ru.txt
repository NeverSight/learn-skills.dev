Оперировать рабочими деревьями, управляемыми Orca, контекстами папок, терминалами, репозиториями, автоматизациями, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Использовать, когда пользователь говорит "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" или "share skills". Предпочитать это перед обычным git worktree, ad hoc PTY или Computer Use, когда задействовано состояние Orca. Использовать Computer Use только тогда, когда нужно управлять видимым окном GUI, которое нельзя контролировать через CLI, файловую систему или API.
