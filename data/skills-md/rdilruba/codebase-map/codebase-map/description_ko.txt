소프트웨어 저장소의 지속적이고 증거 기반 지도를 docs/codebase-map/ 내부에 구축합니다 – TL;DR, Mermaid 로 그린 아키텍처 및 의존성 다이어그램, 원형별 전략으로 추적된 실제 데이터 흐름, 가장 중요한 파일들(“스파인”), 읽기 순서, 필요시 AI 보조 코드, 핵심 개념 및 열린 질문들을 포함합니다. 다섯 가지 모드 - **"codebase-map init"** 은 전체 지도를 만들고, **"codebase-map update"** 는 변경 후에 갱신하며, **"codebase-map explain [topic]"** 은 하나의 기능이나 도메인을 설명하고, **"codebase-map trace [flow]"** 는 하나의 요청 경로를 추적하며, **"codebase-map check"** 은 작성 없이 드리프트를 보고합니다. 사용자는 익숙하지 않거나 AI가 생성한 코드베이스를 이해·문서화·온보딩하고 싶을 때 언제든지 사용합니다 - “map this repo”, “explain the architecture”, “how does this app work”, “trace this feature”, “which files matter”, “update the codebase map”.
