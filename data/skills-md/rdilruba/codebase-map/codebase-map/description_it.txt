Costruisci una mappa persistente e basata su evidenze di un repository software all'interno di docs/codebase-map/ ‑ TL;DR, diagrammi di architettura e dipendenze in Mermaid, flussi di dati reali tracciati con una strategia specifica per l’archetipo, i file più importanti (“la spina dorsale”), un ordine di lettura, potenzialmente codice assistito da IA, concetti chiave e domande aperte. Cinque modalità ‑ “codebase-map init” crea la mappa completa, “codebase‑map update” la aggiorna dopo le modifiche, “codebase‑map explain [topic]” copre una funzionalità o un dominio, “codebase‑map trace [flow]” segue un percorso di richiesta, “codebase‑map check” segnala drift senza scrivere. Usala ogni volta che l’utente vuole comprendere, documentare o inserirsi in un repository sconosciuto o generato da IA ‑ “map this repo”, “explain the architecture”, “how does this app work”, “trace this feature”, “which files matter”, “update the codebase map”.
