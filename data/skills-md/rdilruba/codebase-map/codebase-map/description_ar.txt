أنشئ خريطة مستمرة ومستندة إلى الأدلة لمستودع برمجي داخل docs/codebase‑map/ – خلاصة القول، مخططات الهندسة المعمارية والاعتمادية بـ Mermaid، تدفقات البيانات الحقيقية مُتتبعة باستراتيجية خاصّة بالنموذج، أهم الملفات ("العمود الفقري")، ترتيب القراءة، كود محتمل مدعوم بالذكاء الاصطناعي، المفاهيم الرئيسة، والأسئلة المفتوحة. هناك خمسة أوضاع – "codebase‑map init" يبني الخريطة بالكامل، "codebase‑map update" يُحدّثها بعد التغييرات، "codebase‑map explain [topic]" يغطي ميزة أو مجالًا واحدًا، "codebase‑map trace [flow]" يتتبّع مسار طلبٍ واحد، "codebase‑map check" يُبلغ عن الانحراف دون كتابة. استخدمه كلما رغب المستخدم في فهم أو توثيق أو الانضمام إلى مستودع غير مألوف أو مُولَّد بالذكاء الاصطناعي – "map this repo"، "explain the architecture"، "how does this app work"، "trace this feature"، "which files matter"، "update the codebase map".
