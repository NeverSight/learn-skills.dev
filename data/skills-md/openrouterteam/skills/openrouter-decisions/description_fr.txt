Implémentez des modèles de décision via l’API Decisions d’OpenRouter, qui renvoie des probabilités au lieu de texte généré : choisissez le primitive par jugement, construisez un état minimal, rédigez les questions, épinglez un modèle du catalogue en direct, placez un gate dans le code et testez les seuils sur des entrées réelles. Utilisez-le lorsque vous remplacez un appel LLM « prompt‑and‑parse », une heuristique de mot‑clé ou de similarité, une file d’attente de revue humaine, ou un routeur, filtre ou classificateur défectueux par un modèle de décision, lorsque vous localisez quelque chose dans une image avec une question Box, lorsque vous migrez le SDK TypeSafe ou le code System One vers OpenRouter, lorsqu’on vous demande de trouver ou d’implémenter des cas d’usage de modèles de décision dans une application ou un agent, et chaque fois que les modèles de décision, Jev, TypeSafe ou System One sont évoqués. Couvre le routage, la classification, la modération, les garde‑fous, les vérifications d’ancrage, le scoring, le classement, la déduplication, les escalades et les portes d’approbation, l’extraction bornée et les seuils. Ce n’est pas destiné aux complétions de chat, à la génération de texte ou à la configuration générale d’OpenRouter.
