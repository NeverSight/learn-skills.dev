透過 OpenRouter 的 Decisions API 實作決策模型，該 API 會回傳機率而非產生文字：依判斷挑選原始操作、建構最小化狀態、撰寫問題、從即時目錄釘選模型、在程式碼中設置閘門，並在真實輸入上探測門檻。於以下情況使用：以決策模型取代提示與解析的 LLM 呼叫、關鍵字或相似度啟發式、人工審核佇列，或是錯誤觸發的路由器、過濾器或分類器；在影像中以 Box 問題定位目標；將 TypeSafe SDK 或 System One 程式碼移植至 OpenRouter；被要求在應用或代理中尋找或實作決策模型的使用案例；以及每當決策模型、Jev、TypeSafe 或 System One 出現時。涵蓋路由、分類、內容審查、保護機制、基礎檢核、評分、排名、去重、升級與批准閘門、受限抽取與門檻設定。不適用於聊天完成、文字生成或一般 OpenRouter 設定。
