OpenRouter의 Decisions API를 통해 의사결정 모델을 구현합니다. 이 API는 생성된 텍스트 대신 확률을 반환합니다: 판단마다 원시값을 선택하고, 최소한의 상태를 구축하며, 질문을 작성하고, 라이브 카탈로그에서 모델을 고정하고, 코드에 게이트를 두며, 실제 입력에 대해 임계값을 탐색합니다. 프롬프트‑파싱 LLM 호출, 키워드 또는 유사도 휴리스틱, 인간 검토 큐, 혹은 오작동하는 라우터, 필터, 분류기를 의사결정 모델로 대체할 때, 이미지에서 Box 질문으로 대상을 찾을 때, TypeSafe SDK나 System One 코드를 OpenRouter로 이동할 때, 앱이나 에이전트에서 의사결정 모델 사용 사례를 찾거나 구현하라는 요청이 있을 때, 그리고 의사결정 모델, Jev, TypeSafe, System One이 언급될 때 사용하십시오. 라우팅, 분류, 모더레이션, 가드레일, 근거 검증, 점수화, 순위 매기기, 중복 제거, 에스컬레이션 및 승인 게이트, 제한된 추출 및 임계값 등을 포함합니다. 채팅 완성, 텍스트 생성, 일반 OpenRouter 설정에는 사용하지 않습니다.
