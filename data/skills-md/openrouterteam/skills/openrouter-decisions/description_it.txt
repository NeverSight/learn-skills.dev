Implementa modelli decisionali tramite le Decisions API di OpenRouter, che restituiscono probabilità invece di testo generato: scegli la primitiva per giudizio, costruisci uno stato minimo, scrivi le domande, fissa un modello dal catalogo live, inserisci il controllo nel codice e verifica le soglie su input reali. Usalo quando sostituisci una chiamata LLM con prompt e parsing, un'euristica basata su parole chiave o similarità, una coda di revisione umana o un router, filtro o classificatore che funziona in modo errato con un modello decisionale, quando individui qualcosa in un'immagine con una domanda Box, quando sposti il codice TypeSafe SDK o System One su OpenRouter, quando ti chiedono di trovare o implementare casi d'uso di modelli decisionali in un'app o agente, e ogni volta che compaiano modelli decisionali, Jev, TypeSafe o System One. Copre routing, classificazione, moderazione, guardrails, controlli di grounding, punteggio, ranking, deduplicazione, escalation e porte di approvazione, estrazione limitata e soglie. Non è destinato a completamenti di chat, generazione di testo o alla configurazione generale di OpenRouter.
