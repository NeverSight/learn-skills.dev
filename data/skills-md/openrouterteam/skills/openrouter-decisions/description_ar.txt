نفّذ نماذج اتخاذ القرار عبر واجهة Decisions API الخاصة بـ OpenRouter، والتي تُرجع احتمالات بدلاً من النص المُولد: اختر البدائية لكل حكم، أنشئ حالة دنيا، صغ الأسئلة، ثبت نموذجًا من الفهرس الحي، أدخل البوابة في الكود، واختبر العتبات على المدخلات الحقيقية. استخدم ذلك عندما تستبدل استدعاء LLM مع الإجراء وال解析، أو كلمة مفتاحية أو حدس تشابه، أو طابور مراجعة بشرية، أو موجه غير فعال، أو مصفاة، أو مصنف بنموذج قرار؛ عندما تحدد شيئًا في صورة باستخدام سؤال Box؛ عند نقل كود TypeSafe SDK أو System One إلى OpenRouter؛ عندما يُطلب منك العثور على أو تنفيذ حالات استخدام نموذج القرار في تطبيق أو وكيل؛ وفي أي وقت يذكر فيه نماذج القرار أو Jev أو TypeSafe أو System One. يغطي التوجيه، التصنيف، الإشراف، الحواجز الوقائية، فحوصات الترسيخ، التقييم، الترتيب، إزالة التكرار، تصعيد وإجراءات الموافقة، الاستخراج المحدود، والعتبات. ليس للاستخدام في إكمالات الدردشة، توليد النص، أو إعداد OpenRouter العام.
