OpenRouter の Decisions API を使用して意思決定モデルを実装します。この API は生成されたテキストではなく確率を返します。判断ごとにプリミティブを選択し、最小限の状態を構築し、質問を書き、ライブカタログからモデルを固定し、コード内でゲートし、実際の入力で閾値を探ります。プロンプトとパースを行う LLM 呼び出し、キーワードや類似度ヒューリスティック、人間レビューキュー、誤作動するルーター・フィルタ・分類器を意思決定モデルで置き換える場合、画像内の対象を Box 質問で特定する場合、TypeSafe SDK や System One のコードを OpenRouter に移行する場合、アプリやエージェントで意思決定モデルのユースケースを探す・実装するよう求められたとき、そして意思決定モデル、Jev、TypeSafe、System One が出てくるすべての場面で使用します。対象はルーティング、分類、モデレーション、ガードレール、グラウンディングチェック、スコアリング、ランキング、重複除去、エスカレーションおよび承認ゲート、制限抽出、閾値設定です。チャット完了、テキスト生成、一般的な OpenRouter 設定には使用しません。
