通过 OpenRouter 的 Decisions API 实现决策模型，该 API 返回概率而非生成的文本：为每次判断挑选原语，构建最小状态，编写问题，从实时目录中固定模型，在代码中设定门限，并在真实输入上探测阈值。适用于用决策模型替代提示‑解析 LLM 调用、关键词或相似度启发式、人类审查队列，或误触的路由器、过滤器、分类器；用于在图像中使用 Box 问题定位目标；用于将 TypeSafe SDK 或 System One 代码迁移至 OpenRouter；在需要在应用或代理中寻找或实现决策模型用例时，以及每当提及决策模型、Jev、TypeSafe 或 System One 时使用。涵盖路由、分类、审核、护栏、事实核查、评分、排序、去重、升级与审批门、受限抽取以及阈值。不适用于聊天完成、文本生成或一般的 OpenRouter 设置。
