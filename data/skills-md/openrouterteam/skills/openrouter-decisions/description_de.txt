Implementieren Sie Entscheidungsmodelle über die Decisions‑API von OpenRouter, die Wahrscheinlichkeiten anstelle von generiertem Text zurückgibt: Wählen Sie das Primitive pro Urteil, bauen Sie minimalen Zustand auf, formulieren Sie die Fragen, fixieren Sie ein Modell aus dem Live‑Katalog, implementieren Sie eine Gate‑Logik im Code und prüfen Sie Schwellenwerte mit realen Eingaben. Verwenden Sie dies, wenn ein Prompt‑und‑Parse‑LLM‑Aufruf, ein Schlüsselwort‑ oder Ähnlichkeits‑Heuristik, eine menschliche Prüfungswarteschlange oder ein fehlgeleiteter Router, Filter oder Klassifikator durch ein Entscheidungsmodell ersetzt werden soll, wenn etwas in einem Bild mit einer Box‑Frage gefunden werden soll, wenn TypeSafe‑SDK‑ oder System‑One‑Code auf OpenRouter migriert wird, wenn man aufgefordert wird, Anwendungsfälle für Entscheidungsmodelle in einer App oder einem Agenten zu finden oder zu implementieren, und immer, wenn Entscheidungsmodelle, Jev, TypeSafe oder System One erwähnt werden. Deckt Routing, Klassifizierung, Moderation, Schutzmechanismen, Grounding‑Checks, Scoring, Ranking, Duplikaterkennung, Eskalations‑ und Genehmigungs‑Gate, begrenzte Extraktion und Schwellenwerte ab. Nicht für Chat‑Abschlüsse, Textgenerierung oder allgemeine OpenRouter‑Einrichtung.
