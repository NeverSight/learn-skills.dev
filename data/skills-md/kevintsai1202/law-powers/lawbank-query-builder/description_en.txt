Lawbank (lawbank.com.tw) Query Generator — When a question involves administrative interpretations, legal scholarship, legislative amendment history/legislative rationale, cross-references between judicial interpretations and administrative interpretations, or yields empty results in the taiwan-legal-db while the user holds a Lawbank membership, this tool translates the request into a Lawbank Boolean query (using & for AND, + for OR, - for NOT) and a sectional entry point, which the user must log into manually for searching; it also governs the verification and annotation discipline for user‑submitted data. Trigger keywords include “Lawbank”, “lawbank”, “interpretation”, “administrative interpretation”, “legal scholarship”, “legislative amendment history”, “legislative rationale”. This tool never automatically connects to Lawbank, nor does it request or store usernames or passwords.
