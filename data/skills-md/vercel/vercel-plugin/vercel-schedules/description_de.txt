Vercel Schedules Anleitung — führen Sie eine private Funktion, Route oder Vercel‑Queues‑Thema nach einem Cron‑Zeitplan oder einmal zu einem festgelegten Zeitpunkt aus. Behandelt statische Zeitpläne in vercel.json, dynamische pro‑Benutzer‑Zeitpläne mit @vercel/schedules, handleSchedule, das Vercel Schedules‑CLI, Umgebungen, Jitter und die Migration von Cron‑Jobs. Verwenden Sie es, wenn Sie geplante oder wiederkehrende Aufgaben, einmalige Erinnerungen hinzufügen oder `crons` ersetzen.
