Руководство по Vercel Schedules — запуск приватной функции, маршрута или темы Vercel Queues по cron‑расписанию или один раз в заданное время. Охватывает статические расписания в vercel.json, динамические расписания для каждого пользователя с @vercel/schedules, handleSchedule, CLI Vercel Schedules, окружения, джиттер и миграцию из Cron Jobs. Применяется при добавлении запланированной или периодической работы, одноразовых напоминаний или замене `crons`.
