Évaluez le degré de préparation d’un site web, d’un domaine ou d’un point de terminaison public MCP pour les agents IA en utilisant Is Agentic, puis lisez ou agissez sur le rapport résultant. Utilisez-le lorsqu’on vous demande de vérifier la préparation d’un site aux agents, d’obtenir son score Is Agentic, de récupérer un rapport noté au format JSON ou de corriger les problèmes qui diminuent le score du site.
