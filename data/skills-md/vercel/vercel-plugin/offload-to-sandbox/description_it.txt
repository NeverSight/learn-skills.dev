Sposta i build pesanti, le suite di test complete e gli esperimenti paralleli dalla macchina locale a Vercel Sandboxes usando la CLI `vercel sandbox`. Usala quando una macchina locale è sovraccarica o condivisa da più agenti, quando una suite di test deve essere suddivisa, o quando molti task devono essere eseguiti simultaneamente senza consumare CPU, memoria o disco locali.
