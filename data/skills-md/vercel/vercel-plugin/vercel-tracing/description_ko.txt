Vercel Tracing을 위한 OpenTelemetry 계측을 설정하고 생성된 스팬을 조회합니다. `@vercel/otel`을 추가하거나 수정할 때, 프레임워크의 서버 시작 훅(Next.js, SvelteKit 등)을 연결할 때, 사용자 정의 스팬을 추가할 때, AI SDK, Flags SDK 또는 데이터베이스 클라이언트와 같은 라이브러리에서 스팬을 활성화할 때, 서비스 간에 트레이스 컨텍스트를 전파할 때, 항상 켜진 트레이싱 샘플링을 구성할 때, `vercel traces`로 스팬을 검색하거나 검사할 때, 혹은 실패하거나 느린 서버 요청을 디버깅할 때 사용합니다.
