Configura la instrumentación de OpenTelemetry para Vercel Tracing y consulta los spans resultantes. Úsalo al agregar o corregir `@vercel/otel`, conectar el hook de arranque del servidor de un framework (Next.js, SvelteKit y otros), añadir spans personalizados, habilitar spans de librerías como el AI SDK, Flags SDK o clientes de bases de datos, propagar el contexto de rastreo entre servicios, configurar el muestreo de trazas siempre activo, buscar o inspeccionar spans con `vercel traces`, o depurar solicitudes de servidor fallidas o lentas.
