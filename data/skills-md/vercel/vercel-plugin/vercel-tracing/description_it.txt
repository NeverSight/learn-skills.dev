Configura l'instrumentazione OpenTelemetry per il Tracing di Vercel e interroga gli span risultanti. Usalo quando aggiungi o correggi `@vercel/otel`, collegando il hook di avvio del server di un framework (Next.js, SvelteKit e altri), aggiungendo span personalizzati, attivando gli span da librerie come l'AI SDK, il Flags SDK o i client di database, propagando il contesto di traccia tra i servizi, configurando il campionamento di tracing sempre attivo, cercando o ispezionando gli span con `vercel traces`, o facendo il debug di richieste di server fallite o lente.
