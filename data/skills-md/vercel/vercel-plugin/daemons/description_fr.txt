Guide Vercel Daemons — travailleurs d’arrière‑plan à longue exécution construits à partir d’un Dockerfile et déclarés sous la clé `daemons` dans vercel.json. À utiliser lors de l’exécution de consommateurs de files d’attente, de workers Celery/Sidekiq/BullMQ, de workers de flux de travail ou de lanceurs de jobs à côté d’une application sur Vercel ; pour configurer les instances de daemon par région, mémoire ou commande ; pour gérer le SIGTERM ; ou pour choisir entre Daemons, Functions, Queues et Workflows.
