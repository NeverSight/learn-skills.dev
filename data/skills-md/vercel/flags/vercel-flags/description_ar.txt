أعلام الميزات، اختبارات A/B، والنشر التدريجي باستخدام Vercel Flags في أي تطبيق أو إطار عمل. استخدمها كلما كان المستخدم يخطط لإضافة أو تعديل أو تنظيف علم ميزة أو مفتاح تبديل أو مفتاح إيقاف أو تجربة أو نشر بنسبة مئوية أو قاعدة استهداف، أو يرغب في قفل أو إخفاء ميزة لبعض المستخدمين، حتى قبل اختيار مكتبة أو موفر خدمة. يغطي اختيار التكامل (Flags SDK، `@vercel/flags-core`، OpenFeature)، لوحة تحكم Vercel، سطر أوامر `vercel flags` (إنشاء، فحص، ضبط، تقسيم، نشر، قواعد، قطاعات، تقييمات، أرشفة)، OIDC مقابل مفاتيح SDK، `FLAGS_SECRET`، وتجاوزات Flags Explorer. بالنسبة لإعلانات `flag()`، والمحولات، والاحتساب المسبق، ونقطة النهاية Flags Explorer في كود Next.js أو SvelteKit، حمّل مهارة `flags-sdk`.
