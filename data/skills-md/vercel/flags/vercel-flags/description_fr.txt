Les feature flags, les tests A/B et les déploiements progressifs avec Vercel Flags, dans n’importe quelle application ou framework. Utilisez‑le chaque fois que l’utilisateur planifie, ajoute, modifie ou nettoie un feature flag, un toggle, un kill‑switch, une expérience, un déploiement en pourcentage ou une règle de ciblage, ou souhaite restreindre ou masquer une fonctionnalité pour certains utilisateurs, même avant qu’une bibliothèque ou un fournisseur ne soit choisi. Couvre le choix d’une intégration (Flags SDK, `@vercel/flags-core`, OpenFeature), le tableau de bord Vercel, la CLI `vercel flags` (create, inspect, set, split, rollout, rules, segments, evaluations, archive), OIDC vs clés SDK, `FLAGS_SECRET`, et les surcharges de Flags Explorer. Pour les déclarations `flag()`, les adaptateurs, le pré‑calcul et le point de terminaison Flags Explorer dans le code Next.js ou SvelteKit, chargez la compétence `flags-sdk`.
