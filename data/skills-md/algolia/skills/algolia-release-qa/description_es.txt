Lanzamiento, regresión y QA de implementación de Algolia. Úsalo al auditar una compilación de Algolia antes del lanzamiento, validar cambios de relevancia, comprobar el comportamiento de la interfaz de búsqueda, verificar la instrumentación de eventos, diagnosticar brechas analíticas, revisar claves seguras o crear un plan de pruebas de humo para búsqueda, navegación, autocompletar, indexado y cambios de configuración. NO lo uses para realizar cambios en cuentas en vivo ni inspeccionar datos de cuentas en vivo; usa primero algolia-mcp o algolia-cli. NO lo uses como la habilidad principal de implementación cuando la tarea sea claramente modelado de datos, configuración de eventos, InstantSearch, Autocompletar, NeuralSearch o Agent Studio; usa primero la habilidad enfocada y esta habilidad para la QA final.

Por favor, responde siempre en el idioma del usuario.
