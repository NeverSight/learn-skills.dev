مُحدِّد وتدفق عمل حي كمرجع للمكتبات الحالية لواجهة مستخدم Algolia. استخدمه عند اختيار، تثبيت، ترقية، تنفيذ، أو تدقيق InstantSearch.js، React InstantSearch، Vue InstantSearch، InstantSearch Android، InstantSearch iOS، Algolia لـ Flutter، Autocomplete، تدقيقات أو ترحيلات Angular InstantSearch القديمة، الإكمال التلقائي على نمط DocSearch، التوجيه، SSR، الأحداث، مجموعات تطوير SDK للمحمول، تكاملات الإطار، أمثلة الواجهة، التنسيق، الأداء، مفاتيح API المؤمنة، أو بنية مكتبة البحث للواجهة الأمامية. لا تستخدمه كمرجع API ثابت أو مصدر لإصدارات الحزم؛ تحقق من الوثائق الحالية. لا تستخدمه للتنفيذ الكامل بمجرد اختيار المكتبة؛ استخدم algolia-instantsearch‑ui، algolia‑autocomplete، أو مهارة instantsearch الرسمية.
