Utilisez cette compétence pour configurer et provisionner Algolia à partir de zéro : créez un nouveau compte Algolia, inscrivez‑vous, connectez‑vous / authentifiez le CLI Algolia, ou provisionnez une nouvelle application pour obtenir un ID d’application et une clé API. Déclenchez‑la lorsqu’un utilisateur débute avec Algolia et n’a pas encore de compte, d’application ou d’identifiants — par ex. « créer un compte Algolia », « s’inscrire à Algolia », « provisionner une application Algolia », « j’ai besoin d’un ID d’application / d’une clé API ». NE l’utilisez PAS pour les opérations d’index ou de données sur une application déjà authentifiée (enregistrements, synonymes, règles, paramètres — utilisez algolia‑cli), les interfaces de recherche frontales (utilisez instantsearch), ou la recherche et les analyses en lecture seule (utilisez algolia‑mcp).
