Utiliza esta habilidad para configurar y aprovisionar Algolia desde cero: crea una nueva cuenta de Algolia, regístrate, inicia sesión / autentica el CLI de Algolia, o aprovisiona una nueva aplicación para obtener un ID de aplicación y una clave API. Actívala cuando un usuario está empezando con Algolia y aún no tiene cuenta, aplicación o credenciales, por ejemplo: "crear una cuenta de Algolia", "registrarse en Algolia", "aprovisionar una aplicación de Algolia", "necesito un ID de aplicación / clave API". NO la uses para operaciones de índice o datos en una aplicación existente ya autenticada (registros, sinónimos, reglas, configuraciones — usa algolia‑cli), interfaces de búsqueda frontales (usa instantsearch) o búsquedas y análisis de solo lectura (usa algolia‑mcp).

Por favor, responde siempre en el idioma del usuario.
