Используйте этот навык для настройки и создания Algolia с нуля: создайте новую учётную запись Algolia, зарегистрируйтесь, войдите / аутентифицируйте Algolia CLI или создайте новое приложение, чтобы получить ID приложения и ключ API. Вызывайте, когда пользователь только начинает работать с Algolia и у него ещё нет учётной записи, приложения или учётных данных — например, «создать учётную запись Algolia», «зарегистрироваться в Algolia», «создать приложение Algolia», «мне нужен ID приложения / ключ API». НЕ используйте для операций с индексом или данными в уже существующем, аутентифицированном приложении (записи, синонимы, правила, настройки — используйте algolia‑cli), пользовательских поисковых интерфейсов (используйте instantsearch) или только для чтения поиска и аналитики (используйте algolia‑mcp).

Пожалуйста, всегда отвечайте на языке пользователя.
