使用此技能从头开始设置和配置 Algolia：创建一个新的 Algolia 账户、注册、登录/验证 Algolia CLI，或配置一个新应用以获取 App ID 和 API 密钥。当用户刚开始使用 Algolia 且尚未拥有账户、应用或凭证时触发，例如 “创建 Algolia 账户”、 “注册 Algolia”、 “配置 Algolia 应用”、 “我需要 App ID / API 密钥”。请勿用于已存在且已认证的应用的索引或数据操作（记录、同义词、规则、设置——使用 algolia-cli）、前端搜索 UI（使用 instantsearch）或只读的搜索和分析（使用 algolia-mcp）。

请始终使用用户的语言作答。
