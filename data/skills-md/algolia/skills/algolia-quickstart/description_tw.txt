使用此技能從頭開始設定與佈建 Algolia：建立新 Algolia 帳號、註冊、登入／驗證 Algolia CLI，或佈建新應用程式以取得 App ID 與 API 金鑰。於使用者剛開始使用 Algolia 且尚未有帳號、應用程式或憑證時觸發——例如「建立 Algolia 帳號」、「註冊 Algolia」、「佈建 Algolia 應用程式」、「我需要 App ID／API 金鑰」。請勿用於已存在且已驗證的應用程式之索引或資料操作（record、synonym、rule、setting——使用 algolia‑cli）、前端搜尋 UI（使用 instantsearch）或僅讀的搜尋與分析（使用 algolia‑mcp）。

請始終以使用者的語言回覆。
