Чеклист выполнения для новых построений поиска Algolia, обзора, автодополнения, поиска в электронной коммерции, рекомендаций, персонализации, динамического переранжирования или пользовательского интерфейса поиска. Используйте его при разработке с нуля, чтобы держать контракт данных, таксономию событий, конфигурацию индекса, UI и контроль качества релиза видимыми в виде явных контрольных точек с индикаторами завершения и предложенными артефактами, чтобы агенты действовали осознанно и документировали компромиссы и откладываемые решения. НЕ используйте его в качестве отправной точки для работы с Algolia; начните с algolia-discovery-planning, который сопоставляет запрос с жизненным циклом и загружает этот навык для новых построений.
