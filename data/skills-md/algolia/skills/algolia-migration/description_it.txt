Migrare il codice client API Algolia esistente a una versione principale più recente. Si attiva su: aggiornamento di algoliasearch, passaggio da initIndex ai metodi del client, correzione di “initIndex is not a function”, aggiornamento delle importazioni dopo un bump di versione, gestione delle breaking change da v3→v4 o v4→v5, sostituzione del chaining .wait(), o qualsiasi riferimento a “migrate Algolia client”, “upgrade Algolia SDK”, o a una specifica versione vecchia‑nuova (es. “Python v3 to v4”, “JS v4 to v5”). Copre JavaScript, Python, Go, PHP, Java, C#, Ruby, Kotlin, Scala, Swift. Dart è un nuovo client ed è escluso dal campo di applicazione. NON usarlo per la configurazione di nuovi progetti (usare invece algolia-cli o algolia-mcp), InstantSearch / framework frontend, query di analytics o raccomandazioni.

Rispondi sempre nella lingua dell'utente.
