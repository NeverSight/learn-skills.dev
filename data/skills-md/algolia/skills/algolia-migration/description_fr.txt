Migrer le code client existant de l'API Algolia vers une version majeure plus récente. S'active lors de : la mise à jour d'algoliasearch, le passage de initIndex aux méthodes du client, la résolution de « initIndex is not a function », la mise à jour des imports après un changement de version, la gestion des ruptures de compatibilité de v3→v4 ou v4→v5, le remplacement du chaînage .wait(), ou toute mention de « migrate Algolia client », « upgrade Algolia SDK », ou d'une version ancienne‑vers‑nouvelle spécifique (par ex. « Python v3 to v4 », « JS v4 to v5 »). Couvre JavaScript, Python, Go, PHP, Java, C#, Ruby, Kotlin, Scala, Swift. Dart est un nouveau client et est exclu du périmètre. Ne PAS l'utiliser pour la création d'un nouveau projet (utilisez algolia‑cli ou algolia‑mcp à la place), InstantSearch / frameworks frontend, requêtes d'analytics ou recommandations.
