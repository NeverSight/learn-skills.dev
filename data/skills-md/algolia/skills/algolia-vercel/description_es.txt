La parte de Algolia de una integración del Marketplace de Vercel: qué variables de Algolia inyecta, cómo deben llamarse tanto el CLI de Algolia como el navegador, y cómo lograr una primera búsqueda validada. Úselo cuando el usuario está en Vercel y quiere agregar Algolia desde el Marketplace — “set up Algolia on Vercel”, “vercel integration add algolia” — o cuando las variables inyectadas por el Marketplace ALGOLIA_APP_ID / ALGOLIA_SEARCH_API_KEY / ALGOLIA_WRITE_API_KEY deben conectarse a una aplicación y comprobarse con una consulta. Los mecanismos propios de Vercel — equipos, planes, términos, facturación, comandos de entorno — pertenecen a la documentación de Vercel, no a este documento. NO lo use solo porque un proyecto sea Next.js — Next.js por sí solo no implica Vercel. NO lo use cuando el usuario tiene una aplicación Algolia independiente que pretende mantener. NO lo use para registros, configuraciones, sinónimos, reglas o claves en una aplicación existente (algolia-cli), para la interfaz de búsqueda (instantsearch), para búsqueda de solo lectura y análisis (algolia-mcp), o para cuentas creadas fuera de Vercel (algolia-quickstart).

Por favor, siempre responda en el idioma del usuario.
