La partie Algolia d’une intégration Vercel Marketplace : quelles variables Algolia elle injecte, comment le CLI Algolia et le navigateur ont besoin qu’elles soient nommées, et comment atteindre une première recherche validée. À utiliser lorsque l’utilisateur est sur Vercel et souhaite ajouter Algolia depuis le Marketplace — « set up Algolia on Vercel », « vercel integration add algolia » — ou lorsque les variables injectées par le Marketplace ALGOLIA_APP_ID / ALGOLIA_SEARCH_API_KEY / ALGOLIA_WRITE_API_KEY doivent être reliées à une application et vérifiées avec une requête. Les mécanismes propres à Vercel — équipes, plans, conditions, facturation, commandes d’environnement — relèvent de la documentation Vercel, pas de ce document. NE PAS l’utiliser simplement parce qu’un projet est Next.js — Next.js seul ne signifie pas Vercel. NE PAS l’utiliser lorsque l’utilisateur possède une application Algolia autonome qu’il souhaite conserver. NE PAS l’utiliser pour les enregistrements, paramètres, synonymes, règles ou clés d’une application existante (algolia‑cli), pour l’interface de recherche (instantsearch), pour la recherche en lecture seule et les analyses (algolia‑mcp), ou pour des comptes créés en dehors de Vercel (algolia‑quickstart).
