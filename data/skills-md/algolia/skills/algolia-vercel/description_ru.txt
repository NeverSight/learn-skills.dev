Сторона Algolia в интеграции Vercel Marketplace: какие переменные Algolia она внедряет, как их должны называться в Algolia CLI и в браузере, и как достичь проверенного первого поиска. Используйте, когда пользователь находится на Vercel и хочет добавить Algolia из Marketplace — «set up Algolia on Vercel», «vercel integration add algolia» — или когда внедрённые Marketplace переменные ALGOLIA_APP_ID / ALGOLIA_SEARCH_API_KEY / ALGOLIA_WRITE_API_KEY нужно подключить к приложению и подтвердить запросом. Механика Vercel — команды, планы, условия, биллинг, переменные окружения — относится к документации Vercel, а не сюда. НЕ используйте только потому, что проект — Next.js; наличие Next.js не означает Vercel. НЕ используйте, если у пользователя уже есть отдельное приложение Algolia, которое они хотят сохранить. НЕ используйте для записей, настроек, синонимов, правил или ключей в существующем приложении (algolia‑cli), для UI поиска (instantsearch), для только‑чтения поиска и аналитики (algolia‑mcp) или для аккаунтов, созданных вне Vercel (algolia‑quickstart).
