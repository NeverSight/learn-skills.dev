Vercel Marketplace 整合的 Algolia 端：它會注入哪些 Algolia 變數、Algolia CLI 與瀏覽器各自需要的變數名稱，以及如何取得驗證過的首次搜尋。適用於使用者在 Vercel 上並希望從 Marketplace 加入 Algolia 時——「set up Algolia on Vercel」、「vercel integration add algolia」——或當 Marketplace 注入的 ALGOLIA_APP_ID / ALGOLIA_SEARCH_API_KEY / ALGOLIA_WRITE_API_KEY 需要接入應用程式並以查詢驗證時。Vercel 本身的機制——團隊、方案、條款、計費、環境指令——屬於 Vercel 文件的範疇，與此無關。不要僅因專案是 Next.js 而使用──Next.js 本身並不代表 Vercel。不要在使用者有獨立的 Algolia 應用程式且打算保留時使用。不要用於既有應用程式的紀錄、設定、同義詞、規則或金鑰（algolia-cli）、搜尋 UI（instantsearch）、僅讀搜尋與分析（algolia-mcp），或是 Vercel 以外建立的帳號（algolia-quickstart）。
