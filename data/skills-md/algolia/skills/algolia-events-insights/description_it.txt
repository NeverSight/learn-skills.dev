Linee guida per la strumentazione degli eventi Algolia per Insights, analytics, personalizzazione, Dynamic Re-Ranking, Recommend e cicli di feedback merchandising. Utilizzare per ricerca, autocompletamento, navigazione, e‑commerce, personalizzazione, raccomandazioni o strumentazione analytics. Rende le decisioni sugli eventi esplicite prima che un’interfaccia UI Algolia sia considerata pronta. Utilizzare durante l’implementazione o la verifica di clickedObjectIDsAfterSearch, convertedObjectIDsAfterSearch, viewedObjectIDs, addedToCartObjectIDsAfterSearch, purchasedObjectIDsAfterSearch, userToken, queryID, eventName, eventSubtype o pipeline di eventi frontend/backend. NON utilizzare per il recupero di analytics in tempo reale, l’ispezione delle query più frequenti o diagnostica basata sull’account; usare algolia-mcp. NON utilizzare per le API InstantSearch o Autocomplete specifiche di un framework; utilizzare la skill ufficiale instantsearch insieme a questa skill di pianificazione e validazione.
