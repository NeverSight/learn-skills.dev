Algolia のインサイト、分析、パーソナライズ、ダイナミックリランク、Recommend、マーチャンダイジングフィードバックループ向けイベント計装ガイダンス。検索、オートコンプリート、ブラウジング、eコマース、パーソナライズ、レコメンデーション、または分析計装に使用します。Algolia UI が利用可能になる前に、イベントの決定を明示的にします。clickedObjectIDsAfterSearch、convertedObjectIDsAfterSearch、viewedObjectIDs、addedToCartObjectIDsAfterSearch、purchasedObjectIDsAfterSearch、userToken、queryID、eventName、eventSubtype、またはフロントエンド/バックエンドのイベントパイプラインを実装または監査する際に使用してください。ライブ分析の取得、トップクエリの検査、またはアカウント認識診断には使用しないでください；algolia-mcp を使用してください。フレームワーク固有の InstantSearch や Autocomplete API には使用しないでください；この計画・検証スキルと併せて公式の instantsearch スキルを使用してください。
