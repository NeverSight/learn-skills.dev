Guía de instrumentación de eventos de Algolia para Insights, analítica, personalización, reordenamiento dinámico, Recommend y bucles de retroalimentación de merchandising. Uso para búsqueda, autocompletar, navegación, comercio electrónico, personalización, recomendaciones o instrumentación de analítica. Hace que las decisiones de eventos sean explícitas antes de que una UI de Algolia se considere lista. Utilizar al implementar o auditar clickedObjectIDsAfterSearch, convertedObjectIDsAfterSearch, viewedObjectIDs, addedToCartObjectIDsAfterSearch, purchasedObjectIDsAfterSearch, userToken, queryID, eventName, eventSubtype o pipelines de eventos frontend/backend. NO lo use para recuperación de analítica en tiempo real, inspección de consultas principales o diagnósticos con conocimiento de cuenta; use algolia-mcp. NO lo use para APIs específicas de framework de InstantSearch o Autocomplete; use la skill oficial de instantsearch junto con esta skill de planificación y validación.
