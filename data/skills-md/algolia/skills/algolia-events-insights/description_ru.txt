Руководство по инструментированию событий Algolia для Insights, аналитики, персонализации, динамического пере‑ранжирования, Recommend и циклов обратной связи мерчендайзинга. Используйте для поиска, автодополнения, просмотра, электронной коммерции, персонализации, рекомендаций или инструментирования аналитики. Делает решения о событиях явными до того, как UI Algolia считается готовым. Применяйте при реализации или аудите clickedObjectIDsAfterSearch, convertedObjectIDsAfterSearch, viewedObjectIDs, addedToCartObjectIDsAfterSearch, purchasedObjectIDsAfterSearch, userToken, queryID, eventName, eventSubtype или конвейеров событий фронтенда/бэкенда. НЕ используйте для живого получения аналитики, инспекции топ‑запросов или диагностики с учётом учётной записи; используйте algolia-mcp. НЕ используйте для API InstantSearch или Autocomplete, специфичных для фреймворков; используйте официальный instantsearch‑skill совместно с этим навыком планирования и валидации.
