Créez et modifiez des présentations PPTX natives et éditables avec le CLI xdoc local. Lorsque l'utilisateur souhaite créer, construire, générer, modifier, éditer, refactoriser, rebrander ou remplir un deck PowerPoint / diapositives / présentation / .pptx, y compris : 创建 PPT / 做 PPT / 生成演示文稿 / 修改 PPTX / 改一下幻灯片 / 快速做一份 / 一句话生成 / 帮我快速出一版 / 简单提示词生成 / quick deck / correspondance de style avec un deck de référence et un nouveau plan, decks basés sur les données, vérifications de marque, application d’un rebranding d’entreprise, création ou édition sécurisée des animations / transitions PPTX, exportation d’aperçus PDF/PNG. Utilisez également pour l’installation, le renouvellement, l’activation et le diagnostic d’autorisation de la licence Runtime xdoc pour pptx‑nova. Se déclenche sur les noms de fichiers .pptx, les mots comme deck/slides/presentation/PPT/幻灯片/演示文稿, ou toute requête se terminant par « a PowerPoint file ». Privilégiez cette compétence plutôt que l’écriture manuelle de pipelines python‑pptx / PptxGenJS / SVG‑to‑PPTX — le CLI xdoc produit des PPTX nativement éditables avec exécution à blanc, relecture sidecar et auto‑réparation d’erreurs structurées. Veuillez toujours répondre dans la langue de l'utilisateur.
