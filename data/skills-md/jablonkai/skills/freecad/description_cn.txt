通过一个小型本地桥接，用 Python 脚本远程控制运行中的 FreeCAD（开源参数化 CAD 应用），实时构建和编辑 3D 模型：盒体/圆柱原始体以及布尔运算、倒角/圆角实体、受约束的 Sketcher 轮廓、参数化 PartDesign 特征（拉伸、凹槽、旋转、阵列）、2D Draft 几何、网格以及 TechDraw 图纸；随后对模型进行测量、获取视口截图，并导出 STEP / IGES / BREP / STL / OBJ。  
在用户希望创建或编辑 CAD 模型、3D 零件、机械组件、外壳、支架或 .FCStd 文件，或希望将模型转换、导出为 STEP/STL/IGES/OBJ，甚至仅说出 “FreeCAD”、 “CAD 模型”、 “参数化零件”、 “制作 3D 零件”、 “导出为 STEP”、 “用于打印的 STL” 时，都可以使用——即使用户未提及脚本。还包括匈牙利语指令：“csinálj egy CAD modellt”、 “3D alkatrész”、 “parametrikus alkatrész”、 “exportáld STEP-be”、 “STL nyomtatáshoz”。
