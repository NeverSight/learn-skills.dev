Controla de forma remota un FreeCAD en ejecución (la aplicación CAD paramétrica de código abierto) mediante script Python a través de un pequeño puente local — construye y edita modelos 3D en vivo: primitivas de caja/cilindro y booleanas, sólidos con filetes/chaflanes, perfiles de Sketcher con restricciones, características paramétricas de PartDesign (extrusión, corte, revolución, patrones), geometría 2D de Draft, mallas y dibujos de TechDraw, luego mídelo, captura capturas de pantalla del viewport y exporta a STEP / IGES / BREP / STL / OBJ. Úsalo siempre que el usuario quiera crear o editar un modelo CAD, pieza 3D, componente mecánico, recinto, soporte o archivo .FCStd, convertir o exportar un modelo a STEP/STL/IGES/OBJ, o diga "FreeCAD", "modelo CAD", "pieza paramétrica", "hacer una pieza 3D", "exportar a STEP", "STL para imprimir" — incluso si no menciona scripting. También cubre húngaro: "csinálj egy CAD modellt", "3D alkatrész", "parametrikus alkatrész", "exportáld STEP-be", "STL nyomtatáshoz".
