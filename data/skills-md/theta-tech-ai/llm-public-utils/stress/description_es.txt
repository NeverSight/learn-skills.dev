Somete a prueba de estrés las aplicaciones (especialmente las web) — confirma la fiabilidad, revisa los caminos felices, causa travesuras, reúne un panel de usuarios novatos distintos y busca errores en el código — mediante navegador agente, scripts API o ambos. Úsalo siempre que el usuario quiera encontrar errores, casos límite, nudos, romper una aplicación, robustecer la UX o las APIs, hacer QA de un flujo, ejecutar QA de lanzamiento o de incorporación, probar qué confunde a los usuarios reales, simular diferentes usuarios o personas, o detectar problemas antes que los usuarios — incluso si solo dicen probar la aplicación, probar esto, invocar la API o ver qué se rompe.
