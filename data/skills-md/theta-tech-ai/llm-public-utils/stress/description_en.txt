Stress-test apps (especially webapps) — confirm reliability, comb happy paths, cause mischief, run a panel of distinct first-time users, and hunt bugs in code — via agent browser, API scripts, or both. Use whenever the user wants to find bugs, edge cases, knots, break an app, harden UX or APIs, QA a flow, run launch or onboarding QA, test what confuses real users, simulate different users or personas, or catch issues before users do — even if they only say try the app, test this, hit the API, or see what breaks.
