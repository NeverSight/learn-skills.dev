Analizar y refactorizar código frente a una librería de más de 50 principios de programación — código limpio, arquitectura, fiabilidad y capa de datos — encontrando y corrigiendo descuidos, duplicación, código muerto, sobreabstracción, archivos dios y complejidad innecesaria, midiendo todo con honestidad y ejecutando campañas de simplificación de todo el código. También amplía la librería investigando un principio faltante y fusionándolo. Utilízalo para pasadas de deslizamiento, revisión de calidad de código y PR, depuración y barridos de limpieza, triage de deuda técnica, planificación de refactorizaciones, análisis de complejidad, o cuando el código se considera desordenado, inflado, sobrecomplicado, copiado, difícil de leer o necesita una limpieza.
