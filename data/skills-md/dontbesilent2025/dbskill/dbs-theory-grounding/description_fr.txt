Recherche de sources théoriques et réinterprétation de cas. Examiner les jugements expérientiels dans les PPT, les cours, la rédaction ou les méthodologies ; Déterminez d’abord si la proposition est valable, puis faites correspondre et vérifiez les théories crédibles, en utilisant ces théories pour réinterpréter le cas et indiquer ses limites. Cela s'applique pour trouver les bases de théories auto-développées, compléter les PPT avec des sources théoriques, juger si une déclaration peut être élevée au rang de théorie, vérifier l'utilisation forcée de personnages célèbres ; il se concentre sur l’ancrage théorique d’une seule instance sans pour autant recourir à la recherche analogique historique.
