Sur la base d'une vidéo locale ou de sous-titres horodatés pour diviser les chapitres, les sujets ou les étapes, générez une barre de navigation MP4, une progression segmentée dynamique et un calendrier qui peut être importé dans le logiciel d'édition. À utiliser lorsque l'utilisateur demande une navigation dans un chapitre vidéo, une barre de progression supérieure ou une invite de position actuelle ; ne gère pas l'extraction de données de lien de plate-forme, la copie d'ouverture de couverture de titre, la superposition d'énoncé de risque ou l'édition de séquences originales.
