Создайте проект NocoBase 3 для локальной разработки с помощью `pnpm create @nocobase/app@beta`, настройте его командой `pnpm nocobase config init`, используйте `config set` и `config check`, запустите его и передайте управление руководству самого приложения. Применяйте это, когда пользователь просит установить, создать, настроить или попробовать NocoBase для разработки, а в рабочем каталоге ещё нет приложения NocoBase. Не предназначено для развертывания в продакшн — это относится к навыку `nocobase-app-installer`. Не относится к NocoBase 2 или CLI `nb`, а также не предназначено для работы внутри уже существующего приложения, которое имеет собственный файл AGENTS.md и свои навыки.
