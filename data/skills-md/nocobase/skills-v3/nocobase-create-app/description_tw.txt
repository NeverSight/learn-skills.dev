使用 `pnpm create @nocobase/app@beta` 在本機建立 NocoBase 3 專案以進行開發，使用 `pnpm nocobase config init`、`config set` 與 `config check` 進行配置，啟動後交由應用程式自行指引。當使用者要求安裝、建立、設定或嘗試使用 NocoBase 進行開發，且工作目錄尚未有 NocoBase 應用程式時使用。  
不適用於部署至正式環境，該情境屬於 `nocobase-app-installer` 技能範疇。  
不適用於 NocoBase 2 或 `nb` CLI，也不適用於已存在的應用程式內的工作，因其已有自己的 AGENTS.md 與 Skills。  
請始終以使用者的語言回應。
