NocoBase 3 プロジェクトをローカルで開発するには、`pnpm create @nocobase/app@beta` で作成し、`pnpm nocobase config init`、`config set`、`config check` で設定し、起動してアプリケーション独自のガイダンスに引き継ぎます。ユーザーが NocoBase のインストール、作成、設定、または体験を求め、作業ディレクトリにまだ NocoBase アプリケーションが無い場合に使用します。プロダクションへのデプロイ向けではなく、これは `nocobase-app-installer` スキルに属します。NocoBase 2 や `nb` CLI 用でもなく、既存アプリケーション内での作業（独自の AGENTS.md と Skills を持つ）にも適用しません。

常にユーザーの言語で回答してください。
