إنشاء مشروع NocoBase 3 للتطوير محليًا باستخدام `pnpm create @nocobase/app@beta`، وضبطه عبر `pnpm nocobase config init`، `config set` و `config check`، ثم تشغيله وتسليمه إلى إرشادات التطبيق نفسها. يُستَخدم عندما يطلب المستخدم تثبيت أو إنشاء أو إعداد أو تجربة NocoBase للتطوير، ولا يحتوي دليل العمل على تطبيق NocoBase بعد. ليس للنشر في الإنتاج، الذي يخص مهارة `nocobase-app-installer`. ليس لـ NocoBase 2 أو واجهة `nb` CLI، ولا للعمل داخل تطبيق موجود بالفعل، الذي يحمل ملف AGENTS.md ومهاراته الخاصة. يرجى دائمًا الرد بلغة المستخدم.
