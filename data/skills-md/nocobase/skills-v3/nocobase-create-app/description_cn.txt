创建一个 NocoBase 3 项目以进行本地开发，使用 `pnpm create @nocobase/app@beta`，通过 `pnpm nocobase config init`、`config set` 和 `config check` 进行配置，启动它，并交由应用程序自身的指南。用于用户请求安装、创建、设置或尝试使用 NocoBase 开发时，且工作目录中尚不存在 NocoBase 应用时使用。此技能不用于部署到生产环境，生产部署属于 `nocobase-app-installer` 技能。不适用于 NocoBase 2 或 `nb` CLI，也不用于已存在的应用内部工作，后者拥有自己的 AGENTS.md 和 Skills。

请始终使用用户的语言作答。
