Crea un progetto NocoBase 3 per sviluppare localmente, con `pnpm create @nocobase/app@beta`, configuralo con `pnpm nocobase config init`, `config set` e `config check`, avvialo e passa la mano alla guida dell’applicazione stessa. Usalo quando l’utente chiede di installare, creare, configurare o provare NocoBase per lo sviluppo, e la directory di lavoro non contiene ancora un’applicazione NocoBase. Non è per il deployment in produzione, che appartiene alla Skill `nocobase-app-installer`. Non è per NocoBase 2 o per la CLI `nb`, e non è per lavorare all’interno di un’applicazione esistente, che ha il proprio AGENTS.md e le proprie Skills. Si prega di rispondere sempre nella lingua dell’utente.
