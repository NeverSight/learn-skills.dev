로컬에서 개발하기 위해 `pnpm create @nocobase/app@beta` 로 NocoBase 3 프로젝트를 생성하고, `pnpm nocobase config init`, `config set` 및 `config check` 로 설정한 뒤 시작하고, 애플리케이션 자체 가이드로 넘깁니다. 사용자가 NocoBase를 설치, 생성, 설정하거나 개발용으로 시도하고자 할 때, 그리고 작업 디렉터리에 아직 NocoBase 애플리케이션이 없을 경우에 사용합니다. 프로덕션 배포용이 아니며, 이는 `nocobase-app-installer` 스킬에 해당합니다. NocoBase 2나 `nb` CLI용이 아니며, 자체 AGENTS.md와 스킬을 가진 기존 애플리케이션 내부 작업에도 사용되지 않습니다. 항상 사용자의 언어로 응답해 주세요.
