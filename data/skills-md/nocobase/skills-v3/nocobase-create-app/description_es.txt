Crea un proyecto NocoBase 3 para desarrollar localmente con `pnpm create @nocobase/app@beta`, configúralo con `pnpm nocobase config init`, `config set` y `config check`, inícialo y entrega la guía propia de la aplicación. Úsalo cuando el usuario solicite instalar, crear, configurar o probar NocoBase para desarrollar y el directorio de trabajo aún no contenga una aplicación NocoBase. No es para despliegue en producción, lo cual corresponde a la habilidad `nocobase-app-installer`. No es para NocoBase 2 ni para el CLI `nb`, y tampoco para trabajar dentro de una aplicación existente, que tiene su propio AGENTS.md y habilidades.
