Eine erstellte NocoBase 3‑Anwendung lokal oder per SSH auf einem offline Linux‑Server für die Produktion mit `@nocobase/app-installer` aus dem Bereitstellungs‑Archiv `pnpm build --tar` bereitstellen, dann aktualisieren, zurückrollen und prüfen. Verwenden, wenn der Benutzer auffordert, eine Anwendung in die Produktion oder auf einen Server zu deployen, um eine solche Installation zu aktualisieren oder zurückzurollen, oder wenn das Verzeichnis eine von app‑installer geschriebene `installer.json` enthält. Nicht zum Erstellen eines Projekts für die Entwicklung, das die `nocobase-create-app`‑Fähigkeit nutzt.
