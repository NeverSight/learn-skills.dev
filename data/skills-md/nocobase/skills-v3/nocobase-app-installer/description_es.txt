Despliegue una aplicación NocoBase 3 construida localmente o mediante SSH en un servidor Linux sin conexión, para producción, con `@nocobase/app-installer` a partir del archivo de despliegue que genera `pnpm build --tar`; luego actualícela, retroceda y verifíquelo. Use esta habilidad cuando el usuario solicite desplegar una aplicación en producción o en un servidor, para actualizar o revertir dicha instalación, o cuando el directorio contenga un `installer.json` creado por app‑installer. No es para crear un proyecto de desarrollo, lo cual corresponde a la habilidad `nocobase-create-app`.
