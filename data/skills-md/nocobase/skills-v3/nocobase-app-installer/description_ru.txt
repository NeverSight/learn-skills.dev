Разверните построенное приложение NocoBase 3 локально или через SSH на автономный сервер Linux для продакшн, используя `@nocobase/app-installer` из архива развертывания, созданного командой `pnpm build --tar`, затем выполните обновление, откат и проверку. Используйте, когда пользователь просит развернуть приложение в продакшн или на сервер, обновить или откатить такую установку, либо когда в каталоге присутствует `installer.json`, созданный app‑installer. Не предназначено для создания проекта для разработки — это навык `nocobase-create-app`. 

Пожалуйста, всегда отвечайте на языке пользователя.
