빌드된 NocoBase 3 애플리케이션을 로컬에서 또는 SSH를 통해 오프라인 Linux 서버에 배포하고, 배포 아카이브 `pnpm build --tar`가 생성하는 `@nocobase/app-installer`를 사용하여 프로덕션 환경에 적용한 후, 업그레이드, 롤백 및 검증합니다. 사용자는 애플리케이션을 프로덕션이나 서버에 배포하거나, 해당 설치를 업그레이드·롤백하거나, 디렉터리에 app-installer가 작성한 `installer.json`이 있을 때 사용합니다. 개발용 프로젝트를 생성하는 경우(`nocobase-create-app` 스킬)에는 사용하지 않습니다. 항상 사용자의 언어로 응답해 주세요.
