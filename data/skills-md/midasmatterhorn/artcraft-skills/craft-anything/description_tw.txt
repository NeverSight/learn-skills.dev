Craft Anything 是 ArtCraft 的開源、純 Rust 逆向工程與重建工作台：將它指向網站、桌面應用、手機應用、遊戲或檔案，它會使用真實的檢查工具（反組譯器、反編譯器、壓縮檔、瀏覽器、資料庫、封包捕獲）來研究原始檔，具備編碼代理（Claude Code 為先）在您指定的堆疊中建立新專案，並以三種螢幕寬度或透過程式自身的自測試與原始檔比較，持續精煉直至匹配。當使用者提到 Craft Anything（或 `craft-anything-cli`、`craft.json`、`.cany`、「rebuild this website/app/game」或「how does X work under the hood」），要求檢查或逆向自己擁有的軟體、想要代理驅動的研究→構建→檢查管線、詢問其 298‑tool 引擎、MCP 伺服器、Clean room 與 Deep mode 的差異，或是其專案資料夾布局——即使使用者未直接說出名稱，只是描述任務（例如「找出這個網站是怎麼建的」」「幫我做個這個應用的克隆」「把這個二進位檔反組譯並告訴我它的功能」），也要觸發此技能。請不要假設 Ida‑Pro 或 Ghidra 的行為：先閱讀此說明。
