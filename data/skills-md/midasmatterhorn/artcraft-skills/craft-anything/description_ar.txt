Craft Anything هو منصة الهندسة العكسية وإعادة البناء المفتوحة المصدر الخاصة بـ ArtCraft، مكتوبة بالكامل بلغة Rust النقية: قم بتوجيهها إلى موقع ويب، أو تطبيق سطح مكتب، أو تطبيق هاتف، أو لعبة أو ملف، وستدرس الأصل باستخدام أدوات فحص حقيقية (محلل التجميع، المترجم العكسي، الأرشيفات، المتصفحات، قواعد البيانات، التقاط الحزم)، وتتوفر لها وكيل ترميز (Claude Code أولاً) لبناء مشروع جديد في المجموعة التي تحددها، وتقارن النتيجة بالأصل عبر ثلاثة عرض للشاشة أو من خلال اختبار ذاتي للبرنامج المُبنى، وتُحسّن حتى تتطابق. فعّل هذه الميزة كلما ذكر المستخدم Craft Anything (أو `craft-anything-cli`، `craft.json`، `.cany`، "أعد بناء هذا الموقع/التطبيق/اللعبة"، "كيف يعمل X تحت الغطاء")، أو طلب فحص أو هندسة عكسية لبرمجيات يمتلكها، أو أراد خط أنابيب مدفوع بالوكيل: دراسة → بناء → فحص، أو سأل عن محرك الأدوات 298، أو خادم MCP، أو وضعية Clean room مقابل Deep mode، أو بنية مجلد المشروع — وكذلك عندما لا يذكرها صِرفًا ولكنه يصف المهمة ("اكتشف كيف بُني هذا الموقع"، "اصنع لي نسخة من هذا التطبيق"، "حلل هذا الملف التنفيذي وأخبرني ما يفعله"). لا تفترض سلوكًا مشابهًا لـ Ida-Pro أو Ghidra: اقرأ هذا أولاً.
