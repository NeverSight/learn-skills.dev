Craft Anything is ArtCraft's open-source, pure-Rust reverse-engineering and rebuilding workbench: point it at a website, desktop app, phone app, game or file, and it studies the original with real inspection tools (disassembler, decompiler, archives, browsers, databases, packet captures), has a coding agent (Claude Code first) build a new project in the stack you name, compares the result against the original at three screen widths or via the built program's own self-test, and refines until it matches. Trigger this skill whenever the user mentions Craft Anything (or `craft-anything-cli`, `craft.json`, `.cany`, "rebuild this website/app/game", "how does X work under the hood"), asks to inspect or reverse-engineer software they own, wants an agent-driven study→build→check pipeline, asks about its 298-tool engine, its MCP server, Clean room vs Deep mode, or its project folder layout — and equally when they never name it but describe the job ("figure out how this site is built", "make me a clone of this app", "disassemble this binary and tell me what it does"). Do not assume Ida-Pro-style or Ghidra-style behaviour: read this first.
