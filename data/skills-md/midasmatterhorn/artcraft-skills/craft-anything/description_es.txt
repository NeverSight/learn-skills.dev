Craft Anything es el banco de trabajo de código abierto y puramente escrito en Rust de ArtCraft para la ingeniería inversa y la reconstrucción: apúntalo a un sitio web, aplicación de escritorio, aplicación móvil, juego o archivo, y estudia el original con herramientas reales de inspección (desensamblador, decompilador, archivos, navegadores, bases de datos, capturas de paquetes), cuenta con un agente de codificación (Claude Code primero) que construye un nuevo proyecto en la pila que indiques, compara el resultado con el original en tres anchos de pantalla o mediante la autoprueba del propio programa construido, y refina hasta que coincida. Activa esta habilidad cada vez que el usuario mencione Craft Anything (o `craft-anything-cli`, `craft.json`, `.cany`, "rebuild this website/app/game", "how does X work under the hood"), solicite inspeccionar o invertir ingenieramente software que posea, desee una cadena de estudio→construcción→verificación impulsada por agentes, pregunte sobre su motor de 298‑herramientas, su servidor MCP, modo Clean room vs Deep, o la disposición de la carpeta de proyecto — y también cuando nunca lo nombre pero describa el trabajo ("figure out how this site is built", "make me a clone of this app", "disassemble this binary and tell me what it does"). No asumas un comportamiento al estilo Ida‑Pro o Ghidra: lee esto primero.
