GridCraft is an open-source, clean-room Rust reimplementation of Microsoft Excel: a spreadsheet app for macOS (also Windows, Linux, BSD and the web) that reads and writes real .xlsx files and can be driven headlessly through a CLI, an MCP server and a live JSON control channel. Use this skill whenever the user mentions GridCraft by name; asks what it can do or which formats, keyboard shortcuts, commands or worksheet functions it has; wants to create, edit, convert, calculate, print or export spreadsheets with it; wants to automate or script it (MCP, CLI, control channel, recorded scripts, or the web build's `window.gridcraft` page API); needs inputs prepared for it (build or convert .xlsx, CSV, TSV, JSON, or convert .xls/.xlsb/.ods/.slk into .xlsx); wants its output verified, repaired or round-tripped (gridcraft-cli check); wants to confirm that a machine really confines helper processes (gridcraft-cli sandbox-check); or reports a symptom (crash, wrong formula result, formatting lost on save, Excel saying "we found a problem with some content"). Trigger it even when the app is not named but the job is Excel-style spreadsheet work — "make me an Excel file", "add a formula column", "sort and filter this sheet", "pivot this data", "export this workbook to PDF", "read the values out of this spreadsheet", "make this Arabic sheet read right to left". Do not assume Excel parity from Excel knowledge; check this skill first.
