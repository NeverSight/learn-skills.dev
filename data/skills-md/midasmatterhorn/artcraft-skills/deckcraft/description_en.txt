DeckCraft is the ArtCraft open-source, clean-room PowerPoint-compatible presentation app for macOS (also Windows, Linux, FreeBSD and the web): slides, masters and layouts, shapes, 3-D, text, tables, charts, SmartArt, media, transitions, animations, slide shows, and `.deckcraft`, `.pptx`/`.potx`/`.ppsx`, outline text, Markdown and `.rtf`, PDF/PNG/JPEG/GIF files — driven by 329 scriptable commands, a 12-subcommand CLI, a JSON control channel, a 25-tool MCP server and, in the web build, a `window.deckcraft` page API. Trigger this skill whenever the user mentions DeckCraft, `.deckcraft`, `deckcraft-cli`, asks what DeckCraft can or cannot do, which formats or shortcuts it supports, wants to build, edit, inspect, convert, render, present, export, verify, repair or troubleshoot a deck, wants assets prepared for it, or wants it automated or scripted — even if the app is not named but the job is presentation work ("make a deck", "turn this outline into slides", "export these slides to PDF", "why did my PPTX lose its animations?", "drive a presentation app with an agent"). Do not use it for Microsoft PowerPoint itself.
