SolidCraft is an open-source parametric 3D CAD application in pure Rust (by Tangency Labs, independent clean-room; not an Autodesk/Dassault product): sketches with constraints and parameter-driven dimensions, a parametric feature timeline (extrude, revolve, sweep, loft, fillet, chamfer, shell, draft, holes, threads, patterns, mirror, split, combine, cell grids), sheet metal, plastic enclosure features, assemblies with joints and motion studies, physical materials with exact mass properties, sandboxed WebAssembly command plugins, GnuPG/COSE-signed design provenance, and STEP/IGES/3MF/STL/OBJ/GLB/URDF/DXF interchange plus KiCad PCB import. Desktop app, browser app, headless CLI and a 22-tool MCP server all run the same 647-command registry. Trigger this skill whenever the user mentions SolidCraft (or `.sc`, `solidcraft-cli`, "SolidCraft MCP", the control channel on 27878, a SolidCraft plugin), asks what it can model or open/export, wants an agent to build or edit a parametric part (enclosure, bracket, plate, flange, wing rib, perforated panel), import a KiCad board, sign or verify a design, drive the control channel, script a build, run the oracle, or troubleshoot it — and equally when they never name it but describe parametric CAD work ("model a case for this board", "sketch, constrain and extrude", "export a STEP of this bracket"). Do not assume Fusion/SolidWorks behaviour: read this first.
