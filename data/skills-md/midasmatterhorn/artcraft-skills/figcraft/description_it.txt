FigCraft è un’app open‑source, scritta interamente in Rust, per la progettazione di interfacce offline, prototipazione e lavagna (una re‑implementazione clean‑room del flusso di lavoro di Figma Design): cornici, layout automatico, componenti, stili, variabili, reti vettoriali, prototipazione, Modalità Dev e file board, disponibile su macOS, Windows, Linux, FreeBSD e sul web. Attivala ogni volta che l’utente menziona FigCraft o un file `.figcraft`, chiede cosa può o non può fare, quali formati apre o scrive, come scriptare, automatizzare, batchare o controllare in modalità headless (figcraft‑cli, MCP, il canale di controllo JSON), vuole risorse preparate per un file di design, ha bisogno di verificare o riparare l’output, o chiede di risolverne i problemi — e quando l’app non è nominata ma il compito è uno dei suoi compiti: “creare un mockup”, “progettare una schermata / pagina di destinazione / dashboard”, “costruire un design system”, “esportare queste cornici in PNG/PDF/SVG”, “aprire questo file .fig o JSON di Figma”, “convertire questo file Sketch”, “prototipare questo flusso”, “consegnarlo a uno sviluppatore”, “creare una board retro”. Non presumere capacità basate sulla conoscenza di Figma — FigCraft non è Figma e non esegue plugin di Figma.

Rispondi sempre nella lingua dell’utente.
