FigCraft es una aplicación de código abierto, escrita completamente en Rust, de diseño de interfaces, prototipado y pizarra offline (una reimplementación de sala limpia del flujo de trabajo de Figma Design): marcos, auto‑layout, componentes, estilos, variables, redes vectoriales, prototipado, modo Dev y archivos de pizarra, disponible en macOS, Windows, Linux, FreeBSD y la web. Actívala siempre que el usuario mencione FigCraft o un archivo `.figcraft`, pregunte qué puede o no hacer, qué formatos abre o escribe, cómo scriptar, automatizar, procesar por lotes o controlarla de forma headless (figcraft‑cli, MCP, el canal de control JSON), quiera activos preparados para un archivo de diseño, necesite verificar o reparar la salida, o solicite solucionar problemas — y cuando la aplicación no se nombre pero la tarea sea una de sus funciones: «hacer un mockup», «diseñar una pantalla / página de aterrizaje / panel», «construir un sistema de diseño», «exportar estos marcos a PNG/PDF/SVG», «abrir este archivo .fig o JSON de Figma», «convertir este archivo de Sketch», «prototipar este flujo», «entregarlo a un desarrollador», «crear una pizarra retro». No supongas capacidades basándote en el conocimiento de Figma — FigCraft no es Figma y no ejecuta plugins de Figma.
