Проводит обзор кодовых баз React и TypeScript на предмет тревожных сигналов, указывающих на проблемы с поддерживаемостью, с учётом практики старших фронтенд‑разработчиков. Используйте при аудите кода React, оценке фронтенд‑архитектуры, выявлении «запахов» кода, подготовке рефакторинга или проверке, будет ли поддержка кодовой базы React обременительной.
