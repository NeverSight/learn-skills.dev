Vue 3 と vue-lynx カスタムレンダラーを使用してネイティブ Lynx アプリケーションを構築する方法。デュアルスレッドアーキテクチャ、Lynx ネイティブ要素（<view>、<text>、<image>）、Lynx イベントシステム（:bindtap、:catchtap）、パフォーマンスクリティカルなインタラクション向けのメインスレッドスクリプト、そしてエコシステム統合（Vue Router、Pinia、TanStack Query、Tailwind CSS）をカバーします。ユーザーが Vue Lynx アプリを構築、デバッグ、質問する際、Vue Web コードを Lynx に変換する際、vue-lynx プロジェクトを設定する際、vue-lynx テストを書く際、または Lynx ネイティブ UI を扱う際にこのスキルを使用してください。さらに、ユーザーが lynx.config.ts、rspeedy、LynxExplorer、または 'vue-lynx' からのインポートに言及したときにもトリガーしてください。
