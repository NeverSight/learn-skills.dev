Vue 3와 vue-lynx 커스텀 렌더러를 사용하여 네이티브 Lynx 애플리케이션을 만드는 방법. 듀얼 스레드 아키텍처, Lynx 네이티브 요소 (<view>, <text>, <image>), Lynx 이벤트 시스템 (:bindtap, :catchtap), 성능이 중요한 상호작용을 위한 메인 스레드 스크립트, 그리고 생태계 통합 (Vue Router, Pinia, TanStack Query, Tailwind CSS)을 다룹니다. 사용자가 Vue Lynx 앱을 구축, 디버깅하거나 질문할 때, Vue 웹 코드를 Lynx로 변환할 때, vue-lynx 프로젝트를 설정할 때, vue-lynx 테스트를 작성할 때, 또는 Lynx 네이티브 UI와 작업할 때 이 스킬을 사용하십시오. 또한 사용자가 lynx.config.ts, rspeedy, LynxExplorer를 언급하거나 'vue-lynx'를 임포트할 경우에도 트리거됩니다.
