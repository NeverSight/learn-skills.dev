Cómo crear aplicaciones nativas Lynx usando Vue 3 con el renderizador personalizado vue‑lynx. Cubre la arquitectura de doble hilo, los elementos nativos de Lynx (<view>, <text>, <image>), el sistema de eventos de Lynx (:bindtap, :catchtap), el script del hilo principal para interacciones críticas de rendimiento y la integración del ecosistema (Vue Router, Pinia, TanStack Query, Tailwind CSS). Usa esta habilidad siempre que el usuario esté construyendo, depurando o preguntando sobre apps Vue Lynx, convirtiendo código web Vue a Lynx, configurando un proyecto vue‑lynx, escribiendo pruebas vue‑lynx o trabajando con cualquier UI nativa de Lynx. También se activa cuando el usuario menciona lynx.config.ts, rspeedy, LynxExplorer o importaciones de 'vue-lynx'.
