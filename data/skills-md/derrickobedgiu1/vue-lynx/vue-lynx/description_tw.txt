如何使用 Vue 3 與 vue-lynx 自訂渲染器構建原生 Lynx 應用程式。涵蓋雙執行緒架構、Lynx 原生元素（<view>、<text>、<image>）、Lynx 事件系統（:bindtap、:catchtap）、用於效能關鍵互動的主執行緒腳本，以及生態系統整合（Vue Router、Pinia、TanStack Query、Tailwind CSS）。在使用者構建、除錯或詢問 Vue Lynx 應用、將 Vue 網頁程式碼轉換為 Lynx、設置 vue-lynx 專案、編寫 vue-lynx 測試，或操作任何 Lynx 原生 UI 時，請使用此技能。當使用者提及 lynx.config.ts、rspeedy、LynxExplorer，或從 'vue-lynx' 匯入時，也需觸發此技能。
