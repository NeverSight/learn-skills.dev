Come creare applicazioni native Lynx usando Vue 3 con il renderer personalizzato vue‑lynx. Copre l’architettura a doppio thread, gli elementi nativi di Lynx (<view>, <text>, <image>), il sistema di eventi di Lynx (:bindtap, :catchtap), lo Script del Thread Principale per interazioni critiche di performance e l’integrazione dell’ecosistema (Vue Router, Pinia, TanStack Query, Tailwind CSS). Usa questa competenza ogni volta che l’utente sta sviluppando, facendo debug o chiedendo informazioni su app Vue Lynx, convertendo codice Vue web in Lynx, configurando un progetto vue‑lynx, scrivendo test vue‑lynx o lavorando con qualsiasi UI nativa Lynx. Attiva anche quando l’utente menziona lynx.config.ts, rspeedy, LynxExplorer o importazioni da 'vue‑lynx'.
