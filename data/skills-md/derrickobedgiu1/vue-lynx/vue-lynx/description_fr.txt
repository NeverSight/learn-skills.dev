Comment créer des applications natives Lynx en utilisant Vue 3 avec le rendu personnalisé vue‑lynx. Couvre l’architecture à double thread, les éléments natifs Lynx (<view>, <text>, <image>), le système d’événements Lynx (:bindtap, :catchtap), le script du thread principal pour les interactions critiques en performance, et l’intégration de l’écosystème (Vue Router, Pinia, TanStack Query, Tailwind CSS). Utilisez cette compétence chaque fois que l’utilisateur construit, débogue ou interroge sur les applications Vue Lynx, convertit du code Vue Web en Lynx, configure un projet vue‑lynx, écrit des tests vue‑lynx ou travaille avec toute interface utilisateur native Lynx. Déclenchez également lorsque l’utilisateur mentionne lynx.config.ts, rspeedy, LynxExplorer ou importe depuis « vue‑lynx ».
