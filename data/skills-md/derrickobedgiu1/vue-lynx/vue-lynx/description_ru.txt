Как создавать нативные приложения Lynx с использованием Vue 3 и кастомного рендерера vue-lynx. Охватывает двухпотоковую архитектуру, нативные элементы Lynx (<view>, <text>, <image>), систему событий Lynx (:bindtap, :catchtap), скрипт главного потока для критически важных по производительности взаимодействий и интеграцию в экосистему (Vue Router, Pinia, TanStack Query, Tailwind CSS). Используйте этот навык, когда пользователь разрабатывает, отлаживает или задаёт вопросы о Vue Lynx‑приложениях, конвертирует веб‑код Vue в Lynx, настраивает проект vue-lynx, пишет тесты vue-lynx или работает с любой нативной UI Lynx. Также активируйте, когда пользователь упоминает lynx.config.ts, rspeedy, LynxExplorer или импорты из 'vue-lynx'.

Пожалуйста, всегда отвечайте на языке пользователя.
