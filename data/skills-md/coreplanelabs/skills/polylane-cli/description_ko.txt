'polylane' CLI를 사용하여 터미널에서 Polylane을 구동하고 생산 문제, 사건 및 경고를 조사합니다. 검색 로그 및 쿼리 측정항목 클라우드 리소스, 서비스 및 종속성 그래프를 탐색합니다. 무엇이 배포되었는지 확인하세요. 검색 코드; 추억을 저장하십시오; 카탈로그에서 자동화를 실행합니다. 관찰 도구와 클라우드 계정을 연결합니다. Polylane 에이전트로 스레드를 구동합니다. 작업이 셸 또는 스크립트에서 발생하는 경우, 사용자가 CLI를 요청하는 경우 또는 Polylane MCP 도구가 연결되지 않은 경우 제품 디버그, 서비스 또는 리소스 조회, 코드베이스 검색, 통합 관리, 클라우드 공급자 연결 또는 Polylane 에이전트와 대화하는 데 사용합니다. 검색(`--help`, `polylane api explain`) — 명령이나 플래그를 추측하지 마세요.
