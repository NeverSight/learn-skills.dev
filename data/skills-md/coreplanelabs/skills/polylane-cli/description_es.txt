Conduce Polylane desde la terminal con la CLI `polylane` — investiga problemas de producción, incidentes y alertas; busca en los registros y consulta métricas; explora recursos en la nube, servicios y grafos de dependencias; verifica qué está desplegado; busca código; guarda recuerdos; ejecuta automatizaciones desde un catálogo; conecta herramientas de observabilidad y cuentas en la nube; y dirige hilos con el agente de Polylane. Úsalo cuando el trabajo ocurre en una shell o script, cuando el usuario solicita la CLI, o cuando las herramientas Polylane MCP no están conectadas — para depurar producción, buscar un servicio o recurso, explorar la base de código, gestionar integraciones, conectar un proveedor de nube o conversar con el agente de Polylane. Recupera (`--help`, `polylane api describe`) — nunca adivines comandos o banderas.
