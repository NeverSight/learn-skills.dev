Conduzca Polylane desde la terminal con la CLI `polylane`: investigue problemas de producción, incidentes y alertas; registros de búsqueda y métricas de consulta; explorar recursos, servicios y gráficos de dependencia de la nube; comprobar lo que está desplegado; código de búsqueda; guardar recuerdos; ejecutar automatizaciones desde un catálogo; conectar herramientas de observabilidad y cuentas en la nube; e introduzca hilos con el agente Polylane. Úselo cuando el trabajo se realiza en un shell o script, cuando el usuario solicita la CLI o cuando las herramientas Polylane MCP no están conectadas: para depurar productos, buscar un servicio o recurso, buscar en el código base, administrar integraciones, conectar un proveedor de nube o hablar con el agente de Polylane. Recuperar (`--help`, `polylane api describe`): nunca adivine comandos o indicadores.
