「polylane」CLI を使用してターミナルから Polylane を操作します。運用上の問題、インシデント、アラートを調査します。検索ログとクエリメトリクス。クラウド リソース、サービス、依存関係グラフを探索します。何がデプロイされているかを確認します。検索コード;思い出を保存する。カタログからオートメーションを実行します。可観測性ツールとクラウドアカウントを接続します。 Polylane エージェントを使用してスレッドを駆動します。作業がシェルまたはスクリプトで行われる場合、ユーザーが CLI を要求する場合、または Polylane MCP ツールが接続されていない場合に使用します。これは、本番環境のデバッグ、サービスまたはリソースの検索、コードベースの検索、統合の管理、クラウド プロバイダーの接続、または Polylane エージェントとの通信に使用されます。取得 (`--help`、`polylane api description`) — コマンドやフラグを決して推測しないでください。
