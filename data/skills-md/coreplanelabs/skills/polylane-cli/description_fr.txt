Pilotez Polylane depuis le terminal avec la CLI « polylane » : enquêtez sur les problèmes de production, les incidents et les alertes ; journaux de recherche et métriques de requêtes ; explorez les ressources cloud, les services et les graphiques de dépendance ; vérifiez ce qui est déployé ; code de recherche ; sauvegarder des souvenirs; exécuter des automatisations à partir d'un catalogue ; connecter les outils d'observabilité et les comptes cloud ; et piloter les threads avec l'agent Polylane. À utiliser lorsque le travail s'effectue dans un shell ou un script, lorsque l'utilisateur demande la CLI ou lorsque les outils Polylane MCP ne sont pas connectés : pour déboguer une production, rechercher un service ou une ressource, rechercher dans la base de code, gérer les intégrations, connecter un fournisseur de cloud ou parler à l'agent Polylane. Récupérer (`--help`, `polylane apiscribe`) — ne devinez jamais les commandes ou les indicateurs.
