Управляйте Polylane с терминала с помощью CLI «polylane» — исследуйте производственные проблемы, инциденты и оповещения; журналы поиска и метрики запросов; исследовать облачные ресурсы, сервисы и графики зависимостей; проверить, что развернуто; код поиска; сохранить воспоминания; запускать автоматизацию из каталога; подключать инструменты наблюдения и облачные аккаунты; и управляйте потоками с помощью агента Polylane. Используйте, когда работа происходит в оболочке или скрипте, когда пользователь запрашивает CLI или когда инструменты Polylane MCP не подключены — для отладки продукта, поиска сервиса или ресурса, поиска в базе кода, управления интеграциями, подключения облачного провайдера или общения с агентом Polylane. Получить (`--help`, `polylane api описать`) — никогда не угадывайте команды или флаги.
