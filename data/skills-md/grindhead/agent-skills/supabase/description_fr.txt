Utilisez-le pour toute tâche impliquant Supabase. Déclencheurs : produits Supabase (Database, Auth, Edge Functions, Realtime, Storage, Vectors, Cron, Queues) ; bibliothèques clientes et intégrations SSR (supabase‑js, @supabase/ssr) dans Next.js, React, SvelteKit, Astro, Remix ; problèmes d’authentification (login, logout, sessions, JWT, cookies, getSession, getUser, getClaims, RLS) ; Supabase CLI ou serveur MCP ; changements de schéma, migrations, schémas déclaratifs, audits de sécurité, extensions Postgres (pg_graphql, pg_cron, pg_vector) ; débogage et résolution des erreurs ou comportements inattendus sur les projets Supabase (erreurs HTTP, erreurs Postgres, surprises RLS, permission denied, problèmes de cache de schéma, timeouts, plantages d’Edge Functions, ruptures de Realtime, échecs de Storage) ainsi que la lecture ou l’interrogation des journaux (Logs Explorer, ClickHouse).
