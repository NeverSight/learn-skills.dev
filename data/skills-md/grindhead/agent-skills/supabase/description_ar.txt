استخدمه عند تنفيذ أي مهمة تتعلق بـ Supabase. المشغلات: منتجات Supabase (قاعدة البيانات، المصادقة، وظائف الحافة، الوقت الحقيقي، التخزين، المتجهات، جدولة Cron، قوائم الانتظار)؛ مكتبات العميل وتكاملات SSR (supabase‑js، @supabase/ssr) في Next.js، React، SvelteKit، Astro، Remix؛ مشكلات المصادقة (تسجيل الدخول، تسجيل الخروج، الجلسات، JWT، ملفات تعريف الارتباط، getSession، getUser، getClaims، RLS)؛ CLI الخاص بـ Supabase أو خادم MCP؛ تغييرات المخطط، الترقيات، المخططات التصريحية، تدقيق الأمان، امتدادات PostgreSQL (pg_graphql، pg_cron، pg_vector)؛ تصحيح الأخطاء واستكشاف المشكلات أو السلوك غير المتوقع في مشاريع Supabase (أخطاء HTTP، أخطاء PostgreSQL، مفاجآت RLS، رفض الإذن، مشاكل ذاكرة التخزين المؤقت للمخطط، مهلات، تعطل وظائف الحافة، انقطاعات الوقت الحقيقي، فشل التخزين) وقراءة أو استعلام السجلات (مستكشف السجلات، ClickHouse).
