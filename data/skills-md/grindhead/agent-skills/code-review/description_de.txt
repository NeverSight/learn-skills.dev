Überprüfe die Änderungen seit einem festen Punkt (Commit, Branch, Tag oder Merge‑Base) entlang zweier Achsen: Standards (entspricht der Code den dokumentierten Coding‑Standards dieses Repos?) und Spezifikation (stimmt der Code mit dem überein, was das zugrunde liegende Ticket/Spec gefordert hat?). Führt beide Prüfungen in parallelen Sub‑Agenten durch und stellt sie nebeneinander dar. Verwende dies, wenn der Benutzer einen Branch, einen Pull‑Request, laufende Änderungen prüfen möchte oder auffordert, „seit X“ zu prüfen.
