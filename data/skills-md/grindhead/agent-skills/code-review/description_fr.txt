Examinez les changements depuis un point fixe (commit, branche, tag ou base de fusion) selon deux axes : Standards (le code respecte‑t‑il les standards de codage documentés de ce dépôt ?) et Spécifications (le code correspond‑il à ce que l’incident ou la spécification d’origine demandait ?). Exécutez les deux revues en sous‑agents parallèles et présentez‑les côte à côte. À utiliser lorsque l’utilisateur veut examiner une branche, une PR, des modifications en cours ou demande de « review since X ».
