Aiuta gli utenti a scoprire e installare le competenze dell'agente quando pongono domande come “come faccio X”, “trova una skill per X”, “c'è una skill che può…”, o esprimono interesse ad estendere le capacità. Questa skill dovrebbe essere usata quando l'utente cerca una funzionalità che potrebbe esistere come skill installabile.

Per favore, rispondi sempre nella lingua dell'utente.
