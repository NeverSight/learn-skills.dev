Erstelle einen interaktiven Bash‑Assistenten, der einen Menschen durch Schritte führt, die nur er ausführen kann. Verwende ihn beim Bereitstellen von Infrastruktur, Einrichten von Anmeldeinformationen oder CI‑Geheimnissen, beim Durchführen eines unbekannten Drittanbieter‑Dashboards oder bei einer einmaligen Migration bzw. Umschaltung. Rufe ihn nicht für Schritte auf, die der Agent selbst ausführen kann.
