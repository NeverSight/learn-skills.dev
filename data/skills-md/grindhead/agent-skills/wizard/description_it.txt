Genera un wizard bash interattivo che guidi l'utente attraverso passaggi che solo lui può eseguire. Usalo durante il provisioning dell'infrastruttura, la configurazione di credenziali o segreti CI, la navigazione di una dashboard di terze parti sconosciuta, o l'esecuzione di una migrazione o transizione una tantum. Non invocare questo per passaggi che l'agente può eseguire autonomamente.
