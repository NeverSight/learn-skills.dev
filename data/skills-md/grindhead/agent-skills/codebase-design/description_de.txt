Gemeinsamer Wortschatz für das Design von Deep‑Modulen. Verwenden Sie ihn, wenn der Nutzer die Schnittstelle eines Moduls entwerfen oder verbessern, Vertiefungsmöglichkeiten finden, entscheiden möchte, wo eine Naht gesetzt wird, den Code testbarer oder KI‑navigierbarer machen will oder wenn eine andere Fähigkeit den Deep‑Module‑Wortschatz benötigt.

Bitte immer in der Sprache des Nutzers antworten.
