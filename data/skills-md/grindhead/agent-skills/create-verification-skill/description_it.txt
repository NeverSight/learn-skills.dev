Genera una skill di verifica locale al progetto che guida la tua app come fa un utente — in qualsiasi linguaggio, framework o piattaforma. Usala per /create-verification-skill, “crea una skill di controllo per questo repository”, o quando un progetto non ha modo scriptato per dimostrare il comportamento di UI/CLI/servizio.

Rispondi sempre nella lingua dell’utente.
