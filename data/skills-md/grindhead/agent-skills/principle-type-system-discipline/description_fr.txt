Appliquez-le lors de la conception de types, de la révision d’une signature de fonction ou de l’écriture de code dans tout langage à typage statique. Rendez les états illégaux non représentables, marquez les primitives sémantiques, analysez les données externes aux frontières, refusez de mentir au compilateur, épuisiez les variantes, dérivez de schémas faisant autorité.
