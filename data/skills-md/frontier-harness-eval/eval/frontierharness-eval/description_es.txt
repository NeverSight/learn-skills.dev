Evalúa un arnés de agente de codificación de terceros contra FrontierHarness Eval usando entornos Runta. Proporciona un entorno limpio vinculado al repositorio de GitHub bajo evaluación, instala las pilas Harbor y Pier necesarias para las tareas Terminal‑Bench y DeepSWE, congela un punto de control dorado, ejecuta tareas desde restauraciones frescas idénticas guardando trayectorias como evidencia, genera un diagrama comparativo y crea un informe compartible. Úsalo al evaluar, comparar, puntuar o contrastar un arnés de agente de codificación, o cuando el usuario mencione FrontierHarness, DeepSWE, Terminal‑Bench, Harbor, Pier, puntos de control dorados o trayectorias del arnés.
