قم بقياس أداة تسخير وكيل الترميز التابع لجهة خارجية مقابل FrontierHarness Eval باستخدام أوقات تشغيل Runta. توفير وقت تشغيل نظيف مرتبط بمستودع GitHub قيد التقييم، وتثبيت مجموعات Harbour and Pier اللازمة لمهام Terminal-Bench وDeepSWE، وتجميد نقطة تفتيش ذهبية، وتشغيل المهام من عمليات استعادة جديدة متطابقة مع حفظ المسارات كدليل، وإنشاء مخطط مقارنة، وإنشاء تقرير قابل للمشاركة. يُستخدم عند تقييم مجموعة أدوات الترميز أو قياسها أو تسجيلها أو مقارنتها، أو عندما يذكر المستخدم FrontierHarness، أو DeepSWE، أو Terminal-Bench، أو Harbour، أو Pier، أو نقاط التفتيش الذهبية، أو مسارات الحزام.
