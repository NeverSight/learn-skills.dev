Compétence d'expert pour le framework webman (un framework PHP en mémoire de longue durée basé sur Workerman). Couvre le routage, les contrôleurs, le middleware, la base de données/Redis, les processus personnalisés, les minuteries, les coroutines (v2), le développement de plugins et la protection contre les fuites de mémoire et la pollution de l'état des requêtes croisées dans le cadre du modèle de processus résident. À utiliser lorsque le projet contient start.php, config/process.php ou support/bootstrap.php, ou lorsque l'utilisateur mentionne webman, workman, PHP de type PHP, PHP de type PHP ou PHP de longue durée/en mémoire.
