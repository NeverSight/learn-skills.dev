Utilisez le CLI cjules pour piloter l’API Jules — créez, listez, surveillez, inspectez, envoyez des messages, approuvez, consignez et modifiez les sessions ; gérez les sources ; changez de compte de clé API enregistré. Invoquez‑le lorsque l’utilisateur mentionne Jules, les URL de session jules.google.com, les sessions/sources Jules, ou exécute `cjules …`. Veuillez toujours répondre dans la langue de l’utilisateur.
