Utiliza la CLI cjules para manejar la API de Jules — crear, listar, observar, inspeccionar, enviar mensajes, aprobar, registrar y parchear sesiones; gestionar fuentes; cambiar entre cuentas con claves API guardadas. Invoca cuando el usuario mencione a Jules, URLs de sesiones de jules.google.com, sesiones/fuentes de Jules, o ejecute `cjules ...`.

Por favor, responde siempre en el idioma del usuario.
