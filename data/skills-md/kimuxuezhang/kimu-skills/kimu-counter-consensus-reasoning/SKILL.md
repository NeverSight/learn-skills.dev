# Kimu 反共识推理

英文技术名：`kimu-counter-consensus-reasoning`（Kimu Counter-Consensus Reasoning）。

## 任务目标

给定一篇文稿、观点、提纲或选题，完成四件事：

1. 识别原文依赖或重复的“大众错误共识”。
2. 解释这些共识为何容易形成、流行并被默认接受。
3. 逐条检查其中的事实、逻辑、因果、概念与成立边界问题。
4. 建立比原说法更准确、可论证且有传播力的“正确非共识”；用户要求时，再据此改写文稿。

“正确非共识”不是故意反对大众，也不是把 A 粗暴改成反 A，而是把被传播成绝对句的观点补回变量、条件、证据、边界和因果链，形成更高分辨率的认知。

## 适用场景

- 拆解短视频、公众号、社交媒体、课程、演讲、直播或销售文稿中的流行观点。
- 判断一句“大家都这么说”的话到底错在哪里、在哪些条件下才成立。
- 把陈词滥调、伪常识、单因果解释或平台黑箱猜测改造成新选题。
- 为观点型内容生成“原共识—问题—正确非共识—传播金句”。
- 在保留作者立场、语气和传播张力的前提下重写全文。

以下情况不必强行启动完整流程：文本没有明确观点；用户只要求纠错、摘要或普通润色；原文观点经过检查并不存在值得拆解的错误共识。遇到最后一种情况，应直接说明“未发现足够成立的错误共识”，不要为了交付数量而制造反对意见。

## 核心原则

1. **准确优先于反直觉。** 先判断原说法是否真的有问题，再考虑传播表达。
2. **增加分辨率，不做机械反转。** 新观点必须增加条件、变量、边界或更完整的因果，而不是把结论反过来说。
3. **区分事实、推断、价值判断和行动建议。** 四者证据要求不同，不能混写成同一种“真相”。
4. **批评命题，不贬低人群。** 不把“大众”描写成愚蠢、盲从或低认知群体。
5. **证据强度匹配表达强度。** 证据不足时降低断言强度，并明确未知处。
6. **保留有效观点和作者风格。** 只修正不准确之处，不把有张力的内容改成论文。
7. **先分析，后改写。** 未完成命题拆解和证据判断前，不急着输出成稿。

## 传播学理论框架

只调用能解释本稿现象的理论。理论是诊断工具，不是必须全部出现的固定章节；能用一句话说清就不要展开人物介绍。

### 卢曼：被筛选的信息环境

人并非直接接触全部现实，而是通过媒体、平台、组织和社群筛选后的信息认识现实。反复可见的内容不一定更真实，只可能更符合传播系统的选择机制。

适合解释：样本偏差、平台可见性偏差、把“经常刷到”误认成“普遍存在”、被单一叙事塑造的问题框架。

### 詹姆斯·凯瑞：传播的仪式观

传播不只是传递信息，也通过反复讲述、转发和共同使用某套语言来维持群体身份与共同信念。一个说法被频繁复述，可能是在确认“我们这群人怎么看”，而非验证事实。

适合解释：行业黑话、群体口号、身份叙事、反复转发后被当成常识的观点。

### 诺依曼：沉默的螺旋

当人们感到某种意见占优势时，持异议者更可能沉默，表面上的多数意见因此显得更强，进一步压低不同声音的可见度。

适合解释：表面一致、异议缺席、争议话题中的自我审查，以及“没人反对，所以一定正确”的错觉。

### 使用限制

- 不得每篇机械套用卢曼、凯瑞、诺依曼三套理论。
- 不得用理论名称代替对原文的具体分析。
- 若认知偏差、商业激励、样本结构或平台机制更能解释问题，可直接使用更贴切的机制；不要为了显得专业而硬贴标签。
- 理论只能解释“共识为何形成”，不能自动证明该共识为假。

## 错误共识识别信号

看到以下信号时，提取为待检命题，而不是立即判错：

- 使用“所有、一定、根本、从来、只要、都、唯一、必然”等绝对词。
- 主语过大，如“人性、年轻人、家长、女性、老板、平台、普通人”却无样本边界。
- 用一个原因解释复杂结果，或把结果反推成原因。
- 把相关性、先后顺序或同时发生写成因果。
- 用个案、个人经历、热搜样本或幸存者故事代表普遍规律。
- 用隐喻、情绪强度、道德评价或身份立场代替论证。
- 把连续谱写成非黑即白的二选一。
- 使用无来源的精确数字、名人名言、研究结论或历史故事。
- 把推荐系统、审核、流量、用户心理等黑箱讲成确定机制。
- 一个观点听起来正确，但缺少时间、对象、场景、前提或例外条件。
- 流行表达非常顺口，却无法回答“对谁、在什么情况下、通过什么机制成立”。

## 固定执行流程

### 第一步：确认任务范围

识别用户要的是：只分析、分析并生成非共识、局部改写，还是完整重写。若用户未说明，默认完成分析与非共识生成，不自动重写全文。

### 第二步：提取可检验命题

把原文中的隐含前提和显性结论改写成清楚、可判断的句子。优先提取影响全文结论的 3—6 条；实际不足时如实减少，不凑数。

每条需回答：谁或什么、在何种条件下、发生什么、原文声称原因是什么。

### 第三步：判断它是否属于“大众共识”

区分三类情况：

- **真实流行共识：** 在大众、行业或特定群体中有明显重复传播。
- **原文自设靶子：** 原文声称“大家都认为”，但没有足够迹象证明它普遍存在。
- **普通错误命题：** 观点有问题，但并非大众共识。

不要把所有错误都包装成“大众共识”。证据不足时写成“常见说法”或“原文预设”，不要伪造普遍性。

### 第四步：解释形成机制

只选择与该命题最相关的 1—2 个传播或认知机制，说明它为什么容易被看见、被重复、被相信或让异议消失。必要时使用卢曼、凯瑞或诺依曼；无必要则用普通语言解释。

### 第五步：事实核查与逻辑诊断

先标注命题是已验证、部分可验证、待核查、纯推断还是价值判断，再使用错误类型标签定位问题。若结论依赖外部事实，遵守“事实核查与外部信息规则”。

### 第六步：建立正确非共识

保留原观点中成立的部分，补入缺失变量、条件、边界和因果链。输出：

- 原大众说法或原文预设。
- 它具体哪里不准确。
- 更准确的完整判断。
- 一句可独立传播的非共识金句。

### 第七步：筛选与改写

从全部结果中选出最有价值的 3—5 条，优先保留同时具备“差异度、证据性、解释力、可传播性”的观点。只有用户要求时才重写全文；重写必须遵守本 Skill 的文案规则。

## 错误类型标签

每个问题可标 1—3 个主要标签，避免堆标签：

- `[事实错误]`：与可靠事实直接冲突。
- `[来源不足]`：结论可能成立，但当前无足够来源支持。
- `[无来源精确数字]`：精确数字、比例或时间缺少可追溯出处。
- `[概念偷换]`：论证中悄悄改变关键词含义。
- `[范围过度概括]`：从局部样本推到过大人群、时期或场景。
- `[缺少成立条件]`：观点在部分条件下正确，却被写成普遍规律。
- `[二元化]`：把连续、复杂问题压成非此即彼。
- `[单因果]`：用单一原因解释多变量结果。
- `[因果倒置]`：把结果当原因，或把双向关系写成单向关系。
- `[相关当因果]`：只凭同时出现或统计相关就下因果结论。
- `[样本偏差]`：样本来源、规模或可见性不能代表总体。
- `[幸存者偏差]`：只看留下、成功或被看见的案例。
- `[个案冒充规律]`：用单个故事或个人经验证明普遍命题。
- `[隐喻代替论证]`：修辞形象，但没有完成推理。
- `[价值判断伪装事实]`：把偏好、立场或道德评价写成客观规律。
- `[黑箱确定化]`：把无法确认的平台、算法、审核或心理机制说成确定事实。
- `[时代或语境错位]`：把特定时期、文化或制度下的结论直接外推。
- `[正确但不完整]`：核心方向成立，但遗漏关键变量、例外或作用路径。

## 正确非共识生成标准

一条合格的“正确非共识”必须同时满足：

1. **有差异：** 能修正一个真实存在的常见说法，而非凭空树敌。
2. **可论证：** 能说明证据、机制或推理链，不是情绪化反转。
3. **更精确：** 至少增加一个重要条件、变量、边界或因果环节。
4. **不过度：** 不用新的绝对句替换旧的绝对句。
5. **有用：** 能改变读者的判断方式、行动选择或问题框架。
6. **可传播：** 金句简洁、独立可懂、有张力，但不牺牲准确性。

优先从这些方向寻找非共识：被忽略的前提；常被混淆的两个概念；真正起作用的中间变量；相反案例成立的条件；短期与长期差异；个体与系统差异；可见样本与总体差异；相关与因果差异。

## 事实核查与外部信息规则

- 对具体数字、法律政策、平台规则、科学结论、研究、历史事件、名人引语和现实案例，先判断是否影响核心结论；影响时应核查。
- 来源优先级：原始文件、官方数据、法律或平台原文、论文及权威数据库；其次是可靠专业机构和高质量媒体；社交帖子只能作为线索，不能单独支撑强结论。
- 优先追溯原始出处，不引用“某研究表明”“有数据显示”这类不可验证表述。
- 至少区分：`已核实`、`部分核实`、`待核实`、`存在争议`、`无法确认`。不要把合理推断写成已证实事实。
- 外部来源互相冲突时，说明冲突点、时间和口径差异，不强行合并成唯一答案。
- 无法访问外部信息时，不编造来源、链接、研究、数字或引语；明确列出待核查项，并给出不依赖该事实也能成立的谨慎版本。
- 对平台推荐、限流、审核等黑箱机制，除非有公开规则或可复核证据，否则只能描述可观察现象与可能解释。
- 不为增加“权威感”塞入与论证无关的理论、人名和数据。

## 改写规则

### 场景先行，禁止万能递进句

避免“很多人……到最后……”“一开始……后来才发现……”“你以为……其实……”“真正的……不是……而是……”等可套在任何主题上的万能句式。它们通常只有逻辑姿态，没有人物、动作和画面。

改写时优先使用：

- 一个具体的人正在做的动作。
- 一段符合真实语境的人物语言。
- 可感知的时间、地点、物件、数字或操作细节。
- 一个读者能认出自己的典型场景。

再从场景落到判断。检查动作是：看到“很多人、最后、其实、真正、到头来”等词时，问“这里能否换成一个具体的人正在做的一件事？”能换则优先换。

### 其他改写要求

- 保留作者原有立场、口语节奏、情绪力度和有效金句。
- 修正逻辑，不把全文改成学院式说明文；严谨与传播力同时保留。
- 每段只推进一个关键判断，明确观点之间的因果或转折关系。
- 不编造作者亲历、用户案例、人物身份、对话、数据或结果。
- 原文没有可用场景时，可写明确标注为“示意”的典型场景，或使用不声称真实来源的中性场景；不得伪装成真实案例。
- 不用密集反问、排比、空泛大词或公式化转折制造虚假力量感。
- 原文成立的部分直接保留，不为体现改写幅度而全部推翻。

## 默认输出格式

### 1. 核心大众共识

列出 3—6 条可检验命题；不足则按实际数量输出。注明它是“真实流行共识”“原文自设靶子”还是“普通错误命题”。

### 2. 为什么容易被相信

只解释与本稿相关的传播、认知、利益或样本机制。理论有帮助才引用，并用普通语言说清。

### 3. 逐条拆解

每条使用以下结构：

**原文观点／隐含前提**  
**问题标签**  
**具体问题**  
**证据状态或待核查项**  
**更准确的判断**  
**正确非共识金句**

### 4. 最值得保留的正确非共识

筛出最强的 3—5 条，说明它适合用作选题、标题、开场、正文论点还是结尾。实际不足时不凑数。

### 5. 完整改写稿

仅在用户明确要求改写全文时输出。若只要求诊断，到第 4 部分结束。

### 6. 核查说明

只有在使用外部事实、仍有争议或存在待核查项时增加，列出来源、日期、证据等级和不确定性。

## 禁止事项

- 禁止为了“非共识”故意唱反调、强行反转或制造争议。
- 禁止把少数人的看法伪装成“大众都这么认为”。
- 禁止只给“太绝对、太片面”这类空泛评价而不指出缺失变量。
- 禁止用理论名词、名人背书或金句代替证据和推理。
- 禁止虚构事实、研究、案例、人物对话、平台机制和引用链接。
- 禁止把价值分歧直接判成事实错误。
- 禁止把用户有意保留的强观点全部磨平成中性废话。
- 禁止机械套用固定数量、三套传播理论或同一种句式。
- 禁止在未被要求时自动输出冗长全文改写。
- 禁止使用“很多人 XXX，到最后 XXX”等万能递进句制造代入感。

- [ ] 区分了真实流行共识、原文自设靶子与普通错误命题吗？
- [ ] 理论是否真的解释了形成机制，而非机械套用？
- [ ] 事实、推断、价值判断和行动建议是否分开？
- [ ] 每个批评是否指出具体缺失的变量、条件、边界或因果环节？
- [ ] 关键数字、引语、政策、案例和平台机制是否核查或标注不确定？
- [ ] 是否避免把 A 简单改成反 A？
- [ ] 新观点是否比原观点更精确，同时仍然可传播？
- [ ] 金句是否能独立理解，且没有制造新的绝对化？
- [ ] 是否保留了原文中成立的部分和作者风格？
- [ ] 改写是否用具体场景、动作、人物语言或可感知细节建立代入感？
- [ ] 是否清除了“很多人 XXX，到最后 XXX”等万能递进句？
- [ ] 是否没有虚构案例、数据、出处或作者亲历？
- [ ] 输出数量是否服从实际分析，而不是为了格式凑数？

## 简短示例

**原文：**

> 做自媒体没流量，基本都是平台限流。

**共识类型：** 常见行业说法；是否构成平台层面的真实机制需要具体证据。

**形成机制：** “限流”给复杂结果提供了一个简单、统一、容易在同行之间重复的解释。凯瑞的仪式观可以解释这种行业语言如何在反复交流中变成共同信念；但重复本身不能证明它是真的。

**问题标签：** `[单因果]` `[黑箱确定化]` `[缺少成立条件]`

**具体问题：** 低播放量是结果，不能单凭结果确认平台采取了限制措施。选题、首屏点击、前几秒留存、互动、样本量、账号历史和分发异常等变量需要分开判断。

**更准确的判断：** 平台限制可能是低流量的一种解释，但只有在规则提示、分发数据异常或可复核对照等证据出现时，才应提高其可信度；单条内容播放量低，首先只能说明结果不佳。

**正确非共识金句：**

> 低流量是结果，不是“被限流”的证据。
