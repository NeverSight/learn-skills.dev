# Kimu 圆桌会议

把一个问题变成有结构的圆桌讨论。目标不是制造热闹，也不是用名人数量制造权威感，而是让真正相关、能够追溯的思想视角暴露假设、冲突和选择代价。

用户可以输入：

```text
Kimu 圆桌会议：{话题}
Kimu 圆桌会议：请用{人物或流派}讨论{话题}
Kimu 圆桌会议：请推荐合适的专家讨论{问题}
```

## 建立圆桌

先确认本轮真正要判断的问题。话题过大时，将它收窄成一个能产生分歧的问句；已有明确问句时不重复追问。

先把问题拆成需要哪些判断变量，再选择能分别处理这些变量的人。不得先按行业标签或名气列出人物，再为他们寻找发言位置。

只有问题的核心确实是学习规律、教学方法、课程结构、评价或师生关系时，才读取 [历史教育家选席表](references/historical-educators.md)。课程定价、获客、组织扩张等商业问题不因发生在教培行业就默认选择教育家。

### 用户指定人物

用户给出完整人物名单时，保留用户选择并直接开始第一轮。若某位人物与问题缺少可验证的思想关联，简短说明局限，但不擅自换人；只能从其公开、可核验的思想或实践出发。

用户只给出部分人选或明确要求补充名单时，为空缺席位推荐候选，推荐完成后等待用户确认。

### 用户未指定人物

提出 3–5 位能够形成互补或冲突的候选。先选择适合问题的理论、方法或实践框架，再选择有可靠材料能够代表该框架的人物。已故与在世不设人数比例，也不把历史地位或当代流量当作质量证明。

候选可以来自商业、经济、管理、心理、传播、技术、教育、哲学或其他真正相关的领域。选择依据是他们分别处理不同变量，例如：

- 激励与制度；
- 认知偏差与行为；
- 资源配置与机会成本；
- 组织执行与反馈；
- 伦理、长期影响或利益相关者。

主动推荐的候选必须满足：

- 有清楚、可追溯的核心命题、方法或实践记录；
- 能处理当前问题中的一个独立变量；
- 与其他席位存在真实分工或分歧；
- 不只依赖名气、表达风格或个人成功故事成立。

每个候选只说明：他代表什么框架、负责判断什么、可能质疑谁。若用户说「直接开始」或明确授权系统选人，选择差异最大的三个视角并继续；否则展示名单后等待用户确认或调整，不提前生成讨论。

平台规则、市场数据、法律政策、AI 能力等时效性事实由“当代证据席位”核查，不让历史人物虚构对当前事件的看法。

## 角色真实性

- 人物角色只代表其公开、可核验的理论或著作，不声称是真人本人。
- 不编造引语、私生活、未公开意见或对当前事件的“本人表态”。
- 无法确认的观点写成分析者推断，不使用引号伪装成原话。
- 当代人物可以进入讨论，但要避免把传播风格、个人声量或单次成功当成完整理论。
- 历史人物没有讨论过线上课、短视频、AI 或当前平台时，只能从其已知思想推导可能关注的原则，并明确这是迁移分析。
- 历史地位不能代替论证。主持人要指出理论产生的时代条件，以及哪些部分可能不适用于今天。

## 讨论结构

每轮围绕同一个焦点完成三段：

1. **立场**：每个角色给出判断、依据和一个最担心的变量。
2. **交叉质询**：每个角色挑选一条其他观点，指出它忽略的条件或证据。
3. **主持人收束**：把分歧改写成用户可验证的选择条件。

角色发言应彼此独立，避免所有人只是换一种语气表达同一答案。若宿主支持独立工作单元或并行 Agent，可让每个角色分别分析后再汇总；若不支持，则在同一模型中分段生成，并明确这是模拟圆桌。

## 输出格式

```markdown
## 本轮焦点
{一个可判断的问题}

### {视角一}
判断：...
依据：...
质询：...

### {视角二}
...

## 主持人结论
- 已形成的共识：...
- 真正的分歧：...
- 分歧取决于哪些事实：...
- 用户现在可采取的验证或选择：...

## 行动落点（需要时）
- 哪个分歧会改变用户的选择：...
- 现在可验证的条件：...
- 仍需补充的事实：...

状态：圆桌继续
```

不必机械展示空栏目；内容简单时可以压缩，但必须保留真实分歧和主持人结论。

## 继续与结束

圆桌开始后，普通后续问题沿用本轮角色和已形成的结论。新一轮只回应用户新增的反驳、证据或条件，不重新介绍所有人物。

以下表达结束圆桌：

- 「结束圆桌会议」
- 「退出圆桌」
- 「结束聊天室」
- 「Kimu：返回工具箱」

用户要求更换角色时，保留讨论记录，只替换指定席位并说明新视角补足了什么。

## 质量检查

交付前确认：

- 每个角色处理的变量确实不同；
- 主动推荐的人物有可追溯框架，且不是名人拼盘；
- 教育类话题若使用历史教育家，人物选择能在选席表或可靠材料中找到依据；
- 至少存在一处有意义的相互质询；
- 事实、解释和价值判断没有混成一件事；
- 历史理论、迁移推断和当代事实已经分开；
- 主持人没有用折中话术掩盖关键冲突；
- 建议包含判断条件，而不只是泛泛行动口号。

完成一轮后停止，等待用户继续、换人或结束。
