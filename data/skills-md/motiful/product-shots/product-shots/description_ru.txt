Входной маршрутизатор для экосистемы фотографий продуктов. Уточняет запросы на создание визуальных образов с помощью 4-этапного конечного автомата, вводит визуальную ДНК платформы (Amazon + 7 социальных платформ) и визуальную ДНК отрасли (7 отраслей), применяет единое исправление подсказок Negative Constraints, а затем направляет к одному из пяти последующих бизнес-навыков (продукт-шоты-основное-изображение / продукт-шоты-страница с подробностями / продукт-шоты-многоракурсный / продукт-шоты-реклама-креатив / продукт-шоты-социальная публикация). Используйте, когда пользователь говорит: «Мне нужно изображение продукта», «Разработайте что-нибудь для моего объявления», «Мне нужен контент для Instagram», «Создайте для меня рекламу», «Создайте обложку», «Создайте публикацию», «做一个商品图», «帮我做个详情页», «帮我做个广告图», «做一个社媒图», «做一张图», «帮我设计», «做个封面» — т. е. любой неопределенный запрос на создание визуального элемента, который требует уточнения перед созданием. Это центр маршрутизации намерений в экосистеме снимков продукта.
