Motor unificado de generación de imágenes para el ecosistema de fotografías de productos. Se envía a la familia de modelos correcta (OpenAI gpt-image-2 / Gemini gemini-3-pro-image-preview Nano Banana Pro) con un script parametrizado para texto a imagen e imagen a imagen. Backend principal: puerta de enlace OmniMaaS / Cloubic (https://api.omnimaas.com/v1); también admite cualquier puerta de enlace compatible con OpenAI-SDK a través de variables de entorno alternativas. Cambia automáticamente el tamaño de las imágenes de referencia de gran tamaño para evitar tiempos de espera de proxy de borde. Úselo cuando el usuario dice "generar una imagen", "hacer una imagen", "crear una imagen", "renderizar esto", "editar esta imagen", "做一张图", "生成图片", "改这张图", o cuando otra habilidad de tomas de producto lo invoca como backend de generación de imágenes (imagen principal/página de detalles/creativo publicitario/publicación social/ángulo múltiple). NO es una habilidad de dirección creativa: toma un mensaje + imágenes de referencia opcionales, devuelve una ruta de archivo.
