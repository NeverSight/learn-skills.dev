Moteur de génération d’images unifié pour l’écosystème de photos de produits. Envoyé à la bonne famille de modèles (OpenAI gpt-image-2 / Gemini gemini-3-pro-image-preview Nano Banana Pro) avec un script paramétré pour le texte à l'image et l'image à l'image. Backend principal : passerelle OmniMaaS / Cloubic (https://api.omnimaas.com/v1) ; prend également en charge toute passerelle compatible OpenAI-SDK via des variables d'environnement de secours. Redimensionne automatiquement les images de référence surdimensionnées pour éviter les délais d'attente du proxy de bord. À utiliser lorsque l'utilisateur dit « générer une image », « créer une image », « créer un visuel », « rendre ceci », « modifier cette image », « 做一张图 », « 生成图片 », « 改这张图 » — ou lorsqu'il est invoqué comme backend de génération d'image par une autre compétence de photos de produits (image principale / page de détail / création publicitaire / publication sociale / multi-angle). PAS une compétence de direction créative : prend une invite + des images de référence facultatives, renvoie un chemin de fichier.
