Motore di generazione di immagini unificato per l'ecosistema degli scatti dei prodotti. Invia alla famiglia di modelli giusta (OpenAI gpt-image-2 / Gemini gemini-3-pro-image-preview Nano Banana Pro) con uno script parametrizzato per text-to-image e image-to-image. Backend primario: OmniMaaS / Cloubic gateway (https://api.omnimaas.com/v1); supporta anche qualsiasi gateway compatibile con OpenAI-SDK tramite fallback env vars. Ridimensiona automaticamente le immagini di riferimento sovradimensionate per evitare timeout del proxy edge. Da utilizzare quando l'utente dice "genera un'immagine", "crea un'immagine", "crea un'immagine", "esegui il rendering", "modifica questa immagine", "做一张图", "生成图片", "改这张图" — o quando viene richiamato come backend di generazione di immagini da un'altra abilità di scatti del prodotto (immagine principale/pagina di dettaglio/creatività pubblicitaria/post social/ multiangolo). NON è una capacità di direzione creativa: accetta un prompt + immagini di riferimento opzionali, restituisce un percorso di file.
