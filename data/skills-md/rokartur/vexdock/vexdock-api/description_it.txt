Operare un server Vexdock (piattaforma di distribuzione auto‑ospitata) tramite la sua API REST con un token Bearer. Usare quando viene richiesto di distribuire, ispezionare, riavviare, eseguire un comando, configurare o ripulire qualsiasi cosa su un host Vexdock, o quando VEXDOCK_URL e VEXDOCK_TOKEN sono impostati nell’ambiente. Per favore rispondi sempre nella lingua dell'utente.
