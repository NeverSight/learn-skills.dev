Operar un servidor Vexdock (plataforma de despliegue autoalojada) a través de su API REST con un token Bearer. Úsalo cuando se solicite desplegar, inspeccionar, reiniciar, ejecutar un comando en, configurar o limpiar cualquier cosa en un host Vexdock, o cuando VEXDOCK_URL y VEXDOCK_TOKEN estén configurados en el entorno.
