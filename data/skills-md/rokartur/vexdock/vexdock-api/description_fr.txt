Exploitez un serveur Vexdock (plateforme de déploiement auto‑hébergée) via son API REST avec un jeton Bearer. Utilisez‑le lorsqu’on vous demande de déployer, inspecter, redémarrer, exécuter une commande, configurer ou nettoyer quoi que ce soit sur un hôte Vexdock, ou lorsque VEXDOCK_URL et VEXDOCK_TOKEN sont définis dans l’environnement.

Veuillez toujours répondre dans la langue de l’utilisateur.
