Turn Profile Plus todos (MCP profile-plus) into a formatted Polinema internship log book (DOCX + PDF). Use whenever the user runs /pis-todo-to-tch, or asks to "buat log book", "bikin laporan magang", "generate log book", "cetak log book", "rekap todo jadi log book", "log book bulanan", or wants their Profile Plus todo/attendance data converted into the official LOG BOOK KEGIATAN document. With no period it defaults to the current work week (Mon-Fri); also supports month, month/week, and date-range periods, and outputs to a 'Laporan <Bulan>' folder in the current working directory. PDFs are converted from the DOCX via LibreOffice when available, with an fpdf2 fallback. The SETUP argument bootstraps an empty working folder (personal config, environment report).
