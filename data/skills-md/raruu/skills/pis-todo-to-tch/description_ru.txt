Преобразуйте задачи Profile Plus (MCP profile‑plus) в отформатированную практику Polinema (DOCX + PDF). Используйте при запуске пользователем команды /pis‑todo‑to‑tch или при запросе «buat log book», «bikin laporan magang», «generate log book», «cetak log book», «rekap todo jadi log book», «log book bulanan», а также когда пользователь хочет преобразовать свои данные о задачах/посещаемости Profile Plus в официальный документ LOG BOOK KEGIATAN. Если период не указан, по умолчанию используется текущая рабочая неделя (пн‑пт); поддерживаются также периоды по месяцам, неделям/месяцам и произвольному диапазону дат, результаты сохраняются в папку «Laporan <Месяц>» в текущем рабочем каталоге. PDF‑файлы создаются из DOCX с помощью LibreOffice при наличии, с альтернативой fpdf2. Параметр SETUP инициализирует пустую рабочую папку (личные настройки, отчёт о среде). 

Пожалуйста, всегда отвечайте на языке пользователя.
