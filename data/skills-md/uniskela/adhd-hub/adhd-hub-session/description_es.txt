Protocolo de continuidad de ADHD Progress Hub para un trabajo sustancial de codificación. Utilice el MCP adhd-hub del operador al iniciar/reanudar un trabajo de proyecto significativo, pausar un trabajo incompleto, finalizar una tarea rastreada o configurar un recordatorio. Utilice el buzón de Forge cuando Hub MCP no esté disponible para un agente remoto. No lo utilice para preguntas triviales, búsquedas de solo lectura o pequeñas ediciones.
