ADHS Progress Hub-Kontinuitätsprotokoll für umfangreiche Codierungsarbeiten. Verwenden Sie das adhd-hub MCP des Bedieners, wenn Sie sinnvolle Projektarbeiten starten/fortsetzen, unvollständige Arbeiten anhalten, eine nachverfolgte Aufgabe beenden oder eine Erinnerung einrichten. Verwenden Sie das Forge-Postfach, wenn Hub MCP für einen Remote-Agenten nicht verfügbar ist. Nicht für triviale Fragen, schreibgeschützte Suchvorgänge oder geringfügige Änderungen verwenden.
