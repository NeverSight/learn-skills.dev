بروتوكول استمرارية ADHD Progress Hub لأعمال الترميز الكبيرة. استخدم adhd-hub MCP الخاص بالمشغل عند بدء/استئناف عمل مشروع ذي معنى، أو إيقاف العمل غير المكتمل مؤقتًا، أو إنهاء مهمة متعقبة، أو إعداد تذكير. استخدم صندوق بريد التزوير عندما يكون Hub MCP غير متاح لوكيل بعيد. لا تستخدمه للأسئلة التافهة، أو عمليات البحث للقراءة فقط، أو التعديلات الصغيرة.
