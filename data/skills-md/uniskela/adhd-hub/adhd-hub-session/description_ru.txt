Протокол непрерывности ADHD Progress Hub для существенной работы по кодированию. Используйте MCP adhd-hub оператора при запуске или возобновлении значимой работы над проектом, приостановке незавершенной работы, завершении отслеживаемой задачи или установке напоминания. Используйте почтовый ящик forge, когда Hub MCP недоступен для удаленного агента. Не используйте для тривиальных вопросов, поиска только для чтения или небольших изменений.
