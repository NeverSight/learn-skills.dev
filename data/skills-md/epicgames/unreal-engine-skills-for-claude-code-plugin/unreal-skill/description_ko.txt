이 스킬은 Unreal Engine 에이전트 스킬을 생성, 편집 또는 검토할 때 사용합니다. Unreal Engine 에이전트 스킬은 unreal-mcp 서버에 등록된 명명된 명령어 번들이며, `.claude/skills/` 아래에 있는 Claude Code의 하니스 스킬과는 구별됩니다. 사용자가 인-에디터 에이전트가 로드할 스킬을 추가하거나 변경하려 할 때 트리거합니다. 구체적인 트리거 예시: “새 에이전트 스킬 만들기”, “X 워크플로를 위한 스킬 추가”, “이 스킬 편집/업데이트”, “내 스킬 검토”, “Python 스킬 클래스 만들기”, “스킬 UAsset 생성”, “Claude가 인식하도록 스킬 등록”; UE 플러그인의 `Skills/` 또는 `Python/skills/` 폴더 안에 `SKILL.md`를 작성하거나 편집하는 경우; 스킬 레지스트리에 등록된 Python 스킬 클래스를 정의하는 경우; `CreateSkill`, `ListSkills`, `GetSkills` MCP 도구를 호출하는 경우; 스킬 이름, 설명 또는 명령 본문을 설계하는 경우. 다음 경우에는 사용하지 마세요: 도구세트(authoring a toolset) 작성(도구세트 작성에는 create-toolset 사용), 런타임에 기존 스킬을 호출(실행 시에는 unreal-mcp 사용), `.claude/skills/` 또는 `~/.claude/skills/` 아래에 있는 하니스 레벨 Claude Code 스킬 편집, 또는 일반적인 ‘스킬’이라는 단어 사용.
