Utiliza esta habilidad al crear, editar o revisar una Habilidad de Agente de Unreal Engine, un conjunto nombrado de instrucciones registrado en el servidor unreal-mcp (diferente de las habilidades de arnés de Claude Code bajo `.claude/skills/`). Activa cuando el usuario quiere añadir o cambiar una habilidad que el agente dentro del editor cargará. Disparadores concretos: ‘crear una nueva Habilidad de Agente’, ‘añadir una habilidad para el flujo de trabajo X’, ‘editar/actualizar esta habilidad’, ‘revisar mi habilidad’, ‘crear una clase de habilidad en Python’, ‘crear un UAsset de habilidad’, ‘registrar una habilidad para que Claude la detecte’; escribir o editar un `SKILL.md` dentro de la carpeta `Skills/` o `Python/skills/` de un plugin de UE; definir una clase de habilidad en Python registrada en el registro de habilidades; llamar a las herramientas MCP `CreateSkill`, `ListSkills` o `GetSkills`; diseñar el nombre, la descripción o el cuerpo de instrucción de una habilidad. OMITIR para: crear un conjunto de herramientas (usa create-toolset), invocar una habilidad existente en tiempo de ejecución (usa unreal-mcp), editar habilidades a nivel de arnés de Claude Code bajo `.claude/skills/` o `~/.claude/skills/`, o usos genéricos de la palabra “skill”. 

Por favor, responde siempre en el idioma del usuario.
