在創建、編輯或審核 Unreal Engine 代理技能（註冊於 unreal-mcp 伺服器的具名指令集，與 `.claude/skills/` 下的 Claude Code harness 技能不同）時使用此技能。當使用者想要新增或變更編輯器內代理將載入的技能時觸發。具體觸發情境包括：「建立新 Agent Skill」、「為 X 工作流程新增技能」、「編輯/更新此技能」、「審核我的技能」、「製作 Python 技能類別」、「建立 skill UAsset」、「註冊技能以便 Claude 取得」；在 UE 外掛的 `Skills/` 或 `Python/skills/` 資料夾中編寫或編輯 `SKILL.md`；定義已向技能註冊表註冊的 Python 技能類別；呼叫 MCP 工具 `CreateSkill`、`ListSkills` 或 `GetSkills`；設計技能的名稱、說明或指令內容。**不適用**情況：編寫工具集（使用 create‑toolset）、在執行時呼叫已有技能（使用 unreal‑mcp）、編輯 `.claude/skills/` 或 `~/.claude/skills/` 下的 harness 級 Claude Code 技能，或僅泛指「skill」一詞的情況。请始终以使用者的語言回覆。
