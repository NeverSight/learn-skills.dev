Используйте этот навык при создании, редактировании или обзоре навыка агента Unreal Engine — именованного набора инструкций, зарегистрированных на сервере unreal-mcp (отличающегося от навыков harness Claude Code, находящихся в `.claude/skills/`). Срабатывает, когда пользователь хочет добавить или изменить навык, который загрузит агент в редакторе. Конкретные триггеры: «создать новый навык агента», «добавить навык для X рабочего процесса», «отредактировать/обновить этот навык», «просмотреть мой навык», «создать класс навыка на Python», «создать UAsset навыка», «зарегистрировать навык, чтобы Claude его нашёл»; написание или редактирование `SKILL.md` в папке `Skills/` или `Python/skills/` плагина UE; определение класса навыка на Python, зарегистрированного в реестре навыков; вызов инструментов MCP `CreateSkill`, `ListSkills` или `GetSkills`; разработка названия, описания или тела инструкции навыка. Пропускать (SKIP) для: разработки набора инструментов (используйте create-toolset), вызова существующего навыка во время выполнения (используйте unreal-mcp), редактирования навыков уровня harness Claude Code в `.claude/skills/` или `~/.claude/skills/`, или общих упоминаний слова «навык».  

Пожалуйста, всегда отвечайте на языке пользователя.
