Usa questa skill quando crei, modifichi o rivedi una Unreal Engine Agent Skill, un bundle nominato di istruzioni registrato sul server unreal-mcp (distinto dalle skill harness di Claude Code sotto `.claude/skills/`). Attivala quando l'utente vuole aggiungere o modificare una skill che l'agente in-editor caricherà. Trigger concreti: “crea una nuova Agent Skill”, “aggiungi una skill per il workflow X”, “modifica/aggiorna questa skill”, “rivedi la mia skill”, “crea una classe skill Python”, “crea un UAsset skill”, “registra una skill affinché Claude la rilevi”; scrivere o modificare un `SKILL.md` nella cartella `Skills/` o `Python/skills/` di un plugin UE; definire una classe skill Python registrata nel registro delle skill; chiamare gli strumenti MCP `CreateSkill`, `ListSkills` o `GetSkills`; progettare nome, descrizione o corpo delle istruzioni di una skill. SKIP per: authoring di un toolset (usa create-toolset), invocare una skill esistente a runtime (usa unreal-mcp), modificare skill a livello harness di Claude Code sotto `.claude/skills/` o `~/.claude/skills/`, o usi generici della parola “skill”.  
Rispondi sempre nella lingua dell'utente.
