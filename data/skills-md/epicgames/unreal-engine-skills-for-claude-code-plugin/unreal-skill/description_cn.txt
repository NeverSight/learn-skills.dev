在创建、编辑或审查 Unreal Engine 代理技能时使用此技能，它是注册在 unreal-mcp 服务器上的命名指令集合（不同于 `.claude/skills/` 下的 Claude Code 框架技能）。当用户想要添加或更改编辑器内代理将加载的技能时触发。具体触发词包括：“创建新 Agent Skill”“为 X 工作流添加技能”“编辑/更新此技能”“审查我的技能”“创建 Python 技能类”“创建技能 UAsset”“注册技能以便 Claude 能识别”；在 UE 插件的 `Skills/` 或 `Python/skills/` 文件夹中编写或编辑 `SKILL.md`；定义在技能注册表中注册的 Python 技能类；调用 `CreateSkill`、`ListSkills` 或 `GetSkills` MCP 工具；设计技能的名称、描述或指令正文。跳过以下情况：编写工具集（使用 create-toolset）、在运行时调用现有技能（使用 unreal-mcp）、编辑 `.claude/skills/` 或 `~/.claude/skills/` 下的 Claude Code 框架技能，或对 “skill” 一词的通用使用。
