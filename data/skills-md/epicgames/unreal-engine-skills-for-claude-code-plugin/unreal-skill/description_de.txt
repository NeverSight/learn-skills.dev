Verwende diese Fähigkeit, wenn du eine Unreal Engine Agent Skill erstellst, bearbeitest oder überprüfst, ein benanntes Bündel von Anweisungen, das beim unreal‑mcp‑Server registriert ist (unterscheidet sich von den Harness‑Skills von Claude Code unter `.claude/skills/`). Auslösen, wenn der Benutzer eine Skill hinzufügen oder ändern möchte, die der In‑Editor‑Agent laden wird. Konkrete Auslöser: „eine neue Agent Skill erstellen“, „eine Skill für X‑Workflow hinzufügen“, „diese Skill bearbeiten/aktualisieren“, „meine Skill überprüfen“, „eine Python‑Skill‑Klasse erstellen“, „ein Skill‑UAsset erstellen“, „eine Skill registrieren, damit Claude sie übernimmt“; Schreiben oder Bearbeiten einer `SKILL.md` im `Skills/`‑ oder `Python/skills/`‑Ordner eines UE‑Plugins; Definieren einer Python‑Skill‑Klasse, die im Skill‑Register registriert ist; Aufrufen der MCP‑Tools `CreateSkill`, `ListSkills` oder `GetSkills`; Gestalten des Namens, der Beschreibung oder des Anweisungs‑Körpers einer Skill. Überspringen für: Erstellen eines Toolsets (verwende create‑toolset), Aufrufen einer bestehenden Skill zur Laufzeit (verwende unreal‑mcp), Bearbeiten von Harness‑Level‑Claude‑Code‑Skills unter `.claude/skills/` oder `~/.claude/skills/` oder generische Verwendungen des Wortes „skill“.

Bitte immer in der Sprache des Benutzers antworten.
