Utilisez cette compétence lors de la création, de la modification ou de la révision d’une Unreal Engine Agent Skill, un ensemble nommé d’instructions enregistré auprès du serveur unreal‑mcp (distinct des compétences harness de Claude Code situées sous `.claude/skills/`). Déclenchez‑la lorsque l’utilisateur veut ajouter ou modifier une compétence que l’agent intégré à l’éditeur chargera. Déclencheurs concrets : « créer une nouvelle Agent Skill », « ajouter une compétence pour le workflow X », « éditer/mette à jour cette compétence », « réviser ma compétence », « créer une classe de compétence Python », « créer un UAsset de compétence », « enregistrer une compétence afin que Claude la prenne en compte » ; rédaction ou modification d’un fichier `SKILL.md` dans le dossier `Skills/` ou `Python/skills/` d’un plugin UE ; définition d’une classe de compétence Python enregistrée dans le registre des compétences ; appel des outils MCP `CreateSkill`, `ListSkills` ou `GetSkills` ; conception du nom, de la description ou du corps d’instructions d’une compétence. À IGNORER pour : l’auteur d’un jeu d’outils (utilisez create‑toolset), l’invocation d’une compétence existante à l’exécution (utilisez unreal‑mcp), la modification de compétences harness‑level de Claude Code sous `.claude/skills/` ou `~/.claude/skills/`, ou les usages génériques du mot « skill ». Veuillez toujours répondre dans la langue de l’utilisateur.
