Utilice esta habilidad al crear o ampliar un conjunto de herramientas de Unreal Engine, una clase de funciones estáticas invocables por IA registradas con `ToolsetRegistry` y expuestas a través del servidor unreal-mcp. Se activa cuando el usuario desea agregar, exponer o registrar un nuevo método de herramienta, crear un nuevo conjunto de herramientas o ampliar uno existente como `BlueprintTools`, `StaticMeshTools`, `ObjectTools`, `LevelTools` o `MaterialTools`. Desencadenantes concretos: 'agregar una herramienta a X', 'exponer esto a través de MCP', 'registrar una función para que Claude/el agente pueda llamarla', 'conectar esto al registro del conjunto de herramientas', 'crear un nuevo conjunto de herramientas para Y', 'agregar un conjunto de herramientas Python', 'hacer que esta IA sea invocable'; agregar un método `estático` a un archivo `*Tools.cpp/.h/.py`; editar archivos en una carpeta `Toolsets/`; diseñar parámetros de herramientas, tipos de retorno o esquemas de estructura para un conjunto de herramientas. SALTAR para: invocar herramientas existentes en tiempo de ejecución (use unreal-mcp en su lugar), crear una habilidad de agente (use unreal-skill), refactores genéricos que tocan un archivo de conjunto de herramientas pero no agregan ni rediseñan una herramienta, o usos no relacionados de la palabra 'conjunto de herramientas'.
