Utilisez cette compétence lors de la création ou de l'extension d'un ensemble d'outils Unreal Engine, une classe de fonctions statiques appelables par l'IA enregistrées auprès de « ToolsetRegistry » et exposées via le serveur unreal-mcp. Déclenchement lorsque l'utilisateur souhaite ajouter, exposer ou enregistrer une nouvelle méthode d'outil, créer un nouvel ensemble d'outils ou étendre un ensemble d'outils existant tel que `BlueprintTools`, `StaticMeshTools`, `ObjectTools`, `LevelTools` ou `MaterialTools`. Déclencheurs concrets : « ajouter un outil à X », « exposer ceci via MCP », « enregistrer une fonction pour que Claude/l'agent puisse l'appeler », « câbler ceci dans le registre de l'ensemble d'outils », « créer un nouvel ensemble d'outils pour Y », « ajouter un ensemble d'outils Python », « rendre cet outil appelable par l'IA » ; ajouter une méthode « statique » à un fichier « *Tools.cpp/.h/.py » ; éditer des fichiers dans un dossier `Toolsets/` ; concevoir des paramètres d'outil, des types de retour ou des schémas de structure pour un ensemble d'outils. SAUTER pour : l'appel d'outils existants au moment de l'exécution (utilisez plutôt unreal-mcp), la création d'une compétence d'agent (utilisez unreal-skill), les refactoristes génériques qui touchent un fichier d'ensemble d'outils mais n'ajoutent ou ne reconçoivent pas d'outil, ou des utilisations sans rapport du mot « ensemble d'outils ».
