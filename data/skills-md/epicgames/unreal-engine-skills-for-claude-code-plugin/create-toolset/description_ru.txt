Используйте этот навык при создании или расширении набора инструментов Unreal Engine — класса статических функций, вызываемых ИИ, зарегистрированных в ToolsetRegistry и предоставляемых через сервер Unreal-mcp. Запускается, когда пользователь хочет добавить, предоставить или зарегистрировать новый метод инструмента, создать новый набор инструментов или расширить существующий, например BlueprintTools, StaticMeshTools, ObjectTools, LevelTools или MaterialTools. Конкретные триггеры: «добавить инструмент в X», «открыть это через MCP», «зарегистрировать функцию, чтобы Клод/агент мог ее вызывать», «подключить это к реестру набора инструментов», «создать новый набор инструментов для Y», «добавить набор инструментов Python», «сделать это доступным для ИИ»; добавление `статического` метода в файл `*Tools.cpp/.h/.py`; редактирование файлов в папке «Toolsets/»; проектирование параметров инструментов, типов возвращаемых значений или структурных схем для набора инструментов. ПРОПУСТИТЕ: вызов существующих инструментов во время выполнения (вместо этого используйте unreal-mcp), создание навыков агента (используйте unreal-skill), общие рефакторинги, которые затрагивают файл набора инструментов, но не добавляют или не перепроектируют инструмент, а также несвязанное использование слова «набор инструментов».
