استخدم هذه المهارة عند تأليف أو توسيع مجموعة أدوات Unreal Engine، وهي فئة من الوظائف الثابتة القابلة للاستدعاء بواسطة الذكاء الاصطناعي والمسجلة في "ToolsetRegistry" والمعروضة من خلال خادم Unreal-mcp. يتم تشغيله عندما يريد المستخدم إضافة طريقة أداة جديدة أو كشفها أو تسجيلها، أو إنشاء مجموعة أدوات جديدة، أو توسيع مجموعة موجودة مثل `BlueprintTools` أو `StaticMeshTools` أو `ObjectTools` أو `LevelTools` أو `MaterialTools`. المشغلات الملموسة: "إضافة أداة إلى X"، و"كشف هذا عبر MCP"، و"تسجيل وظيفة حتى يتمكن كلود/الوكيل من الاتصال بها"، و"ربط هذا في سجل مجموعة الأدوات"، و"إنشاء مجموعة أدوات جديدة لـ Y"، و"إضافة مجموعة أدوات Python"، و"اجعل هذا الذكاء الاصطناعي قابلاً للاستدعاء"؛ إضافة طريقة "ثابتة" إلى ملف "*Tools.cpp/.h/.py"؛ وتحرير الملفات ضمن المجلد "Toolsets/"؛ تصميم معلمات الأداة أو أنواع الإرجاع أو مخططات البنية لمجموعة الأدوات. تخطي لـ: استدعاء الأدوات الموجودة في وقت التشغيل (استخدم unreal-mcp بدلاً من ذلك)، أو تأليف مهارة الوكيل (استخدم مهارة غير حقيقية)، أو عوامل إعادة البناء العامة التي تحدث للمس ملف مجموعة أدوات ولكن لا تضيف أداة أو تعيد تصميمها، أو الاستخدامات غير ذات الصلة لكلمة "مجموعة أدوات".
