このスキルは、「ToolsetRegistry」に登録され、unreal-mcp サーバーを通じて公開される静的 AI 呼び出し可能な関数のクラスである Unreal Engine ツールセットを作成または拡張するときに使用します。ユーザーが新しいツール メソッドを追加、公開、または登録したり、新しいツールセットを作成したり、「BlueprintTools」、「StaticMeshTools」、「ObjectTools」、「LevelTools」、または「MaterialTools」などの既存のツールセットを拡張したりする場合にトリガーします。具体的なトリガー: 「X にツールを追加」、「これを MCP 経由で公開」、「クロード/エージェントが呼び出せるように関数を登録」、「これをツールセット レジストリに接続」、「Y 用の新しいツールセットを作成」、「Python ツールセットを追加」、「これを AI 呼び出し可能にする」。 `static` メソッドを `*Tools.cpp/.h/.py` ファイルに追加します。 「Toolsets/」フォルダー内のファイルを編集します。ツールセットのツールパラメータ、戻り値の型、または構造体スキーマの設計。次の場合はスキップしてください: 実行時の既存のツールの呼び出し (代わりに unreal-mcp を使用)、エージェント スキルの作成 (unreal-skill を使用)、たまたまツールセット ファイルに触れるがツールの追加や再設計を行わない汎用リファクタリング、または「ツールセット」という単語の無関係な使用。
