Verwenden Sie diese Fähigkeit, wenn Sie ein Unreal Engine-Toolset erstellen oder erweitern, eine Klasse statischer, KI-aufrufbarer Funktionen, die bei „ToolsetRegistry“ registriert und über den Unreal-mcp-Server verfügbar gemacht werden. Wird ausgelöst, wenn der Benutzer eine neue Tool-Methode hinzufügen, verfügbar machen oder registrieren, ein neues Toolset erstellen oder ein vorhandenes erweitern möchte, z. B. „BlueprintTools“, „StaticMeshTools“, „ObjectTools“, „LevelTools“ oder „MaterialTools“. Konkrete Auslöser: „Fügen Sie ein Tool zu Hinzufügen einer „statischen“ Methode zu einer „*Tools.cpp/.h/.py“-Datei; Bearbeiten von Dateien in einem Ordner „Toolsets/“; Entwerfen von Werkzeugparametern, Rückgabetypen oder Strukturschemata für ein Toolset. ÜBERSPRINGEN für: Aufrufen vorhandener Tools zur Laufzeit (verwenden Sie stattdessen unreal-mcp), Erstellen eines Agenten-Skills (verwenden Sie unreal-skill), generische Refaktorierungen, die zufällig eine Toolset-Datei berühren, aber kein Tool hinzufügen oder neu entwerfen, oder nicht verwandte Verwendungen des Wortes „Toolset“.
