استخدم هذه المهارة لأداء إجراءات داخل مشروع Unreal Engine عبر اتصال MCP للمحرر الحي. يتم التحفيز عندما يرغب المستخدم في تغيير أو الاستعلام أو تشغيل شيء ما في مشروع Unreal Engine الخاص به، وليس لأسئلة مفاهيمية أو وثائقية. المحفزات الملموسة: إنشاء/نقل/تكرار/تحويل الممثلين في مستوى، فتح ملف `.uproject`، إضافة أشياء حول PlayerStart، إنشاء أو تعديل Blueprint/Widget/Material/Niagara/Control Rig/Sequencer/Behavior Tree/قُدرَة GAS، قراءة أو كتابة خصائص على الممثلين (مثل `bIsLocked` على `BP_DoorActor`)، إعادة تجميع Live Coding بعد تعديل C++ (`AActor`، `UMyComponent::Method`، `UPROPERTY`)، أو تعديل أصول Static/Skeletal Mesh. عاملها كسياق Unreal حتى بدون كلمة "Unreal": بادئات الأصول `BP_`، `WBP_`، `M_`، `MI_`، `NS_`، `CR_`، `SK_`، `SM_`، `ABP_`؛ أنواع/ماكرو C++ الخاصة بـ UE؛ `.uproject`؛ متصفح المحتوى؛ المستعرض (Outliner)؛ PlayerStart؛ "في لعبي" مع إشارات UE. تخطَّ الأسئلة المفاهيمية/الوثائقية الصافية، Unity، Godot، أو الاستخدامات غير المتعلقة بـ "blueprint"/"sequencer"/"widget".
