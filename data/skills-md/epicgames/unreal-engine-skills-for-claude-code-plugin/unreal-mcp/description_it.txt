Usa questa abilità per eseguire azioni all'interno di un progetto Unreal Engine tramite una connessione MCP live‑editor. Attiva quando l'utente vuole modificare, interrogare o eseguire qualcosa nel suo progetto Unreal Engine, non per domande concettuali o di documentazione. Trigger concreti: generare/spostare/duplicare/trasformare attori in un livello, aprire un `.uproject`, aggiungere elementi intorno a un PlayerStart, creare o modificare un Blueprint/Widget/Material/Niagara/Control Rig/Sequencer/Behavior Tree/abilità GAS, leggere o scrivere proprietà sugli attori (ad es. `bIsLocked` su `BP_DoorActor`), recompilare Live Coding dopo aver modificato C++ (`AActor`, `UMyComponent::Method`, `UPROPERTY`), o modificare asset Static/Skeletal Mesh. Considera il contesto Unreal anche senza la parola “Unreal”: prefissi degli asset `BP_`, `WBP_`, `M_`, `MI_`, `NS_`, `CR_`, `SK_`, `SM_`, `ABP_`; tipi/macros C++ UE; `.uproject`; Content Browser; Outliner; PlayerStart; “nel mio gioco” più segnali UE. Ignora per: domande puramente concettuali/documentazione, Unity, Godot o usi non correlati di “blueprint”/“sequencer”/“widget”.  

Rispondi sempre nella lingua dell'utente.
