Utilisez cette compétence pour effectuer des actions à l'intérieur d'un projet Unreal Engine via une connexion MCP de l'éditeur en direct. Activez‑la lorsque l'utilisateur veut changer, interroger ou exécuter quelque chose dans son projet Unreal Engine, pas pour des questions conceptuelles ou de documentation. Déclencheurs concrets : faire apparaître, déplacer, dupliquer ou transformer des acteurs dans un niveau, ouvrir un `.uproject`, ajouter des éléments autour d'un PlayerStart, créer ou modifier un Blueprint/Widget/Material/Niagara/Control Rig/Sequencer/Behavior Tree/aptitude GAS, lire ou écrire des propriétés sur des acteurs (par ex. `bIsLocked` sur `BP_DoorActor`), recompiler en Live Coding après avoir édité du C++ (`AActor`, `UMyComponent::Method`, `UPROPERTY`), ou modifier des actifs Static/Skeletal Mesh. Traitez comme un contexte Unreal même sans le mot « Unreal » : préfixes d’actifs `BP_`, `WBP_`, `M_`, `MI_`, `NS_`, `CR_`, `SK_`, `SM_`, `ABP_` ; types/macros C++ UE ; `.uproject` ; Content Browser ; Outliner ; PlayerStart ; « in my game » plus les signaux UE. Ignorer pour : questions purement conceptuelles/de documentation, Unity, Godot ou utilisations non liées de « blueprint », « sequencer » ou « widget ».
