Используйте этот навык для выполнения действий внутри проекта Unreal Engine через живое соединение MCP‑редактора. Активируйте, когда пользователь хочет изменить, запросить или запустить что‑то в своём проекте Unreal Engine, а не для концептуальных или документальных вопросов. Конкретные триггеры: создание/перемещение/дублирование/трансформирование актёров в уровне, открытие файла `.uproject`, добавление элементов вокруг PlayerStart, создание или редактирование Blueprint/Widget/Material/Niagara/Control Rig/Sequencer/Behavior Tree/GAS‑способности, чтение или запись свойств актёров (например, `bIsLocked` у `BP_DoorActor`), перекомпиляция Live Coding после правки C++ (`AActor`, `UMyComponent::Method`, `UPROPERTY`), либо изменение статических/скелетных мешей. Рассматривайте контекст как Unreal даже без слова «Unreal»: префиксы ассетов `BP_`, `WBP_`, `M_`, `MI_`, `NS_`, `CR_`, `SK_`, `SM_`, `ABP_`; типы/macros UE C++; `.uproject`; Content Browser; Outliner; PlayerStart; фразы типа «в моей игре» и другие сигналы UE. Пропускайте: чисто концептуальные/документальные вопросы, Unity, Godot или несвязанные использования слов «blueprint», «sequencer», «widget».
