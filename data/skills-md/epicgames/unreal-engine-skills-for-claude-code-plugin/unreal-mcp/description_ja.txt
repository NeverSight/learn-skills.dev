このスキルは、ライブエディタ MCP 接続を介して Unreal Engine プロジェクト内でアクションを実行するために使用します。ユーザーが Unreal Engine プロジェクト内で何かを変更、問い合わせ、実行したいときにトリガーし、概念的な質問やドキュメントに関する質問には使用しないでください。具体的なトリガー例: レベル内でアクターをスポーン／移動／複製／変形する、`.uproject` を開く、PlayerStart 周辺にものを追加する、Blueprint／Widget／Material／Niagara／Control Rig／Sequencer／Behavior Tree／GAS アビリティを作成または編集する、アクターのプロパティを読み書きする（例: `BP_DoorActor` の `bIsLocked`）、C++ を編集した後の Live Coding 再コンパイル（`AActor`、`UMyComponent::Method`、`UPROPERTY`）や Static／Skeletal Mesh アセットを変更する。`Unreal` という語がなくても Unreal コンテキストとして扱う: アセットプレフィックス `BP_`、`WBP_`、`M_`、`MI_`、`NS_`、`CR_`、`SK_`、`SM_`、`ABP_`、UE の C++ 型・マクロ、`.uproject`、Content Browser、Outliner、PlayerStart、"in my game" といった UE のシグナル。以下の場合はスキップしてください: 純粋な概念的／ドキュメントの質問、Unity、Godot、または「blueprint」「sequencer」「widget」の無関係な使用。
