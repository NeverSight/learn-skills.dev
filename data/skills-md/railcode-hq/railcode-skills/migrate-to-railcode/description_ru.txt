Перенести существующий проект, созданный для другого хостинга (Vercel, Node‑сервер, Docker‑контейнер, стек docker‑compose) на Railcode. Используется, когда у пользователя уже работает приложение и он хочет запустить его на Railcode, включая Next.js‑приложение или контейнеризованный бэкэнд на любом языке. Охватывает инвентаризацию зависимостей проекта, сопоставление каждой зависимости с примитивом Railcode, пере‑создание компонентов, для которых нет прямого эквивалента, другими способами, портирование, тестирование с railcode dev, сохранение или подключение существующей базы данных проекта (Postgres или любой другой) и место выполнения миграций схемы, развертывание рядом с оригиналом и указание того, что Railcode пока не может хостить. Не использовать для нового приложения из идеи или для переноса приложения Railcode v1 в apps v2 — оба случая относятся к create‑railcode‑app.
