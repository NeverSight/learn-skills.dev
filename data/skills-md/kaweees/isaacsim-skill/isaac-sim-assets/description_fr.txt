Configurez et dépannez l'accès aux actifs d'Isaac Sim via les profils de région d’actifs, les racines d’actifs personnalisées ou locales, les packs d’actifs téléchargeables, les manifestes de disponibilité et les API de stockage public. Utilisez cette fonctionnalité pour les actifs Isaac Sim manquants ou inaccessibles, le routage régional, les actifs hors ligne ou la priorité des racines d’actifs ; ne l’utilisez pas pour installer Isaac Sim.

Veuillez toujours répondre dans la langue de l’utilisateur.
