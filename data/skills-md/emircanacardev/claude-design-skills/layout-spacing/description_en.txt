Sets up layout and spacing foundations with a 4 or 8 point spacing scale, proximity-based grouping, alignment rules, a 12-column grid with gutters, container max-widths, vertical section rhythm and density modes, and decides when to use flexbox versus CSS grid. Use when asked to fix spacing, balance a layout or set up a grid, or when a screen looks cramped, too airy or misaligned. Not for breakpoint behavior; use responsive-design.
