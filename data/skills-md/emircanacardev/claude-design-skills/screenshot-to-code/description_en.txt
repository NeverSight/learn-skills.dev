Reproduces a user interface from a screenshot as semantic, responsive code by inventorying regions, estimating spacing on a 4 and 8 px grid, extracting colors and type into tokens, then comparing the result side by side and listing deviations. Use when asked to recreate this screen, convert a screenshot to HTML or React, or rebuild a UI from an image. Only for UIs the user owns or has rights to.
