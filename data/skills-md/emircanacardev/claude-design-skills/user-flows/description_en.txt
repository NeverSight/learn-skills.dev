Maps user flows from goal and entry points through the happy path, decision points, edge cases, error branches, and exits, then outputs a Mermaid flowchart, a screen inventory, a step count, and open questions. Use when asked to map a flow, diagram a user journey, plan the screens for a feature, or find steps to cut. Not for sitemaps and menu structure, which is navigation-ia, or first-run sequences, which is onboarding-flow.
