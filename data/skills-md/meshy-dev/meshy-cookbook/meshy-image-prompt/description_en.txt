Write the prompt and parameters for a Meshy Text to Image (or Image to Image) task whose output will feed Image to 3D, including A-pose and T-pose characters for rigging and the three-call rig-ready pipeline. Use this skill whenever the user wants a 3D model to start from a generated image, asks for a Meshy image prompt, a concept or reference image "for 3D", a character they can rig or animate, an A-pose or T-pose, a multi-view image set, or asks why an Image to 3D result invented a front, fused the arms or baked shadows into the texture. It covers the subject-first image formula (full object, front or three-quarter view, even lighting, plain background), when to use pose_mode versus pose words, remove_background, generate_multi_view and aspect_ratio, and the Image to 3D settings that produced a riggable mesh. Not for Text to 3D preview prompts (meshy-text-to-3d-prompt), texture or retexture prompts (meshy-texture-prompt), or Meshy Edit (meshy-edit-prompt); it writes prompts and parameters, it does not call the API.
