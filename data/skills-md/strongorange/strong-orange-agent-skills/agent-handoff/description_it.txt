Crea pacchetti di consegna focalizzati da thread a thread (spazio di lavoro, obiettivo, decisioni bloccate, file rilevanti, contesto duramente acquisito, accordo di lavoro, rischi, criteri di accettazione, passaggi di verifica e prompt di avvio per il thread successivo). Usali quando cambi compiti, passi dal backend al frontend, suddividi un lavoro grande in fasi o chiedi a un altro agente/thread di continuare l'implementazione senza perdita di contesto.

Per favore, rispondi sempre nella lingua dell'utente.
