Синхронизирует навыки агента между локальным рабочим источником (~/.agents/skills), папками среды выполнения агента и репозиториями публикаций команды/личными, а также проверяет личный репозиторий на наличие корпоративного контента. Использовать только когда пользователь явно просит зарегистрировать, синхронизировать, публиковать или отправлять навыки.
