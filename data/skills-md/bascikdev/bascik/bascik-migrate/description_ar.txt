قم بترحيل موقع ويب موجود إلى Bascik. استخدمه عند تحويل موقع مبني على React أو Next.js أو Vue أو Svelte أو SvelteKit أو Astro أو Eleventy أو Hugo أو WordPress أو موقع HTML بسيط إلى صفحات ومكونات Bascik؛ مع تحويل الخصائص (props)، الفتحات (slots)، الحالة (state)، التوجيه (routing)، القوالب (layouts)، جلب البيانات، مجموعات المحتوى، وحلقات القالب إلى ما يعادلها في Bascik؛ أو التعامل مع ملفات sitemap.xml و robots.txt الحالية أثناء عملية الترحيل.
