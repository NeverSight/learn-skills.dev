决定在 Bascik 网站中使用哪些 HTML、CSS 和 JavaScript 功能。在使用现代或不常见的功能（popover、dialog、invoker commands、anchor positioning、container queries、@layer、@scope、:has()、view transitions、nesting、light-dark()、浏览器中的 TypeScript、web components）之前先三思；当有人问“我可以使用 X 吗”、“Bascik 支持 X 吗”或“X 是 Baseline 吗”；当选择器、DOM 调用或 at-rule 在页面中有效但在组件中无效；或当 linter 报告 css-* 或 js-* 兼容性错误时。包含对 Bascik 兼容性矩阵的实时查询以及 Baseline 浏览器支持检查工具。
