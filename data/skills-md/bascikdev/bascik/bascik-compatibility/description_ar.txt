قرّر أي ميزات HTML وCSS وJavaScript تستخدمها في موقع Bascik. استخدم ذلك قبل اللجوء إلى ميزة حديثة أو غير عادية (popover، dialog، invoker commands، anchor positioning، container queries، @layer، @scope، :has()، view transitions، nesting، light‑dark()، TypeScript في المتصفح، web components)؛ عند السؤال «can I use X»، «does Bascik support X» أو «is X Baseline»؛ عندما يعمل selector أو استدعاء DOM أو at‑rule في صفحة ولكن ليس في مكوّن؛ أو عندما تُظهر أداة التحليل lint أخطاء توافق css‑* أو js‑*. يتضمن بحثًا مباشرًا في مصفوفة توافق Bascik ومدقق دعم المتصفحات Baseline.
