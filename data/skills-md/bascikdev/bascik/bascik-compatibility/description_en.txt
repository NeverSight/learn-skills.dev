Decide which HTML, CSS, and JavaScript features to use in a Bascik site. Use before reaching for a modern or unusual feature (popover, dialog, invoker commands, anchor positioning, container queries, @layer, @scope, :has(), view transitions, nesting, light-dark(), TypeScript in the browser, web components); when asking "can I use X", "does Bascik support X", or "is X Baseline"; when a selector, DOM call, or at-rule works in a page but not in a component; or when the linter reports css-* or js-* compatibility errors. Includes a live lookup of Bascik's compatibility matrix and a Baseline browser support checker.
