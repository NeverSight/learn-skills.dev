Configure, build, and deploy Bascik sites. Use when deciding whether a bascik.config.ts is needed, editing one (directory, components.external, scoping, minify, assets, generate, pipeline.exec, pipeline.watchPaths, scripts, http, base), setting BASCIK_SITE_URL, deploying to a static host, running bascik --server in production, building a Cloudflare or Netlify bundle with --target, placing static assets, 404, and 500 pages, or structuring a monorepo with several sites, shared components, workspaces, and CI. Includes an audit script that flags redundant or invalid config and a workspace checker for multi-site repositories.
