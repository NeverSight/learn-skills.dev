在 Bascik 頁面和組件中使用 Node.js 腳本。編寫時可使用 <script data-bascik-build>（在建構階段從檔案、Markdown、JSON 或 API 產生 HTML）、<script data-bascik-build-once>（所有使用者共享相同的 HTML）、<script data-bascik-routes> 搭配 [slug].html 動態路由、<script data-bascik-server> 或 <script data-bascik-stream> 進行每次請求的渲染、提前繪製的頁腳或 CSS 來源順序串流佈局、src/api/ 中的 API 路由、@/ 匯入別名、BASCIK_* 環境變數、建構腳本快取、對不可信輸出進行轉義，或用於部落格及其他包含前置資料、標籤、草稿與摘要的 Markdown 集合。內含 new-post 腳本。
