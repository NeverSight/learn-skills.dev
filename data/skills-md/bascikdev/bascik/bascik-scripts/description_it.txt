Script Node.js all'interno delle pagine e dei componenti Bascik. Usa quando scrivi <script data-bascik-build> (HTML generato al momento della compilazione da file, Markdown, JSON o API), <script data-bascik-build-once> (HTML identico condiviso da ogni utilizzo), <script data-bascik-routes> con rotte dinamiche [slug].html, <script data-bascik-server> o <script data-bascik-stream> per il rendering per richiesta, footer early-paint o layout di streaming in ordine di sorgente CSS, rotte API in src/api/, alias di importazione @/, variabili d'ambiente BASCIK_*, cache dello script di build, escaping dell'output non attendibile, o un blog o altra collezione Markdown con front matter, tag, bozze e feed. Include uno script new-post.
