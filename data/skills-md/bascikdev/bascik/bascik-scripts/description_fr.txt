Scripts Node.js dans les pages et composants Bascik. À utiliser lors de l’écriture de <script data-bascik-build> (HTML généré à la construction à partir de fichiers, Markdown, JSON ou API), <script data-bascik-build-once> (HTML identique partagé par chaque utilisation), <script data-bascik-routes> avec des routes dynamiques [slug].html, <script data-bascik-server> ou <script data-bascik-stream> pour le rendu à la demande, pieds de page à rendu précoce ou mises en page en streaming selon l’ordre du CSS, routes API dans src/api/, alias d’import @/, variables d’environnement BASCIK_*, le cache du script de construction, l’échappement des sorties non fiables, ou un blog ou une autre collection Markdown avec front matter, tags, brouillons et flux. Inclut un script new-post.
