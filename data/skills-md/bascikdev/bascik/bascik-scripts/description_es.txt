Scripts de Node.js dentro de páginas y componentes Bascik. Úsalos al escribir <script data-bascik-build> (HTML generado en tiempo de compilación a partir de archivos, Markdown, JSON o APIs), <script data-bascik-build-once> (HTML idéntico compartido en cada uso), <script data-bascik-routes> con rutas dinámicas [slug].html, <script data-bascik-server> o <script data-bascik-stream> para renderizado por solicitud, pies de página early-paint o diseños de transmisión con orden de fuentes CSS, rutas API en src/api/, alias de importación @/, variables de entorno BASCIK_*, la caché del script de compilación, escape de salida no confiable, o un blog u otra colección de Markdown con front matter, etiquetas, borradores y un feed. Incluye un script new-post.
