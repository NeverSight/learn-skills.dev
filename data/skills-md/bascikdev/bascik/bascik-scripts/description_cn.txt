Node.js 脚本可嵌入 Bascik 页面和组件中。用于编写 `<script data-bascik-build>`（在构建时从文件、Markdown、JSON 或 API 生成 HTML），`<script data-bascik-build-once>`（每次使用共享相同的 HTML），`<script data-bascik-routes>` 搭配 `[slug].html` 动态路由，`<script data-bascik-server>` 或 `<script data-bascik-stream>` 用于按请求渲染、提前绘制页脚或 CSS 源顺序流式布局，`src/api/` 下的 API 路由，`@/` 导入别名，`BASCIK_*` 环境变量，构建脚本缓存，对不可信输出进行转义，或用于博客及其他带有 front‑matter、标签、草稿和 feed 的 Markdown 集合。还包括一个 new‑post 脚本。
