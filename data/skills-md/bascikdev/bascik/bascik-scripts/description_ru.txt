Скрипты Node.js внутри страниц и компонентов Bascik. Используйте при написании <script data-bascik-build> (HTML, генерируемый во время сборки из файлов, Markdown, JSON или API), <script data-bascik-build-once> (одинаковый HTML, общий для всех использований), <script data-bascik-routes> с динамическими маршрутами [slug].html, <script data-bascik-server> или <script data-bascik-stream> для рендеринга по запросу, ранних отрисовок футеров или потоковых макетов CSS в порядке исходного кода, API‑маршруты в src/api/, псевдонимы импортов @/, переменные окружения BASCIK_*, кэш скриптов сборки, экранирование недоверенного вывода, а также блог или другую коллекцию Markdown с front matter, тегами, черновиками и лентой. Включает скрипт new-post.
