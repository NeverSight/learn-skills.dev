سكريبتات Node.js داخل صفحات ومكوّنات Bascik. استخدمها عند كتابة <script data-bascik-build> (HTML وقت البناء من الملفات أو Markdown أو JSON أو APIs)، <script data-bascik-build-once> (HTML متطابقة تُشارك في كل استعمال)، <script data-bascik-routes> مع مسارات ديناميكية بصيغة [slug].html، <script data-bascik-server> أو <script data-bascik-stream> للتصوير لكل طلب، footers early‑paint أو تخطيطات تدفق CSS حسب ترتيب المصدر، مسارات API في src/api/، أسماء مستعارة للاستيراد @/، متغيّرات البيئة BASCIK_*، ذاكرة التخزين المؤقت لسكريبتات البناء، هروب المخرجات غير الموثوقة، أو مدونة أو مجموعة أخرى من ملفات Markdown مع front matter، وسوم، مسودات، وتغذية. يتضمن سكريبت new‑post.
