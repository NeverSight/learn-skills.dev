Bascik ページとコンポーネント内の Node.js スクリプト。<script data-bascik-build>（ファイル、Markdown、JSON、または API からビルド時に生成される HTML）や、<script data-bascik-build-once>（全ての使用で共有される同一 HTML）を書き込むとき、<script data-bascik-routes>（[slug].html の動的ルート）や、<script data-bascik-server>、<script data-bascik-stream>（リクエストごとのレンダリング）を使用したり、early‑paint フッターや CSS のソースオーダーによるストリーミングレイアウト、src/api/ 内の API ルート、@/ インポートエイリアス、BASCIK_* 環境変数、ビルドスクリプトのキャッシュ、信頼できない出力のエスケープ、またはフロントマター、タグ、ドラフト、フィードを持つブログやその他の Markdown コレクションに利用できます。new‑post スクリプトも含まれます。
