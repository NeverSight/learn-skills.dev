决定哪些内容成为 Bascik 组件，并编写在页面上可多实例使用的组件 CSS 和 TypeScript。适用于以下情况：页面变成大型 HTML 块时、决定是否拆分章节、传递 prop 或使用 slot 时；编写或调试组件的 `<style>`、配套的 `.css` 或 `<script>` 时；组件单次运行正常但出现两个实例就崩溃时；编译后的类名或 ID 名称不正确时；在没有框架的情况下添加标签页、对话框、菜单、切换开关、表单、fetch 请求、存储或组件间事件时；设置设计 token、暗模式、主题切换或字体时；使用本地 CLI 工具优化图片、响应式 WebP、srcset、sizes 或 picture 时；或配置 `deduplicateCss`、`preserve`、`data-bascik-preserve` 或 Tailwind 时。包含 CSS token 检查器和本地 WebP 生成器。
