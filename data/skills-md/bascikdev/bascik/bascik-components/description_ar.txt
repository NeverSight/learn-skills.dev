قرر ما سيصبح مكوّنًا من Bascik واكتب CSS المكوّن وTypeScript بحيث يظل يعمل مع عدة نسخ على الصفحة. استخدم ذلك عندما يتحول صفحة إلى كتلة كبيرة من HTML، وعند اتخاذ قرار ما إذا كان ينبغي تقسيم قسم، تمرير خاصية، أو استخدام slot؛ عند كتابة أو تصحيح <style> الخاص بالمكوّن، أو ملف .css المصاحب، أو <script>؛ عندما يعمل المكوّن مرة واحدة لكنه يتعطل مع وجود نسختين؛ عندما تبدو أسماء الفئات أو المعرفات المترجمة غير صحيحة؛ عند إضافة علامات تبويب، حوارات، قوائم، مفاتيح تبديل، نماذج، طلبات fetch، تخزين، أو أحداث بين المكوّنات دون إطار عمل؛ عند إعداد رموز التصميم، الوضع الداكن، مفتاح التبديل بين السمة، أو الخطوط؛ عند تحسين الصور باستخدام أدوات CLI محلية، WebP الاستجابية، srcset، sizes، أو picture؛ أو عند تكوين deduplicateCss، preserve، data-bascik-preserve، أو Tailwind. يتضمن مُتحقق رموز CSS ومولد WebP محلي.
