Decide qué se convierte en un componente Bascik y escribe CSS y TypeScript del componente que sigan funcionando con varias instancias en una página. Úsalo cuando una página se está convirtiendo en un gran bloque de HTML, al decidir si dividir una sección, pasar una prop o usar un slot; al escribir o depurar el <style> de un componente, su .css acompañante o su <script>; cuando un componente funciona una vez pero se rompe con dos instancias; cuando los nombres de clase o ID compilados se ven incorrectos; al agregar pestañas, diálogos, menús, conmutadores, formularios, llamadas fetch, almacenamiento o eventos entre componentes sin un framework; al configurar tokens de diseño, modo oscuro, un conmutador de tema o fuentes; al optimizar imágenes con herramientas CLI locales, WebP responsivo, srcset, sizes o picture; o al configurar deduplicateCss, preserve, data-bascik-preserve o Tailwind. Incluye un verificador de tokens CSS y un generador local de WebP.
