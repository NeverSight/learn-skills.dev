Decidi cosa diventa un componente Bascik e scrivi il CSS e TypeScript del componente in modo che continui a funzionare con più istanze sulla pagina. Usalo quando una pagina si trasforma in un grande blocco di HTML, quando decidi se suddividere una sezione, passare una prop o usare uno slot; quando scrivi o debuggi il <style> di un componente, il file .css associato o il <script>; quando un componente funziona una volta ma si rompe con due istanze; quando i nomi di classi o ID compilati sembrano sbagliati; quando aggiungi schede, finestre di dialogo, menu, toggle, form, chiamate fetch, storage o eventi tra componenti senza un framework; quando configuri token di design, modalità scura, un toggle del tema o i font; quando ottimizzi le immagini con strumenti CLI locali, WebP reattivo, srcset, sizes o picture; o quando configuri deduplicateCss, preserve, data‑bascik‑preserve o Tailwind. Include un controllore di token CSS e un generatore locale di WebP.
