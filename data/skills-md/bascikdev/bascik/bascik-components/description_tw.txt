決定哪些內容應成為 Bascik 元件，並撰寫元件的 CSS 與 TypeScript，使其在頁面上同時存在多個實例時仍能正常運作。使用情境包括：頁面變成大型 HTML 區塊時、在決定是否拆分區段、傳遞 prop 或使用 slot 時；編寫或除錯元件的 <style>、伴隨的 .css 或 <script> 時；元件單次運作正常但在出現兩個實例時失效時；編譯後的 class 或 ID 名稱看起來不正確時；在沒有框架的情況下加入分頁、對話框、選單、切換器、表單、fetch 請求、儲存或元件間事件時；設定設計代幣、深色模式、主題切換或字體時；使用本機 CLI 工具優化圖片、響應式 WebP、srcset、sizes 或 picture 時；或在配置 deduplicateCss、preserve、data‑bascik‑preserve 或 Tailwind 時。還包括 CSS 代幣檢查器與本機 WebP 產生器。
