Bascik 컴포넌트를 무엇으로 만들지 결정하고, 페이지에 여러 인스턴스가 있어도 동작하는 컴포넌트 CSS와 TypeScript를 작성합니다. 페이지가 거대한 HTML 블록으로 변하고 있을 때, 섹션을 나눌지, prop을 전달할지, 슬롯을 사용할지 결정할 때; 컴포넌트의 <style>, 동반 .css, 혹은 <script>를 작성하거나 디버깅할 때; 컴포넌트가 한 번은 동작하지만 두 개 인스턴스에서는 깨질 때; 컴파일된 클래스나 ID 이름이 이상해 보일 때; 프레임워크 없이 탭, 다이얼로그, 메뉴, 토글, 폼, fetch 호출, 스토리지, 혹은 컴포넌트 간 이벤트를 추가할 때; 디자인 토큰, 다크 모드, 테마 토글, 폰트를 설정할 때; 로컬 CLI 도구, 반응형 WebP, srcset, sizes, picture 등을 사용해 이미지를 최적화할 때; 또는 deduplicateCss, preserve, data-bascik-preserve, Tailwind를 구성할 때 사용합니다. CSS 토큰 체크와 로컬 WebP 생성기를 포함합니다.
