Décidez ce qui devient un composant Bascik et écrivez le CSS et le TypeScript du composant qui continuent de fonctionner avec plusieurs instances sur une page. Utilisez‑le lorsqu’une page se transforme en un gros bloc HTML, lorsqu’il faut décider de diviser une section, de passer une prop ou d’utiliser un slot ; lors de l’écriture ou du débogage du <style> d’un composant, du fichier .css associé ou du <script> ; lorsqu’un composant fonctionne une fois mais se casse avec deux instances ; lorsque les noms de classe ou d’ID compilés semblent incorrects ; lors de l’ajout d’onglets, de dialogues, de menus, de bascules, de formulaires, d’appels fetch, de stockage ou d’événements entre composants sans cadre ; lors de la configuration des tokens de conception, du mode sombre, d’un bascule de thème ou des polices ; lors de l’optimisation des images avec des outils CLI locaux, du WebP réactif, srcset, sizes ou picture ; ou lors de la configuration de deduplicateCss, preserve, data‑bascik‑preserve ou Tailwind. Inclut un vérificateur de tokens CSS et un générateur local de WebP.
