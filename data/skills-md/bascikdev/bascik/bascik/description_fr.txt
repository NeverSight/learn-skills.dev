Construisez des sites web avec Bascik, l'outil de construction de composants HTML sans runtime. Utilisez‑le chaque fois qu’un projet dépend de @bascik/bascik, possède un fichier bascik.config.ts, ou conserve des composants dans src/components/*.html, ou lorsque l’utilisateur mentionne Bascik. Cela couvre les pages, les composants, les slots, les props, l’héritage d’attributs, le CLI Bascik (dev, --build, --server, --check, add), la structure du projet, la vérification de la sortie compilée dans dist/, la création d’un nouveau site et la copie de composants d’exemple testés. Commencez ici ; les compétences complémentaires couvrent les composants, la compatibilité, les scripts, le SEO, la configuration, les tests et la migration.
