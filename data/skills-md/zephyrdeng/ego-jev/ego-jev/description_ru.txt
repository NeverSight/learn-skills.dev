Внутренний цикл Jev (TypeSafe System One) для ego‑browser — одно типизированное решение за ~0.4 с на каждый шаг DOM вместо обращения к LLM. Используйте для многошагового клика по семантической странице: заполните известные значения в форму, задайте фильтры, откройте строку/карточку/меню по имени, перейдите на страницу через навигацию или поиск по сайту. Эскалирует вход, оплату, свободный текст, canvas и чтение контента обратно к вам.
