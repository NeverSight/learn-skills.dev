Escriba documentación para una biblioteca de código mediante un flujo de trabajo iterativo de arriba hacia abajo con revisión del usuario en cada capa. Utilícelo siempre que el usuario solicite documentar una base de código, biblioteca o paquete — incluyendo frases como “write docs for…”, “document this library”, “write technical docs”, o cualquier petición de producir documentación sostenida en lugar de comentarios en línea. La habilidad organiza la salida en secciones de Primeros pasos, Profundizando y Referencia, construyéndolas de forma progresiva (estructura → encabezados → frases temáticas → párrafos), y pausa para la revisión del usuario entre cada pasada. Incluye orientación de estilo de prosa incrustada (Strunk & White) aplicada durante cada pasada de prosa. También úsela para actualizar o refrescar la documentación existente después de cambios en el código — frases como “update the docs”, “the docs are stale” o “sync the docs with the code” — lo que ejecuta el flujo de actualización en la Fase 5.

Por favor, responda siempre en el idioma del usuario.
