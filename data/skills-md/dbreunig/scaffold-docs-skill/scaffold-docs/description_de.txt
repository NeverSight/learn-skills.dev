Schreibe Dokumentation für eine Code‑Bibliothek durch einen iterativen Top‑Down‑Workflow mit Nutzer‑Review auf jeder Ebene. Verwende dies immer, wenn der Nutzer darum bittet, einen Code‑Base, eine Bibliothek oder ein Paket zu dokumentieren – einschließlich Formulierungen wie „write docs for…“, „document this library“, „write technical docs“ oder jede Anfrage, nachhaltige Dokumentation statt Inline‑Code‑Kommentare zu erzeugen. Die Fähigkeit organisiert die Ausgabe in die Abschnitte **Getting Started**, **Diving Deeper** und **Reference**, baut sie schrittweise auf (Struktur → Überschriften → Themensätze → Absätze) und pausiert für das Nutzer‑Review zwischen den jeweiligen Durchgängen. Enthält eingebettete Prosa‑Leitlinien (Strunk & White), die bei jedem Prosa‑Durchlauf angewendet werden. Auch zur Aktualisierung oder Auffrischung bestehender Docs nach Code‑Änderungen verwenden – Formulierungen wie „update the docs“, „the docs are stale“ oder „sync the docs with the code“ – woraufhin der Aktualisierungs‑Workflow in Phase 5 gestartet wird.

Bitte antworte immer in der Sprache des Nutzers.
