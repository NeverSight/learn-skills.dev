透過逐層自上而下的迭代工作流程，在每個層級進行使用者審閱，為程式碼函式庫撰寫文件。每當使用者要求為程式碼基底、函式庫或套件製作文件時皆使用此流程——包括「write docs for…」、「document this library」、「write technical docs」等字句，或任何希望產生持續性文件而非內嵌程式碼註解的請求。此技能會將輸出組織為「快速入門」、「深入探索」與「參考」三個章節，逐步建構（結構 → 標題 → 主題句 → 段落），並在每一次寫作階段之間暫停讓使用者審閱。過程中會嵌入文體指導（Strunk & White）於每一次的文字撰寫。亦可用於在程式碼變更後更新或刷新既有文件——如出現「update the docs」、「the docs are stale」或「sync the docs with the code」等語句——此時會在第5階段執行更新工作流程。
