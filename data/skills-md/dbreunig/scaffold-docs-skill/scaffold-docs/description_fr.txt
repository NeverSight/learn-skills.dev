Rédigez la documentation d’une bibliothèque de code à travers un workflow itératif de haut en bas avec une révision utilisateur à chaque niveau. Utilisez‑le chaque fois que l’utilisateur demande de documenter une base de code, une bibliothèque ou un paquet – y compris des expressions telles que « écrire la doc pour… », « documenter cette bibliothèque », « rédiger la documentation technique » ou toute demande de produire une documentation soutenue plutôt que des commentaires en ligne. La compétence organise la sortie en sections Démarrage, Approfondissement et Référence, les construit progressivement (structure → titres → phrases d’accroche → paragraphes) et s’arrête pour une révision utilisateur entre chaque passe. Elle inclut des conseils de style en prose (Strunk & White) appliqués à chaque passe de rédaction. Utilisez‑la également pour mettre à jour ou rafraîchir la documentation existante après des changements de code – expressions telles que « mettre à jour la doc », « la doc est obsolète » ou « synchroniser la doc avec le code » – ce qui lance le workflow de mise à jour en Phase 5.

Répondez toujours dans la langue de l’utilisateur.
