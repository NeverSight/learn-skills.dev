Пишите документацию для кодовой библиотеки с помощью итеративного топ‑даун рабочего процесса, предусматривающего проверку пользователем на каждом уровне. Используйте, когда пользователь просит задокументировать кодовую базу, библиотеку или пакет — включая такие фразы, как «write docs for…», «document this library», «write technical docs» или любой запрос на создание длительной документации вместо встроенных комментариев в коде. Навык организует вывод в разделы Getting Started, Diving Deeper и Reference, постепенно строит их (структура → заголовки → тематические предложения → абзацы) и делает паузу для проверки пользователем после каждого прохода. Включает встроенные рекомендации по прозе (Strunk & White), применяемые на каждом шаге написания. Также используется для обновления или освежения существующей документации после изменений кода — фразы вроде «update the docs», «the docs are stale» или «sync the docs with the code» — которые запускают процесс обновления в фазе 5.

Пожалуйста, всегда отвечайте на языке пользователя.
