Corrige les problèmes de données structurées. Ajoute et valide le JSON‑LD avec les types Schema.org tels que Organization, WebSite, Product, Article et FAQPage, relie les entités avec @id, ajoute l’attribution de l’auteur et publie des pages d’ancrage de confiance afin que les moteurs de recherche IA puissent comprendre et citer un site web. Utilisez‑le lorsqu’on vous demande « ajouter JSON‑LD », « corriger les données structurées », « ajouter un balisage schema », « améliorer le score des données structurées », « ajouter le schéma Organization », « corriger Schema.org », « ajouter un balisage produit », « ajouter le schéma FAQ », « ajouter le balisage auteur », « ajouter les pages à propos et contact », ou toute tâche JSON‑LD ou Schema.org.  

Veuillez toujours répondre dans la langue de l’utilisateur.
