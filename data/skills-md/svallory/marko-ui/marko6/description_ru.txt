Используйте при написании или редактировании любого файла .markо, при обзоре кода Marko 6 (Tags API) или когда компонент компилируется, но ведёт себя некорректно — устаревшие значения, ошибки гидратации/сериализации, «мертвая» реактивность, неправильные формы атрибутов/обработчиков. Охватывает синтаксис языка, основные теги, улучшения native‑tag, типы TypeScript, API шаблонов, обнаружение пользовательских тегов, стилизацию, ленивую загрузку и каталог ошибок агента. Не предназначено для роутинга/серверов (см. навык marko‑run) или API классов Marko 5.
