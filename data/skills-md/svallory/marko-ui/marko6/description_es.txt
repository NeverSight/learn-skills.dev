Úsalo al escribir o editar cualquier archivo .marko, al revisar código de Marko 6 (API de etiquetas) o cuando un componente se compila pero se comporta de forma incorrecta — valores obsoletos, errores de hidratación/serialización, reactividad muerta, formas incorrectas de atributos o manejadores. Cubre la sintaxis del lenguaje, etiquetas principales, mejoras de native‑tag, tipos de TypeScript, API de plantillas, descubrimiento de etiquetas personalizadas, estilos, carga diferida y catálogo de errores de agente. No es para enrutamiento/servidores (consulta la habilidad marko‑run) ni para la API de clases de Marko 5.  

Por favor, responde siempre en el idioma del usuario.
