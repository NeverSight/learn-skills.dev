Используйте при построении или редактировании приложения Marko Run (@marko/run) — всё, что находится под src/routes (+page, +layout, +handler, +middleware, +meta, +404, +500), синтаксис пути маршрута ($id, $$rest, _pathless, плоские маршруты), вспомогательные функции глаголов Run.GET/POST, контекст запросов ctx/$global, валидация (params/search/json/form), загрузка данных через next(), Run.href, адаптеры vite.config (node/static/netlify) или CLI marko‑run. Не предназначено для самого синтаксиса шаблонов Marko (см. marko6).
