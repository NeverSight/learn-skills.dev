Usa quando costruisci o modifichi un’app Marko Run (@marko/run) — qualsiasi cosa sotto src/routes (+page, +layout, +handler, +middleware, +meta, +404, +500), la sintassi del percorso della route ($id, $$rest, _pathless, route piatte), gli helper di verbo Run.GET/POST, il contesto di richiesta ctx/$global, la validazione (params/search/json/form), il caricamento dei dati tramite next(), Run.href, gli adapter di vite.config (node/static/netlify) o la CLI marko-run. Non è destinato alla sintassi dei template Marko stessi (vedi marko6).
