在构建或编辑 Marko Run（@marko/run）应用时使用——适用于 src/routes 目录下的所有内容（+page、+layout、+handler、+middleware、+meta、+404、+500）、路由路径语法（$id、$$rest、_pathless、扁平路由）、Run.GET/POST 动词助手、ctx/$global 请求上下文、验证（params/search/json/form）、通过 next() 加载数据、Run.href、vite.config 适配器（node/static/netlify），或 marko‑run CLI。**不适用于 Marko 模板语法本身（见 marko6）。**
