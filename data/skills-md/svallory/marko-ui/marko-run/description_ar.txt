يُستخدم عند بناء أو تعديل تطبيق Marko Run (@marko/run) — أي شيء تحت ‎src/routes‎ (+page، +layout، +handler، +middleware، +meta، +404، +500)، وصياغة مسار الروت ($id، $$rest، _pathless، الروت المسطّحة)، مساعدي الأفعال Run.GET/POST، سياق الطلب ctx/$global، التحقق (params/search/json/form)، تحميل البيانات عبر next()، Run.href، مُلحقات vite.config (node/static/netlify)، أو واجهة سطر الأوامر marko-run. ليس للغة قوالب Marko نفسها (انظر marko6).
