Marko Run（@marko/run）アプリの構築や編集時に使用します — src/routes 以下のすべて（+page、+layout、+handler、+middleware、+meta、+404、+500）、ルートパス構文（$id、$$rest、_pathless、フラットルート）、Run.GET/POST 動詞ヘルパー、ctx/$global リクエストコンテキスト、バリデーション（params/search/json/form）、next() を用いたデータロード、Run.href、vite.config アダプター（node / static / netlify）や marko‑run CLI に対してです。Marko テンプレート構文自体には使用しません（marko6 を参照）。
