Úsalo al crear o editar una aplicación Marko Run (@marko/run) — cualquier cosa bajo src/routes (+page, +layout, +handler, +middleware, +meta, +404, +500), sintaxis de ruta ($id, $$rest, _pathless, rutas planas), helpers de verbos Run.GET/POST, contexto de solicitud ctx/$global, validación (params/search/json/form), carga de datos mediante next(), Run.href, adaptadores vite.config (node/static/netlify), o la CLI de marko-run. No es para la sintaxis de plantillas Marko en sí (ver marko6).
