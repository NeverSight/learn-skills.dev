Utilisez‑le lors de la création ou de la modification d’une application Marko Run (@marko/run) — tout ce qui se trouve sous src/routes (+page, +layout, +handler, +middleware, +meta, +404, +500), la syntaxe des chemins de route ($id, $$rest, _pathless, routes plates), les assistants de verbes Run.GET/POST, le contexte de requête ctx/$global, la validation (params/search/json/form), le chargement de données via next(), Run.href, les adaptateurs vite.config (node/static/netlify), ou le CLI marko‑run. Pas destiné à la syntaxe des modèles Marko elle‑même (voir marko6).
