Build, audit, and improve the harness that ensures AI coding agents work reliably: AGENTS.md/CLAUDE.md command files, verification checkpoints, scope boundaries, memory persistence, context budget, tool permission security, and multi‑agent coordination. Use this skill when coding agents are unreliable across sessions—forgetting context, deviating from scope, claiming “completed” before tests pass, or having inconsistent initial states each session—or when creating or evaluating AGENTS.md, CLAUDE.md, init.sh. State and handoff are handled by the installed engineering skill; this skill does not cover those two artifacts. Even if the user never mentions the word “harness,” this skill should be used. When the user requests to update, maintain, or optimize harness components, or to finalize the output of this session, also use this skill.
