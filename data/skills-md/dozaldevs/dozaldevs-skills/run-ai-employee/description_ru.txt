Используйте, когда человек хочет запустить, активировать, стартовать или протестировать существующего AI‑сотрудника, например, запустить сейчас бота‑резюме, запустить гостевого отвечающего или выполнить его один раз для каждой темы из списка входных данных. Активирует сотрудника, может выполнить сухой запуск, чтобы вывести список требуемых входов, и возвращает дескрипторы задач без блокировки. Сначала загрузите operate‑ai‑employees для аутентификации; используйте monitor‑and‑review‑ai‑employee‑work для проверки результата.
