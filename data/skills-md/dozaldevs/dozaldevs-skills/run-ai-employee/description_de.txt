Wird verwendet, wenn ein Mensch einen vorhandenen KI-Mitarbeiter ausführen, auslösen, starten oder testen möchte, z. B. den Recap-Bot jetzt ausführen, den Gast-Responder starten oder ihn einmal pro Thema aus einer Liste von Eingaben ausführen möchte. Löst den Mitarbeiter aus, kann einen Probelauf durchführen, um erforderliche Eingaben aufzulisten, und gibt Aufgabenbearbeitungen zurück, ohne sie zu blockieren. Laden Sie Operate-ai-Mitarbeiter zuerst für auth; verwenden Sie monitor-and-review-ai-employee-work, um das Ergebnis zu überprüfen.
