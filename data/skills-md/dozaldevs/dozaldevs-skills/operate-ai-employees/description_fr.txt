À utiliser lorsqu'un humain vous demande d'exploiter son compte de plateforme d'employé IA : embaucher un employé, en exécuter un, vérifier une tâche, approuver ou rejeter le travail, répertorier ou mettre en pause les employés, ou gérer les connexions, les horaires, les transferts, les membres, l'utilisation, les factures, les activités et les journaux d'exécution. Chargez-le d'abord pour passer entre les quatre compétences professionnelles. La compétence parapluie : dze_ API key auth et son niveau, l'URL de la base de production, la résolution du locataire, le modèle asynchrone et les étapes réservées aux personnes.
