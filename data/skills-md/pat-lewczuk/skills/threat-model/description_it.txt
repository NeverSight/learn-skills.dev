Usa quando l'utente richiede un modello di minaccia (nuovo o aggiornato), un'analisi STRIDE, una revisione della superficie di attacco o dei confini di fiducia, un diagramma di flusso dati con confini di fiducia, “cosa potrebbe andare storto” dal punto di vista della sicurezza, o l'ambito per un pentest, una scansione DAST o un hackathon di sicurezza; prima di implementare qualsiasi cosa sensibile alla sicurezza (autenticazione, autorizzazione, ruoli, tenant, pagamenti, upload, funzionalità amministrative, webhook, integrazioni); e, anche senza le parole “modello di minaccia”, quando una funzionalità aggiunge un componente AI (chatbot, agente, RAG, chiamata di strumenti, server MCP) o un piano di test di sicurezza necessita di un ambito.

Per favore rispondi sempre nella lingua dell'utente.
