Разрабатывает и генерирует по одной полной странице пользовательского интерфейса игры, используя утвержденный стиль и контракт экрана, создавая краткое описание страницы, воспроизводимое изображение, отрицательные ограничения, фактический визуальный актив, когда доступно создание изображения, и запись манифеста. Используйте для домашнего экрана, экрана задач, рейтинга, магазина, инвентаря, персонажа, события, награды, поселения, входа в систему, регистрации, HUD или других игровых экранов.
