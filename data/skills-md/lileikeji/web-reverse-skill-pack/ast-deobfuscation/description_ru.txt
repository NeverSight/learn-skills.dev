Используйте AST Babel для выполнения многослойной, обратимой, целенаправленной деобфускации JavaScript. Применимо к идентификаторам `_0x`, таблицам строк, самостоятельным обёрткам декодера, объектам‑диспатчерам, фальшивым ветвям с константами, уплощению управления потоком `while/for + switch`, цепочкам диспетчеризации `if (literal === opcode)` и сценариям, требующим переключения специализированных скриптов на основе отпечатков сайта или семейства обфускации.  
Когда пользователь явно упоминает reese84, DingXiang, Geetest 4, Tonghuashun, NetEase Yidun, Xiaohongshu, варианты OB или аналогичные адаптации под сайты, следует также использовать этот навык.  
Триггерные слова: «deobfuscation», «_0x», «string table», «control‑flow flattening», «OB» (и их китайские эквиваленты).  
Область применения: данный навык обрабатывает только структурную реконструкцию JS‑кода; он не выполняет анализ алгоритмов шифрования (param‑encryptor), моделирование среды (env‑patcher) или решение капчи (captcha‑solver).  
Деобфускация является предварительным шагом для нахождения логики шифрования; после реконструкции результат должен быть передан соответствующему специализированному навыку.
