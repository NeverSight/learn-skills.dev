使用 Babel AST 進行分層、可逆、針對性的 JavaScript 反混淆。適用於 `_0x` 識別符、字串表、自執行解碼包裝器、分派物件、偽常量分支、`while/for + switch` 控制流程平坦化、`if (literal === opcode)` 分派鏈，以及需要根據站點或混淆族指紋匹配切換專用腳本的情況。  
當使用者明確提及 reese84、DingXiang、Geetest 4、同花順、網易 Yidun、小紅書、OB 變種或類似站點適配時，也應使用此技能。  
觸發詞：「deobfuscation」、「_0x」、「string table」、「control‑flow flattening」、「OB」（以及它們的中文對應）。  
範圍：此技能僅處理 JavaScript 代碼的結構重建；不執行加密演算法分析（param‑encryptor）、環境模擬（env‑patcher）或驗證碼破解（captcha‑solver）。  
反混淆是定位加密邏輯的先決步驟；重建完成後，結果應交由相應的專門技能處理。
