使用 Babel AST 進行分層、可逆、針對性的 JavaScript 反混淆。適用於 `_0x` 識別符、字串表、自執行解碼包裝器、調度器物件、偽常量分支、`while/for + switch` 控制流平坦化、`if (literal === opcode)` 調度鏈，以及需要根據站點或混淆族簽名匹配切換專用腳本的情境。當使用者明確提及 reese84、Dingxiang、Geetest 4、同花順、NetEase Yidun、小紅書、OB 變體或類似站點適配時，也會使用此技能。觸發詞：“deobfuscation”、 “_0x”、 “decode deobfuscation”、 “string table”、 “control‑flow flattening”、 “OB”。範圍：此技能僅處理 JS 程式碼的結構重建，未涵蓋加密演算法分析（param‑encryptor）、環境模擬（env‑patcher）或驗證碼求解（captcha‑solver）。反混淆是定位加密邏輯的前置步驟；結構重建完成後，結果應交給相應的專業技能。請始終以使用者的語言回覆。
