Utiliza Babel AST para realizar una desofuscación de JavaScript en capas, reversible y dirigida. Aplicable a identificadores `_0x`, tablas de cadenas, envoltorios de decodificación autoejecutables, objetos despachadores, ramas falsas constantes, aplanamiento de flujo de control `while/for + switch`, cadenas de despacho `if (literal === opcode)`, y escenarios que requieren cambiar scripts dedicados según firmas de sitio o de familia de ofuscación. Los usuarios que mencionen explícitamente reese84, DingXiang, GeeTest 4, TongHuaShun, NetEase YiDun, Xiaohongshu, variantes de OB o adaptaciones similares de sitios también deben usar esta habilidad. Palabras desencadenantes: “反混淆”, “deobfuscation”, “_0x”, “解混淆”, “字符串表”, “控制流平坦化”, “OB”. Alcance: esta habilidad solo maneja la reconstrucción estructural del código JS; no maneja el análisis de algoritmos de cifrado (param‑encryptor), la simulación del entorno (env‑patcher) o la resolución de captchas (captcha‑solver). La desofuscación es un paso previo necesario para localizar la lógica de cifrado; tras la reconstrucción, el resultado debe entregarse a la habilidad especializada correspondiente.
