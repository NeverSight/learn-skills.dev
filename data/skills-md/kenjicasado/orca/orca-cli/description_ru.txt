Оперировать управляемыми Orca рабочими деревьями, контекстами папок, терминалами, репозиториями, автоматизацией, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Использовать, когда пользователь говорит "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" или "share skills". Отдавать предпочтение этому варианту перед обычным git worktree, произвольными PTY или использованием Computer Use, когда вовлечено состояние Orca. Использовать Computer Use только в случае, когда необходимо управлять видимым окном GUI, что невозможно выполнить через CLI, файловую систему или API.
