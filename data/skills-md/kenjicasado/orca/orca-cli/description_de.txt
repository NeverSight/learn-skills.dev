Bediene Orca‑verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaum‑Kommentare und Orcas eingebetteten Browser über die `orca`‑CLI. Verwende sie, wenn der Nutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzuge sie gegenüber rohem Git‑Worktree, ad‑hoc PTYs oder Computer Use, wenn Orca‑Zustand beteiligt ist. Verwende Computer Use nur, wenn ein sichtbares Fenster GUI‑Steuerung benötigt, die ein CLI, Dateisystem oder eine API nicht leisten kann.
