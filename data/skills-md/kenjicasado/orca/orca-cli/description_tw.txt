透過 `orca` CLI 操作由 Orca 管理的工作樹、資料夾情境、終端機、倉庫、自動化、產出、技能共享、工作樹註解與 Orca 內嵌瀏覽器。當使用者說出「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時，即使用此方式。涉及 Orca 狀態時，優先使用它而非純 git worktree、臨時 PTY 或 Computer Use。只有在需要 GUI 控制的可見視窗且 CLI、檔案系統或 API 無法完成時，才使用 Computer Use。

請始終以使用者的語言回應。
