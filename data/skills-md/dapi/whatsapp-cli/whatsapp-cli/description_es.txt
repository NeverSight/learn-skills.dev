Úselo cuando el usuario desee autenticarse, sincronizar, leer, buscar o enviar mensajes de WhatsApp a través del cliente de cuenta de usuario local whatsapp-cli. También cubre contactos, chats, grupos unidos, descargas de medios y acceso a archivos de WhatsApp. Esto es para el cliente web no oficial de WhatsApp, no para la API de WhatsApp Business.
