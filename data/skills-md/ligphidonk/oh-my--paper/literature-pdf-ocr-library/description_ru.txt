Ищите отслеживаемые академические статьи, скачивайте легально доступные PDF с arXiv и открытых источников, конвертируйте PDF‑файлы или изображения страниц в Markdown с помощью API PaddleOCR, разбирающего макет (или локального fallback‑модуля pdfminer), и упорядочивайте результаты в библиотеку литературы, пригодную для чтения ИИ. Используйте, когда Claude Code нужно собрать корпус статей, выполнить пакетное OCR PDF в Markdown, загрузить реальную научную литературу в базу знаний, получить ссылки на статьи с arXiv или Hugging Face, либо превратить каталог статей в структурированный Markdown с метаданными.
