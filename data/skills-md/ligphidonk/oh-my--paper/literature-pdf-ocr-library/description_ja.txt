追跡可能な学術論文を検索し、arXivやオープンアクセスソースから合法的に取得できるPDFをダウンロードし、PaddleOCR のレイアウト解析 API（またはローカルの pdfminer フォールバック）で PDF またはページ画像を Markdown に変換し、結果を AI が読める文献ライブラリに整理する。Claude Code が論文コーパスを構築したり、PDF をバッチ OCR して Markdown に変換したり、実際の文献をナレッジベースに取り込んだり、arXiv や Hugging Face の論文情報を取得したり、論文ディレクトリを構造化された Markdown とメタデータに変換する必要がある場合に使用する。
