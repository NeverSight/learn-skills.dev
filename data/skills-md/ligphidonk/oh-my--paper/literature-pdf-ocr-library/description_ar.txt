ابحث عن أوراق أكاديمية يمكن تتبعها، وحمّل ملفات PDF المتاحة قانونيًا من arXiv ومصادر الوصول المفتوح، وحوّل ملفات PDF أو صور الصفحات إلى تنسيق Markdown باستخدام واجهة برمجة تطبيقات PaddleOCR لتحليل التخطيط (أو باستخدام pdfminer محلي كاحتياطي)، ونظّم النتائج في مكتبة أدبية قابلة للقراءة بواسطة الذكاء الاصطناعي. استخدم ذلك عندما يحتاج Claude Code إلى بناء مجموعة من الأوراق، أو تحويل دفعة من ملفات PDF إلى Markdown باستخدام OCR، أو إدخال الأدب الحقيقي إلى قاعدة معرفة، أو جلب مراجع أوراق من arXiv أو Hugging Face، أو تحويل دليل من الأوراق إلى Markdown منظم مع البيانات الوصفية. يرجى دائمًا الرد بلغة المستخدم.
