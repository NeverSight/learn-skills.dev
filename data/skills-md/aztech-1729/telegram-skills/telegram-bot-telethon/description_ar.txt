طوّر أو صلّح أو انقل تطبيقات Telegram MTProto بشكل صريح باستخدام Telethon 1.x، بما في ذلك عملاء المستخدمين المصدقين، حسابات البوت، معالجات الأحداث، الكيانات/السجل، نقل الوسائط، المحادثات، وطلبات Telegram الخام. استخدمها عندما يستخدم المشروع الحالي Telethon أو يحتاج إلى قدرات MTProto وصلاحيات الحساب؛ واستخدم إطار عمل Bot API للبوتات العادية عبر HTTP.
