Créez ou maintenez des applications C#/.NET Telegram HTTP Bot API avec Telegram.Bot, y compris les gestionnaires de messages/mises à jour asynchrones, l'interrogation, les webhooks ASP.NET Core, l'annulation, les fichiers, l'état et la compatibilité actuelle de l'API. Utiliser pour les projets .NET ; il ne s'agit pas d'un guide utilisateur-client MTProto.
