Exécute une analyse Periphery pour détecter le code Swift inutilisé dans un projet où Periphery est déjà configuré. À utiliser lorsqu’un utilisateur demande d’exécuter Periphery, d’analyser le code Swift inutilisé ou mort, ou de rechercher et de supprimer le code inutilisé avec Periphery. Pour installer, vous connecter à ou configurer Periphery, utilisez plutôt periphery-scan-setup.
