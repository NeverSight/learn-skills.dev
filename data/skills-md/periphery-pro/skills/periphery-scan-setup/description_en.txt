Agent-guided installation and setup for Periphery, the unused-code finder for Swift. Use when a user wants to install, upgrade or migrate from the open-source Periphery (peripheryapp/periphery), set up or configure Periphery, run their first Periphery scan, write or fix a .periphery.yml, choose which Xcode schemes to scan, or get Periphery working with a Swift package, Xcode project or workspace, CocoaPods, Tuist, XcodeGen, Bazel or another build system. Also use when the user wants to find unused or dead Swift code and Periphery isn't configured yet, when a first scan fails to build or can't find the project, or when they mention `periphery scan --setup`.
