最大100個の並列エージェントで、オープン（または一覧表示された）プルリクエストを一括処理します：外部コントリビュータのセキュリティスキャン、遅れている場合は main にリベース（push --force-with-lease）、該当する場合は初回コントリビュータ向け CI の保留承認、必要に応じて社内 PR のリベース、そしてレビュー担当者の報告を行います。フル、変更のみ、遅れのみ、コンフリクトのみのスコープに対応し、低コストのデイリーローンチが可能です。ユーザーが /pr-sweep（または /pr‑inbound‑sweep）を実行したとき、あるいは「PR を一括処理」「インバウンド PR を一括処理」「外部 PR のセキュリティチェック」「外部 PR をリベース」「自社 PR をリベース」「PR の保留中 CI を承認」「日次 PR スイープ」「外部 PR のレビュー準備」などと依頼したときに使用します。
