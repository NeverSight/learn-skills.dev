Déplacez une application vers TanStack AI à partir du SDK Vercel AI ou des SDK du fournisseur brut, ou déplacez-la d'une API TanStack AI obsolète. À utiliser lorsque quelqu'un demande s'il faut changer de bibliothèque d'IA, lorsque le code mélange streamText, generateText, generateObject, createOpenAI ou @ai-sdk/* avec TanStack AI, lorsqu'une mise à niveau s'interrompt ou lorsque quelqu'un clique sur une option renommée, un package -ui obsolète ou une ancienne forme d'adaptateur. Déclencheurs sur « migrer », « passer du SDK Vercel AI », « ai-sdk », « streamText », « mettre à niveau TanStack AI », « obsolète », « changement radical », « codemod ».
