Utilisez-le lors de la rédaction du titre ou du corps d’une pull request, avant d’exécuter gh pr create, avant de faire un git push sur une branche qui possède déjà une PR ouverte, ou lorsque l’utilisateur dit /pr‑description, « write the PR description », ou « update the PR title ». Ne l’utilisez pas pour les messages de commit, les changelogs ou les commentaires de revue.

Veuillez toujours répondre dans la langue de l’utilisateur.
