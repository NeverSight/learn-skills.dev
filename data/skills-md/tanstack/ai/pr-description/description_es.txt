Usa cuando redactes el título o cuerpo de una pull request, al estar a punto de ejecutar `gh pr create`, al hacer `git push` en una rama que ya tiene una PR abierta, o cuando el usuario dice `/pr-description`, “escribe la descripción de la PR” o “actualiza el título de la PR”. No lo uses para mensajes de commit, changelogs o comentarios de revisión.

Por favor, responde siempre en el idioma del usuario.
