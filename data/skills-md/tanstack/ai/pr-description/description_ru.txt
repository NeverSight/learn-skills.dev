Используйте при написании заголовка или текста pull‑request, перед запуском gh pr create, при выполнении git push в ветку, где уже открыт PR, или когда пользователь пишет /pr‑description, «напиши описание PR» или «обнови заголовок PR». Не используйте для сообщений коммитов, changelog‑ов или комментариев к ревью.

Пожалуйста, всегда отвечайте на языке пользователя.
