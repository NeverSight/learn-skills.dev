Usa quando scrivi il titolo o il corpo di una pull request, quando stai per eseguire **gh pr create**, quando stai per fare **git push** su un branch che ha già una PR aperta, oppure quando l'utente dice **/pr‑description**, “scrivi la descrizione della PR” o “aggiorna il titolo della PR”. Non usarlo per i messaggi di commit, i changelog o i commenti di revisione.
