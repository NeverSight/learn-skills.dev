Verwenden Sie dies, wenn Sie einen Pull‑Request‑Titel oder -Body schreiben, wenn Sie `gh pr create` ausführen, wenn Sie `git push` auf einem Branch ausführen, der bereits einen offenen PR hat, oder wenn der Benutzer `/pr‑description` sagt, „write the PR description“ oder „update the PR title“. Nicht für Commit‑Nachrichten, Changelogs oder Review‑Kommentare verwenden.

Bitte immer in der Sprache des Benutzers antworten.
