Scaffold the Buildpad Workflows module — ready-made /workflows, /workflow-assignments, and /workflow-instances admin pages (WorkflowsManager/WorkflowDetail with a state-diagram editor, WorkflowAssignmentsManager/WorkflowAssignmentDetail, WorkflowInstancesManager/WorkflowInstanceDetail). Use when the user wants an admin UI to design workflow state machines, assign them to collections, or inspect workflow instances and their transition history. To create a workflow for a collection through DaaS (definition, assignment, fields, WorkflowButton), use create-workflow instead.
