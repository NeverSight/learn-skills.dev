Scaffold el módulo Buildpad Files: una biblioteca/files lista para usar (FileManager) y /files/[id] vista detallada (FileDetail) con carga de arrastrar y soltar, importación desde URL, carpetas, vistas de cuadrícula/lista, vista previa, edición de metadatos y eliminación masiva. Respaldado por los ganchos y miniaturas de recursos de useFiles/useFolders. Se usa cuando el usuario dice agregar archivos, administrador de archivos, biblioteca de archivos, módulo de archivos, página de cargas o desea una biblioteca de documentos/medios.
