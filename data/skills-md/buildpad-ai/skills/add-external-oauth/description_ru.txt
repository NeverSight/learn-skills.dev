Добавьте вход через внешнего поставщика идентификации OAuth/OIDC, где Next.js выступает в роли OAuth‑клиента. В проекте Supabase он создает прокси‑поток OAuth с PKCE, provisioning пользователей через Supabase Admin API с назначением роли DaaS по умолчанию и управлением сессиями (необходимо для self‑hosted Supabase без доступа к развертыванию). В проекте Engine доступен только вход через XAppHub, используя вход по ID‑токену Engine с помощью signInWithIdToken; остальные провайдеры отключаются.
