Aggiungi l'accesso a provider di identità OAuth/OIDC esterni, dove Next.js funge da client OAuth. Su un progetto Supabase crea il flusso proxy OAuth con PKCE, il provisioning degli utenti tramite l'API Admin di Supabase con l'assegnazione del ruolo predefinito DaaS, e la gestione della sessione (necessaria per Supabase self‑hosted senza accesso al deployment). Su un progetto Engine è disponibile solo l'accesso XAppHub, tramite l'accesso con token ID dell'Engine usando signInWithIdToken; gli altri provider non sono più supportati.
