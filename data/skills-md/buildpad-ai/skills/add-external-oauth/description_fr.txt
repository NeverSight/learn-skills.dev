Ajoutez une connexion de fournisseur d'identité OAuth/OIDC externe, où Next.js agit en tant que client OAuth. Sur un projet Supabase, il crée le flux proxy OAuth avec PKCE, le provisionnement des utilisateurs via l'API d'administration Supabase avec attribution de rôle DaaS par défaut et la gestion de session (requise pour Supabase auto-hébergée sans accès de déploiement). Sur un projet Engine, seule la connexion XAppHub est disponible, via la connexion ID-token du Engine avec signInWithIdToken ; les autres fournisseurs s'arrêtent.
