Projets Engine uniquement : terminer le déplacement d’un projet Buildpad de Supabase vers le Buildpad Engine. Réécrit les hooks, les jobs cron et les services personnalisés que l’Engine ne pouvait pas exécuter tels quels (engine‑plan/automation-to-review.json) pour le runtime de l’Engine, et transpose le code de l’application : environnement, connexion, appels de données, fichiers, code administrateur, schéma et règles d’accès, fonctions de base de données. À utiliser après qu’un projet a été déplacé, lorsque .buildpad/project.json indique que le backend est engine, ou lorsqu’on demande de porter une application ou une automatisation vers l’Engine. Sur un projet Supabase, explique le déplacement et s’arrête.
