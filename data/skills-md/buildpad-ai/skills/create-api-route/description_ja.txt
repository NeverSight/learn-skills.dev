サーバーサイドの Next.js API ルートを生成します。Engine プロジェクトでは、サインインしたユーザーのセッションを Engine に転送するルート（items、workflow transition、users me、files、permissions、versions）とサインインルートを含みます。Supabase プロジェクトでは、Supabase 認証ルート（login、logout、callback、session）を作成し、Supabase SSR クッキーを管理してサーバーサイドで実行します — ただし、このスキルを使用して DaaS データのプロキシルートを作成しないでください。UI は代わりに Authorization Bearer トークンを使用して DaaS を直接呼び出します。ユーザーが新しい認証エンドポイントまたはサーバーサイドルートを必要とする場合に使用してください。
