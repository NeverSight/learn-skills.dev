Generate a server-side Next.js API route. On an Engine project, routes that forward the signed-in user's session to the Engine (items, workflow transition, users me, files, permissions, versions) plus the sign-in routes. On a Supabase project, Supabase auth routes (login, logout, callback, session) that manage Supabase SSR cookies and run server-side — do NOT use this skill there to create proxy routes for DaaS data, the UI calls DaaS directly using Authorization Bearer tokens instead. Use when the user needs a new auth endpoint or a server-side route.
