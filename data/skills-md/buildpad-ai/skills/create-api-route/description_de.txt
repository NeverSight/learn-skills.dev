Erstelle eine serverseitige Next.js‑API‑Route. In einem Engine‑Projekt gibt es Routen, die die Sitzung des angemeldeten Benutzers an die Engine weiterleiten (items, workflow transition, users me, files, permissions, versions) sowie die Anmelde‑Routen. In einem Supabase‑Projekt gibt es Supabase‑Auth‑Routen (login, logout, callback, session), die Supabase‑SSR‑Cookies verwalten und serverseitig ausgeführt werden – nutze diese Fähigkeit NICHT, um Proxy‑Routen für DaaS‑Daten zu erstellen; die UI ruft DaaS stattdessen direkt mit Authorization‑Bearer‑Tokens auf. Verwende dies, wenn der Nutzer einen neuen Auth‑Endpunkt oder eine serverseitige Route benötigt.

Bitte immer in der Sprache des Benutzers antworten.
