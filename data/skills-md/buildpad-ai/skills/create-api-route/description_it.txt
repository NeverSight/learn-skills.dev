Genera una route API server‑side di Next.js. In un progetto Engine, le route che inoltrano la sessione dell'utente autenticato all'Engine (items, workflow transition, users me, files, permissions, versions) più le route di login. In un progetto Supabase, le route di autenticazione Supabase (login, logout, callback, session) che gestiscono i cookie SSR di Supabase e vengono eseguite lato server — NON utilizzare questa competenza lì per creare route proxy per i dati DaaS, l’interfaccia UI chiama DaaS direttamente usando token Authorization Bearer. Usare quando l’utente ha bisogno di un nuovo endpoint di autenticazione o di una route server‑side.
