서버 측 Next.js API 라우트를 생성합니다. Engine 프로젝트에서는 로그인한 사용자의 세션을 Engine으로 전달하는 라우트(아이템, 워크플로 전환, 현재 사용자, 파일, 권한, 버전)와 로그인 라우트를 포함합니다. Supabase 프로젝트에서는 Supabase 인증 라우트(로그인, 로그아웃, 콜백, 세션)를 제공하여 Supabase SSR 쿠키를 관리하고 서버 측에서 실행합니다 — 이 기능을 사용해 DaaS 데이터에 대한 프록시 라우트를 만들지 마세요. UI는 대신 Authorization Bearer 토큰을 사용해 DaaS에 직접 호출합니다. 사용자가 새로운 인증 엔드포인트나 서버 측 라우트가 필요할 때 사용합니다.
