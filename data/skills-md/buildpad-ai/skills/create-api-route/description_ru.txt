Создайте серверный маршрут API Next.js. В проекте Supabase — маршруты аутентификации Supabase (login, logout, callback, session), которые управляют SSR‑куки Supabase и работают на сервере — НЕ используйте этот навык для создания прокси‑маршрутов данных DaaS, UI обращается к DaaS напрямую, используя токены Authorization Bearer. Используйте, когда пользователю нужен новый endpoint аутентификации или серверный маршрут.
