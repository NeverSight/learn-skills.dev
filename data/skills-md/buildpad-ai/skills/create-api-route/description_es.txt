Genera una ruta API de Next.js del lado del servidor. En un proyecto Engine, crea rutas que reenvíen la sesión del usuario autenticado al Engine (items, transición de flujo de trabajo, usuarios/me, archivos, permisos, versiones) más las rutas de inicio de sesión. En un proyecto Supabase, crea rutas de autenticación de Supabase (login, logout, callback, session) que gestionen las cookies SSR de Supabase y se ejecuten del lado del servidor — NO uses esta habilidad allí para crear rutas proxy para datos DaaS; la UI llama a DaaS directamente usando tokens de autorización Bearer. Utilízalo cuando el usuario necesite un nuevo endpoint de autenticación o una ruta del lado del servidor.
