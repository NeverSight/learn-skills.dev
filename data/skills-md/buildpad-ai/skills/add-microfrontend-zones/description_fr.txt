Configurez une architecture micro‑frontend avec Next.js Multi‑Zones (composition basée sur le chemin sur une même origine). Projets Supabase uniquement pour l’instant : pas encore disponible sur un projet Engine. Créez une application principale (zone par défaut) qui redirige les préfixes de chemin vers des micro‑applications Next.js indépendantes via des réécritures, avec un cookie de session Supabase partagé, un backend DaaS partagé, le AuthenticatedShell du CLI rendu par chaque zone, et sans iframes. Utilisez cette compétence chaque fois que l’utilisateur demande des micro‑frontends, microfrontends, multi‑zones, zones, une composition basée sur le chemin, ou souhaite des applications Next.js indépendantes sous un même domaine — même si l’utilisateur dit « iframe ». N’utilisez la compétence add‑microfrontend (iframe) que lorsque la micro‑application n’est pas une application Next.js, qu’elle est tierce ou du code non fiable, ou qu’elle doit être rendue à l’intérieur d’une page d’une autre application.
