Configura una arquitectura de micro‑frontend con Next.js Multi‑Zones (composición basada en rutas en un solo origen). Solo proyectos Supabase por ahora: aún no disponible en un proyecto Engine. Crea una Aplicación Principal (zona predeterminada) que enruta prefijos de ruta a micro‑aplicaciones Next.js independientes mediante reescrituras, con una única cookie de sesión Supabase compartida, un backend DaaS compartido, el AuthenticatedShell del CLI renderizado por cada zona, y sin iframes. Usa esta habilidad siempre que el usuario solicite micro‑frontends, microfrontends, multi‑zones, zonas, composición basada en rutas, o quiera aplicaciones Next.js independientes bajo un mismo dominio — incluso si el usuario dice “iframe”. Utiliza la habilidad add‑microfrontend (iframe) solo cuando una micro‑aplicación no sea una aplicación Next.js, sea de terceros o código no confiable, o deba renderizarse dentro de una página de otra aplicación.
