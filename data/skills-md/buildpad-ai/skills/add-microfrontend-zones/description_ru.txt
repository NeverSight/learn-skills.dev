Настройте микрофронтенд‑архитектуру с помощью Next.js Multi‑Zones (композиция на основе путей в пределах одного происхождения). Пока доступны только проекты Supabase: в проекте Engine ещё нет поддержки. Создаёт основное приложение (зона по умолчанию), которое перенаправляет префиксы путей к независимым микроприложениям Next.js через rewrite‑правила, используя одну общую cookie‑сессию Supabase, один общий бекенд DaaS, AuthenticatedShell CLI, выводимый каждой зоной, и без iframe. Используйте этот навык каждый раз, когда пользователь запрашивает микрофронтенды, microfrontends, multi‑zones, зоны, композицию на основе путей или хочет независимые приложения Next.js под одним доменом — даже если пользователь говорит «iframe». Навык add‑microfrontend (iframe) используйте только тогда, когда микроприложение не является приложением Next.js, является сторонним или недоверенным кодом, либо должно рендериться внутри страницы другого приложения.

Пожалуйста, всегда отвечайте на языке пользователя.
