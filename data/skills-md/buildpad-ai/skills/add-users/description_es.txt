Scaffold el módulo Buildpad Users: páginas de administración listas para usar /users,/roles y /policies (UsersManager/UserDetail, RolesManager/RoleDetail, PoliciesManager/PolicyDetail) con búsqueda, filtros, asignación de roles, tokens de API y una matriz de permisos por colección. Respaldado por los ganchos useUsers/useRoles/usePolicies. Se usa cuando el usuario dice agregar usuarios, administración de usuarios, administrador de usuarios, página de roles, página de políticas, matriz de permisos o quiere una superficie de administrador de control de acceso.
