Создайте каркас модуля пользователей Buildpad — готовые админ‑страницы /users, /roles и /policies (UsersManager/UserDetail, RolesManager/RoleDetail, PoliciesManager/PolicyDetail) с поиском, фильтрами, назначением ролей, токенами API и матрицей прав доступа для каждой коллекции. Основано на хуках useUsers/useRoles/usePolicies. Используйте, когда пользователь говорит «добавить пользователей», «управление пользователями», «админ пользователей», «страница ролей», «страница политик», «матрица прав» или хочет интерфейс администрирования контроля доступа.

Пожалуйста, всегда отвечайте на языке пользователя.
