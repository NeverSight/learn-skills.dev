Scaffold del modulo Buildpad Users — pagine admin predefinite /users, /roles e /policies (UsersManager/UserDetail, RolesManager/RoleDetail, PoliciesManager/PolicyDetail) con ricerca, filtri, assegnazione di ruoli, token API e una matrice di permessi per collezione. Supportato dagli hook useUsers/useRoles/usePolicies. Da utilizzare quando l'utente dice aggiungere utenti, gestione utenti, admin utenti, pagina ruoli, pagina policy, matrice di permessi, o desidera una superficie admin di controllo accessi.

Rispondi sempre nella lingua dell'utente.
