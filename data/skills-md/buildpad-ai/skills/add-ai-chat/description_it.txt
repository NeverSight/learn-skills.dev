Scaffolding del modulo Buildpad AI Chat — una chat pronta all'uso con un agente Chocolate Factory (AiChatPanel ancorato a destra, AiChatWidget bolla fluttuante, AiChatButton pulsante “Ask AI” nell'header, AiChat per un shell personalizzato) con risposte Markdown in streaming, chat recenti, allegati di immagini e screenshot. Installato con il target CLI ai-chat-routes (browser-direct) o ai-chat-proxy-routes (proxy server). Da utilizzare quando l'utente desidera una chat, chatbot, assistente AI, pulsante “Ask AI”, assistente di supporto, chat Chocolate Factory o chat agente nell'app. Non costruire manualmente una UI di chat o un parser SSE per essa.
