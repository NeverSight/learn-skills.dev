Crea el módulo Buildpad AI Chat — un chat listo para usar con un agente Chocolate Factory (AiChatPanel acoplado a la derecha, AiChatWidget burbuja flotante, AiChatButton botón de encabezado “Ask AI”, AiChat para un shell personalizado) con respuestas en Markdown por streaming, chats recientes, adjuntos de imágenes y capturas de pantalla. Instalado con el objetivo CLI ai‑chat‑routes (directo al navegador) o ai‑chat‑proxy‑routes (proxy del servidor). Úsalo cuando el usuario quiera un chat, chatbot, asistente de IA, botón “Ask AI”, asistente de ayuda, chat Chocolate Factory o chat de agente en la aplicación. Nunca construyas manualmente una interfaz de chat ni un analizador SSE para ello.
