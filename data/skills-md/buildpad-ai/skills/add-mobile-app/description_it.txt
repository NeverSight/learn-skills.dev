Avvolgi un’app Buildpad/Next.js esistente in vere app iOS e Android usando Capacitor in modalità server‑URL — senza riscrivere nulla, il contenitore nativo carica l’app web live distribuita, così middleware, rotte API e autenticazione via cookie continuano a funzionare invariati. Copre i passaggi di configurazione ufficiali, le sole adattamenti nativi che questa piattaforma richiede realmente (gestione dei reindirizzamenti OAuth/SSO, margini delle aree sicure, test locale con server di sviluppo, aggiunta di plugin come le notifiche locali) e le insidie cross‑platform scoperte durante i test pratici (l’inaffidabilità del wildcard allowNavigation di iOS, il bug della navigazione window.open vs click reale, il blocco del DNS privato nell’emulatore Android, host di IdP federati, persistenza dei cookie su Android, versioni di JDK/Gradle). Usa quando l’utente dice add-mobile-app, Capacitor, wrap for mobile, iOS/Android app from the web app, o vuole testare un’app BuildPad su un emulatore/simulatore.
