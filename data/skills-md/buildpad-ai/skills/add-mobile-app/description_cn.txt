使用 Capacitor 的 server‑URL 模式将现有的 Buildpad/Next.js 应用包装成真实的 iOS 和 Android 应用——无需改写，原生壳加载已部署的 Web 应用，middleware、API 路由和 cookie 认证全部保持不变。涵盖官方设置步骤、平台实际需要的仅原生适配（OAuth/SSO 重定向处理、安全区域 inset、本地开发服务器测试、添加本地通知等插件），以及通过实操测试发现的跨平台注意事项（iOS 的 allowNavigation 通配符不可靠、window.open 与真实点击导航类型的 bug、Android 模拟器私有 DNS 卡顿、联邦 IdP 主机、Android cookie 持久化、JDK/Gradle 版本）。在用户提到 add‑mobile‑app、Capacitor、wrap for mobile、从 Web 应用生成 iOS/Android 应用，或想在模拟器/模拟器上测试 BuildPad 应用时使用。
