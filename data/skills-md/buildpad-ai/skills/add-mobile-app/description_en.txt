Wrap an existing Buildpad/Next.js app into real iOS and Android apps using Capacitor in server-URL mode — no rewrite, the native shell loads the live deployed web app so middleware, API routes, and cookie auth all keep working unchanged. Covers the official setup steps, the native-only adaptations this platform actually needs (OAuth/SSO redirect handling, safe-area insets, local dev-server testing, adding plugins such as local notifications), and the cross-platform gotchas found by hands-on testing (iOS's allowNavigation wildcard unreliability, the window.open vs real-click navigation-type bug, the Android emulator private-DNS hang, federated-IdP hosts, Android cookie persistence, JDK/Gradle versions). Use when the user says add-mobile-app, Capacitor, wrap for mobile, iOS/Android app from the web app, or wants to test a BuildPad app on an emulator/simulator.
