Enveloppez une application Buildpad/Next.js existante dans de véritables applications iOS et Android en utilisant Capacitor en mode URL du serveur — aucune réécriture, le shell natif charge l’application web déployée en direct, de sorte que le middleware, les routes API et l’authentification par cookies restent fonctionnels sans changement. Le guide couvre les étapes d’installation officielles, les adaptations propres au natif que cette plateforme nécessite réellement (gestion des redirections OAuth/SSO, marges safe‑area, tests avec serveur de développement local, ajout de plugins tels que les notifications locales), ainsi que les pièges multiplateformes découverts lors de tests pratiques (instabilité du joker allowNavigation d’iOS, bug de navigation entre window.open et clic réel, blocage du DNS privé dans l’émulateur Android, hôtes IdP fédérés, persistance des cookies sous Android, versions du JDK/Gradle). À utiliser lorsque l’utilisateur mentionne add‑mobile‑app, Capacitor, wrap for mobile, application iOS/Android depuis l’application web, ou souhaite tester une application BuildPad sur un émulateur/simulateur.
