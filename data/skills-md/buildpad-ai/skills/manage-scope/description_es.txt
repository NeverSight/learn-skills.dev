Configure y administre la multi‑tenencia o la partición de datos organizacionales usando el sistema de ámbitos nativo de DaaS. Úselo siempre que el usuario necesite aislamiento de inquilinos, control de acceso a nivel organizativo, partición de datos regional o cualquier separación jerárquica de datos. Este es el enfoque estándar de multi‑tenencia para aplicaciones DaaS.
