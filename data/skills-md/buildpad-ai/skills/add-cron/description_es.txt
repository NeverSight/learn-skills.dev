Andamiaje el módulo Buildpad Cron Jobs: páginas de administración listas para usar /cron y/cron/[id] (CronJobsManager con una lista de trabajos y una pestaña de historial de ejecución, CronJobDetail con una ranura de editor de código, configuración e historial por trabajo, CronRunsTable, CronRunLogModal). Se utiliza cuando el usuario desea que una interfaz de usuario de administrador enumere, edite, ejecute, active, clone o elimine trabajos cron de DaaS, o para inspeccionar el historial de ejecución y los registros. Para crear o cambiar un trabajo cron en sí mismo a través de DaaS (programación, código de caja de arena, desencadenador manual), use create-cron en su lugar.
