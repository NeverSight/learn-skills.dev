Cree y administre servicios personalizados de DaaS para código reutilizable compartido entre extensiones y trabajos cron. Defina bibliotecas de utilidades, envoltorios de API, validadores y formateadores que pueden inyectarse mediante `services.custom('name')`. Úselo cuando el usuario necesite lógica compartida entre hooks/crons, quiera evitar la duplicación de código o necesite módulos de servicio comprobables.
