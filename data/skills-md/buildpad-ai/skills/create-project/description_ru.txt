Инициализировать новое приложение Buildpad (Next.js + Buildpad UI) на Buildpad Engine или Supabase. Создаёт основу проекта, включая каркас, прокси‑аутентификацию и тестовую инфраструктуру, готовую для разработки функций по спецификации. Используется, когда пользователь хочет начать новый проект, создать новое приложение или быстро развернуть DaaS‑приложение.
