Initialisez une nouvelle application Buildpad (Next.js + Buildpad UI) sur le Buildpad Engine ou sur Supabase. Crée la base du projet, incluant le scaffolding, le proxy d’authentification et l’infrastructure de test, prête au développement de fonctionnalités guidé par les spécifications. À utiliser lorsque l’utilisateur veut démarrer un nouveau projet, créer une nouvelle application ou lancer une application DaaS.
