Espone i dati e le azioni proprie di un'app Buildpad come un server MCP, in modo che Claude, Copilot, Kiro o Antigravity possano richiamarli come strumenti. Aggiunge una rotta Next.js (`/api/mcp`, HTTP streamable, senza stato) costruita sul SDK TypeScript ufficiale di MCP, dove ogni strumento inoltra il token di accesso del chiamante all'API dei dati, così si applicano i permessi del chiamante e non viene usata alcuna chiave elevata. Copre la progettazione degli strumenti, la validazione degli input, la struttura della risposta, la configurazione del client e i test con l'MCP Inspector. Da utilizzare quando l'utente richiede di aggiungere un server MCP, esporre la mia app ad agenti IA, creare strumenti per un agente o costruire un endpoint MCP nell'app. Non serve per collegare un agente al MCP proprio della piattaforma Buildpad.
