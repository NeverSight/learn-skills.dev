Expose les propres données et actions d’une application Buildpad comme un serveur MCP, afin que Claude, Copilot, Kiro ou Antigravity puissent les appeler comme des outils. Ajoute une route Next.js (`/api/mcp`, HTTP streamable, sans état) construite sur le SDK officiel MCP TypeScript, où chaque outil transmet le jeton d’accès du demandeur à l’API de données, de sorte que les autorisations du demandeur s’appliquent et aucune clé élevée n’est utilisée. Couvre la conception des outils, la validation des entrées, la forme de la réponse, la configuration du client et les tests avec l’Inspecteur MCP. À utiliser lorsque l’utilisateur indique ajouter un serveur MCP, exposer mon application aux agents IA, créer des outils pour un agent ou construire un point de terminaison MCP dans l’application. Pas pour connecter un agent au MCP propre de la plateforme Buildpad.
