قم بطرح بيانات وتفاعلات تطبيق Buildpad الخاص كخادم MCP، بحيث يمكن لـ Claude أو Copilot أو Kiro أو Antigravity استدعاؤها كأدوات. يضيف مسار Next.js واحد (`/api/mcp`، HTTP قابل للبث، بلا حالة) مبني على SDK الرسمي لـ MCP TypeScript، حيث تقوم كل أداة بتمرير رمز الوصول الخاص للمتصل إلى واجهة برمجة البيانات، وبالتالي تُطبق صلاحيات المتصل ولا يُستخدم مفتاح مرتفع. يغطي تصميم الأداة، والتحقق من صحة المدخلات، وشكل الاستجابة، وتكوين العميل، والاختبار باستخدام MCP Inspector. يُستخدم عندما يطلب المستخدم إضافة خادم MCP، أو كشف تطبيقي لوكلاء الذكاء الاصطناعي، أو إنشاء أدوات لوكيل، أو بناء نقطة نهاية MCP في التطبيق. ليس للاتصال بوكيل بمنصة Buildpad الخاصة بـ MCP.
