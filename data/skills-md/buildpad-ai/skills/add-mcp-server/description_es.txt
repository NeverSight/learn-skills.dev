Exponer los propios datos y acciones de una aplicación Buildpad como un servidor MCP, de modo que Claude, Copilot, Kiro o Antigravedad puedan llamarlos como herramientas. Añade una ruta Next.js (`/api/mcp`, HTTP transmisible, sin estado) construida sobre el SDK oficial MCP de TypeScript, donde cada herramienta reenvía el token de acceso del llamador a la API de datos, de modo que se apliquen los permisos del llamador y no se use una clave elevada. Cubre el diseño de la herramienta, la validación de entrada, la forma de la respuesta, la configuración del cliente y pruebas con el Inspector MCP. Úsese cuando el usuario diga agregar un servidor MCP, exponer mi aplicación a agentes de IA, crear herramientas para un agente o construir un endpoint MCP en la app. No es para conectar un agente al propio MCP de la Plataforma Buildpad.
