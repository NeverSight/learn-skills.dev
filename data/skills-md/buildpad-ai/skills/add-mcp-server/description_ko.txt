Buildpad 앱의 고유 데이터와 동작을 MCP 서버로 노출하여 Claude, Copilot, Kiro 또는 Antigravity가 이를 도구로 호출할 수 있도록 합니다. 공식 MCP TypeScript SDK를 기반으로 하는 Next.js 라우트 하나(`/api/mcp`, 스트리밍 가능한 HTTP, 무상태)를 추가하며, 각 도구는 호출자의 액세스 토큰을 데이터 API에 전달하여 호출자의 권한이 적용되고 상승된 키가 사용되지 않도록 합니다. 도구 설계, 입력 검증, 응답 형태, 클라이언트 설정, 그리고 MCP Inspector를 이용한 테스트를 다룹니다. 사용자는 “MCP 서버 추가”, “앱을 AI 에이전트에 노출”, “에이전트를 위한 도구 만들기”, “앱에 MCP 엔드포인트 구축”이라고 말할 때 사용합니다. Buildpad 플랫폼 자체 MCP에 에이전트를 연결하는 경우에는 사용하지 않습니다.
