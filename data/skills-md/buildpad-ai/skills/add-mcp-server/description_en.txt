Expose a Buildpad app's own data and actions as an MCP server, so Claude, Copilot, Kiro or Antigravity can call them as tools. Adds one Next.js route (`/api/mcp`, Streamable HTTP, stateless) built on the official MCP TypeScript SDK, where every tool forwards the caller's own access token to the data API, so the caller's permissions apply and no elevated key is used. Covers tool design, input validation, the response shape, client configuration, and testing with the MCP Inspector. Use when the user says add an MCP server, expose my app to AI agents, make tools for an agent, or build an MCP endpoint in the app. Not for connecting an agent to the Buildpad Platform's own MCP.
