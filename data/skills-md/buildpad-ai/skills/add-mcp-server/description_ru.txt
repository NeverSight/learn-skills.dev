Экспонировать собственные данные и действия приложения Buildpad в виде MCP‑сервера, чтобы Claude, Copilot, Kiro или Antigravity могли вызывать их как инструменты. Добавляет один маршрут Next.js (`/api/mcp`, потоковый HTTP, без состояния), построенный на официальном MCP TypeScript SDK, где каждый инструмент передаёт токен доступа вызывающего в API данных, так что применяются разрешения вызывающего и не используется повышенный ключ. Охватывает проектирование инструмента, проверку входных данных, форму ответа, конфигурацию клиента и тестирование с MCP Inspector. Используется, когда пользователь просит добавить MCP‑сервер, открыть приложение для AI‑агентов, создать инструменты для агента или построить MCP‑конечную точку в приложении. Не предназначено для подключения агента к собственному MCP платформы Buildpad.
