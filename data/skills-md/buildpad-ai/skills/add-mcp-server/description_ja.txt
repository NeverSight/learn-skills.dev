Buildpad アプリの独自データとアクションを MCP サーバーとして公開し、Claude、Copilot、Kiro、または Antigravity がツールとして呼び出せるようにします。公式 MCP TypeScript SDK を使用して、Next.js のルート（`/api/mcp`、ストリーム可能 HTTP、ステートレス）を 1 つ追加し、すべてのツールが呼び出し元のアクセストークンをデータ API に転送するため、呼び出し元の権限が適用され、昇格したキーは使用されません。ツール設計、入力バリデーション、レスポンス形状、クライアント設定、MCP Inspector を用いたテストを網羅しています。ユーザーが「MCP サーバーを追加」「アプリを AI エージェントに公開」「エージェント用のツールを作成」「アプリに MCP エンドポイントを構築」などと言ったときに使用します。Buildpad プラットフォーム固有の MCP にエージェントを接続するためのものではありません。
