実際の製品スクリーンショットを Tella Motion でパララックスショットに変換するには、Tella MCP を介してマスクで各パーツを切り取り、ぼかしと暗転を施した画面上に深度レイヤーとして重ね、カメラを一つ動かすことで近いレイヤーほど遠くへ移動させます。影や深度ぼかし、さらにオプションでわずかな 3D 回転を加えることができます。何も再描画しないため、迅速に、かつ実際の UI をそのまま正確に表現できます。パララックス製品ショットや 2.5D・3D 感覚のスクリーンショットが必要なとき、スクリーンショットを際立たせたり UI の一部を引き出したり、スクリーンショットから B ロールを作成する際に使用してください。インタラクションをアニメーションさせる UI を再構築したい場合は tella-ui-redraw を使用します。tella-motion-design をベースにしています。Tella Motion ツールはベータ版であり、すべてのワークスペースで利用できるわけではありません。
