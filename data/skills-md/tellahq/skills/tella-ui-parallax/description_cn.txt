通过 Tella MCP 将真实的产品截图转化为 Tella Motion 中的视差镜头，使用遮罩将其切割成片段，堆叠为深度层放置在模糊、变暗的屏幕上，并让摄像机在它们之间移动，使近处的层移动得更远，配以阴影、深度模糊和可选的轻微 3D 旋转。没有任何重新绘制，因此速度快且完全是真实 UI。需要视差产品镜头、2.5D 或 3D 感觉的截图时使用，可让截图突出或将 UI 的某一部分拉出，或用于截图的 B‑roll。若要重建可以交互动画的 UI，请使用 tella‑ui‑redraw。基于 tella‑motion‑design 构建。需要 Tella Motion 工具，该工具仍在 beta 阶段，并非所有工作区都可用。
