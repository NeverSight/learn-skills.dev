Rezepte zur Animation des UI‑Verhaltens von Produkten in Tella Motion über das Tella MCP, die einen Button‑Druck, ein Menü‑ oder Modal‑Fenster, das aus dem angeklickten Element herauswächst, einen Schalter, Tabs, das Tippen, ein Feld, das ablehnt oder akzeptiert, das Laden von Inhalten, ein Erfolgshäkchen, eingehende Benachrichtigungen, ein nach oben gleitendes Sheet, das Befüllen einer Liste und das Zählen einer Zahl abdecken. Verwenden Sie tella‑ui‑redraw, wenn die neu gezeichnete UI reagieren muss oder wenn aufgefordert wird, einen UI‑Zustandswechsel zu animieren. Benötigt die Tella Motion‑Tools, die sich in der Beta‑Phase befinden und nicht in jedem Workspace verfügbar sind.
