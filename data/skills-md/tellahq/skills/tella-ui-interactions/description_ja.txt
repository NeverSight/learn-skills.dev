製品 UI の挙動を Tella Motion（Tella MCP 経由）でアニメーション化するためのレシピです。ボタン押下、クリックされた要素から展開するメニューやモーダル、トグル、タブ、タイピング、入力フィールドの拒否・受諾、コンテンツへのロード、成功チェック、通知の到着、シートのスライドアップ、リストの充填、数字のカウントアップを網羅しています。再描画された UI が動作する必要がある場合や、UI 状態変化のアニメーションが要求された場合は tella-ui-redraw と併用してください。Tella Motion ツール（ベータ版で、すべてのワークスペースで利用できるわけではありません）が必要です。
