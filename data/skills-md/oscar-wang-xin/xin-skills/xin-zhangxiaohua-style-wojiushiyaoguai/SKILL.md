# 《我就是妖怪》文风锁定

## 角色定位

## 萃取文风规范

### 1. 叙事视角

第一人称限知叙事，"我"=何安忆（能让时间停止/倒退的时间妖怪，王府大街居委会主任）。碎碎念式独白，**不转"心中"明标**（样本中 心中1、心道7、暗自2、心下1 全极低），直接用"我"自言自语式吐槽，内心活动以"我想/我觉得/我顿时"明述。

多角色群像限知：四妖核心朋友圈（何安忆/阿破/小慧/无双）+各路妖怪（刘老六、高大全、吕唯民、虾仁狗、邵冠今、王成、袁静、孟大妈），每个角色有独立声口（无双冷面、小慧精明、阿破憨直、高大全神族傲娇、王成雇佣兵冷峻、周以港台腔），通过对话与主角观测交错呈现，不锁死单一主角视角但始终以"我"为叙述锚点。

### 2. 句式特征

中等偏长句：平均段长44.6字（中位数34），平均句长41.2字（以 。！？； 切分），短段（≤20字）占25.9%、中长段（21–100字）占66.4%，无超长巨段（>400字 0 段）。

标点活跃、非归一化（已全本对照确认）：问号7.1/千字、感叹号3.3、省略号2.9、破折号1.9 每千字一致活跃；**顿号0.7、分号0.1 极省**（作者几乎不用顿号分号）；冒号14.8/千字高（第一人称"X道："标签说明体）；引号17.1/千字密集。段落末字符 TOP5 为 "：1560 / 。555 / …：113 / ！68 / ？23，显示大量"X道："对话段收尾。

### 3. 对话体系

对话占比31.0%（样本中偏高），平均台词18.2字、中位数12字（短台词为主）。

**标签"道"压倒性使用**：道859次、笑道85、叫道21、怒道5、奇道8、喝道6、问道6、沉吟道等；**"说道"仅1次——禁用"说道"**（与《史上第一混乱》同一作者习惯一致）。一句内多角色对话可串接（"X道：……"紧接着"Y道：……"）。

含引号段落占74.3%，纯对话独立成段6.9%，含2处以上发言段0.4%——对话多嵌于叙事段内，非"一句一段"网文流。

### 4. 叙事节奏

临场突转标记高频：忽然101次（5.0次/章）压倒性强，猛地1、陡然2、转瞬1 极低；跟随性过渡 跟着11、随即9、一晃2。

日常市井描写占比高（妖怪在王府大街的租房、超市、居委会生活），但暗线冲突穿插推进（邵冠今夺刀追杀线、王成雇佣兵回忆、HSK刀匠协会谜题），不靠大起大落，靠"妖怪的不接地气"反差制造笑点与悬念。

**纯现代白话零古体**（已全本对照：看4155:瞧42、什么2765:甚么0、知道1261:知晓0、别1105:勿5、已经1335:已然9、这么774:恁地0、这样622:如此49、一起455:一齐3、刚才226:方才0、这种263:这等3、非常111:甚是0、马上136:便即0）。

### 6. 情绪基调

市井贱萌喜剧 + 妖怪超能力设定 + 现代军事/科技冷幽默。整体调性轻松、接地气、自嘲。

爽感发动机=妖怪在现代社会的"不接地气"反差：妖怪谈房租、谈雇佣兵经历、用刀把公安大楼劈成"大裤衩儿"、时间妖怪随手把跳崖反派拽回地面"跳，跳，跳个毛啊你！"。幽默来自方言谐音 + 自嘲碎碎念 + 群像互怼 + 现代事物与超自然能力的错位拼贴。

### 7. 章节钩子写法

章末钩子多样，无单一固定模式：
- **余味型**："我们的公安大楼，被人家一刀劈成了大裤衩儿……"
- **悬念/反差型**："那小贩其实只差孟大妈5分钱。"
- **动作/吐槽型**："我拽着他脖领子把他拖回到地上，嘟囔道：'下面又没河，也没有九阳真经，跳，跳，跳个毛啊你！'"
- **对话反差型**：章末以一句角色台词收尾留白。

多以"……"或断言句收束，少强断崖式 cliffhanger。

### 8. 环境描写

极简：疑似纯景物段0/2328=0.0%，字数占比0.1%——全书最极端"不写景"样本之一（与同作者《史上第一混乱》并列）。环境仅随行动带出一笔（"远山黛影，小河清水，红砖青瓦，墙上挂着成串的玉米和辣椒"），不铺陈、不抒情、不做氛围渲染。

### 9. 行文禁忌

- **系统流全0**：系统/宿主/任务发布/面板/升级数值/境界体系均为巧合或现代用法（任务87次均为"居委会任务/雇佣兵任务"现代义；穿越7次为吐槽穿越文套路；重生3次为妖怪肉身复原能力），**禁系统/面板/任务发布/升级数值/金手指**。
- **法力0**：本书妖怪**不用修仙"法力/真气/境界"体系**，靠各自超能力（时间停止、控火、重生、妖气、神族之力）设定。仿写禁用"运起法力/真气暴涨/突破境界"等修仙套话。
- 禁用"说道"标签（全书仅1次）。
- 禁硬拽文言（瞧/甚么/知晓/勿/已然/恁地/这等/方才/便即/登时/岂）——本书纯现代白话。
- 禁文艺腔省略号拖尾（"……"作情绪余韵偶有，但不可堆砌成文艺抒情）。
- 禁大段景物/氛围抒情（详见维度8，本书不写景）。
- 禁丢失市井口语与方言谐音笑点（张小花招牌）。
- 禁丢失现代军事/科技词汇的硬核质感——写成纯玄幻架空会立刻破功。

### 10. 开篇习惯

第一人称破题 + 自我吐槽式切入，前200字信息密度高（立人设+抛设定）：
- 类型A："我叫何安忆，何是何安忆的何，安是何安忆的安，忆是——回忆的忆。"（自报家门+碎碎念）
- 类型B：场景对话破题——"第一个问题，我见过你的女儿吗？"（直接进入事件）

开篇不拖沓、不写环境铺陈，要么直接亮主角人设，要么直接抛冲突/设定谜题。

## 段落与句式约束

1. 段长以中短段为主，单段控制在20–80字区间最常见，偶尔长段不超过200字；杜绝400字以上巨段。
2. 句长中等偏长（约40字/句），逗号连缀，允许破折号与省略号作语气/动作余韵，但顿号分号极省。
3. 第一人称"我"为叙述锚点，对话用"X道："标签，引号密集；冒号高频率用于标签。
4. 杜绝大段密集长段落与书面化书面腔；碎碎念口语可短句成段。

## 对话写作规范

1. 角色台词风格：市井口语、自嘲、吐槽、方言谐音；短台词为主（中位12字），可一句内多角色串接。
2. 动作神态搭配：标签后接简笔神态（"小慧忽然抢过电话柔声道""王成讥讽地一笑""高大全掩面而去"），不堆形容词。
3. 对话节奏：占比约三成，嵌于叙事段内为主，非"一句一段"网文流；群像对话各有声口。
4. 对话标签规则：**一律用"道"（含 笑道/叫道/怒道/奇道/喝道/问道 等变体），禁用"说道"**。

## 环境描写规范

1. 描写密度上限：纯景物段趋近0，全书不写景；最多随行动一笔带过（1–2句）。
2. 描写手法偏好：白描、不加形容词渲染，偶用现代比喻（"像两尊门神似的"）。
3. 描写位置规则：绝不章首铺陈，只在行动移动到新场景时顺带一笔。

## 章节钩子规范

1. 末尾悬念类型偏好：余味型 / 悬念反差型 / 动作吐槽型 / 对话留白型，轮换使用，不固定。
2. 末尾句式特征：多以"……"或断言句收束，可留一句角色台词作钩子。
3. 与下章衔接方式：钩子抛谜题或反差，下章自然承接，不靠强断崖。

## 开篇规范

1. 开篇切入方式：第一人称自报家门+碎碎念，或场景对话直接破题。
2. 开篇句式偏好：前200字立人设+抛设定/冲突，不写环境铺陈。
3. 前200字信息密度要求：高——必须同时完成"我是谁/我的异常能力/当前事件"三件事的至少两件。

## 叙事节奏规范

1. 冲突切入速度：快——开篇即事件或人设亮明，不铺垫背景。
2. 铺垫方式：靠妖怪市井日常自然铺陈设定，暗线（夺刀/雇佣兵/HSK谜题）穿插推进。
3. 日常描写占比上限：高（市井生活占比大），但需有暗线冲突托底。
4. 信息释放节奏："忽然"类突转高频（5次/章），笑点与悬念交替释放。

## 词汇修辞规范

1. 允许使用的高频词汇清单：现代白话主体（看/什么/知道/已经/别/如果/这么/这样/一起/刚才/非常/马上）；现代军事科技词（AK-47/74、SAS、GIGN、DNA、Strider、HSK、ABS、BOSS、DVD、IT、OL、MM）；拟声（嘿嘿/呵呵/嘻嘻/哈哈）；方言谐音。

3. 规避的词汇类型：古风词（瞧/甚么/知晓/勿/已然/恁地/这等/方才/便即/登时/岂）、修仙体系词（法力/真气/境界/运功/突破）、"说道"标签、文艺腔堆叠。

## 情绪基调规范

1. 整体调性定位：市井贱萌喜剧 + 都市妖怪群像 + 现代军事科技冷幽默。
2. 每章情绪曲线模板：日常互怼铺垫 → 突转事件（忽然…）→ 妖怪能力反差解围/搞笑 → 余味钩子。
3. 幽默使用规则：方言谐音 + 自嘲碎碎念 + 群像互怼 + 现代事物与超自然错位；不靠段子堆砌。
4. 爽感来源与触发频率：妖怪在现代社会的"不接地气"反差（高频），每章至少一次能力/设定错位笑点。

## 允许与禁止清单

### 允许

3. 改变第一人称视角，或把"我"滑成第三人称

6. 硬拽文言虚词（瞧/甚么/知晓/勿/已然/恁地/这等/方才/便即/登时）
