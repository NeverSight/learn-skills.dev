- **作者**：玉庭君（起点历史穿越 + 修仙 + 沙雕玩梗向代表作者之一）。
- **题材**：现代都市超能力男主（黄天）穿越汉末黄巾时代，并跨界到修仙世界"厚土宗"，把张角、卢植、曹操、董卓、刘宏（汉灵帝）、皇甫嵩等真实历史人物拉进叙事玩梗。本质 = **历史穿越 + 修仙（传统等级，非游戏化系统流）+ 沙雕幽默 + 神话/梗文化乱入**。
- **核心文风一句话**：纯现代白话骨架 + 接地气生活白描 + 高密度情绪标点（叹号、省略号极高）+ 拟声词/微信聊天体/历史人物金句玩梗。
- **态判定**：态1（纯现代白话 + 少量古体虚词选择性残留：说话/纵然/为何），**不是**真·半文半白、不是穿越语域分裂（历史人物说话也是现代白话带玩梗，无文言腔）。

## 三、词汇与修辞硬规则

### A. 古体虚词选择性保留（作者私人语域，执行）
- **用"说话"禁"讲话"**：全本 说话221 : 讲话3（73.7:1）。叙述/对话一律"说话"，禁用"讲话"。
- **用"纵然"禁"即使"**：全本 纵然13 : 即使0（∞）。让步用"纵然"。
- **偏"为何"轻"为什么"**：全本 为何290 : 为什么78（3.7:1）。疑问偏好"为何"，但不禁"为什么"。
- **"何况"可用**（50:况且28，混用，非硬规则）。

### B. 现代白话骨架（别硬拽文言）
- 看4454 / 没有1879 / 如果784 / 别911 / 我们1664 / 心里297 / 已经564 / 知道635 / 现在1226 —— 全现代体压倒。
- "若是"(345)可用但"如果"(784)更主，混用。

### C. 疑问词体系（关键：混用、无硬禁项，与青山/苟在相反）
> ⚠️ 本书疑问词**不立硬规则**，前20章采样（吗37:么0、什幺51）与全本相反，是采样假象，以全本为准：
- **什幺 / 什么 混用**：全本 什幺790 : 什么1402（什么略多）。两者皆可，但**禁"甚幺/啥/咋"**（全书0）。
- **么 / 吗 混用**：全本 么2963 : 吗1341（么略多）。"么"为主但"吗"也大量用，**非"禁吗"**（区别于青山2989:7）。
- **如何 / 怎么 混用**：全本 如何540 : 怎么676（怎么略多）。
- **为何 / 为什么**：偏"为何"（见A）。
- 玉庭君前段爱写特殊拼写 **"怎幺""要幺"**（=怎么/要么），后段混"怎么"；仿写可保留"怎幺/要幺"增强辨识，但非强制。

### D. 引号体系（关键：混用，非纯「」）
- 前20章纯直角引号「」(487/489)；**全本混用全角" "（10530）与直角「」(11720)**，后段历史/战争段大量用全角" "。
- 仿写：对话可用「」或" "，保持一致即可；内部书名/强调用『』(212，全本平衡)；【】框日记体/微信聊天/术语(562)。
- 双直角『』书名/强调、方头【】日记体/聊天体/特殊术语为作者记号，保留。

## 四、句式与节奏

- **短段碎句、高频换行**：均值32字、84%段落≤50字，节奏"碎、密、跳动"。
- **拟声词独立成段**：咻～ / 咻～ / 噼啪～ / 呛啷～ / 哒哒……（全本 咻232/忽～141/呛啷6/哒哒31），常独占一行作动作/转场节拍。

## 六、叙事与玩梗特征（最 distinctive 的部分）

- **第一人称引子 + 第三人称主体**：第1章以"我"的病历/日记体（【9月5日…】框）强代入开局，后续转第三人称写"黄天"，偶尔切张角/卢植/曹操等多POV（群像玩梗）。
- **历史人物拉郎玩梗**：曹操/刘宏/张角/卢植等真实人物用现代白话对话、被写进玩梗章标题（"曹操：和一群虫豸共事，怎能匡扶汉室？""刘宏：你们当朕是傻子吗？"）。历史人物**无文言腔**，说人话带吐槽。
- **微信聊天体**：用【】框表情包与聊天记录（【摸摸猫头.gif】【方便视频吗，有点想你】黄天：【方便】），是本书独特现代感记号。
- **沙雕幽默来源**：主角超能力吐槽（"世界上所有名为黄天的人，都成为了我的信号基站！""被公司当成人才输送给社会了""挂逼发育的快，不是理所当然的吗？"）+ 历史人物荒诞反差 + 历史口号玩梗（"苍天已死，黄天当立，岁在甲子，天下大吉！！"）。
- **修仙元素（非系统流）**：有练气/筑基/境界等传统等级（全本 筑基617/境界516/练气187），但系统47/面板28/升级7/金手指16 极少——**是传统修仙叙事，不是游戏化系统流/网游体**。勿写"属性面板/打怪爆装备"式系统流。

## 七、章标题与章末钩子

- **章标题即玩梗**：几乎每章标题是梗/金句/历史人物吐槽（"苍天已死，黄天当立""不儿，这黄天也行？""仙法面前，顺之者昌，逆之者亡"）。仿写时章标题要有梗感、有反差、有网感。
- **章末钩子**：战场悬念 / 多POV反转 / 历史人物金句收尾，常配高叹号（"传我将令，兵发广宗，诛灭蛾贼！！"）。避免平淡总结式结尾。

## 八、禁忌（勿套用其他书的私人语域）

- 禁用"讲话"（用"说话"）、禁用"即使"（用"纵然"）。
- 禁用"甚幺/啥/咋"（本书不用）。
- 勿把历史人物写成文言腔（本书全现代白话带玩梗）。
- 勿写成系统流/网游体（无属性面板/打怪爆装）。
- 勿堆砌环境景物（本书环境描写0.2%）。
- 勿回避叹号与省略号（本书极高密度，是情绪招牌）。
