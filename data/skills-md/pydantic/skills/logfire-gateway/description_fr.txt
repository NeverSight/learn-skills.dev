Configurez les appels de modèle d’une application pour qu’ils utilisent le Pydantic AI Gateway. Utilisez-le lorsque l'utilisateur demande de router l’inférence de l’application via le Gateway, de connecter une clé Gateway ou d’ajouter un extrait de fournisseur Gateway. Cela ne configure ni n’instrumente les agents de codage.

Veuillez toujours répondre dans la langue de l'utilisateur.
