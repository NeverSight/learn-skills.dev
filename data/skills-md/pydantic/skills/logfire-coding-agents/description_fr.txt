Connectez Claude Code ou Codex lui‑même à la télémétrie Logfire, ou acheminiez les requêtes de modèle d’un agent de codage via la passerelle Pydantic AI. Utilisez‑le pour l’enregistrement de sessions de codage, les politiques de capture, la configuration de l’agent de la passerelle, les lancements temporaires de proxy, le statut ou la suppression. Ce n’est pas destiné à instrumenter une application ou à diriger le client de modèle d’une application.
