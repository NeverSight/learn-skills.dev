Перенесите Python‑приложения из Claude Agent SDK в Pydantic AI и, только при необходимости, в Pydantic AI Harness. Используйте, если исходный код импортирует `claude_agent_sdk` или зависит от цикла агента Claude Code, сессий, встроенных инструментов, хуков, разрешений, навыков или субагентов. Не используйте для Anthropic Messages SDK или Claude Managed Agents.

Пожалуйста, всегда отвечайте на языке пользователя.
