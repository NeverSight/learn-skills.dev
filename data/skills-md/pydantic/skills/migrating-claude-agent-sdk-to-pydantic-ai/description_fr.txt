Migration des applications Python du SDK Claude Agent vers Pydantic AI et, uniquement si nécessaire, Pydantic AI Harness. Utilisez‑le lorsque le code source importe `claude_agent_sdk` ou repose sur la boucle d’agent de Claude Code, les sessions, les outils intégrés, les hooks, les permissions, les compétences ou les sous‑agents. Ne pas utiliser pour le SDK Anthropic Messages ou les Claude Managed Agents.

Veuillez toujours répondre dans la langue de l'utilisateur.
