Migrieren Sie Python-Anwendungen vom Claude Agent SDK zu Pydantic AI und, nur bei Bedarf, zu Pydantic AI Harness. Verwenden Sie dies, wenn der Quellcode `claude_agent_sdk` importiert oder auf die Agentenschleife, Sitzungen, eingebauten Werkzeuge, Hooks, Berechtigungen, Fähigkeiten oder Subagenten von Claude Code angewiesen ist. Nicht verwenden für das Anthropic Messages SDK oder Claude Managed Agents.

Bitte immer in der Sprache des Benutzers antworten.
