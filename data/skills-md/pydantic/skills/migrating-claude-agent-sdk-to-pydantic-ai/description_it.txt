Migra le applicazioni Python dal SDK Claude Agent a Pydantic AI e, solo quando necessario, a Pydantic AI Harness. Usalo quando il codice sorgente importa `claude_agent_sdk` o dipende dal ciclo dell'agente di Claude Code, dalle sessioni, dagli strumenti integrati, dagli hook, dalle autorizzazioni, dalle competenze o dai sottoagenti. Non usarlo per l'SDK Anthropic Messages o per i Claude Managed Agents.

Rispondi sempre nella lingua dell'utente.
