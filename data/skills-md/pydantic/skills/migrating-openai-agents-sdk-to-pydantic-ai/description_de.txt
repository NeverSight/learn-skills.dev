Migrieren Sie Python OpenAI Agents SDK‑Anwendungen zu Pydantic AI und, falls erforderlich, zu Pydantic AI Harness. Verwenden Sie es für `agents.Agent`, `Runner`, Funktionswerkzeuge, Übergaben, Schutzvorrichtungen, Sitzungen, menschliche Genehmigung, Streaming oder `SandboxAgent`. Verwenden Sie es nicht für Anwendungen, die direkt auf der OpenAI Responses API gebaut sind, ohne die Agents SDK‑Laufzeit. Bitte antworten Sie stets in der Sprache des Benutzers.
