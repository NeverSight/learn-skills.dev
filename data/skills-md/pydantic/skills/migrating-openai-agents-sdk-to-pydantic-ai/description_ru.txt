Мигрируйте приложения Python OpenAI Agents SDK на Pydantic AI и, при необходимости, Pydantic AI Harness. Используйте для `agents.Agent`, `Runner`, инструментов функций, handoffs, guardrails, сессий, человеческого одобрения, потоковой передачи или `SandboxAgent`. Не используйте для приложений, построенных напрямую на OpenAI Responses API без среды выполнения Agents SDK.
