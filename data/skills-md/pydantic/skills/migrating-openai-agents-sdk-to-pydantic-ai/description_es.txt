Migre las aplicaciones Python OpenAI Agents SDK a Pydantic AI y, cuando sea necesario, a Pydantic AI Harness. Use para `agents.Agent`, `Runner`, herramientas de funciones, entregas, salvaguardas, sesiones, aprobación humana, transmisión o `SandboxAgent`. No lo use para aplicaciones construidas directamente sobre la API de Respuestas de OpenAI sin el runtime del Agents SDK.

Por favor, responda siempre en el idioma del usuario.
