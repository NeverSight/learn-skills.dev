Migrer les applications Python OpenAI Agents SDK vers Pydantic AI et, le cas échéant, Pydantic AI Harness. Utiliser pour `agents.Agent`, `Runner`, les outils de fonction, les transferts, les garde-fous, les sessions, l'approbation humaine, le streaming ou `SandboxAgent`. Ne pas utiliser pour les applications construites directement sur l'API OpenAI Responses sans le runtime Agents SDK.

Veuillez toujours répondre dans la langue de l'utilisateur.
