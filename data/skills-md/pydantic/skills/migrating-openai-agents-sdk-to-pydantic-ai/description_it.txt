Migra le applicazioni Python OpenAI Agents SDK a Pydantic AI e, quando opportuno, a Pydantic AI Harness. Usa per `agents.Agent`, `Runner`, strumenti di funzione, passaggi, barriere di sicurezza, sessioni, approvazione umana, streaming o `SandboxAgent`. Non usarlo per applicazioni costruite direttamente sull'API OpenAI Responses senza il runtime dell'Agents SDK.

Per favore rispondi sempre nella lingua dell'utente.
