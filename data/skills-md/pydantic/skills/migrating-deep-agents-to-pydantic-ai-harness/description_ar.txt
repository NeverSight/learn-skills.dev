نقل تطبيقات Python LangChain Deep Agents إلى Pydantic AI و Pydantic AI Harness. استخدم ذلك عندما يستخدم المصدر حزمة `deepagents` الأصلية أو يُعيد إنتاج وسائطها، أو خلفياتها، أو مهاراتها، أو ذاكرتها، أو الوكلاء الفرعيين، أو عقود الصندوق الرملية بشكل واضح. استخدم `migrating-langchain-to-pydantic-ai` لترحيلات LangChain العادية أو LangGraph أو LCEL و`pydantic-ai-harness` للاستخدام من الصفر في Harness.
