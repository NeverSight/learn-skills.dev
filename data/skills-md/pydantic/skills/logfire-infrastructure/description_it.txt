Monitora host, contenitori Docker, cluster Kubernetes, server database/coda/cache e parametri del provider cloud con Pydantic Logfire: non è richiesto alcun codice applicativo. Utilizza questa competenza ogni volta che l'utente chiede di "monitorare il mio host/server/VM", "monitorare i miei contenitori Docker", "monitorare il mio cluster Kubernetes", "inviare parametri dell'infrastruttura a Logfire", "monitorare il mio database/Postgres/Redis/MongoDB/Kafka", "raccogliere parametri cloud" (AWS/GCP) o menziona OpenTelemetry Collector nel contesto di Logfire. Si tratta solo dell'infrastruttura: per la strumentazione del CODICE APPLICATIVO (tracce, registri, intervalli AI/agente) utilizzare invece la capacità di strumentazione logfire.
