Pydantic Logfire를 사용하여 호스트, Docker 컨테이너, Kubernetes 클러스터, 데이터베이스/큐/캐시 서버 및 클라우드 제공자 지표를 모니터링하세요. 애플리케이션 코드가 필요하지 않습니다. 사용자가 "내 호스트/서버/VM 모니터링", "내 Docker 컨테이너 모니터링", "내 Kubernetes 클러스터 모니터링", "인프라 메트릭을 Logfire로 보내기", "내 데이터베이스/Postgres/Redis/MongoDB/Kafka 보기", "클라우드 메트릭 수집"(AWS/GCP)을 요청하거나 Logfire 컨텍스트에서 OpenTelemetry Collector를 언급할 때마다 이 기술을 사용하세요. 이는 인프라일 뿐입니다. 애플리케이션 코드(추적, 로그, AI/에이전트 범위)를 계측하려면 대신 logfire 계측 기술을 사용하세요.
