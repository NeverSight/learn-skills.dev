مراقبة الأجهزة المضيفة، وحاويات Docker، ومجموعات Kubernetes، وخوادم قاعدة البيانات/قائمة الانتظار/ذاكرة التخزين المؤقت، ومقاييس موفر السحابة باستخدام Pydantic Logfire - لا يلزم وجود رمز تطبيق. استخدم هذه المهارة عندما يطلب المستخدم "مراقبة المضيف/الخادم/VM"، أو "مراقبة حاويات Docker الخاصة بي"، أو "مراقبة مجموعة Kubernetes الخاصة بي"، أو "إرسال مقاييس البنية التحتية إلى Logfire"، أو "مشاهدة قاعدة بياناتي/Postgres/Redis/MongoDB/Kafka"، أو "جمع مقاييس السحابة" (AWS/GCP)، أو يذكر OpenTelemetry Collector في سياق Logfire. هذه هي البنية التحتية فقط - لاستخدام أدوات رمز التطبيق (الآثار والسجلات وامتدادات الذكاء الاصطناعي/الوكيل) استخدم مهارة أداة إطلاق النار بدلاً من ذلك.
