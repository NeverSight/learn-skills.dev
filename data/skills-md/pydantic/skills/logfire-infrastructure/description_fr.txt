Surveillez les hôtes, les conteneurs Docker, les clusters Kubernetes, les serveurs de base de données/file d'attente/cache et les métriques du fournisseur de cloud avec Pydantic Logfire — aucun code d'application requis. Utilisez cette compétence chaque fois que l'utilisateur demande de « surveiller mon hôte/serveur/VM », « surveiller mes conteneurs Docker », « surveiller mon cluster Kubernetes », « envoyer des métriques d'infrastructure à Logfire », « surveiller ma base de données/Postgres/Redis/MongoDB/Kafka », « collecter des métriques cloud » (AWS/GCP) ou mentionne OpenTelemetry Collector dans le contexte de Logfire. Il s'agit uniquement d'une infrastructure : pour instrumenter le CODE D'APPLICATION (traces, journaux, étendues IA/agent), utilisez plutôt la compétence d'instrumentation logfire.
