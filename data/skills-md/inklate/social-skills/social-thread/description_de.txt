Bauen Sie eine mehrteilige Beitragssequenz mit echter Struktur – einen X (Twitter)-Thread oder einen LinkedIn‑Mehrfachbeitrag – anstatt eines zersplitterten Blogs: einen Hook‑Beitrag, der das Lesen verdient, jeweils eine Idee pro Beitrag, eine Eskalations‑und‑Auflösungs‑Struktur und einen abschließenden CTA‑Beitrag, wobei jeder Beitrag auf das Plattform‑Limit budgetiert wird und die Zeichenanzahl angezeigt wird. Der Hook wird in drei Varianten verfasst und bewertet, bevor irgendetwas anderes geschrieben wird, weil Beitrag 1 entscheidet, ob die restlichen gelesen werden. Verwenden Sie dies, wenn der Nutzer sagt „write a thread“, einen „tweetstorm“ möchte, sagt „turn this into a thread“ oder nach einem „X thread about“ zu einem Thema fragt. Lesen Sie social-context.md für Stimme, Zielgruppe, Positionierung, Ziele und rote Linien. Für einen einzelnen eigenständigen Beitrag verwenden Sie social‑post; für dieselbe Botschaft gleichzeitig über mehrere Plattformen hinweg verwenden Sie social‑crosspost.
