Analyze 3–10 writing samples the user provides — LinkedIn posts, X (Twitter) threads, emails, blog posts — and distill how they actually write: sentence length, rhythm, vocabulary, punctuation and emoji habits, openers, sign-offs, and humor register. The output is a set of concrete, checkable voice rules written into the "## Voice" section of social-context.md, the file every skill in this collection reads for brand voice and setup. Use when the user says "learn my voice", "write like me", "match my tone", or "analyze my writing style". Includes a verification round: a rewritten sample the user judges as "sounds like me" before the rules are saved.
