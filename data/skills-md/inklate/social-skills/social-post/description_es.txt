Redacta una sola publicación social para una plataforma — LinkedIn, X (Twitter), Instagram, Facebook, Threads, Bluesky o Mastodon — diseñada según la forma en que el feed de esa plataforma se lee realmente: un gancho que sobreviva al pliegue, una idea, ritmo de espacio blanco, una llamada a la acción específica y enlaces y hashtags correctos para la plataforma. Utilízalo cuando el usuario dice “write a post”, “draft a LinkedIn post”, “write an X post”, “post this on Instagram” o pide “a post about” algo. Produce dos variantes de gancho y verifica automáticamente el borrador contra las reglas de voz del usuario. Para el mismo mensaje adaptado a varias plataformas a la vez usa social-crosspost; para una secuencia de varias publicaciones usa social-thread. Lee social‑context.md para la voz, audiencia, pilares, posicionamiento, objetivos y líneas rojas, de modo que la publicación suene como el usuario.

Por favor, responde siempre en el idioma del usuario.
