Especificaciones de desarrollo front‑end ingenierizado y entrega de control de acceso para paneles de datos / pantallas de gran formato / consolas industriales. Flujo de trabajo de ingeniería, tokens de diseño, unificación de gráficos y componentes, verificación multi‑resolución y multi‑navegador, puertas de calidad y entrega para dashboards, pantallas KPI, salas de control, pantallas grandes, visualización de datos, consola de administración y proyectos de TV en planta. Utilízese al construir, iterar, refactorizar o revisar un front‑end tipo tablero, cuando una UI debe renderizarse correctamente en televisores de fábrica, muros de video o pantallas de salas de control a 1080p/1440p/4K, o cuando el usuario menciona 看板, 大屏, 控制台, 数据可视化, KPI 大屏, 拼接屏. También sirva para auditar un tablero existente en busca de estilos codificados, tematización inconsistente de gráficos o falta de verificación responsiva. No es aplicable a sitios web de marketing, portafolios u otras páginas de presentación (para esos casos use la habilidad de tipo frontend‑design).
