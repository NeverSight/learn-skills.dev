فيديوهات قصص البيانات حيث يحمل الرسم البياني المتحرك الحجة - خطوط تُرسم مع مرور الوقت، أشرطة تنمو، عدّاد كبير يدق، محاور تُعيد ضبط القياس عندما تفاجئ البيانات، دبابيس توضيحية على اللحظات الرئيسية - تُصدَّر كملف MP4 بنسبة 9:16 أو 16:9 باستخدام HyperFrames وSVG وGSAP. استخدمها كلما أراد أحد تحريك الإحصاءات، إظهار اتجاه، نمو أو تكلفة عبر الزمن، مقارنة الأرقام، تفصيل رقم (راتب، ميزانية، معيار)، أو تحويل مجموعة بيانات أو جدول إلى فيديو قصير مُروي. ليست للعمارة أو تدفقات الطلبات (استخدم system-diagram-animation) أو الفيديوهات النصية فقط (استخدم kinetic-typography).
