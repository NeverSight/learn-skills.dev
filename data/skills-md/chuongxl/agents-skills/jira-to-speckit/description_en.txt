Use when work starts from a Jira issue key or Jira URL and a caller (typically `speckit-auto`) needs a clean, size-bounded intake brief to drive its own spec/plan/task pipeline. This skill is a pure Jira reader — it fetches one issue using `.env` credentials, compacts it into a Speckit-ready brief (title, business goal, acceptance criteria, constraints, open questions) plus a Jira-key-based feature name, and optionally writes a full-fidelity ticket snapshot file. It does not run Speckit stages, review loops, git operations, or track execution progress.
