Используется, когда работа начинается с ключа задачи Jira или URL Jira, а вызывающему (обычно `speckit-auto`) нужен чистый, ограниченный по размеру вводный бриф для управления своим собственным конвейером спецификации/плана/задачи. Этот навык — чистый читатель Jira: он получает одну задачу, используя учётные данные из `.env`, упаковывает её в готовый к Speckit бриф (заголовок, бизнес‑цель, критерии приёма, ограничения, открытые вопросы) плюс название функции, основанное на ключе Jira, и при желании записывает полный снимок тикета в файл. Он не запускает стадии Speckit, циклы обзора, операции с git или отслеживание прогресса выполнения.
