Exécutez une analyse de sécurité complète, 100 % gratuite, sur les dépôts de services de n’importe quelle équipe. L’identité de l’équipe, la liste des dépôts, la pile technologique, le runner CI et les listes blanches sont tous lus à partir d’un seul fichier de configuration repository.md — aucune valeur codée en dur dans la compétence elle-même. Combine Gitleaks (secrets dans l’historique Git), Trivy (CVE + mauvaise configuration Dockerfile), Semgrep (SAST pour TypeScript/NestJS/OWASP), Hadolint (meilleures pratiques Dockerfile), OSV‑Scanner (base de données transitive CVE de Google), TruffleHog (vérification en direct des identifiants) et une vérification hors ligne Shai‑Hulud (ver npm/PyPI : versions compromises connues, fichiers payload, workflows implantés, hooks d’installation de type ver) pour les dépôts et, avec --host, cet ordinateur. Produit un rapport de sécurité structuré par dépôt. Utilisez‑le lorsqu’on vous demande d’analyser les vulnérabilités, les secrets, les maliciels, les mauvaises configurations, les problèmes de chaîne d’approvisionnement, ou pour mettre en place un pipeline de sécurité CI, ou pour vérifier si un dépôt ou un ordinateur portable a été touché par Shai‑Hulud. Prend en charge --repo pour une portée à dépôt unique et --scanner pour des exécutions avec un seul outil.
