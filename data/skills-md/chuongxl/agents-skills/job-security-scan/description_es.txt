Ejecución de un escaneo de seguridad integral, 100 % gratuito, en los repositorios de servicios de cualquier equipo. La identidad del equipo, la lista de repositorios, la pila tecnológica, el ejecutor CI y las listas blancas se leen todas de un único archivo de configuración repository.md — sin valores codificados en la propia habilidad. Combina Gitleaks (secretos en el historial de git), Trivy (CVE + configuraciones erróneas en Dockerfile), Semgrep (SAST para TypeScript/NestJS/OWASP), Hadolint (mejores prácticas para Dockerfile), OSV‑Scanner (base de datos transitoria de CVE de Google), TruffleHog (verificación en vivo de credenciales) y una comprobación offline Shai‑Hulud (gusano npm/PyPI: versiones comprometidas conocidas, archivos de carga útil, flujos de trabajo plantados, ganchos de instalación tipo gusano) para repositorios y, con --host, este equipo. Genera un informe de seguridad estructurado por repositorio. Utilízalo cuando se solicite escanear en busca de vulnerabilidades, secretos, malware, configuraciones erróneas, problemas de cadena de suministro, o para crear una canalización de seguridad CI, o para comprobar si un repositorio o laptop fue afectado por Shai‑Hulud. Soporta --repo para alcance de un solo repositorio y --scanner para ejecuciones de una sola herramienta.
