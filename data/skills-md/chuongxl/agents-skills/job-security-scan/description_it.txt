Esegui una scansione di sicurezza completa, al 100 % gratuita, su tutti i repository di servizio di qualsiasi team. L’identità del team, l’elenco dei repository, lo stack tecnologico, il runner CI e le whitelist vengono letti da un unico file di configurazione repository.md — nessun valore hard‑coded nella skill stessa. Combina Gitleaks (segreti nella cronologia di Git), Trivy (CVE + configurazioni errate del Dockerfile), Semgrep (SAST per TypeScript/NestJS/OWASP), Hadolint (best practice per Dockerfile), OSV‑Scanner (database CVE transitivo di Google), TruffleHog (verifica in tempo reale delle credenziali) e un controllo offline Shai‑Hulud (worm npm/PyPI: versioni compromesse note, file payload, workflow inseriti, hook di installazione simili a worm) per i repository e, con --host, per questo computer. Produce un report di sicurezza strutturato per ogni repository. Usalo quando ti viene chiesto di scansionare vulnerabilità, segreti, malware, configurazioni errate, problemi della catena di fornitura, o per impostare una pipeline di sicurezza CI, o per verificare se un repository o un laptop è stato colpito da Shai‑Hulud. Supporta --repo per ambito a singolo repository e --scanner per esecuzioni con singolo strumento.
