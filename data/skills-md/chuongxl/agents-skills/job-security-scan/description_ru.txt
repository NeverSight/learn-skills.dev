Выполните комплексное, полностью бесплатное сканирование безопасности всех репозиториев сервисов любой команды. Идентификация команды, список репозиториев, технологический стек, CI‑раннер и белые списки читаются из одного конфигурационного файла repository.md — в самом навыке нет жёстко заданных значений. Объединяет Gitleaks (секреты в истории git), Trivy (CVE + неправильные настройки Dockerfile), Semgrep (SAST для TypeScript/NestJS/OWASP), Hadolint (рекомендации по Dockerfile), OSV‑Scanner (транзитивная база CVE от Google), TruffleHog (проверка действительных учётных данных в реальном времени) и офлайн‑проверку Shai‑Hulud (npm/PyPI‑червь: известные компрометированные релизы, файлы‑полезные нагрузки, внедрённые workflow, червеподобные хуки установки) для репозиториев и, с параметром --host, этого компьютера. Создаёт структурированный отчёт по безопасности для каждого репозитория. Используйте, когда требуется просканировать на уязвимости, секреты, вредоносное ПО, неправильные конфигурации, проблемы цепочки поставок, либо настроить CI‑pipeline безопасности, либо проверить, поражён ли репозиторий или ноутбук Shai‑Hulud. Поддерживает параметр --repo для сканирования отдельного репозитория и --scanner для запуска отдельного инструмента.
