Run a comprehensive, 100% free security scan across any team's service repos. Team identity, repo list, tech stack, CI runner, and allowlists are all read from a single repository.md config file — no hardcoded values in the skill itself. Combines Gitleaks (secrets in git history), Trivy (CVE + Dockerfile misconfig), Semgrep (SAST for TypeScript/NestJS/OWASP), Hadolint (Dockerfile best practices), OSV-Scanner (Google transitive CVE DB), TruffleHog (live credential verification), and an offline Shai-Hulud check (npm/PyPI worm: known compromised releases, payload files, planted workflows, worm-like install hooks) for repos and, with --host, this computer. Produces a structured security report per repo. Use when asked to scan for vulnerabilities, secrets, malware, misconfigurations, supply chain issues, or to set up a CI security pipeline, or to check whether a repo or laptop was hit by Shai-Hulud. Supports --repo for single-repo scope and --scanner for single-tool runs.
