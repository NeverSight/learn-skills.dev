Use when a project has no scripted way to prove UI/CLI/service behavior end to end, or when an existing generated verify-<app> skill needs a new or updated feature added to its map. Generates (or incrementally updates) a project-local verification skill (.agents/skills/verify-<app>/) that launches the real app, drives one feature the way a user would, and captures evidence. Triggers include "make a control skill for this repo" and being invoked by speckit-auto's Stage 05 with an already-generated skill present.
