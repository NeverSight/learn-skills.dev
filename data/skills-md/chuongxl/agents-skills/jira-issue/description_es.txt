Úsalo cuando el usuario quiera crear una incidencia en Jira o actualizar una existente a partir de una solicitud en lenguaje natural — por ejemplo, `/jira-issue create a ticket for…`, “update PAYR-31 to add…”, “file a bug in Jira for…”, “log this as a Jira story”. No es para leer o resumir solo un ticket (ver jira-to‑speckit) ni para ningún otro gestor de tareas que no sea Jira.

Por favor, responde siempre en el idioma del usuario.
