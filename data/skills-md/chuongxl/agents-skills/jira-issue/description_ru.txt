Используйте, когда пользователь хочет создать задачу в Jira или обновить уже существующую из запроса на естественном языке — например, `/jira-issue create a ticket for...`, «update PAYR-31 to add...», «file a bug in Jira for...», «log this as a Jira story». Не предназначено только для чтения/резюмирования задачи (см. jira-to-speckit) или для любых других систем трекинга задач, не относящихся к Jira.

Пожалуйста, всегда отвечайте на языке пользователя.
