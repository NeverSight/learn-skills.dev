Use when the user wants a Jira issue created or an existing one updated from a natural-language request — e.g. `/jira-issue create a ticket for...`, "update PAYR-31 to add...", "file a bug in Jira for...", "log this as a Jira story". Not for reading/summarizing a ticket only (see jira-to-speckit) or for any non-Jira task tracker.
