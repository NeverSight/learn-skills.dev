針對 `specs/<feature-folder>/spec.md` 中的功能規格進行深入逐行程式碼審查，規格由 `speckit.specify`（GitHub Spec Kit）或 `superpowers:brainstorming` 產出。產出嚴格的 JSON 通過/失敗結果，包含業務覆蓋、缺失需求、程式碼問題、安全問題、架構問題以及單元測試覆蓋率。觸發詞：`"speckit code review"`、`"review with spec"`、`"compare code to spec.md"`、`"spec coverage audit"`、`"invoke speckit-code-review"`、`"run speckit-code-review"`。請始終以使用者的語言回覆。
