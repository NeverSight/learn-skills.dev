Глубокий построчный обзор кода в соответствии со спецификацией функции, расположенной в specs/<feature-folder>/spec.md, созданной либо с помощью speckit.specify (GitHub Spec Kit), либо superpowers:brainstorming.  
Создаёт строгий JSON‑отчёт о проходе/непроходе с покрытием бизнес‑требований, отсутствующими требованиями, проблемами кода, проблемами безопасности, архитектурными проблемами и покрытием модульных тестов.  
Триггеры: «speckit code review», «review with spec», «compare code to spec.md», «spec coverage audit», «invoke speckit-code-review», «run speckit-code-review».
