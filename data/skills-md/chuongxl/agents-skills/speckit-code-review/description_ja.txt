specs/<feature-folder>/spec.md にある機能仕様に対する深い行単位のコードレビュー、  
speckit.specify（GitHub Spec Kit）または superpowers:brainstorming のいずれかで生成されたもの。  
ビジネスカバレッジ、欠落要件、コード問題、セキュリティ問題、アーキテクチャ問題、ユニットテストカバレッジを含む、厳格な JSON の合格/不合格を生成します。
