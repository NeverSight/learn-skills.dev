Elabora gli input grezzi (trascrizioni, appunti di riunioni, PDF, slide, scarabocchi mentali) da una coda `_inbox/` in una singola nota markdown curata per ogni input e proponi record di memoria su tre livelli di ambito — progetto, cliente e un diario inter‑clienti. Utilizza ogni volta che l’utente vuole processare la inbox, curare le note, svuotare l’inbox, cristallizzare un candidato alla memoria, promuovere qualcosa alla memoria o a un diario — anche se non dice “skill” o non nomina un tipo di file. Usalo anche per impostare il substrato di un nuovo progetto, cliente o del diario — scaffolding di un nuovo progetto qui, impostare il substrato delle note, avviare un cliente, configurare il diario, creare una banca di memoria qui. Gli scaffold di cliente e progetto usano per impostazione predefinita uno schema di memoria leggero a 3 tipi (Decisione/Contesto/Regola) con un’opzione canonica a 4 tipi; producono inoltre un README, `_personal.md`, `working-state.md` (ambito progetto) e una cartella `patterns-journal/`. Funziona solo su directory opt‑in (che contengono `_memory/` o `entries/`, più un `_inbox/` a quel livello o sotto `notes/`).
