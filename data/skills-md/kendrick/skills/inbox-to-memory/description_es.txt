Procesa entradas crudas (transcripciones, notas de reuniones, PDFs, presentaciones, borradores de ideas) desde una cola `_inbox/` en una nota markdown cuidada por cada entrada, y propone registros de memoria en tres niveles de alcance: proyecto, cliente y un diario transcliente. Úsalo siempre que el usuario quiera procesar la bandeja de entrada, pulir notas, vaciar la bandeja, cristalizar un candidato a memoria, promover algo a memoria o a un diario — incluso si no dice “skill” o nombra un tipo de archivo. También sirve para establecer la base de un nuevo proyecto, cliente o el diario — crear la estructura de un nuevo proyecto aquí, preparar la base de notas, iniciar un cliente, configurar el diario, crear un banco de memoria aquí. Los esqueletos de cliente y proyecto usan por defecto un esquema de memoria ligero de 3 tipos (Decisión/Contexto/Regla) con una opción canónica de 4 tipos; también generan un README, `_personal.md`, `working-state.md` (alcance del proyecto) y un `patterns-journal/`. Solo funciona en directorios habilitados (que contengan `_memory/` o `entries/`, más un `_inbox/` en ese nivel o bajo `notes/`).
