处理来自 `_inbox/` 队列的原始输入（文字稿、会议记录、PDF、幻灯片、草稿脑图），为每个输入生成一篇整理好的 Markdown 笔记，并在三个范围层级——项目、客户和跨客户日志——中提出记忆记录。只要用户想要处理收件箱、整理笔记、清空收件箱、结晶记忆候选、将某项提升为记忆或日志时，都使用此功能——即使他们没有说 “skill” 或指明文件类型。也用于为新项目、客户或日志搭建底层结构——在这里搭建新项目、设置笔记底层、启动客户、创建日志、建立记忆库。客户和项目脚手架默认采用轻量的三类记忆模式（Decision/Context/Rule），并配备一个标准的四类选项；它们还会生成 README、`_personal.md`、`working-state.md`（项目范围）以及 `patterns-journal/`。仅在已加入选项的目录（包含 `_memory/` 或 `entries/`，并在该层级或 `notes/` 下拥有 `_inbox/`）中运行。
