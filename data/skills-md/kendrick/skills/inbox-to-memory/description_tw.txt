從 `_inbox/` 隊列中處理原始輸入（文字稿、會議記錄、PDF、簡報、隨手筆記），每個輸入產生一篇整理過的 Markdown 筆記，並在三個範圍層級——專案、客戶、跨客戶日誌——提出記憶記錄。無論使用者是否說「skill」或指明檔案類型，只要使用者想要處理收件匣、整理筆記、清空收件匣、結晶記憶候選、將某物提升為記憶或日誌時，都使用此功能。同時也用於為新專案、客戶或日誌建立基底——在此搭建新專案、設置筆記基底、啟動客戶、設置日誌、建立記憶庫。客戶與專案的腳手架預設使用輕量的三類記憶架構（Decision/Context/Rule），並提供一個標準的四類選項；它們同時會產生 README、`_personal.md`、`working-state.md`（專案範圍）以及 `patterns-journal/`。僅在已選擇的目錄（包含 `_memory/` 或 `entries/`，以及該層級或 `notes/` 之下的 `_inbox/`）中運作。
