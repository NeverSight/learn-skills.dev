Переведите одну задачу GitHub из её утверждённого плана в pull request, в котором все ветки обсуждения отвечены, продолжая с того места, где предыдущий вызов остановился. Используйте, когда у задачи есть утверждённый план и её нужно собрать, опубликовать и ответить на ветки обсуждения, или когда оркеструющая функция запускает одну задачу как lane. Она никогда не планирует задачу и никогда её не сливает: для планирования используйте writing-plans; для выполнения плана без задачи используйте divvy-up.
