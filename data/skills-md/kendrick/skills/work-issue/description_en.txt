Advance one GitHub issue from its approved plan to a pull request whose review threads are answered, resuming from wherever a previous invocation left it. Use when one issue has an approved plan and should be built, published, and its review threads answered, or when an orchestrating skill runs one issue as a lane. It never plans an issue and never merges one: to plan, use writing-plans; to run a plan that has no issue, use divvy-up.
