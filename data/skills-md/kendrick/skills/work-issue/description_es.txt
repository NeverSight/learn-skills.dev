Avanza un issue de GitHub desde su plan aprobado a una pull request cuyas hilos de revisión estén respondidos, reanudando desde donde la invocación anterior lo dejó. Usa esto cuando un issue tiene un plan aprobado y debe ser construido, publicado y sus hilos de revisión respondidos, o cuando una habilidad orquestadora ejecuta un issue como una lane. Nunca planifica un issue y nunca lo fusiona: para planificar, usa writing-plans; para ejecutar un plan que no tiene issue, usa divvy-up.
