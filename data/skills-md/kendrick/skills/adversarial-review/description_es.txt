Revisión adversarial de un diff de git, donde un hallazgo debe reproducirse antes de que pueda bloquear, por algo que no lo creó y por una ruta que el código no sigue. Úsalo cuando los hallazgos de un diff deben probarse antes de bloquear una fusión, cuando el usuario solicita red‑teamear una rama, o cuando otra habilidad necesita que un diff sea revisado bajo ese criterio. Para una revisión general de paso único utiliza code-review, para un escaneo de vulnerabilidades a nivel de repositorio utiliza security-review, y para probar bajo presión un plan utiliza grilling.
