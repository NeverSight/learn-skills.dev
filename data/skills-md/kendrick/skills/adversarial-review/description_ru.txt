Противоборственный обзор git‑diff, при котором найденное должно быть воспроизведено до того, как оно сможет блокировать, выполнено субъектом, не являющимся его автором, и по пути, который код не использует. Используйте, когда выводы diff‑а должны быть доказаны перед блокировкой слияния, когда пользователь просит провести red‑team ветки, или когда другому навыку нужен diff, проверенный по этим критериям. Для общего одноразового обзора используйте code‑review, для сканирования уязвимостей по всему репозиторию — security‑review, а для стресс‑тестирования плана — grilling.
