GitHub 이슈 하나를 파일링합니다: 버그 보고서, 기능 요청, 작업 또는 스파이크를 `gh`로 생성합니다. 사용자는 이슈를 제출하거나 열고 싶을 때, 버그를 보고하고 싶을 때, 기능을 요청하고 싶을 때, 잡일이나 스파이크를 작성하고 싶을 때, 반쯤 형성된 불만을 추적 가능한 것으로 바꾸고 싶을 때, 혹은 코딩 에이전트가 바로 가져갈 수 있는 이슈를 작성하고 싶을 때 사용합니다. 정확히 하나의 이슈만 파일링합니다: 사양이나 계획을 여러 연결된 티켓으로 나누고 싶다면 대신 to‑tickets를 사용하세요. 기존 이슈를 편집, 닫기, 트라이지, 순위 매기지는 절대 하지 않습니다. 생성 이후에는 새 이슈를 부모 이슈 및 블로커와 연결하고 본문에서 연결된 항목을 제거합니다.
