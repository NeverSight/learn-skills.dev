`gh` を使って GitHub の課題を 1 件作成します：バグ報告、機能リクエスト、タスク、またはスパイクです。ユーザーが課題を作成または開きたい、バグを報告したい、機能をリクエストしたい、雑務やスパイクを記述したい、未成熟な不満を追跡可能な形にしたい、またはコーディングエージェントがすぐに取り掛かれる課題を書きたいときに使用します。正確に 1 つの課題を作成します。仕様や計画を多数のリンクされたチケットに分割したい場合は、代わりに to‑tickets を使用してください。既存の課題を編集、クローズ、トリアージ、または順位付けすることはありません。作成以外では、新しい課題を親課題やブロッカーにリンクし、本文からリンクされたエントリを削除するだけです。常にユーザーの言語で返答してください。
