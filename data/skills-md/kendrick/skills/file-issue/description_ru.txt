Создайте один issue на GitHub: сообщение об ошибке, запрос функции, задачу или исследовательскую задачу (spike), созданные с помощью `gh`. Используйте, когда пользователь хочет создать или открыть issue, сообщить об ошибке, запросить функцию, оформить работу или исследование, превратить полуобразную жалобу в отслеживаемый элемент или написать задачу, которую кодирующий агент может сразу взять. Создаёт ровно один issue: чтобы разрезать спецификацию или план на множество связанных тикетов, используйте to‑tickets. Никогда не редактирует, не закрывает, не триажит и не ранжирует существующие issues. За пределами создания он только связывает новый issue с его родителем и блокирующими, затем удаляет связанные записи из тела.
