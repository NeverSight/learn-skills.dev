الموجه الأعلى لواجهة برمجة التطبيقات REST لمنصة Databricks وSDK بايثون. استخدمه لأي مهمة تتعلق بواجهة برمجة التطبيقات أو SDK الخاصة بـ Databricks: Unity Catalog (الفهارس، المخططات، الجداول، الصلاحيات، السلالة، مراقبي الجودة)، الوظائف وتدفقات العمل، مستودعات SQL وتنفيذ العبارات، تقديم النماذج وبوابة الذكاء الاصطناعي، مشاركة Delta، Genie، Marketplace، أو إدارة الملفات على الأحجام وDBFS. استخدمه أيضًا عندما لا تكون متأكدًا أي واجهة برمجة تطبيقات Databricks تملك المهمة.
