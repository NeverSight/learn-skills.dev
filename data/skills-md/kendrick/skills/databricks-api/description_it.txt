Router di livello superiore per le API REST della piattaforma Databricks e per l'SDK Python. Da utilizzare per qualsiasi attività su API o SDK di Databricks: Unity Catalog (cataloghi, schemi, tabelle, autorizzazioni, lineage, monitor di qualità), Jobs e Workflows, magazzini SQL e esecuzione di istruzioni, Model Serving e AI Gateway, Delta Sharing, Genie, Marketplace o gestione dei file su volumi e DBFS. Da utilizzare anche quando non si è sicuri quale API di Databricks gestisce l’attività.
