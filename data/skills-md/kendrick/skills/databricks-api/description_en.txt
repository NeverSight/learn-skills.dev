Top-level router for Databricks platform REST APIs and the Python SDK. Use for any Databricks API or SDK task: Unity Catalog (catalogs, schemas, tables, grants, lineage, quality monitors), Jobs and Workflows, SQL warehouses and statement execution, Model Serving and AI Gateway, Delta Sharing, Genie, Marketplace, or file management on volumes and DBFS. Also use when you're not sure which Databricks API owns the task.
