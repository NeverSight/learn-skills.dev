Routeur de niveau supérieur pour les API REST de la plateforme Databricks et le SDK Python. À utiliser pour toute tâche d’API ou de SDK Databricks : Unity Catalog (catalogues, schémas, tables, autorisations, traçabilité, moniteurs de qualité), Jobs et Workflows, entrepôts SQL et exécution d’instructions, Model Serving et AI Gateway, Delta Sharing, Genie, Marketplace, ou gestion des fichiers sur les volumes et DBFS. À utiliser également lorsque vous n’êtes pas sûr de l’API Databricks qui possède la tâche.
