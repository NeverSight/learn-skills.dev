Verwenden Sie vor der Implementierung der Benutzeroberfläche/des Designs ein Artefakt, das als gewünschte visuelle Referenz bereitgestellt wird, z. B. ein Screenshot, ein CodePen, ein Dribbble-Schuss, eine Website oder eine „Lass es sich so anfühlen“-Anfrage. Screenshots, die nur dazu dienen, auf einen Fehler hinzuweisen, bleiben im normalen Überprüfungspfad. Verhindert Cargo-Culting-Mechaniken, gefälschtes UI-Chrome und Code-First-Fehler, indem vor der Implementierung eine Referenzaufschlüsselung, eine Benutzerfragenkalibrierung, eine visuelle Zielgenehmigung und eine parallele Überprüfung erzwungen werden.
