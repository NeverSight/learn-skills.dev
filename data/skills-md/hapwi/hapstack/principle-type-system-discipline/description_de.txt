Wenden Sie es an beim Entwerfen von Typen, beim Überprüfen einer Funktionssignatur oder beim Schreiben von Code in einer beliebigen statisch typisierten Sprache. Machen Sie illegale Zustände nicht darstellbar, branden Sie semantische Primitive, parsen Sie externe Daten an den Grenzen, weigern Sie sich, den Compiler zu belügen, erschöpfen Sie Varianten und leiten Sie von autoritativen Schemata ab.
