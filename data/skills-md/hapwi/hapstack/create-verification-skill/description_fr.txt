Générez une compétence de vérification locale au projet qui pilote votre application comme le ferait un utilisateur — quel que soit le langage, le framework ou la plateforme. Utilisez‑la pour /create-verification-skill, « créez une compétence de contrôle pour ce dépôt », ou lorsqu’un projet n’a aucun moyen scripté de prouver le comportement de l’UI/CLI/service.

Veuillez toujours répondre dans la langue de l’utilisateur.
