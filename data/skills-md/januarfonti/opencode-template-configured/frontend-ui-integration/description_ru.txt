Реализовать или расширить пользовательский рабочий процесс в веб‑приложении, интегрируя его с существующими API бэкенда. Использовать, когда функция в основном представляет собой изменение UI/UX, поддерживаемое существующими API, затрагивает только веб‑фронтенд и требует соблюдения системы дизайна, маршрутизации и конвенций тестирования.
