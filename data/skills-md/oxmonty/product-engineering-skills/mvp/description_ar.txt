قُم بإجراء مقابلة مع المستخدم قسمًا بقسم لإنشاء أو تحديث وثيقة تصميم MVP (خريطة الطريق + PRD) باستخدام قالب منظم، ثم سلمها إلى مهارات حلقة البناء المرافقة. استخدم ذلك كلما أراد المستخدم تعريف أو تحديد أو تخطيط أو توثيق MVP أو مشروعًا جانبيًا أو أداة جديدة؛ أو طلب "ملء" أو إنشاء ملفات mvp.md / ROADMAP.md / PRD.md؛ أو رغب في وضع علامة على عناصر خريطة الطريق بعد إكمال العمل؛ أو طلب تحديث وثائق المشروع بعد إجراء تغيير. استخدمها أيضًا عندما يقول المستخدم عبارات مثل "لِنحدد هذا"، "قابلني حول هذا المشروع"، "حدّث خريطة الطريق"، أو "علامة E2 تم إنجازه".
