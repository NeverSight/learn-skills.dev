Оперировать рабочими деревьями, управляемыми Orca, контекстами папок, терминалами, репозиториями, автоматизациями, артефактами, обменом навыков, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Использовать, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff» / «handover» / «give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочитать это вместо обычного git worktree, ad hoc PTY или функции Computer Use, когда задействовано состояние Orca. Использовать Computer Use только тогда, когда необходимо управлять видимым окном GUI, которое нельзя контролировать с помощью CLI, файловой системы или API.
