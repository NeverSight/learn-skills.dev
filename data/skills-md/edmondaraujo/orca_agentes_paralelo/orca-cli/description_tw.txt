透過 `orca` CLI 操作 Orca 所管理的工作樹、資料夾情境、終端機、儲存庫、自動化流程、產出物、技能分享、工作樹註解，以及 Orca 內嵌的瀏覽器。當使用者提到「$orca-cli」或「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時即使用此方式。若涉及 Orca 狀態，請優先使用此方法，而非純 git 工作樹、臨時 PTY，或 Computer Use。只有在需要 GUI 控制且 CLI、檔案系統或 API 無法處理可見視窗時，才使用 Computer Use。

請始終以使用者的語言回覆。
