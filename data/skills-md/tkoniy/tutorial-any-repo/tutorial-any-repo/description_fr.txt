Générez automatiquement un site Web de tutoriel code fichier par fichier pour n'importe quel dépôt. Explore la structure du code, crée un suivi TODO, lance des équipes d'agents parallèles pour rédiger la documentation, s'auto‑revue, et déploie sur GitHub Pages. Utilisez-le lorsque l'utilisateur dit « écrire un tutoriel pour ce projet », « expliquer cette base de code », « générer de la documentation du code », etc.

Veuillez toujours répondre dans la langue de l'utilisateur.
