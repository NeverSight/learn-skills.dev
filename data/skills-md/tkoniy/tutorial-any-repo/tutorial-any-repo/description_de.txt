Automatisch eine dateiweise Code‑Tutorial‑Website für jedes Repository erstellen. Erforscht die Struktur der Codebasis, erstellt TODO‑Tracking, startet parallele Agententeams zum Schreiben von Dokumentationen, führt Selbst‑Reviews durch und deployt zu GitHub Pages. Verwenden, wenn der Benutzer sagt „write a tutorial for this project“, „explain this codebase“, „generate code docs“ usw.

Bitte immer in der Sprache des Benutzers antworten.
