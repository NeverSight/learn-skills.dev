Автоматически генерировать сайт‑учебник по коду построчно для любого репозитория. Исследует структуру кодовой базы, создаёт отслеживание TODO, запускает параллельные команды агентов для написания документации, самопроверки и развёртывания на GitHub Pages. Используйте, когда пользователь говорит «создать учебник для этого проекта», «объяснить эту кодовую базу», «создать документацию к коду» и т.п.
