# PHYLAB-Report

交付可编辑、数据可追溯、便于老师扫读的中文 Typst 实验报告。正文采用实验者视角和自然短句，默认只交付源文件，PDF 按当前任务的明确要求导出。

## 按请求确定范围

- 只要计划：先列报告结构、所需数据和处理方法，不直接写成完整报告。
- 预习报告：先读 [prelab.md](references/prelab.md)，按本次预习模板填写栏目，说明原理、计划方法、学习重点与操作难点；无实测数据也可完成，不套用正式报告的结果与误差章节。
- 正式报告尚无数据：完成目的、原理、步骤及不依赖实测数据的思考题；数据、结果和误差结论留空，不编造实测。
- 正式报告已有数据：核对原始记录，完成计算、软件作图、不确定度和实验探讨。
- 修改或评阅：先读用户最新文件，保留其短句和删减；只处理指定部分。只要求评阅时不擅自改写。
- 用户要求导出：导出指定报告并检查成品；已有 PDF 或以前的导出授权不代表每次编辑都要重新导出。

开始时查看项目 `AGENTS.md` 和文件目录。[project-conventions.md](references/project-conventions.md) 提供可调整的目录、模板、排版及命名起点；处理误差时读 [uncertainty.md](references/uncertainty.md)。路径与课程要求以当前项目为准。

## 资料与数据

1. 先读当前课件、老师要求和原始记录。通用评分、修约要求查当前课程的绪论或实验指导，正文直接使用规则。
2. 建立读数与照片的对应关系，保留单位、有效位数、环境条件和特征位置判据。封面信息按当前作者与本次实验核对，不复制参考报告的姓名、学号、班级、日期、桌号或周次。
3. 可疑读数向用户集中核对，同时继续不依赖它们的部分。不能用递增规律、参考值或手算结果替代原始读数；不为得到更小误差而剔除数据。
4. 课件例题、参考报告数据和本次实测分开保存。更正读数后同步核对数据文件、表格、计算与图；必要更正用一句话说明。

数据保存于 `data/`，计算脚本、结果 JSON 和软件图放在 `analysis/`。复用适用脚本，不将上一实验的读数、常数或借用参数套入新实验。

## 照片与图表

- 原始照片保留完整版本。按实验内容命名，另存报告可用格式；显示时去掉多余背景，保留完整曲线、坐标、单位、档位及有测量意义的光标信息。实测波形和读数不做生成式重绘、修饰或补全。
- 逐张核对实验项目、通道、频率比或测量状态与图注。重复照片、不同相位、缺失项目按实际情况标注，不把照片数量当作不同测量组数，也不借用遗留光标作为本组测量。
- 区分实拍、由读数计算的图和理想模型示意。归一化幅值、示意初相位、假设的超前或滞后方向在图注或相邻正文说明一次；不能将模型设定写成实测结论。
- 用 Python、NumPy、Matplotlib 或合适工具作科学图。标题、坐标、图例、标识采用中文并标单位；公式符号保留。检查实际字体与渲染。

## 计算与误差分析

- 保留未修约中间值；正文列关键公式、必要代入和集中结果表。改正原手算错误时简短说明。
- 先确认测量模型和特征间距，再套公式。例如相位法同斜率直线间距为一个波长，正、负斜率交替位置间距为半波长。
- 拟合给出斜率的物理意义、关键参数及相关性，用残差检查模型和漂移。较高相关系数不能单独证明没有系统偏差。
- 区分标称偏差、统计散布、A/B 类及合成不确定度。传播公式写清独立性条件；共同零点或比例误差考虑抵消与相关性，不重复计入。标准不确定度不直接当作置信区间。
- 数值不确定度使用实际精度、重复读数或明确注明的借用参数；未知分量不默认为零。单位、公式和修约独立复核，同组数据的不同算法不作为独立实验平均。

## 学生视角与简洁写作

- 正文围绕实际操作、观察、读数、计算依据和结论展开，可用“本次”“本组”，不强行每句使用“我”。写成作者的实验报告，不写成代写过程说明。
- 编辑安排放在对话的交付说明中。例如“扫描时基检验未开展，故仅在预习部分保留方法说明，不列该项测量数据或结果。”不进入报告正文。未做项目不编造数据，也不为解释章节取舍额外写一段；教师要求交代完成情况时，只陈述实验事实。
- 必要限制从实验记录出发简短表达，例如“未记录相位方向，本次只计算相位差大小”。保留物理适用条件与数据不足的影响，避免“用户未提供”“暂留待补充”“本报告仅保留”等助手视角的措辞。
- 用完整自然句展开条目，每条一个问题；避免固定的“加粗概括词＋解释”格式，如“统计条件。……”“系统偏差。……”。少分层，不为一两句话加小标题。
- 让图表和公式承担数据，正文只解释判据、条件、结论及必要依据。同一数字、更正、模型限制和舍入比较集中说明，不在多处复述；删去铺垫、套话和反复提醒。
- 实验探讨每点通常两句、排版后约两行，按实际字号和幅面调整，不凑字数。围绕本次现象或方法差别，说明可能原因并提出可检验的改进；未证实的原因保留“可能”，未做的操作写为复测建议。
- 按用户最新文字的长度和语气校准；已有删减不自动恢复。实际课程字数要求优先，必要推导保持连续完整。

例如：“六组结果接近，但偏离标称值的来源尚不能确定。复测时用独立频率计分别核验两路信号，判断偏差来自哪一路。”

## 排版、检查与交付

- 在目标 `.typ` 中局部调样式，保护共享模板与其他报告。正文首行缩进，标题、表格、图注和列表不缩进。
- 保持可读字号、行距和图片清晰度；减少无意义分页与大片留白，不强迫固定页数。表题与表格相邻，公式不溢出，短结论不跨页拆开，整个长章节允许分页。
- 未要求 PDF 时只编译 PNG 检查。明确要求 PDF 后，按当前项目约定和当前报告元数据命名导出，并重新打开、渲染导出的 PDF；不能用旧 PNG 代替成品检查。
- 最终逐页检查封面、原始记录、照片与图注、图表、公式、分页和页码。编译成功不等于排版正确。
- 交付简短说明改了什么、验证了什么及仍缺什么，附可点击链接。只要求检查时按发现的问题反馈；估分须说明当前评分依据和主要扣分点。

## 分享与复用

技能和引用文件只保存方法、写作偏好、相对路径与通用示例。姓名、学号、联系方式、本机用户名与绝对个人路径、真实日期桌号、个人授权历史及私人实验数据从当前项目读取，不固化进技能。

分享前检查整个技能目录，包括 `agents/` 与 `references/`；只分享技能文件，不附带个人报告、原始照片或数据。复用时根据同学的项目结构、课程要求和可用字体调整。
