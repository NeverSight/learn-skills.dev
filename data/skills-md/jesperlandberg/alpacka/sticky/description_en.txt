Eases position sticky in and out. The element slows down as it reaches its line and speeds up gradually when its container ends, instead of stopping and starting in one frame. Native sticky still does the pinning; this adds one offset on top as a scroll-driven animation. Use when asked to ease, smooth or soften a sticky element (a sidebar, a rail, a sticky heading, a pinned card), when someone says position sticky feels abrupt or snaps, or when asked for 'eased sticky', 'smooth sticky' or @alpacka/sticky. The implementation ships inside the skill as one file to copy in; there is no package to install.
