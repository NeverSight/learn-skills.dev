Konvertiere eine mehrseitige Excel‑Arbeitsmappe mit eingebetteten Bildern, Flussdiagrammen und Text in ein treues Markdown – ein PNG in Excel‑Qualität pro Blatt plus durchsuchbarer extrahierter Text (Durchgestrichenes erhalten). Verwende es, wenn der Benutzer eine .xlsx lesen, extrahieren, rendern oder konvertieren möchte (insbesondere bei gemischtem Text + Bildern, Screenshots, Fluss‑/Swimlane‑Diagrammen über viele Registerkarten), wenn Bilder unscharf oder über Seiten hinweg aufgeteilt erscheinen oder ein Tabellenblatt in klare Bilder oder Markdown umgewandelt werden muss.
