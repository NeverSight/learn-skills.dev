Analyse multi‑cadres temporels utilisant la méthode à 3 écrans pour les actions NSE/BSE. Le cadre temporel supérieur fixe le biais, le cadre principal identifie la configuration, le cadre inférieur synchronise l’entrée. Inclut un système de notation de convergence.

À utiliser lorsque l’utilisateur demande : « quelle est la tendance hebdomadaire », « quotidien vs hebdomadaire », « vérification multi‑cadres temporels », « analyse du cadre supérieur », « analyse à 3 écrans », « tendance sur différents cadres temporels », « biais hebdomadaire pour [action] », ou toute question concernant l’analyse d’une action sur plusieurs cadres temporels.
