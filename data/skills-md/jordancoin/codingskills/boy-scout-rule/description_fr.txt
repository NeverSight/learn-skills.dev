Lorsqu’on touche à du code existant et qu’on veut le laisser meilleur. À utiliser lorsque l’utilisateur dit « clean this up while I’m here », « should I fix this », « tech debt », « while I’m in this file » ou « incremental improvement ». Pour un refactoring complet, voir solid ou separation‑of‑concerns.

Veuillez toujours répondre dans la langue de l’utilisateur.
