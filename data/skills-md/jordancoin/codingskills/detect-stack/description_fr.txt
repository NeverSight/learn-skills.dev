Analysez une base de code pour détecter son langage, son framework, ses conventions et ses portes CI. Exécutez cela dès la première utilisation dans un projet afin de générer le contexte de la pile que toutes les compétences de principes de codage référencent. Utilisez‑le lorsque l'utilisateur dit « détecter la pile », « analyser ce projet » ou « quel est le codebase utilisé ». Veuillez toujours répondre dans la langue de l'utilisateur.
