Scandit ID Capture (`IdCapture`) en .NET para proyectos Android (`net*-android` como framework de destino, NuGet `Scandit.DataCapture.IdCapture`, C#) — escaneo de pasaportes, licencias de conducir, tarjetas de identificación, permisos de residencia, visas a través de MRZ, VIZ, código de barras PDF417 o documentos móviles. Úselo para la integración, configuración de documentos aceptados y del escáner, manejo del resultado CapturedId, reglas de rechazo, verificación AAMVA, anonimización, UI de superposición y migración de versiones del SDK .NET de Scandit — para aplicaciones MAUI (`<UseMaui>true</UseMaui>`) utilice id-capture-net-maui en su lugar.
