Scandit ID Capture (`IdCapture`) в .NET для Android‑проектов (целевой фреймворк `net*-android`, NuGet `Scandit.DataCapture.IdCapture`, C#) — сканирование паспортов, водительских удостоверений, удостоверений личности, видов на жительство, виз с помощью MRZ, VIZ, штрих‑кода PDF417 или мобильных документов. Используется для интеграции, настройки принимаемых документов и сканера, обработки результата CapturedId, правил отклонения, проверки AAMVA, анонимизации, пользовательского интерфейса оверлея и миграции версии Scandit .NET SDK — для приложений MAUI (`<UseMaui>true</UseMaui>`) используйте id-capture-net-maui.
