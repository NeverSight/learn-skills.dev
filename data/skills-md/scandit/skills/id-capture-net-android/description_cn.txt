Scandit ID Capture（`IdCapture`）在 .NET Android 项目（`net*-android` 目标框架，`Scandit.DataCapture.IdCapture` NuGet，C#）中 — 用于通过 MRZ、VIZ、PDF417 条形码或移动文档扫描护照、驾驶执照、身份证、居留许可、签证。用于集成、接受文档和扫描仪配置、CapturedId 结果处理、拒绝规则、AAMVA 验证、匿名化、覆盖 UI，以及 Scandit .NET SDK 版本迁移 — 对于 MAUI 应用（`<UseMaui>true</UseMaui>`）请改用 id-capture-net-maui。
