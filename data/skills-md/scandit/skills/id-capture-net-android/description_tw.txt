Scandit ID Capture (`IdCapture`) 在 .NET 用於 Android 專案（`net*-android` 目標框架，`Scandit.DataCapture.IdCapture` NuGet，C#）——可掃描護照、駕照、身分證、居留許可、簽證，支援 MRZ、VIZ、PDF417 條碼或行動文件。用於整合、接受文件與掃描器設定、CapturedId 結果處理、拒絕規則、AAMVA 驗證、匿名化、覆蓋 UI，以及 Scandit .NET SDK 版號遷移——對於 MAUI 應用程式（`<UseMaui>true</UseMaui>`）請改用 id-capture-net-maui。
