Scandit ID Capture (`IdCapture`) in .NET per progetti Android (`net*-android` framework di destinazione, NuGet `Scandit.DataCapture.IdCapture`, C#) — scansione di passaporti, patenti di guida, carte d'identità, permessi di soggiorno, visti tramite MRZ, VIZ, codice a barre PDF417 o documenti mobili. Utilizzarlo per l'integrazione, la configurazione di documenti accettati e dello scanner, la gestione del risultato CapturedId, le regole di rifiuto, la verifica AAMVA, l'anonimizzazione, l’interfaccia overlay e la migrazione della versione dello Scandit .NET SDK — per app MAUI (`<UseMaui>true</UseMaui>`) utilizzare id-capture-net-maui.
