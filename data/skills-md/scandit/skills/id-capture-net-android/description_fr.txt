Scandit ID Capture (`IdCapture`) en .NET pour les projets Android (`net*-android` framework cible, package NuGet `Scandit.DataCapture.IdCapture`, C#) — numérisation des passeports, permis de conduire, cartes d'identité, titres de séjour, visas via MRZ, VIZ, code à barres PDF417 ou documents mobiles. Utilisé pour l'intégration, la configuration des documents acceptés et du scanner, la gestion des résultats CapturedId, les règles de rejet, la vérification AAMVA, l'anonymisation, l'interface superposée, et la migration de version du SDK Scandit .NET — pour les applications MAUI (`<UseMaui>true</UseMaui>`) utilisez id-capture-net-maui à la place.
