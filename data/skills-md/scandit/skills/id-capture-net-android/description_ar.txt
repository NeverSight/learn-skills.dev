Scandit ID Capture (`IdCapture`) في .NET لمشاريع Android (إطار الهدف `net*-android`، حزمة NuGet `Scandit.DataCapture.IdCapture`، C#) — مسح جوازات السفر، رخص القيادة، بطاقات الهوية، تصاريح الإقامة، التأشيرات عبر MRZ أو VIZ أو باركود PDF417 أو المستندات المتنقلة. يُستخدم للتكامل، تكوين المستندات المقبولة والمسح الضوئي، معالجة نتيجة CapturedId، قواعد الرفض، التحقق من AAMVA، إخفاء الهوية، واجهة المستخدم المتراكبة، وترحيل نسخة Scandit .NET SDK — لتطبيقات MAUI (`<UseMaui>true</UseMaui>`) استخدم id-capture-net-maui بدلاً من ذلك.
