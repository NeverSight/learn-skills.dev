.NET向けAndroidプロジェクト（`net*-android` ターゲットフレームワーク、`Scandit.DataCapture.IdCapture` NuGet、C#）で使用する Scandit ID Capture（`IdCapture`）―― MRZ、VIZ、PDF417 バーコード、またはモバイル文書を利用したパスポート、運転免許証、身分証明書、居住許可証、ビザのスキャン。統合、受理文書およびスキャナー設定、CapturedId の結果処理、拒否ルール、AAMVA 検証、匿名化、オーバーレイ UI、そして Scandit .NET SDK のバージョン移行に使用します―― MAUI アプリ（`<UseMaui>true</UseMaui>`）の場合は代わりに id-capture-net-maui を使用してください。
