Capacitor MatrixScan Count (BarcodeCount) — плагин scandit‑capacitor‑datacapture‑barcode. Многократный подсчёт штрихкодов и рабочие процессы приёма (сканирование‑и‑подсчёт, инвентарный учёт, список захвата, режим статуса) с BarcodeCountView на DOM‑элементе в приложениях Capacitor, только нативно для iOS/Android. Для React Native используйте matrixscan‑count‑rn. Применяется для интеграции, настройки символики, обработки результатов, кастомизации представления или устранения неполадок в процессах подсчёта.
