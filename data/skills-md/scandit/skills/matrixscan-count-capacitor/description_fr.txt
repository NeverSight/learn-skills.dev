Capacitor MatrixScan Count (BarcodeCount) — plugin scandit-capacitor-datacapture-barcode. Flux de travail de comptage et de réception multi-code‑barres (scan‑and‑count, comptage d’inventaire, capture de liste, mode statut) avec BarcodeCountView sur un élément DOM dans les applications Capacitor, uniquement natif iOS/Android. Pour React Native, utilisez matrixscan-count-rn. À utiliser pour l’intégration, la configuration des symbologies, la gestion des résultats, la personnalisation de la vue ou le dépannage des flux de comptage.
