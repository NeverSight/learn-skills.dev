Smart Label Capture (Scandit `LabelCapture`) en .NET para proyectos iOS (`net*-ios` framework objetivo, NuGet `Scandit.DataCapture.Label`, C#) — extracción de múltiples campos (precio, fecha de caducidad, número de serie o lote, peso) de una etiqueta en un solo escaneo mediante código de barras y campos de texto. Úselo para integración, definiciones de etiquetas (incluyendo VIN predefinido, etiqueta de precio, 7 segmentos), manejo de sesiones capturadas, superposiciones, el Flujo de Validación y la migración de versiones del SDK .NET de Scandit — para aplicaciones MAUI (`<UseMaui>true</UseMaui>`) use label-capture-net-maui en su lugar.
