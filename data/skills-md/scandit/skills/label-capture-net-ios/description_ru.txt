Smart Label Capture (Scandit `LabelCapture`) в .NET для iOS‑проектов (`net*-ios` целевая платформа, NuGet `Scandit.DataCapture.Label`, C#) — извлечение нескольких полей (цена, срок годности, серийный или номер партии, вес) с этикетки за один скан через штрих‑код и текстовые поля. Используется для интеграции, определений этикеток (включая готовые VIN, ценовую этикетку, 7‑сегментные), обработки захваченной сессии, наложений, Validation Flow и миграции версии Scandit .NET SDK — для приложений MAUI (`<UseMaui>true</UseMaui>`) используйте label-capture-net-maui.
