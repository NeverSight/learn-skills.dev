Capture d'étiquettes intelligentes (Scandit `LabelCapture`) en .NET pour les projets iOS (`net*-ios` comme framework cible, paquet NuGet `Scandit.DataCapture.Label`, C#) — extraction de plusieurs champs (prix, date d’expiration, numéro de série ou de lot, poids) d’une étiquette en une seule lecture via le code‑barcode et les champs texte. Utilisez‑le pour l’intégration, les définitions d’étiquettes (y compris VIN préconstruit, étiquette de prix, 7 segments), la gestion des sessions capturées, les superpositions, le flux de validation et la migration de version du SDK Scandit .NET — pour les applications MAUI (`<UseMaui>true</UseMaui>`) utilisez `label-capture-net-maui` à la place.
