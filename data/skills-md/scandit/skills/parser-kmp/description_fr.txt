Analyseur Scandit dans les projets Kotlin Multiplatform (KMP) — artefact com.scandit.datacapture.kmp:parser, importations com.kmp.datacapture.parser. Analyse les chaînes de données de codes‑barres/RFID (GS1 AI, GS1 Digital Link, HIBC, Swiss QR, VIN, carte d’embarquement IATA, EPC) en valeurs ParsedField dans commonMain. Les permis de conduire AAMVA font partie d’ID Capture (compétences id-capture-*). Utilisez‑le pour la configuration de l’analyseur, la configuration du format de données, la gestion du résultat analysé ou le dépannage de l’analyse.
