MatrixScan Batch (MatrixScan, BarcodeBatch, ancien BarcodeTracking) dans les projets web/navigateur (TypeScript/JavaScript) (@scandit/web-datacapture-barcode) — suivi et numérisation de plusieurs codes-barres simultanément. Utilisez-le pour l’intégration, les paramètres et les symbologies, les pinceaux par code-barres, les superpositions AR d’éléments HTML, le retour manuel, le cycle de vie, la migration de version du SDK ou le dépannage.
