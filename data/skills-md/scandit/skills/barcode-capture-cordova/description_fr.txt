Cordova — Scandit Barcode Capture (`BarcodeCapture`) dans les applications hybrides Apache Cordova via les plugins `scandit-cordova-datacapture-*` (global `window.Scandit`), le mode de numérisation à contrôle total de bas niveau, à un seul code‑barres (BarcodeCapture + DataCaptureView + BarcodeCaptureOverlay) sans l’interface pré‑construite SparkScan, et non le SDK web uniquement pour navigateur. À utiliser pour l’intégration, les paramètres de numérisation, la gestion des résultats, le câblage de l’overlay, la migration de version du SDK ou le dépannage.
