Cordova — Scandit のバーコードキャプチャ（`BarcodeCapture`）を、Apache Cordova ハイブリッドアプリで `scandit-cordova-datacapture-*` プラグイン（グローバル `window.Scandit`）を介して使用します。プリビルドされた SparkScan UI を使用せず、低レベルでフルコントロールが可能な単一バーコードスキャンモード（BarcodeCapture + DataCaptureView + BarcodeCaptureOverlay）です。ブラウザ専用の Web SDK ではありません。統合、スキャン設定、結果処理、オーバーレイ配線、SDK バージョンの移行、またはトラブルシューティングに使用します。
