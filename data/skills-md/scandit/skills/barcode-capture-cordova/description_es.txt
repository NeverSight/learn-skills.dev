Cordova — Captura de códigos de barras Scandit (`BarcodeCapture`) en aplicaciones híbridas Apache Cordova mediante los plugins `scandit-cordova-datacapture-*` (global `window.Scandit`), el modo de escaneo de un solo código de barras de bajo nivel y control total (BarcodeCapture + DataCaptureView + BarcodeCaptureOverlay) sin la interfaz preconstruida SparkScan, no el SDK web solo para navegador. Úselo para integración, configuración de escaneo, manejo de resultados, conexión de superposición, migración de versiones del SDK o solución de problemas.
