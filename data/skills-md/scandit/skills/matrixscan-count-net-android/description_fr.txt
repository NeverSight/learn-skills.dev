MatrixScan Count (BarcodeCount) en .NET pour les projets Android (net*-android, NuGet Scandit.DataCapture.Barcode, non-MAUI) — comptage/réception de codes‑barres en masse avec BarcodeCountView, listes de capture/réception, carte spatiale, caméra gérée explicitement. Pour les applications MAUI, utilisez matrixscan-count-net-maui. À utiliser pour l’intégration, la configuration des paramètres, la gestion des résultats, la personnalisation de l’interface, la migration de version du SDK ou le dépannage des flux de comptage.
