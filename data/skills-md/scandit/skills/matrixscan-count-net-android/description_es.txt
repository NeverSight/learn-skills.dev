MatrixScan Count (BarcodeCount) en .NET para proyectos Android (net*-android, paquete NuGet Scandit.DataCapture.Barcode, no MAUI) — conteo/recepción de códigos de barras en lote con BarcodeCountView, captura/recepción de listas, mapa espacial, cámara gestionada explícitamente. Para aplicaciones MAUI use matrixscan-count-net-maui. Úselo para integración, configuración de ajustes, manejo de resultados, personalización de UI, migración de versión del SDK o solución de problemas en flujos de conteo.
