MatrixScan Count (BarcodeCount) в .NET для проектов Android (net*-android, Scandit.DataCapture.Barcode NuGet, non-MAUI) — подсчёт/получение штрих‑кодов в больших объёмах с помощью BarcodeCountView, списков захвата/получения, пространственной карты, явно управляемой камеры. Для приложений MAUI используйте matrixscan-count-net-maui. Применяется для интеграции, настройки параметров, обработки результатов, кастомизации UI, миграции версии SDK или устранения проблем в процессах подсчёта.
