Capacitor — Capture de codes-barres Scandit (`BarcodeCapture`) dans les applications hybrides Capacitor (Ionic) via les plugins Capacitor de Scandit (`ScanditCaptureCorePlugin`), le mode de numérisation à contrôle complet de bas niveau d’un seul code-barres (BarcodeCapture + DataCaptureView + BarcodeCaptureOverlay) sans l’interface pré‑construite SparkScan, et non le SDK web uniquement pour navigateur. À utiliser pour l’intégration, les paramètres de symbologie, le traitement des résultats, la personnalisation du viseur et des retours, la migration de version du SDK ou le dépannage.
