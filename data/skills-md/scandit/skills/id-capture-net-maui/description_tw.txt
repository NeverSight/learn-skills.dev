Scandit ID Capture (`IdCapture`) 在 .NET MAUI 專案（`<UseMaui>true</UseMaui>`、`Scandit.DataCapture.IdCapture` NuGet）——透過 MRZ、VIZ、PDF417 條碼或行動文件掃描護照、駕照、身分證、居留許可、簽證。用於整合、接受文件與掃描器設定、CapturedId 結果處理、拒絕規則、AAMVA 驗證、MAUI 視圖託管與生命週期，以及 SDK 版本遷移——對於非 MAUI .NET 專案，請改用 `id-capture-net-android`（`net*-android`）或 `id-capture-net-ios`（`net*-ios`）。
