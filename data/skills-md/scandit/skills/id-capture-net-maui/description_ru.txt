Scandit ID Capture (`IdCapture`) в проектах .NET MAUI (`<UseMaui>true</UseMaui>`, NuGet `Scandit.DataCapture.IdCapture`) — сканирование паспортов, водительских удостоверений, удостоверений личности, видов на жительство, виз через MRZ, VIZ, штрих‑код PDF417 или мобильные документы. Используется для интеграции, конфигурации принимаемых документов и сканера, обработки результата CapturedId, правил отклонения, проверки AAMVA, хостинга и жизненного цикла представления MAUI, а также миграции версии SDK — для проектов .NET без MAUI используйте `id-capture-net-android` (`net*-android`) или `id-capture-net-ios` (`net*-ios`).
