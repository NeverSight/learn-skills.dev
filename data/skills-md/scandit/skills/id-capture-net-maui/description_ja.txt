.NET MAUI プロジェクト（`<UseMaui>true</UseMaui>`、`Scandit.DataCapture.IdCapture` NuGet）における Scandit ID Capture（`IdCapture`）— MRZ、VIZ、PDF417 バーコード、またはモバイルドキュメントを通じてパスポート、運転免許証、ID カード、居住許可証、ビザをスキャンします。統合、受け入れ可能なドキュメントおよびスキャナー設定、CapturedId の結果処理、リジェクションルール、AAMVA 検証、MAUI ビューのホスティングとライフサイクル、SDK バージョンの移行に使用します — MAUI ではない .NET プロジェクトの場合は代わりに `id-capture-net-android`（`net*-android`）または `id-capture-net-ios`（`net*-ios`）を使用してください。
