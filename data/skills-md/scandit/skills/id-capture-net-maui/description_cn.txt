Scandit ID Capture（`IdCapture`）在 .NET MAUI 项目中（`<UseMaui>true</UseMaui>`，`Scandit.DataCapture.IdCapture` NuGet）——可扫描护照、驾驶执照、身份证、居留许可、签证等，通过 MRZ、VIZ、PDF417 条形码或移动证件。用于集成、接受文档和扫描仪配置、CapturedId 结果处理、拒绝规则、AAMVA 验证、MAUI 视图托管与生命周期以及 SDK 版本迁移——对于非 MAUI .NET 项目，请改用 `id-capture-net-android`（`net*-android`）或 `id-capture-net-ios`（`net*-ios`）。
