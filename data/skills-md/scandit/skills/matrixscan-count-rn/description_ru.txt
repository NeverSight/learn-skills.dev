MatrixScan Count (BarcodeCount) в проектах React Native — пакет scandit-react-native-datacapture-barcode. Многоштрихкодовый подсчёт в рабочих процессах (сканировать‑и‑подсчитывать, подсчёт по ожидаемому списку захватов, наложения статуса) с BarcodeCountView. Для Capacitor используйте matrixscan-count-capacitor. Применяйте для интеграции, настройки и конфигурации символогии, обработки результатов, кастомизации UI или устранения неполадок в процессах подсчёта.
