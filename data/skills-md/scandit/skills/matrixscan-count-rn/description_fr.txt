MatrixScan Count (BarcodeCount) dans les projets React Native — package scandit-react-native-datacapture-barcode. Flux de comptage multi‑codes‑barres (scanner‑et‑compter, comptage par rapport à une liste d’attendus, superpositions d’état) avec BarcodeCountView. Pour Capacitor, utilisez matrixscan-count-capacitor. À utiliser pour l’intégration, les paramètres et la configuration de la symbologie, le traitement des résultats, la personnalisation de l’interface utilisateur ou le dépannage des flux de comptage.
