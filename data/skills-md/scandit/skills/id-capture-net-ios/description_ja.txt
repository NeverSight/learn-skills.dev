Scandit ID Capture（`IdCapture`）は、iOS プロジェクト（`net*-ios` ターゲットフレームワーク、`Scandit.DataCapture.IdCapture` NuGet、C#）向けの .NET 実装です — パスポート、運転免許証、身分証明書、在留許可証、ビザを MRZ、VIZ、PDF417 バーコード、またはモバイル文書でスキャンします。統合、受理文書およびスキャナー設定、CapturedId の結果処理、拒否ルール、AAMVA 検証、匿名化、オーバーレイ UI、そして Scandit .NET SDK のバージョン移行に使用します — MAUI アプリ（`<UseMaui>true</UseMaui>`）の場合は、代わりに id-capture-net-maui を使用してください。
