Scandit ID Capture (`IdCapture`) in .NET per progetti iOS (`net*-ios` framework di destinazione, NuGet `Scandit.DataCapture.IdCapture`, C#) — scansione di passaporti, patenti di guida, carte d'identità, permessi di soggiorno, visti tramite MRZ, VIZ, codice a barre PDF417 o documenti mobili. Utilizzare per l'integrazione, configurazione dei documenti accettati e dello scanner, gestione del risultato CapturedId, regole di rifiuto, verifica AAMVA, anonimizzazione, UI overlay e migrazione della versione dello Scandit .NET SDK — per le app MAUI (`<UseMaui>true</UseMaui>`) usare id-capture-net-maui.
