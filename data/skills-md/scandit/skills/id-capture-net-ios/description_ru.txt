Scandit ID Capture (`IdCapture`) в .NET для iOS‑проектов (`net*-ios` целевая платформа, NuGet `Scandit.DataCapture.IdCapture`, C#) — сканирование паспортов, водительских удостоверений, удостоверений личности, видов на жительство, виз с помощью MRZ, VIZ, штрих‑кода PDF417 или мобильных документов. Используется для интеграции, настройки принимаемых документов и сканера, обработки результата CapturedId, правил отклонения, проверки AAMVA, анонимизации, UI‑наложения и миграции версии Scandit .NET SDK — для MAUI‑приложений (`<UseMaui>true</UseMaui>`) используйте id-capture-net-maui.
