Scandit ID Capture (`IdCapture`) en .NET para proyectos iOS (`net*-ios` framework de destino, NuGet `Scandit.DataCapture.IdCapture`, C#) — escaneo de pasaportes, licencias de conducir, tarjetas de identidad, permisos de residencia, visas mediante MRZ, VIZ, código de barras PDF417 o documentos móviles. Se utiliza para integración, configuración de documentos aceptados y del escáner, manejo de resultados CapturedId, reglas de rechazo, verificación AAMVA, anonimización, interfaz de superposición y migración de versiones del SDK .NET de Scandit — para aplicaciones MAUI (`<UseMaui>true</UseMaui>`) use id-capture-net-maui en su lugar.
