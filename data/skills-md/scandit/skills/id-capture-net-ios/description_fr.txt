Scandit ID Capture (`IdCapture`) dans .NET pour les projets iOS (`net*-ios` cadre cible, NuGet `Scandit.DataCapture.IdCapture`, C#) — numérisation des passeports, permis de conduire, cartes d’identité, titres de séjour, visas via MRZ, VIZ, code‑barres PDF417 ou documents mobiles. Utilisez‑le pour l’intégration, la configuration des documents acceptés et du scanner, la gestion des résultats CapturedId, les règles de rejet, la vérification AAMVA, l’anonymisation, l’interface superposée et la migration de version du SDK .NET Scandit — pour les applications MAUI (`<UseMaui>true</UseMaui>`) utilisez id-capture-net-maui à la place.
