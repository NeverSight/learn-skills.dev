Numérisation d’un seul code‑barcode avec SparkScan et l’interface pré‑conçue `SparkScanView` sous .NET pour les projets Android (`net*-android` framework cible, NuGet `Scandit.DataCapture.Barcode`, non‑MAUI — pour les applications MAUI utilisez sparkscan‑net‑maui). Utilisez‑le pour l’intégration, les paramètres de numérisation, la gestion des résultats, la personnalisation du retour d’information, le câblage du cycle de vie, la migration de version du SDK (v6→v7→v8), le remplacement des scanners tiers (ZXing.Net) ou le dépannage.
