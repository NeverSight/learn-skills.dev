Escaneo de un solo código de barras con SparkScan usando la interfaz preconstruida `SparkScanView` en .NET para proyectos Android (`net*-android` como framework objetivo, paquete NuGet `Scandit.DataCapture.Barcode`, no MAUI — para aplicaciones MAUI use sparkscan-net-maui). Úselo para integración, configuración de escaneo, manejo de resultados, personalización de retroalimentación, conexión del ciclo de vida, migración de versiones del SDK (v6→v7→v8), sustitución de escáneres de terceros (ZXing.Net) o solución de problemas.
