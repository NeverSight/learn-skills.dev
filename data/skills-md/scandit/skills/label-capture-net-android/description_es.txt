Smart Label Capture (Scandit `LabelCapture`) en .NET para proyectos Android (`net*-android` como framework de destino, NuGet `Scandit.DataCapture.Label`, C#) — extracción de varios campos (precio, fecha de caducidad, número de serie o lote, peso) de una etiqueta en una sola escaneo mediante código de barras y campos de texto. Uso para integración, definiciones de etiquetas (incluyendo VIN predefinido, etiqueta de precio, 7 segmentos), manejo de sesiones capturadas, superposiciones, el flujo de validación y migración de versiones del SDK .NET de Scandit — para aplicaciones MAUI (`<UseMaui>true</UseMaui>`) usar label-capture-net-maui en su lugar.
