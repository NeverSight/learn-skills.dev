Smart Label Capture (Scandit `LabelCapture`) в .NET для Android‑проектов (`net*-android` целевая платформа, NuGet `Scandit.DataCapture.Label`, C#) — извлечение нескольких полей (цена, срок годности, серийный или партийный номер, вес) с этикетки за один скан через штрих‑код и текстовые поля. Используется для интеграции, определения этикеток (включая готовые VIN, ценовую этикетку, 7‑сегментную), обработки захваченной сессии, наложений, Validation Flow и миграции версии Scandit .NET SDK — для MAUI‑приложений (`<UseMaui>true</UseMaui>`) используйте label-capture-net-maui.
