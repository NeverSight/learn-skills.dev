Smart Label Capture (Scandit `LabelCapture`) dans .NET pour les projets Android (`net*-android` framework cible, NuGet `Scandit.DataCapture.Label`, C#) — extraction de plusieurs champs (prix, date d'expiration, numéro de série ou de lot, poids) d'une étiquette en un seul scan via le code‑barres et les champs texte. Utiliser pour l'intégration, les définitions d'étiquettes (y compris VIN préconstruit, étiquette de prix, affichage à 7 segments), la gestion des sessions capturées, les superpositions, le flux de validation et la migration de version du SDK .NET Scandit — pour les applications MAUI (`<UseMaui>true</UseMaui>`) utilisez label-capture-net-maui à la place.
