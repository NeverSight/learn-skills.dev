.NET MAUI プロジェクト（`<UseMaui>true</UseMaui>`、`Scandit.DataCapture.Barcode.Maui` NuGet）で、事前構築された `SparkScanView` UI を使用したシングルバーコードスキャン — 非 MAUI の .NET プロジェクトでは sparkscan-net-android または sparkscan-net-ios を使用してください。統合、スキャン設定、結果処理、フィードバックや UI カスタマイズ、SDK バージョン移行（v6→v7→v8）、サードパーティ製 MAUI スキャナ（ZXing.Net.Maui）への置き換え、またはトラブルシューティングに利用できます。
