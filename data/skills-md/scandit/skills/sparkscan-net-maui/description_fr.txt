SparkScan analyse de code‑barres unique avec l’interface pré‑construite `SparkScanView` dans les projets .NET MAUI (`<UseMaui>true</UseMaui>`, NuGet `Scandit.DataCapture.Barcode.Maui`) — pour les projets .NET non MAUI, utilisez sparkscan-net-android ou sparkscan-net-ios. À utiliser pour l’intégration, les paramètres de numérisation, la gestion des résultats, le feedback et la personnalisation de l’UI, la migration de version du SDK (v6→v7→v8), le remplacement des scanners tiers MAUI (ZXing.Net.Maui) ou le dépannage.
