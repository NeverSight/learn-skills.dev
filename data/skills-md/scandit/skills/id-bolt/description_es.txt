Scandit ID Bolt en proyectos web (`@scandit/web-id-bolt`) — el pop‑up alojado y listo para usar de escaneo de documentos de identidad (pasaportes, licencias de conducir, tarjetas de identificación) con transferencia incorporada al teléfono del usuario, para añadir escaneo de identificación a un sitio web con código mínimo y sin necesidad de crear una interfaz de cámara. Úsalo para integración (IdBoltSession), selección de documentos, validadores, opciones de datos devueltos y anonimización, tematización y personalización del flujo de trabajo, o solución de problemas. Un producto diferente de ID Capture — para escaneo totalmente personalizable dentro de la página, incrustado en tu propia UI, usa id-capture-web.
