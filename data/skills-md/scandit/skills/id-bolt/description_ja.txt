Web プロジェクトにおける Scandit ID Bolt（`@scandit/web-id-bolt`） — ホスティングされた、ドロップイン型の身分証明書スキャンポップアップ（パスポート、運転免許証、ID カード）で、ユーザーのスマートフォンへのハンドオーバー機能が組み込まれており、最小限のコードでカメラ UI を構築せずにウェブサイトに ID スキャンを追加できます。統合（IdBoltSession）、ドキュメント選択、バリデータ、返却データと匿名化オプション、テーマ設定やワークフローのカスタマイズ、トラブルシューティングに使用します。ID Capture とは別製品で、ページ内に完全にカスタマイズ可能なスキャンを自分の UI に埋め込む場合は id-capture-web を使用してください。
