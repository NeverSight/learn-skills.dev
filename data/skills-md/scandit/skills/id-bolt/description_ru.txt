Scandit ID Bolt в веб‑проектах (`@scandit/web-id-bolt`) — хостинговый, готовый к использованию поп‑ап сканирования удостоверений личности (паспорта, водительские права, ID‑карты) со встроенной передачей данных на телефон пользователя, позволяющий добавить сканирование документов на сайт с минимальным кодом и без создания пользовательского интерфейса камеры. Используется для интеграции (IdBoltSession), выбора документов, валидаторов, опций возвращаемых данных и анонимизации, настройки тем и рабочего процесса, а также для отладки. Это отдельный продукт от ID Capture — для полностью настраиваемого сканирования внутри страницы, встроенного в ваш собственный UI, используйте id-capture-web.
