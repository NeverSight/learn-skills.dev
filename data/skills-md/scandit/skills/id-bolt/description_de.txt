Scandit ID Bolt in Webprojekten (`@scandit/web-id-bolt`) – das gehostete, sofort einsetzbare Pop‑Up zur Ausweisdokumentenerfassung (Reisepässe, Führerscheine, Personalausweise) mit integrierter Übergabe an das Telefon des Nutzers, um das Scannen von Ausweisen in eine Website mit minimalem Code und ohne eigene Kamerabedienoberfläche einzubinden. Verwenden Sie es für Integration (IdBoltSession), Dokumentenauswahl, Validatoren, Rückgabedaten‑ und Anonymisierungsoptionen, Gestaltung und Workflow‑Anpassung oder Fehlersuche. Ein anderes Produkt als ID Capture – für vollständig anpassbares Scannen innerhalb der Seite, das in Ihre eigene UI eingebettet wird, nutzen Sie id-capture-web.
