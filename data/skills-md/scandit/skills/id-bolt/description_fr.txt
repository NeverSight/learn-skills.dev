Scandit ID Bolt dans les projets web (`@scandit/web-id-bolt`) — le pop‑up hébergé, prêt à l’emploi, de numérisation de documents d’identité (passeports, permis de conduire, cartes d’identité) avec transmission intégrée vers le téléphone de l’utilisateur, pour ajouter la numérisation d’ID à un site web avec un code minimal et aucune interface caméra à développer. Utilisez‑le pour l’intégration (IdBoltSession), la sélection de documents, les validateurs, les options de données retournées et d’anonymisation, la thématisation et la personnalisation du flux de travail, ou le dépannage. Un produit différent d’ID Capture — pour une numérisation entièrement personnalisable dans la page, intégrée à votre propre UI, utilisez id-capture-web.
