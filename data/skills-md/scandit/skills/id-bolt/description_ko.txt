Scandit ID Bolt을 웹 프로젝트에서 사용 (`@scandit/web-id-bolt`) — 호스팅되는 드롭인 신분증 스캔 팝업(여권, 운전면허증, 신분증)으로, 사용자의 전화기로의 핸드오버가 내장되어 있어 최소한의 코드와 카메라 UI 없이도 웹사이트에 ID 스캔을 추가할 수 있습니다. 통합(IdBoltSession), 문서 선택, 검증기, 반환 데이터 및 익명화 옵션, 테마 및 워크플로 맞춤 설정, 문제 해결 등에 사용합니다. ID Capture와는 다른 제품이며, 자체 UI에 완전히 맞춤형 스캔을 페이지 내에 임베드하려면 id-capture-web을 사용하세요.
