Scandit ID Bolt nei progetti web (`@scandit/web-id-bolt`) — il pop‑up ospitato, plug‑and‑play per la scansione di documenti d’identità (passaporti, patenti di guida, carte d’identità) con trasferimento integrato al telefono dell’utente, per aggiungere la scansione di ID a un sito web con codice minimo e senza dover creare un’interfaccia della fotocamera. Usalo per l’integrazione (IdBoltSession), la selezione dei documenti, i validator, le opzioni di dati restituiti e anonimizzazione, la personalizzazione del tema e del flusso di lavoro, o per la risoluzione dei problemi. Un prodotto diverso da ID Capture — per la scansione completamente personalizzabile in‑page incorporata nella tua UI utilizza id-capture-web.
