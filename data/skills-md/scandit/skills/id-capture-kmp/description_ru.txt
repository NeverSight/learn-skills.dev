Scandit ID Capture (`IdCapture`) в проектах Kotlin Multiplatform (KMP) / Compose Multiplatform (`com.kmp.datacapture.id.*`, общий commonMain для Android + iOS) — сканирование паспортов, водительских удостоверений, удостоверений личности, видов на жительство, виз через MRZ, VIZ, штрих‑код PDF417 или мобильные документы. Используется для интеграции, конфигурации принимаемых документов и сканера, обработки результата CapturedId, правил отклонения, проверки AAMVA, анонимизации и размещения общих представлений — а не для нативных Android‑ или iOS‑навыков, чьи API различаются.
