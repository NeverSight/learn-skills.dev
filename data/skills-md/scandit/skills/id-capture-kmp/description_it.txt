Scandit ID Capture (`IdCapture`) in progetti Kotlin Multiplatform (KMP) / Compose Multiplatform (`com.kmp.datacapture.id.*`, commonMain condiviso per Android + iOS) — scansione di passaporti, patenti di guida, carte d’identità, permessi di soggiorno, visti tramite MRZ, VIZ, codice a barre PDF417 o documenti mobili. Utilizzo per integrazione, configurazione dei documenti accettati e dello scanner, gestione del risultato CapturedId, regole di rifiuto, verifica AAMVA, anonimizzazione e hosting di visualizzazioni condivise — non le competenze native Android o native iOS, i cui API differiscono.
