Scandit ID Capture (`IdCapture`) en proyectos Kotlin Multiplatform (KMP) / Compose Multiplatform (`com.kmp.datacapture.id.*`, commonMain compartido dirigido a Android + iOS) — escaneo de pasaportes, licencias de conducir, tarjetas de identificación, permisos de residencia, visas mediante MRZ, VIZ, código de barras PDF417 o documentos móviles. Se utiliza para la integración, configuración de documentos aceptados y del escáner, manejo del resultado CapturedId, reglas de rechazo, verificación AAMVA, anonimización y alojamiento de vistas compartidas — no las habilidades nativas de Android o iOS, cuyas APIs difieren.
