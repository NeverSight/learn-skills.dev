Kotlin Multiplatform（KMP）/ Compose Multiplatform プロジェクト（`com.kmp.datacapture.id.*`、Android と iOS を対象とした shared commonMain）における Scandit ID Capture（`IdCapture`） — MRZ、VIZ、PDF417 バーコード、またはモバイル文書を使用したパスポート、運転免許証、身分証明書、居住許可証、ビザのスキャン。統合、受理文書およびスキャナー設定、CapturedId の結果処理、リジェクションルール、AAMVA 検証、匿名化、共有ビューのホスティングに使用します — API が異なる Android ネイティブや iOS ネイティブのスキルではありません。
