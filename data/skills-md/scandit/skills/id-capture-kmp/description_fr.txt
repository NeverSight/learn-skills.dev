Scandit ID Capture (`IdCapture`) dans les projets Kotlin Multiplatform (KMP) / Compose Multiplatform (`com.kmp.datacapture.id.*`, commonMain partagé ciblant Android + iOS) — numérisation de passeports, permis de conduire, cartes d'identité, titres de séjour, visas via MRZ, VIZ, code‑barres PDF417 ou documents mobiles. Utilisation pour l'intégration, la configuration des documents acceptés et du scanner, la gestion du résultat CapturedId, les règles de rejet, la vérification AAMVA, l'anonymisation et l'hébergement de vues partagées — et non les compétences natives Android ou iOS, dont les API diffèrent.
