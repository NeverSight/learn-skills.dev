Scandit ID Capture（`IdCapture`）在 Kotlin Multiplatform（KMP）/ Compose Multiplatform 项目中（`com.kmp.datacapture.id.*`，共享的 commonMain 面向 Android + iOS）——用于扫描护照、驾驶执照、身份证、居留许可、签证等文档，可通过 MRZ、VIZ、PDF417 条码或移动文档进行扫描。用于集成、接受文档和扫描仪配置、CapturedId 结果处理、拒绝规则、AAMVA 验证、匿名化以及共享视图托管——而非原生 Android 或原生 iOS 技能，其 API 各不相同。
