استخدم عندما يذكر المستخدم Scandit أو SDK لالتقاط البيانات أو منتجات مسح الباركود أو التقاط البيانات الذكي أو اختيار منتج مسح، أو مقارنة ميزات المسح، أو رموز الباركود المدعومة، أو متطلبات النظام، أو توافق الجهاز، أو أسعار Scandit. يساعد على اختيار المنتج المناسب من Scandit (SparkScan، Barcode Capture، MatrixScan، Smart Label Capture، ID Capture، إلخ)، ويشير إلى الوثائق الصحيحة وتطبيقات العينة للمنصة المستخدمة، ثم يسلم المهمة إلى مهارات التنفيذ.
