Scandit Barcode Capture（`BarcodeCapture`）をウェブ/ブラウザ（TypeScript/JavaScript）プロジェクトで使用 — 低レベルで完全に制御できる単一バーコードスキャンモード（BarcodeCapture＋DataCaptureView＋オーバーレイ）で、あらかじめ用意された SparkScan UI は含まれません。Cordova や Capacitor のハイブリッドプラグインではありません。統合、スキャン設定、結果処理、オーバーレイおよびビューファインダーのカスタマイズ、Scandit Web SDK のバージョン移行（v6→v7→v8）、またはトラブルシューティングに使用してください。
