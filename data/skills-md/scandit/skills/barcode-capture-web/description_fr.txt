Scandit Barcode Capture (`BarcodeCapture`) dans les projets web/navigateurs (TypeScript/JavaScript) — le mode de numérisation à contrôle complet et bas niveau d’un seul code‑barcode (BarcodeCapture + DataCaptureView + superposition), sans l’interface SparkScan pré‑construite ; ce n’est pas les plugins hybrides Cordova ou Capacitor. Utilisez‑le pour l’intégration, les paramètres de numérisation, la gestion des résultats, la personnalisation de la superposition et du viseur, la migration des versions du SDK Web Scandit (v6→v7→v8), ou le dépannage.
