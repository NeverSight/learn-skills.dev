Scandit Barcode Capture (`BarcodeCapture`) dans les projets React Native — le mode de numérisation à faible niveau, offrant un contrôle complet d’un seul code‑barcode (BarcodeCapture + DataCaptureView + BarcodeCaptureOverlay), sans l’interface pré‑construite SparkScan. À utiliser pour l’intégration, la configuration des symbologies, la gestion des résultats, la personnalisation du viseur et des retours, la migration de version du SDK ou le dépannage.
