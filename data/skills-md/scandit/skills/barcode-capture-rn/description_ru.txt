Scandit Barcode Capture (`BarcodeCapture`) в проектах React Native — низкоуровневый режим сканирования одного штрихкода с полным контролем (BarcodeCapture + DataCaptureView + BarcodeCaptureOverlay), без готового UI SparkScan. Используется для интеграции, настройки символогии, обработки результатов, настройки видоискателя и обратной связи, миграции версии SDK или устранения неполадок.
