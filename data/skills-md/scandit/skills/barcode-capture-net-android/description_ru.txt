Scandit BarcodeCapture в .NET для Android‑проектов (`net*-android` целевая платформа, NuGet `Scandit.DataCapture.Barcode`, без MAUI — для приложений MAUI используйте barcode-capture-net-maui) — низкоуровневый режим сканирования штрихкодов с полным контролем, без готового UI SparkScan. Используйте для интеграции, настройки сканирования, подключения слушателей и событий, кастомизации наложения, управления жизненным циклом камеры, миграции версии SDK (v6→v7→v8), замены ZXing.Net или привязок ML Kit, а также отладки.
