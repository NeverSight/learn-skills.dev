Migrer l'intégration du SDK Scandit Data Capture après qu’une application Xamarin soit déjà sur la pile .NET (.NET pour Android, .NET pour iOS ou .NET MAUI) — par exemple après l’utilisation des outils de modernisation d’applications .NET de Microsoft. À utiliser lorsque le projet se compile en .NET/MAUI mais que le code Scandit référence encore les packages `Scandit.DataCapture.*.Xamarin(.Forms)`, les espaces de noms `.Unified` ou le legacy `Scandit.BarcodePicker.Xamarin`. Remplace les packages, corrige l’initialisation SDK‑8, les espaces de noms et les vues, vérifie le scan, puis transmet à la compétence correspondante `*-net-android`/`-net-ios`/`-net-maui`. Ne migre que le SDK Scandit, pas l’application générale.
