Xamarin アプリがすでに .NET スタック（.NET for Android、.NET for iOS、または .NET MAUI）上にある状態で Scandit Data Capture SDK の統合を移行します（例：Microsoft の .NET アプリモダナイゼーション ツールを使用した後）。プロジェクトが .NET/MAUI としてビルドされているが、Scandit のコードが依然として `Scandit.DataCapture.*.Xamarin(.Forms)` パッケージや `.Unified` 名前空間、あるいは旧来の `Scandit.BarcodePicker.Xamarin` を参照している場合に使用します。パッケージを入れ替え、SDK‑8 の初期化、名前空間、ビューを修正し、スキャンを検証した上で、対応する `*-net-android`／`-net-ios`／`-net-maui` スキルに引き渡します。一般的なアプリ全体ではなく、Scandit SDK のみを移行します。
