Xamarin 앱이 이미 .NET 스택(.NET for Android, .NET for iOS, 또는 .NET MAUI) 위에 있을 때 Scandit Data Capture SDK 통합을 마이그레이션합니다 — 예: Microsoft의 .NET 앱 현대화 도구 사용 후. 프로젝트가 .NET/MAUI로 빌드되지만 Scandit 코드가 아직 `Scandit.DataCapture.*.Xamarin(.Forms)` 패키지, `.Unified` 네임스페이스, 또는 레거시 `Scandit.BarcodePicker.Xamarin`을 참조하고 있을 때 사용합니다. 패키지를 교체하고, SDK‑8 초기화를 수정하며, 네임스페이스와 뷰를 정리하고, 스캔을 검증한 뒤 해당 `*-net-android`/`-net-ios`/`-net-maui` 스킬로 넘깁니다. 일반 앱이 아니라 Scandit SDK만 마이그레이션합니다.
