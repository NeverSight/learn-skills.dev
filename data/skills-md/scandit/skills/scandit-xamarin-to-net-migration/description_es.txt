Migrar la integración del SDK Scandit Data Capture después de que una aplicación Xamarin ya esté en la pila .NET (.NET para Android, .NET para iOS o .NET MAUI), por ejemplo tras usar las herramientas de modernización de aplicaciones .NET de Microsoft. Utilizar cuando el proyecto se compila como .NET/MAUI pero el código de Scandit aún hace referencia a paquetes `Scandit.DataCapture.*.Xamarin(.Forms)`, espacios de nombres `.Unified` o al legado `Scandit.BarcodePicker.Xamarin`. Cambia los paquetes, corrige la inicialización SDK‑8, los espacios de nombres y las vistas, verifica el escaneo y entrega a la habilidad correspondiente `*-net-android`/`-net-ios`/`-net-maui`. Migra solo el SDK de Scandit, no la aplicación en general.
