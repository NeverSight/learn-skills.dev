Cordova — SparkScan однокодовое сканирование с предустановленным UI сканера в гибридных приложениях Apache Cordova через плагины `scandit-cordova-datacapture-*` (глобальный `window.Scandit`), а не только веб‑SDK для браузера. Используется для интеграции, настройки сканирования, обработки результатов, кастомизации UI, миграции версии SDK или отладки.
