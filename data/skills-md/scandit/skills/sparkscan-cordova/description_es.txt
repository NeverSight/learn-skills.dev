Cordova — escaneo de un solo código de barras con SparkScan usando la interfaz de escaneo preconstruida en aplicaciones híbridas Apache Cordova a través de los plugins `scandit-cordova-datacapture-*` (global `window.Scandit`), no del SDK web solo para navegador. Úsalo para integración, configuración del escaneo, manejo de resultados, personalización de la UI, migración de versiones del SDK o resolución de problemas.
