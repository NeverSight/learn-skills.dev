Cordova — numérisation d’un seul code‑barres SparkScan avec l’interface de numérisation pré‑construite dans les applications hybrides Apache Cordova via les plugins `scandit-cordova-datacapture-*` (global `window.Scandit`), pas le SDK web réservé au navigateur. Utilisez‑le pour l’intégration, les paramètres de numérisation, la gestion des résultats, la personnalisation de l’UI, la migration de version du SDK ou le dépannage.
