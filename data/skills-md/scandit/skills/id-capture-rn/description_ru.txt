Scandit ID Capture (`IdCapture`) в проектах React Native — сканирование паспортов, водительских прав, удостоверений личности, видов на жительство, виз через MRZ, VIZ, штрих‑код или мобильные документы. Используется для интеграции, конфигурации принимаемых документов и сканера, обработки результатов захваченных полей, анонимизации, дополнительных возможностей (обнаружение недействительных ID, декодирование обратной стороны европейских водительских прав, проверка штрих‑кода AAMVA), а также миграции версии SDK.
