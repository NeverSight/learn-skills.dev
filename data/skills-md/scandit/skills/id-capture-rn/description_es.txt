Scandit ID Capture (`IdCapture`) en proyectos React Native — escaneo de pasaportes, licencias de conducir, tarjetas de identificación, permisos de residencia y visas mediante MRZ, VIZ, código de barras o documentos móviles. Se utiliza para integración, configuración de documentos aceptados y del escáner, manejo de resultados de campos capturados, anonimización, capacidades adicionales (detección de identificación anulada, decodificación del reverso de licencias de conducir europeas, verificación de códigos de barras AAMVA) y migración de versiones del SDK.
