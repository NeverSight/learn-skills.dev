Scandit ID Capture (`IdCapture`) nei progetti React Native — scansione di passaporti, patenti di guida, carte d'identità, permessi di soggiorno e visti tramite MRZ, VIZ, codice a barre o documenti mobili. Utilizzo per integrazione, configurazione dei documenti accettati e dello scanner, gestione dei risultati dei campi acquisiti, anonimizzazione, funzionalità aggiuntive (rilevamento di ID annullati, decodifica del retro della patente di guida europea, verifica del codice a barre AAMVA) e migrazione della versione SDK.
