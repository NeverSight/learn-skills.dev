Scandit ID Capture (`IdCapture`) في مشاريع React Native — مسح جوازات السفر، رخص القيادة، بطاقات الهوية، تصاريح الإقامة، التأشيرات عبر MRZ، VIZ، الباركود، أو المستندات المتنقلة. استخدمه للتكامل، تكوين المستند المقبول والمسح الضوئي، معالجة نتائج الحقول الملتقطة، إلغاء التعريف، إمكانات الإضافات (اكتشاف الهوية الملغاة، فك ترميز الجزء الخلفي لرخصة القيادة الأوروبية، التحقق من باركود AAMVA)، وترحيل نسخة SDK.
