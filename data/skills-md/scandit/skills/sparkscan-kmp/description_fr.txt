Numérisation d’un seul code-barres avec SparkScan et l’interface de numérisation pré‑construite dans les projets Kotlin Multiplatform (KMP) et Compose Multiplatform utilisant le SDK KMP de Scandit (`com.kmp.datacapture.*`). À utiliser pour l’intégration, les paramètres de numérisation, la gestion des résultats, les retours et la personnalisation de l’interface utilisateur, l’intégration de `SparkScanView` dans le code partagé, ou le dépannage.
