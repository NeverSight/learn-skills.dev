Scandit ID Capture en proyectos web/navegador (`@scandit/web-datacapture-id`) — escaneo de pasaportes, licencias de conducir, tarjetas de identificación, permisos de residencia, visas mediante MRZ, VIZ, código de barras PDF417 o documentos móviles. Úsalo para integración, configuración de documentos aceptados y del escáner, manejo del resultado CapturedId, reglas de rechazo, verificación AAMVA, interfaz superpuesta y migración de versiones del SDK en aplicaciones web TypeScript/JavaScript.
