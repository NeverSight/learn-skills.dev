Scandit ID Capture في مشاريع الويب/المتصفح (`@scandit/web-datacapture-id`) — مسح جوازات السفر، رخص القيادة، بطاقات الهوية، تصاريح الإقامة، التأشيرات عبر MRZ، VIZ، باركود PDF417، أو المستندات المحمولة. استخدمه للتكامل، تكوين المستندات المقبولة والمسح الضوئي، معالجة نتيجة CapturedId، قواعد الرفض، التحقق من AAMVA، واجهة المستخدم المتراكبة، وترحيل إصدارات SDK في تطبيقات الويب TypeScript/JavaScript.
