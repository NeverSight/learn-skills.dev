Scandit ID Capture nei progetti web/browser (`@scandit/web-datacapture-id`) — scansione di passaporti, patenti di guida, carte d'identità, permessi di soggiorno, visti tramite MRZ, VIZ, codice a barre PDF417 o documenti mobili. Utilizzo per integrazione, configurazione dei documenti accettati e dello scanner, gestione del risultato CapturedId, regole di rifiuto, verifica AAMVA, interfaccia overlay e migrazione della versione SDK in applicazioni web TypeScript/JavaScript.
