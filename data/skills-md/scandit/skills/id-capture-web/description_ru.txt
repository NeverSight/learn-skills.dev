Scandit ID Capture в web/браузерных проектах (`@scandit/web-datacapture-id`) — сканирование заграничных паспортов, водительских удостоверений, удостоверений личности, видов на жительство, виз с помощью MRZ, VIZ, штрих‑кода PDF417 или мобильных документов. Используется для интеграции, настройки принимаемых документов и сканера, обработки результата CapturedId, правил отклонения, проверки AAMVA, интерфейса overlay и миграции версии SDK в веб‑приложениях на TypeScript/JavaScript.
