Scandit ID Capture dans les projets web/navigateur (`@scandit/web-datacapture-id`) — numérisation des passeports, permis de conduire, cartes d’identité, titres de séjour, visas via MRZ, VIZ, code‑barres PDF417 ou documents mobiles. Utilisez‑le pour l’intégration, la configuration des documents acceptés et du scanner, la gestion des résultats CapturedId, les règles de rejet, la vérification AAMVA, l’interface superposée et la migration de version du SDK dans les applications web TypeScript/JavaScript. 

Veuillez toujours répondre dans la langue de l’utilisateur.
