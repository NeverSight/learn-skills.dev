Scandit BarcodeCapture в .NET для проектов iOS (целевой фреймворк `net*-ios`, пакет NuGet `Scandit.DataCapture.Barcode`, без MAUI — для приложений MAUI используйте barcode-capture-net-maui) — низкоуровневый режим сканирования штрихкодов с полным контролем, без готового интерфейса SparkScan. Используется для интеграции, настройки параметров сканирования, подключения слушателей и обработки событий, кастомизации оверлея, управления жизненным циклом камеры, миграции между версиями SDK (v6→v7→v8), замены сканеров ZXing.Net.Mobile или AVFoundation, а также для отладки.
