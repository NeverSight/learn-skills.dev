Scandit ID Capture (`IdCapture`) في مشاريع iOS الأصلية بلغة Swift (UIKit أو SwiftUI) — مسح جوازات السفر، رخص القيادة، بطاقات الهوية، تصاريح الإقامة، بطاقات التأمين الصحي، التأشيرات عبر MRZ، VIZ، شفرة PDF417، أو المستندات المتنقلة على iOS. يُستخدم للتكامل، تكوين المستندات المقبولة والمسح الضوئي، معالجة نتيجة CapturedId، قواعد الرفض، التحقق من AAMVA، إخفاء الهوية، واجهة المستخدم المتراكبة، دورة حياة الكاميرا، وترحيل إصدار Scandit iOS SDK في تطبيقات iOS باستخدام Swift أو UIKit أو SwiftUI.
