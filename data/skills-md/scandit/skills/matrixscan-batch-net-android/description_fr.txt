MatrixScan Batch (MatrixScan, BarcodeBatch, BarcodeTracking hérité) en .NET pour les projets Android (`net*-android` TFM, NuGet `Scandit.DataCapture.Barcode`, non‑MAUI — les applications MAUI utilisent matrixscan-batch-net-maui) — suivi et numérisation de plusieurs codes‑barres à la fois. Utilisez-le pour l’intégration, les paramètres et les symbologies, les écouteurs/événements, la personnalisation basique/avancée des superpositions, le cycle de vie de la caméra, la migration de version du SDK ou le dépannage.
