Scandit BarcodeCapture dans les projets .NET MAUI (`<UseMaui>true</UseMaui>`, package NuGet `Scandit.DataCapture.Barcode.Maui`) — le mode de numérisation de codes-barres à bas niveau, offrant un contrôle complet, avec votre propre contrôle XAML `<scandit:DataCaptureView>` et superposition dans une page MAUI, sans l’interface pré‑construite SparkScan (pour cela utilisez sparkscan‑net‑maui) ; pour .NET non‑MAUI, utilisez barcode‑capture‑net‑android ou barcode‑capture‑net‑ios. À utiliser pour l’intégration, les paramètres de numérisation, la gestion des résultats, le branchement du cycle de vie, la migration de version du SDK (v6→v7→v8), le remplacement de ZXing.Net.Maui ou le dépannage.
