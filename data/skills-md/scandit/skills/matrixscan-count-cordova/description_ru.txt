Cordova MatrixScan Count (BarcodeCount) — плагин scandit-cordova-datacapture-barcode. Рабочие процессы подсчёта и приёма (сканирование‑и‑подсчёт, инвентарный подсчёт, сканирование по списку захвата, режим статуса, нажатие для отмены подсчёта) с BarcodeCountView в приложениях Cordova. Для Capacitor используйте matrixscan-count-capacitor. Применяется для интеграции, настройки символогии, кастомизации представления, обработки результатов, миграции версии SDK или устранения неполадок в процессах подсчёта.
