Cordova MatrixScan Count (BarcodeCount) — plugin scandit-cordova-datacapture-barcode. Flux de travail de comptage et de réception (scanner‑et‑compter, comptage d’inventaire, scanner contre une liste de captures, mode statut, toucher pour décrémenter) avec BarcodeCountView dans les applications Cordova. Pour Capacitor, utilisez matrixscan-count-capacitor. À utiliser pour l’intégration, la configuration des symbologies, la personnalisation de la vue, la gestion des résultats, la migration de version du SDK ou le dépannage des flux de comptage.
