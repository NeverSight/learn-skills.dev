Cordova MatrixScan Count (BarcodeCount) — complemento scandit-cordova-datacapture-barcode. Flujos de trabajo de conteo y recepción (escaneo y conteo, conteo de inventario, escanear contra una lista de captura, modo de estado, tocar para descontar) con BarcodeCountView en aplicaciones Cordova. Para Capacitor use matrixscan-count-capacitor. Úselo para integración, configuración de simbología, personalización de la vista, manejo de resultados, migración de versiones del SDK o solución de problemas de flujos de conteo.
