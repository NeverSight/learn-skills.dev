Smart Label Capture (Scandit `LabelCapture`) en proyectos React Native — extracción de múltiples campos (precio, fecha de caducidad, número de serie o lote, peso) de una etiqueta en un solo escaneo, utilizando campos de código de barras más campos de texto con patrones regex. Uso para integración, configuración de la definición de etiquetas, manejo de etiquetas capturadas, el Flujo de Validación y la migración de versiones del SDK.
