Smart Label Capture (Scandit `LabelCapture`) в проектах React Native — извлечение нескольких полей (цена, срок годности, серийный или номер партии, вес) с этикетки за один скан, используя поля штрих‑кода плюс текстовые поля с шаблонами regex. Используется для интеграции, настройки определения этикеток, обработки захваченных этикеток, потока валидации и миграции версии SDK.
