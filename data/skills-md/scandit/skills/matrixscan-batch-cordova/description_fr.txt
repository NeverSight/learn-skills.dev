Cordova MatrixScan Batch (plugins scandit‑cordova‑datacapture-*) — MatrixScan, BarcodeBatch, BarcodeTracking hérité — suivi et numérisation de plusieurs codes‑barres simultanément avec des superpositions AR de base ou avancées. Utilisez‑le pour l’intégration, les paramètres et les symbologies, les pinceaux par code‑barcode, les annotations TrackedBarcodeView, le cycle de vie, la migration de version du SDK ou le dépannage.
