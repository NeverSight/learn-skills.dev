Cordova MatrixScan Batch (плагины scandit-cordova-datacapture-*) — MatrixScan, BarcodeBatch, устаревший BarcodeTracking — отслеживание и сканирование нескольких штрихкодов одновременно с базовыми/расширенными AR‑наложениями. Используется для интеграции, настроек и символики, кастомных кистей для каждого штрихкода, аннотаций TrackedBarcodeView, жизненного цикла, миграции версии SDK или устранения неполадок.
