MatrixScan Count (BarcodeCount) в .NET для iOS‑проекта (net*-ios, NuGet‑пакет Scandit.DataCapture.Barcode, без MAUI) — подсчёт/приём штрих‑кодов пакетно с помощью BarcodeCountView в UIViewController, захват/приём списков, пространственная карта, явно управляемая камера. Для приложений MAUI используйте matrixscan-count-net-maui. Применяется для интеграции, настройки параметров, обработки результатов, настройки UI, миграции версии SDK или устранения проблем в процессах подсчёта.
