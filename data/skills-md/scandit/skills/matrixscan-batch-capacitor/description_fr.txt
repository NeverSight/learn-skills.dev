Capacitor MatrixScan Batch (scandit-capacitor-datacapture-barcode) — MatrixScan, BarcodeBatch, legacy BarcodeTracking — suivi et lecture de plusieurs codes-barres à la fois avec des superpositions AR basiques/avancées dans les applications Capacitor iOS/Android (pas le pendant web simple). Utilisez pour l'intégration, les paramètres et les symbologies, les pinceaux par code-barres, les annotations TrackedBarcodeView, le cycle de vie, la migration de version du SDK ou le dépannage.
