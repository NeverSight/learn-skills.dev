Capacitor MatrixScan Batch (scandit-capacitor-datacapture-barcode) — MatrixScan, BarcodeBatch, устаревший BarcodeTracking — отслеживание и сканирование нескольких штрихкодов одновременно с базовыми/расширенными AR‑оверлеями в приложениях Capacitor для iOS/Android (не в веб‑версии). Используется для интеграции, настроек и символогий, кистей для каждого штрихкода, аннотаций TrackedBarcodeView, жизненного цикла, миграции версии SDK или устранения неполадок.
