MatrixScan Batch (MatrixScan, BarcodeBatch, Scandit KMP) dans les projets Kotlin Multiplatform (KMP) (`com.scandit.datacapture.kmp` packages, `com.kmp.datacapture.*` imports) — suivi et numérisation de plusieurs codes‑barres simultanément dans le code partagé commonMain avec des hôtes Android/iOS et le Compose Multiplatform DataCaptureView. Utilisez‑le pour l’intégration, les paramètres et les symbologies, la gestion des codes‑barres suivis, la personnalisation des superpositions, le cycle de vie ou le dépannage.
