Escaneo de un solo código de barras con SparkScan utilizando la interfaz preconstruida `SparkScanView` en .NET para proyectos iOS (`net*-ios` framework de destino, paquete NuGet `Scandit.DataCapture.Barcode`, sin MAUI — para aplicaciones MAUI use sparkscan-net-maui). Úselo para integración, configuración de escaneo, manejo de resultados, personalización de retroalimentación, ciclo de vida del escaneo, migración de versiones del SDK (v6→v7→v8), sustitución de escáneres de terceros (ZXing.Net.Mobile) o solución de problemas.
