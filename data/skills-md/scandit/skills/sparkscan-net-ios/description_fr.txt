Scannage de code‑barres à un seul code avec l’interface `SparkScanView` pré‑construite dans .NET pour les projets iOS (`net*-ios` framework cible, NuGet `Scandit.DataCapture.Barcode`, non‑MAUI — pour les applications MAUI utilisez sparkscan-net-maui). Utilisez‑le pour l’intégration, les paramètres de scan, le traitement des résultats, la personnalisation du retour d’information, le cycle de vie du scan, la migration de version du SDK (v6→v7→v8), le remplacement des scanners tiers (ZXing.Net.Mobile) ou le dépannage.
