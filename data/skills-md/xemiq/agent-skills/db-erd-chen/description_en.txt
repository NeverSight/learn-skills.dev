Generates conceptual/logical Entity-Relationship Diagrams (ERDs) in Chen notation, including EER specialization/generalization, as uncompressed diagrams.net (draw.io) XML files saved in the project's db-design/ folder, together with SVG previews and a short summary of entities, relationships and confirmed assumptions. Use it when the user asks to create, draw, update, version or reverse-engineer an ERD, entity-relationship diagram, conceptual or logical data model, or database design diagram from a domain description, business rules, SQL DDL, migrations or ORM models. Asks clarifying questions before generating. Do not use it for physical schemas, SQL DDL, migrations, or Mermaid/PlantUML/DBML diagrams.
