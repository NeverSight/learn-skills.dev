Систематически обрабатывайте комментарии к обзору PR на GitHub: сортируйте их по достоверности, исправляйте код и публикуйте ответы. Используйте всякий раз, когда пользователь упоминает PR-обзоры, отзывы о проверке кода, комментарии рецензентов или хочет ответить на ветки обзоров по запросу на включение. Триггеры включают в себя: «обрабатывать отзывы», «ответить на комментарии по связям с общественностью», «исправить обратную связь по отзывам», «ответить рецензенту», «PR-отзыв», «回一下 обзор», «处理 обзор 意见», «рецензент 说的那个问题» или любое упоминание о работе с комментариями по PR-отзывам. Также срабатывает, когда пользователь вставляет ссылку на PR с неразрешенными разговорами, упоминает рецензента по имени в контексте своего PR или описывает ситуацию: «кто-то оставил комментарий к моему пиару», «帮我看看那些人提的意见», «CI 过了但 обзор 还没回».
