GitHub PR レビューのコメントを体系的に処理します。妥当性の優先順位付け、コードの修正、返信の投稿を行います。ユーザーが PR レビュー、コード レビューのフィードバック、レビュー担当者のコメントについて言及する場合、またはプル リクエストのレビュー スレッドに応答したい場合に使用します。トリガーには、「レビューの処理」、「PR コメントへの応答」、「レビューのフィードバックの修正」、「レビュー担当者への返信」、「看看 PR 评论」、「回一下レビュー」、「处理レビュー意见」、「レビュー担当者说的那个问题」、または PR レビュー コメントの処理に関する言及が含まれます。また、ユーザーが未解決の会話を含む PR リンクを貼り付けた場合、PR のコンテキストでレビューアーの名前に言及した場合、または状況を説明した場合にもトリガーされます (「誰かが私の PR にコメントを残しました」、「帮我看看那爾提的意见」、「CI 过了但レビュー还没回」)。
