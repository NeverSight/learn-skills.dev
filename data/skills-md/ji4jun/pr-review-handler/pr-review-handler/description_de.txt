GitHub-PR-Bewertungskommentare systematisch verarbeiten: Gültigkeit prüfen, Code korrigieren und Antworten posten. Verwenden Sie es immer dann, wenn der Benutzer PR-Bewertungen, Feedback zur Codeüberprüfung oder Kommentare von Prüfern erwähnt oder auf Überprüfungsthreads in einer Pull-Anfrage antworten möchte. Zu den Auslösern gehören: „Rezensionen bearbeiten“, „auf PR-Kommentare antworten“, „Rezensions-Feedback korrigieren“, „dem Rezensenten antworten“, „PR-Rezensionsanfrage“, „Rezensionsrezension“, „Rezensionsrezension“, „Rezensenten-Rezensionskommentare“ oder jede Erwähnung des Umgangs mit PR-Rezensionskommentaren. Wird auch ausgelöst, wenn der Benutzer einen PR-Link mit ungelösten Konversationen einfügt, einen Rezensenten im Kontext seiner PR namentlich erwähnt oder die Situation beschreibt: „Jemand hat Kommentare zu meiner PR hinterlassen“, „帮我看看那些人提的意见“, „CI 过了但 Rezension 还没回“.
