Traitez systématiquement les commentaires de révision de GitHub PR : triez la validité, corrigez le code et publiez les réponses. À utiliser chaque fois que l'utilisateur mentionne des critiques de relations publiques, des commentaires sur la révision du code, des commentaires des réviseurs ou souhaite répondre aux fils de discussion sur une demande d'extraction. Les déclencheurs incluent : "gérer les avis", "répondre aux commentaires PR", "corriger les commentaires d'avis", "répondre au réviseur", "看看 PR 评论", "回一下 review", "处理 review 意见", "reviewer 说的那个问题", ou toute mention du traitement des commentaires d'examen PR. Se déclenche également lorsque l'utilisateur colle un lien PR avec des conversations non résolues, mentionne un évaluateur par son nom dans le contexte de son PR ou décrit la situation : "quelqu'un a laissé des commentaires sur mon PR", "帮我看看那些人提的意见", "CI 过了但 review 还没回".
