Déclencher lorsqu'un utilisateur demande d'analyser, documenter, comprendre ou examiner une base de code ou un module de code. Utiliser lorsque l'utilisateur veut : générer de la documentation technique, tracer le flux de données, analyser des algorithmes, documenter des structures de données, comprendre l'architecture ou examiner la logique du code. Se déclenche sur : « analyze code », « codebase analysis », « document this code », « understand this project », « trace data flow », « 算法分析 », « 代码分析 », « 代码梳理 », « 数据结构分析 », « 技术文档 ». NE PAS déclencher pour : lecture simple de fichier, explication d'une fonction unique, questions de codage génériques.

Veuillez toujours répondre dans la langue de l'utilisateur.
