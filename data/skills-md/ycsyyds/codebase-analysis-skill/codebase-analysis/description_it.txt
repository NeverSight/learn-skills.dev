ATTIVA quando l'utente chiede di analizzare, documentare, comprendere o revisionare un codebase o un modulo di codice. Usala quando l'utente vuole: generare documentazione tecnica, tracciare il flusso dei dati, analizzare algoritmi, documentare strutture dati, comprendere l'architettura o revisionare la logica del codice. Si attiva con: “analyze code”, “codebase analysis”, “document this code”, “understand this project”, “trace data flow”, “算法分析”, “代码分析”, “代码梳理”, “数据结构分析”, “技术文档”. NON attivare per: lettura semplice di file, spiegazione di una singola funzione, domande generiche di programmazione.

Per favore rispondi sempre nella lingua dell'utente.
