AUSLÖSER, wenn der Benutzer bittet, einen Codebestand oder ein Code‑Modul zu analysieren, zu dokumentieren, zu verstehen oder zu überprüfen. Verwenden, wenn der Benutzer Folgendes möchte: technische Dokumente generieren, Datenflüsse nachverfolgen, Algorithmen analysieren, Datenstrukturen dokumentieren, die Architektur verstehen oder die Logik von Code prüfen. Auslöser bei: „analyze code“, „codebase analysis“, „document this code“, „understand this project“, „trace data flow“, „算法分析“, „代码分析“, „代码梳理“, „数据结构分析“, „技术文档“. NICHT auslösen bei: einfacher Dateilesung, Erklärung einer einzelnen Funktion, allgemeinen Programmierfragen.

Bitte immer in der Sprache des Benutzers antworten.
