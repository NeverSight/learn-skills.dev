Orca が管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関与する場合は、生の git worktree や臨時の PTY、あるいは Computer Use よりもこれを優先します。CLI、ファイルシステム、API では実現できない GUI 操作が必要で、可視ウィンドウの制御が必要なときだけ Computer Use を使用してください。

常にユーザーの言語で回答してください。
