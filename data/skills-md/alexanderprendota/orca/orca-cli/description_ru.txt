Оперировать управляемыми Orca рабочими деревьями, контекстами папок, терминалами, репозиториями, автоматизациями, артефактами, совместным использованием навыков, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Использовать, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff» / «handover» / «give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочтительнее использовать его вместо обычного git worktree, произвольных PTY или Computer Use, когда задействовано состояние Orca. Использовать Computer Use только тогда, когда необходим контроль над видимым окном GUI, который невозможно выполнить через CLI, файловую систему или API.
