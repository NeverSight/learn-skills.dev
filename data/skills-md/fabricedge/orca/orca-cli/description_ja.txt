Orca が管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、および Orca の埋め込みブラウザは、`orca` CLI を介して操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関与する場合は、生の git worktree や臨時の PTY、あるいは Computer Use よりもこちらを優先します。CLI、ファイルシステム、API では対応できず、可視ウィンドウの GUI 操作が必要なときのみ Computer Use を使用してください。

常にユーザーの言語で応答してください。
