تشغيل شجرات العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات الناتجة، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر واجهة سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضِّله على شجرة git الخام، أو PTYs المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متضمنة. استخدم استخدام الكمبيوتر فقط عندما تحتاج نافذة مرئية إلى التحكم في الواجهة الرسومية التي لا يمكن لسطر الأوامر أو نظام الملفات أو الـ API القيام بها. يرجى الرد دائمًا بلغة المستخدم.
