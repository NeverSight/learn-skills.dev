Управляйте пространствами, папками и файлами в WeChat Work WeDrive (企业微信微盘) через wiseflow-relay — создавайте пространство, создавайте папку, загружайте изображения/видео, выводите список, получайте информацию, переименовывайте, перемещайте, удаляйте и делитесь файлами через ссылку общего доступа на уровне файла. Стандартный процесс 建空间 → 传文件 → file-share 发分享链接给同事. Учётные данные (corp_id + corp_secret) читаются из daemon.env и передаются для каждого запроса; relay — без состояния. Идентификаторы пространств/папок кэшируются локально в spaces.json.
