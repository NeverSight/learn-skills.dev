Gestisci spazi, cartelle e file in WeChat Work WeDrive (企业微信微盘) tramite wiseflow-relay — crea spazio, crea cartella, carica immagine/video, elenca, ottieni informazioni, rinomina, sposta, elimina e condividi file tramite link di condivisione a livello di file. Flusso standard: crea spazio → carica file → file‑share invia link di condivisione ai colleghi. Le credenziali (corp_id + corp_secret) vengono lette da daemon.env e passate per ogni richiesta; il relay è senza stato. Gli ID di spazio/cartella sono memorizzati localmente in spaces.json.
