La base de connaissances complète hors ligne de l’API DJI Cloud, extraite du site officiel developer.dji.com (v1.16.1). Elle couvre les concepts de base, les sujets MQTT, les attributs du modèle d’objet et les énumérations de champs, les interfaces HTTP/WebSocket, le format de trajet de vol DJI WPML, le vol de commande DRC, les codes d’erreur, les alertes HMS, ainsi que les 145 pages de documentation officielle. Pour tout projet impliquant les DJI Docks (Dock 1/2/3), l’intégration de DJI Pilot 2 avec des clouds tiers, le développement de plateformes cloud pour drones, les tâches de dock/les itinéraires de vol/la diffusion en direct/les médias/la gestion des appareils/les mises à jour du firmware/le débogage à distance/les zones de vol personnalisées/le décollage en un clic, vous pouvez interroger directement cette base de connaissances pour obtenir des réponses sans accéder au site officiel.
