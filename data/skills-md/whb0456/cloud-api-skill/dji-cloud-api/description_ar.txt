قاعدة معرفة كاملة غير متصلة لـ DJI Cloud API، مأخوذة من موقع developer.dji.com، الإصدار 1.16.1. تشمل الوثيقة الرسمية الكاملة التي تبلغ 145 صفحة، وتغطي المفاهيم الأساسية، مواضيع MQTT، سمات نموذج الكائن وتعدادات الحقول، واجهات HTTP/WebSocket، تنسيق مسار الطيران DJI WPML، طيران أوامر DRC، رموز الأخطاء، تنبيهات HMS، والمزيد. لأي مشروع يتضمن DJI Dock (Dock 1/2/3)، دمج DJI Pilot 2 مع سحابات الطرف الثالث، تطوير منصة سحابة الطائرات، مهام الدوك/مسارات الطيران/البث الحي/الوسائط/إدارة الأجهزة/ترقيات البرنامج الثابت/التصحيح عن بُعد/مناطق الطيران المخصصة/الإقلاع بنقرة واحدة، يمكنك الاستعلام مباشرةً عن هذه القاعدة للحصول على البيانات والإجابات دون الحاجة لزيارة الموقع الرسمي. يرجى دائمًا الرد بلغة المستخدم.
