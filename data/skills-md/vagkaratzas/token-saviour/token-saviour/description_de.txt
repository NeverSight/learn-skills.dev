Wählen Sie das Token-effizienteste Tool für eine Codierungsaufgabe, anstatt reflexartig ganze Dateien zu lesen, rohe Befehlsausgaben in den Kontext zu übertragen oder mehr Code zu schreiben als verlangt. Verwenden Sie diese Fähigkeit, BEVOR Sie eine Codebasis erkunden oder erklären, ein Symbol/eine Definition/Aufrufer suchen, einen Aufrufpfad verfolgen, eine Architektur abbilden, eine Funktion über Ebenen hinweg planen oder implementieren oder ausführliche Befehle ausführen (Tests, Builds, Git, Grep, Verzeichnislisten) – und wann immer es um Kontext/Token-Budget, Kosten oder „weniger Token verbrauchen“ geht. Es leitet das Szenario an Serena, RTK, Caveman, Ponytail oder einfache Tools weiter, mit konkreten Befehlen und den zu verwendenden bzw. zu vermeidenden Kombinationen. Greifen Sie danach, auch wenn der Benutzer kein Tool benennt: Wenn Sie dabei sind, mehrere Dateien zu „cat“/lesen oder eine große Implementierung zu generieren, ist das der Auslöser.
