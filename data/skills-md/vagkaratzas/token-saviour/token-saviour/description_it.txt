Scegli lo strumento più efficiente in termini di token per un'attività di codifica invece di leggere di riflesso interi file, scaricare l'output di comandi non elaborati nel contesto o scrivere più codice di quanto richiesto. Usa questa abilità PRIMA di esplorare o spiegare una base di codice, individuare un simbolo/definizione/chiamanti, tracciare un percorso di chiamata, mappare un'architettura, pianificare o implementare una funzionalità su più livelli o eseguire comandi dettagliati (test, build, git, grep, elenchi di directory) e ogni volta che viene visualizzato il budget del contesto/token, il costo o "fai in modo che utilizzi meno token". Indirizza lo scenario a serena, rtk, cavernicolo, coda di cavallo o strumenti semplici, con comandi concreti e le combinazioni da usare ed evitare. Raggiungilo anche quando l'utente non nomina uno strumento: se stai per `cat`/leggere diversi file o se stai per generare una grande implementazione, questo è l'innesco.
