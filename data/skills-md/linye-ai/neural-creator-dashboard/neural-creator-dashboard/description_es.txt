Crea una página web “Creative Neural Network Dashboard” para las notas Markdown/Obsidian del usuario y sus datos de trabajo — con un núcleo central de estrella luminosa, cinco conglomerados estelares en módulos basados en esqueletos de constelaciones reales, con líneas de constelación que se expanden a cada pieza de contenido al hacer clic, y un panel de análisis a la derecha. El fondo es azul‑violeta profundo del espacio con líneas de constelación doradas, y todo el visual se renderiza cuadro a cuadro mediante código sin utilizar recursos de imágenes o video, ejecutándose puramente en el frontend localmente. Utilízalo cuando el usuario desea un tablero de creador o conocimiento estilo red neuronal, quiere visualizar notas de Obsidian, métricas de trabajo y enlaces bidireccionales, o menciona un neural‑creator‑dashboard.
