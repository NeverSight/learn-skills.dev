Ejecute la refactorización arquitectónica a partir de un documento de evaluación con operaciones deterministas y fragmentadas y una verificación agresiva en cada paso. Úselo cuando tenga una evaluación arquitectónica, una revisión de arquitectura limpia, recomendaciones de refactorización o resultados desgarradores y necesite realizar la refactorización de manera segura. Úselo también cuando se le solicite "refactorizar en función de esta evaluación", "ejecutar estas recomendaciones arquitectónicas", "arreglar la deriva arquitectónica", "refactorizar en fragmentos" o cualquier solicitud para reestructurar sistemáticamente una base de código de acuerdo con un plan. Diseñado específicamente para evitar el tipo de deriva del agente que causa problemas arquitectónicos en primer lugar.
