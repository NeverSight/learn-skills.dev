Diagnostica e migliora le prestazioni TCP di un server Linux via SSH, includendo BBR, TCP Brutal, gestione delle code, compatibilità del kernel e pulizia delle ottimizzazioni di rete esistenti. Utilizza per l'ottimizzazione della rete di VPS o server proxy, l'installazione/configurazione del controllo della congestione e la verifica o il ripristino delle modifiche di tuning.

Si prega di rispondere sempre nella lingua dell'utente.
