À utiliser lors du test d'applications Web locales à l'aide de Playwright. Les déclencheurs comprennent des demandes de vérification des fonctionnalités frontales, de débogage du comportement de l'interface utilisateur, de capture de captures d'écran du navigateur, d'affichage des journaux du navigateur ou de test interactif de toute application Web. Écrivez des scripts Playwright Python natifs pour toutes les tâches de test d'applications Web.
