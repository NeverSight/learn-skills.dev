Создание страницы, которая выглядит как уже существующая в курсе страница — скопировать модельную страницу с помощью `duplicate_scene`, затем переписать её текст, используя одну операцию `patch_stage` на каждый слот контента. Применяется, когда новая страница должна унаследовать дизайн существующей страницы, независимо от того, пришла ли модельная страница из импортированной колоды или была ранее написана в курсе. Не предназначено для редактирования уже нужной страницы (это `pro-editing`) и не для работы на уровне курса по каталогизации макетов и назначению их каждому пункту плана (это `style-clone`).
