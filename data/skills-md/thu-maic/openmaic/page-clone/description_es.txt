Construir una página que se vea como una página que el curso ya tiene — copiar la página modelo con `duplicate_scene`, luego reescribir las palabras de la copia con una operación `patch_stage` por cada hueco de contenido. Úsalo cuando una página nueva debe heredar el diseño de una página existente, ya sea que la página modelo provenga de una baraja importada o que el curso la haya creado antes. No es para revisar una página que ya es la que deseas (eso es `pro-editing`), y no es para el trabajo a nivel de curso de catalogar diseños y asignar uno por entrada del esquema (eso es `style-clone`).
