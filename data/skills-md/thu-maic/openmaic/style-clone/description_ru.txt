Создание нового курса внутри чужой презентации — импортировать презентацию как библиотеку макетов, затем создавать каждую страницу нового курса, копируя подходящий макет и переписывая его содержимое элемент за элементом, чтобы результат выглядел так, будто его создал оригинальный автор. Используйте, когда в сессии есть импортированная презентация (или `.pptx` для импорта) и задача — преподавать новый материал в её дизайне — её палитре, типографике, способе разбивки страницы. Не подходит для прямого импорта, который должен оставаться идентичным слайд‑за‑слайдом файлу (это `pptx-import`), и не подходит для извлечения того, как учитель говорит, из записи или раздаточного материала (это `teacher-style-clone`, который обеспечивает голос, а этот — внешний вид; они работают вместе).
