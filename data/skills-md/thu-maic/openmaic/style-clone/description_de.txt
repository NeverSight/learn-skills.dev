Ein neuer Kurs wird in das Deck eines anderen eingebettet — das Deck wird als Bibliothek von Layouts importiert, dann wird jede Seite des neuen Kurses erstellt, indem das passende Layout kopiert und dessen Inhalt Element für Element neu geschrieben wird, sodass das Ergebnis so wirkt, als hätte es der ursprüngliche Autor erstellt. Verwenden, wenn die Sitzung ein importiertes Deck (oder eine zu importierende `.pptx`) hat und die Aufgabe darin besteht, neues Material im Design zu vermitteln — seiner Farbpalette, seiner Typografie, seiner Art, eine Seite zu gliedern. Nicht für einen reinen Import, der slide‑für‑slide identisch mit der Datei bleiben muss (das ist `pptx-import`), und nicht für das Herausziehen der Sprechweise eines Lehrenden aus einer Aufnahme oder einem Handout (das ist `teacher-style-clone`, das die Stimme liefert, während dieses hier das Aussehen liefert; beide ergänzen sich).
