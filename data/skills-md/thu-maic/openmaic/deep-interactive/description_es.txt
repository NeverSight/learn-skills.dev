Cursos profundamente interactivos. Planifica el curso de modo que el aprendiz manipule algo en la mayoría de las páginas — simulaciones, diagramas que explora, código que ejecuta, juegos, escenas 3D — con diapositivas reservadas para el marco de apertura y la consolidación final. Úsalo cuando el tema tenga un mecanismo, una variable para variar, un proceso para rastrear o una estructura para inspeccionar.
