Глубокие интерактивные курсы. Планируют курс так, чтобы обучающийся манипулировал чем‑то на большинстве страниц — симуляциями, диаграммами, которые исследует, кодом, который запускает, играми, 3D‑сценами — а слайды оставляются только для вводного кадра и финального закрепления. Используйте, когда у темы есть механизм, переменная для изменения, процесс для отслеживания или структура для изучения.
