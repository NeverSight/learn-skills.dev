Creazione basata sull’evidenza di una Skill riutilizzabile per la realizzazione di corsi personali a partire dalla cronologia della classe e delle chat dell’utente. Usala quando l’utente chiede di riassumere, analizzare o apprendere dai propri precedenti record/storia di creazione di corsi e di creare una Skill personale, esclusiva o riutilizzabile, come “总结我的做课记录，给我做个专属 Skill” o “从我过去的课程和对话里提炼一个个人技能”. Rispondi sempre nella lingua dell’utente.
