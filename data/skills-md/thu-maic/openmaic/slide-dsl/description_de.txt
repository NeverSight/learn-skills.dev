Das vollständige Slide‑DSL‑Handbuch — die Leinwand und ihr Hintergrund, die zehn Elementtypen Feld für Feld mit Einheiten, Vorgaben und zulässigen Werten, wo jeder Typ seine Wörter behält, welches Feld der Renderer tatsächlich malt, wenn sich zwei widersprechen, genau was mit dem HTML passiert, das Sie in `content` einfügen, und das Struktur‑Schema, das jetzt das EINZIGE ist, gegen das ein Schreibvorgang geprüft wird. Nichts filtert Ihr Markup und nichts normalisiert Ihre Werte, daher ist dieses Handbuch das Ganze dessen, was eine Seite korrekt rendern lässt. Laden Sie es, bevor Sie ein Feld patchen, das Sie noch nie zuvor gepatcht haben, wenn ein Patch zurückgewiesen wird, wenn ein Patch ankommt, aber nichts auf dem Bildschirm bewegt, oder wenn Sie wissen müssen, wo eine Farbe, eine Schrift, eine Tabellenzelle oder eine Code‑Zeile wirklich lebt. Dies ist ein Feld‑Referenzwerk und kein Verfahren — `page-clone` und `pro-editing` entscheiden, welche Seiten berührt werden, `slide-craft` entscheidet, wie eine gute Seite aussieht, und dieses hier sagt, was das JSON bedeutet.
