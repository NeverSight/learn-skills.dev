Créez une affiche atmosphérique haut de gamme de style carte postale de voyage 3:4 à partir de la photo téléchargée : conservez l'image réelle dans la moitié supérieure et restituez le lieu ou l'action du sujet dans la moitié inférieure sous la forme d'un léger souvenir d'aquarelle. Convient pour les villes, les rivières, les paysages naturels, les voyages, les sports, les portraits et les moments en famille ; les séries de portraits doivent utiliser les règles d’aquarelle dynamique Water Motion.
