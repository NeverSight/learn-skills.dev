# 明信片意境海报

把每张照片转成一张独立的 3:4 竖版编辑式明信片海报。核心关系是：

> 上半部记录发生了什么；下半部保留这个瞬间的感觉。

这是一套图像生成 Skill，不是程序化排版器。生成后必须检查版式、人物识别、文字和水彩主体比例；若明显违反规则，应重新生成或修正。

## 基本流程

1. 先检查照片，判断它属于场景系列还是人物动态系列。
2. 找出照片的叙事中心：地点特征、人物、动作、关系、光线和关键物件。
3. 保留照片的原始叙事，在画布上建立严格的上下 50/50 分区。
4. 上半部使用忠实的原始照片，只做轻微编辑式调色。
5. 下半部只提炼必要的地点线索或人物动作，转成有纸张留白的水彩记忆。
6. 根据原照片和用户提供的信息设置标题、地点、年份和分隔线。
7. 直接生成海报，不要只返回 Prompt，除非用户明确只要 Prompt。
8. 检查成品；一张照片对应一张海报，多张照片不得合成 collage。

## 不可妥协的版式

- 画布为 3:4 竖版。
- 上半部和下半部各占约 50%，分界清楚但不必使用粗边框。
- 两个半区必须像同一张高级旅行出版物封面，而不是两张图硬拼在一起。
- 下半部使用暖白或浅象牙色水彩纸，纸张本身必须成为留白的一部分。
- 标题和信息层只能放在下半部留白处，不得压住关键人物或主体。

## 上半部：真实照片

- 尽可能保留人物身份、面部特征、表情、发型、体型比例、衣物、配件、姿势、动作、空间关系、相机视角、光线和原始环境。
- 只做轻微的编辑式色彩调整；不要过度美颜、改脸、改姿势或把真实物件替换成虚构物件。
- 若为了 3:4 需要扩展画面，只扩展天空、地面、墙面、植被、道路或建筑等环境区域。
- 画面中有多个人时，保留对主要叙事有贡献的人，并保持他们的相对位置、距离、方向和互动关系。

## 下半部：水彩记忆

- 不要完整重画照片，也不要做成一块矩形的“水彩滤镜背景”。
- 提炼情绪中心、主要轮廓、动作方向、关键物件和少量环境线索；其余部分逐渐消失到纸张、颜料和留白中。
- 使用透明色层、湿画法、干湿笔触叠加、自然渗色、边缘积色、颗粒和未完成的笔触。
- 从原照片压缩出约 3–5 个主色，水彩整体比照片更轻、更安静；重要的衣物颜色可以保留但要降低饱和度。
- 场景系列的水彩主体通常是中等偏小的视觉群落，约占下半部宽度 35%–60%；可以横向铺开，但四周必须留出明显空白。
- 人物系列以下半部的**留白与意境优先**：以人物正常复现的视觉尺度为基准，先将水彩人物整体缩小到约 60%–75%；如果画面仍显拥挤，可以继续缩小到 60% 以下，直到纸张留白成为下半部的主面积。
- 缩小不是把人物做成模糊的小点：脸部情绪、身体重心、关键动作和人物关系仍须可辨；当“更大的人物”和“更好的意境”冲突时，优先选择更小的人物和更大的留白。
- 环境必须比主体淡化，只留下能帮助识别地点的几笔线索。

## 系列选择

### 场景系列｜Postcard Scene

适用于城市、河流、海边、道路、建筑、自然、日落和旅行风景。

- 从照片中选择 1–3 个地点识别线索，例如天际线、河面、桥、道路、树、栏杆、建筑轮廓或一组云层。
- 不复制整张背景；让线索以小型、疏朗的水彩群落漂浮在纸面上。
- 保留原照片的主色关系，例如蓝色河水、灰蓝天际线、暖金日落、浅绿色草地。
- 透视和主要方向要与照片一致，但细节可以溶解、断裂和留白。

### 人物系列｜Watercolor Motion

- 人物使用水彩技法表现，但核心不是精细写实，而是捕捉运动中的瞬间。
- 严格保留原照片人物的**动作骨架、身体重心、四肢方向、姿态和运动轨迹**。
- 使用 **wet-on-wet、干湿笔触叠加、半透明色层和自然水痕**表现人物。
- **刻意保留运动模糊（motion blur）**：头发、裙摆、衣角、手臂、腿部以及运动器材，可以沿运动方向出现轻微拖影、颜料晕散和重复笔触。
- 动态越强的部位，边缘越可以模糊、破碎、消散；身体重心和关键识别部位则相对清晰。
- 不要把人物每条轮廓都描完整。采用 **“局部清晰 + 局部消失”** 的处理，让人物像正在纸面上移动。
- 可以用少量快速、方向明确的水彩飞白和扫笔表现**速度线、挥动轨迹、身体旋转和惯性**，但不要添加漫画式速度线。
- 运动模糊必须遵循真实动作方向，**不能只是随机把颜料晕开**。
- 保留水彩颜料自然渗透、颜色重叠、边缘积色、纸张吸水产生的不规则痕迹。
- 环境比人物更加淡化，让视线集中在**动作本身**。
- 人物不要填满下半部；人物四周，尤其是头顶、动作延伸方向和身体两侧，要保留连续的象牙色纸面与呼吸空间。

人物系列的最终效果应该是：

> **不是“一个水彩画的人”，而是“一个正在运动的人，被水彩捕捉下来的瞬间”。**

人物系列还必须满足：

> **人物只是记忆的锚点，留白和整体意境才是主角。**

例如高尔夫挥杆，应沿着“球杆挥动方向 → 手臂延伸 → 上半身旋转 → 裙摆甩动 → 双腿重心变化”建立一整条运动链，水彩拖影顺着这条链走。

## 信息层与字体

- 默认采用克制的编辑式排版：主标题和一条短分隔线；地点、年份根据系列和用户要求可选。
- 主标题通常为 1–4 个英文单词，使用大写、细字重、宽字距；不要为了填空而编造标题。
- 人物系列默认只放主标题和短分隔线；场景系列或用户明确要求明信片信息时，可加入地点和年份。
- 地点和年份只能使用用户提供或照片上下文中明确可确认的信息；不要自行发明日期、地点或年份。
- 主标题可以是一行，地点和年份可以各占一行；信息层总量要少，不能变成长说明或宣传文案。
- 如果用户明确要求无文字，完全移除信息层；如果用户提供中文标题，优先保留中文，不要自动翻译。
- 标题、地点和年份之间保持足够留白，不要与水彩主体争夺注意力。

## 生成后的质量检查

- 上半部仍然像真实照片，而不是被重新绘制的相似场景。
- 上下分区清楚，整体比例接近 3:4 和 50/50。
- 场景系列没有复制完整背景；人物系列没有牺牲动作骨架来换取“漂亮水彩”。
- 人物的重心、四肢方向、运动轨迹和人与人之间的关系仍然可辨。
- 运动模糊遵循真实物理方向，不是随机晕染或漫画速度线。
- 下半部纸张、留白、透明颜料和未完成边缘仍然明显。
- 标题、地点、年份没有错字、乱码、额外段落或虚构事实。
- 没有装饰性边框、过密背景、卡通风、3D 渲染或过量飞溅。
