一次性從多個求職平台抓取職缺資訊，並製作一個已驗證、去重的表格。

將「find jobs / scrape job postings / build a job list / monitor new jobs / track a company's careers page」等請求導向至多平台職缺抓取器（LinkedIn、Indeed、Glassdoor、The Muse 以及無需 API 金鑰的版面）或僅遠端職缺聚合器（RemoteOK、We Work Remotely、Remotive、Jobicy、Himalayas、HN Who is hiring），並執行輸出本地性檢查、各平台的原始／合格／去重計數、僅新職缺監控、平台上限以及實際成本估算。

當使用者需要跨平台抓取職缺、在沒有 API 金鑰的情況下取得 Indeed 或 Glassdoor 的職缺、蒐集遠端開發者職缺、監控公司在 Greenhouse、Lever、Ashby 等平台的職涯頁面，或設定每日新職缺提醒時，請使用此功能。

請務必使用使用者的語言回覆。
