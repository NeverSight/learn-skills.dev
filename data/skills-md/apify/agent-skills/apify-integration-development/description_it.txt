Progetta e crea un'integrazione Apify ufficiale per il prodotto di un'azienda: app di automazione del flusso di lavoro (stile Zapier/n8n), plug-in dell'agente AI (competenze dell'agente di codifica + bundle MCP o cablaggi in stile OpenClaw/Hermes), pacchetti framework AI (stile LangChain/LlamaIndex) o client di applicazioni dirette tramite apify-client. Da utilizzare durante la pianificazione, la creazione o la revisione di un'integrazione che espone attori, esecuzioni, set di dati o archivi di valori-chiave Apify all'interno di un altro prodotto.
