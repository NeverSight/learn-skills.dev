Apri e modifica i progetti .uid registrati, confronta i rendering reali con i riferimenti e implementali nel codice dell'applicazione. Crea e modifica un design Compose UI su MCP rispetto a un deployment compose-preview serve — crea una schermata o un widget Wear, inserisci e modifica i nodi e esporta in Kotlin, PNG o SVG. Usalo anche quando non esiste un host e il builder deve essere eseguito localmente (ui-builder --no-project). Usalo quando ti viene chiesto di costruire, modificare o revisionare un design UI Builder (un URL del tipo /ui-builder/catalog/design-id), per esplorare versioni alternative, per trasformare un design approvato in codice Compose o per trovare il design che implementa una PR, o per collaborare con un designer su un progetto.
