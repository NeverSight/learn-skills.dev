افتح وقم بتحرير تصاميم .uid المُدخلة، قارن العروض الحقيقية بالمراجع، ونفّذها في كود التطبيق. أنشئ وصحّح تصميم Compose UI فوق MCP مقابل نشر compose‑preview — أنشئ شاشة أو عنصر واجهة Wear، أدخل وعدّل العقد، وصدر الكود بلغة Kotlin أو صورة PNG أو SVG. استخدمه أيضًا عندما لا يكون هناك مضيف ويجب تشغيل المُنشئ محليًا (ui‑builder --no‑project). استخدمه عند الطلب لبناء أو تعديل أو مراجعة تصميم UI Builder (رابط مثل /ui-builder/catalog/design-id)، لاستكشاف إصدارات بديلة منه، لتحويل تصميم معتمد إلى كود Compose أو للعثور على التصميم الذي يطبّقه طلب السحب، أو للتعاون مع مصمم على تصميم ما.
