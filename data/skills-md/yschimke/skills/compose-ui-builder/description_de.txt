Öffnen und bearbeiten Sie eingecheckte .uid‑Designs, vergleichen Sie reale Renderings mit Referenzen und implementieren Sie sie im Anwendungscode. Erstellen und editieren Sie ein Compose‑UI‑Design über MCP gegenüber einer compose‑preview‑Serve‑Bereitstellung – erstellen Sie einen Screen oder ein Wear‑Widget, fügen Sie Knoten ein und bearbeiten Sie sie und exportieren Sie Kotlin, PNG oder SVG. Verwenden Sie es zudem, wenn kein Host existiert und der Builder lokal ausgeführt werden muss (ui‑builder --no‑project). Verwenden Sie es, wenn Sie aufgefordert werden, ein UI‑Builder‑Design zu bauen, zu ändern oder zu prüfen (eine URL wie /ui‑builder/catalog/design‑id), um alternative Versionen zu erkunden, ein genehmigtes Design in Compose‑Code zu verwandeln oder das Design zu finden, das ein PR implementiert, oder um mit einem Designer an einem Design zusammenzuarbeiten.
