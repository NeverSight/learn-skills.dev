체크인된 .uid 디자인을 열고 편집하며, 실제 렌더링을 참조와 비교하고 이를 애플리케이션 코드에 구현합니다. MCP 위에서 compose‑preview serve 배포와 함께 Compose UI 디자인을 작성하고 편집합니다 — 화면이나 Wear 위젯을 만들고, 노드를 삽입·편집하며 Kotlin, PNG 또는 SVG로 내보냅니다. 또한 호스트가 없고 빌더를 로컬에서 실행해야 할 때(ui‑builder --no‑project) 사용합니다. UI Builder 디자인을 구축·변경·검토하도록 요청받았을 때(예: /ui‑builder/catalog/design‑id와 같은 URL), 하나의 대안 버전을 탐색하거나 승인된 디자인을 Compose 코드로 변환하거나 PR이 구현한 디자인을 찾거나 디자이너와 협업할 때 사용합니다.
