Ouvrez et modifiez les conceptions .uid enregistrées, comparez les rendus réels aux références et implémentez‑les dans le code de l’application. Créez et éditez une conception Compose UI sur MCP par rapport à un déploiement compose-preview serve — créez un écran ou un widget Wear, insérez et modifiez des nœuds, puis exportez le Kotlin, le PNG ou le SVG. Utilisez également lorsque aucun hôte n’est disponible et que le builder doit être exécuté localement (ui-builder --no-project). Utilisez‑le lorsqu’on vous demande de construire, modifier ou réviser une conception UI Builder (une URL du type /ui-builder/catalog/design-id), pour explorer des versions alternatives, transformer une conception approuvée en code Compose, identifier la conception implémentée par une PR, ou collaborer avec un designer sur une conception.
