Abrir y editar diseños .uid registrados, comparar renders reales con referencias y implementarlos en el código de la aplicación. Crear y editar un diseño de Compose UI sobre MCP frente a una implementación de compose‑preview serve — crear una pantalla o un widget de Wear, insertar y editar nodos, y exportar el Kotlin, PNG o SVG. También usar cuando no exista un host y el constructor deba ejecutarse localmente (ui‑builder --no-project). Usar cuando se solicite crear, cambiar o revisar un diseño de UI Builder (una URL como /ui-builder/catalog/design-id), para explorar versiones alternativas de uno, para convertir un diseño aprobado en código Compose o encontrar el diseño que implementa una PR, o para colaborar con un diseñador en uno.
