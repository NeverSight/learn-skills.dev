Проверьте оставшиеся лимиты данных, голосовых минут и SMS от CTExcel (UK) для eSIM или физической SIM с помощью локального CLI ctexcel-usage. Используйте, когда пользователь спрашивает, сколько данных осталось, когда истекает пакет или хочет периодический сводный баланс. CLI входит в систему с кодом подтверждения, отправленным по SMS, и сохраняет только cookie сеанса; эта функция управляет передачей кода, интерпретирует вывод в формате JSON и объясняет, что делать, когда сеанс истекает.

Пожалуйста, всегда отвечайте на языке пользователя.
