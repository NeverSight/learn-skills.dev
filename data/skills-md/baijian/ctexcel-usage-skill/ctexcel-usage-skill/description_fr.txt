Vérifiez les allocations de données, de voix et de SMS CTExcel (Royaume-Uni) restantes pour une eSIM ou une carte SIM physique à l'aide de l'interface de ligne de commande locale ctexcel-usage. À utiliser lorsque l'utilisateur demande combien de données il reste, lorsqu'un forfait expire ou lorsqu'il souhaite un récapitulatif du solde périodique. La CLI se connecte avec un code de vérification SMS et stocke uniquement le cookie de session ; cette compétence guide le transfert de code, interprète la sortie JSON et explique ce qu'il faut faire lorsque la session expire.
