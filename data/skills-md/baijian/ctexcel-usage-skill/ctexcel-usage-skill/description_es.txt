Compruebe las asignaciones restantes de datos, voz y SMS de CTExcel (Reino Unido) para una eSIM o SIM física utilizando la CLI local de uso de ctexcel. Úselo cuando el usuario pregunte cuántos datos quedan, cuándo expira un paquete o si desea un resumen de saldo periódico. La CLI inicia sesión con un código de verificación SMS y almacena solo la cookie de sesión; esta habilidad guía la transferencia del código, interpreta la salida JSON y explica qué hacer cuando expira la sesión.
