Controlla i residui di dati, voce e SMS di CTExcel (UK) per una eSIM o SIM fisica usando il CLI locale ctexcel-usage. Usalo quando l'utente chiede quanti dati sono rimasti, quando un pacchetto scade oppure desidera un riepilogo periodico del saldo. Il CLI accede con un codice di verifica SMS e conserva solo il cookie di sessione; questa skill guida il passaggio del codice, interpreta l'output JSON e spiega cosa fare quando la sessione scade.

Rispondi sempre nella lingua dell'utente.
