مهندس وتحقق من الواجهات مقابل عقد UX مكوّن من 235 قاعدة مع فحوصات قابلة للتنفيذ، لا آراء. استخدم ذلك عند بناء أو تعديل أي شاشة أو تدفق أو صفحة أو مكوّن أو نموذج أو جدول أو لوحة تحكم أو تخطيط — بما في ذلك إضافة صغيرة مثل عنصر حذف أو إرسال، الذي يحمل مهام التأكيد والتراجع. كذلك عند إعادة تصميم أو صقل أو تبسيط أو تقوية واجهة المستخدم، وعند تدقيق قابلية الوصول، وإعادة التدفق المستجيبة، وحالات الفراغ/التحميل/الخطأ/غير المتصل، والإجراءات المدمرة، وترتيب التركيز، والتباين، ومساحات النقر، والحركة، والنصوص الصغيرة أو انزلاق نظام التصميم. يقدم 184 فحصًا ثابتًا مرتبطًا بمعرفات القواعد المذكورة، مستوى متصفح يقيس التباين وإعادة التدفق عند 320 بكسل ويفرض الحالات التي لا يختبرها أحد، و38 قاعدة لنظامي iOS و Android — خلف بوابة لا يُعتبر فيها NOT_RUN حالة ناجحة. يعرض المكونات من العقد، يوفر الاختيار كصفحة، ويرفض تعديل واجهة المستخدم حتى يتم الموافقة على أحدها. يعرف React و Next.js و Svelte و Vue و Tailwind و SwiftUI و Compose و React Native و Flutter. استخدمه حتى إذا قال المستخدم فقط "اجعل هذا يبدو أفضل".
