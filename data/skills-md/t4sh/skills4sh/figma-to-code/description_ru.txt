Реализуйте дизайны Figma в существующей кодовой базе, сопоставьте токены дизайна и установите сопоставления компонентов и правила проекта. Используйте, когда просят «реализовать этот дизайн Figma», «превратить этот Figma в код», «создать из ссылки Figma», «совпадать с этим макетом Figma», «извлечь токены дизайна Figma», «создать правила системы дизайна Figma», «настроить руководства Figma», «подключить код к этому компоненту» или «сопоставить этот компонент Figma с кодом»; либо когда URL/выборка Figma должны стать кодом репозитория, токенами кода, правилами агента или сопоставлениями Code Connect.
