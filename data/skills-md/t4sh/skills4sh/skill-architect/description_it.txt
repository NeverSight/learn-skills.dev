Progettare e controllare le competenze degli agenti portatili per il recupero, la prevedibilità, la divulgazione progressiva, le valutazioni e i gate degli archivi. Da utilizzare quando l'utente chiede di "creare una competenza", "creare una competenza", "migliorare una competenza", "revisionare una competenza", "refattorizzare una competenza", "confrontare le rubriche delle competenze", "distillare una competenza dalle sessioni", "conciliare i piani delle competenze" o "insegnare la creazione di competenze"; quando i percorsi includono `skills/<name>/SKILL.md`, `references/*.md`, script di supporto, valutazioni, file di lock, manifest di sicurezza o adattatori del fornitore; o quando le menzioni includono creatore di abilità, sviluppo di abilità, skills.sh, descrizioni di trigger, criteri di completamento, parole principali o invocazione di modello/utente.
