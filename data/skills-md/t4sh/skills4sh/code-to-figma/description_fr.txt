Pipeline d’exportation de jetons de code vers Figma ancré dans CI pour maintenir Figma aligné avec la base de code. À utiliser lorsque l'utilisateur demande de « synchroniser le code avec Figma », « exporter des jetons de conception vers Figma », « configurer un pipeline de synchronisation Figma », « connecter le plugin tokens-sync-to-figma », « générer un figma-export.json », « créer un marcheur de page » ou « tenir Figma à jour avec la base de code ».
