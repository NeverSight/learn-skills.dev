Eleventy v3, versión preliminar de Build Awesome v4 y guía de operación de Nunjucks para la creación de sitios estáticos, plantillas, canalizaciones de compilación, migraciones y revisión de seguridad. Utilícelo cuando el usuario solicite “crear una página 11ty”, “añadir un filtro Nunjucks”, “arreglar mi cadena de diseño”, “revisar mi plantilla .njk”, “configurar Eleventy”, “migrar a Build Awesome” o “auditar mi sitio estático”; cuando `package.json` incluya `@11ty/eleventy` o `@awesome.me/buildawesome`; cuando las rutas incluyan `.eleventy.js`, `eleventy.config.js`, `.njk`, `.11tydata.js`, `.data.js`, `.11ty.js` o `.server.js`; o al depurar cascadas de datos, filtros, shortcodes, Nunjucks asíncrono, escape automático o seguridad de sitios estáticos.
