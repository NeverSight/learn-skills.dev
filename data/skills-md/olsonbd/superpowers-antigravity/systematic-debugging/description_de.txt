Verwenden Sie dieses Framework, wenn Sie auf einen Fehler, einen fehlgeschlagenen Test oder ein unerwartetes Verhalten stoßen, bevor Sie Korrekturen vorschlagen. Es handelt sich um ein vierstufiges Framework (Ursachenanalyse, Musteranalyse, Hypothesentests, Implementierung), das sicherstellt, dass Sie das Problem verstehen, bevor Sie versuchen, es zu lösen.
