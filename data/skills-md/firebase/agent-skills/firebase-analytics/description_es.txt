Guía completa para Google Analytics para Firebase (GA4F), que incluye la configuración básica, la inicialización del SDK, el seguimiento de pantallas y el registro de eventos en Android e iOS. Utiliza esta habilidad al configurar Google Analytics, agregar el SDK o registrar eventos de analítica. No la uses para iniciar sesión en la CLI de forma independiente o para descargar archivos de proyecto/configuración sin Analytics (usa firebase-basics), ni para Crashlytics, Remote Config, Auth, Firestore, Hosting, App Hosting o Data Connect.

Por favor, responde siempre en el idioma del usuario.
