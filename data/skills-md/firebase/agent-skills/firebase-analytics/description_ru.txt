Полное руководство по Google Analytics для Firebase (GA4F), включающее базовую настройку, инициализацию SDK, отслеживание экранов и журналирование событий на Android и iOS. Используйте этот навык при настройке Google Analytics, добавлении SDK или журналировании аналитических событий. Не используйте его для автономного входа через CLI или загрузки файлов проекта/конфигурации без Analytics (используйте firebase-basics), а также для Crashlytics, Remote Config, Auth, Firestore, Hosting, App Hosting или Data Connect.
