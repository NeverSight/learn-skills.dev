Guida completa per Google Analytics per Firebase (GA4F), includendo configurazione di base, inizializzazione SDK, tracciamento delle schermate e registrazione degli eventi su Android e iOS. Usa questa abilità quando configuri Google Analytics, aggiungi l'SDK o registri eventi di analisi. Non utilizzare per login CLI autonomo o per il download di file di progetto/config senza Analytics (usa firebase-basics), né per Crashlytics, Remote Config, Auth, Firestore, Hosting, App Hosting o Data Connect.
