Разрабатывает, создает, реорганизует и ужесточает правила безопасности Cloud Firestore производственного уровня (firestore.rules). Используйте при создании правил безопасности, написании средств проверки схемы/домена, предотвращении обхода обновлений, обеспечении безопасности типов и ограничений ресурсов или реализации управления доступом на основе ролей. Не используйте для аудита правил безопасности (используйте firebase-security-rules-auditor), подготовки базы данных или запросов клиентского SDK.
