Diseña, crea, refactoriza y refuerza las reglas de seguridad de Cloud Firestore de nivel de producción (firestore.rules). Úselo al crear reglas de seguridad, escribir validadores de esquema/dominio, evitar omisiones de actualizaciones, aplicar límites de recursos y seguridad de tipos o implementar control de acceso basado en roles. No lo use para auditoría de reglas de seguridad (use firebase-security-rules-auditor), aprovisionamiento de bases de datos o consultas del SDK del cliente.
