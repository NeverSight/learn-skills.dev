Entwirft, erstellt, refaktorisiert und härtet produktionstaugliche Cloud Firestore-Sicherheitsregeln (firestore.rules). Verwenden Sie diese Option, wenn Sie Sicherheitsregeln erstellen, Schema-/Domänenvalidatoren schreiben, Update-Umgehungen verhindern, Typsicherheit und Ressourcenbeschränkungen erzwingen oder eine rollenbasierte Zugriffskontrolle implementieren. Nicht für die Überwachung von Sicherheitsregeln (verwenden Sie Firebase-Security-Rules-Auditor), die Datenbankbereitstellung oder Client-SDK-Abfragen verwenden.
