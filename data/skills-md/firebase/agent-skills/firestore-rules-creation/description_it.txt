Progetta, crea, effettua il refactoring e rafforza le regole di sicurezza di Cloud Firestore a livello di produzione (firestore.rules). Da utilizzare durante la creazione di regole di sicurezza, la scrittura di validatori di schema/dominio, la prevenzione di bypass degli aggiornamenti, l'applicazione dell'indipendenza dai tipi e limiti di risorse o l'implementazione del controllo degli accessi in base al ruolo. Non utilizzare per il controllo delle regole di sicurezza (usa firebase-security-rules-auditor), il provisioning del database o le query dell'SDK del client.
