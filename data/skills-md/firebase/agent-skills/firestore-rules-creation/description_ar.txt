يقوم بتصميم وتأليف وإعادة بناء قواعد أمان Cloud Firestore على مستوى الإنتاج (firestore.rules). يُستخدم عند إنشاء قواعد الأمان، أو كتابة أدوات التحقق من صحة المخطط/المجال، أو منع تجاوزات التحديث، أو فرض أمان النوع وحدود الموارد، أو تنفيذ التحكم في الوصول المستند إلى الدور. لا تستخدمه لتدقيق قواعد الأمان (استخدم firebase-security-rules-auditor)، أو توفير قاعدة البيانات، أو استعلامات SDK للعميل.
