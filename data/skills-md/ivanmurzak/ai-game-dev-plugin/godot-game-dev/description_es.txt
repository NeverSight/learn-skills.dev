Usa cuando el usuario quiere crear, configurar o abrir un proyecto Godot con IA, instalar el complemento Godot‑MCP o sus extensiones, iniciar sesión en ai‑game.dev, conectar el editor o conectar tu agente de codificación (Claude Code, Codex, Cursor, Gemini CLI) a las herramientas MCP de Godot. Maneja godot‑cli de extremo a extremo.
