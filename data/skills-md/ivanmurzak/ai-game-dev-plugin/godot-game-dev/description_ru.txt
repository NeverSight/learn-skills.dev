Используется, когда пользователь хочет создать, настроить или открыть проект Godot с помощью ИИ, установить дополнение Godot‑MCP или его расширения, войти в ai‑game.dev, подключить редактор или связать свой кодирующий агент (Claude Code, Codex, Cursor, Gemini CLI) с инструментами MCP Godot. Обеспечивает сквозное управление godot‑cli.
