Usa quando l'utente vuole creare, configurare o aprire un progetto Godot con IA, installare l'addon Godot‑MCP o le sue estensioni, accedere a ai‑game.dev, collegare l'editor o collegare il tuo agente di programmazione (Claude Code, Codex, Cursor, Gemini CLI) agli strumenti MCP di Godot. Gestisce godot‑cli end‑to‑end.

Per favore, rispondi sempre nella lingua dell'utente.
