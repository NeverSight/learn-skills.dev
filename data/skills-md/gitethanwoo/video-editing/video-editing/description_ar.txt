تحرير أي فيديو أو صوت أو صور أو تسجيلات شاشة أو رسومات مقدمة إلى منتج نهائي مصقول. يُستخدم لتقطيع وإعادة هيكلة اللقطات، تجميع متعدد المسارات، صورة داخل صورة، الانتقالات، الترجمات، معالجة الصوت، تغييرات اللون والإطار، عروض الشاشة، تحرير المقدم، مقاطع اجتماعية، ورسوم متحركة تم إنشاؤها باستخدام FFmpeg أو HTML أو React أو SVG أو Remotion. يتضمن فحص المصدر، تصميم المخطط الزمني، أدوات وسائط قابلة لإعادة الاستخدام، توليد تغطية شفافة، عناصر مراجعة سريعة، تصيير حتمي، والتحقق الفني.
