# AI 短剧 / 漫剧编剧

为 AI 短剧和 AI 漫剧创作专业剧本与分镜脚本。融合《救猫咪》节拍表方法论、视听语言原则和 AI 生成合规要求。

详细参考资料见 [reference.md](reference.md)（节拍表、类型库、镜头速查、合规清单）。

## 创作流程

按 7 个阶段依次推进，每个阶段包含合规检查点。每完成一个阶段，向用户确认后再进入下一阶段。

详细范例见 [examples.md](examples.md)（真实爆款剧本格式范例、开场模式范例、套路模板范例）。

---

### Stage 1 — 构思与故事线

**目标**: 产出一句话故事线（logline）和明确的故事类型。

1. 询问用户：题材方向、目标平台（抖音/快手/小红书等）、目标时长（30s/60s/2-3min）、视觉风格（写实/动漫/国风等）
2. 引导选择故事类型——先从 4 大爆款套路模板入手（详见 reference.md）：
   - **身份反转型**: 隐藏身份→受辱→暴露→打脸（占爆款的 26%）
   - **复仇回归型**: 过去惨遭迫害→蛰伏→回来报仇（占 19%）
   - **穿越/金手指型**: 获得超能力/穿越→碾压→爽文（占 10%）
   - **甜宠纠葛型**: 误会→暧昧→揭秘→在一起（占 13%）
3. 也可选择 10 大经典类型（详见 reference.md）：
   - 短剧高频：**麻烦家伙**（逆袭/打脸）、**如愿以偿**（穿越/重生）、**伙伴之情**（双人CP）、**愚者成功**（扮猪吃虎）
   - 漫剧高频：**鬼怪屋**（悬疑恐怖）、**推理侦探**（解谜）、**超级英雄**（异能战斗）
4. 选择开场模式（3 种已验证的高效开场，详见 examples.md）：
   - **前世/惨剧闪回开场**: 先展示悲惨结局，再切回当下（45%的爆款使用）
   - **当下冲突直入**: 第一秒就爆发矛盾，毫无铺垫（39%的爆款使用）
   - **身份/系统觉醒**: 穿越/重生/金手指启动（16%的爆款使用）
5. 产出故事线，检查四要素：
   - **意外性**: 前提本身是否有反差/讽刺感？
   - **心理影像**: 能否让人立刻"看见"这部剧？
   - **观众定位**: 目标人群（性别/年龄/兴趣）是否清晰？
   - **标题杀伤力**: 标题是否能在信息流中抓住眼球？

**合规检查 1**:
- 题材是否触碰红线？（政治敏感、宗教争议、未成年人不当内容、历史虚无主义）
- 是否涉及真实人物肖像或知名 IP 二创？
- 若有风险，立即建议替代方向。

### Stage 2 — 角色设计

**目标**: 建立主要角色，输出行业标准的人物小传。

1. **救猫咪时刻**: 在开场前 5 秒内设计一个让观众喜欢主角的微小行为（善意举动/幽默反应/弱者姿态）
2. **原始动力**: 每个角色必须有一个原始驱动力——生存、爱、复仇、保护、自由
3. **人物小传模板**（行业标准格式，基于 31 部爆款剧本提炼）：

```
男主：[角色名]
[视觉年龄]岁，[一句话身份介绍]。
外表：[具体可视化外貌描述]
性格标签：#关键词1 #关键词2 #关键词3
人物经历：[2-3句背景故事，包含核心动机和创伤/秘密]
```

4. **AI 角色一致性补充**（附加在人物小传后，用于 AI 图像/视频生成）：

```
固定服装: [跨镜头保持一致的服装描述]
标志性道具: [如：总是戴着红围巾/习惯性推眼镜]
```

5. 主角与对手之间必须有清晰的对立关系
6. 配角也需要简短的人物小传（1-2句即可）

**合规检查 2**:
- 角色外貌描述不得指向真实公众人物
- 不得使用已有版权角色（如小猪佩奇、孙悟空特定影视版本等）
- 角色设定不含歧视性刻板印象

### Stage 3 — 结构设计

**目标**: 用适配短剧的节拍表搭建故事骨架。

根据时长选择节拍密度（详见 reference.md 完整节拍表）：

**30-60秒短剧（6拍）**:
| 节拍 | 时间点 | 内容 |
|------|--------|------|
| 钩子 | 0-3s | 视觉冲击或悬念，抓住注意力 |
| 铺垫 | 3-10s | 快速建立人物和世界观 |
| 催化剂 | 10-15s | 打破平衡的事件 |
| 挣扎 | 15-35s | 矛盾升级，主角行动 |
| 高潮 | 35-50s | 核心冲突爆发 |
| 终场 | 50-60s | 反转/升华/钩子（引导下一集） |

**1-3分钟短剧（9拍）**:
| 节拍 | 占比 | 内容 |
|------|------|------|
| 钩子 | 前3秒 | 核心冲突的视觉预告 |
| 铺垫+救猫咪 | 5-10% | 建立角色好感 |
| 催化剂 | 10-15% | 不可逆的事件发生 |
| 争执/抉择 | 15-20% | 主角面临选择 |
| 中点反转 | 50%处 | 假胜利或假失败 |
| 坏蛋逼近 | 55-70% | 压力陡增 |
| 灵魂黑夜 | 70-80% | 主角跌入谷底 |
| 高潮 | 80-90% | 核心对决 |
| 终场 | 最后10% | 主题升华 + 情绪欠条 |

**情绪欠条设计**（每集结尾至少植入一种）：
- 对人物的欠账："我想看他赢/翻身"
- 对关系的欠账："他们到底什么关系？"
- 对真相的欠账："谁在说谎？真相是什么？"

**付费节点**（如适用）：在催化剂或中点反转后设置付费解锁点，利用悬念峰值。

### Stage 3.5 — 前置文档

**目标**: 在正式写剧本前，输出完整的前置文档（81%的爆款剧本都有）。

前置文档包含三部分：

**1. 基本信息**:
```
剧名：《XXX》
类型：[都市情感/古装权谋/悬疑/穿越/男频逆袭...]
体裁：竖屏微短剧
集数：XX集
时长：1min/集
故事亮点：[一句话卖点]
一段话梗概：[100-200字故事概述]
```

**2. 人物小传**: 按 Stage 2 模板输出所有角色

**3. 剧情节奏规划**（多集剧推荐）:
```
1-5集：[开篇钩子+人物建立+核心冲突引爆]
6-15集：[矛盾升级+第一个小高潮]
16-30集：[反转+新势力介入]
...
付费节点：第X集（设在最强悬念处）
大高潮：第X-X集
结局：第X-X集
```

### Stage 4 — 剧本撰写

**目标**: 产出行业标准格式的剧本。

**格式规范**（基于 31 部爆款短剧提炼的行业统一格式）:

```
第一集
1-1  咖啡厅  日  内
人物：林小雨、陈默、服务生
△林小雨推门进入，目光扫过全场。
△陈默坐在角落，端起咖啡杯挡住半张脸。
林小雨：你说的那个人……是他？
陈默（冷笑）：三年了，他终于回来了。
△林小雨的手不自觉攥紧杯子，指节发白。
林小雨OS：不可能，他明明已经死了。
```

**格式要素说明**:
- **场景标头**: `编号  地点  时间  内/外` — 如 `1-1  酒店房间  夜  内`
- **出场人物**: 每场开头列出本场所有出场角色
- **动作描述**: 用 `△` 或 `▲` 开头（行业通用标记，31部中84%使用）
- **对白**: `角色名：台词` 或 `角色名（情绪/动作提示）：台词`
- **内心独白**: `角色名OS：内心想法` 或 `角色名（OS）：内心想法`
- **画外音**: `角色名VO：画外音内容` 或 `角色名（画外音）：内容`
- **闪回**: 用 `【闪回开始】...【闪回结束】` 或 `（回忆）...（回忆结束）`
- **字幕**: `【字幕：三年前】` 或 `字幕：XXX`
- **特效**: 需要后期特效处直接标注 `（特效）`
- **集数分隔**: `第X集` 或 `（完）`

**写作铁律**:
- 删除一切心理描写，用可拍摄动作替代（"他紧张" → "他的手指在桌面上敲个不停"）
- 对白口语化，每句不超过 12 字
- 使用可拍摄动词：推、拉、敲、摔、瞥、蹲、抖、攥、甩
- 每集 3-5 个场景，每集 500-800 字
- 平均 2-3 行动作描述后切一段对白，保持极快节奏
- **每集结尾必须有悬念/反转/冲突**（100%的爆款剧本都遵守此规则）

**合规检查 3**:
- 检查对白中是否含有敏感词（政治人物、敏感历史事件、低俗用语）
- 动作描述中避免过度暴力细节（"刀刺入腹部鲜血喷涌" → "刀光一闪，他捂住腰侧倒下"）
- 避免裸露/性暗示描述

### Stage 5 — 分镜转化

**目标**: 将剧本拆解为可直接用于 AI 生成的分镜脚本。

**每个镜头包含 7 要素**:

| 要素 | 说明 |
|------|------|
| 镜头号 | Shot 01, 02... |
| 画面内容 | 具体的人物动作、表情、环境细节（视觉化描述） |
| 景别 | 远景/全景/中景/近景/特写/大特写 |
| 运镜 | 推进/拉远/平摇/俯拍/仰拍/跟踪/静止 |
| 台词/旁白 | 角色对白或画外音文字 |
| 音效音乐 | BGM风格、环境音、特殊音效 |
| 时长 | 3-6秒/镜 |

**视听语言原则**:
- 动接动、静接静（动态镜头接动态，静态接静态）
- 景别渐进（远→中→近→特写，或反向，避免跳切）
- 不越轴（保持人物左右关系一致）
- 情绪高点用特写，建立场景用远景/全景
- 对话场景：正反打 + 过肩镜头交替

**镜头数量参考**:
- 30s: 6 镜（平均 5s/镜）
- 60s: 8-12 镜
- 2-3min: 20-36 镜

**AI 生成友好的画面描述写法**:
- 明确主体："一个穿红色旗袍的年轻女子"而非"她"
- 明确动作："双手捧着一封信，低头阅读"而非"看信"
- 明确环境："昏暗的中式老宅客厅，烛光摇曳"而非"一个房间"
- 明确光影："侧逆光，金色暖调"而非"光线好看"
- 保持角色描述一致：每镜重复角色核心外貌特征关键词

**合规检查 4**:
- 逐镜检查画面描述是否包含 AI 生成工具敏感词（详见 reference.md 敏感词表）
- 提供安全替代写法：
  - "手持武器对峙" → "两人面对面站立，气氛紧张"
  - "鲜血" → "红色液体/污渍"
  - "尸体" → "倒地的人/一动不动的身影"

---

### Stage 6 — 合规终审

**目标**: 全面检查剧本和分镜是否满足发布要求。

**三层合规清单**:

**Layer 1 — AI 生成工具合规**:
- [ ] 所有画面描述不含政治敏感词
- [ ] 不含暴力/血腥的具体描写
- [ ] 不含裸露/色情暗示
- [ ] 不含真人面孔指向（明星、政治人物）
- [ ] 不含受版权保护的角色/标志

**Layer 2 — 发布平台合规**:
- [ ] 已规划 "AI生成" 标识位置（片头/简介）
- [ ] 备案编号预留位（片头字幕）
- [ ] 创作链路可追溯（保留 AI 对话截图/工程文件建议）
- [ ] 账号已勾选 "AI创作/AI辅助创作"

**Layer 3 — 内容合规**:
- [ ] 无政治敏感、历史虚无主义内容
- [ ] 无暴力色情、低俗擦边内容
- [ ] 无未经授权的真人肖像/声音
- [ ] 无恶搞经典 IP / 儿童 IP
- [ ] 无虚假信息、伪造新闻元素
- [ ] 对白无违禁词/敏感词

通过全部检查后，输出最终剧本和分镜脚本。

## 输出格式选择

根据用户需求输出以下格式之一或组合：

| 格式 | 适用场景 | 包含内容 |
|------|---------|---------|
| 故事大纲 | 早期构思 | 故事线 + 类型 + 角色卡 + 节拍表 |
| 标准剧本 | 完整创作 | 场景描述 + 对白 + 动作指示 |
| 分镜脚本 | 进入制作 | 7要素分镜表（可导出为表格） |
| 全套交付 | 一站式 | 大纲 + 剧本 + 分镜 + 合规报告 |

## 关键原则

- **前3秒定生死**: 开场必须有视觉冲击力或强悬念
- **每120秒一个反转**: 保持情绪波动，防止观众流失
- **删减再删减**: 短剧没有废镜头，每一帧都服务于故事
- **为AI而写**: 画面描述必须是 AI 工具能理解和生成的
- **合规前置**: 在创意阶段就规避风险，而非制作完成后返工
- **情绪大于情节**: 观众记住的是感受，不是剧情细节
