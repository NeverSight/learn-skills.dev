Decide which tests are worth having. Use whenever writing, changing, reviewing, or pruning tests: a gate for every new test, and an audit workflow for tests that re-assert source, mirror the code under test, test mocks, duplicate stronger coverage, or keep test-only production code alive. Triggers: adding a regression test, 'clean up the tests', 'these tests are flaky/brittle', mock-heavy suites, coverage-driven tests.
