Decide qué pruebas valen la pena. Úsalo cada vez que escribas, modifiques, revises o elimines pruebas: una puerta para cada prueba nueva y un flujo de auditoría para pruebas que reafirmen la fuente, reflejen el código bajo prueba, prueben los mocks, dupliquen una cobertura más fuerte o mantengan vivo el código de producción exclusivo de pruebas. Desencadenantes: añadir una prueba de regresión, “limpiar las pruebas”, “estas pruebas son inestables/frágiles”, suites con muchos mocks, pruebas impulsadas por la cobertura.
