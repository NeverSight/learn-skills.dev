Décidez quels tests valent la peine d'être conservés. Utilisez‑le chaque fois que vous écrivez, modifiez, révisez ou supprimez des tests : un verrou pour chaque nouveau test, et un processus d’audit pour les tests qui réaffirment la source, reproduisent le code testé, testent les mocks, dupliquent une couverture plus forte ou maintiennent vivant le code de production présent uniquement dans les tests. Déclencheurs : ajout d’un test de régression, « nettoyer les tests », « ces tests sont instables/fragriles », suites lourdes en mocks, tests guidés par la couverture.
