استخدم هذه المهارة عند إنشاء أو تعديل أو تصحيح تكوينات Docker Compose، حتى إذا قال المستخدم فقط إنه يحتاج إلى ربط الخدمات معًا، أو إضافة قاعدة بيانات إلى مجموعته، أو إعداد بيئة تطوير محلية تضم عدة حاويات. تشمل تعريفات الخدمات، وفحوصات الصحة، وترتيب الاعتماديات، والحجمات، والشبكات، ومتغيرات البيئة، وتجاوزات التطوير. يرجى دائمًا الرد بلغة المستخدم.
