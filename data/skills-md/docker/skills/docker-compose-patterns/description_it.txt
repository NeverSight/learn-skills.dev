Usa questa competenza quando crei, modifichi o debugghi configurazioni Docker Compose, anche se l'utente dice semplicemente che ha bisogno di collegare i servizi, aggiungere un database allo stack o configurare un ambiente di sviluppo locale con più contenitori. Copre definizioni di servizio, controlli di salute, ordinamento delle dipendenze, volumi, reti, variabili d'ambiente e sovrascritture di sviluppo.

Per favore, rispondi sempre nella lingua dell'utente.
