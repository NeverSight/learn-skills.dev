在运行或推荐任何会删除、抹除、重置或以其他方式不可逆更改状态的 Docker 命令之前，请先使用此技能——即使用户仅说“清理”“清除缓存”“重新开始”“全部抹掉”“彻底删除”“重置”“强制删除”或“拆除”Docker 资源。适用于未被更具体技能覆盖的通用 Docker CLI 破坏性操作——`docker rm`、`docker rm -f`、`docker container prune`、`docker kill`、`docker system prune`、`docker rmi`/`docker image rm`、`docker image prune -a`、`docker network rm`、`docker network prune`、`docker builder prune`、`docker buildx rm`、`docker context rm`，以及独立（非 Compose） 的 `docker volume rm`/`docker volume prune`。还包括由其他 Docker 技能（Compose、sandbox、Desktop）拥有的破坏性命令。核心规则——明确说明将会失去的内容并先获得明确确认，除非是范围狭窄、低阻力的 Tier 1 容器清理。

请始终使用用户的语言作答。
