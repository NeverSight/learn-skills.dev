在執行或建議任何會刪除、抹除、重置或以其他方式不可逆地改變狀態的 Docker 指令之前，請先使用此技能——即使用戶只說「清理」、「清除快取」、「重新開始」、「全部抹掉」、「徹底摧毀」、「重置」、「強制移除」或「拆除」Docker 資源，也要使用此技能。涵蓋未被更具體技能掌管的一般 Docker CLI 破壞性操作——`docker rm`、`docker rm -f`、`docker container prune`、`docker kill`、`docker system prune`、`docker rmi`/`docker image rm`、`docker image prune -a`、`docker network rm`、`docker network prune`、`docker builder prune`、`docker buildx rm`、`docker context rm`，以及獨立（非 Compose） 的 `docker volume rm`/`docker volume prune`。同時亦列入其他 Docker 技能（Compose、sandbox、Desktop）所掌管的破壞性指令。核心規則——必須明確說明將會失去什麼，並在執行前取得明確確認，除非是範圍狹窄、低摩擦的 Tier 1 容器清理。

請始終以使用者的語言回覆。
