استخدم هذه المهارة قبل تشغيل أو توصية أي أمر Docker يقوم بالحذف أو المسح أو إعادة الضبط أو أي تغيير لا يمكن عكسه — حتى إذا قال المستخدم فقط "نظّف"، "امسح الذاكرة المؤقتة"، "ابدأ من الصفر"، "امسح كل شيء"، "دمره"، "أعد الضبط"، "إزالة بالقوة"، أو "تدمير" موارد Docker. يغطي ذلك عمليات CLI العامة لتدمير Docker التي لا تملكها مهارة أكثر تحديدًا — `docker rm`، `docker rm -f`، `docker container prune`، `docker kill`، `docker system prune`، `docker rmi`/`docker image rm`، `docker image prune -a`، `docker network rm`، `docker network prune`، `docker builder prune`، `docker buildx rm`، `docker context rm`، و`docker volume rm`/`docker volume prune` المستقلة (غير Compose). كما يدرج أوامر التدمير التي تملكها مهارات Docker أخرى (Compose، sandbox، Desktop). القاعدة الأساسية — صِف بدقة ما سيفقد واطلب تأكيدًا صريحًا أولًا، باستثناء عمليات تنظيف حاوية المستوى الأول الضيقة منخفضة الاحتكاك.
