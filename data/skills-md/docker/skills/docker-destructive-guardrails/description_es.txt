Utiliza esta habilidad antes de ejecutar o recomendar cualquier comando de Docker que elimine, borre, reinicie o cambie de forma irreversible el estado, incluso si el usuario solo dice “limpiar”, “borrar la caché”, “empezar de nuevo”, “borrar todo”, “destruirlo”, “reiniciar”, “forzar eliminación” o “desmontar” recursos de Docker. Cubre operaciones destructivas genéricas del CLI de Docker que no pertenecen a una habilidad más específica: `docker rm`, `docker rm -f`, `docker container prune`, `docker kill`, `docker system prune`, `docker rmi`/`docker image rm`, `docker image prune -a`, `docker network rm`, `docker network prune`, `docker builder prune`, `docker buildx rm`, `docker context rm` y los comandos independientes (no Compose) `docker volume rm`/`docker volume prune`. También indexa comandos destructivos gestionados por otras habilidades de Docker (Compose, sandbox, Desktop). Regla principal: indicar exactamente lo que se perderá y obtener una confirmación explícita primero, salvo en limpiezas estrechas y de baja fricción de contenedores de Nivel 1.

Por favor, responde siempre en el idioma del usuario.
