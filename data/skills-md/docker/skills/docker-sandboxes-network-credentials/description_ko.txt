이 기술은 Docker Sandboxes(`sbx`) 샌드박스가 네트워크에서 접근할 수 있는 대상이나 인증에 사용할 자격 증명을 설정할 때 사용합니다. 사용자가 단순히 “에이전트가 내부 API를 호출하도록 허용”, “모든 네트워크 접근 차단”, “에이전트에 GitHub 토큰 제공”, 또는 “샌드박스에 대한 개인 레지스트리 이미지 사용”이라고 말하더라도 적용됩니다. `sbx policy init/allow/deny/ls/inspect/log/check/rm network`(전역 및 샌드박스별 egress 규칙, deny‑over‑allow 우선순위)와 `sbx secret set/set‑custom/ls/rm/import`(서비스 비밀, `--ref`/`--command` 로 지정하는 동적 비밀, 그리고 기본적으로 호스트당 풀만 허용되는 레지스트리 풀 인증 정보 주입 범위)를 포함합니다.
