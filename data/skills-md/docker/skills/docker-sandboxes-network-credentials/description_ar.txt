استخدم هذه المهارة عند تكوين ما يمكن لبيئة عمل Docker Sandboxes (`sbx`) الوصول إليه على الشبكة أو بيانات الاعتماد التي تُصَدِّق بها، حتى لو قال المستخدم فقط أنه يريد «السماح للوكيل باستدعاء واجهة برمجة تطبيقات داخلية»، «حظر كل الوصول إلى الشبكة»، «توفير رمز GitHub للوكيل»، أو «استخدام صورة سجل خاصة لبيئة عمل». يغطي `sbx policy init/allow/deny/ls/inspect/log/check/rm network` (قواعد الخروج العامة وعند كل بيئة عمل، أولوية الرفض على السماح) و `sbx secret set/set-custom/ls/rm/import` (أسرار الخدمة، أسرار ديناميكية عبر ‎--ref/--command، وبيانات اعتماد سحب السجل بنطاق حقن افتراضي يسمح بالسحب من المضيف فقط).

الرجاء دائمًا الرد بلغة المستخدم.
