Utiliza esta habilidad al configurar a qué puede acceder una sandbox Docker Sandboxes (`sbx`) en la red o con qué credenciales se autentica, incluso si el usuario solo dice que quiere “dejar que el agente llame a una API interna”, “bloquear todo el acceso a la red”, “dar al agente un token de GitHub” o “usar una imagen de registro privado para una sandbox”. Cubre `sbx policy init/allow/deny/ls/inspect/log/check/rm network` (reglas de salida globales y por sandbox, precedencia de denegar sobre permitir) y `sbx secret set/set‑custom/ls/rm/import` (secretos de servicio, secretos dinámicos mediante --ref/--command y credenciales de extracción de registro con su ámbito de inyección que, por defecto, solo permite extracciones del host).

Por favor, responde siempre en el idioma del usuario.
