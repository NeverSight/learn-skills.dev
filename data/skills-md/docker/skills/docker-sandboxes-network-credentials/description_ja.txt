Docker Sandboxes（`sbx`）サンドボックスがネットワーク上でアクセスできる範囲や、認証に使用するクレデンシャルを設定する際にこのスキルを使用してください。たとえユーザーが「エージェントに内部 API を呼ばせたい」「すべてのネットワークアクセスをブロックしたい」「エージェントに GitHub トークンを渡したい」「サンドボックスでプライベートレジストリのイメージを使いたい」とだけ言った場合でも対応できます。対象は `sbx policy init/allow/deny/ls/inspect/log/check/rm network`（全体およびサンドボックス単位の送出ルール、deny が allow より優先される）と `sbx secret set/set‑custom/ls/rm/import`（サービスシークレット、`--ref`／`--command` による動的シークレット、そしてデフォルトでホストごとのプルのみになるレジストリプルクレデンシャルの注入スコープ）です。

常にユーザーの言語で回答してください。
