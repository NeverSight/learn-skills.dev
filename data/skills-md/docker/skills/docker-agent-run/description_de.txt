Verwende diese Fähigkeit, wenn du einen Docker‑Agenten mit `docker agent run` startest, einen Sicherheits‑/Genehmigungsmodus auswählst, das Isolations‑Flag `--sandbox` nutzt, Aliase einrichtest oder bei der Fehlersuche eines Laufs (fehlende Anmeldeinformationen, Arbeitsbäume) unterstützt. Selbst wenn der Nutzer nur sagt, er wolle „mein Agent run“, „mein Agent Tool‑Aufrufe automatisch genehmigen“, „diesen Agenten sicher ausführen“ oder „warum kann mein Agent meinen API‑Schlüssel nicht sehen“, gilt diese Fähigkeit. Sie umfasst `--safety` (strict/balanced/restricted/autonomous), `--yolo`, `--sandbox` und seine Netzwerk‑Allowlist, `--worktree`, `docker agent alias` und `docker agent doctor`.

Bitte antworte immer in der Sprache des Nutzers.
