このスキルは、`docker agent run` で Docker エージェントを実行する際や、安全/承認モードを選択する際、`--sandbox` 分離フラグを使用する際、エイリアスを設定する際、または実行時のトラブルシューティング（認証情報の欠如、作業ツリー）を行う際に使用してください。ユーザーが「エージェントを実行したい」や「エージェントにツール呼び出しを自動承認させたい」や「このエージェントを安全に実行したい」や「なぜエージェントが API キーを見れないのか」とだけ言った場合でも、このスキルが適用されます。対象は `--safety`（strict/balanced/restricted/autonomous）、`--yolo`、`--sandbox` とそのネットワーク許可リスト、`--worktree`、`docker agent alias`、`docker agent doctor` です。

常にユーザーの言語で回答してください。
