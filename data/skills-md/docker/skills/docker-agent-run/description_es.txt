Utiliza esta habilidad al ejecutar un Docker Agent con `docker agent run`, al elegir un modo de seguridad/aprobación, al usar la bandera de aislamiento `--sandbox`, al configurar alias o al solucionar problemas de una ejecución (credenciales faltantes, árboles de trabajo). Incluso si el usuario solo dice que quiere “ejecutar mi agente”, “hacer que mi agente apruebe automáticamente las llamadas a herramientas”, “ejecutar este agente de forma segura” o “¿por qué mi agente no puede ver mi clave API?”, esta habilidad se aplica. Cubre `--safety` (strict/balanced/restricted/autonomous), `--yolo`, `--sandbox` y su lista de permitidos de red, `--worktree`, `docker agent alias` y `docker agent doctor`.  

Por favor, responde siempre en el idioma del usuario.
