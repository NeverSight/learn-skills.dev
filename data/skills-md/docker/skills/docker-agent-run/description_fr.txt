Utilisez cette compétence lorsque vous exécutez un Docker Agent avec `docker agent run`, choisissez un mode de sécurité/approbation, utilisez le drapeau d’isolation `--sandbox`, configurez des alias ou dépannez une exécution (identifiants manquants, worktrees). Même si l'utilisateur dit simplement qu'il veut « run my agent », « make my agent auto-approve tool calls », « run this agent safely » ou « why can’t my agent see my API key », cette compétence s’applique. Elle couvre `--safety` (strict/balanced/restricted/autonomous), `--yolo`, `--sandbox` et sa liste blanche réseau, `--worktree`, `docker agent alias` et `docker agent doctor`.
