استخدم هذه المهارة عند تشغيل عميل Docker باستخدام `docker agent run`، واختيار وضع الأمان/الموافقة، واستخدام علامة العزل `--sandbox`، وإعداد الأسماء المستعارة، أو استكشاف الأخطاء أثناء التشغيل (مثل فقدان الاعتمادات أو مسارات العمل). حتى إذا قال المستخدم فقط إنه يريد «تشغيل وكيلتي»، «جعل وكيلتي يوافق تلقائيًا على استدعاءات الأدوات»، «تشغيل هذا الوكيل بأمان»، أو «لماذا لا يستطيع وكيلتي رؤية مفتاح API الخاص بي»، فإن هذه المهارة تنطبق. تغطي `--safety` (strict/balanced/restricted/autonomous)، `--yolo`، `--sandbox` وقائمة السماح بالشبكة الخاصة به، `--worktree`، `docker agent alias`، و `docker agent doctor`.

يرجى دائمًا الرد بلغة المستخدم.
