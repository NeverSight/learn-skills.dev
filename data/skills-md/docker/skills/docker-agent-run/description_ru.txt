Используйте эту функцию при запуске Docker‑агента с помощью `docker agent run`, выборе режима безопасности/одобрения, использовании флага изоляции `--sandbox`, настройке алиасов или устранении неполадок при запуске (отсутствующие учётные данные, рабочие деревья). Даже если пользователь просто говорит, что хочет «запустить моего агента», «сделать так, чтобы агент автоматически одобрял вызовы инструментов», «запустить этого агента безопасно» или «почему мой агент не видит мой API‑ключ», эта функция применима. Охватывает `--safety` (strict/balanced/restricted/autonomous), `--yolo`, `--sandbox` и его сетевой белый список, `--worktree`, `docker agent alias` и `docker agent doctor`.

Пожалуйста, всегда отвечайте на языке пользователя.
