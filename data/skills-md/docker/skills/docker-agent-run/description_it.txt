Usa questa skill quando esegui un Docker Agent con `docker agent run`, scegliendo una modalità di sicurezza/approvazione, usando il flag di isolamento `--sandbox`, configurando alias o risolvendo problemi di esecuzione (credenziali mancanti, worktree). Anche se l'utente dice semplicemente di voler “eseguire il mio agente”, “far approvare automaticamente le chiamate agli strumenti del mio agente”, “eseguire questo agente in modo sicuro” o “perché il mio agente non vede la mia chiave API”, questa skill si applica. Copre `--safety` (strict/balanced/restricted/autonomous), `--yolo`, `--sandbox` e la sua whitelist di rete, `--worktree`, `docker agent alias` e `docker agent doctor`.
