在使用 `docker agent run` 執行 Docker Agent、選擇安全/批准模式、使用 `--sandbox` 隔離旗標、設定別名，或排除執行問題（缺少憑證、工作樹）時，請使用此技能。即使使用者只說想「執行我的代理」、「讓我的代理自動批准工具呼叫」、「安全執行此代理」或「為什麼我的代理看不到我的 API 金鑰」，此技能仍適用。涵蓋 `--safety`（strict/balanced/restricted/autonomous）、`--yolo`、`--sandbox` 及其網路白名單、`--worktree`、`docker agent alias` 與 `docker agent doctor`。

請始終以使用者的語言回覆。
