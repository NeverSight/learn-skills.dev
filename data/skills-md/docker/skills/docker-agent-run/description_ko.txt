`docker agent run` 명령으로 Docker 에이전트를 실행할 때, 안전/승인 모드를 선택하거나 `--sandbox` 격리 플래그를 사용할 때, 별칭을 설정하거나 실행 중(자격 증명 누락, 워크트리) 문제를 해결할 때 이 기술을 사용하십시오. 사용자가 단순히 “에이전트를 실행하고 싶다”, “에이전트를 자동 승인 도구 호출로 설정하고 싶다”, “이 에이전트를 안전하게 실행하고 싶다”, “왜 내 에이전트가 API 키를 볼 수 없는가”라고 말하더라도 이 기술이 적용됩니다. `--safety`(strict/balanced/restricted/autonomous), `--yolo`, `--sandbox` 및 그 네트워크 허용 목록, `--worktree`, `docker agent alias`, `docker agent doctor`를 포함합니다.
