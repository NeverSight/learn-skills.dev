ローカルのDockerサンドボックス（sbx）内のエージェントにMCPサーバーへのアクセス権を付与する際に、このスキルを使用します。ユーザーが「サンドボックス内のClaudeがGitHubツールを見ることができない」、「サンドボックスにNotion MCPを追加してほしい」、「このMCPサーバーをサンドボックスから削除してほしい」などと言う場合でも同様です。sbx mcp add/load/unload/ls/rm/auth/inspect、静的モードと動的モード、--static-mcp、ホスト側での実行、OAuthとヘッダーシークレット、信頼できないURL、および削除順序について説明します。
