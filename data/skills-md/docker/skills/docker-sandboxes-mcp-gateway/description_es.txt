Utiliza esta habilidad cuando des a un agente en un entorno aislado de Docker local (sbx) acceso a servidores MCP, incluso si el usuario simplemente dice «mi Claude en el entorno aislado no puede ver las herramientas de GitHub», «añade el MCP de Notion a mi entorno aislado» o «retira este servidor MCP del entorno aislado». Cubre los comandos sbx mcp add/load/unload/ls/rm/auth/inspect, el modo estático frente al dinámico, --static-mcp, la ejecución en el lado del host, los secretos de OAuth y de los encabezados, las URL no fiables y el orden de eliminación.
