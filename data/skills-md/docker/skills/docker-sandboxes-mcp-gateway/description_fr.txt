Utilisez cette compétence lorsque vous donnez à un agent dans un sandbox Docker local (sbx) l'accès aux serveurs MCP, même si l'utilisateur se contente de dire « mon Claude dans le sandbox ne peut pas voir les outils GitHub », « ajoutez le MCP Notion à mon sandbox » ou « retirez ce serveur MCP du sandbox ». Couvre les commandes sbx mcp add/load/unload/ls/rm/auth/inspect, le mode statique par rapport au mode dynamique, --static-mcp, l'exécution côté hôte, les secrets OAuth et d'en-tête, les URL non fiables et l'ordre de suppression.
