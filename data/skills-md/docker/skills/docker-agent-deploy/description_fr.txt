Utilisez cette compétence lorsque vous exposez un Docker Agent en tant que serveur (MCP, API HTTP, A2A, ACP ou chat compatible OpenAI), que vous distribuez un agent via un registre OCI avec `docker agent share`, ou que vous mesurez la qualité d’un agent avec `docker agent eval`. Même si l’utilisateur se contente de dire qu’il veut « transformer mon agent en serveur MCP », « laisser Claude Desktop utiliser mon agent », « publier mon agent sur Docker Hub », « pousser mon agent comme une image » ou « tester mon agent en CI », cette compétence s’applique. Elle couvre les adresses d’écoute et les drapeaux d’authentification de `serve mcp/api/a2a/acp/chat`, `share push/pull`, le format JSON des sessions d’évaluation, les métriques de score et le filtre de régression `--baseline`.

Veuillez toujours répondre dans la langue de l’utilisateur.
