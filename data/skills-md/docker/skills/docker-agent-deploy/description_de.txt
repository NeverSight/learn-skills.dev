Verwende diese Fähigkeit, wenn du einen Docker‑Agenten als Server (MCP, HTTP‑API, A2A, ACP oder OpenAI‑kompatiblen Chat) bereitstellst, einen Agenten über ein OCI‑Registry mit `docker agent share` verteilst oder die Agentenqualität mit `docker agent eval` misst. Auch wenn der Nutzer nur sagt, er möchte „meinen Agenten in einen MCP‑Server verwandeln“, „Claude Desktop meinen Agenten nutzen lassen“, „meinen Agenten auf Docker Hub veröffentlichen“, „meinen Agenten wie ein Image pushen“ oder „meinen Agenten in CI testen“, gilt diese Fähigkeit. Deckt `serve mcp/api/a2a/acp/chat` Listen‑Adressen und Auth‑Flags, `share push/pull`, das Eval‑Session‑JSON‑Format, Bewertungsmetriken und das `--baseline` Regressions‑Gate ab.
