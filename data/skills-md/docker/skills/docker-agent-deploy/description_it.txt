Utilizza questa competenza quando esponi un Docker Agent come server (MCP, HTTP API, A2A, ACP o chat compatibile con OpenAI), distribuisci un agente tramite un registro OCI con `docker agent share` o misuri la qualità dell'agente con `docker agent eval`. Anche se l'utente dice semplicemente di voler "trasformare il mio agente in un server MCP", "far usare il mio agente a Claude Desktop", "pubblicare il mio agente su Docker Hub", "spingere il mio agente come un'immagine" o "testare il mio agente in CI", questa competenza si applica. Copre gli indirizzi di ascolto e i flag di autenticazione di `serve mcp/api/a2a/acp/chat`, `share push/pull`, il formato JSON delle sessioni di valutazione, le metriche di punteggio e il filtro di regressione `--baseline`. 

Rispondi sempre nella lingua dell'utente.
