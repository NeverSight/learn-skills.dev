Utiliza esta habilidad al exponer un Docker Agent como servidor (MCP, HTTP API, A2A, ACP o chat compatible con OpenAI), al distribuir un agente a través de un registro OCI con `docker agent share`, o al medir la calidad del agente con `docker agent eval`. Incluso si el usuario solo dice que quiere “convertir mi agente en un servidor MCP”, “permitir que Claude Desktop use mi agente”, “publicar mi agente en Docker Hub”, “empujar mi agente como una imagen” o “probar mi agente en CI”, esta habilidad se aplica. Cubre direcciones de escucha y banderas de autenticación de `serve mcp/api/a2a/acp/chat`, `share push/pull`, formato JSON de sesión de evaluación, métricas de puntuación y la puerta de regresión `--baseline`.

Por favor, responde siempre en el idioma del usuario.
