استخدم هذه المهارة عند نشر وكيل Docker كخادم (MCP، HTTP API، A2A، ACP، أو دردشة متوافقة مع OpenAI)، أو توزيع وكيل عبر سجل OCI باستخدام `docker agent share`، أو قياس جودة الوكيل باستخدام `docker agent eval`. حتى إذا قال المستخدم فقط إنه يريد «تحويل وكيلتي إلى خادم MCP»، «السماح لـ Claude Desktop باستخدام وكيلتي»، «نشر وكيلتي على Docker Hub»، «دفع وكيلتي كصورة»، أو «اختبار وكيلتي في CI»، فإن هذه المهارة تنطبق. يغطي عناوين الاستماع وأعلام المصادقة لـ `serve mcp/api/a2a/acp/chat`، و`share push/pull`، وصيغة JSON لجلسة التقييم، ومقاييس التقييم، وبوابة الانحدار `--baseline`.
