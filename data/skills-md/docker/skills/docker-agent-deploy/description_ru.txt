Используйте это умение, когда разворачиваете Docker Agent как сервер (MCP, HTTP API, A2A, ACP или чат, совместимый с OpenAI), распространяете агент через OCI‑реестр с помощью `docker agent share` или измеряете качество агента с помощью `docker agent eval`. Даже если пользователь просто говорит, что хочет «превратить моего агента в MCP‑сервер», «дать Claude Desktop использовать моего агента», «опубликовать моего агента в Docker Hub», «запушить моего агента как образ» или «протестировать моего агента в CI», это умение применяется. Охватывает адреса прослушивания и флаги аутентификации `serve mcp/api/a2a/acp/chat`, команды `share push/pull`, формат JSON‑сессии eval, метрики оценки и переключатель регрессии `--baseline`.
