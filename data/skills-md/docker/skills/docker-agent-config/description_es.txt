Utiliza esta habilidad al crear o editar un archivo de configuración agent.yaml (o .yml/.hcl) para Docker Agent (cagent), incluyendo la definición de agentes, modelos/proveedores, conjuntos de herramientas integrados o MCP, equipos multi‑agente con sub_agents. Incluso si el usuario solo dice que quiere "crear un agente de IA con Docker", "hacer una configuración de agente de codificación", "añadir una herramienta a mi agente", o "configurar un equipo de agentes", esta habilidad se aplica. Cubre las propiedades del agente (modelo, instrucción, conjuntos de herramientas, sub_agents, fallback), las secciones de modelos/proveedores, los conjuntos de herramientas integrados (filesystem, shell, think, todo, memory, fetch), referencias al conjunto de herramientas MCP y los comandos nombrados.

Por favor, responde siempre en el idioma del usuario.
