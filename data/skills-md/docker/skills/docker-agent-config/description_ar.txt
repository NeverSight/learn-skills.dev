استخدم هذه المهارة عند إنشاء أو تعديل ملف تكوين agent.yaml (أو .yml/.hcl) الخاص بـ Docker Agent (cagent)، بما في ذلك تعريف الوكلاء، النماذج/المزودين، مجموعات الأدوات المدمجة أو MCP، وفرق الوكلاء المتعددة مع sub_agents. حتى إذا قال المستخدم فقط إنه يريد «إنشاء وكيل ذكاء اصطناعي باستخدام Docker» أو «إنشاء تكوين وكيل برمجي» أو «إضافة أداة إلى وكيلتي» أو «إعداد فريق من الوكلاء»، فإن هذه المهارة تنطبق. تغطي خصائص الوكيل (النموذج، التعليمات، مجموعات الأدوات، sub_agents، fallback)، أقسام النماذج/المزودين، مجموعات الأدوات المدمجة (نظام الملفات، shell، think، todo، memory، fetch)، مراجع مجموعة أدوات MCP، والأوامر المسماة.

يرجى دائماً الرد بلغة المستخدم.
