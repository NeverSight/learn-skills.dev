Usa questa competenza quando crei o modifichi un file di configurazione agent.yaml (o .yml/.hcl) per Docker Agent (cagent), includendo la definizione di agenti, modelli/fornitori, set di strumenti integrati o MCP, team multi‑agente con sub_agents. Anche se l'utente dice semplicemente di voler “costruire un agente IA con Docker”, “creare una configurazione agente di codifica”, “aggiungere uno strumento al mio agente” o “impostare un team di agenti”, questa competenza si applica. Copre le proprietà dell'agente (modello, istruzione, set di strumenti, sub_agents, fallback), le sezioni modelli/fornitori, i set di strumenti integrati (filesystem, shell, think, todo, memory, fetch), i riferimenti al set di strumenti MCP e i comandi nominati.
