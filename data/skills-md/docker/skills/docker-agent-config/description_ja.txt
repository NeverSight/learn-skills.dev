このスキルは、Docker Agent（cagent）の agent.yaml（または .yml/.hcl）設定ファイルを作成または編集する際に使用します。エージェント、モデル/プロバイダー、組み込みまたは MCP ツールセット、サブエージェントを持つマルチエージェントチームの定義を含みます。たとえユーザーが「DockerでAIエージェントを作りたい」「コーディングエージェントの設定を作成したい」「エージェントにツールを追加したい」「エージェントチームを設定したい」だけと言っても、このスキルが適用されます。エージェントのプロパティ（model、instruction、toolsets、sub_agents、fallback）、models/providers セクション、組み込みツールセット（filesystem、shell、think、todo、memory、fetch）、MCP ツールセットの参照、名前付きコマンドをカバーします。
