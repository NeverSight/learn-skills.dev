Используйте этот навык при создании или редактировании файла конфигурации agent.yaml (или .yml/.hcl) для Docker Agent (cagent), включая определение агентов, моделей/провайдеров, встроенных или MCP наборов инструментов, мультиагентных команд с sub_agents. Даже если пользователь просто говорит, что хочет «создать AI‑агента с Docker», «сделать конфигурацию кодирующего агента», «добавить инструмент к моему агенту» или «настроить команду агентов», этот навык применяется. Охватывает свойства агента (model, instruction, toolsets, sub_agents, fallback), разделы models/providers, встроенные наборы инструментов (filesystem, shell, think, todo, memory, fetch), ссылки на наборы инструментов MCP и именованные команды.

Пожалуйста, всегда отвечайте на языке пользователя.
