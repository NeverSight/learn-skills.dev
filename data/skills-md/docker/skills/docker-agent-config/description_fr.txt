Utilisez cette compétence lors de la création ou de la modification d’un fichier de configuration agent.yaml (ou .yml/.hcl) pour Docker Agent (cagent), y compris la définition d’agents, de modèles/fournisseurs, d’ensembles d’outils intégrés ou MCP, et d’équipes multi‑agents avec sub_agents. Même si l’utilisateur se contente de dire qu’il veut « créer un agent IA avec Docker », « générer une configuration d’agent de codage », « ajouter un outil à mon agent » ou « mettre en place une équipe d’agents », cette compétence s’applique. Elle couvre les propriétés de l’agent (modèle, instruction, ensembles d’outils, sub_agents, fallback), les sections modèles/fournisseurs, les ensembles d’outils intégrés (filesystem, shell, think, todo, memory, fetch), les références aux ensembles d’outils MCP et les commandes nommées.

Veuillez toujours répondre dans la langue de l’utilisateur.
