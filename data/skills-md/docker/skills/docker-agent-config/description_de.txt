Verwenden Sie diese Fähigkeit beim Erstellen oder Bearbeiten einer agent.yaml (oder .yml/.hcl) Konfigurationsdatei für Docker Agent (cagent), einschließlich der Definition von Agenten, Modellen/Providern, eingebauten oder MCP‑Toolsets, Multi‑Agent‑Teams mit sub_agents. Selbst wenn der Benutzer nur sagt, er wolle „einen KI‑Agent mit Docker bauen“, „eine Coding‑Agent‑Konfiguration erstellen“, „ein Tool zu meinem Agent hinzufügen“ oder „ein Team von Agenten einrichten“, gilt diese Fähigkeit. Sie deckt Agenten‑Eigenschaften (Model, Instruction, Toolsets, sub_agents, Fallback), die Modelle/Provider‑Abschnitte, eingebaute Toolsets (Filesystem, Shell, Think, Todo, Memory, Fetch), MCP‑Toolset‑Referenzen und benannte Befehle ab.

Bitte antworten Sie stets in der Sprache des Benutzers.
