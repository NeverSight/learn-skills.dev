使用此技能根据当前官方 Docker 文档回答任何关于 Docker 产品的问题，而不是依赖记忆，即使用户仅询问“我该如何…”“Docker 是否支持…”“哪个标志用于…”，或“这仍是正确的做法吗”，也适用于 Docker。涵盖 Docker Desktop、Engine、Build/Buildx/Build Cloud、Compose、Hub、Scout、Docker Hardened Images（DHI）、Offload、Testcontainers、Docker Sandboxes（`sbx`、本地和云沙箱、Sandboxes API/SDK）、Docker Agentic Platform、Docker Agent、MCP Catalog/Toolkit/Gateway、Model Runner、Gordon，以及账户、管理员、安全和计费文档。在可用时使用 `search_docker_docs` MCP 工具进行搜索，否则回退到 `docs.docker.com/llms.txt` 和每页的 Markdown。

请始终使用用户的语言作答。
