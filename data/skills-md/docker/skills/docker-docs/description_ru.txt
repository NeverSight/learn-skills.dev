Используйте этот навык для ответов на вопросы о любом продукте Docker из актуальной официальной документации Docker вместо памяти, даже если пользователь просто спрашивает «как мне…», «поддерживает ли Docker…», «какой флаг для…» или «это всё ещё правильный способ» относительно Docker. Охватывает Docker Desktop, Engine, Build/Buildx/Build Cloud, Compose, Hub, Scout, Docker Hardened Images (DHI), Offload, Testcontainers, Docker Sandboxes (`sbx`, локальные и облачные песочницы, API/SDK Sandboxes), Docker Agentic Platform, Docker Agent, MCP Catalog/Toolkit/Gateway, Model Runner, Gordon, а также документы по учётным записям, администрированию, безопасности и биллингу. Выполняет поиск с помощью инструмента `search_docker_docs` MCP, когда он доступен, и в противном случае использует `docs.docker.com/llms.txt` и отдельные Markdown‑страницы.  

Пожалуйста, всегда отвечайте на языке пользователя.
