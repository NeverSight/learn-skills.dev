Utilisez cette compétence pour répondre aux questions sur n'importe quel produit Docker à partir de la documentation officielle Docker actuelle plutôt que de la mémoire, même si l'utilisateur demande simplement « comment faire… », « Docker prend‑il en charge… », « quel est le drapeau pour… » ou « est‑ce toujours la bonne façon » concernant Docker. Couvre Docker Desktop, Engine, Build/Buildx/Build Cloud, Compose, Hub, Scout, Docker Hardened Images (DHI), Offload, Testcontainers, Docker Sandboxes (`sbx`, sandboxes locales et cloud, API/SDK des sandboxes), Docker Agentic Platform, Docker Agent, MCP Catalog/Toolkit/Gateway, Model Runner, Gordon, ainsi que les documents de compte, d'administration, de sécurité et de facturation. Recherche avec l'outil MCP `search_docker_docs` lorsqu'il est disponible et, sinon, revient à `docs.docker.com/llms.txt` et au Markdown par page.  

Veuillez toujours répondre dans la langue de l'utilisateur.
