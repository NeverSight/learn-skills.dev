在編寫、規劃或執行 Docker Sandbox 的宣告式 `sbxenv.yaml` 檔案時（使用 `sbx env create/run/plan/exec/rm`），請使用此技能，即使使用者只是說想「檢入 sandbox 設定檔」、 「讓 sandbox 的 onboarding 可重現」、 「在代理程式啟動前執行設定腳本」或「為共享 sandbox 環境定義參數」等需求。涵蓋 sbxenv.yaml 的結構（schemaVersion、agent、kits、workspace/additionalWorkspaces、args、env、secrets、registries、bindings、mcp、ports、sandboxOptions）、主機的 `lifecycle:` 指令（initialize、postCreate、preRemove）及其批准‑計畫模型、多檔案合併（`-f` 風格的深度合併與使用者層級的 `.sbxenv.yaml` 基礎層），以及檔案寫入保護（`sandboxOptions.writableEnvFiles`）。
