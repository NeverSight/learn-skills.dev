Utilisez cette compétence lors de la rédaction, de la planification ou de l'exécution d'un fichier déclaratif `sbxenv.yaml` pour Docker Sandboxes (`sbx env create/run/plan/exec/rm`), même si l'utilisateur dit simplement qu'il veut « check in a sandbox config », « make onboarding reproducible for a sandbox », « run a setup script before the agent starts » ou « define arguments for a shared sandbox environment ». Couvre le schéma sbxenv.yaml (schemaVersion, agent, kits, workspace/additionalWorkspaces, args, env, secrets, registries, bindings, mcp, ports, sandboxOptions), les commandes hôte `lifecycle:` (initialize/postCreate/preRemove) et leur modèle d'approbation‑plan, la fusion multi‑fichiers (`-f`‑style deep merge et la couche de base utilisateur `.sbxenv.yaml`), ainsi que la protection en écriture des fichiers (`sandboxOptions.writableEnvFiles`).
