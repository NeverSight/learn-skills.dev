在编写、规划或运行 Docker 沙箱的声明式 `sbxenv.yaml` 文件时使用此技能（`sbx env create/run/plan/exec/rm`），即使用户仅说他们想“提交沙箱配置”、 “让沙箱的入职流程可复现”、 “在代理启动前运行设置脚本”，或 “为共享沙箱环境定义参数”。涵盖 sbxenv.yaml 架构（schemaVersion、agent、kits、workspace/additionalWorkspaces、args、env、secrets、registries、bindings、mcp、ports、sandboxOptions）、主机 `lifecycle:` 命令（initialize/postCreate/preRemove）及其批准‑计划模型、多文件合并（类似 `-f` 的深度合并以及用户层面的 `.sbxenv.yaml` 基础层），以及文件写入保护（`sandboxOptions.writableEnvFiles`）。
