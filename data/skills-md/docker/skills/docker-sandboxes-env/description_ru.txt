Используйте это умение при написании, планировании или запуске декларативного файла `sbxenv.yaml` для Docker Sandboxes (`sbx env create/run/plan/exec/rm`), даже если пользователь просто говорит, что хочет «записать конфигурацию песочницы», «сделать процесс онбординга воспроизводимым для песочницы», «запустить скрипт настройки перед запуском агента» или «определить аргументы для общей среды песочницы». Охватывает схему sbxenv.yaml (schemaVersion, agent, kits, workspace/additionalWorkspaces, args, env, secrets, registries, bindings, mcp, ports, sandboxOptions), команды хоста `lifecycle:` (initialize/postCreate/preRemove) и их модель утверждения‑плана, слияние нескольких файлов (`-f`‑style глубокое слияние и базовый уровень пользователя `.sbxenv.yaml`), а также защиту записи файлов (`sandboxOptions.writableEnvFiles`).
