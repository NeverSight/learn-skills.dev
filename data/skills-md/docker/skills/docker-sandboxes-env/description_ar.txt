استخدم هذه المهارة عند كتابة أو تخطيط أو تشغيل ملف `sbxenv.yaml` التصريحي لصناديق Docker Sandboxes (`sbx env create/run/plan/exec/rm`)، حتى إذا قال المستخدم فقط إنه يريد «إدخال تكوين صندوق رمل»، «جعل إعداد onboarding قابلًا للتكرار لصندوق رمل»، «تشغيل برنامج إعداد قبل بدء تشغيل الوكيل»، أو «تحديد الوسائط لبيئة صندوق رمل مشتركة». يغطي مخطط sbxenv.yaml (`schemaVersion`، `agent`، `kits`، `workspace/additionalWorkspaces`، `args`، `env`، `secrets`، `registries`، `bindings`، `mcp`، `ports`، `sandboxOptions`)، أوامر `lifecycle:` للمضيف (`initialize`/`postCreate`/`preRemove`) ونموذج موافقة‑الخطة الخاص بها، دمج ملفات متعددة (دمج عميق بنمط `-f` وطبقة الأساس للمستخدم `.sbxenv.yaml`)، وحماية كتابة الملفات (`sandboxOptions.writableEnvFiles`).
