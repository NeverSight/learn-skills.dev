Utiliza esta habilidad al crear, planificar o ejecutar un archivo declarativo `sbxenv.yaml` para Docker Sandboxes (`sbx env create/run/plan/exec/rm`), incluso si el usuario solo dice que quiere "registrar una configuración de sandbox", "hacer que la incorporación sea reproducible para un sandbox", "ejecutar un script de configuración antes de que el agente inicie", o "definir argumentos para un entorno sandbox compartido". Cubre el esquema sbxenv.yaml (schemaVersion, agent, kits, workspace/additionalWorkspaces, args, env, secrets, registries, bindings, mcp, ports, sandboxOptions), los comandos `lifecycle:` del host (initialize/postCreate/preRemove) y su modelo de aprobación‑plan, la fusión de varios archivos (`-f`‑style deep merge y la capa base de nivel de usuario `.sbxenv.yaml`), y la protección contra escritura de archivos (`sandboxOptions.writableEnvFiles`).
