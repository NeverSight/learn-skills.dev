Usa questa competenza quando scrivi, pianifichi o esegui un file dichiarativo `sbxenv.yaml` per Docker Sandboxes (`sbx env create/run/plan/exec/rm`), anche se l'utente dice semplicemente che vuole "registrare una configurazione sandbox", "rendere riproducibile l’onboarding per una sandbox", "eseguire uno script di setup prima che l'agente parta" o "definire argomenti per un ambiente sandbox condiviso". Copre lo schema sbxenv.yaml (schemaVersion, agent, kits, workspace/additionalWorkspaces, args, env, secrets, registries, bindings, mcp, ports, sandboxOptions), i comandi host `lifecycle:` (initialize/postCreate/preRemove) e il loro modello di approvazione‑piano, il merge multi‑file (`-f`‑style deep merge e il livello base `.sbxenv.yaml` a livello utente) e la protezione di scrittura dei file (`sandboxOptions.writableEnvFiles`).
