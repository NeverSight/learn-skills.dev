استخدم هذه المهارة عند إعداد المشروع أو تهيئته أو وضعه في حاوية Docker، حتى وإن لم يذكر المستخدم Docker صراحةً لكنه وصف الحاجة إلى تطوير محلي محاط بالحاويات، أو إضافة اعتماد قاعدة بيانات أو ذاكرة تخزين مؤقت، أو تشغيل خدمات دون تثبيت على مستوى المضيف. تشمل العملية إنشاء Dockerfile و compose.yaml و .dockerignore وفقًا لأفضل ممارسات Docker.
