Utilizza questa competenza quando configuri, inizializzi o Dockerizzi un progetto, anche se l'utente non menziona esplicitamente Docker ma descrive la necessità di uno sviluppo locale containerizzato, aggiungendo una dipendenza di database o cache, o eseguendo servizi senza installazioni a livello di host. Copre la creazione di Dockerfile, compose.yaml e .dockerignore con le migliori pratiche Docker.
