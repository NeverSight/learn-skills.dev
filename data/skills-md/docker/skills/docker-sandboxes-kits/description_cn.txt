在编写、验证、打包、签名或组装 Docker Sandboxes 套件 `spec.yaml`（`sbx kit add/inspect/pack/pull/push/sign/validate/verify`）时使用此技能，即使用户仅表示想要“向 sandbox 代理添加工具”、“构建可复用的 sandbox 扩展”、“将套件发布到注册表”或“为 mixin 提供独立的凭据和网络访问”。涵盖 kit-spec v2 语法（`kind: sandbox` 与 `kind: mixin` 区别，`sandbox:` 区块，`permissions.network`，`ports`，`credentials` apiKey/oauth，`environment`，`setup` 安装/启动/文件，`volumes`，`args`，`extends`，`mixins`，`requires.agent`），通过 `--kit`/`sbx kit add` 进行组合，以及分发（pack/push/pull/sign/verify/provenance）。
