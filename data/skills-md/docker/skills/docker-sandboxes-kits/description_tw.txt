在撰寫、驗證、打包、簽署或組合 Docker Sandboxes 套件 `spec.yaml`（`sbx kit add/inspect/pack/pull/push/sign/validate/verify`）時使用此技能，即使使用者僅說想要「將工具加入 sandbox 代理」、「建立可重用的 sandbox 擴充功能」、「將套件發佈至註冊中心」或「為 mixin 提供其自己的憑證與網路存取」亦同。涵蓋 kit‑spec v2 語法（`kind: sandbox` 與 `kind: mixin` 的差別、`sandbox:` 區塊、`permissions.network`、`ports`、`credentials` apiKey/oauth、`environment`、`setup` 安裝/啟動/檔案、`volumes`、`args`、`extends`、`mixins`、`requires.agent`），透過 `--kit`/`sbx kit add` 進行組合，以及分發（pack/push/pull/sign/verify/provenance）。
