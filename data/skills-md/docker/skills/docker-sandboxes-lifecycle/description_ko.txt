이 기능은 Docker Sandbox(격리된 마이크로VM에서 AI 코딩 에이전트를 실행하는 독립형 `sbx` CLI)를 생성, 실행, 재접속, 목록 조회, 중지 또는 제거할 때마다 사용하십시오. 사용자가 단순히 “sandbox에서 claude 실행”, “내 리포에서 에이전트를 격리”, “에이전트에게 자체 git 클론 제공”, 혹은 “오래된 sandbox 정리”라고 말하더라도 적용됩니다. `sbx run`/`sbx create`(내장 에이전트 claude, codex, cursor, devin, docker-agent, gemini, opencode, shell 포함), 워크스페이스 바인드 마운트와 `--clone` 격리, 추가 읽기 전용 워크스페이스, `--name`을 통한 재접속, `sbx ls`/`stop`/`rm`/`prune`, `sbx exec`, `sbx cp`, `sbx ports` 등을 다룹니다.
