이 기능은 Docker Sandbox(격리된 microVM에서 AI 코딩 에이전트를 실행하는 독립형 `sbx` CLI)를 생성, 실행, 재연결, 목록 확인, 중지 또는 제거할 때 사용합니다. 사용자가 단순히 “sandbox에서 claude를 실행하고 싶다”, “내 저장소에서 에이전트를 격리하고 싶다”, “에이전트에게 자체 git clone을 제공하고 싶다”, 혹은 “오래된 sandbox를 정리하고 싶다” 라고 말하더라도 적용됩니다. `sbx run`/`sbx create`(내장 에이전트 claude, codex, cursor, devin, docker-agent, gemini, opencode, shell 포함), 작업공간 바인드 마운트와 `--clone` 격리, 추가 읽기 전용 작업공간, `--name` 으로 재연결, `sbx ls`/`stop`/`rm`/`prune`, `sbx exec`, `sbx cp`, `sbx ports` 등을 다룹니다.

항상 사용자의 언어로 응답하십시오.
