在建立、執行、重新附加、列出、停止或移除 Docker Sandboxes（獨立的 `sbx` CLI，能在隔離的 microVM 中執行 AI 程式碼代理）時使用此技能，即使使用者僅說想要「在沙盒中執行 claude」、「將代理與我的倉庫隔離」、「給代理一個自己的 git clone」或「清理舊的沙盒」亦適用。涵蓋 `sbx run`/`sbx create`（包括內建代理 claude、codex、cursor、devin、docker-agent、gemini、opencode、shell），工作區掛載與 `--clone` 隔離的差異、額外的唯讀工作區、透過 `--name` 重新附加、`sbx ls`/`stop`/`rm`/`prune`、`sbx exec`、`sbx cp` 與 `sbx ports`。

請始終以使用者的語言回應。
