Usa questa abilità quando crei, esegui, ricolleghi, elenchi, fermi o rimuovi Docker Sandbox (il CLI autonomo `sbx` che esegue agenti di programmazione AI in microVM isolate), anche se l'utente dice semplicemente di voler “eseguire claude in una sandbox”, “isolare un agente dal mio repository”, “dare a un agente il suo clone git” o “pulire le vecchie sandbox”. Copre `sbx run`/`sbx create` (inclusi gli agenti integrati claude, codex, cursor, devin, docker-agent, gemini, opencode, shell), bind‑mount dello spazio di lavoro vs isolamento `--clone`, spazi di lavoro aggiuntivi in sola lettura, ricollegamento tramite `--name`, `sbx ls`/`stop`/`rm`/`prune`, `sbx exec`, `sbx cp` e `sbx ports`.
