このスキルは、Docker Sandbox の作成、実行、再接続、一覧表示、停止、または削除（isolated microVM 内で AI コーディングエージェントを実行するスタンドアロンの `sbx` CLI）を行う際に使用してください。たとえユーザーが「sandbox で claude を実行したい」「エージェントをリポジトリから分離したい」「エージェントに独自の git クローンを与えたい」「古い sandbox をクリーンアップしたい」だけと言っても同様です。対象は `sbx run`/`sbx create`（組み込みエージェント claude、codex、cursor、devin、docker-agent、gemini、opencode、shell を含む）、ワークスペースのバインドマウントと `--clone` による分離、追加の読み取り専用ワークスペース、`--name` による再接続、`sbx ls`/`stop`/`rm`/`prune`、`sbx exec`、`sbx cp`、`sbx ports` です。
