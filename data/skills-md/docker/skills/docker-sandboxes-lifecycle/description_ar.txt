استخدم هذه المهارة عند إنشاء أو تشغيل أو إعادة الارتباط بـ أو سرد أو إيقاف أو إزالة حاويات Docker Sandbox (أداة سطر الأوامر المستقلة `sbx` التي تشغّل وكلاء الترميز الذكي في ميكرو‑VMs معزولة)، حتى إذا قال المستخدم فقط إنه يريد «تشغيل claude في صندوق عزل»، «عزل وكيل عن مستودعي»، «إعطاء وكيل نسخة git خاصة به»، أو «تنظيف الصناديق القديمة». تشمل `sbx run`/`sbx create` (بما في ذلك الوكلاء المدمجين claude, codex, cursor, devin, docker‑agent, gemini, opencode, shell)، ربط مساحة العمل مقابل العزل بـ `--clone`، مساحات عمل إضافية للقراءة فقط، إعادة الارتباط باستخدام `--name`، `sbx ls`/`stop`/`rm`/`prune`، `sbx exec`، `sbx cp`، و `sbx ports`.
