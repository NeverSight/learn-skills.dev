Оцените риск выпуска версии CawPlan с помощью механизма правил QA Insights: вычислите уровень риска, структурированные причины, предлагаемые действия и сохраните подтвержденную оценку в версии.
Используйте, когда: оценка риска выпуска, можем ли мы выпустить, уровень риска версии, 发版风险评估、能不能发版、版本风险、评估发版风险、保存风险结论.
НЕ для: только хода выполнения теста (используйте `cawplan-test-execution-progress`); использование риска расписания/завершения заявки cawplan-plan-track в качестве вывода A5 (для контекста отображения разрешено `release_at`/завершение только для чтения из `versions track`); регистрация дефектов (используйте `cawplan-defect-ticket`); макет плана испытаний; или заявка на готовность к выпуску отчета по обеспечению качества.
