Rallumez une image fixe — modifiez le réglage d’éclairage, la température de couleur, la direction ou l’ambiance — sur RunComfy via la CLI `runcomfy`. Dirige vers le point de terminaison LoRA dédié `relight` de Qwen Edit 2509 pour un rééclairage spécialement conçu, avec recours aux points de terminaison d’édition préservant l’identité (Nano Banana 2 Edit, GPT Image 2 Edit, FLUX Kontext Pro) lorsque le texte descriptif de l’éclairage suffit. Utilisez-le pour le rééclairage de produits (softbox de studio → lumière de fenêtre), le changement d’humeur d’un portrait (ciel couvert → heure dorée), ou la modification de la colorimétrie. Déclencheurs : « relight », « relighting », « change the lighting », « make it golden hour », « studio lighting », « rim light », « blue hour », « soft window light », « change light direction », « color temperature », ou toute demande explicite de modifier la façon dont une image fixe est éclairée.
