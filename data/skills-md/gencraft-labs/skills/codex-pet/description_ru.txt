Генератор Codex Pet на RunComfy. Создаёт совместимый с Codex набор спрайтов Codex Pet — spritesheet.webp + pet.json из одного эталонного изображения, помещайте его в `${CODEX_HOME:-$HOME/.codex}/pets/<name>/`, и Codex подхватит его как пользовательского Codex Pet рядом с 8 встроенными. Этот навык генерирует точный атлас Codex Pet, который ожидает Codex (1536 × 1872 PNG/WebP, 8 столбцов × 9 строк, ячейки 192 × 208, 9 анимационных состояний — idle, running-right, running-left, waving, jumping, failed, waiting, running, review). Вызывает OpenAI GPT Image 2 edit ОДИН раз через локальный RunComfy CLI как `runcomfy run openai/gpt-image-2/edit` для создания каноничной позы Codex Pet, затем программно собирает все 9 строк анимации с помощью микротрансформов ImageMagick — без Codex Pro, без `$imagegen`, без OPENAI_API_KEY, требуется только RUNCOMFY_TOKEN. Срабатывает на «codex pet», «create codex pet», «make codex pet», «hatch codex pet», «/hatch image», «desktop pet codex», «codex pets», «spritesheet.webp» или любой явный запрос создать пользовательского питомца для OpenAI Codex.
