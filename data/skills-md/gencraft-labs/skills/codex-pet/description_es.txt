Generador de mascotas Codex en RunComfy. Construye un spritesheet.webp compatible con Codex + pet.json a partir de una única imagen de referencia, colócalo en `${CODEX_HOME:-$HOME/.codex}/pets/<name>/` y Codex lo detecta como una mascota Codex personalizada junto a las 8 incorporadas. Esta habilidad produce el atlas de mascotas Codex exacto que Codex espera (PNG/WebP de 1536 x 1872, 8 columnas × 9 filas, celdas de 192 × 208, 9 estados de animación — idle, running‑right, running‑left, waving, jumping, failed, waiting, running, review). Llama a OpenAI GPT Image 2 edit UNA VEZ mediante el CLI local de RunComfy como `runcomfy run openai/gpt-image-2/edit` para generar una pose canónica de la mascota Codex, luego ensambla las 9 filas de animación programáticamente con micro‑transformaciones de ImageMagick — sin Codex Pro, sin `$imagegen`, sin requerir OPENAI_API_KEY, solo RUNCOMFY_TOKEN. Se activa con “codex pet”, “create codex pet”, “make codex pet”, “hatch codex pet”, “/hatch image”, “desktop pet codex”, “codex pets”, “spritesheet.webp”, o cualquier solicitud explícita de crear una mascota personalizada para OpenAI Codex.
