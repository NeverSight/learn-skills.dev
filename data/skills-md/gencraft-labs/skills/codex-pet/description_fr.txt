Générateur de Codex Pet sur RunComfy. Créez une spritesheet Codex‑compatible Codex Pet (spritesheet.webp + pet.json) à partir d’une seule image de référence, déposez‑la dans `${CODEX_HOME:-$HOME/.codex}/pets/<name>/` et Codex la récupère comme un Codex Pet personnalisé à côté des 8 intégrés. Cette fonction produit exactement l’atlas Codex Pet que Codex attend (PNG/WebP 1536 × 1872, 8 colonnes × 9 lignes, cellules 192 × 208, 9 états d’animation — idle, running‑right, running‑left, waving, jumping, failed, waiting, running, review). Elle appelle OpenAI GPT Image 2 edit UNE FOIS via le CLI local RunComfy avec `runcomfy run openai/gpt-image-2/edit` pour générer une pose canonique du Codex Pet, puis assemble les 9 rangées d’animation programmatiquement avec des micro‑transformations ImageMagick — pas de Codex Pro, pas de `$imagegen`, pas de OPENAI_API_KEY requis, seulement RUNCOMFY_TOKEN. Elle se déclenche sur « codex pet », « create codex pet », « make codex pet », « hatch codex pet », « /hatch image », « desktop pet codex », « codex pets », « spritesheet.webp », ou toute demande explicite de créer un pet personnalisé pour OpenAI Codex.
