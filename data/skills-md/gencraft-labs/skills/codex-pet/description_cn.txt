RunComfy 上的 Codex 宠物生成器。 从单张参考图像构建兼容 Codex 的 Codex 宠物 spritesheet.webp + pet.json，放入 `${CODEX_HOME:-$HOME/.codex}/pets/<name>/`，Codex 会将其识别为自定义 Codex 宠物，位于 8 个内置宠物旁边。 此技能生成 Codex 所需的精确宠物图集（1536×1872 PNG/WebP，8 列 × 9 行，单元格 192×208，9 种动画状态——idle、running‑right、running‑left、waving、jumping、failed、waiting、running、review）。 通过本地 RunComfy CLI 调用一次 OpenAI GPT Image 2 edit（`runcomfy run openai/gpt-image-2/edit`）生成标准的 Codex 宠物姿势，然后使用 ImageMagick 微变换程序化地拼装 9 条动画行——不需要 Codex Pro、无需 `$imagegen`，也不需要 OPENAI_API_KEY，只需 RUNCOMFY_TOKEN。 触发词包括 “codex pet”、 “create codex pet”、 “make codex pet”、 “hatch codex pet”、 “/hatch image”、 “desktop pet codex”、 “codex pets”、 “spritesheet.webp”，或任何明确请求为 OpenAI Codex 构建自定义宠物的指令。
