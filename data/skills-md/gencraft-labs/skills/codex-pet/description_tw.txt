RunComfy 上的 Codex 寵物產生器。從單一參考圖像建立相容於 Codex 的 Codex 寵物 spritesheet.webp + pet.json，將其放入 `${CODEX_HOME:-$HOME/.codex}/pets/<name>/`，Codex 會將其視為自訂的 Codex 寵物，與 8 個內建寵物並列。此技能會產生 Codex 所需的完整寵物圖集（1536x1872 PNG/WebP，8 列 x 9 行，192x208 像素格，9 種動畫狀態 — 靜止、向右跑、向左跑、揮手、跳躍、失敗、等待、跑步、審核）。透過本機 RunComfy CLI 執行一次 `runcomfy run openai/gpt-image-2/edit` 呼叫 OpenAI GPT Image 2 edit，產生標準的 Codex 寵物姿勢，然後使用 ImageMagick 微型轉換程式化組合所有 9 行動畫——不需要 Codex Pro、沒有 `$imagegen`、不需要 OPENAI_API_KEY，只需 RUNCOMFY_TOKEN。觸發關鍵字包括「codex pet」、「create codex pet」、「make codex pet」、「hatch codex pet」、「/hatch image」、「desktop pet codex」、「codex pets」、「spritesheet.webp」或任何明確要求為 OpenAI Codex 建立自訂寵物的說法。
