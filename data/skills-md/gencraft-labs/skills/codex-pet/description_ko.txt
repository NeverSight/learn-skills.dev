RunComfy에서 Codex Pet 생성기. 단일 참조 이미지 하나로 Codex 호환 Codex Pet spritesheet.webp와 pet.json을 만들고, 이를 `${CODEX_HOME:-$HOME/.codex}/pets/<name>/`에 넣으면 Codex가 기본 8개와 함께 사용자 정의 Codex Pet으로 인식합니다. 이 기능은 Codex가 예상하는 정확한 Codex Pet 아틀라스를 생성합니다(1536×1872 PNG/WebP, 8열 × 9행, 192×208 셀, 9가지 애니메이션 상태 — idle, running-right, running-left, waving, jumping, failed, waiting, running, review). 로컬 RunComfy CLI(`runcomfy run openai/gpt-image-2/edit`)를 통해 OpenAI GPT Image 2 edit을 한 번 호출하여 표준 Codex Pet 포즈를 만든 뒤, ImageMagick 마이크로 변환을 사용해 9개의 애니메이션 행을 프로그램matically 조합합니다 — Codex Pro도, `$imagegen`도, OPENAI_API_KEY도 필요 없고 RUNCOMFY_TOKEN만 있으면 됩니다. `"codex pet"`, `"create codex pet"`, `"make codex pet"`, `"hatch codex pet"`, `"/hatch image"`, `"desktop pet codex"`, `"codex pets"`, `"spritesheet.webp"` 등과 같이 OpenAI Codex용 맞춤형 펫을 만들라는 명시적인 요청이 있을 때 작동합니다.
