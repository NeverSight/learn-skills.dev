Редактируйте изображения с помощью Google Nano Banana 2 (конечная точка редактирования image‑to‑image) в RunComfy. Описываются сильные стороны Nano Banana Edit (сохранение идентичности объекта, замена фона, локализация правок с помощью пространственного языка, пакетное редактирование нескольких изображений до 20 входов), схема и случаи, когда вместо этого следует переключаться на редактирование GPT Image 2, Flux Kontext или Nano Banana 2 t2i. Выполняет вызов `runcomfy run google/nano-banana-2/edit` через локальный CLI RunComfy. Срабатывает на фразы «nano banana edit», «edit with nano banana», «image edit nano banana» или любой явный запрос редактировать с использованием этой модели.
