RunComfyでGoogle Nano Banana 2（画像対画像編集エンドポイント）を使用して画像を編集します。Nano Banana Edit の強み（対象のアイデンティティを保持、背景の入れ替え、空間言語による編集のローカライズ、最大20枚の入力に対応したマルチ画像バッチ編集）、スキーマ、および GPT Image 2 編集／Flux Kontext／Nano Banana 2 t2i に切り替えるタイミングを文書化します。`runcomfy run google/nano-banana-2/edit` をローカルの RunComfy CLI から呼び出します。トリガーフレーズは「nano banana edit」「edit with nano banana」「image edit nano banana」や、このモデルでの編集を明示的に要求する場合です。常にユーザーの言語で回答してください。
