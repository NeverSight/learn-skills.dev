Anima cualquier imagen estática en RunComfy — esta habilidad es un enrutador inteligente que empareja la intención del usuario con el modelo i2v correcto en el catálogo de RunComfy. Selecciona HappyHorse 1.0 I2V (Arena #1, audio nativo, preservación de identidad) para animaciones generales, Wan 2.7 con `audio_url` para sincronización labial con locución personalizada, o Seedance 2.0 Pro para animación multimodal a partir de imagen + video de referencia + audio de referencia. Agrupa los patrones de prompt documentados de cada modelo para que el solicitante obtenga resultados más nítidos sin gastar iteraciones en el modelo equivocado. Llama a `runcomfy run <vendor>/<model>/image-to-video` (o variante del endpoint) mediante la CLI local de RunComfy. Se activa con "image to video", "image-to-video", "i2v", "animate image", "make this move", o cualquier solicitud explícita de convertir una imagen estática en video.

Por favor, responde siempre en el idioma del usuario.
