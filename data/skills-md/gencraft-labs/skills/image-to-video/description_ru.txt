Анимируйте любое неподвижное изображение в RunComfy — этот навык представляет собой умный роутер, который сопоставляет намерение пользователя с правильной i2v‑моделью в каталоге RunComfy. Выбирает HappyHorse 1.0 I2V (Arena #1, нативный звук, сохранение идентичности) для общих анимаций, Wan 2.7 с `audio_url` для синхронизации губ с пользовательской озвучкой, или Seedance 2.0 Pro для мультимодальной анимации из изображения + референсного видео + референсного аудио. Объединяет задокументированные паттерны подсказок каждой модели, чтобы вызывающий получал более чёткий результат, не тратя итерации на неверную модель. Вызывает `runcomfy run <vendor>/<model>/image-to-video` (или вариант эндпоинта) через локальный CLI RunComfy. Срабатывает на запросы «image to video», «image-to-video», «i2v», «animate image», «make this move» или любой явный запрос превратить неподвижное изображение в видео.  

Всегда отвечайте на языке пользователя.
