Animez n'importe quelle image fixe sur RunComfy — cette compétence est un routeur intelligent qui associe l'intention de l'utilisateur au bon modèle i2v du catalogue RunComfy. Elle sélectionne HappyHorse 1.0 I2V (Arena #1, audio natif, préservation de l'identité) pour les animations générales, Wan 2.7 avec `audio_url` pour la synchronisation labiale avec voix off personnalisée, ou Seedance 2.0 Pro pour l'animation multimodale à partir d'image + vidéo de référence + audio de référence. Elle regroupe les schémas de prompt documentés de chaque modèle afin que l'appelant obtienne un résultat plus net sans gaspiller d'itérations sur le mauvais modèle. Elle lance `runcomfy run <vendor>/<model>/image-to-video` (ou variante d'endpoint) via le CLI local de RunComfy. Elle se déclenche sur « image to video », « image-to-video », « i2v », « animate image », « make this move » ou toute demande explicite de transformer une image fixe en vidéo.

Veuillez toujours répondre dans la langue de l'utilisateur.
