Создавайте кинематографическое короткое видео с помощью ByteDance Seedance 2.0 Pro в RunComfy. Описывайте сильные стороны Seedance 2.0 Pro (мультимодальные референсы — до 9 изображений, 3 видео, 3 аудио — синхронизированный в‑проходной звук с естественной синхронизацией губ, кинематографическая доработка движений), схему длительности 4–15 сек и случаи, когда следует переключать на HappyHorse 1.0 / Wan 2.7 / Kling. Вызывает `runcomfy run bytedance/seedance-v2/pro` через локальный CLI RunComfy. Активируется по словам «seedance», «seedance 2», «seedance v2», «seedance pro», «bytedance video» или любому явному запросу на генерацию видео этой моделью.
