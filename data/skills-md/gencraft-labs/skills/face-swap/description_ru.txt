Замените лицо/персонаж в видео или изображениях на RunComfy с помощью CLI `runcomfy`. Поддерживает маршрутизацию через сообщества Wan 2‑2 Animate (анимация персонажа, управляемая аудио, + замена идентичности), GPT Image 2 Edit (однократный точный обмен лицами на статических изображениях с помощью ссылочного композитинга), Nano Banana Edit (массовый обмен с сохранением идентичности), Flux Kontext (локальная высококачественная правка лица по единственной ссылке) и Kling 2‑6 Motion Control Pro (перенос движений из одного исполнения на целевого персонажа). Выбирает правильную модель в соответствии с реальной задачей пользователя — одиночный кадр против видео, полностью персонаж против только лица, диалоговая сцена против беззвучного движения. Активируется по запросам «face swap», «swap face», «deepfake», «face replacement», «character swap», «head swap», «put X's face on Y», «make this video star X», «replace the actor in this video», «swap the character in the photo», «deepfake video», «ReActor alternative» или любому явному запросу заменить одну личность на другую.
