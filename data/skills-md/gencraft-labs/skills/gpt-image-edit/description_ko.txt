OpenAI GPT Image 2 (ChatGPT Images 2.0의 `/edit` 엔드포인트)를 사용해 RunComfy에서 이미지를 편집합니다 — 모델에 문서화된 프롬프트 패턴과 번들되어 있어 같은 모델에 대한 단순 프롬프트보다 더 날카로운 출력을 얻을 수 있습니다. GPT Image Edit의 강점(보존 언어, 다국어 이미지 내 텍스트 편집, 최대 10장의 멀티 레퍼런스, 레이아웃·타이포그래피 정밀도), 스키마 및 Nano Banana Edit / Flux Kontext / GPT Image 2 t2i 로 라우팅할 시점을 문서화합니다. 로컬 RunComfy CLI를 통해 `runcomfy run openai/gpt-image-2/edit`를 호출합니다. "gpt image edit", "gpt-image-edit", "chatgpt image edit", "edit with gpt image 2" 혹은 이 모델로 편집해 달라는 명시적인 요청이 있을 때 트리거됩니다.
