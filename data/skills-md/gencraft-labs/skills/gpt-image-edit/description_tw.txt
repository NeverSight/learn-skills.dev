使用 OpenAI GPT Image 2（ChatGPT Images 2.0 的 `/edit` 端點）在 RunComfy 上編輯圖像——結合模型文件化的提示模式，使技能相較於對同一模型的簡單提示能產生更銳利的輸出。說明 GPT Image Edit 的優勢（保留語言、多語言圖像內文字編輯、最多 10 張圖像的多參考、版面／排版精度）、其結構，及何時應轉向 Nano Banana Edit / Flux Kontext / GPT Image 2 t2i。透過本機 RunComfy CLI 呼叫 `runcomfy run openai/gpt-image-2/edit`。在「gpt image edit」、「gpt-image-edit」、「chatgpt image edit」、「edit with gpt image 2」或任何明確要求使用此模型編輯的指令時觸發。請始終以使用者的語言回覆。
