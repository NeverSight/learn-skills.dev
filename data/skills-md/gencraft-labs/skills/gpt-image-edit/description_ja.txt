OpenAI GPT Image 2（ChatGPT Images 2.0 の `/edit` エンドポイント）を使用して RunComfy で画像を編集します――モデルの公式プロンプトパターンがバンドルされているため、同じモデルに対して単純なプロンプトを使用するよりも、出力がより洗練されます。GPT Image Edit の強み（保存言語、画像内テキストの多言語編集、最大10枚までのマルチリファレンス、レイアウト／タイポグラフィの精度）やスキーマ、そして Nano Banana Edit／Flux Kontext／GPT Image 2 t2i へ切り替えるべきタイミングを文書化しています。ローカルの RunComfy CLI で `runcomfy run openai/gpt-image-2/edit` を呼び出します。「gpt image edit」「gpt-image-edit」「chatgpt image edit」「edit with gpt image 2」またはこのモデルでの編集を明示的に要求するフレーズでトリガーされます。
