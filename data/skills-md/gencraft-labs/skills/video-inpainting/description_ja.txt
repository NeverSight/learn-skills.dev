RunComfy の `runcomfy` CLI を使用したビデオフレーム全体の領域編集 — 複数フレームにわたって現れるオブジェクトの削除、ワイヤや透かしの除去、動きに合わせた領域の置き換え。Wan 2‑7 の edit‑video（デフォルト、空間言語によるプロンプト駆動の領域編集）、Lucy Edit Restyle（身元が安定した領域認識リスタイル）、および Seedream 4‑0 の edit‑sequential（クリップをフレームスタックとして扱う場合）を経路として使用。変更が文章駆動か、身元ロックか、フレームごとのインペイントを動画にチェーンする必要があるかに応じて適切な経路を選択。「video inpaint」「video inpainting」「remove from video」「mask region in video」「clean up video」「remove object from clip」「video patch」「frame‑by‑frame edit」「remove watermark from video」「remove passing person」またはビデオフレーム全体の領域編集を明示的に要求する語句でトリガーされます。
