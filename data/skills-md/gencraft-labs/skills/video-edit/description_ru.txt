Редактировать существующее видео в RunComfy — этот навык выступает в роли умного маршрутизатора, который сопоставляет намерения пользователя с нужной моделью редактирования в каталоге RunComfy. Выбирает Wan 2.7 Edit‑Video (общий рестайл / замена фона / замена упаковки, сохранение идентичности и движения), Kling 2.6 Pro Motion Control (перенос точного движения из референсного видео на целевого персонажа) или Lucy Edit Restyle (облегчённый рестайл с сохранением идентичности / замена наряда). Объединяет документированные паттерны подсказок каждой модели, чтобы навык делал более точные правки без траты итераций на неправильную модель. Вызывает `runcomfy run <vendor>/<model>/<endpoint>` через локальный CLI RunComfy. Срабатывает на запросы «video edit», «edit video», «restyle video», «swap video background», «motion control», «outfit swap video» или любой явный запрос преобразовать видео.  
Пожалуйста, всегда отвечайте на языке пользователя.
