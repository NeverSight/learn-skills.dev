RunComfy で OpenAI GPT Image 2（ChatGPT Images 2.0）を使って画像を生成・編集します。GPT Image 2 の強み（埋め込みテキスト、ロゴ、多言語タイポグラフィ、指示の精度）、3 つの固定サイズ、保存しながら編集するための言語、そして兄弟モデル（Flux 2／Nano Banana Pro／Seedream）へルーティングすべきタイミングを文書化します。ローカルの RunComfy CLI から `runcomfy run openai/gpt-image-2/text-to-image` または `/edit` を呼び出します。「gpt image 2」「gpt-image-2」「ChatGPT Images 2」「image 2」あるいはこのモデルでの生成・編集を明示的に要求するすべての呼びかけでトリガーされます。
