使用 RunComfy 生成和編輯 OpenAI GPT Image 2（ChatGPT Images 2.0）圖像。說明 GPT Image 2 的優勢（嵌入文字、標誌、多語言排版、指令精確度）、其三種固定尺寸、可保留原圖的編輯語言，以及何時轉向同系列模型（Flux 2 / Nano Banana Pro / Seedream）。透過本機 RunComfy CLI 呼叫 `runcomfy run openai/gpt-image-2/text-to-image` 或 `/edit`。當輸入「gpt image 2」、「gpt-image-2」、「ChatGPT Images 2」、「image 2」或任何明確要求使用此模型生成或編輯時即觸發。請始終以使用者的語言回覆。
