RunComfy에서 OpenAI GPT Image 2(ChatGPT Images 2.0)를 사용해 이미지를 생성하고 편집합니다. GPT Image 2의 강점(내장 텍스트, 로고, 다국어 타이포그래피, 명령 정밀도), 3가지 고정 크기, 보존 편집 언어, 그리고 언제 형제 모델(Flux 2 / Nano Banana Pro / Seedream)로 전환해야 하는지를 문서화합니다. 로컬 RunComfy CLI를 통해 `runcomfy run openai/gpt-image-2/text-to-image` 또는 `/edit` 를 호출합니다. “gpt image 2”, “gpt-image-2”, “ChatGPT Images 2”, “image 2” 혹은 이 모델로 생성·편집하라는 명시적 요청이 있을 때 트리거됩니다.
