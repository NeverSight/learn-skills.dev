Генерировать текст‑видео с Wan 2.7 (флагманской моделью движения Wan‑AI) в RunComfy. Документирует сильные стороны Wan 2.7 (мульти‑референсное условие, синхронизация губ по аудио через `audio_url`, более плавные переходы, расширение подсказки), схему длительности / разрешения / соотношения сторон и когда следует перенаправлять на HappyHorse 1.0 / Seedance 2.0 / Kling / LTX 2 вместо этого. Вызывает `runcomfy run wan-ai/wan-2-7/text-to-video` через локальный CLI RunComfy. Срабатывает по запросам «wan», «wan 2.7», «wan-2-7», «wan video» или любому явному запросу сгенерировать видео этой моделью.
