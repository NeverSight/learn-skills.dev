RunComfyでのKling 3.0ビデオ生成。Kling 3.0（Kling V3.0とも呼ばれる）は、快手テクノロジーの第3世代マルチショット動画モデルで、ネイティブ同期オーディオとショット間で一貫したキャラクターアイデンティティを備えています。このスキルは、3つのレンダリング階層（Standard、Pro、4K）と2つのモード（テキストから動画、画像から動画）にまたがる全6つのKling 3.0エンドポイントをカバーします。ローカルのRunComfy CLI を介して `runcomfy run kling/kling-3.0/<tier>/<mode>` を呼び出します。トリガーは「kling」「kling 3.0」「kling v3」「kling pro」「kling 4k」「kling text to video」「kling image to video」またはKling 3.0で生成またはアニメーションを行う明示的な要求です。
