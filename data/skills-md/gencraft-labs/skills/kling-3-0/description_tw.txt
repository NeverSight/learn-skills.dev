在 RunComfy 上生成 Kling 3.0 影片。Kling 3.0（亦稱 Kling V3.0）是快手科技的第三代多鏡頭影片模型，具備原生同步音訊以及跨鏡頭一致的角色身份。此技能涵蓋所有六個 Kling 3.0 端點，涵蓋三個渲染層級（Standard、Pro、4K）與兩種模式（文字轉影片、影像轉影片）。透過本機 RunComfy CLI，呼叫 runcomfy run kling/kling-3.0/<tier>/<mode>。在出現「kling」「kling 3.0」「kling v3」「kling pro」「kling 4k」「kling text to video」「kling image to video」或任何明確要求使用 Kling 3.0 生成或動畫的情況時觸發。請始終以使用者的語言回應。
