Génération de vidéo Kling 3.0 sur RunComfy. Kling 3.0 (également appelé Kling V3.0) est le modèle vidéo multi‑plan de troisième génération de Kuaishou Technology, doté d’audio synchronisé natif et d’une identité de personnage cohérente entre les plans. Cette compétence couvre les six points de terminaison Kling 3.0, répartis sur trois niveaux de rendu (Standard, Pro, 4K) et deux modes (texte‑vers‑vidéo, image‑vers‑vidéo). Elle appelle runcomfy run kling/kling-3.0/<niveau>/<mode> via le CLI local de RunComfy. Elle se déclenche sur « kling », « kling 3.0 », « kling v3 », « kling pro », « kling 4k », « kling text to video », « kling image to video », ou toute demande explicite de génération ou d’animation avec Kling 3.0. Veuillez toujours répondre dans la langue de l’utilisateur.
