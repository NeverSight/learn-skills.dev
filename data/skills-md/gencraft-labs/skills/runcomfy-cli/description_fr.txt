Lancez n'importe quel modèle sur RunComfy depuis la ligne de commande. Le CLI `runcomfy` est un seul binaire, une authentification, des centaines de points d'accès aux modèles — génération d'images, édition d'images, génération de vidéos, image‑vers‑vidéo, synchronisation labiale, échange de visage, édition vidéo, inpainting, outpainting, extension, ControlNet, éclaircissement, mise à l'échelle, entraînement LoRA et bien plus encore. Soumettez une requête, interrogez le statut, téléchargez le résultat. Cette compétence apprend à l'agent comment installer, s'authentifier, découvrir les schémas des modèles, invoquer les modèles, diffuser / interroger / sans attente, script en mode sortie JSON, et gérer les erreurs. Elle se déclenche sur « runcomfy cli », « install runcomfy », « runcomfy login », « runcomfy run », « runcomfy whoami », « runcomfy api », ou toute demande explicite d'appeler un modèle RunComfy depuis un script ou un terminal. Les compétences voisines (ai-image-generation, ai-video-generation, image-edit, video-edit, face-swap, lipsync, image-to-video, image-inpainting, image-outpainting, video-extend, controlnet-pose, relight) sont toutes dispatchées via ce CLI.
