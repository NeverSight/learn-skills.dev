Ejecuta cualquier modelo en RunComfy desde la línea de comandos. El CLI `runcomfy` es un binario, una autenticación y cientos de puntos finales de modelo: generación de imágenes, edición de imágenes, generación de video, imagen‑a‑video, sincronización labial, intercambio de rostros, edición de video, inpainting, outpainting, extensión, ControlNet, relight, upscale, entrenamiento LoRA y más. Envía una solicitud, consulta el estado y descarga la salida. Esta habilidad enseña al agente cómo instalar, autenticarse, descubrir esquemas de modelo, invocar modelos, transmitir / consultar / sin espera, crear scripts en modo de salida JSON y manejar errores. Se activa con “runcomfy cli”, “install runcomfy”, “runcomfy login”, “runcomfy run”, “runcomfy whoami”, “runcomfy api” o cualquier petición explícita para llamar a un modelo RunComfy desde un script o terminal. Las habilidades hermanas (ai-image-generation, ai-video-generation, image-edit, video-edit, face-swap, lipsync, image-to-video, image-inpainting, image-outpainting, video-extend, controlnet-pose, relight) se despachan a través de este CLI.
