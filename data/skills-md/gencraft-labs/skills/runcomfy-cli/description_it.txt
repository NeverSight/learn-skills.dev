Esegui qualsiasi modello su RunComfy dalla riga di comando. Il CLI `runcomfy` è un unico binario, un'unica autenticazione, centinaia di endpoint di modelli — generazione di immagini, modifica di immagini, generazione di video, immagine‑a‑video, sincronizzazione labiale, scambio di volti, modifica di video, inpainting, outpainting, estensione, ControlNet, riilluminazione, upscale, addestramento LoRA e altro. Invia una richiesta, controlla lo stato, scarica l'output. Questa skill insegna all'agente come installare, autenticarsi, scoprire gli schemi dei modelli, invocare i modelli, streaming / polling / no‑wait, scriptare in modalità output JSON e gestire gli errori. Si attiva con “runcomfy cli”, “install runcomfy”, “runcomfy login”, “runcomfy run”, “runcomfy whoami”, “runcomfy api”, o qualsiasi richiesta esplicita di chiamare un modello RunComfy da uno script o terminale. Le skill correlate (ai-image-generation, ai-video-generation, image-edit, video-edit, face-swap, lipsync, image-to-video, image-inpainting, image-outpainting, video-extend, controlnet-pose, relight) vengono tutte instradate attraverso questo CLI.
