RunComfy の Wan‑AI Wan 3.0 Prime Reference to Video を使って、参照画像、参照動画、参照音声からビデオクリップを作成します。最大で 10 枚の参照画像、5 本の参照動画、5 本の参照音声クリップを、プロンプト内で「Image 1」「Video 1」「Audio 1」などと名前付けしてバインドし、キャラクター・製品・シーンの一貫性を保った 2〜30 秒のショットを、480p、720p、または 1080p の解像度で、同期された音声トラックと共に生成します。完全な入力スキーマ、秒単位の価格モデル（参照動画は再生時間で課金され、画像と音声は課金されません）、および Wan 3.0 Prime のテキスト→ビデオ／画像→ビデオ、Wan 2.7、または Seedance 2.0 Pro に切り替えるタイミングを文書化しています。ローカルの RunComfy CLI を介して `runcomfy run wan-ai/wan-3.0-prime/reference-to-video` を呼び出します。以下のフレーズでトリガーされます：「wan 3 prime reference to video」「wan 3.0 prime」「wan3 prime」「reference to video」「ref2v」「keep the same character across shots」「video from reference images」またはこのモデルで参照からビデオを生成する明示的な要求。
