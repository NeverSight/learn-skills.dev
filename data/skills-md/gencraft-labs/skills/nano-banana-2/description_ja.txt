Google Nano Banana 2（Gemini ファミリーのフラッシュティア テキスト→画像）を RunComfy で画像生成 — モデルのドキュメント化されたプロンプトパターンが同じモデルに対する単純なプロンプトよりも鋭い出力を得られるようにスキルに組み込まれています。Nano Banana 2 の強み（高速な反復、画像内タイポグラフィのレンダリング、予測可能なフレーミング、オプションのウェブベースコンテキスト）、解像度ティアの価格設定、安全許容度ダイヤル、そして Nano Banana Pro / GPT Image 2 / Flux 2 / Seedream に切り替えるタイミングを文書化しています。ローカルの RunComfy CLI を通じて `runcomfy run google/nano-banana-2/text-to-image` を呼び出します。「nano banana」「nano-banana-2」「nano banana 2」「google image gen」「gemini image」またはこのモデルで生成する旨の明示的なリクエストでトリガーされます。
