在 RunComfy 上使用 Google Nano Banana 2（Gemini 系列閃速等級文字生成圖像）生成圖像 — 並捆绑模型已記錄的提示模式，使得此技能的輸出比對同一模型的簡單提示更為精細。說明 Nano Banana 2 的優勢（快速迭代、圖像內文字排版渲染、可預測的構圖、可選的網路基礎上下文）、分辨率等級定價、安全容忍度調節，以及何時切換至 Nano Banana Pro / GPT Image 2 / Flux 2 / Seedream 等其他模型。透過本機 RunComfy CLI 呼叫 `runcomfy run google/nano-banana-2/text-to-image`。在出現「nano banana」、「nano-banana-2」、「nano banana 2」、「google image gen」、「gemini image」或任何明確要求使用此模型生成的指令時觸發。
