Outpainting d'image sur RunComfy via la CLI `runcomfy` — étendre une image fixe au‑delà de son canevas d'origine, remplir ce que la caméra n’a pas capturé, changer le format (carré → 16 : 9, portrait → paysage) tout en préservant le contenu original. Itinéraires à travers Nano Banana 2 Edit (par défaut, piloté par le langage spatial), GPT Image 2 Edit (multi‑référence avec correspondance de style de référence), FLUX Kontext Pro (preservation maximale en une seule passe) et les points de terminaison d’édition de marque (Seedream / Dreamina / Qwen / FLUX 2). Sélectionne le bon itinéraire selon que l’outpaint est guidé par la prose, par la référence ou verrouillé par la marque. Se déclenche sur « outpaint », « outpainting », « extend image canvas », « expand the image », « fill in around the photo », « uncrop », « change aspect ratio », « extend frame », « wide‑screen from square », ou toute demande explicite d’ajouter du canevas autour d’une image existante.  

Veuillez toujours répondre dans la langue de l’utilisateur.
