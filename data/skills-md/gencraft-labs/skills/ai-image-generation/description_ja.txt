RunComfy の `runcomfy` CLI を使用して画像の生成と編集を行う — 画像モデルカタログ全体を跨ぐスマートルータです：FLUX 2（Klein 9B/4B、Pro、Dev、Flash、Turbo、Max）、Google Nano Banana 2 / Pro、OpenAI GPT Image 2、ByteDance Seedream 5 / 4‑5 / 4‑0 と Dreamina 4‑0、Alibaba Qwen Image と Z‑Image Turbo、Wan 2‑7。テキストから画像への変換（t2i）と画像から画像への変換／編集（i2i）の両方に対応し、スキルがユーザーの実際の意図（タイポグラフィの精度、フォトリアリスティックなポートレート、サブ秒の反復、複数参照のブランドスタイリング、オープンウェイトのワークフロー）に最適なモデルを自動選択し、各モデルの文書化されたプロンプトパターンと最小限の `runcomfy run` 呼び出しを提供します。「generate image」「make a picture」「text to image」「AI image」「make an image of …」「image to image」「i2i」など、画像を作成またはリスタイルする明示的な要求があるとトリガーされます。
