Редактировать изображения в RunComfy — этот навык выступает умным роутером, который сопоставляет намерения пользователя с подходящей моделью редактирования в каталоге RunComfy. Выбирает Nano Banana Edit (пакет до 20, сохранение идентичности по умолчанию), OpenAI GPT Image 2 Edit (многоязычная переписка текста внутри изображения, многореференсная композиция, точность компоновки), Flux Kontext Pro (один референс, высококачественное локальное редактирование) или Z‑Image Turbo Inpaint (маска‑управляемое точное редактирование области). Объединяет документированные шаблоны запросов каждой модели, чтобы навык делал более точные правки, не тратя итерации на неверную модель. Вызывает `runcomfy run <vendor>/<model>/edit` через локальный CLI RunComfy. Срабатывает на команды «image edit», «edit image», «image-to-image», «i2i», «swap background», «remove object», «rewrite headline» или любой явный запрос редактировать одно или несколько изображений.
