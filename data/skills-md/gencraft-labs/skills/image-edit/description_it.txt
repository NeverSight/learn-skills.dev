Modifica le immagini su RunComfy — questa skill è un router intelligente che abbina l’intento dell’utente al modello di editing corretto nel catalogo RunComfy. Seleziona Nano Banana Edit (batch fino a 20, impostazione predefinita che preserva l’identità), OpenAI GPT Image 2 Edit (riscrittura di testo multilingue all’interno dell’immagine, composizione multi‑riferimento, precisione del layout), Flux Kontext Pro (editing locale ad alta fedeltà con singolo riferimento) o Z-Image Turbo Inpaint (editing preciso di regioni guidato da maschera). Raggruppa i pattern di prompting documentati per ogni modello in modo che la skill produca modifiche più precise senza sprecare iterazioni sul modello sbagliato. Esegue `runcomfy run <vendor>/<model>/edit` tramite la CLI locale di RunComfy. Si attiva con “image edit”, “edit image”, “image-to-image”, “i2i”, “swap background”, “remove object”, “rewrite headline” o qualsiasi richiesta esplicita di modificare una singola immagine o un batch.
