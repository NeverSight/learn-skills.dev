Modifiez les images sur RunComfy — cette compétence est un routeur intelligent qui associe l’intention de l’utilisateur au bon modèle d’édition du catalogue RunComfy. Elle sélectionne Nano Banana Edit (lot jusqu’à 20, préservation de l’identité par défaut), OpenAI GPT Image 2 Edit (réécriture multilingue de texte dans l’image, composition multi‑référence, précision de mise en page), Flux Kontext Pro (édition locale haute fidélité à référence unique) ou Z‑Image Turbo Inpaint (édition précise de région guidée par masque). Elle regroupe les schémas d’invite documentés de chaque modèle afin que la compétence produise des éditions plus précises sans gaspiller d’itérations sur le mauvais modèle. Elle exécute `runcomfy run <vendor>/<model>/edit` via le CLI local de RunComfy. Elle se déclenche sur « image edit », « edit image », « image-to-image », « i2i », « swap background », « remove object », « rewrite headline », ou toute demande explicite d’éditer une image ou un lot d’images.
