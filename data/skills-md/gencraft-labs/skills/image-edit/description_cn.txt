在 RunComfy 上编辑图像 — 该技能是一个智能路由器，可将用户的意图匹配到 RunComfy 目录中的正确编辑模型。可选择 Nano Banana Edit（批量最高 20，默认保持身份）、OpenAI GPT Image 2 Edit（多语言图内文本重写、多参考合成、布局精度）、Flux Kontext Pro（单参考高保真局部编辑）或 Z-Image Turbo Inpaint（基于掩码的精确区域编辑）。将每个模型的文档化提示模式打包，使技能在不浪费迭代次数于错误模型的情况下实现更精准的编辑。通过本地 RunComfy CLI 调用 `runcomfy run <vendor>/<model>/edit`。在出现“image edit”“edit image”“image-to-image”“i2i”“swap background”“remove object”“rewrite headline”或任何明确要求编辑单张或批量图像的指令时触发。
