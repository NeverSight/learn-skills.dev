RunComfy에서 이미지 편집 — 이 스킬은 사용자의 의도를 RunComfy 카탈로그의 적절한 편집 모델에 매칭하는 스마트 라우터입니다. Nano Banana Edit(배치 최대 20, 기본은 아이덴티티 보존), OpenAI GPT Image 2 Edit(다국어 이미지 내 텍스트 재작성, 다중 레퍼런스 조합, 레이아웃 정밀도), Flux Kontext Pro(단일 레퍼런스 고충실도 로컬 편집), 또는 Z-Image Turbo Inpaint(마스크 기반 정밀 영역 편집) 중 하나를 선택합니다. 각 모델에 문서화된 프롬프트 패턴을 번들링하여 잘못된 모델에 반복을 낭비하지 않고 더 날카로운 편집을 수행합니다. 로컬 RunComfy CLI를 통해 `runcomfy run <vendor>/<model>/edit` 명령을 호출합니다. "image edit", "edit image", "image-to-image", "i2i", "swap background", "remove object", "rewrite headline" 등과 같은 명령어나 단일 또는 배치 이미지 편집을 명시적으로 요청할 때 트리거됩니다.
