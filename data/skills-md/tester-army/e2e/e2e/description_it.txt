Test end-to-end agentici con e2e, il runner e2e. Copre la scaffolding di e2e.config.ts, la scelta del motore browser Playwright o del motore mobile agent-device, l'avvio dell'app in prova dalla configurazione, la gestione dei flussi con agent.act, la valutazione con agent.assert, agent.waitFor e agent.extract, il fissaggio dei valori con screen, app, browser ed expect, la definizione dell'agente (contesto, prompt di sistema, strumenti, personaggi), la cache di replay, la CLI e2e, la lettura di .e2e/report.json e i bug bash (esecuzioni parallele di explore confermate con test di riproduzione). Usare quando un progetto dipende da e2e, quando si richiedono test end-to-end, browser, mobile o UI agentici, per eseguire bug bash o cercare bug, o quando un'esecuzione e2e fallisce.
