أثبت أن أي تغيير في الـ e2e runner أو المحرك أو الـ CLI أو المراسل أو خادم MCP أو الوثائق يعمل كما يراه المستخدم – الـ CLI الحقيقي مقابل بيئة الاختبار وتطبيقات القياس، مع واجهة رسومية وعند الحاجة فيديو، والفرع الرئيسي مقابل الفروع لإصلاح الأخطاء. استخدم ذلك أثناء التكرار وقبل فتح طلب سحب، عندما يُطلب منك تشغيل شيء أو اختباره أو التحقق منه أو أخذ لقطة شاشة، لإعادة إنتاج تقرير خطأ، أو كلما كنت ستقول «إنه يُجمع».
