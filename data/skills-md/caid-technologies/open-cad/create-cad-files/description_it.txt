Creare parti CAD 3D dimensionate a partire da requisiti in linguaggio naturale ed esportare file STEP, STP o STL convalidati con OpenCAD. Utilizzare quando un utente chiede a un agente IA di modellare un componente meccanico, realizzare un STL stampabile, creare un file STEP editabile, convertire una descrizione dimensionale in CAD o revisionare un modello OpenCAD generato in precedenza.
