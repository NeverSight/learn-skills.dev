Compétence de pipeline pour le calcul d’ajustement du risque CMS-HCC et l’identification des lacunes de codage. Utilisez‑la lorsque l’utilisateur demande d’appliquer le mapping ICD‑10 vers HCC, de calculer les scores RAF, de résoudre les hiérarchies de maladies de manière programmatique, d’identifier les lacunes de codage à partir de proxys Rx ou de laboratoire, de projeter les scores de risque au niveau des membres, de construire un pipeline de données d’ajustement du risque, de calculer les coefficients HCC, d’exécuter le code de résolution de hiérarchie ou de générer des rapports de scores de risque des membres. Les déclencheurs incluent « calculate RAF score », « ICD-10 to HCC crosswalk », « hierarchy resolution code », « coding gap detection », « Rx proxy gap », « lab proxy gap », « risk score projection », « HCC pipeline », « member risk report », « risk adjustment Python », « risk adjustment SQL », « RAF calculation code », « CMS-HCC pipeline ».
