Размышляйте о дизайне фармакоэпидемиологических исследований для причинно-следственного вывода из реальных данных — выбирайте активные‑компарторные дизайны новых пользователей, эмулируйте целевые испытания, избегайте смещения бессмертного времени, учитывайте временно изменяющиеся конфаунды с помощью маргинальных структурных моделей и подбирайте методы propensity score. Используйте, когда пользователь просит разработать исследование безопасности или эффективности препарата: выбирайте между propensity score matching, взвешиванием (IPTW) или стратификацией, эмулируйте целевое испытание, устраняйте смещение бессмертного времени, применяйте маргинальные структурные модели, оценивайте несмоделируемое конфаундирование с помощью E‑value, выбирайте активный компаратор, определяйте когорту новых пользователей или оценивайте фармакоэпидемиологический дизайн. Триггеры включают «active comparator», «new‑user design», «target trial emulation», «immortal time bias», «propensity score matching», «IPTW», «marginal structural model», «confounding by indication», «E‑value», «negative control outcomes», «quantitative bias analysis», «time‑varying confounding», «prevalent user bias», «washout period», «landmark analysis», «stabilized weights».
