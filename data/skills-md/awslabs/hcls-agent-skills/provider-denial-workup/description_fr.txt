Compétence de raisonnement pour la gestion des refus dans le cycle de revenu des soins de santé. À utiliser lorsque l'utilisateur doit contester un refus de réclamation, rédiger une lettre d’appel de refus prête pour le payeur, analyser un code de motif de refus ou déterminer si une réclamation refusée doit être annulée, mise en attente ou acceptée. Les déclencheurs incluent « contester un refus de réclamation », « rédiger un appel de refus », « écrire une lettre d’appel », « refus CO-50 », « refus pour nécessité médicale », « appel de code CARC », « code RARC », « annuler le refus », « refus d’autorisation préalable », « refus pour dépôt tardif », « analyse du refus », « réponse du payeur au refus », « renverser le refus de réclamation », « refus CO-96 », « refus CO-97 », « lettre de refus », « gestion des refus », « avis de remise de paiement refusé », « refus 835 », « refus nécessitant une autorisation », « refus ERISA », « refus de soins gérés Medicaid », « refus de limite de visites », « refus de limite de prestations », « refus d’hospitalisation », « déclassement en observation ».
