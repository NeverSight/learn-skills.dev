Réfléchir à la conception d’expériences d’IA pour les données de santé et des sciences de la vie. Utiliser lorsque l’utilisateur demande de concevoir une étude d’IA, de choisir un modèle pour des données cliniques/bio‑médicales, de mettre en place une validation croisée, de sélectionner des métriques d’évaluation, d’auditer l’équité, de planifier une soumission réglementaire ou de critiquer un pipeline d’IA sur les dossiers médicaux électroniques, l’imagerie médicale, la génomique, les molécules ou le texte clinique. Les déclencheurs incluent « concevoir une expérience d’IA », « quel modèle pour ces données cliniques », « comment dois‑je diviser », « validation croisée imbriquée », « déséquilibre de classes », « AUROC vs AUPRC », « calibration », « courbe de décision », « bénéfice net », « TRIPOD+AI », « PROBAST », « CLAIM », « FDA SaMD », « PCCP », « GMLP », « généralisation de site », « fuite temporelle », « division en échafaudage », « évaluation de modèle de fondation », « équité des sous‑groupes », « le modèle est‑il prêt pour le déploiement ». Veuillez toujours répondre dans la langue de l’utilisateur.
