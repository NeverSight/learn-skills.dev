렌더링된 UI에 시각적 회귀 검사가 필요할 때 사용 — “UI가 변경되었는가”, “시각적 테스트”, “스크린샷 차이”, “베이스라인과 비교”, “레이아웃 회귀 포착”, 혹은 테스트 실행 중 시각적 어서션 등. 렌더링할 수 있는 모든 HTML에서 동작 — 디스크에서 열리는 생성된 정적 페이지(디자인 목업, 보고서, 흐름도 포스터) 또는 기존 브라우저·디바이스 자동화에 의해 구동되는 실행 중인 앱. 각 화면을 스크린샷으로 캡처하고, reg‑cli(MIT, 클라우드 없음)를 사용해 커밋된 베이스라인과 차이를 비교하며, 변경된 내용을 HTML 보고서와 합격·불합격 요약으로 제공. 캡처는 이미 사용 중인 브라우저 또는 디바이스 도구 위에서 수행되므로 별도의 헤드리스 엔진을 설치할 필요가 없음. 기능이나 정확성을 검증하는 것이 아니라(차이는 픽셀이 이동했음을 증명할 뿐, 옳은지를 증명하는 것이 아님), 빨간색 차이는 자동 판결이 아니라 확인을 위한 신호임.
