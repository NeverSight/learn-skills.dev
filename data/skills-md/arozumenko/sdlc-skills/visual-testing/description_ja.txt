レンダリングされた UI のビジュアル回帰チェックが必要なときに使用します ― 「UI が変わったか」「ビジュアルテスト」「スクリーンショット差分」「ベースラインと比較」「レイアウト回帰を検出」またはテスト実行時のビジュアルアサーションです。レンダリング可能な HTML であれば何でも動作します ― ディスクから開く生成された静的ページ（デザインモック、レポート、フローマップポスター）でも、既存のブラウザ/デバイス自動化で操作する実行中のアプリでも構いません。各画面をスクリーンショットし、reg‑cli（MIT ライセンス、クラウド不要）でコミットされたベースラインと差分を取り、変更点を HTML レポートと合格/不合格のサマリーで報告します。キャプチャはすでに使用しているブラウザやデバイスツール上で行われ、別途ヘッドレスエンジンをインストールする必要はありません。機能的・正確性のチェックではありません（差分はピクセルが変わったことを示すだけで、正しいかどうかは保証しません）。赤い差分は自動的な判定ではなく、確認すべきサインです。
