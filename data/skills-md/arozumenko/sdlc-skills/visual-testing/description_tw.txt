當需要對渲染後的 UI 進行視覺回歸檢查時使用 — 「UI 是否變更」、 「視覺測試」、 「截圖差異」、 「與基線比較」、 「捕捉版面配置回歸」或測試執行中的視覺斷言。適用於任何可渲染的 HTML — 例如從磁碟開啟的產生的靜態頁面（設計樣稿、報告、流程圖海報），或由現有瀏覽器/裝置自動化驅動的執行中應用程式。對每個畫面截圖，使用 reg-cli（MIT 授權、無雲端）與已提交的基線比較差異，並以 HTML 報告以及通過/失敗摘要的方式呈現變更。擷取工作依賴您現有的瀏覽器或裝置工具 — 無需安裝額外的無頭引擎。**不是**功能或正確性檢查（差異僅證明像素變動，並不代表內容正確），紅色差異只是提示需要檢查，而非自動判決。
