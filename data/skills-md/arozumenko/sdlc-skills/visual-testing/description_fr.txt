À utiliser lorsque l’interface rendue nécessite une vérification de régression visuelle — « l’UI a-t-elle changé », « test visuel », « différence de capture d’écran », « comparer avec la référence », « détecter les régressions de mise en page » ou une assertion visuelle lors d’un test. Fonctionne sur tout HTML que vous pouvez rendre — une page statique générée (maquette, rapport, affiche de flux) ouverte depuis le disque, ou une application en cours d’exécution pilotée par votre automatisation de navigateur/appareil existante. Capture chaque écran, le compare à une référence engagée avec reg‑cli (MIT, aucune donnée cloud), et indique les changements dans un rapport HTML accompagné d’un résumé succès/échec. La capture s’appuie sur le navigateur ou l’outil d’appareil que vous avez déjà — aucun moteur sans tête séparé n’est installé. CE N’EST PAS un test fonctionnel ou de correction (une différence montre que des pixels ont bougé, pas que tout est correct), et une différence rouge constitue une invitation à examiner, pas un verdict automatique.
