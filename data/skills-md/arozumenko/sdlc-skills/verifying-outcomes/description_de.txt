Verwenden Sie diese Option, wenn der Benutzer nach "Verifizieren", "Hat dies tatsächlich funktioniert", "Ist X wirklich erledigt" fragt — oder bevor Sie behaupten, dass eine Aufgabe abgeschlossen ist und bevor Sie ein Problem schließen oder eine PR zusammenführen. Ziel-Rückwärts-Verifizierung — prüft, ob das gewünschte Ergebnis erreicht wurde, nicht, ob Aufgaben als erledigt markiert wurden.
