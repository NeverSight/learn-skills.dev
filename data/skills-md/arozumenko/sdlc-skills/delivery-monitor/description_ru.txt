Монитор доставки для элементов работы Harness — сестринский инструмент токеномики, измеряющий время цикла и ритм. Регистрирует план (кампания → миссия → задача) с диапазоном оценок, приемлемых для человека, фиксирует переходы отправки/слияния/отмены в журнал событий, зафиксированный в git (.agents/telemetry/delivery/), восстанавливает историю из git и формирует отчёт о времени цикла, недельной пропускной способности/скорости и разнице между оценкой и фактом по каждому уровню. Используйте, когда пользователь задаёт вопросы «как быстро мы доставляем», «записать план / оценки», «зафиксировать, что TASK‑023 слит», «отчёт / статус доставки», «включить отслеживание доставки» или «насколько точны наши оценки». Для расчёта стоимости за случай используйте токеномику; для оценки объёма новой работы — автоматизированное определение объёма (automation‑scoping). Пожалуйста, всегда отвечайте на языке пользователя.
