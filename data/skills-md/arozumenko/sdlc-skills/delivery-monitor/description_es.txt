Monitor de entrega para ítems de trabajo de harness — el hermano de ciclo de tiempo y cadencia de tokenomics. Registra un plan (campaña → misión → tarea) con estimaciones en rangos aceptadas por humanos, registra transiciones de envío/fusión/cancelación en un libro de eventos comprometido en git (.agents/telemetry/delivery/), retroactiva el historial desde git y reporta tiempo de ciclo, rendimiento/velocidad semanal y delta de estimación vs real por nivel. Úselo cuando el usuario pregunte “qué tan rápido estamos entregando”, “registrar el plan / estimaciones”, “registrar que TASK‑023 se fusionó”, “informe de entrega / estado”, “activar el seguimiento de entrega” o “qué tan buenas fueron nuestras estimaciones”. Para costo por caso use tokenomics; para dimensionar nuevo trabajo use automation‑scoping.
