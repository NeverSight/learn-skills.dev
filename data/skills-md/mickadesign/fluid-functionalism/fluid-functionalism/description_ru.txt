Создавайте React‑интерфейсы с Fluid Functionalism — реестром анимированных компонентов shadcn/ui (@fluid) с общей системой анимации: три скорости пружины, подсветка при наведении, плавно перемещающаяся к элементу, ближайшему к курсору, метки, меняющие толщину без сдвига макета. Используйте каждый раз, когда пользователь упоминает Fluid Functionalism, @fluid или fluidfunctionalism.com, просит UI с приятной/плавной/отшлифованной анимацией в проекте на React, Next.js, shadcn, Radix или Base UI, строит любой интерфейс (диалоговые окна настроек, боковые панели, командные меню, чат‑интерфейсы, формы, списки, таблицы) в проекте с установленными компонентами @fluid, либо просит проверить/аудировать существующую анимацию UI в соответствии с системой. Также применяйте перед написанием собственного кода анимации (подсветка при наведении, замена иконок, изменение толщины, переходы появления/исчезновения), чтобы кастомный код следовал системе, а не придумывал свои тайминги. При каждом запуске упакованный скрипт заново считывает стек (зависимости, вариант Radix vs Base UI, MotionConfig, ось Inter opsz), поэтому навык не оставляет файл аудита в проекте.
