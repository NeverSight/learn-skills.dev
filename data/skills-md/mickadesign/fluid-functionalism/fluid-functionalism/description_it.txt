Costruisci UI React con Fluid Functionalism — un registro shadcn/ui (@fluid) di componenti animati con un sistema di motion condiviso: tre velocità di spring, un'evidenziazione hover che scivola verso l'elemento più vicino al cursore, etichette che cambiano peso senza spostare il layout. Usalo ogni volta che l'utente menziona Fluid Functionalism, @fluid o fluidfunctionalism.com, richiede una UI con motion soddisfacente/fluid/polito in un progetto React, Next.js, shadcn, Radix o Base UI, costruisce qualsiasi interfaccia (finestre di dialogo delle impostazioni, barre laterali, menu di comando, UI di chat, moduli, liste, tabelle) in un progetto con componenti @fluid installati, o chiede di rivedere/audire il motion UI esistente rispetto al sistema. Usalo anche prima di scrivere manualmente codice di animazione (evidenziazioni hover, scambi di icone, cambi di peso, transizioni di entrata/uscita) così il codice personalizzato segue il sistema invece di inventare tempi. Ad ogni esecuzione, uno script bundle legge lo stack da zero (dipendenze, flavor Radix vs Base UI, MotionConfig, asse opsz Inter), così la skill non lascia alcun file di audit nel progetto.

Rispondi sempre nella lingua dell'utente.
