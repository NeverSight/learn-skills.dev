Construisez des interfaces React avec Fluid Functionalism — un registre shadcn/ui (@fluid) de composants animés dotés d’un système de mouvement partagé : trois vitesses de ressort, un surlignage au survol qui glisse vers l’élément le plus proche du curseur, des libellés qui changent de poids sans décalage de mise en page. Utilisez-le chaque fois que l’utilisateur mentionne Fluid Functionalism, @fluid ou fluidfunctionalism.com, demande une UI avec un mouvement satisfaisant, fluide ou poli dans un projet React, Next.js, shadcn, Radix ou Base UI, construit n’importe quelle interface (boîtes de dialogue de paramètres, barres latérales, menus de commandes, interfaces de chat, formulaires, listes, tableaux) dans un projet avec les composants @fluid installés, ou demande d’examiner/auditer le mouvement UI existant par rapport au système. Utilisez-le également avant d’écrire du code d’animation (surlignages au survol, échanges d’icônes, changements de poids, transitions d’entrée/sortie), afin que le code personnalisé suive le système plutôt que d’inventer des timings. À chaque exécution, un script empaqueté lit la pile à jour (dépendances, variante Radix ou Base UI, MotionConfig, axe Inter opsz), de sorte que la compétence ne laisse aucun fichier d’audit dans le projet.
