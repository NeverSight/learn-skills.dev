使用 Fluid Functionalism 建立 React UI — 一個 shadcn/ui 註冊表（@fluid），提供具共享動作系統的動畫元件：三種彈簧速度、會滑向光標最近項目的懸停高亮、在不改變版面配置的情況下改變字重的標籤。每當使用者提到 Fluid Functionalism、@fluid 或 fluidfunctionalism.com，或要求在 React、Next.js、shadcn、Radix 或 Base UI 專案中取得令人滿意／流暢／精緻的動作 UI，或在已安裝 @fluid 元件的專案中構建任何介面（設定對話框、側邊欄、指令選單、聊天 UI、表單、清單、表格），或要求檢視／稽核現有 UI 動作是否符合系統時，都使用它。另外，在手寫動畫程式碼（懸停高亮、圖示切換、字重變化、進出場過渡）之前先使用它，讓自訂程式碼遵循系統而不是自行發明時機。每次執行時，打包腳本會重新讀取整個堆疊（相依、Radix 與 Base UI 版本、MotionConfig、Inter opsz 軸），因此此技能不會在專案中留下稽核檔案。
