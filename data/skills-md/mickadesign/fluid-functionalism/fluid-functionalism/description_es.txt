Construye interfaces React con Fluid Functionalism — un registro shadcn/ui (@fluid) de componentes animados con un sistema de movimiento compartido: tres velocidades de resorte, un resaltado al pasar el cursor que se desliza al elemento más cercano al puntero, etiquetas que cambian de peso sin desplazamiento de diseño. Usa siempre que el usuario mencione Fluid Functionalism, @fluid o fluidfunctionalism.com, solicite una UI con movimiento satisfactorio/fluid/polido en un proyecto React, Next.js, shadcn, Radix o Base UI, construya cualquier interfaz (diálogos de configuración, barras laterales, menús de comandos, UIs de chat, formularios, listas, tablas) en un proyecto con los componentes @fluid instalados, o pida revisar/auditar el movimiento UI existente contra el sistema. También utilízalo antes de escribir código de animación manual (resaltados al pasar el cursor, intercambios de iconos, cambios de peso, transiciones de entrada/salida), de modo que el código personalizado siga el sistema en lugar de inventar tiempos. Cada ejecución, un script empaquetado lee la pila fresca (dependencias, variante Radix vs Base UI, MotionConfig, eje Inter opsz), por lo que la habilidad no deja ningún archivo de auditoría en el proyecto.
