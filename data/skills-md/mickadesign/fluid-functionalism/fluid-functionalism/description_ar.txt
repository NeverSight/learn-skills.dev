ابنِ واجهات React باستخدام الفلسفة السائلة للوظائف — سجل مكوّنات shadcn/ui (@fluid) المتحركة ذات نظام حركة مشترك: ثلاث سرعات زنبركية، تسليط إضاءة عند التحويم تنزلق إلى العنصر الأقرب إلى المؤشر، تسميات تغير وزنها دون إزاحة التخطيط. استخدم هذا عندما يذكر المستخدم الفلسفة السائلة للوظائف، @fluid، أو fluidfunctionalism.com، أو يطلب واجهة مستخدم ذات حركة مرضية/سائلة/مصقولة في مشروع React أو Next.js أو shadcn أو Radix أو Base UI، أو يبني أي واجهة (حوارات الإعدادات، الأشرطة الجانبية، قوائم الأوامر، واجهات الدردشة، النماذج، القوائم، الجداول) في مشروع مثبت فيه مكوّنات @fluid، أو يطلب مراجعة/تدقيق حركة الواجهة الحالية وفق النظام. كما يجب استخدامه قبل كتابة كود التحريك يدويًا (تسليط إضاءة عند التحويم، تبديل الأيقونات، تغيّر الوزن، انتقالات الدخول/الخروج) هناك، بحيث يتبع الكود المخصص النظام بدلاً من اختلاق توقيتات. في كل تشغيل، يقرأ برنامج مدمج المكدس من جديد (التبعيات، نكهة Radix مقابل Base UI، MotionConfig، محور Inter opsz)، وبالتالي لا يترك المهارة ملف تدقيق في المشروع.
