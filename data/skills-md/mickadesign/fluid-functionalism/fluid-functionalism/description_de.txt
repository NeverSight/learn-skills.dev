Erstelle React-UIs mit Fluid Functionalism — ein shadcn/ui‑Register (@fluid) animierter Komponenten mit einem gemeinsamen Motion‑System: drei Feder‑Geschwindigkeiten, ein Hover‑Highlight, das zum dem Cursor am nächsten liegenden Element gleitet, Labels, die ihr Gewicht ändern, ohne das Layout zu verschieben. Verwende es immer, wenn der Nutzer Fluid Functionalism, @fluid oder fluidfunctionalism.com erwähnt, nach einer UI mit befriedigender/flüssiger/polierter Animation in einem React-, Next.js-, shadcn-, Radix‑ oder Base‑UI‑Projekt fragt, irgendeine Oberfläche (Einstellungsdialoge, Seitenleisten, Befehlsmenüs, Chat‑UIs, Formulare, Listen, Tabellen) in einem Projekt mit installierten @fluid‑Komponenten erstellt oder um eine Überprüfung/Audit der bestehenden UI‑Animation gegenüber dem System bittet. Nutze es außerdem, bevor du Animationscode von Hand schreibst (Hover‑Highlights, Icon‑Austausch, Gewichtänderungen, Ein‑/Austritts‑Transitionen), damit benutzerdefinierter Code dem System folgt, anstatt eigene Timings zu erfinden. Bei jedem Durchlauf liest ein gebündeltes Skript den Stack frisch ein (Abhängigkeiten, Radix‑ vs. Base‑UI‑Variante, MotionConfig, Inter‑Opsz‑Achse), sodass die Fähigkeit keine Audit‑Datei im Projekt hinterlässt.
