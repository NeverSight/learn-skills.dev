PikPak 클라우드 드라이브 공간 상태 보고서 생성: 총 용량/사용량/휴지통 사용량, 폴더 크기 순위, 대용량 파일 목록, 예상 정리 가능한 공간. 읽기 전용 분석이며 삭제는 수행되지 않습니다.

다음과 같은 경우에 이 기능을 사용해야 합니다:
- 사용자가 “내 클라우드 드라이브에서 얼마나 사용했나요?” “공간 부족” “어떤 파일이 공간을 차지하고 있나요?” 라고 물을 때
- 사용자가 공간을 정리하고 싶지만 시작점이 없을 때
- 사용자가 “공간 상태 점검” “용량 보고서” “대용량 파일 순위” 라고 말할 때
- 사용자가 “얼마나 사용했나요”, “스토리지 가득 찼음”, “무엇이 공간을 차지하고 있나요”, “가장 큰 파일” 등을 물을 때
