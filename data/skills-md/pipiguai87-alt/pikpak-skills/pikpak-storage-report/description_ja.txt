PikPakクラウドドライブの容量ヘルスチェックレポートを作成します：総容量 / 使用量 / ごみ箱の使用状況、フォルダーサイズランキング、最大ファイル一覧、推定クリーン可能容量。読み取り専用の分析で、削除は行いません。

このスキルは次の場合に使用してください：
- ユーザーが「クラウドドライブでどれだけの容量を使用したか？」、「容量が足りない。」、「どのファイルが容量を占めているか？」と尋ねたとき
- ユーザーが容量を整理したいが、どこから手を付ければよいか分からないとき
- ユーザーが「容量ヘルスチェック」や「容量レポート」や「大きなファイルランキング」と言ったとき
- ユーザーが「どれだけ容量が使われているか」や「ストレージがいっぱい」や「何が容量を占めているか」や「最大ファイル」と尋ねたとき

キーワード：スペース / 容量 / ストレージ / 大きなファイル / 容量のクリーンアップ / ストレージ

常にユーザーの言語で回答してください。  
常にユーザーの言語で応答してください。
