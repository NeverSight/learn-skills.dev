Générez un rapport d’état de l’espace de stockage du cloud PikPak : capacité totale / utilisée / utilisation de la corbeille, classement des dossiers par taille, liste des plus gros fichiers, espace estimé récupérable. Analyse en lecture seule, aucune suppression n’est effectuée.

Utilisez cette compétence lorsque :
- L’utilisateur demande « Quelle est la quantité d’espace utilisée par mon cloud ? », « Je n’ai pas assez d’espace », « Quels fichiers occupent de l’espace ? »
- L’utilisateur veut libérer de l’espace mais ne sait pas par où commencer
- L’utilisateur mentionne « vérification de santé de l’espace », « rapport de capacité », « classement des gros fichiers »
- L’utilisateur demande « combien d’espace », « stockage plein », « qu’est‑ce qui occupe de l’espace », « les plus gros fichiers »
- Mots‑clés : espace / capacité / stockage / gros fichiers / nettoyer l’espace / stockage

Veuillez toujours répondre dans la langue de l’utilisateur.
