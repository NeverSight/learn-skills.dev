Revisiona una PR come un tour guidato, in un ordine di lettura sensato. Trasforma una pull request in un tour di lettura guidato — l'intento dell'autore, quali file tale intento spiega e quali no, e le affermazioni verificabili per prime, poi dove guardare e perché (fatti calcolati dallo script più riferimenti controllati riga per riga), quindi i file nell'ordine che un revisore dovrebbe leggerli, con ogni test accanto al suo codice, e il rumore (file di lock, file generati, rinominazioni, formattazione) compattato alla fine — resa come una singola pagina HTML autocontenuta più JSON che gli agenti possono leggere. Non le PR impilate di GitHub. Usa quando l'utente chiede di revisionare, attraversare, spiegare o comprendere una PR o un diff, chiede cosa leggere per primo o a cosa prestare attenzione in una PR, o menziona tour della PR o ordine di lettura.
