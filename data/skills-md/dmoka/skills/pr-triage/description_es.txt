Triar PRs abiertos: cuáles necesitan atención primero y por qué. Lea cada pull request abierto en un repositorio, juzgue cuánta atención de revisor requiere cada uno (crítico, alto, medio, bajo) a partir de lo que realmente hace el cambio, y ordene la cola de mayor a menor atención — cada juicio apuntando a la línea que lo motiva, cada PR enlazado a un recorrido completo de lectura. Genera una cola HTML autocontenida más JSON para agentes. Úselo cuando el usuario pregunte cuál PR revisar primero, qué necesita atención en la cola de PR, tenga demasiados PR abiertos, o mencione triage de PR, backlog de revisión o prioridad de revisión.
