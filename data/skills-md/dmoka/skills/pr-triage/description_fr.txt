Triage des PR ouvertes : lesquelles nécessitent d’abord de l’attention, et pourquoi. Lire chaque pull request ouverte dans un dépôt, juger de la quantité d’attention requise par le relecteur pour chacune (critique, haute, moyenne, basse) en fonction de ce que le changement effectue réellement, et ordonner la file d’attente du plus d’attention au premier — chaque jugement pointant sur la ligne qui le motive, chaque PR liée à un parcours de lecture complet. Génère une file d’attente HTML autonome ainsi qu’un JSON pour les agents. À utiliser lorsque l’utilisateur demande quelle PR réviser en premier, ce qui nécessite de l’attention dans la file d’attente des PR, qu’il a trop de PR ouvertes, ou mentionne le triage des PR, le backlog de revues, ou la priorité des revues.
