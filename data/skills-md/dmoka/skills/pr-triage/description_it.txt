Triaggo delle PR aperte: quali necessitano di attenzione per prime e perché. Leggi ogni pull request aperto in un repository, valuta quanta attenzione del revisore richiede ciascuno (critica, alta, media, bassa) in base a ciò che la modifica effettua, e ordina la coda dal più necessario — ogni giudizio punta alla riga che lo genera, ogni PR è collegata a un tour di lettura completo. Genera una coda HTML autonoma più JSON per gli agenti. Usa quando l’utente chiede quale PR revisionare per prima, cosa necessita di attenzione nella coda delle PR, ha troppe PR aperte, o menziona triage delle PR, backlog di revisione o priorità di revisione.
