Testare il codice legacy: valutare prima, poi proporre un piano. Da usare quando una base di codice o un modulo ha pochi o nessun test e devi modificarlo in sicurezza: aggiungere test al codice non testato, ottenere una rete di sicurezza prima di un refactoring, prendere in carico codice che non hai scritto. Analizza lo stack, le dipendenze e il codice che nessun test tocca, propone quali passaggi necessita il repository (renderlo testabile, caratterizzare, approvare, test di proprietà che cercano crash in ogni punto di ingresso, misurare, refactoring per ultimo), attende l’approvazione una volta, poi esegue ogni passaggio approvato senza interruzioni.
