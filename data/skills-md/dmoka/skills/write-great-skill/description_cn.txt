编写或改进代理技能（SKILL.md + 脚本）。在以下情况使用：有人想创建、编写、构建或草拟一个技能；将清单、运行手册、流程、操作指南或他们不断重复的提示转化为技能或斜杠指令；让代理每次都以相同方式执行任务；或修复未触发、触发时间错误或每次运行结果不同的技能。首先进行访谈（触发条件、用户知道而模型不知道的内容、绝对不能发生的情况、哪些步骤是机械的），草拟文件夹（简短的 SKILL.md、用于机械步骤的 scripts/、按需阅读的 references/），用脚本检查，然后与用户一起润色。适用于 Claude Code、Codex、Cursor、Hermes 以及任何 Agent Skills 工具。

请始终使用用户的语言回复。
