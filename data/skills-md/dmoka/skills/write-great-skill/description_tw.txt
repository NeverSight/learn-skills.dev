撰寫或改進代理技能（SKILL.md + 腳本）。在以下情況使用：有人想要建立、撰寫、建構或草擬一個技能；將檢查清單、執行手冊、流程、操作說明或他們不斷重複的提示轉換成技能或斜線指令；讓代理每次以相同方式執行任務；或修復未觸發、觸發時機錯誤、每次執行結果不同的技能。先進行訪談（觸發條件、使用者知道而模型不知道的資訊、絕對不能發生的情況、哪些步驟是機械化的），草擬資料夾（簡短的 SKILL.md、scripts/ 用於機械化步驟、references/ 依需求閱讀），使用腳本檢查，然後與使用者一起精修。適用於 Claude Code、Codex、Cursor、Hermes 以及任何 Agent Skills 工具。

請始終以使用者的語言回覆。
