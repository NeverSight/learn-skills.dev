Scrivi o migliora una skill per agente (SKILL.md + script). Usala quando qualcuno vuole creare, scrivere, costruire o abbozzare una skill; trasformare una checklist, un runbook, una procedura, una guida o un prompt che ripete continuamente in una skill o comando slash; far fare all'agente un compito nello stesso modo ogni volta; o correggere una skill che non si attiva, si attiva al momento sbagliato o funziona diversamente ad ogni esecuzione. Prima si conducono interviste (il trigger, ciò che l'utente sa e che nessun modello conosce, cosa non deve mai accadere, quali passaggi sono meccanici), si prepara la cartella (un breve SKILL.md, scripts/ per i passaggi meccanici, references/ da leggere su richiesta), la si verifica con uno script, poi la si cura insieme all'utente. Funziona per Claude Code, Codex, Cursor, Hermes e qualsiasi strumento di Agent Skills.
