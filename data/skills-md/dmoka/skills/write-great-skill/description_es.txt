Escribe o mejora una habilidad de agente (SKILL.md + scripts). Úsala cuando alguien quiera crear, redactar, construir o esbozar una habilidad; convertir una lista de verificación, runbook, procedimiento, tutorial o prompt que repite en una habilidad o comando slash; hacer que el agente realice una tarea de la misma manera cada vez; o arreglar una habilidad que no se dispara, se dispara en el momento equivocado o funciona de forma distinta en cada ejecución. Primero se realizan entrevistas (el disparador, lo que el usuario sabe y que ningún modelo conoce, lo que nunca debe ocurrir, qué pasos son mecánicos), se redacta la carpeta (un breve SKILL.md, scripts/ para los pasos mecánicos, references/ para consultar bajo demanda), se verifica con un script y luego se cura con el usuario. Funciona para Claude Code, Codex, Cursor, Hermes y cualquier herramienta de habilidades de agentes.
