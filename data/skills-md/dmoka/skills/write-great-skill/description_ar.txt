اكتب أو حسّن مهارة وكيل (SKILL.md + السكريبتات). استخدمها عندما يرغب أحد في إنشاء أو كتابة أو بناء أو صياغة مهارة؛ تحويل قائمة مراجعة أو دليل تشغيل أو إجراء أو دليل “كيف تفعل” أو موجه يكرره المستخدم باستمرار إلى مهارة أو أمر ش slash؛ جعل الوكيل يقوم بالمهمة بنفس الطريقة في كل مرة؛ أو إصلاح مهارة لا تنشط، أو تنشط في الوقت الخطأ، أو تُنفّذ بشكل مختلف في كل تشغيل. ابدأ بإجراء مقابلات (تحديد المشغّل، ما يعرفه المستخدم ولا يعرفه أي نموذج، ما يجب ألا يحدث أبدًا، أي خطوات ميكانيكية)، ثم صغ المجلد (ملف SKILL.md مختصر، scripts/ للخطوات الميكانيكية، references/ للقراءة عند الطلب)، تحقّق منه باستخدام سكريبت، ثم صقّله مع المستخدم. يعمل مع Claude Code وCodex وCursor وHermes وأي أداة مهارات وكيل.
