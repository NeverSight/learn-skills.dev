Write or improve an agent skill (SKILL.md + scripts). Use when someone wants to create, write, build or draft a skill; turn a checklist, runbook, procedure, how-to or a prompt they keep repeating into a skill or slash command; make the agent do a task the same way every time; or fix a skill that does not fire, fires at the wrong time, or runs differently each run. Interviews first (the trigger, what the user knows that no model knows, what must never happen, which steps are mechanical), drafts the folder (a short SKILL.md, scripts/ for the mechanical steps, references/ read on demand), checks it with a script, then curates it with the user. Works for Claude Code, Codex, Cursor, Hermes and any Agent Skills tool.
