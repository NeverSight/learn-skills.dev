Attaquez une PR ou une suite verte avec un agent neuf pour la faire échouer. Utilisez-le lorsqu’on vous demande de « review this PR » avant une fusion, « attack this PR », « find what is wrong with this change », ou sur une suite de tests verte avant de lui faire confiance, en particulier du code généré par IA avec des tests écrits par IA. Transmet le briefing ci‑dessous à un agent séparé avec son propre contexte, afin qu’il ne partage pas les angles morts de l’auteur. Vérifie la modification par rapport aux critères d’acceptation que vous fournissez et aux fichiers CLAUDE.md ou AGENTS.md du dépôt. Prouve chaque constat avec un test qui échoue lorsque c’est possible ; signale le reste comme constats raisonnés (fichier :ligne et l’argument), étiquetés afin qu’ils ne soient jamais confondus avec des constats prouvés. Donne un verdict de fusion, ne corrige rien. Fonctionne dans n’importe quel cadre (un sous‑agent Claude Code, Hermes delegate_task).
