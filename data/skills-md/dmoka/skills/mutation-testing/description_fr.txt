Mutation-test un dépôt : trouvez les tests qui laisseraient passer des bugs. Mesurez la qualité des tests avec le test de mutation et comblez les lacunes qu’il détecte. Utilisez‑le lorsqu’on vous demande si les tests sont bons, lorsque la couverture est élevée mais la confiance est faible, après qu’une IA a écrit ou modifié des tests, ou lorsque l’utilisateur mentionne le test de mutation, le score de mutation, les mutants survivants, ou cite un outil de mutation (Stryker, Pitest, mutmut, Infection, cargo‑mutants).

Veuillez toujours répondre dans la langue de l’utilisateur.
