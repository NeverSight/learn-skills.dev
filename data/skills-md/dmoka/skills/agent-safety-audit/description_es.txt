Audita una configuración de agente de IA: ¿puede un correo electrónico filtrar tus datos? Úsalo cuando alguien pregunte si su agente es seguro, antes de dejar que un agente se ejecute sin supervisión, o después de agregar un conector, servidor MCP, herramienta, token, buzón, webhook o regla de red. Funciona en un repositorio Claude Code (configuraciones, hooks, devcontainer), una rutina Claude Code, una instalación Hermes o un agente en GitHub Actions. Verifica la tríada letal (datos privados, entrada no confiable, una vía de escape), nombra la configuración exacta que abre cada rama y propone la rama más barata de cortar. Solo lectura: informa, no cambia nada.
