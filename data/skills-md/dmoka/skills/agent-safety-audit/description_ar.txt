تدقيق إعداد وكيل الذكاء الاصطناعي: هل يمكن لرسالة بريد إلكتروني واحدة أن تُسرب بياناتك؟ استخدمه عندما يسأل أحدهم ما إذا كان وكيله آمنًا، قبل السماح للوكيل بالعمل دون مراقبة، أو بعد إضافة موصل، خادم MCP، أداة، رمز مميز، صندوق بريد، ويب هوك أو قاعدة شبكة. يعمل على مستودع Claude Code (الإعدادات، الخطاطيف، حاوية التطوير)، روتين Claude Code، تثبيت Hermes، أو وكيل في GitHub Actions. يتحقق من الثلاثية القاتلة (البيانات الخاصة، المدخل غير الموثوق، وسيلة للخروج)، يحدد الإعداد الدقيق الذي يفتح كل طرف، ويقترح أرخص طرف يمكن قطعه. للقراءة فقط: هو يبلّغ ولا يغيّر شيئًا.
