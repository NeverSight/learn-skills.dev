Audit d’une configuration d’agent IA : un seul e‑mail peut‑il fuir vos données ? Utilisez‑le lorsqu’on vous demande si votre agent est sûr, avant de laisser un agent fonctionner sans surveillance, ou après avoir ajouté un connecteur, un serveur MCP, un outil, un jeton, une boîte de réception, un webhook ou une règle réseau. Fonctionne sur un dépôt Claude Code (paramètres, hooks, devcontainer), une routine Claude Code, une installation Hermes ou un agent dans GitHub Actions. Vérifie la trifecta mortelle (données privées, entrée non fiable, fuite), indique la configuration exacte qui ouvre chaque maillon, et propose le maillon le moins coûteux à couper. Lecture seule : il rapporte, il ne modifie rien.

Veuillez toujours répondre dans la langue de l’utilisateur.
