Проверьте настройку ИИ‑агента: может ли одно письмо раскрыть ваши данные? Используйте, когда кто‑то спрашивает, безопасен ли их агент, перед тем как позволять агенту работать без присмотра, или после добавления коннектора, сервера MCP, инструмента, токена, почтового ящика, веб‑хука или правила сети. Работает с репозиторием Claude Code (settings, hooks, devcontainer), процедурой Claude Code, установкой Hermes или агентом в GitHub Actions. Проверяет смертельную триаду (конфиденциальные данные, недоверенный ввод, путь выхода), указывает точную конфигурацию, открывающую каждый из аспектов, и предлагает наименее затратный вариант устранения. Только для чтения: он лишь сообщает, ничего не меняет.
