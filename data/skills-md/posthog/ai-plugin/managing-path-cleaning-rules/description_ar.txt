يفحص مسارات URL ويقترح، يختبر، يرتب، ويطبق قواعد تنظيف المسار على مستوى المشروع بحيث تتحول الأقسام الديناميكية (معرفات رقمية، UUIDs، سلاسل نصية، تواريخ) إلى مستعارات قابلة للقراءة. يُستَخدم عندما يقول المستخدم “clean the paths”، “normalize URLs”، “group similar pages”، “too many distinct paths”، “/users/123 and /users/456 are the same page”، “set up path cleaning”، أو يسأل لماذا تحليل الويب أو تقسيم المسارات متفرّق عبر آلاف الروابط المتشابهة تقريبًا. يغطي صياغة regex (re2)، اتفاقية عنصر نائب للمستعار، ترتيب القواعد، سير عمل الاختبار، وتطبيق القواعد عبر أداة path‑cleaning‑rules‑update في MCP.
