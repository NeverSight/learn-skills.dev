Inspecciona rutas URL y propone, prueba, ordena y aplica reglas de limpieza de rutas a nivel de proyecto para que los segmentos dinámicos (IDs numéricos, UUIDs, slugs, fechas) se conviertan en alias legibles. Úsalo cuando el usuario diga "clean the paths", "normalize URLs", "group similar pages", "too many distinct paths", "/users/123 and /users/456 are the same page", "set up path cleaning", o pregunte por qué un análisis web o un desglose de rutas está fragmentado en miles de URLs casi idénticas. Cubre la sintaxis de regex (re2), la convención de marcadores de posición para alias, el orden de las reglas, el flujo de pruebas y la aplicación de reglas mediante la herramienta MCP path-cleaning-rules-update.
