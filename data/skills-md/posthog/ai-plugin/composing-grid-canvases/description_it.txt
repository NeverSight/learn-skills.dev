Compila le griglie canvas di PostHog — griglie di widget (inclusa la canvas home dell'utente) costruite a partire da canvas di componenti riutilizzabili. Usalo quando un compito richiede di aggiungere, riempire, spostare, ridimensionare o rimuovere un widget su una griglia o sulla canvas home, per comporre un'intera canvas di widget da una singola richiesta, per costruire un widget/componente riutilizzabile, o quando un ID di posizionamento o un ID di canvas griglia è il bersaglio. Copre la ricerca nel negozio dei componenti → configurazione → fork → costruzione della scala, il contratto di posizionamento del componente (dimensione, configSchema), il ciclo di vita del posizionamento (in attesa/generazione/in uso/fallito), il loop di patch del layout protetto e la lettura dei thread di commenti della canvas.
