Componga lienzos de cuadrícula PostHog — cuadrículas de widgets (incluido el lienzo de inicio del usuario) construidas a partir de lienzos de componentes reutilizables. Úselo cuando una tarea solicite agregar, rellenar, mover, redimensionar o eliminar un widget en una cuadrícula o lienzo de inicio, para componer un lienzo completo de widgets a partir de una sola solicitud, para construir un widget/componente reutilizable, o cuando un ID de colocación o un ID de lienzo de cuadrícula sea el objetivo. Cubre la búsqueda en la tienda de componentes → configuración → bifurcación → escalera de construcción, el contrato de colocación del componente (tamaño, configSchema), el ciclo de vida de la colocación (pendiente/generando/en vivo/fallido), el bucle protegido de parcheo de diseño y la lectura de los hilos de comentarios del lienzo.
