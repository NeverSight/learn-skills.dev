Compose PostHog 그리드 캔버스 — 재사용 가능한 컴포넌트 캔버스로부터 구축된 위젯 그리드(사용자 홈 캔버스 포함). 작업이 그리드 또는 홈 캔버스에 위젯을 추가, 채우기, 이동, 크기 조정, 또는 삭제하도록 요구할 때, 하나의 요청으로 전체 위젯 캔버스를 구성할 때, 재사용 가능한 위젯/컴포넌트를 만들 때, 또는 배치 ID나 그리드 캔버스 ID가 대상일 때 사용합니다. 컴포넌트 스토어 검색 → 구성 → 포크 → 빌드 단계, 컴포넌트 배치 계약(크기, configSchema), 배치 생명 주기(대기 중/생성 중/실행 중/실패), 보호된 레이아웃 패치 루프, 그리고 캔버스의 댓글 스레드 읽기를 포함합니다.
