PostHog のグリッドキャンバスを作成する — 再利用可能なコンポーネントキャンバスから構築されたウィジェットグリッド（ユーザーのホームキャンバスを含む）。タスクがグリッドまたはホームキャンバス上のウィジェットの追加、埋め込み、移動、リサイズ、削除を要求する場合、1 つの要請でウィジェット全体のキャンバスを構成する場合、再利用可能なウィジェット／コンポーネントを作成する場合、または配置 ID やグリッドキャンバス ID が対象となる場合に使用します。コンポーネントストアの検索 → 設定 → フォーク → ビルドの流れ、コンポーネント配置契約（サイズ、configSchema）、配置ライフサイクル（pending／generating／live／failed）、ガード付きレイアウトパッチループ、そしてキャンバスのコメントスレッドの読み取りをカバーします。
