Utilisez PostHog Autoresearch, des modèles prédictifs pilotés par agents : demandez « qui fera X dans les N prochains jours ? », laissez un agent entraîner un modèle, puis attribuez quotidiennement un score aux personnes sous forme de propriété d’utilisateur et d’événements `autoresearch_prediction`. Utilisez-le lorsqu’un utilisateur veut prédire le churn, l’activité, le retour, l’adoption de fonctionnalités, la conversion ou tout événement ou action par personne ; créez ou validez un modèle à partir d’un modèle‑type ; lancez l’entraînement ou le scoring immédiatement ; consultez la qualité du modèle (holdout vs AUC réalisée, lift, calibration, segments de vraisemblance, couverture) ; orientez l’entraînement avec des suggestions ; agissez sur les prédictions avec des cohortes, des feature flags, des workflows ou du SQL ; ou diagnostiquez un modèle qui ne s’entraîne pas, qui donne le même score à tout le monde ou qui cesse de scorer. Déclenchez sur « autoresearch », « modèle prédictif », « score de propension », « prédiction de churn », « susceptible de convertir », « qui fera X », « predicted_p_ », « autoresearch_prediction », « AUC réalisée », « modèle champion ».
