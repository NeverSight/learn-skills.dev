Les critères de validation pour PostHog Review, le seuil permettant de décider si un problème de PR signalé mérite d'être conservé. Conserve les vrais problèmes de correction, de sécurité, de perte de données, de contrat ou de performance qui affectent les utilisateurs ; élimine la sur‑ingénierie, les spéculations, la paranoïa, les cas limites improbables et le style.
