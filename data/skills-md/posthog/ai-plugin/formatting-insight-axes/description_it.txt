Scegli l'unità corretta per l'asse y quando crei o aggiorni un insight tramite `posthog:insight-create` o `posthog:insight-update` — sia per TrendsQuery (`trendsFilter.aggregationAxisFormat`) sia per gli insight SQL (`DataVisualizationNode`, `chartSettings.yAxis[].settings.formatting`). Utilizza quando l'agente sta per aggiungere una `formula` esclusivamente per convertire le unità (ad esempio dividere i secondi per 60 per visualizzare i minuti), quando un `math_property` o una colonna SQL è una durata, una valuta, un rapporto o un conteggio elevato, o ogni volta che l'utente menziona “formatta l'asse y”, “durata”, “secondi”, “minuti”, “ore”, “millisecondi”, “ms”, “percentuale”, “%%”, “valuta”, “decimali”, “etichetta dell'asse” o “unità dell'asse” nel contesto di un insight grafico.
