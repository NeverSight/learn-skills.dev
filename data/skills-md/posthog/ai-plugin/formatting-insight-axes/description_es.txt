Elija la unidad correcta del eje Y al crear o actualizar una visión mediante `posthog:insight-create` o `posthog:insight-update` — tanto TrendsQuery (`trendsFilter.aggregationAxisFormat`) como las visiones SQL (`DataVisualizationNode`, `chartSettings.yAxis[].settings.formatting`). Úselo cuando el agente esté a punto de agregar una `formula` únicamente para convertir unidades (p. ej., dividir segundos entre 60 para mostrar minutos), cuando una `math_property` o una columna SQL sea una duración, moneda, razón o un recuento grande, o siempre que el usuario mencione “formatear el eje y”, “duración”, “segundos”, “minutos”, “horas”, “milisegundos”, “ms”, “porcentaje”, “%%”, “moneda”, “decimales”, “etiqueta del eje” o “unidad del eje” en el contexto de una visión gráfica.
