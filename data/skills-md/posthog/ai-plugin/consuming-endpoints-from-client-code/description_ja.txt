PostHog のエンドポイントをクライアントアプリや SDK に組み込む。OpenAPI 仕様の取得、openapi-generator または @hey-api/openapi-ts を使った型付きクライアントの生成、正しい認証ヘッダーの送信、変数ペイロードの整形（HogQL の code_name とインサイトのブレークダウンプロパティの違い）と、レートリミットや materialised‑endpoint エラー応答の処理をカバーします。ユーザーが「エンドポイントを呼び出す方法は？」、「これのクライアントを生成して」または「どの認証ヘッダーを使うべきか」と言ったときに使用してください。
