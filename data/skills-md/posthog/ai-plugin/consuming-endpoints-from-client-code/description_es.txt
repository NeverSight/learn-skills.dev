Conecta un endpoint de PostHog en una aplicación cliente o SDK. Incluye obtener la especificación OpenAPI, generar un cliente tipado con openapi-generator o @hey-api/openapi-ts, enviar el encabezado de autenticación correcto, estructurar la carga de variables (code_name de HogQL vs propiedad de desglose de insight), y manejar respuestas de error por límite de velocidad y endpoint materializado. Úsalo cuando el usuario diga “¿cómo llamo a mi endpoint?”, “generar un cliente para esto” o “¿qué encabezado de autenticación debo usar?”.
