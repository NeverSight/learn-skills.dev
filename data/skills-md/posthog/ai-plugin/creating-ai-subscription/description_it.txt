Crea un report PostHog generato dall'IA ricorrente — programma un prompt di testo libero da eseguire con un cron, con il markdown sintetizzato dal LLM consegnato via email, Slack o Microsoft Teams ad ogni ciclo. Usalo quando l'utente vuole un riepilogo IA ricorrente di X con qualsiasi cadenza (giornaliera, settimanale, mensile, annuale) anziché un report una tantum. (Per allegare un riepilogo IA a una sottoscrizione di insight/dashboard esistente invece di un prompt di testo libero, vedi `managing-subscriptions` e la sua opzione `summary_enabled`.)
