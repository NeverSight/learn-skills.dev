Erstelle einen wiederkehrenden KI-generierten PostHog-Bericht – plane einen Freitext‑Prompt, der in einem Cron ausgeführt wird, wobei das von einem LLM synthesierte Markdown bei jedem Durchlauf per E‑Mail, Slack oder Microsoft Teams zugestellt wird. Verwende dies, wenn der Nutzer eine wiederkehrende KI‑Zusammenfassung von X in beliebigem Intervall (täglich, wöchentlich, monatlich, jährlich) statt eines einmaligen Berichts möchte. (Um einer bestehenden Insight/Dashboard‑Abonnements ein KI‑Zusammenfassung anstelle eines Freitext‑Prompts hinzuzufügen, siehe `managing-subscriptions` und die Option `summary_enabled`.)
