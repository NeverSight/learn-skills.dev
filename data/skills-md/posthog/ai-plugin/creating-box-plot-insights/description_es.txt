Crea análisis de producto o insights de gráficos de caja respaldados por SQL en PostHog. Úsalo cuando un usuario solicite crear, construir o guardar un gráfico de caja, visualizar una distribución numérica, comparar cuartiles o medianas a lo largo de fechas o grupos, o convertir resultados SQL en un gráfico de caja. Elige entre un gráfico de caja estándar de Tendencias y un insight SQL, valida los datos de distribución, guarda el insight y lo verifica.
