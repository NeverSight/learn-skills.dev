ينشئ تحليلات المنتج أو رؤى مخطط الصندوق المدعومة بـ SQL في PostHog. يُستخدم عندما يطلب المستخدم إنشاء أو بناء أو حفظ مخطط صندوق، أو تصور توزيع رقمي، أو مقارنة الأرباع أو المتوسطات عبر التواريخ أو المجموعات، أو تحويل نتائج SQL إلى مخطط صندوق. يختار بين مخطط صندوق Trends القياسي ورؤية SQL، يتحقق من صحة بيانات التوزيع، يحفظ الرؤية، ويتأكد منها.
