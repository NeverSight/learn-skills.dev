Guide l'utilisateur dans la connexion d'une nouvelle source d'entrepôt de données — Postgres, MySQL, Stripe, Hubspot, MongoDB, Salesforce, BigQuery, Snowflake, etc. Utilisez‑le lorsque l'utilisateur veut « connecter Stripe », « importer des données depuis Postgres », « ajouter une nouvelle source de données », « synchroniser mes tables d'entrepôt » ou choisir les méthodes de synchronisation pour chaque table. Parcourt la découverte du type de source, la validation des identifiants, la découverte des tables, la sélection du type de synchronisation par table, puis l’appel final de création. Couvre également le choix d’un bon préfixe et les actions à entreprendre immédiatement après la création.
