Créez, déployez et exploitez des applications Streamlit dans PostHog via les outils MCP streamlit‑apps — créez une application, définissez sa source, démarrez et arrêtez son bac à sable, interrogez le statut, listez les versions, supprimez‑la et partagez l'application avec les humains via son URL PostHog. Utilisez‑le lorsqu’on vous demande « créer une application streamlit », « déployer une application de données », « livrer une application de tableau de bord », « redémarrer/arrêter mon application », « pourquoi mon application ne fonctionne pas » ou « donnez‑moi un lien vers l’application ».

Veuillez toujours répondre dans la langue de l'utilisateur.
