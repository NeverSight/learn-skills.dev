Diagnostique pourquoi un enregistrement de session est absent ou n’a pas été capturé. À utiliser lorsqu’un utilisateur demande pourquoi une session n’a pas de relecture, pourquoi les enregistrements n’apparaissent pas, ou veut résoudre les problèmes de capture de relecture de session pour un ID de session spécifique ou à l’échelle de son projet. Couvre les signaux de diagnostic du SDK, les paramètres du projet, l’échantillonnage, les déclencheurs, les bloqueurs de publicité et les scénarios de quota/facturation.
