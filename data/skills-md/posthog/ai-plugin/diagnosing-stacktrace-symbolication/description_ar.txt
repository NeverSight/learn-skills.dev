مساعدة المستخدمين على تصحيح تتبع الأخطاء في PostHog عبر ترميز تتبع المكدس لأي منصة مدعومة — JavaScript/TypeScript للويب، React Native (Hermes)، Android (Proguard / R8)، أو iOS / macOS (dSYM). تدفق البحث عن مجموعة الرموز في PostHog عالمي عبر جميع المنصات؛ تفاصيل أدوات البناء والقطع الحية موجودة في مراجع كل منصة (JavaScript مفصلة، والبقية تُضاف مع التعرف عليها). استخدم هذا عندما تظل إطارات المكدس مصغرة أو مشوشة بعد تحميل الرموز، وتظهر مجموعات رموز PostHog قيمة last_used ولكن الإطارات غير قابلة للقراءة، أو لا تتطابق معرفات القطع أو UUIDs الخاصة بـ dSYM، أو يظهر "Token not found"، أو تبدو خرائط المصدر / dSYMs / تحويلات Proguard التي تم تحميلها فارغة، أو تحتاج إعدادات أداة التجميع / تحميل الرموز إلى استكشاف الأخطاء وإصلاحها.
