Aiuta gli utenti a fare il debug della simbolizzazione dei trace di errore di PostHog per qualsiasi piattaforma supportata — web JavaScript/TypeScript, React Native (Hermes), Android (Proguard / R8) o iOS / macOS (dSYM). Il flusso di ricerca del set di simboli di PostHog è universale su tutte le piattaforme; i dettagli dello strumento di build e degli artefatti sono disponibili nei riferimenti per piattaforma (JavaScript è completato, gli altri verranno aggiunti man mano che li incontriamo). Usalo quando i frame dello stack rimangono minificati o offuscati dopo il caricamento dei simboli, i set di simboli di PostHog mostrano last_used ma i frame non sono leggibili, gli ID dei chunk o gli UUID dSYM non corrispondono, appare “Token not found”, le source map / dSYM / mapping Proguard caricate sembrano vuote, o la configurazione del bundler / del caricamento dei simboli necessita di risoluzione dei problemi.
