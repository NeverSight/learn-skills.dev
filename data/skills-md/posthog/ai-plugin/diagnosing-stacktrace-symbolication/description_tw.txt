協助使用者除錯 PostHog 錯誤追蹤的堆疊追蹤符號化（symbolication），支援的所有平台包括 JavaScript/TypeScript 網頁、React Native（Hermes）、Android（Proguard / R8）以及 iOS / macOS（dSYM）。PostHog 符號集合查詢流程在各平台之間是通用的；建置工具與產出物的細節則放在各平台的參考文件中（JavaScript 已完整說明，其他平台會隨著需求逐步補齊）。在以下情況請使用本說明：堆疊框架在上傳符號後仍然被最小化或混淆、PostHog 符號集合顯示 last_used 但框架內容不可讀、Chunk ID 或 dSYM UUID 不匹配、出現「Token not found」訊息、上傳的 source map / dSYM / Proguard 映射檔看起來是空的，或是需要排查 bundler / 符號上傳設定問題。
