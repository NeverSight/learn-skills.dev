Помогайте пользователям отлаживать символизацию трассировки стека в системе отслеживания ошибок PostHog для любой поддерживаемой платформы — веб JavaScript/TypeScript, React Native (Hermes), Android (Proguard / R8) или iOS / macOS (dSYM). Процесс поиска наборов символов PostHog универсален для всех платформ; детали инструментов сборки и артефактов находятся в справочных материалах для каждой платформы (JavaScript полностью описан, остальные добавляются по мере появления). Используйте, когда кадры стека остаются минифицированными или обфусцированными после загрузки символов, наборы символов PostHog показывают last_used, но кадры не читаются, идентификаторы чанков или UUID dSYM не совпадают, появляется сообщение «Token not found», загруженные source‑map’ы / dSYM’ы / карты Proguard выглядят пустыми, либо требуется устранение проблем в конфигурации бандлера / загрузки символов.
