Alimente et maintient le catalogue de données d’un projet (couche sémantique) : métriques canoniques, marques de confiance (certifications) sur les tables/vues de l’entrepôt, et relations de tables examinées. À utiliser lorsqu’on demande de configurer / initialiser / amorcer le catalogue de données ou la couche sémantique, de cataloguer les métriques d’un projet, de certifier ou de déprécier les sources de données, de proposer ou de réviser des jointures de tables, ou de traiter la file d’attente de révision des propositions. Pour *utiliser* un catalogue existant afin de répondre à une question chiffrée d’affaires, voir plutôt querying‑posthog‑data. Termes déclencheurs : catalogue de données, couche sémantique, métrique canonique, certifier une table, déprécier une source, proposition de relation, dérive de métrique, file d’attente de révision.
