Aggiunge ed esegue controlli di qualità dei dati (asserzioni in stile dbt‑test) sulle tabelle del magazzino di un progetto e sulle viste di query salvate, nonché sulle metriche del catalogo HogQL: non‑null, unicità, valori accettati, integrità referenziale, limiti del conteggio delle righe, freschezza e HogQL personalizzato. Le metriche supportano solo controlli SQL personalizzati. Usalo quando ti viene chiesto di testare un modello, convalidare una vista, verificare la presenza di null o duplicati, aggiungere controlli di qualità dei dati, scoprire perché un numero sembra errato o giudicare se una tabella del magazzino è affidabile prima di usarla in un’analisi. Per descrivere cosa *significa* i dati (metriche, certificazioni, join), vedi “setting‑up‑data‑catalog”. Termini di attivazione: data quality, data test, dbt test, not null check, uniqueness check, freshness check, referential integrity, row count check, validate model, is this table trustworthy.
