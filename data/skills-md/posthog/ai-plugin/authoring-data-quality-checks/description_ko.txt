프로젝트의 데이터웨어하우스 테이블 및 저장된 쿼리 뷰에 데이터 품질 검사(dbt‑test 스타일 어설션)를 추가하고 실행하며, HogQL 카탈로그 메트릭을 적용합니다: NOT NULL, 유일성, 허용값, 참조 무결성, 행 수 범위, 최신성, 그리고 맞춤형 HogQL. 메트릭은 맞춤 SQL 검사만 지원합니다. 모델을 테스트하거나, 뷰를 검증하거나, NULL 또는 중복을 확인하거나, 데이터 품질 검사를 추가하거나, 수치가 이상하게 보이는 원인을 파악하거나, 분석에 사용하기 전에 데이터웨어하우스 테이블이 신뢰할 수 있는지 판단할 때 사용합니다. 데이터가 무엇을 의미하는지(메트릭, 인증, 조인)를 설명하려면 “setting‑up‑data‑catalog”를 참조하십시오. 트리거 용어: 데이터 품질, 데이터 테스트, dbt 테스트, NOT NULL 검사, 유일성 검사, 최신성 검사, 참조 무결성, 행 수 검사, 모델 검증, 이 테이블은 신뢰할 수 있는가.
