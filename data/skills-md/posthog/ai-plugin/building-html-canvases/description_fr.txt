Rédigez un canvas PostHog avec du HTML sémantique, du CSS et les API directes du navigateur — documents, articles, graphiques génératifs, expériences canvas 2D et WebGL, ainsi que des expériences ciblées où les composants React n’ajoutent aucune structure utile. Utilisez‑le après que building‑canvases a redirigé une requête de canvas vers une implémentation HTML simple/API du navigateur. Cela couvre l’enveloppe de composant légère requise par le runtime actuel, le style et le thématisme sans Quill, les surfaces de dessin, ainsi que les schémas d’animation et de nettoyage.
