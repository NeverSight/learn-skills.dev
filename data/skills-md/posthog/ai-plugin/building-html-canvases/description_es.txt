Autoriza un lienzo de PostHog con HTML semántico, CSS y API directas del navegador — documentos, artículos, gráficos generativos, experiencias de canvas 2D y WebGL, y experimentos focalizados donde los componentes de React no añaden una estructura útil. Usa después de que building-canvases haya dirigido una solicitud de lienzo a una implementación de HTML plano/API del navegador. Cubre el delgado contenedor de componentes que el tiempo de ejecución actual requiere, estilo y tematización sin Quill, superficies de dibujo y patrones de animación/limpieza.
