Verbinde eine beliebige REST‑API mit dem PostHog‑Datenlager als benutzerdefinierte Quelle, indem du ein JSON‑Manifest erstellst, ohne Quellcode pro Quelle zu schreiben. Verwende dies, wenn der Nutzer auf eine API zeigt, die keinen integrierten PostHog‑Connector hat – „Daten aus dieser REST‑API importieren“, „meine interne API synchronisieren“, „diese API aus ihrer Dokumentation verbinden“, „eine benutzerdefinierte Datenlager‑Quelle erstellen“ – und eine Dokumentations‑URL oder eine natürlichsprachliche Beschreibung der Endpunkte liefert. Führt durch das Erstellen des RESTAPIConfig‑Manifests (Authentifizierung – Bearer, API‑Schlüssel, HTTP‑Basic oder OAuth2‑Client‑Credentials/Refresh‑Token – Paginierung, Record‑Pfad, inkrementeller Cursor, Parent/Child‑Fan‑Out), die Validierung, das Test‑Auslesen von Live‑Zeilen zur Überprüfung der Feldzuordnungen und das Anlegen der Quelle. Hat die API bereits einen nativen PostHog‑Connector, verwende stattdessen „Einrichten einer Datenlager‑Quelle“ – diese Fähigkeit prüft zuerst das Connector‑Register und behandelt nur APIs ohne nativen Connector.
