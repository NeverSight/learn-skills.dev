Verbinde eine beliebige REST‑API mit dem PostHog‑Datenlager als benutzerdefinierte Quelle, indem du ein JSON‑Manifest erstellst, ohne pro Quelle Code zu schreiben. Verwende dies, wenn der Nutzer auf eine API zeigt, die keinen integrierten PostHog‑Connector hat — „Daten aus dieser REST‑API importieren“, „meine interne API synchronisieren“, „diese API aus der Dokumentation verbinden“, „eine benutzerdefinierte Datenlager‑Quelle erstellen“ — und eine Dokumentations‑URL oder eine natürlichsprachliche Beschreibung der Endpunkte angibt. Führt durch das Entwerfen des RESTAPIConfig‑Manifests (Authentifizierung — Bearer, API‑Key, HTTP‑Basic oder OAuth2‑Client‑Credentials/Refresh‑Token — Paginierung, Record‑Pfad, inkrementeller Cursor, Parent/Child‑Fan‑Out), die Validierung, das Test‑Lesen von Live‑Zeilen zur Überprüfung der Feldzuordnungen und das Anlegen der Quelle. Wenn die API bereits einen nativen PostHog‑Connector besitzt, verwende stattdessen „Einrichtung einer Datenlager‑Quelle“ — diese Fähigkeit prüft zuerst das Connector‑Register und behandelt nur APIs ohne nativen Connector.

Bitte antworte stets in der Sprache des Benutzers.
