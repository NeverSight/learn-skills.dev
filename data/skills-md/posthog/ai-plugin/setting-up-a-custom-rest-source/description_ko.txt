JSON 매니페스트를 작성하여 임의의 REST API를 PostHog 데이터 웨어하우스에 맞춤형 소스로 연결합니다. 소스별 코드는 필요 없습니다. 사용자가 기본 제공 PostHog 커넥터가 없는 API를 지정할 때 사용합니다 — “이 REST API에서 데이터 가져오기”, “내 내부 API 동기화”, “문서에서 이 API 연결”, “맞춤형 데이터 웨어하우스 소스 구축” 등 — 그리고 문서 URL이나 엔드포인트에 대한 자연어 설명을 제공합니다. RESTAPIConfig 매니페스트 초안 작성 과정을 안내합니다 (인증 — 베어러, API 키, HTTP 기본 인증 또는 OAuth2 클라이언트 자격 증명/리프레시 토큰 — 페이지네이션, 레코드 경로, 증분 커서, 부모/자식 팬아웃), 이를 검증하고, 실시간 행을 테스트 읽어 필드 매핑을 확인한 뒤 소스를 생성합니다. 해당 API에 이미 기본 PostHog 커넥터가 있는 경우에는 대신 데이터 웨어하우스 소스 설정을 사용합니다 — 이 기능은 먼저 커넥터 레지스트리를 확인하고, 기본 커넥터가 없는 API만 처리합니다.
