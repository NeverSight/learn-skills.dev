透過撰寫 JSON manifest，將任意 REST API 連接至 PostHog 資料倉庫作為自訂來源，無需為每個來源寫程式碼。適用於使用者指向沒有內建 PostHog 連接器的 API——「從這個 REST API 匯入資料」「同步我的內部 API」「根據文件連接此 API」「建立自訂資料倉庫來源」——並提供文件 URL 或以自然語言描述端點的情況。說明如何草擬 RESTAPIConfig manifest（認證方式——Bearer、API 金鑰、HTTP 基本認證或 OAuth2 客戶端憑證／刷新令牌——分頁、記錄路徑、增量游標、父子扇出），驗證其正確性，測試讀取即時資料列以確認欄位對應，最後建立來源。如果該 API 已有原生 PostHog 連接器，則改用「設定資料倉庫來源」——此功能會先檢查連接器註冊表，僅處理沒有原生連接器的 API。

請始終以使用者的語言回覆。
