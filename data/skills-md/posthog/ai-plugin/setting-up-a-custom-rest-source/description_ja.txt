JSON マニフェストを作成して、任意の REST API を PostHog データウェアハウスにカスタムソースとして接続します。ソースごとのコードは不要です。ユーザーが、組み込みの PostHog コネクタが存在しない API を指し示す場合に使用します — 「この REST API からデータをインポート」「内部 API を同期」「ドキュメントからこの API を接続」「カスタムデータウェアハウスソースを作成」 等の指示と、ドキュメント URL もしくはエンドポイントの自然言語での説明が提供されたときです。RESTAPIConfig マニフェストの作成手順（認証 — ベアラートークン、API キー、HTTP ベーシック、または OAuth2 クライアント資格情報／リフレッシュトークン、ページング、レコードパス、インクリメンタルカーソル、親子ファンアウト）を説明し、検証し、ライブ行をテスト読み取りしてフィールドマッピングを確認し、ソースを作成します。もしその API にすでにネイティブの PostHog コネクタがある場合は、代わりに「setting‑up‑a‑data‑warehouse‑source」を使用してください — このスキルはまずコネクタレジストリをチェックし、ネイティブコネクタがない API のみを処理します。

常にユーザーの言語で回答してください。
