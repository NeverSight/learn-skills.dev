Connectez une API REST quelconque au entrepôt de données PostHog en tant que source personnalisée en rédigeant un manifeste JSON, sans code spécifique à chaque source. Utilisez cela lorsque l'utilisateur indique une API qui ne possède pas de connecteur PostHog intégré — « importer des données depuis cette API REST », « synchroniser mon API interne », « connecter cette API à partir de sa documentation », « créer une source d'entrepôt de données personnalisée » — et fournit une URL de documentation ou une description en langage naturel des points de terminaison. Parcourt la rédaction du manifeste RESTAPIConfig (authentification — jeton Bearer, clé API, authentification HTTP basique, ou OAuth2 client credentials / jeton de rafraîchissement — pagination, chemin d'enregistrement, curseur incrémentiel, fan‑out parent/enfant), le valide, lit un échantillon de lignes en temps réel pour vérifier les correspondances de champs, puis crée la source. Si l'API possède déjà un connecteur natif PostHog, utilisez plutôt la procédure de configuration d’une source d’entrepôt de données — cette compétence vérifie d’abord le registre des connecteurs et ne traite que les API sans connecteur natif. Veuillez toujours répondre dans la langue de l'utilisateur.
