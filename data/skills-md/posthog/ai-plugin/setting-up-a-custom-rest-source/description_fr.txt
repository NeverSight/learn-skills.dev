Connectez une API REST arbitraire au entrepôt de données PostHog en tant que source personnalisée en créant un manifeste JSON, sans code propre à chaque source. Utilisez‑le lorsque l'utilisateur pointe vers une API qui n’a pas de connecteur PostHog intégré — « importer des données depuis cette API REST », « synchroniser mon API interne », « connecter cette API à partir de sa documentation », « créer une source d’entrepôt de données personnalisée » — et fournit une URL de documentation ou une description en langage naturel des points de terminaison. Parcourez la rédaction du manifeste RESTAPIConfig (authentification — bearer, clé API, authentification HTTP basique ou OAuth2 client credentials / refresh token — pagination, chemin d’enregistrement, curseur incrémentiel, propagation parent/enfant), validez‑le, effectuez une lecture de test en direct des lignes pour vérifier les correspondances de champs, et créez la source. Si l’API possède déjà un connecteur natif PostHog, utilisez plutôt la procédure de mise en place d’une source d’entrepôt de données — cette compétence vérifie d’abord le registre des connecteurs et ne traite que les API sans connecteur natif. Veuillez toujours répondre dans la langue de l’utilisateur.
