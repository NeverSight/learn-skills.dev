通过编写 JSON 清单，将任意 REST API 连接到 PostHog 数据仓库作为自定义源，无需为每个源编写代码。当用户指向一个没有内置 PostHog 连接器的 API 时使用——例如“从此 REST API 导入数据”“同步我的内部 API”“根据文档连接此 API”“构建自定义数据仓库源”——并提供文档 URL 或对端点的自然语言描述。流程包括起草 RESTAPIConfig 清单（认证方式——Bearer、API 密钥、HTTP 基本认证或 OAuth2 客户端凭证/刷新令牌——分页、记录路径、增量游标、父子分叉），验证清单，实时读取测试行以验证字段映射，并创建源。如果该 API 已经拥有原生的 PostHog 连接器，则改用“设置数据仓库源”。此功能首先检查连接器注册表，仅处理没有原生连接器的 API。请始终使用用户的语言进行响应。
