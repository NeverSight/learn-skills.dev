Collega un'API REST arbitraria al data warehouse di PostHog come sorgente personalizzata creando un manifesto JSON, senza codice specifico per sorgente. Usa quando l'utente indica un'API che non ha un connettore PostHog integrato — “importa dati da questa API REST”, “sincronizza la mia API interna”, “collega questa API dalla sua documentazione”, “crea una sorgente personalizzata per il data warehouse” — e fornisce un URL della documentazione o una descrizione in linguaggio naturale degli endpoint. Guida attraverso la stesura del manifesto RESTAPIConfig (autenticazione — bearer, chiave API, HTTP basic o OAuth2 client credentials / refresh token — paginazione, percorso del record, cursore incrementale, fan‑out genitore/figlio), la sua validazione, la lettura di prova di righe live per verificare le mappature dei campi e la creazione della sorgente. Se l'API ha già un connettore nativo di PostHog, usa invece la procedura di impostazione di una sorgente per il data warehouse — questa funzionalità controlla prima il registro dei connettori e gestisce solo le API senza connettore nativo.
