Conecta una API REST arbitraria al almacén de datos de PostHog como una fuente personalizada mediante la creación de un manifiesto JSON, sin código por fuente. Úsalo cuando el usuario apunte a una API que no tenga un conector nativo de PostHog — “importar datos de esta API REST”, “sincronizar mi API interna”, “conectar esta API desde su documentación”, “construir una fuente personalizada para el almacén de datos” — y proporcione una URL de documentación o una descripción en lenguaje natural de los endpoints. Guía paso a paso la elaboración del manifiesto RESTAPIConfig (autenticación — bearer, clave API, HTTP basic o credenciales OAuth2 / token de refresco — paginación, ruta del registro, cursor incremental, fan‑out padre/hijo), su validación, la lectura de prueba de filas en vivo para verificar los mapeos de campos y la creación de la fuente. Si la API ya dispone de un conector nativo de PostHog, utiliza en su lugar la configuración de una fuente de almacén de datos — esta habilidad verifica primero el registro de conectores y solo maneja APIs sin conector nativo.  

Por favor, siempre responde en el idioma del usuario.
