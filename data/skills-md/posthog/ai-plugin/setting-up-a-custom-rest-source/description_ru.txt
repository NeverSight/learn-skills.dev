Подключите произвольный REST API к складу данных PostHog в качестве пользовательского источника, создав JSON‑манифест без написания кода для каждого источника. Используйте, когда пользователь указывает API, для которого нет встроенного коннектора PostHog — «импортировать данные из этого REST API», «синхронизировать мой внутренний API», «подключить этот API по его документации», «создать пользовательский источник для склада данных» — и предоставляет URL документации или описание эндпоинтов на естественном языке. Пошагово опишите составление манифеста RESTAPIConfig (авторизация — bearer‑токен, API‑ключ, HTTP‑Basic или OAuth2 client credentials / refresh token — пагинация, путь к записи, инкрементальный курсор, разветвление parent/child), его проверку, тестовое чтение живых строк для подтверждения соответствия полей и создание источника. Если для API уже существует нативный коннектор PostHog, используйте процесс настройки источника склада данных вместо этого — эта функция сначала проверяет реестр коннекторов и работает только с API без нативного коннектора.
