Collega un'occorrenza di errore di PostHog o gli errori di una sessione a tracce OpenTelemetry, log con lo stesso trace ID e Session Replay. Da usare quando l'utente richiede ID di trace o span su un errore, log con lo stesso trace o tracce backend per errori in una sessione. Parte da un UUID di occorrenza, ID sessione o URL del problema di tracciamento errori. Per una diagnosi generale del problema o un riepilogo della riproduzione, usa investigating-error-issue o investigating-replay.
