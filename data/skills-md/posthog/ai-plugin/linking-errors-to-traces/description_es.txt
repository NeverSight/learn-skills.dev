Enlaza una ocurrencia de error de PostHog o los errores de una sesión con trazas de OpenTelemetry, registros con el mismo ID de traza y Session Replay. Úsalo cuando el usuario solicite IDs de traza o span en un error, registros de la misma traza o trazas de backend para errores en una sesión. Comienza a partir de un UUID de ocurrencia, ID de sesión o URL del issue de seguimiento de errores. Para un diagnóstico general del problema o un resumen de la reproducción, usa investigating-error-issue o investigating-replay.
