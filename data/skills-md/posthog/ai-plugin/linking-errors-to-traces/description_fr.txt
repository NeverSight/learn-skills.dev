Lie une occurrence d’erreur PostHog ou les erreurs d’une session aux traces OpenTelemetry, aux journaux avec le même ID de trace et à la Relecture de session. À utiliser lorsque l’utilisateur demande les ID de trace ou de span sur une erreur, les journaux de même trace ou les traces backend pour des erreurs dans une session. Commence à partir d’un UUID d’occurrence, d’un ID de session ou d’une URL de problème de suivi d’erreurs. Pour un diagnostic général du problème ou un résumé de la relecture, utilisez investigating‑error‑issue ou investigating‑replay.
