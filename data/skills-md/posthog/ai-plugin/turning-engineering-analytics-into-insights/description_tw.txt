將工程分析（PR / CI）資料轉換為已儲存的 PostHog 洞察、儀表板與訂閱，並說明如何直接使用 SQL 查詢產品資料。內容涵蓋透過 engineering-analytics-sources 發掘各團隊的 GitHub 倉儲表格、在 HogQL 中複製精選欄位語意、讀取已公開的 engineering_analytics_* 倉儲檢視（包含產品邏輯，如 CI 成本、指紋失敗行、提交歸屬），使用 insight-create 儲存查詢，以及使用 subscriptions-create 排程傳送。當被要求「把這個存成洞察」、「把 CI 健康／合併時間放在儀表板上」、「每週 email 我 PR 產出量」、「繪製 CI 成本圖表」、「追蹤首次審查時間」、「訂閱這些數字」、「對 CI 成功率發出警報」或「工程分析讀取了哪些資料／表格／檢視」時使用。本說明亦提供 ad‑hoc CI 與合併問題的 diagnosing‑ci‑and‑merge‑bottlenecks；若要調查單一 CI 失敗則使用 investigating‑ci‑failures。請始終以使用者的語言回覆。
