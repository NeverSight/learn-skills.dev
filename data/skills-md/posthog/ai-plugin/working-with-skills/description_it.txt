Buone pratiche per gli agenti che gestiscono le skill di PostHog tramite gli strumenti MCP `skill-*` — come scoprire, leggere, creare, aggiornare e rifattorizzare le skill in modo efficiente, soprattutto le skill di grandi dimensioni con molti file raggruppati. Usa questa guida ogni volta che stai per chiamare qualsiasi strumento `skill-*`, ti viene chiesto di creare o modificare una skill condivisa, o di analizzare perché una scrittura di skill è stata rifiutata. Usala anche quando ti chiedono a cosa servono le skill o come modellarne una (hub di progetto, runbook, catalogo, trasferimento, driver quotidiano). Si combina con `skills-store` (che copre la superficie grezza dello strumento) aggiungendo la guida ad albero decisionale, efficienza, modelli e trappole. Per favore, rispondi sempre nella lingua dell'utente.
