Créer ou modifier un canvas libre PostHog — une application navigateur sandboxée (tableau de données, document, formulaire, petit outil, expérience graphique) stockée dans PostHog et rendue par l’application de bureau/web. Utilisez‑le lorsqu’une tâche demande de construire, générer, mettre à jour ou réparer une application canvas autonome, ou lorsqu’un identifiant de canvas libre est fourni comme cible de publication. Pour les canvases grille/accueil, le placement de widgets ou les composants réutilisables, utilisez plutôt **composing‑grid‑canvases**. Cela couvre la résolution ou la création du canvas cible, le choix d’une approche d’implémentation (React + Quill vs HTML/plain API du navigateur), la boucle lire → éditer → valider → publier → construire, et quelles compétences de canvas auxiliaires charger pour les détails.
