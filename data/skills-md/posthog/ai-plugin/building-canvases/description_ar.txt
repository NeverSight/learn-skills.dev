إنشاء أو تعديل لوحة PostHog الحرة — تطبيق متصفح معزول (لوحة بيانات، مستند، نموذج، أداة صغيرة، تجربة رسومات) مخزن في PostHog ويُعرض عبر تطبيق سطح المكتب/الويب. يُستخدم عندما تطلب مهمة بناء أو توليد أو تحديث أو إصلاح تطبيق لوحة مستقلة، أو عندما يُعطى معرف لوحة حرة كهدف للنشر. بالنسبة للوحات الشبكية/الرئيسية، مواضع الودجت، أو المكونات القابلة لإعادة الاستخدام، استخدم composing‑grid‑canvases بدلاً من ذلك. يغطي حل أو إنشاء لوحة الهدف، اختيار نهج التنفيذ (React + Quill مقابل HTML بسيط/واجهات برمجة تطبيقات المتصفح)، حلقة القراءة → التعديل → التحقق → النشر → الإنشاء، وتحديد أي مهارات لوحة مرافقة يجب تحميلها للتفاصيل.
