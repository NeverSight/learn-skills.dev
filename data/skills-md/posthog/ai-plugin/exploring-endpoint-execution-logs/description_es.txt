Explora y diagnostica los registros de ejecución de un endpoint de PostHog — mensajes de error, ejecuciones fallidas, fallos de caché, ejecuciones lentas o recuentos de filas inesperados durante las invocaciones del endpoint. Úsalo cuando el usuario dice "my endpoint is failing", "show me the logs for endpoint X", "what error did endpoint Y produce", "why did endpoint Z return no rows", "is this endpoint hitting cache", o "check the last N runs". Enfocado en las entradas de registro de tiempo de ejecución de un único endpoint nombrado, no en auditorías a nivel de proyecto ni en el perfilado del rendimiento de consultas.

Por favor, responde siempre en el idioma del usuario.
