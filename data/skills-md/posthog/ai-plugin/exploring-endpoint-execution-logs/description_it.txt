Esplora e diagnostica i registri di esecuzione di un endpoint PostHog — messaggi di errore, esecuzioni fallite, mancanze di cache, esecuzioni lente o conteggi di righe inattesi durante le invocazioni dell'endpoint. Utilizza quando l'utente dice “il mio endpoint sta fallendo”, “mostrami i log per l'endpoint X”, “che errore ha prodotto l'endpoint Y”, “perché l'endpoint Z non ha restituito righe”, “questo endpoint sta usando la cache” o “controlla le ultime N esecuzioni”. Concentrati sui record di log di runtime di un singolo endpoint denominato, non sull’audit a livello di progetto o sul profiling delle prestazioni delle query.

Rispondi sempre nella lingua dell'utente.
