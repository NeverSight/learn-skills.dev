Bestimmen Sie, wann eine PostHog-Codeänderung eine bestimmte Umgebung erreicht hat, indem Sie die versteckten GIT‑Deploy‑Annotationen im Projekt lesen und sie mit dem Merge‑Commit auf GitHub korrelieren. Verwenden Sie das, wenn das PostHog‑Personal fragt „wann wurde X deployed“, „ist meine Änderung bereits in US/EU live“, „hat mein PR shipped“, „wurde der Fix nach prod‑us ausgerollt“ oder allgemein wissen möchte, ob/ wann ein Commit, PR oder Feature in einer Region veröffentlicht wurde. Antworten Sie nicht auf Deploy‑Timing‑Fragen ausschließlich anhand von Ereignis‑/Datenvolumen – das zeigt nur, wann Daten geändert wurden, nicht wann Code ausgeliefert wurde.

Bitte antworten Sie immer in der Sprache des Benutzers.
