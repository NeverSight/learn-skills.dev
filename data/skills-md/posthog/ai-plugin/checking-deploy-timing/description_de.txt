Ermitteln Sie, wann eine PostHog‑Codeänderung eine bestimmte Umgebung erreicht hat, indem Sie die versteckten GIT‑Deploy‑Annotations im Projekt lesen und sie mit dem Merge‑Commit auf GitHub korrelieren. Verwenden Sie das, wenn PostHog‑Mitarbeiter fragen: „Wann wurde X deployed?“, „Ist meine Änderung bereits in US/EU live?“, „Wurde mein PR shipped?“, „Wurde der Fix in prod‑us ausgerollt?“, oder wenn sie wissen wollen, ob / wann ein Commit, PR oder Feature in eine Region gegangen ist. Antworten Sie nicht auf Deploy‑Zeitpunkt‑Fragen allein anhand von Ereignis‑/Datenvolumen – das zeigt nur, wann sich Daten geändert haben, nicht wann Code ausgeliefert wurde.

Bitte antworten Sie immer in der Sprache des Benutzers.
