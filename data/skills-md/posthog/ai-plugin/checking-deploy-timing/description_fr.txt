Déterminez quand un changement de code PostHog a atteint un environnement donné en lisant les annotations de déploiement GIT cachées dans le projet et en les corrélant avec le commit de fusion sur GitHub. Utilisez cela lorsque le personnel de PostHog demande « when was X deployed », « is my change live in the US/EU yet », « has my PR shipped », « did the fix roll out to prod-us », ou veut savoir si/quand un commit, un PR ou une fonctionnalité a été déployé(e) dans une région. Ne répondez pas aux questions de timing de déploiement uniquement à partir des événements/du volume de données — cela ne montre que le moment où les données ont changé, pas quand le code a été expédié.

Veuillez toujours répondre dans la langue de l'utilisateur.
