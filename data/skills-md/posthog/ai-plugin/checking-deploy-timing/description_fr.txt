Déterminez quand une modification de code PostHog a atteint un environnement donné en lisant les annotations de déploiement GIT cachées dans le projet et en les corrélant avec le commit de fusion sur GitHub. Utilisez cela lorsque le personnel de PostHog demande « quand X a été déployé », « ma modification est‑elle déjà en ligne aux États‑Unis/UE », « mon PR a‑t‑il été expédié », « le correctif a‑t‑il été déployé en prod‑us », ou souhaite savoir si/quand un commit, une PR ou une fonctionnalité a été mis en production dans une région. Ne répondez pas aux questions de timing de déploiement uniquement à partir du volume d’événements/données — cela ne montre que quand les données ont changé, pas quand le code a été déployé.

Veuillez toujours répondre dans la langue de l’utilisateur.
