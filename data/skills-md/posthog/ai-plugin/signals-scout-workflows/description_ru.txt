Сигналы‑скаут для рабочих процессов PostHog. Анализирует рабочие процессы, владелец которых запросил предложения, читает метрики доставки каждой версии шага электронной почты и предлагает одно конкретное изменение, которое человек может одобрить, через API предложений для рабочих процессов. Отчёт не создаётся и сигнал не генерируется: предложение на странице рабочего процесса является выводом.
