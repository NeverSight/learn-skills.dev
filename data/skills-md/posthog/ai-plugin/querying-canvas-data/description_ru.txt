Получайте данные PostHog в canvas корректно: SDK `ph`, внедрённый хостом (loadInsight, query, capture, state, connectors, openExternal, navigate), иерархию данных (сначала сохранённые инсайты, затем типизированные узлы запросов, в конце inline HogQL), проверяемость (метрики, основанные на инсайтах, связывают их с сохранённым инсайтом в PostHog; ad‑hoc запросы показывают точный выполненный запрос), формы результатов в зависимости от типа инсайта, прогрессивную загрузку по каждому запросу, привязку диапазона дат, живые сторонние данные через собственные соединения зрителя (ph.connectors) и захват событий из canvas. Используйте, когда canvas отображает метрики, диаграммы, таблицы, любые данные PostHog, данные из GitHub или сервера MCP, либо когда необходимо отправлять аналитические события.
