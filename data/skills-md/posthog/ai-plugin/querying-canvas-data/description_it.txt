Ottieni i dati di PostHog in un canvas correttamente: l'SDK `ph` iniettato dall'host (loadInsight, query, capture, state, connectors, openExternal, navigate), la gerarchia dei dati (prima gli insight salvati, poi i nodi di query tipizzati, infine l'HogQL inline), la verificabilità (le metriche basate su insight collegano il loro insight salvato in PostHog; le query ad‑hoc espongono la query esatta eseguita), le forme dei risultati per tipo di insight, il caricamento progressivo per query, il collegamento dell'intervallo di date, i dati di terze parti in tempo reale tramite le proprie connessioni del visualizzatore (ph.connectors) e la cattura di eventi da un canvas. Usa questo approccio ogni volta che un canvas mostra metriche, grafici, tabelle, qualsiasi dato di PostHog, o dati da GitHub o da un server MCP, o deve inviare eventi di analisi.
