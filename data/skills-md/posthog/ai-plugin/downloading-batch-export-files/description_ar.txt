صدّر أحداث PostHog أو الأشخاص أو الجلسات أو نتائج استعلام HogQL عند الطلب وقم بتنزيل الملفات الناتجة. استخدم ذلك عندما يطلب المستخدم تنزيل/تصدير البيانات الخام من PostHog، أو تصدير نتائج استعلام HogQL، أو إنشاء تصدير ملف لمرة واحدة، أو جلب تصدير بصيغة Parquet أو JSONLines، أو استخدام واجهة برمجة التطبيقات file_download_batch_exports. يغطي بدء التصدير باستخدام MCP، ومتابعة اكتماله، والتنزيل عبر نقطة النهاية لإعادة التوجيه REST الحالية.
