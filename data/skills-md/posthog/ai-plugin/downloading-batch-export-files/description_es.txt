Exporta eventos, personas, sesiones de PostHog o los resultados de una consulta HogQL a demanda y descarga los archivos resultantes. Úsalo cuando el usuario solicite descargar/exportar datos sin procesar de PostHog, exportar resultados de consultas HogQL, crear una exportación de archivo puntual, obtener una exportación en Parquet o JSONLines, o utilizar la API file_download_batch_exports. Incluye iniciar la exportación con MCP, sondear la finalización y descargar mediante el endpoint de redirección REST existente.
