Esporta gli eventi, le persone, le sessioni di PostHog o i risultati di una query HogQL su richiesta e scarica i file risultanti. Usa questa funzione quando l'utente chiede di scaricare/esportare i dati grezzi di PostHog, esportare i risultati di una query HogQL, creare un'esportazione di file una tantum, recuperare un'esportazione in formato Parquet o JSONLines, o utilizzare l'API file_download_batch_exports. Copre l'avvio dell'esportazione con MCP, il polling per il completamento e il download tramite l'endpoint di reindirizzamento REST esistente.
