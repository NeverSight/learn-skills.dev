Экспортировать события PostHog, персон, сессии или результаты запроса HogQL по требованию и загрузить полученные файлы. Используйте, когда пользователь просит скачать/экспортировать сырые данные PostHog, экспортировать результаты запроса HogQL, создать однократный экспорт файла, получить экспорт в формате Parquet или JSONLines, либо воспользоваться API file_download_batch_exports. Охватывает запуск экспорта с помощью MCP, опрос завершения и загрузку через существующий REST‑endpoint перенаправления.
