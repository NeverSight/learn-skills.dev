PostHog のイベント、人物、セッション、または HogQL クエリの結果を必要に応じてエクスポートし、生成されたファイルをダウンロードします。ユーザーが生の PostHog データのダウンロード/エクスポート、HogQL クエリ結果のエクスポート、一度限りのファイルエクスポートの作成、Parquet または JSONLines エクスポートの取得、あるいは file_download_batch_exports API の使用を求めたときに使用します。MCP でエクスポートを開始し、完了をポーリングし、既存の REST リダイレクトエンドポイントを介してダウンロードするプロセスをカバーしています。
