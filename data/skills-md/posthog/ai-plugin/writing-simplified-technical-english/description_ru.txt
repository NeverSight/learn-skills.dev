Пишите английский так, чтобы читатель не мог его неправильно понять: одно значение на слово, активный залог, простые времена, одна идея в предложении, короткие предложения. Основано на ASD‑STE100 (Simplified Technical English) — стандарте контролируемого языка, разработанном для руководств по обслуживанию самолётов. Используйте его для любого текста, который создаёт агент и который будет использовать другой человек. Это охватывает отчёты и выводы, описания PR и сообщения коммитов, инструкции, передаваемые другому агенту, описания инструментов, сообщения об ошибках, сводки статуса и подсказки. Также применяйте его по запросу, при триггерах вроде «simplify this», «make this readable», «too dense», «rewrite in STE», «simplified technical english», «ASD‑STE100».  

Всегда отвечайте на языке пользователя.
