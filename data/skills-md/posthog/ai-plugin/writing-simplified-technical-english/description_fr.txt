Écrivez de l'anglais qu'un lecteur ne peut pas mal interpréter : un sens par mot, voix active, temps simples, une idée par phrase, phrases courtes. Basé sur l'ASD‑STE100 (Simplified Technical English), la norme de langue contrôlée rédigée pour les manuels de maintenance d’avions. Utilisez‑le pour tout texte qu’un agent produit et sur lequel quelqu’un d’autre agit. Cela couvre les rapports et constats, les descriptions de PR et les messages de commit, les instructions remises à un autre agent, les descriptions d’outils, les messages d’erreur, les résumés d’état et les invites. Utilisez‑le également sur demande, avec des déclencheurs tels que « simplify this », « make this readable », « too dense », « rewrite in STE », « simplified technical english », « ASD‑STE100 ».

Veuillez toujours répondre dans la langue de l'utilisateur.
