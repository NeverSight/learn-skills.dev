Écrivez, modifiez et adaptez les scouts PostHog Signals : des agents programmés qui analysent un projet et rapportent leurs constats. Utilisez-les pour modifier la portée, les seuils, le planning ou les paramètres de simulation d’un scout canonique ; ajouter un scout pour une zone non couverte ; enregistrer la sortie structurée d’un scoring LLM planifié ; ou donner un retour via des notes. Couvre la structure SKILL.md, les exigences du rapport, les vérifications de suivi du rapport, la sortie structurée, la détection de doublons, la mémoire du carnet de notes, les notes du scout, les compétences par équipe et les modifications du référentiel canonique, ainsi que les tests. Déclencheurs : « écrire/modifier/personnaliser un scout signals », « nouveau scout pour X », « ajuster le planning de mon scout », « créer un scout qui surveille <événement> », « évaluer/juger/mesurer X avec un scout », « sortie structurée d’un scout », « sortie du scout vers Slack », « laisser une note / donner un retour à un scout ».
