PostHog 엔드포인트(저장된 HogQL/인사이트 쿼리를 API 라우트로 노출한 것)를 같은 조직의 다른 프로젝트로 복사하거나, 같은 프로젝트 내에서 새 이름으로 복제합니다. 사용자는 엔드포인트를 복제하거나, 스테이징에서 프로덕션으로 엔드포인트를 승격시키거나, 다른 워크스페이스에 엔드포인트의 쿼리·변수·신선도 설정을 복제하거나, 엔드포인트를 복제해 반복 작업을 하고자 할 때 사용합니다. 기능 플래그와 실험과 달리, 엔드포인트에는 기본 제공되는 교차 프로젝트 복사 도구가 **전혀** 없습니다—이 기술은 읽고 다시 만드는 흐름(엔드포인트‑get 후 엔드포인트‑create), 필요한 활성 프로젝트 전환, 이름 충돌 검사, 그리고 안전한 기본값(대상에 비물질화된 형태로 배치하고 엔드포인트‑run으로 검증) 을 포함합니다. 엔드포인트 버전 편집(‘managing‑endpoint‑versions’ 참조)이나 완전히 새로운 엔드포인트를 처음부터 만드는 작업(‘creating‑an‑endpoint’ 참조)은 포함하지 않습니다.
