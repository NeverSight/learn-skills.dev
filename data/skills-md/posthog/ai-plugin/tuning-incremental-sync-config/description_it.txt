Cambia la configurazione di sincronizzazione di uno schema di data warehouse esistente — passa a un diverso sync_type, scegli un altro incremental_field, imposta primary_key_columns, seleziona cdc_table_mode o modifica sync_frequency. Utilizza questa risposta quando l'utente richiede “switch my orders table from full refresh to incremental”, “this table is syncing too slowly / too frequently”, “I need to pick a different incremental column”, “set up CDC for this Postgres table”, oppure quando la diagnosi di una sincronizzazione fallita indica una cattiva configurazione del campo incremental o della chiave primaria. Rispondi sempre nella lingua dell'utente.
