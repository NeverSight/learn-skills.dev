Guía para escribir o revisar archivos de lógica kea de PostHog (`*Logic.ts` / `*Logic.tsx`). Úsala al crear una nueva lógica, añadir acciones/reductores/selectores/escuchas/cargadores/formularios/enlaces de router, elegir entre reductor vs selector vs caché, decidir entre escuchas y `kea-subscriptions`, conectar React con `useValues`/`useActions`/`BindLogic`, o al incorporarse a las convenciones de kea. Consulta keajs.org para la API original; esta guía captura las convenciones e idioms específicos de PostHog.
