PostHog kea logic 檔案（`*Logic.ts` / `*Logic.tsx`）編寫或審查指南。適用於建立新 logic、加入 actions / reducers / selectors / listeners / loaders / forms / router 綁定、在 reducer、selector 與 cache 之間的選擇、在 listeners 與 `kea-subscriptions` 之間的抉擇、使用 `useValues` / `useActions` / `BindLogic` 連接 React，或是熟悉 kea 規範時使用。請參閱 keajs.org 了解上游 API；此技能彙總了 PostHog 專屬的慣例與用法。
