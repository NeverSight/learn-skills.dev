Diagnostique l'état de santé des intégrations du SDK PostHog d'un projet : quels SDK sont obsolètes et comment les mettre à jour. À utiliser lorsqu'un utilisateur pose des questions sur les versions du SDK PostHog, les SDK obsolètes, les recommandations de mise à niveau, la « santé du SDK », le « SDK doctor » (ancien nom), ou lorsque des événements ou des fonctionnalités semblent anormaux et que cela pourrait être dû à un SDK obsolète.
