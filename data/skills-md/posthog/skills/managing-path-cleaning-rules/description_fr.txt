Examine les chemins d'URL et propose, teste, ordonne et applique des règles de nettoyage de chemins au niveau du projet afin que les segments dynamiques (ID numériques, UUID, slugs, dates) se transforment en alias lisibles. Utilisez ceci lorsque l'utilisateur dit « clean the paths », « normalize URLs », « group similar pages », « too many distinct paths », « /users/123 and /users/456 are the same page », « set up path cleaning », ou demande pourquoi une analyse Web ou une ventilation des chemins est fragmentée en milliers d'URL presque identiques. Couvre la syntaxe des expressions régulières (re2), la convention de placeholder d'alias, l'ordre des règles, le flux de test, et l'application des règles via l'outil MCP path‑cleaning‑rules‑update.
