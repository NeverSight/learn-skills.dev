Claude Code と Codex 用のデータクリーニング、エンティティマッチング、重複除去スキル：エンリッチメント前に B2B 企業またはコンタクトの CSV、Excel、JSON リストをトリアージ、標準化、検証します。企業名とドメインを正規化し、メールアドレスと電話番号を検証、レコードをマッチング・重複除去し、無効な行には破壊的でないタグ付けを行います。エンリッチメントや CRM インポートの前に実行して、ノイズの多いレコードに費用がかからないようにします。CRM エンリッチメントの準備、企業名・ウェブサイトのマッチング、エンティティマッチング、コンタクトの重複除去にご利用ください。Claude Code、Codex、MCP 経由の n8n でも動作します。
