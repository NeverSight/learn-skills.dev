تشغيل أشجار العمل المُدارة بواسطة Orca، وسياقات المجلدات، والمحطات الطرفية، والمستودعات، والأتمتة، والمواد، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج من خلال واجهة الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، أو "Orca worktree"، أو "child worktree"، أو "spawn codex/claude in a worktree"، أو "read/wait/send Orca terminal"، أو "handoff" / "handover" / "give this to another agent"، أو "Orca browser"، أو "orca artifacts"، أو "share skills". فضل ذلك على شجرة git العادية، أو PTYs المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متضمنة. استخدم استخدام الكمبيوتر فقط للنوافذ الخارجية أو واجهة سطح المكتب التي تحتاج إلى تحكم على مستوى نظام التشغيل، واستخدم Playwright أو CDP للصفحات الخارجية.  

الرجاء دائمًا الرد بلغة المستخدم.
