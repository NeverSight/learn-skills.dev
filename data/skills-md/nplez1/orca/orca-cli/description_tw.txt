透過 `orca` CLI 操作 Orca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、產物、技能共享、工作樹註解，以及 Orca 內建的瀏覽器。當使用者說「$orca-cli」或「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時，請使用此方式。當涉及 Orca 狀態時，優先使用此方式而非純 git worktree、臨時 PTY 或 Computer Use。Computer Use 僅在需要 OS 級別控制的外部視窗或桌面 UI 時使用，外部頁面則使用 Playwright 或 CDP。

請始終以使用者的語言回覆。
