Orca가 관리하는 워크트리, 폴더 컨텍스트, 터미널, 저장소, 자동화, 아티팩트, 스킬 공유, 워크트리 댓글, 그리고 Orca의 내장 브라우저를 `orca` CLI를 통해 조작합니다. 사용자는 “$orca-cli”, “Orca 워크트리”, “child 워크트리”, “워크트리에서 codex/claude 생성”, “읽기/대기/보내기 Orca 터미널”, “handoff” / “handover” / “다른 에이전트에게 전달”, “Orca 브라우저”, “orca 아티팩트”, 혹은 “스킬 공유”라고 말할 때 이를 사용합니다. Orca 상태가 관련될 경우 원시 git 워크트리, 임시 PTY, 혹은 Computer Use보다 이를 우선합니다. 컴퓨터 사용은 OS 수준 제어가 필요한 외부 창이나 데스크톱 UI에만 사용하고, 외부 페이지에 대해서는 Playwright 또는 CDP를 사용합니다.
