Управляйте рабочими деревьями, управляемыми Orca, контекстами папок, терминалами, репозиториями, автоматизацией, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Используйте это, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff» / «handover» / «give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочитайте этот способ вместо обычного git worktree, случайных PTY или Computer Use, когда задействовано состояние Orca. Используйте Computer Use только для внешних окон или интерфейса рабочего стола, требующего управления на уровне ОС, а Playwright или CDP — для внешних страниц.
