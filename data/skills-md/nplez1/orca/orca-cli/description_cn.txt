通过 `orca` CLI 操作 Orca 管理的工作树、文件夹上下文、终端、仓库、自动化、制品、技能共享、工作树评论以及 Orca 的嵌入式浏览器。用户说“$orca-cli”“Orca worktree”“child worktree”“spawn codex/claude in a worktree”“read/wait/send Orca terminal”“handoff”“handover”“give this to another agent”“Orca browser”“orca artifacts”或“share skills”时使用。涉及 Orca 状态时，优先使用它而不是原始 git 工作树、临时 PTY 或 Computer Use。仅在需要操作外部窗口或桌面 UI（需要操作系统级控制）时使用 Computer Use，外部页面则使用 Playwright 或 CDP。
