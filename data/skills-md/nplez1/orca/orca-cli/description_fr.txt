Manipulez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via la CLI `orca`. Utilisez‑le lorsque l’utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Préférez‑le au worktree git brut, aux PTY ad hoc ou à l’usage de l’ordinateur lorsque l’état d’Orca est en jeu. Recourez à « Computer Use » uniquement pour les fenêtres externes ou l’interface de bureau nécessitant un contrôle au niveau du système d’exploitation, et à Playwright ou CDP pour les pages externes.

Veuillez toujours répondre dans la langue de l’utilisateur.
