ينظم شفرة تدريب PyTorch باستخدام حزمة Lightning (PyTorch Lightning): LightningModule، LightningDataModule، Trainer، callbacks مثل ModelCheckpoint و EarlyStopping، مسجلات (TensorBoard، W&B، MLflow، Comet، CSV)، واستراتيجيات متعدد وحدات المعالجة الرسومية/الوحدات النمطية Tensor Processing Units (DDP، FSDP، DeepSpeed). يُستخدم عند هيكلة نموذج PyTorch إلى خطوات التدريب، والتحقق، والاختبار. يُستخدم عند تكوين Trainer لتشغيلات متعددة الـGPU أو الـTPU. يُستخدم عند كتابة LightningDataModule لتحميل البيانات. يُستخدم عند إضافة حفظ نقاط التحقق، الإيقاف المبكر أو تسجيل التجارب إلى عملية التدريب. يُستخدم عند اختيار بين DDP، FSDP وDeepSpeed بحسب حجم النموذج. ليس مناسبًا لحلقات PyTorch العادية دون Lightning.
