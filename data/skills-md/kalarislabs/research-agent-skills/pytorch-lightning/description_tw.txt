使用 lightning 套件（PyTorch Lightning）組織 PyTorch 訓練程式碼：LightningModule、LightningDataModule、Trainer、如 ModelCheckpoint 與 EarlyStopping 等回呼函式、記錄器（TensorBoard、W&B、MLflow、Comet、CSV），以及多 GPU/TPU 策略（DDP、FSDP、DeepSpeed）。在將 PyTorch 模型劃分為訓練、驗證與測試步驟時使用。在為多 GPU 或 TPU 執行配置 Trainer 時使用。在撰寫 LightningDataModule 進行資料載入時使用。在為訓練執行加入檢查點、提前停止或實驗記錄時使用。在根據模型規模選擇 DDP、FSDP 或 DeepSpeed 時使用。不適用於沒有 Lightning 的純 PyTorch 迴圈。
