Ce générateur compile tout type de données de recherche (articles PDF, dépôts GitHub, journaux d&#39;expérimentation, répertoires de code ou notes brutes) en un artefact de recherche complet, compatible avec les agents (ARA), comprenant une couche cognitive (affirmations, concepts, heuristiques), une couche physique (configurations, ébauches de code), un graphe d&#39;exploration et des preuves concrètes. Utilisez-le pour intégrer un article ou une base de code dans un ensemble de connaissances structuré et exécutable par machine, pour créer un ARA de A à Z ou pour convertir des résultats de recherche en un format falsifiable et exploitable par un agent.
