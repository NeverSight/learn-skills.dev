Multi-Agent-Orchestrierungs-Framework für autonome KI-Zusammenarbeit. Verwendung beim Aufbau von Teams spezialisierter Agenten, die gemeinsam an komplexen Aufgaben arbeiten, wenn Sie eine rollenbasierte Agentenzusammenarbeit mit dem Arbeitsspeicher benötigen oder für Produktionsworkflows, die eine sequenzielle/hierarchische Ausführung erfordern. Erstellt ohne LangChain-Abhängigkeiten für schlanke, schnelle Ausführung.
