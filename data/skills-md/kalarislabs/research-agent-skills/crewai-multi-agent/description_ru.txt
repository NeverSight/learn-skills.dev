Многоагентный оркестрационный фреймворк для автономного взаимодействия ИИ. Используйте при создании команд специализированных агентов, работающих совместно над сложными задачами, когда требуется ролевая коллаборация агентов с памятью, или для производственных процессов, требующих последовательного/иерархического выполнения. Построен без зависимостей от LangChain для компактного и быстрого выполнения.
