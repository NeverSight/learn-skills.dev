Arbor 論文の Hypothesis Tree Refinement (HTR) を用いて、目的と評価者に対して実際のアーティファクト（コード、トレーニングレシピ、エージェントハーネス、データパイプライン、プロンプト）を自律的に改善します。過学習せずに多数の実験を通じて何かを反復的に最適化したいときにこれを使用してください—たとえば「モデルの評価スコアを上げたい」「このエージェント／ハーネスを改善したい」「このパイプラインをチューニングしたい」「このベンチマークでベースラインを上回りたい」「さまざまなアプローチを探索してベストを残したい」「MLEベンチやKaggleスタイルの最適化を行いたい」あるいは「このアーティファクトを長期的に改善し、開発セットを単に暗記しない」タスク全般です。ユーザーが「Arbor」や「hypothesis tree」と言及していなくても、繰り返し実験と評価のループ、競合するアイデアの枝分かれ探索、あるいは開発／テストギャップへの懸念が記述されている場合は、これを発動します。Claude をコーディネータとして実行し、サブエージェント実行者を分離された git worktree で動かします。スタンドアロンの `arbor` CLI ツールについては references/arbor-upstream.md を参照してください。必ずユーザーの言語で応答してください。
