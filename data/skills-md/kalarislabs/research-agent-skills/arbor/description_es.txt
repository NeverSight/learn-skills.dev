Mejora de forma autónoma un artefacto real (código, receta de entrenamiento, harness de agente, canal de datos, prompt) frente a un objetivo y un evaluador, utilizando Hypothesis Tree Refinement (HTR) del artículo Arbor. Usa esto siempre que alguien quiera optimizar iterativamente algo mediante muchos experimentos sin sobreajustar — por ejemplo, “subir la puntuación de evaluación de mi modelo”, “mejorar este agente/harness”, “ajustar este pipeline”, “superar la línea base en este benchmark”, “ejecutar una búsqueda de enfoques y conservar el mejor”, “realizar una optimización al estilo MLE‑bench / Kaggle”, o cualquier tarea a largo plazo del tipo “hacer que este artefacto sea mejor y no solo memorizar el conjunto de desarrollo”. Actívalo incluso cuando el usuario no mencione “Arbor” o “hypothesis tree”, pero describa bucles repetidos de experimento‑evaluación, exploración ramificada de ideas competidoras o preocupaciones sobre una brecha dev/test. Claude se ejecuta como coordinador con subagentes ejecutores en worktrees de git aislados; para la herramienta CLI independiente `arbor` consulta references/arbor-upstream.md.
