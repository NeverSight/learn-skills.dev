Scrive documenti scientifici e documentazione in markdown con diagrammi Mermaid integrati come formato sorgente canonico e diffabile con git. Include una guida di stile per markdown, una guida di stile per Mermaid, 24 riferimenti di tipi di diagrammi Mermaid (flowchart, sequence, ER, Gantt, state, mindmap, radar, sankey, grafico XY e altri), e 9 modelli (paper di ricerca, report di stato, decision record, how‑to, pull request, issue, kanban, presentazione, documentazione di progetto). Da utilizzare quando si scrive un rapporto, un manoscritto, un README o un'analisi in markdown. Da utilizzare quando si aggiunge un workflow, pipeline, timeline o diagramma di architettura a un documento. Da utilizzare quando si sceglie il tipo di diagramma Mermaid corretto o si corregge la sintassi Mermaid, ad esempio radar‑beta o xychart‑beta. Da utilizzare quando si parte da un modello di documento o si verificano le regole di citazione e di intestazione. Non è adatto per scatter plot di dati reali o immagini fotorealistiche; per questi utilizzare il plotting in Python o schemi scientifici.
