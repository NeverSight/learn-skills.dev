Écrit des documents scientifiques et de la documentation en markdown avec des diagrammes Mermaid intégrés comme format source canonique, diffable par git. Couvre un guide de style markdown, un guide de style Mermaid, 24 références de types de diagrammes Mermaid (flowchart, séquence, ER, Gantt, état, mindmap, radar, sankey, graphique XY, et autres), et 9 modèles (article de recherche, rapport d’état, registre de décision, mode d’emploi, pull request, ticket, kanban, présentation, documentation de projet). À utiliser lors de la rédaction d’un rapport, d’un manuscrit, d’un README ou d’une analyse en markdown. À utiliser lors de l’ajout d’un workflow, d’un pipeline, d’une chronologie ou d’un diagramme d’architecture à un document. À utiliser pour choisir le bon type de diagramme Mermaid ou corriger la syntaxe Mermaid telle que radar‑beta ou xychart‑beta. À utiliser lorsqu’on part d’un modèle de document ou qu’on vérifie les citations et les règles de titres. Pas pour les nuages de points de données réelles ou les images photoréalistes ; utilisez le traçage Python ou les schématiques scientifiques pour ceux‑ci.
