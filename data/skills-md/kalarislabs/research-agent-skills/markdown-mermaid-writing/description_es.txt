Redacta documentos científicos y documentación como markdown con diagramas Mermaid incrustados, como formato fuente canónico y diferenciable por git. Incluye una guía de estilo para markdown, una guía de estilo para Mermaid, 24 referencias de tipos de diagramas Mermaid (flowchart, sequence, ER, Gantt, state, mindmap, radar, sankey, XY chart y otros) y 9 plantillas (artículo de investigación, informe de estado, registro de decisiones, guía práctica, pull request, issue, kanban, presentación, documentación de proyecto). Úsalo al escribir un informe, manuscrito, README o análisis en markdown. Úsalo al añadir un flujo de trabajo, pipeline, cronograma o diagrama de arquitectura a un documento. Úsalo al elegir el tipo de diagrama Mermaid adecuado o al corregir la sintaxis de Mermaid, como radar-beta o xychart-beta. Úsalo al comenzar a partir de una plantilla de documento o al verificar citas y normas de encabezados. No es para gráficos de dispersión de datos reales ni imágenes fotorrealistas; usa trazado con Python o esquemas científicos para esos casos.
