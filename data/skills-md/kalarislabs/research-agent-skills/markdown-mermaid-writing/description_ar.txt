يكتب المستندات العلمية والوثائق بصيغة ماركداون مع رسومات مِرْميد المدمجة كصيغة المصدر القانونية القابلة للفرق في Git. يغطي دليل أسلوب الماركداون، دليل أسلوب مِرْميد، 24 مرجعًا لأنواع رسومات مِرْميد (مخطط تدفق، تسلسل، ER، غانت، حالة، خريطة ذهنية، رادار، ساني، مخطط XY، وغيرها)، و9 قوالب (ورقة بحث، تقرير حالة، سجل قرار، دليل خطوة بخطوة، طلب سحب، قضية، كانبان، عرض تقديمي، وثائق المشروع). يُستَخدم عند كتابة تقرير أو مخطوطة أو README أو تحليل بصيغة ماركداون. يُستَخدم عند إضافة سير عمل أو خط أنابيب أو خط زمني أو مخطط بنية إلى مستند. يُستَخدم عند اختيار نوع رسم مِرْميد المناسب أو تصحيح صياغة مِرْميد مثل radar‑beta أو xychart‑beta. يُستَخدم عند البدء من قالب مستند أو التحقق من الاستشهادات وقواعد العناوين. ليس للاستخدام في مخططات التشتت للبيانات الحقيقية أو الصور الفوتوغرافية الواقعية؛ استعمل الرسم البياني ببايثون أو المخططات العلمية لتلك الحالات.
