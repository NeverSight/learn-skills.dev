Пишет научные документы и документацию в виде markdown с встроенными диаграммами Mermaid как канонический, пригодный для сравнения через git diff исходный формат. Включает руководство по стилю markdown, руководство по стилю Mermaid, 24 справочника типов диаграмм Mermaid (flowchart, sequence, ER, Gantt, state, mindmap, radar, sankey, XY chart и другие) и 9 шаблонов (исследовательская статья, статусный отчёт, запись решения, инструкция, pull‑request, issue, kanban, презентация, проектная документация). Используйте при написании отчёта, рукописи, README или анализа в markdown. Используйте при добавлении диаграммы рабочего процесса, конвейера, временной шкалы или архитектуры в документ. Используйте при выборе подходящего типа диаграммы Mermaid или исправлении синтаксиса Mermaid, такого как radar‑beta или xychart‑beta. Используйте при начале работы с шаблоном документа или проверке цитат и правил заголовков. Не подходит для точечных графиков реальных данных или фотореалистичных изображений; для этого используйте построения в Python или scientific‑schematics.
