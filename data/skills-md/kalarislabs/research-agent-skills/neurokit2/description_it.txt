Usa NeuroKit2 per costruire o verificare flussi di lavoro di ricerca riproducibili per il preprocessing di serie temporali fisiologiche, l'analisi di eventi/intervalli, l'allineamento multimodale, la variabilità e la complessità. Attiva quando il codice importa neurokit2 o richiede le sue API attuali, gli schemi e la validazione consapevole del metodo—not per diagnosi o validazione di dispositivi.
