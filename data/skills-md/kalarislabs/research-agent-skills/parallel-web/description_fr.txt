Exécute l’outil parallel‑cli pour les flux de travail Web : recherche Web, extraction d’URL et de PDF, rapports de recherche approfondis, enrichissement de données structurées des lignes fournies, découverte d’entités FindAll et moniteurs Web récurrents. Privilégie la littérature primaire et les sources institutionnelles pour les requêtes scientifiques. À utiliser lors de la recherche de preuves Web actuelles ou d’une question de recherche délimitée. À utiliser lors de la récupération de contenu à partir d’une URL connue, d’un PDF ou d’une page rendue par JavaScript. À utiliser pour ajouter des champs provenant du Web à une liste d’entreprises, de personnes ou de produits. À utiliser lors de la découverte d’entités correspondant à des critères en langage naturel. À utiliser lorsqu’un rapport multi‑sources explicitement exhaustif est demandé. À utiliser pour suivre les changements du Web selon un planning récurrent. Pas pour des vérifications ponctuelles d’une page connue ne nécessitant pas de CLI, ou pour des bases de données de littérature hors ligne.
