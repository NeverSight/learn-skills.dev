Ejecuta la herramienta parallel-cli para flujos de trabajo web: búsqueda en la web, extracción de URL y PDF, informes de investigación profunda, enriquecimiento de datos estructurados de filas suministradas, descubrimiento de entidades FindAll y monitores web recurrentes. Prefiere literatura primaria y fuentes institucionales para consultas científicas. Úsalo al buscar evidencia web actual o una pregunta de investigación delimitada. Úsalo al obtener contenido de una URL conocida, PDF o página renderizada con JavaScript. Úsalo al añadir campos de origen web a una lista de empresas, personas o productos. Úsalo al descubrir entidades que coincidan con criterios en lenguaje natural. Úsalo cuando se solicite un informe explícitamente exhaustivo de múltiples fuentes. Úsalo al rastrear cambios en la web de forma recurrente. No es para verificaciones puntuales de una página conocida que no requieran CLI, o para bases de datos de literatura offline.
