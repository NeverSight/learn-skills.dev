Esegue lo strumento parallel-cli per i flussi di lavoro web: ricerca web, estrazione di URL e PDF, report di ricerca approfondita, arricchimento strutturato dei dati delle righe fornite, scoperta di entità FindAll e monitoraggi web ricorrenti. Preferisce la letteratura primaria e le fonti istituzionali per le query scientifiche. Usare quando si cercano evidenze web attuali o una domanda di ricerca delimitata. Usare quando si recupera contenuto da un URL noto, PDF o pagina resa con JavaScript. Usare quando si aggiungono campi provenienti dal web a un elenco di aziende, persone o prodotti. Usare quando si scoprono entità che corrispondono a criteri in linguaggio naturale. Usare quando viene richiesto un report multiriferimento esplicitamente esaustivo. Usare quando si monitorano cambiamenti web su base ricorrente. Non è adatto per controlli una tantum di una pagina conosciuta che non richiedono CLI, né per banche dati di letteratura offline.
