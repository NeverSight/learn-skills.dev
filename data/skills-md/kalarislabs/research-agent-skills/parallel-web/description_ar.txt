يشغّل أداة parallel‑cli لتدفقات عمل الويب: البحث على الويب، استخراج عناوين URL وملفات PDF، تقارير أبحاث عميقة، إغناء البيانات المهيكلة للصفوف المقدَّمة، اكتشاف الكيانات FindAll، ومراقبين ويب متكررين. يفضّل الأدبيات الأولية والمصادر المؤسسية للاستفسارات العلمية. يُستعمل عند البحث عن أدلة ويب حديثة أو سؤال بحث محدود. يُستعمل عند جلب المحتوى من عنوان URL معروف، أو ملف PDF، أو صفحة تُعرض بإطار JavaScript. يُستعمل عند إضافة حقول مستمدّة من الويب إلى قائمة من الشركات أو الأشخاص أو المنتجات. يُستعمل عند اكتشاف كيانات تتطابق مع معايير اللغة الطبيعية. يُستعمل عندما يُطلب تقرير شامل متعدد المصادر بشكل صريح. يُستعمل عند تتبع تغيّرات الويب وفق جدول زمني متكرر. ليس للاستخدام في التحقق لمرة واحدة من صفحة معروفة لا تحتاج إلى سطر أوامر، أو لقاعدة بيانات أدبيات غير متصلة.
