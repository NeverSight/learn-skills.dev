Webワークフロー向けに parallel-cli ツールを実行します：ウェブ検索、URL および PDF の抽出、深層調査レポート、提供された行の構造化データ強化、FindAll エンティティ発見、そして定期的なウェブモニタリング。科学的問い合わせでは一次文献や機関情報源を優先します。現在のウェブ証拠や限定された研究質問を調べる際に使用してください。既知の URL、PDF、または JavaScript でレンダリングされたページからコンテンツを取得する際に使用してください。企業、人物、製品のリストにウェブ由来のフィールドを追加する際に使用してください。自然言語の条件に合致するエンティティを発見する際に使用してください。明示的に包括的なマルチソースレポートが求められる場合に使用してください。定期的なスケジュールでウェブの変化を追跡する際に使用してください。一度きりの既知ページのチェックで CLI を必要としない場合や、オフラインの文献データベースには使用しないでください。
