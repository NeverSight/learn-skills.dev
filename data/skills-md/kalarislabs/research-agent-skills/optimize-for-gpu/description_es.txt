GPU acelera Python científico en hardware NVIDIA y verifica que el resultado sea correcto y más rápido. Úselo para optimización CUDA/GPU; cargas de trabajo con NumPy, SciPy, pandas, scikit-learn, NetworkX, scikit-image, búsqueda vectorial, procesamiento de imágenes, grafos, simulación o I/O de archivos que estén limitadas por la CPU; preguntas sobre CuPy, cuDF, cuML, cuGraph, cuVS, cuCIM, KvikIO, Warp, Newton, Numba-CUDA o RAFT; y cuellos de botella de perfilado, transferencia de memoria, kernel o multi‑GPU. También utilícelo cuando un código Python de gran paralelismo de datos sea lento y la aceleración por GPU sea una opción plausible, incluso si el usuario no menciona CUDA.
