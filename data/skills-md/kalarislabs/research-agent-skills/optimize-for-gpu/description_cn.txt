在 NVIDIA 硬件上对科学 Python 进行 GPU 加速，并验证结果既正确又更快。适用于 CUDA/GPU 优化；CPU 受限的 NumPy、SciPy、pandas、scikit-learn、NetworkX、scikit-image、向量搜索、图像处理、图、模拟或文件 I/O 工作负载；以及 CuPy、cuDF、cuML、cuGraph、cuVS、cuCIM、KvikIO、Warp、Newton、Numba‑CUDA 或 RAFT 相关问题；并处理分析、内存传输、内核或多 GPU 瓶颈。也可在大型数据并行 Python 代码运行缓慢且 GPU 加速是可行选项时使用，即使用户未提及 CUDA。
