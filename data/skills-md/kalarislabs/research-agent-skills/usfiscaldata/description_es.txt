Consulta la API REST de Datos Fiscales del Tesoro de EE. UU. para obtener datos financieros federales. No se requiere clave de API. Úsala para la deuda nacional (deuda al centavo), los estados diarios del Tesoro, los estados mensuales del Tesoro, las subastas de valores del Tesoro, tasas de interés, tipos de cambio, bonos de ahorro o las estadísticas de ingresos y gastos del gobierno de EE. UU.
