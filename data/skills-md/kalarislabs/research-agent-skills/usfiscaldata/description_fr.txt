Interrogez l'API REST Fiscal Data du Trésor américain pour obtenir des données financières fédérales. Aucune clé API n'est requise. Utilisez‑la pour la dette nationale (dette à la penny), les relevés quotidiens du Trésor, les relevés mensuels du Trésor, les enchères de titres du Trésor, les taux d'intérêt, les taux de change, les bons d'épargne ou les statistiques de revenus et de dépenses du gouvernement américain.

Veuillez toujours répondre dans la langue de l'utilisateur.
