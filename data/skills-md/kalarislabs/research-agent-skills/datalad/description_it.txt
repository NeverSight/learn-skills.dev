Recupera, versiona e pubblica dataset scientifici con DataLad e git‑annex, e cattura la provenienza computazionale con datalad run, rerun e containers‑run. Usalo quando cloni o scarichi dati da OpenNeuro, DANDI, datasets.datalad.org o qualsiasi dataset DataLad; quando un file in un dataset appare come un collegamento simbolico rotto o un piccolo puntatore anziché i dati reali; quando un’analisi necessita di un record leggibile da macchina su come è stato prodotto ciascun output, così da poterlo rieseguire; o quando pubblichi un dataset su repository gemelli, come un repository GitHub più un remoto di storage. Usalo anche per decidere tra DataLad e Git puro per un repository che contiene dati.
