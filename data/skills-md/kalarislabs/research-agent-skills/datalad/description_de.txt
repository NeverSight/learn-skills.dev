Abrufen, versionieren und veröffentlichen Sie wissenschaftliche Datensätze mit DataLad und git-annex und erfassen Sie die rechnerische Provenienz mit datalad run, rerun und containers‑run. Verwenden Sie das Werkzeug beim Klonen oder Abrufen von Daten von OpenNeuro, DANDI, datasets.datalad.org oder irgendeinem DataLad‑Datensatz; wenn eine Datei in einem Datensatz als defekter Symlink oder als kleiner Zeiger anstelle echter Daten angezeigt wird; wenn eine Analyse einen maschinenlesbaren Nachweis darüber benötigt, wie jedes Ergebnis erzeugt wurde, damit es erneut ausgeführt werden kann; oder wenn ein Datensatz zu „Siblings“ wie einem GitHub‑Repository plus einem Speicher‑Remote veröffentlicht wird. Nutzen Sie es zudem, um zwischen DataLad und reinem Git für ein daten­tragendes Repository zu entscheiden.
