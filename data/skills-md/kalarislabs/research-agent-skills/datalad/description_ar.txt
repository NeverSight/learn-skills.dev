استرجع، وقم بإصدار إصدارات، وانشر مجموعات البيانات العلمية باستخدام DataLad و git‑annex، وسجّل أصول الحوسبة باستخدام datalad run و rerun و containers‑run. استخدم ذلك عند استنساخ أو جلب البيانات من OpenNeuro أو DANDI أو datasets.datalad.org أو أي مجموعة بيانات DataLad؛ عندما يُظهر ملف في مجموعة البيانات كرمز ارتباط مكسور أو مؤشر صغير بدلاً من بيانات حقيقية؛ عندما يحتاج التحليل إلى سجل قابل للقراءة آليًا لكيفية إنتاج كل مخرج حتى يمكن إعادة تشغيله؛ أو عند نشر مجموعة بيانات إلى مستودعات شقيقة مثل مستودع GitHub بالإضافة إلى تخزين بعيد. استخدمه أيضًا لتحديد ما إذا كان يجب اختيار DataLad أو Git العادي لمستودع يحمل البيانات.
