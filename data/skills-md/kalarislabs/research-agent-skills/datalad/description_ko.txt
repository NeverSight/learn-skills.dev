DataLad와 git-annex를 사용하여 과학 데이터 세트를 검색·버전 관리·공개하고, datalad run, rerun, containers-run으로 계산 이력을 캡처합니다. OpenNeuro, DANDI, datasets.datalad.org 또는 기타 DataLad 데이터 세트에서 데이터를 복제하거나 가져올 때; 데이터 세트 내 파일이 실제 데이터가 아닌 깨진 심볼릭 링크나 작은 포인터로 표시될 때; 각 출력이 어떻게 생성되었는지 기계가 읽을 수 있는 기록이 필요해 다시 실행해야 할 때; 혹은 GitHub 저장소와 저장소 원격 등 형제 저장소에 데이터 세트를 발표할 때 사용합니다. 또한 데이터를 담은 저장소에 대해 DataLad와 일반 Git 중 어떤 방식을 선택할지 결정할 때도 활용합니다.
