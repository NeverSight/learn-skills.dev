Recupera, versiona y publica conjuntos de datos científicos con DataLad y git-annex, y captura la procedencia computacional con datalad run, rerun y containers‑run. Úsalo al clonar u obtener datos de OpenNeuro, DANDI, datasets.datalad.org o cualquier conjunto de datos de DataLad; cuando un archivo en un conjunto de datos aparece como un enlace simbólico roto o como un puntero pequeño en lugar de datos reales; cuando un análisis necesita un registro legible por máquina de cómo se produjo cada salida para poder volver a ejecutarlo; o al publicar un conjunto de datos en repositorios hermanos, como un repositorio de GitHub más un remoto de almacenamiento. También sirve para decidir entre DataLad y Git puro para un repositorio que transporta datos.
