Получайте, версионируйте и публикуйте научные наборы данных с помощью DataLad и git-annex, а также фиксируйте вычислительную провенанс с помощью datalad run, rerun и containers‑run. Используйте при клонировании или загрузке данных из OpenNeuro, DANDI, datasets.datalad.org или любого набора данных DataLad; когда файл в наборе данных отображается как битая символьная ссылка или небольший указатель вместо реальных данных; когда анализ требует машинно‑читаемую запись о том, как был получен каждый результат, чтобы его можно было переиспользовать; или при публикации набора данных в связанные репозитории, такие как репозиторий GitHub плюс удалённое хранилище. Также используйте для выбора между DataLad и обычным Git в репозитории, содержащем данные.
