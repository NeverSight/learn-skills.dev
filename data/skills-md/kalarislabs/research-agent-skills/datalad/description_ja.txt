DataLad と git‑annex を使って科学データセットを取得、バージョン管理、公開し、datalad run、rerun、containers‑run で計算の系譜（プロヴァンス）を記録します。OpenNeuro、DANDI、datasets.datalad.org、または任意の DataLad データセットからクローンやフェッチを行うとき、データセット内のファイルが壊れたシンボリックリンクや実データではなく小さなポインタとして表示されるとき、各出力がどのように生成されたかを機械可読な記録として保持し、再実行可能にしたい解析を行うとき、あるいは GitHub リポジトリとストレージリモートなどのシブリングにデータセットを公開するときに使用します。また、データを保持するリポジトリに対して DataLad と単なる Git のどちらを使用すべきか判断する際にも利用できます。
