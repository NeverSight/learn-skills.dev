Создаёт фигуры публикационного качества для статей по машинному обучению из исследовательского контекста. При наличии раздела статьи или описания извлекает компоненты системы и их взаимосвязи, чтобы генерировать архитектурные диаграммы с помощью Gemini. При наличии результатов экспериментов или данных автоматически выбирает тип графика и генерирует фигуры, основанные на данных, с помощью matplotlib/seaborn. Используйте при создании любой фигуры для конференционной статьи. Пожалуйста, всегда отвечайте на языке пользователя.
