Instructor Python ライブラリと Pydantic 応答モデルを使用して、LLM の応答から構造化された検証済みデータを抽出します。ネストされたモデル、列挙型、カスタムバリデータ、検証エラーのフィードバックによる自動リトライ、部分オブジェクトやイテラブルのストリーミングを含みます。Anthropic、OpenAI、ローカルの Ollama モデルで動作します。自由テキストから型付きフィールドやエンティティを取得したいとき、テキストを固定カテゴリに分類したいとき、LLM がスキーマ検証に合格する JSON を返す必要があるとき、抽出失敗時に自動リトライが必要なとき、または部分的な構造化結果をストリーミングしたいときに使用します。プロンプト最適化（DSPy を使用）やマルチステップチェーンの構築（LangChain を使用）には適しません。
