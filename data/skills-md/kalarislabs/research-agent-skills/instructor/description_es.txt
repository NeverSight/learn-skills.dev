Extrae datos estructurados y validados de respuestas de LLM usando la biblioteca Instructor de Python con modelos de respuesta Pydantic, incluidos modelos anidados, enumeraciones, validadores personalizados, reintentos automáticos con retroalimentación de errores de validación y transmisión de objetos parciales o iterables. Funciona con modelos de Anthropic, OpenAI y Ollama locales. Úsalo cuando extraes campos tipados o entidades de texto libre, cuando clasificas texto en categorías fijas, cuando un LLM debe devolver JSON que cumpla la validación de esquema, cuando se requieren reintentos automáticos tras extracciones fallidas o cuando se transmiten resultados estructurados parciales. No es para optimización de prompts (usa DSPy) ni para construir cadenas de varios pasos (usa LangChain).
