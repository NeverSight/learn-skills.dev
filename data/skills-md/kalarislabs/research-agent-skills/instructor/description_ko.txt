Instructor Python 라이브러리와 Pydantic 응답 모델을 사용하여 LLM 응답에서 구조화된 검증된 데이터를 추출합니다. 중첩 모델, 열거형(enum), 사용자 정의 검증기, 검증 오류 피드백을 통한 자동 재시도, 부분 객체 또는 반복 가능한 스트리밍을 포함합니다. Anthropic, OpenAI, 로컬 Ollama 모델에서 작동합니다. 자유 텍스트에서 유형화된 필드나 엔티티를 추출할 때, 텍스트를 고정 카테고리로 분류할 때, LLM이 스키마 검증을 통과하는 JSON을 반환해야 할 때, 추출 실패 시 자동 재시도가 필요할 때, 혹은 부분 구조화 결과를 스트리밍해야 할 때 사용합니다. 프롬프트 최적화(DSPy 사용)나 다단계 체인 구축(LangChain 사용)에는 적합하지 않습니다.
