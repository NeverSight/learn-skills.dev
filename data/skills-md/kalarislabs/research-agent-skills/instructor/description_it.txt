Estrae dati strutturati e convalidati dalle risposte delle LLM utilizzando la libreria Instructor per Python con modelli di risposta Pydantic, inclusi modelli nidificati, enum, validator personalizzati, tentativi automatici di nuovo con feedback sugli errori di validazione e streaming di oggetti o iterabili parziali. Funziona con i modelli Anthropic, OpenAI e Ollama locali. Da usare quando si estraggono campi tipizzati o entità da testo libero, quando si classificano testi in categorie fisse, quando una LLM deve restituire JSON che superi la validazione dello schema, quando le estrazioni fallite richiedono un nuovo tentativo automatico o quando si trasmettono risultati strutturati parziali in streaming. Non è destinato all'ottimizzazione dei prompt (usa DSPy) né alla creazione di catene multi‑step (usa LangChain). Rispondi sempre nella lingua dell'utente.
