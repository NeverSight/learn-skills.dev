Извлекает структурированные, проверенные данные из ответов LLM с использованием библиотеки Instructor для Python и моделей ответов Pydantic, включая вложенные модели, перечисления, пользовательские валидаторы, автоматические повторные запросы с обратной связью о ошибках валидации и потоковую передачу частичных объектов или итерируемых элементов. Работает с моделями Anthropic, OpenAI и локальными моделями Ollama. Используется при извлечении типизированных полей или сущностей из свободного текста, при классификации текста по фиксированным категориям, когда LLM должен возвращать JSON, проходящий схему валидации, при необходимости автоматического повторения неудачных извлечений либо при потоковой передаче частичных структурированных результатов. Не предназначено для оптимизации запросов (используйте DSPy) или построения многошаговых цепочек (используйте LangChain).  

Пожалуйста, всегда отвечайте на языке пользователя.
