Framework de aprendizaje automático cuántico agnóstico al hardware con diferenciación automática. Úsalo para entrenar circuitos cuánticos mediante gradientes, construir modelos híbridos cuántico‑clásicos o cuando necesites portabilidad entre dispositivos de IBM/Google/Rigetti/IonQ. Ideal para algoritmos variacionales (VQE, QAOA), redes neuronales cuánticas e integración con PyTorch o JAX. Para optimizaciones específicas de hardware utiliza qiskit (IBM) o cirq (Google); para sistemas cuánticos abiertos usa qutip.
