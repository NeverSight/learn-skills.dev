Библиотека Facebook для эффективного поиска сходства и кластеризации плотных векторов. Поддерживает миллиарды векторов, ускорение на GPU и различные типы индексов (Flat, IVF, HNSW). Используется для быстрого k‑NN‑поиска, крупномасштабного извлечения векторов или когда нужен чистый поиск сходства без метаданных. Лучшее решение для высокопроизводительных приложений.
