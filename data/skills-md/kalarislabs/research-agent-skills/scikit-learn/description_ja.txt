scikit-learn（sklearn）を用いた Python の古典的機械学習を網羅しています：分類および回帰推定器、クラスタリングと次元削減、前処理、Pipeline と ColumnTransformer、交差検証、評価指標、そして GridSearchCV によるハイパーパラメータチューニング。表形式データやテキストデータで分類器や回帰器を学習・比較する場合、データのクラスタリングやクラスタ数の選択、情報漏洩のない前処理パイプラインの構築、交差検証と指標によるモデル評価、またはハイパーパラメータのチューニングに使用してください。ディープラーニングには適していません。代わりに専用のニューラルネットワークフレームワークを使用してください。
