Modal es una plataforma en la nube sin servidor para ejecutar Python a demanda, incluyendo GPUs bajo demanda. Úsala al desplegar o servir modelos de IA/ML, ejecutar cargas de trabajo aceleradas por GPU (entrenamiento, ajuste fino, inferencia), servir puntos finales web, programar trabajos por lotes o escalar código Python a contenedores en la nube con el SDK de Modal.
