Modal — это безсерверная облачная платформа для запуска Python по запросу, включая GPU по требованию. Используйте её при развертывании или обслуживании моделей AI/ML, выполнении GPU‑ускоренных задач (обучение, донастройка, инференс), предоставлении веб‑эндпоинтов, планировании пакетных заданий или масштабировании кода Python в облачные контейнеры с помощью Modal SDK.
