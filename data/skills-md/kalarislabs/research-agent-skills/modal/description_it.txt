Modal è una piattaforma cloud serverless per eseguire Python su richiesta, inclusi GPU su richiesta. Usala quando distribuisci o servi modelli AI/ML, esegui carichi di lavoro accelerati da GPU (addestramento, fine‑tuning, inferenza), fornisci endpoint web, programmi lavori batch o scala il codice Python in contenitori cloud con l'SDK di Modal.
