Modal ist eine serverlose Cloud‑Plattform zum Ausführen von Python auf Abruf, einschließlich GPU auf Abruf. Verwenden Sie sie, wenn Sie KI/ML‑Modelle bereitstellen oder bedienen, GPU‑beschleunigte Workloads ausführen (Training, Feinabstimmung, Inferenz), Web‑Endpunkte bereitstellen, Batch‑Jobs planen oder Python‑Code mit dem Modal‑SDK zu Cloud‑Containern skalieren.
