Метод Anthropic по обучению безвредного ИИ через саморазвитие. Двухэтапный подход — контролируемое обучение с само‑критикой/пересмотром, затем RLAIF (обучение с подкреплением на основе обратной связи ИИ). Используется для согласования безопасности, снижения вредных выводов без человеческих меток. Обеспечивает работу системы безопасности Claude.
