El método de Anthropic para entrenar IA inofensiva mediante auto‑mejora. Enfoque de dos fases: aprendizaje supervisado con auto‑crítica/revisión, y luego RLAIF (aprendizaje por refuerzo a partir de retroalimentación de IA). Se usa para la alineación de seguridad, reduciendo salidas dañinas sin etiquetas humanas. Alimenta el sistema de seguridad de Claude.
