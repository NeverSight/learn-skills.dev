Библиотека низкоуровневой отрисовки графиков с полной настройкой. Используйте её, когда требуется детальный контроль над каждым элементом графика, создание новых типов графиков или интеграция с определёнными научными рабочими процессами. Экспортируйте в PNG/PDF/SVG для публикаций. Для быстрых статистических графиков используйте seaborn; для интерактивных — plotly; для готовых к публикации многостраничных фигур со стилем журнала — scientific-visualization.
