Librería de gráficos de bajo nivel para personalización completa. Úsala cuando necesites control detallado sobre cada elemento del gráfico, crear tipos de gráficos novedosos o integrarte con flujos de trabajo científicos específicos. Exporta a PNG/PDF/SVG para publicación. Para gráficos estadísticos rápidos utiliza seaborn; para gráficos interactivos usa plotly; para figuras multipanel listas para publicación con estilo de revista, usa scientific-visualization.
