Kit de herramientas del operador para flujos de trabajo nf-core/pacsomatic de tumor‑normal emparejados a partir de entradas BAM. Use esta habilidad cuando el usuario necesite validar los inputs de ejecución, generar hojas de muestra compatibles con pacsomatic, preparar artefactos reproducibles de lanzamiento de Nextflow, ejecutar localmente o enviarlos a planificadores (LSF/Slurm/PBS/SGE), y gestionar fallos de ejecución. Se activa con solicitudes para ejecutar pacsomatic, preparar comandos/scripts de lanzamiento, realizar verificaciones en modo seco o solucionar problemas de inicio del pipeline y errores de envío al planificador.
