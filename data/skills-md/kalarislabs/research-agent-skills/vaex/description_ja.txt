RAM に収まりきらない表形式データセットを、メモリマップされた HDF5 および Arrow ファイル上で遅延評価・アウト・オブ・コアの DataFrame を提供する Python ライブラリ Vaex を使用して処理・解析します。CSV と Parquet のインポート/エクスポートに対応しています。仮想列、フィルタリング、groupby 集計、大規模データのヒートマップやヒストグラム、vaex-ml のトランスフォーマー、PCA、K‑means をカバーします。数十ギガバイト規模の CSV/HDF5/Arrow/Parquet ファイルのオープンや変換、数十億行の高速統計計算、巨大データセットの可視化、メモリに収まらない機械学習パイプラインの構築、遅延評価と delay=True による遅い集計の高速化に利用してください。データが RAM に収まる場合は Polars、クラスター分散処理が必要な場合は Dask を選択してください。
