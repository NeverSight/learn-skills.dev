Verteilte Datenverarbeitung für größer-als-RAM-Pandas/NumPy-Workflows. Verwenden Sie es, wenn Sie vorhandenen Pandas/NumPy-Code über den Arbeitsspeicher hinaus oder über Cluster hinweg skalieren müssen. Ideal für parallele Dateiverarbeitung, verteilte ML, Integration mit vorhandenem PANDAS-Code. Für Out-of-Core-Analysen auf Einzelmaschinen verwenden Sie vaex; für In-Memory-Geschwindigkeit verwenden Sie Polare.
