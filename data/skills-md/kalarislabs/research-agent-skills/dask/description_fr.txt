Informatique distribuée pour les workflows de pandas/NumPy plus grands que la RAM. À utiliser lorsque vous devez faire évoluer le code existant des pandas/NumPy au-delà de la mémoire ou entre les clusters. Idéal pour le traitement de fichiers en parallèle, le ML distribué, l'intégration avec le code pandas existant. Pour les analyses out-of-core sur une seule machine, utilisez vaex ; pour la vitesse en mémoire, utilisez polars.
