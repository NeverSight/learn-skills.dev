Выполняет дифференциальный анализ экспрессии на данных подсчётов bulk RNA‑seq с помощью PyDESeq2, Python‑порта DESeq2. Поддерживает формульные одно‑ и многофакторные дизайны, контрасты, тесты Вальда, коррекцию ФДР методом Бенджамини‑Хохберга, необязательное сжатие LFC с помощью apeGLM, интеграцию с pandas и AnnData (H5AD), экспорт в CSV, построение вулканов и MA‑графиков, а также скрипт командной строки. Используется при сравнении экспрессии генов между условиями, например, обработка vs контроль, с учётом батчей или ковариат, при переносе рабочего процесса DESeq2 из R в Python или при построении Python‑конвейера для дифференциального анализа экспрессии из сырых целочисленных счётов. Не предназначено для данных одиночных клеток или самого DESeq2 на R.
