Genera imágenes con modelos Stable Diffusion (SD 1.5, SDXL, SD 3.0, Flux) mediante la biblioteca HuggingFace Diffusers, abarcando texto a imagen, imagen a imagen, inpainting, outpainting, condicionamiento con ControlNet, adaptadores LoRA, intercambio de scheduler y optimización de memoria GPU. Úsalo al generar imágenes a partir de prompts de texto, transformar o reenfocar una imagen existente, rellenar regiones enmascaradas de una imagen, añadir control espacial a partir de bordes, poses o mapas de profundidad, cargar adaptadores de estilo LoRA, o corregir errores de falta de memoria y de imágenes negras en una canalización Diffusers. No es para generación solo mediante API sin GPU, donde DALL‑E 3 es más adecuado.
