Genera immagini con i modelli Stable Diffusion (SD 1.5, SDXL, SD 3.0, Flux) tramite la libreria HuggingFace Diffusers, coprendo text‑to‑image, image‑to‑image, inpainting, outpainting, condizionamento ControlNet, adapter LoRA, scambio di scheduler e ottimizzazione della memoria GPU. Da usare quando si generano immagini da prompt testuali, si trasforma o si ri‑stile un’immagine esistente, si riempiono regioni mascherate di un’immagine, si aggiunge controllo spaziale da bordi, pose o mappe di profondità, si caricano adapter LoRA o si risolvono errori di out‑of‑memory e immagini nere in una pipeline Diffusers. Non è destinato a generazione solo tramite API senza GPU, dove DALL‑E 3 è più appropriato.
