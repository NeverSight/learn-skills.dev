Создаёт изображения с помощью моделей Stable Diffusion (SD 1.5, SDXL, SD 3.0, Flux) через библиотеку HuggingFace Diffusers, охватывая текст‑в‑изображение, изображение‑в‑изображение, инпейтинг, аутпейтинг, условие ControlNet, адаптеры LoRA, замену планировщика и оптимизацию видеопамяти GPU. Используйте при генерации изображений из текстовых подсказок, преобразовании или стилизации существующего изображения, заполнении маскированных областей изображения, добавлении пространственного контроля по краям, позам или картам глубины, загрузке LoRA‑адаптеров стиля или исправлении ошибок «out‑of‑memory» и чёрных изображений в конвейере Diffusers. Не предназначено для генерации только через API без GPU, где лучше подходит DALL‑E 3.
