Stable Diffusion（SD 1.5、SDXL、SD 3.0、Flux）モデルを使用し、HuggingFace Diffusers ライブラリ経由で画像を生成します。テキスト→画像、画像→画像、インペインティング、アウトペインティング、ControlNet 条件付け、LoRA アダプタ、スケジューラの切り替え、GPU メモリ最適化に対応しています。テキストプロンプトから画像を生成したり、既存の画像を変換・リスタイルしたり、画像のマスク領域を埋めたり、エッジ・ポーズ・深度マップから空間的制御を加えたり、LoRA スタイルアダプタをロードしたり、Diffusers パイプラインでのメモリ不足や黒画像エラーを修正したりする際に使用してください。GPU がなく API のみで生成する場合や、DALL‑E 3 の方が適しているケースでは使用しないでください。
