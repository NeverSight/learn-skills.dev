ML molecular con featurizadores diversos y conjuntos de datos preconstruidos. Úsalo para la predicción de propiedades (ADMET, toxicidad) con ML tradicional o GNNs cuando necesites opciones de featurización extensas y los benchmarks de MoleculeNet. Ideal para experimentos rápidos con modelos preentrenados y representaciones moleculares variadas. Para flujos de trabajo basados en gráficos con PyTorch utiliza torchdrug; para conjuntos de datos de referencia usa pytdc.
