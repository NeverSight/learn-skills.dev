ML moléculaire avec divers featuriseurs et ensembles de données pré-construits. À utiliser pour la prédiction des propriétés (ADMET, toxicité) avec les ML ou GNN traditionnels lorsque vous souhaitez des options de featurisation étendues et des repères MoleculeNet. Idéal pour des expériences rapides avec des modèles pré-entraînés, des représentations moléculaires diverses. Pour les flux de travail PyTorch axés sur les graphes, utilisez torchdrug ; pour les ensembles de données de référence, utilisez pytdc.
