Meta の LlamaGuard（7B v1、8B v2、v3）を使用して、LLM のプロンプトと応答を安全か危険かに分類します。分類は、暴力・ヘイト、性的コンテンツ、銃器・違法武器、規制対象物質、自殺・自己傷害、犯罪計画の 6 カテゴリに分けられます。HuggingFace Transformers と vLLM の推論、FastAPI のモデレーションエンドポイント、SageMaker デプロイ、NeMo Guardrails との統合をサポートします。LLM 呼び出し前のユーザープロンプトのフィルタリング、表示前のモデル出力のモデレーション、セルフホスト型モデレーション API の提供、あるいは vLLM や量子化によるモデレーションモデルのレイテンシ・GPU メモリ削減が必要なときに使用してください。偽陽性を削減するために閾値調整を行う場合にも有用です。よりシンプルなホスト型オプションが必要な場合は、代わりに OpenAI Moderation API を利用してください。
