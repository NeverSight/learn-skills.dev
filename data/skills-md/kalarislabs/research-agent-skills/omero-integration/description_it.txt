Ispeziona in modo sicuro e automatizza i flussi di lavoro dei dati di microscopia contro OMERO.server con omero-py, BlitzGateway, OMERO CLI, tabelle, annotazioni, ROI, rendering e le API documentate di OMERO.web. Usalo per un inventario OMERO a portata limitata, esportazione di metadati, pianificazione di import/export o flussi di lavoro di scrittura revisionati.
