Framework de datos para crear aplicaciones LLM con RAG. Se especializa en la ingestión de documentos (más de 300 conectores), indexación y consultas. Incluye índices vectoriales, motores de consulta, agentes y soporte multimodal. Úsalo para preguntas y respuestas sobre documentos, chatbots, recuperación de conocimiento o construcción de pipelines RAG. Ideal para aplicaciones LLM centradas en los datos.
