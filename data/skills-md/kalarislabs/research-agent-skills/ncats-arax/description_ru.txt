Запрашивает производственный API NCATS Translator ARAX для ограниченных, типизированных, богато документированных одношаговых и конечными точками зафиксированных двухшаговых биомедицинских отношений в графе знаний. Используйте для поиска в RTX‑KG2, ограниченного Biolink, явной федерации ARAX с выбранным поставщиком, отдельной нормализации сущностей, обхода графа с учётом квалификаторов и инспекции привязок рёбер TRAPI, публикаций и провенанса источников знаний. Не используйте для вывода, ранжирования, открытого поиска путей, клинических рекомендаций или чувствительных запросов.
