يُنشئ تمثيلات الجُمَل والنصوص والصور محليًا باستخدام مكتبة Python sentence‑transformers (SBERT)، مستفيدًا من نماذج Hugging Face المدربة مسبقًا مثل all‑MiniLM‑L6‑v2 وall‑mpnet‑base‑v2 والنُسخ المتعددة اللغات. يغطي الترميز، التشابه الكوسي، البحث الدلالي، الترميز على دفعات، الضبط الدقيق، وتكامل LangChain/LlamaIndex. يُستَخدم عند بناء تمثيلات لـ RAG، أو تشغيل بحث دلالي أو حساب تشابه، أو تجميع أو تصنيف النصوص، أو تمثيل نصوص متعددة اللغات دون واجهة برمجة تطبيقات، أو ضبط نموذج تمثيل على بيانات المجال. بالنسبة للتمثيلات المستندة إلى واجهة برمجة تطبيقات أو المُدارة، استخدم OpenAI أو Cohere Embed بدلاً من ذلك.
