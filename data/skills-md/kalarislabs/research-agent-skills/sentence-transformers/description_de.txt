Erzeugt Satz‑, Text‑ und Bild‑Embeddings lokal mit der Python‑Bibliothek sentence‑transformers (SBERT) und nutzt vortrainierte Hugging‑Face‑Modelle wie all‑MiniLM‑L6‑v2, all‑mpnet‑base‑v2 und mehrsprachige Varianten. Deckt das Codieren, Kosinus‑Ähnlichkeit, semantische Suche, Batch‑Codierung, Feinabstimmung sowie die Integration von LangChain/LlamaIndex ab. Verwenden Sie es, wenn Sie Embeddings für RAG erstellen, semantische Suche oder Ähnlichkeitsbewertung durchführen, Texte clustern oder klassifizieren, mehrsprachige Texte ohne API einbetten oder ein Embedding‑Modell anhand von Domain‑Daten feinabstimmen. Für API‑basierte oder verwaltete Embeddings verwenden Sie stattdessen OpenAI oder Cohere Embed.
