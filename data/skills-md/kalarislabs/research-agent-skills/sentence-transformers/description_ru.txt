Генерирует эмбеддинги предложений, текста и изображений локально с помощью библиотеки Python sentence‑transformers (SBERT), используя предобученные модели Hugging Face, такие как all‑MiniLM‑L6‑v2, all‑mpnet‑base‑v2 и их многократные варианты. Охватывает кодирование, косинусное сходство, семантический поиск, пакетное кодирование, дообучение и интеграцию с LangChain/LlamaIndex. Применяется при построении эмбеддингов для RAG, запуске семантического поиска или оценки схожести, кластеризации или классификации текста, эмбеддинге многоязычного текста без API, а также дообучении модели эмбеддингов на доменных данных. Для эмбеддингов на основе API или управляемыми используйте OpenAI или Cohere Embed вместо этого.  

Пожалуйста, всегда отвечайте на языке пользователя.
