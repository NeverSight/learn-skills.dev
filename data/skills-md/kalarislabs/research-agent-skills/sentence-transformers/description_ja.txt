Python の sentence‑transformers（SBERT）ライブラリを使用し、all‑MiniLM‑L6‑v2、all‑mpnet‑base‑v2、マルチリンガル バリアントなどの事前学習済み Hugging Face モデルを用いて、文・テキスト・画像の埋め込みをローカルで生成します。エンコーディング、余弦類似度、セマンティック検索、バッチエンコーディング、ファインチューニング、そして LangChain/LlamaIndex との統合をカバーしています。RAG の埋め込み作成、セマンティック検索や類似度スコアリング、テキストのクラスタリングや分類、API を使わずに多言語テキストを埋め込む、あるいはドメインデータで埋め込みモデルをファインチューニングする場合に使用してください。API ベースまたはマネージドな埋め込みが必要な場合は、OpenAI や Cohere Embed を利用してください。
