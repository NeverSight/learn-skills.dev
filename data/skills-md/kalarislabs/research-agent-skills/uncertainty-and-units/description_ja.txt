pint と uncertainties を使用して、科学計算における物理単位の追跡と測定不確かさの伝搬を行います。単位変換や次元チェック、GUM の不確かさ予算、Type A および Type B の評価、カバレッジ係数と拡大不確かさ、モンテカルロ伝搬、有意数字と ± 表記、曲線フィットを通じた誤差伝搬、CODATA 定数、単位が除去された Python コードや不確かさ伝搬の破損を監査、無次元数（レイノルズ数、ペクレ数、ダムコーレ数、ヌッケン数、ビオ数、ウォーマーズリー数）によるオーダー・オブ・マグニチュードの妥当性チェック、拡散時間やデバイ長さなどの特徴スケール、観測された大きさの範囲を使用します。「この数値は物理的に妥当か」「単位のサニティチェック」「この流れはどのレジームに属するか」またはオーダー・オブ・マグニチュードでずれている結果が出たときにトリガーします。
