Rastrea unidades físicas y propaga la incertidumbre de medida en cálculos científicos usando pint y uncertainties. Úsalo para conversión de unidades y verificación dimensional, presupuestos de incertidumbre GUM, evaluación Tipo A y Tipo B, factores de cobertura e incertidumbre ampliada, propagación Monte Carlo, reporte de cifras significativas y ±, propagación de errores a través de ajustes de curvas, constantes CODATA, auditoría de código Python para unidades eliminadas o propagación de incertidumbre defectuosa, y comprobaciones de plausibilidad de orden de magnitud mediante grupos adimensionales (Reynolds, Peclet, Damköhler, Knudsen, Biot, Womersley), escalas características como tiempo de difusión o longitud de Debye, y rangos de magnitud observados. Se activa con «¿es este número físicamente razonable?», «verifica la lógica de estas unidades», «¿en qué régimen está este flujo?» o cuando un resultado parece fuera de orden de magnitud.
