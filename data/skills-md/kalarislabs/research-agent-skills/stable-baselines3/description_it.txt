Algoritmi di reinforcement learning pronti per la produzione (PPO, SAC, DQN, TD3, DDPG, A2C) con API in stile scikit-learn. Usali per esperimenti RL standard, prototipazione rapida e implementazioni di algoritmi ben documentate. Ideale per RL a singolo agente con ambienti Gymnasium. Per addestramento parallelo ad alte prestazioni, sistemi multi‑agente o ambienti vettorizzati personalizzati, usa invece pufferlib. Per favore rispondi sempre nella lingua dell'utente.
