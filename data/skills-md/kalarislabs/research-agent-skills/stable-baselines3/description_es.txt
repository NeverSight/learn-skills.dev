Algoritmos de aprendizaje por refuerzo listos para producción (PPO, SAC, DQN, TD3, DDPG, A2C) con una API similar a scikit-learn. Úsalos para experimentos estándar de RL, prototipado rápido y implementaciones de algoritmos bien documentadas. Son ideales para RL de un solo agente con entornos Gymnasium. Para entrenamiento paralelo de alto rendimiento, sistemas multiagente o entornos vectorizados personalizados, utiliza pufferlib en su lugar.
