TileDB-VCF データセットにおいて、tiledbvcf Python API と CLI（create、store、export、list、stat）を使用してゲノム変異データの保存とクエリを行います。.csi または .tbi インデックス付きの単一サンプル VCF/BCF ファイルの取り込み、サンプルのインクリメンタルな追加、領域とサンプルの並列クエリ、ローカルディスクや S3、Azure、GCS 上での VCF/BCF または TSV へのエクスポートをカバーします。コホート向けの変異データベース構築、既存データセットへの新規サンプル追加、複数サンプルに跨る特定領域のクエリ、大規模 VCF コレクションからのサブセットエクスポート、アレル頻度や GWAS 入力などの集団ゲノミクスデータの準備に使用してください。マルチサンプル VCF は未対応であり、単一 VCF ファイルの一時的な解析には適していません。
