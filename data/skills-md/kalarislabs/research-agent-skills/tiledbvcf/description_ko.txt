TileDB-VCF 데이터 세트에 TileDBVCF Python API 및 CLI(생성, 저장, 내보내기, 목록, 통계)를 사용해 유전체 변이 데이터를 저장하고 쿼리합니다. .csi 또는 .tbi 인덱스가 있는 단일 샘플 VCF/BCF 파일을 ingest하고, 샘플을 점진적으로 추가하며, 지역 및 샘플을 병렬로 쿼리하고, 로컬 디스크 또는 S3, Azure, GCS에서 VCF/BCF 또는 TSV로 내보냅니다. 코호트용 변이 데이터베이스를 구축하거나, 기존 데이터 세트에 새로운 샘플을 추가하거나, 다수 샘플에 걸친 특정 영역을 쿼리하거나, 대규모 VCF 컬렉션의 일부를 내보내거나, 대립유전자 빈도나 GWAS 입력과 같은 집단 유전체학 데이터를 준비할 때 사용합니다. 다중 샘플 VCF는 지원되지 않으며, 단일 VCF 파일을 일회성으로 파싱하는 경우에도 사용하지 않습니다.
