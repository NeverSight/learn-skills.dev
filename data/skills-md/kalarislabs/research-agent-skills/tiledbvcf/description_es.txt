Almacena y consulta datos de variantes genómicas en conjuntos de datos TileDB‑VCF utilizando la API de Python tiledbvcf y la CLI (crear, almacenar, exportar, listar, stat). Cubre la ingestión de archivos VCF/BCF de una sola muestra con índices .csi o .tbi, la incorporación de muestras de forma incremental, la consulta de regiones y muestras en paralelo, y la exportación a VCF/BCF o TSV, tanto en disco local como en S3, Azure y GCS. Úselo al crear una base de datos de variantes para una cohorte, al añadir nuevas muestras a un conjunto de datos existente, al consultar regiones específicas en muchas muestras, al exportar subconjuntos de una gran colección de VCF, o al preparar datos de genómica poblacional como frecuencias alélicas o entradas para GWAS. No es para VCF multi‑muestra, que no están soportados, ni para el análisis puntual de un único archivo VCF.
