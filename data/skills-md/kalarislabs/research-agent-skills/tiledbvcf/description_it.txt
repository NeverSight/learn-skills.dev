Memorizza e interroga i dati di varianti genomiche nei dataset TileDB-VCF utilizzando l'API Python e la CLI tiledbvcf (create, store, export, list, stat). Copre l'ingestione di file VCF/BCF a campione singolo con indici .csi o .tbi, l'aggiunta incrementale di campioni, l'interrogazione di regioni e campioni in parallelo e l'esportazione in VCF/BCF o TSV, su disco locale o su S3, Azure e GCS. Da utilizzare quando si costruisce un database di varianti per una coorte, si aggiungono nuovi campioni a un dataset esistente, si interrogano regioni specifiche su molti campioni, si esportano sottoinsiemi di una grande collezione di VCF o si prepara la genomica di popolazione, ad esempio frequenze alleliche o input per GWAS. Non è adatto per VCF multi‑campione, che non sono supportati, né per l'analisi una tantum di un singolo file VCF.
