Высокопроизводительная библиотека DataFrame для Python ETL, аналитики и миграции с pandas. Используется для манипулирования данными на основе выражений с ленивой оптимизацией запросов, параллельным выполнением, потоковой обработкой данных вне памяти, совместимости с Arrow и опционального выполнения на GPU.
