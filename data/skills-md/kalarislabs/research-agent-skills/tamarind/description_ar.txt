احصل على مجموعة من أدوات التصميم الجزيئي والبيولوجيا الهيكلية مفتوحة المصدر على منصة Tamarind Bio، عبر واجهة REST API أو خادم MCP — دون الحاجة إلى وحدات معالجة رسومية محلية. تجمع Tamarind نماذج مفتوحة المصدر شائعة للتنبؤ بالهيكل (AlphaFold، Boltz، Chai، ESMFold)، وتصميم البروتين، والروابط، وتصميم de novo (RFdiffusion، ProteinMPNN، BoltzGen)، وتصميم الأجسام المضادة والنانو أجسام المضادة وتقييم قابلية التطوير، وتراكم البروتين‑الليغاند (DiffDock، Autodock Vina)، وتنبؤ ارتباطية التفاعل، وتوليد MSA، والمحاكاة الديناميكية الجزيئية. استخدمها عندما يذكر المستخدم Tamarind أو tamarind.bio، أو يرغب في تشغيل أي من هذه الأدوات المفتوحة المصدر في السحابة، أو يشير إلى app.tamarind.bio/api أو رأس x‑api‑key، أو يحتاج إلى تقديم دفعات من التسلسلات للتوصيف الهيكلي أو الفيزيولوجي الحيوي.
