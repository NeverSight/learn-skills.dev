通过 Tamarind Bio 平台的 REST API 或 MCP 服务器访问一系列开源分子设计和结构生物学工具——无需本地 GPU。Tamarind 整合了流行的开源模型用于结构预测（AlphaFold、Boltz、Chai、ESMFold）、蛋白质、结合体和全新设计（RFdiffusion、ProteinMPNN、BoltzGen）、抗体和纳米抗体设计与可开发性、蛋白质-配体对接（DiffDock、Autodock Vina）、结合亲和力预测、MSA 生成以及分子动力学。当用户提及 Tamarind 或 tamarind.bio，想在云端运行这些开源工具，引用 app.tamarind.bio/api 或 x‑api‑key 头部，或需要提交批量序列进行结构或生物物理特性表征时，请使用。
