透過 REST API 或 MCP 伺服器，於 Tamarind Bio 平台上存取一系列開源分子設計與結構生物學工具 — 無需本地 GPU。Tamarind 整合了熱門的開源模型，用於結構預測（AlphaFold、Boltz、Chai、ESMFold）、蛋白質、結合體與全新設計（RFdiffusion、ProteinMPNN、BoltzGen）、抗體與納米抗體設計與可開發性、蛋白質‑配體對接（DiffDock、Autodock Vina）、結合親和力預測、MSA 生成，以及分子動力學。當使用者提及 Tamarind 或 tamarind.bio、希望在雲端執行任何這些開源工具、引用 app.tamarind.bio/api 或 x‑api‑key 標頭，或需要提交大量序列以進行結構或生物物理特性分析時，請使用本功能。請始終以使用者的語言回覆。
