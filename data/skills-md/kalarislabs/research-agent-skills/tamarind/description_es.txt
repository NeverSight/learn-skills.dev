Acceda a una colección de herramientas de diseño molecular y biología estructural de código abierto en la plataforma Tamarind Bio, a través de su API REST o servidor MCP — sin necesidad de GPU locales. Tamarind incluye modelos de código abierto populares para predicción de estructuras (AlphaFold, Boltz, Chai, ESMFold), diseño de proteínas, ligandos y de novo (RFdiffusion, ProteinMPNN, BoltzGen), diseño y desarrollabilidad de anticuerpos y nanocuerpos, acoplamiento proteína‑ligando (DiffDock, Autodock Vina), predicción de afinidad de unión, generación de MSA y dinámica molecular. Úselo cuando el usuario mencione Tamarind o tamarind.bio, quiera ejecutar alguna de estas herramientas de código abierto en la nube, haga referencia a app.tamarind.bio/api o al encabezado x‑api‑key, o necesite enviar lotes de secuencias para caracterización estructural o biofísica.
