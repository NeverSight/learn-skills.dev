Crea, migliora e testa le skill degli agenti per i flussi di lavoro di ricerca (scrittura di articoli, protocolli di laboratorio, pipeline di analisi, database di dominio) che soddisfano la specifica Agent Skills e gli standard di qualità e sicurezza di questo repository. Usalo quando trasformi un compito di ricerca ricorrente in una skill riutilizzabile, contributi con una nuova skill a Research Agent Skills, riscrivi una skill esistente, redigi descrizioni precise rispetto ai trigger o aggiungi valutazioni. Funziona in sinergia con il creatore di skill ufficiale di Anthropic.

Per favore rispondi sempre nella lingua dell'utente.
