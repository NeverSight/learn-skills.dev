Diseña hardware de laboratorio personalizado como modelos paramétricos con build123d y exporta archivos STEP, STL y DXF listos para fabricación: chips y moldes microfluídicos, montajes optomecánicos y adaptadores para protoboard, soportes para cubetas y microplacas, bandejas para tubos, rigs de comportamiento animal y fijaciones de instrumentos impresas en 3D. Úsalo cuando una tarea de investigación requiera una pieza física que deba acoplarse con material de laboratorio estandarizado, una mesa óptica, un sistema de jaulas o un proceso de impresión, CNC o láser.
