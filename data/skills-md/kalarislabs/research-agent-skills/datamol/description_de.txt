Wraps RDKit durch die Python‑Bibliothek datamol (import datamol as dm) für molekulare Cheminformatik und gibt native rdkit.Chem.Mol‑Objekte zurück. Deckt die Konvertierung von SMILES/SELFIES/InChI, Sanitization und Standardisierung, Deskriptoren, Fingerabdrücke und Ähnlichkeiten, Butina‑Clustering und Auswahl diverser Teilmengen, Bemis‑Murcko‑Gerüste, BRICS/RECAP‑Fragmentierung, 3‑D‑Konformer, Reaktionen, SDF/CSV/Excel‑I/O inklusive Cloud‑Pfade sowie parallele Batch‑Verarbeitung ab. Verwenden Sie es, wenn Sie SMILES aus externen Quellen parsen oder standardisieren, Deskriptoren oder Fingerabdrücke für eine Verbindungssammlung berechnen, Moleküle clustern oder diverse Moleküle auswählen, scaffold‑basierte Train/Test‑Aufteilungen erstellen oder Konformer generieren wollen. Verwenden Sie es, wenn Sie eine Molekül‑Verarbeitungspipeline mit n_jobs ausführen. Für feinkörnige Steuerung oder benutzerdefinierte Parameter nutzen Sie stattdessen direkt RDKit.
