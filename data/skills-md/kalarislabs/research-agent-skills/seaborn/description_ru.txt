Статистическая визуализация с интеграцией pandas. Используется для быстрой разведки распределений, взаимосвязей и категориальных сравнений с красивыми настройками по умолчанию. Наилучшим образом подходит для ящиковых графиков, скрипичных графиков, парных графиков, тепловых карт. Основано на matplotlib. Для интерактивных графиков используйте plotly; для оформления публикаций — scientific-visualization.
