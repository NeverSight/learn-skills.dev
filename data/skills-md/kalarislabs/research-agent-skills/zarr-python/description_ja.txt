Zarr-Python 3 を使用して、チャンク化された圧縮 N 次元配列やグループをローカル、メモリ上、ZIP、fsspec に対応した S3／GCS／HTTP ストアに保存する方法を指南します。また、NumPy、Dask、Xarray との連携もサポートします。配列の作成、サイズ変更、追記、属性、チャンクおよびシャードのサイズ設定、コーデック、統合メタデータ、そして v2 から v3 への移行について解説します。以下の場合に使用してください。

- Zarr 配列またはグループを作成・開くとき  
- 大規模データセットのチャンクサイズや圧縮方式を選択するとき  
- S3 や GCS 上で配列を読み書きするとき  
- 時系列配列にデータを追記するとき  
- Zarr-Python 2 から 3 へコードを移行するとき  

Dask や Xarray を用いた並列 I/O を設定する際にも利用できます。ラベル付き多次元データセットを扱う場合は、Xarray を使用してください。
