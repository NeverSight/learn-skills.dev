指導 Zarr-Python 3 用於儲存分塊、壓縮的 N 維陣列與群組，支援本機、記憶體內、ZIP 以及以 fsspec 為基礎的 S3/GCS/HTTP 儲存，並可與 NumPy、Dask、Xarray 整合。涵蓋陣列的建立、重新調整大小與追加、屬性、分塊與分片大小、編解碼器、合併的中繼資料，以及 v2 到 v3 的遷移。適用於建立或開啟 Zarr 陣列或群組、為大型資料集選擇分塊大小或壓縮、在 S3 或 GCS 上讀寫陣列、對時間序列陣列追加資料，或將程式碼從 Zarr-Python 2 移植至 3。亦適用於使用 Dask 或 Xarray 設定平行 I/O。對於具標籤的多維資料集，請改用 Xarray。
