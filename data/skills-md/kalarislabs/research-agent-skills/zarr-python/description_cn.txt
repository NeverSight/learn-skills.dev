本指南介绍 Zarr-Python 3 的使用，用于存储分块、压缩的 N 维数组和组，支持本地、内存、ZIP 以及基于 fsspec 的 S3/GCS/HTTP 存储，并集成 NumPy、Dask 和 Xarray。内容涵盖数组创建、大小调整和追加、属性、块和分片大小、编解码器、合并元数据以及 v2‑to‑v3 迁移。适用于创建或打开 Zarr 数组或组、为大数据集选择块大小或压缩、在 S3 或 GCS 上读取或写入数组、向时间序列数组追加数据，或将代码从 Zarr‑Python 2 迁移到 3。也适用于使用 Dask 或 Xarray 设置并行 I/O。对于带标签的多维数据集，请使用 Xarray。
