دليل استخدام Zarr-Python 3 لتخزين المصفوفات متعددة الأبعاد المقسَّمة إلى شرائح ومضغوطة، والمجموعات، مع مخازن محلية، وفي الذاكرة، وZIP، ومخازن مدعومة بـ fsspec مثل S3/GCS/HTTP، بالإضافة إلى التكامل مع NumPy وDask وXarray. يغطي إنشاء المصفوفات، تعديل حجمها وإلحاق البيانات، السمات، حجم الشرائح والشرائح الفرعية، المشفرات، البيانات الوصفية المجمعة، وترحيل الإصدار 2 إلى 3. يُستخدم عند إنشاء أو فتح مصفوفات أو مجموعات Zarr، واختيار أحجام الشرائح أو الضغط للبيانات الكبيرة، وقراءة أو كتابة المصفوفات على S3 أو GCS، وإلحاق بيانات السلاسل الزمنية، أو ترحيل الكود من Zarr-Python 2 إلى 3. يُستخدم عند إعداد الإدخال/الإخراج المتوازي مع Dask أو Xarray. بالنسبة لمجموعات البيانات متعددة الأبعاد الموسومة، استخدم Xarray بدلاً من ذلك.
