Leitet die Verwendung von Zarr‑Python 3 zum Speichern von chunkweise, komprimierten N‑dimensionalen Arrays und Gruppen an, mit lokalen, im Speicher, ZIP‑ und fsspec‑gestützten S3‑/GCS‑/HTTP‑Speichern sowie NumPy‑, Dask‑ und Xarray‑Integration. Behandelt die Array‑Erstellung, Größenanpassung und das Anhängen, Attribute, Chunk‑ und Shard‑Größen, Codecs, konsolidierte Metadaten und die Migration von v2 zu v3. Verwenden Sie es beim Erstellen oder Öffnen von Zarr‑Arrays oder –Gruppen, beim Auswählen von Chunk‑Größen oder Kompression für große Datensätze, beim Lesen oder Schreiben von Arrays auf S3 oder GCS, beim Anhängen an Zeitreihen‑Arrays oder beim Migrieren von Code von Zarr‑Python 2 zu 3. Verwenden Sie es beim Einrichten von parallelem I/O mit Dask oder Xarray. Für gekennzeichnete mehrdimensionale Datensätze verwenden Sie stattdessen Xarray.
