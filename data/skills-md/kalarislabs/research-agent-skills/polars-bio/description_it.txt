Libreria Python polars-bio per operazioni su intervalli genomici e I/O di file bioinformatici su DataFrame Polars, costruita su Arrow e DataFusion. Include sovrapposizione, intervallo più vicino, merge, clustering, copertura, complemento, sottrazione, count_overlaps, profondità pileup per base e lettura/scansione/scrittura di BED, VCF, BAM, CRAM, SAM, GFF/GTF, FASTA, FASTQ, oltre a query SQL su questi file. Da usare quando si intersecano o si fondono intervalli genomici in Polars. Da usare quando si leggono o si trasmettono in streaming grandi file BED, VCF o BAM, anche da S3, GCS o Azure. Da usare quando si calcola la profondità di lettura da BAM o CRAM. Da usare quando si eseguono query SQL su file genomici. Da usare quando si migra codice bioframe verso un’alternativa più veloce. Non è adatta a workflow solo pandas che non utilizzano Polars o DataFusion.
