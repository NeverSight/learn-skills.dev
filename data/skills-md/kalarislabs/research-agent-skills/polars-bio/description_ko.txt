Python 라이브러리 polars-bio는 Arrow와 DataFusion 위에 구축된 Polars DataFrame에서 유전체 구간 연산 및 생물정보학 파일 I/O를 제공합니다. 겹침(overlap), 가장 가까운 구간(nearest), 병합(merge), 클러스터(cluster), 커버리지(coverage), 보완(complement), 차집합(subtract), 겹침 개수(count_overlaps), 염기별 pileup 깊이, 그리고 BED, VCF, BAM, CRAM, SAM, GFF/GTF, FASTA, FASTQ 파일의 읽기·스캔·쓰기와 이들 파일에 대한 SQL 쿼리를 지원합니다. Polars에서 유전체 구간을 교차하거나 병합할 때 사용하세요. S3, GCS, Azure 등에서 대용량 BED, VCF, BAM 파일을 읽거나 스트리밍할 때 사용하세요. BAM 또는 CRAM에서 읽기 깊이를 계산할 때 사용하세요. 유전체 파일에 대해 SQL을 실행할 때 사용하세요. bioframe 코드를 더 빠른 대안으로 마이그레이션할 때 사용하세요. Polars나 DataFusion을 사용하지 않는 pandas 전용 워크플로에는 적합하지 않습니다.
