Python 函式庫 polars-bio 用於在 Polars DataFrames 上執行基因組區間操作與生物資訊檔案 I/O，基於 Arrow 和 DataFusion 建置。支援 overlap、nearest、merge、cluster、coverage、complement、subtract、count_overlaps、逐鹼基 pileup 深度，並能讀取、掃描、寫入 BED、VCF、BAM、CRAM、SAM、GFF/GTF、FASTA、FASTQ 等檔案，同時支援對這些檔案的 SQL 查詢。適合在 Polars 中交叉或合併基因組區間時使用。適合讀取或串流大型 BED、VCF 或 BAM 檔案，包括來自 S3、GCS 或 Azure 的情況。適合從 BAM 或 CRAM 計算讀取深度時使用。適合在基因組檔案上執行 SQL 時使用。適合將 bioframe 程式碼遷移至更快速的替代方案時使用。不適用於僅使用 pandas 且不使用 Polars 或 DataFusion 的工作流程。
