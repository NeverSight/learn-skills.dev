Python库 polars-bio 用于在 Polars DataFrame 上进行基因组区间操作和生物信息学文件 I/O，基于 Arrow 和 DataFusion 构建。支持 overlap、nearest、merge、cluster、coverage、complement、subtract、count_overlaps、per-base pileup depth，以及对 BED、VCF、BAM、CRAM、SAM、GFF/GTF、FASTA、FASTQ 的读取/扫描/写入，还可对这些文件执行 SQL 查询。适用于在 Polars 中进行基因组区间的交叉或合并。适用于读取或流式处理大型 BED、VCF 或 BAM 文件，包括来自 S3、GCS 或 Azure 的文件。适用于从 BAM 或 CRAM 计算读取深度。适用于在基因组文件上运行 SQL。适用于将 bioframe 代码迁移到更快的替代方案。不适用于仅使用 pandas 且不使用 Polars 或 DataFusion 的工作流。
