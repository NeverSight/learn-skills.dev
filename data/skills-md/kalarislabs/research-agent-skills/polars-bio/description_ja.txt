Polars DataFrames 上でゲノム区間操作とバイオインフォマティクスファイル I/O を行う Python ライブラリ polars‑bio。Arrow と DataFusion 上に構築されています。overlap、nearest、merge、cluster、coverage、complement、subtract、count_overlaps、per‑base pileup depth などをサポートし、BED、VCF、BAM、CRAM、SAM、GFF/GTF、FASTA、FASTQ の読み取り/スキャン/書き込み、さらにそれらのファイルに対する SQL クエリも可能です。Polars でゲノム区間を交差させたりマージしたりする際に使用してください。S3、GCS、Azure からの大規模な BED、VCF、BAM ファイルの読み取りやストリーミングにも適しています。BAM や CRAM からリード深度を計算する際にも利用できます。ゲノムファイル上で SQL を実行する場合にも使用できます。高速な代替手段として bioframe のコードを移行する際にも便利です。Polars や DataFusion を使用しない pandas のみのワークフローには適していません。
