Inferir redes regulatorias de genes (GRNs) a partir de datos de expresión génica usando algoritmos escalables (GRNBoost2, GENIE3). Úselo al analizar datos transcriptómicos (RNA‑seq en lote, RNA‑seq de una sola célula) para identificar relaciones entre factores de transcripción y genes objetivo e interacciones regulatorias. Soporta cómputo distribuido para conjuntos de datos a gran escala.
