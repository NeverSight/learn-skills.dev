Конвертирует документы в Markdown с помощью Microsoft MarkItDown (Python API, CLI markitdown, плагин markitdown‑ocr, сервер markitdown‑mcp), поддерживая PDF, Word, PowerPoint, Excel, HTML, CSV, EPUB, ZIP и потоки, а также извлечение из Azure. Используйте при подготовке статей или отчётов для загрузки в LLM/RAG; при пакетном преобразовании папки с литературой в Markdown с указанием происхождения; при конвертации загруженных байтов или файловых потоков; когда требуется OCR отсканированных PDF или текста на изображениях; при предоставлении конвертации локальному агенту через MCP. Не используйте для получения ограничивающих рамок или координат страниц (используйте LiteParse) или для объединения/разделения/форм PDF (используйте навык pdf).
