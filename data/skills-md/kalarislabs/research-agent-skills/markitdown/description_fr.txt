Convertit les documents en Markdown avec Microsoft MarkItDown (API Python, CLI markitdown, plugin markitdown-ocr, serveur markitdown-mcp), couvrant PDF, Word, PowerPoint, Excel, HTML, CSV, EPUB, ZIP et flux, ainsi que l’extraction Azure. À utiliser lors de la préparation de documents ou de rapports pour l’ingestion LLM/RAG ; lors de la conversion en lot d’un dossier de littérature en Markdown avec traçabilité ; lors de la conversion de bytes ou de flux de fichiers téléchargés ; lorsqu’une OCR de PDF scannés ou de texte d’image est nécessaire ; lors de l’exposition de la conversion à un agent local via MCP. Ne pas utiliser pour les boîtes englobantes ou les coordonnées de page (utiliser LiteParse) ou la fusion/partition/formulaires PDF (utiliser la compétence pdf).
