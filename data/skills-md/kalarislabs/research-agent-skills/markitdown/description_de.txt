Wandelt Dokumente mit Microsoft MarkItDown (Python‑API, markitdown‑CLI, markitdown‑ocr‑Plugin, markitdown‑mcp‑Server) in Markdown um und unterstützt PDF, Word, PowerPoint, Excel, HTML, CSV, EPUB, ZIP und Streams sowie Azure‑Extraktion. Verwenden Sie es, wenn Sie Texte oder Berichte für die LLM/RAG‑Eingabe vorbereiten; wenn Sie einen Literaturordner stapelweise in Markdown mit Herkunftsinformationen konvertieren; wenn Sie hochgeladene Bytes oder Dateistreams umwandeln; wenn eine OCR von gescannten PDFs oder Bildtexten nötig ist; wenn Sie die Konvertierung über MCP einem lokalen Agenten bereitstellen. Nicht verwenden für Begrenzungsrahmen oder Seitenkoordinaten (verwenden Sie LiteParse) oder für PDF‑Zusammenführen‑/‑Teilen‑/‑Formulare (verwenden Sie die PDF‑Fähigkeit).
