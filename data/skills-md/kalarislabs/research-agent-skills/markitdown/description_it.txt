Converte documenti in Markdown con Microsoft MarkItDown (API Python, CLI markitdown, plugin markitdown-ocr, server markitdown-mcp), coprendo PDF, Word, PowerPoint, Excel, HTML, CSV, EPUB, ZIP e flussi, oltre all’estrazione Azure. Da usare quando si preparano articoli o rapporti per l’ingestione LLM/RAG; quando si converte in batch una cartella di letteratura in Markdown con provenienza; quando si convertono byte o flussi di file caricati; quando è necessario l’OCR di PDF scansionati o testo da immagini; quando si espone la conversione a un agente locale tramite MCP. Non utilizzare per riquadri di delimitazione o coordinate di pagina (usare LiteParse) o per unire/dividere/moduli PDF (usare la skill pdf).
