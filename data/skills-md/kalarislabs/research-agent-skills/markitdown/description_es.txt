Convierte documentos a Markdown con Microsoft MarkItDown (API de Python, CLI markitdown, plugin markitdown-ocr, servidor markitdown-mcp), abarcando PDF, Word, PowerPoint, Excel, HTML, CSV, EPUB, ZIP y flujos, además de extracción en Azure. Úsalo al preparar artículos o informes para ingestión LLM/RAG; al convertir en lote una carpeta de literatura a Markdown con procedencia; al convertir bytes cargados o flujos de archivos; cuando se necesita OCR de PDFs escaneados o texto de imágenes; al exponer la conversión a un agente local mediante MCP. No lo uses para cajas delimitadoras o coordenadas de página (usa LiteParse) o para combinar/dividir/formularios PDF (usa la habilidad pdf).
