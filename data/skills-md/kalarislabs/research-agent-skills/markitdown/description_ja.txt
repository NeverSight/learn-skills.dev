Microsoft MarkItDown（Python API、markitdown CLI、markitdown-ocr プラグイン、markitdown-mcp サーバー）を使用して、PDF、Word、PowerPoint、Excel、HTML、CSV、EPUB、ZIP、ストリーム、さらに Azure 抽出を含むドキュメントを Markdown に変換します。LLM/RAG へのインジェスト用に論文やレポートを準備する際、出典情報付きで文献フォルダーを一括で Markdown に変換する際、アップロードされたバイトやファイルストリームを変換する際、スキャンした PDF や画像テキストの OCR が必要なとき、MCP を介してローカルエージェントに変換機能を提供する際に使用してください。バウンディングボックスやページ座標の取得（LiteParse を使用）や PDF の結合・分割・フォーム処理（pdf スキルを使用）には使用しないでください。
