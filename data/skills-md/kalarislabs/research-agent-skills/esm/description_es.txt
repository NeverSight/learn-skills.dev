Cubre el SDK de Python EvolutionaryScale/Biohub `esm`: diseño generativo de proteínas con ESM3 (pistas de secuencia, estructura y función, cadena de pensamiento), incrustaciones ESMC, plegado inverso, predicción de estructura con ESMFold2 e inferencia alojada en Forge/Biohub con ESM_API_KEY. Úsese al generar o completar proteínas con ESM3, extraer incrustaciones ESMC para clasificación o similitud, plegar una secuencia o diseñar secuencias a partir de una estructura, o elegir entre los modelos esm3-open, esmc_300m y los alojados en Forge. Úsese al agrupar llamadas asíncronas a la API de Forge o Biohub. No es para otros modelos de proteínas como AlphaFold o uso genérico de transformers de Hugging Face.
