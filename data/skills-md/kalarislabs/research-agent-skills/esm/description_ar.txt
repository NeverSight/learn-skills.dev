يغطي مجموعة أدوات Python SDK الخاصة بـ EvolutionaryScale/Biohub `esm`: تصميم بروتيني توليدي باستخدام ESM3 (مسارات التسلسل، الهيكل والوظيفة، تفكير السلسلة)، تضمينات ESMC، الطي العكسي، توقع الهيكل باستخدام ESMFold2، والاستدلال المستضاف عبر Forge/Biohub باستخدام ESM_API_KEY. يُستخدم عند توليد أو إكمال البروتينات باستخدام ESM3، استخراج تضمينات ESMC للتصنيف أو التشابه، طي تسلسل أو تصميم تسلسلات من هيكل، أو الاختيار بين نماذج esm3-open و esmc_300m والنماذج المستضافة عبر Forge. يُستخدم عند تجميع طلبات Forge أو Biohub API غير المتزامنة. غير مخصص للنماذج البروتينية الأخرى مثل AlphaFold أو الاستخدام العام لمحوّلات Hugging Face.
