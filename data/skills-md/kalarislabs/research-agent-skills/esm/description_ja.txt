EvolutionaryScale/Biohub の `esm` Python SDK を対象としています：ESM3 の生成的タンパク質設計（配列、構造、機能トラック、チェーン・オブ・ソート）、ESMC 埋め込み、逆フォールディング、ESMFold2 構造予測、そして ESM_API_KEY を使用した Forge/Biohub のホスト推論です。ESM3 でタンパク質を生成・補完する際、分類や類似性のために ESMC 埋め込みを抽出する際、配列をフォールドさせたり構造から配列を設計したり、esm3-open、esmc_300m、Forge ホストモデルのいずれかを選択する際に使用してください。非同期の Forge または Biohub API 呼び出しをバッチ処理する場合に使用します。AlphaFold などの他のタンパク質モデルや、一般的な Hugging Face トランスフォーマーの使用には適しません。
