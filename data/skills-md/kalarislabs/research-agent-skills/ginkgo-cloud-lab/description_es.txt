Envíe y gestione protocolos en Ginkgo Bioworks Cloud Lab (cloud.ginkgo.bio), una interfaz web para la ejecución autónoma de laboratorios en Carros de Automatización Reconfigurables (RAC). Úselo cuando el usuario desee realizar expresión y purificación de proteínas (sin células, E. coli o Pichia), cuantificación HiBiT o A280 o LabChip, síntesis de ARNm/ARNc circular, ensayos de desplazamiento térmico / desarrollabilidad, métodos de enzimas o analitos Echo‑MS, incorporación de objetivos SPR, arte pixelado fluorescente, o cualquier otra interacción con los servicios de Ginkgo Cloud Lab. Cubre la selección de protocolos, preparación de insumos, precios y flujos de trabajo de pedidos.
