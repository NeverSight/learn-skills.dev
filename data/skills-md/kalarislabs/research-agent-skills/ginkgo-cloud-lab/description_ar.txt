قم بتقديم وإدارة البروتوكولات على منصة سحابة Ginkgo Bioworks Cloud Lab (cloud.ginkgo.bio)، وهي واجهة ويب للتنفيذ المستقل للتجارب على العربات الآلية القابلة لإعادة التكوين (RACs). استخدمها عندما يرغب المستخدم في تشغيل تعبير وتنقية البروتين (بدون خلايا أو E. coli أو Pichia)، أو قياس HiBiT أو A280 أو LabChip، أو تخليق mRNA/ circRNA باستخدام IVT، أو اختبارات الانزياح الحراري/القابلية للتطوير، أو طرق إنزيمية أو تحليلية Echo‑MS، أو إدخال أهداف SPR، أو فن البكسل الفلوري، أو أي تفاعل آخر مع خدمات سحابة Ginkgo Cloud Lab. تشمل العملية اختيار البروتوكول، إعداد المدخلات، التسعير، وإجراءات الطلب.
