Analyse statistique guidée pour les données de recherche – sélection de tests, vérification des hypothèses, tailles d’effet, analyse de puissance, alternatives bayésiennes et compte rendu au format APA. Utilisez‑la chaque fois qu’un utilisateur souhaite comparer des groupes, tester une hypothèse, analyser des données expérimentales ou d’enquête, vérifier les hypothèses statistiques, calculer les tailles d’échantillon requises ou rédiger les résultats – même s’il ne nomme jamais de test spécifique. Couvre les tests t, l’ANOVA, le chi‑carré, la corrélation, la régression, les méthodes non paramétriques et bayésiennes. Pour les API de modèles de bas niveau, consultez les compétences statsmodels et pymc.

Veuillez toujours répondre dans la langue de l’utilisateur.
