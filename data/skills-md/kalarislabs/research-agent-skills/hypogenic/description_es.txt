Los planes y auditorías utilizan ChicagoHAI HypoGeniC/HypoRefine para la generación de hipótesis asistida por LLM a partir de conjuntos de datos de texto etiquetados. Úselo con el paquete `hypogenic`, sus configuraciones de tareas, bancos de hipótesis o los conjuntos de datos HypoBench, no para la formulación manual de hipótesis o la validación científica.
