Utilizza il pacchetto PyTDC (import tdc, Therapeutics Data Commons) per scoprire compiti di ML terapeutici da tdc.metadata, pianificare e caricare set di dati approvati, applicare suddivisioni consapevoli del compito (random, scaffold, cold_split, combinazione, time), eseguire metriche di valutazione, valutare gruppi di benchmark come admet_group e eseguire il punteggio limitato di oracoli molecolari. Usalo quando selezioni un compito o un set di dati TDC, pianifichi una suddivisione senza download, valuti le previsioni con gli evaluator TDC, esegua una valutazione di gruppo di benchmark o controlli le licenze dei set di dati e gli effetti della cache prima del download. Usalo quando valuti molecole con oracoli TDC come QED. Non è destinato alla chemi‑informatica generica con RDKit né all'addestramento di generatori di molecole.
