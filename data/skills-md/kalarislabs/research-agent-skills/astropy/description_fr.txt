Bibliothèque Python de base pour les flux de travail en astronomie et astrophysique nécessitant les API d’Astropy, incluant les unités/quantités, les coordonnées, la lecture/écriture FITS, les tables, les systèmes de temps, le WCS et la cosmologie. À utiliser lors de la mise en œuvre ou du débogage de code d’analyse de données astronomiques avec Astropy.
