Unsloth를 사용하여 대형 언어 모델을 파인튜닝하는 방법에 대한 안내를 제공합니다. Unsloth는 LoRA와 QLoRA를 활용한 빠르고 메모리 사용량이 적은 학습을 위한 라이브러리이며, 공식 문서(references/llms-txt.md)를 기반으로 합니다. Unsloth를 이용해 LLM의 LoRA 또는 QLoRA 파인튜닝을 설정할 때, 학습 중 GPU 메모리 사용을 줄이려 할 때, Unsloth 기능이나 API를 찾아볼 때, Unsloth 학습 코드를 디버깅할 때, 또는 Unsloth 모범 사례를 배우고자 할 때 사용하세요. 일반적인 Hugging Face Transformers 또는 PEFT만을 사용한 모델 학습에는 적용되지 않습니다.
