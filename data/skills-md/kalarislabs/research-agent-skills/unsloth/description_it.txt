Fornisce indicazioni su come eseguire il fine‑tuning di grandi modelli linguistici con Unsloth, una libreria per un addestramento più veloce e a basso consumo di memoria usando LoRA e QLoRA, basata sulla sua documentazione ufficiale (references/llms-txt.md). Da utilizzare quando si imposta il fine‑tuning LoRA o QLoRA di un LLM con Unsloth, riducendo l’uso di memoria GPU durante l’addestramento, si cercano le funzionalità o le API di Unsloth, si effettua il debug del codice di addestramento Unsloth o si apprendono le migliori pratiche di Unsloth. Non è destinato all’addestramento generico di modelli con Hugging Face Transformers standard o PEFT senza Unsloth.

Per favore rispondi sempre nella lingua dell’utente.
