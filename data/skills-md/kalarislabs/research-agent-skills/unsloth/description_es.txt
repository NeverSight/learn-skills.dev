Proporciona orientación sobre la afinación de grandes modelos de lenguaje con Unsloth, una biblioteca para entrenamiento más rápido y con menor uso de memoria mediante LoRA y QLoRA, basándose en su documentación oficial (references/llms-txt.md). Úsela al configurar la afinación LoRA o QLoRA de un LLM con Unsloth, reducir el uso de memoria GPU durante el entrenamiento, buscar características o API de Unsloth, depurar el código de entrenamiento de Unsloth o aprender buenas prácticas de Unsloth. No es para entrenamiento general de modelos con Hugging Face Transformers o PEFT sin Unsloth.
