Предоставляет рекомендации по тонкой настройке крупных языковых моделей с помощью Unsloth, библиотеки для более быстрого обучения с меньшим потреблением памяти с использованием LoRA и QLoRA, основанные на её официальной документации (references/llms-txt.md). Используйте при настройке LoRA или QLoRA для тонкой настройки LLM с Unsloth, снижении использования памяти GPU во время обучения, поиске функций или API Unsloth, отладке кода обучения Unsloth или изучении лучших практик Unsloth. Не предназначено для общего обучения моделей с использованием обычных Hugging Face Transformers или PEFT без Unsloth.

Пожалуйста, всегда отвечайте на языке пользователя.
