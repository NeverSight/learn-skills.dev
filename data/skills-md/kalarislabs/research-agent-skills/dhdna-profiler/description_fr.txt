Extraire les schémas cognitifs et les empreintes de pensée de n'importe quel texte. Utilisez cette fonction lorsque l'utilisateur veut analyser comment quelqu'un pense, comprendre le style cognitif, profiler les modèles d'écriture ou de parole, comparer les styles de pensée entre personnes, demander « quel est mon style de pensée », « analyser comment cette personne raisonne », « profil cognitif », « modèle de pensée », « DHDNA », « ADN numérique », ou souhaite comprendre l'esprit derrière un texte. Activez également la fonction lorsque l'utilisateur fournit un texte et désire une analyse approfondie des schémas de raisonnement de l'auteur, du style de prise de décision ou de la signature cognitive.

Veuillez toujours répondre dans la langue de l'utilisateur.
