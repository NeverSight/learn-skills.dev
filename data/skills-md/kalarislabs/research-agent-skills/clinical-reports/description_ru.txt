Генерирует «fail‑closed» черновые шаблоны JSON и выполняет локальные детерминированные проверки структуры и согласованности для клинических отчетов: кейс‑репорты CARE, радиологические, патологические и лабораторные шаблоны, CONSORT 2025, SPIRIT 2025, ICH E3 CSR, агрегированные таблицы побочных событий, манифесты происхождения, схемы терминологии и контрольные списки процессов деперсонализации. Использовать при подготовке кейс‑репорта для публикации на основе проверенного манифеста фактов‑источника. Использовать при проверке рукописи результатов испытания, протокола или черновика CSR на соответствие его структуре отчётности. Использовать при построении агрегированной таблицы безопасности из синтетических или деперсонализированных данных. Использовать при направлении артефакта к соответствующей рекомендации. Не предназначено для диагностики, советов по лечению, создания индивидуального отчёта о безопасности случая или подачи и регистрации.
