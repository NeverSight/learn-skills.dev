Оборачивает существующие скрипты обучения PyTorch с помощью HuggingFace Accelerate (класс Accelerator, конфигурация accelerate, запуск accelerate), чтобы один и тот же код работал на CPU, одной GPU, нескольких GPU, в многонодовой системе, на TPU или Apple MPS. Охватывает размещение устройств, смешанную точность FP16/BF16/FP8, аккумуляцию градиентов, распределённое сохранение контрольных точек и переключение между бекэндами DDP, DeepSpeed ZeRO, FSDP и Megatron. Используется при конвертации скрипта с одной GPU на несколько GPU, включении смешанной точности, настройке DeepSpeed ZeRO или FSDP, а также при настройке аккумуляции градиентов. Применяется, когда один скрипт должен работать на различном оборудовании. Не предназначено для тренировочных циклов с большим количеством callbacks (используйте PyTorch Lightning) или для многонодовой оркестрации с гиперпараметрическим поиском (используйте Ray Train).
