Envuelve scripts de entrenamiento PyTorch existentes con HuggingFace Accelerate (clase Accelerator, configuración accelerate, accelerate launch) para que el mismo código se ejecute en CPU, una sola GPU, múltiples GPU, multi‑nodo, TPU o Apple MPS. Cubre la colocación de dispositivos, precisión mixta FP16/BF16/FP8, acumulación de gradientes, checkpoints distribuidos y el cambio entre los backends DDP, DeepSpeed ZeRO, FSDP y Megatron. Úsalo al convertir un script de una sola GPU a multi‑GPU, al habilitar precisión mixta, al configurar DeepSpeed ZeRO o FSDP, o al establecer acumulación de gradientes. Úsalo cuando un script deba ejecutarse en diferentes hardware. No es adecuado para bucles de entrenamiento con muchos callbacks (usa PyTorch Lightning) ni para orquestación multi‑nodo con ajuste de hiperparámetros (usa Ray Train).
