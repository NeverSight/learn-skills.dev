Как использовать API и Python SDK Adaptyv Bio Foundry для проектирования, отправки и получения результатов экспериментов с белками. Используйте этот навык каждый раз, когда пользователь упоминает Adaptyv, Foundry API, протеиновые связывающие анализы, эксперименты по скринингу белков, BLI/SPR анализы, термостабильностные анализы или хочет отправить последовательности белков для экспериментальной характеристики. Также активируйте, когда в коде импортируются `adaptyv`, `adaptyv_sdk` или `FoundryClient`, или упоминается `foundry-api-public.adaptyvbio.com`.

Пожалуйста, всегда отвечайте на языке пользователя.
