Comment utiliser l'API Foundry d'Adaptyv Bio et le SDK Python pour la conception d'expériences protéiques, la soumission et la récupération des résultats. Utilisez cette compétence chaque fois que l'utilisateur mentionne Adaptyv, l'API Foundry, les essais de liaison protéique, les expériences de criblage de protéines, les essais BLI/SPR, les essais de thermostabilité, ou souhaite soumettre des séquences protéiques pour une caractérisation expérimentale. Déclenchez également lorsque le code importe `adaptyv`, `adaptyv_sdk` ou `FoundryClient`, ou fait référence à `foundry-api-public.adaptyvbio.com`.

Veuillez toujours répondre dans la langue de l'utilisateur.
