Cómo utilizar la API de Adaptyv Bio Foundry y el SDK de Python para el diseño, envío y recuperación de resultados de experimentos de proteínas. Use esta habilidad siempre que el usuario mencione Adaptyv, la API de Foundry, ensayos de unión de proteínas, experimentos de cribado de proteínas, ensayos BLI/SPR, ensayos de termostabilidad, o quiera enviar secuencias de proteínas para su caracterización experimental. También se debe activar cuando el código importe `adaptyv`, `adaptyv_sdk` o `FoundryClient`, o haga referencia a `foundry-api-public.adaptyvbio.com`.
