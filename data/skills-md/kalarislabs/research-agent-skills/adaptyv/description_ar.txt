كيفية استخدام واجهة برمجة تطبيقات معمل أديبتيف بايو فوندر (Adaptyv Bio Foundry) و SDK بايثون لتصميم تجارب البروتين، تقديمها، واسترجاع النتائج. استخدم هذه المهارة كلما ذكر المستخدم Adaptyv أو Foundry API أو اختبارات ربط البروتين أو تجارب فحص البروتين أو اختبارات BLI/SPR أو اختبارات الاستقرار الحراري، أو رغب في تقديم تسلسلات بروتينية للتوصيف التجريبي. كما يجب تفعيلها عندما يتم استيراد الكود `adaptyv` أو `adaptyv_sdk` أو `FoundryClient`، أو عند الإشارة إلى `foundry-api-public.adaptyvbio.com`.

يرجى دائمًا الرد بلغة المستخدم.
