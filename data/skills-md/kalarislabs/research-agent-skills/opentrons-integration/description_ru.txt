Создавайте, проверяйте, мигрируйте, симулируйте и устраняйте ошибки официальных протоколов Opentrons Python Protocol API v2 для роботов Flex и OT‑2. Используйте для специфической для робота работы с жидкостями, настройки дека и лабораторной посуды, пипеток, модулей, параметров выполнения, классов жидкостей и анализа в приложении Opentrons. Используйте pylabrobot, когда один рабочий процесс должен поддерживать нескольких поставщиков роботов.
