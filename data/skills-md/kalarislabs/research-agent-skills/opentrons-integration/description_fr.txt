Rédiger, réviser, migrer, simuler et résoudre les problèmes des protocoles officiels Opentrons Python Protocol API v2 pour les robots Flex et OT‑2. Utilisez‑le pour la manipulation de liquides propre aux robots, la configuration du plateau et du matériel de laboratoire, les pipettes, les modules, les paramètres d’exécution, les classes de liquides et l’analyse de l’application Opentrons. Utilisez plutôt pylabrobot lorsqu’un même flux de travail doit prendre en charge plusieurs fournisseurs de robots. Veuillez toujours répondre dans la langue de l'utilisateur.
