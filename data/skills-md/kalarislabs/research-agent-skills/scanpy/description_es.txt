Pipeline estándar de análisis de RNA‑seq de célula única. Úselo para control de calidad, normalización, reducción de dimensionalidad (PCA/UMAP/t‑SNE), clustering, expresión diferencial, visualización y conversión de formatos compatibles con R, como archivos RDS de Seurat o SingleCellExperiment, a h5ad para Scanpy. Ideal para análisis exploratorio de scRNA‑seq con flujos de trabajo establecidos. Para modelos de aprendizaje profundo, use scvi‑tools; para preguntas sobre formatos de datos, use anndata.
