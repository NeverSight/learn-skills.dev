Pipeline standard per l'analisi di single-cell RNA‑seq. Da utilizzare per QC, normalizzazione, riduzione della dimensionalità (PCA/UMAP/t‑SNE), clustering, espressione differenziale, visualizzazione e conversione di formati single‑cell compatibili con R, come i file RDS di Seurat o SingleCellExperiment, in h5ad per Scanpy. Ideale per analisi esplorativa di scRNA‑seq con workflow consolidati. Per modelli di deep learning usa scvi‑tools; per domande sui formati dei dati usa anndata.
