Локальный парсинг документов и PDF, возвращающий пространственный текст с ограничивающими рамками. Используется для извлечения текста из PDF, DOCX, Office‑файлов и изображений; выполнения OCR на сканах; создания JSON с сохранённым макетом для RAG; массовой загрузки папок с документами; либо визуализации страниц в PNG для мультимодальных агентов. Отличительные возможности — ограничивающие рамки для каждого токена, вывод растровой страницы и полностью локальная обработка без облачных API.
