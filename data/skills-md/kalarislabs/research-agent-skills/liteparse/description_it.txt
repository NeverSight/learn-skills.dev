Analisi locale di documenti e PDF che restituisce testo spaziale con riquadri di delimitazione. Da utilizzare per estrarre testo da PDF, DOCX, file Office e immagini; eseguire OCR su scansioni; produrre JSON con layout preservato per RAG; ingerire in batch cartelle di documenti; o convertire le pagine in PNG per agenti multimodali. Le capacità distintive sono riquadri di delimitazione per token, output raster della pagina e elaborazione completamente locale senza API cloud.
