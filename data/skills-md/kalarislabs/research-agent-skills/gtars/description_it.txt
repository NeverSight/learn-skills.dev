Ispeziona e pianifica il lavoro con Gtars, il toolkit Rust/Python/CLI per intervalli genomici: algebra dei set RegionSet BED (reduce, setdiff, intersect, closest, cluster, gaps), conteggi di sovrapposizioni, set di picchi consensuali, copertura, tokenizzatori, elaborazione di frammenti e archivi refget/BEDbase. Da utilizzare quando si fondono o confrontano set di intervalli BED, si costruisce un consenso o un universo a partire dai picchi, si tokenizzano regioni per modelli ML, si lavora con file di frammenti o si pianifica la raccolta di sequenze refget e l'uso della cache BEDbase. Da utilizzare quando si verificano coordinate BED, contig o strand prima di eseguire gtars. Non è destinato all'elaborazione generale di BAM/VCF; per questo utilizzare samtools o bedtools.
