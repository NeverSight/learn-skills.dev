Costruisci e usa Pi, il framework di codifica minimale per terminale. Usalo per installare Pi, configurare provider/modelli/impostazioni/variabili d'ambiente, creare skill/estensioni/pacchetti/temi/template di prompt di Pi, incorporare Pi tramite l'SDK, integrare via RPC o flussi di eventi JSON, analizzare le sessioni, eseguire modelli locali tramite il router llama.cpp, sviluppare provider Pi personalizzati e componenti TUI, o utilizzare pacchetti dell'ecosistema come pi-subagents (delegazione/orchestrazione), pi-mcp-adapter (server MCP), pi-interview (moduli interattivi) e pi-web-access (ricerca web, recupero, comprensione video).

Rispondi sempre nella lingua dell'utente.
