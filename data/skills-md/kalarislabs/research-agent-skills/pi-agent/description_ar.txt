ابنِ واستخدم Pi، حزمة الترميز الطرفية المصغرة. استخدمها لتثبيت Pi، وتكوين الموفرين/النماذج/الإعدادات/متغيّرات البيئة، وإنشاء مهارات/امتدادات/حزم/سمات/قوالب المطالبات الخاصة بـ Pi، وتضمين Pi عبر SDK، والتكامل عبر RPC أو تدفقات أحداث JSON، وتحليل الجلسات، وتشغيل النماذج المحلية عبر موجه llama.cpp، وتطوير موفرين مخصصين لـ Pi ومكوّنات TUI، أو استخدام حزم النظام الإيكولوجي مثل pi‑subagents (التفويض/التنسيق)، pi‑mcp‑adapter (خوادم MCP)، pi‑interview (نماذج تفاعلية)، وpi‑web‑access (بحث ويب، جلب، فهم الفيديو).
