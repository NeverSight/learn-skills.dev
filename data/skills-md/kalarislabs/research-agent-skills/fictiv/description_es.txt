Controla la aplicación web de fabricación bajo demanda de Fictiv (app.fictiv.com) en el navegador del usuario, ya que no hay API pública. Cubre la carga de archivos CAD (STEP, SLDPRT, STL), la configuración del proceso, material, acabado, roscas y tolerancias, la lectura de comentarios DFM, cotizaciones instantáneas o manuales, niveles de tiempo de entrega, pago con tarjeta o PO, seguimiento de pedidos y reordenes. Úsalo cuando el usuario mencione Fictiv. Úsalo cuando quieran una pieza mecanizada CNC, impresa en 3D, fabricada en chapa metálica, fundida o moldeada en línea. Úsalo cuando soliciten obtener una cotización o pedir piezas a partir de un archivo STEP o STL. Úsalo cuando necesiten verificar una cotización o el estado de un pedido de Fictiv. Úsalo cuando falle una carga en Fictiv, una advertencia DFM, el precio o el proceso de pago. No es para piezas controladas por ITAR, que Fictiv no acepta.

Por favor, responde siempre en el idioma del usuario.
