Résoudre les libellés scientifiques en texte libre en identifiants de termes d'ontologie et valider les CURIE existants contre le Service de recherche d'ontologies d'EBI (OLS4). Rechercher également les préfixes dans Bioregistry, résoudre les identifiants compacts via Identifiers.org, mapper les abréviations de laboratoire avec ZOOMA, et construire des pages de termes Ontobee. Utiliser chaque fois qu'un identifiant d'ontologie doit être produit ou vérifié – annoter les champs tissu, type cellulaire, maladie, phénotype, protocole, produit chimique, organisme, sexe ou stade de développement ; préparer les métadonnées pour les soumissions GEO, ENA, BioSamples, CELLxGENE, HCA ou ISA-Tab ; auditer un tableau de métadonnées d'identifiants de termes ; vérifier si un terme est obsolète et ce qui le remplace ; ou choisir entre HPO et HP. Les déclencheurs comprennent « terme d'ontologie », « ID d'ontologie », « CURIE », « vocabulaire contrôlé », « UBERON », « CL: », « MONDO », « HPO », « EFO », « ChEBI », « NCBITaxon », « terme GO », « PATO », « Zooma », « Bioregistry », « Identifiers.org », « Ontobee », « annoter ce tissu/type cellulaire/maladie », ainsi que toute demande d'émettre ou de vérifier un identifiant de la forme PREFIX:0001234.
