使用 PyHealth 的 Dataset → Task → Model → Trainer → Metrics 模式构建临床深度学习流水线。涵盖加载 MIMIC-III/IV、eICU、OMOP、SleepEDF、ChestXray14 和 EHRShot 数据，定义预测任务（死亡率、再入院、住院时长、药物推荐、睡眠分期、ICD 编码、EEG 事件），模型如 Transformer、RETAIN、GAMENet、SafeDrug 和 StageNet，使用 Trainer 进行训练，以及 ICD/ATC/NDC/RxNorm 编码查询与交叉映射。适用于在电子健康记录数据上构建临床预测模型的场景。适用于使用 MIMIC 或 eICU 数据集的情况。适用于基于信号进行药物推荐或睡眠分期的场景。适用于在 ICD、ATC、NDC 或 RxNorm 之间映射医学编码的需求。不适用于通用的基于表格数据的 PyTorch 应用。
