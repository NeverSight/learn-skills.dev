Construye pipelines clínicos de deep learning con PyHealth utilizando su patrón Dataset → Task → Model → Trainer → Metrics. Incluye la carga de datos MIMIC-III/IV, eICU, OMOP, SleepEDF, ChestXray14 y EHRShot, la definición de tareas de predicción (mortalidad, readmisión, duración de la estancia, recomendación de fármacos, clasificación del sueño, codificación ICD, eventos EEG), modelos como Transformer, RETAIN, GAMENet, SafeDrug y StageNet, entrenamiento con Trainer y búsqueda y mapeo cruzado de códigos ICD/ATC/NDC/RxNorm. Úselo al construir un modelo de predicción clínica sobre datos de EHR. Úselo al trabajar con los conjuntos de datos MIMIC o eICU. Úselo al recomendar fármacos o clasificar el sueño a partir de señales. Úselo al mapear códigos médicos entre ICD, ATC, NDC o RxNorm. No es para PyTorch genérico en datos tabulares.
