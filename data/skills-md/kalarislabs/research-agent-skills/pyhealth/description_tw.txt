使用 PyHealth 以 Dataset → Task → Model → Trainer → Metrics 的模式構建臨床深度學習流水線。涵蓋載入 MIMIC-III/IV、eICU、OMOP、SleepEDF、ChestXray14 以及 EHRShot 資料，定義預測任務（死亡率、再入院、住院天數、藥物推薦、睡眠分期、ICD 編碼、EEG 事件），模型如 Transformer、RETAIN、GAMENet、SafeDrug 與 StageNet，使用 Trainer 進行訓練，並支援 ICD、ATC、NDC、RxNorm 代碼的查詢與交叉映射。適用於在電子健康記錄（EHR）資料上建立臨床預測模型；適用於使用 MIMIC 或 eICU 資料集；適用於根據訊號進行藥物推薦或睡眠分期；適用於在 ICD、ATC、NDC 或 RxNorm 之間映射醫療代碼。不適用於一般的 PyTorch 表格資料。
