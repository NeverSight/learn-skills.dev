PyHealth の Dataset → Task → Model → Trainer → Metrics パターンを用いて臨床向けディープラーニングパイプラインを構築します。MIMIC‑III/IV、eICU、OMOP、SleepEDF、ChestXray14、EHRShot データの読み込み、予測タスク（死亡率、再入院、滞在日数、薬剤推奨、睡眠ステージ付け、ICD コーディング、EEG イベント）の定義、Transformer、RETAIN、GAMENet、SafeDrug、StageNet といったモデル、Trainer による学習、ICD/ATC/NDC/RxNorm コードの検索および相互マッピングをカバーします。EHR データ上で臨床予測モデルを構築する際に使用してください。MIMIC や eICU データセットを扱う際に使用してください。信号から薬剤を推奨したり睡眠をステージ分けする際に使用してください。ICD、ATC、NDC、RxNorm の医療コード間のマッピングを行う際に使用してください。汎用的な表形式データ向けの PyTorch では使用しません。
