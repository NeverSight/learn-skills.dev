PyHealth의 Dataset → Task → Model → Trainer → Metrics 패턴을 사용하여 임상 딥러닝 파이프라인을 구축합니다. MIMIC-III/IV, eICU, OMOP, SleepEDF, ChestXray14 및 EHRShot 데이터를 로드하고, 예측 작업(사망률, 재입원, 입원 기간, 약물 추천, 수면 단계 구분, ICD 코딩, EEG 이벤트)을 정의하며, Transformer, RETAIN, GAMENet, SafeDrug, StageNet과 같은 모델을 사용하고, Trainer로 학습하며, ICD/ATC/NDC/RxNorm 코드 조회 및 교차 매핑을 지원합니다. EHR 데이터에 대한 임상 예측 모델을 구축할 때 사용하세요. MIMIC 또는 eICU 데이터셋을 다룰 때 사용하세요. 신호에서 약물을 추천하거나 수면 단계를 구분할 때 사용하세요. ICD, ATC, NDC 또는 RxNorm 간 의료 코드를 매핑할 때 사용하세요. 일반적인 표 형식 데이터에 대한 PyTorch 용도는 아닙니다.
