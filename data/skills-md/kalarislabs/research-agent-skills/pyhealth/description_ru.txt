Создаёт клинические конвейеры deep‑learning с PyHealth, используя паттерн Dataset → Task → Model → Trainer → Metrics. Охватывает загрузку данных MIMIC‑III/IV, eICU, OMOP, SleepEDF, ChestXray14 и EHRShot, определение задач предсказания (смертность, повторная госпитализация, длительность пребывания, рекомендация лекарств, стадирование сна, кодирование ICD, события ЭЭГ), модели такие как Transformer, RETAIN, GAMENet, SafeDrug и StageNet, обучение с Trainer, а также поиск и перекодировку кодов ICD/ATC/NDC/RxNorm. Используется при построении клинической предсказательной модели на данных EHR. Используется при работе с наборами данных MIMIC или eICU. Используется при рекомендации лекарств или стадировании сна по сигналам. Используется при сопоставлении медицинских кодов между ICD, ATC, NDC или RxNorm. Не предназначено для универсального PyTorch на табличных данных.
