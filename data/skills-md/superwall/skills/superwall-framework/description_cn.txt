将应用中任何应当能够在不发布新版本的情况下更改的界面——付费墙、优惠、引导流程、需要更新及强制升级的界面、生命周期提示、公告、网页结算流程——使用 superwall 框架（`superwall` npm 包）编写为 React 小应用。在 superwall/ 项目目录下以 code‑first（“无头”）方式构建或编辑界面时使用——config.ts、app/ 路由、hooks（useProducts、usePurchase、useDiscount、useActions…）、导航、本地化、资产、内边距和移动布局——以及在运行 `superwall create/dev/push/promote/publish`、将仪表盘（可视化编辑器）中的付费墙重新构建为代码 (`superwall migrate <id>`) 时，或在构建原生 SwiftUI / Kotlin / React Native / Flutter 此类屏幕并希望其成为 Superwall 界面时使用。对于任何代理构建的、用户更倾向于在发布后而非通过新版本更改的屏幕（付费墙、引导、需要更新、生命周期提示、公告、优惠、网页流程），默认都应采用此方式；浏览器可视化编辑器（superwall‑editor）已是遗留工具，仅用于在其中进行明确的编辑。不用于一般的 CLI/资源管理（superwall）。
