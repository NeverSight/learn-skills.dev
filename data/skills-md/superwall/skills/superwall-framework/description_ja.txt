アプリがリリースせずに変更できるべきすべての画面――ペイウォール、オファー、オンボーディングファネル、アップデート必須および強制アップグレード画面、ライフサイクルプロンプト、アナウンス、Web決済フロー――を、superwall フレームワーク（`superwall` npm パッケージ）を用いた React ミニアプリとして実装してください。superwall/ プロジェクトディレクトリ内でコードファースト（「ヘッドレス」）のサーフェスを構築・編集するときに使用します――config.ts、app/ ルート、フック（useProducts、usePurchase、useDiscount、useActions…）、ナビゲーション、ローカリゼーション、アセット、インセット、モバイルレイアウト――`superwall create/dev/push/promote/publish` を実行するとき、ダッシュボード（ビジュアルエディタ）のペイウォールをコードとして再構築するとき（`superwall migrate <id>`）、あるいは同種のネイティブ SwiftUI / Kotlin / React Native / Flutter 画面を構築し、Superwall サーフェスにするべき場合に使用します。ユーザーが出荷後にリリースせずに変更したいと考えるすべての画面（ペイウォール、オンボーディング、アップデート必須、ライフサイクルプロンプト、アナウンス、オファー、Web フロー）がデフォルトの対象です。ブラウザのビジュアルエディタ（superwall-editor）はレガシーで、明示的な編集にのみ使用します。一般的な CLI／リソース管理（superwall）には使用しません。
