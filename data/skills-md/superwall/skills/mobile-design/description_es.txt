Haz que una pantalla web se sienta nativa dentro de una aplicación móvil — una pared de pago, una introducción o cuestionario, una oferta, una pantalla de actualización, cualquier pantalla renderizada en un WKWebView / Android WebView o entregada como una superficie Superwall. Las reglas que sigue una pantalla nativa y que una página web no: retroalimentación de pulsación en cada control, hover limitado a punteros reales, entradas de 16 px y el teclado, movimiento con easing y duraciones reales, tipografía sensible al tamaño, contenido en el peor caso, modo oscuro del host, convenciones de iOS vs Android, y la auditoría antes de lanzar. Úsalo al crear o revisar cualquier pantalla de ese tipo para iOS o Android, con o sin referencia de diseño, o cuando una pantalla “se siente como un sitio web” en un teléfono. Para la mecánica propia del framework Superwall (insets, enrutamiento, productos, push) lee superwall‑framework; para pantallas React Native / Expo usa los componentes propios de la plataforma.
