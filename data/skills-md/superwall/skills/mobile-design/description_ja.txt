Web 画面を電話アプリ内でネイティブに感じさせる ― ペイウォール、オンボーディングやクイズ、オファー、アップデート画面、WKWebView / Android WebView で表示される、または Superwall のサーフェスとして提供される任意の画面。ネイティブ画面が従うが Web ページが従わないルール：すべてのコントロールでのプレスフィードバック、実際のポインタに限定されたホバー、16px の入力フィールドとキーボード、実際のイージングと期間を持つモーション、サイズに応じたタイポグラフィ、最悪ケースのコンテンツ、ホストからのダークモード、iOS と Android の慣習、そして出荷前の監査。iOS または Android 向けにその種の画面を構築またはレビューする際（デザイン参照の有無にかかわらず）、あるいは画面が「ウェブサイトのように感じる」場合に使用すること。Superwall フレームワーク固有のメカニクス（インセット、ルーティング、プロダクト、プッシュ）については superwall‑framework を参照。React Native / Expo の画面については、プラットフォーム独自のコンポーネントを使用すること。
