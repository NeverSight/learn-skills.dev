让网页屏幕在手机应用中感觉原生——无论是付费墙、引导页或测验、优惠、更新页面，或任何在 WKWebView / Android WebView 中渲染或作为 Superwall 表面呈现的屏幕。原生屏幕遵循而网页不具备的规则包括：每个控件都有点击反馈、悬停仅在真实指针上触发、采用 16px 输入框和键盘、使用真实的缓动和时长的动效、对尺寸敏感的排版、最坏情况的内容、来自宿主的深色模式、iOS 与 Android 的规范差异，以及上线前的审查。在为 iOS 或 Android 构建或审查此类任何屏幕时（有无设计参考），或当屏幕在手机上“像网站”时使用这些规则。关于 Superwall 框架自身的机制（内边距、路由、产品、推送），请阅读 superwall‑framework；对于 React Native / Expo 页面，请使用平台自带的组件。
