웹 화면을 전화 앱 내부에서 네이티브처럼 느끼게 만들기 — 결제 벽, 온보딩 또는 퀴즈, 오퍼, 업데이트 화면, WKWebView / Android WebView로 렌더링되거나 Superwall 표면으로 제공되는 모든 화면. 네이티브 화면이 따르는 규칙이며 웹 페이지는 따르지 않는 것: 모든 컨트롤에 대한 터치 피드백, 실제 포인터에만 작동하는 호버, 16 px 입력 필드와 키보드, 실제 이징과 지속 시간을 가진 모션, 크기 인식 타이포그래피, 최악의 경우를 대비한 콘텐츠, 호스트의 다크 모드, iOS와 Android 관례, 그리고 배포 전 감사. iOS 또는 Android용으로 이와 같은 화면을 제작하거나 검토할 때(디자인 레퍼런스 유무에 관계없이) 혹은 화면이 휴대폰에서 “웹사이트처럼” 느껴질 때 사용하세요. Superwall 프레임워크 자체 메커니즘(인셋, 라우팅, 제품, 푸시)에 대해서는 superwall‑framework를 참고하고, React Native / Expo 화면의 경우 플랫폼 고유 컴포넌트를 사용하세요.
