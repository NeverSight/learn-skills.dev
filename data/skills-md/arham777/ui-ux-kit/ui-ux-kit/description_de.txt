Gestalte und verbessere JEDEN Web- oder App‑Interface mit einem geschmacksorientierten, anti‑AI‑Slopp‑Workflow und dokumentiere das Ergebnis in einer Projektdatei DESIGN_SYSTEM.md, damit jede zukünftige Seite visuell konsistent bleibt. Universal: leitet das Briefing zu den passenden Regeln für eine Landing‑/Marketing‑Seite, ein Dashboard/Admin‑Interface, ein Produkt‑/App‑UI, E‑Commerce/Store, Content/Redaktion/Dokumentation, mobile/native App, ein Redesign oder eine reine Design‑System‑Aufgabe. Die Engine ist web‑first (CSS/Tokens/Tailwind); für iOS/Android legt sie platform‑spezifische Leitlinien über diese Engine und delegiert tiefgreifende Plattform‑Komponenten‑Arbeit an HIG/Material. Verwende das System, wenn der Nutzer auffordert, ein Interface zu designen, zu bauen, neu zu gestalten, zu auditieren oder zu verfeinern — insbesondere, wenn er einen Markennamen, eine Farbpalette, Stimmung/Style, Schriftarten, Animationen, Karten‑Style, Bildquelle, Framework oder Plattform (Web / iOS / Android) nennt. Auslöser: „design a landing page“, „build a dashboard“, „design a mobile app“, „build a store / product page / checkout“, „design a docs or blog site“, „redesign this“, „make the UI look premium“, „create a design system“, „audit the UX“, „clean up the design“, „find design references / inspiration“, „make it faster“, „improve performance / Core Web Vitals“.
