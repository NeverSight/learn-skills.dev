صمم وحسّن أي واجهة ويب أو تطبيق باستخدام سير عمل يركز على الذوق ويمنع الاعتماد المفرط على الذكاء الاصطناعي، ثم وثّق النتيجة في ملف المشروع DESIGN_SYSTEM.md لضمان اتساق بصري لجميع الصفحات المستقبلية. شامل: يوجه الموجز إلى القواعد المناسبة لصفحة هبوط/تسويق، لوحة تحكم/إدارة، واجهة منتج/تطبيق، تجارة إلكترونية/متجر، محتوى/تحرير/وثائق، تطبيق موبايل/أصلي، إعادة تصميم، أو مهمة تخص نظام التصميم فقط. المحرك يركز على الويب أولاً (CSS/توكنات/Tailwind)؛ بالنسبة لـ iOS/Android يضيف إرشادات خاصة بالمنصة فوق هذا المحرك ويؤجل العمل العميق على مكونات المنصة إلى HIG/Material. يُستخدم عندما يطلب المستخدم تصميم، بناء، إعادة تصميم، تدقيق أو صقل أي واجهة — خاصة عندما يذكر اسم علامة تجارية، لوحة ألوان، مزاج/نمط، خطوط، حركات، نمط البطاقات، مصدر الصور، إطار عمل أو منصة (ويب / iOS / Android). المحفزات: "صمم صفحة هبوط"، "أنشئ لوحة تحكم"، "صمم تطبيق موبايل"، "أنشئ متجر / صفحة منتج / إتمام عملية الشراء"، "صمم موقع وثائق أو مدونة"، "أعد تصميم هذا"، "اجعل واجهة المستخدم تبدو فاخرة"، "أنشئ نظام تصميم"، "تدقيق تجربة المستخدم"، "نظف التصميم"، "ابحث عن مراجع/إلهام تصميمي"، "اجعلها أسرع"، "حسن الأداء / مؤشرات Core Web Vitals".
