使用以品味为先、抵制 AI 低质量的工作流来设计和改进任何网页或应用界面，然后将结果记录在项目 DESIGN_SYSTEM.md 中，以确保所有后续页面在视觉上保持一致。  
通用：根据需求将简报分配到合适的规则，例如着陆页/营销页、仪表盘/管理后台、产品/应用 UI、电子商务/店铺、内容/编辑/文档、移动/原生应用、重新设计或仅设计系统的任务。  
引擎以 Web 为首（CSS/标记/Tailwind）；在 iOS/Android 上，它在该引擎之上叠加平台惯例指导，并将深层平台组件的工作交给 HIG/Material 处理。  
当用户请求设计、构建、重新设计、审计或打磨任何界面时使用——尤其是当他们提到品牌名称、配色方案、氛围/风格、字体、动画、卡片样式、图片来源、框架或平台（Web / iOS / Android）时。  
触发词：“design a landing page”（设计着陆页）、“build a dashboard”（构建仪表盘）、“design a mobile app”（设计移动应用）、“build a store / product page / checkout”（搭建店铺/产品页/结账页）、“design a docs or blog site”（设计文档或博客站点）、“redesign this”（重新设计此页面）、“make the UI look premium”（使 UI 看起来更高端）、“create a design system”（创建设计系统）、“audit the UX”（审计用户体验）、“clean up the design”（清理设计）、“find design references / inspiration”（寻找设计参考/灵感）、“make it faster”（让它更快）、“improve performance / Core Web Vitals”（提升性能 / 核心网络指标）。  
请始终使用用户的语言作答。
