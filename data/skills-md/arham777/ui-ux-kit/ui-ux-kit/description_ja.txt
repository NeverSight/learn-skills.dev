ANY のウェブまたはアプリインターフェースを「テイスト優先」かつ「AI スロップ防止」ワークフローで設計・改善し、結果をプロジェクトの DESIGN_SYSTEM.md に記録して、将来のすべてのページがビジュアル面で一貫性を保てるようにします。  
ユニバーサル：ブリーフをランディング/マーケティングページ、ダッシュボード/管理画面、プロダクト/アプリ UI、E コマース/ストア、コンテンツ/編集/ドキュメント、モバイル/ネイティブアプリ、リデザイン、またはデザインシステムだけのタスクに適したルールへルーティングします。エンジンはウェブファースト（CSS／トークン／Tailwind）で、iOS／Android についてはその上にプラットフォーム固有のガイダンスを重ね、深いプラットフォームコンポーネントの実装は HIG／Material に委譲します。  
ユーザーが「デザインする」「構築する」「リデザインする」「監査する」「磨く」などインターフェースに関する依頼をしたとき、特にブランド名、カラーパレット、ムード／スタイル、フォント、アニメーション、カードスタイル、画像ソース、フレームワーク、プラットフォーム（Web / iOS / Android）に言及がある場合に使用します。
