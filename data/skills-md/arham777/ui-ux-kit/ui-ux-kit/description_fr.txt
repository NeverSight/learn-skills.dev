Concevez et améliorez N’IMPORTE quelle interface web ou d’application avec un flux de travail centré sur le goût, anti‑brouillon IA, puis documentez le résultat dans un fichier DESIGN_SYSTEM.md afin que chaque page future reste visuellement cohérente. Universel : oriente le cahier des charges vers les bonnes règles pour une page d’atterrissage/marketing, un tableau de bord/administration, une UI produit/application, un e‑commerce/magasin, du contenu/éditorial/documentation, une application mobile/native, une refonte, ou une tâche uniquement de conception de système. Le moteur est web‑first (CSS/jetons/Tailwind) ; pour iOS/Android il superpose des directives d’idiome de plateforme à ce moteur et délègue le travail approfondi des composants natifs aux HIG/Material. Utilisez‑le lorsque l’utilisateur demande de concevoir, construire, refondre, auditer ou peaufiner une interface — en particulier lorsqu’il mentionne un nom de marque, une palette de couleurs, une ambiance/style, des polices, des animations, un style de cartes, une source d’image, un framework ou une plateforme (web / iOS / Android). Déclencheurs : « concevoir une page d’atterrissage », « construire un tableau de bord », « concevoir une application mobile », « créer un magasin / page produit / paiement », « concevoir un site de documentation ou de blog », « refondre cela », « rendre l’UI premium », « créer un système de design », « auditer l’UX », « nettoyer le design », « trouver des références / inspirations de design », « accélérer », « améliorer les performances / Core Web Vitals ». Veuillez toujours répondre dans la langue de l’utilisateur.
