Aiuta gli utenti a scoprire e installare le skill dell'agente da skills.sh quando chiedono “come faccio X”, “trova una skill per X”, “c’è una skill che può…”, o esprimono interesse a estendere le capacità. Usala per la scoperta generale di skill. Se l’utente menziona esplicitamente “clawhub”, “clawdhub” o altre piattaforme specifiche, usa la skill corrispondente per quella piattaforma.

Rispondi sempre nella lingua dell’utente.
