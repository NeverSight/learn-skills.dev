Erstellen Sie einen maßgeschneiderten Portfolio-Link (ein Objektiv) auf Temis Website für eine Bewerbung oder überprüfen Sie, ob ein Objektiv-Link geöffnet wurde und was gelesen wurde. Immer dann verwenden, wenn eine Bewerbung, ein Anschreiben, eine Formularantwort oder eine Recruiter-Nachricht einen Portfolio-Link enthalten sollte, wenn er nach einem Objektiv oder einem Portfolio-Link für eine Rolle fragt und wenn er fragt, ob ein Unternehmen sein Portfolio eröffnet oder gelesen hat.
