Realice revisiones de códigos de seguridad basadas en evidencia en repositorios de aplicaciones, servicios, bibliotecas y solicitudes de extracción. Úselo cuando Codex necesite auditar el código fuente en busca de fallas de seguridad, mapear límites de confianza, verificar la autenticación o autorización, rastrear datos no confiables hasta receptores sensibles, evaluar la lógica de negocios o la criptografía, o producir hallazgos priorizados cuando no hay un lenguaje más específico o una habilidad de revisión de plataforma adecuada.
