Führen Sie evidenzbasierte Überprüfungen des Sicherheitscodes für Anwendungs-Repositorys, Dienste, Bibliotheken und Pull-Anfragen durch. Verwenden Sie Codex, wenn Codex den Quellcode auf Sicherheitslücken prüfen, Vertrauensgrenzen abbilden, Authentifizierung oder Autorisierung überprüfen, nicht vertrauenswürdige Daten auf sensible Senken zurückführen, Geschäftslogik oder Kryptografie bewerten oder priorisierte Ergebnisse erstellen muss, wenn keine engere Sprach- oder Plattformüberprüfungskompetenz passt.
