قم بإجراء مراجعات لرموز الأمان المبنية على الأدلة عبر مستودعات التطبيقات والخدمات والمكتبات وطلبات السحب. يُستخدم عندما يحتاج الدستور الغذائي إلى تدقيق كود المصدر بحثًا عن عيوب أمنية، أو تعيين حدود الثقة، أو التحقق من المصادقة أو الترخيص، أو تتبع البيانات غير الموثوق بها إلى المصارف الحساسة، أو تقييم منطق العمل أو التشفير، أو إنتاج نتائج ذات أولوية عندما لا تكون هناك لغة أضيق أو مهارة مراجعة النظام الأساسي مناسبة.
