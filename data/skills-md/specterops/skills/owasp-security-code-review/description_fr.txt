Effectuez des examens du code de sécurité fondés sur des preuves dans les référentiels d'applications, les services, les bibliothèques et les demandes d'extraction. À utiliser lorsque le Codex doit auditer le code source pour détecter les failles de sécurité, cartographier les limites de confiance, vérifier l'authentification ou l'autorisation, tracer des données non fiables jusqu'à des récepteurs sensibles, évaluer la logique métier ou la cryptographie, ou produire des résultats prioritaires lorsqu'aucune compétence plus étroite en matière de langage ou d'examen de plate-forme ne convient.
