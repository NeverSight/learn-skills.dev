قم بإجراء مراجعات لرموز الأمان المستندة إلى CWE ورسم خرائط دقيقة لنقاط الضعف باستخدام مجموعة MITRE CWE المشتقة محليًا، ورسوم بيانية للعلاقات، وملاحظات رسم الخرائط، وطرق الكشف، وعمليات التخفيف، ودلالات المخطط. يُستخدم عندما يحتاج Codex إلى تدقيق كود المصدر أو سحب الطلبات، أو تحديد فئات الضعف السبب الجذري، أو التمييز بين الأعراض العامة من CWEs القابلة للتخطيط، أو تبرير معرفات CWE في النتائج، أو مراجعة الكود مقابل طرق عرض CWE مثل تطوير البرمجيات، أو مفاهيم البحث، أو أفضل 25، أو OWASP، أو مجموعات الضعف الخاصة باللغة، أو AI/ML.
