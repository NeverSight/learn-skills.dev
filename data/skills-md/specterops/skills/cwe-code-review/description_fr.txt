Effectuez des examens du code de sécurité basés sur CWE et une cartographie précise des faiblesses à l’aide d’un corpus MITRE CWE dérivé localement, de graphiques de relations, de notes de mappage, de méthodes de détection, d’atténuations et de sémantique de schéma. À utiliser lorsque le Codex doit auditer le code source ou les demandes d'extraction, identifier les classes de faiblesses à l'origine des causes, distinguer les symptômes généraux des CWE mappables, justifier les ID CWE dans les résultats ou examiner le code par rapport aux vues CWE telles que le développement logiciel, les concepts de recherche, le Top 25, l'OWASP, les ensembles de faiblesses spécifiques à un langage ou à l'IA/ML.
