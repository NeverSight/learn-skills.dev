Dibuja cómo se mueve cualquier sistema entre estados, como un flujo de productos, un protocolo o un servicio, como un diagrama de estado de Mermaid a partir de un modelo TLA +. Cada error es un camino numerado con bordes azules a un estado que rompe una regla. Utilícelo para /statechart, para mostrar un error como un camino a través de estados, o para convertir un gráfico acordado en un esqueleto TLA +.
