Beim Schreiben, Ändern oder Beibehalten eines Tests anwenden. Rufen Sie den Code so auf, wie es seine Benutzer tun, und setzen Sie das beobachtete Ergebnis gegen einen buchstäblichen Erwartungswert durch. Wenn der Test immer noch bestehen würde, wenn jede importierte Funktion undefiniert zurückgegeben wird, schreiben Sie die Behauptung neu oder löschen Sie den Test.
