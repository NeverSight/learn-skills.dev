Wird verwendet, wenn eine benutzerdefinierte Benutzeroberfläche (Seite, Dashboard, Schaltflächen) erstellt wird, die einen Grok-Bot über einem Webhook aufwecken soll, wenn der Benutzer einen Webhook-Senderschlüssel angeben muss oder wenn diese Benutzeroberfläche auf Tailscale verfügbar gemacht wird.
