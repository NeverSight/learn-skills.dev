Guía completa de SEO + GEO (Optimización de Motores Generativos) + AEO (Optimización de Motores de Respuesta) para 2026. Cubre el ranking de búsqueda tradicional, cómo los motores de IA + agentes de codificación (ChatGPT/Bing, Claude + Claude Code/Codex/OpenClaw/Brave, Gemini/Google, Perplexity) descubren, clasifican y citan páginas, implementación consciente del framework (Next.js App Router Metadata API + prerendering de React SPA), datos estructurados, SEO técnico, títulos/meta, estrategia de contenido, IndexNow, Google + Bing Search Console, análisis de competidores, los cambios de I/O 2026 + actualizaciones principales, y una lista de verificación priorizada. Úsala al optimizar cualquier sitio web para motores de búsqueda y motores de respuesta de IA, planificar la estrategia de contenido/SEO, añadir datos estructurados, corregir títulos/meta, lograr citaciones por chatbots/agentes de IA o configurar Search Console. También abarca SEO de entidad / marca personal en varios dominios propios y la triage de sitios pequeños (cuándo eliminar en lugar de publicar).
