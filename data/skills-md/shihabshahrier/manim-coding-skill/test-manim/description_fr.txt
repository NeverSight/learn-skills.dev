Sujet, durée et nom du modèle configurables. Fonctionne avec Claude Code et opencode sur n’importe quel modèle. Invocation : /test-manim "sujet" [--duration 30|60|90|120] [--model nom] Durée par défaut : 30 s. Objectif principal : une excellente narration + une clarté visuelle.
