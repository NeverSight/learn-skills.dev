Создавайте анимации STEM высокого образовательного качества с помощью ManimGL. Генерируют анимации с повествовательным сюжетом, разбитые на 15‑секундные фрагменты, объединяемые в окончательное видео. Настраиваемые тема, продолжительность и название модели. Работает с Claude Code и opencode на любой модели. Вызов: /test-manim "тема" [--duration 30|60|90|120] [--model имя] Длительность по умолчанию: 30 с. Основная цель: отличное повествование + визуальная ясность.
