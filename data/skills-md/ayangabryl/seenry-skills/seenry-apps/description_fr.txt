Concevoir et créer des écrans d’application mobile à sensation native et des flux (SwiftUI, UIKit, React Native, Expo, Flutter, prototypes web mobiles) qui correspondent aux meilleures applications de l’App Store. Utiliser pour l’onboarding, la navigation à onglets et en pile, les listes, les formulaires, les paramètres, les paywalls, les lecteurs, les sheets et les états vides ou d’erreur. Recherche les parcours complets dans les applications réelles via Seenry MCP (le flux de l’application sur laquelle il se base, l’aspect de l’application à imiter), puis impose les portes de navigation, un pré‑vol mécanique de tolérance et une porte de dépassement de référence.
