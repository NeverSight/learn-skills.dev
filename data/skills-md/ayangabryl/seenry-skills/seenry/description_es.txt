Diseña y construye interfaces web con calidad de estudio de diseño, no con calidad de plantilla de IA. Úsalo para cualquier página nueva, landing page, tablero, shell de aplicación, precios, configuraciones, formulario o componente único, web o móvil (pantallas nativas de app con seenry-apps), para rediseños y pulido visual, y para coincidir con una referencia. Diseña primero la identidad de la marca, como hacen los estudios (una verdad, una voz tipográfica, un campo de color, un dispositivo gráfico, un tratamiento de imagen), estudia identidades reales, sitios de estudios y líderes de categoría de Seenry MCP, construye la página como una aplicación de esa identidad sobre un producto y base de movimiento probados, y no termina hasta que pase una verificación estricta de holgura y un crítico ciego califique la página al nivel de una gran empresa.
