Основная запись capmap-skills (курирование базовой карты способностей, а не обычная работа с документами): план → (основное: спецификации / нарезка / контроль доступа) → тег разработки → тестирование → рекомендации по использованию → архивирование; обратное дополнение git, docs_root, capmap-lint. Настройте .agents/skills/capmap-system/capmap.yaml. Capmap-навыки хранилища первичного исходного кода (этот пакет). Используйте, когда пользователь упоминает capmap, базовую карту способностей, систему документации, тестовую документацию, рекомендации по использованию, архивирование, анализ документов, контроль доступа к срезам спецификаций, проверку папки «Входящие», создание заметок, ошибки времени выполнения/раунды отладки или не уверен, какой этап capmap‑* использовать. Каждый навык этапа можно активировать независимо.
