الإدخال الرئيسي لمهارات capmap (تنظيم خريطة قاعدة القدرات، وليس عملية المستندات العادية): الخطة → (الرئيسية: المواصفات/الشرائح/التحكم في الوصول) → علامة التطوير → الاختبار → مواصفات الاستخدام → الأرشفة؛ ردم بوابة، docs_root، capmap-lint. قم بتكوين .agents/skills/capmap-system/capmap.yaml. مهارات capmap لمستودع المصدر الرئيسي (هذا الجناح). يُستخدم عندما يذكر المستخدم capmap، أو خريطة قاعدة الإمكانات، أو نظام التوثيق، أو وثائق الاختبار، أو مواصفات الاستخدام، أو الأرشفة، أو نسيج المستند، أو المواصفات/الشريحة/التحكم في الوصول، أو فحص البريد الوارد، أو تدوين الملاحظات أولاً، أو جولة خطأ/تصحيح الأخطاء في وقت التشغيل، أو غير متأكد من مرحلة capmap-* المطلوب استخدامها. يمكن تفعيل كل مهارة مرحلة بشكل مستقل.
