Correction de bogues d'exécution/erreurs de publication/contrat de cycle de débogage : reproduisez d'abord, supposez ≤2, apportez des modifications minimes, appliquez une courte liste de contrôle et trois stop‑loss ; n'entrez pas dans la machine à états de solution, ne modifiez pas les balises slice. Convient pour Erreur/Exception/Traceback, correction d'une erreur, poursuite de la correction, débogage. Peut être utilisé indépendamment ; peut coexister avec un découpage en cours.
