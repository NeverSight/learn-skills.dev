Es unterstützt zwei Modi: Bootcamp-Typ (technische Erzählung) und Club-Typ (Serviceförderung). Es wird für Anfragen wie „Schreibe eine README-Datei“, „Schreibe mir eine README-Datei“, „Erstelle eine README-Datei“, „Projekteinführungsdokument“, „GitHub-README-Datei“, „Portfolio-README-Datei“, „Verbessere die README-Datei“, „schreibe die README-Datei neu“ und „Koreanische README-Datei“ verwendet. Das Hauptziel sind Projekt-Repositories von Bootcamps und gemeinsamen IT-Clubs (SOPT, Diffman, YAPP, Nexters, Mashup, DDD, CodeTato, UMC, Boostcamp, Wooahan Tech Course, Kakao Tech Campus).
