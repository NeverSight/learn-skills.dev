Écrivez un README sous la forme d’une « introduction au projet », comme on le trouve dans la culture coréenne du développement. Il prend en charge deux modes : type bootcamp (récit technique) et type club (promotion du service). Il est utilisé pour des requêtes telles que « écrire un README », « écrire un README », « créer un README », « document d'introduction du projet », « GitHub README », « portfolio README », « améliorer le README », « réécrire le README », « README de style coréen ». La cible principale sont les référentiels de projets des bootcamps et des clubs communs informatiques (SOPT, Diffman, YAPP, Nexters, Mashup, DDD, CodeTato, UMC, Boostcamp, Wooahan Tech Course, Kakao Tech Campus).
