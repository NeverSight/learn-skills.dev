اكتب التمهيدي في شكل "مقدمة المشروع" كما هو موجود في ثقافة التنمية الكورية. وهو يدعم وضعين: نوع المعسكر التدريبي (السرد الفني) ونوع النادي (ترويج الخدمة). يتم استخدامه لطلبات مثل "اكتب ملف README" و"اكتب لي ملف README" و"إنشاء ملف README" و"مستند مقدمة المشروع" و"ملف README لـ GitHub" و"محفظة README" و"تعزيز ملف README" و"إعادة كتابة ملف README" و"ملف README على النمط الكوري". الهدف الأساسي هو مستودعات المشروع لمعسكرات التدريب ونوادي تكنولوجيا المعلومات المشتركة (SOPT، Diffman، YAPP، Nexters، Mashup، DDD، CodeTato، UMC، Boostcamp، Wooahan Tech Course، Kakao Tech Campus).
