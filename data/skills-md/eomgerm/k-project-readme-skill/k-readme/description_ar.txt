اكتب الملف التمهيدي على شكل "مقدمة مشروع" نموذجية لثقافة التنمية الكورية. وهو يدعم وضعين: نمط المعسكر التدريبي (السرد الفني) ونمط النادي (ترويج الخدمة). يُستخدم لطلبات مثل "اكتب ملف تمهيدي" و"اكتب ملف تمهيدي لي" و"إنشاء ملف تمهيدي" و"مستند مقدمة المشروع" و"ملف التمهيد الخاص بـ GitHub" و"ملف الملف التمهيدي" و"تحسين الملف التمهيدي" و"إعادة كتابة الملف التمهيدي" و"الملف التمهيدي على النمط الكوري". الهدف الأساسي هو مستودعات المشروع لمعسكرات التدريب ونوادي تكنولوجيا المعلومات المشتركة (SOPT، Diffman، YAPP، Nexters، Mashup، DDD، Coletto، UMC، Boostcamp، Woowa Tech Course، Kakao Tech Campus).
