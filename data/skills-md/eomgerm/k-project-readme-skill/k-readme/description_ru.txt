Напишите README в форме «введения о проекте», принятого в корейской культуре разработки. Он поддерживает два режима: типа учебного курса (техническое повествование) и клубного типа (продвижение услуг). Он используется для таких запросов, как «напишите README», «напишите мне README», «создайте README», «вводный документ проекта», «README GitHub», «README портфолио», «улучшите README», «перепишите README», «README в корейском стиле». Основная цель — репозитории проектов учебных курсов и совместных ИТ-клубов (SOPT, Diffman, YAPP, Nexters, Mashup, DDD, CodeTato, UMC, Boostcamp, Wooahan Tech Course, Kakao Tech Campus).
