Trabaja dentro de wonder-image/new-site o cualquier sitio generado a partir de él. Úsalo cuando composer.json dependa de `wonder-image/app` pero no sea el paquete del framework, o cuando el trabajo toque `custom/`, `app/Models`, `app/Resources`, `lang/`, `assets/{ASSETS_VERSION}/`, `PRODUCT.md`, `php forge credentials`, `php forge update --local`, `php forge start` o la configuración de npm. Cubre páginas, modelos, recursos, repeticiones, contenido editable, traducciones, rutas, roles, permisos, módulos externos, sobrescrituras de componentes y UI/estilos que deben reutilizar `wonder-image/lib`. No lo uses para el núcleo `wonder-image/app`, ediciones directas bajo `vendor/wonder-image/app`, o el código fuente de `wonder-image/lib`.
