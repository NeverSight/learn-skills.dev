Travaillez à l'intérieur de wonder-image/new-site ou de tout site généré à partir de celui‑ci. Utilisez‑le lorsque composer.json dépend de `wonder-image/app` mais n’est pas le paquet du framework, ou lorsque le travail touche `custom/`, `app/Models`, `app/Resources`, `lang/`, `assets/{ASSETS_VERSION}/`, `PRODUCT.md`, `php forge credentials`, `php forge update --local`, `php forge start` ou la configuration npm. Couvre les pages, les modèles, les ressources, les répéteurs, le contenu éditable, les traductions, les routes, les rôles, les permissions, les modules externes, les surcharges de composants et l’interface utilisateur/le style qui doivent réutiliser `wonder-image/lib`. Ne l’utilisez pas pour le cœur `wonder-image/app`, les modifications directes sous `vendor/wonder-image/app`, ou le code source de `wonder-image/lib`.
