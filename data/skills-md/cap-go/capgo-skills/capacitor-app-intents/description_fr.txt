Expose les fonctionnalités de l’application Capacitor à Siri, Raccourcis, Spotlight, le bouton Action, Apple Intelligence, les widgets et les contrôles via les App Intents natifs dans ios/App/App, reliés à la couche Web. Couvre les intents d’ouverture d’application acheminés par les Universal Links / `OpenURLIntent` et @capacitor/app `appUrlOpen`, ou par un plugin local avec un magasin de routes en attente ; les intents d’arrière‑plan sans interface ; le partage de données App Group / Preferences ; les phrases AppShortcutsProvider, les requêtes AppEntity ; les API iOS 26/27 (`supportedModes` remplaçant `openAppWhenRun`, `continueInForeground`, `LongRunningIntent`, AppIntentsTesting) limitées à Capacitor 8 (iOS 15) et 9 (iOS 16). Couvre le placement des fichiers, l’appartenance aux cibles et la livraison d’URL UIScene (Capacitor 8.5+). À utiliser pour « add Siri shortcut », « Shortcuts action », « App Shortcuts », « control widget », ou un intent qui ouvre l’application mais dont la vue Web ne navigue jamais. Ne pas utiliser pour la configuration de liens profonds (capacitor-deep-linking), les notifications push (capacitor-push-notifications) ou les raccourcis Android.
