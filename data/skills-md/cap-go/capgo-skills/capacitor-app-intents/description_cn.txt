将 Capacitor 应用功能暴露给 Siri、快捷指令、Spotlight、操作按钮、Apple Intelligence、部件和控件，使用位于 ios/App/App 中的原生 App Intents，并桥接到 Web 层。涵盖通过通用链接 / `OpenURLIntent` 和 @capacitor/app 的 `appUrlOpen`，或使用带有待处理路由存储的本地插件的打开应用 Intent；无 UI 的后台 Intent；App Group / Preferences 数据共享；AppShortcutsProvider 短语、AppEntity 查询；iOS 26/27 API（`supportedModes` 替代 `openAppWhenRun`、`continueInForeground`、`LongRunningIntent`、AppIntentsTesting），仅在 Capacitor 8（iOS 15）和 9（iOS 16）中可用。包括文件放置、目标成员资格以及 UIScene（Capacitor 8.5+）URL 传递。用于“添加 Siri 快捷指令”“快捷指令动作”“应用快捷指令”“控制部件”或打开应用但 WebView 从不导航的 Intent。不要用于深链接设置（capacitor-deep-linking）、推送（capacitor-push-notifications）或 Android 快捷指令。
