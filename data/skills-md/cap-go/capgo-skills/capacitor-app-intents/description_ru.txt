Открывает возможности приложения на Capacitor для Siri, Shortcuts, Spotlight, кнопки Action, Apple Intelligence, виджетов и элементов управления с помощью нативных App Intents в ios/App/App, соединённых с веб‑слоем. Охватывает интенты «открыть приложение», маршрутизируемые через Universal Links / `OpenURLIntent` и @capacitor/app `appUrlOpen`, либо локальный плагин с хранилищем ожидающих маршрутов; безголовые фоновые интенты; обмен данными через App Group / Preferences; фразы AppShortcutsProvider, запросы AppEntity; API iOS 26/27 (`supportedModes`, заменяющий `openAppWhenRun`, `continueInForeground`, `LongRunningIntent`, AppIntentsTesting), доступные в Capacitor 8 (iOS 15) и 9 (iOS 16). Описывает размещение файлов, включение в цели и доставку URL через UIScene (Capacitor 8.5+). Используйте для «add Siri shortcut», «Shortcuts action», «App Shortcuts», «control widget» или интента, открывающего приложение, но не вызывающего навигацию веб‑вью. Не используется для настройки deep link (capacitor-deep-linking), push‑уведомлений (capacitor-push-notifications) или Android‑ярлыков.
