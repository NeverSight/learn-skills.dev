Audita y endurece progresivamente la configuración de compilación de seguridad de Xcode para una aplicación iOS con Capacitor (ios/App/App.xcodeproj, esquema App) y el código de plugins nativos (Swift/ObjC/C, Package.swift, podspec). Cubre `xcodebuild -showBuildSettings -json`, advertencias de compilador de seguridad, verificadores del analizador estático (`xcodebuild analyze`), Seguridad Mejorada de Xcode (ENABLE_ENHANCED_SECURITY, derechos com.apple.security.hardened-process, autenticación de punteros / arm64e, modo suave de etiquetado de memoria), lo que es seguro para una aplicación híbrida WKWebView frente a lo que rompe CocoaPods, xcframeworks binarios de SPM o plugins de Cordova, adopción escalonada y un registro de decisiones. Úselo para “endurecer mi compilación iOS”, “activar Seguridad Mejorada”, auditoría de configuraciones de compilación de seguridad, errores de enlace arm64e después de activar la autenticación de punteros, o configuración de Build and Analyze. No lo use para ATS/TLS, firma, secretos o reglas de WebView (capacitor‑security), ni para la revisión de la App Store (capacitor‑apple‑review‑preflight).
