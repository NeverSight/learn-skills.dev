Audite et renforce progressivement les paramètres de compilation de sécurité Xcode pour une application iOS Capacitor (ios/App/App.xcodeproj, schéma App) et le code des plugins natifs (Swift/ObjC/C, Package.swift, podspec). Couvre `xcodebuild -showBuildSettings -json`, les avertissements du compilateur de sécurité, les vérificateurs de l’analyseur statique (`xcodebuild analyze`), la Sécurité Améliorée d’Xcode (ENABLE_ENHANCED_SECURITY, droits com.apple.security.hardened-process, authentification des pointeurs / arm64e, mode doux de marquage de mémoire), ce qui est sûr pour une application hybride WKWebView versus ce qui casse CocoaPods, les xcframeworks binaires SPM ou les plugins Cordova, l’adoption progressive, et un journal de décision. À utiliser pour « renforcer ma compilation iOS », « activer la Sécurité Améliorée », l’audit des paramètres de compilation de sécurité, les erreurs de liaison arm64e après activation de l’authentification des pointeurs, ou la configuration Build and Analyze. Ne pas utiliser pour ATS/TLS, la signature, les secrets ou les règles WebView (capacitor-security), ni pour la révision App Store (capacitor-apple-review-preflight).
