Aktualisiert eine Capacitor‑App von v8 auf v9 (Vorabversion, installiert mit @next bis zum GA). Deckt die Vorbereitung (Node 24, Xcode 27, Android Studio 2026.1.1, UIScene‑Einführung ab 8.5), `npx cap migrate` und die manuelle Checkliste ab – iOS 16‑Ziel, @UIApplicationMain zu @main, entfernte CAPBridge‑APIs, AGP 9.2.1, Gradle 9.5.1, SDK 37/minSdk 26, Aufräumen von gradle.properties, integriertes Kotlin, Entfernung von jcenter, core‑ktx, Umbenennung von proguard-android.txt, optionaler Cordova‑Runtime, `cap run --url`, Entfernen von push‑`alert`, Standard‑Splash‑Fade. Verwenden für „Upgrade auf Capacitor 9“, Fehlermeldungen wie „'@UIApplicationMain' ist veraltet“, „Could not find method jcenter()“, getDefaultProguardFile('proguard-android.txt')‑Fehler, doppeltes Kotlin‑Plugin, doppelte Klasse core‑ktx, „unknown option '-l'“. Nicht verwenden für reine UIScene‑Umstellung von 8.4 auf 8.5 (verwenden Sie capacitor-uiscene-migration), Plugin‑Bibliotheken (verwenden Sie capacitor-plugin-upgrade-v8-to-v9) oder ältere Majors.
