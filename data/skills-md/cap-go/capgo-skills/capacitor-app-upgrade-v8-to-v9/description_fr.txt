Met à jour une application Capacitor de la version v8 à v9 (pré‑release, installée avec @next jusqu’à la version GA). Couvre la phase de pré‑vol (Node 24, Xcode 27, Android Studio 2026.1.1, adoption d’UIScene depuis la 8.5), `npx cap migrate` et la checklist manuelle – cible iOS 16, @UIApplicationMain vers @main, API CAPBridge supprimées, AGP 9.2.1, Gradle 9.5.1, SDK 37/minSdk 26, nettoyage de gradle.properties, Kotlin intégré, suppression de jcenter, core-ktx, renommage de proguard-android.txt, runtime Cordova optionnel, `cap run --url`, suppression de l’`alert` push, fondu du splash par défaut. À utiliser pour « upgrade to Capacitor 9 », erreurs telles que « '@UIApplicationMain' est obsolète », « Could not find method jcenter() », échecs de getDefaultProguardFile('proguard-android.txt'), plugin Kotlin dupliqué, classe core-ktx dupliquée, « unknown option '-l' ». Ne pas utiliser pour la migration uniquement de 8.4 à 8.5 UIScene (utiliser capacitor-uiscene-migration), les bibliothèques de plugins (utiliser capacitor-plugin-upgrade-v8-to-v9), ou les versions majeures antérieures.
