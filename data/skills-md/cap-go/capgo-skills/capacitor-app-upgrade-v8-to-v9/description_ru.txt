Обновляет приложение Capacitor с версии v8 до v9 (пререлиз, установленный через @next до GA). Охватывает предполетную проверку (Node 24, Xcode 27, Android Studio 2026.1.1, переход на UIScene, начиная с 8.5), `npx cap migrate` и ручной чек‑лист — целевая iOS 16, замену @UIApplicationMain на @main, удалённые API CAPBridge, AGP 9.2.1, Gradle 9.5.1, SDK 37/minSdk 26, очистку gradle.properties, встроенный Kotlin, удаление jcenter, core‑ktx, переименование proguard-android.txt, опциональную среду выполнения Cordova, `cap run --url`, удаление push‑alert, splash‑fade по умолчанию. Используйте для «обновления до Capacitor 9», ошибок типа «'@UIApplicationMain' is deprecated», «Could not find method jcenter()», сбои `getDefaultProguardFile('proguard-android.txt')`, дублирование плагина Kotlin, дублирование класса core‑ktx, «unknown option '-l'». Не используйте для перехода только с 8.4 на 8.5 UIScene (используйте capacitor-uiscene-migration), библиотек плагинов (используйте capacitor-plugin-upgrade-v8-to-v9) либо более старых мажоров.
