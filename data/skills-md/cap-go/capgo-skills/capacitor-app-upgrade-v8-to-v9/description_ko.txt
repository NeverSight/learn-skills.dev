Capacitor 앱을 v8에서 v9(프리릴리스, GA가 나올 때까지 @next로 설치)로 업그레이드합니다. 사전 점검(Node 24, Xcode 27, Android Studio 2026.1.1, 8.5부터의 UIScene 도입), `npx cap migrate`, 그리고 수동 체크리스트(iOS 16 타깃, @UIApplicationMain을 @main으로 교체, 제거된 CAPBridge API, AGP 9.2.1, Gradle 9.5.1, SDK 37/minSdk 26, gradle.properties 정리, 내장 Kotlin, jcenter 제거, core-ktx, proguard-android.txt 이름 변경, 선택적 Cordova 런타임, `cap run --url`, 푸시 `alert` 제거, 스플래시 페이드 기본값)를 포함합니다. "upgrade to Capacitor 9"에 사용하고, '@UIApplicationMain'이 더 이상 사용되지 않음, "Could not find method jcenter()", getDefaultProguardFile('proguard-android.txt') 오류, Kotlin 플러그인 중복, core-ktx 클래스 중복, "unknown option '-l'" 같은 오류를 해결합니다. 8.4에서 8.5 UIScene 전용 업그레이드(전용 capacitor-uiscene-migration 사용), 플러그인 라이브러리(전용 capacitor-plugin-upgrade-v8-to-v9 사용), 혹은 이전 메이저 버전에는 사용하지 마세요.
