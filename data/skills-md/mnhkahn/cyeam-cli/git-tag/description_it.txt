Crea un tag di versione Git; gli utenti richiedono il tagging, aggiornamenti di versione minore o invocano esplicitamente /git-tag o $git-tag. Esegui tramite `cyeam tag`, impostando di default il minore, supportando il maggiore e `--dry-run`. Il tagging non viene eseguito quando si modificano solo le descrizioni delle skill o si discute delle regole di versione.  

Rispondi sempre nella lingua dell'utente.
