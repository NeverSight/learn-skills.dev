Créer une balise de version Git ; les utilisateurs demandent le balisage, les mises à jour de version mineure, ou invoquent explicitement /git-tag, $git-tag. Exécuter via cyeam tag, par défaut en mineur, en prenant en charge le majeur et l’option --dry-run. Le balisage n’est pas effectué lorsqu’on se contente d’éditer les descriptions de compétences ou de discuter des règles de version.

Veuillez toujours répondre dans la langue de l’utilisateur.
