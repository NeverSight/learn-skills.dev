Crea una etiqueta de versión en Git; los usuarios solicitan etiquetar, realizar una actualización menor de versión o invocar explícitamente /git-tag, $git-tag. Ejecuta mediante `cyeam tag`, por defecto menor, con soporte para mayor y `--dry-run`. No se realiza el etiquetado cuando solo se editan descripciones de habilidades o se discuten reglas de versión.

Por favor, responde siempre en el idioma del usuario.
