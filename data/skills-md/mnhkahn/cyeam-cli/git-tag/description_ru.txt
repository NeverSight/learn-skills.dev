Создайте тег версии Git; пользователи запрашивают тегирование, небольшие обновления версии или явно вызывают /git-tag или $git-tag. Выполняется через `cyeam tag`, по умолчанию создаётся минорный тег, поддерживаются мажорный и `--dry-run`. Тегирование не выполняется, если только редактируются описания навыков или обсуждаются правила версионирования.
