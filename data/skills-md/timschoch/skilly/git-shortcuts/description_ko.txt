단축형 git/GitHub 워크플로 명령을 올바른 작업 순서로 변환합니다. 사용자의 메시지에 "--c", "--p", "--cp", "--pr", "--prm", "--cppr", "--cpprm", "--ff", "--release", "--pub", "--close"와 같이 접두사가 붙은 "--" 약어가 포함된 경우 항상 트리거됩니다. — 후행 "?" 유무에 관계없이. "--" 접두사가 필요합니다. 일반 문장에 나타나는 "c" 또는 "pr"과 같은 단순 문자에서는 트리거하지 마십시오. 절대로 이 기술을 자동으로 호출하지 마십시오. 메시지에서 명시적인 "--" 약어를 통해 항상 사용자가 호출해야 합니다.
