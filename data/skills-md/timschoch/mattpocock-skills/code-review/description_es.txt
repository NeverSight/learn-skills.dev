Revise los cambios desde un punto fijo (confirmación, rama, etiqueta o base de fusión) a lo largo de dos ejes: Estándares (¿el código sigue los estándares de codificación documentados de este repositorio?) y Especificaciones (¿el código coincide con lo que solicitó el problema/especificación de origen?). Ejecuta ambas revisiones en subagentes paralelos y las informa en paralelo. Úselo cuando el usuario quiera revisar una sucursal, un PR, cambios en el trabajo en progreso o solicite "revisar desde X".
