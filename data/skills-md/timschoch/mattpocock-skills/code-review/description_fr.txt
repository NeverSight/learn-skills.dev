Examinez les modifications depuis un point fixe (validation, branche, balise ou base de fusion) selon deux axes : normes (le code suit-il les normes de codage documentées de ce dépôt ?) et Spécification (le code correspond-il à ce que le problème/la spécification d'origine a demandé ?). Exécute les deux révisions dans des sous-agents parallèles et les signale côte à côte. À utiliser lorsque l'utilisateur souhaite réviser une branche, un PR, des modifications de travaux en cours ou demande de « réviser depuis X ».
