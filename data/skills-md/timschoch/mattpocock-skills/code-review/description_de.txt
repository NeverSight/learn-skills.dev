Überprüfen Sie die Änderungen seit einem festen Punkt (Commit, Branch, Tag oder Merge-Base) entlang zweier Achsen: Standards (entspricht der Code den dokumentierten Codierungsstandards dieses Repos?) und Spezifikation (entspricht der Code den Anforderungen des ursprünglichen Problems/der ursprünglichen Spezifikation?). Führt beide Überprüfungen in parallelen Subagenten durch und meldet sie nebeneinander. Verwenden Sie diese Option, wenn der Benutzer einen Zweig, eine PR oder laufende Änderungen überprüfen möchte oder eine „Überprüfung seit X“ anfordert.
