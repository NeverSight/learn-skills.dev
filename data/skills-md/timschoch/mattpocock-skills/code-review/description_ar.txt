قم بمراجعة التغييرات منذ نقطة ثابتة (التزام أو فرع أو علامة أو قاعدة دمج) على محورين: المعايير (هل يتبع الكود معايير الترميز الموثقة لهذا الريبو؟) والمواصفات (هل يتطابق الكود مع ما طلبته المشكلة/المواصفات الأصلية؟). تشغيل كلا المراجعتين في وكلاء فرعيين متوازيين والإبلاغ عنهما جنبًا إلى جنب. يُستخدم عندما يريد المستخدم مراجعة فرع أو علاقة عامة أو تغييرات قيد التنفيذ أو يطلب "المراجعة منذ X".
