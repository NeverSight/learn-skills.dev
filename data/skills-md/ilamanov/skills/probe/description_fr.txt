Esquissez l'architecture porteuse d'un changement complexe sous forme de véritables squelettes de code – quelles que soient les décisions qui guident le reste du travail (schéma, surface d'API, interfaces, flux de données, frontières des modules…) – sans remplir les détails d'implémentation. L'utilisateur examine et itère le squelette de façon interactive, puis le remet à la compétence « ship » pour l'implémenter entièrement. Utilisez‑le lorsque l'utilisateur dit « probe », « probe this », « sketch the architecture first », ou souhaite se mettre d'accord sur la forme globale d'un changement complexe avant une implémentation complète.

Veuillez toujours répondre dans la langue de l'utilisateur.
