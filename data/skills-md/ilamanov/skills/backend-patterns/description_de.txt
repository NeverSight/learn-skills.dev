Allgemein anwendbare Best Practices für Backends/Daten. Verwendung beim Schreiben oder Ändern von Backend-/Datencode — API-Routen, Serveraktionen, DB-Schreiben, Hintergrundjobs, Agententools, Importabläufen, Webhooks, Paste-Handlern oder überall dort, wo Daten in das System gelangen. Konsultieren Sie VOR dem Schreiben des Codes, damit die Muster eingebrannt und nicht nachgerüstet werden. Wenn ein im Fertigkeitskörper beschriebenes Szenario mit der Arbeit übereinstimmt, wenden Sie das Muster an — fragen Sie nicht, sondern befolgen Sie es einfach (rufen Sie die Auswahl in einer Zeile auf, damit der Benutzer sie überschreiben kann).
