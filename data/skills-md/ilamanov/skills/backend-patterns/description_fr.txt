Bonnes pratiques généralement applicables au backend/données. Utilisez‑les chaque fois que vous écrivez ou modifiez du code backend/données — routes d’API, actions serveur, écritures en base de données, jobs en arrière‑plan, outils d’agent, flux d’importation, webhooks, gestionnaires de collage, ou partout où les données entrent dans le système. Consultez AVANT d’écrire le code afin que les modèles soient intégrés, pas rétrofités. Si un scénario décrit dans le corps de la compétence correspond au travail, appliquez le modèle — ne demandez pas, suivez‑le simplement (indiquez le choix en une ligne pour que l’utilisateur puisse le remplacer).
