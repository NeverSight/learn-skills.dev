Allgemein anwendbare Konventionen dafür, wie Code geschrieben und strukturiert wird — Tooling/Paketmanager, Importstil, Benennung von Dateien & Komponenten, Kommentare und wo Dateien abgelegt werden (Kollokation vs. globale Ordner). Verwende sie immer beim Erstellen, Benennen, Verschieben oder Importieren einer Datei, beim Ausführen von Projektbefehlen oder beim Entscheiden, wo ein neues Modul hingehört. Konsultiere sie, BEVOR du den Code schreibst, damit die Konventionen von Anfang an verankert sind und nicht nachträglich angepasst werden. Wenn eine der unten stehenden Konventionen zur Arbeit passt, wende sie an — frage nicht, folge ihr einfach (nenne die Auswahl in einer Zeile, damit der Nutzer sie überschreiben kann).
