Convenciones generalmente aplicables sobre cómo se escribe y organiza el código — herramientas/gestor de paquetes, estilo de importación, nomenclatura de archivos y componentes, comentarios y ubicación de los archivos (co‑ubicación vs. carpetas globales). Utilízalas siempre que se cree, nombre, mueva o importe un archivo, se ejecuten comandos del proyecto o se decida dónde pertenece un nuevo módulo. Consulta ANTES de escribir el código para que las convenciones estén incorporadas, no añadidas después. Si una de las convenciones a continuación coincide con el trabajo, aplícala — no preguntes, simplemente síguela (indica la elección en una línea para que el usuario pueda sobrescribirla).

Por favor, responde siempre en el idioma del usuario.
