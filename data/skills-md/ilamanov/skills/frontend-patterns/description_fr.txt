Bonnes pratiques généralement applicables au front‑end/UI. Utilisez‑les chaque fois que vous construisez, modifiez ou examinez une UI — ajout d’un formulaire/bouton/dialogue/modale, configuration de raccourcis clavier, création de toute surface interactive qui soumet un formulaire, ou à chaque fois que du TSX/JSX est écrit ou modifié. Consultez‑AVANT d’écrire le code afin que les modèles soient intégrés, pas ajoutés rétroactivement. Si un scénario décrit dans le corps de la compétence correspond au travail, appliquez le modèle — ne demandez pas, suivez‑le simplement (indiquez le choix en une ligne pour que l’utilisateur puisse le remplacer).

Veuillez toujours répondre dans la langue de l’utilisateur.
