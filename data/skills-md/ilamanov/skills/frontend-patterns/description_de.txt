Allgemein anwendbare Frontend-/UI‑Best‑Practices. Verwenden Sie sie immer, wenn Sie UI erstellen, modifizieren oder überprüfen – ein Formular, einen Button, Dialog oder Modal hinzufügen, Tastatur‑Shortcuts einbinden, irgendeine interaktive Oberfläche erstellen, die ein Formular übermittelt, oder jederzeit, wenn TSX/JSX geschrieben oder bearbeitet wird. Konsultieren Sie die Richtlinien, BEVOR Sie den Code schreiben, damit die Muster eingebettet und nicht nachträglich angepasst werden. Wenn ein im Skill‑Body beschriebenes Szenario mit der Arbeit übereinstimmt, wenden Sie das Muster an – fragen Sie nicht nach, folgen Sie einfach (benennen Sie die Wahl in einer Zeile, damit der Benutzer sie überschreiben kann).
