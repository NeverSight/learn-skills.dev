Создаёт богатую визуальную HTML‑страницу‑один‑лист, позволяющую занятому ревьюеру понять набор изменений и либо одобрить предложенный стек PR, либо смёржить готовый — без необходимости читать дифф самостоятельно. Автоматически определяет, является ли запуск ЧЕРНОВИКОМ (изменения в рабочем дереве плюс предложенный стек, до одобрения) или ФИНАЛОМ (реальный стек PR с завершённым обзором, перед слиянием). Начинается с TL;DR, выводит стек PR в верхней части, отмечает изменения с высоким риском (эндпоинты, аутентификация, схема), затем проводит ревьюера через важный код в виде пронумерованного Code Tour с встроенными фрагментами диффа. Используется, когда кто‑то хочет быстро оценить изменения перед одобрением или слиянием — «просмотрите изменения», «покажите, что изменилось», «суммируйте дифф / ветку / стек», «что я собираюсь одобрить», «пройдите со мной по тому, что отгрузилось», «объясните финальный код», или любой процесс одобрения/слияния в рабочем процессе выпуска — даже если они не используют слова «кратко» или «HTML».
