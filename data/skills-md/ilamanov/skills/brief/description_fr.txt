Génère une page HTML riche et visuelle qui permet à un examineur occupé de comprendre un ensemble de changements et soit d’approuver une pile de PR proposée, soit de fusionner une pile terminée — sans lire le diff lui‑même. Détecte automatiquement si l’exécution est EN BOURRIL (modifications de l’arbre de travail plus une pile proposée, pré‑approbation) ou FINALE (une vraie pile de PR avec révision complète, pré‑fusion). Commence par un TL;DR, place la pile de PR en haut, signale les changements à haut risque (points de terminaison, authentification, schéma), puis guide l’examinateur à travers le code important sous forme de visite de code numérotée avec des extraits de diff en ligne. À utiliser chaque fois que quelqu’un veut examiner rapidement un changement avant d’approuver ou de fusionner — « examiner les changements », « montre‑moi ce qui a changé », « résumer le diff / la branche / la pile », « que suis‑je sur le point d’approuver », « guide‑moi à travers ce qui a été livré », « expliquer le code final », ou tout autre point de validation/fusion dans le flux de travail de mise en production — même s’ils n’utilisent pas les mots « bref » ou « HTML ».
