產生一個富含視覺效果的 HTML 單頁文件，讓忙碌的審查者在不必自行閱讀 diff 的情況下，就能了解整體變更，並可批准提議的 PR 堆疊或合併已完成的堆疊。會自動偵測執行模式是 DRAFT（工作樹變更加上提議的堆疊，尚未批准）還是 FINAL（已完成審查的正式 PR 堆疊，待合併）。開頭提供 TL;DR，並在頁面上方顯示 PR 堆疊，標示高風險變更（如端點、驗證、資料結構），接著以編號的 Code Tour 方式，搭配內嵌的 diff 片段，引導審查者逐步瀏覽重要程式碼。適用於任何想在批准或合併前先快速瀏覽變更的情境——「審查變更」、「把我變更的內容顯示出來」、「摘要 diff／分支／堆疊」、「我要批准什麼」、「帶我走過已上線的內容」、「解釋最終程式碼」，或任何出貨工作流程的批准/合併關卡——即使使用者未明確說出「簡述」或「HTML」等字眼。
