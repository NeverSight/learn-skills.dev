변경 사항을 한눈에 파악하고 제안된 PR 스택을 승인하거나 완료된 스택을 병합할 수 있도록, 바쁜 리뷰어에게 시각적으로 풍부한 HTML 원페이지를 생성합니다—diff를 직접 읽지 않아도 됩니다. 실행이 DRAFT(작업 트리 변경 및 제안된 스택, 사전 승인)인지 FINAL(리뷰가 완료된 실제 PR 스택, 사전 병합)인지를 자동으로 감지합니다. TL;DR을 앞에 배치하고, 페이지 상단 근처에 PR 스택을 표시하며, 엔드포인트, 인증, 스키마 등 고위험 변경을 표시합니다. 그런 다음 중요한 코드를 번호가 매겨진 Code Tour 형태로 인라인 diff 스니펫과 함께 리뷰어에게 안내합니다. 누군가가 승인이나 병합 전에 변경 사항을 살펴보고 싶을 때마다 사용합니다—“변경 사항 검토”, “무엇이 바뀌었는지 보여줘”, “diff/브랜치/스택 요약”, “내가 곧 승인할 내용은?”, “배포된 내용을 안내해줘”, “최종 코드를 설명해줘” 등과 같은 상황에, “brief”나 “HTML”이라는 단어가 언급되지 않더라도 적용됩니다.
