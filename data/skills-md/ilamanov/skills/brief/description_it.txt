Genera una pagina HTML ricca e visiva che permette a un revisore impegnato di comprendere un insieme di modifiche e di approvare uno stack PR proposto o di unire quello completato — senza leggere direttamente il diff. Rileva automaticamente se l'esecuzione è DRAFT (modifiche nell'albero di lavoro più uno stack proposto, pre-approvazione) o FINAL (uno stack PR reale con revisione completa, pre-merge). Inizia con un TL;DR, mette in evidenza lo stack PR vicino all'inizio, segnala le modifiche critiche (endpoint, autenticazione, schema), quindi guida il revisore attraverso il codice importante con un Tour del Codice numerato e snippet di diff in linea. Da utilizzare ogni volta che qualcuno vuole dare un’occhiata a una modifica prima di approvarla o unirla — “rivedere le modifiche”, “mostrami cosa è cambiato”, “riassumi il diff / il ramo / lo stack”, “cosa sto per approvare”, “guidami attraverso ciò che è stato rilasciato”, “spiega il codice finale”, o qualsiasi fase di approvazione/merge del workflow di rilascio — anche se non usano le parole “brief” o “HTML”.
