生成一个内容丰富、视觉化的 HTML 单页，让忙碌的审阅者能够了解一系列更改，并在不自行阅读 diff 的情况下，批准提议的 PR 堆栈或合并已完成的 PR —— 自动检测运行是草稿（工作树更改加上提议的堆栈，待批准）还是最终（审查完成的真实 PR 堆栈，待合并）。页面开头提供 TL;DR，靠近顶部展示 PR 堆栈，标记高风险更改（端点、认证、模式），随后通过带编号的代码导览和内嵌 diff 片段，引导审阅者浏览重要代码。适用于任何人在批准或合并前想快速查看更改的情形——“审查更改”、 “展示有哪些改动”、 “总结 diff / 分支 / 堆栈”、 “我要批准什么”、 “带我了解已发布的内容”、 “解释最终代码”，或任何交付工作流的批准/合并环节——即使他们未使用 “简要” 或 “HTML” 等词。
