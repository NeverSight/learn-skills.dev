Effettua il reverse engineering di applicazioni native, gestite, Electron/JavaScript, pacchettizzate e browser con REA. Utilizza artefatti distribuiti o evidenze runtime richieste per spiegare le funzionalità, confrontare le versioni, decompilare il codice o guidare una ricostruzione. Salta REA per l'analisi dell'architettura di repository di codice sorgente ordinari.
