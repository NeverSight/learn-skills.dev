ينشئ أو يُحدّث موقعًا محليًا خاصًا لـ Coding Wrapped بناءً على تاريخ جلسات Claude Code وCodex. استخدمه لـ Coding Wrapped، حقائق ممتعة عن وكيل الترميز، رؤى حول سلوك الترميز الذكي، لوحة تحكم ترميز شخصية على localhost، بطاقات رؤى جديدة، أو تصدير نسخة موجودة من Wrapped. يُجري فحصًا محليًا، يستبعد النصوص الخام من الحالة المُولّدة، وينتج لغة واحدة مع مقاييس إجمالية، نظرة عامة على الترميز، ورؤى مصورة بأربع عناصر في كل مرة.
