Générateur de messages de commit ultra-compact. Supprime le bruit des messages de commit tout en préservant l'intention et le raisonnement. Format Conventional Commits. Sujet ≤50 caractères, corps uniquement lorsque le « pourquoi » n'est pas évident. Utilisez-le quand l'utilisateur dit « write a commit », « commit message », « generate commit », « /commit » ou invoque /caveman-commit. Se déclenche automatiquement lors du staging des changements.

Veuillez toujours répondre dans la langue de l'utilisateur.
