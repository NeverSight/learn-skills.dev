Garde les commentaires de code et les docstrings peu nombreux, courts et essentiels. Utilise-le pour toute tâche de codage qui écrit ou modifie des commentaires, des docstrings, du JSDoc ou des blocs de documentation. Utilisez-le également lorsque l'utilisateur dit « trop de commentaires », « les commentaires sont trop longs », « nettoyer les commentaires », « déformer les commentaires », « supprimer les commentaires d'IA », ou indique que le code ressemble à un texte écrit par une IA. Par défaut, il n’écrit aucun commentaire et n’en ajoute qu’un seul lorsque cela dit quelque chose que le code ne peut pas exprimer. Il fonctionne pendant la rédaction et comme passe de nettoyage sur les fichiers existants ou un diff. Il ne touche que les commentaires et les docstrings, jamais le code. Veuillez toujours répondre dans la langue de l'utilisateur.
