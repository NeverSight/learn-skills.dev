Revisión de pull‑request que verifica cada afirmación contra el código antes de afirmarla, prueba los hallazgos numéricos con una ejecución en seco ejecutable y prioriza lo que vale la pena señalar. Úsalo siempre que el usuario solicite revisar un PR, revisar cambios, ver un diff, comprobar una rama o diga “review #N”, “what’s wrong with this PR”, “is this mergeable”, o te proporcione una URL de PR. También úsalo para peticiones informales como “¿le echas un vistazo al 414?”. Publica los hallazgos en GitHub solo cuando el usuario lo pida.
