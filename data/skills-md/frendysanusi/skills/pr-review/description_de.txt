Pull-Request-Review, die jede Behauptung gegen den Code verifiziert, bevor sie ausgesprochen wird, numerische Befunde mit einem ausführbaren Trockenlauf belegt und beurteilt, was es wert ist, hervorgehoben zu werden. Verwende sie immer, wenn der Benutzer bittet, einen PR zu prüfen, Änderungen zu reviewen, einen Diff anzusehen, einen Branch zu überprüfen oder sagt „review #N“, „was ist mit diesem PR los“, „ist das mergebar“ bzw. dir eine PR‑URL gibt. Auch bei lockeren Anfragen wie „schau dir 414 an?“. Ergebnisse werden nur dann auf GitHub gepostet, wenn der Benutzer danach fragt.
