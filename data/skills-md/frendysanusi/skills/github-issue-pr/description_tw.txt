透過 `gh` CLI 起草並提交結構良好的 GitHub 問題與拉取請求（PR）。在使用者想要建立、提交、開啟、起草、提出或記錄 GitHub issue / ticket / bug / feature‑request / task，或是想要開啟／起草／建立 Pull Request（PR）時使用——例如「create an issue」、「file a gh issue」、「open a github ticket」、「log this bug」、「raise an issue」、「open a PR」、「draft a pull request」、「create the PR」等說法，或是當他們提供聊天內容、diff 或工作片段並請你將其捕捉為 GitHub issue 或 PR 時也使用。也可利用此功能把 issue 或 PR 的正文寫入檔案，以便在提交前進行審閱。它會區分錯誤回報（需包含重現步驟、根本原因、file:line）與功能／任務問題（說明結果與驗收標準，**不**包含實作），以及 issue（描述行為，**不**涉及程式內部）與 PR（「Changes」段落會包含程式內部）。此功能僅用於透過 `gh` 操作 GitHub——若是 Jira、Linear、Asana，請改用相應的票證技能。

請始終以使用者的語言回覆。
