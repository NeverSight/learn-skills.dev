`gh` CLI を使用して、構造化された GitHub の Issue と Pull Request を下書き・作成します。ユーザーが GitHub の Issue／チケット／バグ／機能要望／タスク を作成・提出・開く・下書き・提起・記録したい場合、または Pull Request（PR） を開く・下書き・作成したい場合に使用します。たとえば「issue を作成」「gh issue をファイル」「github のチケットを開く」「このバグを記録」「issue を提起」「PR を開く」「pull request を下書き」「PR を作成」などの表現や、チャット・diff・作業の一部を渡されてそれを GitHub の Issue や PR として取りまとめてほしいときにも使用します。また、Issue や PR の本文をファイルに書き出して、提出前にレビューできるようにします。バグレポートは「再現手順 + 根本原因 + ファイル:行番号」で区別し、機能・タスクの Issue は「成果物 + 受入基準（実装は除く）」で区別します。Issue は「振る舞いを記述」しコード内部は含めず、PR は「Changes セクションでコード内部を含める」ことが求められます。これは GitHub 用の `gh` に限定した機能で、Jira／Linear／Asana については専用のチケットスキルを使用してください。

常にユーザーの言語で回答してください。
