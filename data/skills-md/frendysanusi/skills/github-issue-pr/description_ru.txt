Создавайте черновики и оформляйте хорошо структурированные задачи GitHub И запросы на вытягивание (pull requests) через CLI `gh`. Используйте это каждый раз, когда пользователь хочет создать, оформить, открыть, черновик, поднять или зафиксировать задачу/баг/запрос функции/задачу GitHub, ИЛИ открыть/создать/черновик запрос на вытягивание (PR) — формулировки типа «создать задачу», «оформить задачу gh», «открыть тикет GitHub», «записать этот баг», «поднять задачу», «открыть PR», «черновик запроса на вытягивание», «создать PR», или когда они дают вам чат/дифф/кусок работы и просят зафиксировать его как задачу GitHub или PR. Также используйте его, чтобы записать тело задачи или PR в файл для предварительного просмотра перед оформлением. Он различает сообщения об ошибках (воспроизведение + коренная причина + файл:строка) от задач/запросов функций (результат + критерии приёмки, НЕ реализация), и задачи (описание поведения, без кода внутри) от PR (раздел **Changes** СОДЕРЖИТ детали кода). Это предназначено для GitHub через `gh` — для Jira/Linear/Asana используйте специализированный навык тикетов.
