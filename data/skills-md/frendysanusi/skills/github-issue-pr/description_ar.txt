قم بصياغة وتسجيل مشكلات GitHub ذات بنية جيدة وطلبات السحب عبر أداة سطر الأوامر `gh`. استخدم ذلك كلما أراد المستخدم إنشاء، تسجيل، فتح، صياغة، رفع، أو توثيق مشكلة/تذكرة/خطأ/طلب ميزة/مهمة على GitHub، أو لفتح/صياغة/إنشاء طلب سحب (PR) — عبارات مثل "create an issue"، "file a gh issue"، "open a github ticket"، "log this bug"، "raise an issue"، "open a PR"، "draft a pull request"، "create the PR"، أو عندما يقدّم لك محادثة/فرق/قطعة عمل ويطلب توثيقها كمشكلة أو طلب سحب على GitHub. كما يمكن استخدامه لكتابة نص المشكلة أو طلب السحب إلى ملف للمراجعة قبل التسجيل. يميز بين تقارير الأخطاء (إعادة الإنتاج + السبب الجذري + ملف:سطر) ومشكلات الميزة/المهمة (النتيجة + معايير القبول، دون تنفيذ)، وبين المشكلات (وصف السلوك، دون تفاصيل الشيفرة الداخلية) وطلبات السحب (قسم التغييرات يحتوي على تفاصيل الشيفرة الداخلية). هذا مخصص لـ GitHub عبر `gh` — بالنسبة لـ Jira/Linear/Asana استخدم مهارة التذاكر المخصصة.
