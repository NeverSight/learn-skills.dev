Publique el archivo de video finalizado en plataformas como YouTube, Douyin, Canales de WeChat y Xiaohongshu. Esto se utiliza para escenarios en los que los usuarios dicen “publicar video, sincronizar lanzamiento, subir a YouTube, publicar en Douyin, Canales de WeChat, Xiaohongshu, programar lanzamiento”, etc. Verifique la versión del video, la miniatura, los subtítulos, el título, la descripción y el aviso de IA/derechos de autor según la plataforma, y genere un paquete de publicación específico para cada una; después de que el usuario autorice cada plataforma, cargue mediante la API oficial disponible, el asistente de completado de formularios o la herramienta de carga en tiempo real como privado, borrador o programado, nunca utilizando un envío masivo de un solo clic. Cuando la capacidad de carga no esté disponible, entregue un paquete de publicación manual.
