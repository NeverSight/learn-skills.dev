Methodik‑Playbook zur Analyse von Cross‑Chain‑Bridge‑ und Messaging‑Protokolldaten auf Allium — CCTP, LayerZero, Wormhole, Across, kanonische/Anwendungs‑Bridges und allgemeine Lock‑and‑Mint‑Flows. Verwenden Sie es, wann immer eine Frage das Bridge‑Transfer‑Volumen, Netto‑Flows zwischen Chains, das Nachverfolgen einer spezifischen Cross‑Chain‑Transaktion oder die Zuordnung von Bridge‑Aktivität zu einem Protokoll/Integrator berührt — selbst wenn der Nutzer lediglich eine Bridge nennt oder bittet, „diese Übertragung über Chains hinweg zu verfolgen“. Deckt die Richtungs‑/Doppelzählungs‑Mechanik und die Non‑EVM‑Tracing‑Lücke ab, die immer wieder auftauchen, bevor Sie das SQL schreiben. Unterscheidet sich von einem formellen Third‑Party‑Coverage‑Benchmark (siehe bridge‑protocol‑coverage‑assessment dafür) — dies ist die leichtgewichtige Referenz, um eine einzelne Bridge‑Abfrage korrekt zu erstellen.
