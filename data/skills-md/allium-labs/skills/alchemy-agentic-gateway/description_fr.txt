Câbler Alchemy dans le code d'application sans clé API, en utilisant la passerelle x402 ou MPP avec authentification basée sur un portefeuille (SIWE/SIWS) et paiements par demande (USDC via x402, ou USDC/carte de crédit via MPP). Chemin d'intégration d'applications spécialisées. À utiliser lorsque l'utilisateur crée un code d'application ET qu'aucune clé API n'est disponible, ou s'il s'agit d'un agent autonome qui doit payer lui-même, ou s'il souhaite explicitement x402/MPP. Pour un code d'application normal avec une clé API Alchemy, utilisez `alchemy-api`.
