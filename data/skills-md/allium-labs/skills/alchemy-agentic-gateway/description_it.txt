Integra Alchemy nel codice dell'applicazione senza una chiave API, utilizzando il gateway x402 o MPP con autenticazione basata su wallet (SIWE/SIWS) e pagamenti per richiesta (USDC tramite x402, o USDC/carta di credito tramite MPP). Percorso specializzato di integrazione dell'app. Usa quando l'utente sta creando codice dell'applicazione E nessuna chiave API è disponibile, oppure è un agente autonomo che deve pagare da solo, oppure desidera esplicitamente x402/MPP. Per il codice dell'app normale con una chiave API di Alchemy, usa `alchemy-api`.
