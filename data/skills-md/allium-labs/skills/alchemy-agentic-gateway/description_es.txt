Transfiera Alchemy al código de la aplicación sin una clave API, utilizando la puerta de enlace x402 o MPP con autenticación basada en billetera (SIWE/SIWS) y pagos por solicitud (USDC a través de x402 o USDC/tarjeta de crédito a través de MPP). Ruta de integración de aplicaciones especializada. Se utiliza cuando el usuario está creando código de aplicación Y no hay una clave API disponible, o es un agente autónomo que necesita pagarse por sí mismo, o quiere explícitamente x402/MPP. Para el código normal de la aplicación con una clave API de Alchemy, use `alchemy-api`.
