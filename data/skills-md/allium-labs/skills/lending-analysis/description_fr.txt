Manuel de méthodologie pour analyser les données des protocoles de prêt DeFi sur Allium — Aave, Morpho, Fluid, Euler, Maple, les fourches de type Compound et les marchés de prêt par chaîne. À utiliser chaque fois qu’une question porte sur les dépôts, les emprunts, les liquidations, les échanges de collatéral, l’utilisation, le TVL ou le levier d’un protocole de prêt — même si l’utilisateur ne fait que nommer un protocole/actif ou demande de comparer deux tableaux de métriques de prêt. Couvre les pièges des jointures table‑par‑type‑d’événement, les incohérences de nommage des colonnes et le double comptage des remplissages de liquidation qui reviennent fréquemment avant que vous rédigiez le SQL.

Veuillez toujours répondre dans la langue de l’utilisateur.
