طابق سؤالًا تحليليًا مع جدول Allium المناسب أو المقياس أو لوحة المعلومات أو نقطة النهاية الفورية. مطلوب عند اختيار مصدر بيانات جديد لاستعلام أو تحليل: عرّف المعنى المقصود، قارن بين مرشحات المخطط، اختبر التغطية وسجّل مدى التوافق والتحذيرات قبل اعتبار المصدر صحيحًا. نفّذ هذا قبل `allium‑investigation` أو أي تحليل آخر.
