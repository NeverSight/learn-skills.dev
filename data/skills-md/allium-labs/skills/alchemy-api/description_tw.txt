使用標準 API 金鑰將 Alchemy 接入應用程式碼（伺服器、後端、dApp、腳本）。這是一般伺服器/後端使用的首選應用整合路徑。涵蓋 EVM JSON‑RPC、WebSocket 訂閱、模擬、Webhooks/Notify、Solana RPC、Solana DAS、Solana Yellowstone gRPC、Sui gRPC、Wallets/Account Kit、Account Abstraction 以及營運相關主題。需要 `$ALCHEMY_API_KEY`。對於沒有 API 金鑰的應用程式碼（自主代理按請求付費，或明確的 x402/MPP），請改用 `alchemy-agentic-gateway`。
