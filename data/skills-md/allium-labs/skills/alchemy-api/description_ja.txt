標準の API キーを使用して、Alchemy をアプリケーションコード（サーバー、バックエンド、dApp、スクリプト）に組み込みます。通常のサーバー/バックエンド利用向けの推奨アプリ統合パスです。EVM JSON‑RPC、WebSocket サブスクリプション、シミュレーション、Webhooks/Notify、Solana RPC、Solana DAS、Solana Yellowstone gRPC、Sui gRPC、Wallets/Account Kit、Account Abstraction、そして運用に関するトピックをカバーしています。`$ALCHEMY_API_KEY` が必要です。API キーなしでアプリコードを使用する場合（リクエストごとに支払う自律エージェント、または明示的な x402/MPP）、代わりに `alchemy-agentic-gateway` を使用してください。
