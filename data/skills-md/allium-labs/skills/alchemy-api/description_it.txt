Integra Alchemy nel codice dell'applicazione (server, backend, dApp, script) usando una chiave API standard. Percorso di integrazione preferito per uso normale su server/backend. Copre EVM JSON-RPC, sottoscrizioni WebSocket, Simulazione, Webhook/Notify, Solana RPC, Solana DAS, Solana Yellowstone gRPC, Sui gRPC, Wallets/Account Kit, Account Abstraction e argomenti operativi. Richiede `$ALCHEMY_API_KEY`. Per codice dell'app senza una chiave API (agente autonomo che paga per richiesta, o esplicito x402/MPP), usa invece `alchemy-agentic-gateway`.
