استخدم Alchemy في شفرة التطبيق (الخادم، الواجهة الخلفية، dApp، السكريبت) باستخدام مفتاح API قياسي. يُعد هذا المسار المفضل لتكامل التطبيق للاستخدام العادي للخادم/الواجهة الخلفية. يغطي EVM JSON‑RPC، اشتراكات WebSocket، المحاكاة، Webhooks/Notify، Solana RPC، Solana DAS، Solana Yellowstone gRPC، Sui gRPC، محافظ/Account Kit، التجريد الحسابي (Account Abstraction)، والمواضيع التشغيلية. يتطلب `$ALCHEMY_API_KEY`. بالنسبة لشفرة التطبيق بدون مفتاح API (وكيل مستقل يدفع لكل طلب، أو x402/MPP صريح)، استخدم `alchemy-agentic-gateway` بدلاً من ذلك.
