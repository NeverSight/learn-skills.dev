Подключите Alchemy к коду приложения (сервер, бекенд, dApp, скрипт) с помощью стандартного API‑ключа. Предпочтительный путь интеграции для обычного серверного/бекенд‑использования. Охватывает EVM JSON‑RPC, подписки WebSocket, симуляцию, Webhooks/Notify, Solana RPC, Solana DAS, Solana Yellowstone gRPC, Sui gRPC, Wallets/Account Kit, Account Abstraction и оперативные темы. Требуется `$ALCHEMY_API_KEY`. Для кода приложения без API‑ключа (автономный агент, платящий за запрос, или явный x402/MPP) используйте `alchemy-agentic-gateway`.
