Conecta Alchemy en el código de la aplicación (servidor, backend, dApp, script) usando una clave API estándar. Ruta de integración de aplicación preferida para uso normal de servidor/backend. Cubre EVM JSON‑RPC, suscripciones WebSocket, Simulación, Webhooks/Notify, Solana RPC, Solana DAS, Solana Yellowstone gRPC, Sui gRPC, Wallets/Account Kit, Abstracción de cuentas y temas operacionales. Requiere `$ALCHEMY_API_KEY`. Para código de aplicación sin una clave API (agente autónomo pagando por solicitud, o x402/MPP explícito), usa `alchemy-agentic-gateway` en su lugar.
