使用标准 API 密钥将 Alchemy 接入应用代码（服务器、后端、dApp、脚本）。推荐的应用集成路径适用于普通服务器/后端使用。涵盖 EVM JSON-RPC、WebSocket 订阅、Simulation、Webhooks/Notify、Solana RPC、Solana DAS、Solana Yellowstone gRPC、Sui gRPC、钱包/Account Kit、账户抽象以及运营相关主题。需要 `$ALCHEMY_API_KEY`。对于没有 API 密钥的应用代码（自行付费的自治代理，或显式的 x402/MPP），请改用 `alchemy-agentic-gateway`。

请始终使用用户的语言作答。
