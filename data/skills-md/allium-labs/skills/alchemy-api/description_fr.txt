Incorporez Alchemy dans le code d’application (serveur, backend, dApp, script) en utilisant une clé API standard. Chemin d’intégration d’application préféré pour une utilisation serveur/backend normale. Couvre EVM JSON‑RPC, les abonnements WebSocket, la simulation, les Webhooks/Notify, Solana RPC, Solana DAS, Solana Yellowstone gRPC, Sui gRPC, Wallets/Account Kit, l’abstraction de compte et les sujets opérationnels. Nécessite `$ALCHEMY_API_KEY`. Pour le code d’application sans clé API (agent autonome payant à la requête, ou x402/MPP explicite), utilisez `alchemy-agentic-gateway` à la place.
