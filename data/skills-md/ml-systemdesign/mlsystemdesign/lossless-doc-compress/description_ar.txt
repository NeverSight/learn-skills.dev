استخدم عندما يُطلب منك ضغط أو تشديد أو تقصير أو تكثيف أو إزالة انحدار مستند تصميم أو PRD أو RFC أو ملاحظة معمارية أو نثر مماثل "دون فقدان المعلومات". يزيل فقط التكرار الذي يمكن إثباته - الحشو، والتحوط، وLLM-slop، والمحتوى المعاد صياغته - وليس أي حقيقة أو رقم أو قرار أو تحذير، ويضع علامة على كل حكم يستدعي المؤلف. إرجاع مستند مضغوط وسجل إزالة مصنف وبطاقة أداء قابلة للمشاركة.
