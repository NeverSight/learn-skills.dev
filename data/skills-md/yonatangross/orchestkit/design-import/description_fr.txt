Génère le squelette des composants React à partir d’un bundle de remise Claude Design et s’arrête aux fichiers sur le disque : pas de stories, pas de tests, pas de pull request. Utilisez‑le lorsque vous recevez une URL claude.ai/design ou un fichier de bundle local ; lorsque le même squelette doit poursuivre avec la génération de tests, la vérification du navigateur et une pull request ouverte, lancez /ork:design-ship à la place.
