Diagnostica una ejecución de CI fallida contra un playbook de 11 patrones. Clasifica la falla, cita la entrada de memoria pertinente y propone el comando exacto de corrección — pero NUNCA lo aplica sin la aprobación explícita del usuario. Úsalo cuando una verificación específica de PR o una ejecución de GitHub Actions haya fallado y necesites un diagnóstico en lugar de especulación. No lo uses para inspecciones a nivel organizativo de CI (eso es /status) ni para fallas de pruebas a nivel de aplicación (el playbook es específico de CI‑infra).
