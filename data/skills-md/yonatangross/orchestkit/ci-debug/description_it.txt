Diagnostica un'esecuzione CI fallita contro un playbook a 11 pattern. Classifica il fallimento, cita la voce di memoria pertinente, propone il comando di correzione esatto — ma NON lo applica mai senza l'esplicita approvazione dell'utente. Usalo quando un controllo PR specifico o un run di GitHub Actions è fallito e vuoi una diagnosi invece di speculazioni. Non usarlo per scansioni CI a livello di organizzazione (questo è /status) o per fallimenti di test a livello di app (il playbook è specifico per l'infrastruttura CI).
