Диагностировать неудачный запуск CI в соответствии с плейбуком из 11 шаблонов. Классифицирует ошибку, указывает соответствующую запись в памяти, предлагает точную команду исправления — но НИКОГДА не применяет её без явного согласия пользователя. Используйте, когда конкретная проверка PR или запуск GitHub Actions завершились неудачно и вам нужен диагноз вместо предположений. Не используйте для глобальных проверок CI в организации (это /status) или для ошибок тестов на уровне приложения (плейбук специфичен для CI‑инфраструктуры). Пожалуйста, всегда отвечайте на языке пользователя.
