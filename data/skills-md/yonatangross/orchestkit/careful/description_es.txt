Bloquea los comandos destructivos de shell una vez invocados: una protección PreToolUse Bash niega rm -rf fuera de los directorios temporales, force pushes y borrados de ramas remotas, git reset --hard, DROP TABLE / DROP DATABASE / TRUNCATE, kubectl delete y terraform o tofu destroy, incluso dentro de comandos remotos ssh, y hace que Claude pregunte al operador. Úselo antes de tocar producción, una rama compartida, una base de datos en vivo o un clúster.
