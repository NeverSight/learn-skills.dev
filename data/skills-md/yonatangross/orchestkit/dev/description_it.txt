Avvio del ciclo di sviluppo con un solo comando. Avvia una configurazione senza porta (sottodominio HTTPS nominato), emula (mock API con stato), il server di sviluppo del progetto e una sessione agente‑browser, tutti collegati al ramo git corrente. Da utilizzare quando si avvia un ramo di funzionalità, si cambiano i worktree o si ritorna a un progetto dopo una pausa. Salta silenziosamente con suggerimenti di installazione quando mancano i binari prerequisiti.
