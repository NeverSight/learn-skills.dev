تشغيل حلقة التطوير بأمر واحد. يشتغل بدون منفذ (نطاق فرعي HTTPS مسمى)، يحاكي (محاكيات API ذات حالة)، خادم التطوير للمشروع، وجلسة متصفح‑وكيل، كلها مرتبطة بفرع git الحالي. يُستخدم عند بدء فرع ميزة، تبديل شجرات العمل، أو العودة إلى المشروع بعد استراحة. يتخطى بصمت مع إرشادات التثبيت عندما تكون الثنائيات المطلوبة مفقودة.
