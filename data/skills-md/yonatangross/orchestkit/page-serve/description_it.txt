Fornisci a un umano una pagina HTML resa disponibile su un URL HTTPS stabile. Registra una rotta senza porta per un file o una directory (https://NOME.localhost/, mai con :porta), stampa l'URL, opzionalmente ne cattura uno screenshot e lo chiude al termine. Usalo quando un agente ha prodotto una pagina che un umano deve aprire: spiegazioni di glifi, sandbox, pagine decisionali, anteprime di documenti. Sostituisce il server Python http.server ad hoc più i pattern di alias che lasciano i server in esecuzione.
