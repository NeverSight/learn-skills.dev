Remettre à un humain une page HTML rendue à une URL HTTPS stable. Enregistre une route sans port pour un fichier ou un répertoire (https://NAME.localhost/, jamais :port), affiche l’URL, prend éventuellement une capture d’écran, et la supprime à l’arrêt. À utiliser lorsqu’un agent a produit une page que l’humain doit ouvrir : explicateurs de glyphes, terrains de jeu, pages de décision, aperçus de documentation. Remplace le python http.server ad hoc ainsi que les modèles d’alias qui laissent les serveurs actifs.
