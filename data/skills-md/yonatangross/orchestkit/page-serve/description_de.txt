Übergib einem Menschen eine gerenderte HTML‑Seite unter einer stabilen HTTPS‑URL. Registriert eine portfreie Route für eine Datei oder ein Verzeichnis (https://NAME.localhost/, niemals ein :Port), gibt die URL aus, erstellt optional einen Screenshot und beendet sie beim Stoppen. Verwende es, wenn ein Agent eine Seite erzeugt hat, die ein Mensch öffnen soll: Glyph‑Erklärungen, Spielplätze, Entscheidungsseiten, Dokumentenvorschauen. Ersetzt das ad‑hoc python http.server plus Alias‑Muster, die Server am Leben lassen.
