Entrega a una persona una página HTML renderizada en una URL HTTPS estable. Registra una ruta sin puerto para un archivo o directorio (https://NOMBRE.localhost/, nunca con :puerto), muestra la URL, opcionalmente hace una captura de pantalla y la desmonta al detenerse. Úsalo cuando un agente haya generado una página que el humano debe abrir: explicadores de glifos, áreas de juego, páginas de decisiones, vistas previas de documentación. Sustituye al uso improvisado de python http.server y patrones de alias que dejan los servidores activos.
