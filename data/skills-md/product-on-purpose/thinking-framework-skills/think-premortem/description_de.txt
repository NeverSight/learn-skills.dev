Erstellt ein geordnetes Risikoregister, das eine geplante Entscheidung einem Stresstest unterzieht, indem es sich vorstellt, dass sie bereits gescheitert ist, die wahrscheinlichen Ursachen aufdeckt und jede mit einem Abhilfe-, Stolperdraht- und Abbruchkriterium verknüpft. Verwenden Sie diese Option, wenn Sie sich zu einer Markteinführung, einer Einstellung, einer Investition, einer Migration oder einer anderen riskanten, schwer rückgängig zu machenden Entscheidung verpflichten möchten oder wenn Sie vor der Verpflichtung Risiken erkennen müssen.
