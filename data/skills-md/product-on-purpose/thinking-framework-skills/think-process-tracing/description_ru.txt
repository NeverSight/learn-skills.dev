Оценивает соперничающие причинно-следственные объяснения отдельного случая, типируя каждую часть доказательств по делу по ее диагностике (обруч, дымящийся пистолет, соломинка на ветру, тесты с двойным решением) против цепочки механизмов каждого соперника, а затем устраняя или подтверждая конкурентов по пунктам, а не путем подсчета. Используйте, когда произошел один результат, несколько подлинных конкурирующих объяснений конкурируют за его объяснение, а доказательства на уровне механизма (журналы, временные метки, документы, кто знает, что и когда) доступны для их различения - посмертный инцидент, всплеск оттока, потерянная сделка, метрическая аномалия. Не для перекрестного обобщения, не для подсчета очков по матрице согласованности и не для случаев, в которых нет конкурентов.
