REST API（OpenAPI や Swagger 仕様の有無にかかわらず）から GraphOS スーパグラフ用の Apollo Connectors サブグラフを構築・反復し、API が提供する内容、ユーザーの操作とフィールド選択、すべての設計決定、各検証層が生成した証拠を記録する専用の git ワークスペースで管理します。ユーザーが REST API を自分のスーパグラフ用 GraphQL サブグラフとしてラップしたいとき、既存のコネクタサブグラフから操作やフィールドを追加・削除したいとき、新しい仕様に合わせてリフレッシュしたいとき、あるいはライブ API トラフィックをテストフィクスチャとして記録したいときに使用してください。たとえ「コネクタ」「サブグラフ」「Apollo」という語が含まれていなくても構いません。
