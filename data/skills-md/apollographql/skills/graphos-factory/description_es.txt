Construye e itera sobre un subgrafo de Apollo Connectors para un supergrafo GraphOS a partir de una API REST, con o sin una especificación OpenAPI o Swagger, en un espacio de trabajo git dedicado que registre lo que la API ofrece, la operación y selección de campos del usuario, cada decisión de diseño y la evidencia que produjo cada capa de verificación. Úsalo siempre que el usuario quiera envolver una API REST como un subgrafo GraphQL para su supergrafo, añadir o eliminar operaciones o campos de un subgrafo conector existente, actualizarlo con una nueva especificación o registrar el tráfico en vivo de la API como fixtures de prueba, incluso si no mencionan “connector”, “subgraph” o “Apollo”.
