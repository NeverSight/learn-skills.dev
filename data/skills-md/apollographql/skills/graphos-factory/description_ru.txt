Создавайте и улучшайте подграф Apollo Connectors для суперграфа GraphOS на основе REST API, с OpenAPI или Swagger спецификацией либо без неё, в отдельном git‑рабочем пространстве, где фиксируются возможности API, выбранные пользователем операции и поля, каждое проектное решение и доказательства, полученные каждым уровнем проверки. Используйте это, когда пользователь хочет обернуть REST API в GraphQL‑подграф для своего суперграфа, добавить или удалить операции или поля из существующего подграфа‑коннектора, обновить его по новой спецификации или записать живой трафик API в виде тестовых фикстур, даже если они не используют слова «connector», «subgraph» или «Apollo».
