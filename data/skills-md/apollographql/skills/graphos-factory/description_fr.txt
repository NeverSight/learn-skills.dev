Construisez et itérez sur un sous‑graphe Apollo Connectors pour un supergraphe GraphOS à partir d’une API REST, avec ou sans spécification OpenAPI ou Swagger, dans un espace de travail git dédié qui consigne ce que l’API propose, l’opération et la sélection de champs de l’utilisateur, chaque décision de conception, ainsi que les preuves générées par chaque couche de vérification. Utilisez‑le chaque fois que l’utilisateur veut encapsuler une API REST en tant que sous‑graphe GraphQL pour son supergraphe, ajouter ou supprimer des opérations ou des champs d’un sous‑graphe connecteur existant, rafraîchir l’un d’eux à partir d’une nouvelle spécification, ou enregistrer le trafic API en direct comme fixtures de test, même s’ils ne mentionnent pas « connector », « subgraph » ou « Apollo ».
