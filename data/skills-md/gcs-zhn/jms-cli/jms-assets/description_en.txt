JumpServer v4 asset discovery and resolution: `jms ls` (list / keyword search of authorized assets, -n count), the search_assets/list_assets/ resolve_asset library API, AssetInfo connection parameters, account alias and protocol selection rules (select_account: @USER first, then the first non-@ alias/username, then the first account, finally @INPUT; select_protocol: ssh first), exact-name match preferred over the first search hit, and limit/offset pagination semantics. Use whenever the user lists or searches assets, hits a not-found error (No asset found / Asset 'x' not found), resolves connection parameters, writes code that calls the assets library, or wants to confirm an asset is reachable — even if they just ask "what assets are there" or "is x on prod". CLI first (jms ls); programmatic use via search_assets / resolve_asset.
