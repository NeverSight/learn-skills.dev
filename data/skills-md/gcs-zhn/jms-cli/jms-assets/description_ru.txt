Обнаружение и разрешение ресурсов JumpServer v4: `jms ls` (поиск по списку/ключевому слову авторизованных ресурсов, -n count), API библиотеки search_assets/list_assets/solve_asset, параметры подключения AssetInfo, псевдоним учетной записи и правила выбора протокола (сначала select_account: @USER, затем первый псевдоним/имя пользователя, отличный от @, затем первая учетная запись, наконец @INPUT; select_protocol: сначала ssh), точное совпадение имени предпочтительнее первого поиска попадание и семантика нумерации страниц ограничения/смещения. Используйте всякий раз, когда пользователь перечисляет или ищет активы, сталкивается с ошибкой «не найден» (актив не найден / актив «x» не найден), разрешает параметры соединения, пишет код, который вызывает библиотеку ресурсов, или хочет подтвердить доступность актива — даже если они просто спрашивают «какие ресурсы есть» или «есть ли x на продукте». сначала CLI (jms ls); программное использование через search_assets/solve_asset.
