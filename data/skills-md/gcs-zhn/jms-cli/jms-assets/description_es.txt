Descubrimiento y resolución de activos de JumpServer v4: `jms ls` (búsqueda de lista/palabra clave de activos autorizados, -n recuento), API de la biblioteca search_assets/list_assets/ resolve_asset, parámetros de conexión AssetInfo, alias de cuenta y reglas de selección de protocolo (select_account: @USER primero, luego el primer alias/nombre de usuario que no sea @, luego la primera cuenta, finalmente @INPUT; select_protocol: ssh primero), se prefiere la coincidencia de nombre exacto a la primera búsqueda semántica de paginación de acierto y límite/desplazamiento. Úselo siempre que el usuario enumere o busque activos, encuentre un error de no encontrado (No se encontró ningún activo/Activo 'x' no encontrado), resuelva parámetros de conexión, escriba código que llame a la biblioteca de activos o quiera confirmar que se puede acceder a un activo, incluso si solo pregunta "qué activos hay" o "hay x en la producción". CLI primero (jms ls); uso programático a través de search_assets / resolve_asset.
