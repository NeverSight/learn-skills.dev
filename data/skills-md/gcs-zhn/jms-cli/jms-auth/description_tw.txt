JumpServer v4 驗證與連線令牌：雙重驗證（REST Bearer + Django 表單登入 jms_sessionid cookie）、MFA/TOTP 處理（程式碼與錯誤欄位上的 mfa_required 偵測、質詢端點、來自 otp_secret 的自動 TOTP 與注入的 otp_prompt 鍵2222、JMS-{id}帳戶）、HTTP 重試和錯誤分類（401 到 AuthError、帶有 status_code 的 APIError）。每當使用者報告登入失敗、MFA 提示、WebSocket 拒絕（缺少 cookie）、連接令牌錯誤、401/APIError 或需要登入或建立令牌的代碼時使用，即使他們只說「無法登入」。首先 CLI（jms config add 驗證憑證）；使用 JMSSession / create_connection_token 進行程式設計會話。
