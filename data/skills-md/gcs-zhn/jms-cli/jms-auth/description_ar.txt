مصادقة JumpServer v4 ورموز الاتصال: المصادقة المزدوجة (REST Bearer + ملف تعريف الارتباط jms_sessionid لتسجيل الدخول بنموذج Django)، معالجة MFA/TOTP (الكشف عن mfa_required في كل من حقول التعليمات البرمجية والخطأ، نقطة نهاية التحدي، TOTP التلقائي من otp_secret مقابل رد اتصال otp_prompt المحقون)، إنشاء رمز الاتصال (SSH web_cli / SFTP web_sftp، منفذ KoKo 2222، حساب JMS-{id})، إعادة محاولة HTTP وتصنيف الأخطاء (401 إلى AuthError، APIError مع رمز_الحالة). يُستخدم عندما يبلغ المستخدم عن فشل تسجيل الدخول، أو مطالبات MFA، أو رفض WebSocket (ملف تعريف الارتباط المفقود)، أو أخطاء رمز الاتصال، أو 401/APIError، أو يحتاج إلى رمز يقوم بتسجيل الدخول أو إنشاء الرموز المميزة، حتى لو كانوا يقولون فقط "لا يمكن تسجيل الدخول". CLI أولاً (إضافة jms config للتحقق من صحة بيانات الاعتماد)؛ استخدم JMSSession / create_connection_token للجلسات الآلية.
