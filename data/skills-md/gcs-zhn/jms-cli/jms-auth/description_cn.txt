JumpServer v4 身份验证和连接令牌：双重身份验证（REST Bearer + Django 表单登录 jms_sessionid cookie）、MFA/TOTP 处理（代码和错误字段上的 mfa_required 检测、质询端点、来自 otp_secret 的自动 TOTP 与注入的 otp_prompt 回调）、连接令牌创建（SSH web_cli / SFTP web_sftp、KoKo 端口 2222、JMS-{id}帐户）、HTTP 重试和错误分类（401 到 AuthError、带有 status_code 的 APIError）。每当用户报告登录失败、MFA 提示、WebSocket 拒绝（缺少 cookie）、连接令牌错误、401/APIError 或需要登录或创建令牌的代码时使用，即使他们只说“无法登录”。首先 CLI（jms config add 验证凭据）；使用 JMSSession / create_connection_token 进行编程会话。
