jms-cli JumpServer サーバー構成の管理: config.yaml (スキーマ v1.0) 読み取り/書き込み、platformdirs 構成パス、AES-256-GCM 資格情報暗号化 (enc:v1:)、「jms config add/list/remove/set-default」コマンド、およびload_config/add_server/remove_server/set_default_server ライブラリ API。 「config」と書かれていない場合でも、ユーザーがサーバー エイリアスの追加または検査、構成エラー (構成が見つからない、ホスト/ユーザー名/パスワードの欠落、復号化の失敗) の修正、config.yaml の手動編集または生成、暗号化された資格情報の理解または処理、または --config および JMS_CONFIG パスの動作の解決が必要な場合に使用します。 CLI が最初です。プログラムによるアクセスにはライブラリ API を使用します。
