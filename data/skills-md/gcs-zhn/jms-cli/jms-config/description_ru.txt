Управляйте конфигурацией сервера JumpServer jms-cli: чтение/запись config.yaml (схема v1.0), пути конфигурации Platformdirs, шифрование учетных данных AES-256-GCM (enc:v1:), команды `jms config add/list/remove/set-default` и API библиотеки load_config/add_server/remove_server/set_default_server. Используйте всякий раз, когда пользователю необходимо добавить или проверить псевдоним сервера, исправить ошибки конфигурации (конфигурация не найдена, отсутствует хост/имя пользователя/пароль, сбой расшифровки), вручную отредактировать или сгенерировать config.yaml, понять или обработать зашифрованные учетные данные или разрешить --config и поведение пути JMS_CONFIG, даже если они не говорят «config». CLI в первую очередь; используйте API библиотеки для программного доступа.
