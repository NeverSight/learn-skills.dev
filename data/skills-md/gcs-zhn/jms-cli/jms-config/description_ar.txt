إدارة تكوين خادم jms-cli JumpServer: config.yaml (المخطط v1.0) للقراءة/الكتابة، ومسارات تكوين Platformdirs، وتشفير بيانات الاعتماد AES-256-GCM (enc:v1:)، وأوامر `jms config add/list/remove/set-default`، وواجهة برمجة تطبيقات مكتبةload_config/add_server/remove_server/set_default_server. يُستخدم عندما يحتاج المستخدم إلى إضافة اسم مستعار للخادم أو فحصه، أو إصلاح أخطاء التكوين (لم يتم العثور على التكوين، أو فقدان المضيف/اسم المستخدم/كلمة المرور، أو فشل فك التشفير)، أو التحرير اليدوي أو إنشاء config.yaml، أو فهم بيانات الاعتماد المشفرة أو التعامل معها، أو حل سلوك مسار --config وJMS_CONFIG، حتى لو لم يذكر "config". سطر الأوامر أولاً؛ استخدم واجهة برمجة تطبيقات المكتبة للوصول البرمجي.
