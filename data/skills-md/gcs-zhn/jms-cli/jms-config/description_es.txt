Administre la configuración del servidor jms-cli JumpServer: lectura/escritura config.yaml (esquema v1.0), rutas de configuración de platformdirs, cifrado de credenciales AES-256-GCM (enc:v1:), los comandos `jms config add/list/remove/set-default` y la API de biblioteca load_config/add_server/remove_server/set_default_server. Úselo siempre que el usuario necesite agregar o inspeccionar un alias de servidor, corregir errores de configuración (Configuración no encontrada, falta host/nombre de usuario/contraseña, error de descifrado), editar manualmente o generar config.yaml, comprender o manejar credenciales cifradas o resolver el comportamiento de ruta --config y JMS_CONFIG, incluso si no dicen "config". CLI primero; utilice la API de la biblioteca para el acceso programático.
