Используйте его всякий раз, когда истекает время выполнения или зависает, анализ выходных данных WS работает неправильно, сеансы прерываются при контрольном сигнале, вход в интерактивные сеансы, добавление серверной части протокола или написание кода Execute(). Сначала CLI (jms exec / вход в jms); используйте API библиотеки Connect() для встроенных терминалов.
