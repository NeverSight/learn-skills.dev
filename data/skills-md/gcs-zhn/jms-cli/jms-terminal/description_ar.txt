الواجهات الخلفية لمحطة jms-cli (SSH / WebSocket): BackendType وconnect()، دلالات SSH exec (الموعد النهائي الإجمالي، recv_exit_status، stderr لم يتم خلطها مطلقًا في stdout)، بروتوكول علامة WS exec (علامة __JMSDONE مزدوجة + كود خروج __JMSRC، إطارات ثنائية، استنزاف بعد كل تنفيذ)، إبقاء على قيد الحياة (نقل SSH 30 ثانية / إطارات نص PING على مستوى التطبيق WS كل 30 ثانية، لا يوجد كود تشغيل WS مطلقًا 0x9)، وPTY تفاعلي (Ctrl+] للخروج، ومزامنة تغيير حجم SIGWINCH)، وإضافة واجهات خلفية جديدة (register_backend / AbstractTerminal / _AUTO_SEQUENCE). يُستخدم عند انتهاء مهلة exec أو تعليقها، أو حدوث خطأ في تحليل مخرجات WS، أو انخفاض الجلسات عند نبضات القلب، أو تسجيل الدخول إلى الجلسات التفاعلية، أو إضافة واجهة خلفية للبروتوكول، أو كتابة كود التنفيذ(). CLI أولاً (تسجيل الدخول jms exec / jms) ؛ استخدم واجهة برمجة تطبيقات مكتبة Connect() للمحطات الطرفية المدمجة.
