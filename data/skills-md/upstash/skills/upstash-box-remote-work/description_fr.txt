Travaillez dans une Upstash Box, un conteneur cloud en bac à sable piloté via le serveur Upstash MCP distant (mcp.upstash.com), plutôt que sur la machine locale. À utiliser lorsque l'utilisateur demande à exécuter, créer, tester, cloner ou modifier quelque chose à distance, dans un bac à sable, dans le cloud ou dans une boîte, lorsque le livrable est une demande d'extraction, une URL d'aperçu publique ou une capture d'écran d'une application en cours d'exécution, lorsque la machine locale ne peut pas livrer (pas de connexion GitHub pour gh, aucun moyen d'exposer un port, une extraction locale sale ou lente), ou lorsque plusieurs tâches indépendantes doivent s'exécuter en parallèle sur des machines distinctes, une fabrique de code qui transforme une liste de tâches en une liste d'extractions. demandes. S'applique chaque fois que la session dispose des outils MCP box_* et blob_*, même lorsque Upstash n'est pas nommé.
