로컬 시스템 대신 원격 Upstash MCP 서버(mcp.upstash.com)를 통해 구동되는 샌드박스 클라우드 컨테이너인 Upstash Box에서 작업하세요. 사용자가 샌드박스, 클라우드 또는 상자에서 원격으로 무언가를 실행, 빌드, 테스트, 복제 또는 편집하도록 요청하는 경우, 결과물이 끌어오기 요청, 공개 미리 보기 URL 또는 실행 중인 앱의 스크린샷인 경우, 로컬 컴퓨터에서 전달할 수 없는 경우(gh에 대한 GitHub 로그인 없음, 포트를 노출할 방법 없음, 더럽거나 느린 로컬 체크아웃), 또는 여러 독립적인 작업이 별도의 컴퓨터에서 병렬로 실행되어야 하는 경우, 작업 목록을 끌어오기 요청 목록으로 바꾸는 코드 팩토리를 사용합니다. Upstash의 이름이 지정되지 않은 경우에도 세션에 box_* 및 blob_* MCP 도구가 있을 때마다 적용됩니다.
