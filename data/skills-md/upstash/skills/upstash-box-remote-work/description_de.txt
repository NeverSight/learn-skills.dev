Arbeiten Sie in einer Upstash-Box, einem Sandbox-Cloud-Container, der über den Remote-Upstash-MCP-Server (mcp.upstash.com) gesteuert wird, statt auf dem lokalen Computer. Wird verwendet, wenn der Benutzer etwas aus der Ferne, in einer Sandbox, in der Cloud oder in einer Box ausführen, erstellen, testen, klonen oder bearbeiten möchte, wenn das Ergebnis eine Pull-Anfrage, eine öffentliche Vorschau-URL oder ein Screenshot einer laufenden App ist, wenn der lokale Computer nicht liefern kann (keine GitHub-Anmeldung für gh, keine Möglichkeit, einen Port freizugeben, ein schmutziger oder langsamer lokaler Checkout) oder wenn mehrere unabhängige Aufgaben parallel auf separaten Maschinen ausgeführt werden sollen, eine Codefabrik, die eine Liste von Aufgaben in eine Pull-Liste umwandelt Anfragen. Gilt immer dann, wenn die Sitzung über die MCP-Tools box_* und blob_* verfügt, auch wenn Upstash nicht benannt ist.
