Lavora in un Upstash Box, un contenitore cloud sandbox gestito attraverso il server MCP Upstash remoto (mcp.upstash.com), anziché sul computer locale. Da utilizzare quando l'utente chiede di eseguire, creare, testare, clonare o modificare qualcosa in remoto, in una sandbox, nel cloud o in una scatola, quando il risultato finale è una richiesta pull, un URL di anteprima pubblica o uno screenshot di un'app in esecuzione, quando il computer locale non può eseguire la consegna (nessun accesso GitHub per gh, nessun modo di esporre una porta, un checkout locale sporco o lento) o quando diverse attività indipendenti devono essere eseguite in parallelo su macchine separate, una code factory che trasforma un elenco di attività in un elenco di richieste pull. Si applica ogni volta che la sessione ha gli strumenti MCP box_* e blob_*, anche quando Upstash non è nominato.
