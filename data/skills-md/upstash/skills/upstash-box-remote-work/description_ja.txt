ローカル マシンではなく、リモート Upstash MCP サーバー (mcp.upstash.com) 経由で駆動されるサンドボックス クラウド コンテナである Upstash Box で作業を行ってください。ユーザーがリモート、サンドボックス、クラウド、またはボックス内で何かを実行、ビルド、テスト、クローン作成、または編集するように要求した場合、成果物がプル リクエスト、パブリック プレビュー URL、または実行中のアプリのスクリーンショットである場合、ローカル マシンが配信できない場合 (gh の GitHub ログインがない、ポートを公開する方法がない、ダーティまたは遅いローカル チェックアウト)、または複数の独立したタスクを別のマシンで並行して実行する必要がある場合、タスクのリストをプルのリストに変換するコード ファクトリを使用します。リクエスト。 Upstash という名前が付けられていない場合でも、セッションに box_* および blob_* MCP ツールがある場合に適用されます。
