Haz el trabajo en un Upstash Box, un contenedor en la nube aislado que se controla a través del servidor remoto Upstash MCP (mcp.upstash.com), en lugar de hacerlo en la máquina local. Úsalo cuando el usuario solicite ejecutar, compilar, probar, clonar o editar algo de forma remota, en un sandbox, en la nube o en una caja, cuando el entregable sea una solicitud de extracción, una URL de vista previa pública o una captura de pantalla de una aplicación en ejecución, cuando la máquina local no pueda cumplir (sin inicio de sesión en GitHub para gh, sin manera de exponer un puerto, un checkout local sucio o lento), o cuando varias tareas independientes deban ejecutarse en paralelo en máquinas separadas, una fábrica de código que convierta una lista de tareas en una lista de solicitudes de extracción. Se aplica siempre que la sesión tenga las herramientas box_* y blob_* de MCP, incluso cuando Upstash no se mencione.
