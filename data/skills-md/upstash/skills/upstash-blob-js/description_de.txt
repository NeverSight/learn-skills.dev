Arbeiten Sie mit dem @upstash/blob TypeScript/JavaScript SDK für S3-kompatible Objektspeicherung mit direkten Browser-Uploads, vorsignierten URLs, mehrteiligen und signierten Lesevorgängen. Verwenden Sie diese Option, wenn Sie Dateien oder Blobs speichern, Avatare, Bilder, Videos, Anhänge oder Benutzerdokumente hochladen, einen Browser direkt in den Speicher hochladen lassen, ohne Bytes über einen Server zu übertragen, öffentliche oder zeitlich begrenzte signierte URLs generieren, private Dateien bereitstellen, große Dateien mit Pause und Fortsetzen streamen, Cache-Header für gespeicherte Objekte festlegen oder einen S3-kompatiblen Bucket über das AWS SDK erreichen.
