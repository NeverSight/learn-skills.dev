Trabaje con el SDK @upstash/blob TypeScript/JavaScript para almacenamiento de objetos compatible con S3 con cargas directas al navegador, URL prefirmadas, lecturas multiparte y firmadas. Úselo al almacenar archivos o blobs, cargar avatares, imágenes, videos, archivos adjuntos o documentos de usuario, permitir que un navegador cargue directamente al almacenamiento sin enviar bytes mediante proxy a través de un servidor, generar URL firmadas públicas o por tiempo limitado, entregar archivos privados, transmitir archivos grandes con pausa y reanudación, configurar encabezados de caché en objetos almacenados o acceder a un depósito compatible con S3 desde el SDK de AWS.
