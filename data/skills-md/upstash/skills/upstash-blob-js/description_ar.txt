اعمل مع @upstash/blob TypeScript/JavaScript SDK لتخزين الكائنات المتوافقة مع S3 مع تحميلات المتصفح المباشرة وعناوين URL الموقعة مسبقًا والقراءات المتعددة الأجزاء والموقعة. يُستخدم عند تخزين الملفات أو الكائنات الثنائية الكبيرة، أو تحميل الصور الرمزية، أو الصور، أو مقاطع الفيديو، أو المرفقات، أو مستندات المستخدم، أو السماح للمتصفح بالتحميل مباشرة إلى وحدة التخزين دون إنشاء وكيل للبايتات من خلال خادم، أو إنشاء عناوين URL موقعة عامة أو محدودة الوقت، أو تقديم ملفات خاصة، أو دفق الملفات الكبيرة مع الإيقاف المؤقت والاستئناف، أو تعيين رؤوس ذاكرة التخزين المؤقت على الكائنات المخزنة، أو الوصول إلى حاوية متوافقة مع S3 من AWS SDK.
