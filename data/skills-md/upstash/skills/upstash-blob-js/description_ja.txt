@upstash/blob TypeScript/JavaScript SDK を使用して、ブラウザーへの直接アップロード、署名付き URL、マルチパート、および署名付き読み取りを行う S3 互換オブジェクト ストレージを使用します。ファイルや BLOB の保存、アバター、画像、ビデオ、添付ファイル、またはユーザー ドキュメントのアップロード、サーバー経由でバイトをプロキシせずにブラウザでストレージに直接アップロードできるようにする、パブリックまたは期限付きの署名付き URL を生成する、プライベート ファイルを提供する、一時停止と再開を伴う大きなファイルのストリーミング、保存されたオブジェクトにキャッシュ ヘッダーを設定する、または AWS SDK から S3 互換バケットにアクセスする場合に使用します。
