Utilizza l'SDK TypeScript/JavaScript @upstash/blob per l'archiviazione di oggetti compatibile con S3 con caricamenti diretti nel browser, URL prefirmati, letture multiparte e firmate. Da utilizzare quando si archiviano file o BLOB, si caricano avatar, immagini, video, allegati o documenti utente, si consente a un browser di caricarsi direttamente nello spazio di archiviazione senza proxy di byte tramite un server, si generano URL firmati pubblici o limitati nel tempo, si servono file privati, si eseguono streaming di file di grandi dimensioni con pausa e ripresa, si impostano intestazioni di cache su oggetti archiviati o si raggiunge un bucket compatibile con S3 dall'SDK AWS.
