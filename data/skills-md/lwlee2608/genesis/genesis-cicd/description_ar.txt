استخدم عند إضافة GitHub Actions CI/CD إلى مشروع تم إنشاؤه باستخدام genesis (services/<app>-server API بلغة Go، services/<app>-web تطبيق React باستخدام pnpm). يُسأل عن هدف النشر المستمر (Railway، Kubernetes، VM + Overwatcher) وعن نموذج الفروع (main = الإنتاج، أو main = التجربة + release = الإنتاج)، ثم يُنشئ ملف ci.yml واحد مُربط بـ needs بحيث يعرض GitHub رسمًا بيانيًا موحدًا لخط الأنابيب.
