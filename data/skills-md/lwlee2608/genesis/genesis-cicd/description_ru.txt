Используйте при добавлении GitHub Actions CI/CD к проекту, сгенерированному с помощью genesis (services/<app>-server — Go API, services/<app>-web — pnpm React‑приложение). Запрашивает, какой CD‑target использовать (Railway, Kubernetes, VM + Overwatcher) и какую модель веток (main = production, либо main = staging + release = production), затем создаёт один файл ci.yml с настройками needs, чтобы GitHub отображал единый график пайплайна.
