Usa quando aggiungi GitHub Actions CI/CD a un progetto generato con genesis (services/<app>-server API Go, services/<app>-web app React con pnpm). Chiede quale target CD (Railway, Kubernetes, VM + Overwatcher) e quale modello di ramo (main = produzione, oppure main = staging + release = produzione), quindi genera un ci.yml collegato con *needs* in modo che GitHub visualizzi un unico grafico della pipeline.
