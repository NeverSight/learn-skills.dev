# Drafting Messages

Makes a draft ready to copy and paste, and written for its reader.

## Rules

1. **Put the draft in a code block.** It copies cleanly, with no blockquote bars or rendered markdown. Put any note to the user outside the block.
2. **Use full sentences.** The reader is not the user, so do not carry over a terse reply style.
3. **Lead with the answer, then give only the reason the reader needs.** A chat reply is 2-3 sentences in one paragraph unless the user asks for more. Add no offers or next steps the user did not ask for.
