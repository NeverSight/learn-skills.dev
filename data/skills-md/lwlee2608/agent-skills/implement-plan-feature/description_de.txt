Verwenden Sie es, wenn Sie eine phasenweise Feature‑Plan‑Datei implementieren. Jede Phase wird in einem eigenen Branch gebaut und per PR in einen Feature‑Integrations‑Branch integriert, Reviews und Korrekturen erfolgen in Runden, anschließend werden die Änderungen gemergt, die Demo des Plans ausgeführt und der finale Merge in den Main‑Branch dem Benutzer überlassen.
