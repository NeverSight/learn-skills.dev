Используйте при реализации планов функции в несколько этапов. Каждый этап создаётся в отдельной ветке и отправляется в виде pull‑request в ветку интеграции функции, после чего проводятся раундовые ревью и исправления, сливаются, затем запускается демонстрация плана, а окончательное слияние в main оставляется пользователю.
