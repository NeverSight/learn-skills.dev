Использовать, когда пользователь запрашивает ретроспективу по сессии агента ("/retro", "как прошла эта сессия", "что могло бы быть сделано лучше в этой сессии"), для текущей сессии или заданного идентификатора сессии либо пути к транскрипту. Отчёт включает время по каждому этапу, ошибки вызовов инструментов, повторяющиеся медленные тестовые запуски и неэффективность навыков. Работает с Claude Code и pi.

Пожалуйста, всегда отвечайте на языке пользователя.
