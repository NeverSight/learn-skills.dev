Используется, когда пользователь запрашивает ретроспективу сеанса агента ("/retro", "как прошёл этот сеанс", "что могло бы быть сделано лучше в этом сеансе") для текущего сеанса либо для указанного идентификатора сеанса или пути к транскрипту. Сообщает время, затраченное на каждую фазу, ошибки вызова инструментов, повторяющиеся медленные запуски тестов и неэффективность навыков. Работает с Claude Code и pi.
