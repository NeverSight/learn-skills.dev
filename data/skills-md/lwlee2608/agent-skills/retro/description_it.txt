Usa quando l'utente richiede una retrospettiva su una sessione di agente ("/retro", "come è andata questa sessione", "cosa potrebbe migliorare questa sessione"), per la sessione corrente o per un ID sessione o percorso di trascrizione specificato. Riporta il tempo per fase, gli errori nelle chiamate agli strumenti, esecuzioni lente di test ripetute e inefficienze delle competenze. Funziona per Claude Code e pi.
