منهجية بنية اختيار الأنظمة والموردين باستخدام التقييم المرجّح مع معايير متوافقة مع أصحاب المصلحة. استخدم هذه المهارة عندما يطلب المستخدم تقييم الموردين، أو إنشاء طلب عروض (RFP)، أو قرارات البناء مقابل الشراء، أو اختيار النظام، أو اختيار ERP، أو اختيار CRM، أو تقييم المنصة، أو شراء البرمجيات، أو مقارنة موردي التكنولوجيا. تغطي دورة الحياة الكاملة من جمع المتطلبات وحتى التفاوض على العقد مع نمذجة التكلفة الإجمالية للملكية (TCO) وإطارات عمل عرض القرار.
