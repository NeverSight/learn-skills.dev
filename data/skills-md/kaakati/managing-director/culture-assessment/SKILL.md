# Culture Assessment & Transformation

## Required Inputs

| Input | Description | Required? |
|-------|-------------|-----------|
| Organization context | Industry, size, history, ownership, strategy | Yes |
| Stated values | Published mission, vision, values statements | Yes |
| Assessment purpose | Diagnostic, M&A DD, transformation, strategy alignment | Yes |
| Scope | Enterprise-wide, BU-specific, cross-entity (M&A) | Yes |
| Employee data | Headcount by function, level, location, tenure | Recommended |
| Engagement survey data | Most recent engagement/pulse survey results | Recommended |

| Leadership interviews | Access to 8-15 senior leaders for interviews | Recommended |
| Strategic plan | Strategy document to assess culture-strategy alignment | Recommended |

## Execution Steps

### 1. Culture Assessment Framework

Apply the **Competing Values Framework (CVF)** as the primary diagnostic model:

```
                        FLEXIBILITY & DISCRETION
                              |
              CLAN            |           ADHOCRACY
         (Collaborate)        |          (Create)
    - Teamwork, mentoring     |    - Innovation, agility
    - Loyalty, tradition      |    - Entrepreneurship
    - Consensus-driven        |    - Risk-taking, vision
    - Internal cohesion       |    - Experimentation
                              |
  INTERNAL -------------------|------------------- EXTERNAL
  FOCUS                       |                    FOCUS
                              |
           HIERARCHY          |           MARKET
          (Control)           |         (Compete)
    - Process, efficiency     |    - Results, winning
    - Stability, consistency  |    - Competition, goals
    - Rules, procedures       |    - Achievement, speed
    - Risk-averse             |    - Market share, profit
                              |
                       STABILITY & CONTROL
```

**CVF Scoring (aggregate from surveys and interviews):**

| Culture Type | Current Score (1-10) | Desired Score (1-10) | Gap | Implication |
|-------------|---------------------|---------------------|-----|-------------|
| Clan (Collaborate) | | | | |
| Adhocracy (Create) | | | | |
| Market (Compete) | | | | |
| Hierarchy (Control) | | | | |

The **dominant culture** is the highest-scoring type. The **gap** between current and desired reveals the transformation direction.

### 2. Assessment Methodology Options

**Multi-Method Approach (recommended for rigor):**

| Method | Sample Size | Data Type | Strengths | Limitations | Timeline |
|--------|------------|-----------|----------|-------------|----------|
| **Online survey** | All employees or stratified sample (n=200+) | Quantitative | Scalable, anonymous, statistical analysis | Self-report bias, low context | 2-3 weeks |
| **Leadership interviews** | 10-15 senior leaders | Qualitative | Depth, candor (if trust established), strategic perspective | Small sample, positional bias | 2-3 weeks |
| **Focus groups** | 6-10 groups of 8-12 employees | Qualitative | Rich narrative, cross-validation, uncover stories | Groupthink risk, time-intensive | 2-4 weeks |
| **Behavioral observation** | Site visits, meeting shadowing | Observational | Unfiltered reality, non-verbal cues | Observer effect, limited sample | 1-2 weeks |
| **Artifact analysis** | Documents, spaces, communications | Documentary | Objective evidence, triangulation | Incomplete picture, interpretation required | 1 week |
| **Network analysis (ONA)** | Email/collaboration metadata | Quantitative | Reveals informal networks, silos, influence | Privacy concerns, IT dependency | 2-4 weeks |

**Survey Design -- Core Culture Dimensions:**

| Dimension | Sample Survey Items (5-point Likert) |
|-----------|-------------------------------------|
| Innovation orientation | "We are encouraged to experiment, even if it means making mistakes" |
| Collaboration | "People across teams share information and help each other willingly" |
| Customer centricity | "Decisions are ultimately judged by their impact on customers" |
| Accountability | "People take ownership of outcomes, not just activities" |
| Speed / urgency | "We make decisions quickly and act on them" |
| Quality focus | "We would rather delay than deliver something below standard" |
| Risk tolerance | "Taking calculated risks is valued, even when they don't pay off" |
| Transparency | "Leaders share information openly, including bad news" |
| Meritocracy | "People advance based on performance and capability, not politics" |
| Psychological safety | "I can speak up with concerns without fear of negative consequences" |

### 3. Espoused vs. Enacted Values Gap Analysis

This is the most critical diagnostic step. Every organization has gaps -- the question is magnitude and risk.

**Gap Assessment Template:**

| Espoused Value (stated) | Evidence It Is Enacted | Evidence It Is NOT Enacted | Gap Severity (1-5) | Impact |
|-------------------------|----------------------|--------------------------|-------------------|--------|
| "Innovation" | [R&D budget, patent activity, new product launches] | [Ideas killed by bureaucracy, no innovation time, risk-averse leaders] | | [Employee cynicism, talent attrition] |
| "Customer first" | [NPS tracking, customer advisory board] | [Internal metrics prioritized, customer complaints escalate slowly] | | [Customer churn, brand erosion] |
| "People are our greatest asset" | [Development budgets, internal promotions] | [First cost cut is training, layoffs without dignity] | | [Trust deficit, disengagement] |
| "Integrity" | [Ethics hotline, compliance training] | [Pressure to hit numbers overrides ethics, selective enforcement] | | [Regulatory risk, reputation] |

**Sources of Evidence for Enacted Values:**

| Evidence Source | What It Reveals |
|----------------|----------------|
| Where the company spends money | True priorities (follow the budget) |
| Who gets promoted | Behaviors actually rewarded |
| Who gets fired (and who doesn't) | Accountability thresholds |
| How bad news is received | Psychological safety reality |
| What leaders do (not say) | Role modeling reality |
| Exit interview themes | Unfiltered truth from departing employees |
| Glassdoor / anonymous feedback | External perception of internal reality |
| Meeting behaviors | Decision-making, inclusion, candor norms |

| Compatibility Score | Recommended Approach | Description |
|--------------------|---------------------|-------------|

### 10. Target Culture Definition

**Target Culture Design Process:**

| Step | Activity | Output |
|------|---------|--------|
| 1 | Strategy review | Cultural attributes required by strategy |
| 2 | Current state assessment | Strengths to preserve, gaps to close |
| 3 | Leadership alignment workshop | Agreed target culture dimensions and behaviors |
| 4 | Behavioral definition | Observable behaviors at each level for each dimension |
| 5 | Validation | Test with broader employee groups for resonance and realism |

**Behavioral Definition Template:**

| Target Value / Dimension | Executive Behaviors | Manager Behaviors | Individual Contributor Behaviors | Anti-Patterns (what good does NOT look like) |
|--------------------------|--------------------|--------------------|-------------------------------|---------------------------------------------|
| [E.g., Customer Obsession] | Prioritize customer impact in every strategic decision; spend time with customers monthly | Empower teams to resolve customer issues without escalation; share customer feedback weekly | Proactively seek customer input; escalate friction points; know customer metrics | Referencing customers only in presentations; ignoring customer complaints; internal-metrics-only focus |

### 11. Culture Change Roadmap

**Four Levers of Culture Change:**

| Lever | What It Means | Actions | Timeline |
|-------|-------------|---------|----------|
| **Behaviors** | What people do daily; the most direct lever | Define target behaviors by level; leader role modeling; peer accountability; behavioral nudges | Immediate, ongoing |
| **Symbols** | Visible signals of what matters | Office design, meeting formats, language, dress code, who attends what meetings, stories told | Month 1-3 |
| **Systems** | Formal mechanisms that reinforce or undermine culture | Performance management, rewards, hiring criteria, decision rights, promotion criteria | Month 3-12 |
| **Stories** | Narratives that define "how we do things here" | Curate and amplify stories of desired behaviors; retire stories that reinforce old culture | Month 1-6 |

**Culture Change Phased Roadmap:**

| Phase | Timeline | Focus | Key Actions | Success Indicators |
|-------|----------|-------|------------|-------------------|
| 1. Align leadership | Month 1-2 | Top team alignment and commitment | Leadership workshop, personal commitment statements, executive coaching | 100% leadership team articulates target culture consistently |
| 2. Signal change | Month 2-4 | Visible symbolic changes | Quick wins, communication campaign, retire old symbols, introduce new rituals | Employees notice and comment on visible changes |
| 3. Enable change | Month 3-9 | Systems and processes alignment | Update performance criteria, hiring profiles, rewards, decision processes | New hires selected for culture fit; reviews include behaviors |
| 4. Embed change | Month 6-18 | Behavioral reinforcement at scale | Training, coaching, recognition programs, peer accountability, onboarding | Survey scores show movement toward target on key dimensions |
| 5. Sustain | Month 12+ | Continuous reinforcement | Ongoing measurement, leadership reinforcement, course corrections | Target culture scores sustained across 3+ measurement cycles |

### 12. Measurement Framework

**Leading Indicators (measure change in progress):**

| Indicator | Measurement Method | Frequency | Target |
|-----------|-------------------|-----------|--------|
| Leadership behavior alignment | 360 feedback on target behaviors | Quarterly | 80%+ role-modeling target behaviors |
| Employee awareness of target culture | Pulse survey question | Monthly | 90%+ can articulate target values |
| Behavioral observation scores | Manager observation, peer feedback | Quarterly | Improvement trend over 3 quarters |
| Story frequency | Track stories shared in comms that reinforce target culture | Monthly | X stories/month |
| Hiring for culture | % of new hires assessed for target culture behaviors | Quarterly | 100% assessed |

**Lagging Indicators (measure outcomes):**

| Indicator | Measurement Method | Frequency | Target |
|-----------|-------------------|-----------|--------|
| CVF culture profile shift | Full culture survey (CVF instrument) | Annually | Move X points toward target profile |
| Engagement scores | Engagement survey | Semi-annually | Improve by X points on key dimensions |
| Voluntary attrition | HR data | Monthly | Reduce to below X% |
| Customer satisfaction | NPS / CSAT | Quarterly | Improve by X points |
| Innovation metrics | New products, patents, ideas submitted | Quarterly | Increase by X% |
| Ethical incidents | Ethics hotline, compliance reports | Quarterly | Reduce by X% |

## Quality Checks

- [ ] Assessment uses a structured framework (CVF or equivalent) -- not ad hoc impressions or anecdotes
- [ ] Multiple assessment methods are employed (survey + interviews + observation minimum) for triangulation
- [ ] Espoused vs. enacted values gap analysis uses concrete evidence -- not opinion -- for each value
- [ ] Cultural dimensions are scored on defined scales with both current and target states
- [ ] Subculture mapping covers function, geography, level, and tenure dimensions
- [ ] Culture-strategy alignment links each strategic priority to required cultural attributes with gap scores
- [ ] Cultural risk assessment explicitly addresses toxic behaviors, ethical risk, and compliance culture
- [ ] M&A culture integration (if applicable) scores compatibility dimension-by-dimension with integration approach
- [ ] Target culture is defined in observable behavioral terms by level -- not abstract aspirational statements
- [ ] Culture change roadmap uses all four levers (behaviors, symbols, systems, stories) -- not just communications
- [ ] Measurement framework includes both leading indicators (in-progress) and lagging indicators (outcomes)
- [ ] Engagement data is correlated with cultural dimensions to identify highest-impact intervention points
- [ ] Report distinguishes between findings (data) and interpretations (analysis) throughout
