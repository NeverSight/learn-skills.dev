Exécutez du code Python dans un environnement sandbox sécurisé via [inference.sh](https://inference.sh). Préinstallés : NumPy, Pandas, Matplotlib, requests, BeautifulSoup, Selenium, Playwright, MoviePy, Pillow, OpenCV, trimesh et plus de 100 autres bibliothèques. Utilisez pour : traitement des données, extraction web, manipulation d’images, création vidéo, traitement de modèles 3D, génération de PDF, appels d’API, scripts d’automatisation. Déclencheurs : python, exécuter du code, exécuter un script, extraction web, analyse de données, traitement d’images, montage vidéo, modèles 3D, automatisation, pandas, matplotlib.
