Извлекать структурированную информацию с веб‑сайтов с помощью web_fetch для простых страниц и автоматизации браузера для динамических сайтов, потоков с требованием входа, пагинации, бесконечной прокрутки или страниц, требующих щелчков/поиска/фильтрации. Использовать, когда пользователь просит собрать данные с сайта, собрать списки, собрать поля с множества страниц, мониторить изменения сайта или превратить содержание веб‑страницы в структурированные резюме/JSON/CSV.
