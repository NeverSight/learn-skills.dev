Extraiga información estructurada de sitios web utilizando web_fetch para páginas simples y automatización del navegador para sitios dinámicos, flujos de inicio de sesión, paginación, desplazamiento infinito o páginas que requieren hacer clic/buscar/filtrar. Úselo cuando el usuario solicite raspar un sitio, recopilar listados, recopilar campos de muchas páginas, monitorear los cambios en el sitio web o convertir el contenido de la página web en resúmenes estructurados/JSON/CSV.
