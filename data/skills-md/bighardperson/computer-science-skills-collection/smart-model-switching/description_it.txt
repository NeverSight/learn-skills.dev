Instrada automaticamente i compiti al modello Claude più economico che funzioni correttamente. Progressione a tre livelli: Haiku → Sonnet → Opus. Classifica prima di rispondere. HAIKU (predefinito): domande fattuali, saluti, promemoria, controlli di stato, ricerche, operazioni su file semplici, heartbeat, conversazione informale, compiti di 1‑2 frasi. ESCALA A SONNET: codice >10 righe, analisi, confronti, pianificazione, rapporti, ragionamento a più passaggi, tabelle, scrittura lunga >3 paragrafi, sintesi, sintesi della ricerca, la maggior parte delle conversazioni dell'utente. ESCALA A OPUS: decisioni architetturali, debugging complesso, refactoring multi‑file, pianificazione strategica, giudizio sfumato, ricerca approfondita, decisioni critiche di produzione. Regola: se un essere umano ha bisogno di >30 secondi di pensiero concentrato, escalare. Se Sonnet fatica con la complessità, passa a Opus. Risparmia dal 50 al 90 % sui costi API iniziando con il più economico e scalando solo quando necessario. Rispondi sempre nella lingua dell'utente.
