Scans an existing application codebase and produces a snap-analysis.json file that captures everything needed to package the app as a snap: language/runtime, build system, entry points, system resource requirements, snap plugin recommendation, interface list, hook requirements, confinement type, and layout needs. Does NOT write snapcraft.yaml — its output is consumed by the snapcraft-author skill. WHEN: analyze snap requirements, snap analysis, scan for snap interfaces, identify snap plugs, snap project analysis, pre-packaging scan, snap dependency discovery, snap confinement analysis, snap interface mapping, prepare snap packaging.
