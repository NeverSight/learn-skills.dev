샷 분해: 완성된 동영상을 개별 샷별 분석 표로 나누기 — 각 샷의 길이, 샷 타입, 카테고리, 카메라 움직임, 비주얼.

노동 분업은 내재되어 있음: **“에너지”는 모두 코드에서 파생** (컷 포인트는 ffmpeg 씬 탐지에서 얻고, 길이는 컷 포인트 간 차이; 움직임 양은 프레임별 차이의 중앙값). 모델은 실제로 결정해야 할 몇 가지(샷 타입 / 카테고리 / 카메라 움직임 / 비주얼 / 리듬)만 선택하고, 각 결정은 즉시 코드에 의해 검증됨 — **돌리/줌/팬/틸트 주장들은 측정상 거의 정적으로 판명되어 게이트에서 즉시 차단**.

시청은 컨택트 시트 방식으로 이루어짐(각 샷의 첫 프레임과 마지막 프레임을 큰 이미지에 각각 배치; 하나의 화면에 수십 개 샷을 표시하고, a/b 비교로 카메라 움직임을 반영), 샷을 하나씩 넘겨보는 것이 아님. 놓친 컷이나 추가된 컷은 재컷으로 처리하여 컷을 추가·제거하고, 번호를 자동으로 재배열하고 길이를 재계산함; 게이트를 통과하지 못하는 수동 경계 조정은 거부됨.

출력물: shots.json + 마크다운 샷 표 + **단일 페이지 인터랙티브 샷‑분해 보고서**: 삽입된 플레이어(재생 중 현재 샷을 동기화하여 강조, 샷 클릭 시 해당 지점으로 이동), 샷 리듬 바, 검색·필터·정렬 가능한 샷 표(목록 및 카드 뷰, 시작·종료 키프레임을 나란히 표시, 썸네일 클릭 시 확대), 샷 타입·카테고리·카메라 움직임·등장 인물·품질 게이트 분포, JSON 내보내기. 단일 파일, 의존성 제로; 더블 클릭으로 오프라인에서 바로 열 수 있음.

15가지 품질 게이트 모두 스크립트로 결정론적으로 검사됨. 의존성 제로, API 키 제로; 필요한 것은 node와 ffmpeg뿐.
