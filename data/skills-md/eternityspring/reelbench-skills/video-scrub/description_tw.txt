把影片重建成只包含畫面與聲音的乾淨檔案——**不會轉移原始影片的任何中繼資料**：GPS、裝置型號、帳號 ID、建立時間、章節、GoPro 遙測軌跡——全部保留在原處。我們使用白名單而非黑名單：我們不列出要刪除的項目，只指定要帶入的內容（一次影片串流、一次音訊串流）。隱私保護來自結構，而非列舉。

困難不在於容器標籤，而在**看不見的層面**：x264 會把完整的編碼參數寫入 SEI 並塞進位元流，AAC 把版本號寫入 DSE，avc1 的 compressorname 也會包含一份——`ffprobe` 看不到任何這些資訊。我們逐一封鎖這五個隱藏點，並以測試驗證。

預設 `--mode copy`：**影片以位元組逐一複製**（用 cmp 驗證），只有音訊重新編碼；53 秒的剪輯在 1.3 秒內完成。  
`--mode encode` 完全重新編碼，移除更多位元流層面的資料。

接受標準不依賴聲稱：我們把來源影片的每個中繼資料字串當作「針」來處理，對輸出檔案進行**位元層級掃描**——只要命中一次即視為失敗。全部十二個檢查點皆由腳本決定性檢查。

零相依套件，零 API 金鑰；只需 node 與 ffmpeg。

使用情境：當被要求清除中繼資料、移除中繼資料、抹除影片資訊、影片隱私、移除水印資訊、剝離影片中繼資料、移除影片 EXIF、清理影片時。
