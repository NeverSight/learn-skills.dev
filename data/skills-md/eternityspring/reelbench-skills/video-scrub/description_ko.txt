비디오를 재구성하여 비디오와 오디오만 포함된 깨끗한 파일을 만든다 — **원본 메타데이터는 전혀 전송되지 않는다**: GPS, 기기 모델, 계정 ID, 생성 시간, 챕터, GoPro 텔레메트리 트랙 등은 모두 그대로 남는다. 블랙리스트가 아니라 화이트리스트 방식으로 동작한다: 삭제할 항목을 나열하는 대신 가져올 항목(비디오 스트림 하나, 오디오 스트림 하나)을 명시한다. 프라이버시 보장은 열거가 아니라 구조에서 온다. 어려움은 컨테이너 태그가 아니라 **보이지 않는 레이어**에 있다: x264는 전체 인코딩 파라미터를 SEI로 기록해 비트스트림에 삽입하고, AAC는 버전 번호를 DSE에 기록하며, avc1의 compressorname에도 복사본이 포함된다—`ffprobe`로는 이들을 볼 수 없다. 다섯 개의 숨겨진 위치를 하나씩 차단했으며, 각각 실험적으로 검증했다. 기본 `--mode copy`: **비디오는 바이트 단위로 그대로 복사**(cmp로 검증)되고, 오디오는 재‑인코딩된다; 53초 클립이 1.3초에 완료된다; `--mode encode`는 완전 재‑인코딩을 수행해 비트스트림 영역 데이터를 더 많이 제거한다. 수용 여부는 주장에 근거하지 않는다: 원본의 모든 메타데이터 문자열을 “바늘”로 간주하고 출력 파일을 **바이트 수준으로 스캔**한다—하나라도 발견되면 실패한다. 12개의 검사는 모두 스크립트로 결정적으로 검증된다. 의존성 zero, API 키 zero, 필요한 것은 node와 ffmpeg뿐이다. 메타데이터 정리, 메타데이터 제거, 비디오 정보 삭제, 비디오 프라이버시, 워터마크 정보 제거, 비디오 메타데이터 스트립, 비디오에서 exif 제거, 비디오 스크럽이 필요할 때 사용한다.
