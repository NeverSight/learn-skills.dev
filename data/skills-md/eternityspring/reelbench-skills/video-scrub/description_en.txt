Rebuild a video into a clean file that contains only picture and sound — **no source metadata is transferred**:
GPS, device model, account ID, creation time, chapters, GoPro telemetry tracks, all stay where they are.  
We use a whitelist instead of a blacklist: we don’t list what to delete, we only specify what to bring over (one video stream, one audio stream).  
Privacy guarantees come from the structure, not from enumeration.  
The difficulty is not in the container tags, but in **the invisible layers**: x264 writes the full encoding parameters as SEI and stuffs them into the bitstream,  
AAC writes the version number into DSE, avc1’s compressorname also contains a copy — `ffprobe` sees none of them.  
The five hiding places are blocked one by one, each verified by tests.  
Default `--mode copy`: **video is copied byte‑by‑byte** (verified with cmp), only audio is re‑encoded; a 53‑second clip finishes in 1.3 seconds;  
`--mode encode` does a full re‑encode, removing even more bitstream‑level data.  
Acceptance is not based on claims: we treat every metadata string from the source as a “needle” and perform a **byte‑level scan** in the output file,  
as soon as we find one, it fails. All 12 checks are deterministically performed by scripts.  
Zero dependencies, zero API key, only node and ffmpeg are needed.
