클립 데이터와 원본 영상을 하나의 **시청 가능한 비디오**로 결합합니다: 한쪽에는 화면을, 다른 쪽에는 해당 샷에 대한 스토리보드 정보를 표시합니다 (샷 번호, 시작/끝, 기간, 구도, 카테고리, 카메라 움직임, 시각적 설명, 대사). 샷이 전환될 때 정보도 함께 전환되며, 샷 리스트가 자동으로 스크롤되고 현재 샷을 강조 표시합니다.

레이아웃은 원본 가로세로 비율에만 따라 달라집니다: **가로 / 정사각형 → 화면이 위에, 정보가 아래에; 세로 → 화면이 왼쪽, 정보가 오른쪽**. 화면은 항상 비례적으로 스케일링되며—잘라내거나 늘리지 않습니다.

샷 리스트는 **재생과 함께 스크롤**됩니다: 각 컷마다 짧게 스크롤하여 현재 샷을 기준점으로 이동시킨 뒤 멈추고, 강조 바가 동기화되어 슬라이드합니다.

구현은 세 장의 이미지(배경 플레이트 + 펼쳐진 긴 이미지 두 장)만 캡처합니다. 스크롤링과 강조는 ffmpeg를 사용해 시간 기반 크롭 창으로 처리합니다. **모든 레이아웃은 `scripts/panel.css`에 정의되어 있습니다; 스크립트를 건드리지 않고 레이아웃을 변경하려면 해당 파일을 수정하면 됩니다**.

`shots.json`(video‑shots에서 생성된 파일)을 사용합니다(`frames/` 폴더가 있으면 키프레임을 썸네일로 사용). npm 의존성이 전혀 없으며; 합성은 ffmpeg로 수행하고 헤드리스 브라우저가 패널을 렌더링합니다.

**다음 작업을 요청받을 때 사용**: 비디오 내보내기, 비디오 병합, 스토리보드 비디오 생성, 스토리보드 정보를 포함한 비디오 제작, 내레이션 버전 생성, **샷 정보가 포함된 비디오**, **주석이 달린 샷 비디오**.

항상 사용자의 언어로 답변해 주세요.
