Объедините данные вырезанных клипов и оригинальный видеоматериал в **непосредственно просматриваемое видео**: с одной стороны показывается изображение, с другой — информация раскадровки для данного кадра (номер кадра, начало‑конец, длительность, размер кадра, категория, движение камеры, визуальное описание, диалог), **при резке кадра информация обрезается одновременно**, а таблица кадров автоматически прокручивается и выделяет текущий кадр.  

Макет зависит только от соотношения сторон оригинального видеоматериала: **альбомный / квадратный → изображение сверху, информация снизу; портретный → изображение слева, информация справа**, при этом изображение всегда масштабируется пропорционально — без обрезки или растягивания.  

Таблица кадров **прокручивается вместе с воспроизведением**: в каждой точке резки она смещается на небольшое расстояние, чтобы привести текущий кадр к фиксированной точке, затем останавливается, а полоса выделения скользит синхронно.  

Реализация извлекает только три изображения (фон + две развернутые длинные картинки); прокрутка и выделение выполняются ffmpeg с помощью обрезки по времени, **весь макет находится в scripts/panel.css; отредактируйте его для изменения макета**, без изменения каких‑либо скриптов.  

Он использует `shots.json`, созданный video‑shots (если существует папка `frames/`, ключевые кадры используются в качестве эскизов).  

Никакие зависимости npm не требуются; использует ffmpeg для компоновки и безголовый браузер для рендеринга панели.  

Применяйте, когда просят **экспортировать видео, составное видео, видео‑рассказку, видео с информацией о кадрах, озвученную версию видео, видео с данными о кадрах, аннотированное видео кадра**.
