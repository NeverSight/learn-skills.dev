Escriba un guión para un drama corto de IA: convierta los esquemas del episodio de una novela en una lista estructurada de escenas más un flujo de ritmo (alternando ritmos de acción y líneas de diálogo). Cada línea de diálogo debe incluir al hablante y el tono, y la duración de cada episodio se calcula de manera determinista en función de la velocidad del habla. Produzca script.json, Markdown y un informe de revisión de una sola página (indicador de duración/guiones de episodios/tabla de escenas general/guión de diálogo agregado por carácter, incluido JSON exportado). El guión gestiona el drama, el guión gráfico gestiona el rodaje; esta habilidad no crea un guión gráfico, no tiene números de tomas y no escribe indicaciones de generación; esos pertenecen a una habilidad de guión gráfico de nivel más profundo.

Los diez controles de calidad se aplican mediante comprobaciones de guión deterministas (duración del episodio ±15%; cada línea ≤35 caracteres; orador válido; suspenso escrito en papel; gancho entregado concretamente dentro de los primeros tres tiempos (hookBeat afirma una apertura fría); al menos un tiempo de acción por escena; reclamo de un punto satisfactorio; reconciliación de personajes, escenarios, iluminación, accesorios, etc.). Si contorno.json está presente, utilícelo como semilla para rellenar previamente el esqueleto de cada episodio; proporcionar el estado de iluminación junto con el arte de la reconciliación.

Cero dependencias, cero clave API, utilizando la cuota de sesión actual. Úselo cuando se le solicite escribir un guión, producir un guión, diálogos, escenas, escribir un drama o escribir un guión para un drama corto de IA.
