Write scripts for AI short dramas: transform the episode summaries of a novel-outline into structured scenes + beat flow (alternating action beats and lines of dialogue).  
Each line of dialogue includes the speaker and tone, and the duration per episode is deterministically calculated based on speech rate. Produce script.json, Markdown, and a single-page review report (duration gauge / episode scripts / scene master list / dialogue script aggregated by character, including exported JSON).  
The script manages the drama, the storyboard manages the shooting—this skill does not handle storyboard frames, has no shot numbers, and does not write generation prompts; those belong to the next-level storyboard skill.  
All ten quality checkpoints are deterministically verified by the script (episode length within ±15%, each line ≤35 characters, valid speakers, hooks and suspense written on paper, hooks realized within the first three beats (hookBeat claims the cold opening), at least one action beat per scene, claim of payoff moments, upstream reconciliation of characters/sets/lighting/props, etc.).  
If outline.json is present, use it as a seed to pre-fill each episode’s skeleton; with the --art option, reconcile lighting states as well.  
Zero dependencies, no API key, using the current session quota.  
Use when asked to write scripts, produce scripts, dialogue, scenes, write dramas, screenwriting for AI short drama.
