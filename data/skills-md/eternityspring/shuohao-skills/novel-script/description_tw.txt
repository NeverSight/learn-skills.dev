编写人工智能短剧剧本：将小说大纲的情节摘要转换为结构化场景+节拍流（交替的动作节拍和对话台词）。  
每行对话都包括说话者和语气，每集的持续时间是根据语速确定性计算的。產生 script.json、Markdown 和單頁審核報告（按角色聚合的時長計/劇集腳本/場景主清單/對話腳本，包括匯出的 JSON）。  
劇本管理戲劇，分鏡管理拍攝－這個技能不處理分鏡框架，沒有鏡頭編號，也不寫生成提示；這些屬於下一級故事板技能。  
所有十個品質檢查點均由劇本確定性驗證（劇集長度在±15%以內，每行≤35個字符，有效的演講者，紙上寫的掛鉤和懸念，在前三個節拍內實現的掛鉤（hookBeat聲稱冷開場），每個場景至少一個動作節拍，要求回報時刻，角色/佈景/燈光/道具的協調上游等）。  
如果outline.json存在，使用它作为种子来预填充每集的骨架；使用 --art 选项，也可以协调照明状态。  
零依赖，无 API 密钥，使用当前会话配额。  
当要求写剧本时使用，制作剧本、对话、场景、写戏剧、为AI短剧编剧。
