Напишите сценарии для коротких драм с искусственным интеллектом: преобразуйте краткое содержание эпизодов романа в структурированные сцены + поток битов (чередующиеся ритмы действия и строки диалога).  
Каждая строка диалога включает говорящего и тон, а продолжительность эпизода детерминированно рассчитывается на основе скорости речи. Создайте файл script.json, Markdown и одностраничный отчет о проверке (шкала продолжительности/сценарии эпизодов/основной список сцен/сценарий диалогов, агрегированные по персонажам, включая экспортированный JSON).  
Сценарий управляет драмой, раскадровка управляет съемками — этот навык не обрабатывает кадры раскадровки, не имеет номеров кадров и не записывает подсказки для генерации; они относятся к навыкам раскадровки следующего уровня.  
Все десять контрольных точек качества детерминированно проверяются сценарием (длина эпизода в пределах ±15%, каждая строка ≤35 символов, допустимые динамики, зацепки и саспенс, написанные на бумаге, зацепки, реализованные в течение первых трех тактов (hookBeat утверждает, что это холодное начало), по крайней мере, один такт действия на сцену, утверждение моментов выигрыша, восходящая согласованность персонажей/декораций/освещения/реквизита и т. д.).  
Если имеется файл Outline.json, используйте его в качестве начального значения для предварительного заполнения скелета каждого эпизода; с опцией --art также согласовывайте состояния освещения.  
Нулевые зависимости, отсутствие ключа API, использование текущей квоты сеанса.  
Используйте, когда вас просят написать сценарии, создать сценарии, диалоги, сцены, написать драму, написать сценарий для короткометражной драмы с искусственным интеллектом.
