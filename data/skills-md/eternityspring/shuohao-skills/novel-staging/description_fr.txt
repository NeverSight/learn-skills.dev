Organisez les positions d’ouverture pour chaque scène d’un court métrage d’IA : commencez par identifier, à partir du diagramme de la scène, les éléments sur lesquels on peut se tenir ou s’asseoir (projetés sur un plan vu de dessus), puis, selon le script, attribuez pour chaque scène qui se trouve de quel côté de quel élément, s’ils s’assoient ou se tiennent debout, dans quelle direction ils font face, et s’il y a des acteurs de fond. Le programme génère une phrase décrivant le mouvement d’ouverture pour chaque scène ; copiez cette phrase comme premier paragraphe du storyboard de cette scène. Par défaut, fournissez un rapport d’outil HTML qui permet de glisser‑déposer pour ajuster les positions, avec la possibilité d’exporter un fichier staging.json depuis la page ; le JSON est également enregistré comme données de travail, et le Markdown peut être exporté si besoin. Les huit contrôles de qualité sont exécutés de manière déterministe par le script (vérifier le nombre d’éléments reconnus, les éléments placés sur le diagramme, le nombre de personnages apparaissant n’est ni trop élevé ni trop faible, les personnages présents sont placés sur les éléments reconnus, aucun chevauchement de personnages du même côté, les acteurs de fond clairement indiqués, etc.). Utilisez le script.json de novel‑script et art.json de novel‑art pour pré‑remplir le squelette. Zéro dépendance, zéro clé API. Utilisez‑le lorsqu’on vous demande le positionnement, le positionnement d’ouverture, le positionnement de groupe‑scène, qui s’assoit où, l’agencement des sièges, les mouvements, le blocage, la mise en scène pour un court métrage d’IA.

Veuillez toujours répondre dans la langue de l’utilisateur.
