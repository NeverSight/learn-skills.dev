Arrange the opening positions for each scene of an AI short drama: first identify from the scene diagram the items that can be stood on or sat on (projected onto a top‑down plane), then, according to the script, assign for each scene who is on which side of which item, whether they sit or stand, which direction they face, and whether there are background actors. The program generates a sentence describing the opening movement for each scene; copy that sentence as the first paragraph of the storyboard for that scene. By default, deliver an HTML tool report that allows dragging to adjust positions, with the ability to export a staging.json file from the page; the JSON is also saved as working data, and Markdown can be exported as needed. All eight quality checks are deterministically performed by the script (verify the number of recognized items, items placed on the diagram, the number of appearing characters is neither too many nor too few, present characters are placed on the recognized items, no overlapping characters on the same side, background actors clearly indicated, etc.). Use the script.json from novel‑script and art.json from novel‑art to pre‑fill the skeleton. Zero dependencies, zero API key. Use when asked for positioning, opening positioning, group‑scene positioning, who sits where, arranging seats, movement, blocking, staging for AI short drama.
