Organiza las posiciones de apertura para cada escena de un cortometraje de IA: primero identifica en el diagrama de la escena los objetos sobre los que se puede estar de pie o sentarse (proyectados en un plano superior), luego, según el guion, asigna para cada escena quién está en qué lado de qué objeto, si se sienta o se para, hacia qué dirección mira y si hay actores de fondo. El programa genera una frase que describe el movimiento de apertura para cada escena; copia esa frase como el primer párrafo del storyboard de esa escena. Por defecto, entrega un informe de herramienta HTML que permite arrastrar para ajustar posiciones, con la capacidad de exportar un archivo staging.json desde la página; el JSON también se guarda como datos de trabajo, y se puede exportar Markdown según sea necesario. Los ocho controles de calidad se realizan de manera determinista mediante el script (verificar el número de objetos reconocidos, objetos colocados en el diagrama, que el número de personajes que aparecen no sea ni demasiado grande ni demasiado pequeño, los personajes presentes están colocados en los objetos reconocidos, sin superposición de personajes en el mismo lado, actores de fondo indicados claramente, etc.). Usa script.json de novel‑script y art.json de novel‑art para pre‑llenar el esqueleto. Cero dependencias, cero clave API.
