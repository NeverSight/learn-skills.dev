Ordnen Sie die Anfangspositionen für jede Szene eines KI‑Kurzdramas an: Identifizieren Sie zunächst im Szenendiagramm die Gegenstände, auf die man stehen oder sitzen kann (auf eine von oben betrachtete Ebene projiziert), und weisen Sie dann gemäß dem Skript für jede Szene zu, wer auf welcher Seite welches Objekt befindet, ob er sitzt oder steht, in welche Richtung er blickt und ob Hintergrunddarsteller vorhanden sind. Das Programm erzeugt einen Satz, der die Eröffnungsbewegung für jede Szene beschreibt; kopieren Sie diesen Satz als ersten Absatz des Storyboards für die jeweilige Szene. Standardmäßig liefern Sie einen HTML‑Tool‑Report, der das Ziehen zum Anpassen der Positionen ermöglicht, mit der Fähigkeit, eine staging.json‑Datei von der Seite zu exportieren; das JSON wird ebenfalls als Arbeitsdaten gespeichert, und bei Bedarf kann Markdown exportiert werden. Alle acht Qualitätsprüfungen werden deterministisch vom Skript durchgeführt (Überprüfung der Anzahl erkannter Gegenstände, platzierte Gegenstände im Diagramm, die Anzahl der erscheinenden Charaktere ist weder zu hoch noch zu niedrig, vorhandene Charaktere stehen auf den erkannten Gegenständen, keine überlappenden Charaktere auf derselben Seite, Hintergrunddarsteller klar gekennzeichnet usw.). Verwenden Sie das script.json aus novel‑script und art.json aus novel‑art, um das Gerüst vorzubelegen. Keine Abhängigkeiten, kein API‑Schlüssel. Verwenden Sie das, wenn nach Positionierung, Eröffnungspositionierung, Gruppenszenen‑Positionierung, wer wo sitzt, Sitzanordnung, Bewegung, Blocking, Inszenierung für KI‑Kurzdramen gefragt wird.

Bitte immer in der Sprache des Benutzers antworten.
