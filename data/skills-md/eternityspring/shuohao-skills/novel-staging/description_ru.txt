Организуйте стартовые позиции для каждой сцены короткой AI‑драмы: сначала определите из схемы сцены объекты, на которые можно встать или сесть (проецированные на плоскость сверху), затем, согласно сценарию, назначьте для каждой сцены, кто находится на какой стороне какого объекта, сидит он или стоит, в каком направлении смотрит и есть ли фоновые актёры. Программа генерирует предложение, описывающее начальное движение для каждой сцены; скопируйте это предложение в качестве первого абзаца сториборда для этой сцены. По умолчанию предоставьте отчёт в виде HTML‑инструмента, позволяющего перетаскивать элементы для корректировки позиций, с возможностью экспортировать файл staging.json со страницы; JSON также сохраняется как рабочие данные, а при необходимости можно экспортировать Markdown. Все восемь проверок качества детерминированно выполняются скриптом (проверка количества распознанных объектов, размещённых на схеме, количество появляющихся персонажей не слишком велико и не слишком мало, присутствующие персонажи расположены на распознанных объектах, отсутствие перекрытия персонажей на одной стороне, фоновые актёры явно указаны и т.д.). Используйте script.json из novel‑script и art.json из novel‑art для предварительного заполнения скелета. Ноль зависимостей, ноль API‑ключей. Применяйте при запросе позиционирования, начального позиционирования, группового позиционирования сцен, кто где сидит, расстановки мест, движения, блокировки, постановки для AI‑короткой драмы.
