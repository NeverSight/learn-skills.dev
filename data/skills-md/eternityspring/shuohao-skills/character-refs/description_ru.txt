Предоставьте аутентичные референс‑изображения для любого персонажа в истории (адаптация романа, оригинальная история или отдельный дизайн персонажа; оригинальный текст романа не требуется):
Начните с абзаца, описывающего персонажа, разделённого на слоистые поля, завершите и подтвердите их,
Сначала сгенерируйте фронтальное полно‑туловое «якорное» изображение; все остальные виды (портрет крупным планом, боковой вид под углом 90°, вид сзади, детали, портрет крупным планом под углом 45°) должны ссылаться только на это якорное изображение,
Создавайте изображения уровнями по мере необходимости. Каждое изображение включает идентификатор, может быть перегенерировано индивидуально, и после регенерации система автоматически помечает, какие изображения устарели.
Поддерживает Qwen Image (ComfyUI), встроенную генерацию изображений Codex, API изображений OpenAI (GPT‑4 Vision) и пользовательские команды; основное изображение и производные изображения могут использовать разные модели.
Выводит файл asset.json плюс набор PNG‑файлов и отчёт, который можно открыть двойным щелчком. Никаких зависимостей.
Если дан только запрос и изображение не создано, используйте «novel‑characters».
Используйте при запросе создания изображений персонажей, создания референсных изображений персонажей, генерации изображений для моего персонажа, создания финальных «макияжных» снимков, создания настоящих трёх‑видовых рендеров, референсных изображений персонажей.
