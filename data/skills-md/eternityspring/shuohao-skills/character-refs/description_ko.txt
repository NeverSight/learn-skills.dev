스토리의 어떤 캐릭터든 진정성 있는 레퍼런스 이미지를 생성합니다 (소설 각색, 원본 이야기, 혹은 독립적인 캐릭터 디자인에 적용 가능; 원본 소설 텍스트는 필요 없음):
캐릭터를 설명하는 단락을 제공하고, 이를 계층화된 필드로 나눈 뒤 채운 후 확인합니다.
먼저 앞면 전신 앵커 이미지를 만들고; 다른 모든 뷰(인물 초상, 90° 측면 보기, 뒤쪽 보기, 디테일 샷, 45° 초상)는 이 앵커만을 기준으로 합니다.
필요에 따라 단계별로 이미지를 제작합니다. 각 이미지마다 식별자가 포함되며 개별적으로 재생성할 수 있고, 재생성 후 자동으로 어떤 이미지가 오래되었는지 표시합니다.
Qwen Image (ComfyUI), Codex 내장 이미지 생성, OpenAI Images API (GPT Image 2), 그리고 맞춤 명령을 지원합니다; 메인 이미지와 파생 이미지는 서로 다른 모델을 사용할 수 있습니다.
asset.json 파일 + PNG 세트 + 더블 클릭으로 열 수 있는 보고서를 출력합니다. 의존성 없이 동작합니다.
프롬프트만 주어지고 이미지가 생성되지 않을 경우, 소설 캐릭터를 사용합니다.
‘캐릭터 이미지를 생성해 주세요’, ‘캐릭터 레퍼런스 이미지를 만들어 주세요’, ‘내 캐릭터 이미지를 만들어 주세요’, ‘최종 레퍼런스 샷을 만들고 싶어요’, ‘진정한 3뷰 레퍼런스를 만들고 싶어요’, ‘캐릭터 레퍼런스 이미지를 제공해 주세요’와 같이 요청받았을 때 사용합니다.

항상 사용자의 언어로 응답해주세요.
