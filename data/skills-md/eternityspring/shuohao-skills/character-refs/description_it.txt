Fornire vere immagini di riferimento per qualsiasi personaggio in una storia (adattamenti di romanzi, storie originali o un personaggio progettato autonomamente, senza richiedere il testo originale del romanzo):
Iniziare con un paragrafo che descriva il personaggio, suddividerlo in campi a strati, completarlo e confermarlo.
Generare prima un’immagine di ancoraggio frontale a figura intera; tutte le altre visualizzazioni (primo piano, vista laterale a 90°, vista posteriore, dettagli, primo piano a 45°) si basano solo su questa immagine di ancoraggio.
Generare le immagini su richiesta in livelli separati. Ogni immagine ha un identificatore, può essere rigenerata singolarmente e, dopo la rigenerazione, il sistema contrassegna automaticamente quali immagini sono obsolete.
Supporta Qwen Image (ComfyUI), rendering integrato di Codex, OpenAI Images API (GPT‑4 Image 2) e comandi personalizzati; l’immagine principale e le immagini derivate possono utilizzare modelli diversi.
Produci un asset.json, un set di PNG e un report cliccabile per aprire. Zero dipendenze.
Se viene fornito solo un prompt e non viene prodotta alcuna immagine, utilizzare personaggi di romanzo.
Usare quando viene chiesto di generare immagini di personaggi, creare immagini di riferimento del personaggio, renderizzare il mio personaggio, produrre una foto set‑dress, fornire realmente immagini a tre viste, immagini di riferimento del personaggio.

Rispondi sempre nella lingua dell’utente.
