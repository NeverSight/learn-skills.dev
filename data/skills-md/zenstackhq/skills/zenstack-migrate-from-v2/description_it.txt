Aggiorna un progetto ZenStack V2 esistente a V3. Da utilizzare quando si rinominano i pacchetti V2 (zenstack, @zenstackhq/runtime), si sposta il controllo degli accessi sul plugin della policy, si converte future() in post-update/before(), si sostituiscono modelli astratti con tipi+mixins, si aggiornano adattatori server (getPrisma → getClient) e si migrano hook TanStack Query lato client.
