Administre las migraciones de esquemas de bases de datos en ZenStack V3. Úselo al crear/aplicar migraciones (zen migrar dev/deploy/reset/status/resolve), crear prototipos con zen db push, introspeccionar una base de datos existente con zen db pull, inicializar, manejar funciones (vistas) no compatibles con --create-only o conectar migraciones a una canalización de implementación.
