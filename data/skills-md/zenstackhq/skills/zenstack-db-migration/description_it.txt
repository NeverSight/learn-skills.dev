Gestisci le migrazioni dello schema del database in ZenStack V3. Da utilizzare durante la creazione/applicazione di migrazioni (zen migrate dev/deploy/reset/status/resolve), la prototipazione con zen db push, l'introspezione di un database esistente con zen db pull, il seeding, la gestione di funzionalità non supportate (viste) con --create-only o il cablaggio delle migrazioni in una pipeline di distribuzione.
