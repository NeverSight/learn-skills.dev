Управляйте миграцией схемы базы данных в ZenStack V3. Используйте при создании/применении миграций (zenmigrate dev/deploy/reset/status/resolve), прототипировании с помощью zen db push, анализе существующей базы данных с помощью zen db pull, заполнении, обработке неподдерживаемых функций (представлений) с помощью --create-only или подключении миграций к конвейеру развертывания.
