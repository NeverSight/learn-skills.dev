Sviluppa plugin ZenStack V3. Da utilizzare durante la creazione o la dichiarazione di un plugin: attributi/funzioni ZModel personalizzati, generatori di codice CLI (CliPlugin con un callback di generazione per `zen generate`) o plugin runtime installati tramite $use/definePlugin (onQuery, onKyselyQuery, hook onEntityMutation, estensione del client, argomenti di query personalizzati, campi dei risultati calcolati).
