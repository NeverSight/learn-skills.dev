Desarrollar complementos ZenStack V3. Úselo al crear o declarar un complemento: atributos/funciones de ZModel personalizados, generadores de código CLI (CliPlugin con una devolución de llamada de generación para `zen generate`), o complementos de tiempo de ejecución instalados a través de $use/definePlugin (onQuery, onKyselyQuery, enlaces onEntityMutation, extensión del cliente, argumentos de consulta personalizados, campos de resultados calculados).
