Développer les plugins ZenStack V3. À utiliser lors de la création ou de la déclaration d'un plugin : attributs/fonctions ZModel personnalisés, générateurs de code CLI (CliPlugin avec un rappel de génération pour "zen generate") ou plugins d'exécution installés via $use/definePlugin (onQuery, onKyselyQuery, hooks onEntityMutation, extension du client, arguments de requête personnalisés, champs de résultat calculés).
