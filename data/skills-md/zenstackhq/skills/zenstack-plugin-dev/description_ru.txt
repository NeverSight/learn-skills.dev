Разрабатывайте плагины ZenStack V3. Используйте при создании или объявлении плагина — пользовательские атрибуты/функции ZModel, генераторы кода CLI (CliPlugin с обратным вызовом генерации для `zengenerate`) или плагины времени выполнения, установленные через $use/definePlugin (перехватчики onQuery, onKyselyQuery, onEntityMutation, расширение клиента, пользовательские аргументы запроса, вычисляемые поля результатов).
