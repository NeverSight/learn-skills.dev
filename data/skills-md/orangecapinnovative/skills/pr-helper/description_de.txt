Erstelle einen neuen Pull Request oder aktualisiere einen offenen Pull Request mit einem klaren Änderungsprotokoll und einer Beschreibung in beliebigem Repository. Folgt der PR‑Vorlage des Repositories, erhöht die semantischen Versionsnummern anhand der neuesten GitHub‑Tags und lässt Backticks im Textkörper weg. Verwende dies, wann immer der Benutzer bittet, einen Pull Request zu öffnen, zu erstellen, zu aktualisieren oder zu verwalten. Bitte antworte immer in der Sprache des Benutzers.
