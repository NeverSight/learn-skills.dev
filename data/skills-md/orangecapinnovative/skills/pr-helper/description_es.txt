Abre un nuevo PR o actualiza un PR abierto con un registro de cambios claro y una descripción, en cualquier repositorio. Sigue la plantilla de PR del repositorio, incrementa las versiones semánticas a partir de las últimas etiquetas de GitHub y evita usar comillas invertidas en el cuerpo. Utilízalo siempre que el usuario solicite abrir, crear, actualizar o gestionar una solicitud de extracción.

Por favor, responde siempre en el idioma del usuario.
