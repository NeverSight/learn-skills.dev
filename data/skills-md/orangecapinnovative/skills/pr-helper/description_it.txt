Apri una nuova pull request o aggiorna una pull request aperta con un changelog chiaro e una descrizione, in qualsiasi repository. Segue il modello di PR del repository, aggiorna le versioni semantiche dagli ultimi tag di GitHub e mantiene i backtick fuori dal corpo. Usalo ogni volta che l'utente chiede di aprire, creare, aggiornare o gestire una pull request. Per favore rispondi sempre nella lingua dell'utente.
