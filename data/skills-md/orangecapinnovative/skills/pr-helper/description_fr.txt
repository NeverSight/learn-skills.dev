Ouvrez une nouvelle PR ou mettez à jour une PR existante avec un journal de modifications clair et une description, dans n'importe quel dépôt. Respectez le modèle de PR du dépôt, incrémentez les versions sémantiques à partir des derniers tags GitHub, et évitez les backticks dans le corps. Utilisez‑le chaque fois que l'utilisateur demande d'ouvrir, créer, mettre à jour ou gérer une pull request. Veuillez toujours répondre dans la langue de l'utilisateur.
