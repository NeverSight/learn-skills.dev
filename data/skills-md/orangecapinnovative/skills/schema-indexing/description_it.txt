Crea script di gestione degli indici MongoDB per progetti NestJS + Mongoose. Usali quando ti viene chiesto di aggiungere, modificare o gestire gli indici del database su qualsiasi collezione. Impone il pattern “indici come script, mai inline” — non mette mai le definizioni degli indici nei file di schema né si affida a autoIndex. Rispondi sempre nella lingua dell'utente.
