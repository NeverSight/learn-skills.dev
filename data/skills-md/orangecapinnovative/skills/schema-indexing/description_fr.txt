Créez des scripts de gestion des index MongoDB pour les projets NestJS + Mongoose. Utilisez‑les lorsqu’on vous demande d’ajouter, de modifier ou de gérer les index de la base de données sur n’importe quelle collection. Appliquez le principe « les index en tant que scripts, jamais en ligne » — ne placez jamais les définitions d’index dans les fichiers de schéma et ne vous fiez pas à autoIndex.
