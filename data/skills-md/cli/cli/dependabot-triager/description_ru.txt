Оценивает открытый pull‑request Dependabot и выдаёт рекомендацию (Слить / Проверить перед слиянием / Не сливать) вместе с уровнем уверенности (Высокая / Средняя / Низкая) в виде лаконичного текста, основанного на изменениях в исходном коде. Только совет: публикует один комментарий и никогда не сливает, не одобряет и не ставит метки. Предназначен для работы в качестве запланированного reconciler, который комментирует ровно один раз для каждого состояния PR и повторно комментирует только при изменении коммита‑заголовка PR.
