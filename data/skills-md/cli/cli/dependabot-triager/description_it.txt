Valuta una pull request aperta di Dependabot e fornisce una raccomandazione (Unisci / Revisiona prima di unire / Non unire) insieme a una stima di confidenza (Alta / Media / Bassa) con una prosa concisa basata sulle modifiche alla sorgente originale. Solo a scopo consultivo: pubblica un unico commento e non esegue mai merge, approvazioni o etichette. Progettato per funzionare come riconciliatore programmato che commenta esattamente una volta per stato della PR e ricommenta solo quando il commit head della PR cambia.
