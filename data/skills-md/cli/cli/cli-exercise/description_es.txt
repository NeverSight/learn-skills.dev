Ejecuta programas reales de línea de comandos a partir de casos explícitos o un objetivo, con grabaciones fieles del terminal y resultados observados. Úsalo cuando se solicite registrar casos de prueba de CLI, demostrar el comportamiento de un comando, validar un flujo de trabajo interactivo o explorar un comando respecto a un objetivo; no es para la ejecución ordinaria de pruebas unitarias o la creación de habilidades.
