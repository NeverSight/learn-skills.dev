Estrai un sistema di design completo da qualsiasi sito web, directory locale o repository pubblico su GitHub utilizzando la CLI skillui. Genera SKILL.md, DESIGN.md e file di token (colors.json, spacing.json, typography.json) che Claude legge automaticamente. Usalo quando l'utente vuole estrarre un sistema di design o token di design da un sito o codice esistente prima di costruire un'interfaccia UI, desidera un sistema di design di riferimento da abbinare, o dice cose come “estrai il sistema di design da”, “ottieni i token da”, “estrae gli stili da questo sito”, “clona l'aspetto di”, oppure fornisce un URL/repo e vuole corrispondere al suo linguaggio visivo.
