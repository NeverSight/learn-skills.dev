Extraire un système de conception complet à partir de n'importe quel site web, répertoire local ou dépôt public GitHub en utilisant le CLI skillui. Génère SKILL.md, DESIGN.md et des fichiers de tokens (colors.json, spacing.json, typography.json) que Claude lit automatiquement. À utiliser lorsque l'utilisateur veut extraire un système de conception ou des tokens de conception d'un site ou d'une base de code existante avant de créer une interface, désire un système de conception de référence à assortir, ou dit des choses comme « extraire le système de conception de », « obtenir les tokens de », « récupérer les styles de ce site », « reproduire l'aspect de », ou fournit une URL/dépôt et souhaite correspondre à son langage visuel.

Veuillez toujours répondre dans la langue de l'utilisateur.
