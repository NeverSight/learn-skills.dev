Extrahiere ein komplettes Designsystem von jeder Website, jedem lokalen Verzeichnis oder öffentlichen GitHub‑Repo mithilfe des skillui‑CLI. Generiert SKILL.md, DESIGN.md und Token‑Dateien (colors.json, spacing.json, typography.json), die Claude automatisch ausliest. Verwende es, wenn der Benutzer ein Designsystem oder Designtoken von einer bestehenden Site oder Codebasis extrahieren möchte, bevor er eine UI erstellt, ein Referenz‑Designsystem zum Abgleichen benötigt oder Formulierungen wie „extract the design system from“, „get the tokens from“, „pull styles from this site“, „clone the look of“ verwendet, bzw. eine URL/Repository bereitstellt und dessen visuelle Sprache angleichen will.

Bitte antworte immer in der Sprache des Nutzers.
