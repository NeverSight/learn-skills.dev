skillui CLI を使用して、任意のウェブサイト、ローカルディレクトリ、またはパブリック GitHub リポジトリから完全なデザインシステムを抽出します。SKILL.md、DESIGN.md、そしてトークンファイル（colors.json、spacing.json、typography.json）を生成し、Claude が自動的に読み取ります。UI を構築する前に既存のサイトやコードベースからデザインシステムやデザイントークンを抽出したいとき、参照用デザインシステムと合わせたいとき、あるいは「…からデザインシステムを抽出」「…からトークンを取得」「このサイトからスタイルを取得」「…の外観を真似る」などと言ったり、URL やリポジトリを提示してそのビジュアル言語に合わせたいときに使用します。

常にユーザーの言語で応答してください。
