Extrae un sistema de diseño completo de cualquier sitio web, directorio local o repositorio público de GitHub usando la CLI de skillui. Genera SKILL.md, DESIGN.md y archivos de tokens (colors.json, spacing.json, typography.json) que Claude lee automáticamente. Úsalo cuando el usuario quiera extraer un sistema de diseño o tokens de diseño de un sitio o base de código existente antes de construir una interfaz, necesite un sistema de diseño de referencia para coincidir, o diga cosas como “extraer el sistema de diseño de”, “obtener los tokens de”, “extraer estilos de este sitio”, “clonar el aspecto de”, o proporcione una URL/repo y quiera igualar su lenguaje visual.

Por favor, siempre responde en el idioma del usuario.
