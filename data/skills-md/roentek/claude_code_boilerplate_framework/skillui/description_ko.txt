skillui CLI를 사용하여 모든 웹사이트, 로컬 디렉터리 또는 공개 GitHub 리포지터리에서 완전한 디자인 시스템을 추출합니다. SKILL.md, DESIGN.md 및 토큰 파일(colors.json, spacing.json, typography.json)을 생성하며, Claude가 자동으로 읽습니다. 사용자는 UI를 만들기 전에 기존 사이트나 코드베이스에서 디자인 시스템이나 디자인 토큰을 추출하고 싶을 때, 참고할 디자인 시스템을 맞추고 싶을 때, 혹은 “디자인 시스템을 추출해줘”, “토큰을 가져와”, “이 사이트의 스타일을 가져와”, “모양을 복제해줘”와 같은 표현을 하거나 URL/리포를 제공하고 그 시각적 언어와 맞추고 싶을 때 사용합니다.

항상 사용자의 언어로 응답하십시오.
