使用 skillui CLI 从任何网站、本地目录或公开的 GitHub 仓库提取完整的设计系统。生成 SKILL.md、DESIGN.md 和 token 文件（colors.json、spacing.json、typography.json），Claude 会自动读取。适用于用户希望在构建 UI 之前从现有站点或代码库中提取设计系统或设计 token、需要参考设计系统以匹配，或使用类似 “extract the design system from”“get the tokens from”“pull styles from this site”“clone the look of” 的表述，或提供 URL/仓库并希望匹配其视觉语言的情况。

请始终使用用户的语言回复。
