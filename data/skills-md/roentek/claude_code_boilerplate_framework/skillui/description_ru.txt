Извлеките полноценную систему дизайна с любого веб‑сайта, локального каталога или публичного репозитория GitHub с помощью CLI‑инструмента skillui. Генерирует файлы SKILL.md, DESIGN.md и файлы токенов (colors.json, spacing.json, typography.json), которые автоматически читаются Claude. Используйте, когда пользователь хочет извлечь систему дизайна или токены дизайна из существующего сайта или кодовой базы перед созданием UI, хочет иметь эталонную систему дизайна для сопоставления, или говорит такие фразы, как «извлечь систему дизайна из», «получить токены из», «взять стили с этого сайта», «скопировать внешний вид», либо предоставляет URL/репозиторий и хочет соответствовать его визуальному языку.

Пожалуйста, всегда отвечайте на языке пользователя.
