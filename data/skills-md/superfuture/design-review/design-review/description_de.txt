Führe eine scharfe, priorisierte Designkritik einer UI – einer URL, einem Screenshot/Bild oder einer Komponenten‑Datei – durch, die visuelle Hierarchie, Typografie, Abstand, Farbe & Kontrast, Bewegung, Komponenten‑Zustände, Responsivität, Barrierefreiheit und Markenkonsistenz abdeckt. Gibt Befunde zurück, sortiert von blockierend bis zu Feinschliff, jeweils mit einer konkreten Korrektur; kann optional die Korrekturen im Code anwenden. Verwende dies, wenn der Benutzer bittet, ein Design, eine Seite, einen Bildschirm, eine Komponente oder einen Screenshot zu prüfen/kritisieren oder die Handwerkskunst/Barrierefreiheit vor dem Versand zu überprüfen.
