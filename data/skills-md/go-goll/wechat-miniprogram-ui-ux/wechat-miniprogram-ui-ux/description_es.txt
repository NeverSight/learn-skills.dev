Se utiliza cuando el usuario desea diseñar, implementar, perfeccionar o revisar una página, flujo o sistema de diseño del Programa WeChat Mini en WXML/WXSS/JS. Combina las restricciones de diseño del programa WeChat Mini con un flujo de trabajo del sistema de diseño, un filtrado antipatrón y una lista de verificación de entrega adaptada a las interfaces del programa Mobile First Mini.
