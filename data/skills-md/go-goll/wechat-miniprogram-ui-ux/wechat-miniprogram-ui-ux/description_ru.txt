Используется, когда пользователь хочет разработать, реализовать, уточнить или проверить страницу, поток или систему дизайна WeChat Mini Program в WXML/WXSS/JS. Сочетает ограничения дизайна WeChat Mini Program с рабочим процессом системы дизайна, фильтрацией анти‑паттернов и контрольным списком доставки, адаптированным для мобильных мини‑программ.
