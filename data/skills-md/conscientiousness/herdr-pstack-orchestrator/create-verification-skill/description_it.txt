Genera una skill di verifica locale al progetto che guidi la tua app come farebbe un utente — qualsiasi linguaggio, framework o piattaforma. Usala per /create-verification-skill, “crea una skill di controllo per questo repository”, o quando un progetto non dispone di un modo scriptato per dimostrare il comportamento UI/CLI/servizio.

Per favore rispondi sempre nella lingua dell'utente.
