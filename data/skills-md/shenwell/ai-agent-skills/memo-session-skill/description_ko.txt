코딩 세션을 위한 영구 AI 에이전트 메모리 — 컨텍스트 창이 초기화돼도 살아남는 세션 간 지식. 세션의 잡음을 내구성 있는 사실로 통합하고, 메모리 라우팅을 통해 MEMORY.md, memory/ HOT/WARM/COLD 계층, 프로젝트 위키, AGENTS.md, 스킬, 그리고 선택적인 포트폴리오 메모리로 전달 — git 추적, 충돌 게이트와 온도 제한 존재. 휘발성 채팅 컨텍스트가 사라질 때 상태 전달; 벡터 RAG 또는 관리형 메모리 플랫폼을 보완하며 대체하지 않음. 사용자는 “wrap up the session”, “save what we learned”, “handoff”, “open loops”, “update memory”, “agent memory”, “persistent memory”, “cross‑session persistence”, “how to give my agent memory”라고 말하거나 다른 스킬이 메모리 체크포인트를 요청할 때 사용. 또한 포트폴리오/전역 메모리, 프로젝트 메모리 부트스트랩, 세션 변경 로그, `/inbox`, 프로세스 인박스, 또는 memory/inbox에서 파일을 ingest 할 때도 사용. memo‑session‑mcp가 연결된 경우, 포트폴리오/프로젝트 조회에 `search_all`을 사용하고 쓰기 후 `reindex_changed`를 실행. 비트리비얼 디버깅이나 사용자 수정 후에 우선 사용. 한 줄 퀴즈, 비밀, 관리형 벡터 메모리 설정, 혹은 git 히스토리 대체용으로는 사용하지 않음.
