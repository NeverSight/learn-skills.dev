Генерировать видеоролики цифрового человека с говорящей фотографией с помощью Dreamina (ByteDance OmniHuman) через API AceDataCloud. Использовать при анимации портретного изображения с сопровождающим аудиотреком, чтобы получить видео с синхронным движением губ, где человек говорит. Поддерживает маско‑ориентированное таргетирование нескольких человек и асинхронный опрос задач.
