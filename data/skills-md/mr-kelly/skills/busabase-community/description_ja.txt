Busabaseコミュニティフォーラム（community.busabase.com）に対し、/api/v1/community REST API を通じて読み取り、回答、投稿を行います。カテゴリと投稿の一覧取得、スレッドとその返信の閲覧、検索、そして明示的な確認の上で投稿や返信の公開を行います。ユーザーが $busabase-community や /busabase-community を呼び出したとき、Busabaseコミュニティで何が起きているかを尋ねたとき、未回答の質問の対応や回答を求めたとき、あるいは何かを投稿・告知したいときに使用してください。

常にユーザーの言語で応答してください。
