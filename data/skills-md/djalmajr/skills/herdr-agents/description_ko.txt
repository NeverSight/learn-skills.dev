Herdr 내부에서 omp 스타일의 역할 에이전트 팀(스카우터, 플래너, 디자이너, 구현자, 태스커, 리뷰어, 보안‑리뷰어, 연구원, 인스펙터)을 실행하십시오. 호출 에이전트는 오케스트레이터 역할을 유지하며, 각 역할마다 형제 창에 하나의 CLI 에이전트를 생성하고, 독립적인 브리프를 전달하며, 파일 기반 보고서를 수집하고, 통합, 게이트, git을 담당합니다. HERDR_ENV=1이 설정된 Herdr 환경에서 비정형 작업을 수행할 때 사용하십시오: 사용자가 헤드, 팀, 역할, 디자이너 또는 리뷰어 에이전트, 병렬 작업자, “omp 에이전트와 같은” 구성을 요청하거나, 작업에 설문조사(여러 파일, 다른 저장소, 도구 규약)가 필요하고, 두 개 이상의 파일을 수정하거나, 프로젝트의 AGENTS.md가 이 스킬을 통해 작업을 라우팅하도록 지정한 경우입니다. Herdr 외부에서는 사용하지 마십시오; 제품 결정이 필요 없는 1~2개의 파일만 변경하는 경우는 직접 수행합니다.
