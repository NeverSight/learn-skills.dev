Навык автоматизированного тестирования для инструментов Windows-MCP. Используйте этот навык, когда пользователь хочет протестировать, проверить, провести бенчмарк или оценить любой инструмент Windows-MCP (App, PowerShell, Screenshot, Snapshot, Click, Type, Scroll, Move, Shortcut, Wait, MultiSelect, MultiEdit, Clipboard, Process, Notification, FileSystem, Registry, Scrape). Срабатывает на такие фразы, как «тестировать инструмент Click», «бенчмарк Screenshot», «проверить FileSystem», «запустить QA для Registry», «проверить, работает ли PowerShell», «оценить производительность инструмента» или любое упоминание тестирования/валидации инструмента Windows-MCP. Каждый вызов тестирует ровно один инструмент.

Пожалуйста, всегда отвечайте на языке пользователя.
