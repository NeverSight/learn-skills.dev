Windows-MCP 工具的自動化測試功能。當使用者希望測試、驗證、基準測試或評估任何 Windows-MCP 工具時，請使用此功能（包括 App、PowerShell、Screenshot、Snapshot、Click、Type、Scroll、Move、Shortcut、Wait、MultiSelect、MultiEdit、Clipboard、Process、Notification、FileSystem、Registry、Scrape）。觸發條件包括像是「test the Click tool」（測試 Click 工具）、「benchmark Screenshot」（基準測試 Screenshot）、「validate FileSystem」（驗證 FileSystem）、「run QA on Registry」（執行 Registry 的 QA）、「check if PowerShell works」（檢查 PowerShell 是否正常）、「evaluate tool performance」（評估工具效能）或任何提及測試/驗證 Windows-MCP 工具的語句。每次呼叫僅測試一個工具。請始終以使用者的語言回覆。
