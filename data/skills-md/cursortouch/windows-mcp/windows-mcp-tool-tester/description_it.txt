Abilità di test automatizzati per gli strumenti Windows‑MCP. Usa questa abilità ogni volta che l’utente vuole testare, convalidare, fare benchmark o valutare qualsiasi strumento Windows‑MCP (App, PowerShell, Screenshot, Snapshot, Click, Type, Scroll, Move, Shortcut, Wait, MultiSelect, MultiEdit, Clipboard, Process, Notification, FileSystem, Registry, Scrape). Si attiva con frasi come “testa lo strumento Click”, “benchmark Screenshot”, “convalida FileSystem”, “esegui QA su Registry”, “verifica se PowerShell funziona”, “valuta le prestazioni dello strumento”, o qualsiasi menzione di testare/convalidare uno strumento Windows‑MCP. Ogni invocazione testa ESATTAMENTE UN SOLO strumento.

Rispondi sempre nella lingua dell’utente.
