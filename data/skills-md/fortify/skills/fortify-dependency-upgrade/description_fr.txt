Effectuer une évaluation de l’impact de la mise à niveau des dépendances, des correctifs de code et des travaux de migration. Utiliser pour remédier aux découvertes Fortify SCA / open source / analyse de composition logicielle — dépendances tierces vulnérables, CVE/GHSA, composants signalés par FoD ou SSC — en mettant à jour vers une version sûre et en corrigeant les ruptures éventuelles. Utiliser également lorsque l’utilisateur demande ce qui va se casser après un changement de version, rencontre des échecs de compilation ou de test, a besoin de corriger le code pour la compatibilité, a besoin d’aide pour résoudre les conflits de dépendances, ou corriger les changements cassants issus de mises à jour de dépendances directes ou transitives, y compris les changements de version de framework qui affectent les starters, plugins, annotations, configurations ou imports. (Pour les conclusions de code SAST/DAST, utilisez fortify‑remediate à la place.) Couvre npm/yarn, Maven/Gradle, pip/poetry, modules Go, Cargo, Bundler, Composer, NuGet, C++ (CMake/Conan/vcpkg), iOS/macOS (CocoaPods/SPM/Carthage) et Scala (sbt/Mill).
