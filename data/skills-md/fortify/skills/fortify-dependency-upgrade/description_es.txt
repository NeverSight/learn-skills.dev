Realizar evaluación de impacto de la actualización de dependencias, correcciones de código y trabajo de migración. Utilizar para remediar hallazgos de Fortify SCA / código abierto / análisis de composición de software — dependencias de terceros vulnerables, CVE/GHSA, componentes señalados por FoD o SSC — mediante la actualización a una versión segura y la corrección de cualquier ruptura resultante. También usar cuando el usuario pregunta qué se romperá tras un cambio de versión, encuentra fallos de compilación/prueba, necesita código corregido para compatibilidad, necesita ayuda para resolver conflictos de dependencias o arreglar cambios disruptivos de actualizaciones de dependencias directas o transitivas, incluidos los cambios de versión del framework que afectan a starters, plugins, anotaciones, configuraciones o importaciones. (Para hallazgos de código SAST/DAST, use fortify-remediate en su lugar.) Cubre npm/yarn, Maven/Gradle, pip/poetry, Go modules, Cargo, Bundler, Composer, NuGet, C++ (CMake/Conan/vcpkg), iOS/macOS (CocoaPods/SPM/Carthage) y Scala (sbt/Mill).
