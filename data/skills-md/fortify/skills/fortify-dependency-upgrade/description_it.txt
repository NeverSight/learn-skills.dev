Eseguire la valutazione dell'impatto dell'aggiornamento delle dipendenze, le correzioni del codice e il lavoro di migrazione. Utilizzare per sanare le segnalazioni di Fortify SCA / open source / analisi della composizione del software — dipendenze di terze parti vulnerabili, CVE/GHSA, componenti segnalati da FoD o SSC — aggiornando a una versione sicura e correggendo eventuali rotture. Utilizzare anche quando l'utente chiede cosa si romperà dopo un cambio di versione, incontra errori di compilazione/test, necessita di correzioni del codice per compatibilità, ha bisogno di aiuto per risolvere conflitti di dipendenze, o per correggere cambiamenti breaking derivanti da aggiornamenti di dipendenze dirette o transitive, inclusi cambi di versione del framework che influenzano starter, plugin, annotazioni, configurazioni o import. (Per le segnalazioni di codice SAST/DAST, utilizzare invece fortify‑remediate.) Copre npm/yarn, Maven/Gradle, pip/poetry, Go modules, Cargo, Bundler, Composer, NuGet, C++ (CMake/Conan/vcpkg), iOS/macOS (CocoaPods/SPM/Carthage) e Scala (sbt/Mill). Rispondi sempre nella lingua dell'utente.
