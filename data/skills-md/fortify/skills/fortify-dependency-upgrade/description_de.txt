Durchführen einer Auswirkungsanalyse bei Dependency‑Upgrades, Codekorrekturen und Migrationsarbeiten. Verwenden, um Fortify SCA / Open‑Source / Software‑Composition‑Analysis‑Ergebnisse zu beheben – verwundbare Drittanbieter‑Abhängigkeiten, CVEs/GHSAs, von FoD oder SSC markierte Komponenten – indem auf eine sichere Version aktualisiert und etwaige dadurch entstehende Fehler behoben werden. Außerdem verwenden, wenn der Nutzer fragt, was nach einer Versionsänderung bricht, Kompilier‑/Testfehler auftreten, Code für Kompatibilität korrigiert werden muss, Hilfe bei der Auflösung von Abhängigkeitskonflikten benötigt wird oder Breaking‑Changes durch direkte oder transitive Dependency‑Updates behoben werden sollen, einschließlich Framework‑Versionsänderungen, die Starter, Plugins, Annotationen, Konfigurationen oder Importe betreffen. (Für SAST/DAST‑Code‑Findings bitte fortify‑remediate verwenden.) Deckt npm/yarn, Maven/Gradle, pip/poetry, Go‑Modules, Cargo, Bundler, Composer, NuGet, C++ (CMake/Conan/vcpkg), iOS/macOS (CocoaPods/SPM/Carthage) und Scala (sbt/Mill) ab.
