`h0x` CLI を使用して、h0x-ADE が管理するワークツリー、フォルダー コンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリー コメント、および h0x-ADE の組み込みブラウザを操作します。ユーザーが「$orca-cli」、「h0x cli を使用」、「h0x-ADE ワークツリー」、「子ワークツリー」、「cardStatus」、「ワークツリー内で codex/claude を生成」、「h0x-ADE ターミナルの読み取り/待機/送信」、「ターミナル送信」、「フル ハンドオフ」、「ハンドオーバー」、「これを別のエージェントに渡す」、「別のワークツリー」、「h0x-ADE ブラウザ」、 「h0x アーティファクト」、「HTML/マークダウンの共有」、「パブリック アーティファクト リンク」、「スキルの共有」、または「h0x-ADE 内のブラウザの制御」。タスクが h0x-ADE 管理状態に達する場合は、生の `git worktree`、アドホック PTY、Playwright、または Computer Use よりもこれを優先します。コンピュータを使用するタスクでフォーカス、メニュー、ダイアログ、座標、スクリーンショットなどの OS/ウィンドウ レベルの制御が必要な場合にのみ、外部ブラウザ ウィンドウ、Web ビュー、またはデスクトップ UI に使用します。 h0x-ADE の埋め込みページには「orca-cli」を使用し、外部ページには Playwright や CDP などのページ自動化ツールを使用します。
