Boucle de rétroaction visuelle d'agent IA pour toute application web. À utiliser lors de l'itération sur du code visuel (UI, canvas, 3D, SVG, graphiques, animations) et lorsque vous devez VOIR le résultat rendu pour évaluer la qualité. Couvre : le modèle d’API dev‑screenshot (déclencheur GET → SSE → capture client → POST retour → fichier sauvegardé), rendu paramétré, sidecars de métadonnées, régression visuelle avec différence de pixels, enregistrement d’outil WebMCP et solutions de secours console. S’active sur : « prendre une capture d’écran », « montre‑moi le rendu », « QA visuelle », « comparer avant/après », « différence de pixels », ou tout travail visuel itératif où l’agent doit inspecter la sortie rendue.
