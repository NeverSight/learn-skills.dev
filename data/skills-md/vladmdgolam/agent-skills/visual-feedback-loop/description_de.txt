KI-Agent‑Visuelle‑Feedback‑Schleife für jede Web‑App. Verwenden, wenn Sie an visuellem Code (UI, Canvas, 3D, SVG, Diagrammen, Animationen) iterieren und das gerenderte Ergebnis SEHEN müssen, um die Qualität zu bewerten. Beinhaltet: dev‑screenshot‑API‑Muster (GET‑Trigger → SSE → Client‑Erfassung → POST zurück → Datei gespeichert), parametriertes Rendering, Metadaten‑Sidecars, visuelle Regression mit Pixel‑Diff, WebMCP‑Tool‑Registrierung und Konsolen‑Fallbacks. Aktivieren bei: „Screenshot machen“, „Zeig mir das Rendering“, „Visuelle QA“, „Vorher/Nachher vergleichen“, „Pixel‑Diff“ oder jeder iterativen visuellen Arbeit, bei der der Agent die gerenderte Ausgabe prüfen muss.
