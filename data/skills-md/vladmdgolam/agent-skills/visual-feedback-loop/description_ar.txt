حلقة تغذية بصرية للوكيل الذكي لأي تطبيق ويب. استخدمها عند التكرار على الكود البصري (واجهة المستخدم، القماش، ثلاثي الأبعاد، SVG، المخططات، الرسوم المتحركة) وتحتاج إلى رؤية النتيجة المرسومة لتقييم الجودة. تشمل: نمط واجهة برمجة التطبيقات dev‑screenshot (تحفيز GET → SSE → التقاط العميل → POST للعودة → حفظ الملف)، التصيير المعلم بالمعاملات، ملفات التعريف الجانبية للبيانات الوصفية، الانحدار البصري مع فرق البكسل، تسجيل أداة WebMCP، والبدائل عبر وحدة التحكم. يتم التفعيل عند: "خذ لقطة شاشة"، "أظهر لي الرسم"، "ضمان الجودة البصري"، "قارن قبل/بعد"، "فرق البكسل"، أو أي عمل بصري تكراري يحتاج الوكيل إلى فحص المخرجات المرسومة.
