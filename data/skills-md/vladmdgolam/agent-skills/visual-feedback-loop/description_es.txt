Bucle de retroalimentación visual de agente de IA para cualquier aplicación web. Úsalo al iterar sobre código visual (UI, canvas, 3D, SVG, gráficos, animaciones) y necesitas VER el resultado renderizado para evaluar la calidad. Incluye: patrón de API dev-screenshot (disparador GET → SSE → captura del cliente → POST de vuelta → archivo guardado), renderizado parametrizado, sidecars de metadatos, regresión visual con diferencia de píxeles, registro de herramienta WebMCP y alternativas en consola. Actívalo con: “tomar una captura de pantalla”, “muéstrame el render”, “QA visual”, “comparar antes/después”, “diferencia de píxeles”, o cualquier trabajo visual iterativo donde el agente necesite inspeccionar la salida renderizada.
