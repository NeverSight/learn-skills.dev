Используйте при итеративной работе над визуальным кодом (UI, canvas, 3D, SVG, графики, анимации), когда необходимо УВИДЕТЬ отрендеренный результат для оценки качества. Включает: шаблон API dev‑screenshot (GET‑триггер → SSE → захват клиентом → POST обратно → сохранение файла), параметризованный рендеринг, сопутствующие метаданные, визуальная регрессия с пиксельным отличием, регистрация инструмента WebMCP и резервные варианты в консоли. Активируется по командам: «сделай скриншот», «покажи рендер», «визуальное QA», «сравни до/после», «pixel diff», или любой итеративной визуальной задаче, где агенту нужно проверить отрендеренный вывод.
