Richten Sie ein Live2D-Kubismus-Webprojekt von Grund auf ein. Initialisieren Sie das Kubismus-Framework, laden Sie .moc3-Modelle über CubismUserModel, implementieren Sie die Render-Schleife, behandeln Sie Touch/Mouse-Eingaben mit Schwenken/Zoomen über CubismViewMatrix, Treffererkennung und strukturieren Sie eine Produktions-LAppModel-Klasse. Wird verwendet, wenn Sie eine neue Cubism Web-App erstellen oder Live2D in ein Webprojekt integrieren.
