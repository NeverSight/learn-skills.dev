Configurez un projet Web Live2D Cubism à partir de zéro. Initialiser le framework Cubism, charger les modèles .moc3 via CubismUserModel, implémenter la boucle de rendu, gérer l'entrée tactile/souris avec panoramique/zoom via CubismViewMatrix, détecter les coups et structurer une classe LAppModel de production. À utiliser lors de la création d'une nouvelle application Web Cubism ou de l'intégration de Live2D dans un projet Web.
