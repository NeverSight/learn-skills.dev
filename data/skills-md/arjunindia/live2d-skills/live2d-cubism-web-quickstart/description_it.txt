Imposta un progetto Live2D Cubism Web da zero. Inizializza il Cubism Framework, carica i modelli .moc3 tramite CubismUserModel, implementa il ciclo di rendering, gestisci l'input touch/mouse con pan/zoom tramite CubismViewMatrix, la rilevazione dei colpi e struttura una classe LAppModel per la produzione. Usalo quando costruisci una nuova app Cubism Web o integri Live2D in un progetto web.

Per favore rispondi sempre nella lingua dell'utente.
