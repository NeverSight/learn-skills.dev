Read-only security audit of a web project — stack detection, vulnerable dependencies and runtimes (PHP, Node.js, Next.js…), leaked secrets, injection patterns (SQLi, XSS, SSRF, command execution), auth/session/cookie/CORS/header misconfiguration, Docker, CI and external services (Supabase, Firebase). Use when the user asks to audit, security-review or "check for vulnerabilities" in a codebase, asks whether their site is affected by a CVE, or before deploying an AI-generated app. Reports confirmed issues, findings that need review and preventive advice separately, and never modifies code without explicit approval.
