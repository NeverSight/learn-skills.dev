Auditoría de seguridad de solo lectura de un proyecto web — detección de stack, dependencias vulnerables y entornos de ejecución (PHP, Node.js, Next.js…), secretos filtrados, patrones de inyección (SQLi, XSS, SSRF, ejecución de comandos), configuración incorrecta de autenticación/sesión/cookie/CORS/encabezados, Docker, CI y servicios externos (Supabase, Firebase). Utilice cuando el usuario solicite auditar, revisión de seguridad o "comprobar vulnerabilidades" en una base de código, pregunte si su sitio está afectado por un CVE, o antes de desplegar una aplicación generada por IA. Reporta problemas confirmados, hallazgos que requieren revisión y consejos preventivos por separado, y nunca modifica el código sin aprobación explícita.

Por favor, responda siempre en el idioma del usuario.
