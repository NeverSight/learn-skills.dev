Nur‑Lese‑Sicherheitsaudit eines Webprojekts — Stack‑Erkennung, verwundbare Abhängigkeiten und Laufzeiten (PHP, Node.js, Next.js …), geleakte Secrets, Injektionsmuster (SQLi, XSS, SSRF, Befehlsausführung), Fehlkonfiguration von Authentifizierung/Session/Cookie/CORS/Headers, Docker, CI und externe Dienste (Supabase, Firebase). Verwenden, wenn der Nutzer um ein Audit, eine Sicherheitsüberprüfung oder ein „Check auf Schwachstellen“ in einem Code‑Base bittet, ob seine Seite von einer CVE betroffen ist oder vor der Bereitstellung einer KI‑generierten Anwendung. Berichtet bestätigte Probleme, Erkenntnisse, die überprüft werden müssen, und präventive Ratschläge getrennt und ändert niemals Code ohne ausdrückliche Zustimmung. Bitte immer in der Sprache des Nutzers antworten.
