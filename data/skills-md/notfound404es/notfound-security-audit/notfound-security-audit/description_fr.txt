Audit de sécurité en lecture seule d'un projet web — détection de la stack, dépendances et environnements vulnérables (PHP, Node.js, Next.js…), secrets divulgués, modèles d'injection (SQLi, XSS, SSRF, exécution de commandes), mauvaise configuration de l'authentification/séance/cookie/CORS/en-têtes, Docker, CI et services externes (Supabase, Firebase). À utiliser lorsque l'utilisateur demande un audit, une revue de sécurité ou « vérifier les vulnérabilités » dans une base de code, se demande si son site est affecté par un CVE, ou avant de déployer une application générée par IA. Signale séparément les problèmes confirmés, les constats nécessitant une révision et les conseils préventifs, et ne modifie jamais le code sans approbation explicite. Veuillez toujours répondre dans la langue de l'utilisateur.
