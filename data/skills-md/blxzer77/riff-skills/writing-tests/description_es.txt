Escribe pruebas que detectan regresiones y preservan el comportamiento. Úselo cuando corrija un error, añada o cambie un comportamiento, refactorice (especialmente código no probado), evalúe la cobertura, elija una estrategia de pruebas o corrija pruebas inestables o con demasiados simulacros, incluso si no se mencionan las pruebas. No es para la configuración de CI ni para las pruebas de carga.
