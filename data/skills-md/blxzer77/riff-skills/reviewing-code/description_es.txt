Úselo cuando revise un diff, una solicitud de fusión (PR), una rama o cambios preparados en busca de errores, regresiones, problemas de seguridad o infracciones de las reglas del proyecto, o para determinar si es seguro realizar la fusión. No sirve para aplicar correcciones o comentarios de revisión, auditar repositorios completos ni añadir pruebas o diseños.
