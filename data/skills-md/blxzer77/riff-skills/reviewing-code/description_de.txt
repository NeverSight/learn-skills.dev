Überprüft eine Codeänderung auf verifizierte Fehler mit hohem Signalwert, die sie einführt. Verwenden Sie diese Option, wenn Sie einen Diff, einen PR, einen Branch oder zwischengespeicherte Änderungen auf Bugs, Regressionen, Sicherheits- oder Projektregelverstöße überprüfen möchten oder um festzustellen, ob ein Merge sicher ist. Nicht geeignet für das Anwenden von Korrekturen oder Überprüfungskommentaren, Audits des gesamten Repositorys, das Hinzufügen von Tests oder Designs.
