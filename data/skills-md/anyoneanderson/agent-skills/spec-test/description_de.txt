Erstellen Sie Tests für eine Spezifikationsaufgabenimplementierung und führen Sie sie aus.

Liest Kriterien für den Abschluss von Aufgaben aus task.md, erkennt vorhandene Testmuster,
erstellt Testfälle, führt sie aus und gibt eine strukturierte Testergebnisdatei aus.
Funktioniert eigenständig oder als Teil der Spezifikations-Implementierungs-Pipeline.
