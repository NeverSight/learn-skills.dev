Создайте и запустите тесты для реализации конкретной задачи.

Считывает критерии завершения задачи из Tasks.md, обнаруживает существующие тестовые шаблоны,
создает тестовые примеры, запускает их и выводит структурированный файл результатов теста.
Работает автономно или как часть конвейера реализации спецификации.

Английские триггеры: «Протестировать эту задачу», «Запустить спецификационный тест», «Создать тесты для задачи».
日本語トリガー: 「このタスクをテスト」「spec-testを実行」「タスクのテストを作成」
