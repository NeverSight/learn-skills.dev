Cree y ejecute pruebas para la implementación de una tarea específica.

Lee los criterios de finalización de tareas de task.md, detecta patrones de prueba existentes,
crea casos de prueba, los ejecuta y genera un archivo de resultados de prueba estructurado.
Funciona de forma independiente o como parte del proceso de implementación de especificaciones.

Activadores en inglés: "Probar esta tarea", "Ejecutar prueba de especificaciones", "Crear pruebas para la tarea"
日本語トリガー: 「このタスクをテスト」「spec-testを実行」「タスクのテストを作成」
