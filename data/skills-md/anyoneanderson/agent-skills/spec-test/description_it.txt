Creare ed eseguire test per l'implementazione di un'attività specifica.

Legge i criteri di completamento delle attività da task.md, rileva modelli di test esistenti,
crea casi di test, li esegue e genera un file di risultati di test strutturato.
Funziona in modo autonomo o come parte della pipeline di implementazione delle specifiche.

Trigger in inglese: "Testa questa attività", "Esegui spec-test", "Crea test per l'attività"
日本語トリガー: 「このタスクをテスト」「spec-testを実行」「タスクのテストを作成」
