Auditez une base de code ENTIÈRE avec plusieurs agents en parallèle — mappez le dépôt, partitionnez‑le en tranches d’examen, déployez un (ou plusieurs, multi‑lentilles) sous‑agent réviseur par tranche, agrégez avec un critique transversal/architectural + une vérification de complétude, puis triez, corrigez et rappelez avec un registre de couverture honnête. Utilisez‑le lorsqu’on vous demande « auditer l’ensemble du code », « revue complète de sécurité/qualité du dépôt », « examiner tout le projet », « effectuer un audit de code profond/complet », « scanner tout pour des bugs ou des vulnérabilités », lors de l’intégration ou de la prise en main d’un dépôt inconnu, ou pour un balayage approfondi périodique. Portée sur l’ensemble du dépôt et le nombre d’agents s’ajuste à la taille du dépôt — PAS une revue de diff (pour les lignes modifiées, utilisez la double revue d’agent).
