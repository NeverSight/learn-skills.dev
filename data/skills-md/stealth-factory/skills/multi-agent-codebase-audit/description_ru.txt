Аудит ИЗ ЦЕЛОЙ кодовой базы с несколькими агентами параллельно — построить карту репозитория, разбить его на части для обзора, развести по каждому фрагменту одного (или нескольких, мульти‑линзовых) под‑агента‑рецензента, собрать результаты с помощью сквозного/архитектурного критика + проверки полноты, затем выполнить триаж, исправления и отчёт с честным реестром покрытости. Использовать, когда просят «аудировать всю кодовую базу», «полный обзор безопасности/качества репозитория», «просмотреть весь проект», «сделать глубокий/комплексный кодовый аудит», «просканировать всё на наличие багов или уязвимостей», при включении/приёмке незнакомого репозитория или для периодической глубокой проверки. Охват всей репозитории, количество агентов масштабируется в зависимости от размера репозитория — НЕ обзор диффа (для изменённых строк используйте двойной агент‑обзор).
