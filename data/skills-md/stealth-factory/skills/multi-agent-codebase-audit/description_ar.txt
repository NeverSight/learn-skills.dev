تدقيق كامل لكافة قاعدة الشيفرة باستخدام عدة وكلاء متوازين — رسم خريطة المستودع، تقسيمه إلى شرائح مراجعة، توزيع وكيل فرعي مراجع (واحد أو أكثر، متعدد الزوايا) لكل شريحة، ثم تجميع النتائج باستخدام ناقد معماري شامل + فحص للاكتمال، ثم فرز المشكلات، إصلاحها، وتقديم تقرير مع سجل تغطية صادق. يُستعمل عندما يُطلب «تدقيق كامل لقاعدة الشيفرة»، «مراجعة شاملة للأمان/الجودة للمستودع»، «مراجعة المشروع بأكمله»، «إجراء تدقيق عميق/شامل للشيفرة»، «مسح كل شيء بحثًا عن أخطاء أو ثغرات»، عند الانضمام/توريث مستودع غير مألوف، أو لإجراء فحص دوري عميق. نطاقه كامل المستودع ويتكيف عدد الوكلاء مع حجم المستودع — ليس مراجعة للفرق (للتغييرات استخدم مراجعة مزدوجة الوكلاء).
