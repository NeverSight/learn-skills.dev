Audita una BASE DE CÓDIGO COMPLETA con múltiples agentes en paralelo: mapea el repositorio, divídelo en fragmentos de revisión, despliega uno (o varios, con varias perspectivas) agente revisor por fragmento, reduce con un crítico transversal/arquitectónico + una verificación de exhaustividad, luego triage, corrige y reporta con un registro honesto de cobertura. Úsalo cuando te pidan “auditar todo el código”, “revisión completa de seguridad/calidad del repo”, “revisar todo el proyecto”, “hacer una auditoría de código profunda/comprehensiva”, “escaneo total de bugs o vulnerabilidades”, al incorporarte a un repo desconocido o para una revisión profunda periódica. Ámbito de todo el repositorio y escala el número de agentes al tamaño del repo — NO es una revisión de diffs (para líneas cambiadas usa revisión de doble agente).
