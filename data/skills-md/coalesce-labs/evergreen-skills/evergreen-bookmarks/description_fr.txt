Inspectez et modifiez les signets stockés dans un référentiel de synchronisation Evergreen. À utiliser lorsqu'on vous demande de vérifier la fraîcheur des signets, de fusionner des dossiers de signets en double, de réorganiser ou de renommer les signets ou d'enregistrer les références de recherche dans les signets du navigateur. Publie les modifications demandées avec un commit et un push Git afin qu'Evergreen puisse les synchroniser entre les navigateurs et les profils. Pas pour changer le code source de l'extension.
