Concevoir et mettre en œuvre des interfaces produit délibérées dans une base de code existante ou un nouveau prototype. Utiliser lorsque l’on demande de créer une page, un flux, un composant, une page d'atterrissage, un tableau de bord, une expérience web au format mobile, une surface de système de conception, ou de rendre une interface plus claire, plus cohérente, plus réactive ou plus raffinée. Déclencheurs : concevoir cette interface, construire cette UI, améliorer le design, redessiner cet écran, le rendre intentionnel, hiérarchie visuelle, conception d’interaction, états responsifs, états vides, états de chargement, système de design, implémentation UI.
