Concevoir et implémenter des interfaces produits délibérées dans une base de code existante ou un nouveau prototype. Utilisez‑le lorsqu’on vous demande de créer une page, un flux, un composant, une page d’atterrissage, un tableau de bord, une expérience web adaptée aux mobiles, une surface de système de design, ou d’améliorer la clarté, la cohérence, la réactivité ou le raffinement d’une interface. S’active sur : concevoir cette interface, créer cette UI, améliorer le design, redessiner cet écran, lui donner une intention, la hiérarchie visuelle, le design d’interaction, les états réactifs, les états vides, les états de chargement, le système de design, l’implémentation UI.

Veuillez toujours répondre dans la langue de l’utilisateur.
