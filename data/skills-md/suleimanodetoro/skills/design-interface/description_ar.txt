صمم ونفّذ واجهات منتجات مقصودة في قاعدة شفرة موجودة أو نموذج أولي جديد. استخدم ذلك عندما يُطلب منك إنشاء صفحة أو تدفق أو مكوّن أو صفحة هبوط أو لوحة تحكم أو تجربة ويب مهيأة للهواتف المحمولة أو سطح نظام تصميم، أو لجعل الواجهة أوضح، أكثر تماسكًا، أكثر استجابة، أو أكثر صقلًا. يتم التفعيل عند: صمّم هذه الواجهة، ابنِ هذه الواجهة، حسّن التصميم، أعد تصميم هذه الشاشة، اجعلها تبدو متعمدة، هرمية بصرية، تصميم تفاعل، حالات استجابة، حالات فارغة، حالات تحميل، نظام تصميم، تنفيذ واجهة المستخدم.
