Aktualisiert die Android SDK-Abhängigkeit von Flutter auf eine neue Android-API-Version (oder Vorschau/Canary-Release) in packets.txt, überprüft die Eindeutigkeit des CIPD-Tags und paketiert/lädt die Binärdateien mit create_cipd_packages.sh unter macOS, Linux und Windows hoch. Verwenden Sie es immer dann, wenn ein Benutzer eine neue Version von Android erwerben oder Android SDK-Pakete auf CIPD hochladen möchte.
