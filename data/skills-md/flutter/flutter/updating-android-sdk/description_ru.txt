Обновляет зависимость Flutter Android SDK до новой версии Android API (или предварительной версии/canary-версии) в packages.txt, проверяет уникальность тега CIPD и упаковывает/загружает двоичные файлы с помощью create_cipd_packages.sh в macOS, Linux и Windows. Используйте, когда пользователь хочет получить новую версию Android или загрузить пакеты Android SDK в CIPD.
