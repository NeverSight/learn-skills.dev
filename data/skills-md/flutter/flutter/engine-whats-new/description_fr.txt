Génère le résumé de la version « Quoi de neuf » et le fichier de comparaison pour les modifications apportées au moteur Flutter (//engine/src/flutter) entre deux versions (par exemple, 3.47 contre 3.44).
Quand l'utiliser : - Activer uniquement lorsque l'utilisateur le demande explicitement pour générer les nouveautés du moteur, comparer les versions du moteur Flutter ou produire un résumé des versions du moteur.
Quand ne pas utiliser : - Ne pas utiliser pour des questions générales sur les validations, l'historique de fichiers individuels ou les recherches dans la base de code, sauf si cela est explicitement demandé pour générer la différence ou le résumé de la version du moteur.
