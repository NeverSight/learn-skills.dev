معالجة مسارات الملفات والمجلدات عبر الأنظمة، وتقسيم القطاعات، واستخراج الامتداد، وتحويل السياق باستخدام `package:path` و `package:file`. يُستَخدم عند كتابة، فحص، دمج، تقسيم، أو إعادة هيكلة مسارات الملفات، أسماء المجلدات، أو الامتدادات، أو استبدال عمليات مسارات السلاسل الخام (`.split('/')`, `'$dir/$file'`, `.endsWith('.ext')`, `.replaceAll('\\', '/')`). لا تُستَخدم لتوجيه عناوين URI عبر الشبكة HTTP، أو سلاسل استعلام قاعدة البيانات، أو معالجة السلاسل غير المتعلقة بالمسارات. يرجى الرد دائمًا بلغة المستخدم.
