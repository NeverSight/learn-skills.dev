パッケージ `package:path` と `package:file` を使用した、クロスプラットフォームのファイル・ディレクトリパス操作、セグメント分割、拡張子抽出、コンテキスト変換。ファイルパスやディレクトリ名、拡張子の作成、検査、結合、分割、リファクタリング、あるいは生の文字列パス操作（`.split('/')`、`'$dir/$file'`、`.endsWith('.ext')`、`.replaceAll('\\', '/')`）の置き換えに使用してください。HTTP のネットワーク URI ルーティングやデータベースクエリ文字列、パス以外の文字列処理には使用しないでください。
