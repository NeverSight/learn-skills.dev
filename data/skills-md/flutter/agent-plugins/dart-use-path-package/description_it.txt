Manipolazione di percorsi di file e directory multipiattaforma, divisione di segmenti, estrazione dell'estensione e conversione di contesto utilizzando `package:path` e `package:file`. Usalo quando scrivi, ispezioni, unisci, dividi o ristrutturi percorsi di file, nomi di directory o estensioni, o sostituisci operazioni di percorso su stringhe grezze (`.split('/')`, `'$dir/$file'`, `.endsWith('.ext')`, `.replaceAll('\\', '/')`). Non usarlo per il routing di URI HTTP, stringhe di query di database o elaborazione di stringhe non legate a percorsi.

Rispondi sempre nella lingua dell'utente.
