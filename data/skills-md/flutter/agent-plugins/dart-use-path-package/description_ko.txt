'package: path' 및 `package: file` 을 사용하여 플랫폼 간 파일 및 디렉터리 경로 조작, 세그먼트 분할, 확장자 추출 및 컨텍스트 변환. 파일 경로, 디렉터리 이름 또는 확장명을 작성, 검사, 조인, 분할 또는 리팩터링하거나 원시 문자열 경로 작업 (`.split (`/`)', '' $ dir/$ file `', '.endsWith (' .ext `)', '.replaceAll (`\\ `,'/')') 을 대체할 때 사용합니다. HTTP 네트워크 URI 라우팅, 데이터베이스 쿼리 문자열 또는 경로가 아닌 문자열 처리에 사용하지 마십시오.
