Manipulación de rutas de archivos y directorios multiplataforma, división de segmentos, extracción de extensiones y conversión de contexto utilizando `package:path` y `package:file`. Úselo al escribir, inspeccionar, unir, dividir o refactorizar rutas de archivos, nombres de directorio o extensiones, o al reemplazar operaciones de ruta de cadena sin procesar (`.split('/`)`, ''$dir/$file'`, `.endsWith ('.ext')`, `.replaceAll ('\\', '/')`). No utilizar para enrutamiento de URI de red HTTP, cadenas de consulta de base de datos o procesamiento de cadenas sin ruta.
