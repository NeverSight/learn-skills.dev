# assumption-set

## 何时使用

必须使用：即将 `model-build`；假设与符号冲突。

禁止使用：用假设取消题面硬约束；假设条数 0 或 >8。

## 循环

目标：每条假设 = 内容 + 依据 + 若放松会怎样。符号无重名。

`max_rounds`: 3

## 步骤

1. 只保留模型推导真正用到的简化。
2. 无效假设示例（禁止）：“数据真实可靠”“参赛队认真作答”。
3. 有效假设示例结构：「板凳视为刚体；依据题面尺寸远小于路径曲率半径的量级估计；放松后需改成柔性体，超出本题数据。」
4. 符号表：决策 / 中间 / 目标 / 已知 / 待标定。单位与取值范围分开写。
5. 全文此后不得偷偷换符号；要换必须改状态并全局替换。

## 验收

- [ ] 3–6 条假设，每条三要素齐全
- [ ] 每条能指出影响哪个小问的哪个公式
- [ ] 符号表无重复定义
- [ ] 未把题面给定常数改写成“假设”

## 输出

`assumptions`、`symbols`。`status=assumptions_locked`。
