Aiuta a scegliere una licenza software/open-source appropriata (ad esempio MIT, Apache‑2.0, GPL‑3.0, AGPL‑3.0, MPL‑2.0, BSD) in base agli obiettivi e ai vincoli dell'utente; spiega i compromessi (permessiva vs copyleft, concessioni di brevetti, copyleft SaaS/rete); verifica i vincoli derivanti dalle dipendenze; e genera o aggiorna i file LICENSE e le brevi intestazioni di licenza. Usalo quando un utente chiede quale licenza scegliere, se le licenze sono compatibili, o per aggiungere un file LICENSE a un repository.  

Rispondi sempre nella lingua dell'utente.
