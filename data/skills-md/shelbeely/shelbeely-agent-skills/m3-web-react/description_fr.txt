Implémentez Material Design 3 dans React en utilisant MUI (Material UI) avec un thème aligné sur M3, ou @material/web avec des emballages React. Couvre la configuration du thème, l'utilisation des composants, le mode sombre et l'intégration SSR Next.js. Utilisez ceci lors de la création d'applications React ou Next.js de style M3.
