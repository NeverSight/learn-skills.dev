Interroga i metadati e scarica i dati dal NCBI Gene Expression Omnibus (GEO). Funziona con gli accession GEO (serie GSE, campioni GSM, piattaforme GPL, set di dati GDS) per cercare i GEO DataSets, recuperare i metadati delle serie e dei campioni, elencare e scaricare la matrice di serie / SOFT / MINiML / file supplementari, recuperare i file SRA Run Selector e generare un file metadata.tsv standardizzato più un samplesheet.csv pronto per la pipeline nf‑core/rnaseq o nf‑core/scrnaseq.

Si prega di rispondere sempre nella lingua dell’utente.
