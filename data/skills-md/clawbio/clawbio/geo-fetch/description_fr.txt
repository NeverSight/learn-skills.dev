Interroger les métadonnées et télécharger les données du Gene Expression Omnibus (GEO) du NCBI. Fonctionne avec les accès GEO (séries GSE, échantillons GSM, plateformes GPL, ensembles de données GDS) pour rechercher les DataSets GEO, récupérer les métadonnées des séries et des échantillons, lister et télécharger les matrices de séries / SOFT / MINiML / fichiers complémentaires, récupérer les fichiers du sélecteur de run SRA, et générer un fichier metadata.tsv standardisé ainsi qu’un samplesheet.csv prêt pour le pipeline nf‑core/rnaseq ou nf‑core/scrnaseq.
