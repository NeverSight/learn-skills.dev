Сгенерировать 4‑панельный региональный диагностический график LocusCompare для одного кортежа (ведущий вариант, исследование‑экспозиция, исследование‑исход) — наложить GWAS‑Манхэттен, QTL‑Манхэттен, трек генов GENCODE и кросс‑признаковый scatter, раскрашенный по LD r². Использовать, когда требуется визуальное подтверждение того, что два сигнала GWAS/QTL имеют один и тот же причинный вариант (конвенция Liu 2019 LocusCompare). Входные данные: ведущий вариант + два предварительно полученных гармонизированных среза sumstats (или идентификаторы из eQTL Catalogue/GWAS Catalog для пакетного получения). Выход: PNG + JSON‑манифест.
