Запрашивайте метаданные и скачивайте данные из PRIDE Archive, базы данных идентификации протеомики EMBL‑EBI, через REST API PRIDE Archive версии 3. Работает с идентификаторами PRIDE/ProteomeXchange (PXD, PRD) для получения метаданных проекта, списка и загрузки файлов (RAW, mzIdentML, mzML, mzTab, MGF, SDRF), поиска проектов, создания стандартизированного файла metadata.tsv, генерации минимального листа образцов SDRF, готового для quantms, и формирования скрипта загрузки на Bash + SLURM.
