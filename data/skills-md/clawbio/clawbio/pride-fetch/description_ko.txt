PRIDE Archive, EMBL-EBI의 단백질체학 식별 데이터베이스에서 메타데이터를 조회하고 데이터를 다운로드합니다. PRIDE Archive REST API v3를 통해 수행합니다. PRIDE/ProteomeXchange 접근자(PXD, PRD)를 사용하여 프로젝트 메타데이터를 가져오고, 파일(RAW, mzIdentML, mzML, mzTab, MGF, SDRF) 목록을 확인하고 다운로드하며, 프로젝트를 검색하고, 표준화된 metadata.tsv를 생성하고, quantms에 준비된 최소 SDRF 샘플 시트를 작성하며, bash + SLURM 다운로드 스크립트를 생성합니다.

항상 사용자의 언어로 응답해 주세요.
