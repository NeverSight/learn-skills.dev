Consulta metadatos y descarga datos del PRIDE Archive, la base de datos de identificaciones de proteómica de EMBL‑EBI, mediante la API REST v3 del PRIDE Archive. Funciona con los accesos PRIDE/ProteomeXchange (PXD, PRD) para obtener los metadatos del proyecto, listar y descargar archivos (RAW, mzIdentML, mzML, mzTab, MGF, SDRF), buscar proyectos, generar un archivo metadata.tsv estandarizado, crear una hoja de muestra SDRF mínima lista para quantms y generar un script de descarga bash + SLURM.
