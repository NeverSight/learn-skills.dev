Interrogez les métadonnées et téléchargez les données depuis le PRIDE Archive, la base de données d’identifications protéomiques d’EMBL‑EBI, via l’API REST v3 du PRIDE Archive. Fonctionne avec les accès PRIDE/ProteomeXchange (PXD, PRD) pour récupérer les métadonnées du projet, lister et télécharger les fichiers (RAW, mzIdentML, mzML, mzTab, MGF, SDRF), rechercher des projets, générer un fichier metadata.tsv standardisé, créer une feuille d’échantillons SDRF minimale compatible quantms, et produire un script de téléchargement bash + SLURM.
