Interroga i metadati e scarica i dati di sequenziamento dall'European Nucleotide Archive (ENA) tramite le API del Portale e del Browser. Funziona con gli accession ENA/SRA (studi PRJEB/PRJNA, run ERR/SRR/DRR, esperimenti ERX/SRX, campioni SAMEA/SAMN), elencando i run e i link FASTQ, creando report di file personalizzati, eseguendo ricerche avanzate sui metadati e generando un metadata.tsv standardizzato più un samplesheet.csv pronto per pipeline nf‑core/rnaseq o nf‑core/scrnaseq. Per favore rispondi sempre nella lingua dell'utente.
