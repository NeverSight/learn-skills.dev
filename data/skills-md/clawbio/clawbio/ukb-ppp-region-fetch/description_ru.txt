Получите региональный фрагмент сводных статистических данных pQTL плазмы из проекта UK Biobank Pharma Proteomics (UKB‑PPP; Sun 2023 Nature) для конкретного измерения (протеин, популяция). Используется, когда агенту нужны бета‑коэффициент, стандартная ошибка и p‑значение для каждой вариации вокруг лидирующего варианта в колокализе для последующей колокализации, менделевской рандомизации или регионального построения графиков по сравнению с экспозицией pQTL. Канонический случай применения — окно cis‑вокруг TSS кодирующего гена протеина, но UKB‑PPP предоставляет полногеномные сводные данные по каждому протеину, поэтому поддерживается любой окно GRCh38 (включая транс‑локусы), если пользователь задаёт явный (хромосома, start_bp, end_bp). Ввод: protein_label (HGNC или UniProt), ancestry, chromosome, start_bp, end_bp. Вывод: согласованный TSV‑фрагмент + манифест + человекочитаемый отчёт.
