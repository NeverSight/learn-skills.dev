Abrufen eines regionalen Ausschnitts von PlasmapQTL‑Zusammenfassungsstatistiken aus dem UK Biobank Pharma Proteomics Project (UKB‑PPP; Sun 2023 Nature) für eine spezifische (Protein, Abstammung) Messung. Verwendung, wenn ein Agent per‑Variante Beta / SE / p‑Wert um eine coloc‑Lead‑Variante für nachgelagerte Kolokalisierung, Mendelsche Randomisierung oder regionale Visualisierung gegenüber einer pQTL‑Exposition benötigt. Der typische Anwendungsfall ist das cis‑Fenster um den Transkriptionsstartort (TSS) des codierenden Gens des Proteins, aber UKB‑PPP stellt genomsweite Zusammenfassungsstatistiken pro Protein zur Verfügung, sodass jedes GRCh38‑Fenster (einschließlich trans‑Loci) unterstützt wird, wenn der Nutzer ein explizites (Chromosom, start_bp, end_bp) angibt. Eingabe: protein_label (HGNC oder UniProt), Abstammung, Chromosom, start_bp, end_bp. Ausgabe: harmonisierter TSV‑Ausschnitt + Manifest + menschenlesbarer Bericht.
