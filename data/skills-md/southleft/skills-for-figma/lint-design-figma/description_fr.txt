Analyse (lint) un arbre de nœuds Figma pour l'accessibilité WCAG 2.2 ET la qualité du système de conception — contraste, taille cible, indicateurs de focus, signalisation uniquement par couleur, couleurs codées en dur, styles de texte manquants, composants détachés, et plus encore. À utiliser lorsque l'utilisateur souhaite un audit côté design AVANT la remise : déclenche « lint this frame », « check accessibility », « WCAG audit », « is my design accessible », « find contrast issues », « check color contrast », « find hardcoded colors », « are my components using tokens », « design QA », « a11y check on this page », « audit my design for issues ». Parcourt l'arbre à partir d'un nœud (ou de la page entière) et renvoie des constats avec sévérité (critique/avertissement/info) et niveau WCAG (A/AA/AAA/meilleure pratique). Le MCP natif de Figma n’a AUCUN lint côté design — c’est unique à cette collection. Pour le tableau de bord a11y détaillé par composant, utilisez audit‑accessibility‑figma ; pour les vérifications côté CODE (HTML), utilisez scan‑code‑accessibility‑figma.
