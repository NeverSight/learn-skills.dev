Проверьте дерево узлов Figma на соответствие WCAG 2.2 и качеству дизайн‑системы — контраст, размер целевого элемента, индикаторы фокуса, сигналы только цветом, жёстко закодированные цвета, отсутствие текстовых стилей, отсоединённые компоненты и многое другое. Используется, когда пользователь хочет провести аудит дизайна ДО передачи: вызываются команды «lint this frame», «check accessibility», «WCAG audit», «is my design accessible», «find contrast issues», «check color contrast», «find hardcoded colors», «are my components using tokens», «design QA», «a11y check on this page», «audit my design for issues». Обходит дерево, начиная с узла (или всей страницы), и возвращает найденные проблемы с уровнем серьёзности (critical/warning/info) и уровнем WCAG (A/AA/AAA/best‑practice). Встроенный Figma MCP НЕ имеет проверки дизайна — это уникально для этой коллекции. Для глубокого анализа доступности по каждому компоненту используйте audit-accessibility-figma; для проверок на стороне кода (HTML) — scan-code-accessibility-figma.
