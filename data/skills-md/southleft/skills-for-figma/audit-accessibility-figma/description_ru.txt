Глубокая карточка оценки доступности для отдельного компонента Figma или набора компонентов — покрытие состояний (по умолчанию/при наведении/фокус/отключено/ошибка/активно/загрузка), качество индикатора фокуса и контраст, различие состояний без использования цвета, размер цели, полнота аннотаций и имитация восприятия людьми с дальтонизмом (протанопия/дейтеранопия/тританопия), всё объединено в оценки от 0 до 100 по каждой категории и приоритетные рекомендации. Используется, когда пользователь хочет проверить ОДИН компонент перед выпуском: активирует «аудитировать этот компонент», «оценка доступности этой кнопки», «является ли набор компонентов доступным», «проверить состояния этого компонента», «есть ли у моей кнопки состояние фокуса», «проверка для дальтоников», «оценить этот компонент по a11y», «карточка доступности компонента». Работает на любой подписке Figma. Для широкого анализа всей страницы/фрейма используйте lint-design-figma; для проверок на стороне кода (HTML) — scan-code-accessibility-figma.
