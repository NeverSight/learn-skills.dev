Tarjeta de puntuación de accesibilidad profunda para un solo componente de Figma o conjunto de componentes: cobertura de estados (predeterminado/paso del ratón/enfoque/desactivado/error/activo/cargando), calidad y contraste del indicador de foco, diferenciación de estados sin color, tamaño del objetivo, exhaustividad de anotaciones y simulación para daltonismo (protanopia/deuteranopia/tritanopia), todo consolidado en puntuaciones de 0 a 100 por categoría y recomendaciones priorizadas. Úsala cuando el usuario quiera evaluar UN COMPONENTE antes de publicarlo: activa “auditar este componente”, “puntuación de accesibilidad para este botón”, “¿es accesible este conjunto de componentes?”, “verificar los estados de este componente”, “¿mi botón tiene estado de foco?”, “verificación para daltonismo”, “calificar este componente por a11y”, “tarjeta de puntuación de accesibilidad del componente”. Funciona en CUALQUIER plan de Figma. Para una revisión amplia de toda una página o marco usa lint-design-figma; para verificaciones del lado del CÓDIGO (HTML) usa scan-code-accessibility-figma.
