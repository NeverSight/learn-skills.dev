Générez une documentation Markdown complète pour un composant Figma — anatomie/arbre des calques, tokens de conception (couleurs, espacements, typographie), matrice d’états/variantes, notes d’accessibilité, directives de contenu, et éventuellement la parité de code + front‑matter YAML. À utiliser lorsque l’utilisateur veut une page de documentation ou une spécification de remise pour un composant ou un ensemble de composants. Déclencheurs : « documenter ce composant », « générer les docs/spéc du composant », « créer une page de docs pour le Button », « rédiger l’anatomie et les variantes », « doc de remise du composant depuis Figma », « transformer ce composant en docs Markdown ». Lit l’arbre de nœuds, les variables/tokens liés et les annotations du designer, puis l’agent assemble le Markdown. Nécessite l’application de bureau Figma (API du plugin).

Veuillez toujours répondre dans la langue de l’utilisateur.
