Генерировать полную Markdown‑документацию для компонента Figma — анатомию/дерево слоёв, дизайн‑токены (цвета, отступы, типографика), матрицу состояний/вариантов, заметки по доступности, рекомендации по контенту и при необходимости код‑паритет + YAML‑frontmatter. Используется, когда пользователь хочет страницу документации или handoff‑спецификацию для компонента или набора компонентов. Триггеры: «document this component», «generate component docs/spec», «create a docs page for the Button», «write up the anatomy and variants», «component handoff doc from Figma», «turn this component into Markdown docs». Считывает дерево узлов, привязанные переменные/токены и аннотации дизайнера, затем агент собирает Markdown. Требуется приложение Figma Desktop (Plugin API).

Пожалуйста, всегда отвечайте на языке пользователя.
