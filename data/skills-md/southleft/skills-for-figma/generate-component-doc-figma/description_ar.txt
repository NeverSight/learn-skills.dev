إنشاء وثائق Markdown كاملة لمكوّن Figma — التركيب/شجرة الطبقات، رموز التصميم (الألوان، الفواصل، الخطوط)، مصفوفة الحالات/البدائل، ملاحظات إمكانية الوصول، إرشادات المحتوى، ورمز موازاة اختياري + مقدمة YAML. يُستَخدم عندما يرغب المستخدم في صفحة توثيق أو مواصفة تسليم لمكوّن أو مجموعة مكوّنات. المحفزات: "وثّق هذا المكوّن"، "أنشئ وثائق/مواصفات المكوّن"، "أنشئ صفحة توثيق للزر"، "اكتب التركيب والبدائل"، "وثيقة تسليم المكوّن من Figma"، "حوّل هذا المكوّن إلى وثائق Markdown". يقرأ شجرة العقد، المتغيّرات/الرموز المرتبطة، وتعليقات المصمم، ثم يجمع الوكيل الـMarkdown. يتطلّب تطبيق Figma Desktop (API الإضافة). يرجى دائمًا الرد بلغة المستخدم.
