Erstelle vollständige Markdown-Dokumentation für ein Figma‑Komponente — Anatomie/Ebenenbaum, Design‑Tokens (Farben, Abstände, Typografie), Zustands‑/Varianten‑Matrix, Barrierefreiheits‑Hinweise, Inhaltsrichtlinien sowie optional Code‑Parity + YAML‑Frontmatter. Verwende dies, wenn der Nutzer eine Dokumentations‑Seite oder ein Handoff‑Spezifikations‑Dokument für eine Komponente oder ein Komponentenset benötigt. Auslöser: „document this component“, „generate component docs/spec“, „create a docs page for the Button“, „write up the anatomy and variants“, „component handoff doc from Figma“, „turn this component into Markdown docs“. Liest den Knot‑Baum, gebundene Variablen/Token und Designer‑Anmerkungen und assembliert anschließend das Markdown. Benötigt die Figma‑Desktop‑App (Plugin‑API).

Bitte antworte stets in der Sprache des Benutzers.
