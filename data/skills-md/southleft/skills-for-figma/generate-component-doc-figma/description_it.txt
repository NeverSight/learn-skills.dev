Genera una documentazione Markdown completa per un componente Figma — anatomia/albero dei livelli, token di design (colori, spaziature, tipografia), matrice di stati/varianti, note di accessibilità, linee guida per i contenuti e, opzionalmente, parity del codice + frontmatter YAML. Usalo quando l'utente desidera una pagina di documentazione o una specifica di handoff per un componente o un set di componenti. Trigger: “documenta questo componente”, “genera docs/spec del componente”, “crea una pagina di documentazione per il Pulsante”, “scrivi l'anatomia e le varianti”, “documento di handoff del componente da Figma”, “trasforma questo componente in documenti Markdown”. Legge l'albero dei nodi, le variabili/token collegati e le annotazioni del designer, quindi l'agente assembla il Markdown. Richiede l'app Figma Desktop (API del plugin). Per favore rispondi sempre nella lingua dell'utente.
