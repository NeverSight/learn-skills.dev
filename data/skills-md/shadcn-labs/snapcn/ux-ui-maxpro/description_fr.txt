Répliquez une interface de référence pixel par pixel et créez un chrome de site poli, piloté par des tokens. Utilisez-le lorsque la tâche consiste à reproduire exactement une capture d’écran ou un site en direct, à redessiner une page pour qu’elle ressemble à une référence de conception, ou à créer une mise en page en maçonnerie/galerie/grille qui doit refléter la source. Les déclencheurs incluent « pixel perfect », « réplica exact », « pas un seul changement », « correspondre à ce design », « comme cette capture d’écran », « grille maçonnerie », « galerie de design », « redesign de l’aperçu », « même espacement », « même style de design », « cloner cette mise en page », et toute demande associant une image cible UI avec « faites‑le exactement comme ça ». Activez également lorsque vous mesurez l’espacement ou la typographie à partir d’une référence avant d’écrire le CSS.

Veuillez toujours répondre dans la langue de l’utilisateur.
