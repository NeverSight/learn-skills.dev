コンソールに入らずに、qianwenai‑deploy によって Alibaba Cloud 国内サイト（aliyun.com）にデプロイされたアプリケーションのヘルス、パフォーマンス、リソース状態、実際のコストを自然言語で報告します。プロジェクトディレクトリの .qianwenai‑deploy ステートファイルを読み取り、アプリケーションとその ECS（およびオプションの RDS MySQL）リソースを特定し、読み取り専用のクラウド API を呼び出して、アプリケーションの可用性、ECS/RDS のパフォーマンス、そして人民元でのコストを要約します。

使用例: ユーザーがデプロイされたアプリケーションの稼働状況を尋ね、ヘルス／パフォーマンス／コストの概要を求め、CPU／メモリ／接続数／スロークエリリスクに関心がある、あるいは qianwenai がデプロイしたアプリケーションの月間コストを問い合わせる場合。

非使用例: .qianwenai‑deploy ステートファイルが存在しない場合；対象が Alibaba Cloud 国際サイト（qwencloud‑observe を使用）; ユーザーがリソースの変更や復元を希望する場合（qianwenai‑operate を使用）。

常にユーザーの言語で回答してください。
