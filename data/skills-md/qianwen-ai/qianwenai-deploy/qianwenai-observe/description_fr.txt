Rapportez la santé, les performances, l’état des ressources et le coût réel des applications déployées par qianwenai‑deploy sur le site domestique d’Alibaba Cloud (aliyun.com) en langage naturel, sans besoin d’ouvrir la console. Il lit le fichier d’état .qianwenai‑deploy dans le répertoire du projet pour identifier l’application et ses ressources ECS (et éventuellement RDS MySQL), puis appelle les API cloud en lecture seule afin d’agréger la disponibilité de l’application, les performances ECS/RDS et les coûts en RMB. Cas d’utilisation : l’utilisateur demande comment l’application déployée fonctionne, souhaite un aperçu de la santé/performance/coût, s’intéresse au CPU/mémoire/compte de connexions/risque de SQL lent, ou s’enquiert du coût mensuel de l’application déployée par qianwenai. Cas non pertinents : il n’y a pas de fichier d’état .qianwenai‑deploy ; la cible est le site international d’Alibaba Cloud (utiliser qwencloud‑observe) ; l’utilisateur veut modifier ou restaurer des ressources (utiliser qianwenai‑operate).
