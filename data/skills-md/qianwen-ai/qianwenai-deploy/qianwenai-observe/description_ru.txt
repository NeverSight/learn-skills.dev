Отчет в естественном языке о состоянии здоровья, производительности, статусе ресурсов и фактической стоимости приложений, развернутых qianwenai-deploy в отечественном сайте Alibaba Cloud (aliyun.com), без входа в консоль. Прочитайте файл состояния .qianwenai-deploy в каталоге проекта, чтобы определить приложение и его ресурсы ECS (и при желании RDS MySQL), затем вызовите только для чтения облачные API, чтобы суммировать доступность приложения, производительность ECS/RDS и затраты в RMB. Сценарий использования: пользователи спрашивают, как работает развернутое приложение, хотят обзор состояния здоровья/производительности/стоимости, интересуются CPU/памятью/числом соединений/риском медленных SQL, либо запрашивают месячную стоимость приложения, развернутого qianwenai‑deployed. Сценарий, не подпадающий под использование: отсутствует файл состояния .qianwenai‑deploy; цель — международный сайт Alibaba Cloud (использовать qwencloud‑observe); пользователи хотят изменить или восстановить ресурсы (использовать qianwenai‑operate).  

Всегда отвечайте на языке пользователя.
