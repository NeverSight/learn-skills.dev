Report the health, performance, resource status, and actual costs of applications deployed to the Alibaba Cloud domestic site (aliyun.com) by qianwenai-deploy in natural language, without needing to access the console. Read the .qianwenai-deploy status file in the project directory to identify the application and its ECS (and optionally RDS MySQL) resources, then call read‑only cloud APIs to aggregate application availability, ECS/RDS performance, and costs in RMB. Use cases: users ask how a deployed application is running, want an overview of health/performance/costs, care about CPU/memory/connection count/slow‑SQL risk, or inquire about the monthly cost of an application deployed by qianwenai. Non‑use cases: there is no .qianwenai-deploy status file; the target is Alibaba Cloud international site (use qwencloud-observe); users want to modify or restore resources (use qianwenai-operate).
