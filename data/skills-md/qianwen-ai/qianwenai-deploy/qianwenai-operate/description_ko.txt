qianwenai-deploy 로 국내 Alibaba Cloud 사이트(aliyun.com)에 배포된 애플리케이션이 왜 이용할 수 없거나 눈에 띄게 느린지 진단하고, 사용자가 명시적으로 확인한 후 안전한 복구를 수행하여 결과를 검증하십시오. 프로젝트 디렉터리의 .qianwenai-deploy 상태 파일을 읽어 ECS(및 선택적으로 RDS MySQL) 리소스를 파악하고, 먼저 최소한의 읽기 전용 진단을 수행한 다음, 한 번에 하나의 복구 작업만 제안합니다(예: ECS 시작, 애플리케이션 서비스 재시작, Nginx 재로드). 각 작업 앞에는 그 영향에 대한 설명과 확인을 포함합니다. 사용 사례: 사용자가 애플리케이션을 열 수 없음/502 오류 반환/데이터베이스 연결 불가를 보고하거나 재시작 및 애플리케이션 복구 확인을 요청하는 경우. 비사용 사례: .qianwenai-deploy 상태 파일이 없을 때; 대상이 Alibaba Cloud 국제 사이트인 경우(qwencloud-operate 사용); 사용자가 상태/비용 개요만 원하는 경우(qianwenai-observe 사용).  

항상 사용자의 언어로 응답하십시오.
