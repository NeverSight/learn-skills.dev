Диагностировать, почему приложение, развернутое с помощью qianwenai-deploy на отечественном сайте Alibaba Cloud (aliyun.com), недоступно или заметно медленно, а после явного подтверждения пользователя выполнить безопасное восстановление и проверить результат. Прочитать файл состояния .qianwenai-deploy в каталоге проекта, чтобы определить ресурсы ECS (и при необходимости RDS MySQL), сначала провести минимальную диагностику только для чтения, затем предлагать по одной восстановительной операции за раз (запустить ECS, перезапустить сервис приложения, перезагрузить Nginx), при каждой операции сначала дав объяснение и запрос подтверждения её воздействия.
