درب نموذجًا على رواية، ثم استمر في الكتابة داخل عالم تلك الرواية — مع حفظ الذاكرة للشخصيات، والأماكن، والأحداث الأخيرة. حمِّل هذه المهارة كلما طلب المستخدم تدريب/تحسين/تعلم أسلوب رواية أو ملف .txt، أو ذكر Echo-Quill / Alchemist / 炼金 / 双塔، أو طلب فتح لوحة التحكم الخاصة بالتدريب، أو سأل عن طريقة عمل النظام، أو طلب إيقاف أو إعادة تشغيل خدمات التدريب، أو طلب كتابة/متابعة نص (مع أو بدون الذاكرة)، أو طلب تدريب فصل إضافي أو استكمال كتبَه، أو طلب التراجع إلى حالة الرواية الأصلية. تُدير المهارة خلفية محلية باستخدام FastAPI + لوحة تحكم Vite/React، وتثبيت الاعتمادات، وإنشاء ملفات .env، والتدريب، والاستمرار بوضع الذاكرة، والاستمرار بأسلوب نقي، والتراجع — يزوِّد المستخدم بمسار الرواية أو مقطع نصي، وتتعامل المهارة مع كل ما يلزم تحت السطح.
