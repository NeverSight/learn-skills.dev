Imposta una “fabbrica di software” che trasforma le issue etichettate su GitHub in pull request revisionate, usando agenti di codifica (Claude Code, Codex o qualsiasi altro agente CLI) che operano in sandbox Upstash Box e vengono avviati da GitHub Actions. Utilizzala ogni volta che qualcuno vuole creare, ricreare, estendere o fare debug di una pipeline issue‑to‑PR, di un pool di agenti di codifica in background, di “agenti che lavorano sulle mie issue di GitHub”, di un flusso di lavoro attivato da etichette, o di qualsiasi cosa che combini Upstash Box con agenti di codifica e GitHub, anche se non menzionano mai “fabbrica di software”. Usala anche per aggiungere un repository, un tipo di agente, dei worker, un modello o un’impostazione di effort, o un’immagine di worker (snapshot) a una fabbrica creata in questo modo.
