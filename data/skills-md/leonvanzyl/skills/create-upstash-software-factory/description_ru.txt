Настройте «фабрику программного обеспечения», которая преобразует помеченные задачи GitHub в проверенные pull‑request’ы, используя кодирующие агенты (Claude Code, Codex или любой другой CLI‑агент), работающие в песочницах Upstash Box и запускаемые через GitHub Actions. Применяйте её каждый раз, когда кто‑то хочет создать, воссоздать, расширить или отладить конвейер «задача‑в‑PR», пул фоновых кодирующих агентов, «агентов, работающих над моими задачами GitHub», рабочий процесс, инициируемый меткой, или любую комбинацию Upstash Box с кодирующими агентами и GitHub, даже если они никогда не используют термин «фабрика программного обеспечения». Также используйте её для добавления репозитория, типа агента, рабочих процессов, модели или настройки усилий, а также образа рабочего процесса (снимка) в фабрику, построенную таким способом.
