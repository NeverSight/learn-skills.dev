Richten Sie eine „Softwarefabrik“ ein, die mit etikettierten GitHub‑Issues geprüfte Pull‑Requests erstellt, indem Sie Codierungs‑Agents (Claude Code, Codex oder irgendeinen anderen CLI‑Agent) verwenden, die in Upstash‑Box‑Sandboxen laufen und von GitHub‑Actions gestartet werden. Nutzen Sie das immer, wenn jemand eine Issue‑zu‑PR‑Pipeline aufbauen, neu erstellen, erweitern oder debuggen möchte, einen Pool von Hintergrund‑Coding‑Agents, „Agents, die an meinen GitHub‑Issues arbeiten“, einen durch Labels ausgelösten Agent‑Workflow oder irgendetwas, das Upstash Box mit Coding‑Agents und GitHub kombiniert, selbst wenn sie nie „Softwarefabrik“ sagen. Verwenden Sie es außerdem, um ein Repository, einen Agententyp, Workers, eine Modell‑ oder Aufwandseinstellung oder ein Worker‑Image (Snapshot) zu einer auf diese Weise aufgebauten Fabrik hinzuzufügen.
