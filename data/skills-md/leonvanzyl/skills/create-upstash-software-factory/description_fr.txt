Configurez une « usine logicielle » qui transforme les tickets GitHub étiquetés en pull requests révisées, en utilisant des agents de codage (Claude Code, Codex ou tout autre agent CLI) qui s'exécutent dans des sandbox Upstash Box et sont lancés par GitHub Actions. Utilisez cela chaque fois que quelqu’un veut créer, recréer, étendre ou déboguer un pipeline issue‑to‑PR, un pool d’agents de codage en arrière‑plan, « agents qui travaillent sur mes tickets GitHub », un workflow d’agents déclenché par un label, ou tout ce qui combine Upstash Box avec des agents de codage et GitHub, même s’ils ne mentionnent jamais « software factory ». Utilisez‑le également pour ajouter un dépôt, un type d’agent, des workers, un paramètre de modèle ou d’effort, ou une image de worker (snapshot) à une usine construite de cette manière.
