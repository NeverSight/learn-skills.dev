建立一個「軟體工廠」，將有標籤的 GitHub 問題轉換為已審核的 Pull Request，使用在 Upstash Box 沙箱中執行、由 GitHub Actions 啟動的程式碼代理（如 Claude Code、Codex 或其他任意 CLI 代理）。

每當有人想要建立、重建、擴充或除錯 issue‑to‑PR 流程、背景程式碼代理池、稱為「處理我的 GitHub 問題的代理」的系統、標籤觸發的代理工作流程，或任何結合 Upstash Box、程式碼代理與 GitHub 的應用時，都請使用此方法，即使他們從未提及「軟體工廠」。

同時，也可利用它向以此方式構建的工廠中新增儲存庫、代理類型、工作者、模型或工作量設定，或工作者映像（快照）。
