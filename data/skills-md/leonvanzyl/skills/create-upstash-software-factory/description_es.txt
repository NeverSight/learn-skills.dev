Configure una "fábrica de software" que convierta los issues etiquetados de GitHub en pull requests revisados, utilizando agentes de codificación (Claude Code, Codex o cualquier otro agente CLI) que se ejecuten en entornos sandbox de Upstash Box y sean iniciados por GitHub Actions. Use esto siempre que alguien quiera crear, recrear, ampliar o depurar una canalización de issue a PR, un conjunto de agentes de codificación en segundo plano, "agentes que trabajan en mis issues de GitHub", un flujo de trabajo de agente activado por etiquetas, o cualquier cosa que combine Upstash Box con agentes de codificación y GitHub, incluso si nunca mencionan "fábrica de software". También úselo para añadir un repositorio, un tipo de agente, workers, un modelo o configuración de esfuerzo, o una imagen de worker (instantánea) a una fábrica construida de esta manera.
