라벨이 지정된 GitHub 이슈를 검토된 풀 리퀘스트로 변환하는 “소프트웨어 팩토리”를 설정하고, Upstash Box 샌드박스에서 실행되며 GitHub Actions에 의해 시작되는 코딩 에이전트(Claude Code, Codex 또는 기타 CLI 에이전트)를 사용하세요. 이 방법은 누군가가 이슈‑to‑PR 파이프라인을 구축, 재구성, 확장 또는 디버깅하고자 할 때, 백그라운드 코딩 에이전트 풀, “내 GitHub 이슈를 작업하는 에이전트”, 라벨 트리거 에이전트 워크플로우, 혹은 Upstash Box와 코딩 에이전트, GitHub를 결합한 모든 경우에 사용하십시오—설령 그들이 “소프트웨어 팩토리”라는 말을 쓰지 않더라도. 또한 이렇게 구축된 팩토리에 레포지토리, 에이전트 유형, 워커, 모델 또는 노력 설정, 혹은 워커 이미지(스냅샷)를 추가하는 데에도 사용하세요.
