إعداد "مصنع برمجيات" يحول القضايا الموسومة على GitHub إلى طلبات سحب مُراجَعة، باستخدام وكلاء الترميز (Claude Code، Codex أو أي وكيل سطر أوامر آخر) الذين يعملون في بيئات صندوق Upstash Box الرملية ويتم تشغيلهم بواسطة GitHub Actions. استخدم ذلك كلما أراد أحدهم بناء أو إعادة إنشاء أو توسيع أو تصحيح خط أنابيب من قضية إلى طلب سحب، أو مجموعة من وكلاء الترميز في الخلفية، أو "وكلاء يعملون على قضايا GitHub الخاصة بي"، أو سير عمل وكيل مُفعَّل بالعلامة، أو أي شيء يجمع بين Upstash Box ووكلاء الترميز وGitHub، حتى لو لم يذكروا أبدًا "مصنع برمجيات". كما يمكن استخدامه لإضافة مستودع، أو نوع وكيل، أو عمال، أو نموذج أو إعداد الجهد، أو صورة عامل (لقطة) إلى مصنع تم بناؤه بهذه الطريقة. يرجى دائمًا الرد بلغة المستخدم.
