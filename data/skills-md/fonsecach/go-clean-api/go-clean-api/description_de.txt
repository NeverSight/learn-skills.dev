Validiert und reproduziert eine Go‑HTTP‑API, deren Abhängigkeiten nach innen gerichtet sind: cmd verbindet, Domain besitzt Entitäten und Ports, Application besitzt Anwendungsfälle, Infrastructure besitzt Adapter, Delivery besitzt chi. Verwenden Sie es, wenn der Nutzer sagt „go-clean-api“, „review the layers“, „where does this code go“, „add an endpoint“, „scaffold a Go API“, „OpenAPI“ oder „add telemetry“. Nicht verwenden für Go‑Stil auf Zeilenebene (go-coding-standards), REST‑Ressourcenstruktur (go-api-design), CLIs und Bibliotheken (go-project-layout) oder Feature‑Planung (tlc-spec-lean). Bitte immer in der Sprache des Benutzers antworten.
