Valide et reproduit une API HTTP Go dont les dépendances pointent vers l'intérieur : cmd assure le câblage, le domaine possède les entités et les ports, l'application possède les cas d'utilisation, l'infrastructure possède les adaptateurs, la livraison possède chi. Utilisez‑le lorsque l'utilisateur dit « go-clean-api », « review the layers », « where does this code go », « add an endpoint », « scaffold a Go API », « OpenAPI » ou « add telemetry ». NE l'utilisez PAS pour le style Go au niveau de la ligne (go-coding-standards), la forme des ressources REST (go‑api‑design), les CLI et bibliothèques (go‑project‑layout), ou la planification de fonctionnalités (tlc‑spec‑lean).

Veuillez toujours répondre dans la langue de l'utilisateur.
