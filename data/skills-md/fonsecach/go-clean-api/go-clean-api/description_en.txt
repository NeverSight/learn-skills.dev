Validates and reproduces a Go HTTP API whose dependencies point inward: cmd wires, domain owns entities and ports, application owns use cases, infrastructure owns adapters, delivery owns chi. Use when the user says "go-clean-api", "review the layers", "where does this code go", "add an endpoint", "scaffold a Go API", "OpenAPI", or "add telemetry". Do NOT use for line-level Go style (go-coding-standards), REST resource shape (go-api-design), CLIs and libraries (go-project-layout), or feature planning (tlc-spec-lean).
