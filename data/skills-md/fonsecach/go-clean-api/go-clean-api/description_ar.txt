يُحقق ويعيد إنتاج واجهة برمجة تطبيقات HTTP بلغة Go تكون تبعياتها موجهة إلى الداخل: cmd يربط، المجال يمتلك الكيانات والمنافذ، التطبيق يمتلك حالات الاستخدام، البنية التحتية تمتلك المحولات، والتسليم يمتلك chi. يُستَخدم عندما يقول المستخدم "go-clean-api"، "review the layers"، "where does this code go"، "add an endpoint"، "scaffold a Go API"، "OpenAPI"، أو "add telemetry". لا تُستخدم لتنسيق Go على مستوى السطر (go-coding-standards)، أو شكل موارد REST (go-api-design)، أو واجهات سطر الأوامر والمكتبات (go-project-layout)، أو تخطيط الميزات (tlc-spec-lean). يرجى دائمًا الرد بلغة المستخدم.
