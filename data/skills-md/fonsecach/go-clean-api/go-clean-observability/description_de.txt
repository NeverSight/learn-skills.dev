Strukturiertes Logging, verteiltes Tracing, Metriken und der Grafana‑LGTM‑Stack für Go‑HTTP‑APIs, bereitgestellt von go-clean-api. Deckt slog, OpenTelemetry und den Observability‑Standard ab: ein OTel‑Collector verteilt an Prometheus, Loki und Tempo, mit bereitgestelltem Grafana und Log/Trace‑Korrelation. Verwendung, wenn: „Logging hinzufügen“, „strukturierte Logs“, „Tracing hinzufügen“, „OpenTelemetry“, „Metriken hinzufügen“, „Prometheus“, „Grafana“, „Loki“, „Tempo“, „Dashboard“, „Observability“, „Observability‑Stack“, „OTel‑Collector“, „diesen Code instrumentieren“ oder wenn Produktions‑Telemetry für eine Go‑API eingerichtet wird. Nicht verwenden für: wenn Code in den Schichten lebt (verwende go-clean-api), Performance‑Profiling mit pprof (verwende go-performance-review), Fehlerbehandlungsmuster (verwende go-error-handling) oder Health‑Check‑Endpunkte (verwende go-api-design).
