NO usar para: donde el código reside en las capas (usar go‑clean‑api), perfilado de rendimiento con pprof (usar go‑performance‑review), patrones de manejo de errores (usar go‑error‑handling), o endpoints de verificación de salud (usar go‑api‑design).
