Structured logging, distributed tracing, metrics, and the Grafana LGTM stack for Go HTTP APIs laid out by go-clean-api. Covers slog, OpenTelemetry, and the observability standard: one OTel Collector fans out to Prometheus, Loki, and Tempo, with provisioned Grafana and log/trace correlation. Use when: "add logging", "structured logs", "add tracing", "OpenTelemetry", "add metrics", "Prometheus", "Grafana", "Loki", "Tempo", "dashboard", "observability", "observability stack", "otel collector", "instrument this code", or when standing up production telemetry for a Go API. Do NOT use for: where code lives in the layers (use go-clean-api), performance profiling with pprof (use go-performance-review), error handling patterns (use go-error-handling), or health check endpoints (use go-api-design).
