结构化日志、分布式追踪、指标以及由 go-clean-api 布局的 Go HTTP API 的 Grafana LGTM 堆栈。涵盖 slog、OpenTelemetry 和可观测性标准：一个 OTel Collector 将数据分发到 Prometheus、Loki 和 Tempo，并配备预置的 Grafana 以及日志/追踪关联。使用场景："add logging"、"structured logs"、"add tracing"、"OpenTelemetry"、"add metrics"、"Prometheus"、"Grafana"、"Loki"、"Tempo"、"dashboard"、"observability"、"observability stack"、"otel collector"、"instrument this code"，或在为 Go API 建立生产级遥测时使用。不要使用于：代码位于层次结构中（使用 go-clean-api）、使用 pprof 进行性能分析（使用 go-performance-review）、错误处理模式（使用 go-error-handling）或健康检查端点（使用 go-api-design）。
