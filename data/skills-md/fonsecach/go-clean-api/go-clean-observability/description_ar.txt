التسجيل الهيكلي، التتبع الموزع، المقاييس، ومجموعة Grafana LGTM لواجهات برمجة التطبيقات HTTP في Go التي تم تنظيمها بواسطة go-clean-api. يغطي slog، OpenTelemetry، ومعيار الرصد: جامع OTel واحد يوزع إلى Prometheus وLoki وTempo، مع Grafana مُجهّزة وربط السجلات/التتبع. الاستخدام عندما تكون هناك حاجة إلى: “إضافة تسجيل”، “سجلات هيكلية”، “إضافة تتبع”، “OpenTelemetry”، “إضافة مقاييس”، “Prometheus”، “Grafana”، “Loki”، “Tempo”، “لوحة تحكم”، “رصد”، “مجموعة رصد”، “مجمع otel”، “إدراج أدوات التتبع في هذا الكود”، أو عند إعداد رصد الإنتاج لواجهة برمجة تطبيقات Go. لا يُستعمل لـ: وجود الكود في الطبقات (استخدم go-clean-api)، تحليل الأداء باستخدام pprof (استخدم go-performance-review)، أنماط معالجة الأخطاء (استخدم go-error-handling)، أو نقاط فحص الصحة (استخدم go-api-design).
