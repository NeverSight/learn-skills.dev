Logging strutturato, tracing distribuito, metriche e lo stack Grafana LGTM per le API HTTP Go presentate da go-clean-api. Copre slog, OpenTelemetry e lo standard di osservabilità: un OTel Collector distribuisce i dati a Prometheus, Loki e Tempo, con Grafana provisionata e correlazione log/traccia. Da utilizzare quando: "add logging", "structured logs", "add tracing", "OpenTelemetry", "add metrics", "Prometheus", "Grafana", "Loki", "Tempo", "dashboard", "observability", "observability stack", "otel collector", "instrument this code", o quando si implementa la telemetria di produzione per una API Go. NON utilizzare per: dove il codice vive nei layer (usa go-clean-api), profiling delle prestazioni con pprof (usa go-performance-review), pattern di gestione degli errori (usa go-error-handling) o endpoint di health check (usa go-api-design).
