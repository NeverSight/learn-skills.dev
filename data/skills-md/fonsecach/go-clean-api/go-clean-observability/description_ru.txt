Структурированное логирование, распределённое трассирование, метрики и стек Grafana LGTM для Go HTTP API, представленный в go‑clean‑api. Охватывает slog, OpenTelemetry и стандарт наблюдаемости: один OTel Collector разветвляется в Prometheus, Loki и Tempo, с предустановленной Grafana и корреляцией журналов/трассировок. Использовать, когда: «add logging», «structured logs», «add tracing», «OpenTelemetry», «add metrics», «Prometheus», «Grafana», «Loki», «Tempo», «dashboard», «observability», «observability stack», «otel collector», «instrument this code», либо при развертывании производственной телеметрии для Go API. НЕ использовать для: размещения кода в слоях (используйте go‑clean‑api), профилирования производительности с pprof (используйте go‑performance‑review), шаблонов обработки ошибок (используйте go‑error‑handling) или эндпоинтов проверки состояния (используйте go‑api‑design).
