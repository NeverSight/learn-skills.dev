結構化日誌、分散式追蹤、指標以及由 go-clean-api 規劃的 Go HTTP API 用 Grafana LGTM 堆疊。涵蓋 slog、OpenTelemetry 與可觀測性標準：單一 OTel Collector 會向 Prometheus、Loki 與 Tempo 發送資料，並提供配置好的 Grafana 與日誌/追蹤關聯。適用情境：「add logging」、「structured logs」、「add tracing」、「OpenTelemetry」、「add metrics」、「Prometheus」、「Grafana」、「Loki」、「Tempo」、「dashboard」、「observability」、「observability stack」、「otel collector」、「instrument this code」，或在為 Go API 建置生產環境遙測時使用。請勿使用於：程式碼位於層級中的情況（使用 go-clean-api）、使用 pprof 進行效能分析（使用 go-performance-review）、錯誤處理模式（使用 go-error-handling）或健康檢查端點（使用 go-api-design）。
