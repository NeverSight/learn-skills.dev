go-clean-api が定義する Go HTTP API 向けの構造化ロギング、分散トレーシング、メトリクス、Grafana LGTM スタックです。slog、OpenTelemetry、観測可能性の標準をカバーし、1 つの OTel Collector が Prometheus、Loki、Tempo にデータを流し、Grafana がプロビジョニングされログ/トレースの相関が取れます。使用シーン: 「add logging」「structured logs」「add tracing」「OpenTelemetry」「add metrics」「Prometheus」「Grafana」「Loki」「Tempo」「dashboard」「observability」「observability stack」「otel collector」「instrument this code」、または Go API の本番テレメトリを構築する場合。使用しないでください: コードがレイヤーに存在する場合（go-clean-api を使用）、pprof によるパフォーマンスプロファイリング（go-performance-review を使用）、エラーハンドリングパターン（go-error-handling を使用）、ヘルスチェックエンドポイント（go-api-design を使用）。
