La journalisation structurée, le traçage distribué, les métriques et la pile Grafana LGTM pour les API HTTP Go présentées par go-clean-api. Couvre slog, OpenTelemetry et la norme d’observabilité : un collecteur OTel se répartit vers Prometheus, Loki et Tempo, avec Grafana provisionnée et corrélation logs/traces. À utiliser lorsque : « add logging », « structured logs », « add tracing », « OpenTelemetry », « add metrics », « Prometheus », « Grafana », « Loki », « Tempo », « dashboard », « observability », « observability stack », « otel collector », « instrument this code », ou lors de la mise en place de la télémétrie de production pour une API Go. Ne PAS utiliser pour : où le code vit dans les couches (utiliser go-clean-api), le profilage de performance avec pprof (utiliser go-performance-review), les modèles de gestion d’erreurs (utiliser go-error-handling) ou les points de contrôle de santé (utiliser go-api-design).
