에이전트가 작성한 앱을 리포지토리에서 사용자가 직접 선택한 제공업체(호스팅, 데이터베이스, 인증, 결제, 이메일, 도메인/DNS)를 이용해 사용자의 자체 계정으로 실서비스에 배포합니다. 사용자는 계정을 연결하고 변경을 승인하며, 지원되는 연결 작업은 로컬 CLI를 통해 실행되고 명시적인 제한이 포함된 검증 증거를 생성합니다. 사용자가 앱을 배포, 출시, 온라인 공개하거나, 환경 변수, 웹훅, 인증 설정(회원가입, 이메일 확인, 비밀번호 정책), 실제 회원가입 → 확인 이메일 → 로그인 흐름, 비밀번호 복구, 두 사용자 간 계정 격리, 인증 리다이렉트, 이메일 DNS 또는 사용자 지정 도메인 설정을 요청할 때 사용합니다.
