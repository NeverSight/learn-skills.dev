Créez un ensemble de documents de conception système (README.md, docs/, plans/) à partir d’un TOR ou de toute exigence système avant de commencer le développement, puis vérifiez que les documents sont corrects, utilisables, cohérents et que le flux de travail est complet. Utilisez cette compétence chaque fois que l’utilisateur veut analyser ou concevoir un système à partir de spécifications, que l’utilisateur saisisse le flux de travail lui‑-même, indique un dossier contenant un fichier TOR, ou envoie une image d’un diagramme ou d’un document de flux. De plus, chaque fois que l’utilisateur mentionne TOR, périmètre, exigence, spécification, SRS, document de conception système, analyse système, liste de fonctionnalités, flow, modèle de données, spécification API, liste d’écrans, plan de développement, ou demande de « créer la documentation avant de démarrer le système », même s’il ne nomme pas la compétence ou n’utilise pas le terme document de conception directement. Utilisez‑le pour l’analyse et la documentation de conception d’un système à partir d’un TOR, d’un périmètre ou d’exigences pour tout type de système. Ne l’utilisez pas pour l’écriture de code, la revue de code ou la documentation d’un système déjà développé, comme les manuels d’utilisateur.
