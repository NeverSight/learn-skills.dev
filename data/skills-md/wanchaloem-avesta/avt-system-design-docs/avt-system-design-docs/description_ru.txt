Создайте набор документации по проектированию системы (README.md, docs/, plans/) на основе TOR‑объёма или требований любой системы до начала разработки, а затем проверьте, что документы корректны, пригодны к использованию, согласованы и рабочий процесс завершён. Используйте этот навык каждый раз, когда пользователь хочет проанализировать или спроектировать систему по спецификациям, независимо от того, вводит ли пользователь процесс вручную, указывает папку с файлом TOR или отправляет изображение схемы или документа. Кроме того, каждый раз, когда пользователь упоминает TOR, объём, требования, спецификацию, SRS, системную документацию по проектированию, системный анализ, список функций, рабочий процесс, модель данных, спецификацию API, список экранов, план разработки или просит «создать документацию перед началом системы», даже если он не называет навык явно или не использует термин «документация по проектированию». Применяйте его для системного анализа и проектной документации на основе TOR, объёма или требований любого типа системы. Не используйте его для написания кода, ревью кода или документирования завершённой системы, например пользовательских руководств.

Пожалуйста, всегда отвечайте на языке пользователя.
