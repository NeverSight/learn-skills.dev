在开始开发之前，从任何系统的 TOR（任务书）或需求中创建一套系统设计文档（README.md、docs/、plans/），随后检查文档是否正确、真正可用、没有矛盾，并且工作流完整。每当用户需要根据规格进行系统分析或设计时，无论用户自行输入工作流、指向包含 TOR 文件的文件夹，或发送流程图或文档的图片，都请使用此技能。每次用户提到 TOR、工作范围、需求、规范、SRS、系统设计文档、系统分析、功能列表、工作流、数据模型、API 规范、界面列表、开发计划，或请求“在系统开始前创建文档”，即使用户未直接提到此技能或使用“设计文档”一词，也请使用此技能来进行系统分析和设计文档的编写，适用于任何类型系统的 TOR、范围或需求。不要将其用于代码编写、代码审查或已完成系统的文档（如用户手册）。
