إنشاء مجموعة توثيق لتصميم النظام (README.md، docs/، plans/) من نطاق TOR أو متطلبات أي نظام قبل بدء التطوير، ومراجعة أن المستندات صحيحة، عملية الاستخدام، متسقة، وتغطي سير العمل الكامل. استخدم هذه المهارة كلما رغب المستخدم في تحليل أو تصميم نظام من المواصفات، سواءً كتب المستخدم سير العمل بنفسه، أو أشار إلى مجلد يحتوي على ملف TOR، أو قدم صورة لمخطط تدفق أو مستند. وكل مرة يذكر فيها المستخدم TOR أو النطاق أو المتطلبات أو المواصفات أو SRS أو وثيقة تصميم النظام أو تحليل النظام أو قائمة الميزات أو سير العمل أو نموذج البيانات أو مواصفات API أو قائمة الشاشات أو خطة التطوير، أو يطلب “إنشاء توثيق قبل بدء النظام”، حتى وإن لم يذكر اسم المهارة أو يستخدم مصطلح توثيق التصميم مباشرة. استخدمها لتحليل وتصميم النظام من TOR أو النطاق أو المتطلبات لأي نوع من الأنظمة. لا تستخدمها لكتابة الكود، مراجعة الكود، أو توثيق نظام مكتمل، مثل أدلة المستخدم.
