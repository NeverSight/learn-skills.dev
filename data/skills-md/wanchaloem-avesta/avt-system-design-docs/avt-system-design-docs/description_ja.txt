開発を開始する前に、TOR または任意のシステム要件からシステム設計ドキュメント（README.md、docs/、plans/）のセットを作成し、ドキュメントが正確で機能的かつ一貫性があり、全体のワークフローを網羅していることを確認してください。  

ユーザーが仕様からシステムの分析や設計を行う必要がある場合は、ユーザーがワークフローステップを書き込む場合でも、TOR ファイルが入ったフォルダを指し示す場合でも、フローチャートやドキュメントの画像を送信する場合でも、このスキルを使用してください。  

ユーザーが TOR、スコープ、要件、仕様、SRS、システム設計ドキュメント、システム分析、機能リスト、ワークフロー、データモデル、API 仕様、画面リスト、開発計画、または「システム開始前にドキュメントを作成してほしい」と要請した場合（たとえスキル名を挙げたり「設計ドキュメント」という用語を直接使用しなくても）、必ずこのスキルを使用してください。  

任意のシステムに対して、TOR、スコープ、または要件からシステム分析および設計ドキュメントを作成する際に使用してください。  

コードの作成、コードレビュー、またはユーザーマニュアルのような完成したシステムのドキュメント作成には使用しないでください。  

常にユーザーの言語で回答してください。
