Cree un conjunto de documentos de diseño del sistema (README.md, docs/, plans/) a partir de un TOR o de los requisitos de cualquier sistema antes de que comience el desarrollo, luego revise que los documentos sean correctos, prácticamente utilizables, consistentes y contengan un flujo de trabajo completo. Utilice esta habilidad siempre que el usuario necesite analizar o diseñar un sistema a partir de especificaciones—ya sea que proporcione los pasos del flujo de trabajo, indique una carpeta con un archivo TOR, o envíe imágenes de diagramas de flujo o documentos. Aplíquelo también cada vez que el usuario mencione TOR, alcance, requisito, especificación, SRS, documentos de diseño del sistema, análisis del sistema, lista de funciones, flujo de trabajo, modelo de datos, especificación de API, lista de pantallas, plan de desarrollo, o pida “crear documentación antes de iniciar el sistema,” incluso si el usuario no nombra explícitamente la habilidad o utiliza el término documentación de diseño. Úselo para el análisis del sistema y la documentación de diseño a partir de un TOR, alcance o requisitos de cualquier tipo de sistema. No lo utilice para escribir código, revisar código o documentar un sistema ya completado, como manuales de usuario. 

Por favor, responda siempre en el idioma del usuario.
