Ejecuta una revisión de seguridad con conciencia de contexto de un proyecto de software — primero comprende lo que hace el sistema y quién podría atacarlo, luego adapta el análisis en lugar de usar una lista de verificación estática. Produce un informe de hallazgos clasificado y respaldado por evidencia y prioriza cada hallazgo según el tipo de acción que necesita (corrección de código, cambio de especificación, cambio de diseño/ADR, decisión de producto o riesgo aceptado). Nunca edita el proyecto — solo análisis. Úsalo cuando el usuario solicite una revisión de seguridad, pase de seguridad, auditoría de seguridad o para encontrar vulnerabilidades en su proyecto.
