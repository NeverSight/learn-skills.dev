Contextualise le métier d’un système existant (brownfield) pour travailler AI‑first dessus – élabore la cartographie des capacités (ce que le système fait aujourd’hui), met en lumière les règles métier cachées dans le code et construit le glossaire métier ↔ code avec l’ARCH, le tout avec des preuves, puis s’arrête pour une approbation humaine. À utiliser lorsque le rôle de BA démarre sur un système existant sans PRD ni backlog, ou lorsqu’on demande de documenter ce qu’un système hérité fait, d’extraire ses règles métier ou de construire un glossaire de domaine.
