Подготовьте Sprint 0 (walking skeleton) проекта, исходя из его Tech Design и ADR — классифицируйте ADR на трансверсальные и исторические, определите карту владения маршрутами по ролям, напишите Definition of Done скелета и предложите план, затем остановитесь для человеческого одобрения. Используйте, когда LEAD (или пользователь) нужно подготовить, спланировать или инициализировать Sprint 0 / walking skeleton проекта до создания любой пользовательской истории.
