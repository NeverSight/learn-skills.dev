Prepara el Sprint 0 (walking skeleton) de un proyecto a partir de su Tech Design y ADRs - clasifica los ADRs en transversales y de historia, define el mapa de propiedad de rutas por rol, escribe la Definition of Done del esqueleto y propone un plan, y se detiene para aprobación humana. Se utiliza cuando el CLIENTE POTENCIAL (o el usuario) necesita preparar, planificar o inicializar el Sprint 0 /esqueleto andante de un proyecto antes de crear cualquier historia de usuario.
