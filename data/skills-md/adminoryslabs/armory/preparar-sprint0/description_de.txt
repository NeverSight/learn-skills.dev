Prepara el Sprint 0 (walking skeleton) de un proyecto a partir de su Tech Design y ADRs - clasifica los ADRs en transversales y de historia, define el mapa de propiedad de rutas por rol, escribe la Definition of Done del esqueleto y propone un plan, y se detiene para aprobación humana. Wird verwendet, wenn der LEAD (oder der Benutzer) das Sprint 0 /Walking-Skelett eines Projekts vorbereiten, planen oder initialisieren muss, bevor eine User Story erstellt wird.
