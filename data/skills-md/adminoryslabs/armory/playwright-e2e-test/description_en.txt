Writes and runs one Playwright end-to-end test for a single critical user flow (e.g. checkout, booking, sign-up), so the agent can verify its own work in a real browser instead of claiming "it works". Proposes the test plan in plain language first and waits for approval, reuses an existing Playwright setup or installs a minimal one, runs only that spec, and proves the test can actually fail. When the test fails it reports with evidence and never edits the test just to make it pass — the human decides whether the bug is in the app or in the test. Use when the user asks to create an e2e test, a Playwright test, a browser test, or to cover a critical flow with automated QA.
