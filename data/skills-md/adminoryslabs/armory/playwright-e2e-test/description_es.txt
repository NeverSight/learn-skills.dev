Escribe y ejecuta una prueba end‑to‑end con Playwright para un único flujo crítico de usuario (p. ej., checkout, reserva, registro), de modo que el agente pueda verificar su propio trabajo en un navegador real en lugar de afirmar “funciona”. Propone el plan de prueba en lenguaje sencillo primero y espera la aprobación, reutiliza una configuración existente de Playwright o instala una mínima, ejecuta solo esa especificación y demuestra que la prueba puede fallar realmente. Cuando la prueba falla, informa con evidencia y nunca edita la prueba solo para que pase — el humano decide si el error está en la aplicación o en la prueba. Úsalo cuando el usuario solicite crear una prueba e2e, una prueba Playwright, una prueba de navegador o cubrir un flujo crítico con QA automatizada.
