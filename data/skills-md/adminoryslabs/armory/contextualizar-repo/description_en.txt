Contextualiza un repositorio existente (brownfield) para trabajar AI-first sobre él - verifica cómo se arranca y se prueba, crea el índice de CodeGraph, reconstruye el mapa de capas real, documenta las decisiones heredadas como ADR, arma el catálogo de patrones (canon vs. legado), el mapa de deuda y las reglas de construcción verificables, todo con evidencia archivo:línea, y se detiene para aprobación humana. Use when the ARCH role starts on an existing codebase without a PRD, or when asked to contextualize, onboard, document, map or understand a legacy/brownfield repository before working on it.
