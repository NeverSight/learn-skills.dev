Construisez des applications de bureau multiplateformes avec Go + les technologies Web en utilisant Wails v3. Utilisez cette compétence chaque fois que l'utilisateur travaille avec Wails v3 — création d’un nouveau projet, exécution ou compilation de l’application, génération de liaisons TypeScript/JavaScript à partir du code Go, enregistrement de services, utilisation de l’API d’exécution côté frontend (Events, Window, Dialogs, Clipboard, Screens, WML), configuration de l’application, gestion du cycle de vie des services, utilisation de la CLI ou empaquetage pour la distribution. Déclenchez sur toute mention de wails3, wails v3, go desktop app, génération de liaisons, @wailsio/runtime ou enregistrement de service.
