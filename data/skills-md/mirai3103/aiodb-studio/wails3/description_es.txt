Construye aplicaciones de escritorio multiplataforma con Go + tecnologías web usando Wails v3. Utiliza esta habilidad siempre que el usuario esté trabajando con Wails v3 — creando un nuevo proyecto, ejecutando o compilando la aplicación, generando enlaces TypeScript/JavaScript a partir del código Go, registrando servicios, usando la API de tiempo de ejecución del frontend (Eventos, Ventana, Diálogos, Portapapeles, Pantallas, WML), configurando la aplicación, manejando los ciclos de vida de los servicios, usando la CLI o empaquetando para distribución. Activa en cualquier mención de wails3, wails v3, go desktop app, generación de enlaces, @wailsio/runtime o registro de servicios.
