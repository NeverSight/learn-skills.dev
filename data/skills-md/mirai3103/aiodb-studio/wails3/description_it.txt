Crea applicazioni desktop multipiattaforma con Go + tecnologie Web utilizzando Wails v3. Usa questa competenza ogni volta che l'utente lavora con Wails v3 — creando un nuovo progetto, eseguendo o compilando l'app, generando binding TypeScript/JavaScript dal codice Go, registrando i servizi, utilizzando l'API del runtime frontend (Eventi, Finestra, Dialoghi, Appunti, Schermi, WML), configurando l'applicazione, gestendo i cicli di vita dei servizi, usando la CLI o impacchettando per la distribuzione. Attiva su qualsiasi menzione di wails3, wails v3, app desktop go, generazione di binding, @wailsio/runtime o registrazione del servizio.
