プロフェッショナルなアーキテクチャ、ワークフロー、シーケンス、データフロー、ライフサイクル/状態図を、SVG グラフィックスを備えたスタンドアロン HTML ファイルとして作成し、組み込みのダーク/ライト テーマ切り替え機能を備え、ワンクリックで PNG / JPEG / WebP / SVG にエクスポートできます。平易な言語の説明または貼り付けられた Mermaid コード (フローチャート、シーケンスダイアグラム、状態ダイアグラム) を受け入れ、図をアーキファイ スタイルで最初からレイアウトします。ユーザーがシステム アーキテクチャ図、インフラストラクチャ図、クラウド アーキテクチャの視覚化、セキュリティ図、ネットワーク トポロジ、テクニカル ワークフロー、承認フロー、ランブック、CI/CD フロー、プロセス図、API 呼び出しシーケンス、リクエスト ライフサイクル、データ パイプライン、ETL/ELT マップ、PII 境界、データ リネージ、ステート マシン、ライフサイクル図、ステータス遷移を要求する場合、またはマーメイド図の変換/美化を要求する場合に使用します。
