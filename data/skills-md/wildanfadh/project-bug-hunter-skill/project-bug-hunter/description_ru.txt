Этот навык предназначен для широкого поиска багов в текущей рабочей директории и должен срабатывать по таким фразам, как «cari bug di project ini», «cek project ini», «audit bug», «review kode», «temukan error tersembunyi», «scan direktori sekarang», «check this repo for bugs» или аналогичным запросам, даже если пользователь не указывает язык/фреймворк. Сначала он генерирует отчёт о багах, основанный на доказательствах, и не должен изменять файлы, если пользователь явно не попросит их исправить.

Пожалуйста, всегда отвечайте на языке пользователя.
