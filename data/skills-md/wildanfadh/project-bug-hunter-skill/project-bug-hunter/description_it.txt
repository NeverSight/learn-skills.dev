Usa questa abilità ogni volta che l'utente chiede di trovare bug, auditare un progetto, revisionare il codice per difetti, scansionare la directory attualmente aperta, investigare errori nascosti, preparare un progetto prima del deployment o verificare perché un progetto potrebbe fallire. Questa abilità è destinata a una ricerca ampia di bug nell’intera directory di lavoro corrente e dovrebbe attivarsi su frasi come “cari bug di project ini”, “cek project ini”, “audit bug”, “review kode”, “temukan error tersembunyi”, “scan direktori sekarang”, “check this repo for bugs” o richieste simili, anche se l’utente non specifica un linguaggio o framework. Produce prima un rapporto di bug basato su evidenze e non deve modificare i file a meno che l’utente non chieda esplicitamente di sistemarli.

Rispondi sempre nella lingua dell'utente.
