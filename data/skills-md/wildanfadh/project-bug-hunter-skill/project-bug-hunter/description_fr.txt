Utilisez cette compétence chaque fois que l'utilisateur demande de trouver des bugs, d’auditer un projet, de revoir le code pour détecter des défauts, de scanner le répertoire actuellement ouvert, d’enquêter sur des erreurs cachées, de préparer un projet avant le déploiement ou de vérifier pourquoi un projet pourrait échouer. Cette compétence sert à la recherche générale de bugs dans le répertoire de travail actuel et doit se déclencher sur des phrases telles que « cari bug di project ini », « cek project ini », « audit bug », « review kode », « temukan error tersembunyi », « scan direktori sekarang », « check this repo for bugs », ou des demandes similaires même si l'utilisateur ne précise pas de langage ou de framework. Elle génère d’abord un rapport de bugs basé sur des preuves et ne doit pas modifier les fichiers, sauf si l'utilisateur le demande explicitement.  

Veuillez toujours répondre dans la langue de l'utilisateur.
