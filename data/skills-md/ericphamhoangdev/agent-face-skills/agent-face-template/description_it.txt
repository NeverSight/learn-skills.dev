Crea o modifica i tuoi modelli di volto, ovvero le sottocartelle di .agent-face/ nel tuo repository che contengono le immagini degli stati, i fotogrammi della bocca per il lip‑sync e i clip audio. Utilizzali quando l'utente desidera un nuovo volto o un aspetto diverso, nuovi o modificati stati o espressioni, stati animati, una bocca parlante, clip audio aggiunte o il lip‑sync ottimizzato; quando si trasferiscono i modelli dall'app vecchia Agent Face MCP o dalla cartella agent‑face/ della versione 0.1; e ogni volta che il controllo di face.cjs segnala problemi. È necessario avere la skill agent‑face installata accanto.
