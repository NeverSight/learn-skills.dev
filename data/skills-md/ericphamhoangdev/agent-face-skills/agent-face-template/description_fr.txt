Créez ou modifiez vos modèles de visage, c’est‑à‑dire les sous‑dossiers de .agent‑face/ dans votre dépôt qui contiennent les images d’état, les images de bouche pour la synchronisation labiale et les clips audio. Utilisez‑les lorsque l’utilisateur souhaite un nouveau visage ou un autre aspect, de nouveaux états ou expressions, des états animés, une bouche parlante, des clips audio ajoutés ou une synchronisation labiale ajustée ; lors du transfert de modèles depuis l’ancienne application Agent Face MCP ou depuis le dossier agent‑face/ de la version 0.1 ; et chaque fois que le contrôle face.cjs signale des problèmes. Nécessite la compétence agent‑face installée à côté.

Veuillez toujours répondre dans la langue de l’utilisateur.
