Создайте или измените шаблоны лица, то есть подпапки .agent‑face/ в вашем репозитории, где хранятся изображения состояний, кадры губ для синхронизации речи и голосовые клипы. Используйте их, когда пользователь хочет новое лицо или иной внешний вид, новые или изменённые состояния или выражения, анимированные состояния, говорящую пасть, добавленные голосовые клипы или настроенную синхронизацию губ; при переносе шаблонов из старого приложения Agent Face MCP или из папки agent‑face/ версии 0.1; и каждый раз, когда проверка face.cjs сообщает о проблемах. Требуется установленный рядом навык agent‑face.
