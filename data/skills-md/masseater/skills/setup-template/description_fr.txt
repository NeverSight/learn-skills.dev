Synchroniser les paramètres GitHub d’un dépôt créé à partir de masseater/typescript-template à l’aide de gh. Cela sert lorsque vous créez un nouveau dépôt à partir du modèle ou lorsque vous devez ré‑aligner les paramètres GitHub. Cela peut également s’appliquer à d’autres dépôts, mais dans ce cas vous devez confirmer les étapes d’application avec l’utilisateur.
