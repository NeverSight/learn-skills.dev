Настройте параметры GitHub репозитория, созданного из шаблона masseater/typescript-template, с помощью gh. Используйте его, когда создаёте новый репозиторий из шаблона, или когда необходимо переустановить настройки GitHub. Его также можно применять к другим репозиториям, но в этом случае следует подтвердить шаги применения с пользователем.

Пожалуйста, всегда отвечайте на языке пользователя.
