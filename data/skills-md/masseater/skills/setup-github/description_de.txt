Konfigurieren Sie die GitHub-Seite eines Repositorys, das aus dieser Vorlage erstellt wurde, mit gh. Richten Sie die Aktionsgeheimnisse aus, erlauben Sie die PR-Erstellung über Aktionen, legen Sie Einschränkungen fest, wer PRs erstellen und die automatische Zusammenführung aktivieren darf, und standardisieren Sie den Regelsatz für den Standardzweig. Verwenden Sie diese Option, wenn Sie ein neues Repository aus der Vorlage erstellen oder die GitHub-Einstellungen neu konfigurieren.
