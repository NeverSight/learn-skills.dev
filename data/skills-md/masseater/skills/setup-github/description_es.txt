Configure el lado GitHub de un repositorio creado a partir de esta plantilla usando `gh`. Alinee los secretos de las Acciones, el permiso para que las Acciones creen solicitudes de extracción, las restricciones sobre quién puede crear solicitudes de extracción y la fusión automática, y el conjunto de reglas para la rama predeterminada. Utilícelo al crear un nuevo repositorio a partir de la plantilla o al restablecer la configuración de GitHub.
