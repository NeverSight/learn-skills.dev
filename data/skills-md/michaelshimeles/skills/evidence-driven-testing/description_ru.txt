Записывает визуальное доказательство при тестировании поведения UI — агент вручную тестирует приложение через компьютер, пока запись экрана со структурированными аннотациями тестов/утверждений фиксирует сессию — затем размещает видео и сводку результатов в PR и задачу трекера. Используйте, когда изменение требует проверяемых доказательств его работоспособности, вместо текстовых утверждений — включая безголовые среды (скриптовые скриншоты и пробы) и изменения, не связанные с UI (измеренные числа, пары выводов).
