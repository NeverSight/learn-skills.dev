Verbessert iterativ einen PR (GitHub), MR (GitLab) oder ein abgelegtes Changelist (Perforce), bis Greptile ihm eine Bewertung von 5/5 mit null offenen Kommentaren gibt. Löst eine Greptile‑Überprüfung aus, behebt alle umsetzbaren Kommentare, pusht/legt erneut ab, startet die Überprüfung erneut und wiederholt den Vorgang. Verwenden, wenn der Benutzer einen PR/MR/CL vollständig an Greptiles Code‑Review‑Standards optimieren möchte.
