Подключите память агента Redis к существующему агенту с помощью redis‑iris, чтобы он запоминал пользователей между сессиями. Задаёт пять вопросов (что запоминать, что делиться, что никогда не хранить, как долго хранить, можно ли забыть пользователей), записывает ответы в service.yaml, создаёт сервис из терминала командой `iris agent-memory service create`, затем интегрирует восстановление и запись обратно в ход агента в любой фреймворк. Используйте, когда агент забывает пользователей, использует только InMemoryStore или чекпоинтер, хранит память в словаре или локальной БД, либо пользователь запрашивает длительную память, восстановление или право на удаление.
