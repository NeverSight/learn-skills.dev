Intégrez la mémoire d'agent Redis dans un agent existant avec redis-iris afin qu’il se souvienne des utilisateurs d’une session à l’autre. Posez cinq questions (ce qu’il faut mémoriser, ce qu’il faut partager, ce qu’il ne faut jamais conserver, pendant combien de temps le conserver, si les utilisateurs peuvent être oubliés), écrivez les réponses dans service.yaml, provisionnez le service depuis le terminal avec `iris agent-memory service create`, puis branchez le rappel et la réécriture dans le tour de l’agent dans n’importe quel framework. Utilisez‑le lorsque l’agent oublie les utilisateurs, utilise uniquement InMemoryStore ou un point de contrôle, garde la mémoire dans un dict ou une base de données locale, ou que l’utilisateur demande une mémoire à long terme, un rappel ou le droit à l’effacement.
