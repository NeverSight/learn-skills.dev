Redis-iris を使って既存のエージェントに Redis エージェントメモリを組み込み、セッション間でユーザーを記憶させます。5 つの質問（何を記憶するか、何を共有するか、何を絶対に保持しないか、保持期間、ユーザーを忘れることができるか）を行い、回答を service.yaml に書き込み、ターミナルで `iris agent-memory service create` を実行してサービスをプロビジョニングし、任意のフレームワークでエージェントのターンにリコールと書き戻しを接続します。エージェントがユーザーを忘れたり、InMemoryStore やチェックポイントのみを使用したり、メモリを辞書やローカル DB に保持している場合、またはユーザーが長期記憶、リコール、消去権（right‑to‑erasure）を求めたときに使用してください。

常にユーザーの言語で応答してください。
