redis-iris를 사용하여 기존 에이전트에 Redis 에이전트 메모리를 연결하면 세션 간에 사용자를 기억할 수 있습니다. 기억할 내용, 공유할 내용, 절대 보관하지 않을 내용, 보관 기간, 사용자를 잊을 수 있는지 여부의 다섯 가지 질문을 하고, 그 답변을 service.yaml에 기록한 뒤 터미널에서 `iris agent-memory service create` 명령으로 서비스를 프로비저닝합니다. 그런 다음 어떤 프레임워크든 에이전트의 턴에 기억 회수와 쓰기 되돌리기를 연결합니다. 에이전트가 사용자를 잊어버리거나 InMemoryStore 또는 체크포인터만 사용하는 경우, 메모리를 사전이나 로컬 DB에 보관하는 경우, 혹은 사용자가 장기 메모리, 회수, 혹은 삭제 권리를 요청할 때 사용합니다.
