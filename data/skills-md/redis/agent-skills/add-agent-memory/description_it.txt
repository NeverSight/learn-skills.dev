Collega la Memoria dell'Agente Redis a un agente esistente con redis-iris in modo che ricordi gli utenti tra le sessioni. Pone cinque domande (cosa ricordare, cosa condividere, cosa non conservare mai, per quanto tempo conservarlo, se gli utenti possono essere dimenticati), scrive le risposte in service.yaml, provvede al servizio dal terminale con `iris agent-memory service create`, quindi collega il richiamo e la scrittura di ritorno al turno dell’agente in qualsiasi framework. Usalo quando l’agente dimentica gli utenti, utilizza solo InMemoryStore o un checkpointer, conserva la memoria in un dizionario o un DB locale, o l’utente richiede memoria a lungo termine, richiamo o diritto alla cancellazione.
