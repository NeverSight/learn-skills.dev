Conecta la Memoria de Agente Redis a un agente existente con redis-iris para que recuerde a los usuarios entre sesiones. Hace cinco preguntas (qué recordar, qué compartir, qué nunca guardar, cuánto tiempo conservarlo, si los usuarios pueden ser olvidados), escribe las respuestas en service.yaml, provisiona el servicio desde la terminal con `iris agent-memory service create`, y luego enlaza la recuperación y la escritura de vuelta en el turno del agente en cualquier framework. Úsalo cuando el agente olvida a los usuarios, utiliza solo InMemoryStore o un checkpointer, mantiene la memoria en un diccionario o base de datos local, o el usuario solicita memoria a largo plazo, recuperación o el derecho al olvido.
