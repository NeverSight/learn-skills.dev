Verbinde Redis Agent Memory in einen bestehenden Agenten mit redis-iris, damit er sich Benutzer über Sitzungen hinweg merkt. Stellt fünf Fragen (was zu merken ist, was zu teilen, was niemals zu behalten ist, wie lange es zu behalten ist, ob Benutzer vergessen werden können), schreibt die Antworten in service.yaml, stellt den Service über das Terminal mit `iris agent-memory service create` bereit und verknüpft dann das Abrufen und Zurückschreiben in den Turn des Agenten in jedem Framework. Verwende dies, wenn der Agent Benutzer vergisst, nur InMemoryStore oder einen Checkpointer verwendet, das Gedächtnis in einem Dict oder einer lokalen Datenbank speichert oder der Benutzer nach Langzeitgedächtnis, Abruf oder dem Recht auf Vergessen verlangt.
