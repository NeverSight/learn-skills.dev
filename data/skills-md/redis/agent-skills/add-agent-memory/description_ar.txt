قم بربط ذاكرة وكيل Redis إلى وكيل موجود باستخدام redis-iris حتى يتذكر المستخدمين عبر الجلسات. يطرح خمس أسئلة (ما الذي يجب تذكره، ما الذي يجب مشاركته، ما الذي لا يجب الاحتفاظ به أبدًا، مدة الاحتفاظ به، وهل يمكن نسيان المستخدمين)، يكتب الإجابات في ملف service.yaml، يُنشئ الخدمة من الطرفية باستخدام الأمر `iris agent-memory service create`، ثم يربط الاستدعاء وإعادة الكتابة إلى دور الوكيل في أي إطار عمل. استخدم ذلك عندما ينسى الوكيل المستخدمين، أو يستخدم InMemoryStore أو checkpoint فقط، أو يحتفظ بالذاكرة في قاموس أو قاعدة بيانات محلية، أو عندما يطلب المستخدم ذاكرة طويلة الأجل، أو الاستدعاء، أو حق المحو.
