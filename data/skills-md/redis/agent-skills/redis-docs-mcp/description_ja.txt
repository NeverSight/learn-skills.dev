redis-docs MCPサーバー（redis.io/mcp の search / fetch / ask）を活用する — インデックスの形状と返される結果の読み方。これらのツールが利用可能で、Redis ドキュメントを調べようとしているとき、あるいは結果が分かりにくいときに使用します — fetch がページではなく短いセクションだけを返した、複数のヒットが同じ URL を共有している、ID が #sec:w1 のようになっている、metadata.version が 1.0.0 と表示される、検索が空結果だった、あるいは ask がレートリミットされ「ドキュメントに該当しない」と言われた、などの場合です。また、redis.io がインデックスするものとしないものについても説明します。
