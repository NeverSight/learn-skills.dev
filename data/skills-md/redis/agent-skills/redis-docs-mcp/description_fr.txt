Travailler avec le serveur MCP de redis-docs (search / fetch / ask sur redis.io/mcp) — comment son index est structuré et comment lire ce qu’il renvoie. À utiliser lorsque ces outils sont disponibles et que vous êtes sur le point de consulter la documentation Redis, ou lorsqu’un résultat est déroutant — fetch a renvoyé une courte section au lieu d’une page, plusieurs hits partagent la même URL, les identifiants ressemblent à #sec:w1, metadata.version indique 1.0.0, une recherche est revenue vide, ou ask était limité en débit ou indiquait que la documentation ne le couvre pas. Couvre également ce que redis.io indexe et ne indexe pas.
