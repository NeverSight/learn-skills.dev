Trabajando con el servidor MCP de redis‑docs (search / fetch / ask en redis.io/mcp) — cómo está estructurado su índice y cómo leer lo que devuelve. Úsalo cuando esas herramientas estén disponibles y estés a punto de buscar algo en la documentación de Redis, o cuando un resultado sea confuso: fetch devolvió una sección corta en lugar de una página, varios resultados comparten una URL, los IDs parecen #sec:w1, metadata.version muestra 1.0.0, una búsqueda no devolvió resultados, o ask estuvo limitado por tasa o indicó que la documentación no lo cubre. También cubre lo que redis.io indexa y lo que no indexa.
