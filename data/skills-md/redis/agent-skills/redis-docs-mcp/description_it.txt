Lavorare con il server MCP di redis-docs (search / fetch / ask su redis.io/mcp) — come è strutturato il suo indice e come leggere ciò che restituisce. Da usare quando quegli strumenti sono disponibili e stai per cercare qualcosa nella documentazione di Redis, o quando un risultato è confuso — fetch ha restituito una breve sezione anziché una pagina, diversi risultati condividono lo stesso URL, gli ID sembrano #sec:w1, metadata.version mostra 1.0.0, una ricerca è tornata vuota, oppure ask è stato limitato per rate‑limit o ha detto che la documentazione non lo copre. Include anche cosa redis.io indicizza e cosa non indicizza.
