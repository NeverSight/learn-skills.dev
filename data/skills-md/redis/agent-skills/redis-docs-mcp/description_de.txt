Arbeiten mit dem redis-docs MCP‑Server (search / fetch / ask unter redis.io/mcp) – wie sein Index aufgebaut ist und wie man die zurückgegebenen Daten liest. Verwenden, wenn diese Werkzeuge verfügbar sind und man etwas in der Redis‑Dokumentation nachschlagen möchte, oder wenn ein Ergebnis verwirrend ist – fetch hat nur einen kurzen Abschnitt statt einer ganzen Seite zurückgegeben, mehrere Treffer teilen dieselbe URL, IDs sehen aus wie #sec:w1, metadata.version zeigt 1.0.0, eine Suche war leer, oder ask wurde gedrosselt bzw. sagte, die Dokumentation deckt das Thema nicht ab. Enthält außerdem, was redis.io indexiert und was nicht.
