أضف دفاتر تشغيل وكيل Redis Iris إلى وكيل موجود. استخدمها عندما تكون الإجابات المعتمدة أو الإجراءات القابلة للتكرار موجودة في المطالبات أو استرداد المستندات أو ذاكرة التخزين المؤقت للردود الدلالية. اتصل أو وفِّر دفتر تشغيل، وانشر الأسئلة الشائعة والمهارات، وتحقق من أول دورة تطبيق مع مقترحات مراجعة اختيارية.
