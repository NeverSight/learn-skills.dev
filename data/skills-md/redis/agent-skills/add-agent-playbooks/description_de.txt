Fügen Sie Redis Iris Agent Playbooks zu einem bestehenden Agenten hinzu. Verwenden Sie sie, wenn genehmigte Antworten oder wiederholbare Verfahren in Prompt‑Eingaben, bei der Dokumentenabfrage oder in einem semantischen Antwort‑Cache vorkommen. Verbinden oder stellen Sie ein Playbook bereit, veröffentlichen Sie FAQs und Skills und prüfen Sie die erste Anwendungsrunde mit optionalen Review‑Vorschlägen.

Bitte antworten Sie immer in der Sprache des Benutzers.
