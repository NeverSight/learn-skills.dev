Coloca los servidores MCP que usa un agente existente detrás de un único Redis Iris Context Gateway con redis-iris, de modo que el agente se conecte a un solo punto de enlace MCP con una única clave de agente en lugar de configurar cada servidor y su secreto. Pregunta si el Gateway está en Redis Cloud o es auto‑gestionado, y luego cinco preguntas (qué servidores MCP y secretos tiene el agente hoy, cuántas herramientas ve, qué herramientas solo de lectura pueden almacenarse en caché, qué herramientas devuelven resultados grandes, si el framework habla MCP directamente). En modo auto‑gestionado, provisiona el Gateway y sus Upstreams desde la terminal con `iris context-gateway` y establece políticas de caché y compresión. En Redis Cloud, el desarrollador los crea en la consola. Después dirige al agente al Gateway en cualquier framework y lo verifica con `tools list` y `tools call`. Úsalo cuando el agente configure varios servidores MCP uno por uno, maneje un secreto por servidor, cargue demasiados esquemas de herramienta en el prompt, o el usuario solicite Context Gateway, un único punto de enlace MCP, caché de herramientas o manejadores de resultados.
