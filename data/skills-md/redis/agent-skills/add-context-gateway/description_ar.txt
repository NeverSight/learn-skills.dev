ضع خوادم MCP التي يستخدمها عامل موجود خلف بوابة سياق Redis Iris واحدة باستخدام redis-iris، بحيث يتصل العامل بنقطة نهاية MCP واحدة بمفتاح عامل واحد بدلاً من تكوين كل خادم وسريه بشكل منفصل. اسأل ما إذا كانت البوابة في Redis Cloud أم مُدارة ذاتيًا، ثم اطرح خمس أسئلة (ما هي خوادم MCP والأسرار التي يمتلكها العامل اليوم، عدد الأدوات التي يرها، أي الأدوات للقراءة فقط يمكن تخزينها مؤقتًا، أي الأدوات تُرجع نتائج كبيرة، هل الإطار يتحدث MCP نفسه). إذا كانت مُدارة ذاتيًا، يتم توفير البوابة ومصادرها العلوية من الطرفية باستخدام الأمر `iris context-gateway` وتعيين سياسات التخزين المؤقت والضغط. في Redis Cloud ينشئ المطورها عبر لوحة التحكم. بعد ذلك يتم توجيه العامل إلى البوابة في أي إطار والتحقق منها باستخدام `tools list` و `tools call`. يُستخدم هذا عندما يكوّن العامل عدة خوادم MCP واحدة تلو الأخرى، يحمل سراً واحداً لكل خادم، يحمّل الكثير من مخططات الأدوات في الطلب، أو يطلب المستخدم بوابة السياق، نقطة نهاية MCP واحدة، تخزين الأدوات مؤقتًا، أو معالجات النتائج.
