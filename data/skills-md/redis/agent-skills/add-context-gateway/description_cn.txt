把现有代理使用的 MCP 服务器放在一个使用 redis‑iris 的 Redis Iris Context Gateway 后面，这样代理只需使用一个代理密钥连接到一个 MCP 端点，而无需为每个服务器及其密钥单独配置。先询问 Gateway 是在 Redis Cloud 还是自建，然后提出五个问题（当前代理拥有的 MCP 服务器及其密钥、它看到多少工具、哪些只读工具可以被缓存、哪些工具会返回大量结果、框架本身是否支持 MCP）。如果是自建，则通过终端使用 `iris context-gateway` 创建 Gateway 及其上游，并设置缓存和压缩策略。 在 Redis Cloud 中，开发者在控制台中创建它们。随后在任何框架中将代理指向该 Gateway，并通过 `tools list` 和 `tools call` 进行验证。当代理逐个配置多个 MCP 服务器、每个服务器携带一个密钥、向提示中加载了过多工具模式，或用户需要 Context Gateway、单一 MCP 端点、工具缓存或结果句柄时使用。
