Metti i server MCP che un agente esistente utilizza dietro un unico Redis Iris Context Gateway con redis‑iris, così l’agente si connette a un unico endpoint MCP con una sola chiave agente invece di configurare ogni server e il suo segreto. Chiedi se il Gateway è in Redis Cloud o auto‑gestito, poi poni cinque domande (quali server MCP e segreti ha l’agente oggi, quanti tool vede, quali tool read‑only possono essere memorizzati nella cache, quali tool restituiscono risultati di grandi dimensioni, se il framework parla direttamente MCP). In modalità auto‑gestita, provvedi il Gateway e i suoi upstream dal terminale con `iris context-gateway` e imposti le politiche di cache e compressione. In Redis Cloud lo sviluppatore li crea nella console. Poi indirizzi l’agente al Gateway in qualsiasi framework e lo verifichi con `tools list` e `tools call`. Usalo quando l’agente configura diversi server MCP uno per volta, gestisce un segreto per server, carica troppi schemi di tool nel prompt, o l’utente richiede Context Gateway, un unico endpoint MCP, caching dei tool o gestione dei risultati.
