把現有代理使用的 MCP 伺服器放在一個使用 `redis-iris` 的 Redis Iris Context Gateway 後面，讓代理只連接一個 MCP 端點並使用單一代理金鑰，而不必為每個伺服器及其密鑰單獨設定。先詢問 Gateway 是位於 Redis Cloud 還是自行管理，接著問五個問題（目前代理擁有的 MCP 伺服器與密鑰是哪些、它看到多少個工具、哪些唯讀工具可以快取、哪些工具會返回大型結果、框架本身是否支援 MCP）。自行管理時，使用 `iris context-gateway` 從終端機佈署 Gateway 與其上游，並設定快取與壓縮策略。若在 Redis Cloud，開發者則在管理介面中建立。之後將代理指向任何框架中的 Gateway，並透過 `tools list` 與 `tools call` 進行驗證。適用於代理逐一設定多個 MCP 伺服器、每個伺服器攜帶單獨密鑰、將過多工具 schema 載入提示詞，或使用者需求 Context Gateway、單一 MCP 端點、工具快取或結果句柄的情況。
