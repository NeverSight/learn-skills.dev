既存のエージェントが手書きで実装したルーティング（キーワードの if/else チェーン、正規表現、またはルートだけを選択する LLM 呼び出し）を、redis-iris を通じた Redis Iris Intent Router に置き換えます。これにより、メッセージは例示フレーズとスコア閾値に基づいて定義されたインテントとそのディスパッチ先にマッピングされます。まず、次の5つの質問を行います（現在のルートは何か、各ルートに対する実際のフレーズをいくつか、各ルートがディスパッチする先、何もマッチしなかった場合の挙動、使用する埋め込みモデル）。その回答を intents.yaml に書き込み、ターミナルから `iris intent-router service create` でルーターをプロビジョニングし、 `iris intent-router intents add` でインテントをロードします。その後、エージェントが現在決定している箇所に `router.match()` を組み込みます。エージェントがキーワードや余分な LLM 呼び出しでルーティングする場合、またはユーザーがインテント検出、インテントルーティング、あるいはセマンティックルーティングを求めた場合に使用してください。

常にユーザーの言語で回答してください。
