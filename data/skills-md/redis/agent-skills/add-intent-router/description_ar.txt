استبدل توجيه الوكيل المكتوب يدويًا (سلاسل if/else بالكلمات المفتاحية، أو regex، أو استدعاء LLM يختار مسارًا فقط) بـ Redis Iris Intent Router عبر redis‑iris، بحيث تُطابق الرسالة نيةً محددة وهدف توزيعها من خلال عبارات مثال وعَتَبة للدرجة. اسأل خمس أسئلة (ما هي المسارات الحالية، بعض العبارات الحقيقية لكل مسار، إلى أين يوجه كل مسار، ماذا يحدث عندما لا يتطابق شيء، أي نموذج تضمين يُستخدم)، واكتب الإجابات في intents.yaml، ثم أنشئ الـ Router من الطرفية باستخدام `iris intent-router service create`، وحمّل النوايا باستخدام `iris intent-router intents add`، ثم اربط `router.match()` حيث يقرر الوكيل اليوم. استخدمه عندما يوجه الوكيل بال关键词 أو باستدعاء LLM إضافي، أو عندما يطلب المستخدم كشف النية أو توجيه النية أو التوجيه الدلالي.
