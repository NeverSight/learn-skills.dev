Remplacez le routage manuscrit d’un agent existant (chaînes if/else basées sur des mots‑clés, regex ou appel LLM qui ne fait que choisir une route) par un Redis Iris Intent Router via redis‑iris, de façon qu’un message soit mappé à une intention définie et à sa cible de dispatch grâce à des formulations d’exemple et à un seuil de score. Posez cinq questions (quelles sont les routes aujourd’hui, quelques formulations réelles par route, vers quoi chaque route dispatch, que se passe‑t‑il lorsqu’aucune correspondance n’est trouvée, quel modèle d’embedding), écrivez les réponses dans intents.yaml, provisionnez le Router depuis le terminal avec `iris intent-router service create`, chargez les intentions avec `iris intent-router intents add`, puis intégrez `router.match()` à l’endroit où l’agent décide aujourd’hui. Utilisez‑le lorsque l’agent effectue le routage avec des mots‑clés ou un appel LLM supplémentaire, ou lorsque l’utilisateur demande la détection d’intention, le routage d’intention ou le routage sémantique.
