Замените существующую ручную маршрутизацию агента (цепочки if/else на основе ключевых слов, regex или вызов LLM, который лишь выбирает маршрут) на маршрутизатор Redis Iris Intent Router через redis-iris, чтобы сообщение сопоставлялось с определённым интентом и целевым обработчиком по примерам формулировок и порогу оценки. Задайте пять вопросов (каковы текущие маршруты, несколько реальных формулировок для каждого маршрута, куда каждый маршрут направляет, что происходит, если ничего не совпадает, какая модель эмбеддингов), запишите ответы в intents.yaml, создайте сервис маршрутизатора из терминала с помощью `iris intent-router service create`, загрузите интенты командой `iris intent-router intents add`, затем подключите `router.match()` в месте, где сегодня агент принимает решение. Используйте, когда агент маршрутизирует на основе ключевых слов или дополнительного вызова LLM, либо пользователь запрашивает определение интента, маршрутизацию интента или семантическую маршрутизацию.
