Sostituisci il routing scritto a mano di un agente esistente (catene di if/else basate su parole chiave, regex o una chiamata LLM che sceglie solo una rotta) con un Redis Iris Intent Router tramite redis-iris, in modo che un messaggio venga mappato a un intento definito e al suo target di dispatch tramite frasi di esempio e una soglia di punteggio. Fai cinque domande (quali sono le rotte oggi, qualche frase reale per ogni rotta, a cosa invia ciascuna rotta, cosa succede quando nulla corrisponde, quale modello di embedding), scrivi le risposte in intents.yaml, provisiona il Router dal terminale con `iris intent-router service create`, carica gli intenti con `iris intent-router intents add`, poi collega `router.match()` dove l'agente decide oggi. Usa quando l'agente effettua il routing con parole chiave o una chiamata LLM aggiuntiva, o l'utente richiede il rilevamento dell'intento, il routing dell'intento o il routing semantico.
