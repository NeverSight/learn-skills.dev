Ersatz einer handgeschriebenen Routing‑Logik eines bestehenden Agenten (Keyword‑if/else‑Ketten, Regex oder ein LLM‑Aufruf, der nur eine Route auswählt) durch einen Redis Iris Intent Router über redis-iris, sodass eine Nachricht anhand von Beispielphrasen und einem Score‑Schwellenwert einer definierten Intent und ihrem Dispatch‑Ziel zugeordnet wird. Stelle fünf Fragen (was die aktuellen Routen sind, ein paar echte Formulierungen pro Route, was jede Route dispatcht, was passiert, wenn nichts passt, welches Embedding‑Modell verwendet wird), schreibe die Antworten in intents.yaml, provisioniere den Router über das Terminal mit `iris intent-router service create`, lade die Intents mit `iris intent-router intents add` und binde dann `router.match()` dort ein, wo der Agent heute entscheidet. Verwende dies, wenn der Agent mit Keywords oder einem zusätzlichen LLM‑Aufruf routet oder der Benutzer nach Intent‑Erkennung, Intent‑Routing oder semantischem Routing fragt.
