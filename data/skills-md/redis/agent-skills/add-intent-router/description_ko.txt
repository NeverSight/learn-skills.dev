기존 에이전트의 수동 라우팅(키워드 if/else 체인, 정규식, 혹은 라우트만 선택하는 LLM 호출)을 redis-iris를 통한 Redis Iris Intent Router로 교체하여, 메시지가 예시 구문과 점수 임계값을 통해 정의된 인텐트와 그 디스패치 대상에 매핑되도록 합니다. 다섯 가지 질문을 합니다(현재 라우트가 무엇인지, 라우트당 몇 개의 실제 구문, 각 라우트가 디스패치하는 대상, 매칭되지 않을 경우 어떻게 되는지, 어떤 임베딩 모델을 사용할지). 답변을 intents.yaml에 기록하고, 터미널에서 `iris intent-router service create`로 라우터를 프로비저닝하며, `iris intent-router intents add`로 인텐트를 로드합니다. 그런 다음 에이전트가 현재 결정하는 부분에 `router.match()`를 연결합니다. 에이전트가 키워드나 추가 LLM 호출로 라우팅할 때, 혹은 사용자가 인텐트 감지, 인텐트 라우팅, 혹은 의미 기반 라우팅을 요청할 때 사용합니다.
