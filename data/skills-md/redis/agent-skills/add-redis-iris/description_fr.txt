Ajoutez Redis Iris à un agent IA existant dans n'importe quel framework (LangGraph, LangChain, OpenAI Agents SDK, Google ADK, Pydantic AI, CrewAI ou une boucle simple). Utilisez-le lorsque l'utilisateur demande d'ajouter Iris, Redis Agent Memory, Agent Playbooks, Context Gateway, Intent Router ou Lens à son agent, ou demande quel produit Iris son agent nécessite. Détecte le framework et le redirige vers la compétence produit. Veuillez toujours répondre dans la langue de l'utilisateur.
