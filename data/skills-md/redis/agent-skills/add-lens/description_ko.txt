redis-iris를 통해 기존 AI 에이전트에 Redis Iris Lens 트레이싱을 추가하여, 에이전트의 각 턴이 Lens UI에서 LLM 호출, 토큰, 툴 호출, 메모리 및 문서 검색, 그리고 프롬프트에 입력된 항목들을 포함한 하나의 트레이스로 표시되도록 합니다. 에이전트가 어떻게 실행되는지(LangGraph 또는 ADK attach, workflows.turn, 다른 프레임워크, 혹은 단순 루프)를 감지하고, redis-iris[llm-tracing]을 설치하며, lens.init(agent_id=…)를 호출하고, Iris가 아직 열지 않은 경우 각 턴마다 lens.turn()를 하나씩 엽니다. 또한 애플리케이션이 이미 가지고 있는 OpenTelemetry 설정이나 LLM 계측과의 공존도 지원합니다. 사용자가 Lens, 트레이싱, 가시성 또는 턴별 트레이스를 에이전트에 추가하고 싶다고 요청하거나, Lens 트레이스가 누락된 이유를 물을 때 사용합니다. 항상 사용자의 언어로 응답하십시오.
