أضف تتبع Redis Iris Lens إلى وكيل AI موجود عبر redis-iris، بحيث يكون كل دور للوكيل بمثابة تتبع واحد في واجهة Lens مع استدعاءات LLM الخاصة به، والرموز، واستدعاءات الأدوات، والذاكرة، واسترجاع المستندات، وأي منها تم إدخاله في النص. يكتشف طريقة تشغيل الوكيل (LangGraph أو ADK attach، workflows.turn، إطار عمل آخر، أو حلقة عادية)، يثبت redis-iris[llm-tracing]، يستدعي lens.init(agent_id=...)، يفتح lens.turn() واحدًا لكل دور في حال لم يفتحه Iris بالفعل، ويغطي التعايش مع إعداد OpenTelemetry أو أدوات تتبع LLM التي يمتلكها التطبيق مسبقًا. يُستخدم عندما يطلب المستخدم إضافة Lens أو التتبع أو المراقبة أو تتبع كل دور إلى وكيله، أو عندما يسأل لماذا تتبعاته في Lens مفقودة.
