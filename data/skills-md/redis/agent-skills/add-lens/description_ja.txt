redis-iris を介して既存の AI エージェントに Redis Iris Lens のトレーシングを追加し、エージェントの各ターンを Lens UI で 1 つのトレースとして表示し、LLM 呼び出し、トークン、ツール呼び出し、メモリ、ドキュメント取得、そしてそれらのどれがプロンプトに入ったかを示します。エージェントの実行方法（LangGraph または ADK attach、workflows.turn、他のフレームワーク、あるいは単純なループ）を検出し、redis-iris[llm-tracing] をインストールし、lens.init(agent_id=…) を呼び出し、Iris がまだ開いていない場合は各ターンで lens.turn() を 1 回開き、OpenTelemetry の設定やアプリがすでに持っている LLM 計測との共存もカバーします。ユーザーがエージェントに Lens、トレーシング、可観測性、またはターンごとのトレースの追加を求めたとき、または Lens のトレースが欠落している理由を尋ねたときに使用してください。
