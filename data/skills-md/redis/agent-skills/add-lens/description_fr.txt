Ajoutez le traçage Redis Iris Lens à un agent IA existant via redis-iris, de sorte que chaque tour d'agent soit une trace dans l'interface Lens avec ses appels LLM, jetons, appels d’outils, mémoires et récupérations de documents, et indique lequel d’entre eux a été intégré dans le prompt. Détecte comment l’agent s’exécute (LangGraph ou ADK attach, workflows.turn, un autre framework ou une simple boucle), installe redis-iris[llm-tracing], appelle lens.init(agent_id=…), ouvre un lens.turn() par tour lorsque Iris ne l’a pas déjà ouvert, et couvre la coexistence avec une configuration OpenTelemetry ou une instrumentation LLM déjà présente dans l’application. Utilisez ceci lorsque l’utilisateur demande d’ajouter Lens, du traçage, de l’observabilité ou des traces par tour à son agent, ou demande pourquoi ses traces Lens manquent.
