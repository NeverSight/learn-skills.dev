Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザーを `orca` CLI で操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関与する場合は、生の git worktree やアドホック PTY、Computer Use よりもこちらを優先してください。CLI、ファイルシステム、API では対処できない可視ウィンドウが必要な GUI 操作がある場合にのみ Computer Use を使用します。

常にユーザーの言語で応答してください。
