قم بتشغيل شجرات العمل التي يديرها Orca وسياقات المجلدات والطرفيات والمستودعات والأتمتة والقطع الفنية ومشاركة المهارات وتعليقات شجرة العمل والمتصفح المدمج في Orca عبر واجهة الأوامر `orca`. استخدمها عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّلها على شجرة Git العادية أو PTYs العارضة أو استخدام الكمبيوتر عندما تكون حالة Orca متضمنة. استخدم "Computer Use" فقط عندما تحتاج نافذة مرئية إلى التحكم الرسومي الذي لا يستطيع سطر الأوامر أو نظام الملفات أو واجهة برمجة التطبيقات توفيره. يرجى دائماً الرد بلغة المستخدم.
