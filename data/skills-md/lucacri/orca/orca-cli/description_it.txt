Gestire worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser incorporato di Orca tramite la CLI `orca`. Utilizzare quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff”/“handover”/“give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferirla rispetto a un worktree Git grezzo, PTY ad hoc o Uso del Computer quando è coinvolto lo stato di Orca. Usare Uso del Computer solo quando una finestra visibile richiede il controllo GUI che una CLI, il file system o un'API non possono gestire.

Rispondi sempre nella lingua dell'utente.
