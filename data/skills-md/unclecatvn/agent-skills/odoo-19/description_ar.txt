قاعدة معرفة تطوير Odoo 19 مع 18 دليلًا متخصصًا تغطي الإجراءات (ir.actions.*، وظائف الكرون، إجراءات الخادم)، المتحكمات (توجيه HTTP، نقاط النهاية، أنواع المصادقة)، ملفات البيانات (سجلات XML/CSV، الاختصارات، noupdate)، مزخرات API (@api.depends، @api.constrains، @api.ondelete، @api.onchange، @api.model، @api.private)، قيود SQL (models.Constraint بدلاً من _sql_constraints)، فهارس قاعدة البيانات (models.Index)، تطوير الوحدات (المانيفست، المعالجون، التقارير)، أنواع الحقول (Char، Text، Monetary، الحقول العلائقية)، تكوين المانيفست (__manifest__.py، الاعتماديات، حزم الأصول)، الخلطات (mail.thread، mail.activity.mixin، mail.alias.mixin، utm.mixin)، طرق نموذج ORM (search، CRUD، مرشحات النطاق، مجموعات السجلات، تسمية النموذج بصيغة CamelCase)، سكريبتات الهجرة (خطاطيف pre/post/end، هجرة البيانات)، مكونات الواجهة الأمامية OWL (خطاطيف، خدمات، دورة الحياة)، تحسين الأداء (منع N+1، عمليات الدفعات، _read_group)، تقارير QWeb (PDF/HTML، تنسيقات الورق، الباركود، t-out)، الأمان/ACL (قواعد السجلات، أذونات الحقول، مجموعات مبنية على الامتيازات، @api.private)، الاختبار (TransactionCase، HttpCase، محاكاة، تأكيدات عدد الاستعلامات)، المعاملات (نقاط الحفظ، UniqueViolation، فشل التسلسل)، الترجمات (i18n، ملفات PO، الحقول القابلة للترجمة)، عروض XML (قائمة/نموذج/بحث، قوالب بطاقات كانبان، وراثة xpath، قوالب QWeb). استخدمها عند كتابة أو مراجعة أو تصحيح أي كود Python أو XML في Odoo 19، أو إنشاء أو تعديل الوحدات، أو إصلاح مشكلات الأداء، أو البحث عن أنماط API في Odoo 19 وأفضل الممارسات. تشمل تأليف ومراجعة أصول CSS/SCSS للإضافات في Odoo.
