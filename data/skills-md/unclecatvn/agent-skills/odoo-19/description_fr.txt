Base de connaissances du développement Odoo 19 avec 18 guides spécialisés couvrant les Actions (ir.actions.*, jobs cron, actions serveur), Contrôleurs (routage HTTP, points de terminaison, types d’authentification), Fichiers de données (enregistrements XML/CSV, raccourcis, noupdate), Décorateurs API (@api.depends, @api.constrains, @api.ondelete, @api.onchange, @api.model, @api.private), Contraintes SQL (models.Constraint remplaçant _sql_constraints), Index de base de données (models.Index), Développement de modules (manifest, assistants, rapports), Types de champs (Char, Text, Monetary, champs relationnels), Configuration du manifest (__manifest__.py, dépendances, bundles d’actifs), Mixins (mail.thread, mail.activity.mixin, mail.alias.mixin, utm.mixin), Méthodes du modèle ORM (search, CRUD, filtres de domaine, recordsets, nommage CamelCase des modèles), Scripts de migration (hooks pre/post/end, migration de données), Composants frontend OWL (hooks, services, cycle de vie), Optimisation des performances (prévention du N+1, opérations en lot, _read_group), Rapports QWeb (PDF/HTML, formats papier, codes‑barres, t‑out), Sécurité/ACL (règles d’enregistrement, permissions de champ, groupes basés sur les privilèges, @api.private), Tests (TransactionCase, HttpCase, mock, assertions du nombre de requêtes), Transactions (points de sauvegarde, UniqueViolation, échecs de sérialisation), Traductions (i18n, fichiers PO, champs traduisibles), Vues XML (liste/formulaire/recherche, modèles de cartes kanban, héritage xpath, modèles QWeb). À utiliser lors de la rédaction, de la révision ou du débogage de tout code Python ou XML Odoo 19, de la création ou modification de modules, de la résolution de problèmes de performance, ou de la recherche de modèles d’API Odoo 19 et des meilleures pratiques. Inclut la création et la révision d’actifs CSS/SCSS pour les modules Odoo.
