Compruebe un modelo TLA+ de un sistema que se desplaza entre estados, como un flujo de producto, un protocolo o un servicio, y dibújelo como un diagrama de estados Mermaid. El informe proporciona la ruta más corta a cada estado que infringe una regla. Úselo para /statechart, o para mostrar un error como una ruta a través de los estados.
