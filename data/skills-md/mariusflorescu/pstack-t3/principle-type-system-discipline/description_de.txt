Anwenden beim Entwerfen von Typen, beim Prüfen einer Funktionssignatur oder beim Schreiben von Code in einer beliebigen statisch typisierten Sprache. Illegale Zustände nicht darstellbar machen, semantische Primitive kennzeichnen, externe Daten an den Schnittstellen parsen, dem Compiler nicht widersprechen, Varianten vollständig ausschöpfen, aus autoritativen Schemata ableiten.
