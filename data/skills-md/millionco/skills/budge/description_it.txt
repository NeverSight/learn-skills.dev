Usalo quando apporti modifiche visive a singole proprietà CSS o utility Tailwind nei progetti Next.js con App Router. Presenta un widget di controllo fluttuante sulla pagina in modo che l'utente possa regolare il valore prima che venga salvato. Copre modifiche di stile atomiche, anteprima in tempo reale e pulizia. Si attiva su modifiche di un singolo valore CSS o di una singola classe utility Tailwind.
