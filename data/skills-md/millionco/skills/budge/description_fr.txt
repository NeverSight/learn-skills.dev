Utilisez-le lors de modifications visuelles d’une seule propriété CSS ou d’une classe utilitaire Tailwind dans les projets Next.js avec le routeur d’application. Il présente un widget de contrôle flottant sur la page afin que l’utilisateur puisse ajuster la valeur avant qu’elle ne soit persistée. Il couvre les changements de style atomiques, l’aperçu en direct et le nettoyage. Il se déclenche sur la modification d’une seule valeur CSS ou d’une seule classe utilitaire Tailwind.
