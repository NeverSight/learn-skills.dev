Используйте при внесении однопараметрических изменений CSS или визуальных правок Tailwind в проектах Next.js с App Router. На странице отображается плавающий виджет управления, позволяющий пользователю отрегулировать значение перед его сохранением. Охватывает атомарные изменения стилей, живой предварительный просмотр и очистку. Срабатывает при изменении одного значения CSS или одного класса‑утилиты Tailwind.
