تشغيل الأشجار العاملة التي يديرها Orca، وسياقات المجلدات، والطوابير الطرفية، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات الأشجار العاملة، والمتصفح المدمج في Orca عبر واجهة الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضلها على استخدام git worktree الخام أو PTYs المخصصة أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية ولا يمكن للواجهة النصية أو نظام الملفات أو API القيام بذلك. يرجى دائمًا الرد بلغة المستخدم.
