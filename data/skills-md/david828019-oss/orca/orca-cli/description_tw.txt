通過 `orca` CLI 操作 Orca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、構件、技能共享、工作樹註釋，以及 Orca 內建瀏覽器。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時即使用。涉及 Orca 狀態時，優先使用此方式而非純 git 工作樹、臨時 PTY 或電腦使用。僅在需要可見視窗且 CLI、檔案系統或 API 無法控制的 GUI 操作時，才使用電腦使用。
