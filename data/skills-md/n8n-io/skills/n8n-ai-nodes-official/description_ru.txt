Используйте при построении или редактировании ИИ внутри рабочего процесса n8n: узел AI Agent, Text Classifier, Information Extractor, Sentiment Analysis, Summarization Chain, Basic LLM Chain, embeddings, vector stores, однократные (one‑shot) вызовы LLM, а также генерацию медиа‑контента ИИ (изображения / аудио / видео) через нативные провайдерные узлы LangChain. Также когда полноценный n8n Agent не справляется: данные триггера, точно сопоставленные с параметрами инструмента, или память, общая между рабочими процессами. Триггеры на любом узле `@n8n/n8n-nodes-langchain.*`, «AI Agent node», «LLM with tools», «tool calling», «fromAi», «system prompt», «memory window», «structured output», «outputParser», «RAG», «vector store», «embeddings», «classify with AI», «extract fields with LLM», «sentiment analysis», «summarize with LLM», «single LLM call», чат‑триггеры с файлами, рабочие процессы ботов Slack / Discord / Teams / Telegram, генерацию изображений / видео / аудио ИИ, либо любой многократный или однократный шаг LLM в рабочем процессе.
