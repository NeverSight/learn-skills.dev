استخدم عند بناء أو تعديل الذكاء الاصطناعي داخل سير عمل n8n: عقدة وكيل الذكاء الاصطناعي، المصنف النصي، مستخرج المعلومات، تحليل المشاعر، سلسلة التلخيص، سلسلة LLM الأساسية، التضمينات، مخازن المتجهات، مكالمة LLM واحدة، أو توليد وسائط الذكاء الاصطناعي (صورة / صوت / فيديو) عبر عقد موفر LangChain الأصلية. أيضاً عندما لا يستطيع وكيل n8n من الدرجة الأولى إنجاز المهمة: تشغيل البيانات التي تُطابق تمامًا معلمات الأدوات، أو الذاكرة المشتركة عبر سير العمل. يتم تشغيله على أي عقدة `@n8n/n8n-nodes-langchain.*`، "عقدة وكيل الذكاء الاصطناعي"، "LLM مع الأدوات"، "استدعاء الأداة"، "fromAi"، "موجه النظام"، "نافذة الذاكرة"، "الإخراج المهيكل"، "outputParser"، "RAG"، "متجر المتجهات"، "التضمينات"، "التصنيف بالذكاء الاصطناعي"، "استخراج الحقول بالـ LLM"، "تحليل المشاعر"، "تلخيص بالـ LLM"، "مكالمة LLM واحدة"، مشغلات الدردشة مع الملفات، سير عمل بوتات Slack / Discord / Teams / Telegram، توليد صورة / فيديو / صوت بالذكاء الاصطناعي، أو أي خطوة LLM متعددة الجولات أو ذات مرة واحدة في سير العمل.
