Utilisez‑le lors de la création ou de la modification d’IA dans un workflow n8n : le nœud AI Agent, le classificateur de texte, l’extracteur d’informations, l’analyse de sentiment, la chaîne de résumé, la chaîne LLM de base, les embeddings, les magasins de vecteurs, les appels LLM ponctuels (one‑shot) ou la génération de médias IA (image / audio / vidéo) via les nœuds natifs du fournisseur LangChain. Aussi lorsque qu’un agent n8n de première classe ne peut pas accomplir la tâche : données de déclenchement mappées exactement sur les paramètres d’outil, ou mémoire partagée entre workflows. Déclencheurs sur n’importe quel nœud `@n8n/n8n-nodes-langchain.*`, « AI Agent node », « LLM with tools », « tool calling », « fromAi », « system prompt », « memory window », « structured output », « outputParser », « RAG », « vector store », « embeddings », « classify with AI », « extract fields with LLM », « sentiment analysis », « summarize with LLM », « single LLM call », déclencheurs de chat avec fichiers, workflows de bots Slack / Discord / Teams / Telegram, génération d’image / vidéo / audio IA, ou toute étape LLM multi‑tour ou ponctuelle dans un workflow. Veuillez toujours répondre dans la langue de l’utilisateur.
