Construye interfaces web con React usando la colección web de PanelUI: agrega sus componentes desde el registro shadcn o desde npm, coloreándolos con el tema y combinándolos en paneles enmarcados. Se aplica al trabajar en un proyecto React que tenga shadcn/ui configurado con un registro @panelui o tenga panelui-web instalado, cuando el usuario menciona PanelUI en la web, o cuando solicite un globo punteado, una tarjeta KPI, un tablero kanban, un grafo de nodos, una cuadrícula de actividades o un cuadro de diálogo de retroalimentación en React.
