Crea interfacce web React con la collezione web di PanelUI — aggiungendo i suoi componenti dal registro shadcn o da npm, colorandoli secondo il tema e componendoli in pannelli incorniciati. Si applica quando si lavora in un progetto React che ha shadcn/ui configurato con un registro @panelui o ha installato panelui‑web, quando l’utente menziona PanelUI sul web, o quando richiede un globo punteggiato, una scheda KPI, una board kanban, un grafo di nodi, una griglia di attività o una finestra di dialogo di feedback in React.
