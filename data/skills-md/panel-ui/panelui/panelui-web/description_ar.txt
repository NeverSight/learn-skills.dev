بناء واجهات ويب React باستخدام مجموعة الويب الخاصة بـ PanelUI — بإضافة مكوّناتها من سجل shadcn أو من npm، وتلوينها وفقًا للثيم، وتجميعها في لوحات مؤطَّرة. ينطبق ذلك عند العمل في مشروع React يحتوي على shadcn/ui مُعد مع سجل @panelui أو مثبت فيه panelui‑web، وعند ذكر المستخدم لـ PanelUI على الويب، أو عندما يطلب كرة نقطية، بطاقة KPI، لوحة كانبان، رسم بياني للعقد، شبكة نشاط أو حوار ملاحظات في React.
