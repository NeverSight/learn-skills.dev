Construisez des interfaces web React avec la collection web de PanelUI — en ajoutant ses composants depuis le registre shadcn ou depuis npm, en les colorant selon le thème, et en les composant en panneaux encadrés. S'applique lorsque vous travaillez dans un projet React qui a shadcn/ui configuré avec un registre @panelui ou qui a panelui-web installé, lorsque l'utilisateur mentionne PanelUI sur le web, ou lorsqu'il demande un globe pointillé, une carte KPI, un tableau Kanban, un graphe de nœuds, une grille d'activité ou une boîte de dialogue de feedback en React.
