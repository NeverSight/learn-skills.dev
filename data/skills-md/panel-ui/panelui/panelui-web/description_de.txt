Erstelle React-Web-UIs mit der Web‑Sammlung von PanelUI – indem du seine Komponenten aus dem shadcn‑Register oder von npm hinzufügst, sie aus dem Theme färbst und zu gerahmten Panels zusammensetzt. Gilt, wenn du in einem React‑Projekt arbeitest, das shadcn/ui mit einem @panelui‑Register eingerichtet hat oder panelui-web installiert ist, wenn der Nutzer PanelUI im Web erwähnt oder wenn er nach einem gepunkteten Globus, einer KPI‑Karte, einem Kanban‑Board, einem Knotendiagramm, einem Aktivitätsraster oder einem Feedback‑Dialog in React fragt. Bitte antworte immer in der Sprache des Nutzers.
