PanelUI の Web コレクションを使用して React の Web UI を構築します — コンポーネントは shadcn レジストリまたは npm から追加し、テーマで色付けし、フレーム化されたパネルに組み立てます。shadcn/ui が @panelui レジストリで設定されている、または panelui-web がインストールされている React プロジェクトで作業している場合、ユーザーが Web 上で PanelUI に言及したとき、または React で点線の地球儀、KPI カード、カンバンボード、ノードグラフ、アクティビティグリッド、フィードバックダイアログを求めたときに適用されます。
