Охватывает стеки шрифтов TextMeshPro, динамические резервные атласы, коэффициенты заполнения и выборки, SDF16, дисциплину AutoSize, мировое пространство и UGUI и захват данных шрифтов Memory Profiler. Используйте, когда пользователь упоминает TextMeshPro, Text Mesh Pro, TMP (TextMeshPro), ресурс шрифта, динамический атлас, локализацию TMP, шрифты CJK (китайский, японский, корейский), выравнивание шрифтов по сценариям, смешанные западные и восточные шрифты, производительность рендеринга текста, маркеры профилировщика, связанные с генерацией текста или растеризацией глифов, стратегию резервного шрифта, нормализацию шрифта, многоязычный или локализованный рендеринг текста, качество шрифта SDF или память, связанную с текстом. проблемы — не для макета UI Toolkit (unity-ui-toolkit) или uGUI, отличного от TMP (unity-ui).
