يغطي مجموعات خطوط TextMeshPro، والأطالس الاحتياطية الديناميكية، ونسب الحشو وأخذ العينات، وSDF16، ونظام AutoSize، وworldspace مقابل UGUI، والتقاط بيانات خط Memory Profiler. يُستخدم عندما يذكر المستخدم TextMeshPro، أو Text Mesh Pro، أو TMP (TextMeshPro)، أو أصل الخط، أو الأطلس الديناميكي، أو توطين TMP، أو خطوط CJK (الصينية واليابانية والكورية)، ومحاذاة الخط عبر البرامج النصية، والخطوط الغربية والشرقية المختلطة، وأداء عرض النص، وعلامات ملفات التعريف المتعلقة بإنشاء النص أو تنقيط الحروف الرسومية، أو إستراتيجية الخط الاحتياطي، أو تسوية الخط، أو عرض النص متعدد اللغات أو المترجم، أو جودة خط SDF، أو مشكلات الذاكرة المتعلقة بالنص - لا لتخطيط مجموعة أدوات واجهة المستخدم (unity-ui-toolkit) أو غير TMP uGUI (unity-ui).
