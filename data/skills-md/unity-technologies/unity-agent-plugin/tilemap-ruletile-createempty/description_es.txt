Crea un recurso RuleTile vacío sin entradas de Sprite o Spritesheet. Úselo SÓLO cuando el usuario desee un RuleTile, HexagonalRuleTile o IsometricRuleTile en blanco para la configuración de reglas personalizadas Y no haya proporcionado ni hecho referencia a ningún sprite. Si el usuario menciona sprites existentes, arte del terreno, mosaicos de borde o una carpeta de mosaicos, use en su lugar Tilemap-ruletile-createfromsegment, nunca esta habilidad.
