Génère des requêtes Unity Search / Quick Search et ouvre la fenêtre Unity Search pour des requêtes de consultation en lecture seule d’actifs ou d’objets de scène dans l’éditeur Unity. Utilisez-le toujours lorsque l’utilisateur demande de trouver, rechercher, afficher, localiser, filtrer, consulter, interroger ou lister des actifs concrets ou des objets de scène dans le projet ou la scène en cours, même si Unity Search n’est pas mentionné. Couvre les matériaux, textures, préfabriqués, scènes, scripts, shaders, GameObjects, composants, lumières, caméras, objets UI, libellés, chemins, références, actifs sélectionnés ou nommés, et types d’actifs. Utilisez-le également lorsque l’utilisateur mentionne explicitement Unity Search, Quick Search, fenêtre de recherche, ouvrir la recherche, ou demande quelle requête Unity Search utiliser. Ne l’utilisez pas pour une vue d’ensemble générale du projet, la structure du projet, les résumés d’usage des dossiers, les explications de gameplay/système, les questions de programmation, la recherche sur le web, la recherche de texte dans le dépôt, les journaux de compilation, l’installation de paquets, la recherche de menus ou de paramètres, la modification des résultats, ou la recherche dans le système de fichiers non Unity, sauf si l’utilisateur demande explicitement d’utiliser Unity Search.
