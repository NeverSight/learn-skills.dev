Génère des requêtes Unity Search / Quick Search et ouvre la fenêtre Unity Search pour les demandes de recherche d'actifs ou d'objets de scène en lecture seule de Unity Editor. À toujours utiliser lorsque l'utilisateur demande à rechercher, rechercher, afficher, localiser, filtrer, rechercher, interroger ou répertorier des ressources concrètes ou des objets de scène dans le projet ou la scène en cours, même si Unity Search n'est pas nommé. Couvre les matériaux, les textures, les préfabriqués, les scènes, les scripts, les shaders, les GameObjects, les composants, les lumières, les caméras, les objets de l'interface utilisateur, les étiquettes, les chemins, les références, les actifs sélectionnés ou nommés et les types d'actifs. À utiliser également lorsque l'utilisateur mentionne explicitement Unity Search, Quick Search, la fenêtre de recherche, ouvre la recherche ou demande quelle requête Unity Search utiliser. Ne pas utiliser pour la présentation générale du projet, la structure du projet, les résumés des dossiers, les explications du gameplay/système, les questions pratiques sur la programmation, la recherche sur le Web, la recherche de texte dans le référentiel, les journaux de construction, l'installation de packages, la recherche de menus ou de paramètres, la modification des résultats ou la recherche de systèmes de fichiers non-Unity, sauf si l'utilisateur demande explicitement d'utiliser Unity Search.
