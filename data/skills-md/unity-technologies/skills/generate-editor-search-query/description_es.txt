Genera consultas de Unity Search/Quick Search y abre la ventana de Unity Search para solicitudes de búsqueda de objetos de escena o activos de Unity Editor de solo lectura. Úselo siempre cuando el usuario solicite buscar, mostrar, ubicar, filtrar, buscar, consultar o enumerar recursos concretos u objetos de escena en el proyecto o escena actual, incluso si Unity Search no tiene nombre. Cubre materiales, texturas, prefabricados, escenas, scripts, sombreadores, GameObjects, componentes, luces, cámaras, objetos de interfaz de usuario, etiquetas, rutas, referencias, activos seleccionados o con nombre y tipos de activos. Úselo también cuando el usuario mencione explícitamente Unity Search, Búsqueda rápida, ventana de búsqueda, abra la Búsqueda o pregunte qué consulta de Unity Search usar. No lo use para descripción general del proyecto, estructura del proyecto, resúmenes del propósito de las carpetas, explicaciones del juego/sistema, preguntas prácticas de programación, búsqueda web, búsqueda de texto en el repositorio, registros de compilación, instalación de paquetes, búsqueda de menús o configuraciones, modificación de resultados o búsqueda en sistemas de archivos que no sean de Unity, a menos que el usuario solicite explícitamente usar Unity Search.
