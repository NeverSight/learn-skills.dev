Genera query Unity Search/Ricerca rapida e apre la finestra Unity Search per le richieste di sola lettura di risorse Unity Editor o di ricerca di oggetti scena. Da utilizzare sempre quando l'utente chiede di trovare, cercare, mostrare, individuare, filtrare, cercare, eseguire query o elencare risorse concrete o oggetti della scena nel progetto o nella scena corrente, anche se Unity Search non è nominato. Copre materiali, trame, prefabbricati, scene, script, shader, GameObject, componenti, luci, telecamere, oggetti dell'interfaccia utente, etichette, percorsi, riferimenti, risorse selezionate o denominate e tipi di risorse. Da utilizzare anche quando l'utente menziona esplicitamente Unity Search, Ricerca rapida, finestra di ricerca, ricerca aperta o chiede quale query Unity Search utilizzare. Non utilizzare per una panoramica generale del progetto, la struttura del progetto, i riepiloghi sullo scopo delle cartelle, le spiegazioni sul gameplay/sistema, le domande sulla programmazione, la ricerca sul Web, la ricerca di testo nel repository, i registri di creazione, l'installazione di pacchetti, la ricerca di menu o impostazioni, la modifica dei risultati o la ricerca di file system non Unity a meno che l'utente non chieda esplicitamente di utilizzare Unity Search.
