Генерирует запросы Unity Search/Quick Search и открывает окно Unity Search для запросов на поиск ресурсов Unity Editor или объектов сцены только для чтения. Всегда используйте, когда пользователь просит найти, найти, отобразить, отфильтровать, найти, запросить или составить список конкретных ресурсов или объектов сцены в текущем проекте или сцене, даже если Unity Search не назван. Охватывает материалы, текстуры, префабы, сцены, сценарии, шейдеры, игровые объекты, компоненты, источники света, камеры, объекты пользовательского интерфейса, метки, пути, ссылки, выбранные или именованные ресурсы и типы ресурсов. Также используйте, когда пользователь явно упоминает Unity Search, Quick Search, окно поиска, открытый поиск или спрашивает, какой запрос Unity Search использовать. Не используйте для общего обзора проекта, структуры проекта, сводки назначения папок, объяснений игрового процесса/системы, вопросов по программированию, веб-поиска, текстового поиска в репозитории, журналов сборки, установки пакетов, поиска меню или настроек, изменения результатов или поиска в файловой системе, отличной от Unity, если пользователь явно не просит использовать Unity Search.
