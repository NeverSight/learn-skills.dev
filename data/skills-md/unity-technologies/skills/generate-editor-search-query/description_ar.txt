يُنشئ استعلامات Unity Search / Quick Search ويفتح نافذة Unity Search لطلبات البحث عن أصول Unity Editor أو كائنات المشهد للقراءة فقط. يُستخدم دائمًا عندما يطلب المستخدم البحث عن الأصول الملموسة أو كائنات المشهد أو البحث عنها أو إظهارها أو تحديد موقعها أو تصفيتها أو البحث عنها أو الاستعلام عنها أو إدراجها في المشروع أو المشهد الحالي، حتى إذا لم يتم تسمية Unity Search. يغطي المواد، والأنسجة، والمباني الجاهزة، والمشاهد، والبرامج النصية، والتظليلات، وكائنات الألعاب، والمكونات، والأضواء، والكاميرات، وكائنات واجهة المستخدم، والتسميات، والمسارات، والمراجع، والأصول المحددة أو المسماة، وأنواع الأصول. استخدمه أيضًا عندما يذكر المستخدم صراحةً Unity Search أو البحث السريع أو نافذة البحث أو فتح البحث أو يسأل عن استعلام Unity Search المطلوب استخدامه. لا تستخدمه للحصول على نظرة عامة على المشروع، أو هيكل المشروع، أو ملخصات غرض المجلد، أو شرح اللعب/النظام، أو أسئلة البرمجة الإرشادية، أو بحث الويب، أو البحث عن نص المستودع، أو سجلات الإنشاء، أو تثبيت الحزمة، أو البحث في القائمة أو الإعدادات، أو تعديل النتائج، أو البحث في نظام ملفات غير تابع لـ Unity ما لم يطلب المستخدم صراحةً استخدام Unity Search.
