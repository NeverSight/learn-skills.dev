يولد استعلامات Unity Search / Quick Search ويفتح نافذة Unity Search لطلبات البحث عن الأصول أو كائنات المشهد في محرر Unity للقراءة فقط. استخدمه دائمًا عندما يطلب المستخدم العثور على، البحث عن، إظهار، تحديد موقع، تصفية، البحث عن، الاستعلام عن، أو سرد أصول أو كائنات مشهد محددة في المشروع الحالي أو المشهد الحالي، حتى وإن لم يُذكر Unity Search. يغطي المواد، القوام، الـ Prefabs، المشاهد، السكريبتات، الـ Shaders، GameObjects، المكونات، الأضواء، الكاميرات، عناصر واجهة المستخدم، التسميات، المسارات، المراجع، الأصول المحددة أو المسماة، وأنواع الأصول. استخدمه أيضًا عندما يذكر المستخدم صراحةً Unity Search أو Quick Search أو نافذة البحث أو فتح البحث أو يسأل عن استعلام Unity Search الذي يجب استخدامه. لا تستخدمه لأغراض نظرة عامة عامة على المشروع، بنية المشروع، ملخصات غرض المجلدات، شروحات اللعب/النظام، أسئلة كيفية البرمجة، بحث على الويب، بحث نصي في المستودع، سجلات البناء، تثبيت الحزم، بحث في القوائم أو الإعدادات، تعديل النتائج، أو البحث في نظام ملفات غير Unity ما لم يطلب المستخدم صراحةً استخدام Unity Search.
