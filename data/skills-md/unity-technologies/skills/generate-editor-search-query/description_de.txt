Erstellt Unity-Such-/Schnellsuchabfragen und öffnet das Unity-Suchfenster für schreibgeschützte Unity Editor-Asset- oder Szenenobjekt-Suchanfragen. Immer verwenden, wenn der Benutzer konkrete Assets oder Szenenobjekte im aktuellen Projekt oder in der aktuellen Szene suchen, suchen, anzeigen, lokalisieren, filtern, nachschlagen, abfragen oder auflisten möchte, auch wenn Unity Search nicht benannt ist. Behandelt Materialien, Texturen, Prefabs, Szenen, Skripte, Shader, GameObjects, Komponenten, Lichter, Kameras, UI-Objekte, Beschriftungen, Pfade, Referenzen, ausgewählte oder benannte Assets und Asset-Typen. Verwenden Sie dies auch, wenn der Benutzer ausdrücklich Unity Search, Schnellsuche, Suchfenster erwähnt, die Suche öffnet oder fragt, welche Unity Search-Abfrage verwendet werden soll. Nicht für allgemeine Projektübersicht, Projektstruktur, Zusammenfassungen von Ordnerzwecken, Gameplay-/Systemerklärungen, Fragen zur Anleitung zur Programmierung, Websuche, Repository-Textsuche, Build-Protokolle, Paketinstallation, Menü- oder Einstellungssuche, Änderungsergebnisse oder Nicht-Unity-Dateisystemsuche verwenden, es sei denn, der Benutzer fordert ausdrücklich die Verwendung von Unity Search an.
