Construye herramientas de editor basadas en nodos con Unity Graph Toolkit (GTK) en Unity 6.6+: gráficos, nodos, puertos y validación, herramientas de la API de máquinas de estado en 6.7+, y activos en tiempo de ejecución mediante un importador scriptado. Úsalo para editores personalizados de gráficos, nodos o máquinas de estado, o para migrar una herramienta GraphView. No es para Shader Graph, VFX Graph o controladores de Animator.
