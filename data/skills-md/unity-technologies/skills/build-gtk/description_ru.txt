Создаёт инструменты редактора на основе узлов с Unity Graph Toolkit (GTK) в Unity 6.6+: графы, узлы, порты и проверка, инструменты API State Machine в 6.7+ и активы времени выполнения через скриптовый импортёр. Используйте для пользовательских редакторов графов, узлов или конечных автоматов, а также для миграции инструмента GraphView. Не предназначено для Shader Graph, VFX Graph или Animator Controllers.
