Construit des outils d’éditeur basés sur des nœuds avec Unity Graph Toolkit (GTK) sur Unity 6.6 +: graphes, nœuds, ports et validation, outils API de machine à états sur 6.7 +, et actifs d’exécution via un importateur scripté. À utiliser pour des éditeurs de graphe, nœud ou machine à états personnalisés, ou pour migrer un outil GraphView. Pas pour Shader Graph, VFX Graph ou les contrôleurs d’animation.
