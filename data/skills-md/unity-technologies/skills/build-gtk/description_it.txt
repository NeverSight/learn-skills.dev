Crea strumenti editor basati su nodi con Unity Graph Toolkit (GTK) su Unity 6.6+: grafici, nodi, porte e validazione, strumenti API di macchine a stati su 6.7+, e asset runtime tramite un importatore scriptato. Da usare per editor di grafici, nodi o macchine a stati personalizzati, o per migrare uno strumento GraphView. Non per Shader Graph, VFX Graph o Animator Controllers.
