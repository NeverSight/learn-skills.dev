يبني أدوات محرر قائمة على العقد باستخدام Unity Graph Toolkit (GTK) على Unity 6.6+: الرسوم البيانية، العقد، المنافذ والتحقق، أدوات واجهة برمجة تطبيقات الآلة الحالة على 6.7+، وأصول وقت التشغيل عبر مستورد مُبرمج. يُستخدم لتطبيقات محررات الرسوم البيانية أو العقد أو آلات الحالة المخصصة، أو لترحيل أداة GraphView. ليس للـ Shader Graph أو VFX Graph أو متحكمات Animator.
