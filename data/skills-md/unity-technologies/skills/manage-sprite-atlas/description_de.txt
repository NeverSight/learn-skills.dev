Verwalten Sie SpriteAtlas mithilfe der vorgefertigten Pipeline mit IPreprocessBuildWithReport (STANDARD-Ansatz). Verwenden Sie es, um Masteratlanten, Variantenatlanten, Textureinstellungen, Verpackungseinstellungen und plattformspezifische Konfigurationen zu konfigurieren. Verwenden Sie diese Option, wenn der Benutzer Fragen zum Erstellen von Sprite-Atlanten, zum Optimieren von Sprites, zum Konfigurieren von Atlas-Einstellungen, zum Hinzufügen von Sprites zu Atlanten, zum Erstellen von Variantenatlanten, zum Implementieren der automatisierten Atlas-Generierung oder zum Zugriff auf Sprite-Atlas zur Laufzeit stellt. Verwenden Sie immer den Prebuild-Ansatz, es sei denn, der Benutzer fordert ausdrücklich eine manuelle Erstellung an.
