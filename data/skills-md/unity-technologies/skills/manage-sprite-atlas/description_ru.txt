Управляйте SpriteAtlas с помощью конвейера предварительной сборки с помощью IPreprocessBuildWithReport (подход DEFAULT). Используйте его для настройки основных атласов, вариантов атласов, настроек текстур, настроек упаковки и конфигураций для конкретной платформы. Используйте, когда пользователь спрашивает о создании атласов спрайтов, оптимизации спрайтов, настройке параметров атласа, добавлении спрайтов в атласы, создании вариантов атласов, реализации автоматического создания атласов или доступе к атласу спрайтов во время выполнения. Всегда используйте подход предварительной сборки, если пользователь явно не запрашивает разработку вручную.
