Planifie, exécute et résout les problèmes des projets Unity passant du pipeline de rendu intégré (BiRP/BIRP/Built‑in RP) au pipeline de rendu universel (URP). À utiliser lorsque l'utilisateur demande à mettre à jour, convertir, changer ou migrer un projet, une scène, un matériau ou un shader vers l'URP/Universal Render Pipeline ; corriger les matériaux roses ou magenta après l'URP ; convertir les matériaux/shaders intégrés ; passer un projet 2D à l'URP 2D ; examiner l’éclairage, la qualité, le post‑traitement, les lightmaps pré‑boulées ou les sondes de réflexion après l’URP ; ou diagnostiquer des problèmes visuels suite à une migration de pipeline de rendu.
