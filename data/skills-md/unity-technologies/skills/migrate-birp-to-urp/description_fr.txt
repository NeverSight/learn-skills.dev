Planifie, exécute et dépanne les projets Unity passant du pipeline de rendu intégré (BiRP/BIRP/RP intégré) au pipeline de rendu universel (URP). À utiliser lorsque l'utilisateur demande à mettre à niveau, convertir, changer ou migrer un projet, une scène, un matériau ou un shader vers URP/Universal Render Pipeline ; réparer les matériaux roses ou magenta après URP ; convertir les matériaux/shaders intégrés ; déplacer un projet 2D vers URP 2D ; examiner l'éclairage, la qualité, le post-traitement, les cartes lumineuses cuites ou les sondes de réflexion après l'URP ; ou diagnostiquer des problèmes visuels après une migration de pipeline de rendu.
