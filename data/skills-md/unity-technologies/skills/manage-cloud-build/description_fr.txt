Configure les cibles de construction de Unity Build Automation et diagnostique les builds cloud qui ont échoué. Assurez-vous d’utiliser cette compétence lorsque l’utilisateur souhaite configurer des builds cloud pour un projet ou demande pourquoi un build cloud a échoué, mais pas pour les builds locaux ou l’automatisation de pipeline.

Veuillez toujours répondre dans la langue de l’utilisateur.
