Настраивает цели сборки Unity Build Automation и диагностирует неудачные облачные сборки. Убедитесь, что используете этот навык, когда пользователь хочет настроить облачные сборки для проекта или задаёт вопрос, почему облачная сборка не удалась, но не для локальных сборок или автоматизации конвейера.
