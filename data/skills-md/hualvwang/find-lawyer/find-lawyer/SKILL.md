# 找律师（66law / 华律网）

## Overview

把用户的自然语言需求转成查询参数，调用 `scripts/find_lawyer.js`（封装
`https://m.66law.cn/findlawyer/rpc/loadlawyerlist/`），对返回律师做筛选与排序，
给出 Top 3 卡片式推荐及理由。字典文件 `area.json`/`category.json` 由脚本自动读取。
运行环境：Node ≥18（用内置 fetch），零依赖、无需 `npm install`；入口见 `package.json`。

## 工作流

### 1. 提取需求维度

| 维度 | 处理 |
|---|---|
| 地区 | 用户没说→全国；说了→原样传给 `--province/--city`（脚本自动解析名称/adcode） |
| 领域 | 模糊语义先映射（见下表），拿不准就跑 `lookup.js category <词>` 确认 cateid |
| 条件 | "10年以上"→`--min-year 10`；"口碑好"→`--score 480`；"回复快/急"→`--active` 并结合响应时长展示；"现在能联系"→`--online`；"资深"→`--order 6`；"接单多/靠谱"→`--order 7` |
| 数量 | 最终推荐**固定 Top 3**；用户要"更多名单"→`--all --limit 40` 后先给 3 张卡片，其余以一行一条的简表附后 |

常见模糊需求 → cateid 映射：

- 欠钱不还/借钱/讨债/高利贷 → 2 债权债务
- 被辞退/拖欠工资/加班费/工伤赔偿(赔偿类→7) → 6 劳动纠纷
- 离婚/抚养权/财产分割 → 73 离婚（泛婚姻家庭→11）
- 家人被抓/拘留/取保候审/判刑 → 36 刑事辩护
- 买房/交房/物业/房产证 → 19 房产纠纷
- 车祸/事故赔偿 → 4 交通事故
- 医疗事故 → 3 医疗纠纷
- 合同违约/模板审查 → 5 合同纠纷
- 商标/专利/著作权 → 24 知识产权
- 征地/拆迁 → 1 拆迁安置
- 告官府/行政 → 39 行政诉讼
- 开公司/股权 → 71 公司经营（股权纠纷→55）

### 2. 执行查询

在本 skill 目录下运行（任意 cwd 均可，脚本按自身路径找字典）：

```bash
node scripts/find_lawyer.js --province 四川 --city 成都 --cate 劳动纠纷 \
    --min-year 10 --score 480 --limit 16 --all --json
```

- 参数：`--province/--city/--cate/--min-year/--max-year/--order(0智能|6年限|7服务人数|8好评率|9入驻)/--score(400|450|480|500)/--help-min/--online/--active/--high-reply/--school/--new/--keyword/--page/--limit/--all/--include-promo/--json`
- 地区或领域名解析失败时脚本会打印候选项——把候选转述给用户选择，不要瞎猜
- 需要手工确认编码时：`node scripts/lookup.js area 成都`、`node scripts/lookup.js category 劳动`
- 完整接口细节与响应字段：`references/api.md`

### 3. 结果不足时逐级放宽（每步重查，最多 2 次放宽）

1. 去掉 `--min-year`/`--score` 等硬条件
2. 城市放宽到省：只传 `--province`
3. 领域放宽：子类→父类（如 35 取保候审→36 刑事辩护，用 `lookup.js category` 查）
4. 仍无结果→如实告知"该平台该组合无匹配"，建议用户调整需求表述

### 4. 呈现推荐（卡片式，最多 3 张）

从返回中挑 Top 3（`--all` 抓多页后本地排序：评分 → 帮助人数数值 → 响应时长 → 执业年限）。**不得编造接口未返回的信息**。每位律师一张引用块卡片：

```markdown
> **1️⃣ 杨鹏淋律师** · 执业律师 · 已认证
> ![头像](avatar字段URL)
> ⭐ 5.0　👥 1.63万+人　⏱ 24小时内　🎓 浙江大学　📅 执业11年
> 🏷 有顾问单位经验 / 丰富的专业经验
> **擅长**：劳动纠纷、婚姻家庭、公司法、债权债务、交通事故
> **推荐理由**：杭州劳动纠纷类服务人数最高的个人律师，满分好评
> 🔗 [律师主页](url字段)　💬 [向TA咨询](consult_url字段)
```

卡片规则：

- 字段行只写接口有值的项；`years=0` 写"执业年限未公开"，不写 0 年；无学校/标签则省略该图标
- 每张卡片必须带两个链接：主页（`url`）与咨询单入口（`consult_url`，即向该律师发布咨询）
- 律所/团队账号（`account_type`）在姓名后标注；用户明确要"个人律师"时排除团队账号
- `promo=true` 默认剔除（脚本已处理）
- 3 张卡片后可附一句"其余 N 位符合条件，需要名单可展开"
- 结尾提示：可翻页/细化条件；信息来自华律网公开数据，以律师主页与执业证为准

## 约束

- 每次对话对该接口发起的请求不超过 5 次；不要循环抓取全部页
- 不向用户暴露原始 HTML 标签字段（`commentScore` 等已由脚本清洗）
- 律师联系方式只给 `url` 主页与 `consult_url` 咨询单链接，接口不提供电话/微信
- 本 skill 不处理律师费报价、案件代理等承诺性内容；对"哪个律师最能赢"类问题只陈述数据不做保证
