À utiliser pour activer ou vérifier la barre latérale Omni-Channel sur une application de console Lightning. Déclencheurs : activez la barre latérale Omni, épinglez Omni-Channel dans une application de console, configurez la barre latérale Omni, activez la région utilitaire Omni-Channel, vérifiez le widget Omni épinglé. Ne pas utiliser pour les applications Aura, les applications standard, les widgets Omni à barre utilitaire uniquement ou pour créer une application de console.
