Úselo para habilitar o verificar la barra lateral omnicanal en una aplicación de consola Lightning. Activadores: habilite la barra lateral Omni, fije Omni-Channel en una aplicación de consola, configure la barra lateral Omni, encienda la región de utilidad Omni-Channel, verifique el widget Omni fijado. No lo use para aplicaciones Aura, aplicaciones estándar, widgets Omni solo para barras de utilidad o para crear una aplicación de consola.
