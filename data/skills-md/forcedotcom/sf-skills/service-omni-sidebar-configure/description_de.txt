Verwenden Sie diese Option, um die Omni-Channel-Seitenleiste in einer Lightning-Konsolen-App zu aktivieren oder zu überprüfen. Auslöser: Aktivieren Sie die Omni-Seitenleiste, pinnen Sie Omni-Channel in einer Konsolen-App, konfigurieren Sie die Omni-Seitenleiste, aktivieren Sie die Omni-Channel-Dienstprogrammregion, überprüfen Sie das gepinnte Omni-Widget. Verwenden Sie es nicht für Aura-Apps, Standard-Apps, Omni-Widgets nur für die Utility-Leiste oder zum Erstellen einer Konsolen-App.
