Применяется для включения или проверки боковой панели Omni-Channel в консольном приложении Lightning. Триггеры: включить боковую панель Omni, закрепить Omni-Channel в консольном приложении, настроить боковую панель Omni, включить регион утилиты Omni-Channel, проверить закреплённый виджет Omni. Не использовать для приложений Aura, стандартных приложений, виджетов Omni, доступных только в панели утилит, или для создания консольного приложения.
