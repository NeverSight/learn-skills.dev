Usa per abilitare o verificare la barra laterale Omni‑Channel in un’app console Lightning. Attivazioni: abilita la barra laterale Omni, fissa Omni‑Channel in un’app console, configura la barra laterale Omni, attiva la regione utility Omni‑Channel, verifica il widget Omni fissato. Non utilizzare per app Aura, app standard, widget Omni solo per la barra utility o per creare un’app console.
