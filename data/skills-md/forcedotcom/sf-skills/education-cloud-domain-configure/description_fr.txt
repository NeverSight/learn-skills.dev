Utilisez cette compétence pour configurer les domaines d’Education Cloud (Student Success, Recruitment & Admissions, Academic Operations, Alumni Relations, Student Management ou Mentoring) via une configuration conversationnelle. Se déclenche lorsqu’un utilisateur souhaite activer ou configurer des fonctionnalités d’Education Cloud. Guide étape par étape : active la condition préalable des Person Accounts, active le domaine cible, puis configure les sous‑fonctionnalités du domaine. Couvre les processus de support, les types d’enregistrements de cas, les équipes de réussite, les plans de soins, les candidatures, les admissions, le catalogue de cours, l’engagement des anciens, la collecte de fonds, l’inscription, les programmes et le mentorat. Explique chaque fonctionnalité, confirme avant de poursuivre, vérifie que chaque modification a bien pris effet et avertit que les basculements de domaine et de fonctionnalité sont IRRÉVERSIBLES. NE PAS DÉCLENCHER pour la génération de métadonnées, les objets personnalisés ou le déploiement de packages — cela configure les fonctionnalités existantes de la plateforme via les paramètres de l’organisation, pas les fichiers de métadonnées.

Veuillez toujours répondre dans la langue de l’utilisateur.
