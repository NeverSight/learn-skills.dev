Используется для разработки персонажа AI‑агента — идентичность, голос, тон, стиль поведения, ограничения — и кодирования его в файлы Agent Script (.agent) или значения полей Agentforce Builder. Выполняет четыре последовательные фазы (DRAFT, REFINE, SCORE, ENCODE) плюс пять направлений (NAME, FILL OUT, ADJUST, CHECKLIST, WORKSHOP). Поддерживает greenfield (ввод бренда в стартовый .agent‑файл) и brownfield (аудит существующего .agent‑файла и перекодирование только полей персонажа) с 100‑балльной оценочной рубрикой. Срабатывает, когда пользователь разрабатывает новый персонаж агента, модернизирует согласованность персонажа, переводит бренд‑гайдлайны в голос агента, определяет тон/регист/формальность/тёплоту/юмор/персонификацию, кодирует персонажа для Agent Script или Agentforce Builder, либо оценивает/аудирует существующий .agent‑файл на качество персонажа. Не срабатывает при построении действий/метаданных Agentforce, написании логики потока Agent Script без работы над персонажем или тестировании разговоров агента.
