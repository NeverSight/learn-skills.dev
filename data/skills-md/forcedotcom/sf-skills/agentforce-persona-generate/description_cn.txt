用于设计 AI 代理人格——身份、声音、语调、行为风格、守则——并将其编码为 Agent Script（.agent 文件）或 Agentforce Builder 字段值。运行四个顺序阶段（草稿 DRAFT、完善 REFINE、评分 SCORE、编码 ENCODE）以及五个分支（命名 NAME、填写 FILL OUT、调整 ADJUST、检查清单 CHECKLIST、工作坊 WORKSHOP）。支持绿地模式（将品牌输入到起始的 .agent 文件）和棕地模式（审计现有 .agent 文件并仅重新编码人格字段），并配有 100 分评估量表。触发条件为用户设计新代理人格、改造人格一致性、将品牌指南转化为代理声音、定义语调/注册/正式程度/温暖度/幽默感/拟人化、为 Agent Script 或 Agentforce Builder 编码人格，或对现有 .agent 文件进行人格质量评分或审计。非触发情形包括构建 Agentforce 动作/元数据、在未涉及人格工作的情况下编写 Agent Script 流程控制，或测试代理对话。
