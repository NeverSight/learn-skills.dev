AI 에이전트 페르소나(정체성, 음성, 톤, 행동 양식, 가드레일)를 설계하고 이를 Agent Script(.agent 파일) 또는 Agentforce Builder 필드 값에 인코딩하는 데 사용합니다. 네 단계의 순차적 단계(DRAFT, REFINE, SCORE, ENCODE)와 다섯 개의 서브 단계(NAME, FILL OUT, ADJUST, CHECKLIST, WORKSHOP)를 수행합니다. 그린필드(브랜드 입력을 기반으로 시작 .agent 파일을 생성)와 브라운필드(기존 .agent 파일을 감사하고 페르소나 필드만 재인코딩) 방식을 지원하며, 100점 만점 평가 루브릭을 사용합니다. 사용자가 새로운 에이전트 페르소나를 설계하거나 페르소나 일관성을 재구성하고, 브랜드 가이드라인을 에이전트 음성으로 변환하며, 톤/레지스터/포멀리티/온도/유머/의인화를 정의하고, 페르소나를 Agent Script 또는 Agentforce Builder에 인코딩하거나, 기존 .agent 파일의 페르소나 품질을 점수 매기거나 감audit할 때 트리거됩니다. 에이전트포스 액션/메타데이터를 구축하거나, 페르소나 작업 없이 Agent Script 흐름 제어를 작성하거나, 에이전트 대화를 테스트하는 경우에는 트리거되지 않습니다.
