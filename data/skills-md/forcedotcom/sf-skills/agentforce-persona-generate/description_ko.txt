AI 에이전트 페르소나를 설계(정체성, 목소리, 톤, 행동 양식, 가드레일)하고 이를 Agent Script(.agent 파일) 또는 Agentforce Builder 필드 값으로 인코딩하는 데 사용합니다. DRAFT, REFINE, SCORE, ENCODE 네 단계와 NAME, FILL OUT, ADJUST, CHECKLIST, WORKSHOP 다섯 가지 스포크로 구성된 순차적 프로세스를 실행합니다. 브랜드 입력을 시작 .agent 파일에 적용하는 그린필드와 기존 .agent 파일을 감사하고 페르소나 필드만 재인코딩하는 브라운필드를 지원하며, 100점 평가 루브릭을 사용합니다. 사용자가 새로운 에이전트 페르소나를 설계하거나, 페르소나 일관성을 재구성하거나, 브랜드 가이드라인을 에이전트 목소리로 변환하거나, 톤·레지스터·형식·친근함·유머·의인화를 정의하거나, Agent Script 또는 Agentforce Builder용 페르소나를 인코딩하거나, 기존 .agent 파일의 페르소나 품질을 점수 매기거나 감사할 때 트리거됩니다. Agentforce 행동·메타데이터 구축, 페르소나 작업 없이 Agent Script 흐름 제어 저작, 에이전트 대화 테스트와 같은 경우에는 트리거되지 않습니다.
