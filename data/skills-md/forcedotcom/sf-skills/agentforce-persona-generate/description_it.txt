Usato per progettare il persona di un agente IA — identità, voce, tono, stile comportamentale, linee guida di sicurezza — e codificarlo in Agent Script (file .agent) o nei valori dei campi di Agentforce Builder. Esegue quattro fasi sequenziali (DRAFT, REFINE, SCORE, ENCODE) più cinque rami (NAME, FILL OUT, ADJUST, CHECKLIST, WORKSHOP). Supporta il greenfield (input del brand per un file .agent iniziale) e il brownfield (audit di un file .agent esistente e ricodifica solo dei campi del persona), con una rubrica di valutazione a 100 punti. Si attiva quando un utente progetta un nuovo persona per l'agente, retrofitta la coerenza del persona, traduce le linee guida del brand nella voce dell'agente, definisce tono/registro/formalità/calore/umorismo/personificazione, codifica un persona per Agent Script o Agentforce Builder, oppure assegna un punteggio o verifica un file .agent esistente per la qualità del persona. Non si attiva per la creazione di azioni/metadati di Agentforce, l'autorizzazione del controllo del flusso di Agent Script senza lavoro sul persona, o il testing delle conversazioni dell'agente.
