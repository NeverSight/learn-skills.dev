Usa per progettare la persona di un agente IA — identità, voce, tono, stile comportamentale, linee guida — e codificarla in Agent Script (file .agent) o nei valori dei campi di Agentforce Builder. Si articola in quattro fasi sequenziali (DRAFT, REFINE, SCORE, ENCODE) più cinque componenti (NAME, FILL OUT, ADJUST, CHECKLIST, WORKSHOP). Supporta i casi greenfield (input del brand in un file .agent di partenza) e brownfield (audit di un file .agent esistente e ricodifica solo dei campi della persona), con una rubrica di valutazione a 100 punti. Si attiva quando un utente progetta una nuova persona per l'agente, adatta la coerenza della persona, traduce le linee guida del brand nella voce dell'agente, definisce tono/registro/formalità/calore/umorismo/personificazione, codifica una persona per Agent Script o Agentforce Builder, oppure valuta o verifica un file .agent esistente per la qualità della persona. Non attivarsi per la creazione di azioni/metadati di Agentforce, per la scrittura del controllo del flusso di Agent Script senza lavoro sulla persona, o per il testing delle conversazioni dell'agente.
