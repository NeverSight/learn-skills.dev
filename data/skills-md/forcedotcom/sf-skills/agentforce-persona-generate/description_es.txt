Usar para diseñar una personalidad de agente IA — identidad, voz, tono, estilo conductual, limitaciones — y codificarla en Agent Script (archivos .agent) o valores de campo de Agentforce Builder. Ejecuta cuatro fases secuenciadas (BORRADOR, REFINAR, CALIFICAR, CODIFICAR) más cinco ramificaciones (NOMBRE, COMPLETAR, AJUSTAR, LISTA DE VERIFICACIÓN, TALLER). Soporta greenfield (entrada de marca a un archivo .agent inicial) y brownfield (auditar un archivo .agent existente y recodificar solo los campos de la personalidad), con una rúbrica de evaluación de 100 puntos. Se activa cuando un usuario diseña una nueva personalidad de agente, adapta la consistencia de la personalidad, traduce las directrices de marca a la voz del agente, define tono/registro/formalidad/calidez/humor/personificación, codifica una personalidad para Agent Script o Agentforce Builder, o califica o audita un archivo .agent existente para la calidad de la personalidad. No se activa para construir acciones/metadatos de Agentforce, crear control de flujo de Agent Script sin trabajo de personalidad, o probar conversaciones del agente.
