Usar para diseñar una personalidad de agente de IA — identidad, voz, tono, estilo de comportamiento, directrices — y codificarla en Agent Script (archivos .agent) o en los valores de campo de Agentforce Builder. Ejecuta cuatro fases secuenciadas (BORRADOR, REFINAR, PUNTUAR, CODIFICAR) más cinco ejes (NOMBRE, COMPLETAR, AJUSTAR, LISTA DE VERIFICACIÓN, TALLER). Soporta greenfield (entrada de marca a un archivo .agent inicial) y brownfield (auditar un archivo .agent existente y volver a codificar solo los campos de la personalidad), con una rúbrica de evaluación de 100 puntos. Se activa cuando un usuario diseña una nueva personalidad de agente, retroajusta la consistencia de la personalidad, traduce las directrices de marca a la voz del agente, define tono/registro/formalidad/calidez/humor/personificación, codifica una personalidad para Agent Script o Agentforce Builder, o puntúa o audita un archivo .agent existente para la calidad de la personalidad. No se activa para crear acciones/metadatos de Agentforce, redactar control de flujo de Agent Script sin trabajo de personalidad, o probar conversaciones del agente.
