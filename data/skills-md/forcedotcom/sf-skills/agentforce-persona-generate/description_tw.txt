用於設計 AI 代理人格 — 身份、語音、語調、行為風格、守則 — 並將其編碼為 Agent Script（.agent 檔案）或 Agentforce Builder 欄位值。執行四個順序階段（草稿、精練、評分、編碼）以及五個分支（名稱、填寫、調整、檢查清單、工作坊）。支援綠地（將品牌輸入至起始 .agent 檔案）和棕地（審核現有 .agent 檔案並僅重新編碼人格欄位），並使用 100 分評估量表。當使用者設計新代理人格、調整人格一致性、將品牌指南轉換為代理語音、定義語調／語域／正式度／溫度／幽默感／人格化、為 Agent Script 或 Agentforce Builder 編碼人格，或對現有 .agent 檔案進行人格品質評分或審核時觸發。不要在構建 Agentforce 動作／元資料、撰寫無人格相關的 Agent Script 流程控制，或測試代理對話時觸發。

請始終以使用者的語言回覆。
