استخدم لتصميم شخصية وكيل ذكاء اصطناعي — الهوية، الصوت، النبرة، أسلوب السلوك، الضوابط — وتشفيرها في ملفات Agent Script (.agent) أو قيم حقول Agentforce Builder. يعمل بأربع مراحل متسلسلة (مسودة، تحسين، تقييم، تشفير) بالإضافة إلى خمس محاور (الاسم، تعبئة، تعديل، قائمة التحقق، ورشة عمل). يدعم الوضع الأخضر (إدخال العلامة التجارية إلى ملف .agent بدءي) والوضع البني (تدقيق ملف .agent موجود وإعادة تشفير حقول الشخصية فقط)، مع معيار تقييم مكوّن من 100 نقطة. يُفعل عندما يصمم المستخدم شخصية وكيل جديدة، أو يعيد توحيد اتساق الشخصية، أو يترجم إرشادات العلامة التجارية إلى صوت الوكيل، أو يحدد النبرة/السجل/الرسمية/الدفء/الفكاهة/التجسيد، أو يشفر شخصية لـ Agent Script أو Agentforce Builder، أو يقيم أو يدقق ملف .agent موجود لجودة الشخصية. لا يُفعل عند بناء إجراءات/بيانات تعريفية لـ Agentforce، أو تأليف تدفق Agent Script بدون عمل على الشخصية، أو اختبار محادثات الوكيل.
