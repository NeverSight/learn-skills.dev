Verwenden, um eine KI‑Agenten‑Persona zu entwerfen — Identität, Stimme, Ton, Verhaltensstil, Leitplanken — und sie in Agent Script (.agent‑Dateien) oder Agentforce Builder‑Feldwerte zu kodieren. Durchläuft vier sequenzierte Phasen (ENTWURF, VERFEINERN, BEWERTEN, KODIEREN) plus fünf Spreizer (NAME, AUSFÜLLEN, ANPASSEN, CHECKLISTE, WORKSHOP). Unterstützt Greenfield (Marken‑Input zu einer Starter‑.agent‑Datei) und Brownfield (Audit einer bestehenden .agent‑Datei und erneutes Kodieren nur der Persona‑Felder) mit einem 100‑Punkte‑Bewertungsraster. Auslösen, wenn ein Benutzer eine neue Agenten‑Persona entwirft, Persona‑Konsistenz retrofittet, Markenrichtlinien in die Agentenstimme übersetzt, Ton/ Register/ Formalität/ Wärme/ Humor/ Personifizierung definiert, eine Persona für Agent Script oder Agentforce Builder kodiert oder eine bestehende .agent‑Datei hinsichtlich Persona‑Qualität bewertet oder auditiert. Nicht auslösen bei der Erstellung von Agentforce‑Aktionen/Metadaten, beim Autorieren von Agent Script‑Ablaufsteuerungen ohne Persona‑Arbeit oder beim Testen von Agentengesprächen. Bitte immer in der Sprache des Nutzers antworten.
