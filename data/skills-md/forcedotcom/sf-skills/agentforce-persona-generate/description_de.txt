Verwenden, um eine KI‑Agenten‑Persona zu entwerfen – Identität, Stimme, Ton, Verhaltensstil, Leitplanken – und sie in Agent Script (.agent‑Dateien) oder Agentforce‑Builder‑Feldwerte zu codieren. Führt vier aufeinanderfolgende Phasen (DRAFT, REFINE, SCORE, ENCODE) sowie fünf Module (NAME, FILL OUT, ADJUST, CHECKLIST, WORKSHOP) aus. Unterstützt Greenfield (Markeneingabe in eine Starter‑.agent‑Datei) und Brownfield (Audit einer bestehenden .agent‑Datei und erneutes Codieren nur der Persona‑Felder) mit einer 100‑Punkte‑Bewertungsrichtlinie. Auslösen, wenn ein Benutzer eine neue Agent‑Persona gestaltet, die Konsistenz der Persona nachträgt, Markenrichtlinien in die Agentenstimme übersetzt, Ton/Registern/Formalität/Wärme/Humor/Personifizierung definiert, eine Persona für Agent Script oder Agentforce Builder codiert oder eine bestehende .agent‑Datei auf Persona‑Qualität bewertet oder auditieren lässt. Nicht auslösen beim Erstellen von Agentforce‑Aktionen/Metadaten, beim Autorisieren von Agent Script‑Ablaufsteuerung ohne Persona‑Arbeit oder beim Testen von Agent‑Konversationen.
