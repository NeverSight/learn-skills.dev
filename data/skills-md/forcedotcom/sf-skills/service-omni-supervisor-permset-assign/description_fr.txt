Utilisé pour attribuer le PermissionSet standard ContactCenterSupervisor fourni par Salesforce (par défaut) à N utilisateurs superviseurs existants via DML PermissionSetAssignment. Idempotent — SOQL détecte les paires (utilisateur, permission‑set) existantes avant le POST, et DUPLICATE_VALUE est considéré comme réutilisé. L’ensemble standard possède sa propre licence de jeu de permissions et s’attribue proprement sur les organisations activées Service‑Cloud ; un utilisateur dont la licence ne comprend pas le droit déclenche FIELD_INTEGRITY_EXCEPTION afin que l’opérateur puisse corriger le profil/la licence. Déclencheurs : attribuer le permission‑set superviseur, accorder les permissions de superviseur, finaliser le provisionnement du superviseur. Ne pas utiliser sur les organisations de production ou pour attribuer des permission‑sets d’agent.
