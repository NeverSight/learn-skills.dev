Salesforce 組織で Consumer Goods Cloud TPM プロモーション ビジネス オブジェクト (BO) API フレームワークを有効にするために使用し、追加したいカスタム ワークフロー ステップについてユーザにインタビューし、その Apex クラスを生成してデプロイし、それを作成/更新/コピー ワークフローに接続し、ヘッドレス REST インジェストを介してエンドツーエンドで証明します。動作する参照サンプル (SetCommentValue) が同梱されますが、カスタマイズは組織ごとにユーザーが指定します。 「プロモーション BO API のデプロイ」、「プロモーション BO API の設定」、「ヘッドレス プロモーションの作成」、「BO API ワークフロー ステップの追加」をトリガーします。
