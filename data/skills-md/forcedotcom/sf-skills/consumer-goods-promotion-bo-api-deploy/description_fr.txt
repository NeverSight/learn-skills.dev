Utilisez-le pour activer le framework API Consumer Goods Cloud TPM Promotion Business Object (BO) dans une organisation Salesforce, interroger l'utilisateur pour l'étape de workflow personnalisée qu'il souhaite ajouter, générer et déployer cette classe Apex, la connecter aux workflows de création/mise à jour/copie et la prouver de bout en bout via l'ingestion REST sans tête. Fournit un exemple de référence fonctionnel (SetCommentValue), mais la personnalisation est fournie par l'utilisateur par organisation. Déclencheurs sur "déployer l'API BO de promotion", "configurer l'API BO de promotion", "créer une promotion sans tête", "ajouter une étape de workflow de l'API BO".
