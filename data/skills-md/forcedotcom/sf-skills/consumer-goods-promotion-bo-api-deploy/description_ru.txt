Используйте, чтобы включить платформу API бизнес-объекта (BO) продвижения потребительских товаров в облаке TPM в организации Salesforce, опросить пользователя для настраиваемого шага рабочего процесса, который он хочет добавить, создать и развернуть этот класс Apex, подключить его к рабочим процессам создания, обновления и копирования и доказать его сквозное выполнение с помощью безголовой загрузки REST. Поставляется рабочий справочный пример (SetCommentValue), но настройка предоставляется пользователем для каждой организации. Триггеры по «развертыванию API BO продвижения», «настройке API BO продвижения», «созданию безголового продвижения», «добавлению шага рабочего процесса API BO».
