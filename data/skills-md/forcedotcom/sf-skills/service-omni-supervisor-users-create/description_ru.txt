Используйте для создания N пользователей-супервизоров Omni-Channel в организации Salesforce через Anonymous Apex с использованием шаблона Supervisor{i}.<suffix>@example.com с идемпотентностью на основе SOQL (повторные запуски пропускают существующие имена пользователей). Пароли устанавливаются через System.setPassword и обрабатываются в случае закрытия при сбое: оболочка доказывает отсутствие активного отладочного TraceFlag перед установкой пароля, а в противном случае оставляет пользователя ACTIVE и reset_required. Триггеры: создание пользователей-супервайзеров, предоставление учетных записей супервизоров, создание персон супервизоров. Не используйте в производственных организациях клиентов (заблокированных защитой Safe_to_write), для привязки супервизоров к OmniSupervisorConfig (service-omni-supervisor-config-deploy) или для назначения набора разрешений ContactCenterSupervisor (service-omni-supervisor-permset-assign).
