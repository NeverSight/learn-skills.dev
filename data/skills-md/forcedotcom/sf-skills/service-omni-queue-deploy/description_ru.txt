Используйте для проверки или создания очереди в организации Salesforce для маршрутизируемого объекта sObject (Case | Incident | MessagingSession | VoiceCall), обнаруженного с помощью привязки QueueSobject, а не по жестко закодированному имени. Повторно использует любую очередь, уже маршрутизирующую целевой sObject; с --create-if-missing он создает очередь через API метаданных (Group + QueueSobject), когда ни один из них не привязан, и выравнивает свой QueueRoutingConfigId с QRC, указанным вызывающим абонентом. Возврат создан, повторно использован, обновлен или заблокирован. Триггеры: проверка или создание очереди для маршрутизации обращений/инцидентов/сообщений/голосовой связи, согласование конфигурации маршрутизации очереди, настройка голосовой очереди Omni. Не используйте для добавления пользователей в очередь (service-omni-queue-members-assign) или для sObject вне Case/Incident/MessagingSession/VoiceCall.
