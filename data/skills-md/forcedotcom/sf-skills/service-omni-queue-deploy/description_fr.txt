À utiliser pour vérifier ou créer une file d'attente sur une organisation Salesforce pour un sObject routable (Case | Incident | MessagingSession | VoiceCall), découvert via sa liaison QueueSobject plutôt que par son nom codé en dur. Réutilise la file d'attente qui achemine déjà le sObject cible ; avec --create-if-missing, il crée une file d'attente via l'API de métadonnées (Group + QueueSobject) lorsqu'aucune n'est liée et aligne son QueueRoutingConfigId sur un QRC spécifié par l'appelant. Retours créés, réutilisés, mis à jour ou bloqués. Déclencheurs : vérifiez ou créez une file d'attente pour le routage des cas/incidents/messages/voix, alignez la configuration du routage de la file d'attente, configurez une file d'attente vocale Omni. Ne pas utiliser pour ajouter des utilisateurs à la file d'attente (service-omni-queue-members-assign) ou pour des sObjects en dehors de Case/Incident/MessagingSession/VoiceCall.
