Se utiliza para habilitar Command Center para Service V2 y configurar sus controles de supervisor compatibles mediante la API de metadatos de Configuración de OmniChannel, preservando la configuración no relacionada. Requiere consentimiento explícito de aplicación, rechaza organizaciones de cliente en producción y verifica la página y pestaña V2 sembradas. DESENCADENA cuando: habilitar Command Center V2, configurar la monitorización de conversaciones, habilitar la vista previa del agente, habilitar la vista previa del cliente, configurar mensajes de susurro o habilitar acciones de colas y habilidades. No se debe usar para asignar permisos de supervisor ni para configurar metadatos clásicos de OmniSupervisorConfig.
