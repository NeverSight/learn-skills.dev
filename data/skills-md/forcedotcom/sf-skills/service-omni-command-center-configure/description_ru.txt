Используется для включения Command Center для Service V2 и настройки поддерживаемых контролей супервизора через API метаданных настроек OmniChannel при сохранении несвязанных настроек. Требует явного согласия на применение, отклоняет организации клиентов в продакшене и проверяет предварительно созданную страницу и вкладку V2. СРАБОТЫВАЕТ, когда: включён Command Center V2, настроен мониторинг разговоров, включён режим «подглядывания» агента, включён режим «подглядывания» клиента, настроены шепотные сообщения или включены действия очередей и навыков. Не используется для назначения прав супервизора или настройки классических метаданных OmniSupervisorConfig.
