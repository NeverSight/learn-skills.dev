Úsese para habilitar los cinco ajustes base de Omni‑Channel en una organización de Salesforce a través de la API de Metadatos. El escritor canónico scripts/configure-and-report.sh detecta, despliega y vuelve a verificar en una sola llamada (modo ejecución) o solo detecta (modo planificación); es idempotente (despliega únicamente cuando un interruptor es falso o falta) y protege las escrituras con una verificación safe_to_write para sandbox/CDO/prueba/DE. Siempre muestra la brecha de comportamiento de inicio de sesión solo en la UI en su informe. Activadores: habilitar Omni‑Channel, activar los ajustes base de Omni, configurar OmniChannelSettings, desplegar Settings:OmniChannel. No lo use para configurar entidades Omni descendentes (colas, presencia, permisos — use la habilidad específica de la entidad) ni para desplegar otros tipos de Settings (use platform-metadata-deploy).
