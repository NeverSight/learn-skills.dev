使用此工具通过 Metadata API 在 Salesforce 组织中启用五项 Omni‑Channel 基础设置。规范的 writer 脚本 scripts/configure-and-report.sh 可在一次调用中检测、部署并重新验证（运行模式），或仅进行检测（计划模式）；它具备幂等性（仅在开关为 false 或缺失时才部署），并通过 sandbox/CDO/trial/DE 的 safe_to_write 检查来保护写入。它始终在报告中呈现仅 UI 登录行为的差距。触发条件：启用 Omni‑Channel、打开 Omni 基础设置、配置 OmniChannelSettings、部署 Settings:OmniChannel。请勿用于配置下游 Omni 实体（队列、在岗状态、权限——使用对应实体的 skill）或部署其他 Settings 类型（使用 platform-metadata-deploy）。
