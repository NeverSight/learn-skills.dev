メタデータ API を介して Salesforce 組織で 5 つのオムニチャネル基本設定を有効にするために使用します。正規のライター scripts/configure-and-report.sh は、1 回の呼び出し (実行モード) で検出、展開、および再検証を行うか、検出のみ (計画モード) を行います。これはべき等であり (トグルが false または欠落している場合にのみデプロイされます)、サンドボックス/CDO/トライアル/DE の安全な書き込みチェックで書き込みを保護します。レポートでは、UI のみのログイン動作のギャップが常に明らかになります。トリガー: オムニチャネルを有効にし、オムニ基本設定をオンにし、OmniChannelSettings を構成し、Settings:OmniChannel を展開します。ダウンストリームの Omni エンティティ (キュー、プレゼンス、権限 - エンティティ固有のスキルを使用) を構成したり、他の設定タイプをデプロイしたり (platform-metadata-deploy を使用) するためには使用しないでください。
