このツールは、Metadata API を介して Salesforce 組織の 5 つの Omni‑Channel 基本設定を有効化するために使用します。標準スクリプト `scripts/configure-and-report.sh` は、1 回の呼び出しで検出・デプロイ・再検証を行う（run モード）か、検出のみを行う（plan モード）ことができます。冪等性が保たれ、トグルが false または未設定の場合にのみデプロイし、sandbox/CDO/trial/DE の `safe_to_write` チェックで書き込みを保護します。レポートでは常に UI のみのログイン挙動ギャップが表れます。トリガー: Omni‑Channel を有効化し、Omni 基本設定をオンにし、OmniChannelSettings を構成し、Settings:OmniChannel をデプロイします。下流の Omni エンティティ（キュー、プレゼンス、権限…）を構成するため、または他の Settings タイプをデプロイするために使用しないでください（エンティティ固有のスキル、または `platform-metadata-deploy` を使用）。
