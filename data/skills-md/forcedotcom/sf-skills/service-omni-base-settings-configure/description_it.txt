Utilizzare per abilitare le cinque impostazioni di base di Omni‑Channel su un’organizzazione Salesforce tramite l’API Metadata. Lo script canonico scripts/configure-and-report.sh rileva, distribuisce e ri‑verifica in un’unica chiamata (modalità esecuzione) o solo rileva (modalità pianificazione); è idempotente (effettua il deployment solo quando un toggle è falso o assente) e protegge le scritture con un controllo safe_to_write per sandbox/CDO/trial/DE. Evidenzia sempre il divario di comportamento di login solo UI nel suo report. Trigger: abilitare Omni‑Channel, attivare le impostazioni di base Omni, configurare OmniChannelSettings, distribuire Settings:OmniChannel. Non utilizzare per configurare entità Omni a valle (code, presenza, autorizzazioni — usare la skill specifica per l’entità) o per distribuire altri tipi di Settings (usare platform-metadata-deploy).
