Используйте для включения пяти базовых настроек многоканального режима в организации Salesforce через API метаданных. Канонический модуль записи scripts/configure-and-report.sh обнаруживает, развертывает и повторно проверяет за один вызов (режим выполнения) или только обнаруживает (режим планирования); он идемпотентен (развертывается только тогда, когда переключатель ложный или отсутствует) и защищает записи с помощью проверки sandbox/CDO/trial/DE Safe_to_write. В своем отчете он всегда отображает пробел в поведении при входе только в пользовательский интерфейс. Триггеры: включить Omni-Channel, включить базовые настройки Omni, настроить OmniChannelSettings, развернуть Settings:OmniChannel. Не используйте для настройки нисходящих объектов Omni (очереди, присутствие, разрешения — используйте навык, специфичный для объекта) или для развертывания других типов настроек (используйте развертывание метаданных платформы).
