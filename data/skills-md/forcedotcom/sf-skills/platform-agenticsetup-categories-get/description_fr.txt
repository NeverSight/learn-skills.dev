Obtenez les catégories d’invites de configuration agentique à partir d’une organisation Salesforce connectée en utilisant l’API Connect via une requête sf api REST. Utilisez cette compétence pour appeler GET /services/data/vXX.0/agenticsetup/categories et renvoyer la liste des catégories d’invites, éventuellement avec leurs invites imbriquées en utilisant fetchPrompts=true. DÉCLENCHER lorsque : l’utilisateur demande d’obtenir, récupérer, lister ou afficher les catégories de configuration agentique, les catégories d’invites, les catégories de copilote de configuration, les catégories de bibliothèque d’invites, les invites de configuration disponibles, la bibliothèque d’invites Agentforce, les invites de copilote, ou invoque l’API REST Connect des catégories agenticsetup. NE PAS DÉCLENCHER lorsque : l’utilisateur souhaite créer de nouvelles catégories, travailler avec des points de terminaison qui ne sont pas des catégories, ou générer des spécifications OpenAPI.  

Veuillez toujours répondre dans la langue de l’utilisateur.
