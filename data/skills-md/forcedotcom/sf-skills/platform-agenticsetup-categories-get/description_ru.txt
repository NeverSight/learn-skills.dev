Получить категории запросов агентской настройки из подключенной организации Salesforce с помощью Connect API через REST‑запрос sf api. Использовать этот навык для вызова GET /services/data/vXX.0/agenticsetup/categories и вернуть список категорий запросов, опционально с их вложенными запросами, используя fetchPrompts=true. ТРИГГЕР, когда: пользователь просит получить, извлечь, найти, перечислить или показать категории агентской настройки, категории запросов, категории настройки copilot, категории библиотеки запросов, доступные настройки запросов, библиотеку запросов Agentforce, запросы copilot, либо вызывает Connect REST API категорий agenticsetup. НЕ ТРИГГЕР, когда: пользователь хочет создать новые категории, работать с эндпоинтами, не связанными с категориями, или генерировать спецификации OpenAPI.
