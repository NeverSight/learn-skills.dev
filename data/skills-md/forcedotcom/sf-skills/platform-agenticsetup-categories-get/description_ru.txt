Получить категории запросов агентской настройки из подключённой организации Salesforce, используя Connect API через REST‑запрос sf api. Используйте этот навык, чтобы вызвать GET /services/data/vXX.0/agenticsetup/categories и вернуть список категорий запросов, при необходимости с их вложенными запросами, используя параметр fetchPrompts=true. ТРИГГЕР, когда: пользователь просит получить, извлечь, найти, перечислить или показать категории агентской настройки, категории запросов, категории настройки копилота, категории библиотеки запросов, доступные запросы настройки, библиотеку запросов Agentforce, запросы копилота, либо вызывает Connect REST API для категорий agenticsetup. НЕ ТРИГГЕРИТЬ, когда: пользователь хочет создать новые категории, работать с эндпоинтами, не связанными с категориями, или генерировать спецификации OpenAPI.
