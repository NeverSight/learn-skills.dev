Ottieni le categorie di prompt di configurazione agentic da un'organizzazione Salesforce connessa usando l'API Connect tramite richiesta REST sf api. Usa questa abilità per chiamare **GET /services/data/vXX.0/agenticsetup/categories** e restituisci l'elenco delle categorie di prompt, opzionalmente con i loro prompt nidificati usando **fetchPrompts=true**. **TRIGGER** quando: l'utente chiede di ottenere, recuperare, elencare o mostrare categorie di configurazione agentic, categorie di prompt, categorie di copilot di configurazione, categorie della libreria di prompt, prompt di setup disponibili, libreria di prompt Agentforce, prompt di copilot, o chiama l'API REST Connect agenticsetup/categories. **DO NOT TRIGGER** quando: l'utente vuole creare nuove categorie, lavorare con endpoint non‑categorie o generare specifiche OpenAPI.
