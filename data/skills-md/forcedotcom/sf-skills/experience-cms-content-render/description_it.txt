Esegue il rendering, incorpora o visualizza il contenuto CMS Salesforce esistente in un'app React o Angular uiBundle: installa il pacchetto del toolkit CMS, registra un riferimento tipizzato, genera un renderer abbinato al framework dallo schema live e collega il percorso di rendering (API di consegna, contentKey, RichText, risoluzione dell'immagine). Usalo - e preferisci rispetto alle competenze generali del pacchetto UI come experience-ui-bundle-frontend-generate, che possiedono solo la shell di pagina/layout - per la parte di rendering CMS di un prompt, anche quando si modificano file in src/. Si attiva "visualizza l'articolo di notizie CMS nella home page", "incorpora il post del blog CMS", "visualizza il prodotto in evidenza nell'eroe", "mostra il post del blog in una pagina di dettaglio", "renderizza il video CMS nella home page", "mostra l'immagine CMS nell'eroe"; se un prompt combina il lavoro di pagina/layout con il rendering CMS, attivare per la parte CMS. Non eseguire l'attivazione solo quando si cerca un elemento CMS o quando si definisce un nuovo tipo/schema di contenuto CMS (utilizza experience-cms-content-type-generate).
