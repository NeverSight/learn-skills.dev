在 React 或 Angular uiBundle 应用程序中渲染、嵌入或显示现有 Salesforce CMS 内容：安装 CMS 工具包包、注册类型化引用、从实时架构生成框架匹配的渲染器，并连接渲染路径（交付 API、contentKey、RichText、图像分辨率）。对于提示的 CMS 渲染部分，即使在编辑 src/ 下的文件时，也可以使用它，而不是像 experience-ui-bundle-frontend-generate 这样只拥有页面/布局 shell 的一般 UI 捆绑技能。触发“在首页渲染 CMS 新闻文章”、“嵌入 CMS 博文”、“在英雄中显示特色产品”、“在详情页显示博文”、“在首页渲染 CMS 视频”、“在英雄中显示 CMS 图片”；如果提示将页面/布局与 CMS 渲染混合使用，请激活 CMS 部分。仅搜索 CMS 项目或定义新的 CMS 内容类型/架构（使用 experience-cms-content-type-generate）时不触发。
