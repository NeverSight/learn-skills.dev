استخدمه قبل إنشاء أو تعديل أو كتابة شفرة ضد بيانات تعريف Salesforce، لمعرفة ما هو موجود بالفعل في المؤسسة باستخدام الأداة المناسبة. يوجه كل سؤال إلى ربط البيانات التعريفية، أو SOQL محدد باستخدام استعلام بيانات sf، أو قائمة أو وصف sobject في sf، أو قائمة بيانات تعريف org في sf، أو استرجاع المصدر، أو الملفات المحلية، ويغطي المؤسسات والإعدادات التي لا يتوفر فيها ربط البيانات التعريفية. استخدمه للتحقق مما إذا كان كائن أو حقل أو قائمة اختيار أو مجموعة أذونات أو صفحة أو تطبيق أو تدفق موجودًا بالفعل قبل إنشائه، ولتأكيد أسماء الحقول وأنواعها وقيم قوائم الاختيار قبل كتابة Apex أو LWC أو SOQL أو منطق Flow، ولإدراج كل حقل في كائن أو كل عضو من نوع بيانات تعريف، وللعثور على الأتمتة التي تعمل على كائن، أو لشرح كيفية تكوين شيء ما في المؤسسة ومن يمكنه الوصول إليه. لا تُفعِل ذلك للحصول على نظرات شاملة على المؤسسة بأكملها، أو مقارنة المؤسسات، أو الانحراف (استخدم dx-org-analyze)، أو بنية ملفات البيانات التعريفية أو شكل XML (platform-metadata-api-context-get)، أو مخطط Data Cloud DLO و DMO (data360-code-extension-generate). يرجى دائمًا الرد بلغة المستخدم.
