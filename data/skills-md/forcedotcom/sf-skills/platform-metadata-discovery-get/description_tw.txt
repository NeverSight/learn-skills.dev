在建立、變更或編寫針對 Salesforce 元資料的程式碼之前使用，以使用正確的工具找出組織中已存在的內容。將每個問題導向元資料基礎、帶範圍的 SF Data Query SOQL、SF SObject 列表或描述、SF Org 列表元資料、來源檢索或本機檔案，並涵蓋在基礎不可用的組織與設定。用於在建立物件、欄位、挑選清單、權限集合、頁面、應用程式或流程之前，檢查它是否已存在；在編寫 Apex、LWC、SOQL 或 Flow 邏輯之前，確認欄位名稱、類型與挑選清單值；列出物件的所有欄位或某個元資料類型的所有成員；找出在物件上執行的自動化；或說明組織中某項設定的方式以及誰能存取它。請勿觸發整個組織概況、組織比較或漂移（使用 dx‑org‑analyze）、元資料檔案結構或 XML 形態（platform‑metadata‑api‑context‑get），或 Data Cloud DLO 與 DMO 架構（data360‑code‑extension‑generate）。
