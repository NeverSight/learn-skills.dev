使用前在创建、修改或编写针对 Salesforce 元数据的代码之前，使用正确的工具了解组织中已经存在的内容。将每个问题路由到元数据基础、使用 sf data query 的范围化 SOQL、sf sobject 列表或 describe、sf org 列表元数据、源检索或本地文件，并覆盖在没有基础的组织和设置。用于在创建对象、字段、下拉列表、权限集、页面、应用或流程之前检查其是否已存在，在编写 Apex、LWC、SOQL 或 Flow 逻辑之前确认字段名称、类型和下拉列表值，列出对象的每个字段或元数据类型的每个成员，查找在对象上运行的自动化，或解释组织中某项配置以及谁可以访问它。不要触发整体组织概览、组织比较或漂移（使用 dx‑org‑analyze）、元数据文件结构或 XML 形状（platform‑metadata‑api‑context‑get），以及 Data Cloud DLO 和 DMO 架构（data360‑code‑extension‑generate）。
