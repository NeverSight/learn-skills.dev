Usa prima di creare, modificare o scrivere codice contro i metadati di Salesforce, per scoprire cosa esiste già nell'org con lo strumento giusto. Instrada ogni domanda verso il grounding dei metadati, SOQL limitato con sf data query, sf sobject list o describe, sf org list metadata, recupero del codice sorgente o file locali, e copre org e configurazioni dove il grounding non è disponibile. Usalo per verificare se un oggetto, campo, picklist, permission set, pagina, app o flow esiste già prima di crearne uno, confermare i nomi dei campi, i tipi e i valori delle picklist prima di scrivere Apex, LWC, SOQL o logica Flow, elencare tutti i campi di un oggetto o tutti i membri di un tipo di metadato, trovare l'automazione che gira su un oggetto, o spiegare come qualcosa è configurato nell'org e chi può accedervi. NON ATTIVARE per panoramiche dell'intera org, confronto di org o drift (usa dx‑org‑analyze), struttura dei file dei metadati o forma XML (platform‑metadata‑api‑context‑get), o schema Data Cloud DLO e DMO (data360‑code‑extension‑generate).

Rispondi sempre nella lingua dell'utente.
