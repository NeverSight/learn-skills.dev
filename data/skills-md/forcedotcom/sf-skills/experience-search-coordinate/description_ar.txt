يبحث عن المحتوى والوسائط الموجودة ويستعيدها (المقالات والمدونات والأخبار والأسئلة الشائعة والأحداث والمنتجات والصور والشعارات والأيقونات والصور والرسومات واللافتات والصور الرئيسية ومقاطع الصوت ومقاطع الفيديو والمستندات) من Salesforce CMS أو مصادر أخرى متصلة. استخدم هذه المهارة في أي وقت يقول فيه المستخدم "بحث" أو "بحث" أو "إحضار" أو "جلب" أو "استرداد" أو "بحث" أو "تحديد موقع" أو "أرني" أو "قائمة" أو "أحتاج" متبوعة بمحتوى أو كلمات وسائط مثل "مدونة" أو "مقال" أو "أخبار" أو "الأسئلة الشائعة" أو "حدث" أو "صفحة منتج" أو "صورة" أو "شعار" أو "رمز" أو "صورة" أو "شعار" أو "صوت" أو "فيديو" أو "مستند". استخدمه أيضًا للطلبات التي تمزج بين الاثنين، مثل "إعادة استخدام الأصول الموجودة" لصفحة ما. يقوم بتوجيه كل نية إلى سير العمل الفرعي الصحيح - البحث عن المحتوى المنظم أو البحث عن الوسائط - ويمكن تشغيلهما معًا في نفس الطلب. لا ينطبق عندما يكون الطلب هو إنشاء محتوى أو صور جديدة من البداية، أو تحديد مخططات نوع المحتوى، أو تطبيق إرشادات العلامة التجارية.
