Шаг развертывания Headless 360 REST API для создания записей sObject. Обрабатывает обнаружение полей на основе describe, вывод обязательных полей, упорядочивание по сущностно‑отношенческим зависимостям и составные графовые транзакции. Используйте эту возможность, когда дизайнерская функция (или пользователь напрямую) необходимо создать записи sObject после подтверждения дизайна, включая создание sObject, не относящихся к настройке.
