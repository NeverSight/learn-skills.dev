Paso de implementación de la API REST 360 sin interfaz para crear registros sObject. Gestiona el descubrimiento de campos basado en descripciones, la derivación de campos obligatorios, el ordenamiento de relaciones entre entidades y las transacciones de gráficos compuestos. Use esta capacidad cuando una habilidad de diseñador (o un usuario directamente) necesite crear registros sObject tras la confirmación del diseño, incluida la creación de sObject que no son de configuración. 

Por favor, responda siempre en el idioma del usuario.
