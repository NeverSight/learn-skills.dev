تُستخدم لضمان وجود قناة ServiceChannel واحدة فقط في منظمة Salesforce لكائن sObject قابل للتوجيه (Case | Incident | MessagingSession | VoiceCall)، مع إعادة استخدام أي قناة قياسية أو مخصصة مرتبطة بالفعل بهذا الـsObject وعدم نشر قالب قياسي إلا عندما لا توجد أي قناة. تفرض Salesforce قناة ServiceChannel واحدة لكل كيان مرتبط (RelatedEntity)، لذا تقوم الأداة بالكشف عبر واجهة برمجة التطبيقات Tooling API أولًا. القنوات القياسية متوفرة لـ Case (الحالات)، MessagingSession (sfdc_livemessage)، VoiceCall (sfdc_phone)؛ ولا توجد قناة قياسية لـ Incident. المحفزات: تكوين ServiceChannel لتوجيه Case/Incident/Messaging/Voice، إضافة توجيه Incident أو Voice إلى Omni. لا تُستخدم لضبط سعة كل sObject (استخدم PresenceUserConfig.Capacity)، أو لإعادة تعيين قناة مكوّفة بشكل غير صحيح إلى الشكل القياسي، أو لكائنات sObject خارج نطاق Case/Incident/MessagingSession/VoiceCall. يرجى دائمًا الرد بلغة المستخدم.
