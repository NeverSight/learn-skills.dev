Используется для управления правилами маршрутизации на основе атрибутов Omni-Channel через Tooling API. ТРИГГЕР, когда: перечисление правил маршрутизации по атрибутам, просмотр правила WorkSkillRouting, создание неактивного правила маршрутизации, добавление сопоставления поле‑на‑навык, активация полного правила маршрутизации, деактивация правила маршрутизации или удаление правила маршрутизации или атрибута. Не используется для создания навыков агентов или потоков маршрутизации.
