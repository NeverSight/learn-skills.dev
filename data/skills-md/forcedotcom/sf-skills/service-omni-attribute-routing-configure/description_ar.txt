استخدم لإدارة قواعد التوجيه القائمة على السمات في Omni‑Channel عبر واجهة برمجة الأدوات. تشغيل عندما: قائمة قواعد التوجيه القائمة على السمات، فحص قاعدة WorkSkillRouting، إنشاء قاعدة توجيه غير نشطة، إضافة تعيين حقل إلى مهارة، تنشيط قاعدة توجيه مكتملة، إلغاء تنشيط قاعدة توجيه، أو حذف قاعدة توجيه أو سمة. لا تستخدم لإنشاء مهارات الوكلاء أو تدفقات التوجيه. يرجى دائمًا الرد بلغة المستخدم.
