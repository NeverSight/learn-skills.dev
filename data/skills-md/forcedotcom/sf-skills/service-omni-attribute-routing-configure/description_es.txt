Utilícelo para gestionar las reglas de enrutamiento basadas en atributos omnicanal a través de la API de herramientas. DESENCADENAR cuando: enumere las reglas de enrutamiento de atributos, inspeccione una regla de WorkSkillRouting, cree una regla de enrutamiento inactiva, agregue una asignación de campo a habilidad, active una regla de enrutamiento completa, desactive una regla de enrutamiento o elimine una regla o atributo de enrutamiento. No utilizar para crear habilidades de agente o flujos de enrutamiento.
