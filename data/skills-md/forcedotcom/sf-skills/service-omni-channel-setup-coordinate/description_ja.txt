Salesforce 上でヘッドレスでオムニチャネル設定を立ち上げるために使用します: 基本設定、エージェントユーザー、サービスチャネル、ルーティング設定、キュー (作成および調整) とメンバー、プレゼンスステータス、権限の割り当て、従来のオムニスーパーバイザ設定とそのアクション/タブ画面、および - Case と VoiceCall の場合 - レコードトリガーのルーティングフロー。ケース、インシデント、MessagingSession、および VoiceCall ターゲットをサポートします。既存のレコードを再利用し、不足しているものを作成します。オプトイン追加機能: プレゼンス ユーザー設定、オムニ サイドバー、スキルベースのルーティング、およびフィールドベースの WorkSkillRouting。また、組織がクラシック スーパーバイザ サーフェス上にあるか、Command Center V2 上にあるかどうかもレポートします (読み取り専用)。トリガー: オムニチャネルのセットアップ、オムニルーティングの構成、オムニエージェントまたはスーパーバイザーのプロビジョニング、ケース/インシデント/メッセージング/音声ルーティングの構成。 Agentforce エージェントまたはボット、単一の既存の Omni フィールド変更、ベア メタデータ デプロイメント (platform-metadata-deploy を使用)、または Command Center V2 の有効化 (メタデータ API を介して書き込み不可) には使用しないでください。
