Úselo para implementar la configuración OmniCanal sin cabeza en Salesforce: configuraciones básicas, usuarios de agentes, canales de servicio, configuraciones de enrutamiento, colas (crear y alinear) y miembros, estados de presencia, asignaciones de permisos, la configuración clásica de Omni Supervisor más su superficie de acción/pestaña y, para Caso y Llamada de voz, el flujo de enrutamiento activado por registro. Admite objetivos de caso, incidente, sesión de mensajería y llamada de voz; reutiliza registros existentes y crea lo que falta. Opciones adicionales: configuración de presencia de usuario, barra lateral Omni, enrutamiento basado en habilidades y WorkSkillRouting basado en campo; También informa (solo lectura) si la organización está en la superficie de supervisor clásica o en Command Center V2. Activadores: configurar OmniCanal, configurar el enrutamiento Omni, aprovisionar agentes o supervisores Omni, configurar caso/incidente/mensajería/enrutamiento de voz. No lo use para agentes o bots de Agentforce, un único cambio de campo Omni existente, implementación de metadatos simples (use plataforma-metadata-deploy) o para habilitar Command Center V2 (no se puede escribir a través de la API de metadatos).
