Utilisez-le pour mettre en place la configuration Omni-Channel sans tête sur Salesforce : paramètres de base, utilisateurs d'agents, canaux de service, configurations de routage, files d'attente (créer et aligner) et membres, statuts de présence, attributions d'autorisations, la configuration classique d'Omni Supervisor plus sa surface d'action/onglet et, pour Case et VoiceCall, le flux de routage déclenché par l'enregistrement. Prend en charge les cibles Case, Incident, MessagingSession et VoiceCall ; réutilise les enregistrements existants et crée ce qui manque. Extras opt-in : configuration utilisateur de présence, barre latérale Omni, routage basé sur les compétences et WorkSkillRouting basé sur le terrain ; indique également (en lecture seule) si l'organisation se trouve sur la surface de supervision classique ou sur Command Center V2. Déclencheurs : configurez Omni-Channel, configurez le routage Omni, provisionnez les agents ou superviseurs Omni, configurez le routage de cas/incident/messagerie/voix. Ne pas utiliser pour les agents ou les robots Agentforce, une seule modification de champ Omni existant, un déploiement de métadonnées nues (utilisez platform-metadata-deploy) ou pour activer Command Center V2 (non accessible en écriture via l'API de métadonnées).
