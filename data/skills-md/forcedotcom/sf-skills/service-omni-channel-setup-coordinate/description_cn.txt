用于在 Salesforce 上无头部署 Omni‑Channel 设置：基础设置、代理用户、服务渠道、路由配置、队列（创建并对齐）及成员、在线状态、权限分配、经典 Omni 主管配置及其操作/标签界面，以及针对 Case 和 VoiceCall 的记录触发路由流。支持 Case、Incident、MessagingSession 与 VoiceCall 目标；复用已有记录并创建缺失的记录。可选附加功能：在线用户配置、Omni 侧边栏、基于技能的路由和基于字段的 WorkSkillRouting；还会（只读）报告组织使用的是经典主管界面还是 Command Center V2。触发器：设置 Omni‑Channel、配置 Omni 路由、配置 Omni 代理或主管、配置 Case/Incident/Messaging/Voice 路由。请勿用于 Agentforce 代理或机器人、单个已有 Omni 字段的更改、纯元数据部署（请使用 platform-metadata-deploy），或用于启用 Command Center V2（该功能不可通过 Metadata API 写入）。
