Comparez deux organisations Salesforce côte à côte et générez un rapport de comparaison avec un score de dérive, ou analysez une seule organisation pour produire un inventaire couvrant les composants de métadonnées, les autorisations d’organisation, les autorisations système, les profils, les paquets installés, les licences et les limites de l’organisation. Utilisez cette compétence lorsque l’utilisateur souhaite comparer des orgs, diff des orgs, auditer la dérive de configuration, trouver ce qui a changé entre deux environnements, comparer le sandbox à la production, ou analyser une seule org. Les expressions déclencheuses incluent : « compare orgs », « compare these 2 orgs », « compare my orgs », « diff orgs », « org diff », « what is different between these orgs », « compare metadata », « org comparison », « audit org differences », « compare sandbox to production », « introspect org », « org inventory », « what is in my org », « analyze org », « org analysis », « analyze my org », « analyze my Salesforce org ». Ne pas l’utiliser pour récupérer des métadonnées (utilisez platform-metadata-retrieve), déployer des métadonnées (utilisez platform-metadata-deploy) ou changer d’organisation (utilisez dx-org-switch).

Veuillez toujours répondre dans la langue de l’utilisateur.
