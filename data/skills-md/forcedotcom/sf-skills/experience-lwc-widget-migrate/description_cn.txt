将特定的现有 Lightning Web Component（LWC）完整转换为声明式 HXL / Agentforce 小部件。通过 experience-lwc-widget-assess 进行检查，当小部件无法满足 LWC 的用途时停止；否则将派生的字段形状交给 platform-widget-generate，并将小部件连接为 Lightning Type 渲染器。触发条件：用户想要转换、迁移、移植、重建或将指定的 LWC 转换为小部件或声明式 Agentforce 小部件，或请求基于现有 LWC 组件构建的小部件。不触发条件：用户仅想了解 LWC 是否可以成为小部件（使用 experience-lwc-widget-assess），或想要针对数据形状、实体或没有现有 LWC 的 Lightning Type 的小部件（使用 platform-widget-generate 或 platform-lightning-type-widget-coordinate）。请始终使用用户的语言作答。
