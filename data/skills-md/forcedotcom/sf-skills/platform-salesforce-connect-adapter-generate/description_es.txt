Generación de adaptador Apex personalizado para Salesforce Connect: conecta cualquier API REST externa a Salesforce como objetos externos consultables y activos sin ETL ni copia de datos. DISPARAR cuando: el usuario quiere conectar una API externa no estándar a Salesforce, solicita escribir un DataSource.Provider o DataSource.Connection, quiere mostrar datos externos como registros de Salesforce, dice "conectar mi API a Salesforce sin copiar datos" o pregunta si Apex personalizado es el enfoque correcto para cualquier sistema. También se activa en: "adaptador personalizado", "campo ExternalId", "espacio de nombres DataSource". NO DISPARAR cuando: el usuario está configurando un adaptador estándar que ya tiene y NO pregunta sobre Apex personalizado (p. ej., configuración del terminal OData, configuración del conector Snowflake). NO DISPARAR cuando: el usuario quiera copiar o sincronizar datos de forma masiva: utilice la gestión de datos de plataforma. NO DISPARE las llamadas de Apex fuera de Connect: use platform-apex-generate o Integration-Connectivity-generate.
