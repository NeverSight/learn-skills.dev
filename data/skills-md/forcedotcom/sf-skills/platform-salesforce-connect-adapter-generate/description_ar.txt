إنشاء محول Apex مخصص لـ Salesforce Connect - يربط أي REST API خارجي بـ Salesforce ككائنات خارجية مباشرة وقابلة للاستعلام دون ETL أو نسخ البيانات. يتم تشغيله عندما: يريد المستخدم توصيل واجهة برمجة تطبيقات خارجية غير قياسية بـ Salesforce، أو يطلب كتابة DataSource.Provider أو DataSource.Connection، أو يريد عرض بيانات خارجية كسجلات Salesforce، أو يقول "قم بتوصيل واجهة برمجة التطبيقات الخاصة بي بـ Salesforce دون نسخ البيانات"، أو يسأل عما إذا كان Apex المخصص هو النهج الصحيح لأي نظام. قم بتشغيل أيضًا: "المحول المخصص"، "حقل المعرف الخارجي"، "مساحة اسم مصدر البيانات". لا تقم بالتشغيل عندما: يقوم المستخدم بتكوين محول قياسي لديه بالفعل ولا يسأل عن Apex المخصص (على سبيل المثال، إعداد نقطة نهاية OData، وتكوين موصل Snowflake). لا تقم بالتشغيل عندما: يريد المستخدم نسخ البيانات أو مزامنتها بشكل مجمع - استخدم إدارة بيانات النظام الأساسي. لا تقم بتشغيل وسائل شرح Apex خارج Connect - استخدم إنشاء منصة apex أو إنشاء اتصال التكامل.
