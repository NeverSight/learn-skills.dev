Salesforce Connect 的自定义 Apex 适配器生成 — 将任何外部 REST API 作为实时、可查询的外部对象连接到 Salesforce，无需 ETL 或数据复制。当以下情况触发：用户想要将非标准外部 API 连接到 Salesforce，要求编写 DataSource.Provider 或 DataSource.Connection，想要将外部数据显示为 Salesforce 记录，说“将我的 API 连接到 Salesforce 而不复制数据”，或者询问自定义 Apex 是否是任何系统的正确方法。还触发：“自定义适配器”、“ExternalId 字段”、“数据源命名空间”。不要在以下情况下触发：用户正在配置他们已有的标准适配器，并且不询问自定义 Apex（例如，OData 端点设置、Snowflake 连接器配置）。不要在以下情况下触发：用户想要复制或批量同步数据 - 使用平台数据管理。请勿在 Connect 外部触发 Apex 标注 — 使用 platform-apex-generate 或integration-connectivity-generate。
