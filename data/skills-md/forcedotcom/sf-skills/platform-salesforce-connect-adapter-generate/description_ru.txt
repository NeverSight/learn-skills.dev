Создание пользовательского адаптера Apex для Salesforce Connect — подключает любой внешний API REST к Salesforce в виде живых, доступных для запроса внешних объектов без ETL или копирования данных. ТРИГГЕР, когда: пользователь хочет подключить нестандартный внешний API к Salesforce, просит написать DataSource.Provider или DataSource.Connection, хочет отображать внешние данные в виде записей Salesforce, говорит «подключите мой API к Salesforce без копирования данных» или спрашивает, является ли пользовательский Apex правильным подходом для любой системы. Также активируйте: «пользовательский адаптер», «поле ExternalId», «пространство имен DataSource». НЕ ЗАПУСКАЙТЕ, когда: пользователь настраивает уже имеющийся у него стандартный адаптер и НЕ запрашивает пользовательский Apex (например, настройку конечной точки OData, конфигурацию соединителя Snowflake). НЕ ЗАПУСКАЙТЕ, когда: пользователь хочет скопировать или выполнить массовую синхронизацию данных — используйте управление данными платформы. НЕ СРАБАТЫВАЙТЕ вызовы Apex вне Connect — используйте Platform-apex-generate или Integration-Connectivity-Generate.
