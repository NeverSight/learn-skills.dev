Salesforce Connect용 사용자 정의 Apex 어댑터 생성 — ETL 또는 데이터 복사 없이 외부 REST API를 실시간 쿼리 가능한 외부 개체로 Salesforce에 연결합니다. TRIGGER 시기: 사용자가 비표준 외부 API를 Salesforce에 연결하려고 하거나 DataSource.Provider 또는 DataSource.Connection을 작성하도록 요청하거나 외부 데이터를 Salesforce 레코드로 표시하려고 하거나 "데이터를 복사하지 않고 내 API를 Salesforce에 연결"이라고 말하거나 사용자 정의 Apex가 모든 시스템에 적합한 접근 방식인지 묻는 경우입니다. 또한 "사용자 정의 어댑터", "ExternalId 필드", "DataSource 네임스페이스"에서도 트리거됩니다. 다음의 경우에는 트리거하지 마십시오: 사용자가 이미 가지고 있는 표준 어댑터를 구성하고 있으며 사용자 정의 Apex(예: OData 끝점 설정, Snowflake 커넥터 구성)에 대해 묻지 않습니다. 다음과 같은 경우에는 트리거하지 마세요. 사용자가 데이터를 복사하거나 대량 동기화하려는 경우 — 플랫폼 데이터 관리를 사용하세요. Connect 외부에서 Apex 콜아웃을 트리거하지 마십시오. platform-apex-generate 또는 Integration-connectivity-generate를 사용하십시오.
