Génération d'adaptateur Apex personnalisé pour Salesforce Connect : connecte n'importe quelle API REST externe à Salesforce en tant qu'objets externes en direct et interrogeables sans ETL ni copie de données. DÉCLENCHEMENT lorsque : l'utilisateur souhaite connecter une API externe non standard à Salesforce, demande d'écrire un DataSource.Provider ou DataSource.Connection, souhaite faire apparaître des données externes sous forme d'enregistrements Salesforce, dit "connecter mon API à Salesforce sans copier de données", ou demande si l'Apex personnalisé est la bonne approche pour n'importe quel système. Déclenchez également sur : "adaptateur personnalisé", "champ ExternalId", "espace de noms DataSource". NE PAS DÉCLENCHER lorsque : l'utilisateur configure un adaptateur standard qu'il possède déjà et ne demande PAS d'Apex personnalisé (par exemple, configuration du point de terminaison OData, configuration du connecteur Snowflake). NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite copier ou synchroniser en masse des données – utilisez platform-data-manage. NE PAS DÉCLENCHER pour les appels Apex en dehors de Connect : utilisez platform-apex-generate ou Integration-Connectivity-generate.
