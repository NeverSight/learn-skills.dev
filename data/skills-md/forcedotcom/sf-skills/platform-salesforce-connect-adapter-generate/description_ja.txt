Salesforce Connect 用のカスタム Apex アダプタの生成 — ETL やデータのコピーを行わずに、外部 REST API をライブでクエリ可能な外部オブジェクトとして Salesforce に接続します。トリガーとなる場合: ユーザが非標準の外部 API を Salesforce に接続したい場合、DataSource.Provider または DataSource.Connection の作成を要求する場合、外部データを Salesforce レコードとして表示したい場合、「データをコピーせずに API を Salesforce に接続する」と言われる場合、またはカスタム Apex がシステムにとって適切なアプローチであるかどうかを尋ねる場合。また、「カスタム アダプター」、「外部 ID フィールド」、「DataSource 名前空間」でもトリガーされます。次の場合はトリガーしないでください: ユーザーが既に所有している標準アダプタを設定しており、カスタム Apex について質問していない場合 (OData エンドポイントのセットアップ、Snowflake コネクタの設定など)。次の場合はトリガーしないでください: ユーザーがデータをコピーまたは一括同期したい場合 - platform-data-manage を使用します。 Connect の外部で Apex コールアウトをトリガーしないでください。platform-apex-generate または integration-connectivity-generate を使用してください。
