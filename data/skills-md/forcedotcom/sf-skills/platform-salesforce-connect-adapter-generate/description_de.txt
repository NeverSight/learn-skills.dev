Generierung eines benutzerdefinierten Apex-Adapters für Salesforce Connect – verbindet jede externe REST-API als live abfragbare externe Objekte mit Salesforce, ohne ETL oder Datenkopieren. TRIGGER, wenn: Der Benutzer möchte eine nicht standardmäßige externe API mit Salesforce verbinden, bittet darum, einen DataSource.Provider oder DataSource.Connection zu schreiben, möchte externe Daten als Salesforce-Datensätze anzeigen, sagt „meine API mit Salesforce verbinden, ohne Daten zu kopieren“ oder fragt, ob benutzerdefiniertes Apex der richtige Ansatz für jedes System ist. Auch auslösen bei: „Benutzerdefinierter Adapter“, „ExternalId-Feld“, „DataSource-Namespace“. NICHT AUSLÖSEN, wenn: Der Benutzer einen bereits vorhandenen Standardadapter konfiguriert und NICHT nach benutzerdefiniertem Apex fragt (z. B. OData-Endpunkt-Setup, Snowflake-Connector-Konfiguration). NICHT AUSLÖSEN, wenn: Der Benutzer Daten kopieren oder massenhaft synchronisieren möchte – verwenden Sie „platform-data-manage“. NICHT für Apex-Callouts außerhalb von Connect auslösen – verwenden Sie „platform-apex-generate“ oder „integration-connectivity-generate“.
