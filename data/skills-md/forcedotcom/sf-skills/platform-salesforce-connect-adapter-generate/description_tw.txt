Salesforce Connect 的自訂 Apex 適配器產生 — 將任何外部 REST API 作為即時、可查詢的外部物件連接到 Salesforce，無需 ETL 或資料複製。當以下情況觸發：使用者想要將非標準外部 API 連接到 Salesforce，要求編寫 DataSource.Provider 或 DataSource.Connection，想要將外部資料顯示為 Salesforce 記錄，說“將我的 API 連接到 Salesforce 而不複製資料”，或者詢問自訂 Apex 是否是任何系統的正確方法。也觸發：「自訂適配器」、「ExternalId 欄位」、「資料來源命名空間」。請勿在下列情況下觸發：使用者正在配置他們已有的標準適配器，並且不詢問自訂 Apex（例如，OData 端點設定、Snowflake 連接器配置）。不要在以下情況下觸發：使用者想要複製或批次同步資料 - 使用平台資料管理。請勿在 Connect 外部觸發 Apex 標註 — 使用 platform-apex-generate 或integration-connectivity-generate。
