ВСЕГДА ИСПОЛЬЗУЙТЕ ЭТУ НАВЫК ДЛЯ СОЗДАНИЯ, ПРОВЕРКИ СТАТУСА, СПИСКА ИЛИ УДАЛЕНИЯ СНИПШОТОВ СКРАТЧ‑ОРГОВ. СНИПШОТ — ЭТО КОПИЯ МЕТАДАННЫХ И ДАННЫХ СКРАТЧ‑ОРГА В ОПРЕДЕЛЁННЫЙ МОМЕНТ ВРЕМЕНИ, ССЫЛКА НА КОТОРЫЙ ХРАНИТСЯ ПО ИМЕНИ В ПОЛЕ `snapshot` ФАЙЛА ОПРЕДЕЛЕНИЯ СКРАТЧ‑ОРГА. ИСПОЛЬЗУЙТЕ, КОГДА ПОЛЬЗОВАТЕЛЬ ПРОСИТ СОЗДАТЬ/СНЯТЬ СНИПШОТ, ПРОВЕРИТЬ СТАТУС ИЛИ ПРОГРЕСС СОЗДАНИЯ СНИПШОТА, ПОЛОЖИТЬ/ПОКАЗАТЬ/ОТКРЫТЬ СУЩЕСТВУЮЩИЕ СНИПШОТЫ (ВКЛЮЧАЯ ФИЛЬТРАЦИЮ СНИПШОТОВ, СКОРО ИСТЕКАЮЩИХ), ИЛИ УДАЛИТЬ/УБРАТЬ СНИПШОТ. ТРЕБУЕТСЯ DEV HUB С ВКЛЮЧЕННОЙ ФУНКЦИЕЙ SCRATCH ORG SNAPSHOTS. НЕ ПРИМЕНЯТЬ ДЛЯ СОЗДАНИЯ ФОРМ ОРГАНИЗАЦИЙ (ИСПОЛЬЗУЙТЕ dx-org-shape-manage) ИЛИ ДЛЯ СОЗДАНИЯ СКРАТЧ‑ОРГОВ, В ТОМ ЧИСЛЕ ИЗ СУЩЕСТВУЮЩЕГО СНИПШОТА ЧЕРЕЗ `--snapshot` (ИСПОЛЬЗУЙТЕ dx-org-manage).

ПОЖАЛУЙСТА, ВСЕГДА ОТВЕЧАЙТЕ НА ЯЗЫКЕ ПОЛЬЗОВАТЕЛЯ.
