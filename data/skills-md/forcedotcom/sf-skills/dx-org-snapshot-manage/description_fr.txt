UTILISEZ TOUJOURS CETTE COMPÉTENCE pour créer, vérifier le statut, lister ou supprimer des snapshots d'organisations scratch. Un snapshot est une copie à un instant donné des métadonnées ET des données d’une organisation scratch, référencée par son nom dans le champ `snapshot` d’un fichier de définition d’organisation scratch. Utilisez-la lorsque l’utilisateur demande de créer / prendre un snapshot, de vérifier le statut ou l’avancement de la création d’un snapshot, de lister / afficher / voir les snapshots existants (y compris en filtrant les snapshots expirant bientôt), ou de supprimer / retirer un snapshot. Nécessite un Dev Hub avec les Snapshots d’Org Scratch activés. NE PAS DÉCLENCHER pour créer des formes d’organisation (utilisez dx‑org‑shape‑manage) ou pour créer des organisations scratch, y compris à partir d’un snapshot existant via `--snapshot` (utilisez dx‑org‑manage).

Veuillez toujours répondre dans la langue de l’utilisateur.
