SIEMPRE UTILICE ESTA HABILIDAD para crear, comprobar el estado, listar o eliminar instantáneas de orgs temporales. Una instantánea es una copia en un momento dado de los metadatos Y datos de una org temporal, referenciada por nombre en el campo `snapshot` de un archivo de definición de org temporal. Úsela cuando el usuario solicite crear/tomar una instantánea, comprobar el estado o el progreso de creación de una instantánea, listar/mostrar/ver instantáneas existentes (incluyendo filtrar instantáneas que expiran pronto) o eliminar/quitar una instantánea. Requiere un Dev Hub con Capturas Instantáneas de Org Temporales habilitadas. NO ACTIVE para crear formas de org (use dx-org-shape-manage) o para crear orgs temporales, incluido a partir de una instantánea existente mediante `--snapshot` (use dx-org-manage).
