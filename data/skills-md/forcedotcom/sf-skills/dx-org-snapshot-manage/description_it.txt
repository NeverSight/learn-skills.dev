USA SEMPRE QUESTA ABILITÀ per creare, controllare lo stato, elencare o eliminare gli snapshot di scratch org. Uno snapshot è una copia puntuale dei metadati E dei dati di una scratch org, referenziata per nome nel campo `snapshot` di un file di definizione della scratch org. Usala quando l'utente chiede di creare/effettuare uno snapshot, verificare lo stato o l'avanzamento della creazione di uno snapshot, elencare/mostrare/visualizzare gli snapshot esistenti (incluso filtrare gli snapshot in scadenza a breve), o eliminare/rimuovere uno snapshot. Richiede un Dev Hub con gli Snapshot di Scratch Org abilitati. NON ATTIVARE per la creazione di forme di org (usa dx‑org‑shape‑manage) o per la creazione di scratch org, incluso da uno snapshot esistente tramite `--snapshot` (usa dx‑org‑manage).

Rispondi sempre nella lingua dell'utente.
