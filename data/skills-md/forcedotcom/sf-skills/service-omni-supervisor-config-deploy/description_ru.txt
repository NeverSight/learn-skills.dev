Использовать для развертывания безголовой конфигурации Omni‑Channel Supervisor, развертывая классический OmniSupervisorConfig (родительский плюс пользователь‑супервизор и сопутствующие очереди) в одном атомарном деплое Metadata API, идемпотентном через состояние деплоя. Требует активных пользователей‑супервизоров, базовых настроек Omni и контролируемых очередей. Триггеры: настройка Omni Supervisor, конфигурация классического Supervisor Command Center. Не использовать для создания пользователей‑супервизоров, назначения набора разрешений ContactCenterSupervisor или развертывания очередей, сервисных каналов или статусов присутствия.
