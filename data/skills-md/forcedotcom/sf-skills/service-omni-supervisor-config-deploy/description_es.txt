Úselo para crear una configuración de Supervisor Omni-Channel sin interfaz desplegando el clásico OmniSupervisorConfig (padre más los usuarios supervisor y sus colas asociadas) en un despliegue atómico de la API de Metadatos, idempotente mediante el estado del despliegue. Requiere usuarios supervisores activos, configuraciones base de Omni y las colas monitorizadas. Disparadores: configurar Omni Supervisor, configurar el Centro de Comando clásico del Supervisor. No lo use para crear usuarios supervisores, asignar el conjunto de permisos ContactCenterSupervisor o desplegar colas, canales de servicio o estados de presencia.
