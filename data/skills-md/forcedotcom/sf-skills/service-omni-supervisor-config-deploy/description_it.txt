Utilizzare per avviare una configurazione Supervisor Omni‑Channel senza interfaccia grafica distribuendo il classico OmniSupervisorConfig (genitore più gli utenti supervisor e i companion di coda) in un unico deploy atomico tramite Metadata API, idempotente tramite lo stato del deploy. Richiede utenti supervisor attivi, impostazioni di base Omni e le code monitorate. Trigger: configurare Omni Supervisor, impostare il classico Supervisor Command Center. Non utilizzare per creare utenti supervisor, assegnare il permission set ContactCenterSupervisor o distribuire code, canali di servizio o stati di presenza.
