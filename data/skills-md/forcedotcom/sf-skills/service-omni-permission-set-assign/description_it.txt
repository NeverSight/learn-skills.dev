Assegnare i set di autorizzazioni Omni richiesti agli utenti dell'agente con provisioning. SI ATTIVA quando gli utenti chiedono di assegnare autorizzazioni Omni agli agenti, concedere l'accesso Omni-canale, aggiungere autorizzazioni Omni_Agent, riparare assegnazioni di autorizzazioni Omni mancanti o preparare gli agenti a utilizzare il widget Omni. NON ATTIVARE la creazione di set di autorizzazioni arbitrari, la creazione di agenti o l'appartenenza a code.
