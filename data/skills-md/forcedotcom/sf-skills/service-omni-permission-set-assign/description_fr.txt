Attribuez les ensembles d'autorisations Omni requis aux utilisateurs d'agent provisionnés. DÉCLENCHEUR lorsque les utilisateurs demandent d'attribuer des autorisations Omni aux agents, d'accorder un accès Omni-Channel, d'ajouter des autorisations Omni_Agent, de réparer les attributions d'autorisations Omni manquantes ou de préparer les agents à utiliser le widget Omni. NE PAS DÉCLENCHER en cas de création d'ensembles d'autorisations arbitraires, de création d'agent ou d'appartenance à une file d'attente.
