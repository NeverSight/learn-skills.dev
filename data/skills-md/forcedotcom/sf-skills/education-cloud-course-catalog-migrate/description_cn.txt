使用此技能可将课程目录数据从外部来源（CSV、PDF、网站）迁移，并在教育云中批量创建 Learning 和 LearningCourse 记录。当用户希望导入课程、解析课程目录文档或为学期设置课程目录时触发。处理多源数据摄取，智能解释课程结构（通过 IsLinkedOnly 标志链接的讲座+实验课程、学分、课程类型），通过 sObject REST API 批量创建，进行数据质量验证，解决已有课程的冲突，并识别缺口。说明缺失的内容（描述、类型）并请求额外来源。对多组件课程和冲突数据进行澄清时暂停。不要用于手动创建单个 Learning Course 记录、创建 Learning Programs（不同工作流）或用于注册/登记工作流。
