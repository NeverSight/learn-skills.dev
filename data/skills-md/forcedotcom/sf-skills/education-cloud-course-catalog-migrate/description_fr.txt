Utilisez cette compétence pour migrer les données du catalogue de cours à partir de sources externes (CSV, PDF, site Web) et créer en masse des enregistrements d'apprentissage et de cours d'apprentissage dans Education Cloud. Se déclenche lorsqu'un utilisateur souhaite importer des cours, analyser des documents de catalogue de cours ou configurer un catalogue de cours pour un trimestre universitaire. Gère l'ingestion de données multi-sources, l'interprétation intelligente des structures de cours (cours liés cours + laboratoire via l'indicateur IsLinkedOnly, heures de crédit, types de cours), la création de lots via l'API REST sObject, la validation de la qualité des données, la résolution des conflits pour les cours existants et l'identification des lacunes. Explique ce qui manque (descriptions, types) et demande des sources supplémentaires. Pauses pour clarifier les cours à plusieurs composants et les données contradictoires. NE PAS DÉCLENCHER pour la création manuelle d'enregistrements de cours de formation individuels, pour la création de programmes de formation (flux de travail différent) ou pour les flux de travail d'inscription/d'inscription.
