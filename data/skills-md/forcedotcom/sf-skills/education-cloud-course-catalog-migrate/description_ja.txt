このスキルを使用して、外部ソース (CSV、PDF、Web サイト) からコース カタログ データを移行し、Education Cloud で Learning レコードと LearningCourse レコードを一括作成します。ユーザーがコースのインポート、コース カタログ ドキュメントの解析、または学期のコース カタログのセットアップを希望するときにトリガーされます。マルチソース データの取り込み、コース構造のインテリジェントな解釈 (IsLinkedOnly フラグを介した講義とラボのリンクされたコース、単位時間、コース タイプ)、sObject REST API を介したバッチ作成、データ品質の検証、既存のコースの競合解決、およびギャップの特定を処理します。不足しているもの (説明、種類) を説明し、追加の情報源を要求します。複数のコンポーネントのコースと矛盾するデータを明確にするために一時停止します。個々の学習コース レコードを手動で作成する場合、学習プログラム (別のワークフロー) を作成する場合、または登録/登録ワークフローをトリガーしないでください。
