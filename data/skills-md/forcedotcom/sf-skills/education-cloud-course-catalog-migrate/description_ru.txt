Используйте этот навык для переноса данных каталога курсов из внешних источников (CSV, PDF, веб-сайт) и массового создания записей Learning и LearningCourse в Education Cloud. Срабатывает, когда пользователь хочет импортировать курсы, проанализировать документы каталога курсов или настроить каталог курсов для академического семестра. Управляет приемом данных из нескольких источников, интеллектуальной интерпретацией структур курса (курсы, связанные лекции + лабораторные работы через флаг IsLinkedOnly, кредитные часы, типы курсов), созданием пакетов через sObject REST API, проверкой качества данных, разрешением конфликтов для существующих курсов и выявлением пробелов. Объясняет, чего не хватает (описания, виды) и запрашивает дополнительные источники. Паузы для уточнения многокомпонентных курсов и противоречивых данных. НЕ ИСПОЛЬЗУЙТЕ для создания отдельных записей курса обучения вручную, для создания программ обучения (другой рабочий процесс) или для рабочих процессов зачисления/регистрации.
