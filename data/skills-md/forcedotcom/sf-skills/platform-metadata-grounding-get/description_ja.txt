Salesforce 組織にすでに存在するメタデータを、正確な API 名が分からなくても意味から見つけます。オブジェクト、項目、フロー、Apex クラス、ピックリスト値、権限セット、検証ルール、レコードタイプ、共有ルールなど、何を格納・実行しているかで検索するために使用します。類似したものが既に存在しないか確認するためにメタデータを作成する前、また Apex、LWC、SOQL、フローのロジックを書く前に実際の名前を確認するために使用します。項目、オブジェクト、検証ルールがどのように設定されているか、どのプロファイルや権限セットがその項目を読み取りまたは編集できるかを確認するためにも利用できます。Metadata Grounding MCP（search_metadata、query_metadata、describe_metadata）または Salesforce MCP 操作の searchMetadata、queryMetadata、describeMetadata を通じて機能します。組織に Salesforce Catalog が必要です。グラウンディング、SOQL、CLI の選択（platform-metadata-discovery-get を使用）、ソース取得（platform-metadata-retrieve）、または Data Cloud DLO と DMO スキーマ（data360-code-extension-generate）をトリガーしないでください。
