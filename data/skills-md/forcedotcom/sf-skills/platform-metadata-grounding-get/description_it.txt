Trova i metadati già presenti in un’organizzazione Salesforce per significato, quando non si conosce il nome API esatto. Usalo per individuare oggetti, campi, flow, classi Apex, valori di picklist, set di permessi, regole di convalida, tipi di record e regole di condivisione in base a ciò che memorizzano o a ciò che fanno. Utilizzalo prima di creare metadati per verificare se qualcosa di simile esiste già, e prima di scrivere Apex, LWC, SOQL o logica Flow per confermare i nomi reali. Servi per leggere come è configurato un campo, un oggetto o una regola di convalida, e quali profili e set di permessi possono leggere o modificare un campo. Funziona tramite il Metadata Grounding MCP (search_metadata, query_metadata, describe_metadata) o le operazioni Salesforce MCP searchMetadata, queryMetadata e describeMetadata. Richiede il Salesforce Catalog nell’organizzazione. NON ATTIVARE per scegliere tra grounding, SOQL e la CLI (usa platform-metadata-discovery-get), per recuperare il sorgente (platform-metadata-retrieve) o per lo schema Data Cloud DLO e DMO (data360-code-extension-generate).
