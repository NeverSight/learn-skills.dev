根據含義在 Salesforce 組織中找出已存在的中繼資料，當您不知道其確切的 API 名稱時使用。可用於依照物件、欄位、流程、Apex 類別、選取清單值、權限集、驗證規則、記錄類型與共享規則的功能或內容來搜尋。於建立中繼資料前先檢查是否已有類似項目，並在撰寫 Apex、LWC、SOQL 或 Flow 邏輯前確認真實名稱。可用於閱讀欄位、物件或驗證規則的設定，以及哪些設定檔與權限集能讀取或編輯該欄位。透過 Metadata Grounding MCP（search_metadata、query_metadata、describe_metadata）或 Salesforce MCP 操作 searchMetadata、queryMetadata、describeMetadata 來運作。需要組織內的 Salesforce 目錄。請勿觸發用於在 grounding、SOQL 與 CLI 之間作選擇（使用 platform-metadata-discovery-get）、取得來源（platform-metadata-retrieve）或 Data Cloud DLO 與 DMO 架構（data360-code-extension-generate）的流程。
