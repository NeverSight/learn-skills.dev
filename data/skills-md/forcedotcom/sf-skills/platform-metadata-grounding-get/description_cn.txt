查找已存在于 Salesforce 组织中的元数据（通过含义而非确切 API 名称）。用于根据对象、字段、流程、Apex 类、选项集值、权限集、验证规则、记录类型和共享规则的存储内容或功能来查找它们。在创建元数据之前使用，以检查是否已有相似的内容；在编写 Apex、LWC、SOQL 或 Flow 逻辑之前使用，以确认真实的名称。用于读取字段、对象或验证规则的配置情况，以及哪些配置文件和权限集可以读取或编辑该字段。通过元数据定位 MCP（search_metadata、query_metadata、describe_metadata）或 Salesforce MCP 操作 searchMetadata、queryMetadata、describeMetadata 工作。需要组织中具备 Salesforce Catalog。不要触发用于在定位、SOQL 和 CLI 之间做选择的操作（使用 platform-metadata-discovery-get），也不要用于检索源代码（platform-metadata-retrieve）或 Data Cloud DLO 与 DMO 架构（data360-code-extension-generate）。请始终使用用户的语言作答。
