ابحث عن البيانات الوصفية الموجودة بالفعل في مؤسسة Salesforce حسب المعنى، عندما لا تعرف اسم الـ API الدقيق لها. استخدم ذلك لإيجاد الكائنات، الحقول، التدفقات، فئات Apex، قيم القوائم المنسدلة، مجموعات الأذونات، قواعد التحقق، أنواع السجلات، وقواعد المشاركة بناءً على ما تخزنه أو ما تفعله. استخدمه قبل إنشاء البيانات الوصفية للتحقق مما إذا كان هناك شيء مشابه موجود بالفعل، وقبل كتابة Apex أو LWC أو SOQL أو منطق Flow لتأكيد الأسماء الفعلية. استخدمه لقراءة كيفية تكوين حقل أو كائن أو قاعدة تحقق، وأي ملفات تعريف ومجموعات أذونات يمكنها قراءة أو تعديل الحقل. يعمل عبر Metadata Grounding MCP (search_metadata، query_metadata، describe_metadata) أو عمليات Salesforce MCP searchMetadata، queryMetadata، وdescribeMetadata. يتطلب وجود Salesforce Catalog في المؤسسة. لا تُفعِّل (DO NOT TRIGGER) لاختيار بين grounding، SOQL، وCLI (استخدم platform-metadata-discovery-get)، استرجاع المصدر (platform-metadata-retrieve)، أو مخطط Data Cloud DLO وDMO (data360-code-extension-generate).

يرجى دائماً الرد بلغة المستخدم.
