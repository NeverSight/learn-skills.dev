Trouvez les métadonnées déjà présentes dans une organisation Salesforce par leur signification, lorsqu’on ne connaît pas leur nom API exact. Utilisez‑le pour trouver les objets, champs, flux, classes Apex, valeurs de listes de sélection, ensembles d’autorisations, règles de validation, types d’enregistrement et règles de partage en fonction de ce qu’ils contiennent ou de ce qu’ils font. Utilisez‑le avant de créer des métadonnées pour vérifier si quelque chose de similaire existe déjà, et avant d’écrire du code Apex, LWC, SOQL ou une logique Flow afin de confirmer les véritables noms. Utilisez‑le pour lire la configuration d’un champ, d’un objet ou d’une règle de validation, ainsi que les profils et ensembles d’autorisations qui peuvent lire ou modifier un champ. Fonctionne via le MCP Metadata Grounding (search_metadata, query_metadata, describe_metadata) ou les opérations Salesforce MCP searchMetadata, queryMetadata et describeMetadata. Nécessite le catalogue Salesforce dans l’organisation. NE PAS DÉCLENCHER pour choisir entre le grounding, le SOQL et la CLI (utilisez platform-metadata-discovery-get), récupérer le source (platform-metadata-retrieve), ou le schéma Data Cloud DLO et DMO (data360-code-extension-generate). Veuillez toujours répondre dans la langue de l'utilisateur.
