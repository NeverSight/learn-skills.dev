Используйте для создания или обновления записи QueueRoutingConfig в организации Salesforce через API данных (идемпотентное обнаружение SOQL + обновление REST). Именование зависит от цели: Case→Case_Routing_Config, VoiceCall→Voice_Routing_Config, Incident→Incident_Routing_Config, MessagingSession→Messaging_Routing_Config (через QRC_ROUTING_TARGET) или передается явное имя разработчика/метка/мощность/приоритет. RoutingModel MostAvailable (по умолчанию) или LeastActive. Триггеры: создание конфигурации маршрутизации обращений или голосовых сообщений, развертывание QueueRoutingConfig, настройка маршрутизации очереди для Omni Cases/Voice, настройка емкостиWeight для каждой очереди. Не используйте для маршрутизации на основе атрибутов (IsAttributeBased=true выходит за рамки) или моделей маршрутизации, отличных от MostAvailable/LeastActive.
