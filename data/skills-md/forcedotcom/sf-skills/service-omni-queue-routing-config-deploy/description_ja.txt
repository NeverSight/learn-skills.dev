Data API (冪等 SOQL 検出 + REST upsert) を介して Salesforce 組織で QueueRoutingConfig レコードを作成または更新するために使用します。名前付けはターゲットから派生します: Case→Case_Routing_Config、VoiceCall→Voice_Routing_Config、Incident→Incident_Routing_Config、MessagingSession→Messaging_Routing_Config (QRC_ROUTING_TARGET 経由)、または明示的な開発者名/ラベル/容量/優先度を渡します。 RoutingModel MostAvailable (デフォルト) または LeastActive。トリガー: ケースまたは音声ルーティング設定の作成、QueueRoutingConfig の展開、Omni Cases/Voice のキュー ルーティングの設定、キューごとの CapacityWeight の設定。属性ベースのルーティング (IsAttributeBased=true は範囲外です) または MostAvailable/LeastActive 以外のルーティング モデルには使用しないでください。
