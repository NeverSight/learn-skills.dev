Úselo para crear o actualizar un registro QueueRoutingConfig en una organización de Salesforce a través de la API de datos (detección SOQL idempotente + inserción REST). La denominación se deriva del objetivo: Caso→Case_Routing_Config, VoiceCall→Voice_Routing_Config, Incident→Incident_Routing_Config, MessagingSession→Messaging_Routing_Config (a través de QRC_ROUTING_TARGET), o pase un nombre/etiqueta/capacidad/prioridad de desarrollador explícito. Modelo de enrutamiento MostAvailable (predeterminado) o LeastActive. Activadores: cree una configuración de enrutamiento de casos o voz, implemente un QueueRoutingConfig, configure el enrutamiento de colas para Omni Cases/Voice, configure CapacityWeight por cola. No lo utilice para enrutamiento basado en atributos (IsAttributeBased=true está fuera del alcance) ni para modelos de enrutamiento que no sean MostAvailable/LeastActive.
