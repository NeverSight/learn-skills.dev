Zum Erstellen oder Aktualisieren eines QueueRoutingConfig-Datensatzes in einer Salesforce-Organisation über die Daten-API (idempotente SOQL-Erkennung + REST-Upsert). Die Benennung erfolgt zielabgeleitet: Case→Case_Routing_Config, VoiceCall→Voice_Routing_Config, Incident→Incident_Routing_Config, MessagingSession→Messaging_Routing_Config (über QRC_ROUTING_TARGET) oder übergeben Sie einen expliziten Entwicklernamen/-bezeichnung/-kapazität/-priorität. RoutingModel MostAvailable (Standard) oder LeastActive. Auslöser: Erstellen Sie eine Case- oder Voice-Routing-Konfiguration, stellen Sie eine QueueRoutingConfig bereit, richten Sie das Warteschlangen-Routing für Omni Cases/Voice ein, konfigurieren Sie CapacityWeight pro Warteschlange. Nicht für attributbasiertes Routing (IsAttributeBased=true liegt außerhalb des Gültigkeitsbereichs) oder andere Routingmodelle als MostAvailable/LeastActive verwenden.
