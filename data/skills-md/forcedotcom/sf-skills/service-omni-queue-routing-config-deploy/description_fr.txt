À utiliser pour créer ou mettre à jour un enregistrement QueueRoutingConfig sur une organisation Salesforce via l'API Data (détection SOQL idempotente + upsert REST). La dénomination est dérivée de la cible : Case→Case_Routing_Config, VoiceCall→Voice_Routing_Config, Incident→Incident_Routing_Config, MessagingSession→Messaging_Routing_Config (via QRC_ROUTING_TARGET), ou transmettez un nom/étiquette/capacité/priorité de développeur explicite. RoutingModel MostAvailable (par défaut) ou LeastActive. Déclencheurs : créez une configuration de routage Case ou Voice, déployez un QueueRoutingConfig, configurez le routage de file d'attente pour Omni Cases/Voice, configurez CapacityWeight par file d'attente. Ne pas utiliser pour le routage basé sur les attributs (IsAttributeBased=true est hors de portée) ou pour les modèles de routage autres que MostAvailable/LeastActive.
