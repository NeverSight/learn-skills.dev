Utilisez-le pour configurer et vérifier l'escalade agent-humain d'Agentforce, y compris le transfert humain, une file d'attente de secours dotée de personnel et les directives de seuil d'échec. Déclencheurs : configurer l'escalade d'agent, escalader vers un agent humain, transférer l'agent vers une file d'attente, configurer une file d'attente d'escalade humaine, définir un transfert de secours Agentforce. Ne pas utiliser pour créer un agent ou configurer le routage des canaux entrants ; utilisez service-agentforce-channel-configure pour le routage entrant.
