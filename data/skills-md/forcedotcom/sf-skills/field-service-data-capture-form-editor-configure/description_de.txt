Patchen Sie einen vorhandenen Datenerfassungsfluss, der bereits in einer verbundenen Salesforce-Organisation bereitgestellt ist. Ruft die Live-Flow-Metadaten im JSON-Format über die Tooling-API ab, wendet die vom Benutzer angeforderte Änderung an und fügt sie zurück. Wird verwendet, wenn der Benutzer einen vorhandenen Fluss benennt und darum bittet, ein Feld hinzuzufügen/zu entfernen/umzubenennen, die Sichtbarkeit zu ändern, einen Fehler zu beheben, visuellen Feinschliff hinzuzufügen oder einen Platzhalter gegen eine reale Komponente auszutauschen („Fügen Sie ein Notizenfeld zu Inventory_Transfer hinzu“, „korrigieren Sie die Sichtbarkeitsregel für Work_Order_Number“, „machen Sie die Teilewiederholung optional“, „ersetzen Sie den Signature-Platzhalter durch die echte dcSignature-Komponente“). Verwenden Sie diese Fähigkeit NICHT, um einen brandneuen Ablauf zu erstellen – das ist „fs-data-capture-form-designer“, gefolgt von „fs-data-capture-form-deployer“.
