Parchee un flujo de captura de datos existente que ya esté implementado en una organización de Salesforce conectada. Recupera el JSON de metadatos de flujo en vivo a través de la API de herramientas, aplica el cambio solicitado por el usuario y lo parchea. Úselo cuando el usuario nombra un flujo existente y solicita agregar/eliminar/cambiar el nombre de un campo, cambiar la visibilidad, corregir un error, agregar pulido visual o cambiar un marcador de posición por un componente real ("agregar un campo de Notas a Inventory_Transfer", "corregir la regla de visibilidad en Work_Order_Number", "hacer que el repetidor de piezas sea opcional", "reemplazar el marcador de posición de Firma con el componente dcSignature real"). NO utilice esta habilidad para crear un flujo completamente nuevo: es fs-data-capture-form-designer seguido de fs-data-capture-form-deployer.
