接続されている Salesforce 組織に既にデプロイされている既存のデータキャプチャ フローにパッチを適用します。ツール API を介してライブ フロー メタデータ JSON を取得し、ユーザーが要求した変更を適用して、パッチを適用します。ユーザーが既存のフローに名前を付け、フィールドの追加/削除/名前変更、表示設定の変更、バグの修正、視覚的な磨きの追加、または実際のコンポーネントのプレースホルダーの交換 (「Inventory_Transfer に Notes フィールドを追加する」、「Work_Order_Number の表示ルールを修正する」、「部品のリピーターをオプションにする」、「Signature プレースホルダーを実際の dcSignature コンポーネントに置き換える」) を要求する場合に使用します。このスキルをまったく新しいフローの構築に使用しないでください。つまり、fs-data-capture-form-designer の後に fs-data-capture-form-deployer が続くフローです。
