Исправьте существующий поток сбора данных, который уже развернут в подключенной организации Salesforce. Извлекает JSON метаданных потока в реальном времени через API инструментов, применяет запрошенные пользователем изменения и исправляет их обратно. Используйте, когда пользователь называет существующий поток и просит добавить/удалить/переименовать поле, изменить видимость, исправить ошибку, добавить визуальную доработку или заменить заполнитель для реального компонента («добавить поле примечаний в Inventory_Transfer», «исправить правило видимости для Work_Order_Number», «сделать повторитель деталей необязательным», «заменить заполнитель подписи реальным компонентом dcSignature»). НЕ используйте этот навык для создания совершенно нового потока — это fs-data-capture-form-designer, за которым следует fs-data-capture-form-deployer.
