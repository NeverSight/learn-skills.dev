연결된 Salesforce 조직에 이미 배포된 기존 데이터 캡처 흐름을 패치합니다. Tooling API를 통해 라이브 흐름 메타데이터 JSON을 검색하고, 사용자가 요청한 변경 사항을 적용하고, 다시 패치합니다. 사용자가 기존 흐름의 이름을 지정하고 필드 추가/제거/이름 바꾸기, 가시성 변경, 버그 수정, 시각적 개선 추가 또는 실제 구성 요소에 대한 자리 표시자 교체('Inventory_Transfer에 메모 필드 추가', 'Work_Order_Number의 가시성 규칙 수정', '부품 반복기를 선택 사항으로 설정', '서명 자리 표시자를 실제 dcSignature 구성 요소로 교체')를 요청할 때 사용합니다. 새로운 흐름(fs-data-capture-form-designer와 fs-data-capture-form-deployer)을 구축하는 데 이 기술을 사용하지 마십시오.
