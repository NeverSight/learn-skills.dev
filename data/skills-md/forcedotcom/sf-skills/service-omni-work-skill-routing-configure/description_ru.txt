Используйте для создания правила Omni WorkSkillRouting (критерии навыков на основе полей): сопоставьте значение поля связанной сущности с требуемым навыком Omni (например, добавьте навык голосовой связи, когда Case.Origin = Phone), развернутым как одна запись WorkSkillRouting через API метаданных. Идемпотент через сигнал Metadata API files[].state; одно правило для каждой связанной сущности. Триггеры: добавить маршрутизацию навыков на основе полей, маршрутизировать по полю Case к навыку, маршрутизировать по полю MessagingSession к навыку, настроить маршрутизацию навыков на основе атрибутов, потребовать навык Omni для значения поля. Не используйте для создания навыка или привязки к нему агентов (service-omni-skills-based-routing-configure), для создания пользователей агентов или для настройки очередей.
