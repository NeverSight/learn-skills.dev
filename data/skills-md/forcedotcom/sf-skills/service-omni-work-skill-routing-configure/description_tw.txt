用於編寫 Omni WorkSkillRouting 規則（基於欄位的技能標準）：將相關實體欄位值對應到所需的 Omni Skill（例如，當 Case.Origin = Phone 時新增語音技能），透過元資料 API 部署為一條 WorkSkillRouting 記錄。透過元資料 API files[].state 訊號實作冪等；每個相關實體一條規則。觸發器：新增基於欄位的技能路由、按 Case 欄位路由到技能、按 MessagingSession 欄位路由到技能、設定基於屬性的技能路由、需要欄位值的 Omni 技能。請勿用於建立技能或將代理程式綁定到該技能 (service-omni-skills-based-routing-configure)、建立代理用戶或設定佇列。
