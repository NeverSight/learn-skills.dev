Úselo para crear una regla Omni WorkSkillRouting (criterios de habilidad basados ​​en campos): asigne un valor de campo de entidad relacionada a una habilidad Omni requerida (por ejemplo, agregue la habilidad de voz cuando Case.Origin = Teléfono), implementada como un registro WorkSkillRouting a través de la API de metadatos. Idempotente a través de los archivos API de metadatos [].state señal; una regla por entidad relacionada. Activadores: agregar enrutamiento de habilidades basado en campos, enrutar mediante un campo Caso a una habilidad, enrutar mediante un campo MessagingSession a una habilidad, configurar enrutamiento de habilidades basado en atributos, requerir una habilidad Omni para un valor de campo. No lo utilice para crear la habilidad ni vincular agentes a ella (servicio-omni-skills-based-routing-configure), para crear usuarios de agentes ni para configurar colas.
