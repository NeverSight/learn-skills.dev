Omni WorkSkillRouting 규칙(필드 기반 기술 기준)을 작성하는 데 사용: 관련 엔터티 필드 값을 필수 Omni Skill에 매핑하고(예: Case.Origin = Phone인 경우 음성 기술 추가) 메타데이터 API를 통해 하나의 WorkSkillRouting 레코드로 배포됩니다. 메타데이터 API files[].state 신호를 통한 멱등성; 관련 엔터티당 하나의 규칙. 트리거: 필드 기반 기술 라우팅 추가, 사례 필드를 통해 기술로 라우팅, MessagingSession 필드를 통해 기술로 라우팅, 속성 기반 기술 라우팅 구성, 필드 값에 대해 Omni 기술 필요. 스킬을 생성하거나 에이전트를 여기에 바인딩(service-omni-skills-based-routing-configure)하거나 에이전트 사용자를 생성하거나 대기열을 구성하는 데 사용하지 마십시오.
