À utiliser pour créer une règle Omni WorkSkillRouting (critères de compétence basés sur le champ) : mapper une valeur de champ d'entité associée à une compétence Omni requise (par exemple, ajouter la compétence vocale lorsque Case.Origin = Phone), déployée en tant qu'enregistrement WorkSkillRouting via l'API de métadonnées. Idempotent via le signal API Metadata files[].state ; une règle par entité liée. Déclencheurs : ajoutez un routage de compétences basé sur le champ, acheminez par un champ de cas vers une compétence, acheminez par un champ MessagingSession vers une compétence, configurez le routage de compétences basé sur des attributs, exigez une compétence Omni pour une valeur de champ. Ne pas utiliser pour créer la compétence ou y lier des agents (service-omni-skills-based-routing-configure), pour créer des utilisateurs d'agent ou pour configurer des files d'attente.
