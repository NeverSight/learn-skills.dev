Omni WorkSkillRouting ルール (フィールドベースのスキル基準) を作成するために使用します。関連エンティティのフィールド値を必要なオムニ スキルにマップし (例: Case.Origin = Phone の場合に音声スキルを追加)、メタデータ API を介して 1 つの WorkSkillRouting レコードとしてデプロイされます。メタデータ API files[].state シグナルを介した冪等。関連エンティティごとに 1 つのルール。トリガー: フィールドベースのスキルルーティングの追加、Case フィールドによるスキルへのルーティング、MessagingSession フィールドによるスキルへのルーティング、属性ベースのスキルルーティングの構成、フィールド値の Omni スキルの必要性。スキルの作成やスキルへのエージェントのバインド (service-omni-skills-based-routing-configure)、エージェント ユーザーの作成、またはキューの構成には使用しないでください。
