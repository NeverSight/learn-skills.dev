استخدم لتأليف قاعدة Omni WorkSkillRouting (معايير المهارات المستندة إلى الحقل): قم بتعيين قيمة حقل كيان ذي صلة إلى Omni Skill المطلوبة (على سبيل المثال، أضف مهارة الصوت عندما يكون Case.Origin = Phone)، ويتم نشره كسجل WorkSkillRouting واحد عبر Metadata API. Idempotent عبر إشارة ملفات Metadata API[].state; قاعدة واحدة لكل كيان ذي صلة. المشغلات: إضافة توجيه المهارات المستندة إلى الحقل، والتوجيه بواسطة حقل حالة إلى مهارة، والتوجيه عبر حقل MessagingSession إلى مهارة، وتكوين توجيه المهارات المستندة إلى السمات، وتتطلب مهارة Omni لقيمة الحقل. لا تستخدم لإنشاء المهارة أو ربط الوكلاء بها (تكوين التوجيه القائم على المهارات الشاملة للخدمة)، أو لإنشاء مستخدمين وكيل، أو لتكوين قوائم الانتظار.
