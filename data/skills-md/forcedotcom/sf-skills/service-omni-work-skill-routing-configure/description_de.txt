Zum Erstellen einer Omni WorkSkillRouting-Regel (feldbasierte Fertigkeitskriterien) verwenden: Ordnen Sie einen Feldwert einer zugehörigen Entität einer erforderlichen Omni-Fertigkeit zu (z. B. fügen Sie die Voice-Fertigkeit hinzu, wenn Case.Origin = Telefon), bereitgestellt als ein WorkSkillRouting-Datensatz über die Metadaten-API. Idempotent über das Metadaten-API files[].state signal; eine Regel pro verbundener Entität. Auslöser: feldbasiertes Skill-Routing hinzufügen, von einem Case-Feld zu einem Skill weiterleiten, von einem MessagingSession-Feld zu einem Skill weiterleiten, attributbasiertes Skill-Routing konfigurieren, einen Omni-Skill für einen Feldwert erfordern. Nicht zum Erstellen des Skills oder zum Binden von Agenten daran (service-omni-skills-based-routing-configure), zum Erstellen von Agentbenutzern oder zum Konfigurieren von Warteschlangen verwenden.
