Utilisé pour lier les utilisateurs d'agent dans une file d'attente Salesforce via les POST de l'API de données GroupMember, avec une idempotence basée sur SOQL (réexécution sécurisée – insère uniquement les liaisons manquantes). Lie soit les agents de démonstration générés (agent{1..N}.<suffix>@example.com), soit une liste explicite d'agents réels transmis en tant que noms d'utilisateur/identifiants d'utilisateur. Déclencheurs : ajoutez des agents à une file d'attente Case/Voice, affectez des utilisateurs d'agent à une file d'attente, remplissez l'adhésion à la file d'attente pour le routage Omni. Ne pas utiliser pour créer la file d'attente (service-omni-queue-deploy), pour créer les utilisateurs de l'agent (service-omni-agent-users-create) ou pour attribuer des ensembles d'autorisations (service-omni-permission-set-assign).
