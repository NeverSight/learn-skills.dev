SOQL ベースの冪等性 (安全な再実行 - 欠落しているバインディングのみを挿入します) を使用して、GroupMember Data API POST 経由でエージェントユーザを Salesforce キューにバインドするために使用します。生成されたデモ エージェント (agent{1..N}.<suffix>@example.com) またはユーザー名/ユーザー ID として渡された実際のエージェントの明示的なリストのいずれかをバインドします。トリガー: エージェントを Case/Voice キューに追加し、エージェント ユーザーをキューに割り当て、オムニ ルーティングのキュー メンバーシップを設定します。キューの作成 (service-omni-queue-deploy)、エージェント ユーザーの作成 (service-omni-agent-users-create)、または権限セットの割り当て (service-omni-permission-set-assign) には使用しないでください。
