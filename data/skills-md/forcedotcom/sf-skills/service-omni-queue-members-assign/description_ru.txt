Используйте для привязки пользователей агента к очереди Salesforce через POST API данных GroupMember с идемпотентностью на основе SOQL (безопасный повторный запуск — вставляются только отсутствующие привязки). Связывает либо сгенерированные демонстрационные агенты (agent{1..N}.<суффикс>@example.com), либо явный список реальных агентов, передаваемых как имена пользователей/идентификаторы пользователей. Триггеры: добавление агентов в очередь обращений/голосовых сообщений, назначение пользователей агентов в очередь, заполнение членства в очереди для Omni-маршрутизации. Не используйте для создания очереди (service-omni-queue-deploy), для создания пользователей агента (service-omni-agent-users-create) или для назначения наборов разрешений (service-omni-permission-set-assign).
