يُستخدم لربط مستخدمي الوكلاء بقائمة انتظار Salesforce عبر GroupMember Data API POSTs، مع الفاعلية المستندة إلى SOQL (إعادة التشغيل الآمن - يُدرج فقط الارتباطات المفقودة). يربط إما الوكلاء التجريبيين الذين تم إنشاؤهم (agent{1..N}.<suffix>@example.com) أو قائمة صريحة من الوكلاء الحقيقيين الذين تم تمريرهم كأسماء مستخدمين/معرفات مستخدمين. المشغلات: إضافة وكلاء إلى قائمة انتظار الحالة/الصوت، وتعيين مستخدمي الوكلاء إلى قائمة انتظار، وملء عضوية قائمة الانتظار للتوجيه Omni. لا تستخدم لإنشاء قائمة الانتظار (service-omni-queue-deploy)، أو لإنشاء مستخدمي الوكيل (service-omni-agent-users-create)، أو لتعيين مجموعات الأذونات (service-omni-permission-set-sign).
