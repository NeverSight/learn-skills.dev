SOQL 기반 멱등성(안전한 재실행 - 누락된 바인딩만 삽입)을 통해 GroupMember Data API POST를 통해 에이전트 사용자를 Salesforce 대기열에 바인딩하는 데 사용됩니다. 생성된 데모 에이전트(agent{1..N}.<suffix>@example.com) 또는 사용자 이름/사용자 ID로 전달된 실제 에이전트의 명시적 목록을 바인딩합니다. 트리거: Case/Voice 대기열에 에이전트를 추가하고, 에이전트 사용자를 대기열에 할당하고, Omni 라우팅을 위한 대기열 구성원을 채웁니다. 대기열 생성(service-omni-queue-deploy), 에이전트 사용자 생성(service-omni-agent-users-create) 또는 권한 집합 할당(service-omni-permission-set-sign)에는 사용하지 마십시오.
