Úselo para vincular a los usuarios de agentes a una cola de Salesforce a través de POST de API de datos de GroupMember, con idempotencia basada en SOQL (reejecución segura: solo inserta los enlaces que faltan). Vincula los agentes de demostración generados (agente{1..N}.<sufijo>@ejemplo.com) o una lista explícita de agentes reales pasados ​​como nombres de usuario/ID de usuario. Activadores: agregue agentes a una cola de casos/voz, asigne usuarios de agentes a una cola, complete la membresía de la cola para el enrutamiento Omni. No lo utilice para crear la cola (service-omni-queue-deploy), para crear los usuarios del agente (service-omni-agent-users-create) ni para asignar conjuntos de permisos (service-omni-permission-set-assign).
