用於將 Omni PresenceUserConfig（線上狀態配置）部署為一個完整記錄元資料寫入，並一致設定拒絕/ACW 欄位：自動接受關閉、拒絕開啟、拒絕原因開啟（在同一包中部署 PresenceDeclineReason）以及對話後工作總結計時器。代理是透過使用者名稱分配的。透過元資料 API files[].state 訊號實現冪等。觸發器：建立線上狀態設定、為座席啟用拒絕 + 拒絕原因 + ACW 總結計時器、為使用者指派線上狀態設定。請勿用於 ServicePresenceStatus（單獨的技能）、對狀態的權限集存取或在 ServiceChannel 上設定通道級 ACW 計時器。
