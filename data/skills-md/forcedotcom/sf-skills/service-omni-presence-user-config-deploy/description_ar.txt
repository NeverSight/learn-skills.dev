يُستخدم لنشر Omni PresenceUserConfig (تكوين التواجد) كسجل واحد كامل لكتابة بيانات التعريف مع تعيين حقول الرفض/ACW بشكل متسق: إيقاف القبول التلقائي، تشغيل الرفض، تشغيل سبب الرفض (مع نشر PresenceDeclineReason في نفس الحزمة)، ومؤقت اختتام العمل بعد المحادثة. يتم تعيين الوكلاء عن طريق اسم المستخدم. Idempotent عبر إشارة ملفات Metadata API [].state. المشغلات: إنشاء تكوين الحضور، وتمكين الرفض + سبب الرفض + مؤقت اختتام ACW للوكلاء، وتعيين تكوين الحضور للمستخدمين. لا تستخدمه مع ServicePresenceStatus (مهارة منفصلة)، أو للوصول إلى الحالات من خلال مجموعة الأذونات، أو لتعيين مؤقت ACW على مستوى القناة على ServiceChannel.
