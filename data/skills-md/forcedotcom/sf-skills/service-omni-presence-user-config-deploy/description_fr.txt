À utiliser pour déployer un Omni PresenceUserConfig (configuration de présence) sous la forme d'une écriture de métadonnées d'enregistrement complet avec les champs de refus/ACW définis de manière cohérente : acceptation automatique désactivée, refus activé, motif du refus activé (avec un PresenceDeclineReason déployé dans le même package) et un minuteur de conclusion après la conversation. Les agents sont attribués par nom d'utilisateur. Idempotent via le signal Metadata API files[].state. Déclencheurs : créer une configuration de présence, activer le refus + motif de refus + minuteur de conclusion ACW pour les agents, attribuer une configuration de présence aux utilisateurs. Ne pas utiliser pour ServicePresenceStatus (compétence distincte), pour un accès défini aux statuts ou pour définir la minuterie ACW au niveau du canal sur un ServiceChannel.
