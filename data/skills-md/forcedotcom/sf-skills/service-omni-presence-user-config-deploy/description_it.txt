Da utilizzare per distribuire un Omni PresenceUserConfig (configurazione della presenza) come scrittura di metadati dell'intero record con i campi di rifiuto/ACW impostati in modo coerente: Accettazione automatica disattivata, Rifiuto attivato, Motivo del rifiuto attivato (con un PresenceDeclineReason distribuito nello stesso pacchetto) e un timer di riepilogo post-conversazione-lavoro. Gli agenti vengono assegnati tramite nome utente. Idempotente tramite il segnale dei file API dei metadati[].state. Trigger: crea configurazione di presenza, abilita il rifiuto + motivo del rifiuto + timer di riepilogo ACW per gli agenti, assegna la configurazione di presenza agli utenti. Non utilizzare per ServicePresenceStatus (competenza separata), per l'accesso agli stati con set di autorizzazioni o per impostare il timer ACW a livello di canale su un ServiceChannel.
