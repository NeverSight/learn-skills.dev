거부/ACW 필드가 일관되게 설정된 단일 전체 레코드 메타데이터 쓰기로 Omni PresenceUserConfig(현재 상태 구성)를 배포하는 데 사용됩니다. 자동 수락 꺼짐, 거부 켜짐, 거부 이유 켜짐(동일한 패키지에 PresenceDeclineReason 배포됨) 및 대화 후 작업 마무리 타이머. 에이전트는 사용자 이름으로 할당됩니다. Metadata API files[].state 신호를 통한 멱등성. 트리거: 현재 상태 구성 생성, 상담원에 대한 거부 + 거부 이유 + ACW 마무리 타이머 활성화, 사용자에게 현재 상태 구성 할당. ServicePresenceStatus(별도 기술), 상태에 대한 권한 설정 액세스 또는 ServiceChannel에서 채널 수준 ACW 타이머 설정을 위해 사용하지 마십시오.
