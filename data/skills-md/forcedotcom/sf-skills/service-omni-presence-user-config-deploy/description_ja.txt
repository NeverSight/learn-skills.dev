Omni PresenceUserConfig (プレゼンス構成) を、拒否/ACW フィールドが一貫して設定された 1 つのレコード全体のメタデータ書き込みとしてデプロイするために使用します: 自動受け入れオフ、拒否オン、拒否理由オン (同じパッケージにデプロイされた PresenceDeclineReason を使用)、および After-Conversation-Work ラップアップ タイマー。エージェントはユーザー名によって割り当てられます。メタデータ API の files[].state シグナルを介した冪等。トリガー: プレゼンス設定を作成し、エージェントの辞退 + 辞退理由 + ACW ラップアップ タイマーを有効にし、プレゼンス設定をユーザーに割り当てます。 ServicePresenceStatus (別のスキル)、ステータスへの権限セット アクセス、または ServiceChannel でのチャネル レベルの ACW タイマーの設定には使用しないでください。
