Используйте для развертывания Omni PresenceUserConfig (конфигурация присутствия) как одну запись метаданных всей записи с последовательно установленными полями отклонения/ACW: автоматическое принятие отключено, отклонение включено, причина отклонения включена (с PresenceDeclineReason, развернутым в том же пакете) и таймером завершения работы после разговора. Агенты назначаются по имени пользователя. Идемпотент через сигнал Metadata API files[].state. Триггеры: создание конфигурации присутствия, включение отклонения + причина отклонения + таймер завершения ACW для агентов, назначение конфигурации присутствия пользователям. Не используйте для ServicePresenceStatus (отдельный навык), для доступа к статусам с установлением разрешений или для установки таймера ACW на уровне канала в ServiceChannel.
