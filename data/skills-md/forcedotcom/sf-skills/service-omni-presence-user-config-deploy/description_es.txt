Úselo para implementar Omni PresenceUserConfig (configuración de presencia) como una escritura de metadatos de registro completo con los campos de rechazo/ACW configurados de manera consistente: aceptación automática desactivada, rechazo activado, motivo de rechazo activado (con un PresenceDeclineReason implementado en el mismo paquete) y un temporizador de conclusión del trabajo después de la conversación. Los agentes se asignan por nombre de usuario. Idempotente a través de la señal de archivos API de metadatos [].state. Activadores: crear configuración de presencia, habilitar rechazo + motivo de rechazo + temporizador de finalización de ACW para agentes, asignar configuración de presencia a los usuarios. No lo use para ServicePresenceStatus (habilidad separada), para acceso con permisos establecidos a estados o para configurar el temporizador ACW a nivel de canal en un ServiceChannel.
