使用此技能将 TPM 负债计提数据套件端到端部署到 Salesforce org。当客户或团队成员想要安装计提引擎、验证 Data Cloud 连接、部署 Data Kit 组件以及安排导出和计提计算链时调用。触发短语包括：“部署计提数据套件”“设置负债计提”“安装 TPM 计提”“无头计提设置”“配置 Data Cloud 导出连接器”“安排计提链”。请勿仅用于创建 Data Space（使用 platform-dataspace-access-configure）、用于通用 Salesforce 元数据部署（使用 platform-metadata-deploy）、仅用于查询 org 数据（使用 platform-soql-query），或在为交易促销效果（TPE）功能设置数据套件时使用（请改用 consumer-goods-tpe-datakit-deploy）。请始终使用用户的语言作答。
