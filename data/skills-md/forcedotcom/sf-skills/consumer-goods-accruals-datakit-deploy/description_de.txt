Verwenden Sie diese Fähigkeit, um das TPM Liability Accruals Data Kit End‑to‑End in einer Salesforce‑Organisation zu deployen. Rufen Sie sie auf, wenn ein Kunde oder Teammitglied die Accrual‑Engine installieren, die Data‑Cloud-Verbindung prüfen, die Data‑Kit‑Komponenten bereitstellen und die Export‑ und Accrual‑Berechnungskette planen möchte. Trigger‑Phrasen umfassen: „deploy the accrual data kit“, „set up liability accruals“, „install TPM accruals“, „headless accruals setup“, „configure the Data Cloud export connector“, „schedule the accrual chain“. Verwenden Sie sie NICHT, um allein einen Data Space zu erstellen (nutzen Sie platform-dataspace-access-configure), für generische Salesforce‑Metadaten‑Deployments (nutzen Sie platform-metadata-deploy), ausschließlich zum Abfragen von Org‑Daten (nutzen Sie platform-soql-query) oder beim Einrichten des Data Kits für die Trade Promotion Effectiveness (TPE)‑Funktion (nutzen Sie stattdessen consumer-goods-tpe-datakit-deploy).

Bitte antworten Sie immer in der Sprache des Benutzers.
