Utilisez cette compétence pour déployer le kit de données TPM Liability Accruals de bout en bout dans une organisation Salesforce. Appelez‑la lorsqu’un client ou un collègue souhaite installer le moteur d’accumulation, vérifier la connexion Data Cloud, déployer les composants du Data Kit et planifier la chaîne d’exportation et de calcul des accumulations. Les phrases déclencheuses incluent : « déployer le kit de données d’accumulation », « configurer les accumulations de passif », « installer les accumulations TPM », « configuration sans tête des accumulations », « configurer le connecteur d’exportation Data Cloud », « planifier la chaîne d’accumulation ». NE l’utilisez PAS uniquement pour créer un Data Space (utilisez platform-dataspace-access-configure), pour le déploiement générique de métadonnées Salesforce (utilisez platform-metadata-deploy), pour interroger seulement les données de l’org (utilisez platform-soql-query), ou lors de la mise en place du kit de données pour la fonctionnalité Trade Promotion Effectiveness (TPE) (utilisez consumer-goods-tpe-datakit-deploy à la place).
