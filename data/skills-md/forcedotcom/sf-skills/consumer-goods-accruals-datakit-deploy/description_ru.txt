Используйте это умение для полного развертывания набора данных TPM Liability Accruals в организации Salesforce. Вызывайте его, когда клиент или коллега хочет установить механизм начисления, проверить соединение с Data Cloud, развернуть компоненты Data Kit и запланировать цепочку экспорта и расчёта начислений. Фразы‑триггеры включают: «развернуть набор данных начислений», «настроить начисления обязательств», «установить TPM начисления», «настройка безголовых начислений», «сконфигурировать коннектор экспорта Data Cloud», «запланировать цепочку начислений». НЕ используйте для создания только Data Space (используйте platform-dataspace-access-configure), для общего развертывания метаданных Salesforce (используйте platform-metadata-deploy), только для запросов данных организации (используйте platform-soql-query) или при настройке набора данных для функции Trade Promotion Effectiveness (TPE) (используйте consumer-goods-tpe-datakit-deploy вместо этого).

Пожалуйста, всегда отвечайте на языке пользователя.
