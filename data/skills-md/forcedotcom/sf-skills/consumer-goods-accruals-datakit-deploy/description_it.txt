Utilizza questa skill per distribuire end‑to‑end il data kit TPM Liability Accruals in un’organizzazione Salesforce. Invocala quando un cliente o un collega desidera installare il motore di accrual, verificare la connessione Data Cloud, distribuire i componenti del Data Kit e programmare la catena di esportazione e calcolo delle accrual. Le frasi di attivazione includono: “deploy the accrual data kit”, “set up liability accruals”, “install TPM accruals”, “headless accruals setup”, “configure the Data Cloud export connector”, “schedule the accrual chain”. NON usarla per creare solo un Data Space (usa platform-dataspace-access-configure), per il deployment generico di metadata Salesforce (usa platform-metadata-deploy), per interrogare solo i dati dell’org (usa platform-soql-query), o quando si configura il data kit per la funzionalità Trade Promotion Effectiveness (TPE) (usa consumer-goods-tpe-datakit-deploy invece).

Rispondi sempre nella lingua dell’utente.
