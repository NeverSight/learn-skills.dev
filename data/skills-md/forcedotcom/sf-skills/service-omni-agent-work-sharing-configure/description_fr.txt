À utiliser pour configurer ou vérifier la visibilité d'AgentWork à l'échelle de l'organisation pour les superviseurs après confirmation explicite. Déclencheurs : permettre aux superviseurs de lire AgentWork, configurer le partage d'AgentWork, vérifier AgentWork OWD, rendre AgentWork visible aux superviseurs, modifier l'accès interne d'AgentWork. Ne pas utiliser pour filtrer les commerciaux qui apparaissent dans Command Center ; utilisez service-omni-supervisor-config-deploy pour cela.
