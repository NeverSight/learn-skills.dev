Используйте для настройки или проверки видимости AgentWork в масштабах всей организации для руководителей после явного подтверждения. Триггеры: разрешить супервизорам читать AgentWork, настроить общий доступ к AgentWork, проверить AgentWork OWD, сделать AgentWork видимым для супервизоров, изменить внутренний доступ AgentWork. Не используйте для фильтрации представителей, отображаемых в Командном центре; используйте для этого service-omni-supervisor-config-deploy.
