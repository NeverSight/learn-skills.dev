Úselo para configurar o verificar la visibilidad de AgentWork en toda la organización para los supervisores después de una confirmación explícita. Activadores: permitir que los supervisores lean AgentWork, configurar el uso compartido de AgentWork, verificar AgentWork OWD, hacer que AgentWork sea visible para los supervisores, cambiar el acceso interno de AgentWork. No lo utilice para filtrar qué representantes aparecen en el Centro de comando; use service-omni-supervisor-config-deploy para eso.
