Utilice esta habilidad para enumerar, ver o administrar proyectos de DevOps Center en una organización de Salesforce: mostrar todos los proyectos, crear un nuevo proyecto o actualizar el nombre, la descripción o el estado activo de un proyecto existente. Invóquelo para ejecutar la lista de proyectos de sf devops siempre que el usuario quiera mostrar, ver, visualizar o enumerar los proyectos disponibles, comprobar cuáles o cuántos proyectos del Centro DevOps existen o buscar un ID de proyecto; incluso una solicitud de listado simple debería utilizar esta habilidad en lugar de una herramienta sin formato o una respuesta directa. También invoque para crear un proyecto, configurar una nueva base de canalización de implementación, inicializar DevOps Center para una nueva característica, actualizar la configuración del proyecto como el nombre y la descripción, o activar/desactivar (archivar) un proyecto. Consolida las operaciones de lista/creación/actualización de proyectos de sf devops. NO DISPARE para elementos de trabajo, procesos, promociones u operaciones de conflicto; esas son habilidades separadas.
