Verwenden Sie diesen Skill, um DevOps Center-Projekte in einer Salesforce-Organisation aufzulisten, anzuzeigen oder zu verwalten – zeigen Sie alle Projekte an, erstellen Sie ein neues Projekt oder aktualisieren Sie den Namen, die Beschreibung oder den aktiven Status eines vorhandenen Projekts. Rufen Sie es auf, um sf devops project list immer dann auszuführen, wenn der Benutzer verfügbare Projekte anzeigen, anzeigen, anzeigen oder auflisten möchte, überprüfen möchte, welche oder wie viele DevOps Center-Projekte vorhanden sind, oder eine Projekt-ID nachschlagen möchte – selbst bei einer einfachen Auflistungsanfrage sollte diese Fähigkeit anstelle eines reinen Tools oder einer direkten Antwort verwendet werden. Rufen Sie auch auf, um ein Projekt zu erstellen, eine neue Bereitstellungspipeline-Grundlage einzurichten, DevOps Center für eine neue Funktion zu initialisieren, Projekteinstellungen wie Name und Beschreibung zu aktualisieren oder ein Projekt zu aktivieren/deaktivieren (archivieren). Konsolidiert Vorgänge zum Auflisten/Erstellen/Aktualisieren von SF-Devops-Projekten. NICHT für Arbeitselement-, Pipeline-, Heraufstufungs- oder Konfliktvorgänge auslösen – das sind separate Fähigkeiten.
