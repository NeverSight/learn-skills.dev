استخدم هذه المهارة لسرد مشاريع DevOps Center أو عرضها أو إدارتها في مؤسسة Salesforce — اعرض جميع المشاريع، أو أنشئ مشروعًا جديدًا، أو قم بتحديث اسم المشروع الحالي أو وصفه أو حالته النشطة. قم باستدعائها لتشغيل قائمة مشاريع sf devops عندما يريد المستخدم عرض المشاريع المتاحة أو مشاهدتها أو عرضها أو إدراجها، أو التحقق من عدد مشاريع DevOps Center الموجودة أو عددها، أو البحث عن معرف المشروع - حتى طلب القائمة العادي يجب أن يستخدم هذه المهارة بدلاً من أداة أولية أو إجابة مباشرة. قم أيضًا بالاستدعاء لإنشاء مشروع، أو إعداد أساس خط أنابيب نشر جديد، أو تهيئة DevOps Center لميزة جديدة، أو تحديث إعدادات المشروع مثل الاسم والوصف، أو تنشيط/إلغاء تنشيط (أرشفة) مشروع. يدمج عمليات إنشاء/تحديث قائمة المشاريع/إنشاء/تحديث sf. لا تقم بالتحفيز على عنصر العمل أو خط الأنابيب أو الترقية أو عمليات الصراع - فهذه مهارات منفصلة.
