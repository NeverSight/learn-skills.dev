Utilisez cette compétence pour répertorier, afficher ou gérer les projets DevOps Center dans une organisation Salesforce : afficher tous les projets, créer un nouveau projet ou mettre à jour le nom, la description ou l'état actif d'un projet existant. Appelez-le pour exécuter la liste de projets sf devops chaque fois que l'utilisateur souhaite afficher, voir, afficher ou répertorier les projets disponibles, vérifier quels ou combien de projets DevOps Center existent, ou rechercher un ID de projet - même une demande de liste simple doit utiliser cette compétence plutôt qu'un outil brut ou une réponse directe. Invoquez également pour créer un projet, configurer une nouvelle base de pipeline de déploiement, initialiser DevOps Center pour une nouvelle fonctionnalité, mettre à jour les paramètres du projet tels que le nom et la description, ou activer/désactiver (archiver) un projet. Consolide les opérations de liste/création/mise à jour de projets SF Devops. NE PAS DÉCLENCHER pour les opérations d'élément de travail, de pipeline, de promotion ou de conflit : ce sont des compétences distinctes.
