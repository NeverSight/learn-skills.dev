このスキルを使用して、Salesforce 組織内の DevOps Center プロジェクトを一覧表示、表示、または管理します。すべてのプロジェクトを表示したり、新しいプロジェクトを作成したり、既存のプロジェクトの名前、説明、アクティブステータスを更新したりできます。ユーザーが利用可能なプロジェクトを表示、表示、表示、またはリストしたい場合、存在する DevOps Center プロジェクトの種類または数を確認したい場合、またはプロジェクト ID を検索したい場合に、これを呼び出して sf devops project list を実行します。単純なリスト要求であっても、生のツールや直接の回答ではなく、このスキルを使用する必要があります。また、プロジェクトの作成、新しいデプロイメント パイプライン基盤のセットアップ、新しい機能用の DevOps Center の初期化、名前や説明などのプロジェクト設定の更新、またはプロジェクトのアクティブ化/非アクティブ化 (アーカイブ) を行うためにも呼び出します。 sf devops プロジェクトのリスト/作成/更新操作を統合します。作業項目、パイプライン、プロモーション、または競合操作についてはトリガーしないでください。これらは別のスキルです。
