Design, render and measure game sound effects as code with plinkfx. Use when the user wants a sound effect for a game or UI ("a heavy door for a dungeon", "a softer coin", "a laser that sounds like 1985"), wants to tweak an existing plinkfx sound, or needs WAV/OGG files of game sounds. Produces a plinkfx parameter object plus a WAV, checked against loudness and peak limits. Runs locally through the plinkfx CLI; no network, no AI audio models.
