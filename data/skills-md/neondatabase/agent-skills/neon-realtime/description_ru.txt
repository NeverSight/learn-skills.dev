Neon Realtime делает любой SQL‑запрос живым. Создавайте realtime‑ и реактивные приложения и агентов на Lakebase Postgres с живыми SQL‑запросами и примитивами реактивности. Используйте, когда UI приложения или состояние агента должны обновляться в реальном времени из строк базы данных (дашборды, ленты, совместная работа, синхронизация между несколькими пользователями или устройствами), для оптимистичных мутаций или чтобы заменить опрос или другие системы realtime‑синхронизации. Триггеры включают «live query», «subscribe», «sync engine», «useLiveQuery», «TanStack DB», «optimistic updates», «@neon/realtime». Для пуш‑сообщений, не связанных со строками базы данных (присутствие, набор текста, потоки LLM), используйте neon-functions.
