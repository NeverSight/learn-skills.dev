Neon Realtime 让任何 SQL 查询成为实时的。使用 Live SQL 查询和响应式原语，在 Lakebase Postgres 上构建实时、响应式的应用和代理。适用于应用 UI 或代理状态必须实时从数据库行更新的场景（仪表板、信息流、协作、多用户或多设备同步）、乐观变更，或替代轮询或其他实时同步系统。触发器包括“live query”“subscribe”“sync engine”“useLiveQuery”“TanStack DB”“optimistic updates”“@neon/realtime”。对于不是来自数据库行的推送（在线状态、输入提示、LLM 流），请使用 neon-functions。
