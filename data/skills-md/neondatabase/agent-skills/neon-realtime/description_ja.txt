Neon Realtime は任意の SQL クエリをリアルタイム化します。Lakebase Postgres 上でライブ SQL クエリとリアクティビティプリミティブを使用して、リアルタイム・リアクティブなアプリやエージェントを構築できます。アプリの UI やエージェントの状態をデータベース行からリアルタイムに更新する必要がある場合（ダッシュボード、フィード、コラボレーション、マルチユーザーまたはマルチデバイス同期）、楽観的なミューテーションを行う場合、またはポーリングや他のリアルタイム同期システムを置き換える場合に使用します。トリガーには「live query」「subscribe」「sync engine」「useLiveQuery」「TanStack DB」「optimistic updates」「@neon/realtime」などがあります。データベース行から来ないプッシュ（プレゼンス、タイピング、LLM ストリーム）には neon-functions を使用してください。
