Neon Realtime は任意の SQL クエリをリアルタイムにします。Lakebase Postgres 上でライブ SQL クエリとリアクティビティプリミティブを使用して、リアルタイムで反応的なアプリやエージェントを構築できます。アプリの UI やエージェントの状態をデータベースの行からリアルタイムに更新する必要がある場合（ダッシュボード、フィード、コラボレーション、マルチユーザーまたはマルチデバイスの同期）、楽観的ミューテーションのため、またはポーリングやその他のリアルタイム同期システムの代替として使用します。トリガーには「live query」「subscribe」「sync engine」「useLiveQuery」「TanStack DB」「optimistic updates」「@neon/realtime」などがあります。データベースの行から来ないプッシュ（プレゼンス、タイピング、LLM ストリーム）には neon‑functions を使用してください。
