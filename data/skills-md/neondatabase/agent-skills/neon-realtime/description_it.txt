Neon Realtime rende qualsiasi query SQL in tempo reale. Crea app e agenti reattivi in tempo reale su Lakebase Postgres con query SQL live e primitive di reattività. Usalo quando l’interfaccia dell’app o lo stato dell’agente devono aggiornarsi in tempo reale dalle righe del database (dashboard, feed, collaborazione, sincronizzazione multi‑utente o multi‑dispositivo), per mutazioni ottimistiche, o per sostituire il polling o altri sistemi di sincronizzazione in tempo reale. I trigger includono "live query", "subscribe", "sync engine", "useLiveQuery", "TanStack DB", "optimistic updates", "@neon/realtime". Per push che non provengono dalle righe del database (presenza, digitazione, flussi LLM), usa neon-functions.
