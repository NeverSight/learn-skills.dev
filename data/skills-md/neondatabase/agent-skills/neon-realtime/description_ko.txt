Neon Realtime는 모든 SQL 쿼리를 실시간으로 만듭니다. Lakebase Postgres에서 실시간 SQL 쿼리와 반응성 프리미티브를 사용해 실시간·반응형 앱과 에이전트를 구축하세요. 앱 UI나 에이전트 상태가 데이터베이스 행으로부터 실시간으로 업데이트되어야 할 때(대시보드, 피드, 협업, 다중 사용자·다중 디바이스 동기화), 낙관적 뮤테이션을 위해, 혹은 폴링이나 기타 실시간 동기화 시스템을 대체하려는 경우에 사용합니다. 트리거에는 “live query”, “subscribe”, “sync engine”, “useLiveQuery”, “TanStack DB”, “optimistic updates”, “@neon/realtime”가 포함됩니다. 데이터베이스 행에서 비롯되지 않는 푸시(존재감, 타이핑, LLM 스트림 등)의 경우에는 neon‑functions를 사용하세요.
