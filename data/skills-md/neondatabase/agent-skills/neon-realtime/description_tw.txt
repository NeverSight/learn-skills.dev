Neon Realtime 讓任何 SQL 查詢即時化。透過即時 SQL 查詢與反應式原語，在 Lakebase Postgres 上構建即時、反應式的應用程式與代理。當應用程式 UI 或代理狀態必須即時根據資料庫列更新（如儀表板、資訊流、協作、多使用者或多裝置同步）時使用，適用於樂觀變更，或取代輪詢或其他即時同步系統。觸發器包括「live query」、「subscribe」、「sync engine」、「useLiveQuery」、「TanStack DB」、「optimistic updates」以及「@neon/realtime」。若需要推送的資訊不來自資料庫列（如在場狀態、輸入中、LLM 串流），請使用 neon-functions。
