Neon Realtime rend n'importe quelle requête SQL en direct. Créez des applications et des agents réactifs en temps réel sur Lakebase Postgres avec des requêtes SQL en direct et des primitives de réactivité. Utilisez-le lorsque l'interface utilisateur de l'application ou l'état d'un agent doit se mettre à jour en direct à partir des lignes de la base de données (tableaux de bord, flux, collaboration, synchronisation multi‑utilisateur ou multi‑appareil), pour des mutations optimistes, ou pour remplacer le polling ou d'autres systèmes de synchronisation en temps réel. Les déclencheurs incluent « live query », « subscribe », « sync engine », « useLiveQuery », « TanStack DB », « optimistic updates », « @neon/realtime ». Pour les push qui ne proviennent pas des lignes de la base de données (présence, saisie, flux LLM), utilisez neon-functions.
