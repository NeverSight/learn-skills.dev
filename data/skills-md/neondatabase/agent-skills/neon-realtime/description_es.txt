Neon Realtime hace que cualquier consulta SQL sea en tiempo real. Construye aplicaciones y agentes reactivos en tiempo real sobre Lakebase Postgres con consultas SQL en vivo y primitivas de reactividad. Úsalo cuando la interfaz de usuario de la aplicación o el estado del agente deban actualizarse en tiempo real a partir de filas de la base de datos (tableros, feeds, colaboración, sincronización multiusuario o multidispositivo), para mutaciones optimistas, o para reemplazar el sondeo u otros sistemas de sincronización en tiempo real. Los disparadores incluyen "consulta en vivo", "suscribirse", "motor de sincronización", "useLiveQuery", "TanStack DB", "actualizaciones optimistas", "@neon/realtime". Para notificaciones push que no provienen de filas de la base de datos (presencia, escritura, flujos de LLM), usa neon-functions.
