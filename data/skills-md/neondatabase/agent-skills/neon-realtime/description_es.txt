Neon Realtime hace que cualquier consulta SQL sea en tiempo real. Construye aplicaciones y agentes reactivos en tiempo real sobre Lakebase Postgres con consultas SQL en vivo y primitivas de reactividad. Úsalo cuando la interfaz de la aplicación o el estado del agente deben actualizarse en tiempo real a partir de filas de la base de datos (tableros, feeds, colaboración, sincronización multiusuario o multidispositivo), para mutaciones optimistas o para reemplazar sondeos u otros sistemas de sincronización en tiempo real. Los disparadores incluyen "live query", "subscribe", "sync engine", "useLiveQuery", "TanStack DB", "optimistic updates", "@neon/realtime". Para notificaciones que no provienen de filas de la base de datos (presencia, escritura, flujos de LLM), usa neon-functions.
