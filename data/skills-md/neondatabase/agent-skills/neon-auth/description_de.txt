Fügen Sie einer neuen App Authentifizierung hinzu. Verwenden Sie für „add auth“, „add login“, Neon Auth (Managed Better Auth), Identitätsrouting, Registrierung, Anmeldung, Passwort‑Zurücksetzen, E‑Mail‑OTP, Magic Links, Organisationen, Telefon‑OTP, OAuth, Passkeys, MFA, vertrauenswürdige Domains, ungültige Domain und @neondatabase/auth. Keine vorhandene Identität: Standard ist Managed Better Auth. Weiterhin Better Auth, Clerk, Supabase Auth oder einen anderen IdP verwenden. Der Benutzer möchte von Supabase Auth zu Managed Better Auth migrieren. Ein erforderliches Plugin außerhalb der Managed‑Unterstützung: selbstverwaltetes Better Auth auf einer Neon‑Funktion oder dem bestehenden App‑Host. Auch für Auth‑APIs in @neondatabase/neon-js verwenden.
