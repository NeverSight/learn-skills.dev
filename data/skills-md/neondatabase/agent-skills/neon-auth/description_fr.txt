Ajoutez l'authentification à une nouvelle application. Utilisez pour « add auth », « add login », Neon Auth (Managed Better Auth), le routage d'identité, l'inscription, la connexion, la réinitialisation du mot de passe, l'OTP par e‑mail, les liens magiques, les organisations, l'OTP par téléphone, OAuth, les passkeys, MFA, les domaines de confiance, le domaine invalide et @neondatabase/auth. Aucun compte existant : par défaut Managed Better Auth. Continuez à travailler avec Better Auth, Clerk, Supabase Auth ou un autre IdP. L'utilisateur a demandé de migrer de Supabase Auth : Managed Better Auth. Un plugin requis en dehors du support Managed : Better Auth auto‑géré sur une fonction Neon ou sur l’hôte de l’application existante. Utilisez également pour les API d'authentification dans @neondatabase/neon-js.
