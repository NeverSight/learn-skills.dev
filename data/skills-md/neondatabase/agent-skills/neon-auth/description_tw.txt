為新的應用程式新增驗證功能。用於「add auth」、 「add login」、 Neon Auth（Managed Better Auth）、身份路由、註冊、登入、密碼重設、電子郵件 OTP、魔法連結、組織、電話 OTP、OAuth、通行密鑰、MFA、受信任的域名、無效域名，以及 @neondatabase/auth。若沒有既有身分識別：預設使用 Managed Better Auth。持續使用 Better Auth、Clerk、Supabase Auth 或其他 IdP。使用者要求從 Supabase Auth 移行至 Managed Better Auth。需要的外部插件支援未包含於 Managed：在 Neon Function 或現有應用主機上自行管理的 Better Auth。同時用於 @neondatabase/neon-js 中的驗證 API。
