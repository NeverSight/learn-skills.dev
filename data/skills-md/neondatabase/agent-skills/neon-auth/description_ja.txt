新しいアプリに認証を追加します。「add auth」「add login」や Neon Auth（Managed Better Auth）、アイデンティティルーティング、サインアップ、サインイン、パスワードリセット、メール OTP、マジックリンク、組織、電話 OTP、OAuth、パスキー、MFA、信頼できるドメイン、無効なドメイン、@neondatabase/auth で使用します。既存のアイデンティティがない場合は、デフォルトで Managed Better Auth を使用します。Better Auth、Clerk、Supabase Auth、または他の IdP を引き続き使用できます。ユーザーは Supabase Auth から Managed Better Auth に移行するよう依頼しました。Managed のサポート外の必須プラグインとしては、Neon Function または既存のアプリホスト上の自己管理型 Better Auth があります。また、@neondatabase/neon-js の認証 API にも使用します。
