قم بكشط مستودع المضيف الموجود بداخله، وقم ببناء/صيانة حزمة المعرفة `.lokf/` كعربة جانبية، متوافقة مع مخطط تنسيق المعرفة المرتبطة المفتوحة (LOKF) (ملف تعريف دلالي لـ OKF). يُستخدم عندما: إنشاء أو تحديث ملفات المفاهيم ضمن .lokf/knowledge/؛ إضافة العلاقات المكتوبة (isPartOf/dependsOn/derivedFrom/about/references/...); اختيار فئة LOKF (الخدمة/المقياس/مجموعة البيانات/الجدول/السياسة/دليل التشغيل/مصطلح المصطلحات/...)؛ إعداد base_iri/context/id بحيث يتم توسيع المادة الأمامية إلى JSON-LD/RDF؛ التحقق من صحة الحزمة باستخدام JSON Schema وSHACL عبر مجموعة أدوات lokf؛ تحويل/تقديم الحزمة كرسم بياني؛ تدقيق .lokf/ للتأكد من صحته أو وجود ثغرات أو أخطاء؛ إعداد تغيير LOKF لمراجعة المشرف البشري؛ أو تشغيل مهمة مكتبة LLM المجدولة التي تحافظ على دقة .lokf/ (قاعدة كارباثي).
