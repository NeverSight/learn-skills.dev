Raclez le dépôt hôte dans lequel cette compétence se trouve et créez / maintenez le bundle de connaissances `.lokf/` en tant que sidecar, conforme au schéma Linked Open Knowledge Format (LOKF) (un profil sémantique de l’OKF). Utilisez‑le lorsque : création ou mise à jour de fichiers de concepts sous `.lokf/knowledge/` ; ajout de relations typées (isPartOf/dependsOn/derivedFrom/about/references/…) ; choix d’une classe LOKF (Service/Metric/Dataset/Table/Policy/Playbook/GlossaryTerm/…) ; définition de `base_iri`/`context`/`id` afin que le frontmatter s’étende en JSON‑LD/RDF ; validation du bundle avec JSON Schema et SHACL via la boîte à outils lokf ; conversion / servir le bundle sous forme de graphe ; audit de `.lokf/` pour vérifier la conformité, les lacunes ou les bugs ; préparation d’un changement LOKF pour révision par le mainteneur humain ; ou exécution de la tâche planifiée LLM‑librarian qui maintient `.lokf/` à jour (règle de Karpathy).
