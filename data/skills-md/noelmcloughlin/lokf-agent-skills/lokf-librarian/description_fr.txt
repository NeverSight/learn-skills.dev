Grattez le référentiel hôte dans lequel se trouve cette compétence et créez/maintenez l'ensemble de connaissances `.lokf/` en tant que side-car, conforme au schéma Linked Open Knowledge Format (LOKF) (un profil sémantique d'OKF). À utiliser lors de : la création ou la mise à jour de fichiers de concept sous .lokf/knowledge/ ; ajout de relations typées (isPartOf/dependsOn/derivedFrom/about/references/...) ; choisir une classe LOKF (Service/Metric/Dataset/Table/Policy/Playbook/GlossaryTerm/...) ; définir base_iri/context/id pour que le frontmatter s'étende à JSON-LD/RDF ; valider le bundle avec JSON Schema et SHACL via la boîte à outils lokf ; convertir/servir le paquet sous forme de graphique ; auditer .lokf/ pour vérifier son exactitude, ses lacunes ou ses bogues ; préparer un changement de LOKF pour un examen humain par le responsable ; ou exécuter la tâche planifiée du bibliothécaire LLM qui maintient .lokf/ précis (règle de Karpathy).
