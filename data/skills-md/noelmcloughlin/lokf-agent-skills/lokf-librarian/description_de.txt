Durchsuchen Sie das Host-Repository, in dem sich dieser Skill befindet, und erstellen/verwalten Sie das „.lokf/“-Wissenspaket als Sidecar, das mit dem Linked Open Knowledge Format (LOKF)-Schema (einem semantischen Profil von OKF) kompatibel ist.
