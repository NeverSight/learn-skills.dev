Recupera il repository host all'interno di cui si trova questa competenza e crea/mantieni il pacchetto di conoscenze `.lokf/` come sidecar, conforme allo schema Linked Open Knowledge Format (LOKF) (un profilo semantico di OKF). Utilizzare quando: si creano o si aggiornano file di concetti in .lokf/knowledge/; aggiunta di relazioni tipizzate (isPartOf/dependsOn/derivedFrom/about/references/...); scegliendo una classe LOKF (Service/Metric/Dataset/Table/Policy/Playbook/GlossaryTerm/...); impostando base_iri/context/id in modo che frontmatter si espanda in JSON-LD/RDF; convalida del bundle con JSON Schema e SHACL tramite il toolkit lokf; convertire/servire il bundle come grafico; controllare .lokf/ per verificarne la correttezza, le lacune o i bug; preparare una modifica LOKF per la revisione del manutentore umano; o eseguendo l'attività pianificata del bibliotecario LLM che mantiene .lokf/ accurato (regola di Karpathy).
