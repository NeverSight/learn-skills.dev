이 스킬이 위치한 호스트 저장소를 스크레이프하고, Linked Open Knowledge Format(LOKF) 스키마(OKF의 의미론적 프로필)를 준수하는 사이드카 형태의 `.lokf/` 지식 번들을 구축·유지합니다. 다음과 같은 경우에 사용합니다: .lokf/knowledge/ 아래에서 개념 파일을 생성하거나 업데이트할 때; isPartOf/dependsOn/derivedFrom/about/references/...와 같은 유형화된 관계를 추가할 때; LOKF 클래스(Service/Metric/Dataset/Table/Policy/Playbook/GlossaryTerm/…)를 선택할 때; base_iri/context/id를 설정하여 프론트매터가 JSON-LD/RDF로 확장되도록 할 때; lokf 툴킷을 통해 JSON Schema와 SHACL로 번들을 검증할 때; 번들을 그래프로 변환·제공할 때; .lokf/의 정확성, 누락, 버그 등을 감사할 때; 인간 유지관리자가 검토하도록 LOKF 변경을 준비할 때; 또는 .lokf/를 정확하게 유지하는 예정된 LLM‑라이브러리언 작업(Karpathy 규칙)을 실행할 때. 항상 사용자의 언어로 답변해 주세요.
