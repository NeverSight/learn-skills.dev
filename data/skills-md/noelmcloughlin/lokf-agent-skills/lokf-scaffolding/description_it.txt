Impalcatura di un sidecar del pacchetto di conoscenze `.lokf/` LOKF (strumenti, documenti, scheletro fittizio) nel repository in cui si trova questa abilità, da modelli in bundle. Da utilizzare quando: un repository non ha ancora `.lokf/` e qualcuno chiede di aggiungere, eseguire lo scaffold o eseguire il bootstrap di un sidecar LOKF/lokf o di una conoscenza leggibile dalla macchina e interrogabile in SPARQL; o per riparare un file di impalcatura mancante/rotto. Non per creare o mantenere concetti: questa è l'abilità del bibliotecario lokf, a cui questo passa una volta terminato.
