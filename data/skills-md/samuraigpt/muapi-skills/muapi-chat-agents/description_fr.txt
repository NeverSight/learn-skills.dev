Exécutez Claude Code ou Codex CLI sur Muapi (api.muapi.ai) en utilisant les crédits Muapi au lieu d'un compte fournisseur séparé. Utilisez ceci lorsque l'utilisateur souhaite qu'un agent de codage local utilise Muapi comme fournisseur de modèle, demande quels modèles Muapi fonctionnent avec Claude Code ou Codex, ou a besoin de l'URL de base, de la variable de clé API, du bloc fournisseur ou du nom du modèle pour l'un ou l'autre agent. Couvre Claude Code (messages Anthropic) et Codex CLI (réponses OpenAI), la découverte de modèles, la vérification et le dépannage.

Veuillez toujours répondre dans la langue de l'utilisateur.
