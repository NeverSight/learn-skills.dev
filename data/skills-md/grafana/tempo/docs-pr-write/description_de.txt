Erstelle oder aktualisiere Produktdokumentation für benutzerorientierte PR‑Änderungen. Verwende dies, wenn der Benutzer darum bittet, Dokumentation für einen PR zu schreiben, einen PR zu dokumentieren, bestehende Dokumente basierend auf einer Code‑Änderung zu aktualisieren, PRs zu verarbeiten, die von docs‑pr‑check markiert wurden, oder PR‑Nummern bzw. Links angibt und die entsprechende Dokumentation erstellt oder aktualisiert haben möchte – selbst wenn sie sagen „diese Änderungen dokumentieren“, ohne PRs ausdrücklich zu erwähnen. Diese Fähigkeit erstellt und aktualisiert nur Dokumente; sie triagiert keine PRs (verwende docs‑pr‑check), überprüft keine bestehenden Dokumente (verwende docs‑review) und erzeugt keine Release‑Notes.

Bitte antworte immer in der Sprache des Benutzers.
