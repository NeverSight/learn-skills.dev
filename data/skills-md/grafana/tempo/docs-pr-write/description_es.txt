Redacta o actualiza la documentación del producto para cambios de PR orientados al usuario. Úsalo cuando el usuario solicite escribir documentación para un PR, documentar un PR, actualizar la documentación existente basada en un cambio de código, procesar PRs marcados por docs-pr-check, o proporcione números o enlaces de PR y quiera que se cree o actualice la documentación correspondiente — incluso si dice “documentar estos cambios” sin mencionar explícitamente los PRs. Esta habilidad solo redacta y actualiza documentación; no realiza la triaje de PRs (usa docs-pr-check), revisa la documentación existente (usa docs-review) ni genera notas de lanzamiento.

Por favor, responde siempre en el idioma del usuario.
