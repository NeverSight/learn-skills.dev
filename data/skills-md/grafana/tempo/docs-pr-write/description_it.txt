Scrivi o aggiorna la documentazione di prodotto per le modifiche PR rivolte agli utenti. Utilizza quando l'utente richiede di scrivere documenti per una PR, documentare una PR, aggiornare la documentazione esistente in base a una modifica al codice, elaborare PR segnate da docs-pr-check, o fornisce numeri o link di PR e desidera che la relativa documentazione sia creata o aggiornata — anche se dice “documenta queste modifiche” senza menzionare esplicitamente le PR. Questa abilità scrive e aggiorna solo documenti; non effettua il triage delle PR (usa docs-pr-check), non revisiona la documentazione esistente (usa docs-review) e non genera note di rilascio.

Rispondi sempre nella lingua dell'utente.
