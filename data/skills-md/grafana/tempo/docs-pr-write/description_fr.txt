Rédiger ou mettre à jour la documentation produit pour les modifications de PR destinées aux utilisateurs. Utilisez cela lorsque l'utilisateur demande d'écrire la documentation d’une PR, de documenter une PR, de mettre à jour la documentation existante suite à un changement de code, de traiter les PR signalées par docs‑pr‑check, ou fournit des numéros ou des liens de PR et veut que la documentation correspondante soit créée ou mise à jour — même s’il dit « documenter ces changements » sans mentionner explicitement les PR. Cette compétence se limite à rédiger et mettre à jour la documentation ; elle ne triage pas les PR (utilisez docs‑pr‑check), ne révise pas la documentation existante (utilisez docs‑review) et ne génère pas de notes de version.

Veuillez toujours répondre dans la langue de l’utilisateur.
