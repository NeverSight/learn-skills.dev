Пишите или обновляйте документацию продукта для PR‑изменений, ориентированных на пользователя. Используйте, когда пользователь просит написать документацию к PR, задокументировать PR, обновить существующую документацию на основе изменения кода, обработать PR, помеченные docs‑pr‑check, или предоставляет номера PR или ссылки и хочет, чтобы соответствующая документация была создана или обновлена — даже если они говорят «задокументировать эти изменения», не упоминая PR явно. Этот навык только пишет и обновляет документацию; он не занимается триажем PR (используйте docs‑pr‑check), не проверяет существующую документацию (используйте docs‑review) и не генерирует релиз‑ноты.

Пожалуйста, всегда отвечайте на языке пользователя.
