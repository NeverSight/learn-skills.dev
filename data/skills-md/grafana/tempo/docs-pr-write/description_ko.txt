사용자에게 노출되는 PR 변경 사항에 대한 제품 문서를 작성하거나 업데이트하십시오. 사용자가 PR에 대한 문서를 작성하라고 요청하거나, PR을 문서화하거나, 코드 변경을 기반으로 기존 문서를 업데이트하라고 요청할 때, docs‑pr‑check으로 표시된 PR을 처리할 때, 혹은 PR 번호나 링크를 제공하고 해당 문서를 생성하거나 업데이트하길 원할 때—심지어 “이 변경 사항을 문서화해 주세요”라고 PR을 명시하지 않아도 사용합니다. 이 스킬은 문서를 작성하고 업데이트하는 데에만 사용되며, PR을 분류( docs‑pr‑check 사용)하거나 기존 문서를 검토( docs‑review 사용)하거나 릴리즈 노트를 생성하는 데에는 사용되지 않습니다.
