Сквозной рабочий процесс для документирования PR — проверка, написание, рецензирование и, при необходимости, валидация скриншотов. Используйте, когда пользователь хочет задокументировать один или несколько PR от начала до конца, запустить весь конвейер документации или запросить полное прохождение документирования PR.
