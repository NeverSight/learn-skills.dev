Scans and cleans regenerable Windows C: drive caches using a configurable target list (uv, WPS, Notion, IDE caches, Temp, Package Cache, Windows Update download, etc.). Use when the user asks to free C: space, clean disk caches, reclaim disk space on Windows, or explicitly asks to use this skill / windows-c-drive-cleaner. Always scan and confirm before deleting. Dangerous targets require multi-step confirmation with risk explanation. Works with any agent that can load SKILL.md; also runnable as standalone PowerShell.
