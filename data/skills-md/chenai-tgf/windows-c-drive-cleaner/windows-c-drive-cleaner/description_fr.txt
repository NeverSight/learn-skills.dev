Analyse et nettoie les caches régénérables du lecteur C: sous Windows en utilisant une liste cible configurable (uv, WPS, Notion, caches IDE, Temp, cache de paquets, téléchargement de Windows Update, etc.). Utilisez‑le lorsque l'utilisateur demande de libérer de l'espace sur le C:, de nettoyer les caches du disque, de récupérer de l'espace disque sous Windows, ou demande explicitement d'utiliser cette compétence / windows-c-drive-cleaner. Analysez toujours et confirmez avant de supprimer. Les cibles dangereuses nécessitent une confirmation en plusieurs étapes avec explication du risque. Fonctionne avec tout agent pouvant charger SKILL.md ; peut également être exécuté en PowerShell autonome.

Veuillez toujours répondre dans la langue de l'utilisateur.
