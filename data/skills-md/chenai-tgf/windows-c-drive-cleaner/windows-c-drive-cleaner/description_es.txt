Escanea y limpia la caché regenerable del disco C: de Windows usando una lista de objetivos configurable (uv, WPS, Notion, cachés de IDE, Temp, caché de paquetes, descargas de Windows Update, etc.). Utilízalo cuando el usuario pida liberar espacio en C:, limpiar cachés de disco, recuperar espacio en disco en Windows, o solicite explícitamente usar esta habilidad / windows-c-drive-cleaner. Siempre escanea y confirma antes de eliminar. Los objetivos peligrosos requieren una confirmación de varios pasos con explicación del riesgo. Funciona con cualquier agente que pueda cargar SKILL.md; también se puede ejecutar como PowerShell independiente.
