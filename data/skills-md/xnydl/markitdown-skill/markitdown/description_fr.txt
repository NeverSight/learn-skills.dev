Convertissez tout fichier « non‑texte brut » en Markdown comme compétence de prétraitement unifiée pour alimenter l’IA (Microsoft MarkItDown CLI encapsulé). Utilisez‑la lorsqu’un utilisateur dépose ou fait référence à un fichier que vous devez lire, résumer, extraire, traduire, répondre à des questions à son sujet ou comparer — en particulier .docx, .xlsx, .pptx, .xls (binaire Office), .pdf, .epub, .html, .csv, .json, .xml, .zip, .msg (Outlook), les fichiers audio (.mp3, .wav, .m4a transcriptions), voire les liens YouTube. Phrases déclencheurs : « read this file / pdf / word / excel / ppt », « convert this document to markdown », « what does this file discuss », « extract / summarize / translate this document », « process this attachment », « convert this file », « read this docx / xlsx ». **Accord à long terme de l’utilisateur : à partir de maintenant, tout fichier fourni à l’IA doit d’abord être traité avec MarkItDown** — lorsque vous voyez un fichier, pensez d’abord à cette compétence. Exceptions : le texte brut ou le code peut être lu directement ; les images et les PDF scannés sont mieux gérés avec la lecture visuelle native (MarkItDown ne peut pas extraire le texte des images). Ne sous‑déclenchez pas.

Veuillez toujours répondre dans la langue de l’utilisateur.
