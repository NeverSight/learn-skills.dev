Konvertiere jede „non‑plain‑text“-Datei in Markdown als einheitliche Vorverarbeitungs‑Skill zum Einspeisen von KI (eingebundene Microsoft MarkItDown CLI). Verwende sie, wenn ein Nutzer eine Datei ablegt oder referenziert, damit du sie lesen, zusammenfassen, extrahieren, übersetzen, Fragen dazu beantworten oder vergleichen kannst – insbesondere .docx, .xlsx, .pptx, .xls (Office‑Binary), .pdf, .epub, .html, .csv, .json, .xml, .zip, .msg (Outlook), Audio (.mp3, .wav, .m4a‑Transkriptionen) und sogar YouTube‑Links. Trigger‑Phrasen: “read this file / pdf / word / excel / ppt”, “convert this document to markdown”, “what does this file discuss”, “extract / summarize / translate this document”, “process this attachment”, “convert this file”, “read this docx / xlsx”. **Langzeit‑Vereinbarung des Nutzers: Ab sofort soll jede Datei, die der KI übergeben wird, zuerst mit MarkItDown verarbeitet werden** – wenn du eine Datei siehst, denke zuerst an diese Fähigkeit. Ausnahmen: Klartext oder Code können direkt gelesen werden; Bilder und gescannte PDFs werden besser mit nativer visueller Lesefunktion behandelt (MarkItDown kann Text aus Bildern nicht extrahieren). Unter‑Triggern vermeiden.
