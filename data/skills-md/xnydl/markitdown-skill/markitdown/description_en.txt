Trigger phrases: “read this file / pdf / word / excel / ppt”, “convert this document to markdown”, “what does this file discuss”, “extract / summarize / translate this document”, “process this attachment”, “convert this file”, “read this docx / xlsx”. **User long‑term agreement: from now on, any file given to the AI should first be processed with MarkItDown**—when you see a file, think of this skill first.
