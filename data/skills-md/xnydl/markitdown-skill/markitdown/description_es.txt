Convierte cualquier archivo “non‑plain‑text” a Markdown para alimentarlo a la IA como una habilidad de preprocesamiento unificada (CLI de Microsoft MarkItDown envuelta). Úsalo cuando un usuario suelte o haga referencia a un archivo para que lo leas, resumas, extraigas, traduzcas, respondas preguntas al respecto o lo compares —especialmente .docx / .xlsx / .pptx / .xls (binario de Office), .pdf, .epub, .html, .csv / .json / .xml, .zip, .msg (Outlook), audio (.mp3 / .wav / .m4a transcripción), incluso enlaces de YouTube. Frases disparadoras: “read this file / pdf / word / excel / ppt”, “convert this document to markdown”, “what does this file say”, “extract / summarize / translate this document”, “process this attachment”, “convert this file”, “read this docx / xlsx”. **Acuerdo a largo plazo del usuario: a partir de ahora cualquier archivo que se le entregue a la IA debe procesarse primero con MarkItDown** —cuando veas un archivo, piensa primero en esta habilidad. Excepciones: texto plano / código pueden leerse directamente; las imágenes y los PDF escaneados se manejan mejor con OCR visual nativo (MarkItDown no puede extraer texto de imágenes). No subdispares.

Por favor, responde siempre en el idioma del usuario.
