Преобразуйте любой «не‑текстовый» файл в Markdown как единый навык предварительной обработки для подачи в ИИ (обёртка Microsoft MarkItDown CLI). Используйте его, когда пользователь загружает или упоминает файл, который вы должны прочитать, суммировать, извлечь, перевести, ответить на вопросы о нём или сравнить — особенно .docx, .xlsx, .pptx, .xls (двойичный формат Office), .pdf, .epub, .html, .csv, .json, .xml, .zip, .msg (Outlook), аудио (.mp3, .wav, .m4a с транскрипциями), даже ссылки YouTube. Фразы‑триггеры: «прочитать этот файл / pdf / word / excel / ppt», «конвертировать этот документ в markdown», «о чём этот файл», «извлечь / суммировать / перевести этот документ», «обработать вложение», «конвертировать этот файл», «прочитать этот docx / xlsx». **Долгосрочное соглашение пользователя: с этого момента любой файл, передаваемый ИИ, должен сначала обрабатываться с помощью MarkItDown** — когда вы видите файл, думайте об этом навыке в первую очередь. Исключения: простой текст или код можно читать напрямую; изображения и сканированные PDF лучше обрабатывать визуально (MarkItDown не может извлекать текст из изображений). Не недо‑триггерьте.

Всегда отвечайте на языке пользователя.
