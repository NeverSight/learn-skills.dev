Converti qualsiasi file “non‑plain‑text” in Markdown come abilità di pre‑elaborazione unificata per alimentare l'IA (wrapper Microsoft MarkItDown CLI). Usala quando un utente rilascia o fa riferimento a un file da leggere, riassumere, estrarre, tradurre, rispondere a domande su di esso o confrontarlo — soprattutto .docx, .xlsx, .pptx, .xls (formato binario Office), .pdf, .epub, .html, .csv, .json, .xml, .zip, .msg (Outlook), audio (.mp3, .wav, .m4a trascrizioni), anche link YouTube. Frasi di attivazione: “leggi questo file / pdf / word / excel / ppt”, “converti questo documento in markdown”, “di cosa parla questo file”, “estrai / riassumi / traduci questo documento”, “elabora questo allegato”, “converti questo file”, “leggi questo docx / xlsx”. **Accordo a lungo termine dell'utente: d'ora in poi, qualsiasi file fornito all'IA deve essere prima processato con MarkItDown** — quando vedi un file, pensa prima a questa abilità. Eccezioni: testo semplice o codice possono essere letti direttamente; le immagini e i PDF scansionati sono meglio gestiti con la lettura visiva nativa (MarkItDown non può estrarre testo dalle immagini). Non attivare in modo insufficiente.

Rispondi sempre nella lingua dell'utente.
