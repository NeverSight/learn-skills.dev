Utilisez-le lorsque l'utilisateur demande la division des responsabilités, la vérification des principes de conception, le choix de motifs de conception, la conception de la structure du code ou la refactorisation structurelle ; à partir du code existant et des exigences changeantes, améliorez la cohésion, les dépendances, les contrats et la testabilité, et évitez le sur‑design. Applicable à plusieurs langages et architectures ; le texte ordinaire, le formatage et les corrections clairement définies sur une seule ligne ne nécessitent pas le lancement du processus complet.

Veuillez toujours répondre dans la langue de l'utilisateur.
