استخدمه عندما يطلب المستخدم تقسيم المسؤولية، فحص مبادئ التصميم، اختيار نمط التصميم، تصميم بنية الشيفرة، أو إعادة هيكلة بنية الكود؛ استنادًا إلى الكود الحالي والمتطلبات المتغيرة، تحسين التجانس، الاعتمادات، العقود، وإمكانية الاختبار، ومنع الإفراط في التصميم. ينطبق على عدة لغات ومعمارية؛ النص العادي، التنسيق، والإصلاحات المحددة بوضوح ذات سطر واحد لا تتطلب بدء العملية الكاملة.
