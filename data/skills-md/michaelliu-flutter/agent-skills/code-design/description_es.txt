Se utiliza cuando el usuario solicita asignación de responsabilidades, comprobaciones de principios de diseño, selección de patrones de diseño, diseño de estructura de código o refactorización estructural; según el código existente y los requisitos cambiantes, mejora la cohesión, las dependencias, los contratos y la capacidad de prueba, y evita el diseño excesivo. Aplicable a múltiples lenguajes y arquitecturas; la copia ordinaria, el formato y las correcciones de una sola línea claramente definidas no requieren iniciar el proceso completo.
