Inverse le génie d’une application en une carte de reconnaissance : inventaire des écrans, flux utilisateurs, liste des composants, modèle de données inféré et matrice des fonctionnalités, à partir des pages publiques, captures d’écran, listings du store, documents d’aide et du compte de l’utilisateur. La première étape du pack Replica. À utiliser lorsque l’utilisateur dit « clone cette application », « reverse engineer X », « comment fonctionne X », « cartographie X », « quels écrans X possède », « je veux créer ma propre version de X », « copie cette application », ou colle l’URL d’une application ou le lien de l’App Store et souhaite la reconstruire.
