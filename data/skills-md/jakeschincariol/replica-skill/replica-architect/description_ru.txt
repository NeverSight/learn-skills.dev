Планирует стек, схему базы данных и API для клона приложения, исходя из карты разведки, написанной replica-recon. Выбирает скучные, управляемые технологии, превращает инферированную модель данных в реальный SQL с индексами и правилами доступа, перечисляет каждый маршрут по потоку и организует построение в виде тонкого вертикального среза в первую очередь. Используется, когда пользователь говорит «планировать клон», «какой стек мне использовать», «разработать базу данных», «написать схему», «планировать API», «архитектура моей версии X», или после завершения /replica-recon. Пожалуйста, всегда отвечайте на языке пользователя.
