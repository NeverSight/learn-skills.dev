Planifie la pile, le schéma de base de données et l'API pour un clone d'application, à partir de la carte de reconnaissance écrite par replica-recon. Choisit des technologies ennuyeuses et gérées, transforme le modèle de données inféré en SQL réel avec index et règles d'accès, répertorie chaque route par flux, et organise la construction en commençant par une fine tranche verticale. Utilisez ceci lorsque l'utilisateur dit « plan the clone », « what stack should I use », « design the database », « write the schema », « plan the API », « architecture for my version of X », ou après la fin de /replica-recon.

Veuillez toujours répondre dans la langue de l'utilisateur.
