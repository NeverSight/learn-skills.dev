Clique à travers chaque flux d’un clone d’application et le teste à la recherche de bugs : un plan de test généré à partir des flux de reconnaissance avec les chemins heureux et les cas limites, des tests end‑to‑end Playwright lorsque cela est possible, un clic‑through dans le navigateur sinon, et des rapports de bugs au format fixe contenant gravité, étapes et preuves. À utiliser lorsque l’utilisateur dit « test my clone », « find bugs », « QA this », « click through everything », « write e2e tests », « does it work », ou après /replica‑build ou /replica‑backend.
