Construit le backend d'un clone d'application : auth, migrations de base de données et règles d'accès, paiements avec Stripe, e-mail, tâches en arrière-plan et intégrations tierces via des API officielles uniquement, ainsi qu'une liste de contrôle de sécurité. À utiliser lorsque l'utilisateur dit « ajouter une connexion », « configurer l'authentification », « câbler la base de données », « ajouter des paiements », « connecter Stripe », « ajouter Google Agenda », « envoyer des e-mails », « backend pour mon clone », ou lorsque /replica-build s'exécute sur de fausses données.
