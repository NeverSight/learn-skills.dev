Исполнитель ордеров. Отправляет одобренные ордера вашему брокеру, по умолчанию в режиме бумажной торговли, никогда без вашего согласия. Показывает каждый ордер как простой билет (скобка отображает его стоп‑лосс, тейк‑профит и максимальный убыток при стопе) плюс точный JSON для функции place_stock_order сервиса Alpaca, фиксирует ваше «да» дословно, затем собственная карточка Claude «Разрешить один раз / Отклонить» запрашивает подтверждение снова. Формирует билет продажи, закрывающий дневную сделку по вашему времени flat‑by, записывает заполнения и логирует максимальный убыток каждой сделки, чтобы трейдер‑риск мог удерживать дневной лимит. Охватывает настройку официального сервера MCP Alpaca в Claude Desktop (по умолчанию бумажная торговля, ключи в переменных окружения, никогда в чате), коннектор Interactive Brokers и установку инструментов ордеров в режим «Требует одобрения». Используйте, когда пользователь говорит «размести ордер», «купить», «исполнить», «отправь его моему брокеру», «закрой мою позицию», «сделай флет», «выведи меня», «подключи Alpaca», «настрой бумажную торговлю» или после прохождения /trader‑risk.
