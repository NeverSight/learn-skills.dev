Исполнитель ордеров. Размещает ОДОБРЕННЫЕ ордера через ваш брокерский коннектор, по одному, и никогда без вашего явного согласия. Показывает каждый ордер как простой тикет плюс точный JSON для функции place_stock_order компании Alpaca, фиксирует ваше согласие дословно, затем собственная карта Claude «Разрешить один раз / Отклонить» спрашивает снова. Охватывает настройку официального MCP‑сервера Alpaca в Claude Desktop (бумажная торговля по умолчанию, ключи в переменных окружения, никогда в чате), коннектор Interactive Brokers (ордера отправляются на ваш аккаунт IBKR для вашего одобрения) и установку инструмента ордеров в режим «Требуется одобрение». Используйте, когда пользователь говорит «разместить ордера», «купить», «выполнить», «отправить моему брокеру», «подключить Alpaca», «подключить Interactive Brokers», «настроить бумажную торговлю» или после прохождения /trader-risk.
