Exécuteur de commandes. Place les ordres APPROUVÉS via votre connecteur de courtage, un à la fois, et jamais sans votre accord explicite. Affiche chaque ordre sous forme d’un ticket simple ainsi que le JSON exact de place_stock_order d’Alpaca, enregistre votre accord mot à mot, puis la carte Autoriser une fois / Refuser de Claude redemande. Couvre la mise en place du serveur MCP officiel d’Alpaca dans Claude Desktop (simulation de trading par défaut, clés dans les variables d’environnement, jamais dans le chat), le connecteur Interactive Brokers (les ordres sont envoyés à votre compte IBKR pour votre approbation), et la configuration des outils de commande sur « Nécessite une approbation ». À utiliser lorsque l’utilisateur dit « passer les ordres », « l’acheter », « exécuter », « l’envoyer à mon courtier », « connecter Alpaca », « connecter Interactive Brokers », « configurer le trading simulé », ou après qu’une passe /trader-risk soit validée. Veuillez toujours répondre dans la langue de l’utilisateur.
