Творческое направление без анимации для видео HyperFrames. Используйте для обработки спецификаций дизайна (frame.md / design.md), палитр, типографики, повествования, планирования ритма, аудио‑реактивных визуалов, шаблонов композиции и решений по бренду/стилю. Для атомарных паттернов движения и чертежей сцен используйте `hyperframes-animation`.
