HyperFrames のすべてのアニメーション知識 — 原子レベルのモーションルール、マルチフェーズシーンの青写真、シーントランジション、より広範なモーションデザイン技法、そして 7 つのランタイムアダプタ（GSAP デフォルト、Lottie、Three.js、Anime.js、CSS キーフレーム、Web Animations API、TypeGPU）。任意のモーションやアニメーションタスクに使用可能：2〜4 のルールを選んで構成するか、青写真をロードするか、ランタイム固有の API を参照する（例：GSAP の ease、Lottie プレイヤー、Three.js ミキサー）。既存のコンポジションの振付（アニメーションマップ）を監査する方法や、24 個の名前付きテキストアニメーション効果もカバー。HyperFrames ネイティブ：単一の一時停止タイムライン、シーク安全、決定的。
