Весь набор знаний по анимации для HyperFrames — атомарные правила движения, многофазные чертежи сцен, переходы между сценами, более широкие техники motion‑design, а также семь адаптеров среды выполнения (по умолчанию GSAP, плюс Lottie, Three.js, Anime.js, CSS‑ключевые кадры, Web Animations API, TypeGPU). Используйте для любой задачи по движению или анимации: выберите 2–4 правила и составьте композицию, загрузите чертёж или найдите специфичный для среды выполнения API (например, плавности GSAP / плеер Lottie / микшер Three.js). Также охватывается аудит хореографии существующей композиции (карта анимации) и 24 именованных текстовых анимационных эффекта. Нативный HyperFrames: единственная приостановленная временная шкала, безопасная при перемотке, детерминированная.
