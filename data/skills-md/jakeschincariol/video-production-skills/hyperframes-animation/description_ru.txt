Все знания по анимации для HyperFrames — атомарные правила движения, мультифазовые чертежи сцен, переходы между сценами, более широкие техники motion‑design и семь адаптеров рантайма (GSAP по умолчанию, плюс Lottie, Three.js, Anime.js, CSS‑ключевые кадры, Web Animations API, TypeGPU). Используйте для любой задачи по движению или анимации: выберите 2‑4 правила и составьте композицию, либо загрузите чертёж, либо найдите API, специфичное для конкретного рантайма (например, eases GSAP / плеер Lottie / микшер Three.js). Также охватывается аудит хореографии существующей композиции (карта анимации) и 24 именованных эффекта текстовой анимации. HyperFrames‑native: один приостановленный таймлайн, безопасный при перемотке, детерминированный.
