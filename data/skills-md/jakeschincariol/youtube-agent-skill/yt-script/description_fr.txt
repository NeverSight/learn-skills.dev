Rédigez un script vidéo YouTube à partir d’une idée brute : options d’accroche basées sur 21 formules, notées, puis le script complet avec les repères de rétention indiqués. Utilisez-le chaque fois que l’utilisateur veut un script vidéo, une accroche, une phrase d’ouverture, « que devrais‑je dire », « écris ma prochaine vidéo », ou qu’il s’apprête à enregistrer et n’a pas encore les quinze premières secondes.

Veuillez toujours répondre dans la langue de l’utilisateur.
