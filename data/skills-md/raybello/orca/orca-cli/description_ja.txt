Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザを `orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関与する場合は、純粋な git worktree やアドホック PTY、あるいは Computer Use よりもこちらを優先してください。CLI、ファイルシステム、API では対応できない、可視ウィンドウの GUI 操作が必要な場合にのみ Computer Use を使用します。

常にユーザーの言語で応答してください。
