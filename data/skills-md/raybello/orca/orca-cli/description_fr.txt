Utilisez le CLI `orca` pour gérer les worktrees Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca. Employez‑le lorsque l’utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Privilégiez‑le au git worktree brut, aux PTY ad hoc ou à l’utilisation de l’ordinateur lorsque l’état d’Orca est impliqué. N’utilisez l’ordinateur qu’en cas de besoin d’un contrôle GUI d’une fenêtre visible qu’une ligne de commande, le système de fichiers ou une API ne peuvent gérer.
