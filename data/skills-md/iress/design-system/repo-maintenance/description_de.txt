Leitfaden für die Wartung der IDS (Iress Design System) monorepo. Umfasst das Hinzufügen/Ändern von Komponenten, Aktualisieren von Token, Verwalten von Abhängigkeiten, Freigaben, CI/CD-Fehlerbehebung, Bündelbudgets, Dokumentationswartung und PR-Überprüfungs-Checklisten. Verwenden Sie diese Option, wenn Sie aufgefordert werden, eine Komponente hinzuzufügen, Token zu aktualisieren, CI zu beheben, eine PR zu überprüfen, eine Version zu schneiden, Abhängigkeiten zu aktualisieren, die Paketgröße zu überprüfen oder eine Repo-Wartungsaufgabe durchzuführen.
