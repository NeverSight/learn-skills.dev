Руководство по поддержке монорепозитория IDS (Iress Design System). Охватывает добавление/модификацию компонентов, обновление токенов, управление зависимостями, релизы, решение проблем CI/CD, бюджеты размеров бандлов, поддержание документации и контрольные списки проверки PR. Используйте при добавлении компонента, обновлении токенов, исправлении CI, ревью PR, выпуске релиза, обновлении зависимостей, проверке размера бандла или любой другой задаче по обслуживанию репозитория.
