エージェントが自分のモッドをテストできるように、実際のゲームを起動し、画面を確認し、操作します。Steam または exe からの起動、固定サイズのウィンドウモード、ゲームウィンドウのスクリーンショット（GPU 安全なキャプチャ）、メニューへのクリックと入力、キーのホールド、相対マウス、クラッシュレポーターのクリーンアップ、PID によるプロセス終了、ログの読み取り、スクリプト化されたテストシーン、そしてエージェントが観測・操作できるゲーム内 JSON ブリッジを網羅しています。Windows 優先（WSL からも利用可）で、Linux と macOS 用の注意点も掲載。ゲーム内でモッドを検証する必要があるとき、メニューを自動で操作する際、あるいは再現性のあるテストやデモシーンを作成する際に使用してください。
