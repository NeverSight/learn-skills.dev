Déterminez comment un jeu installé spécifique peut être moddé, avant d'écrire tout code de mod. Couvre l'emplacement d'installation, le moteur et la version, le code géré vs le code natif, l'anti‑triche, les chargeurs déjà présents, les dossiers de sauvegarde et de configuration, ainsi que la voie de modding de la communauté. Utilisez‑le lorsque l'utilisateur demande « puis‑je modder <jeu> ? », « quel moteur utilise <jeu> ? », « comment les gens modifient <jeu> ? », ou au début de toute tâche de modding. Produit MODDING_PLAN.md.
