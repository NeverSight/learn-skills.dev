Lisez comment un jeu fonctionne réellement afin qu’un mod puisse s’y raccrocher. Décompilez .NET/Mono (ILSpy), IL2CPP (Cpp2IL, Il2CppDumper), Java (Vineflower) et le code natif (Ghidra, IDA, via les serveurs MCP) ; extrayez les données et les formats d’actifs ; rétro‑ingéniez un format de fichier binaire et prouvez‑le par un aller‑retour ; lisez la mémoire en direct (Cheat Engine, Frida, x64dbg) ; trouvez les passes de rendu (RenderDoc). Utilisez‑le quand un mod a besoin des internes du jeu, par ex. « comment fonctionne l’IA du boss », « trouver la fonction de dégâts », « quel est le format de ce .sld/.pak/.dat », « où se trouve la position du joueur en mémoire ».
