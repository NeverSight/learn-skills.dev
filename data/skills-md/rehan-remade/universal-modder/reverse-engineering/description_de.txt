Lies nach, wie ein Spiel tatsächlich funktioniert, damit ein Mod es hooken kann. Dekompiliere .NET/Mono (ILSpy), IL2CPP (Cpp2IL, Il2CppDumper), Java (Vineflower) und nativen Code (Ghidra, IDA, über MCP‑Server); dump Daten‑ und Asset‑Formate; reverse‑engineere ein binäres Dateiformat und beweise es mit einem Round‑Trip; lies den Live‑Speicher (Cheat Engine, Frida, x64dbg); finde Render‑Passes (RenderDoc). Verwende dies, wenn ein Mod Spiel‑Interna benötigt, z. B. „wie funktioniert die Boss‑KI“, „finde die Schadensfunktion“, „welches Format hat diese .sld/.pak/.dat“, „wo befindet sich die Spielerposition im Speicher“.
