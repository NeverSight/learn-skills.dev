Packager et publier un mod de jeu terminé. Couvre le lint pré‑sortie (pas de fichiers du jeu, de code décompilé ou de clés divulguées), le README et les étapes d’installation, les crédits et la divulgation d’IA, le versionnage, les plateformes de téléchargement (Nexus Mods, Steam Workshop, Thunderstore, mod.io, versions GitHub), ainsi que le post avec une vidéo. Utilisez‑le lorsque l’utilisateur veut expédier, partager, télécharger, publier ou poster un mod.
