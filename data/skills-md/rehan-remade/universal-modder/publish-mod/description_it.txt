Impacchetta e rilascia una mod di gioco completa. Copre il lint pre‑rilascio (nessun file di gioco, codice decompilato o chiavi trapelate), il README e i passaggi di installazione, i crediti e la dichiarazione sull'IA, il versionamento, dove caricarla (Nexus Mods, Steam Workshop, Thunderstore, mod.io, GitHub releases) e il post con un video. Usalo quando l'utente vuole distribuire, condividere, caricare, rilasciare o pubblicare una mod.
