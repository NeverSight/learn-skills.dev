WordPress から microCMS へのコンテンツ移行の手順書および品質チェックリストです。構造の抽出、microCMS スキーマの設計、メディアのアップロードと URL の置換、リッチテキストエディタ用 HTML の変換、プロジェクトごとの移行スクリプト作成ガイドライン、項目数と漏れ項目の検証、リダイレクトテーブルについて説明しています。本書は WordPress から microCMS への移行を対象とし、WXR / WP REST API / ACF / カスタム投稿タイプ / Gutenberg / ショートコードを microCMS に持ち込むこと、WordPress コンテンツの一括登録・インポート、移行に使用する見積もりや事前調査を扱います。フロントエンドの移行・実装は範囲外です。
