Ein Verfahrensleitfaden und Qualitätsprüfung für die Migration von Inhalten von WordPress zu microCMS. Er umfasst das Extrahieren der Struktur, das Entwerfen des microCMS‑Schemas, das Hochladen von Medien und das Ersetzen von URLs, das Konvertieren von HTML für Rich‑Editoren, Richtlinien zur Erstellung von Migrationsskripten pro Projekt, die Verifizierung von Item‑Zahlen und Auslassungen sowie bis zur Redirect‑Tabelle. Er behandelt die Migration von WordPress zu microCMS, das Einbringen von WXR / WP REST API / ACF / benutzerdefinierten Beitragstypen / Gutenberg / Shortcodes in microCMS, die massenhafte Registrierung und den Import von WordPress‑Inhalten und wird für Kostenschätzungen und Voruntersuchungen von Migrationen von WordPress zu microCMS verwendet. Front‑End‑Migration und Implementierung sind nicht im Umfang enthalten.
