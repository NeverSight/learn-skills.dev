Procedural guide and quality check for migrating content from WordPress to microCMS. It covers extracting the structure, designing the microCMS schema, uploading media and replacing URLs, converting HTML for rich editors, guidelines for creating migration scripts per project, verification of item counts and omissions, and the redirect table. Discussion of migration from WordPress to microCMS, bringing WXR / WP REST API / ACF / custom post types / Gutenberg / shortcodes into microCMS, bulk registration and import of WordPress content, and use in estimates and preliminary investigations for migration from WordPress to microCMS. Front‑end migration and implementation are out of scope.
