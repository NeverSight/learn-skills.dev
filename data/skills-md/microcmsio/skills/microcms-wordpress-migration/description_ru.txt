Процедуры и проверки качества при миграции контента с WordPress в microCMS. Включает извлечение структуры, разработку схемы microCMS, загрузку медиа и замену URL, конвертацию HTML для редакторов с расширенным форматированием, рекомендации по созданию скриптов миграции для каждого проекта, проверку количества элементов и отсутствующих записей, а также работу с таблицами редиректов. Охватывает миграцию с WordPress в microCMS, перенос WXR / WP REST API / ACF / пользовательских типов записей / Gutenberg / шорткодов в microCMS, массовую регистрацию и импорт контента WordPress, и используется для оценки и предварительного исследования миграции WordPress в microCMS. Миграция и реализация фронтенда не включены в объём работы.
