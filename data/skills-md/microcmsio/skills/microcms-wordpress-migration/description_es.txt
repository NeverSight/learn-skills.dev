Manual de procedimientos y control de calidad para migrar contenido de WordPress a microCMS. Incluye la extracción de la estructura, el diseño de esquemas en microCMS, la carga de medios y la sustitución de URLs, la conversión de HTML para el editor enriquecido, directrices para crear scripts de migración por proyecto, la verificación del recuento de ítems y omisiones, y la gestión de tablas de redirección. Se discute la migración de WordPress a microCMS, trayendo WXR / API REST de WP / ACF / tipos de contenido personalizados / Gutenberg / shortcodes a microCMS, el registro/importación masiva de contenido de WordPress, y su uso en estimaciones e investigaciones previas a la migración para pasar de WordPress a microCMS. La migración/implementación del front‑end está fuera del alcance.
