WordPress에서 microCMS로 콘텐츠를 마이그레이션하기 위한 절차와 품질 검증. 구조 추출, microCMS 스키마 설계, 미디어 업로드 및 URL 교체, 리치 에디터용 HTML 변환, 프로젝트별 마이그레이션 스크립트 작성 가이드, 항목 수와 누락 항목 확인, 리다이렉트 테이블 처리 등을 포함합니다. WordPress에서 microCMS로의 마이그레이션을 다루며, WXR / WP REST API / ACF / 커스텀 포스트 타입 / Gutenberg / 숏코드를 microCMS로 가져오고, WordPress 콘텐츠를 대량 등록 및 가져오기하며, WordPress에서 microCMS로의 마이그레이션 비용 산정 및 사전 조사에 활용됩니다. 프런트엔드 마이그레이션 및 구현은 범위에 포함되지 않습니다.
