Ottieni la documentazione ufficiale per sviluppatori di microCMS (document.microcms.io) e verifica le specifiche API, i limiti, l'autenticazione, le query e le procedure operative della console admin con citazioni. Usa questa risorsa quando devi controllare le specifiche più recenti o fare riferimento a materiali ufficiali ed esempi di codice. Dai priorità a microcms‑guide per la progettazione, l'implementazione e il miglioramento del progetto, e a microcms‑nextjs per le implementazioni specifiche di Next.js, integrando eventuali controlli di specifica necessari con questa competenza.

Rispondi sempre nella lingua dell'utente.
