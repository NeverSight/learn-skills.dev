À utiliser lors de la révision du code avant sa fusion : le vôtre, celui d'un autre agent ou celui d'un humain. Évalue la qualité sur cinq axes (exactitude, lisibilité, architecture, sécurité, performances) avant qu'un changement n'entre dans la branche principale. Ne PAS utiliser pour écrire du code ou comme substitut aux tests automatisés/CI ; il s'agit d'une porte d'examen, pas d'un guide de mise en œuvre. Fait partie de la collection afonsoft/skills.
