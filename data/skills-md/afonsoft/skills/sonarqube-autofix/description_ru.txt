Используйте при анализе проблем SonarQube и создании SDD SPEC с предлагаемыми исправлениями. Классифицирует проблемы по типу (ошибка, запах кода, безопасность) и генерирует `.specs/SPEC-{YYYYMMDD}-{issue-key}-{type}.md` для `execute-tdd-spec` для реализации. Поддерживает сообщества, предприятия и пользовательские развертывания SonarQube через переменные среды. НЕ используйте для общей проверки кода без SonarQube (используйте проверку кода и качество), для контроля качества всего репозитория без SonarQube (используйте реализацию проверки качества) или для инструментов статического анализа, отличных от SonarQube. Часть коллекции afonsoft/skills.
