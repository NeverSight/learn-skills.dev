Используйте при создании диаграмм архитектуры, диаграмм систем/сервисов, топологии сети, облачной архитектуры, блок-схем, диаграмм ER или любой визуализации draw.io/diagrams.net. И вам необходимо подключить официальный сервер MCP draw.io (npx @drawio/mcp) или фактически открыть диаграммы с помощью инструментов MCP (open_drawio_xml, open_drawio_mermaid, open_drawio_csv, search_shapes, list/get/set_page). Охватывает конфигурацию сервера MCP для Claude Desktop, Claude Code, VS Code/Copilot, Cursor, OpenCode и других клиентов MCP stdio, а также встроенную разработку XML .drawio (макеты многоуровневых/swimlane/вложенных контейнеров, облачные значки, пограничную маршрутизацию, проходы компоновки libavoid/ELK). НЕ используйте для генерации кода без диаграмм или редактирования изображений. Часть коллекции afonsoft/skills.
