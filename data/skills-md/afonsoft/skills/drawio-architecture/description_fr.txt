À utiliser lors de la génération de diagrammes d'architecture, de diagrammes de système/service, de topologie de réseau, d'architecture cloud, d'organigrammes, de diagrammes ER ou de toute visualisation draw.io/diagrams.net, ET vous devez connecter le serveur draw.io MCP officiel (npx @drawio/mcp) ou ouvrir réellement des diagrammes via les outils MCP (open_drawio_xml, open_drawio_mermaid, open_drawio_csv, search_shapes, list/get/set_page). Couvre la configuration du serveur MCP sur Claude Desktop, Claude Code, VS Code/Copilot, Cursor, OpenCode et d'autres clients MCP stdio, ainsi que la création XML native .drawio (mises en page en couches/couloir/conteneur imbriqué, icônes cloud, routage périphérique, passes de mise en page libavoid/ELK). Ne PAS utiliser pour la génération de code non-diagramme ou l'édition d'images. Fait partie de la collection afonsoft/skills.
