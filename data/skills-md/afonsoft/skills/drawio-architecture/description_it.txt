Da utilizzare quando si generano diagrammi di architettura, diagrammi di sistema/servizio, topologia di rete, architettura cloud, diagrammi di flusso, diagrammi ER o qualsiasi visualizzazione draw.io/diagrams.net E è necessario collegare il server MCP draw.io ufficiale (npx @drawio/mcp) o aprire effettivamente i diagrammi tramite gli strumenti MCP (open_drawio_xml, open_drawio_mermaid, open_drawio_csv, search_shapes, list/get/set_page). Copre la configurazione del server MCP su Claude Desktop, Claude Code, VS Code/Copilot, Cursor, OpenCode e altri client MCP stdio, oltre alla creazione di XML .drawio nativi (layout a livelli/swimlane/contenitori nidificati, icone cloud, edge routing, passaggi di layout libavoid/ELK). NON utilizzare per la generazione di codice non diagramma o la modifica di immagini. Parte della raccolta afonsoft/skills.
