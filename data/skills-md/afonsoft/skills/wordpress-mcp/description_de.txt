Verwenden Sie diese Option, wenn der Benutzer WordPress-Sites über MCP (Model Context Protocol) verwalten möchte. Deckt drei Pfade ab – (A) das offizielle WordPress/mcp-Adapter-Plugin (Abilities API, 3 Meta-Tools, HTTP+STDIO-Transport, v0.6.1+ kein Composer erforderlich), (B) das AI Engine-Plugin (43-109+ Admin-Tools: Beiträge, Benutzer, Medien, Plugins, Optionen, SEO, soziale Netzwerke, AI-Bildgenerierung, Gutenberg-Blöcke) und (C) wp-mcp-ultimate (Community, 58 Fähigkeiten, OAuth 2.1, in sich geschlossen, WP 6.7+). Beinhaltet die Plugin-Installation über WP-CLI, die Einrichtung von Anwendungskennwort/Bearer-Token/OAuth, STDIO + HTTP-Transport, plattformspezifische MCP-Konfiguration (Claude Code, Devin, OpenCode, Gemini, Codex, AGY, OpenClaw), Endpunktüberprüfung und Fehlerbehebung. Wird ausgelöst, wenn der Benutzer „WordPress MCP“, „mcp-adapter“, „AI Engine MCP“, „wp-mcp-ultimate“, „WordPress für Agenten konfigurieren“ sagt oder WordPress über MCP für KI-Agenten verfügbar machen möchte. NICHT zum Erstellen eines neuen MCP-Servers verwenden (verwenden Sie „building-mcp-servers“). Teil der afonsoft/skills-Sammlung.
