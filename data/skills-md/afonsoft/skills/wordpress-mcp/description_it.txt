Utilizzare quando l'utente desidera gestire i siti WordPress tramite MCP (Model Context Protocol). Copre tre percorsi: (A) il plugin ufficiale WordPress/mcp-adapter (API Abilities, 3 meta-strumenti, trasporto HTTP+STDIO, v0.6.1+ nessun compositore necessario), (B) il plugin AI Engine (43-109+ strumenti di amministrazione: post, utenti, media, plugin, opzioni, SEO, social, generazione di immagini AI, blocchi Gutenberg) e (C) wp-mcp-ultimate (community, 58 abilità, OAuth 2.1, autonomo, WP 6.7+). Include installazione plug-in tramite WP-CLI, configurazione password applicazione/token portatore/OAuth, trasporto STDIO + HTTP, configurazione MCP per piattaforma (Claude Code, Devin, OpenCode, Gemini, Codex, AGY, OpenClaw), verifica endpoint e risoluzione dei problemi. Si attiva quando l'utente dice "WordPress MCP", "mcp-adapter", "AI Engine MCP", "wp-mcp-ultimate", "configure WordPress for agent" o desidera esporre WordPress agli agenti AI tramite MCP. NON utilizzare per creare un nuovo server MCP (utilizzare building-mcp-servers). Parte della raccolta afonsoft/skills.
