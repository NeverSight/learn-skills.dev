يُستخدم عندما يريد المستخدم إدارة مواقع WordPress عبر MCP (بروتوكول السياق النموذجي). يغطي ثلاثة مسارات - (أ) المكون الإضافي الرسمي لـ WordPress/mcp-adapter (Abilities API، 3 أدوات وصفية، نقل HTTP+STDIO، الإصدار 0.6.1+ لا حاجة إلى مؤلف)، (ب) المكون الإضافي AI Engine (43-109+ أدوات إدارية: المنشورات، المستخدمون، الوسائط، المكونات الإضافية، الخيارات، تحسين محركات البحث، الشبكات الاجتماعية، إنشاء صور AI، كتل Gutenberg)، و(C) wp-mcp-ultimate (المجتمع، 58 قدرة، OAuth 2.1، مستقل، WP 6.7+). يتضمن تثبيت البرنامج المساعد عبر WP-CLI، وكلمة مرور التطبيق / Bearer Token / إعداد OAuth، ونقل STDIO + HTTP، وتكوين MCP لكل نظام أساسي (Claude Code، وDevin، وOpenCode، وGemini، وCodex، وAGY، وOpenClaw)، والتحقق من نقطة النهاية، واستكشاف الأخطاء وإصلاحها. يتم تشغيله عندما يقول المستخدم "WordPress MCP"، أو "mcp-adapter"، أو "AI Engine MCP"، أو "wp-mcp-ultimate"، أو "تكوين WordPress للوكلاء"، أو يريد كشف WordPress لوكلاء الذكاء الاصطناعي عبر MCP. لا تستخدمه لبناء خادم MCP جديد (استخدم خوادم بناء mcp). جزء من مجموعة afonsoft/المهارات.
