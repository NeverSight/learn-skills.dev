當使用者想要透過 MCP（模型上下文協定）管理 WordPress 網站時使用。涵蓋三個路徑 - (A) 官方 WordPress/mcp-adapter 外掛程式（Abilities API、3 個元工具、HTTP+STDIO 傳輸、v0.6.1+ 無需 Composer）、(B) AI Engine 外掛程式（43-109+ 管理工具：貼文、使用者、媒體、外掛程式、選項、SEO、社交圖塊、圖塊生成） wp-mcp-ultimate（社區，58）能力，OAuth 2.1，獨立，WP 6.7+）。包括透過 WP-CLI 進行插件安裝、應用程式密碼/不記名令牌/OAuth 設定、STDIO + HTTP 傳輸、每個平台 MCP 配置（Claude Code、Devin、OpenCode、Gemini、Codex、AGY、OpenClaw）、端點驗證和故障排除。當使用者說出「WordPress MCP」、「mcp-adapter」、「AI Engine MCP」、「wp-mcp-ultimate」、「為代理程式配置 WordPress」或希望透過 MCP 將 WordPress 暴露給 AI 代理程式時觸發。請勿用於建置新的 MCP 伺服器（使用building-mcp-servers）。 afonsoft/skills 集合的一部分。
