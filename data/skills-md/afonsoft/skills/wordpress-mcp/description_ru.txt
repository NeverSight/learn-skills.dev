Используйте, когда пользователь хочет управлять сайтами WordPress через MCP (протокол контекста модели). Охватывает три пути: (A) официальный плагин WordPress/mcp-адаптера (Abilities API, 3 мета-инструмента, HTTP+STDIO транспорт, v0.6.1+ без композитора), (B) плагин AI Engine (43-109+ инструментов администрирования: публикации, пользователи, мультимедиа, плагины, параметры, SEO, социальные сети, создание изображений AI, блоки Гутенберга) и (C) wp-mcp-ultimate (сообщество, 58) возможности, OAuth 2.1, автономный, WP 6.7+). Включает установку плагина через WP-CLI, настройку пароля приложения/токена носителя/OAuth, транспорта STDIO + HTTP, конфигурацию MCP для каждой платформы (Claude Code, Devin, OpenCode, Gemini, Codex, AGY, OpenClaw), проверку конечной точки и устранение неполадок. Запускается, когда пользователь говорит «WordPress MCP», «mcp-adapter», «AI Engine MCP», «wp-mcp-ultimate», «настроить WordPress для агентов» или хочет предоставить WordPress агентам ИИ через MCP. НЕ используйте для создания нового сервера MCP (используйте Building-MCP-серверы). Часть коллекции afonsoft/skills.
