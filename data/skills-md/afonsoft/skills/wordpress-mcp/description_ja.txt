ユーザーが MCP (Model Context Protocol) 経由で WordPress サイトを管理したい場合に使用します。 3 つのパスをカバーします — (A) 公式 WordPress/mcp-adapter プラグイン (Abilities API、3 つのメタツール、HTTP+STDIO トランスポート、v0.6.1 以降コンポーザーは不要)、(B) AI エンジン プラグイン (43-109+ 管理ツール: 投稿、ユーザー、メディア、プラグイン、オプション、SEO、ソーシャル、AI 画像生成、Gutenberg ブロック)、(C) wp-mcp-ultimate (コミュニティ、58 の機能、OAuth 2.1、自己完結型、WP 6.7+)。 WP-CLI 経由のプラグインのインストール、アプリケーション パスワード / ベアラー トークン / OAuth セットアップ、STDIO + HTTP トランスポート、プラットフォームごとの MCP 構成 (Claude Code、Devin、OpenCode、Gemini、Codex、AGY、OpenClaw)、エンドポイントの検証、およびトラブルシューティングが含まれます。ユーザーが「WordPress MCP」、「mcp-adapter」、「AI Engine MCP」、「wp-mcp-ultimate」、「エージェント用に WordPress を設定」と発言したとき、または MCP 経由で WordPress を AI エージェントに公開したいときにトリガーされます。新しい MCP サーバーの構築には使用しないでください (building-mcp-servers を使用してください)。 afonsoft/スキル コレクションの一部。
