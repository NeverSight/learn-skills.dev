Úselo cuando el usuario desee administrar sitios de WordPress a través de MCP (Protocolo de contexto modelo). Cubre tres rutas: (A) el complemento oficial de WordPress/mcp-adapter (API de habilidades, 3 metaherramientas, transporte HTTP+STDIO, v0.6.1+ no se necesita compositor), (B) el complemento AI Engine (43-109+ herramientas de administración: publicaciones, usuarios, medios, complementos, opciones, SEO, redes sociales, generación de imágenes de IA, bloques de Gutenberg) y (C) wp-mcp-ultimate (comunidad, 58 habilidades, OAuth 2.1, autónomo, WP 6.7+). Incluye instalación de complemento a través de WP-CLI, configuración de contraseña de aplicación/token de portador/OAuth, transporte STDIO + HTTP, configuración de MCP por plataforma (Claude Code, Devin, OpenCode, Gemini, Codex, AGY, OpenClaw), verificación de punto final y solución de problemas. Se activa cuando el usuario dice "WordPress MCP", "mcp-adapter", "AI Engine MCP", "wp-mcp-ultimate", "configurar WordPress para agentes" o quiere exponer WordPress a agentes de IA a través de MCP. NO lo use para construir un nuevo servidor MCP (use building-mcp-servers). Parte de la colección afonsoft/skills.
