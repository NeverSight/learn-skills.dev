À utiliser lorsque l'utilisateur souhaite gérer des sites WordPress via MCP (Model Context Protocol). Couvre trois chemins : (A) le plugin officiel WordPress/mcp-adapter (API Abilities, 3 méta-outils, transport HTTP+STDIO, v0.6.1+ aucun compositeur nécessaire), (B) le plugin AI Engine (43-109+ outils d'administration : publications, utilisateurs, médias, plugins, options, SEO, social, génération d'images AI, blocs Gutenberg) et (C) wp-mcp-ultimate (communauté, 58 capacités, OAuth 2.1, autonome, WP 6.7+). Comprend l'installation du plugin via WP-CLI, la configuration du mot de passe de l'application / du jeton de porteur / OAuth, le transport STDIO + HTTP, la configuration MCP par plate-forme (Claude Code, Devin, OpenCode, Gemini, Codex, AGY, OpenClaw), la vérification des points de terminaison et le dépannage. Déclenchez lorsque l'utilisateur dit « WordPress MCP », « mcp-adapter », « AI Engine MCP », « wp-mcp-ultimate », « configurer WordPress pour les agents » ou souhaite exposer WordPress aux agents IA via MCP. Ne PAS utiliser pour créer un nouveau serveur MCP (utilisez building-mcp-servers). Fait partie de la collection afonsoft/skills.
