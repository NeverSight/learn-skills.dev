Úselo cuando el usuario quiera usar Google NotebookLM (Gemini Notebook) con un agente de IA a través de la CLI `nlm` o el servidor MCP `notebooklm-mcp`, cuando `devin mcp list` / `claude mcp list` muestra que `notebooklm-mcp` no enumera las herramientas, cuando `nlm login --check` falla con `ClientAuthenticationError`, al autenticar NotebookLM en un servidor sin navegador, al extraer cookies de Google manualmente o a través de un proveedor de CDP externo (OpenClaw), o cuando el usuario solicita configurar/autenticar/usar NotebookLM MCP. Cubre la autenticación basada en cookies (modo de archivo manual + OpenClaw CDP), la configuración del servidor MCP en todas las plataformas y la superficie de comando CLI completa `nlm`. NO lo use para construir un nuevo servidor MCP (use building-mcp-servers). Parte de la colección afonsoft/skills.
