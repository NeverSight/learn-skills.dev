À utiliser lorsque l'utilisateur souhaite utiliser Google NotebookLM (Gemini Notebook) avec un agent IA via la CLI `nlm` ou le serveur MCP `notebooklm-mcp`, lorsque `devin mcp list` / `claude mcp list` montre que `notebooklm-mcp` ne parvient pas à lister les outils, lorsque `nlm login --check` échoue avec `ClientAuthenticationError`, lors de l'authentification de NotebookLM sur un serveur sans tête sans un navigateur, lors de l'extraction manuelle des cookies Google ou via un fournisseur CDP externe (OpenClaw), ou lorsque l'utilisateur demande à configurer/authentifier/utiliser NotebookLM MCP. Couvre l'authentification basée sur les cookies (mode fichier manuel + OpenClaw CDP), la configuration du serveur MCP sur toutes les plates-formes et la surface complète des commandes CLI `nlm`. Ne PAS utiliser pour créer un nouveau serveur MCP (utilisez building-mcp-servers). Fait partie de la collection afonsoft/skills.
