يُستخدم عندما يريد المستخدم استخدام Google NotebookLM (Gemini Notebook) مع وكيل AI عبر واجهة سطر الأوامر `nlm` أو خادم MCP `notebooklm-mcp`، عندما تعرض `devin mcp list` / `claude mcp list` فشل `notebooklm-mcp` في قائمة الأدوات، عندما يفشل `nlm تسجيل الدخول --check` مع `ClientAuthenticationError`، عند مصادقة NotebookLM على خادم بدون متصفح، أو عند استخراج ملفات تعريف الارتباط من Google يدويًا أو عبر موفر CDP خارجي (OpenClaw)، أو عندما يطلب المستخدم تكوين/مصادقة/استخدام NotebookLM MCP. يغطي المصادقة المستندة إلى ملفات تعريف الارتباط (وضع الملف اليدوي + OpenClaw CDP)، وإعداد خادم MCP عبر الأنظمة الأساسية، وسطح أوامر `nlm` CLI الكامل. لا تستخدمه لبناء خادم MCP جديد (استخدم خوادم بناء mcp). جزء من مجموعة afonsoft/المهارات.
