Verwenden Sie diese Option, wenn der Benutzer Google NotebookLM (Gemini Notebook) mit einem KI-Agenten über die „nlm“-CLI oder den „notebooklm-mcp“-MCP-Server verwenden möchte, wenn „devin mcp list“ / „claude mcp list“ anzeigt, dass „notebooklm-mcp“ keine Tools auflisten kann, wenn „nlm login --check“ mit „ClientAuthenticationError“ fehlschlägt, wenn NotebookLM auf einem Headless-Server ohne a authentifiziert wird Browser, beim manuellen Extrahieren von Google-Cookies oder über einen externen CDP-Anbieter (OpenClaw) oder wenn der Benutzer NotebookLM MCP konfigurieren/authentifizieren/verwenden möchte. Deckt die Cookie-basierte Authentifizierung (manueller Dateimodus + OpenClaw CDP), die plattformübergreifende MCP-Server-Einrichtung und die vollständige „nlm“-CLI-Befehlsoberfläche ab. NICHT zum Erstellen eines neuen MCP-Servers verwenden (verwenden Sie „building-mcp-servers“). Teil der afonsoft/skills-Sammlung.
