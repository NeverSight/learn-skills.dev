Используйте, когда пользователь хочет использовать Google NotebookLM (Gemini Notebook) с агентом AI через CLI `nlm` или сервер MCP `notebooklm-mcp`, когда `devin mcp list` / `claude mcp list` показывает, что `notebooklm-mcp` не отображает список инструментов, когда `nlm login --check` завершается с ошибкой `ClientAuthenticationError`, при аутентификации NotebookLM на автономном сервере без браузере, при извлечении файлов cookie Google вручную или через внешнего поставщика CDP (OpenClaw) или когда пользователь запрашивает настройку/аутентификацию/использование NotebookLM MCP. Охватывает аутентификацию на основе файлов cookie (ручной файловый режим + OpenClaw CDP), настройку сервера MCP на разных платформах и полную командную поверхность CLI `nlm`. НЕ используйте для создания нового сервера MCP (используйте Building-MCP-серверы). Часть коллекции afonsoft/skills.
