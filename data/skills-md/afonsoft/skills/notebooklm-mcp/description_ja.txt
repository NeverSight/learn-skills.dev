ユーザーが「nlm」 CLI または「notebooklm-mcp」 MCP サーバー経由で AI エージェントで Google NotebookLM (Gemini Notebook) を使用したい場合、「devin mcp list」/「claude mcp list」で「notebooklm-mcp」がツールのリストに失敗していることが示された場合、「nlm login --check」が「ClientAuthenticationError」で失敗した場合、ヘッドレス サーバーで NotebookLM を認証するときに使用します。ブラウザで Google Cookie を手動または外部 CDP プロバイダー (OpenClaw) 経由で抽出するとき、またはユーザーが NotebookLM MCP の構成/認証/使用を要求するとき。 Cookie ベースの認証 (手動ファイル モード + OpenClaw CDP)、プラットフォーム全体での MCP サーバーのセットアップ、および完全な「nlm」 CLI コマンド サーフェイスをカバーします。新しい MCP サーバーの構築には使用しないでください (building-mcp-servers を使用してください)。 afonsoft/スキル コレクションの一部。
