Da utilizzare quando l'utente desidera utilizzare Google NotebookLM (Gemini Notebook) con un agente AI tramite la CLI `nlm` o il server MCP `notebooklm-mcp`, quando `devin mcp list` / `claude mcp list` mostra che `notebooklm-mcp` non riesce a elencare gli strumenti, quando `nlm login --check` fallisce con `ClientAuthenticationError`, quando si autentica NotebookLM su un server headless senza browser, quando si estrae Google cookie manualmente o tramite un provider CDP esterno (OpenClaw), o quando l'utente richiede di configurare/autenticarsi/utilizzare NotebookLM MCP. Copre l'autenticazione basata su cookie (modalità file manuale + OpenClaw CDP), la configurazione del server MCP su più piattaforme e l'intera superficie di comando CLI `nlm`. NON utilizzare per creare un nuovo server MCP (utilizzare building-mcp-servers). Parte della raccolta afonsoft/skills.
