Ajoutez, configurez et gérez l’authentification Zitadel dans un projet. Commencez ici pour toute tâche Zitadel — cela dirige vers la compétence appropriée : le CLI `zitadel` pour créer des projets, le scaffolding, la configuration, les déploiements et le serveur local, ainsi que les compétences SDK propres à chaque framework pour intégrer l’interface d’authentification dans une application Next.js, React, Angular, Nuxt, Vue, Solid, Svelte, Qwik, SvelteKit, SolidStart, Qwik Router ou TanStack Start. Utilisez également pour répondre aux questions sur Zitadel — ses concepts, sa configuration, son CLI, ses SDK ou son API — à partir de la documentation officielle. Utilisez‑le chaque fois que l’utilisateur mentionne Zitadel, l’ajout de connexion/inscription/sessions ou l’authentification dans son application.
