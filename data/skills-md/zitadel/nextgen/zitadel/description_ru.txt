Добавляйте, настраивайте и управляйте аутентификацией Zitadel в проекте. Начните здесь для любой задачи, связанной с Zitadel — он перенаправит вас к нужному навыку: CLI `zitadel` для создания проектов, шаблонов, конфигураций, развертываний и локального сервера, а также SDK‑навыки для каждого фреймворка, чтобы интегрировать UI аутентификации в приложение Next.js, React, Angular, Nuxt, Vue, Solid, Svelte, Qwik, SvelteKit, SolidStart, Qwik Router или TanStack Start. Также используйте его для ответов на вопросы о Zitadel — его концепциях, конфигурации, CLI, SDK или API — из официальной документации. Применяйте каждый раз, когда пользователь упоминает Zitadel, добавление входа/регистрации/сессий или аутентификацию в своём приложении.
