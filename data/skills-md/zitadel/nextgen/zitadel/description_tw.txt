在專案中新增、設定與管理 Zitadel 認證。從此處開始執行任何 Zitadel 任務——它會導向正確的技能：`zitadel` CLI 用於建立專案、腳手架、設定、部署以及本機伺服器，還有各框架的 SDK 技能，將認證 UI 整合到 Next.js、React、Angular、Nuxt、Vue、Solid、Svelte、Qwik、SvelteKit、SolidStart、Qwik Router 或 TanStack Start 應用程式。亦可用於根據官方文件回答有關 Zitadel—其概念、設定、CLI、SDK 或 API—的問題。每當使用者提及 Zitadel、在應用中加入登入/註冊/會話或認證時，都請使用此技能。
