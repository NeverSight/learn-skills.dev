Incapsula, tematizza, personalizza o controlla direttamente il componente web di login Zitadel — gli elementi Lit indipendenti dal framework `<zitadel-login>` / `<zitadel-logout>` provenienti da `@zitadel/components`. Usalo quando inserisci il widget di login in una semplice pagina HTML, stilizzandolo con i token di design `--zl-*` o i hook `::part(...)`, fissando il suo tema/variante/locale, collegando gli eventi del flusso o automatizzandolo in un browser tramite i suoi hook shadow‑DOM — cioè usando direttamente il widget di login Zitadel, al di fuori di qualsiasi wrapper SDK di framework.
