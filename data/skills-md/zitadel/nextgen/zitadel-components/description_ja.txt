Zitadel のログイン Web コンポーネントを直接埋め込んだり、テーマを設定したり、カスタマイズしたり、制御したりできます — フレームワーク非依存の `<zitadel-login>` / `<zitadel-logout>` Lit 要素（`@zitadel/components`）です。プレーンな HTML ページにログインウィジェットを配置し、`--zl-*` デザイントークンや `::part(...)` フックでスタイリングし、テーマ／バリアント／ロケールを固定し、フローイベントを接続したり、シャドウ DOM フックを利用してブラウザ上で自動化したりする場合に使用します — つまり、フレームワーク SDK ラッパーを介さずに Zitadel のログインウィジェット自体を使うシーンです。
