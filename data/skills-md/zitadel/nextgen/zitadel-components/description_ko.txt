Zitadel 로그인 웹 컴포넌트를 직접 임베드하고, 테마를 적용하거나, 커스터마이징하거나, 제어하세요 — `@zitadel/components`의 프레임워크에 구애받지 않는 `<zitadel-login>` / `<zitadel-logout>` Lit 요소입니다. 순수 HTML 페이지에 로그인 위젯을 삽입하고, `--zl-*` 디자인 토큰이나 `::part(...)` 훅으로 스타일링하거나, 테마/버전/언어를 고정하고, 플로우 이벤트를 연결하거나, 섀도우 DOM 훅을 통해 브라우저에서 자동화할 때 사용합니다 — 즉, 어떤 프레임워크 SDK 래퍼 없이 Zitadel 로그인 위젯 자체를 사용하는 경우입니다.
