Écrivez des notes de mémoire de base qui s'affichent sous forme de graphiques, de tableaux, de tableaux de bord et de tableaux de bord en direct avec les composants Comark `: : bm- *`. À utiliser lorsqu'une note se lit mieux comme une figure, une liste de contrôle, un tableau Kanban ou une vue en direct sur la base de connaissances (comptes, classements, activité récente, résultats de recherche), ou lors de la modification d'une note qui contient déjà des directives `: : bm- *`.
