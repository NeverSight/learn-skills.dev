Scrivi note Basic Memory che vengono visualizzate come grafici, tabelle, board e dashboard live con i componenti Comark `::bm-*`. Usali quando una nota risulterebbe più chiara come figura, checklist, board Kanban o una visualizzazione live del knowledge base (conteggi, classifiche, attività recenti, risultati di ricerca), o quando stai modificando una nota che contiene già direttive `::bm-*`.
