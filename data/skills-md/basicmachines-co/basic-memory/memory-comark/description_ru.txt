Пишите заметки Basic Memory, которые отображаются в виде диаграмм, таблиц, досок и живых панелей управления с помощью компонентов `::bm-*` Comark. Используйте их, когда заметка будет восприниматься лучше как иллюстрация, чеклист, канбан‑доска или живой обзор базы знаний (количества, рейтинги, недавняя активность, результаты поиска), либо при редактировании заметки, уже содержащей директивы `::bm-*`.

Пожалуйста, всегда отвечайте на языке пользователя.
