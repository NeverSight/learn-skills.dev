Erstellen und pflegen Sie SvelteKit‑3‑Anwendungen, die von Go mit skgo bereitgestellt werden. Verwenden Sie es für Go‑Remote‑Funktionen, Server‑Lasten, Routinen‑Handler, Server‑Komposition, Generierung, Entwicklung und Bereitstellung. Verwenden Sie es nicht für gewöhnliche SvelteKit‑Apps, deren Server in JavaScript läuft.
