يُطبَّق عند إنتاج أي مكوّن markdown لينقحه شخص آخر (أو نفسك المستقبلية) — ملفات README، وثائق التحليل، صفحات Confluence، تقارير الحالة، مقالات حل المشكلات، محتوى المهارات، ملخصات المحادثات، أوصاف التذاكر، تقارير ما بعد الوفاة، لقطات لحالة النظام، أو أي مستند يتضمن قيمًا ملموسة للحالة الحالية. يعرّف قاعدة “لقطة + مُعيد الإنتاج” (يجب إقران كل قيمة ثابتة بالأمر/الاستعلام/السكريبت الذي يعيد توليدها)، وقاعدة المصدر الواحد للحقيقة (الإشارة إلى المواقع الأصلية بدلاً من تكرار القيم)، وعلامة التفريق بين الحقيقة والافتراض. تشمل الكلمات المفتاحية المنبثقة كتابة أو إنتاج أو إنشاء أو صياغة ملف README، أو تحليل، أو صفحة Confluence، أو تحديث حالة، أو ملخص، أو لقطة، أو حالة حالية، أو توثيق البيانات، أو نشر النتائج، أو شجرة الملفات، أو رقم المنفذ، أو رقم الإصدار، أو عدد الجداول، أو أي قيمة ملموسة قد تتغيّر مع مرور الوقت. يرجى دائمًا الرد بلغة المستخدم.
