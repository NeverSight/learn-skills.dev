ترجمة طلبات اللغة الطبيعية حول تعديل وكيل ترميز الذكاء الاصطناعي، ومهاراته، وأدوات MCP، وخوادم MCP، والمطالبات، والتوجيه، وأوصاف الأدوات، وتحميل السياق، والذاكرة، وقابلية النقل، أو أي سلوك وكيل آخر إلى الآليات الملموسة للنظام المستهدف. يُستخدم عندما يكون الطلب غير محدد بشكل كافٍ، أو يتم صياغته بمصطلحات بشرية بدلاً من مصطلحات وقت التشغيل، أو يخاطر بإجراء تغيير خاطئ لأنه يجب على الوكيل التفكير في كيفية اختيار Codex أو Claude Code أو OpenCode أو الأنظمة المستندة إلى MCP أو أوقات التشغيل المماثلة للمهارات، واختيار الأدوات، وتحميل التعليمات، وتطبيق التكوين، والبقاء قابلاً للتحويل عبر المستخدمين والأجهزة.
