استكشاف أخطاء وتشغيل متصفح OpenClaw على البوابات المحلية أو البعيدة. استخدمه عندما يحتاج Codex إلى تمكين ملحق المتصفح المدمج، أو حل أخطاء “pairing required” أو موافقة الجهاز، أو الاختيار بين ملف التعريف المُدار `openclaw` وملف التعريف المرفق `user`، أو التعامل مع فشل تشغيل Linux بدون واجهة رسومية أو Chrome CDP، أو إثبات التحكم في المتصفح باستخدام `profiles` و`start` و`open` و`snapshot` و`screenshot`.
