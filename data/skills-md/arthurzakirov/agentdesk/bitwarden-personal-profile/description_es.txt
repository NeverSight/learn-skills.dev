Cargue, valide y use el perfil personal privado de un usuario de Bitwarden CLI para completar formularios, completar PDF, solicitudes y reutilizar identidad/contacto/empleo/vivienda. Se utiliza cuando un agente necesita datos personales estables respaldados por Bitwarden, valores de perfil conscientes del idioma, un esquema agrupado para datos personales o un flujo de trabajo seguro que materialice valores de perfil reales fuera de Git.
