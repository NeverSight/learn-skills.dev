Installieren und konfigurieren Sie `agent-browser` auf einem Windows-Computer mit WSL2, nachdem ein Browserpfad bereits funktioniert hat. Wird verwendet, wenn ein Benutzer die CLI "agent-browser", seine heruntergeladene Laufzeit, das Repository "vercel-labs/agent-browser" oder eine Anlage "agent-browser" an eine Windows-Host-Browserbrücke von WSL2 wünscht.
