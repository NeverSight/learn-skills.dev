Instale y configure `agent-browser' en una máquina Windows con WSL2 después de que una ruta del navegador ya esté funcionando. Se utiliza cuando un usuario desea la CLI del `agente-navegador`, su tiempo de ejecución descargado, el repositorio `vercel-labs/agente-navegador` o un archivo adjunto `agente-navegador` a un puente del navegador host de Windows desde WSL2.
