Installez et configurez `agent-browser` sur une machine Windows avec WSL2 une fois qu’un chemin de navigateur fonctionne déjà. Utilisez‑le lorsque un utilisateur veut le CLI `agent-browser`, son runtime téléchargé, le dépôt `vercel-labs/agent-browser`, ou une attache `agent-browser` à un pont de navigateur hôte Windows depuis WSL2.
