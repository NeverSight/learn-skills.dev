Installez et configurez les navigateurs pour Windows plus WSL2. À utiliser lorsqu'un utilisateur souhaite que Chrome Linux natif dans WSL fonctionne pour les flux de navigation ou de connexion normaux, ou lorsqu'un outil dans WSL a besoin d'une instance Chrome ou Edge hôte Windows exposée sur CDP. Préférez cette compétence avant toute configuration d’automatisation de navigateur spécifique à un outil.
