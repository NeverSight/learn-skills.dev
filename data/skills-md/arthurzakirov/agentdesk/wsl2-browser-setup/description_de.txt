Installieren und konfigurieren Sie Browser für Windows plus WSL2. Verwenden Sie diese Option, wenn ein Benutzer möchte, dass natives Linux Chrome innerhalb der WSL für normale Browsing- oder Anmeldevorgänge funktioniert, oder wenn ein Tool in der WSL eine über CDP verfügbar gemachte Windows-Host-Chrome- oder Edge-Instanz benötigt. Bevorzugen Sie diese Fertigkeit vor jeder Tool-spezifischen Browser-Automatisierungseinrichtung.
