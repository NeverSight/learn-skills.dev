Установите и настройте браузеры для Windows и WSL2. Используйте, когда пользователь хочет, чтобы нативный Linux‑Chrome внутри WSL работал для обычного веб‑просмотра или процессов входа, либо когда инструмент в WSL требует доступ к экземпляру Chrome или Edge на хосте Windows через CDP. Предпочтительно выполнить эту настройку перед любой инструмент‑специфической автоматизацией браузера.
