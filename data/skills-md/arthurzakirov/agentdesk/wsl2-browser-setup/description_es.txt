Instalar y configurar navegadores para Windows más WSL2. Úselo cuando un usuario quiera que Linux Chrome nativo dentro de WSL funcione para flujos de inicio de sesión o navegación normales, o cuando una herramienta en WSL necesita una instancia de Chrome o Edge de host de Windows expuesta a través de CDP. Prefiere esta habilidad antes que cualquier configuración de automatización del navegador específica de una herramienta.
