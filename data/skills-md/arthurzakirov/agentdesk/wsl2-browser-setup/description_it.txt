Installa e configura i browser per Windows più WSL2. Da utilizzare quando un utente desidera che Chrome Linux nativo all'interno di WSL funzioni per i normali flussi di navigazione o di accesso oppure quando uno strumento in WSL necessita di un'istanza Chrome host Windows o di Edge esposta su CDP. Preferisci questa competenza prima di qualsiasi configurazione di automazione del browser specifica per lo strumento.
