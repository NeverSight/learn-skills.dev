تثبيت وتكوين المتصفحات لنظام التشغيل Windows plus WSL2. يُستخدم عندما يريد المستخدم أن يعمل Linux Chrome الأصلي داخل WSL للتصفح العادي أو تدفقات تسجيل الدخول، أو عندما تحتاج إحدى الأدوات في WSL إلى مثيل Windows Chrome أو Edge الذي يتم عرضه عبر CDP. تفضل هذه المهارة قبل أي إعداد تلقائي للمتصفح خاص بالأداة.
