Используйте Bitwarden Agent Access CLI (`aac`) с управляемыми агентом потоками входа в браузер. Применяйте, когда пользователь хочет, чтобы AI‑агент вошёл на сайт через `aac listen`/`aac run`, одобрил учётные данные в Bitwarden Agent Access, заполнил формы входа в браузере без вывода паролей, отладил сопряжение входа в браузер через Agent Access или создал мост, учитывающий учётные данные, между инъекцией окружения `aac run` и автоматизацией браузера.
