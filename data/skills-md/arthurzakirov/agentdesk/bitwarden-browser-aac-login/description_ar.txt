استخدم Bitwarden Agent Access CLI (`aac`) مع تدفقات تسجيل الدخول إلى المتصفح التي يتحكم فيها الوكيل. يُستخدم عندما يريد المستخدم من وكيل الذكاء الاصطناعي تسجيل الدخول إلى موقع ويب من خلال `aac استمع`/`aac run`، أو الموافقة على بيانات الاعتماد في Bitwarden Agent Access، أو ملء نماذج تسجيل الدخول إلى المتصفح دون طباعة كلمات المرور، أو تصحيح أخطاء تسجيل الدخول إلى متصفح Agent Access، أو إنشاء جسر واعي لبيانات الاعتماد بين حقن env `aac run` وأتمتة المتصفح.
