Utilisez Bitwarden Agent Access CLI (`aac`) avec les flux de connexion au navigateur contrôlés par l'agent. À utiliser lorsqu'un utilisateur souhaite qu'un agent IA se connecte à un site Web via « aac Listen »/« aac run », approuve les informations d'identification dans Bitwarden Agent Access, remplisse les formulaires de connexion du navigateur sans imprimer les mots de passe, débogue le couplage de connexion du navigateur Agent Access ou crée un pont soucieux des informations d'identification entre l'injection d'environnement « aac run » et l'automatisation du navigateur.
