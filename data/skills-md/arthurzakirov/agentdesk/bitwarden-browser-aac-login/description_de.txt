Verwenden Sie die Bitwarden Agent Access CLI („aac“) mit agentengesteuerten Browser-Anmeldeabläufen. Verwenden Sie diese Option, wenn ein Benutzer möchte, dass sich ein KI-Agent über „aac listen“/„aac run“ bei einer Website anmeldet, Anmeldeinformationen in Bitwarden Agent Access genehmigt, Browser-Anmeldeformulare ausfüllt, ohne Passwörter auszudrucken, die Browser-Anmeldepaarung von Agent Access debuggt oder eine anmeldeinformationsbewusste Brücke zwischen „aac run“-Env-Injection und Browser-Automatisierung baut.
