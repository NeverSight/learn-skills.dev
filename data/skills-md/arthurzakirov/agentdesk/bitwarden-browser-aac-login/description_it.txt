Utilizza Bitwarden Agent Access CLI (`aac`) con flussi di accesso del browser controllati dall'agente. Da utilizzare quando un utente desidera che un agente AI acceda a un sito Web tramite "aac listen"/`aac run", approvi le credenziali in Bitwarden Agent Access, compili moduli di accesso al browser senza stampare password, esegua il debug dell'accoppiamento di accesso al browser Agent Access o crei un ponte attento alle credenziali tra "aac run" env injection e automazione del browser.
