Utilisez cette compétence lors de la création ou du renommage d'un dépôt GitHub, d'un produit, d'une CLI, d'un plugin, d'un pack de compétences, d'un framework, d'une application ou d'un projet public de développeur. Elle rétro‑ingénie les modèles de nommage open‑source basés sur les associations et génère le nom du produit, le slug du dépôt, le slogan, la description « À propos », les sujets, les noms rejetés et le texte principal du README.

Veuillez toujours répondre dans la langue de l'utilisateur.
