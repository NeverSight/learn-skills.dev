Ripara PDF di scansione ID di bassa qualità o impaginati in modo strano. Da utilizzare quando un PDF di un documento d'identità personale, passaporto o patente di guida richiede che il contenuto della pagina venga ruotato senza modificare l'orientamento della pagina, ingrandito per utilizzare una parte maggiore della pagina senza ritagli, rinominato con nomi file bronzo/argento/oro stabili, autocontrollato per contenuti tagliati o aperto localmente per la revisione finale.
