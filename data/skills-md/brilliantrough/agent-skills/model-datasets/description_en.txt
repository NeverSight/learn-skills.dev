Unified conventions for downloading, storing, and loading models and datasets: the platform (HF / ModelScope) is only a download tool; locally, everything should be placed under /data/models/<org>__<name> and /data/datasets/<org>__<name>, and only absolute paths are fed to transformers / datasets. Include the /data disk preparation rules for new machines (initialize or symlink when /data does not exist). Use when downloading or organizing models/datasets, deciding where to store them, using the hf / modelscope CLI, or loading with from_pretrained / load_dataset. Trigger words: where to put the model, where to put the dataset, download model, from_pretrained path, /data, hf, modelscope, where to put large files.
