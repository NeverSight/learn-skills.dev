Convenciones unificadas para descargar, almacenar y cargar modelos y conjuntos de datos: la plataforma (HF / ModelScope) es solo un método de descarga; localmente todo debe ubicarse bajo /data/models/<org>__<name> y /data/datasets/<org>__<name>, proporcionando rutas absolutas a transformers/datasets. Incluya reglas de preparación del disco /data para nuevas máquinas (inicializar o crear un enlace simbólico cuando /data no exista). Úselo al descargar u organizar modelos/conjuntos de datos, al decidir dónde almacenarlos, al utilizar la CLI de HF/ModelScope o al cargar con from_pretrained/load_dataset. Palabras clave: dónde colocar el modelo, dónde colocar el conjunto de datos, descargar modelo, ruta from_pretrained, /data, hf, modelscope, dónde colocar archivos grandes.
