Единые правила для загрузки, хранения и загрузки моделей и наборов данных: платформа (HF / ModelScope) служит лишь инструментом загрузки; локально всё должно располагаться в директориях /data/models/<org>__<name> и /data/datasets/<org>__<name>, и только абсолютные пути передаются в transformers / datasets. Включите правила подготовки диска /data для новых машин (инициализировать или создать символическую ссылку, если /data не существует). Применяйте при загрузке или организации моделей/наборов данных, при выборе места их хранения, используя CLI hf / modelscope, или при загрузке через from_pretrained / load_dataset. Ключевые слова: где разместить модель, где разместить набор данных, загрузить модель, путь from_pretrained, /data, hf, modelscope, где разместить большие файлы.
