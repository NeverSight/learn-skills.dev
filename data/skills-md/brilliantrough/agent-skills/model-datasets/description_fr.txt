Conventions unifiées pour le téléchargement, le stockage et le chargement des modèles et jeux de données : la plateforme (HF / ModelScope) n’est qu’un outil de téléchargement ; localement, tout doit être placé sous /data/models/<org>__<name> et /data/datasets/<org>__<name>, et seuls les chemins absolus sont fournis aux transformers / datasets. Inclure les règles de préparation du disque /data pour les nouvelles machines (initialiser ou créer un lien symbolique lorsque /data n’existe pas). Utiliser lors du téléchargement ou de l’organisation des modèles/jeux de données, du choix de l’emplacement de stockage, en utilisant les CLI hf / modelscope, ou lors du chargement avec from_pretrained / load_dataset. Mots déclencheurs : où placer le modèle, où placer le jeu de données, télécharger le modèle, chemin from_pretrained, /data, hf, modelscope, où placer les gros fichiers.
