モデルとデータセットのダウンロード、保存、ロードに関する統一規約：プラットフォーム（HF / ModelScope）は単なるダウンロードツールにすぎません。ローカルではすべてを `/data/models/<org>__<name>` と `/data/datasets/<org>__<name>` の下に配置し、Transformers / Datasets には絶対パスのみを渡すようにします。新しいマシン向けの `/data` ディスク準備ルール（`/data` が存在しない場合は初期化またはシンボリックリンクを作成）も含めてください。モデルやデータセットをダウンロード・整理する際、保存場所を決める際、hf / ModelScope CLI を使用する際、あるいは `from_pretrained` / `load_dataset` でロードする際にこの規約を適用します。トリガーワード：モデルの配置場所、データセットの配置場所、モデルダウンロード、`from_pretrained` パス、`/data`、hf、ModelScope、大容量ファイルの配置場所。
