Convenzioni unificate per il download, l'archiviazione e il caricamento di modelli e dataset: la piattaforma (HF / ModelScope) è solo uno strumento di download; localmente, tutto deve essere collocato sotto /data/models/<org>__<name> e /data/datasets/<org>__<name>, e solo percorsi assoluti vengono passati a transformers / datasets. Includere le regole di preparazione del disco /data per nuove macchine (inizializzare o creare un symlink quando /data non esiste). Utilizzare quando si scaricano o organizzano modelli/dataset, si decide dove archiviarli, si usa la CLI hf / modelscope, o si carica con from_pretrained / load_dataset. Parole chiave: dove mettere il modello, dove mettere il dataset, scaricare modello, percorso from_pretrained, /data, hf, modelscope, dove mettere file di grandi dimensioni.
