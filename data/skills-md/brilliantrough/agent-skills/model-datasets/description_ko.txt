모델 및 데이터셋의 다운로드, 영구 저장, 로드에 대한 통합 규칙: 플랫폼(HF / ModelScope)은 단지 다운로드 도구일 뿐이며, 로컬에서는 모든 것이 /data/models/<org>__<name> 및 /data/datasets/<org>__<name> 아래에 배치되어야 하고, 절대 경로만이 transformers / datasets에 전달됩니다. 여기에는 새로운 머신에서 /data 디스크를 준비하는 규칙( /data가 존재하지 않으면 초기화하거나 심링크 생성)이 포함됩니다. 모델/데이터셋을 다운로드하거나 정리할 때, 저장 위치를 결정할 때, hf / ModelScope CLI를 사용할 때, 혹은 from_pretrained / load_dataset으로 로드할 때 사용합니다. 트리거 단어: 모델을 어디에 놓을지, 데이터셋을 어디에 놓을지, 모델 다운로드, from_pretrained 경로, /data, hf, ModelScope, 큰 파일을 어디에 놓을지.
