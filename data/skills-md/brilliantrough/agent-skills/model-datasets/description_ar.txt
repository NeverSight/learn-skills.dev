الاتفاقيات الموحدة لتنزيل النماذج ومجموعات البيانات وتخزينها وتحميلها: المنصة (HF / ModelScope) هي مجرد أداة تنزيل؛ محليًا، يجب وضع كل شيء تحت ‎/data/models/<org>__<name>‎ و ‎/data/datasets/<org>__<name>‎، ويُمرّر فقط مسارات مطلقة إلى ‎transformers / datasets. تضمّن قواعد إعداد قرص ‎/data‎ للأجهزة الجديدة (تهيئة أو إنشاء ارتباط رمزي عندما لا يكون ‎/data‎ موجودًا). استخدم ذلك عند تنزيل أو تنظيم النماذج/مجموعات البيانات، وتحديد موقع تخزينها، باستخدام واجهة سطر الأوامر ‎hf / modelscope‎، أو التحميل عبر ‎from_pretrained / load_dataset‎. كلمات التحفيز: أين وضع النموذج، أين وضع مجموعة البيانات، تنزيل النموذج، مسار ‎from_pretrained‎، ‎/data‎، ‎hf‎، ‎modelscope‎، أين وضع الملفات الكبيرة.
