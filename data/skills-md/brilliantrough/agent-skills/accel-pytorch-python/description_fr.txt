Couche Python/wheel : créer ou réparer un environnement Python pour la pile PyTorch de la plateforme d’accélération — politiques source fournisseur vs source publique, matrice de compatibilité des versions, variables d’environnement, procédure d’installation, vérification et échecs courants, applicables à toute plateforme fournisseur. À utiliser lors de la création ou de la réparation d’un environnement Python pour le PyTorch de la plateforme d’accélération (back‑end torch du fournisseur, torchvision/torchaudio, plateforme Triton, bibliothèques de communication du fournisseur) sur n’importe quelle plateforme. Le texte principal correspond à l’instance actuellement vérifiée (actuellement source MUSA/Moore Thread) ; pour une plateforme qui n’est pas encore initialisée, réécrire d’abord le texte principal selon l’en-tête « Comment spécialiser ». Mots déclencheurs : installer torch, source wheel, correspondance de version, source pip, conflits de dépendances.
