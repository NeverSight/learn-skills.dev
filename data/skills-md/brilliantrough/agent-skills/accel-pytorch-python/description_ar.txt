طبقة Python/wheel: إنشاء أو إصلاح بيئة Python لمكدس PyTorch لمنصة المسارّعات — سياسات المصدر للمورد مقابل المصدر العام، مصفوفة توافق الإصدارات، متغيرات البيئة، إجراءات التثبيت، التحقق والأخطاء الشائعة، قابلة للتطبيق على أي منصة مورد. استخدمها عند إنشاء أو إصلاح بيئة Python لـ PyTorch على منصة المسارّعات (واجهة torch الخلفية من المورد، torchvision/torchaudio، منصة Triton، مكتبات التواصل من المورد) على أي منصة. النص الرئيسي هو الحالة التي تم التحقق منها حاليًا (حاليًا مصدر MUSA/Moore Thread)؛ بالنسبة لمنصة لم تُنشأ بعد، أعد كتابة النص الرئيسي وفقًا للعنوان “كيفية التخصيص”. كلمات التحفيز: تثبيت torch، مصدر wheel، مطابقة الإصدارات، مصدر pip، تضارب الاعتماديات.
