Capa Python/wheel: Crear o reparar un entorno Python para la pila PyTorch de la plataforma de aceleradores—políticas de fuente del proveedor vs. fuente pública, matriz de compatibilidad de versiones, variables de entorno, proceso de instalación, verificación y fallas comunes, aplicable a cualquier plataforma de proveedor. Úselo al crear o reparar un entorno Python para la plataforma‑aceleradora PyTorch (backend torch del proveedor, torchvision/torchaudio, Triton de la plataforma, bibliotecas de comunicación del proveedor) en cualquier plataforma. El texto principal proporciona un ejemplo actualmente validado (actualmente fuente de subprocesos MUSA/Moore); para una plataforma que no haya sido inicializada antes, primero reescriba el texto principal según el encabezado “Cómo especializar”. Palabras clave: instalar torch, fuente wheel, coincidencia de versiones, fuente pip, conflictos de dependencias.
