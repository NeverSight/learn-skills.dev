Слой Python/wheel: Создайте или восстановите окружение Python для стека PyTorch платформы ускорителей — политика использования исходного кода поставщика vs публичного исходного кода, матрица совместимости версий, переменные среды, процедура установки, проверка и типичные ошибки, применимо к любой платформе поставщика. Используйте при создании или восстановлении окружения Python для PyTorch на платформе ускорителей (бекенд torch от поставщика, torchvision/torchaudio, платформа Triton, библиотеки связи от поставщика) на любой платформе. Основной текст — текущий проверенный пример (в настоящее время источник MUSA/Moore Thread); для платформы, ещё не инициализированной, сначала перепишите основной текст согласно заголовку «Как специализировать». Ключевые слова‑триггеры: установить torch, источник wheel, сопоставление версий, источник pip, конфликты зависимостей.
