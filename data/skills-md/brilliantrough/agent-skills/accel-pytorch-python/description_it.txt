Strato Python/wheel: crea o ripara un ambiente Python per lo stack PyTorch della piattaforma di accelerazione — politiche sorgente del fornitore vs sorgente pubblica, matrice di compatibilità delle versioni, variabili d'ambiente, procedura di installazione, verifica e problemi comuni, applicabile a qualsiasi piattaforma del fornitore. Usa quando crei o ripari un ambiente Python per PyTorch della piattaforma di accelerazione (backend torch del fornitore, torchvision/torchaudio, piattaforma Triton, librerie di comunicazione del fornitore) su qualsiasi piattaforma. Il testo principale è l'istanza attualmente verificata (attualmente sorgente MUSA/Moore Thread); per una piattaforma non ancora inizializzata, riscrivi prima il testo principale secondo l'intestazione “Come specializzare”. Parole chiave: install torch, wheel source, version matching, pip source, dependency conflicts.
