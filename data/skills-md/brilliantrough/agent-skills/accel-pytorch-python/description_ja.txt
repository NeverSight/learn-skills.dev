Python/wheelレイヤー：アクセラレータプラットフォームのPyTorchスタック用にPython環境を作成または修復する — ベンダーソースとパブリックソースの方針、バージョン互換性マトリックス、環境変数、インストール手順、検証および一般的な失敗例、すべてのベンダープラットフォームに適用可能。アクセラレータプラットフォームのPyTorch（ベンダーtorchバックエンド、torchvision/torchaudio、プラットフォームTriton、ベンダー通信ライブラリ）用にPython環境を作成または修復するときに使用する。本文は現在検証済みのインスタンス（現在はMUSA/Moore Threadソース）です；未初期化のプラットフォームの場合は、まずヘッダー「How to specialize」に従って本文を書き換えてください。トリガーワード：install torch、wheel source、version matching、pip source、dependency conflicts。
