Слой кода: писать/портировать/отлаживать/запускать код приложений PyTorch на локальной платформе ускорителя — отображение CUDA→API платформы, абстракция обнаружения устройств, AMP и численная стабильность, распределённые вычисления, совместимость сторонних пакетов, чек‑лист миграционного аудита, применимо к любой платформе поставщика. Используйте ТОЛЬКО при написании, портировании, обзоре, отладке или запуске кода приложений для локальной платформы ускорителя. Основной текст — текущий проверенный пример (в данный момент таблица отображения MUSA/CUDA→MUSA); для иных платформ перепишите основной текст согласно заголовку «Как специализировать» при первой инициализации. Используйте accel-pytorch-python для Python‑окружения и обёртки, а accel-platform-install для системной установки. Триггерные слова: портирование, переписывание torch.cuda, обнаружение устройств, is_available, распределённый бекенд, совместимость операторов.
