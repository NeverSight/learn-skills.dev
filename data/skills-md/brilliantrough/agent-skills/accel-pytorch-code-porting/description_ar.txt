طبقة الشيفرة: كتابة/نقل/تصحيح/تشغيل كود تطبيق PyTorch على منصة المعجِّل المحلي — تحويل من CUDA إلى واجهة برمجة التطبيقات للمنصة، تجريد اكتشاف الجهاز، AMP والاستقرار العددي، الحوسبة الموزَّعة، توافق الحزم الخارجية، قائمة تدقيق ترحيل، قابل للتطبيق على أي منصة بائع. استخدمها فقط عند كتابة أو نقل أو مراجعة أو تصحيح أو تشغيل كود التطبيق لمنصة المعجِّل المحلي. النص الرئيسي هو المثال المؤكد حالياً (حالياً جدول تحويل MUSA/CUDA→MUSA)؛ بالنسبة للمنصات غير هذه، أعد كتابة النص الرئيسي وفقًا للعنوان “كيف تتخصص” أثناء التهيئة الأولى. استخدم accel-pytorch-python لبيئة Python والواجهة، وaccel-platform-install للتثبيت على مستوى النظام. كلمات التحفيز: النقل، إعادة كتابة torch.cuda، اكتشاف الجهاز، is_available، الخلفية الموزَّعة، توافق العمليات.
