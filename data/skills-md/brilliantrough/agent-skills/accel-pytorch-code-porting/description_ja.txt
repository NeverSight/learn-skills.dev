コード層: ローカルアクセラレータプラットフォーム上で PyTorch アプリケーションコードを書き/移植/デバッグ/実行する――CUDA→プラットフォーム API マッピング、デバイス検出抽象化、AMP と数値安定性、分散コンピューティング、サードパーティパッケージ互換性、移行監査チェックリスト、任意のベンダープラットフォームに適用可能。ローカルアクセラレータプラットフォーム向けにアプリケーションコードを書いたり、移植したり、レビューしたり、デバッグしたり、実行したりする場合にのみ使用してください。本文は現在検証済みの例（現在は MUSA/CUDA→MUSA マッピングテーブル）です；それ以外のプラットフォームの場合は、初回初期化時に「How to specialize」ヘッダーに従って本文を書き換えてください。Python 環境とラッパーには accel-pytorch-python、システムレベルのインストールには accel-platform-install を使用します。トリガーワード: porting、torch.cuda rewrite、device discovery、is_available、distributed backend、operator compatibility。
