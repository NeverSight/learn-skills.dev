Couche de code : écrire/porter/déboguer/exécuter du code d'application PyTorch sur la plateforme d'accélérateur locale — mappage API CUDA→plateforme, abstraction de la découverte des dispositifs, AMP et stabilité numérique, calcul distribué, compatibilité avec les packages tiers, checklist d'audit de migration, applicable à toute plateforme fournisseur. Utilisez uniquement lors de l'écriture, du portage, de la révision, du débogage ou de l'exécution du code d'application pour la plateforme d'accélérateur locale. Le texte principal est l'exemple actuellement vérifié (actuellement le tableau de mappage MUSA/CUDA→MUSA) ; pour les autres plateformes, réécrivez le texte principal selon l’en-tête « Comment spécialiser » lors de la première initialisation. Utilisez accel-pytorch-python pour l’environnement Python et le wrapper, et accel-platform-install pour l’installation au niveau système. Mots déclencheurs : portage, réécriture torch.cuda, découverte de dispositif, is_available, backend distribué, compatibilité des opérateurs.
