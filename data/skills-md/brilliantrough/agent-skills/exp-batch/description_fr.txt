Exécutez une branche d’expérimentation de recherche bornée dans la session en cours avec le goût ponytail-for-experiments. Utilisez‑la lorsqu’elle est explicitement demandée, ou pour un lot cohérent d’exécutions avec une configuration connue (une méthode × jeu de données × budget, ou une branche d’ablation d’une campagne). Vérifiez d’abord que la branche n’a pas déjà été élaguée ou résolue, interrogez uniquement les décisions de configuration non résolues, effectuez un pré‑vol de l’environnement et des ressources, lancez les exécutions selon les conventions du projet, puis enregistrez les métriques dans le tableau partagé sous une forme utilisable directement par les figures finales. Privilégiez exp-discuss quand l’idée est encore vague et nécessite une discussion ; privilégiez exp-campaign quand le travail requiert un élagage progressif des branches ; privilégiez exp-probe pour des vérifications ponctuelles.

Veuillez toujours répondre dans la langue de l’utilisateur.
