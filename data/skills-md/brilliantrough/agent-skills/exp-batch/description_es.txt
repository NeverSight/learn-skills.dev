Ejecuta una rama de experimento de investigación delimitada en la sesión actual con sabor ponytail-for-experiments. Úsala cuando se solicite explícitamente, o para un lote coherente único de ejecuciones con configuración conocida (un método × conjunto de datos × presupuesto, o una rama de ablación de una campaña). Primero verifica que la rama no haya sido ya podada o respondida, interroga solo las decisiones de configuración no resueltas, realiza una verificación previa del entorno y los recursos, ejecuta según las convenciones del proyecto y registra las métricas en la tabla compartida en una forma que las cifras finales puedan usar directamente. Prefiere exp-discuss cuando la idea sigue siendo vaga y necesita discutirse; prefiere exp-campaign cuando el trabajo requiere poda escalonada entre ramas; prefiere exp-probe para verificaciones puntuales aisladas.

Por favor, responde siempre en el idioma del usuario.
