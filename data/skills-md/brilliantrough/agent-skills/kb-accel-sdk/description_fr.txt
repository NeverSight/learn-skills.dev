Base de connaissances publique : un référentiel rapide pour la composition du SDK, les méthodes d’installation, les écosystèmes Triton et TileLang, ainsi que les écosystèmes des cadres d’inférence VLLM et SGLang des principales plateformes d’accélération (CUDA, MUSA, Ascend CANN, ROCm, Alibaba PPU, Muxi MACA). Utilisez‑le lorsque vous travaillez sur n’importe quel serveur d’accélération, choisissez les versions du SDK/roue/cadre d’inférence, ou lorsqu’un paquet ou un comportement spécifique à une plateforme vous surprend. Compétence de type connaissance : peut être écrasée et rafraîchie, pas spécialisée pour la machine locale ; de nouveaux faits sont renvoyés au référentiel via le processus de compétence d’écriture. Mots déclencheurs : composition du SDK, installer CANN, torch_npu, vllm Ascend, sglang carte domestique, fork Triton, tilelang, PPU.
