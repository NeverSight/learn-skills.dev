Общедоступная база знаний: Быстрый справочник по составу SDK, методам установки, экосистемам Triton и TileLang, а также экосистемам фреймворков вывода VLLM и SGLang для основных ускорительных платформ (CUDA, MUSA, Ascend CANN, ROCm, Alibaba PPU, Muxi MACA). Используйте её при работе с любым ускорительным сервером, выборе версий SDK/колеса/фреймворка вывода или когда пакет или поведение, специфичное для платформы, вызывает удивление. Навык типа «знание»: может быть перезаписан и обновлен, не специализирован для конкретной машины; новые факты возвращаются в репозиторий через процесс навыка письма. Триггерные слова: состав SDK, установить CANN, torch_npu, vllm Ascend, sglang отечественная карта, форк triton, tilelang, PPU.
