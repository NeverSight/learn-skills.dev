Entwerfen Sie eine gestufte, beschneidbare Forschungs‑Experimentkampagne für die Idee, Hypothese oder Optimierungsrichtung eines Forschers, mit Ponytail‑for‑Experiments‑Geschmack. Verwenden Sie sie, wenn ausdrücklich danach gefragt wird oder wenn ein Forscher eine Richtung vorschlägt, die viele Experimente, Ablationszweige oder faktorübergreifende Sweeps erfordert. Beobachten Sie bestehende Ergebnisse, befragen Sie den Forscher, um ein gemeinsames Verständnis zu erreichen, enumerieren Sie den maximalen Experimentraum und beschneiden Sie ihn anschließend mit günstigen Probe‑Experimenten, deren Ergebnisse entscheiden, welche Zellen niemals ausgeführt werden; liefern Sie einen Entscheidungsbaum‑Plan mit Beobachtungsgattern und dem finalen Metrik‑/Figur‑Design und übergeben Sie die Ausführung pro Stufe an exp‑batch. Für einen einzelnen, begrenzten Experimentzweig verwenden Sie exp‑batch; für einmalige Stichprobenprüfungen verwenden Sie exp‑probe.
