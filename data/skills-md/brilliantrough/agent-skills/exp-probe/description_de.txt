Führen Sie einmalige Forschungs‑Spot‑Experimente mit minimalem Aufwand durch. Verwenden Sie sie, wenn sie ausdrücklich angefordert werden, für einen fehlenden Datenpunkt, einen Neustart nach einem Fehler (OOM, Absturz), einen Sanity‑Check einer Konfiguration, eine minimale Fehlerreproduktion oder eine günstige Messung, die eine Kampagne vor einer Entscheidung benötigt. Höchstens eine fokussierte Frage; ausführen, aufzeichnen, in einer Zeile berichten. Eskalieren Sie zu exp‑batch, wenn der Spot‑Check zu einem Zweig wird, oder zu exp‑campaign, wenn er einen Entscheidungsbaum offenbart; ist die Frage selbst noch vage, zurück zu exp‑discuss leiten.
