Ejecuta experimentos puntuales de investigación únicos con la mínima ceremonia. Úsalo cuando se solicite explícitamente, o para un punto de datos faltante, una reejecución tras un fallo (OOM, bloqueo), una comprobación de sanidad de una configuración, una reproducción mínima de un error, o una medición económica que una campaña necesita antes de decidir. Como máximo una pregunta enfocada; ejecuta, registra, informa en una sola línea. Escala a exp‑batch si la verificación puntual se convierte en una rama, o a exp‑campaign si revela un árbol de decisiones; si la propia pregunta sigue siendo difusa, redirige a exp‑discuss.
