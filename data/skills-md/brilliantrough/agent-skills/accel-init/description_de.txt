Haupt‑Einstiegspunkt zur Initialisierung einer Deep‑Learning‑Rechnerplattform: Die Beschleunigerplattform und ihren aktuellen Zustand erkennen (oder vom Benutzer direkt mitgeteilt bekommen), eine duale Python‑Grundlage einrichten (miniconda + uv + Tsinghua‑Quelle), Plattformrecherchen zur Kompatibilität von Wheel‑Matrix/Fork/Ecosystem durchführen, einen Plan erstellen, ausführen, die Validierungsschritte durchlaufen und schließlich an das accel‑skill‑template zur Bereitstellung übergeben. Verwenden, wenn ein frischer Rechner‑Server für Deep Learning (CUDA/MUSA/Ascend/ROCm‑Treiber, SDKs, PyTorch, Triton, Transformers‑Ökosystem) eingerichtet wird, wenn man aufgefordert wird, die Rechnerumgebung zu initialisieren/den Plattform‑Stack zu installieren/einen neuen Server für Deep Learning zu konfigurieren oder wenn ein Plattform‑Stack repariert und neu validiert werden muss. Wenn nur eine Python‑Umgebung ohne Plattformbeteiligung benötigt wird, dem üblichen Verfahren folgen; siehe accel‑skill‑template für Details zur Bereitstellungsvorlage.
