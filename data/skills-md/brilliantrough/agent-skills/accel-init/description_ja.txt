ディープラーニング計算プラットフォームを初期化するための主要エントリーポイント：アクセラレータプラットフォームとその現在の状態を検出（またはユーザーに直接指定させ）し、Python のデュアルスタック基盤（miniconda + uv + 清華ソース）をセットアップし、ホイールマトリックス／フォーク／エコシステムの互換性に関するプラットフォーム調査を実施し、計画を立案・実行し、検証ステップを経て、最終的に accel‑skill‑template に引き継いで実装する。新規のディープラーニング計算サーバーを構築する場合（CUDA／MUSA／Ascend／ROCm ドライバ、SDK、PyTorch、Triton、Transformers エコシステム）や、計算環境の初期化・プラットフォームスタックのインストール・新サーバーの設定を依頼されたとき、またはプラットフォームスタックの修復と再検証が必要なときに使用する。プラットフォームに関わらず Python 環境だけが必要な場合は、通常の手順を直接実行すること。実装テンプレートの詳細は accel‑skill‑template を参照。
