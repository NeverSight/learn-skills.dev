Punto di ingresso principale per l'inizializzazione di una piattaforma di calcolo per deep learning: rilevare (o essere direttamente informati dall'utente) la piattaforma di accelerazione e il suo stato attuale, configurare una base Python a doppio stack (miniconda + uv + mirror di Tsinghua), analizzare la compatibilità della matrice di wheel/fork/ecosistema della piattaforma, elaborare un piano, eseguirlo, attraversare le fasi di convalida e infine passare al accel‑skill‑template per il deployment. Da usare quando si allestisce un server di calcolo nuovo per deep learning (driver CUDA/MUSA/Ascend/ROCm, SDK, PyTorch, Triton, ecosistema Transformers), quando viene richiesto di inizializzare l'ambiente di calcolo/installare lo stack della piattaforma/configurare un nuovo server per deep learning, o quando uno stack di piattaforma necessita di riparazione e ri‑convalida. Se è necessario solo un ambiente Python senza componenti di piattaforma, seguire la procedura normale; consultare accel‑skill‑template per i dettagli del modello di deployment.
