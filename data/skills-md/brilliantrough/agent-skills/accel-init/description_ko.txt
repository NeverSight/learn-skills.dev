딥러닝 컴퓨트 플랫폼 초기화의 주요 진입점: 가속기 플랫폼과 현재 상태를 감지(또는 사용자가 직접 명시)하고, 듀얼 스택 파이썬 베이스(miniconda + uv + Tsinghua 미러)를 설정한 뒤, 휠 매트릭스/포크/에코시스템 호환성에 대한 플랫폼 연구를 수행하고, 계획을 수립·실행하며 검증 절차를 거친 후 최종적으로 accel‑skill‑template에 넘겨 배포한다. 딥러닝을 위한 새 컴퓨트 서버(CUDA/MUSA/Ascend/ROCm 드라이버, SDK, PyTorch, Triton, transformers 에코시스템)를 설정할 때, 컴퓨트 환경을 초기화·플랫폼 스택을 설치·새 서버를 딥러닝용으로 구성해야 할 때, 혹은 플랫폼 스택이 고장 나 재검증이 필요할 때 사용한다. 플랫폼과 무관하게 파이썬 환경만 필요한 경우에는 일반 절차를 따르고, 배포 템플릿 세부 사항은 accel‑skill‑template을 참고한다.
