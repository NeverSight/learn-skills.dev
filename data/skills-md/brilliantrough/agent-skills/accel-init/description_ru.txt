Главная точка входа инициализации вычислительной платформы глубокого обучения: обнаружить (или получить от пользователя напрямую) платформу ускорителя и её текущий статус, установить двойную основу Python (miniconda + uv + зеркало Tsinghua), изучить совместимость колёсных матриц/форков/экосистемы платформы, разработать план, выполнить его, пройти через лестницу валидации и, наконец, передать управление шаблону accel‑skill‑template для сохранения. Применяется при настройке нового вычислительного сервера для глубокого обучения (драйверы, SDK CUDA/MUSA/Ascend/ROCm и т.д., PyTorch, Triton, экосистема Transformers), когда нужно инициализировать вычислительную среду/установить стек платформы/сконфигурировать новый сервер для среды глубокого обучения, либо когда стек платформы требует восстановления и повторной валидации. Если требуется только Python‑окружение без участия платформы, следуйте обычному процессу; см. детали шаблона в accel‑skill‑template.
