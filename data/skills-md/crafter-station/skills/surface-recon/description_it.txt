Mappare un obiettivo autorizzato in contratti supportati da prove e produrre un rapporto di ricognizione da cui un implementatore può basarsi. Utilizzare per API Web o mobili, portali di accesso, app desktop, CLI, SDK, server MCP, daemon locali, formati di file e progetti, dispositivi USB/BLE/seriale/HID, pacchetti firmware, runtime e acceleratori. Si attiva quando l'utente dice di effettuare una ricognizione, effettuare il reverse engineering, mappare l'interfaccia o il protocollo, ispezionare un'integrazione non documentata, scoprire cosa supporta effettivamente un dispositivo o desidera creare un client, CLI, MCP, SDK, adattatore o un'implementazione compatibile prima che il relativo contratto venga verificato.
