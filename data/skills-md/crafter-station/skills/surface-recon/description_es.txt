Asigne un objetivo autorizado a contratos respaldados por evidencia y produzca un informe de reconocimiento a partir del cual un implementador pueda construir. Úselo para API web o móvil, portales de inicio de sesión, aplicaciones de escritorio, CLI, SDK, servidores MCP, demonios locales, formatos de archivos y proyectos, dispositivos USB/BLE/serial/HID, paquetes de firmware, tiempos de ejecución y aceleradores. Se activa cuando el usuario dice realizar reconocimiento, realizar ingeniería inversa, mapear la interfaz o el protocolo, inspeccionar una integración no documentada, descubrir qué es lo que realmente admite un dispositivo o quiere crear un cliente, CLI, MCP, SDK, adaptador o implementación compatible antes de que se verifique su contrato.
