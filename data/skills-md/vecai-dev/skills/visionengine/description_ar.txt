VisionEngine (视擎科技) سطر أوامر قدرات الذكاء الاصطناعي للوسائط: يغطي إنشاء الصور/التحرير/التعرف/الهندسة العكسية السريعة، وتوليف الكلام واستنساخ الصوت، وتوليد الترجمة والتوقيت، وإعادة عرض نمط الصورة إلى فيديو/نص إلى فيديو/فيديو/فهم الفيديو، ومزامنة الشفاه البشرية الرقمية، وإدارة ملفات مساحة عمل Remotion والعرض عن بعد، وإنشاء كتابة النصوص LLM. عندما يطلب المستخدم إنشاء صورة أو فيديو، أو دبلجة الفيديو، أو استنساخ الصوت، أو الإنشاء البشري الرقمي، أو إنشاء الترجمة أو النسخ، أو نقل نمط الفيديو، أو تحميل الأصول إلى مساحة عمل Remotion، أو تقديم إخراج Remotion النهائي، أو مطالبات الصور الهندسية العكسية، أو الإشارة إلى مهمة وسائط تتعلق بـ VisionEngine / 视擎 / ve، استخدم هذه المهارة - حتى إذا لم يذكر المستخدم اسم VisionEngine بشكل صريح، طالما أن المهمة تقع ضمن إمكانات الذكاء الاصطناعي للوسائط المذكورة أعلاه، فيجب استخدامها. لا ينطبق على معالجة ffmpeg المحلية الخالصة أو مهام التشفير العامة غير المرتبطة بمنصة VisionEngine.
