سطر أوامر قدرات الذكاء الاصطناعي لوسائط VisionEngine (ShiQing Technology): يغطي إنشاء الصور/تحريرها/التعرف عليها/الهندسة العكسية السريعة، وتوليف الكلام واستنساخ الصوت، وإنشاء الترجمة وتوقيتها، وإعادة رسم نمط الصورة إلى فيديو/نص إلى فيديو/فيديو/فهم الفيديو، ومزامنة الشفاه البشرية الرقمية، وإدارة ملفات مساحة عمل Remotion والعرض عن بُعد، وإنشاء كتابة النصوص LLM. عندما يطلب المستخدم إنشاء صور أو مقاطع فيديو، أو دبلجة مقطع فيديو، أو استنساخ صوت، أو إنشاء إنسان رقمي، أو إنشاء ترجمات مصاحبة أو نسخ صوتي، أو إجراء نقل نمط الفيديو، أو تحميل المواد إلى مساحة عمل Remotion، أو عرض مخرجات Remotion النهائية، أو مطالبات الصور ذات الهندسة العكسية، أو ذكر مهام الوسائط VisionEngine / ShiQing / ve، يجب استخدام هذه المهارة - حتى إذا لم يذكر المستخدم اسم VisionEngine صراحةً، طالما أن المهمة تقع ضمن قدرة الذكاء الاصطناعي للوسائط المذكورة أعلاه النطاق الذي ينبغي استخدامه. لا ينطبق على معالجة ffmpeg المحلية الخالصة أو مهام التشفير العامة غير المرتبطة بمنصة VisionEngine.
