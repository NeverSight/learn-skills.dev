تصفح ميزات موقع إثيرسكان، ونقاط النهاية للواجهة البرمجية (API)، وأوامر سطر الأوامر (CLI)، وأدوات MCP. استخدمه عند اختيار واجهة إثيرسكان، أو العثور على صفحة مستكشف أو أداة مطور، أو بناء أو تشخيص طلبات الـ API، أو أتمتة سير العمل في الطرفية، أو الاتصال بأدوات إثيرسكان MCP أو استدعائها، أو التعامل مع المصادقة، أو التأكد من دعم السلسلة، أو تفسير الأخطاء، أو مقارنة القدرات والحدود والسلوك عبر واجهات إثيرسكان. يرجى دائمًا الرد بلغة المستخدم.
