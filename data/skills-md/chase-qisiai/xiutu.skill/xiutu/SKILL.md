# 修图

## 核心原则

- 先判断用户是“自动修图”还是“主动修图”。
- 使用提示词库前，读取 `references/prompt-library.md`；当前文件保留项目原始提示词的原顺序和原文，不自行分类或改写库内文本。
- 用户要求整套职场证件照时，额外读取 `references/workplace-id-photo-prompts.md`，不要把六组提示词压缩成一组。
- 优先复用库内提示词；没有合适匹配时，再根据用户意图自行编写提示词。
- 只改变用户要求或已确认的部分，尽量保留人物身份、姿态、构图、服装、背景和其他未要求内容。
- 能调用当前环境的内置生图工具时直接调用；没有可用生图工具时，返回整理好的最终提示词，明确告诉用户可复制到其他生图平台。

## 先判断工作模式

### 自动修图

适用于用户只上传图片，或说“自动修图”“帮我优化一下”但没有明确指定修改内容的情况。

1. 检查图片是否可见，并基于图片实际内容判断可能需要改善的地方；看不到图片时先要求用户重新上传，不要猜测画面问题。
2. 从提示词库匹配候选提示词。说明每条候选会改变什么，并列出不会改变什么。
3. 如果判断为人像照片，优先把以下三项作为候选：`消除背景游客`、`自动调光`、`自动美颜`。只有图片确实适合时才推荐每一项，不能因为默认偏好而虚构背景游客或强行美容。
4. 把候选修改交给用户确认。用户确认前不得调用生图工具。
5. 用户确认后，按“画面清理 → 基础光色 → 人像局部 → 明确指定的风格”整理并组合提示词，再执行生图。

确认信息尽量简短，至少包含：发现的问题、准备采用的提示词、可能保留的内容，以及用户可以删改的项目。

### 主动修图

适用于用户上传图片并给出具体要求，例如“去掉后面的人”“把光线调自然一点”“做成直闪风格”。

1. 先用自然语言理解用户真正想改变的对象、程度和风格。
2. 在 `references/prompt-library.md` 中按标题和正文语义查找最接近的提示词；可以组合多个提示词，但不要重复同一要求。
3. 需求明确时直接执行生图，并在执行前简要说明采用了哪些提示词；需求存在关键歧义时，只问一个最必要的澄清问题。
4. 没有库内匹配时，自行编写完整提示词，并沿用“未要求部分保持不变”的边界。

## 一整套职场证件照

当用户提出“一整套职场证件照”“六张职业头像”“六套职场形象照”等明确请求，并已上传人物照片时，使用 `references/workplace-id-photo-prompts.md` 的特殊流程：

1. 确认图片可见，并判断主体的男性或女性呈现。用户明确说明性别时，以用户说明为准；画面呈现不明确时，先询问“使用男性版还是女性版”，不要猜测。
2. 选择对应版本的六组提示词。所有六组都使用同一张上传照片作为身份参考，并保留面部结构、身份辨识度和未要求的个人特征。
3. 每组提示词单独生成一张图片，必须得到六张独立图片；不要把六组提示词合并成一张拼图，也不要只生成其中一张作为预览。
4. 这是用户已经明确授权的整套生成请求，不需要像“自动修图”那样逐项确认；只有在图片缺失、性别呈现无法判断或用户要求存在关键歧义时才暂停询问。
5. 生成完成后按 1–6 编号交付，并标明每张对应的服装、背景或风格。若内置生图工具不可用，则按 1–6 输出六组可复制提示词，并明确说明尚未生成图片。
6. 提示词中的年龄、发色、肤色、种族和模特描述不得覆盖上传者的实际身份；与原图冲突时，以身份保留规则为优先，只采用该组提示词的构图、服装、背景、光线和整体风格。

## 提示词组合规则

- 库内提示词要尽可能原样保留；组合时在外层增加清晰的执行顺序和保留边界。
- “消除背景游客”属于画面清理；“自动调光”属于整体光色；“自动美颜”属于人像局部；“闪光灯氛围感”属于整体风格。
- 默认优先顺序为：画面清理 → 基础光色 → 人像局部 → 风格。若风格提示词与基础调光冲突，风格要求优先，除非用户明确要求同时保留两者。
- 不要把“保持画面完全不变”理解成禁止执行用户已经确认的修改；它表示除该提示词目标外的内容保持不变。
- 组合完成后，检查是否出现互相覆盖的要求，例如同时要求“背景均匀明亮”和“背景欠曝”，发现冲突时先询问或采用用户后说、用户明确指定的要求。

## 生图与交付

1. 生成前检查最终提示词是否包含：输入图作为编辑对象、明确的修改项、保留边界、禁止额外改动。
2. 调用内置生图工具时，把用户上传的图片作为编辑参考，并传入组合后的提示词。
3. 如果工具不可用，不要假装已经生成；直接输出一份可复制的最终提示词，并说明当前只能提供提示词。
4. 生成失败时保留最终提示词，简要说明失败原因，并允许用户重试或改用外部平台。

## 提示词库同步

项目根目录中的 `提示词（未整理）.md` 是当前维护源；Skill 内的 `references/prompt-library.md` 是运行副本。维护源有任何新增、修改、删除或顺序调整，都先修改维护源，再从项目根目录运行：

```bash
python3 ~/.codex/skills/xiutu/scripts/sync_prompt_library.py \
  --source './提示词（未整理）.md'
```

同步后用 `--check` 检查内容和校验信息；不要单独编辑 Skill 副本。当前不对提示词进行分类，直到用户明确要求。

职场证件照提示词使用独立的项目维护源 `职场证件照提示词库.md`。修改后同步到 Skill：

```bash
python3 ~/.codex/skills/xiutu/scripts/sync_prompt_library.py \
  --source './职场证件照提示词库.md' \
  --target './references/workplace-id-photo-prompts.md' \
  --manifest './references/workplace-id-photo-prompts.manifest.json'
```
