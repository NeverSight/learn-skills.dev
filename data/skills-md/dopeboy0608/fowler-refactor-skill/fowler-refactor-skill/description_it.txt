Analizza il codice usando il catalogo di refactoring di Martin Fowler (Extract Function, Decompose Conditional, Replace Conditional with Lookup Table, Split Phase, ecc.) e proponi miglioramenti sicuri e retrocompatibili tramite un’intervista strutturata. Utilizza quando ti viene chiesto di rifattorizzare, migliorare la struttura del codice, rimuovere i code smell, introdurre strati di indirection o quando invochi esplicitamente /fowler-refactor-skill.

Per favore rispondi sempre nella lingua dell'utente.
