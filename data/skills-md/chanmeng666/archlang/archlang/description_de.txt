Verwenden Sie diese Option, wenn der Benutzer einen architektonischen Grundriss / Gebäudelayout als Code erstellen, bearbeiten oder inspizieren möchte — z. B. „eine 2-Zimmer-Wohnung zeichnen“, „diesem Plan ein Badezimmer hinzufügen“, „das Schlafzimmer 1 m breiter machen“, „eine Büroetage anlegen“. ArchLang ist eine winzige Textsprache, die eine .arch-Datei zu einer professionellen Grundrisszeichnung (SVG/PNG/PDF/DXF) kompiliert. Fahren Sie es vollständig durch die "archlang" CLI; Rendern Sie nicht von Hand.
