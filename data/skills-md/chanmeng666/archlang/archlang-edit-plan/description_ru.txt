Использовать, когда пользователь хочет изменить существующий план этажей ArchLang .arch, например «сделать спальню на 1 м шире», «добавить ванную рядом с холлом», «переместить входную дверь на южную стену», «объединить кухню с гостиной». Считывает факты плана через CLI archlang, вносит минимальное редактирование, которое решает задачу, и повторно проверяет. Не предназначено для написания плана по заданию (archlang-brief-to-plan).

Пожалуйста, всегда отвечайте на языке пользователя.
