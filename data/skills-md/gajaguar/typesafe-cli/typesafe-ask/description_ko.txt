`typesafe ask` 및 System One 모델로 텍스트에 대한 명명된 질문 (noul, choice, score) 에 답변합니다. JSON 또는 YAML로 질문 파일을 작성하고, 질문 플래그를 사용하고, 여러 주에서 배치 모드를 실행하고, 요청 옵션을 설정합니다. 사용자가 "다음 질문으로 이 텍스트를 평가", "typeafe로 이 메시지를 분류", "typesafe ask", "score this text", "run typesafe over a file of states" 또는 "questions file" 이라고 말할 때 사용합니다.
