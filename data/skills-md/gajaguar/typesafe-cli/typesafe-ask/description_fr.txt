Répondez à des questions nommées (noul, choix, score) sur un texte avec des modèles `typesafe ask` et System One - écrivez le fichier de questions en JSON ou YAML, utilisez des drapeaux de questions, exécutez le mode batch sur de nombreux états et définissez les options de demande. À utiliser lorsque l'utilisateur dit « évaluer ce texte avec ces questions », « classer ce message avec typesafe », « typesafe ask », « noter ce texte », « exécuter typesafe sur un fichier d'états » ou « fichier de questions ».
