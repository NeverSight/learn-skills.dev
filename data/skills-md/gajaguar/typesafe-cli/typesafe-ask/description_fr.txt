Répondez aux questions nommées (noul, choice, score) sur un texte avec `typesafe ask` et les modèles System One – créez le fichier de questions en JSON ou YAML, utilisez les indicateurs de question, exécutez le mode batch sur de nombreux états et définissez les options de requête. Utilisez ceci lorsque l'utilisateur dit « évaluez ce texte avec ces questions », « classez ce message avec typesafe », « typesafe ask », « notez ce texte », « exécutez typesafe sur un fichier d'états » ou « fichier de questions ».  
Veuillez toujours répondre dans la langue de l'utilisateur.
