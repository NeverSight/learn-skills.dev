`typesafe ask` と System One モデルを使用してテキストに関する名前付き質問（noul、choice、score）に回答します — 質問ファイルは JSON または YAML で作成し、質問フラッグを使用し、複数のステートに対してバッチモードで実行し、リクエストオプションを設定します。  
ユーザーが「このテキストをこれらの質問で評価する」「typesafe でこのメッセージを分類する」「typesafe ask」「このテキストをスコアリングする」「states のファイルに対して typesafe を実行する」または「questions file」と言ったときに使用します。  
常にユーザーの言語で応答してください。
