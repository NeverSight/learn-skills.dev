Auditez un projet Gradle selon les meilleures pratiques officielles de Gradle, signalez les constats et proposez des modifications de code pour mettre le build en conformité. Utilisez cette compétence chaque fois que l'utilisateur veut vérifier, auditer, lint, examiner ou valider un build Gradle — et aussi lorsqu'il souhaite appliquer, adopter, corriger ou imposer les meilleures pratiques. Déclenchez l’action sur des expressions telles que « check my build », « audit gradle », « best practices review », « any issues with my build? », « gradle health check », « lint my build files », « is my gradle setup correct? », « apply gradle best practices », « fix my build to follow best practices », « make my build follow best practices », « modernize my build » ou simplement « check best practices ». Déclenchez également lorsque l'utilisateur pose des questions sur la qualité d’un build Gradle, telles que la gestion des dépendances, les performances du build, la structure du build ou le câblage des tâches.  

Veuillez toujours répondre dans la langue de l'utilisateur.
