Importez ou téléchargez des fichiers HTML ou de projet locaux dans Figma, choisissez des cadres de conception modifiables, des couches de code exécutables ou du code autonome (également appelé Make), et réparez les aperçus importés. N'utilisez cela que lorsque l'utilisateur indique explicitement des couches de conception modifiables, une couche de code exécutable ou un fichier de code/Make autonome, ou fournit une clé/lien de fichier Figma comme destination d'importation. Les demandes de code générique ou de composants de code nécessitent une clarification des réponses avant d'utiliser ce flux de travail. Veuillez toujours répondre dans la langue de l'utilisateur.
