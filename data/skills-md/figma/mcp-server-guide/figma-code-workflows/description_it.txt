Importa o carica file HTML locali o file di progetto in Figma, scegli cornici di Design modificabili, Livelli di Codice eseguibili o Codice autonomo (noto anche come Make) e ripara le anteprime importate. Usa solo quando l'utente indica esplicitamente livelli di Design modificabili, un Livello di Codice eseguibile o un file di Codice/Make autonomo, oppure fornisce una chiave/link a un file Figma come destinazione dell'importazione. Le richieste generiche di codice o di componenti di codice richiedono una chiarificazione dell'output prima di utilizzare questo flusso di lavoro.

Per favore rispondi sempre nella lingua dell'utente.
