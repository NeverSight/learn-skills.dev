Importa o carga archivos HTML o de proyecto locales en Figma, elige marcos de Diseño editables, Capas de Código ejecutables o Código independiente (también conocido como Make), y repara vistas previas importadas. Úsalo solo cuando el usuario indique explícitamente capas de Diseño editables, una Capa de Código ejecutable o un archivo de Código/Make independiente, o proporcione una clave/enlace de archivo de Figma como destino de la importación. Las solicitudes genéricas de código o de componentes de código requieren aclaración de salida antes de usar este flujo de trabajo.

Por favor, responde siempre en el idioma del usuario.
