Fügen Sie 3D-Transformationen hinzu oder bearbeiten Sie sie – Tiefe, Perspektive, Drehung um die Z-Achse, Neigung, isometrische und Parallax-Effekte, die eine flache 2D-Drehung nicht darstellen kann. Verwenden Sie diese Option, wenn eine Anfrage die dritte Dimension betrifft – „Machen Sie es 3D“, „Fügen Sie Tiefe/Perspektive hinzu“, „Kippen/Drehen Sie es nach hinten“, „Z-Ebene“, „Isometrisch“, „Drehen Sie es wie eine Karte“, „Parallaxe“, „Fluchtpunkt“, „In die Ferne zurückweichen“, „Lassen Sie es hervorstechen“.
