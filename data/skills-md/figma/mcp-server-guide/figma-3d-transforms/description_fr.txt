Ajoutez ou modifiez des transformations 3D : profondeur, perspective, rotation sur l'axe Z, inclinaison, isométrie et effets de parallaxe que la rotation 2D plane ne peut pas exprimer. Utilisez-les chaque fois qu'une demande concerne la troisième dimension : « Rendre en 3D », « Ajouter de la profondeur/de la perspective », « Incliner/faire pivoter vers l'arrière », « Plan Z », « Isométrique », « Retourner comme une carte », « Parallaxe », « Point de fuite », « S'éloigner dans le lointain », « Faire ressortir ».
