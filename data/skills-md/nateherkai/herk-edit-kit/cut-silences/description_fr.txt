Agent 1 du pipeline de montage vidéo. Supprime les silences et les temps morts d’un enregistrement de type talking‑head. À utiliser lorsqu’on demande de couper les silences, de réduire les pauses, de supprimer les temps morts / écarts, ou de resserrer le rythme d’une vidéo brute, à partir d’une transcription mot à mot. Produit une liste de montage (EDL), une transcription re‑timée pour les agents en aval, et éventuellement la vidéo découpée via ffmpeg. NE coupe PAS les erreurs, répétitions ou faux départs — c’est l’agent de coupe des erreurs.
