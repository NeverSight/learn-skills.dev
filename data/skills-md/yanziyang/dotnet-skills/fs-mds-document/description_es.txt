Use esta habilidad siempre que el usuario solicite una especificación funcional, FS, especificación de diseño de módulo, MDS, documento de diseño detallado, especificación de software/sistema, documentación de requisitos extraída del código o cualquier entregable de “spec” para un sistema .NET, especialmente cuando mencione Word, docx o diagramas.
