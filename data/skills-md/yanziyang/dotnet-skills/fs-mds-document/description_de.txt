Nutzen Sie diese Fähigkeit immer, wenn der Benutzer nach einer Functional Spec, FS, Module Design Spec, MDS, einem detaillierten Design‑Dokument, einer Software‑/System‑Specification, einer aus Code rückentwickelten Anforderungsdokumentation oder irgendeinem „Spec“‑Liefergegenstand für ein .NET‑System fragt – besonders, wenn Word, docx oder Diagramme genannt werden.

Bitte immer in der Sprache des Benutzers antworten.
