Scansiona un intero repository .NET (.NET 8–10, ASP.NET Core, workers, librerie di classi) e genera un documento di progettazione architetturale professionale in formato Word (.docx), illustrato con diagrammi renderizzati (contesto di sistema, container, componenti, sequenze, modello ER, distribuzione) i cui file sorgente modificabili (Mermaid .mmd e draw.io) vengono esportati in una sottocartella diagrams/. Usa questa competenza ogni volta che l’utente richiede un documento di architettura, un documento di design, documentazione di soluzione/sistema, documentazione tecnica, documentazione di onboarding, “documenta questo codebase/soluzione”, o qualsiasi consegna che descriva come è progettato un sistema .NET — soprattutto quando menzionano Word, docx o diagrammi.

Rispondi sempre nella lingua dell’utente.
