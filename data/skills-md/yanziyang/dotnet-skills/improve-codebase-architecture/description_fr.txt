Analysez une base de code .NET ( .NET 8–10, ASP.NET Core ou bibliothèques de classes ) à la recherche d’opportunités d’approfondissement architectural — couches de passage, interfaces à implémentation unique, dépôts génériques sur EF Core, entités anémiques, cérémonies MediatR, prolifération de projets par couche — et présentez‑les sous forme de rapport HTML visuel avec des diagrammes avant/après. Utilisez cette compétence chaque fois que l’utilisateur demande à examiner ou améliorer l’architecture, à identifier des opportunités de refactorisation ou de simplification, à réduire les couches / interfaces / code boilerplate, à évaluer la dette technique ou le sur‑ingénierie, ou pose la question « comment puis‑je rendre cette base de code meilleure, plus simple, plus testable » — même s’il ne prononce jamais le mot « architecture ».
