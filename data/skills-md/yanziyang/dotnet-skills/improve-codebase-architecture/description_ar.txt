قم بمسح قاعدة أكواد .NET (الإصدار 8–10، ASP.NET Core أو مكتبات الفئات) للبحث عن فرص تعميق العمارة — طبقات تمرير، واجهات ذات تنفيذ واحد، مستودعات عامة فوق EF Core، كيانات ضعيفة، طقوس MediatR، انتشار الطبقة لكل مشروع — وعرضها كتقرير HTML بصري مع مخططات قبل / بعد. استخدم هذه القدرة كلما طلب المستخدم مراجعة أو تحسين العمارة، أو العثور على فرص لإعادة هيكلة أو تبسيط، أو تقليل الطبقات/الواجهات/الكود المتكرر، أو تقييم الدين التقني أو الهندسة الزائدة، أو سأل “كيف يمكنني جعل قاعدة الشيفرة هذه أفضل/أبسط/أكثر قابلية للاختبار” — حتى لو لم يستخدم كلمة “العمارة”. الرجاء دائمًا الرد بلغة المستخدم.
