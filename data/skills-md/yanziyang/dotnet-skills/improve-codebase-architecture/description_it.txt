Scansiona un codebase .NET (.NET 8–10, ASP.NET Core o librerie di classi) alla ricerca di opportunità di approfondimento architettonico — layer di passaggio, interfacce a un'unica implementazione, repository generici su EF Core, entità anemiche, ceremony di MediatR, proliferazione di layer-per-progetto — e presenta i risultati in un report HTML visuale con diagrammi prima/dopo. Usa questa competenza ogni volta che l'utente chiede di revisionare o migliorare l'architettura, trovare opportunità di refactoring o semplificazione, ridurre layer/interfacce/boilerplate, valutare il debito tecnico o l'over‑engineering, o chiede “come posso rendere questo codebase migliore/più semplice/più testabile” — anche se non dice mai la parola “architettura”.  

Per favore rispondi sempre nella lingua dell'utente.
