مراجعة تغييرات كود C#/.NET (الإصدارات .NET 8–10، ASP.NET Core ومكتبات الفئات) للتحقق من الصحة، والبرمجة غير المتزامنة/الخيوط، وEF Core، والأمن، وعمر الموارد، وعيوب عقد API، وتقديم النتائج كتقرير HTML بصري مع شارات الشدة والكود قبل/بعد. استخدم هذه المهارة كلما طلب المستخدم مراجعة الكود، مراجعة فرق/طلب سحب/فرع/التزام، التحقق من التغييرات قبل الالتزام أو الدمج، العثور على أخطاء في التغييرات الأخيرة، أو سأل "هل هذا صحيح / هل هناك شيء خاطئ في هذا" بخصوص كود C# أو .NET — حتى لو لم يذكر كلمات "مراجعة الكود".
