Revisiona le modifiche al codice C#/.NET ( .NET 8–10, ASP.NET Core e librerie di classi) per correttezza, async/threading, EF Core, sicurezza, durata delle risorse e difetti del contratto API, e presenta i risultati in un report HTML visivo con badge di gravità e codice prima/dopo. Usa questa competenza ogni volta che l’utente chiede di revisionare codice, revisionare un diff/PR/branch/commit, controllare le modifiche prima del commit o merge, trovare bug nelle modifiche recenti, o chiede “sembra corretto / c’è qualcosa di sbagliato” su codice C# o .NET — anche se non usa le parole “code review”.

Rispondi sempre nella lingua dell’utente.
