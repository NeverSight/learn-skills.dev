Создайте профессиональный словарь данных в виде документа Word (.docx) из DDL базы данных (скрипты CREATE TABLE, проекты баз данных SQL Server или миграции EF Core), обогащённый сканированием репозитория .NET и документации, чтобы выяснить, что действительно означают каждая таблица и столбец — с диаграммами «Сущность‑Отношение» (разбитыми по модулям при большой схеме), исходные файлы которых (Mermaid .mmd и файлы draw.io) экспортируются в подпапку diagrams/. Используйте этот навык каждый раз, когда пользователь запрашивает словарь данных, документацию по базе данных, документирование схемы, справочник таблиц/столбцов, ERD или диаграмму сущность‑отношение, или хочет «документировать базу данных/таблицы/схему» — особенно когда упоминаются DDL, SQL‑скрипты, Word или docx.
