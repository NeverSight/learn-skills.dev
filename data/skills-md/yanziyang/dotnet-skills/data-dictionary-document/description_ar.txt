إنشاء قاموس بيانات احترافي بصيغة Word (.docx) من DDL لقاعدة البيانات (نصوص CREATE TABLE، مشاريع قاعدة بيانات SQL Server، أو ترحيلات EF Core)، معززًا بفحص مستودع .NET والوثائق لمعرفة ما يعنيه كل جدول وعمود فعليًا — مع مخططات العلاقات الكيانية (مقسمة حسب الوحدة عندما يكون المخطط كبيرًا) التي تُصدر مصادرها القابلة للتحرير (ملفات Mermaid .mmd وملفات draw.io) إلى مجلد فرعي diagrams/. استخدم هذه المهارة كلما طلب المستخدم قاموس بيانات، توثيق قاعدة بيانات، توثيق مخطط، مرجع جدول/عمود، مخطط ERD أو مخطط العلاقات الكيانية، أو أراد "توثيق قاعدة البيانات/الجداول/المخطط" — خصوصًا عندما يذكر DDL، نصوص SQL، Word، أو docx.
