Genera un dizionario dati professionale come documento Word (.docx) a partire dal DDL di un database (script CREATE TABLE, progetti di database SQL Server o migrazioni EF Core), arricchito analizzando il repository .NET e la documentazione per capire il significato reale di ogni tabella e colonna — con diagrammi di relazione tra entità (suddivisi per modulo quando lo schema è grande) i cui sorgenti modificabili (file Mermaid .mmd e draw.io) sono esportati in una sottocartella diagrams/. Usa questa capacità ogni volta che l'utente richiede un dizionario dati, documentazione del database, documentazione dello schema, riferimento a tabelle/colonne, ERD o diagramma di relazione tra entità, o vuole “documentare il database/tabelle/schema” — soprattutto quando menzionano DDL, script SQL, Word o docx. Rispondi sempre nella lingua dell'utente.
