データベースのDDL（CREATE TABLE スクリプト、SQL Server データベース プロジェクト、または EF Core マイグレーション）から、.NET リポジトリとドキュメントをスキャンして各テーブルやカラムの意味を補足した、プロフェッショナルなデータ辞書を Word（.docx）ドキュメントとして生成します — スキーマが大規模な場合はモジュールごとに分割したエンティティ リレーションシップ ダイアグラムを添付し、編集可能なソース（Mermaid の .mmd ファイルや draw.io ファイル）は diagrams/ サブフォルダにエクスポートします。このスキルは、ユーザーがデータ辞書、データベース文書、スキーマ文書、テーブル/カラム リファレンス、ERD またはエンティティ リレーションシップ ダイアグラム、あるいは「データベース/テーブル/スキーマを文書化したい」と求めたときに常に使用してください — 特に DDL、SQL スクリプト、Word、または docx が言及された場合に適用します。
