Générez un dictionnaire de données professionnel sous forme de document Word (.docx) à partir du DDL d’une base de données (scripts CREATE TABLE, projets de base de données SQL Server ou migrations EF Core), enrichi en analysant le référentiel .NET et la documentation pour déterminer la signification réelle de chaque table et colonne — avec des diagrammes de relation d’entités (décomposés par module lorsque le schéma est volumineux) dont les sources éditables (fichiers Mermaid .mmd et draw.io) sont exportées dans un sous‑dossier diagrams/. Utilisez cette compétence chaque fois que l’utilisateur demande un dictionnaire de données, une documentation de base de données, une documentation de schéma, une référence table/colonne, un ERD ou un diagramme de relation d’entités, ou souhaite « documenter la base de données/les tables/le schéma » — en particulier lorsqu’il mentionne le DDL, des scripts SQL, Word ou docx.

Veuillez toujours répondre dans la langue de l’utilisateur.
