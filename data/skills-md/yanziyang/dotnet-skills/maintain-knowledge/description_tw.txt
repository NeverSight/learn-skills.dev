在 Documentation/ 目錄下為 .NET 解決方案（.NET 8–10）建立並維護一個即時更新的 Markdown 知識庫——包括專案結構、使用 Mermaid 圖表的架構、功能清單、資料模型、開發指南、技術債務、改進待辦清單、可重用元件，以及針對代理優化的 KnowledgeBase.md 和機器可讀的 PROJECT_KNOWLEDGE.json。於以下情況使用：更新文件、以 Markdown 記錄程式碼基礎、建立或刷新知識庫、產生新人上線或代理上下文文件、分析程式碼基礎、發掘功能、追蹤技術債務，或讓 Documentation/ 與程式碼保持同步。一次性的 Word（.docx）交付請使用 architecture-design-document 或 fs-mds-document 取代。
