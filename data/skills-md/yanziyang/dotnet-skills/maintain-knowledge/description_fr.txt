Créer et maintenir une base de connaissances markdown vivante dans Documentation/ pour une solution .NET (.NET 8–10) — structure du projet, architecture avec diagrammes Mermaid, inventaire des fonctionnalités, modèle de données, guide de développement, dette technique, backlog d’améliorations, composants réutilisables, ainsi qu’un KnowledgeBase.md optimisé pour les agents et un PROJECT_KNOWLEDGE.json lisible par machine. Utilisez‑le lorsqu’on vous demande de mettre à jour la documentation, de documenter le code en markdown, de créer ou rafraîchir une base de connaissances, de générer des documents d’onboarding ou de contexte agent, d’analyser le code, de découvrir les fonctionnalités, de suivre la dette technique, ou de garder Documentation/ synchronisé avec le code. Pour les livrables ponctuels Word (.docx), utilisez architecture-design-document ou fs-mds-document à la place.

Veuillez toujours répondre dans la langue de l’utilisateur.
