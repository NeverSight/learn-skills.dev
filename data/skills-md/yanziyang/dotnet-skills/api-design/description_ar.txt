أنماط تصميم واجهات برمجة التطبيقات REST لـ .NET / ASP.NET Core (net8.0–net10.0) تشمل تسمية الموارد، رموز الحالة، استجابات الأخطاء ProblemDetails، الترميز الصفحات، الفلترة، النسخ، وتحديد معدل الاستخدام لواجهات برمجة التطبيقات في بيئة الإنتاج. استخدم هذه المهارة عند تصميم أو مراجعة نقاط النهاية في ASP.NET Core (واجهات برمجة التطبيقات البسيطة أو المتحكمات)، إضافة نقاط نهاية للقوائم، إرجاع الأخطاء من واجهة برمجة التطبيقات، اختيار رموز الحالة، أو عندما يذكر المستخدم REST أو نقاط النهاية أو Web API أو الترميز الصفحات أو إصدار API أو حدود المعدل — حتى لو لم يذكر "تصميم API" صراحةً. يرجى الرد دائمًا بلغة المستخدم.
