Modèles de conception d'API REST pour .NET / ASP.NET Core (net8.0–net10.0) incluant la nomination des ressources, les codes d'état, les réponses d'erreur ProblemDetails, la pagination, le filtrage, le versionnage et la limitation de débit pour les API de production. Utilisez cette compétence chaque fois que vous concevez ou examinez des points de terminaison ASP.NET Core (Minimal APIs ou contrôleurs), ajoutez des points de terminaison de liste, renvoyez des erreurs depuis une API, choisissez des codes d'état, ou lorsque l'utilisateur mentionne REST, points de terminaison, Web API, pagination, versionnage d'API ou limites de débit — même s'il ne dit pas explicitement « conception d'API ».

Veuillez toujours répondre dans la langue de l'utilisateur.
