Page Object Model を使用した、ハードウェイトゼロで完全なドキュメント付きの A+ レベルの本番向き Playwright E2E テストを生成します。**このスキルは、ユーザーが次の語句に言及したときに使用してください**：'test'、'e2e'、'end-to-end'、'playwright'、'accessibility'、'a11y'、'smoke test'、'API test'、'test automation'、'test suite'、'create tests'、'add tests'、'test this'、'test the'、'write tests'、またはウェブアプリケーションの機能、ページ、コンポーネント、API エンドポイントのテストを希望する場合。キャンバステストや複雑な UI 操作（ドラッグ＆ドロップ、描画、アニメーション）にも、適切な Page Object Model アーキテクチャでのテストが必要なときに使用してください。
