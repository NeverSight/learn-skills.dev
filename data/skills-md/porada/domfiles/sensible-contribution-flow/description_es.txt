Evalúe, prepare y revise contribuciones a repositorios de GitHub que el usuario no posee, incluidas discusiones, incidencias, informes de vulnerabilidades privados y pull requests.

Úselo al incorporar comentarios o hallazgos en una contribución, al preparar el próximo pull request en una serie de contribuciones o al realizar revisiones solicitadas por el usuario a un pull request existente, incluido el feedback del mantenedor después de la presentación.

No lo utilice para trabajo rutinario en los repositorios propios del usuario ni para el monitoreo continuo después de la presentación.
