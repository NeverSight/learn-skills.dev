Valuta, prepara e revisiona i contributi a repository GitHub che l'utente non possiede, includendo discussioni, issue, segnalazioni private di vulnerabilità e pull request.

Usalo quando incorpori feedback o risultati in un contributo, preparando la prossima pull request in una serie di contributi, o effettuando revisioni richieste dall'utente a una pull request esistente, includendo il feedback del manutentore dopo la sottomissione.

Non usarlo per lavoro di routine nei repository propri dell'utente o per il monitoraggio continuo dopo la sottomissione.

Si prega di rispondere sempre nella lingua dell'utente.
