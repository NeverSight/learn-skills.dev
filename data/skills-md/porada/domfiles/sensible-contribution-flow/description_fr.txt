Évaluer, préparer et examiner les contributions aux dépôts GitHub que l'utilisateur ne possède pas, y compris les discussions, les tickets, les rapports de vulnérabilité privés et les pull requests.

Utilisez-le lors de l'intégration de commentaires ou de découvertes dans une contribution, de la préparation de la prochaine pull request d’une série de contributions, ou pour effectuer des révisions demandées par l'utilisateur à une pull request existante, y compris les retours du mainteneur après la soumission.

Ne l'utilisez pas pour les tâches routinières dans les dépôts propres de l'utilisateur ou pour la surveillance continue après la soumission.
