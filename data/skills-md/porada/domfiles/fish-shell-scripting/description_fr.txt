Écrivez, examinez, auditez, refactorisez et diagnostiquez le code et la configuration Fish. Utilisez‑le chaque fois que le code est destiné à s’exécuter dans Fish ou qu’une migration cible Fish.

Utilisez‑le dans les fichiers `.fish`, les shebang Fish, `config.fish`, les fonctions auto‑chargées, les invites et les complétions.

Ne l’utilisez pas lorsque la sortie demandée n’est que du code pour un autre shell.

Veuillez toujours répondre dans la langue de l’utilisateur.
