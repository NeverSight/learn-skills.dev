Schreibe, überprüfe, prüfe, refaktoriere und diagnostiziere Fish-Code und -Konfiguration. Verwende es, wann immer Code für die Ausführung in Fish vorgesehen ist oder eine Migration Fish zum Ziel hat.

Verwende es in `.fish`‑Dateien, Fish‑Hashbangs, `config.fish`, automatisch geladenen Funktionen, Eingabeaufforderungen und Vervollständigungen.

Verwende es nicht, wenn die angeforderte Ausgabe ausschließlich Code für eine andere Shell ist.

Bitte antworte immer in der Sprache des Benutzers.
