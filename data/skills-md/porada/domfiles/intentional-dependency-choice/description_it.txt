Usa quando scegli, proponi, rivedi o dichiari una nuova dipendenza o uno strumento di sviluppo, incluse le acquisizioni temporanee di runner di pacchetti. Usalo anche quando dichiari una dipendenza esistente per un ulteriore consumatore di workspace o quando modifichi le funzionalità, la sorgente o la versione prescritta di una dipendenza o di uno strumento.

Non usarlo semplicemente per riutilizzare una dipendenza di progetto esistente senza aggiungere o modificare una dichiarazione, installare o ripristinare dipendenze già prescritte, incorporare dichiarazioni di dipendenze esistenti tramite integrazione autorizzata della cronologia, o condurre un inventario generale delle dipendenze o un audit di sicurezza senza una decisione di selezione.
