Verwenden Sie es für direkte Arbeiten mit GitHub: Inspektion von Remote‑Quellcode oder Repository‑Zustand, Durchsuchen von gehostetem Code, Aufrufen von GitHub‑CLI (`gh`)‑Befehlen wie `gh search` und `gh api` oder Ausführen einer anderen Operation gegen GitHub.  

Verwenden Sie es nicht für gewöhnliche lokale Git‑Arbeiten, es sei denn, der Benutzer fordert `gh` ausdrücklich an. Verwenden Sie es nicht für Aufgaben, die auf das Anzeigen oder Interagieren mit GitHub in einem Browser beschränkt sind.
