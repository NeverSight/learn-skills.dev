Úsalo para trabajo directo con GitHub: inspeccionar el código remoto o el estado del repositorio, buscar código alojado, invocar comandos de la CLI de GitHub (`gh`) como `gh search` y `gh api`, o realizar otra operación contra GitHub.

No lo uses para trabajo local ordinario de Git a menos que el usuario solicite explícitamente `gh`. No lo uses para tareas limitadas a ver o interactuar con GitHub en un navegador.

Por favor, responde siempre en el idioma del usuario.
