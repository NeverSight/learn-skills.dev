Используйте для прямой работы с GitHub: проверки удалённого исходного кода или состояния репозитория, поиска размещённого кода, вызова команд GitHub CLI (`gh`), таких как `gh search` и `gh api`, либо выполнения другой операции над GitHub.

Не используйте его для обычной локальной работы с Git, если пользователь явно не запросит `gh`. Не используйте его для задач, ограниченных просмотром или взаимодействием с GitHub в браузере.
