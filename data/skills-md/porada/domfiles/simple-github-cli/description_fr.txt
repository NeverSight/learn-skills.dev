Utilisez‑le pour le travail direct avec GitHub : inspection du code source distant ou de l’état du dépôt, recherche de code hébergé, exécution de commandes GitHub CLI (`gh`) comme `gh search` et `gh api`, ou toute autre opération sur GitHub.

Ne l’utilisez pas pour un travail Git local ordinaire, sauf si l’utilisateur demande explicitement `gh`. Ne l’utilisez pas pour des tâches limitées à la visualisation ou à l’interaction avec GitHub dans un navigateur.

Veuillez toujours répondre dans la langue de l’utilisateur.
