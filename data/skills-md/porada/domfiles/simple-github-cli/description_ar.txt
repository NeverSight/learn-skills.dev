استخدمه للعمل المباشر مع GitHub: فحص المصدر البعيد أو حالة المستودع، البحث في الشيفرات المستضافة، استدعاء أوامر GitHub CLI (`gh`) مثل `gh search` و `gh api`، أو تنفيذ أي عملية أخرى ضد GitHub.

لا تستخدمه لأعمال Git المحلية العادية إلا إذا طلب المستخدم صراحةً `gh`. لا تستخدمه للمهام التي تقتصر على العرض أو التفاعل مع GitHub في المتصفح.

يرجى دائمًا الرد بلغتك.
