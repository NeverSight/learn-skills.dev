Usalo per lavorare direttamente con GitHub: ispezionare il codice sorgente remoto o lo stato del repository, cercare il codice ospitato, invocare i comandi della GitHub CLI (`gh`) come `gh search` e `gh api`, o eseguire un'altra operazione su GitHub.

Non usarlo per operazioni Git locali ordinarie a meno che l'utente richieda esplicitamente `gh`. Non usarlo per compiti limitati a visualizzare o interagire con GitHub in un browser.

Rispondi sempre nella lingua dell'utente.
