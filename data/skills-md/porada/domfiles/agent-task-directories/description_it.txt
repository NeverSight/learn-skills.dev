Usa per attività che richiedono file temporanei, anche durante un altro workflow. Usalo anche prima di creare, ispezionare, spostare, rimuovere o riutilizzare directory delle attività dell'agente come `.agent-*`, e quando compaiono durante la scoperta o la validazione del repository.

Non usarlo per attività limitate a output durevoli del progetto, risorse temporanee interne dei programmi o cache gestite dallo strumento.
