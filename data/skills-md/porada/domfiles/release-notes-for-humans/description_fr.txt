Utilisez cette compétence pour rédiger les notes de version du package, les entrées du journal des modifications et les descriptions de version hébergées à partir de brouillons fournis ou de changements vérifiés, ou pour réviser le texte de la version afin d’en vérifier l’exhaustivité, la cohérence et la formulation.

Le travail peut porter sur un commit, une plage de commits, une pull request, une branche, un tag, un diff, ou sur chaque changement depuis la dernière version.

Ne l’utilisez pas pour des résumés de commits ordinaires, sauf s’ils sont destinés à être utilisés dans les notes de version ou le journal des modifications.

Veuillez toujours répondre dans la langue de l’utilisateur.
