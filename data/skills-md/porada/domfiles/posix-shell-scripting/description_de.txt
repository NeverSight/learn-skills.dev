Schreibe, überprüfe, prüfe, refaktorisiere und diagnostiziere POSIX‑`sh`‑Code und -Konfiguration. Verwende es immer dann, wenn Code unter einer POSIX‑Shell ausgeführt werden soll oder eine Migration POSIX `sh` zum Ziel hat.

Verwende es in `.sh`‑Dateien, `#!/bin/sh`‑Einstiegspunkten, Befehlen ohne Dateiendung, geladenen Bibliotheken, Hooks, Start‑Fragmenten, generierten Shell‑Fragmenten und anderem Shell‑Code ohne erkennbaren Shell‑Dialekt.

Verwende es nicht, wenn die angeforderte Ausgabe ausschließlich Code für eine nicht‑POSIX‑Shell ist.

Bitte antworte immer in der Sprache des Benutzers.
