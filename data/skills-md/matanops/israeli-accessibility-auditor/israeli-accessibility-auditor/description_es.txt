Auditar un sitio web público (predeterminado, rastreo completo del sitio con --site), una página renderizada (--url) o el código fuente del frontend (--path) para accesibilidad, con informes en hebreo RTL, tipos de problemas priorizados y entrega de reparación. Utilizar cuando un usuario solicite comprobar o auditar la URL de un sitio o la carpeta de código para accesibilidad (נגישות, בדיקת נגישות, ת"י 5568, WCAG, "בדוק את ... עם israeli-accessibility-auditor"). Solo auditoría a menos que se solicite explícitamente una corrección. Siempre responda en el idioma del usuario.
