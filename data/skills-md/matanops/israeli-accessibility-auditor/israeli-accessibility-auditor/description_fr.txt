Auditez un site web public (par défaut, exploration complète du site avec --site), une page rendue (--url) ou le code source du frontend (--path) pour l’accessibilité, avec des rapports RTL en hébreu, des types de problèmes priorisés et un transfert de réparation. Utilisez-le lorsqu’un utilisateur demande de vérifier ou d’auditer l’URL d’un site ou le dossier de code pour l’accessibilité (נגישות, בדיקת נגישות, ת"י 5568, WCAG, «בדוק את ... עם israeli-accessibility-auditor»). Audit uniquement sauf si une correction est explicitement demandée.

Veuillez toujours répondre dans la langue de l’utilisateur.
