Esta habilidad debe usarse para crear aplicaciones de escritorio nativas de Apple macOS (Mac) en Swift con SwiftUI, SwiftData y la pila macOS 26 “Tahoe”, siempre que el usuario quiera crear, estructurar, diseñar, depurar o ampliar una aplicación para Mac: ventanas y escenas (WindowGroup/Window/Settings/MenuBarExtra), la barra de menús global y los comandos con atajos de teclado, NavigationSplitView/Table/inspectores, Liquid Glass, estado @Observable y el sistema de foco de Mac, persistencia con SwiftData/CloudKit, concurrencia de Swift 6, interoperabilidad con AppKit, aplicaciones basadas en documentos, procesos de barra de menús/fondo/elementos de inicio de sesión, Apple Intelligence en el dispositivo (Modelos Fundamentales), StoreKit 2, accesibilidad, pruebas y el gauntlet de publicación para Mac (App Sandbox, Hardened Runtime, firma Developer ID + notarización, o Mac App Store), incluso cuando la solicitud nunca mencione “macOS” o “SwiftUI” (por ejemplo, “hazme una app para Mac”, “una app de barra de menús”, “una pequeña utilidad para mi Mac”). No es para apps de iPhone/iPad (use ios‑dev), visionOS (use visionos‑dev), Mac Catalyst o contenedores web como Electron/Tauri.
