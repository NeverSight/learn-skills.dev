يجب استخدام هذه المهارة لبناء تطبيقات سطح مكتب Apple macOS (Mac) أصلية بلغة Swift باستخدام SwiftUI وSwiftData، ومجموعة macOS 26 "Tahoe" — كلما أراد المستخدم إنشاء، أو تمهيد، أو تصميم، أو تصحيح، أو توسيع تطبيق Mac: النوافذ والمشاهد (WindowGroup/Window/Settings/MenuBarExtra)، شريط القوائم العالمي وأوامر اختصارات لوحة المفاتيح، NavigationSplitView/Table/inspectors، Liquid Glass، حالة @Observable ونظام التركيز في Mac، تخزين SwiftData/CloudKit، التزامن في Swift 6، التفاعل مع AppKit، التطبيقات المعتمدة على المستندات، عمليات شريط القوائم/الخلفية/عنصر تسجيل الدخول، الذكاء الاصطناعي داخل الجهاز من Apple (نماذج الأساس)، StoreKit 2، إمكانية الوصول، الاختبار، وعقبة إصدار Mac (App Sandbox، Hardened Runtime، توقيع Developer ID + التصديق، أو متجر تطبيقات Mac) — حتى عندما لا يذكر الطلب كلمة "macOS" أو "SwiftUI" (مثلًا "اصنع لي تطبيق Mac"، "تطبيق شريط قوائم"، "أداة صغيرة لجهازي Mac"). لا تُستخدم لتطبيقات iPhone/iPad (استخدم ios‑dev)، visionOS (استخدم visionos‑dev)، Mac Catalyst، أو أطر الويب Electron/Tauri.
