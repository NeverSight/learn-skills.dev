Эту функцию следует использовать для создания нативных настольных приложений Apple macOS (Mac) на Swift с SwiftUI, SwiftData и стеком macOS 26 «Tahoe» — каждый раз, когда пользователь хочет создать, сгенерировать каркас, спроектировать, отладить или расширить Mac‑приложение: окна и сцены (WindowGroup/Window/Settings/MenuBarExtra), глобальная строка меню и команды с клавиатурными сочетаниями, NavigationSplitView/Table/inspectors, Liquid Glass, состояние @Observable и система фокуса Mac, хранение данных SwiftData/CloudKit, конкурентность Swift 6, взаимодействие с AppKit, приложения на основе документов, процессы меню‑бара/фон/элементы входа в систему, локальный Apple Intelligence (Foundation Models), StoreKit 2, доступность, тестирование и проверка готовности Mac к выпуску (App Sandbox, Hardened Runtime, подпись Developer ID + нотаризация или Mac App Store) — даже если запрос никогда не упоминает «macOS» или «SwiftUI» (например, «сделай мне приложение для Mac», «приложение‑меню‑бар», «небольшая утилита для моего Mac»). НЕ предназначено для приложений iPhone/iPad (используйте ios‑dev), visionOS (используйте visionos‑dev), Mac Catalyst или веб‑обёрток Electron/Tauri.

Пожалуйста, отвечайте всегда на языке пользователя.
