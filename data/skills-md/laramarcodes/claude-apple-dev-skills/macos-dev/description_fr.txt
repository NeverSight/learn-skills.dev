Cette compétence doit être utilisée pour créer des applications natives Apple macOS (Mac) de bureau en Swift avec SwiftUI, SwiftData et la pile macOS 26 « Tahoe » — chaque fois que l'utilisateur veut créer, structurer, concevoir, déboguer ou étendre une application Mac : fenêtres et scènes (WindowGroup/Window/Settings/MenuBarExtra), la barre de menus globale et les commandes de raccourcis clavier, NavigationSplitView/Table/inspecteurs, Liquid Glass, l’état @Observable et le système de focus Mac, la persistance SwiftData/CloudKit, la concurrence Swift 6, l’interop AppKit, les applications basées sur des documents, les processus de barre de menus/arrière‑plan/éléments de connexion, l’Intelligence Apple sur l’appareil (modèles fondamentaux), StoreKit 2, l’accessibilité, les tests et le parcours de validation Mac (App Sandbox, Hardened Runtime, signature Developer ID + notarisation, ou Mac App Store) — même lorsque la demande ne cite jamais « macOS » ou « SwiftUI » (par ex. « faites‑moi une application Mac », « une application de barre de menus », « une petite utilité pour mon Mac »). NE PAS l’utiliser pour les applications iPhone/iPad (utilisez ios‑dev), visionOS (utilisez visionos‑dev), Mac Catalyst ou les conteneurs web Electron/Tauri.  

Veuillez toujours répondre dans la langue de l'utilisateur.
