Alibaba Cloud Bailei Sandbox instance and template lifecycle management entry point: when users need to create, query, connect, pause, resume, or release a Bailei sandbox, or view built-in base images, upload template mount files, create, update, query, delete sandbox templates, and check template build status, they use `bl sandbox`. When users want to access a created instance, open WebShell, connect to browser-use browser automation, or view a VNC live screen, they first obtain connection information and then connect to the data plane. This does not apply to host-executed sandbox settings, E2B official cloud resources, or generic file transfers. The `agents.yaml` hosts Agent / Session / Environment management handed over to bailian-managed-agent. Official installation: `bl skill init` (installed together with the shared protocol bailian-protocol).
