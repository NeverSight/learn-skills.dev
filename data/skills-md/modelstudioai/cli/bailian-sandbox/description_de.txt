Einstiegspunkt für das Alibaba Cloud Bailei Sandbox-Instanz- und Vorlagenlebenszyklusmanagement: Wenn Benutzer eine Bailei-Sandbox erstellen, abfragen, verbinden, anhalten, fortsetzen oder freigeben oder integrierte Basisbilder anzeigen, Vorlagen-Mount-Dateien hochladen, Sandbox-Vorlagen erstellen, aktualisieren, abfragen, löschen und den Status der Vorlagenerstellung überprüfen müssen, verwenden sie „bl Sandbox“. Wenn Benutzer auf eine erstellte Instanz zugreifen, WebShell öffnen, eine Verbindung zur browserbasierten Browserautomatisierung herstellen oder einen VNC-Live-Bildschirm anzeigen möchten, erhalten sie zunächst Verbindungsinformationen und stellen dann eine Verbindung zur Datenebene her. Dies gilt nicht für vom Host ausgeführte Sandbox-Einstellungen, offizielle E2B-Cloud-Ressourcen oder generische Dateiübertragungen. Die „agents.yaml“ hostet die Agenten-/Sitzungs-/Umgebungsverwaltung, die an bailian-managed-agent übergeben wird. Offizielle Installation: „bl skills init“ (wird zusammen mit dem gemeinsamen Protokoll bailian-protocol installiert).
