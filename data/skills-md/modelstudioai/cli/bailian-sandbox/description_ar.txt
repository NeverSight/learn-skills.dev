مثيل Alibaba Cloud Bailei Sandbox ونقطة إدخال إدارة دورة حياة القالب: عندما يحتاج المستخدمون إلى إنشاء صندوق حماية Bailey أو الاستعلام عنه أو الاتصال به أو إيقافه مؤقتًا أو استئنافه أو تحريره، أو عرض الصور الأساسية المضمنة، وتحميل ملفات تثبيت القالب، وإنشاء، وتحديث، والاستعلام، وحذف قوالب وضع الحماية، والتحقق من حالة بناء القالب، فإنهم يستخدمون "bl sandbox". عندما يرغب المستخدمون في الوصول إلى مثيل تم إنشاؤه، أو فتح WebShell، أو الاتصال بأتمتة المتصفح الذي يستخدم المستعرض، أو عرض شاشة VNC المباشرة، فإنهم يحصلون أولاً على معلومات الاتصال ثم يتصلون بمستوى البيانات. لا ينطبق هذا على إعدادات وضع الحماية التي ينفذها المضيف، أو موارد السحابة الرسمية لـ E2B، أو عمليات نقل الملفات العامة. تم تسليم إدارة "agents.yaml" المضيفة / الجلسة / البيئة إلى الوكيل المُدار بواسطة Bailian. التثبيت الرسمي: `bl Skill init` (مثبت مع البروتوكول المشترك Bailian-Protocol).
