Entrée de gestion du cycle de vie des instances et des modèles Bailei Sandbox d'Alibaba Cloud : les utilisateurs utilisent `bl sandbox` pour créer, interroger, se connecter, mettre en pause, reprendre ou libérer un sandbox Bailei, ou pour visualiser les images de base intégrées, télécharger des fichiers de montage de modèle, créer, mettre à jour, interroger, supprimer des modèles de sandbox et consulter l’état de construction du modèle. Lorsque les utilisateurs veulent accéder à une instance créée, ouvrir WebShell, se connecter via l’automatisation du navigateur ou l’écran en temps réel VNC, ils obtiennent d’abord les informations de connexion, puis se connectent au plan de données. Ce n’est pas destiné aux paramètres d’exécution d’hôte du sandbox, aux ressources cloud officielles E2B ou aux transferts de fichiers généraux. La gestion du fichier hébergé agents.yaml (Agent / Session / Environnement) est déléguée à bailian‑managed‑agent. Installation officielle : `bl skill init` (installé avec le protocole partagé bailian‑protocol).
