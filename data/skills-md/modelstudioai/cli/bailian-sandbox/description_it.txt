Alibaba Cloud Bailei Sandbox instance and template lifecycle management entry point: when users need to create, query, connect, pause, resume, or release a Bailei sandbox, or view built-in base images, upload template mount files, create, update, query, delete sandbox templates, and check template build status, they use `bl sandbox`. When users want to access a created instance, open WebShell, connect to browser-use browser automation, or view a VNC live screen, they first obtain connection information and then connect to the data plane. Ciò non si applica alle impostazioni sandbox eseguite dall'host, alle risorse cloud ufficiali E2B o ai trasferimenti di file generici. Il file `agents.yaml` ospita la gestione dell'agente/sessione/ambiente affidata a bailian-owned-agent. Installazione ufficiale: `bl skill init` (installato insieme al protocollo condiviso bailian-protocol).
