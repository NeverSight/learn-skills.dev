Alibaba Cloud Bailei Sandbox 인스턴스 및 템플릿 라이프사이클 관리 진입점: 사용자가 Bailei 샌드박스를 생성, 조회, 연결, 일시 중지, 재개 또는 해제하거나 내장 베이스 이미지를 확인하고, 템플릿 마운트 파일을 업로드하며, 샌드박스 템플릿을 생성, 업데이트, 조회, 삭제하고 템플릿 빌드 상태를 확인해야 할 때는 `bl sandbox`를 사용합니다. 사용자가 생성된 인스턴스에 접근하고 WebShell을 열거나 브라우저 자동화를 사용해 브라우저에 연결하거나 VNC 실시간 화면을 보려면 먼저 연결 정보를 얻은 뒤 데이터 플레인에 연결합니다. 이는 호스트 측 샌드박스 설정, E2B 공식 클라우드 리소스, 일반 파일 전송에 사용되지 않습니다. agents.yaml에 호스팅된 Agent/Session/Environment 관리는 bailian‑managed‑agent에 위임됩니다. 공식 설치: `bl skill init` (공유 bailian‑protocol과 함께 설치됩니다).
