Alibaba Cloud Bailei Sandbox 인스턴스 및 템플릿 수명주기 관리 진입점: 사용자가 Bailei 샌드박스를 생성, 쿼리, 연결, 일시 중지, 재개 또는 릴리스하거나 내장된 기본 이미지를 보고, 템플릿 마운트 파일을 업로드하고, 샌드박스 템플릿을 생성, 업데이트, 쿼리, 삭제하고, 템플릿 빌드 상태를 확인해야 하는 경우 'bl sandbox'를 사용합니다. 사용자가 생성된 인스턴스에 액세스하거나, WebShell을 열거나, 브라우저 사용 브라우저 자동화에 연결하거나, VNC 라이브 화면을 보려는 경우 먼저 연결 정보를 얻은 다음 데이터 플레인에 연결합니다. 이는 호스트 실행 샌드박스 설정, E2B 공식 클라우드 리소스 또는 일반 파일 전송에는 적용되지 않습니다. `agents.yaml`은 bailian-managed-agent에 넘겨진 에이전트/세션/환경 관리를 호스팅합니다. 공식 설치: `bl Skill init`(공유 프로토콜 bailian-protocol과 함께 설치됨)
