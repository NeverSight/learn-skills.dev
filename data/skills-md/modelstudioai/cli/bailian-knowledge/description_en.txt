Personal data integration and knowledge‑base usage. It is employed when a task needs to refer to the user’s own historical documents, client information, old proposals, meeting records, or study materials, such as “refer to previous materials to prepare a meeting,” “write a version based on the old plan,” “why was this decided before.” The user is not required to say “knowledge base” or name Bailian. It is also used when the user wants to reuse a batch of materials repeatedly later, or requests to integrate, update, view, pause, resume, or clean the knowledge base. It also handles explicit bl knowledge / kscli resource operations. Purely generic Q&A, summarizing only the current attachment, or writing that does not need historical data does not trigger it; personal preferences and chat memory belong to bailian‑memory, while DingTalk document management, model selection, and fine‑tuning are not part of this skill.
