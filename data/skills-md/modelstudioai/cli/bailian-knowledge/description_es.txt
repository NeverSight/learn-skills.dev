Integración del perfil personal y uso de la base de conocimientos. Se utiliza cuando una tarea requiere referenciar los documentos históricos del usuario, información del cliente, propuestas antiguas, actas de reuniones o materiales de estudio, como “referirse a materiales previos para preparar una reunión”, “escribir una versión basada en la propuesta anterior”, “por qué se tomó esta decisión antes”. No se le exige al usuario decir “base de conocimientos” ni mencionar a Bailei. También se usa cuando el usuario desea un lote de materiales para reutilizarlo repetidamente en el futuro, o solicita importar, actualizar, visualizar, pausar, reanudar o limpiar la base de conocimientos. También gestiona operaciones explícitas de recursos bl knowledge / kscli. Preguntas y respuestas puramente genéricas, resumir solo el archivo adjunto actual o redactar contenido que no requiera datos históricos no lo activan; las preferencias personales y la memoria de chat pertenecen a bailian‑memory, la gestión de documentos de DingTalk, la selección de modelo y el ajuste fino no forman parte de esta habilidad. Por favor, responda siempre en el idioma del usuario.
