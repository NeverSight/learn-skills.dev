Nettoyez et simplifiez le code récemment modifié pour plus de qualité – et non pour la recherche de bogues. À utiliser chaque fois que l'utilisateur demande de « simplifier », « nettoyer ce code », « ranger mes modifications », « refactoriser pour plus de clarté », « peaufiner ma différence », « rendre cela plus propre » ou souhaite que ses modifications récentes soient examinées pour des problèmes de réutilisation, de simplification, d'efficacité et d'altitude (profondeur droite) avant de valider ou d'ouvrir un PR. Examine le git diff à travers quatre objectifs de nettoyage – Réutilisation, Simplification, Efficacité, Altitude – présente les résultats et applique les correctifs après approbation. Ne recherche PAS les bogues d'exactitude ; il s’agit d’une tâche distincte de révision de code. Déclenchez même si l'utilisateur dit seulement "pouvez-vous simplifier ce que je viens d'écrire".
