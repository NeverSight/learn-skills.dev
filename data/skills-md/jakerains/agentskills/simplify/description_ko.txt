버그 사냥이 아닌 품질을 위해 최근 변경된 코드를 정리하고 단순화합니다. 사용자가 PR을 커밋하거나 열기 전에 "단순화", "이 코드 정리", "변경 사항 정리", "명확성을 위해 리팩터링", "차이점 개선", "이것을 더 깔끔하게 만들기"를 요청하거나 최근 편집 내용을 재사용, 단순화, 효율성 및 고도(적절한 깊이) 문제에 대해 검토하기를 원할 때마다 사용합니다. 재사용, 단순화, 효율성, 고도 등 4가지 정리 렌즈를 통해 git diff를 검토하여 결과를 제시하고 승인 시 수정 사항을 적용합니다. 정확성 버그를 찾지 않습니다. 이는 별도의 코드 검토 작업입니다. 사용자가 "방금 작성한 내용을 단순화할 수 있습니까?"라고만 말하는 경우에도 트리거됩니다.
