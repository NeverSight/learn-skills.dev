Bereinigen und vereinfachen Sie kürzlich geänderten Code für mehr Qualität – nicht für die Suche nach Fehlern. Verwenden Sie diese Option immer dann, wenn der Benutzer „vereinfachen“, „diesen Code bereinigen“, „meine Änderungen aufräumen“, „zur Verdeutlichung umgestalten“, „mein Diff aufpolieren“, „dies sauberer machen“ möchte oder möchte, dass seine letzten Änderungen auf Wiederverwendungs-, Vereinfachungs-, Effizienz- und Höhenprobleme (rechte Tiefe) überprüft werden, bevor er eine PR festschreibt oder öffnet. Überprüft den Git-Diff durch vier Bereinigungslinsen – Wiederverwendung, Vereinfachung, Effizienz, Höhe – präsentiert die Ergebnisse und wendet die Korrekturen bei der Genehmigung an. Sucht NICHT nach Korrektheitsfehlern; Das ist eine separate Codeüberprüfungsaufgabe. Wird auch dann ausgelöst, wenn der Benutzer nur sagt: „Können Sie das, was ich gerade geschrieben habe, vereinfachen?“
