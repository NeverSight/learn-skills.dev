Delega lavori pesanti di contesto o indipendentemente preziosi tramite pacchetti di contesto compatti, lavoratori riutilizzabili e un registro di validazione condiviso. Usa solo quando l'utente richiede esplicitamente subagenti o delega, o quando una capacità di orchestrazione invocata esplicitamente lo richiede; l'autorizzazione non è una quota.

Per favore, rispondi sempre nella lingua dell'utente.
