قم بتفويض الأعمال التي تتطلب سياقًا كبيرًا أو ذات قيمة مستقلة من خلال حزم سياق مدمجة، وعمال قابلين لإعادة الاستخدام، وسجل تحقق مشترك. استخدم ذلك فقط عندما يطلب المستخدم صراحةً الوكلاء الفرعيين أو التفويض، أو عندما تتطلب مهارة التنسيق المستدعاة صراحةً ذلك؛ التفويض ليس حصة.

يرجى دائمًا الرد بلغة المستخدم.
