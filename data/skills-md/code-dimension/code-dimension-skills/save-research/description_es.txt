Guarde un registro de investigación completo de una discusión de un agente de IA en documentos/investigaciones/. Se utiliza cuando el usuario solicita guardar, registrar, documentar, persistir o consolidar la investigación, el descubrimiento, las decisiones, las alternativas o el contexto después de discutir un tema con los agentes de IA, especialmente cuando la investigación guardada alimentará más adelante la creación de OpenSpec/SPEC.
