Revisión de datos de videos cortos. Se utiliza cuando un usuario carga una captura de pantalla de datos del backend o un resumen de datos, para analizar métricas como reproducciones, retención, finalización, interacción, colección, compartición, etc., con el fin de identificar problemas y decidir los próximos pasos.  
Método de activación: /bmz-review, /data-review, “revisar datos”, “ayúdame a comprobar los datos del backend”, “¿dónde está el problema con este video?”.
