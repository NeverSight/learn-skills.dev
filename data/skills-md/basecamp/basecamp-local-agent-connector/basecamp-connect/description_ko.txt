Basecamp에서 로컬 Claude Code 에이전트를 관리합니다. 연결 브리지(bin/connect)를 실행하고, 해당 STDOUT을 신뢰할 수 있는 이벤트(기본적으로 운영자만 작성하고 실제 Basecamp 에이전트 사용자를 @멘션한 이벤트) 위해 감시합니다. 각 이벤트를 에이전트로서 몇 초 안에 인식하고(적절한 내용으로 빠른 보강이나 적합한 답변), 이후 백그라운드 에이전트에 넘겨 컨텍스트를 수집하고 작업을 수행한 뒤 해당 에이전트 사용자로 답변합니다. 이렇게 하면 감시 스레드가 새로운 멘션을 계속 받아들일 수 있습니다.  
인자 없이 호출하면 ~/.config/basecamp-connect/last.json에 저장된 최근 사용 에이전트와 프로젝트를 불러와 시작 전에 확인합니다.  
Basecamp에서 로컬 에이전트를 구동하거나, Basecamp에서 에이전트 명령을 감시하도록 요청받을 때 사용합니다.
