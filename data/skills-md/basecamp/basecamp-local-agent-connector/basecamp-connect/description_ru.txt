Управляйте локальными агентами Claude Code из Basecamp. Запускает мост‑коннектор (bin/connect), отслеживает его STDOUT в поисках доверенных событий — созданных авторизованным пользователем (по умолчанию только оператором) и @упоминающих реального пользователя‑агента Basecamp — подтверждает каждое в течение секунд (быстрый ответ с уместным контентом или подходящий ответ), затем передаёт его фоновому агенту, который собирает контекст, выполняет работу и отвечает от имени этого пользователя‑агента, чтобы поток‑наблюдатель оставался свободным для обработки новых упоминаний. При вызове без аргументов он восстанавливает последний использованный агент и проекты из ~/.config/basecamp-connect/last.json, подтверждая их перед запуском. Используйте, когда требуется управлять локальными агентами из Basecamp или наблюдать за Basecamp на предмет команд агентам.
