从 Basecamp 管理本地 Claude Code 代理。运行连接桥（bin/connect），监视其 STDOUT 中的受信任事件——这些事件由已授权用户（默认仅限操作员）编写，并 @ 提及真实的 Basecamp 代理用户——在几秒内以代理身份确认每个事件（快速提供恰当内容或合适的回复），随后将其交给后台代理，后台代理收集上下文、执行工作，并以该代理用户的身份回复，这样监视线程就能保持空闲，继续接受新的提及。未带参数调用时，它会从 ~/.config/basecamp-connect/last.json 中读取上一次使用的代理和项目，在启动前进行确认。用于在 Basecamp 中驱动本地代理，或监视 Basecamp 中的代理指令。
