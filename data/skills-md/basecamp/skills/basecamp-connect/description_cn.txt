从 Basecamp 驱动您自己的 Claude Code 会话。启动本地连接器（basecamp connect），该连接器作为 Basecamp 代理监听账户的事件流，并对每个受信任的请求输出一行：提及、指派或代理关注的线程中的评论。此会话在几秒钟内（用它自己的话说是一次加速）确认每个请求，选择项目的代码仓库，并将请求交给后台子代理，子代理读取上下文，使用您的设置和工具完成工作，并以代理的身份回复。会话保持空闲，随时可处理下一个请求，您可以持续使用。

它还将代理连接到此计算机并管理其设置：代理的凭证（basecamp auth agent connect）、可以向其分配任务的人，以及它服务的项目（basecamp connect setup），另有状态和诊断功能。

在需要连接代理、从 Basecamp 驱动代理、监视 Basecamp 中代理的提及、启动或停止连接器，或更改允许给代理分配任务的人员或其服务的项目时使用。
