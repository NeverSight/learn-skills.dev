從 Basecamp 驅動您自己的 Claude Code 會話。啟動本機連接器（basecamp connect），它會作為 Basecamp 代理監聽帳戶的事件訊息流，對每個可信請求（提及、指派或代理關注之討論串的留言）印出一行。此會話會在數秒內回應每個請求（以其自己的說法提升），選擇該專案的代碼庫，並將請求交給背景子代理，由它閱讀上下文、使用您的設定與工具完成工作，並以代理身份回覆。會話在完成後仍保持空閒，等待下一個請求，您可以持續使用它。

同時也會把代理連接到此電腦並管理其設定：代理的憑證（basecamp auth agent connect）、可以指派工作給它的人，以及它服務的專案（basecamp connect setup），另外還有狀態與診斷（doctor）資訊。

在需要連接代理、從 Basecamp 驅動代理、監控 Basecamp 中代理的提及、啟動或停止連接器，或變更可指派工作的人或代理服務的專案時使用本功能。
