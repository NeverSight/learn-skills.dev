Basecamp에서 자체 Claude Code 세션을 구동합니다. 로컬 커넥터(basecamp connect)를 시작하여 계정의 이벤트 피드를 Basecamp 에이전트로 청취하고, 신뢰할 수 있는 요청마다 한 줄을 출력합니다: 멘션, 할당, 에이전트가 팔로우하는 스레드에 달린 댓글 등. 이 세션은 각 요청을 몇 초 안에 확인하고(자체적으로는 boost라고 부름), 프로젝트에 맞는 저장소를 선택한 뒤, 컨텍스트를 읽고 사용자 설정과 도구를 이용해 작업을 수행하며 에이전트로서 응답하는 백그라운드 서브에이전트에 요청을 전달합니다. 세션은 다음 요청을 받을 준비가 언제든 열려 있으며, 계속해서 사용할 수 있습니다. 또한 에이전트를 이 컴퓨터에 연결하고 설정을 관리합니다: 에이전트 자격증명(basecamp auth agent connect), 작업을 맡길 수 있는 사람, 담당할 프로젝트(basecamp connect setup) 및 상태와 진단 정보를 포함합니다. 에이전트를 연결하거나 Basecamp에서 에이전트를 구동하고, 에이전트 멘션을 감시하거나, 커넥터를 시작·중지하거나, 작업을 맡길 수 있는 사람이나 담당 프로젝트를 변경할 때 사용합니다.
