Basecamp から自分の Claude Code セッションを駆動します。ローカルコネクタ（basecamp connect）を起動し、アカウントのイベントフィードを Basecamp エージェントとして監視し、信頼できるリクエスト（メンション、割り当て、エージェントがフォローしているスレッドへのコメント）ごとに 1 行を出力します。このセッションはそれぞれを数秒以内に確認し（自身の言葉で言えば「ブースト」）、プロジェクトに対応するリポジトリを選択し、コンテキストを読み取って設定とツールを用いて作業し、エージェントとして返信するバックグラウンドのサブエージェントにリクエストを渡します。セッションは次のリクエストを受け取る準備が常にできており、引き続き使用できます。また、エージェントをこのコンピュータに接続し、その設定を管理します：エージェントの認証情報（basecamp auth agent connect）、作業を依頼できるユーザー、サービス対象のプロジェクト（basecamp connect setup）、さらにステータスと診断機能です。エージェントの接続依頼、Basecamp からエージェントを駆動、エージェントへのメンション監視、コネクタの起動・停止、エージェントに作業を依頼できるユーザーや対象プロジェクトの変更時に使用してください。
