Prepara, confirma y envía los cambios de Git con mensajes de confirmación convencionales. Úsalo cuando el usuario quiera confirmar y enviar cambios, mencione enviar a un repositorio remoto o pida guardar y enviar su trabajo. También se activa cuando el usuario dice «hacer push de los cambios», «hacer commit y push», «hacer push de esto», «hacer push a GitHub» o solicitudes similares relacionadas con el flujo de trabajo de Git.
