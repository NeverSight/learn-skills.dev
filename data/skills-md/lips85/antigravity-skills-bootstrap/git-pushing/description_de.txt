Staging, Commit und Push von Git-Änderungen mit konventionellen Commit-Nachrichten. Verwenden Sie diese Option, wenn der Benutzer Änderungen committen und pushen möchte, das Pushen auf ein Remote-Repository erwähnt oder darum bittet, seine Arbeit zu speichern und zu pushen. Wird auch aktiviert, wenn der Benutzer „Änderungen pushen“, „Commit und Push“, „Dies pushen“, „Auf GitHub pushen“ oder ähnliche Anfragen zum Git-Workflow äußert.
