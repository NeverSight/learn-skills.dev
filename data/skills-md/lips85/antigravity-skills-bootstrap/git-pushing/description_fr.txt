Indexer, valider et pousser les modifications Git avec des messages de validation conventionnels. À utiliser lorsque l'utilisateur souhaite valider et pousser les modifications, mentionne la poussée vers un dépôt distant ou demande à enregistrer et à pousser son travail. S'active également lorsque l'utilisateur dit « push des modifications », « commit et push », « push ceci », « push vers GitHub » ou formule des demandes similaires liées au workflow Git.
