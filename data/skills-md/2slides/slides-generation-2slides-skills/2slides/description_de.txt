KI-gestützte Präsentationsgenerierung mit 2slides API. Erstellen Sie Folien aus Textinhalten, passen Sie Referenzbildstile an oder fassen Sie Dokumente in Präsentationen zusammen. Verwenden Sie diese Option, wenn Benutzer "eine Präsentation erstellen", "Folien erstellen", "ein Deck erstellen", "Folien aus diesem Inhalt/Dokument/Bild erstellen" oder eine Aufgabe zum Erstellen einer Präsentation anfordern. Unterstützt Themenauswahl, mehrere Sprachen und sowohl synchrone als auch asynchrone Generierungsmodi.
