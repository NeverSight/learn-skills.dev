يُستخدم عندما تحتاج مهمة واجهة المستخدم/تجربة المستخدم إلى ذكاء تصميمي قابل للبحث: التخطيط أو البناء أو الإنشاء أو التصميم أو التنفيذ أو المراجعة أو الإصلاح أو التحسين أو التحسين أو التحسين أو إعادة البناء أو التحقق من واجهة مستخدم الويب/الهاتف المحمول. يغطي مواقع الويب والصفحات المقصودة ولوحات المعلومات ولوحات الإدارة والتجارة الإلكترونية وSaaS والمحافظ والمدونات وتطبيقات الهاتف المحمول والمكونات والنماذج والجداول والمخططات وأنظمة الألوان وإمكانية الوصول والرسوم المتحركة والتخطيط والطباعة والتباعد وحالات التفاعل والظلال والتدرجات وخيارات نظام التصميم. يتضمن 67 نمطًا لواجهة المستخدم، و161 لوحة ألوان، و57 زوجًا من الخطوط، و161 قاعدة منطقية للمنتج، و99 دليلًا إرشاديًا لتجربة المستخدم، و25 نوعًا من المخططات، وأكثر من 15 حزمة مكدسة بما في ذلك React وNext.js وVue وSvelte وAstro وSwiftUI وReact Native وFlutter وTailwind/HTML وshadcn/ui وThree.js وAngular وLaravel.
