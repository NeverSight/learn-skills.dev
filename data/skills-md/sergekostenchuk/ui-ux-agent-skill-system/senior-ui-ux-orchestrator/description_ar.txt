مهارة تنسيق واجهة المستخدم/تجربة المستخدم الرئيسية. استخدم هذه المهارة عندما يطلب المستخدم إنشاء أو إعادة بناء أو تدقيق أو نقد أو تخطيط أو التحقق من صحة واجهة مستخدم تطبيق الويب، ولوحات معلومات SaaS، والأدوات الداخلية، والصفحات المقصودة، وصفحات المنتج، ولقطات الشاشة، وتصميمات Figma، وسير عمل Figma MCP، والتصميم إلى التعليمات البرمجية، والرمز إلى اللوحة القماشية، ومزامنة نظام التصميم، واستكشاف واجهة المستخدم للخياطة/الذكاء الاصطناعي، واستكشاف التصميم ثلاثي الاتجاهات، وتأثيرات كشف المؤشر، والسلوك سريع الاستجابة، وإمكانية الوصول، والجودة المرئية، وكبار السن قرارات مجلس UI/UX/SEO/LLM، أو بوابات سياق wiki، أو سير عمل نظام مهارات واجهة المستخدم. تعمل المسارات على webapp-ui-skill، وmarketing-site-skill، وux-audit-skill، وdesign-critic-skill، وui-ux-pro-max، وstitch-design-bridge، و Senior-figma-orchestrator، و cursor-reveal-hero، و image-layer-alignment-validator، و Task-plan-v2-orchestrator، و obsidian-wiki-ingest، وأدوات التحقق المشتركة أثناء الإنفاذ الخصوصية المحلية أولاً، وكرسي مركزي واحد، وعدم وجود أدوات مزيفة، وإعداد تقارير الأدلة، والتحقق البصري.
