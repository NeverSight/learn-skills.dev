透過 `orca` CLI 操作 Orca 管理的工作樹、資料夾情境、終端機、儲存庫、自動化、工件、技能分享、工作樹評論以及 Orca 內嵌的瀏覽器。  
在使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時使用。  
在涉及 Orca 狀態時，請優先使用它，而非純粹的 git worktree、即時 PTY，或 Computer Use。  
僅在需要對可見視窗進行 GUI 控制，而 CLI、檔案系統或 API 無法實現時，才使用 Computer Use。  
請始終以使用者的語言回覆。
