Bedienen Sie von Orca verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaum‑Kommentare und den in Orca eingebetteten Browser über die `orca` CLI. Verwenden Sie sie, wenn der Nutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzugen Sie sie gegenüber rohen Git‑Arbeitsbäumen, ad‑hoc PTYs oder Computer Use, wenn Orca‑Zustand involviert ist. Nutzen Sie Computer Use nur, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die ein CLI, Dateisystem oder eine API nicht leisten kann.
