Usa questa modalità quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferiscila rispetto all'uso diretto di git worktree, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Usa Computer Use solo quando è necessaria la gestione di una finestra visibile mediante GUI che la CLI, il filesystem o le API non possono eseguire.
