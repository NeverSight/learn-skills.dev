Оперировать рабочими деревьями, управляемыми Orca, контекстами папок, терминалами, репозиториями, автоматизациями, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Использовать, когда пользователь говорит "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" или "share skills". Предпочитать его вместо обычного git worktree, произвольных PTY или использования компьютера, когда задействовано состояние Orca. Использовать Computer Use только в случае, когда необходимо управление видимым окном GUI, которое нельзя выполнить с помощью CLI, файловой системы или API.
