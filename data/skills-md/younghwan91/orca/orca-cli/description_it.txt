Usa quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferiscila rispetto a un worktree git grezzo, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Usa Computer Use solo quando è necessaria una finestra visibile che richieda il controllo GUI che la CLI, il filesystem o l'API non possono fare.

Rispondi sempre nella lingua dell'utente.
