Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザを `orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」「share skills」などと言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree や臨時の PTY、あるいは Computer Use よりもこれを優先してください。CLI、ファイルシステム、API では実行できない GUI 操作が必要で、可視ウィンドウを操作しなければならない場合にのみ Computer Use を使用します。

常にユーザーの言語で回答してください。
