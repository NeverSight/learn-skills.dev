تشغيل شجرات العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الأثرية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر واجهة سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّلها على شجرة git العادية، أو PTY المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متضمنة. استخدم استخدام الكمبيوتر فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة رسومية لا يمكن لسطر الأوامر أو نظام الملفات أو واجهة برمجة التطبيقات القيام به.
