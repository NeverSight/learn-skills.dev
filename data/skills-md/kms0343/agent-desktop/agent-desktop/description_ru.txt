Оперировать настольные приложения в macOS, Windows и Linux через родные деревья доступности, используя CLI agent‑desktop. Используйте, когда ИИ‑агенту необходимо видеть или взаимодействовать с настольным графическим интерфейсом: нажимать кнопки, заполнять формы, считывать состояние UI, перемещаться по меню, переключать чекбоксы, прокручивать, перетаскивать, вводить текст, нажимать сочетания клавиш, делать скриншоты, управлять окнами, использовать буфер обмена, запускать или закрывать приложения, читать уведомления. Триггеры: «click button», «fill form», «open app», «read UI», «computer use», «operate desktop», «accessibility tree», «snapshot app», «type into field», «navigate menu», «toggle checkbox», «take screenshot», «desktop automation», «agent-desktop» или любая задача настольного GUI в macOS, Windows или Linux.
