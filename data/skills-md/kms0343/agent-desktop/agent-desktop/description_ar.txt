تشغيل تطبيقات سطح المكتب على macOS وWindows وLinux عبر أشجار الوصول الأصلية، باستخدام واجهة سطر الأوامر agent‑desktop. يُستعمل عندما يحتاج وكيل الذكاء الاصطناعي إلى رؤية أو التفاعل مع واجهة المستخدم الرسومية لسطح المكتب: النقر على الأزرار، تعبئة النماذج، قراءة حالة الواجهة، التنقل في القوائم، تبديل خانات الاختيار، التمرير، السحب، كتابة النص، الضغط على الاختصارات، أخذ لقطات شاشة، إدارة النوافذ، استخدام الحافظة، تشغيل أو إغلاق التطبيقات، قراءة الإشعارات. يتم التحفيز عند: "click button"، "fill form"، "open app"، "read UI"، "computer use"، "operate desktop"، "accessibility tree"، "snapshot app"، "type into field"، "navigate menu"، "toggle checkbox"، "take screenshot"، "desktop automation"، "agent-desktop"، أو أي مهمة GUI على سطح المكتب على macOS أو Windows أو Linux.
