تشغيل منصة FMZ Quant للتداول (fmz.com) من خلال أدوات MCP الخاصة بها وكتابة استراتيجيات لها بلغة JavaScript/TypeScript أو Python أو C++ أو Rust أو Pine Script أو MyLanguage (麦语言). يشمل الحصول على التفويض والاتصال (تدفق رمز الجهاز، مفتاح API، رأس Bearer، الصلاحيات)، نموذج المنصة (حسابات البورصات، العقد، الاستراتيجيات، القوالب، الروبوتات، الاختبارات الخلفية، الرسائل)، كل أداة MCP وواجهة برمجة التطبيقات الموسعة REST، وثائق واجهة برمجة التطبيقات الكاملة للاستراتيجيات مع أمثلة بأربع لغات، مؤشرات TA/talib، تكوين الاختبار الخلفي السحابي وقراءة النتائج، وقواعد الأمان لمنصة المال الحقيقي. استخدم ذلك كلما تم الاتصال بخادم FMZ MCP، أو عندما تذكر المهمة FMZ أو روبوتاتها أو استراتيجياتها أو اختباراتها الخلفية أو عقدها أو مفاتيح API، أو كود الاستراتيجية للمنصة.

الرجاء دائمًا الرد بلغة المستخدم.
