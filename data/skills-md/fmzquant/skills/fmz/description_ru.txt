Оперировать торговой платформой FMZ Quant (fmz.com) через её инструменты MCP и писать стратегии для неё на JavaScript/TypeScript, Python, C++, Rust, Pine Script или MyLanguage (麦语言). Охватывает получение авторизации и подключение (flow с кодом устройства, API‑ключ, заголовок Bearer, области доступа), модель платформы (счета бирж, узлы, стратегии, шаблоны, роботы, бэктесты, сообщения), каждый инструмент MCP и расширенный REST‑API, полную документацию API стратегий с примерами на четырёх языках, индикаторы TA/talib, конфигурацию облачного бэктеста и чтение результатов, а также правила безопасности реальной денежной платформы. Используйте, когда сервер MCP FMZ подключён, либо когда задача упоминает FMZ, её роботов, стратегии, бэктесты, узлы или API‑ключи, или код стратегии для платформы.
