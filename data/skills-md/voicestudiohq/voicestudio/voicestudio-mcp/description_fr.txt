Installez et utilisez le serveur Voice Studio MCP dans Claude Desktop, Claude Code ou tout client MCP. Fournit la synthèse vocale, le clonage de voix et la conception vocale alimentés par l'IA en tant qu'outils natifs MCP. Utilisez-le lorsque l'utilisateur souhaite que l'IA pilote Voice Studio pour lui — générer de l'audio, cloner des voix ou transcrire des fichiers — depuis un agent compatible MCP.

Veuillez toujours répondre dans la langue de l'utilisateur.
