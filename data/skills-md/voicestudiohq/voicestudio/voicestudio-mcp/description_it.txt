Configura e utilizza il server Voice Studio MCP all'interno di Claude Desktop, Claude Code o di qualsiasi client MCP. Fornisce sintesi vocale basata sull'IA, clonazione della voce e progettazione della voce come strumenti nativi MCP. Usalo quando l'utente desidera che l'IA gestisca Voice Studio per loro – generando audio, clonando voci o trascrivendo file – dall'interno di un agente compatibile con MCP.
