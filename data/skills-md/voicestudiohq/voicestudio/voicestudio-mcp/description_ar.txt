قم بإعداد واستخدام خادم Voice Studio MCP داخل Claude Desktop أو Claude Code أو أي عميل MCP. يوفر تحويل النص إلى كلام مدعوم بالذكاء الاصطناعي، واستنساخ الأصوات، وتصميم الصوت كأدوات MCP أصلية. يُستخدم عندما يرغب المستخدم في أن يقوم الذكاء الاصطناعي بتشغيل Voice Studio له - توليد الصوت، استنساخ الأصوات، أو نسخ الملفات - من داخل عميل مدرك لـ MCP. يرجى دائمًا الرد بلغة المستخدم.
