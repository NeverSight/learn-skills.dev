Configura e utilizza il CLI di Voice Studio per script shell, elaborazione batch, pipeline CI o qualsiasi automazione non MCP. Offre sintesi vocale basata sull'IA, clonazione della voce e progettazione della voce come comandi shell componibili. Usa quando l'utente desidera scrivere script per Voice Studio da bash/zsh, farm di rendering, GitHub Actions o incanalare il suo output in altri strumenti (jq, ffmpeg, ecc.).
