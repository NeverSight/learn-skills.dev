Установите и используйте CLI Voice Studio для скриптов оболочки, пакетной обработки, CI‑конвейеров или любой автоматизации, не связанной с MCP. Предоставляет AI‑управляемый синтез речи, клонирование голоса и создание голоса в виде составных команд оболочки. Используйте, когда пользователь хочет скриптовать Voice Studio из bash/zsh, рендер‑ферм, GitHub Actions или передавать его вывод в другие инструменты (jq, ffmpeg и др.).
