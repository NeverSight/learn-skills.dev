قم بإعداد واستخدام واجهة سطر أوامر Voice Studio للسكريبتات الشل، المعالجة الدفعية، خطوط أنابيب CI، أو أي أتمتة غير MCP. توفر تحويل النص إلى كلام مدعوم بالذكاء الاصطناعي، استنساخ الصوت، وتصميم الصوت كأوامر شل مركبة. استخدمها عندما يرغب المستخدم في كتابة سكريبتات Voice Studio من bash/zsh، مزارع التصيير، GitHub Actions، أو توجيه مخرجاتها إلى أدوات أخرى (jq، ffmpeg، إلخ).
