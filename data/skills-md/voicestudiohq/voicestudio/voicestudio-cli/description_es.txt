Configura y utiliza la CLI de Voice Studio para scripts de shell, procesamiento por lotes, pipelines de CI o cualquier automatización no MCP. Proporciona texto a voz impulsado por IA, clonación de voz y diseño de voz como comandos de shell composables. Úsalo cuando el usuario quiera scriptar Voice Studio desde bash/zsh, granjas de renderizado, GitHub Actions o canalizar su salida a otras herramientas (jq, ffmpeg, etc.).
