Installez et utilisez le CLI Voice Studio pour les scripts shell, le traitement par lots, les pipelines CI ou toute automatisation non‑MCP. Fournit une synthèse vocale, un clonage de voix et une conception vocale alimentés par l’IA sous forme de commandes shell composables. À utiliser lorsque l’utilisateur souhaite piloter Voice Studio depuis bash/zsh, des fermes de rendu, GitHub Actions, ou acheminer sa sortie vers d’autres outils (jq, ffmpeg, etc.). Veuillez toujours répondre dans la langue de l’utilisateur.
