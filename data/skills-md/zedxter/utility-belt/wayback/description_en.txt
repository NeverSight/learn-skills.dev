Checks, lists, reads and saves Internet Archive Wayback Machine snapshots of public web pages without a key - whether a URL was ever archived (first and latest capture), the capture closest to a date, every capture in a period or only those where the content changed, all archived URLs under a path or site, what a page said at a given time (readable text or the original bytes, PDFs included), and Save Page Now. Use when a link is dead, 404 or changed, when the user asks what a web page said before or on a date, wants an old or previous version of a page or docs site, an archived or cached copy, needs to prove or cite how a page looked, or asks to archive a URL in the Wayback Machine ("что было на странице в 2020", "найди в веб-архиве"). Not for live pages that load fine (read those directly), git or file history, backups, zip or tar archives, archive.today, or private and logged-in pages.
