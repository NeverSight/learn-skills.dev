Search the web from the user's own machine without an API key and get title, URL, snippet (and date/source for news) from DuckDuckGo, Bing, Brave, Google, Yahoo or Wikipedia through the ddgs metasearch library, or from the user's own SearXNG instance; filter by time window, region, site or news, and with --read N fetch the top results through the web-extract skill so one call returns what the pages actually say. Free local stand-in for paid search APIs (Tavily, Serper, Firecrawl search, Jina search). Use when the user asks to look something up, find sources, recent news or documentation, compare what several sites say, check a fact, or when a built-in web search tool is missing, rate-limited or returns thin results ("найди в интернете", "что пишут о"). Not for reading a URL the user gave (web-extract), a whole site (web-crawl), YouTube videos (youtube-search), Hacker News (hackernews), Wikipedia (wiki-lookup) or scholarly papers (scholar-search).
