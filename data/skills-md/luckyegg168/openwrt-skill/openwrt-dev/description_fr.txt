Utilisez cette compétence chaque fois qu’un utilisateur mentionne OpenWrt, le développement de routeurs, les appareils réseau Linux embarqués, LuCI, UCI, les paquets ipk, le firmware de routeur ou toute tâche de développement liée à l’écosystème OpenWrt. Même si l’utilisateur demande simplement « comment exécuter mon propre programme sur le routeur », cela doit être déclenché.
