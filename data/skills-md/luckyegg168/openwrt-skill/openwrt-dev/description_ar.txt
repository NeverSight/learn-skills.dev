دليل كامل لتطوير فيرموير الراوتر OpenWrt وحزم البرمجيات. يغطي نظام البناء، تطوير الحزم، واجهة LuCI، الوحدات الأساسية، تكوين الشبكة، الترجمة المتقاطعة، التصحيح، والأمان. استخدم هذه المهارة كلما ذكر المستخدم OpenWrt أو تطوير الراوتر أو أجهزة الشبكة المدمجة بنظام لينكس أو LuCI أو UCI أو حزم ipk أو فيرموير الراوتر أو أي مهام تطوير تتعلق بنظام OpenWrt. حتى إذا سأل المستخدم فقط “كيفية تشغيل برنامجي الخاص على الراوتر”، يجب تفعيلها.
