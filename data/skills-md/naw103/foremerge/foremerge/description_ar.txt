نسّق الوكلاء البرمجيين المتوازيين باستخدام واجهة سطر الأوامر المتوافقة مع Git المحلي الخاصة بـ Foremerge وخادم MCP. استخدمها عندما يحتاج الوكيل إلى نشر النية قبل التحرير، أو ادعاء النطاق الدلالي، أو اكتشاف الأعمال المكررة أو غير المتوافقة، أو التنسيق بشأن النزاعات المستديمة، أو نشر مجموعة تغييرات، أو تشغيل فحص توثيق موثوق مسمى، أو قبول العمل المُتحقق منه، أو تسجيل تكامله مع Git.
