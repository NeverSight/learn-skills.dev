قم بتنسيق الوكلاء البرمجيين المتوازيين باستخدام واجهة سطر الأوامر المتوافقة مع Git وخادم MCP المحلي من Foremerge. استخدم ذلك عندما يجب على الوكيل نشر النية قبل التحرير، أو المطالبة بنطاق دلالي، أو اكتشاف العمل المكرر أو غير المتوافق، أو التنسيق حول النزاعات المستدامة، أو نشر مجموعة التغييرات، أو تشغيل فحص التحقق الموثوق المُسمّى، أو قبول العمل المُتحقق منه، أو تسجيل تكامله مع Git.
