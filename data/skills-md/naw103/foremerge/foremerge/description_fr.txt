Coordonnez les agents de codage parallèles avec le CLI local compatible Git de Foremerge et le serveur MCP. Utilisez‑le lorsqu’un agent doit publier son intention avant de modifier, revendiquer une portée sémantique, détecter un travail dupliqué ou incompatible, coordonner des conflits persistants, publier un ChangeSet, exécuter une vérification fiable nommée, accepter le travail validé ou enregistrer son intégration Git.
