Coordonnez les agents de codage parallèles avec le serveur local CLI et MCP compatible Git de Foremerge. À utiliser lorsqu'un agent doit publier l'intention avant la modification, revendiquer la portée sémantique, détecter le travail en double ou incompatible, coordonner les conflits durables, publier un ChangeSet, exécuter une vérification nommée de confiance, accepter le travail validé ou enregistrer son intégration Git.
