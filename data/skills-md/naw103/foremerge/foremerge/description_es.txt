Coordine los agentes de codificación paralela con el servidor local CLI y MCP compatible con Git de Foremerge. Se utiliza cuando un agente debe publicar la intención antes de editar, reclamar el alcance semántico, detectar trabajos duplicados o incompatibles, coordinar conflictos duraderos, publicar un ChangeSet, ejecutar una verificación de confianza, aceptar trabajos validados o registrar su integración con Git.
