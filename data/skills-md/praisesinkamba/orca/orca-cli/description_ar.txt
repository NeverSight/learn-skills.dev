قم بتشغيل الأشجار العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، أو "Orca worktree"، أو "child worktree"، أو "spawn codex/claude in a worktree"، أو "read/wait/send Orca terminal"، أو "handoff" / "handover" / "give this to another agent"، أو "Orca browser"، أو "orca artifacts"، أو "share skills". فضّل ذلك على استخدام git worktree الخام، أو PTYs العشوائية، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية بحيث لا يستطيع سطر الأوامر أو نظام الملفات أو API القيام بذلك.
