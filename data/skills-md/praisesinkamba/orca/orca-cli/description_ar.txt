تشغيل شجرات العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل هذا على استخدام git worktree الخام، أو PTYs المخصصة، أو استخدام الكمبيوتر عندما تكون حالة Orca متورطة. استعن باستخدام الكمبيوتر فقط عندما يتطلب التحكم في نافذة مرئية لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به.
