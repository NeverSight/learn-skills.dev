Verwalte Orca‑verwaltete Arbeitsbäume, Ordner‑Kontexte, Terminals, Repositories, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaum‑Kommentare und Orcas integrierten Browser über die `orca`‑CLI. Verwende sie, wenn der Benutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzuge sie gegenüber roher Git‑Worktree‑Nutzung, ad‑hoc‑PTYs oder Computer‑Use, wenn Orca‑Zustände involviert sind. Setze Computer‑Use nur ein, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die ein CLI, Dateisystem oder eine API nicht leisten kann.
