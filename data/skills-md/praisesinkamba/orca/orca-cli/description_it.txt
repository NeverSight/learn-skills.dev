Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser integrato di Orca tramite il CLI `orca`. Utilizzalo quando l’utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferiscilo rispetto a un git worktree grezzo, PTY ad‑hoc o Computer Use quando è coinvolto lo stato di Orca. Usa Computer Use solo quando una finestra visibile richiede il controllo GUI che né il CLI, né il filesystem, né l’API possono fornire. Rispondi sempre nella lingua dell’utente.
