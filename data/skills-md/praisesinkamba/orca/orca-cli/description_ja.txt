Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用します。Orca の状態が関与している場合は、生の git worktree やアドホック PTY、あるいは Computer Use よりもこの方法を優先してください。CLI、ファイルシステム、API では対応できない可視ウィンドウの GUI 操作が必要な場合にのみ Computer Use を使用してください。常にユーザーの言語で返答してください。
