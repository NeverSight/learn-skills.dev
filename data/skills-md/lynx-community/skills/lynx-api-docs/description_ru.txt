Предоставляет авторитетное руководство по разработке Lynx, включая страницы, шаблоны, компоненты, CSS, макеты, элементы, веб-миграцию, ошибки рендеринга или стиля, а также проверку кода. Применяется к *.ttml, Lynx *.tsx и всем файлам, специфичным для Lynx, и перед действием требует поиска в установленной документации API.
