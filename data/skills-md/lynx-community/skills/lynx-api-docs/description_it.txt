Fornisce una guida autorevole per lo sviluppo di Lynx che coinvolge pagine, modelli, componenti, CSS, layout, elementi, migrazione web, bug di rendering o di stile e revisione del codice. Si applica a *.ttml, Lynx *.tsx e a tutti i file specifici di Lynx e richiede la ricerca nei documenti API installati prima di agire.
