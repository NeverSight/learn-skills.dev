Usa solo quando l'utente chiede di scrivere un handoff, un prompt di continuazione o un file di trasferimento della sessione affinché un altro agente, modello o harness possa continuare il lavoro corrente, o lo chiama session-handoff. Scrivi un breve file sotto `.handoff/` che il successore esegue: cosa stava venendo fatto, cosa viene dopo e le domande da porre all'utente. NON quando l'utente fornisce il percorso di un file handoff esistente o dice di continuare da uno: quello ti chiede di eseguire il compito del file, non di scrivere o migliorare un handoff. NON per limitare un esecutore più debole su un piano approvato (small-model-handoff), scrivere o eseguire piani (gigio-write-plan, gigio-execute-plan), o leggere il transcript di un'altra sessione (read-agent-sessions). Non attivare mai perché una sessione è diventata lunga o il contesto è quasi esaurito.  

Rispondi sempre nella lingua dell'utente.
