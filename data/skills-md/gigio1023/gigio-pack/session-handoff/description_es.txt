Usar solo cuando el usuario solicite escribir un handoff, una solicitud de continuación o un archivo de transferencia de sesión para que otro agente, modelo o harness pueda continuar el trabajo actual, o se denomine session-handoff. Escribe un archivo breve bajo `.handoff/` que el sucesor ejecutará: lo que se estaba haciendo, lo que sigue y las preguntas que debe hacer al usuario. NO cuando el usuario proporcione la ruta de un archivo de handoff existente o indique continuar desde uno: eso le pide ejecutar la tarea del archivo, no escribir o mejorar un handoff. NO para limitar un ejecutor más débil en un plan aprobado (small-model-handoff), escribir o ejecutar planes (gigio-write-plan, gigio-execute-plan), o leer la transcripción de otra sesión (read-agent-sessions). Nunca activar porque una sesión se haya alargado mucho o el contexto esté bajo.

Por favor, responde siempre en el idioma del usuario.
