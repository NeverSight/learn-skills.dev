Distill the design philosophy of the Apple Human Interface Guidelines into design trade‑offs and UI review criteria for web products. Use it when the user explicitly requests Apple HIG, Apple‑style, native‑feeling, modern clean restraint, or wants to design and review a web product's navigation, toolbar, menu, overlay, list, charts, loading, feedback, modal, undo, drag‑and‑drop, search, and onboarding primarily based on HIG; it also applies to visual AI development interfaces such as GGN. Do not use it for ordinary brand marketing pages, pure visual beautification, backend business logic, or Apple native app API implementations.
