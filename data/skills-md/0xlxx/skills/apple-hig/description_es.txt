Destila la filosofía de diseño de las Apple Human Interface Guidelines en compensaciones de diseño y criterios de revisión de UI para productos web. Úsala cuando el usuario solicite explícitamente Apple HIG, estilo Apple, sensación nativa, modernidad limpia y contenida, o quiera diseñar y revisar la navegación, barra de herramientas, menú, superposición, lista, gráficos, carga, retroalimentación, modal, deshacer, arrastrar y soltar, búsqueda y onboarding de un producto web basándose principalmente en HIG; también se aplica a interfaces de desarrollo de IA visual como GGN. No la uses para páginas de marketing de marca convencionales, puro embellecimiento visual, lógica de negocio del backend o implementaciones de API de aplicaciones nativas de Apple.

Por favor, responde siempre en el idioma del usuario.
