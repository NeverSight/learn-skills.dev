Le migliori pratiche per lo sviluppo della robotica ROS 2, che coprono la struttura dei pacchetti, i nodi, i topic / service / action, i file di lancio, il QoS, le trasformazioni tf2 e i test. Da utilizzare quando si creano pacchetti ROS 2, si scrivono nodi in rclpy o rclcpp, si definiscono messaggi / service / action personalizzati, si scrivono file di lancio, si configurano profili QoS, si lavora con le trasformazioni tf2 o si costruisce e si testa un workspace colcon. Per favore rispondi sempre nella lingua dell'utente.
