Best Practices für den Aufbau von KI‑Agenten mit Googles Agent Development Kit (ADK) in Python, inklusive Agenten‑Design, Werkzeuge, Sitzungen, Speicher, Artefakte, Bewertung und Bereitstellung. Verwenden Sie dies beim Erstellen von LLM‑Agenten oder Multi‑Agenten‑Systemen mit ADK, beim Definieren von ADK‑Werkzeugen, dem Vernetzen von Sitzungen/Zustand/Speicher, der Arbeit mit ADK‑Artefakten, dem Schreiben von Agenten‑Bewertungen oder der Bereitstellung von ADK‑Agenten auf Vertex AI Agent Engine oder Cloud Run.
