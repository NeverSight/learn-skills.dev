Le migliori pratiche per il Fortran moderno (2003/2008+) nella scienza e nel calcolo numerico, che coprono moduli, interfacce esplicite, parametri di kind, sicurezza della memoria e testing. Da utilizzare quando si scrive o si revisiona codice Fortran (.f90/.f95/.f03/.f08), si definiscono moduli e tipi derivati, si scelgono parametri di kind numerici, si lavora con array allocabili, si imposta una build Fortran con CMake o fpm, o si scrivono test unitari per codice numerico.
