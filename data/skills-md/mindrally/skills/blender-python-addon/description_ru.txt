Лучшие практики написания аддонов для Blender на Python с использованием API bpy, охватывающие операторов, панелей, свойств, регистрации и безопасного скриптинга API. Применяется при создании аддона Blender, определении классов bpy.types.Operator или Panel, регистрации настроек PropertyGroup, написании функций register() / unregister(), работе с bmesh или отладке аддонов в консоли Python Blender.
