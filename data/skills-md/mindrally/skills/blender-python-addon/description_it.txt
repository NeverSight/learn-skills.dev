Migliori pratiche per scrivere add‑on Python per Blender usando l’API bpy, includendo operatori, pannelli, proprietà, registrazione e scripting sicuro per l’API. Da utilizzare quando si crea un add‑on per Blender, si definiscono classi bpy.types.Operator o Panel, si registrano impostazioni PropertyGroup, si scrivono le funzioni register()/unregister(), si lavora con bmesh o si debugga gli add‑on nella console Python di Blender.
