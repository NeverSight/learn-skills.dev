Типобезопасная файловая маршрутизация для React с TanStack Router. Используйте при определении маршрутов с помощью createFileRoute, валидации параметров поиска с Zod, написании загрузчиков маршрутов, настройке охранников аутентификации с beforeLoad, интеграции TanStack Query в загрузчики или конфигурации контекста роутера и предзагрузке.
