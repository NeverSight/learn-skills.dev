Best Practices für TanStack Start, das Full‑Stack‑React‑Framework, das auf TanStack Router und Vite/Nitro basiert. Verwenden Sie es beim Erstellen von Server‑Funktionen mit createServerFn, beim Einrichten von SSR und Streaming mit defer()/Await, beim Schreiben von API‑Routen, beim Konfigurieren von app.config.ts oder beim Deployen einer TanStack‑Start‑App auf Node, Vercel, Netlify, Bun oder Cloudflare.

Bitte immer in der Sprache des Benutzers antworten.
