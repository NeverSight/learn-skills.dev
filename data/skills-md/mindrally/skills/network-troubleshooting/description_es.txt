Diagnóstico sistemático y con prioridad de seguridad de fallos de red de desarrolladores, como conexión rechazada, errores de resolución DNS, problemas de certificados TLS, fallos de proxy y tiempos de espera del registro de paquetes. Úsalo cuando un comando falle con un error de tipo red (curl, npm, pip, git, docker), cuando un servicio sea inaccesible o cuando el usuario solicite depurar problemas de conectividad, DNS, TLS o proxy.

Por favor, responde siempre en el idioma del usuario.
