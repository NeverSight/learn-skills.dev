Principes de code propre, maintenable et lisible par l'humain combinés à une discipline anti-sur‑ingénierie : nommage, responsabilité unique, DRY et limitation des changements à exactement ce qui a été demandé. À utiliser lors de l'écriture de nouveau code, du refactoring de code existant, de la révision du code pour la qualité, ou pour décider du niveau d'abstraction réellement nécessaire à une modification.
