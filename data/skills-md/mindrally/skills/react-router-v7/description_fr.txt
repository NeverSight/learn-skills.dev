Conventions du mode framework de React Router v7 pour les modules de route, les chargeurs de données, les actions et l'amélioration progressive. À utiliser lors de la création de routes basées sur des fichiers avec des chargeurs/actions, de la gestion des soumissions de formulaires avec Form / useFetcher / useSubmit, de l’ajout de composants ErrorBoundary aux routes, de la revalidation des données après des mutations, ou de la migration de modules de route de style Remix vers React Router v7.
