Convenciones del modo framework de React Router v7 para módulos de rutas, cargadores de datos, acciones y mejora progresiva. Úsalo al crear rutas basadas en archivos con loaders/acciones, al manejar envíos de formularios con Form/useFetcher/useSubmit, al agregar componentes ErrorBoundary a las rutas, al volver a validar datos después de mutaciones o al migrar módulos de rutas al estilo Remix a React Router v7.
