Convenzioni della modalità framework di React Router v7 per i moduli di route, i loader dei dati, le azioni e il miglioramento progressivo. Usa quando crei route basate su file con loader/azioni, gestisci le sottomissioni di form con Form/useFetcher/useSubmit, aggiungi componenti ErrorBoundary alle route, rivalida i dati dopo le mutazioni o migri i moduli di route in stile Remix a React Router v7.
