قواعد وضع الإطار في React Router v7 لوحدات المسارات، محملات البيانات، الإجراءات، والتحسين التدريجي. يُستخدم عند بناء مسارات مستندة إلى الملفات مع محملات/إجراءات، معالجة إرسالات النماذج باستخدام Form / useFetcher / useSubmit، إضافة مكونات ErrorBoundary للمسار، إعادة التحقق من صحة البيانات بعد التعديلات، أو نقل وحدات المسارات بنمط Remix إلى React Router v7.
