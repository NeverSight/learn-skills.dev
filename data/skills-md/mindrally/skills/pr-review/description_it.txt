Pratiche di revisione mirata delle pull request con risultati classificati per gravità, citati per file e riga, su quattro aspetti: sicurezza, prestazioni, test e architettura. Da utilizzare quando ti viene chiesto di revisionare una pull request, esaminare un diff o un insieme di modifiche, revisionare “questa PR”, o fornire una revisione del codice prima del merge. Per favore, rispondi sempre nella lingua dell'utente.
