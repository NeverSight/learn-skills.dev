Conventions de structure, de ton et de contenu pour rédiger des fichiers README de projet efficaces, incluant les accroches, les démarrages rapides, la présentation des fonctionnalités, les badges et les sections de documentation courantes. À utiliser lors de la rédaction d’un nouveau README, de la réécriture d’un existant ou de l’évaluation de la qualité d’un README pour un dépôt, une bibliothèque ou un outil en ligne de commande.
