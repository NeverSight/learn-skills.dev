Kit d'outils pour créer et valider des compétences et des sous‑agents. À utiliser lors de : la création d’une nouvelle compétence (mode rapide ou complet), la validation d’une compétence existante, la décision Compétences vs Sous‑agents, la migration de documents vers les compétences, l’estimation du coût en jetons, ou l’exécution d’une analyse de sécurité. Déclencheurs : « create skill », « build skill », « validate skill », « new subagent », « skills vs subagents », « estimate tokens », « security scan ».
