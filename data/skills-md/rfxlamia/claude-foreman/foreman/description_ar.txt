نقل تنفيذ العمل إلى وكلاء ترميز خارجيين عبر سطر الأوامر (مثل OpenAI Codex `codex exec`، أو Google Antigravity/Gemini `agy -p`، أو أي أداة مع محول) بدلاً من وكلاء Claude الفرعيين، بحيث يُحمّل الترميز الثقيل حصص مقدمي الخدمات الآخرين بينما يعمل Claude كالمشرف - يخطط، يوجّه، يراجع الفروقات ويتحقق منها. يُستخدم هذا عندما يستدعي المستخدم الأمر /foreman، أو يطلب "استخدام codex/gemini/agy كعاملين"، أو "توفير حصة/حدود Claude"، أو "السماح لنموذج آخر بالترميز بينما تقوم بالمراجعة". يعمل العاملون في مسارات عمل git معزولة عبر scripts/dispatch.sh.
