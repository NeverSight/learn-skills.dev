클로드 하위 에이전트 대신 외부 코딩 에이전트 CLI(OpenAI Codex `codex exec`, Google Antigravity/Gemini `agy -p` 또는 어댑터가 있는 어떤 하니스)를 사용해 구현 작업을 위임하세요. 이렇게 하면 무거운 코딩은 다른 공급자의 할당량을 소모하고, 클로드는 현장 감독자 역할을 하며—계획, 브리핑, 차이점 검토 및 검증을 수행합니다. 사용자는 /foreman을 호출하거나, “codex/gemini/agy를 작업자로 사용해 주세요”, “클로드 할당량/제한을 절약하고 싶어요”, 혹은 “다른 모델이 코딩을 맡고 당신은 검토만 하세요”와 같은 요청을 할 때 사용합니다. 작업자는 scripts/dispatch.sh 스크립트를 통해 격리된 git worktree에서 실행됩니다.

항상 사용자의 언어로 응답하세요.
