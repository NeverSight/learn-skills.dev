Zweischichtiges PR-Überprüfungstool (Ravens Urteil). Führt parallele kontradiktorische zynische Überprüfungen und Edge Case Hunter durch, verschmilzt und dedupliziert Ergebnisse zu professionellen Engineering-Outputs. Wird verwendet, wenn der Benutzer zur „Überprüfung einer PR“ auffordert und eine PR-URL oder -ID bereitstellt.
