Herramienta de revisión de relaciones públicas de doble capa (Veredicto de Raven). Ejecuta la revisión cínica adversarial y el cazador de casos de borde en paralelo, fusiona y deduplica los hallazgos en resultados de ingeniería profesional. Utilícelo cuando el usuario solicite "revisar un PR" y proporcione una URL o ID de PR.
