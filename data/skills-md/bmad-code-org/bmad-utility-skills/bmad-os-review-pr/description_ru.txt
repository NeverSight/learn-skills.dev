Двухуровневый инструмент обзора PR (Verdict Ворона). Параллельно запускает адверсариальный циничный обзор и поиск граничных случаев, объединяет и удаляет дублирующиеся находки, выдавая профессиональный инженерный результат. Используйте, когда пользователь просит «провести обзор PR» и предоставляет URL или ID PR.

Пожалуйста, всегда отвечайте на языке пользователя.
