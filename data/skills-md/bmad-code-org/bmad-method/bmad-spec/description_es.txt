Condense cualquier aporte (una idea, un resumen, un PRD, una transcripción o notas mixtas) en una breve especificación: SPEC.md más archivos de respaldo a partir de los cuales se desarrollan las habilidades posteriores. También actualiza y valida las especificaciones existentes y puede dividir una especificación en historias. Úselo cuando el usuario diga "crear una especificación", "destilar esto en una especificación", "validar esta especificación", "actualizar la especificación" o "dividir esto en historias".
