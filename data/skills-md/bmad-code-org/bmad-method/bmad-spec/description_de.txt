Fassen Sie alle Eingaben – eine Idee, ein Brief, ein PRD, ein Transkript oder gemischte Notizen – in einer kurzen Spezifikation zusammen: SPEC.md plus unterstützenden Dateien, auf denen nachgelagerte Fähigkeiten aufbauen. Aktualisiert und validiert außerdem vorhandene Spezifikationen und kann eine Spezifikation in Storys aufteilen. Wird verwendet, wenn der Benutzer sagt: „Eine Spezifikation erstellen“, „Dies in eine Spezifikation destillieren“, „Diese Spezifikation validieren“, „Die Spezifikation aktualisieren“ oder „Dies in Storys aufteilen“.
