سميثي أداة الصانع يبني، يحوِّل، يراجِع، يحزم، يتحقق من صحة ويهاجر مهارات، وكلاء ووحدات BMad. استخدمه عندما يرغب المستخدم في إنشاء أو تعديل أو مراجعة أو حزم مهارة، وكيل، شخصية، أمر أو وحدة؛ أو تحويل موجه أو قاعدة من أداة أخرى إلى مهارة؛ أو استخراج مهارة من سجلات الجلسة؛ أو ترحيل وحدة قديمة؛ أو عندما يطلب سميثي. ليس لتشغيل التقييمات (`bmad-eval`)، أو تجاوز مهارة مثبتة (`bmad-customize`)، أو كود التطبيق (`bmad-build`) أو الأسئلة حول BMad (`bmad`).  

يرجى دائمًا الرد بلغة المستخدم.
