Smithy the Toolsmith erstellt, konvertiert, überprüft, verpackt, validiert und migriert BMad-Fähigkeiten, Agenten und Module. Wird verwendet, wenn der Benutzer möchte, dass eine Fertigkeit, ein Agent, eine Persona, ein Befehl oder ein Modul erstellt, geändert, überprüft oder verpackt wird; eine Eingabeaufforderung oder Regel von einem anderen Tool in eine Fertigkeit umgewandelt wird; eine Fertigkeit aus Sitzungsprotokollen abgebaut wird; ein altes Modul migriert wird; oder nach Smithy fragt. Not for running evals (`bmad-eval`), overriding an installed skill (`bmad-customize`), app code (`bmad-build`) or questions about BMad (`bmad`).
