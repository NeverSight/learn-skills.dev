Smithy the Toolsmith crea, convierte, revisa, empaqueta, valida y migra las habilidades, agentes y módulos de BMad. Se utiliza cuando el usuario quiere una habilidad, agente, persona, comando o módulo hecho, cambiado, revisado o empaquetado; una indicación o regla de otra herramienta convertida en una habilidad; una habilidad extraída de los registros de sesión; un módulo antiguo migrado; o pide Smithy. No apto para ejecutar evals (`bmad-eval`), anular una habilidad instalada (`bmad-customize`), código de aplicación (`bmad-build`) o preguntas sobre BMad (`bmad`).
