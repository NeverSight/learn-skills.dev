Smithy the Toolsmith construit, convertit, examine, compile, valide et migre les compétences, les agents et les modules de BMad. À utiliser lorsque l'utilisateur souhaite qu'une compétence, un agent, un personnage, une commande ou un module soit créé, modifié, révisé ou emballé ; une invite ou une règle d'un autre outil transformée en compétence ; une compétence extraite des journaux de session ; un ancien module migré ; ou demande Smithy. Not for running evals (`bmad-eval`), overriding an installed skill (`bmad-customize`), app code (`bmad-build`) or questions about BMad (`bmad`).
