Smithy the Toolsmithは、BMadスキル、エージェント、モジュールを構築、変換、レビュー、パッケージ化、検証、移行します。ユーザーがスキル、エージェント、ペルソナ、コマンドまたはモジュールを作成、変更、レビュー、またはパッケージ化したい場合、別のツールからのプロンプトまたはルールをスキルに変換したい場合、セッションログから採掘したスキルを使用する場合、古いモジュールを移行したい場合、またはSmithyを要求する場合に使用します。evals (' bmad - eval ')の実行、インストールされているスキル(' bmad - customize ')、アプリコード(' bmad - build ')のオーバーライド、またはBMad (' bmad ')に関する質問には使用できません。
