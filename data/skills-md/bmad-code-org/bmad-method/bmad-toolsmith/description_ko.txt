Smithy the Toolsmith는 BMad 기술, 에이전트 및 모듈을 구축, 변환, 검토, 패키지화, 검증 및 마이그레이션합니다. 사용자가 스킬, 에이전트, 페르소나, 명령 또는 모듈을 제작, 변경, 검토 또는 패키징하거나, 다른 도구의 프롬프트 또는 규칙을 스킬로 변환하거나, 세션 로그에서 채굴한 스킬을 사용하거나, 이전 모듈을 마이그레이션하거나, Smithy를 요청할 때 사용합니다. Evals (`bmad-eval`), 설치된 스킬 ('bmad-customize`), 앱 코드 (`bmad-build`) 또는 BMad (`bmad`) 에 대한 질문을 재정의하지 않습니다.
