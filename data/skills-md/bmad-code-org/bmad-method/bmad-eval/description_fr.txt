Exécute les événements d'une compétence BMad à travers le harnais d'agent dans lequel l'utilisateur travaille et rapporte ce qu'ils montrent : ligne de base par rapport au modèle nu, variante par rapport à une version dépouillée ou antérieure, qualité par rapport à une rubrique et précision de déclenchement de la description avec une boucle d'optimisation optionnelle. À utiliser lorsque l'utilisateur demande d'évaluer, de comparer, de tester les déclencheurs, de noter ou de comparer les versions d'une compétence, ou lorsque la compétence bmad-toolsmith demande une évaluation d'une compétence qu'elle a construite.
