Transforme une transcription, un fil de discussion, une note vocale ou un document long en une note citée sur laquelle les agents peuvent agir. Utilisez‑le lorsque l’utilisateur dit « ingérer ceci », « traiter cette transcription », « prendre des notes à partir de ce fil ou de cet enregistrement » ou « ce qui ressort de cette réunion ». Veuillez toujours répondre dans la langue de l’utilisateur.
