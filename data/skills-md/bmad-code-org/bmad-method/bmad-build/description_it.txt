Trasforma il lavoro di implementazione in codice funzionante, rivisto e verificato. Da utilizzare quando l'utente delega una funzionalità, una storia, una correzione di bug o una modifica significativa; conta una semplice storia o un collegamento a un problema. Evita la manutenzione meccanica ovvia e a basso rischio, come piccole modifiche di file da ignorare, solo errori di battitura, sola formattazione o modifiche di configurazione. Le richieste BMAD esplicite sono sempre qualificate. Non offrirti volontario per modifiche interattive dirette dall'utente o operazioni di controllo della versione che registrano solo il lavoro esistente.
