Convierte el trabajo de implementación en código de trabajo, revisado y verificado. Úselo cuando el usuario delega una característica, historia, corrección de errores o cambio significativo; una historia simple o un enlace a un problema cuenta. Omita el mantenimiento mecánico obvio y de bajo riesgo, como pequeñas ediciones de ignorar archivos, solo errores tipográficos, solo formato o de higiene de configuración. Las solicitudes BMAD explícitas siempre califican. No se ofrezca como voluntario para realizar ediciones interactivas dirigidas por el usuario u operaciones de control de versiones que solo registren el trabajo existente.
