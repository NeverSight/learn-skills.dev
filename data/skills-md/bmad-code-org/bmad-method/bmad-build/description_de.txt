Verwandelt die Implementierungsarbeit in funktionierenden Code, der überprüft und verifiziert wird. Verwenden Sie diese Option, wenn der Benutzer eine Funktion, eine Story, eine Fehlerbehebung oder eine bedeutungsvolle Änderung delegiert. Ein bloßer Story- oder Issue-Link zählt. Überspringen Sie offensichtliche, risikoarme mechanische Wartungsarbeiten wie kleine Datei-Ignorier-, Tippfehler-, Formatierungs- oder Konfigurationshygieneänderungen. Explizite BMAD-Anfragen sind immer qualifiziert. Nehmen Sie nicht freiwillig an benutzergesteuerten interaktiven Bearbeitungen oder Versionskontrollvorgängen teil, bei denen nur vorhandene Arbeiten aufgezeichnet werden.
