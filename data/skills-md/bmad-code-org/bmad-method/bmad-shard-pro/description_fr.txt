Rend les longs documents faciles à parcourir pour les agents. Utilisez-le lorsque l'utilisateur dit « fractionner ce document », « ce fichier est trop long pour les agents », « transformer ce document en wiki », « ajouter une table des matières afin que les agents puissent trouver des choses », ou « mettre à jour le document fragmenté ». Veuillez toujours répondre dans la langue de l'utilisateur.
