Erstellen und verwalten Sie Tickets auf allen Ebenen — schneiden Sie eine Initiative in Epics, brechen Sie ein Epic in Stories auf, schreiben oder verfeinern Sie ein Ticket und führen Sie das Board aus (veröffentlichen, bereit, verschieben, zuweisen, Status, abbrechen). Verwenden Sie diese Option, wenn der Benutzer „Eine neue Initiative erstellen“, „dies in Scheiben schneiden“, „dieses Epos aufnehmen“, „ein Ticket erstellen“, „dieses Ticket verfeinern“, „was ist fertig“, „Status einer Geschichte“, „Ticketänderungen veröffentlichen“ sagt.
