Flujo de trabajo interactivo de escalado-resolución para el orquestador bmad-loop. Una ejecución de bucle bmad se detuvo en una escalada CRÍTICA (una contradicción o brecha que una sesión de desarrollo/revisión no pudo resolver de manera segura por sí sola); usted y el humano desambiguan la especificación congelada para que la historia pueda volver a impulsarse. Invocado como /bmad-loop-resolve<story-key>. A diferencia de las sesiones automatizadas de desarrollo/revisión, esta sesión es interactiva: un ser humano está presente y DEBE preguntar.
