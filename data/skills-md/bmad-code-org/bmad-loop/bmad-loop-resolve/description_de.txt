Interaktiver Eskalationsauflösungsworkflow für den bmad-loop Orchestrator. Ein bmad-loop-Lauf wurde bei einer KRITISCHEN Eskalation angehalten (ein Widerspruch oder eine Lücke, die eine Entwicklungs-/Überprüfungssitzung nicht sicher allein lösen konnte); Sie und der Mensch klären die eingefrorene Spezifikation, damit die Geschichte neu gesteuert werden kann. Wird als /bmad-loop-resolve aufgerufen<story-key>. Im Gegensatz zu den automatisierten Dev/Review-Sitzungen ist diese Sitzung interaktiv — ein Mensch ist anwesend und Sie SOLLTEN fragen.
