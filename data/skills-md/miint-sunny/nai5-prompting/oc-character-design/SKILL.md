# OC 整体角色设计

普通生成使用本包方法与本次资料，不为补题或更像某人自主检索历史作品、旧提示词、反推及维护报告。用户指定的角色、原串和参考按本次范围读取；只有明确要求核对依据、分析指定作品或制作其变体时才读相关历史材料。

读 [角色设计方法](references/character.md)，按本次需要发展角色在意什么、遇事怎样行动、在何处生活，以及远看轮廓与近看细节怎样让人辨认。从零设计时可以大胆提出新方案；使用已有 OC 时以用户提供或实际启用的资料为事实，保留锁定细节，只发展开放部分。没有 OC 库也能完成新角色设计。

只有用户要求查证背景，或方案依赖尚未确认的现实／原作事实时，才选读[背景资料核对](references/background.md)。已有依据足够时继续设计。

交用户请求的角色概念、具体外形、整体方案或局部重设计，不强制补全传记。整体角色与服装分工按方法处理：已知角色只换衣服就沿用其设定；同时要求角色与服装时交完整方案，不用职责划分截断请求。新增提案不自动写回永久设定。

本包可独立完成角色设计，不要求其他技能必装。需要深入服装、构图、故事或转词且相应技能已启用时，可按方法中的技能名接续；未启用时用本包完成能做的内容，如实说明能力边界，不声称读过缺失资源。角色设计本身即可结束，不默认附提示词或执行工作台操作。
