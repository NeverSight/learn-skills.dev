Создавайте или редактируйте изображения с помощью встроенного генератора изображений Codex из любого агента, через инструмент MCP или обычный CLI. Для каждого запроса изображения сначала предлагаются как минимум четыре разных стилистических направления (24 отточенных шаблона, 48 пресетов, 20 художников постеров Mondo), пользователь выбирает, запрос уточняется, генерируется и проверяется результат. Сценарии: обложка видео, видеоплакат, иллюстрации для Xiaohongshu, обложка публичного аккаунта, обложка X, постер для кругов друзей, обложка книги, обложка альбома, постер продукта, портрет, постер сезонных праздников, постер выставки, слайд PPT, генерация изображения из изображения. Использовать для создания изображений, иллюстраций, постеров, обложек, «дай мне несколько стилей», «нарисуй с помощью Codex». Исключения: редактирование фотографий локальными инструментами, построение графиков или диаграмм по данным, макеты UI, генерация видео или любые задачи, требующие сервисов изображений с API‑ключом.
