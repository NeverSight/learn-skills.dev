استخدم واجهة برمجة التطبيقات الرسمية للبحث/الجلب من DeepSeek لتكملة أبحاث البحث، والتحقق المتقاطع من الوقائع، وتحديد أحدث المعلومات والمصادر، وجلب محتوى صفحة الويب بصيغة Markdown. يمكن للنموذج الذي يستدعي هذه الميزة فهم أي موضوع، وتوسيع الاستفسارات، وسد الفجوات المعلوماتية، وتقييم الصلة، والتحقق من التعارضات؛ حيث تتولى السكريبتات عملية الاسترجاع، والجلب، وإزالة التكرار. يتم استخدام ذلك عندما يقول المستخدم “use DeepSeek search”، “DS search”، “supplementary search”، “find a few more sources”، “DeepSeek fetch this webpage”، أو عند تكوين مفتاح API qiaomu-ds-search. ابحث مع المصادر وجلب الصفحات العامة. إذا كان مفتاح API مفقودًا، قم بإرشاد المستخدم لفتح الصفحة الرسمية، وإنشاء مفتاح، وإكمال تكوين الأمان، وإجراء اختبار عملي. استثنِ إعادة الكتابة/الترجمة غير المتصلة بالإنترنت، والبحث في الملفات المحلية، واستدعاءات نموذج الدردشة، والتكوينات العامة التي لا تحدد DeepSeek، وتجاوز جدران تسجيل الدخول، والزحف الكامل للموقع؛ كتكملة لقدرات البحث الحالية، لا يفرض استحواذًا كاملًا على جميع عمليات البحث.
