Utilisez l’API officielle Search / Fetch de DeepSeek pour compléter la recherche, recouper les faits, localiser les informations et sources les plus récentes, et récupérer le contenu Markdown d’une page web. Le modèle invoquant la compétence peut comprendre n’importe quel sujet, élargir les requêtes, combler les lacunes d’information, évaluer la pertinence et vérifier les contradictions ; les scripts gèrent la récupération, le fetch et la déduplication. Cela est employé lorsque l’utilisateur dit « use DeepSeek search », « DS search », « supplementary search », « find a few more sources », « DeepSeek fetch this webpage », ou lors de la configuration de la clé API qiaomu-ds-search. Effectuez une recherche avec sources et récupérez les pages publiques. Si la clé API manque, guidez l’utilisateur pour ouvrir la page officielle, créer une clé, terminer la configuration de sécurité et réaliser des tests pratiques. Excluez la réécriture/traduction purement hors ligne, la recherche de fichiers locaux, les appels de modèle de chat, les configurations génériques ne mentionnant pas DeepSeek, les contournements de mur de connexion et le crawl complet du site ; en tant que complément aux capacités de recherche existantes, cela ne prend pas le contrôle de toutes les recherches.  

Veuillez toujours répondre dans la langue de l’utilisateur.
