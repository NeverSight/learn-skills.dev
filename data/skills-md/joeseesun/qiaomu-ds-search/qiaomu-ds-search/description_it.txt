Utilizza l'API ufficiale Search/Fetch di DeepSeek per integrare la ricerca, verificare incrociatamente i fatti, individuare le informazioni e le fonti più recenti e recuperare il contenuto Markdown delle pagine web, consentendo al modello che invoca le Skill di comprendere qualsiasi argomento, espandere le query, colmare le lacune informative, valutare la pertinenza e verificare i conflitti; gli script gestiscono il recupero, il fetch e la deduplicazione. Questo viene impiegato quando l'utente dice “use DeepSeek search”, “DS search”, “supplementary search”, “find a few more sources”, “DeepSeek fetch this page”, o quando si configura la chiave API qiaomu-ds-search. Ricerca con fonti e recupero di pagine pubbliche. Se la chiave API manca, guida l'utente alla pagina ufficiale per crearne una e completare la configurazione di sicurezza e i test. Esclude la pura riscrittura/offline traduzione, la ricerca di file locali, le chiamate al modello chat, le configurazioni generiche che non specificano DeepSeek, i bypass dei login‑wall e la scansione completa del sito; serve come integrazione alle capacità di ricerca esistenti senza prendere forzatamente il controllo di tutte le ricerche.

Rispondi sempre nella lingua dell'utente.
