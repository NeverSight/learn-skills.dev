Utilizza l'API ufficiale Search / Fetch di DeepSeek per integrare la ricerca, verificare incrociatamente i fatti, individuare le informazioni e le fonti più recenti e recuperare il contenuto Markdown delle pagine web. Il modello che invoca la Skill può comprendere qualsiasi argomento, espandere le query, colmare le lacune informative, valutare la rilevanza e verificare i conflitti; gli script gestiscono il recupero, il fetching e la deduplicazione. Questo viene impiegato quando l'utente dice “use DeepSeek search”, “DS search”, “supplementary search”, “find a few more sources”, “DeepSeek fetch this webpage”, o quando si configura la chiave API qiaomu-ds-search. Ricerca con fonti e recupera pagine pubbliche. Se la chiave API manca, guida l'utente ad aprire la pagina ufficiale, creare una chiave, completare la configurazione di sicurezza e effettuare test pratici. Escludi riscritture/traduzioni pure offline, ricerca di file locali, chiamate al modello di chat, configurazioni generiche che non specificano DeepSeek, bypass di login‑wall e scansioni complete del sito; come integrazione delle capacità di ricerca esistenti, non prende forzatamente il controllo di tutte le ricerche.

Rispondi sempre nella lingua dell'utente.
