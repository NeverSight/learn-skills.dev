Создавайте готовые видео из существующих записей экрана и озвучки с двуязычными китайско‑английскими субтитрами, семантическими эффектами движения, лёгкой фоновой музыкой и обложкой контента с помощью FFmpeg/ASS. Поддерживает выделение отдельного слова, стилизованный текст‑ключевые слова в стиле Douyin, эмодзи и мем‑стикеры (Noto/Fluent/memegen), стрелки UI и рамки‑прожекторы, карточки глав, оригинальные лёгкие звуковые эффекты, списки слов OCR с экрана и обнаружение движения камеры, локальный видеомонтаж или шумоподавление аудио в FFmpeg, независимое выравнивание аудио, Doubao ASR, локальные Whisper/Qwen, генерацию изображений Codex‑ом или преднастроенные API изображений, синтез оригинального кода по умолчанию, по‑запросу чистую инструментальную фонова музыку YuE2/Suno и неблокирующую генерацию HTML‑дашборда; опционально стиль «редакционная раскадровка» (Vercel × The New Yorker: крупные открывающие титры, линия прогресса главы, 4K). Предназначено для «записи экрана с субтитрами», «превратить запись экрана в видео», «демультипликация записи экрана», «запись экрана с эффектами движения», «синхронизация аудио с внешнего микрофона с записью экрана», «китайско‑английские субтитры с музыкой», «запись экрана в стиле Vercel/New Yorker», «полоска прогресса главы в записи экрана», «screen2video». Не предназначено для съёмки новых демонстраций, действий UI видеомонтажа, ремикса фильма, цифровых людей, озвучки или полных рекламных роликов.
