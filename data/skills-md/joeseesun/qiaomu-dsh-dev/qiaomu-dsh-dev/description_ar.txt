طوّر، أنشئ الهيكل، صحّح الأخطاء، راجع، اختبر، ثبّت وانشر إضافات وحزم DeepSeek Harness (DSH) Cordis المستمرة من البداية إلى النهاية. استخدمها لخدمات/أدوات المضيف، فتحات/ألواح العميل، الجسور البعيدة، المحادثات الأصلية، بيانات الإضافة، دمج الملفات الشخصية، فشل عمليات البناء، ترقيات المضيف ومصفوفات التوافق، تراجع واجهة المستخدم، التحقق المباشر من المضيف، إصدارات GitHub، ملف README ثنائي اللغة ومُوضح، الحزم المعبأة وتقديمات السوق. تشمل "Doctor" المستقل، إنشاء الهيكل، تدقيق الحزمة، مقارنة الملفات المثبتة والتحقق من التحميل العام؛ لا يلزم تثبيت مهارات أخرى. تحقق من نسخة Harness المثبتة وواجهة برمجة التطبيقات الحالية. استثنِ الإضافات الخاصة بـ Obsidian فقط، التطبيقات الويب العامة، أسئلة الاستخدام الفردية لـ DSH، حزم Cordis Run المؤقتة وكتابة المهارات.
