通用線上影片與音樂下載、媒體擷取技能。  
當使用者表達下載意圖，例如「download this / save this / download this」並提供 HTTPS 連結時，即使未明確提及「影片」或「音樂」，此技能也會偵測並下載。  
內建 WeChat Channels 與 Spotify 曲目的轉接器，並支援 yt‑dlp 的擷取器，涵蓋 YouTube、Bilibili、X／Twitter、抖音／TikTok、小紅書、Instagram、Facebook、Vimeo、Twitch、Reddit、微博、AcFun 等平台；同時能處理 MP3、字幕、媒體資訊，以及 yt‑dlp 更新。  
若僅貼上 URL 而未表達下載意圖，則不會自動下載。  
它絕不使用 UI 自動化來操作 WeChat、小紅書或風控驗證頁面。
