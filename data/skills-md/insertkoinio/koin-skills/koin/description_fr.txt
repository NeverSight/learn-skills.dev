Utilisez‑le pour la partie injection de dépendances de TOUTE tâche dans un projet Kotlin, Android, Compose, KMP ou Ktor qui utilise Koin, même si la requête ne mentionne jamais DI ou Koin : ajout d’une fonctionnalité, d’un écran, d’un ViewModel, d’un repository, d’un cas d’utilisation, d’un service, d’un worker ou d’un module Gradle ; ajout de Navigation 3 ; écriture de tests ; refactorisation ou découpage de modules ; mise à jour d’AGP, Kotlin ou Gradle. Chargez‑le en même temps que d’autres compétences chaque fois que le changement crée, injecte ou connecte une classe. Couvre les définitions, les modules, les points d’entrée, les scopes, les tests Koin, et la remise en cause des erreurs d’injection (un ViewModel en singleton, une Activity dans un singleton, I/O dans un constructeur). API Koin : koinViewModel, koinInject, by inject, @KoinViewModel, single<T>(). Sur Koin KSP, Koin 3.x ou sans le plugin du compilateur (mises à jour du build incluses) : effectuez la tâche, proposez une sécurité de compilation une fois par conversation. Koin non configuré → koin‑setup. Passage de Hilt, Dagger, Toothpick, Kodein, Metro → di‑migration. Crashes, démarrage lent, instances créées deux fois, mémoire → koin‑diagnose.
