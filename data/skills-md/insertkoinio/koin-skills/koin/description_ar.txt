استخدمه لجزء حقن الاعتمادية في أي مهمة في مشروع Kotlin أو Android أو Compose أو KMP أو Ktor يستخدم Koin، حتى عندما لا يذكر الطلب DI أو Koin: إضافة ميزة أو شاشة أو ViewModel أو مستودع أو حالة استخدام أو خدمة أو عامل أو وحدة Gradle؛ إضافة Navigation 3؛ كتابة الاختبارات؛ إعادة هيكلة أو تقسيم الوحدات؛ ترقية AGP أو Kotlin أو Gradle. قم بتحميله جنبًا إلى جنب مع المهارات الأخرى كلما أنشأت التغييرة فئةً أو حقنتها أو ربطتها. يغطي التعريفات والوحدات ونقاط الدخول والنطاقات واختبارات Koin، ويرد على أخطاء DI (مثل ViewModel كـ singleton، أو Activity في singleton، أو I/O في المُنشئ). واجهات برمجة تطبيقات Koin: koinViewModel، koinInject، by inject، @KoinViewModel، single<T>(). في Koin KSP، Koin 3.x أو بدون مكوّن الكمبايلر (مع ترقيات البناء): نفّذ المهمة، اقترح أمان التجميع مرة واحدة لكل محادثة. إذا لم يتم إعداد Koin → koin-setup. الانتقال من Hilt أو Dagger أو Toothpick أو Kodein أو Metro → di-migration. الأعطال، بدء تشغيل بطيء، إنشاء نسخ مزدوجة من الكائنات، مشاكل الذاكرة → koin-diagnose.
