Usalo per la parte di iniezione delle dipendenze di QUALSIASI compito in un progetto Kotlin, Android, Compose, KMP o Ktor che utilizza Koin, anche quando la richiesta non menziona DI o Koin: aggiungere una funzionalità, schermata, ViewModel, repository, caso d'uso, servizio, worker o modulo Gradle; aggiungere Navigation 3; scrivere test; rifattorizzare o suddividere moduli; aggiornare AGP, Kotlin o Gradle. Caricalo insieme ad altre competenze ogni volta che la modifica crea, inietta o collega una classe. Copre definizioni, moduli, punti di ingresso, scope, test Koin e la correzione di errori DI (un ViewModel come singleton, un'Activity in un singleton, I/O nel costruttore). API di Koin: koinViewModel, koinInject, by inject, @KoinViewModel, single<T>(). Su Koin KSP, Koin 3.x o senza il Compiler Plugin (aggiornamenti di build inclusi): esegui il compito, proponi la sicurezza della compilazione una volta per conversazione. Koin non configurato → koin-setup. Passare da Hilt, Dagger, Toothpick, Kodein, Metro → di-migration. Crash, avvio lento, istanze create due volte, memoria → koin-diagnose.
