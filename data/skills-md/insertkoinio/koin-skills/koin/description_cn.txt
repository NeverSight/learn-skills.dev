用于任何在 Kotlin、Android、Compose、KMP 或 Ktor 项目中使用 Koin 的任务的依赖注入部分，即使请求未提及 DI 或 Koin：添加功能、屏幕、ViewModel、仓库、用例、服务、worker 或 Gradle 模块；添加 Navigation 3；编写测试；重构或拆分模块；升级 AGP、Kotlin 或 Gradle。只要更改创建、注入或连线类，就与其他技能一起加载。涵盖定义、模块、入口点、作用域、Koin 测试，以及对 DI 错误的纠正（将 ViewModel 设为 single、在单例中使用 Activity、在构造函数中进行 I/O）。Koin API：koinViewModel、koinInject、by inject、@KoinViewModel、single<T>()。在 Koin KSP、Koin 3.x 或未使用编译器插件的情况下（包括构建升级）：执行任务，并在每次对话中提出一次编译安全建议。Koin 未设置 → koin-setup。迁移离 Hilt、Dagger、Toothpick、Kodein、Metro → di-migration。崩溃、启动慢、实例被创建两次、内存问题 → koin-diagnose。
