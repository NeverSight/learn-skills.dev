Úsalo para la parte de inyección de dependencias de CUALQUIER tarea en un proyecto Kotlin, Android, Compose, KMP o Ktor que use Koin, incluso cuando la solicitud nunca mencione DI o Koin: agregar una característica, pantalla, ViewModel, repositorio, caso de uso, servicio, worker o módulo Gradle; añadir Navigation 3; escribir pruebas; refactorizar o dividir módulos; actualizar AGP, Kotlin o Gradle. Cárgalo junto con otras habilidades siempre que el cambio cree, inyecte o conecte una clase. Cubre definiciones, módulos, puntos de entrada, alcances, pruebas de Koin y rechazar errores de DI (un ViewModel como singleton, una Activity en un singleton, I/O en un constructor). APIs de Koin: koinViewModel, koinInject, by inject, @KoinViewModel, single<T>(). En Koin KSP, Koin 3.x o sin el Compiler Plugin (actualizaciones de compilación incluidas): realiza la tarea, propone seguridad de compilación una vez por conversación. Koin no está configurado → koin-setup. Migrar fuera de Hilt, Dagger, Toothpick, Kodein, Metro → di-migration. Fallos, arranque lento, instancias creadas dos veces, memoria → koin-diagnose.

Por favor, responde siempre en el idioma del usuario.
