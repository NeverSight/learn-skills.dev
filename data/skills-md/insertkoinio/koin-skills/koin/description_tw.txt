使用於任何 Kotlin、Android、Compose、KMP 或 Ktor 專案中使用 Koin 的相依注入（DI）部分，即使請求從未提及 DI 或 Koin：新增功能、畫面、ViewModel、Repository、Use Case、Service、Worker 或 Gradle 模組；加入 Navigation 3；撰寫測試；重構或拆分模組；升級 AGP、Kotlin 或 Gradle。當變更建立、注入或連接類別時，請與其他技能一併載入。涵蓋定義、模組、入口點、作用域、Koin 測試，以及回應 DI 錯誤（將 ViewModel 設為 single、將 Activity 放入 singleton、在建構子中執行 I/O）。Koin API：koinViewModel、koinInject、by inject、@KoinViewModel、single<T>()。在 Koin KSP、Koin 3.x 或未使用編譯器外掛的情況（包含升級建置）：執行任務，並在每次對話中建議一次編譯安全性。若未設定 Koin → koin-setup。從 Hilt、Dagger、Toothpick、Kodein、Metro 移除 → di-migration。當出現當機、啟動緩慢、實例建立兩次、記憶體問題時 → koin-diagnose。
