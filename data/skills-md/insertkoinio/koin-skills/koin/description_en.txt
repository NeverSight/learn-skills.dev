Use for the dependency-injection part of ANY task in a Kotlin, Android, Compose, KMP or Ktor project that uses Koin, even when the request never mentions DI or Koin: adding a feature, screen, ViewModel, repository, use case, service, worker or Gradle module; adding Navigation 3; writing tests; refactoring or splitting modules; upgrading AGP, Kotlin or Gradle. Load it alongside other skills whenever the change creates, injects or wires a class. Covers definitions, modules, entry points, scopes, Koin tests, and pushing back on DI mistakes (a ViewModel as single, an Activity in a singleton, I/O in a constructor). Koin APIs: koinViewModel, koinInject, by inject, @KoinViewModel, single<T>(). On Koin KSP, Koin 3.x or without the Compiler Plugin (build upgrades included): do the task, propose compile safety once per conversation. Koin not set up → koin-setup. Moving off Hilt, Dagger, Toothpick, Kodein, Metro → di-migration. Crashes, slow startup, instances created twice, memory → koin-diagnose.
