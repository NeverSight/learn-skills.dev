ترحيل مشاريع Kotlin / Android / KMP إلى Koin 4.x باستخدام مكوّن Koin Compiler Plugin: Hilt، Dagger 2، Toothpick، Kodein وMetro إلى Koin، Koin 3.x إلى 4.x، إضافة مكوّن Compiler Plugin إلى مشروع Koin DSL (يتم فحص كل صيغة DSL عند التجميع، بما فيها Classic)، وإرفاق تعليقات Koin KSP إلى مكوّن Compiler Plugin. بشكل تدريجي، وحدةً بوحدةٍ، مع الحفاظ على تشغيل الحاوية القديمة حتى ينتقل آخر ربط. يُستخدم عندما يرغب المستخدم في ترحيل أو تحويل أو تبديل أطر DI، إزالة Hilt / Dagger / Toothpick / Kodein / Metro، ترقية Koin، الخروج من KSP، جعل مخطط Koin آمناً أثناء التجميع أو مُتحققاً في وقت البناء، تحويل Koin DSL إلى DSL مكوّن Compiler Plugin، أو لصق كود وحدة Hilt / Dagger / Toothpick / Kodein / Metro للتحويل — "استبدال Hilt بـ Koin"، "الابتعاد عن Dagger"، "Kodein إلى Koin"، "Metro إلى Koin"، "Koin KSP إلى مكوّن Compiler Plugin"، "الترقية إلى Koin 4"، "جعل Koin آمنًا أثناء التجميع". إضافة Koin إلى مشروع بلا DI تُعرف بـ koin-setup.
