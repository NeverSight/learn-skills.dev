Kotlin / Android / KMP プロジェクトを Koin 4.x に移行するための Koin Compiler Plugin：Hilt、Dagger 2、Toothpick、Kodein、Metro から Koin へ、Koin 3.x から 4.x へ、Koin DSL プロジェクトに Compiler Plugin を追加（すべての DSL 形態をコンパイル時にチェック、Classic も含む）、そして Koin KSP アノテーションを Compiler Plugin に統合。段階的にモジュール単位で移行し、最後のバインディングが完了するまで旧コンテナを稼働させたままにする。DI フレームワークの移行・変換・切り替え、Hilt/Dagger/Toothpick/Kodein/Metro の除去、Koin のアップグレード、KSP からの脱却、Koin グラフをコンパイル時に安全にするまたはビルド時に検証する、Koin DSL を Compiler Plugin DSL に変換する、あるいは Hilt/Dagger/Toothpick/Kodein/Metro のモジュールコードを貼り付けて変換したいときに使用する — 「Hilt を Koin に置き換える」「Dagger から離れる」「Kodein を Koin に」「Metro を Koin に」「Koin KSP を Compiler Plugin に」「Koin 4 にアップグレードする」「Koin をコンパイル時に安全にする」。DI が未使用のプロジェクトに Koin を導入する場合は koin-setup と呼ぶ。
