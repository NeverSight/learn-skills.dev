Мигрировать проекты Kotlin / Android / KMP на Koin 4.x с помощью Koin Compiler Plugin: Hilt, Dagger 2, Toothpick, Kodein и Metro в Koin, Koin 3.x в 4.x, добавить Compiler Plugin в проект Koin DSL (каждая форма DSL проверяется на этапе компиляции, включая Classic) и аннотации Koin KSP в Compiler Plugin. Поэтапно, модуль за модулем, поддерживая старый контейнер до переноса последней привязки. Использовать, когда пользователь хочет мигрировать, конвертировать или переключать DI‑фреймворки, удалить Hilt / Dagger / Toothpick / Kodein / Metro, обновить Koin, отказаться от KSP, сделать граф Koin безопасным при компиляции или проверенным во время сборки, конвертировать Koin DSL в DSL Compiler Plugin, либо вставить код модуля Hilt / Dagger / Toothpick / Kodein / Metro для конверсии — «заменить Hilt на Koin», «отойти от Dagger», «Kodein в Koin», «Metro в Koin», «Koin KSP в compiler plugin», «обновить до Koin 4», «сделать Koin безопасным при компиляции». Добавление Koin в проект без DI называется koin-setup.
