Migrer les projets Kotlin / Android / KMP vers Koin 4.x avec le Koin Compiler Plugin : Hilt, Dagger 2, Toothpick, Kodein et Metro vers Koin, Koin 3.x vers 4.x, le Compiler Plugin ajouté à un projet Koin DSL (toute forme DSL vérifiée à la compilation, Classic incluse), et les annotations Koin KSP vers le Compiler Plugin. Progressif, module par module, en gardant l’ancien conteneur en fonctionnement jusqu’à ce que la dernière liaison soit déplacée. À utiliser lorsque l’utilisateur veut migrer, convertir ou changer de framework DI, supprimer Hilt / Dagger / Toothpick / Kodein / Metro, mettre à jour Koin, quitter KSP, rendre le graphe Koin sûr à la compilation ou vérifié lors de la construction, convertir le DSL Koin en DSL du Compiler Plugin, ou coller le code d’un module Hilt / Dagger / Toothpick / Kodein / Metro à convertir — « remplacer Hilt par Koin », « s’éloigner de Dagger », « Kodein vers Koin », « Metro vers Koin », « Koin KSP vers le plugin compilateur », « mettre à jour vers Koin 4 », « rendre Koin sûr à la compilation ». Ajouter Koin à un projet sans DI s’appelle koin-setup.
