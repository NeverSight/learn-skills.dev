将 Kotlin / Android / KMP 项目迁移到使用 Koin Compiler Plugin 的 Koin 4.x：将 Hilt、Dagger 2、Toothpick、Kodein 和 Metro 迁移到 Koin，将 Koin 3.x 升级到 4.x，在 Koin DSL 项目中添加 Compiler Plugin（每种 DSL 形式都进行编译检查，Classic 也包括在内），以及将 Koin KSP 注解转为 Compiler Plugin。逐步、按模块进行迁移，保持旧容器运行直至最后一个绑定迁移完成。适用于用户希望迁移、转换或切换 DI 框架、移除 Hilt / Dagger / Toothpick / Kodein / Metro、升级 Koin、摆脱 KSP、使 Koin 图在编译时安全或在构建时验证、将 Koin DSL 转换为 Compiler Plugin DSL，或粘贴 Hilt / Dagger / Toothpick / Kodein / Metro 模块代码进行转换的场景——例如“用 Koin 替换 Hilt”“摆脱 Dagger”“Kodein 转 Koin”“Metro 转 Koin”“Koin KSP 转 Compiler Plugin”“升级到 Koin 4”“使 Koin 编译安全”。在没有 DI 的项目中添加 Koin 的命令是 koin-setup。
