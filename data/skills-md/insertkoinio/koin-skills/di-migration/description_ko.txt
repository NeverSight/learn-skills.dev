Kotlin / Android / KMP 프로젝트를 Koin Compiler Plugin을 사용해 Koin 4.x로 마이그레이션: Hilt, Dagger 2, Toothpick, Kodein 및 Metro를 Koin으로, Koin 3.x를 4.x로, Koin DSL 프로젝트에 Compiler Plugin을 추가(모든 DSL 형태가 컴파일 체크됨, Classic 포함), 그리고 Koin KSP 어노테이션을 Compiler Plugin으로 전환. 점진적으로 모듈별로 진행하여 마지막 바인딩이 이동할 때까지 기존 컨테이너를 계속 실행. 사용자가 DI 프레임워크를 마이그레이션, 변환 또는 전환하고 싶을 때, Hilt / Dagger / Toothpick / Kodein / Metro를 제거하고, Koin을 업그레이드하고, KSP를 포기하며, Koin 그래프를 컴파일 시 안전하게 만들거나 빌드 시 검증하고, Koin DSL을 Compiler Plugin DSL로 변환하거나 Hilt / Dagger / Toothpick / Kodein / Metro 모듈 코드를 붙여 변환할 때 사용 — “Hilt를 Koin으로 교체”, “Dagger에서 벗어나기”, “Kodein을 Koin으로”, “Metro를 Koin으로”, “Koin KSP를 Compiler Plugin으로”, “Koin 4로 업그레이드”, “Koin을 컴파일 안전하게 만들기”. DI가 없는 프로젝트에 Koin을 추가하는 것은 koin‑setup이다.
