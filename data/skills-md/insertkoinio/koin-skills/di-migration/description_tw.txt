將 Kotlin / Android / KMP 專案遷移至 Koin 4.x，使用 Koin Compiler Plugin：將 Hilt、Dagger 2、Toothpick、Kodein 與 Metro 轉換為 Koin，將 Koin 3.x 升級至 4.x，將 Compiler Plugin 加入 Koin DSL 專案（所有 DSL 形式皆進行編譯檢查，Classic 亦包括），以及將 Koin KSP 註解轉為 Compiler Plugin。採取逐模組、漸進式遷移，保持舊的容器在最後一個綁定搬遷前仍持續運作。適用於使用者想要遷移、轉換或切換 DI 框架、移除 Hilt / Dagger / Toothpick / Kodein / Metro、升級 Koin、拋棄 KSP、使 Koin 圖在編譯時安全或於建置時驗證、將 Koin DSL 轉為 Compiler Plugin DSL，或貼上 Hilt / Dagger / Toothpick / Kodein / Metro 模組程式碼以進行轉換——「用 Koin 取代 Hilt」、「遠離 Dagger」、「Kodein 轉 Koin」、「Metro 轉 Koin」、「Koin KSP 轉 Compiler Plugin」、「升級至 Koin 4」、「使 Koin 編譯安全」。將 Koin 加入沒有 DI 的專案稱為 koin-setup。
