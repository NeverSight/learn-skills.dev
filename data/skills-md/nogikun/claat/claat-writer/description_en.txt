入力されたコンテンツやコンテキスト（プロジェクトのソース、README、設定ファイル、既存ドキュメント、手順メモ、ログ、URL など）から、Google Codelabs の claat が HTML 化できる manual.md を、中学生でも迷わず実行できる日本語の手順書として書き起こす。実際に動くコード、実際の出力、スクリーンショットを根拠つきで配置し、cmd/claat-tools の lint 規約（メタデータ7キー、`#` タイトル1つ、`##` 手順ごとの `Duration` 行、相対画像の実在）を満たしたうえで、natural-japanese による日本語チェックを通してから渡す。ユーザーが codelab / コードラボ / claat / 手順書 / マニュアル / チュートリアル / セットアップガイド / 使い方ドキュメント の作成・下書き・書き直しを求めたときは必ず使うこと。「このプロジェクトの手順書を作って」「manual.md を書いて」「セットアップ手順をまとめて」のように claat という語を出さずに手順書化を依頼された場合も同じく使う。生成済みの .md を HTML に変換する工程は claat-build skill が担当する。
