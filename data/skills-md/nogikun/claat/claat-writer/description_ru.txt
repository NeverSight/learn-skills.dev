Из предоставленного контента и контекста (исходный код проекта, README, файлы конфигурации, существующая документация, процедурные заметки, журналы, URL‑адреса и т.п.) создайте `manual.md`, который может быть преобразован в HTML с помощью Google Codelabs claat, написанный как пошаговое руководство на японском языке, понятное даже ученикам средней школы без путаницы. Включите реально работающий код, реальный вывод и скриншоты с подтверждающими данными, и убедитесь, что он удовлетворяет правилам lint cmd/claat‑tools (семь ключей метаданных, один заголовок `#`, строка `Duration` для каждого шага под `##` и наличие относительных изображений) перед тем как пропустить его через natural‑japanese для проверки японского языка и затем доставить. Каждый раз, когда пользователь просит создать, составить или откорректировать codelab / code lab / claat / пошаговое руководство / manual / tutorial / setup guide / usage document, вы обязаны использовать именно такой подход. Это также относится к запросам, сформулированным без упоминания слова «claat», например «Создать руководство для этого проекта», «Написать manual.md» или «Свести шаги настройки». Преобразование сгенерированного `.md` в HTML обрабатывается навыком claat‑build.

Пожалуйста, всегда отвечайте на языке пользователя.
