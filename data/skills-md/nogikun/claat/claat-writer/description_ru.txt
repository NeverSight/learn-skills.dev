Исходя из входных данных и контекста (исходный код проекта, README, файлы конфигурации, существующие документы, процессные заметки, логи, URL и т.д.), создайте `manual.md`, который Google Codelabs claat может преобразовать в HTML, написанный как пошаговое руководство на японском языке, понятное даже ученикам средней школы, чтобы они не потерялись. Включите реально работающий код, реальный вывод и скриншоты с надлежащим объяснением; соблюдайте правила lint‑проверки cmd/claat‑tools (семь метаданных, один заголовок `#`, строку `## Duration` для каждого шага и наличие относительных изображений), затем пройдите проверку на японском с помощью natural‑japanese перед доставкой. Каждый раз, когда пользователь просит создать, составить или переписать codelab / code lab / claat / пошаговое руководство / руководство / учебник / инструкцию по настройке / документ по использованию, вы обязаны использовать именно этот подход. Даже если запрос сформулирован без упоминания «claat», например «Создайте руководство для этого проекта», «Напишите manual.md» или «Подытожьте шаги настройки», вы всё равно должны применять тот же процесс. Преобразование сгенерированного `.md` в HTML осуществляется с помощью навыка claat‑build. Пожалуйста, всегда отвечайте на языке пользователя.
