Dal contenuto di input e dal contesto (codice sorgente del progetto, README, file di configurazione, documenti esistenti, note procedurali, log, URL, ecc.), genera un `manual.md` che Google Codelabs claat possa convertire in HTML, scritto come una guida passo‑passo in giapponese che anche gli studenti delle scuole medie possano seguire senza perdersi. Includi codice funzionante reale, output reale e screenshot con adeguata giustificazione; soddisfa le regole di lint di cmd/claat‑tools (sette chiavi di metadati, un unico titolo con `#`, una riga `##` di `Duration` specifica per ogni passaggio e la presenza di immagini relative), quindi supera il controllo in giapponese usando natural‑japanese prima di consegnare. Ogni volta che un utente chiede la creazione, la redazione o la riscrittura di un codelab / code lab / claat / guida passo‑passo / manuale / tutorial / guida all'installazione / documento d'uso, devi sempre utilizzare questo approccio. Anche se la richiesta è formulata senza menzionare “claat”, ad esempio “Crea una guida per questo progetto”, “Scrivi un manual.md” o “Riassumi i passaggi di configurazione”, dovresti comunque applicare lo stesso processo. La conversione del `.md` generato in HTML è gestita dalla skill claat‑build.  
Rispondi sempre nella lingua dell'utente.
