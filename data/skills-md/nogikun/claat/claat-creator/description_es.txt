claat es el punto de entrada que supervisa todo el proceso de crear una guía paso a paso. A partir de los materiales (fuente del proyecto, README, notas, documentos existentes) escribimos manual.md, ejecutamos verificaciones en japonés y lint, generamos HTML y producimos un informe; estos pasos se asignan a la habilidad claat‑writer y a la habilidad claat‑build para proceder. Cuando un usuario hace una solicitud que abarca tanto la escritura como la conversión, como “crear una guía y convertirla a HTML”, “producir un codelab completo”, “hacer un manual para este proyecto y publicarlo” o “ejecutar el flujo de trabajo claat”, o cuando la etapa actual no está clara (el .md está parcialmente escrito, el lint falla, aún no se han tomado imágenes, el HTML está desactualizado), siempre se utiliza esta lógica. Si la solicitud es solo para escribir, use claat‑writer; si la solicitud es solo para convertir/validar un .md existente, use claat‑build directamente. Determinar el orden de los pasos, decidir rechazos y confirmar los criterios de finalización son responsabilidades de esta habilidad; no realiza la redacción real del texto ni las correcciones de lint.
