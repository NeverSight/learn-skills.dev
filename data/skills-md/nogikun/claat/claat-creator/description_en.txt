Entrance that oversees the entire process of creating a claat manual. Starting from materials (project source, README, notes, existing documents), you write manual.md, run Japanese checks and lint, generate HTML, and report—assigning these steps to the claat‑writer skill and claat‑build skill. When a user makes a request that spans both authoring and conversion—e.g., “create a manual and make it HTML,” “produce a full codelab,” “make a manual for this project and prepare it for publishing,” or “run the claat workflow”—or when the current stage is ambiguous (the .md is partially written, lint is failing, images not yet taken, HTML outdated), this skill is always used. If the request is only to write, use claat‑writer; if it is only to convert/validate an existing .md, use claat‑build directly. Determining the order of steps, deciding on rejections, and confirming completion criteria are the responsibilities of this skill; it does not perform the actual writing of the content or the lint fixes.
