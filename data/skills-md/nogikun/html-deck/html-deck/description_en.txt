From source material (memos, articles, research documents, meeting minutes, URLs, verbal requests), create HTML slide decks, including diagrams such as SVG and draw.io, and test them on a fixed 1600 × 900 canvas. Refine readability through a review loop with an evaluation sub‑agent. When asked to “make slides,” “presentation material,” “talking points,” “proposal material,” “deck,” “slides,” “presentation,” “turn this document into slides,” or “summarize for a presentation,” use this skill first, even if the format isn’t specified. It is also used for improving slide quality—e.g., fixing text that’s too small, overly cramped, overflowing, or hard to read—and for polishing existing HTML decks. The skill also includes a “review mode” where the user points to elements on the generated deck and requests corrections. When told “let me review it,” “there’s something I want to fix,” “open the deck,” “read the comment,” “apply the comment you sent,” or “fix this part,” the skill handles it as long as there is an existing deck. Only when an editable .pptx file itself is a delivery requirement do we switch to the PPTX skill.
