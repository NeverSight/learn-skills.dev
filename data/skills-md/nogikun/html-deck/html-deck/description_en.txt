Create HTML slide decks from source material (notes, articles, research documents, meeting minutes, URLs, verbal requests), including figures and SVG/draw.io diagrams, and test them on a fixed 1600 × 900 canvas. Refine readability through a feedback loop with an evaluation sub‑agent. When asked to “make slides,” “presentation material,” “talk deck,” “proposal deck,” “deck,” “slides,” “presentation,” “turn this document into slides,” or “summarize for a presentation,” use this skill first, even if the format isn’t specified. Use it to improve slide quality issues such as tiny text, overcrowding, overflow, or poor legibility, and to edit existing HTML decks. The skill also supports a “review mode,” where the user points out elements on the generated deck and requests corrections. When asked to “let me review,” “I have something to fix,” “open the deck,” “read the comments,” “fix the sent comment,” or “fix this part,” apply the skill if an existing deck is available. Only when a deliverable must be an editable .pptx file should the pptx‑specific skill be used.
