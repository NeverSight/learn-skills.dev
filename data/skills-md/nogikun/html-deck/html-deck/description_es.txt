Desde el material fuente (memorandos, artículos, documentos de investigación, actas de reuniones, URLs, solicitudes verbales), crea presentaciones en HTML, incluyendo diagramas como SVG y draw.io, y pruébalas en un lienzo fijo de 1600 × 900. Refina la legibilidad mediante un bucle de revisión con un sub‑agente de evaluación. Cuando se solicite “hacer diapositivas”, “material de presentación”, “puntos clave”, “material de propuesta”, “deck”, “diapositivas”, “presentación”, “convertir este documento en diapositivas” o “resumir para una presentación”, usa esta habilidad primero, incluso si no se especifica el formato. También se emplea para mejorar la calidad de las diapositivas—p. ej., corregir texto demasiado pequeño, demasiado comprimido, que se desborda o es difícil de leer—y para pulir presentaciones HTML existentes. La habilidad también incluye un “modo de revisión” en el que el usuario señala elementos de la presentación generada y solicita correcciones. Cuando se dice “déjame revisarla”, “hay algo que quiero arreglar”, “abre la presentación”, “lee el comentario”, “aplica el comentario que enviaste” o “corrige esta parte”, la habilidad lo gestiona siempre que exista una presentación previa. Sólo cuando se requiera entregar un archivo .pptx editable cambiamos a la habilidad PPTX.
