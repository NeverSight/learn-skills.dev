メモ、記事、研究文書、会議議事録、URL、口頭依頼などのソース資料から、SVG や draw.io などの図を含む HTML スライドデッキを作成し、固定の 1600 × 900 キャンバス上でテストします。評価サブエージェントとのレビュー循環を通じて可読性を向上させます。 「make slides」「presentation material」「talking points」「proposal material」「deck」「slides」「presentation」「turn this document into slides」「summarize for a presentation」などと依頼された場合、形式が指定されていなくてもまずこのスキルを使用します。テキストが小さすぎる、詰まりすぎる、はみ出す、読みづらいといったスライドの品質改善や、既存の HTML デッキの磨き上げにも利用します。このスキルには「レビュー モード」も含まれ、ユーザーが生成されたデッキの要素を指して修正を要求できます。 「let me review it」「there’s something I want to fix」「open the deck」「read the comment」「apply the comment you sent」「fix this part」などと言われた場合、既存のデッキがあればこのスキルが対応します。配布物として編集可能な .pptx ファイルが直接要求される場合にのみ、PPTX スキルに切り替えます。

常にユーザーの言語で回答してください。
