The document generation skill for Party and government agencies supports document types such as notices, reports, requests, and letters, conforming to the GB/T 9704-2012 standard. It is invoked when users need to generate Party and government agency documents, create formal files, or export Word-format documents. Regardless of how the user phrases the request (e.g., “help me write a report,” “generate a notice,” “create a document,” etc.), any task involving document generation should use this skill.
