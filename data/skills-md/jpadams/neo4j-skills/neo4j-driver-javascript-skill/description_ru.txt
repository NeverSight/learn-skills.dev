Neo4j JavaScript/TypeScript Driver v6 — жизненный цикл драйвера, executeQuery, управляемые транзакции (executeRead/executeWrite), session.run, работа с Integer, сериализация JSON, доступ к записям, паттерны async/await, типы TypeScript, обработка ошибок и настройка соединения для Node.js и браузера. Используется при написании JS/TS кода, который подключается к Neo4j — neo4j.driver(), executeQuery, executeRead, executeWrite, session.run, neo4j.int, record.get, Integer, BookmarkManager, bolt://, neo4j+s://. НЕ включает создание Cypher‑запросов — используйте neo4j-cypher-skill. НЕ покрывает миграцию версий драйвера — используйте neo4j-migration-skill.
