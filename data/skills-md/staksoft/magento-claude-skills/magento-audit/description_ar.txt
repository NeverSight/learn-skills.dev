تدقيق الأداء لمتجر Magento 2 / Mage‑OS / Adobe Commerce: فقدان ذاكرة التخزين المؤقت للصفحة الكاملة وتسربات cacheable="false"، تكوين Varnish/Redis، أوضاع الفهرسة وصحة الـ cron، زمن الاستجابة الأول (TTFB)، أحجام الحمولة، وCore Web Vitals. استخدم هذه المهارة كلما ذكر المستخدم أن متجر Magento بطيء، أو طلب تدقيق/مراجعة/فحص أداء المتجر، أو أشار إلى FPC أو معدل الضربات في الذاكرة المؤقتة، X‑Magento‑Cache‑Debug، Varnish لا يقوم بالتخزين المؤقت، ارتفاع TTFB، فهرس عالق أو فهرس في الوقت الحقيقي، مشاكل الـ cron، أو Core Web Vitals/درجات PageSpeed لموقع Magento أو Mage‑OS. تعمل من خلال رابط URL فقط، أو من قاعدة الشفرة فقط، أو كليهما. لكتابة أو إصلاح كود الوحدة، استخدم مهارة magento‑module بدلاً من ذلك.
