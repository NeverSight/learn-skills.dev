Audit de performance d’une vitrine Magento 2 / Mage‑OS / Adobe Commerce : manques de cache plein page et fuites cacheable="false", configuration Varnish/Redis, modes d’indexeur et santé du cron, TTFB, tailles des charges utiles et Core Web Vitals. Utilisez cette compétence chaque fois que l’utilisateur indique qu’une boutique Magento est lente, demande un audit/revue/vérification de la performance de la vitrine, mentionne le FPC ou le taux de hits du cache, X‑Magento‑Cache‑Debug, Varnish qui ne met pas en cache, un TTFB élevé, des indexeurs bloqués ou en temps réel, des problèmes de cron, ou les Core Web Vitals / scores PageSpeed pour un site Magento ou Mage‑OS. Fonctionne à partir d’une URL seule, d’une base de code seule ou des deux. Pour écrire ou corriger du code de module, utilisez la compétence magento‑module à la place.
