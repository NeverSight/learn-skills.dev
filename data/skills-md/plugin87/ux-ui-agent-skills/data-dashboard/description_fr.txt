Construisez un écran dense, riche en données – une console d’analyse ou un terminal de trading – avec de vrais graphiques issus de jetons : chandelier, volume, profondeur, aires empilées, cascade, nuage de points, matrice de corrélation, anneau, jauge, sparklines, cartes thermiques et carnets d’ordres.  
Utilisez‑le lorsque la demande est un tableau de bord, un terminal, une vue de surveillance, une console de données, ou tout écran dont la fonction est d’afficher de nombreux chiffres simultanément.  
Couvre la séquence de mise en page, la géométrie SVG, le contrat d’accessibilité par type de graphique, et les pièges de contraste qui n’apparaissent qu’en mode sombre.
