使用 `cx profiling` CLI 查询 Coralogix 连续剖析数据 —— 查找哪些服务使用的 CPU 或内存最多，服务拥有的剖析类型，剖析可以按哪些维度过滤，何时出现使用峰值以及是哪个 pod 或版本导致的，以及服务在 CPU 或内存上消耗的代码路径和函数（火焰图）。在用户询问“哪些服务使用的 CPU 最多”“内存消费最高的服务”“服务 X 正在把 CPU 用在什么上”“热点函数”“服务的火焰图”“为什么这个服务使用这么多 CPU”“按函数的内存分配”“pod 的 CPU 峰值”“哪个版本导致 CPU 增加”“连续剖析”“剖析数据”，或想要探索某个服务的剖析时使用此方法。对于查询服务或 pod 使用了多少 CPU 或内存以及是否已饱和，请改用 `cx-service-catalog`。请始终使用用户的语言作答。
