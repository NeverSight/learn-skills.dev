`cx profiling` CLI を使って Coralogix の継続的プロファイリングデータをクエリします — どのサービスが最も CPU やメモリを使用しているか、サービスが持つプロファイルタイプ、プロファイルのフィルタリング条件、使用量が急増したタイミングとそれを引き起こしたポッドやバージョン、サービスが CPU やメモリを費やしているコードパスや関数（フレームグラフ）を特定します。ユーザーが「どのサービスが最も CPU を使用しているか」「トップメモリ使用者」「サービス X が CPU を使っているのは何か」「ホット関数」「サービスのフレームグラフ」「なぜこのサービスが大量の CPU を使用しているのか」「関数別メモリ割り当て」「ポッド別 CPU スパイク」「どのバージョンが CPU を増加させたか」「継続的プロファイリング」「プロファイリングデータ」などを尋ねたり、サービスのプロファイルを探索したい場合に使用してください。サービスやポッドが使用している CPU やメモリの量、そして飽和状態かどうかを確認したい場合は、代わりに `cx-service-catalog` を使用してください。

常にユーザーの言語で回答してください。
