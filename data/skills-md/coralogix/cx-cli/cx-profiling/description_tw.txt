使用 `cx profiling` CLI 查詢 Coralogix 持續分析資料——找出哪些服務使用最多的 CPU 或記憶體、服務擁有哪些分析類型、可以依哪些條件篩選分析、使用量何時激增以及是哪個 pod 或版本造成的，還有服務在 CPU 或記憶體上花費的程式碼路徑與函式（火焰圖）。當使用者詢問「哪些服務使用最多 CPU」「記憶體使用量最高的服務」「服務 X 把 CPU 花在哪裡」「熱點函式」「服務的火焰圖」「為什麼這個服務使用這麼多 CPU」「函式的記憶體分配」「Pod 的 CPU 峰值」「哪個版本提升了 CPU」「持續分析」「分析資料」或想探索服務的分析時，請使用此方式。若要查詢服務或 pod 使用多少 CPU 或記憶體以及是否已達飽和，請改用 `cx-service-catalog`。
