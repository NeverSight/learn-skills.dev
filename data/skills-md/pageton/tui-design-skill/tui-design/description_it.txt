Progetta, crea, ridisegna, revisiona e fai il debug delle interfacce utente da terminale (TUI). Usalo quando l'utente vuole costruire o migliorare una TUI, convertire una CLI in un'app terminale interattiva, scegliere un framework TUI (Bubble Tea, Textual, Ratatui, Ink), progettare layout e combinazioni di tasti, gestire caratteri Unicode, caratteri a larghezza variabile o testo RTL, garantire la compatibilità con il terminale, scrivere test per le TUI o risolvere problemi di rendering nel terminale.
