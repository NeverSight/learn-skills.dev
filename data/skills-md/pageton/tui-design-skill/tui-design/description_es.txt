Diseña, construye, rediseña, revisa y depura interfaces de usuario de terminal (TUIs). Úsalo cuando el usuario quiera crear o mejorar una TUI, convertir una CLI en una aplicación interactiva de terminal, elegir un framework TUI (Bubble Tea, Textual, Ratatui, Ink), diseñar disposiciones y atajos de teclado, manejar Unicode/caracteres anchos/texto RTL, garantizar la compatibilidad del terminal, escribir pruebas para TUI o solucionar problemas de renderizado en el terminal.
