إنشاء مخططات وشروحات بصرية لملاحظات التعلم - اختيار مخططات Mermaid وقواعد الصياغة بالإضافة إلى إرشادات رسم SVG لملاحظات الدروس في خزانة markdown. يُستخدم عندما يحتاج المفهوم إلى صورة مثل التدفقات أو الهياكل الهرمية أو الخطوط الزمنية أو المقارنات أو التخطيطات المكانية، وعند إنشاء أو تضمين المخططات في ملاحظات الدروس.
