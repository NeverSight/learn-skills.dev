YouTube Data API v3を使用して、現在どのYouTubeのニッチで何がトレンドになっているかをスキャンします。急成長しているチャンネル、ブレイク中の動画、注目を集めつつあるトピックを見つけましょう。ユーザーが（1）現在自分のニッチで何がトレンドになっているかを確認したい場合、（2）異常な数の再生回数を獲得しているブレイクアウト動画を見つけたい場合、（3）異常な勢いのある急上昇中のチャンネルを発見したい場合、（4）トレンドがピークに達する前に把握したい場合、（5）リメイクすべき古いコンテンツを見つけたい場合、（6）ファーストムーバーの機会を特定したい場合に利用します。ユーザーのYouTube Data API v3キーが必要です。
