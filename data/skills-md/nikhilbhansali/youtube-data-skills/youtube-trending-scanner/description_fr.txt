Analysez ce qui est tendance actuellement dans n'importe quel créneau YouTube à l'aide de l'API YouTube Data v3. Identifiez les valeurs aberrantes en termes de vitesse, les chaînes en plein essor, les vidéos qui décollent et les sujets émergents. À utiliser lorsque les utilisateurs souhaitent (1) voir ce qui est tendance dans leur niche actuellement, (2) trouver des vidéos qui décollent et obtiennent un nombre de vues disproportionné, (3) découvrir des chaînes émergentes qui suscitent un intérêt inhabituel, (4) repérer les tendances avant qu'elles n'atteignent leur apogée, (5) trouver des contenus obsolètes à refaire, (6) identifier les opportunités de pionnier. Nécessite la clé YouTube Data API v3 de l'utilisateur.
