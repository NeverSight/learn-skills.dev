Cree interfaces frontend web distintivas y de calidad de producción con alta calidad de diseño. Se utiliza cuando el usuario solicita explícitamente construir o rediseñar sustancialmente un componente web, una página o una aplicación. Solo se aplica cuando la inspección del repositorio confirma que la superficie visual es una interfaz de usuario web representada por el navegador. No lo utilice para gráficos, sombreadores, juegos, interfaces de usuario de terminales u otros sistemas visuales no web nativos o renderizados por GPU. Ignore menciones y rastros incidentales.
