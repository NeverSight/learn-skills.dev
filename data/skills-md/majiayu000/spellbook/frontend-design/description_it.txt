Crea interfacce frontend Web distintive e di livello produttivo con un'elevata qualità di progettazione. Da utilizzare quando l'utente chiede esplicitamente di creare o riprogettare sostanzialmente un componente Web, una pagina o un'applicazione. Si applica solo quando l'ispezione del repository conferma che la superficie visiva è un'interfaccia utente Web renderizzata tramite browser. Non utilizzare per grafica nativa o con rendering GPU, shader, giochi, interfacce utente di terminali o altri sistemi visivi non web. Ignorare menzioni e tracce accidentali.
