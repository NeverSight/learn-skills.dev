Conseils neutres sur la plate-forme pour l'utilisation d'Open Computer Use, du serveur Open Source Computer Use MCP et de la CLI pour macOS, Linux et Windows. À utiliser lorsqu'un agent a besoin d'installer, de vérifier, de dépanner, de configurer ou d'exploiter Open Computer Use via son CLI natif, son serveur MCP stdio ou des appels d'outils d'utilisation directe de l'ordinateur.
