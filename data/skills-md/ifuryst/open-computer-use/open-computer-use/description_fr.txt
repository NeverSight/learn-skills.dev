Guide indépendant de la plateforme pour l’utilisation d’Open Computer Use, le serveur MCP open‑source et l’interface en ligne de commande pour macOS, Linux et Windows. À utiliser lorsqu’un agent doit installer, vérifier, dépanner, configurer ou exploiter Open Computer Use via son CLI natif, le serveur MCP stdio ou des appels directs aux outils Computer Use.
