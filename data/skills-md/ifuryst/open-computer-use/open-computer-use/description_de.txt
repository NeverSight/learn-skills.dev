Plattformneutrale Anleitung zur Verwendung von Open Computer Use, dem Open-Source-Computer Use MCP-Server und CLI für macOS, Linux und Windows. Wird verwendet, wenn ein Agent Open Computer Use über seine native CLI, seinen STDIO-MCP-Server oder direkte Aufrufe des Computernutzungs-Tools installieren, überprüfen, beheben, konfigurieren oder betreiben muss.
