Indicazioni neutrali rispetto alla piattaforma per l'utilizzo di Open Computer Use, il server MCP open-source e la CLI per macOS, Linux e Windows. Da utilizzare quando un agente deve installare, verificare, risolvere problemi, configurare o gestire Open Computer Use tramite la sua CLI nativa, il server MCP stdio o chiamate dirette agli strumenti di Computer Use.

Si prega di rispondere sempre nella lingua dell'utente.
