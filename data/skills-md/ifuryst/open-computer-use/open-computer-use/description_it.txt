Linee guida neutre rispetto alla piattaforma per l'uso di Open Computer Use, il server MCP e la CLI open-source per Computer Use su macOS, Linux e Windows. Da utilizzare quando un agente deve installare, verificare, risolvere problemi, configurare o gestire Open Computer Use tramite la sua CLI nativa, il server MCP stdio o chiamate dirette agli strumenti di Computer Use.
