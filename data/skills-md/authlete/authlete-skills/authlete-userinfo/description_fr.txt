Ajoutez le point de terminaison OIDC UserInfo (OpenID Connect Core §5.3) à un serveur basé sur Authlete. À utiliser lorsqu'un développeur souhaite un point de terminaison d'informations utilisateur ou pour renvoyer le profil d'un utilisateur/des réclamations par e-mail pour un jeton d'accès. Fonctionne avec la compétence de base authlete-oauth-server (qui comprend déjà une info utilisateur de base).
