Aggiungi l'endpoint OIDC UserInfo (OpenID Connect Core §5.3) a un server basato su Authlete. Usalo quando uno sviluppatore desidera un endpoint userinfo o restituire le rivendicazioni di profilo/email dell'utente per un token di accesso. Funziona con la skill di base authlete‑oauth‑server (che include già un userinfo di base).

Rispondi sempre nella lingua dell'utente.
