Agregue el punto de conexión OIDC UserInfo (OpenID Connect Core §5.3) a un servidor basado en Authlete. Se utiliza cuando un desarrollador quiere un punto final de información de usuario o para devolver las reclamaciones de perfil/correo electrónico de un usuario para un token de acceso. Funciona con la habilidad base authlete-oauth-server (que ya incluye una información de usuario básica).
