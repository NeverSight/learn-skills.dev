Aggiungi le Richieste di Autorizzazione Inviate (PAR, RFC 9126) a un server OAuth/OIDC basato su Authlete. Usalo quando uno sviluppatore vuole PAR, un endpoint di autorizzazione push, `request_uri` o l’integrità della richiesta FAPI. Funziona con la skill di base authlete‑oauth‑server (Go, Ruby o TypeScript).

Per favore rispondi sempre nella lingua dell'utente.
