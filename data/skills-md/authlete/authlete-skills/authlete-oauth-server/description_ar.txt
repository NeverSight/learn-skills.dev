يولد خادم تفويض OAuth 2.0 / OpenID Connect بسيطًا وكاملاً على Authlete — نقاط النهاية OAuth/OIDC بالإضافة إلى تسجيل دخول وتفويض أساسي مدمج — بلغة تتوفر لها حزمة SDK الرسمية من Authlete 3.0 (Go أو Ruby أو TypeScript حاليًا؛ وسيُضاف C# لاحقًا). استخدمه عند بناء أو إنشاء أو توليد خادم OAuth، أو خادم تفويض، أو موفر OIDC، أو خلفية مصادقة Authlete.
