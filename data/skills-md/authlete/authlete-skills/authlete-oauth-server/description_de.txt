Generiert einen einfachen, vollständigen OAuth 2.0 / OpenID Connect-Autorisierungsserver auf Authlete — die OAuth/OIDC-Endpunkte plus integrierte grundlegende Anmeldung und Zustimmung — in einer Sprache mit einem offiziellen Authlete 3.0 SDK (Go, Ruby oder TypeScript heute; C# kommt). Wird beim Erstellen, Gerüsten oder Generieren eines OAuth-Servers, Autorisierungsservers, OIDC-Anbieters oder Authlete-Authentifizierungs-Backends verwendet.
