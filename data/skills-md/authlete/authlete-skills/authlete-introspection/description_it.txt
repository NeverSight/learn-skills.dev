Aggiungi l’introspezione dei token RFC 7662 a un server OAuth/OIDC basato su Authlete. Usalo quando uno sviluppatore vuole un endpoint di introspezione, o un server di risorse che deve verificare se un token di accesso è valido e leggere i relativi metadati. Funziona con la skill base authlete‑oauth‑server.
