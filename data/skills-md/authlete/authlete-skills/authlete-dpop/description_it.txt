Aggiungi DPoP (token vincolati al mittente, RFC 9449) a un server OAuth/OIDC basato su Authlete. Usalo quando uno sviluppatore vuole DPoP, prova di possesso, token legati a `jkt` o un flusso DPoP‑Nonce. È un componente trasversale che si sovrappone agli endpoint esistenti. Funziona con la skill di base authlete‑oauth‑server.
