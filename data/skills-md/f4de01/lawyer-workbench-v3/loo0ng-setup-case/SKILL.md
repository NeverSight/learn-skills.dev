# 起手

一案一次，在案件工作区里跑：工作区就是会话当前目录，`图.json` 是它的身份标记（ADR-0007）。**前置是当前目录没有 `图.json`**：有就拒绝，告诉律师这个目录已经是案件工作区，要改图的构成调用 skill "loo0ng-graph"，要另起一案换一个空目录。脚本自己也守这一条。

CLI 是本目录的 `scripts/setup.py`（Python 标准库，零依赖，不 import 图引擎；写图经 skill "loo0ng-graph" 的引擎子进程）。退出码 0 完成；1 拒绝（原因在 stderr，工作区不留半截）；2 用法错。`--help` 是参数的权威。

## 七步，中间只有一个确认点

顺序是死的：**建目录 → 起手图 → 归档收件箱 → 指南非空则跑雏形 → 回显起手清单 → 律师一句话 → 写图**。起手清单是这一路上唯一的确认点（ADR-0008），前面五步不问律师，后面写图不再问第二遍。

### 1–2. 六格与起手图（一条命令）

起手图三选一是人的决定，不受惰性约束（ADR-0004）。律师那句话里说了就照办；没说清就只问这一件，给三个选项，别替他选：

| 律师要 | 命令 |
| --- | --- |
| 整份领域图（本领域全套模块与节点，最常见） | `init --full --domain <领域目录>` |
| 空图，自己一句句长 | `init --empty --domain <领域目录>`（没有领域目录时用 `--name <领域名>`） |
| 开发者交付的定制图 | `init --from <定制图.json> [--domain <领域目录>]` |

```
python <本目录>/scripts/setup.py init --full --domain <领域目录>
```

领域目录在 skill "loo0ng-domain" 的 `assets/<领域名>/`（本 skill 的兄弟目录）：起手时工作区还没有 `AGENTS.md`，路径只能从那里取，取绝对路径。

一条命令落下六格、图与两份视图、起手图上挂到的官方模板原件、工作区指针块，回显逐条说明。官方模板原件住领域目录，起手时按图上挂到的那几件拷进 `模板/官方/`（出件读的是工作区里这一份，见 skill "loo0ng-domain" 与 skill "loo0ng-to-docx" 的正文）；图上没挂的不拷，领域目录里缺原件只报不拒。

```
<案件工作区>/
├── 图.json  图视图.md  图视图.json
├── 收件箱/
├── 材料/律师陈述/
├── 指南/
├── 模板/官方/  模板/生成/
└── 文书/                     ← <节点标题>/ 出件时才建
```

指针块照 [references/工作区AGENTS.md](references/工作区AGENTS.md) 落成工作区根的 `AGENTS.md`（Codex 读）与一行 `@AGENTS.md` 的 `CLAUDE.md`（Claude Code 读），四项：领域名与领域目录绝对路径、图与视图文件名、入口名、「本工作区对 skill 仓库只读」。它由起手图三选一机械推出，不加确认点，之后没有任何 skill 往里写；引擎与别的 skill 要领域目录路径都从这里读。

引擎拒了就一格不建、一个字不写：把拒写的原话照读给律师，别自己改 JSON 绕过去。

### 3. 归档收件箱

调用 skill "loo0ng-filing"：先 `archive.py list`，逐件判去向（本案事实来源原件→`材料`；本案适用的官方要求文件→`指南`；官方发布的空白件→`模板/官方`；自己或所里做的空白件→`模板/生成`），三格都无正向证据的留在收件箱并说一句为什么拿不准。律师不逐件参与。收件箱本来就是空的，这一步不必做也不必回显。

### 4. 指南非空则跑雏形

归档之后 `指南/` 非空，调用 skill "loo0ng-domain"：整读每一份指南，写雏形文件到 `%TEMP%`（不落进工作区），跑 `sketch.py check` 判重回显。**只 `check` 不 `apply`**：这一步图一字不动。`指南/` 是空的就没有雏形，直接到下一步。

### 5. 起手清单（唯一的确认点）

雏形与既有成品的建议登记合成一张表，一次回显、一句话拍板（ADR-0008）。既有成品 = 归档进 `材料/` 的、律师起手前就已经写成并对得上某个节点的本案文书；对不上任何节点的不进清单，只是普通材料。

```markdown
## 起手清单

**要在图上建的（从 指南/ 提出，来源：<指南文件名>）**

| # | 模块 | 节点 | 空白模板 | 判重 |
| - | ---- | ---- | -------- | ---- |
| 1 | 越冬（新模块） | 覆膜 | 官方:覆膜记录.docx | 新 |
| 2 | 养护 | 施追肥 | 无 | 新 |

**建议登记为已生成的既有成品（来源记律师，不是确认）**

| # | 文件 | 登记到节点 | 登记后状态 |
| - | ---- | ---------- | ---------- |
| 3 | 材料/旧的下种记录.md | 下种 | 已生成（未确认） |

**待定**（雏形里与图里相似但不同名的，律师定是同一个还是新的）

| # | 雏形里的 | 图里已有的 |
| - | -------- | ---------- |
| 4 | 浇灌 | 浇水 |

一句话拍板整张：可以是「都按建议登记」「照这个建」「第 3 条不要」。说了才写图。
```

清单之外不加自己的判断，也不先写再问。没有雏形也没有既有成品就不出清单，直接收尾。

### 6–7. 律师一句话之后才写图

- 雏形：`sketch.py apply`（待定按律师的话处理：是同一个就从雏形文件里删掉那条，是新的就 `--as-new <标题>`；有一条待定没定 `apply` 就整个拒、一字不写）。
- 既有成品：一件一条

  ```
  python <本目录>/scripts/setup.py register --node <节点标题> --doc 材料/<归档后的相对路径> --words "<律师那句话>"
  ```

  它按 [references/既有成品审查报告.md](references/既有成品审查报告.md) 写一份审查报告（每一版文书必有一份），再经引擎追加一条来源为律师的生成条目。

**没有任何节点被自动确认。** 确认只能由律师在读过审查报告后一句话发起（ADR-0002）；起手登记的这一版本工作台没参与写作、没跑门禁，审查报告里照实写着这句。律师说「这份就这样了」是确认，那是 skill "loo0ng-doit" 的事，不在起手里做。

## 收尾三段

同别的入口一个形状：

1. **落了什么**：五行，一行一样，**少一行就是没照做**（不是「说得简略」）；每行起头那几个字原样照抄，件数与节点名逐个写实，没有的那一样写「0 件」而不是整行不写：

   > 六格与图：六格建齐，`图.json`、`图视图.md`、`图视图.json` 三份都落了盘。
   > 起手图：<三选一是哪一种>，<几> 个模块 <几> 个节点。
   > 归档：材料 <几> 件、律师陈述 <几> 件、指南 <几> 件、官方模板 <几> 件、生成模板 <几> 件，留在收件箱 <几> 件（逐件说一句为什么留）。
   > 雏形：写进图 <几> 条，逐条点名。
   > 既有成品：登记 <几> 件，逐件点名，都是已生成未确认。

   发出去之前数一遍这五行在不在。只报「新增了几个节点、归档了几件」不算这一段。

2. **你现在该拍板什么**：起手不产生要拍板的东西；有既有成品登记的，说明它们是已生成未确认，要确认得读过一版审查报告后在办节点的对话里说。
3. **下一句该打什么**：`loo0ng-doit <节点标题>` 开一个新对话办第一个节点；不知道从哪开始就打 `ask-loo0ng`。

## 与邻居的边界

- 归档搬运与律师陈述归 skill "loo0ng-filing"；本 skill 只在第 3 步调它，不自己搬文件。
- 雏形与领域目录归 skill "loo0ng-domain"；本 skill 只在第 4、6 步调它，不自己判重。
- 除起手图与既有成品登记外的一切写图归 skill "loo0ng-graph"；本 skill 的两条写入也都经它的引擎子进程。
- 出一版文书与拍板归 skill "loo0ng-doit"；起手不出件、不确认。
- 本 skill 不含领域语义：换一个领域只换 `--domain` 指向的目录。
