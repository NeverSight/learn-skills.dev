# 归档与陈述

案件工作区就是会话当前目录，`图.json` 是身份标记（ADR-0007）。本 skill 持两个 CLI（Python 标准库，零依赖，互不 import，也不 import 图引擎）：

- `scripts/archive.py`：只搬不写。把收件箱里的东西按相对路径原样搬到四格之一。
- `scripts/statement.py`：只写不搬。把律师在对话里说的一句话落成 `材料/律师陈述/` 下的一个文件。

两个脚本都只在有 `图.json` 的目录里工作，退出码 0 落盘、1 拒绝、2 用法错。拒绝时落档什么都不写；归档整条拒绝（越界、不存在、去向不合规则）时一件不搬，只有同名那种是那件不搬、其余照搬，回显里逐件说明。`--help` 是参数的权威。陈述文件的字段与样例见 [references/格式.md](references/格式.md)。

## 归档

判断归模型，搬运归脚本。四格的判据：

| 这件东西是 | 去向 |
| --- | --- |
| 本案的事实来源原件（合同、账、函、笔录、照片、压缩包） | `材料` |
| 本案适用的官方要求文件（法院的通知、指引、清单） | `指南` |
| 官方发布的空白件（表格、格式文本） | `模板/官方` |
| 自己或所里做的空白件 | `模板/生成` |
| 三格都无正向证据 | 留在收件箱，回显时说一句为什么拿不准 |

三个进入点，律师都不逐件参与：

1. 起手末尾：先 `list`，逐件判去向，搬完回显。
2. 出一版开场：同上，先清收件箱再读材料。
3. 律师一句话：「把收件箱里的某文件归到材料」，照说的搬。

```
python <本目录>/scripts/archive.py list
python <本目录>/scripts/archive.py move --to 材料|指南|模板/官方|模板/生成 <收件箱内相对路径>...
```

脚本自己守的规则，拒了就照实转告：不改名；不覆盖，同名已存在则那件不搬、留在收件箱并报出；子目录的相对路径原样保持，也可整个目录搬；压缩包与照片只能原样归 `材料`，不解压不识图；`..`、绝对路径、收件箱之外一律拒绝，且一件都不搬；永不写入 `材料/律师陈述/`。搬空的收件箱子目录顺手清掉。归档不登记、不算指纹、不去重、不写图。律师自己写的 `.md` 拷进收件箱，经归档只是普通材料，没有性质；要成为陈述得由律师说一句。

## 陈述

**不在盘上的事实不是材料。** 律师在对话里给出、盘上没有的事实（案号、日期、金额、某人的说法、对某个问题的选择），agent 先落成陈述、回显一行，再据此生成或审查。理由：审查报告的依据必须可引，下一回合是新对话看不到这一句，材料只能整读文件。落档瞬时完成，不是确认点，不先出示再问。

一条陈述一个文件，落盘后只读。性质三档，由模型从律师那句话判：

| 性质 | 含义 | 命令要点 |
| --- | --- | --- |
| 直接陈述 | 律师本人是权威来源的事实 | 不带 `--source` |
| 转述 | 律师转录他人或他处，来源强度低一档 | `--source` 必填（谁说的、哪份东西） |
| 裁定 | 律师对本案某个问题的选择，不是事实 | `--question` 必填，正文固定问题与裁定两段 |

```
python <本目录>/scripts/statement.py --nature 直接陈述|转述|裁定 --title <标题> --words "<原话>"
    [--source <转述来源>] [--node <节点标题>]... [--reply <审查报告相对路径>] [--supersedes <旧陈述文件名>]
    [--item 项目=值]... [--question <问题>]
```

- **标题由 agent 拟**，不超 20 字、不含案件人名、只用汉字字母数字（无标点无空格）；律师不起题。
- **原话逐字**。`--words` 里是律师那句，不润色不补词；事件本身何时发生写在原话里，录入时间一律取落档时刻（`--at` 只给开发侧测试，办案里不传）。
- **一句话带多个值**（几个日期、几笔金额）时加 `--item 项目=值` 逐个列出，脚本写成 `## 整理` 表并标明是 agent 整理；单值不写整理。
- **节点**用图内唯一标题，可多个可空；**回应**在答审查报告的待裁定项时指向那份报告的相对路径。
- **改口是整条取代**：新陈述 `--supersedes <旧文件名>`，旧文件一字不动；只改一个值时也整条取代，把旧陈述其余现行值抄进新陈述的 `--item`，原话仍只是律师新说的那句。现行陈述 = 未被任何文件指为取代目标的那些，读头部即得，不设清单。
- **不是陈述的**：确认与不适用是图里的条目，调用 skill "loo0ng-graph"；本案具体日期是陈述，时限句只住领域图。

脚本自己守的：文件名 `YYYYMMDD-HHMMSS-<标题>.md`；六字段齐全且顺序固定；转述缺来源拒绝；取代目标必须已在 `材料/律师陈述/`；同名拒绝覆盖；写完设只读。拒了就照实转告，脚本的回显那一行照读给律师。

## 与邻居的边界

- 归档与陈述是两个方向相反的动作：归档只搬不写，陈述只写不搬；归档永不产生陈述。
- 两者都不动 `图.json`；要往图里写条目调用 skill "loo0ng-graph"。
- 归档之后若 `指南/` 非空，从指南长雏形是 skill "loo0ng-domain" 的事。
- 审查报告引用陈述的格式（`[律师陈述·转述] 材料/律师陈述/<文件名>：<项目> <值>`）住在出件 skill，这里只保证文件可引。
