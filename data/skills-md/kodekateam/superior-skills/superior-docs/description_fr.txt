Créer, reconstruire, synchroniser ou enregistrer automatiquement une documentation durable du référentiel à partir du code actuel, de la configuration, des tests, de la documentation existante et de l’historique Git. Utiliser pour le contexte du projet, l’architecture, les décisions, les enregistrements de changements d’implémentation, les calendriers, les guides de construction et de distribution, les transferts de maintenance ou la continuité entre les sessions. Après un travail d’implémentation matériel vérifié, enregistrer le résultat par défaut, sauf si l’utilisateur se désinscrit explicitement. Ne pas utiliser pour les commentaires incidentels ou les modifications non matérielles.
