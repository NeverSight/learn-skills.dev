Revisa un cambio de código, diff, commit, rama o pull request en busca de defectos accionables, regresiones, riesgos de seguridad, rupturas de compatibilidad y verificaciones faltantes. Utilízalo cuando la revisión de código sea el resultado principal solicitado. Mantén la revisión en modo solo lectura a menos que el usuario solicite explícitamente implementar correcciones; no lo uses como sustituto de la implementación o de una auditoría visual especializada.
