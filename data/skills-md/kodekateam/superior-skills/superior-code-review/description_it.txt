Revisiona una modifica di codice, un diff, un commit, un branch o una pull request per individuare difetti correggibili, regressioni, rischi di sicurezza, rotture di compatibilità e verifiche mancanti. Usala quando la revisione del codice è il risultato principale richiesto. Mantieni la revisione in sola lettura a meno che l'utente richieda esplicitamente di implementare correzioni; non usarla come sostituto dell'implementazione o di un audit visivo specializzato. Rispondi sempre nella lingua dell'utente.
