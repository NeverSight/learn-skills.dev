Überprüfen Sie eine Code‑Änderung, einen Diff, Commit, Branch oder Pull Request auf umsetzbare Defekte, Regressionen, Sicherheitsrisiken, Kompatibilitätsbrüche und fehlende Verifizierung. Verwenden Sie dies, wenn Code‑Review das primäre gewünschte Ergebnis ist. Halten Sie die Überprüfung schreibgeschützt, es sei denn, der Benutzer bittet ausdrücklich um die Umsetzung von Korrekturen; nutzen Sie sie nicht als Ersatz für die Implementierung oder eine spezialisierte visuelle Prüfung.
