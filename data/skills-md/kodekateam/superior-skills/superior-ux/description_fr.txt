Concevoir ou examiner les expériences produit à travers les objectifs utilisateur, les parcours, l’architecture de l’information, les flux de tâches, les modèles d’interaction, les retours, la récupération et la continuité entre les écrans. Utiliser lorsque la question principale est de savoir comment les utilisateurs comprennent et accomplissent un objectif à travers les étapes ou les surfaces. Ne pas utiliser pour le style visuel, la logique uniquement d’implémentation ou les affirmations de recherche utilisateur non étayées.
