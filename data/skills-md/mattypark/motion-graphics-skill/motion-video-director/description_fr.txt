Planifier, diriger et produire des graphiques animés 2D/3D générés par code ainsi que des vidéos montées (reels, accroches, explications SaaS/produit, montages en face caméra) sur la machine locale de l'utilisateur via tout agent de codage disposant d'un terminal et d'un accès aux fichiers (Claude Code, Codex, Cursor, Claude Desktop, agents VS Code, etc.). Flux de travail : expliquer le processus → l'utilisateur fournit des références + le scénario → rédiger un script de voix off prêt à être collé pour ElevenLabs → l'utilisateur génère et renvoie le MP3 → construire, prévisualiser, rendre. Utilise Canvas/SVG/p5.brush/Three.js/GSAP rendus dans Chrome sans tête, Motion Canvas/Revideo, ffmpeg, petits modèles d'IA locaux (découpage, transcription), ainsi que LottieFiles, Freesound, Pexels/Pixabay, Firecrawl et les MCP d'ElevenLabs, et le MCP Playwright pour parcourir visuellement n'importe quel site web (Pinterest, Behance, Dribbble, sites de marques) et récupérer lui‑même les assets image/vidéo. Utiliser lorsque l'utilisateur demande de créer, éditer, animer, ajouter des légendes, voix ou conception sonore à une vidéo.
