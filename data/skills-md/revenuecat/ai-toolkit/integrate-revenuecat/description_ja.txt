エンドツーエンドのRevenueCat統合 — RevenueCat MCP または `rc` CLI（プロジェクト、アプリ、パブリックAPIキー）を使用してダッシュボード側を設定し、アプリにPurchases SDK をインストール／設定します。ユーザーがRevenueCatの追加、RevenueCatの連携、アプリへのサブスクリプションやアプリ内課金の追加、Purchases の統合、RevenueCat SDK のインストール、RevenueCat API キーの設定、起動時の Purchases 設定、または iOS、Android、Kotlin Multiplatform、Flutter、React Native での新規 RevenueCat 統合の構築を求めたときに使用してください。
