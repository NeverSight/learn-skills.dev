Muestra un paywall de RevenueCat dentro de una aplicación utilizando el SDK RevenueCatUI. Úsalo cuando el usuario solicite añadir un paywall, muestra un paywall de RevenueCat, presenta PaywallView, integra RevenueCatUI, protege una pantalla premium con un paywall, lanza PaywallActivity, llama a presentPaywall o presentPaywallIfNeeded, o muestra la UI del paywall configurada en el dashboard en iOS, Android, Kotlin Multiplatform, Flutter o React Native. Para crear, editar, evaluar o auditar el propio paywall del dashboard, usa revenuecat‑paywall‑design.
