Affichez un paywall RevenueCat dans une application à l'aide du SDK RevenueCatUI. Utilisez-le lorsque l'utilisateur demande à ajouter un paywall, affichez un paywall RevenueCat, présentez PaywallView, intégrez RevenueCatUI, protégez un écran premium avec un paywall, lancez PaywallActivity, appelez presentPaywall ou presentPaywallIfNeeded, ou affichez l’interface paywall configurée via le tableau de bord sur iOS, Android, Kotlin Multiplatform, Flutter ou React Native. Pour créer, modifier, évaluer ou auditer le paywall du tableau de bord lui‑même, utilisez revenuecat‑paywall‑design.  

Veuillez toujours répondre dans la langue de l'utilisateur.
