Utilizza questa competenza durante il test di un'integrazione Android di RevenueCat. Copre il RevenueCat Test Store (prefisso della chiave API test_, nella finestra di dialogo Scelta Successo/Fallito/Annulla), test unitari basati su mockk con un wrapper di interfaccia attorno agli Acquisti e un pattern CI di GitHub Actions. Evita la sandbox di Google Play per l'iterazione dei test quotidiani.
