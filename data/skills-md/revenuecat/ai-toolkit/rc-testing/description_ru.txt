Используйте этот навык при тестировании интеграции RevenueCat с Android. Охватывает хранилище тестов RevenueCat (префикс ключа API test_, в диалоговом окне выбора «Успех/Неудача/Отмена»), модульное тестирование на основе макета с интерфейсной оболочкой для покупок и шаблон GitHub Actions CI. Избегает песочницы Google Play для ежедневных итераций тестирования.
