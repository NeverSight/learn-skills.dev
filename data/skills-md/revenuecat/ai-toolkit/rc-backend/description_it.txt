Utilizza questa competenza quando il tuo backend deve leggere o aggiornare lo stato di RevenueCat su Android. Copre l'API REST RevenueCat (endpoint abbonati v1, concessione/revoca di diritti, attributi), l'utilizzo delle chiavi API SDK segrete e pubbliche e il motivo per cui non crei un backend di verifica delle ricevute con RevenueCat.
