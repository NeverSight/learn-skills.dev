Используйте этот навык, когда вашему серверу необходимо прочитать или обновить состояние RevenueCat на Android. Описывается REST API RevenueCat (конечная точка подписчиков версии 1, предоставление или отзыв прав, атрибуты), использование секретных и общедоступных ключей API SDK, а также причины, по которым вы не создаете серверную часть проверки квитанций с помощью RevenueCat.
