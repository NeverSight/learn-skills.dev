استخدم هذه المهارة عندما تحتاج الواجهة الخلفية لديك إلى قراءة حالة RevenueCat أو تحديثها على Android. يغطي RevenueCat REST API (نقطة نهاية المشتركين v1، واستحقاقات المنح/الإلغاء، والسمات)، واستخدام مفتاح SDK API السري مقابل الاستخدام العام، وسبب عدم إنشاء واجهة خلفية للتحقق من الاستلام باستخدام RevenueCat.
