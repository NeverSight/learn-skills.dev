Analiza las imágenes de referencia proporcionadas por el usuario y realiza ingeniería inversa de indicaciones de alta fidelidad para la generación de imágenes mediante IA. Utilízalo cuando el usuario pida recrear, imitar, realizar ingeniería inversa o extraer indicaciones de fotografías, ilustraciones, renderizados 3D, productos, personajes, paisajes, tipografías, logotipos, carteles u otras referencias visuales. No lo uses para solicitudes que solo requieran OCR o una descripción de imagen normal.
