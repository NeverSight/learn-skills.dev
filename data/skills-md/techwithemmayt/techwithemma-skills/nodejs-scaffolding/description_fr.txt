Générez ou étendez des projets TypeScript Express orientés production avec une architecture src fixe, une gestion d’erreurs partagée, des en‑têtes de sécurité, une limitation du débit, une journalisation console, une fermeture propre, une authentification optionnelle par cookie JWT avec Passport, et une configuration MongoDB en option. Utilisez‑le lors de la création d’une API Node.js, de l’ajout d’une authentification à une API ou de la configuration de MongoDB pour celle‑ci.
