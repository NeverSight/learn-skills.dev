Используйте при написании оперативной документации — runbook’ов, руководств по настройке, процедур выпуска, руководств по миграции, руководств по выводу из эксплуатации, записей по устранению неполадок или любой упорядоченной процедуры, которую кто‑то будет выполнять под давлением времени. Закодирует скелет runbook’а, легенду рисков, формат устранения неполадок, начинающийся с симптомов, и правила руководства по миграции (таблица соответствий, обязательный откат, даты вывода из эксплуатации, встроенный срок действия). Применяйте всякий раз, когда кто‑то будет исполнять текст, даже если он называется «руководство» или «заметки по настройке».
