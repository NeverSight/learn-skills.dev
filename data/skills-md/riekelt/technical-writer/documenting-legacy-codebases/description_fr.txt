Utilisez‑le lorsqu’il faut documenter une base de code existante dont la documentation est manquante, périmée ou peu fiable — un système hérité, une application legacy, un dépôt où la documentation traîne — ou lors de la reconstruction d’un arbre de documentation à partir du code, ou quand quelqu’un demande ce que fait réellement un système. Il encode l’inventaire « survey‑first », la hiérarchie des preuves côté rédacteur, les règles profondeur‑par‑surface, le test de refactorisation, les preuves vivant‑ou‑mort, la division particularités‑et‑constatations, le registre de couverture, la campagne parallèle et le squelette de l’arbre de documentation. Utilisez‑le chaque fois que la documentation doit être reconstruit à partir du code plutôt que rédigée en même temps qu’un changement.
