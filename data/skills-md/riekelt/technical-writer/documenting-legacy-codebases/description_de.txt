Verwenden Sie es, wenn Sie eine bestehende Codebasis dokumentieren, deren Dokumentation fehlt, veraltet oder unzuverlässig ist – ein geerbtes System, eine Altanwendung, ein Repository, in dem die Docs liegen – oder wenn Sie einen Dokumentationsbaum neu am Code ausrichten oder wenn jemand fragt, was ein System tatsächlich tut. Es kodiert das Survey‑First‑Inventar, die Evidenz‑Hierarchie des Autors, die Depth‑per‑Surface‑Regeln, den Refactor‑Test, Dead‑or‑Alive‑Nachweise, die Aufteilung in Eigenheiten und Befunde, das Coverage‑Ledger, die parallele Kampagne und das Skelett des Docs‑Baums. Verwenden Sie es immer dann, wenn die Dokumentation aus dem Code rekonstruiert werden muss, statt sie parallel zu einer Änderung zu schreiben.
