استخدم عندما تقوم بتوثيق واجهة برمجة تطبيقات HTTP، أو حمولات الرسائل، أو عقود الطوابير، أو DTOs، أو صيغ الملفات، أو الويب هوكس — أو عند كتابة مرجع الـ API لحملة قديمة، أو عندما يظل المتصلون يسألون ما معنى حقل ما أو ما هي الأخطاء التي تُرجعها نقطة النهاية. يشفّر المستويات الأربعة للتفصيل، كتالوج DTO‑الأول، أنواع الأسلاك مع مرساة المصدر، قاعدة “منزل واحد” للمواصفات المولَّدة، ودلالات الإغفال مقابل القيم الفارغة. استخدمه كلما احتاج واجهة آلة إلى توثيق لمستدعينيها، حتى وإن لم يقل أحد “توثيق API”.
