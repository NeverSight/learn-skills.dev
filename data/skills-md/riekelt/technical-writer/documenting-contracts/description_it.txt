Usa quando documenti un'API HTTP, i payload dei messaggi, i contratti delle code, i DTO, i formati di file o i webhook – o quando scrivi il riferimento API di una campagna legacy, o quando gli chiamanti continuano a chiedere cosa significhi un campo o quali errori restituisca un endpoint. Codifica i quattro livelli di dettaglio, il catalogo DTO‑first, i tipi di trasmissione con ancore di origine, la regola one‑home della specifica generata e la semantica omesso‑versus‑null. Usa ogni volta che un'interfaccia macchina necessita di essere documentata per i suoi chiamanti, anche se nessuno dice “documentazione API”.
