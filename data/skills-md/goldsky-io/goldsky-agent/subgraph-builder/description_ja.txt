Goldsky Subgraph を構築・作成・デプロイする——オンチェーンデータ上にホストされた GraphQL API を提供します。サブグラフの作成、スキャフォールド、記述、デプロイ、スキーマ／エンティティの設計、AssemblyScript マッピングハンドラの記述または修正、subgraph.yaml の設定（ハンドラ、テンプレート、ABI からのインスタント／ノーコード生成）、GraphQL エンドポイント、タグ、Webhook の設定、遅いサブグラフの最適化（eth_calls、イミュータブルエンティティ）やサブグラフの一時停止／再開が必要なときに使用します。トリガーは「サブグラフの構築／デプロイ／スキャフォールド」「マッピングの記述」「スキーマの設計」「subgraph.yaml」「インスタントサブグラフ」「複数サブグラフの結合／合成／マージ」「クロスチェーンサブグラフ」「インデックス速度の最適化」「eth_calls が多すぎる」「サブグラフの一時停止／再開」などです。サブグラフが失敗、スタック、エラー、デプロイできない場合は /subgraph-doctor を使用してください（健全なサブグラフの最適化はここではなく doctor ではありません）。The Graph からの移行には /subgraph-migrate を、GraphQL を使わずに生チェーンデータを DB にストリーミングしたい場合は /turbo-builder を使用してください。
