Construye, escribe y despliega Subgraphs de Goldsky — APIs GraphQL alojadas sobre datos on‑chain. Úsalo cuando el usuario quiera crear, estructurar, escribir o desplegar un subgraph; diseñar un esquema/entidades; escribir o corregir manejadores de mapeo en AssemblyScript; configurar subgraph.yaml (manejadores, plantillas, instantáneo/sin código a partir de ABI); configurar puntos finales GraphQL, etiquetas o webhooks; optimizar un subgraph lento (eth_calls, entidades inmutables); o pausar/reanudar un subgraph. Se activa con: “construir/desplegar/estructurar un subgraph”, “escribir un mapeo”, “diseñar un esquema”, “subgraph.yaml”, “subgraph instantáneo”, “combinar/componer/fusionar varios subgraphs”, “subgraph cross‑chain”, “optimizar velocidad de indexado”, “demasiados eth_calls”, “pausar/reanudar subgraph”. Para un subgraph que está fallando, atascado, con errores o que no se despliega, utiliza /subgraph-doctor (optimizar un subgraph saludable pertenece aquí, no al doctor). Para migrar fuera de The Graph, usa /subgraph-migrate. Para transmitir datos crudos de la cadena a una base de datos sin GraphQL, usa /turbo-builder.
