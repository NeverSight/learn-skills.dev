بناء، تأليف، ونشر Goldsky Subgraphs — واجهات برمجة تطبيقات GraphQL مستضافة للبيانات على السلسلة. يُستخدم عندما يرغب المستخدم في إنشاء، أو إعداد هيكلي، أو كتابة، أو نشر subgraph؛ تصميم مخطط/كيانات؛ كتابة أو إصلاح معالجات التعيين بـ AssemblyScript؛ تكوين subgraph.yaml (المعالجات، القوالب، subgraph فوري/بدون كود من ABI)؛ إعداد نقاط النهاية GraphQL، العلامات، أو webhooks؛ تحسين subgraph بطيء (eth_calls، الكيانات غير القابلة للتغيير)؛ أو إيقاف/استئناف subgraph. يتم التحفيز على: "بناء/نشر/إعداد هيكلي لـ subgraph"، "كتابة تعيين"، "تصميم مخطط"، "subgraph.yaml"، "subgraph فوري"، "دمج/تكوين/دمج عدة subgraphs"، "subgraph عبر سلاسل متعددة"، "تحسين سرعة الفهرسة"، "عدد كبير من eth_calls"، "إيقاف/استئناف subgraph". بالنسبة لـ subgraph الذي يفشل، أو يتعطل، أو ينتج أخطاء، أو لا يمكن نشره، استخدم /subgraph-doctor (تحسين subgraph سليم يندرج هنا، وليس في doctor). للترحيل بعيدًا عن The Graph، استخدم /subgraph-migrate. لبث بيانات السلسلة الخام إلى قاعدة بيانات بدون GraphQL، استخدم /turbo-builder. يرجى دائمًا الرد بلغة المستخدم.
