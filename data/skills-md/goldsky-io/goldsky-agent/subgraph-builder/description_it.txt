Costruisci, scrivi e distribuisci i Goldsky Subgraph — API GraphQL ospitate su dati on‑chain. Usa quando l’utente vuole creare, scaffoldare, scrivere o distribuire un subgraph; progettare uno schema/entità; scrivere o correggere handler di mapping AssemblyScript; configurare il file subgraph.yaml (handler, template, subgraph istantaneo/senza codice da ABI); impostare endpoint GraphQL, tag o webhook; ottimizzare un subgraph lento (eth_calls, entità immutabili); o mettere in pausa/riprendere un subgraph. Trigger: “costruisci/distribuisci/scaffold un subgraph”, “scrivi un mapping”, “progetta uno schema”, “subgraph.yaml”, “subgraph istantaneo”, “combina/componi/unisci più subgraph”, “subgraph cross‑chain”, “ottimizza la velocità di indicizzazione”, “troppi eth_calls”, “pausa/riprendi subgraph”. Per un subgraph che fallisce, è bloccato, genera errori o non si distribuisce, usa /subgraph-doctor (ottimizzare un subgraph sano rientra qui, non nel doctor). Per migrare fuori da The Graph, usa /subgraph-migrate. Per trasmettere dati grezzi della catena a un DB senza GraphQL, usa /turbo-builder.
