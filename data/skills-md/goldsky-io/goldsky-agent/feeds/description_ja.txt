Goldsky Feeds をクエリし、1 つのウォレットの残高と転送を取得する REST API です。ウォレット保有額、ポートフォリオ価値、転送履歴、入金チェック、edge.goldsky.com/data/feeds、Feeds API キー、または GOLDSKY_FEEDS_API_KEY を使用してください。goldsky feeds コマンドは存在せず、CLI のログイントークンはこのキーではありません。ユーザー自身のデータベース内の行については /turbo-builder を使用します。Turbo データセット名については /datasets を使用してください。JSON‑RPC については /edge または /boost を使用します。

常にユーザーの言語で回答してください。
