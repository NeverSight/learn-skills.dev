Consulta Goldsky Feeds, la API REST para los saldos y transferencias de una cartera. Úsala para holdings de la cartera, valor del portafolio, historial de transferencias, verificaciones de depósitos, edge.goldsky.com/data/feeds, una clave de API de Feeds o GOLDSKY_FEEDS_API_KEY. No existe el comando goldsky feeds, y el token de inicio de sesión del CLI no es esta clave. Para filas en la propia base de datos del usuario, usa /turbo-builder. Para un nombre de conjunto de datos Turbo, usa /datasets. Para JSON‑RPC, usa /edge o /boost.

Por favor, responde siempre en el idioma del usuario.
