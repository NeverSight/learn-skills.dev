Interrogez Goldsky Feeds, l'API REST pour les soldes et les transferts d'un portefeuille. À utiliser pour les portefeuilles, la valeur du portefeuille, l'historique des transferts, les chèques de dépôt, edge.goldsky.com/data/feeds, une clé API de flux ou GOLDSKY_FEEDS_API_KEY. Il n'y a pas de commande goldsky feeds, et le jeton de connexion CLI n'est pas cette clé. Pour les lignes de la propre base de données de l'utilisateur, utilisez /turbo-builder. Pour un nom d'ensemble de données Turbo, utilisez /datasets. Pour JSON-RPC, utilisez /edge ou /boost.
