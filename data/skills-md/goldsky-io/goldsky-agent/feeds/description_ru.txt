Запрашивайте Goldsky Feeds, REST API для балансов и переводов одного кошелька. Используйте его для контроля активов кошелька, оценки портфеля, истории переводов, проверки депозитов, edge.goldsky.com/data/feeds, ключа API Feeds или GOLDSKY_FEEDS_API_KEY. Команды goldsky feeds нет, а токен входа CLI не является этим ключом. Для строк в собственной базе данных пользователя используйте /turbo-builder. Для имени набора данных Turbo — /datasets. Для JSON‑RPC используйте /edge или /boost.

Всегда отвечайте на языке пользователя.
