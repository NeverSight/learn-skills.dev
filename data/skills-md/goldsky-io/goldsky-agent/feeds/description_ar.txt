استعلم عن Goldsky Feeds، API REST لأرصدة وتحويلات محفظة واحدة. استخدمه لعرض مملكة المحفظة، قيمة المحفظة، تاريخ التحويلات، التحقق من الإيداع، edge.goldsky.com/data/feeds، مفتاح API للـ Feeds، أو GOLDSKY_FEEDS_API_KEY. لا يوجد أمر goldsky feeds، ورمز الدخول في سطر الأوامر ليس هذا المفتاح. للصفوف في قاعدة بيانات المستخدم الخاصة، استخدم /turbo-builder. لاسم مجموعة بيانات Turbo، استخدم /datasets. لتقنية JSON‑RPC، استخدم /edge أو /boost.

يرجى دائمًا الرد بلغة المستخدم.
