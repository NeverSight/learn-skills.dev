Interroga Goldsky Feeds, la REST API per i saldi e i trasferimenti di un singolo portafoglio. Usala per le partecipazioni del portafoglio, il valore del portafoglio, la cronologia dei trasferimenti, i controlli dei depositi, edge.goldsky.com/data/feeds, una chiave API Feeds o GOLDSKY_FEEDS_API_KEY. Non esiste un comando goldsky feeds, e il token di login CLI non è questa chiave. Per le righe nel database dell'utente, usa /turbo-builder. Per un nome di dataset Turbo, usa /datasets. Per JSON‑RPC, usa /edge o /boost.
