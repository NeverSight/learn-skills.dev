Ruta de automatización on‑chain orientada a eventos que detecta actividad, aplica lógica y envía una transacción como respuesta. Úsala para “cuando X ocurre on‑chain, hacer Y”, flujos de trabajo de monitorizar‑y‑ejecutar, llamadas a contratos inteligentes activadas por eventos, keepers, automatización de protocolos, autorreclamación o capitalización de recompensas, liquidaciones, reequilibrio y automatización de liquidaciones. Combina Turbo/Subgraphs/Mirror para la detección con Compose para decisiones y ejecución, incluyendo carteras, patrocinio de gas y writeContract. Carga /compose para la ejecución y /turbo-builder cuando la detección necesita escala de conjunto de datos. El indexado puro o streaming sin acción on‑chain pertenece a /turbo-builder, /subgraph-builder o /mirror. Para una única aplicación ya identificada como Compose, usa /compose directamente.
