Атлас в конвейерах CI/CD с действиями Atlas: ariga/setup-atlas и ariga/atlas-action в GitHub Actions, компонентами GitLab CI, orb‑ом CircleCI, pipe‑ом Bitbucket и задачей Azure DevOps AtlasAction. Шаги CI/CD (migrate lint, push, diff, hash, autorebase, test, apply, down, set, drift; schema plan, plan approve, push, apply, lint, test; script exec, query, loop, test, push; security scan; monitor schema; create-repo) с их входными параметрами, выходными данными, токенами, разрешениями и комментариями к pull‑request, а также фиксация версий, раннеров и исправление неудачного запуска. Используйте навык atlas каждый раз, когда конвейер запускает Atlas или проверка Atlas в CI завершается ошибкой.
