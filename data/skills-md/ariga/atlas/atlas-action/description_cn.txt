在 CI/CD 流水线中使用 Atlas：通过 GitHub Actions 的 ariga/setup-atlas 与 ariga/atlas-action、GitLab CI 组件、CircleCI orb、Bitbucket pipe 以及 Azure DevOps AtlasAction 任务。CI/CD 步骤包括（migrate lint、push、diff、hash、autorebase、test、apply、down、set、drift；schema plan、plan approve、push、apply、lint、test；script exec、query、loop、test、push；security scan；monitor schema；create‑repo），以及它们的输入、输出、令牌、权限和拉取请求评论，并且涉及固定版本、运行器以及修复失败的运行。每当流水线运行 Atlas 或 CI 中的 Atlas 检查失败时，请使用 atlas skill。
