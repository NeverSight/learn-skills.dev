Atlas في خطوط الأنابيب CI/CD مع إجراءات Atlas: ariga/setup-atlas وariga/atlas-action على GitHub Actions، ومكوّنات GitLab CI، وCircleCI orb، وBitbucket pipe، ومهمة Azure DevOps AtlasAction. خطوات CI/CD (migrate lint، push، diff، hash، autorebase، test، apply، down، set، drift؛ schema plan، plan approve، push، apply، lint، test؛ script exec، query، loop، test، push؛ security scan؛ monitor schema؛ create-repo) مع مدخلاتها ومخرجاتها والرموز والأذونات وتعليقات طلب السحب، بالإضافة إلى تثبيت الإصدارات، المشغّلين، وإصلاح تشغيل فاشل. استخدم مهارة Atlas كلما شغلت خط أنابيب Atlas أو فشل فحص Atlas في CI.
