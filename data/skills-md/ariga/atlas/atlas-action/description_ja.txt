GitHub Actions の ariga/setup-atlas と ariga/atlas-action、GitLab CI のコンポーネント、CircleCI の orb、Bitbucket の pipe、Azure DevOps の AtlasAction タスクを使用した CI/CD パイプラインにおける Atlas。CI/CD の各ステップ（migrate lint、push、diff、hash、autorebase、test、apply、down、set、drift、schema plan、plan approve、push、apply、lint、test、script exec、query、loop、test、push、security scan、monitor schema、create‑repo）とそれらの入力、出力、トークン、権限、プルリクエストコメント、バージョン固定、ランナー設定、失敗した実行の修正。パイプラインが Atlas を実行する際や CI で Atlas のチェックが失敗した際は、atlas スキルと共に使用してください。
