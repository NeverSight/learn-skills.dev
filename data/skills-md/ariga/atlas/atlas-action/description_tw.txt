在 CI/CD 流水線中使用 Atlas：透過 GitHub Actions 上的 ariga/setup-atlas 與 ariga/atlas-action、GitLab CI 元件、CircleCI orb、Bitbucket pipe 以及 Azure DevOps 的 AtlasAction 任務來整合 Atlas。CI/CD 步驟（migrate lint、push、diff、hash、autorebase、test、apply、down、set、drift；schema plan、plan approve、push、apply、lint、test；script exec、query、loop、test、push；security scan；monitor schema；create‑repo）以及其輸入、輸出、Token、權限與 Pull Request 評論，另加上版本鎖定、執行環境設定與失敗執行的修復。每當流水線執行 Atlas 或 CI 中的 Atlas 檢查失敗時，請使用 Atlas skill。
