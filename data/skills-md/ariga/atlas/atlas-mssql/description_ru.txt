Особенности SQL Server для Atlas (а также Azure SQL и MSSQL): логин, база данных разработки и область URL (mode=schema vs mode=database, параметр запроса database), уровень совместимости и сопоставление (collation), автоматически генерируемые имена ограничений, значения по умолчанию для кластеризованных индексов и точность datetime2 в HCL, батчи GO и директива delimiter, транзакции и операторы, которые нельзя выполнять в одной, столбцы identity, вычисляемые и временные, типы псевдонимов и таблиц, изменения, планируемые как удаление и добавление, что Atlas опускает (DENY, синонимы, безопасность на уровне строк, разрежённые столбцы), роли базы данных, пользователи и гранты, тесты схем и миграций, а также пользовательские правила lint. Используйте с навыком atlas каждый раз, когда Atlas управляет базой данных SQL Server или Azure SQL.
