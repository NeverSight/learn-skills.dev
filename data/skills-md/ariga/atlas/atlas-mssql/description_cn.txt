Atlas（以及 Azure SQL 和 MSSQL）的 SQL Server 细节：登录、开发数据库和 URL 范围（mode=schema 与 mode=database，database 查询参数），兼容性级别和排序规则，系统生成的约束名称，聚簇索引默认值和 HCL 中 datetime2 的精度，GO 批处理和分隔符指令，事务以及不能在同一事务中运行的语句，标识列、计算列和时态列，别名和表类型，计划作为删除和添加的更改，Atlas 未包含的内容（DENY、同义词、行级安全、稀疏列），数据库角色、用户和权限授予，模式和迁移测试，以及自定义 lint 规则。每当 Atlas 管理 SQL Server 或 Azure SQL 数据库时，请使用 atlas 技能。
