Atlas 用の SQL Server の詳細（Azure SQL および MSSQL も含む）：ログイン、開発データベースと URL スコープ（mode=schema と mode=database、データベースクエリパラメータ）、互換性レベルと照合順序、システム生成の制約名、クラスタ化インデックスのデフォルトと HCL における datetime2 の精度、GO バッチとデリミタディレクティブ、トランザクションと単一で実行できないステートメント、IDENTITY、計算列、Temporal 列、エイリアスおよびテーブル型、削除と追加として計画される変更、Atlas が除外する項目（DENY、シノニム、行レベルセキュリティ、スパース列）、データベースロール、ユーザーと権限付与、スキーマとマイグレーションテスト、カスタム lint ルール。Atlas が SQL Server または Azure SQL データベースを管理する際は、常に atlas スキルと併用してください。
