Specifiche di SQL Server per Atlas (anche Azure SQL e MSSQL): login, database di sviluppo e ambito URL (mode=schema vs mode=database, parametro di query database), livello di compatibilità e collazione, nomi di vincoli generati dal sistema, impostazioni predefinite dell’indice clustered e precisione datetime2 in HCL, batch GO e direttiva delimiter, transazioni e istruzioni che non possono essere eseguite in una sola, colonne identity, calcolate e temporali, alias e tipi di tabella, modifiche pianificate come drop e add, ciò che Atlas omette (DENY, sinonimi, sicurezza a livello di riga, colonne sparse), ruoli del database, utenti e grant, test di schema e migrazione, e regole lint personalizzate. Usa la skill Atlas ogni volta che Atlas gestisce un database SQL Server o Azure SQL.
