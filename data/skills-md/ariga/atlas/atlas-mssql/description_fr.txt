Spécificités de SQL Server pour Atlas (également Azure SQL et MSSQL) : connexion, base de données de développement et portée de l’URL (mode=schema vs mode=database, le paramètre de requête database), niveau de compatibilité et collation, noms de contraintes générés par le système, valeurs par défaut des index clusterisés et précision datetime2 dans HCL, lots GO et directive de délimiteur, transactions et instructions qui ne peuvent pas s’exécuter ensemble, colonnes d’identité, calculées et temporelles, alias et types de table, modifications prévues comme une suppression puis une addition, ce que Atlas omet (DENY, synonymes, sécurité au niveau des lignes, colonnes sparses), rôles de base de données, utilisateurs et privilèges, tests de schéma et de migration, et règles de lint personnalisées. Utilisez la compétence Atlas chaque fois qu’Atlas gère une base de données SQL Server ou Azure SQL.
