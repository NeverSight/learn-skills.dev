Especificaciones de SQL Server para Atlas (también Azure SQL y MSSQL): inicio de sesión, base de datos de desarrollo y ámbito de URL (modo=esquema frente a modo=base de datos, el parámetro de consulta de la base), nivel de compatibilidad e intercalación, nombres de restricciones generados por el sistema, valores predeterminados del índice agrupado y precisión de datetime2 en HCL, lotes GO y la directiva del delimitador, transacciones y sentencias que no pueden ejecutarse en una sola, columnas de identidad, calculadas y temporales, alias y tipos de tabla, cambios planificados como una eliminación y una adición, lo que Atlas omite (DENY, sinónimos, seguridad a nivel de fila, columnas escasas), roles de base de datos, usuarios y concesiones, pruebas de esquema y migración, y reglas de lint personalizadas. Usa la habilidad Atlas siempre que Atlas gestione una base de datos SQL Server o Azure SQL.
