تفاصيل SQL Server لـ Atlas (وأيضًا Azure SQL و MSSQL): تسجيل الدخول، قاعدة البيانات التطويرية ونطاق URL (mode=schema مقابل mode=database، معامل الاستعلام للقاعدة)، مستوى التوافق والترميز، أسماء القيود التي يولدها النظام، الإعدادات الافتراضية للفهرس المتجمع ودقة datetime2 في HCL، دفعات GO وتوجيه الفاصل، المعاملات والعبارات التي لا يمكن تشغيلها معًا، الأعمدة الهوية، المُحسوبة والزمانية، الأنواع المستعارة والجداول، التغييرات المخطط لها كحذف وإضافة، ما لا يشمله Atlas (DENY، المرادفات، أمان الصفوف، الأعمدة المتناثرة)، أدوار القاعدة، المستخدمين ومنح الصلاحيات، اختبارات المخطط والهجرة، وقواعد lint المخصصة. استخدمها مع مهارة Atlas كلما كان Atlas يدير قاعدة بيانات SQL Server أو Azure SQL.
