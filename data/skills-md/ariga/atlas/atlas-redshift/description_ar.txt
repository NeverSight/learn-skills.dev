تفاصيل Redshift لـ Atlas: برنامج تشغيل الدخول فقط، عناوين URL بنظام redshift:// وData API (redshift+http://) ونطاقها، قاعدة البيانات التطويرية بدون Docker، التوزيع، مفاتيح الفرز، والترميزات، أعمدة الهوية، التغييرات التي لا يمكن لـ Redshift تعديلها وسياسة allow_recreate، المشاهد والمشاهد المادية، الدوال والإجراءات، المستخدمون، المجموعات، الأدوار ومنح الصلاحيات، مشاركات البيانات (datashares)، المخططات الخارجية، العبارات التي لا يمكن تشغيلها داخل معاملة، عدم وجود قفل استشاري، اختبارات المخطط والترحيل، وقواعد lint مخصصة. استخدمها مع مهارة Atlas كلما قام Atlas بإدارة قاعدة بيانات Redshift.
