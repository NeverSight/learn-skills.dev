Trie les alertes de production à l’aide du signal d’observabilité. Le mode A rassemble le contexte confirmé/inféré pour une seule alerte ou un seul ticket et met à jour le tracker ; Le mode B se propage sur les alertes déclenchées dans une fenêtre, supprime le bruit sourd et non acheminé, déduple via une empreinte digitale stable et classe ou met à jour les problèmes de manière idempotente. Met en corrélation les alertes avec les modifications récentes via le manifeste O11y Change Context. À utiliser lors de l'enquête sur une alerte ou un incident, ou lors de l'exécution d'un tri planifié sur appel.
