最高のホスト型画像モデル（Nano Banana 2 / Pro、GPT Image 2、Seedream、Bria）を使って、画像の生成、編集、切り抜き、検査ができます。テキストからの生成、写真の編集・レタッチ、ロゴ／テキストの入れ替え、背景変更、アップスケール、製品撮影、ポートレート、試着、3Dレンダリングなど、あらゆる画像リクエストに対応します。これが Starchild の唯一の画像スキルです。従来の image‑create / image‑edit / image‑3d / image‑ecommerce / image‑portrait / image‑tryon / image‑bg‑remove スキルは廃止され、ここに統合されました。
