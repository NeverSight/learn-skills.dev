Exploitez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via la CLI `orca`. Utilisez‑la lorsque l’utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Privilégiez‑la plutôt que le worktree Git brut, les PTY ad hoc ou l’utilisation de l’ordinateur quand un état Orca est en jeu. N’utilisez l’utilisation de l’ordinateur que lorsqu’une fenêtre visible nécessite un contrôle GUI qu’une CLI, le système de fichiers ou une API ne peuvent assurer.
