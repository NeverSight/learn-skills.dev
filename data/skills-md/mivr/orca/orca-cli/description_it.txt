Gestisci i worktree gestiti da Orca, i contesti di cartelle, i terminali, i repository, le automazioni, gli artefatti, la condivisione di competenze, i commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Usala quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferiscila rispetto a un semplice git worktree, PTY ad hoc o l'uso del Computer quando è coinvolto lo stato di Orca. Usa il Computer solo quando è necessaria la gestione di una finestra visibile che una CLI, il file system o un'API non possono controllare.

Rispondi sempre nella lingua dell'utente.
