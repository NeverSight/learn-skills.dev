透過 `orca` CLI 操作 Orca 管理的工作樹、資料夾情境、終端機、倉庫、自動化、產物、技能分享、工作樹註解，以及 Orca 內建的瀏覽器。當使用者說出「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」或「share skills」時使用。在涉及 Orca 狀態時，請優先使用此方式，而非純 git 工作樹、臨時 PTY 或 Computer Use。只有在需要對可見視窗進行 GUI 控制，而 CLI、檔案系統或 API 無法完成時，才使用 Computer Use。
