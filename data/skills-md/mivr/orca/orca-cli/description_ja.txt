Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の埋め込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」「handover」「give this to another agent」「Orca browser」「orca artifacts」「share skills」などと言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree や臨時の PTY、Computer Use よりもこの方法を優先してください。CLI、ファイルシステム、API では対処できない可視ウィンドウの GUI 操作が必要なときだけ Computer Use を使用します。

常にユーザーの言語で回答してください。
