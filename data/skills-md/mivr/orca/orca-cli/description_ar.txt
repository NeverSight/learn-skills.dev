قم بتشغيل شجرات العمل التي تُدار بواسطة Orca، وسياقات المجلدات، والمحطات الطرفية، والمستودعات، والأتمتة، والقطع الأثرية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر واجهة سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، أو "Orca worktree"، أو "child worktree"، أو "spawn codex/claude in a worktree"، أو "read/wait/send Orca terminal"، أو "handoff" / "handover" / "give this to another agent"، أو "Orca browser"، أو "orca artifacts"، أو "share skills". فضل هذا الخيار على شجرة git العادية أو PTYs العارضة أو استخدام الكمبيوتر عندما تكون حالة Orca متورطة. استخدم "استخدام الكمبيوتر" فقط عندما تحتاج نافذة مرئية إلى تحكم رسومي لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به.
