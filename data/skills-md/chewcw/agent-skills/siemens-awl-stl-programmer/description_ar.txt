توليد برامج قائمة العبارات (STL/AWL) الخاصة بـ Siemens S7-300/S7-400/S7-1500 المتوافقة مع Step7 Classic وTIA Portal. استخدم هذه القدرة كلما طلب المستخدم كتابة أو إنشاء أو تعديل أي منطق PLC أو كتل وظائف أو كتل تنظيم أو كتل بيانات أو برامج تحكم بصيغة STL/AWL. كما يتم تفعيلها لأي أسئلة حول عنونة الذاكرة في Siemens S7، المؤقتات، العدادات، المجمعات، بنية الكتل، أو استيرادات Step7/TIA Portal. استخدم هذه القدرة دائمًا حتى إذا أشار المستخدم فقط إلى "STL"، "AWL"، "Step7"، "TIA Portal"، "S7-300"، "S7-400"، "S7-1500"، "كتلة PLC"، "OB"، "FB"، "FC"، أو "DB". يرجى دائمًا الرد بلغة المستخدم.
