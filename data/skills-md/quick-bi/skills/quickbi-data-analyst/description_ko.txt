Quick BI AIPro 데이터 Q&A(Questioning) 채널은 자연어 데이터 질문을 AIPro로 라우팅하고 준비된 데이터 자산을 기반으로 기본 쿼리를 수행하며 분석 결론을 텍스트 및 테이블 형식으로 반환합니다.

트리거 조건: 사용자가 데이터 쿼리, 검색, 지표 계산, 순위, 추세, 비율, 전년 대비 또는 월별 질문을 합니다. 예: "지난 30일 동안의 판매량은 얼마입니까?", "7월 채널별 출하량 순위", "지난 달 사업 규모가 전년 대비 어떻게 변했습니까?" 또는 대화에서 이미 이 기술을 호출했으며 사용자가 계속해서 데이터를 요청하고 시간 범위, 분석 차원 또는 통계 범위를 추가하거나 조정합니다.

비트리거 조건: 사용자가 대시보드, 스코어카드, 차트, 보고서, 분석 보고서, HTML 페이지 또는 기타 시각적 아티팩트를 생성하거나 수정하도록 요청합니다. 데이터 자산 동기화, 파일 업로드, 데이터 세트 또는 데이터 소스 생성 데이터 세트 필드 편집 또는 권한 설정과 같은 데이터 모델링 또는 구성 작업을 수행합니다. 데이터 분석과 관련 없는 일상적인 채팅, 코드 작성 또는 문서 작성 작업도 가능합니다. 처음 세 가지 유형의 요청에 대해서는 현재 기술이 해당 요청을 지원하지 않는다는 점을 사용자에게 명확하게 알리고 Quick BI로 안내하여 적절한 작업을 수행하도록 합니다. 관련되지 않은 다른 요청은 적절한 기능으로 넘겨져야 합니다.
