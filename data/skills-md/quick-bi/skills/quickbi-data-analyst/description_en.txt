Quick BI AIPro Data Q&A (Query) channel routes natural language data questions to AIPro, completes basic queries based on prepared data assets, and returns analysis conclusions in text and table format.

Trigger conditions: The user poses data queries, data retrieval, metric calculations, rankings, trends, proportions, year‑over‑year or month‑over‑month questions, such as “What is the sales amount for the past 30 days?”, “July ranking of shipment amount by channel”, “How did the business scale change year‑over‑year last month?”; or the conversation has already invoked this skill, and the user continues to ask about data, supplementing or adjusting the time range, analysis dimensions, and statistical scope.

Non‑trigger conditions: The user requests to generate or modify dashboards, boards, charts, reports, analysis reports, HTML pages, or other visual artifacts; synchronizing data assets, uploading files, creating datasets or data sources; performing data modeling or configuration operations, such as modifying dataset fields or configuring permissions; as well as chit‑chat unrelated to data analysis, code writing, or document authoring tasks. For the first three types of requests, clearly inform the user that the current skill does not support them and guide them to Quick BI to perform the relevant actions; other unrelated requests should be handed off to an appropriate capability.
