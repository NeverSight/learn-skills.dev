자체 Kubernetes 클러스터(관리형, 온프레미스 또는 엣지)에서 Qdrant Hybrid Cloud를 설정하고 실행하기: 전제 조건, 스토리지/CSI 및 백업, Qdrant Cloud 에이전트와 오퍼레이터 설치, 클러스터 생성·노출·보안, 레지스트리 미러링 및 비밀 회전. 사용자는 자체 인프라에 Hybrid Cloud를 설정, 설치, 배포 또는 구성하고자 할 때; 자체 EKS, GKE, AKS, OpenShift 또는 기타 Kubernetes에서 Qdrant를 운영하고 있을 때; 에이전트·오퍼레이터, Hybrid Cloud용 스토리지 클래스·볼륨 스냅샷, 클러스터 노출, Qdrant 이미지 미러링, 비밀 회전 등에 대해 문의할 때; 또는 스토리지·연결 문제로 Hybrid Cloud 설치가 실패할 때 활용하십시오.
