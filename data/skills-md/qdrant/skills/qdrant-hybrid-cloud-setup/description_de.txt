Einrichtung und Betrieb von Qdrant Hybrid Cloud auf Ihrem eigenen Kubernetes‑Cluster (verwaltet, On‑Premise oder Edge): Voraussetzungen, Speicher/CSI und Backups, Installation des Qdrant Cloud‑Agents und Operators, Erstellen/Exponieren/Sichern von Clustern, Registry‑Mirroring und Geheimnis‑Rotation. Verwenden, wenn jemand Hybrid Cloud auf seiner eigenen Infrastruktur einrichten, installieren, bereitstellen oder konfigurieren möchte; Qdrant auf eigenem EKS, GKE, AKS, OpenShift oder anderem Kubernetes betreibt; Fragen zum Agenten oder Operator, zu einer Storage‑Klasse oder Volume‑Snapshots für Hybrid Cloud, zum Exponieren eines Clusters, zum Mirroring von Qdrant‑Images oder zur Rotation von Geheimnissen hat; oder wenn eine Hybrid‑Cloud‑Installation bei Speicher‑ oder Konnektivitätsproblemen fehlschlägt.
