在您自己的 Kubernetes 集群（托管、私有或边缘）上设置和运行 Qdrant Hybrid Cloud：前置条件、存储/CSI 与备份，安装 Qdrant Cloud 代理和 Operator，创建/暴露/安全集群，镜像仓库镜像以及密钥轮换。适用于以下情况：有人想在自有基础设施上设置、安装、部署或配置 Hybrid Cloud；在自己的 EKS、GKE、AKS、OpenShift 或其他 Kubernetes 上运行 Qdrant；询问有关代理或 Operator、Hybrid Cloud 的存储类或卷快照、暴露集群、镜像 Qdrant 镜像或轮换密钥；或 Hybrid Cloud 安装在存储或连接性上出现故障时。
