在您自己的 Kubernetes 叢集（受管、內部部署或邊緣）上設置與運行 Qdrant Hybrid Cloud：先決條件、儲存/CSI 與備份、安裝 Qdrant Cloud 代理與 Operator、建立/公開/保護叢集、映像庫鏡像以及密鑰輪換。適用於以下情況：有人想在自己的基礎設施上設置、安裝、部署或配置 Hybrid Cloud；在自己的 EKS、GKE、AKS、OpenShift 或其他 Kubernetes 上運行 Qdrant；詢問有關代理或 Operator、Hybrid Cloud 的儲存類別或卷快照、叢集公開、鏡像 Qdrant 映像或密鑰輪換；或當 Hybrid Cloud 安裝在儲存或連線上失敗時。
