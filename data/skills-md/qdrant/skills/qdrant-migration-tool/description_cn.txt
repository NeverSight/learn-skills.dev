本指南介绍如何使用 Qdrant Migration Tool CLI 将向量、元数据以及稀疏嵌入从其他向量数据库迁移到 Qdrant。适用于以下情形：有人询问“如何从 Pinecone、Weaviate、Milvus、Elasticsearch、OpenSearch、pgvector、s3、Azure、Chroma、Redis、MongoDB、FAISS、Solr 迁移到 Qdrant”、 “将我的向量数据库迁移到 Qdrant”、 “Qdrant 有迁移工具吗”、 “我的迁移被中断，如何恢复”、 “迁移速度太慢”，或者 “迁移后未创建集合”。也适用于选择迁移批量大小、决定是否使用 `--net=host`，以及在迁移后验证数据的情况。请始终使用用户的语言进行回复。
