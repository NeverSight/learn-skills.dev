Leitet die Verwendung des Qdrant Migration Tool CLI an, um Vektoren, Metadaten und spärliche Einbettungen von einer anderen Vektordatenbank nach Qdrant zu verschieben. Verwenden Sie dies, wenn jemand fragt: „Wie migriere ich von Pinecone/Weaviate/Milvus/Elasticsearch/OpenSearch/pgvector/s3/Azure/Chroma/Redis/MongoDB/FAISS/Solr zu Qdrant?“, „Verschiebe meine Vektordatenbank zu Qdrant“, „Gibt es ein Migrationstool für Qdrant?“, „Meine Migration wurde unterbrochen, wie setze ich sie fort?“, „Die Migration ist zu langsam“ oder „Collection wurde nach der Migration nicht erstellt“. Auch verwenden, wenn die Batchgröße für die Migration gewählt wird, über `--net=host` entschieden wird oder Daten nach einer Migration überprüft werden.
