Guides l'utilisation de l'outil CLI de migration Qdrant pour déplacer les vecteurs, les métadonnées et les embeddings sparses d'une autre base de données vectorielle vers Qdrant. À utiliser lorsqu'une personne demande « comment migrer de Pinecone/Weaviate/Milvus/Elasticsearch/OpenSearch/pgvector/s3/Azure/Chroma/Redis/MongoDB/FAISS/Solr vers Qdrant », « déplacer ma base de données vectorielle vers Qdrant », « existe‑t‑il un outil de migration pour Qdrant », « ma migration a été interrompue, comment la reprendre », « la migration est trop lente » ou « la collection n'a pas été créée après la migration ». À utiliser également lors du choix de la taille du lot de migration, de la décision d'utiliser `--net=host`, ou de la vérification des données après une migration.
