Guía el uso de la CLI de la herramienta de migración de Qdrant para mover vectores, metadatos e incrustaciones escasas de otra base de datos vectorial a Qdrant. Úsala cuando alguien pregunte “¿cómo migro de Pinecone/Weaviate/Milvus/Elasticsearch/OpenSearch/pgvector/s3/Azure/Chroma/Redis/MongoDB/FAISS/Solr a Qdrant?”, “mover mi base de datos vectorial a Qdrant”, “¿existe una herramienta de migración para Qdrant?”, “mi migración se interrumpió, ¿cómo la reanudo?”, “la migración es demasiado lenta” o “la colección no se creó después de la migración”. También se utiliza al elegir el tamaño del lote de migración, decidir sobre `--net=host` o verificar los datos tras una migración.
