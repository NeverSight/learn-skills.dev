تدقيق قابلية الزحف، قابلية الفهرسة، HTTPS وإعادة التوجيه، Core Web Vitals، توافق المحمول، البيانات الوصفية، الروابط الكانونية، البيانات المهيكلة، والهندسة الداخلية باستخدام بيانات تدقيق الموقع من Semrush، مع فصل العيوب المؤكدة عن حكم المحلل. يُستخدم عندما يطلب المستخدم تدقيقًا فنيًا لتحسين محركات البحث أو فحص صحة الموقع، أو لمعرفة لماذا لا تُفهرس الصفحات، أو لماذا يفقد الموقع رؤيته في البحث لأسباب تقنية.
