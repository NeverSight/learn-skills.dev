Спецификация стиля для диаграммы mermaid — «zone-tinted flowchart» (flowchart + subgraph с заливкой per region + classDef палитра + значимые формы). Загружайте ЗАРАНЕЕ при написании/редактировании любого блока ```mermaid``` в документе, особенно C1 System Context, C2 Modules, пользовательский поток. Диаграмма должна иметь достаточную цветовую гамму, чтобы её можно было читать как в светлом, так и в тёмном режиме. Запрещены C4Context/C4Container. Включите `verify.py` — lint + рендеринг в 2 режима (светлый/тёмный) для визуальной проверки перед вставкой. Только для чтения, не изменяйте содержимое файла.
