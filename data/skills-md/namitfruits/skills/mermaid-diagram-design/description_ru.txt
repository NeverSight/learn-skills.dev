Спецификация стиля для диаграмм mermaid — «зоно‑окрашенный блок‑схема» (блок‑схема + subgraph с заливкой по регионам + palette classDef + значимая форма). Загружать ЗАРАНЕЕ при написании/редактировании любого блока ```mermaid``` в документе, особенно C1 System Context, C2 Modules, пользовательский поток. Диаграмма должна быть достаточно цветной, чтобы её можно было читать как в светлом, так и в тёмном режиме. Запрещать C4Context/C4Container. Включать `verify.py` — lint + рендер двух вариантов (светлый/тёмный) для визуальной проверки перед вставкой. Только для чтения, не изменять содержимое файла.
