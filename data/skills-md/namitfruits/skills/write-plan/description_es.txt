Escribe un documento de plan de implementación (plan doc) para una característica — preséntalo en el chat anterior, confirma el ID de la tarea, genera el archivo siguiendo un marco fijo de 7 secciones (Problem · Goal · Mental model · Probe · Decisions · Design · Phases — Probe opcional) con los símbolos 🤖/👤, y marca con un tick hasta donde hayas avanzado. Úsalo cuando el usuario dice "elaborar plan", "escribir plan para X", "guardar el plan", "crear doc plan", "diseñar X antes de codificar", o cuando una solicitud sea lo suficientemente grande como para requerir un plan antes de modificar el código. Lee la convención del proyecto (CLAUDE.md / AGENTS.md / carpeta docs) para obtener el **binding** — carpeta, sistema de IDs, doc fuente, comando de verificación — y la **forma del doc sigue esta skill**. Incluye `verify.py` — lint del marco de secciones, cadena `P → D → DS → phase`, cubre `DS`, tick/estado.
