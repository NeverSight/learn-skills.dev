为一个功能编写部署计划文档（plan doc）——在之前的聊天中阐述，确认工作 ID，按照固定的 7 部分框架（Problem · Goal · Mental model · Probe · Decisions · Design · Phases——Probe 为可选）创建文件，使用 🤖/👤 标记，然后根据勾选进度进行。用户说“制定计划”“为 X 编写 plan”“保存 plan”“创建 doc plan”“在编码前设计 X”或当一个需求足够大需要在修改代码前制定计划时使用。阅读项目约定（CLAUDE.md / AGENTS.md / docs 目录）以获取 **binding**——目录、ID 系统、源文档、检查命令——而 **文档形式则遵循此技能**。附带 `verify.py`——对章节框架进行 lint，链路 `P → D → DS → phase`，覆盖 `DS`，勾选/状态。
