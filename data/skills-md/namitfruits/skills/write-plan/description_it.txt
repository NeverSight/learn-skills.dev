Scrivi un documento di piano di implementazione (plan doc) per una feature — presentalo nella chat precedente, conferma l'ID del lavoro, crea il file secondo una struttura fissa a 7 sezioni (Problem · Goal · Mental model · Probe · Decisions · Design · Phases — Probe opzionale) con i simboli 🤖/👤, e spunta man mano che procedi. Usalo quando l'utente dice “lập kế hoạch”, “viết plan cho X”, “lưu lại plan”, “tạo doc plan”, “thiết kế X trước khi code”, oppure quando una richiesta è abbastanza grande da richiedere un piano prima di modificare il codice. Leggi le convenzioni del progetto (CLAUDE.md / AGENTS.md / cartella docs) per prendere **binding** — cartella, sistema ID, documento di origine, comando di verifica — e la **forma del documento** segue questa skill. Includi `verify.py` — lint della struttura delle sezioni, catena `P → D → DS → phase`, copertura `DS`, tick/status.
