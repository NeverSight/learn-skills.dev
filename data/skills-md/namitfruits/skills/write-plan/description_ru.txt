Составьте документ плана развертывания (plan doc) для функции — представьте его в предыдущем чате, зафиксируйте ID задачи, создайте файл по фиксированному шаблону из 7 разделов (Problem · Goal · Mental model · Probe · Decisions · Design · Phases — Probe optional) с обозначениями 🤖/👤, затем отмечайте галочкой, насколько продвинулась работа. Использовать, когда пользователь говорит «lập kế hoạch», «viết plan cho X», «lưu lại plan», «tạo doc plan», «thiết kế X trước khi code», или когда запрос достаточно крупный, требующий плана перед правкой кода. Изучите конвенцию проекта (CLAUDE.md / AGENTS.md / директория docs), чтобы получить **binding** — директорию, систему ID, исходный документ, проверочную команду — а **форма документа следует этому навыку**. Включите `verify.py` — проверку (lint) структуры разделов, цепочку `P → D → DS → phase`, покрытие `DS`, отметка/статус.
