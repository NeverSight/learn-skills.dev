Создать документ плана внедрения (plan doc) для функции — предварительно обсудить в чате, уточнить ID задачи, сформировать файл по фиксированному шаблону из 7 разделов (Problem · Goal · Mental model · Probe · Decisions · Design · Phases — Probe optional) с обозначениями 🤖/👤, и отмечать галочкой, пока продвигаешься. Используется, когда пользователь говорит «составить план», «написать план для X», «сохранить план», «создать doc план», «спроектировать X перед кодированием», или когда запрос достаточно большой, требующий план перед изменением кода. Прочитать конвенцию проекта (CLAUDE.md / AGENTS.md / каталог docs), чтобы получить **binding** — каталог, систему ID, исходный документ, проверочную команду, а **форма документа следует этому навыку**. Прикладывать `verify.py` — lint шаблона разделов, цепочку `P → D → DS → phase`, покрытие `DS`, отмечать статус.
