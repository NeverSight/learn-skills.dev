프로젝트에 Claude Code가 실행되는 각 세션을 기록하는 방법을 설치합니다 — 각 프롬프트, 모델 및 도구 호출마다, 시간, 토큰, 서브에이전트, 스킬 — 그리고 로컬 웹 페이지로 확인합니다. 설치 명령은 스크립트, 서버, 조회 페이지를 프로젝트의 `.metrics/`에 복사하고 `.claude/settings.json`에 훅을 추가합니다, 다른 훅은 유지; 업그레이드 시 훅이 중복되지 않도록 재설치합니다. 훅은 각 세션을 `.metrics/sessions/<id>.json` 파일에 기록하고, 비밀을 가리고 이미지를 제외합니다; 파일은 git에 포함되므로 어떤 컴퓨터가 pull해도 모든 컴퓨터의 세션을 볼 수 있습니다. `python3 .metrics/serve_metrics.py` 로 확인합니다. `python3`가 필요하고 macOS와 Linux에서 실행됩니다. 사용자가 “cài tracking session”, “đo session Claude”, “theo dõi token”, “session metrics”, “xem agent đã làm gì, tốn bao nhiêu”, “mở trang metrics” 라고 말하거나 세션 간 노력 비교를 원할 때 사용합니다.
