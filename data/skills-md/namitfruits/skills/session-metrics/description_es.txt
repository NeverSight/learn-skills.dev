Instala en un proyecto una forma de registrar cada sesión de Claude Code que se ejecute allí — cada prompt, cada llamada al modelo y a la herramienta, tiempo, token, subagente, habilidad — y luego verla mediante una página web local. El comando de instalación copia el script, el servidor y la página de visualización en `.metrics/` del proyecto y añade un hook en `.claude/settings.json`, manteniendo otros hooks; reinstala para actualizar sin duplicar el hook. El hook registra cada sesión en un archivo `.metrics/sessions/<id>.json`, oculta secretos, elimina imágenes; el archivo sigue en git, así que cualquier máquina que lo descargue podrá ver las sesiones de todas las máquinas. Visualiza con `python3 .metrics/serve_metrics.py`. Necesita `python3`, funciona en macOS y Linux. Se usa cuando el usuario dice "instalar seguimiento de sesión", "medir sesión Claude", "seguir token", "métricas de sesión", "ver qué hizo el agente, cuánto costó", "abrir página de métricas", o quiere comparar el esfuerzo entre sesiones.
