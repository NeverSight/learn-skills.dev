在一個專案中安裝此功能，以記錄每個 Claude Code 的 session——包括每個提示、每次呼叫模型與工具、時間、token、子代理、技能——然後可透過本地網頁查看。安裝指令會將腳本、伺服器、檢視頁面複製到專案的 `.metrics/` 目錄，並在 `.claude/settings.json` 中加入 hook，保留其他 hook；重新安裝以升級時不會重複加入相同的 hook。該 hook 為每個 session 寫入一個檔案 `.metrics/sessions/<id>.json`，會遮蔽機密資訊，去除圖片；檔案隨 git 版本控制，任何拉取程式碼的機器都能看到所有機器的 session。使用 `python3 .metrics/serve_metrics.py` 觀看。需要 `python3`，可在 macOS 與 Linux 上執行。適用於使用者說「安裝 session 追蹤」、『測量 Claude session』、『追蹤 token』、『session metrics』、『查看代理執行了什麼、花了多少』、『開啟 metrics 頁面』，或想比較各 session 工作量的情況。
