Установите в проект способ записи каждой сессии Claude Code, которая в нём запускается — каждый запрос, каждый вызов модели и инструмента, время, токены, субагент, навык — и просматривайте их через локальный веб‑интерфейс. Команда установки копирует скрипт, сервер и страницу просмотра в каталог `.metrics/` проекта и добавляет hook в файл `.claude/settings.json`, сохраняя остальные хуки; переустановка для обновления не дублирует hook. Hook сохраняет каждую сессию в файл `.metrics/sessions/<id>.json`, маскирует секреты, удаляет изображения; файл находится под контролем git, поэтому любой репозиторий после pull может просматривать сессии с любого компьютера. Просмотр осуществляется командой `python3 .metrics/serve_metrics.py`. Требуется `python3`, работает на macOS и Linux. Используется, когда пользователь говорит «установить отслеживание сессии», «измерить сессию Claude», «отслеживать токены», «метрики сессии», «посмотреть, что сделал агент и сколько это стоило», «открыть страницу метрик» или хочет сравнить затраты между сессиями.
