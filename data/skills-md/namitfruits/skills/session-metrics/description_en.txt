Cài vào một project cách ghi lại từng session Claude Code chạy trong đó — mỗi prompt, mỗi lần gọi model và tool, thời gian, token, subagent, skill — rồi xem bằng một trang web local. Lệnh cài chép script, server, trang xem vào `.metrics/` của project và thêm hook vào `.claude/settings.json`, giữ hook khác; cài lại để nâng cấp không nhân đôi hook. Hook ghi mỗi session một file `.metrics/sessions/<id>.json`, che secret, bỏ ảnh; file đi theo git nên máy nào pull về cũng xem được session của mọi máy. Xem bằng `python3 .metrics/serve_metrics.py`. Cần `python3`, chạy trên macOS và Linux. Dùng khi user nói "cài tracking session", "đo session Claude", "theo dõi token", "session metrics", "xem agent đã làm gì, tốn bao nhiêu", "mở trang metrics", hoặc muốn so công sức giữa các session.
