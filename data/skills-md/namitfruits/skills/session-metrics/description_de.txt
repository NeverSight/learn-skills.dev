Installiere in ein Projekt eine Möglichkeit, jede Claude‑Code‑Session, die darin läuft, aufzuzeichnen – jede Eingabeaufforderung, jeden Aufruf von Modell und Werkzeug, Zeit, Token, Sub‑Agent, Fähigkeit – und sie dann über eine lokale Webseite anzusehen. Der Installationsbefehl kopiert Skript, Server und Anzeigeseite in das Verzeichnis `.metrics/` des Projekts und fügt einen Hook in `.claude/settings.json` ein, wobei andere Hooks erhalten bleiben; bei einer Neuinstallation wird das Upgrade durchgeführt, ohne den Hook zu duplizieren. Der Hook schreibt jede Session in eine Datei `.metrics/sessions/<id>.json`, maskiert Secrets, entfernt Bilder; die Datei wird per Git versioniert, sodass jeder Rechner, der sie pullt, die Sessions aller Maschinen sehen kann. Ansicht erfolgt mit `python3 .metrics/serve_metrics.py`. Benötigt `python3`, läuft auf macOS und Linux. Verwendung, wenn der Benutzer sagt „cài tracking session“, „đo session Claude“, „theo dõi token“, „session metrics“, „xem agent đã làm gì, tốn bao nhiêu“, „mở trang metrics“ oder die Aufwände zwischen den Sessions vergleichen möchte.
