在项目中安装一种记录 Claude Code 每个会话运行情况的方法——每个提示、每次调用模型和工具、时间、token、子代理、技能——然后通过本地网页查看。安装命令会把脚本、服务器、查看页面复制到项目的 `.metrics/` 目录，并在 `.claude/settings.json` 中添加 hook，保留其他 hook；重新安装以升级时不会重复添加 hook。hook 为每个会话记录一个文件 `.metrics/sessions/<id>.json`，屏蔽 secret，去除图片；文件随 git 迁移，任何机器 pull 下来都能查看所有机器的会话。通过 `python3 .metrics/serve_metrics.py` 查看。需要 `python3`，在 macOS 和 Linux 上运行。用于用户说“安装跟踪会话”“测量 Claude 会话”“监控 token”“会话指标”“查看代理做了什么，花费多少”“打开指标页面”，或想比较各会话之间的工作量时。
