تثبيت في مشروع طريقة لتسجيل كل جلسة تشغيل Claude Code فيه — كل مطالبة، كل استدعاء للنموذج والأداة، الوقت، الرموز، الوكيل الفرعي، المهارة — ثم عرضها عبر موقع ويب محلي. أمر التثبيت ينسخ السكريبت والخادم وصفحة العرض إلى `.metrics/` داخل المشروع ويضيف hook إلى `.claude/settings.json`، مع الحفاظ على الـ hook الأخرى؛ وإعادة التثبيت للترقية دون تكرار الـ hook. الـ hook يسجل كل جلسة في ملف `.metrics/sessions/<id>.json`، يُخفي السر، يحذف الصور؛ الملف يُتبع عبر git لذا أي جهاز يسحب المستودع يستطيع مشاهدة جلسات جميع الأجهزة. العرض يتم عبر `python3 .metrics/serve_metrics.py`. يتطلب `python3`، يعمل على macOS وLinux. يُستخدم عندما يقول المستخدم "cài tracking session"، "đo session Claude"، "theo dõi token"، "session metrics"، "xem agent đã làm gì, tốn bao nhiêu"، "mở trang metrics"، أو يريد مقارنة الجهد بين الجلسات.
