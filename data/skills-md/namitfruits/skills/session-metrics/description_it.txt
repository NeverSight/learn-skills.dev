Installa in un progetto un modo per registrare ogni sessione di Claude Code che vi viene eseguita — ogni prompt, ogni chiamata al modello e agli strumenti, tempo, token, sub‑agent, skill — e poi visualizzarle tramite una pagina web locale. Il comando di installazione copia lo script, il server e la pagina di visualizzazione nella cartella `.metrics/` del progetto e aggiunge un hook in `.claude/settings.json`, mantenendo altri hook; reinstallare per aggiornare senza duplicare il hook. Il hook registra ogni sessione in un file `.metrics/sessions/<id>.json`, nasconde i segreti, rimuove le immagini; il file è sotto controllo git, quindi qualsiasi macchina che effettua il pull può vedere le sessioni di tutti i computer. Visualizza con `python3 .metrics/serve_metrics.py`. È necessario `python3`, funziona su macOS e Linux. Si usa quando l'utente dice "cài tracking session", "đo session Claude", "theo dõi token", "session metrics", "xem agent đã làm gì, tốn bao nhiêu", "mở trang metrics", o vuole confrontare lo sforzo tra diverse sessioni.
