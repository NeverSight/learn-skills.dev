プロジェクトにインストールして、Claude Code が実行する各セッションを記録する方法です — 各プロンプト、モデルやツールの呼び出し、時間、トークン、サブエージェント、スキル — そしてローカルのウェブページで閲覧します。インストールコマンドはスクリプト、サーバー、閲覧ページをプロジェクトの `.metrics/` にコピーし、`.claude/settings.json` にフックを追加し、他のフックは保持します；アップグレード時にフックが二重にならないように再インストールします。フックは各セッションを `.metrics/sessions/<id>.json` というファイルに記録し、シークレットを隠し、画像は除外します；ファイルは git で管理されるので、どのマシンでも pull すれば全マシンのセッションを閲覧できます。`python3 .metrics/serve_metrics.py` で閲覧します。`python3` が必要で、macOS と Linux で動作します。ユーザーが「セッショントラッキングをインストール」「Claude セッションを測定」「トークンを追跡」「セッションメトリクス」「エージェントが何をしたか、どれだけコストがかかったかを見る」「メトリクスページを開く」またはセッション間の労力を比較したいときに使用します。
