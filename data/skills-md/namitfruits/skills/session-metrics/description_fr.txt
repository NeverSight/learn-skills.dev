Installez dans un projet une méthode pour enregistrer chaque session Claude Code qui s’y exécute — chaque prompt, chaque appel au modèle et à l’outil, le temps, les tokens, le sous‑agent, la compétence — et visualisez‑les via une page web locale. La commande d’installation copie le script, le serveur, la page de visualisation dans `.metrics/` du projet et ajoute un hook dans `.claude/settings.json`, en conservant les autres hooks ; réinstallez pour mettre à jour sans dupliquer le hook. Le hook enregistre chaque session dans un fichier `.metrics/sessions/<id>.json`, masque les secrets, supprime les images ; le fichier étant suivi par git, n’importe quelle machine qui le récupère peut voir les sessions de toutes les machines. Visualisez avec `python3 .metrics/serve_metrics.py`. Nécessite `python3`, fonctionne sous macOS et Linux. Utilisé quand l’utilisateur dit « installer le suivi de session », « mesurer la session Claude », « suivre les tokens », « metrics de session », « voir ce que l’agent a fait, combien ça a coûté », « ouvrir la page metrics », ou veut comparer l’effort entre différentes sessions.
