Взаимодействуйте с пользователем, чтобы уточнить, чего он действительно хочет — только уточняйте, а не анализируйте. Начните с повторения запроса, чтобы пользователь мог исправить любые недоразумения, спросите о текущем состоянии (что уже есть в системе, чего не хватает), затем разбейте запрос на модули — основные модули берутся прямо из слов в запросе (например, «приложение для записи встреч с напоминаниями и оплатой» превращается в «Планирование встреч · Напоминания · Оплата»); если основному модулю чего‑то не хватает (например, для доступа требуются разрешения / логин), спросите пользователя, добавить ли дополнительный модуль — позвольте пользователю **выбирать галочками функции** для каждого модуля — выбранные пункты определяют объём работы — завершите общую картину, затем перейдите к каждому модулю: пользователь сначала рассказывает, агент задаёт вопросы о целях и возможных пробелах (что · кто · когда · что получаем в ответ · реальный пример), пока не сформируется чёткая картина, после чего перефразируйте её своими словами для подтверждения пользователем. Делайте вопросы с предустановленными вариантами ответов; спрашивайте о целях, не вдаваясь в боли пользователя; не фиксируйте численные значения, не разбирайте сценарии ошибок, не пишите пользовательские истории — это относится к более позднему этапу анализа. Создайте папку `.brainstorm/NNN-slug/`, содержащую файл описания `brief.md` на основе `templates/brief.md` и файл чек‑листа `checklist.md` на основе `templates/checklist.md`: каждая итерация продолжается, пока все пункты шага не будут закрыты, чек‑лист добавляет новые пункты при появлении новых модулей или функций, при прерывании читайте чек‑лист, чтобы продолжить. Включите `templates/modules.md` (рекомендованные функции для типовых модулей) и `scripts/verify.py` для проверки формата `brief` и чек‑листа. Используйте это, когда пользователь говорит «brainstorm», «давайте подумаем, чего я хочу», «уточните идею», «проведите интервью», «уточните требования» или предоставляет список функций вроде «я хочу сделать А, Б, В», не уточняя детали каждой.

Пожалуйста, всегда отвечайте на языке пользователя.
