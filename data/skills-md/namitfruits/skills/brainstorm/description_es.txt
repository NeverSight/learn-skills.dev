Interactúa con el usuario para aclarar lo que realmente quiere — solo aclarar, no analizar. Comienza reformulando el enunciado para que el usuario pueda corregir cualquier malentendido, pregunta sobre el estado actual (qué tiene el sistema, qué le falta), luego divide el enunciado en módulos — los módulos principales se toman directamente de las palabras del enunciado (p. ej., “app scheduling with reminders and payment” se convierte en Schedule · Reminder · Payment); si a los módulos principales les falta algo (p. ej., autorización requiere inicio de sesión) pregunta al usuario si se deben añadir módulos suplementarios — permite que el usuario **marque** las funcionalidades de cada módulo — las marcadas definen el alcance — finaliza la visión general, luego recorre cada módulo: el usuario narra primero, el agente pregunta sobre el objetivo y cualquier vacío (qué · quién · cuándo · qué se devuelve · un ejemplo real) hasta que se forme una imagen clara, luego repítela con nuestras propias palabras para que el usuario la confirme. Pregunta con opciones de respuesta predefinidas; pregunta por el objetivo, no indagues en puntos de dolor; no fijes números, no explores casos de error, no redactes historias de usuario — eso es para la fase de análisis posterior. Crea un directorio `.brainstorm/NNN‑slug/` que contenga un archivo breve `brief.md` basado en `templates/brief.md` y un archivo de lista de verificación `checklist.md` basado en `templates/checklist.md`: cada iteración continúa hasta que todos los ítems del paso estén cerrados, la lista de verificación añade nuevos ítems cuando aparece un nuevo módulo o funcionalidad, y si se interrumpe leer la lista de verificación para reanudar. Incluye `templates/modules.md` (funcionalidades sugeridas para módulos comunes) y `scripts/verify.py` para validar el brief y la lista de verificación. Usa esto cuando el usuario diga “brainstorm”, “let’s think about what I want”, “clarify the idea”, “interview me”, “clarify requirements”, o proporcione una lista de funcionalidades como “I want to do A, B, C” sin detalles claros para cada una.

Siempre responde en el idioma del usuario.
