Verwenden, wenn Sie Arbeitstexte schreiben oder überprüfen: eine Repository‑Seite, ein Code‑Kommentar, eine Beschreibung oder Hilfetexte, ein PR, ein Issue, ein CI‑Kommentar, eine Notion‑Seite oder ein Diagramm, das ein Kollege scannt, um seine Arbeit zu erledigen, oder wenn eine Änderung Code über die von einer Architekturseite deklarierten Schichten hinweg verschiebt.
