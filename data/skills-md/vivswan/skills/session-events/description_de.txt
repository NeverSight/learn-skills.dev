Verwenden Sie es, wenn eine Sitzung Ereignisse von einem beliebigen abgefragten System als Nachrichten statt als Abfragen erhalten muss, oder wenn Sie die Quelle schreiben, die das System abfragt, sodass ein von der Sitzung verwalteter Daemon die Alarme jeder Abfrage im Peer‑Envelope trägt, seine Notizen im Log führt und nichts aus dem abgefragten System zitiert.
