Используется, когда Codex на macOS должен управлять браузером Chromium пользователя (Brave, Vivaldi, Opera, Edge, Chrome) через встроенный плагин Chrome, либо когда этот плагин выдаёт ошибку «Codex auth token is unavailable», отсутствует соединение расширения или кэш плагина устарел после обновления настольного приложения. Только Codex.
