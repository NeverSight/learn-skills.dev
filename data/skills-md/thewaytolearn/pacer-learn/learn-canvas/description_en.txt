[Tool] Convert a video into a tldraw canvas. Two modes: (1) Segment-by-segment diagram using analysis.json, drawing only the truly important characters; (2) `map`: PACER C type “draw first, then check the answer” — only drop concept nodes without lines, the user connects them themselves, and after connecting runs /learn-digest to compare with the answer sheet. Use when the user says “draw it,” “understand through drawing,” “draw in tldraw,” “segment N,” or “I want to draw a map.”
