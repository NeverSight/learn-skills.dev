[Инструмент] Преобразовать видео в холст tldraw. Два режима: (1) Диаграмма по сегментам с использованием analysis.json, рисовать только действительно важные символы; (2) `map`: тип PACER C «сначала нарисовать, потом проверить ответ» — размещать только узлы концепций без линий, пользователь соединяет их сам, а после соединения запускает /learn-digest для сравнения с листом ответов. Использовать, когда пользователь говорит «нарисуй это», «понять через рисование», «рисовать в tldraw», «сегмент N» или «я хочу нарисовать карту». Пожалуйста, всегда отвечайте на языке пользователя.
