[Outil] Convertir une vidéo en canevas tldraw. Deux modes : (1) analyse de diagramme segment par segment .json, ne dessinant que les personnages vraiment importants ; (2) `map` : type PACER C « dessiner d’abord, puis vérifier les réponses » — ne déposer que les nœuds de concept sans lignes, laissant l’utilisateur les connecter lui‑même ; après connexion, exécuter /learn-digest do C pour comparer avec la feuille de réponses. Utilisé lorsque l’utilisateur dit « dessine‑le », « comprendre par le dessin », « dessiner dans tldraw », « segment N » ou « je veux dessiner une carte ».
