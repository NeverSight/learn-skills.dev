Se usa cuando un usuario publica un enlace de YouTube o la URL de un artículo de blog y solicita aprendizaje, organización, toma de notas o análisis textual. Orden general: primero estimar el costo de tiempo y la carga de trabajo pendiente, luego ejecutar secuencialmente obtener → segmentar → capturar → analizar → digerir → notas → renderizar para producir plan.html, ejercicios PACER y notas.
