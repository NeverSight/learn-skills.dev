Appliquer, examiner et expliquer les conventions fortement opinionées du Guide de style TypeScript. Utilisez‑les automatiquement uniquement lorsque les conventions TypeScript font partie de la tâche demandée, y compris la modélisation des types, les unions discriminées, les API de fonctions, les variables et l’état, la dénomination, l’organisation du code source, les props React, les API de composants, la gestion d’état, le flux de données ou les tests. Ne les utilisez pas uniquement pour le style ou la mise en page.

Veuillez toujours répondre dans la langue de l'utilisateur.
