Applica, revisiona e spiega le convenzioni soggettive presenti nella Guida di stile TypeScript. Utilizza automaticamente solo quando le convenzioni TypeScript fanno parte del compito richiesto, includendo modellazione dei tipi, unioni discriminanti, API di funzioni, variabili e stato, denominazione, organizzazione del codice, props di React, API dei componenti, gestione dello stato, flusso di dati o test. Non usare per stilizzazione o layout da solo.
