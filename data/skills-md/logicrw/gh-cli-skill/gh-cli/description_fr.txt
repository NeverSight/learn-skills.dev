Opérations GitHub CLI via la commande `gh`. Utilisez‑le lorsque vous travaillez avec des dépôts GitHub, des pull requests, des issues, la recherche de code, des releases, ou toute opération d’API GitHub. Cette compétence remplace le serveur GitHub MCP par des appels CLI directs. Déclencheurs : GitHub, PR, pull request, issue, repo, branch, release, tag, commit, fork, merge, review, gh.
