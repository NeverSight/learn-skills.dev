Операции GitHub CLI через команду `gh`. Используйте при работе с репозиториями GitHub, пул‑запросами, issue, поиском кода, релизами или любой операцией GitHub API. Этот навык заменяет сервер GitHub MCP прямыми вызовами CLI. Срабатывает на: GitHub, PR, pull request, issue, repo, branch, release, tag, commit, fork, merge, review, gh.
