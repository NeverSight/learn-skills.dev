Ejecuta la CLI real `10x` (@przeprogramowani/10x-cli) de extremo a extremo como lo haría un aprendiz — login, list, get, sync, changelog, doctor — contra una API local simulada de entrega con configuración y directorios de proyecto aislados, y captura stdout/stderr/códigos de salida, pantallas PTY y hashes del árbol de archivos como prueba. Úsala después de modificar un comando, el escritor, el manejo de conflictos, la autenticación o el cliente API, cuando las pruebas unitarias pasan pero necesitas ver el comportamiento entregado, o cuando te pidan “verificar”, “ejecutar la CLI”, “demostrar que funciona”.
