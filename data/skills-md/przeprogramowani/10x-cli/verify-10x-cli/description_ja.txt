学習者が行うように、実際の `10x` CLI（@przeprogramowani/10x-cli）をエンドツーエンドで駆動し、ログイン、リスト、取得、同期、変更履歴、doctor などの操作をローカルのフェイク配信 API に対して実行し、設定とプロジェクトディレクトリを分離した状態で、stdout・stderr・終了コード、PTY 画面、ファイルツリーのハッシュを証拠として取得します。コマンドやライター、競合処理、認証、API クライアントを変更した後、ユニットテストは通っていても実際の挙動を確認したいとき、あるいは「検証して」「CLI を実行して」「動作を証明して」と求められたときに使用します。
