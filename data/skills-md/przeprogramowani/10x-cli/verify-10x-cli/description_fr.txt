Pilotez le véritable CLI `10x` (@przeprogramowani/10x-cli) de bout en bout comme le ferait un apprenant — connexion, liste, récupération, synchronisation, journal des modifications, doctor — contre une API de livraison factice locale avec des configurations et répertoires de projet isolés, et capturez les sorties stdout/stderr, les codes de sortie, les écrans PTY et les hachages de l'arborescence de fichiers comme preuve. Utilisez‑le après avoir modifié une commande, le rédacteur, la gestion des conflits, l'authentification ou le client API, lorsque les tests unitaires passent mais que vous devez voir le comportement livré, ou lorsqu'on vous demande de « vérifier », « exécuter le CLI », « prouver que cela fonctionne ».
