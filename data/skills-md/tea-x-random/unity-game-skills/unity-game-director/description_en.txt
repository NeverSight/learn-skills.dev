Primary entrypoint for building casual iOS games in Unity. Use by default for any Unity work: build-a-game, prototype, vertical slice, upgrade, polish, premium, 2D or 3D casual, hyper-casual, puzzle, runner, arcade, release-ready, or App Store requests. Triggers when the working directory is a Unity project (Assets/, ProjectSettings/, Packages/manifest.json present). Detects the Unity version, drives the Unity Editor through the unity-mcp-bridge skill, routes through gameplay/layout/composition/graphics/UI/audio/3D/2D-asset/asset-pipeline/debug/QA phases, and verifies a real playable slice with Play Mode tests and screenshots instead of producing only design docs. Loads sibling unity-* skills so the user does not pick skills manually.
