Generate and edit STATIC non-pixel 2D image assets for Unity casual games using Google's Gemini image API, then import them as sprites/textures/UI. Use for exploratory/concept art, style boards, non-pixel static sprites, backgrounds, tile/ground art, tiling textures, UI panels, buttons, icons, logos, title/menu art, particle textures, material/texture references, and high-quality image-to-3D references. For PIXEL ART final assets (low-res sprites, tilesets, directional sheets, animation strips), use unity-pixel-art/PixelLab instead; Gemini may only explore concepts. For non-pixel ANIMATED/motion assets prefer Tripo (unity-3d-generator) to rig + animate, then pre-render only for high-res/painterly 2D — never downscale 3D into pixel art. Covers Unity 2D import: Sprite mode, pixels-per-unit, filtering, sprite atlas, and ASTC for iOS.
