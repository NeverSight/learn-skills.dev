Nur‑Lese‑Planung für ein Ticket im Projekt‑Issue‑Tracker. Ruft das Ticket (und ggf. verknüpften übergeordneten Ticket) ab, durchsucht relevanten Code und wechselt dann in den Planungsmodus mit einem strukturierten Plan, der einen expliziten Ansatz (RGR oder direkt) deklariert. Verwenden, wenn der Benutzer /plan-work mit einer Ticketreferenz eingibt oder beim Planen eines Tickets, bevor es manuell implementiert wird.
