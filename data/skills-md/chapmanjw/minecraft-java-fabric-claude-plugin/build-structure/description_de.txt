Orchestriert eine einzelne benannte oder eigenständige Struktur und den Untergrund, auf dem sie steht, in einer realen Minecraft-Java-Welt – ein Gebäude, eine reale oder fiktive Nachbildung, eine Statue oder ein Denkmal, ein Spielerhaus oder eine Brücke als Objekt. Sequenzen von Entwurf, Planung, Blaupause, Bau, Einstufung und einem Integrationsdurchgang, sodass die Struktur als zu ihrem Standort gehörend wahrgenommen wird und nicht darauf abgelegt wird. Tier-2-Orchestrator (verwaltet den Fall, dass die nicht-triviale Regel einen erstklassigen Pfad ergibt).
