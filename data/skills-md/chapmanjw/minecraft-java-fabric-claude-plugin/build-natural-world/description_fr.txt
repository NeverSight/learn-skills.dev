Orchestre un paysage ou une région principalement naturelle dans un monde Java Minecraft en direct : terrain, reliefs, biomes, eau, paysages naturels, merveilles naturelles nommées et grottes conçues. Séquence les compétences des feuilles de terrain et enchaîne un contexte de cohérence partagé (une donnée, une recette continue, une palette, un biome + plan de dispersion, une passe d'intégration) de sorte que le résultat se lit comme un seul lieu cohérent. Utilisation pour les canyons, les montagnes, les îles, les côtes, les vallées fluviales, les forêts, les systèmes de grottes et les reconstitutions de merveilles naturelles. Orchestrateur de niveau 2.
