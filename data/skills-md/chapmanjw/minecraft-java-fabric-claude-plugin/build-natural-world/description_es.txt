Orquesta un paisaje o región principalmente natural en un mundo Java de Minecraft en vivo: terreno, accidentes geográficos, biomas, agua, paisajes naturales, maravillas naturales con nombre y cuevas diseñadas. Secuencia las habilidades de hoja del terreno y enhebra un contexto de coherencia compartido (un dato, una receta continua, una paleta, un bioma+plan de dispersión, un pase de integración) para que el resultado se lea como un lugar coherente. Úselo para cañones, montañas, islas, costas, valles fluviales, bosques, sistemas de cuevas y recreaciones de maravillas naturales. Orquestador de nivel 2.
