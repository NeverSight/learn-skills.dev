ينسق منظرًا طبيعيًا أو منطقة طبيعية في المقام الأول في عالم Minecraft Java المباشر - التضاريس والتضاريس والمناطق الأحيائية والمياه والمناظر الطبيعية والعجائب الطبيعية المسماة والكهوف المصممة. يقوم بتسلسل مهارات ورقة التضاريس وخيوط سياق تماسك مشترك واحد (مرجع واحد، وصفة واحدة مستمرة، لوحة واحدة، منطقة حيوية واحدة + خطة مبعثرة، تمريرة تكامل واحدة) بحيث تُقرأ النتيجة كمكان واحد متماسك. يُستخدم في الأخاديد والجبال والجزر والسواحل ووديان الأنهار والغابات وأنظمة الكهوف وإعادة إنتاج العجائب الطبيعية. منسق من الدرجة الثانية.
