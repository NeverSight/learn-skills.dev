Управляет преимущественно природным ландшафтом или регионом в живом мире Minecraft Java — местностью, формами рельефа, биомами, водой, природными пейзажами, названными чудесами природы и спроектированными пещерами. Упорядочивает навыки листа ландшафта и объединяет один общий контекст связности (одна база данных, один непрерывный рецепт, одна палитра, один биом + план разброса, один проход интеграции), поэтому результат читается как одно связное место. Используйте для каньонов, гор, островов, береговых линий, речных долин, лесов, пещерных систем и воссозданий чудес природы. Оркестратор второго уровня.
