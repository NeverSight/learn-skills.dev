Orchestra un paesaggio o una regione prevalentemente naturale in un mondo Java Minecraft dal vivo: terreno, morfologie, biomi, acqua, scenari naturali, meraviglie naturali con nomi e grotte progettate. Mette in sequenza le abilità delle foglie del terreno e intreccia un contesto di coerenza condiviso (un dato, una ricetta continua, una tavolozza, un piano bioma+dispersione, un passaggio di integrazione) in modo che il risultato venga letto come un luogo coerente. Utilizzare per canyon, montagne, isole, coste, valli fluviali, foreste, sistemi di grotte e riproduzioni di meraviglie naturali. Orchestratore di livello 2.
