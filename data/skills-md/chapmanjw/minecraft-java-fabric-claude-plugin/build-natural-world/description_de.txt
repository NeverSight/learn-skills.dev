Orchestriert eine hauptsächlich natürliche Landschaft oder Region in einer Live-Minecraft-Java-Welt – Gelände, Landformen, Biome, Wasser, Naturlandschaften, benannte Naturwunder und gestaltete Höhlen. Sequenziert die Terrain-Blatt-Fertigkeiten und verfeinert einen gemeinsamen Kohärenzkontext (ein Datum, ein kontinuierliches Rezept, eine Palette, ein Biom+Streuungsplan, ein Integrationsdurchgang), sodass das Ergebnis als ein kohärenter Ort gelesen wird. Verwendung für Schluchten, Berge, Inseln, Küsten, Flusstäler, Wälder, Höhlensysteme und Nachbildungen von Naturwundern. Tier-2-Orchestrator.
