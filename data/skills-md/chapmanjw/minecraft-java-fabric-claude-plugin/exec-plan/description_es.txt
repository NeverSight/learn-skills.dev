Captura los requisitos de construcción para un mundo de Minecraft Java Edition, entrevista al usuario para resolver ambigüedades y produce un plan de construcción detallado y completamente resuelto que un modelo pequeño puede ejecutar mecánicamente. Úselo al iniciar una nueva construcción o característica de Minecraft, o cuando una solicitud de construcción debe convertirse en un plano concreto antes de colocar cualquier bloque. Parte del flujo de trabajo de Minecraft-Builder.
