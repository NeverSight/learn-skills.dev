Cattura i requisiti di costruzione per un mondo Minecraft Java Edition, intervista l'utente per risolvere l'ambiguità e produce un piano di costruzione dettagliato e completamente risolto che un piccolo modello può eseguire meccanicamente. Da utilizzare quando si avvia una nuova build o funzionalità di Minecraft o quando una richiesta di build deve essere trasformata in un piano concreto prima che vengano posizionati i blocchi. Parte del flusso di lavoro di Minecraft-Builder.
