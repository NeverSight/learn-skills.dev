Собирает требования к сборке для мира Minecraft Java Edition, опрашивает пользователя, чтобы устранить двусмысленность, и создает подробный, полностью решенный план сборки, который небольшая модель может выполнить механически. Используйте при запуске новой сборки или функции Minecraft, а также когда запрос на сборку необходимо превратить в конкретный план перед размещением каких-либо блоков. Часть рабочего процесса Minecraft-Builder.
