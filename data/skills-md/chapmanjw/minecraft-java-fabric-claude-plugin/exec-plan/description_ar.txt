يلتقط متطلبات البناء لعالم Minecraft Java Edition، ويجري مقابلات مع المستخدم لحل الغموض، وينتج خطة بناء مفصلة ومحلولة بالكامل يمكن لنموذج صغير تنفيذها ميكانيكيًا. يُستخدم عند بدء بناء أو ميزة جديدة في لعبة Minecraft، أو عندما يجب تحويل طلب البناء إلى خطة ملموسة قبل وضع أي كتل. جزء من سير عمل ماين كرافت.
