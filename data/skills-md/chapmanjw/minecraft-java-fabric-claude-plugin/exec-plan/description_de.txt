Erfasst die Build-Anforderungen für eine Minecraft Java Edition-Welt, befragt den Benutzer, um Unklarheiten auszuräumen, und erstellt einen detaillierten, vollständig gelösten Build-Plan, den ein kleines Modell mechanisch ausführen kann. Verwenden Sie diese Option, wenn Sie mit einem neuen Minecraft-Build oder einer neuen Funktion beginnen oder wenn eine Build-Anfrage in einen konkreten Plan umgewandelt werden muss, bevor Blöcke platziert werden. Teil des Minecraft-Builder-Workflows.
