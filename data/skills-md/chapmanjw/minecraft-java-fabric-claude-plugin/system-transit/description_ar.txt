قم بتصميم وتخطيط شبكات النقل والبنية التحتية الممتدة على مستوى العالم في عالم Minecraft Java Edition المباشر - خطوط السكك الحديدية والطرق والطرق السريعة والعبور السفلي والجسور والأنفاق والمصاعد والأرصفة والمطارات - الشبكة المتصلة بين المباني المنفصلة. يختار طوبولوجيا الشبكة ويوجه الروابط. يُستخدم عندما يريد المستخدم ربط موقعين أو أكثر، أو إنشاء شبكة نقل، أو مركز سفلي، أو طريق سريع، أو جسر، أو نفق، أو خط سكة حديد بين الأماكن. جزء من سير عمل ماين كرافت.
