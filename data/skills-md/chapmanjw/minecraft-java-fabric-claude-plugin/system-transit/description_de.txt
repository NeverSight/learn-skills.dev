Entwirft und entwirft weltumspannende Verkehrs- und Infrastrukturnetzwerke in einer Live-Welt der Minecraft Java Edition – Eisenbahnlinien, Straßen und Autobahnen, Nahverkehrsknotenpunkte, Brücken, Tunnel, Aufzüge, Docks und Flughäfen – das Verbindungsnetzwerk zwischen einzelnen Gebäuden. Wählt die Netzwerktopologie und leitet die Links weiter. Verwenden Sie diese Option, wenn der Benutzer zwei oder mehr Standorte verbinden, ein Verkehrsnetz, einen Nether-Hub, eine Autobahn, eine Brücke, einen Tunnel oder eine Eisenbahnlinie zwischen Orten bauen möchte. Teil des Minecraft-Builder-Workflows.
