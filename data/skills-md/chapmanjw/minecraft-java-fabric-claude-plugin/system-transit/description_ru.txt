Проектирует и проектирует транспортные и инфраструктурные сети, охватывающие весь мир, в реальном мире Minecraft Java Edition — железнодорожные линии, дороги и автомагистрали, транзитные узлы, мосты, туннели, лифты, доки и аэропорты — соединительную сеть между отдельными зданиями. Выбирает топологию сети и маршрутизирует ссылки. Используйте, когда пользователь хочет соединить два или более объекта, построить транзитную сеть, узел, шоссе, мост, туннель или железнодорожную линию между местами. Часть рабочего процесса Minecraft-Builder.
