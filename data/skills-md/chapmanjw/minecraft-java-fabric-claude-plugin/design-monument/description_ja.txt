Minecraft Java Edition のライブ ワールドで、巨大な彫像、有機生物やドラゴン、抽象的な彫刻、ピクセル アートや壁画、大きな 3D テキストやロゴなどの記念碑、彫刻、ビルド アートをデザインおよび設計します。ピクセル グリッド イメージ マッピング、有機的な曲線の構築、パレット グラデーション マッピング、およびアーマー スタンドのディテールを使用して、居住可能な内部を持たない固体またはシェルのみの比喩的なフォームを生成します。ユーザーが彫像、彫刻、記念碑、記念碑、壁画、ピクセル アート、ロゴ、巨大なテキスト、または大きな生き物を必要とする場合に使用します。 Minecraft ビルダーのワークフローの一部。
