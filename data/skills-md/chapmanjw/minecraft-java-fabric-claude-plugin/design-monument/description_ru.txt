Проектирует и чертит памятники, скульптуры и произведения искусства в живом мире Minecraft Java Edition — гигантские статуи, органические существа и драконы, абстрактные скульптуры, пиксельная графика и фрески, большой 3D-текст и логотипы. Создает твердые фигуративные формы или только оболочки без обитаемых интерьеров, используя отображение изображений в виде пиксельной сетки, построение органических кривых, отображение градиента палитры и детализацию подставок для брони. Используйте, когда пользователю нужна статуя, скульптура, памятник, мемориал, фреска, пиксельная графика, логотип, гигантский текст или большое существо. Часть рабочего процесса Minecraft-Builder.
