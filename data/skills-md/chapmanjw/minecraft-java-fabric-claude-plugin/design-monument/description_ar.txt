تصميمات ومخططات للآثار والمنحوتات والأعمال الفنية في عالم Minecraft Java Edition المباشر - تماثيل عملاقة ومخلوقات عضوية وتنانين ومنحوتات مجردة وفن بكسل وجداريات ونصوص وشعارات ثلاثية الأبعاد كبيرة. تنتج أشكالًا مجسمة صلبة أو صدفية فقط بدون تصميمات داخلية صالحة للسكن، باستخدام رسم خرائط الصور على شبكة البكسل، وبناء المنحنى العضوي، ورسم خرائط متدرجة الألوان، وتفاصيل حامل الدروع. يُستخدم عندما يريد المستخدم تمثالًا أو منحوتة أو نصبًا تذكاريًا أو جدارية أو فن بيكسل أو شعارًا أو نصًا عملاقًا أو مخلوقًا كبيرًا. جزء من سير عمل ماين كرافت.
