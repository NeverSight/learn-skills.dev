Авторы создают натуралистический ландшафт в реальном мире Minecraft Java — горы, долины, холмы, реки, озера, береговые линии, острова, плато — как один непрерывный рецепт графа сэмплера, проверяет его в автономном режиме и генерирует исполняемые фазы. Создает эродированный, материализованный маской, смешанный с биомом ландшафт, который читается как настоящий, а не сложенный друг в друга прямоугольниками или террасными зиккуратами. Лист уровня 3, вызываемый оркестраторами build-* (ранее: терраформирование).
