الخطوة 4 من 4 لإعداد Minecraft Java MCP. قم بتسجيل خادم minecraft-java MCP قيد التشغيل (Fabric mod) مع Claude (Claude Code أو Claude Desktop) حتى تصبح أدوات Java العالمية متاحة، ثم تحقق من الاتصال من خلال مكالمة اختبار مباشرة. يُستخدم عندما يكون خادم MCP قيد التشغيل ويحتاج إلى توصيل Claude بعالم Minecraft الخاص به.
