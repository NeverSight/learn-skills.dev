Passaggio 4 di 4 della configurazione dell'MCP Java di Minecraft. Registra il server MCP minecraft-java in esecuzione (il mod Fabric) con Claude (Claude Code o Claude Desktop) in modo che gli strumenti del mondo Java diventino disponibili, quindi verifica la connessione con una chiamata di prova dal vivo. Da utilizzare quando l'utente ha il server MCP in esecuzione e deve connettere Claude al proprio mondo Minecraft.
