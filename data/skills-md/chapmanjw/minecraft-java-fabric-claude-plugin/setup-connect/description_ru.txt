Шаг 4 из 4 настройки MCP для Minecraft Java. Зарегистрируйте работающий сервер minecraft‑java MCP (мод Fabric) в Claude (Claude Code или Claude Desktop), чтобы инструменты Java‑мира стали доступны, затем проверьте соединение с помощью живого тестового вызова. Используйте, когда пользователь уже запустил сервер MCP и нужно подключить Claude к его миру Minecraft.
