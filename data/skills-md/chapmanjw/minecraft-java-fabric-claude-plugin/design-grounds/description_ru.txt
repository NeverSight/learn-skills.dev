Проекты и чертежи специально спроектированы для открытого пространства в живом мире Minecraft Java Edition — формальные сады, парки, площади, дворы, лабиринты из живой изгороди, фонтаны, партеры, топиарии, монастырские сады, усадьбы. Охватывает французские формальные, итальянские, английские пейзажные, могольские, японские, китайские, модернистские и другие традиции. Геометричность и намеренность — преднамеренный аналог натуралистического навыка формирования формы местности. Используйте, когда пользователю нужен сад, парк, площадь, двор, лабиринт из живой изгороди, фонтан или спроектированная территория. Часть рабочего процесса Minecraft-Builder.
