Entwürfe und Blaupausen haben absichtlich Außenbereiche in einer lebendigen Minecraft Java Edition-Welt entworfen – formelle Gärten, Parks, Plätze, Innenhöfe, Heckenlabyrinthe, Springbrunnen, Parterres, Formschnitte, Klostergärten, Anwesen. Deckt französische formale, italienische, englische Landschafts-, Mogul-, japanische, chinesische, modernistische und andere Traditionen ab. Geometrisch und absichtlich – das bewusste Gegenstück zur naturalistischen Geländeformfähigkeit. Verwenden Sie es, wenn der Benutzer einen Garten, einen Park, einen Platz, einen Innenhof, ein Heckenlabyrinth, einen Brunnen oder ein gestaltetes Gelände wünscht. Teil des Minecraft-Builder-Workflows.
