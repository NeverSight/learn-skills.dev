Disegni e progetti progettati intenzionalmente per spazi esterni in un mondo live di Minecraft Java Edition: giardini formali, parchi, piazze, cortili, labirinti di siepi, fontane, parterre, arte topiaria, giardini di chiostri, terreni di proprietà. Copre le tradizioni formali francesi, italiane, inglesi, moghul, giapponesi, cinesi, moderniste e altre. Geometrico e intenzionale: la controparte deliberata dell'abilità naturalistica di modellazione del terreno. Utilizzare quando l'utente desidera un giardino, un parco, una piazza, un cortile, un labirinto di siepi, una fontana o un terreno progettato. Parte del flusso di lavoro di Minecraft-Builder.
