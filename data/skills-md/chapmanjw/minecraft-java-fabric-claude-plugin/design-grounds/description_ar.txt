تصميمات ومخططات لمساحة خارجية مصممة عمدًا في عالم Minecraft Java Edition المباشر - حدائق رسمية، ومتنزهات، وساحات، وأفنية، ومتاهات التحوط، ونوافير، وحدائق، وحدائق توبياري، وحدائق الدير، وأراضي العقارات. يغطي التقاليد الفرنسية الرسمية، والإيطالية، والإنجليزية، والمغولية، واليابانية، والصينية، والحداثية، وغيرها من التقاليد. هندسية ومتعمدة - النظير المتعمد لمهارة شكل التضاريس الطبيعية. يُستخدم عندما يريد المستخدم حديقة أو متنزهًا أو ساحة عامة أو ساحة فناء أو متاهة سياج أو نافورة أو أراضي مصممة. جزء من سير عمل ماين كرافت.
