Minecraft Java Edition のライブ ワールドで複雑なレッドストーンや機械仕掛けを設計、計画、検証します。これには、アイテム仕分け機、隠しドアとピストン ドア、自動農場、Mob スポナー コレクター、トロッコ ネットワークとジェット コースター、水と泡のエレベーター、音符ブロックの音楽、トラップ、装飾機械などがあります。 Java の修正: Java レッドストーンの仕組み (疑似接続、決定論的なタイミング) を使用し、パッチアウトされたトリックを回避します。設計には、機能的なインワールド検証と自動修正が組み込まれて出荷されます。ユーザーがレッドストーン ビルド、自動農場、仕掛け、または動作する機械を必要とする場合に使用します。 Minecraft ビルダーのワークフローの一部。
