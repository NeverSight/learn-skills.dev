Progetta, pianifica e verifica complessi congegni meccanici e pietre rosse in un mondo live di Minecraft Java Edition: selezionatori di oggetti, porte nascoste e a pistoni, fattorie automatiche, raccoglitori di spawner di mob, reti di carrelli da miniera e montagne russe, ascensori per acqua e bolle, musica con blocchi di note, trappole e macchine decorative. Java corretto: utilizza la meccanica Java redstone (quasi connettività, tempistica deterministica) ed evita trucchi corretti. I progetti vengono forniti con verifica funzionale nel mondo e correzione automatizzata. Da utilizzare quando l'utente desidera una costruzione in pietra rossa, una fattoria automatica, un aggeggio o qualsiasi macchina funzionante. Parte del flusso di lavoro di Minecraft-Builder.
