Проектирует, планирует и проверяет сложные конструкции из красного камня и механические приспособления в реальном мире Minecraft Java Edition — сортировщики предметов, скрытые и поршневые двери, автоматические фермы, сборщики мобов, сети вагонеток и американские горки, водные и пузырьковые лифты, музыкальные блокноты, ловушки и декоративные машины. Java-корректно: использует механику Java Redstone (квазисвязность, детерминированное время) и избегает устаревших трюков. Проекты поставляются с функциональной проверкой в ​​реальном времени и автоматической коррекцией. Используйте, когда пользователю нужна сборка из красного камня, автоматическая ферма, хитрое приспособление или любая работающая машина. Часть рабочего процесса Minecraft-Builder.
