Passaggio 2 di 4 della configurazione dell'MCP Java di Minecraft. Scarica il mod jar MCP minecraft-java e il relativo jar API Fabric corrispondente e installali entrambi nella cartella mod di Minecraft. Da utilizzare quando l'utente ha Minecraft Java con il caricatore Fabric pronto e necessita dell'installazione della mod MCP e dell'API Fabric.
