Passaggio 3 di 4 della configurazione dell'MCP Java di Minecraft. Configura il config.json della mod MCP (host, porta, autenticazione, categorie di strumenti), avvia Minecraft o il server dedicato, verifica che il server MCP incorporato sia in ascolto su /healthz e acquisisci il token di connessione per le configurazioni remote. Da utilizzare quando l'utente ha la mod MCP e l'API Fabric installate e necessita che il server MCP sia configurato e in esecuzione.
