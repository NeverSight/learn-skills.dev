الخطوة 3 من 4 لإعداد Minecraft Java MCP. قم بتكوين config.json الخاص بـ MCP mod (المضيف، المنفذ، المصادقة، فئات الأدوات)، قم بتشغيل Minecraft أو الخادم المخصص، وتحقق من أن خادم MCP المضمن يستمع إلى /healthz، والتقط الرمز المميز للحامل للإعدادات عن بعد. يُستخدم عندما يكون لدى المستخدم تعديل MCP وFabric API مثبتًا ويحتاج إلى تكوين خادم MCP وتشغيله.
