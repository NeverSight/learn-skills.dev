Paso 3 de 4 de la configuración de Minecraft Java MCP. Configure el config.json del mod MCP (host, puerto, autenticación, categorías de herramientas), inicie Minecraft o el servidor dedicado, verifique que el servidor MCP integrado esté escuchando en /healthz y capture el token de portador para configuraciones remotas. Úselo cuando el usuario tiene instalado el mod MCP y la API Fabric y necesita el servidor MCP configurado y en ejecución.
