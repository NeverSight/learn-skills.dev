Шаг 3 из 4 настройки Minecraft Java MCP. Настройте config.json мода MCP (хост, порт, аутентификация, категории инструментов), запустите Minecraft или выделенный сервер, убедитесь, что встроенный сервер MCP прослушивает /healthz, и запишите токен носителя для удаленных настроек. Используйте, когда у пользователя установлен мод MCP и API Fabric, и ему необходимо настроить и запустить сервер MCP.
