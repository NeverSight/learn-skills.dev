Étape 3 sur 4 de la configuration de Minecraft Java MCP. Configurez le config.json du mod MCP (hôte, port, authentification, catégories d'outils), lancez Minecraft ou le serveur dédié, vérifiez que le serveur MCP intégré écoute sur /healthz et capturez le jeton du porteur pour les configurations à distance. À utiliser lorsque l'utilisateur a installé le mod MCP et l'API Fabric et a besoin que le serveur MCP soit configuré et en cours d'exécution.
