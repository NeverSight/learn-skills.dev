Превращает план сборки Minecraft в именованные, многократно используемые определения структуры, сохраняемые внутри мира, поэтому элементы сборки можно размещать, копировать и повторять позже без какого-либо внешнего состояния. Используйте после планирования для создания или обновления библиотеки структур для сборки. Часть рабочего процесса Minecraft-Builder.
