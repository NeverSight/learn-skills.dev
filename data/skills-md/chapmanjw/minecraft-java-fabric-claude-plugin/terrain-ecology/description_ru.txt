Проектирует посадку и экологию биома готовой местности в живом мире Minecraft Java — какие растительные сообщества где растут, смешение видов, плотность и переходы экотонов — и выдает рецепт разброса. Используйте после назначения формы ландшафта + биома, чтобы украсить ландшафт растительностью, которая воспринимается как настоящая экосистема, а не как однородная посыпка. Лист уровня 3, вызываемый build-natural-world/build-settlement.
