يصمم بيئة الزراعة والبيئة الحيوية للتضاريس النهائية في عالم Minecraft Java المباشر - ما هي مجتمعات النباتات التي تنمو فيها، واختلاط الأنواع، والكثافات، والتحولات البيئية - وتصدر الوصفة المبعثرة. استخدم بعد شكل التضاريس + تخصيص المنطقة الحيوية، لتزيين المناظر الطبيعية بالنباتات التي يمكن قراءتها كنظام بيئي حقيقي بدلاً من رش موحد. ورقة الطبقة 3، التي تم استدعاؤها بواسطة بناء العالم الطبيعي / بناء التسوية.
