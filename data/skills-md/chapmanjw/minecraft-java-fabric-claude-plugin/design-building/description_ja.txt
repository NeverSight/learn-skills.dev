深い調査、高度な建築技術、定義された構造モジュールの多用な再利用により、Minecraft Java Edition のライブ ワールド内で特定の名前の付いた建物や複合建築物 (現実世界のレプリカ (歴史的および現代)、ポップ カルチャーのレプリカ (ホグワーツ、ミナス ティリス)、ユーザー記述のオリジナル、生成スタイルの架空の建物) を設計および青写真で作成します。ユーザーが建物に名前を付ける場合、レクリエーションやレプリカを要求する場合、「のスタイル」のものを要求する場合、または建築タイプ (大聖堂、城、寺院、宮殿、高層ビル、要塞、記念碑) に名前を付ける場合に使用します。 Minecraft ビルダーのワークフローの一部。
