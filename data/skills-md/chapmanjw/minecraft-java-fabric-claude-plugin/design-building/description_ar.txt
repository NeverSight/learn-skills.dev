تصميمات ومخططات مباني محددة ومجمعات بناء محددة في عالم Minecraft Java Edition المباشر - نسخ طبق الأصل من العالم الحقيقي (التاريخية والحديثة)، نسخ طبق الأصل من الثقافة الشعبية (Hogwarts، Minas Tirith)، نسخ أصلية وصفها المستخدم، ومباني خيالية ذات نمط توليدي - مع بحث عميق وتقنية بناء متقدمة وإعادة استخدام مكثف لوحدات البنية المحددة. يُستخدم عندما يقوم المستخدم بتسمية مبنى، أو يطلب إعادة إنشاء أو نسخة طبق الأصل، أو يطلب شيئًا "على طراز"، أو يسمي نوعًا معماريًا (كاتدرائية، قلعة، معبد، قصر، ناطحة سحاب، حصن، نصب تذكاري). جزء من سير عمل ماين كرافت.
