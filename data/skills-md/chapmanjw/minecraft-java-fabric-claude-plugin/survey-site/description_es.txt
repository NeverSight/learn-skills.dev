Investiga el estado actual de un mundo de Minecraft Java Edition: terreno, biomas, estructuras y construcciones existentes, entorno del jugador y cualquier otra cosa necesaria para fundamentar un plan de construcción. Úselo antes de planificar una construcción, o cada vez que el usuario pregunte qué hay en el mundo, qué hay a su alrededor o dónde hay espacio para construir. Parte del flujo de trabajo de Minecraft-Builder.
