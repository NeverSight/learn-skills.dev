Esamina lo stato attuale di un mondo di Minecraft Java Edition: terreno, biomi, strutture e costruzioni esistenti, ambiente del giocatore e qualsiasi altra cosa necessaria per fondare un piano di costruzione. Utilizzare prima di pianificare una costruzione o ogni volta che l'utente chiede cosa c'è nel mondo, cosa c'è intorno a sé o dove c'è spazio per costruire. Parte del flusso di lavoro di Minecraft-Builder.
