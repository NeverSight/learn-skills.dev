Orchestra un sistema funzionante o connettivo in un mondo Java Minecraft dal vivo: un aggeggio in pietra rossa o una fattoria automatica, una linea di transito, un hub del Nether, un meccanismo, insieme al suo alloggiamento e al diritto di precedenza. Progettazione delle sequenze, verifica funzionale, costruzione, tagli/pendenze del terreno di cui ha bisogno e un passaggio di integrazione in modo che la macchina funzioni E si trovi nel mondo senza cuciture grezze. Orchestratore di livello 2.
