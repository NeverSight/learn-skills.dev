Diseña espacios subterráneos deliberados en un mundo vivo de Minecraft Java (sistemas de cuevas, salas de cavernas, barrancos, tubos de lava, minas, bóvedas y los alrededores de una base subterránea) a diferencia de las cuevas de vainilla aleatorias que el mundo ya tiene. Talla vacíos intencionales con una entrada, ruta y cámaras conocidas y dimensionadas para un propósito, luego los reviste (estratos, estalactitas, líquenes, agua). Hoja de nivel 3, invocada por build-natural-world / build-structure / build-settlement.
