Создает продуманное подземное пространство в реальном мире Minecraft Java — системы пещер, пещерные залы, овраги, лавовые трубы, шахты, хранилища и окрестности подземной базы — в отличие от случайных ванильных пещер, которые уже есть в мире. Вырезает намеренные пустоты с известным входом, маршрутом и камерами определенного размера, а затем обрабатывает их (пласты, капельный камень, лишайник, вода). Лист уровня 3, вызываемый build-natural-world / build-structure / build-settlement.
