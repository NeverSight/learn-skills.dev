Progetta uno spazio sotterraneo deliberato in un mondo Java di Minecraft dal vivo - sistemi di caverne, sale di caverne, burroni, tubi di lava, miniere, volte e dintorni di una base sotterranea - in contrasto con le caverne di vaniglia casuali che il mondo già possiede. Scolpisce vuoti intenzionali con un ingresso, un percorso e camere dimensionati per uno scopo noti, quindi li riveste (strati, gocciolamenti, licheni, acqua). Foglia di livello 3, invocata da build-natural-world / build-structure / build-settlement.
