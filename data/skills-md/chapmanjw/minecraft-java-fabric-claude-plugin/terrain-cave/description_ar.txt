تصميمات مخصصة لمساحة جوفية في عالم Minecraft Java المباشر - أنظمة الكهوف، وقاعات الكهوف، والوديان، وأنابيب الحمم البركانية، والمناجم، والأقبية، والمناطق المحيطة بقاعدة تحت الأرض - على عكس كهوف الفانيليا العشوائية الموجودة في العالم بالفعل. ينحت فراغات مقصودة بمدخل وطريق وغرف معروفة الحجم لغرض ما، ثم يكسوها (الطبقات، حجر التنقيط، الأشنة، الماء). ورقة المستوى 3، التي يتم استدعاؤها من خلال بناء العالم الطبيعي / بناء الهيكل / بناء التسوية.
