يقوم بربط البناء النهائي بعالم Minecraft Java المحيط به بحيث يُقرأ على أنه ينتمي هناك، ولا يتم إسقاطه - يؤدي إلى تآكل المئزر حول أثر البناء مع حماية البناء نفسه، ثم إعادة تجسيد المئزر ليتناسب مع اللوحة المحيطة (تنورة الكاحل الآلية). كما يقوم بتطبيع تضاريس الفانيليا الموجودة. تعمل كبوابة التكامل المطلوبة بعد أي بناء يحمل بصمة القدم. ورقة الطبقة 3.
