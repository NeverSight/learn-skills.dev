Conecta una construcción terminada al mundo circundante de Minecraft Java para que se lea como si perteneciera allí, no para dejarla caer: erosiona un delantal alrededor de la huella de la construcción mientras protege la construcción misma, luego vuelve a materializar el delantal para que coincida con la paleta circundante (el faldón de talud programático). También naturaliza el terreno vainilla existente. Se ejecuta como la puerta Integrate requerida después de cualquier construcción con huella. Hoja de nivel 3.
