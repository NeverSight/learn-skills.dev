バイオームとユーザーの要求に適合した標準の Minecraft 村の建物タイプを再利用することにより、ライブ Minecraft Java Edition ワールドで機能的でカスタマイズされた村と居住地 (数棟の建物からなる集落から最大 5 ～ 15 人の標準的な村まで) を設計します。アダプティブ インタビューを実行し、レイアウト オプションを提案し、ユーザーと対話を繰り返し、Java Edition の村の仕組み (アイアン ゴーレム、ベッド、ワークステーション、ベル、襲撃) を尊重します。ユーザーが村、集落、町、集落、または交易拠点を必要とする場合に使用します。 Minecraft ビルダーのワークフローの一部。
