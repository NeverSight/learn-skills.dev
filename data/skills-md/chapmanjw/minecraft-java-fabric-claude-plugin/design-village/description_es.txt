Diseña aldeas y asentamientos funcionales y personalizados en un mundo vivo de Minecraft Java Edition (aldeas de unos pocos edificios hasta aldeas estándar de 5 a 15) mediante la reutilización de tipos de construcción de aldeas estándar de Minecraft adaptados al bioma y a la solicitud del usuario. Realiza una entrevista adaptativa, propone opciones de diseño, itera con el usuario y respeta la mecánica de la aldea de Java Edition (gólems de hierro, camas, estaciones de trabajo, campanas, incursiones). Úselo cuando el usuario desee una aldea, aldea, ciudad, asentamiento o centro comercial. Parte del flujo de trabajo de Minecraft-Builder.
