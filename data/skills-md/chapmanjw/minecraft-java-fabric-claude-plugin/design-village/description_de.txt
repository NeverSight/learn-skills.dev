Entwirft funktionale, maßgeschneiderte Dörfer und Siedlungen in einer Live-Welt der Minecraft Java Edition – Weiler mit wenigen Gebäuden bis hin zu Standarddörfern mit 5–15 – durch Wiederverwendung standardmäßiger Minecraft-Dorfgebäudetypen, die an das Biom und die Anforderungen des Benutzers angepasst sind. Führt ein adaptives Interview durch, schlägt Layoutoptionen vor, iteriert mit dem Benutzer und respektiert die Dorfmechanik der Java Edition (Eisengolems, Betten, Arbeitsstationen, Glocken, Raids). Verwenden Sie diese Option, wenn der Benutzer ein Dorf, einen Weiler, eine Stadt, eine Siedlung oder einen Handelsknotenpunkt wünscht. Teil des Minecraft-Builder-Workflows.
