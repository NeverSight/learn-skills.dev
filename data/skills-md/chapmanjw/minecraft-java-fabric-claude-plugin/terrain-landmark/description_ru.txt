Составляет узнаваемые настоящие чудеса природы в живом мире Minecraft Java — Гранд-Каньон, Ниагара, Улуру, залив Халонг, Брайс, Башня Дьявола и т. д. — путем определения 2–4 характерных особенностей и построения их из библиотеки повторно используемых примитивов формации в виде одного непрерывного рецепта. Узнаваемость достигается за счет подписей и достоверных пропорций, а не простого размера. Лист уровня 3, вызываемый build-natural-world (было: natural-landmarks).
