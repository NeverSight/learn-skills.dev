Compone maravillas naturales reconocibles del mundo real en un mundo Java de Minecraft en vivo (Gran Cañón, Niágara, Uluru, Bahía de Halong, Bryce, Devils Tower y similares) identificando de 2 a 4 características distintivas y construyéndolas a partir de una biblioteca de primitivas de formación reutilizables como una receta continua. El reconocimiento proviene de las firmas y las proporciones creíbles, no del tamaño bruto. Hoja de nivel 3, invocada por build-natural-world (antes: natural-landmarks).
