Управляет населенным пунктом в живом мире Minecraft Java — деревней, поселком, городом, районом или зданием вместе с его территорией и контекстом. Последовательная планировка, проектирование каждого здания, транспорт, спроектированные территории, планировка и один проход интеграции, объединение общего словаря архитектуры/материалов и данных объекта, чтобы место воспринималось как ОДНО поселение, а не как лоскутное одеяло из красивых зданий, которые не связаны друг с другом. Оркестратор второго уровня.
