Minecraft Java Edition のライブ ワールドで、現実世界のレプリカ (現代および歴史的)、ポップ カルチャーのレプリカ、およびオリジナルの都市など、都市全体と都市地区全体を設計および青写真で作成します。地区のゾーニング、街路の階層、交通機関、壁、再利用された地域の建築モジュールなど、都市構造を計画し、名前付きランドマークすべてを設計構築スキルに委ねます。アダプティブ インタビューを実行し、地区レイアウトを提案し、ユーザーと対話を繰り返します。ユーザーが都市、都市地区、16 以上の建物からなる町、または認識可能な大都市のスカイラインを必要とする場合に使用します。 Minecraft ビルダーのワークフローの一部。
