Überprüft nach jeder Phase einen Minecraft Java Edition-Build in der Welt – prüft, ob der Plan wie angegeben ausgeführt wurde, ob das Ergebnis sauber in die Welt passt (keine baumelnden Kanten, blockierten Pfade oder unbeabsichtigten Überschreibungen) und schlägt konkrete Kurskorrekturen vor. Wird nach jeder größeren Phase der Ausführung eines Buildplans als Selbstkorrekturkontrollpunkt des Builds verwendet. Teil des Minecraft-Builder-Workflows.
