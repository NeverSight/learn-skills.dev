Проверяет сборку Minecraft Java Edition в мире после каждого этапа — проверяет, был ли план выполнен в соответствии с указанными требованиями, что результат полностью соответствует миру (без висячих краев, заблокированных путей или непреднамеренных переопределений), и предлагает конкретные корректировки курса. Используйте после каждого основного этапа выполнения плана сборки в качестве контрольной точки самокоррекции сборки. Часть рабочего процесса Minecraft-Builder.
