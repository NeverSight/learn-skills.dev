Verifica una compilación de Minecraft Java Edition en el mundo después de cada fase: verifica que el plan se llevó a cabo según lo especificado, que el resultado se ajusta perfectamente al mundo (sin bordes colgantes, caminos bloqueados o anulaciones no deseadas) y propone correcciones de rumbo concretas. Úselo después de cada fase importante de la ejecución de un plan de construcción, como punto de control de autocorrección de la construcción. Parte del flujo de trabajo de Minecraft-Builder.
