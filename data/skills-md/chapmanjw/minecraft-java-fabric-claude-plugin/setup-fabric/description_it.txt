Passaggio 1 di 4 della configurazione dell'MCP Java di Minecraft. Installa Minecraft Java Edition con il caricatore Fabric, un client per giocatore singolo o un server dedicato headless, come base all'interno della quale viene eseguita la mod MCP. Da utilizzare quando l'utente desidera configurare da zero Minecraft Java per il controllo AI/MCP o chiede come far funzionare Fabric in modo che Claude possa costruire nel suo mondo.
