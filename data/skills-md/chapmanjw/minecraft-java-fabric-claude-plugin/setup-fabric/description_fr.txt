Étape 1 sur 4 de la configuration de Minecraft Java MCP. Installez Minecraft Java Edition avec le chargeur Fabric – soit un client solo ou un serveur dédié sans tête – comme base sur laquelle le mod MCP s'exécute. À utiliser lorsque l'utilisateur souhaite configurer Minecraft Java pour le contrôle AI/MCP à partir de zéro, ou demande comment faire fonctionner Fabric afin que Claude puisse construire dans son monde.
