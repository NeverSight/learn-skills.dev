Шаг 1 из 4 настройки MCP для Minecraft Java. Установите Minecraft Java Edition с загрузчиком Fabric — либо клиент для одиночной игры, либо безголовый выделенный сервер — в качестве основы, в которой работает мод MCP. Используйте этот шаг, когда пользователь хочет настроить Minecraft Java для контроля ИИ/MCP с нуля или спрашивает, как запустить Fabric, чтобы Claude мог строить в их мире.
