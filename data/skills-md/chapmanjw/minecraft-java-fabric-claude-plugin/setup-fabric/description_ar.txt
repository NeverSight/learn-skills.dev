الخطوة 1 من 4 لإعداد Minecraft Java MCP. قم بتثبيت Minecraft Java Edition باستخدام أداة تحميل النسيج - إما عميل لاعب واحد أو خادم مخصص بدون رأس - كأساس يعمل عليه تعديل MCP بالداخل. يُستخدم عندما يريد المستخدم إعداد Minecraft Java للتحكم في AI/MCP من البداية، أو يسأل عن كيفية تشغيل Fabric حتى يتمكن Claude من البناء في عالمه.
