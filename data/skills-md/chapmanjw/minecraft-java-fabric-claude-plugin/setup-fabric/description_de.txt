Schritt 1 von 4 des Minecraft Java MCP-Setups. Installieren Sie Minecraft Java Edition mit dem Fabric Loader – entweder einem Einzelspieler-Client oder einem Headless-Dedicated-Server – als Grundlage für die Ausführung des MCP-Mods. Verwenden Sie diese Option, wenn der Benutzer Minecraft Java für die AI/MCP-Steuerung von Grund auf einrichten möchte oder fragt, wie er Fabric zum Laufen bringt, damit Claude in seiner Welt bauen kann.
