Conçoit et planifie la base d'opérations d'un joueur dans un monde Minecraft Java Edition en direct - un endroit où vivre, stocker, fabriquer, enchanter et exposer - et non le logement d'un villageois PNJ. Exécute une interview adaptative, propose des plans ASCII / Markdown / Mermaid, itère avec l'utilisateur jusqu'à approbation, puis rédige le plan de construction. À utiliser lorsque l'utilisateur souhaite une maison, une base, une maison de survie, une cabane de démarrage, un chalet, un manoir, un château, une cabane dans les arbres, une base sous-marine, une base de grotte ou similaire. Une partie du flux de travail du constructeur Minecraft.
