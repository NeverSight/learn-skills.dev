Progetta e progetta la base operativa di un giocatore in un mondo live di Minecraft Java Edition, un luogo in cui vivere, immagazzinare, creare, incantare ed esporre, non alloggi per villici NPC. Esegue un colloquio adattivo, propone progetti ASCII/Markdown/Sirena, itera con l'utente fino all'approvazione, quindi scrive il piano di costruzione. Da utilizzare quando l'utente desidera una casa, una base, una casa di sopravvivenza, una baracca iniziale, un cottage, un palazzo, un castello, una casa sull'albero, una base sottomarina, una base in una grotta o simili. Parte del flusso di lavoro di Minecraft-Builder.
