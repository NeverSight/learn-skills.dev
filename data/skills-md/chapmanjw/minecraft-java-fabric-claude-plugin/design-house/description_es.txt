Diseña y crea planos de la base de operaciones de un jugador en un mundo en vivo de Minecraft Java Edition: un lugar para vivir, almacenar, crear, encantar y exhibir, no viviendas para aldeanos NPC. Ejecuta una entrevista adaptativa, propone planos ASCII/Markdown/Sirena, itera con el usuario hasta que se aprueba y luego escribe el plan de construcción. Úselo cuando el usuario desee una casa, base, hogar de supervivencia, choza de inicio, cabaña, mansión, castillo, casa en un árbol, base submarina, base de cueva o similar. Parte del flujo de trabajo de Minecraft-Builder.
