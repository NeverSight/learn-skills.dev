Entwirft und entwirft die Operationsbasis eines Spielers in einer Live-Welt der Minecraft Java Edition – ein Ort zum Leben, Lagern, Basteln, Verzaubern und Ausstellen – keine Behausung von NPC-Dorfbewohnern. Führt ein adaptives Interview durch, schlägt ASCII-/Markdown-/Mermaid-Blaupausen vor, iteriert mit dem Benutzer bis zur Genehmigung und schreibt dann den Build-Plan. Verwenden Sie diese Option, wenn der Benutzer ein Haus, eine Basis, ein Überlebensheim, eine Starterhütte, ein Cottage, ein Herrenhaus, ein Schloss, ein Baumhaus, eine Unterwasserbasis, eine Höhlenbasis oder ähnliches möchte. Teil des Minecraft-Builder-Workflows.
