تصميم وتخطيط قاعدة عمليات اللاعب في عالم Minecraft Java Edition المباشر - مكان للعيش والتخزين والحرفية والسحر والعرض - وليس إسكان قروي NPC. يجري مقابلة تكيفية، ويقترح مخططات ASCII / Markdown / Mermaid، ويكرر الأمر مع المستخدم حتى تتم الموافقة عليه، ثم يكتب خطة البناء. يُستخدم عندما يريد المستخدم منزلاً، أو قاعدة، أو منزل بقاء، أو كوخًا مبدئيًا، أو كوخًا، أو قصرًا، أو قلعة، أو منزل شجرة، أو قاعدة تحت الماء، أو قاعدة كهف، أو ما شابه ذلك. جزء من سير عمل ماين كرافت.
