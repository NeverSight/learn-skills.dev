Проектирует и проектирует базу операций игрока в реальном мире Minecraft Java Edition — место, где можно жить, хранить, создавать, зачаровывать и демонстрировать, а не жилье жителей деревни NPC. Проводит адаптивное собеседование, предлагает чертежи ASCII/Markdown/Mermaid, взаимодействует с пользователем до тех пор, пока не будет одобрено, затем пишет план сборки. Используйте, когда пользователю нужен дом, база, дом для выживания, стартовая хижина, коттедж, особняк, замок, домик на дереве, подводная база, пещерная база или что-то подобное. Часть рабочего процесса Minecraft-Builder.
