Routeur Contentstack Studio : charge l'un des guides spécialisés intégrés selon la tâche (installation du SDK, approvisionnement du projet, enregistrement de composants, sections et modèles, liaison de données, canevas et routes d'aperçu, publication, dépannage). Utilisez-le lorsque l'utilisateur mentionne Contentstack Studio ou ses concepts : le SDK Studio, le canevas, les compositions, les modèles Connected ou Freeform, les sections, les emplacements de sections, les répéteurs, l'enregistrement de composants, BYOC, les routes d'aperçu du Studio, ou la mise en place d'un projet prêt pour le Studio. Ne pas l'utiliser pour les questions générales sur Contentstack CMS, Live Preview, Visual Editor ou Launch qui n'impliquent pas le Studio.

Veuillez toujours répondre dans la langue de l'utilisateur.
