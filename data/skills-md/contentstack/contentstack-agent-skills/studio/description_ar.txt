موجّه Contentstack Studio: يحمل أحد الأدلة المتخصصة المدمجة لكل مهمة (تثبيت SDK، توفير المشروع، تسجيل المكوّنات، الأقسام والقوالب، ربط البيانات، القماش ومسارات المعاينة، النشر، استكشاف الأخطاء وإصلاحها). يُستَخدَم عندما يذكر المستخدم Contentstack Studio أو مفاهيمه: SDK الاستوديو، القماش، التركيبات، القوالب المتصلة أو القوالب الحرة الشكل، الأقسام، فتحات الأقسام، المكررات، تسجيل المكوّنات، BYOC، مسارات معاينة الاستوديو، أو جعل المشروع جاهزًا للاستوديو. لا يُستَخدَم للأسئلة العامة المتعلقة بـ Contentstack CMS، المعاينة الحية، المحرر البصري أو الإطلاق التي لا تتضمن الاستوديو.
