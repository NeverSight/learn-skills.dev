Contentstack Visual Experience（ライブプレビュー、Visual Editor（Visual Builder とも呼ばれる）、Timeline）を診断しガイドします。固定プロトコルに従います：オンボーディングチェックを読み取り、フレームワークとレンダリングモードを検出し、壊れた契約（init、edit tags、preview fetch、iframe の到達性）を一つ特定し、最小限の修正またはサポートへの引き継ぎを提供します。ユーザーがライブプレビュー、Visual Editor/Visual Builder、または Timeline を任意のフレームワーク（CSR、SSR、SSG、GraphQL、ミドルウェア/BFF）で設定、構成、デバッグしているときに使用します。プレビュー領域が空白または到達不可、編集内容が表示されない、古いまたは公開済みのみのプレビュー、オンボーディングチェックが停止、キャンバス上で何も編集できない、edit‑tag のマッピング失敗、ナビゲーション後にプレビューコンテキストが失われる、共有 SSR ステートやキャッシュ汚染、ロケールやバリアントが間違っている、Timeline が誤ったバージョンを表示する、という場合に適用します。リポジトリへのアクセスがある場合はコードレビューに、アクセスがない場合は実装ガイダンスに利用してください。
