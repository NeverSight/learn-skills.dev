Contentstack Visual Experience(라이브 프리뷰, Visual Editor(Visual Builder라고도 함) 및 타임라인)를 진단하고 안내합니다. 고정된 프로토콜을 따릅니다: 온보딩 체크를 읽고, 프레임워크와 렌더링 모드를 감지한 뒤, 하나의 깨진 계약(초기화, 편집 태그, 프리뷰 가져오기, iframe 접근성)을 지역화하고, 가장 작은 해결책이나 지원 인수인계를 제공합니다. 사용자는 CSR, SSR, SSG, GraphQL, 미들웨어/BFF 등 어떤 프레임워크에서도 라이브 프리뷰, Visual Editor/Visual Builder 또는 타임라인을 설정·구성·디버깅할 때 사용합니다. 여기에는 빈 화면이거나 접근할 수 없는 프리뷰 창, 편집 내용이 표시되지 않음, 오래된 혹은 게시된 것만 보이는 프리뷰, 온보딩 체크가 멈춤, 캔버스에서 편집 불가, 편집‑태그 매핑 실패, 탐색 후 프리뷰 컨텍스트 손실, 공유 SSR 상태 또는 캐시 오염, 잘못된 로케일이나 변형, 타임라인에 잘못된 버전 표시 등이 포함됩니다. 저장소 접근이 가능한 경우 코드 검토에, 접근이 불가능한 경우 구현 가이드에 사용합니다.
