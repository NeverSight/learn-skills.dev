Diagnosticar y guiar Contentstack Visual Experience: Live Preview, Visual Editor (también llamado Visual Builder) y Timeline. Sigue un protocolo fijo: leer el Onboarding Check, detectar el framework y el modo de renderizado, localizar un contrato roto (init, edit tags, preview fetch, iframe reachability) y luego ofrecer la solución más pequeña o una derivación a Soporte. Úsalo cuando un usuario está configurando, ajustando o depurando Live Preview, Visual Editor/Visual Builder o Timeline en cualquier framework (CSR, SSR, SSG, GraphQL, middleware/BFF), incluyendo un panel de vista previa en blanco o inaccesible, ediciones que nunca aparecen, vista previa obsoleta o solo publicada, un Onboarding Check atascado, nada editable en el lienzo, fallos de mapeo de edit‑tag, pérdida del contexto de vista previa tras la navegación, estado SSR compartido o contaminación de caché, locale o variante incorrecta, o Timeline que muestra la versión equivocada. Utilízalo para revisión de código cuando hay acceso al repositorio y para guía de implementación cuando no lo hay.
