تشخيص وتوجيه تجربة Contentstack البصرية: المعاينة الحية، محرر البصري (المسمى أيضًا منشئ بصري) والجدول الزمني. يتبع بروتوكول ثابت: قراءة فحص الاستقبال، اكتشاف الإطار ووضعية العرض، تحديد عقدة مكسورة واحدة (التهيئة، وسوم التحرير، جلب المعاينة، قابلية وصول الـ iframe)، ثم تقديم أصغر إصلاح أو تحويل إلى الدعم. يُستخدم عندما يقوم المستخدم بإعداد أو تكوين أو تصحيح الأخطاء للمعاينة الحية، محرر/منشئ البصري أو الجدول الزمني في أي إطار (CSR، SSR، SSG، GraphQL، middleware/BFF)، بما في ذلك لوحة معاينة فارغة أو غير قابلة للوصول، تعديلات لا تظهر أبداً، معاينة قديمة أو للمنشورات فقط، فحص استقبال عالق، عدم وجود شيء قابل للتحرير على اللوحة، فشل مطابقة وسوم التحرير، فقدان سياق المعاينة بعد التنقل، حالة SSR مشتركة أو تلوث الذاكرة المؤقتة، لغة أو نسخة خاطئة، أو جدول زمني يعرض النسخة الخاطئة. استخدمه للمراجعة البرمجية عندما يكون الوصول إلى المستودع متاحًا ولإرشاد التنفيذ عندما لا يكون.
