診斷並指導 Contentstack Visual Experience：Live Preview、Visual Editor（亦稱 Visual Builder）與 Timeline。遵循固定流程：讀取 Onboarding Check、偵測框架與渲染模式、定位單一斷裂的合約（初始化、編輯標籤、預覽抓取、iframe 可達性），然後提供最小修復或交由支援處理。當使用者在任何框架（CSR、SSR、SSG、GraphQL、middleware/BFF）中設定、配置或除錯 Live Preview、Visual Editor/Visual Builder 或 Timeline 時使用，包括預覽窗格為空白或無法連線、編輯內容從未顯示、過時或僅發布的預覽、卡住的 Onboarding Check、畫布上無任何可編輯項目、編輯標籤映射失敗、導覽後失去預覽上下文、共享的 SSR 狀態或快取污染、語系或變體錯誤，或 Timeline 顯示錯誤版本。當有倉庫存取權限時可用於程式碼審查，沒有時則提供實作指導。
