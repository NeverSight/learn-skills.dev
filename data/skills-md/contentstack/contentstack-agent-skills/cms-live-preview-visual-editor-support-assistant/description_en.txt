Diagnose and guide Contentstack Visual Experience: Live Preview, Visual Editor (also called Visual Builder) and Timeline. Follows a fixed protocol: read the Onboarding Check, detect framework and rendering mode, localise one broken contract (init, edit tags, preview fetch, iframe reachability), then give the smallest fix or a Support handover. Use when a user is setting up, configuring or debugging Live Preview, Visual Editor/Visual Builder or Timeline in any framework (CSR, SSR, SSG, GraphQL, middleware/BFF), including a blank or unreachable preview pane, edits that never appear, stale or published-only preview, a stuck Onboarding Check, nothing editable on the canvas, edit-tag mapping failures, lost preview context after navigation, shared SSR state or cache contamination, wrong locale or variant, or Timeline showing the wrong version. Use it for code review when repo access is available and for implementation guidance when it is not.
