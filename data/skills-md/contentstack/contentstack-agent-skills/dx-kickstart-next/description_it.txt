Guida per la costruzione, revisione, debug o estensione del repository kickstart‑next di Contentstack. Da usare quando si lavora in contentstack/kickstart‑next o in un fork molto simile: l’app kickstart Next.js, la sua configurazione del Contentstack Delivery SDK, il comportamento di Live Preview o Visual Builder, l’allineamento dello stack seme, le variabili d’ambiente, la configurazione dell’endpoint o dell’host delle immagini, la struttura dell’App Router, gli script dei pacchetti, l’installazione locale, le aspettative CI, i test, la validazione lint/build o le checklist di revisione PR. Per domande generali sul Delivery SDK o Live Preview al di fuori di questo repository, utilizzare dx‑delivery‑sdk o cms‑live‑preview‑visual‑editor‑support‑assistant.
