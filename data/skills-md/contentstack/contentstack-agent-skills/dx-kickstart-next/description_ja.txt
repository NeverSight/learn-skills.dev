Contentstack の kickstart-next リポジトリの構築、レビュー、デバッグ、または拡張に関するガイダンスです。contentstack/kickstart-next またはそれに近いフォークで作業する際に使用してください：Next.js キックスタートアプリ、その Contentstack Delivery SDK 設定、Live Preview または Visual Builder の挙動、シードスタックの整合性、環境変数、エンドポイントや画像ホストの設定、App Router の構造、パッケージスクリプト、ローカルセットアップ、CI の期待事項、テスト、lint/ビルドの検証、または PR レビューのチェックリスト。リポジトリ外の一般的な Delivery SDK や Live Preview に関する質問は、dx-delivery-sdk または cms-live-preview-visual-editor-support-assistant を使用してください。
