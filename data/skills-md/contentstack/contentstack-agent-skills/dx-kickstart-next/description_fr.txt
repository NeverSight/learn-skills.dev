Guide pour créer, examiner, déboguer ou étendre le référentiel kickstart‑next de Contentstack. Utilisez‑le lorsque vous travaillez dans contentstack/kickstart‑next ou dans un fork proche : l’application de démarrage Next.js, sa configuration du SDK Delivery de Contentstack, le comportement du Live Preview ou du Visual Builder, l’alignement avec la pile semée, les variables d’environnement, la configuration du point de terminaison ou de l’hôte d’images, la structure du routeur d’application, les scripts de paquet, la configuration locale, les attentes CI, les tests, la validation du lint/build, ou les listes de vérification lors de la révision de PR. Pour des questions générales sur le SDK Delivery ou le Live Preview en dehors de ce dépôt, utilisez dx‑delivery‑sdk ou cms‑live‑preview‑visual‑editor‑support‑assistant.
