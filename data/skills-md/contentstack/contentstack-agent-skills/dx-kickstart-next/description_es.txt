Guía para compilar, revisar, depurar o ampliar el repositorio kickstart‑next de Contentstack. Úsala cuando trabajes en contentstack/kickstart‑next o en un fork cercano: la aplicación de inicio rápido Next.js, su configuración del SDK de Delivery de Contentstack, el comportamiento de Live Preview o Visual Builder, la alineación del stack sembrado, variables de entorno, configuración del endpoint o del host de imágenes, la estructura del App Router, scripts de paquetes, configuración local, expectativas de CI, pruebas, validación de lint/construcción o listas de verificación para revisión de PR. Para preguntas generales sobre el SDK de Delivery o Live Preview fuera de este repositorio, utiliza dx‑delivery‑sdk o cms‑live‑preview‑visual‑editor‑support‑assistant.
