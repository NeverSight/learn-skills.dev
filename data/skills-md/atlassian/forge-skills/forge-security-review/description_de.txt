Führt eine White-Box-Sicherheitsprüfung von Atlassian Forge-Apps mithilfe strukturierter, forgespezifischer Sicherheitsregeln und evidenzbasierter Berichte durch. Wird verwendet, wenn der Benutzer eine Forge-Sicherheitsprüfung, eine Sicherheitsüberprüfung, eine Vuln-Bewertung, eine Code-Überprüfung im Pentest-Stil, eine Authz-Überprüfung, eine Mandantenisolationsanalyse, eine Web-Trigger-Härtung oder eine statische Analyse für eine Forge-App anfordert.
