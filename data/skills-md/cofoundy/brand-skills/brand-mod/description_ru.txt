Поместите бренд в Claude Code — брендированный спиннер для терминала и настольного приложения (цвета бренда, собственные слова бренда, его логотип), предварительно отображаемый в HTML для одобрения перед генерацией как устанавливаемый мод. Используйте, когда пользователь говорит «брендировать наш Claude Code», «брендированный спиннер», «мод Claude Code с нашим брендом», «кастомный спиннер», «сделать терминал в стиле бренда», «брендировать агента», «спиннер с нашим логотипом», «показывать наш бренд, пока работает Claude», или хочет, чтобы Claude Code их команды или клиента выглядел в соответствии с их брендом (для видеозаписей экрана, демо или ежедневного использования). Только Claude Code — моды не существуют в других агентах.
