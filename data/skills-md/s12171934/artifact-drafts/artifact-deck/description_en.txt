Create the presentation material as a claude.ai Artifact HTML deck. Copy the template and populate the slides with <slide> tags, while the framework (jsDelivr’s @s-dante/artifact-deck) handles slide navigation, fullscreen mode, presenter notes, and synchronization between the presenter and audience windows. It is invoked by requests such as “make presentation material,” “create slides,” “write deck,” “presentation,” or “prepare presentation.” If the user asks for a .pptx file, it will not be used.
