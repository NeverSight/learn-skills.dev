Cache Components in einer Next.js‑App aktivieren und die dabei auftretenden blockierenden Routen beheben. Verwenden, wenn der Nutzer Cache Components aktivieren, übernehmen oder migrieren möchte, das Flag `cacheComponents` umschalten, eine Flut von blocking-prerender‑/instant‑Validierungsfehlern bearbeiten, den Codemod `cache-components-instant-false` ausführen oder zwischen dem Ausschließen von Routen mittels `export const instant = false` und deren sofortiger Korrektur entscheiden.
