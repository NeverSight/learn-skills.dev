Schalten Sie Cache Components in einer Next.js‑App ein und beheben Sie die blockierenden Routen, die dadurch angezeigt werden. Verwenden Sie dies, wenn der Nutzer Cache Components aktivieren, übernehmen oder darauf migrieren möchte, das `cacheComponents`‑Flag umschalten, sich durch eine Flut von blockierenden prerender‑/instant‑Validierungsfehlern arbeiten, den `cache-components-instant-false`‑Codemod ausführen oder zwischen dem Ausschließen von Routen mit `export const instant = false` und deren Behebung vor Ort entscheiden muss.
