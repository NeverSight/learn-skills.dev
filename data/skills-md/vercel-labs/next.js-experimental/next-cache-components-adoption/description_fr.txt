Activez les Cache Components dans une application Next.js et résolvez les routes bloquantes qu’ils font apparaître. Utilisez‑les lorsque l’utilisateur veut activer, adopter ou migrer vers les Cache Components, basculer le drapeau `cacheComponents`, gérer un afflux d’erreurs de pré‑rendu bloquant / validation instantanée, exécuter le codemod `cache-components-instant-false`, ou choisir entre exclure les routes avec `export const instant = false` et les corriger sur place.
