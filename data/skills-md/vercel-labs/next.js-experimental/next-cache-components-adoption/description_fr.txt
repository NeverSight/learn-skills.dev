Activez les Cache Components dans une application Next.js et résolvez les itinéraires bloquants qu’ils font apparaître. Utilisez cette option lorsque l’utilisateur souhaite activer, adopter ou migrer vers les Cache Components, basculer le drapeau `cacheComponents`, faire face à une avalanche d’erreurs de pré‑rendu bloquant / validation instantanée, exécuter le codemod `cache-components-instant-false`, ou choisir entre exclure les routes avec `export const instant = false` et les corriger sur place.
