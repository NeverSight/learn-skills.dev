Activa los Cache Components en una aplicación Next.js y resuelve las rutas bloqueadoras que aparecen. Úsalo cuando el usuario quiera habilitar, adoptar o migrar a Cache Components, cambiar la bandera `cacheComponents`, enfrentarse a una avalancha de errores de prerenderizado bloqueante o de validación instantánea, ejecutar la codemod `cache-components-instant-false`, o decidir entre excluir rutas con `export const instant = false` y corregirlas in situ.
