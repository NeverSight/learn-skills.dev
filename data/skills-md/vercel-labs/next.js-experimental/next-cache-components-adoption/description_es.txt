Activa los Componentes de Caché en una aplicación Next.js y resuelve las rutas bloqueantes que aparecen. Úsalo cuando el usuario quiera habilitar, adoptar o migrar a Componentes de Caché, activar la bandera `cacheComponents`, enfrentarse a una avalancha de errores de prerenderizado bloqueante o validación instantánea, ejecutar la codemod `cache-components-instant-false`, o decidir entre excluir rutas con `export const instant = false` y corregirlas in situ.
