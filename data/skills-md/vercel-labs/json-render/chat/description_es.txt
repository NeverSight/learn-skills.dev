Chat SDK renderer para json-render que convierte las especificaciones JSON en tarjetas de chat nativas (Block Kit en Slack, Adaptive Cards en Teams y el formato de tarjeta de otros adaptadores de Chat SDK). Úselo cuando trabaje con @json-render/chat, cree bots que publiquen mensajes enriquecidos con tablas, gráficos, campos o botones, transmita una tarjeta generada en un hilo de chat o cuando el usuario mencione Chat SDK, Slack Block Kit o Teams Adaptive Cards junto con json-render.
