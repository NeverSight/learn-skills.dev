Rendu Chat SDK pour json‑render qui transforme les spécifications JSON en cartes de chat natives (Block Kit sur Slack, Adaptive Cards sur Teams et le format de carte des autres adaptateurs Chat SDK). À utiliser avec @json‑render/chat, lors de la création de bots publiant des messages riches avec des tableaux, graphiques, champs ou boutons, pour diffuser une carte générée dans un fil de discussion, ou lorsque l’utilisateur mentionne Chat SDK, Slack Block Kit ou Teams Adaptive Cards avec json‑render.
