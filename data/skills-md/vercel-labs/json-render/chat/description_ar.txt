مُحوِّل Chat SDK لـ json‑render الذي يحوِّل مواصفات JSON إلى بطاقات محادثة أصلية (Block Kit على Slack، Adaptive Cards على Teams، وتنسيق البطاقات للمحوّلات الأخرى الخاصة بـ Chat SDK). يُستخدم عند العمل مع @json-render/chat، بناء البوتات التي تنشر رسائل غنية بالجداول والرسوم البيانية والحقول أو الأزرار، بث بطاقة مُولَّدة في سلسلة محادثة، أو عندما يذكر المستخدم Chat SDK أو Slack Block Kit أو Teams Adaptive Cards مع json‑render.
