Renderer Chat SDK per json-render che trasforma le specifiche JSON in schede chat native (Block Kit su Slack, Adaptive Cards su Teams e il formato scheda di altri adapter Chat SDK). Da utilizzare quando si lavora con @json-render/chat, si costruiscono bot che pubblicano messaggi ricchi con tabelle, grafici, campi o pulsanti, si trasmette una scheda generata in un thread di chat, o quando l'utente menziona Chat SDK, Slack Block Kit o Teams Adaptive Cards insieme a json-render.
