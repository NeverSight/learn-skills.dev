Adaptador Svelte 5 para el inspector de devtools de json‑render. Úsalo cuando el usuario quiera agregar, configurar o solucionar problemas de @json-render/devtools-svelte en una aplicación Svelte json‑render, incluyendo inspección de especificaciones, edición de estado, líneas de tiempo de acciones y flujos, navegación por el catálogo o selección de DOM.
