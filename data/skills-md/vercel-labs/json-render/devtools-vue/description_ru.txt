Vue‑адаптер для инспектора devtools json‑render. Используйте его, когда пользователь хочет добавить, настроить или отладить @json-render/devtools-vue в приложении Vue json‑render, включая инспекцию спецификаций, редактирование состояния, таймлайны действий и потоков, просмотр каталога или выбор элементов DOM.
