Adaptateur Vue pour l'inspecteur devtools de json-render. Utilisez-le chaque fois que l'utilisateur souhaite ajouter, configurer ou dépanner @json-render/devtools-vue dans une application Vue json-render, y compris l'inspection des spécifications, la modification de l'état, les chronologies d'actions et de flux, la navigation dans le catalogue ou la sélection du DOM.
