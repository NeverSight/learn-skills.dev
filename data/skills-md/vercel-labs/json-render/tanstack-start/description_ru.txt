Создавайте приложения TanStack Start, определенные в формате JSON, с помощью @json-render/tanstack-start. Используйте для спецификаций начального маршрута, Splat-маршрутизации, загрузчиков SSR, метаданных заголовка, макетов и навигации по клиенту. Не используйте для общих приложений TanStack Router, которые не используют json-render.
