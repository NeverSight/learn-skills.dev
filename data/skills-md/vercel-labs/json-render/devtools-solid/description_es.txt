Adaptador SolidJS para el inspector de devtools de json-render. Úsalo siempre que el usuario quiera agregar, configurar o depurar @json-render/devtools-solid en una aplicación SolidJS json-render, incluyendo inspección de especificaciones, edición de estado, líneas de tiempo de acciones y streams, exploración del catálogo o selección de elementos del DOM.
