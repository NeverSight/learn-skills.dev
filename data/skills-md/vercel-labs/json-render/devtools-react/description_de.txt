React-Adapter für den json-render-DevTools-Inspektor. Verwenden Sie ihn, wann immer der Benutzer @json-render/devtools-react in einer React‑json-render‑App hinzufügen, konfigurieren oder Fehler beheben möchte, einschließlich Spezifikationsinspektion, Zustandsbearbeitung, Aktions‑ und Stream‑Zeitlinien, Katalogdurchsicht oder DOM‑Auswahl.
