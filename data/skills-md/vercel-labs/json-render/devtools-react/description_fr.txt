Adaptateur React pour l’inspecteur des devtools json‑render. À utiliser chaque fois que l’utilisateur veut ajouter, configurer ou dépanner @json‑render/devtools‑react dans une application React json‑render, y compris l’inspection des spécifications, l’édition d’état, les chronologies d’actions et de flux, la navigation dans le catalogue ou le repérage du DOM.
