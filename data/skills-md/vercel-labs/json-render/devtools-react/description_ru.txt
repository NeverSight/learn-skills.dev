Адаптер React для инспектора devtools json‑render. Используйте его, когда пользователю необходимо добавить, настроить или отладить @json-render/devtools-react в приложении React json‑render, включая проверку спецификации, редактирование состояния, тайм‑линии действий и потоков, просмотр каталога или выбор элементов DOM.
