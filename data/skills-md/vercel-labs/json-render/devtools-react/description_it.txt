Adapter React per l'ispettore devtools di json-render. Usalo ogni volta che l'utente desidera aggiungere, configurare o risolvere problemi con @json-render/devtools-react in un'app React json-render, includendo l'ispezione delle specifiche, la modifica dello stato, le timeline di azioni e stream, la navigazione nel catalogo o la selezione del DOM.
