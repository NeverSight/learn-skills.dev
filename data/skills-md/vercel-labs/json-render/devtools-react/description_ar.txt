محول React لأداة فحص أدوات التطوير json-render. استخدمه كلما رغب المستخدم في إضافة أو تكوين أو استكشاف الأخطاء وإصلاحها لـ @json-render/devtools-react في تطبيق React يعتمد على json-render، بما في ذلك فحص المواصفات، تحرير الحالة، خطوط زمنية للإجراءات وتدفقات البيانات، تصفح الكتالوج، أو اختيار عناصر DOM.
