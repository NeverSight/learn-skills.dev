Pattern di composizione React scalabili. Da usare durante la refactoring di componenti con proliferazione di proprietà booleane, la creazione di librerie di componenti flessibili o la progettazione di API riutilizzabili. Si attiva per attività che coinvolgono componenti composti, render props, provider di contesto o architettura dei componenti. Include le modifiche all'API di React 19.
