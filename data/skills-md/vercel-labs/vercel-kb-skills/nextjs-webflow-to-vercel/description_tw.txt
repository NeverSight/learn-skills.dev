將 Next.js 應用程式從 Webflow Cloud 遷移到 Vercel。當使用者想要將 Next.js 應用程式從 Webflow Cloud 移動、遷移或移植到 Vercel 時，請使用此技能。這包括刪除 OpenNext Cloudflare 轉接器 (@opennextjs/cloudflare) 和 initOpenNextCloudflareForDev 開發掛鉤、卸載 Wrangler、刪除 Webflow Cloud 設定檔（webflow.json、wrangler.json、open-next.config.ts、cloudflare-env.d.. 。 Next.js 在 Vercel 上本機運行，因此沒有適配器可以取代 OpenNext。觸發器包括「遷移到 Vercel」、「移出 Webflow Cloud」、「Next.js Webflow Cloud 到 Vercel」等短語，或 Next.js 專案中存在 webflow.json、wrangler.json、@opennextjs/cloudflare、open-next.config.ts 或 getCloudflareContext。請勿用於非 Next.js 框架或相反方向的遷移（Vercel 到 Webflow Cloud）。
