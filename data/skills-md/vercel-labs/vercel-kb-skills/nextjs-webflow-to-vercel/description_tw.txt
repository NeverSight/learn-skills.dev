將 Next.js 應用程式從 Webflow Cloud 移植到 Vercel。當使用者想要將 Next.js 應用程式從 Webflow Cloud 移動、遷移或移植到 Vercel 時，使用此技能。這包括移除 OpenNext Cloudflare 適配器（@opennextjs/cloudflare）與 initOpenNextCloudflareForDev 開發掛鉤、解除安裝 Wrangler、刪除 Webflow Cloud 設定檔（webflow.json、wrangler.json、open-next.config.ts、cloudflare‑env.d.ts）、取消應用在 Webflow 網站上掛載的基礎路徑（next.config.ts 中的 basePath 與 assetPrefix）、從路由處理器與中介軟體中移除 Edge 執行時指令（export const runtime = 'edge'）、將透過 getCloudflareContext().env 讀取的 Cloudflare 儲存綁定（Object Storage/R2、Key‑Value Store/Workers KV、SQLite/D1）重新指向 Vercel 儲存、重新建立環境變數，並部署。Next.js 在 Vercel 上原生執行，因此不需要任何適配器取代 OpenNext。觸發條件包括「migrate to Vercel」、「move off Webflow Cloud」、「Next.js Webflow Cloud to Vercel」等語句，或在 Next.js 專案中出現 webflow.json、wrangler.json、@opennextjs/cloudflare、open‑next.config.ts、或 getCloudflareContext 等檔案／程式碼。請勿用於非 Next.js 框架，亦不要用於相反方向的遷移（Vercel 到 Webflow Cloud）。
