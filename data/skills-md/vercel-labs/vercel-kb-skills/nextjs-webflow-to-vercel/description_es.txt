Migre una aplicación Next.js de Webflow Cloud a Vercel. Utilice esta habilidad cuando un usuario quiera mover, migrar o transferir una aplicación Next.js de Webflow Cloud a Vercel. Esto cubre la eliminación del adaptador OpenNext Cloudflare (@opennextjs/cloudflare) y el gancho de desarrollo initOpenNextCloudflareForDev, la desinstalación de Wrangler, la eliminación de los archivos de configuración de Webflow Cloud (webflow.json, wrangler.json, open-next.config.ts, cloudflare-env.d.ts), la eliminación de la ruta base en la que se montó la aplicación en un sitio de Webflow (basePath y activePrefix en next.config.ts), eliminando la directiva de tiempo de ejecución de Edge (export const runtime = 'edge') de los controladores de ruta y el middleware, redirigiendo los enlaces de almacenamiento de Cloudflare leídos a través de getCloudflareContext().env (Object Storage/R2, Key Value Store/Workers KV, SQLite/D1) al almacenamiento de Vercel, recreando variables de entorno e implementando. Next.js se ejecuta de forma nativa en Vercel, por lo que ningún adaptador reemplaza a OpenNext. Los desencadenantes incluyen frases como "migrar a Vercel", "salir de Webflow Cloud", "Next.js Webflow Cloud a Vercel" o la presencia de webflow.json, wrangler.json, @opennextjs/cloudflare, open-next.config.ts o getCloudflareContext en un proyecto Next.js. No lo use para marcos que no sean Next.js o para migraciones en la dirección opuesta (Vercel a Webflow Cloud).
