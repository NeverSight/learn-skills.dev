Next.js 애플리케이션을 Webflow Cloud에서 Vercel로 마이그레이션합니다. 사용자가 Next.js 앱을 Webflow Cloud에서 Vercel로 이동, 마이그레이션 또는 포팅하려는 경우 이 기술을 사용하세요. 여기에는 OpenNext Cloudflare 어댑터(@opennextjs/cloudflare) 및 initOpenNextCloudflareForDev dev 후크 제거, Wrangler 제거, Webflow Cloud 구성 파일(webflow.json, wrangler.json, open-next.config.ts, cloudflare-env.d.ts) 삭제, Webflow 사이트에 탑재된 앱의 기본 경로 삭제(next.config.ts의 basePath 및 AssetPrefix), 경로 처리기 및 미들웨어의 Edge 런타임 지시문(export const 런타임 = 'edge'), getCloudflareContext().env(Object Storage/R2, Key Value Store/Workers KV, SQLite/D1)를 통해 읽은 Cloudflare 저장소 바인딩을 Vercel 저장소로 다시 지정하고, 환경 변수를 다시 생성하고 배포합니다. Next.js는 Vercel에서 기본적으로 실행되므로 OpenNext를 대체하는 어댑터가 없습니다. 트리거에는 'Vercel로 마이그레이션', 'Webflow Cloud에서 이동', 'Next.js Webflow Cloud에서 Vercel로'와 같은 문구 또는 Next.js 프로젝트의 webflow.json, wrangler.json, @opennextjs/cloudflare, open-next.config.ts 또는 getCloudflareContext의 존재가 포함됩니다. Next.js 프레임워크가 아니거나 반대 방향(Vercel에서 Webflow Cloud로)으로의 마이그레이션에는 사용하지 마세요.
