将 Next.js 应用程序从 Webflow Cloud 迁移到 Vercel。当用户想要将 Next.js 应用程序从 Webflow Cloud 移动、迁移或移植到 Vercel 时，请使用此技能。这包括删除 OpenNext Cloudflare 适配器 (@opennextjs/cloudflare) 和 initOpenNextCloudflareForDev 开发挂钩、卸载 Wrangler、删除 Webflow Cloud 配置文件（webflow.json、wrangler.json、open-next.config.ts、cloudflare-env.d.ts）、删除 Webflow 站点上安装的应用程序的基本路径（next.config.ts 中的 basePath 和 assetPrefix）、删除 Edge从路由处理程序和中间件中添加运行时指令 (export const runtime = 'edge')，将通过 getCloudflareContext().env（对象存储/R2、键值存储/Workers KV、SQLite/D1）读取的 Cloudflare 存储绑定重新指向 Vercel 存储，重新创建环境变量并进行部署。 Next.js 在 Vercel 上本机运行，因此没有适配器可以替代 OpenNext。触发器包括“迁移到 Vercel”、“移出 Webflow Cloud”、“Next.js Webflow Cloud 到 Vercel”等短语，或者 Next.js 项目中存在 webflow.json、wrangler.json、@opennextjs/cloudflare、open-next.config.ts 或 getCloudflareContext。请勿用于非 Next.js 框架或相反方向的迁移（Vercel 到 Webflow Cloud）。
