Migrieren Sie eine Next.js-Anwendung von Webflow Cloud nach Vercel. Verwenden Sie diesen Skill, wenn ein Benutzer eine Next.js-App von Webflow Cloud auf Vercel verschieben, migrieren oder portieren möchte. Dies umfasst das Entfernen des OpenNext Cloudflare-Adapters (@opennextjs/cloudflare) und des initOpenNextCloudflareForDev-Dev-Hooks, die Deinstallation von Wrangler, das Löschen der Webflow Cloud-Konfigurationsdateien (webflow.json, wrangler.json, open-next.config.ts, cloudflare-env.d.ts) und das Löschen des Basispfads, unter dem die App auf einer Webflow-Site bereitgestellt wurde (basePath und assetPrefix in). next.config.ts), Entfernen der Edge-Laufzeitdirektive (export const runtime = 'edge') aus Routenhandlern und Middleware, Neuverweisen der über getCloudflareContext().env (Object Storage/R2, Key Value Store/Workers KV, SQLite/D1) gelesenen Cloudflare-Speicherbindungen auf den Vercel-Speicher, Neuerstellen von Umgebungsvariablen und Bereitstellen. Next.js läuft nativ auf Vercel, daher ersetzt kein Adapter OpenNext. Zu den Auslösern gehören Ausdrücke wie „zu Vercel migrieren“, „von Webflow Cloud verschieben“, „Next.js Webflow Cloud zu Vercel“ oder das Vorhandensein von webflow.json, wrangler.json, @opennextjs/cloudflare, open-next.config.ts oder getCloudflareContext in einem Next.js-Projekt. Nicht für Nicht-Next.js-Frameworks oder für Migrationen in die entgegengesetzte Richtung (Vercel zu Webflow Cloud) verwenden.
