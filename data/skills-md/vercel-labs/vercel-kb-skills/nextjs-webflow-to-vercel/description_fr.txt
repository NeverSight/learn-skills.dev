Migrez une application Next.js de Webflow Cloud vers Vercel. Utilisez cette compétence lorsqu'un utilisateur souhaite déplacer, migrer ou porter une application Next.js de Webflow Cloud vers Vercel. Cela couvre la suppression de l'adaptateur OpenNext Cloudflare (@opennextjs/cloudflare) et du hook de développement initOpenNextCloudflareForDev, la désinstallation de Wrangler, la suppression des fichiers de configuration Webflow Cloud (webflow.json, wrangler.json, open-next.config.ts, cloudflare-env.d.ts), la suppression du chemin de base sous lequel l'application est montée sur un site Webflow (basePath et AssetPrefix dans next.config.ts), supprimant la directive d'exécution Edge (export const runtime = 'edge') des gestionnaires de routes et du middleware, redirigeant les liaisons de stockage Cloudflare lues via getCloudflareContext().env (Object Storage/R2, Key Value Store/Workers KV, SQLite/D1) vers le stockage Vercel, recréant les variables d'environnement et déployant. Next.js s'exécute nativement sur Vercel, donc aucun adaptateur ne remplace OpenNext. Les déclencheurs incluent des expressions telles que « migrer vers Vercel », « quitter Webflow Cloud », « Next.js Webflow Cloud vers Vercel » ou la présence de webflow.json, wrangler.json, @opennextjs/cloudflare, open-next.config.ts ou getCloudflareContext dans un projet Next.js. Ne pas utiliser pour les frameworks non-Next.js ou pour les migrations en sens inverse (Vercel vers Webflow Cloud).
