قم بترحيل تطبيق Next.js من Webflow Cloud إلى Vercel. استخدم هذه المهارة عندما يريد المستخدم نقل تطبيق Next.js أو ترحيله أو نقله من Webflow Cloud إلى Vercel. يغطي هذا إزالة محول OpenNext Cloudflare (@opennextjs/cloudflare) وخطاف التطوير initOpenNextCloudflareForDev، وإلغاء تثبيت Wrangler، وحذف ملفات تكوين Webflow Cloud (webflow.json، wrangler.json، open-next.config.ts، cloudflare-env.d.ts)، وإسقاط المسار الأساسي الذي تم تثبيت التطبيق عليه على موقع Webflow (basePath) وAssetPrefix في next.config.ts)، وإزالة توجيه وقت تشغيل Edge (export const runtime = 'edge') من معالجات الطريق والبرامج الوسيطة، وإعادة تحديد روابط تخزين Cloudflare المقروءة من خلال getCloudflareContext().env (Object Storage/R2، Key Value Store/Workers KV، SQLite/D1) إلى تخزين Vercel، وإعادة إنشاء متغيرات البيئة، والنشر. يعمل Next.js أصلاً على Vercel، لذلك لا يوجد محول يحل محل OpenNext. تتضمن المشغلات عبارات مثل "الترحيل إلى Vercel"، أو "الانتقال من Webflow Cloud"، أو "Next.js Webflow Cloud إلى Vercel"، أو وجود webflow.json، أو wrangler.json، أو @opennextjs/cloudflare، أو open-next.config.ts، أو getCloudflareContext في مشروع Next.js. لا تستخدمه مع أطر عمل غير Next.js أو لعمليات الترحيل في الاتجاه المعاكس (Vercel إلى Webflow Cloud).
