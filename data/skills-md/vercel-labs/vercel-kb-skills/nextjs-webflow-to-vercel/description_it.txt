Migrare un'applicazione Next.js da Webflow Cloud a Vercel. Utilizza questa competenza quando un utente desidera spostare, migrare o trasferire un'app Next.js da Webflow Cloud a Vercel. Ciò copre la rimozione dell'adattatore OpenNext Cloudflare (@opennextjs/cloudflare) e l'hook di sviluppo initOpenNextCloudflareForDev, la disinstallazione di Wrangler, l'eliminazione dei file di configurazione di Webflow Cloud (webflow.json, wrangler.json, open-next.config.ts, cloudflare-env.d.ts), l'eliminazione del percorso di base in cui è stata montata l'app su un sito Webflow (basePath e assetPrefix in next.config.ts), rimuovendo la direttiva Edge runtime (export const runtime = 'edge') dai gestori di route e dal middleware, riorientando i collegamenti di storage Cloudflare letti tramite getCloudflareContext().env (Object Storage/R2, Key Value Store/Workers KV, SQLite/D1) allo storage Vercel, ricreando le variabili di ambiente e distribuendo. Next.js viene eseguito in modo nativo su Vercel, quindi nessun adattatore sostituisce OpenNext. I trigger includono frasi come "migrare a Vercel", "spostare Webflow Cloud", "Next.js Webflow Cloud a Vercel" o la presenza di webflow.json, wrangler.json, @opennextjs/cloudflare, open-next.config.ts o getCloudflareContext in un progetto Next.js. Non utilizzare per framework non Next.js o per migrazioni nella direzione opposta (da Vercel a Webflow Cloud).
