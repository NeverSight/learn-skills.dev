Migra un'applicazione Next.js da Webflow Cloud a Vercel. Usa questa competenza quando un utente vuole spostare, migrare o trasferire un'app Next.js da Webflow Cloud a Vercel. Questo copre la rimozione dell'adattatore OpenNext Cloudflare (@opennextjs/cloudflare) e dell'hook di sviluppo initOpenNextCloudflareForDev, la disinstallazione di Wrangler, l'eliminazione dei file di configurazione di Webflow Cloud (webflow.json, wrangler.json, open-next.config.ts, cloudflare‑env.d.ts), la rimozione del percorso base sotto cui l'app è montata su un sito Webflow (basePath e assetPrefix in next.config.ts), la rimozione della direttiva di runtime Edge (export const runtime = 'edge') da Route Handlers e middleware, il reindirizzamento dei binding di storage Cloudflare letti tramite getCloudflareContext().env (Object Storage/R2, Key Value Store/Workers KV, SQLite/D1) verso lo storage Vercel, la ricreazione delle variabili d'ambiente e il deployment. Next.js gira nativamente su Vercel, quindi nessun adattatore sostituisce OpenNext. I trigger includono frasi come 'migrate to Vercel', 'move off Webflow Cloud', 'Next.js Webflow Cloud to Vercel', oppure la presenza di webflow.json, wrangler.json, @opennextjs/cloudflare, open-next.config.ts o getCloudflareContext in un progetto Next.js. Non usare per framework non Next.js o per migrazioni nella direzione opposta (da Vercel a Webflow Cloud).
