Next.js アプリケーションを Webflow Cloud から Vercel に移行します。ユーザーが Next.js アプリを Webflow Cloud から Vercel に移動、移行、または移植する場合は、このスキルを使用します。これには、OpenNext Cloudflare アダプター (@opennextjs/cloudflare) と initOpenNextCloudflareForDev 開発フックの削除、Wrangler のアンインストール、Webflow クラウド構成ファイル (webflow.json、wrangler.json、open-next.config.ts、cloudflare-env.d.ts) の削除、Webflow サイトにアプリがマウントされたベース パス (basePath とassetPrefix の削除) が含まれます。 next.config.ts)、ルート ハンドラーとミドルウェアから Edge ランタイム ディレクティブ (export const runtime = 'edge') を削除し、getCloudflareContext().env (オブジェクト ストレージ/R2、キー バリュー ストア/ワーカー KV、SQLite/D1) を通じて読み取られた Cloudflare ストレージ バインディングを Vercel ストレージに再ポイントし、環境変数を再作成してデプロイします。 Next.js は Vercel 上でネイティブに実行されるため、OpenNext に代わるアダプターはありません。トリガーには、「Vercel への移行」、「Webflow Cloud からの移行」、「Next.js Webflow Cloud から Vercel」などのフレーズ、または Next.js プロジェクト内の webflow.json、wrangler.json、@opennextjs/cloudflare、open-next.config.ts、または getCloudflareContext の存在が含まれます。 Next.js 以外のフレームワークや、逆方向の移行 (Vercel から Webflow Cloud) には使用しないでください。
