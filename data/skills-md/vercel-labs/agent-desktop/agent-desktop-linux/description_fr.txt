Guide de la plateforme Linux pour l'interface en ligne de commande agent-desktop. Liste, pour chaque groupe de commandes, ce qui fonctionne sous X11 et sous Wayland, comment vérifier le bus d'accessibilité AT‑SPI, les pièges de première prise de contact (noms d’applications, drapeaux de Chromium et Electron, focus avec tête, combinaisons de touches bloquées), et où trouver les détails sur le cycle de vie, les captures d’écran, le presse‑papier, la zone de notification, les notifications et le dépannage. Déclencheurs : « automatisation du bureau Linux », « arbre AT‑SPI », « automatiser une application GNOME », « agent-desktop sous Linux », « bus d’accessibilité indisponible », « supported_surfaces vide », « consentement de capture d’écran Wayland », ou toute tâche d’interaction GUI sous Linux.
