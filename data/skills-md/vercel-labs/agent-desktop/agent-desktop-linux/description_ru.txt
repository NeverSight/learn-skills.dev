Руководство по платформе Linux для CLI agent‑desktop. Перечисляет для каждой группы команд, что работает в X11 и в Wayland, как проверить шину доступности AT‑SPI, подводные камни при первом контакте (имена приложений, флаги Chromium и Electron, фокус в заголовке окна, заблокированные комбинации клавиш) и где найти детали о жизненном цикле, скриншотах, буфере обмена, трее, уведомлениях и устранении неполадок. Срабатывает по запросам: «linux desktop automation», «AT‑SPI tree», «automate GNOME app», «agent‑desktop on Linux», «accessibility bus not available», «empty supported_surfaces», «wayland screenshot consent» или любой задаче взаимодействия с графическим интерфейсом Linux.
