Руководство по платформе Windows для CLI agent‑desktop. Перечисляет для каждой группы команд, что работает в Windows, а что отказывается, первые подводные камни (кавычки в PowerShell‑ref, минимизированные окна, ввод только в активном окне), а также где найти оболочечные поверхности, уведомления, оверлей курсора, повышение привилегий UIPI, поведение укладывания Chromium/Electron и устранение неполадок. Триггеры: «автоматизация рабочего стола Windows», «дерево UIA», «автоматизировать приложение Windows», «agent‑desktop в Windows», «ввод в повышенном окне заблокирован», «E_ACCESSDENIED» или любая задача взаимодействия с графическим интерфейсом Windows.
