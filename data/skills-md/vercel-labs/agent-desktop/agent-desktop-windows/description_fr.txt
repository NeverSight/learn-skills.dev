Guide de la plateforme Windows pour l'interface en ligne de commande agent-desktop. Liste, par groupe de commandes, ce qui fonctionne sous Windows et ce qui refuse, les pièges de première prise de contact (citation de références PowerShell, fenêtres minimisées, saisie uniquement en mode avec tête), ainsi que l’endroit où trouver les surfaces du shell, les notifications, la superposition du curseur, l’élévation UIPI, le comportement de stabilisation de Chromium/Electron et le dépannage. Déclencheurs : « automatisation du bureau Windows », « arborescence UIA », « automatiser une application Windows », « agent-desktop sur Windows », « saisie de fenêtre élevée bloquée », « E_ACCESSDENIED », ou toute tâche d’interaction GUI sous Windows.
