دليل منصة Windows لواجهة سطر أوامر agent‑desktop. يحدد لكل مجموعة أوامر ما يعمل على Windows وما يرفض، المشكلات التي تظهر عند أول اتصال (إحالة PowerShell إلى الاقتباس، النوافذ المصغّرة، الإدخال في الواجهة ذات الرأس فقط)، وأين يمكن العثور على أسطح الصدفة، الإشعارات، تراكب المؤشر، رفع مستوى UIPI، سلوك الاستقرار في Chromium/Electron وحلول المشكلات. يُفعَّل عند: "windows desktop automation"، "UIA tree"، "automate Windows app"، "agent‑desktop on Windows"، "elevated window input blocked"، "E_ACCESSDENIED"، أو أي مهمة تفاعل مع واجهة المستخدم الرسومية في Windows.
