Guía de la plataforma macOS para la CLI agent-desktop. Uso para la automatización de escritorio en macOS: otorgar permisos de Accesibilidad y Grabación de pantalla (TCC), qué hace el modo headed en macOS (clic físico primero, escribir y desplazarse), superficies (menú, barra de menús, hoja, popover, alerta), Centro de Notificaciones, aplicaciones Chromium y Electron, incluido el arranque con --cdp, y solución de PERM_DENIED, árboles de accesibilidad vacíos, ACTION_FAILED y APP_UNRESPONSIVE.
