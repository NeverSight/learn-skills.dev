Руководство по платформе macOS для CLI agent-desktop. Используется для автоматизации рабочего стола в macOS: предоставление прав доступа к Accessibility и Screen Recording (TCC), что делает режим с графическим интерфейсом в macOS (клик, ввод и прокрутка, имитирующие физические действия), поверхности (меню, строка меню, лист, всплывающее окно, диалоговое окно), Центр уведомлений, приложения Chromium и Electron, включая запуск с параметром --cdp, а также исправление ошибок PERM_DENIED, пустых деревьев доступности, ACTION_FAILED и APP_UNRESPONSIVE.
