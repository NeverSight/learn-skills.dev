Управляйте настольными приложениями на macOS, Windows и Linux через родные деревья доступности, используя CLI agent‑desktop. Используйте, когда ИИ‑агенту необходимо видеть или взаимодействовать с настольным GUI: нажимать кнопки, заполнять формы, считывать состояние интерфейса, перемещаться по меню, переключать флажки, прокручивать, перетаскивать, вводить текст, нажимать сочетания клавиш, делать скриншоты, управлять окнами, использовать буфер обмена, запускать или закрывать приложения, читать уведомления. Срабатывает по запросам: «click button», «fill form», «open app», «read UI», «computer use», «operate desktop», «accessibility tree», «snapshot app», «type into field», «navigate menu», «toggle checkbox», «take screenshot», «desktop automation», «agent-desktop» или любой задаче настольного GUI на macOS, Windows или Linux.

Пожалуйста, всегда отвечайте на языке пользователя.
