agent-desktop CLI を使って、macOS、Windows、Linux 上のデスクトップアプリケーションをネイティブアクセシビリティツリーを通じて操作します。AI エージェントがデスクトップ GUI を見たり操作したりする必要があるときに使用します：ボタンをクリック、フォームに入力、UI の状態を読み取る、メニューをナビゲート、チェックボックスを切り替え、スクロール、ドラッグ、テキスト入力、ショートカットキーを押す、スクリーンショットを撮る、ウィンドウを管理、クリップボードを使用、アプリを起動・終了、通知を読む。トリガー語は「click button」「fill form」「open app」「read UI」「computer use」「operate desktop」「accessibility tree」「snapshot app」「type into field」「navigate menu」「toggle checkbox」「take screenshot」「desktop automation」「agent-desktop」または macOS、Windows、Linux 上の任意のデスクトップ GUI タスクです。
