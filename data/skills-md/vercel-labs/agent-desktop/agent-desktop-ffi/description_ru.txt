C-ABI привязки поверх PlatformAdapter из agent-desktop. Потребители (Python ctypes, Swift, Node ffi-napi, Go cgo, C++, Ruby fiddle) связывают libagent_desktop_ffi.{dylib,so,dll} и вызывают функции `ad_*` напрямую, не порождая исполняемый файл CLI при каждом вызове. Канонический процесс наблюдения‑действия выглядит так: ad_init → ad_adapter_create[_with_session] → ad_snapshot → чтение квалифицированных ссылок (@s8f3k2p9:e5) → ad_execute_by_ref → ad_free_string → ad_adapter_destroy.
