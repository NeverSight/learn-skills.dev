Steuern Sie eine Desktop‑Anwendung anhand eines einfachen, natürlichsprachlichen Ziels oder bearbeiten Sie jeweils eine Absicht, ohne jemals den Accessibility‑Tree zu lesen. Verwenden Sie es, wenn Sie eine Desktop‑App automatisieren und den 150‑Elemente‑JSON‑Baum aus Ihrem Kontext fernhalten möchten. Geben Sie `run.mjs` ein komplettes Ziel; es beobachtet, entscheidet und handelt, bis das Ziel erreicht ist. Geben Sie `act.mjs` einen einzelnen Schritt, wenn Sie den Plan selbst behalten wollen. Es legt fest, welches Element, welche Operation, wann tiefer geschaut werden muss und wann gestoppt wird. Benötigt einen Klon des agent-desktop‑Repositories und einen TYPESAFE_API_KEY.
