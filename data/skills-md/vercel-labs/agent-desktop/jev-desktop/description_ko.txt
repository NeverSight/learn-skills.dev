데스크톱 애플리케이션을 하나의 자연어 목표에서 구동하거나 한 번에 하나의 의도만 해결합니다. 접근성 트리를 전혀 읽지 않습니다. 데스크톱 앱을 자동화하면서 150요소 JSON 트리를 컨텍스트에서 제외하고 싶을 때 사용합니다. `run.mjs`에 전체 목표를 전달하면 목표가 달성될 때까지 관찰하고 판단하고 행동합니다; 직접 계획을 유지하고 싶을 때는 `act.mjs`에 단일 단계를 전달합니다. 어느 요소를, 어떤 작업을, 언제 더 깊이 살펴볼지, 언제 멈출지를 다룹니다. agent-desktop 저장소를 복제하고 TYPESAFE_API_KEY가 필요합니다.
