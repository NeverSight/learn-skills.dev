Utilisez cela lorsque l'utilisateur demande d'expliquer un problème, un ticket, une PR ou une fonctionnalité sous forme d'infographie. Créez une explication visuelle pas à pas à partir du code ou des actions de l'utilisateur, avec une délimitation claire problème/solution, des extraits de code avec mise en évidence syntaxique et des diagrammes ciblés. Prenez en charge les PDF éducatifs autonomes et les explications en Markdown avec de petits fragments SVG pour les PR. Appliquez également lorsque cela est explicitement invoqué par le rédacteur de la PR du dépôt.

Veuillez toujours répondre dans la langue de l'utilisateur.
