Создавать, проверять и редактировать документацию для разработчиков SDK, библиотек и фреймворков, включая сайты такие как agent-browser.dev и portless.sh. Используется для руководств по началу работы, учебных материалов, справочников API, концептуальных объяснений, руководств по интеграции, руководств по миграции, устранения неполадок и примеров кода.
