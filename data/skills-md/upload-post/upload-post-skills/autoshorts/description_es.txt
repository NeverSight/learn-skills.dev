Pipeline diario que selecciona un video largo de una carpeta, lo transcribe con Whisper, usa Gemini 3 Flash multimodal para encontrar cada momento viral de formato corto, corta cada candidato con FFmpeg, añade una superposición de texto de enganche, presenta los candidatos al usuario para su aprobación y publica los clips aprobados en TikTok / Instagram Reels / YouTube Shorts mediante la API Upload‑Post. Úsalo cuando el usuario quiera crear shorts/reels/clips a partir de videos más largos, mencione autoshorts, clips virales o reutilización de contenido, o solicite el lote diario de clips.
