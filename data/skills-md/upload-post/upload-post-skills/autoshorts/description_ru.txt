Ежедневный конвейер, который выбирает одно длинное видео из папки, расшифровывает его с помощью Whisper, использует Gemini 3 Flash мультимодальный для поиска каждого вирусного короткого момента, обрезает каждый вариант с помощью FFmpeg, добавляет наложение текста‑крючка, представляет варианты пользователю для одобрения и публикует одобренные клипы в TikTok / Instagram Reels / YouTube Shorts через API Upload‑Post. Используйте, когда пользователь хочет создавать шорты/рилсы/клипы из более длинных видео, упоминает автошорты, вирусные клипы или переиспользование контента, либо запрашивает ежедневный пакет клипов.
