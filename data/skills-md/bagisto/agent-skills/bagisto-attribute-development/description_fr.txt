À utiliser lorsque vous travaillez avec le système d'attributs EAV de Bagisto : ajout ou modification d'un attribut, d'une famille ou d'un groupe d'attributs, lecture ou écriture d'une valeur d'attribut de produit, ou débogage d'une valeur qui se lit comme vide ou à partir d'une langue ou d'un canal incorrect. Les expressions déclenchantes comprennent « attribut », « EAV », « famille d’attributs », « groupe d’attributs », « option d’attribut », « attribut personnalisé », « value_per_locale », « value_per_channel », « product_flat », « échantillon ».
