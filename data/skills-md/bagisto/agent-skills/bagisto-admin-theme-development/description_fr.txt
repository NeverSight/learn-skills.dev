À utiliser lors de la création ou de la modification d’un thème d’administration Bagisto : un package de thème, des mises en page d’administration, des remplacements de composants Blade ou le pipeline d’assets Vite pour le panneau d’administration. Les expressions déclenchantes comprennent « thème administrateur », « mise en page administrateur », « style du panneau administrateur », « paquet de thème », « Vite », « Tailwind », « publier des vues », « mise en page personnalisée ».
