Acquisizione delle decisioni sui requisiti di prodotto e creazione di issue su GitHub. Usare solo quando un umano invoca esplicitamente `$write-prd`; non selezionare mai questa funzionalità automaticamente in base a somiglianze con feature, pianificazione, PRD o creazione di issue. Quando invocata esplicitamente, definire o finalizzare un PRD, trasformare un'idea di funzionalità in un issue GitHub completo di decisioni, e risolvere le decisioni rilevanti riguardanti prodotto, tecnica, operativa, rollout, osservabilità, supporto, documentazione e test. Si prega di rispondere sempre nella lingua dell'utente.
