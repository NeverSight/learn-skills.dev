Migrate an app's charts from Recharts to Bklit UI. Detects Recharts usage — direct `recharts` imports or shadcn/ui's `components/ui/chart.tsx` wrapper (ChartContainer, ChartConfig, ChartTooltipContent, ChartLegendContent) — inventories every chart, classifies each as clean / needs workaround / keep on Recharts, installs the matching `@bklit/*` shadcn registry items, and rewrites each chart with the equivalent bklit components while preserving data, colours, and labels. Use when the user asks to replace, migrate, convert, or port Recharts or shadcn charts to bklit, to remove the recharts dependency, or asks what it would take to switch chart libraries.
