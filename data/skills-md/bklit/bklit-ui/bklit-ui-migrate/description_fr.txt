Migrer les graphiques d’une application de Recharts vers Bklit UI. Détecte l’utilisation de Recharts — importations directes de `recharts` ou le wrapper `components/ui/chart.tsx` de shadcn/ui (ChartContainer, ChartConfig, ChartTooltipContent, ChartLegendContent) — recense chaque graphique, le classe comme propre / nécessite une solution de contournement / à conserver sur Recharts, installe les éléments correspondants du registre `@bklit/*` de shadcn, et réécrit chaque graphique avec les composants bklit équivalents tout en préservant les données, les couleurs et les libellés. À utiliser lorsque l’utilisateur demande à remplacer, migrer, convertir ou porter des graphiques Recharts ou shadcn vers bklit, pour supprimer la dépendance à Recharts, ou demande ce qu’il faudrait pour changer de bibliothèque de graphiques.
