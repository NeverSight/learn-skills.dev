ترحيل مخططات التطبيق من Recharts إلى Bklit UI. يكتشف استخدام Recharts — الاستيراد المباشر لـ `recharts` أو الغلاف `components/ui/chart.tsx` الخاص بـ shadcn/ui (ChartContainer, ChartConfig, ChartTooltipContent, ChartLegendContent) — يجرد كل مخطط، يصنفه على أنه نظيف / يحتاج إلى حل بديل / يبقى على Recharts، يثبّت عناصر سجل shadcn المطابقة `@bklit/*`، ويعيد كتابة كل مخطط باستخدام مكوّنات bklit المكافئة مع الحفاظ على البيانات والألوان والوسوم. يُستخدم عندما يطلب المستخدم استبدال أو ترحيل أو تحويل أو نقل مخططات Recharts أو shadcn إلى bklit، لإزالة تبعية Recharts، أو يسأل عما يلزم لتغيير مكتبة المخططات.
