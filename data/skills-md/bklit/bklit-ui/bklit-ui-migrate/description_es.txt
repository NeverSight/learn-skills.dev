Migrar los gráficos de una aplicación de Recharts a Bklit UI. Detecta el uso de Recharts — importaciones directas de `recharts` o el wrapper `components/ui/chart.tsx` de shadcn/ui (ChartContainer, ChartConfig, ChartTooltipContent, ChartLegendContent) — inventaría cada gráfico, lo clasifica como limpio / necesita solución alternativa / mantener en Recharts, instala los elementos del registro `@bklit/*` de shadcn correspondientes y reescribe cada gráfico con los componentes equivalentes de bklit preservando datos, colores y etiquetas. Úselo cuando el usuario solicite reemplazar, migrar, convertir o portar gráficos de Recharts o shadcn a bklit, eliminar la dependencia de recharts, o pregunte qué se necesita para cambiar de biblioteca de gráficos.
