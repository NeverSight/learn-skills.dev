Turns plain-language chart design requests into exact Bklit UI (@bklit shadcn registry) components and props, styled to fit the host app. Use when someone describes how a chart should look rather than naming props, e.g. "diagonal pattern background that fades out", "squircle bars", "3D glass bars", "hatched area", "dot grid", "skeleton loading state", "dashed forecast", "half donut", "make the charts match my brand / dark mode / border radius". Detects the project's Tailwind version, colour format, dark-mode strategy, radius and existing chart tokens, then picks a proven recipe, installs the right @bklit/<item>, adapts colours to theme tokens and states honestly when Bklit has no prop for the request. Also use when theming or restyling Bklit charts.
