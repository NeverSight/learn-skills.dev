Transforme les demandes de conception de graphiques en langage clair en composants et propriétés Bklit UI exacts (@bklit shadcn registry), stylisés pour s’adapter à l’application hôte. À utiliser lorsqu’une personne décrit l’aspect d’un graphique plutôt que de nommer des props, par ex. « arrière‑plan à motif diagonal qui s’estompe », « barres squircle », « barres en verre 3D », « zone hachurée », « grille à points », « état de chargement skeleton », « prévision en pointillés », « demi‑donut », « faire correspondre les graphiques à ma marque / mode sombre / rayon de bordure ». Détecte la version de Tailwind du projet, le format des couleurs, la stratégie de mode sombre, le rayon et les jetons de graphiques existants, puis sélectionne une recette éprouvée, installe le bon @bklit/<item>, adapte les couleurs aux jetons de thème et indique honnêtement lorsqu’il n’existe pas de prop Bklit pour la demande. À utiliser aussi pour le thématisation ou le restylage des graphiques Bklit.  

Veuillez toujours répondre dans la langue de l’utilisateur.
