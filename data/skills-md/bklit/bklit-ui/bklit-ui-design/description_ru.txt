Превращает естественные запросы по дизайну диаграмм в точные компоненты и свойства Bklit UI (регистрация @bklit shadcn), стилизованные под приложение‑хост. Используется, когда кто‑то описывает, как должна выглядеть диаграмма, а не указывает свойства, например: «фон с диагональным узором, который исчезает», «квадратные кружёобразные столбцы», «3D‑стеклянные столбцы», «заштрихованная область», «сеточка точек», «скелетон‑загрузка», «пунктирный прогноз», «полукольцо», «сделайте диаграммы в стиле моего бренда / тёмного режима / скругления». Определяет версию Tailwind проекта, формат цвета, стратегию тёмного режима, радиус скругления и существующие токены диаграмм, затем выбирает проверенный рецепт, устанавливает нужный пакет @bklit/<item>, адаптирует цвета к токенам темы и откровенно сообщает, когда у Bklit нет свойства для запроса. Также используется при тематизации или переформатировании диаграмм Bklit.
