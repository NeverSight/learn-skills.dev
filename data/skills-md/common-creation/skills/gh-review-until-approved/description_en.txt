Continuously monitor a GitHub pull‑request review, validate each comment against the actual code and requirements, and for the correct comments only, fix, verify, commit, and push using git‑commit skills, repeating the process until the current PR head is formally approved. It is used for requests such as “monitor the review and keep fixing,” “continue until approval,” or “automate review handling with /goal,” accompanied by the GitHub PR URL. Comments that are erroneous, ambiguous, conflicting, dangerous, out of scope, or already satisfied are skipped from the changes, while the monitoring loop continues with the remaining comments.
