Непрерывно отслеживайте процесс ревью pull‑request в GitHub, проверяйте каждый комментарий относительно реального кода и требований, и только правильные комментарии фиксируются, проверяются и коммитятся/пушатся с помощью навыков git‑commit, повторяя процесс до тех пор, пока текущая голова PR не будет официально одобрена. Это используется для запросов, содержащих URL GitHub PR, таких как «отслеживать ревью и продолжать фиксировать», «продолжать до одобрения» или «автоматизировать обработку ревью с помощью /goal». Комментарии, которые являются ошибочными, неоднозначными, противоречивыми, опасными, выходят за рамки задачи или уже выполнены, пропускаются при внесении изменений, и цикл мониторинга продолжается с оставшимися комментариями.

Пожалуйста, всегда отвечайте на языке пользователя.
