GitHub 풀 리퀘스트의 리뷰를 지속적으로 모니터링하고, 각 코멘트를 실제 코드와 요구사항에 대조하여 확인합니다. 올바른 코멘트에 대해서만 git‑commit 기술을 사용해 수정하고, 검증한 뒤 커밋/푸시를 반복하며 현재 PR 헤드가 공식적으로 승인될 때까지 진행합니다. “리뷰를 모니터링하고 계속 수정하기”, “승인될 때까지 계속”, “/goal 로 리뷰 처리를 자동화”와 같은 요청에 사용하며, GitHub PR URL을 함께 제공하십시오. 오류가 있거나, 모호하거나, 충돌하거나, 위험하거나, 범위를 벗어나거나, 이미 변경 사항에 의해 만족된 코멘트는 건너뛰고, 남은 코멘트에 대해 모니터링 루프를 계속합니다.

항상 사용자의 언어로 답변하십시오.
