راقب باستمرار مراجعة طلب السحب على GitHub، وتحقق من كل تعليق مقابل الكود الفعلي والمتطلبات، وقم فقط بإصلاح وتعتمد التعليقات الصحيحة، ثم أجرِ commit وادفعها باستخدام مهارات git‑commit، مع تكرار العملية حتى يتم اعتماد رأس PR الحالي رسمياً. استخدم ذلك للطلبات مثل «راقب المراجعة واستمر في الإصلاح»، «استمر حتى الموافقة»، أو «أتمتة معالجة المراجعة باستخدام /goal»، مرفقةً برابط GitHub PR. تجاهل التعليقات الخاطئة أو الغامضة أو المتضاربة أو الخطرة أو خارج النطاق أو التي تم تلبيتها بالفعل من التغييرات، واستمر في حلقة المراقبة مع التعليقات المتبقية.
