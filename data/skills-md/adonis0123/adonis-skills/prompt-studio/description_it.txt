Trasforma una richiesta di immagine o video a una riga in un asset finito: indirizzala a un'immagine, a un Code Video reso da codice o a un Model Video, cerca in numerose librerie di prompt su GitHub prompt collaudati per immagini, prompt video-modello (Seedance, Kling, Veo, Hailuo/MiniMax, Wan, Grok Imagine) e modelli di code‑video, mostra i migliori 5 con i relativi esempi, modello, autore e licenza, scrivi un brief di generazione, consegnalo a un canale disponibile (strumento host, Codex/Grok CLI, API, Hyperframes), quindi controlla e registra il risultato. Utilizzalo ogni volta che l'utente desidera una copertina, un'illustrazione, un poster, una miniatura, un'infografica, un'animazione, una clip in movimento, un video AI o un prompt migliore per uno di questi, anche se dice semplicemente “fammi un'immagine”. Anche per richieste in lingua cinese per copertine WeChat, illustrazioni, clip da statico a movimento e ottimizzazione di prompt per immagini/video. Non è destinato a prompt generali per chatbot o codifica, a fotoritocco senza generazione, a implementazione UI o a presentazioni.
