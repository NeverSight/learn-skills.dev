Используйте, когда пользователю нужна обложка, иллюстрация, постер, миниатюра, инфографика, анимация, клип, AI‑видео или лучшая подсказка для них, даже если он просто сказал «сделай мне изображение». Также для запросов на китайском языке о обложках для WeChat, иллюстрациях, переходе из статичного в движение и оптимизации подсказок для изображений/видео.
