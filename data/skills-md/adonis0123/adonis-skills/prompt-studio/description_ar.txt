حوّل طلب صورة أو فيديو من سطر واحد إلى منتج نهائي: وجهه إلى صورة، أو فيديو مُكوَّن عبر الكود (Code Video) أو فيديو نموذج (Model Video)، ابحث في العديد من مكتبات الموجهات على GitHub عن موجهات صور مثبتة، وموجهات فيديو‑نموذج (Seedance، Kling، Veo، Hailuo/MiniMax، Wan، Grok Imagine) وقوالب فيديو‑كود، اعرض أفضل 5 مع عيناتها، النموذج، المؤلف والترخيص، اكتب ملخصاً للتوليد، سلّمه إلى قناة متاحة (أداة مضيفة، Codex/Grok CLI، API، Hyperframes)، ثم افحص وسجّل النتيجة. استخدم ذلك كلما أراد المستخدم غلافاً، أو توضيحاً، أو ملصقاً، أو صورةً مصغرة، أو مخططاً معلوماتياً، أو رسومًا متحركة، أو مقطع حركة، أو فيديو ذكاءً اصطناعيًا، أو موجهًا أفضل لواحدٍ منها، حتى وإن قال فقط «اصنع لي صورة». يشمل ذلك أيضًا الطلبات الصينية لأغلفة WeChat، والرسومات التوضيحية، ومقاطع ثابت‑إلى‑حركة، وتحسين موجهات الصورة/الفيديو. لا يُستخدم للمحادثات العامة أو موجهات الترميز، أو تعديل الصور دون توليد، أو تنفيذ واجهات المستخدم، أو عروض الشرائح.
