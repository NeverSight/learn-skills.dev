Проверьте, актуальны ли CLI Claude Code, Codex, Grok Build, Muse Code и Antigravity (Gemini), а затем при необходимости обновите устаревшие CLI после выбора y/Esc. `setup` выбирает, какие CLI проверять. Сначала он проверяет GitHub на наличие более новой версии самого себя и запрашивает y/n перед обновлением. Используйте, когда пользователь запускает /ai-cli-version или /check-uu (с `setup` или без), или просит проверить наличие обновлений, узнать, есть ли у CLI более новая версия, когда версия была выпущена или установлена, «моя CLI актуальна?», или «когда это было выпущено», включая эквивалентные запросы на любом языке.
