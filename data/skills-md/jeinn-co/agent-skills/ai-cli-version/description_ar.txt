تحقق مما إذا كانت واجهات سطر الأوامر (CLI) لـ Claude Code و Codex و Grok Build و Muse Code و Antigravity (Gemini) محدثة، ثم اختياريًا قم بتحديث الواجهات غير المحدثة بعد اختيار y/Esc. يحدد الأمر `setup` الواجهات التي يجب فحصها. يبدأ أولًا بالتحقق من GitHub وجود نسخة أحدث لنفسه ويسأل y/n قبل التحديث. يُستعمل عندما يُشغل المستخدم /ai-cli-version أو /check-uu (مع أو بدون `setup`)، أو يطلب فحص التحديثات، أو معرفة ما إذا كان هناك نسخة أحدث لواجهة الأوامر، أو متى تم إصدار أو تثبيت نسخة، أو «هل واجهتي محدثة»، أو «متى تم إصدار هذه النسخة»، بما في ذلك الطلبات المكافئة بأي لغة.
