Prüfen Sie, ob die CLIs Claude Code, Codex, Grok Build, Muse Code und Antigravity (Gemini) aktuell sind, und aktualisieren Sie optional veraltete CLIs nach einer y/Esc‑Auswahl. `setup` bestimmt, welche CLIs geprüft werden. Zuerst wird auf GitHub nach einer neueren Version von sich selbst gesucht und vor dem Update nach y/n gefragt. Verwenden Sie dies, wenn der Benutzer /ai-cli-version oder /check-uu (mit oder ohne `setup`) ausführt, oder nach Updates fragt, ob ein CLI eine neuere Version hat, wann eine Version veröffentlicht oder installiert wurde, „ist mein CLI aktuell“ oder „wann wurde das veröffentlicht“, einschließlich entsprechender Anfragen in jeder Sprache.
