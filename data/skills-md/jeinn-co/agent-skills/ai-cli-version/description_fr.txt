Vérifiez si les CLI Claude Code, Codex, Grok Build, Muse Code et Antigravity (Gemini) sont à jour, puis mettez éventuellement à jour les CLI obsolètes après un choix y/Esc. `setup` choisit les CLI à vérifier. Il vérifie d’abord sur GitHub s’il existe une version plus récente de lui‑même et demande y/n avant de mettre à jour. Utilisez‑le lorsque l’utilisateur exécute /ai-cli-version ou /check-uu (avec ou sans `setup`), ou demande de vérifier les mises à jour, de savoir si un CLI a une version plus récente, quand une version a été publiée ou installée, « mon CLI est‑il à jour », ou « quand cela a‑t‑il été publié », y compris les requêtes équivalentes dans n’importe quelle langue.

Répondez toujours dans la langue de l'utilisateur.
