檢查 Claude Code、Codex、Grok Build、Muse Code 與 Antigravity（Gemini）CLI 是否為最新版本，然後在使用者選擇 y/Esc 後可選擇更新過時的 CLI。`setup` 用於選擇要檢查的 CLI。它會先在 GitHub 上檢查自身是否有較新版本，並在更新前詢問 y/n。當使用者執行 /ai-cli-version 或 /check-uu（有或沒有 `setup`）時，或要求檢查更新、查詢某 CLI 是否有較新版本、版本何時發布或安裝、「我的 CLI 是否為最新」或「這個什麼時候發布」時，都可使用此功能，亦包括任何語言的等效請求。

請永遠以使用者的語言回覆。
