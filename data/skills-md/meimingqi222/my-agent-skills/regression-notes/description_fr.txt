Enregistrez les décisions de correction de bugs comme des Notes d'Agent liées aux tests de régression afin que les modifications de code pilotées par l'IA ne puissent pas régresser silencieusement. Utilisez-les lors de la correction d'un bug, de la révision d'un correctif, de la vérification d'un arbre de notes ou lorsqu'on demande quand rédiger un compte rendu post‑mortem. Ne les utilisez pas pour la documentation générale des fonctionnalités ou les journaux de modifications.

Veuillez toujours répondre dans la langue de l'utilisateur.
