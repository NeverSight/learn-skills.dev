Registra le decisioni di correzione dei bug come Note dell'Agente collegate ai test di regressione, così le modifiche al codice guidate dall'IA non possono regressare silenziosamente. Usa quando correggi un bug, rivedi una correzione, verifichi un albero di note o chiedi quando scrivere un postmortem. Non usarlo per documentazione generale delle funzionalità o changelog.
