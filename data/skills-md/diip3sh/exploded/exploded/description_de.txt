Wandle eine reale, gerenderte UI-Komponente (Button, Input, Switch, Card, Menü, Dialog, irgendeine React/Vue/HTML-Komponente) in ein lebendiges, interaktives, exploded Spec Sheet um. Die Komponente wird isometrisch in ihre Farbe‑Schichten (Elevation, Surface, Stroke, innere Flächen, Content, Fokus‑Ring) zerlegt, jeder Zustand (Hover, Focus, Pressed, Disabled, Invalid, On/Off) kann umgeschaltet werden, und jede Messgröße (Padding, Radius, Gap, Type, Shadow, Ring) plus das Design‑Token, das der Autor tatsächlich geschrieben hat, wird aus dem Browser ausgelesen, nie manuell eingegeben. Nutze dies, wann immer jemand Komponenten‑Dokumentation, eine Design‑System‑ oder Storybook‑Seite, ein „Spec Sheet“, Redlines, eine Anatomie oder Aufschlüsselung einer Komponente, eine exploded‑ bzw. geschichtete Ansicht von UI, ein visuelles Handoff‑Dokument oder einen interaktiven Erklärer darüber, wie eine Komponente aufgebaut ist, benötigt – selbst wenn sie nie das Wort „exploded“ erwähnen. Funktioniert rahmenfrei (ein Skript und ein Stylesheet) und in React/Next.js über eine Wrapper‑Komponente.
