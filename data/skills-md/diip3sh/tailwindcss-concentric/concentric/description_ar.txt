ثبّت، قم بإعداد واستخدام ملحق tailwindcss-concentric لإصلاح ومنع عدم تطابق نصف قطر الزوايا المتداخلة في مشروعات Tailwind CSS الإصدار 4. استخدمه عندما يطلب المستخدم إضافة أو إعداد tailwindcss-concentric، أو لتدقيق أو إصلاح نصف أقطار الحدود المتداخلة، أو عند بناء أو مراجعة واجهة مستخدم يكون فيها عنصر مستدير داخل عنصر أصل مستدير مبطن أو مُحدّد الحواف (بطاقات مع وسائط، أزرار في أشرطة البحث أو الأدوات، عناصر تحكم مقسمة، حلقات اختيار، نوافذ منبثقة، مجموعات إدخال)، وعند رؤية نصف أقطار داخلية محددة يدويًا مثل rounded-[calc(...) ]، أو عندما يذكر المستخدم كلمة «متحدة المركز»، «متداخلة»، «داخلية» أو «خارجية» لنصف قطر الزاوية. يرجى الرد دائمًا بلغة المستخدم.
