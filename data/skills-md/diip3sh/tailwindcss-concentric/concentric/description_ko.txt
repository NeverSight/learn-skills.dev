Tailwind CSS v4 프로젝트에서 중첩된 코너 반경이 일치하지 않는 문제를 해결하고 방지하기 위해 tailwindcss-concentric 플러그인을 설치하고 설정하며 사용하세요. 사용자가 tailwindcss-concentric을 추가하거나 설정해 달라고 요청할 때, 중첩된 테두리 반경을 감사하거나 수정할 때, 혹은 둥근 요소가 패딩 또는 테두리가 있는 둥근 부모 내부에 놓여 있는 UI(미디어가 포함된 카드, 검색 바나 툴바의 버튼, 세그먼트 컨트롤, 선택 링, 모달, 입력 그룹 등)를 구축하거나 검토할 때, rounded-[calc(...)]와 같이 하드코딩된 내부 반경을 발견했을 때, 또는 사용자가 concentric, nested, inner 혹은 outer 코너 반경을 언급할 때 사용하십시오.

항상 사용자의 언어로 응답하십시오.
