Instala, configura y utiliza el plugin tailwindcss-concentric para corregir y prevenir radios de esquina anidados desajustados en proyectos Tailwind CSS v4. Úsalo cuando el usuario solicite añadir o configurar tailwindcss-concentric, para auditar o arreglar radios de borde anidados, o al crear o revisar una UI donde un elemento redondeado está dentro de un padre redondeado con relleno o borde (tarjetas con medios, botones en barras de búsqueda o barras de herramientas, controles segmentados, anillos de selección, modales, grupos de entrada), cuando veas radios internos codificados como rounded-[calc(...)], o cuando el usuario mencione radios de esquina concéntricos, anidados, internos o externos.
