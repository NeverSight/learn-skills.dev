Install, set up and use the tailwindcss-concentric plugin to fix and prevent mismatched nested corner radii in Tailwind CSS v4 projects. Use when the user asks to add or set up tailwindcss-concentric, to audit or fix nested border radii, or when building or reviewing UI where a rounded element sits inside a padded or bordered rounded parent (cards with media, buttons in search bars or toolbars, segmented controls, selection rings, modals, input groups), when you see hard-coded inner radii such as rounded-[calc(...)], or when the user mentions concentric, nested, inner or outer corner radius.
