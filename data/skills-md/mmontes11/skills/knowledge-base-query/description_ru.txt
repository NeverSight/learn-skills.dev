Отвечайте на вопросы о том, что знает mmontes11/knowledge‑base — отслеживаемый проект (что это, его API, последняя версия, функции, архитектура), книга в `books/` или фундаментальная тема в `foundation/` — читая таблицы индексов в корневом README, чтобы найти нужную папку, а затем читая соответствующий файл. Используйте это, когда пользователь задаёт вопрос, на который может дать ответ база знаний, и хочет получить ответ, основанный именно на ней — «что делает <project>», «какая последняя версия <project>», «как работает API <project>», «какие проекты отслеживает база знаний», «что говорит база знаний о <topic>», «суммируйте главу N книги <book>» — а не полагаясь на общие знания.

Пожалуйста, всегда отвечайте на языке пользователя.
