Répondez aux questions sur ce que le mmontes11/knowledge-base sait — un projet suivi (ce que c’est, son API, sa dernière version, ses fonctionnalités, son architecture), un livre dans `books/`, ou un sujet fondamental dans `foundation/` — en lisant les tables d’index du README racine pour localiser le bon dossier, puis en lisant le fichier pertinent. Utilisez cela chaque fois que l’utilisateur demande quelque chose que la base de connaissances pourrait contenir et souhaite une réponse ancrée dans celle‑ci — « what does <project> do », « what's the latest release of <project> », « how does <project>'s API work », « which projects does the knowledge base track », « what does the knowledge base say about <topic> », « summarize chapter N of <book> » — plutôt que de se baser sur des connaissances générales.

Veuillez toujours répondre dans la langue de l’utilisateur.
