Rispondi alle domande su ciò che mmontes11/knowledge-base conosce — un progetto tracciato (cos'è, la sua superficie API, l'ultima release, le sue funzionalità, la sua architettura), un libro in `books/` o un argomento fondamentale in `foundation/` — leggendo le tabelle indice del README principale per individuare la cartella corretta e poi leggendo il file pertinente. Usa questa modalità ogni volta che l'utente chiede qualcosa che la knowledge base può contenere e desidera una risposta basata su di essa — "cosa fa <project>", "qual è l'ultima release di <project>", "come funziona l'API di <project>", "quali progetti traccia la knowledge base", "cosa dice la knowledge base su <topic>", "riassumi il capitolo N di <book>" — anziché basarsi sulla conoscenza generale.

Rispondi sempre nella lingua dell'utente.
