Add a new tracked project (or a new category) to the mmontes11/knowledge-base `projects/` section, or update an existing project during a maintenance run. Create the fixed set of standard documents (README, api-reference, releases, features, optional architecture) populated and attributed from upstream, keep frontmatter fresh, register the project in the Tracked projects table, and push to main. Use whenever the user wants to add, track, or refresh a project in the knowledge base — "add <repo> to the knowledge base", "start tracking <project>", "update the <project> entry", "run the maintenance for <project>", "add a new category <x>" — even if they only name the upstream repository.
