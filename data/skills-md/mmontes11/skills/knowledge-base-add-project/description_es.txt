Agregar un nuevo proyecto rastreado (o una nueva categoría) a la sección `projects/` de mmontes11/knowledge-base, o actualizar un proyecto existente durante una ejecución de mantenimiento. Crear el conjunto fijo de documentos estándar (README, api-reference, releases, features, optional architecture) poblados y atribuidos desde upstream, mantener el frontmatter actualizado, registrar el proyecto en la tabla de Proyectos rastreados y hacer push a main. Usar siempre que el usuario quiera añadir, rastrear o refrescar un proyecto en la base de conocimientos — "add <repo> to the knowledge base", "start tracking <project>", "update the <project> entry", "run the maintenance for <project>", "add a new category <x>" — incluso si solo menciona el repositorio upstream.
