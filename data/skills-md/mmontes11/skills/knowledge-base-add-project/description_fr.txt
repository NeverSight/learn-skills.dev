Ajoutez un nouveau projet suivi (ou une nouvelle catégorie) à la section `projects/` du dépôt mmontes11/knowledge-base, ou mettez à jour un projet existant lors d’une session de maintenance. Créez l’ensemble fixe de documents standards (README, api-reference, releases, features, architecture optionnelle) remplis et attribués à partir de l’amont, maintenez le front‑matter à jour, enregistrez le projet dans le tableau des projets suivis, et poussez la modification vers la branche principale. Utilisez cela chaque fois que l’utilisateur veut ajouter, suivre ou rafraîchir un projet dans la base de connaissances — « add <repo> to the knowledge base », « start tracking <project> », « update the <project> entry », « run the maintenance for <project> », « add a new category <x> » — même s’il ne mentionne que le dépôt amont.
