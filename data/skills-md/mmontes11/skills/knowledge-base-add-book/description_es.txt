Añade un nuevo libro a la sección `books/` del repositorio mmontes11/knowledge-base: crea la entrada con formato de libro (README de la entrada, un archivo numerado por capítulo, el PDF fuente), resume cada capítulo fielmente y atribúyelo, agrega diagramas mermaid donde aclaren un mecanismo y registra el libro en la tabla de Libros rastreados del README raíz. Utiliza esta instrucción siempre que el usuario quiera añadir, crear o importar un libro a la base de conocimiento — “añade este libro a la base de conocimiento”, “resume <book> para la KB”, “crea una entrada books/ para <title>”, “trabaja el capítulo N de <book>” — incluso si no menciona explícitamente “base de conocimiento”.

Por favor, responde siempre en el idioma del usuario.
