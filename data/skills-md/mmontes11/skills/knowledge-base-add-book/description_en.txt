Add a new book to the mmontes11/knowledge-base `books/` section: create the book-shaped entry (entry README, one numbered file per chapter, the source PDF), summarize each chapter faithfully and attribute it, add mermaid diagrams where they clarify a mechanism, and register the book in the root README's Tracked books table. Use whenever the user wants to add, create, or import a book into the knowledge base — "add this book to the knowledge base", "summarize <book> for the KB", "create a books/ entry for <title>", "work through chapter N of <book>" — even if they don't say "knowledge base" explicitly.
