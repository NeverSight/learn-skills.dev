將一本新書加入 mmontes11/knowledge-base 的 `books/` 目錄：建立書籍條目（條目 README、每章一個編號檔案、原始 PDF），忠實地概括每章並註明來源，在需要澄清機制的地方加入 mermaid 圖表，並將此書登錄於根目錄 README 的「Tracked books」表格。無論使用者是否明確說出「knowledge base」，只要他們想要新增、建立或匯入書籍——例如「將這本書加入知識庫」、「為 KB 概要 <book>」、「為 <title> 建立 books/ 條目」、「逐章研讀 <book> 的第 N 章」——皆使用此指令。請始終以使用者的語言回覆。
