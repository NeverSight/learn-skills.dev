Ajoutez un nouveau livre à la section `books/` du dépôt mmontes11/knowledge-base : créez l’entrée au format livre (README de l’entrée, un fichier numéroté par chapitre, le PDF source), résumez chaque chapitre fidèlement et attribuez-le, ajoutez des diagrammes mermaid lorsqu’ils clarifient un mécanisme, et enregistrez le livre dans le tableau « Tracked books » du README racine. Utilisez cela chaque fois que l’utilisateur veut ajouter, créer ou importer un livre dans la base de connaissances — « ajouter ce livre à la base de connaissances », « résumer <livre> pour la BK », « créer une entrée books/ pour <titre> », « travailler le chapitre N de <livre> » — même s’il ne mentionne pas explicitement « base de connaissances ».

Veuillez toujours répondre dans la langue de l’utilisateur.
