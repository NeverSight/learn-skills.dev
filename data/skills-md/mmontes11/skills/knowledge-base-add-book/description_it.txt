Aggiungi un nuovo libro alla sezione `books/` del repository mmontes11/knowledge-base: crea la voce a forma di libro (README della voce, un file numerato per capitolo, il PDF originale), riassumi fedelmente ogni capitolo e attribuiscilo, aggiungi diagrammi mermaid dove chiariscono un meccanismo e registra il libro nella tabella “Tracked books” del README principale. Usa questa procedura ogni volta che l'utente vuole aggiungere, creare o importare un libro nella knowledge base — “add this book to the knowledge base”, “summarize <book> for the KB”, “create a books/ entry for <title>”, “work through chapter N of <book>” — anche se non menziona esplicitamente “knowledge base”.
