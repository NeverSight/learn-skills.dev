أضف كتابًا جديدًا إلى قسم `books/` في قاعدة معرفة mmontes11/knowledge-base: أنشئ الإدخال الخاص بالكتاب (ملف README للإدخال، ملف صغير مرقّم لكل فصل، ملف PDF المصدر)، لخص كل فصل بأمانة وأشر إلى المصدر، أضف مخططات mermaid حيث توضح آلية معينة، وسجل الكتاب في جدول “الكتب المتتبعة” بملف README الرئيسي. استخدم هذا الإجراء كلما أراد المستخدم إضافة، إنشاء أو استيراد كتاب إلى قاعدة المعرفة — "أضف هذا الكتاب إلى قاعدة المعرفة"، "لخص <الكتاب> للقاعدة"، "أنشئ إدخالًا في books/ لـ <العنوان>"، "اعمل على الفصل N من <الكتاب>" — حتى وإن لم يذكر صراحةً "قاعدة المعرفة".  

يرجى دائمًا الرد بلغة المستخدم.
