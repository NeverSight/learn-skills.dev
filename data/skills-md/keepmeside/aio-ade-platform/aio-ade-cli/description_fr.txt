Utilisez le CLI public `aio-ade` pour gérer les worktrees contrôlés par AIO-ADE, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les commentaires de worktree et le navigateur intégré dans l'application AIO-ADE. Utilisez-le lorsque l'utilisateur dit « $aio-ade-cli », « use aio-ade cli », « AIO-ADE worktree », « child worktree », « cardStatus », « spawn codex/claude in a worktree », « read/wait/send AIO-ADE terminal », « terminal send », « full handoff », « handover », « give this to another agent », « another worktree », « AIO-ADE browser » ou « control the browser inside AIO-ADE ». Privilégiez cela à `git worktree` brut, aux PTY ad hoc, à Playwright ou à l’Utilisation de l’Ordinateur lorsque la tâche touche un état géré par AIO-ADE. Utilisez l’Utilisation de l’Ordinateur pour les fenêtres de navigateur, les vues web ou l’interface UI du bureau en dehors du navigateur intégré d’AIO-ADE.

Veuillez toujours répondre dans la langue de l’utilisateur.
