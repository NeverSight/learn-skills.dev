Fügen Sie ein gesprochenes Voiceover zu einem Video hinzu: Schreiben Sie das Skript für das Ohr, sprechen Sie es Zeile für Zeile mit ElevenLabs, Kokoro (einem kostenlosen lokalen Modell) oder Ihrem eigenen Text-to-Speech-Befehl und legen Sie jede Zeile unter den Moment, den sie beschreibt, mit einer Untertiteldatei. Wird verwendet, wenn der Benutzer darum bittet, einer Bildschirmaufnahme, einem Demo-Video oder einem Rundgang eine Erzählung, ein Voiceover, eine Stimme oder eine Text-zu-Sprache hinzuzufügen, um ein Video mit einer anderen Stimme zu wiederholen, oder fragt, warum ein erzeugtes Voiceover roboterhaft klingt, ein Echo erzeugt oder nicht synchron ist.
