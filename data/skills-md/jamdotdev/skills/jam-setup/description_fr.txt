Configurer Jam (enregistrements d’écran et captures d’écran de jam.dev avec la console, le réseau et les actions utilisateur attachés) pour cet agent de codage en une seule exécution, dans l’ordre : installer le CLI Jam, se connecter, connecter le MCP Jam, installer les compétences Jam, puis vérifier le tout avec `jam doctor`. Utiliser lorsque l’utilisateur dit « set up jam », « install jam », « connect jam to claude/cursor/codex », « jam isn’t working », ou lorsqu’une compétence Jam s’est arrêtée parce que le CLI, la connexion ou le MCP manquait.
