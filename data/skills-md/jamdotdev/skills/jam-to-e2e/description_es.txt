Convierta un Jam (una grabación de pantalla jam.dev con la consola, la red y las acciones del usuario adjuntas) en pasos y una prueba de extremo a extremo en el propio runner y lenguaje del proyecto, con orientación de primera clase para Playwright y tester-army/e2e, basada en el código actual. Un atasco de un flujo o demostración se convierte en una prueba que lo protege; un atasco de un error se convierte en una prueba fallida, la solución se vuelve verde. Se utiliza cuando el usuario pega un enlace jam.dev y solicita una prueba e2e, una prueba de regresión, una repro o "escribir una prueba para esto".
