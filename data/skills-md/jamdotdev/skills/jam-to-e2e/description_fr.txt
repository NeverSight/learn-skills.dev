Transformez un Jam (un enregistrement d'écran Jam.dev avec la console, le réseau et les actions de l'utilisateur attachés) en étapes et en un test de bout en bout dans le propre runner et le langage du projet, avec des conseils de première classe pour Playwright et testeur-armée/e2e, ancrés dans le code actuel. Un bourrage d'un flux ou d'une démo devient un test qui le protège ; un bourrage d'un bug devient un test défaillant, le correctif devient vert. À utiliser lorsque l'utilisateur colle un lien jam.dev et demande un test e2e, un test de régression, un repro, ou pour « écrire un test pour cela ».
