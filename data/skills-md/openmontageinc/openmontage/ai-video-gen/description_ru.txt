Генерируйте AI‑видео из текстовых подсказок, используя несколько шлюзов поставщиков. Используйте, когда: (1) создаёте видео из текстовых описаний, (2) создаёте AI‑сгенерированные видеоклипы для производства контента, (3) генерируете видео из изображения по референс‑изображению, (4) выбираете между провайдерами генерации видео (VEO, Kling, Sora, Runway, Seedance, MiniMax, Gemini Omni). Поддерживаются шлюзы: HeyGen API, fal.ai API и Gemini API (Gemini Omni Flash).
