Обмен лицами в видео с помощью ИИ через API HeyGen. Использовать, когда: (1) заменяете лицо в видео другим лицом, (2) переносите лицо с исходного изображения на целевое видео, (3) создаёте персонализированные видео, вставляя лицо конкретного человека, (4) работаете с конечной точкой /v1/workflows/executions сервиса HeyGen для обработки замены лиц.
