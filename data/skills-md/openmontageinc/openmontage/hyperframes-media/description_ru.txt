Аудио‑ и медиа‑ресурсы для композиций HyperFrames, создаваемые одним общим аудио‑движком (`scripts/audio.mjs`) — многопровайдерный TTS (HeyGen / ElevenLabs / Kokoro local), фоновая музыка + звуковые эффекты (по умолчанию получение из аудио‑библиотеки HeyGen, с локальной генерацией BGM через Lyria / MusicGen и встроенной библиотекой SFX как резерв без учётных данных), транскрипция Whisper, удаление фона и создание субтитров. Используйте для озвучки / TTS, фоновой музыки, SFX / звуковых эффектов, транскрипции, субтитров / титров / текстов песен / караоке / стилизации по словам, выбора голоса + провайдера и подсказывания музыкального настроения.
