Шаблоны композиции React, которые масштабируются. Используйте при рефакторинге компонентов с избыточным использованием булевых пропов, построении гибких библиотек компонентов или проектировании переиспользуемых API. Применяется к задачам, связанным со составными компонентами, render props, провайдерами контекста или архитектурой компонентов. Включает изменения API React 19.
