Понимайте содержимое видео локально с помощью извлечения кадров ffmpeg и транскрипции Whisper. Ключи API не требуются.  
Используйте, когда: (1) Нужно понять, что содержит видео, (2) Транскрибировать аудио видео локально, (3) Выделять ключевые кадры для визуального анализа, (4) Получать содержимое видео без ключей API.
