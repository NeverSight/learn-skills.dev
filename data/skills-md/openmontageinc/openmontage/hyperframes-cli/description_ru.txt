Цикл разработки HyperFrames CLI. Используется при запуске npx hyperframes init, add, catalog, capture, lint, validate, inspect, layout, snapshot, preview, play, render, publish, lambda, doctor, browser, info, upgrade, skills, compositions, docs, benchmark, telemetry, transcribe, tts или remove‑background, а также при устранении неполадок среды сборки/рендеринга HyperFrames. Точка входа для облачного рендеринга AWS Lambda (`hyperframes lambda deploy / render / progress / destroy / policies`).
