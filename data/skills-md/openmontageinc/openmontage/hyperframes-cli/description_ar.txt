حلقة تطوير CLI لـ HyperFrames. استخدمها عند تشغيل npx hyperframes init، add، catalog، capture، lint، validate، inspect، layout، snapshot، preview، play، render، publish، lambda، doctor، browser، info، upgrade، skills، compositions، docs، benchmark، telemetry، transcribe، tts، أو remove‑background، أو عند استكشاف أخطاء بيئة بناء/تصيير HyperFrames. نقطة الدخول لتصوير السحابة عبر AWS Lambda (`hyperframes lambda deploy / render / progress / destroy / policies`).
