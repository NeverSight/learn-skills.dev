Guida gli utenti nella configurazione di una chiave API di ElevenLabs per gli strumenti ElevenLabs MCP. Da usare quando l'utente deve configurare una chiave API di ElevenLabs, quando gli strumenti ElevenLabs falliscono a causa della chiave API mancante, o quando l'utente menziona la necessità di accedere a ElevenLabs. Prima verifica se ELEVENLABS_API_KEY è già configurata e valida, e avvia la configurazione completa solo se necessario.

Rispondi sempre nella lingua dell'utente.
