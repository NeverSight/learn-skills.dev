Guide les utilisateurs pour configurer une clé API ElevenLabs pour les outils ElevenLabs MCP. Utilisez ce guide lorsque l'utilisateur doit configurer une clé API ElevenLabs, lorsque les outils ElevenLabs échouent en raison d’une clé API manquante, ou lorsque l'utilisateur mentionne qu’il a besoin d’accéder à ElevenLabs. Vérifie d'abord si la variable ELEVENLABS_API_KEY est déjà configurée et valide, et ne lance la configuration complète que si nécessaire.

Veuillez toujours répondre dans la langue de l'utilisateur.
