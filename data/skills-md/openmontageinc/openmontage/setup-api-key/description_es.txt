Guía a los usuarios para configurar una clave API de ElevenLabs para las herramientas MCP de ElevenLabs. Úsela cuando el usuario necesite configurar una clave API de ElevenLabs, cuando las herramientas de ElevenLabs fallen por falta de clave API, o cuando el usuario mencione que necesita acceso a ElevenLabs. Primero verifica si ELEVENLABS_API_KEY ya está configurada y es válida, y solo ejecuta la configuración completa cuando sea necesario.

Por favor, siempre responda en el idioma del usuario.
