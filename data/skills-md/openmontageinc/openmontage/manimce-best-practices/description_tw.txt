觸發條件： (1) 使用者提到「manim」或「Manim Community」或「ManimCE」； (2) 程式碼包含 `from manim import *`； (3) 使用者執行 `manim` CLI 指令； (4) 正在使用 Scene、MathTex、Create() 或 ManimCE 專屬類別。

Manim Community Edition 的最佳實踐──由社群維護的 Python 動畫引擎。內容涵蓋 Scene 結構、動畫、LaTeX/MathTex、使用 ThreeDScene 的 3D、相機控制、樣式設定與 CLI 使用方式。

不適用於 ManimGL/3b1b 版本（該版本使用 `manimlib` 匯入與 `manimgl` CLI）。

請始終以使用者的語言回覆。
