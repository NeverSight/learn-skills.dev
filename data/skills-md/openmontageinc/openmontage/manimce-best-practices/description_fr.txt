Déclencher lorsqu : (1) l’utilisateur mentionne « manim », « Manim Community » ou « ManimCE », (2) le code contient `from manim import *`, (3) l’utilisateur exécute des commandes CLI `manim`, (4) il travaille avec Scene, MathTex, Create() ou des classes spécifiques à ManimCE.

Bonnes pratiques pour Manim Community Edition – le moteur d’animation Python maintenu par la communauté. Couvre la structure des scènes, les animations, LaTeX/MathTex, la 3D avec ThreeDScene, le contrôle de la caméra, le style et l’utilisation de la ligne de commande.

PAS pour la version ManimGL/3b1b (qui utilise les imports `manimlib` et la CLI `manimgl`).

Veuillez toujours répondre dans la langue de l’utilisateur.
