Disparador cuando: (1) el usuario menciona “manim” o “Manim Community” o “ManimCE”, (2) el código contiene `from manim import *`, (3) el usuario ejecuta comandos CLI de `manim`, (4) se trabaja con Scene, MathTex, Create() o clases específicas de ManimCE.

Mejores prácticas para Manim Community Edition, el motor de animación de Python mantenido por la comunidad. Cubre la estructura de Scene, animaciones, LaTeX/MathTex, 3D con ThreeDScene, control de cámara, estilo y uso de la CLI.

NO es para la versión ManimGL/3b1b (que usa importaciones `manimlib` y la CLI `manimgl`).
