Crear visualizaciones de datos interactivas usando d3.js. Esta habilidad debe emplearse al crear gráficos, diagramas, redes, visualizaciones geográficas o cualquier visualización de datos compleja basada en SVG que requiera un control muy detallado sobre los elementos visuales, transiciones o interacciones. Utilícela para visualizaciones a medida más allá de las bibliotecas de gráficos estándar, ya sea en React, Vue, Svelte, JavaScript puro o cualquier otro entorno.
