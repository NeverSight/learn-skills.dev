Agent Media OS — решает любую медиапотребность (фонова музыка — BGM, звуковые эффекты — SFX, изображение, иконка) в замороженный локальный файл + запись в реестр. Один глагол (`resolve`) обрабатывает всю каскаду — кеш проекта, глобальный кеш, поиск в каталоге HeyGen, «заморозка», регистрация. Сохраняет «шум» поиска на диске, передаёт агенту путь. Используйте, когда композиции нужна фоновая музыка, звуковые эффекты, изображения или иконки.
