Agent Media OS — löse jeden Medienbedarf (BGM, SFX, Bild, Icon) in eine eingefrorene lokale Datei + Ledger‑Eintrag auf. Ein einziges Verb (`resolve`) übernimmt die komplette Kaskade — Projekt‑Cache, Global‑Cache, HeyGen‑Katalogsuche, Einfrieren, Registrieren. Hält Suchrauschen auf der Festplatte und gibt dem Agenten einen Pfad. Verwenden, wenn eine Komposition Hintergrundmusik, Soundeffekte, Bilder oder Icons benötigt.
