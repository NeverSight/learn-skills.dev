Agent Media OS — risolve qualsiasi esigenza di media (BGM, SFX, immagine, icona) in un file locale congelato + record del registro. Un solo verbo (`resolve`) gestisce l'intera cascata — cache del progetto, cache globale, ricerca nel catalogo HeyGen, congelamento, registrazione. Mantiene il rumore delle ricerche su disco, consegna all'agente un percorso. Da utilizzare quando una composizione ha bisogno di musica di sottofondo, effetti sonori, immagini o icone.
