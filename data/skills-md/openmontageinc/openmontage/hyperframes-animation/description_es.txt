Todo el conocimiento de animación para HyperFrames — reglas atómicas de movimiento, planos de escena multifiásicos, transiciones de escena, técnicas más amplias de motion‑design, Y los siete adaptadores de tiempo de ejecución (GSAP por defecto, más Lottie, Three.js, Anime.js, keyframes CSS, Web Animations API, TypeGPU). Úsalo para cualquier tarea de movimiento o animación: elige de 2 a 4 reglas y compón, o carga un plano, o busca la API específica del runtime (p. ej., easing de GSAP / reproductor Lottie / mezclador de Three.js). Nativo de HyperFrames: línea de tiempo única en pausa, seguro para buscar, determinista.
