Все анимационные знания для HyperFrames — атомарные правила движения, многофазные чертежи сцен, переходы между сценами, более широкие техники motion‑design и семь адаптеров среды выполнения (GSAP по умолчанию, плюс Lottie, Three.js, Anime.js, CSS‑ключевые кадры, Web Animations API, TypeGPU). Используйте для любой задачи по движению или анимации: выберите 2‑4 правила и составьте композицию, загрузите чертёж или найдите API конкретного рантайма (например, плавные функции GSAP / плеер Lottie / микшер Three.js). Нативный HyperFrames: один приостановленный таймлайн, безопасный при перемотке, детерминированный.
