使用 ByteDance Seedance 2.0 生成電影剪輯 — 在配置付費閘道時，OpenMontage 中首選的高級影片模型。適用情境：(1) 製作預告片、預熱短片、宣傳剪輯或高品質電影剪輯；(2) 需要一次性產生同步的原生音訊（語音、音效、環境音）；(3) 需要在一次生成中完成多鏡頭剪輯；(4) 需要導演級的鏡頭控制；(5) 需要根據提示中引用的對話進行唇形同步；(6) 需要以最多 9 張圖像 + 3 段影片 + 3 段音訊作為參考條件的生成；(7) 想要在不同鏡頭中保持角色身份一致。可透過 fal.ai（`seedance_video` 工具）、HeyGen（Video Agent / Avatar Shots）、Replicate、Runway（企業版，非美國地區）、Freepik、BytePlus ModelArk、Higgsfield、Pollo 以及其他聚合平台存取。
