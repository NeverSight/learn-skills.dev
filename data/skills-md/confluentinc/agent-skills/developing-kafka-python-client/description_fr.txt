Utilisez-le lorsque l'utilisateur souhaite créer un producteur ou un consommateur Kafka en Python, ajouter le registre de schémas à du code Python existant, migrer du JSON brut vers une sérialisation basée sur un schéma, ou générer un projet confluent‑kafka‑python pour Confluent Cloud, Docker local ou WarpStream. Utilisez-le également lorsque l'utilisateur veut optimiser la configuration du client Kafka Python pour WarpStream.
