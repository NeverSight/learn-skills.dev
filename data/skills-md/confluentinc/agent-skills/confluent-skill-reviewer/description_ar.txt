راجع مهارة وكيل Confluent في هذا المستودع وفقًا لمواصفات مهارات الوكيل (agentskills.io) ومعايير Confluent الموجودة في CLAUDE.md وبوابات قالب طلب السحب، وقاعدة evals-as-contract. استخدم هذه المهارة كلما طلب المستخدم مراجعة أو تدقيق أو تحقق أو فحص (lint) لمهارة؛ أو فتح أو فحص طلب سحب يضيف أو يغيّر أي شيء تحت `skills/`؛ أو سأل عن توافق المواصفات، التحميل المتأخر، شكل الـ frontmatter، تداخل المشغلات، أو تغطية التقييم؛ أو يرغب في فحص صحة ما قبل الدمج لتغييرات المهارة. لا تُفعّل لهذه الحالات: مراجعة الكود العامة لتطبيقات؛ مراجعة الأمن؛ تدقيق المخططات، إعدادات المنتج/المستهلك، تصنيف البيانات الشخصية (PII)، أو توليد Terraform لسجل المخططات (يُدار بواسطة `kafka-schema-registry`)؛ تحليل وقت التشغيل/السجلات لسلوك المهارة (استخدم `tools/skill_review_dashboard.py`)؛ أو أي تغييرات لا تمس شجرة `skills/`.

يرجى دائمًا الرد بلغة المستخدم.
