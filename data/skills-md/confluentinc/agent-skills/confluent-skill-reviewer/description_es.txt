Revisa una skill de agente Confluent en este repositorio contra la especificación Agent Skills (agentskills.io), las convenciones Confluent en CLAUDE.md, los filtros de la plantilla de PR y la regla evals-as-contract. Usa esta skill siempre que el usuario solicite revisar, auditar, validar o hacer lint a una skill; abra o inspeccione un PR que agregue o modifique cualquier cosa bajo `skills/`; pregunte sobre la conformidad con la especificación, lazy-loading, la forma del frontmatter, superposición de disparadores o cobertura de evals; o quiera una verificación de sentido antes de fusionar los cambios de la skill. NO se active para revisiones generales de código de aplicación; revisión de seguridad; auditoría de esquemas, configuraciones de productor/consumidor, etiquetado de PII o generación de Terraform para Schema Registry (manejado por `kafka-schema-registry`); análisis de tiempo de ejecución/logs del comportamiento de la skill (usa `tools/skill_review_dashboard.py`); o cualquier cambio que no afecte al árbol `skills/`.

Por favor, siempre responde en el idioma del usuario.
