Revisiona una skill agente Confluent in questo repository rispetto alla specifica Agent Skills (agentskills.io), alle convenzioni Confluent in CLAUDE.md, ai gate del modello di PR e alla regola evals-as-contract. Usa questa skill ogni volta che l'utente chiede di revisionare, auditare, validare o lintare una skill; apre o ispeziona una PR che aggiunge o modifica qualsiasi cosa sotto `skills/`; chiede della conformità alla specifica, del lazy-loading, della forma del frontmatter, della sovrapposizione dei trigger o della copertura degli eval; o vuole un controllo di sanità pre‑merge sulle modifiche alla skill. NON attivare per revisioni generiche di codice applicativo; revisione di sicurezza; audit di schemi, configurazioni producer/consumer, etichettatura PII o generazione Terraform per Schema Registry (gestito da `kafka-schema-registry`); analisi runtime/log del comportamento della skill (usa `tools/skill_review_dashboard.py`); o qualsiasi modifica che non tocchi l'albero `skills/`.

Rispondi sempre nella lingua dell'utente.
