Создавайте навыки, специфичные для Confluent, для внешних пользователей. Используйте этот навык, когда пользователи хотят создать, разработать или написать новый навык, связанный с Confluent Cloud, Confluent Platform, Apache Kafka, WarpStream, Flink, коннекторами, Schema Registry, Tableflow, CDC‑конвейерами или любым продуктом Confluent. Навыки могут быть ориентированы на конкретный сценарий (например, обогащение данных, CDC в Tableflow, рабочие процессы потоковой обработки) или на отдельный компонент (например, навык Flink, навык Schema Registry или навык Connector). НЕ используйте этот навык, когда пользователи хотят напрямую работать с продуктами Confluent (например, построить конвейер, написать продюсер, развернуть Flink SQL) — вместо этого применяйте соответствующий продуктовый навык. Этот навык предназначен исключительно для создания новых навыков, а не для использования существующих. 

Пожалуйста, всегда отвечайте на языке пользователя.
