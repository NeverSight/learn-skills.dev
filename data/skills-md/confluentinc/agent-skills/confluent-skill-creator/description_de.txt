Erstelle Confluent-spezifische Skills für externe Benutzer. Verwende diesen Skill, wenn Benutzer einen neuen Skill im Zusammenhang mit Confluent Cloud, Confluent Platform, Apache Kafka, WarpStream, Flink, Connectors, Schema Registry, Tableflow, CDC‑Pipelines oder irgendeinem Confluent‑Produkt erstellen, bauen oder verfassen möchten. Skills können fallbezogen ausgerichtet sein (wie Datenanreicherung, CDC zu Tableflow, Stream‑Processing‑Workflows) oder komponentenspezifisch (wie ein Flink‑Skill, Schema‑Registry‑Skill oder Connector‑Skill). Verwende diesen Skill NICHT, wenn Benutzer Confluent‑Produkte direkt nutzen wollen (z. B. eine Pipeline bauen, einen Producer schreiben, Flink‑SQL bereitstellen) – nutze stattdessen den entsprechenden produktbezogenen Skill. Dieser Skill dient ausschließlich dem Erstellen neuer Skills, nicht der Nutzung bestehender.

Bitte antworte stets in der Sprache des Benutzers.
