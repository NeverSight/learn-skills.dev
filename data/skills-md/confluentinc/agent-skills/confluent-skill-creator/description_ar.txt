أنشئ مهارات مخصصة لـ Confluent للمستخدمين الخارجيين. استخدم هذه المهارة عندما يرغب المستخدمون في إنشاء أو بناء أو تأليف مهارة جديدة تتعلق بـ Confluent Cloud أو Confluent Platform أو Apache Kafka أو WarpStream أو Flink أو الموصلات أو Schema Registry أو Tableflow أو خطوط أنابيب CDC أو أي منتج من منتجات Confluent. يمكن أن تكون المهارات مركزة على حالة الاستخدام (مثل إثراء البيانات، CDC إلى Tableflow، سير عمل معالجة التدفق) أو مخصصة لمكون معين (مثل مهارة Flink أو مهارة Schema Registry أو مهارة Connector). لا تستخدم هذه المهارة عندما يرغب المستخدمون في استخدام منتجات Confluent مباشرة (مثل بناء خط أنابيب، كتابة منتج، نشر Flink SQL) — استخدم المهارة المتخصصة بالمنتج المناسب بدلاً منها. هذه المهارة مخصصة خصيصًا لإنشاء مهارات جديدة، وليس لاستخدام المهارات القائمة.
