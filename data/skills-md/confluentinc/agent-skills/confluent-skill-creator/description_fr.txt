Créez des compétences spécifiques à Confluent pour les utilisateurs externes. Utilisez cette compétence lorsque les utilisateurs souhaitent créer, construire ou rédiger une nouvelle compétence liée à Confluent Cloud, Confluent Platform, Apache Kafka, WarpStream, Flink, les connecteurs, le registre de schémas, Tableflow, les pipelines CDC ou tout produit Confluent. Les compétences peuvent être axées sur des cas d’utilisation (comme l’enrichissement de données, le CDC vers Tableflow, les flux de travail de traitement en continu) ou spécifiques à un composant (comme une compétence Flink, une compétence registre de schémas ou une compétence connecteur). N’UTILISEZ PAS cette compétence lorsque les utilisateurs veulent utiliser directement les produits Confluent (par exemple, créer un pipeline, écrire un producteur, déployer du SQL Flink) — utilisez plutôt la compétence spécifique au produit approprié. Cette compétence est destinée spécifiquement à la création de nouvelles compétences, pas à l’utilisation de celles existantes.

Veuillez toujours répondre dans la langue de l’utilisateur.
