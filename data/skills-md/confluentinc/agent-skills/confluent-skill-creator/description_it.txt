Crea competenze specifiche per Confluent per utenti esterni. Usa questa competenza quando gli utenti desiderano creare, costruire o redigere una nuova competenza relativa a Confluent Cloud, Confluent Platform, Apache Kafka, WarpStream, Flink, connettori, Schema Registry, Tableflow, pipeline CDC o a qualsiasi prodotto Confluent. Le competenze possono essere focalizzate su casi d'uso (come l'arricchimento dei dati, CDC verso Tableflow, flussi di lavoro di elaborazione in streaming) o specifiche per componenti (come una competenza Flink, una competenza Schema Registry o una competenza per connettori). NON usare questa competenza quando gli utenti vogliono utilizzare direttamente i prodotti Confluent (ad esempio, creare una pipeline, scrivere un produttore, distribuire Flink SQL) — utilizza invece la competenza specifica del prodotto appropriata. Questa competenza è specificamente destinata alla creazione di nuove competenze, non all'uso di quelle esistenti.

Rispondi sempre nella lingua dell'utente.
