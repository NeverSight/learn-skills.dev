Cree habilidades específicas de Confluent para usuarios externos. Utilice esta habilidad cuando los usuarios deseen crear, construir o redactar una nueva habilidad relacionada con Confluent Cloud, Confluent Platform, Apache Kafka, WarpStream, Flink, Conectores, Schema Registry, Tableflow, pipelines CDC o cualquier producto de Confluent. Las habilidades pueden estar enfocadas en casos de uso (como enriquecimiento de datos, CDC a Tableflow, flujos de procesamiento de streams) o ser específicas de componentes (como una habilidad de Flink, una habilidad de Schema Registry o una habilidad de Conector). No USE esta habilidad cuando los usuarios quieran utilizar directamente los productos de Confluent (por ejemplo, crear un pipeline, escribir un productor, desplegar Flink SQL); use en su lugar la habilidad específica del producto correspondiente. Esta habilidad es específicamente para crear nuevas habilidades, no para usar las existentes.
