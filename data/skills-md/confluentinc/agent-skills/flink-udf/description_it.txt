Costruisci e distribuisci funzioni definite dall'utente (UDF) di Apache Flink in Java per l'elaborazione di flussi su Kafka. Usa questa competenza quando gli utenti desiderano creare UDF scalari, funzioni di tabella definite dall'utente (UDTF) o funzioni di tabella di processo (PTF) in Java, distribuirle su Confluent Cloud o in ambienti Docker locali, e invocarle da Flink SQL o dalla Table API.  

Attiva su: Flink UDF, funzione Flink personalizzata, funzione di tabella di processo, PTF, UDTF, Flink definito dall'utente, estendere Flink SQL, elaborazione di flussi con stato in Flink.  

NON attivare per: UDF di Kafka Streams (usa la competenza kafka‑streams‑programming), sviluppo generale di job Flink senza funzioni personalizzate, pipeline di dati CDC in streaming che includono Flink (preferisci la competenza confluent‑cloud‑cdc‑tableflow), configurazione di connettori Flink, o codice produttore/consumatore Kafka.  

Rispondi sempre nella lingua dell'utente.
