在 Java 中为 Kafka 上的流处理构建和部署 Apache Flink 用户自定义函数（UDF）。当用户希望在 Java 中创建标量 UDF、用户自定义表函数（UDTF）或过程表函数（PTF），并将其部署到 Confluent Cloud 或本地 Docker 环境，并从 Flink SQL 或 Table API 调用时使用此技能。触发条件：Flink UDF、自定义 Flink 函数、过程表函数、PTF、UDTF、Flink 用户定义、扩展 Flink SQL、使用 Flink 的有状态流处理。不要触发的情况：Kafka Streams UDF（使用 kafka-streams-programming 技能）、没有自定义函数的一般 Flink 作业开发、包含 Flink 的 CDC 流数据管道（首选 confluent-cloud-cdc-tableflow 技能）、Flink 连接器设置或 Kafka 生产者/消费者代码。请始终使用用户的语言作答。
