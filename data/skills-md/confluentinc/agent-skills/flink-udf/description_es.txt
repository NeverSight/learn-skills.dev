Construye y despliega funciones definidas por el usuario (UDF) de Apache Flink en Java para el procesamiento de streams sobre Kafka. Usa esta habilidad cuando los usuarios desean crear UDF escalares, funciones de tabla definidas por el usuario (UDTF) o funciones de tabla de proceso (PTF) en Java, desplegarlas en Confluent Cloud o entornos Docker locales, y llamarlas desde Flink SQL o la API Table. Activar con: Flink UDF, función personalizada de Flink, función de tabla de proceso, PTF, UDTF, Flink definido por el usuario, ampliar Flink SQL, procesamiento de streams con estado en Flink. No activar para: UDFs de Kafka Streams (usar la habilidad kafka-streams-programming), desarrollo general de trabajos Flink sin funciones personalizadas, pipelines de datos CDC que incluyan Flink (preferir la habilidad confluent‑cloud‑cdc‑tableflow), configuración de conectores Flink o código de productor/consumidor Kafka.
