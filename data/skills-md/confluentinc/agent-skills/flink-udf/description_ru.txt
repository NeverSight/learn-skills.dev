Создавайте и развертывайте пользовательские функции Apache Flink (UDF) на Java для потоковой обработки данных из Kafka. Используйте этот навык, когда пользователи хотят создавать скалярные UDF, пользовательские табличные функции (UDTF) или функции обработки таблиц (PTF) на Java, развертывать их в Confluent Cloud или локальных Docker‑окружениях и вызывать из Flink SQL или Table API. Триггер: Flink UDF, пользовательская функция Flink, функция обработки таблиц, PTF, UDTF, пользовательская функция Flink, расширение Flink SQL, stateful потоковая обработка с Flink. НЕ триггерить для: UDF Kafka Streams (используйте навык kafka-streams-programming), общего развития Flink‑заданий без пользовательских функций, CDC‑конвейеров потоковых данных, включающих Flink (предпочтительно навык confluent-cloud-cdc-tableflow), настройки коннекторов Flink или кода продюсера/консюмеров Kafka.
