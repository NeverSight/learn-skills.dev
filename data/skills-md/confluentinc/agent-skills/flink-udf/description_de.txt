Bauen und deployen Sie benutzerdefinierte Apache Flink‑Funktionen (UDFs) in Java für die Stream‑Verarbeitung über Kafka. Verwenden Sie diese Fähigkeit, wenn Benutzer skalare UDFs, benutzerdefinierte Tabellenfunktionen (UDTFs) oder Prozess‑Tabellenfunktionen (PTFs) in Java erstellen, sie in Confluent Cloud oder lokalen Docker‑Umgebungen bereitstellen und aus Flink SQL oder der Table API aufrufen möchten. Auslösen bei: Flink UDF, benutzerdefinierte Flink‑Funktion, Prozess‑Tabellenfunktion, PTF, UDTF, Flink benutzerdefiniert, Erweiterung von Flink SQL, zustandsbehaftete Stream‑Verarbeitung mit Flink. Nicht auslösen für: Kafka Streams UDFs (verwenden Sie die kafka‑streams‑programming‑Fähigkeit), allgemeine Flink‑Job‑Entwicklung ohne benutzerdefinierte Funktionen, CDC‑Streaming‑Datenpipelines, die Flink enthalten (bevorzugen Sie die confluent‑cloud‑cdc‑tableflow‑Fähigkeit), Flink‑Connector‑Setup oder Kafka‑Producer/Consumer‑Code.

Bitte immer in der Sprache des Benutzers antworten.
