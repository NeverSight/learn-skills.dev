Construisez et déployez des fonctions définies par l'utilisateur (UDF) Apache Flink en Java pour le traitement de flux sur Kafka. Utilisez cette compétence lorsque les utilisateurs souhaitent créer des UDF scalaires, des fonctions de table définies par l'utilisateur (UDTF) ou des fonctions de table de traitement (PTF) en Java, les déployer sur Confluent Cloud ou des environnements Docker locaux, et les invoquer depuis Flink SQL ou l'API Table. Déclencher sur : Flink UDF, fonction Flink personnalisée, fonction de table de traitement, PTF, UDTF, fonction définie par l'utilisateur Flink, extension de Flink SQL, traitement de flux étatful avec Flink. Ne pas déclencher pour : les UDF Kafka Streams (utilisez la compétence kafka‑streams‑programming), le développement général de jobs Flink sans fonctions personnalisées, les pipelines de données en streaming CDC incluant Flink (préférez la compétence confluent‑cloud‑cdc‑tableflow), la configuration de connecteurs Flink, ou le code producteur/consommateur Kafka.  

Veuillez toujours répondre dans la langue de l'utilisateur.
