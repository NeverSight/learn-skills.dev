بناء ونشر وظائف Apache Flink المعرفة من قبل المستخدم (UDFs) بلغة Java لمعالجة التدفق عبر Kafka. استخدم هذه المهارة عندما يرغب المستخدمون في إنشاء وظائف UDF عددية، أو وظائف جدول معرفة من قبل المستخدم (UDTFs)، أو وظائف معالجة الجداول (PTFs) بلغة Java، ونشرها على سحابة Confluent أو بيئات Docker المحلية، واستدعائها من Flink SQL أو Table API. التحفيز على: Flink UDF، وظيفة Flink مخصصة، وظيفة معالجة جدول، PTF، UDTF، Flink معرفة من قبل المستخدم، توسيع Flink SQL، معالجة تدفق حالة مع Flink. لا تتحفّز لـ: وظائف UDF في Kafka Streams (استخدم مهارة kafka‑streams‑programming)، تطوير وظائف Flink العامة دون وظائف مخصصة، خطوط بيانات CDC المتدفقة التي تشمل Flink (يفضل مهارة confluent‑cloud‑cdc‑tableflow)، إعداد موصل Flink، أو كود منتج/مستهلك Kafka.
