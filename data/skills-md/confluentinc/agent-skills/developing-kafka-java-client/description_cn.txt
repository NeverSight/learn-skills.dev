当用户希望在现有应用中集成 Kafka 客户端，或为 Confluent Cloud、本地 Docker 或 WarpStream 搭建基于 Maven 或 Gradle 的 Java Kafka 客户端项目时使用。涵盖 Apache Kafka Java 客户端（KafkaProducer/KafkaConsumer/KafkaShareConsumer），支持 Avro、JSON Schema 或 Protobuf 序列化。也适用于用户希望为 WarpStream 优化 Java Kafka 客户端配置的情况。不要用于 Kafka Streams 应用（使用 kafka-streams-programming）、Flink、连接器或 Kafka Python 客户端（使用 developing-kafka-python-client）。
