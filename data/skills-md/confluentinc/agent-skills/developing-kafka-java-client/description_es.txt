Use cuando el usuario desea integrar un cliente Kafka en una aplicación existente o crear un proyecto cliente Kafka en Java (basado en Maven o Gradle) para Confluent Cloud, Docker local o WarpStream. Cubre los clientes Java de Apache Kafka (KafkaProducer/KafkaConsumer/KafkaShareConsumer) con serializadores Avro, JSON Schema o Protobuf. También úselo cuando el usuario quiera optimizar la configuración del cliente Kafka Java para WarpStream. NO lo active para aplicaciones Kafka Streams (use kafka-streams-programming), Flink, conectores o el cliente Kafka Python (use developing-kafka-python-client).

Por favor, responda siempre en el idioma del usuario.
