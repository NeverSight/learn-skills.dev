استخدم عندما يريد المستخدم دمج عميل Kafka في تطبيق موجود أو إنشاء مشروع عميل Java Kafka (مستند إلى Maven أو Gradle) لـ Confluent Cloud أو Docker المحلي أو WarpStream. يغطي عملاء Apache Kafka Java (KafkaProducer/KafkaConsumer/KafkaShareConsumer) مع مسلسلات Avro أو JSON Schema أو Protobuf. استخدم أيضًا عندما يريد المستخدم تحسين تكوين عميل Java Kafka لـ WarpStream. لا تُطبق على تطبيقات Kafka Streams (استخدم kafka-streams-programming)، ولا على Flink أو الموصلات أو عميل Kafka Python (استخدم developing-kafka-python-client).

يرجى دائمًا الرد بلغة المستخدم.
