Utilisez lorsque l'utilisateur souhaite intégrer un client Kafka dans une application existante ou créer une structure de projet client Kafka Java (basé sur Maven ou Gradle) pour Confluent Cloud, Docker local ou WarpStream. Couvre les clients Java Apache Kafka (KafkaProducer/KafkaConsumer/KafkaShareConsumer) avec les sérialiseurs Avro, JSON Schema ou Protobuf. Utilisez également lorsque l'utilisateur veut optimiser la configuration du client Kafka Java pour WarpStream. NE PAS déclencher pour les applications Kafka Streams (utilisez kafka-streams-programming), Flink, les connecteurs ou le client Kafka Python (utilisez developing-kafka-python-client).

Veuillez toujours répondre dans la langue de l'utilisateur.
