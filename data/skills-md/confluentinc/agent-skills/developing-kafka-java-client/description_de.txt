Verwenden Sie dies, wenn der Nutzer einen Kafka‑Client in eine bestehende Anwendung integrieren oder ein Java‑Kafka‑Client‑Projekt (Maven‑ oder Gradle‑basiert) für Confluent Cloud, lokales Docker oder WarpStream erstellen möchte. Deckt die Apache‑Kafka‑Java‑Clients (KafkaProducer/KafkaConsumer/KafkaShareConsumer) mit Avro‑, JSON‑Schema‑ oder Protobuf‑Serialisierern ab. Ebenso verwenden, wenn der Nutzer die Java‑Kafka‑Client‑Konfiguration für WarpStream optimieren möchte. Nicht auslösen für Kafka‑Streams‑Anwendungen (verwenden Sie kafka‑streams‑programming), Flink, Connectors oder den Kafka‑Python‑Client (verwenden Sie developing‑kafka‑python‑client). Bitte antworten Sie immer in der Sprache des Benutzers.
