Используйте, когда пользователь хочет интегрировать клиент Kafka в существующее приложение или создать шаблон проекта Java‑клиента Kafka (на основе Maven или Gradle) для Confluent Cloud, локального Docker или WarpStream. Охватываются Java‑клиенты Apache Kafka (KafkaProducer/KafkaConsumer/KafkaShareConsumer) с сериализаторами Avro, JSON Schema или Protobuf. Также используйте, когда пользователь хочет оптимизировать конфигурацию Java‑клиента Kafka для WarpStream. НЕ активировать для приложений Kafka Streams (используйте kafka-streams-programming), Flink, коннекторов или клиента Kafka на Python (используйте developing-kafka-python-client).

Пожалуйста, всегда отвечайте на языке пользователя.
