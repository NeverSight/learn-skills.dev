Usa quando l'utente desidera integrare un client Kafka in un'applicazione esistente o creare lo scheletro di un progetto client Kafka Java (basato su Maven o Gradle) per Confluent Cloud, Docker locale o WarpStream. Copre i client Java di Apache Kafka (KafkaProducer/KafkaConsumer/KafkaShareConsumer) con serializer Avro, JSON Schema o Protobuf. Utilizza anche quando l'utente vuole ottimizzare la configurazione del client Kafka Java per WarpStream. NON attivare per le app Kafka Streams (usa kafka-streams-programming), Flink, connettori o il client Kafka Python (usa developing-kafka-python-client).
