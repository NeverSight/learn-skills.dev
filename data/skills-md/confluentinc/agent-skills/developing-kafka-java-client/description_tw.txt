當使用者想要將 Kafka 客戶端整合到現有應用程式中，或為 Confluent Cloud、本機 Docker 或 WarpStream 建立 Java Kafka 客戶端專案（基於 Maven 或 Gradle）時使用。涵蓋 Apache Kafka Java 客戶端（KafkaProducer/KafkaConsumer/KafkaShareConsumer）以及 Avro、JSON Schema 或 Protobuf 序列化器。亦可在使用者想要為 WarpStream 優化 Java Kafka 客戶端配置時使用。不要針對 Kafka Streams 應用程式觸發（請使用 kafka-streams-programming）、Flink、連接器或 Kafka Python 客戶端（請使用 developing‑kafka‑python‑client）。
