قم بإعداد خطوط أنابيب التقاط بيانات التغيير (CDC) من النهاية إلى النهاية على Confluent Cloud باستخدام موصلات المصدر Debezium، و Flink للتحويل، و Tableflow لتكامل بحيرة البيانات. يدعم صيغ JSON_SR و Avro و Protobuf. يتعامل مع المواضيع بدون مخطط (JSON عادي بدون SR) والمواضيع متعددة الأحداث. هذه المهارة تدير سير العمل الكامل من قاعدة البيانات إلى جداول Iceberg/Delta. استخدم هذه المهارة عندما يرغب المستخدمون في التقاط تغييرات قاعدة البيانات وتحويلها إلى جداول Iceberg أو Delta Lake عبر Tableflow في Confluent Cloud. تشمل عبارات التفعيل "CDC to Tableflow"، "database to Iceberg"، "database to Delta Lake"، "stream database changes to data lake"، "set up Tableflow pipeline"، "schemaless topic to Tableflow"، أو "multi-event topic to Iceberg". لا تقم بالتفعيل لطلبات CDC العامة أو Debezium أو تكرار قاعدة البيانات التي لا تتضمن Tableflow أو Iceberg/Delta Lake كوجهة.
