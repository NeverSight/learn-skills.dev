Configurez des pipelines de capture de données de changement (CDC) de bout en bout sur Confluent Cloud en utilisant des connecteurs source Debezium, Flink pour la transformation et Tableflow pour l’intégration du lac de données. Prend en charge les formats JSON_SR, Avro et Protobuf. Gère les sujets sans schéma (JSON simple sans SR) et les sujets à événements multiples. Cette compétence gère le flux de travail complet de la base de données vers les tables Iceberg/Delta. Utilisez cette compétence lorsque les utilisateurs souhaitent capturer les changements de base de données et les matérialiser dans des tables Iceberg ou Delta Lake via Confluent Cloud Tableflow. Les phrases déclencheurs incluent « CDC to Tableflow », « database to Iceberg », « database to Delta Lake », « stream database changes to data lake », « set up Tableflow pipeline », « schemaless topic to Tableflow », ou « multi-event topic to Iceberg ». NE déclenchez PAS pour des demandes générales de CDC, Debezium ou de réplication de base de données qui n’impliquent pas Tableflow ou Iceberg/Delta Lake comme destination.

Veuillez toujours répondre dans la langue de l’utilisateur.
