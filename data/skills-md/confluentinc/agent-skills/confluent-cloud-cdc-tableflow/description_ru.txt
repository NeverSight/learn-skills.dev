Настройте сквозные конвейеры захвата изменений данных (CDC) в Confluent Cloud с использованием коннекторов-источников Debezium, Flink для трансформации и Tableflow для интеграции с озером данных. Поддерживает форматы JSON_SR, Avro и Protobuf. Обрабатывает темы без схемы (обычный JSON без SR) и темы с несколькими событиями. Этот навык охватывает весь рабочий процесс от базы данных до таблиц Iceberg/Delta. Используйте этот навык, когда пользователи хотят захватить изменения в базе данных и материализовать их в таблицах Iceberg или Delta Lake через Confluent Cloud Tableflow. Фразы‑триггеры включают «CDC to Tableflow», «database to Iceberg», «database to Delta Lake», «stream database changes to data lake», «set up Tableflow pipeline», «schemaless topic to Tableflow» или «multi-event topic to Iceberg». НЕ активируйте для общих запросов CDC, Debezium или репликации баз данных, которые не включают Tableflow или Iceberg/Delta Lake в качестве назначения.
