Configura pipelines de captura de datos de cambio (CDC) de extremo a extremo en Confluent Cloud usando conectores de origen Debezium, Flink para transformación y Tableflow para integración con el lago de datos. Soporta formatos JSON_SR, Avro y Protobuf. Maneja topics sin esquema (JSON plano sin SR) y topics con múltiples eventos. Esta habilidad gestiona el flujo de trabajo completo desde la base de datos hasta tablas Iceberg/Delta. Utiliza esta habilidad cuando los usuarios desean capturar cambios de base de datos y materializarlos en tablas Iceberg o Delta Lake a través de Confluent Cloud Tableflow. Las frases disparadoras incluyen “CDC a Tableflow”, “base de datos a Iceberg”, “base de datos a Delta Lake”, “transmitir cambios de base de datos al lago de datos”, “configurar pipeline Tableflow”, “topic sin esquema a Tableflow” o “topic multi‑evento a Iceberg”. NO se debe activar para solicitudes generales de CDC, Debezium o replicación de base de datos que no impliquen Tableflow o Iceberg/Delta Lake como destino.
