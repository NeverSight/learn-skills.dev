Richten Sie End-to-End-Change-Data-Capture (CDC)-Pipelines in Confluent Cloud ein, indem Sie Debezium-Quell-Connectoren, Flink für die Transformation und Tableflow für die Data‑Lake-Integration verwenden. Unterstützt JSON_SR, Avro und Protobuf-Formate. Verarbeitet schemalose Topics (reines JSON ohne SR) und Multi‑Event‑Topics. Diese Fähigkeit übernimmt den gesamten Workflow von der Datenbank zu Iceberg‑/Delta‑Tabellen. Verwenden Sie diese Fähigkeit, wenn Nutzer Datenbankänderungen erfassen und über Confluent Cloud Tableflow in Iceberg‑ oder Delta‑Lake‑Tabellen materialisieren wollen. Auslöserphrasen sind u. a. „CDC to Tableflow“, „database to Iceberg“, „database to Delta Lake“, „stream database changes to data lake“, „set up Tableflow pipeline“, „schemaless topic to Tableflow“ oder „multi-event topic to Iceberg“. Nicht auslösen bei allgemeinen CDC‑, Debezium‑ oder Datenbank‑Replikationsanfragen, die Tableflow oder Iceberg/Delta Lake nicht als Ziel haben.

Bitte immer in der Sprache des Nutzers antworten.
