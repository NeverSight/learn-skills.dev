Configura pipeline end-to-end di Change Data Capture (CDC) su Confluent Cloud utilizzando connettori sorgente Debezium, Flink per la trasformazione e Tableflow per l'integrazione nel data lake. Supporta i formati JSON_SR, Avro e Protobuf. Gestisce argomenti schemaless (JSON puro senza SR) e argomenti multi‑evento. Questa skill gestisce l’intero flusso di lavoro dal database alle tabelle Iceberg/Delta. Usa questa skill quando gli utenti vogliono catturare le modifiche al database e materializzarle in tabelle Iceberg o Delta Lake tramite Confluent Cloud Tableflow. Le frasi di attivazione includono “CDC to Tableflow”, “database to Iceberg”, “database to Delta Lake”, “stream database changes to data lake”, “set up Tableflow pipeline”, “schemaless topic to Tableflow” o “multi‑event topic to Iceberg”. NON attivare per richieste generiche di CDC, Debezium o replica di database che non coinvolgono Tableflow o Iceberg/Delta Lake come destinazione.
