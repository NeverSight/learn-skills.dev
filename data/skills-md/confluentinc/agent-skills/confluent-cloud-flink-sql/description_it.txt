Scrivi e fai il debug di Flink SQL che gira su Confluent Cloud, imponendo il confine di dialetto tra CC e Apache Flink (OSS). Usalo quando la directory di lavoro è un workspace Flink di Confluent Cloud, quando una dichiarazione Flink SQL necessita di verifica prima di essere eseguita su un pool di calcolo CC, o quando l'utente cita CC Flink, Confluent Cloud Flink SQL, il CLI `confluent flink`, un pool di calcolo CFU, `CREATE CONNECTION`, o chiede di controllare o fare il debug di Flink SQL il cui runtime è Confluent Cloud. Attiva anche quando viene posta una domanda su Flink SQL e non viene stabilito alcun runtime Apache Flink OSS. NON attivare per: la costruzione o il deployment di Flink UDF in Java (UDF/UDTF/PTF — usa flink‑udf); una pipeline CDC completa da un database tramite Flink verso Tableflow/Iceberg/Delta Lake (usa confluent‑cloud‑cdc‑tableflow); lavoro sulla topologia Kafka Streams (usa kafka‑streams‑programming); o Flink SQL confermato per l'esecuzione su Apache Flink OSS, non su Confluent Cloud. Per favore, rispondi sempre nella lingua dell'utente.
