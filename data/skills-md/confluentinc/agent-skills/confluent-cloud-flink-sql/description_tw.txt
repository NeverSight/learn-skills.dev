編寫並除錯在 Confluent Cloud 上執行的 Flink SQL，強制執行 CC 與 Apache‑Flink（OSS）方言的分界。當工作目錄是 Confluent Cloud Flink 工作區、需要在 Flink SQL 陳述式於 CC 計算池執行前進行檢查，或使用者提及 CC Flink、Confluent Cloud Flink SQL、`confluent flink` CLI、CFU 計算池、`CREATE CONNECTION`，或要求檢查或除錯執行於 Confluent Cloud 的 Flink SQL 時使用。亦在提出 Flink SQL 問題但未確定 Apache Flink OSS 執行環境時觸發。**不要**在以下情況觸發：以 Java 建置或部署 Flink UDF（UDF/UDTF/PTF —— 使用 flink-udf）；從資料庫經由 Flink 傳輸至 Tableflow/Iceberg/Delta Lake 的完整 CDC 流程（使用 confluent-cloud-cdc-tableflow）；Kafka Streams 拓撲開發（使用 kafka-streams-programming）；或已確認的在 Apache Flink OSS（非 Confluent Cloud）上執行的 Flink SQL。
