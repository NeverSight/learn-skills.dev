Пишите и отлаживайте Flink SQL, который работает в Confluent Cloud, обеспечивая границу диалекта между CC и Apache Flink (OSS). Используйте, когда рабочий каталог является рабочим пространством Flink в Confluent Cloud, когда нужно проверить заявление Flink SQL перед его выполнением в вычислительном пуле CC, либо когда пользователь упоминает CC Flink, Flink SQL в Confluent Cloud, CLI `confluent flink`, вычислительный пул CFU, `CREATE CONNECTION`, или просит проверить или отладить Flink SQL, исполняемый в Confluent Cloud. Также активируйте, когда задаётся вопрос по Flink SQL, и не установлено, что среда исполнения — Apache Flink OSS. Не активировать для: создания или развертывания Flink UDF на Java (UDF/UDTF/PTF — используйте flink‑udf); полного CDC‑конвейера из базы данных через Flink в Tableflow/Iceberg/Delta Lake (используйте confluent‑cloud‑cdc‑tableflow); работы с топологией Kafka Streams (используйте kafka‑streams‑programming); или Flink SQL, подтверждённого как работающий на Apache Flink OSS, а не в Confluent Cloud. Пожалуйста, всегда отвечайте на языке пользователя.
