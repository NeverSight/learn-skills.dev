Écrire et déboguer du Flink SQL qui s’exécute sur Confluent Cloud, en appliquant la frontière du dialecte CC‑vs‑Apache‑Flink (OSS). Utiliser lorsque le répertoire de travail est un espace de travail Flink de Confluent Cloud, lorsqu’une instruction Flink SQL doit être vérifiée avant de s’exécuter sur un pool de calcul CC, ou lorsque l’utilisateur mentionne CC Flink, Confluent Cloud Flink SQL, le CLI `confluent flink`, un pool de calcul CFU, `CREATE CONNECTION`, ou demande de vérifier ou déboguer du Flink SQL dont le runtime est Confluent Cloud. Déclencher également lorsqu’une question Flink SQL est posée et qu’aucun runtime Apache Flink OSS n’est établi. NE PAS déclencher pour : la construction ou le déploiement de Flink UDF en Java (UDF/UDTF/PTF — utilisez flink‑udf) ; un pipeline CDC complet d’une base de données via Flink vers Tableflow/Iceberg/Delta Lake (utilisez confluent‑cloud‑cdc‑tableflow) ; le travail de topologie Kafka Streams (utilisez kafka‑streams‑programming) ; ou du Flink SQL confirmé s’exécutant sur Apache Flink OSS, pas Confluent Cloud.

Veuillez toujours répondre dans la langue de l’utilisateur.
