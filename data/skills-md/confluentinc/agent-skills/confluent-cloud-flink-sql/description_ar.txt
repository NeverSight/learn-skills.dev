اكتب وصحّح Flink SQL الذي يعمل على Confluent Cloud مع الالتزام بحدود لهجة CC مقابل Apache Flink (OSS). استخدم هذا عندما يكون دليل العمل مساحة عمل Flink في Confluent Cloud، أو عندما تحتاج عبارة Flink SQL إلى فحص قبل تشغيلها على مجموعة حوسبة CC، أو عندما يذكر المستخدم CC Flink أو Confluent Cloud Flink SQL أو سطر الأوامر `confluent flink` أو مجموعة حوسبة CFU أو `CREATE CONNECTION` أو يطلب فحص أو تصحيح Flink SQL الذي يُنفَّذ على Confluent Cloud. كما يجب التفعيل عندما يُطرح سؤال حول Flink SQL ولا يتم تحديد بيئة تشغيل Apache Flink OSS. لا تُفعَّل في الحالات التالية: بناء أو نشر Flink UDFs بلغة Java (UDF/UDTF/PTF — استخدم flink-udf)؛ خط أنابيب CDC كامل من قاعدة بيانات عبر Flink إلى Tableflow/Iceberg/Delta Lake (استخدم confluent-cloud-cdc-tableflow)؛ عمل طوبولوجيا Kafka Streams (استخدم kafka-streams-programming)؛ أو Flink SQL مؤكد أنه يُنفَّذ على Apache Flink OSS، وليس على Confluent Cloud.
