Confluent Cloud에서 실행되는 Flink SQL을 작성하고 디버그하며, CC와 Apache Flink(OSS) 방언 경계를 적용합니다. 작업 디렉터리가 Confluent Cloud Flink 워크스페이스일 때, Flink SQL 문이 CC 컴퓨트 풀에서 실행되기 전에 확인이 필요할 때, 혹은 사용자가 CC Flink, Confluent Cloud Flink SQL, `confluent flink` CLI, CFU 컴퓨트 풀, `CREATE CONNECTION`을 언급하거나 실행 런타임이 Confluent Cloud인 Flink SQL을 체크하거나 디버그해 달라고 요청할 때 사용합니다. 또한 Flink SQL 질문이 제시되고 Apache Flink OSS 런타임이 확정되지 않은 경우에도 트리거합니다. 다음 경우에는 트리거하지 마세요: Java에서 Flink UDF를 구축하거나 배포하는 작업(UDF/UDTF/PTF — flink-udf 사용); 데이터베이스 → Flink → Tableflow/Iceberg/Delta Lake 전체 CDC 파이프라인(⟨confluent‑cloud‑cdc‑tableflow⟩ 사용); Kafka Streams 토폴로지 작업(kafka‑streams‑programming 사용); 혹은 Flink SQL이 Apache Flink OSS에서 실행된다고 확인된 경우(Confluent Cloud 아님).
