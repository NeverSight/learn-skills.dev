Schreiben und debuggen Sie Flink‑SQL, das auf Confluent Cloud läuft, und erzwingen Sie die Abgrenzung zwischen dem CC‑ und dem Apache‑Flink‑(OSS)‑Dialekt. Verwenden Sie es, wenn das Arbeitsverzeichnis ein Confluent‑Cloud‑Flink‑Workspace ist, wenn eine Flink‑SQL‑Anweisung vor der Ausführung in einem CC‑Compute‑Pool geprüft werden muss oder wenn der Nutzer CC Flink, Confluent Cloud Flink SQL, das `confluent flink`‑CLI, einen CFU‑Compute‑Pool, `CREATE CONNECTION` erwähnt oder um die Prüfung bzw. das Debuggen von Flink‑SQL bittet, das in Confluent Cloud ausgeführt wird. Auch auslösen, wenn eine Flink‑SQL‑Frage gestellt wird und nichts eine Apache‑Flink‑OSS‑Runtime etabliert. Nicht auslösen für: das Erstellen oder Deployen von Flink‑UDFs in Java (UDF/UDTF/PTF — verwenden Sie flink‑udf); eine vollständige CDC‑Pipeline von einer Datenbank über Flink zu Tableflow/Iceberg/Delta Lake (verwenden Sie confluent‑cloud‑cdc‑tableflow); Kafka‑Streams‑Topologie‑Arbeiten (verwenden Sie kafka‑streams‑programming); oder Flink‑SQL, das eindeutig auf Apache Flink OSS und nicht auf Confluent Cloud läuft.
