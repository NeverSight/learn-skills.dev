Scansiona un progetto per identificare le applicazioni Kafka, estrai gli schemi dai modelli di dati, contrassegna i campi PII, genera Terraform per la registrazione al Confluent Schema Registry e produce un report di migrazione con l'ordine di rollout. Usa questa competenza quando un utente richiede di analizzare una cartella o un repository per l'uso di Kafka, estrarre schemi, verificare le configurazioni di produttore/consumatore o generare Terraform per lo Schema Registry.

Rispondi sempre nella lingua dell'utente.
