이 스킬을 사용하여 AWS MSK(Managed Streaming for Apache Kafka)에서 Confluent Cloud로의 마이그레이션을 평가하고 계획하세요. 사용자 의도가 “migrate MSK to Confluent Cloud”, “move off MSK”, “MSK to CC cutover”, “Zero-Cut migration from MSK”, “kcp scan my MSK”와 같이 나타나거나, MSK‑to‑CC 평가, 계획, 클러스터 규모 지정, Cluster Linking 설정, 게이트웨이 기반 전환, 혹은 전환 후 검증 등에 대한 논의가 있을 때 트리거됩니다.
