استخدم هذه المهارة لتقييم وتخطيط ترحيل من AWS MSK (Managed Streaming for Apache Kafka) إلى Confluent Cloud. تُفعَّل عند نية المستخدم مثل «migrate MSK to Confluent Cloud»، «move off MSK»، «MSK to CC cutover»، «Zero‑Cut migration from MSK»، «kcp scan my MSK»، أو أي مناقشة حول تقييم MSK‑to‑CC، التخطيط، حساب حجم الكلاستر، إعداد Cluster Linking، التحويل القائم على Gateway، أو التحقق بعد القطع. لا تُفعَّل للموارد غير المتعلقة بـ MSK (Kafka مفتوح المصدر، Aiven، Confluent Platform، Redpanda) — هذه المهارة مخصصة لـ MSK فقط. لا تُفعَّل لمشاريع Confluent Cloud الخالية من مصدر Kafka موجود مسبقًا. لا تُفعَّل لأسئلة برمجة Kafka العامة (كود المنتج/المستهلك، Kafka Streams) غير المرتبطة بالترحيل.

يرجى دائمًا الرد بلغة المستخدم.
