Verwenden Sie diese Fähigkeit, um eine Migration von AWS MSK (Managed Streaming for Apache Kafka) zu Confluent Cloud zu bewerten und zu planen. Sie wird ausgelöst bei Nutzerabsichten wie „MSK zu Confluent Cloud migrieren“, „von MSK wegwechseln“, „MSK‑zu‑CC‑Cutover“, „Zero‑Cut‑Migration von MSK“, „kcp scan my MSK“ oder jeder Diskussion über MSK‑zu‑CC‑Bewertung, Planung, Cluster‑Dimensionierung, Einrichtung von Cluster Linking, gateway‑basierten Umschalten oder Validierung nach dem Cutover. Nicht auslösen für nicht‑MSK‑Kafka‑Quellen (Open‑Source‑Kafka, Aiven, Confluent Platform, Redpanda) — diese Fähigkeit gilt ausschließlich für MSK. Nicht auslösen für Greenfield‑Confluent‑Cloud‑Projekte ohne bestehende Kafka‑Quelle. Nicht auslösen für allgemeine Kafka‑Programmierungsfragen (Producer/Consumer‑Code, Kafka Streams), die nicht mit der Migration zu tun haben.

Bitte antworten Sie immer in der Sprache des Benutzers.
