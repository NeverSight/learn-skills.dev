Используйте это умение для оценки и планирования миграции из AWS MSK (Managed Streaming for Apache Kafka) в Confluent Cloud. Срабатывает при намерениях пользователя, таких как «перенести MSK в Confluent Cloud», «отказаться от MSK», «MSK to CC cutover», «Zero‑Cut миграция из MSK», «kcp scan my MSK» или любое обсуждение оценки, планирования, подбора размера кластера, настройки Cluster Linking, переключения на основе шлюза или проверки после переключения. НЕ срабатывайте для неконтролируемых источников Kafka, отличных от MSK (open‑source Kafka, Aiven, Confluent Platform, Redpanda) — это умение работает только с MSK. НЕ срабатывайте для новых проектов Confluent Cloud без существующего источника Kafka. НЕ срабатывайте для общих вопросов программирования Kafka (код продюсера/консьюмера, Kafka Streams), не связанных с миграцией.

Всегда отвечайте на языке пользователя.
