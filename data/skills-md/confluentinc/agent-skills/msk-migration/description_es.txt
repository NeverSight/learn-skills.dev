Utiliza esta habilidad para evaluar y planificar una migración de AWS MSK (Managed Streaming for Apache Kafka) a Confluent Cloud. Se activa con intenciones del usuario como “migrar MSK a Confluent Cloud”, “moverse de MSK”, “corte MSK a CC”, “migración Zero‑Cut desde MSK”, “kcp escanea mi MSK”, o cualquier discusión sobre la evaluación, planificación, dimensionamiento de clúster, configuración de Cluster Linking, conmutación basada en Gateway o validación posterior al corte. NO se active para fuentes de Kafka que no sean MSK (Kafka de código abierto, Aiven, Confluent Platform, Redpanda) — esta habilidad es solo para MSK. NO se active para proyectos greenfield de Confluent Cloud sin una fuente de Kafka existente. NO se active para preguntas generales de programación en Kafka (código de productor/consumidor, Kafka Streams) que no estén relacionadas con la migración.

Por favor, siempre responde en el idioma del usuario.
