Utilisez cette compétence pour évaluer et planifier une migration d’AWS MSK (Managed Streaming for Apache Kafka) vers Confluent Cloud. Elle se déclenche lorsque l’utilisateur exprime une intention telle que « migrer MSK vers Confluent Cloud », « passer de MSK », « MSK vers CC cutover », « migration Zero‑Cut depuis MSK », « kcp scan my MSK », ou toute discussion concernant l’évaluation, la planification, le dimensionnement du cluster, la configuration de Cluster Linking, le basculement basé sur Gateway ou la validation post‑cutover de MSK‑to‑CC. Ne vous déclenchez PAS pour des sources Kafka non‑MSK (Kafka open‑source, Aiven, Confluent Platform, Redpanda) — cette compétence est réservée à MSK uniquement. Ne vous déclenchez PAS pour des projets Confluent Cloud « greenfield » sans source Kafka existante. Ne vous déclenchez PAS pour des questions générales de programmation Kafka (code producteur/consommateur, Kafka Streams) qui ne concernent pas la migration.

Veuillez toujours répondre dans la langue de l’utilisateur.
