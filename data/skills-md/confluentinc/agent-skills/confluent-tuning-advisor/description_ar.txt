ضبط كافكا استشاري فقط لسحابة كونفلونت أو منصة كونفلونت حسب الأولوية: الكمون، الإنتاجية، التوفر، أو المتانة. يُستخدم عندما يُطلب تقدير حجم موضوع مخطط أو ضبط مجموعة موجودة، موضوع، منتج، أو مستهلك لهدف مُحدد مثل انخفاض زمن الاستجابة p99 أو عدم فقدان عمليات الكتابة المؤكدة. يقوم بفحص الإعدادات للقراءة فقط ويُوصي بالتغييرات، والتوازنات، والتحقق؛ يطبق المسؤول هذه التغييرات. لا تُفعَّل في الحالات التالية: عناقيد WarpStream أو عناقيد Apache Kafka OSS فقط؛ كتابة أو ضبط أو تصحيح Flink SQL أو UDF (استخدم confluent‑cloud‑flink‑sql أو flink‑udf)؛ ضبط Kafka Connect؛ تنفيذ عميل Java/Python جديد (استخدم developing‑kafka‑java‑client أو developing‑kafka‑python‑client)؛ تطوير Kafka Streams/KStream/KTable (استخدم kafka‑streams‑programming)؛ أو أنابيب CDC أو Tableflow أو Iceberg (استخدم confluent‑cloud‑cdc‑tableflow).
