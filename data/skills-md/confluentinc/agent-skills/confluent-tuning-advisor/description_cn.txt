仅提供建议的 Kafka 调优，针对 Confluent Cloud 或 Confluent Platform，按优先级：延迟、吞吐量、可用性或持久性。用于在需要为计划的主题或现有集群、主题、生产者或消费者进行尺寸评估或调优，以实现量化目标（例如降低 p99 延迟或确保不丢失已确认的写入）时。仅读取配置并提供更改、权衡和验证建议；管理员负责实际应用。请勿在以下情况下触发：WarpStream 或仅 Apache Kafka OSS 集群；Flink SQL 或 UDF 编写、调优或调试（使用 confluent‑cloud‑flink‑sql 或 flink‑udf）；Kafka Connect 调优；新的 Java/Python 客户端实现（使用 developing‑kafka‑java‑client 或 developing‑kafka‑python‑client）；Kafka Streams/KStream/KTable 开发（使用 kafka‑streams‑programming）；以及 CDC、Tableflow 或 Iceberg 流水线（使用 confluent‑cloud‑cdc‑tableflow）。
