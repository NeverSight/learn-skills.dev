Wie man KI-Unterstützung in Git Commits gemäß der Linux-Kernel-Coding-Assistants-Richtlinie zuweist. Verwenden Sie es, wenn Sie eine git Commit-Nachricht schreiben, einen Commit oder PR vorbereiten oder wenn der Benutzer fragt, wie Commits Claude gutschreiben sollen. Ein PreToolUse-Hook in diesem Plugin erzwingt die Regel auch automatisch bei "git commit".
