Comment attribuer l'assistance d'IA dans les commits git, en suivant la politique des assistants de codage du noyau Linux. À utiliser lors de la rédaction d'un message de validation git, de la préparation d'une validation ou d'une RP, ou lorsque l'utilisateur demande comment les validations doivent créditer Claude. Un crochet PreToolUse dans ce plugin applique également la règle automatiquement sur `git commit`.
