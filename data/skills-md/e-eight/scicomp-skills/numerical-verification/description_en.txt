Verify numerical and scientific code against independent oracles — closed-form solutions, slow reference implementations, invariants and symmetries, limiting cases, convergence order, and property tests — instead of hand-written expected values. Use this whenever writing, testing, refactoring, or optimizing simulation, solver, linear algebra, Monte Carlo, or analysis code; whenever a test needs an expected value that isn't obvious; whenever someone asks how to test code whose right answer is unknown; and before trusting any number a research script produces. This replaces ordinary TDD for scientific code.
