Создавайте редактируемые прототипы пользовательского интерфейса для стороны B/C с помощью Figma MCP. Используйте его, когда пользователь говорит: «Нарисовать прототип, каркас, черновик Figma, серверную страницу или страницу приложения». Принудительно внедрите полный рабочий процесс проектирования внешнего интерфейса (план проектирования → Anti-Slop → page.ui.yaml → Figma → самопроверка скриншота → инкрементальное исправление) вместе с двухдорожечной визуализацией DESIGN.md, чтобы избежать эстетики ИИ по умолчанию и случайной регенерации. Не создавайте без спецификации; не вызывайте use_figma без Anti-Slop PASS.
