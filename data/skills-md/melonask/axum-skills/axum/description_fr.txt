Guide complet pour construire des applications web et des API avec le framework Rust axum (par tokio-rs). Utilisez cette compétence chaque fois que l'utilisateur souhaite : créer des serveurs web, des API REST ou des services HTTP en Rust avec axum ; configurer le routage avec des paramètres de chemin, des routeurs imbriqués, des retours par défaut ou le routage par méthode ; utiliser les extracteurs de requête (Path, Query, Json, Form, Bytes, String, HeaderMap, State, Extension, WebSocket, Multipart, Cookie) ; créer des types de réponse avec IntoResponse ; implémenter des middlewares avec middleware::from_fn ou des couches tower ; gérer l’état de l’application avec State et FromRef ; gérer les erreurs avec des implémentations personnalisées d’IntoResponse ; travailler avec des connexions WebSocket pour des fonctionnalités en temps réel ; servir des Server‑Sent Events (SSE) ; gérer les téléchargements de formulaires multiparties ; gérer les cookies (signés, privés ou simples) ; servir des fichiers statiques ; configurer CORS, le tracing, la compression, les délais d’attente et d’autres couches tower‑http ; mettre en place une fermeture gracieuse ; migrer d’axum 0.7 vers 0.8 ; ou intégrer axum avec le middleware tower. Assurez‑vous d’utiliser cette compétence lorsque l’utilisateur mentionne axum, framework web Rust, serveur HTTP Rust, API REST Rust, tokio‑rs axum, développement web Rust, serveur d’API Rust ou tout service web construit avec axum.
