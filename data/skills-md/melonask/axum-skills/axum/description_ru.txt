Полное руководство по созданию веб‑приложений и API с помощью фреймворка axum на Rust (от tokio‑rs). Используйте этот навык, когда пользователь хочет: создавать веб‑серверы, REST‑API или HTTP‑сервисы на Rust с использованием axum; настраивать маршрутизацию с параметрами пути, вложенными роутерами, резервными обработчиками или маршрутизацией по методам; использовать извлекатели запросов (Path, Query, Json, Form, Bytes, String, HeaderMap, State, Extension, WebSocket, Multipart, Cookie); создавать типы ответов с помощью IntoResponse; реализовывать middleware через middleware::from_fn или слои tower; управлять состоянием приложения с помощью State и FromRef; обрабатывать ошибки с помощью пользовательских реализаций IntoResponse; работать с WebSocket‑соединениями для функций в реальном времени; обслуживать Server‑Sent Events (SSE); обрабатывать загрузки multipart‑форм; управлять cookie (подписанными, приватными или обычными); обслуживать статические файлы; настраивать CORS, трассировку, сжатие, тайм‑ауты и другие слои tower‑http; организовывать корректное завершение работы; мигрировать с axum 0.7 на 0.8; либо интегрировать axum с middleware tower. Обязательно используйте этот навык, когда пользователь упоминает axum, Rust web framework, Rust HTTP server, Rust REST API, tokio‑rs axum, Rust web development, Rust API server или любой веб‑сервис, построенный на axum.  

Пожалуйста, всегда отвечайте на языке пользователя.
