Guida completa per costruire applicazioni web e API con il framework Rust axum (di tokio-rs). Usa questa competenza ogni volta che l'utente desidera: creare server web, API REST o servizi HTTP in Rust usando axum; configurare il routing con parametri di percorso, router annidati, fallback o routing per metodo; utilizzare gli estrattori di richieste (Path, Query, Json, Form, Bytes, String, HeaderMap, State, Extension, WebSocket, Multipart, Cookie); creare tipi di risposta con IntoResponse; implementare middleware con middleware::from_fn o layer di tower; gestire lo stato dell'applicazione con State e FromRef; gestire gli errori con implementazioni personalizzate di IntoResponse; lavorare con connessioni WebSocket per funzionalità in tempo reale; servire eventi server‑sent (SSE); gestire upload di moduli multipart; amministrare cookie (firmati, privati o semplici); servire file statici; configurare CORS, tracing, compressione, timeout e altri layer tower‑http; impostare lo spegnimento graduale; migrare da axum 0.7 a 0.8; o integrare axum con middleware tower. Assicurati di utilizzare questa competenza quando l'utente menziona axum, framework web Rust, server HTTP Rust, API REST Rust, tokio‑rs axum, sviluppo web Rust, server API Rust o qualsiasi servizio web costruito con axum.
