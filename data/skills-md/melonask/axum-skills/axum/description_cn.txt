使用 axum Rust 框架（tokio‑rs）构建 Web 应用和 API 的综合指南。每当用户想要：使用 axum 在 Rust 中构建 Web 服务器、REST API 或 HTTP 服务；使用路径参数、嵌套路由、回退或方法路由设置路由；使用请求提取器（Path、Query、Json、Form、Bytes、String、HeaderMap、State、Extension、WebSocket、Multipart、Cookie）；使用 IntoResponse 创建响应类型；通过 middleware::from_fn 或 tower 层实现中间件；使用 State 和 FromRef 管理应用状态；使用自定义 IntoResponse 实现处理错误；使用 WebSocket 连接实现实时功能；提供服务器发送事件（SSE）；处理 multipart 表单上传；管理 cookie（签名、私有或普通）；提供静态文件服务；配置 CORS、tracing、压缩、超时以及其他 tower‑http 层；设置优雅关机；从 axum 0.7 迁移到 0.8；或将 axum 与 tower 中间件集成。确保在用户提及 axum、Rust Web 框架、Rust HTTP 服务器、Rust REST API、tokio‑rs axum、Rust Web 开发、Rust API 服务器或任何使用 axum 构建的 Web 服务时使用此技能。
