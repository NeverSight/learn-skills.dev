axum Rustフレームワーク（tokio‑rs提供）でウェブアプリケーションと API を構築するための包括的ガイドです。このスキルは、ユーザーが以下を行いたいときに使用してください：axum を使って Rust でウェブサーバー、REST API、または HTTP サービスを構築すること；パスパラメータ、ネストされたルーター、フォールバック、メソッドルーティングを用いたルーティング設定；リクエストエクストラクタ（Path、Query、Json、Form、Bytes、String、HeaderMap、State、Extension、WebSocket、Multipart、Cookie）の利用；IntoResponse でレスポンスタイプを作成すること；middleware::from_fn または tower レイヤーでミドルウェアを実装すること；State と FromRef でアプリケーション状態を管理すること；カスタム IntoResponse 実装でエラー処理を行うこと；リアルタイム機能のために WebSocket 接続を扱うこと；Server‑Sent Events（SSE）を提供すること；マルチパートフォームのアップロードを処理すること；署名付き、プライベート、またはプレーンのクッキーを管理すること；静的ファイルを提供すること；CORS、トレーシング、圧縮、タイムアウト、その他 tower‑http レイヤーを設定すること；グレースフルシャットダウンを設定すること；axum 0.7 から 0.8 への移行を行うこと；あるいは axum を tower ミドルウェアと統合すること。ユーザーが axum、Rust ウェブフレームワーク、Rust HTTP サーバー、Rust REST API、tokio‑rs axum、Rust ウェブ開発、Rust API サーバー、または axum で構築されたウェブサービスに言及した場合は必ずこのスキルを使用してください。
