Guía completa para construir aplicaciones web y APIs con el framework axum de Rust (por tokio-rs). Utiliza esta habilidad siempre que el usuario quiera: crear servidores web, APIs REST o servicios HTTP en Rust usando axum; configurar enrutamiento con parámetros de ruta, routers anidados, fallback o enrutamiento por método; usar extractores de solicitud (Path, Query, Json, Form, Bytes, String, HeaderMap, State, Extension, WebSocket, Multipart, Cookie); crear tipos de respuesta con IntoResponse; implementar middleware con middleware::from_fn o capas tower; gestionar el estado de la aplicación con State y FromRef; manejar errores con implementaciones personalizadas de IntoResponse; trabajar con conexiones WebSocket para funcionalidades en tiempo real; servir eventos enviados por el servidor (SSE); manejar cargas de formularios multipart; gestionar cookies (firmadas, privadas o simples); servir archivos estáticos; configurar CORS, tracing, compresión, tiempos de espera y otras capas tower‑http; configurar un apagado elegante; migrar de axum 0.7 a 0.8; o integrar axum con middleware tower. Asegúrate de usar esta habilidad cuando el usuario mencione axum, framework web de Rust, servidor HTTP de Rust, API REST de Rust, tokio‑rs axum, desarrollo web con Rust, servidor de API Rust o cualquier servicio web construido con axum.
