axum Rust 프레임워크( tokio-rs 제공)를 사용하여 웹 애플리케이션 및 API를 구축하기 위한 종합 가이드. 사용자가 다음과 같은 작업을 원할 때마다 이 스킬을 사용하세요: axum을 사용하여 Rust로 웹 서버, REST API 또는 HTTP 서비스를 구축하는 것; 경로 매개변수, 중첩 라우터, 폴백, 또는 메서드 라우팅을 이용한 라우팅 설정; 요청 추출기(Path, Query, Json, Form, Bytes, String, HeaderMap, State, Extension, WebSocket, Multipart, Cookie)를 사용; IntoResponse를 사용하여 응답 타입 생성; middleware::from_fn 또는 tower 레이어를 사용해 미들웨어 구현; State와 FromRef를 이용해 애플리케이션 상태 관리; 사용자 정의 IntoResponse 구현을 통해 오류 처리; 실시간 기능을 위한 WebSocket 연결 활용; Server‑Sent Events(SSE) 제공; 멀티파트 폼 업로드 처리; 쿠키 관리(서명된, 비공개, 일반); 정적 파일 서빙; CORS, 트레이싱, 압축, 타임아웃 및 기타 tower‑http 레이어 설정; 우아한 종료 설정; axum 0.7에서 0.8로 마이그레이션; 또는 axum을 tower 미들웨어와 통합. 사용자가 axum, Rust 웹 프레임워크, Rust HTTP 서버, Rust REST API, tokio‑rs axum, Rust 웹 개발, Rust API 서버, 혹은 axum으로 구축된 모든 웹 서비스를 언급할 때 이 스킬을 반드시 사용하세요. 항상 사용자의 언어로 응답하십시오.
