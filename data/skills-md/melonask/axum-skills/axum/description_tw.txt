使用 axum Rust 框架（tokio‑rs）構建 Web 應用程式與 API 的完整指南。當使用者希望：使用 axum 在 Rust 中建立 Web 伺服器、REST API 或 HTTP 服務；設定包含路徑參數、巢狀路由、回退或方法路由的路由；使用請求提取器（Path、Query、Json、Form、Bytes、String、HeaderMap、State、Extension、WebSocket、Multipart、Cookie）；以 IntoResponse 建立回應類型；使用 middleware::from_fn 或 tower 層實作中介軟體；以 State 和 FromRef 管理應用程式狀態；透過自訂 IntoResponse 實作處理錯誤；使用 WebSocket 連線實作即時功能；提供 Server‑Sent Events（SSE）；處理 multipart 表單上傳；管理簽名、私密或普通 Cookie；提供靜態檔案；設定 CORS、追蹤、壓縮、逾時及其他 tower‑http 層；設定優雅關閉；從 axum 0.7 遷移至 0.8；或將 axum 與 tower 中介軟體整合時，請使用此技巧。確保在使用者提到 axum、Rust Web 框架、Rust HTTP 伺服器、Rust REST API、tokio‑rs axum、Rust 網頁開發、Rust API 伺服器或任何使用 axum 建置的 Web 服務時使用此技巧。
