دليل شامل لبناء تطبيقات الويب وواجهات برمجة التطبيقات باستخدام إطار العمل axum للغة Rust (من tokio-rs). استخدم هذه المهارة كلما رغب المستخدم في: بناء خوادم ويب، أو واجهات برمجة تطبيقات REST، أو خدمات HTTP بلغة Rust باستخدام axum؛ إعداد التوجيه باستخدام معلمات المسار، روترات متداخلة، بدائل، أو توجيه حسب الطريقة؛ استخدام مستخرجات الطلب (Path، Query، Json، Form، Bytes، String، HeaderMap، State، Extension، WebSocket، Multipart، Cookie)؛ إنشاء أنواع استجابة باستخدام IntoResponse؛ تنفيذ الوسيط (middleware) باستخدام middleware::from_fn أو طبقات tower؛ إدارة حالة التطبيق باستخدام State وFromRef؛ معالجة الأخطاء باستخدام تطبيقات مخصصة لـ IntoResponse؛ العمل مع اتصالات WebSocket للميزات الوقتية الفورية؛ تقديم أحداث الخادم المرسلة (SSE)؛ معالجة تحميلات النماذج المتعددة الأجزاء؛ إدارة ملفات تعريف الارتباط (الموقعة، الخاصة، أو العادية)؛ تقديم ملفات ثابتة؛ تكوين CORS، التتبع، الضغط، مهلات الوقت، وغيرها من طبقات tower‑http؛ إعداد إغلاق سلس؛ الترقية من axum 0.7 إلى 0.8؛ أو دمج axum مع وسيط tower. تأكد من استخدام هذه المهارة عندما يذكر المستخدم axum، أو إطار عمل ويب Rust، أو خادم HTTP Rust، أو واجهة برمجة تطبيقات REST Rust، أو tokio‑rs axum، أو تطوير ويب Rust، أو خادم API Rust، أو أي خدمة ويب مبنية بـ axum.
