Reconstruisez une page Web ou une interface utilisateur responsive à partir d'une capture d'écran, d'une maquette ou d'une image fournie. À utiliser pour la conversion d'image en code, la conversion de capture d'écran en React, l'implémentation pixel-parfait, l'extraction de ressources, la décomposition de calques, l'inspection des tokens de conception et de la typographie, la récupération d'icônes et l'assurance qualité visuelle sur les appareils mobiles, les tablettes et les ordinateurs de bureau. Ne pas utiliser pour une demande de fonctionnalité textuelle sans référence visuelle.
