Rekonstruieren Sie eine responsive Webseite oder Benutzeroberfläche anhand eines bereitgestellten Screenshots, Mockups oder Bildes. Verwenden Sie es für die Umwandlung von Bildern in Code, von Screenshots in React, für eine pixelgenaue Implementierung, die Extraktion von Assets, die Zerlegung von Ebenen, die Überprüfung von Design-Tokens und Typografie, die Wiederherstellung von Symbolen sowie die visuelle Qualitätssicherung auf Mobilgeräten, Tablets und Desktops. Nicht für eine textuelle Funktionsanforderung ohne visuelle Referenz verwenden.
