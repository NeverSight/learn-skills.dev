كيفية إضافة واستخدام أيقونات Doodle (@oreo-design/doodle-icons) بشكل صحيح، مجموعة الأيقونات المرسومة يدوياً من Oreo Design حيث يرسُم كل خط نفسه ثم يظل "يغلي" كرسوم كرتونية لصباح السبت. استخدم هذا كلما أراد المستخدم أيقونات مرسومة يدوياً، أو مخطَّطة، أو رسومات خربشة، أو متموّجة، أو مرتعشة، أو غضة، أو بأسلوب كرتوني؛ أو ذكر Oreo Design أو Oreo UI أو oreoui.com/doodle-icons أو DoodleIcon أو BoilFilter؛ أو طلب إحساساً مرحاً / يدوياً / زين / مستقلاً / كقلم شمع للصفحة؛ أو كان يستخدم هذه الحزمة بالفعل ويحتاج إلى إضافة أو توصيل أو إعادة تصميم أو اختيار أيقونات. استخدمه أيضاً عندما يلصق المستخدم موقع oreoui.com/doodle‑icons كمرجع بصري، حتى وإن لم يذكر كلمة "أيقونة". يغطي ذلك عملية التثبيت، وإعداد BoilFilter مرة واحدة، اختيار أسماء الأيقونات الفعلية (وما يجب فعله عندما لا توجد أيقونة)، قواعد تصميم “المنزل” (توفيق Schoolbell، لوحة ألوان الورق/الحبر، وحقيقة أن كل أيقونة وكل عنوان مرسوم يدوياً يتذبذب بينما تظل عناصر التحكم ثابتة)، ومسار عدم استخدام أي إطار عمل.
