Cómo añadir y usar correctamente Doodle Icons (@oreo-design/doodle-icons), el conjunto de íconos dibujados a mano de Oreo Design donde cada trazo se dibuja solo y luego sigue "hirviendo" como un dibujo animado de sábado por la mañana. Úsalo siempre que el usuario quiera íconos dibujados a mano, con aspecto de boceto, garabato, temblorosos, ondulados, boiling o estilo de caricatura; mencione Oreo Design, Oreo UI, oreoui.com/doodle-icons, DoodleIcon o BoilFilter; solicite una sensación lúdica / artesanal / zine / indie / de crayón para una página; o ya esté usando este paquete y necesite añadir, cablear, reestilizar o escoger íconos. También úsalo cuando el usuario pegue el sitio oreoui.com/doodle-icons como referencia visual, aun si nunca dice la palabra "icon". Cubre la instalación, la configuración única de BoilFilter, la selección de nombres de íconos reales (y qué hacer cuando un ícono no existe), las reglas de diseño interno (combinación Schoolbell, paleta de papel/tinta, y el hecho de que cada ícono y cada encabezado dibujado a mano se bambolea mientras los controles permanecen estáticos), y la ruta sin framework.
