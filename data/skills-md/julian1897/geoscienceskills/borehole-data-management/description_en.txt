Drilling data management and stratigraphic correlation (Mineral Geology & 3D Modeling). Read logging curves and wellhead information from LAS (Log ASCII Standard) format files, and construct a Striplog stratigraphic profile combined with lithology interpretation results. LAS is the petroleum industry standard for logging data exchange. Use when user asks about mineral geology and 3D modeling tasks such as: load the LAS files of these five wells and generate a standard column chart; use GR curve characteristics to assist in stratigraphic correlation; calculate the three‑dimensional wellbore trajectories for each well. Core tools: striplog_read_las_well, striplog_read_las_well.
