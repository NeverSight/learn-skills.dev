Crea y mantiene de forma incremental un índice de proyecto y módulos AGENTS.md para el repositorio de código. Se utiliza para inicializar o actualizar el contexto de IA, organizar la estructura del proyecto para que los agentes la usen y se invoca activamente cuando un agente modifica el contenido de un módulo que requiere que el índice existente se actualice. No está destinado al README, a la documentación de la API ni a otros índices de búsqueda.
