Créer et maintenir de façon incrémentielle un index de projet et de modules AGENTS.md pour le référentiel de code. Il est utilisé pour initialiser ou mettre à jour le contexte d'IA, organiser la structure du projet pour l'utilisation par les agents, et il doit être invoqué de manière proactive lorsqu'un agent modifie le contenu d'un module, nécessitant la mise à jour de l'index existant. Il n'est pas destiné au README, à la documentation API ou à d'autres index de recherche. Veuillez toujours répondre dans la langue de l'utilisateur.
