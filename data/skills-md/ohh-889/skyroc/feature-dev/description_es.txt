Exploración de la base de código, decisiones arquitectónicas, implementación y flujo de trabajo de revisión de calidad para funcionalidades complejas. Úselo solo cuando el usuario invoque explícitamente esta habilidad, o cuando la funcionalidad involucre claramente múltiples módulos o sistemas, cambios arquitectónicos significativos, decisiones de compatibilidad, migración de datos o implementaciones de alto riesgo; no lo utilice para cambios pequeños o medianos con un alcance claro.
