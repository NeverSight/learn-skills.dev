Exploración de la base de código, decisiones arquitectónicas, implementación y flujo de trabajo de revisión de calidad para funciones complejas. Úselo solo cuando el usuario invoque explícitamente esta Habilidad, o cuando la característica involucre claramente múltiples módulos o sistemas, ajustes arquitectónicos importantes, decisiones de compatibilidad, migración de datos o implementaciones de alto riesgo; no aplicarlo a cambios bien definidos de pequeña o mediana escala.
