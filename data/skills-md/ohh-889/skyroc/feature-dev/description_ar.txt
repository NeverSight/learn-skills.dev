استكشاف قاعدة التعليمات البرمجية والقرارات المعمارية والتنفيذ وسير عمل مراجعة الجودة للميزات المعقدة. يُستخدم فقط عندما يستدعي المستخدم هذه المهارة بشكل صريح، أو عندما تتضمن الوظيفة بشكل واضح وحدات أو أنظمة متعددة، أو تعديلات معمارية رئيسية، أو قرارات توافق، أو ترحيل البيانات، أو تطبيقات عالية المخاطر؛ لا تستخدمه لإجراء تغييرات صغيرة أو متوسطة بنطاق محدد جيدًا.
