استكشاف قاعدة التعليمات البرمجية والقرارات المعمارية والتنفيذ وسير عمل مراجعة الجودة للوظائف المعقدة. يُستخدم فقط عندما يستدعي المستخدم هذه المهارة بشكل صريح، أو عندما تتضمن الوظيفة بشكل واضح وحدات أو أنظمة متعددة، أو تغييرات معمارية مهمة، أو قرارات توافق، أو ترحيل البيانات، أو تطبيقات عالية المخاطر؛ لا تستخدم لإجراء تغييرات صغيرة أو متوسطة النطاق بشكل واضح.
