تداول الأسهم فقط — صَنِّف حركة السعر الحالية للسهم إلى أحد الحالات الخمس (انفجار / نطاق / تراجع / تصحيح عميق / كسر هيكلي) وفقًا لإطار عمل جاكل كوانت، وقدم دليل حجم المراكز المناسب. يُستخدم عندما يكتب المستخدم بالإنجليزية: "what state is $TICKER in"، "state classify NVDA"، "Jackal state for MRVL"، "5-state $TICKER"، أو بالصينية: "$TICKER 现在是哪个 state"، "$TICKER 在哪个阶段"، "$TICKER 的 5态分类"، "用 Jackal 框架看 $TICKER".

لا تُفعَّل في الحالات التالية: آلات الحالة البرمجية، مخططات حالة الكود، الأوتوماتونات المحدودة الحالة، حالة React، حالة Redux، أو أي استفسار غير متعلق بسوق الأسهم. إذا وردت كلمة "state" دون رمز سهم أو سياق سوق، لا تُستدعي.

يرجى الرد دائمًا بلغة المستخدم.
