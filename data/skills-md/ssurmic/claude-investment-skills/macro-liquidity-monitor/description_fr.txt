Radar de liquidité USD / financement repo. Suit l’écart SOFR‑IORB, la queue du SOFR, le tampon ON RRP, les réserves bancaires vs LCLoR, le drain/ajout TGA, la liquidité nette et la prise SRF (l’alarme de stress de financement). Produit un régime de tension 🟢 ABONDANT / 🟡 AMPLE / 🟠 RESSERRAGE / 🔴 STRESS avec deux perspectives — « trop lâche → bulle » et « trop serré → stress de financement ». Toutes les données proviennent de l’API NY Fed Markets + FRED (sans clé API). Fonctionne à la demande ou quotidiennement via GitHub Actions avec notification Telegram lors d’un changement de régime. Déclencheurs en anglais (« liquidity check », « is liquidity tight », « SOFR IORB spread », « RRP balance », « when does liquidity tighten », « repo stress ») ou en chinois (« 流动性怎么样 », « 流动性紧不紧 », « 什么时候收紧 », « SOFR IORB 利差 », « RRP 还剩多少 », « 回购市场压力 », « 美元流动性 »).
