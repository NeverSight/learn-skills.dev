Радар ликвидности в долларах США (фандинг/репо‑сети). Отслеживает спред SOFR‑IORB, хвост SOFR, буфер ON RRP, банковские резервы против LCLoR, отток/пополнение TGA, чистую ликвидность и захват SRF (сигнал о стрессовой ситуации финансирования). Выдаёт режим плотности 🟢 ОБИЛЬНЫЙ / 🟡 ДОВОЛЬНЫЙ / 🟠 СЖИМАЮЩИЙСЯ / 🔴 СТРЕСС с двумя перспективами — «слишком свободно → пузырь» и «слишком тесно → стресс финансирования». Все данные получаются из NY Fed Markets API + FRED (без ключа API). Работает по запросу или ежедневно через GitHub Actions с отправкой уведомления в Telegram при смене режима. Активируется на английском («liquidity check», «is liquidity tight», «SOFR IORB spread», «RRP balance», «when does liquidity tighten», «repo stress») или на китайском («流动性怎么样», «流动性紧不紧», «什么时候收紧», «SOFR IORB 利差», «RRP 还剩多少», «回购市场压力», «美元流动性»). Пожалуйста, всегда отвечайте на языке пользователя.
