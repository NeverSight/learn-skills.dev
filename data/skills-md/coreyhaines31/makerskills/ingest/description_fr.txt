Lorsque vous collez une entrée humaine brute — une transcription d’appel (Grain, Zoom, Granola, Fathom), un SMS ou un e‑mail d’un client/partenaire/ami, un dépôt de mémo vocal ou des notes de réunion — et que vous voulez qu’elle soit convertie en travail structuré. Elle extrait les décisions, les points d’action (les vôtres vs les leurs), les bugs/demandes de fonctionnalités et les faits à conserver ; crée des tickets GitHub dans le bon dépôt, les enregistre dans le coffre‑fort du second cerveau et rédige (sans jamais envoyer) la réponse. Elle se déclenche avec « /ingest », « ingest this », « here's my call with X », « here's the transcript », « this is from [person] », « [person] asked me this », « from [person] :», une transcription collée avec des étiquettes de locuteur, ou un message client transféré indiquant clairement qu’un traitement est attendu. Le routage personne→projet vit dans une configuration privée ; les expéditeurs inconnus sont interrogés une fois, puis mémorisés.
