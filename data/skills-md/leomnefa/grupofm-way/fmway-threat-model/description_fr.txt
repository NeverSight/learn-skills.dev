Utiliser pour construire un modèle de menace petit et limité sur le travail actuel ou sur du code nouveau — une fonctionnalité, un service, une API ou les changements de la branche actuelle. Décompose le système en actifs, points d’entrée et frontières de confiance, énumère les menaces avec STRIDE et consigne les mesures d’atténuation et le risque résiduel dans un rapport traçable avec un diagramme de flux de données. Il est invoqué séparément pour modéliser un composant, ou depuis un autre flux (fmway‑dev après le PRD ou le plan, fmway‑bugs pour une correction avec impact de sécurité) pour exposer les menaces avant d’écrire ou de livrer le code. Particulièrement important pour les nouvelles surfaces externes, les flux d’authentification, les paiements ou les données personnelles, et les changements dans les frontières de confiance.
