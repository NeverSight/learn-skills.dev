Générez une interface Android sans défauts avec Jetpack Compose + Material 3 Expressif (Android 14+ / API 34+). Utilisez-le chaque fois que l’utilisateur demande de construire, concevoir, structurer, restyler ou améliorer un écran, un composant, une activité, un fragment ou toute interface Android dans Compose. Deux phases — d’abord les jetons de thème (avec porte d’approbation), puis l’UI — les deux sont conditionnées par une checklist d’auto‑audit que le modèle DOIT exécuter avant de prétendre avoir terminé.

Veuillez toujours répondre dans la langue de l’utilisateur.
