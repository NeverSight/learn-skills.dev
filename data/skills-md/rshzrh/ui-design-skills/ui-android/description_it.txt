Genera interfacce Android senza difetti in Jetpack Compose + Material 3 Expressive (Android 14+ / API 34+). Utilizza ogni volta che l'utente richiede di costruire, progettare, strutturare, ridisegnare o migliorare una schermata, componente, activity, fragment o qualsiasi interfaccia Android in Compose.
