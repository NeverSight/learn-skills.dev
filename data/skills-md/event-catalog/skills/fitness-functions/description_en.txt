Writes, runs and debugs EventCatalog architecture fitness functions — TypeScript rules in `*.fitness.ts` files that check the documented architecture (ownership, naming, domain boundaries, dependencies, data access, schemas) and fail CI when it drifts. Turns an architecture rule described in plain language into a working fitness function, places it globally or beside the domain, system, service, message or data store it governs, runs `eventcatalog fitness check`, verifies the result, and wires it into CI. Use when user asks to "write a fitness function", "add an architecture rule", "enforce that every event has an owner", "check domain boundaries", "stop services sharing databases", "detect circular dependencies", "fail the build when the architecture breaks a rule", "run fitness checks in CI", or "why is my fitness function failing".
