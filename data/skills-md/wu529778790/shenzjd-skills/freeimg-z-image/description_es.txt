Genera imágenes IA a partir de indicaciones de texto mediante el modelo gratuito z-image-turbo (API serverless de Gitee AI, ~100 imágenes 2K gratuitas al día con un token gratuito). La configuración única almacena el token localmente; luego genera imágenes PNG en cualquier tamaño (múltiplo de 8), con indicaciones negativas y control de pasos. Aplicación web acompañante con una biblioteca de más de 18000 indicaciones y 12 estilos predefinidos: https://freeimg.shenzjd.com. Úsala para generar, dibujar o crear imágenes (iconos, portadas, ilustraciones, carteles).
