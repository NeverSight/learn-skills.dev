Websuche und Textgrundierung von Seiten über einen lokalen RustXNG‑Server (schlüssellos, selbstgehosteter SearXNG‑Port), gesteuert mit curl und jq. Verwendung, wenn eine Aufgabe aktuelle Fakten aus dem Web benötigt und das `rustxng`‑Binary im PATH liegt: Suchen, Abrufen von Seitentexten zur Untermauerung einer Antwort, Einschränken einer Abfrage auf bestimmte Domains oder Durchführen eines Multi‑Query‑`/research`‑Durchlaufs. Außerdem wird das Crawlen eines Korpus in einen lokalen BM25‑Index mit `rustxng-index` behandelt.
