Web search and page-text grounding through a local RustXNG server (keyless, self-hosted SearXNG port), driven with curl and jq. Use when a task needs current facts from the web and a `rustxng` binary is on PATH: searching, pulling page text to ground an answer, restricting a lookup to certain domains, or running a multi-query `/research` sweep. Also covers crawling a corpus into a local BM25 index with `rustxng-index`.
