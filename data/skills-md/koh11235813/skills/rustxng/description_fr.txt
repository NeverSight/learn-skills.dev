Recherche Web et ancrage de texte de page via un serveur local RustXNG (sans clé, port SearXNG auto-hébergé), piloté avec curl et jq. À utiliser lorsqu’une tâche nécessite des faits actuels du Web et qu’un binaire `rustxng` est présent dans le PATH : recherche, extraction du texte de page pour étayer une réponse, restriction d’une recherche à certains domaines, ou exécution d’un balayage multi‑requêtes `/research`. Couvre également le crawl d’un corpus dans un index BM25 local avec `rustxng-index`.
