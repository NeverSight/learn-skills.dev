Настройте harness‑агента этого репозитория для Claude Code: одну точку входа проверки (scripts/check.sh), раннер pre‑commit, линтеры, форматтеры, типизаторы и тесты, которые он запускает, хуки, которые выполняют их после каждого изменения и в конце каждого хода, включённые серверы языков, подтверждённые реальным LSP‑hover, а также облачную настройку, которая устанавливает их в каждый Claude Code в веб‑сессии, доказанную на реальном примере; каждый сторонний инструмент зафиксирован и проверяется при установке. Независимо от Ship; запустите её перед /setup-skills. Перезапускайте в любой момент для отчёта о пробелах, предлагающего только то, чего не хватает, что сломано или отстаёт, сохраняя собственные дополнения репозитория и выбранные варианты.
