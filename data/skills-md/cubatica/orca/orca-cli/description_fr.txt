Utilisez le CLI public `orca` pour gérer les worktrees contrôlés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les commentaires de worktree et le navigateur intégré à l’application Orca. Utilisez-le lorsque l’utilisateur dit « $orca-cli », « use orca cli », « Orca worktree », « child worktree », « cardStatus », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « terminal send », « full handoff », « handover », « give this to another agent », « another worktree », « Orca browser » ou « control the browser inside Orca ». Préférez cette option plutôt que le `git worktree` brut, les PTY ad hoc, Playwright ou l’Utilisation de l’ordinateur lorsque la tâche touche l’état géré par Orca. Utilisez l’Utilisation de l’ordinateur pour les fenêtres de navigateur, les webviews ou l’interface utilisateur de bureau en dehors du navigateur intégré d’Orca.

Veuillez toujours répondre dans la langue de l’utilisateur.
