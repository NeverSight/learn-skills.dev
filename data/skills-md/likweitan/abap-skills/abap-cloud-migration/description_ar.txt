المساعدة في ترحيل كود ABAP الكلاسيكي المخصص إلى مستويات نظيفة أعلى (المستوى A/B/C/D) بما في ذلك تكييف الكود المخصص، تحديد بدائل واجهات برمجة التطبيقات (API) الصادرة والكلاسيكية، إنشاء فئات غلاف (wrapper) للكائنات غير الصادرة، فحوصات ATC للنظام النظيف (clean core) والتحقق من جاهزية السحابة، سجل التغييرات لكائنات SAP، معالجة بناء الجمل اللغوية غير المتوافقة، وتدفقات عمل تصحيحية خطوة بخطوة. استخدمه عندما يطرح المستخدمون أسئلة حول الترحيل إلى ABAP Cloud، ترحيل الكود المخصص، جاهزية السحابة، تصحيح مستوى النظام النظيف، القضاء على المستوى D، تقليل المستوى C، استبدال واجهات برمجة التطبيقات غير الصادرة، نمط الغلاف (wrapper)، فحوصات ATC للنظام النظيف، تكييف الكود، الترحيل من الكلاسيكي إلى السحابة، أو الامتثال للنظام النظيف. تشمل المحفزات عبارات مثل "migrate to ABAP Cloud"، "cloud readiness check"، "clean core level"، "eliminate Level D"، "reduce Level C"، "non-released API"، "replace with released API"، "custom code adaptation"، "wrapper for non-released"، "ATC clean core"، "clean core migration"، "changelog for SAP objects" أو "ABAP Cloud compatibility". يرجى دائمًا الرد بلغة المستخدم.
