Aide pour migrer le code ABAP classique personnalisé vers des niveaux de clean core plus élevés (Niveau A/B/C/D), incluant l’adaptation du code personnalisé, l’identification des remplacements d’API publiées et classiques, la génération de classes wrapper pour les objets non publiés, les contrôles ATC clean core et cloud readiness, le journal des modifications pour les objets SAP, la gestion des constructions de langage incompatibles, ainsi que des workflows de remédiation étape par étape. À utiliser lorsque les utilisateurs posent des questions sur la migration vers ABAP Cloud, la migration du code personnalisé, la vérification de la readiness cloud, la remédiation du niveau clean core, l’élimination du Niveau D, la réduction du Niveau C, le remplacement d’API non publiées, le pattern wrapper, les contrôles ATC clean core, l’adaptation du code, la migration du classique vers le cloud ou la conformité clean core. Les déclencheurs comprennent « migrer vers ABAP Cloud », « vérification de readiness cloud », « niveau clean core », « éliminer le Niveau D », « réduire le Niveau C », « API non publiée », « remplacer par une API publiée », « adaptation du code personnalisé », « wrapper pour non publié », « ATC clean core », « migration clean core », « journal des modifications des objets SAP » ou « compatibilité ABAP Cloud ».
