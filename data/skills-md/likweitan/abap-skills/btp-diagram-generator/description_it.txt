Genera diagrammi di architettura di soluzioni SAP BTP (Business Technology Platform) come file nativi draw.io (.drawio) seguendo le linee guida ufficiali per i diagrammi SAP BTP Solution (sistema di design Fiori Horizon) e aprili tramite un server draw.io MCP configurato. USALO QUANDO: l'utente richiede di creare/disegnare/progettare/abbozzare un diagramma BTP, architettura BTP, landscape BTP, diagramma di soluzione BTP, architettura di riferimento BTP, diagramma SAP Business Technology Platform, o vuole visualizzare i servizi SAP BTP (CAP, Build, Integration Suite, SAC, AI Core, HANA Cloud, Cloud Foundry, Kyma, Workzone, ecc.) e le loro interdipendenze in draw.io / drawio / diagrams.net. NON USARLO PER: diagrammi di architettura non BTP, flowchart generici, diagrammi di sequenza/UML, o diagrammi che dovrebbero rimanere in Mermaid/PlantUML.

Rispondi sempre nella lingua dell'utente.
