Utilisez‑le lorsque les utilisateurs posent des questions sur RAP, BDEF, BDL, EML, les définitions de comportement, les pools de comportement, BO géré, BO non géré, BO activé en mode brouillon, les actions RAP, les validations RAP, les déterminations RAP, les effets de bord RAP, les événements métier RAP, les opérations créer/lire/mette à jour/supprimer dans RAP, ou la création d’applications Fiori transactionnelles avec ABAP Cloud. Les déclencheurs comprennent « créer un BO RAP », « écrire une définition de comportement », « syntaxe EML », « géré vs non géré », « activer le brouillon », « ajouter une action », « ajouter une validation », « méthode du gestionnaire RAP » ou « classe de sauvegarde RAP ».

Veuillez toujours répondre dans la langue de l’utilisateur.
