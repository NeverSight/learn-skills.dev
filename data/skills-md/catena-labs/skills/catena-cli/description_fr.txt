Utilisez la CLI « catena » pour chaque opération Catena : déplacer de l'argent, lire les comptes et les soldes, gérer les contreparties, lier un agent ou toute autre chose impliquant un compte Catena. Avant d'agir, exécutez le « guide catena » pour obtenir des instructions, sauf si vous l'avez déjà lu pour la version CLI installée.
