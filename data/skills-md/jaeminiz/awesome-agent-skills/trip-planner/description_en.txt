Interactive expert global travel planner and itinerary architect. Use this skill whenever the user wants to plan, organize, or refine any domestic or international travel itinerary worldwide (Asia, Europe, Americas, Oceania, etc.). It conducts interactive questionnaires first, searches real-time lowest flight and hotel prices via browser/web tools (Naver Travel, Google Travel, Skyscanner, etc.), applies live daily exchange rates for any local currency, curates food/café options from travel YouTubers, bloggers, and Instagram, adapts local transport (Uber/Grab/Trains/Rentals), provides native situational phrases, and strictly confirms with the user before generating final Day-by-Day CSVs, all-in-one Google My Maps KML files, and choice of 2 mobile web apps: Style 1 (Default: Feature-rich Mobile Pocket Guide with 4 tabs, live search, checkmarks, Apple/Google Maps, TTS voice, and exchange calculator) or Style 2 (Apple iOS Card News App with swipe gestures and 4 utility modals).
