# 证件照制作

在 Codex 中采用“内置图像编辑 + 确定性整理”的两段式流程。不要用 OpenCV、GrabCut 或临时 Python 代码替代 Codex 已有的语义图像编辑能力。

## 工作流

1. 明确用途、尺寸、背景色、文件格式和文件大小限制。用户只说“一寸照”等通用名称时，读取 `references/specs_reference.md`。尺寸优先级为：用户明确指定的像素或毫米尺寸 > 用户提供的机构要求 > skill 预设规格；不要让图片生成工具猜测精确尺寸。
   - 用户说“入学照、学籍照、新生照片”时，先从上下文区分幼儿园、中小学或高校，并优先读取学校通知、迎新系统或学籍平台要求。只有泛称且没有机构规格时，幼儿园使用“入园入托”，中小学使用“中小学学籍”，高校使用“高校入学”预设。
   - 不要把某一学校的要求描述为全国统一标准。中小学常见淡蓝底 `260×320 px`，高校常见白底 `240×320 px` 或蓝/浅蓝/白底 `480×640 px`，最终以学校要求为准。
2. 使用 Codex 的图片查看能力检查原图。确认照片中人物、头肩是否完整、脸部清晰度、姿态、遮挡、光线、背景和着装。若没有可访问的原图，请用户重新附图，不要凭空重建其身份外貌。
3. 判断是否需要语义编辑：
   - 只需精确缩放、轻微居中裁剪、写入 DPI 或压缩时，跳过图片生成，直接运行整理脚本。
   - 需要换背景、换合规着装、抠图、补齐画布、改善发丝/衣领边缘或调整证件照构图时，使用 Codex 内置图像编辑工具（如 GPT Image）。必须把用户原图作为参考图传入。
   - 不要用脚本做人像分割、生成式补脸或美颜。
4. 编辑后再次查看结果，检查身份相似度、五官、脸型、发际线、耳朵、眼镜、痣等稳定特征是否被改变，并检查头顶、下巴、肩部和替换后的服装是否自然完整。若存在明显变化，使用原图重新编辑并收紧提示词。
5. 所有最终交付都必须运行 `scripts/finalize.py`，即使用户没有要求改尺寸。脚本通过像素级重新编码清除来源文件中的 EXIF、XMP、ICC、C2PA/JUMBF、Photoshop/IPTC、注释等元数据，并按上述优先级输出精确像素、DPI 和 JPEG 文件大小。不要直接交付图片生成工具的原始文件。
6. 查看最终文件并报告实际像素、DPI、背景、文件格式、大小和“来源元数据已清除”。对于正式证件，说明最终是否受理仍以主管机关或报名平台审核为准。

## 内置图片编辑要求

调用 Codex 内置图片编辑能力时，提示词应包含以下约束，并按用户请求补充目标规格：

```text
将参考照片编辑为标准证件照。严格保留同一人的身份、真实五官、脸型、肤色、发际线、发型和可辨识特征；不要美颜、磨皮、瘦脸、改变年龄、表情或妆容。保持正面自然姿态，头部端正，双眼自然睁开，嘴巴自然闭合，头顶、下巴和双肩完整。将背景改为指定的均匀纯色，并精细保留发丝、耳朵、衣领和肩部边缘，不要产生白边、色溢或半透明轮廓。若原图为赤膊、背心、吊带、露肩、低领、透视或其他明显不符合该证件用途的着装，自动替换为符合对应要求、带袖、领口得体、无标志无图案的纯色日常上衣；白底正式证件优先使用深色上衣，其他背景使用有清晰对比的中性色。服装必须真实贴合原有颈肩和体型，光线一致，不得改变身体或身份特征。画面按目标宽高比构图，但在四周保留少量安全余量，精确像素由后续脚本完成。
```

- 原着装合规时保持不变。赤膊、背心、吊带、露肩、低领、透视等明显不合规时无需追问，自动替换为朴素、带袖、无标志无图案且与背景有对比的上衣；除非对应规范或用户明确要求，否则不要擅自添加西装或领带。
- 处理儿童入园或中小学入学照时，使用适龄、舒适、带袖、无校徽和品牌标志的简洁上衣；不要把儿童成人化，不添加领带、制服、妆容或不必要饰品。
- 优先遵循用户提供的机构着装要求。没有具体要求时，白底正式证件使用深色圆领或有领上衣；蓝底、红底使用与背景对比清晰的黑、白、灰等中性色上衣。不要生成制服、工装标识、文字、徽章或夸张配饰。
- 证件照默认使用均匀纯色背景。只有简历照等非正式用途且用户明确要求时才使用渐变背景。
- 不声称生成结果“符合官方标准”或“保证通过”；只能说明它按已知规格制作。
- 双人结婚登记照属于特殊场景：同时保留两人的身份和相对位置，整理脚本只负责最终尺寸，不负责判定“男左女右”。

## 确定性整理与元数据清理

首次使用只需安装 Pillow：

```bash
python3 -m pip install Pillow
```

按预设规格整理：

```bash
python3 {SKILL_ROOT}/scripts/finalize.py edited.png 一寸 -o final.jpg
python3 {SKILL_ROOT}/scripts/finalize.py edited.png 护照 -o passport.jpg
python3 {SKILL_ROOT}/scripts/finalize.py edited.png 美国签证 -o us-visa.jpg
```

指定 JPEG 质量或自定义像素：

```bash
python3 {SKILL_ROOT}/scripts/finalize.py edited.png 一寸 -o final.jpg --quality 95
python3 {SKILL_ROOT}/scripts/finalize.py edited.png 自定义 -o custom.jpg --width 300 --height 400 --dpi 300 --max-kb 100
python3 {SKILL_ROOT}/scripts/finalize.py edited.png 自定义 -o custom-mm.jpg --width-mm 25 --height-mm 35 --dpi 300
```

`--width/--height` 表示精确像素；`--width-mm/--height-mm` 按指定 DPI 换算像素。两组参数不要同时使用。脚本使用居中等比裁剪，不做人脸检测。若最终构图不理想，回到内置图片编辑步骤调整画布与人物位置，不要反复盲裁。

脚本会丢弃输入文件的全部附加元数据，以新像素缓冲区重新编码 JPEG，只保留显示 DPI 所需的 JFIF 密度字段；随后检查输出中不存在 EXIF、XMP、ICC、C2PA/JUMBF、Photoshop/IPTC 或注释段。不要再用会复制原元数据的工具覆盖最终文件。

## 兼容回退

`scripts/generator.py` 是面向不具备图片编辑工具的旧环境的 OpenCV 回退方案。在 Codex 中不要默认运行它。只有内置图片编辑工具不可用、用户接受边缘质量可能下降且明确需要继续时，才安装 `scripts/requirements.txt` 并使用该脚本。

## 规格数据

- 详细规格与注意事项：`references/specs_reference.md`
