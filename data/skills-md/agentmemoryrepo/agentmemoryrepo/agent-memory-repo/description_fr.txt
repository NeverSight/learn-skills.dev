Conservez la mémoire d’une session à l’autre dans un dépôt Git local séparé qui suit la spécification du dépôt de mémoire d’Agent. Utilisez‑le lorsque l’utilisateur invoque cette compétence, vous demande de retenir quelque chose pour les sessions futures, ou vous interroge sur ce que vous vous souvenez.

Veuillez toujours répondre dans la langue de l’utilisateur.
