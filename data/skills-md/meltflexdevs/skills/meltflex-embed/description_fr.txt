Placez l'outil de conception MeltFlex AI sur le propre site Web de l'utilisateur sous forme d'iframe (site Web intégré). À utiliser lorsque l'utilisateur souhaite que les visiteurs de son site, de sa boutique ou de ses pages de produits conçoivent une pièce à partir d'une photo ou placent les propres produits de la boutique dans leur chambre, sans compte MeltFlex. Couvre la création de l'intégration dans le constructeur, le collage du code en HTML, React / Next.js, Vue, Shopify, WordPress et Webflow, l'ouverture avec un produit sur les pages produit et la fixation d'un cadre vide. Aucune clé API requise.
