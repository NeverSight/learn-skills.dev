Разместите дизайн‑инструмент MeltFlex AI на собственном сайте пользователя в виде iframe (встраивание сайта). Используйте, когда пользователь хочет, чтобы посетители их сайта, магазина или страниц товаров могли спроектировать комнату по фотографии или разместить товары магазина в своей комнате, без учётной записи MeltFlex. Охватывает создание встраивания в конструкторе, вставку кода в HTML, React / Next.js, Vue, Shopify, WordPress и Webflow, открытие с товаром на страницах продукта и решение проблемы с пустым фреймом. Ключ API не требуется.
