Genera rediseños interior y exterior fotorrealistas a partir de una foto usando MeltFlex AI. Úsalo cuando el usuario quiera restilizar, rediseñar, despejar, escenificar virtualmente o retematizar una habitación, fachada o jardín; cambiar un suelo, acabado de pared, escalera, puertas o ventanas; rediseñar una cocina o baño; convertir un borrador 3D en una foto; o previsualizar un espacio en un estilo, material o estación diferentes. También puede producir un recorrido cinematográfico en video; para modelos 3D y mundos 3D consulta la habilidad complementaria meltflex-3d. Funciona directamente contra la API REST de MeltFlex — no se requiere instalación adicional.
