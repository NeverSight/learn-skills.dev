MeltFlex AIで3Dアセットを生成します。ユーザーが1枚の写真から家具のダウンロード可能な3Dモデル（GLB）を欲しい場合、2D平面図から3Dモデルまたはレンダリングされた3D画像が欲しい場合、または部屋の写真やレンダリングから探索可能な3Dワールド（Gaussian splat、.spz とホストされたビューアリンク）を欲しい場合に使用します。長時間ビルドのポーリング（HTTP 202）や期限切れのワールドリンクの更新にも対応します。MeltFlex REST API に直接対話でき、追加インストールは不要です。/meltflex:design のコンパニオンです。
