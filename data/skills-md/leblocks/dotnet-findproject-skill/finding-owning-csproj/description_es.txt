Encuentra el proyecto .csproj que posee un archivo fuente de C# (.cs) determinado utilizando la herramienta de CLI de dotnet de findproject. Utilícelo al localizar, crear o probar el proyecto que contiene un archivo .cs específico, al resolver un archivo en su proyecto más cercano, o cuando el usuario mencione findproject, csproj lookup o el proyecto propietario de un archivo. No lo use para proyectos .vbproj o .fsproj, para lenguajes que no sean .NET o para resolver un proyecto a su solución (.sln).
