Findet das .csproj-Projekt, das eine bestimmte C# (.cs) -Quelldatei besitzt, mit dem CLI-Tool findproject dotnet. Verwenden Sie diese Option, wenn Sie das Projekt suchen, erstellen oder testen, das eine bestimmte .cs-Datei enthält, wenn Sie eine Datei in das nächstgelegene Projekt auflösen oder wenn der Benutzer findproject, csproj lookup oder das eigene Projekt einer Datei erwähnt. Verwenden Sie es nicht für .vbproj- oder .fsproj-Projekte, für Nicht.NET-Sprachen oder zum Auflösen eines Projekts in seiner Lösung (.sln).
