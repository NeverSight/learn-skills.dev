API crewai 1.15.x actuelle versus l'API 0.x dont se souviennent les assistants de codage : importations, paramètres et valeurs par défaut d’Agent/Task/Crew, variantes de lancement, champs CrewOutput, chaînes de modèles LLM et options du fournisseur, sortie structurée (output_pydantic, response_model, response_format), garde‑fous, mémoire unifiée, embeddeurs de connaissances, l’assistant `crewai create crew` contre --classic, drapeaux reset‑memories et fonctionnalités supprimées. À utiliser lors de l’écriture, la révision ou le débogage de tout code crewai, avant de faire confiance à la syntaxe crewai mémorisée, ou lorsqu’un utilisateur colle des erreurs telles que `cannot import name 'BaseTool' from 'crewai_tools'`, `cannot import name 'persist'`, `ShortTermMemory`, `Anthropic native provider not available`, `LiteLLM fallback package is not installed`, `got an unexpected keyword argument 'response_format'`, `OPENAI_API_KEY is required`, `If return type is annotated, it must be Tuple[bool, Any]` ou `result.pydantic is None`.
