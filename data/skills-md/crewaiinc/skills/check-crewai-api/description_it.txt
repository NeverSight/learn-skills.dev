API corrente di crewai 1.15.x rispetto all'API 0.x che gli assistenti di codifica ricordano: import, parametri e valori predefiniti di Agent/Task/Crew, varianti di avvio, campi di CrewOutput, stringhe dei modelli LLM e extra del provider, output strutturato (output_pydantic, response_model, response_format), guardrails, Memoria unificata, incorporatori di conoscenza, la procedura guidata `crewai create crew` vs --classic, flag reset-memories e funzionalità rimosse. Usare quando si scrive, rivede o fa il debug di qualsiasi codice crewai, prima di fidarsi della sintassi crewai ricordata, o quando un utente incolla errori come `cannot import name 'BaseTool' from 'crewai_tools'`, `cannot import name 'persist'`, `ShortTermMemory`, `Anthropic native provider not available`, `LiteLLM fallback package is not installed`, `got an unexpected keyword argument 'response_format'`, `OPENAI_API_KEY is required`, `If return type is annotated, it must be Tuple[bool, Any]`, oppure `result.pydantic is None`.
