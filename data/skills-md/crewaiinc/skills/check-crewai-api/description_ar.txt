واجهة برمجة التطبيقات crewai 1.15.x الحالية مقارنةً بواجهة 0.x التي يتذكرها مساعدو الترميز: الاستيرادات، معلمات Agent/Task/Crew والقيم الافتراضية، أشكال بدء التشغيل، حقول CrewOutput، سلاسل نماذج LLM وامتيازات الموفر، الإخراج المهيكل (output_pydantic، response_model، response_format)، الحواجز، الذاكرة الموحدة، مُضمّنات المعرفة، معالج `crewai create crew` مقابل ‎--classic، علامات reset-memories، والميزات التي أُزيلت. استخدمها عند كتابة أو مراجعة أو تصحيح أي كود crewai، قبل الوثوق بصياغة crewai التي يتذكرها المساعد، أو عندما يلصق المستخدم أخطاء مثل `cannot import name 'BaseTool' from 'crewai_tools'`، `cannot import name 'persist'`، `ShortTermMemory`، `Anthropic native provider not available`، `LiteLLM fallback package is not installed`، `got an unexpected keyword argument 'response_format'`، `OPENAI_API_KEY is required`، `If return type is annotated, it must be Tuple[bool, Any]`، أو `result.pydantic is None`.
