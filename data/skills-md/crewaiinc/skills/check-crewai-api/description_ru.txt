Текущий API crewai 1.15.x против API 0.x, которое запоминают помощники‑программисты: импорты, параметры и значения по умолчанию Agent/Task/Crew, варианты запуска, поля CrewOutput, строки моделей LLM и дополнительные параметры провайдеров, структурированный вывод (output_pydantic, response_model, response_format), ограничения, унифицированная память, эмбеддеры знаний, мастер `crewai create crew` против --classic, флаги reset-memories и удалённые функции. Используйте при написании, проверке или отладке любого кода crewai, прежде чем доверять запомненной синтаксису crewai, или когда пользователь вставляет ошибки типа `cannot import name 'BaseTool' from 'crewai_tools'`, `cannot import name 'persist'`, `ShortTermMemory`, `Anthropic native provider not available`, `LiteLLM fallback package is not installed`, `got an unexpected keyword argument 'response_format'`, `OPENAI_API_KEY is required`, `If return type is annotated, it must be Tuple[bool, Any]`, или `result.pydantic is None`.
