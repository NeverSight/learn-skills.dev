Bereitstellung von crewAI‑Agenten mit Werkzeugen und MCP‑Servern in crewai 1.15.x: benutzerdefiniertes BaseTool mit args_schema und @tool, welche crewai_tools‑Namen tatsächlich existieren, Werkzeug‑Caching, max_usage_count, ToolFailure, Agent(mcps=[…])‑String und MCPServerStdio/HTTP/SSE‑Formen, umbenannte MCP‑Werkzeugnamen, MCPServerAdapter, Zeitlimits und das, was in einer gehosteten Bereitstellung funktioniert. Verwenden Sie dies beim Schreiben oder Debuggen eines Werkzeugs oder einer MCP‑Verbindung, wenn Sie „cannot import name BaseTool from crewai_tools“, „You are missing the mcp package“, „MCPConnectionError“, „Operation timed out after 30 seconds“, „reached its usage limit“, „Invalid MCP reference“, „Anthropic function name … must start with a letter“, einen Agenten, der niemals ein MCP‑Werkzeug aufruft, mcps=[…]‑Einträge, die keine Werkzeuge liefern (z. B. ein https://‑String unter akickoff oder in CrewAI AMP), oder einen stdio MCP‑Server, der lokal funktioniert, nach der Bereitstellung jedoch nicht, sehen.
