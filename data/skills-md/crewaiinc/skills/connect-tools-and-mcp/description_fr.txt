Fournir aux agents crewAI des outils et des serveurs MCP sur crewai 1.15.x : BaseTool personnalisée avec args_schema et @tool, les noms de crewai_tools qui existent réellement, mise en cache des outils, max_usage_count, ToolFailure, chaîne Agent(mcps=[...]) et les formes MCPServerStdio/HTTP/SSE, noms d’outils MCP réécrits, MCPServerAdapter, temps d’attente, et ce qui fonctionne sur un déploiement hébergé. Utilisez‑le lors de l’écriture ou du débogage d’un outil ou d’une connexion MCP, lorsque vous voyez « cannot import name BaseTool from crewai_tools », « You are missing the mcp package », « MCPConnectionError », « Operation timed out after 30 seconds », « reached its usage limit », « Invalid MCP reference », « Anthropic function name … must start with a letter », un agent qui n’appelle jamais un outil MCP, mcps=[…] qui ne produit aucun outil (par exemple une chaîne https:// sous akickoff ou sur CrewAI AMP), ou un serveur MCP stdio qui fonctionne localement mais pas après le déploiement.
