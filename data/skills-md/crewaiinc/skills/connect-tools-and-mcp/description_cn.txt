在 crewai 1.15.x 中为 crewAI 代理提供工具和 MCP 服务器：自定义 BaseTool（带 args_schema 和 @tool），实际存在的 crewai_tools 名称，工具缓存，max_usage_count，ToolFailure，Agent(mcps=[...]) 字符串以及 MCPServerStdio/HTTP/SSE 形式，重新编写的 MCP 工具名称，MCPServerAdapter，超时设置，以及在托管部署中可用的方案。编写或调试工具或 MCP 连接时使用，当出现 “cannot import name BaseTool from crewai_tools”、 “You are missing the mcp package”、 “MCPConnectionError”、 “Operation timed out after 30 seconds”、 “reached its usage limit”、 “Invalid MCP reference”、 “Anthropic function name … must start with a letter”、 代理从不调用 MCP 工具、 mcps=[...] 未产生任何工具（例如在 akickoff 中的 https:// 字符串或在 CrewAI AMP 中），或本地可用但部署后失效的 stdio MCP 服务器时，请参考本指南。
