crewai 1.15.x에서 crewAI 에이전트에 도구와 MCP 서버를 제공하기: args_schema와 @tool을 사용한 사용자 정의 BaseTool, 실제로 존재하는 crewai_tools 이름들, 도구 캐싱, max_usage_count, ToolFailure, Agent(mcps=[…]) 문자열 및 MCPServerStdio/HTTP/SSE 형태, 재작성된 MCP 도구 이름들, MCPServerAdapter, 타임아웃, 그리고 호스팅된 배포 환경에서 동작하는 항목들. 도구나 MCP 연결을 작성하거나 디버깅할 때, ‘cannot import name BaseTool from crewai_tools’, ‘You are missing the mcp package’, ‘MCPConnectionError’, ‘Operation timed out after 30 seconds’, ‘reached its usage limit’, ‘Invalid MCP reference’, ‘Anthropic function name … must start with a letter’ 와 같은 오류 메시지를 보거나, MCP 도구를 전혀 호출하지 않는 에이전트, 도구가 전혀 나오지 않는 mcps=[…] (예: akickoff 아래 또는 CrewAI AMP에서 https:// 문자열) 또는 로컬에서는 작동하지만 배포 후에는 작동하지 않는 stdio MCP 서버와 같은 상황에서 사용하십시오.
