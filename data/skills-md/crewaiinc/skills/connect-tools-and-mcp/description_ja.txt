crewAI エージェントにツールと MCP サーバーを提供する（crewai 1.15.x 対応）: args_schema と @tool を備えたカスタム BaseTool、実際に存在する crewai_tools の名前、ツールのキャッシュ、max_usage_count、ToolFailure、Agent(mcps=[…]) 文字列と MCPServerStdio/HTTP/SSE 形式、書き換えられた MCP ツール名、MCPServerAdapter、タイムアウト、そしてホスト環境で動作するもの。ツールや MCP 接続を作成・デバッグする際に使用し、次のエラーメッセージが表示されたときに参照してください: 「cannot import name BaseTool from crewai_tools」「You are missing the mcp package」「MCPConnectionError」「Operation timed out after 30 seconds」「reached its usage limit」「Invalid MCP reference」「Anthropic function name … must start with a letter」。また、MCP ツールを一度も呼び出さないエージェント、mcps=[…] がツールを返さない（例: akickoff もしくは CrewAI AMP の下にある https:// 文字列）場合、ローカルでは動作するがデプロイ後に機能しない stdio MCP サーバーの場合にも利用してください。
