Chiamare un crew o un flow distribuito su CrewAI AMP via HTTP: il token bearer e l'URL di deployment, GET /inputs, POST /kickoff con il corpo {"inputs": {...}}, le chiavi di input richieste ({placeholder} token), polling GET /status/{kickoff_id} con una scadenza e backoff, stati terminali e dove risiede il risultato, webhook, POST /resume, prime chiamate lente e scrivere crew che rimangano corretti quando vengono avviati più volte o in modo concorrente. Da usare quando si scrive un client, script, backend o frontend che chiama un crew distribuito, quando un kickoff restituisce 422 "Missing inputs: ...", quando un polling di stato non termina mai, riporta "NOT FOUND" o il campo result è vuoto, quando /resume restituisce 422 per executionId, quando il prompt di un run mostra i dati di un altro run, o quando l'utente incolla un kickoff_id, un curl /kickoff, o 'Template variable ... not found in inputs dictionary'.
