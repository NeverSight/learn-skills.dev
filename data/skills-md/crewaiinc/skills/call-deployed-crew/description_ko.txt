CrewAI AMP에 배포된 크루 또는 흐름을 HTTP로 호출하기: 베어러 토큰과 배포 URL, GET /inputs, {"inputs": {...}} 본문을 포함한 POST /kickoff, 필요한 입력 키({placeholder} 토큰), 마감 시간과 백오프를 사용한 GET /status/{kickoff_id} 폴링, 종료 상태와 결과가 저장되는 위치, 웹훅, POST /resume, 초기 호출이 느린 경우, 그리고 크루가 반복적이거나 동시적으로 킥오프될 때도 올바르게 동작하도록 작성하기. 배포된 크루를 호출하는 클라이언트, 스크립트, 백엔드 또는 프론트엔드를 작성할 때, 킥오프가 422 "Missing inputs: ..."를 반환할 때, 상태 폴링이 끝나지 않고 "NOT FOUND"라고 하거나 결과 필드가 비어 있을 때, /resume가 executionId 때문에 422를 반환할 때, 실행의 프롬프트에 다른 실행의 데이터가 표시될 때, 혹은 사용자가 kickoff_id, /kickoff curl, 또는 'Template variable ... not found in inputs dictionary'를 붙여넣을 때 사용하십시오.
