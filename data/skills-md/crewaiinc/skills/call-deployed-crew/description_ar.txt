استدعاء طاقم أو تدفق تم نشره على CrewAI AMP عبر HTTP: رمز الـ bearer وعنوان النشر، GET /inputs، POST /kickoff مع جسم ‎{"inputs": {...}}‎، مفاتيح الإدخال المطلوبة (‎{placeholder}‎ tokens)، الاستطلاع عبر GET /status/{kickoff_id} مع حد زمني وتراجع (backoff)، الحالات النهائية ومكان وجود النتيجة، webhooks، POST /resume، النداءات الأولية البطيئة، وكتابة الفرق التي تظل صحيحة عندما تُشغل بشكل متكرر أو متزامن. يُستخدم عند كتابة عميل أو سكريبت أو خلفية أو واجهة أمامية تستدعي طقمًا مُنشرًا، عندما يُعيد kickoff حالة 422 "Missing inputs: …"، عندما لا ينتهي استطلاع الحالة أبدًا أو يُظهر "NOT FOUND" أو يكون حقل النتيجة فارغًا، عندما تُعيد /resume حالة 422 للـ executionId، عندما يُظهر موجه التشغيل بيانات تشغيل آخر، أو عندما يلصق المستخدم ‎kickoff_id‎ أو أمر ‎curl /kickoff‎ أو 'Template variable … not found in inputs dictionary'.
