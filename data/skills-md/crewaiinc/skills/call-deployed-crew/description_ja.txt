HTTP 経由で CrewAI AMP にデプロイされたクルーまたはフローを呼び出す際のポイント：ベアラートークンとデプロイメント URL、GET /inputs、{"inputs": {...}} ボディを使った POST /kickoff、必須の入力キー（{placeholder} トークン）、デッドラインとバックオフを設定した GET /status/{kickoff_id} のポーリング、ターミナル状態と結果が格納される場所、Webhook、POST /resume、最初の呼び出しが遅いこと、そして繰り返しまたは同時にキックオフされても正しく動作し続けるクルーの作り方。デプロイされたクルーを呼び出すクライアント、スクリプト、バックエンドまたはフロントエンドを作成するとき、kickoff が 422 「Missing inputs: ...」を返すとき、ステータスポーリングが終了しないとき、「NOT FOUND」と表示されるとき、または結果フィールドが空のとき、/resume が executionId に対して 422 を返すとき、実行のプロンプトに別の実行のデータが表示されるとき、あるいはユーザーが kickoff_id、/kickoff の curl コマンド、もしくは「Template variable ... not found in inputs dictionary」というエラーメッセージを貼り付けたときに活用してください。
