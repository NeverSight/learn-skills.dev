Appeler un crew ou un flow déployé sur CrewAI AMP via HTTP : le token bearer et l’URL de déploiement, GET /inputs, POST /kickoff avec le corps {"inputs": {…}} où les clés d’entrée requises ({placeholder} tokens) sont indiquées, interroger GET /status/{kickoff_id} avec une deadline et un back‑off, états terminaux et localisation du résultat, webhooks, POST /resume, premiers appels lents, et rédiger des crews qui restent corrects lorsqu’ils sont déclenchés de façon répétée ou concurrente. Utilisez‑le lors de l’écriture d’un client, script, backend ou frontend qui appelle un crew déployé, lorsqu’un kickoff renvoie 422 « Missing inputs: … », lorsqu’un poll de statut ne se termine jamais, indique « NOT FOUND » ou que le champ result est vide, lorsque /resume renvoie 422 pour executionId, lorsque l’invite d’une exécution montre les données d’une autre exécution, ou lorsque l’utilisateur colle un kickoff_id, un curl /kickoff, ou « Template variable … not found in inputs dictionary ».
