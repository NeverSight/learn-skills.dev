Получение CrewAI‑команды или потока в CrewAI AMP: форма проекта, которую ожидает сборка (uv.lock, тип [tool.crewai], точки входа src/<pkg>/, реальный подкласс Flow, абсолютные импорты, самостоятельный корень), `crewai deploy validate`, три пути развертывания (CLI create/push, GitHub, загрузка ZIP) и что каждый из них действительно загружает, переменные окружения для каждого развертывания и что CLI повторно отправляет из .env, ключи провайдеров и дополнительные параметры, а также выбор организации на уровне машины. Используйте при запуске `crewai deploy create` / `crewai deploy push` / `crewai deploy validate`, когда развертывание показывает статус Online, но запускает старый код, старые значения env или потерянный ключ, либо при появлении ошибок вроде `missing_lockfile`, `Crew class annotated with @CrewBase not found`, `No Flow subclass found`, `Expected to find at least one of these files: uv.lock or poetry.lock`, `OPENAI_API_KEY is required`, `Anthropic native provider not available`, `deployment_not_found`, `git_clone_failure`, `Automation error, fix the code and deploy again` или `pyproject.toml not found`.
