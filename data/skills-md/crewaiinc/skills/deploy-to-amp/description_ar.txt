الحصول على طاقم CrewAI أو تدفق Flow على CrewAI AMP: شكل المشروع الذي يتوقعه البناء (uv.lock، نوع [tool.crewai]، نقاط الدخول src/<pkg>/، فئة Flow فرعية حقيقية، استيرادات مطلقة، جذر مستقل)، `crewai deploy validate`، مسارات النشر الثلاثة (إنشاء/دفع عبر سطر الأوامر، GitHub، رفع ZIP) وما يحمّله كل مسار فعليًا، متغيّرات البيئة لكل نشر وما يعيد إرساله سطر الأوامر من .env، مفاتيح الموفرين والإضافات، واختيار المؤسسة على مستوى الجهاز. يُستخدم عند تشغيل `crewai deploy create` / `crewai deploy push` / `crewai deploy validate`، عندما يُظهر النشر حالة Online لكنه يُشغّل كودًا قديمًا، قيم بيئة قديمة أو فقدان مفتاح، أو عند لصق الأخطاء مثل `missing_lockfile`، `Crew class annotated with @CrewBase not found`، `No Flow subclass found`، `Expected to find at least one of these files: uv.lock or poetry.lock`، `OPENAI_API_KEY is required`، `Anthropic native provider not available`، `deployment_not_found`، `git_clone_failure`، `Automation error, fix the code and deploy again`، أو `pyproject.toml not found`.
