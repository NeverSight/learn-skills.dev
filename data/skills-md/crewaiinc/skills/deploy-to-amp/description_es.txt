Obtener una crew o flow de CrewAI en CrewAI AMP: la forma del proyecto que la compilación espera (uv.lock, tipo [tool.crewai], puntos de entrada src/<pkg>/, una subclase real de Flow, importaciones absolutas, una raíz autocontenida), `crewai deploy validate`, los tres caminos de despliegue (CLI create/push, GitHub, carga ZIP) y lo que cada uno realmente sube, variables de entorno por despliegue y lo que el CLI reenvía desde .env, claves de proveedores y extras, y selección de organización a nivel de máquina. Úsalo al ejecutar `crewai deploy create` / `crewai deploy push` / `crewai deploy validate`, cuando un despliegue indica Online pero ejecuta código antiguo, valores de entorno antiguos o perdió una clave, o al pegar errores como `missing_lockfile`, `Crew class annotated with @CrewBase not found`, `No Flow subclass found`, `Expected to find at least one of these files: uv.lock or poetry.lock`, `OPENAI_API_KEY is required`, `Anthropic native provider not available`, `deployment_not_found`, `git_clone_failure`, `Automation error, fix the code and deploy again`, o `pyproject.toml not found`.
