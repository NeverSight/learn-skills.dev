CrewAIのクルーまたはフローをCrewAI AMPに配置する方法：ビルドが期待するプロジェクト形状（uv.lock、[tool.crewai] タイプ、src/<pkg>/ エントリーポイント、実際のFlowサブクラス、絶対インポート、自己完結型ルート）、`crewai deploy validate`、デプロイの3つのパス（CLIのcreate/push、GitHub、ZIPアップロード）とそれぞれが実際にアップロードするもの、デプロイごとの環境変数とCLIが .env から再送信する項目、プロバイダーキーと追加情報、そしてマシン全体の組織選択。`crewai deploy create`、`crewai deploy push`、`crewai deploy validate` を実行する際、デプロイが「Online」と表示されても古いコードが走っている、古い環境変数が使われている、キーが失われた、または以下のようなエラーが貼り付けられた場合に使用してください：`missing_lockfile`、`Crew class annotated with @CrewBase not found`、`No Flow subclass found`、`Expected to find at least one of these files: uv.lock or poetry.lock`、`OPENAI_API_KEY is required`、`Anthropic native provider not available`、`deployment_not_found`、`git_clone_failure`、`Automation error, fix the code and deploy again`、あるいは `pyproject.toml not found`。
