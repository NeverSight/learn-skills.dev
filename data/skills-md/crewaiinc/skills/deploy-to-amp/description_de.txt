Ein *CrewAI*‑Crew oder -Flow in *CrewAI AMP* bekommen: die Projektstruktur, die der Build erwartet (uv.lock, [tool.crewai]‑Typ, src/<pkg>/‑Einstiegspunkte, eine tatsächliche Flow‑Unterklasse, absolute Importe, ein eigenständiger Root), `crewai deploy validate`, die drei Bereitstellungspfade (CLI create/push, GitHub, ZIP‑Upload) und was jeder von ihnen tatsächlich hochlädt, Umgebungsvariablen pro Deployment und was das CLI aus .env erneut sendet, Provider‑Schlüssel und Extras sowie die organisationsweite Auswahl auf Maschinenebene. Verwendung beim Ausführen von `crewai deploy create` / `crewai deploy push` / `crewai deploy validate`, wenn ein Deployment „Online“ anzeigt, aber alten Code, alte Env‑Werte ausführt oder einen Schlüssel verloren hat, oder beim Auftreten von Fehlermeldungen wie `missing_lockfile`, `Crew class annotated with @CrewBase not found`, `No Flow subclass found`, `Expected to find at least one of these files: uv.lock or poetry.lock`, `OPENAI_API_KEY is required`, `Anthropic native provider not available`, `deployment_not_found`, `git_clone_failure`, `Automation error, fix the code and deploy again` oder `pyproject.toml not found`.
