pytest を用いた CrewAI のクルーやフローの決定論的・オフラインテスト：API キー不要でテキスト、構造化出力、ツール呼び出しを駆動するスタブ BaseLLM（references/stub_llm.py に同梱）により、CrewAI が生成したプロンプトをアサートし、ガードレールやフローのルーティングをテストし、`crewai test` が実際に行うこと、デバッグ用イベントリスナー、そして正確なトレース／テレメトリ環境変数の値を確認できます。CrewAI プロジェクトのテスト作成時に、LLM をモックまたはスタブ化したり、カスタム BaseLLM を実装したり、CI で `TypeError: ... call() got an unexpected keyword argument 'from_task'` や `ValueError: OPENAI_API_KEY is required`、pytest で `TraceGrantError` が出たとき、`crewai test` を実行する際、BaseEventListener を追加する際、あるいは CREWAI_TRACING_ENABLED / CREWAI_DISABLE_TELEMETRY / OTEL_SDK_DISABLED を設定する際に使用します。
