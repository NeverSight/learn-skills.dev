اختبار حتمي وغير متصل لفرق CrewAI وتدفقات العمل باستخدام pytest: قاعدة BaseLLM تجريبية (موجودة في references/stub_llm.py) تُحَرك النص، والإخراج المنظم، واستدعاءات الأدوات دون الحاجة إلى مفتاح API، مع التأكيد على المطالبات التي يبنيها crewai، واختبار الحواجز وتوجيه التدفق، وما يفعله فعليًا `crewai test`، ومستمعي الأحداث لتصحيح الأخطاء، والقيم الدقيقة لمتغيرات البيئة للتتبع/التليمترية. استخدم ذلك عند كتابة اختبارات لمشروع crewai، أو محاكاة أو تجسيد الـLLM، أو كتابة BaseLLM مخصص، أو مواجهة الخطأ `TypeError: ... call() got an unexpected keyword argument 'from_task'`، أو `ValueError: OPENAI_API_KEY is required` في CI، أو `TraceGrantError` في pytest، أو تشغيل `crewai test`، أو إضافة BaseEventListener، أو ضبط المتغيرات CREWAI_TRACING_ENABLED / CREWAI_DISABLE_TELEMETRY / OTEL_SDK_DISABLED.
