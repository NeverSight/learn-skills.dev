Deterministisches, offline Testen von CrewAI Crews und Flows mit pytest: ein Stub‑BaseLLM (geliefert in references/stub_llm.py), das Text, strukturierte Ausgabe und Tool‑Aufrufe ohne API‑Schlüssel steuert, Assertions auf den von crewai erstellten Prompts ausführt, Guardrails und Flow‑Routing testet, was `crewai test` wirklich macht, Event‑Listener zum Debuggen bereitstellt und die genauen Werte der Tracing/Telemetry‑Umgebungsvariablen liefert. Verwenden Sie es beim Schreiben von Tests für ein crewai‑Projekt, beim Mocken oder Stubben des LLM, beim Schreiben eines eigenen BaseLLM, wenn Sie `TypeError: … call() got an unexpected keyword argument 'from_task'`, `ValueError: OPENAI_API_KEY is required` in CI, `TraceGrantError` in pytest sehen, `crewai test` ausführen, einen BaseEventListener hinzufügen oder CREWAI_TRACING_ENABLED / CREWAI_DISABLE_TELEMETRY / OTEL_SDK_DISABLED setzen.
