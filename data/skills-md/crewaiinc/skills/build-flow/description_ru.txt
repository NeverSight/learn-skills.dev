Создание Flow‑ов CrewAI в crewai 1.15.x: состояния в виде структур (Pydantic) против словарей и state.id, связь @start/@listen/@router, семантика or_/and_, метки роутеров vs имена методов, @persist (правильный импорт, где сохраняет состояние, restore_from_state_id), контрольные точки с CheckpointConfig, @human_feedback и HumanFeedbackResult.feedback, plot(), вызов команд (crews) и агентов из методов flow, входные данные при запуске и шаблон `crewai create flow`. Используйте при написании или отладке подкласса Flow или main.py с `from crewai.flow import ...`, когда слушатель никогда не срабатывает или срабатывает дважды, либо появляются ошибки типа «listen condition 'x' references the handler name 'x'», «cannot import name 'persist'», «'StateWithId' object is not subscriptable», «Flow state model must have an 'id' field», «--inputs requires a declarative flow definition», «invoked synchronously from within a running event loop» или HumanFeedbackCollapseError.
