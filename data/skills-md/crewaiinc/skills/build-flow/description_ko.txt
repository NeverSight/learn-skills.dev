CrewAI 1.15.x에서 CrewAI Flow를 구축하기: 구조화된(Pydantic) 상태와 dict 상태 및 state.id, @start/@listen/@router 연결, or_/and_ 의미론, 라우터 라벨 vs 메서드 이름, @persist(올바른 import, 상태를 저장하는 위치, restore_from_state_id), CheckpointConfig를 활용한 체크포인팅, @human_feedback 및 HumanFeedbackResult.feedback, plot(), flow 메서드에서 crew와 agent 호출, kickoff 입력, 그리고 `crewai create flow` 스캐폴드. Flow 서브클래스나 main.py를 `from crewai.flow import ...` 로 작성·디버깅할 때, 리스너가 전혀 실행되지 않거나 두 번 실행될 때, 혹은 다음과 같은 오류가 나타날 경우에 사용합니다: "listen condition 'x' references the handler name 'x'", "cannot import name 'persist'", "'StateWithId' object is not subscriptable", "Flow state model must have an 'id' field", "--inputs requires a declarative flow definition", "invoked synchronously from within a running event loop", 또는 HumanFeedbackCollapseError.
