Erstellen von CrewAI‑Flows auf crewai 1.15.x: strukturierter (Pydantic) vs. dict‑Zustand und state.id, @start/@listen/@router‑Verdrahtung, or_/and_‑Semantik, Router‑Labels vs. Methodennamen, @persist (richtiger Import, wo es den Zustand speichert, restore_from_state_id), Checkpointing mit CheckpointConfig, @human_feedback und HumanFeedbackResult.feedback, plot(), Aufrufen von Crews und Agents aus Flow‑Methoden, Kickoff‑Eingaben und das `crewai create flow`‑Gerüst. Verwenden Sie dies beim Schreiben oder Debuggen einer Flow‑Unterklasse oder main.py mit `from crewai.flow import ...`, wenn ein Listener nie ausgelöst wird oder zweimal ausgelöst wird, oder wenn Sie Fehler wie „listen condition 'x' references the handler name 'x'“, „cannot import name 'persist'“, „'StateWithId' object is not subscriptable“, „Flow state model must have an 'id' field“, „--inputs requires a declarative flow definition“, „invoked synchronously from within a running event loop“ oder HumanFeedbackCollapseError sehen.
