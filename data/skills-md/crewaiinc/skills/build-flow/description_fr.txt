Construction de CrewAI Flows sur crewai 1.15.x : état structuré (Pydantic) vs état dictionnaire et state.id, câblage @start/@listen/@router, sémantiques or_/and_, libellés de routeur vs noms de méthodes, @persist (import correct, où il stocke l’état, restore_from_state_id), point de contrôle avec CheckpointConfig, @human_feedback et HumanFeedbackResult.feedback, plot(), appel des crews et agents depuis les méthodes du flow, entrées de lancement, et le squelette `crewai create flow`. À utiliser lors de l’écriture ou du débogage d’une sous‑classe Flow ou de main.py avec `from crewai.flow import …`, lorsqu’un écouteur ne se déclenche jamais ou se déclenche deux fois, ou lorsqu’apparaissent des erreurs telles que « listen condition 'x' references the handler name 'x' », « cannot import name 'persist' », « 'StateWithId' object is not subscriptable », « Flow state model must have an 'id' field », « --inputs requires a declarative flow definition », « invoked synchronously from within a running event loop », ou HumanFeedbackCollapseError.
