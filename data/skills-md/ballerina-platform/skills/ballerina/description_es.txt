Escribe, ejecuta, prueba, depura y despliega programas e integraciones de Ballerina. Úsalo cuando el usuario solicite escribir, crear, implementar, actualizar o corregir código Ballerina; crear o configurar un nuevo proyecto o paquete Ballerina; construir un servicio HTTP, API, servicio GraphQL o integración en Ballerina; ejecutar, probar o compilar un proyecto Ballerina; añadir una biblioteca o dependencia; depurar, diagnosticar o explicar un error de compilación, un pánico en tiempo de ejecución, una traza de pila o una integración fallida de Ballerina; trabajar con un archivo .bal, Ballerina.toml, Dependencies.toml o Config.toml; ejecutar un comando bal; generar código Ballerina a partir de una especificación OpenAPI o proto; desplegar un servicio Ballerina a Docker, Kubernetes o una imagen nativa GraalVM; o cuando el usuario no tenga Ballerina instalado y necesite ayuda para configurarlo.
