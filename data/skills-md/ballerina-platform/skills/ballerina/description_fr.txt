Écrit, exécute, teste, débogue et déploie des programmes et des intégrations Ballerina. À utiliser lorsque l'utilisateur demande d'écrire, créer, implémenter, mettre à jour ou corriger du code Ballerina ; créer ou configurer un nouveau projet ou paquet Ballerina ; construire un service HTTP, une API, un service GraphQL ou une intégration en Ballerina ; exécuter, tester ou compiler un projet Ballerina ; ajouter une bibliothèque ou une dépendance ; déboguer, diagnostiquer ou expliquer une erreur de compilation Ballerina, une panique d'exécution, une trace de pile ou une intégration qui échoue ; travailler avec un fichier .bal, Ballerina.toml, Dependencies.toml ou Config.toml ; exécuter une commande bal ; générer du code Ballerina à partir d'une spécification OpenAPI ou proto ; déployer un service Ballerina sur Docker, Kubernetes ou une image native GraalVM ; ou lorsque l'utilisateur n'a pas Ballerina installé et a besoin d'aide pour le configurer.
