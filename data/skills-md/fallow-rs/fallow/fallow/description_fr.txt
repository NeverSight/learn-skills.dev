Intelligence du code pour TypeScript et JavaScript. L’analyse statique signale les risques liés au code modifié, les opportunités de nettoyage, la duplication, les dépendances circulaires, les points chauds de complexité, les limites d’architecture, la dérive du système de conception, les drapeaux de fonctionnalité et les candidats à la sécurité opt‑in. La découverte locale optionnelle de code similaire trouve les fonctions qui peuvent implémenter la même intention malgré une syntaxe différente. La couverture d’exécution peut fusionner les données d’exécution en production. Utilisez‑le lorsqu’on vous demande d’auditer le risque d’une PR, de trouver du code ou des dépendances inutilisés, de comparer des fonctions sémantiquement similaires, de détecter des duplications, d’inspecter les limites d’architecture, de fusionner la couverture d’exécution, de corriger automatiquement les problèmes pris en charge, ou de fonctionner en mode veille.
