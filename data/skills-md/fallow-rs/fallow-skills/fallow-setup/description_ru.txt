Настройте или модернизируйте инструменты контроля качества кода для проектов на JavaScript и TypeScript. Используйте при создании проекта, добавлении проверок здоровья кода или качества CI, подготовке репозитория к работе с агентами, а также при консолидации анализа мёртвого кода, дублирования, архитектуры, зависимостей и изменённого кода. Не используйте для задач, связанных только с форматированием, только с правилами lint или только с ошибками типизации TypeScript. Не используйте для запуска анализа уже настроенного проекта; используйте соответствующий навык для этого.

Пожалуйста, всегда отвечайте на языке пользователя.
