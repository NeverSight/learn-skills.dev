Configura o modernizza gli strumenti di qualità del codice per progetti JavaScript e TypeScript. Usalo quando crei un progetto, aggiungi controlli di salute del codice o verifiche di qualità CI, rendi un repository pronto per gli agenti o consolidi l'analisi di codice morto, duplicazione, architettura, dipendenze e codice modificato. Non usarlo solo per formattazione, solo per regole lint o per errori di tipo TypeScript. Non usarlo per eseguire un'analisi di un progetto già configurato; utilizza la skill fallow per questo.
