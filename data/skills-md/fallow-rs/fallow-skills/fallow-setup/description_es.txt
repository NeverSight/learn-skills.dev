Configurar o modernizar herramientas de calidad de código para proyectos JavaScript y TypeScript. Úselo al crear un proyecto, agregar comprobaciones de calidad de salud de código o CI, preparar un agente de repositorio o consolidar código muerto, duplicación, arquitectura, dependencia y análisis de código cambiado. No lo utilice para tareas de solo formato, solo regla de pelusa o error de tipo TypeScript. No lo use para ejecutar un análisis de un proyecto que ya está configurado; use la habilidad en barbecho para eso.
