C’est spécifiquement destiné à l’écriture, la modification, l’explication et le débogage de code VTK (Visualization Toolkit) en Python/C++. Les utilisateurs doivent recourir à cette compétence chaque fois qu’ils font de la programmation VTK, des pipelines VTK, vtkPolyData/vtkImageData/vtkUnstructuredGrid, des lecteurs/filtres/mappers/acteurs/écrivains, STL/OBJ/PLY/VTP/VTU/DICOM, le rendu de volume, l’intégration Qt, CMake, vtk_module_autoinit, la gestion de code qui ne s’affiche pas/ne se met pas à jour/plante, la conversion Python/C++, la recherche de noms de classes VTK/fichiers d’en‑tête/modules, ou le désir de se référer aux programmes d’exemple officiels. Cette compétence est le routeur principal « code‑first » : déterminer d’abord quel type de code VTK écrire/modifier/déboguer, puis lire une petite quantité de référence si nécessaire ; les index de classes et les exemples ne sont que auxiliaires afin d’éviter d’inventer des API.

Veuillez toujours répondre dans la langue de l’utilisateur.
