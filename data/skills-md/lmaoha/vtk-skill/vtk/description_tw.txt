專門用於編寫、修改、解讀與除錯 VTK（Visualization Toolkit）Python/C++ 程式碼。使用者在進行 VTK 程式設計、操作 vtk 流管、vtkPolyData / vtkImageData / vtkUnstructuredGrid、讀取器 / 過濾器 / 映射器 / 演員 / 寫入器、處理 STL / OBJ / PLY / VTP / VTU / DICOM 檔案、體積渲染、Qt 整合、CMake、vtk_module_autoinit、遇到程式碼不顯示 / 不更新 / 崩潰、在 Python 與 C++ 之間轉換、查找 VTK 類別名稱 / 標頭檔 / 模組，或想參考官方範例程式時，都應運用此技能。此技能作為「程式碼優先」的主要切入點：首先確定要編寫 / 修改 / 除錯的 VTK 程式類型，然後在需要時查閱少量參考；類別索引與範例僅作為輔助，以避免捏造 API。
