Específicamente para escribir, modificar, interpretar y depurar código VTK (Visualization Toolkit) en Python/C++. Los usuarios deben emplear esta habilidad siempre que estén programando en VTK, trabajando con pipelines de vtk, vtkPolyData/vtkImageData/vtkUnstructuredGrid, lectores/filtros/mappers/actores/escritores, manejando archivos STL/OBJ/PLY/VTP/VTU/DICOM, renderizado de volúmenes, integración con Qt, CMake, vtk_module_autoinit, experimentando que el código no se muestra/no se actualiza/se bloquea, convirtiendo entre Python y C++, buscando nombres de clases/archivos de encabezado/módulos de VTK, o quieran referirse a programas de ejemplo oficiales. Esta habilidad sirve como punto de entrada principal centrado en el código: primero determinar qué tipo de código VTK escribir/modificar/depurar, luego consultar una pequeña cantidad de referencia según sea necesario; los índices de clases y ejemplos son solo auxiliares, para evitar inventar APIs.

Por favor, responda siempre en el idioma del usuario.
