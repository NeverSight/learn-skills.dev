Specifically for writing, modifying, interpreting, and debugging VTK (Visualization Toolkit) Python/C++ code. Users should employ this skill whenever they are doing VTK programming, working with vtk pipelines, vtkPolyData/vtkImageData/vtkUnstructuredGrid, readers/filters/mappers/actors/writers, handling STL/OBJ/PLY/VTP/VTU/DICOM files, volume rendering, Qt integration, CMake, vtk_module_autoinit, experiencing code not displaying/not updating/crashing, converting between Python and C++, looking up VTK class names/header files/modules, or want to refer to official example programs. This skill serves as the code‑first main entry point: first determine which type of VTK code to write/modify/debug, then consult a small amount of reference as needed; class indexes and examples are only auxiliary, to avoid fabricating APIs.
