Linterizzazione e formattazione del codice SAS con @sasjs/lint – le regole .sasjslint e i loro valori predefiniti, severityLevel e codici di uscita, le sovrascritture @sasjslint per file, cosa corregge il formattatore e come il SASjs CLI, l’estensione VS Code e il SASjs Server lo eseguono. Usalo quando configuri le regole di lint, risolvi un avviso di lint o integri il lint in CI, in un hook Git o in un editor.
