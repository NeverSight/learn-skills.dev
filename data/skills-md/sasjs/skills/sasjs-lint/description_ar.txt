تدقيق وتنسيق كود SAS باستخدام @sasjs/lint – قواعد .sasjslint وإعداداتها الافتراضية، مستوى الخطورة وأكواد الخروج، التجاوزات per-file لـ @sasjslint، ما الذي يُصلاحه المنسق، وكيفية تشغيله عبر SASjs CLI، ملحق VS Code وخادم SASjs. استخدمه عند تكوين قواعد التدقيق، حل تحذير تدقيق، أو ربط التدقيق بـ CI، خطاف Git أو محرر.
