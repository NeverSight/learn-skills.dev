Linter et formatage du code SAS avec @sasjs/lint - les règles .sasjslint et leurs valeurs par défaut, le niveau de gravité et les codes de sortie, les surcharges @sasjslint par fichier, ce que le formatteur corrige, et comment le CLI SASjs, l’extension VS Code et le serveur SASjs l’exécutent. À utiliser lors de la configuration des règles de lint, de la résolution d’un avertissement de lint, ou de l’intégration du lint dans le CI, un hook git ou un éditeur.
