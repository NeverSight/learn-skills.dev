Installation, chargement et déchargement des packages SAS avec le SAS Packages Framework (SPF) et l’archive SASPAC – les règles de fileref des packages, %installPackage / %loadPackage / %helpPackage / %unloadPackage, le verrouillage de version. À utiliser lors de l’installation d’un package tel que sasjscore, ou pour déboguer une installation qui renvoie rc=20006 ou un zip de package manquant.
