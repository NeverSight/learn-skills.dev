Revue adversariale d’une API ou d’une conception de package Go proposée avant son implémentation, en s’appuyant sur l’idiome des API Go et la conception pilotée par le domaine. Elle attaque les limites du package, la propriété des invariants et de l’état persistant, le cycle de vie et les états d’échec, ainsi que la forme des types exportés et des signatures, puis se termine par une ligne VERDICT lisible par machine. Utilisez‑la lorsqu’on vous demande d’examiner une conception, un plan, une proposition d’API, un plan de refactorisation ou une nouvelle disposition de type ou de package pour du code Go, ou lorsqu’un workflow indique de revoir la forme d’une API avant d’écrire le code, même si la demande se limite à « revoir ce plan » ou « cette API a‑t‑elle du sens ».
