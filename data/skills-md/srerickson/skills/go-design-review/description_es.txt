Revisión adversarial de un diseño propuesto de API o paquete de Go antes de implementarlo, basándose en el uso idiomático de la API de Go y en el diseño guiado por el dominio. Ataca los límites del paquete, la propiedad de invariantes y del estado persistente, los ciclos de vida y los estados de falla, y la forma de los tipos y firmas exportados, y finaliza con una línea VERDICT legible por máquina. Utilízalo cuando se solicite revisar un diseño, plan, propuesta de API, plan de refactorización o nuevo esquema de tipos o paquetes para código Go, o cuando un flujo de trabajo indique revisar la forma de una API antes de escribir código, incluso si la petición solo dice “revisa este plan” o “¿tiene sentido esta API?”.
