React Native TV UI best practices for tvOS, Android TV, Fire TV, and Vega OS (covers react-native-tvos and @amazon-devices/react-native-kepler). Utilícelo al revisar o crear la interfaz de usuario de TV: gestión de enfoque (TVFocusGuideView, hasTVPreferredFocus, trapFocus, FocusManager, Navigable, useTVEventHandler), navegación D-pad / RCU, carriles de navegación, banderas de héroe, cajones, pestañas, modales, zonas de sobreescaneo/seguridad, tipografía y contraste de TV, HDR y entrada de texto o voz a distancia.
