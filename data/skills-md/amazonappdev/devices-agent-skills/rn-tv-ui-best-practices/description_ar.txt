أفضل ممارسات واجهة مستخدم التلفزيون في React Native لأنظمة tvOS و Android TV و Fire TV و Vega OS (تشمل react-native-tvos و @amazon-devices/react-native-kepler). استخدمها عند مراجعة أو بناء واجهة تلفزيون — إدارة التركيز (TVFocusGuideView، hasTVPreferredFocus، trapFocus، FocusManager، Navigable، useTVEventHandler)، تنقل D‑pad / RCU، مسارات السباحة، بانرات البطل، الأدراج، علامات التبويب، النوافذ المنبثقة، مناطق الفائض/المناطق الآمنة، الطباعة التلفزيونية والتباين، HDR، وإدخال النص أو الصوت عبر جهاز التحكم عن بُعد.
