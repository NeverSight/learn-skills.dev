Лучшие практики UI для телевизоров на React Native для tvOS, Android TV, Fire TV и Vega OS (охватывает react-native-tvos и @amazon-devices/react-native-kepler). Используйте при проверке или создании TV UI — управление фокусом (TVFocusGuideView, hasTVPreferredFocus, trapFocus, FocusManager, Navigable, useTVEventHandler), навигация с D‑pad / RCU, swimlanes, главные баннеры, выдвижные меню, вкладки, модальные окна, зоны оверскана/безопасные зоны, типография и контраст TV, HDR и ввод текста или голоса с пульта.
