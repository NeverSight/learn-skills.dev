اكتب، وتحقق من صحة وصياغة الأوامر لـ Z-Image Turbo (Z Image Turbo 1.0، "ZIT") من Tongyi-MAI (Alibaba)، بالإنجليزية أو الصينية، ثم قدّم الإعدادات المناسبة لـ Draw Things، Diffusers، ComfyUI أو مساحة Hugging Face الرسمية. استخدم هذه المهارة كلما ذكر المستخدم Z-Image أو Z Image Turbo أو ZIT أو Tongyi-MAI أو نموذج الصور الخاص بـ Tongyi، أو أراد أمر صورة لذلك، حتى لو لم يذكر كلمة "prompt". تشمل القواعد الرسمية لمُحسّن الأوامر، وعرض النص داخل علامات الاقتباس، والأوامر الثنائية اللغة، نافذة 512 رمزًا، الدقات الرسمية، إعدادات العينة والتكرار.
