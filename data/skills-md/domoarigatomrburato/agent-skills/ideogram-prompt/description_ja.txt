Ideogram 4（Ideogram 4.0 / V_4_0）用のプロンプトを作成、検証、提供します。2つのモードで対応します：構造化されたJSONキャプション（マジックプロンプトオフ、テキスト、パレット、レイアウトを正確に制御）またはプレーンテキスト（マジックプロンプトオン、探索的）。ブリーフに合わせてモードを選択し、判断できない場合は質問します。ユーザーが Ideogram に言及したり、ポスター、ロゴ、チラシ、ソーシャルカード、サムネイル、カバー、パッケージ、ラベル、メニュー、プロダクトショット、タイポグラフィ作品、または Ideogram MCP、REST API、Web アプリ、オープンウェイトを通じて作成したい画像を希望したり、「JSON prompt」「v4 caption」「magic prompt」「バウンディングボックス」「HEX カラーパレット制御」や透過背景アセットを求めたり、Ideogram の JSON キャプションを貼り付けて修正・検証したり、参照画像（describe_image）から抽出したスタイルレシピを新しい対象に適用したりする場合に使用します。Ideogram MCP が接続されているときは、「Ideagram で画像を作って」や「ロゴを生成して」などの指示でもトリガーします。

常にユーザーの言語で回答してください。
