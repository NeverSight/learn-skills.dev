Scrivi, valida e consegna prompt per Ideogram 4 (Ideogram 4.0 / V_4_0) in due modalità: didascalia JSON strutturata (magic prompt disattivato, controllo preciso su testo, palette e layout) o testo semplice (magic prompt attivato, esplorativo). Sceglie la modalità per il brief, oppure chiede quando non è sicuro. Usa questa regola ogni volta che l'utente menziona Ideogram, desidera un poster, logo, volantino, scheda social, miniatura, copertina, confezione, etichetta, menù, foto di prodotto, elemento tipografico o qualsiasi immagine creata tramite l'Ideogram MCP, REST API, web app o pesi aperti; richiede un "prompt JSON", "didascalia v4", "magic prompt", box di delimitazione, controllo della palette di colori esadecimali o un asset con sfondo trasparente; incolla una didascalia JSON di Ideogram da correggere o convalidare; o vuole una ricetta di stile estratta da immagini di riferimento (describe_image) e applicata a nuovi soggetti. Attiva anche per "fammi un'immagine con Ideogram" o "genera un logo" quando l'Ideogram MCP è collegato.

Rispondi sempre nella lingua dell'utente.
