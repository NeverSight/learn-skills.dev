撰寫、驗證並交付 Ideogram 4（Ideogram 4.0 / V_4_0）的提示，分為兩種模式：結構化 JSON 說明（關閉魔法提示，對文字、調色板與版面進行精確控制）或純文字（開啟魔法提示，探索式）。  
根據簡報自動選擇模式，若不確定則詢問。  
只要使用者提及 Ideogram、需要海報、標誌、傳單、社交卡片、縮圖、封面、包裝、標籤、菜單、商品攝影、排版作品，或任何透過 Ideogram MCP、REST API、Web App 或開放權重製作的圖像；要求「JSON 提示」(JSON prompt)、「v4 說明」(v4 caption)、「魔法提示」(magic prompt)、邊框框選、十六進位色彩調色板控制或透明背景資產；貼上 Ideogram JSON 說明以進行修正或驗證；或想取得從參考圖像 (describe_image) 擷取的風格配方並套用於新主題時，都使用此規則。  
即使是「幫我用 Ideogram 產生圖像」或「生成標誌」等語句，只要 Ideogram MCP 已連線，也會觸發此規則。  
請始終以使用者的語言回覆。
