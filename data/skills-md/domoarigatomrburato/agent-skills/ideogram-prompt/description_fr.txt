Rédigez, validez et livrez des invites pour Ideogram 4 (Ideogram 4.0 / V_4_0) selon deux modes : légende JSON structurée (magie d’invite désactivée, contrôle exact du texte, de la palette et de la mise en page) ou texte brut (magie d’invite activée, exploratoire). Choisissez le mode pour le brief, ou demandez en cas de doute. Utilisez ceci chaque fois que l’utilisateur mentionne Ideogram, souhaite une affiche, un logo, un flyer, une carte sociale, une vignette, une couverture, un emballage, une étiquette, un menu, une prise de produit, une pièce typographique ou toute image créée via l’Ideogram MCP, l’API REST, l’application web ou les poids ouverts ; demande un « JSON prompt », « v4 caption », « magic prompt », des boîtes de délimitation, le contrôle d’une palette de couleurs hex ou un actif à fond transparent ; colle une légende JSON Ideogram à corriger ou valider ; ou veut une recette de style extraite d’images de référence (describe_image) et appliquée à de nouveaux sujets. Déclenchez même pour « make me an image with Ideogram » ou « generate a logo » lorsque l’Ideogram MCP est connecté.

Veuillez toujours répondre dans la langue de l’utilisateur.
