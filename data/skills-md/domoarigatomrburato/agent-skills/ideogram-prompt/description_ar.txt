اكتب، تحقق وصِّد المطالبات لـ Ideogram 4 (Ideogram 4.0 / V_4_0) بطريقتين: توضيح JSON مُنظم (مع إيقاف “المحث السحري”، تحكم دقيق في النص، لوحة الألوان والتخطيط) أو نص عادي (مع تشغيل “المحث السحري”، استكشافي). يختار الوضع المناسب للملخص، أو يطلب التوضيح عندما يكون غير متأكد. استخدم هذا كلما ذكر المستخدم Ideogram، أو أراد بوستر، شعار، نشرة، بطاقة اجتماعية، صورة مصغرة، غلاف، تغليف، لافتة، قائمة طعام، لقطة منتج، قطعة طباعة أو أي صورة تُصنع عبر Ideogram MCP، REST API، التطبيق الويب أو الأوزان المفتوحة؛ أو طلب “مطالبة JSON”، “وصف v4”، “المحث السحري”، مربعات الحد (bounding boxes)، التحكم في لوحة ألوان سداسية (hex) أو أصل بخلفية شفافة؛ أو ألصق وصف JSON لـ Ideogram لتصحيح أو التحقق؛ أو أراد وصفًا أسلوبيًا مستخرجًا من صور مرجعية (describe_image) وتطبيقه على مواضيع جديدة. فعِّل ذلك حتى عند قول “اصنع لي صورة بـ Ideogram” أو “أنشئ شعارًا” عندما يكون Ideogram MCP متصلاً.
