Rendez les invites via le serveur API (gRPC) de l'application Draw Things depuis le terminal au lieu de les coller dans l'application. Choisissez une recette de modèle (Krea 2 Turbo, Ideogram 4 et Qwen Image 2512 via le calcul cloud Draw Things+, ou tout modèle que l'application possède localement), exécutez un jeu de graines une tâche à la fois, survivez au cloud instable (reprises, détection de blocage, reprise) tout en restant facile à arrêter, enregistrez des PNG avec l’invite exacte, un journal d’exécution et une planche‑contact, puis examinez les résultats. Utilisez cette compétence chaque fois que l’utilisateur veut générer, rendre, batcher, réessayer, comparer des graines ou consigner des expériences d’image avec Draw Things, mentionne son serveur API, gRPC, le mode Bridge ou le calcul cloud, ou demande à exécuter une invite Krea ou Ideogram « dans Draw Things », même s’il dit simplement « render it » ou « try a few seeds ».
