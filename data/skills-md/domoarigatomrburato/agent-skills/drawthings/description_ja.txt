ターミナルから Draw Things アプリの API サーバー（gRPC）を介してプロンプトをレンダリングし、アプリに貼り付ける代わりに実行します。モデルレシピ（Krea 2 Turbo、Ideogram 4、Draw Things+ のクラウドコンピュートを利用した Qwen Image 2512、またはローカルにある任意のモデル）を選択し、シードセットを1件ずつ実行し、クラウドの不安定さ（再試行、スタック検出、再開）に耐えつつ、停止しやすく、正確なプロンプトと実行ログ、コンタクトシートを付けた PNG を保存し、結果を確認します。ユーザーが Draw Things で生成、レンダリング、バッチ処理、リトライ、シード比較、画像実験のログ記録をしたいとき、API サーバー、gRPC、Bridge Mode、またはクラウドコンピュートを言及したとき、あるいは「Draw Things で Krea や Ideogram のプロンプトを実行して」と要求したとき、たとえ「レンダーして」や「シードをいくつか試して」だけでも、このスキルを常に使用してください。
