Esegui il rendering dei prompt tramite il server API (gRPC) dell’app Draw Things dal terminale, invece di incollarli nell’app.  
Sceglie una ricetta di modello (Krea 2 Turbo, Ideogram 4 e Qwen Image 2512 tramite il cloud compute di Draw Things+, o qualsiasi modello disponibile localmente nell’app), esegue un set di semi un lavoro alla volta, sopravvive al cloud instabile (ritenti, rilevamento di blocchi, ripresa) mantenendo la facilità di arresto, salva PNG con il prompt esatto, un registro di esecuzione e una scheda di contatto, e osserva i risultati.  
Usa questa capacità ogni volta che l’utente desidera generare, fare il rendering, eseguire batch, riprovare, confrontare i semi o registrare esperimenti di immagini con Draw Things, menziona il suo server API, gRPC, Bridge Mode o cloud compute, o chiede di eseguire un prompt Krea o Ideogram “in Draw Things”, anche se dice solo “renderizzalo” o “prova alcuni semi”.  
Per favore rispondi sempre nella lingua dell’utente.
