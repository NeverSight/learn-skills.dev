從終端機透過 Draw Things 應用程式的 API 伺服器（gRPC）渲染提示，而不是把它們貼到應用程式中。選擇模型配方（Krea 2 Turbo、Ideogram 4 以及 Qwen Image 2512 透過 Draw Things+ 雲端運算，或任何應用程式本機擁有的模型），一次執行一個種子集的工作，能在不穩定的雲端環境中生存（重試、卡頓偵測、恢復），同時保持易於停止，將 PNG 檔案與完整提示、執行記錄與聯絡表一起保存，並檢視結果。每當使用者想要生成、渲染、批次、重試、比較種子或記錄圖像實驗，提到其 API 伺服器、gRPC、Bridge Mode 或雲端運算，或要求在 Draw Things 中執行 Krea 或 Ideogram 提示時，都請使用此技巧，即使他們只說「渲染它」或「試試幾個種子」也一樣。
