قم بإنشاء الأوامر عبر خادم API لتطبيق Draw Things (gRPC) من الطرفية بدلاً من لصقها في التطبيق. اختر وصفة نموذج (Krea 2 Turbo أو Ideogram 4 أو Qwen Image 2512 عبر الحوسبة السحابية لـ Draw Things+، أو أي نموذج يمتلكه التطبيق محليًا)، نفّذ مجموعة البذور وظيفة واحدة في كل مرة، وتجاوز مشاكل السحابة غير المستقرة (إعادة المحاولة، اكتشاف التوقف، الاستئناف) مع الحفاظ على سهولة الإيقاف، احفظ ملفات PNG مع النص الأصلي، سجل تشغيل، ورقة تجميع، وتفحص النتائج. استخدم هذه المهارة كلما أراد المستخدم إنشاء، عرض، تجميع، إعادة محاولة، مقارنة البذور أو تسجيل تجارب الصور باستخدام Draw Things، أو ذكر خادم API الخاص به، gRPC، وضع الجسر أو الحوسبة السحابية، أو طلب تشغيل أمر Krea أو Ideogram "في Draw Things"، حتى وإن قال فقط "اعرضه" أو "جرب عدة بذور".
