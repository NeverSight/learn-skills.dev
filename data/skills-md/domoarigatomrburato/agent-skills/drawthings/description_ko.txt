터미널에서 Draw Things 앱의 API 서버(gRPC)를 통해 프롬프트를 렌더링하고, 앱에 붙여넣는 대신 사용합니다. 모델 레시피(Krea 2 Turbo, Ideogram 4, Qwen Image 2512 등을 Draw Things+ 클라우드 컴퓨팅을 통해 사용하거나, 앱에 로컬로 있는 어떤 모델이든) 중 하나를 선택하고, 시드 셋을 한 번에 하나씩 작업으로 실행합니다. 불안정한 클라우드 환경에서도(재시도, 멈춤 감지, 재개) 견고하게 동작하면서 중지하기도 쉽고, 정확한 프롬프트와 실행 로그, 연락처 시트를 포함한 PNG 파일을 저장한 뒤 결과를 확인합니다. 사용자가 Draw Things로 이미지 생성, 렌더링, 배치, 재시도, 시드 비교 또는 실험 로그를 원하거나, API 서버, gRPC, Bridge Mode, 클라우드 컴퓨팅을 언급하거나, Krea 또는 Ideogram 프롬프트를 “Draw Things에서” 실행해 달라고 요청할 때마다 이 기능을 사용하세요. 사용자가 단순히 “렌더링해줘” 또는 “시드를 몇 개 시도해봐” 라고 말해도 마찬가지입니다.
