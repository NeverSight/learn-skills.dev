Use an external agent to autonomously create OpenMAIC courseware based on the original material and package it into a .maic.zip that can be directly imported. This applies to requests such as “Help me make courseware/slides/interactive lessons about X,” “Turn this material into a lesson,” “Generate MAIC courseware,” “Create a .maic.zip.” All content is personally written by the agent from the user‑uploaded original material, without invoking OpenMAIC’s internal generation pipeline; the layout reuses the upstream “clone existing pages, only change text” mechanism, and the structure is controlled by the upstream JSON Schema. It does not cover pure chat, requests for only PPTX files, or questions that only ask about how to use OpenMAIC.
