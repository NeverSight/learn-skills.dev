Usa un agente esterno per creare autonomamente materiale didattico OpenMAIC basato sul materiale originale e impacchettarlo in un file .maic.zip che può essere importato direttamente. Ciò si applica a richieste come “Aiutami a creare materiale didattico/slides/lezioni interattive su X”, “Trasforma questo materiale in una lezione”, “Genera corso MAIC”, “Crea un .maic.zip”. Tutto il contenuto è scritto personalmente dall’agente a partire dal materiale originale caricato dall’utente, senza invocare la pipeline di generazione interna di OpenMAIC; il layout riutilizza il meccanismo “clona le pagine esistenti, cambia solo il testo”, e la struttura è controllata dallo schema JSON a monte. Non copre la pura chat, le richieste di soli file PPTX o le domande che chiedono solo come usare OpenMAIC.
