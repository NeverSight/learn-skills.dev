Подготовьте и запустите закреплённый рабочий процесс согласованности Qwen Image Edit через локальный ComfyUI с одной или двумя референтными изображениями, точным запросом редактирования, детерминированными копиями рабочего процесса, проверкой зависимостей, мониторингом и извлечением результатов. Используйте только когда пользователь явно вызывает `$qwen-image-edit` или `$qwen-image-edit help`; никогда не вызывайте этот навык неявно для обычных запросов по редактированию изображений. Пожалуйста, всегда отвечайте на языке пользователя.
