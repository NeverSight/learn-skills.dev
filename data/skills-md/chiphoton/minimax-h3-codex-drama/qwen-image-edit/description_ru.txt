Подготовьте и запустите закреплённый workflow согласованности Qwen Image Edit через локальный ComfyUI с одним или двумя эталонными изображениями, точным запросом редактирования, детерминированными копиями workflow, проверкой зависимостей, мониторингом и получением результата. Используйте только когда пользователь явно вызывает `$qwen-image-edit` или `$qwen-image-edit help`; никогда не вызывайте эту функцию автоматически для обычных запросов по редактированию изображений.

Пожалуйста, всегда отвечайте на языке пользователя.
