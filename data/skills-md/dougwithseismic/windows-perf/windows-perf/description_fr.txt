Optimisez Windows 11 pour la performance, la confidentialité et la productivité des développeurs. Utilisez cette compétence chaque fois que l’utilisateur veut accélérer Windows, supprimer les bloatwares, désencombrer sa machine, ajuster Windows pour le développement, nettoyer les applications inutiles, optimiser les réglages GPU/réseau/mémoire, désactiver la télémétrie, ou de façon générale rendre son ordinateur Windows plus rapide. Déclenchez également cette compétence lorsque les utilisateurs mentionnent des builds lents, du bloat Windows, l’optimisation du démarrage, ou tout ce qui concerne rendre Windows moins agaçant. Même s’ils disent simplement « mon PC est lent » ou « nettoyez cette machine » sur un système Windows — cette compétence s’applique.
