Оптимизировать Windows 11 для производительности, конфиденциальности и продуктивности разработчиков. Используйте этот навык каждый раз, когда пользователь хочет ускорить Windows, удалить предустановленное ПО, очистить свою систему, настроить Windows для разработки, избавиться от ненужных приложений, оптимизировать настройки GPU/сети/памяти, отключить телеметрию или просто сделать свою машину на Windows быстрее. Также активировать, когда пользователи упоминают медленные сборки, “bloat” в Windows, оптимизацию запуска или любые темы, связанные с уменьшением раздражения от Windows. Даже если они просто говорят «мой ПК работает медленно» или «очистите эту машину», на системе Windows — этот навык применим.

Пожалуйста, всегда отвечайте на языке пользователя.
