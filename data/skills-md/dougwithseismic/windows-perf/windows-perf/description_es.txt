Optimizar Windows 11 para rendimiento, privacidad y productividad del desarrollador. Usa esta habilidad siempre que el usuario quiera acelerar Windows, eliminar bloatware, desbloatear su máquina, ajustar Windows para desarrollo, limpiar aplicaciones basura, optimizar la configuración de GPU/red/memoria, desactivar la telemetría o, en general, hacer su equipo Windows más rápido. También se activa cuando los usuarios mencionan compilaciones lentas, exceso de bloat en Windows, optimización del inicio o cualquier cosa relacionada con hacer Windows menos molesto. Incluso si solo dicen “mi PC se siente lenta” o “limpia esta máquina” en un sistema Windows, esta habilidad se aplica.

Por favor, responde siempre en el idioma del usuario.
