Эту задачу следует использовать, когда пользователь хочет превратить статическое изображение — скриншот, мокап, концептуальный рендер или дизайн‑комп — в реальный, редактируемый файл Figma с правильными слоями, фреймами авто‑лейаута, редактируемым текстом и настоящими векторными логотипами (а не вставленным битмапом). Активируется по запросам «image to Figma», «screenshot to Figma», «turn this mockup into Figma», «make this PNG a real design» или при указании на файл .png/.jpg с просьбой создать версию для Figma. Также охватывает обратный процесс — чтение фрейма Figma через сервер Figma MCP для генерации кода.
