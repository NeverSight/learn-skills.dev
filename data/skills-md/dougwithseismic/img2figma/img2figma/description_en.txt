This skill should be used when the user wants to turn a static image — a screenshot, mockup, concept render or design comp — into a real, editable Figma file with proper layers, auto-layout frames, editable text and true vector logos (not a pasted bitmap). Triggers on "image to Figma", "screenshot to Figma", "turn this mockup into Figma", "make this PNG a real design", or pointing at a .png/.jpg and asking for a Figma version. Also covers the reverse leg — reading a Figma frame back out via the Figma MCP server to build code from it.
