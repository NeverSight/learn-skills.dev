Starten und liefern Sie Vorgänge mit manueller Genehmigung, Anordnung von Arbeitsbäumen, Entwicklung, unabhängiger Abnahme und Nacharbeit innerhalb eines Gates. Benutzer verwalten die Arbeit mithilfe eines Backlogs, eines Vorgangs oder eines Gates oder nutzen es beim Umgang mit Merges, Pushes, Pull Requests und dem Schließen dieses Vorgangs/Gates; reguläre Änderungen, Merges oder Pushes werden gemäß den Projektregeln behandelt. Nachdem der Benutzer Agent B bezeichnet und das aktuelle Gate gestartet hat, wird automatisch zum finalen Integrationsdurchlauf oder zu einer Stopp‑Bedingung übergegangen.
