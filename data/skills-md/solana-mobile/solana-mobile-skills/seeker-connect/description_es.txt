Conecta una dapp web al monedero integrado del dispositivo Seeker con Seeker Connect. Úsalo al agregar conexión de monedero, iniciar sesión con Solana, firmar mensajes o transacciones en un sitio web que se ejecuta en el navegador de un teléfono Seeker, registrar el monedero Wallet Standard “Seeker Connect”, elegir el relé Nostr para relayDomain, usar el elemento seeker-connect-button o depurar códigos de SeekerConnectError como association-failed.
