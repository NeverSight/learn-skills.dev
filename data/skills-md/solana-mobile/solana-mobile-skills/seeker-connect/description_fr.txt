Connectez une application Web au portefeuille intégré de l'appareil Seeker avec Seeker Connect. À utiliser lors de l'ajout d'une connexion de portefeuille, d'une connexion avec Solana, d'une signature de message ou d'une signature de transaction à un site Web qui s'exécute dans le navigateur sur un téléphone Seeker, de l'enregistrement du portefeuille standard « Seeker Connect », du choix du relais Nostr pour relayDomain, de l'utilisation de l'élément seeker-connect-button ou du débogage des codes SeekerConnectError comme l'association a échoué.
