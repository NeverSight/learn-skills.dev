Verbinden Sie mit Seeker Connect eine Web-DApp mit der integrierten Wallet des Seeker-Geräts. Verwenden Sie diese Option, wenn Sie eine Wallet-Verbindung hinzufügen, sich bei Solana anmelden, Nachrichten signieren oder Transaktionen auf einer Website signieren, die im Browser auf einem Seeker-Telefon ausgeführt wird, die Wallet-Standard-Wallet „Seeker Connect“ registrieren, das Nostr-Relay für RelayDomain auswählen, das Element seeker-connect-button verwenden oder SeekerConnectError-Codes wie „Assoziation fehlgeschlagen“ debuggen.
