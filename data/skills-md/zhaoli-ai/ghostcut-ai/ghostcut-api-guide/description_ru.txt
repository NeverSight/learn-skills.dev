Навык руководства по API GhostCut разработан для сценариев видеоперевода, расширения контента за рубежом и мультимедийной локализации, помогая AI‑агентам использовать GhostCut для извлечения субтитров, их удаления, перевода и дубляжа, обработки фоновой музыки, пакетного синтеза и сжатия субтитров. Он также охватывает перевод изображений, удаление текста с изображений и другие возможности обработки изображений. Работает на базе GhostCut.
