Générez un rapport de recherche d’actions détaillé Achat/Vente/Conserver pour le marché boursier indien (entreprises cotées sur le NSE/BSE). Utilisez cette compétence chaque fois que l’utilisateur demande une analyse d’action, une recherche d’actions, une recommandation d’investissement, un prix cible, une analyse fondamentale, une analyse technique ou une opinion d’achat/vente/conservation sur n’importe quelle société ou action indienne. Déclencheurs sur des expressions telles que « analyse [action] », « devrais‑je acheter [action] », « rapport de recherche pour [entreprise] », « prix cible pour [action] », « [action] est‑elle un bon achat », « analyse d’action NSE/BSE », etc. Utilisez toujours cette compétence pour toute demande de recherche d’actions indienne — même si l’utilisateur ne fait que nommer un symbole boursier ou une entreprise et demande « qu’en pensez‑vous ? ».

Veuillez toujours répondre dans la langue de l’utilisateur.
