Расширяет ежемесячное включённое использование Cursor (пул моделей Cursor и другие пулы моделей) и расходы по требованию, сохраняя качество вывода. Используйте, когда пользователь исчерпывает использование Cursor, видит высокие расходы по требованию, спрашивает, когда использовать Auto, Composer, Max Mode или передовую модель, или запрашивает аудит .cursor/rules, .cursorrules, AGENTS.md, .cursorignore или серверов MCP для повышения эффективности. Триггеры включают «usage limit», «included usage», «on-demand», «Max Mode», «token saving», «reduce cost», «context limit», «使用量», «トークン節約», «節約», «月間制限», «上限», «従量課金».
