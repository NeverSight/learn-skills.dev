Étire l’utilisation mensuelle incluse de Cursor (pool de modèles Cursor et autre pool de modèles) ainsi que les dépenses à la demande tout en maintenant la qualité de sortie. À utiliser lorsque l’utilisateur épuise son utilisation de Cursor, constate des frais élevés à la demande, demande quand utiliser Auto, Composer, Max Mode ou un modèle de pointe, ou demande d’auditer .cursor/rules, .cursorrules, AGENTS.md, .cursorignore ou les serveurs MCP pour l’efficacité. Les déclencheurs incluent « limite d’utilisation », « utilisation incluse », « à la demande », « Max Mode », « économie de tokens », « réduire les coûts », « limite de contexte », « 使用量 », « トークン節約 », « 節約 », « 月間制限 », « 上限 », « 従量課金 ».
