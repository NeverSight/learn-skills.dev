حافظ على ذاكرة مشروع التطوير والبحث الاستكشافي، وسجلات التجارب، والحالة (ذاكرة المشروع، توضيحات البحث، السكريبتات، سجلات التجارب، نتائج التجارب، الحالة الحالية، والاتجاهات المستقبلية) تحت ./tmp/ في جذر المشروع. استخدم ذلك عندما يرغب المستخدم في “تسجيل شيء / ملاحظة هذا الاستنتاج / الحفاظ على حالة المشروع / التقدم الحالي / الخطوة التالية / سجل البحث / سجل التجربة / بدء تجربة / تسجيل نتائج التجربة / تنظيم ملاحظات الاستكشاف / لا تضع هذه في الوثائق بعد”، أو يذكر ذاكرة المشروع أو اليومية أو تشغيل التجربة. حافظ على ذاكرة المشروع، ملاحظات البحث، سجلات التجارب والحالة الحالية تحت ./tmp/.
