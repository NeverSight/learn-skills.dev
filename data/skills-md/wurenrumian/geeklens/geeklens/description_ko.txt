geekLens — 실제 소스 코드의 특정 부분(특정 기능, 특정 변경, 혹은 데이터 흐름·콜 체인)에 대한 깔끔한 “읽기 버전” 주석을 만든다: 순차적 읽기를 방해하는 디버깅, 계측, 그리고 죽은 코드를 제거하고 핵심 로직만 남기며, 라인‑별 주석을 추가하고, 전후 비교, 데이터 구조 매뉴얼, 교차 링크된 README를 제공한다; 읽기용 복사본에서만 작업하고 실제 소스는 절대 수정하지 않는다. 사용자가 코드 주석, 라인‑별 설명, 함수·콜 체인에 대한 면밀한 읽기, 필드나 동기화 관계 설명, 혹은 읽기 버전 정리를 요청할 때마다 활용한다; 일단 트리거되면 차분한 설명 프로토콜을 적용해야 하지만, 소스 사실과 추론을 혼합해서는 안 된다. 실제 코드의 집중된 조각에 대해 깔끔하고 소스‑충실한 주석이 달린 읽기용 버전을 생성하라 — 차분하고 단계별 설명, 전후 비교, 데이터 구조 참고 자료와 함께 — 실제 소스는 수정하지 않는다.
