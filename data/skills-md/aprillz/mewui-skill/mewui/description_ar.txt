إنشاء أو توسيع أو تصحيح أو معاينة أو نشر تطبيقات MewUI كاملة من حزم NuGet العامة باستخدام الترميز السلس للغة C#. استخدمه لإعداد المشروع، وعروض النوافذ وعناصر التحكم، ودورة الحياة بدون نافذة، وإعادة التحميل السريع، والعناصر، والتخطيط، والحالة ذات النوع المحدد وربطها، والمجموعات، والتنقل، والسمات، والحوار، والموارد، وعناصر التحكم المخصصة، وأنظمة عرض الخلفية، وNativeAOT. لا تستخدمه لأعمال تنفيذ إطار MewUI أو لأطر UI .NET غير ذات صلة.
