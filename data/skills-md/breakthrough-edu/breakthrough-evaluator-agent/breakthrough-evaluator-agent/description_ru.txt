Отправьте независимого судью, который не является автором: свежий субагент‑оценщик, проверяющий готовую работу по критериям прохождения, записанным до её создания (режим оценивания), либо аудиторующий партию относительно её источника истины (режим аудита), предоставляя доказательства для каждого вердикта и никогда не делая исправления. Используйте, когда владелец просит оценщика, рецензента, аудитора или судью, или говорит «отправьте судью», «оцените это», «проверьте мою работу свежим агентом», «получите второго агента для проверки», «аудировать эту папку», «аудировать мой реестр», «проверьте это против источника истины» или «LLM‑as‑judge». Работает только по запросу; не запускается самостоятельно в конце задачи. Не предназначено для проверок, которые может выполнить машина (тесты, проверка схем, поиск, который должен вернуть ноль), не для сотен одинаковых единиц и не для исправления чего‑либо.
