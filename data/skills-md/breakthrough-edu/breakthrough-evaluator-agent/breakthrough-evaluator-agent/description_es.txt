Envía un juez independiente que no sea el autor: un subagente evaluador nuevo que verifica el trabajo terminado contra los criterios de aprobación escritos antes de que se construyera (modo evaluador), o audita un lote contra su fuente de verdad (modo auditor), con evidencia para cada veredicto y nunca una corrección. Úsalo cuando el propietario pida un evaluador, revisor, auditor o juez, o diga “envía un juez”, “evalúa esto”, “revisa mi trabajo con un agente nuevo”, “obtén un segundo agente para revisar esto”, “audita esta carpeta”, “audita mi registro”, “verifica esto contra la fuente de verdad”, o “LLM-como-juez”. Se ejecuta solo cuando se solicita; no se activa por sí solo al final de una tarea. No es para verificaciones que una máquina pueda ejecutar (pruebas, validación de esquemas, una búsqueda que debe devolver cero), no es para cientos de unidades idénticas, y no es para arreglar nada.
