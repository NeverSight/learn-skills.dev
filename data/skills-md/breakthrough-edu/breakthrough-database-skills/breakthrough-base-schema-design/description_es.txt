Diseña una Base Lark para el negocio del usuario a través de una entrevista guiada: encuentra la única unidad de trabajo que el negocio repite, determina dónde nace cada tipo de registro (la propia Base o el software que ya utilizan, como contabilidad, un CRM, recursos humanos o una tienda online) y cómo fluye, luego deriva las tablas, enlaces y fórmulas a partir de los números que el propietario quiere ver. Termina con un Plano de Base, una prueba de aceptación y una Hoja de Plan; una sesión nueva sigue para construir la Base. Úsalo cuando el usuario quiera diseñar una base de datos o un hub de datos ("design my Lark Base", "what tables do I need", "帮我设计多维表格", "我的业务要怎么建表", "data hub", "把会计软件的资料打通进 Base", "哪个系统为准"), cuando una tabla gigante necesita reestructuración, o cuando no esté seguro de si algo es un campo, una selección o su propia tabla. NO la construcción en sí (una sesión nueva sigue a la Hoja de Plan), NO informes o paneles de control a partir de una base de datos llena (breakthrough-database-to-dashboard), NO un almacén de segunda mente (my-second-brain). Por favor, responde siempre en el idioma del usuario.
