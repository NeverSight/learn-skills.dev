Concevez un Lark Base pour l’entreprise de l’utilisateur à l’aide d’une interview guidée : identifiez l’unité de travail que l’entreprise répète, déterminez où chaque type d’enregistrement est créé (le Base lui‑même, ou les logiciels déjà utilisés tels que la comptabilité, un CRM, les RH ou une boutique en ligne) et le flux qu’il suit, puis dérivez les tables, les liens et les formules à partir des chiffres que le propriétaire veut voir. Le résultat se conclut par un Blueprint du Base, un test d’acceptation et une feuille de plan ; une nouvelle session suit pour construire le Base. À utiliser lorsque l’utilisateur veut qu’on conçoive une base de données ou un hub de données (« design my Lark Base », « what tables do I need », « 帮我设计多维表格 », « 我的业务要怎么建表 », « data hub », « 把会计软件的资料打通进 Base », « 哪个系统为准 »), lorsqu’une table géante nécessite une restructuration, ou en cas de doute sur la nature d’un élément (champ, liste déroulante ou table propre). PAS la construction elle‑même (une nouvelle session suit la feuille de plan), PAS les rapports ou tableaux de bord à partir d’une base remplie (breakthrough-database-to-dashboard), PAS un coffre‑fort de « second brain » (my‑second‑brain).

Veuillez toujours répondre dans la langue de l’utilisateur.
