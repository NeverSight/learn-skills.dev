Convierte los datos empresariales que el usuario ya tiene (Airtable, Notion, Google Sheets, Lark Base, Excel, exportaciones CSV o una base de datos que alguien le configuró) en tres cosas en una sola sesión: una descripción en lenguaje sencillo de lo que realmente registra su base de datos, una lista de hallazgos con problemas de datos y puntos ciegos, y un panel de una página que responda la pregunta financiera más urgente, con alertas clasificadas por el dinero en riesgo. Úsalo cuando el usuario quiera un panel o una lectura de sus datos (“build me a dashboard”, “turn my spreadsheet into a dashboard”, “what is my data telling me”, “帮我做仪表板”, “分析我的数据/表格”), pegue un enlace o suelte archivos de uno de esos productos y pregunte qué dicen los datos, o regrese con una exportación nueva para actualizar una página creada anteriormente. NO es para diseñar o reestructurar la base de datos en sí (eso es breakthrough‑base‑schema‑design), NO es para crear un segundo cerebro o vault, y NO es un panel en vivo que se actualice automáticamente: cada página es una instantánea de una exportación.
