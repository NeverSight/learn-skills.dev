사용자가 이미 가지고 있는 비즈니스 데이터(Airtable, Notion, Google Sheets, Lark Base, Excel, CSV 내보내기, 또는 누군가 한 번 설정해 둔 데이터베이스)를 한 번에 세 가지로 변환합니다: 데이터베이스가 실제로 기록하는 내용을 쉬운 언어로 설명한 것, 데이터 문제점 및 눈에 띄지 않는 부분을 나열한 보고서, 그리고 가장 시급한 금전적 질문에 답하는 한 페이지 대시보드(위험에 처한 금액 순으로 정렬된 알림 포함). 사용자가 대시보드나 데이터 분석을 원할 때(예: “대시보드 만들어줘”, “스프레드시트를 대시보드로 바꿔줘”, “내 데이터가 뭐라고 말하는지 알려줘”, “帮我做仪表板”, “分析我的数据/表格”) 해당 제품의 링크를 붙여넣거나 파일을 업로드하고 데이터가 무엇을 의미하는지 물어보거나, 이전에 만든 페이지를 새 내보내기로 갱신하고자 할 때 사용합니다. 데이터베이스 자체를 설계하거나 재구성하는 용도는 아닙니다(그것은 breakthrough‑base‑schema‑design). 두 번째 두뇌나 보관소를 설정하는 용도도 아니며, 실시간 자동 업데이트 대시보드도 아닙니다: 모든 페이지는 하나의 내보내기 데이터를 기반으로 한 스냅샷입니다.
