Úselo al crear o enviar un widget de mensaje de Telegram (burbuja HTML, HTMLBubbles, `sendWidget`, `messageMediaWidget`, API de bots 10.4): un programa interactivo de HTML, CSS y JS dentro de una burbuja de chat, como un juego, una encuesta, una calculadora o un ticker en tiempo real. Enseña todo lo necesario para crear uno: tamaño, burbuja, entrada, reglas del entorno aislado, estado y solicitudes, envío y en qué se diferencia la entrega en tiempo real de la documentación. No es para miniaplicaciones ni mensajes enriquecidos.
