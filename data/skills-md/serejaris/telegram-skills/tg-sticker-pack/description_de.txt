Verwenden Sie diese Option, wenn Sie statische Telegram-Sticker oder ein Sticker-Paket aus einem Meme-Frame, einem Foto oder einem Video erstellen: Schneiden Sie die Person aus, fügen Sie eine Bildunterschrift ein (WordArt, Impact, Label-Tags), überprüfen Sie das 512-px-PNG-/WEBP-Format offline und veröffentlichen Sie das Set über ein Benutzerkonto über @Stickers oder über einen Bot über createNewStickerSet/addStickerToSet.
