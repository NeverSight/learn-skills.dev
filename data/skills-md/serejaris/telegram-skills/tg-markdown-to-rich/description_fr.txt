À utiliser lors de la conversion de documents Markdown, de rapports ou de tout contenu textuel en message enrichi Telegram pour l'envoi via un bot. Déclencheurs : « envoyer du Markdown à Telegram », « convertir un document en message enrichi », « publier un rapport via le bot », « formater du Markdown pour sendRichMessage », « message enrichi Telegram à partir d’un fichier ». Génère un objet JSON InputRichMessage prêt pour la méthode sendRichMessage de l'API Telegram Bot 10.2, incluant file_id, URL et les liaisons multimédias pour le chargement multipart.
