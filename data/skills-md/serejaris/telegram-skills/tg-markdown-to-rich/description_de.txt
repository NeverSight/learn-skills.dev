Verwenden Sie diese Option, wenn Sie Markdown-Dokumente, Berichte oder beliebige Textinhalte in eine Telegram-Rich-Nachricht umwandeln, die über einen Bot gesendet werden soll. Trigger: „Markdown an Telegram senden“, „Dokument in Rich Message konvertieren“, „Bericht an Bot veröffentlichen“, „Markdown für sendRichMessage formatieren“, „Telegram-Rich-Message aus Datei“. Erzeugt ein InputRichMessage-JSON-Objekt, das für Telegram Bot API 10.2 sendRichMessage bereit ist, einschließlich file_id, URL und Bindungen für den Multipart-Upload von Medien.
