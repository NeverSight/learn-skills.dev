Markdownドキュメント、レポート、または任意のテキストコンテンツをTelegramリッチメッセージに変換して、ボットを介して配信する場合に使用します。トリガー：「MarkdownをTelegramに送信」、「ドキュメントをリッチメッセージに変換」、「レポートをボットに公開」、「sendRichMessage用のMarkdownをフォーマット」、「ファイルからTelegramリッチメッセージを作成」。Telegram Bot API 10.2のsendRichMessageに対応したInputRichMessage JSONオブジェクトを生成します。これには、file_id、URL、およびマルチパートアップロードメディアのバインディングが含まれます。
