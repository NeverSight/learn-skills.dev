Разработайте этап проектирования флюсового SDD/AgentSpec с использованием архива Markdown для Brainstorm, архива DEFINE и взаимодействия с техническими разъяснениями с обычными пользователями. Преобразование требований к проверке в архитектуре, компонентах, встроенных ADR, файловом манифесте, кодовых файлах, потоках данных, интеграции, стратегии тестирования, обработке ошибок, настройке, безопасности и наблюдении. Используйте SDD Define с помощью RDD, особенно когда вы используете BRAINSTORM_*.md и DEFINE_*.md, и вам нужно быстро включить DESIGN_*.md для SDD Build с помощью RDD.
