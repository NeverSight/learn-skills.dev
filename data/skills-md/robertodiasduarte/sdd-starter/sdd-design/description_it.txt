Elaborare la fase di progettazione di un flusso SDD/AgentSpec dal file Markdown di Brainstorm, dal file DEFINE e dalle interazioni di chiarimento tecnico con l'utente. Trasformare requisiti convalidati in architettura, componenti, ADR in linea, file manifest, codici di codice, flusso di dati, integrazioni, strategia di test, trattamento degli errori, configurazione, sicurezza e osservabilità. Usalo dopo SDD Define by RDD, soprattutto quando l'utente fornecer BRAINSTORM_*.md e DEFINE_*.md e vuoi generare subito DESIGN_*.md per SDD Build by RDD.
