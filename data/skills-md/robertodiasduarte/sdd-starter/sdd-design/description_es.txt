Elaborar a fase Diseño de un flujo SDD/AgentSpec a partir del archivo Markdown de Brainstorm, del archivo DEFINE y de interacciones de aclaración técnica con el usuario. Transformar requisitos validados en arquitectura, componentes, ADR inline, file manifest, padrões de código, fluxo de dados, integrações, estratégia de testes, tratamento de erros, configuração, segurança y observabilidade. Usar después de SDD Define by RDD, especialmente cuando el usuario fornecer BRAINSTORM_*.md y DEFINE_*.md y quiere generar un DESIGN_*.md pronto para SDD Build by RDD.
