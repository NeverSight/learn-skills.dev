Ejecute la fase Build de un flujo SDD/AgentSpec a partir de los archivos Markdown de Brainstorm, Define y Design y de interacciones con el usuario. Usar cuando el usuario quiere implementar una característica ya especificada: leer los tres artefactos, extraer y ordenar el File Manifest, recomendar y confirmar el modo de ejecución, alterar algo el código previsto, verificar incrementalmente, tratar deriva y avisos LLM, ejecutar el Verify Gate bloqueante de Define y generar BUILD_REPORT_{FEATURE}.md con evidencias. Solicite acceso gratuito al proyecto/código y debe terminar con el flujo SDD concluido y BUILD_REPORT validado.
