Brainstorm、Define、Design の Markdown ファイルとユーザーとのインタラクションから、SDD/AgentSpec フローの Build フェーズを実行します。ユーザーがすでに仕様化された機能を実装したい場合に使用します：3つのアーティファクトを読み込み、File Manifest を抽出して順序付け、実行モードを推奨・確認し、予定されたコードのみを変更し、インクリメンタルに検証し、ドリフトや LLM のプロンプトを処理し、Define の阻止的 Verify Gate を実行し、証拠とともに BUILD_REPORT_{FEATURE}.md を生成します。プロジェクト/コードへの書き込み権限が必要で、SDD フローが完了し BUILD_REPORT が検証された状態で終了しなければなりません。
