Wenn Sie den Benutzer verwenden, müssen Sie eine bestimmte Funktion implementieren: Alle drei Objekte anzeigen, das Dateimanifest extrahieren und bestellen, den Ausführungsmodus empfehlen und bestätigen, einen Moment oder den vorherigen Code ändern, inkrementell überprüfen, Drift und Eingabeaufforderungen in LLM ausführen, das Verify Gate ausführen, das durch Definieren blockiert wird, und erstellen BUILD_REPORT_{FEATURE}.md mit Beweisen. Fordern Sie den Zugriff auf das Projekt/den Code an und müssen Sie mit dem abgeschlossenen SDD-Flux und dem validierten BUILD_REPORT enden.
