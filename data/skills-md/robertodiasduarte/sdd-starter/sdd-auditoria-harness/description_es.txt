Audita de solo lectura el harness SDD de un repositorio para LIMPIEZA Y DERIVACIÓN: inventariará comandos, agentes, habilidades, hooks, configuraciones y scripts de CUALQUIER motor (Claude Code, Codex, Kimi CLI: lea CLAUDE.md y AGENTS.md, .claude/, .agents/ y .codex/), medirá referencias, recencia, duplicación y derivación entre docs y código, y generará un único informe AUDITORIA_SDD_<fecha>.md sin alterar nada. Invocar cuando alguien diga “el harness creció demasiado”, “qué aquí nadie usa”, “¿los docs aún coinciden con el código?”, o pida una limpieza del harness (`.claude/`, `.agents/` o `.codex/`). ⚠️ Frontera: esta skill pregunta QUÉ SOBRA Y QUÉ DERIVÓ (higiene). Para SEGURIDAD — easter egg, código malicioso, backdoor, exfiltración, unicode invisible en material de terceros que vas a instalar — usa la skill rdd-audita-harness. El exceso no es amenaza; ambas son de solo lectura y se complementan.
