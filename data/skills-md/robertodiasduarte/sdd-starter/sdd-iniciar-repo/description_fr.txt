Place le projet qui n’utilise pas encore git sur git et sur un GitHub privé, sans inclure les données client : vérifie le dossier (hors iCloud/OneDrive/Dropbox/Google Drive), liste ce qui entrerait dans git en signalant le mot de passe (.env), le certificat A1 (.pfx), la feuille de calcul et le gros fichier, propose le .gitignore, offre l’alarme de commit de sdd‑higiene‑dado avant le premier commit et ne commite et ne publie qu’avec l’accord explicite à chaque étape. S’adresse à ceux qui n’ont jamais utilisé git : une étape à la fois, avec ce qui a été fait, ce qui vient maintenant et les options de chaque décision. Reprend là où il s’était arrêté (git sans commit, commit sans GitHub, envoi qui a échoué). Utilise quand l’utilisateur dit « mettre sur git », « créer le dépôt », « pousser sur le GitHub », « ce projet n’a pas de git », ou lorsque sdd‑new‑session ou sdd‑checar‑ambiente indiquent que le projet n’utilise pas encore git. Ne supprime pas l’historique déjà diffusé, ne se connecte pas à GitHub pour l’utilisateur et n’automatise aucun autre hébergeur (GitLab, etc.), ne fournit que les commandes.
