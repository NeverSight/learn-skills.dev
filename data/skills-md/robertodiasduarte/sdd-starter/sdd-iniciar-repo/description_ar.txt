ضع المشروع على Git وفي GitHub خاص إذا كان لا يستخدم Git بعد، دون إحضار بيانات العميل: تحقق من المجلد (خارج iCloud/OneDrive/Dropbox/Google Drive)، أدرج ما سيُضاف إلى Git مع الإشارة إلى كلمة المرور (.env)، شهادة A1 (.pfx)، الجدول والملف الكبير، اقترح ملف ‎.gitignore، قدّم تنبيه الالتزام من sdd‑higiene‑dado قبل أول التزام ولا تقوم بالالتزام والنشر إلا بعد الحصول على موافقة صريحة في كل مرحلة. تحدّث مع من لم يستخدم Git من قبل: خطوة واحدة في كل مرة، مع ما تم إنجازه، ما سيأتي الآن وخيارات كل قرار. استأنف من حيث توقفت (Git بدون التزام، التزام بدون GitHub، رفع فشل). استخدم عندما يقول المستخدم “ضعه على Git”، “إنشاء المستودع”، “رفع إلى GitHub”، “هذا المشروع لا يملك Git”، أو عندما تقول sdd‑new‑session أو sdd‑checar‑ambiente إن المشروع لا يستخدم Git بعد. لا تمسح التاريخ الذي تسرب، لا تقوم بتسجيل الدخول إلى GitHub باسم المستخدم ولا تُ自动 أتمتة استضافة أخرى (GitLab إلخ)، فقط قدّم الأوامر.
