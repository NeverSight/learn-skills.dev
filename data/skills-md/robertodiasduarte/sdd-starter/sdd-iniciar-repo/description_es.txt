Habla con quien nunca ha usado git: una etapa a la vez, con lo que se hizo, lo que viene ahora y las opciones de cada decisión. Retoma desde donde quedó (git sin commit, commit sin GitHub, envío que falló). Usa cuando el usuario diga “pôr no git”, “criar o repositório”, “subir para o GitHub”, “este proyecto no tiene git”, o cuando sdd‑new‑session o sdd‑checar‑ambiente indiquen que el proyecto aún no usa git.
