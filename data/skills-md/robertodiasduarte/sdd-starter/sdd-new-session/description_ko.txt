이 리포지토리에서 격리된 작업 프론트를 엽니다: 프로젝트 폴더 밖에 git worktree를 생성하고, 원격의 최신 프로덕션 브랜치에서 파생된 새로운 브랜치를 사용합니다. 폴더(의존성, 로컬 파일)를 준비하고 편집기에서 엽니다. 처음에는 리포지토리를 조사하고 발견한 내용을 sdd/ambiente.md에 기록합니다. 사용자가 “abrir uma frente”, “nova sessão”, “nova tarefa isolada”, “criar worktree para X”라고 말하거나 진행 중인 다른 작업과 섞지 않고 기능/수정을 시작하고 싶을 때 사용합니다.
