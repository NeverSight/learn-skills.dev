Apri un fronte di lavoro isolato in questo repository: crea un git worktree fuori dalla cartella del progetto, con un nuovo branch nato dal branch di produzione AGGIORNATO del remoto, prepara la cartella (dipendenze, file locali) e aprila nell'editor. La prima volta, indaga il repository e registra ciò che hai scoperto in sdd/ambiente.md. Usa quando l'utente dice “aprire un fronte”, “nuova sessione”, “nuova attività isolata”, “creare worktree per X” o vuole avviare una feature/correzione senza mescolarla con un'altra in corso.
