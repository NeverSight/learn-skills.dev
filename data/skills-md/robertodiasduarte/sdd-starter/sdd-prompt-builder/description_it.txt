Genera, perfeziona e ottimizza prompt di produzione per LLM con contratto di output esplicito, criteri di completezza, gestione del contesto mancante e verifica concisa. Utilizzare quando l'utente richiede di creare o migliorare prompt destinati al runtime, o quando un flusso SDD design/build crea o modifica system prompt, passaggi di pipeline, classificatori, sintetizzatori, prompt su edge/worker/runtime, file **/prompts/**, system prompt inline o template in _shared. Non utilizzare per documentazione umana, prompt interni di orchestrazione SDD, email, notifiche o copy transazionale UI.
