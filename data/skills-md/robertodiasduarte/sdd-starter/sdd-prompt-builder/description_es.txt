Genera, refina y optimiza prompts de producción para LLMs con contrato de salida explícito, criterios de completitud, manejo de contexto ausente y verificación concisa. Usar cuando el usuario solicite crear o mejorar prompts destinados a runtime, o cuando un flujo SDD de diseño/construcción cree o modifique system prompts, pasos de pipeline, clasificadores, sintetizadores, prompts en edge/worker/runtime, archivos **/prompts/**, system prompts inline o plantillas en _shared. No usar para documentación humana, prompts internos de orquestación SDD, correos electrónicos, notificaciones o copy transaccional de UI.
