在得到使用电脑者的明确同意后，安装一个提交报警器（git 的 pre‑commit），当检测到有效校验位的 CPF 或 CNPJ、密码文件（.env）、带私钥的证书（.pfx、.p12、.pem）或新建的电子表格时拒绝提交，解释原因及如何修复，提及 git commit --no-verify 并说明如何卸载。用户希望在以下情形使用：保护仓库不让客户数据或 A1 证书进入 git、在准备办公室机器用于 SDD 工作时，或提交被此报警器拒绝时。此工具不适用于期限（不查询规范也不进行计算）。它不修复 git 历史，不撤销证书，不内部读取 .xlsx 表格，也不对 LGPD 或职业保密给出意见；如需在不安装任何东西的情况下诊断环境，请使用 sdd‑checar‑ambiente。

请始终使用用户的语言作答。
