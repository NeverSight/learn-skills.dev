Instala, con el consentimiento explícito del usuario del ordenador, una alarma de commit (pre‑commit de git) que rechaza el commit cuando encuentra CPF o CNPJ con dígito verificador válido, archivo de contraseñas (.env), certificado con clave privada (.pfx, .p12, .pem) o una hoja de cálculo nueva, explica por qué y cómo corregirlo, menciona git commit --no-verify y dice cómo desinstalarlo. Úsalo cuando el usuario quiera proteger el repositorio contra datos de cliente o certificado A1 que se envíen a git, al preparar la máquina de la oficina para trabajar con SDD, o cuando un commit sea rechazado por esta alarma. No se aplica a periodos (no consulta norma ni calcula). No arregla el historial de git, no revoca el certificado, no lee la hoja de cálculo .xlsx por dentro, no da parecer sobre la LGPD o el secreto profesional; para diagnosticar el entorno sin instalar nada, usa sdd-checar-ambiente.
