在得到使用電腦者的明確同意下，安裝一個提交警報（git 的 pre‑commit），當檢測到有效校驗位的 CPF 或 CNPJ、密碼檔案（.env）、帶有私鑰的證書（.pfx、.p12、.pem）或新建的試算表時，拒絕提交，並說明原因與修正方式，提及 git commit --no‑verify 並說明如何解除安裝。當使用者想保護倉庫不讓客戶資料或 A1 證書流入 git，或在辦公室的機器上準備使用 SDD，或當提交被此警報拒絕時使用。本功能不適用於期間（不查詢規範亦不計算）。不會修復 git 歷史、不會撤銷證書、不會內部讀取 .xlsx 試算表，也不會對 LGPD 或職業保密提供意見；若要在不安裝任何東西的情況下診斷環境，請使用 sdd‑checar‑ambiente。
