Installa, con il consenso esplicito di chi usa il computer, un allarme di commit (pre‑commit di git) che rifiuta il commit quando trova CPF o CNPJ con cifra di controllo valida, file di password (.env), certificato con chiave privata (.pfx, .p12, .pem) o nuovo foglio di calcolo, spiega il perché e come correggere, cita git commit --no‑verify e indica come disinstallare. Usalo quando l’utente vuole proteggere il repository da dati di cliente o certificato A1 che finiscano su git, durante la preparazione della macchina d’ufficio per lavorare con SDD, o quando un commit viene rifiutato da questo allarme. Non si applica a periodi (non consulta norme né calcola). Non ripara la cronologia di git, non revoca certificati, non legge internamente file .xlsx, non fornisce pareri su LGPD o riservatezza professionale; per diagnosticare l’ambiente senza installare nulla, usa sdd‑checar‑ambiente.
