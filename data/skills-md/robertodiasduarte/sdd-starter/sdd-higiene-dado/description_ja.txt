コンピュータを使用している人の明示的な許可を得て、CPF や CNPJ の有効な検証数字、パスワードファイル（.env）、プライベートキー付き証明書（.pfx、.p12、.pem）または新しいスプレッドシートが検出されたときにコミットを拒否するコミットアラーム（git の pre‑commit）をインストールし、なぜそうなるのか、どのように修正するかを説明し、git commit --no-verify を引用し、アンインストール方法を示す。ユーザーがクライアントデータや A1 証明書が git に流出するのを防ぎたいとき、オフィスのマシンを SDD 用に準備するとき、またはこのアラームによってコミットが拒否されたときに使用してください。期間には適用されません（規格を参照したり計算したりしません）。git の履歴を修正したり、証明書を失効させたり、.xlsx スプレッドシートの中身を読み取ったり、LGPD や職業上の機密保持に関して見解を示したりはしません。何もインストールせずに環境を診断したい場合は sdd‑checar‑ambiente を使用してください。
