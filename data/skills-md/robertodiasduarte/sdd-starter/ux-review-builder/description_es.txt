Conduce una entrevista progresiva, sin exigir vocabulario de UX o diseño, para crear o evolucionar el patrón canónico de UX de un proyecto de software y generar tres artefactos coordinados: UX_STANDARD.md, una skill ux‑review personalizada y UX_REVIEW_TEMPLATE.md. Úsalo cuando quieras definir look and feel, público, principios, design system, accesibilidad, responsividad, tono de voz, referencias, interacciones, criterios de calidad o gobernanza de UX antes de revisar funcionalidades. La ux‑review generada se convierte en la etapa del SDD entre Define y Design. No ejecuta la revisión de una funcionalidad en lugar de la skill generada.
