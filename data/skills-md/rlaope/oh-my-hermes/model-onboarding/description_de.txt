Integrieren Sie eine neue Modellgeneration oder ein Schwestermodell in oh-my-hermes: Prüfen Sie die Routererkennung, recherchieren Sie den offiziellen Vertrag, schreiben Sie die Kalibrierung von Merkmalen zu Zählern, platzieren Sie das Routing in beiden Spuren, kalkulieren Sie den Preis nur anhand der dokumentierten Liste, konfigurieren Sie die Gate-Maschine auf einer bedienten Route, testen Sie mit den Gates und schließen Sie mit einem Benchmark-Paar ab. Verwenden Sie dies, wenn eine Modellfamilie eine neue Generation auf den Markt bringt (zum Beispiel „Fable 5.1 ist verfügbar“, „GLM 5.4 wurde ausgeliefert“, „neues Modell integrieren“, „Modell zu Ketten hinzufügen“).
