Intégrer une nouvelle génération de modèle ou un modèle apparenté dans oh-my-hermes : tester la reconnaissance du routeur, étudier le contrat officiel, rédiger l’étalonnage caractéristique-compteur, placer le routage dans les deux voies, fixer le prix uniquement à partir de la liste documentée, configurer la machine de contrôle d’accès sur un itinéraire desservi, effectuer des tests avec les contrôles d’accès, conclure avec une paire de référence. À utiliser lorsqu'une famille de modèles lance une nouvelle génération (par exemple « Fable 5.1 est disponible », « GLM 5.4 a été lancé », « intégrer un nouveau modèle », « ajouter un modèle aux chaînes »).
