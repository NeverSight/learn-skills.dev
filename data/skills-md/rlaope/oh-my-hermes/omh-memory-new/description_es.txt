[omh] Dato del proyecto que hay que recordar en futuras sesiones: capturar un candidato a memoria de proyecto o producto delimitado y duradero mediante una revisión explícita de recordar, rechazar o aplazar; para una memoria Hermes existente, usar omh-memory-sync, y para una decisión pasada, usar omh_memory recall u «omh-decision-recall». Úselo cuando el usuario diga: memoria-nueva, nueva memoria, memoria del proyecto, memoria del producto, recordar este proyecto, recordar este producto, no guardar, no guardar este token.
