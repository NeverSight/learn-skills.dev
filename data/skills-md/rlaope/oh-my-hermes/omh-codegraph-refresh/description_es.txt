[omh] Índice de código o mapa de código desactualizado: actualiza la inteligencia de código local, resume la estructura del repositorio y prepara el contexto de transferencia del codegraph con alcance de tarea sin solicitar una ejecución excesiva. Úselo cuando el usuario diga: codegraph-refresh, codegraph refresh, refresh codegraph, update codegraph, codegraph stale, stale codegraph, codegraph handoff, codegraph summary.
