Diese Fähigkeit sollte verwendet werden, wenn der Benutzer ein Projekt, eine Funktion oder eine Fehlerbehebung unter Verwendung von Linear als Agentensteuerungsebene planen möchte. Verwenden Sie diese Option, wenn der Benutzer sagt: „In Linear planen“, „Linear-Tickets erstellen“, „In Aufgaben aufteilen“, „An Linear senden“, „Unser Board für diese Funktion einrichten“ oder eine Beschreibung oder Spezifikation in gut strukturierte, agentenbereite Linear-Probleme umwandeln möchte. Erfordert die Konfiguration des offiziellen Linear MCP-Servers.
