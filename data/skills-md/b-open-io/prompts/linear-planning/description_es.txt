Esta habilidad debe usarse cuando el usuario desea planificar un proyecto, característica o corrección de errores utilizando Linear como plano de control del agente. Úselo cuando el usuario diga "planificar esto en Linear", "crear tickets de Linear", "dividir esto en tareas", "enviar a Linear", "configurar nuestro tablero para esta función" o quiere convertir una descripción o especificación en problemas de Linear bien estructurados y listos para el agente. Requiere la configuración del servidor oficial Linear MCP.
