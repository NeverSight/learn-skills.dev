يجب استخدام هذه المهارة عندما يريد المستخدم التخطيط لمشروع أو ميزة أو إصلاح خطأ باستخدام Linear كمستوى تحكم للوكيل. يُستخدم عندما يقول المستخدم "تخطيط هذا بخط خطي"، أو "إنشاء تذاكر خطية"، أو "تقسيم هذا إلى مهام"، أو "اضغط إلى خطي"، أو "إعداد اللوحة الخاصة بنا لهذه الميزة"، أو عندما يريد تحويل وصف أو مواصفات إلى مشكلات خطية جيدة التنظيم وجاهزة للوكيل. يتطلب تكوين خادم Linear MCP الرسمي.
