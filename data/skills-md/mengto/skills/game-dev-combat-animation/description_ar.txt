قم بإنشاء وإصلاح ومراجعة رسومات القتال الخاصة بالشخصية (ضربات القتال القريب، إطلاق السهام، إلقاء التعاويذ، المهارات، هجمات الوحوش، مجموعات الحركات الكاملة) بحيث تبدو كأنها في ديابلو IV أو بالدرز جيت 3 أو إلدن رينغ ولا تُظهر أي تمدد أو قفل أو تشويه أو كسر في الذراع أو المعصم أو اليد. معيار مكتوب يتضمن قواعد مرقمة، اختبارات إطارٍ‑إطار على النموذج المشطّ بالجلد الحقيقي، مفاتيح مصممة من نوايا العضد العلوي، الساعد والنصل، فحوصات من كل كاميرا يراها اللاعب، نقّّانان أعمى بالإضافة إلى اختبار أ/ب أعمى مقابل الإصدار الأخير، وكل ادعاء من النقّاد يُتحقق منه مقابل الإطارات عالية الدقة وأرقام rig الحية. يُستخدم عند إنشاء أو إعادة صياغة أي هجوم أو مهارة أو مجموعة حركات؛ عندما يقول المستخدم إن الذراعين أو اليدين أو المعصمين أو المرفقين أو الأسلحة تبدو متمَددة أو غريبة أو مكسورة أو خاطئة؛ عندما يطلب معيارًا أو قواعد أو اختبارات للرسوميات؛ أو عندما يطلب تقييم الرسوميات أو الحصول على درجة N من عشرة.
