Construye, integra, audita o refactoriza monstruos riggeados para Three.js y juegos de acción web. Utilízalo para contratos de activos de monstruos, rigs de criaturas procedurales o importados, juntas y sockets semánticos, hurtboxes y volúmenes de ataque, estados de animación de combate, adaptadores de tiempo de ejecución de enemigos, LODs, fixtures de revisión determinista y para validar que cada monstruo siga un sistema compartido.
