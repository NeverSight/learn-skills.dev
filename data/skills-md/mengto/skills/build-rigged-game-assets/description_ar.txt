أنشئ أو دمج أو راجع شخصيات ثلاثية الأبعاد مُجهزة للإنتاج والوحوش المتحركة مع نموذج رئيسي، هيكل عظمي، مكتبة حركية، منافذ (sockets)، عقود تصادم، معدات شخصية منفصلة، ملفات تشغيل محسنة، وسائط كاتالوج، ومفتش تفاعلي لحركات الشخصية. استخدم ذلك عند إنشاء أو استيراد ممثلي اللعبة بصيغتي FBX/GLB؛ تحديد متطلبات أصول الشخصية مقابل الوحش؛ فصل السيوف، الدروع، الخوذ، الدروع أو العتاد المخزن؛ إضافة مقاطع الخمول، المشي، الجري، الهجوم، الضربة، التملص، الحجب، الإلقاء أو الموت؛ ربط الأصل بسير اللعبة؛ أو إضافة تحكمات الحركة والمعدات مع اختبارات حتمية إلى كاتالوج أصول اللعبة.
