Imballa un progetto locale completato in un repository GitHub intenzionale, crea un README robusto e un’anteprima visiva, effettua il push in modo sicuro, configura un URL pubblico di GitHub Pages quando il progetto è compatibile e verifica il risultato distribuito. Usa questa procedura quando un utente chiede di caricare, pubblicare, rendere open‑source, condividere o trasformare un esperimento locale HTML/CSS/JavaScript o un piccolo progetto web in un repository GitHub documentato con una demo live.
