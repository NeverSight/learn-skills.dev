أضف مؤشرات تحميل متحركة للذكاء الاصطناعي وحالة الوكيل قابلة للوصول باستخدام مكتبة React thinking-orbs. استخدمها عندما يحتاج الدردشة أو المساعد أو الصوت أو البحث أو التوليد أو واجهة تشغيل الأدوات إلى حالة معنوية مثل العمل أو البحث أو الحل أو الاستماع أو التأليف أو التشكيل؛ عند استبدال مؤشر التحميل العام بكرّة نشاط الذكاء الاصطناعي؛ أو عند تطبيق حجم المكتبة، السمة، السرعة، الإيقاف المؤقت، الحركة المخفضة، وسلوك اللوحة. يرجى دائمًا الرد بلغة المستخدم.
