أضف تأثير الفأرة Shaders WebGPU المستخدم في بطل Tidal Commons: أثر مؤشر نصف لون أبيض متلألئ يُدار بواسطة ChromaFlow، مغطى عبر DotGrid، ومُختتم بتموجات لونية وحبوب أفلام، ومحمي بأوضاع ثابتة، ولمس، وإمكانية وصول، وSSR، واستخدامات احتياطية للأداء. استخدمه عندما يطلب المستخدم هذا التأثير الفأري للظلّات، أو أثر مؤشر نصف لون، أو خلفية ويبGPU تفاعلية للبطل/الاتصال، أو طبقة ظلّات تتبع المؤشر قابلة لإعادة الاستخدام في React أو Next.js أو Vue أو Svelte أو Solid أو مشاريع الويب العادية. الرجاء دائمًا الرد بلغة المستخدم.
