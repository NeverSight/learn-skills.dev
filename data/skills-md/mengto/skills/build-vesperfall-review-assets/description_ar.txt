بناء أزواج مراجعة صادقة لمكتبة أصول Vesperfall من مراجع PNG شفافة ونماذج Three.js أو FBX أو img2threejs الحية. استخدمها عند إضافة شخصية أو عدو أو عنصر أو أصل معدات إلى فهرس Vesperfall؛ إنشاء بطاقة PNG مع معالجة نموذج المفتش؛ كشف نموذج معزول أو مسار تحريك؛ أو توحيد المصدر، والأساس، والاختبارات، والتحقق عبر متصفح Codex لمراجعة فن اللعبة.
