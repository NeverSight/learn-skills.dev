顯示應用程式在網頁上運作，透過在 HTML 中即時繪製，而非錄製影片。Mac 風格的視窗一步步播放應用程式，且每一幀都是唯一時鐘 View(t) 的純函式，繪製在固定 1200 × 750 的舞台上，使用 CSS 縮放即可適應任何寬度。指標由腳本控制，標籤與圖片取自真實的應用程式，步驟列位於視窗下方，僅在畫面可見時播放，並為縮減動作設計結束幀。適用於想要產品示範、動畫式應用程式視窗或主視覺、功能導覽，「UI 以 HTML 動畫與模擬」的情境，「像螢幕錄製但使用 HTML」的需求，或在著陸頁或下載頁上提供互動式產品導覽，亦或想要以清晰的即時 HTML 取代 UI 的螢幕錄製、GIF 或 MP4。也可用於透過輔助代理一次建立多個此類視窗，或對它們進行快覽、凍結與截圖。
