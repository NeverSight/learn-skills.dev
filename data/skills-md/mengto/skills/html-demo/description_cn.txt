在网页上通过实时绘制 HTML 来展示应用运行，而不是录制视频。一个 mac 风格的窗口一步步播放该应用，每一帧都是时钟 View(t) 的纯函数，绘制在固定的 1200 × 750 舞台上，使用 CSS 缩放即可适配任何宽度。指针由脚本控制，标签和图片取自真实的应用，步骤条位于窗口下方，只有在屏幕可见时才播放，并为减少动画设计了结束帧。适用于需要产品演示、动画应用窗口或主视觉、功能演练、“UI 在 HTML 中动画模拟”、类似屏幕录制但使用 HTML、在登录页或下载页上的交互式产品导览，或想用清晰的实时 HTML 替代 UI 的屏幕录制、GIF 或 MP4。也可用于通过助手一次构建多个此类窗口，或对它们进行抓取、冻结和截图。
