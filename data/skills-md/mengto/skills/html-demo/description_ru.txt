Покажите приложение, работающего на веб‑странице, рисуя его в реальном времени в HTML вместо записи. Окно в стиле Mac воспроизводит приложение пошагово, и каждый кадр — чистая функция одного таймера View(t), нарисованная на фиксированной сцене 1200 × 750, которую один CSS‑масштаб подгоняет под любую ширину. Указатель управляется скриптом, подписи и изображения берутся из настоящего приложения, под окном расположен индикатор шагов, воспроизведение происходит только пока окно находится на экране, а для уменьшённого движения создаются специальные конечные кадры. Используйте, когда нужен демонстрационный ролик продукта, анимированное окно приложения или герой‑баннер, пошаговое руководство по функции, «интерфейс анимирован и смоделирован в HTML», «как видеозапись, но в HTML», интерактивный тур продукта на лендинге или странице загрузки, либо когда хочется заменить видеозаписи, GIF‑ы или MP4‑файлы интерфейса на чёткий живой HTML. Также можно использовать для массового создания таких окон с помощью вспомогательных агентов, или для перемотки, заморозки и создания скриншотов.
