Zeige eine App, die auf einer Webseite arbeitet, indem du sie live in HTML zeichnest anstatt sie aufzunehmen. Ein Mac‑ähnliches Fenster spielt die App Schritt für Schritt ab, und jedes Bild ist eine reine Funktion einer einzigen Uhr, View(t), gezeichnet auf einer festen 1200 × 750‑Bühne, die durch einen CSS‑Skalierungsfaktor an jede Breite angepasst wird. Der Zeiger ist geskriptet, Beschriftungen und Bilder stammen aus der echten App, eine Schrittleiste befindet sich unter dem Fenster, es spielt nur ab, solange es sichtbar ist, und bei reduzierter Bewegung werden End‑Frames gestaltet. Verwende es, wenn jemand eine Produktdemo, ein animiertes App‑Fenster oder Hero, einen Funktions‑Walkthrough, „die UI animiert und simuliert in HTML“, „wie eine Bildschirmaufnahme, aber HTML“, eine interaktive Produkttour auf einer Landing‑ oder Download‑Seite möchte oder Bildschirmaufnahmen, GIFs oder MP4s ihrer UI durch scharfes Live‑HTML ersetzen will. Auch zum Erstellen vieler solcher Fenster gleichzeitig mit Hilfs‑Agenten oder zum Durchschieben, Einfrieren und Screenshot‑Erstellen.
