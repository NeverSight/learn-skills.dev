Trasforma una cattura giornaliera completata di ispirazione UI in esattamente cinque landing page originali, una per ogni compito Codex separato, utilizzando Sites. Usa questa procedura quando l'utente chiede di convertire i riferimenti di ispirazione quotidiana, un pacchetto di prompt UI da cinque elementi o un articolo datato `*-ui-inspiration-capture` in pagine HTML distinte, modificando i brand di origine, i nomi, il testo, le persone, i numeri, i prezzi, le affermazioni e le immagini.

Rispondi sempre nella lingua dell'utente.
