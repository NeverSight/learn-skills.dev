Construir, ampliar o auditar editores de mapas en navegador vinculados a producción para Three.js y juegos isométricos. Utilízalo cuando Codex necesite crear una vista de director privado, derivar un documento de editor versionado a partir de colocaciones creadas, añadir esquema, capa, selección, arrastre, ajuste, inspector o controles de cámara, exponer superposiciones de agro, correa o patrulla de enemigos, implementar importación de borrador local, exportación, deshacer y reinicio, asegurar una ruta del editor con sesiones de IP y contraseña, o validar y lanzar un editor de mapas sin mutar los datos de juego en vivo.
