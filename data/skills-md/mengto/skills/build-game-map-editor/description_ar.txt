ابنِ، أو وسّع، أو راجع محرّرات خرائط المتصفح المرتبطة بالإنتاج لـ Three.js وألعاب الإسومتري. استخدمه عندما يحتاج Codex إلى إنشاء عرض مخرج خاص، استخراج وثيقة محرّر مُصدّرة بإصدارات من المواضع المكتوبة، إضافة قائمة توضيحية، طبقة، اختيار، سحب، تثبيت، فاحص، أو أدوات تحكم بالكاميرا، كشف طبقات عدوان العدو، السلسلة، أو مسارات الدورية، تنفيذ استيراد مسودة محلية، تصدير، التراجع، وإعادة تعيين، تأمين مسار المحرّر باستخدام جلسات IP وكلمة مرور، أو التحقق من صحة وإصدار محرّر الخريطة دون تعديل بيانات اللعب الحية.
