Genera múltiples mundos de campañas de marca originales a partir de una referencia visual suministrada, controlando cuán cercano se percibe el nuevo trabajo sin copiar elementos característicos protegidos. Utilízalo cuando un usuario proporcione una imagen de identidad de marca, póster, campaña editorial, moodboard o concepto generado y solicite alternativas inspiradas, varias marcas distintas dentro de una misma familia visual, una versión V2 más cercana a la referencia, logotipos exactos dentro de las imágenes o indicaciones y resultados de generación de imágenes que garanticen originalidad.
