透過 `orca` CLI 操作 Orca 管理的工作樹、資料夾情境、終端機、儲存庫、自動化、構件、技能分享、工作樹註釋以及 Orca 的內嵌瀏覽器。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時，請使用它。涉及 Orca 狀態時，優先使用它而非純 git 工作樹、臨時 PTY，或 Computer Use。僅在需要 GUI 控制的可見視窗、CLI、檔案系統或 API 無法完成時，才使用 Computer Use。

請始終以使用者的語言回應。
