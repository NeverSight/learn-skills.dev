Aiuta a migrare un plugin DeepSeek Harness (DSH) da DSH 0.1.1 a 0.1.5 con il CLI dsh-doctor, decidendo esplicitamente in anticipo se la versione aggiornata deve rimanere compatibile con DSH 0.1.1. Da utilizzare quando lo sviluppatore di un plugin pianifica una migrazione o una valutazione di compatibilità: controllare cosa è cambiato tra le versioni di DSH, sostituire gli import dei pacchetti rimossi in 0.1.5 (come dsh-client-runtime o dsh-host-apiproxy), migrare settingsNamespace al Service settings, aggiornare gli intervalli di dipendenza di DSH, o verificare e preparare una release del plugin per 0.1.5. Applica solo riscritture esatte confermate dal catalogo automaticamente e guida le modifiche semantiche che richiedono il giudizio dello sviluppatore. Non è destinato al debug di un plugin che mira già a 0.1.5, a domande generali sull'uso o la configurazione di DSH, o allo sviluppo del Harness stesso.
