Помогите мигрировать плагин DeepSeek Harness (DSH) с версии DSH 0.1.1 на 0.1.5 с помощью CLI dsh‑doctor, заранее явно решив, должна ли обновлённая версия оставаться совместимой с DSH 0.1.1. Используйте, когда разработчик плагина планирует миграцию или оценку совместимости: проверка изменений между версиями DSH, замена импортов пакетов, удалённых в 0.1.5 (например, dsh-client-runtime или dsh-host-apiproxy), перенос settingsNamespace в сервис Settings, обновление диапазонов зависимостей DSH, либо проверка и подготовка выпуска плагина для 0.1.5. Применяется только к автоматически подтверждённым в каталоге точным переписыванию и направляет семантические изменения, требующие решения разработчика. Не предназначено для отладки плагина, уже нацеленного на 0.1.5, общих вопросов по использованию или конфигурации DSH, либо разработки самого Harness.
