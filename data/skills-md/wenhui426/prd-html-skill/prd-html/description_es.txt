Solución basada en PRD para generar prototipos interactivos en HTML (una versión simplificada basada en especificaciones). Úselo cuando los usuarios quieran generar prototipos interactivos HTML, prototipos en los que se puede hacer clic, prototipos de varias páginas, páginas con datos simulados pero con interacciones reales, convertir PRD/documentos de requisitos/listas de páginas/capturas de pantalla del sistema en prototipos web interactivos, o discutir combinaciones de entrega de PRD a HTML, documento MD+HTML. Cuando los usuarios dicen "convertir los requisitos en una página en la que se puede hacer clic", "generar una página web demostrable", "crear páginas prototipo según el documento XX" o "convertir PRD en un prototipo web", también se debe activar, incluso si HTML no se menciona explícitamente.
