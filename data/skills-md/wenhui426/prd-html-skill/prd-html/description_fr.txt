Solution basée sur PRD pour la sortie de prototypes interactifs en utilisant HTML (une version simplifiée basée sur les spécifications). Utilisez-le lorsque l'utilisateur souhaite générer un prototype interactif HTML, un prototype cliquable, un prototype multipage, une page avec des données fictives mais une interaction réelle, convertir PRD/documents d'exigences/listes de pages/captures d'écran du système en un prototype Web interactif, ou discuter d'un combo PRD vers HTML, document MD + livraison HTML. Il doit également être déclenché lorsque l'utilisateur dit « transformer les exigences en une page cliquable », « générer une page Web démontrable », « créer une page prototype selon le document XX » ou « convertir le PRD en un prototype Web », même si HTML n'est pas explicitement mentionné.
