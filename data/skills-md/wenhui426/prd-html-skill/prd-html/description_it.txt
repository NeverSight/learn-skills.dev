Una soluzione basata su PRD per la produzione di prototipi interattivi con HTML (una versione semplificata basata sulle specifiche). Usalo quando gli utenti desiderano generare prototipi interattivi HTML, prototipi cliccabili, prototipi multipagina, pagine con dati fittizi ma interazioni reali o per trasformare documenti PRD/requisiti/elenchi di pagine/screenshot di sistema in prototipi Web interattivi o quando si discute di combinazioni di distribuzione PRD-to-HTML, documenti MD+HTML. Dovrebbe anche essere attivato quando gli utenti dicono “trasforma i requisiti in una pagina cliccabile”, “genera una pagina web demo”, “crea pagine prototipo secondo il documento XX” o “converti il ​​PRD in un prototipo web”, anche se non menzionano esplicitamente l’HTML.
