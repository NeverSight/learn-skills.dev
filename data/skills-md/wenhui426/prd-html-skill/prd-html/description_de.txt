PRD-gesteuerte Lösung zur Ausgabe interaktiver Prototypen mithilfe von HTML (eine vereinfachte spezifikationsgesteuerte Version). Es wird verwendet, wenn ein Benutzer interaktive HTML-Prototypen, anklickbare Prototypen, mehrseitige Prototypen, Seiten mit Scheindaten, aber echten Interaktionen generieren, PRD/Anforderungsdokumente/Seitenlisten/System-Screenshots in interaktive Web-Prototypen umwandeln oder eine Kombination aus PRD-zu-HTML, MD-Dokument und HTML-Bereitstellung besprechen möchte. Wenn der Benutzer sagt: „Anforderungen in eine anklickbare Seite umwandeln“, „Demo-Webseite erstellen“, „Prototypseite basierend auf XX-Dokument erstellen“ oder „PRD in einen Web-Prototyp umwandeln“, sollte dies auch dann ausgelöst werden, wenn HTML nicht explizit erwähnt wird.
