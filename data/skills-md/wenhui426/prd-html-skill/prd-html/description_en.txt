PRD-driven solution for outputting interactive prototypes in HTML (a simplified spec‑driven version). It is used when a user wants to generate HTML interactive prototypes, clickable prototypes, multi‑page prototypes, or pages with mock data and real interactions, wants to turn PRD/requirement documents/page inventories/system screenshots into interactive web prototypes, or discuss PRD‑to‑HTML, MD document + HTML delivery combos. When the user says “turn the requirements into a clickable page”, “generate a demonstrable web page”, “create prototype pages according to XX document”, or “convert PRD to a web prototype”, it should also be triggered, even if HTML isn’t explicitly mentioned.
