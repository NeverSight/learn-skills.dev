حل يعتمد على PRD لإخراج النماذج الأولية التفاعلية بتنسيق HTML (إصدار مبسط يعتمد على المواصفات). عندما يرغب المستخدمون في إنشاء نماذج أولية تفاعلية بتنسيق HTML - نماذج أولية قابلة للنقر، ونماذج أولية متعددة الصفحات، وصفحات تحتوي على بيانات وهمية وتفاعلات حقيقية - قم بتحويل PRD/مستندات المتطلبات/قوائم الصفحات/لقطات شاشة النظام إلى نماذج أولية تفاعلية على الويب، أو مناقشة مجموعة من مستندات PRD-to-HTML وMD + تسليم HTML. قم بتشغيل هذا عندما يقول المستخدم "تحويل المتطلبات إلى صفحة قابلة للنقر"، أو "إنشاء صفحة ويب يمكن إثباتها"، أو "إنشاء صفحة نموذج أولي استنادًا إلى مستند XX"، أو "تحويل PRD إلى نموذج أولي للويب"، حتى لو لم يذكر HTML صراحةً.
