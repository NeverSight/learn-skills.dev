Решение на основе PRD для вывода интерактивных прототипов в HTML (упрощенная версия на основе спецификаций). Он используется, когда пользователь хочет создать интерактивные HTML-прототипы, кликабельные прототипы, многостраничные прототипы или страницы с фиктивными данными и реальными взаимодействиями, хочет превратить PRD/документы с требованиями/инвентаризация страниц/скриншоты системы в интерактивные веб-прототипы или обсудить комбинации доставки PRD-to-HTML, MD document+HTML. Когда пользователь говорит «превратить требования в интерактивную страницу», «создать демонстрационную веб-страницу», «создать прототип страницы в соответствии с документом XX» или «преобразовать PRD в веб-прототип», это также должно сработать, даже если HTML не упоминается явно.
