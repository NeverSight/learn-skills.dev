Audite una afirmación de comportamiento determinada y la prueba, el validador, el punto de referencia o la puerta citados como prueba, o audite un conjunto determinado de pruebas existentes para detectar pruebas redundantes o de bajo valor. No lo utilice para implementaciones ordinarias, para escribir nuevas pruebas, para pruebas que no superan los controles, para una cobertura deficiente o para la presencia de simulaciones.
