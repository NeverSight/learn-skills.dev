Überprüfen Sie eine benannte verhaltensbezogene Behauptung und den Test, den Validator, den Benchmark oder das Gate, die als Nachweis angeführt werden, oder überprüfen Sie eine benannte Gruppe bestehender Tests auf redundante oder wenig aussagekräftige Tests. Nicht für gewöhnliche Implementierungen, das Schreiben neuer Tests, fehlgeschlagene Tests, schwache Abdeckung oder das Vorhandensein von Mocks verwenden.
