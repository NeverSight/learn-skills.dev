Instrument a code path starting from the questions on-call will ask, map each log, metric, and span to one of them, and prove the telemetry works by diagnosing an induced failure from it alone. Use when adding logging, metrics, or tracing to a new endpoint, worker, job, or external call, or when an incident showed the existing signals could not answer what happened. Do not use for alert routing, paging policy, or dashboards without a question behind them.
