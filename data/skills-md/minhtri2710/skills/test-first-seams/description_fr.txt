Créer une fonctionnalité, corriger un bug ou ajouter des tests au code existant en appliquant l’approche « test-first » dans des tranches verticales rouge-vert aux points de jonction convenus. À utiliser lorsque l'utilisateur demande un travail TDD, rouge-vert ou test-first, souhaite qu'un bug soit prouvé par un test qui échoue avant la correction, ou demande quels tests un module nécessite et où les placer. Ne pas utiliser pour auditer les tests existants afin de vérifier leur valeur probante ou leur redondance.
