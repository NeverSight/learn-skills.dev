Entwickeln Sie eine Funktion, beheben Sie einen Fehler oder fügen Sie Tests zu vorhandenem Code hinzu – Test-First in rot-grünen vertikalen Slices an vereinbarten Schnittstellen. Anwenden, wenn der Benutzer um TDD-, Red-Green- oder Test-First-Arbeit bittet, einen Fehler möchte, der durch einen fehlgeschlagenen Test vor der Behebung nachgewiesen wird, oder fragt, welche Tests ein Modul benötigt und wo sie platziert werden sollen. Nicht verwenden, um vorhandene Tests auf ihren Nachweiswert oder ihre Redundanz zu prüfen.
