Mejorar un problema de rendimiento medido mediante un bucle de medición, corrección, nueva medición y mantenimiento o reversión. Utilícelo cuando se informe o se presupueste un problema de latencia, tiempo de carga, rendimiento, consulta, paquete o Core Web Vitals, o cuando se sospeche que un cambio ha provocado una regresión del rendimiento. No lo utilice para una optimización especulativa sin pruebas de que exista un problema, ni para un fallo aún sin medir cuya causa se desconozca; eso es diagnóstico de errores.
