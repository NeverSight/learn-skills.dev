Controla Herdr, un multiplexor de terminal para agentes de codificación, y ejecuta entregas delimitadas dentro de él con el modelo de roles Supervisor / Líder / Peer: operaciones de paneles y agentes, admisión y propiedad, un problema a la vez en una checkout compartida y una rama, un Líder que divide el problema en pares ingenieros propietarios del camino que se ejecutan en paralelo cuando se descompone, confirmaciones de propiedad del Líder, revisión independiente exact‑head por un Peer Revisor, pares que informan de vuelta mediante un aviso, una silla de Supervisor atendida por humanos, enrutamiento de puerta humana con notificación, entrega de evidencia y cierre seguro. Utilízalo siempre que el usuario mencione explícitamente Herdr — para inspeccionar o controlar paneles, pestañas, espacios de trabajo, comandos u otro agente, para implementar un cambio con uno o más agentes, para ejecutar una canalización de implementación a revisión, para monitorizar una entrega delimitada o para supervisar una. No lo uses simplemente porque una tarea podría beneficiarse de un terminal en segundo plano, delegación o trabajo paralelo. El control de Herdr requiere HERDR_ENV=1.

Por favor, responde siempre en el idioma del usuario.
