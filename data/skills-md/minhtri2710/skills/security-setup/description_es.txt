Diseñar y, tras una aprobación explícita, implementar una línea base de seguridad prioritaria a nivel local con detección de secretos siempre activa, dependencias que funcionen sin conexión y comprobaciones estáticas, informes legibles por máquina, derivaciones explícitas y un espejo de CI opcional con control de acceso independiente. Utilícela cuando refuerce el flujo de trabajo de seguridad local de un repositorio. No lo utilice para responder a incidentes, revisar la seguridad en la nube o decidir si una dependencia puede entrar en el proyecto.
