Cree código desechable que responda a una pregunta de diseño, ya sea una demostración HTML de un solo archivo que gestione un modelo de estado o varias variantes de interfaz de usuario estructuralmente diferentes en una ruta. Úselo cuando el usuario quiera comprobar si una máquina de estados, una forma de datos o una superficie de API funcionan bien, o para ver algunas opciones sobre cómo debería ser una pantalla, antes de comprometerse con una implementación. No lo utilice para crear la funcionalidad real, para probar el código de producción ni para diseñar o perfeccionar la interfaz de usuario real de una pantalla existente.
