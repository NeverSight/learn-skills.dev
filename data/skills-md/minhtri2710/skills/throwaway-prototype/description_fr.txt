Créez un code jetable qui répond à une question de conception, qu’il s’agisse d’une démo HTML à fichier unique qui pilote un modèle d’état ou de plusieurs variantes d’interface utilisateur structurellement différentes sur un même itinéraire. À utiliser lorsque l’utilisateur souhaite vérifier si une machine à états, une forme de données ou une surface d’API est viable, ou pour voir quelques options concernant l’apparence d’un écran, avant de s’engager dans une implémentation. Ne pas utiliser pour créer la fonctionnalité réelle, pour tester le code de production, ou pour concevoir ou peaufiner l’interface utilisateur réelle d’un écran existant.
