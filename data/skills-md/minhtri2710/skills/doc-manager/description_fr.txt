À utiliser pour le README, la documentation et le Markdown des composants qui doivent correspondre au code. Si un document contient un runbook de configuration, de publication, de déploiement ou d'exploitation, validez également cette section via le chemin de vérification uniquement dans references/runbook-validation.md.
