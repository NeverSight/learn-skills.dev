Diseñar o profundizar en la interfaz de un módulo y en la ubicación de las uniones utilizando el vocabulario de módulos profundos. Úselo cuando el usuario quiera diseñar la interfaz de un módulo, decidir dónde va una unión, encontrar oportunidades de profundización en un área determinada o comparar interfaces alternativas. No lo utilice para una auditoría de arquetipos de todo el proyecto.
