Fondez le code spécifique à un framework ou à une bibliothèque sur la documentation officielle de la version exacte installée, en fournissant des citations. À utiliser lorsque l’utilisateur demande une utilisation documentée, actuelle ou vérifiée d’un framework ou d’une API de bibliothèque, ou lorsque l’exactitude dépend d’un modèle spécifique à une version. Ne pas utiliser pour une logique indépendante de la version.
