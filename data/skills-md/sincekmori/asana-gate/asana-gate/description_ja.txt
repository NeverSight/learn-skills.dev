Asana‑gate を介して Asana を操作します。as a n a‑gate は、AI エージェント用の宣言的 YAML ポリシーを Asana REST API の前に置くポリシーゲートウェイであり、MCP ツール（asana_*）や asana‑gate コマンドラインとして機能します。タスクが asana‑gate に関わるすべての場合にこれを使用してください：ポリシーの作成または修正（where/allow/deny スコープ、必須メンバーやタイトル接頭辞、レートリミット、確認といった制約）、asana‑gate コマンドの実行、MCP ツールの呼び出し、拒否応答の確認（404: 認識されない ID、403: asana‑gate:、400: ポリシーに適合しない、428: 確認が必要、429: 制限超過）、.asana‑gate 設定やキャッシュの構成、あるいはエージェントが Asana で実行できることの判断。ユーザーが allowed_actions、Asana ポリシー、gate、または Asana 用 MCP サーバーについて言及し、asana‑gate と名前を付けずに言及した場合にも適用されます。
