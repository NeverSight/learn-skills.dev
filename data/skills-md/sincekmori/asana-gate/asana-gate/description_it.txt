Utilizza Asana tramite asana-gate, il gateway di policy che inserisce una policy YAML dichiarativa davanti all'API REST di Asana per gli agenti AI, come strumenti MCP (asana_*) e la riga di comando asana-gate. Usa questo ogni volta che un task interagisce con asana-gate in qualsiasi modo: scrivere o correggere una policy (scope where/allow/deny, vincoli come membri obbligatori, prefissi del titolo, limiti di velocità e conferme), eseguire comandi asana-gate, chiamare i suoi strumenti MCP, leggere i suoi rifiuti (404 ID non riconosciuto, 403 asana-gate:, 400 non soddisfa la policy, 428 conferma, 429 limite), configurare le impostazioni .asana-gate o la cache, o decidere cosa un agente può fare in Asana. Si applica anche quando l'utente menziona allowed_actions, una policy di Asana, il gate o un server MCP per Asana senza citare asana-gate.
