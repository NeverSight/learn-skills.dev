Operate Asana through asana-gate, the policy gateway that puts a declarative YAML policy in front of the Asana REST API for AI agents, as MCP tools (asana_*) and the asana-gate command line. Use this whenever a task touches asana-gate in any way: writing or fixing a policy (where/allow/deny scopes, constraints such as required members, title prefixes, rate limits and confirmations), running asana-gate commands, calling its MCP tools, reading its refusals (404 Not a recognized ID, 403 asana-gate:, 400 does not satisfy the policy, 428 confirmation, 429 limit), configuring .asana-gate settings or the cache, or deciding what an agent may do in Asana. Also applies when the user mentions allowed_actions, an Asana policy, the gate, or an MCP server for Asana without naming asana-gate.
