تشغيل Asana عبر asana-gate، بوابة السياسات التي تضع سياسة YAML إعلانية أمام واجهة برمجة تطبيقات Asana REST للوكيلات الذكية، كأدوات MCP (asana_*) وسطر أوامر asana-gate. استخدم ذلك كلما تلامس مهمة asana-gate بأي طريقة: كتابة أو تعديل سياسة (نطاقات where/allow/deny، قيود مثل الأعضاء المطلوبين، بادئات العناوين، حدود المعدل والتأكيدات)، تشغيل أوامر asana-gate، استدعاء أدوات MCP الخاصة به، قراءة رفضاته (404 غير معرف معروف، 403 asana-gate:, 400 لا يحقق السياسة، 428 تأكيد، 429 حد)، تكوين إعدادات .asana-gate أو الذاكرة المؤقتة، أو تحديد ما يمكن للوكيل القيام به في Asana. ينطبق أيضاً عندما يذكر المستخدم allowed_actions أو سياسة Asana أو البوابة أو خادم MCP لـ Asana دون ذكر asana-gate.
