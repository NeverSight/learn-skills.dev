Opera Asana a través de asana-gate, la puerta de enlace de políticas que coloca una política YAML declarativa delante de la API REST de Asana para agentes de IA, como herramientas MCP (asana_*) y la línea de comandos de asana-gate. Utiliza esto siempre que una tarea toque asana-gate de cualquier manera: escribir o corregir una política (alcances where/allow/deny, restricciones como miembros requeridos, prefijos de título, límites de velocidad y confirmaciones), ejecutar comandos de asana-gate, llamar a sus herramientas MCP, leer sus rechazos (404 No es una ID reconocida, 403 asana-gate:, 400 no cumple la política, 428 confirmación, 429 límite), configurar los ajustes .asana-gate o la caché, o decidir qué puede hacer un agente en Asana. También se aplica cuando el usuario menciona allowed_actions, una política de Asana, la puerta de enlace o un servidor MCP para Asana sin nombrar asana-gate.

Por favor, responde siempre en el idioma del usuario.
