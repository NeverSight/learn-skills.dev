Asigna la superficie de creación `hunkdiff/extension` para Hunk, el visor de diferencias del terminal: ocultar o reordenar archivos revisados, paneles acoplados, vistas alternativas de archivos, comandos y combinaciones de teclas, cuadros de diálogo, escrituras en el espacio de trabajo, temas, lenguajes de sintaxis, backends de VCS, eventos del ciclo de vida. Úsela al escribir, depurar o instalar una extensión de Hunk, o cuando una solicitud pida a Hunk que se comporte de forma diferente. No se debe usar para revisar un diff en una sesión en tiempo real; para eso se debe usar hunk-review.
