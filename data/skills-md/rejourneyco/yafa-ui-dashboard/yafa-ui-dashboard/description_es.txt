Diseña, construye, refactorea o revisa paneles de análisis responsivos y pulidos, paneles de administración SaaS, interfaces de inteligencia empresarial y UI de productos con gran carga de datos usando Yafa-UI. Incluye navegación lateral, encabezados de página de una sola fila, tarjetas KPI multicolor, gráficos, tablas, filtros, íconos Lucide, estados accesibles y diseños de paneles móviles en React, Next.js, Tailwind CSS, Vue, Svelte y otras pilas frontend. No uses este sistema visual como predeterminado para sitios de marketing, autenticación, asistentes de configuración, configuraciones de cuenta o facturación, o páginas públicas no relacionadas.
