在 Markdown 文档中创建可视化：图表、图示、卡片、架构和页面布局。图表和分析视图（柱形图、折线图、饼图、热图、相关性、回归）；可靠性与运维（延迟、事件、吞吐量、周期时间、OKR、站会、值班）；产品与财务（漏斗、留存、收入、预算）；流程与工作流（审批、BPMN）；软件设计与行为（类、状态机、时序图、C4）；依赖与影响（依赖图、ER、因果关系）；系统架构作为 HTML 页面（层叠、翼、分区、拓扑、服务目录、请求路径）；基础设施（云、Kubernetes、ETL、网络、安全、IAM、合规）；治理与人员（ArchiMate、组织结构图、招聘）；知识与规划（思维导图、路线图、甘特图、迁移）；文档（对比、SWOT、备忘录、政策、目录、案例研究）。在文档需要图表、图示或卡片时使用。不要用于幻灯片或数学符号，亦不适用于 mermaid / canvas / drawio。
