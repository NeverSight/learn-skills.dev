إنشاء رسومات بصريّة في مستندات Markdown: مخططات، رسومات بيانية، بطاقات، بنية وتصميم الصفحات. المخططات والعروض التحليلية (شريطية، خطية، دائرية، خريطة حرارية، ارتباط، انحدار)؛ الموثوقية والعمليات (الكمون، الحادث، الإنتاجية، زمن الدورة، OKR، الوقوف اليومي، الاستدعاء)؛ المنتج والمال (قمع، الاحتفاظ، الإيرادات، الميزانية)؛ العملية وسير العمل (الموافقة، BPMN)؛ تصميم البرمجيات والسلوك (فئة، آلة حالة، تسلسل، C4)؛ الاعتمادات والأثر (رسم بياني للاعتماد، ER، السببية)؛ بنية النظام كصفحة HTML (طبقة، أجنحة، مناطق، طوبولوجيا، كتالوج الخدمة، مسارات الطلب)؛ البنية التحتية (السحابة، Kubernetes، ETL، الشبكة، الأمان، IAM، الامتثال)؛ الحوكمة والأشخاص (ArchiMate، مخطط تنظيمي، التوظيف)؛ المعرفة والتخطيط (خريطة ذهنية، خريطة طريق، مخطط غانت، الترحيل)؛ المستندات (مقارنة، SWOT، مذكرّة، سياسة، كتالوج، دراسة حالة). استخدمه عندما يحتاج المستند إلى رسم بياني أو مخطط أو بطاقة. ليس لعروض الشرائح أو الصيغ الرياضية، ولا لـ mermaid / canvas / drawio.
