Validiert einen kompilierten Robomotion‑Flow gegen pspec‑Schemas über `robomotion validate <flow-dir>`. Gibt bei sauberem Durchlauf 0 zurück, bei Fehler 1, mit node‑by‑node‑Bericht auf stderr; keine stdout‑Ausgabe (für Shell‑Pipelines geeignet). Verwenden, wenn der Benutzer sagt „validate this flow“, „check the flow“, „is this correct“ oder vor dem Ausführen. Führt den Flow NICHT aus – für Verhaltens‑Tests verwenden Sie testing‑flow.
