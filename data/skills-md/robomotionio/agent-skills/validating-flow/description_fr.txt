Valide un flux Robomotion compilé contre les schémas pspec via `robomotion validate <flow-dir>`. Retourne 0 en cas de succès, 1 en cas d’erreur avec un rapport nœud par nœud sur stderr ; aucune sortie stdout (s’intègre dans les pipelines shell). Utilisez‑le lorsque l’utilisateur dit « validez ce flux », « vérifiez le flux », « est‑ce correct », ou avant d’exécuter. NE PAS exécuter le flux — pour les tests comportementaux, utilisez testing-flow.
