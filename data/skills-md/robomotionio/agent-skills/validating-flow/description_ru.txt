Проверяет скомпилированный поток Robomotion на соответствие схемам pspec с помощью `robomotion validate <flow-dir>`. Возвращает код выхода 0 при отсутствии ошибок и 1 при ошибке, выводя отчёт по узлам в stderr; вывод в stdout отсутствует (можно использовать в конвейерах оболочки). Применяется, когда пользователь говорит «validate this flow», «check the flow», «is this correct» или перед запуском. НЕ запускает поток — для поведенческих тестов используйте testing-flow.
