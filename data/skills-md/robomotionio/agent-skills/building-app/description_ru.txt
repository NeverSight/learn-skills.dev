Создаёт приложение Robomotion — настоящее React‑веб‑приложение, расположенное перед потоком робота, — посредством общения с нетехническим пользователем. Ответственно за весь жизненный цикл: уточнение → контракт (app.json) → экраны с app‑kit → поток за ними → запуск на роботе приложения → использование приложения в браузере и исправление до полной работоспособности → публикация. Используется, когда пользователю нужен приложение, дашборд, портал, форма, очередь утверждения, доска объектов, проходящих через стадии, или любые экраны, по которым люди будут кликать.
