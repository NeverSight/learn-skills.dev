Erstellt eine Robomotion‑App – eine echte React‑Web‑App vor einem Roboter‑Flow – durch Gespräch mit einer nicht‑technischen Person. Verantwortet den gesamten Lebenszyklus: klären → Vertrag (app.json) → Bildschirme mit App‑Kit → den Flow dahinter → Ausführen auf dem Roboter der App → Nutzung der App im Browser und Korrekturen, bis sie funktioniert → veröffentlichen. Verwendung, wenn der Nutzer eine App, ein Dashboard, ein Portal, ein Formular, eine Genehmigungswarteschlange, ein Board für Dinge, die durch Phasen gehen, oder beliebige Bildschirme, die Menschen anklicken, möchte.
