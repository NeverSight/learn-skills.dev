Construit une application Robomotion – une vraie application web React placée devant un flux de robot – à partir d’une conversation avec une personne non technique. Gère l’ensemble du cycle de vie : clarifier → contrat (app.json) → écrans avec app-kit → le flux derrière eux → l’exécuter sur le robot de l’application → utiliser l’application dans un navigateur et corriger jusqu’à ce qu’elle fonctionne → publier. À utiliser lorsque l’utilisateur veut une application, un tableau de bord, un portail, un formulaire, une file d’attente d’approbation, un tableau de choses qui progressent à travers des étapes, ou tout écran sur lequel les gens cliqueront.
