Construye una aplicación Robomotion —una verdadera aplicación web React frente a un flujo de robot— mediante conversación con una persona no técnica. Se encarga de todo el ciclo de vida: clarificar → contrato (app.json) → pantallas con app‑kit → el flujo detrás de ellas → ejecutarla en el robot de la aplicación → usar la aplicación en un navegador y corregirla hasta que funcione → publicar. Se utiliza cuando el usuario desea una aplicación, panel, portal, formulario, cola de aprobaciones, un tablero de cosas que pasan por etapas, o cualquier pantalla en la que la gente haga clic.
