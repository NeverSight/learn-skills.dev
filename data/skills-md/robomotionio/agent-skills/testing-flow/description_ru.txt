Запускает и пишет поведенческие тесты для потоков Robomotion, используя @robomotion/sdk/testing. Применять, когда пользователь говорит «тестировать поток», «напиши тесты для main.ts», «замокай этот сервис», «проверь покрытие веток» или когда потоку нужны регрессионные тесты перед изменением. Для проверки схемы pspec используйте validating-flow.

Пожалуйста, всегда отвечайте на языке пользователя.
