Exécute et rédige des tests comportementaux pour les flux Robomotion en utilisant @robomotion/sdk/testing. Utilisez‑le lorsque l’utilisateur dit « test the flow », « write tests for main.ts », « mock this service », « check branch coverage », ou lorsqu’un flux nécessite des tests de régression avant une modification. Pour la validation du schéma pspec, utilisez validating-flow à la place.

Veuillez toujours répondre dans la langue de l’utilisateur.
