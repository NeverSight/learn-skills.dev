Verwende es, wenn der Benutzer sagt „test the flow“, „write tests for main.ts“, „mock this service“, „check branch coverage“ oder wenn ein Flow vor einer Änderung Regressionstests benötigt. Für die pspec‑Schema‑Validierung verwende validating‑flow.
