Esegue e scrive test comportamentali per i flussi Robomotion utilizzando @robomotion/sdk/testing. Usalo quando l'utente dice "test the flow", "write tests for main.ts", "mock this service", "check branch coverage", oppure quando un flusso necessita di test di regressione prima di una modifica. Per la convalida dello schema pspec, usa invece validating-flow. Per favore rispondi sempre nella lingua dell'utente.
