Обращает сетевой трафик, проходящий через поток браузера, чтобы заменить медленную автоматизацию браузера прямыми HTTP‑запросами. Используйте, когда пользователь говорит «этот поток браузера слишком медленный», «найти API, который использует эта страница», «конвертировать в HTTP», «можем ли мы вызвать API вместо этого», или когда `exploring-browser` раскрывает чистый REST/GraphQL‑эндпоинт. Пожалуйста, всегда отвечайте на языке пользователя.
