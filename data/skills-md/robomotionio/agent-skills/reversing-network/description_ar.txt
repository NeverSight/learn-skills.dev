يعكس حركة الشبكة خلف تدفق المتصفح لاستبدال أتمتة المتصفح البطيئة بطلبات HTTP مباشرة. استخدمه عندما يقول المستخدم "هذا التدفق في المتصفح بطيء"، "ابحث عن الـ API الذي تستخدمه هذه الصفحة"، "تحويل إلى HTTP"، "هل يمكننا استدعاء الـ API بدلاً من ذلك"، أو عندما يكشف `exploring-browser` عن نقطة نهاية REST/GraphQL نظيفة. يرجى دائمًا الرد بلغة المستخدم.
