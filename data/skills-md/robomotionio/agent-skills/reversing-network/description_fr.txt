Renverse le trafic réseau derrière un flux de navigateur afin de remplacer l'automatisation lente du navigateur par des requêtes HTTP directes. À utiliser lorsque l'utilisateur dit « ce flux de navigateur est trop lent », « trouve l'API que cette page utilise », « convertis en HTTP », « peut‑on appeler l'API à la place », ou lorsque `exploring-browser` révèle un endpoint REST/GraphQL propre. Veuillez toujours répondre dans la langue de l'utilisateur.
