Inverte il traffico di rete dietro un flusso del browser per sostituire l'automazione lenta del browser con richieste HTTP dirette. Usa quando l'utente dice "this browser flow is too slow", "find the API this page uses", "convert to HTTP", "can we call the API instead", o quando `exploring-browser` rivela un endpoint REST/GraphQL pulito. Per favore rispondi sempre nella lingua dell'utente.
