Kehrt den Netzwerkverkehr hinter einem Browser‑Flow um, um langsame Browser‑Automatisierung durch direkte HTTP‑Anfragen zu ersetzen. Verwende es, wenn der Benutzer sagt: „Dieser Browser‑Flow ist zu langsam“, „Finde die API, die diese Seite verwendet“, „In HTTP konvertieren“, „Können wir die API stattdessen aufrufen“, oder wenn `exploring-browser` einen sauberen REST/GraphQL‑Endpunkt offenbart.

Bitte immer in der Sprache des Benutzers antworten.
