Utilisez le CLI public `orca` pour gérer les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, les commentaires de worktree et le navigateur intégré dans l’application Orca. Utilisez‑le lorsque l’utilisateur dit « $orca-cli », « use orca cli », « Orca worktree », « child worktree », « cardStatus », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « terminal send », « full handoff », « handover », « give this to another agent », « another worktree », « Orca browser », « orca artifacts », « share HTML/Markdown », « public artifact link » ou « control the browser inside Orca ». Privilégiez cela plutôt que le `git worktree` brut, des PTY ad‑hoc, Playwright ou l’**Utilisation de l’Ordinateur** lorsque la tâche touche l’état géré par Orca. Utilisez l’**Utilisation de l’Ordinateur** pour les fenêtres du navigateur, les webviews ou l’interface de bureau en dehors du navigateur intégré d’Orca.

Veuillez toujours répondre dans la langue de l’utilisateur.
