Gérez les tâches, projets, étiquettes et compartiments Vikunja à l'aide du CLI vja. Utilisez‑le pour « ajouter une tâche », « lister mes tâches », « marquer la tâche comme terminée », « modifier une tâche », « créer un projet » ou « ce qui est dû » lorsque Vikunja ou vja est nommé ou établi comme système de tâches.

Veuillez toujours répondre dans la langue de l'utilisateur.
