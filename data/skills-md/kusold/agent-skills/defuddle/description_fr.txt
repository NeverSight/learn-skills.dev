Extrait le contenu d'article propre et les métadonnées d'une page web au format Markdown avec l'outil en ligne de commande defuddle ; utilisez-le pour « extraire cet article », « convertir cette page en markdown », « obtenir le contenu principal de cette URL », « nettoyer ce HTML », « enregistrer un instantané lisible », ou lorsqu'on vous demande de récupérer le texte lisible d'une page au lieu du HTML brut.

Veuillez toujours répondre dans la langue de l'utilisateur.
