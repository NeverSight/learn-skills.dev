Orchestrateur de flux de travail d'écriture de code IA, s'exécute strictement dans l'ordre suivant : brainstorming → plans d'écriture → plans d'exécution → règles de code keyblade-pro. Prend en charge la détection des compétences ; si une compétence requise manque, l'étape est automatiquement ignorée et le processus suivant se poursuit.
