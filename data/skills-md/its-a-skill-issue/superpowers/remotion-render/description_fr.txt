Rendre des vidéos à partir du code de composant React/Remotion via inference.sh. Fournissez du code TSX, obtenez du MP4. Prend en charge toutes les API Remotion : useCurrentFrame, useVideoConfig, spring, interpolate, AbsoluteFill, Sequence. Résolution, FPS, durée et codec configurables. À utiliser pour : génération de vidéos programmatique, graphiques animés, design de motion, vidéos basées sur les données, animations React vers vidéo. Déclencheurs : remotion, rendu vidéo à partir du code, tsx vers vidéo, vidéo react, vidéo programmatique, rendu remotion, code vers vidéo, vidéo animée, code de motion graphics, vidéo d'animation react.
