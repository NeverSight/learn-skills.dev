Веб‑поиск и извлечение контента с Tavily и Exa через CLI inference.sh. Приложения: Tavily Search, Tavily Extract, Exa Search, Exa Answer, Exa Extract. Возможности: поиск на основе ИИ, извлечение контента, прямые ответы, исследования. Применение: исследования, конвейеры RAG, проверка фактов, агрегация контента, агенты. Триггеры: веб‑поиск, tavily, exa, API поиска, извлечение контента, исследования, поиск в интернете, поиск ИИ, помощник поиска, веб‑скрейпинг, rag, альтернатива Perplexity.
