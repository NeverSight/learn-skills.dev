Applicazioni: x/post-tweet, x/post-create (con media), x/post-like, x/post-retweet, x/dm-send, x/user-follow. Capacità: pubblicare tweet, programmare contenuti, mettere mi piace ai post, ritwittare, inviare DM, seguire utenti, ottenere profili. Utilizzo: automazione dei social media, programmazione dei contenuti, bot di coinvolgimento, crescita del pubblico, API X. Trigger: API Twitter, API X, automazione tweet, pubblica su Twitter, bot Twitter, automazione dei social media, automazione X, pianificatore di tweet, integrazione Twitter, pubblica tweet, post Twitter, post X, invia tweet.
