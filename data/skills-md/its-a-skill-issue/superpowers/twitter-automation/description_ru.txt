Автоматизируйте Twitter/X с помощью публикаций, взаимодействия и управления пользователями через CLI inference.sh. Приложения: x/post-tweet, x/post-create (с медиа), x/post-like, x/post-retweet, x/dm-send, x/user-follow. Возможности: публиковать твиты, планировать контент, ставить лайки, ретвитить, отправлять личные сообщения, подписываться на пользователей, получать профили. Использовать для: автоматизации социальных сетей, планирования контента, ботов взаимодействия, роста аудитории, X API. Триггеры: twitter api, x api, автоматизация твитов, публикация в twitter, twitter‑бот, автоматизация социальных сетей, x automation, планировщик твитов, интеграция twitter, post tweet, twitter post, x post, send tweet.
