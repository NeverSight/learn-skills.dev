Automatiza Twitter/X con publicación, interacción y gestión de usuarios mediante la CLI de inference.sh. Aplicaciones: x/post-tweet, x/post-create (con multimedia), x/post-like, x/post-retweet, x/dm-send, x/user-follow. Capacidades: publicar tuits, programar contenido, dar like a publicaciones, hacer retweet, enviar DMs, seguir usuarios, obtener perfiles. Usos: automatización de redes sociales, programación de contenido, bots de interacción, crecimiento de audiencia, API de X. Disparadores: twitter api, x api, tweet automation, post to twitter, twitter bot, social media automation, x automation, tweet scheduler, twitter integration, post tweet, twitter post, x post, send tweet
