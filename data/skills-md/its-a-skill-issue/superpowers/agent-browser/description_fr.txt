Automatisation de navigateur pour les agents IA via inference.sh. Naviguer sur des pages web, interagir avec les éléments en utilisant des références @e, prendre des captures d'écran, enregistrer des vidéos. Capacités : extraction de données web, remplissage de formulaires, clics, saisie, glisser‑déposer, téléchargement de fichiers, exécution de JavaScript. Utilisations : automatisation web, extraction de données, tests, navigation d’agents, recherche. Déclencheurs : navigateur, automatisation web, extraction, navigation, clic, remplissage de formulaire, capture d’écran, navigation web, Playwright, navigateur sans tête, agent web, surfer sur Internet, enregistrement vidéo.
