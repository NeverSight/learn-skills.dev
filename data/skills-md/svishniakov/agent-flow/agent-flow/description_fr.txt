Utilisez uniquement lorsque l'utilisateur demande explicitement d'exécuter la tâche via Agent Flow n'importe où dans la requête, par exemple `Agent Flow`, `AgentFlow`, `$agent-flow` ou `agent-flow`. Dirigez cette demande vers un résultat vérifié avec le plus petit budget utile. Le budget léger reste seul ; les budgets standard et release peuvent recourir à des sous‑agents lorsque l’orchestrateur décide qu’ils ajoutent une réelle valeur de vérification ou de parallélisme.
