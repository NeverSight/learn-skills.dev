What to do after a run of e2e, the agentic test runner from e2e.com (`e2e.config.ts`, `*.e2e.ts` files, `agent.act` steps), leaves the machine it ran on. Not for Playwright runs. Use when an e2e test failed in CI and its trace page is not in the local `.e2e/` folder, when deciding from run history whether an e2e test is flaky or broken, when quarantining a failing e2e test or checking that a fix held, when sharded e2e jobs need to show as one run, when agent steps cost more than expected or stopped replaying from the cache, when a device run's recording or an explore or bug bash finding needs a shared home, or when linking e2e tests to test cases. Results reach TestDino through the `@testdino/e2e` reporter and are read back over the TestDino MCP server. To write, run or fix an e2e test locally, use the e2e skill instead.
