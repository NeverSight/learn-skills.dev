Найдите и получите протоколы заседаний Японского национального парламента (国会) через официальный API NDL Kokkai (авторизация не требуется). Охватывает все сессии Диеты с 1947 года, поддерживает поиск по ключевым словам, поиск выступающих, поиск на уровне собраний и фильтрацию по дате/сессии/проблеме. Полезно для политических исследований, отслеживания законодательства, анализа выступлений и любых задач, связанных с отчетами японского парламента. API-интерфейс NDL (1947 год), API経由で検索・取得するスキル。発言・会議・キーワード検索および期間/回次/会派による絞り込みに対応。Использовать используйте этот навык при исследовании дебатов в японском парламенте, заявлений депутатов или парламентских протоколов.
