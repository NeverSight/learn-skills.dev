Ищите и получайте японские законы и правила с помощью официального API Закона об электронном правительстве версии 2 (авторизация не требуется). Поддерживает поиск по названию закона, поиск статей, историю изменений и полнотекстовый поиск по ключевым словам. Полезно для юридических исследований, проверок соответствия, проверки контрактов и любых задач, связанных с законодательством Японии (民法/Гражданский кодекс, 会社法/Закон о компаниях, 個人情報保護法/APPI, 労働基準法/Закон о трудовых стандартах и ​​т. д.). API API электронного правительства Версия V2.文取得、改正履歴、キーワード検索に対応。Use используйте этот навык при исследовании японских законов, постановлений или юридических текстов.
