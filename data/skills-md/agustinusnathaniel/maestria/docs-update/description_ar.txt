قيّم تأثير التوثيق وقم بتحديث المستندات المتأثرة لتغيير في الكود أو الـ API أو التكوين أو سير عمل المشغل. استخدم ذلك عندما يؤثر التغيير على سلوك موثق، أو عندما يُطلب تحديث مستندات قديمة أو مواءمة المستندات مع الكود، أو عندما يتغير قرار أو حالة مسجلة في الخطط أو سجلات اتخاذ القرار (ADRs). لا تستخدمه للتغييرات التافهة التي لا تتضمن سطحًا موثَّقًا، أو لصياغة نص جديد للمنتج من الصفر.

يرجى الرد دائمًا بلغة المستخدم.
