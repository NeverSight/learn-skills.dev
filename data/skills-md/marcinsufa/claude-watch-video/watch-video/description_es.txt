Haz que Claude “vea” un video — archivo local, URL pública (yt-dlp) o adjunto de Jira (totalmente automatizado cuando se configura un token API de Atlassian). Extrae fotogramas clave con ffmpeg y transcribe el audio con faster‑whisper (multilingüe), luego Claude lee los fotogramas + la transcripción para responder a la pregunta del usuario. Úsalo cuando el usuario quiera analizar una grabación de pantalla, un video de reproducción de error, una captura de demo o cualquier video al que apunte. Disparadores: “ver este video”, “analizar este video”, “qué ocurre en <file>.mp4”, “transcribir y ver”, “procesar esta reproducción de bug”, una clave de ticket de Jira seguida de “ver el video”, una URL de YouTube/Loom/TikTok/etc. con “ver esto” o “resumir esto”.
