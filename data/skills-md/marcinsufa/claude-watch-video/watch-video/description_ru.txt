Сделайте так, чтобы Клод «просмотрел» видео — локальный файл, общедоступный URL (yt-dlp) или вложение из Jira (полностью автоматизировано при настроенном токене API Atlassian). Выделяет ключевые кадры с помощью ffmpeg и расшифровывает аудио через faster‑whisper (многоязычно), после чего Клод читает кадры + транскрипт, чтобы ответить на вопрос пользователя. Используйте, когда пользователь хочет проанализировать запись экрана, видео воспроизведения бага, демонстрационный захват или любое другое видео, на которое он указывает. Триггеры — «watch this video», «analyze this video», «what happens in <file>.mp4», «transcribe and watch», «process this bug repro», ключ тикета Jira, за которым следует «watch the video», URL YouTube/Loom/TikTok/и др. с «watch this» или «summarize this».
