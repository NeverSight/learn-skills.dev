À utiliser lorsque l'utilisateur souhaite interagir avec Plan to Eat (plantoeat.com) via le serveur MCP Plan-to-eat connecté - afficher ou mettre à jour son plan de repas, gérer les recettes, planifier des notes/ingrédients/restes sur le planificateur, suivre le congélateur ou vérifier la liste de courses. Se déclenche sur des phrases telles que « qu'y a-t-il dans mon plan de repas », « plan X pour le dîner du mercredi », « ajouter une note au petit-déjeuner du mardi », « déplacer le dîner au vendredi », « congeler les restes », « qu'est-ce qu'il y a dans le congélateur », « qu'y a-t-il dans ma liste de courses ».
