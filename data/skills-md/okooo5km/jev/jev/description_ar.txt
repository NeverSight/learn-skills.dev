احصل على حكم سريع ورخيص ومصنّف على النص أو JSON عبر أداة jev CLI — احتمال نعم/لا، اختيار واحد من بين التصنيفات، أو درجة ترتيبية — إجابات مُعايرة فقط، دون نص أو شروحات. يمكن تشغيله الآن من سطر الأوامر أو الوكيل، دفعةً واحدة (قرار واحد لكل سطر) وفي سلاسل الأنابيب (رموز الخروج، grep معنوي). استخدمه لتصنيف، فرز، توجيه، تصفية، ترتيب أو وضع علامات جماعية على عناصر مثل البريد الإلكتروني، ملاحظات العملاء، الدردشة أو رسائل المجموعات، التغريدات، السجلات، اختلافات git أو طلبات المستخدم، وكذلك كفلتر مسبق رخيص قبل القراءة المكلفة لنماذج اللغة الكبيرة، كفحص أمان، أو كموجه للنماذج/الوكلاء. 适用：分类、筛选、分诊、路由、打分、是非判断、批量打标签、语义过滤——只要结论，不要解释。ليس للأحكام التي يجب أن تصاحبها شرح أو تحليل أو رد مكتوب؛ ليس للكتابة أو التلخيص أو استخراج النص؛ ليس للرياضيات أو حسابات التاريخ. لتصميم أو برمجة تكامل TypeSafe داخل تطبيق، استخدم مهارة `typesafe-ai` الرسمية. غير رسمي؛ يستدعي نموذج Jev الخاص بـ TypeSafe عبر واجهة برمجة التطبيقات TypeSafe (افتراضيًا) أو OpenRouter.
