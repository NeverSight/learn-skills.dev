jev CLI에서 텍스트나 JSON에 대해 빠르고 저렴하며 타입이 지정된 판단을 얻으세요 — 예/아니오 확률, 레이블 중 하나 선택, 혹은 순서형 점수 — 간결하게 보정된 답변만 제공하고 문장은 절대 제공하지 않습니다. 현재 셸이나 에이전트에서, 대량으로(줄당 하나의 결정) 그리고 파이프라인에서(종료 코드, 의미 기반 grep) 실행됩니다. 이메일, 고객 피드백, 채팅 혹은 그룹 메시지, 트윗, 로그, git diff 또는 사용자 요청과 같은 항목을 분류, 선별, 라우팅, 스크리닝, 순위 매기기, 필터링 또는 대량 라벨링하는 데 사용하고, 비용이 많이 드는 LLM 읽기 전의 저렴한 사전 필터, 가드레일 검사 또는 모델/에이전트 라우터로 활용하세요. 적용 분야: 분류, 필터링, 트리아지, 라우팅, 점수 매기기, 옳고 그름 판단, 대량 라벨링, 의미 필터링 — 결론만 필요하고 설명은 필요하지 않음. 설명, 분석 또는 서면 답변이 반드시 동반되어야 하는 판단에는 사용하지 마세요; 텍스트 작성, 요약 또는 추출에도 사용하지 마세요; 수학이나 날짜 연산에도 사용하지 마세요. 애플리케이션 내부에 TypeSafe 통합을 설계하거나 코딩하려면 공식 `typesafe-ai` 스킬을 사용하세요. 비공식; 기본적으로 TypeSafe API를 통해 TypeSafe의 Jev 모델을 호출하거나 OpenRouter를 사용합니다.
