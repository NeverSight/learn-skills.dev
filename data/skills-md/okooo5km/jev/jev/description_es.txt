Obtén un juicio rápido, barato y tipado sobre texto o JSON usando la CLI jev: una probabilidad sí/no, una opción entre etiquetas o una puntuación ordinal, respuestas calibradas sin prosa ni explicaciones. Funciona ahora desde un shell o agente, en lote (una decisión por línea) y en canalizaciones (códigos de salida, grep semántico). Úsalo para clasificar, triage, enrutar, filtrar, clasificar, puntuar o etiquetar masivamente elementos como correos electrónicos, retroalimentación de clientes, chats o mensajes grupales, tuits, registros, diffs de git o solicitudes de usuarios, y como un pre‑filtro económico antes de una lectura costosa de LLM, una comprobación de guardia o un enrutador de modelo/agente. Aplicable: clasificación, filtrado, triage, enrutamiento, puntuación, juicios de verdadero/falso, etiquetado masivo, filtrado semántico — solo la conclusión, sin explicación. No es adecuado para juicios que requieran explicación, análisis o respuesta escrita; no es para escribir, resumir o extraer texto; ni para matemáticas o cálculos de fechas. Para diseñar o codificar una integración TypeSafe dentro de una aplicación, usa la skill oficial `typesafe‑ai`. No oficial; llama al modelo Jev de TypeSafe a través de la API de TypeSafe (predeterminada) o OpenRouter.
