Générez et modifiez des images raster avec le CLI imagegen via APIMart, gérez les paramètres par défaut de génération locale et comparez les modèles d'images disponibles ainsi que leurs prix. Utilisez-le pour la création d'images, les modifications basées sur des références, la transparence ou la sélection de modèle APIMart ; privilégiez les actifs vectoriels ou de code existants pour les modifications natives à ces formats.
