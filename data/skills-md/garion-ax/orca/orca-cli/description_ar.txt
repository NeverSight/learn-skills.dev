قم بتشغيل شجرات العمل التي يديرها Orca وسياقات المجلدات والطرفيات والمستودعات والأتمتة والملفات الناتجة ومشاركة المهارات وتعليقات شجرة العمل ومتصفح Orca المدمج عبر واجهة سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل هذا على شجرة git العادية أو PTYs المتقطعة أو استخدام الكمبيوتر عندما تكون حالة Orca متورطة. استخدم استخدام الكمبيوتر فقط للنوافذ الخارجية أو واجهة المستخدم المكتبية التي تحتاج إلى تحكم على مستوى نظام التشغيل، واستخدم Playwright أو CDP للصفحات الخارجية.
