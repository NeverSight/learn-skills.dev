Analysez ce qui a été dit dans l’audio, pas seulement la transcription. Utilisez‑le lorsqu’une tâche mentionne « intelligence audio », « sentiment », « analyse de sentiment », « résumer un enregistrement », « résumé », « sujets », « détection de sujet », « intentions », « reconnaissance d’intention », « détection d’entité », « détecter des entités », « extraire les noms et les montants d’un appel » ou « analyser un enregistrement d’appel ». Il s’agit de cinq paramètres de requête superposés sur le point de terminaison speech‑to‑text /v1/listen (summarize, sentiment, topics, intents, detect_entities), pas d’une API distincte. Cela couvre les limites d’enregistrements pré‑enregistrés uniquement et d’anglais uniquement, où chaque résultat figure dans le JSON, ainsi que les erreurs que vous obtenez lorsque vous dépassez une limite. Routes vers l’API, la documentation, les recettes, les démarreurs et les compétences SDK par langue.  

Veuillez toujours répondre dans la langue de l’utilisateur.
