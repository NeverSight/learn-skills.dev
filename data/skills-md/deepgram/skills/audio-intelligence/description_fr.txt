Analysez ce qui a été dit dans l’audio, pas seulement la transcription. Utilisez‑le lorsqu’une tâche mentionne « audio intelligence », « sentiment », « sentiment analysis », « summarize a recording », « summarization », « topics », « topic detection », « intents », « intent recognition », « entity detection », « detect entities », « extract names and amounts from a call » ou « analyze a call recording ». Il s’agit de cinq paramètres de requête superposés sur le point de terminaison speech‑to‑text /v1/listen (summarize, sentiment, topics, intents, detect_entities), et non d’une API distincte. Cela couvre les limites « préréglé uniquement » et « anglais uniquement », où chaque résultat se trouve dans le JSON, ainsi que les erreurs que vous obtenez lorsque vous dépassez une limite. Inclut les chemins vers l’API, la documentation, les recettes, les démarrages rapides et les SDK spécifiques à chaque langue.  

Veuillez toujours répondre dans la langue de l’utilisateur.
