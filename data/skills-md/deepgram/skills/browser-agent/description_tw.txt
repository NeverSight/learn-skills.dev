在瀏覽器中使用四個 Browser Agent SDK 套件執行 Deepgram 語音代理：@deepgram/agents（核心 WebSocket 會話、麥克風、播放器）、@deepgram/react（AgentProvider 與 hooks）、@deepgram/ui（預建的 React 元件），以及 @deepgram/agents-widget（即插即用，無框架）。當任務提及「browser voice agent」「voice widget」「embed a voice agent」「react voice agent」「@deepgram/react」「@deepgram/ui」「agents‑widget」「AgentProvider」「useAgentState」「useDeepgramAgent」「AgentSession」「tokenFactory」「Orb」「voice agent on my website」或詢問如何將 Deepgram API 金鑰保留在客戶端程式碼之外時使用。選擇相應層級，啟動一條路徑，並將其導向底層 WebSocket 合約的 voice‑agent 技能。
