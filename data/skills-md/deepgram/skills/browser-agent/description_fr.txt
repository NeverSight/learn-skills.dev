Exécutez un agent vocal Deepgram dans le navigateur avec les quatre packages SDK Browser Agent : @deepgram/agents (session WebSocket principale, micro, lecteur), @deepgram/react (AgentProvider et hooks), @deepgram/ui (composants React pré‑construits) et @deepgram/agents‑widget (prêt à l’emploi, sans framework). Utilisez‑le lorsqu’une tâche mentionne « browser voice agent », « voice widget », « embed a voice agent », « react voice agent », « @deepgram/react », « @deepgram/ui », « agents‑widget », « AgentProvider », « useAgentState », « useDeepgramAgent », « AgentSession », « tokenFactory », « Orb », « voice agent on my website », ou demande comment garder une clé API Deepgram hors du code côté client. Choisissez la couche, lancez un chemin et orientez‑le vers la compétence voice‑agent pour le contrat WebSocket sous‑jacent. Veuillez toujours répondre dans la langue de l'utilisateur.
