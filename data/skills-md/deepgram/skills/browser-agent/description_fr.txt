Exécutez un agent vocal Deepgram dans le navigateur avec les quatre packages SDK Browser Agent : @deepgram/agents (session WebSocket de base, micro, lecteur), @deepgram/react (AgentProvider et hooks), @deepgram/ui (composants React pré‑construits) et @deepgram/agents‑widget (prêt à l’emploi, aucun framework). Utilisez‑le lorsqu’une tâche mentionne « browser voice agent », « voice widget », « embed a voice agent », « react voice agent », « @deepgram/react », « @deepgram/ui », « agents‑widget », « AgentProvider », « useAgentState », « useDeepgramAgent », « AgentSession », « tokenFactory », « Orb », « voice agent on my website », ou demande comment garder une clé API Deepgram hors du code côté client. Il sélectionne la couche, lance un chemin et dirige vers la compétence voice‑agent pour le contrat WebSocket sous‑jacent.
