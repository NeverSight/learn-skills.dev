شغِّل وكيل صوت Deepgram في المتصفح باستخدام حزم SDK الأربعة للوكيل المتصفح: @deepgram/agents (جلسة WebSocket الأساسية، الميكروفون، المشغل)، @deepgram/react (AgentProvider والهوكات)، @deepgram/ui (مكونات React مسبقة الصنع)، و @deepgram/agents-widget (إدماج مباشر، بدون إطار عمل). استخدم ذلك عندما تقول المهمة "وكيل صوت المتصفح"، "أداة صوتية"، "دمج وكيل صوت"، "وكيل صوت React"، "@deepgram/react"، "@deepgram/ui"، "agents-widget"، "AgentProvider"، "useAgentState"، "useDeepgramAgent"، "AgentSession"، "tokenFactory"، "Orb"، "وكيل صوت على موقعي"، أو عندما تسأل كيف تحافظ على مفتاح Deepgram API بعيدًا عن شفرة الطرف العميل. يختار الطبقة، يُشغّل مسارًا واحدًا، ويوجه إلى مهارة الوكيل الصوتي لعقد WebSocket الموجود تحتها.
