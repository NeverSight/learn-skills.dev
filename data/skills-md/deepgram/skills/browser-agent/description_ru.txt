Запустите голосового агента Deepgram в браузере с помощью четырёх пакетов Browser Agent SDK: @deepgram/agents (основная WebSocket‑сессия, микрофон, плеер), @deepgram/react (AgentProvider и хуки), @deepgram/ui (готовые React‑компоненты) и @deepgram/agents-widget (быстрая интеграция без фреймворка). Используйте, когда задача содержит «browser voice agent», «voice widget», «embed a voice agent», «react voice agent», «@deepgram/react», «@deepgram/ui», «agents-widget», «AgentProvider», «useAgentState», «useDeepgramAgent», «AgentSession», «tokenFactory», «Orb», «voice agent on my website» или когда спрашивают, как скрыть ключ Deepgram API из клиентского кода. Выбирает слой, запускает один путь и перенаправляет к навыку голосового агента для нижележащего контракта WebSocket.
