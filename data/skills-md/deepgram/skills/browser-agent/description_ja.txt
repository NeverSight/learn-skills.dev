ブラウザで Deepgram ボイスエージェントを実行するには、4 つの Browser Agent SDK パッケージを使用します：@deepgram/agents（コア WebSocket セッション、マイク、プレーヤー）、@deepgram/react（AgentProvider とフック）、@deepgram/ui（事前構築済みの React コンポーネント）、@deepgram/agents-widget（ドロップイン、フレームワーク不要）。タスクで「browser voice agent」「voice widget」「embed a voice agent」「react voice agent」「@deepgram/react」「@deepgram/ui」「agents-widget」「AgentProvider」「useAgentState」「useDeepgramAgent」「AgentSession」「tokenFactory」「Orb」「voice agent on my website」などと言及されている場合、または Deepgram API キーをクライアント側コードに残さない方法を尋ねられた場合に使用します。レイヤーを選択し、1 つのパスを実行させ、下層の WebSocket 契約に対して voice‑agent スキルへルーティングします。
