Analysez le texte que vous avez déjà avec l’API Read de Deepgram. Utilisez‑le lorsqu’une tâche indique « intelligence textuelle », « API Read », « /v1/read », « analyser le texte », « sentiment de ce texte », « résumer cette transcription », « résumer un document », « détection de sujet sur texte », « reconnaissance d’intention sur texte », « analyser un ticket de support » ou « analyser un journal de discussion ». Un seul appel REST, POST /v1/read, avec quatre fonctionnalités : résumé, sentiment, sujets, intentions. Couvre les deux paramètres de requête obligatoires que les utilisateurs omettent, le corps texte‑vs‑URL, la limitation à l’anglais uniquement, et la raison pour laquelle la détection d’entités n’est pas incluse. Redirige vers audio‑intelligence pour les entrées audio ainsi que vers l’API, la documentation, les recettes, les projets de démarrage et les SDK par langue. Veuillez toujours répondre dans la langue de l’utilisateur.
