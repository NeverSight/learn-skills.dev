Android APK をリバースエンジニアリング、デブロート、広告除去、パッチ適用、または再署名し、実行時およびサーバ側の挙動を分析する。.apk/.aab/.dex/.so サンプル、smali や dex のパッチ、Frida／objection の実行時フック、再パッケージ化と再署名、広告や SDK トラッカーの除去、モバイルアプリの HTTP API を調査する場合、あるいはクライアント側パッチが目的を達成できるかどうかを判断する必要があるタスクで使用する。リコン、アンチタンパー、広告除去、会員制／ペイウォール制限、dex レベルの外科的パッチ、再パックの落とし穴、デバイス・エミュレータの設定、そして長年の試行錯誤で得た失敗カタログを網羅する。パッチ作業を計画する前に本文を読むこと：冒頭に症状インデックスと最初にクリアすべき四つのゲートがある。
