عكّ كود، إزالة البلوط الزائد، إزالة الإعلانات، تعديل أو إعادة توقيع ملفات APK لنظام أندرويد، وتحليل سلوكها في وقت التشغيل وعلى الخادم. استخدمها عندما تتضمن المهمة عينة .apk/.aab/.dex/.so، أو تعديل smali أو dex، أو ربط Frida/objection في وقت التشغيل، أو إعادة تجميع وتوقيع، أو إزالة الإعلانات أو متتبعات SDK، أو استكشاف واجهة HTTP API لتطبيق الجوال، أو تحديد ما إذا كان تصحيح من جانب العميل قادرًا على تحقيق الهدف. يغطي الاستطلاع، الحماية ضد العبث، إزالة الإعلانات، حدود العضوية/جدران الدفع، تعديل جراحي على مستوى dex، مخاطر إعادة التجميع، إعداد الجهاز والمحاكي، وكاتالوغ الأخطاء المكتسبة بصعوبة. احمل النص قبل التخطيط لأي عمل تصحيح: يبدأ بفهرس الأعراض وأربعة أبواب يجب اجتيازها أولًا.
