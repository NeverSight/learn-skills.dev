Analizza l’intero albero di lavoro non ancora committato (staged, unstaged, untracked), prima mostra un’anteprima, poi esegui il commit in batch secondo la logica; solo quando l’utente richiede esplicitamente di combinare tutto in un unico commit (o di non suddividerlo, ma di effettuare un solo commit) deve essere usata la modalità commit singolo. Il titolo deve utilizzare uno shortcode cz‑emoji e includere un (scope); l’oggetto predefinito è in cinese semplificato.

Quando l’utente richiede: mxcat‑commit, commit code, generate commit message, auto commit, help me commit, auto commit, generate commit, write commit message, code commit, submit code, split commits, batch commit, o esprime “guarda il codice non committato in git, categorizzalo e fai un commit batch”, usa questa funzionalità.

Rispondi sempre nella lingua dell’utente.
