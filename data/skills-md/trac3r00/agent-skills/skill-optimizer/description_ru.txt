Оптимизатор, который уточняет и профессионализирует навыки AI‑агентов через реальное использование — экономит токены, устраняет избыточность и уплотняет инструкции, чтобы навыки стоили меньше при выполнении. Учится на ошибках, проверяет качество и со временем улучшается. Наблюдает за выполнением навыка в текущем разговоре, анализирует до четырёх источников (трения в разговоре, различия файлов, обратная связь пользователей, статическая диагностика) плюс накопленные уроки и предлагает конкретные улучшения в файл SKILL.md целевого навыка. Работает с Claude Code и совместимыми фреймворками агентных навыков на основе SKILL.md. Используйте после выполнения любого навыка: `/skill-optimizer [name]` или `/skill-optimizer` для автоопределения. `--review` обрабатывает накопленные уроки.

Пожалуйста, всегда отвечайте на языке пользователя.
