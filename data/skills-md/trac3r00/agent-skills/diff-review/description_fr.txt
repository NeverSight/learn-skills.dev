Passage de révision mécanique rapide sur un diff unifié avant qu’un humain ou un agent ne le lise. Signale les sorties de débogage laissées dans les chemins de production, les marqueurs TODO/FIXME/HACK ajoutés par le changement, les assertions de test triviales qui ne prouvent rien, ainsi que les tests supprimés. Chaîne les portes sœurs (secret-gate, comment-checker) de sorte qu’une seule commande exécute l’ensemble de la couche mécanique. Déterministe, uniquement bibliothèque standard, lit un diff unifié depuis stdin.
