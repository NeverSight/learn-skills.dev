Schnelle mechanische Überprüfung eines unified diff, bevor ein Mensch oder Agent ihn liest. Kennzeichnet Debug‑Ausgaben, die in Produktionspfaden zurückgelassen wurden, TODO/FIXME/HACK‑Markierungen, die durch die Änderung hinzugefügt wurden, triviale Test‑Assertions, die nichts beweisen, und gelöschte Tests. Kettet Geschwister‑Gates (secret-gate, comment-checker), sodass ein Befehl die gesamte mechanische Ebene ausführt. Deterministisch, nur Standardbibliothek, liest einen unified diff von stdin.
