فرق دلالي بين مستندي JSON يُبلغ عنه عبر مسار JSON — تم الإضافة، الحذف، والتغيير مع القيم القديمة/الجديدة، مع تكرار الكائنات المتداخلة ومقارنة المصفوفات موضعياً. يُستخدم عندما يكون أمر `diff` على JSON عديم فائدة (إعادة ترتيب المفاتيح، ضجيج التنسيق)، لفحوصات انحراف الإعدادات، مقارنة استجابة API، أو للبوابات في CI على المخرجات المتوقعة.
