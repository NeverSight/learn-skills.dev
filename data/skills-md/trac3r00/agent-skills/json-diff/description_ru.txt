Семантическое различие между двумя JSON‑документами, отображаемое с помощью JSON‑path — добавленные, удалённые, изменённые элементы с указанием старых/новых значений, рекурсия по вложенным объектам и позиционное сравнение массивов. Используйте, когда `diff` для JSON бессмыслен из‑за перестановки ключей и шума форматирования, для проверки отклонения конфигурации, сравнения ответов API или контроля CI на ожидаемый вывод.
