Diff sémantique entre deux documents JSON signalé par le chemin JSON — ajouts, suppressions, modifications avec les anciennes/nouvelles valeurs, en parcourant récursivement les objets imbriqués et en comparant les tableaux positionnellement. À utiliser lorsque `diff` sur JSON est inutile (réarrangement des clés, bruit de formatage), pour les vérifications de dérive de configuration, la comparaison de réponses d’API, ou les portes CI sur la sortie attendue.
