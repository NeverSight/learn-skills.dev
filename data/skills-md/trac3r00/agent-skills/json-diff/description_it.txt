Diff semantico tra due documenti JSON segnalato tramite JSON path — aggiunti, rimossi, modificati con valori vecchi/nuovi, ricorsivamente negli oggetti nidificati e confrontando gli array posizionalmente. Da usare quando il `diff` su JSON è inutile (riordino delle chiavi, rumore di formattazione), per controlli di deriva della configurazione, confronto delle risposte API o gate CI sull'output atteso.
