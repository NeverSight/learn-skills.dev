Diferencia semántica entre dos documentos JSON reportada por ruta JSON — añadido, eliminado, modificado con valores antiguo/nuevo, recursivamente en objetos anidados y comparando arreglos posicionalmente. Úsalo cuando `diff` en JSON es inútil (reordenamiento de claves, ruido de formato), para verificaciones de deriva de configuración, comparación de respuestas de API o puertas CI sobre la salida esperada.
