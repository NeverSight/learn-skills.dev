Extrait le texte brut des documents Office et Web sans aucune dépendance — docx, pptx, xlsx, html, markdown et texte brut, en utilisant uniquement la stdlib de Python (zipfile + xml.etree). Pas de LibreOffice, pas de python-docx, pas de réseau. Les PDF font appel à pdftotext lorsqu’il est installé, en signalant honnêtement son absence. À utiliser lorsqu’un agent doit lire, résumer ou comparer des documents sans installer d’outils de traitement de documents.
