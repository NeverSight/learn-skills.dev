Extrae texto plano de documentos de oficina y web sin dependencias — docx, pptx, xlsx, html, markdown y texto plano, usando solo la biblioteca estándar de Python (zipfile + xml.etree). Sin LibreOffice, sin python-docx, sin red. PDF delega a pdftotext cuando está instalado, informando honestamente cuando no lo está. Úsalo cuando un agente necesita leer, resumir o comparar documentos sin instalar herramientas de documentos.
