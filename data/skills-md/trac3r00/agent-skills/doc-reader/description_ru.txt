Извлекает простой текст из офисных и веб‑документов без зависимостей — docx, pptx, xlsx, html, markdown и обычный текст, используя только стандартную библиотеку Python (zipfile + xml.etree). Нет LibreOffice, нет python-docx, без сети. Для PDF используется pdftotext, если он установлен, и честно сообщает, когда его нет. Используйте, когда агенту нужно читать, суммировать или сравнивать документы без установки дополнительных средств работы с документами.
