Extrahiert Klartext aus Office‑ und Web‑Dokumenten ohne Abhängigkeiten — docx, pptx, xlsx, html, markdown und Klartext, wobei nur die Python‑Standardbibliothek (zipfile + xml.etree) verwendet wird. Kein LibreOffice, kein python‑docx, kein Netzwerk. PDF wird an pdftotext delegiert, wenn es installiert ist, andernfalls wird dies ehrlich gemeldet. Verwenden Sie es, wenn ein Agent Dokumente lesen, zusammenfassen oder vergleichen muss, ohne Dokumenten‑Tools zu installieren.
