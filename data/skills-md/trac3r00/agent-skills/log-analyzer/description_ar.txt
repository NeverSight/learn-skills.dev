يقوم بتجميع أخطاء ملف السجل وفق النمط وترتيب المخالفين — يُطبع الرموز المتقلبة (طوابع الوقت، UUIDs، عناوين IP، المسارات، الأرقام) بحيث تُحسب "connection refused to db-01" و "db-99" كمشكلة واحدة تُرى N مرة. يدعم كلًا من السجلات الموسومة بمستوى (ERROR/WARN/INFO) وسجلات الأخطاء بنمط الاستثناء (DaemonError:, Traceback). يعمل دون اتصال، باستخدام مكتبة Python القياسية فقط، وبشكل حتمي.
