Erkennt benutzerdefinierte Skills über alle auf dem System installierten KI-Anbieter hinweg — Claude Code, Codex, OMO, gjc, OpenCode, Gemini, Cursor, Factory und Plugin‑Caches — und fasst sie in einem einzigen universellen Verzeichnis zusammen (standardmäßig mittels Symlinks), sodass jeder SKILL.md‑lesende Agent sie alle nutzen kann.
