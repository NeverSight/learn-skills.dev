Обнаруживает пользовательские навыки во всех установках провайдеров ИИ на машине — Claude Code, Codex, OMO, gjc, OpenCode, Gemini, Cursor, Factory и кэши плагинов — и объединяет их в один универсальный каталог (по умолчанию с символическими ссылками), чтобы любой агент, читающий SKILL.md, мог использовать их все. Сообщает происхождение, устраняет дубликаты по имени и разрешённому пути и выявляет конфликты между провайдерами.
