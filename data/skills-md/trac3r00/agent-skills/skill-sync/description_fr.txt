Découvre les compétences personnalisées sur chaque installation de fournisseur d'IA de la machine — Claude Code, Codex, OMO, gjc, OpenCode, Gemini, Cursor, Factory et les caches de plugins — et les unifie dans un répertoire universel (liens symboliques par défaut) afin que tout agent lisant SKILL.md puisse les utiliser toutes. Signale la provenance, déduplique par nom et chemin résolu, et met en évidence les conflits entre fournisseurs.
