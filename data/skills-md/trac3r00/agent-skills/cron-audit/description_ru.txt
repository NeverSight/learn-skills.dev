Разбирает crontab, раскрывает каждое расписание в конкретные значения, объясняет каждую задачу простыми словами и помечает неверные строки, невозможные расписания и слишком частые задачи. Синтаксис crontab обычно только для записи; этот инструмент делает его читаемым. Только стандартная библиотека, детерминировано.
