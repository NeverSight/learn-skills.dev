Отправляет реальные HTTP‑запросы и проверяет ответы в соответствии с ожиданиями — код статуса, значения полей JSON (путь в dot‑нотации), лимит задержки, тип контента — используя stdlib urllib, без библиотеки requests и без subprocess‑curl. Используйте для проверки конечных точек из CI или сеанса агента, дымового теста развертывания или подтверждения того, что API работает как документировано, перед дальнейшей разработкой.
