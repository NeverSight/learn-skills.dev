Lanza solicitudes HTTP reales y valida las respuestas contra las expectativas — código de estado, valores de campos JSON (rutas en notación de punto), presupuesto de latencia, tipo de contenido — usando la biblioteca estándar urllib, sin la biblioteca requests, sin subproceso curl. Úsalo para verificar endpoints desde CI o una sesión de agente, hacer pruebas de humo de un despliegue o demostrar que una API se comporta según la documentación antes de construir sobre ella.
