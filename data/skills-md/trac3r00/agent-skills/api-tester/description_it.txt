Esegue richieste HTTP reali e valida le risposte rispetto alle aspettative — codice di stato, valori dei campi JSON (percorsi in notazione puntata), budget di latenza, content‑type — usando urllib della libreria standard, senza la libreria requests, senza subprocess curl. Usalo per verificare gli endpoint da CI o da una sessione agente, per eseguire un smoke test di un deployment, o per dimostrare che un’API si comporta come documentato prima di costruirci sopra.
