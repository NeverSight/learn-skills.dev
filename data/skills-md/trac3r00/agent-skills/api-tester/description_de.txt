Sendet echte HTTP‑Anfragen und prüft die Antworten anhand von Erwartungen — Statuscode, JSON‑Feldwerte (Pfade in Punktnotation), Latenzbudget, Content‑Type — mit der stdlib‑urllib, ohne Requests‑Bibliothek, ohne curl‑Subprozess. Wird verwendet, um Endpunkte aus CI oder einer Agentensitzung zu verifizieren, ein Deployment als Smoke‑Test zu prüfen oder zu beweisen, dass eine API wie dokumentiert funktioniert, bevor darauf aufgebaut wird.
