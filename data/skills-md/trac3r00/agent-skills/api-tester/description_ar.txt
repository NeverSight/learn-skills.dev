يطلق طلبات HTTP حقيقية ويُصَدِّق الردود مقابل التوقعات — رمز الحالة، قيم حقول JSON (مسارات بنمط النقاط)، ميزانية الزمان، نوع المحتوى — باستخدام urllib من مكتبة Python القياسية، دون مكتبة requests ولا استدعاء curl كعملية فرعية. يُستخدم للتحقق من نقاط النهاية من CI أو جلسة وكيل، لاختبار سريع للنشر، أو لإثبات أن واجهة برمجة التطبيقات تعمل وفق المستندات قبل البناء عليها.
