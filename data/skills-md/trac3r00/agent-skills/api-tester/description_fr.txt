Envoie de vraies requêtes HTTP et valide les réponses par rapport aux attentes — code d’état, valeurs des champs JSON (chemins en notation pointée), budget de latence, type de contenu — avec urllib de la bibliothèque standard, sans la bibliothèque requests, sans sous‑processus curl. À utiliser pour vérifier les points de terminaison depuis le CI ou une session d’agent, réaliser un test de fumée d’un déploiement, ou prouver qu’une API se comporte comme documenté avant de s’appuyer dessus.
