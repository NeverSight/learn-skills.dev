Évalue la structure d’un CV, l’impact quantifié et la couverture des mots‑clés ATS par rapport à une description de poste. Lit le markdown ou le texte brut (convertir d’abord le PDF / docx avec doc‑reader) et vérifie les informations de contact, les sections standard, le ratio de puces quantifiées, les débuts par verbe d’action, les formulations faibles (« responsible for »), et — étant donné une JD — quels mots‑clés requis sont manquants. Hors ligne, déterministe, sans LLM.
