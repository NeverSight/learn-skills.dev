Навык эскалации для заблокированного или труднодоступного веб‑доступа — загружайте его, когда обычный просмотр/запрос блокируется (WAF, 403, Cloudflare, рендеринг только через JS, требующий входа, или платформа, которую обычный fetcher не может прочитать). Многоуровневый роутер: УРОВЕНЬ 1 безумный‑поиск (безголовое извлечение + обход WAF через curl_cffi TLS‑имперсонацию, yt‑dlp, Jina Reader, публичные API, запасной Playwright с реальным Chrome); УРОВЕНЬ 1.5 агент‑доступ (чтение платформ‑родных для китайских и социальных сервисов: Xiaohongshu, Douyin, Weibo, Bilibili, V2EX, WeChat, а также Twitter/Reddit/LinkedIn/GitHub); УРОВЕНЬ 2 Chrome stealth (CloakBrowser stealth Chromium + агент‑браузер CDP для кликов, форм, скриншотов, видео, входа через куки). Триггеры: заблокированный сайт, обход обнаружения ботов, обход Cloudflare/WAF, скрейпинг, скрытый браузер, импорт куки, заполнение формы, скриншот, воспроизведение YouTube, Xiaohongshu, Douyin, Weibo, Bilibili, V2EX, статья WeChat, транскрипт подкаста. НЕ предназначено для простых поисков (используйте web-search) или обычных запросов (используйте webfetch).
