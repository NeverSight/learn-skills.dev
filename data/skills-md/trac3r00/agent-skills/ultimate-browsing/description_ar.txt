مهارة التصعيد للوصول إلى الويب المحجوب أو الصعب الوصول إليه — يتم تحميلها عندما يُحَجَب التصفح/الاستدعاء العادي (WAF، 403، Cloudflare، عرض JavaScript فقط، حجب الدخول، أو منصة لا يستطيع المستدعي العام قراءتها). موجه متعدد المستويات: المستوى 1 البحث الجنوني (استخراج بدون رأس + تجاوز WAF عبر تزوير TLS باستخدام curl_cffi، yt‑dlp، Jina Reader، واجهات برمجة التطبيقات العامة، fallback إلى Playwright الحقيقي‑Chrome)؛ المستوى 1.5 الوصول عبر الوكيل (قراء مدمجون للمنصات الصينية والاجتماعية: Xiaohongshu، Douyin، Weibo، Bilibili، V2EX، WeChat، بالإضافة إلى Twitter/Reddit/LinkedIn/GitHub)؛ المستوى 2 التسلل عبر Chrome (CloakBrowser المتخفي على Chromium + CDP للمتصفح الوكيل للنقرات، النماذج، لقطات الشاشة، الفيديو، تسجيل الدخول عبر الكوكيز). المشغلات: موقع محجوب، تجاوز كشف الروبوتات، تجاوز Cloudflare/WAF، استخراج البيانات، المتصفح المتخفي، استيراد الكوكيز، ملء نموذج، لقطة شاشة، تشغيل يوتيوب، Xiaohongshu، Douyin، Weibo، Bilibili، V2EX، مقال WeChat، نص بودكاست. ليس للأبحاث البسيطة (استخدم web‑search) أو الاستدعاءات العادية (استخدم webfetch).
