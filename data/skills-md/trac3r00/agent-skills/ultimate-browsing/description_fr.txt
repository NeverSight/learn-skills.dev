Compétence d'escalade pour un accès web bloqué ou difficile d’accès — chargez‑la lorsqu’une navigation ou récupération normale est bloquée (WAF, 403, Cloudflare, rendu uniquement en JavaScript, accès limité par connexion, ou une plateforme qu’un récupérateur générique ne peut pas lire). Routeur à niveaux : NIVEAU 1 recherche‑extrême (extraction sans tête + contournement WAF via impersonation TLS curl_cffi, yt‑dlp, Jina Reader, API publiques, repli Playwright Chrome réel) ; NIVEAU 1,5 portée‑agent (lecteurs natifs pour les plateformes chinoises et sociales : Xiaohongshu, Douyin, Weibo, Bilibili, V2EX, WeChat, ainsi que Twitter/Reddit/LinkedIn/GitHub) ; NIVEAU 2 furtivité Chrome (CloakBrowser Chromium furtif + CDP du navigateur‑agent pour clics, formulaires, captures d’écran, vidéo, connexion par cookie). Déclencheurs : site bloqué, contournement de la détection de bots, contournement Cloudflare/WAF, extraction, navigateur furtif, importation de cookies, remplissage de formulaire, capture d’écran, lecture YouTube, Xiaohongshu, Douyin, Weibo, Bilibili, V2EX, article WeChat, transcription de podcast. PAS pour des recherches simples (utilisez web‑search) ou des récupérations directes (utilisez webfetch).
