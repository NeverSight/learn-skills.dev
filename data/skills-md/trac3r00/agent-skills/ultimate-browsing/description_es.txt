Habilidad de escalada para acceso web bloqueado o de difícil alcance — cárgala cuando una navegación u obtención normal está bloqueada (WAF, 403, Cloudflare, renderizado solo con JS, acceso mediante inicio de sesión, o una plataforma que un buscador genérico no puede leer). Enrutador por niveles: TIER 1 búsqueda extrema (extracción sin cabeza + elusión de WAF mediante suplantación TLS con curl_cffi, yt‑dlp, Jina Reader, APIs públicas, alternativa Playwright con Chrome real); TIER 1.5 alcance de agente (lectores nativos para plataformas chinas y sociales: Xiaohongshu, Douyin, Weibo, Bilibili, V2EX, WeChat, además de Twitter/Reddit/LinkedIn/GitHub); TIER 2 Chrome sigiloso (CloakBrowser Chromium sigiloso + CDP de agente‑navegador para clics, formularios, capturas de pantalla, video, inicio de sesión con cookies). Activadores: sitio bloqueado, elusión de detección de bots, elusión de Cloudflare/WAF, raspado, navegador sigiloso, importación de cookies, rellenar formulario, captura de pantalla, reproducir YouTube, Xiaohongshu, Douyin, Weibo, Bilibili, V2EX, artículo de WeChat, transcripción de podcast. NO es para búsquedas simples (usa web‑search) ni para peticiones simples (usa webfetch).
