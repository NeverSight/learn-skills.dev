Génère un RULE.md à partir de l'historique des sessions IA d'un projet en extrayant chaque fois que l'humain a corrigé l'agent — « non, n'utilisez jamais jwt », « exécutez toujours les tests d'abord », « nous utilisons des sessions, pas des tokens ». Le fichier de contexte le plus performant qu'un projet puisse avoir est celui construit à partir de son propre historique d'erreurs. Lit les magasins Claude Code, Codex et OpenCode (mêmes conventions que session‑handoff), entièrement hors ligne.

Veuillez toujours répondre dans la langue de l'utilisateur.
