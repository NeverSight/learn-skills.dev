Barrière de compréhension avant le portage, la copie ou l'adaptation d'une implémentation existante. Elle prouve que l'utilisateur a compris le code de référence avant d'écrire tout nouveau code. À utiliser lorsque la tâche est « porter X », « copier la façon dont Y le fait », « adapter Z » ou réimplémenter un comportement existant.
