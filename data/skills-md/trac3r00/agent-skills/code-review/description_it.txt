Protocollo di revisione del codice rigido e gelido — nulla è dato per scontato, tutto è messo in discussione, ogni affermazione richiede prove. Revisiona un diff o un set di modifiche per correttezza, sicurezza, gestione degli errori, contratti API, prestazioni e integrità dei test, con valutazioni di gravità obbligatorie e una regola di nessun timbro di approvazione automatica. La fase di revisione guidata dall'LLM che i controlli meccanici di diff‑review non possono eseguire.
