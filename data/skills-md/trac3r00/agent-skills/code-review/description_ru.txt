Строгий, холодный как лёд протокол рецензирования кода — ничего не считается само собой разумеющимся, всё ставится под вопрос, каждое утверждение требует доказательств. Обзор диффа или набора изменений охватывает корректность, безопасность, обработку ошибок, контракт API, производительность и целостность тестов, с обязательной оценкой тяжести и правилом «без автоподписей». Это LLM‑управляемый проход рецензии, который не способны выполнить механические проверки дифф‑ревью.
