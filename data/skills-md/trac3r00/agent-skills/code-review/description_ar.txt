بروتوكول مراجعة الكود الصارم والبارد كالثلج — لا يُفترض شيء، كل شيء يُستجوب، كل ادعاء يتطلب دليلًا. يراجع الفرق أو مجموعة التغييرات من حيث الصحة، الأمان، معالجة الأخطاء، عقود الـ API، الأداء، وسلامة الاختبارات، مع تصنيفات شدة إلزامية وقاعدة عدم الختم السريع. هو مرور المراجعة المدفوع بالذكاء الاصطناعي الذي لا تستطيع الفحوص الميكانيكية لـ diff‑review القيام به.
