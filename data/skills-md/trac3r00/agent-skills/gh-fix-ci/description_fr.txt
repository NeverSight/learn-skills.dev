Utilisez lorsque l'utilisateur demande de déboguer ou de corriger des vérifications de PR GitHub qui échouent dans GitHub Actions ; utilisez `gh` pour inspecter les vérifications et les journaux, résumez le contexte de l’échec, rédigez un plan de correction et ne l’implémentez qu’après une approbation explicite. Considérez les fournisseurs externes (par exemple Buildkite) comme hors de portée et ne signalez que l’URL des détails.

Veuillez toujours répondre dans la langue de l'utilisateur.
