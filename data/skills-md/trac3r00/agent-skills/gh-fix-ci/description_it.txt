Usa quando un utente chiede di effettuare il debug o correggere i controlli PR di GitHub che falliscono e vengono eseguiti in GitHub Actions; usa `gh` per ispezionare i controlli e i log, riassumi il contesto del fallimento, redigi un piano di correzione e implementalo solo dopo un'esplicita approvazione. Considera i provider esterni (ad esempio Buildkite) fuori dal campo di competenza e segnala solo l'URL dei dettagli.

Per favore, rispondi sempre nella lingua dell'utente.
