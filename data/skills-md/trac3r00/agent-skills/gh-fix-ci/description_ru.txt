Использовать, когда пользователь просит отладить или исправить не проходящие проверки PR в GitHub, которые запускаются в GitHub Actions; использовать `gh` для просмотра проверок и журналов, суммировать контекст ошибки, подготовить план исправления и реализовать его только после явного одобрения. Считайте внешних провайдеров (например, Buildkite) вне зоны ответственности и указывайте только URL с деталями.

Всегда отвечайте на языке пользователя.
