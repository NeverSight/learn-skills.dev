استخدامه عندما يطلب المستخدم تصحيح أو إصلاح فحوصات طلب السحب الفاشلة التي تُجري في GitHub Actions؛ استخدم `gh` لفحص الفحوصات والسجلات، لخص سياق الفشل، ضع خطة إصلاح، ونفّذ فقط بعد الموافقة الواضحة. اعتبر الموفرين الخارجيين (مثل Buildkite) خارج النطاق وقدم فقط عنوان URL للتفاصيل.

يرجى دائمًا الرد بلغة المستخدم.
