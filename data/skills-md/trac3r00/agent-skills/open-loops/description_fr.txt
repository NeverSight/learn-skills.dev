Extrait les engagements non résolus, les reports, les décisions et les questions ouvertes d’une transcription de conversation dans un petit registre JSON — afin qu’une autre interface (une tâche cron, un déclencheur, une nouvelle session) puisse les récupérer au lieu de les perdre. À utiliser pour transmettre le contexte entre surfaces, ou pour conditionner le transfert d’une session/thread à la quantité de points laissés en suspens.
