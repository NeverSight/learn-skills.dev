Учёт токенов и сессий между клиентами. Каждый клиент AI‑агента фиксирует, что он потребил — JSONL‑файлы использования Claude Code по сообщениям, события token_count в Codex, столбцы токенов по сессиям в OpenCode — но ни один из них не показывает общий итог по всем клиентам. Читает те же локальные хранилища, что и передача сессии (только для чтения, ничего не загружается) и выводит отчёт о токенах по модели, клиенту и проекту, с необязательным ограничителем бюджета.
