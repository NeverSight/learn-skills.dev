Transfère le contexte de travail entre les clients d'agents IA. Lit les journaux de session depuis le magasin natif de chaque client installé (projets Claude Code JSONL, déploiement Codex JSONL, OpenCode SQLite, discussions Gemini CLI) et crée un briefing de passation portable — ce qui a été demandé, ce qui a été fait, les fichiers touchés, l’état final — afin qu’une session dans un client puisse poursuivre le travail commencé dans un autre. À utiliser lors du changement de client en cours de tâche (« transfère tout ce sur quoi j’ai travaillé dans Codex vers cette session Claude »), lors d’une reprise après plusieurs jours d’absence, ou pour auditer ce qu’un client a fait récemment.
