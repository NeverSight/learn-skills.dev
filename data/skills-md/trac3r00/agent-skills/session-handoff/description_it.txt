Trasporta il contesto di lavoro tra i client di agenti IA. Legge i log delle sessioni da tutti i repository nativi dei client installati (progetti Claude Code JSONL, rollout Codex JSONL, OpenCode SQLite, chat Gemini CLI) e produce un briefing di passaggio portatile — cosa è stato richiesto, cosa è stato fatto, file toccati, ultimo stato — così una sessione in un client può continuare il lavoro iniziato in un altro. Usalo quando si cambia client a metà compito (“porta tutto quello su cui ho lavorato in Codex in questa sessione Claude”), riprendendo dopo giorni di assenza, o per verificare cosa ha fatto recentemente qualsiasi client.
