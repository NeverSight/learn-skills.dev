Переносит контекст работы между клиентами ИИ‑агентов. Читает журналы сессий из нативного хранилища каждого установленного клиента (проекты Claude Code в формате JSONL, развертывание Codex в JSONL, OpenCode SQLite, чаты Gemini CLI) и формирует переносимый брифинг — что запрашивалось, что было сделано, какие файлы затронуты, последнее состояние — чтобы сессия в одном клиенте могла продолжить работу, начатую в другом. Используйте при переключении клиентов в середине задачи («перенеси всё, над чем я работал в Codex, в эту сессию Claude»), при возобновлении спустя несколько дней или при аудите недавних действий любого клиента.  

Пожалуйста, всегда отвечайте на языке пользователя.
