Herdr をドライブし、AI コーディングエージェント用のターミナルワークスペースマネージャーを任意のエージェントクライアント（Claude Code、Codex、pi/senpi、Gemini、OpenCode、Kimi、Grok、Cursor、Hermes など）から操作します。ワークスペース、タブ、ペイン、エージェントのライフサイクル、ワークツリー、リモートマシン、統合、設定、そして 103 メソッドのソケット API まで、全ての領域をカバーしています。そのため、クライアントはターミナルレイアウトを構築し、兄弟エージェントを開始・プロンプトし、出力を読み取り、状態変化を待機し、並行作業を調整できます。ユーザーが Herdr と言及したとき、またはペイン、タブ、兄弟エージェント、永続的なターミナルセッションの検査や制御が必要なときに使用してください。
