Управляйте Herdr, менеджером терминальных рабочих пространств для AI‑агентов, пишущих код, из любого клиентского агента (Claude Code, Codex, pi/senpi, Gemini, OpenCode, Kimi, Grok, Cursor, Hermes и других). Охватывает всю поверхность — рабочие пространства, вкладки, панели, жизненный цикл агента, рабочие деревья, удалённые машины, интеграции, конфигурацию и API сокетов с 103 методами — чтобы клиент мог строить макет терминала, запускать и запрашивать соседних агентов, читать их вывод, ожидать изменения состояния и координировать параллельную работу. Используйте, когда пользователь упоминает Herdr или когда необходимо проинспектировать или контролировать панели, вкладки, соседних агентов или постоянную терминальную сессию.
