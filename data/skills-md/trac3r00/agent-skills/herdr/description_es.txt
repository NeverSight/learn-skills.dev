Controla Herdr, un gestor de espacios de trabajo de terminal para agentes de codificación de IA, desde cualquier cliente de agente (Claude Code, Codex, pi/senpi, Gemini, OpenCode, Kimi, Grok, Cursor, Hermes y más). Cubre toda la superficie: espacios de trabajo, pestañas, paneles, ciclo de vida del agente, árboles de trabajo, máquinas remotas, integraciones, configuración y la API de socket de 103 métodos, de modo que un cliente pueda construir la disposición del terminal, iniciar y solicitar agentes hermanos, leer su salida, esperar cambios de estado y coordinar trabajo paralelo. Úsalo cuando el usuario mencione Herdr o cuando sea necesario inspeccionar o controlar paneles, pestañas, agentes hermanos o una sesión de terminal persistente.
