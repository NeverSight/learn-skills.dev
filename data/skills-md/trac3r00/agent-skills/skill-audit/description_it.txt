Esegue una scansione di sicurezza delle skill di agenti di terze parti prima di fidarti di esse. Un SKILL.md è un'autorizzazione eseguibile — gli agenti lo seguono con le tue credenziali e il file system. Rileva schemi di iniezione di prompt (sovrascritture di istruzioni, direttive di occultamento), firme di esfiltrazione dei dati (percorsi sensibili + invii di rete) e pattern di script pericolosi (pipe-to-shell, eval-on-download) in qualsiasi directory di skill. Offline, deterministico, solo stdlib.
