Scannez la sécurité des compétences d'agents tiers avant de leur faire confiance. Un SKILL.md est une autorité exécutable — les agents le suivent avec vos identifiants et votre système de fichiers. Détecte les modèles d'injection de prompt (remplacements d'instructions, directives de dissimulation), les signatures d'exfiltration de données (chemins sensibles + envois réseau) et les modèles de script dangereux (pipe-vers-shell, éval-sur-téléchargement) dans n'importe quel répertoire de compétences. Hors ligne, déterministe, uniquement la bibliothèque standard. Veuillez toujours répondre dans la langue de l'utilisateur.
