Auditieren Sie das pro‑Turn‑Kontextfenster eines KI‑Agents wie eine Kostenstelle – ordnen Sie, was tatsächlich Token verbraucht (Systemprompt, Fähigkeiten, Speicher, Werkzeug‑Schemata, Gate‑Code) und lassen Sie die CI fehlschlagen, wenn der Agent dicker wird. Verwenden Sie das, wenn die Token‑Kosten bei einem langfristig laufenden autonomen Agenten steigen oder Sie eine Kontext‑Aufblähung vermuten.
