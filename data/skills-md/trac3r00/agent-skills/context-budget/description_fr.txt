Auditez la fenêtre de contexte à chaque tour d’un agent IA comme un centre de coûts : classez ce qui consomme réellement les jetons (prompt système, compétences, mémoire, schémas d’outils, code de porte) et faites échouer l’intégration continue lorsque l’agent grossit. Utilisez cela lorsque les coûts en jetons augmentent sur un agent autonome de longue durée ou que vous suspectez un gonflement du contexte.
