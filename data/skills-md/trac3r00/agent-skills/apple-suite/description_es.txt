Automatiza aplicaciones de macOS mediante AppleScript y esquemas de URL — Notas, Recordatorios, Mapas, Mail, Calendario, Terminal, Atajos, Contactos, Fotos, búsqueda en la App Store y Teléfono. Se ejecuta localmente a través de osascript sin claves API y sin conexión de red para las operaciones de AppleScript. La capacidad de script de cada aplicación se evalúa de forma honesta; las aplicaciones no scriptables (VoiceMemos, Passwords, Find My, Activity Monitor, listado de la App Store) se documentan con sus limitaciones reales en lugar de fingir.
