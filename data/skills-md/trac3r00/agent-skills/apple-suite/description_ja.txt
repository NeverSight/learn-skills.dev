AppleScript と URL スキームを使用して macOS アプリを自動化します — メモ、リマインダー、マップ、メール、カレンダー、ターミナル、ショートカット、連絡先、フォト、App Store 検索、電話。osascript を介してローカルで実行し、API キーやネットワークを使用せずに AppleScript 操作を行います。各アプリのスクリプタビリティは正直に評価されています。スクリプト対応できないアプリ（VoiceMemos、Passwords、Find My、Activity Monitor、App Store リスティング）は、偽らずに実際の制限を文書化しています。
