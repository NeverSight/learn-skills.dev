Automatise les applications macOS via AppleScript et les schémas d’URL — Notes, Rappels, Plans, Mail, Calendrier, Terminal, Raccourcis, Contacts, Photos, recherche dans l’App Store et Téléphone. S’exécute localement via osascript sans clés API et sans réseau pour les opérations AppleScript. La scriptabilité de chaque application est évaluée honnêtement ; les applications non scriptables (Mémos vocaux, Mots de passe, Localiser, Moniteur d’activité, liste de l’App Store) sont documentées avec leurs véritables limitations plutôt que falsifiées.

Veuillez toujours répondre dans la langue de l’utilisateur.
