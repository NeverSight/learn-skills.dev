يقوم بأتمتة تطبيقات macOS عبر AppleScript ومخططات URL — الملاحظات، التذكيرات، الخرائط، البريد، التقويم، الطرفية، الاختصارات، جهات الاتصال، الصور، بحث متجر التطبيقات، والهاتف. يعمل محليًا من خلال osascript دون الحاجة إلى مفاتيح API ولا شبكة للعمليات الخاصة بـ AppleScript. يتم تقييم قابلية البرمجة لكل تطبيق بصراحة؛ التطبيقات غير القابلة للبرمجة (VoiceMemos، Passwords، Find My، Activity Monitor، قائمة متجر التطبيقات) يتم توثيقها بحدودها الفعلية بدلاً من تزويرها. يرجى دائمًا الرد بلغة المستخدم.
