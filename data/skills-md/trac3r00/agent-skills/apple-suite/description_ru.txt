Автоматизирует приложения macOS с помощью AppleScript и URL‑схем — Notes, Reminders, Maps, Mail, Calendar, Terminal, Shortcuts, Contacts, Photos, поиск в App Store и Phone. Работает локально через osascript без API‑ключей и без сети для операций AppleScript. Возможности скриптования каждого приложения оцениваются честно; несценарируемые приложения (VoiceMemos, Passwords, Find My, Activity Monitor, список App Store) документируются с их реальными ограничениями, а не подделываются.
