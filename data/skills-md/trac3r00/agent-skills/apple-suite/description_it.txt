Automatizza le app macOS tramite AppleScript e schemi URL — Note, Promemoria, Maps, Mail, Calendario, Terminale, Scorciatoie, Contatti, Foto, ricerca App Store e Telefono. Viene eseguito localmente tramite osascript senza chiavi API e senza rete per le operazioni AppleScript. La scriptabilità di ogni app è valutata onestamente; le app non scriptabili (Memo vocali, Password, Trova i miei, Monitoraggio attività, elenco App Store) sono documentate con le loro reali limitazioni invece di essere falsificate.
