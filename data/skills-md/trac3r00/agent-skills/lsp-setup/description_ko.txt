특정 언어에 대한 Language Server(LSP)를 구성하여 에디터·에이전트 도구—진단, 정의로 이동, 참조 찾기, 이름 바꾸기—가 정상적으로 동작하도록 합니다. 다음과 같은 경우에 사용합니다: LSP를 설정하거나, lsp 설정을 수행하거나, 언어 서버를 설치·구성하거나, ‘no LSP server configured’·‘server not installed’ 오류를 해결하거나, 서버 간 선택( basedpyright vs pyright vs ty vs ruff )을 해야 할 때, 혹은 .codex/lsp-client.json·.opencode/lsp.json 파일을 연결할 때. 언어서버 설정. 파일 확장자별로 references/<language>/README.md 로 라우팅해 정확한 내장 서버를 확인하고, OS별 설치 명령(macOS·Linux·Windows), 두 구성 파일에 대한 설정 스니펫, 초기화 옵션, 대안, 문제 해결 방법을 제공합니다. 포함된 스크립트: detect-lsp.ts(프로젝트 내 언어와 각 서버의 설치·구성 상태를 스캔)와 verify-lsp.ts(실제 진단 라운드트립 실행). 지원 언어: typescript, python, go, rust, c/c++, java, kotlin, c#/razor, swift, ruby, php, dart, elixir, zig, lua, bash, yaml, terraform, haskell, julia.
