Настройте языковой сервер (LSP) для конкретного языка, чтобы инструменты редактора/агента — диагностика, переход к определению, поиск ссылок, переименование — работали. Используйте, когда нужно: настроить LSP, выполнить настройку LSP, установить или настроить языковой сервер, исправить сообщения «no LSP server configured» / «server not installed», выбрать между серверами (basedpyright vs pyright vs ty vs ruff) или подключить .codex/lsp-client.json / .opencode/lsp.json. Настройка языкового сервера. Маршрутизация по расширению файла к references/<language>/README.md для точного встроенного сервера, команды установки для каждой ОС (macOS/Linux/Windows), фрагменты конфигурации для обоих файлов конфигурации, параметры инициализации, альтернативы и устранение неполадок. Поставляются скрипты: detect-lsp.ts (сканирует проект на наличие языков и проверяет статус установки/конфигурации каждого сервера) и verify-lsp.ts (выполняет реальный раунд диагностики). Поддерживаются TypeScript, Python, Go, Rust, C/C++, Java, Kotlin, C#/Razor, Swift, Ruby, PHP, Dart, Elixir, Zig, Lua, Bash, YAML, Terraform, Haskell, Julia.
