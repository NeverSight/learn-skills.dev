特定の言語用に Language Server (LSP) を構成し、エディタ/エージェントのツール（診断、定義へジャンプ、参照検索、リネーム）が機能するようにします。以下のような場合に使用します：LSP の設定、lsp のセットアップ、言語サーバーの導入またはインストール、'no LSP server configured' / 'server not installed' のエラー修正、サーバー間の選択（basedpyright vs pyright vs ty vs ruff）、または .codex/lsp-client.json / .opencode/lsp.json の配線。언어서버 설정。ファイル拡張子ごとに references/<language>/README.md へルーティングし、正確な組み込みサーバーを示します。OS 別のインストールコマンド（macOS/Linux/Windows）、両方の設定ファイル用の設定スニペット、初期化オプション、代替案、トラブルシューティングを提供します。付属スクリプトとして detect-lsp.ts（プロジェクト内の言語をスキャンし、各サーバーのインストール/設定状況を確認）と verify-lsp.ts（実際の診断ラウンドトリップを実行）があります。対象言語は TypeScript、Python、Go、Rust、C/C++、Java、Kotlin、C#/Razor、Swift、Ruby、PHP、Dart、Elixir、Zig、Lua、Bash、YAML、Terraform、Haskell、Julia です。
