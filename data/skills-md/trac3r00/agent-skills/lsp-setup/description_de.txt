Konfiguriere einen Language Server (LSP) für eine bestimmte Sprache, damit Editor/Agent‑Werkzeuge — Diagnosen, Gehe‑zu‑Definition, Referenzen‑Suchen, Umbenennen — funktionieren. Verwende ihn, wenn du Folgendes brauchst: LSP konfigurieren, LSP‑Setup, einen Language Server einrichten oder installieren, den Fehler „no LSP server configured“ / „server not installed“ beheben, zwischen Servern wählen (basedpyright vs pyright vs ty vs ruff) oder .codex/lsp-client.json / .opencode/lsp.json anbinden. Sprachserver‑Einrichtung. Leitet nach Dateierweiterung zu references/<language>/README.md für den genauen eingebauten Server, liefert install‑Befehle pro Betriebssystem (macOS/Linux/Windows), Konfigurations‑Snippets für beide Konfigurationsdateien, Initialisierungs‑Optionen, Alternativen und Fehlersuche. Mitgelieferte Skripte: detect-lsp.ts (scannt ein Projekt nach Sprachen + Installations‑/Konfigurations‑Status jedes Servers) und verify-lsp.ts (führt einen echten Diagnose‑Rundlauf aus). Unterstützt TypeScript, Python, Go, Rust, C/C++, Java, Kotlin, C#/Razor, Swift, Ruby, PHP, Dart, Elixir, Zig, Lua, Bash, YAML, Terraform, Haskell, Julia.
