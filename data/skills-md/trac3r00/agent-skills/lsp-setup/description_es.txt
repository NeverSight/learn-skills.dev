Configura un Servidor de Lenguaje (LSP) para un lenguaje específico para que las herramientas del editor/agente — diagnósticos, ir a la definición, buscar referencias, renombrar — funcionen. Úsalo cuando necesites: configurar LSP, configurar lsp, instalar o configurar un servidor de lenguaje, arreglar “no LSP server configured” / “server not installed”, elegir entre servidores (basedpyright vs pyright vs ty vs ruff), o enlazar .codex/lsp-client.json / .opencode/lsp.json. 언어서버 설정. Rutas por extensión de archivo a references/<language>/README.md para el servidor incorporado exacto, comandos de instalación por SO (macOS/Linux/Windows), fragmentos de configuración para ambos archivos de configuración, opciones de inicialización, alternativas y solución de problemas. Incluye scripts: detect‑lsp.ts (escanea un proyecto en busca de lenguajes + el estado de instalación/configuración de cada servidor) y verify‑lsp.ts (ejecuta una ronda real de diagnóstico). Cubre typescript, python, go, rust, c/c++, java, kotlin, c#/razor, swift, ruby, php, dart, elixir, zig, lua, bash, yaml, terraform, haskell, julia.
