配置特定語言的語言伺服器（LSP），使編輯器/代理工具的診斷、跳轉到定義、尋找參照、重新命名等功能正常運作。當您需要以下情況時使用：配置 LSP、設定 LSP、安裝或設定語言伺服器、修復「未配置 LSP 伺服器」/「伺服器未安裝」的問題、在伺服器之間做選擇（basedpyright、pyright、ty、ruff），或編寫 .codex/lsp-client.json / .opencode/lsp.json。語言伺服器設定。根據檔案副檔名路由至 references/<language>/README.md 以取得精確的內建伺服器說明，提供各作業系統的安裝指令（macOS、Linux、Windows），提供兩個設定檔的設定範例、初始化選項、替代方案以及故障排除。隨附腳本：detect-lsp.ts（掃描專案以偵測語言及每個伺服器的安裝/設定狀態）以及 verify-lsp.ts（執行真實的診斷往返測試）。支援的語言包括 TypeScript、Python、Go、Rust、C/C++、Java、Kotlin、C#/Razor、Swift、Ruby、PHP、Dart、Elixir、Zig、Lua、Bash、YAML、Terraform、Haskell、Julia。
