Genera uno scheletro funzionante di un’estensione per browser Manifest V3 — manifest.json, service worker di background, script di contenuto e popup — valido al primo avvio in Chrome/Edge/Firefox senza npm e senza bundler. Rifiuta di sovrascrivere una directory esistente. Usalo quando si avvia qualsiasi estensione per browser invece di scrivere il boilerplate.
