Создаёт рабочий скелет расширения браузера Manifest V3 — manifest.json, фонового сервис‑воркера, контент‑скрипта и всплывающего окна — валидный при первом запуске в Chrome/Edge/Firefox без npm и без сборщика. Отказывается перезаписывать существующую директорию. Используйте при начале разработки любого расширения вместо написания шаблонного кода.
