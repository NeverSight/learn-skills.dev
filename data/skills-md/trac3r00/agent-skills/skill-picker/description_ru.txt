Находит подходящие навыки для вашей рабочей нагрузки из каталога. Запрашивает catalogue.json (сгенерированный из реального каталога skills/, никогда не поддерживается вручную) по персонажу, семейству, ключевому слову или тегу и выводит совпадающие навыки с командами установки. Используйте его, чтобы ответить на вопрос «что мне установить для X», не просматривая каждый SKILL.md.
