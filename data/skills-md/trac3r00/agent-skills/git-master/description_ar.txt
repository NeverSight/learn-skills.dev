يجب الاستخدام كلما احتاجت مهمة إلى عملية commit أو التحقيق في تاريخ git. يُغطي الالتزامات الذرية، الإعداد (staging)، نمط رسالة الالتزام، rebase، squash، fixup/autosquash، blame، bisect، reflog، git log -S/-G، وأسئلة مثل من كتب هذا أو متى تم إضافته. لا تُستَخدم لهذه الغاية في تعديل الكود العادي إلا إذا طلب المستخدم عمل git. يرجى دائمًا الرد بلغة المستخدم.
