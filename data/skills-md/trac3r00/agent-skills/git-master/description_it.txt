DEVI USARE ogni volta che un compito richiede un commit o un'indagine sulla cronologia di Git. Copre commit atomici, staging, stile dei messaggi di commit, rebase, squash, fixup/autosquash, blame, bisect, reflog, git log -S/-G, e domande come chi ha scritto questo o quando è stato aggiunto. Non usarlo per modifiche di codice ordinarie a meno che l'utente non richieda lavoro su Git.

Per favore rispondi sempre nella lingua dell'utente.
