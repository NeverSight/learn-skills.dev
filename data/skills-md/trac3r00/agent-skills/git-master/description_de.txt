MUSS VERWENDEN, wenn eine Aufgabe einen Commit oder eine Untersuchung der Git‑Historie erfordert. Deckt atomare Commits, Staging, Commit‑Message‑Stil, Rebase, Squash, Fixup/Autosquash, Blame, Bisect, Reflog, git log ‑S/‑G und Fragen wie „Wer hat das geschrieben?“ oder „Wann wurde das hinzugefügt?“ ab. Nicht für gewöhnliche Code‑Änderungen verwenden, es sei denn, der Benutzer bittet ausdrücklich um Git‑Arbeiten.

Bitte immer in der Sprache des Benutzers antworten.
