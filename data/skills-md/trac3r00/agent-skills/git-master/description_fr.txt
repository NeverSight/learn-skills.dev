DOIT ÊTRE UTILISÉ chaque fois qu'une tâche nécessite un commit ou une enquête sur l'historique git. Couvre les commits atomiques, le staging, le style des messages de commit, le rebase, le squash, le fixup/autosquash, le blame, le bisect, le reflog, git log -S/-G, et les questions comme qui a écrit cela ou quand cela a été ajouté. Ne pas l'utiliser pour les modifications de code ordinaires à moins que l'utilisateur ne demande du travail git.

Veuillez toujours répondre dans la langue de l'utilisateur.
