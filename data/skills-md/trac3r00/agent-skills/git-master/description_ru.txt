НЕОБХОДИМО ИСПОЛЬЗОВАТЬ, когда задача требует коммита или исследования истории Git. Охватывает атомарные коммиты, индексацию, стиль сообщений коммита, rebase, squash, fixup/autosquash, blame, bisect, reflog, git log -S/-G и такие вопросы, как кто это написал или когда было добавлено. Не используйте для обычных правок кода, если только пользователь не просит выполнить работу с Git. Пожалуйста, всегда отвечайте на языке пользователя.
