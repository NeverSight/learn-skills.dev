Erstelle neue Fähigkeiten, modifiziere und verbessere bestehende Fähigkeiten und messe die Leistungsfähigkeit von Fähigkeiten. Verwende dies, wenn Benutzer eine Fähigkeit von Grund auf neu erstellen, eine vorhandene Fähigkeit bearbeiten oder optimieren, Evaluationen durchführen, um eine Fähigkeit zu testen, die Leistungsfähigkeit einer Fähigkeit mit Varianzanalyse benchmarken oder die Beschreibung einer Fähigkeit für eine bessere Auslösegenauigkeit optimieren möchten.
