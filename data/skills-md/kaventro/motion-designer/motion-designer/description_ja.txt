アプリのローンチ映像を作成します。モバイル（iPhone 内）またはデスクトップ（ノートパソコンのデスクトップ上のウィンドウ、実際のポインタ付き；ウェブアプリはブラウザウィンドウ）向けに、実際の UI を HTML で再構築またはキャプチャしたもの、あるいはブランドキャラクターとエンドカード付きのパネルストーリーのいずれかで作ります。映像は、オリジナルのトラック（またはユーザー提供のトラック）に合わせてビートでカットし、選択したビジュアルスタイルで仕上げ、ユーザーが選ぶローカルボイス（Chatterbox または Kokoro）によるオプションのナレーションを付け、フレームごとにチェックしたうえで MP4、無音ループ、ポスター、単一の自己完結型 HTML にレンダリングします。また、バーとフレームに合わせて音楽を作成またはカットし、ナレーションを書き起こしてミックスし、必要なツールを確認·インストールします（事前に確認します）。この機能は、ユーザーが iOS、Android、macOS、Windows、Linux、Electron、Tauri、またはウェブアプリのローンチ動画、プロモーション、ティーザー、製品映像を求めるとき、映像のストーリー、スタイル、ペース、デバイス、音楽、ナレーションを変更したいとき、音楽の制作や映像のビートに合わせたトラックのカット、ナレーションのミックスを希望するとき、あるいはツールの実行に必要なものを尋ねるときに使用します。
