为应用制作启动影片，可在移动端（iPhone 内部）或桌面端（笔记本桌面的窗口，带真实光标；浏览器窗口中的 Web 应用），使用真实 UI 重新构建或以 HTML 捕获，或通过面板讲述品牌角色的故事并加上结束卡。影片按照节拍剪辑，配以为其专门制作的原始音乐（或用户提供的音乐），采用用户选择的视觉风格，可选配本地语音旁白（用户可选择 Chatterbox 或 Kokoro），逐帧检查后渲染为 MP4、静音循环、海报及单个独立的 HTML。它还能制作或剪辑符合节拍和画面的音乐，编写并混音旁白，并在询问后检查并安装所需工具。当用户需要其 iOS、Android、macOS、Windows、Linux、Electron、Tauri 或 Web 应用的启动视频、宣传片、预告片或产品影片，或想更改此类影片的故事、风格、节奏、设备、音乐或旁白，或需要制作音乐或将音乐剪辑到影片节拍或配上旁白混音，或询问工具运行所需条件时使用。
