قم بإنشاء فيلم إطلاق لتطبيق، إما للهواتف المحمولة (داخل iPhone) أو لأجهزة الحاسوب (نافذة على سطح مكتب لابتوب مع مؤشر حقيقي؛ تطبيقات الويب في نافذة المتصفح)، مع إعادة بناء واجهته الحقيقية أو التقاطها بـ HTML، أو قصة تُروى في ألواح مع شخصية العلامة التجارية وبطاقة نهائية. يتم قص الفيلم على إيقاع مسار أصلي صُنع له (أو للمستخدم)، بأسلوب بصري مختار، مع تعليق صوتي اختياري بصوت محلي يختاره المستخدم (Chatterbox أو Kokoro)، يُفحص إطارًا بإطار ثم يُصدّر إلى MP4، حلقة صامتة، ملصق، وملف HTML واحد مستقل. كما يكوّن أو يقتطع مسارًا وفقًا للبار والإطار، يكتب ويخلط التعليق الصوتي، ويتحقق من الأدوات المطلوبة ويثبتها بعد الاستفسار. استخدمه عندما يرغب المستخدم في فيديو إطلاق، ترويج، تشويق أو فيلم منتج لتطبيق iOS أو Android أو macOS أو Windows أو Linux أو Electron أو Tauri أو ويب، ويريد تعديل قصة الفيلم أو أسلوبه أو توقيته أو الجهاز أو الموسيقى أو التعليق الصوتي، أو يرغب في صنع موسيقى أو قص مسار ليتماشى مع إيقاع الفيلم أو خلط السرد فوقه، أو يسأل عن المتطلبات التي تحتاجها الأداة لتعمل.
