Livello di giudizio della visualizzazione dei dati SSOT—caricalo prima di disegnare qualsiasi grafico, dashboard o board, non dopo aver finito. Regola “se disegnarlo in questo modo”: quale conclusione il grafico deve portare al lettore, se usare media o mediana, se l'aggregazione è possibile, stacked o line, se usare un asse duale, schema di colori e numero di colori, se la stessa entità tra i grafici deve avere lo stesso colore e posizione, quante colonne deve mantenere una tabella. Media‑agnostico: si applica allo stesso modo a pagine di report HTML, dashboard React/Vue, grafici PPT nativi, matplotlib/plotly/ECharts/D3, grafici renderizzati in PNG. Uso quando: prima di creare manualmente un grafico, o quando si revisionano grafici esistenti (“cosa c’è di sbagliato in questi grafici”, “perché le legende sono incoerenti”). Non per: layout/componente/interazione delle pagine di report (usa report-with-html:report-with-html) o le problematiche di implementazione e rendering dei grafici PPT nativi (usa deck-creator:deck-creator).
