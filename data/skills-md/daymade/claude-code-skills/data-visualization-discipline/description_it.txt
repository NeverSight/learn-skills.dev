Livello di giudizio della visualizzazione dati SSOT — caricalo prima di creare qualsiasi grafico, dashboard o board, non dopo aver finito. Regola “se disegnare in questo modo”: quale conclusione il grafico deve condurre il lettore a trarre, se usare media o mediana, se l’aggregazione è possibile, stacked versus line, se si possono usare assi doppi, schema colore e numero di colori, se la stessa entità deve avere colori e posizioni coerenti tra i grafici, e quante colonne mantenere in una tabella. Medium‑agnostic: si applica uniformemente a pagine di report HTML, dashboard React/Vue, grafici PPT nativi, matplotlib/plotly/ECharts/D3 e grafici renderizzati come PNG. Uso: prima di disegnare un grafico, o nella revisione di grafici esistenti (“quali problemi hanno questi grafici?”, “perché le legende sono incoerenti?”). Non per: layout/componente/interazione delle pagine di report (usa report‑with‑html:report‑with‑html) o per problematiche di implementazione e rendering dei grafici PPT nativi (usa deck‑creator:deck‑creator).
