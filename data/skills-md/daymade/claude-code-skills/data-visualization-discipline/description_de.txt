Urteils‑Schicht der Datenvisualisierung SSOT — laden Sie sie, bevor Sie ein Diagramm, Dashboard oder Board zeichnen, nicht nach dem Abschluss. Steuert „ob man es so zeichnet“: welche Schlussfolgerung das Diagramm dem Leser vermitteln soll, ob Mittelwert oder Median verwendet wird, ob Aggregation möglich ist, gestapelt oder Liniendiagramm, ob eine Doppelachse verwendet wird, Farbschema und Anzahl der Farben, ob dieselbe Entität in verschiedenen Diagrammen die gleiche Farbe und Position haben soll, wie viele Spalten eine Tabelle behalten soll. Medien‑agnostisch: gilt gleichermaßen für HTML‑Berichtsseiten, React/Vue‑Dashboards, native PPT‑Diagramme, matplotlib / plotly / ECharts / D3, zu PNG gerenderte Diagramme. Verwendung: bevor ein Diagramm von Hand erstellt wird oder beim Prüfen vorhandener Diagramme („Was ist falsch an diesen Diagrammen?“, „Warum sind die Legenden inkonsistent?“). Nicht geeignet für: Layout/Komponente/Interaktion von Berichtsseiten (verwenden Sie report‑with‑html:report‑with‑html) oder die Implementierungs‑ und Rendering‑Fallstricke nativer PPT‑Diagramme (verwenden Sie deck‑creator:deck‑creator).
