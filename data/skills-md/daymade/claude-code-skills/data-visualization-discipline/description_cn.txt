数据可视化判断层 SSOT — 在创建任何图表、仪表盘或看板之前加载，而不是完成后再加载。它决定“是否采用这种绘制方式”：图表要引导读者得出的结论、使用均值还是中位数、是否可以聚合、堆叠图还是折线图、是否可以使用双坐标轴、配色方案及颜色数量、同一实体在不同图表中是否保持一致的颜色和位置、以及表格中保留多少列。媒体无关：统一适用于 HTML 报告页面、React/Vue 仪表盘、原生 PPT 图表、matplotlib/plotly/ECharts/D3，以及渲染为 PNG 的图表。使用场景：绘制图表前，或审查已有图表时（如“这些图表存在哪些问题？”、“图例为何不一致？”）。不适用场景：报告页面的布局/组件/交互（使用 report‑with‑html:report‑with‑html）或原生 PPT 图表的实现与渲染坑（使用 deck‑creator:deck‑creator）。
