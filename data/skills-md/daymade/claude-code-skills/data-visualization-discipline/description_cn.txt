数据可视化的判断层（SSOT）——在绘制任何图表、仪表盘或看板之前加载，而不是完成后再加载。  
决定“是否按这种方式绘制”：图表希望引导读者得出的结论、是使用均值还是中位数、是否可以进行聚合、采用堆叠还是折线、是否使用双坐标轴、配色方案及颜色数量、跨图表的同一实体是否应使用相同的颜色和位置、表格应保留多少列。  
媒体无关：同样适用于 HTML 报告页面、React/Vue 仪表盘、本地 PPT 图表、matplotlib/plotly/ECharts/D3，以及渲染为 PNG 的图表。  
使用场景：在手工绘制图表之前，或在审查已有图表时（如“这些图表有什么问题”， “为何图例不一致”）。  
不适用场景：报告页面的布局/组件/交互（使用 report-with-html:report-with-html）或本地 PPT 图表的实现和渲染陷阱（使用 deck-creator:deck-creator）。
