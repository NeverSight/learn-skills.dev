Judgment layer of data visualization SSOT—load it before drawing any chart, dashboard, or board, not after finishing. Governs “whether to draw it this way”: what conclusion the chart is intended to lead the reader to, whether to use mean or median, whether aggregation is possible, stacked or line, whether to use a dual axis, color scheme and number of colors, whether the same entity across charts should have the same color and position, how many columns a table should keep. Media‑agnostic: applies equally to HTML report pages, React/Vue dashboards, native PPT charts, matplotlib/plotly/ECharts/D3, charts rendered to PNG. Use when: before hand‑crafting a chart, or when reviewing existing charts (“what’s wrong with these charts”, “why are the legends inconsistent”). Not for: layout/component/interaction of report pages (use report-with-html:report-with-html) or the implementation and rendering pitfalls of native PPT charts (use deck-creator:deck-creator).
