Data visualization judgment layer SSOT — load it before creating any chart, dashboard, or board, not after finishing. It governs “whether to draw this way”: what conclusion the chart is meant to lead the reader to, whether to use mean or median, whether aggregation is possible, stacked versus line, whether dual axes can be used, color scheme and number of colors, whether the same entity should have consistent colors and positions across charts, and how many columns to retain in a table. Medium‑agnostic: applies uniformly to HTML report pages, React/Vue dashboards, native PPT charts, matplotlib/plotly/ECharts/D3, and charts rendered as PNG. Use when: before drawing a chart, or reviewing existing charts (“what issues do these charts have?”, “why are the legends inconsistent?”). Not for: layout/component/interaction of report pages (use report‑with‑html:report‑with‑html) or implementation and rendering pitfalls of native PPT charts (use deck‑creator:deck‑creator).
