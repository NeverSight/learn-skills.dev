Capa de juicio de visualización de datos SSOT: cárgala antes de dibujar cualquier gráfico, panel o tablero, no después de terminar. Rige “si se debe dibujar de esta manera”: qué conclusión se pretende que el gráfico lleve al lector, si se debe usar la media o la mediana, si es posible la agregación, si debe ser apilado o de líneas, si se utiliza un eje dual, el esquema de colores y la cantidad de colores, si la misma entidad en diferentes gráficos debe tener el mismo color y posición, cuántas columnas debe conservar una tabla. Agnóstica de medio: se aplica igualmente a páginas de informes HTML, tableros React/Vue, gráficos nativos de PPT, matplotlib/plotly/ECharts/D3, gráficos exportados a PNG. Uso: antes de crear manualmente un gráfico o al revisar gráficos existentes (“qué está mal en estos gráficos”, “por qué las leyendas son inconsistentes”). No para: diseño/componentes/interacción de páginas de informes (use report-with-html:report-with-html) o los problemas de implementación y renderizado de gráficos nativos de PPT (use deck-creator:deck-creator).
