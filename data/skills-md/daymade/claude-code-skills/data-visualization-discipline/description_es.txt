La capa de juicio del SSOT de visualización de datos — cárgala antes de crear cualquier gráfico, tablero o panel, no después de terminar. Governa “si dibujarlo de esta manera”: qué conclusión se pretende que el gráfico lleve al lector, si se debe usar media o mediana, si la agregación es posible, apilado o línea, si se puede usar un eje dual, esquema de colores y número de colores, si la misma entidad entre gráficos debe compartir el mismo color y posición, y cuántas columnas debe conservar una tabla. Independiente del medio: se aplica uniformemente a páginas de informes HTML, tableros React/Vue, gráficos nativos de PPT, matplotlib/plotly/ECharts/D3 y gráficos renderizados como PNG. Uso: antes de comenzar a dibujar, o al revisar gráficos existentes (“¿qué problemas tienen estos gráficos?”, “¿por qué son inconsistentes las leyendas?”). No para: disposición/componente/interacción de páginas de informes (use report‑with‑html:report‑with‑html) o problemas de implementación y renderizado de gráficos nativos de PPT (use deck‑creator:deck‑creator).
