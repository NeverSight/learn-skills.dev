資料視覺化判斷層 SSOT — 在建立任何圖表、儀表板或看板之前載入，而不是在完成後才載入。它負責「是否以此方式繪製」：圖表希望引導讀者得出的結論、使用平均值或中位數、是否可以彙總、堆疊圖與折線圖的選擇、是否可使用雙軸、色彩方案與顏色數量、相同實體在不同圖表中是否應保持一致的顏色與位置、以及表格中保留多少欄位。媒介無關：同時適用於 HTML 報告頁面、React/Vue 儀表板、原生 PPT 圖表、matplotlib/plotly/ECharts/D3 以及 PNG 格式的圖表。使用時機：繪製圖表之前，或檢視現有圖表時（「這些圖表有哪些問題？」、「為何圖例不一致？」）。不適用於：報告頁面的版面/元件/互動（使用 report‑with‑html:report‑with‑html）或原生 PPT 圖表的實作與渲染問題（使用 deck‑creator:deck‑creator）。
