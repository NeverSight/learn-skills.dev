데이터 시각화 SSOT의 판단 레이어—차트, 대시보드 또는 보드를 그리기 전에 로드하고, 완료 후에 로드하지 마십시오. “이렇게 그릴지 말지”를 결정합니다: 차트가 독자에게 전달하려는 결론, 평균과 중앙값 중 선택, 집계 가능 여부, 누적형인지 선형인지, 이중 축 사용 여부, 색상 구성 및 색상 수, 차트 간 동일한 엔터티에 동일한 색상과 위치 적용 여부, 테이블이 유지해야 할 열의 개수 등. 미디어에 구애받지 않음: HTML 보고서 페이지, React/Vue 대시보드, 네이티브 PPT 차트, matplotlib/plotly/ECharts/D3, PNG로 렌더링된 차트에 모두 동일하게 적용됩니다. 사용 시점: 차트를 직접 만들기 전이나 기존 차트를 검토할 때(“이 차트들에 뭐가 문제인가”, “범례가 일관되지 않은 이유”). 사용하지 않을 경우: 보고서 페이지의 레이아웃·컴포넌트·인터랙션(보고서는 report‑with‑html:report‑with‑html 사용)이나 네이티브 PPT 차트의 구현 및 렌더링 함정( deck‑creator:deck‑creator 사용).
