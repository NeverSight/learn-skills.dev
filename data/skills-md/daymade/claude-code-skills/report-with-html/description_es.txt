Produce el artefacto HTML orientado al lector: informe, panel de control, vista de arquitectura, navegador de datos o banco de trabajo de revisión: respaldado por evidencia, verificado por el navegador. Utilícelo cuando el entregable sea un informe HTML visual o el usuario solicite una presentación HTML/web. Cargue la disciplina de visualización de datos para el juicio del gráfico. No para el estado del chat o la prosa de Markdown a menos que se le pida que se convierta en un informe; no para PowerPoint (Ruta C del creador de mazos).
