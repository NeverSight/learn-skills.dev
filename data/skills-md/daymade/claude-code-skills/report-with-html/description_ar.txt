ينتج الأداة HTML الموجهة للقراء — تقرير، لوحة معلومات، عرض بنية، متصفح بيانات، أو مساحة مراجعة — مدعومة بالأدلة ومتحققة عبر المتصفح. يُستخدم عندما يكون الناتج تقرير HTML بصري، أو يطلب المستخدم عرضًا بصيغة HTML/ويب. حمّل دليل تصور البيانات لتقييم الرسوم البيانية. ليس للاستخدام في حالة الدردشة أو نصوص Markdown إلا إذا طُلب تحويلها إلى تقرير؛ وليس لإنشاء عروض PowerPoint (مسار مُنشئ الشرائح C). يرجى دائمًا الرد بلغة المستخدم.
