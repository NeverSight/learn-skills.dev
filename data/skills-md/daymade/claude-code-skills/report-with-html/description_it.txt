Produce l'artefatto HTML rivolto al lettore — rapporto, cruscotto, vista architetturale, browser dati o banco di revisione — supportato da prove, verificato dal browser. Usalo quando il risultato è un rapporto HTML visivo, o l'utente richiede una presentazione HTML/web. Carica la disciplina di visualizzazione dei dati per la valutazione dei grafici. Non è per lo stato della chat o prosa in Markdown a meno che non venga richiesto di trasformarlo in un rapporto; non è per PowerPoint (creatore di deck, Percorso C). Rispondi sempre nella lingua dell'utente.
