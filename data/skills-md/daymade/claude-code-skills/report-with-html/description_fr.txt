Produit l'artefact HTML destiné au lecteur — rapport, tableau de bord, vue d'architecture, navigateur de données ou poste de révision — appuyé par des preuves, vérifié par le navigateur. Utilisez-le lorsque le livrable EST un rapport HTML visuel, ou que l'utilisateur demande une présentation HTML/web. Chargez la discipline de visualisation des données pour le jugement des graphiques. Pas pour le statut de chat ou le texte en Markdown sauf si l’on demande d’en faire un rapport ; pas pour PowerPoint (Route C du créateur de diaporamas).

Veuillez toujours répondre dans la langue de l'utilisateur.
