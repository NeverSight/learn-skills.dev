Mejora una aplicación existente utilizando su código, contrato de producto, historial de trabajo autorizado y evidencia de la competencia. Usar 取长补短、取其精华去其糟粕、参考竞品优化应用 o evolucionar una aplicación a partir de un trabajo exitoso y fallido.
