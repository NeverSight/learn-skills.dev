Маршрутизирует любую операцию Feishu/Lark/Doubao, включая поиск записей по дате (按日期找会议录音), через доменное руководство lark-cli, соответствующее версии, встроенное в установленный CLI, затем выполняет и проверяет задачу. Используется для документов, диска, таблиц, Base, вики, протоколов, встреч, календаря, мгновенных сообщений, почты, задач, утверждений, приложений, аутентификации/объёмов доступа, URL‑адресов ресурсов или токенов в Feishu/Lark/Doubao, а также для устранения неполадок lark-cli. Это единственная точка входа в Lark; используйте ima‑copilot вместо этого для Tencent IMA.
