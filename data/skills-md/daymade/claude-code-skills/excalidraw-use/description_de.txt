Platzieren Sie vorhandene Bilder auf einem Excalidraw-Whiteboard, wandeln Sie einen Foliensatz zunächst in saubere Bilder pro Folie um und prüfen Sie, was in einer .excalidraw-Datei enthalten ist. Verwenden Sie es immer dann, wenn jemand Excalidraw, ein Whiteboard oder eine Leinwand, eine .excalidraw-Datei, Zeichen oder Wörter erwähnt – insbesondere „Legen Sie diese Screenshots auf meine Tafel“, „Fügen Sie meine alten Workshop-Bilder zur Leinwand hinzu“, „Räumen Sie sie auf, damit ich den Abstand nicht manuell anpassen muss“, „Verwandeln Sie diese Folien in Bilder, auf denen ich zeichnen kann“ oder „Was ist in dieser Szenendatei?“. Verwenden Sie es auch, wenn ein Vortrag oder ein Workshop durch manuelles Überzeichnen von Screenshots auf einer gemeinsamen Leinwand gehalten wird oder wenn jemand eine Auswahlliste mit vielen Bildern zur Auswahl benötigt. Nicht für die Generierung eines Diagramms aus einer Textbeschreibung – das ist eine andere Aufgabe.
