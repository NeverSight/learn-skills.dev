Posiziona le immagini esistenti su una lavagna Excalidraw, trasforma prima un gruppo di diapositive in immagini pulite per diapositiva e controlla cosa c'è all'interno di un file .excalidraw. Da utilizzare ogni volta che qualcuno menziona Excalidraw, una lavagna o una tela, un file .excalidraw, 白板 o 画板, in particolare "metti questi screenshot sulla mia lavagna", "aggiungi le immagini del mio vecchio laboratorio alla tela", "distanziale in modo da non dover regolare la spaziatura manualmente", "trasforma queste diapositive in immagini su cui posso disegnare" o "cosa c'è in questo file di scena". Utilizzalo anche quando un discorso o un workshop viene tenuto disegnando a mano su screenshot su una tela condivisa o quando qualcuno ha bisogno di un vassoio di raccolta di molte immagini tra cui scegliere. Non per generare un diagramma da una descrizione testuale: è un lavoro diverso.
