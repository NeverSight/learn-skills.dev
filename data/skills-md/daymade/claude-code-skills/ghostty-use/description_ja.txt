Ghostty タブ内の Claude Code / Codex セッションを、再起動をまたいでスナップショット、復元、統合します。Mac をアップデートのために終了する際に使用します（端末セッションを保存 / 再起動前に端末をバックアップ）、再起動後に元のセッション ID でタブを再オープンする（以前のウィンドウを復元 / Ghostty タブを復元）、またはどのセッションが残っているか監査する際に使用します。--resume を使った単一会話の再開、端末のスクリーンショット、tmux の状態には使用しません。定期的な変更のみのスナップショットにも使用します（定期的な増分スナップショット / 変更がなければ記録しない）。手動で Codex アカウントを切り替える前後にも使用します（クレジットが尽きたらアカウントを変更 / アカウント切替後にすべての Codex を復元）。
