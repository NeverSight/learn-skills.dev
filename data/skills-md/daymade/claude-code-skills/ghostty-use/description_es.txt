Instantáneas, restauraciones y conciliaciones de sesiones de Claude Code/Codex dentro de pestañas de Ghostty entre reinicios. Úselo al apagar la Mac para una actualización (guardar la sesión del terminal / respaldar el terminal antes del reinicio), después del reinicio para volver a abrir pestañas con sus ID de sesión originales (recuperar las ventanas anteriores / restaurar mis pestañas de Ghostty), o para auditar qué sesiones sobrevivieron. No es para reanudar una conversación mediante su propio --resume, capturas de pantalla del terminal o el estado de tmux. También úselo para instantáneas periódicas solo de cambios (instantáneas incrementales regulares / no registrar si no hay cambios). Asimismo, utilícelo antes o después de un cambio manual de cuenta de Codex (agotado el límite, cambiar de cuenta / restaurar todo Codex después de cambiar de cuenta).
