Crea istantanee, ripristina e riconcilia le sessioni Claude Code / Codex all'interno delle schede Ghostty tra i riavvii. Utilizzalo quando chiudi il Mac per un aggiornamento (保存终端会话 / 重启前备份终端), dopo il riavvio per riaprire le schede con i loro ID di sessione originali (恢复之前的窗口 / restore my ghostty tabs), o per verificare quali sessioni sono sopravvissute. Non serve per riprendere una conversazione tramite il suo --resume, per screenshot del terminale o per lo stato di tmux. È utile anche per snapshot periodici solo delle modifiche (定期增量快照 / 没变化不记录). Usalo prima o dopo uno scambio manuale dell'account Codex (额度耗尽换号 / 换号后恢复全部 Codex).
