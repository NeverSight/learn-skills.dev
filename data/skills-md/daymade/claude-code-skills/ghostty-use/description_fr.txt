Capture des instantanés, restauration et conciliation des sessions Claude Code / Codex dans les onglets Ghostty entre les redémarrages. À utiliser lors de la fermeture du Mac pour une mise à jour (保存终端会话 / 重启前备份终端), après le redémarrage pour rouvrir les onglets avec leurs identifiants de session d'origine (恢复之前的窗口 / restore my ghostty tabs), ou pour auditer quelles sessions ont survécu. Ce n’est pas destiné à reprendre une conversation via son propre --resume, aux captures d’écran du terminal ou à l’état de tmux. À utiliser également pour des instantanés périodiques uniquement en cas de changement (定期增量快照 / 没变化不记录). À utiliser avant ou après un changement manuel de compte Codex (额度耗尽换号 / 换号后恢复全部 Codex).
