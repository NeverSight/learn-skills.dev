Снимки, восстановления и согласование сессий Claude Code / Codex внутри вкладок Ghostty между перезагрузками. Используйте при выходе из macOS для обновления (保存终端会话 / 重启前备份终端), после перезапуска — для повторного открытия вкладок с их исходными идентификаторами сессий (恢复之前的窗口 / restore my ghostty tabs), либо для аудита, какие сессии выжили. Не предназначено для возобновления одной беседы через её собственный --resume, скриншотов терминала или состояния tmux. Также используйте для периодических снапшотов только при изменениях (定期增量快照 / 没变化不记录). Применяйте также перед или после ручной смены аккаунта Codex (额度耗尽换号 / 换号后恢复全部 Codex).
