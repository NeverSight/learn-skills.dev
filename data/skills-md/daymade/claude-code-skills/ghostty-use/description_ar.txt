تلتقط لقطات، وتستعيد، وتُسوٍّ جلسات Claude Code / Codex داخل علامات تبويب Ghostty عبر عمليات إعادة التشغيل. استخدمها عند إغلاق الماك لتحديث (保存终端会话 / 重启前备份终端)، بعد إعادة التشغيل لإعادة فتح العلامات بتعريفات الجلسة الأصلية (恢复之前的窗口 / restore my ghostty tabs)، أو لتدقيق أي الجلسات التي نجت. ليست مخصصة لاستئناف محادثة واحدة عبر خاصية ‎--resume‎ الخاصة بها، أو لالتقاط صور شاشات الطرفية، أو لحالة tmux. يمكن أيضًا استخدامها للقطات دورية تُسجل التغيّر فقط (定期增量快照 / 没变化不记录). كما يمكن استخدامها قبل أو بعد تبديل يدوي لحساب Codex (额度耗尽换号 / 换号后恢复全部 Codex).
