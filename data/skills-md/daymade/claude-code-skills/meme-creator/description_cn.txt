创建视频/GIF 梗图的方法是将图像（标志、头像、贴纸）叠加到剪辑中移动的对象上，使用帧精确跟踪，然后导出 MP4 与 GIF。适用于用户想要从现有素材中生成梗图、表情包或反应 GIF；需要在视频中遮盖人脸或头部；希望让标志或头像跟随移动的人或物体；想把视频片段转成可分享的 GIF；或要求把 logo/头像贴到视频里跟着动。支持源码下载（yt-dlp）、通过联系表（contact sheet）选择片段、使用 CSRT 跟踪并配合重新锚点和手动关键帧回退、在帧边缘和镜头切换处处理淡入淡出以及 GIF 大小预算。此功能不用于基于文字的编辑、程序化场景生成或字幕工作。
