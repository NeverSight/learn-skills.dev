フレーム単位で正確にトラッキングし、画像（ロゴ、アバター、ステッカー）をクリップ内の動くオブジェクトに重ね合わせてビデオ／GIFミームを作成し、MP4 と GIF にエクスポートします。ユーザーが既存映像からミーム、梗图、表情包、またはリアクション GIF を作りたいとき、動画内の顔や頭部を隠したいとき、ロゴやアバターを動く人物やオブジェクトに追随させたいとき、動画の一瞬をシェア可能な GIF に変えたいとき、あるいは「把 logo/头像贴到视频里跟着动」と依頼されたときに使用します。ソースのダウンロード（yt‑dlp）、コンタクトシートによるセグメント選択、CSRT 追跡に再アンカリングと手動キー‑フレームのフォールバックを組み合わせ、フレーム端やカット変更時のフェード処理、GIF のサイズ予算管理を行います。トランスクリプトベースの編集、プログラム的なシーン生成、字幕作業には適していません。
