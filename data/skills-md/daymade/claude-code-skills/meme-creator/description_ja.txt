フレーム精度のトラッキングでクリップ内の移動オブジェクトに画像 (ロゴ、アバター、ステッカー) をオーバーレイすることでビデオ/GIF ミームを作成し、MP4 + GIF をエクスポートします。ユーザーが既存の映像からミーム、梗图、表情包、またはリアクション GIF を必要とする場合に使用します。ビデオ内で顔や頭を覆うこと。動く人物や物体にロゴやアバターを追従させること。ビデオの瞬間を共有可能な GIF に変換します。または、ロゴ/画像をビデオ里跟着動に持ってくるように依頼します。ソースのダウンロード (yt-dlp)、コンタクト シートによるセグメントの選択、再アンカーと手動キーフレーム フォールバックによる CSRT トラッキング、フレーム エッジとショット変更でのフェード、GIF サイズの割り当てを処理します。トランスクリプト主導の編集、プログラムによるシーン生成、または字幕作業には適していません。
