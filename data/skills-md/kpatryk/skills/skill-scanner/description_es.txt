Use esta habilidad siempre que un usuario solicite escanear paquetes `SKILL.md`, asegurar un repositorio `skills/`, integrar verificaciones de seguridad de habilidades de agentes en CI/CD (especialmente cargas SARIF de GitHub Actions), ajustar políticas del escáner, reducir falsos positivos, añadir escaneo pre‑commit o solucionar problemas de banderas y comportamiento del analizador de `skill-scanner`. Utilice siempre esta habilidad para solicitudes que involucren "skill scanner", "agent skill security", "scan-all", preajustes de política (estricto/equilibrado/permisivo), verificaciones de superposición o triage de hallazgos de amenazas.
