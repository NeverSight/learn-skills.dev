Всеобъемлющее руководство по Skill Scanner (Cisco AI Defense) для обнаружения внедрения подсказок, кражи данных, злоупотребления командами и вредоносных шаблонов в навыках AI‑агентов. Используйте этот навык каждый раз, когда пользователь просит просканировать пакеты `SKILL.md`, защитить репозиторий `skills/`, интегрировать проверки безопасности навыков агента в CI/CD (особенно загрузки SARIF в GitHub Actions), настроить политики сканера, уменьшить количество ложных срабатываний, добавить сканирование на этапе pre‑commit или отладить флаги `skill-scanner` и поведение анализатора. Всегда применяйте этот навык для запросов, связанных с «skill scanner», «agent skill security», «scan-all», предустановками политик (strict/balanced/permissive), проверками наложений или сортировкой результатов угроз.
