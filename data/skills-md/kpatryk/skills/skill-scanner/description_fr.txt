Guide complet pour Skill Scanner (Cisco AI Defense) afin de détecter les injections d’instructions, l’exfiltration de données, les abus de commandes et les modèles malveillants dans les compétences des agents IA. Utilisez cette compétence chaque fois qu’un utilisateur demande d’analyser des packages `SKILL.md`, de sécuriser un référentiel `skills/`, d’intégrer des contrôles de sécurité des compétences d’agent dans le CI/CD (en particulier les téléchargements SARIF GitHub Actions), d’ajuster les politiques du scanner, de réduire les faux positifs, d’ajouter une analyse pré‑commit, ou de dépanner les drapeaux du `skill-scanner` et le comportement de l’analyseur. Utilisez toujours cette compétence pour les demandes impliquant « skill scanner », « sécurité des compétences d’agent », « scan‑all », les préréglages de politiques (strict/équilibré/permissif), les vérifications de chevauchement ou le tri des constats de menace.
