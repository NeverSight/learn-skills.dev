دليل شامل لأداة فحص المهارات (Skill Scanner) من سيسكو AI Defense لاكتشاف حقن الإرشادات، تسرب البيانات، سوء استخدام الأوامر، والأنماط الخبيثة في مهارات الوكيل الذكي. استخدم هذه الأداة كلما طلب المستخدم فحص حزم `SKILL.md`، تأمين مستودع `skills/`، دمج فحوصات أمان مهارات الوكيل في CI/CD (خاصة تحميلات SARIF عبر GitHub Actions)، ضبط سياسات الفاحص، تقليل الإيجابيات الكاذبة، إضافة فحص ما قبل الالتزام، أو استكشاف أخطاء أعلام `skill-scanner` وسلوك المحلل. دائمًا استخدم هذه الأداة للطلبات التي تتضمن "skill scanner"، "agent skill security"، "scan-all"، إعدادات سياسات مسبقة (صارمة/متوازنة/متساهلة)، فحوصات التداخل، أو تصنيف نتائج التهديدات.

يرجى دائمًا الرد بلغة المستخدم.
