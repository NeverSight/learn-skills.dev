Guida completa per Skill Scanner (Cisco AI Defense) per rilevare iniezione di prompt, esfiltrazione di dati, abuso di comandi e schemi maligni nelle skill degli agenti AI. Usa questa skill ogni volta che un utente richiede di scansionare pacchetti `SKILL.md`, mettere in sicurezza un repository `skills/`, integrare controlli di sicurezza delle skill degli agenti nel CI/CD (in particolare caricamenti SARIF di GitHub Actions), regolare le politiche dello scanner, ridurre i falsi positivi, aggiungere scansioni pre‑commit o risolvere problemi con i flag `skill-scanner` e il comportamento dell'analizzatore. Usa sempre questa skill per richieste che coinvolgono "skill scanner", "agent skill security", "scan-all", preset di policy (strict/balanced/permissive), verifiche di sovrapposizione o triage dei risultati delle minacce.

Rispondi sempre nella lingua dell'utente.
