將 Markdown 文件編譯成符合指定格式的 Word（.docx）：排版、標題、原生 OMML 公式、三線表格、圖表說明、交叉引用、目錄欄位、分章頁碼、CSL 參考文獻，以及匯出前後的品質檢查。把 Markdown 匯出為符合規範的 Word：學位論文、期刊論文、技術報告、公文、說明書都適用；格式寫在一份隨稿件進 Git 的格式檔案裡。當使用者需要 .docx——提交稿、報告、正式文件或僅是可讀的副本時使用——包括匯出 Word、文件轉 Word、轉成 Word、論文排版、公文排版、報告排版、prepare submission docx。不適用於 PDF、HTML 或 LaTeX 輸出。
