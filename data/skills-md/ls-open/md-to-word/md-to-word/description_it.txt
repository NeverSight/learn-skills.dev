Compila un documento Markdown in Word (.docx) che rispetti un formato dichiarato: tipografia, titoli, equazioni native OMML, tabelle a tre linee, didascalie, riferimenti incrociati, campo TOC, numerazione delle pagine per sezione, bibliografie CSL e controlli di qualità pre/post esportazione. Esporta Markdown in Word conforme alle norme: tesi di laurea, articoli di rivista, rapporti tecnici, documenti ufficiali, manuali sono tutti supportati; il formato è scritto in un file di configurazione incluso nel repository Git insieme al manoscritto. Da utilizzare quando l'utente desidera un .docx — una sottomissione, un rapporto, un documento ufficiale o semplicemente una copia leggibile — includendo esportazione a Word, conversione documento in Word, trasformazione in Word, impaginazione di tesi, impaginazione di documenti ufficiali, impaginazione di rapporti, preparazione del documento di sottomissione .docx. Non per output PDF, HTML o LaTeX.
