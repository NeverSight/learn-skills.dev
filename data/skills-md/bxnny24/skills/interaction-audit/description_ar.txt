امشِ عبر تطبيق كامل واختبر كل تفاعل يقدمه، واحدة تلو الأخرى، مع إثبات بصري (لقطة شاشة) وملف قائمة مراجعة. أجرِ جردًا لكل شاشة، وعنصر تحكم، وإيماءة من الشيفرة والتطبيق الجاري، وقم بتشغيل كل منها بالأداة المناسبة للمنصة (محاكي iOS أو iPhone فعلي، محاكي Android، الويب، امتداد المتصفح، تطبيق سطح المكتب على macOS أو Windows)، وسجل كل تعطل، عنصر تحكم غير فعال، حركة مكسورة أو نص خاطئ مع خطوات إعادة الإنتاج. استخدم هذا كلما أراد المستخدم "المرور عبر التطبيق بالكامل"، "النقر على كل شيء"، "اختبار كل زر/تفاعل"، إجراء جولة شاملة لواجهة المستخدم أو تدقيق تفاعلات، اختبار دخان أو جولة استكشافية قبل الإصدار، التحقق من أن لا شيء معطَّل بعد تغيير كبير، أو قول "/interaction-audit" مع منصة مثل mobile أو ios أو android أو web أو extension أو desktop — حتى وإن لم يذكروا كلمة "اختبار".
