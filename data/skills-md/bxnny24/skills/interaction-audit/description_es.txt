Recorre toda una aplicación y ejercita cada interacción que ofrece, una por una, con pruebas de captura de pantalla y un archivo de lista de verificación. Inventario cada pantalla, control y gesto a partir del código y la aplicación en ejecución, impulsa cada uno con la herramienta adecuada para la plataforma (Simulador de iOS o iPhone real, emulador de Android, web, extensión de navegador, aplicación de escritorio en macOS o Windows), y registra cada bloqueo, control inactivo, animación rotas o texto incorrecto con pasos de reproducción. Usa esto siempre que el usuario quiera “recorrer toda la app”, “tocar todo”, “probar cada botón/interacción”, hacer un recorrido completo de la UI o auditoría de interacciones, prueba de humo o pasada exploratoria antes de un lanzamiento, comprobar que nada está roto tras un cambio importante, o diga “/interaction-audit” con una plataforma como móvil, iOS, Android, web, extensión o escritorio — incluso si no dice “test”.
