Sitio completo o producto — una auditoría completa de accesibilidad web (a11y) contra WCAG 2.2, siguiendo la metodología WCAG-EM. Define el alcance, muestra páginas y flujos representativos, ejecuta el nivel automatizado (`accessibility-scan`) y el nivel manual práctico (`accessibility‑inspect`), y produce un informe de conformidad. Califica cada hallazgo por gravedad y base de evidencia, y indica la conformidad por criterio como aprobado, fallido o indeterminado (requiere intervención humana). Úsalo para “auditar mi sitio para accesibilidad”, “¿este producto es accesible?”, “auditoría a11y”, “informe de conformidad WCAG o Sección 508”, o cualquier evaluación multipágina. Evalúa; no corrige (usa `accessibility-fix`) ni compara diferencias (usa `accessibility-diff`). Para una sola página usa `accessibility-scan`; para verificaciones prácticas con teclado y lector de pantalla usa `accessibility-inspect`.
