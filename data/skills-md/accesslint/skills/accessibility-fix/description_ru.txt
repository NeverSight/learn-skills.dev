Только исправление — ремонтировать нарушения веб‑доступности (a11y) в соответствии с WCAG 2.2 с помощью цикла «базовый чек → редактирование → проверка». Принимает цель (URL, файлы, каталог) или список найденных проблем из `accessibility‑scan`/`accessibility‑inspect`/`accessibility‑audit`, применяет механические исправления как указано, оставляет TODO‑записи для визуального или контекстного суждения и проверяет, запуская базовый чек повторно. Он только исправляет. Чтобы найти проблемы, используйте `accessibility‑scan` (одна страница, автоматизировано), `accessibility‑inspect` (одна страница, вручную) или `accessibility‑audit` (весь сайт, WCAG‑EM); для проверки регрессий — `accessibility‑diff`. Применяйте это для «исправить проблемы a11y в X», «сделать это доступным», «добавить недостающие alt‑тексты и метки», «применить эти исправления доступности», «устранить эти нарушения».
