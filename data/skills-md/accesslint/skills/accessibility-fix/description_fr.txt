Remédiation uniquement — réparer les violations d'accessibilité Web (a11y) selon WCAG 2.2 avec une boucle baseline, édition et vérification. Prend comme cible (URL, fichiers, répertoire) ou une liste de constats provenant de `accessibility-scan`/`accessibility-inspect`/`accessibility-audit`, applique les correctifs mécaniques fournis, laisse des TODO pour le jugement visuel ou contextuel, et vérifie en relançant la vérification de référence. Il ne fait que corriger. Pour trouver les problèmes, utilisez `accessibility-scan` (une page, automatisé), `accessibility-inspect` (une page, manuel) ou `accessibility-audit` (site complet, WCAG‑EM) ; pour vérifier les régressions, utilisez `accessibility-diff`. Utilisez‑le pour « corriger les problèmes d’a11y dans X », « rendre cela accessible », « ajouter les textes alt et les libellés manquants », « appliquer ces correctifs d’accessibilité », « remédier à ces violations ».
