Remediación únicamente — reparar violaciones de accesibilidad web (a11y) según WCAG 2.2 con un bucle de línea base, edición y verificación. Acepta como objetivo (URL, archivos, directorio) o una lista de hallazgos de `accessibility-scan`/`accessibility‑inspect`/`accessibility‑audit`, aplica correcciones mecánicas según se indican, deja TODOs para juicio visual o contextual, y verifica ejecutando nuevamente la comprobación de línea base. Sólo corrige. Para encontrar problemas usa `accessibility-scan` (una página, automatizado), `accessibility‑inspect` (una página, manual) o `accessibility‑audit` (todo el sitio, WCAG‑EM); para comprobar regresiones usa `accessibility-diff`. Úsalo para “corregir los problemas de a11y en X”, “hacer esto accesible”, “añadir texto alternativo y etiquetas faltantes”, “aplicar estas correcciones de accesibilidad”, “remediar estas violaciones”.
