Controllo di regressione — confronta le violazioni di accessibilità web (a11y) di una pagina live rispetto a una baseline. Per impostazione predefinita confronta le modifiche non ancora committate (basate sullo stash); utilizza `--branch [<name>]` per confrontare con un branch. Riporta le nuove violazioni WCAG introdotte, quelle risolte e il numero di quelle preesistenti. Usalo per “la mia modifica ha rotto l’accessibilità”, “quali problemi di a11y ha aggiunto questa PR”, o come gate CI. Per una scansione completa di una pagina usa `accessibility-scan`; per un intero sito usa `accessibility-audit`.
