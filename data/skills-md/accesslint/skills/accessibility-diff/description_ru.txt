Проверка регрессии — сравнение нарушений веб‑доступности (a11y) живой страницы с базовым уровнем. По умолчанию сравнивает ваши непереданные изменения (на основе stash); передайте `--branch [<name>]`, чтобы сравнить с веткой. Выводит новые нарушения WCAG, которые появились, исправленные и количество уже существующих. Используйте для вопросов «сломал ли мой коммит доступность», «какие проблемы a11y добавил этот PR» или как проверку в CI. Для полного сканирования одной страницы используйте `accessibility-scan`; для всего сайта — `accessibility-audit`.
