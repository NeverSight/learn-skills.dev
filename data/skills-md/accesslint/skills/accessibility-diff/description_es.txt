Verificación de regresión — compara las violaciones de accesibilidad web (a11y) de una página en vivo con una línea base. Por defecto compara tus cambios no confirmados (basados en stash); pasa `--branch [<name>]` para comparar con una rama. Informa de las nuevas violaciones WCAG introducidas, las corregidas y el recuento de las preexistentes. Úsalo para “¿mi cambio rompió la accesibilidad?”, “¿qué problemas de a11y añadió este PR?” o como una puerta de CI. Para un escaneo completo de una página usa `accessibility-scan`; para un sitio completo usa `accessibility-audit`.
