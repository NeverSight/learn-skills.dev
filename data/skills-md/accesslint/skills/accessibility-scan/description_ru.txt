Одностраничный, автоматизированный уровень — запуск движка правил веб‑доступности (a11y) против живой страницы и обнаружение каждого нарушения, которое он может определить механически. Передайте URL, имя целевого конфига (например `accesslint:accessibility-scan dev`), или ничего, чтобы использовать целевой параметр по умолчанию из `accesslint.config.json`. Обеспечивает отлаживаемый Chrome, запускает движок @accesslint/core через CDP и возвращает список задач с нарушениями WCAG 2.2 в живом DOM, каждое из которых привязано к его селектору DOM и исходному `file:line`. Находит; не редактирует. Используйте его для «является ли эта страница доступной», «проверьте a11y по этому URL», «найдите проблемы контраста и альтернативного текста» или для проверки изменения UI. Для ручных проверок клавиатуры и скрин‑ридера используйте `accessibility-inspect`; для всего сайта или продукта — `accessibility-audit`; чтобы сравнить с неподтверждёнными изменениями или веткой, используйте `accessibility-diff`.
