單頁自動層——對即時頁面執行網頁無障礙（a11y）規則引擎，機械式找出所有它能偵測到的違規。傳入 URL、設定目標名稱（例如 `accesslint:accessibility-scan dev`），或什麼也不傳以使用 `accesslint.config.json` 中的預設目標。確保 Chrome 可偵錯，透過 CDP 執行 @accesslint/core 引擎，並回傳即時 DOM 的 WCAG 2.2 違規工作清單，每項都對應到其 DOM selector 與來源 `file:line`。僅定位，不會修改。可用於「此頁面是否可及」、『檢查此 URL 的無障礙』、『找出對比度與 alt 文字問題』，或驗證 UI 變更。實作鍵盤與螢幕閱讀器檢查請使用 `accessibility‑inspect`；整站或產品請使用 `accessibility‑audit`；與未提交的變更或分支比對請使用 `accessibility‑diff`。
