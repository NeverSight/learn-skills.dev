HTML PPT Studio : créez des présentations HTML statiques à partir de modèles. Un fichier de thème correspond à un style, un fichier de mise en page correspond à un type de page, une classe d'animation correspond à un effet d'entrée. Comprend des modèles de présentation complète, des effets Canvas FX et un mode présentateur avec script pour l'intervenant et minuteur. Aucune étape de compilation.
