Recherchiert gründlich eine Codebasis und entwirft eine Funktion durch iteratives Brainstorming
und Annotationszyklen und zerlegt es dann in eine umsetzbare Problemhierarchie
(übergeordnete + untergeordnete Probleme mit Abhängigkeiten) auf GitHub oder GitLab. Harte Tore dazwischen
Phasen stellen sicher, dass die Forschung vor dem Design stattfindet und dass das Design vorher abgeschlossen ist
Umsetzung. Jedes Unterthema ist so angelegt, dass keine kreativen Entscheidungen erforderlich sind.
