Investiga profundamente una base de código, diseña una función mediante una lluvia de ideas iterativa
y ciclos de anotación, luego lo descompone en una jerarquía de problemas implementable
(problemas principales + secundarios con dependencias) en GitHub o GitLab. Puertas duras entre
Las fases garantizan que la investigación se realice antes del diseño y que el diseño se complete antes de
implementación. Cada subtema tiene como objetivo no requerir decisiones creativas.
