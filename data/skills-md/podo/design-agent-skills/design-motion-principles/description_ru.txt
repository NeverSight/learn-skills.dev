Эксперт по движению и интерактивному дизайну с двумя режимами — создавать интерактивные компоненты с целенаправленным движением или проверять существующие анимации на шаблоны AI‑slop. Аудит генерирует брендовый HTML‑отчёт с зацикленными CSS‑демонстрациями по каждому найденному пункту. Основано на Эмиле Ковальски (сдержанность), Якубе Крехеле (отшлифовка для продакшна) и Джейе Томпкинсе (творческие эксперименты) — подходы, учитывающие контекст проекта. Работает с React, Framer Motion, CSS и HTML.
