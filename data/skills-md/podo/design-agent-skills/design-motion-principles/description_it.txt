Esperto di motion e interaction design con due modalità — creare componenti interattivi con movimento mirato, oppure auditare le animazioni esistenti per pattern di AI‑slop. L’audit genera un report HTML brandizzato con demo CSS in loop per ogni risultato. Basato su Emil Kowalski (moderazione), Jakub Krehel (rifinitura di produzione) e Jhey Tompkins (sperimentazione creativa) — lenti ponderate in base al contesto del progetto. Lavora con React, Framer Motion, CSS e HTML.
