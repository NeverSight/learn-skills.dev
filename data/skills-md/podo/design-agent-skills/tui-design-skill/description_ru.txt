Разрабатывает чистые, профессиональные терминальные пользовательские интерфейсы и CLI в четырёх экосистемах: Go (Bubble Tea/Lipgloss), Rust (Ratatui), Python (Textual) и TypeScript (Ink). Охватывает шаблоны компоновки, системы цветов, соглашения о привязке клавиш и специфические для фреймворка шаблоны проектирования.
