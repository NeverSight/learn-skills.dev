تطوير خلفية Python جاهزة للإنتاج باستخدام FastAPI. استخدم هذه المهارة كلما كان المستخدم يبني واجهة برمجة تطبيقات خلفية، أو يُنظّم خدمة Python، أو يصمّم طبقات النطاق، أو يُنشئ المستودعات، أو يُعدّ حقن التبعيات، أو يكتب Dockerfiles، أو يكوّن خطوط CI، أو ينفّذ الاختبارات، أو يتّخذ أي قرار معماري بخصوص خلفية Python. يغطي مفهوم DDD الخفيف، ومبادئ SOLID، وأنماط FastAPI، والتحقق باستخدام Pydantic، وتسجيل هيكلي، وأمان الحاويات، واستراتيجية الاختبار. يجب أن تشمل كل ميزة اختباراتٍ مُقابلة.
