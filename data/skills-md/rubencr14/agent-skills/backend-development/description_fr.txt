Développement backend Python prêt pour la production avec FastAPI. Utilisez cette compétence chaque fois que l'utilisateur construit une API backend, structure un service Python, conçoit des couches de domaine, crée des dépôts, met en place l'injection de dépendances, écrit des Dockerfiles, configure des pipelines CI, implémente des tests ou prend toute décision architecturale concernant un backend Python. Couvre le DDD léger, les principes SOLID, les patterns FastAPI, la validation Pydantic, la journalisation structurée, la sécurité des conteneurs et la stratégie de test. Chaque fonctionnalité doit inclure ses tests correspondants.

Veuillez toujours répondre dans la langue de l'utilisateur.
