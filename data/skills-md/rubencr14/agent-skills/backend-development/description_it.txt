Sviluppo backend Python pronto per la produzione con FastAPI. Usa questa competenza ogni volta che l'utente costruisce un'API backend, struttura un servizio Python, progetta livelli di dominio, crea repository, imposta l'iniezione delle dipendenze, scrive Dockerfile, configura pipeline CI, implementa test o prende qualsiasi decisione architettonica su un backend Python. Copre DDD leggero, principi SOLID, pattern FastAPI, validazione Pydantic, logging strutturato, sicurezza dei container e strategia di testing. Ogni funzionalità deve includere i relativi test.
