Разработка готового к продакшену бэкенда на Python с FastAPI. Используйте этот навык, когда пользователь создаёт API бэкенда, структурирует сервис на Python, проектирует доменные слои, создаёт репозитории, настраивает внедрение зависимостей, пишет Dockerfile, конфигурирует CI‑конвейеры, реализует тесты либо принимает любые архитектурные решения относительно бэкенда на Python. Охватывает лёгкое DDD, принципы SOLID, паттерны FastAPI, валидацию Pydantic, структурированное логирование, безопасность контейнеров и стратегию тестирования. Каждая функция должна включать соответствующие тесты.
