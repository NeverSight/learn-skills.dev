Desarrollo backend de Python listo para producción con FastAPI. Utiliza esta habilidad siempre que el usuario esté construyendo una API backend, estructurando un servicio Python, diseñando capas de dominio, creando repositorios, configurando inyección de dependencias, escribiendo Dockerfiles, configurando pipelines CI, implementando pruebas o tomando cualquier decisión arquitectónica sobre un backend Python. Cubre DDD ligero, principios SOLID, patrones de FastAPI, validación con Pydantic, registro estructurado, seguridad de contenedores y estrategia de pruebas. Cada característica debe incluir sus pruebas correspondientes.
