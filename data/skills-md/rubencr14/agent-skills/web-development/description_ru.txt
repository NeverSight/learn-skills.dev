Архитектура, паттерны и организация кода для приложений на Next.js и React. Используйте этот навык, когда пользователь разрабатывает фронтенд‑фичу, структурирует проект React/Next.js, решает, как организовать компоненты, создаёт уровни получения данных, настраивает паттерны репозиториев, работает с DTO и мапперами, либо принимает любое архитектурное решение по коду веб‑приложения. Охватывает организацию по функционалу, облегчённую чистую архитектуру, порты и адаптеры, границы серверных/клиентских компонентов, управление состоянием, обработку ошибок и контракты TypeScript. Это касается структуры кода и поддерживаемости — а не визуального дизайна (см. frontend-design) или механики тестов (см. web-testing).
