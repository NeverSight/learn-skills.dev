الهندسة المعمارية، الأنماط، وتنظيم الكود لتطبيقات Next.js وReact. استخدم هذه المهارة كلما كان المستخدم يبني ميزة للواجهة الأمامية، أو يُنظِّم مشروع React/Next.js، أو يقرر كيفية تنظيم المكونات، أو يُنشئ طبقات جلب البيانات، أو يُعد نمط المستودعات، أو يعمل مع DTOs والمحوِّلات، أو يتخذ أي قرار معماري بشأن قاعدة كود تطبيق ويب. يغطي تنظيم القابلية للميزات أولاً، والهندسة النظيفة الخفيفة، ومنفذ ومحول (Ports and Adapters)، وحدود مكونات الخادم/العميل، وإدارة الحالة، ومعالجة الأخطاء، وعقود TypeScript. هذا يتعلق ببنية الكود وقابليته للصيانة — وليس التصميم البصري (انظر frontend-design) أو آليات الاختبار (انظر web-testing).
