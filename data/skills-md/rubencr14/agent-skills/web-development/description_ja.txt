Next.js と React アプリケーションのアーキテクチャ、パターン、コード組織化。ユーザーがフロントエンド機能を構築する際、React/Next.js プロジェクトを構造化する際、コンポーネントの整理方法を決める際、データ取得層を作成する際、リポジトリパターンを設定する際、DTO とマッパーを扱う際、あるいはウェブアプリケーションのコードベースに関するあらゆるアーキテクチャ的決定を行う際にこのスキルを使用してください。機能優先の組織、クリーンアーキテクチャ・ライト、ポートとアダプター、サーバー／クライアントコンポーネントの境界、状態管理、エラーハンドリング、そして TypeScript の契約をカバーします。これはコード構造と保守性に関するものであり、視覚的デザイン（frontend‑design を参照）やテストメカニズム（web‑testing を参照）ではありません。
