Architecture, modèles et organisation du code pour les applications Next.js et React. Utilisez cette compétence chaque fois que l'utilisateur crée une fonctionnalité front‑end, structure un projet React/Next.js, décide comment organiser les composants, crée des couches de récupération de données, met en place des modèles de dépôt, travaille avec des DTO et des mappages, ou prend toute décision architecturale concernant la base de code d’une application web. Couvre l’organisation axée sur les fonctionnalités, une architecture propre légère, ports et adaptateurs, les limites entre les composants serveur/client, la gestion d’état, le traitement des erreurs et les contrats TypeScript. Il s’agit de la structure du code et de la maintenabilité — pas du design visuel (voir frontend-design) ni des mécanismes de test (voir web-testing). Veuillez toujours répondre dans la langue de l’utilisateur.
