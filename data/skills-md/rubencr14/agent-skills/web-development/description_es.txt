Arquitectura, patrones y organización de código para aplicaciones Next.js y React. Utiliza esta habilidad siempre que el usuario esté construyendo una característica de frontend, estructurando un proyecto React/Next.js, decidiendo cómo organizar los componentes, creando capas de obtención de datos, configurando patrones de repositorio, trabajando con DTOs y mapeadores, o tomando cualquier decisión arquitectónica sobre la base de código de una aplicación web. Cubre organización orientada a características, arquitectura limpia ligera, puertos y adaptadores, límites entre componentes de servidor/cliente, gestión de estado, manejo de errores y contratos TypeScript. Esto trata de la estructura del código y la mantenibilidad — no del diseño visual (ver frontend-design) ni de la mecánica de pruebas (ver web-testing). Por favor, responde siempre en el idioma del usuario.
