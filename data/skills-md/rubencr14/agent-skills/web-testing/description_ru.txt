Тестирование фронтенда с Vitest и Testing Library. Используется для юнит‑тестов, тестов компонентов, интеграционных тестов, визуальной регрессии и тестов доступности в веб‑приложениях. Охватывает React, Vue и фреймворк‑независимые паттерны, включая WebGL/Canvas, BVA, мокирование с MSW, покрытие кода и Testcontainers. Для Vitest — НЕ Playwright и не E2E‑автоматизация браузера.
