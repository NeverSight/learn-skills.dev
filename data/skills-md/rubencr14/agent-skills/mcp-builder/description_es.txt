Guía para crear servidores MCP (Protocolo de Contexto del Modelo) de alta calidad que permitan a los LLM interactuar con servicios externos a través de herramientas bien diseñadas. Úsela al construir servidores MCP para integrar APIs o servicios externos, ya sea en Python (FastMCP) o Node/TypeScript (MCP SDK).

Por favor, responda siempre en el idioma del usuario.
