OpenClash user feature guide. Used to answer users' questions about how to enable/disable various functions of the OpenClash plugin, including: switching operation mode, proxy toggle, DNS settings, traffic control, access control black/white lists, IPv6 toggle, rule/GEO updates, automatic restart, dashboard settings, subscription management, override settings, connection anomaly troubleshooting, etc. Each option is marked with the corresponding UCI configuration item, the modified Mihomo YAML configuration segment, and the triggered script. Use when user asks how to enable, disable, configure, or troubleshoot any OpenClash feature on OpenWrt.
