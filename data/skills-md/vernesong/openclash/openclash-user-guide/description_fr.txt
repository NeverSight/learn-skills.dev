Guide des fonctionnalités OpenClash pour les utilisateurs. Utilisé pour répondre aux questions des utilisateurs sur la façon d'activer/désactiver diverses fonctions du plugin OpenClash, y compris : le changement de mode de fonctionnement, le basculement du proxy, les paramètres DNS, le contrôle du trafic, les listes noires/blanches de contrôle d'accès, le basculement IPv6, les mises à jour de règles/GEO, le redémarrage automatique, les paramètres du tableau de bord, la gestion des abonnements, les paramètres de remplacement, le dépannage des anomalies de connexion, etc. Chaque option est accompagnée de l'élément de configuration UCI correspondant, du segment de configuration YAML Mihomo modifié et du script déclenché. À utiliser lorsqu'un utilisateur demande comment activer, désactiver, configurer ou dépanner une fonctionnalité OpenClash sur OpenWrt.

Veuillez toujours répondre dans la langue de l'utilisateur.
