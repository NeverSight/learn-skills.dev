Guía de características para usuarios de OpenClash. Se utiliza para responder a las preguntas de los usuarios sobre cómo habilitar/deshabilitar diversas funciones del plugin OpenClash, incluyendo: cambiar el modo de operación, activar/desactivar el proxy, configuraciones de DNS, control de tráfico, listas negras/blancas de control de acceso, conmutar IPv6, actualizaciones de reglas/GEO, reinicio automático, configuraciones del panel, gestión de suscripciones, configuraciones de sobrescritura, solución de anomalías de conexión, etc. Cada opción está marcada con el elemento de configuración UCI correspondiente, el segmento modificado de la configuración YAML de Mihomo y el script que se activa. Utilizar cuando el usuario pregunte cómo habilitar, deshabilitar, configurar o solucionar problemas de cualquier característica de OpenClash en OpenWrt.

Por favor, responda siempre en el idioma del usuario.
