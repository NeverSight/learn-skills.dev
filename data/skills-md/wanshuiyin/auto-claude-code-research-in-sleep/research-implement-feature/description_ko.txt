간단한 “implement X for me” 요청에서 작업 가능한 결과물을 만든다: 먼저 엔드‑투‑엔드 스파인을 실행 가능한 형태로 구축하고, 그 다음 각 단계마다 하나의 기능을 추가한다. 모든 불명확한 결정은 해당 코드를 작성하기 전에 가정 장부에 기록하고, 선언되지 않은 상황이 흐른 경우를 위해 교차 모델 검토를 수행한다. 사용자가 “给我实现”, “implement X”, “帮我做一个能跑的”, “先搭个原型再加功能”, “build this feature”, “prototype then extend”와 같이 말하거나 실험 계획이 아닌 기능 설명을 제공할 때 사용한다.

항상 사용자의 언어로 응답하세요.
