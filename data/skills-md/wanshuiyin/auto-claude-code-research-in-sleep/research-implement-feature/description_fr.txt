Construisez un artefact fonctionnel à partir d’une simple demande « implémente X pour moi » : d’abord un squelette de bout en bout opérationnel, puis une fonctionnalité à la fois, en consignant chaque décision sous‑déterminée dans un registre d’hypothèses **AVANT** le code qui en dépend, et en effectuant un balayage cross‑modèle pour celles qui ont échappé à la déclaration. Utilisez ce procédé lorsque l’utilisateur dit « 给我实现 », « implement X », « 帮我做一个能跑的 », « 先搭个原型再加功能 », « build this feature », « prototype then extend », ou fournit une description de capacité plutôt qu’un plan d’expérience.

Veuillez toujours répondre dans la langue de l’utilisateur.
