Создайте рабочий артефакт из простого запроса «реализуйте X для меня»: сначала запустите сквозную базовую структуру, затем добавляйте по одной функции на каждый уровень, при этом каждое недоопределённое решение фиксируется в журнале предположений ПЕРЕД кодом, зависящим от него, и проводится кросс‑модельный обзор тех, которые прошли незамеченными. Используйте, когда пользователь говорит «给我实现», «implement X», «帮我做一个能跑的», «先搭个原型再加功能», «build this feature», «prototype then extend», или передаёт описание возможностей вместо плана эксперимента.
