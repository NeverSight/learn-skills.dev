Construye un artefacto funcional a partir de una solicitud simple de “implementa X para mí”: primero una columna vertebral completa y operativa, luego una característica por cada peldaño, con cada decisión indeterminada anotada en un registro de suposiciones ANTES del código que dependa de ella y una revisión transversal de modelos para las que se hayan escapado sin declararse. Úsalo cuando el usuario diga “给我实现”, “implement X”, “帮我做一个能跑的”, “先搭个原型再加功能”, “build this feature”, “prototype then extend”, o entregue una descripción de capacidad en lugar de un plan de experimento.

Por favor, responde siempre en el idioma del usuario.
