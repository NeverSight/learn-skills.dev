Registre des compétences UI/UX frontend de qualité production. Acheminement automatique vers la compétence appropriée en fonction de l'intention de l'utilisateur. À utiliser pour tout ce qui concerne ce que les utilisateurs voient et sur quoi ils cliquent dans un navigateur : création ou correction de composants, de pages et de mises en page React/Next.js ; défauts visuels ; animations ; tableaux de bord ; formulaires ; audits d'accessibilité ; performances frontend ; 3D avec Three.js/R3F ; systèmes de conception et tokens ; et tests pour tout cela. À ne pas utiliser pour la logique backend, les API, les bases de données et l'infrastructure.
