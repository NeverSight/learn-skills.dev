Wird verwendet, wenn der Benutzer in einem benannten Modul darum bittet, eine Wissensdatenbank-Seite (Konzept, Tabelle, Vertrag, Nutzungsfluss oder Muster) aus einem Rohartefakt, einem Schema- oder Tabellenexport oder Code zu schreiben oder zu aktualisieren, z. B. "Schreiben einer Vertragsseite für X", oder um ein bearbeitetes Artefakt zu markieren. Nicht zur Beantwortung von Fragen von bestehenden Seiten oder zur Registrierung von Modulen.
