Se utiliza cuando el usuario solicita, en un módulo con nombre, escribir o actualizar una página de base de conocimientos (concepto, tabla, contrato, flujo de uso o patrón) a partir de un artefacto sin procesar, un esquema o exportación de tabla, o código, por ejemplo, "escribir una página de contrato para X", o marcar un artefacto procesado. No es para responder preguntas de páginas existentes o para registrar módulos.
