Se utiliza cuando el usuario solicita configurar, arrancar o reanudar la configuración de un espacio de trabajo de enrutamiento de contexto en un repositorio, por ejemplo, "convertir este repositorio en un espacio de trabajo de enrutamiento de contexto". Ejecuta un arranque por fases y reanudable. No para añadir un módulo a un espacio de trabajo existente (use add-module) y no para el trabajo rutinario en un espacio de trabajo terminado.
