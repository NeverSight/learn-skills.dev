Wird verwendet, wenn der Benutzer zum Einrichten, Starten oder Fortsetzen des Einrichtens eines Context-Routing-Arbeitsbereichs in einem Repository auffordert, z. B. „dieses Repo in einen Context-Routing-Arbeitsbereich umwandeln“. Führt einen phasenweisen, wiederaufnehmbaren Bootstrap aus. Nicht zum Hinzufügen eines Moduls zu einem vorhandenen Arbeitsbereich (verwenden Sie das Add-Modul) und nicht für Routinearbeiten in einem fertigen Arbeitsbereich.
