À utiliser lorsque l'utilisateur demande de configurer, d'amorcer ou de reprendre la configuration d'un espace de travail de routage contextuel dans un référentiel, par exemple « transformer ce repo en espace de travail de routage contextuel ». Exécute un bootstrap phasé et résorbable. Pas pour ajouter un module à un espace de travail existant (utilisez add-module) et pas pour le travail de routine dans un espace de travail fini.
