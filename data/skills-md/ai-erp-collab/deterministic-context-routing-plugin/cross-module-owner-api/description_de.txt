Wird verwendet, wenn eine Aufgabe im aktiven Modul eine Regel benötigt, die einem anderen Modul gehört (z. B. Zugriffsregeln, ein Hierarchiepfad, Statusübergänge), oder wenn der Benutzer fragt, ob eine solche Regel existiert, oder sagt, dass ein anderes Modul wiederverwendet oder erweitert werden soll. Findet den Eigentümer, behält die Regel hinter einer Eigentümer-API bei und verknüpft Verbraucher und Eigentümer.
