À utiliser lorsqu'une tâche du module actif nécessite une règle appartenant à un autre module (par exemple, des règles d'accès, une marche hiérarchique, des transitions d'état) ou lorsque l'utilisateur demande si une telle règle existe ou dit de réutiliser ou d'étendre un autre module. Recherche le propriétaire, conserve la règle derrière une API propriétaire et relie le consommateur et le propriétaire.
