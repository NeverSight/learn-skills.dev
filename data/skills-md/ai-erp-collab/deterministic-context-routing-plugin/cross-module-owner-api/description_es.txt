Se utiliza cuando una tarea en el módulo activo necesita una regla propiedad de otro módulo (por ejemplo, reglas de acceso, un paseo jerárquico, transiciones de estado), o el usuario pregunta si tal regla existe o dice que se reutilice o amplíe otro módulo. Encuentra al propietario, mantiene la regla detrás de una API de propietario y vincula al consumidor y al propietario.
