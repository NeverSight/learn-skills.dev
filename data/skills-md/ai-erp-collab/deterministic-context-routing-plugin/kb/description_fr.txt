À utiliser lorsqu'un message de crochet KB ou un problème de vérification doit être résolu, qu'un fichier source est trop volumineux pour une lecture, qu'une preuve ou qu'une exportation de tableau arrive, que l'utilisateur demande si la base de connaissances a déjà une page ou un terme pour quelque chose, qu'une technique stable peut devenir une recette ou que l'espace de travail a besoin d'une mise à niveau. Exécute l'outil d'intégrité.
