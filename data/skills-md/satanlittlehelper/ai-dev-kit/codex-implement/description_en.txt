Delegates implementation of an already-approved plan (from writing-plans) to a single long-running Codex session that writes code directly (workspace-write sandbox). Codex chooses and drives its own superpowers:subagent-driven-development or superpowers:executing-plans to work the plan end to end, including tests. Never touches git — Codex may not commit, and the skill never offers to. Always runs in the current working directory / current branch — there is no worktree mode and no mode choice. Codex runs in a sandbox that cannot install dependencies, use Docker or reliably run tests, so it hands those steps back to Claude via an IMPLEMENTATION_HANDOFF sentinel; Claude executes them (install, confirm tests are red, confirm green), reports the results into the same Codex session and resumes it — this keeps the plan's TDD order intact. Only when everything is green does Claude run the final review, finish and clean up all service artifacts. Invoke as `/codex-implement <plan-path>`.
