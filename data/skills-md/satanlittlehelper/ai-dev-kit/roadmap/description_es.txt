Usa para cualquier cosa que implique una hoja de ruta (un plan de varias fases y puntos de control rastreado con casillas de verificación en markdown bajo docs/<feature-slug>/) — crear una para una tarea demasiado grande para una sola especificación/plan ("roadmap"/"дорожная карта", migración de varias semanas, despliegue multiversión, reescritura por fases), una solicitud genérica de “continuemos la hoja de ruta” que no especifica si se trata de documentación o implementación, tomar el siguiente punto de control sin terminar ("возьми следующую задачу в роадмапе", "take the next roadmap task", "next roadmap checkpoint"), o redactar y validar en lote varios de los planes/especificaciones de sus pasos a la vez ("напиши несколько планов", "пройтись по роадмапу", "на все задачи роадмапа"). Esta habilidad es el punto de entrada único para todo eso: lee la situación y dirige al archivo de referencia correcto por sí mismo.
