Orcaが管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、およびOrcaの組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」・「child worktree」・「spawn codex/claude in a worktree」・「read/wait/send Orca terminal」・「handoff」／「handover」／「give this to another agent」・「Orca browser」・「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、純粋な git worktree、即席の PTY、あるいは Computer Use よりもこれを優先してください。CLI、ファイルシステム、API では対応できない可視ウィンドウの GUI 操作が必要な場合にのみ Computer Use を利用してください。
