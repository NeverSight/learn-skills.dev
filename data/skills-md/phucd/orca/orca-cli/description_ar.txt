قم بتشغيل أشجار عمل مُدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج من خلال سطر الأوامر `orca`. استخدم ذلك عندما يذكر المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل هذا الخيار على استخدام git worktree الخام، أو PTYs المؤقتة، أو الاستخدام الحاسوبي عندما تكون حالة Orca متضمنة. استخدم الاستخدام الحاسوبي فقط عندما تتطلب نافذة مرئية التحكم في واجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو واجهة برمجة التطبيقات القيام بذلك.
