Crea, ritocca o migliora una Skill di Agente. Chiede dove la skill dovrebbe essere collocata — all’interno di questa suite, in un progetto o per un singolo utente — e poi la scrive lì con le regole e le fasi di rilascio richieste da quella posizione. Usala quando ti viene chiesto di creare una skill, trasformare un workflow in una skill, correggere una descrizione o un trigger, ristrutturare una skill eccessivamente complessa o ritoccare una skill esistente.

Per favore rispondi sempre nella lingua dell’utente.
