Lavoro manuale tra sessioni in qualsiasi harness. mode:write (predefinito) scrive un file di handoff autonomo in /tmp/sassywares e fornisce all'utente un comando per continuare in una nuova sessione; mode:read prende un file di handoff, spiega cosa è stato fatto, perché e a che punto si è, quindi chiede cosa fare dopo. Usalo al confine di una fase, quando il contesto sta diventando lungo, quando l'utente chiede di fare l'handoff o per riprendere un file di handoff.

Rispondi sempre nella lingua dell'utente.
