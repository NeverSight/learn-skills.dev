Hand work between sessions in any harness. mode:write (default) writes a self-contained handoff file under /tmp/sassywares and gives the user a command to continue in a fresh session; mode:read takes a handoff file, explains what was done, why, and where things stand, then asks what to do next. Use at a phase boundary, when context is getting long, when the user asks to hand off, or to pick up a handoff file.
