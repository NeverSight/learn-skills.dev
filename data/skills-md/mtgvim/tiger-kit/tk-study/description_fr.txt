Il est utilisé lorsqu’on demande un processus d’apprentissage ou des supports d’études avancés qui enseignent plusieurs concepts chapitre par chapitre selon les connaissances préalables. Il n’est pas utilisé pour la recherche comparative afin de sélectionner une approche, les questions courtes de concept, les explications de modification de code ou la rédaction de compétences.
