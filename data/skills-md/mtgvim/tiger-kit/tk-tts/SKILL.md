# 로컬 내레이션 생성

<a id="shared-references"></a>
## 공통 참조

현재 설치된 소유 스킬에서 해당 분기의 조건에 따라 기준을 읽습니다. 소유 스킬이나 자원이 없거나 식별이 다르면 해당 행동을 중단합니다. 기억, 다른 설치본이나 승인되지 않은 설치로 대신하지 말고 `tk-setup-skills`를 사용합니다. 참조 읽기는 워크플로 실행이나 변경 권한을 부여하지 않습니다.

- 사용자 소유 결정·누락된 승인·미충족 선행 조건을 질문이나 질문 도구 입력으로 제시하기 직전에 [질문 라운드](../tk-questioning/references/questions.md)를 이번 작업에서 읽었는지 확인하고 누락했으면 먼저 읽습니다. 독립적인 결정과 승인은 각각 별도 질문으로 두며, 승인 선택지를 결정 질문에 섞지 않습니다.
- 사용자에게 완료 보고를 하거나 산출물 경로를 인계하거나 채팅에서 여러 속성을 비교하기 전에 [채팅 전달](../tk-writing/references/delivery.md)을 읽습니다. 해당 작업의 구체적인 출력 계약이 우선합니다.

원고에서 WAV로의 합성, 고정된 모델/런타임, 승인된 캐시 재사용과 오디오 검증을 담당합니다. `tk-video`는 장면/인코딩을 담당하며 교육 작업의 호출자는 수업 내용을 담당합니다. 일반 오디오와 측정한 길이를 반환합니다. 형제 패키지를 import하거나 수정하지 않습니다. 생성은 발행 권한을 부여하지 않습니다.

엔진을 import하지 않고 지원되는 로컬 경로를 확인하려면 `scripts/list_options.py`를 실행합니다. 선택지를 제안하기 전에 실제 장치/의존성/캐시를 비교합니다. 미지정 시 첫 추천은 플랫폼과 관계없이 Supertonic 3 ONNX CPU/F1이며, 추천은 사용자 답변이 아니므로 엔진 선택을 묻습니다. 해당 upstream은 보관 처리되어 유지보수·보안 수정이 없고 AI 합성 고지가 필요합니다. Qwen3 0.6B CustomVoice MLX 5bit는 Apple Silicon에서 sohee·serena 화자가 필요할 때의 선택지이고 ppaso ONNX CPU는 경량 한국어 선택지입니다. 명시적인 Qwen MLX 8bit와 공식 PyTorch도 유지합니다. 탐색은 런타임/모델 준비 완료나 품질 순위를 의미하지 않습니다. 선택지를 제시할 때부터 “이 경로를 고르면 영상 전체에 작은 AI 합성 고지가 들어갑니다”라고 알립니다. 선택되면 사용자에게 고지가 필요하다고 알리고 receipt의 `disclosure_required`와 `disclosure_notice`를 반환합니다. 오디오/영상에 자동으로 표시했다고 주장하지 않습니다. 호출자가 전달한 유효한 저장 선호는 `scripts/list_options.py --preferred <id>`로 표시하며, 현재 명시적 선택이 없을 때 그 엔진을 첫 추천으로 제시합니다. `preferred`와 미지정 시의 `recommended`는 별개이며, 이 스킬이 다른 담당자의 설정 파일을 직접 읽지 않습니다. 선호값이 있어도 `list_options.py`의 모든 경로를 장치/플랫폼, 목소리와 의존성/캐시 준비 상태와 함께 제시합니다. 선호 엔진이 준비되지 않았으면 설치 안내와 대안 선택지를 제시하고 자동으로 다른 엔진에 넘기지 않습니다. 현재 요청이나 유효한 저장값으로 엔진이 이미 확정되었으면 같은 선택을 반복 질문하지 않습니다. 저장값과 미지정 시 추천의 해석·승인 경계는 [미디어 선호](../tk-writing/references/media-preferences.md)를 따릅니다. 과거 평가는 권고에만 영향을 주며 표시할 엔진을 제한하지 않습니다. 공통 질문 계약의 도구 우선순위와 대체 형식을 적용하고, 지원되지 않거나 설치되지 않은 경로도 한계와 함께 유지합니다. 검증, 다운로드나 합성 전에 [설치와 고정 버전](references/installation.md)을 읽습니다. 검증된 설정과 일치하는 승인을 재사용합니다. 작업 전에 중요한 엔진/목소리 선택을 확정합니다. 실패 후 엔진을 몰래 바꾸거나 전역 환경에 설치하지 않습니다.

선택한 합성에는 [합성과 검사](references/synthesis.md)를 읽습니다. 직접 작성한 UTF-8 발음 교정 텍스트, 완전한 문장, 순차 요청과 새로운 WAV 경로를 사용합니다. 자막/UI literal은 별도로 충실하게 보존합니다. 제한된 마감 시간/정체 점검을 적용한 새 실행 소유 프로세스에서 선택한 로컬 adapter만 실행합니다. 오디오를 디코딩하고 유효하지 않거나 비유한 값이 있거나 무음인 오디오는 거부합니다. 측정한 길이, 엔진/모델 revision, 문장/캐시/메모리 사실과 `human_action: listen`을 반환합니다. 실제 의미, 발음, 고유 명사/숫자와 잘린 끝부분은 직접 들을 때까지 확인 대기 상태로 남습니다. 무음이 아니라는 사실이 알아들을 수 있다는 뜻은 아닙니다. ASR, 목소리 복제, 유료/클라우드 합성, 상주 서버나 자동 엔진 fallback을 추가하지 않습니다.

여러 클립으로 구성된 내레이션은 전달 전에 [오디오 후처리](references/postprocessing.md)를 읽습니다. 일괄 정규화한 결과를 새 파일에 저장하고 원본 WAV를 보존하며, 측정한 처리 내용/한계를 반환합니다.

사용할 수 없는 선행 조건은 안전한 모듈 정보 또는 실제/기대 버전 상세와 승인된 복구 경로를 함께 보고합니다. 원본 오디오/캐시 바이트를 보존하고 실행 소유가 입증된 임시 자료만 정리합니다. 간결한 경로와 실제 검증 결과/남은 청취 한계를 반환합니다. 이미 명시한 내레이션 선택을 다시 질문할 필요는 없습니다. 목소리나 엔진 선호만으로 TTS 사용·설치·다운로드가 승인되지는 않습니다. `voice`와 대체값 sohee는 선택한 Qwen 경로에만 적용하고, 다른 엔진에서는 무시한다는 사실을 선택 질문에 표시합니다.

출처와 의도적으로 제외한 사항은 [출처](references/sources.md)를 참조합니다.

<a id="artifact-paths"></a>
## 산출물 경로

승인된 산출물 쓰기, checkout/전송/제외 설정 또는 임시 입력 소비 전에 [산출물 경로](../tk-artifacts/references/artifact-paths.md)를 읽습니다. 저장소 임시 자료에는 소유권이 확인된 안전한 nonsymlink 경로와 입증된 Git 제외를 사용합니다. 점검 실패 시 해당 파일 분기를 중단합니다. 명시한 최종 목적지와 소유자별 기본값을 보존합니다. 미리 채운 입력은 입력 완료가 아닙니다. 정리 대상은 기록된 literal 형태의 해석된 절대 경로 중 실행 소유 경로로만 제한하며, cwd 상대 경로나 glob을 사용하지 않습니다.
