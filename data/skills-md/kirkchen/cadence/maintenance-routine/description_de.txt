Wird verwendet, wenn ein geplanter mechanischer Wartungsdurchlauf über ein Repo ausgeführt wird – Entfernung von totem Code, Bereinigung nutzloser Tests, Behebung von Layering-Verletzungen, Duplikatvereinheitlichung, Behebung von Logikfehlern, Logikvereinfachung oder Reduzierung übermäßiger Abstraktion. Wird als „/cadence:maintenance-routine <archetype>“ aufgerufen, normalerweise von einem Planer (Cron, ein CI-Zeitplan oder der Zeitauslöser einer Agent Workbench). Ein Archetyp pro Aufruf; öffnet PRs und führt niemals zusammen. NICHT zum Überprüfen einer PR (verwenden Sie PR-Review), NICHT für Ad-hoc-Refactoring, das der Benutzer direkt angefordert hat.
