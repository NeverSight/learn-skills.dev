À utiliser lors de l'exécution d'une maintenance mécanique planifiée sur un dépôt : suppression de code mort, élagage de tests inutiles, correction de violations de superposition, unification des doublons, correction de bogues logiques, simplification logique ou aplatissement d'abstraction excessive. Invoqué en tant que `/cadence:maintenance-routine <archetype>`, généralement à partir d'un planificateur (cron, une planification CI ou un déclencheur temporel d'un agent Workbench). Un archétype par invocation ; ouvre les PR et ne fusionne jamais. PAS pour réviser un PR (utilisez la pré-révision), PAS pour une refactorisation ad hoc demandée directement par l'utilisateur.
