Ejecuta un equipo de entrega multi‑agente con dotación obligatoria, bloqueos de alcance y puertas de verificación. Úsalo al coordinar varios agentes de IA en una única base de código — dimensionando el equipo más pequeño para una tarea, congelando un diff verificado antes de un commit, manteniendo el trabajo de un escritor independiente de su verificador o auditando por qué se envió un cambio. Incluye un resolvedor de forma de flujo de trabajo, un tablero de tareas duradero, contratos de roles y el protocolo de entrega. Ajustado para la aplicación Herdr; la política y los scripts se ejecutan con cualquier entorno de agente.
