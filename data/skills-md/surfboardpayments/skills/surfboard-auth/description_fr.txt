Identifiants et authentification de Surfboard Payments : obtenir les clés API de démonstration depuis la console développeur, le modèle d’en‑tête API-KEY/API-SECRET/MERCHANT‑ID, les jetons d’authentification client pour les navigateurs et les applications mobiles, ainsi que les emplacements où chaque schéma est autorisé ou non. À utiliser lors de la configuration des identifiants Surfboard, du débogage d’une erreur 401 ou 403, ou de l’appel de l’API depuis le code côté client.
