Bauen Sie Kartenzahlungen im Laden mit Surfboard Payments auf: Erstellen Sie eine Bestellung an einem Terminal, initiieren Sie eine CARD/SWISH/KLARNA‑Zahlung, prüfen Sie den Status ab und stellen Sie einen Beleg aus. Unterstützt SurfTouch, SurfPad, SurfPrint, SurfMini, CheckoutX SoftPOS, inter‑App‑Integration, Trinkgelder und Teilzahlungen. Einsatz für POS, Kasse, Kiosk oder jede Integration, die ein physisches Zahlungsterminal steuert.
