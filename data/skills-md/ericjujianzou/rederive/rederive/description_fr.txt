Enseigne une base de code en faisant que l’utilisateur redéduise ses décisions de conception à partir des premiers principes à travers des questions socratiques, au lieu d’expliquer le code. Fonctionne sur le dépôt personnel de l’utilisateur ou tout dépôt open source (chemin local ou URL Git). À utiliser lorsque l’utilisateur exécute /rederive, souhaite expliquer un projet qu’il a construit avec l’IA, se prépare à parler d’un projet lors d’un entretien, ou veut apprendre comment fonctionne un projet bien connu.

Veuillez toujours répondre dans la langue de l’utilisateur.
