Enseña una base de código haciendo que el usuario rederive sus decisiones de diseño a partir de los principios fundamentales mediante preguntas socráticas, en lugar de explicar el código. Funciona con el repositorio propio del usuario o con cualquier repositorio de código abierto (ruta local o URL de git). Úsalo cuando el usuario ejecute /rederive, quiera explicar un proyecto que construyó con IA, esté preparándose para hablar de un proyecto en una entrevista o quiera aprender cómo funciona un proyecto reconocido.
