COMMENCEZ ICI après avoir installé les compétences de Brad Frost — exécutez-le une fois pour tout configurer. Trouve laquelle des compétences vous avez installée, exécute la configuration dont chacun a besoin (entretien sur les limites) et vous indique comment utiliser celles qui n'ont pas besoin de configuration. À utiliser lorsque l'utilisateur dit « configurer les compétences en matière de gel », exécute /configure les compétences en matière de gel, vient d'installer cette collection ou demande comment commencer à utiliser ces compétences.
