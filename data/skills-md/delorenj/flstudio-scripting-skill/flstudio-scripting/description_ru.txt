Python‑скриптинг FL Studio для разработки MIDI‑контроллеров, манипуляций с пианороллом, аудио‑редактирования в Edison, автоматизации рабочего процесса и парсинга FLP‑файлов с помощью PyFLP. Используется для программной конфигурации, настройки устройств, MIDI‑транспорта, макросов и манипуляций сохранёнными файлами. Охватывает все более 427 функций API в 14 модулях MIDI‑скриптинга, а также контексты пианоролла, Edison и PyFLP.
