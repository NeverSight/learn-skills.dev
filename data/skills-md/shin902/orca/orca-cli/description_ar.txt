تشغيل شجرة العمل المدارة بواسطة Orca وسياقات المجلدات والطرفيات والمستودعات والأتمتة والقطع الأثرية ومشاركة المهارات وتعليقات شجرة العمل والمتصفح المدمج لـ Orca عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على استخدام git worktree الخام أو PTYs المؤقتة أو استخدام الحاسوب عندما تكون حالة Orca متورطة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى تحكم رسومي لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به.  

الرجاء دائمًا الرد بلغة المستخدم.
