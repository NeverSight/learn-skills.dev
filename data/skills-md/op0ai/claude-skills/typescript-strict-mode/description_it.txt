Guida per pratiche TypeScript rigorose, includendo l'evitare `any`, l'uso di annotazioni di tipo corrette e lo sfruttamento efficace del sistema di tipi di TypeScript. Da utilizzare quando si lavora con codebase TypeScript che impongono controlli di tipo severi, quando serve una guida sui pattern di sicurezza dei tipi o quando si incontrano errori di tipo. Si attiva per errori di tipo TypeScript, violazioni della modalità strict o migliori pratiche generali di TypeScript.
