Guía para prácticas estrictas de TypeScript, que incluye evitar any, usar anotaciones de tipo apropiadas y aprovechar eficazmente el sistema de tipos de TypeScript. Úsela al trabajar con bases de código de TypeScript que imponen una verificación de tipos estricta, cuando necesite orientación sobre patrones de seguridad de tipos o al encontrarse con errores de tipos. Se activa para errores de tipos de TypeScript, violaciones del modo estricto o mejores prácticas generales de TypeScript.
