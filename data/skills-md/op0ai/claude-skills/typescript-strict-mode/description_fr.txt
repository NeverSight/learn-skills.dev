Guide des pratiques strictes TypeScript, incluant l’évitement de any, l’utilisation d’annotations de type appropriées et l’exploitation efficace du système de types de TypeScript. À utiliser lors du travail avec des bases de code TypeScript qui imposent une vérification stricte des types, lorsque vous avez besoin de conseils sur les modèles de sécurité de type, ou en cas d’erreurs de type. S’active pour les erreurs de type TypeScript, les violations du mode strict ou les meilleures pratiques générales de TypeScript.
