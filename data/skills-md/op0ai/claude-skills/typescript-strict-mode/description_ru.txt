Руководство по строгим практикам TypeScript, включающее избегание any, использование корректных аннотаций типов и эффективное применение системы типов TypeScript. Используйте его при работе с кодовой базой TypeScript, где включён строгий режим проверки типов, когда нужна рекомендация по паттернам обеспечения типовой безопасности, либо при возникновении ошибок типов. Активируется при ошибках типов TypeScript, нарушениях строгого режима или общих рекомендациях по лучшим практикам TypeScript.
