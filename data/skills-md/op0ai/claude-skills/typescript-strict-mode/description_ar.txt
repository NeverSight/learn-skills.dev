دليل للممارسات الصارمة في TypeScript يشمل تجنّب any، واستخدام تعليقات نوعية صحيحة، والاستفادة الفعّالة من نظام النوع في TypeScript. يُستَخدم عند العمل مع قواعد شفرة TypeScript التي تُفرض فحص نوع صارم، أو عندما تحتاج إلى إرشاد حول أنماط أمان النوع، أو عند مواجهة أخطاء نوع. يُفَعَّل عند حدوث أخطاء نوع في TypeScript، أو انتهاكات الوضع الصارم، أو لممارسات TypeScript العامة.
