Claude Code と claude-in-chrome MCP を使用すると、ユーザーの既存のログイン ChatGPT Web セッションを再利用し、任意の ChatGPT モデルにタスクを委任し、会話、プロジェクト、メモリ、ライブラリなどを管理しながら、会話、アーティファクト、画像をローカルに保存することができます。これは、「ChatGPT に質問する / GPTPro に考えさせてもらう / @Google ドライブを使用してリストする / ChatGPT に詳細な調査をしてもらう / この会話を削除する / すべてのチャットをアーカイブする / 共有を取り消す / メモリをクリアする / プロジェクトを作成する / この会話を保存する / その DR レポートをダウンロードする / この画像をローカルに保存する」などというユーザーに適しています。別の自動ブラウザは起動せず、Cookie やセッションにも影響しません。
