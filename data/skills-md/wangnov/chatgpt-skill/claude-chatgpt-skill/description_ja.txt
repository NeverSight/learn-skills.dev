Claude Code と claude-in-chrome MCP を使用すると、ユーザーの既存のログイン済み ChatGPT Web セッションを再利用したり、任意の ChatGPT モデルにタスクを委任したり、会話、プロジェクト、メモリ、ライブラリなどを管理したりしながら、会話、アーティファクト、画像をローカルに保存したりできます。これは、「ChatGPT に質問する / GPTPro に考えさせてもらう / @Google Drive を使ってリストする / ChatGPT に詳細な調査をしてもらう / この会話を削除する / すべてのチャットをアーカイブする / 共有を元に戻す / メモリをクリアする / プロジェクトを作成する / この会話を保存する / その DR レポートをダウンロードする / この画像をローカルに保存する」などというユーザーに適しています。別の自動化ブラウザを起動したり、Cookie やセッションにアクセスしたりすることはありません。
