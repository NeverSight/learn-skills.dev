С помощью Claude Code и Claude-in-Chrome MCP вы можете повторно использовать существующий веб-сеанс пользователя, вошедшего в систему ChatGPT, делегировать задачи любой модели ChatGPT и управлять разговорами, проектами, памятью, библиотеками и т. д., а также сохранять разговоры, артефакты и изображения локально. Это подходит для пользователей, которые говорят: «Спросите ChatGPT / Позвольте GPTPro помочь мне подумать / Перечислите его с помощью @Google Drive / Попросите ChatGPT провести глубокое исследование / Удалить этот разговор / Архивировать все чаты / Отменить общий доступ / Очистить память / Создать проект / Сохранить этот разговор / Загрузите этот отчет о аварийном восстановлении / Сохраните это изображение локально» и так далее. Он не запускает отдельный браузер автоматизации и не трогает файлы cookie или сеансы.
