Über Claude Code und das claude-in-chrome MCP können Sie die bestehende, angemeldete ChatGPT-Websitzung des Benutzers wiederverwenden, Aufgaben an ein beliebiges ChatGPT-Modell delegieren und Konversationen, Projekte, Speicher, Bibliotheken usw. verwalten und gleichzeitig Konversationen, Artefakte und Bilder lokal speichern. Es eignet sich für Benutzer, die sagen: „Fragen Sie ChatGPT / Lassen Sie GPTPro mir beim Nachdenken helfen / Listen Sie es mit @Google Drive auf / Lassen Sie ChatGPT eine gründliche Recherche durchführen / Löschen Sie diese Konversation / Archivieren Sie alle Chats / Machen Sie diese Freigabe rückgängig / Löschen Sie den Speicher / Erstellen Sie ein Projekt / Speichern Sie diese Konversation / Laden Sie diesen DR-Bericht herunter / Behalten Sie dieses Bild lokal“ und so weiter. Es wird kein separater Automatisierungsbrowser gestartet und Cookies oder Sitzungen werden nicht berührt.
