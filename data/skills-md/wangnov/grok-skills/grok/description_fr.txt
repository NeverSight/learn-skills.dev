Pilotez l’interface en ligne de commande grok build (exécutez `grok`) pour la recherche, l’investigation et la création de médias. Utilisez‑la pour la recherche Web Grok/X avec citations ; la recherche parallèle à grande échelle via grok headless + sous‑agents ; la génération d’images (image_gen) et de vidéos (image_to_video) via la session grok connectée sans frais d’API ; et le post‑traitement ffmpeg tel que la suppression d’écran vert / chroma‑key, la concaténation et l’ajout de filigrane. Multi‑plateforme (macOS/Linux/Windows). API de recherche/média xAI en option comme solution de secours payante. Les déclencheurs incluent grok, grok build, 生图, 生成图片, 生成视频, 绿幕抠像, 批量调研, xAI search.
