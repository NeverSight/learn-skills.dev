Maneja la CLI de grok build (ejecuta `grok`) para búsqueda, investigación y creación de medios. Úsala para búsquedas web con Grok/X con citas; investigación paralela a gran escala mediante grok headless + subagentes; generación de imágenes (image_gen) y videos (image_to_video) a través de la sesión iniciada de grok sin costo de API; y post‑procesado con ffmpeg como eliminación de pantalla verde/croma, concatenación y marca de agua. Multiplataforma (macOS/Linux/Windows). API de búsqueda/medios xAI opcional como alternativa de pago. Los disparadores incluyen grok, grok build, 生图, 生成图片, 生成视频, 绿幕抠像, 批量调研, xAI search.
