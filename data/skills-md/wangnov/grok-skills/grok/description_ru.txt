Используйте CLI grok build (запускайте `grok`) для поиска, исследований и создания медиа. Применяйте для веб‑поиска Grok/X с цитатами; масштабных параллельных исследований через grok headless + субагенты; генерации изображений (image_gen) и видео (image_to_video) в рамках авторизованной сессии grok без затрат на API; а также постобработки ffmpeg, такой как удаление хромакея/зелёного экрана, склейка и наложение водяных знаков. Кроссплатформенно (macOS/Linux/Windows). По желанию доступен платный резервный API поиска/медиа xAI. Триггеры включают grok, grok build, 生图, 生成图片, 生成视频, 绿幕抠像, 批量调研, xAI search.
