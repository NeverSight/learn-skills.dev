検索、調査、メディア作成のために grok build CLI（`grok` を実行）を駆動します。引用付きの Grok/X Web 検索、grok headless とサブエージェントによる大規模並列調査、ログイン済みの grok セッションで API コストゼロで画像（image_gen）や動画（image_to_video）を生成し、さらに緑幕／クロマキー除去、連結、透かし入れといった ffmpeg 後処理を行えます。クロスプラットフォーム（macOS／Linux／Windows）対応。オプションで有料の xAI 検索／メディア API をフォールバックとして利用可能です。トリガーは grok、grok build、​生图、生成图片、生成视频、绿幕抠像、批量调研、xAI search です。
