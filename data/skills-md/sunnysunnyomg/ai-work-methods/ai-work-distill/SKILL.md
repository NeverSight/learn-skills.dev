# AI 经验与 Skill 化

让经验改变下一次实际行动。一次事故或参数变化先记录证据，不能自动升格为通用规则。

提炼“什么条件 → 做什么 → 怎样知道有效”，保留反例、未证结果和适用边界。先检查能否更新已有流程/Skill；没有新规律允许零新增。用户明确要求创建Skill时完成该请求，并说明规则的适用边界，不以零新增原则拒绝授权。

稳定选择条件与可执行配方才封装。主干保留触发、判断、最小动作和完成检查；复杂情形进按需references。确定性重复操作有实际价值才加script。

判断保留/合并/缩小/撤销，读 [lesson-decisions.md](references/lesson-decisions.md)；准备编写与验证Skill，读 [skill-shape.md](references/skill-shape.md)。

在当前环境若有适用skill-creator就读后使用，缺少时按本模块步骤完成，不假装已调用。交付可审核的规则或技能源码，不默认安装、发布或改配置；只有用户授权才做这些动作。不反向调用入口。
