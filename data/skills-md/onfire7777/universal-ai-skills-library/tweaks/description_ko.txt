HTML 아티팩트를 라이브 파라미터 사이드 패널로 감싸 색상, 간격, 타이포그래피 및 동작을 안전하게 시각적으로 조정합니다. 모든 HTML 아티팩트를 라이브 파라미터화된 컨트롤(강조 색상, 타입 스케일, 밀도, 모션, 테마)을 포함한 사이드 패널로 감싸 CSS 커스텀 프로퍼티를 실시간으로 재작성하고 localStorage에 저장합니다. 사용자가 에이전트를 다시 호출하지 않고도 디자인의 변형을 탐색할 수 있게 합니다. 브리프에 “variants”, “side-by-side options”, “tweak this”, “let me adjust”, “live knobs”, 혹은 “实时调参”가 포함된 경우 사용하세요.
