Prépare des sites statiques compatibles CanAI sous forme d’un fichier HTML autonome par page : HTML5 sémantique, classes utilitaires Tailwind, JavaScript vanille ou Alpine.js pour l’interactivité, balisage d’icônes Lucide. À utiliser lorsque l’utilisateur demande de préparer du HTML pour CanAI, des pages HTML uniques, image/mockup vers HTML, capture d’écran vers HTML, SPA ou PWA vers pages statiques, export de site statique, ou « canai-prepare ». Se déclenche sur : « canai-prepare », « prepare html », « image to html », « mockup to html », « screenshot to html », « spa to html », « pwa to html », « static html », « single html », « per-page html », « convert design to html ».
