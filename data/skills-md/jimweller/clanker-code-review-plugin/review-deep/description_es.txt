Auditoría profunda de base de código completa. Divide el repositorio en 25 componentes de archivo, ejecuta 9 perspectivas por 3 modelos (OpenAI, Gemini, Claude) en cada componente a través de la ejecución de código abierto con navegación Serena, barre las brechas y ejecuta un pase de cobertura de escaneo ocr. Luego coteja y deduplica los hallazgos y verifica cada problema crítico y alto contra una exportación limpia del compromiso revisado con jueces claude -p aislados. El directorio run alimenta la habilidad review-tickets.
