Полный аудит всего кода. Репозиторий разбивается на компоненты по 25 файлов, для каждого компонента запускаются 9 перспектив с использованием 3 моделей (OpenAI, Gemini, Claude) через opencode run с навигацией Serena, производится поиск пробелов и один проход сканирования OCR для охвата. Затем собираются и удаляются дублирования находок, и каждая критическая и высокая проблема проверяется против чистого экспорта проверенного коммита с изолированными судьями claude -p. Директория выполнения питает навык review‑tickets.
