Anthropic의 Claude Code 모범 사례와 Matt Pocock의 Writing-Great-skills 방법론을 4가지 축 (Trigger, Structure, Steering, Pruning) 에 걸쳐 병합된 프레임워크에 대해 상담원 기술을 평가합니다. 증거로 인용된 스코어 카드 (0–100), 가중치가 부여된 전체 점수 및 우선 순위 수정으로 진단된 실패 모드를 생성합니다. 사용자가 기술 평가, 평가 또는 감사 ("이 기술 평가", "기술 스코어 카드", "SKILL.md 검토") 를 요청하거나 두 기술을 비교할 때 사용합니다.
