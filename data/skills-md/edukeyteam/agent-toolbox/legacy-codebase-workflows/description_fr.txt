Enquêtez, documentez ou modifiez une base de code héritée inconnue en utilisant des cartes locales du dépôt, un contexte source limité et des preuves vérifiées. Utilisez cela pour les frameworks internes non documentés, le comportement inter‑modules ou les grands dépôts ; une modification de fichier connu ou une recherche d’un seul symbole nécessite généralement seulement une recherche directe.
