À utiliser lorsqu'une demande de tirage ou une demande de fusion comporte des commentaires d'examen pour inspecter, adresser ou répondre, que ce soit d'une personne ou d'un réviseur automatisé sur GitHub, GitLab ou Bitbucket. Cette compétence gère les commentaires déjà reçus ; elle n'effectue pas de nouvelle révision de code.
