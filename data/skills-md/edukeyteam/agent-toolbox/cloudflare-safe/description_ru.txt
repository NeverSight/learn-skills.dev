Используйте при проверке или изменении любого элемента в аккаунте Cloudflare в качестве агента — записи DNS, пользовательские правила WAF, настройки ботов, перенаправления, трансформации, кэш или правила страниц, настройки зоны, туннели, Workers, Pages, R2 или аналитику. Чтения выполняются через локальный токен API только для чтения, который агент не видит. Изменения предлагаются человеку для выполнения в панели управления или применяются через шаг одобрения, когда пользователь специально сохранил токен с правом записи.
