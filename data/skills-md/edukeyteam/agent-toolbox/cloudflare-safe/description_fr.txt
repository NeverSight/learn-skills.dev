À utiliser lors de l'inspection ou de la modification de quoi que ce soit dans un compte Cloudflare en tant qu'agent - enregistrements DNS, règles personnalisées WAF, paramètres de bot, redirection, transformation, règles de cache ou de page, paramètres de zone, tunnels, Travailleurs, Pages, R2 ou analyses. Les lectures passent par un jeton API local en lecture seule que l'agent ne voit jamais. Les modifications sont proposées à l'humain dans le tableau de bord, ou appliquées via une étape d'approbation lorsque l'utilisateur a délibérément stocké un jeton d'écriture.
