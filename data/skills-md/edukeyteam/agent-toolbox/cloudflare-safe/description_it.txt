Utilizzare quando si ispeziona o si modifica qualsiasi cosa in un account Cloudflare come agente – record DNS, regole personalizzate WAF, impostazioni bot, redirect, trasformazioni, regole di cache o di pagina, impostazioni della zona, tunnel, Workers, Pages, R2 o analisi. Le letture avvengono tramite un token API locale in sola lettura che l’agente non vede mai. Le modifiche vengono proposte all’utente da eseguire nel pannello di controllo, o applicate tramite un passaggio di approvazione quando l’utente ha deliberatamente memorizzato un token di scrittura.
