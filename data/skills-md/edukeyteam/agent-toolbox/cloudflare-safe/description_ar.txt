استخدم عند فحص أو تغيير أي شيء في حساب Cloudflare كوكيل – سجلات DNS، قواعد WAF المخصصة، إعدادات الروبوتات، إعادة التوجيه، التحويل، التخزين المؤقت أو قواعد الصفحات، إعدادات المنطقة، الأنفاق، Workers، Pages، R2 أو التحليلات. تتم عمليات القراءة عبر رمز API محلي للقراءة فقط لا يراه الوكيل أبدًا. يتم اقتراح التغييرات للإنسان لتطبيقها في لوحة التحكم، أو تُنفّذ من خلال خطوة موافقة عندما يكون المستخدم قد خزن عن قصد رمز كتابة.  
  
يرجى دائمًا الرد بلغة المستخدم.
