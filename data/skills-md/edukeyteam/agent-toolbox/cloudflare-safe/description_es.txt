Úselo al inspeccionar o cambiar cualquier cosa en una cuenta de Cloudflare como agente: registros DNS, reglas personalizadas WAF, configuración de bot, redirección, transformación, reglas de caché o página, configuración de zona, túneles, trabajadores, páginas, R2 o análisis. Las lecturas pasan por un token de API de solo lectura local que el agente nunca ve. Se proponen cambios para que el humano los realice en el panel de control, o se aplican a través de un paso de aprobación cuando el usuario ha almacenado deliberadamente un token de escritura.
