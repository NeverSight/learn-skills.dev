Verwenden Sie diese Funktion, wenn Sie etwas in einem Cloudflare-Konto als Agent überprüfen oder ändern - DNS-Einträge, benutzerdefinierte WAF-Regeln, Bot-Einstellungen, Umleitung, Transformation, Cache- oder Seitenregeln, Zoneneinstellungen, Tunnel, Arbeiter, Seiten, R2 oder Analysen. Lesevorgänge durchlaufen ein lokales schreibgeschütztes API-Token, das der Agent nie sieht. Änderungen werden vorgeschlagen, damit der Mensch sie im Dashboard vornehmen kann, oder sie werden durch einen Genehmigungsschritt angewendet, wenn der Benutzer absichtlich ein Schreibtoken gespeichert hat.
