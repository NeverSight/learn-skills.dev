Extraiga un sistema de diseño de cualquier URL de sitio web conduciendo un navegador real con la CLI de Playwright. Produce tokens de diseño (JSON), activos de marca (logotipo y favicon cuando están disponibles), una captura de pantalla de la página de inicio y un documento design-guidelines.md. Úselo cuando el usuario quiera clonar, hacer coincidir o mantener la coherencia con una marca externa.
