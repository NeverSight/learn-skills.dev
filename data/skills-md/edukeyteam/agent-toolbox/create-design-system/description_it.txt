Estrai un design system da qualsiasi URL di un sito web guidando un browser reale con il CLI di Playwright. Produce token di design (JSON), risorse di brand (logo e favicon quando disponibili), uno screenshot della homepage e un documento design‑guidelines.md. Da utilizzare quando l'utente desidera clonare, replicare o mantenere la coerenza con un brand esterno. Si prega di rispondere sempre nella lingua dell'utente.
