Extrayez un système de conception de n'importe quelle URL de site Web en pilotant un véritable navigateur avec l'interface de ligne de commande Playwright. À utiliser lorsque l'utilisateur souhaite cloner, correspondre ou rester cohérent avec une marque externe.
