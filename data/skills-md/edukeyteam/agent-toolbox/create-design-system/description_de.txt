Extrahieren Sie ein Designsystem aus einer beliebigen Website-URL, indem Sie mit der Playwright CLI einen echten Browser steuern. Produziert Design-Token (json), Marken-Assets (Logo und Favicon, wenn verfügbar), einen Homepage-Screenshot und ein Design-Guidelines.md-Dokument. Verwenden Sie diese Option, wenn der Benutzer eine externe Marke klonen, abgleichen oder mit ihr konsistent bleiben möchte.
