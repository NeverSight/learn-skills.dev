Fügen Sie einem bestehenden Dial‑Kanal eine weitere Telefonnummer hinzu – eine zweite (oder dritte) öffentliche Leitung für den Agenten, sodass eine NanoClaw‑Installation SMS‑ und KI‑Sprachanrufe über mehrere Nummern beantwortet. Verwenden Sie dies, wenn Dial bereits installiert ist und der Betreiber eine zusätzliche Nummer möchte (z. B. eine persönliche Leitung plus eine Support‑Leitung). Erfordert, dass der Dial‑Kanal bereits installiert ist (siehe /add-dial).
