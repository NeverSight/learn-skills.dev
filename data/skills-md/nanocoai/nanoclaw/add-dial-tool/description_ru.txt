Дайте выбранным агентам NanoClaw реальный номер телефона в виде контейнерного инструмента — CLI `dial`, встроенный в образ агента, плюс инъекция учётных данных OneCLI для api.getdial.ai, привязанная только к выбранным вами агентам, чтобы они могли отправлять SMS, совершать AI‑голосовые вызовы и получать коды подтверждения изнутри песочницы. Независимо от канала Dial; идемпотентно; повторный запуск изменит, какие агенты могут его использовать. Используйте, когда пользователь хочет, чтобы агенты отправляли сообщения, звонили или запускали `dial …` из чата, без подключения Dial в качестве канала обмена сообщениями.
