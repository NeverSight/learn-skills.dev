선택한 NanoClaw 에이전트에게 실제 전화번호를 컨테이너 도구로 제공하세요 — 에이전트 이미지에 내장된 `dial` CLI와 api.getdial.ai용 OneCLI 자격 증명 주입을 선택한 에이전트에만 연결하여, 샌드박스 내부에서 SMS를 보내고 AI 음성 전화를 걸며 인증 코드를 받을 수 있게 합니다. Dial 채널과는 별개이며, 멱등적이고, 어떤 에이전트가 사용할지 변경하려면 다시 실행하면 됩니다. 사용자가 에이전트에게 문자, 전화, 혹은 채팅에서 `dial …` 를 실행하도록 원할 때, Dial을 메시징 채널로 연결하지 않고 사용하세요.
