Используйте Cursor (local Agent SDK) в качестве полноценного поставщика агентов — планирование, оркестрация инструментов, инструменты MCP, возобновление сеанса — вместе с Claude или вместо него. Вход в аккаунт Cursor или API‑ключ хранится в шлюзе учётных данных. Для каждой группы через `ncl groups config update --provider cursor`. Это отличается от использования Cursor как облачного агента (такие агенты работают на виртуальных машинах Cursor и не являются этим провайдером).
