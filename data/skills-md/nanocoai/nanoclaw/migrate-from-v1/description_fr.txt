Terminez la migration d’une installation NanoClaw v1 vers v2. Exécutez après que `bash migrate-v2.sh` soit terminé. Initialise le propriétaire, migre la mémoire héritée, réconcilie les configurations des conteneurs et aide à porter le code personnalisé v1. Se déclenche sur « migrate from v1 », « finish migration », « v1 migration ».
