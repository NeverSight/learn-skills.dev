Aggiungi clidash — una dashboard web solo lettura, senza dipendenze, che genera le schede e le tabelle in tempo reale da qualsiasi CLI che elenca le risorse come JSON. Viene fornito preconfigurato per il CLI ncl di NanoClaw (gruppi di agenti, sessioni, canali, utenti, ruoli), oltre a grafici di attività dei messaggi, un tail dei log e un visualizzatore di file in sola lettura per le competenze di gruppo/CLAUDE.md/profili.
