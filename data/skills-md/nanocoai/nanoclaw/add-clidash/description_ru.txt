Добавьте clidash — это веб‑панель без зависимостей, только для чтения, которая формирует свои вкладки и таблицы во время выполнения на основе любого CLI, выводящего ресурсы в формате JSON. Поставляется заранее настроенной для ncl CLI от NanoClaw (группы агентов, сессии, каналы, пользователи, роли), а также включает диаграммы активности сообщений, хвост журнала и просмотрщик файлов только для чтения для group skills/CLAUDE.md/profiles.
