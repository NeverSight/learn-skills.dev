Agrega clidash — un panel web de solo lectura sin dependencias que genera sus pestañas y tablas en tiempo de ejecución a partir de cualquier CLI que enumere recursos como JSON. Se entrega preconfigurado para el CLI ncl de NanoClaw (grupos de agentes, sesiones, canales, usuarios, roles), además de gráficos de actividad de mensajes, un tail del registro y un visor de archivos de solo lectura para habilidades de grupo/CLAUDE.md/perfiles.
