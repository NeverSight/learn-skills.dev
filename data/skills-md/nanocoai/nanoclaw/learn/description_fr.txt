Distillez une compétence réutilisable à partir de n'importe quoi — un répertoire, une URL, des notes collées, ou ce que vous venez de faire ensemble — ou affinez une compétence existante avec de nouveaux apprentissages. Utilisez lorsque l'utilisateur dit « /learn », « learn this », « turn this into a skill », « capture this workflow », « make a skill from <source> » ou « improve/update the <name> skill ». Produit ou met à jour un fichier .claude/skills/<name>/SKILL.md rédigé selon les directives de compétences de NanoClaw. (Cela CRÉE ou AFFICHE une compétence à partir d’une source ; cela n’installe pas de compétences existantes depuis un registre.)

Veuillez toujours répondre dans la langue de l'utilisateur.
