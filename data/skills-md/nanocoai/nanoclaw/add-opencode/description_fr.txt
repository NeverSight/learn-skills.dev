Utilisez OpenCode comme fournisseur d’agent. OpenRouter, OpenAI, Google, DeepSeek, etc. via la configuration OpenCode — pas le SDK Anthropic Agent. Par groupe via `ncl groups config update --provider opencode` ; l’hôte transmet OPENCODE_* et le montage XDG lors du lancement des conteneurs.

Veuillez toujours répondre dans la langue de l’utilisateur.
