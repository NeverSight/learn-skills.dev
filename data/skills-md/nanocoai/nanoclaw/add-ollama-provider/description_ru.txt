Перенаправьте группу агентов NanoClaw на локальную модель Ollama вместо API Anthropic. Ollama нативно поддерживает API Anthropic (v1/messages), поэтому изменения кода провайдера не требуются — достаточно переопределить переменные окружения и задать модель. Используйте, когда пользователь хочет запускать своего агента локально, сократить расходы на API или экспериментировать с моделями открытого веса. См. docs/ollama.md для справки.
