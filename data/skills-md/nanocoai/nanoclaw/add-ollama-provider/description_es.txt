Enruta un grupo de agentes NanoClaw a un modelo local de Ollama en lugar de la API de Anthropic. Ollama habla la API de Anthropic de forma nativa (v1/messages), por lo que no se requieren cambios en el código del proveedor, solo sobrescrituras de variables de entorno y una configuración del modelo. Úsalo cuando el usuario quiera ejecutar su agente localmente, reducir costos de API o experimentar con modelos de peso abierto. Consulta docs/ollama.md para obtener más información.
