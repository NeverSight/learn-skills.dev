Routage d'un groupe d'agents NanoClaw vers un modèle local Ollama au lieu de l'API Anthropic. Ollama parle nativement l'API Anthropic (v1/messages), donc aucun changement de code fournisseur n’est nécessaire — seulement des surcharges de variables d’environnement et un paramètre du modèle. À utiliser lorsque l’utilisateur veut exécuter son agent localement, réduire les coûts d’API ou expérimenter avec des modèles à poids ouvert. Voir docs/ollama.md pour le contexte.
