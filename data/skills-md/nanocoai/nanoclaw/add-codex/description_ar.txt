استخدم Codex (خادم تطبيق Codex الخاص بـ OpenAI) كمزود وكيل كامل — التخطيط، تنسيق الأدوات، أدوات MCP، السجل على الخادم، استئناف الجلسة — إلى جانب أو بدلاً من Claude. اشتراك ChatGPT أو مفتاح API الخاص بـ OpenAI، خزنًا فقط عبر البوابة المختارة. لكل مجموعة عبر `ncl groups config update --provider codex`. مختلف عن استخدام OpenAI كأداة MCP (حيث يظل Claude هو المخطط).
