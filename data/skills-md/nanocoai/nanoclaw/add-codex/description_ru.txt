Используйте Codex (сервер приложений Codex от OpenAI) в качестве полноценного поставщика агентов — планирования, оркестрации инструментов, MCP‑инструментов, истории на стороне сервера, возобновления сессий — совместно или вместо Claude. Подписка ChatGPT или ключ API OpenAI, только через выбранный шлюз в хранилище. Для каждой группы через `ncl groups config update --provider codex`. Отличается от использования OpenAI как MCP‑инструмента (где планировщиком остаётся Claude).
