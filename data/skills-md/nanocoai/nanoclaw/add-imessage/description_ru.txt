Добавьте iMessage в NanoClaw — один канал, два бэкенда. Локальный (chat.db этого Mac через мост Chat SDK; macOS + полный доступ к диску) или хостинговый iMessage (через photon.codes — native spectrum‑ts с мастером входа по устройству; любая ОС, без ретрансляции через Mac). Срабатывает по командам «add imessage», «connect imessage», «add photon», «imessage via photon», «native imessage».
