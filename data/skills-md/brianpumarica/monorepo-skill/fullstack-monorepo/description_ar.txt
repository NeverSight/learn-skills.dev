معيار ودليل تشغيل لمستودعات مونوريبوس full‑stack في Docker — تدقيق، إنشاء هياكل وإعادة هيكلة المستودع (compose dev/prod، Dockerfiles متعددة المراحل غير جذرية، نقطة الدخول مع انتظار القاعدة، إعادة تحميل ساخنة في الحاويات، توجيه SPA) ونشره باستخدام GitHub Actions إلى Vercel مع عامل تشغيل مُستضاف ذاتيًا. استخدم عندما يتعلق الطلب بـ docker‑compose أو Dockerfile أو entrypoint أو deploy.yml، أو الحالة الفعلية لما يتم تشغيله على الخادم. ثلاثة أوضاع — تحليل (تدقيق وخطة)، تنفيذ (تطبيق وإزالة التراث)، فحص (تشخيص قراءة فقط للنشر).
