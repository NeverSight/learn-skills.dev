Configurazione automatizzata, impostazione e runbook di produzione per i tunnel Cloudflare (cloudflared) all'interno di Docker Compose. Da utilizzare ogni volta che si espongono backend locali e database in esecuzione su Raspberry Pi 5 o server domestici a Internet con HTTPS, configurando le politiche di accesso Zero Trust, impostando nomi host pubblici, gestendo CORS e stabilendo un accesso remoto sicuro al database senza aprire porte del router o esporre IP pubblici.
