Runbook automatizado de configuración, configuración y producción para túneles Cloudflare (Cloudflared) dentro de Docker Compose. Utilícelo siempre que exponga backends y bases de datos locales que se ejecutan en Raspberry Pi 5 o servidores domésticos a Internet con HTTPS, configurando políticas de acceso de Zero Trust, configurando nombres de host públicos, manejando CORS y estableciendo un acceso remoto seguro a la base de datos sin abrir puertos de enrutador ni exponer IP públicas.
