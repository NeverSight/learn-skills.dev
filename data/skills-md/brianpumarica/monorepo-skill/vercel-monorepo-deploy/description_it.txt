Migliori pratiche, configurazioni e runbook di automazione per distribuire frontend monorepo (Next.js, Vite SPA, React) su Vercel. Copre pipeline Vercel CLI GitHub Actions (bypass gratuito per organizzazioni), salto della build con turbo‑ignore, riscritture di routing lato client in vercel.json, impostazione della directory radice del monorepo, iniezione a tempo di build di NEXT_PUBLIC, collegamento dell’ambiente API remoto con Cloudflare Tunnels e compatibilità con Node 22/pnpm 10. Utilizzare ogni volta che si configura o si effettua il debug di distribuzioni Vercel da un monorepo pnpm/npm. 

Per favore rispondi sempre nella lingua dell'utente.
