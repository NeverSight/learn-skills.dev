Best practices, configurations, and automation runbook for deploying monorepo frontends (Next.js, Vite SPAs, React) to Vercel. Covers Vercel CLI GitHub Actions pipelines (free organization bypass), turbo-ignore build skipping, client-side routing rewrites in vercel.json, monorepo root directory setup, NEXT_PUBLIC build-time injection, remote API environment wiring with Cloudflare Tunnels, and Node 22/pnpm 10 compatibility. Use whenever configuring or debugging Vercel deployments from a pnpm/npm monorepo.
