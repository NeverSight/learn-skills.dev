Лучшие практики, конфигурации и руководство по автоматизации развертывания фронтендов монорепозитория (Next.js, Vite SPA, React) в Vercel. Охватывает пайплайны Vercel CLI GitHub Actions (обход ограничения бесплатной организации), пропуск сборки turbo‑ignore, перенаправления клиентской маршрутизации в vercel.json, настройку корневой директории монорепозитория, внедрение переменных NEXT_PUBLIC во время сборки, подключение удалённого API через Cloudflare Tunnels и совместимость с Node 22/pnpm 10. Используйте при настройке или отладке развертываний Vercel из pnpm/npm‑монорепозитория.
