Mejores prácticas, configuraciones y guía de automatización para desplegar frontends monorepo (Next.js, Vite SPAs, React) en Vercel. Cubre pipelines de Vercel CLI y GitHub Actions (omitiendo la organización gratuita), omisión de compilaciones con turbo‑ignore, reescrituras de enrutamiento del lado del cliente en vercel.json, configuración del directorio raíz del monorepo, inyección en tiempo de compilación de NEXT_PUBLIC, conexión del entorno de API remoto mediante Cloudflare Tunnels y compatibilidad con Node 22/pnpm 10. Utilízalo siempre que configures o depures despliegues de Vercel desde un monorepo pnpm/npm.
