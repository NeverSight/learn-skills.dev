ビデオ編集スキル：トーキングヘッド動画（YouTube動画、講座レッスン、製品デモ、カメラ前のポッドキャスト、Vlog）をエディターのように編集します。単語タイムスタンプ付きで文字起こし（無料のローカル faster‑whisper、独自の Groq または OpenAI キー、または既存の SRT/VTT を使用）、無音部分や「うん」「ええ」などのフィラー、吃音やリテイク（最後のテイクを残す）を除去し、ジャンプカットのパンチインを追加、音声をクリーニング・レベル調整し、SRT 字幕ファイルと YouTube チャプターを作成、必要に応じて字幕を焼き込みまたは縦型バージョンを作成、レンダリング前にカットリストを表示して承認を得た後、あなたが「はい」と言ったら WoopSocial を使って YouTube や他のプラットフォームへ投稿します。ffmpeg と Pillow を使用するので、Mac、Windows、Linux で動作し、有料 API は不要です。以下のような要望があるときに使用します：「ビデオを編集して」「無音を削除して」「うんをカットして」「フィラーワードを除去して」「ビデオをジャンプカットして」「この録音をクリーンアップして」「このトーキングヘッド動画を編集して」または「Claude Code でビデオ編集」など。ユーザーが保持したいとマークした部分は決してカットせず、投稿前に必ず確認します。スタンドアロンで、他のスキルは不要です。
