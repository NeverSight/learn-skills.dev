Orcaが管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そしてOrcaの組み込みブラウザを `orca` CLI で操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree や臨時 PTY、Computer Use よりもこれを優先してください。GUI コントロールが必要な可視ウィンドウがあり、CLI、ファイルシステム、API で対処できない場合にのみ Computer Use を使用します。

常にユーザーの言語で回答してください。
