Integrate the CFDI Express REST API to issue Mexican CFDI 4.0 invoices from any system: PUE/PPD/global invoices, credit notes, payment complements (REP / Pagos 2.0), payroll receipts (nómina / Nómina 1.2), cancellations with SAT acknowledgment, issuer (RFC/CSD) management, SAT catalogs and prepaid balance. Stripe-style conventions. Use when the user needs to stamp, list, fetch or cancel CFDIs (including recibos de nómina), register issuers or upload CSD certificates, search SAT product/unit/usos/regimen/nómina codes, check balance and usage, or receive webhooks about stamped documents against api.cfdi.express.
