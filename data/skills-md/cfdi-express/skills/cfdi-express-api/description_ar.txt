قم بدمج واجهة برمجة التطبيقات REST لـ CFDI Express لإصدار الفواتير المكسيكية CFDI 4.0 من أي نظام: فواتير PUE/PPD/عالمية، ملاحظات الخصم، ملاحق الدفع (REP / Pagos 2.0)، إيصالات الرواتب (nómina / Nómina 1.2)، الإلغاءات مع إقرار SAT، إدارة المصدر (RFC/CSD)، كتالوجات SAT والرصيد المدفوع مسبقًا. اتباع أساليب مشابهة لStripe. استخدمه عندما يحتاج المستخدم إلى ختم أو سرد أو جلب أو إلغاء CFDIs (بما في ذلك recibos de nómina)، تسجيل المصادر أو رفع شهادات CSD، البحث عن رموز منتجات/وحدات/استخدامات/نظام/رواتب SAT، التحقق من الرصيد والاستخدام، أو استقبال webhooks حول المستندات المختومة عبر api.cfdi.express.
