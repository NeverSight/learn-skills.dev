CFDI Express REST API를 통합하여 모든 시스템에서 멕시코 CFDI 4.0 인보이스를 발행합니다: PUE/PPD/글로벌 인보이스, 신용 메모, 지급 보완(REC / Pagos 2.0), 급여 영수증(nómina / Nómina 1.2), SAT 확인과 함께하는 취소, 발행자(RFC/CSD) 관리, SAT 카탈로그 및 선불 잔액.
