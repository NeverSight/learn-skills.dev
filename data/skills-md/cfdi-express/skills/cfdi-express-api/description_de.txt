Integrieren Sie die CFDI Express REST‑API, um mexikanische CFDI 4.0‑Rechnungen aus jedem System zu erstellen: PUE‑/PPD‑/Global‑Rechnungen, Gutschriften, Zahlungs‑Komplemente (REP / Pagos 2.0), Lohnabrechnungen (nómina / Nómina 1.2), Stornierungen mit SAT‑Bestätigung, Verwalten von Ausstellern (RFC/CSD), SAT‑Kataloge und Guthaben. Stripe‑ähnliche Konventionen. Verwenden Sie sie, wenn der Nutzer CFDIs (einschließlich recibos de nómina) stempeln, auflisten, abrufen oder stornieren, Aussteller registrieren oder CSD‑Zertifikate hochladen, SAT‑Produkt‑/Einheiten‑/Usos‑/Regimen‑/Nómina‑Codes suchen, das Guthaben und die Nutzung prüfen oder Webhooks über gestempelte Dokumente von api.cfdi.express erhalten muss.
