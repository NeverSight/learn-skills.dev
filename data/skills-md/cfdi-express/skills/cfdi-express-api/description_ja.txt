CFDI Express の REST API を統合して、任意のシステムからメキシコの CFDI 4.0 請求書を発行します：PUE/PPD/グローバル請求書、クレジットノート、支払い補足（REP / Pagos 2.0）、給与明細（nómina / Nómina 1.2）、SAT からの承認付き取消し、発行者（RFC/CSD）管理、SAT カタログと前払残高。Stripe スタイルの規約。ユーザーが CFDI のスタンプ付与、一覧取得、取得、取消し（給与明細を含む）を行う必要があるとき、発行者を登録または CSD 証明書をアップロードする場合、SAT の商品・単位・用途・体制・給与コードを検索する場合、残高と使用状況を確認する場合、または api.cfdi.express に対してスタンプ付きドキュメントの Webhook を受信する場合に使用してください。
