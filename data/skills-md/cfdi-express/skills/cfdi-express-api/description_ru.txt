Интегрируйте REST API CFDI Express для выпуска мексиканских счетов CFDI 4.0 из любой системы: счета PUE/PPD/глобальные, кредит‑ноты, платёжные дополнения (REP / Pagos 2.0), расчётные листы (nómina / Nómina 1.2), отмены с подтверждением SAT, управление эмитентами (RFC/CSD), каталоги SAT и предоплаченный баланс. Конвенции в стиле Stripe. Используйте, когда пользователю требуется поставить печать, получить список, извлечь или аннулировать CFDI (включая recibos de nómina), зарегистрировать эмитентов или загрузить сертификаты CSD, искать коды продуктов/единиц/использований/режимов/нómina в SAT, проверять баланс и использование, либо получать веб‑хуки о поставленных документах через api.cfdi.express.
