Integra la API REST de CFDI Express para emitir facturas mexicanas CFDI 4.0 desde cualquier sistema: facturas PUE/PPD/globales, notas de crédito, complementos de pago (REP / Pagos 2.0), recibos de nómina (nómina / Nómina 1.2), cancelaciones con acuse del SAT, gestión de emisores (RFC/CSD), catálogos del SAT y saldo prepago. Convenciones al estilo Stripe. Úsala cuando el usuario necesite timbrar, listar, obtener o cancelar CFDIs (incluidos recibos de nómina), registrar emisores o subir certificados CSD, buscar códigos de producto/unidad/usos/régimen/nómina del SAT, consultar saldo y consumo, o recibir webhooks sobre documentos timbrados contra api.cfdi.express.
