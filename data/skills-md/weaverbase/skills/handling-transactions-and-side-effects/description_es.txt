Úsese al escribir o modificar código que confirma o revierte una transacción de base de datos, reintenta trabajos o solicitudes, envía correos electrónicos o webhooks, publica eventos, llama a API externas que modifican el estado, ejecuta flujos de trabajo de varios pasos que pueden fallar a mitad del proceso, o concilia la intención almacenada con el estado externo en tiempo real; también para bandeja de salida, idempotencia, condición de carrera, entrega duplicada, fallo parcial, límite de concurrencia y preguntas de cancelación.
