استخدمه عند كتابة أو تعديل مخططات SQL أو تعريفات الجداول أو الترقيات أو الاستعلامات، واختيار أنواع أعمدة PostgreSQL للـ JSON أو الطوابع الزمنية، وتشغيل استعلامات قاعدة البيانات عبر ORM أو برنامج تشغيل في تطبيق غير متزامن، وبناء SQL من مدخلات المستخدم، أو تخطيط عمليات DROP أو TRUNCATE أو إزالة الأعمدة أو تغيير الأنواع أو الحذف الجماعي.
