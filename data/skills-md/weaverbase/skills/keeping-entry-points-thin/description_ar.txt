استخدم ذلك عند تنفيذ أو تعديل معالجات HTTP أو المسارات، إجراءات الخادم، أوامر سطر الأوامر، معالجات أحداث واجهة المستخدم، مستهلكات الطابور، الوظائف المجدولة، أو العمال الذين يقومون بتحليل المدخلات، استعلام قاعدة البيانات، تشغيل عمليات فرعية، فرض التفويض، أو تحويل أخطاء التطبيق إلى رموز حالة، رموز خروج، رسائل أو اعترافات؛ كذلك عندما تكون مغريًا لوضع استعلام SQL أو سير عمل داخل مسار لأنه للقراءة فقط، أو عاجل، أو لمرة واحدة، أو لإرجاع نص الاستثناء إلى المستدعين.
