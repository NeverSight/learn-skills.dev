Verwenden Sie es, wenn Sie Geschäftslogik hinzufügen oder ändern, die von einer API, einer CLI, einem Worker, einem geplanten Job oder einer UI‑Aktion aufgerufen wird; wenn Sie entscheiden, ob die Logik in einer Servicemethode, einer eigenständigen Funktion, einer Abfrage‑ oder Hilfsfunktion liegen soll; wenn ein Service zu einem Durchleitungs‑Wrapper, einer Klasse pro Aktion oder einer Allzwecklösung wird; wenn das gleiche Verhalten über einen zweiten Transport angefordert wird; oder wenn Sie festlegen, was ein Vorgang zurückgibt und wie er erwartete Fehler meldet.
