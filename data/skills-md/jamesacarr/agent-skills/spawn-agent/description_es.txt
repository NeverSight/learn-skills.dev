Inicia una sesión de agente con nombre (Claude Code, Codex, pi o cualquier tipo compatible con Herdr) en una nueva pestaña de Herdr en el espacio de trabajo actual, opcionalmente en un modelo específico. Úselo cuando el usuario solicite generar un agente, abrir una nueva pestaña que ejecute Claude, Codex o pi, o entregar una tarea secundaria a una nueva sesión (por ejemplo, "/spawn-agent ABC-123", "activar un agente de codex para los documentos"). NO lo use para implementar un ticket (use implement-ticket). Requiere HERDR_ENV=1.
