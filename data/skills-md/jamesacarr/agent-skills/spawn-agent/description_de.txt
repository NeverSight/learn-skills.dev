Startet eine benannte Agentensitzung (Claude Code, Codex, pi oder jede von Herdr unterstützte Art) in einer neuen Herdr-Registerkarte im aktuellen Arbeitsbereich, optional auf einem bestimmten Modell. Verwenden Sie diese Option, wenn der Benutzer darum bittet, einen Agenten zu erzeugen, einen neuen Tab mit Claude, Codex oder Pi zu öffnen oder eine Nebenaufgabe an eine neue Sitzung zu übergeben (z. B. „/spawn-agent ABC-123“, „einen Codex-Agenten für die Dokumente starten“). NICHT zum Implementieren eines Tickets verwenden (implementieren-ticket verwenden). Erfordert HERDR_ENV=1.
