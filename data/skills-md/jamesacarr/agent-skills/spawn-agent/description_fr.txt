Démarre une session d'agent nommé (Claude Code, Codex, pi ou tout autre type pris en charge par Herdr) dans un nouvel onglet Herdr de l'espace de travail actuel, éventuellement sur un modèle spécifique. À utiliser lorsque l'utilisateur demande à générer un agent, ouvre un nouvel onglet exécutant Claude, Codex ou pi, ou confie une tâche secondaire à une nouvelle session (par exemple "/spawn-agent ABC-123", "lancez un agent codex pour la documentation"). Ne PAS utiliser pour implémenter un ticket (utilisez Implement-Ticket). Nécessite HERDR_ENV=1.
