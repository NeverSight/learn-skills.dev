Запускает сеанс именованного агента (Claude Code, Codex, pi или любой другой тип, поддерживаемый Herdr) на новой вкладке Herdr в текущей рабочей области, необязательно для конкретной модели. Используйте, когда пользователь просит создать агента, открыть новую вкладку с запуском Claude, Codex или pi или передать побочную задачу новому сеансу (например, «/spawn-agent ABC-123», «раскрутить агент кодекса для документов»). НЕ используйте для реализации билета (используйте реализация-тикет). Требуется HERDR_ENV=1.
