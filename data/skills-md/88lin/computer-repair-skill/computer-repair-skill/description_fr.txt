Utilisez cette compétence lorsqu'un utilisateur demande à diagnostiquer, réparer, nettoyer, récupérer, migrer, configurer, sécuriser ou entretenir un ordinateur Windows, macOS ou Linux. Il couvre les lecteurs système, la migration d'applications ou de données vers un autre lecteur, les machines lentes ou instables, le stockage, les applications, les mises à jour, la mise en réseau, les imprimantes, les sauvegardes, les informations d'identification, les pilotes, le matériel, le démarrage/WinRE, BitLocker, les partitions, la récupération de données, les outils de développement et la configuration d'OpenClaw. Ne pas utiliser pour la programmation générale, la conception de logiciels, les conseils d'achat ou les questions qui ne nécessitent pas l'inspection ou le changement d'un ordinateur.
