استخدم هذه المهارة عندما يطلب المستخدم تشخيص جهاز كمبيوتر يعمل بنظام التشغيل Windows أو macOS أو Linux أو إصلاحه أو تنظيفه أو استعادته أو ترحيله أو تكوينه أو تأمينه أو صيانته. وهو يغطي محركات أقراص النظام، وترحيل التطبيقات أو البيانات إلى محرك أقراص آخر، والأجهزة البطيئة أو غير المستقرة، والتخزين، والتطبيقات، والتحديثات، والشبكات، والطابعات، والنسخ الاحتياطية، وبيانات الاعتماد، وبرامج التشغيل، والأجهزة، وبدء التشغيل/WinRE، وBitLocker، والأقسام، واستعادة البيانات، وأدوات المطورين، وإعداد OpenClaw. لا تستخدم للبرمجة العامة أو تصميم البرامج أو نصائح الشراء أو الأسئلة التي لا تتطلب فحص جهاز كمبيوتر أو تغييره.
