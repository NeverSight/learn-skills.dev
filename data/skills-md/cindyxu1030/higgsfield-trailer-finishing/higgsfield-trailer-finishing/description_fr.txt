Finir les clips générés en une vidéo livrée : assembler avec ffmpeg, appliquer un passage colorimétrique cinématographique optionnel, ajouter une bande‑son originale correspondant au montage assemblé (Sonilo vidéo‑vers‑musique, clé SONILO_API_KEY fournie par l’utilisateur — sous licence, sûre pour une utilisation commerciale, conditions applicables), et multiplexage.  
Utiliser quand : « assembler ces clips en une seule vidéo », « créer une bande‑annonce à partir de ces clips », « assembler mes clips et ajouter de la musique », « corriger les couleurs de ce montage », « ajouter une musique qui correspond à ma vidéo », « ajouter une bande‑son à ce montage », « finaliser ce montage ».  
Enchaîner avec : higgsfield-generate pour créer d’abord les clips (Seedance 2.0 / Kling 3.0) ; les clips provenant de toute autre source fonctionnent aussi.  
PAS pour : générer des clips (utiliser higgsfield-generate), vidéo publicitaire de marque (utiliser Marketing Studio dans higgsfield-generate), musique ou effets sonores de durée fixe à partir d’une simple invite (utiliser sonilo_music / seed_audio dans higgsfield-generate).
