Muestre lo que cuestan las sesiones de agente de codificación para cada árbol de trabajo del repositorio actual (Cursor, Claude Code y Codex) como tarjetas de traspaso con dólares y tokens. Se usa cuando el usuario pregunta cuánto cuesta un repositorio, árbol de trabajo, tarea o sesión, quiere un desglose de gastos o invoca `/melech-cost`.
