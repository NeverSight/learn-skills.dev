Mostra quanto costano le sessioni dell'agente di codifica per ogni worktree del repository corrente — Cursor, Claude Code e Codex — sotto forma di schede in stile handoff con dollari e token. Usalo quando l'utente chiede quanto costa un repository, un worktree, un compito o una sessione, vuole una ripartizione delle spese o invoca `/melech-cost`. Per favore rispondi sempre nella lingua dell'utente.
