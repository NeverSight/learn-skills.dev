Revisiona una soluzione prima di approvarla, come la scheda delle modifiche di GitHub: un albero dei file con pseudo‑codice rosso e verde su cui l'utente può commentare in linea, poi rispondere Approva, Commentato o Rifiutato. Utilizza quando l'utente desidera vedere cosa cambierebbe, un diff in stile git o il PR come se fosse pronto.
