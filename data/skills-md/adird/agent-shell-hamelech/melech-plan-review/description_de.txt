Überprüfen Sie eine Lösung, bevor Sie sie genehmigen, z. B. eine Registerkarte für GitHub-Änderungen: ein Dateibaum mit rotem und grünem Pseudocode, den der Benutzer inline kommentieren und dann genehmigen, kommentieren oder ablehnen kann. Verwenden Sie es, wenn der Benutzer sehen möchte, was sich ändern würde, einen git-ähnlichen Diff oder die PR, als wäre sie bereit.
