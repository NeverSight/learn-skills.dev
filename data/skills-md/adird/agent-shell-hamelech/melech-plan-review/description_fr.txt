Examinez une solution avant de l’approuver, comme l’onglet des modifications de GitHub : un arbre de fichiers de pseudo‑code en rouge et vert que l’utilisateur peut commenter en ligne, puis répondre Approuver, Commenté ou Rejeté. Utilisez‑le lorsque l’utilisateur veut voir ce qui changerait, un diff de type git, ou la PR comme si elle était prête.

Veuillez toujours répondre dans la langue de l’utilisateur.
