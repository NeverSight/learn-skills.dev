Passez en revue une solution avant de l'approuver, comme un onglet de modifications GitHub : une arborescence de pseudo-code rouge et vert que l'utilisateur peut commenter en ligne, puis répondez Approuver, Commenté ou Rejeté. À utiliser lorsque l'utilisateur veut voir ce qui changerait, un diff de type git ou le PR comme s'il était prêt.
