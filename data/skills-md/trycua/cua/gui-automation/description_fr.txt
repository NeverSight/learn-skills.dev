Utilisez-le lorsque vous devez interagir visuellement avec une interface graphique — tester les boutons, remplir des formulaires, vérifier les mises en page visuelles, faire du fuzzing de pages web, automatiser les flux utilisateurs, prendre des captures d'écran ou réaliser des tests QA de bout en bout sur n'importe quelle application. Fonctionne sur les machines virtuelles cloud, les conteneurs Docker, les machines locales et les sandbox. Installation : pip install cua.
