Cree o rediseñe artefactos visuales pulidos representados por el navegador con HTML/CSS/JavaScript/React: páginas, paneles, prototipos, diapositivas, animaciones, maquetas de interfaz de usuario y visualizaciones de datos. Se utiliza para la creación visual de front-end, la exploración del sistema de diseño, la crítica del diseño o la aceptación / control de calidad explícito del navegador de un artefacto web. No es para back-end, CLI, codificación no visual, conversión de artículos de fuente a formato largo o presentaciones de video de clics basadas en la narración.
