Genera interfaces UI verdaderamente hermosas y alineadas con la marca, en lugar de "AI slop" genérico: úsalo siempre que el usuario solicite construir, diseñar, estilizar o mejorar una UI, página de aterrizaje, panel, pantalla de aplicación o componente; siempre que un PRD/especificación necesite una pasada de diseño antes de la implementación; siempre que el usuario pegue imágenes de referencia o enlaces de Pinterest/Dribbble y quiera que la aplicación se vea como ellos; o siempre que el usuario se queje de que la UI generada por IA parece genérica, aburrida, repetitiva o "como cualquier otra app de IA". Asegúrate de activarlo incluso si el usuario no dice explícitamente "diseñar": frases como "haz que esto se vea bien", "construye el frontend para X", "esto se ve como cualquier otro sitio SaaS" o "iguala este ambiente" también califican. También se activa con los verbos "estudiar"/"extraer el look de" una captura de pantalla o URL de referencia, y "auditar"/"revisar"/"¿por qué esto parece generado por IA?" para criticar una UI existente.
