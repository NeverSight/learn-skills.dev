ImageMagick을 사용하여 로컬 이미지 파일을 압축하고 ffmpeg를 사용하여 로컬 비디오 파일을 압축합니다. Codex가 JPEG, PNG, WebP, HEIC, TIFF, MP4, MOV, MKV 또는 기타 로컬 미디어를 축소해야 하는 경우 이것을 사용하십시오. 폴더 일괄 압축, 공유 전 이미지 크기 조정, 사진이나 스크린샷을 동일한 디렉터리, 동일한 이름의 WebP 파일로 자동 변환, 비디오를 동일한 경로 MP4/H.265로 자동 압축, 원본 파일을 유지할 때 소스 디렉터리 구조를 미러링하면서 "압축된" 디렉터리로 출력, 성공적인 압축 후 출력 크기 확인, 0KB 출력에서 ​​재시도, 기본적으로 원본 파일 삭제 또는 교체, 압축 전후의 크기 변경 보고에 작동합니다.
