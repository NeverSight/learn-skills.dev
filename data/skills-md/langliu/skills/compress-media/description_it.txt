Usa ImageMagick per comprimere i file immagine locali e ffmpeg per comprimere i file video locali. Usalo quando Codex deve ridurre le dimensioni di JPEG, PNG, WebP, HEIC, TIFF, MP4, MOV, MKV o altri media locali; adatto per la compressione batch di cartelle, il ridimensionamento delle immagini prima della condivisione, la conversione automatica di foto o screenshot nella stessa directory, file WebP con lo stesso nome, la compressione automatica di video sullo stesso percorso MP4/H.265, l'output in una directory "compressa" che rispecchia la struttura della directory di origine quando si mantengono i file originali, il controllo delle dimensioni dell'output dopo una compressione riuscita, il tentativo di output da 0 KB e, per impostazione predefinita, l'eliminazione o la sostituzione del file originale segnalando la modifica delle dimensioni prima e dopo la compressione.
