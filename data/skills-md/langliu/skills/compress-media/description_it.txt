Usa ImageMagick per comprimere i file immagine locali e ffmpeg per comprimere i file video locali. Applicalo quando Codex deve ridurre JPEG, PNG, WebP, HEIC, TIFF, MP4, MOV, MKV o altri media locali. È adatto per la compressione batch di cartelle, il ridimensionamento delle immagini prima della condivisione, la conversione automatica di foto o screenshot in file WebP con lo stesso nome nella stessa directory, la compressione automatica di video in MP4/H.265 nella stessa posizione, l'output in una directory "compressa" che rispecchia la struttura originale quando si mantengono i file di origine, il controllo delle dimensioni dell'output dopo una compressione riuscita, il tentativo di output da 0 KB e, per impostazione predefinita, l'eliminazione o la sostituzione del file originale segnalando la modifica delle dimensioni prima e dopo la compressione.
