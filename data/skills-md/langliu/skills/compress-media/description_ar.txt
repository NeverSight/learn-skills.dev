استخدم ImageMagick لضغط ملفات الصور المحلية وffmpeg لضغط ملفات الفيديو المحلية. استخدمه عندما يحتاج Codex إلى تقليل حجم JPEG أو PNG أو WebP أو HEIC أو TIFF أو MP4 أو MOV أو MKV أو الوسائط المحلية الأخرى؛ مناسب لضغط المجلدات على دفعات، وتغيير حجم الصور قبل المشاركة، وتحويل الصور أو لقطات الشاشة تلقائيًا إلى نفس الدليل، وملفات WebP بنفس الاسم، وضغط مقاطع الفيديو تلقائيًا إلى نفس المسار MP4/H.265، والإخراج إلى دليل "مضغوط" يعكس بنية الدليل المصدر عند الاحتفاظ بالملفات الأصلية، والتحقق من حجم الإخراج بعد الضغط الناجح، وإعادة محاولة إخراج 0 كيلو بايت، وبشكل افتراضي حذف الملف الأصلي أو استبداله أثناء الإبلاغ عن تغيير الحجم قبل الضغط وبعده.
