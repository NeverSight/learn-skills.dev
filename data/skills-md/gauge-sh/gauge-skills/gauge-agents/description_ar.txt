اختبر كيف يكتشف الوكلاء البرمجيون منتجك ويستخدمونه. استخدمه عند طلب إجراء تقييمات الوكلاء، واختبار ما إذا كان الوكلاء يستطيعون استخدام SDK أو API أو CLI أو خادم MCP، وتحديد أماكن صعوبة onboarding لدى الوكلاء، أو قياس ما إذا كانت الوثائق والمهارات تحسّن نجاح الوكيل. يشغّل جلسات وكيل حقيقية ويُقيّم النتائج عبر Gauge CLI. استخدمه أيضًا لمهام Gauge Agents؛ ليست اختبارات وحدة عادية أو تتبع رؤية البحث الذكي.
