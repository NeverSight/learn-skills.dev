Testez comment les agents de codage découvrent et utilisent votre produit. Utilisez‑le lorsqu’on vous demande d’évaluer les agents, de vérifier s’ils peuvent exploiter un SDK, une API, une CLI ou un serveur MCP, de repérer les points où les agents peinent lors de l’onboarding, ou de mesurer si la documentation et les compétences améliorent le succès des agents. Lancez de véritables sessions d’agents et notez les résultats via la CLI Gauge. Utilisez‑le également pour les tâches Gauge Agents ; ce ne sont pas des tests unitaires ordinaires ni un suivi de visibilité de recherche IA.
