اقرأ محادثات المشروع من Codex أو Claude Code أو ZCode أو WorkBuddy، وقم بتحليل المتطلبات المعبر عنها وطرق التعاون، وحافظ على فهم المشروع بشكل تدريجي، وراجع التغييرات في الاقتراحات التاريخية. استخدم هذا عندما يطلب المستخدم تحليل محادثات المشروع، أو تحسين التواصل مع الذكاء الاصطناعي، أو مراجعة الاقتراحات؛ عندما يتم تحديد محادثة معينة بشكل صريح، قم بتحليل تلك المحادثة فقط. لا تقم بإجراء التحليل عند مناقشة تصميم المهارات أو الإشارة إلى أمثلة الاتصال فقط.
