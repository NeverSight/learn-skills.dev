検出可能なAIライティングパターンを除去するために、テキストの評価や書き直しを行う際に使用します。特にUXコピー、プロダクトコピー、マイクロコピー、ランディングページ、オンボーディングフロー、ツールチップ、エラーメッセージ、CTA、マーケティングテキストに効果的です。FigmaのURLやUIスクリーンショットでも動作し、コピーを抽出してスコア付けし、改善されたテキストをFigmaにプッシュすることができます。「humanize」「make it sound human」「remove AI patterns」「rewrite naturally」「less AI-sounding」「AI detection」「sounds like ChatGPT」「too polished」「sounds robotic」「make it natural」「assess this text」「score this copy」「check the copy in this figma」「humanize this screen」「improve text」「improve this text」「improve copy」「improve this copy」「better copy」「rewrite this」「fix this text」「clean up this copy」「polish this text」などのフレーズでトリガーされます。
