Initialisez Clapper et créez, éditez, prévisualisez, rendez et améliorez les vidéos React ainsi que les partitions originales « musique en code » avec une narration vocale locale en option. Gère la configuration CLI/temps d'exécution/projet, les instruments SFZ échantillonnés, le MIDI et les stems, la vue Studio Musique/Code, le motion design, les personnages, le foley et la révision visuelle/audio antagoniste. À utiliser pour les films Clapper, les partitions originales, les démonstrations animées et les recuts ; pas pour les interfaces utilisateur de sites web classiques ou les éditeurs vidéo non liés.
