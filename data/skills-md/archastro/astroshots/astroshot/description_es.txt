Capture capturas de pantalla deterministas de PNG y películas de viajes con la CLI unificada de @ archastro/astroshot. Utilice React para componentes de navegador aislados, Ink para estados de componentes de terminal fijos, PTY para ejecutables de terminal interactivos reales y película para navegador, PTY truecolor, ventana nativa de macOS o grabaciones de fotogramas personalizados. Use el navegador del agente para acciones únicas del navegador en vivo; use astroshots-review para transmitir capturas y leer comentarios; use una captura de pantalla para organizar un conjunto de imágenes de documentación.
