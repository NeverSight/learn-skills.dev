التقط لقطات شاشة PNG محددة ومقاطع رحلة باستخدام أداة CLI الموحدة @archastro/astroshot. استخدم React لمكونات المتصفح المعزولة، Ink لحالات مكونات الطرفية الثابتة، PTY لتنفيذات الطرفية التفاعلية الحقيقية، وmovie لتسجيلات المتصفح أو PTY بألوان حقيقية أو نافذة macOS الأصلية أو إطارات مخصصة. استخدم agent-browser لإجراءات المتصفح الحية لمرة واحدة؛ واستخدم astroshots-review لبث الالتقاطات وقراءة التعليقات؛ واستخدم screenshot لتنظيم مجموعة صور الوثائق.
