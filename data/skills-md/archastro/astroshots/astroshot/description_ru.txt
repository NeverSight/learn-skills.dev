Захватывайте детерминированные PNG‑скриншоты и видеоролики путешествий с помощью унифицированного CLI @archastro/astroshot. Используйте React для изолированных компонентов браузера, Ink — для фиксированных состояний терминальных компонентов, PTY — для реальных интерактивных терминальных исполняемых файлов, а movie — для записей браузера, truecolor PTY, нативного окна macOS или пользовательского кадра. Используйте agent-browser для единичных живых действий в браузере; используйте astroshots‑review для потоковой передачи захватов и чтения обратной связи; используйте screenshot для организации набора изображений документации.

Пожалуйста, всегда отвечайте на языке пользователя.
