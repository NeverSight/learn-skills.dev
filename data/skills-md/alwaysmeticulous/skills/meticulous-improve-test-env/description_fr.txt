Déterminez ce qu’il faut changer dans l’environnement de test d’un projet afin que le groupe d’agents ne soit plus bloqué lorsqu’il teste contre un backend en direct — semer de meilleures données de test, élargir les permissions de l’utilisateur de test, activer les drapeaux de fonctionnalités, corriger la connexion de test, etc. Lisez les obstacles de configuration enregistrés par le groupe d’agents, inspectez le code source et la configuration de l’environnement de test, et proposez des correctifs concrets. À utiliser lorsque les cas du groupe d’agents sont bloqués par l’environnement plutôt que par l’application, ou lorsqu’on demande « améliorer l’environnement de test », « corriger les obstacles de configuration du groupe d’agents » ou « pourquoi le groupe d’agents est bloqué ».
