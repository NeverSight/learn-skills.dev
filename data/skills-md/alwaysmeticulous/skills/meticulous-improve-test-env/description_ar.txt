اكتشف ما الذي يجب تغييره في بيئة الاختبار للمشروع حتى يتوقف تجمّع الوكلاء عن الانحشار عندما يختبر ضد خلفية حية — ضع بيانات اختبار أفضل، وسّع صلاحيات مستخدم الاختبار، فعّل أعلام الميزات، أصلح تسجيل الدخول للاختبار، وما إلى ذلك. يقرأ عوائق الإعداد التي سجّلتها Agent swarm، يفحص قاعدة الشيفرة وتكوين بيئة الاختبار، ويقترح إصلاحات ملموسة. يُستخدم عندما تُحجم حالات Agent swarm بسبب البيئة بدلاً من التطبيق، أو عند طلب "تحسين بيئة الاختبار"، "إصلاح عوائق إعداد Agent swarm" أو "لماذا تم حجب Agent swarm".
