Разберитесь, что нужно изменить в тестовой среде проекта, чтобы Agent Swarm перестал блокироваться при тестировании against live‑backend — добавьте более подходящие тестовые данные, расширьте права тестового пользователя, включите флаги функций, исправьте тестовый вход в систему и т.п. Считывает зафиксированные Agent Swarm блокирующие настройки, исследует кодовую базу и конфигурацию тестовой среды, предлагает конкретные исправления. Используйте, когда случаи Agent Swarm блокируются средой, а не приложением, или когда просят «улучшить тестовую среду», «исправить блоки настройки Agent Swarm» или «почему Agent Swarm заблокирован».
