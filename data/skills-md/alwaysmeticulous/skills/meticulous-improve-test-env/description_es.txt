Determina qué cambiar en el entorno de pruebas de un proyecto para que Agent swarm deje de quedar bloqueado al probar contra un backend en vivo — sembrar datos de prueba más adecuados, ampliar los permisos del usuario de prueba, activar banderas de características, corregir el inicio de sesión de pruebas, etc. Lee los bloqueos de configuración que Agent swarm ha registrado, inspecciona el código y la configuración del entorno de pruebas, y propone soluciones concretas. Úsalo cuando los casos de Agent swarm estén bloqueados por el entorno y no por la aplicación, o cuando se solicite “mejorar el entorno de pruebas”, “corregir los bloqueos de configuración de Agent swarm” o “¿por qué está bloqueado Agent swarm?”.
