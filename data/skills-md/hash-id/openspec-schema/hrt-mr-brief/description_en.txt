Writes mr-brief.md for tempa-spec's apply phase: a three-section brief (Summary, Evidence, Merge Danger) that helps a reviewer understand an implemented change, written so its content can be pasted as a merge/pull request comment after the user commits. Built from the change's own artifacts and real test runs, never invented. Adapted from mattpocock/skills `pr`, itself credited to Dex Horthy's `show-me`. Use at the end of the tempa-spec `apply` phase, after the review loop.
