Вход для темного режима tempa-spec (ограниченное автономное принятие решений посредством обнаружения через выравнивание, опционально через применение). Никогда не предлагалось заранее — активируется только тогда, когда пользователь просит об этом без подсказки, по его собственным словам. Перед любым подтверждением показывает обязательное предупреждение о риске, затем спрашивает, какой вариант (только планирование или +реализация) и создает dark.md. Используйте один раз, при обнаружении или после него, только по явному запросу пользователя.
