Die Überprüfung der Änderungsgröße wird innerhalb der „Vorschlags“-Phase des Tempa-Spec-Schemas ausgeführt, bevor die Liste „Was ändert sich“ finalisiert wird. Erkennt, wenn ein Entwurf mehrere unabhängige Änderungen bündelt, von denen jede ihre eigene Änderung verdient, stoppt und fragt den Benutzer, ob er geteilt werden soll (Standard: eine Änderung; der Agent teilt nie von selbst). Wenn der Benutzer teilt, werden die zurückgestellten Slices im Abschnitt „Out of Scope“ von Proposal.md, in den Schlüsselentscheidungen von Discovery.md und in OpenSpec/BACKLOG.md aufgezeichnet.
