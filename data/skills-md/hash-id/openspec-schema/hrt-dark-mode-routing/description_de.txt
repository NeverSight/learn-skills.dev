Eine einzige Quelle der Wahrheit, die angibt, wohin ein eskalationswürdiges Ergebnis gelangt, wenn der Dunkelmodus von tempa-spec aktiv ist (dark.md vorhanden). Jeder Vorschlag, jede Spezifikation, jedes Design, jede Ausrichtung und jedes Anwenden punktet hier, anstatt seinen eigenen Dark-Mode-Carveout einzubinden. Gibt an, welche Ergebnisse an hrt-dark-mode-decision-gate weitergeleitet werden, welche noch an den Benutzer gehen und welcher Abschnitt von dark.md das Ergebnis aufzeichnet.
