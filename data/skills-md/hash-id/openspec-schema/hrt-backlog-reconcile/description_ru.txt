Пользовательское обслуживание openspec/BACKLOG.md. Согласовывает записи отложенного среза с поставляемыми спецификациями в openspec/specs/, предлагает удалить уже охваченные записи и редактирует файл только после подтверждения каждой записи пользователем. Не является частью конвейера tempa-spec. Запустите его вручную, в идеале сразу после архива openspec.
