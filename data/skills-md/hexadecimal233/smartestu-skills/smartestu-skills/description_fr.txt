Travaillez avec smartestu.cn (数你最灵) depuis un agent. Lisez les cours d’un étudiant, la liste des 作业, le détail des 作业 avec chaque exercice, les 批改结果, et soumettez ou soumettez à nouveau les réponses via l’API HTTP documentée. Utilisez ceci lorsque l’utilisateur mentionne smartestu, 数你最灵, 作业, 交卷, 待批改, 习题, 错题本, 签到, 学号登录, ou demande d’inspecter les données de devoirs capturées depuis ce site.

Veuillez toujours répondre dans la langue de l’utilisateur.
