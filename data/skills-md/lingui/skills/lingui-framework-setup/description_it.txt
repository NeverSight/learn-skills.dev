Configura Lingui in un framework React. Usalo quando aggiungi Lingui a un progetto Next.js App Router, Vite, React Router 7, Remix o TanStack Start, quando imposti il rilevamento della lingua, URL con prefisso di lingua o la risoluzione della lingua in SSR, o quando una configurazione funzionante si rompe dopo un aggiornamento del framework o dello strumento di build.
