Audite un proyecto Lingui para detectar cadenas codificadas orientadas al usuario que nunca estuvieron incluidas en macros. Úselo cuando se le solicite buscar cadenas no traducidas, desenvueltas o codificadas, para verificar la cobertura de i18n, para auditar lo que se perdió en una configuración o migración de i18n, o cuando el texto se muestra en el idioma de origen después de que supuestamente todo se tradujo.
