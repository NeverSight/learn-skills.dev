# 多平台文案改写 · dby-rewrite

把一份原文改写成**某个平台读者习惯的样子**。七个平台，一次可以指定一个、几个或全部（一稿多发 = 各出一版，不是一版群发七处）。

> ⚠️ 本包纯本地不计费，改写全在你自己的 agent 里完成；服务端曾有过的云端改写能力已于 2026-08-28 整条下线，不存在任何计费的改写接口。

---

## 1. 怎么用（三步）

### 第 1 步：拿到原文和目标平台

**用户没说平台就问一句**，别默认公众号。

### 第 2 步：读该平台的规则

🔑 **一平台一文件，读要的那个就行，别整摞读。**

| 用户要哪个平台 | 读这份 | 这个平台的要害 |
|---|---|---|
| 公众号 / 微信公众号 | [`references/公众号.md`](references/公众号.md) | 金句 + 钩子；标题字数口径（15–28 字，见该文件）；正文带 2–3 个 Keyword；末尾 5–10 个 `#` 标签 |
| 视频号 / 微信视频号 | [`references/视频号.md`](references/视频号.md) | 口播感，开头三秒抓人 |
| 抖音 / dy | [`references/抖音.md`](references/抖音.md) | 第一句就是钩子（黄金三秒）；夸张只许用在情绪，不许用在功效 |
| 快手 / ks | [`references/快手.md`](references/快手.md) | 接地气、短小精悍、直给 |
| B站 / 哔站 / bilibili / 哔哩哔哩 | [`references/B站.md`](references/B站.md) | 社区黑话与弹幕感 |
| 小红书 / 红书 / xhs | [`references/小红书.md`](references/小红书.md) | **标题 ≤20 字、正文 ≤1000 字是发布硬上限**；至少 5 个不重复 emoji；二极管标题法；种草口吻；末尾 3–5 个 `#` 标签 |
| 知乎 / zhihu | [`references/知乎.md`](references/知乎.md) | 论证感、有理有据、克制 |

每份规则的结构都一样：`Role`（角色定位）/ `WritingSkills`（写作技巧）/ `Rules`（改写规则）/
`Workflow`（工作流程）。**照着 Workflow 走**，别只扫一眼 Role 就动笔。

也可以让脚本把规则打出来（脚本读的就是上面这些文件）：

```bash
python3 scripts/rewrite.py list                  # 七个平台和它们的别名
python3 scripts/rewrite.py 小红书                 # 单平台规则
python3 scripts/rewrite.py 抖音,知乎 "原文…"       # 多平台（逗号或空格分隔都行）
python3 scripts/rewrite.py all                   # 全平台（一稿多发）
python3 scripts/rewrite.py --selfcheck           # 离线自检：平台表与规则文件一一对应
```

### 第 3 步：直接输出改写结果

按该平台的 Workflow 改写，**直接给成品**。

**同时给一份改动清单**（原文这句 → 改写成什么 → 为什么），交付后问一次要不要存进稿件——
清单怎么拆、命令行怎么调见 [`references/draft/draft-changes.md`](references/draft/draft-changes.md)。

## 2. 通用纪律（七个平台都适用）

- **以文案发起者的身份写**：把用户的文案当自己的文案，只做风格转换。
  ❌ 不要说「帮你改写了」「以下是改写后的版本」，直接出成品。
- **只改风格，不改事实**：产品参数、价格、功效、时间地点一律照搬原文；编出来的卖点会变成用户的虚假宣传。
- **不反问、不确认**：输出完就结束，别再问「需要调整吗」。
- **多平台时逐个平台各出一版**，别出一版说「通用」。

---

## 3. 交付前自检（超限稿不交付）

逐平台过完这张单再交；超限的当场改到限内，不交「差一点点」的稿：

- **小红书**：标题 ≤20 字（emoji 计入）、正文 ≤1000 字、标签 3–5 个、无外站联系方式（微信 / vx / 电话 / 公众号同名）。
- **公众号**：标题 15–28 字。
- **七平台通用 · 极限词与功效承诺不进标题 / 摘要 / 正文**：权威口径与词表在 `dby-banned-words`，
  本包不自建一份，过一遍就行：
  ```bash
  python3 <dby-banned-words>/scripts/check_multi.py "<标题+正文>" --platforms xiaohongshu,douyin,gongzhonghao   # 只留本次涉及的平台
  ```
  命中即改；其余四平台不在检测口径里，但《广告法》第九条一样管，极限词照删。
- **事实核对**：产品参数 / 价格 / 时间地点逐项对回原文（第 2 节「只改风格，不改事实」的执行面）。

**Recovery**：`references/<平台>.md` 读不到 → 如实说明这个平台的规则缺失、**不凭印象改**，其余平台照常出。
