Studio tematico per il layout dell'account pubblico WeChat: regola lo stile di layout predefinito dell'articolo del tuo account pubblico (combinazione di colori/titoli/virgolette/didascalie delle figure) in base alla tua lingua parlata, con anteprima locale istantanea e infine applica le modifiche in due punti: salva nuovamente sul server + salva come file del tema locale. Utilizza doubaoya.com, con l'autenticazione tramite la tua DOUBAOYA_API_KEY. Metodi di attivazione: /dby‑tema, modifica il layout dell'account pubblico, personalizza lo stile del tema, modifica la combinazione di colori dell'account pubblico, regola il tema del layout, modifica il layout predefinito. Parole trigger: personalizza il tema dell'articolo WeChat, modifica il layout/palette/stile dell'intestazione.
