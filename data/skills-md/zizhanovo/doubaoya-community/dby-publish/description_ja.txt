パブリック アカウントの記事パイプライン · 最終状態は **フォーマットされたパブリック アカウント HTML** または **独自のパブリック アカウントの下書きボックスに保存された記事**です。その場合はそれを使用してください (下書きの保存のみを行い、一括送信はしないでください)。入力は **すでに書かれている** Markdown/HTML です。このパイプラインは本文を書き込まず、確定的な後処理 (レンダリング → 画像の事前アップロード → 表紙 → ドラフトの保存) のみを実行します。 ⚠️ これは **ユーザー自身のパブリック アカウント バックエンドに書き込む**ため、原稿が完成したらユーザーが勝手に実行しないでください。下書きを保存するには、アカウント + DOUBAOYA_API_KEY をバインドする必要があります。ローカルレンダリング/テーマ切り替えのみの場合は必要ありません。トリガーワード: 本文の準備ができたら公開する方法 / 公用アカウントの HTML の書式設定が必要 / 次に書式を設定して下書きを送信 / 公用アカウントを作成 / 公用アカウントの書式設定に変換 / 公用アカウントの下書きをプッシュ / 下書きを再プッシュ / 表紙を下書きボックスに公開 / 記事を公用アカウントの下書きボックスに保存 / 公用アカウントの記事パイプライン / dby 公開 / 公用アカウントの下書きを保存 /パブリックアカウントの下書きボックス / プロキシによるパブリックアカウントへの公開 ドラフトボックス / addDraft / ドラフト/追加 / パブリックアカウントへの記事のプッシュ / パブリックアカウントのバックエンドへの原稿の送信。
