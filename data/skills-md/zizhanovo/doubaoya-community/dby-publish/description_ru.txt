Конвейер статей для общедоступной учетной записи · Конечным состоянием является **отформатированный HTML-код общедоступной учетной записи** или **статья, сохраненная в ящике черновиков общедоступной учетной записи**; используйте его тогда (сохраняйте только черновики, но не массовую отправку). Входные данные **уже написаны** в формате Markdown/HTML; этот конвейер не записывает тело, он только выполняет детерминированную постобработку: рендеринг → предварительная загрузка изображений → обложка → сохранение черновика. ⚠️ Он будет **записываться в собственную общедоступную учетную запись пользователя**, поэтому, когда рукопись будет завершена, пользователь не должен произвольно запускать ее. Для сохранения черновиков требуется привязка аккаунта + DOUBAOYA_API_KEY; только локальный рендеринг/переключение темы в этом не нуждаются.
