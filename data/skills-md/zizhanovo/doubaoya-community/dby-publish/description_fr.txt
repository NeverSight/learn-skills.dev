Pipeline d'articles de compte public · L'état final est **un HTML de compte public formaté** ou **l'article enregistré dans votre propre boîte de brouillon de compte public** ; utilisez-le alors (enregistrez uniquement les brouillons, jamais envoyez-le en masse). L'entrée est **déjà écrite** Markdown/HTML ; ce pipeline n'écrit pas le corps, il effectue uniquement un post-traitement déterministe : rendu → pré-télécharger les images → couverture → enregistrer le brouillon. ⚠️ Il **écrira dans le backend du compte public de l'utilisateur**, donc lorsque le manuscrit est terminé, l'utilisateur ne doit pas l'exécuter arbitrairement. L'enregistrement des brouillons nécessite de lier un compte + DOUBAOYA_API_KEY ; seul le rendu local/le changement de thème n'en a pas besoin.
