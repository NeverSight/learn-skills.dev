Pipeline de publication d'articles de compte public · L'état final est soit **un HTML de compte public bien formaté**, soit **l'article enregistré dans votre propre boîte de brouillons de compte public** ; utilisez-le (il enregistre uniquement les brouillons, jamais les envois en masse). L'entrée est **pré-écrit** Markdown/HTML ; ce pipeline n'écrit pas le corps pour vous, il effectue uniquement un post-traitement déterministe : rendu → pré-télécharger les images → couverture → enregistrer le brouillon. ⚠️ Il **écrira dans le backend du compte public de l'utilisateur**, donc une fois le brouillon terminé, ne l'exécutez pas arbitrairement. L'enregistrement des brouillons nécessite un compte lié + DOUBAOYA_API_KEY ; il n'est pas nécessaire uniquement pour le rendu local/le changement de thème.
