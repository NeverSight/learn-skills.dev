公眾號文章管道 · 最終狀態是**格式化的公眾號HTML**或**保存到自己的公眾號草稿箱中的文章**；然後使用它（僅保存草稿，切勿批量發送）。輸入是**已經寫好的** Markdown/HTML；該管道不寫入正文，它只執行確定性後處理：渲染→預上傳圖像→封面→保存草稿。 ⚠️它會**寫入用戶自己的公眾號後台**，所以當稿件完成後，用戶不要隨意運行它。儲存草稿需要綁定帳號+DOUBAOYA_API_KEY；只有本地渲染/主題切換不需要它。觸發詞：正文準備好後如何發布 / 需要格式化公眾號 HTML / 然後格式化並發送草稿 / 編寫公眾號 / 轉換為公眾號格式 / 推送公眾號草稿 / 重新推送草稿 / 帶封面發佈到草稿箱 / 將文章保存到公眾號草稿/ 公眾/ 草稿/新增 /文章推送到公眾號/發送稿件到公眾號後台。
