Fournir des commentaires à « All‑Explosion Duck » (ce canard) : lorsqu'un utilisateur souhaite signaler un bug, faire une suggestion ou se plaindre de l'expérience, l'agent rédige immédiatement un rapport de commentaires complet basé sur les événements réels survenus dans la conversation en cours. L'utilisateur révise le texte intégral puis le soumet au responsable ; si le point de terminaison est inaccessible, le rapport est enregistré dans un fichier local. Mots déclencheurs : « signaler un bug », « signaler un bug », « commentaires », « donner une suggestion », « faire une demande », « donner un avis », « se plaindre », « ne peut pas l'utiliser », « cassé ? À ne pas faire : la détection des mots interdits est gérée par dby-banned-words ; la mise à jour de ce canard est gérée par dby‑update ; la copie de réécriture est gérée par dby‑rewrite.
