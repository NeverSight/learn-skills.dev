Commentaires pour Du Bao Duck (ce canard) : lorsqu'un utilisateur souhaite signaler un bug, faire une suggestion ou s'exprimer sur l'expérience, l'agent rédige instantanément un retour complet basé sur les événements réels survenus dans la conversation en cours. Une fois que l'utilisateur a examiné le texte intégral, celui-ci est soumis au responsable ; si le point de terminaison n'est pas disponible, il est enregistré dans un fichier local. Mots déclencheurs : « signaler un bug », « rapport de bug », « commentaires », « donner une suggestion », « demander », « donner un avis », « exprimer », « ne peut pas utiliser », « cassé ? À ne pas faire : la détection des mots interdits passe par les mots interdits ; la mise à jour de ce canard passe par dby‑update ; la copie de réécriture passe par dby‑rewrite.
