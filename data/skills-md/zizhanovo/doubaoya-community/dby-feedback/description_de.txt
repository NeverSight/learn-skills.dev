Geben Sie DuBao Duck (dieser Ente) Feedback: Wenn ein Benutzer einen Fehler melden, einen Vorschlag machen oder sich zu seiner Erfahrung äußern möchte, verfasst der Agent sofort ein vollständiges Feedback-Dokument, das auf den tatsächlichen Ereignissen des aktuellen Gesprächs basiert. Der Benutzer überprüft den vollständigen Text und übermittelt ihn dann an den Betreuer. Wenn der Endpunkt nicht erreichbar ist, wird er in einer lokalen Datei gespeichert. Auslöserwörter: Fehler melden, Fehler melden, Feedback geben, einen Vorschlag machen, eine Anforderung vorschlagen, eine Meinung abgeben, sich beschweren, nicht verwenden, kaputt, das ist nervig, zu schwer zu verwenden, fühlt sich unangenehm an, kann es geändert werden, sagen Sie es dem Autor/Betreuer/Entwickler. Nicht behandelt: Die Erkennung verbotener Wörter erfolgt über dby-verbotene Wörter. Das Aktualisieren dieser Ente erfolgt über dby-update; Das Umschreiben der Kopie erfolgt über dby-rewrite.
