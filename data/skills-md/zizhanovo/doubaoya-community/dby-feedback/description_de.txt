Feedback für Du Bao Duck (diese Ente): Wenn ein Benutzer einen Fehler melden, einen Vorschlag machen oder sich über die Erfahrung äußern möchte, schreibt der Agent sofort ein vollständiges Feedback basierend auf den tatsächlichen Ereignissen, die in der aktuellen Konversation aufgetreten sind. Nachdem der Benutzer den vollständigen Text überprüft hat, wird er an den Betreuer übermittelt. Wenn der Endpunkt nicht verfügbar ist, wird er in einer lokalen Datei gespeichert. Auslöserwörter: „Einen Fehler melden“, „Fehler melden“, „Feedback“, „einen Vorschlag machen“, „Anfrage“, „eine Meinung abgeben“, „entlüften“, „nicht verwenden“, „kaputt?“, „das ist nervig“, „zu schwer zu verwenden“, „fühlt sich umständlich an“, „können Sie es ändern“, „sagen Sie es dem Autor/Betreuer/Entwickler“. Tun Sie dies nicht: Die Erkennung verbotener Wörter erfolgt über dby-verbotene Wörter. Das Aktualisieren dieser Ente erfolgt über dby-update; Das Umschreiben der Kopie erfolgt über dby-rewrite.
