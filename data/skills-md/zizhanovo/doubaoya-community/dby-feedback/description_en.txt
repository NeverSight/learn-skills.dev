Feedback for Du Bao Duck (this duck): When a user wants to report a bug, make a suggestion, or vent about the experience, the agent instantly writes a complete feedback based on the actual events that occurred in the current conversation. After the user reviews the full text, it is submitted to the maintainer; if the endpoint is unavailable, it is saved to a local file.
