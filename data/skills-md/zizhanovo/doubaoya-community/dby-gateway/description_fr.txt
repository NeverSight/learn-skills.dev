**Invocation Gateway** de la plateforme Doubaoya (compétence d'infrastructure, **ne gère pas l'intention commerciale**) : comment gérer l'authentification, comment choisir entre deux routes sans secours, comment interpréter l'enveloppe unifiée et les codes d'erreur, et une règle : **extraire la spécification d'entrée avant l'invocation**. Non responsable de la rédaction d'articles/de la sélection de sujets/de la création de couvertures/de la vérification des mots interdits ; ceux-ci passent par « dby ». Mots déclencheurs : protocole d'invocation doubaoya / passerelle d'invocation / DOUBAOYA_API_KEY / operationKey /execution.target / inputContract / spécification d'entrée / enveloppe unifiée / SKILL_NOT_FOUND / ENDPOINT_NOT_FOUND / DEDICATED_ROUTE / NO_RESULT / CAPABILITY_UNAVAILABLE / quelle route emprunter ; ainsi que lors de l'appel des API Doubaoya « erreurs 401 / 404 / 429 », « impossible de se connecter », « comment s'authentifier », « requestId ».
