**بوابة الاستدعاء** الخاصة بمنصة Doubaoya (مهارة البنية التحتية، **لا تتعامل مع نية العمل**): كيفية إجراء المصادقة، وكيفية الاختيار بين مسارين غير احتياطيين، وكيفية فك تشفير المغلف الموحد وأكواد الخطأ، وقاعدة واحدة —** سحب مواصفات الإدخال قبل الاستدعاء**. ليست مسؤولة عن كتابة المقالات / اختيار المواضيع / إنشاء الغلاف / التحقق من الكلمات المحظورة؛ هؤلاء يمرون بـ "dby". كلمات التشغيل: بروتوكول استدعاء doubaoya / بوابة الاستدعاء / DOUBAOYA_API_KEY / OperationKey / Execution.target / inputContract / مواصفات الإدخال / المغلف الموحد / SKILL_NOT_FOUND / ENDPOINT_NOT_FOUND / DEDICATED_ROUTE / NO_RESULT / CAPABILITY_UNAVAILABLE / أي طريق يجب استخدامه؛ وكذلك عند الاتصال بواجهات Doubaoya API التي تواجه "أخطاء 401 / 404 / 429"، "لا يمكن الاتصال"، "كيفية المصادقة"، "معرف الطلب".
