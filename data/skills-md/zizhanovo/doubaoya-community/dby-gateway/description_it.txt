**Invocation Gateway** della piattaforma Doubaoya (competenza infrastrutturale, **non gestisce l'intento aziendale**): come gestire l'autenticazione, come scegliere tra due percorsi non di fallback, come interpretare la busta unificata e i codici di errore e una regola: **estrazione della specifica di input prima dell'invocazione**. Non è responsabile della scrittura di articoli/selezione di argomenti/creazione di copertine/controllo delle parole proibite; quelli passano attraverso "dby". Parole trigger: protocollo di invocazione doubaoya / gateway di invocazione / DOUBAOYA_API_KEY / operazioneKey / esecuzione.target / inputContract / specifica di input / busta unificata / SKILL_NOT_FOUND / ENDPOINT_NOT_FOUND / DEDICATED_ROUTE / NO_RESULT / CAPABILITY_UNAVAILABLE / quale percorso prendere; così come quando si chiamano le API Doubaoya “errori 401/404/429”, “impossibile connettersi”, “come autenticarsi”, “requestId”.
