**Invocation Gateway** della piattaforma Doubaoya (competenza infrastrutturale, **non gestisce l'intento aziendale**): come effettuare l'autenticazione, come scegliere tra due percorsi che si escludono a vicenda, come interpretare la busta unificata e i codici di errore e una regola: **pull delle specifiche dei parametri di input prima dell'invocazione**. Non è responsabile della scrittura di articoli, della selezione degli argomenti, della creazione di copertine o del controllo delle parole proibite; quelli passano attraverso "dby". Parole trigger: protocollo di invocazione doubaoya / gateway di invocazione / DOUBAOYA_API_KEY / operazioneKey / esecuzione.target / inputContract / specifica dei parametri di input / busta unificata / SKILL_NOT_FOUND / ENDPOINT_NOT_FOUND / DEDICATED_ROUTE / NO_RESULT / CAPABILITY_UNAVAILABLE / quale percorso utilizzare; così come quando si chiamano le API Doubaoya “errori 401/404/429”, “chiamata non riuscita”, “come autenticarsi”, “requestId”.
