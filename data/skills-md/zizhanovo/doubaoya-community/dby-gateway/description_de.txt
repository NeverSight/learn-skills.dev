**Invocation Gateway** der Doubaoya-Plattform (Infrastruktur-Skill, **verwaltet keine Geschäftsabsicht**): wie man mit der Authentifizierung umgeht, wie man zwischen zwei Nicht-Fallback-Routen wählt, wie man den einheitlichen Umschlag und die Fehlercodes interpretiert und eine Regel – **die Eingabespezifikation vor dem Aufruf abrufen**. Nicht verantwortlich für das Schreiben von Artikeln / die Auswahl von Themen / das Erstellen von Covern / das Überprüfen verbotener Wörter; diese durchlaufen „dby“. Auslöserwörter: Doubaoya-Aufrufprotokoll / Aufruf-Gateway / DOUBAOYA_API_KEY / OperationKey / Execution.target / InputContract / Eingabespezifikation / einheitlicher Umschlag / SKILL_NOT_FOUND / ENDPOINT_NOT_FOUND / DEDICATED_ROUTE / NO_RESULT / CAPABILITY_UNAVAILABLE / welche Route genommen werden soll; sowie beim Aufruf der Doubaoya-APIs „401/404/429-Fehler“, „Verbindung nicht möglich“, „Authentifizierung“, „requestId“.
