Das **Call-Gateway** der Doubaoya-Plattform (Infrastruktur-Skill, **verwaltet keine geschäftlichen Absichten**): wie man die Authentifizierung durchführt, wie man zwischen zwei Nicht-Fallback-Routen wählt, wie man den einheitlichen Umschlag und die Fehlercodes auflöst und eine Regel – **die Eingabespezifikation vor dem Aufruf abrufen**. Es ist nicht verantwortlich für das Schreiben von Artikeln / die Auswahl von Themen / das Erstellen von Covern / das Überprüfen verbotener Wörter; diese durchlaufen „dby“. Auslösewörter: Doubaoya-Aufrufprotokoll / Aufruf-Gateway / DOUBAOYA_API_KEY / OperationKey / Execution.target / InputContract / Eingabespezifikation / einheitlicher Umschlag / SKILL_NOT_FOUND / ENDPOINT_NOT_FOUND / DEDICATED_ROUTE / NO_RESULT / CAPABILITY_UNAVAILABLE / welche Route verwendet werden soll; sowie beim Aufrufen der API von Doubaoya stoßen Sie auf „401/404/429-Fehler“, „Verbindung nicht möglich“, „Authentifizierung“ und „RequestId“.
