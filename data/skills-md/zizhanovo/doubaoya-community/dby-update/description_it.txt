Aggiornamento della riconciliazione delle competenze di Doubaoya (doubaoya / 本鸭): riconcilia il set locale di competenze 本鸭 con la raccolta completa corrente del repository ufficiale: archivia quelle che sono state rimosse a monte, installa quelle appena aggiunte, aggiorna quelle obsolete e infine esegui un autocontrollo. Identificare i pacchetti in base all'hash del contenuto; lasciare intatti i pacchetti altrui o quelli che l'utente ha modificato anche di un solo carattere; spostare i pacchetti rimossi in una directory di archivio invece di eliminarli. Riconcilia le abilità doubaoya installate con il set a monte, quindi esegue l'autocontrollo. Metodi di attivazione: /dby-update, “aggiorna 本鸭”, “aggiorna 都爆鸭”, “aggiorna abilità doubaoya”, “controlla gli aggiornamenti 本鸭”, “aggiorna 本鸭 all’ultima versione”.
