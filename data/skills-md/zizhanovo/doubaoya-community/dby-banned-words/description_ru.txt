Многоплатформенное обнаружение запрещенных слов — единый фрагмент копии, который одновременно сравнивает критерии проверки трех основных платформ (Xiaohongshu, Douyin, общедоступные учетные записи WeChat), выводит таблицу сравнения рисков для каждой платформы и версию, переписанную для обеспечения безопасности на всех платформах. Триггерные слова: запрещенные слова для нескольких платформ, запрещенные слова для всех платформ, запрещенные слова для публичной учетной записи, межплатформенное соответствие, обнаружение соответствия, одобрение, обнаружение запрещенных слов, деликатные слова, слова-нарушения, крайние слова, абсолютный язык, самопроверка, ограничивающая поток, неудавшаяся проверка, закон о рекламе. Не следует: менять стиль письма или тон платформы с помощью dby‑rewrite; напишите текст с нуля, используя dby‑write.
