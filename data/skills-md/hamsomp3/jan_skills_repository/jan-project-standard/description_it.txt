Estandardizza progetti personali e accademici con le convenzioni di Jan Polanco Velasco: Python con uv/Astral (3.13+), src‑layout, Ruff, pre‑commit, Makefile, pytest, CONSTITUTION.md come fonte unica di verità, Conventional Commits, README con badge, licenza MIT, governance GitHub (template PR/issue, CI, Dependabot, etichette), contesto per agenti (AGENTS.md, .opencode/, tgrep), identità Git automatica (includeIf; profilo Jan o profilo personale su macOS/Windows) e diagrammi di architettura con Archify. Usala quando crei o standardizzi un repository, redigi un CONSTITUTION.md, configuri uv/Ruff/pre‑commit/CI, aggiungi un Makefile o README, configuri l’identità Git automatica, generi un diagramma con Archify o colleghi il progetto a GitHub. Usa quando scaffolding di un repository Python, scrivi un CONSTITUTION.md, imposti uv, Ruff, pre‑commit o CI, configuri l’identità Git automatica, generi un diagramma Archify o standardizzi un progetto.
