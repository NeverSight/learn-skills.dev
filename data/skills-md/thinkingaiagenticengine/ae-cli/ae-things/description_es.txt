Elementos del espacio de trabajo (cosas): use `ae-cli things` para crear, consultar, actualizar y avanzar elementos dentro de un AgentSpace claramente definido. Emplee esto de manera proactiva cada vez que la conversación incluya asignaciones de roles (quién es responsable de qué), entregables, ritmo, tareas pendientes, próximos pasos, hitos o planes de fase, sin que el usuario tenga que decir explícitamente "crear elemento".
