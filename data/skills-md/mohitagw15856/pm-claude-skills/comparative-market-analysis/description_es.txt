Crear un análisis de mercado comparativo (CMA) para fijar el precio de una propiedad. Utilícelo cuando se solicite un CMA, un análisis de mercado comparativo, fijar el precio de una casa o estimar el valor de una propiedad a partir de comparables. Produce un CMA estructurado: la propiedad objeto, los comparables seleccionados con ajustes, un rango de valor estimado, contexto del mercado y una recomendación de precio con justificación, para que un profesional inmobiliario lo revise. No es una tasación formal.
