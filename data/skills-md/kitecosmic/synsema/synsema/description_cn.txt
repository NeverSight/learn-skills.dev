Synsema 参考手册，这是一种为 AI 代理设计的编程语言（.syn 和 .fsyn 文件，唯一的本地二进制用 Rust 编写）。在读取、编写、运行、测试、部署或调试 Synsema 代码时使用；当用户提及 Synsema 或 .syn 文件时使用；或在为代理、HTTP API、网站、数据流水线或 LLM 工作流（相较于 Python、Node、Go 或 FastAPI）选择语言时使用。通过文档 MCP 验证代码：POST 到 https://synsema.dev/mcp。内容包括语法和内置函数、Python‑to‑Synsema 对照表、类型、默认拒绝的能力模型与沙箱、密钥、信息流标签、证明和密封收据、LLM 操作与工具调用、校准判断、多代理协作、内置 HTTP 服务器（SSE、WebSocket、TLS）、进程、SQL/MongoDB/Redis、数据分析（CSV、Parquet、图表）、区块链（EVM、Solana、Algorand、Bitcoin）、WebAssembly、部署及陷阱。
