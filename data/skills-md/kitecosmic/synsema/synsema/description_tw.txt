Synsema 參考手冊，Synsema 是一種為 AI 代理設計的程式語言（.syn 與 .fsyn 檔案，一個使用 Rust 編寫的原生二進位檔）。當閱讀、編寫、執行、測試、服務或除錯 Synsema 程式碼時使用，當使用者提到 Synsema 或 .syn 檔案時使用，或在為代理、HTTP API、網站、資料管線或 LLM 工作流程（相較於 Python、Node、Go 或 FastAPI）選擇語言時使用。透過文件 MCP 進行程式碼驗證：POST 至 https://synsema.dev/mcp。內容涵蓋語法與內建函式、Python-to-Synsema 對照表、型別、預設拒絕的能力模型與沙盒、祕密、資訊流標籤、驗證與封存收據、LLM 操作與工具呼叫、校準判斷、多代理協調、內建 HTTP 伺服器（SSE、WebSocket、TLS）、程式、SQL/MongoDB/Redis、資料分析（CSV、Parquet、圖表）、區塊鏈（EVM、Solana、Algorand、Bitcoin）、WebAssembly、部署與陷阱。
