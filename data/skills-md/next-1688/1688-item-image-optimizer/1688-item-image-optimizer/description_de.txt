Einheitlicher Einstieg für die Erstellung von Produktbildern: Hauptbildoptimierung, Karussellbilder, Detailbilder, Hintergrundaustausch, digitale Modelle. Kernfunktionen: verify_permission (erweiterte Berechtigungsprüfung), build_tool_url (Erstellung der Tool‑Seiten‑URL), configure (AK‑Konfiguration). Auslöserwörter: ein Set von Bildern erstellen, Bilder erstellen, Bilder generieren, Hauptbild optimieren, Hauptbildoptimierung, Karussellbilder, Detailbilder, Hintergrundaustausch, digitales Modell, Produktbilder, Bild bearbeiten, Bildoptimierung. Sollte nicht auslösen: neues Produkt‑Launch/Bulk‑Listing (von der Produktfreigabefähigkeit behandelt), Marken‑VI/Poster/Store‑Dekoration, Bildspezifikations‑Q&A. Der Bildgenerierungsprozess dieser Fähigkeit ist bereits durch einen Workflow abgedeckt; wenn Auslöserwörter erkannt werden, wird der Workflow direkt ausgeführt. Falls der Workflow die Aufgabe nicht erledigen kann (z. B. reine Fähigkeits‑Q&A, Einzelbefehl‑Aufruf, explorative Nutzung), lade dieses SKILL.md zur Weiterverarbeitung. Bitte immer in der Sprache des Benutzers antworten.
