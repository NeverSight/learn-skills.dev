Entrée unifiée pour la création d'images produit : optimisation de l'image principale, images de carrousel, images détaillées, remplacement d'arrière-plan, modèle numérique. Capacités de base : verify_permission (vérification avancée des autorisations), build_tool_url (construire l'URL de la page d'outil), configure (configuration AK). Mots déclencheurs : créer un ensemble d'images, créer image, générer image, optimiser l'image principale, optimisation de l'image principale, image de carrousel, image détaillée, remplacement d'arrière-plan, modèle numérique, image produit, éditer image, optimisation d'image. Ne doit pas déclencher : nouveau lancement de produit/listage par lot (utiliser la compétence de lancement de produit), identité visuelle de marque/affiche/décoration de magasin, questions‑réponses sur les spécifications d'image. Le processus de création d'image pour cette compétence est couvert par l'orchestration du workflow ; lorsqu'un mot déclencheur est détecté, le workflow s'exécute directement. Si le workflow ne peut pas accomplir la tâche (par ex., Q&A pure capacité, invocation d'une seule commande, usage exploratoire), chargez ce SKILL.md pour le raisonnement.

Veuillez toujours répondre dans la langue de l'utilisateur.
