Единая точка входа для создания изображений продукта: оптимизация основной картинки, изображения‑карусели, детализированные изображения, замена фона, цифровая модель. Основные возможности: verify_permission (расширенная проверка разрешений), build_tool_url (формирование URL страницы инструмента), configure (конфигурация AK). Триггерные слова: создать набор изображений, делать изображения, генерировать изображения, оптимизировать основную картинку, оптимизация основной картинки, изображения‑карусели, детализированные изображения, замена фона, цифровая модель, изображение продукта, редактировать изображение, оптимизация изображений. Не должны срабатывать: запуск нового продукта/массовый листинг (использовать навык выпуска продукта), брендовый VI/постер/оформление магазина, вопросы‑ответы по спецификациям изображений. Процесс создания изображений этим навыком уже покрыт оркестрацией рабочих процессов; при обнаружении триггерных слов рабочий процесс запускается непосредственно. Если рабочий процесс не может выполнить задачу (например, чистый Q&A по возможностям, вызов одной команды, исследовательское использование), загрузите этот SKILL.md для рассуждения.
