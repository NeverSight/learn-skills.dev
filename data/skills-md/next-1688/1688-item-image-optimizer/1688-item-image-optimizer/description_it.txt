Entrata unificata per la creazione di immagini di prodotto: ottimizzazione dell'immagine principale, immagini carousel, immagini dettagli, sostituzione dello sfondo, modello digitale. Capacità principali: verify_permission (verifica avanzata dei permessi), build_tool_url (costruzione dell'URL della pagina dello strumento), configure (configurazione AK). Parole di attivazione: creare un set di immagini, creare immagini, generare immagini, ottimizzare immagine principale, ottimizzazione immagine principale, immagini carousel, immagini dettagli, sostituzione sfondo, modello digitale, immagini di prodotto, modificare immagini, ottimizzazione immagini. Non dovrebbe attivarsi: lancio di nuovo prodotto/elenco batch (usare la skill di lancio prodotto), brand VI/poster/decoro del negozio, Q&A specifiche immagine. Il processo di creazione di immagini di questa skill è già coperto dall’orchestrazione del workflow; quando le parole di attivazione corrispondono, il workflow viene eseguito direttamente. Se il workflow non può completare il compito (ad es., Q&A di pura capacità, invocazione di comando singolo, uso esplorativo), caricare questo SKILL.md per il ragionamento.

Rispondi sempre nella lingua dell'utente.
