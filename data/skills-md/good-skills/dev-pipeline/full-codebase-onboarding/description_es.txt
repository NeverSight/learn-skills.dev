Genera un manual de incorporación visual completo a partir de cualquier repositorio de código fuente grande. Combina análisis estructurado de todo el proyecto, diagramas editoriales de diseño, documentación detallada de módulos, tutor de IA en vivo potenciado por LiteLLM y una base de conocimiento autoactualizable. Úsalo cuando el usuario necesite una incorporación total para una enorme base de código, quiera un sitio de guía visual que cubra todo el proyecto, conectar LiteLLM o crear una IA que responda preguntas y aprenda del código fuente.
