Générez un guide d'intégration visuel complet à partir de n'importe quel grand référentiel de code source. Combine une analyse structurée de l'ensemble du projet, des diagrammes éditoriaux de conception, une documentation détaillée des modules, un tuteur IA en direct alimenté par LiteLLM et une base de connaissances auto‑mise à jour. Utilisez‑le lorsque l'utilisateur a besoin d'une intégration complète pour une base de code massive, souhaite un site de guide visuel couvrant l'ensemble du projet, connecter LiteLLM ou créer une IA qui répond aux questions et apprend à partir du code source.

Veuillez toujours répondre dans la langue de l'utilisateur.
