Запускает фазовый конвейер отслеживания разработки продукта для рабочих процессов AI‑агентов: документы до продакшна, перенос текущих проектов из существующей документации, фазовые брифы, обновляющие бизнес‑логику и бэклог из пользовательского текста с дедупликацией требований, общие для продукта пользовательские истории (создание или извлечение из реализованных функций) с проверкой охвата каждой ветки при передаче задач, эпики/фичи/задачи со стабильными идентификаторами, переключение фаз без нарушающих изменений, единый источник правды для контрактов между слоями/сервисами (frontend→backend и новые сервисы), регистрация поверхностей, сжатие текста в стиле «Caveman» для передачи между агентами (--compress/--caveman) и автономные передачи запросов задач. Использовать, когда пользователь начинает с /dev-pipeline, просит инициализировать или принять конвейер бэклога продукта, оформить бриф фазы, создать или извлечь пользовательские истории, создать или переключить фазу, зарегистрировать новую поверхность/сервис, обновить общие контракты, сгенерировать следующий запрос задачи для агента, при желании углубить передачу с помощью Promptize, либо отслеживать статус эпиков/фич в многогенерационном развитии.
