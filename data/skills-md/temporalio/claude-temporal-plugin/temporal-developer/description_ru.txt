Разрабатывайте, отлаживайте и управляйте приложениями Temporal на Python, TypeScript, Go, Java, .NET, Ruby и Rust. Используйте, когда пользователь создаёт рабочие процессы, активности или воркеры с помощью SDK Temporal, отлаживает такие проблемы, как ошибки недетерминизма, зависшие рабочие процессы или повторные попытки активности, используя Temporal CLI, Temporal Server или Temporal Cloud, а также работает с концепциями долговечного выполнения, такими как сигналы, запросы, heartbeats, версионирование, continue-as-new, дочерние рабочие процессы или шаблоны saga. Также используйте, когда пользователь упоминает «запустить рабочий процесс Temporal из CLI», «запустить dev‑сервер», «run temporal server start-dev», «temporal workflow start», «temporal workflow execute», «temporal workflow signal», «temporal workflow query», «temporal workflow update».
