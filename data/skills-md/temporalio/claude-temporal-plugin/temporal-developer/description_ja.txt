Python、TypeScript、Go、Java、.NET、Ruby、Rustで Temporal アプリケーションを開発、デバッグ、管理します。ユーザーが Temporal SDK でワークフロー、アクティビティ、ワーカーを構築しているとき、非決定性エラーや停止したワークフロー、アクティビティのリトライなどの問題をデバッグする際、Temporal CLI、Temporal Server、Temporal Cloud を使用する際、またはシグナル、クエリ、ハートビート、バージョニング、continue-as-new、子ワークフロー、サガパターンといった耐久実行の概念で作業しているときに使用してください。さらに、ユーザーが「CLI から Temporal ワークフローを実行する」「開発サーバーを起動する」「temporal server start‑dev を実行する」「temporal workflow start」「temporal workflow execute」「temporal workflow signal」「temporal workflow query」「temporal workflow update」と言及した場合にも使用してください。
