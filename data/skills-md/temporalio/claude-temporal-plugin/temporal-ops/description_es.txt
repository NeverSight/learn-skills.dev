Administrar y diagnosticar entornos de Temporal Cloud o Temporal Server autoalojado en ejecución mediante CLI (temporal, tcld) — no código SDK. Operaciones: CRUD de namespaces, capacidad de Cloud/APS, rotación de claves API, rotación de certificados mTLS, salud de flujos de trabajo, cancelación/terminación/restablecimiento por lotes, exportación, atributos de búsqueda, API de Operaciones, facturación, registros de auditoría, Terraform, SAML/SCIM, migración. Diagnóstico: triage de abajo hacia arriba de flujos de trabajo atascados, no determinismo, salud del worker, problemas de colas de tareas, conmutación por error HA, límites de tamaño de payload, cuellos de botella de rendimiento, programaciones perdidas. NO activar para errores genéricos de TLS/gRPC no relacionados con Temporal, escritura de código de aplicación (temporal-developer) o ajuste/tamaño de workers (temporal-workertuning).  

Por favor, responda siempre en el idioma del usuario.
