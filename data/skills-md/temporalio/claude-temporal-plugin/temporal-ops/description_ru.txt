Администрировать и диагностировать работающие среды Temporal Cloud или самостоятельно развернутый Temporal Server через CLI (temporal, tcld) — не код SDK. Операции: CRUD пространств имён, ёмкость облака/APS, ротация API‑ключей, ротация сертификатов mTLS, состояние воркфлоу, массовая отмена/завершение/сброс, экспорт, атрибуты поиска, Ops API, биллинг, аудит‑журналы, Terraform, SAML/SCIM, миграция. Диагностика: снизу‑вверх триаж зависших воркфлоу, недетерминизм, состояние воркеров, проблемы очереди задач, переключение HA, ограничения размера полезной нагрузки, узкие места производительности, пропущенные расписания. НЕ вызывайте для общих ошибок TLS/gRPC, не связанных с Temporal, написания прикладного кода (temporal-developer) или настройки/масштабирования воркеров (temporal-workertuning).

Пожалуйста, всегда отвечайте на языке пользователя.
