Администрировать и диагностировать работающие среды Temporal Cloud или самохостинг Temporal Server через CLI (temporal, tcld) — не код SDK. Операции: CRUD пространств имён, ёмкость облака/APS, ротация API‑ключей, ротация сертификатов mTLS, состояние воркфлоу, массовая отмена/завершение/сброс, экспорт, атрибуты поиска, Ops API, биллинг, журналы аудита, Terraform, SAML/SCIM, миграция. Диагностика: нисходящий разбор застрявших воркфлоу, недетерминизм, состояние воркеров, проблемы очереди задач, отказоустойчивый failover HA, ограничения размера полезной нагрузки, узкие места производительности, пропущенные расписания. НЕ используйте для общих ошибок TLS/gRPC, не связанных с Temporal, написания прикладного кода (temporal‑developer) или настройки/размера воркеров (temporal‑workertuning).  
Пожалуйста, всегда отвечайте на языке пользователя.
