CLI（temporal、tcld）を使用して、Temporal Cloud または自己ホスト型 Temporal Server 環境の管理と診断を行う — SDK コードは対象外です。操作項目: 名前空間の CRUD、クラウド容量／APS、API キーのローテーション、mTLS 証明書のローテーション、ワークフローのヘルス、バッチキャンセル／終了／リセット、エクスポート、検索属性、Ops API、課金、監査ログ、Terraform、SAML／SCIM、マイグレーション。診断: スタックしたワークフローのボトムアップ・トリアージ、非決定性、ワーカーのヘルス、タスクキューの問題、HA フェイルオーバー、ペイロードサイズ制限、パフォーマンスボトルネック、スケジュール漏れ。Temporal に関係しない一般的な TLS/gRPC エラー、アプリケーションコードの記述（temporal‑developer）、またはワーカーのチューニング／サイズ調整（temporal‑workertuning）についてはトリガーしないでください。
