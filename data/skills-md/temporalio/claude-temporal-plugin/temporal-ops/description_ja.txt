CLI（temporal、tcld）を使用して、Temporal Cloud またはセルフホストの Temporal Server 環境を管理・診断する（SDK コードは対象外）。操作例：名前空間の CRUD、クラウド容量 / APS、API キーのローテーション、mTLS 証明書のローテーション、ワークフローのヘルスチェック、バッチでのキャンセル／終了／リセット、エクスポート、検索属性、Ops API、課金、監査ログ、Terraform、SAML／SCIM、マイグレーション。診断例：スタックしたワークフローのボトムアップトリアージ、非決定性、ワーカーのヘルス、タスクキューの問題、HA フェイルオーバー、ペイロードサイズ制限、パフォーマンスボトルネック、スケジュール漏れ。Temporal に関係しない一般的な TLS／gRPC エラーや、アプリケーションコードの記述（temporal‑developer）、ワーカーのチューニング／サイズ調整（temporal‑workertuning）についてはトリガーしないでください。
