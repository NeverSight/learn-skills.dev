Amministrare e diagnosticare ambienti Temporal Cloud o Temporal Server auto‑ospitati in esecuzione tramite CLI (temporal, tcld) — non codice SDK. Operazioni: CRUD dei namespace, capacità Cloud/APS, rotazione della chiave API, rotazione del certificato mTLS, salute dei workflow, annullamento/terminazione/reset in batch, esportazione, attributi di ricerca, API Ops, fatturazione, log di audit, Terraform, SAML/SCIM, migrazione. Diagnosi: triage bottom‑up di workflow bloccati, non determinismo, salute dei worker, problemi della coda di attività, failover HA, limiti di dimensione del payload, colli di bottiglia delle prestazioni, pianificazioni mancate. NON attivare per errori generici TLS/gRPC non correlati a Temporal, scrittura di codice applicativo (temporal-developer) o ottimizzazione/dimensionamento dei worker (temporal-workertuning).
