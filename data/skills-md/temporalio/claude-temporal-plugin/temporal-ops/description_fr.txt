Administrer et diagnostiquer les environnements Temporal Cloud ou serveurs Temporal auto‑hébergés en cours d’exécution via la CLI (temporal, tcld) — pas de code SDK.  

Opérations : CRUD de l’espace de noms, capacité Cloud/APS, rotation des clés API, rotation des certificats mTLS, santé des workflows, annulation/termination/réinitialisation en lot, exportation, attributs de recherche, API Ops, facturation, journaux d’audit, Terraform, SAML/SCIM, migration.  

Diagnostic : triage du bas vers le haut des workflows bloqués, non‑déterminisme, santé des workers, problèmes de file d’attente de tâches, basculement HA, limites de taille de charge utile, goulets de performance, horaires manqués.  

Ne PAS déclencher pour des erreurs TLS/gRPC génériques sans lien avec Temporal, l’écriture de code applicatif (temporal‑developer) ou l’ajustement/dimensionnement des workers (temporal‑workertuning).
