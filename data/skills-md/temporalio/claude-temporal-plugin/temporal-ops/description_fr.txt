Administrer et diagnostiquer les environnements Temporal Cloud ou Temporal Server auto‑hébergés en cours d’exécution via CLI (temporal, tcld) — pas de code SDK. Opérations : CRUD de namespace, capacité Cloud/APS, rotation de clé API, rotation de certificat mTLS, santé des workflows, annulation/termination/réinitialisation par lot, exportation, attributs de recherche, API Ops, facturation, journaux d’audit, Terraform, SAML/SCIM, migration. Diagnostic : triage bottom‑up des workflows bloqués, non‑déterminisme, santé des workers, problèmes de file d’attente de tâches, bascule HA, limites de taille de payload, goulots d’étranglement de performance, plannings manqués. Ne PAS déclencher pour des erreurs génériques TLS/gRPC non liées à Temporal, écriture de code d’application (temporal-developer), ou réglage/redimensionnement des workers (temporal-workertuning).
