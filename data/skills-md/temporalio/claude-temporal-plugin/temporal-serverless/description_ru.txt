Разверните и эксплуатируйте Temporal Workers на безсерверных вычислениях (AWS Lambda), управляемых экземпляром Worker Controller Instance (WCI). Используйте, когда пользователь упоминает: «serverless worker», «Temporal serverless», «Worker Controller Instance», «WCI», «deploy Temporal worker on Lambda», «Lambda packaging», «Lambda timeout», «WCI inspection», «CloudFormation Temporal».
