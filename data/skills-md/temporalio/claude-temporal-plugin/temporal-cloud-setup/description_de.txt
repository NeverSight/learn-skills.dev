Temporal Cloud einrichten und für den Nutzer einen Beispiel‑Workflow darauf ausführen, die Arbeit von Anfang bis Ende erledigen. Verwenden Sie dies, wenn der Nutzer Temporal Cloud einrichten, mit Temporal Cloud beginnen, die einheitliche Temporal‑CLI (Vorabversion cloud-cli) installieren, einen Cloud‑Namespace oder API‑Schlüssel erstellen, eine Geld‑Transfer‑Beispiel‑App klonen, die Client‑Konfigurations‑TOML schreiben oder einen lokalen Worker mit Temporal Cloud verbinden und einen Beispiel‑Workflow ausführen möchte. Dies ist der Cloud‑Einrichtungs‑Pfad, nicht der lokale Lernpfad (siehe temporal-getting-started). Deckt die SDKs für Python, TypeScript, Go, Java, .NET und Ruby ab.
