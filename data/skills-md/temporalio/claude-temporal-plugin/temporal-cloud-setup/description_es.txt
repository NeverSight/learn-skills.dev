Configura Temporal Cloud y ejecuta un flujo de trabajo de muestra en él para el usuario, realizando el trabajo de extremo a extremo. Úsalo cuando el usuario quiera configurar Temporal Cloud, iniciarse en Temporal Cloud, instalar el CLI unificado de Temporal (prerelease cloud-cli), crear un espacio de nombres en la nube o una clave API, clonar una aplicación de ejemplo de transferencia de dinero, escribir el archivo de configuración del cliente TOML, o conectar un Worker local a Temporal Cloud y ejecutar un flujo de trabajo de muestra. Esta es la ruta de configuración en la nube, no la ruta de aprendizaje local (ver temporal-getting-started). Cubre los SDK de Python, TypeScript, Go, Java, .NET y Ruby.
