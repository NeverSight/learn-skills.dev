Configurez Temporal Cloud et exécutez un flux de travail d'exemple dessus pour l'utilisateur, en effectuant le travail de bout en bout. À utiliser lorsque l'utilisateur souhaite configurer Temporal Cloud, démarrer sur Temporal Cloud, installer le CLI unifié de Temporal (préversion cloud‑cli), créer un espace de noms Cloud ou une clé API, cloner une application d'exemple de transfert d'argent, écrire le fichier de configuration client TOML, ou connecter un Worker local à Temporal Cloud et exécuter un flux de travail d'exemple. Il s'agit du chemin d'installation Cloud, et non du chemin d'apprentissage local (voir temporal‑getting‑started). Couvre les SDK Python, TypeScript, Go, Java, .NET et Ruby.
