Temporal Cloud를 설정하고 사용자를 위해 샘플 워크플로를 실행하여 작업을 처음부터 끝까지 수행합니다. 사용자가 Temporal Cloud를 설정하고, Temporal Cloud를 시작하고, 통합 Temporal CLI(prerelease cloud-cli)를 설치하고, Cloud 네임스페이스 또는 API 키를 생성하고, money‑transfer 샘플 앱을 복제하고, 클라이언트 구성 TOML을 작성하거나, 로컬 워커를 Temporal Cloud에 연결하여 샘플 워크플로를 실행하려는 경우에 사용합니다. 이는 로컬 학습 경로가 아닌 Cloud 설정 경로입니다(temporal‑getting‑started 참조). Python, TypeScript, Go, Java, .NET 및 Ruby SDK를 다룹니다.
