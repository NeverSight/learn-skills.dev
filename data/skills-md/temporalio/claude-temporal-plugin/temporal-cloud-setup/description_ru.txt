Настройте Temporal Cloud и выполните на нём пример рабочего процесса для пользователя, выполнив всю работу от начала до конца. Используйте, когда пользователь хочет настроить Temporal Cloud, начать работу с Temporal Cloud, установить унифицированный Temporal CLI (prerelease cloud-cli), создать пространство имён в облаке или API‑ключ, клонировать пример приложения money‑transfer, написать конфигурационный TOML клиента или подключить локального Worker к Temporal Cloud и запустить пример рабочего процесса. Это путь настройки облака, а не локальный путь обучения (см. temporal‑getting‑started). Охватываются SDK для Python, TypeScript, Go, Java, .NET и Ruby.
