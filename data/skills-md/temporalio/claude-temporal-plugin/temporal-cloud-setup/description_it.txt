Configura Temporal Cloud ed esegui un workflow di esempio su di esso per l'utente, completando il lavoro dall'inizio alla fine. Utilizza quando l'utente desidera configurare Temporal Cloud, iniziare su Temporal Cloud, installare la CLI unificata di Temporal (pre‑release cloud-cli), creare un namespace Cloud o una chiave API, clonare un'app di esempio per il trasferimento di denaro, scrivere il file di configurazione client TOML, oppure collegare un worker locale a Temporal Cloud ed eseguire un workflow di esempio. Questo è il percorso di configurazione Cloud, non il percorso di apprendimento locale (vedi temporal-getting-started). Copre gli SDK per Python, TypeScript, Go, Java, .NET e Ruby.
