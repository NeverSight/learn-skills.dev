Temporal Cloud をセットアップし、サンプル Workflow をユーザーのためにエンドツーエンドで実行します。Temporal Cloud のセットアップ、Temporal Cloud の開始、統合 Temporal CLI（プレリリース版 cloud-cli）のインストール、Cloud ネームスペースまたは API キーの作成、money‑transfer サンプルアプリのクローン、クライアント設定 TOML の作成、またはローカル Worker を Temporal Cloud に接続してサンプル Workflow を実行したい場合に使用します。これはローカル学習パスではなく Cloud 設定パスです（temporal‑getting‑started を参照）。Python、TypeScript、Go、Java、.NET、Ruby SDK をカバーします。
