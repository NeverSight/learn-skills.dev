Worker Controller Instance（WCI）によって駆動されるサーバーレスコンピュート（AWS Lambda、GCP Cloud Run）上で Temporal ワーカーをデプロイおよび運用します。ユーザーが以下の語句を言及したときに使用してください：「serverless worker」「Temporal serverless」「Worker Controller Instance」「WCI」「deploy Temporal worker on Lambda」「Lambda packaging」「Lambda timeout」「WCI inspection」「CloudFormation Temporal」「Cloud Run worker」「deploy Temporal worker on Cloud Run」。
