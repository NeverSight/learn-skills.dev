In Spring‑Projekten orchestrieren Sie mehrstufige Geschäftsabläufe mithilfe des Processor + Context + Handler‑Musters, indem Sie einen langen Prozess in geordnete Handler zerlegen und Zwischenergebnisse über den Context zwischen den Schritten weitergeben. Verwenden Sie diesen Ansatz, wenn Sie Schreibvorgänge hinzufügen oder refaktorisieren müssen, die aus mehreren unabhängig beschriebenen Schritten bestehen, oder um die Schritte und die Reihenfolge eines vorhandenen Processor‑Workflows anzupassen.
