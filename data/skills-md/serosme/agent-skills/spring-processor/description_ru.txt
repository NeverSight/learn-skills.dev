В проектах Spring организуйте многошаговые бизнес‑операции, используя шаблон Processor + Context + Handler, разбивая длительные процессы на упорядоченные обработчики и передавая промежуточные результаты между шагами через Context. Применяйте этот подход, когда необходимо добавить или рефакторить операции записи, состоящие из нескольких независимо описываемых шагов, либо когда требуется изменить шаги и их порядок в существующем потоке Processor.
