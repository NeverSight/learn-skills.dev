Dopo aver modificato o aggiunto un file Markdown, utilizza markdownlint-cli2 installato localmente per verificare il formato e tentare correzioni automatiche, segnalando eventuali problemi che non possono essere risolti singolarmente. Usa questo quando modifichi file .md, hai bisogno di verificare la formattazione Markdown o di validare i documenti prima del commit.

Per favore, rispondi sempre nella lingua dell'utente.
