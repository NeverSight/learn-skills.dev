Après avoir modifié ou ajouté des fichiers Markdown, utilisez markdownlint-cli2 installé localement pour vérifier le formatage et tenter des corrections automatiques, en signalant tout problème qui ne peut pas être résolu individuellement. Utilisez cela lorsque vous éditez des fichiers .md, que vous devez vérifier le format Markdown ou valider la documentation avant de valider.
