Orquestación de agentes multi‑modelo usando agentes especializados para planificación, codificación, investigación, matemáticas/ciencia, análisis visual y revisión adversarial. Utilízalo cuando las tareas sean lo suficientemente complejas como para aprovechar las fortalezas de diferentes modelos, cuando quieras una revisión adversarial para detectar puntos ciegos, o al coordinar flujos de trabajo de varios pasos entre roles de agentes. Se activa en proyectos complejos, tareas de varios pasos, decisiones de arquitectura o cuando se solicite explícitamente.
