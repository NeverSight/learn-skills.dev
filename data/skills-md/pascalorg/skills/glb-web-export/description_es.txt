Audita un .glb o .gltf y hazlo pequeño, correcto y rápido de cargar en un navegador, con un informe medido antes/después. Úsalo cuando un modelo sea “demasiado grande” o “lento de cargar”, cuando el usuario pida “optimizar este GLB”, “comprimir este glTF” o “exportar para web”, o cuando mencionen Draco, meshopt, gltfpack, KTX2, Basis, VRAM de texturas, draw calls o una exportación de Blender / CAD / fotogrametría / Pascal dirigida a Three.js, React Three Fiber (drei useGLTF), Babylon.js o model‑viewer. Cubre inspección, validación de especificación, compresión de geometría y texturas, limpieza del grafo de escena y las verificaciones de corrección (metros, Y‑up, nombres de nodos, animaciones, fidelidad PBR, modos alfa, colores de vértice) que no deben regredir. No es para editar o modelar geometría, crear o disponer una escena, generar 3D a partir de texto o imágenes, convertir de FBX/OBJ/CAD o depurar la velocidad de fotogramas en tiempo de ejecución que no tenga relación con el tamaño del activo.
