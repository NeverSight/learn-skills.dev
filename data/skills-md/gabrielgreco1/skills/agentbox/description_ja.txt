ウェブスクレイピングサブエージェントをサブエージェントごとに1つずつ、隔離された Docker サンドボックス内で実行します。各ボックスにはターミナル（curl、python）、永続的なヘッドレス Chromium、すべての HTTP 呼び出しを記録する受動的リクエストリスナー、そしてハード予算とリクエストごとの既知コストを持つオプションのプロキシが備わっています。タスクが複数のサブエージェントに分散してウェブサイトを閲覧・スクレイピングしたり、ページ背後の隠れた API エンドポイントを発見したり、データソースを検証したり、クローラーを構築したりする必要があり、あらゆるリクエストとエージェントのステップをログに残して監査可能にしたいときに使用してください。
