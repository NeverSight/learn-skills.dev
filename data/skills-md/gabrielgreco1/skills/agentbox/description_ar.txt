شغّل وكلاء فرعيين لتجريف الويب داخل حاويات Docker معزولة، حاوية واحدة لكل وكيل فرعي. كل حاوية تحتوي على طرفية (curl، python)، ومتصفح Chromium بلا رأس مستمر، ومستمعات طلبات سلبية تسجل كل نداء HTTP، وخيار بروكسي اختياري بميزانية ثابتة وتكلفة معروفة لكل طلب. استخدمها عندما تتفرّع مهمة إلى عدة وكلاء فرعيين يجب عليهم تصفح أو تجريف المواقع، العثور على نقاط API مخفية خلف الصفحات، التحقق من صحة مصادر البيانات أو بناء الزاحفين، وتحتاج إلى تسجيل كل طلب وكل خطوة للوكيل لتكون قابلة للتدقيق.
