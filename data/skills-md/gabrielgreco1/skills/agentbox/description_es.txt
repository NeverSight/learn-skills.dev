Ejecute subagentes de web‑scraping dentro de contenedores Docker aislados, una caja por subagente. Cada caja dispone de una terminal (curl, python), un Chromium headless persistente, escuchas pasivas de peticiones que registran cada llamada HTTP y un proxy opcional con un presupuesto estricto y costo conocido por solicitud. Úselo cuando una tarea se ramifique en varios subagentes que deban navegar o raspar sitios web, encontrar puntos finales de API ocultos tras páginas, validar fuentes de datos o crear rastreadores, y necesite que cada petición y cada paso del agente queden registrados y auditables.
