Run web-scraping subagents inside isolated Docker sandboxes, one box per subagent. Each box has a terminal (curl, python), a persistent headless Chromium, passive request listeners that log every HTTP call, and an optional proxy with a hard budget and known cost per request. Use when a task fans out to several subagents that must browse or scrape websites, find hidden API endpoints behind pages, validate data sources or build crawlers, and you need every request and every agent step logged and auditable.
