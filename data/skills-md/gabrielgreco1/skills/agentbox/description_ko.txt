웹 스크래핑 서브에이전트를 격리된 Docker 샌드박스 내에서 실행합니다. 서브에이전트당 하나의 박스를 사용합니다. 각 박스에는 터미널(curl, python), 지속적인 헤드리스 Chromium, 모든 HTTP 호출을 기록하는 수동 요청 리스너, 그리고 요청당 비용이 알려진 하드 예산의 선택적 프록시가 포함됩니다. 작업이 여러 서브에이전트로 분산되어 웹을 탐색하거나 스크래핑하고, 페이지 뒤에 숨겨진 API 엔드포인트를 찾으며, 데이터 소스를 검증하거나 크롤러를 구축해야 할 때, 모든 요청과 모든 에이전트 단계가 기록되고 감사 가능하도록 사용합니다.
