专家数据提取指南。首先进行结构化的需求收集，以了解目标。始终优先尝试成本最低的路径（HTTP 请求 → 浏览器指纹 → 无头浏览器）。涵盖 TLS/HTTP 指纹冒充（curl_cffi、primp、rnet），现代隐身浏览器技术栈（patchright、camoufox、nodriver），反机器人供应商矩阵（Cloudflare、DataDome、Kasada、Akamai）及其针对性绕过，CAPTCHA/Turnstile 验证破解，代理网络和托管解封服务（Zyte API、Web Unlocker）并支持地理定位，结构化数据提取（JSON‑LD、microdata、OpenGraph），AI/大语言模型驱动的自适应提取（scrapling、crawl4ai、firecrawl），站点技术栈攻略（Next.js App Router/RSC、Tableau、OData、PX‑Web、SDMX、ASP.NET、GraphQL、SPA），浏览器请求注入，实时请求拦截，以及面向对象的清晰架构标准，用于爬虫和提取数据。用户在需要从网站或 API 抓取/提取数据时均可使用。
