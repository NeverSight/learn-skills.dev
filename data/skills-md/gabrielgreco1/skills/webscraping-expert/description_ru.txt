Экспертное руководство по извлечению данных. Начинается со структурированного сбора информации, чтобы понять цель. Всегда пытается сначала самый дешёвый путь (HTTP‑запросы → отпечаток браузера → безголовый браузер). Охватывает подделку отпечатков TLS/HTTP (curl_cffi, primp, rnet), современный стек скрытных браузеров (patchright, camoufox, nodriver), матрицу анти‑бот провайдеров (Cloudflare, DataDome, Kasada, Akamai) с обходом для каждого провайдера, решение CAPTCHA/Turnstile, сети прокси и управляемые разблокировщики (Zyte API, Web Unlocker) с гео‑таргетингом, извлечение структурированных данных (JSON‑LD/microdata/OpenGraph), извлечение, управляемое ИИ/LLM и адаптивное (scrapling, crawl4ai, firecrawl), плейбуки для стека сайта (Next.js App Router/RSC, Tableau, OData, PX‑Web, SDMX, ASP.NET, GraphQL, SPA), внедрение запросов браузера, перехват живых запросов и чистые стандарты ООП‑архитектуры для скрейперов и извлечённых данных. Использовать каждый раз, когда пользователь хочет скрейпить/извлекать данные с веб‑сайта или API.
