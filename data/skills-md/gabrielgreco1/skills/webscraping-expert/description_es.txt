Guía experta de extracción de datos. Comienza con una recopilación estructurada para entender el objetivo. Siempre intenta la ruta más económica primero (solicitudes HTTP → huellas digitales del navegador → navegador sin cabeza). Cubre la suplantación de huellas TLS/HTTP (curl_cffi, primp, rnet), la pila moderna de navegadores furtivos (patchright, camoufox, nodriver), la matriz de proveedores anti‑bot (Cloudflare, DataDome, Kasada, Akamai) con evasión por proveedor, resolución de CAPTCHA/Turnstile, redes de proxies y desbloqueadores gestionados (Zyte API, Web Unlocker) con geo‑segmentación, extracción de datos estructurados (JSON‑LD/microdata/OpenGraph), extracción adaptativa impulsada por IA/LLM (scrapling, crawl4ai, firecrawl), guías de pila de sitio (Next.js App Router/RSC, Tableau, OData, PX‑Web, SDMX, ASP.NET, GraphQL, SPA), inyección de solicitudes del navegador, interceptación de solicitudes en tiempo real y estándares de arquitectura OOP limpios para scrapers y datos extraídos. Utilízalo siempre que el usuario desee raspar o extraer datos de un sitio web o API.
