Audit et améliore la qualité d’un dépôt GitHub — structure du README, fichiers de santé communautaire, configuration du répertoire .github, modèles d’issues/PR, métadonnées, releases et hygiène des branches. Utilisez cette compétence chaque fois que l’utilisateur demande d’améliorer, d’auditer, de réviser ou de configurer un dépôt GitHub, ou lorsqu’il mentionne des expressions telles que « rendre mon dépôt professionnel », « ajouter des consignes de contribution », « configurer des modèles d’issues », « améliorer mon README », « nettoyer mon dépôt », « préparer mon dépôt pour l’open source », ou « donner une bonne apparence à mon projet GitHub ». Activez‑la également lorsqu’on travaille dans un dépôt git et que l’utilisateur interroge sur les bonnes pratiques de documentation, de fichiers communautaires ou de structure de dépôt. Si l’utilisateur se trouve dans un répertoire de dépôt et mentionne README, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, LICENSE, .github, modèles ou tags de release, utilisez cette compétence.

Veuillez toujours répondre dans la langue de l’utilisateur.
