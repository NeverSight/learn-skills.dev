Verifica e migliora la qualità del repository GitHub — struttura del README, file di salute della community, configurazione della directory .github, template per issue/PR, metadati, rilasci e igiene dei rami. Usa questa competenza ogni volta che l'utente chiede di migliorare, auditare, revisionare o configurare un repository GitHub, o quando menziona cose come “rendi il mio repo professionale”, “aggiungi linee guida per i contributi”, “configura i template per le issue”, “migliora il mio README”, “pulisci il mio repo”, “prepara il mio repo per l'open source” o “rendi il mio progetto GitHub bello”. Attiva anche quando si lavora all'interno di un repository git e l'utente chiede le migliori pratiche per la documentazione, i file della community o la struttura del repository. Se l'utente è in una directory di repo e menziona README, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, LICENSE, .github, template o tag di rilascio, utilizza questa competenza. Rispondi sempre nella lingua dell'utente.
