Аудитирует и улучшает качество репозитория GitHub — структуру README, файлы здоровья сообщества, настройку каталога .github, шаблоны issue/PR, метаданные, релизы и чистоту веток. Используйте этот навык всякий раз, когда пользователь просит улучшить, проаудировать, проверить или настроить репозиторий GitHub, а также когда он упоминает такие фразы, как «make my repo look professional», «add contributing guidelines», «set up issue templates», «improve my README», «clean up my repo», «prepare my repo for open source» или «make my GitHub project look good». Также активируйте навык при работе внутри git‑репозитория, когда пользователь задаёт вопросы о лучших практиках документации, файлов сообщества или структуры репозитория. Если пользователь находится в директории репозитория и упоминает README, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, LICENSE, .github, шаблоны или теги релизов, используйте этот навык.
