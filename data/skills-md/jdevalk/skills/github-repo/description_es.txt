Audita y mejora la calidad del repositorio de GitHub — estructura del README, archivos de salud de la comunidad, configuración del directorio .github, plantillas de issues/PR, metadatos, lanzamientos y higiene de ramas. Usa esta habilidad siempre que el usuario pida mejorar, auditar, revisar o configurar un repositorio de GitHub, o cuando mencione cosas como “haz que mi repo se vea profesional”, “añade guías de contribución”, “configura plantillas de issues”, “mejora mi README”, “limpia mi repo”, “prepara mi repo para código abierto” o “haz que mi proyecto de GitHub luzca bien”. También actívala al trabajar dentro de un repositorio git y que el usuario pregunte sobre mejores prácticas para documentación, archivos de la comunidad o estructura del repositorio. Si el usuario está en un directorio de repositorio y menciona README, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, LICENSE, .github, plantillas o etiquetas de lanzamiento, usa esta habilidad.

Por favor, siempre responde en el idioma del usuario.
