Backport de seguridad de Chrome de extremo a extremo para una rama de lanzamiento de Electron. Dada una URL del blog de lanzamientos de Chrome y una rama (por ejemplo, 41-x-y), determina qué correcciones de CVE faltan en la *fuente sincronizada real*, escribe los parches seleccionados localmente, los valida con `e sync --3` + `lint --patches` y luego envía un único PR. Úselo cuando se le solicite realizar un backport de una versión de seguridad de Chrome a N-x-y, "¿CVE-X ya está en N-x-y?", o para producir/validar el conjunto de selección para una rama de versión.
