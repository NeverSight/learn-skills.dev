Rétroportage de sécurité Chrome de bout en bout pour une branche de version Electron. Étant donné l'URL du blog Chrome Releases et une branche (par exemple 41-x-y), détermine quels correctifs CVE manquent dans la *source synchronisée réelle*, écrit localement les correctifs sélectionnés, les valide avec `e sync --3` + `lint --patches`, puis envoie un seul PR. À utiliser lorsqu'il est demandé de rétroporter une version de sécurité de Chrome vers N-x-y, "CVE-X est-il déjà dans N-x-y ?", ou pour produire/valider l'ensemble de sélection pour une branche de version.
