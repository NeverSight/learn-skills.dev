Backport di sicurezza end-to-end di Chrome per un ramo di rilascio di Electron. Dato l'URL del blog delle versioni Chrome e un ramo (ad esempio 41-x-y), determina quali correzioni CVE mancano dalla *fonte sincronizzata effettiva*, scrive localmente le patch selezionate, le convalida con `e sync --3` + `lint --patches`, quindi invia un singolo PR. Da utilizzare quando viene richiesto di eseguire il backport di una versione di sicurezza di Chrome su N-x-y, "CVE-X è già in N-x-y?" o ​​per produrre/convalidare il set di selezione per un ramo di versione.
