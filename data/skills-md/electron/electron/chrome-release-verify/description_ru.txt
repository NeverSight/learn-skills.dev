Комплексная поддержка безопасности Chrome для ветки выпуска Electron. Учитывая URL-адрес блога Chrome Releases и ветку (например, 41-x-y), определяет, какие исправления CVE отсутствуют в *фактическом синхронизированном источнике*, записывает выбранные патчи локально, проверяет их с помощью `e sync --3` + `lint --patches`, затем отправляет один PR. Используйте, когда вас попросят перенести версию безопасности Chrome в N-x-y, «CVE-X уже есть в N-x-y?» или для создания/проверки отборочного набора для ветки выпуска.
