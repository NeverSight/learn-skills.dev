Electron リリース ブランチのエンドツーエンドの Chrome セキュリティ バックポート。 Chrome リリース ブログの URL とブランチ (例: 41-x-y) を指定すると、*実際の同期ソース* からどの CVE 修正が欠落しているかを判断し、チェリーピック パッチをローカルに書き込み、それらを `e sync --3` + `lint --patches` で検証し、単一の PR をプッシュします。 Chrome セキュリティ リリースを N-x-y にバックポートするように求められた場合、「CVE-X はすでに N-x-y にありますか?」、またはリリース ブランチのチェリーピック セットを生成/検証するために使用します。
