Electron 릴리스 분기를 위한 엔드투엔드 Chrome 보안 백포트입니다. Chrome 릴리스 블로그 URL과 분기(예: 41-x-y)가 주어지면 *실제 동기화 소스*에서 누락된 CVE 수정 사항을 확인하고, 체리 선택 패치를 로컬로 작성하고, `e sync --3` + `lint --patches`를 사용하여 유효성을 검사한 다음 단일 PR을 푸시합니다. Chrome 보안 릴리스를 N-x-y로 백포트하라는 요청을 받거나 "CVE-X가 이미 N-x-y에 있습니까?" 또는 릴리스 분기에 대한 체리 선택 세트를 생성/검증하라는 요청을 받을 때 사용합니다.
