Руководство по обновлению версии Node.js в проекте Electron. Используйте при работе с веткойroller/node/main для исправления конфликтов патчей во время `e sync --3`. Охватывает рабочий процесс приложения исправлений, разрешение конфликтов, анализ исходных изменений Node.js, сборку, запуск набора тестов Node.js и правильное форматирование фиксации для исправлений исправлений.
