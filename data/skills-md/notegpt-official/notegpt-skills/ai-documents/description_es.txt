Crea, edita o mejora documentos según los requisitos del usuario, generando siempre un archivo. Si no se especifica ningún formato, el valor predeterminado es un archivo Markdown (.md). Palabras clave de activación: crear documento, redactar documento, editar documento, mejorar documento, generar documento, crear un documento, redactar un informe, borrador de documento, reescribir documento. Actívalo cuando el usuario pida crear, revisar o pulir un documento y quiera obtener un archivo.
