Analysieren Sie die Daten des Benutzers und erstellen Sie leicht verständliche visuelle Insight-Berichte mit professionellen Diagrammen, wobei immer eine Datei erstellt wird. Wenn kein Format angegeben ist, wird standardmäßig eine HTML-Datei (.html) erstellt. Trigger-Schlüsselwörter: Daten analysieren, Datenanalyse, meine Daten analysieren, Dateneinblicke, Daten visualisieren, Diagrammbericht, visueller Bericht, Bericht erstellen, Datenanalytik. Wird aktiviert, wenn der Benutzer Daten bereitstellt und um eine Analyse mit Diagrammen bittet.
