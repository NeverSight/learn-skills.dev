Analiza los datos del usuario y genera informes visuales de fácil comprensión con gráficos profesionales, creando siempre un archivo. Si no se especifica ningún formato, se genera por defecto un archivo HTML (.html). Palabras clave de activación: analizar datos, análisis de datos, analizar mis datos, información sobre datos, visualizar datos, informe con gráficos, informe visual, generar un informe, analítica de datos. Activar cuando el usuario proporcione datos y solicite un análisis con gráficos.
