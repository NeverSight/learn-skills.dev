Analysez les données de l'utilisateur et générez des rapports d'analyse visuels faciles à comprendre, avec des graphiques professionnels, en produisant toujours un fichier. Par défaut, un fichier HTML (.html) est généré lorsqu'aucun format n'est spécifié. Mots-clés de déclenchement : analyser les données, analyse des données, analyser mes données, informations sur les données, visualiser les données, rapport sous forme de graphique, rapport visuel, générer un rapport, analyse des données. Activer lorsque l'utilisateur fournit des données et demande une analyse avec des graphiques.
