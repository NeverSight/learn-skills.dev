Alibaba Java開発マニュアルのプログラミング規約で、命名スタイル、定数定義、コードフォーマット、OOP規約、日付と時間、コレクション処理、並行処理、制御文、コメント規約などを含みます。Javaコードを書くとき、コードをレビューするとき、またはAlibaba Javaコーディング標準に従うときに使用してください。ユーザーがJavaの命名規則、コードフォーマット、クラス命名、メソッド命名、変数命名、定数、コードスタイル、インデント、OOPの実践、日時処理、コレクション、HashMap、並行性、マルチスレッド、制御フロー、コメント、Javadoc、またはその他のJavaコーディングスタイルに関する質問をしたときは、たとえ『Alibaba』や『coding standards』と明示されていなくても、このスキルを必ず使用してください。また、ユーザーが自分のJavaコードがベストプラクティスに従っているか、コードレビューの指針が必要かを確認したいときにも使用してください。
