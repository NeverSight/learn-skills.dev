دليل تطوير جافا من علي بابا يتضمن قواعد البرمجة، بما يشمل أسلوب التسمية، تعريف الثوابت، تنسيق الشيفرة، قواعد البرمجة الكائنية (OOP)، التعامل مع التاريخ والوقت، معالجة المجموعات، معالجة التزامن، عبارات التحكم، قواعد التعليقات، وغيرها. استخدمها عند كتابة شيفرة جافا، مراجعة الشيفرة، أو اتباع معايير ترميز جافا الخاصة بعلي بابا. تأكد من استخدام هذه المهارة كلما سأل المستخدم عن قواعد تسمية جافا، تنسيق الشيفرة، تسمية الفئات، تسمية الدوال، تسمية المتغيرات، الثوابت، أسلوب الشيفرة، المسافات البادئة، ممارسات البرمجة الكائنية، التعامل مع التاريخ والوقت، المجموعات، HashMap، التزامن، البرمجة المتعددة الخيوط، تدفق التحكم، التعليقات، Javadoc، أو أي أسئلة حول أسلوب ترميز جافا، حتى لو لم يذكر صراحةً "علي بابا" أو "معايير الترميز". كذلك استخدمها عندما يرغب المستخدم في التحقق مما إذا كانت شيفرة جافا الخاصة به تتبع أفضل الممارسات أو يحتاج إلى إرشادات مراجعة الشيفرة.
