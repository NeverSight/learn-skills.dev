Utiliza el CLI de Obsidian para guardar conclusiones de conversaciones, resúmenes de investigación, planes o decisiones en un Wiki. Esto se aplica cuando un usuario solicita “guardar en wiki”, “archivar la discusión reciente en la base de conocimientos”, “registrar este punto de conocimiento”, “registrar este plan”, “registrar esta decisión”, o al complementar una página de Wiki existente. Si no se especifica otra ubicación de almacenamiento, dichas solicitudes de registro se tratan como guardar en el Wiki sin necesidad de mencionar explícitamente el Wiki. El sistema maneja la verificación de duplicados, revisiones de evidencia y privacidad, redacción dirigida y verificación. Las preguntas y respuestas ordinarias no se guardan automáticamente; la ingestión completa o incremental de fuentes y el lint de base de datos completa utilizan el flujo de trabajo correspondiente del repositorio de destino. Por favor, siempre responde en el idioma del usuario.
