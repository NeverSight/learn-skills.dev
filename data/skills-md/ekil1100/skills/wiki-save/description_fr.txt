Utilisez l’interface en ligne de commande d’Obsidian pour enregistrer les conclusions de conversation, les résumés de recherche, les plans ou les décisions dans un Wiki. Cela s’applique lorsqu’un utilisateur demande « enregistrer dans le wiki », « stocker la discussion récente dans la base de connaissances », « consigner ce point de connaissance », « consigner ce plan », « consigner cette décision », ou lorsqu’il ajoute à une page Wiki existante ; si aucun autre emplacement d’enregistrement n’est spécifié, ces demandes sont traitées comme un enregistrement dans le Wiki sans devoir mentionner explicitement le Wiki. Le processus gère la détection des doublons, les vérifications de preuves et de confidentialité, la rédaction ciblée et la vérification. Les questions‑réponses standards ne sont pas sauvegardées automatiquement ; l’ingestion complète ou incrémentale des sources et le linting complet de la base de données utilisent le processus correspondant pour le dépôt cible.
