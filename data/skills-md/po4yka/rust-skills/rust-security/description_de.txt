Zu verwenden, wenn du cargo-audit oder cargo-deny ausführst, deny.toml bearbeitest, einen RUSTSEC-Hinweis oder eine CVE in einer Abhängigkeit klassifizierst, eine neue oder aktualisierte Crate auf Typosquatting, bösartige Crates oder das Risiko einer kompromittierten Version überprüfst oder einen Rust-Parser absicherst, der nicht vertrauenswürdige Dateien, Archive oder Binärformate liest. Nicht für Authentifizierung, Speicherung von Geheimnissen, kryptografisches Design oder TLS-Richtlinien (TLS gehört zu rust-networking). Wird ausgelöst bei „RUSTSEC“, „Lieferkette“, „yanked“, „Path Traversal“, „Decompression Bomb“.
