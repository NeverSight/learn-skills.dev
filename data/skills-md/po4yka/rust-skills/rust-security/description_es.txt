Utilícelo cuando ejecute cargo-audit o cargo-deny, edite deny.toml, clasifique una advertencia de RUSTSEC o un CVE en una dependencia, examine una «crate» nueva o actualizada para detectar «typosquatting», «crates» maliciosas o riesgo de versiones comprometidas, o refuerce un analizador Rust que lea archivos, archivos comprimidos o formatos binarios no fiables. No es para autenticación, almacenamiento de secretos, diseño criptográfico ni política TLS (TLS pertenece a rust-networking). Se activa con «RUSTSEC», «cadena de suministro», «retirado», «recorrido de rutas», «bomba de descompresión».
