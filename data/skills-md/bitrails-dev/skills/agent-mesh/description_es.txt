Orquestador universal de malla de agentes inter‑harness que permite comunicación asincrónica, punto a punto y basada en eventos entre Claude Code, Antigravity, OpenCode, Pi, Codex y cualquier agente compatible con ACP, con visibilidad de sesiones en tiempo real, aislamiento de worktree de Git y arrendamiento de sesiones. Soporta una configuración de un solo comando mediante `mesh --init` o `mesh --install`, y eliminación limpia mediante `mesh --uninstall`. Úsalo siempre que el usuario solicite coordinar múltiples harnesses de agentes de IA, hacer que los agentes se comuniquen entre harnesses, ejecutar flujos de trabajo entre agentes, ver o adjuntar a sesiones de agentes en tiempo real, o inicializar la malla. Por favor, responde siempre en el idioma del usuario.
