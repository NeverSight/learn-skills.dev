Universal inter-harness agent mesh orchestrator enabling asynchronous, peer-to-peer, and event-driven communication across Claude Code, Antigravity, OpenCode, Pi, Codex, and any ACP-compliant agent with live session visibility, git worktree isolation, and session leasing. Supports one-command setup via `mesh --init` or `mesh --install`, and clean removal via `mesh --uninstall`. Use whenever the user asks to coordinate multiple AI agent harnesses, have agents communicate across harnesses, run cross-agent workflows, view/attach to agent sessions live, or initialize the mesh.
