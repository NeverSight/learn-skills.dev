منسق شبكة عالمي للوكيل بين الأنظمة يتيح الاتصال غير المتزامن، من نظير إلى نظير، والقائم على الأحداث عبر Claude Code، Antigravity، OpenCode، Pi، Codex، وأي وكيل متوافق مع ACP مع إمكانية رؤية الجلسات الحية، وعزل شجرة عمل git، وتأجير الجلسات. يدعم إعدادًا بأمر واحد عبر `mesh --init` أو `mesh --install`، وإزالة نظيفة عبر `mesh --uninstall`. استخدمه كلما طلب المستخدم تنسيق عدة أطر وكلاء AI، أو جعل الوكلاء يتواصلون عبر الأطر، أو تشغيل سير عمل عبر الوكلاء، أو مشاهدة/إرفاق الجلسات الحية للوكيل، أو تهيئة الشبكة.
