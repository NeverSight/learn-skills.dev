Operator guide for the installed dicos CLI: run Slurm CPU/GPU jobs on ASGC DiCOS (slurm-ui.twgrid.org) from a laptop through one 2FA SSH master. Covers install/update, first-run setup (dicos init, doctor), config.yaml, the status/run/sweep/list/show/logs/wait/stop/clean/ssh/exec/code/logout commands, git vs --sync code shipping, job states, login-ban safety, and troubleshooting. Use when submitting, monitoring, stopping or cleaning DiCOS jobs, choosing a partition or GPU count, or diagnosing failed logins, stuck queued jobs, failed submissions or lost jobs — not when developing the dicos repo itself.
