دليل المشغل لواجهة سطر الأوامر dicos المثبتة: تشغيل وظائف Slurm للمعالج المركزي/وحدة المعالجة الرسومية على ASGC DiCOS (slurm‑ui.twgrid.org) من جهاز لاب توب عبر خادم SSH واحد باستخدام المصادقة الثنائية (2FA). يغطي التثبيت/التحديث، إعداد التشغيل الأول (dicos init، doctor)، ملف config.yaml، أوامر status/run/sweep/list/show/logs/wait/stop/clean/ssh/exec/code/logout، مقارنة git بخيار --sync لنقل الشيفرة، حالات الوظائف، أمان حظر تسجيل الدخول، وحل المشكلات. يُستعمل عند تقديم، مراقبة، إيقاف أو تنظيف وظائف DiCOS، اختيار قسم أو عدد وحدات المعالجة الرسومية، أو تشخيص فشل تسجيل الدخول، الوظائف العالقة في قائمة الانتظار، فشل الإرسال أو فقدان الوظائف — وليس عند تطوير مستودع dicos نفسه.
