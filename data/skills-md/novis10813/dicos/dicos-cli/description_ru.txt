Руководство оператора для установленного CLI dicos: запуск задач Slurm CPU/GPU на ASGC DiCOS (slurm-ui.twgrid.org) с ноутбука через один мастер‑сервер SSH с двухфакторной аутентификацией. Охватывает установку/обновление, начальную настройку (dicos init, doctor), файл config.yaml, команды status/run/sweep/list/show/logs/wait/stop/clean/ssh/exec/code/logout, различия между git и передачей кода через --sync, состояния задач, меры безопасности при блокировке входа и устранение неполадок. Используйте при отправке, мониторинге, остановке или очистке задач DiCOS, выборе раздела или количества GPU, а также для диагностики неудачных входов, «зависших» задач в очереди, неуспешных отправок или потерянных задач — не для разработки самого репозитория dicos.
