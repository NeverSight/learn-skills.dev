Erstelle oder überarbeite ein kohärentes, nicht redundantes Set von KI‑Coding‑Agent‑Anweisungsdateien für ein Projekt — eine kanonische Einstiegsdatei (AGENTS.md) plus ein Regelverzeichnis, das in das Zielwerkzeug eingebunden ist (OpenCode‑opencode.json, Cursors .cursor/rules/*.mdc, CLAUDE.md oder allein AGENTS.md). Aufgebaut auf einer Bibliothek spezialisierter Regelvorlagen, die anhand des erkannten Stacks ausgewählt werden, anstatt ein komplettes Profil zu kopieren. Verwende dies, wann immer der Nutzer Regeln für ein neues Projekt bootstrappen, Regeln zu einem bestehenden Projekt hinzufügen, Regeln für einen neuen Stack neu generieren möchte oder sich darüber beschwert, dass KI‑generierte Regeldateien spaghettiartig sind — überlappend, redundant, widersprüchlich, zu vage, vom Agenten ignoriert oder in ihrer Tiefe von Datei zu Datei inkonsistent. Auch einsetzen, wenn der Nutzer fragt, wie AGENTS.md strukturiert werden soll, bestehende Konventionen eines Codebases erhalten oder migrieren will oder einen wiederholbaren Prozess statt jedes Mal von Grund auf neu zu prompten wünscht.
