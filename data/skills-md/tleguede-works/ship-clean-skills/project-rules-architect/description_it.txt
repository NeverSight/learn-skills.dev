Genera o ristruttura un insieme coerente e non ridondante di file di istruzioni per agenti IA in un progetto — un file di ingresso canonico (AGENTS.md) più una directory di regole, integrati nello strumento di destinazione (opencode.json di OpenCode, .cursor/rules/*.mdc di Cursor, CLAUDE.md o solo AGENTS.md). Costruito su una libreria di template di regole specializzate selezionati in base alla stack rilevata, non copiando un profilo completo. Usalo ogni volta che l'utente vuole avviare le regole per un nuovo progetto, aggiungere regole a uno esistente, rigenerare le regole per una nuova stack, o si lamenta che i file di regole generati dall'IA sono spaghetti — sovrapposti, ridondanti, contraddittori, troppo vaghi, ignorati dall'agente, o incoerenti nella profondità da un file all'altro. Usalo anche quando l'utente chiede come strutturare AGENTS.md, desidera preservare o migrare le convenzioni esistenti di un codebase, o vuole un processo ripetibile invece di ricominciare da capo per ogni progetto.
