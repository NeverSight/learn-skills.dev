プロジェクト向けに、統一性があり冗長性のないAIコーディングエージェント用指示ファイルのセット（正規エントリーファイル AGENTS.md とルールディレクトリ）を生成または全面的に見直す。対象ツール（OpenCode の opencode.json、Cursor の .cursor/rules/*.mdc、CLAUDE.md、または AGENTS.md のみ）に組み込む。検出されたスタックに基づき選択された専門的なルールテンプレートのライブラリから構築し、プロファイル全体をコピーするのではない。ユーザーが新規プロジェクトのルールをブートストラップしたい、既存プロジェクトにルールを追加したい、新しいスタック用にルールを再生成したい、あるいはAI生成のルールファイルがスパゲッティ状で—重複・冗長・矛盾・曖昧すぎ・エージェントに無視される・ファイル間で深さが一貫しないと不満を抱いたときに使用する。また、ユーザーが AGENTS.md の構成方法を尋ねたり、コードベースの既存の慣習を保守または移行したいと求めたり、毎回プロジェクトごとに最初から再プロンプトするのではなく、再現可能なプロセスを望む場合にも使用する。
