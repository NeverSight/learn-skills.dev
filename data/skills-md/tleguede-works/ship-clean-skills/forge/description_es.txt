Plataforma de diseño, planificación y especificación de nuevos productos de software. Convierte una idea inicial en un plan de implementación exhaustivo, sin ambigüedades, lo suficientemente preciso para ser ejecutado por una IA incluso poco potente. Cubre PRD, hoja de ruta, benchmarks, diseño UI/UX, arquitectura, desglose en slices, plan de implementación por slice, plan de pruebas, análisis de impacto y validación automática de los planes (modo Fast Track). Utilizar para cualquier proyecto nuevo (greenfield), desde la idea vaga hasta el plan listo para codificar. No usar para migrar un proyecto existente a otra pila, ni para trabajar con código legado.

— Plataforma de diseño, planificación y especificación para nuevos productos de software. Convierte una idea imprecisa en un plan de implementación exhaustivo y sin ambigüedades, lo suficientemente preciso para que un modelo de baja capacidad lo ejecute: PRD, hoja de ruta, benchmarks, diseño UI/UX, arquitectura, desglose en slices, planes de implementación por slice, plan de pruebas, análisis de impacto y validación automática del plan (modo Fast Track). Utiliza esta habilidad para cualquier proyecto greenfield, desde una idea vaga hasta un plan listo para codificar. No lo uses para migrar un proyecto existente a una pila diferente, ni para trabajar con código legado.
