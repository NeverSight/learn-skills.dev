Платформа проектирования, планирования и спецификации новых программных продуктов. Превращает начальную идею в исчерпывающий план реализации без двусмысленностей, достаточно точный, чтобы его могла выполнить даже маломощная ИИ. Охватывает PRD, дорожную карту, бенчмарки, дизайн UI/UX, архитектуру, разбиение на слайсы, план реализации по каждому слайсу, план тестов, анализ воздействия и автоматическую проверку планов (режим Fast Track). Использовать для любого нового проекта (greenfield) — от расплывчатой идеи до готового к кодированию плана. Не использовать для миграции существующего проекта на другую стек‑технологию и не использовать для работы с наследуемым (legacy) кодом. — Платформа дизайна, планирования и спецификации новых программных продуктов. Используйте этот навык для любого проекта «с нуля», от расплывчатой идеи до готового к коду плана. Не используйте его для миграции существующего проекта на другую стек‑технологию или для работы с наследуемым кодом.
