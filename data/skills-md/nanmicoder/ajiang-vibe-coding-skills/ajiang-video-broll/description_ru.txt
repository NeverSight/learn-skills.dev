Создавайте полноэкранные сегменты B‑roll / MG‑упаковки для уже смонтированных видеороликов с озвучкой (технические обзоры, обучающие ролики, демонстрации AI‑инструментов, авторские материалы на Bilibili). Вводите субтитры в формате SRT (исходное видео обычно находится в той же папке) и временные отрезки, которые нужно упаковать; выбирайте набор из десяти шаблонов (в основном бумажно‑белый с сигнально‑оранжевым, плюс стикер‑поп, чёрно‑белый мятный, тёплый туман, нотный‑обзор, перфорированная печать, постер Шова, ретро‑восходящее солнце, коллаж‑карточки, геометрия Баухауза; каждый набор имеет собственный макет, композицию, расположение анимационных эффектов, цветовую схему, звуковые эффекты и музыкальное оформление). Сначала создайте страницу‑превью на том же движке, что и финальное видео, с помощью Claude.ai (синхронная озвучка, перетаскиваемые, наложенные субтитры для проверки) для подтверждения пользователем. Затем выполните рендер в 4K с помощью Remotion, добавьте тематический фоли и фон‑музыку (на 16 дБ ниже озвучки) и сдайте файлы, названные согласно миллисекундным меткам из SRT, чтобы напрямую заменить соответствующую видеодорожку на монтажной шкале. Используйте этот процесс, когда пользователь говорит «упаковать видео / B‑roll / MG‑анимацию / AE‑эффект / Remotion‑клип / анимировать по субтитрам / изменить стиль темы».
