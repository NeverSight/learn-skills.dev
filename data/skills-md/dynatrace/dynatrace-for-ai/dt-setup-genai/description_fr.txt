Processus de décision indépendant du framework pour instrumenter une application GenAI/LLM (Python ou TypeScript, n'importe quel SDK fournisseur/agent) afin qu'elle émette des spans OTel selon la convention sémantique GenAI (gen_ai.*) interrogeables dans Dynatrace. Quatre étapes : détecter, instrumenter, enrichir, valider. Décide de l'approche requise par un SDK donné ; ne remplace pas les recettes concrètes spécifiques à chaque framework dans dynatrace-oss/dynatrace-ai-agent-instrumentation-examples. Déclencheurs : « instrumenter cette application GenAI », « ajouter du tracing à cette application LLM », « comment obtenir des spans gen_ai dans Dynatrace », « intégrer cette application agent à l'Observabilité IA ». NE PAS utiliser pour analyser la télémétrie d'une application déjà instrumentée (utilisez dt-obs-genai) ou pour des langages autres que Python/TypeScript.
