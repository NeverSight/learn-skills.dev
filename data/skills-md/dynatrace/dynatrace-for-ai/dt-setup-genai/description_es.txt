Proceso de decisión independiente del framework para instrumentar una aplicación GenAI/LLM (Python o TypeScript, cualquier SDK de proveedor/agente) de modo que emita spans con la convención semántica OTel GenAI (gen_ai.*) consultables en Dynatrace. Cuatro pasos: detectar, instrumentar, enriquecer, validar. Decide qué enfoque necesita un SDK concreto; no reemplaza las recetas específicas por framework en dynatrace-oss/dynatrace-ai-agent-instrumentation-examples. Activador: "instrumenta esta aplicación GenAI", "agrega trazas a esta aplicación LLM", "¿cómo consigo que los spans gen_ai lleguen a Dynatrace?", "incorpora esta aplicación de agente a la Observabilidad de IA". NO lo use para analizar telemetría de una aplicación ya instrumentada (use dt-obs-genai) ni para lenguajes distintos de Python/TypeScript.
