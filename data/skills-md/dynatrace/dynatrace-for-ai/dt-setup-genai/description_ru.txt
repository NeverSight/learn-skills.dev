Независимый от фреймворка процесс принятия решений по инструментации приложения GenAI/LLM (Python или TypeScript, любой SDK провайдера/агента), чтобы оно генерировало спаны OTel GenAI по семантической конвенции (gen_ai.*), доступные для запросов в Dynatrace. Четыре шага: обнаружить, инструментарировать, обогатить, проверить. Определяет, какой подход нужен конкретному SDK; не заменяет конкретные рецепты для каждого фреймворка в репозитории dynatrace-oss/dynatrace-ai-agent-instrumentation-examples. Триггеры: «инструментировать это приложение GenAI», «добавить трассировку в это приложение LLM», «как получить спаны gen_ai в Dynatrace», «подключить это приложение‑агент к AI Observability». НЕ использовать для анализа телеметрии уже инструментаризированного приложения (используйте dt-obs-genai) или для языков, отличных от Python/TypeScript.
