Guide les utilisateurs à travers la mise à niveau de Dynatrace de la version classic/2e génération vers la 3e génération. Évalue la maturité du tenant, exécute des requêtes de suivi, identifie les actions de migration pour les tableaux de bord, les requêtes d’entité, IAM, les zones de gestion, OpenPipeline, la détection de services, les logs, K8s, RUM, le synthetic et l’alerting. Comprend la migration de l’intégration cloud (AWS, Azure, GCP) du classic vers le nouveau (Smartscape sur Grail) : découverte des connexions, cartographie des métriques et bascule. Mots‑clés : upgrade, migrate, classic, gen3, phase2, phase3, readiness, cloud integration, AWS, Azure, GCP, classic connection, new connection, Smartscape on Grail, fleet management, Site Reliability Guardian (SRG), classic pipeline, log processing pipeline, bizevents pipeline, pipeline upgrade, classic processing rules, ActiveGate, authToken, auth token, DynaKube, dynatrace-operator, classicFullStack, Platform token, enable RUM on Grail, RUM migration, mobile RUM, web RUM, Experience Vitals.
