Connaissances de référence pour installer, désinstaller ou créer‑et‑installer Dynatrace OneAgent sur VM/serveur, Kubernetes (Operator + DynaKube), AWS Lambda (layer + variables d’environnement, plus option de provisionnement d’une nouvelle fonction), hôtes Windows, hôtes Linux distants / instances EC2 via SSH, et machines Azure VM / ensembles d’échelle VM. Retourne les points de terminaison documentés, les variables d’environnement, les étendues de jeton, ainsi que des commandes prêtes à copier‑coller. Retourne les commandes exactes à exécuter plutôt que de les exécuter. À utiliser lorsque l’utilisateur demande d’installer ou de désinstaller OneAgent, ou pose « comment faire… », « quelle URL/étendue/variable me faut‑il pour… » ou « expliquer le déploiement de OneAgent pour X ».
