Enlaces de Zig para la biblioteca multimedia SDL3. Uso para desarrollo de juegos multiplataforma, gráficos, audio, manejo de entrada. Cubre ventanas, renderizado, computación GPU, eventos, gamepads, flujos de audio, redes. Destaca patrones específicos de Zig como el manejo de errores con try/catch, defer para la limpieza, integración de asignador personalizado, envoltorios de callbacks y conversiones de tipos fromSdl/toSdl.
