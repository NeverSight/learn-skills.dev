Liens Zig pour la bibliothèque multimédia SDL3. Utilisés pour le développement de jeux multiplateforme, les graphiques, l’audio, la gestion des entrées. Couvre la gestion des fenêtres, le rendu, le calcul GPU, les événements, les manettes, les flux audio, le réseau. Met l’accent sur les modèles spécifiques à Zig tels que la gestion des erreurs avec try/catch, defer pour le nettoyage, l’intégration d’un allocateur personnalisé, les wrappers de rappel et les conversions de type fromSdl/toSdl.
