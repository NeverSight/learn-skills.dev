Utilisez Codeguard pour exécuter et diagnostiquer la vérification des normes de code pour les projets Java ; employez‑le lorsque les utilisateurs demandent du linting, des vérifications de format, des corrections automatiques, une validation de qualité pré‑commit ou lorsqu’il y a des échecs liés à `mvn -q javadoc:jar -DskipTests`. Commencez par confirmer la configuration du dépôt et la disponibilité de l’outil, distinguez les cas réussis, échoués, non vérifiables et planifiés ; après correction, le processus doit être relancé.

Veuillez toujours répondre dans la langue de l’utilisateur.
