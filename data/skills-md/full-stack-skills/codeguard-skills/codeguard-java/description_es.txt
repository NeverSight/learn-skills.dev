Utiliza Codeguard para ejecutar y diagnosticar la puerta de estilo de código para proyectos Java; úsalo cuando el usuario solicite linting, verificaciones de formato, correcciones automáticas, verificación de calidad pre‑commit, o cuando ocurran fallos relacionados con `mvn -q javadoc:jar -DskipTests`. Primero confirma la configuración del repositorio y la disponibilidad de la herramienta, diferencia entre los estados aprobado, fallido, no verificable y planificado, y después de corregir, el proceso debe ejecutarse de nuevo.

Por favor, responde siempre en el idioma del usuario.
