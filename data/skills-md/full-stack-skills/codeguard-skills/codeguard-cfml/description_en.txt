Use Codeguard to execute and diagnose code standard gatekeeping for CFML (ColdFusion) projects; use it when the user requests linting, format checks, automatic fixes, pre‑commit quality verification, or when a cflint '{file}'‑related failure occurs. First confirm repository configuration and tool availability, differentiate between passed, failed, unable to verify, and planned, and after fixing, it must be re‑run.
