Redigi e valida i messaggi di commit secondo lo stile Conventional Commits, Gitmoji o Udacity, basandoti sui diff in staging e sulla cronologia del repository; usa questo quando l'utente vuole scrivere un messaggio di commit, eseguire git commit, configurare commitlint o chiedere informazioni sulle convenzioni dei commit. Non inventare modifiche senza una conversazione e non aggirare il controllo con --no-verify.

Rispondi sempre nella lingua dell'utente.
