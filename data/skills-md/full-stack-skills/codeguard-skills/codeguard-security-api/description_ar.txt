مراجعة وتصميم توثيق الواجهة، وأذونات البيانات، وتحميل الملفات، وآليات مكافحة إعادة التشغيل باستخدام مفتاح API/الطابع الزمني/التوقيع؛ استخدمها عندما يكتب المستخدمون أو يراجعون واجهات برمجة التطبيقات، أو يضيفون تعليقات Shiro/Spring Security، أو يطبقون تصفية متعددة المستأجرين، أو يحملون الملفات، أو يستفسرون عن تجاوز الصلاحيات أو أمان الواجهة.
