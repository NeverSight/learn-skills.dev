Utilisez Codeguard pour appliquer et diagnostiquer les portails de style de code pour les projets SQL ; employez‑le lorsque l'utilisateur demande du linting, des vérifications de formatage, des correctifs automatiques, une validation de qualité pré‑commit ou lorsqu’un échec du lint sqlfluff « {file} » se produit. Commencez par confirmer la configuration du dépôt et la disponibilité de l’outil, catégorisez les résultats comme réussis, échoués, impossible à vérifier ou prévus, et après correction, les vérifications doivent être relancées.

Veuillez toujours répondre dans la langue de l'utilisateur.
