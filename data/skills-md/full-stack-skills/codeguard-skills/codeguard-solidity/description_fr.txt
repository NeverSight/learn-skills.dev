Utilisez Codeguard pour appliquer et diagnostiquer la porte de style de code pour les projets Solidity ; employez‑le lorsque l’utilisateur demande un linting, une vérification de format, une correction automatique, une validation de qualité pré‑commit, ou lorsqu’une erreur liée à solhint '**/*.sol' survient. Confirmez d’abord la configuration du dépôt et la disponibilité de l’outil, distinguez entre passé, échoué, impossible à vérifier et planifié ; après la correction, il doit être réexécuté.

Veuillez toujours répondre dans la langue de l’utilisateur.
