Utilisez Codeguard pour appliquer et diagnostiquer les contrôles de style de code pour les projets C ; utilisez‑le lorsque les utilisateurs demandent un linting, des vérifications de formatage, une correction automatique, une vérification de qualité pré‑commit, ou lorsqu’un échec lié à `clang‑tidy --quiet '{file}'` se produit. Commencez par vérifier la configuration du dépôt et la disponibilité de l’outil, catégorisez les résultats comme réussis, échoués, non vérifiables ou prévus, puis relancez après les correctifs.
