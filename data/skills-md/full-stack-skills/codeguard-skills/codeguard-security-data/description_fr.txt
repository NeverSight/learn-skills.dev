Examiner la classification des données sensibles, le stockage crypté, le masquage des retours/journaux, l'intégrité de la transmission, les sauvegardes et les preuves d'évaluation de conformité/sécurité ; utilisé lorsque les utilisateurs traitent des champs tels que les numéros de téléphone, les numéros d'identité, les cartes bancaires, les adresses, ou s'interrogent sur le masquage, KMS, SM2/SM3/SM4, la conformité ou l'évaluation de sécurité.
