Utilisez Codeguard pour appliquer et diagnostiquer les contrôles de style de code sur les projets Visual Basic .NET ; employez‑le lorsque les utilisateurs demandent du linting, des vérifications de formatage, des corrections automatiques, une validation de la qualité avant le commit, ou lorsqu’une erreur « dotnet format --verify-no-changes » survient. Commencez par vérifier la configuration du dépôt et la disponibilité de l’outil, distinguez les états réussis, échoués, non vérifiables et prévus, et après correction, le processus doit être relancé.
