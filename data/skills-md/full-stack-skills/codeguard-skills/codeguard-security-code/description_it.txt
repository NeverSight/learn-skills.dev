Revisare le perdite di codice sorgente/configurazione, le credenziali hard‑coded e le CVE delle dipendenze, e sviluppare una correzione riproducibile o un piano di mitigazione; utilizzare quando gli utenti richiedono sicurezza del codice, prevenzione di perdite di configurazione, scansione delle vulnerabilità, sicurezza delle dipendenze o controllo di sicurezza pre‑release. Le chiavi trapelate devono essere ruotate; la semplice cancellazione dei file non costituisce una correzione.

Rispondere sempre nella lingua dell'utente.
