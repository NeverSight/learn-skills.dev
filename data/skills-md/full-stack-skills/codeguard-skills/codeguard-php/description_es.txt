Use Codeguard para aplicar y diagnosticar la puerta de estilo de código para proyectos PHP; utilícelo cuando el usuario solicite linting, verificación de formato, autocorrección, validación de calidad pre‑commit o cuando ocurra una falla relacionada con php -l '{file}'. Primero confirme la configuración del repositorio y la disponibilidad de la herramienta, categorice los resultados como aprobado, fallido, no se pudo verificar o planificado, y vuelva a ejecutar después de corregir.
