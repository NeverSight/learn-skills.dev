Utilisez Codeguard pour exécuter et diagnostiquer le contrôle du style de code pour les projets PHP ; employez‑le lorsqu’un utilisateur demande un linting, des vérifications de formatage, des corrections automatiques, une validation de qualité avant validation, ou lorsqu’une erreur `php -l '{file}'` se produit. Vérifiez d’abord la configuration du dépôt et la disponibilité de l’outil, catégorisez les résultats comme réussite, échec, impossible à vérifier ou prévu, et après toute correction le processus doit être réexécuté.
