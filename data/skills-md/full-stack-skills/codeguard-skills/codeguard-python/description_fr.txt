Utilisez Codeguard pour exécuter et diagnostiquer la surveillance du style de code pour les projets Python ; employez‑le lorsqu’un utilisateur demande du linting, des vérifications de formatage, des corrections automatiques, une vérification de qualité pré‑commit ou lorsqu’un contrôle ruff échoue. Commencez par vérifier la configuration du référentiel et la disponibilité de l’outil, catégorisez les résultats comme réussis, échoués, impossible à vérifier ou prévus, et après correction, les vérifications doivent être relancées.
