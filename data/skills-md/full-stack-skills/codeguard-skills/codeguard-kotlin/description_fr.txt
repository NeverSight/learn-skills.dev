Utilisez Codeguard pour exécuter et diagnostiquer la validation du style de code pour les projets Kotlin ; employez‑le lorsque l'utilisateur demande le linting, les vérifications de format, les corrections automatiques, la vérification de qualité pré‑commit, ou lorsqu’une erreur liée à ./gradlew detekt se produit. Vérifiez d’abord la configuration du dépôt et la disponibilité de l’outil, catégorisez les résultats comme réussite, échec, impossible à vérifier ou prévu, et après correction, les vérifications doivent être relancées.  

Veuillez toujours répondre dans la langue de l’utilisateur.
