Utilisez Codeguard pour exécuter et diagnostiquer les portes de style de code pour les projets Markdown ; employez‑le lorsqu’un utilisateur demande le linting, la vérification de format, l’auto‑correction, la vérification de qualité pré‑commit ou rencontre des échecs liés à `npx --no-install markdownlint-cli2`. Commencez par confirmer la configuration du référentiel et la disponibilité de l’outil, distinguez les résultats comme réussis, échoués, impossible à vérifier ou prévus, et après correction, le processus doit être relancé.

Veuillez toujours répondre dans la langue de l’utilisateur.
