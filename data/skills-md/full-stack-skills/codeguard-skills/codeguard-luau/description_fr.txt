Utilisez Codeguard pour appliquer et diagnostiquer les contrôles de style de code pour les projets Luau ; utilisez‑le lorsqu’un utilisateur demande le linting, les vérifications de formatage, les corrections automatiques, la vérification de qualité avant le commit, ou lorsque des échecs liés à luau‑analyze « {file} » surviennent. Commencez par confirmer la configuration du dépôt et la disponibilité de l’outil, classez les résultats comme réussis, échoués, non vérifiables ou prévus, puis relancez après les corrections.

Veuillez toujours répondre dans la langue de l'utilisateur.
