Utilisez Codeguard pour appliquer et diagnostiquer les contrôles de style de code pour les projets Lua ; employez‑le lorsqu’un utilisateur demande un linting, une vérification de format, une correction automatique, une validation de qualité pré‑commit, ou lorsqu’une défaillance liée à luacheck survient. Commencez par vérifier la configuration du dépôt et la disponibilité de l’outil, catégorisez les résultats comme réussi, échoué, impossible à vérifier ou prévu, puis relancez après toute correction.

Veuillez toujours répondre dans la langue de l’utilisateur.
