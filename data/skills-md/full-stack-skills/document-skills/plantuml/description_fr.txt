Créez ou révisez le code source PlantUML pour une documentation UML et d’architecture précise, incluant les diagrammes de classe, de séquence, de composant, de déploiement, d’état, d’activité, de cas d’utilisation, ER, ArchiMate et C4. Utilisez‑le lorsque l’utilisateur demande explicitement PlantUML, UML, C4, `.puml`, la sémantique UML standard ou une notation d’architecture détaillée. Privilégiez Mermaid pour les diagrammes légers natifs Markdown et ProcessOn uniquement pour le rendu hébergé et éditable.  

Veuillez toujours répondre dans la langue de l’utilisateur.
