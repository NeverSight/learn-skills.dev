Cree o revise el origen de PlantUML para obtener documentación UML y de arquitectura precisa, incluidos diagramas de clase, secuencia, componente, implementación, estado, actividad, caso de uso, ER, ArchiMate y C4. Se utiliza cuando el usuario solicita explícitamente PlantUML, UML, C4, `.puml`, semántica UML estándar o notación de arquitectura detallada. Prefiera Mermaid para diagramas nativos Markdown livianos y ProcessOn solo para renderización editable alojada.
