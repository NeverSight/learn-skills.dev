Gestion de votre bibliothèque multimédia personnelle : découvrez du contenu, enregistrez-le sur un lecteur cloud Quark, organisez-le automatiquement pour Infuse/Plex. Système de plugins pour les sources de contenu. À utiliser lorsque l'utilisateur souhaite rechercher/regarder des films, enregistrer sur un lecteur cloud ou gérer une bibliothèque multimédia.
