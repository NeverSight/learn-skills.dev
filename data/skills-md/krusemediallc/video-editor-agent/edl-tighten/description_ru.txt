Хирургически удалять неловкие паузы, «мертвый эфир» и длинные тишины из ГОТОВОГО ролика с озвучкой, при этом сохранять синхронность видео, аудио озвучки, субтитров, синхронных со словами, звуковых эффектов и таймлайна композиции. Использовать, когда просят «утянуть монтаж», «удалить паузу на 0:41», «вырезать мертвый эфир», «пробел между предложениями слишком длинный», «подстричь тишины», «здесь затянуто», или когда этап правки добавляет новые разрезы к уже утянутому монтажу. Находит пробелы двумя способами (silencedetect + RMS‑оболочка), выбирает окна резки, квантизированные по кадрам, которые никогда не обрезают начало речи, маскирует сплайсы в точках разрезов или «привлечениях внимания», выполняет ОДИН фильтровый граф trim/concat для каждого потока из исходного источника, переназначает транскрипт через EDL с помощью scripts/remap-transcript.py (никогда не пере‑whisper) и проверяет результат повторным сканированием плюс извлечением кадров. Требуются только ffmpeg/ffprobe и python3. Не предназначено для создания самого монтажа (branded‑ad‑edit / talking‑head‑recut) или QA рендера, который вы не монтировали (video‑qa).
