將原始垂直對講頭影片重新剪輯成完成的短片：持續顯示的標題橫幅、與文字同步的卡拉 OK 字幕、旁白與關鍵字 CTA 的提示框，以及緊湊的靜音切割「自言自語」節奏——全部以單一 JSON 規格描述，並以確定性方式渲染。適用於使用者提供對講頭影片，想要編輯、樣式化或「讓它與我的其他影片／此參考 Reel 相匹配」的情況——包括「加入我的字幕」、「放上橫幅」、「加緊剪輯／使其更有衝擊力」、「剪除冷場」、「在我說 X 時加入提示框」或「修正我口誤的那段」。亦可用於修改 Reel 重新剪輯的版本（更改橫幅文字、加入/移動提示框、移除口誤、重新校準字幕時間），以及在品牌合作素材上僅做節奏調整的無圖形原始剪輯，由客戶的編輯者完成。不是用於未經剪輯的純字幕（嵌入式字幕）、在未修改影片的情況下覆蓋圖形卡（對講頭重新剪輯），或完整的品牌動態圖形廣告（品牌廣告編輯）。
