Edita un evento, conferencia, cumbre, viaje o recapitulación entre bastidores a partir de tomas habladas y B‑roll suministrado. Elige la toma más fuerte para cada línea, elimina pausas y reinicios, sincroniza el metraje con la narración, combina diseños de pantalla completa y dividida, añade subtítulos y gráficos selectivos, luego renderiza, verifica y revisa. Usa para “video de resumen”, “resumen de evento” o “edita esta cumbre como esta referencia”; no para un resumen de texto o una edición de demostración de pantalla de producto.
