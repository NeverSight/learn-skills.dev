ГЕНЕРИРОВАТЬ B‑roll и элементы моушн‑графики для монтажа с использованием AI‑моделей видео/изображений через внешнее API Arcads (Seedance, Sora 2, Veo 3.1, Kling, Grok Video, Nano Banana) — клипы продукта B‑roll, ритмические отрезки сцен, вставки в стиле UGC, статичные карточки кадров и наложения моушн‑графики со смешиванием экрана. Использовать, когда в монтаже требуются материалы, которые невозможно снять: «сгенерировать B‑roll продукта», «создать AI‑клип для этого ритма», «моушн‑графическое наложение для этой реплики», «AI‑вставка кадра». НЕ предназначено для захвата реальных веб‑страниц/экранов (broll‑capture) или создания композиций карточек (branded‑ad‑edit).
