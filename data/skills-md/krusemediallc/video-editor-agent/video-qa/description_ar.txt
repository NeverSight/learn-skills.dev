تحقق جودة بأربع طبقات لفيديو مُعدل — شغّله على أي ملف .mp4/.mov أنت أو خط الإنتاج قد أنشأه للتو. استخدمه عندما يُطلب منك فحص / التحقق / تدقيق تصيير أو تصدير، البحث عن كلمات مقطوعة، حوار مكرر عند القطعات، فراغ صوتي، نقرات قص، إطارات سوداء / متجمدة / وامضة، مشاكل مستوى الصوت (LUFS) أو تشويه، تأكيد إصلاح بعد إعادة تصيير، أو إنشاء حزمة فحص (صفحة اتصال + شكل موجة + نص) للوقت المشكوك فيه. L1 = فحوصات تقنية باستخدام ffmpeg/ffprobe، L2 = فحوصات حدود النص المترجم المرتبطة بملف EDL، L3 = تمريرة اختيارية للمشاهدة والاستماع عبر Gemini على نسخة بروكسي بدقة 480p، L4 = حزم فحص مستهدفة. يحتاج فقط إلى ffmpeg/ffprobe؛ whisper و GEMINI_API_KEY يفتحان الطبقات الأعمق.
