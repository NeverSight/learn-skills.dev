Four-layer QA for a rendered video edit — run it on any .mp4/.mov you or a pipeline just produced. Use when asked to QA / check / verify / audit a render or export, hunt clipped words, duplicate dialogue at cuts, dead air, splice clicks, black / frozen / flash frames, loudness (LUFS) or clipping problems, confirm a fix after a re-render, or build an inspection packet (contact sheet + waveform + transcript) for a suspect timestamp. L1 = ffmpeg/ffprobe technical checks, L2 = transcript edit-boundary checks mapped through the EDL, L3 = optional Gemini watch+listen pass on a 480p proxy, L4 = targeted inspection packets. Needs only ffmpeg/ffprobe; whisper and GEMINI_API_KEY unlock the deeper layers.
