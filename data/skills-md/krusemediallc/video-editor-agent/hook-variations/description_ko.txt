하나의 완성된 본문 클립에 여러 개의 훅 클립을 결합하여 훅당 하나의 독립 영상을 생성합니다—이 훅 A/B 배치를 별개의 광고 크리에이티브로 업로드합니다. “이 본문에 모든 훅을 추가하고 싶다”, “이 비디오를 폴더 안의 모든 훅과 결합한다”, “다른 오프너로 21개의 버전을 만든다”, “훅을 교체한다”, “훅 변형을 만든다”, “같은 본문에 대해 이 훅들을 테스트한다” 등과 같이 사용자가 하나의 본문 파일과 훅 폴더를 제공하고 N개의 완성 영상을 기대할 때 사용합니다. 또한 같은 형태에 다른 문구를 적용할 때도 사용합니다: 인트로 변형, 오프너 테스트, 콜드 오프너 A/B 세트, 혹은 기존 변형 배치를 새로운 본문 컷에 다시 적용할 때도 활용합니다. 결합은 무손실(본문 프레임이 비트 동일성을 유지)이며, 훅의 음량을 본문에 맞추어 이음새가 튀지 않게 하고, AVFoundation을 통해 검증합니다. ffmpeg만으로는 파라미터 세트 고정 현상을 잡지 못해 ffmpeg에서는 정상 재생되지만 QuickTime에서는 멈추는 문제를 방지합니다. 단일 비디오 편집, 캡션 추가, 혹은 긴 녹화에서 훅을 잘라내는 용도로는 사용하지 마세요.
