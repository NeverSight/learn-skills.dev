Скомбинируйте ОДИН готовый отрезок основного видео (body) с МНОГИМИ клипами‑хуками, чтобы получить отдельное готовое видео для каждого хука — пакет A/B хука, который вы загружаете как отдельные рекламные креативы. Используйте, когда кто‑то хочет «добавить все эти хуки к этому основному видео», «соединить это видео со всеми хуками из этой папки», «сделать 21 вариант с разными открывающимися частями», «заменить хук», «создать варианты хука», «протестировать эти хуки на одном и том же основном видео», или передаёт один файл основного видео плюс папку с хуками и ожидает N готовых видеороликов. Также применяется для одной и той же структуры с разными словами: варианты интро, тесты открывающих фраз, наборы холодных A/B открытий, либо повторный запуск уже существующего пакета вариантов на НОВОМ отрезке основного видео. Соединяет без потерь (кадры основного видео остаются бит‑идентичными), подгоняет громкость хука под основной материал, чтобы переход не был заметен, и проверяется с помощью AVFoundation, потому что проверка только ffmpeg не может обнаружить «заморозку» наборов параметров, из‑за которой файлы работают в ffmpeg, но зависают в QuickTime. НЕ используйте для редактирования одного видео, добавления субтитров или вырезания самих хуков из более длинной записи.
