Разделить ОДНУ длинную запись, содержащую множество отдельных хуков/взят, на набор независимых видеороликов — по одному на каждый хук — и подогнать каждый так, чтобы не было пустого воздуха, опусканий и повторов. Используйте, когда пользователь передаёт один длинный файл и хочет вырезать из него части: «вырезать эти хуки», «здесь более 20 хуков, сделайте каждый отдельным видео», «разрезать это на отдельные клипы», «одно видео на пример», «разбить этот композит», «подправьте их и пришлите мне». Также применяется в последующих раундах — чтение заметок ревьюера с таймлайнов, снятых с панели обзора, и их применение. Создано для формы демонстрации «запрос → результат» (создатель задаёт запрос, воспроизводит сгенерированное ИИ видео, реагирует), но механизм универсален: любой длинный записанный материал с повторяющимися дублями. НЕ предназначено для стилизации готового ролика баннерами/подписями (reel-recut), НЕ для графического редактирования брендированных реклам (branded-ad-edit) и НЕ для самой панели обзора единого реза (video-review-canvas — этот навык поставляется с собственным вариантом галереи 21‑up).
