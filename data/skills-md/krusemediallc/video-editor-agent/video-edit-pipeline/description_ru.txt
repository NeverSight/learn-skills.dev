МАСТЕР-ОРКЕСТРАЦИОННЫЙ НАВЫК для создания готового короткометражного видео из необработанного материала с говорящей головой. Используйте его для ЛЮБЫХ запросов по редактированию, производству, пере‑монтажу или «созданию рекламы/ролика» из такого материала — с примером стиля или без — включая «отредактировать это видео», «сделать монтаж как в референс‑ролике», «превратить этот клип в готовый ролик», «выполнить полный монтаж», «сделать так, чтобы выглядело как их победные рекламные ролики» или запрос на доработку уже предоставленного монтажа. Он распределяет каждый этап к нужному специализированному навыку (reel-style-clone, branded-ad-edit, reel-recut, arcads-video-edit, recap-video, talking-head-image-overlays, hook-splitter, sound-design, ai-audio-sound-design, video-qa, video-review-canvas, edl-tighten, hook-variations, naming-convention, capcut-export) и полностью управляет циклом «приём → стиль → монтаж → QA → доставка → исправление». НЕ используйте для простых субтитров к нетронутому материалу или одиночных сгенерированных клипов.
