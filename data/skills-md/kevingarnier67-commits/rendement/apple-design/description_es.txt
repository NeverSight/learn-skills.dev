Revisor de diseño UI/UX multiplataforma basado en las Human Interface Guidelines de Apple (123 páginas extraídas de developer.apple.com, incluidas 57 páginas de componentes) más una mirada de artesanía de diseño para trabajos distintivos y no plantillados. Úsalo para auditar, revisar, criticar o mejorar cualquier aplicación móvil (iOS, Flutter, React Native) o aplicación de escritorio (macOS, Tauri, Electron) : revisión de diseño, auditoría UI, cumplimiento de HIG, auditoría de accesibilidad, modo oscuro, Liquid Glass o glassmorphism, estructura de navegación, diseños para iPhone Duo o dispositivos plegables, onboarding, formularios, iconos de app, UX de IA generativa o peticiones como «haz que esto se vea menos genérico». También utilízalo siempre que el usuario comparta capturas de pantalla, maquetas, wireframes, exportaciones de Figma o código UI y quiera retroalimentación, incluso si solo dice «revisa mi diseño» o «¿es buena UI?». Funciona con SwiftUI, UIKit, AppKit, Flutter, React Native, Tauri y Electron.

Por favor, responde siempre en el idioma del usuario.
