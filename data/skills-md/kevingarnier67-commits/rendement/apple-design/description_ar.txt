مراجِع تصميم UI/UX متعدد المنصات مستند إلى إرشادات واجهة المستخدم البشرية لشركة Apple (123 صفحة مأخوذة من developer.apple.com، بما فيها 57 صفحة مكوّنات) بالإضافة إلى منظور حرفي للتصميم لأعمال مميزة غير نمطية. استخدمه لتدقيق، مراجعة، نقد أو تحسين أي تصميم لتطبيقات الهواتف المحمولة (iOS، Flutter، React Native) أو تطبيقات سطح المكتب (macOS، Tauri، Electron): مراجعة التصميم، تدقيق UI، التوافق مع HIG، تدقيق إمكانية الوصول، الوضع الداكن، Liquid Glass أو glassmorphism، هيكل التنقل، تخطيطات iPhone Duo أو القابلة للطي، onboarding، النماذج، أيقونات التطبيقات، تجربة المستخدم للذكاء الاصطناعي التوليدي، أو طلبات مثل "اجعل هذا أقل عمومية". استخدمه أيضًا عندما يشارك المستخدم لقطات شاشة، نماذج مبدئية، مخططات سلكية، تصديرات Figma، أو شفرة UI ويطلب ملاحظات، حتى وإن قال فقط "مراجعة تصميمي" أو "هل هذا UI جيد". يعمل مع SwiftUI، UIKit، AppKit، Flutter، React Native، Tauri، وElectron.
