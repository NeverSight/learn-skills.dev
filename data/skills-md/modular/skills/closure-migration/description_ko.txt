Mojo 코드를 레거시 매개변수 클로저(`capturing[_]`, `@__parameter` / `@parameter`, `api[fn](args)`)에서 값 가져오기 통합 클로저(`{imm}` / `{mut}` / `{var}` / 명명된 캡처 목록이 있는 `api(args, fn)`)로 마이그레이션합니다. 파라메트릭 오버로드 제거, "캡처 씬" 변환 오류 수정, 중첩된 실행/콜백 클로저 재작성 또는 comptime 함수 매개변수를 사용하는 API 마이그레이션 시 사용합니다. 또한 `compile_offload_closure func는 완전히 바인딩되어야 합니다`를 사용하여 Mojo 객체를 컴파일하는 동안 CI SIGSEGV를 사용할 때 사용합니다. 이는 호스트 정교화입니다. 원격 GPU 실행이 아닌 `kgen -elaborate`로 확인하세요.
