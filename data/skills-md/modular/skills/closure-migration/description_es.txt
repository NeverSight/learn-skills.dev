Migra el código Mojo de cierres paramétricos heredados (`capturing[_]`, `@__parameter` / `@parameter`, `api[fn](args)`) a cierres unificados de toma de valor (`api(args, fn)` con `{imm}` / `{mut}` / `{var}` / listas de captura con nombre). Úselo al eliminar sobrecargas paramétricas, corregir errores de conversión "capturadores", reescribir cierres de inicio/devolución de llamada anidados o migrar cualquier API que tomó un parámetro de función de tiempo de compilación. Úselo también cuando los CI SIGSEGV al compilar un objeto Mojo con la función `compile_offload_closure deben estar completamente vinculados`, es decir, elaboración del host; verifique con `kgen -elaborate`, no con la ejecución remota de GPU.
