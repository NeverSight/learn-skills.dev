Migriert Mojo-Code von älteren parametrischen Abschlüssen („capturing[_]“, „@__parameter“ / „@parameter“, „api[fn](args)“) auf wertübernehmende einheitliche Abschlüsse („api(args, fn)“ mit „{imm}“ / „{mut}“ / „{var}“ / benannte Erfassungslisten). Verwenden Sie diese Option, wenn Sie parametrische Überladungen entfernen, „Thin Capture“-Konvertierungsfehler beheben, verschachtelte Start-/Callback-Abschlüsse neu schreiben oder eine API migrieren, die einen Comptime-Funktionsparameter verwendet. Wird auch verwendet, wenn CI-SIGSEGVs beim Kompilieren eines Mojo-Objekts mit „compile_offload_closure func“ vollständig gebunden sein müssen – das ist Host-Ausarbeitung; Überprüfen Sie mit „kgen -elaborate“, nicht mit Remote-GPU-Ausführung.
