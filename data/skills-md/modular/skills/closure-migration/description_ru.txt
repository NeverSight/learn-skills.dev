Переносит код Mojo из устаревших параметрических замыканий (`captureing[_]`, `@__parameter` / `@parameter`, `api[fn](args)`) в унифицированные замыкания, принимающие значения (`api(args, fn)` с `{imm}` / `{mut}` / `{var}` / именованные списки захвата). Используйте при удалении параметрических перегрузок, исправлении ошибок «захвата тонкого» преобразования, переписывании вложенных замыканий запуска/обратного вызова или переносе любого API, который принимал параметр функции Comptime. Также используйте, когда CI SIGSEGV при компиляции объекта Mojo с функцией compile_offload_closure должна быть полностью привязана — это разработка хоста; проверьте с помощью «kgen -elaborate», а не с помощью удаленного выполнения графического процессора.
