Mojo コードを従来のパラメトリック クロージャ (`capturing[_]`、`@__parameter` / `@parameter`、`api[fn](args)`) から値を取る統合クロージャ (`{imm}` / `{mut}` / `{var}` / 名前付きキャプチャ リストを備えた `api(args, fn)`) に移行します。パラメトリック オーバーロードの削除、「キャプチャ シン」変換エラーの修正、ネストされた起動/コールバック クロージャの書き換え、または comptime 関数パラメータを受け取った API の移行を行う場合に使用します。また、「compile_offload_closure 関数を完全にバインドする必要がある」を使用して Mojo オブジェクトをコンパイルするときに CI SIGSEGV を使用する場合にも使用します。これはホスト エラボレーションです。リモート GPU 実行ではなく、`kgen -elaborate` で検証してください。
