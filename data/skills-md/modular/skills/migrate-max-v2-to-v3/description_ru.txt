Используйте при переносе модели MAX из V2 графического API (max.nn, TensorValue, явное построение Graph) в ModuleV3 (max.experimental.nn, Tensor, F.lazy() + compile()). Срабатывает на: «migrate to ModuleV3», «port a max.nn model to max.experimental», «convert TensorValue to Tensor», «update my model to the V3 API», «ModuleV3 migration». Рабочий процесс: прочитайте карту концепций, перепишите импорты и сигнатуры __call__, замените построение графа на compile(weights=...), согласуйте имена весов с новой иерархией модулей, переместите разворачивание KV‑кеша в forward(), перенесите шардинг в DeviceMesh, если модель V2 была шардирована, затем проверьте, что жадные выводы совпадают с реализацией V2.
