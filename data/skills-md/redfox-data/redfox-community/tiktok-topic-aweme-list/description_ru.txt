Получить данные о работах TikTok по заданной теме. На основе данных Red Fox выполнить запрос списка работ в рамках темы TikTok, по умолчанию выводя основные данные, такие как просмотры, лайки, комментарии и репосты, в порядке убывания количества просмотров, а также кликабельные ссылки на полные работы, поддерживая постраничный вывод и переключатели сортировки. Подходит для пользователей, которым необходимо запросить работы по теме TikTok, данные о ID темы или списки работ по хэштегам/челленджам. Триггерные слова: работы темы TikTok, список работ темы, данные темы TikTok, список работ по хэштегу, список работ по челленджу.
