Инструмент для реального‑временного запроса списка работ аккаунта Bilibili. Он получает последний список видеоработ, опубликованных загрузчиком Bilibili по UID загрузчика, поддерживая курсорную пагинацию для просмотра большего количества работ. Используйте его, когда хотите просмотреть список работ загрузчика Bilibili, видео аккаунта или список публикаций.
