Outil de recherche de compte TikTok et de requête de liste d’abonnements. Basé sur les données Red Fox, il localise les comptes cibles sur TikTok par surnom ou identifiant et affiche les profils tels que le nombre d’abonnés, les publications, les likes et le statut de vérification ; il peut également récupérer la liste des comptes suivis par un utilisateur spécifié et analyser les caractéristiques de ces abonnements. Les deux fonctions peuvent être combinées — rechercher d’abord un compte, puis vérifier ses abonnements. Convient aux scénarios comme la recherche d’utilisateurs TikTok, voir qui un compte particulier suit et étudier les profils des abonnés. Mots‑déclencheurs : TikTok rechercher utilisateur, TikTok trouver compte, TikTok liste d’abonnements, TikTok qui suit.
