Инструмент для поиска аккаунтов в TikTok и запроса списка подписок. На основе данных Red Fox он позволяет находить целевые аккаунты в TikTok по нику или имени пользователя, просматривать профили, такие как количество подписчиков, постов, лайков и статус верификации; также может получать список аккаунтов, на которые подписан данный пользователь, анализируя характер этих подписок. Обе возможности можно объединить — сначала выполнить поиск аккаунта, затем проверить его подписки. Подходит для сценариев, таких как поиск пользователей TikTok, просмотр, кого конкретный аккаунт подписал, и исследование профилей целей подписки. Триггерные слова: поиск пользователя TikTok, найти аккаунт TikTok, список подписок TikTok, кто они подписали.
