Поиск данных о темах TikTok по ключевому слову и поддержка запроса списка работ внутри темы по ID темы. На основе данных Red Fox возвращаются основные метрики, такие как название темы, ID темы, количество использований, количество просмотров и число участников для заданного ключевого слова; ввод ID темы позволяет дальше искать работы в этой теме, выводя основные данные, такие как количество воспроизведений, лайков, комментариев, репостов и кликабельную ссылку на полную работу, с возможностью пагинации и сортировки. Это предназначено для пользователей, которым необходимо искать темы TikTok, находить темы, связанные с ключевым словом, или получать работы по ID темы. Триггерные фразы: поиск темы TikTok по ключевому слову, поиск темы TikTok, данные темы TikTok, поиск работ по ID темы, поиск хештегов.
