Buscar datos de temas de TikTok por palabra clave y también permitir consultar la lista de videos bajo un tema usando su ID de tema. Basado en datos de Red Fox, devolver métricas clave como nombre del tema, ID del tema, recuento de uso, recuento de vistas y recuento de participantes para una palabra clave dada; ingresar un ID de tema permite recuperar los videos de ese tema, proporcionando datos esenciales como reproducciones, me gusta, comentarios, compartidos, además de enlaces clicables a los videos completos, con opciones de paginación y ordenación. Esto está destinado a usuarios que necesitan buscar temas de TikTok, encontrar temas relacionados con una palabra clave o buscar videos por ID de tema. Frases de activación: búsqueda de tema por palabra clave en TikTok, buscar temas de TikTok, datos de tema de TikTok, búsqueda de video por ID de tema, búsqueda de hashtag.
