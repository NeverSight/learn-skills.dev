Übersee‑übergreifende Hot‑Content‑Suche – Geben Sie ein beliebiges Stichwort (Chinesisch oder Englisch) ein, um beliebte Inhalte auf X, TikTok und YouTube mit einer einzigen Anfrage zu durchsuchen. Für jede Plattform werden die Top‑N‑Ergebnisse (Standard 5) in einer einheitlichen Liste (Plattform / Titel / Autor / Aufrufe / Likes / Kommentare / Veröffentlichungszeit / Link) angezeigt, mit gruppierten Tabellen im Terminal, CSV‑Export und einem interaktiven HTML‑Report (Karten‑ und Tabellen‑Doppelsicht). Das System priorisiert intelligent Inhalte in derselben Sprache wie das Stichwort (chinesische Begriffe → zuerst Chinesisch, englische Begriffe → zuerst Englisch, andere Sprachen als Fallback). Nutzen Sie es, wenn Sie Trends auf ausländischen Plattformen erkunden, plattformübergreifende Inhalte vergleichen, Themen oder Wettbewerber‑Stimmungen überwachen oder Material für die Themenauswahl sammeln.
