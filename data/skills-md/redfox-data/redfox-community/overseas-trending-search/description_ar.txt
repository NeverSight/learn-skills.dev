البحث عن المحتوى الساخن عبر المنصات الأجنبية — أدخل أي كلمة مفتاحية (صينية/إنجليزية) للبحث عن المحتوى الشائع عبر X / تيك‑توك / يوتيوب في استعلام واحد. يُرجع قائمة موحدة بأفضل N عناصر لكل منصة (الافتراضي 5) تُظهر المنصة، العنوان، المؤلف، عدد المشاهدات، الإعجابات، التعليقات، تاريخ النشر، والرابط. تُعرض النتائج في جداول مُجمَّعة على الطرفية، مع تصدير CSV وتقرير HTML تفاعلي (عرض بطاقات وجدول مزدوج). يفضِّل النظام بذكاء المحتوى بنفس لغة الكلمة المفتاحية (كلمة صينية → محتوى صيني أولاً، كلمة إنجليزية → محتوى إنجليزي أولاً، واللغات الأخرى كخيار احتياطي). استخدم هذه الأداة للبحث عن اتجاهات المنصات الأجنبية، مقارنة المحتوى عبر المنصات، مراقبة رأي الموضوع أو المنافسين، وجمع أفكار لإنشاء محتوى.
