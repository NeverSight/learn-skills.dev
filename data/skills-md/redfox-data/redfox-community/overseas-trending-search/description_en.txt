Overseas Cross‑Platform Hot Content Search — Enter any keyword (Chinese/English) to search popular content across X / TikTok / YouTube in a single query. Returns a unified list of the top N items per platform (default 5) showing platform, title, author, views, likes, comments, publish date, and link. Results are presented in grouped tables on the terminal, with CSV export and an interactive HTML report (card and table dual view). The system intelligently prioritizes content in the same language as the keyword (Chinese keyword → Chinese content first, English keyword → English content first, other languages as fallback). Use this tool for searching overseas platform trends, cross‑platform content comparison, topic or competitor sentiment monitoring, and gathering ideas for content creation.
