Ein Werkzeug zum Durchsuchen von Dongchedi‑Nutzern und zum Abonnieren ihrer Werke. Durch Eingabe von Schlüsselwörtern können Sie Nutzer‑ (Autor‑) Konten auf Dongchedi finden, wobei Follower‑Zahl und Bio auf einen Blick ersichtlich sind; wählen Sie den gewünschten Nutzer, um dessen Werkliste abzurufen, die Titel, Typ, Aufrufe, Likes, Kommentare, Favoriten und Veröffentlichungszeit anzeigt; ein Klick auf ein Werk führt zur Originalseite. Es unterstützt zudem das Abonnieren von Nutzern und schiebt täglich automatisch deren gestrige Updates. Verwenden Sie es, wenn Sie Dongchedi‑Nutzer suchen, Dongchedi‑Autoren/Influencer finden, die Werkliste eines Dongchedi‑Nutzers einsehen, Dongchedi‑Nutzer‑Updates abonnieren oder Dongchedi‑Creator‑Inhalte studieren möchten.
