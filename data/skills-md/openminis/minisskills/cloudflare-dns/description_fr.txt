Utilisez l’outil de ligne de commande flarectl pour gérer les enregistrements DNS Cloudflare, notamment pour lister, ajouter, mettre à jour et supprimer des enregistrements DNS, ainsi que pour interroger les informations relatives aux zones. Cette compétence doit être déclenchée chaque fois qu’un utilisateur mentionne « DNS Cloudflare », « DNS CF », « ajouter un enregistrement DNS », « supprimer un enregistrement DNS », « mettre à jour le DNS », « afficher les enregistrements DNS », « cloudflare-dns », « flarectl » ou tout scénario impliquant la gestion du DNS Cloudflare.
