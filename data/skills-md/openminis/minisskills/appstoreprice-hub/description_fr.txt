Une compétence permettant d'interroger les prix des applications App Store dans toutes les régions du monde, à l'aide des données d'appstoreprice.org. Il utilise le navigateur intégré Minis (CLI d'utilisation du mini-navigateur) pour appeler la fonction de signature native du site Web directement dans le contexte de la page, sans clé API et sans avoir besoin d'implémenter vous-même l'algorithme de signature. Il prend en charge la recherche d'applications par nom, l'interrogation des prix d'une application dans toutes les régions, la récupération du classement des régions les moins chères et la navigation dans les listes d'applications avec pagination. Cette compétence doit être déclenchée lorsque l'utilisateur mentionne « prix de l'App Store », « quelle région est la moins chère », « prix de la région de Turquie », « prix de l'Appstore », « comparaison des prix des applications », « régions de l'App Store à bas prix », « quelle région d'abonnement est la meilleure valeur » ou tout scénario nécessitant des comparaisons de prix entre régions pour les applications iOS/macOS.
