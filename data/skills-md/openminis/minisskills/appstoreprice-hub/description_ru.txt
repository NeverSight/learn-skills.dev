Навык запроса цен на приложения в App Store в разных регионах мира с использованием данных с сайта appstoreprice.org. Он использует встроенный браузер Minis (интерфейс командной строки minis-browser-use) для вызова собственной функции подписи веб-сайта непосредственно в контексте страницы, без ключа API и необходимости самостоятельно реализовывать алгоритм подписи. Он поддерживает поиск приложений по названию, запрос цен на одно приложение во всех регионах, получение рейтингов самых дешевых регионов и просмотр списков приложений с нумерацией страниц. Этот навык должен активироваться, когда пользователь упоминает «цены в App Store», «какой регион самый дешевый», «цена в регионе Турции», «цена в магазине приложений», «сравнение цен на приложения», «регионы App Store с низкими ценами», «какой регион подписки является лучшим по цене» или любой сценарий, требующий сравнения цен между регионами для приложений iOS/macOS.
