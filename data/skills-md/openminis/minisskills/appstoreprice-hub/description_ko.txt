appstoreprice.org의 데이터를 사용하여 전 세계 지역의 App Store 앱 가격을 쿼리하는 기술입니다. Minis 내장 브라우저(minis-browser-use CLI)를 사용하여 API 키나 서명 알고리즘을 직접 구현할 필요 없이 페이지 컨텍스트에서 직접 웹사이트의 기본 서명 기능을 호출합니다. 이름으로 앱을 검색하고, 모든 지역에서 하나의 앱에 대한 가격을 쿼리하고, 가장 저렴한 지역의 순위를 검색하고, 페이지 매김을 통해 앱 목록을 탐색하는 기능을 지원합니다. 이 기술은 사용자가 "App Store 가격", "어느 지역이 가장 저렴한지", "터키 지역 가격", "appstoreprice", "앱 가격 비교", "저렴한 App Store 지역", "가치가 가장 높은 구독 지역" 또는 iOS/macOS 앱에 대해 지역 간 가격 비교가 필요한 모든 시나리오를 언급할 때 트리거되어야 합니다.
