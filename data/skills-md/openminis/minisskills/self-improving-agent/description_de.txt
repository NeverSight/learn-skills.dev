Protokollierung zur Selbstverbesserung und Closed-Loop-Feedback: Wird ausgelöst, wenn ein Befehl oder eine Operation fehlschlägt, der Benutzer Sie korrigiert, veraltetes Wissen identifiziert wird, eine externe API fehlschlägt oder eine bessere wiederverwendbare Lösung gefunden wird. Überprüfen Sie frühere Erkenntnisse, bevor Sie wichtige Aufgaben ausführen. Vermeiden Sie das Auslösen während eines normalen Chats, bei vorübergehenden Fehlern, die nicht protokolliert werden müssen, oder wenn der Benutzer ausdrücklich gesagt hat, dass nichts protokolliert werden soll.
