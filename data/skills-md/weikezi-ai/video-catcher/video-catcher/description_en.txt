This is used when a user requests to download videos, save videos from webpages, download MP4/M3U8/MPD files, download videos from platforms such as YouTube, Bilibili, Douyin, TikTok, X, Instagram, batch‑download videos, download subtitles or covers, check which media resources are present on a page, view which download resolutions are available for a video, specify resolutions like 360p/720p/1080p/2K/4K, or resume an interrupted video download. For local agents like Codex, Claude Code, etc.: the user only needs to provide a link and a target, and the skill automatically performs yt‑dlp, YouTube PO Token Provider, browser‑fingerprint retries, static discovery, isolated persistent browser network sniffing, request‑context inheritance, audio‑video merging, DRM checks, resumable downloading, validation and reporting; by default it does not rely on the Chrome/Edge cookie database the user is running, nor does it require the user to choose a technical approach during the download.
