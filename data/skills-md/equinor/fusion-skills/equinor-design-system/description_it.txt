Regole di progettazione EDS autorevoli e leggibili dalla macchina per token di colore, tipografia, spaziatura, elevazione, icone e zone di layout di pagina. UTILIZZARE PER: ricerca delle proprietà personalizzate CSS EDS corrette, nomi delle varianti tipografiche, token di spaziatura, token di ombra/elevazione, regole di utilizzo delle icone e convenzioni di layout della pagina di Fusion Portal. Si tratta di un riferimento di ricerca utilizzato da altre competenze e agenti: non ha un flusso di lavoro autonomo. NON UTILIZZARE PER: oggetti di scena dei componenti React o esempi di utilizzo (utilizzare fusion-research + mcp_fusion_search_eds), attività generali di codifica di Copilot o domande sull'API Fusion Framework.
