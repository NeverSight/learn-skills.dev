macOS Cache Cleanup Agent (Little Raccoon). Performs a read‑only health check of development tool caches and application caches on a Mac, determines which can be deleted based on the safety levels in the cache map, and executes the cleanup after user confirmation. Use when: the user says the disk is full, wants to clean caches, Mac has insufficient space, an app is taking dozens of gigabytes, asks for slimming down, cache cleaner, disk health check. Only handles caches; does not uninstall apps or perform system optimization.
