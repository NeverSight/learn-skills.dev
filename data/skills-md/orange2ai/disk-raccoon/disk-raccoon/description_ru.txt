macOS Cache Cleaning Agent (Little Raccoon). Выполняет диагностику только для чтения кэшей инструментов разработки и кэшей приложений на Mac, определяет, какие из них можно удалить в соответствии с уровнями безопасности в карте кэша, и осуществляет очистку после подтверждения пользователем. Использовать, когда: пользователь сообщает, что диск заполнен, хочет очистить кэши, места на Mac недостаточно, конкретное приложение занимает десятки ГБ, требуется обрезка, очистка кэша, проверка состояния диска. Обрабатывает только кэши; не удаляет приложения и не выполняет оптимизацию системы.
