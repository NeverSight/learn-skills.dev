Assicurati di utilizzare questa funzione ogni volta che l'utente digita `/handoff` (con o senza un argomento di nome file), dice “handoff”, “save state”, “context rot”, “save session”, “create a handoff”, “I need a clean start”, vuole fare uno snapshot dei progressi prima di cancellare il contesto o cambiare sessione, si sta avvicinando al limite di contesto (300–400k token), o desidera delegare lo stato della sessione corrente a un altro agente. Invocala anche per la modalità RIPRESA: quando l'utente dice “load handoff”, “resume from [file]”, “continue where we left off”, “pick up where I left off”, “load the handoff at [path]”, fa riferimento a un percorso di file `.claude/handoffs/`, o afferma che esiste un file di handoff da una sessione precedente. Crea o carica uno snapshot JSON strutturato che cattura obiettivi, decisioni, passaggi completati, lavoro in sospeso, vincoli e file modificati, così il lavoro può continuare pulitamente in una nuova sessione.

Rispondi sempre nella lingua dell'utente.
