Assurez-vous d'utiliser cette compétence chaque fois que l'utilisateur tape /handoff (avec ou sans argument de nom de fichier), dit « handoff », « save state », « context rot », « save session », « create a handoff », « I need a clean start », veut prendre un instantané de la progression avant de nettoyer le contexte ou de changer de session, approche de la limite de contexte (300–400 k tokens), ou souhaite déléguer l'état actuel de la session à un autre agent. Activez également le mode REPRENDRE : lorsque l'utilisateur dit « load handoff », « resume from [file] », « continue where we left off », « pick up where I left off », « load the handoff at [path] », fait référence à un chemin de fichier .claude/handoffs/, ou indique qu'il existe un fichier de handoff d'une session précédente. Crée ou charge un instantané JSON structuré capturant les objectifs, les décisions, les étapes accomplies, le travail en cours, les contraintes et les fichiers modifiés afin que le travail puisse se poursuivre proprement dans une nouvelle session.

Veuillez toujours répondre dans la langue de l'utilisateur.
