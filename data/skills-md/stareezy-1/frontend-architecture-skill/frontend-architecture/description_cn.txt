一种适用于任何 React 或 React Native 前端的可移植、框架无关的架构风格。将应用组织为带有页面/屏幕目录的特性模块，严格区分服务器状态与 UI 状态，仅使用 barrel 方式进行跨模块导入，样式与代码同位置，并具备明确的组件提升规则。状态管理无关（Zustand、Redux Toolkit、MobX、Jotai、Valtio 或 Context）。样式无关（Tailwind、CSS Modules、Tamagui、StyleSheet、styled‑components）。在搭建新应用、添加特性或模块、决定组件、hook 或状态片段的存放位置、命名类型和接口，或审查文件夹结构和导入边界时使用此技能。兼容 Next.js App Router、React + Vite SPA、Remix，以及 Expo / React Native。
