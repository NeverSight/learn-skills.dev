نمط بنية محمول وغير معتمد على إطار عمل لأي واجهة أمامية باستخدام React أو React Native. ينظم التطبيقات إلى وحدات ميزات مع أدلة للصفحات/الشاشات، تقسيم صارم بين حالة الخادم وحالة واجهة المستخدم، استيرادات عبر الوحدات باستخدام barrel‑only فقط، أنماط موضعية، وقواعد واضحة لترقية المكونات. غير معتمد على إدارة الحالة (Zustand، Redux Toolkit، MobX، Jotai، Valtio، أو Context). غير معتمد على الأسلوب (Tailwind، CSS Modules، Tamagui، StyleSheet، styled‑components). استخدم هذه القدرة عند إنشاء تطبيق جديد، إضافة ميزة أو وحدة، تحديد موقع المكوّن أو الخطاف أو جزء من الحالة، تسمية الأنواع والواجهات، أو مراجعة بنية المجلدات وحدود الاستيراد. يعمل مع Next.js App Router، React + Vite SPA، Remix، وExpo / React Native.
