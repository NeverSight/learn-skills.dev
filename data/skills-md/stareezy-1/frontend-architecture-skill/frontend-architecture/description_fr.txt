Un style d'architecture portable, indépendant du framework, pour tout frontend React ou React Native. Il organise les applications en modules fonctionnels avec des répertoires page/écran, une séparation stricte entre l’état serveur et l’état UI, des imports inter‑modules uniquement via des barrels, des styles co‑localisés et des règles claires de promotion des composants. Indépendant de la gestion d’état (Zustand, Redux Toolkit, MobX, Jotai, Valtio ou Context). Indépendant du style (Tailwind, CSS Modules, Tamagui, StyleSheet, styled‑components). Utilisez cette compétence lors du scaffolding d’une nouvelle appli, de l’ajout d’une fonctionnalité ou d’un module, pour décider où placer un composant, un hook ou un morceau d’état, nommer les types et interfaces, ou réviser la structure des dossiers et les limites d’importation. Fonctionne avec Next.js App Router, React + Vite SPA, Remix et Expo / React Native.
