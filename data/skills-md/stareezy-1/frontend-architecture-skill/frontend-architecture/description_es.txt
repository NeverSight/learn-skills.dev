Un estilo de arquitectura portátil y agnóstico al framework para cualquier frontend de React o React Native. Organiza las aplicaciones en módulos de funcionalidad con directorios de página/pantalla, una separación estricta entre estado del servidor y estado de UI, importaciones entre módulos solo a través de barriles, estilos co‑ubicados y reglas claras de promoción de componentes. Agnóstico en la gestión del estado (Zustand, Redux Toolkit, MobX, Jotai, Valtio o Context). Agnóstico en el estilo (Tailwind, CSS Modules, Tamagui, StyleSheet, styled‑components). Usa esta habilidad al crear una nueva aplicación, añadir una funcionalidad o módulo, decidir dónde debe residir un componente, hook o pieza de estado, nombrar tipos e interfaces, o revisar la estructura de carpetas y los límites de importación. Funciona con Next.js App Router, React + Vite SPA, Remix y Expo / React Native.
