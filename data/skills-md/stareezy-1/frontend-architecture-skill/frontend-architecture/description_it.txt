Uno stile di architettura portatile e indipendente dal framework per qualsiasi frontend React o React Native. Organizza le app in moduli funzionali con directory page/screen, una netta separazione tra stato del server e stato UI, importazioni cross-modulo solo tramite barrel, stili co‑locati e regole chiare per la promozione dei componenti. Indipendente dalla gestione dello stato (Zustand, Redux Toolkit, MobX, Jotai, Valtio o Context). Indipendente dallo styling (Tailwind, CSS Modules, Tamagui, StyleSheet, styled‑components). Usa questa competenza quando crei la struttura di una nuova app, aggiungi una funzionalità o un modulo, decidi dove posizionare un componente, hook o pezzo di stato, nomini tipi e interfacce, o rivedi la struttura delle cartelle e i confini di importazione. Compatibile con Next.js App Router, React + Vite SPA, Remix e Expo / React Native.
