任意の React または React Native フロントエンド向けの、ポータブルでフレームワークに依存しないアーキテクチャスタイルです。アプリをページ/スクリーンディレクトリを持つ機能モジュールに整理し、サーバー状態と UI 状態を厳密に分離し、バレルインポートのみを用いたクロスモジュールインポート、スタイルを同居させ、コンポーネントの昇格ルールを明確にします。状態管理に依存しません（Zustand、Redux Toolkit、MobX、Jotai、Valtio、または Context）。スタイリングにも依存しません（Tailwind、CSS Modules、Tamagui、StyleSheet、styled‑components）。このスキルは、新しいアプリのスキャフォールド、機能やモジュールの追加、コンポーネント・フック・状態の配置場所の決定、型やインターフェースの命名、フォルダ構造やインポート境界のレビュー時に使用してください。Next.js App Router、React + Vite SPA、Remix、Expo / React Native で動作します。
