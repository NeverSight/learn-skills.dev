一種可移植、與框架無關的架構風格，適用於任何 React 或 React Native 前端。將應用程式組織為具備頁面／螢幕目錄的功能模組，嚴格區分 server‑state 與 UI‑state，僅使用 barrel 方式跨模組匯入，樣式與程式碼共同放置，並有明確的元件升級規則。對狀態管理保持中立（Zustand、Redux Toolkit、MobX、Jotai、Valtio 或 Context）。對樣式保持中立（Tailwind、CSS Modules、Tamagui、StyleSheet、styled‑components）。在以下情境使用此技能：搭建新應用、加入功能或模組、決定元件、hook 或狀態應放置於何處、命名類型與介面，或審查資料夾結構與匯入邊界。相容於 Next.js App Router、React + Vite SPA、Remix 以及 Expo / React Native。
