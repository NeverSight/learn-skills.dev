Переносимый, независимый от фреймворка стиль архитектуры для любого фронтенда на React или React Native. Организует приложения в модульные функции с каталогами страниц/экранов, строго разделяет серверное состояние и состояние UI, использует только barrel‑импорты между модулями, размещает стили рядом с компонентами и задаёт чёткие правила продвижения компонентов. Не привязан к какому‑либо управлению состоянием (Zustand, Redux Toolkit, MobX, Jotai, Valtio или Context). Не привязан к стилям (Tailwind, CSS Modules, Tamagui, StyleSheet, styled‑components). Используйте эту практику при создании нового приложения, добавлении функции или модуля, определении места расположения компонента, хука или части состояния, именовании типов и интерфейсов, а также при проверке структуры каталогов и границ импортов. Работает с Next.js App Router, React + Vite SPA, Remix и Expo / React Native.
