Создаёт каркасы .NET 10 Minimal API конечных точек с документацией OpenAPI, стратегиями версионирования и паттернами безопасности. Используйте при создании REST‑API, добавлении конечных точек, настройке проектов API или конфигурировании инфраструктуры API. Не используйте, если проект построен на контроллерах MVC — вместо этого используйте dotnet‑vertical‑slice для архитектуры обработчиков. Пожалуйста, всегда отвечайте на языке пользователя.
