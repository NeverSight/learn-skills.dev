يبني نقاط نهاية Minimal API في .NET 10 مع توثيق OpenAPI، واستراتيجيات النسخة، وأنماط الأمان. يُستَخدم عند إنشاء واجهات برمجة تطبيقات REST، إضافة نقاط النهاية، إعداد مشاريع API، أو تهيئة بنية تحتية للـ API. لا يُستَخدم عندما يكون المشروع قائمًا على MVC مع المتحكمات — استخدم dotnet-vertical-slice لهندسة المعالجات بدلاً من ذلك.
