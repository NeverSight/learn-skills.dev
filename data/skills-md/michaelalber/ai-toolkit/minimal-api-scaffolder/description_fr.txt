Crée des squelettes d’endpoints Minimal API .NET 10 avec documentation OpenAPI, stratégies de versionnage et modèles de sécurité. À utiliser lors de la création d’APIs REST, de l’ajout d’endpoints, de la mise en place de projets API ou de la configuration de l’infrastructure API. NE PAS utiliser lorsque le projet est basé sur des contrôleurs MVC — utilisez dotnet-vertical-slice pour une architecture de gestionnaires à la place.

Répondez toujours dans la langue de l’utilisateur.
