Planificar, crear, refactorizar y revisar el marcado CSS y HTML utilizando la metodología MaintainableCSS de Adam Silver. Utilícelo al diseñar una arquitectura CSS modular, nombrar clases semánticas con convenciones de módulo/componente/estado/modificador de lowerCamelCase, desenredar hojas de estilo heredadas de alta especificidad o migrar lejos de patrones de clases visuales y de utilidad.
