Genera token di installazione per l'app GitHub e risolvi l'identità di revisione dichiarata dal documento di tracciamento di un repository. Usa quando una funzionalità di pubblicazione richiede il comando di login e review-token per un'app di revisione, oppure quando una persona invoca /review-bot per creare, installare o verificare l'app.

Si prega di rispondere sempre nella lingua dell'utente.
