Utilisez‑le lors de l’ajout de Supabase Edge Functions, de gestionnaires Stripe/webhook, de secrets côté serveur ou de routes API qui ne doivent pas s’exécuter dans le navigateur. Ce n’est pas destiné à l’UI uniquement côté client, au CSS ou aux opérations CRUD simples que RLS + le client peuvent gérer en toute sécurité.
