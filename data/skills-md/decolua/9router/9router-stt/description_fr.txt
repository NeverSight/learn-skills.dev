Reconnaissance vocale via 9Router /v1/audio/transcriptions en utilisant les modèles OpenAI Whisper / Groq / Gemini / Deepgram / AssemblyAI / NVIDIA / HuggingFace. À utiliser lorsque l'utilisateur souhaite transcrire un audio, convertir la parole en texte ou obtenir des sous-titres à partir de fichiers audio.

Veuillez toujours répondre dans la langue de l'utilisateur.
