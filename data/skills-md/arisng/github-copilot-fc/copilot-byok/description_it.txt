Configura e passa da un provider LLM BYOK (Bring Your Own Key) all'altro sia per GitHub Copilot CLI che per VS Code Chat. Usalo quando imposti OpenAI, Azure OpenAI, Anthropic, Ollama, Moonshot, OpenCode Go, OpenRouter o altri endpoint compatibili con OpenAI; crei o cambi profili provider riutilizzabili per la CLI; cambi tra più account (chiavi API) per lo stesso provider; configuri chatLanguageModels.json per VS Code; calcoli sovrascritture dei token massimi per prompt o output; configuri l'API wire e lo sforzo di ragionamento; o risolvi problemi relativi a COPILOT_PROVIDER_BASE_URL, COPILOT_PROVIDER_TYPE, COPILOT_PROVIDER_API_KEY, COPILOT_MODEL, COPILOT_PROVIDER_WIRE_API, COPILOT_PROVIDER_MAX_PROMPT_TOKENS, COPILOT_PROVIDER_MAX_OUTPUT_TOKENS, COPILOT_OFFLINE e alle impostazioni del modello linguistico di VS Code.
