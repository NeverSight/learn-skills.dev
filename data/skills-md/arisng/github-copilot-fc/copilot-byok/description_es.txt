Configura y cambia entre proveedores LLM BYOK (Bring Your Own Key) tanto para GitHub Copilot CLI como para VS Code Chat. Úsalo al configurar OpenAI, Azure OpenAI, Anthropic, Ollama, Moonshot, OpenCode Go, OpenRouter u otros puntos finales compatibles con OpenAI; al crear o cambiar perfiles de proveedor reutilizables para la CLI; al cambiar entre múltiples cuentas (claves API) para el mismo proveedor; al configurar chatLanguageModels.json para VS Code; al calcular anulaciones de tokens máximos de solicitud o salida; al configurar la API wire y el esfuerzo de razonamiento; o al solucionar problemas de COPILOT_PROVIDER_BASE_URL, COPILOT_PROVIDER_TYPE, COPILOT_PROVIDER_API_KEY, COPILOT_MODEL, COPILOT_PROVIDER_WIRE_API, COPILOT_PROVIDER_MAX_PROMPT_TOKENS, COPILOT_PROVIDER_MAX_OUTPUT_TOKENS, COPILOT_OFFLINE y la configuración del modelo de lenguaje de VS Code.
