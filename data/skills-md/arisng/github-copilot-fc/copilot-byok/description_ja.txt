GitHub Copilot CLI と VS Code Chat の両方で、BYOK（Bring Your Own Key）LLM プロバイダーを構成し、切り替えます。OpenAI、Azure OpenAI、Anthropic、Ollama、Moonshot、OpenCode Go、OpenRouter、またはその他の OpenAI 互換エンドポイントを設定する際、CLI 用に再利用可能なプロバイダープロファイルを作成または切り替える、同一プロバイダーの複数アカウント（API キー）間を切り替える、VS Code 用に chatLanguageModels.json を構成する、最大プロンプトまたは出力トークンのオーバーライドを計算する、wire API と推論コストを設定する、あるいは COPILOT_PROVIDER_BASE_URL、COPILOT_PROVIDER_TYPE、COPILOT_PROVIDER_API_KEY、COPILOT_MODEL、COPILOT_PROVIDER_WIRE_API、COPILOT_PROVIDER_MAX_PROMPT_TOKENS、COPILOT_PROVIDER_MAX_OUTPUT_TOKENS、COPILOT_OFFLINE、VS Code の言語モデル設定のトラブルシューティングを行う際に使用します。

常にユーザーの言語で応答してください。
