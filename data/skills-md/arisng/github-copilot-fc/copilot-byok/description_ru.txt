Настройте и переключайтесь между BYOK (Bring Your Own Key) провайдерами LLM как для GitHub Copilot CLI, так и для VS Code Chat. Используйте при настройке OpenAI, Azure OpenAI, Anthropic, Ollama, Moonshot, OpenCode Go, OpenRouter или других совместимых с OpenAI конечных точек; при создании или переключении переиспользуемых профилей провайдера для CLI; при переключении между несколькими учётными записями (API‑ключами) одного и того же провайдера; при конфигурации файла chatLanguageModels.json для VS Code; при расчёте переопределений максимального количества токенов в запросе или ответе; при настройке wire API и усилий рассуждения; или при устранении неполадок с переменными COPILOT_PROVIDER_BASE_URL, COPILOT_PROVIDER_TYPE, COPILOT_PROVIDER_API_KEY, COPILOT_MODEL, COPILOT_PROVIDER_WIRE_API, COPILOT_PROVIDER_MAX_PROMPT_TOKENS, COPILOT_PROVIDER_MAX_OUTPUT_TOKENS, COPILOT_OFFLINE и настройками языковой модели VS Code.

Пожалуйста, всегда отвечайте на языке пользователя.
