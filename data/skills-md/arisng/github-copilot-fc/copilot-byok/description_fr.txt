Configurez et basculez entre les fournisseurs LLM BYOK (Bring Your Own Key) pour le GitHub Copilot CLI et le VS Code Chat. Utilisez‑le lors de la configuration d’OpenAI, Azure OpenAI, Anthropic, Ollama, Moonshot, OpenCode Go, OpenRouter ou d’autres points de terminaison compatibles OpenAI ; créez ou changez de profils de fournisseur réutilisables pour le CLI ; passez d’un compte (clés API) à un autre pour le même fournisseur ; configurez le fichier chatLanguageModels.json pour VS Code ; calculez les dépassements de jetons de prompt ou de sortie maximum ; configurez l’API wire et l’effort de raisonnement ; ou dépannez les variables COPILOT_PROVIDER_BASE_URL, COPILOT_PROVIDER_TYPE, COPILOT_PROVIDER_API_KEY, COPILOT_MODEL, COPILOT_PROVIDER_WIRE_API, COPILOT_PROVIDER_MAX_PROMPT_TOKENS, COPILOT_PROVIDER_MAX_OUTPUT_TOKENS, COPILOT_OFFLINE et les paramètres du modèle de langage de VS Code.
