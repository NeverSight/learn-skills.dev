Konfigurieren und zwischen BYOK (Bring Your Own Key) LLM-Anbietern für sowohl GitHub Copilot CLI als auch VS Code Chat wechseln. Verwenden Sie dies beim Einrichten von OpenAI, Azure OpenAI, Anthropic, Ollama, Moonshot, OpenCode Go, OpenRouter oder anderen OpenAI‑kompatiblen Endpunkten; beim Erstellen oder Wechseln wiederverwendbarer Anbieterprofile für die CLI; beim Wechseln zwischen mehreren Konten (API‑Schlüsseln) für denselben Anbieter; beim Konfigurieren von chatLanguageModels.json für VS Code; beim Berechnen von Überschreibungen der maximalen Prompt‑ oder Ausgabe‑Token; beim Konfigurieren der Wire‑API und des Reasoning‑Aufwands; oder bei der Fehlersuche von COPILOT_PROVIDER_BASE_URL, COPILOT_PROVIDER_TYPE, COPILOT_PROVIDER_API_KEY, COPILOT_MODEL, COPILOT_PROVIDER_WIRE_API, COPILOT_PROVIDER_MAX_PROMPT_TOKENS, COPILOT_PROVIDER_MAX_OUTPUT_TOKENS, COPILOT_OFFLINE und den VS Code‑Einstellungen für Sprachmodelle.
