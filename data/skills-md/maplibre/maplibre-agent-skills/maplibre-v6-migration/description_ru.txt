Обновление приложения MapLibre GL JS с версии v5 до версии 6 — сборка только для ESM, удаленный экспорт по умолчанию, поломка CommonJS require(), изменение styleimagemissing/setMissingStyleImageResolver, удаление внутреннего файла map.transform, разделение MapDataEvent → MapSourceDataEvent/MapStyleDataEvent и требование setWorkerUrl() только для компоновщика. Используйте, когда приложение версии 5 выходит из строя после обновления до версии 6 или перед закреплением установки версии 6.
