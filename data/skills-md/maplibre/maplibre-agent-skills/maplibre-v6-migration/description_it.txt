Aggiornamento di un'app MapLibre GL JS dalla v5 alla v6: build solo ESM, esportazione predefinita rimossa, interruzione di CommonJS require(), modifica styleimagemissing/setMissingStyleImageResolver, rimozione del file map.transform interno, MapDataEvent → MapSourceDataEvent/MapStyleDataEvent divisione e requisito setWorkerUrl() solo bundler. Da utilizzare quando un'app v5 si interrompe dopo l'aggiornamento alla v6 o prima di bloccare un'installazione v6.
