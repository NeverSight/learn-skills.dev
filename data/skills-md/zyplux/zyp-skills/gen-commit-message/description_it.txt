Redigi un messaggio di commit per il progetto corrente ispezionando lo stato di Git (status, diff in staging, log recente) ed emettendo un messaggio che segua la specifica Conventional Commits v1.0.0. Usa questo ogni volta che l'utente esegue `/gen-commit-message`, richiede un messaggio di commit o un titolo per la PR, o sta per effettuare un commit senza averne scritto uno. Produci solo il messaggio — non eseguire `git commit` né mettere in stage i file.
