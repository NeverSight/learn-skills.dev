Redacte un mensaje de confirmación para el proyecto actual inspeccionando el estado de git (estado, diff por etapas, registro reciente) y emitiendo un mensaje que siga la especificación Conventional Commits v1.0.0. Use esto cada vez que el usuario ejecute /gen-commit-message, solicite un mensaje de confirmación o un título de PR, o esté a punto de confirmar y no haya escrito uno. Produzca solo el mensaje: no ejecute `git commit` ni archivos de etapa.
