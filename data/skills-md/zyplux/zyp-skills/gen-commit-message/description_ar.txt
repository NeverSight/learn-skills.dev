قم بكتابة مسودة رسالة ارتكاب للمشروع الحالي من خلال فحص حالة git (status، الفرق المراحل، السجل الأخير) وإصدار رسالة تتبع مواصفات Conventional Commits الإصدار 1.0.0. استخدم هذا كلما قام المستخدم بتشغيل /gen-commit-message، أو طلب رسالة ارتكاب أو عنوان PR، أو كان على وشك الارتكاب ولم يكتب واحدة. قدِّم الرسالة فقط — لا تُشغِّل `git commit` ولا تُعدِّ الملفات.

يرجى دائمًا الرد بلغة المستخدم.
