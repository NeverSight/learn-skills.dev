Entwerfen Sie eine Commit‑Nachricht für das aktuelle Projekt, indem Sie den Git‑Zustand (Status, gestagten Diff, letzten Log) prüfen und eine Nachricht ausgeben, die der Conventional Commits v1.0.0‑Spezifikation entspricht. Verwenden Sie dies immer, wenn der Nutzer /gen‑commit‑message ausführt, nach einer Commit‑Nachricht oder PR‑Titel fragt oder gerade committen will, aber noch keine geschrieben hat. Geben Sie nur die Nachricht aus – führen Sie keinen `git commit` aus und stellen Sie keine Dateien bereit.

Bitte antworten Sie immer in der Sprache des Benutzers.
