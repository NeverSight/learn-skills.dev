Verwandle einen groben Gedanken (vom Benutzer initiiert) oder eine umfangreiche Zwischenbeobachtung (vom Agenten initiiert) in ein nachverfolgtes GitHub‑Issue + Entwurf‑PR + Plan‑Artefakt, optimiert für die Übergabe an einen automatisch implementierenden Agenten. Kombiniert sich mit `/plan-storm` für die Storm‑Phase und liefert ein deterministisches CLI, das Vorlagen, Branches, PRs und einen Gist‑Fallback verwaltet. Verwende es, wenn der Benutzer `/stormitem [grobe Idee]` ausführt, wenn ein Agent auf eine Umgehung/Limitation stößt, die ein nachverfolgtes Issue rechtfertigt, oder beim Erfassen einer Funktionsanfrage gegen ein registriertes Repository.  

Bitte immer in der Sprache des Benutzers antworten.
