粗い考え（ユーザー発信）や豊かなタスク途中の観察（エージェント発信）を、追跡可能な GitHub Issue + 下書き PR + 計画アーティファクトに変換し、自動実装エージェントへの引き継ぎに最適化します。ストーミングフェーズでは `/plan‑storm` と連携し、テンプレート、ブランチ、PR、gist フォールバックを管理する決定的な CLI を提供します。ユーザーが `/stormitem [粗いアイデア]` を実行したとき、エージェントが回避策や制限に直面し追跡 Issue が必要なとき、または登録リポジトリに対する機能リクエストを記録するときに使用してください。

常にユーザーの言語で回答してください。
