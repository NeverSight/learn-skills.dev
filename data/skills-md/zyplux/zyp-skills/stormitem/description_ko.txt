거친 생각(사용자 기원)이나 풍부한 작업 중 관찰(에이전트 기원)을 추적된 GitHub 이슈 + 초안 PR + 계획 아티팩트로 전환하여 자동 구현 에이전트에게 인계하기에 최적화합니다. `/plan-storm`과 함께 폭풍 단계에 사용하고 템플릿, 브랜치, PR, 그리고 gist 대체를 관리하는 결정론적 CLI를 제공합니다. 사용자가 `/stormitem [거친 아이디어]`를 실행할 때, 에이전트가 우회/제한에 부딪혀 추적된 이슈가 필요할 때, 또는 등록된 레포에 대한 기능 요청을 캡처할 때 사용합니다.

항상 사용자의 언어로 응답하십시오.
