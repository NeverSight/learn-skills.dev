Convierte una idea preliminar (generada por el usuario) o una observación enriquecida a mitad de tarea (generada por el agente) en un issue rastreado de GitHub + PR borrador + artefacto de plan, optimizado para la entrega a un agente de autoimplementación. Se combina con `/plan‑storm` para la fase de tormenta y ofrece una CLI determinista que maneja plantillas, ramas, PRs y una alternativa de gist. Úsalo cuando el usuario ejecute `/stormitem [idea preliminar]`, cuando un agente encuentre una solución alternativa/limitación que justifique un issue rastreado, o al capturar una solicitud de funcionalidad contra un repositorio registrado.  

Por favor, responde siempre en el idioma del usuario.
