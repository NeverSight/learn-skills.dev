Trasforma un'idea grezza (originata dall'utente) o un'osservazione ricca a metà compito (originata dall'agente) in una issue di GitHub tracciata + una PR bozza + un artefatto di piano, ottimizzati per il passaggio a un agente di auto‑implementazione. Si combina con `/plan-storm` per la fase di brainstorming e fornisce una CLI deterministica che gestisce template, branch, PR e fallback su gist. Da utilizzare quando l'utente esegue `/stormitem [idea grezza]`, quando un agente incontra una soluzione alternativa/limite che richiede una issue tracciata, o quando si cattura una richiesta di funzionalità per un repository registrato.
