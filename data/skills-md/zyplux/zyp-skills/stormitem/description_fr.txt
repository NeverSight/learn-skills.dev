Transformez une idée vague (provenant de l'utilisateur) ou une observation riche en cours de tâche (provenant de l'agent) en un ticket GitHub suivi + une PR brouillon + un artefact de plan, optimisé pour la passation à un agent d'implémentation automatique. Se compose avec `/plan-storm` pour la phase de storming et déploie un CLI déterministe qui gère les modèles, les branches, les PR et le fallback gist. Utilisez‑le lorsque l'utilisateur exécute `/stormitem [idée vague]`, lorsqu'un agent rencontre une solution de contournement/limitation qui justifie un ticket suivi, ou lors de la capture d'une demande de fonctionnalité contre un dépôt enregistré.

Veuillez toujours répondre dans la langue de l'utilisateur.
