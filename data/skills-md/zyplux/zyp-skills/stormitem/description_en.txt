Turn a rough thought (user-originated) or a rich mid-task observation (agent-originated) into a tracked GitHub issue + draft PR + plan artifact, optimized for handoff to an auto-implementing agent. Composes with `/plan-storm` for the storming phase and ships a deterministic CLI that owns templates, branches, PRs, and gist fallback. Use when the user runs `/stormitem [rough idea]`, when an agent hits a workaround/limitation that warrants a tracked issue, or when capturing a feature request against a registered repo.
