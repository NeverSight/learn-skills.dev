Создавайте диаграммы Mermaid для markdown — flowchart’ы, диаграммы последовательностей, конечные автоматы, ER‑диаграммы, архитектурные схемы, диаграммы Ганта, Sankey, майндмэпы и более 20 других типов. Используйте их каждый раз, когда пользователь просит нарисовать, набросать, визуализировать, создать диаграмму, график или схему чего‑либо, что должно оказаться в markdown (README, документ дизайна, комментарий к коду, PR/issue, wiki) — даже если слово «mermaid» не упомянуто. Срабатывайте на запросы типа «нарисовать/показать поток/архитектуру/состояние/последовательность/отношения», «добавить flowchart/диаграмму последовательности», «схематизировать, как работает X», «построить схему», или каждый раз, когда пользователь предоставляет существующий блок mermaid для расширения или исправления. Выбор правильного типа диаграммы для вопроса важнее, чем владение синтаксисом — навык включает отобранный справочник по типам и синтаксису для каждого типа. НЕ используйте для производственных графиков из реальных данных (matplotlib, plotly, d3), формального моделирования архитектуры записи или когда пользователь хочет статическое изображение вместо markdown — Mermaid предназначен для объяснений, размещаемых рядом с текстом.

Пожалуйста, всегда отвечайте на языке пользователя.
