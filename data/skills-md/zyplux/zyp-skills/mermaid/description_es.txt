Genera diagramas Mermaid para markdown — diagramas de flujo, diagramas de secuencia, máquinas de estado, diagramas ER, arquitecturas, Gantt, Sankey, mapas mentales y más de 20 tipos diferentes. Úsalo siempre que el usuario solicite dibujar, esbozar, visualizar, diagramar, crear un gráfico o una tabla de cualquier cosa que termine en markdown (README, documento de diseño, comentario de código, PR/issue, wiki), incluso cuando no se mencione “mermaid”. Se activa con frases como “dibujar/mostrar el flujo/arquitectura/estado/secuencia/relación”, “añadir un diagrama de flujo/diagrama de secuencia”, “diagramar cómo funciona X”, “graficar el esquema”, o cualquier momento en que el usuario muestre un bloque mermaid existente para ampliarlo o corregirlo. Elegir el tipo de diagrama correcto para la pregunta es más importante que la fluidez de la sintaxis; la habilidad incluye una guía de selección curada y referencias de sintaxis por tipo. NO lo uses para gráficos de producción con datos reales (matplotlib, plotly, d3), modelado formal de arquitectura de registro, o cuando el usuario quiera una imagen estática en lugar de markdown — Mermaid es para explicaciones que viven junto al texto.

Por favor, responde siempre en el idioma del usuario.
