Ejecuta una sesión interactiva de lluvia de ideas que produzca y refine continuamente un archivo de plan (`plan/plan-<name>.md`) para un nuevo proyecto, característica o iniciativa. Cada ronda escribe/re‑escribe el plan, luego plantea hasta tres interacciones numeradas y ricas en opciones (aclaración, idea creativa, desafío o recomendación) y reporta un porcentaje de preparación que puede subir o bajar. Utiliza esta habilidad siempre que el usuario invoque `/plan‑storm`, diga “hagamos una lluvia de ideas de un plan / proyecto / característica”, quiera ayuda para pensar los requisitos antes de escribir cualquier código, presente una idea aproximada y pida ayuda para darle forma, o desee someter a prueba una idea con opciones y desafíos. Funciona para proyectos greenfield y para nuevas características dentro de proyectos existentes. NO uses esta habilidad una vez que exista un plan y el usuario ya esté implementándolo; úsalas solo en la etapa de lluvia de ideas / diseño.

Por favor, responde siempre en el idioma del usuario.
