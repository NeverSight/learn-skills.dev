Проверьте набор навыков Claude Code на предмет дублирования, устаревших технических ссылок и смещения названий/триггеров/объемов, а затем порекомендуйте сохранить/улучшить/обновить/вывести из употребления/объединить каждый из них. Используйте всякий раз, когда пользователь хочет просмотреть, очистить или подвести итоги своих навыков («проверить мои навыки», «перекрываются ли они», «подвести итоги», «какие навыки устарели»), особенно по мере роста коллекции.
