قم بمراجعة مجموعة من مهارات Claude Code بحثًا عن التداخل والمراجع الفنية القديمة وانجراف الاسم/المشغل/النطاق، ثم أوصي بالاحتفاظ/التحسين/التحديث/التقاعد/الدمج لكل منها. يُستخدم عندما يريد المستخدم مراجعة مهاراته أو تنظيفها أو تقييمها ("تدقيق مهاراتي"، "هل هذه متداخلة"، "جرد"، "ما هي المهارات التي لا معنى لها")، خاصة مع نمو المجموعة.
