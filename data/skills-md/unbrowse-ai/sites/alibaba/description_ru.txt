Алибаба (alibaba.com) для агентов: поиск товаров по ключевому слову; поиск alibaba.com — через ограниченный MCP Unbrowse для alibaba.com (неофициальный), который воспроизводит собственный первый‑партный API alibaba.com (без браузера, проверенные результаты). Используется, когда пользователь хочет что‑нибудь с alibaba.com, например поиск товаров по ключевому слову.
