Гутенберг (gutenberg.org) для агентов: Поиск gutenberg — через Scoped MCP Unbrowse для gutenberg.org (неофициальный), который воспроизводит собственный API первого уровня gutenberg.org (без браузера, проверенные результаты). Используйте, когда пользователь хочет что‑нибудь с gutenberg.org, например поиск gutenberg.

Пожалуйста, всегда отвечайте на языке пользователя.
