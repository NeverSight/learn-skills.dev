[Book Squeezer] extrait la connaissance complète d’un livre à partir de fichiers epub/pdf/md : modèles mentaux, concepts clés, citations mémorables, études de cas, anti‑patrons et listes de contrôle d’actions. Le processus est déclenché lorsque l’utilisateur fournit un fichier et dit « deconstruct », « distill » ou « squeeze » ; lorsqu’il dit « integrate », « merge deconstruction » ou « produce knowledge manual », il suit le pipeline d’intégration de contenu (déconstruction d’un seul livre → déconstruction par lot → manuel thématique chaîne complète). La convention de nommage extrait un titre de livre épuré comme nom de base (en supprimant les sous‑titres, les parenthèses, les redondances d’auteur tout en conservant les numéros de série) ; après la conversion, il nettoie automatiquement les balises HTML et les liens d’images cassés. Le chemin de sortie est lu depuis config.json (par défaut : knowledge‑base inbox/book deconstruction ; s’il n’existe pas, il est créé automatiquement).
