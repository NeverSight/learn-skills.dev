[Book Juicer] Extract the complete knowledge from epub/pdf/md files: mental models, key concepts, golden sentences, case studies, anti-patterns, and action checklists. It is triggered when the user provides a file and says “disassemble,” “distill,” or “juice.” When the user says “integrate,” “merge disassembly,” or “produce knowledge manual,” it follows the content integration pipeline (single‑book disassembly → batch disassembly → thematic manual full chain). Naming standardization extracts a clean book title as the base name (removing subtitles, parentheses, author redundancies, while retaining series numbers), and after conversion automatically cleans HTML tags and broken image links. The output path is read from config.json (default knowledge‑base inbox/book disassembly; created automatically if it does not exist).
