Crée un nouveau worktree git isolé dans le dossier `.worktrees/` du dépôt, avec sa propre branche, à partir d’une brève description du besoin ou du nom explicite de branche/dossier que l'utilisateur souhaite utiliser — pour pouvoir travailler sur plusieurs choses en parallèle sans faire de stash/checkout dans le même checkout. Utilise cette compétence lorsque l'utilisateur demande « crée un worktree », « nouveau worktree », « je veux travailler en parallèle », « isole cette fonctionnalité dans son propre dossier », « donne-moi un checkout séparé pour X », « lance un worktree pour Y », « new worktree », « work on multiple branches at once », « set up a parallel checkout », ou lorsqu'il mentionne explicitement le dossier `.worktrees/`.

Veuillez toujours répondre dans la langue de l'utilisateur.
