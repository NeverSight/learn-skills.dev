Convierte una imagen de referencia en un prompt de generación detallado con Mage, luego crea nuevas imágenes con ese aspecto: composición, sujeto, estilo, luz, cámara, materiales, color y ambiente se describen, y el prompt se entrega al modelo de imágenes. La aplicación Recreate como una habilidad. Uso cuando: “recrear esta imagen”, “qué prompt produciría esto”, “ingeniería inversa de esta foto”, “escribe un prompt a partir de esta imagen”, “hacer algo en este estilo”, “quiero este aspecto”, “variaciones de esta referencia”, “copiar esta vibra con mi propio sujeto”. NO para: editar la imagen misma (mage‑refine, mage‑inpaint), insertar a una persona o producto específico (mage‑character‑swap, mage‑product‑photoshoot), anuncios (mage‑ad‑multiplier), o copiar la semejanza de una persona real o la obra protegida de una marca.
