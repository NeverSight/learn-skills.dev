Transformez une image de référence en une invite de génération détaillée avec Mage, puis créez de nouvelles images dans ce même style : la composition, le sujet, le style, la lumière, la caméra, les matériaux, la couleur et l’ambiance sont décrits, et l’invite est transmise au modèle d’image. L’application Recreate comme compétence. À utiliser lorsque : « recréez cette image », « quelle invite donnerait cela », « rétroconcevoir cette image », « écrire une invite à partir de cette image », « créer quelque chose dans ce style », « je veux ce look », « variations sur cette référence », « copier cette ambiance avec mon propre sujet ». NON pour : la retouche de l’image elle‑même (mage‑refine, mage‑inpaint), insérer une personne ou un produit spécifique (mage‑character‑swap, mage‑product‑photoshoot), publicités (mage‑ad‑multiplier), ou copier le visage d’une personne réelle ou l’œuvre protégée d’une marque.

Veuillez toujours répondre dans la langue de l’utilisateur.
