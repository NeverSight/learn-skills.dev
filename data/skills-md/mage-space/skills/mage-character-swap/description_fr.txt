Remplacez la personne entière dans une image par un personnage différent en utilisant Mage, en conservant la scène, la pose, l’action et l’expression. L’application Échange de personnage comme compétence, sur Mango 3 par défaut. À utiliser quand : « échange de personnage », « remplacer la personne dans cette image par ce personnage », « mettre mon personnage dans cette scène », « échanger le sujet », « même prise mais avec cette personne à la place », « l’échange de visage a laissé une couture ». PAS pour : changer uniquement le visage (mage-face-swap), uniquement les vêtements (mage-outfit-swap), une personne dans une vidéo (mage-video-character-swap), une nouvelle pose ou une nouvelle scène (mage-generate avec le personnage), ou utiliser l’image d’une vraie personne sans son consentement.
