Échangez un visage d’une image sur la personne d’une autre avec Mage : toute la tête (visage, cheveux, peau, cou) est remplacée tandis que la pose, l’expression, les vêtements et l’arrière‑plan restent. L’application Face Swap en tant que compétence, sur Mango 3 par défaut. À utiliser quand : « face swap », « swap faces », « mettre ce visage sur cette photo », « mettre mon visage sur cette image », « remplacer le visage dans cette image », « corriger le visage dans cette image pour qu’il corresponde aux autres ». PAS pour : échanger un visage dans une vidéo (mage-video-face-swap), remplacer toute la personne, corps et tenue inclus (mage-character-swap), changer uniquement les vêtements (mage-outfit-swap), ou insérer une personne réelle dans quoi que ce soit sans son consentement.
