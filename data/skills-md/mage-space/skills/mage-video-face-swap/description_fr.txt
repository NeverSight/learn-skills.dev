Échangez un visage dans une vidéo avec Mage : la nouvelle identité (visage, cheveux, peau, cou) est appliquée à chaque image tandis que la pose, le mouvement, les expressions, les mouvements des lèvres, les vêtements et l’arrière‑plan d’origine restent. L’application Video Face Swap est disponible en tant que compétence, sur Cherry 2 Pro par défaut. À utiliser pour : « échange de visage vidéo », « échanger le visage dans cette vidéo », « mettre le visage de mon personnage sur ce clip », « mettre mon visage dans cette vidéo », « remplacer son visage dans la séquence », « le visage a dérivé dans ce clip, corrigez‑le ». PAS pour : les échanges de visage sur une image fixe (mage-face-swap), remplacer toute la personne avec le corps et la tenue (mage-video-character-swap), d’autres montages vidéo (mage-video-editor), la synchronisation labiale avec l’audio (mage-lipsync), ou mettre une personne réelle dans une vidéo sans son consentement.
