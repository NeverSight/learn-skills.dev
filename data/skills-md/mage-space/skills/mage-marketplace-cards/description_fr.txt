Images d’annonce sur les places de marché avec Mage : une image principale conforme sur fond blanc pur, images secondaires (infographie, multiples angles, détail, style de vie, contenu de la boîte) et modules A+ / contenu de marque amélioré, générés à partir d’une seule photo produit en conservant le produit exact. Mango 3 pour les photos produit, GPT Image 2.5 Flare pour les images avec texte. À utiliser pour : « images d’annonce Amazon », « images marketplace », « photos d’annonce produit », « image principale », « image à fond blanc », « infographie pour mon produit », « contenu A+ », « contenu de marque amélioré », « images secondaires », « ensemble d’images d’annonce », « images produit Etsy / Walmart / Shopify ». NON pour : photographie de marque ou sociale sans contexte d’annonce (utilisez mage‑product‑photoshoot), publicités statiques (mage‑ad‑multiplier), vidéos produit (mage‑ugc‑video) ou images sans produit (mage‑generate). Veuillez toujours répondre dans la langue de l’utilisateur.
