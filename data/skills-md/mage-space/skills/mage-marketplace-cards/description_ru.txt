Изображения листинга для маркетплейса с Mage: соответствующее главное изображение на чисто белом фоне, вторичные изображения (инфографика, несколько ракурсов, детали, лайфстайл, что находится в коробке) и модули A+ / улучшенного брендового контента, сгенерированные из одной фотографии продукта с точным сохранением продукта. Mango 3 для фотосъёмки продукта, GPT Image 2.5 Flare для изображений с текстом. Использовать, когда: «изображения листинга Amazon», «изображения для маркетплейса», «фотографии листинга продукта», «главное изображение», «изображение на белом фоне», «инфографика для моего продукта», «контент A+», «улучшенный брендовый контент», «вторичные изображения», «набор изображений листинга», «изображения товаров для Etsy / Walmart / Shopify». НЕ использовать для: брендовой или социальной фотографии без контекста листинга (использовать mage-product-photoshoot), статических реклам (mage-ad-multiplier), видеороликов продукта (mage-ugc-video) или изображений без продукта (mage-generate).

Пожалуйста, всегда отвечайте на языке пользователя.
