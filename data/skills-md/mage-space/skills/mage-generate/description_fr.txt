Générez des images, des vidéos et du son avec les modèles de Mage via le connecteur Mage (MCP) : choisissez le modèle approprié, indiquez le prix en Gemmes, générez, et attendez le résultat. Valeurs par défaut : Mango 3 pour les images, Cherry 2 Pro pour les vidéos, Seed Audio pour l’audio. À utiliser lorsqu’on dit : « générer une image », « faire une photo », « faire une vidéo », « animer cette image », « image en vidéo », « éditer cette image », « changer l’arrière‑plan », « créer de la musique », « effet sonore », « voix off », « le faire avec Mage », ou toute autre demande de création de médias avec Mage. Enchaînez avec mage‑characters pour garder une personne cohérente. NON destiné à : les séances photo de produits (utilisez mage‑product‑photoshoot), les images de fiches marketplace (mage‑marketplace‑cards), les variantes publicitaires, les redimensionnements ou traductions (mage‑ad‑multiplier, mage‑ad‑resizer, mage‑ad‑localizer), les vidéos produit UGC (mage‑ugc‑video), les vidéos narrées sans visage (mage‑faceless‑video), les miniatures YouTube (mage‑youtube‑thumbnail), ou les échanges, inpainting, re‑illumination, synchronisation labiale et modifications d’une vidéo existante (la compétence mage‑* correspondante). Veuillez toujours répondre dans la langue de l’utilisateur.
