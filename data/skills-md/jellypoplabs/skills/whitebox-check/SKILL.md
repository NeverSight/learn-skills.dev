# 白模自检

白模 = 一条灰白色的三维草稿动画，镜头怎么飞、东西放哪儿都在这里定好，再交给 AI 视频模型（小云雀 Seedance 2.5 等）换成真实画面。

这个 skill 来自一条纸飞机一镜到底视频，前后生成了十遍才跑通。下面每一项检查，都对应一次真实踩过的坑。

## 整个流程

1. **生成白模**：把 `templates/白模提示词.md` 里的提示词给你的 AI 编程助手，让它写 Blender 脚本出白模。电脑上要先装 Blender。
2. **白模自检**：`scripts/check_blend.py`（见下）。有问题让 AI 改，再检查，直到报告里没有「穿模」，「转太快」的地方心里有数。
3. **截关键帧**：同一个命令加 `--keyframes 5`，自动在镜头转得慢的时刻截图。也可以自己挑：每个不同画面的核心各一张。
4. **出参考图**：把关键帧放进小云雀的图片生成，图生图，提示里写「构图、镜头角度、地平线、所有物体的位置和大小和原图完全一致，只把灰白模型换成真实材质和光线」。
5. **叠图核对**：`scripts/overlay.py`，跑偏的那张重出。
6. **渲染**：小云雀视频生成 → Seedance 2.5 → 模式选**视频编辑**（不要用全能参考），传白模和参考图，提示词里写清楚每个灰白东西变成什么。先出 480P。
7. **扫描成片**：`scripts/scan_video.py`，没有跳帧、叠化再提升画质到 1080P。

## 1. 白模自检 `check_blend.py`

```bash
blender -b 白模.blend --python scripts/check_blend.py -- [--small 纸飞机,鸟] [--ignore 水面] [--keyframes 5] [--out 报告目录]
```

报告在 `whitebox_check/report.md`：

| 检查 | 为什么要查 | 怎么改 |
|---|---|---|
| 穿模 | 镜头钻进墙里，AI 会画成撞上去或切镜头 | 把那几秒的镜头路径挪开 |
| 贴太近（默认 0.8 米） | 贴着栏杆、墙面飞，AI 画出来像撞上了 | 拉开一点，或者让物体让开 |
| 转太快（默认每帧 3 度） | AI 会在急转弯停住几帧再跳到下一个构图。纸飞机那条两次跳帧（4.0 秒、4.3 秒）都在白模转得最快的 4.0 到 4.3 秒 | 把转弯拉长；这一段不要放参考图 |
| 小物体变成一条线 | 纸飞机侧着对镜头时几乎没有面积，AI 会把它画没 | 做成 V 形翅膀，或者调整它的朝向 |
| 每秒速度和转弯表 | 看节奏：哪里太快、哪里拖 | 按秒告诉 AI 改哪段 |

镜头离地/离水的高度看「贴太近」那一行：贴着水面飞也会报。

## 2. 叠图 `overlay.py`

```bash
python3 scripts/overlay.py 关键帧1.png 参考图1.png 关键帧2.png 参考图2.png --out 对比.png
```

每行：白模 / 参考图 / 叠加。看叠加那张的线有没有重合。常见跑偏：主体被画大、往上挪、镜头角度变了、多出太阳或彩虹（之后会在成片里闪一下）。

没有自动打分：试过按轮廓重合度打分，对的和错的配对分不开，会给假的「通过」。要用眼睛看，或者把对比图发给能看图的 AI。

参考图如果带「AI生成」之类的角标，先裁掉再喂给视频生成，否则模型会把角标也画进成片。

## 3. 成片扫描 `scan_video.py`

```bash
python3 scripts/scan_video.py 成片.mp4
```

- 列出画面变化最大的几帧。一处分数远高于其他（比第二名高一倍，或 6 以上）基本就是跳了：纸飞机 v8 那条 4.33 秒是 8.4，第二名才 5.4，其余都在 2 左右；跑通的那条最高 3.1。
- 每秒 10 帧的检查图 `sheet_*.png`：叠化（远景被慢慢换掉、人物变半透明）打分抓不到，只能看图。
- 分数最高的几处单独拼成逐帧图 `cut_*.png`。

## 经验（每条都是一次真实失败）

- **先有白模，再出参考图。** 先出参考图再照着搭白模，参考图的构图永远对不上白模某一秒的画面，模型会先照参考图画，再跳回白模（硬切或叠化）。从白模截关键帧图生图，构图天生对齐。
- **镜头转得快的地方不放参考图。** 两张参考图之间镜头转了几十度，模型补不出中间过程。
- **用视频编辑模式，不用全能参考（参考生成）。** 全能参考会把白模和参考图都当参考自己再发挥一遍；视频编辑是在白模上直接换材质，镜头跟得更紧。视频编辑的比例和时长跟着白模走。
- **提示词里点名每个灰白物体是什么。** 一根竖着的白条，AI 认成了「桥」还要删掉；写明「这是瀑布，不是桥，不能删」。
- **先 480P，满意了再提升画质。**
- **成片要逐帧看，不只看切点检测。** 叠化是慢慢变的，切点检测抓不到。

## 需要

- Blender 4.x（命令行 `blender` 或 `/Applications/Blender.app/Contents/MacOS/Blender`）
- ffmpeg（scan_video.py）
- Python 3 + Pillow（overlay.py）
