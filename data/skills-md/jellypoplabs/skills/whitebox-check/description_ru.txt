Самопроверка белой модели. Используется при управлении движением камеры ИИ‑видео с помощью белого бокса в Blender (серо‑белый 3D‑набросок): после создания белого бокса, перед созданием референсных изображений, перед отправкой его в Xiaoyunque/Seedance для рендеринга и после получения конечного видеоматериала. Проверяйте наличие клиппинга, слишком близко расположенных объектов, чрезмерно быстрых вращений, мелких объектов, которые исчезают при боковом виде; автоматически выбирайте ключевые кадры, накладывайте изображения для проверки референсных картинок и сканируйте финальное видео на наличие склейок. Применяется при построении белого бокса (серого блок‑аут) в Blender для управления камерой модели ИИ‑видео, перед рендерингом в Seedance / 小云雀 и для сканирования полученного видео на склейки.
