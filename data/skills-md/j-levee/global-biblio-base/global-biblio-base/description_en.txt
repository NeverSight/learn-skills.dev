Global 1.2 billion-document knowledge base (80 million downloadable Chinese journals) — provides Chinese and foreign academic literature search and download capabilities via the SmartLib open platform API, covering 80 million full‑text authorized Chinese journals plus 1.228 billion global document metadata (journals 719 million / patents 215 million / conferences 71.55 million / dissertations 24.73 million / standards 2.68 million).

Capabilities: Chinese and English keyword search, document details, full‑text PDF download of Chinese journals, free download of foreign OA literature through ten‑level channels (no quota consumption), intelligent keyword expansion, core‑journal priority sorting, relevance re‑ranking, citation tracing, classification‑number search.

Quota: Automatic registration on first use, free 100 searches + 10 downloads per month; when exhausted, a package automatically pops up (trial card / personal monthly / professional monthly / single download / download bundle), which can be invoked by saying “upgrade / recharge”; corporate/institution custom contact vipsmart@vipslib.com.

Trigger: Activated when a user expresses intents such as “search paper”, “find literature”, “academic search”, “search journal”, “search patent”, “find standard”, “download paper”, “write literature review”, “find references”, “search SCI/EI”, etc.; also applies to phrases like “help me find papers about XX”, “write literature review”, “find a few citations to support arguments”. English examples: “find papers”, “search literature”, “write literature review”, “find supporting citations”.

Before calling, you must first use /consume to obtain a consume_token, then use the token to call /search (each billed API call requires a /consume).
