قاعدة معرفة عالمية تضم 1.2 مليار وثيقة (80 مليون مجلة صينية قابلة للتحميل) — توفر إمكانية البحث وتحميل الأدبيات الأكاديمية الصينية والأجنبية عبر واجهة برمجة التطبيقات لمنصة SmartLib المفتوحة، وتغطي 80 مليون مجلة صينية بنص كامل مرخص بالإضافة إلى 1.228 مليار من بيانات الأدبيات العالمية (مجلات 719 مليون / براءات اختراع 215 مليون / مؤتمرات 71.55 مليون / رسائل ماجستير ودكتوراه 24.73 مليون / معايير 2.68 مليون).

القدرات: بحث بالكلمات المفتاحية بالصينية والإنجليزية، عرض تفاصيل الوثائق، تحميل ملفات PDF بنص كامل للمجلات الصينية، تحميل مجاني للأدبيات المفتوحة الأجنبية عبر عشرة مسارات (دون استهلاك الحصة)، توسيع ذكي للكلمات المفتاحية، ترتيب أولوية للمجلات الأساسية، إعادة ترتيب حسب الصلة، تتبع الاستشهادات، بحث حسب رقم التصنيف.

الحصة: التسجيل التلقائي عند أول استخدام، 100 عملية بحث مجانية + 10 عمليات تحميل شهريًا؛ عند استنفادها، تظهر حزمة تلقائيًا (بطاقة تجريبية / شهرية شخصية / شهرية احترافية / تحميل وثيقة واحدة / حزمة تحميل)، يمكن تفعيلها بقول “ترقية / شحن”. للتخصيص للمؤسسات/الجامعات يرجى التواصل عبر vipsmart@vipslib.com.

المحفز: يتم التفعيل عندما يُظهر المستخدم نوايا مثل “بحث عن ورقة”، “البحث عن أدبيات”، “بحث أكاديمي”، “البحث عن مجلات”، “بحث عن براءة اختراع”، “البحث عن معيار”، “تحميل ورقة”، “كتابة مراجعة أدبية”، “العثور على مراجع”، “بحث SCI/EI”، إلخ؛ ويشمل أيضًا “ساعدني في العثور على أوراق حول XX”، “اكتب مراجعة أدبية”، “اعثر على بعض الاستشهادات لدعم الحجة”. المرادفات الإنجليزية: “find papers”، “search literature”، “write literature review”، “find supporting citations”.

قبل الاستدعاء، يجب أولاً استخدام /consume للحصول على consume_token، ثم استخدام هذا الرمز لاستدعاء /search (كل مكالمة API مُحاسبة تتطلب استهلاكًا مسبقًا عبر /consume).
