1.2 十億件の文書（80 百万件の中国語ジャーナルがダウンロード可能）からなるグローバルナレッジベース – SmartLib オープンプラットフォーム API を通じて、中国語および外国語の学術文献検索・ダウンロード機能を提供し、80 百万件の全文許可済み中国語ジャーナル記事と 1.228 十億件の世界的文書メタデータ（ジャーナル 719 百万件／特許 215 百万件／会議 71.55 百万件／学位論文 24.73 百万件／標準 2.68 百万件）をカバー。

機能：中文・英語のキーワード検索、文書詳細、中文ジャーナルの全文 PDF ダウンロード、10 段階チャネルを通じた外国 OA 文献の無料ダウンロード（クォータを消費しない）、インテリジェントなキーワード展開、コアジャーナルの優先順位付け、関連性再ランク付け、引用追跡、分類番号検索。

クォータ：初回利用時に自動登録、月間無料検索 100 回＋ダウンロード 10 回。枯渇するとパッケージが自動で提示される（トライアルカード／個人月額／プロフェッショナル月額／単体ダウンロード／ダウンロードバンドル）。「upgrade」や「recharge」と言えば呼び出せる。企業・機関向けのカスタム契約は vipsmart@vipslib.com へお問い合わせください。

トリガー：ユーザーが「論文を検索」「文献を探す」「学術検索」「ジャーナルを検索」「特許を検索」「標準を探す」「論文をダウンロード」「文献レビューを書きたい」「参考文献を探す」「SCI/EI を検索」などの意図を示したときに発動。また「XX に関する論文を探して」「文献レビューを書いて」「議論を裏付ける引用を数件見つけて」などにも適用。英語例： “find papers”, “search literature”, “write literature review”, “find supporting citations”。

呼び出す前に、まず /consume を使用して consume_token を取得し、そのトークンで /search を呼び出す必要があります（課金 API 呼び出しは事前に /consume が必要）。

常にユーザーの言語で応答してください。
