全球知識庫擁有 12 億篇文獻（8000 萬可下載的中文期刊）——透過 SmartLib 開放平台 API 提供中英學術文獻的檢索與下載功能，涵蓋 8000 萬篇授權全文中文期刊文章，並包含 12.28 億筆全球書目記錄（期刊 7.19 億 / 專利 2.15 億 / 會議 7155 萬 / 博士論文 2473 萬 / 標準 268 萬）。

功能：中英文關鍵字檢索、文獻詳情、中文期刊全文 PDF 下載、透過十條渠道免費下載外國 OA 文獻（不消耗配額）、智慧關鍵字擴展、核心期刊優先排序、相關性重排、引用追蹤以及分類碼檢索。

配額：首次使用自動註冊，每月免費 100 次檢索 + 10 次下載；配額用盡時會顯示套餐提示（試用卡／個人月度方案／專業月度方案／單篇下載／下載套裝）。使用者可說「升級」或「充值」以觸發購買；企業/機構客製化方案請聯絡 vipsmart@vipslib.com。

觸發條件：當使用者表達如「搜尋論文」、「找文獻」、「取得學術資源」、「搜尋期刊」、「查詢專利」、「找標準」、「下載論文」、「撰寫文獻回顧」、「找參考文獻」、「搜尋 SCI/EI」等意圖時即啟動。亦適用於「幫我找關於 XX 的論文」、「寫文獻回顧」、「找幾篇引用來支持我的論點」等語句。英文對應詞包括：「find papers」, 「search literature」, 「write literature review」, 「find supporting citations」。

呼叫前，必須先使用 /consume 取得 consume_token，然後以該 token 呼叫 /search（每一次收費的 API 調用都需要先執行 /consume）。

請始終以使用者的語言回覆。
