Глобальная база знаний из 1,2 млрд документов (80 млн китайских журналов доступных для скачивания) — обеспечивает поиск и загрузку китайской и иностранной академической литературы через открытый API платформы SmartLib, охватывая 80 млн полных авторизованных китайских журналов плюс 1,228 млрд глобальных метаданных документов (журналы 719 млн / патенты 215 млн / конференции 71,55 млн / диссертации 24,73 млн / стандарты 2,68 млн).

**Возможности:** поиск по ключевым словам на китайском и английском, детали документа, загрузка PDF полных текстов китайских журналов, бесплатная загрузка иностранной открытой литературы через десятки каналов (не расходует квоту), интеллектуальное расширение ключевых слов, приоритетная сортировка основных журналов, переранжирование релевантности, отслеживание цитат, поиск по классификационному номеру.

**Квота:** при первом использовании происходит автоматическая регистрация, бесплатно 100 поисков + 10 загрузок в месяц; после исчерпания появляется автоматическое предложение пакета (пробный билет / личный месячный / профессиональный месячный / покупка одной загрузки / пакет загрузок), которое можно активировать, сказав «upgrade / recharge»; индивидуальные условия для предприятий/учреждений — писать на vipsmart@vipslib.com.

**Триггер:** активируется, когда пользователь выражает намерения типа «search paper», «find literature», «search academic», «search journal», «search patent», «find standard», «download paper», «write literature review», «find reference», «search SCI/EI» и т.п.; также подходит к запросам «help me find papers about XX», «write a literature review», «find a few citations to support a point». Эквиваленты на английском: «find papers», «search literature», «write literature review», «find supporting citations».

**Процедура вызова:** перед вызовом получить `consume_token` через `/consume`, затем использовать токен для вызова `/search` (каждый оплачиваемый API‑вызов требует предварительного `/consume`).
