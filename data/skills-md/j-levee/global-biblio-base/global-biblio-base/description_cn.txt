全球12 亿文献知识库（8000 万可下载中文期刊）——通过 SmartLib 开放平台 API 提供中外学术文献检索与下载功能，覆盖 8000 万全文授权中文期刊以及 12.28 亿全球文献元数据（期刊 7.19 亿 / 专利 2.15 亿 / 会议 7,155 万 / 学位论文 2,473 万 / 标准 268 万）。  

功能特点：中英文关键词检索、文献详情查询、中文期刊全文 PDF 下载、通过十层渠道免费下载国外 OA 文献（不消耗配额）、智能关键词扩展、核心期刊优先排序、相关度再排序、引文追踪、分类号检索。  

配额规则：首次使用自动注册，免费每月可进行 100 次检索 + 10 次下载；配额用尽后系统自动弹出套餐（试用卡 / 个人月卡 / 专业月卡 / 单次下载 / 下载包），可通过说“升级/充值”进行调用；企业/机构定制请联系 vipsmart@vipslib.com。  

触发方式：当用户表达如“搜索论文”“查找文献”“学术搜索”“检索期刊”“检索专利”“查找标准”“下载论文”“写文献综述”“找参考文献”“检索 SCI/EI”等意图时即激活；也适用于“帮我找关于 XX 的论文”“写文献综述”“找几条引用支持论点”等表述。英文示例：“find papers”“search literature”“write literature review”“find supporting citations”。  

调用前须先使用 /consume 获取 consume_token，再使用该 token 调用 /search（每一次计费的 API 调用都需要先 /consume）。  

请始终使用用户语言作答。
