Utilisez cette compétence pour toutes les opérations d'écriture GitHub dans les référentiels d'organisations de conception graphique créative (tels que les générateurs de conception), y compris les validations et les poussées Git, la création et les mises à jour de relations publiques, les commentaires sur les problèmes et les relations publiques, les étiquettes, les jalons et les fusions demandées par l'utilisateur. Exécutez-les en tant qu'utilisateur de la machine de création-conception-graphique-développement. Utilisez-le à la fois lorsque l'utilisateur demande explicitement le compte de bot ou de développement et chaque fois que vous commencez un travail d'écriture dans un référentiel d'organisation de conception graphique et créative sans demande explicite ; ne l'utilisez jamais dans les référentiels d'une autre organisation ou d'un autre hôte.
