استخدم هذه المهارة لجميع عمليات الكتابة على GitHub في مستودعات مؤسسات التصميم الجرافيكي الإبداعي (مثل مولدات التصميم)، بما في ذلك التزامات git ودفعاتها، وإنشاء العلاقات العامة وتحديثاتها، وتعليقات المشكلات والعلاقات العامة، والتسميات، والمعالم الرئيسية، وعمليات الدمج التي يطلبها المستخدم. قم بتنفيذها كمستخدم لجهاز تصميم الرسوم البيانية الإبداعية. استخدمه عندما يطلب المستخدم صراحةً حساب الروبوت أو حساب المطور، وعندما يبدأ العمل في الكتابة في مستودع مؤسسة التصميم الجرافيكي الإبداعي دون طلب صريح؛ لا تستخدمه مطلقًا في مستودعات أي منظمة أو مضيف آخر.
