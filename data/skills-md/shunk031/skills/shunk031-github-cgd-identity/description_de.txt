Verwenden Sie diese Fähigkeit für alle GitHub-Schreibvorgänge in Repositorys von Organisationen für kreatives Grafikdesign (z. B. Designgeneratoren), einschließlich Git-Commits und -Pushes, PR-Erstellung und -Updates, Problem- und PR-Kommentare, Beschriftungen, Meilensteine ​​und vom Benutzer angeforderte Zusammenführungen. Führen Sie sie als Benutzer der Maschine „creative-graphic-design-dev“ aus. Verwenden Sie es sowohl, wenn der Benutzer explizit das Bot- oder Entwicklerkonto anfordert, als auch immer dann, wenn Sie ohne explizite Anfrage mit der Schreibarbeit in einem Repository einer Organisation für kreatives Grafikdesign beginnen. Verwenden Sie es niemals in Repositorys einer anderen Organisation oder eines anderen Hosts.
