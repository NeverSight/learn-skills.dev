Utilizza questa competenza per tutte le operazioni di scrittura di GitHub nei repository di organizzazioni di progettazione creativa-grafica (come i generatori di design), inclusi commit e push git, creazione e aggiornamenti di PR, commenti su problemi e PR, etichette, traguardi e unioni richieste dagli utenti. Eseguili come utente della macchina di sviluppo creatività-grafica-progettazione. Usalo sia quando l'utente richiede esplicitamente il bot o l'account dev sia ogni volta che inizi a scrivere un lavoro in un repository di organizzazioni di design creativo-grafico senza una richiesta esplicita; non utilizzarlo mai nei repository di qualsiasi altra organizzazione o host.
