Прикрепляйте локальные файлы к задаче GitHub или комментарию запроса на включение через Playwright CLI и возвращайте размещенные URL-адреса вложений, не отправляя комментарий. Используйте, если вам нужны URL-адреса изображений или документов, размещенных на GitHub, на github.com или GitHub Enterprise Server.
