Récupérez les données du tableau KIS-NET YTM coréen via l'interface en ligne de commande autonome ytm ou le SDK Node @sjunepark/ytm. Utilisez-le lorsque les demandes portent sur les rendements des obligations KIS-NET pour une date, l'historique des rendements sur plusieurs dates ou les N dernières observations, ou les types d'obligations pris en charge. Exclut les calculs généraux de rendement à l'échéance, les conseils en investissement, les autres fournisseurs de données et la maintenance du dépôt.

Veuillez toujours répondre dans la langue de l'utilisateur.
