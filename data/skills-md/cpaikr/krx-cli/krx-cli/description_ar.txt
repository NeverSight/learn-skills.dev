استعلم وحلّل بيانات سوق بورصة كوريا (KRX) عبر واجهة الأوامر الأصلية krx CLI. استخدم ذلك عندما يطلب المستخدمون أسعار الأسهم الكورية، مؤشرات KOSPI/KOSDAQ، أو بيانات ETF/ETN/ELW، السندات، المشتقات، السلع، أو بيانات ESG الخاصة بـ KRX؛ وكذلك استخدام أوامر krx، الإعداد، عمليات التخزين المؤقت أو الحالة المحلية؛ أو حالة المصادقة على KRX وموافقة الخدمة، حتى بدون تسمية هذه المهارة. استخدم أيضاً للطلبات السريعة لتقديم طلبات الوصول إلى خدمة KRX Open API عبر علامة تبويب متصفح مصدّقة ومفوّضة من قبل المستخدم، بما يشمل جميع النقاط النهائية الحالية أو غير المعتمدة أو مجموعة فرعية تتطلب توضيحًا. قم بتوجيه الأسئلة التي تتعلق بالحالة فقط حصريًا إلى فرع CLI. لا تستخدم لهذا الغرض لتقديم نصائح استثمارية عامة، أو بيانات أسواق غير KRX، أو تسجيل حساب، أو إدخال بيانات اعتماد أو OTP، أو حل أو تجاوز CAPTCHA، أو حذف أو تجديد أو إعادة إصدار مفتاح API.  

يرجى دائمًا الرد بلغة المستخدم.
