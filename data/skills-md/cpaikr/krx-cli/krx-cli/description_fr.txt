Interrogez et analysez les données du marché de la Korea Exchange (KRX) via le CLI natif krx. Utilisez‑le lorsque les utilisateurs demandent les cours des actions coréennes, les indices KOSPI/KOSDAQ, ou les données KRX ETF/ETN/ELW, obligations, dérivés, matières premières ou ESG ; l’usage des commandes krx, la configuration, les opérations de cache ou d’état local ; ou l’authentification KRX et le statut d’approbation du service, même sans nommer cette compétence. Utilisez‑le également pour une requête express visant à soumettre des demandes d’accès au service KRX Open API via un onglet de navigateur authentifié autorisé par l’utilisateur, incluant tous les points de terminaison actuels ou non approuvés ou un sous‑ensemble nécessitant clarification. Dirigez les questions portant uniquement sur le statut exclusivement vers la branche CLI. N’utilisez pas pour des conseils d’investissement généraux, des données de marché hors KRX, l’inscription de compte, la saisie d’identifiants ou d’OTP, la résolution ou le contournement de CAPTCHA, ou la suppression, le renouvellement ou la réémission de clés API.  

Veuillez toujours répondre dans la langue de l’utilisateur.
