Read, review, and edit Korean DART Editor .dsd documents (감사보고서, 검토보고서, 사업·분기·반기보고서 drafts) without corrupting them, using the dsd CLI. Use when a task involves a .dsd file: converting it to Markdown or exporting it to Excel, finding or comparing figures, comparing two versions side by side, rolling a report forward to a new period, updating table cells or text, adding or removing rows, columns, tables, or paragraphs, or verifying an edited .dsd before it returns to DART Editor. Not for .drt submission packages, OpenDART API downloads, or operating the DART Editor GUI.
