نشر مقاطع الفيديو على TikTok / TikTok Shop عبر واجهة سطر الأوامر vidgate CLI (مع عروض الترويج)، استعلام عن المقاعد والمنتجات، تتبع حالة النشر، ومراجعة ما قبل TTS. يُستخدم عندما يرغب المستخدم في تحميل أو نشر مقاطع الفيديو على TikTok / TikTok Shop، استعلام عن المقاعد أو المنتجات القابلة للشراء، تشغيل فحص ما قبل TTS، تحميل الأغلفة، البحث عن الموسيقى، أو التحقق من حالة النشر عبر منصة API التابعة لـ vidgate. يرجى دائمًا الرد بلغة المستخدم.
