通过 vidgate CLI 发布视频到 TikTok / TikTok Shop（挂车带货）、查询坐席与商品、跟踪发布状态、TTS 预审。Se utiliza cuando el usuario desea subir o publicar videos en TikTok / TikTok Shop, consultar asientos o productos comprables, ejecutar la verificación previa de TTS, subir portadas, buscar música o verificar el estado de publicación a través de la plataforma API de vidgate.
