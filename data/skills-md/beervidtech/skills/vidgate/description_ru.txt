Через vidgate CLI публикуйте видео в TikTok / TikTok Shop (продажи через подвешенные объявления), запрашивайте места и товары, отслеживайте статус публикации, выполняйте предварительную проверку TTS. Используется, когда пользователь хочет загрузить или опубликовать видео в TikTok / TikTok Shop, запросить места или продаваемые товары, запустить предварительную проверку TTS, загрузить обложки, искать музыку или проверить статус публикации через платформу API vidgate.
