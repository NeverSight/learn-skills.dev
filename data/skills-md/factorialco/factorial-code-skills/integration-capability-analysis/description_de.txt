Analysiert die API oder Dateispezifikation eines Drittanbieters anhand des Integrationsrahmens von Factorial und erstellt ein detailliertes Integrations‑Mapping‑Dokument – die Integrationsdomäne (Lohn‑ oder Finanzbereich), jede Fähigkeit in dieser Domäne mit ihrem Ergebnis (vollständig, teilweise oder nicht unterstützt), die jeweiligen Vendor‑Endpunkte und das Feld‑zu‑Feld‑Mapping zwischen Factorials API und der des Anbieters. Verwende es, wann immer jemand eine Vendor‑API‑Spezifikation, OpenAPI/Swagger‑Datei, Entwickler‑Portal‑Link, Integrationsanleitung oder Dateistruktur teilt und wissen möchte, was wir dagegen bauen könnten, wie es zuzuordnen ist, ob eine Integration machbar ist, oder nach Integrations‑Scoping, einer Fit‑Gap‑Bewertung oder einem Feld‑Mapping fragt. Nutze es auch bei informellen Anfragen („Können wir damit integrieren?“, „Wie würden neueinstellungen zur API des Anbieters gemappt?“) und bei partiellen Spezifikationen.
