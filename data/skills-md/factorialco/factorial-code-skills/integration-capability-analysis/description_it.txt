Analizza l'API o la specifica dei file di un sistema di terze parti rispetto al framework di integrazione di Factorial e produce un documento dettagliato di mappatura dell'integrazione — il dominio dell'integrazione (paghe o finanza), ogni capacità in quel dominio con il suo esito (completamente, parzialmente o non supportato), gli endpoint del fornitore da utilizzare per ciascuna, e la mappatura campo per campo tra l'API di Factorial e quella del fornitore. Usalo ogni volta che qualcuno condivide una specifica API del fornitore, un file OpenAPI/Swagger, un link al portale sviluppatori, una guida all'integrazione o il layout di un file e vuole sapere cosa potremmo costruire su di esso, come mapparlo, se un'integrazione è fattibile, o richiede una definizione dell'ambito dell'integrazione, una valutazione fit‑gap o una mappatura dei campi. Utilizzalo anche per richieste informali (“possiamo integrare con questo?”, “come verrebbero mappati i nuovi assunti nella loro API?”) e per specifiche parziali.
