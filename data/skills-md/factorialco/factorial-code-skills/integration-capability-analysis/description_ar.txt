يُحلل واجهة برمجة تطبيقات أو مواصفات ملف نظام تابع لجهة خارجية مقابل إطار عمل التكاملات الخاص بـ Factorial ويُنتج مستندًا تفصيليًا لتخطيط التكامل — مجال التكامل (الرواتب أو المالية)، كل قدرة في ذلك المجال مع حكمها (مدعومة بالكامل، مدعومة جزئيًا أو غير مدعومة)، نقاط النهاية الخاصة بالبائع لاستخدامها لكل منها، وتطابق الحقول خطوة بخطوة بين واجهة برمجة تطبيقات Factorial وواجهة البائع. استخدمه كلما شارك شخص ما مواصفات واجهة برمجة تطبيقات للبائع، ملف OpenAPI/Swagger، رابط بوابة المطورين، دليل التكامل أو مخطط الملف ويرغب في معرفة ما يمكننا بناؤه بناءً عليه، كيفية ربطه، ما إذا كان التكامل قابلًا للتنفيذ، أو يطلب تحديد نطاق التكامل، تقييم الفجوة أو تطابق الحقول. استخدمه حتى للطلبات غير الرسمية ("هل يمكننا التكامل مع هذا؟"، "كيف سيُطابق الموظفون الجدد مع واجهة برمجة التطبيقات الخاصة بهم؟") وللمواصفات الجزئية. يرجى دائمًا الرد بلغة المستخدم.
