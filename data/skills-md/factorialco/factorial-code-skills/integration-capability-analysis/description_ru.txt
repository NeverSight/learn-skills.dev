Анализирует API или файловую спецификацию сторонней системы в соответствии с фреймворком интеграций Factorial и создает подробный документ по сопоставлению интеграции — домен интеграции (заработная плата или финансы), каждую возможность в этом домене с её оценкой (полностью, частично или не поддерживается), конечные точки поставщика, которые следует использовать для каждой, а также послойное сопоставление полей между API Factorial и API поставщика. Используйте, когда кто‑то делится спецификацией API поставщика, файлом OpenAPI/Swagger, ссылкой на портал разработчиков, руководством по интеграции или схемой файлов и хочет понять, что мы можем построить на её основе, как её сопоставить, возможна ли интеграция, либо запрашивает определение объёма интеграции, оценку соответствия/разрыва или сопоставление полей. Применяйте также к неформальным запросам («можем ли мы интегрировать это?», «как новые сотрудники сопоставляются с их API?») и частичным спецификациям. Пожалуйста, всегда отвечайте на языке пользователя.
