Откройте процесс Factorial Code для Factorial как Factorial Action — блок `factorial` в metadata.json процесса (главный переключатель, awaitResult, requiredPolicies и точки входа uiTrigger / form / agentTool / backend), контракт инструмента Factorial One (description, effect, whenToUse, whenNotToUse, preconditions, doesNotDo, degradation, simulatesFor), зарезервированные слаги жизненного цикла, схему параметров как контракт с Factorial и то, как наследуемые блоки `form` / uiTrigger` сохраняются зеркально. Используйте при настройке того, как Factorial достигает процесса, написании контракта инструмента‑агента или заполнении раздела «Trigger from Factorial» процесса.
