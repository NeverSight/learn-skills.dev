Esporre un processo Factorial Code a Factorial come un’Azione Factorial — il blocco `factorial` nel file metadata.json di un processo (interruttore principale, awaitResult, requiredPolicies e i punti di ingresso uiTrigger / form / agentTool / backend), il contratto dello strumento Factorial One (description, effect, whenToUse, whenNotToUse, preconditions, doesNotDo, degradation, simulatesFor), i slug di ciclo di vita riservati, lo schema dei parametri come contratto con Factorial e il modo in cui i blocchi legacy `form` / uiTrigger sono mantenuti speculari. Usare quando si configura come Factorial raggiunge un processo, si redige un contratto di strumento agente o si compila la sezione “Trigger from Factorial” di un processo.
