将 Factorial Code 流程以 Factorial Action 的形式暴露给 Factorial —— 即在流程的 metadata.json 中的 `factorial` 区块（包括 master switch、awaitResult、requiredPolicies，以及 uiTrigger / form / agentTool / backend 入口），Factorial One 工具合约（包括 description、effect、whenToUse、whenNotToUse、preconditions、doesNotDo、degradation、simulatesFor），保留的生命周期 slug，作为与 Factorial 合同的参数模式，以及如何将传统的 `form` / `uiTrigger` 区块保持镜像。用于配置 Factorial 如何触达流程、编写 agent tool 合约，或填写流程的 “Trigger from Factorial” 部分时。
