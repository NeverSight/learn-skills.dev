Exponer un proceso de Factorial Code a Factorial como una Acción Factorial — el bloque `factorial` en el metadata.json de un proceso (master switch, awaitResult, requiredPolicies y los puntos de entrada uiTrigger / form / agentTool / backend), el contrato de herramienta Factorial One (description, effect, whenToUse, whenNotToUse, preconditions, doesNotDo, degradation, simulatesFor), los slugs de ciclo de vida reservados, el esquema de parámetros como el contrato con Factorial, y cómo los bloques heredados `form` / `uiTrigger` se mantienen reflejados. Utilícelo al configurar cómo Factorial llega a un proceso, al redactar un contrato de herramienta de agente o al completar la sección “Trigger from Factorial” de un proceso.
