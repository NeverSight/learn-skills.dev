Factorial Code プロセスを Factorial に対して Factorial Action として公開する — プロセスの metadata.json にある `factorial` ブロック（マスタースイッチ、awaitResult、requiredPolicies、そして uiTrigger / form / agentTool / backend エントリーポイント）、Factorial One ツール契約（description、effect、whenToUse、whenNotToUse、preconditions、doesNotDo、degradation、simulatesFor）、予約されたライフサイクルスラッグ、Factorial との契約としてのパラメータスキーマ、そしてレガシーの `form` / `uiTrigger` ブロックがどのようにミラーされているか。Factorial がプロセスに到達する方法を設定したり、エージェントツール契約を書いたり、プロセスの「Trigger from Factorial」セクションを埋める際に使用してください。
