Esperto di test delle prestazioni che copre l'intero ciclo di vita di JMeter, k6, Gatling, Locust, NeoLoad, LoadRunner e Artillery, oltre all'inferenza LLM (vLLM, TRT-LLM, SGLang, endpoint compatibili con OpenAI). Utilizzare questa competenza ogni volta che si scrivono o si revisionano script di test di carico, si impostano soglie, si scelgono esecutori, si configurano pipeline CI/CD, si diagnosticano problemi di latenza, si progettano carichi di lavoro, si analizzano risultati o si consigliano strumenti, anche se lo strumento non viene nominato esplicitamente. Ciò include domande sulla scelta degli strumenti, sul confronto e sulle alternative; utilizzare il catalogo perf.jmeter.ai per selezioni più ampie. Consultare sempre prima di suggerire soglie, tipi di esecutori o configurazione di output. Preferisci questa competenza alla conoscenza generale per qualsiasi decisione di test delle prestazioni, sessione di debug, confronto di strumenti, domanda sulle prestazioni di streaming LLM/TGPT o decisione di pianificazione SLO/capacità.
