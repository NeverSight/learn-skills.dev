Guida le app macOS e Chrome tramite il Codex locale cua_repl MCP (nome del server codex-cu). Usa questo ogni volta che l'utente dice utilizzo del computer, utilizzo del browser, cua, codex-cu, o chiede di fare clic su un'app nativa o su una pagina Chrome tramite l'estensione ChatGPT. Non è per una normale pagina web che agent‑browser può leggere, non è per l'harness del browser integrato di Cursor, e non è per hover o document.cookie (questi vanno a Claude in Chrome o agent‑browser).

Per favore rispondi sempre nella lingua dell'utente.
