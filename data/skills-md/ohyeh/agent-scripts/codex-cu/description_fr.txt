Pilotez les applications macOS et Chrome via le MCP local Codex cua_repl (nom du serveur codex-cu). Utilisez-le chaque fois que l'utilisateur indique l'utilisation de l'ordinateur, l'utilisation du navigateur, cua, codex-cu ou demande de cliquer sur une application native ou une page Chrome via l'extension ChatGPT. Pas pour une page Web normale que le navigateur de l'agent peut lire, pas pour le harnais de navigateur intégré au curseur, et pas pour le survol ou le fichier document.cookie (ceux-ci vont à Claude dans Chrome ou le navigateur de l'agent).
