Impulsa las aplicaciones de macOS y Chrome a través del Codex cua_repl MCP local (nombre del servidor codex-cu). Use esto cada vez que el usuario diga uso del ordenador, uso del navegador, cua, codex-cu o solicite hacer clic en una aplicación nativa o en una página de Chrome a través de la extensión ChatGPT. No para una página web normal que el navegador del agente pueda leer, no para el arnés del navegador integrado Cursor, y no para hover o document.cookie (van a Claude en Chrome o al navegador del agente).
