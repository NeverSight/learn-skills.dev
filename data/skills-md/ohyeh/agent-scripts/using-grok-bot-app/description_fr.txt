Lisez et pilotez l'application de bureau macOS « Grok Bot » (une application Electron) via CDP avec un navigateur d'agent : répertoriez ses robots et ses dossiers, lisez une transcription de conversation ou vérifiez ce qu'un robot a dit en dernier lieu. Utilisez-le chaque fois que l'utilisateur mentionne Grok Bot, "l'application de robot", NOVA, BOT_FACTORY ou un robot nommé dans la barre latérale de cette application, demande ce sur quoi l'un de ces robots a répondu ou travaille, ou souhaite qu'un message soit lu ou rédigé dans cette application - même s'il dit seulement "l'application de robot" sans la nommer. Pas pour l'hôte de déploiement `grok-bot` (une machine Tailscale SSH qui partage le nom) et pas pour l'API Grok de xAI.
