اقرأ تطبيق سطح المكتب "Grok Bot" لنظام التشغيل macOS (تطبيق Electron) وقم بتشغيله عبر CDP باستخدام متصفح الوكيل - أدرج برامج الروبوت والمجلدات الخاصة به، أو اقرأ نص المحادثة، أو تحقق مما قاله الروبوت آخر مرة. استخدم هذا عندما يذكر المستخدم Grok Bot، أو "تطبيق الروبوت"، أو NOVA، أو BOT_FACTORY، أو روبوت مسمى في الشريط الجانبي لذلك التطبيق، أو يسأل عما أجاب عليه أحد تلك الروبوتات أو يعمل عليه، أو يريد قراءة رسالة من هذا التطبيق أو صياغتها فيه - حتى عندما يقولون فقط "تطبيق الروبوت" دون تسميته. ليس لمضيف النشر `grok-bot` (جهاز Tailscale SSH الذي يحدث لمشاركة الاسم) وليس لـ Grok API الخاص بـ xAI.
