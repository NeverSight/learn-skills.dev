Прочтите и управляйте настольным приложением Grok Bot для macOS (приложение Electron) через CDP с помощью агента-браузера — составьте список его ботов и папок, прочитайте стенограмму разговора или проверьте, что последний раз сказал бот. Используйте это всякий раз, когда пользователь упоминает Grok Bot, «приложение-бот», NOVA, BOT_FACTORY или бот, указанный на боковой панели этого приложения, спрашивает, что один из этих ботов ответил или над чем работает, или хочет, чтобы сообщение было прочитано или добавлено в это приложение — даже если он говорит только «приложение-бот», не называя его. Не для хоста развертывания `grok-bot` (машина Tailscale SSH, имеющая то же имя) и не для API Grok от xAI.
