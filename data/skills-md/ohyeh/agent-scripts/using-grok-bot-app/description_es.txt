Lea y controle la aplicación de escritorio macOS "Grok Bot" (una aplicación de Electron) a través de CDP con un navegador de agente: enumere sus bots y carpetas, lea la transcripción de una conversación o verifique lo que dijo un bot por última vez. Use esto cada vez que el usuario mencione Grok Bot, "la aplicación del bot", NOVA, BOT_FACTORY o un bot nombrado en la barra lateral de esa aplicación, pregunte qué respondió o en qué está trabajando uno de esos robots, o quiera que se lea un mensaje o se redacte en esa aplicación, incluso cuando solo digan "la aplicación del bot" sin nombrarla. No para el host de implementación `grok-bot` (una máquina SSH de Tailscale que comparte el nombre) y no para la API Grok de xAI.
