エージェント ブラウザを使用して、CDP 経由で「Grok Bot」macOS デスクトップ アプリ (Electron アプリ) を読み取って実行します。そのボットとフォルダーを一覧表示したり、会話の記録を読んだり、ボットが最後に発言した内容を確認したりできます。ユーザーが Grok Bot、「ボット アプリ」、NOVA、BOT_FACTORY、またはそのアプリのサイドバーで名前が付けられたボットについて言及する場合、それらのボットの 1 つが返信したり作業中であることを尋ねる場合、またはそのアプリからメッセージを読み取ったり、そのアプリに下書きするメッセージを要求したりする場合には、名前を付けずに「ボット アプリ」とだけ言った場合でも、これを使用します。 「grok-bot」デプロイ ホスト (偶然名前を共有する Tailscale SSH マシン) や xAI の Grok API ではありません。
