Lorsque l'utilisateur souhaite rechercher, profiler ou analyser des concurrents à partir de leurs URL. À utiliser également lorsque l'utilisateur mentionne « profil du concurrent », « recherche de concurrents », « analyse des concurrents », « profiler ce concurrent », « analyser le concurrent », « veille concurrentielle », « analyse approfondie des concurrents », « qui sont mes concurrents », « paysage des concurrents », « dossier du concurrent », « audit concurrentiel » ou « rechercher ces concurrents ». L'entrée est une liste d'URL de concurrents. Le résultat est constitué de fichiers de démarques structurés de profils de concurrents. Pour créer des pages de comparaison/alternatives à partir de profils, voir concurrents. Pour les cartes de combat spécifiques aux ventes, voir sales-enablement.
