Когда пользователь хочет исследовать, профилировать или анализировать конкурентов по их URL-адресам. Также используйте, когда пользователь упоминает «профиль конкурента», «исследования конкурентов», «анализ конкурентов», «профилирование этого конкурента», «анализ конкурента», «конкурентная разведка», «глубокое изучение конкурента», «кто мои конкуренты», «ландшафт конкурентов», «досье конкурента», «конкурентный аудит» или «изучить этих конкурентов». Входные данные — список URL-адресов конкурентов. Выходные данные представляют собой структурированные файлы уценки профилей конкурентов. Для создания страниц сравнения/альтернативных страниц из профилей см. конкурентов. Информацию о боевых картах для конкретных продаж см. в разделе «Возможность продаж».
