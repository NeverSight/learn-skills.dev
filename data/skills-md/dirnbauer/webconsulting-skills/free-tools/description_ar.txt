عندما يريد المستخدم تخطيط أو تقييم أو بناء أداة مجانية لأغراض التسويق - جذب العملاء المحتملين، أو قيمة تحسين محركات البحث، أو الوعي بالعلامة التجارية. استخدمه أيضًا عندما يذكر المستخدم "الهندسة كتسويق"، أو "أداة مجانية"، أو "أداة تسويق"، أو "آلة حاسبة"، أو "مولد"، أو "أداة تفاعلية"، أو "أداة جذب عملاء محتملين"، أو "إنشاء أداة للعملاء المحتملين"، أو "مورد مجاني"، أو "حاسبة عائد الاستثمار"، أو "أداة تصنيف"، أو "أداة تدقيق"، أو "هل يجب أن أقوم بإنشاء أداة مجانية"، أو "أدوات لتوليد عملاء محتملين". استخدم هذا عندما يريد شخص ما إنشاء شيء مفيد والتبرع به لجذب العملاء المحتملين أو كسب الروابط. للحصول على مغناطيسات الرصاص للمحتوى القابل للتنزيل (الكتب الإلكترونية وقوائم المراجعة والقوالب)، راجع مغناطيسات الرصاص.
