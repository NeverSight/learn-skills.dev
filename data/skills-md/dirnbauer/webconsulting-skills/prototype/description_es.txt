Construya un prototipo desechable para desarrollar un diseño antes de comprometerse con él. Rutas entre dos sucursales: una aplicación de terminal ejecutable para preguntas de estado/lógica empresarial, o varias variaciones de UI radicalmente diferentes que se pueden alternar desde una ruta. Úselo cuando el usuario quiera crear un prototipo, verificar la integridad de un modelo de datos o una máquina de estado, simular una interfaz de usuario, explorar opciones de diseño o decir "prototipar esto", "déjame jugar con él", "probar algunos diseños".
