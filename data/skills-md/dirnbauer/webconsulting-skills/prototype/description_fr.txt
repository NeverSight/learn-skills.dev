Construisez un prototype jetable pour étoffer une conception avant de vous y engager. Routes entre deux branches : une application de terminal exécutable pour les questions d'état/de logique métier, ou plusieurs variantes d'interface utilisateur radicalement différentes pouvant être basculées à partir d'une seule route. À utiliser lorsque l'utilisateur souhaite créer un prototype, vérifier l'intégrité d'un modèle de données ou d'une machine à états, créer une maquette d'une interface utilisateur, explorer des options de conception ou dire « prototyper ceci », « laissez-moi jouer avec », « essayer quelques conceptions ».
