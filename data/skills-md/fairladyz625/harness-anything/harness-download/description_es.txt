Guíe al usuario desde la descarga inicial hasta comenzar a usar Harness Anything: verifique el entorno, obtenga el código fuente persistente, instale las dependencias, vincule el conjunto completo de habilidades al directorio del usuario del agente seleccionado y, a continuación, proceda con la inicialización del repositorio objetivo y el primer uso de la habilidad de control maestro. Destinado a usuarios que solicitan descargar, instalar la suite completa, realizar la conexión inicial o completar Harness en un solo párrafo; actualmente usando distribución de código fuente, sin asumir un paquete npm publicado existente.
