Каркас реализации Loop Engineering (循环工程 / 环路工程), кодовое имя персонажа «Yu Gong». Превратите расплывчатое заявление вроде «Я хочу автоматически обрабатывать X» в самозапускаемый цикл, оснащённый целью, входными данными, триггером, рабочим деревом, генератором/проверяющим, коннекторами, состоянием, верификацией и ограничениями, и в конце предоставьте вам одно‑кликовую исполняемую команду — вы сами инициируете её.  

Это инженерная реализация четвёртого этапа — Loop Engineering, после Prompt Engineering → Context Engineering → Harness Engineering: вы больше не подсказываете агенту вручную раунд за раундом, а разрабатываете цикл, способный автономно обнаруживать задачи, выполнять их, проверять и повторять, пока цель не будет достигнута. Выходные данные включают матрицу компонентов, нейтральную к среде исполнения «Loop Spec», два набора непосредственно исполняемых команд — Claude Code и Codex, а также файлы состояния, такие как манифесты и журналы.  

Ключевые слова‑триггеры включают, но не ограничиваются: create a Loop Engineering, turn this task into a loop, make the task a goal, design a looping project, loop engineering, 循环工程, 环路工程, let the agent run by itself, autonomous workflow, make maintenance/triage/upgrade an automatic loop, help me open a goal, design /goal, design /loop, run an agent that can iterate itself, Yu Gong.  

Даже если пользователь говорит лишь «I want the agent to automatically do something daily/repeatedly and iterate itself to completion», при условии, что намерение состоит в том, чтобы превратить ручное пошаговое подсказывание в самозапускаемую систему цикла, триггер должен сработать.  

Не использовать для: написания обычного навыка с нуля (используйте skill‑creator), полировки/обновления одного существующего навыка (используйте Luban), одноразовых задач в один раунд (выполняйте их напрямую, цикл не нужен), обычного обзора кода (используйте code‑review).  

Пожалуйста, всегда отвечайте на языке пользователя.
