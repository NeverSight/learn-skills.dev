루프 엔지니어링(원형 엔지니어링/루프 엔지니어링) 구현 스캐폴드, 코드명 “유공”. 모호한 문장 “X를 자동으로 처리하고 싶다”를 목표, 입력, 트리거, 작업 트리, 메이커/체커, 커넥터, 상태, 검증, 가드레일을 갖춘 자체 실행 루프로 변환하고, 최종적으로 원클릭 실행 명령—스스로 당기는 트리거—을 제공합니다.

이는 프롬프트 엔지니어링 → 컨텍스트 엔지니어링 → 하니스 엔지니어링 다음 네 번째 단계인 루프 엔지니어링의 구현이며, 이제 라운드마다 에이전트를 수동으로 프롬프트하지 않고, 작업을 자율적으로 발견·실행·검증·반복하여 목표를 달성하도록 설계합니다. 출력물에는 컴포넌트 매트릭스, 런타임에 구애받지 않는 “루프 스펙”, 두 세트의 직접 실행 가능한 명령어—Claude Code와 Codex—그리고 매니페스트/로그 상태 파일이 포함됩니다.

트리거 문구는 다음에 국한되지 않습니다: “루프 엔지니어링 만들기”, “이 작업을 루프로 전환”, “작업을 목표로 만들기”, “루프 엔지니어링 설계”, “루프 엔지니어링”, “循环工程”, “环路工程”, “에이전트를 스스로 실행하게 하기”, “자율 워크플로”, “유지보수/트라이에지/업그레이드를 자동 루프로 전환”, “목표 열기 도와줘”, “design /goal”, “design /loop”, “자신을 반복할 수 있는 에이전트 실행”, “유공”.

사용자가 단순히 “에이전트가 매일/반복적으로 자동으로 무언가를 수행하고 완료될 때까지 스스로 반복했으면 좋겠다”라고 설명하더라도, 의도가 수동 라운드 프롬프트를 자체 실행 루프 시스템으로 전환하는 것이라면 트리거됩니다.
