Nutzen Sie LLM als Simulator für Expertendebatten und gegensätzliche Standpunkte, anstatt eine einzige kriecherische Antwort zu erhalten. Verwenden Sie diese Fähigkeit, wenn der Benutzer eine wichtige Entscheidung treffen muss, eine Idee einem Stresstest unterziehen möchte, eine Devil's Advokat-Analyse benötigt, Bestätigungsverzerrungen vermeiden möchte oder sagt: „Dagegen argumentieren“, „Was sind die Gegenargumente“, „Experten simulieren“, „Dies diskutieren“, „Mein Denken herausfordern“. Basierend auf einem Karpathy 31k-ähnlichen Beitrag.
