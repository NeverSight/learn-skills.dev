إنشاء سكريبتات لجمع البيانات من الويب باستخدام Playwright. يُستخدم عندما يرغب المستخدم في استخراج موقع ويب، جمع البيانات من الصفحات، بناء خط أنابيب للاستخراج، تهيئة مشروع استخراج، أو أتمتة جمع البيانات من المواقع. يدعم بيئات Python وNode.js. يتعامل مع إعدادات الوكيل، وضع التخفي مع patchright، وتصدير البيانات إلى CSV أو JSON أو قاعدة بيانات.
