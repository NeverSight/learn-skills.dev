Crea script per web scraper usando Playwright. Utilizzalo quando l'utente vuole estrarre dati da un sito web, raccogliere informazioni dalle pagine, costruire una pipeline di scraping, inizializzare un progetto di scraping o automatizzare la raccolta di dati da siti web. Supporta gli ecosistemi Python e Node.js. Gestisce la configurazione del proxy, la modalità stealth con patchright e l'esportazione dei dati in CSV, JSON o database.
