Crea scripts web scraper usando Playwright. Se utiliza cuando el usuario desea raspar un sitio web, extraer datos de páginas web, crear un proceso de raspado, inicializar un proyecto de raspado o automatizar la recopilación de datos de sitios web. Admite ecosistemas de Python y Node.js. Maneja la configuración de proxy, el modo sigiloso con patchright y la exportación de datos a CSV, JSON o base de datos.
