Créez des scripts de scraping web avec Playwright. À utiliser lorsque l'utilisateur souhaite extraire des données d’un site web, récupérer le contenu de pages web, construire un pipeline de scraping, initialiser un projet de scraping ou automatiser la collecte de données depuis des sites web. Prend en charge les écosystèmes Python et Node.js. Gère la configuration du proxy, le mode furtif avec patchright, et l’exportation des données au format CSV, JSON ou base de données.
