Ottimizza il tuo pool di proxy Webshare per un sito web specifico. Testa tutti i proxy contro il target, identifica gli IP bloccati per paese/ASN/subnet usando i dati del Webshare CLI e li sostituisce tramite il Webshare MCP. Usalo quando i proxy falliscono su un sito, quando configuri un nuovo target di scraping o quando vuoi ottimizzare il tuo pool di proxy. Invocare con un URL di destinazione come argomento.
