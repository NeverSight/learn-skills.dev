Оптимизируйте свой пул прокси Webshare для конкретного целевого сайта. Тестирует все прокси относительно цели, определяет заблокированные IP‑адреса по стране/ASN/подсети с использованием данных из CLI Webshare и заменяет их через Webshare MCP. Используйте, когда прокси не работают на сайте, при настройке новой цели скрапинга или когда хотите настроить свой пул прокси. Вызывайте с URL‑адресом цели в качестве аргумента.
