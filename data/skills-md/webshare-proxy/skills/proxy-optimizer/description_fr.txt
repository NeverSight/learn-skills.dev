Optimisez votre pool de proxys Webshare pour un site cible spécifique. Testez tous les proxys contre la cible, identifiez les IP bloquées par pays/ASN/sous‑réseau à l’aide des données du CLI Webshare, et remplacez‑les via le MCP Webshare. À utiliser lorsque les proxys échouent sur un site, lors de la mise en place d’une nouvelle cible de scraping, ou lorsque vous souhaitez affiner votre pool de proxys. Appelez‑le avec une URL cible en argument.
