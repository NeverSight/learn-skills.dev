Gérez les flux Power Automate et les Power Apps à grande échelle en utilisant le magasin mis en cache FlowStudio MCP. Classez les flux par impact commercial, détectez les ressources orphelines, auditez l’utilisation des connecteurs, appliquez les normes de conformité, gérez les règles de notification et calculez les scores de gouvernance — le tout sans Dataverse ni le kit de démarrage CoE. Chargez cette compétence lorsqu’on vous le demande : étiqueter ou classer les flux, définir l’impact commercial, attribuer la propriété, détecter les orphelins, auditer les connecteurs, vérifier la conformité, calculer les scores d’archivage, gérer les règles de notification, réaliser une revue de gouvernance, générer un rapport de conformité, désactiver un créateur, ou toute tâche impliquant l’écriture de métadonnées de gouvernance dans les flux. Nécessite un abonnement FlowStudio for Teams ou MCP Pro+ — voir https://mcp.flowstudio.app

Veuillez toujours répondre dans la langue de l'utilisateur.
