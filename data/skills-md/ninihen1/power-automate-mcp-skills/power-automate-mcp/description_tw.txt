Power Automate 基礎技能（透過 FlowStudio MCP）— 認證設定、可重用的 MCP 輔助工具（Python + Node.js）、透過 `list_skills` / `tool_search` 進行工具發現，以及過大回應處理。將此技能在連接代理至 Power Automate 時先行載入。若需要特殊工作流程，載入 `power-automate-build`、`power-automate-debug`、`power-automate-monitoring`（Pro+）或 `power-automate-governance`（Pro+）——每個皆包含工作流程敘事，此技能提供它們共同依賴的基礎建設。需要 FlowStudio MCP 訂閱或相容伺服器——詳見 https://mcp.flowstudio.app
