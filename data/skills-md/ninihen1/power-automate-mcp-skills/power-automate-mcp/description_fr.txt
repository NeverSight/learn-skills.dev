Compétence de base pour Power Automate via FlowStudio MCP — configuration d’authentification, l’assistant MCP réutilisable (Python + Node.js), découverte d’outils via `list_skills` / `tool_search`, et gestion des réponses surdimensionnées. Chargez d’abord cette compétence lors de la connexion d’un agent à Power Automate. Pour des flux de travail spécialisés, chargez `power-automate-build`, `power-automate-debug`, `power-automate-monitoring` (Pro+), ou `power-automate-governance` (Pro+) — chacune contient le récit du flux de travail ; cette compétence fournit l’infrastructure sur laquelle elles s’appuient toutes. Nécessite un abonnement FlowStudio MCP ou un serveur compatible — voir https://mcp.flowstudio.app
