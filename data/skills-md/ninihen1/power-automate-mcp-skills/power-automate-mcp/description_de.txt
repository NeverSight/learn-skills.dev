Grundlagen‑Skill für Power Automate über FlowStudio MCP — Authentifizierungseinrichtung, der wiederverwendbare MCP‑Helper (Python + Node.js), Tool‑Erkennung über `list_skills` / `tool_search` und Behandlung von übergroßen Antworten. Laden Sie diesen Skill zuerst, wenn Sie einen Agenten mit Power Automate verbinden. Für spezialisierte Workflows laden Sie `power-automate-build`, `power-automate-debug`, `power-automate-monitoring` (Pro+) oder `power-automate-governance` (Pro+) — jede enthält das Workflow‑Narrativ, dieser Skill liefert die zugrunde liegende Infrastruktur, auf die sie alle angewiesen sind. Benötigt ein FlowStudio MCP‑Abonnement oder einen kompatiblen Server — siehe https://mcp.flowstudio.app
