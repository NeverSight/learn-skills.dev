Habilidad base para Power Automate a través de FlowStudio MCP — configuración de autenticación, el ayudante reutilizable MCP (Python + Node.js), descubrimiento de herramientas mediante `list_skills` / `tool_search` y manejo de respuestas de gran tamaño. Carga esta habilidad primero al conectar un agente a Power Automate. Para flujos de trabajo especializados, carga `power-automate-build`, `power-automate-debug`, `power-automate-monitoring` (Pro+) o `power-automate-governance` (Pro+) — cada una contiene la narrativa del flujo de trabajo; esta habilidad proporciona la infraestructura de la que todas dependen. Requiere una suscripción a FlowStudio MCP o un servidor compatible — ver https://mcp.flowstudio.app
