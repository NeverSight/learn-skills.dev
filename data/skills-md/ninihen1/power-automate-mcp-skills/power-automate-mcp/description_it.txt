Abilità di base per Power Automate tramite FlowStudio MCP — configurazione dell'autenticazione, helper MCP riutilizzabile (Python + Node.js), scoperta degli strumenti tramite `list_skills` / `tool_search` e gestione delle risposte sovradimensionate. Carica prima questa abilità quando colleghi un agente a Power Automate. Per flussi di lavoro specializzati, carica `power-automate-build`, `power-automate-debug`, `power-automate-monitoring` (Pro+) o `power-automate-governance` (Pro+) — ognuna contiene la narrazione del flusso di lavoro, questa abilità fornisce l'infrastruttura su cui tutti si basano. Richiede un abbonamento FlowStudio MCP o un server compatibile — vedi https://mcp.flowstudio.app
