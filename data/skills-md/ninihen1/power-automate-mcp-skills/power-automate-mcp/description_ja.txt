FlowStudio MCP を介した Power Automate の基礎スキル — 認証設定、再利用可能な MCP ヘルパー（Python + Node.js）、`list_skills` / `tool_search` によるツール探索、そして過大レスポンス処理。エージェントを Power Automate に接続する際は、まずこのスキルをロードしてください。専門的なワークフロー向けには、`power-automate-build`、`power-automate-debug`、`power-automate-monitoring`（Pro+）または `power-automate-governance`（Pro+）をロードします — 各スキルはワークフローのシナリオを含み、このスキルがそれらすべてが依存するインフラを提供します。FlowStudio MCP のサブスクリプションまたは互換サーバーが必要です — https://mcp.flowstudio.app を参照してください。
