Базовый навык для Power Automate через FlowStudio MCP — настройка аутентификации, переиспользуемый помощник MCP (Python + Node.js), обнаружение инструментов через `list_skills` / `tool_search` и обработка слишком больших ответов. Загрузите этот навык первым при подключении агента к Power Automate. Для специализированных рабочих процессов загрузите `power-automate-build`, `power-automate-debug`, `power-automate-monitoring` (Pro+) или `power-automate-governance` (Pro+) — каждый содержит сценарий процесса, этот навык обеспечивает инфраструктуру, от которой они все зависят. Требуется подписка FlowStudio MCP или совместимый сервер — см. https://mcp.flowstudio.app
