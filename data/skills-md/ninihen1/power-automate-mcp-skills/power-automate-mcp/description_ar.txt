مهارة الأساس لـ Power Automate عبر FlowStudio MCP — إعداد المصادقة، المساعد القابل لإعادة الاستخدام MCP (Python + Node.js)، اكتشاف الأدوات عبر `list_skills` / `tool_search`، ومعالجة الاستجابات الضخمة. حمّل هذه المهارة أولاً عند ربط وكيل بـ Power Automate. للعمليات المتخصصة، حمّل `power-automate-build`، `power-automate-debug`، `power-automate-monitoring` (Pro+)، أو `power-automate-governance` (Pro+) — كل منها يحتوي على سرد سير العمل، وهذه المهارة توفر البنية التحتية التي يعتمدون عليها جميعًا. يتطلب اشتراكًا في FlowStudio MCP أو خادمًا متوافقًا — راجع https://mcp.flowstudio.app
