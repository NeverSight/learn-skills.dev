FlowStudio MCP サーバーを使用して、Power Automate のクラウドフローを構築・スキャフォールド・デプロイします。エージェントはフロー定義を作成し、接続を配線し、デプロイとテストをすべて MCP 経由でポータルを開かずに実行します。このスキルは、フローの作成、新規フローの構築、フロー定義のデプロイ、Power Automate ワークフローのスキャフォールド、フロージェイソンの作成、既存フローのアクションの更新、フロー定義のパッチ適用、フローへのアクション追加、接続の配線、またはゼロからワークフロー定義を生成するよう求められたときにロードしてください。FlowStudio MCP のサブスクリプションが必要です — https://mcp.flowstudio.app
