Construisez, structurez et déployez des flux cloud Power Automate en utilisant le serveur FlowStudio MCP. Votre agent crée des définitions de flux, établit les connexions, déploie et teste — le tout via MCP sans ouvrir le portail. Chargez cette compétence lorsqu’on vous demande de : créer un flux, construire un nouveau flux, déployer une définition de flux, structurer un workflow Power Automate, créer un JSON de flux, mettre à jour les actions d’un flux existant, corriger une définition de flux, ajouter des actions à un flux, établir les connexions ou générer une définition de workflow à partir de zéro. Nécessite un abonnement FlowStudio MCP — voir https://mcp.flowstudio.app

Veuillez toujours répondre dans la langue de l'utilisateur.
