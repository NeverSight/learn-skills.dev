When a user wants to review an existing piece of text or document together with an agent, use this skill—to examine logical coherence, structural organization, redundancy, AI‑like tone, style and voice, and (when a reference input is provided) cross‑document SSOT (single source of truth) consistency; after the user confirms, it can proceed to rewrite. Trigger phrases include: “review this document,” “take a look,” “see if it’s reasonable,” “any logical issues,” “any repetition,” “too wordy,” “has an AI vibe,” “less AI‑sounding,” “help me go through it.” Polishing actions (“polish,” “rewrite,” “condense,” “polish,” “rewrite,” “shorten”) also trigger this skill. Not applicable: translation, fact‑checking (only flag doubtful points without verification), writing from scratch, changing content intent (adding viewpoints/changing conclusions), code review.
