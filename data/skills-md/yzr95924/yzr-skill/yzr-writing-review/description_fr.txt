Utilisez cette compétence lorsqu’un utilisateur souhaite réviser un texte ou un document existant avec un agent — examiner la cohérence logique, l’organisation structurelle, la redondance, les formulations de type IA, le style et le ton, et (lorsqu’une entrée de référence est fournie) la cohérence SSOT inter‑documents ; après que l’utilisateur ait confirmé, vous pouvez procéder à la réécriture.  
Déclencheurs : « revoir ce document », « jeter un œil », « voir si c’est raisonnable », « y a‑t‑il des problèmes logiques », « y a‑t‑il des répétitions », « trop verbeux », « ça sonne trop IA », « moins IA », « aide‑moi à le parcourir », etc. Les commandes d’affinage (« polir », « réécrire », « condense », « polir », « réécrire », « raccourcir ») déclenchent également cette compétence.  
Non applicable : traduction, vérification des faits (seulement signaler les points douteux sans vérification), rédaction à partir de zéro, changement d’intention du contenu (ajout de points de vue / modification des conclusions), revue de code.  
Veuillez toujours répondre dans la langue de l’utilisateur.
