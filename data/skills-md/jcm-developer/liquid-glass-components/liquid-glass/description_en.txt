Generate web UI components with Apple's Liquid Glass aesthetic: real refraction, specular rims and spring motion, in plain CSS with an optional vanilla JS engine. Use this skill when creating or restyling navigation bars, tab bars, toolbars, sidebars, docks, modals, popovers, toasts, floating buttons, switches, sliders or any chrome/control layer element with a translucent glass appearance. Do NOT use for content-layer elements like article cards, table cells or feeds. Always enforce WCAG AA contrast and the reduced transparency, increased contrast, reduced motion and forced colors fallbacks.
