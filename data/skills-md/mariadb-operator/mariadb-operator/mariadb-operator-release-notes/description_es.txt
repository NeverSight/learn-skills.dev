Crea las notas de la versión y la guía de actualización para un lanzamiento de mariadb-operator. Dado el PR de lanzamiento cuyo cuerpo enumera cada PR incluido en la versión, recopila cada PR, agrupa los cambios por relevancia y genera `docs/releases/RELEASE_<version>_HEADER.md.gotmpl` y `docs/releases/UPGRADE_<version>.md` en el formato que usan los lanzamientos anteriores, y luego abre un PR dirigido a `release-<version>`. Si no se proporciona un PR de lanzamiento, solicita la nueva versión e infiere los cambios a partir del historial de git desde la última etiqueta. Utilízalo siempre que el usuario necesite notas de lanzamiento, una guía de actualización/mejora o documentación para una nueva versión de mariadb-operator — "crea las notas de la versión para 26.10.0", "escribe la guía de actualización", "documenta este lanzamiento", "prepara la documentación del PR de lanzamiento" — aunque no mencione un PR de lanzamiento.
