Crea las notas de la versión y la guía de actualización para una liberación de mariadb-operator. Dado el PR de lanzamiento cuyo cuerpo enumera cada PR incluido en la versión, recopila cada PR, agrupa los cambios por relevancia y genera `docs/releases/RELEASE_<versión>_HEADER.md.gotmpl` y `docs/releases/UPGRADE_<versión>.md` con el formato que usan los lanzamientos anteriores, luego abre un PR dirigido a `release-<versión>`. Si no se proporciona un PR de lanzamiento, solicita la nueva versión e infiere los cambios del historial de git desde la última etiqueta. Utilízalo siempre que el usuario quiera notas de la versión, una guía de actualización/actualización, o documentación para una nueva versión de mariadb-operator — “crear las notas de la versión 26.10.0”, “escribir la guía de actualización”, “documentar este lanzamiento”, “preparar la documentación del PR de lanzamiento” — incluso si no mencionan un PR de lanzamiento.
