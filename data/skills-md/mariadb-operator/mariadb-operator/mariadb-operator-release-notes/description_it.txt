Crea le note di rilascio e la guida all'aggiornamento per una release di mariadb-operator. Dato il PR di rilascio il cui corpo elenca tutti i PR inclusi nella release, raccoglie ciascun PR, raggruppa le modifiche per rilevanza e genera `docs/releases/RELEASE_<version>_HEADER.md.gotmpl` e `docs/releases/UPGRADE_<version>.md` nel formato usato dalle release precedenti, quindi apre un PR che punta a `release-<version>`. Se non viene fornito un PR di rilascio, richiede la nuova versione e deduce le modifiche dalla cronologia git a partire dall'ultimo tag. Usa questo ogni volta che l'utente desidera note di rilascio, una guida di upgrade/aggiornamento o documentazione per una nuova versione di mariadb-operator — "crea le note di rilascio per 26.10.0", "scrivi la guida all'aggiornamento", "documenta questa release", "prepara la documentazione del PR di release" — anche se non menzionano un PR di rilascio.

Rispondi sempre nella lingua dell'utente.
