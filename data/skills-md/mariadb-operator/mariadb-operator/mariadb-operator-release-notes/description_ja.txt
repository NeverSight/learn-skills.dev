mariadb-operator のリリース向けにリリースノートとアップグレードガイドを作成します。リリース PR の本文に含まれるすべての PR が列挙されている場合、各 PR を取得し、関連性で変更をグループ化して、`docs/releases/RELEASE_<version>_HEADER.md.gotmpl` と `docs/releases/UPGRADE_<version>.md` を、過去のリリースが使用した形式で生成し、`release-<version>` を対象とした PR を開きます。リリース PR が提供されていない場合は、新しいバージョンを尋ね、最後のタグ以降の git 履歴から変更を推測します。ユーザーがリリースノート、アップグレード/アップデートガイド、または新しい mariadb-operator バージョンのドキュメントを求めるとき（例:「26.10.0 のリリースノートを作成」「アップグレードガイドを書いて」「このリリースを文書化」「リリース PR のドキュメントを準備」）に使用してください。たとえリリース PR が言及されていなくてもです。

常にユーザーの言語で回答してください。
