mariadb-operator のリリース向けにリリースノートとアップグレードガイドを作成します。リリース PR の本文に含まれるすべての PR が列挙されている場合、各 PR を収集し、関連性で変更をグループ化して、以前のリリースで使用された形式の `docs/releases/RELEASE_<version>_HEADER.md.gotmpl` と `docs/releases/UPGRADE_<version>.md` を生成し、`release-<version>` を対象とした PR を作成します。リリース PR が提供されていない場合は、新しいバージョンを問い合わせ、最後のタグ以降の git 履歴から変更を推測します。ユーザーがリリースノート、アップグレード/アップデートガイド、または新しい mariadb-operator バージョンのドキュメントを求めたとき（例: 「26.10.0 のリリースノートを作成して」「アップグレードガイドを書いて」「このリリースを文書化して」「リリース PR のドキュメントを用意して」）に使用してください。たとえリリース PR が言及されていなくても構いません。

常にユーザーの言語で応答してください。
