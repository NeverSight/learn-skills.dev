为 mariadb-operator 发布创建发布说明和升级指南。给定包含所有 PR 的发布 PR（其正文列出每个 PR），系统会收集每个 PR，按相关性分组更改，并生成 `docs/releases/RELEASE_<version>_HEADER.md.gotmpl` 和 `docs/releases/UPGRADE_<version>.md`，采用之前发布使用的格式，然后打开一个针对 `release-<version>` 的 PR。如果未提供发布 PR，系统会询问新版本号，并从自上一个标签以来的 git 历史中推断更改。无论用户想要发布说明、升级/更新指南，还是新 mariadb-operator 版本的文档——例如“创建 26.10.0 的发布说明”“编写升级指南”“记录此发布”“准备发布 PR 文档”等，即使他们未提及发布 PR，也请使用此功能。请始终使用用户的语言回应。
