為 mariadb-operator 版本建立發行說明與升級指南。給定列出此發行版所含每個 PR 的發行 PR 本文，系統會收集每個 PR，依相關性分組變更，並生成符合過往發行版格式的 `docs/releases/RELEASE_<version>_HEADER.md.gotmpl` 與 `docs/releases/UPGRADE_<version>.md`，然後開啟針對 `release-<version>` 的 PR。若未提供發行 PR，系統會詢問新版本號，並從自上一次 tag 以來的 git 歷史推斷變更。無論使用者是想要發行說明、升級/更新指南，或是新 mariadb-operator 版本的文件——例如「為 26.10.0 建立發行說明」、「撰寫升級指南」、「記錄此發行版」、「準備發行 PR 文件」——即使未提及發行 PR，也請使用本功能。

請始終以使用者的語言回覆。
