mariadb-operator 릴리스를 위한 릴리즈 노트와 업그레이드 가이드를 생성합니다. 릴리즈 PR의 본문에 포함된 모든 PR이 나열되어 있으면, 각 PR을 수집하고 변경 사항을 관련성에 따라 그룹화하여 `docs/releases/RELEASE_<version>_HEADER.md.gotmpl` 및 `docs/releases/UPGRADE_<version>.md` 파일을 이전 릴리즈에서 사용한 형식으로 만들어낸 뒤, `release-<version>`을 대상으으로 하는 PR을 엽니다. 릴리즈 PR이 제공되지 않은 경우 새 버전을 묻고 마지막 태그 이후의 git 히스토리를 기반으로 변경 사항을 추론합니다. 사용자가 릴리즈 노트, 업그레이드/업데이트 가이드, 또는 새로운 mariadb-operator 버전에 대한 문서를 원할 때마다 — “26.10.0 릴리즈 노트를 만들어줘”, “업그레이드 가이드를 작성해줘”, “이번 릴리즈를 문서화해줘”, “릴리즈 PR 문서를 준비해줘” 등 – 릴리즈 PR이 언급되지 않더라도 이 기능을 사용합니다. 

항상 사용자의 언어로 응답해 주세요.
