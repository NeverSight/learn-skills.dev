Создайте примечания к выпуску и руководство по обновлению для релиза mariadb-operator. Если предоставлен PR релиза, в теле которого перечислены все PR, включённые в выпуск, система собирает каждый PR, группирует изменения по релевантности и генерирует файлы `docs/releases/RELEASE_<version>_HEADER.md.gotmpl` и `docs/releases/UPGRADE_<version>.md` в формате, используемом в предыдущих релизах, после чего открывает PR, нацеленный на ветку `release-<version>`. Если PR релиза не предоставлен, система запрашивает новую версию и выводит изменения из истории git, начиная с последнего тега. Используйте эту функцию каждый раз, когда пользователь запрашивает примечания к выпуску, руководство по обновлению/обновлению или документацию для новой версии mariadb-operator — «создать примечания к выпуску 26.10.0», «написать руководство по обновлению», «задокументировать этот выпуск», «подготовить документы PR релиза» — даже если они не упоминают PR релиза.
