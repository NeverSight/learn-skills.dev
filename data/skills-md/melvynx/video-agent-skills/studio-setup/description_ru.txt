Настраивает студию видеомонтажа создателя, предназначенную для коротких роликов и видео YouTube, на их компьютере и в их проекте — инструменты, папка video‑agent/, студия Remotion, файл voice.md создателя, разрешения и необязательные аккаунты (Treg для Instagram, TikTok и YouTube, ключ ElevenLabs, Codex). Используется, когда пользователь говорит «setup», «onboarding», «install», «start here», «configure», «connect my account», «Treg», «first time using studio‑script», «short‑editing», «publish» или любой видеонавык, или хочет обновить свой голос, нишу, CTA или цвет бренда. Проверяет наличие Node, ffmpeg, yt‑dlp и git с командами установки для macOS, Windows и Linux, создает voice.md из их собственных видео или короткого интервью, предварительно одобряет команды инструментов в .claude/settings.json.
