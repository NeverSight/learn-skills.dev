Configure le studio de montage vidéo du créateur, pour les shorts et les vidéos YouTube, sur son ordinateur et dans son projet - outils, le dossier video-agent/, le studio Remotion, le fichier voice.md du créateur, les permissions, et les comptes optionnels (Treg pour Instagram, TikTok et YouTube, une clé ElevenLabs, Codex). À utiliser quand l'utilisateur dit configuration, onboarding, installer, « commencer ici », configurer, connecter mon compte, Treg, première fois d’utilisation du studio‑script, montage court, publier ou toute compétence vidéo, ou veut mettre à jour sa voix, sa niche, son CTA ou la couleur de sa marque. Vérifie Node, ffmpeg, yt‑dlp et git avec les commandes d’installation pour macOS, Windows et Linux, crée voice.md à partir de ses propres vidéos ou d’une courte interview, pré‑approuve les commandes d’outil dans .claude/settings.json.
