Das eigene B‑Roll des Erstellers (seine Clips, Bildschirmaufnahmen, Fotos) wird zu einer Bibliothek, die jeder Agent mit einem einzigen Grep durchsuchen kann – einmal gescannt mit ffprobe und ffmpeg (Länge, Ausrichtung, Datum, GPS, ein Kontaktblatt pro Clip), getaggt von günstigen Haiku‑Sub‑Agents (Titel, Beschreibung, Stimmung, Schlüsselwörter, Ersteller im Bild), dann im Vollbild in einem Short durch Kurz‑Schnitt platziert. Verwenden für /broll setup, /broll add, /broll use, /broll search oder wenn der Nutzer sagt „mein B‑Roll“, „füge diese Clips hinzu“, „setze mein B‑Roll in diesen Short“, „finde mir eine Sonnenuntergangs‑Aufnahme“.
