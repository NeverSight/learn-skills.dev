Собственный B‑ролик автора (его клипы, записи экрана, фотографии) превратился в библиотеку, которую любой агент может искать одной командой grep — единожды просканированной с помощью ffprobe и ffmpeg (длина, ориентация, дата, GPS, один контактный лист на каждый клип), помеченной недорогими суб‑агентами Haiku (заголовок, описание, настроение, ключевые слова, создатель в кадре), а затем размещённой на весь экран в коротком ролике при коротком монтаже. Используйте для /broll setup, /broll add, /broll use, /broll search или когда пользователь говорит «моя B‑ролика», «добавьте эти клипы», «поставьте мою B‑ролик в этот шорт», «найдите мне кадр с закатом».
