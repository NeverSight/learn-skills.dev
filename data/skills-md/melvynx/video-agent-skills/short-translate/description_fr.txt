Traduit une prise de tête (ou une vidéo terminée) dans une autre langue avec la voix clonée du créateur grâce au doublage ElevenLabs, en utilisant sa clé API ElevenLabs – configure la clé, coupe d’abord la prise afin de ne pas payer les bégaiements, estime la durée en minutes, l’envoie après un « oui », attend, remet la voix doublée sur l’image, puis transmet la prise traduite au montage court pour les sous‑titres dans la nouvelle langue. À utiliser lorsque l’utilisateur dit traduire, dub, dubbing, version anglaise, version espagnole, traduis, version anglaise, doublage, ElevenLabs, ou souhaite un second compte dans une autre langue.
