ElevenLabs の API キーを使用して、クリエイター自身のクローン音声で ElevenLabs Dubbing を通じて、トーキングヘッドのテイク（または完成した動画）を別の言語に翻訳します。キーを設定し、最初にテイクをトリミングして無駄なスタッターを防ぎ、所要時間を見積もり、ユーザーが「はい」と答えた後に送信し、待機して、吹き替えた音声を映像に戻し、最後に翻訳されたテイクを短編集に渡して新しい言語の字幕を付けます。ユーザーが「translate」「dub」「dubbing」「English version」「Spanish version」「traduis」「version anglaise」「doublage」「ElevenLabs」と言ったり、別の言語でのセカンドアカウントを希望したときに使用します。常にユーザーの言語で応答してください。
