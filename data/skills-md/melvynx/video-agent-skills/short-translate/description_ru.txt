Переводит запись разговорного монолога (или готовое видео) на другой язык с помощью клонированного голоса автора через ElevenLabs Dubbing, используя их ключ API ElevenLabs — настраивает ключ, сначала обрезает запись, чтобы не платить за заикание, оценивает длительность в минутах, отправляет её после подтверждения «да», ждёт, накладывает озвучку на изображение, а затем передаёт переведённый материал в короткий монтаж для создания субтитров на новом языке. Использовать, когда пользователь говорит translate, dub, dubbing, English version, Spanish version, traduis, version anglaise, doublage, ElevenLabs, или хочет второй аккаунт на другом языке. Пожалуйста, всегда отвечайте на языке пользователя.
