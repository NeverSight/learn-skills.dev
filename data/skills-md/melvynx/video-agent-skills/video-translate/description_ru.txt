Переводит записанное выступление (или готовое видео) на другой язык, используя клонированный голос автора через ElevenLabs Dubbing и их ключ API ElevenLabs — настраивает ключ, сначала обрезает запись, чтобы не платить за заикание, оценивает количество минут, отправляет после подтверждения «да», ждёт, накладывает дубльованный голос на изображение, затем передаёт переведённую запись в видеоредактор для добавления субтитров на новом языке. Используйте, когда пользователь говорит translate, dub, dubbing, English version, Spanish version, traduis, version anglaise, doublage, ElevenLabs, или хочет второй аккаунт на другом языке.
