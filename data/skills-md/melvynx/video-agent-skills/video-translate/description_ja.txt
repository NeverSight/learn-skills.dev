トーキングヘッドのテイク（または完成したビデオ）を、クリエイター自身のクローン音声を使って ElevenLabs Dubbing で別言語に翻訳します。ElevenLabs の API キーを使用し、キーを設定し、最初にテイクをトリミングして無音や途切れが発生しないようにし、分数を見積もり、ユーザーが「はい」と答えた後に送信し、待機して、吹き替えた音声を映像に重ね、最後に翻訳されたテイクを video‑edit に渡して新しい言語の字幕を付けます。ユーザーが *translate*、*dub*、*dubbing*、*English version*、*Spanish version*、*traduis*、*version anglaise*、*doublage*、*ElevenLabs* と言ったとき、または別言語での二番目のアカウントを希望する場合に使用してください。

常にユーザーの言語で応答してください。
