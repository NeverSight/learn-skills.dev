يقوم بترجمة لقطة رأس متحدث (أو فيديو نهائي) إلى لغة أخرى باستخدام صوت المبدع المستنسخ عبر دبلجة ElevenLabs، باستخدام مفتاح API الخاص بـ ElevenLabs — يُعد المفتاح، يقتطع اللقطة أولاً حتى لا يُدفع مقابل التلعثم، يقدّر الدقائق، يرسلها بعد الموافقة بنعم، ينتظر، يُعيد وضع الصوت المدبلج على الصورة، ثم يُسلم اللقطة المترجمة إلى محرّر الفيديو لإضافة ترجمات باللغة الجديدة. يُستخدم عندما يقول المستخدم ترجمة، دبلجة، نسخة إنجليزية، نسخة إسبانية، traduis، version anglaise، doublage، ElevenLabs، أو يرغب في حساب ثانٍ بلغة أخرى.
