Первый запуск навыков видеоустройства — настраивает видеомонтаж на компьютере создателя и в их проекте: инструменты, папку video-agent/, студию Remotion, файл voice.md создателя, разрешения и необязательные аккаунты (Treg для Instagram, TikTok и YouTube, ключ ElevenLabs, Codex). Использовать, когда пользователь говорит «setup», « onboarding», «install», «start here», «configure», «connect my account», «Treg», «first time using video‑script», «video‑edit», «video‑publish» или любой другой видеонавык, или хочет обновить свой голос, нишу, CTA или фирменный цвет. Проверяет наличие Node, ffmpeg, yt‑dlp и git с командами установки для macOS, Windows и Linux, создает voice.md из их собственных видео или короткого интервью, предварительно одобряет команды инструмента в .claude/settings.json.
