他のクリエイターの編集スタイルを、short‑editing が自分の作品に適用できる名前付きスタイルとしてコピーします。ユーザーが「steal」や「copy the style of」「edit like @x」「make a style from this reel」「vole le style de」と言ったとき、またはリールやショートを見本として提示したときに使用します。リールをダウンロードします（yt‑dlp、または Instagram と TikTok 用の Treg）。目測ではなく ffmpeg でスタイルを測定します（コンタクトシート、1 秒あたりのハードカット数、ビートのスペクトログラムとカット時の効果音、音声下の音楽レベル、顔のサイズとズーム）。video‑agent/styles/<name>.md に書き込み、次に short‑editing でテスト動画を編集し、元動画とフレーム単位で比較します。
