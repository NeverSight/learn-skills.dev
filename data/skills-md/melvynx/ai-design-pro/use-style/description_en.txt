A library of named visual styles to inspire and dress anything the user will look at - landing pages, sales pages, websites, apps, dashboards, mobile app screens, HTML reports, documents, visuals - plus the user's own custom styles made with /inspiration. Use for /use-style, "list styles", a style name (vercel, stripe, linear, raycast, anthropic, kinfolk, aman, muji, gumroad, duolingo, craigslist, poolsuite, new-york-times, dusk, luma, testspirite, grid, black-grid, ios-app, linktree, lumail, codelynx, tchao, saveit, thumbfast, codeline), or whenever you create a file with a visual design and the global rules name a default style.
