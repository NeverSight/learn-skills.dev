Делает так, чтобы Claude Code улучшал себя на основе вашей собственной истории. Читает все сессии Claude Code за последние дни, сохранённые на вашем компьютере (~/.claude/projects/**/*.jsonl), затем сообщает, какие ошибки Claude постоянно допускает, какие исправления вы повторяете, какие навыки вам следует создать и какие задачи вы делаете каждый день, которые можно автоматизировать, и пишет выбранный вами навык или автоматизацию. Используется, когда пользователь вводит /ameliore-systeme, задаёт вопрос «qu'est-ce que je fais mal», «quels skills je devrais créer» или хочет, чтобы Claude учился на прошлых сессиях.

Пожалуйста, всегда отвечайте на языке пользователя.
