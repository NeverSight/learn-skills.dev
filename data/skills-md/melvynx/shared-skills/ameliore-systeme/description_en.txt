Makes Claude Code improve itself from your own history. Reads every Claude Code session of the last days saved on your computer (~/.claude/projects/**/*.jsonl), then reports what Claude keeps getting wrong, the corrections you repeat, the skills you should create and the tasks you redo every day that could be automated, and writes the skill or automation you pick. Use when the user types /ameliore-systeme, asks "qu'est-ce que je fais mal", "quels skills je devrais créer", or wants Claude to learn from past sessions.
