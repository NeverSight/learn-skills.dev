Fait que Claude Code s'améliore à partir de votre propre historique. Il lit chaque session Claude Code des derniers jours enregistrée sur votre ordinateur (~/.claude/projects/**/*.jsonl), puis signale ce que Claude se trompe régulièrement, les corrections que vous répétez, les compétences que vous devriez créer et les tâches que vous refaites chaque jour et qui pourraient être automatisées, et rédige la compétence ou l'automatisation que vous choisissez. À utiliser lorsque l'utilisateur tape /ameliore-systeme, demande « qu'est‑ce que je fais mal », « quels skills je devrais créer », ou veut que Claude apprenne des sessions passées.

Veuillez toujours répondre dans la langue de l'utilisateur.
