Claude Code が自分の履歴から自己改善します。コンピュータに保存された過去数日のすべての Claude Code セッション（~/.claude/projects/**/*.jsonl）を読み取り、Claude が繰り返し間違えている点、あなたが何度も修正している箇所、作成すべきスキル、毎日やり直しているが自動化できるタスクを報告し、選択したスキルや自動化を作成します。ユーザーが **/ameliore-systeme** と入力したとき、"qu'est‑ce que je fais mal"、"quels skills je devrais créer" と尋ねたとき、または Claude に過去のセッションから学習させたいときに使用してください。

常にユーザーの言語で応答してください。
