Installez, mettez à jour, supprimez, créez, améliorez ou auditez les skills pour Claude Code et Codex, sur cet ordinateur, dans un seul dossier ou sur leur serveur. Utilisez lorsque l'utilisateur dit « installe ce skill », fournit un lien de skill, « supprime ce skill », « mets à jour mes skills », « fais‑en un skill », ou qu'un skill se comporte mal.

Veuillez toujours répondre dans la langue de l'utilisateur.
