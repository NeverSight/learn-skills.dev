Применяйте именованный визуальный стиль к любому объекту, который пользователь будет видеть — целевым страницам, приложениям, панелям мониторинга, HTML‑отчетам, документам, визуализациям. Используйте для /use-style, «list styles», название стиля (vercel, stripe, linear, raycast, anthropic, gumroad, new-york-times, dusk, luma, testspirite, grid, black-grid, ios-app) либо каждый раз, когда создаёте файл с визуальным дизайном, а глобальные правила задают стиль по умолчанию.
