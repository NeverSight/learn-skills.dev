Applica uno stile visivo con nome a tutto ciò che l'utente vedrà – pagine di atterraggio, app, dashboard, report HTML, documenti, visuali. Usa per /use-style, “list styles”, un nome di stile (vercel, stripe, linear, raycast, anthropic, gumroad, new-york-times, dusk, luma, testspirite, grid, black-grid, ios-app), o ogni volta che crei un file con un design visivo e le regole globali indicano uno stile predefinito.
