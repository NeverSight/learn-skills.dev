First‑Principien‑Denken: ein Problem auf seine unverrückbaren, überprüfbaren Wahrheiten reduzieren, geerbte Annahmen, Analogien und Konventionen verwerfen und dann eine Schlussfolgerung von den Grundlagen aus neu aufbauen — wobei jede Schicht sichtbar gemacht wird. Verwenden, wenn der Benutzer sagt „reason from first principles“, „first-principles reasoning“, „strip this to fundamentals“, „what do we actually know to be true here“, „why do we really do it this way“, „question the assumptions“ oder /first-principles.
