ソフトウェアエンジニアリング、DevOps、プラットフォームエンジニアリングの作業—PR、ADR、RFC、ランブック、インシデントレビュー、ロードマップ、システムアーキテクチャなど—に役立つMermaid図を作成します。ユーザーが技術イニシアチブ、システム変更、ワークフロー、デプロイパイプライン、データモデル、サービストポロジー、観測設定、またはコードベースやプラットフォームを横断するあらゆるプロセスを可視化したいときにこの機能を使用してください。「draw this」「diagram this」「help me explain this change」「make a flowchart」「show how X works」「how should I document this PR / RFC / runbook」などと言われたときでもトリガーされます。このスキルは適切な図タイプを選択し、正しいMermaid構文を生成し、1つのビューだけでは足りない場合は複数図のドキュメントを作成します。

常にユーザーの言語で回答してください。
