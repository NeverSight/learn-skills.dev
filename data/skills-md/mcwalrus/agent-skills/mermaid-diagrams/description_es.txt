Crea diagramas Mermaid útiles para trabajo de SWE, DevOps y Platform Engineering: PRs, ADRs, RFCs, runbooks, revisiones de incidentes, hojas de ruta, arquitectura del sistema y más. Usa esta habilidad siempre que el usuario quiera visualizar una iniciativa técnica, un cambio de sistema, flujo de trabajo, pipeline de despliegue, modelo de datos, topología de servicios, configuración de observabilidad o cualquier proceso en bases de código y plataformas. Se activa incluso cuando el usuario dice cosas como «dibuja esto», «diagrame esto», «ayúdame a explicar este cambio», «haz un diagrama de flujo», «muestra cómo funciona X» o «cómo debería documentar este PR / RFC / runbook». La habilidad elige el tipo(s) de diagrama adecuado(s), genera sintaxis Mermaid válida y compone documentos con múltiples diagramas cuando una sola vista no es suficiente. Por favor, responde siempre en el idioma del usuario.
