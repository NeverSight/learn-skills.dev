Crée des diagrammes Mermaid utiles pour le travail de SWE, DevOps et d’ingénierie de plateforme — PR, ADR, RFC, runbooks, revues d’incidents, feuilles de route, architecture système, et plus encore. Utilisez cette compétence chaque fois que l’utilisateur souhaite visualiser une initiative technique, un changement de système, un flux de travail, un pipeline de déploiement, un modèle de données, une topologie de service, une configuration d’observabilité ou tout processus à travers des bases de code et des plateformes. Activez‑la même lorsque l’utilisateur dit des choses comme « draw this », « diagram this », « help me explain this change », « make a flowchart », « show how X works » ou « how should I document this PR / RFC / runbook ». La compétence choisit le(s) bon(s) type(s) de diagramme, génère une syntaxe Mermaid valide et compose des documents multi‑diagrammes lorsqu’une seule vue ne suffit pas.  

Veuillez toujours répondre dans la langue de l’utilisateur.
