Carica questa abilità quando ti viene richiesto di controllare il codice sorgente al di fuori di questo codebase, oppure gli utenti ti forniscono una specifica di repository GitHub che segue il formato <owner-name>/<repo-name>. Usala quando la directory corrente non è il progetto target, quando è necessario un altro progetto locale o quando sono coinvolti più progetti.

Per favore, rispondi sempre nella lingua dell'utente.
