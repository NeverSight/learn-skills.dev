Chargez cette compétence lorsque vous devez vérifier le code source en dehors de cette base de code, ou que les utilisateurs vous donnent une spécification de dépôt GitHub suivant le format \<owner-name>/\<repo-name>. Utilisez‑la lorsque le répertoire actuel n’est pas le projet cible, lorsqu’un autre projet local est nécessaire, ou lorsque plusieurs projets sont impliqués.

Veuillez toujours répondre dans la langue de l’utilisateur.
