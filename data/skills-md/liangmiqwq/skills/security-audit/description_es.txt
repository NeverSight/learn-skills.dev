Guía de seguridad y revisión de vulnerabilidades para bases de código, API, servicios, herramientas CLI, bibliotecas y demonios. Úsalo para preguntas de seguridad, revisiones enfocadas, investigación de vulnerabilidades, auditorías de seguridad o pruebas de penetración. Ejecuta el flujo de trabajo completo solo para solicitudes explícitas de auditoría de bases de código o pruebas de penetración, revisiones completas/comprensivas/de extremo a extremo, o artefactos de informe solicitados.
