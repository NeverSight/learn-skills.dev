Guide de sécurité et revue de vulnérabilités pour les bases de code, les API, les services, les outils CLI, les bibliothèques et les démons. Utilisez-le pour les questions de sécurité, les revues ciblées, la recherche de vulnérabilités, les audits de sécurité ou les tests d’intrusion. Exécutez le flux de travail complet uniquement pour les demandes explicites d’audit de base de code ou de test d’intrusion, les revues complètes/compréhensives/de bout en bout, ou les artefacts de rapport demandés.
