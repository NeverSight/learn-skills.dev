Создайте качественный Vue‑композабл для библиотеки, который принимает возможно‑реактивные входные данные (MaybeRef / MaybeRefOrGetter), чтобы вызывающие могли передавать обычное значение, ref или getter. Нормализуйте входные данные с помощью toValue()/toRef() внутри реактивных эффектов (watch/watchEffect), чтобы поведение было предсказуемым и реактивным. Используйте этот навык, когда пользователь просит создать адаптируемые или переиспользуемые композаблы.
