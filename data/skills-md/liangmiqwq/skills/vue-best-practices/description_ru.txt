Обязательно использовать для задач Vue.js.  
Настоятельно рекомендуется использовать Composition API с `<script setup>` и TypeScript как стандартный подход.  
Поддерживает Vue 3, SSR, Volar, vue‑tsc.  
Загружается для любого Vue, файлов .vue, Vue Router, Pinia или Vite с поддержкой Vue.  
Всегда используйте Composition API, если только проект явно не требует Options API.  

Пожалуйста, всегда отвечайте на языке пользователя.
