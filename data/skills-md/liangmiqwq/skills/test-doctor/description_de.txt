Auditieren und verbessern Sie die automatisierten Tests eines bestehenden Softwareprojekts als Regressionsschutz. Verwenden Sie es, wenn Codex die Testqualität bewerten, Tests den benutzerseitig sichtbaren Funktionen oder dokumentierten Verträgen zuordnen, implementierungsgebundene, über‑gemockte, tote, doppelte, fragile oder wenig wertvolle Tests finden, CI‑Kosten reduzieren, einen Test‑Migrationsplan entwerfen oder Tests refaktorieren muss, dabei jedoch eine sinnvolle Abdeckung beibehalten wird. Gilt für Unit‑, Integrations‑, Vertrags‑, Komponenten‑ und End‑to‑End‑Suites über verschiedene Sprachen und Frameworks hinweg.
