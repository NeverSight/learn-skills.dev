Auditar y mejorar las pruebas automatizadas de un proyecto de software existente como protección contra regresiones. Utilizar cuando Codex necesita evaluar la calidad de las pruebas, mapearlas a capacidades visibles para el usuario o contratos documentados, encontrar pruebas acopladas a la implementación, sobre‑mockeadas, obsoletas, duplicadas, frágiles o de bajo valor, reducir el coste de CI, diseñar un plan de migración de pruebas o refactorizar pruebas preservando una cobertura significativa. Aplica a suites unitarias, de integración, de contrato, de componentes y de extremo a extremo, en diversos lenguajes y frameworks.
