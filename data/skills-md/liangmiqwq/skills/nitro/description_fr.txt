Nitro est le kit d’outils serveur indépendant du framework (alimentant Nuxt) pour créer et déployer des serveurs web partout. Utilisez‑le lorsque vous travaillez avec nitro.config, les routes serveur/gestionnaires d’événements, les règles de routage, la mise en cache, le stockage, les tâches, les websockets ou le déploiement sur Node/Bun/Deno/Cloudflare/Vercel.
