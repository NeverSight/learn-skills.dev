Les lignes directrices d'optimisation des performances de React et Next.js de Vercel Engineering. Cette compétence doit être utilisée lors de l'écriture, de la révision ou de la refactorisation du code React/Next.js afin d'assurer des modèles de performances optimaux. Déclencheurs sur les tâches impliquant des composants React, des pages Next.js, la récupération de données, l'optimisation des bundles ou les améliorations de performance.

Veuillez toujours répondre dans la langue de l'utilisateur.
