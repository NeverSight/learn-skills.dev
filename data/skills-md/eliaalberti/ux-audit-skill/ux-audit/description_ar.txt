قم بإجراء تدقيق تجريبي لتجربة المستخدم (UX) لرحلة العميل من لقطات الشاشة. استخدم ذلك عندما يطلب المستخدم تدقيق UX أو تقييم تجريبي أو مراجعة قابلية الاستخدام أو تفكيك التصميم أو مراجعة خبراء للشاشات أو النماذج أو التدفق، سواء كان منتجك الخاص أو منتج منافس. يتم التقييم وفقًا للأطر المذكورة (Nielsen، Shneiderman، Gerhardt‑Powals، Bastien & Scapin، Hick/Fitts/Miller/Jakob/Peak‑End، Fogg، Cialdini، Gestalt، Norman، Tognazzini، WCAG 2.1، قواعد تصميم المحتوى) ويُنتج نتائج مصنفة حسب الخطورة مع إشارات تجريبية، لقطات شاشة مشروحة، وتقرير منسق بصيغة markdown. لا تُستخدم لإنشاء تصاميم جديدة أو لإجراء فحوصات إمكانية الوصول على مستوى الشيفرة لواجهة DOM الحية.

الرجاء دائمًا الرد بلغة المستخدم.
