# Design Growth Loop

## Contract

A loop must close: one cohort's value-producing behavior creates qualified input for the next cycle. Distinguish loops from one-way funnels and campaigns. Optimize retained value, not invitations or impressions.

## Workflow

1. Define the core value event, target participant, and retained outcome.
2. Map the loop step by step: trigger, value creation, artifact or interaction, exposure, recipient motivation, conversion, activation, value realization, and re-entry.
3. Classify the mechanism: collaboration, sharing, content, marketplace, referral, or repeated usage. Validate that it is natural to the product.
4. Quantify each transition, the number of outputs per participant, loop coefficient, cycle time, quality, and leakage using ranges.
5. Identify incentives, friction, abuse, spam, privacy, trust, saturation, and adverse selection.
6. Select the highest-leverage bottleneck and design one experiment with guardrails.
7. Model how the loop interacts with acquisition channels, retention, monetization, and network effects.

## BuildBetter Acceleration

If BuildBetter MCP is available, search organization skills first. Use customer evidence, survey responses, people or account context, calls, and product documents to understand sharing and collaboration behavior. Do not contact users or activate a referral or messaging flow without explicit approval.

## Output

Return loop diagram in text, participant and value event, equations and assumptions, transition metrics, bottleneck, incentives, risks, guardrails, experiment, and scale conditions.

## Quality Gate

Reject loops that do not close, depend on coerced sharing, ignore recipient value, or project exponential growth without retention, saturation, and cycle-time constraints.
