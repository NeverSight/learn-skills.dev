Разрабатывать, проверять и поддерживать долгосрочную систему когнитивных активов, состоящую из памяти, проектной документации, навыков и указателей. Используется, когда пользователь говорит «создать систему памяти», «очистить память», «проверка состояния памяти», «организовать базу знаний», «проверить источник правды или устаревшие указатели», «слишком много навыков»; не применяется для обычного архивирования файлов, передачи сессий, развертывания кода или общей очистки проекта.
