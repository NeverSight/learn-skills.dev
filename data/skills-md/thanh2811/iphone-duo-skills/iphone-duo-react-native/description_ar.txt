تكييف تطبيق React Native أو Expo لجهاز iPhone Duo، أول هاتف قابل للطي من Apple — مسافات المنطقة الآمنة غير المتناظرة، معالجة تغيير الحجم، وكيفية كشف منطقة الحجز وواجهات برمجة تطبيقات المفصل في iOS 27.1 من خلال وحدة أصلية. يُستخدم عندما يحتاج تطبيق iOS مبني على React Native أو Expo أو JavaScript إلى دعم iPhone القابل للطي.
