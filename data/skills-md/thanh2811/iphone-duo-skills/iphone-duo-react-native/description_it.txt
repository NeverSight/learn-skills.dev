Adatta un'app React Native o Expo a iPhone Duo, il primo iPhone pieghevole di Apple — rientri sicuri asimmetrici, gestione del ridimensionamento e modalità per esporre le API della regione riservata e della cerniera di iOS 27.1 tramite un modulo nativo. Da usare quando un'app iOS basata su React Native, Expo o JavaScript necessita del supporto per iPhone pieghevoli.
