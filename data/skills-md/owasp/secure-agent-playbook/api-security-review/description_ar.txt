مراجعة شاملة لأمان واجهة برمجة التطبيقات وفقًا لأعلى 10 مخاطر أمان API لــ OWASP (2023). يُستخدم عند مراجعة مواصفات OpenAPI/Swagger، وتدقيق تنفيذات REST/GraphQL/gRPC، واختبار آليات المصادقة، أو فحص إعدادات بوابة API. يغطي BOLA/IDOR، ضعف المصادقة، التعيين الجماعي، تحديد معدل الطلبات، SSRF، وغير ذلك مع سيناريوهات هجمات واقعية.
