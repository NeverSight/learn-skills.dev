Revue de sécurité API complète conforme à l'OWASP API Security Top 10 (2023). À utiliser lors de la révision de spécifications OpenAPI/Swagger, de l’audit d’implémentations REST/GraphQL/gRPC, des tests de mécanismes d’authentification ou de la vérification des configurations de passerelle API. Couvre BOLA/IDOR, authentification défaillante, affectation massive, limitation du débit, SSRF et bien plus, avec des scénarios d’attaque réalistes.
