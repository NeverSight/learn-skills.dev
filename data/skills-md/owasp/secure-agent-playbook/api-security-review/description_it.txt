Revisione completa della sicurezza delle API rispetto all'OWASP API Security Top 10 (2023). Da utilizzare durante la revisione delle specifiche OpenAPI/Swagger, l’audit di implementazioni REST/GraphQL/gRPC, il test dei meccanismi di autenticazione o la verifica delle configurazioni del gateway API. Copre BOLA/IDOR, autenticazione difettosa, assegnazione di massa, limitazione della velocità, SSRF e altro, con scenari di attacco reali.
