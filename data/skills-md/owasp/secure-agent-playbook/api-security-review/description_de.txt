Umfassende API-Sicherheitsüberprüfung gemäß OWASP API Security Top 10 (2023). Verwendung beim Prüfen von OpenAPI/Swagger‑Spezifikationen, Auditing von REST/GraphQL/gRPC‑Implementierungen, Testen von Authentifizierungsmechanismen oder Überprüfen von API‑Gateway‑Konfigurationen. Deckt BOLA/IDOR, fehlerhafte Authentifizierung, Massenzuweisung, Rate‑Limiting, SSRF und mehr mit realen Angriffsszenarien ab.
