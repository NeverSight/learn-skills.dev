Тщательный обзор безопасности API в соответствии с OWASP API Security Top 10 (2023). Используйте при проверке спецификаций OpenAPI/Swagger, аудите реализаций REST/GraphQL/gRPC, тестировании механизмов аутентификации или проверке конфигураций API‑шлюза. Охватывает BOLA/IDOR, уязвимости аутентификации, массовое присвоение, ограничение скорости запросов, SSRF и др., с реальными сценариями атак.
