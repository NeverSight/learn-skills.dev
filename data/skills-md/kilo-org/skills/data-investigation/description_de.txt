Ein Workflow zur Durchführung rigoroser, reproduzierbarer Datenuntersuchungen und Ad-hoc-Analysen. Diese Fähigkeit sollte eingesetzt werden, wenn eine Geschäftsfrage untersucht, eine Anomalie bei einer Kennzahl erklärt, eine Hypothese validiert, eine Ursachenanalyse durchgeführt oder ein einmaliges Untersuchungs-Dashboard oder -Memo erstellt wird.
