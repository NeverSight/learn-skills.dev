Esta habilidad debe usarse cuando un usuario necesita ayuda para depurar una consulta SQL de Snowflake, comprender un fallo en una consulta de Snowflake, aislar resultados incorrectos, corregir combinaciones o filtros, diagnosticar problemas de rendimiento o convertir un error vago del almacén en una causa raíz concreta y una consulta corregida. Se trata de una habilidad independiente de depuración de consultas de Snowflake para tareas SQL ad hoc en bases de datos, esquemas y entornos.
