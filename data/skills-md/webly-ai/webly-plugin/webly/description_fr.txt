Webly héberge ce que les agents créent : publier un site web, ou partager des fichiers et dossiers, à une URL active en quelques secondes sans compte, puis laisser la personne se connecter et le revendiquer pour le garder, le modifier via MCP, et publier les brouillons qu’elle approuve. Utilisez-le lorsque l’on vous demande « publier ceci », « héberger ceci », « déployer ceci », « mettre en ligne », « créer un site web », « partager cela sous forme de page web », « donnez‑moi un lien vers ce site », « partager ces fichiers », « envoyer ces fichiers », « donnez‑moi un lien de téléchargement », « conserver mon site », « revendiquer mon site », « créer un compte Webly », « connecter Webly », « connecter mon domaine », « utiliser mon propre domaine », ou lorsqu’on travaille sur un site hébergé sur Webly (*.webly.site). Utilisez‑le également au début de toute session où un site Webly ou une étape Webly inachevée attend sur cette machine.

Veuillez toujours répondre dans la langue de l'utilisateur.
