Configure les directives de projet pour les agents IA/de codage afin d’utiliser le mode agent Allure pendant le travail de test en détectant les commandes de test locales, les capacités Allure, les chemins de résultats et les conventions de preuve, puis en créant de courts routeurs d’agents racine ainsi que le fichier docs/allure-agent-mode.md. Utilisez‑le lorsque l’objectif est d’orienter le flux de travail des agents, le processus de révision des preuves, les attentes et les instructions de test propres au projet ; pas lorsque le but principal est d’installer des adaptateurs Allure, de faire générer des résultats par les tests, d’ajouter des scripts de rapport ou de configurer la publication CI.
