Configura la guía del proyecto para que los agentes de IA/codificación utilicen el modo agente de Allure durante el trabajo de pruebas detectando comandos locales de prueba, capacidades de Allure, rutas de resultados y convenciones de evidencia, y luego creando routers raíz cortos para el agente más docs/allure-agent-mode.md. Úsalo cuando el objetivo sea guiar el flujo de trabajo del agente, el flujo de revisión de evidencia, las expectativas y las instrucciones de pruebas específicas del proyecto; no cuando el objetivo principal sea instalar adaptadores de Allure, hacer que las pruebas emitan resultados, añadir scripts de informe o configurar la publicación en CI.
