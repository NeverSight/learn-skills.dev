Настройте руководство проекта для ИИ/кодирующих агентов, чтобы использовать режим Allure‑agent при тестовой работе, обнаруживая локальные команды тестов, возможности Allure, пути к результатам и конвенции доказательств, а затем создавая короткие корневые роутеры агентов плюс файл docs/allure-agent-mode.md. Используйте, когда цель — руководство по рабочему процессу агента, процессу проверки доказательств, ожиданиям и инструкциям по тестовой работе, специфичным для проекта; не используйте, когда основной целью является установка адаптеров Allure, заставление тестов выдавать результаты, добавление скриптов отчётов или настройка публикации в CI.
