Konfigurieren Sie Projektanweisungen für KI‑/Programmierungs‑Agenten, um den Allure‑Agentenmodus während der Testarbeit zu verwenden, indem Sie lokale Testbefehle, Allure‑Fähigkeiten, Ergebnis‑Pfade und Evidenz‑Konventionen erkennen und anschließend kurze Root‑Agent‑Router sowie docs/allure-agent-mode.md erstellen. Verwenden Sie dies, wenn das Ziel eine Agent‑Workflow‑Leitung, ein Evidenz‑Überprüfungs‑Workflow, Erwartungen und projektspezifische Testarbeits‑Anweisungen ist; nicht, wenn das Hauptziel die Installation von Allure‑Adapter, das Erzeugen von Testergebnissen, das Hinzufügen von Bericht‑Skripten oder die Konfiguration von CI‑Veröffentlichungen ist.
