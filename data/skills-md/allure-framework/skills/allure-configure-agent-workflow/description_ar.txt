قم بتكوين إرشادات المشروع لوكلاء الذكاء الاصطناعي/البرمجة لاستخدام وضع وكيل Allure أثناء عمل الاختبار عن طريق اكتشاف أوامر الاختبار المحلية، وقدرات Allure، ومسارات النتائج، واتفاقيات الأدلة، ثم إنشاء موزِّعات وكيل جذرية قصيرة بالإضافة إلى docs/allure-agent-mode.md. استخدم ذلك عندما يكون الهدف هو إرشاد سير عمل الوكيل، وسير مراجعة الأدلة، والتوقعات، وتعليمات عمل الاختبار الخاصة بالمشروع؛ وليس عندما يكون الهدف الأساسي هو تثبيت محولات Allure، أو جعل الاختبارات تُصدر النتائج، أو إضافة سكربتات التقارير، أو تهيئة نشر CI.

يرجى دائمًا الرد بلغة المستخدم.
