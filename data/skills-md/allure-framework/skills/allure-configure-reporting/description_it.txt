Configura la creazione di report Allure nei progetti esistenti selezionando gli adattatori del framework di test, le directory dei risultati, l'installazione locale dello strumento Allure, gli script di pacchettizzazione/build, le integrazioni di prove aggiuntive e la gestione di artefatti o report CI. Usa questa configurazione quando i test non emettono ancora risultati Allure, una configurazione Allure esistente è incompleta o difettosa, o l'utente richiede di installare Allure, aggiungere adattatori, aggiungere comandi di report, pubblicare i report in CI o aggiungere integrazioni come allegati HTTP, matcher, screenshot, tracce, diff di immagini, log o altre evidenze ricche.

Per favore rispondi sempre nella lingua dell'utente.
