# YouTube Manager

Use this skill for channel setup and ongoing channel/creator management. It maintains approved channel context and guides channel research and strategy. Per-video scripts, publishing assets, and production work belong to Video Kit.

## Workflow

1. **Load only relevant context.** Find `CHANNEL_MEMORY.md` and useful transcript/style references in the active channel workspace. Read the approved memory and only the guide needed for this request. Treat observations, creator-confirmed guidance, inferences, and unknowns as distinct.
2. **Set up when memory is missing or the creator requests a rebuild.** Read [setup-intake.md](references/setup-intake.md). Ask only for the channel URL or handle if it is not already known. Find the latest three uploads yourself; the creator may optionally name up to three gold-standard videos. Research the channel and make a best-effort transcript check for recent videos. If captions are unavailable, use the local fallback in [transcripts.md](references/transcripts.md) on a representative sample. Present the evidence-based profile for approval before creating or replacing persistent memory and transcript references.
3. **Maintain approved memory over time.** Update durable preferences and decisions in place when the creator explicitly confirms them, date the change, and mention the update. Keep one-video decisions and product experiences with that video's project. Treat repeated observations as provisional until the creator confirms them. Read [channel-memory-template.md](references/channel-memory-template.md) when creating or substantially rebuilding memory.
4. **Do channel work.** For channel strategy, quick content ideas, channel research, or product/business concepts, read [content-strategy.md](references/content-strategy.md). If supplied Studio data can inform the request, also read [performance-review.md](references/performance-review.md). For deep, current research and a ranked shortlist of YouTube topic opportunities, use **Topic Scout** (`topic-scout`) when available; it can use dated performance reports when present. For per-video outlines/scripts, publishing assets, or production, route to **Video Kit** (`video-kit`). For hands-on review experience, use **Review Grill** (`review-grill`) to research and interview the creator; Review Grill saves `review-brief.md` in the video's project folder, which Video Kit can use later.
5. **Report useful limits.** Link created files and distinguish verified facts from inference, unreviewed transcript output, and unknown private information.

## Evidence and creator fit

- Browse for current channel, audience, and platform facts when they affect strategy. Prefer primary sources and record checked dates for research deliverables.
- Treat public views and sampled comments as clues, not private analytics or representative audience research.
- Do not invent private analytics, goals, production resources, or commercial rules.
- Keep channel memory and research notes in the creator's preferred internal language. Write channel-facing material in the approved language, script, and register. Preserve original spoken wording in transcript references and label ASR method, coverage, confidence, and review status.
- Keep the skill generic. Channel-specific defaults belong in the active `CHANNEL_MEMORY.md`, not in shared skill instructions.
