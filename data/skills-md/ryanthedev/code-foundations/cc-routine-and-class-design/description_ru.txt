Применяет правила проектирования процедур и классов из Code Complete на уровне процедур: классификация связности, пороговое количество параметров, проверка наследования по принципу LSP и решение о выборе композиции вместо наследования. Для уровня процедур и классов, а не системной архитектуры (использовать ca-architecture-boundaries).
