Сопоставляет симптомы кода — разросшиеся комбинации подклассов, диспетчеризацию по типу, запутанное создание объектов, несовместимые интерфейсы, каскадные обновления «один‑ко‑многим» — с соответствующим шаблоном из «Банды четырёх», затем загружает структурный рецепт этого шаблона из его 23 справочных файлов. Для выбора и реализации шаблона проектирования; не для границ уровня системы (используйте ca-architecture-boundaries) или глубины интерфейса модуля (используйте aposd-designing-deep-modules).
