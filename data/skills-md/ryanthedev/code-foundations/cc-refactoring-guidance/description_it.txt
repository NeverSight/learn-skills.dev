Guida al refactoring sicuro usando la disciplina “fix‑first‑then‑refactor” di Code Complete: decide tra refactoring, riscrittura e fix‑first; impone commit separati; applica rigore al piccolo cambiamento per one‑liner ad alto tasso di errori. Non è inteso per diagnosticare il bug stesso (usa cc‑debugging), trasformare la complessità del codice funzionante (usa aposd‑simplifying‑complexity) o per codice legacy non testato (lo indirizza a welc‑legacy‑code).
