Руководит безопасным рефакторингом, используя дисциплину Code Complete «сначала исправление, затем рефакторинг»: принимает решение между рефакторингом, переписыванием и сначала‑исправлением; обеспечивает отдельные коммиты; применяет строгий подход к небольшим изменениям для однострочных фрагментов с высоким уровнем ошибок. Не предназначено для диагностики самой ошибки (используйте cc-debugging), преобразования сложности работающего кода (используйте aposd-simplifying-complexity) или для непроверенного наследуемого кода (перенаправляет к welc-legacy-code).
