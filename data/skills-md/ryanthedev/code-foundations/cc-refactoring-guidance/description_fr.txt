Guide le refactoring sûr en utilisant la discipline « fix‑first‑then‑refactor » de Code Complete : décide entre refactoriser, réécrire et appliquer le fix‑first ; impose des commits séparés ; applique une rigueur de petits changements aux lignes uniques à fort taux d’erreurs. Ne sert pas à diagnostiquer le bug lui‑même (utilisez cc‑debugging), à transformer la complexité du code fonctionnel (utilisez aposd‑simplifying‑complexity), ou au code hérité non testé (il renvoie à welc‑legacy‑code).
