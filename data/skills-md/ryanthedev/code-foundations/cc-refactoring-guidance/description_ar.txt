يوجه إعادة تشكيل آمنة باستخدام منهجية «إصلاح أولاً ثم إعادة تشكيل» في Code Complete: يحدد بين إعادة التشكيل، وإعادة الكتابة، وإصلاح أولاً؛ يفرض الالتزام بفواصل منفصلة؛ يطبق صرامة التغييرات الصغيرة على الأسطر الواحدة ذات معدل الأخطاء العالي. ليس لتشخيص الخطأ نفسه (استخدم cc-debugging)، أو لتحويل تعقيد الكود العامل (استخدم aposd-simplifying-complexity)، أو للكود التقليدي غير المختبر (يتم توجيهه إلى welc-legacy-code). يرجى دائمًا الرد بلغة المستخدم.
