Guía la refactorización segura usando la disciplina “fix-first-then-refactor” de Code Complete: decide entre refactorizar, reescribir y fix-first; impone commits separados; aplica el rigor de cambios pequeños a una‑línea con alta tasa de errores. No es para diagnosticar el error en sí (use cc-debugging), transformar la complejidad del código que funciona (use aposd-simplifying-complexity) o código heredado sin pruebas (se redirige a welc-legacy-code).
