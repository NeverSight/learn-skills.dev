Разбивает недостаточно уточнённые запросы, классифицируя пробелы (отсутствующая информация, неоднозначность, ложные предпосылки) и генерируя целенаправленные уточняющие вопросы. Формирует подтверждённое описание проблемы до начала любой реализации. Предназначено для уточнения уже существующего запроса; не подходит для открытого поиска требований из расплывчатой идеи (используйте команду research).
