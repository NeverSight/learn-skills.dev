Descompone solicitudes poco precisas clasificando las brechas (información faltante, ambigüedad, premisas falsas) y generando preguntas aclaratorias dirigidas. Produce una declaración de problema confirmada antes de que comience cualquier implementación. Para refinar una solicitud que ya existe; no para la exploración abierta de requisitos a partir de una idea vaga (utilice el comando de investigación).
