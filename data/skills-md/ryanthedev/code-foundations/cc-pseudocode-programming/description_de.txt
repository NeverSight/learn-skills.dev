Strukturiert das Routinedesign durch eine Pseudocode‑erste Iteration: klärt Benennung und Zweck vor jeglichem Code, erkennt Designfehler kostengünstig und verhindert Kompilier‑Debug‑Schleifen bei schlecht verstandenen Routinen. Für das Entwerfen einer Routine vor dem Schreiben; nicht zur Bewertung bereits existierender Routinen (verwenden Sie cc-routine-and-class-design).
