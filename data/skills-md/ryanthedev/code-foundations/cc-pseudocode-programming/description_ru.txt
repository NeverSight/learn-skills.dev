Структурирует проектирование процедур посредством итераций, начинающихся с псевдокода: уточняет названия и назначение до написания кода, дешево выявляет проектные недостатки и предотвращает циклы компиляции‑отладки в плохо понятных процедурах. Предназначено для проектирования процедуры перед её написанием; не подходит для оценки уже существующих процедур (используйте cc-routine-and-class-design).
