يقوم بتدقيق وإعادة هيكلة تدفق التحكم باستخدام قواعد nesting، التعقيد الحلقي (cyclomatic complexity)، تصميم الحلقات، شرط الحراسة (guard‑clause)، وتبسيط القيم المنطقية وفقًا لكتاب Code Complete. يغطي التعمق في nesting، تصميم خروجات الحلقات، تسميات الفهارس، وسلاسل الاستدعاءات اللاحقة. يختص بتدفق التعليمات داخل الروتين؛ ليس لتصميم الروتين/الفئة (استخدم cc‑routine‑and‑class‑design) أو لتهيئة إعادة هيكلة أوسع (استخدم cc‑refactoring‑guidance).
