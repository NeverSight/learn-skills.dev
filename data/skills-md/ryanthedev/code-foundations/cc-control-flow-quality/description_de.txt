Prüft und restrukturiert den Kontrollfluss anhand der Verschachtelungs‑, zyklomatischen Komplexitäts‑, Schleifendesign‑, Guard‑Clause‑ und booleschen Vereinfachungsregeln von Code Complete. Behandelt tiefe Verschachtelung, das Design von Schleifenausgängen, Indexbenennung und Callback‑Ketten. Für den Anweisungs‑level‑Fluss innerhalb einer Routine; nicht für die Routine‑/Klassenstruktur (verwende cc-routine-and-class-design) oder für die Planung einer umfassenderen Refaktorisierung (verwende cc-refactoring-guidance).
