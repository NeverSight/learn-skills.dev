Проводит аудит и перестраивает поток управления, используя правила вложенности, цикломатической сложности, проектирования циклов, guard‑clause и упрощения булевых выражений из Code Complete. Охватывает глубокую вложенность, дизайн выхода из цикла, именование индексов и цепочки обратных вызовов. Предназначено для анализа потока на уровне операторов внутри процедуры; не предназначено для структуры процедуры/класса (используйте cc-routine-and-class-design) или для планирования более масштабного рефакторинга (используйте cc-refactoring-guidance).
