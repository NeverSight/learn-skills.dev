Проводит аудит и улучшает ясность кода и документацию, используя правила очевидности APOSD: качество имен, точность комментариев, полноту документации, ориентированной на ИИ, и процесс «комментарии‑сначала» для нового кода. Не предназначено для создания общепроектных документов по конвенциям (используйте code-standards) или структурного упрощения самого кода (используйте aposd-simplifying-complexity). Пожалуйста, всегда отвечайте на языке пользователя.
