Guida all’invio di sottagenti per lo strumento Agent — se delegare o lavorare inline, il contratto di delega in quattro parti, la selezione di modello e sforzo, il dimensionamento del fan‑out parallelo, fork vs nuovo sottagente e l’invio di agenti verificatori indipendenti. Da usare prima di qualsiasi chiamata allo strumento Agent: generare sottagenti, distribuire il lavoro su file o angoli di ricerca, delegare l’esplorazione o la revisione, informare un verificatore o decidere se la delega valga la pena. Non è per: formulare un prompt che non è un invio di agente (usa oberskills:prompt) o creare file di definizione riutilizzabili di skill e agent — struttura, frontmatter e valutazioni (usa oberskills:skill-craft); i loro corpi di prompt (usa oberskills:prompt).
