建立、評估與審核 Claude Code 技能與可重複使用的代理人定義檔（結構、前置資料、評估）。涵蓋 skill 與 subagent 與 hook 的決策、SKILL.md 的撰寫與前置資料、觸發描述最佳化、以 skill-eval MCP 工具進行基線優先評估與壓力測試、驗證與打包。當建立新技能、改進或基準測試現有技能、審查技能目錄，或為技能撰寫評估時使用。 不適用於提示語句的設計或審查——包括在代理人定義中內嵌提示正文（使用 oberskills:prompt）、即時子代理分派（使用 oberskills:agent）或文字編輯（使用 oberskills:write）。 請始終以使用者的語言回覆。
