Claude Code のスキルと再利用可能なエージェント定義ファイル（構造、フロントマター、評価）を作成、評価、レビューします。スキル‑対‑サブエージェント‑対‑フックの判断、SKILL.md の執筆とフロントマター、トリガー記述の最適化、スキル評価 MCP ツールによるベースライン優先の評価と圧力テスト、検証、パッケージ化をカバーします。新しいスキルを作成する際、既存のスキルを改善またはベンチマークする際、スキルディレクトリをレビューする際、あるいはスキルの評価を書き込む際に使用してください。プロンプト文言の設計やレビュー（エージェント定義内にプロンプト本文を入れる場合は oberskills:prompt を使用）、ライブサブエージェントのディスパッチ（oberskills:agent を使用）、文章の編集（oberskills:write を使用）は対象外です。
