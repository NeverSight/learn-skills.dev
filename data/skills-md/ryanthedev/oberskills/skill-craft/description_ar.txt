إنشاء وتقييم ومراجعة مهارات Claude Code وملفات تعريف الوكيل القابلة لإعادة الاستخدام (البنية، الفروتماتر، الاختبارات). يغطي قرار المهارة مقابل الوكيل الفرعي مقابل الخطاف، تأليف ملف SKILL.md والفروتماتر، تحسين وصف المشغَّل، الاختبارات الأولية مع اختبار الضغط عبر أدوات skill‑eval MCP، التحقق، والتعبئة. يُستعمل عند إنشاء مهارة جديدة، تحسين أو قياس أداء مهارة موجودة، مراجعة دليل مهارات، أو كتابة اختبارات لمهارة. ليس لتصميم أو مراجعة صياغة المطالبات — بما في ذلك نص المطالبة داخل تعريف الوكيل (استخدم oberskills:prompt)، إرسال وكيل فرعي مباشر (استخدم oberskills:agent)، أو تحرير النثر (استخدم oberskills:write).

يرجى دائمًا الرد بلغة المستخدم.
