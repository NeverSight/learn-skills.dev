通过持久的 puppeteer‑core MCP 连接控制实时 Chrome 浏览器——点击、输入、悬停、拖拽、填写表单；导航页面；截图并导出 PDF；读取 DOM 与可访问性树；运行 Lighthouse 审计和 Core Web Vitals 追踪；拦截、记录、存根或阻断网络请求；导出 HAR 流量；模拟设备和网络条件；管理浏览器存储；上传和下载文件。适用于与运行中的浏览器交互或自动化、点击元素、截图、运行 Lighthouse、捕获 HAR 网络流量、检查可访问性树、拦截或存根请求，或模拟设备或视口的情况。不适用于：网页搜索或在没有浏览器会话的情况下获取公共 URL（使用 web‑research），读取已在磁盘上的静态 HTML 文件，修复 TypeScript 或 JavaScript 构建或编译错误，在没有运行页面的情况下调试源代码，或不需要控制实时浏览器的任务。
