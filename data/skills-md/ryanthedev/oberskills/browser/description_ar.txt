يتحكم في متصفح Chrome حيًّا عبر اتصال مستمر من نوع puppeteer‑core MCP — النقر، الكتابة، التحويم، السحب، تعبئة النماذج؛ تصفّح الصفحات؛ أخذ لقطات شاشة وتصدير ملفات PDF؛ قراءة شجرة الـ DOM وشجرة إمكانية الوصول؛ تشغيل تدقيقات Lighthouse وتتبع Core Web Vitals؛ اعتراض، تسجيل، تمثيل أو حجب طلبات الشبكة؛ تصدير حركة مرور HAR؛ محاكاة الأجهزة وظروف الشبكة؛ إدارة تخزين المتصفح؛ رفع وتنزيل الملفات. يُستَخدم عندما تحتاج إلى التفاعل مع أو أتمتة متصفح جارٍ، النقر على العناصر، أخذ لقطات شاشة، تشغيل Lighthouse، التقاط حركة مرور الشبكة بصيغة HAR، فحص شجرة إمكانية الوصول، اعتراض أو تمثيل الطلبات، أو محاكاة جهاز أو مساحة عرض. لا يُستخدم لـ: البحث في الويب أو جلب عناوين URL عامة دون جلسة متصفح (استخدم web‑research)، قراءة ملف HTML ثابت موجود على القرص، إصلاح أخطاء بناء أو تجميع TypeScript أو JavaScript، تصحيح شفرة المصدر دون صفحة تعمل، أو أي مهمة لا تتطلب التحكم في متصفح حي.
