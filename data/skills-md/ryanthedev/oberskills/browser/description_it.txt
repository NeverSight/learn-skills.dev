Controlla un browser Chrome live tramite una connessione persistente MCP di puppeteer‑core — clicca, digita, passa il mouse, trascina, compila moduli; naviga tra le pagine; cattura screenshot ed esporta PDF; legge il DOM e l'albero di accessibilità; esegue audit Lighthouse e tracce Core Web Vitals; intercetta, registra, simula o blocca richieste di rete; esporta il traffico HAR; emula dispositivi e condizioni di rete; gestisce lo storage del browser; carica e scarica file. Da utilizzare quando si interagisce con o si automatizza un browser in esecuzione, si cliccano elementi, si fanno screenshot, si esegue Lighthouse, si cattura il traffico di rete come HAR, si verifica l'albero di accessibilità, si intercettano o simulano richieste, o si emula un dispositivo o una viewport. Non è adatto per: ricerca web o recupero di URL pubblici senza una sessione del browser (usa web‑research), lettura di un file HTML statico già su disco, correzione di errori di compilazione o build di TypeScript o JavaScript, debug del codice sorgente senza una pagina in esecuzione, o compiti che non richiedono il controllo di un browser live.
