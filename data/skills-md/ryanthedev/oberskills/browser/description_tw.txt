透過持續的 puppeteer‑core MCP 連線控制即時的 Chrome 瀏覽器——點擊、輸入、懸停、拖曳、填寫表單；導覽頁面；截圖與匯出 PDF；讀取 DOM 與可及性樹；執行 Lighthouse 稽核與 Core Web Vitals 追蹤；攔截、記錄、模擬或封鎖網路請求；匯出 HAR 流量；模擬裝置與網路條件；管理瀏覽器儲存；上傳與下載檔案。適用於與正在執行的瀏覽器互動或自動化、點擊元素、截圖、執行 Lighthouse、捕捉 HAR 網路流量、檢查可及性樹、攔截或模擬請求、或模擬裝置或視口的情境。非適用於：使用網路搜尋或在未開啟瀏覽器會話的情況下取得公開 URL（請使用 web‑research）、讀取已在磁碟上的靜態 HTML 檔案、修正 TypeScript 或 JavaScript 的建置或編譯錯誤、在沒有執行頁面的情況下除錯原始碼，或不需要控制即時瀏覽器的任務。
