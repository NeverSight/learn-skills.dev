永続的な puppeteer‑core MCP 接続を介してライブ Chrome ブラウザを制御します — クリック、入力、ホバー、ドラッグ、フォーム入力；ページのナビゲーション；スクリーンショット取得と PDF エクスポート；DOM とアクセシビリティツリーの読み取り；Lighthouse 監査と Core Web Vitals トレースの実行；ネットワークリクエストのインターセプト、記録、スタブ、ブロック；HAR トラフィックのエクスポート；デバイスやネットワーク条件のエミュレーション；ブラウザストレージの管理；ファイルのアップロードとダウンロード。  

以下のような場合に使用します：実行中のブラウザと対話または自動化したいとき、要素のクリック、スクリーンショット取得、Lighthouse 実行、ネットワークトラフィックを HAR として取得、アクセシビリティツリーの確認、リクエストのインターセプトやスタブ、デバイスやビューポートのエミュレーションなど。  

使用しないケース：ブラウザセッションなしでウェブ検索や公開 URL の取得（その場合は web‑research を使用）、ディスク上の静的 HTML ファイルを読むだけ、TypeScript や JavaScript のビルド・コンパイルエラーの修正、ページが実行されていない状態でのソースコードデバッグ、ライブブラウザの制御を必要としないタスク。
