应用数据可视化和信息设计原则，以真实且高效的方式编码数据。适用于关于图表或图形的问题——图表类型选择（柱形图、折线图、散点图、热力图、小倍图），数据墨水比与图表冗余减少（Tufte VDQI），先觉属性（Knaflic Storytelling with Data），仪表板布局与 KPI 设计（Few Information Dashboard Design），真实编码与图表欺骗检测（Cairo How Charts Lie），标记与通道（Munzner），针对色盲安全的图表配色方案选择，或图表可访问性。非适用情形：品牌或 UI 配色方案生成（use core color mode）；整体页面构图和视觉层次（use core audit mode）；作为 UI 模式的数据展示表格（use usability）；字体或字型选择（use core fonts mode）；UI 文案或写作（use content-design）。
