Aplica principios de visualización de datos y diseño de información para codificar los datos de manera veraz y eficiente. Úsalo cuando la pregunta sea sobre gráficos o diagramas — selección del tipo de gráfico (barras, líneas, dispersión, mapa de calor, pequeños múltiplos), proporción de tinta de datos y reducción de elementos superfluos (Tufte VDQI), atributos preatencionales (Knaflic Storytelling with Data), diseño de paneles y KPI (Few Information Dashboard Design), codificación veraz y detección de engaños en gráficos (Cairo How Charts Lie), marcas y canales (Munzner), selección de paletas seguras para daltónicos en gráficos, o accesibilidad de los gráficos. No es para: generación de paletas de color de marca o UI (usa el modo color central); composición general de página y jerarquía visual (usa el modo auditoría central); tablas de visualización de datos como patrón UI (usa usabilidad); selección de tipografía o fuente (usa el modo fuentes central); redacción de copia UI o escritura (usa diseño de contenido).

Por favor, siempre responde en el idioma del usuario.
