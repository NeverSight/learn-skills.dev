應用資料視覺化與資訊設計原則，真實且高效地編碼資料。當問題涉及圖表或圖形時使用 — 圖表類型選擇（長條圖、折線圖、散點圖、熱圖、小多重圖），資料墨水比與圖表雜訊減少（Tufte VDQI），前注意屬性（Knaflic Storytelling with Data），儀表板布局與 KPI 設計（Few Information Dashboard Design），真實編碼與圖表謊言偵測（Cairo How Charts Lie），標記與通道（Munzner），針對色盲安全的圖表調色盤選擇，或圖表可及性。不適用於：品牌或使用者介面色彩調色盤生成（使用 core color 模式）；整體頁面構成與視覺層次（使用 core audit 模式）；作為 UI 模式的資料顯示表格（使用 usability）；字型或字體選擇（使用 core fonts 模式）；UI 文案或寫作（使用 content-design）。請始終以使用者的語言回覆。
