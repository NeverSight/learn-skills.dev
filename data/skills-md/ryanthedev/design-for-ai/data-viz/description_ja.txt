データ可視化および情報デザインの原則を適用し、データを真実かつ効率的にエンコードします。質問がチャートやグラフに関する場合に使用します — チャートタイプの選択（棒、折れ線、散布図、ヒートマップ、スモールマルチプル）、データインク比とチャートジャンク削減（Tufte VDQI）、先行注意属性（Knaflic Storytelling with Data）、ダッシュボードレイアウトとKPI設計（Few Information Dashboard Design）、真実のエンコードとチャートの嘘検出（Cairo How Charts Lie）、マークとチャネル（Munzner）、色覚異常に配慮したパレット選択、またはチャートのアクセシビリティ。

対象外：ブランドや UI のカラーパレット生成（core color mode を使用）; ページ全体の構成と視覚階層（core audit mode を使用）; UI パターンとしてのデータ表示テーブル（usability を使用）; 書体やフォントの選択（core fonts mode を使用）; UI コピーや文書作成（content‑design を使用）。
