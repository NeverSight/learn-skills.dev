Produce mockup e wireframe HTML/CSS autonomi a partire da token di design e specifiche di pagina — l'output è sempre un file .html visualizzabile, non linee guida o codice. Da utilizzare quando la richiesta è vedere un design, creare un mockup, costruire o mostrare un prototipo, creare un wireframe, generare un'anteprima o visualizzare l'aspetto di una pagina prima di scrivere il codice di produzione. Legge i token in DESIGN.md e le specifiche di pagina in JOURNEY.md quando presenti; utilizza i valori predefiniti in scala di grigi per i wireframe se assenti. Rende tramite il browser MCP e restituisce il percorso dello screenshot quando connesso; emette il .html con una nota aperta quando non è connesso. Non è per: scegliere o definire font, colori, identità visiva o token di design (usare core design); criticare, auditare o rivedere un design esistente (usare core audit); pianificare IA, flussi o specifiche di pagina (usare journey); costruire un sistema di token di design o una libreria di componenti (usare design-systems).
