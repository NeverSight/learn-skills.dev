Produit des maquettes et des wireframes HTML/CSS autonomes à partir des jetons de conception et des spécifications de page — le résultat est toujours un fichier .html affichable, et non des directives ou du code. À utiliser lorsque la demande consiste à voir un design, créer une maquette, construire ou présenter un prototype, créer un wireframe, générer un aperçu, ou visualiser à quoi ressemble une page avant d’écrire le code de production. Lit les jetons de DESIGN.md et les spécifications de page JOURNEY.md lorsqu’ils sont présents ; utilise les paramètres par défaut en niveaux de gris pour les wireframes lorsqu’ils sont absents. Rend via le navigateur MCP et renvoie le chemin d’une capture d’écran lorsqu’il est connecté ; génère le .html avec une note ouverte sinon. Pas destiné à : choisir ou définir les polices, les couleurs, l’identité visuelle ou les jetons de conception (utiliser core design) ; critiquer, auditer ou examiner un design existant (utiliser core audit) ; planifier l’IA, les flux ou les spécifications de page (utiliser journey) ; construire un système de jetons de conception ou une bibliothèque de composants (utiliser design‑systems). Veuillez toujours répondre dans la langue de l'utilisateur.
