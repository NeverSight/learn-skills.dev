Produce maquetas y wireframes autoconclusivos en HTML/CSS a partir de tokens de diseño y especificaciones de página — la salida es siempre un archivo .html visible, no orientación ni código. Úselo cuando la solicitud sea ver un diseño, crear una maqueta, construir o mostrar un prototipo, crear un wireframe, generar una vista previa o visualizar cómo se ve una página antes de escribir el código de producción. Lee los tokens DESIGN.md y las especificaciones de página JOURNEY.md cuando están presentes; usa valores predeterminados de wireframe en escala de grises cuando no los hay. Renderiza a través del navegador MCP y devuelve una ruta de captura de pantalla cuando está conectado; emite el .html con una nota abierta cuando no lo está. No es para: elegir o definir fuentes, colores, identidad visual o tokens de diseño (use core design); criticar, auditar o revisar un diseño existente (use core audit); planificar IA, flujos o especificaciones de página (use journey); construir un sistema de tokens de diseño o una biblioteca de componentes (use design-systems). Por favor, responde siempre en el idioma del usuario.
