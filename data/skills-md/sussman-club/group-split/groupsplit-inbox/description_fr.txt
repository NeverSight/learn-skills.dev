Transformez les lignes bancaires importées en dépenses GroupSplit sans enregistrer deux fois le même argent. UTILISER POUR : la boîte de réception GroupSplit, les lignes bancaires importées ou synchronisées, le classement d'une ligne bancaire comme dépense, le rapprochement d'un relevé de carte avec ce qu'un groupe a déjà enregistré, un refus POSSIBLE_DUPLICATE_EXPENSE, une "boîte de réception groupsplit", une "banque groupsplit" ou des "correspondances bancaires de transactions groupsplit". NE PAS UTILISER POUR : l'enregistrement d'une dépense saisie par quelqu'un (c'est-à-dire « création de transactions »), les soldes, le règlement ou toute autre chose dans la CLI - utilisez la compétence groupsplit. REQUIERT : la compétence groupsplit pour le contrat JSON, les codes de sortie et le protocole de confirmation. Lisez-le d'abord.
