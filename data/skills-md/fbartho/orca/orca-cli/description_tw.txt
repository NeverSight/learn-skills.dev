透過「orca」 CLI 操作 Orca 管理的工作樹、資料夾上下文、終端機、儲存庫、自動化、工件、技能共享、工作樹註解和 Orca 的嵌入式瀏覽器。當使用者說“$orca-cli”、“Orca 工作樹”、“子工作樹”、“在工作樹中生成 codex/claude”、“讀取/等待/發送 Orca 工作樹”、“移交”/“移交”/“將其交給另一個代理”、“Orca 瀏覽器”、“orca 工件”或“共享技能”時使用。當涉及 Orca 狀態時，比原始 git worktree、ad hoc PTY 或電腦使用更喜歡它。使用電腦 僅用於需要作業系統層級控制的外部視窗或桌面 UI，以及用於外部頁面的 Playwright 或 CDP。
