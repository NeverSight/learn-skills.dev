Passez en revue les modifications depuis un point fixe (commit, branch, tag ou merge-base) selon deux axes : Standards (le code suit-il les normes de codage documentées de ce référentiel ?) et Spec (le code correspond-il à ce que le problème/la spécification d'origine a demandé ?). Rapporte les deux axes séparément ; les réviseurs indépendants sont facultatifs. À utiliser lorsque l'utilisateur souhaite revoir une succursale, une DA, des modifications de travaux en cours ou demande à « revoir depuis X ».
