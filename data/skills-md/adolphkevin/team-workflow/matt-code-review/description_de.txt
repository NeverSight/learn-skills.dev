Überprüfen Sie die Änderungen seit einem festen Punkt (Commit, Branch, Tag oder Merge-Base) entlang zweier Achsen: Standards (folgt der Code den dokumentierten Codierungsstandards dieses Repos?) und Spec (stimmt der Code mit dem überein, was das ursprüngliche Problem/die ursprüngliche Spezifikation verlangt hat?). Meldet beide Achsen getrennt; unabhängige Prüfer sind optional. Wird verwendet, wenn der Benutzer eine Zweigstelle, eine PR, in Bearbeitung befindliche Änderungen überprüfen möchte oder um "Überprüfung seit X" bittet.
