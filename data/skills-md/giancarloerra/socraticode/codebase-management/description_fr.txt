Configurez, indexez et gérez l'indexation de base de code SocratiCode. À utiliser lorsque l'utilisateur souhaite indexer un projet, vérifier l'état de l'infrastructure, démarrer/arrêter la surveillance des fichiers, configurer les artefacts de contexte, résoudre les problèmes d'indexation, gérer le graphe de code ou toute tâche administrative SocratiCode. S'active lorsque l'utilisateur mentionne l'indexation, la configuration de la recherche, l'infrastructure SocratiCode ou la gestion de l'index de base de code.
