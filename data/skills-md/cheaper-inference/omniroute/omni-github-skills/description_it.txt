Cerca, valuta, analizza e importa le abilità degli agenti dai repository GitHub che contengono SKILL.md, CLAUDE.md, .cursorrules e file simili di abilità per agenti. Scopri le abilità della community in molte categorie di strumenti e fornitori, valuta la rilevanza con un punteggio euristico, verifica la presenza di malware o segreti hardcoded e installale nelle directory degli agenti di Hermes, Claude Code, Gemini CLI o OpenCode.
