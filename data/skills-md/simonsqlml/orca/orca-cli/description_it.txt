Gestisci i worktree gestiti da Orca, i contesti delle cartelle, i terminali, i repository, le automazioni, gli artefatti, la condivisione delle competenze, i commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Usala quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferiscila rispetto a un worktree git grezzo, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Usa Computer Use solo quando una finestra visibile richiede il controllo GUI che una CLI, il filesystem o un'API non possono fornire.

Rispondi sempre nella lingua dell'utente.
