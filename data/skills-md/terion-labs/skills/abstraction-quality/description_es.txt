Úselo cuando decida si extraer una función, introducir una interfaz, crear una nueva clase, añadir un helper, dividir un módulo, añadir un hook de plugin o generalizar una pieza de código; al revisar una pull request que propone una nueva abstracción; cuando un helper compartido está aumentando parámetros de tipo bandera; cuando tiene duplicación y no está seguro de si extraerla; o cuando una abstracción existente se siente equivocada pero no puede nombrar por qué. También actívelo cuando el usuario pregunte “¿debo extraer esto?”, “¿es esta la abstracción correcta?”, “¿está sobre‑ingenierizado?”, “¿es suficientemente DRY?”, “¿debo generalizar esto?”, “¿debo añadir una interfaz aquí?” o “¿es una abstracción prematura?”. Esta habilidad proporciona un procedimiento de decisión; se referencia en writing-good-code y refactoring-and-reviewing-code, y también puede usarse por sí sola.
