Usa quando decidi se estrarre una funzione, introdurre un’interfaccia, creare una nuova classe, aggiungere un helper, suddividere un modulo, aggiungere un hook per plugin o generalizzare un pezzo di codice; quando revisioni una pull request che propone una nuova astrazione; quando un helper condiviso sta crescendo aggiungendo parametri flag; quando hai duplicazione e non sei sicuro se estrarla; o quando un’astrazione esistente sembra sbagliata ma non riesci a dire il perché. Attiva anche quando l’utente chiede “should I extract this?”, “is this the right abstraction?”, “is this over‑engineered?”, “is this DRY enough?”, “should I generalize this?”, “should I add an interface here?” o “is this premature abstraction?”. Questa competenza fornisce una procedura decisionale; è referenziata da writing‑good‑code e refactoring‑and‑reviewing‑code, e può essere usata anche da sola.  

Rispondi sempre nella lingua dell’utente.
