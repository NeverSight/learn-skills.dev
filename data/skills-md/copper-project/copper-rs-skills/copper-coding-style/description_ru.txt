Стиль кодирования и конвенции для рабочей области copper-rs (`cu29`) на Rust. Используйте их при написании, редактировании или проверке Rust‑кода, пользовательской документации или вывода в консоль/интерфейсе в этом репозитории, чтобы они соответствовали внутреннему стилю: именование, группировка импортов, обработка ошибок `CuResult`/`CuError`, дисциплина std/no_std, макросы логирования `debug!`/`info!`/`warning!`/`error!`, документирующие комментарии/доктесты, подводные камни clippy, ограничения трейтов payload и расположение тестов. Для описания архитектуры выполнения см. `copper-arch`; для ограничений основной реализации — `copper-core-dev`; для команд сборки/тестирования/отладки — `copper-workflow`.
