copper-rs（`cu29`）Rust ワークスペースのコーディングスタイルと規約です。このリポジトリ内で Rust コード、ユーザードキュメント、コンソール／UI 出力を書いたり、編集したり、レビューしたりする際に、命名規則、インポートのグループ化、`CuResult`／`CuError` のエラーハンドリング、std／no_std の方針、`debug!`／`info!`／`warning!`／`error!` ロギングマクロ、ドキュメントコメント／ドクトテスト、clippy の注意点、ペイロードトレイトの境界、テストのレイアウトなどが社内スタイルに合うように使用してください。ランタイムアーキテクチャは `copper-arch`、コア実装の制約は `copper-core-dev`、ビルド／テスト／デバッグコマンドは `copper-workflow` を参照してください。
