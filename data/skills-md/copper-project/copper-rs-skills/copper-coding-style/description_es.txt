Estilo de codificación y convenciones para el espacio de trabajo copper-rs (`cu29`) en Rust. Úsese al escribir, editar o revisar código Rust, documentación de usuario o salida de consola/UI en este repositorio para que coincida con el estilo interno: nombres, agrupación de importaciones, manejo de errores `CuResult`/`CuError`, disciplina std/no_std, los macros de registro `debug!/info!/warning!/error!`, comentarios/documentación de pruebas, trampas de clippy, límites de rasgos de payload y disposición de pruebas. Para la arquitectura de tiempo de ejecución consulte `copper-arch`; para las restricciones de implementación central consulte `copper-core-dev`; para los comandos de compilación/prueba/debug consulte `copper-workflow`.

Por favor, responda siempre en el idioma del usuario.
