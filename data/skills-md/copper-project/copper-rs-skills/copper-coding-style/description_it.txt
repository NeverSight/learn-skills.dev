Stile di codifica e convenzioni per l'ambiente Rust di copper-rs (`cu29`). Usalo quando scrivi, modifichi o rivedi codice Rust, documentazione utente o output console/UI in questo repository affinché rispetti lo standard interno: nomenclatura, raggruppamento degli import, gestione degli errori `CuResult`/`CuError`, disciplina std/no_std, le macro di logging `debug!/info!/warning!/error!`, commenti/documentazione/doctest, insidie di clippy, vincoli dei trait di payload e struttura dei test. Per l'architettura di runtime vedere `copper-arch`; per i vincoli di implementazione core vedere `copper-core-dev`; per i comandi di build/test/debug vedere `copper-workflow`.
