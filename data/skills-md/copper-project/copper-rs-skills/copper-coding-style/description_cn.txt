Copper-rs (`cu29`) Rust 工作区的编码风格与约定。编写、编辑或审阅本仓库中的 Rust 代码、用户文档或控制台/ UI 输出时使用，使其符合内部风格：命名、导入分组、`CuResult`/`CuError` 错误处理、std/no_std 规范、内部的 `debug!/info!/warning!/error!` 日志宏、文档注释/文档测试、Clippy 陷阱、payload 特征约束以及测试布局。运行时架构请参见 `copper-arch`；核心实现约束请参见 `copper-core-dev`；构建/测试/调试命令请参见 `copper-workflow`。

请始终使用用户的语言作答。
