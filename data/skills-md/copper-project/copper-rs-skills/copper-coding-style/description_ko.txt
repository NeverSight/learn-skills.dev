copper-rs(`cu29`) Rust 작업공간에 대한 코딩 스타일 및 규칙입니다. 이 저장소에서 Rust 코드를 작성·편집·검토하거나 사용자 문서, 콘솔/UI 출력을 만들 때 하우스 스타일에 맞추어 사용하십시오: 명명 규칙, import 그룹화, `CuResult`/`CuError` 오류 처리, std/no_std 규칙, 인터닝 `debug!/info!/warning!/error!` 로깅 매크로, 문서 주석·도크테스트, clippy 함정, 페이로드 트레이트 바운드, 테스트 레이아웃. 런타임 아키텍처는 `copper-arch`를, 핵심 구현 제약은 `copper-core-dev`를, 빌드·테스트·디버그 명령은 `copper-workflow`를 참조하십시오. 항상 사용자의 언어로 답변하십시오.
