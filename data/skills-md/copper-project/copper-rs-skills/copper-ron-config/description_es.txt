Referencia de esquema profunda para `copperconfig.ron`. Úsela al leer, escribir o depurar un archivo de configuración copper‑rs: cada clave de nivel superior, cada campo por tarea/por conexión/por puente, reglas tipadas de acceso `ComponentConfig` (`get` vs `get_value`) y los errores exactos de validación que emite el analizador. Todas las afirmaciones citan `core/cu29_runtime/src/config.rs`. Para la arquitectura de tiempo de ejecución y el modelo mental del grafo de tareas consulte `copper-arch`; para el formato `fmtron` y el ciclo `just fmt` consulte `copper-workflow`; para las reglas de “cómo debería sentirse un nuevo campo de configuración” (enumeraciones mediante `Deserialize`, sin análisis de cadenas) consulte `copper-api-flavor`.
