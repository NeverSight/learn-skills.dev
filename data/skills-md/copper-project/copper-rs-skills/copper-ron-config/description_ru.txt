Глубокая ссылка на схему для `copperconfig.ron`. Используйте её при чтении, записи или отладке конфигурационного файла copper‑rs: каждый ключ верхнего уровня, каждое поле per‑task/per‑cnx/per‑bridge, типизированные правила доступа `ComponentConfig` (`get` vs `get_value`), а также точные сообщения об ошибках валидации, которые выдаёт парсер. Все утверждения ссылаются на `core/cu29_runtime/src/config.rs`. Для архитектуры выполнения и ментальной модели графа задач см. `copper-arch`; для форматирования `fmtron` и цикла `just fmt` — `copper-workflow`; для правил «как должно ощущаться новое поле конфигурации» (перечисления через `Deserialize`, без строкового парсинга) — `copper-api-flavor`.

Пожалуйста, всегда отвечайте на языке пользователя.
