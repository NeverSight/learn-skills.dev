Ciclo de compilación, pruebas y depuración para el repositorio copper-rs (`cu29`). Úsalo al ejecutar los objetivos `just` alineados con CI (pr-check/lint/test/std-ci/nostd-ci/api-check), al añadir o revisar recetas del justfile, publicar versiones estables, configurar el entorno para que pasen, renderizar el DAG, expandir la macro de tiempo de ejecución, o depurar una aplicación en ejecución/grabada mediante el registro unificado `.copper`: extracción de copperlists, resim (reproducción determinista), la API de depuración remota, o la exportación a Python. Para la arquitectura consulta `copper-arch`; para el estilo de código consulta `copper-coding-style`.
