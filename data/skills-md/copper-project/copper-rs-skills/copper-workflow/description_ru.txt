Процесс сборки, тестирования и отладки для репозитория copper-rs (`cu29`). Используйте его при запуске CI‑соответствующих целей `just` (pr-check/lint/test/std-ci/nostd-ci/api-check), добавлении или просмотре рецептов в justfile, публикации стабильных релизов, настройке окружения для их успешного выполнения, построении DAG, раскрытии макроса времени выполнения, а также при отладке работающего или записанного приложения через унифицированный лог `.copper`: извлечение copperlists, resim (детерминированный повтор), удалённый API отладки или экспорт в Python. Для архитектуры см. `copper-arch`; для стиля кода — `copper-coding‑style`.
