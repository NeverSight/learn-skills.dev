Руководство по разработке ядра runtime для рабочего пространства copper-rs (`cu29`). Используйте его при изменении кода в каталоге `core/` или поведения, затрагивающего всю среду выполнения: планирование выполнения, трейты задач/мостов, генерация proc‑macro, разбор конфигураций, подключение ресурсов, унифицированное логирование и воспроизведение, публичные API, производительность в реальном времени или совместимость с `std`/`no_std`. Для обзора модели выполнения см. `copper-arch`; для правил кодирования — `copper-coding-style`; для проверки, согласованной с CI, — `copper-workflow`.
