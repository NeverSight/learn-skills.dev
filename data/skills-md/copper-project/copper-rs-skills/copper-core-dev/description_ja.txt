Copper - rs （' cu 29 '）ワークスペースのコアランタイム開発ガイド。`core /'またはランタイム全体の動作の下でコードを変更する場合に使用します。実行計画、タスク/ブリッジトレイト、proc - macro生成、構成解析、リソース配線、ユニファイドロギングとリプレイ、パブリックAPIサーフェイス、リアルタイムパフォーマンス、または` std '/' no_std `互換性。実行モデルの概要については、' copper - arch `を参照してください。コードの規則については、' copper - coding - style `を参照してください。CIに沿った検証については、' copper - workflow `を参照してください。
