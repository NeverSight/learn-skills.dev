Guida allo sviluppo del core-runtime per lo spazio di lavoro copper-rs (`cu29`). Utilizzala quando modifichi il codice sotto `core/` o il comportamento a livello di runtime: pianificazione dell'esecuzione, trait di task/bridge, generazione di proc-macro, parsing della configurazione, collegamento delle risorse, logging unificato e replay, interfacce API pubbliche, prestazioni in tempo reale o compatibilità `std`/`no_std`. Per la panoramica del modello di esecuzione vedi `copper-arch`; per le convenzioni di codifica vedi `copper-coding-style`; per la verifica allineata al CI vedi `copper-workflow`.
