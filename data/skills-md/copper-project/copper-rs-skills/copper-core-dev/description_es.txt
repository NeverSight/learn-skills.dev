Guía de desarrollo Core-runtime para el espacio de trabajo copper-rs (`cu29`). Utilícelo al cambiar el código en `core/` o en el comportamiento de todo el tiempo de ejecución: planificación de ejecución, rasgos de tarea/puente, generación proc-macro, análisis de configuración, cableado de recursos, registro y reproducción unificados, superficies de API públicas, rendimiento en tiempo real o compatibilidad `std`/'no_std`. Para la descripción general del modelo de ejecución, consulte `copper-arch`; para las convenciones de código, consulte `copper-coding-style`; para la verificación alineada con CI, consulte `copper-workflow`.
