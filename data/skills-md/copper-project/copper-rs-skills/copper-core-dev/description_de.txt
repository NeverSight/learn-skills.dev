Core-Laufzeit-Entwicklungsleitfaden für den Arbeitsbereich copper-rs (`cu29`). Verwendung beim Ändern von Code unter `core/` oder Laufzeit-weiten Verhalten: Ausführungsplanung, Task-/Bridge-Eigenschaften, Proc-Macro-Generierung, Konfigurations-Parsing, Ressourcenverkabelung, Unified Logging und Replay, öffentliche API-Oberflächen, Echtzeit-Performance oder `std`/`no_std` -Kompatibilität. Für die Ausführungsmodellübersicht siehe `copper-arch`; für Codekonventionen siehe `copper-coding-style'; für CI-ausgerichtete Verifizierung siehe `copper-workflow`.
