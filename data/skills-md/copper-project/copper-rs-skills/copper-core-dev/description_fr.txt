Guide de développement Core-runtime pour l'espace de travail cuivre-rs (`cu29`). À utiliser lors de la modification du code sous le comportement « core/» ou à l'échelle de l'exécution : planification de l'exécution, traits de caractère des tâches/ponts, génération de macro-proc, analyse de configuration, câblage des ressources, journalisation et relecture unifiées, surfaces d'API publiques, performances en temps réel ou compatibilité « std »/« no_std ». Pour la vue d'ensemble du modèle d'exécution, voir « copper-arch » ; pour les conventions de code, voir « copper-coding-style » ; pour la vérification alignée sur CI, voir « copper-workflow ».
