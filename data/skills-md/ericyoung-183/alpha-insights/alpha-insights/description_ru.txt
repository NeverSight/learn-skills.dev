Навыки бизнес-аналитика. Активируется, когда пользователи спрашивают о бизнес-анализе, отраслевых исследованиях, конкурентном анализе, анализе продуктов, анализе бизнес-моделей, обнаружении бизнес-возможностей, стратегии выхода на рынок, инвестиционных решениях, стратегическом планировании, комплексной проверке и других стратегических темах. Предоставляет подробные исследовательские отчеты в формате HTML для принятия решений посредством семиэтапного рабочего процесса (Брифинг → Разработка → Планирование → Исследование → Аналитическая информация → Отчет → Итерация).
