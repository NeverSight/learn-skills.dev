Créer et utiliser un index colonnaire clusterisé (CCI) pour les requêtes analytiques OLAP/HTAP sur PolarDB‑X 2.0 Enterprise Edition. Couvre la syntaxe de création du CCI, le choix des clés de partition/tri, l’optimisation des requêtes, les instantanés (AS OF TSO), les commandes SHOW/CHECK, les limites DDL, CCI vs GSI.  
À utiliser lorsque l’utilisateur a besoin de requêtes analytiques (agrégation, scans de tables larges, rapports) sur PolarDB‑X, souhaite activer le HTAP, ou interroge le stockage colonnaire.  
Déclencheurs : « CCI », « 列存索引 », « columnar index », « OLAP », « 分析查询 », « HTAP », « 宽表聚合 », « CLUSTERED COLUMNAR », « 行列混存 », « 列存快照 », « AS OF TSO », « SHOW COLUMNAR », « 排序键 », « sort key ».
