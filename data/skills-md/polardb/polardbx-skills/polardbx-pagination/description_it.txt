Paginazione efficiente e traversata di tabelle di grandi dimensioni per PolarDB‑X 2.0 Enterprise Edition. Raccomanda la paginazione Keyset (paginazione a cursore) al posto di LIMIT M,N per scenari di paginazione profonda, fornisce traversata per shard per casi estremi, include requisiti di indice ed esempi completi di codice Java. Da utilizzare quando si implementano query di paginazione, si attraversano tabelle di grandi dimensioni, si esportano dati in batch o si ottimizzano query lente con LIMIT M,N su PolarDB‑X.
