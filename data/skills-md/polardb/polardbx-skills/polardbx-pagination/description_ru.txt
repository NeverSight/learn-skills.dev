Эффективная пагинация и обход больших таблиц для PolarDB‑X 2.0 Enterprise Edition. Рекомендует использовать пагинацию по ключевому набору (Keyset pagination, курсорную пагинацию) вместо LIMIT M,N при сценариях глубокой пагинации, предоставляет обход по шардам в экстремальных случаях, включает требования к индексам и полноценные примеры кода на Java.  
Применяется при реализации запросов с пагинацией, обходе больших таблиц, пакетном экспорте данных или оптимизации медленных запросов LIMIT M,N в PolarDB‑X.  
Триггеры: «分页查询», «deep pagination», «Keyset pagination», «大表遍历», «数据导出», «LIMIT优化», «分页性能», «cursor pagination», «游标分页», «翻页慢», «深翻页», «pagination query», «batch traversal», «LIMIT M N slow», «efficient paging».
