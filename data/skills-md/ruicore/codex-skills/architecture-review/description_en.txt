General-purpose architecture review for any code repository. Use when Codex needs to assess concept ownership, authoritative sources, module boundaries, architecture decisions, architecture drift, duplicated concepts, scattered rules, hidden assumptions, over-engineering, architectural change surface, phased refactor planning, or how architecture exposes ownership and change boundaries to future coding agents. Do not use for ordinary code review, testing review, implementation review, framework review, style review, narrow bug diagnosis, or a standalone agent-legibility audit unless the user explicitly asks for architecture assessment.
