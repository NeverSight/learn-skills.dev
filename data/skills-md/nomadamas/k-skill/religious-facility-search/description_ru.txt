Используйте, когда пользователь запрашивает поиск близлежащих церквей, соборов, поиск храма/святыни, запрос о религиозных объектах или поиск церкви/собора/храма по корейскому району, станции или достопримечательности. Вызовите официальный локальный API Kakao через k-skill-proxy, чтобы получить религиозные объекты, отсортированные по расстоянию, и организовать адрес, номер телефона и ссылку KakaoMap. Это навык, предназначенный только для поиска и не требующий ключа API пользователя.
