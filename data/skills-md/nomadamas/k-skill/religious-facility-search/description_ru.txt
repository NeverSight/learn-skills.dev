Используйте, когда пользователь запрашивает поиск близлежащей церкви, местонахождение собора, поиск храма или святыни, поиск религиозного объекта или поиск церкви/собора/храма по корейскому району, станции или достопримечательности. Вызовите официальный локальный API Kakao через прокси-сервер k‑skill, чтобы получить религиозные объекты, отсортированные по расстоянию, и скомпилируйте адрес, номер телефона и ссылку KakaoMap. Это навык, предназначенный только для запросов, не требующий ключа API пользователя.
