À utiliser lorsque l'utilisateur demande une recherche d'église à proximité, l'emplacement d'une cathédrale, une recherche de temple ou de sanctuaire, une demande d'établissement religieux ou une recherche d'église/cathédrale/temple par quartier, gare ou point de repère coréen. Appelez l'API officielle Kakao Local via le proxy k‑skill‑proxy pour récupérer les établissements religieux triés par distance et compiler l'adresse, le numéro de téléphone et le lien KakaoMap. Il s'agit d'une compétence de requête uniquement qui ne nécessite pas de clé API utilisateur.
