Da utilizzare quando l'utente richiede la ricerca di chiese nelle vicinanze, l'ubicazione di una cattedrale, una ricerca di templi o santuari, una richiesta di strutture religiose o una ricerca di chiese/cattedrali/templi per quartiere, stazione o punto di riferimento coreano. Chiama l'API Kakao Local ufficiale tramite k‑skill‑proxy per recuperare strutture religiose ordinate per distanza e compilare l'indirizzo, il numero di telefono e il collegamento KakaoMap. Si tratta di una capacità di sola query che non richiede una chiave API utente.
