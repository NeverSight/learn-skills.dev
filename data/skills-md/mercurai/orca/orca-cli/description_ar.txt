تشغيل شجرات العمل المُدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والمواد الناتجة، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على شجرة git الخام، أو PTYs المؤقتة، أو استخدام الحاسوب عندما تكون حالة Orca مشمولة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى تحكم رسومي لا يستطيع سطر الأوامر أو نظام الملفات أو API تحقيقه.
