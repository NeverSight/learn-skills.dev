Opérez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via le CLI `orca`. Utilisez‑le lorsque l’utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Privilégiez‑le aux worktrees git bruts, PTY ad‑hoc ou à l’utilisation de l’ordinateur lorsque l’état d’Orca est impliqué. N’utilisez l’« Utilisation de l’ordinateur » que lorsqu’une fenêtre visible nécessite un contrôle GUI qu’un CLI, le système de fichiers ou une API ne peuvent réaliser.

Veuillez toujours répondre dans la langue de l’utilisateur.
