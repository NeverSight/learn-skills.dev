Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関係している場合は、生の git ワークツリーやアドホック PTY、または Computer Use よりもこちらを優先してください。CLI、ファイルシステム、または API では対応できない、可視ウィンドウの GUI 操作が必要な場合にのみ Computer Use を利用してください。
