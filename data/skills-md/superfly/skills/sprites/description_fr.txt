Utilisez cette compétence pour Sprites — des environnements Linux cloud isolés et persistants de Fly.io avec leur propre système de fichiers, URL, services, points de contrôle et politique réseau. Activez‑la pour créer, lister, exécuter dans, ou détruire des sprites ; pour exécuter des builds, des tests ou des agents dans un bac à sable distant ; pour démarrer des services à long terme et exposer une URL de prévisualisation ; pour prendre un instantané et revenir à un état antérieur ; pour modifier les règles réseau sortantes ; pour appeler des API tierces (GitHub, Slack, etc.) via la passerelle injectant les informations d’identification ; ou chaque fois que l’utilisateur mentionne Sprites, sprite‑env ou sprites.dev. Fonctionne aussi bien depuis l’intérieur d’un sprite que depuis une machine extérieure.
