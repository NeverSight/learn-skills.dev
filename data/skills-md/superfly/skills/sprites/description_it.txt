Usa questa funzionalità per Sprites — ambienti Linux cloud isolati e persistenti di Fly.io con il proprio filesystem, URL, servizi, checkpoint e policy di rete. Attivala per creare, elencare, entrare o distruggere sprite; per eseguire build, test o agenti in una sandbox remota; per avviare servizi a lungo termine ed esporre un URL di anteprima; per fare snapshot e ripristinare lo stato; per modificare le regole di rete in uscita; per chiamare API di terze parti (GitHub, Slack, ecc.) tramite il gateway che inietta credenziali; o ogni volta che l'utente cita Sprites, sprite‑env o sprites.dev. Funziona sia dall'interno di uno sprite sia da una macchina esterna.
