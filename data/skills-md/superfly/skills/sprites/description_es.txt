Usa esta habilidad para Sprites — entornos Linux en la nube aislados y persistentes de Fly.io con su propio sistema de archivos, URL, servicios, puntos de control y política de red. Actívala para crear, listar, entrar o destruir sprites; para ejecutar compilaciones, pruebas o agentes en un sandbox remoto; para iniciar servicios de larga duración y exponer una URL de vista previa; para crear instantáneas y revertir el estado; para cambiar las reglas de red saliente; para llamar a APIs de terceros (GitHub, Slack, etc.) a través de la puerta de enlace que inyecta credenciales; o siempre que el usuario mencione Sprites, sprite‑env o sprites.dev. Funciona tanto desde dentro de un sprite como desde una máquina externa.
