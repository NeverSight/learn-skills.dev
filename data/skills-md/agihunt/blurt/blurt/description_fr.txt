Écran + voix → travail structuré. L'utilisateur enregistre son écran tout en parlant (démo de son produit, navigation, exploration d'une idée) ; transformer l'enregistrement en éléments — problèmes de bug/amélioration avec étapes de reproduction, captures d’écran et code suspect, idées avec leur inspiration, notes, tâches — leur permettre de les revoir sur une page locale, puis exporter (Feishu/Lark Bitable, CSV/Markdown, GitHub Issues…) ou commencer à corriger. À utiliser lorsque l'utilisateur veut enregistrer des retours / QA / idées en parlant tout en utilisant son écran, remet une telle vidéo, ou veut traiter les enregistrements de l'application Blurt. Déclencheurs : « blurt », « /blurt », « 开始口喷 », « 口喷鸡 », « 开始录 », « 录屏提 bug », « 录一下我的想法 », « record feedback », « turn this recording into issues », « 处理我录的视频 », « process my recordings ».
