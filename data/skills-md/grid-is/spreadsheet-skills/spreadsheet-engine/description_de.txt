Excel-kompatible Tabellenkalkulations-Engine für JavaScript und TypeScript (@grid-is/spreadsheet-engine). Lade .xlsx‑Arbeitsmappen oder erstelle sie von Grund auf, werte Excel‑ und Google‑Sheets‑Formeln aus, lese berechnete Zellwerte, schreibe Zellen mit automatischer Neuberechnung des Abhängigkeitsgraphen, bearbeite Formeln und Tabellen und exportiere .xlsx – alles headless in Node, Deno, Bun oder im Browser ohne Excel‑Installation. Verwende sie, wenn eine Aufgabe das Auslesen von Formel‑Ergebnissen aus einer Excel‑Datei im Code, das Neuberechnen einer Tabelle, das Ausführen eines Formels‑Strings gegen eine Arbeitsmappe, „SheetJS berechnet keine Formeln“, das Erstellen eines Berechnungs‑Backends oder das programmgesteuerte Bearbeiten von Arbeitsmappen umfasst. Außerdem werden das CSV‑zu‑Arbeitsmappe‑Rezept sowie die Funktionsmodi von Excel gegenüber Google Sheets behandelt.
