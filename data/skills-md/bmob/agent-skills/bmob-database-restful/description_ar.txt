استخدمه عند التفاعل مع سحابة Bmob عبر HTTP عادي / curl من أي لغة لا تتوفر على SDK لـ Bmob — Python (requests/httpx)، Go (net/http)، PHP (Guzzle)، C# (HttpClient)، Rust (reqwest)، Ruby، Java backend، Bash، Deno، البرمجة الجانبية للخادم، ترحيل البيانات. واستخدمه أيضًا عندما يرغب المستخدم صراحةً في curl أو نمط URL الخام لواجهة REST. نطاق API الأساسي: https://api.codenow.cn (مثال: /1/classes/Token). المشغلات: /1/classes/، /1/users، /1/batch، /1/cloudQuery، /1/timestamp، /1/requestSmsCode، X-Bmob-Application-Id، X-Bmob-REST-API-Key، X-Bmob-Safe-Sign، المصادقة البسيطة، المصادقة المشفرة، توقيع MD5، curl bmob، Bmob REST API، Bmob HTTP. لا يُستخدم لـ JavaScript / Node / Web / Mini Program (استخدم bmob-database-javascript)، Android (استخدم bmob-database-android)، iOS (استخدم bmob-database-ios)، أو Flutter / Dart (استخدم bmob-database-flutter). إذا تم تكوين Bmob MCP، يمكن لأداة generate_code MCP إنتاج curl جاهز للاستخدام لـ13 نوعًا من العمليات — يفضَّل استخدامها بدلاً من كتابة curl يدويًا.
