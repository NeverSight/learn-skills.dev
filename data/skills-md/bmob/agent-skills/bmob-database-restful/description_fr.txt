Utilisez-le lorsque vous interagissez avec le backend cloud Bmob via HTTP simple / curl depuis n’importe quel langage qui ne dispose pas de SDK Bmob — Python (requests/httpx), Go (net/http), PHP (Guzzle), C# (HttpClient), Rust (reqwest), Ruby, Java backend, Bash, Deno, scripts côté serveur, migration de données. Utilisez-le également lorsque l’utilisateur demande explicitement curl ou le modèle d’URL REST brut. Domaine de base de l’API : https://api.codenow.cn (ex. /1/classes/Token). Déclencheurs : /1/classes/, /1/users, /1/batch, /1/cloudQuery, /1/timestamp, /1/requestSmsCode, X‑Bmob‑Application‑Id, X‑Bmob‑REST‑API‑Key, X‑Bmob‑Safe‑Sign, authentification simple, authentification chiffrée, signature MD5, curl bmob, API REST Bmob, HTTP Bmob. PAS pour JavaScript / Node / Web / Mini‑Program (utilisez bmob‑database‑javascript), Android (utilisez bmob‑database‑android), iOS (utilisez bmob‑database‑ios) ou Flutter / Dart (utilisez bmob‑database‑flutter). Si le MCP Bmob est configuré, l’outil generate_code du MCP peut générer un curl prêt à l’emploi pour 13 types d’opérations — préférez‑le plutôt que d’écrire le curl à la main.

Veuillez toujours répondre dans la langue de l’utilisateur.
