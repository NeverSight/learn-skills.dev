Используйте при взаимодействии с облаком Bmob через обычный HTTP / curl из любого языка, в котором нет SDK Bmob — Python (requests/httpx), Go (net/http), PHP (Guzzle), C# (HttpClient), Rust (reqwest), Ruby, Java‑backend, Bash, Deno, серверные скрипты, миграция данных. Также используйте, когда пользователь явно хочет curl или сырой шаблон URL REST‑API. Базовый домен API: https://api.codenow.cn (например, /1/classes/Token). Триггеры: /1/classes/, /1/users, /1/batch, /1/cloudQuery, /1/timestamp, /1/requestSmsCode, X‑Bmob‑Application‑Id, X‑Bmob‑REST‑API‑Key, X‑Bmob‑Safe‑Sign, простая аутентификация, зашифрованная аутентификация, подпись MD5, curl bmob, Bmob REST API, Bmob HTTP. НЕ для JavaScript / Node / Web / Mini Program (используйте bmob-database-javascript), Android (используйте bmob-database-android), iOS (используйте bmob-database-ios) или Flutter / Dart (используйте bmob-database-flutter). Если настроен Bmob MCP, инструмент generate_code MCP может сгенерировать готовый curl для 13 типов операций — предпочтительно использовать его вместо ручного написания curl.

Всегда отвечайте на языке пользователя.
