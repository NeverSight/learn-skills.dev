在任何没有 Bmob SDK 的语言中使用纯 HTTP / curl 与 Bmob 后端云交互时使用——例如 Python（requests/httpx）、Go（net/http）、PHP（Guzzle）、C#（HttpClient）、Rust（reqwest）、Ruby、Java 后端、Bash、Deno、服务器端脚本、数据迁移等。用户明确要求使用 curl 或原始 REST API URL 模式时也使用。API 基础域名：https://api.codenow.cn（例如 /1/classes/Token）。触发路径包括：/1/classes/、/1/users、/1/batch、/1/cloudQuery、/1/timestamp、/1/requestSmsCode，及请求头 X-Bmob-Application-Id、X-Bmob-REST-API-Key、X-Bmob-Safe-Sign，支持简单认证、加密认证、MD5 签名、curl bmob、Bmob REST API、Bmob HTTP。**不适用于** JavaScript / Node / Web / 小程序（使用 bmob-database-javascript）、Android（使用 bmob-database-android）、iOS（使用 bmob-database-ios）或 Flutter / Dart（使用 bmob-database-flutter）。如果配置了 Bmob MCP，generate_code MCP 工具可生成 13 种操作类型的即用 curl——优先使用该工具而不是手写 curl。
