Bmob バックエンドクラウドとプレーン HTTP / curl でやり取りする際に、Bmob SDK が存在しない任意の言語（Python（requests/httpx）、Go（net/http）、PHP（Guzzle）、C#（HttpClient）、Rust（reqwest）、Ruby、Java バックエンド、Bash、Deno、サーバーサイドスクリプト、データマイグレーション）で使用してください。また、ユーザーが明示的に curl や生の REST API URL パターンを要求した場合にも使用します。API のベースドメインは https://api.codenow.cn（例：/1/classes/Token）です。トリガー例：/1/classes/、/1/users、/1/batch、/1/cloudQuery、/1/timestamp、/1/requestSmsCode、X‑Bmob‑Application‑Id、X‑Bmob‑REST‑API‑Key、X‑Bmob‑Safe‑Sign、シンプル認証、暗号化認証、MD5 署名、curl bmob、Bmob REST API、Bmob HTTP。JavaScript / Node / Web / ミニプログラム（bmob-database-javascript を使用）や Android（bmob-database-android を使用）、iOS（bmob-database-ios を使用）、Flutter / Dart（bmob-database-flutter を使用）には使用しないでください。Bmob MCP が設定されている場合、generate_code MCP ツールは 13 種類の操作に対してすぐに使える curl を生成できるので、手書きの curl よりもそちらを優先してください。
