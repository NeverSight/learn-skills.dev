當使用者已設定 Bmob MCP 伺服器 (http://mcp.bmobapp.com/mcp) 且想從 IDE 直接對其 Bmob 後端雲端專案執行即時操作時使用。觸發詞：'list bmob tables'、'show bmob schema'、'create bmob table'、'add a row to bmob'、'update bmob record'、'delete bmob data'、'生成 bmob curl'、'design bmob schema'、'上傳雲函式'、'部署雲函式'、'發布雲函式'、'同步雲函式'、'同步函式'、'拉取雲函式'、'下載雲函式'、'呼叫雲函式'、'執行雲函式'、'invoke cloud function'、'run cloud function'、'一鍵部署網站'、'靜態托管'、'部署靜態站點'、'deploy static site'、'deploy website'。提供 12 個工具：get_project_tables（必須先呼叫以在任何寫入前發現 schema）、create_table、add_single_data、update_single_data、delete_single_data、generate_code、deploy_cloud_function、invoke_cloud_function、list_cloud_functions、get_cloud_function、deploy_static_site、mcp_endpoint_mcp_post。 **不** 用於編寫會隨使用者應用程式發佈的 client/SDK 程式碼—若需此功能請使用 bmob-database-{javascript,android,ios,swift,flutter,restful}。 **不** 用於 ACL/角色設計（使用 bmob-acl-and-roles）或雲函式開發（使用 bmob-cloud-function-development）。
