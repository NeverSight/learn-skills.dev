Utilisez lorsque l'utilisateur a le serveur Bmob MCP configuré (http://mcp.bmobapp.com/mcp) et souhaite effectuer des opérations EN DIRECT sur son projet cloud Bmob depuis l'IDE. NE PAS utiliser pour la conception d'ACL / rôles (utilisez bmob-acl-and-roles) ou le développement de fonctions cloud (utilisez bmob-cloud-function-development).

Veuillez toujours répondre dans la langue de l'utilisateur.
