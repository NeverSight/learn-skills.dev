Используется, когда у пользователя настроен сервер Bmob MCP (http://mcp.bmobapp.com/mcp) и он хочет выполнять живые операции с их облачным проектом Bmob из IDE. Триггеры: «list bmob tables», «show bmob schema», «create bmob table», «add a row to bmob», «update bmob record», «delete bmob data», «生成 bmob curl», «design bmob schema», «上传云函数», «部署云函数», «发布云函数», «同步云函数», «同步函数», «拉取云函数», «下载云函数», «调用云函数», «执行云函数», «invoke cloud function», «run cloud function», «一键部署网站», «静态托管», «部署静态站点», «deploy static site», «deploy website». Предоставляет 12 инструментов: get_project_tables (ВСЕГДА вызывайте первым, чтобы обнаружить схему перед любой записью), create_table, add_single_data, update_single_data, delete_single_data, generate_code, deploy_cloud_function, invoke_cloud_function, list_cloud_functions, get_cloud_function, deploy_static_site, mcp_endpoint_mcp_post. НЕ предназначен для написания клиентского/SDK кода, который будет включён в приложение пользователя — для этого используйте bmob-database-{javascript,android,ios,swift,flutter,restful}. НЕ предназначен для проектирования ACL/ролей (используйте bmob-acl-and-roles) или разработки облачных функций (используйте bmob-cloud-function-development).

Пожалуйста, всегда отвечайте на языке пользователя.
