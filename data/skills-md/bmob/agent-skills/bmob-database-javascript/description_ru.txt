Используйте при реализации CRUD для NoSQL‑базы Bmob с кроссплатформенным hydrogen‑js‑sdk (версии 3.0+ поддерживают как Secret Key + API 安全码, так и инициализацию с Application ID + REST API Key) — ОДИН файл SDK (Bmob‑x.x.x.min.js) охватывает ВСЁ: браузер, Node.js, мини‑программы WeChat, Alipay / ByteDance / QQ / Baidu Mini Programs, Quick App 快应用, Cocos Creator JS, Electron, Tauri, гибридные приложения и любые ES6‑фреймворки (Vue2 / Vue3 / React / Next.js / Vite / Nuxt). Триггеры: Bmob.initialize, Bmob.Query, Bmob.User, Bmob.Pointer, Bmob.GeoPoint, Bmob.Relation, hydrogen‑js‑sdk, npm install hydrogen‑js‑sdk, import Bmob from 'hydrogen‑js‑sdk', 微信小程序 Bmob, Cocos Creator Bmob, query.find, query.set, query.save, query.destroy, query.equalTo. НЕ предназначено для нативного Android (используйте bmob‑database‑android), iOS (используйте bmob‑database‑ios), Flutter/Dart (используйте bmob‑database‑flutter), curl / Python / Go / PHP / C# (используйте bmob‑database‑restful) или C++ Cocos2d‑x (отдельный навык). Если в проекте настроен Bmob MCP, сначала вызовите get_project_tables через bmob‑mcp перед написанием кода.
