在使用跨平台 hydrogen-js-sdk 实现 Bmob NoSQL 数据库 CRUD 时使用（3.0+ 支持 Secret Key + API 安全码 和 Application ID + REST API Key 初始化）——唯一的 SDK 文件 (Bmob-x.x.x.min.js) 覆盖所有：浏览器、Node.js、微信小程序、支付宝 / 字节跳动 / QQ / 百度小程序、快应用、Cocos Creator JS、Electron、Tauri、混合应用，以及任何 ES6 框架（Vue2 / Vue3 / React / Next.js / Vite / Nuxt）。触发点：Bmob.initialize、Bmob.Query、Bmob.User、Bmob.Pointer、Bmob.GeoPoint、Bmob.Relation、hydrogen-js-sdk、npm install hydrogen-js-sdk、import Bmob from 'hydrogen-js-sdk'、微信小程序 Bmob、Cocos Creator Bmob、query.find、query.set、query.save、query.destroy、query.equalTo。**不适用于** Android 原生（使用 bmob-database-android）、iOS 原生（使用 bmob-database-ios）、Flutter / Dart（使用 bmob-database-flutter）、curl / Python / Go / PHP / C#（使用 bmob-database-restful）或 C++ Cocos2d-x（单独技能）。如果项目中配置了 Bmob MCP，请在编写代码前通过 bmob-mcp 调用 get_project_tables。
