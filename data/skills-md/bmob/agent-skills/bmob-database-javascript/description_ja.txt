クロスプラットフォーム hydrogen-js-sdk を使用して Bmob NoSQL データベースの CRUD を実装する際に使用してください（3.0+ は Secret Key + API 安全码 と Application ID + REST API Key の初期化の両方に対応）。 — ONE SDK ファイル (Bmob-x.x.x.min.js) が以下すべてをカバーします：ブラウザ、Node.js、微信ミニプログラム、Alipay / ByteDance / QQ / Baidu ミニプログラム、Quick App 快应用、Cocos Creator JS、Electron、Tauri、ハイブリッドアプリ、そして任意の ES6 フレームワーク（Vue2 / Vue3 / React / Next.js / Vite / Nuxt）。 トリガー：Bmob.initialize、Bmob.Query、Bmob.User、Bmob.Pointer、Bmob.GeoPoint、Bmob.Relation、hydrogen-js-sdk、npm install hydrogen-js-sdk、import Bmob from 'hydrogen-js-sdk'、微信小程序 Bmob、Cocos Creator Bmob、query.find、query.set、query.save、query.destroy、query.equalTo。 Android ネイティブ向けではなく（bmob-database-android を使用）、iOS ネイティブ向けでもなく（bmob-database-ios を使用）、Flutter / Dart 向けでもなく（bmob-database-flutter を使用）、curl / Python / Go / PHP / C# 向けでもなく（bmob-database-restful を使用）、または C++ Cocos2d‑x 向け（別スキル）です。 プロジェクトで Bmob MCP が設定されている場合、コードを書く前に bmob-mcp で get_project_tables を呼び出してください。
