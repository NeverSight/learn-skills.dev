استخدم عند تنفيذ عمليات CRUD لقاعدة بيانات Bmob NoSQL باستخدام SDK النقي Swift BmobSwiftSDK لنظام iOS 15+ / macOS 12+ مع Swift Package Manager أو CocoaPods، استورد BmobSDK، async/await، Bmob.initialize(appKey:)، BmobObject، BmobQuery، BmobUser، BmobFile، BmobPointer، BmobRelation، BmobGeoPoint، BmobACL، CloudFunction. ليس للاستخدام مع مشاريع Objective‑C القديمة / Bridging Header (استخدم bmob-database-ios)، JavaScript / WeChat Mini Program (استخدم bmob-database-javascript)، Android (استخدم bmob-database-android)، Flutter / Dart (استخدم bmob-database-flutter)، أو طلبات HTTP الخام من لغات أخرى (استخدم bmob-database-restful). إذا تم تكوين Bmob MCP، استدعي get_project_tables عبر bmob-mcp قبل كتابة الشيفرة.
