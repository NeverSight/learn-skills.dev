Úsese al implementar operaciones CRUD de la base de datos NoSQL Bmob con el puro BmobSwiftSDK en Swift para iOS 15+ / macOS 12+ utilizando Swift Package Manager o CocoaPods, importando BmobSDK, async/await, Bmob.initialize(appKey:), BmobObject, BmobQuery, BmobUser, BmobFile, BmobPointer, BmobRelation, BmobGeoPoint, BmobACL, CloudFunction. NO es para proyectos heredados en Objective‑C con BmobSDK / Bridging Header (use bmob-database-ios), JavaScript / Mini Program de WeChat (use bmob-database-javascript), Android (use bmob-database-android), Flutter / Dart (use bmob-database-flutter) o HTTP crudo desde otros lenguajes (use bmob-database-restful). Si Bmob MCP está configurado, llame a get_project_tables mediante bmob-mcp antes de escribir código.
