在使用 Swift Package Manager 或 CocoaPods 并导入 BmobSDK、使用 async/await、Bmob.initialize(appKey:)、BmobObject、BmobQuery、BmobUser、BmobFile、BmobPointer、BmobRelation、BmobGeoPoint、BmobACL、CloudFunction，实现 iOS 15+ / macOS 12+ 的纯 Swift BmobSwiftSDK 对 Bmob NoSQL 数据库的 CRUD 时使用。**不适用于** 旧版 Objective‑C BmobSDK / Bridging Header 项目（请使用 bmob-database-ios）、JavaScript / 微信小程序（请使用 bmob-database-javascript）、Android（请使用 bmob-database-android）、Flutter / Dart（请使用 bmob-database-flutter），或其他语言的原始 HTTP（请使用 bmob-database-restful）。如果已配置 Bmob MCP，请在编写代码前通过 bmob-mcp 调用 get_project_tables。
