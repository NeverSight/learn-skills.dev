Utilisez‑le lors de l'implémentation du CRUD de la base de données NoSQL Bmob avec le SDK pur Swift BmobSwiftSDK pour iOS 15+ / macOS 12+ en utilisant Swift Package Manager ou CocoaPods, importez BmobSDK, async/await, Bmob.initialize(appKey:), BmobObject, BmobQuery, BmobUser, BmobFile, BmobPointer, BmobRelation, BmobGeoPoint, BmobACL, CloudFunction. PAS pour les projets Objective‑C legacy BmobSDK / Bridging Header (utilisez bmob-database-ios), JavaScript / WeChat Mini Program (utilisez bmob-database-javascript), Android (utilisez bmob-database-android), Flutter / Dart (utilisez bmob-database-flutter), ou HTTP brut depuis d'autres langages (utilisez bmob-database-restful). Si le MCP de Bmob est configuré, appelez get_project_tables via bmob-mcp avant d'écrire le code.
