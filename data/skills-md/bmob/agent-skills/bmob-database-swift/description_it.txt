Usa quando implementi le operazioni CRUD del database NoSQL Bmob con il puro BmobSwiftSDK per iOS 15+ / macOS 12+ usando Swift Package Manager o CocoaPods, importa BmobSDK, async/await, Bmob.initialize(appKey:), BmobObject, BmobQuery, BmobUser, BmobFile, BmobPointer, BmobRelation, BmobGeoPoint, BmobACL, CloudFunction. NON per progetti legacy Objective‑C BmobSDK / Bridging Header (usa bmob-database-ios), JavaScript / Mini Program WeChat (usa bmob-database-javascript), Android (usa bmob-database-android), Flutter / Dart (usa bmob-database-flutter), o HTTP grezzo da altre lingue (usa bmob-database-restful). Se Bmob MCP è configurato, chiama get_project_tables tramite bmob-mcp prima di scrivere il codice.
