Используйте при реализации CRUD в NoSQL‑базе данных Bmob с чистым Swift‑SDK BmobSwiftSDK для iOS 15+ / macOS 12+ с помощью Swift Package Manager или CocoaPods, импортируя BmobSDK, async/await, Bmob.initialize(appKey:), BmobObject, BmobQuery, BmobUser, BmobFile, BmobPointer, BmobRelation, BmobGeoPoint, BmobACL, CloudFunction. НЕ для устаревших проектов на Objective‑C с BmobSDK / Bridging Header (используйте bmob-database-ios), JavaScript / WeChat Mini Program (используйте bmob-database-javascript), Android (используйте bmob-database-android), Flutter / Dart (используйте bmob-database-flutter) или прямого HTTP из других языков (используйте bmob-database-restful). Если настроен Bmob MCP, вызовите get_project_tables через bmob-mcp перед написанием кода.
