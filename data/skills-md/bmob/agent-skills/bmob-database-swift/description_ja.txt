iOS 15+ ／ macOS 12+ 用の純粋な Swift BmobSwiftSDK を使用して Bmob NoSQL データベースの CRUD を実装する際に使用します。Swift Package Manager または CocoaPods を利用し、BmobSDK をインポートし、async/await、Bmob.initialize(appKey:)、BmobObject、BmobQuery、BmobUser、BmobFile、BmobPointer、BmobRelation、BmobGeoPoint、BmobACL、CloudFunction を活用します。レガシーな Objective‑C BmobSDK／Bridging Header プロジェクト（bmob‑database‑ios を使用）、JavaScript／WeChat ミニプログラム（bmob‑database‑javascript を使用）、Android（bmob‑database‑android を使用）、Flutter／Dart（bmob‑database‑flutter を使用）、または他言語からの生の HTTP（bmob‑database‑restful を使用）には使用しないでください。Bmob MCP が設定されている場合は、コードを書く前に bmob‑mcp で get_project_tables を呼び出してください。
