Bmob NoSQL データベースの CRUD を iOS のネイティブプロジェクト（Objective‑C と Swift／SwiftUI／UIKit の両方）で実装する際に使用してください。トリガー: BmobSDK、BmobSDK.xcframework、pod 'BmobSDK'、#import <BmobSDK/Bmob.h>、Bmob registerWithAppKey、[Bmob register(withAppKey:)]、BmobObject objectWithClassName、BmobQuery queryWithClassName、BmobUser、BmobInstallation、BmobFile、BmobGeoPoint、BmobRelation、saveInBackgroundWithResultBlock、getObjectInBackgroundWithId、findObjectsInBackground、Bridging-Header.h。クロスプラットフォームの JavaScript / WeChat Mini Program 用ではありません（bmob-database-javascript を使用）、Android 用ではありません（bmob-database-android を使用）、Flutter／Dart 用ではありません（bmob-database-flutter を使用）、または REST 経由の他の言語用でもありません（bmob-database-restful を使用）。Bmob MCP が設定されている場合は、コードを書く前に bmob-mcp で get_project_tables を呼び出してください。

常にユーザーの言語で回答してください。
