بناء، توثيق، مراجعة، أخذ لقطات شاشة، وتسليم نماذج واجهات HTML الأصلية باستخدام وكلاء الذكاء الاصطناعي مع حزم واجهة مستخدم قابلة لإعادة الاستخدام، وتعليقات منتجات مرتبطة بـ DOM، وتحرير مباشر داخل المتصفح، ودبابيس مراجعة المتصفح، وخادم تأليف محلي، ومفتش العنصر إلى المصدر، ولقطات شاشة متعددة الحالات. استخدمه عندما يذكر المستخدم /html-prototype-build أو يطلب إعادة بناء واجهة المستخدم بـ HTML، أو إنشاء تعليقات المنتجات، أو تعديل أنماط النموذج الأولي، أو مراجعة أو تمييز عناصر DOM، أو التقاط حالات النموذج الأولي، أو تجميع مخرجات النموذج الأولي. يعمل مع Claude Code و Codex و Cursor وغيرها من عملاء مهارات الوكيل؛ لا تستخدمه للملاحة العامة في شفرة المصدر، أو الوثائق العادية، أو تطوير الواجهة الأمامية للإنتاج.
