Construye, anota, revisa, captura pantallas y entrega prototipos nativos de UI en HTML con agentes de IA usando paquetes UI reutilizables, anotaciones de producto vinculadas al DOM, edición directa en el navegador, indicadores de revisión en el navegador, un servidor de autoría local, un inspector de elemento a fuente y capturas de pantalla de múltiples estados. Utilízalo cuando el usuario mencione /html-prototype-build o solicite reconstruir la UI en HTML, crear anotaciones de producto, editar estilos del prototipo, revisar o marcar elementos del DOM, capturar estados del prototipo o empaquetar los entregables del prototipo. Funciona con Claude Code, Codex, Cursor y otros clientes de Agent Skills; no lo uses para navegación genérica de código fuente, documentación ordinaria o desarrollo frontend de producción.
