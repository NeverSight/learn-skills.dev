Costruisci, annota, revisiona, cattura screenshot e consegna prototipi UI HTML nativi con agenti IA utilizzando pacchetti UI riutilizzabili, annotazioni prodotto legate al DOM, Direct Edit in-browser, pin di revisione del browser, un server di authoring locale, un Inspector elemento‑source e screenshot a più stati. Utilizza quando l'utente menziona /html-prototype-build o chiede di ricostruire l'interfaccia in HTML, creare annotazioni prodotto, modificare gli stili del prototipo, revisionare o contrassegnare elementi del DOM, catturare gli stati del prototipo o impacchettare i deliverable del prototipo. Funziona con Claude Code, Codex, Cursor e altri client Agent Skills; non usarlo per la navigazione generica del codice sorgente, la documentazione ordinaria o lo sviluppo frontend di produzione. Si prega di rispondere sempre nella lingua dell'utente.
