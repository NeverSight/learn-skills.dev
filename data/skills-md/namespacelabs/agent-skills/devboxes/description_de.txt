Erstellen, Befehle ausführen, teilen und abbauen von Namespace‑Devboxen – remote Linux/AMD64‑ oder macOS/ARM64‑Maschinen, gesteuert über die `devbox`‑CLI. Verwenden Sie sie für eine isolierte Linux‑ oder macOS‑Umgebung, eine Remote‑Entwicklungsumgebung, einen temporären Linux‑Docker‑Host, für das Ausführen von mehr Aufgaben, als die lokale Maschine bewältigen kann (einschließlich Test‑Suites, die parallel auf mehrere Devboxen verteilt sind) oder um eine `devbox.so`‑URL bereitzustellen, damit ein Teamkollege die Arbeit in seinem Browser öffnen kann.
