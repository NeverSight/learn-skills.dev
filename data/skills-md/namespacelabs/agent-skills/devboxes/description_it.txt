Crea, esegui comandi, condividi e smonta devbox Namespace – macchine remote linux/amd64 o macos/arm64 gestite dal CLI `devbox`. Utilizzalo per un ambiente Linux o macOS isolato, un ambiente di sviluppo remoto, un host Docker Linux usa e getta, per eseguire più di quanto la macchina locale possa gestire (inclusi suite di test suddivise su più devbox in parallelo) o per esporre un URL `devbox.so` così che un collega possa aprire il lavoro nel proprio browser.
