Crea, ejecuta comandos, comparte y desmantela devboxes de Namespace: máquinas remotas linux/amd64 o macos/arm64 controladas por la CLI `devbox`. Úsalo para un entorno aislado de Linux o macOS, un entorno de desarrollo remoto, un host Docker Linux desechable, ejecutar más de lo que la máquina local puede manejar (incluidos suites de pruebas divididas entre varios devboxes en paralelo), o exponer una URL `devbox.so` para que un compañero de equipo pueda abrir el trabajo en su navegador.
