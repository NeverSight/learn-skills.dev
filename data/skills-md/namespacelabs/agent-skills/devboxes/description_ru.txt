Создавайте, выполняйте команды, делитесь и удаляйте devbox’ы Namespace — удалённые машины linux/amd64 или macos/arm64, управляемые CLI `devbox`. Используйте для изолированной среды Linux или macOS, удалённой среды разработки, временного хоста Linux Docker, выполнения задач, превышающих возможности локального компьютера (включая распределение тестовых наборов по нескольким devbox’ам параллельно), либо для предоставления URL `devbox.so`, чтобы коллега мог открыть работу в своём браузере.
