À utiliser lors de l'écriture de nouveaux composants React qui impliquent un état dérivé d'accessoires, d'effets secondaires liés à des événements ou d'abonnements externes. À utiliser également lors de l'audit du code existant pour une utilisation inutileAppels effect, révision des composants useEffect-lourds ou refactorisation pour éliminer les rendus en cascade. S'applique aux bases de code React 18+.
