Usa quando scrivi nuovi componenti React che coinvolgono stato derivato dalle props, effetti collaterali basati su eventi o abbonamenti esterni. Utilizzalo anche durante l’audit del codice esistente per chiamate useEffect non necessarie, nella revisione di componenti con uso intensivo di useEffect o nel refactoring volto a eliminare render a cascata. Si applica ai codebase React 18+.
