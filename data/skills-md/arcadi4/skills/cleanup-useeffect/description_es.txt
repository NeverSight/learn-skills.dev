Utilícelo al escribir nuevos componentes de React que involucren el estado derivado de accesorios, efectos secundarios impulsados por eventos o suscripciones externas. También se usa al auditar el código existente para llamadas useEffect innecesarias, revisar los componentes de useEffect-heavy o refactorizar para eliminar renders en cascada. Se aplica a las bases de código de React 18+.
