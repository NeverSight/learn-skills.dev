Wird beim Schreiben neuer React-Komponenten verwendet, bei denen der Status von Requisiten, ereignisgesteuerten Nebenwirkungen oder externen Abonnements abgeleitet wird. Verwenden Sie diese Option auch, wenn Sie vorhandenen Code auf unnötige useEffect-Aufrufe überprüfen, useEffect-lastige Komponenten überprüfen oder umgestalten, um kaskadierende Renderings zu eliminieren. Gilt für React 18+ Codebasen.
