أنشئ شخصية تميمة بتصميم مسطح بصيغة SVG مع مجموعة أوضاع متعددة متسقة (محايدة، تلوح بيدها، تشير، تمشي، تحتفل، إلخ) للمواقع الإلكترونية، المحافظ، التطبيقات، المستندات، أو العلامات التجارية. استخدم هذه المهارة كلما طلب المستخدم تميمة أو شخصية أو صورة رمزية أو رفيق علامة تجارية أو شخصية دليل للموقع أو شخصية مصورة أو مجموعة من أوضاع/ملصقات الشخصية — حتى وإن لم يذكر كلمة «SVG» أو «تميمة» صراحة (مثلًا «أضف رجلاً صغيرًا إلى صفحة الهبوط الخاصة بي»، «أريد شخصية تلوّح في قسم البطل»، «اصنع أوضاعًا لشخصيتي»). واستخدمها أيضًا عند توسيع تميمة موجودة بأوضاع أو تعبيرات جديدة. يرجى دائمًا الرد بلغة المستخدم.
