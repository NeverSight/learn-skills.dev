Interrogez l'API publique d'ESPN pour obtenir les scores en direct, les classements, les effectifs, les statistiques des joueurs, les cotes, le déroulement jeu par jeu, les blessures, les transactions, les actualités et plus encore pour 17 sports et 139 ligues. Utilisez‑la lorsque l'utilisateur a besoin de données sportives d'ESPN, souhaite créer une application sportive, récupérer les scores ou les calendriers, consulter les statistiques des joueurs ou des équipes, obtenir les cotes de paris ou extraire toute donnée sportive structurée. Se déclenche à la mention d'ESPN, des scores sportifs, des classements, des feuilles de match, des statistiques de joueurs, des données de jeu ou des données de ligue.

Veuillez toujours répondre dans la langue de l'utilisateur.
