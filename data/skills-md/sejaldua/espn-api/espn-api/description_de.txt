Abfrage der öffentlichen API von ESPN für Live-Ergebnisse, Ranglisten, Kader, Spielerstatistiken, Quoten, Spielverlauf, Verletzungen, Transaktionen, Nachrichten und mehr für 17 Sportarten und 139 Ligen. Verwenden, wenn der Nutzer Sportdaten von ESPN benötigt, eine Sport‑App erstellen möchte, Ergebnisse oder Spielpläne abrufen will, Spieler‑ oder Teamstatistiken nachschlagen möchte, Wettquoten erhalten will oder irgendeine strukturierte Sportdaten abrufen möchte. Wird ausgelöst bei Erwähnungen von ESPN, Sportergebnissen, Ranglisten, Boxscores, Spielerstatistiken, Spieldaten oder Ligadaten. Bitte immer in der Sprache des Nutzers antworten.
