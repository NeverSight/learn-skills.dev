Generar diversas variantes de soluciones con estimaciones de probabilidad mediante el muestreo verbalizado (arXiv 2510.01171). Utilícelo cuando tenga que elegir entre varios enfoques, depurar con una causa raíz desconocida, generar hipótesis o datos sintéticos, o cuando las indicaciones directas produzcan respuestas repetitivas con colapso modal. NO lo uses para scripts triviales, consultas fácticas ni código de producción estable.
