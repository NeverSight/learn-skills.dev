Conduisez la CLI Mole (`mo`) sur macOS ou Windows : trouvez ce qui occupe l’espace disque, prévisualisez et lancez le nettoyage, désinstallez les applications et consultez l’état du système ainsi que l’historique du nettoyage. Utilisez‑le avant d’exécuter toute commande `mo`. Ce n’est pas destiné à l’édition du code source de Mole.
