Reconocimiento pasivo de código abierto y comprobaciones de exposición externa de un dominio, una dirección IP o una organización mediante OpenOSINT (DNS, RDAP, WHOIS, autenticación de correo electrónico, TLS, cabeceras de seguridad, menciones en noticias, «dorks» de búsqueda). Úsalo cuando el usuario pida investigar, perfilar, reconocer o «buscar» un dominio, una IP o una empresa, o comprobar qué expone un dominio a Internet. No se necesitan claves de API para el flujo predeterminado.
