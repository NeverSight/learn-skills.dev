Utilizza questa skill quando crei, rivedi o modifichi skill in formato Agent Skills, o quando implementi la scoperta e il caricamento delle skill in un client agente. Copre la struttura delle directory, i metadati SKILL.md, la divulgazione progressiva, le valutazioni e le convenzioni del repository. Non utilizzare questa skill per lavori software generali che non coinvolgono il formato o il ciclo di vita delle Agent Skills.
