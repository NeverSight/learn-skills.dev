Lesen Sie den Stripe‑Kontostatus von einem Terminal oder Agenten: Kontostand, Zahlungsabsichten und Abonnements — und führen Sie gesicherte Änderungen wie das Kündigen eines Abonnements durch — unterstützt von einem gebündelten stripe‑cli‑Skript, das zunächst schreibgeschützt ist und jeden zustandsverändernden Befehl hinter einer --dry-run/--yes‑Bestätigung verbirgt. Verwenden Sie es, wenn ein Agent Fragen zum Kontostand, zu kürzlichen Zahlungen, zu aktiven Abonnements beantworten oder eine bestätigte Kündigung eines Abonnements ausführen muss. Nicht verwenden für die Integration von Stripe‑Zahlungen in eine Anwendung (das ist Stripe‑Integrationsentwicklung), die Verwaltung von Stripe‑Dashboard‑Einstellungen oder andere Zahlungsanbieter (das ist deren eigenes Tooling).
