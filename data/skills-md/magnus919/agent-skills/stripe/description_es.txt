Lea el estado de la cuenta de Stripe desde una terminal o agente: saldo, intenciones de pago y suscripciones, y realice mutaciones protegidas como cancelar una suscripción, respaldado por un script stripe‑cli empaquetado que inicialmente es de solo lectura y bloquea cada comando que cambia el estado detrás de una confirmación --dry‑run/--yes. Úselo cuando un agente necesite responder preguntas sobre el saldo de la cuenta, pagos recientes, suscripciones activas o aplicar una cancelación de suscripción confirmada. No lo use para integrar pagos de Stripe en una aplicación (eso es desarrollo de integración de Stripe), gestionar la configuración del panel de Stripe o para otros procesadores de pago (eso es su propia herramienta).
