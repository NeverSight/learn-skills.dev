Чтение состояния учётной записи Stripe из терминала или агента: баланса, намерений оплаты и подписок — и выполнение защищённых изменений, таких как отмена подписки — с помощью объединённого скрипта stripe-cli, который сначала работает в режиме только чтения и ставит каждый изменяющий состояние команду за подтверждением --dry-run/--yes. Используйте, когда агенту нужно отвечать на вопросы о балансе аккаунта, недавних платежах, активных подписках или выполнить подтверждённую отмену подписки. Не используйте для внедрения платежей Stripe в приложение (это разработка интеграции Stripe), управления настройками панели Stripe или других платёжных процессоров (это их собственные инструменты).
