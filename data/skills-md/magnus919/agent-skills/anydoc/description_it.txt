Converti documenti Word (.doc/.docx/.docm), PowerPoint (.ppt/.pps/.pot/.pptx/.pptm/.ppsx/.ppsm), Excel (.xls/.xlsx/.xlsm/.xlsb), OpenDocument (.odt/.ods/.odp), RTF, EPUB, CSV e PDF in Markdown pulito con GitHub‑Flavored Markdown localmente usando l’Any Doc CLI (npx -y @firecrawl/anydoc@0.2.4): intestazioni, tabelle GFM, struttura delle slide e note a piè di pagina in un unico passaggio. Usalo quando un compito richiede il contenuto di un documento office, foglio di calcolo, presentazione, ebook o PDF che non puoi leggere direttamente. Non usarlo per generare, modificare o convalidare documenti (usa i documenti), per il packaging di ebook (usa epub). Per PDF scansionati o solo immagine, utilizza l’OCR ospitato solo quando l’utente autorizza esplicitamente il caricamento dell’intero documento; altrimenti instrada al tool OCR locale.
