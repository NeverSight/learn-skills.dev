Конвертируйте документы Word (.doc/.docx/.docm), PowerPoint (.ppt/.pps/.pot/.pptx/.pptm/.ppsx/.ppsm), Excel (.xls/.xlsx/.xlsm/.xlsb), OpenDocument (.odt/.ods/.odp), RTF, EPUB, CSV и PDF в чистый GitHub‑Flavored Markdown локально с помощью Any Doc CLI (npx -y @firecrawl/anydoc@0.2.4): заголовки, таблицы GFM, структура слайдов и сноски за один проход. Используйте, когда задача требует содержимого офисного документа, таблицы, презентации, электронного книги или PDF, который нельзя прочитать напрямую. Не используйте для генерации, редактирования или валидации документов (используйте документы), для упаковки электронных книг (используйте epub). Для отсканированных или только из изображений PDF используйте облачное OCR только когда пользователь явно разрешает загрузку всего документа; иначе перенаправляйте к локальному OCR‑инструменту.
