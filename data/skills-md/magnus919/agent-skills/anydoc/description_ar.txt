حوّل مستندات Word (.doc/.docx/.docm) وPowerPoint (.ppt/.pps/.pot/.pptx/.pptm/.ppsx/.ppsm) وExcel (.xls/.xlsx/.xlsm/.xlsb) وOpenDocument (.odt/.ods/.odp) وRTF وEPUB وCSV وPDF إلى ماركداون بنكهة GitHub نظيف محليًا باستخدام Any Doc CLI (npx -y @firecrawl/anydoc@0.2.4): العناوين، وجداول GFM، وبنية الشرائح، والحواشي في عملية واحدة. استخدمه عندما تتطلب مهمة محتوى مستند مكتبي، جدول بيانات، عرض تقديمي، كتاب إلكتروني أو PDF لا يمكنك قراءته مباشرة. لا تستخدمه لإنشاء أو تحرير أو التحقق من المستندات (استخدم المستندات)، ولا لتعبئة الكتب الإلكترونية (استخدم epub). بالنسبة لملفات PDF الممسوحة ضوئيًا أو التي تحتوي على صور فقط، استعن بـ OCR المستضيف فقط عندما يصرح المستخدم صراحةً بتحميل المستند بالكامل؛ وإلا وُجه إلى أدوات OCR محلية.
