Úsalo cuando una tarea necesite el contenido de un documento de oficina, hoja de cálculo, presentación, ebook o PDF que no puedas leer directamente. No lo uses para generar, editar o validar documentos (usa documentos), ni para empaquetado de ebooks (usa epub). Para PDFs escaneados o solo de imágenes, usa OCR alojado únicamente cuando el usuario autorice explícitamente la carga del documento completo; de lo contrario, dirige el proceso a herramientas OCR locales.
