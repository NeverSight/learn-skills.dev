Führe eine strukturierte Multi‑Agenten‑Debatte durch, indem du ein Gremium von Experten‑Agenten zu jeder Frage zusammenstellst, mit konvergenzbewusster Iteration und typisiertem Synthese‑Output über das `agent-council`‑CLI. Verwende es, wenn eine Entscheidung echte Zielkonflikte, hohe Einsätze oder verborgene Annahmen aufweist, die eine gegnerische Zusammenarbeit wert sind, oder wenn Konfidenz‑Diagnosen wichtiger sind als eine einzelne Empfehlung. Kompatibel mit jedem KI‑Agenten‑Framework, das agentskills.io‑Skills unterstützt (Claude Code, Cursor, Hermes Agent, OpenHands usw.). Nicht einsetzen für einfache Faktenabfragen, Aufgaben mit einer klaren richtigen Antwort, routinemäßige einseitige Arbeiten oder Codeausführung und Tool‑Orchestrierung jenseits von Debatten.
