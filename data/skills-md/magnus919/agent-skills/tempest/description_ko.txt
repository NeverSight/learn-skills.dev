WeatherFlow Tempest 스테이션의 REST API와 허브의 로컬 UDP 브로드캐스트를 통해 초지역 날씨를 조회합니다: 현재 상황, 예보, 과거 관측, 실시간 디코드된 데이터그램(obs_st, rapid_wind, evt_precip, evt_strike, hub_status). 사용자는 자신의 Tempest/WeatherFlow 스테이션에 대한 날씨, 온도, 강우, 바람, 습도 또는 예보 데이터를 물어보거나 허브의 UDP 포트 50222 브로드캐스트를 파싱하고 싶을 때 이 기능을 사용하십시오. Tempest 스테이션이 없는 일반적인 도시 예보(공공 날씨 서비스가 제공)나 셰익스피어의 연극 《템페스트》와 같은 문학 질문, 혹은 다른 업체의 날씨 하드웨어에 대해서는 이 기능을 사용하지 마세요 — REST 엔드포인트는 개인용 토큰이 필요하고 UDP 브로드캐스트는 Tempest 허브의 LAN에서만 존재합니다.

항상 사용자의 언어로 응답하십시오.
