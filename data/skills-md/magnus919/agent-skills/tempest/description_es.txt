Consulta el tiempo hiperlocal desde una estación WeatherFlow Tempest a través de su API REST y la transmisión UDP local del hub: condiciones actuales, pronóstico, observaciones históricas y datagramas decodificados en tiempo real (obs_st, rapid_wind, evt_precip, evt_strike, hub_status). Utiliza esto cuando el usuario pregunte sobre el clima, temperatura, lluvia, viento, humedad o datos de pronóstico de su propia estación Tempest/WeatherFlow, o quiera analizar la transmisión UDP del puerto 50222 del hub. No uses esta habilidad para pronósticos genéricos o de ciudades sin una estación Tempest (los servicios meteorológicos públicos sirven para eso), para la obra de Shakespeare *La Tempestad* u otras preguntas literarias, o para hardware meteorológico de otros proveedores; los endpoints REST requieren un token de uso personal y la transmisión UDP solo existe en la LAN de un hub Tempest.

Por favor, responde siempre en el idioma del usuario.
