通过 WeatherFlow Tempest 站点的 REST API 和集线器的本地 UDP 广播查询超本地天气：当前状况、预报、历史观测以及实时解码的数据报（obs_st、rapid_wind、evt_precip、evt_strike、hub_status）。当用户询问其自己的 Tempest/WeatherFlow 站点的天气、温度、降雨、风速、湿度或预报数据，或希望解析集线器的 UDP 端口 50222 广播时使用。本技能不要用于没有 Tempest 站点的通用或城市预报（此类请使用公共天气服务），也不要用于莎士比亚的戏剧《暴风雨》或其他文学问题，或用于其他厂商的天气硬件——REST 接口需要个人使用令牌，UDP 广播仅在 Tempest 集线器的局域网中存在。
