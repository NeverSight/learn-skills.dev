Despliegue, configure y opere el CrowdSec Security Engine, cscli, componentes de remediación, pipelines de adquisición y el WAF de AppSec. Úselo para instalaciones en Linux o Docker, diseño de detección a bloqueo, revisión de incidentes y cambios seguros. No lo utilice para firewalls genéricos, Kubernetes o diseños de reverse‑proxy; dirija esos casos a la habilidad de plataforma correspondiente y use esta habilidad para la integración de CrowdSec.
