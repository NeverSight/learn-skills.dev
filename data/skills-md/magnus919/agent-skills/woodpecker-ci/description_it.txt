Gestisci Woodpecker CI dall'installazione alla risoluzione dei problemi in produzione: configura server e agenti, collega Forgejo/Gitea o un altro forge, scrivi e valida pipeline, gestisci segreti e plugin, utilizza backend Docker o Kubernetes, esegui la CLI e diagnostica build fallite. Usa questa competenza quando configuri, amministri o esegui il debug di Woodpecker CI. Non utilizzare questa abilità per richieste non correlate; indirizza al più vicino specialista nominato. Rispondi sempre nella lingua dell'utente.
