Recherchez, téléchargez et extrayez des livres du domaine public depuis Project Gutenberg. Recherchez des livres par ID ou par mot‑clé via gutendex, téléchargez les éditions texte brut et EPUB, supprimez le texte légal standard, extrayez le texte épuré des EPUB pour les œuvres illustrées, et classez les ouvrages en fiction ou non‑fiction. Livré avec un script CLI portable sans aucune dépendance externe. Utilisez-le lorsque l'utilisateur dit « gutenberg », « domaine public », « télécharger un livre », « littérature classique », « ebook gratuit », « gutenberg.org », ou mentionne un titre ou un auteur du domaine public. N'utilisez pas cette fonction pour des demandes sans rapport ; redirigez vers le spécialiste nommé le plus proche. Veuillez toujours répondre dans la langue de l'utilisateur.
