在 Project Gutenberg 搜尋、下載與提取公有領域書籍。可透過 gutendex 依 ID 或關鍵字查找書籍，下載純文字與 EPUB 版本，移除授權聲明的樣板，從插圖作品的 EPUB 中擷取純淨文字，並判別小說與非小說。提供一個無需外部相依的可攜式 CLI 腳本。當使用者說出「gutenberg」、「public domain」、「download a book」、「classic literature」、「free ebook」、「gutenberg.org」或提及任何公有領域的書名或作者時使用此功能。請勿將此技能用於不相關的請求；請轉交最近的指定專家。
