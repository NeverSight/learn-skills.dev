Cerca, scarica ed estrai libri di pubblico dominio da Project Gutenberg. Trova i libri per ID o parola chiave tramite gutendex, scarica le edizioni in testo semplice e EPUB, rimuovi il boilerplate delle licenze, estrai il testo pulito dagli EPUB per le opere illustrate e classifica narrativa vs saggistica. Fornisce uno script CLI portatile senza dipendenze esterne. Usalo quando l'utente dice “gutenberg”, “public domain”, “download a book”, “classic literature”, “free ebook”, “gutenberg.org” o menziona qualsiasi titolo o autore di pubblico dominio. Non utilizzare questa abilità per richieste non correlate; indirizza allo specialista più vicino. 

Rispondi sempre nella lingua dell'utente.
