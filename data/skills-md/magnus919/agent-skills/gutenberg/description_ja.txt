Project Gutenberg からパブリックドメインの本を検索、ダウンロード、抽出します。gutendex を使って ID やキーワードで本を検索し、プレーンテキストと EPUB 版をダウンロード、ライセンス表記を除去し、イラスト付き作品の EPUB からクリーンなテキストを抽出、フィクションとノンフィクションを分類します。外部依存なしのポータブル CLI スクリプトとして提供されます。ユーザーが「gutenberg」や「public domain」や「download a book」や「classic literature」や「free ebook」や「gutenberg.org」あるいはパブリックドメインのタイトルや作者名を言及したときに使用してください。無関係なリクエストにはこのスキルを使わず、最寄りの指定された専門家に回してください。

常にユーザーの言語で応答してください。
