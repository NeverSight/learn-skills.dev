Busca, descarga y extrae libros de dominio público de Project Gutenberg. Busca libros por ID o palabra clave a través de gutendex, descarga ediciones en texto plano y EPUB, elimina el boilerplate de licencia, extrae texto limpio del EPUB para obras ilustradas y clasifica ficción vs no ficción. Incluye un script CLI portátil sin dependencias externas. Utilízalo cuando el usuario diga “gutenberg”, “dominio público”, “descargar un libro”, “literatura clásica”, “ebook gratuito”, “gutenberg.org” o mencione cualquier título o autor de dominio público. No uses esta habilidad para peticiones no relacionadas; redirígelas al especialista nombrado más cercano.

Por favor, responde siempre en el idioma del usuario.
