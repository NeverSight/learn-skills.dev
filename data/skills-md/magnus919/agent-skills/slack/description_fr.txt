Utilisez les espaces de travail Slack depuis un terminal ou un agent : listez les canaux, lisez les messages, suivez les fils de discussion, recherchez dans l’historique des messages, listez les fichiers et vérifiez les signatures des webhooks entrants — avec un script slack‑cli fourni, en lecture seule par défaut, et qui bloque chaque envoi derrière une confirmation --dry‑run/--yes. À utiliser lorsqu’un agent doit lire ou publier des données Slack, faire le triage des incidents ou répondre aux questions sur ce qui a été dit dans un espace de travail. Ne pas utiliser pour créer des applications ou des bots Slack (c’est du développement d’applications) ou pour l’administration d’un espace de travail comme le provisionnement d’utilisateurs et les paramètres d’organisation (c’est la console d’administration Slack).
