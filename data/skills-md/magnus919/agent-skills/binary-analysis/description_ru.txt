Анализируйте неизвестные бинарные файлы с помощью детерминированного CLI, оборачивающего статический анализатор Ghidra. Используйте, когда необходимо инспектировать файл PE, ELF или Mach‑O — проводить триаж подозрительных бинарников, картировать импортированные API, декомпилировать функции, отслеживать пути вызовов или создавать структурированные отчёты о доказательствах. Не используйте для анализа во время выполнения (отладка, динамический трассинг, выполнение в песочнице), для модификации или патчинга бинарников, а также для бинарников, о которых вы уже знаете всё. Навык отвечает за планирование, формирование гипотез и синтез доказательств; CLI отвечает за все детерминированные операции.
