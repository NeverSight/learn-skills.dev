Analiza archivos binarios desconocidos mediante una CLI determinista que envuelve el motor de análisis estático de Ghidra. Úsala cuando necesites inspeccionar un archivo PE, ELF o Mach-O — clasifica binarios sospechosos, mapea APIs importadas, decompila funciones, rastrea rutas de llamadas o genera informes estructurados de evidencia. No la uses para análisis en tiempo de ejecución (depuración, trazado dinámico, ejecución en sandbox), para modificar o parchear binarios, o para binarios de los que ya sabes todo. La habilidad se encarga de la planificación, la formulación de hipótesis y la síntesis de evidencia; la CLI se encarga de todas las operaciones deterministas.
