Ghidra の静的解析エンジンをラップした決定論的 CLI を利用して、未知のバイナリファイルを分析します。PE、ELF、Mach-O ファイルの検査が必要なときに使用してください——疑わしいバイナリのトリアージ、インポートされた API のマッピング、関数の逆コンパイル、呼び出し経路の追跡、あるいは構造化された証拠レポートの作成に適しています。ランタイム解析（デバッグ、動的トレース、サンドボックス実行）やバイナリの変更・パッチ適用、既に全てを把握しているバイナリには使用しないでください。このスキルは計画、仮説形成、証拠の統合を担当し、CLI がすべての決定論的操作を担います。
