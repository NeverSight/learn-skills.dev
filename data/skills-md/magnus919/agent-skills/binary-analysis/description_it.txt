Analizza file binari sconosciuti tramite una CLI deterministica che avvolge il motore di analisi statica di Ghidra. Usala quando devi ispezionare un file PE, ELF o Mach‑O — esegui il triage di binari sospetti, mappa le API importate, decompila le funzioni, traccia i percorsi di chiamata o produci report di evidenza strutturati. Non usarla per analisi runtime (debugging, tracciamento dinamico, esecuzione in sandbox), per modificare o patchare binari, o per binari di cui conosci già tutto. La competenza comprende pianificazione, formazione di ipotesi e sintesi delle evidenze; la CLI gestisce tutte le operazioni deterministiche.  

Rispondi sempre nella lingua dell'utente.
