حَلِّل ملفات ثنائية غير معروفة عبر واجهة سطر أوامر حتمية تُغلف محرك التحليل الثابت الخاص بـ Ghidra. استخدمها عندما تحتاج إلى فحص ملف PE أو ELF أو Mach‑O — لتصنيف الثنائيات المشبوهة، ورسم خريطة لواجهات برمجة التطبيقات المستوردة، وفك تجميع الدوال، وتتبع مسارات الاستدعاء، أو لإصدار تقارير دليلية منظمة. لا تستخدمها للتحليل أثناء التشغيل (التصحيح، التتبع الديناميكي، التنفيذ في بيئة رملية)، ولا لتعديل أو تصحيح الثنائيات، ولا للثنائيات التي تعرف كل شيء عنها بالفعل. المهارة تشمل التخطيط، وتكوين الفرضيات، وتوليف الأدلة؛ بينما تتحكم واجهة سطر الأوامر في جميع العمليات الحتمية.
