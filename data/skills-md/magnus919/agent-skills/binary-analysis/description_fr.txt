Analysez des fichiers binaires inconnus via une CLI déterministe qui encapsule le moteur d’analyse statique de Ghidra. Utilisez‑la lorsque vous devez inspecter un fichier PE, ELF ou Mach‑O — triage de binaires suspects, cartographie des API importées, décompilation de fonctions, traçage des chemins d’appels ou production de rapports d’évidence structurés. Ne l’utilisez pas pour l’analyse à l’exécution (débogage, traçage dynamique, exécution en sandbox), pour modifier ou patcher des binaires, ou pour des binaires dont vous connaissez déjà tout. La compétence maîtrise la planification, la formation d’hypothèses et la synthèse de preuves ; la CLI maîtrise toutes les opérations déterministes.
