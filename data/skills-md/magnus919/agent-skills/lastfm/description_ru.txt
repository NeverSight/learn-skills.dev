Взаимодействуйте с API музыкальных данных Last.fm: ищите историю прослушиваний пользователя, получайте метаданные исполнителя/альбома/трека, открывайте похожую музыку с помощью коллаборативной фильтрации, исследуйте глобальные и страновые чарты, ищите по исполнителю/альбому/треку, управляйте тегами и фиксируйте прослушивания (scrobble). Используйте, когда пользователь задаёт вопросы о музыкальных данных, статистике прослушиваний, рекомендациях музыки, похожих исполнителях, чартах или хочет зафиксировать прослушивание или «любить» треки. Не применяйте этот навык к нерелевантным запросам; перенаправляйте к ближайшему именованному специалисту.

Пожалуйста, всегда отвечайте на языке пользователя.
