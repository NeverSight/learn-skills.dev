Interroga il catalogo di Open Library dal terminale: cerca libri e autori, consulta opere, edizioni e ISBN, elenca ogni edizione di un'opera, leggi le valutazioni della community e risolvi gli URL delle copertine. API pubblica completamente senza chiavi. Include il riferimento al grafo chiave OL…M/W/A, la risoluzione di redirect ISBN 302, la sintassi delle query di ricerca, le regole di hosting delle copertine e le pipeline elaborate. Non utilizzare per l'amministrazione IT di biblioteca (migrazione Koha/MARC/ILS), feed commerciali di dati sui libri o per gestire il tuo account di lettura su Open Library stesso.  

Rispondi sempre nella lingua dell'utente.
