Interrogez le catalogue Open Library depuis le terminal : recherchez des livres et des auteurs, consultez les œuvres, les éditions et les ISBN, énumérez chaque édition d’une œuvre, lisez les évaluations de la communauté et résolvez les URL des images de couvertures. API publique entièrement sans clé. Inclut la référence du graphe de clés OL…M/W/A, la résolution de redirection ISBN 302, la syntaxe des requêtes de recherche, les règles d’hébergement des couvertures et les pipelines de travail. N’utilisez pas pour l’administration informatique des bibliothèques (migration Koha/MARC/ILS), les flux de données commerciales de livres, ou la gestion de votre compte de lecture sur Open Library même.

Veuillez toujours répondre dans la langue de l'utilisateur.
