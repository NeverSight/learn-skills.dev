Запрашивайте каталог Open Library из терминала: ищите книги и авторов, просматривайте произведения, издания и ISBN, перечисляйте все издания произведения, читайте оценки сообщества и получайте URL‑адреса обложек. Полностью открытый публичный API без ключей. Включает ссылку на граф ключей OL…M/W/A, разрешение перенаправления ISBN 302, синтаксис поискового запроса, правила хостинга обложек и рабочие конвейеры. Не используйте для администрирования библиотечных ИТ (миграция Koha/MARC/ILS), коммерческих поставок книжных данных или управления своей учётной записью чтения в Open Library.
