Consulta el catálogo de Open Library desde la terminal: busca libros y autores, consulta obras, ediciones e ISBN, enumera cada edición de una obra, lee las valoraciones de la comunidad y resuelve las URLs de las imágenes de portada. API pública totalmente sin clave. Incluye la referencia del grafo de claves OL…M/W/A, resolución de redirección ISBN 302, sintaxis de consultas de búsqueda, reglas del host de portadas y flujos de trabajo. No lo uses para la administración de TI de bibliotecas (migración Koha/MARC/ILS), fuentes comerciales de datos de libros o para gestionar tu cuenta de lectura en Open Library.

Por favor, responde siempre en el idioma del usuario.
