Utiliza esta habilidad al crear u operar plataformas internas para desarrolladores: infraestructura como código, CI/CD, orquestación de contenedores, redes de servicios, secretos y observabilidad, o al diseñar productos de plataforma, interfaces de autoservicio, evidencia de adopción y límites de políticas. No la emplees para definir procesos de lanzamiento, promoción, despliegue o políticas de reversión; usa ingeniería de releases para ese modelo de entrega. Redirige la configuración y solución de problemas de la herramienta nombrada a la habilidad operativa correspondiente, como Kubernetes o Traefik para la configuración del controlador de ingreso.
