Construisez, développez, déployez, auto‑hébergez, sécurisez et dépannez des agents d’IA backend durables avec Vercel Eve. Utilisez‑le lors de la création d’un agent Eve, de l’ajout d’outils, de compétences, de sous‑agents, de canaux, de plannings, de sandbox, de sessions durables, d’observabilité, ou du déploiement d’Eve sur Vercel ou un hôte Node. N’utilisez pas pour les API d’agents distinctes du Vercel AI SDK telles que ToolLoopAgent ou WorkflowAgent ; utilisez une compétence spécifique au SDK d’IA pour celles‑ci.
