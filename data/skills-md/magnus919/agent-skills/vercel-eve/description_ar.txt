قم بإنشاء وتطوير ونشر واستضافة ذاتية وتأمين وحل مشاكل الوكلاء الخلفية الذكاء الاصطناعي المستدامة باستخدام Vercel Eve. استخدمه عند إنشاء وكيل Eve، وإضافة الأدوات، والمهارات، والوكلاء الفرعيين، والقنوات، والجدولات، وعزل البيئة (sandboxing)، والجلسات المستدامة، والرصد، أو عند نشر Eve على Vercel أو على مضيف Node. لا تستخدمه لواجهات برمجة التطبيقات المستقلة لـ Vercel AI SDK Agent مثل ToolLoopAgent أو WorkflowAgent؛ استخدم مهارة خاصة بـ AI SDK لتلك.
