Просматривайте федеративные видео PeerTube из терминала — статистика инстанса, последние видео, детали видео, ветки комментариев, каналы, аккаунты, поиск внутри инстанса и вход через OAuth2 с сохранением токена для каждого инстанса. Установите PEERTUBE_SERVER на любой инстанс; укажите sepiasearch.org для поиска по всему федиверсу. Используйте, когда пользователь упоминает PeerTube, федеративное видео, SepiaSearch или просмотр конкретного инстанса PeerTube. Не используйте эту возможность для загрузок на YouTube/Vimeo, видеомонтажа или установки и администрирования сервера PeerTube.
