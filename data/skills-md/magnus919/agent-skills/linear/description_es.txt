Administra equipos, proyectos, ciclos, incidencias, comentarios, estado del flujo de trabajo y documentos de Linear desde una terminal a través de la API pública GraphQL de Linear. Utilízalo cuando un usuario solicite listar, buscar, inspeccionar, crear, actualizar, mover o comentar sobre el trabajo de Linear, o para encontrar documentos de Linear. No lo uses para incrustar un agente en vivo dentro de Linear o para construir una integración MCP.
