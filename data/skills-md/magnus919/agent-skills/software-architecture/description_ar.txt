صمم وراجع بنى البرمجيات بدءًا من محفزات الأعمال مرورًا بحدود النظام، والتنازلات، وسلوك وقت التشغيل، والتطور، وممارسة الهندسة المعمارية. استخدمه عند اختيار بنية خضراء أو بنية مستهدفة، ومقارنة أشكال المونوليث المعياري والخدمات، وتصميم التناسق الموزع، والنسخ، والتجزئة، والتنسيق، والترتيب، وعزل المعاملات، أو سلوك الفشل، وتحديد دليل ملاءمة البنية، أو تسهيل مراجعة بنية ذات عواقب. لا تستخدمه لهندسة العكس، أو دلالات عقد API، أو تصميم منصة البيانات، أو التنفيذ، أو عمليات البنية التحتية، أو دورة حياة الأمان، أو تنفيذ迁移؛ وجه تلك إلى مهارات المتخصصين المسماة.
