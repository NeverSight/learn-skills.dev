Utilisez‑le lors de la gestion d’un serveur Forgejo ou Gitea depuis le terminal : issues, pull requests, dépôts, contenus de fichiers, labels, jalons, releases, webhooks, paramètres utilisateur, ou tout point de terminaison /api/v1 via une commande API générique sécurisée. Veuillez toujours répondre dans la langue de l’utilisateur.
