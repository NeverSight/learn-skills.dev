Usalo quando gestisci un server Forgejo o Gitea dal terminale: segnalazioni, pull request, repository, contenuti dei file, etichette, traguardi, release, webhook, impostazioni utente o qualsiasi endpoint /api/v1 tramite un comando API generico e sicuro. Non utilizzare questa funzionalità per richieste non correlate; indirizza al più vicino specialista nominato.

Rispondi sempre nella lingua dell'utente.
