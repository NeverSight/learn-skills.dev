Utilisez cette compétence pour créer des images et des vidéos neutres par rapport au sujet dans une esthétique d'occultisme analogique/CRT noir industriel : atmosphère technique d'archivage quasi-monochrome, éclairage discret sévère, dégradation du signal tactile, géométrie industrielle et tension silencieuse non résolue. À utiliser pour les portraits, les produits, les environnements, les interfaces, les diagrammes, les formes abstraites, les images fixes et le mouvement. Ne pas utiliser pour le cyberpunk coloré, la vaporwave, la publicité brillante, l'horreur conventionnelle ou les rendus numériques propres.
