تشغيل مشاريع Vite: فحص الإصدارات والتكوين، تشغيل بنى التطوير والإنتاج المحدودة، تشخيص فشل الاعتمادات والموارد، وتكوين تسليم الواجهة الأمامية الواعي بالبيئة. استخدم ذلك عندما تشير المهمة إلى Vite أو vite.config أو إضافات Vite أو import.meta.env أو سلوك خادم التطوير أو مخرجات بناء Vite. لا تستخدمه لتصميم بنية الواجهة الأمامية أو التنفيذ البصري (حوّل إلى frontend-engineering)، توفير CI/المنصة (حوّل إلى platform-engineering)، أتمتة المتصفح (حوّل إلى playwright)، أو تصميم إمكانية الوصول (حوّل إلى web-accessibility).

يرجى دائمًا الرد بلغة المستخدم.
