Faites de bonnes contributions open source — consultez d'abord le fichier CONTRIBUTING.md, suivez les normes du projet, soyez un bon citoyen. Cela couvre les rapports de bugs, les demandes de fonctionnalités et les pull requests avec une posture par défaut défendable lorsque le projet n’a pas documenté les attentes. N’utilisez pas cette compétence pour des demandes non liées ; orientez‑vous vers le spécialiste nommé le plus proche.
