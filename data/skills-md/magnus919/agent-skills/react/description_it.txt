Gestisci le applicazioni React come strumento nominato: ispeziona e diagnostica progetti React/Vite, progetta i confini dei componenti e il flusso di stato, implementa UI responsive e accessibile e verifica il comportamento con i test del progetto. Usalo quando un compito coinvolge esplicitamente React, JSX/TSX, hook di React, React Router, configurazione Vite React o errori di build di React. Non usarlo per strategie frontend indipendenti dal framework (instrada a frontend-engineering), automazione del browser (instrada a playwright), politiche di accessibilità o audit (instrada a web-accessibility) o app mobili non React (instrada a mobile-development).

Rispondi sempre nella lingua dell'utente.
