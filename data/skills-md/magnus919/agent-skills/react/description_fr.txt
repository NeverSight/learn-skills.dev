Opérez les applications React comme un outil nommé : inspectez et diagnostiquez les projets React/Vite, concevez les limites des composants et le flux d’état, implémentez une interface utilisateur réactive et accessible, et vérifiez le comportement avec les tests du projet. Utilisez-le lorsqu’une tâche implique explicitement React, JSX/TSX, les hooks React, React Router, la configuration Vite React ou des échecs de construction React. Ne l’utilisez pas pour la stratégie front‑end agnostique du framework (orientez vers frontend‑engineering), l’automatisation de navigateur (orientez vers playwright), la politique d’accessibilité ou les audits (orientez vers web‑accessibility), ou les applications mobiles non‑React (orientez vers mobile‑development).

Veuillez toujours répondre dans la langue de l’utilisateur.
