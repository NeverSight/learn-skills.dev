تشغيل تطبيقات React كأداة مسماة: فحص وتشخيص مشاريع React/Vite، تصميم حدود المكوّنات وتدفق الحالة، تنفيذ واجهة مستخدم متجاوبة وميسرة، والتحقق من السلوك باستخدام اختبارات المشروع. يُستخدم عندما تتضمن المهمة صراحةً React، JSX/TSX، خطاطيف React، React Router، تكوين Vite لتطبيقات React، أو فشل بناء React. لا يُستخدم لاستراتيجية الواجهة الأمامية غير المرتبطة بإطار عمل (يُحوَّل إلى frontend-engineering)، أو أتمتة المتصفح (يُحوَّل إلى playwright)، أو سياسات أو تدقيقات الوصول (يُحوَّل إلى web-accessibility)، أو التطبيقات المتنقلة غير React (يُحوَّل إلى mobile-development). يرجى دائمًا الرد بلغة المستخدم.
