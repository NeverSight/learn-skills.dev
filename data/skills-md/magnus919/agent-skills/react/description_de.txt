React-Anwendungen als benanntes Werkzeug betreiben: React/Vite‑Projekte inspizieren und diagnostizieren, Komponenten­grenzen und Zustands­flüsse entwerfen, barrierefreie, responsive UI implementieren und das Verhalten mit den Tests des Projekts verifizieren. Verwenden, wenn eine Aufgabe explizit React, JSX/TSX, React‑Hooks, React‑Router, Vite‑React‑Konfiguration oder React‑Build‑Fehler beinhaltet. Nicht verwenden für framework‑agnostische Frontend‑Strategie (weiterleiten an frontend-engineering), Browser‑Automatisierung (weiterleiten an playwright), Barrierefrei‑keits‑Richtlinien oder Audits (weiterleiten an web-accessibility) oder nicht‑React‑Mobile‑Apps (weiterleiten an mobile-development).

Bitte immer in der Sprache des Benutzers antworten.
