Работайте с React‑приложениями как с именованным инструментом: инспектируйте и диагностируйте проекты React/Vite, проектируйте границы компонентов и поток состояния, реализуйте доступный отзывчивый UI и проверяйте поведение с помощью тестов проекта. Используйте, когда задача явно связана с React, JSX/TSX, хуками React, React Router, конфигурацией Vite для React или ошибками сборки React. Не используйте для стратегии фронтенда, независимой от фреймворка (перенаправляйте к frontend‑engineering), автоматизации браузера (перенаправляйте к playwright), политики доступности или аудитов (перенаправляйте к web‑accessibility) или мобильных приложений без React (перенаправляйте к mobile‑development).

Пожалуйста, всегда отвечайте на языке пользователя.
