使用此技能來執行 BMad（突破性敏捷 AI 驅動開發方法）作為一個與框架無關的控制平面協議，將人類意圖轉化為有界、可檢查、可恢復的代理工作。將意圖壓縮成五欄合約（Why、Capabilities、Constraints、Non‑goals、Success signal）；將工作分類為 direct / bounded / initiative，並路由至最小安全路徑；以持久化工件承載決策；以分診方式審查；將失敗路由至產生模糊的層級；並以可觀測的接受度以及機器可讀狀態（draft、ready‑for‑dev、in‑progress、in‑review、done、blocked）來門控自治。當變更請求、功能、委派建置或多代理史詩需要意圖捕捉、界限實作、審查與可恢復性時使用，無論使用哪種代理框架。不要用於驗證問題是否真實（product‑discovery）、在規劃前形塑投注（product‑shaping）、正式規格／門檻流水線（spec‑driven‑development），或是 issue 到 PR 的交付流程（neckbeard）。
