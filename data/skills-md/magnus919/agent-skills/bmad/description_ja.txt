このスキルを使用して、BMad（Breakthrough Method of Agile AI-Driven Development）をハーネス非依存のコントロールプレーンプロトコルとして実行し、人間の意図を限定的で検査可能、再開可能なエージェント作業に変換します。意図は5つのフィールド（Why、Capabilities、Constraints、Non‑goals、Success signal）からなる契約に圧縮します；作業を direct / bounded / initiative に分類し、最小の安全パスへルーティングします；決定は永続的なアーティファクトに保持します；レビューはトリアージとして行います；失敗は曖昧性が入り込んだ層へルーティングします；そして自律性は機械可読なステータス（draft / ready‑for‑dev / in‑progress / in‑review / done / blocked）で観測可能な受容に基づいてゲートします。変更要求、機能、委任されたビルド、またはマルチエージェントエピックで、意図の取得、限定的実装、レビュー、再開可能性がエージェントハーネスに関係なく必要な場合に使用してください。問題が実在するかの検証（product‑discovery）、計画前のベット形成（product‑shaping）、形式的な仕様／ゲートパイプライン（spec‑driven‑development）、または issue‑to‑PR 配信フロー（neckbeard）には使用しないでください。
