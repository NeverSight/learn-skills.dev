Operar el alojamiento de podcasts de Transistor.fm desde la terminal: verificar el acceso a la API, explorar programas y episodios con salida compatible con JSON:API, ejecutar el ciclo de vida de publicación de episodios (crear borrador, adjuntar audio, publicar o programar mediante el endpoint de publicación dedicado), obtener análisis de descargas y gestionar suscriptores privados del podcast y webhooks. Utilizar cuando el usuario mencione Transistor, Transistor.fm, alojamiento de podcasts, publicación de episodios, suscriptores privados del podcast o análisis de descargas de podcasts. No usar esta habilidad para otros hospedadores de podcasts (Buzzsprout, Libsyn, Megaphone, Spotify for Creators), para editar o producir audio, o para análisis de feed/RSS — el CLI incluido gestiona una cuenta de Transistor a través de su API v1 y no puede crear nuevos programas (solo desde el panel).
