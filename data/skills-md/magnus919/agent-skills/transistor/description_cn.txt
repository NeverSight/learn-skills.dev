在终端操作 Transistor.fm 播客托管：验证 API 访问，使用 JSON:API 感知的输出浏览节目和剧集，执行剧集发布生命周期（创建草稿、附加音频、通过专用发布端点发布或安排），获取下载分析，并管理私有播客订阅者和 Webhook。当用户提到 Transistor、Transistor.fm、播客托管、剧集发布、私有播客订阅者或播客下载分析时使用。不要将此技能用于其他播客平台（Buzzsprout、Libsyn、Megaphone、Spotify for Creators），也不要用于编辑或制作音频，或用于 Feed/RSS 解析——该捆绑的 CLI 通过其 v1 API 管理 Transistor 账户，且不能创建新节目（仅限仪表板）。
