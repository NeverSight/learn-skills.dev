Управляйте хостингом подкастов Transistor.fm из терминала: проверяйте доступ к API, просматривайте шоу и эпизоды с выводом, совместимым с JSON:API, запускайте жизненный цикл публикации эпизода (создание черновика, прикрепление аудио, публикацию или планирование через специальный эндпоинт публикации), получайте аналитику загрузок и управляйте подписчиками закрытых подкастов и веб‑хуками. Используйте, когда пользователь упоминает Transistor, Transistor.fm, хостинг подкастов, публикацию эпизодов, подписчиков закрытых подкастов или аналитику загрузок подкастов. Не используйте этот навык для других хостингов подкастов (Buzzsprout, Libsyn, Megaphone, Spotify for Creators), для редактирования или производства аудио, а также для парсинга лент/RSS — встроенный CLI управляет аккаунтом Transistor через его API v1 и не может создавать новые шоу (только через панель).

Пожалуйста, всегда отвечайте на языке пользователя.
