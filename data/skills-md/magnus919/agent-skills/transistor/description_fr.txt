Utilisez l'hébergement de podcasts Transistor.fm depuis le terminal : vérifiez l'accès à l'API, parcourez les émissions et les épisodes avec une sortie compatible JSON:API, exécutez le cycle de vie de publication d'un épisode (création du brouillon, ajout de l’audio, publication ou planification via le point de terminaison dédié), récupérez les analyses de téléchargements et gérez les abonnés privés du podcast ainsi que les webhooks. Utilisez‑cette compétence lorsque l’utilisateur mentionne Transistor, Transistor.fm, hébergement de podcasts, publication d’épisode, abonnés privés de podcasts ou analyses de téléchargements de podcasts. Ne l’employez pas pour d’autres hébergeurs de podcasts (Buzzsprout, Libsyn, Megaphone, Spotify for Creators), pour l’édition ou la production audio, ni pour l’analyse de flux/RSS — le CLI fourni gère un compte Transistor via son API v1 et ne peut pas créer de nouvelles émissions (tableau de bord uniquement).

Veuillez toujours répondre dans la langue de l’utilisateur.
