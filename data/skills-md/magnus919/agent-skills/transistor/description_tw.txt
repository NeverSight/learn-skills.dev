從終端操作 Transistor.fm 播客託管：驗證 API 存取、以 JSON:API 感知的輸出瀏覽節目與集數、執行集數發佈生命週期（建立草稿、附加音訊、透過專屬發佈端點發佈或排程）、取得下載分析，並管理私人播客訂閱者與 webhook。當使用者提到 Transistor、Transistor.fm、播客託管、集數發佈、私人播客訂閱者或播客下載分析時使用。請勿將此功能用於其他播客平台（Buzzsprout、Libsyn、Megaphone、Spotify for Creators）、編輯或製作音訊，或解析 feed/RSS——此捆綁的 CLI 透過 v1 API 管理 Transistor 帳號，且無法建立新節目（僅限於儀表板）。
