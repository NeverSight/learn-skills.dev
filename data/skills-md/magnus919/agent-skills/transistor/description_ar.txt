تشغيل استضافة البودكاست عبر Transistor.fm من الطرفية: التحقق من وصول API، تصفح البرامج والحلقات مع إخراج يدعم JSON:API، تشغيل دورة نشر الحلقة (إنشاء مسودة، إرفاق الصوت، النشر أو الجدولة عبر نقطة النهاية المخصصة للنشر)، سحب تحليلات التحميل، وإدارة المشتركين الخاصين في البودكاست والويبهوك. استخدم ذلك عندما يذكر المستخدم Transistor أو Transistor.fm أو استضافة البودكاست أو نشر الحلقات أو المشتركين الخاصين في البودكاست أو تحليلات تنزيل البودكاست. لا تستخدم هذه المهارة مع مضيفي بودكاست آخرين (Buzzsprout، Libsyn، Megaphone، Spotify for Creators)، أو لتعديل أو إنتاج الصوت، أو لتحليل الخلاصات/‏RSS — فإن أداة سطر الأوامر المجمعة تدير حساب Transistor عبر واجهة API الإصدار 1 ولا يمكنها إنشاء برامج جديدة (فقط عبر لوحة التحكم). يرجى دائمًا الرد بلغة المستخدم.
