Erstellen Sie Multi‑Agenten‑KI‑Systeme mit LangGraph – dem Low‑Level‑Orchestrierungsframework für zustandsbehaftete, graphbasierte Agenten‑Workflows. Nutzen Sie dies, wenn Sie Agentenarchitekturen entwerfen, die Zyklen, bedingte Verzweigungen, parallele Ausführung oder Human‑in‑the‑Loop‑Muster benötigen. Verwenden Sie diese Fähigkeit nicht für unzusammenhängende Anfragen; leiten Sie sie an den nächstgelegenen benannten Spezialisten weiter.
