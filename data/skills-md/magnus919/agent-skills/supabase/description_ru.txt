Используйте этот навык при разработке приложений с Supabase, работе с Supabase CLI, проектировании миграций и политик RLS, тестировании поведения базы данных, генерации клиентских типов, развертывании официального самохостингового Docker‑стека или администрировании его Postgres, Auth, Storage, Realtime, Functions, API‑gateway, резервных копий, обновлений и безопасности. Применяйте его как для управляемых, так и для самохостинговых проектов. Не используйте его для обычных задач PostgreSQL без сервисов или соглашений Supabase.
