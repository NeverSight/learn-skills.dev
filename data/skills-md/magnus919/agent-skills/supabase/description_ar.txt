استخدم هذه المهارة عند تطوير التطبيقات باستخدام Supabase، وتشغيل واجهة سطر الأوامر Supabase CLI، وتصميم عمليات الهجرة وسياسات RLS، واختبار سلوك قاعدة البيانات، وتوليد أنواع العملاء، ونشر مجموعة Docker الرسمية المستضافة ذاتيًا، أو إدارة Postgres و Auth و Storage و Realtime و Functions و API gateway والنسخ الاحتياطية والترقيات والأمان. استخدمها للمشروعات المدارة والمستضافة ذاتيًا. لا تستخدمها لأعمال PostgreSQL العامة التي لا تشمل خدمات أو اتفاقيات Supabase.
