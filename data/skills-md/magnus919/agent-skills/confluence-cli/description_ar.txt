التفاعل مع Atlassian Confluence من الطرفية: سرد المساحات، تصفح الصفحات، عرض محتوى الصفحة، البحث باستخدام CQL، وإنشاء الصفحات. استخدمه عندما يذكر المستخدم Confluence أو مفتاح مساحة (مثل DEV) أو يسأل عن وثائق، صفحات الويكي، محتوى المساحة، أو مقالات قاعدة المعرفة. لا تستخدم هذه المهارة للطلبات غير ذات الصلة؛ حولها إلى أقرب أخصائي مسمى.

يرجى دائمًا الرد بلغة المستخدم.
