Interagissez avec Atlassian Confluence à partir du terminal : listez les espaces, parcourez les pages, affichez le contenu de la page, effectuez une recherche avec CQL et créez des pages. À utiliser lorsque l'utilisateur mentionne Confluence, une clé d'espace (par exemple, dev) ou pose des questions sur la documentation, les pages wiki, le contenu de l'espace ou les articles de la base de connaissances. N'utilisez pas cette compétence pour des demandes non liées ; dirigez-vous vers le spécialiste nommé le plus proche.
