Используйте этот навык для локального анализа медиа с помощью FFmpeg/FFprobe, ремульсинга, транскодирования, фильтрации, обзора видео с ограничением по доказательствам, редакционных планов с поддержкой транскрипций, списков решений по монтажу, очистки подкастов/аудио, рендеринга и принятия результатов. Он подчёркивает явный выбор потоков, сохранение исходного материала, команды с учётом сборки, ограниченные доказательства и проверенные новые выводы. Не используйте его для программирования с API libav, непрозрачного понимания полного видео, автоматической публикации, урегулирования прав, обхода DRM, профессиональной сертификации вещания/цветокоррекции или композиций, созданных HyperFrames; перенаправляйте такие задачи к их владельцам.
