Gérez le contenu de Ghost CMS via l’API Admin — parcourez les articles, les pages et les tags, rédigez et publiez du contenu, planifiez les publications et inspectez les informations du site depuis le terminal. N’utilisez pas cette compétence pour l’installation du serveur Ghost ou l’administration du site (installation, nginx, SSL, systemd, mises à jour) ; cela relève de l’outil officiel npm ghost-cli.

Veuillez toujours répondre dans la langue de l’utilisateur.
