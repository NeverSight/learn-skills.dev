Gestiona el contenido de Ghost CMS a través de la API de administración — navega por publicaciones, páginas y etiquetas, redacta y publica contenido, programa publicaciones y examina la información del sitio desde la terminal. No uses esta habilidad para la instalación del servidor Ghost o la administración del sitio (instalación, nginx, SSL, systemd, actualizaciones); esas tareas pertenecen a la herramienta oficial npm ghost‑cli.
