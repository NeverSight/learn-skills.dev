Gestisci i contenuti di Ghost CMS tramite l'Admin API — sfoglia post, pagine e tag, redigi e pubblica contenuti, programma i post e ispeziona le informazioni del sito dal terminale. Non utilizzare questa funzionalità per l'installazione del server Ghost o per l'amministrazione del sito (installazione, nginx, SSL, systemd, aggiornamenti); queste operazioni appartengono allo strumento ufficiale npm ghost-cli.

Rispondi sempre nella lingua dell'utente.
