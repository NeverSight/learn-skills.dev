Управляйте контентом Ghost CMS через Admin API — просматривайте посты, страницы и теги, создавайте черновики и публикуйте материалы, планируйте публикацию постов и просматривайте информацию о сайте из терминала. Не используйте эту возможность для установки сервера Ghost или администрирования сайта (установка, nginx, SSL, systemd, обновления); для этого предназначены официальные инструменты npm ghost‑cli.

Пожалуйста, всегда отвечайте на языке пользователя.
