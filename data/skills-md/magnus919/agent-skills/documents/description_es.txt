Generar, inspeccionar, validar y reparar documentos PDF, Word (.docx), Excel (.xlsx) y PowerPoint (.pptx): convertir contenido estructurado en artefactos listos para renderizar, verificar la calidad estructural y de salida antes de la entrega, y reparar archivos dañados. Utilízalo cuando una tarea implique crear, editar, convertir o validar documentos de oficina y PDFs. No lo uses para empaquetado de libros electrónicos (usa epub), para imágenes, video u otra producción de medios, para documentación de API o código, o para canalizaciones de datos (usa data-engineering).

Por favor, responde siempre en el idioma del usuario.
