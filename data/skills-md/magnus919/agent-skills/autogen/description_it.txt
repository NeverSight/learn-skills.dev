Costruisci sistemi multi‑agente conversazionali con Microsoft AutoGen. AssistantAgent, UserProxyAgent, GroupChat, esecuzione del codice, chat nidificate, token di cancellazione, integrazione di strumenti e supporto MCP. Utilizzalo quando costruisci sistemi multi‑agente guidati dalla conversazione o confronti framework di agenti. Non utilizzare questa abilità per richieste non correlate; indirizzala allo specialista più vicino.

Rispondi sempre nella lingua dell'utente.
