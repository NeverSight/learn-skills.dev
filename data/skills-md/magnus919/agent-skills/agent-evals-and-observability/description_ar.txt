صمّم أو نفّذ أو راجع أو أصدر تقييمات ومراقبة محايدة للمنصات والبائعين للوكالات الذكية. استخدمها عند تعريف تقييمات الوكالات، مجموعات البيانات، المقيمين، مراجعة المسارات، تحليل الانحدار، بوابات الإصدار، تتبعات الإنتاج، أو القياسات الحساسة للخصوصية. تشمل العقود الخاصة بالمهام والمسارات، المقارنات الإحصائية، وتعلم الحوادث إلى الحالات؛ وجه تنفيذ الإطار إلى pydanticai أو langgraph عند الحاجة. لا تستخدم هذه المهارة للطلبات غير المتعلقة؛ وحوّل إلى أقرب متخصص مسمى.

يرجى الرد دائمًا بلغة المستخدم.
