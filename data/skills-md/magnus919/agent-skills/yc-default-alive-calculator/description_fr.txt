Évaluez la durée de piste, la consommation, les revenus et la trajectoire de rentabilité d’une startup en utilisant le cadre Default Alive / Default Dead. N’utilisez pas cette compétence pour les expériences de croissance hebdomadaires ou les décisions de croissance opérationnelle ; utilisez `yc-weekly-growth-compass` pour ces décisions.

Veuillez toujours répondre dans la langue de l’utilisateur.
