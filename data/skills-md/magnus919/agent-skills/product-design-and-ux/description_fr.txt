Définissez le comportement du produit destiné aux utilisateurs à partir de preuves validées et d’un périmètre approuvé. Utilisez‑le pour l’architecture de l’information, les flux de tâches, les modèles d’état et de récupération, les contrats d’interface, les plans d’étude d’utilisabilité, les compromis de modèles d’interaction, les recommandations d’IA et les sorties générées, l’incertitude, le contrôle humain, les retours, ou les transferts d’ingénierie UX. Utilisez‑le après la découverte du produit et les décisions produit ; orientez le travail de conformité WCAG/ARIA vers l’accessibilité web et les spécifications logicielles formelles vers le développement piloté par les spécifications. N’utilisez pas cette compétence pour des demandes non liées ; orientez‑la vers le spécialiste nommé le plus proche.

Veuillez toujours répondre dans la langue de l’utilisateur.
