vLLM 推論サーバーの操作、設定、ベンチマーク、トラブルシューティング：Docker および Kubernetes デプロイ、量子化対応モデル設定（テンソル並列、KV キャッシュ）、OpenAI 互換 API の提供、スループットとレイテンシのベンチマーク、継続的バッチングのチューニング、GPU の運用、アップグレード／ロールバック。vLLM サーバー（vllm serve、vllm/vllm-openai）をデプロイまたは実行する際、GPU 用にモデルと KV キャッシュのサイズを決める際、量子化や並列化を選択する際、/v1 エンドポイントで提供する際、提供スループットやレイテンシを測定する際、バッチングを調整する際、または vLLM デプロイにおいて GPU、OOM、起動失敗を診断する際に使用してください。モデルのトレーニング、ファインチューニング、評価セット設計、エンジン選択手法（ml‑engineering）や、GGUF モデルを用いた llama.cpp スタックの運用（llama‑cpp）には使用しないでください。他の推論エンジン（TGI、Ollama、Triton）は対象外です。
