操作、配置、效能測試與除錯 vLLM 推論伺服器：Docker 與 Kubernetes 部署、量化感知模型設定（張量平行、KV 快取）、相容 OpenAI 的 API 服務、吞吐量與延遲基準測試、持續批次調校、GPU 操作以及升級/回滾。於以下情境使用：部署或執行 vLLM 伺服器（vllm serve、vllm/vllm-openai）、為 GPU 尺寸模型與其 KV 快取進行配置、選擇量化與平行方式、透過 /v1 端點提供服務、測量服務吞吐量或延遲、調整批次，或診斷 GPU、OOM 或啟動失敗等 vLLM 部署問題。請勿將本指南用於模型訓練、微調、評估集設計或引擎選型方法（即 ml‑engineering），亦勿用於操作使用 GGUF 模型的 llama.cpp 堆疊（即 llama‑cpp）；其他推論引擎（TGI、Ollama、Triton）不在本範圍內。
