Installa, configura, gestisci, proteggi, automatizza, ottimizza, risolvi i problemi e ripristina i backup di restic su back‑end locali, SFTP, compatibili S3, cloud e REST. Utilizzalo quando crei o gestisci un repository restic, progetti una politica di backup o di conservazione, convalidi i ripristini, gestisci la salute o i blocchi del repository, sposti i repository o crei lavori di backup pianificati e sicuri. Non usarlo per un'operazione generica di copia di file che non richiede snapshot crittografati e deduplicati.
