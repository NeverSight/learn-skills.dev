صمم، وابنِ، وراجِع واجهات الويب القابلة للوصول مع الدلالات الأصلية، سلوك لوحة المفاتيح والتركيز، النماذج والاسترداد، الإدخال المتجاوب، الحركة، اختبار التقنية المساعدة، ودلائل مستندة إلى WCAG 2.2. استخدمه لأعمال a11y، WCAG، ARIA، قارئ الشاشة، لوحة المفاتيح، التركيز، الحوار، النموذج، الودجت، أو مراجعة إمكانية الوصول عبر أطر العمل. لا تستخدم هذه المهارة لطلبات غير ذات صلة؛ احوِلها إلى أقرب متخصص مسمى.
