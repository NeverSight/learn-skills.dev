Diagnostiquez les problèmes de flux Kanban et concevez des modèles d'exploitation de tableau. Chargez ceci lorsque votre équipe a du mal avec le débit, que les temps de cycle sont imprévisibles, que plusieurs parties prenantes se font concurrence pour les mêmes ingénieurs, ou que vous vous demandez si le Kanban vous convient. N'utilisez pas cette compétence pour des demandes non liées ; dirigez vers le spécialiste nommé le plus proche.

Veuillez toujours répondre dans la langue de l'utilisateur.
