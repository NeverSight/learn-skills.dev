Взаимодействуйте с Atlassian Jira из терминала: ищите задачи с помощью JQL, просматривайте детали, создавайте задачи, добавляйте комментарии, подсчитывайте совпадения быстрым approximate-count, выводите список проектов, обнаруживайте допустимые переходы и меняйте статус. Включает полное справочное руководство по языку JQL (функции, операторы, предикаты истории, выражения дат, сохранённые фильтры, настройка производительности) плюс руководство по аутентификации REST и пагинации. Используйте, когда пользователь упоминает Jira, ключ задачи (например, PROJ-123), задаёт вопросы о задачах, багах, тикетах, проектах или спринт‑работе, либо нужно написать, отладить или оптимизировать запросы JQL. Не используйте для отслеживания задач в GitHub или GitLab, администрирования сайта Jira или общих систем тикетов.
