التفاعل مع Atlassian Jira من الطرفية: البحث عن القضايا باستخدام JQL، عرض التفاصيل، إنشاء القضايا، إضافة تعليقات، عد المطابقات باستخدام العد التقريبي السريع، سرد المشاريع، اكتشاف الانتقالات الصالحة، وتغيير الحالة. يتضمن مرجعًا كاملاً للغة JQL (الدوال، المشغلات، متنبئات التاريخ، تعبيرات التاريخ، الفلاتر المحفوظة، تحسين الأداء) بالإضافة إلى إرشادات المصادقة/التصفح عبر REST. استخدمه عندما يذكر المستخدم Jira أو مفتاح تذكرة (مثال: PROJ-123) أو يسأل عن القضايا أو الأخطاء أو المهام أو المشاريع أو عمل السبرينت، أو يحتاج إلى كتابة أو تصحيح أو تحسين استعلامات JQL. لا تستخدمه لتتبع القضايا على GitHub أو GitLab، أو لإدارة موقع Jira، أو لأنظمة التذاكر العامة.
