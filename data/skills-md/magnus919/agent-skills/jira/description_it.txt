Interagisci con Atlassian Jira dal terminale: cerca le issue con JQL, visualizza i dettagli, crea issue, aggiungi commenti, conta le corrispondenze con il conteggio approssimato veloce, elenca i progetti, scopri le transizioni valide e cambia lo stato. Include un riferimento completo al linguaggio JQL (funzioni, operatori, predicati di cronologia, espressioni di data, filtri salvati, ottimizzazione delle prestazioni) più indicazioni su autenticazione REST e paginazione. Usalo quando l'utente menziona Jira, una chiave di ticket (es. PROJ‑123), chiede informazioni su issue, bug, task, progetti o lavoro di sprint, o ha bisogno di scrivere, fare debug o ottimizzare query JQL. Non usarlo per il tracciamento di issue su GitHub o GitLab, per l'amministrazione di siti Jira o per sistemi di ticketing generici.

Rispondi sempre nella lingua dell'utente.
