터미널에서 Atlassian Jira와 상호작용: JQL로 이슈 검색, 상세 보기, 이슈 생성, 코멘트 추가, 빠른 근사 카운트로 매치 수 세기, 프로젝트 목록 조회, 유효한 전이 찾기, 상태 변경. 전체 JQL 언어 참고자료(함수, 연산자, 히스토리 프레디케이트, 날짜 표현식, 저장된 필터, 성능 튜닝)와 REST 인증·페이지네이션 가이드를 포함. 사용자는 Jira, 티켓 키(예: PROJ-123)를 언급하거나 이슈, 버그, 작업, 프로젝트, 스프린트 작업에 대해 질문하거나 JQL 쿼리를 작성·디버그·최적화해야 할 때 사용하세요. GitHub 또는 GitLab 이슈 트래킹, Jira 사이트 관리, 일반 티켓 시스템에는 사용하지 마세요.
