Interactúa con Atlassian Jira desde la terminal: busca incidencias con JQL, visualiza detalles, crea incidencias, añade comentarios, cuenta coincidencias con fast approximate-count, lista proyectos, descubre transiciones válidas y cambia el estado. Incluye una referencia completa del lenguaje JQL (funciones, operadores, predicados de historial, expresiones de fecha, filtros guardados, afinación del rendimiento) más guía de autenticación/paginación REST. Utilízalo cuando el usuario mencione Jira, una clave de ticket (p. ej., PROJ-123), pregunte sobre incidencias, errores, tareas, proyectos o trabajo de sprint, o necesite escribir, depurar u optimizar consultas JQL. No lo uses para el seguimiento de incidencias en GitHub o GitLab, la administración del sitio Jira, o sistemas genéricos de tickets.
