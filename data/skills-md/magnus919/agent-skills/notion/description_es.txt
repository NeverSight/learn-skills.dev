Operar Notion desde una terminal o agente: recuperar páginas, consultar bases de datos, buscar páginas y bases de datos, y actualizar las propiedades de las páginas — con un script notion-cli incluido que es de solo lectura por defecto y protege cada creación o actualización detrás de una confirmación --dry-run/--yes. Úselo cuando un agente necesite leer contenido de Notion, responder preguntas de una wiki o base de datos del equipo, o realizar una edición confirmada. No lo use para crear integraciones de Notion o composición de páginas a nivel de bloque más allá de la actualización de propiedades (eso es desarrollo de aplicaciones con la API de Notion), ni para otras bases de conocimiento (es decir, sus propias herramientas).
