Utilizza la collaborazione crittografata di CryptPad per integrazione, automazione e diagnosi con la sua API di integrazione del browser, scoperta delle istanze, importazione/esportazione di documenti e ciclo di vita della chiave di sessione. Usala per la fattibilità dell'API di CryptPad, editor incorporati, condivisione, persistenza o risoluzione dei problemi di istanze auto‑ospitate. Non usarla per EncryptPad/OpenPGP, conversione generica di file Office o per progettare un servizio di collaborazione non correlato.  

Rispondi sempre nella lingua dell'utente.
