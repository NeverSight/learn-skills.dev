Utilisez le wrapper minimal FlareSolverr pour un contrôle de santé ponctuel ou un GET/POST basé sur le navigateur lorsque la récupération ordinaire est bloquée par Cloudflare ou DDoS‑GUARD. Choisissez flaresolverr‑cli à la place pour la gestion du cycle de vie d’une session nommée, les retours uniquement cookies, la planification en mode simulation, ou l’ensemble complet des commandes opérationnelles. N’utilisez pas cette compétence pour des demandes non liées ; dirigez‑les vers le spécialiste nommé le plus proche.

Veuillez toujours répondre dans la langue de l’utilisateur.
