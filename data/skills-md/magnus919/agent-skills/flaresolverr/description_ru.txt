Используйте минимальную обёртку FlareSolverr для одноразовой проверки состояния или GET/POST через браузер, когда обычный запрос блокируется Cloudflare или DDoS‑GUARD. Выбирайте flaresolverr‑cli для управления именованными сессиями, возврата только cookie, планирования «сухого прогона» или полного набора команд. Не используйте этот навык для нерелевантных запросов; перенаправляйте их к ближайшему именованному специалисту.

Пожалуйста, всегда отвечайте на языке пользователя.
