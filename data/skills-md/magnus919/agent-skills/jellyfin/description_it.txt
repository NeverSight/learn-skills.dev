Interroga il tuo server multimediale Jellyfin dal terminale — media aggiunti di recente, ricerca, dettagli dell'elemento, navigazione delle serie, episodi successivi, navigazione della libreria, informazioni sul server e accesso utente. Utilizza quando l'utente chiede di Jellyfin, server multimediali, film, serie TV, episodi successivi o la sua libreria multimediale. Non usare questa funzionalità per l'installazione del server, la gestione della libreria, il controllo della riproduzione o per server Emby/Plex.

Rispondi sempre nella lingua dell'utente.
