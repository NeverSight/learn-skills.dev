Interrogez votre serveur multimédia Jellyfin depuis le terminal — médias récemment ajoutés, recherche, détails d’éléments, navigation dans les séries, épisodes à venir, navigation dans la bibliothèque, informations du serveur et connexion utilisateur. Utilisez-le lorsque l’utilisateur pose des questions sur Jellyfin, les serveurs multimédias, les films, les séries télévisées, les prochains épisodes ou leur bibliothèque multimédia. N’utilisez pas cette compétence pour l’installation du serveur, la gestion de la bibliothèque, le contrôle de la lecture ou les serveurs Emby/Plex.

Veuillez toujours répondre dans la langue de l’utilisateur.
