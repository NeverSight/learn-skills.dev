操作 Playwright 進行完整的瀏覽器自動化：編寫與除錯 E2E 測試套件（強韌的定位器、網路攔截與模擬、平行執行者、可及性快照檢查），將它們整合至 CI，並以 headless 瀏覽與爬蟲執行「抽取 → 驗證 → 儲存」迴圈。適用於使用 Playwright 撰寫、執行、修正或爬取時，或當 Playwright CI 失敗或 JSON 報告需要排查，或需要使用內建的 pwrun 腳本分析執行結果時。不要用於 QA 策略或測試框架選擇（請導向 qa‑methodology）、前端元件或架構設計（請導向 frontend‑engineering），或繞過 Cloudflare/DDoS‑GUARD 挑戰（使用 flaresolverr）。
