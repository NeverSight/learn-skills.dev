Playwright를 사용해 브라우저 자동화를 엔드 투 엔드로 수행합니다: E2E 테스트 스위트를 작성하고 디버깅합니다(견고한 로케이터, 네트워크 가로채기 및 모킹, 병렬 워커, 접근성 스냅샷 검사), 이를 CI에 연결하고 추출 → 검증 → 저장 루프로 헤드리스 브라우징 및 스크래핑을 구동합니다. Playwright로 작성, 실행, 수정, 또는 스크래핑을 할 때, Playwright CI 실패나 JSON 보고서의 트라이지가 필요할 때, 또는 번들된 pwrun 스크립트가 실행을 분석해야 할 때 사용합니다. QA 전략이나 테스트 프레임워크 선택에는 사용하지 마세요(qa-methodology로 이동), 프론트엔드 컴포넌트나 아키텍처 설계에는 사용하지 마세요(frontend-engineering으로 이동), Cloudflare/DDoS‑GUARD 챌린지 우회에는 사용하지 마세요(flaresolverr 사용).
