Gestisci Playwright per l’automazione del browser end‑to‑end: crea e debugga suite di test E2E (locator robusti, intercettazione e mocking della rete, worker paralleli, controlli di snapshot di accessibilità), integrali nel CI e guida la navigazione headless e lo scraping con un ciclo estrai → valida → salva. Usalo quando scrivi, esegui, correggi o fai scraping con Playwright, quando un errore di CI di Playwright o un report JSON richiedono triage, o quando lo script pwrun incluso deve analizzare un’esecuzione. Non usarlo per la strategia QA o la selezione del framework di test (indirizza a qa‑methodology), per la progettazione di componenti o architettura frontend (indirizza a frontend‑engineering), o per aggirare le sfide Cloudflare/DDoS‑GUARD (usa flaresolverr).

Rispondi sempre nella lingua dell’utente.
