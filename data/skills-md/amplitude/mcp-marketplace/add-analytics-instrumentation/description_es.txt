Flujo de trabajo de instrumentación analítica de extremo a extremo para una PR, rama, archivo, directorio o funcionalidad. Lee el código, descubre qué eventos deben rastrearse y genera un plan de instrumentación concreto, todo en una sola pasada. Usa esta habilidad siempre que un usuario quiera añadir analítica a una PR, solicite “instrumentar esta PR”, “añadir seguimiento a esta rama”, “qué analítica necesita este archivo”, “instrumentar el flujo de checkout”, “ejecutar el flujo completo de instrumentación”, o cualquier petición que implique pasar de cambios de código a un plan de seguimiento. También se activa cuando el usuario proporciona un enlace a una PR, el nombre de una rama, la ruta de un archivo o una descripción de una funcionalidad y menciona analítica, eventos o instrumentación. Este es el punto de entrada principal para el flujo de trabajo de analítica — prefierelo sobre llamar a los pasos individuales (diff‑intake, discover‑event‑surfaces, instrument‑events) por separado.

Por favor, responde siempre en el idioma del usuario.
