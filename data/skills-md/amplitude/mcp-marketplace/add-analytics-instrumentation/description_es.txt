Flujo de trabajo de instrumentación de análisis de extremo a extremo para una PR, rama, archivo, directorio o característica. Lee el código, descubre qué eventos deben rastrearse y produce un plan de instrumentación concreto, todo en una sola pasada. Utiliza esta habilidad siempre que un usuario quiera agregar análisis a una PR, solicite "instrumentar esta PR", "agregar seguimiento a esta rama", "qué análisis necesita este archivo", "instrumentar el flujo de pago", "ejecutar el flujo de trabajo completo de instrumentación", o cualquier solicitud que implique pasar de cambios de código a un plan de seguimiento. También se activa cuando el usuario te proporciona un enlace a una PR, el nombre de una rama, la ruta de un archivo o una descripción de una característica y menciona análisis, eventos o instrumentación. Este es el punto de entrada principal para el flujo de trabajo de análisis; prefíere este enfoque en lugar de llamar a los pasos individuales (diff-intake, discover-event-surfaces, instrument-events) por separado.
