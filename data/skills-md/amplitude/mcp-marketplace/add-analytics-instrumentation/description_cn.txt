针对 PR、分支、文件、目录或功能的端到端分析仪器化工作流。读取代码，发现应跟踪的事件，并生成具体的仪器化计划——一次完成。每当用户想要在 PR 中添加分析、请求“对该 PR 进行仪器化”“为此分支添加跟踪”“此文件需要哪些分析”“对结账流程进行仪器化”“运行完整的仪器化工作流”，或任何暗示从代码更改生成跟踪计划的请求时，都使用此技能。当用户提供 PR 链接、分支名称、文件路径或功能描述，并提及分析、事件或仪器化时，也触发。本入口是分析工作流的主要入口——优先于单独调用各步骤（diff-intake、discover-event-surfaces、instrument-events）。

请始终使用用户的语言作答。
