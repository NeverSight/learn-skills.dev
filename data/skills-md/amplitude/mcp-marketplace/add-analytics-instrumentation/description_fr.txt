Flux de travail d'instrumentation analytique de bout en bout pour une PR, une branche, un fichier, un répertoire ou une fonctionnalité. Lit le code, découvre quels événements doivent être suivis et produit un plan d’instrumentation concret — le tout en une seule fois. Utilisez cette compétence chaque fois qu’un utilisateur veut ajouter de l’analytique à une PR, demande « instrumenter cette PR », « ajouter le suivi à cette branche », « quelles analyses ce fichier nécessite », « instrumenter le flux de paiement », « exécuter le workflow complet d’instrumentation », ou toute demande qui implique de passer des changements de code à un plan de suivi. Déclenchez également lorsque l’utilisateur vous fournit un lien de PR, le nom d’une branche, le chemin d’un fichier ou une description de fonctionnalité et mentionne l’analytique, les événements ou l’instrumentation. C’est le point d’entrée principal du workflow analytique — privilégiez‑le plutôt que d’appeler séparément les étapes individuelles (diff‑intake, discover‑event‑surfaces, instrument‑events).

Veuillez toujours répondre dans la langue de l’utilisateur.
