PR、ブランチ、ファイル、ディレクトリ、または機能向けのエンドツーエンド分析インストルメンテーションワークフローです。コードを読み取り、追跡すべきイベントを発見し、具体的なインストルメンテーションプランを一度に生成します。ユーザーが PR に分析を追加したい、「instrument this PR」や「add tracking to this branch」・「what analytics does this file need」・「instrument the checkout flow」・「run the full instrumentation workflow」など、コード変更からトラッキングプランへの変換を意味するリクエストをしたときにこのスキルを使用してください。また、ユーザーが PR のリンク、ブランチ名、ファイルパス、または機能の説明を提示し、分析、イベント、インストルメンテーションに言及した場合にもトリガーします。これは分析ワークフローの主要エントリーポイントです——個別のステップ（diff-intake、discover‑event‑surfaces、instrument‑events）を別々に呼び出すよりも、こちらを優先してください。

常にユーザーの言語で応答してください。
