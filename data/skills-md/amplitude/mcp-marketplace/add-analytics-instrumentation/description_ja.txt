PR、ブランチ、ファイル、ディレクトリ、または機能に対するエンドツーエンドの分析計装ワークフローです。コードを読み取り、追跡すべきイベントを発見し、具体的な計装プランを一度に生成します。このスキルは、ユーザーが PR に分析を追加したいときや「この PR を計装して」「このブランチにトラッキングを追加して」「このファイルに必要な分析は何か」「checkout フローを計装して」「完全な計装ワークフローを実行して」など、コード変更からトラッキングプランへの変換を暗示するリクエストがある場合に使用してください。また、ユーザーが PR のリンク、ブランチ名、ファイルパス、または機能の説明を提供し、分析、イベント、または計装に言及したときにもトリガーしてください。これは分析ワークフローの主要エントリーポイントです——個別のステップ（diff-intake、discover‑event‑surfaces、instrument‑events）を別々に呼び出すよりもこちらを優先してください。
