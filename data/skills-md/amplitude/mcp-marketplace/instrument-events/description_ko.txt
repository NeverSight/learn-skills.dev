event_candidates YAML( discover-event-surfaces의 출력)를 기반으로 우선순위 3(중요) 이벤트에 대한 구체적인 계측 계획을 생성합니다. 소프트웨어 아키텍트 역할을 수행하며: 코드베이스에서 기존 분석 패턴을 발견하고, 힌트가 제공된 파일을 읽어 범위 내 변수들을 파악하며, 최소한의 차트‑유용 속성을 설계하고, 각 트래킹 호출의 정확한 삽입 지점을 식별합니다. 구조화된 JSON trackingPlan을 출력합니다. 이는 discover-event-surfaces 이후 분석 계측 워크플로우의 단계 3으로 사용합니다. 사용자가 event_candidates를 가지고 트래킹 코드를 생성하고자 할 때, “instrument these events”, “generate tracking plan”, “add analytics for these events”, “where should I put the tracking calls”와 같은 요청이나 이벤트 후보를 구체적인 구현 지침으로 전환하고자 하는 모든 요청이 있을 때 트리거됩니다.
