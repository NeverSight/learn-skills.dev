event_candidates の YAML（discover-event-surfaces の出力）を受け取り、優先度 3（クリティカル）イベントの具体的な計測プランを生成します。ソフトウェアアーキテクトとして機能し、コードベース内の既存の分析パターンを発見し、ヒントが付されたファイルを読み取ってスコープ内の変数を特定し、最小限で実用的なチャートプロパティを設計し、各トラッキング呼び出しの正確な挿入位置を特定します。構造化された JSON 形式の trackingPlan を出力します。これは discover-event-surfaces の後の分析計測ワークフローのステップ 3 として使用します。ユーザーが event_candidates を持ち、計測コードの生成を希望し、「これらのイベントを計測する」「トラッキングプランを生成する」「これらのイベントに分析を追加する」「トラッキング呼び出しをどこに置くべきか」など、イベント候補を具体的な実装指針に変換するリクエストがあったときにトリガーします。

必ずユーザーの言語で応答してください。
