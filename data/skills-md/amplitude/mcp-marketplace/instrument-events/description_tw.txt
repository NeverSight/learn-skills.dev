給定 event_candidates YAML（discover-event-surfaces 的輸出），生成針對 priority-3（關鍵）事件的具體插裝計畫。作為軟體架構師：發現程式碼庫中現有的分析模式，讀取提示的檔案以確定哪些變數在範圍內，設計最小化且對圖表有用的屬性，並找出每個追蹤呼叫的確切插入點。輸出結構化的 JSON trackingPlan。將此作為分析插裝工作流程的第 3 步，於 discover-event-surfaces 之後使用。當使用者擁有 event_candidates 且想產生追蹤程式碼，或詢問「instrument these events」（插裝這些事件）、「generate tracking plan」（產生追蹤計畫）、「add analytics for these events」（為這些事件加入分析）、「where should I put the tracking calls」（追蹤呼叫應放在哪裡）或任何將事件候選轉換為具體實作指引的需求時，即觸發。請始終以使用者的語言回應。
