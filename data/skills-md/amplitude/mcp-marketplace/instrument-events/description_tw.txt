給定 event_candidates YAML（由 discover-event-surfaces 輸出），產生針對優先級 3（關鍵）事件的具體插裝計畫。充當軟體架構師：發現程式碼庫中既有的分析模式，讀取提示的檔案以確定哪些變數在作用範圍內，設計最小且對圖表有用的屬性，並找出每個追蹤呼叫的精確插入點。輸出結構化的 JSON trackingPlan。將此作為分析插裝工作流程的第 3 步，於 discover-event-surfaces 之後。當使用者持有 event_candidates 並希望產生追蹤程式碼、詢問「instrument these events」、「generate tracking plan」、「add analytics for these events」、「where should I put the tracking calls」或任何將事件候選轉為具體實作指導的請求時，即觸發此功能。
