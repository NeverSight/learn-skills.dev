Данный YAML‑файл event_candidates (результат работы discover-event-surfaces) генерирует конкретный план инструментирования для событий приоритета 3 (критических). Выступает в роли архитектора программного обеспечения: обнаруживает существующие аналитические паттерны в кодовой базе, читает подсказанные файлы, чтобы определить, какие переменные находятся в области видимости, разрабатывает минимальные полезные свойства для диаграмм и определяет точную точку вставки для каждого вызова трекинга. Выводит структурированный JSON‑объект trackingPlan. Используйте это как третий шаг процесса инструментирования аналитики, после discover-event-surfaces. Срабатывает каждый раз, когда у пользователя есть event_candidates и он хочет сгенерировать код трекинга, задаёт вопросы «инструментировать эти события», «сгенерировать план трекинга», «добавить аналитику для этих событий», «куда разместить вызовы трекинга» или любой запрос превратить кандидаты событий в конкретные рекомендации по реализации.

Пожалуйста, всегда отвечайте на языке пользователя.
