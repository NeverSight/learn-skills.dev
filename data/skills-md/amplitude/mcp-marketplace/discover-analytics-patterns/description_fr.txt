Découvre comment les appels de suivi analytique sont réellement écrits dans ce code—les appels SDK concrets, les signatures de fonctions et les schémas d'importation utilisés pour envoyer des événements. Utilise cette compétence chaque fois que tu dois comprendre les modèles d’instrumentation analytique existants avant d’ajouter un nouveau suivi, lorsque quelqu’un demande « comment suivi‑t‑on les événements ici ? », « montre‑moi la configuration analytique », « quel est le modèle analytique dans ce code ? », ou à chaque fois que les compétences instrument‑events ou discover‑event‑surfaces sont sur le point d’être exécutées et que tu as besoin de connaître le style de codage correct à suivre. Produit une liste dédupliquée de modèles avec des exemples généralisés et les chemins de fichiers où chaque modèle apparaît, ainsi que les conventions dominantes de nommage des événements et des propriétés déduites de ces points d’appel. Utilise toujours cette compétence avant d’écrire tout code d’instrumentation analytique.
