يقوم بقراءة طلب سحب (PR) أو فرق الفروع ويولد ملخص تغييرات بنية YAML منظم لمهارات أدوات التحليل اللاحقة. استخدم هذا كخطوة أولى كلما شارك المستخدم رابط طلب سحب، مقارنة فروع، أو فرق خام ويرغب في فهم ما تم تغييره، وما الذي يحتاج إلى تتبع، أو كيفية تفعيل ميزة. يتم التفعيل عند العبارات مثل "review this PR"، "what changed in this branch"، "help me instrument this diff"، "check analytics coverage for this change"، أو أي طلب لبدء سير عمل مراجعة التحليلات.

يرجى دائمًا الرد بلغة المستخدم.
