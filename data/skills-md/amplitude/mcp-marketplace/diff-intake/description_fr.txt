Lit un PR ou le diff d’une branche et produit un bref structuré au format YAML des changements pour les compétences d’instrumentation analytique en aval. Utilisez-le comme première étape chaque fois qu’un utilisateur partage un lien PR, une comparaison de branche ou un diff brut et souhaite comprendre ce qui a changé, ce qui doit être suivi, ou comment instrumenter une fonctionnalité. Déclenchez-le sur des phrases telles que « review this PR », « what changed in this branch », « help me instrument this diff », « check analytics coverage for this change », ou toute demande de démarrer le flux de travail de révision analytique.

Veuillez toujours répondre dans la langue de l’utilisateur.
