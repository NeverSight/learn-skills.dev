Lit un PR ou un diff de branche et génère un bref de changement YAML structuré pour les compétences d’instrumentation analytique en aval. Utilisez ceci comme première étape chaque fois qu’un utilisateur partage un lien PR, une comparaison de branches ou un diff brut et souhaite comprendre ce qui a changé, ce qui doit être suivi ou comment instrumenter une fonctionnalité. Se déclenche sur des phrases telles que « review this PR », « what changed in this branch », « help me instrument this diff », « check analytics coverage for this change », ou toute demande de lancer le flux de travail de révision analytique.

Veuillez toujours répondre dans la langue de l'utilisateur.
