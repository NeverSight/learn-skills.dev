Lee un PR o diff de rama y genera un breve estructurado en YAML de los cambios para las habilidades de instrumentación de analítica downstream. Úsalo como el primer paso siempre que un usuario comparta un enlace de PR, una comparación de ramas o un diff sin procesar y quiera entender qué cambió, qué necesita seguimiento o cómo instrumentar una característica. Se activa con frases como "review this PR", "what changed in this branch", "help me instrument this diff", "check analytics coverage for this change", o cualquier solicitud para iniciar el flujo de trabajo de revisión de analítica.

Por favor, responde siempre en el idioma del usuario.
