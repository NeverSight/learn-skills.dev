Lee un PR o diff de rama y produce un resumen estructurado en YAML de cambios para habilidades de instrumentación de análisis descendentes. Úsalo como el primer paso siempre que un usuario comparta un enlace de PR, una comparación de ramas o un diff sin procesar y quiera entender qué cambió, qué necesita ser rastreado o cómo instrumentar una funcionalidad. Se activa con frases como "review this PR", "what changed in this branch", "help me instrument this diff", "check analytics coverage for this change", o cualquier solicitud de iniciar el flujo de trabajo de revisión de análisis.

Por favor, responde siempre en el idioma del usuario.
