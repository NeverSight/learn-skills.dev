change_brief YAML(diff-intake 출력)을 기반으로 계측할 분석 이벤트 후보 목록을 전체적으로 생성합니다. PM 마인드를 갖춘 엔지니어의 관점에서 접근해, PM이 실제로 중요한 것을 결정할 수 있도록 고려할 만한 모든 요소를 드러냅니다. 이를 분석 계측 워크플로우의 2단계로 사용하며, diff-intake이 change_brief를 생성한 직후에 실행합니다. 사용자가 change_brief YAML을 가지고 분석 이벤트 추가 방법을 알고 싶을 때, “이 PR에서 무엇을 추적해야 할까”, “어떤 이벤트를 계측해야 할까”, “이벤트 후보 생성” 등 코드 변경에 대한 분석 범위 격차를 파악하고자 하는 요청이 있을 때마다 트리거됩니다.  

항상 사용자의 언어로 답변하십시오.
