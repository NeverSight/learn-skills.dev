diff-intake에서 생성된 change_brief YAML을 받아, 계측할 분석 이벤트 후보 목록을 포괄적으로 생성합니다. PM 마인드셋을 가진 엔지니어의 관점에서 접근하여, PM이 실제로 중요한 사항을 결정할 수 있도록 고려할 가치가 있는 모든 것을 표출합니다. 이를 분석 계측 워크플로우의 2단계로 사용하며, diff-intake가 change_brief를 만든 직후에 바로 적용합니다. 사용자가 change_brief YAML을 가지고 있고 어떤 분석 이벤트를 추가해야 할지 알고 싶을 때, 또는 “이 PR에서 무엇을 추적해야 하나요”, “어떤 이벤트를 계측해야 하나요”, “이벤트 후보를 생성해 주세요” 혹은 코드 변경에 대한 분석 커버리지 격차를 드러내 달라는 요청이 있을 때마다 트리거됩니다.
