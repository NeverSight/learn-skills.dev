Dado un YAML de change_brief (salida de diff-intake), genera una lista exhaustiva de eventos analíticos candidatos para instrumentar. Asume la perspectiva de un ingeniero con mentalidad de PM — muestra todo lo que vale la pena considerar para que un PM pueda decidir qué es realmente importante. Utilízalo como el paso 2 del flujo de trabajo de instrumentación analítica, inmediatamente después de que diff-intake produzca un change_brief. Se activa siempre que un usuario tenga un YAML de change_brief y quiera saber qué eventos analíticos añadir, o pregunte “qué debería rastrear para este PR”, “qué eventos debería instrumentar”, “generar candidatos a eventos”, o cualquier solicitud para revelar brechas de cobertura analítica de un cambio de código.

Por favor, siempre responde en el idioma del usuario.
