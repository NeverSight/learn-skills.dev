إنشاء فيديوهات كرتونية يدوية الصنع بألوان مائية وحبر (MP4) باستخدام الشيفرة — p5.js + p5.brush تُرسم إطارًا تلو الآخر في Chrome بدون واجهة، وتُشفَّر باستخدام ffmpeg — مع كلود أو أي شخصية أخرى. يُستَخدم عندما يطلب المستخدم إنشاء رسوم متحركة، فيلم قصير، كرتون، فيديو موسيقي، فيديو كلمات، GIF متحرك/حلقة أو "فيديو لكلود…"، أو عندما يذكر نهج PDoomVideo / ClaudeAnimationBase. يغطي تخطيط القصة، واجهة برمجة المحرك، المزامنة مع الموسيقى وكلمات LRC، مراجعة المعاينة الصديقة للسحابة، واختيار التنفيذ المحلي أو السحابي للفيديو النهائي.
