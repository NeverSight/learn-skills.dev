Genere conjuntos de íconos de aplicaciones para Android e iOS a partir de una imagen fuente con un script Pillow incluido. Úselo cuando Codex necesite crear íconos de inicio de aplicaciones móviles, activos AppIcon.appiconset de iOS, íconos de mapa MIP de Android, archivos XML de primer plano/fondo/iconos adaptables, tamaños cuadrados adicionales o exportaciones de íconos de esquinas redondeadas desde un logotipo o archivo de arte.
