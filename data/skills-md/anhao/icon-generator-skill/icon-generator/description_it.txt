Genera set di icone di app Android e iOS da un'immagine sorgente con uno script Pillow in bundle. Da utilizzare quando Codex deve creare icone di avvio di app mobili, risorse AppIcon.appiconset per iOS, icone mipmap Android, file XML in primo piano/sfondo di icone adattive, dimensioni extra quadrate o esportazioni di icone con angoli arrotondati da un logo o un file di grafica.
