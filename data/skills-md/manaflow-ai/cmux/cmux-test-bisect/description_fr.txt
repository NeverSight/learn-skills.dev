Trouvez quand et pourquoi les tests ont échoué sur main : effectuez un bisect d’une suite de paquets Swift sur le CI à travers d’anciens commits, lisez la matrice d’échecs et décidez pour chaque test si le test est devenu obsolète ou si le code a régressé. Utilisez cela lorsqu’une suite est rouge sur main, lorsque le CI du PR n’a exécuté que des tests filtrés et que la suite complète a dérivé, ou lorsqu’on vous demande quel PR a cassé un test.
