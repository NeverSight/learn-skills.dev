Leiten Sie Arbeit von der einfachen „cmux vm“-CLI (alias „cmux cloud“) an cmux-Cloud-Maschinen weiter: Route/Ausführen/Agent wählt eine Maschine, einen „VM-Baum“ und einen „Surface-LS“-Katalog aus. Dieser Mac und die Cloud-Oberflächen sowie Öffnungs-, Ausführungs-, Übertragungs-, Arbeitsbereichs-, Terminal-, Port-, Prüfpunkt- und Domänenvorgänge nutzen dieselben App-Pfade. Verwenden Sie diese Option, wenn ein Agent Builds, Tests, Server, Desktop-/Browseraufgaben oder einen anderen Agenten auf einer Cloud-Maschine ausführen soll oder wenn der Benutzer „Cloud-Maschine“, „Cloud-VM“, „in der Cloud ausführen“, „cmux vm“ oder „cmux-Cloud“ sagt.
