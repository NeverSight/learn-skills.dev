Acheminez le travail vers les machines cmux Cloud à partir de la CLI simple `cmux vm` (alias `cmux cloud`) : route/exécution/agent sélectionne une machine, `vm tree` et `surface ls` catalogue Ces surfaces Mac et cloud, et les opérations d'ouverture, d'exécution, de transfert, d'espace de travail, de terminal, de port, de point de contrôle et de domaine partagent les mêmes chemins d'application. À utiliser lorsqu'un agent doit exécuter des builds, des tests, des serveurs, des tâches de bureau/navigateur ou un autre agent sur une machine cloud, ou lorsque l'utilisateur dit « machine cloud », « VM cloud », « l'exécuter dans le cloud », « cmux vm » ou « cmux cloud ».
