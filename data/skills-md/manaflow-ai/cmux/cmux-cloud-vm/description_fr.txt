Routage du travail vers les machines cloud cmux depuis le simple CLI `cmux vm` (alias `cmux cloud`) : route/run/agent choisissez une machine, `vm tree` et `surface ls` répertorient les surfaces de ce Mac et du cloud, et les opérations open, exec, transfer, workspace, terminal, port, checkpoint et domain partagent les mêmes chemins d’application. Utilisez‑le lorsqu’un agent doit exécuter des builds, des tests, des serveurs, des tâches de bureau/navigateur, ou un autre agent sur une machine cloud, ou lorsque l’utilisateur dit « machine cloud », « VM cloud », « exécuter dans le cloud », « cmux vm » ou « cmux cloud ».
