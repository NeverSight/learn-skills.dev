Habilidad del SDK de Rust para Appwrite. Úsalo al crear aplicaciones Rust del lado del servidor con Appwrite. Cubre la configuración del cliente asíncrono con claves API, gestión de usuarios, operaciones de base de datos/tablas/filas en TablesDB, almacenamiento de archivos, ejecuciones de funciones, permisos, consultas y manejo de errores. Utiliza el paquete `appwrite` de crates.io y Tokio.
