Habilidad de Appwrite Rust SDK. Úselo al crear aplicaciones Rust del lado del servidor con Appwrite. Cubre la configuración asíncrona del cliente con claves API, gestión de usuarios, operaciones de base de datos/tabla/fila de TablesDB, almacenamiento de archivos, ejecuciones de funciones, permisos, consultas y manejo de errores. Utiliza el paquete `appwrite` de crates.io y Tokio.
