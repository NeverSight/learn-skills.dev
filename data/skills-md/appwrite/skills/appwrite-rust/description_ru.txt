Навык Appwrite Rust SDK. Используется при создании серверных приложений на Rust с Appwrite. Охватывает асинхронную настройку клиента с API‑ключами, управление пользователями, операции с базой данных TablesDB (база/таблица/строка), хранение файлов, выполнение функций, права доступа, запросы и обработку ошибок. Использует пакет `appwrite` из crates.io и Tokio.
