Compétence Appwrite Rust SDK. À utiliser lors de la création d'applications Rust côté serveur avec Appwrite. Couvre la configuration du client asynchrone avec les clés API, la gestion des utilisateurs, les opérations de base de données/table/ligne TablesDB, le stockage de fichiers, les exécutions de fonctions, les autorisations, les requêtes et la gestion des erreurs. Utilise le package « appwrite » de cates.io et Tokio.
