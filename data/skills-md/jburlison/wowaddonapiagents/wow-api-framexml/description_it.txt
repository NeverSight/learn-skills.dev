Documentazione completa per le funzioni FrameXML di World of Warcraft — funzioni globali Lua, mixin, pool di oggetti, utility SharedXML e moduli di utilità di gioco. Usa questa per gli helper UI (StaticPopup_Show, EasyMenu), la formattazione (SecondsToTime, FormatLargeNumber), le utility di tabelle/matematica (tContains, Lerp), i pattern mixin/pool, i filtri dei frame di chat, gli helper per i tooltip, le funzioni per gli zaini, la marcatura di texture/atlas e tutti i moduli di utilità di gioco FrameXML.
