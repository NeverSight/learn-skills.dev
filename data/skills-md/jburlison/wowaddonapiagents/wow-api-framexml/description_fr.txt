Documentation complète des fonctions FrameXML de World of Warcraft — fonctions Lua globales, mixins, pools d’objets, utilitaires SharedXML et modules utilitaires du jeu. Utilisez‑le pour les aides UI (StaticPopup_Show, EasyMenu), le formatage (SecondsToTime, FormatLargeNumber), les utilitaires table/math (tContains, Lerp), les modèles mixin/pool, les filtres de cadre de chat, les aides d’infobulles, les fonctions de sac, le balisage texture/atlas, ainsi que tous les modules utilitaires du jeu FrameXML.
