Анализирует существующие агенты, навыки, подсказки и инструкции с целью выявления перекрытий, избыточности и конфликтов. Работает с GitHub Copilot, Claude Code, Codex, OpenCode и другими поставщиками. Используйте перед созданием новых файлов настройки, чтобы избежать дублирования, при консолидации агентов или при устранении конфликтующего поведения.
