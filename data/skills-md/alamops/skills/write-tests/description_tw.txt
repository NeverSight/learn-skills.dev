「(alamops) 為變更撰寫所需的測試——單元測試、整合測試與端對端測試 (e2e)，只要涉及使用者可見的流程或跨越程式流程邊界時皆會執行。當使用者要求撰寫、加入或補足測試時使用——無論是分支相對於主分支的變更、新的 API 端點、測試不足的模組，或是端對端流程——支援任何測試框架（jest、vitest、pytest、Playwright、Cypress…）。可從計畫的測試拆解、分支差異或指定的模組/流程出發；依測試的模組將代理人分割、擴充現有的測試框架與夾具；涵蓋驗收標準、負向路徑與失敗狀態；保持端對端測試的可決定性；將「e2e 不適用」記錄為明確決策；並證明每個新測試都能執行且可能失敗，回報真實的產品缺陷，而非為了通過而彎曲測試。屬於 `implement` 的第 6 階段，可單獨執行；接受 `--no-e2e` 參數。不是用來執行或修復失敗的測試套件 (test‑loop)、在執行中的應用程式上找錯 (break‑fix)，或是開發功能本身 (implement)。」
