(alamops) Effectue une révision approfondie en lecture seule de toute source de modifications — une pull request, un diff git, des changements non commis dans l’arbre de travail, des commits récents sur la branche courante, ou du code qui vient d’être produit ou discuté dans la conversation. Signale les bugs, les problèmes de sécurité (isolement des locataires, lacunes d’autorisation, atomicité, sécurité des nouvelles tentatives, complétude des flux multi‑étapes, récursivité auto‑référentielle des politiques RLS/row‑policy), les problèmes de performances (agrégation en mémoire, diffusion séquentielle, comparaisons de périodes partielles), les problèmes de cohérence (y compris la dérive des références colonnes schéma ↔ code), et les lacunes de rayon d’explosion. Retourne des constats structurés (catégorie, sévérité, fichier, ligne, suggestion) sans modifier le code. Utilisez-le chaque fois que l’utilisateur demande une révision de code, une revue de PR, une revue de diff, un retour sur des changements en attente ou récents, ou une critique du code justé écrit lors de cette session.
