(alamops) Führt eine gründliche, schreibgeschützte Code‑Review für jede Änderungsquelle durch – einen Pull‑Request, einen Git‑Diff, nicht committete Änderungen im Arbeitsbaum, aktuelle Commits im aktuellen Branch oder Code, der gerade erzeugt oder im Gespräch besprochen wurde. Kennzeichnet Bugs, Sicherheitsprobleme (Tenant‑Isolation, Authz‑Lücken, Atomizität, Retry‑Sicherheit, Vollständigkeit mehrstufiger Abläufe, RLS/Zeilenrichtlinien‑Selbstrekursion), Performance‑Probleme (In‑Memory‑Aggregation, sequenzielle Fan‑Out, Teil‑Perioden‑Vergleiche), Konsistenzprobleme (einschließlich Schema‑↔‑Code‑Spaltenreferenz‑Drift) und Blast‑Radius‑Lücken. Gibt strukturierte Befunde zurück (Kategorie, Schweregrad, Datei, Zeile, Vorschlag), ohne Code zu ändern. Verwenden Sie dies immer, wenn der Nutzer um eine Code‑Review, PR‑Review, Diff‑Review, Feedback zu ausstehenden oder kürzlich vorgenommenen Änderungen oder um eine Kritik an gerade in dieser Sitzung geschriebenem Code bittet.
