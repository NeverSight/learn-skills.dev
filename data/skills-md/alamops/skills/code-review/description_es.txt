(alamops) Realiza una revisión de código exhaustiva, de solo lectura, en cualquier origen de cambios: una pull request, un diff de git, ediciones no confirmadas en el árbol de trabajo, commits recientes en la rama actual, o código que acaba de producirse o discutirse en la conversación. Señala errores, problemas de seguridad (aislamiento de inquilinos, brechas de autorización, atomicidad, seguridad en reintentos, completitud de flujos de múltiples pasos, recursión propia de RLS / políticas de fila), problemas de rendimiento (agregación en memoria, fan‑out secuencial, comparaciones de períodos parciales), problemas de consistencia (incluido el desvío entre el esquema y la referencia de columnas en el código) y brechas en el radio de impacto. Devuelve hallazgos estructurados (categoría, gravedad, archivo, línea, sugerencia) sin modificar el código. Utilícelo siempre que el usuario solicite una revisión de código, revisión de PR, revisión de diff, retroalimentación sobre cambios pendientes o recientes, o una crítica del código escrito en esta sesión.
