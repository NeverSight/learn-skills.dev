(alamops) Выполняет тщательный, только‑для‑чтения обзор кода любого источника изменений — pull request, git diff, неподтверждённые правки в рабочем дереве, недавние коммиты в текущей ветке или код, который только что был создан или обсуждён в разговоре. Выявляет баги, проблемы безопасности (изоляция арендаторов, пробелы в авторизации, атомарность, безопасность повторных попыток, полнота многошаговых потоков, рекурсия политик RLS/строк), проблемы производительности (агрегация в памяти, последовательный fan‑out, сравнения частичных периодов), проблемы согласованности (включая дрейф ссылок колонок схемы ↔ кода) и пробелы в радиусе воздействия. Возвращает структурированные выводы (категория, критичность, файл, строка, предложение) без изменения кода. Используйте, когда пользователь просит обзор кода, ревью PR, ревью diff, обратную связь по ожидающим или недавним изменениям или критику кода, написанного в текущей сессии.
