(alamops) 실행 중인 앱에 대한 적대적인 엔드‑투‑엔드 버그 사냥. 실제 앱을 적대적이거나 혼란스럽거나 조급한 사용자처럼 조작한다 — 무의미하고 경계값 입력, 중복 제출, 순서가 뒤섞인 단계, 흐름 중간에 뒤로 가기와 새로 고침, 만료된 세션, 하나의 레코드에 두 탭, 불안정한 네트워크, 변조된 URL 파라미터 — 이를 통해 예외를 발생시키고, 상태를 손상시키며, 데이터를 잃게 하거나 UI를 고립시킨다. 뷰포트만 보는 것이 아니라 콘솔, 네트워크 및 서버 로그도 감시한다. 그런 다음 각 발견을 결정적으로 재현하고, 코드에서 근본 원인을 추적하며, *실패하는* 엔드‑투‑엔드 회귀 테스트를 작성하고, 결함을 수정하여 테스트 스위트가 초록색이 되는 것을 증명한다. 사용자가 “앱을 망가뜨려라”, “부숴봐”, “버그 사냥”, “버그 배시”, “QA 스윕”, “탐색적/적대적/카오스/몽키/퍼즈 테스트”, “실제로 사용하면서 버그 찾기”, “클릭하면서 무엇이 폭발하는지 보기”, 혹은 버그가 다시 나타나지 않도록 엔드‑투‑엔드 테스트를 요구할 때마다 사용한다. 사용자가 제어하는 로컬/개발/스테이징 대상에만 실행한다. 코드 차이 검토(코드 리뷰), 기능 구현(구현), 혹은 Sentry에서 온 프로덕션 오류 트리아징에는 사용하지 않는다.
