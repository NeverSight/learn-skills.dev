(alamops) Используйте, когда пользователь хочет, чтобы его iOS‑приложение проверили на соответствие Руководству по проверке приложений App Store от Apple, или спрашивает, отклонит ли Apple что‑то. Триггеры — «проверьте это по руководству App Store», «отклонит ли Apple это?», предотправочный аудит, готовность к App Store, предполетная проверка перед загрузкой в TestFlight или App Store Connect, «почему Apple постоянно отклоняет моё приложение», соблюдение правил (3.1.1, 4.8, 5.1.1 и т.д.), либо вопрос, разрешено ли конкретное изменение (перевод подписок из IAP в Stripe/внешнюю оплату, добавление SDK аналитики/отслеживания/атрибуции, социальный вход, новое разрешение, манифест конфиденциальности, ATT, удаление аккаунта, IAP/подписки). Работает с любой кодовой базой iOS‑приложения — native Swift/SwiftUI/UIKit/Xcode, React Native, Expo, Flutter, Capacitor/Ionic, Unity. Получает актуальное руководство с developer.apple.com, затем возвращает выводы о риске отклонения, сгруппированные по номеру пункта руководства, с указанием серьёзности, доказательством в виде файл:строка и рекомендациями по исправлению. Только для чтения. Не предназначено для общего обзора багов/производительности и не предназначено для реализации функций.

Пожалуйста, всегда отвечайте на языке пользователя.
