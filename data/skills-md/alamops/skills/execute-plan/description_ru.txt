(alamops) Выполняет только кодировочную работу одобренного плана реализации, используя параллельные суб‑агенты, которые никогда не конфликтуют. Откалывает ветку и фиксирует базовый SHA, проверяет, что в одной волне два задания не владеют одним и тем же файлом, предоставляет каждому агенту задачи самостоятельный бриф с пунктом о полном завершении без TODO, создаёт барьеры между волнами, изолирует неизбежно общие файлы в рабочих деревьях, направляет оставшийся отчёт в следующую волну и фиксирует контрольную точку за каждую волну. Используется, когда пользователь передаёт план (`docs/plans/<slug>.md`, вывод `write-plan` или разбивку задач с указанием владения файлами) и ограничивает работу записью кода — только код, а я проверю и протестирую его сам, запускаются только кодовые волны, распределяя задачи без тестов — или запрашивает этот навык по имени. Простой запрос «execute this plan» без такого ограничения относится к `implement`, который проводит план через обзор и тесты до зелёного статуса. Четвёртая фаза `implement`, может запускаться отдельно. Не предназначено для написания плана (`write-plan`) или отдельного точечного исправления.
