(alamops) 전체 기능을 처음부터 끝까지 구축하고 배포하는 데 쓰이는 기본 스킬 — 단순히 계획하거나 검토하는 것이 아니라. `/implement` 호출에 언제든 적용할 수 있음 — 인자 없이, 작업과 함께, 조합 가능한 수정 플래그(`--auto`는 무인 원격/CI 실행용, `--no-e2e`, `--no-spikes`, `--no-follow-ups`는 소유자가 연기한 나머지까지 차단 — `--no-followups`, `--nofollowups`, `--no-follow-up`, `--no-followup`, `--nofollowup` 등도 허용), 혹은 `--config`/`--update`와 같이 — 그리고 사용자가 평문으로 실제로 기능을 구축·배포·전달하라고 요청할 때마다 — 미지사항을 조사하고, 질문하고, 계획하고, 코딩하고, 검토하고, 초록색이 될 때까지 테스트한다. 전달된 계획이나 PRD를 실행하거나, 여러 백그라운드 에이전트가 병렬로 확장되거나 API, 웹, 모바일 등 여러 표면에 걸쳐 빌드하는 경우에도 같은 스킬을 사용하고, `AGENTS_CONFIG.yml`에 관한 모든 것—단계별 모델 라우팅, 하네스별 라우팅(Claude Code, Codex, Cursor, Gemini CLI, Kimi, Grok) 혹은 현재 스키마로 설정을 마이그레이션하는 경우에도 작업이 없어도 적용한다. 정확한 편집, 단일 코드/diff 검토, 코드 설명, PRD를 티켓으로 변환, git 작업, 혹은 답변이 출력되는 시간 제한 스파이크(코드가 배포되는 것이 아니라)와 같은 경우에는 사용하지 않는다.
