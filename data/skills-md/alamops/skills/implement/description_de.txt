Überspringe sie für eine punktgenaue Bearbeitung, ein einzelnes Code/Diff‑Review, das Erklären von Code, das Umwandeln eines PRD in Tickets, Git‑Aufgaben oder einen zeitlich begrenzten Spike, dessen Ausgabe eine Antwort und kein ausgeliefertes Code‑Produkt ist.
