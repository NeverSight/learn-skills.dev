(alamops) Ejecuta toda la suite de pruebas de un proyecto — unitarias, de integración y e2e — de forma autónoma, y la lleva a estado verde. Úsalo para cualquier solicitud de ejecutar las pruebas o la suite e2e, obtener una suite roja o CI roja verde, o corregir pruebas que fallan, están rotas o son inestables (después de un rebase o una actualización de dependencias), o para aplicar correcciones obligatorias de revisión y volver a ejecutar — incluso un simple "ejecuta las pruebas", y aun cuando sea necesario levantar primero una base de datos u otros servicios. Posee el ciclo de vida e2e por sí mismo — inicia los servicios y la aplicación, espera a que estén realmente listos, ejecuta en modo headless, y desmonta. Reporta paso/fallo por capa; ante fallos vuelve a ejecutar e2e una vez para separar flacos de defectos, decide si el problema está en el producto o en la prueba, corrige cada cluster de causa raíz con agentes independientes de archivos y vuelve a ejecutar todo, hasta tres rondas. Nunca alcanza el estado verde omitiendo, borrando o aflojando pruebas. Fases 7‑8 de `implement`, ejecutable de forma aislada; acepta `--no-e2e`. No está destinado a escribir nueva cobertura (write-tests), caza exploratoria de bugs (break-fix) ni incidentes de producción.
