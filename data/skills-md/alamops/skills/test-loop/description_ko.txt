(alamops) 프로젝트 전체 테스트 스위트—유닛, 통합, e2e—를 스스로 실행하고, 이를 녹색 상태로 만들며 구동합니다. 테스트 실행 요청, e2e 스위트 실행, 레드 스위트 또는 레드 CI를 그린으로 전환, 재베이스나 의존성 업데이트 후 실패하거나 깨지거나 불안정한 테스트 수정, 리뷰에서 반드시 고쳐야 할 사항 적용 후 재실행—심지어 "테스트 실행" 하나만으로도, 데이터베이스나 기타 서비스가 먼저 시작되어야 할 경우에도 사용할 수 있습니다. e2e 라이프사이클을 직접 관리해 서비스와 앱을 시작하고 실제 준비가 될 때까지 기다린 뒤 헤드리스로 실행하고 정리합니다. 레이어별 통과/실패를 보고하고, 실패 시 플래크와 결함을 구분하기 위해 e2e를 한 번 재실행하며, 제품 문제인지 테스트 문제인지 판단하고 파일이 겹치지 않는 에이전트로 각 원인 클러스터를 수정한 뒤 모든 테스트를 최대 세 번까지 재실행합니다. 테스트를 건너뛰거나 삭제하거나 완화하여 녹색 상태에 도달하지 않습니다. `implement` 단계의 7–8 단계에 해당하며, 단독 실행이 가능하고 `--no-e2e` 옵션을 받습니다. 새로운 커버리지를 작성( write-tests ), 탐색적 버그 사냥( break-fix ), 혹은 운영 사고 대응에는 사용하지 않습니다.
