Паттерн для обёртывания клиентских SDK сторонних сервисов (Stripe, Resend, AWS и т.д.) с помощью Effect. Используется при создании сервисов Effect, которые оборачивают внешние библиотеки с API на основе Promise. Обеспечивает типобезопасную обработку ошибок, автоматическое трассирование и чистую инъекцию зависимостей через паттерн «use».
