مراجعة الأمان وإرشادات الترميز الآمن لتطبيقات NestJS الإصدارات 10.x و11.x و12.x التي تعمل على محول Express أو Fastify. يُستخدم عند إجراء تدقيق، أو مراجعة، أو التحضير لاختبار الاختراق، أو تعزيز أمان خلفية NestJS أو واجهة برمجة التطبيقات، أو عند كتابة أو تعديل المتحكمات (controllers) أو الحراس (guards) أو الأنابيب (pipes) أو كائنات نقل البيانات (DTOs) أو الوحدات (modules) أو عمليات المصادقة أو معالجة JWT أو محللات GraphQL أو بوابات WebSocket أو معالجات الخدمات المصغرة أو عمليات الرفع أو تكوين main.ts. ينشط في المشاريع التي يعتمد ملف package.json الخاص بها على @nestjs/core أو @nestjs/common، أو التي تحتوي على nest‑cli.json أو main.ts مع NestFactory.create، أو ملفات *.module.ts و*.controller.ts. يغطي ترتيب الحراس ووسيطات الطلب (middleware)، أنماط الفشل المفتوح @Public، قائمة السماح في ValidationPipe وتعيين الكتلة الجماعية، كشف البيانات عبر class‑transformer، Passport وJWT، IDOR وCASL، مُقنن السرعة (throttler)، CORS، CSRF، Helmet، تفويض حقول GraphQL وتفحصها، مصادقة البوابة ونقل TCP، حقن ORM، multer وFileTypeValidator، SSRF، كشف Swagger، استشارات NestJS، والتحقق عبر supertest.
