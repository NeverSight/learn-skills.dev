针对在 Express 或 Fastify 适配器上运行的 NestJS 10.x、11.x 与 12.x 应用的安全审查与安全编码指南。适用于审计、评审、渗透测试准备或强化 NestJS 后端或 API，亦适用于编写或修改其控制器、守卫、管道、DTO、模块、认证、JWT 处理、GraphQL 解析器、WebSocket 网关、微服务处理器、文件上传或 main.ts 配置时。触发条件为项目的 package.json 依赖 @nestjs/core 或 @nestjs/common，或包含 nest-cli.json、使用 NestFactory.create 的 main.ts，或存在 *.module.ts 与 *.controller.ts 文件。内容覆盖守卫与中间件的执行顺序、@Public 失效打开（fail‑open）模式、ValidationPipe 的白名单与批量赋值、class‑transformer 的数据暴露、Passport 与 JWT、IDOR 与 CASL、速率限制器、CORS、CSRF、helmet、GraphQL 字段授权与自省、网关与 TCP 传输的认证、ORM 注入、multer 与 FileTypeValidator、SSRF、Swagger 暴露、NestJS 安全公告以及 supertest 验证。
