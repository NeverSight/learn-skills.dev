Express または Fastify アダプタ上の NestJS 10.x、11.x、12.x アプリケーション向けのセキュリティレビューと安全なコーディングガイドライン。NestJS バックエンドや API の監査、レビュー、ペンテスト準備、堅牢化、あるいはコントローラ、ガード、パイプ、DTO、モジュール、認証、JWT ハンドリング、GraphQL リゾルバ、WebSocket ゲートウェイ、マイクロサービスハンドラ、アップロード、main.ts 設定の作成・変更時に使用します。プロジェクトの package.json が @nestjs/core または @nestjs/common に依存している、あるいは nest‑cli.json、NestFactory.create を含む main.ts、*.module.ts、*.controller.ts ファイルが存在する場合にトリガーされます。ガードとミドルウェアの順序、@Public のフェイルオープンパターン、ValidationPipe のホワイトリストと大量代入、class‑transformer のデータ露出、Passport と JWT、IDOR と CASL、スロットラー、CORS、CSRF、helmet、GraphQL フィールド認可とイントロスペクション、ゲートウェイおよび TCP トランスポートの認証、ORM インジェクション、multer と FileTypeValidator、SSRF、Swagger の公開、NestJS アドバイザリ、そして supertest の検証についてカバーしています。
