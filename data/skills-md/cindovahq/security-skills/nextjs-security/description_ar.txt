مراجعة الأمان وإرشادات الترميز الآمن لتطبيقات Next.js (موجه التطبيق وموجه الصفحات، Next.js إصدارات 14.x إلى 16.x). يُستخدم عند تدقيق أو تعزيز قاعدة شفرة Next.js، أو عند كتابة أو تعديل إجراءات الخادم (Server Actions)، ومعالجات المسارات (Route Handlers)، ومسارات API للصفحات، أو ملف middleware.ts أو proxy.ts، ومكونات الخادم والعميل، والتخزين المؤقت (fetch cache، use cache، unstable_cache، ISR)، وإعدادات next.config، ومتغيرات البيئة، وإعدادات الصور، أو تكامل Auth.js أو Clerk أو Supabase للمصادقة. يتم تفعيل الفحص عند وجود next في package.json، أو ملف next.config.js/mjs/ts، أو أدلة app/ أو pages/، أو middleware.ts/proxy.ts. يغطي التفويض في إجراءات الخادم وIDOR، وتجاوز middleware وproxy (CVE-2025-29927)، وتنبيهات مكونات الخادم في React (React2Shell، CVE-2025-55182)، وتسرب البيانات إلى مكونات العميل، وكشف أسرار NEXT_PUBLIC_، وتسرب التخزين المؤقت بين المستخدمين، وCSRF وCORS، وXSS (dangerouslySetInnerHTML، Markdown، JSON داخل وسوم script)، وSSRF ومُحسّن الصور، وإعادة التوجيه المفتوح، ورؤوس الأمان وCSP، وضع المسودة، والاعتمادات، والتحقق من الإصلاح.
