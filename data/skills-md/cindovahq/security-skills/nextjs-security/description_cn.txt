针对 Next.js 应用（App Router 与 Pages Router，Next.js 14.x 到 16.x）的安全审查和安全编码指南。适用于审计或加固 Next.js 代码库，或在编写或修改 Server Actions、Route Handlers、Pages API 路由、middleware.ts 或 proxy.ts、服务器与客户端组件、缓存（fetch cache、use cache、unstable_cache、ISR）、next.config、环境变量、图像配置，或 Auth.js、Clerk、Supabase 身份验证集成时使用。触发条件为 package.json 中的 next、next.config.js/mjs/ts 文件、app/ 或 pages/ 目录，或 middleware.ts/proxy.ts。涵盖 Server Action 授权与 IDOR、middleware 与 proxy 绕过（CVE-2025-29927）、React Server Components 警告（React2Shell、CVE-2025-55182）、数据泄露到 Client Components、NEXT_PUBLIC_ 机密暴露、跨用户缓存泄漏、CSRF 与 CORS、XSS（dangerouslySetInnerHTML、Markdown、脚本标签中的 JSON）、SSRF 与图像优化器、开放重定向、安全头部与 CSP、草稿模式、依赖项以及修复验证。
