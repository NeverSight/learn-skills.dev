Next.js 애플리케이션(App Router 및 Pages Router, Next.js 14.x~16.x)을 위한 보안 검토 및 안전한 코딩 가이드입니다. Next.js 코드베이스를 감사하거나 강화할 때, 혹은 Server Actions, Route Handlers, Pages API 라우트, middleware.ts 또는 proxy.ts, 서버 및 클라이언트 컴포넌트, 캐시(fetch cache, use cache, unstable_cache, ISR), next.config, 환경 변수, 이미지 설정, Auth.js, Clerk 또는 Supabase 인증 통합을 작성하거나 변경할 때 사용하십시오. package.json의 next, next.config.js/mjs/ts 파일, app/ 또는 pages/ 디렉터리, middleware.ts/proxy.ts에서 트리거됩니다. Server Action 권한 부여 및 IDOR, 미들웨어 및 프록시 우회(CVE-2025-29927), React Server Components 권고(Rreact2Shell, CVE-2025-55182), 데이터가 클라이언트 컴포넌트로 유출, NEXT_PUBLIC_ 비밀 노출, 사용자 간 캐시 누수, CSRF 및 CORS, XSS( dangerouslySetInnerHTML, Markdown, 스크립트 태그 내 JSON), SSRF와 이미지 옵티마이저, 오픈 리다이렉트, 보안 헤더 및 CSP, 드래프트 모드, 의존성 및 수정 검증 등을 다룹니다.
