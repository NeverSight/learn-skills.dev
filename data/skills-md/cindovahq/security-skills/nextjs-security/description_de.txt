Sicherheitsüberprüfung und Leitfaden für sicheres Codieren von Next.js-Anwendungen (App Router und Pages Router, Next.js 14.x bis 16.x). Verwendung beim Auditing oder Härten einer Next.js‑Codebasis oder beim Schreiben bzw. Ändern von Server Actions, Route Handlers, Pages‑API‑Routen, middleware.ts oder proxy.ts, Server‑ und Client‑Komponenten, Caching (fetch‑Cache, use‑cache, unstable_cache, ISR), next.config, Umgebungsvariablen, Bildkonfiguration oder Auth.js‑, Clerk‑ oder Supabase‑Auth‑Integration. Wird ausgelöst bei „next“ in package.json, einer next.config.js/mjs/ts‑Datei, den Verzeichnissen app/ oder pages/ oder middleware.ts/proxy.ts. Behandelt Server‑Action‑Autorisierung und IDOR, Middleware‑ und Proxy‑Umgehung (CVE‑2025‑29927), React Server Components‑Hinweise (React2Shell, CVE‑2025‑55182), Datenlecks zu Client‑Komponenten, NEXT_PUBLIC_‑Geheimnis‑Exposition, Cache‑Lecks zwischen Benutzer*innen, CSRF und CORS, XSS (dangerouslySetInnerHTML, Markdown, JSON in Script‑Tags), SSRF und den Bild‑Optimizer, offene Weiterleitungen, Sicherheits‑Header und CSP, Draft‑Modus, Abhängigkeiten sowie die Verifizierung von Fixes.
