Next.js アプリケーション（App Router と Pages Router、Next.js 14.x から 16.x）向けのセキュリティレビューと安全なコーディングガイドライン。Next.js のコードベースを監査・強化する際、または Server Actions、Route Handlers、Pages API ルート、middleware.ts や proxy.ts、サーバーコンポーネント・クライアントコンポーネント、キャッシュ（fetch cache、use cache、unstable_cache、ISR）、next.config、環境変数、画像設定、Auth.js、Clerk、Supabase 認証統合を作成・変更する際に使用します。package.json の `next`、next.config.js/mjs/ts ファイル、app/ または pages/ ディレクトリ、middleware.ts／proxy.ts がトリガーになります。Server Action の認可と IDOR、ミドルウェア・プロキシのバイパス（CVE-2025-29927）、React Server Components の勧告（React2Shell、CVE-2025-55182）、クライアントコンポーネントへのデータ漏洩、NEXT_PUBLIC_ シークレットの露出、ユーザー間キャッシュ漏洩、CSRF と CORS、XSS（dangerouslySetInnerHTML、Markdown、スクリプトタグ内の JSON）、SSRF と画像最適化、オープンリダイレクト、セキュリティヘッダーと CSP、ドラフトモード、依存関係、修正検証 を網羅しています。
