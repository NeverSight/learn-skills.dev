Обзор безопасности и рекомендации по безопасному программированию для приложений Next.js (App Router и Pages Router, Next.js 14.x – 16.x). Использовать при аудите или укреплении кодовой базы Next.js, а также при написании или изменении Server Actions, Route Handlers, API‑маршрутов страниц, middleware.ts или proxy.ts, серверных и клиентских компонентов, кэширования (fetch cache, use cache, unstable_cache, ISR), next.config, переменных окружения, конфигурации изображений, или интеграции Auth.js, Clerk или Supabase Auth. Срабатывает при наличии next в package.json, файла next.config.js/mjs/ts, каталогов app/ или pages/, либо middleware.ts/proxy.ts. Охватывает авторизацию Server Action и IDOR, обход middleware и proxy (CVE‑2025‑29927), рекомендации по React Server Components (React2Shell, CVE‑2025‑55182), утечки данных в клиентские компоненты, раскрытие секретов NEXT_PUBLIC_, кросс‑пользовательские утечки кэша, CSRF и CORS, XSS (dangerouslySetInnerHTML, Markdown, JSON в тегах script), SSRF и оптимизатор изображений, открытые редиректы, заголовки безопасности и CSP, режим черновика, зависимости и проверку исправлений.
