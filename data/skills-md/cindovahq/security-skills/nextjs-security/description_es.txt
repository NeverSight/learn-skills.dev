Revisión de seguridad y guía de codificación segura para aplicaciones Next.js (App Router y Pages Router, Next.js 14.x a 16.x). Úsese al auditar o reforzar una base de código Next.js, o al escribir o modificar Server Actions, Route Handlers, rutas API de Pages, middleware.ts o proxy.ts, componentes Server y Client, caché (fetch cache, use cache, unstable_cache, ISR), next.config, variables de entorno, configuración de imágenes, o integración de autenticación con Auth.js, Clerk o Supabase. Se dispara con la presencia de next en package.json, un archivo next.config.js/mjs/ts, los directorios app/ o pages/, o middleware.ts/proxy.ts. Cubre autorización de Server Actions e IDOR, eludir middleware y proxy (CVE-2025-29927), avisos de React Server Components (React2Shell, CVE-2025-55182), filtración de datos a Componentes Client, exposición de secretos NEXT_PUBLIC_, fugas de caché entre usuarios, CSRF y CORS, XSS (dangerouslySetInnerHTML, Markdown, JSON en etiquetas script), SSRF y el optimizador de imágenes, redirecciones abiertas, encabezados de seguridad y CSP, modo borrador, dependencias y verificación de correcciones.
