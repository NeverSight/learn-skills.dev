Next.js 應用程式（App Router 與 Pages Router，Next.js 14.x 至 16.x）的安全審查與安全程式編寫指引。於審計或加固 Next.js 程式碼庫，或在編寫或變更 Server Actions、Route Handlers、Pages API 路由、middleware.ts 或 proxy.ts、Server 與 Client Component、快取（fetch cache、use cache、unstable_cache、ISR）、next.config、環境變數、圖片設定，或 Auth.js、Clerk 或 Supabase 認證整合時使用。觸發條件包括 package.json 中的 next、next.config.js/mjs/ts 檔案、app/ 或 pages/ 目錄，或 middleware.ts/proxy.ts。涵蓋 Server Action 授權與 IDOR、middleware 與 proxy 繞過（CVE-2025-29927）、React Server Components 警示（React2Shell、CVE-2025-55182）、資料洩漏至 Client Component、NEXT_PUBLIC_ 密鑰曝光、跨使用者快取洩漏、CSRF 與 CORS、XSS（dangerouslySetInnerHTML、Markdown、script 標籤內的 JSON）、SSRF 與圖片最佳化器、開放式重定向、安全標頭與 CSP、草稿模式、相依套件，以及修正驗證。
