Examen de sécurité et guide de codage sécurisé pour les applications Next.js (App Router et Pages Router, Next.js 14.x à 16.x). À utiliser lors de l’audit ou du renforcement d’une base de code Next.js, ou lors de l’écriture ou de la modification d’Actions Serveur, de Gestionnaires de Routes, de routes API Pages, de middleware.ts ou proxy.ts, de Composants Serveur et Client, de la mise en cache (fetch cache, use cache, unstable_cache, ISR), de next.config, des variables d’environnement, de la configuration des images, ou de l’intégration Auth.js, Clerk ou Supabase Auth. S’active sur « next » dans le package.json, un fichier next.config.js/mjs/ts, les répertoires app/ ou pages/, ou middleware.ts/proxy.ts. Couvre l’autorisation des Actions Serveur et les IDOR, le contournement du middleware et du proxy (CVE‑2025‑29927), les avis sur les React Server Components (React2Shell, CVE‑2025‑55182), les fuites de données vers les Composants Client, l’exposition des secrets NEXT_PUBLIC_, les fuites de cache inter‑utilisateurs, CSRF et CORS, XSS (dangerouslySetInnerHTML, Markdown, JSON dans les balises script), SSRF et l’optimiseur d’images, les redirections ouvertes, les en‑têtes de sécurité et CSP, le mode draft, les dépendances, et la vérification des correctifs.
