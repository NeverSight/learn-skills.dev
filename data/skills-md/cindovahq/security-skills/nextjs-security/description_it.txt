Revisione della sicurezza e linee guida per il coding sicuro per le applicazioni Next.js (App Router e Pages Router, Next.js 14.x‑16.x). Da utilizzare durante la verifica o il rafforzamento di un codebase Next.js, o durante la scrittura o la modifica di Server Actions, Route Handlers, rotte API di Pages, middleware.ts o proxy.ts, componenti Server e Client, caching (fetch cache, use cache, unstable_cache, ISR), next.config, variabili d’ambiente, configurazione delle immagini, o integrazioni Auth.js, Clerk o Supabase auth. Si attiva su next in package.json, su un file next.config.js/mjs/ts, nelle directory app/ o pages/, oppure su middleware.ts/proxy.ts. Copre l’autorizzazione delle Server Action e IDOR, bypass di middleware e proxy (CVE‑2025‑29927), avvisi sui React Server Components (React2Shell, CVE‑2025‑55182), perdita di dati verso i Componenti Client, esposizione di segreti NEXT_PUBLIC_, perdite di cache tra utenti, CSRF e CORS, XSS (dangerouslySetInnerHTML, Markdown, JSON nei tag script), SSRF e l’ottimizzatore di immagini, redirect aperti, intestazioni di sicurezza e CSP, modalità draft, dipendenze e verifica delle correzioni.
