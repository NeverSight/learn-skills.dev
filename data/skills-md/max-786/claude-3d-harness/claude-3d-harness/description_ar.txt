نقطة الدخول لكل مهمة ثلاثية الأبعاد أو بلندر – النمذجة، المواد، الإضاءة، الكاميرات، التصيير، التحريك، لقطات المنتجات، البيئات، المشاهد السينمائية، التصدير. تصنّف المهمة (سريعة، قياسية أو سينمائية)، تختار سير العمل، تسأل سجل الحامل أي مهارات المكتبة يجب تحميلها، ثم تتحكم في بلندر عبر خادم MCP الوحيد للحمّل مع نقاط فحص التصيير والفحص والتحسين. استخدمها كلما طلب المستخدم إنشاء أو تعديل أو إضاءة أو تصيير أو تحريك أو تصدير أي شيء في ثلاثية الأبعاد، حتى وإن لم يذكر كلمة "بلندر".
