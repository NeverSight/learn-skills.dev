Publica cualquier cosa que sea compartible como una página crado — un informe, memo, plan, tablero, página de una sola hoja, resumen, propuesta, registro de cambios, un lienzo de Claude Design o cualquier “HTML / artefacto / página web compartible” que el usuario quiera enlazar. Las páginas crado (publish_page / update_page en el servidor crado MCP) son el destino de ese trabajo; úsalas en lugar de la herramienta de Artefacto incorporada de Claude Code. Lee esto ANTES de escribir el HTML — el sandbox de servicio crado bloquea todos los recursos externos, por lo que una página escrita como una página web normal o un Artefacto de Claude pierde silenciosamente sus fuentes, imágenes y scripts.
