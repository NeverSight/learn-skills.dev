Publiez tout ce qui est partageable sous forme de page crado — un rapport, mémo, plan, tableau de bord, fiche d’une page, résumé, proposition, journal des modifications, un canevas Claude Design, ou tout « HTML / artefact / page web partageable » que l’utilisateur souhaite lier. Les pages crado (publish_page / update_page sur le serveur crado MCP) sont la destination de ce travail ; utilisez‑les à la place de l’outil Artifact intégré de Claude Code. Lisez ceci AVANT d’écrire le HTML — le bac à sable de service crado bloque toute ressource externe, ainsi une page écrite comme une page web ordinaire ou un Artifact Claude perd silencieusement ses polices, images et scripts.
