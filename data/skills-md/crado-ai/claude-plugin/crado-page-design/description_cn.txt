将任何可分享的内容发布为 crado 页面——报告、备忘录、计划、仪表盘、单页、摘要、提案、变更日志、Claude Design 画布，或用户希望获取链接的任何“可分享的 HTML / 工件 / 网页”。crado 页面（通过 crado MCP 服务器的 publish_page / update_page）是这些工作的目标；请使用它们，而不是 Claude Code 内置的 Artifact 工具。在编写 HTML 之前请先阅读此内容——crado 的服务沙箱会阻止所有外部资源，因此像普通网页或 Claude Artifact 那样编写的页面会悄悄失去字体、图像和脚本。

请始终使用用户的语言作答。
