Pubblica qualsiasi contenuto condivisibile come una pagina crado — un rapporto, un memo, un piano, un dashboard, una pagina singola, un riassunto, una proposta, un changelog, una canvas Claude Design o qualsiasi “HTML / artefatto / pagina web condivisibile” a cui l'utente desideri fornire un link. Le pagine crado (publish_page / update_page tramite il server crado MCP) sono la destinazione di quel lavoro; usale invece dello strumento Artifact integrato in Claude Code. Leggi questo PRIMA di scrivere l'HTML — il sandbox di erogazione crado blocca ogni risorsa esterna, quindi una pagina scritta come una normale pagina web o un Artifact di Claude perde silenziosamente i caratteri, le immagini e gli script.

Per favore rispondi sempre nella lingua dell'utente.
