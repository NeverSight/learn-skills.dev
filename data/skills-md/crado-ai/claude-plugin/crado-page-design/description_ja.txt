共有可能なものは何でも crado ページとして公開してください—レポート、メモ、プラン、ダッシュボード、ワンページ、サマリー、提案書、変更ログ、Claude Design キャンバス、またはユーザーがリンクを欲しがる「共有可能な HTML / アーティファクト / Web ページ」などです。crado ページ（crado MCP サーバー上の publish_page / update_page）はその作業の宛先です；Claude Code の組み込み Artifact ツールの代わりにそれらを使用してください。HTML を書く前に必ずこれを読んでください—crado のサービングサンドボックスはすべての外部リソースをブロックするため、通常の Web ページや Claude Artifact のように書かれたページはフォント、画像、スクリプトが静かに失われます。

必ずユーザーの言語で返信してください。
