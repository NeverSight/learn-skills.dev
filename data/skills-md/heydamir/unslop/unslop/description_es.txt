Convierte una UI con aspecto de IA y vibecodificada en una interfaz diseñada con su propio carácter. Encuentra una dirección a partir del propio producto, luego corrige el espaciado, el color, los íconos, el texto, la tipografía, el diseño, los detalles, los elementos visuales y el movimiento en ese orden, y puede generar un visual principal real con una herramienta de imágenes cuando está disponible. Úsalo cuando el usuario pida desenredar, pulir, limpiar o rediseñar una pantalla para que deje de parecer generada por IA, o cuando una UI muestre los indicadores habituales como degradados púrpuras, brillos, texto degradado, etiquetas con emojis, insignias de “Nuevo ✨”, manchas brillantes, etiquetas en mayúsculas con espaciado amplio, elementos pulsantes o espaciado irregular. Funciona con React, Tailwind, HTML y CSS, para tableros, aplicaciones y páginas de destino.
