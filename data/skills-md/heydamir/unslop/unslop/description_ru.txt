Трансформирует виброкодированный, «искусственный» UI в продуманный интерфейс с собственным характером. Находит направление от самого продукта, затем последовательно исправляет отступы, цвета, иконки, тексты, шрифты, макет, детали, визуалы и анимацию, а при наличии инструмента для изображений может сгенерировать реальный главный визуал. Используйте, когда пользователь просит «расшить», полировать, очистить или переработать экран, чтобы он перестал выглядеть сгенерированным ИИ, или когда UI содержит типичные признаки: пурпурные градиенты, свечения, градиентный текст, эмодзи‑метки, бейджики «Новый ✨», блестящие «блобзы», заглавные буквы с межбуквенным интервалом, пульсирующие элементы или неравномерные отступы. Работает с React, Tailwind, HTML и CSS для панелей управления, приложений и лендингов.
