جهّز حزمة تكرار جاهزة للتقديم وفقًا لمتطلبات معيار توفر البيانات والشفرة للاتحاد الاقتصادي الأمريكي (DCAS) / openICPSR / منصة إعادة إنتاج العلوم الاجتماعية — ملف README قياسي للتكرار، بيان مجموعة البيانات، توثيق المتطلبات الحاسوبية، خريطة تربط الجدول/الرسوم البيانية بالسكريبت:السطر، وخطة إيداع للبيانات السرية. استخدم ذلك عندما يقول المستخدم "بناء حزمة التكرار"، "تحضير إيداع openICPSR"، "إنشاء حزمة بيانات وشفرة AEA"، "امتثال DCAS"، "تجميع الإيداع للمجلة"، أو بعد قبول ورقة علمية ويحتاج محرر بيانات المجلة إلى الحزمة. ليس مُتحققًا رقميًا — فهو يستدعي /audit-reproducibility لتأكيد أن الادعاءات تُعاد إنتاجها قبل التجميع.
