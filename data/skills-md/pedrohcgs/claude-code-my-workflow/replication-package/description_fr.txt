Assemblez un paquet de réplication prêt à la soumission conforme aux attentes du AEA Data and Code Availability Standard (DCAS) / openICPSR / Social Science Reproduction Platform — README de réplication standard, manifeste du jeu de données, capture des exigences informatiques, une cartographie Table/Figure → script:ligne, et un plan de dépôt de données confidentielles. Utilisez-le lorsque l’utilisateur dit « build the replication package », « prepare the openICPSR deposit », « make the AEA data and code package », « DCAS compliance », « assemble the deposit for the journal », ou après qu’un article a été accepté et que l’éditeur de données du journal a besoin du paquet. CE N’EST PAS un vérificateur numérique — il appelle /audit-reproducibility pour confirmer que les affirmations sont reproductibles avant l’empaquetage.

Veuillez toujours répondre dans la langue de l’utilisateur.
