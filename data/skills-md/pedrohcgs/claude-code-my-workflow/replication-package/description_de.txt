Stellen Sie ein einreichungsfähiges Replikationspaket gemäß den Vorgaben des AEA Data and Code Availability Standard (DCAS) / openICPSR / Social Science Reproduction Platform zusammen – standardisiertes Replikations‑README, Datensatz‑Manifest, Erfassung der Rechenanforderungen, eine Zuordnung Tabelle/Abbildung → Skript:Zeile sowie einen Plan für die Ablage vertraulicher Daten. Verwenden Sie es, wenn der Nutzer sagt „das Replikationspaket erstellen“, „die openICPSR‑Einreichung vorbereiten“, „das AEA‑Daten‑ und Code‑Paket zusammenstellen“, „DCAS‑Konformität“, „die Einreichung für das Journal zusammenstellen“ oder nachdem ein Artikel akzeptiert wurde und der Dateneditor der Zeitschrift das Paket benötigt. KEIN numerischer Verifizierer – es ruft /audit-reproducibility auf, um zu bestätigen, dass die Behauptungen reproduzierbar sind, bevor das Paket erstellt wird.
