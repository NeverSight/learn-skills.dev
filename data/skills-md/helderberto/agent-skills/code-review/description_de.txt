Überprüfen Sie einen GitHub Pull Request auf Fehler, Sicherheit, Leistung und Codequalität. Verwenden Sie diese Option, wenn der Benutzer um die Überprüfung einer PR bittet oder Feedback zu einer Pull-Anfrage wünscht. Nicht zum Überprüfen lokaler, nicht festgeschriebener Änderungen, zum Erstellen neuer PRs oder zum Zusammenführen von Zweigen verwenden.
