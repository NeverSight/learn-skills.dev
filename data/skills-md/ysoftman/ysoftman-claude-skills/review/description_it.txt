Rivedi le PR di GitHub e traccia i miglioramenti come attività. Usalo quando l'utente chiede di rivedere una PR, controllare una pull request, dice “PR 리뷰해줘”, “PR 봐줘”, o fornisce un URL o un numero di PR di GitHub. Delega sia il giudizio della revisione sia la scrittura dei commenti all'agente `reviewer` (eseguito in background).

Per favore rispondi sempre nella lingua dell'utente.
