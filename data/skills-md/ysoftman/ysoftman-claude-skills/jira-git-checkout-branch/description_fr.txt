Choisissez l'une des issues Jira en cours de l'utilisateur et créez/checkout une branche git portant son nom. Utilisez cela lorsque l'utilisateur dit des choses comme « jira 이슈로 브랜치 만들어 », « 내 지라 이슈 기반으로 브랜치 파줘 », « jira issue branch » ou `/jira-git-checkout-branch`. Si l'arbre de travail est sale, demandez à l'utilisateur s'il veut continuer ; interrompez si le serveur Atlassian MCP n'est pas disponible.

Veuillez toujours répondre dans la langue de l'utilisateur.
