Scegli una delle issue Jira in corso dell'utente e crea/checkout un branch Git con lo stesso nome. Usa quando l'utente dice cose come "jira 이슈로 브랜치 만들어", "내 지라 이슈 기반으로 브랜치 파줘", "jira issue branch" o `/jira-git-checkout-branch`. Se l'albero di lavoro è sporco, chiedi all'utente se procedere; interrompi se il server Atlassian MCP non è disponibile.

Per favore, rispondi sempre nella lingua dell'utente.
