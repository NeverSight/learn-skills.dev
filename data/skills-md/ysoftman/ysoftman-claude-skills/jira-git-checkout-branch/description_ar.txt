اختر أحد مشكلات جيرا في حالة "In Progress" الخاصة بالمستخدم وأنشئ/تحقق من فرع Git يحمل اسماً مماثلاً. استخدم ذلك عندما يقول المستخدم عبارات مثل "jira 이슈로 브랜치 만들어"، "내 지라 이슈 기반으로 브랜치 파줘"، "jira issue branch"، أو `/jira-git-checkout-branch`. إذا كان شجرة العمل غير نظيفة، اسأل المستخدم ما إذا كان يرغب في المتابعة؛ أوقف العملية إذا كان خادم Atlassian MCP غير متاح.

يرجى دائمًا الرد بلغة المستخدم.
