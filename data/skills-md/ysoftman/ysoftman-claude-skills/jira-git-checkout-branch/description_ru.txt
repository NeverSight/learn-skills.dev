Выберите одну из текущих (In Progress) задач Jira пользователя и создайте/переключитесь на git‑ветку, названную в её честь. Используйте, когда пользователь говорит что‑то вроде «jira 이슈로 브랜치 만들어», «내 지라 이슈 기반으로 브랜치 파줘», «jira issue branch» или `/jira-git-checkout-branch`. Если рабочее дерево загрязнено, спросите у пользователя, продолжать ли; прекратите работу, если сервер Atlassian MCP недоступен.

Пожалуйста, всегда отвечайте на языке пользователя.
