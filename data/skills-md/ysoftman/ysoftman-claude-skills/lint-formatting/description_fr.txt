Lancez les linters spécifiques aux langages, les formatteurs et les vérifications de typage statique avec une référence complète des commandes. Utilisez cela lorsque l'utilisateur demande de lint, de formater, de vérifier le typage, de vérifier le style, ou dit « 린트 », « 포맷 », « 타입 체크 », « lint », « format », « type check », « biome », « ruff », « pyright », « clippy », « golangci-lint », « gopls », « rumdl », « prettier », « shfmt ». Utilisez également lorsque des variantes détaillées de commandes (vérification‑only, correction‑only, portée partielle) sont nécessaires au‑delà de la commande standard de correction totale.

Veuillez toujours répondre dans la langue de l'utilisateur.
