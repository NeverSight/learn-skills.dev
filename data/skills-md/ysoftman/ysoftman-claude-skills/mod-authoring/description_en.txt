Practical guide for using the built‑in `plugin-authoring` skill when creating or fixing a Claude Code mod (function‑hook plugin — pane/panel, band above the prompt, shortcut chip, slash command). Covers displaying and switching panel tabs, `keybindings.json` `command:` shortcuts and their hints (the hint‑line tail below the prompt), how multiple mods can share a band/hint line, test‑kit tips, and checking the load path when changes are not applied. When the user mentions creating a mod or mode, panel, pane, band, a single line above the prompt, hint line, PromptHint, shortcut chip, tab switching, “reload‑plugins but nothing changed”, `ysoftman-claude-kit/plugins`, `dev-mods`, `register.tsx`, `ui.render`, `$.ui.open`, etc., they must be used together with plugin‑authoring.
