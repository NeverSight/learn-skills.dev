Claude Code モッド（function‑hook プラグイン — ペイン/パネル、プロンプト上部のバンド、ショートカットチップ、スラッシュコマンド）実践ガイド。組み込みの `plugin-authoring` スキルと併用してモッドを作成または修正する際の手順を示します。パネルタブの表示と切り替え、`keybindings.json` の `command:` ショートカットとそのガイダンス（プロンプト下のヒント行）、複数のモッドがバンド/ヒント行を共有する方法、テストキットのコツ、変更が適用されないときのロードパスの確認方法を解説します。ユーザーがモッド、モード、パネル、ペイン、バンド、プロンプト上の単一行、ヒント行、PromptHint、ショートカットチップ、タブ切り替え、「reload‑plugins したのに何も変わらない」、`ysoftman-claude-kit/plugins`、`dev-mods`、`register.tsx`、`ui.render`、`$.ui.open` などに言及した場合は、必ず plugin‑authoring と合わせて使用する必要があります。
