实用指南：在创建或修复 Claude Code 模块（函数钩子插件——面板、提示上方的横幅、快捷键芯片、斜杠指令）时使用内置的 `plugin-authoring` 技能。内容包括显示和切换面板标签页、`keybindings.json` 中的 `command:` 快捷方式及其提示（提示行在提示下方的尾部）、多个模块如何共享同一横幅/提示行、测试工具箱技巧，以及在更改未生效时检查加载路径。用户若提及创建模块或模式、面板、窗格、横幅、提示上方的一行、提示行、PromptHint、快捷键芯片、标签切换、“reload‑plugins 但没有变化”、`ysoftman-claude-kit/plugins`、`dev-mods`、`register.tsx`、`ui.render`、`$.ui.open` 等，都必须与 plugin‑authoring 共同使用。
