實用指南：使用內建的 `plugin-authoring` 功能在建立或修正 Claude Code 模組（函式掛鉤插件 — 窗格/面板、提示上方的帶狀區、快捷鍵晶片、斜線指令）時的操作說明。內容涵蓋顯示與切換面板分頁、keybindings.json 中 `command:` 快捷鍵及其提示（提示行尾在提示字元下方）、多個模組如何共享帶狀/提示行、測試套件技巧，以及當變更未被反映時檢查載入路徑。當使用者提到建立模組、面板、窗格、帶狀、提示上方的單行、提示行、PromptHint、快捷鍵晶片、分頁切換、「reload‑plugins 但沒變更」等情況時，必須搭配 plugin‑authoring 使用。
