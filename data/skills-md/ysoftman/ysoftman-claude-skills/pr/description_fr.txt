Créer des pull requests GitHub avec des titres en anglais et un contenu de corps structuré. Utilisez cela lorsque l'utilisateur veut créer une PR, ouvrir une pull request, une merge request, ou dit « PR 만들어줘 », « PR 생성 », « 풀리퀘 », « pull request ». Activez également cela lorsque l'utilisateur a terminé son travail sur une branche et dit « 이거 올려줘 » ou une expression similaire.

Veuillez toujours répondre dans la langue de l'utilisateur.
