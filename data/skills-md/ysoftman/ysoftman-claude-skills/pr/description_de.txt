Erstelle GitHub-Pull-Requests mit englischen Titeln und strukturiertem Body-Inhalt. Verwende dies, wenn der Nutzer einen PR erstellen, einen Pull Request öffnen, eine Merge-Anfrage stellen möchte oder sagt „PR 만들어줘“, „PR 생성“, „풀리퀘“, „pull request“. Auslösen auch, wenn der Nutzer die Arbeit an einem Branch beendet und sagt „이거 올려줘“ oder Ähnliches. Bitte antworte immer in der Sprache des Nutzers.
