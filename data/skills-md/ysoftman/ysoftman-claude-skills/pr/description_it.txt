Crea pull request su GitHub con titoli in inglese e contenuto del corpo strutturato. Usa quando l'utente vuole creare un PR, aprire una pull request, una merge request, o dice “PR 만들어줘”, “PR 생성”, “풀리퀘”, “pull request”. Attiva anche quando l'utente termina il lavoro su un branch e dice “이거 올려줘” o simile. Per favore rispondi sempre nella lingua dell'utente.
