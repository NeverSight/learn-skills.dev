Создавайте pull request’ы в GitHub с английскими заголовками и структурированным содержимым тела. Используйте этот шаблон, когда пользователь хочет создать PR, открыть pull request, выполнить merge‑request или произносит «PR 만들어줘», «PR 생성», «풀리퀘», «pull request». Также реагируйте, когда пользователь завершает работу над веткой и говорит «이거 올려줘» или что‑то похожее.

Пожалуйста, всегда отвечайте на языке пользователя.
