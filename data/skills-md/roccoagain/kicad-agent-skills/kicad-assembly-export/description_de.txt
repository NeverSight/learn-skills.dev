Erstellt JLCPCB-Bestückungsdateien (Stückliste und CPL/Bestückungsliste) aus einer KiCad-10-Platine und überprüft die Reihenfolge: LCSC-Nummern auf jedem bestückten Bauteil, Übereinstimmung von Stückliste und CPL, Bauteile nicht am Rand, Drehungen. Verwenden Sie diese Option, wenn der Benutzer möchte, dass JLC eine Platine bestückt, eine Stückliste, eine CPL-, Centroid- oder Bestückungsdatei anfordert oder LCSC-Nummern hinzufügt. Verwenden Sie für Gerber-Dateien kicad-fab-export.
