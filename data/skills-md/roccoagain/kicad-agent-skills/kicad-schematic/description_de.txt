Bearbeitet oder zeichnet einen KiCad-10-Schaltplan mit sch.py, einer kleinen Python-Bibliothek im Ordner dieser Skill: Fügt Symbole (einschließlich Bauteile mit mehreren Einheiten), Leitungen, Beschriftungen, Stromversorgungssymbole und Nicht-Verbindungen nach Pin hinzu, ändert Werte und Felder, führt dann eine ERC-Prüfung durch und überträgt die Änderung auf die Platine. Verwenden Sie diese Funktion, wenn Sie Änderungen an einem Schaltplan vornehmen, z. B. das Hinzufügen eines Bauteils, das Verbinden von Netzen oder das Ändern eines Werts, und wenn Sie einen neuen Schaltplan zeichnen. Verwenden Sie zum Erstellen eines Symbols die KiCad-Bibliothek.
