Creates a new KiCad 10 project without opening KiCad, using the scripts in kicad-schematic and kicad-board-edit: schematic and board files, layer count, thickness, design rules and net classes, rounded outline, mounting holes, parts from the schematic, ground pours, libraries, jobsets and .gitignore. Use when the user wants a new board, a new revision of an existing one, or a PCB for a schematic that doesn't have one yet.
