Legt fest, wo Bauteile auf einer KiCad-10-Leiterplatte platziert werden: Pin-Zuordnung anhand des Lageplans, Layout-Einschränkungen gemäß Datenblatt, Anpassung passiver Bauteile an Pins mit engem Rastermaß, Montageabstände und Vergleich möglicher Platzierungen mit der Bewertung von board.py. Verwenden Sie es, wenn Sie eine neue Platzierung planen oder eine vorhandene Platzierung überarbeiten. Verschiebungen werden mit kicad-board-edit vorgenommen. Um ein fertiges Layout zu beurteilen, verwenden Sie kicad-layout-review.
