Teile und lese Agent‑Konversationen oder Markdown‑Dokumente mit Bildern über Threadshare. Verwende es, wenn Nutzer einen Gesprächslink, eine Team‑Dokumentenüberprüfung, verankerte Kommentare oder das Zurückbringen von Feedback an ihren Agenten zur Überarbeitung benötigen. Unterstützt Codex, Codex Cloud, Claude Code und Paseo‑Konversationen, Exporte von Dokumentenprüfungen in JSON oder Markdown, Ablauf und Widerruf sowie explizite lokale Sitzungsanalysen oder Team‑Memory‑Workflows.
