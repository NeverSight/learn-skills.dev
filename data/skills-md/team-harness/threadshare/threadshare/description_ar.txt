شارك واقرأ محادثات الوكيل أو مستندات ماركداون التي تحتوي على صور عبر Threadshare. يُستخدم عندما يرغب المستخدمون في رابط للمحادثة، مراجعة مستند الفريق، تعليقات مثبتة، أو لإرجاع الملاحظات إلى وكيلهم للتعديل. يدعم محادثات Codex وCodex Cloud وClaude Code وPaseo، وتصدير مراجعات المستندات بصيغة JSON أو ماركداون، بالإضافة إلى خيارات انتهاء الصلاحية وإلغاء الترخيص، وتحليل الجلسة المحلي الصريح أو تدفقات عمل الذاكرة الجماعية.
