Создавайте кроссплатформенные VoIP‑приложения для звонков с помощью React Native и Telnyx Voice SDK. Высокоуровневый реактивный API с автоматическим управлением жизненным циклом, интеграцией CallKit/ConnectionService и push‑уведомлениями. Используйте для мобильных VoIP‑приложений с минимальной настройкой.
