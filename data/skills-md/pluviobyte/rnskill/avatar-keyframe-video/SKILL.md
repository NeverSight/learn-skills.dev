# 法天象地连续帧成片

把一次可读懂的力量展示拆成连续状态，再把相邻状态之间的动作交给视频生成。按用户本次要求交付方案、关键帧或成片，不自动扩大范围。

## 从当前进度接手

- 有批准的风格图：直接作为母版，不重新海选风格。
- 有批准的连续帧：检查帧间矛盾后制作视频，不重复出图。
- 只要方案、Skill、提示词或关键帧：完成对应部分，不自动提交收费视频任务。
- 用户说“选定后再继续”时停在选择点；已选定或已授权则不重复确认。
- 缺少非关键偏好且允许自主决定时，采用合理默认推进。雨夜、八帧、25秒、刀与配乐都不是固定要求。

可接收 `novel-distill` 的事件卡，也可直接使用用户构想，无须安装额外 Skill。原文事实 F、视听处理 P、新增改编 A 分清；参考视频里的领域、法相、武器不能倒灌为小说事实。无原文时称视觉概念演绎。

## 工具选择：平台无关

本 Skill 固定制作方法，不指定默认成片平台。出图、图生视频、剪辑混音可以由不同工具完成，也可以在同一平台完成。

- 用户指定工具或已有项目时优先沿用，核实其实际能力；不因历史案例用过 Pexo 就自动选择它。
- 未指定时，根据当前可用工具、参考图约束能力、时长、可下载输出与预算选择，并简短说明理由。若已有可用方案且用户允许自主决定，无须为平台选择另设确认环节。
- 没有可调用的生成工具时，交付独立关键帧、通用分段简报和提示词，说明缺少的能力；不把制作好素材说成已生成视频。
- 先核实当前接口或界面，再将通用简报映射成具体参数。平台名称不等于模型能力，不预设每个平台都支持多图参考、首尾帧或原生音效。

## 1. 锁定同框关系与连续性

用简短连续性表记录已有信息：

| 项目 | 要锁定的内容 |
|---|---|
| 人物 | 脸、年龄、发型、衣袍剪影、材质、识别物 |
| 法相 | 默认是自己的放大显现，同脸同装束；若用户指定神灵/异形则记录其对应关系 |
| 同框空间 | 本体前景、法相后方高过建筑；小人轮廓和巨相面部同时可读 |
| 身体与画面坐标 | 解剖学哪只手持什么，起点和终点在画面哪里 |
| 场景 | 建筑地标、光源、天气、机位与动作轴线 |
| 材质演变 | 如银灰虚影→肤色衣料→边缘消散；用户不需要则不强加 |
| 出招 | 起手→蓄力→释放→收势，次数、方向、受力对象和环境反应 |

**同动作映射，不是水平镜像。** 本体解剖学右臂对应法相右臂，不写含混的“mirror pose”导致左右翻转。法相不能变成远处的第二名对手；单独大脸特写不能替代要求的同框关键画面。

默认沿母版单一机位或轻微推进，降低接续难度；用户要多机位时明确切镜及轴线，不把单机位变成风格禁令。

## 2. 先设计状态变化，再生成独立帧

读 [references/keyframes.md](references/keyframes.md)。每帧记录本体姿态、法相姿态/透明度、武器状态、环境反应、与前帧的差异、尚未发生的动作。差异应能从图中看见。

常见结构是“蓄势→领域初开→初现→展开→凝实→聚刃举手→同步释放→余波”，可合并或拆分。聚刃和举手跨度太大时加过渡状态，不往同一提示词塞更多要求。

使用当前可用的图像生成/编辑工具；用户指定平台或型号时确认实际可调用能力。接口没有返回版本就记录渠道与“版本未披露”，不冒称 GPT-Image 2 等具体型号。

每次一张独立画面，保持画幅。通常传入“批准母版＋上一张通过的帧”：母版维持身份，前帧维持状态。前帧有错先修，不传播错误，也不一股脑投入所有图片。早期帧明确压住母版里的高潮：尚未显相不能已有巨脸，尚未释放不能已有完整刀光。

每帧出图后看图再继续。只有法相手臂错时定向修改，保留正确的本体、脸、衣服与场景。局部纹理允许合理差异，重大身份、手侧和动作阶段矛盾须先解决。

## 3. 把帧间动作分配给视频段

读 [references/video-and-qa.md](references/video-and-qa.md)。按时长能力和动作复杂度分段，相邻段共享一个通过的边界状态。共享图片不保证生成后自然接续。

每段写首态、尾态、过程参考、主要动作、镜头运动、双方对应关系、环境受力、声音节拍和结束姿态。图固定外观与状态，视频提示词描述状态间的运动，不做静图轮播。

有专用首/尾帧字段就按接口使用；普通 `image_list` 只能称有序参考。没有尾帧约束时检查实际段尾，必要时用通过的段尾作下一段首帧。边界明确且工具支持相应约束时才适合同时提交独立片段。

只有本次确实使用 Pexo 时才读可选适配说明 [references/pexo.md](references/pexo.md)。它不是默认入口或必需依赖；其他工具按通用简报与当前能力执行。

## 4. 验收、修正与合成

先看实际素材，再决定重生成。优先修同源关系、手侧与方向、重复出招、动作倒退、重大身份漂移。材质偏差按原定目标判断，平台一段自检文字不能直接触发收费重试。

**同框不等于同步。** 本体已收刀而法相仍举刀是关键错误。查看释放前后与每处接点；用合理裁切、匹配切点、音效桥接处理小差异，不用倒放或长叠化掩盖错误姿势。

记录原版与修正版，不覆盖唯一成功素材。每轮处理明确缺陷；预留重试和后期额度。用户给定上限不能擅自提高，助手自己的成本目标也要报告偏差。多段修正逐项计入消耗，不把“一轮”误写成免费重试。

声音按蓄势、释放、余波安排，保留有效环境与动作音效。配乐过长先裁切淡出，内容不适合才考虑重生成。“替换音轨”不能声称是“叠加保留”。平台不能混音时可按已有授权完成外部后期，但如实说明分工。

本地技术检查示例：

```bash
python3 scripts/audit_video.py /absolute/path/final.mp4 --cuts 6.04,12.08,17.12 --out /absolute/path/qa
```

切点必须填实际时间线。需要 Python 3、ffmpeg、ffprobe。脚本输出媒体参数、全程概览、接点抽帧、黑屏与音量检测；不判断人物同步、听感或是否有人声，仍须看图与适当音频检查。

## 交付

按范围交付独立关键帧和/或可下载成片，保留状态表、提示词与制作记录。记录实际工具/可确认的型号、时间线、重试、消耗和残留偏差。成片同时记录源素材与输出规格，不把上采样说成原生高分辨率，不把平台“完成”当作验收。

最终直接展示作品及重要限制。需要真实案例时读 [references/worked-example.md](references/worked-example.md)；历史价格和效果不构成成功率、预算或涨粉承诺。
