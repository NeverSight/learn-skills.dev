Activez cette compétence lorsque les utilisateurs ont besoin d'aide avec le flux de travail aperçu/programme du mode studio d'OBS — mettre en scène les changements de scène de manière privée, répéter les transitions et les appliquer à la diffusion en direct. Les déclencheurs incluent « activer le mode studio », « prévisualiser la scène suivante », « répéter une transition », « promouvoir l'aperçu vers le programme », « ce qui est en attente dans l'aperçu » ou « changer ma transition en fondu ». Cette compétence se concentre sur la discipline à deux scènes (programme = ce que les spectateurs voient, aperçu = ce qui est en cours de préparation) plutôt que sur la configuration générale du streaming. Veuillez toujours répondre dans la langue de l'utilisateur.
