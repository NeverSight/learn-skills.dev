Invocare sempre quando è necessario acquisire, preparare, riparare, scalare o spostare dati geospaziali tramite una pipeline ripetibile. Include l'acquisizione di open‑data/OSM/STAC, formati spaziali, trasformazioni CRS, controlli di qualità e architettura ETL batch per join in crescita o ricorrenti. Invocare insieme a PostGIS per l'esecuzione sul database e insieme agli standard SWE quando il codice viene consegnato. Non attivare semplicemente perché un altro specialista legge dati pronti per l'analisi. Per favore, rispondi sempre nella lingua dell'utente.
