Canonical Flows technische Überprüfungen und Scoring (Jagdbefehle, Geltungsbereich, Paketprüfung, öffentliche Kriterien, Muss/Soll/Nizza). Geladen von Flows-Code-Review und von jeder externen Review-Fähigkeit. Kopieren Sie diese Schecks nicht in eine andere Fertigkeit. Verwenden Sie diese Fähigkeit nicht, um Code zu reparieren. Wird verwendet, wenn ein Orchestrator sagt, dass Flows geladen werden sollen - Überprüfungsprüfungen überprüfen, oder wenn zwei Überprüfungsflüsse auf derselben Leiste ausgerichtet werden.
