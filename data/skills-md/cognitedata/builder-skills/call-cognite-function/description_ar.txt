استدعِ دالة Cognite CDF المنشورة واسترد استجابتها، مع استجابات API التي تم التحقق منها باستخدام Zod وخطاف React Query اختياري. استخدم هذه المهارة كلما احتجت إلى استدعاء أي دالة CDF (عن طريق معرف الدالة الرقمي أو المعرف الخارجي)، وتمرير بيانات إدخال عشوائية، والحصول على نتيجة مُعرَّفة ومُتحقق منها — بغض النظر عما تفعله الدالة، أو ما إذا كان لديها مخرجات، أو ما هو شكل إدخالها/إخراجها. الكلمات المفتاحية: استدعاء دالة cognite، استدعاء دالة CDF، تشغيل دالة CDF، استطلاع دالة CDF، API دوال CDF، نتيجة دالة cognite، nonce استدعاء الدالة.
