استدعِ دالة Cognite CDF المنشورة واسترجع استجابتها، مع استجابات API مُتحققة باستخدام Zod وخطاف React Query اختياري. استخدم هذه المهارة كلما احتجت إلى استدعاء أي دالة CDF (عن طريق معرف الدالة الرقمي أو المعرف الخارجي)، وتمرير بيانات إدخال عشوائية، والحصول على نتيجة مُصنَّفة ومُتحققة — بغض النظر عما تفعله الدالة، أو ما إذا كانت لديها مخرجات، أو ما هو شكل إدخال/إخراجها. الكلمات المفتاحية: استدعاء دالة cognite، استدعاء دالة CDF، تشغيل دالة CDF، استطيان دالة CDF، واجهة برمجة تطبيقات دوال CDF، نتيجة دالة cognite، nonce استدعاء الدالة.
