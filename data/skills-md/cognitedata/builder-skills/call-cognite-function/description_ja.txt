デプロイされた Cognite CDF 関数を呼び出してその応答を取得します。Zod で検証された API 応答と、オプションの React Query フックを使用します。このスキルは、数値の関数 ID または外部 ID で任意の CDF 関数を呼び出す必要があるとき、任意の入力データを渡し、型付けされ検証された結果を取得したいときに使用してください — 関数が何を行うか、出力があるかどうか、入力・出力の形状がどうであるかに関係なく。トリガー: call cognite function, invoke CDF function, run CDF function, poll CDF function, CDF Functions API, cognite function result, function call nonce.
