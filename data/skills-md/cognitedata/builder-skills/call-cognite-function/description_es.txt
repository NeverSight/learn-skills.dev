Llama a una función Cognite CDF implementada y recupera su respuesta, con respuestas de API validadas con Zod y un hook opcional de React Query. Usa esta habilidad siempre que necesites invocar cualquier función CDF (por ID numérico o ID externo), pasar datos de entrada arbitrarios y obtener un resultado tipado y validado — sin importar lo que haga la función, si tiene una salida, o la forma que tengan sus entradas/salidas. Disparadores: llamar función cognite, invocar función CDF, ejecutar función CDF, sondear función CDF, API de Funciones CDF, resultado de función cognite, nonce de llamada a función.
