Appelez une fonction CDF Cognite déployée et récupérez sa réponse, avec des réponses API validées par Zod et un hook React Query facultatif. Utilisez cette compétence chaque fois que vous devez invoquer une fonction CDF (par ID numérique ou ID externe), transmettre des données d'entrée arbitraires et obtenir un résultat typé et validé — quel que soit le comportement de la fonction, la fonction a une sortie, ou la forme de ses entrées/sorties. Déclencheurs : appeler fonction Cognite, invoquer fonction CDF, exécuter fonction CDF, interroger fonction CDF, API des fonctions CDF, résultat de fonction Cognite, nonce d’appel de fonction.
