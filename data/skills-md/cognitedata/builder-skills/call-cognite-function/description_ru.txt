Вызовите развернутую функцию Cognite CDF и получите её ответ, используя ответы API, проверенные Zod, и необязательный хук React Query. Используйте это умение, когда необходимо вызвать любую функцию CDF (по числовому идентификатору функции или внешнему ID), передать произвольные входные данные и получить типизированный, проверенный результат — независимо от того, что делает функция, имеет ли она выходные данные или какую форму принимают её ввод/вывод. Триггеры: вызов функции Cognite, вызов функции CDF, запуск функции CDF, опрос функции CDF, API функций CDF, результат функции Cognite, nonce вызова функции.
