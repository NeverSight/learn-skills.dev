Вызвать развернутую функцию Cognite CDF и получить её ответ, используя проверку ответов API с помощью Zod и необязательный хук React Query. Используйте это умение, когда нужно вызвать любую функцию CDF (по числовому ID функции или внешнему ID), передать произвольные входные данные и получить типизированный, проверенный результат — независимо от того, что делает функция, имеет ли она вывод или какой формы являются её входные/выходные данные. Триггеры: call cognite function, invoke CDF function, run CDF function, poll CDF function, CDF Functions API, cognite function result, function call nonce.
