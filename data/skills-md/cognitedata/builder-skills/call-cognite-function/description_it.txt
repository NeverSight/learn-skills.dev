Chiama una funzione Cognite CDF distribuita e recupera la sua risposta, con risposte API validate da Zod e un hook opzionale React Query. Usa questa abilità ogni volta che devi invocare una qualsiasi funzione CDF (tramite ID numerico della funzione o ID esterno), fornire dati di input arbitrari e ottenere un risultato tipizzato e validato — indipendentemente da ciò che la funzione fa, se la funzione ha un output o da quale forma assumano input e output. Trigger: chiamare funzione Cognite, invocare funzione CDF, eseguire funzione CDF, interrogare funzione CDF, API delle Funzioni CDF, risultato della funzione Cognite, nonce della chiamata funzione.
