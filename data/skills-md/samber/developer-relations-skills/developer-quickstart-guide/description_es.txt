Escribe o revisa un quickstart para desarrolladores que lleva al lector de cero a un éxito verificado: ruta mínima, comandos para copiar‑pegar, salida esperada en cada paso, ramas de error y un presupuesto de tiempo de ejecución en frío. Úsalo siempre que el usuario mencione un quickstart, una página de “getting‑started”, un documento hello‑world, “tiempo hasta el primer éxito” o “tiempo hasta el primer valor”, documentación de incorporación para una API, SDK, CLI o herramienta auto‑alojada, o se queje de que nadie termina su página de introducción, incluso si solo dice “nuestra configuración es demasiado difícil”. NO lo uses para un tutorial de enseñanza (samber/developer-relations-skills@developer-tutorial) ni para reescribir un README (samber/developer-relations-skills@readme-optimization).
