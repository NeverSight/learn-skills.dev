Создаёт приоритетный список ключевых слов для технических поисковых запросов (строки ошибок, задачи типа «как сделать X в Y», намерения интеграции, сравнения, миграции), полученных из журналов поиска по документации, тикетов поддержки, трекеров проблем и собственных данных запросов, а не из объёма инструментов подбора ключевых слов. Используйте, когда пользователь спрашивает, что действительно ищут разработчики, хочет ключевые слова для инструмента разработчика, API, SDK или сайта документации, список ключевых слов по сообщениям об ошибках, оценку спроса на техническую тему или какие страницы документации создать на основе поискового спроса — даже если они не используют слово «ключевое слово». Не создает страницы. Не используйте для SEO на странице или сайта документации — используйте samber/developer-relations-skills@docs-seo.
