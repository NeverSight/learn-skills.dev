開発者向けドキュメントのすべてのコードサンプルが満たすべきポリシーを定義し、既存のサンプルコーパスをそれに照らして監査し、優先順位付けされた修正キューを返します。ユーザーがドキュメントのコードサンプル、ドキュメント内のコードスニペット、実行可能な例、コンパイルできなくなった例、コピー＆ペーストの失敗、API 変更後のスニペットのずれ、CI でのドキュメント例のテスト、言語間での SDK スニペットのパリティ、サンプルの保守所有権について言及したり、ドキュメント内の例が動作しない理由を尋ねたりした場合（たとえ「ドキュメントが壊れている」とだけ言っていても）に使用してください。サンプルの構成要素、コピー＆ペーストおよびセキュリティの安全性、実行レベル、テスト済みコードからの単一ソース化、言語間のパリティを対象とします。クイックスタートページの作成には使用せず、samber/developer-relations-skills@developer-quickstart-guide を使用してください。
