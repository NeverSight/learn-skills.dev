Определяет политику, которой должен соответствовать каждый образец кода в документации для разработчиков, и проводит аудит существующего корпуса примеров, возвращая упорядоченную очередь исправлений. Используйте, когда пользователь упоминает примеры кода в документации, фрагменты кода в документах, исполняемые примеры, примеры, которые больше не компилируются, ошибки при копипасте, отклонения фрагментов после изменения API, тестирование примеров документации в CI, паритет SDK‑фрагментов между языками, ответственность за поддержание примеров или спрашивает, почему примеры в их документации не работают — даже если они просто говорят, что документация сломана. Охватывает структуру примера, безопасность при копипасте, уровни выполнения, единый источник из проверенного кода и паритет языков.
