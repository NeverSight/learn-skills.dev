Преобразует тикеты поддержки, историю проблем и телеметрию ошибок в страницы по устранению неполадок и справочники по ошибкам, которые разработчик находит, вставляя строку ошибки — симптомы, условия, причина, решение и проверки, каталог кодов ошибок, сгенерированный из единого источника истины, и исправления, встроенные в собственный вывод ошибок продукта. Используйте, когда пользователь упоминает документы по устранению неполадок, документирование кодов ошибок, страницы сообщений об ошибках, страницу известных проблем, создание FAQ из тикетов поддержки или «мы отвечаем на один и тот же вопрос каждую неделю» — даже если они просто говорят «пользователи постоянно сталкиваются с этой ошибкой». Не предназначено для отладки живого инцидента. Не использовать для ранжирования поиска по документам — используйте samber/developer-relations-skills@docs-seo. Пожалуйста, всегда отвечайте на языке пользователя.
