Audite et réécrit le README d’un dépôt afin qu’un développeur qui n’a jamais vu le projet puisse comprendre ce que c’est, pourquoi il surpasse l’alternative, et exécuter la première commande en moins d’une minute – chaque affirmation et l’installation documentée sont vérifiées par rapport au code source, la page est structurée en un entonnoir de conversion rapide, les badges inutiles sont retirés. Utilisez-le chaque fois que quelqu’un dit « review my README », « my readme is bad », « write a README for this repo », « nobody understands what my project does », « repo first impression », « readme structure », « too many badges », ou qu’il prépare un lancement open‑source – même s’il l’appelle simplement la page d’atterrissage du repo. Ce n’est pas un README de profil – utilisez samber/developer‑relations‑skills@github‑profile‑optimization.
