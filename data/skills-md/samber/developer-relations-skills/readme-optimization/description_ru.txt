Аудитирует и переписывает README репозитория так, чтобы разработчик, никогда не видевший проект, мог понять, что это за проект, почему он лучше альтернативы, и запустить первую команду за минуту — каждое утверждение и описанная установка проверены по исходному коду, страница упорядочена в быстрый воронкообразный путь, лишние бейджи, не приносящие пользы, удалены. Применяйте, когда кто‑то говорит «проверьте мой README», «мой README плох», «напишите README для этого репо», «никто не понимает, что делает мой проект», «первое впечатление о репо», «структура README», «слишком много бейджей», или готовит open‑source запуск — даже если называют это только посадочной страницей репозитория. Не профильный README — используйте samber/developer-relations-skills@github-profile-optimization.
