Создаёт план отслеживания, который инструмента­лизирует поверхности взаимодействия с разработчиками — документацию, блог, репозитории, реестры пакетов, площадки сообщества и офлайн‑выступления — с помощью таксономии событий, идентификационной основы, дисциплины тегирования ссылок, маркировки доверия к источнику и представлений воронки. Используется, когда пользователь говорит «план отслеживания devrel», «аналитика документации», «UTM‑дисциплина», «таксономия событий для нашей документации», «числа с GitHub не совпадают с аналитикой», «как инструмента­лизировать воронку разработчиков», «соединить трафик документации с регистрациями» или хочет понять, почему цифры devrel разнятся между инструментами. Только слой инструментирования — какие KPI заслуживают целевого значения, относится к samber/developer-relations-skills@devrel-metrics.
