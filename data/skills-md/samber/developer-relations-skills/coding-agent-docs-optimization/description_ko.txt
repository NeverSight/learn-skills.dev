SDK, API 또는 프로토콜 문서를 코딩 에이전트가 무인 상태에서 통합할 수 있도록 만든다 — 크롤러 접근, 기계가 읽을 수 있는 진입점(llms.txt, 마크다운 엔드포인트, OpenAPI 및 JSON Schema 파일), 자체 포함된 복사‑붙여넣기 안전 페이지, 그리고 첫 번째 시도 에이전트 성공률을 측정한다. 사용자는 에이전트가 읽을 수 있는 문서나 AI‑준비 문서, 에이전트 경험 또는 AX, llms.txt 또는 llms-full.txt, 코딩 에이전트를 위한 문서, 존재하지 않는 API 호출을 발명하는 에이전트, 혹은 에이전트가 문서만으로 SDK를 연결할 수 있는지 묻는 경우(비록 "에이전트"라는 말을 쓰지 않더라도) 이 지침을 적용한다. AI 검색 인용이나 레포지토리 자체의 기여자 대상 에이전트 지침에는 사용하지 않는다. 인간 문서 아키텍처에 대해서는 samber/developer-relations-skills@developer-docs-structure-audit 를 참고한다.

항상 사용자의 언어로 응답하십시오.
