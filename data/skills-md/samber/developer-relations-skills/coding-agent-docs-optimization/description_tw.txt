將 SDK、API 或協定文件變成能讓程式碼代理在無人看管的情況下整合的對象——提供爬蟲存取、機器可讀的入口點（llms.txt、Markdown 端點、OpenAPI 與 JSON Schema 檔案）、自包含且可直接複製貼上的頁面，以及可衡量的首次嘗試代理成功率。當使用者提及可供代理閱讀或 AI 準備的文件、代理體驗或 AX、llms.txt 或 llms‑full.txt、供程式碼代理使用的文件、代理發明不存在的 API 呼叫，或詢問是否僅靠文件就能讓代理接線其 SDK——即使他們從未說「代理」時，都請使用此方式。此規則不適用於 AI 搜尋引用，亦不適用於倉庫自身面向貢獻者的代理說明。對於人類文件架構請使用 samber/developer‑relations‑skills@developer‑docs‑structure‑audit。
