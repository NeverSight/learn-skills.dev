Macht SDK-, API- oder Protokolldokumentation zu etwas, das ein Coding‑Agent unbeaufsichtigt integrieren kann – Crawler‑Zugriff, maschinenlesbare Einstiegspunkte (llms.txt, Markdown‑Endpoints, OpenAPI‑ und JSON‑Schema‑Dateien), eigenständige, copy‑paste‑sichere Seiten und eine gemessene Erfolgsquote beim ersten Versuch eines Agenten. Verwende dies immer, wenn der Nutzer agentenlesbare oder KI‑fertige Dokumente, Agentenerfahrung oder AX, llms.txt oder llms‑full.txt, Dokumente für Coding‑Agents, Agents, die API‑Aufrufe erfinden, die nicht existieren, erwähnt oder fragt, ob ein Agent sein SDK allein aus den Docs verbinden könnte – selbst wenn er nie das Wort „Agent“ verwendet. Nicht für KI‑Suchzitate oder die eigenen beitragenden Anleitungen eines Repos für Agents. Für die Architektur von menschlichen Dokumenten verwende samber/developer-relations-skills@developer-docs-structure-audit.
