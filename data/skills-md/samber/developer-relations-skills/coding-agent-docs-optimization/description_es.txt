Hace que la documentación de SDK, API o protocolos sea algo que un agente de codificación pueda integrar de forma desatendida: acceso de rastreador, puntos de entrada legibles por máquinas (llms.txt, endpoints en markdown, archivos OpenAPI y JSON Schema), páginas autónomas seguras para copiar y pegar, y una tasa de éxito medida en el primer intento del agente. Utilícelo siempre que el usuario mencione documentación legible por agentes o lista para IA, experiencia de agente o AX, llms.txt o llms-full.txt, documentación para agentes de codificación, agentes que inventan llamadas API que no existen, o pregunte si un agente podría conectar su SDK solo con la documentación, incluso si nunca dice "agente". No es para citación de búsqueda de IA, ni para instrucciones de agente dirigidas a contribuidores de un repositorio. Para la arquitectura de documentación humana use samber/developer-relations-skills@developer-docs-structure-audit.  

Por favor, siempre responda en el idioma del usuario.
