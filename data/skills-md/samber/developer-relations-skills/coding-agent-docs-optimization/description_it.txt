Rende la documentazione SDK, API o di protocollo qualcosa che un agente di programmazione può integrare in modo autonomo – accesso crawler, punti di ingresso leggibili dalla macchina (llms.txt, endpoint markdown, file OpenAPI e JSON Schema), pagine autonome e sicure per copia‑incolla, e una percentuale misurata di successo al primo tentativo dell’agente. Usalo ogni volta che l’utente menziona documenti leggibili da agente o pronti per l’IA, esperienza dell’agente o AX, llms.txt o llms-full.txt, documenti per agenti di codifica, agenti che inventano chiamate API inesistenti, o chiede se un agente potrebbe configurare il loro SDK solo dalla documentazione, anche se non dice mai “agente”. Non è destinato a citazioni di ricerca AI, né alle istruzioni per agenti rivolte ai contributori di un repository. Per l’architettura dei documenti destinati agli esseri umani usa samber/developer‑relations‑skills@developer‑docs‑structure‑audit.
