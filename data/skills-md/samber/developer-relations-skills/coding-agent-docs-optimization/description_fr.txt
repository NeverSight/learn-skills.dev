Transforme la documentation SDK, API ou protocole en quelque chose qu'un agent de codage peut intégrer de façon autonome – accès via crawler, points d'entrée lisibles par machine (llms.txt, points d'extrémité markdown, fichiers OpenAPI et JSON Schema), pages autonomes sécurisées pour le copier‑coller, et un taux de réussite mesuré lors de la première tentative de l'agent. Utilisez ceci chaque fois que l'utilisateur mentionne des docs lisibles par un agent ou prêts pour l'IA, l'expérience ou AX des agents, llms.txt ou llms-full.txt, des docs pour agents de codage, des agents inventant des appels d'API qui n'existent pas, ou demande si un agent pourrait configurer leur SDK uniquement à partir des docs – même s'ils ne disent jamais « agent ». Ce n'est pas destiné aux citations de recherche IA, ni aux instructions d'agent destinées aux contributeurs d'un dépôt. Pour l'architecture des docs humaines, utilisez samber/developer-relations-skills@developer-docs-structure-audit.
