SDK、API、またはプロトコルのドキュメントを、コーディングエージェントが無人で統合できるようにします――クローラによるアクセス、機械可読エントリーポイント（llms.txt、Markdown エンドポイント、OpenAPI や JSON Schema ファイル）、自己完結型でコピー＆ペーストして安全に利用できるページ、そして初回試行時のエージェント成功率を測定したものです。ユーザーが agent‑readable や AI‑ready ドキュメント、エージェント体験（AX）、llms.txt や llms‑full.txt、コーディングエージェント向けドキュメント、存在しない API 呼び出しを考案するエージェント、またはエージェントがドキュメントだけで SDK を配線できるかどうかを尋ねた（たとえ「エージェント」という語が出てこなくても）場合に使用してください。AI 検索の引用や、リポジトリの貢献者向けエージェント指示には使用しません。人間向けドキュメントのアーキテクチャについては samber/developer-relations-skills@developer-docs-structure-audit を参照してください。
