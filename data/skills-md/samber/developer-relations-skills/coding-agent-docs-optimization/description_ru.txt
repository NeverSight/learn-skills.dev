Делает SDK, API или протокольную документацию тем, что кодировочный агент может интегрировать без участия человека — доступ для краулеров, машинно‑читаемые точки входа (llms.txt, markdown‑конечные точки, файлы OpenAPI и JSON Schema), автономные страницы, безопасные для копирования‑вставки, и измеренный показатель успеха агента при первой попытке. Используйте, когда пользователь упоминает документацию, читаемую агентом или готовую для ИИ, опыт агента или AX, llms.txt или llms-full.txt, документацию для кодовых агентов, агентов, придумывающих API‑вызовы, которых нет, или спрашивает, может ли агент настроить их SDK только по документации — даже если они вовсе не говорят слово «агент». Не предназначено для цитирования AI‑поиска, а также для инструкций агенту, ориентированных на участников репозитория. Для архитектуры человеческой документации используйте samber/developer-relations-skills@developer-docs-structure-audit.
