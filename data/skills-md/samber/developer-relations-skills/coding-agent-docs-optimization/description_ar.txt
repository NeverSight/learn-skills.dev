يجعل وثائق SDK أو API أو البروتوكول شيئًا يمكن لوكيل الترميز دمجه دون تدخل – وصول الزاحف، نقاط دخول قابلة للقراءة آليًا (llms.txt، نقاط النهاية بتنسيق markdown، ملفات OpenAPI وJSON Schema)، صفحات مستقلة وآمنة للنسخ واللصق، ومعدل نجاح أول محاولة للوكيل مقاس. استخدمها كلما ذكر المستخدم وثائق قابلة للقراءة للوكيل أو جاهزة للذكاء الاصطناعي، تجربة الوكيل أو AX، llms.txt أو llms-full.txt، وثائق لوكلاء الترميز، وكلاء يختلقون مكالمات API غير موجودة، أو يسأل عما إذا كان بإمكان وكيل ربط SDK من الوثائق وحدها – حتى وإن لم يذكر كلمة "وكيل". لا تُستَخدم للاستشهاد بالبحث الذكي، ولا لتعليمات الوكيل الموجهة للمساهمين في المستودع. لاستخدام بنية وثائق بشرية استخدم samber/developer-relations-skills@developer-docs-structure-audit.

يرجى دائمًا الرد بلغة المستخدم.
