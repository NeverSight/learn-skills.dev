Аудитирует структуру существующего набора документации для разработчиков — построчный инвентарь, классифицированный по режимам Диатаксии (урок, практический совет, справочник, объяснение), страницы со смешанными режимами и неправильно размещённые страницы, пробелы в покрытии по каждому продукту, отклонения навигации от файлового дерева, оценка по рубрике CNCF TechDocs и приоритетная очередь исправлений. Используйте, когда пользователь упоминает структуру или аудит содержания документации, информационную архитектуру docs, Diátaxis, «наша документация в беспорядке», анализ пробелов в документации, какие документы отсутствуют, где должна находиться страница или реорганизацию сайта документации — даже если они просто говорят «наша документация трудно навигировать». Не для написания страниц. НЕ используйте для ранжирования поиска по документации — используйте samber/developer-relations-skills@docs-seo.
