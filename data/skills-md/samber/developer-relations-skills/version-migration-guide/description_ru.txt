Пишет или проверяет руководство по миграции для ломающего изменения — что ломается, упорядочено по радиусу поражения, с сигналом обнаружения и кодом до/после для каждой записи, графиком устаревания, границей охвата кодмода и проверкой через холодное обновление реального проекта. Использовать каждый раз, когда кто‑то упоминает руководство по миграции, руководство по обновлению, страницу ломающих изменений, крупный bump версии, «как мы сообщим пользователям о v3», переключение версии API, уведомление об устаревании или завершении поддержки, или кодмод/совместимую сборку — даже если они лишь говорят, что выпускают v2. Охватывает библиотеки, SDK, CLI, фреймворки, хостируемые API и схемные руководства. Не является заметками о релизе — используйте samber/developer-relations-skills@changelog-writing.
