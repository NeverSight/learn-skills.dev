다른 회사가 구축하는 플랫폼으로 개발자 제품을 열어야 하는지, 언제, 그리고 얼마나 깊게 열어야 하는지를 결정합니다—확장 포인트, 파트너가 만든 통합, 타사 앱, 보완 에코시스템 등—그리고 이것이 영구적으로 여러분에게 어떤 의무를 부과하는지. 제품을 플랫폼으로 전환해야 하는지, 타사에게 확장 포인트나 앱 모델을 열어야 하는지, 통합 에코시스템을 어떻게 시작할지, 왜 아무도 API 위에 구축하지 않는지, 파트너가 커넥터를 구축해야 하는지, 보완자가 유지해야 할 가치가 얼마나 되는지 등에 대해 누군가 물을 때마다 사용하십시오—그들이 “통합 이야기를 원한다”고만 말하더라도. 마켓플레이스 운영이나 API 설계에는 사용하지 마십시오. 수익 모델에 대해서는 사용하지 마시고 samber/developer-relations-skills@devtools-business-model을 사용하십시오.
