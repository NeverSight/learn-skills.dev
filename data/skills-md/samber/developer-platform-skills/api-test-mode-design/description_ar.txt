صمم وضع الاختبار/الصندوق الرمل لمنصة API عامة بحيث يتمكن المدمجون الخارجيون من البناء والتحقق دون التعامل مع أموال أو رسائل أو بيانات حقيقية – بنية عزل (تبديل وضع اختبار ناعم مقابل صندوق رمل منفصل ثابت)، إضافة بادئة لمفاتيح الاختبار، قيم اختبار سحرية، كائنات وشخصيات محاكية، أحداث اختبار عند الطلب، تعديل زمني حتمي، إعادة ضبط وتوليد بيانات أولية، حصص الصندوق الرمل، ضوابط الانتشار، والترقية إلى الوضع الحي. استخدم هذا عندما يذكر المستخدم صندوق الرمل، وضع الاختبار، مفاتيح API الاختبارية، القيم السحرية أو الوهمية، أحداث webhook المحاكية، أو بيانات العرض – حتى وإن لم يذكر "وضع الاختبار". لا تقم باستخدامه لتوفير صناديق الرمل للشركاء – استخدم samber/developer-platform-skills@partner-app-onboarding بدلاً من ذلك.
