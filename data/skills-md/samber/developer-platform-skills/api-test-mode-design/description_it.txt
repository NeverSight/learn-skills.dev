Progetta la modalità test/sandbox di una piattaforma API pubblica in modo che gli integratori esterni possano costruire e validare senza toccare denaro reale, messaggi o dati: architettura di isolamento (commutatore soft per modalità test vs sandbox separata a copia hard), prefissazione delle chiavi di test, valori di test magici, oggetti e persona simulati, eventi di test su richiesta, manipolazione deterministica del tempo, reset e seeding, quote sandbox, controlli di abuso e graduazione alla modalità live. Usa ogni volta che l'utente menziona un sandbox, modalità test, chiavi API di test, valori magici o dummy di test, eventi webhook simulati o dati demo, anche se non dice mai “modalità test”. Non è sandboxing di esecuzione di codice né mocking di unit test. NON utilizzare per il provisioning di sandbox per partner – usa invece samber/developer-platform-skills@partner-app-onboarding.
