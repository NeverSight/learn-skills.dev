Diseña el modo de prueba/sandbox de una plataforma de API pública para que los integradores externos construyan y validen sin tocar dinero real, mensajes o datos: arquitectura de aislamiento (alternancia suave del modo de prueba vs sandbox de copia separada rígida), prefijado de claves de prueba, valores mágicos de prueba, objetos y personas simulados, eventos de prueba a demanda, manipulación determinista del tiempo, reinicio y siembra, cuotas de sandbox, controles de abuso y graduación a producción. Úsalo siempre que el usuario mencione un sandbox, modo de prueba, claves de API de prueba, valores mágicos o ficticios, eventos webhook simulados o datos de demostración, aunque nunca digan “modo de prueba”. No se trata de sandboxing de ejecución de código ni de simulación de pruebas unitarias. NO lo uses para el aprovisionamiento de sandbox de socios; utiliza samber/developer-platform-skills@partner-app-onboarding en su lugar.
