Progetta una superficie gRPC pubblica per sviluppatori esterni – il punto di ingresso “quando usare gRPC” (la maggior parte delle piattaforme mantiene gRPC interno e pubblica REST o JSON trascritto), le convenzioni di pacchetto e versionamento dei proto AIP, i gate di breaking change di buf e il loro punto cieco google.api.http, le decisioni di streaming unary per impostazione predefinita, il modello di errore google.rpc.Status con le sue trappole di mappatura HTTP, la transcoding e l'architettura del gateway (Connect-RPC, grpc-gateway, Envoy), e l'autenticazione esterna e TLS. Usa ogni volta che l'utente menziona gRPC, protobuf o file .proto, buf, Connect-RPC, grpc-gateway o transcoding gRPC-JSON ai margini pubblici – anche se non dice mai “progettazione API gRPC”. Solo il livello di progettazione, non l'implementazione server specifica del linguaggio.
