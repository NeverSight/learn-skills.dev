Diseña una superficie pública gRPC para desarrolladores externos: la puerta de cuándo‑usar‑gRPC (la mayoría de las plataformas mantienen gRPC interno y publican REST o JSON transcodificado), convenciones de paquetes proto y versionado de AIP, puertas de cambios disruptivos de buf y su punto ciego google.api.http, decisiones de streaming unary‑por‑defecto, el modelo de error google.rpc.Status con sus trampas de mapeo HTTP, transcoding y arquitectura de puerta de enlace (Connect‑RPC, grpc‑gateway, Envoy), y autenticación externa y TLS. Usa siempre que el usuario mencione gRPC, protobuf o archivos .proto, buf, Connect‑RPC, grpc‑gateway o transcoding gRPC‑JSON en un borde público, incluso si nunca dice “diseño de API gRPC”. Solo la capa de diseño, no la implementación del servidor específica de lenguaje.
