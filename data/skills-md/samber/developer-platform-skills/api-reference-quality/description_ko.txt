엔드포인트 수준에서 공개된 API 레퍼런스를 사양 표면과 대조하여 감사하세요—모든 작업, 매개변수, 응답 코드 및 오류가 문서화되고, 요청/응답 예제가 제공되며, 언어별 코드 스니펫이 동일하고, Try‑it 기능이 작동하는지 확인하고—레퍼런스 드리프트를 방지하는 진실의 근원 게이트(사양 기반 생성, OpenAPI 린트, 계약 테스트, CI에서의 스니펫 일치)를 설치하세요. 사용자가 API 레퍼런스 문서, OpenAPI 문서 완전성, 문서화되지 않은 엔드포인트나 오류 코드, 오래되었거나 드리프트되는 문서, 혹은 문서 CI 게이트를 언급할 때마다 적용하십시오—비록 “레퍼런스 품질”이라고 직접 말하지 않더라도 됩니다. 엔드포인트 수준의 레퍼런스에만 적용하고, 포털 IA 및 온보딩에는 사용하지 말고 대신 samber/developer-platform-skills@developer-portal-design를 사용하십시오.
