Audita una referencia de API publicada a nivel de endpoint contra su especificación visible: cada operación, parámetro, código de respuesta y error documentados, ejemplos de solicitud/respuesta presentes, fragmentos de código por idioma en paridad, funcionalidades de prueba interactiva funcionando, y establece los mecanismos de control de la fuente de verdad que evitan la deriva de la referencia (generación basada en especificaciones, lint de OpenAPI, pruebas de contrato, paridad de fragmentos en CI). Utilízalo siempre que el usuario mencione documentación de referencia de API, completitud de documentación OpenAPI, endpoints o códigos de error no documentados, documentación obsoleta o desalineada, o puertas de CI para documentación, incluso si nunca dice "calidad de referencia". Solo a nivel de referencia de endpoint. No lo uses para IA del portal ni incorporación; usa samber/developer-platform-skills@developer-portal-design en su lugar.
