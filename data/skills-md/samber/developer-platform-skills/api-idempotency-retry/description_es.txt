Diseña soporte para la clave de idempotencia y guía de reintentos del cliente en una API pública para que los integradores reintenten de forma segura: derivación de clave y alcance por llamante, TTL de almacenamiento y ventanas de repetición, mecanismos de reclamación atómica (restricción única en la base de datos, bloqueo de fila SERIALIZABLE, escrituras condicionales), rechazo por discrepancia de carga útil, manejo de duplicados en vuelo, retroceso exponencial con jitter, presupuestos de reintentos, propagación de tiempo de espera y valores predeterminados de reintento del SDK. Usa siempre cuando el usuario mencione el encabezado Idempotency-Key, solicitudes duplicadas o enviadas dos veces, reintentos seguros de POST, retroceso o jitter, aunque nunca digan "idempotencia". NO lo uses para lo que indica la respuesta de error (samber/developer-platform-skills@api-error-design) o para los reintentos de entrega de webhook (samber/developer-platform-skills@webhook-platform-design).
