Progetta la superficie di autenticazione con API‑key che una piattaforma fornisce ai propri consumatori API – formato della chiave con convenzioni di prefisso + checksum, archiviazione hashata (irrecuperabile) vs crittografata (recuperabile), rotazione a zero downtime con sovrapposizione di doppie chiavi, scoping a privilegio minimo, proprietà individuale vs organizzazione vs account di servizio, comportamento della dashboard self‑service delle chiavi e governance del ciclo di vita SOC 2 / PCI‑DSS 4.0. Usa ogni volta che l’utente menziona API keys, secret keys, prefissi delle chiavi, rotazione delle chiavi, scoping delle chiavi o revoca delle chiavi dopo la partenza di un dipendente – anche se non dice mai “API key management”. Solo lato provider, non consumare l’API di un altro fornitore.
