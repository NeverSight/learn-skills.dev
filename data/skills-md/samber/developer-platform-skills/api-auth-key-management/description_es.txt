Diseña la superficie de autenticación con claves API que una plataforma emite a sus propios consumidores de API: formato de clave con convenciones de prefijo + checksum, almacenamiento hash (irrecuperable) vs cifrado (recuperable), rotación sin tiempo de inactividad con superposición de doble clave, alcance de menor privilegio, propiedad individual vs organización vs cuenta de servicio, comportamiento del panel de autoservicio de claves y gobernanza del ciclo de vida conforme a SOC 2 / PCI‑DSS 4.0. Utilízalo siempre que el usuario mencione claves API, claves secretas, prefijos de claves, rotación de claves, alcance de claves o revocación de claves tras la salida de un empleado, incluso si nunca dice «gestión de claves API». Solo del lado del proveedor, no consumiendo la API de otro proveedor.
