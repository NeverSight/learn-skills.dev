صمم واجهة مصادقة مفاتيح API التي تصدرها المنصة لمستهلكي API الخاصين بها – تنسيق المفتاح مع صيغ البادئة+التحقق من المجموع، التخزين هاش (غير قابل للاسترداد) مقابل التخزين المشفر (قابل للاسترداد)، تدوير بدون توقف مع تداخل المفتاحين، تحديد نطاق الأقل امتياز، الملكية الفردية مقابل ملكية المنظمة مقابل حساب الخدمة، سلوك لوحة المفاتيح ذاتية الخدمة، وإدارة دورة الحياة وفقًا لمعياري SOC 2 / PCI‑DSS 4.0. استخدم ذلك كلما ذكر المستخدم مفاتيح API أو مفاتيح سرية أو بادئات المفاتيح أو تدوير المفاتيح أو تحديد نطاق المفاتيح أو إلغاء المفاتيح بعد مغادرة الموظف – حتى وإن لم يذكر عبارة «إدارة مفاتيح API». فقط جانب الموفر، وليس استهلاك API من بائع آخر. لا تستخدم ذلك لتصميم خادم تفويض OAuth – استخدم samber/developer-platform-skills@oauth2-provider-design بدلاً من ذلك.
