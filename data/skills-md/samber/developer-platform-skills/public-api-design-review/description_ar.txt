تدقيق واجهة برمجة تطبيقات عامة REST الحالية أو المقترحة وفقًا لقائمة مراجعة تخطيطية - تسمية الموارد وURI، صحة طريقة HTTP ورمز الحالة، اتساق تسمية الحقول، اختيار نمط التقسيم إلى صفحات، معايير الفلترة/الترتيب/اختيار الحقول، غلاف خطأ موحّد، ومخاطر التوافقية الخلفية وفق قانون Hyrum - كل اكتشاف يُصنّف إلى "يجب تغييره" أو "تحسين" مع الإشارة إلى القاعدة المستند إليها، بالإضافة إلى برنامج المراجعة المستمر (الجمهور، محفّزات دورة الحياة، سلطة المراجع، الفحص اللغوي، الاتحاد). استخدم هذا الوصف كلما ذكر المستخدم مراجعة تصميم API، أو اتساق REST API، أو تسمية النقاط النهاية، أو نمط التقسيم إلى صفحات، أو حوكمة تصميم API - حتى وإن لم يذكر كلمة "مراجعة تصميم". لا تستخدمه لتصاميم GraphQL - استخدم samber/developer-platform-skills@public-graphql-api-design بدلاً منه.
