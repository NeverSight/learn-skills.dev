Recrutement côté employeur pour les rôles de plateforme développeur - Chef de produit API, Ingénieur/Architecte plateforme, Ingénieur partenaire/intégration. Démystifie d’abord le terme « ingénieur plateforme », car il signifie majoritairement les plateformes internes pour développeurs dans le reste de l’industrie. Calibre la fiche d’évaluation selon l’archétype d’entreprise (infra/API‑first, API publique en supplément, écosystème de partenaires d’entreprise), signale un schéma d’effondrement de périmètre distinct de la taxonomie gardien/pit‑trap de DevRel, puise ses sources dans apidays, et non dans le public interne‑IDP de PlatformCon, construit la boucle à partir de la répartition entretien conception d’API vs conception système, et compare les rémunérations à l’échelle générale ingénierie/PM plutôt qu’à un titre de plateforme sur mesure. À utiliser lorsque l’utilisateur demande comment recruter un ingénieur plateforme, un chef de produit API ou un ingénieur partenaire/intégration, rédiger une offre ou concevoir une boucle. NE PAS l’utiliser pour la préparation de candidats (samber/developer‑platform‑skills@developer‑platform‑career) ou le recrutement DevRel (samber/developer‑relations‑skills@devrel‑hiring).
