Найм со стороны работодателя для ролей в области платформы разработчика — менеджер продукта API, инженер/архитектор платформы, инженер по партнёрствам/интеграциям. Сначала уточняет значение термина «инженер платформы», поскольку в отрасли он почти всегда означает внутренние платформы для разработчиков. Настраивает карточку оценки под архетип компании (инфраструктура/API‑first, подключаемый публичный API, корпоративная экосистема партнёров), отмечает паттерн сужения области, отличающийся от таксономии DevRel «gatekeeper/pit‑trap», использует данные из apidays, а не аудиторию внутреннего IDP PlatformCon, формирует цикл на основе разделения интервью по дизайну API и системному дизайну, и сравнивает компенсацию с общей лестницей инженеров/PM, а не с кастомным названием платформы. Используйте, когда пользователь спрашивает, как нанять инженера платформы, менеджера продукта API или инженера по партнёрствам/интеграциям, написать объявление или спроектировать цикл.
