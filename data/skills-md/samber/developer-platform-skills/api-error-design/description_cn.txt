为公共 API 设计错误界面，使集成者能够自行修复——提供机器可读的错误码分类（扁平目录，代码/子码，Google 风格的域/原因），采用 RFC 9457 problem‑details 包装并带有扩展字段，可操作的错误信息，可重试性信号（retryable 标志，Retry‑After），以及每个端点的错误文档并跟踪 request‑ID。每当用户提及 API 错误码、错误分类、RFC 9457、application/problem+json、4xx/5xx 响应体或令人困惑的 API 错误信息时都使用——即使他们从未说过“错误设计”。不要用于客户端重试机制——请使用 samber/developer-platform-skills@api-idempotency-retry，也不要用于事件和状态页沟通——请使用 samber/developer-platform-skills@api-status-communication 替代。
