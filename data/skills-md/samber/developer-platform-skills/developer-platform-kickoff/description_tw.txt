在開始任何開發平台、公開 API 或整合工作之前——或在未選擇其他平台技能時——將任務導向 samber/developer-platform-skills 中的正確技能，或直接說明沒有合適的，然後啟動或恢復專案的共享平台情境。此規則在每次 API 或平台專案開始時、每次定期平台審查時，以及路由不明確時觸發。當使用者提到開發平台啟動、新的公開 API 計畫、整合面向路線圖、「我需要哪種平台技能」或「我要從哪裡開始我們的公開 API」、平台技能路由或定期平台檢查時，都應使用它——即使他們從未提及具體技能或要求被路由。它涵蓋 REST、GraphQL 與 gRPC 設計、Webhooks、SDK、MCP、OAuth 與 API 金鑰、速率限制、版本管理、開發者入口網站、文件、沙盒、市集以及合作夥伴策略，因此模糊的平台問題應首先歸於此處。輸出一個短列表與有序的技能鏈，絕不輸出設計本身。
