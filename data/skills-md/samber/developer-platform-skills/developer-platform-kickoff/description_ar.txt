قبل البدء في أي عمل يتعلق بمنصة المطورين أو API عمومي أو تكامل - أو كلما لم يتم اختيار أي مهارة منصة أخرى - قم بتحويل المهمة إلى المهارة الصحيحة في samber/developer‑platform‑skills، أو قل بصراحة أنه لا توجد مهارة مناسبة، ثم ابدأ أو استأنف سياق منصة المشروع المشترك. يُفعَّل هذا في كل بدء لمشروع API أو منصة، في كل مراجعة دورية للمنصة، وعند عدم وضوح عملية التوجيه. استخدمه كلما ذكر المستخدم بدء منصة مطورين، برنامج API عمومي جديد، خارطة طريق لسطح التكامل، «ما هي مهارة المنصة التي أحتاجها»، «من أين أبدأ مع API العمومي الخاص بنا»، توجيه مهارة المنصة، أو فحص دوري للمنصة - حتى إن لم يذكروا مهارة أو يطلبوا التوجيه. يغطي التصميم لـ REST وGraphQL وgRPC، webhooks، SDKs، MCP، OAuth ومفاتيح API، حدود المعدل، الإصدارات، بوابات المطورين، الوثائق، بيئات الاختبار، الأسواق، واستراتيجية الشركاء، لذا فإن أي سؤال غير واضح حول المنصة يندرج هنا أولاً. يخرج قائمة مختصرة وسلسلة مهارات مرتبة، ولا يقدم التصميم نفسه.
