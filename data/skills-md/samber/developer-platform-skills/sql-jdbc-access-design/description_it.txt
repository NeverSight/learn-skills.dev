Progetta l'accesso SQL rivolto ai clienti ai dati di un prodotto – un endpoint JDBC/ODBC, una condivisione del warehouse o una superficie di query ospitata. Copre il gate di architettura in base alla frequenza di scansione (condivisione zero‑copy, copia replicata, isolamento di calcolo per tenant), isolamento a livello di motore per tenant con viste sicure e sicurezza a livello di riga, un contratto di stabilità dello schema solo aggiuntivo applicato in CI, connettività con strumenti BI e certificazione dei driver, governance delle query e limiti di costo, emissione di credenziali a breve termine e la struttura dei prezzi. Utilizzalo ogni volta che l'utente menziona JDBC, ODBC, accesso SQL per i clienti, collegare Tableau o Power BI ai dati del prodotto, o la definizione di prezzo di un add‑on SQL – anche se non dice esplicitamente “accesso SQL”. NON usarlo per la consegna di file bulk – utilizza invece samber/developer-platform-skills@bulk-data-sharing-design. 

Rispondi sempre nella lingua dell'utente.
