صمم وصول SQL للعملاء إلى بيانات المنتج — نقطة نهاية JDBC/ODBC، مشاركة مستودع، أو واجهة استعلام مستضافة. يغطي بوابة الهندسة بحسب تردد الفحص (مشاركة بدون نسخ، نسخة مكررة، عزل حوسبة لكل مستأجر)، عزل المستأجر على مستوى المحرك مع وجهات نظر آمنة وأمان على مستوى الصف، عقد استقرار مخطط يقتصر على الإضافة يُفرض في CI، اتصال أدوات ذكاء الأعمال وشهادات التعريف للبرمجيات، حوكمة الاستعلام وحدود التكلفة، إصدار بيانات اعتماد قصيرة الأجل، وشكل التسعير. استخدمه كلما ذكر المستخدم JDBC أو ODBC أو وصول SQL للعملاء أو ربط Tableau أو Power BI ببيانات المنتج أو تسعير إضافة SQL — حتى وإن لم يُذكر "وصول SQL". لا تستخدمه لتسليم ملفات ضخمة — استخدم samber/developer-platform-skills@bulk-data-sharing-design بدلاً من ذلك. يرجى دائمًا الرد بلغة المستخدم.
