قرّر مجموعة لغات SDK لواجهة برمجة تطبيقات عامة — أي اللغات ستحصل على SDK رسمي وفي أي ترتيب، النموذج المُولد مقابل المكتوب يدويًا، مستويات الدعم الرسمية ومجتمعية مع بوابة ترقية، إيقاف SDK وانتهاء صلاحيته، وفصل إصدار SemVer للـ SDK عن إصدارات الـ API وتكرارها. استخدم هذا عندما يذكر المستخدم مكتبات العميل، أو SDKs، أو اللغات التي يجب دعمها أولاً، أو مولد SDK (Stainless، Fern، OpenAPI Generator)، أو SDKs المجتمع، أو إيقاف SDK — حتى وإن لم يذكر صراحةً "محفظة SDK". التركيز على استراتيجية المحفظة فقط، لا على كفاءة SDK واحدة أو نشر السجل. لا تستخدمه لتحديد ما إذا كان يجب تقديم SDKs كواجهة على الإطلاق — استخدم ‎samber/developer-platform-skills@api-integration-surface-strategy‎ بدلاً من ذلك.

الرجاء دائمًا الرد بلغة المستخدم.
