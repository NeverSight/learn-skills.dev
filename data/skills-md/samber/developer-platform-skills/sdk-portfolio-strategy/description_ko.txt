공개 API의 언어‑SDK 포트폴리오를 결정하세요 – 어떤 언어에 공식 SDK를 제공하고 어느 순서로 제공할지, 자동 생성 모델과 수작업 빌드 모델, 승격 게이트가 있는 공식 및 커뮤니티 지원 티어, SDK 폐기 및 종료 시점, 그리고 SDK SemVer를 API 버전 관리 및 릴리스 주기와 분리하는 것 등을 포함합니다. 사용자가 클라이언트 라이브러리, SDK, 우선 지원할 언어, SDK 생성기(예: Stainless, Fern, OpenAPI Generator), 커뮤니티 SDK 또는 SDK 종료에 대해 언급할 때마다 이 지침을 적용하세요 – 설령 “SDK 포트폴리오”라는 표현을 쓰지 않더라도 마찬가지입니다. 포트폴리오 전략에만 초점을 맞추고, 개별 SDK 사용성이나 레지스트리 게시와는 관련하지 않습니다. SDK를 제공할 표면 자체를 결정하는 데는 사용하지 말고, 대신 samber/developer‑platform‑skills@api‑integration‑surface‑strategy를 사용하세요.
