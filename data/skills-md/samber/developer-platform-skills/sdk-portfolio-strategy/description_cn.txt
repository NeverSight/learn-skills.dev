决定公开 API 的语言‑SDK 组合——哪些语言获取官方 SDK、顺序如何、生成式与手写构建模型、官方与社区支持层级及晋升门槛、SDK 弃用和终止生命周期，以及将 SDK 的 SemVer 与 API 版本和发布节奏解耦。每当用户提及客户端库、SDK、首选支持的语言、SDK 生成器（如 Stainless、Fern、OpenAPI Generator）、社区 SDK 或 SDK 退役时，都使用此策略——即便他们未提到“SDK 组合”。仅关注组合策略，而非单个 SDK 的易用性或注册表发布。不要将其用于决定是否提供 SDK 作为接入点——此时请使用 samber/developer-platform-skills@api-integration-surface-strategy。
