Diseña la política de limitación de velocidad que una API pública publica para sus consumidores: el modelo de medición por paradigma (conteo de solicitudes REST vs puntos de costo GraphQL), niveles y números de cuota vs ráfaga, equidad multitenente, encabezados de limitación de velocidad (heredados X-RateLimit-* vs campos RateLimit de IETF), comportamiento 429 y Retry-After, sobrescripciones para empresas y socios, y reglas de notificación de cambios. Utiliza siempre cuando el usuario mencione limitaciones de velocidad, cuotas, niveles de estrangulamiento, respuestas 429, vecinos ruidosos o solicitudes de aumento de límite, incluso si nunca dice “política de limitación de velocidad”. Solo capa de política, no configuración del gateway. No uses para el sobre de error 429; usa samber/developer-platform-skills@api-error-design en su lugar.
