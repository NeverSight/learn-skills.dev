設計一個 SaaS 產品的 MCP 伺服器，作為產品介面的 AI 代理人運作平台──評估建置投資規模，策劃 5‑15 個工作流程工具代理介面，而非直接鏡射 API 端點，命名為寫入工具安全模式（限定憑證、唯讀鎖定、人為參與審批、風險分層的伺服器端門檻、乾跑預檢、冪等性與支出上限），使用 OAuth 2.1 進行遠端託管，對工具介面進行版本管理，MCP 登錄可發現性，並衡量代理人的採用率。當使用者提及 MCP、Model Context Protocol、面向代理人的工具介面、向 AI 代理或程式碼助理公開產品，或 MCP 寫入工具安全──即使未說「MCP 伺服器」時，也請使用此設計。僅設計層面──代碼生成的 MCP 建置技能會腳手架出此規範。
