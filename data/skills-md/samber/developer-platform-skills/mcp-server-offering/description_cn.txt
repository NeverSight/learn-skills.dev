设计一个SaaS产品的MCP服务器，作为AI代理人操作的产品表面——评估构建投资规模，策划一个包含5‑15个工作流工具的代理人表面，而不是单纯镜像API端点，命名为写入工具安全模式（范围化凭证、只读锁定、人机交互审批、风险分层的服务器端门禁、预运行干跑、幂等性和费用上限），使用OAuth 2.1进行远程托管，对工具表面进行版本管理，确保MCP注册表可发现，并衡量代理人采纳率。每当用户提及MCP、Model Context Protocol、面向代理人的工具表面、向AI代理或编码助理暴露产品，或MCP写入工具安全时，都使用此设计——即使他们未提及“MCP服务器”。仅设计层面——代码生成的MCP构建器技能按此规范搭建。
