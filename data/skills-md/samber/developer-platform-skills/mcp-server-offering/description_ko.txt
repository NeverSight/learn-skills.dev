SaaS 제품의 MCP 서버를 AI 에이전트가 작동하는 제품 표면으로 설계하십시오 - 구축 투자 규모를 산정하고, API 엔드포인트를 그대로 복제하는 대신 5~15개의 워크플로우‑툴 에이전트 표면을 큐레이션합니다. 이를 “write‑tool safety patterns”(범위 지정 자격 증명, 읽기 전용 잠금, 인간‑인‑루프 승인, 위험 단계별 서버‑사이드 게이트, 사전 실행 드라이런, 멱등성 및 지출 한도)이라고 명명합니다. OAuth 2.1을 사용한 원격 호스팅, 툴 표면 버전 관리, MCP 레지스트리 탐색 가능성, 그리고 에이전트 채택률 측정을 포함합니다. 사용자가 MCP, Model Context Protocol, 에이전트‑대면 툴 표면, AI 에이전트 또는 코딩 어시스턴트에 제품을 노출하는 경우, 혹은 MCP write‑tool safety에 대해 언급할 때마다 (비록 “MCP 서버”라고 명시하지 않더라도) 위 내용을 적용하십시오. 설계 레이어만 제공하고, 코드 생성 MCP 빌더 스킬은 이 사양을 기반으로 스캐폴딩합니다.
