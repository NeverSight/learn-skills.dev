决定平台为外部开发者和AI代理提供哪些集成接口——REST、GraphQL、gRPC、SQL访问、批量数据共享、Webhook、SDK、CLI、MCP、嵌入式组件——以及它们的构建顺序，按逆向成本和受众而非新颖性排序。每当用户提及先构建哪个API、添加GraphQL或MCP层、制定集成接口路线图、API‑first 与 embedded‑first 的取舍，或缺失的接口阻碍交易时，都使用此规则——即使他们从未提到“集成接口”。仅提供总体策略——一旦选择了某个接口，具体的接口设计归属于如 samber/developer-platform-skills@webhook-platform-design 和 samber/developer-platform-skills@sdk-portfolio-strategy 等兄弟项目。
