決定平台向外部開發者與 AI 代理提供的整合介面──REST、GraphQL、gRPC、SQL 存取、批量資料共享、Webhook、SDK、CLI、MCP、嵌入式元件──以及其建置順序，依照逆向成本與受眾而非新奇度排序。當使用者提到要先建置哪個 API、加入 GraphQL 或 MCP 層、整合介面路線圖、API‑first 與 embedded‑first 的取捨，或是缺少某個介面導致交易受阻時，都要使用此規則，即使他們從未說「整合介面」這個詞。僅提供總體策略——一旦選定介面，具體介面的設計交由如 samber/developer‑platform‑skills@webhook‑platform‑design 與 samber/developer‑platform‑skills@sdk‑portfolio‑strategy 等兄弟專案負責。
