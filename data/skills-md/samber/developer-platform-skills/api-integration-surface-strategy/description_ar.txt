قرر أي واجهات التكامل التي تقدمها المنصة للمطورين الخارجيين وعوامل الذكاء الاصطناعي - REST، GraphQL، gRPC، وصول SQL، مشاركة البيانات الضخمة، webhooks، SDKs، CLI، MCP، المكونات المدمجة - وما هو ترتيب بنائها، يتم ترتيبه وفق تكلفة العكس والجمهور بدلاً من الحداثة. استخدم ذلك كلما ذكر المستخدم أي API يجب بناؤه أولاً، أو إضافة طبقة GraphQL أو MCP، أو خريطة طريق لواجهة التكامل، أو API‑first مقابل embedded‑first، أو واجهة مفقودة تعيق الصفقات - حتى وإن لم يذكر كلمة "واجهة التكامل". استراتيجية شاملة فقط - بمجرد اختيار الواجهة، يصبح تصميم كل واجهة مسؤولية الأشقاء مثل samber/developer‑platform‑skills@webhook‑platform‑design و samber/developer‑platform‑skills@sdk‑portfolio‑strategy.
