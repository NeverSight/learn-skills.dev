Diseña un programa estructurado de reuniones empresariales 1:1 para un evento técnico: decide si se debe ejecutar, cómo se emparejan las dos partes (directorio, intermediación, aceptación mutua, clasificación puntuada), cómo se reservan los espacios dentro de la cuadrícula, qué cuota de reuniones puede comprometer honestamente un paquete de patrocinio, cómo se absorbe la ausencia de una reunión reservada y qué medir. Úsalo siempre que se solicite organizar reuniones 1:1 programadas en un evento, gestionar emparejamientos comprador‑vendedor o fundador‑inversor, prometer a un patrocinador un número de reuniones o crear un calendario de reuniones reservadas. Empareja dos poblaciones para conversaciones de negocios. NO lo uses para la formación de equipos en hackathon: usa samber/dev-event-organizer-skills@hackathon-team-formation, ni para el área de exposición: usa samber/dev-event-organizer-skills@event-booth-experience.
