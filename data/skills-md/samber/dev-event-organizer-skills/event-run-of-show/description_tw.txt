在排程發布後，撰寫並執行技術活動當天的節目流程——逐分鐘的作業手冊、當天角色分配（主持人、講者介紹者、會議室負責人、當值組織者）、每個環節的提示表、僅供組織者使用且與參與者通訊渠道分離的溝通頻道、升級路徑與即時事故回應、經過驗證的交接班輪替以及收尾工作。當使用者提及當天流程表、提示表、主持人或會議室負責人的角色、組織者無線電或 Slack 頻道、交接班，或在會議超時時即時決定裁剪內容時，皆適用——即使他們未曾說出「節目流程」這個詞。請勿用於建立網格本身——應使用 samber/dev-event-organizer-skills@event-schedule-design 代替。請始終以使用者的語言回覆。
