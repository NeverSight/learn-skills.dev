Genehmigen und koordinieren Sie von Dritten organisierte Satellitenveranstaltungen rund um eine technische Veranstaltung – die Prüfungsinstanz, Terminabstimmung mit dem veröffentlichten Kalender, Regeln zur Namens‑ und Logo‑Verwendung sowie den Hinweis, wofür das Hauptevent keine Garantie übernimmt. Verwenden Sie dies immer dann, wenn eine Nutzergruppe, ein Sponsor oder ein Teilnehmer während der Veranstaltungsdaten eine Party, ein Treffen, ein Abendessen, einen Workshop oder eine After‑Party veranstalten möchte, wenn jemand bereits den Namen der Veranstaltung auf seiner eigenen Seite nutzt oder wenn Randveranstaltungen mit dem Hauptprogramm kollidieren – selbst wenn sie nie den Ausdruck „Side Event“ verwenden. Oft ist es die richtige Entscheidung, nichts zu genehmigen; leitet Marken‑ und Haftungsrisiken an die Rechtsabteilung weiter. Verwenden Sie dies NICHT für das eigene Abendprogramm des Veranstalters – verwenden Sie stattdessen samber/dev-event-organizer-skills@event‑official‑social‑program.
