Antes de responder a cualquier solicitud de organización de eventos que abra un nuevo proyecto o una nueva sesión, ejecuta primero este enrutador: asigna la tarea a la colección de 71 habilidades samber/dev-event-organizer-skills, o indica claramente que ninguna encaja, y arranca o reanuda el contexto compartido del proyecto para que la siguiente sesión comience caliente. Esto se activa en un estado conversacional, no en un tema; invócalo al iniciar cada proyecto de evento incluso cuando las habilidades de la colección ya se estén usando a diario en otro evento, en cada chequeo recurrente del mismo proyecto y siempre que el enrutamiento entre elementos hermanos sea confuso. Cubre lanzamientos de conferencias, meetups y hackatones, “qué habilidad de evento necesito”, “por dónde empiezo a organizar este evento”, enrutamiento de habilidades del organizador de eventos y chequeos recurrentes de eventos. Utilízalo siempre que alguien describa un problema de organización de eventos sin nombrar una habilidad, incluso si nunca dice “lanzamiento”, “enrutamiento” o “empezar”.
