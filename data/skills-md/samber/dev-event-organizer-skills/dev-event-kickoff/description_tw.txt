在回覆任何開啟新專案或新會話的活動組織請求之前，先執行此路由器——它會將任務映射到 71‑skill samber/dev-event-organizer-skills 集合，或直接說明沒有適合的，並啟動或恢復專案的共用情境，使下一個會話能暖身開始。這是在對話狀態下觸發，而非在主題上——即使該集合的技能已在其他活動中每日使用，也要在每一次活動專案開始時、在同一專案的每次例行檢查時，以及在兄弟專案之間的路由不明確時呼叫它。涵蓋會議、聚會與黑客松的啟動、「我需要哪個活動技能」、「我該從何開始組織此活動」、活動組織者技能路由以及例行的活動檢查。無論何時有人描述活動組織問題卻未提及具體技能，即使他們從未說過「啟動」、「路由」或「開始」，也請使用此規則。
