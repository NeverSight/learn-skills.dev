Запустите процесс рецензирования и отбора заявок CFP, собранных для технического мероприятия, — состав комиссии, механизм слепого рецензирования (скрытие на платформе versus роль отдельного анонимизатора) и его ограничения, критерии оценки, многоэтапные каскады «оценка → шортлист → соответствие программе», отвод участников при конфликте интересов, балансировка разнообразия и выступлений новичков, управление уровнем принятия, а также коммуникация по принятию/отклонению/в лист ожидания. Применяйте этот процесс всякий раз, когда пользователь упоминает программный комитет, сетку оценки докладов, слепой обзор CFP, выбор докладов для программы, конфликты интересов у рецензентов или письма о приёме и отклонении — даже если слово «отбор» не используется. НЕ используйте его для разработки самого Call for Papers — для этого применяйте samber/dev-event-organizer-skills@event-cfp-design.
