Ejecuta el proceso de ventas de patrocinadores para un evento técnico, desde la lista de objetivos hasta el sí firmado: construcción y puntuación de la lista de objetivos, alcance cronometrado según el cierre del presupuesto del patrocinador del año fiscal, elección del canal de primer contacto (introducción cálida, solicitud de referencia, correo frío bajo la etiqueta específica del patrocinador), la llamada exploratoria, cadencias de seguimiento limitadas, manejo de objeciones, seguimiento del pipeline y renovación frente a nuevos patrocinadores como movimientos distintos. Utilízalo siempre que el usuario mencione encontrar patrocinadores, un correo de alcance a patrocinadores, presentar una patrocinación, una objeción de patrocinador o perseguir renovaciones, incluso si nunca dicen “alcance”. No lo uses para la tabla de precios: usa samber/dev‑event‑organizer‑skills@event‑sponsor‑pricing; la entrega post‑venta es samber/dev‑event‑organizer‑skills@event‑sponsor‑fulfillment.
