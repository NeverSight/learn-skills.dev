Erstelle ein Sponsoring‑Prospekt für ein technisches Event – das veröffentlichte Dokument, das ein bestehendes Sponsor‑Wertversprechen und eine Preisliste in ein Credibility‑before‑Price‑Abschnitts‑Anatomie verpackt, eine Check‑Mark‑Stufentabelle mit echten, offengelegten Obergrenzen, benannte Benefits pro Stufe und Add‑On‑Pakete, einen Abschnitt mit Nachweisen zur Zielgruppen‑Demografie und ein Verteilungsformat (Webseite oder PDF‑Kit), das bei jeder Ausgabe aktualisiert wird. Verwende es stets, wenn der Nutzer von einem Sponsor‑Deck, einem Sponsoring‑Kit, einem Sponsor‑Pakete‑Dokument, einem Prospekt oder einer Sponsor‑Seite für eine Konferenz, ein Treffen oder einen Hackathon spricht – selbst wenn er nie das Wort „Prospekt“ verwendet. Gib niemals Garantien, erfundene Knappheiten oder Lead‑Listen‑Vorteile aus, die das Event nicht liefern kann. Verwende es NICHT, um Preise festzulegen – verwende stattdessen samber/dev-event-organizer-skills@event-sponsor-pricing.
