Générez ou mettez à jour le JSON du parseur de composants Pixso Design‑to‑Code (`componentParsers` / configuration du composant) à partir du fichier Pixso Desktop actuel, de la sortie `get_all_components`, d’une bibliothèque de composants locale ou d’une bibliothèque de composants open source. Utilisez‑le lorsque l’utilisateur demande de créer, extraire, rédiger, valider ou mettre à jour la configuration JSON du parseur de composants. Confirmez toujours d’abord la ressource de code cible, récupérez les faits actuels sur les composants Pixso via le MCP de Pixso, examinez le DSL du nœud représentatif avant les correspondances complexes, et ne générez jamais de correspondances à partir de données en cache, de sorties périmées ou d’hypothèses. Veuillez toujours répondre dans la langue de l’utilisateur.
