أنشئ أو حدّث ملف JSON لمحلل مكوّنات Pixso Design-to-Code (`componentParsers` / تكوين المكوّن) من ملف Pixso المكتبي الحالي، مخرجات `get_all_components`، مكتبة مكوّنات محلية، أو مكتبة مكوّنات مفتوحة المصدر. استخدم هذا عندما يطلب المستخدم إنشاء أو استخراج أو صياغة أو التحقق من صحة أو تحديث تكوين JSON لمحلل المكوّنات. تأكد دائمًا من تحديد مورد الشيفرة المستهدف أولاً، واستخرج حقائق مكوّنات Pixso الحالية عبر Pixso MCP، وتفحص تمثيل DSL للعقد قبل إجراء أي تحويلات معقدة، ولا تقم أبدًا بإنشاء التحويلات استنادًا إلى بيانات مخزنة مؤقتًا أو مخرجات قديمة أو تخمينات.
