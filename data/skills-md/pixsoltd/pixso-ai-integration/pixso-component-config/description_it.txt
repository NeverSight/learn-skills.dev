Genera o aggiorna il parser JSON dei componenti Pixso Design-to-Code (`componentParsers` / configurazione del componente) dal file desktop Pixso corrente, dall'output `get_all_components`, da una libreria locale di componenti o da una libreria di componenti open source. Usalo quando l'utente richiede di creare, estrarre, redigere, convalidare o aggiornare il JSON di configurazione del parser dei componenti. Conferma sempre prima la risorsa di codice di destinazione, recupera i fatti attuali sui componenti Pixso tramite Pixso MCP, ispeziona il DSL dei nodi rappresentativi prima di effettuare mappature complesse e non generare mai mappature da dati in cache, output obsoleti o congetture.

Rispondi sempre nella lingua dell'utente.
