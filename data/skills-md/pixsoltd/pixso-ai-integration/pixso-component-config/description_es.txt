Genera o actualiza el JSON del analizador de componentes de Pixso Design-to-Code (`componentParsers` / configuración del componente) a partir del archivo de escritorio actual de Pixso, la salida de `get_all_components`, una biblioteca de componentes local o una biblioteca de componentes de código abierto. Úsalo cuando el usuario solicite crear, extraer, redactar, validar o actualizar el JSON de configuración del analizador de componentes. Siempre confirma primero el recurso de código objetivo, recupera los datos actuales de los componentes de Pixso a través de Pixso MCP, inspecciona el DSL de nodos representativo antes de realizar asignaciones complejas, y nunca generes asignaciones a partir de datos en caché, salidas obsoletas o suposiciones.

Por favor, responde siempre en el idioma del usuario.
