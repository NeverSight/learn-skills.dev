Generieren und pflegen Sie Projektdokumentation aus dem Code (README, API‑Referenz, Architekturnotizen, Einrichtungsdokumentation). Wiederholbar, um die Dokumente nach Refactorings synchron zu halten. Verwenden Sie es, wenn ein Projekt keine Dokumentation hat, wenn Dokumente vom Code abgewichen sind oder wenn ein neuer Mitwirkender das Projekt nicht anhand der bestehenden Dokumentation zum Laufen bringen kann.
