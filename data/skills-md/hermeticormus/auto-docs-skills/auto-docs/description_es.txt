Generar y mantener la documentación del proyecto a partir del código (README, referencia de API, notas de arquitectura, documentación de instalación). Reejecutable para mantener la documentación sincronizada después de refactorizaciones. Úsalo cuando un proyecto no tiene documentación, tiene documentación que se ha desviado del código, o cuando un nuevo colaborador no puede ponerlo en marcha con la documentación existente.
