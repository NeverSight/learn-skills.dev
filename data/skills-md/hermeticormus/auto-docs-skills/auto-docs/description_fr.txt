Générez et maintenez la documentation du projet à partir du code (README, référence API, notes d’architecture, documentation d’installation). Réexécutable pour garder la documentation synchronisée après les refactorisations. À utiliser lorsqu’un projet n’a pas de documentation, que la documentation a dérivé du code, ou lorsqu’un nouveau contributeur ne parvient pas à le faire fonctionner à partir de la documentation existante.
