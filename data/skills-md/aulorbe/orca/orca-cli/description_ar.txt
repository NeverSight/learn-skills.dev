تشغيل شجرة العمل المدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والمواد المُنتجة، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل هذا على استخدام git worktree العادي، أو PTY المؤقتة، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم "Computer Use" فقط عندما يتطلب الأمر التحكم في نافذة مرئية لا يمكن لسطر الأوامر أو نظام الملفات أو API التعامل معها.
