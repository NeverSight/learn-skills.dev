`orca` CLI を使って、Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザを操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、純粋な git worktree や臨時の PTY、あるいは Computer Use よりもこちらを優先します。CLI、ファイルシステム、API では対処できない可視ウィンドウの GUI 操作が必要なときだけ Computer Use を使用してください。

必ずユーザーの言語で回答してください。
