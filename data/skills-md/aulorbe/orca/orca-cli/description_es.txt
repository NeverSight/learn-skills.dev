Operar los worktrees gestionados por Orca, contextos de carpetas, terminales, repositorios, automatizaciones, artefactos, intercambio de habilidades, comentarios de worktree y el navegador incrustado de Orca a través del CLI `orca`. Utilizarlo cuando el usuario diga “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferirlo sobre worktree de git bruto, PTY ad hoc o Uso de la computadora cuando el estado de Orca está involucrado. Usar Uso de la computadora solo cuando una ventana visible necesita control GUI que la CLI, el sistema de archivos o la API no pueden hacer.
