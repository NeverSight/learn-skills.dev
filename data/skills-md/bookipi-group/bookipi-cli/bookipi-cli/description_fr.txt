Exécutez les opérations de petite entreprise de l'utilisateur dans Bookipi via le CLI `bookipi` : factures, facturation, paiements, dépenses, reçus, clients, affaires, propositions, contrats, signature électronique, réunions, calendrier, planification, rapports, tableaux de bord, analyses.  
Les phrases déclencheuses incluent : qui me doit de l'argent, envoyer INV‑650, marquer payé, rappeler en retard, enregistrer ce reçu, chercher Wayne, qui est mon plus gros client, qu’est‑ce qui est sur mon calendrier, afficher mes réunions, briefing du matin, rédiger une proposition, envoyer le MSA, rédiger le contrat, Bruce a‑t‑il signé, marquer l’affaire gagnée, montrer le revenu, créer un tableau de bord, digest hebdomadaire, insights, meilleurs clients, e‑mail à Maria, relancer Acme.  
Déclenchez également sur les demandes de menu dans un contexte professionnel — montrez‑moi le menu Bookipi, montrez‑moi le menu, menu principal, que pouvez‑vous faire.  
Déclenchez aussi sur le téléchargement d’images/PDF de reçus ou de factures, numéros de facture comme INV‑123, identifiants comme @i1 ou @c1, et toute question concernant le compte Bookipi de l’utilisateur, l’entreprise ou l’identité connectée.
