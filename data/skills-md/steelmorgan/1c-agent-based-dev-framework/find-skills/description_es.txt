Ayuda a los usuarios a descubrir e instalar habilidades del agente cuando hacen preguntas como “¿cómo hago X?”, “buscar una habilidad para X”, “¿existe una habilidad que pueda…?” o expresan interés en ampliar sus capacidades. Esta habilidad debe usarse cuando el usuario está buscando una funcionalidad que podría existir como una habilidad instalable.
