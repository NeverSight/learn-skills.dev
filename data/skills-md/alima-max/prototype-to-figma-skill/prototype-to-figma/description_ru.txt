Преобразует рабочий прототип Claude Code в структурированный файл дизайна Figma, разбивая каждый поток взаимодействия на отдельные кадры, используя компоненты системы дизайна целевого файла и аннотируя детали взаимодействия изначально в Figma. Используйте этот навык всякий раз, когда пользователь просит превратить прототип в фреймы Figma, сгенерировать спецификации дизайна на основе прототипа, создать передачу Figma из кода, разбить прототип на состояния или сделать прототип доступным для проверки межфункциональными партнерами. Также срабатывает, когда пользователь упоминает «прототип для Figma», «обзор дизайна на основе прототипа», «асинхронную обратную связь по прототипу», «разбить прототип на потоки», «спецификации Figma из кода» или хочет сделать рабочий прототип понятным для нетехнических заинтересованных сторон. Даже если пользователь просто говорит «поместите это в Figma» или «сделайте это доступным для просмотра» в контексте прототипа, используйте этот навык.
