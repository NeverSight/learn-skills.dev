Cette compétence doit être utilisée lorsque l'utilisateur demande à « faire pivoter les clés SSH », « régénérer les clés SSH », « remplacer les clés SSH », « renouveler les clés SSH », ou lorsque l'agent a besoin d'un accès SSH à une VM déployée pour le dépannage (journaux, débogage, accès à la base de données) mais découvre que le fichier de clé SSH attendu est absent du disque local (par exemple `~/.ssh/<nom-du-repo>` n'existe pas). Utilisez‑la également lorsque l'utilisateur mentionne « clé SSH perdue », « clé SSH introuvable », « impossible de se connecter en SSH au serveur », « permission refusée SSH », « déplacé vers un nouvel ordinateur » ou « dépôt cloné sur une autre machine ».

Veuillez toujours répondre dans la langue de l'utilisateur.
