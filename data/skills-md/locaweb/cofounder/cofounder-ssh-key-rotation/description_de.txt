Diese Fähigkeit sollte verwendet werden, wenn der Benutzer darum bittet, „SSH‑Schlüssel zu rotieren“, „SSH‑Schlüssel zu regenerieren“, „SSH‑Schlüssel zu ersetzen“, „SSH‑Schlüssel zu erneuern“ oder wenn der Agent SSH‑Zugriff auf eine bereitgestellte VM zur Fehlersuche (Protokolle, Debugging, Datenbankzugriff) benötigt, jedoch feststellt, dass die erwartete SSH‑Schlüsseldatei auf der lokalen Festplatte fehlt (z. B. existiert `~/.ssh/<repo-name>` nicht). Verwenden Sie sie auch, wenn der Benutzer von einem „verlorenen SSH‑Schlüssel“, „SSH‑Schlüssel nicht gefunden“, „kann nicht per SSH auf Server zugreifen“, „Zugriff verweigert bei SSH“, „umgezogen auf einen neuen Computer“ oder „Repo auf einem anderen Rechner geklont“ spricht.

Bitte immer in der Sprache des Benutzers antworten.
