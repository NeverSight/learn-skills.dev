Estrategia de pruebas automatizadas de dos capas para aplicaciones web con Go + React. Cubre pruebas unitarias/integración del backend (Go) y pruebas de componentes del frontend (Vitest). Las pruebas se escriben en paralelo con el código de la aplicación: cada controlador recibe un archivo de prueba, cada componente interactivo recibe un archivo de prueba. Usa esta habilidad siempre que el usuario solicite probar, ejecutar pruebas, añadir pruebas o verificar la aplicación.

Por favor, responde siempre en el idioma del usuario.
