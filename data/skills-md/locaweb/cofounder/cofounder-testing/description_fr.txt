Stratégie de test automatisé à deux niveaux pour les applications web Go + React. Couvre les tests unitaires/intégration du backend (Go) et les tests de composants frontend (Vitest). Les tests sont écrits en même temps que le code de l'application — chaque gestionnaire reçoit un fichier de test, chaque composant interactif reçoit un fichier de test. Utilisez cette compétence chaque fois que l'utilisateur demande de tester, d'exécuter des tests, d'ajouter des tests ou de vérifier l'application.

Veuillez toujours répondre dans la langue de l'utilisateur.
