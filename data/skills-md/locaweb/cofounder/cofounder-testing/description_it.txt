Strategia di test automatizzati a due livelli per applicazioni web Go + React. Copre i test unitari/integrativi del backend (Go) e i test dei componenti frontend (Vitest). I test sono scritti in parallelo al codice dell'applicazione — ogni handler ottiene un file di test, ogni componente interattivo ottiene un file di test. Usa questa competenza ogni volta che l'utente chiede di testare, eseguire i test, aggiungere test o verificare l'applicazione.

Per favore rispondi sempre nella lingua dell'utente.
