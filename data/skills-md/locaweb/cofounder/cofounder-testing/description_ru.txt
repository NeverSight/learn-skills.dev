Двухуровневая автоматизированная стратегия тестирования для веб‑приложений на Go + React. Охватывает модульные/интеграционные тесты бэкенда (Go) и тесты компонентов фронтенда (Vitest). Тесты пишутся одновременно с кодом приложения — каждому обработчику соответствует файл теста, каждому интерактивному компоненту — файл теста. Используйте этот навык, когда пользователь просит протестировать, запустить тесты, добавить тесты или проверить приложение.

Пожалуйста, всегда отвечайте на языке пользователя.
