معمارية كامل‑المكدس باستخدام Go + React مع تطوير محلي تكراري. استخدم هذه المهارة عند إنشاء هيكل تطبيق جديد، إضافة ميزات، إصلاح الأخطاء، تشغيل حلقة التطوير المحلي، أو عندما يطلب المستخدم "تشغيل التطبيق محليًا"، "تشغيل التطبيق على حاسوبي"، "بدء التطبيق"، "rodar o programa"، "rodar o app"، "executar localmente"، أو أي طلب مكافئ لإطلاق التطبيق في بيئتهم المحلية. يغطي تخطيط المشروع، ترحيلات قاعدة البيانات، توليد شفرة sqlc، Supabase/Postgres محلي عبر Podman، امتدادات Postgres (pgmq، pg_cron، pgroonga، pgvector، pg_jsonschema، LISTEN/NOTIFY)، تقديم الصفحات العامة مسبقًا لتحسين محركات البحث وملفات الزاحف للذكاء الاصطناعي، ودورة التغذية الراجعة كتابة‑اختبار‑إعادة.
