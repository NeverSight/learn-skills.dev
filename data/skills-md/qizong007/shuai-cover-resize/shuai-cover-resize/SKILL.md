# Cover Resize

把源封面当作唯一母版，为每个目标比例独立重构画面。保持内容含义不变，允许改变元素的位置、大小、换行、裁切与留白。

## 1. 确定目标

1. 读取用户明确指定的比例；未指定时使用 `4:3、3:4、16:9`。
2. 用户明确要求公众号版时加入 `1:1` 和 `2.35:1`；明确要求 X 文章版时加入 `5:2`；只指定某个比例时，仅生成指定比例。
3. 运行：

   ```bash
   python3 <skill-dir>/scripts/detect_ratio.py <source-image> [目标比例...]
   ```

4. 若原图已符合某个目标比例，直接复用原图，不重复生成该版本。
5. 若用户的额外 prompt 要求修改画面，即使比例已符合也执行编辑。
6. 把额外 prompt 作为该次任务的最高视觉指令，但除非用户明确要求，不得改写标题、主题、人物身份或品牌信息。

## 2. 锁定母版信息

编辑前先检查原图，内部列出以下内容：

- 原图尺寸与比例。
- 所有可见文字，逐字记录大小写、数字、标点和行序。
- 核心人物及其身份特征、表情、服装和人数。
- 核心物体、背景、品牌色、字体气质和整体风格。
- 信息层级：主标题、副标题、人物、辅助图形。

看不清的文字不得猜测。优先保留原始文字区域；仍无法可靠保留时，请用户提供文案。

## 3. 重构原则

- 从原图分别生成每个目标比例；不得用已生成的版本继续改下一个比例。
- 各比例任务互相独立，可并行提交生成，不必串行等待。
- 高保真：保持原图的细节、质感、字体边缘和清晰度，不得出现重绘感、涂抹感或画质劣化；输出分辨率不低于原图等效像素，且不低于目标平台的最低分辨率（见第 4 节）。
- 优先使用扩图、重排、移动、缩放和重新换行；禁止横向或纵向拉伸。
- 保持主题、叙事、标题原文、品牌识别、人物身份和核心物体不变。
- 允许改变背景延展、装饰元素、人物景别、文字位置与换行，以适应新画布。
- 标题必须逐字一致。不得翻译、润色、缩写、补字或生成伪文字。
- 保持人物脸部、发型、服装和年龄一致；不得新增人物、重复人物或改变肢体结构。
- 给文字和脸部留出安全区，不贴边，不被平台 UI 或裁切遮挡。
- 若“保留全部元素”和“可读性”冲突，优先保留主题、标题、人物身份和核心物体，弱化非关键装饰。

## 4. 平台构图

### 1:1｜公众号方图

- 使用紧凑、中心明确的方形构图，保证标题和核心视觉在消息列表及分享卡片中清晰可辨。
- 默认保留主题人物或核心物体，减少横向装饰与非关键留白，避免简单截取横版中央区域。
- 标题可重新分为 2–4 行；四边保留安全区，不让文字、脸部或 Logo 贴边。
- 输出分辨率不低于 1080×1080。

### 3:4｜小红书 / 视频号竖版

- 使用竖版高密度构图，第一眼看清人物和主标题。
- 默认保留人物，突出脸部，并露出上半身或更多身体，避免只剩大头。
- 让标题适合手机阅读，可重新分为 2–4 行；底部预留 UI 安全区。
- 视觉可以更亲近、更生活化，但不得擅自加入“小红书风”贴纸或新文案。
- 视频号竖版沿用该比例，优先保证信息流中的人物、标题和核心物体一眼可辨。
- 输出分辨率不低于 1080×1440。

### 4:3｜B站 / 视频号横版

- 使用均衡、信息清晰的横版构图。
- 默认保留人物，露出上半身或半身；让人物和标题形成明确左右或前后层级。
- 标题字号醒目，缩略图状态下仍可读；避免元素挤在四边。
- 视频号横版沿用该比例，保持核心信息居中且完整，避免预览界面遮挡人物和标题。
- 输出分辨率不低于 1200×900。

### 16:9｜YouTube

- 使用强焦点横版构图，人物与标题尽量左右分区。
- 默认保留人物，并比原图多露出身体和手势；避免脸部被标题遮挡。
- 增强主体与背景的明暗或色彩对比，但保持原风格与品牌色。
- 四边保留约 5%–8% 安全区，避免关键信息贴边。
- 输出分辨率不低于 1280×720。

### 5:2｜X 文章

- 使用编辑感、留白充足的超宽构图，以图片、标题和氛围为主。
- 尽可能不保留真人。优先通过背景延展、核心物体、场景或抽象视觉继续表达原主题。
- 若人物身份本身就是主题，且移除会改变含义，则仅保留为较小的环境人物；不要使用大头像。
- 标题保持简洁清楚，关键信息避开四边，防止在预览或分享卡片中被裁切。
- 输出分辨率不低于 1500×600。

### 2.35:1｜公众号

- 使用编辑感、留白充足的超宽构图，以图片、标题和氛围为主。
- 默认不出现人物。通过背景延展、物体、场景或抽象视觉继续表达原主题。
- 若人物身份本身就是主题且移除会改变含义，则保留为较小的环境人物；不要使用视频式大头像。
- 主标题保持简洁清楚，并避开过宽拉散或贴边。
- 公众号头图比例为 2.35:1；常用的 900×383 是该比例的整数像素近似值。输出分辨率不低于 900×383。

## 5. 给图像编辑模型的指令结构

每个比例单独提交一次编辑请求，并明确这是“基于源图的版式重构”。指令至少包含：

```text
将所附源封面重构为 [目标比例] 的 [平台] 封面。
保持不变：[逐字标题]、[主题]、[人物身份/核心物体]、[品牌色和风格]。
允许调整：画布扩展、构图、元素位置与大小、文字换行、人物景别、背景延展。
平台构图：[对应平台规则]。
高保真：保持原图的细节、质感、字体边缘和清晰度，禁止重绘感、涂抹感和画质劣化。
输出分辨率：不低于 [平台最低分辨率]，且不低于原图等效像素。
禁止：拉伸、改字、伪文字、新增人物、身份漂移、重复肢体、删除核心信息。
额外要求：[用户 prompt；没有则写“无”]。
最终画面必须严格为 [目标比例]。
```

明确要求模型编辑所附原图，不要从文字描述重新想象一张新封面。

## 6. 验收与重试

逐张检查：

1. 像素比例正确，且分辨率不低于该平台最低要求。
2. 标题逐字正确且缩略图可读。
3. 主题、人物身份、核心物体与原图一致。
4. 人物数量正确，无畸形、重复脸或多余肢体。
5. 构图符合目标平台，脸和文字未贴边或被遮挡。
6. 没有新增文案、Logo、水印或无关元素。
7. 整体色彩、光线和质感与母版连续，细节清晰，无重绘感或画质劣化。

任一项失败，只重试失败的比例，并在修正 prompt 中点名错误。文字仍不稳定时，优先生成无字底图，再用可靠排版工具叠加原文，不接受错误文字成品。

## 7. 交付

- 输出文件放在源图所在目录，使用 `<原文件名>__1x1`、`__4x3`、`__3x4`、`__16x9`、`__5x2`、`__235x100` 命名。
- 目标文件已存在时，不覆盖，依次追加序号后缀，如 `__16x9-2`、`__16x9-3`。
- 对已符合比例且没有额外编辑要求的版本，标注“复用原图”，不要制造重复文件。
- 简要列出已生成、已复用和未通过验收的版本。
