Generieren Sie CLAUDE.md und CONVENTIONS.md für ein brandneues Projekt durch ein kurzes Interview und erstellen Sie das Specs/ Directory mit weiterentwickelter Bigpowers-Struktur (Product/, Tech-Architecture/, Verifications/, Epics/Archive/). Einstiegspunkt für Greenfield-Projekte. Wird verwendet, wenn ein neues Projekt von Grund auf neu gestartet wird, wenn der Benutzer darum bittet, KI-Agentenkonventionen einzurichten, oder wenn es noch keine CLAUDE.md gibt.
