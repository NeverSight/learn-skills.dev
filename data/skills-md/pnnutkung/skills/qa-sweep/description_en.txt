QA of a whole repo or one feature (a path or a ticket), with no diff needed: finds defects, weak tests and test gaps, proves each one in code, and adds the regression tests that close them to the project's own unit, integration and e2e suites. A behavior nobody wrote down becomes a question to the user, never an assumption. It only adds tests: no product-code edits, no commits. Use for 'find missing tests', 'find weak tests', 'QA this feature', 'regression tests for ...', 'which modules lack e2e tests', or a QA pass over a module or a ticket.
