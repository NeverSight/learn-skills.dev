Chiedi alla persona i segreti e gli altri valori privati (chiavi API, token, password, stringhe di connessione) tramite il CLI di query locale, che apre un prompt fluttuante sul loro Mac, invece di chiedere loro di incollare i valori nella chat. Usa questa modalità ogni volta che un'attività richiede una credenziale o una variabile d'ambiente che l'agente non possiede, come una chiave API mancante, un comando che fallisce segnalando una variabile non impostata, un file .env che necessita di un valore o un test che richiede credenziali live.

Per favore, rispondi sempre nella lingua dell'utente.
