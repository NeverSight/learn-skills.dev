Überprüft Codeänderungen auf Fehler, Sicherheitsprobleme und Qualitätsprobleme. Verwenden Sie diese Option für eine einmalige Überprüfung eines PRs, eines Branches oder eines lokalen Diffs. Verwenden Sie für große PRs, die sich über mehrere Subsysteme erstrecken, die Option „Deep-Review“ (`.agents/skills/deep-review/`).
