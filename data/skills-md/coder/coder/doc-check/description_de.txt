Überprüft einen PR, einen Branch oder einen lokalen Diff auf Richtigkeit und Vollständigkeit der Dokumentation. Überprüft, ob jede Aussage in der Dokumentation im Code zutrifft, ob für das dem Benutzer sichtbare Verhalten eine Dokumentation vorhanden ist und ob neue oder bearbeitete Dokumentationen den Inhaltsrichtlinien und dem Styleguide entsprechen. Verwenden Sie es, bevor Sie einen PR öffnen oder aktualisieren, der sich auf docs/ oder das Verhalten gegenüber Benutzer:innen bezieht, sowie in der CI. Um Dokumentationen zu verfassen oder umzustrukturieren, verwenden Sie write-docs.
