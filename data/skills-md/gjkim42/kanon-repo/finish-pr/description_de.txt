Beende einen PR, indem du wiederholt eine Kelos‑Überprüfung anforderst, auf deren Prüfung wartest, gültige Review‑Erkenntnisse adressierst, Commits squashst und den PR aktualisierst, bis eine Überprüfung genehmigt und diese Iteration abgeschlossen ist. Verwende dies, wenn der Benutzer „finish‑pr“ sagt oder nach dieser Review‑und‑Fix‑Schleife fragt. Standardmäßig bezieht es sich auf den PR des aktuellen Branches.
