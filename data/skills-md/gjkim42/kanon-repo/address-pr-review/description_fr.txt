Examinez les commentaires sur un PR et répondez aux conclusions qui sont valides et requises. À utiliser lorsque l'utilisateur dit « adresse-pr-révision », demande de répondre à la révision du PR, de gérer ou d'appliquer les commentaires de révision ou de réviser les commentaires sur un PR, ou de corriger ce que les évaluateurs ont demandé. La valeur par défaut est le PR de la branche actuelle lorsqu'aucune n'est nommée. Cette compétence change le code ; ce n'est pas une passe de révision.
