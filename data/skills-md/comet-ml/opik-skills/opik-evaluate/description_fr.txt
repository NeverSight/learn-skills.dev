Construisez une évaluation LLM et exécutez‑la contre l’application, en renvoyant une expérience Opik avec des scores et son lien. Choisissez une suite de tests avec des assertions de juge ou un jeu de données avec métriques, puisez les cas à partir de traces ou de données synthétiques, notez d’abord les heuristiques puis les juges à mode d’échec unique, exécutez côté client via le SDK ou côté serveur pour les cibles uniquement prompt, et récupérez les scores. Couvre l’évaluation RAG, l’analyse d’erreurs, la rédaction et la validation de juges LLM contre des étiquettes humaines, et l’audit d’un pipeline d’évaluation existant. Utilisez pour « évaluer mon agent », « mesurer la qualité », « construire une évaluation », « rédiger un juge LLM pour les hallucinations », « auditer notre pipeline d’évaluation », « à quel point mon RAG est bon », « mettre en place des évaluations pour ceci ». Pas pour avant/après sur une suite existante (utilisez comparer), un cas de régression (utilisez test), le scoring du trafic de production (utilisez évaluation en ligne), ou la décision ship/hold (utilisez vérifier).
