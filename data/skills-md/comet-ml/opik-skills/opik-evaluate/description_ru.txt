Создайте оценку LLM и запустите её против приложения, получив эксперимент Opik с оценками и ссылкой на него. Выбирает тестовый набор с утверждениями судьи или набор данных с метриками, берёт случаи из трассировок или синтетических данных, оценивает сначала по эвристикам, затем с помощью судей с единственным режимом отказа, запускает клиент‑сайд через SDK или сервер‑сайд для целей только с подсказкой и считывает оценки обратно. Охватывает оценку RAG, анализ ошибок, написание и проверку судей LLM против человеческих меток, а также аудит существующего конвейера оценки. Используется для «оценить моего агента», «измерить качество», «создать оценку», «написать судью LLM для галлюцинаций», «аудитировать наш конвейер оценки», «насколько хорош мой RAG», «настроить оценки для этого». Не предназначено для сравнения до/после в существующем наборе (используйте compare), отдельного случая регрессии (используйте test), оценки производственного трафика (используйте online-eval) или решения о выпуске/задержке (используйте verify).  

Пожалуйста, всегда отвечайте на языке пользователя.
