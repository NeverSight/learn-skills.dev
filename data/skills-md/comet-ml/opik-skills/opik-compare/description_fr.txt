Exécutez un candidat contre la référence sur une suite de tests Opik et récupérez les chiffres — quels cas ont échoué, quels cas ont été corrigés, les écarts par métrique, les lignes les plus mauvaises, et si les deux exécutions sont comparables — avec le lien de vue comparée Opik. Les exécutions se font via le SDK ; les résultats sont lus via le MCP lorsqu’il est connecté. Aucun verdict d’envoi ou de non‑envoi n’est émis. À utiliser pour « mon correctif a‑t‑il fonctionné », « comparer à la référence », « exécuter la suite de régression », « pourquoi la qualité a‑t‑elle baissé », « quels cas ont régressé », « comparer ces deux expériences ». Pas pour la décision d’envoi/retention elle‑même (utilisez verify), le triage en production en temps réel (utilisez diagnose), la création d’une évaluation à partir de zéro (utilisez evaluate), ou la capture d’un cas unique (utilisez test).
