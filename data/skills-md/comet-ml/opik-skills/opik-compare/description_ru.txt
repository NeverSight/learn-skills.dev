Запустите кандидат против базовой линии в тестовом наборе Opik и получите обратно числа — какие случаи сломались, какие исправились, отклонения по метрикам, худшие строки и сопоставимы ли два запуска — через ссылку сравнения Opik. Запускается через SDK; результаты читаются через MCP при подключении. Не выдаёт вердикт «отправлять/не отправлять». Используйте для «работает ли моё исправление», «сравнение с базовой линией», «запуск регрессионного набора», «почему упало качество», «какие случаи регрессировали», «сравнить два эксперимента». Не предназначено для самого решения о выпуске/задержке (используйте verify), живой диагностики в продакшн (используйте diagnose), построения оценки с нуля (используйте evaluate) или захвата отдельного случая (используйте test).
