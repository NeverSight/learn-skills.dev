Ajoutez le traçage Opik à une application existante et vérifiez une trace réelle. Installe le package Opik, détecte le langage et le cadre LLM, ajoute le traçage minimum, exécute un chemin représentatif sécurisé, confirme une trace dans Opik et renvoie le lien de trace. Utiliser pour « instrumenter mon code », « ajouter traçage opik », « ajouter observabilité », « tracer mon agent ». Pas pour créer une nouvelle application à partir de zéro, ou un laissez-passer de révision uniquement sans modification de code.
