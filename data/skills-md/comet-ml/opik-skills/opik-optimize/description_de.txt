Verbessern Sie einen Prompt mit dem Opik Agent Optimizer – lösen Sie den Prompt, ein Dataset und eine Metrik, wählen Sie den Algorithmus, führen Sie eine begrenzte Optimierung durch, prüfen Sie den Gewinn an gehaltenen Daten und speichern Sie den Gewinner als neue Prompt‑Version mit dem Link zum Optimierungslauf. Läuft über das opik‑optimizer‑Paket; liest Prompts und Datasets über das MCP, wenn verbunden. Verwenden Sie es für „optimiere diesen Prompt“, „verbessere meinen System‑Prompt“, „lasse den Agenten besser antworten“, „tune den Prompt gegen mein Dataset“, „führe den Prompt‑Optimierer aus“. Nicht zum einmaligen Qualitätsmessen (verwenden Sie evaluate), vor/nach einer Suite (verwenden Sie compare) oder zum manuellen Editieren eines Prompts ohne Daten.

Bitte antworten Sie immer in der Sprache des Benutzers.
