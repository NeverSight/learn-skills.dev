Улучшайте подсказку с помощью Opik Agent Optimizer — определите подсказку, набор данных и метрику, выберите алгоритм, запустите ограниченную оптимизацию, проверьте прирост на отложенных данных и сохраните победителя как новую версию подсказки со ссылкой на запуск оптимизации. Работает через пакет opik-optimizer; читает подсказки и наборы данных через MCP при подключении. Используйте для «оптимизировать эту подсказку», «улучшить мой системный запрос», «сделать ответ агента лучше», «настроить подсказку по моему набору данных», «запустить оптимизатор подсказок». Не предназначено для одноразового измерения качества (используйте evaluate), сравнения до/после в наборе (используйте compare) или ручного редактирования подсказки без данных.  

Пожалуйста, всегда отвечайте на языке пользователя.
