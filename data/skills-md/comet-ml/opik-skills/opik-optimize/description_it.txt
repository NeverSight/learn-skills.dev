Migliora un prompt con l'Opik Agent Optimizer — risolvi il prompt, un dataset e una metrica, scegli l'algoritmo, esegui un'ottimizzazione limitata, verifica il guadagno sui dati di test e salva il vincitore come nuova versione del prompt con il link all'esecuzione dell'ottimizzazione. Funziona tramite il pacchetto opik-optimizer; legge prompt e dataset tramite l'MCP quando connesso. Da utilizzare per “ottimizza questo prompt”, “migliora il mio prompt di sistema”, “fai rispondere meglio l'agente”, “regola il prompt rispetto al mio dataset”, “esegui l'ottimizzatore di prompt”. Non è destinato a misurare la qualità una tantum (usa evaluate), prima/dopo su una suite (usa compare), o a modificare manualmente un prompt senza dati.
