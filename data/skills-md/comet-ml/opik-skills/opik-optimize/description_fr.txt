Améliorez une invite avec l'Optimiseur d'Agent Opik — résolvez l'invite, un jeu de données et une métrique, choisissez l'algorithme, lancez une optimisation bornée, vérifiez le gain sur des données de validation, et enregistrez le gagnant comme une nouvelle version d'invite avec le lien de l'exécution d'optimisation. Fonctionne via le package opik-optimizer ; lit les invites et les jeux de données via le MCP lorsqu’il est connecté. Utilisez‑le pour « optimiser cette invite », « améliorer mon invite système », « faire mieux répondre l’agent », « ajuster l’invite à mon jeu de données », « exécuter l’optimiseur d’invite ». Ce n’est pas destiné à mesurer la qualité une fois (utilisez évaluer), avant/après sur une suite (utilisez comparer), ou à éditer manuellement une invite sans données.

Veuillez toujours répondre dans la langue de l'utilisateur.
