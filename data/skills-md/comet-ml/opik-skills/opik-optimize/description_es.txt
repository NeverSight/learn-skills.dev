Mejora un prompt con el Optimizador de Agente Opik — resuelve el prompt, un conjunto de datos y una métrica, elige el algoritmo, ejecuta una optimización limitada, verifica la ganancia en datos reservados y guarda el ganador como una nueva versión del prompt con el enlace de la ejecución de optimización. Funciona a través del paquete opik-optimizer; lee prompts y conjuntos de datos mediante el MCP cuando está conectado. Úsalo para "optimizar este prompt", "mejorar mi prompt de sistema", "hacer que el agente responda mejor", "ajustar el prompt contra mi conjunto de datos", "ejecutar el optimizador de prompts". No es para medir la calidad una sola vez (usa evaluate), antes/después en una suite (usa compare), o editar manualmente un prompt sin datos.
