Определите, выпускать или откладывать кандидат на основе чисел навыка сравнения, согласно явной политике релиза — регрессии, коэффициент успешных запусков, случаи с пометкой безопасности, согласованность подгрупп, ограничения по задержке и стоимости, нестабильность, размер доказательств и проверена ли судья. Считывает два эксперимента в тестовом наборе Opik через SDK (или MCP при подключении) и возвращает вердикт с указанием для каждого критерия «пройдено/не пройдено». Используется для «это безопасно выпускать», «могу ли я слить это», «go/no-go для этого изменения», «ограничить этот релиз», «нужно ли развернуть это». Не предназначено для получения чисел (используйте compare), построения оценки (используйте evaluate) или развертывания чего‑либо.
