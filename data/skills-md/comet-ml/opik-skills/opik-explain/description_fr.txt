Racine : provoquez une trace Opik spécifique, ou un motif à travers les traces, et renvoyez une explication fondée. Utilise le MCP Opik hébergé lorsqu'il est connecté, et revient au script SDK autrement. Renvoie la cause racine, les preuves s'étendent sous forme de liens d'interface utilisateur Opik cliquables, et une étape suivante suggérée. Utilisez pour « pourquoi cette trace a-t-elle échoué », « expliquer cette trace », « déboguer cette trace », « pourquoi mon agent est-il lent ou erroné ». Pas pour ajouter un suivi à une application (utilisez la compétence d'instrument) ou pour changer de code.
