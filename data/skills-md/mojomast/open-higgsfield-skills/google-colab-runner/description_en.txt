Run video-director productions on Google Colab. It packages a manifest into a self-contained Google Colab bundle (a generated .ipynb that installs ComfyUI and custom nodes at pinned commits, downloads the open-weights models with the user's own Hugging Face token from Google Colab secrets, renders every shot, detects the GPU tier and collects outputs to Drive or a zip), or it lets the director drive a running Google Colab ComfyUI through a tunnel URL with a compute-unit estimate, the spend gate, a hard cap, drop-and-resume and teardown. Use it when the user has no local GPU, or asks to run on Google Colab.
