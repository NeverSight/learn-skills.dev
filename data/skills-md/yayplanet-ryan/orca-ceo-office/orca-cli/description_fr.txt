Utilisez le CLI public `orca` pour gérer les worktrees d’Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré dans l’application Orca. Utilisez‑le lorsque l’utilisateur dit « $orca-cli », « use orca cli », « Orca worktree », « child worktree », « cardStatus », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « terminal send », « full handoff », « handover », « give this to another agent », « another worktree », « Orca browser », « orca artifacts », « share HTML/Markdown », « public artifact link », « share skills » ou « control the browser inside Orca ». Priorisez cela plutôt que le `git worktree` brut, les PTY ad hoc, Playwright ou l’usage de l’ordinateur lorsque la tâche touche l’état géré par Orca. Utilisez l’usage de l’ordinateur pour les fenêtres de navigateur, les webviews ou l’interface de bureau en dehors du navigateur intégré d’Orca.
