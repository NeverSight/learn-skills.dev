从微软官方分发接口（FE3 / Windows Update）离线获取并安装 Microsoft Store 应用包（appx / appxbundle / msix），不需要打开 Microsoft Store。适用于商店打不开或报错、winget 安装卡在「启动程序包安装」、以及需要补装 AV1 / HEVC / VP9 等系统媒体扩展的场景。Downloads Microsoft Store packages straight from Microsoft's official delivery API (FE3) and installs them via Add-AppxPackage, bypassing the Store app entirely. Use when the Microsoft Store is broken or unavailable, when winget hangs on install, or when a codec / media extension must be sideloaded.
