حدد مشروع GitHub الحالي وقارن الملفات التي تم تعديلها بسجل مسارات JSON المملوك للمهارة، ثم نفّذ عروض تقارير القبول البشري قبل الالتزام وتذكيرات الالتزام أو طلب السحب. استخدم ذلك قبل أن يقوم وكيل بإجراء تغييرات خدمية قد تتطلب قبول شخص حقيقي، أو عند صيانة قواعد المتصل والمنفذ عبر المستودعات. لا تُفعّل بناءً على هوية المستودع فقط أو لإنشاء اختبارات آلية عادية.
