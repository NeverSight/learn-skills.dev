Identifica il progetto GitHub corrente e confronta i file modificati con un registro di percorsi JSON di proprietà della skill, quindi applica le offerte di report di accettazione umana pre‑commit e i promemoria di commit o PR. Usalo prima che un agente effettui commit di modifiche al servizio che possono richiedere l’accettazione da parte di una persona reale, o quando si mantengono regole di chiamante e implementatore tra repository. Non attivare il meccanismo basandoti solo sull’identità del repository o per la creazione ordinaria di test automatizzati.
