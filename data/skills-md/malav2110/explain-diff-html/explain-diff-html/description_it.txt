Produci una spiegazione HTML ricca, interattiva e autonoma di un diff, un branch o una pull request, con Contesto, Intuizione, Analisi del Codice e un Quiz, scritta come un unico file datato nella cartella **code-explanations** nella home directory dell'utente, al di fuori del repository. Si attiva con i comandi “explain this diff”, “walk me through this branch”, “explain PR 1234”. Non è destinata alla revisione delle modifiche né a spiegare un ticket di issue autonomo.

Rispondi sempre nella lingua dell'utente.
