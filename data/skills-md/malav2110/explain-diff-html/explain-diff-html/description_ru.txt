Создайте насыщенное, интерактивное, автономное HTML‑объяснение diff, ветки или pull‑request, включающее разделы «Фон», «Интуиция», «Разбор кода» и «Викторина», записанное как датированный файл в папку code‑explanations в домашнем каталоге пользователя, вне репозитория. Активируется по запросам «explain this diff», «walk me through this branch», «explain PR 1234». Не предназначено для обзора изменений и не для объяснения отдельного тикета задачи.
