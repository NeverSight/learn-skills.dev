أنشئ شرحًا غنيًا وتفاعليًا ومُعتمدًا على HTML ذاتي المحتوى لفرق (diff) أو فرع (branch) أو طلب سحب (pull request)، يتضمن الخلفية، الفكرة، مراجعة الكود، واختبارًا قصيرًا، يُكتب كملف واحد مؤرخ في مجلد code-explanations داخل دليل المستخدم الرئيسي، خارج المستودع. يُفعَّل عند الأوامر "explain this diff"، "walk me through this branch"، "explain PR 1234". ليس لأغراض مراجعة التغييرات ولا لشرح تذكرة مشكلة مستقلة.

يرجى الرد دائمًا بلغة المستخدم.
