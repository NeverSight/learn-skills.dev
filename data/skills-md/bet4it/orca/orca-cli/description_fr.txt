Opérez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via la CLI `orca`. Utilisez‑le lorsque l’utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Préférez‑le au worktree git brut, aux PTY ad hoc ou à l’Utilisation de l’Ordinateur lorsqu’un état Orca est en jeu. N’utilisez l’Utilisation de l’Ordinateur que lorsqu’une fenêtre visible nécessite un contrôle GUI qu’une CLI, un système de fichiers ou une API ne peut pas assurer.
