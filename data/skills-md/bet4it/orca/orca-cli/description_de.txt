Betriebe von Orca‑verwalteten Arbeitsbäumen, Ordnerkontexten, Terminals, Repositories, Automatisierungen, Artefakten, Fähigkeits­austausch, Arbeitsbaum‑Kommentaren und Orcas eingebettetem Browser über die `orca`‑CLI. Verwende sie, wenn der Nutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzuge sie gegenüber rohen Git‑Worktrees, ad‑hoc‑PTYs oder Computer‑Use, wenn Orca‑Zustand involviert ist. Nutze Computer‑Use nur, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die eine CLI, das Dateisystem oder eine API nicht leisten kann.
