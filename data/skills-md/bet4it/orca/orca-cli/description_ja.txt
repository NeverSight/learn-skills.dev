`orca` CLI を通じて、Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザを操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」「handover」「give this to another agent」「Orca browser」「orca artifacts」「share skills」などと言った場合に使用してください。Orca の状態が関与する場合は、生の git worktree、臨時の PTY、あるいは Computer Use よりもこちらを優先します。CLI、ファイルシステム、API では実行できない、可視ウィンドウの GUI 操作が必要なときのみ Computer Use を使用してください。

常にユーザーの言語で回答してください。
