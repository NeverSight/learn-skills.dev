تشغيل worktrees المُدارة بواسطة Orca، وسياقات المجلدات، والطُرف، والمستودعات، والأتمتة، والملفات، ومشاركة المهارات، وتعليقات worktree، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضِّلها على git worktree العادي، أو PTYs العشوائية، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى تحكم GUI لا يمكن لسطر الأوامر أو نظام الملفات أو الـ API القيام به.
