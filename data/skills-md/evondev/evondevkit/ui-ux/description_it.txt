Stile UI/UX per app — dashboard, elenco, tabella, form, impostazioni, modal, pagina scorrevole per la selezione. Di default, come un designer — brief, 2–3 wireframe, l'utente sceglie prima di procedere. Altri approcci quando la richiesta è chiara — ispezionare UI esistente (“vedi per favore”, “review”), ricostruire mantenendo il brand (“mantieni il brand”, “keep the brand”) o secondo le proprie competenze (“rimuovi lo stile vecchio”), refactoring mantenendo l’aspetto, costruire direttamente (“costruisci subito”, “just build it”), design system prima (“UI kit”, “library di componenti”), logo semplice (“crea logo”), modificare un componente. Di default è flat; è possibile realizzare glass, gradient, effetti di rilievo, sfondo scuro. Landing page, negozio online, blog non sono ancora stati insegnati — comunque li realizzo, con avviso in anticipo. Utilizzato per costruire, ricostruire, modificare l’interfaccia di un’app, visualizzare immagini o link dell’app, o quando si richiede “fare UI bello”, “costruire una schermata”, “progettare”, “rifare UX”, “sembra confuso”, “build a page”, “design this screen”, “redesign”, “make it look good”, “ecommerce”, “ui‑ux”, “evon”.
