Угол UI/UX для приложения — dashboard, список, таблица, форма, настройки, модальное окно, страница‑пролистывание для выбора. По умолчанию как у дизайнера — бриф, 2–3 вайрфрейма, пользователь выбирает, потом создаётся. Другой подход, когда задание уточнено — анализировать существующий UI («посмотри», «review»), перепроектировать, сохранив бренд («сохранить бренд», «keep the brand»), либо по навыкам («убрать старый стиль»), рефакторинг без изменения внешнего вида, сразу построить («построить сразу», «just build it»), сначала создать систему дизайна («UI‑kit», «библиотека компонентов»), простой логотип («сделать логотип»), исправить один компонент. По умолчанию — плоский стиль; можно сделать glass, градиент, объёмный, тёмный фон. Landing page, онлайн‑магазин, блог пока не обучаются — всё равно делаем, предупреждаем заранее. Используется при создании, переделке, исправлении интерфейса приложения, просмотре изображений или ссылки на приложение, либо по запросу «сделать UI красивым», «построить экран», «дизайн», «переработать UX», «выглядит запутанно», «build a page», «design this screen», «redesign», «make it look good», «ecommerce», «ui‑ux», «evon».
