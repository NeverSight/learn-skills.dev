ذوق UI/UX للتطبيق — لوحة القيادة، القائمة، الجدول، النموذج، الإعدادات، النافذة المنبثقة، صفحة التصفح للاختيار. الافتراضي كالمصمم - موجز، 2–3 مخططات سلكية، يختار المستخدم ثم يتم الإنشاء. طريقة أخرى عندما يوضح الطلب - مراجعة UI الموجود ("xem giúp"، "review")، إعادة بناء مع الحفاظ على العلامة التجارية ("giữ brand"، "keep the brand") أو حسب ذوق الميزة ("bỏ style cũ")، إعادة هيكلة مع الحفاظ على الشكل، الإنشاء مباشرة ("dựng luôn"، "just build it")، نظام التصميم أولاً ("UI kit"، "component library")، شعار بسيط ("làm logo")، تعديل مكوّن واحد. الافتراضي مسطح؛ يمكن عمل زجاج، تدرج لوني، بارز، خلفية داكنة. صفحة الهبوط، المتجر الإلكتروني، المدونة لم تُدرّس بعد - ما زال يتم العمل عليها، يتم الإبلاغ مسبقًا. يستخدم عند إنشاء، إعادة إنشاء، تعديل واجهة التطبيق، مشاهدة صورة أو رابط التطبيق، أو عند تذكير بـ "làm UI cho đẹp"، "dựng màn"، "thiết kế"، "làm lại UX"، "nhìn rối"، "build a page"، "design this screen"، "redesign"، "make it look good"، "ecommerce"، "ui-ux"، "evon".
