Utilice ast-grep (sg) para la búsqueda y reescritura de código compatible con AST en 25 idiomas. Activador para la coincidencia de código estructural o codemods deterministas: encuentre cada función/llamada/clase/importación con forma de X, reescriba console.log en logger.info, elimine `como cualquier`, migre require() para importar, encuentre bloques de captura vacíos o en espera faltantes, y escanee/aplique las reglas YAML. Prefiera esto a rg/grep cuando el objetivo sea la forma de la sintaxis en lugar del texto; use rg para el contenido de cadenas, comentarios, nombres de archivos o búsquedas de bytes al estilo regex.
