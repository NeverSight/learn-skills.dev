Ast - grep （ sg ）を使用して、ASTを認識したコード検索を行い、25言語で書き換えます。構造コードマッチングまたは決定論的コードモッドのトリガー： Xのような形のすべての関数/呼び出し/クラス/インポートを見つけ、console.logをlogger.infoに書き換え、`as any`を取り除き、require ()をインポートするために移行し、空のキャッチブロックまたは欠落しているawaitを見つけ、YAMLルールをスキャン/適用します。ターゲットがテキストではなく構文シェイプの場合は、rg/grepよりもこれを優先します。文字列の内容、コメント、ファイル名、または正規表現スタイルのバイト検索にはrgを使用します。
