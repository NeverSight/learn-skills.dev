Verwenden Sie ast-grep (sg) für die AST-bewusste Codesuche und das Neuschreiben in 25 Sprachen. Auslöser für strukturellen Codeabgleich oder deterministische Codemods: Finden Sie jede Funktion/Aufruf/Klasse/Import in Form von X, schreiben Sie console.log auf logger.info um, entfernen Sie `as any`, migrieren Sie require() zum Importieren, finden Sie leere Fangblöcke oder fehlende warten Sie und scannen/wenden Sie YAML-Regeln an. Bevorzugen Sie dies gegenüber rg/grep, wenn das Ziel Syntaxform statt Text ist; verwenden Sie rg für Zeichenfolgeninhalte, Kommentare, Dateinamen oder Bytesuchen im Regex-Stil.
