Utilisez ast-grep (sg) pour la recherche et la réécriture de code AST dans 25 langues. Déclencheur pour la correspondance de code structurel ou les codemods déterministes : trouvez chaque fonction/appel/classe/importation en forme de X, réécrivez console.log dans logger.info, supprimez `as any`, migrez require() pour importer, trouvez les blocs de capture vides ou l'attente manquante, et scannez/appliquez les règles YAML. Préférez cela à rg/grep lorsque la cible est une forme syntaxique plutôt que du texte ; utilisez rg pour le contenu des chaînes, les commentaires, les noms de fichiers ou les recherches d'octets de style regex.
