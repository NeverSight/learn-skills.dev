DOIT ÊTRE UTILISÉ lorsque l'utilisateur a besoin d'informations actuelles, en ligne ou provenant du web — actualités, dernières versions, documents du fournisseur, exemples réels, changements récents, ou tout ce qui n'est pas présent dans le jeu de données d'entraînement du modèle. Compétence neutre vis‑à‑vis des LLM qui expose une CLI de recherche web unifiée derrière une seule commande. Fonctionne avec un ou plusieurs fournisseurs en parallèle, enregistre le JSON brut + normalisé dans un répertoire temporaire, affiche le chemin afin que les appelants puissent le transmettre via rg / jq / grep. Zéro configuration dès l'installation. Fonctionne de façon identique sur macOS, Linux, WSL, Git Bash pour Windows, et tout environnement disposant de Python 3.8+. Déclencheurs : « search the web », « look up online », « google this », « find current information », « latest news », « recent docs », « check the internet », « web search », « browser search », « research this », « what is the latest », « who is X », « find examples of », « is there documentation for », « how do people solve », « web-search », « web_search ». Veuillez toujours répondre dans la langue de l'utilisateur.
