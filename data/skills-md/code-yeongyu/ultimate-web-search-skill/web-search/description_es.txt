DEBE USAR cuando el usuario necesita información actual, en línea o derivada de la web — noticias, últimos lanzamientos, documentación del proveedor, ejemplos del mundo real, cambios recientes o cualquier cosa que no esté en el conjunto de entrenamiento del modelo. Habilidad neutral para LLM que expone una CLI de búsqueda web unificada detrás de un solo comando. Ejecuta uno o varios proveedores en paralelo, guarda JSON bruto + normalizado en un directorio temporal, imprime la ruta para que los llamadores puedan canalizarlo a través de rg / jq / grep. Configuración cero desde el principio. Funciona idénticamente en macOS, Linux, WSL, Git Bash para Windows y cualquier entorno con Python 3.8+. Activadores: “buscar en la web”, “consultar en línea”, “googlear esto”, “encontrar información actual”, “últimas noticias”, “documentos recientes”, “verificar internet”, “búsqueda web”, “búsqueda en el navegador”, “investigar esto”, “qué es lo último”, “quién es X”, “encontrar ejemplos de”, “¿existe documentación para?”, “¿cómo la gente resuelve?”, “web-search”, “web_search”.
