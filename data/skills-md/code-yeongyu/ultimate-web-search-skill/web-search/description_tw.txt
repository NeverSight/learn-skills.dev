當使用者需要即時、線上或網路衍生的資訊——新聞、最新發行、供應商文件、真實範例、最近變更，或任何模型訓練資料未涵蓋的內容時，必須使用。本技能為與 LLM 無關的功能，將統一的網路搜尋 CLI 隱藏於單一指令背後。可同時執行單一或多供應商的平行搜尋，將原始與正規化的 JSON 儲存至暫存目錄，並印出路徑，以便呼叫端透過 rg / jq / grep 進行管道處理。開箱即用，零設定。於 macOS、Linux、WSL、Windows 的 Git Bash 以及任何支援 Python 3.8+ 的環境中皆能一致運作。觸發詞包括：「search the web」「look up online」「google this」「find current information」「latest news」「recent docs」「check the internet」「web search」「browser search」「research this」「what is the latest」「who is X」「find examples of」「is there documentation for」「how do people solve」「web-search」「web_search」。請始終以使用者的語言回覆。
