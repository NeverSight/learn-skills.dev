ユーザーが最新のオンライン情報やウェブ由来の情報（ニュース、最新リリース、ベンダーのドキュメント、実例、最近の変更、モデルの学習データに含まれていないもの）を必要とする場合は必ず使用してください。  
LLM 非依存のスキルで、単一のコマンドから統一されたウェブ検索 CLI を提供します。単一プロバイダーまたは複数プロバイダーを並列実行し、raw と正規化された JSON を一時ディレクトリに保存し、パスを出力するので、呼び出し側は rg / jq / grep でパイプできます。設定不要ですぐに使用可能です。macOS、Linux、WSL、Windows 用 Git Bash、Python 3.8 以上がインストールされた環境で同一に動作します。  
トリガー語句: 「search the web」「look up online」「google this」「find current information」「latest news」「recent docs」「check the internet」「web search」「browser search」「research this」「what is the latest」「who is X」「find examples of」「is there documentation for」「how do people solve」「web-search」「web_search」。
