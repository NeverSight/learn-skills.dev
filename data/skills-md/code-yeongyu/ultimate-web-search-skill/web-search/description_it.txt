DEVE USARE quando l'utente ha bisogno di informazioni attuali, online o derivanti dal web — notizie, ultime versioni, documenti dei fornitori, esempi reali, modifiche recenti o qualsiasi cosa non presente nel set di addestramento del modello. Funzionalità neutrale rispetto al LLM che espone un'interfaccia di ricerca web unificata dietro un unico comando. Funziona con un singolo o più provider in parallelo, salva JSON grezzo e normalizzato in una directory temporanea e stampa il percorso affinché gli chiamanti possano pipeare attraverso rg / jq / grep. Configurazione zero fin da subito. Funziona allo stesso modo su macOS, Linux, WSL, Git Bash per Windows e qualsiasi ambiente con Python 3.8+. Trigger: 'search the web', 'look up online', 'google this', 'find current information', 'latest news', 'recent docs', 'check the internet', 'web search', 'browser search', 'research this', 'what is the latest', 'who is X', 'find examples of', 'is there documentation for', 'how do people solve', 'web-search', 'web_search'.

Rispondi sempre nella lingua dell'utente.
