ДОЛЖЕН ИСПОЛЬЗОВАТЬСЯ, когда пользователю нужны актуальные, онлайн или полученные из сети сведения — новости, последние релизы, документы поставщиков, реальные примеры, недавние изменения или что‑то, чего нет в наборе обучения модели. LLM‑нейтральный навык, который открывает единую CLI‑команду веб‑поиска. Запускает один или несколько провайдеров параллельно, сохраняет необработанный и нормализованный JSON во временную директорию, выводит путь, чтобы вызывающие могли перенаправлять через rg / jq / grep. Работает без настройки сразу из коробки. Идентично работает на macOS, Linux, WSL, Git Bash для Windows и в любой среде с Python 3.8+. Триггеры: «search the web», «look up online», «google this», «find current information», «latest news», «recent docs», «check the internet», «web search», «browser search», «research this», «what is the latest», «who is X», «find examples of», «is there documentation for», «how do people solve», «web-search», «web_search».
