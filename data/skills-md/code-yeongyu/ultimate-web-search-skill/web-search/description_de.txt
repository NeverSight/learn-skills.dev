MUSS VERWENDET WERDEN, wenn der Benutzer aktuelle, online‑ oder webbasiert Informationen benötigt – Nachrichten, neueste Veröffentlichungen, Lieferantendokumentation, Praxisbeispiele, aktuelle Änderungen oder alles, was nicht im Trainingsdatensatz des Modells enthalten ist.  
LLM‑neutrale Fähigkeit, die eine einheitliche Web‑Such‑CLI hinter einem einzigen Befehl bereitstellt.  
Führt Einzel‑ oder Mehranbieter‑Suchen parallel aus, speichert Roh‑ und normalisiertes JSON in einem temporären Verzeichnis, gibt den Pfad aus, sodass Aufrufer über rg / jq / grep weiterleiten können.  
Null‑Konfiguration sofort einsatzbereit.  
Funktioniert identisch unter macOS, Linux, WSL, Git Bash für Windows und in jeder Umgebung mit Python 3.8+.  
Auslöser: „search the web“, „look up online“, „google this“, „find current information“, „latest news“, „recent docs“, „check the internet“, „web search“, „browser search“, „research this“, „what is the latest“, „who is X“, „find examples of“, „is there documentation for“, „how do people solve“, „web-search“, „web_search“.  
Bitte immer in der Sprache des Benutzers antworten.
