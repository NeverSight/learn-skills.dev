Utiliza una cuenta personal de QQ/WeChat en Tencent Docs para gestionar la integración de desarrollo: comparte hojas de orden de trabajo, registra miembros y asignaciones de tareas opcionales, publica desde el área de staging de Git, reclama tareas individuales, conserva el historial de seguimiento y acepta manualmente con retorno de escritura. Úsalo cuando un usuario solicite crear una hoja de integración, conectar o vincular una hoja de orden de trabajo de Tencent, publicar la funcionalidad de staging, reclamar o continuar el desarrollo de elementos de integración, y aprobar o devolver la aceptación.
