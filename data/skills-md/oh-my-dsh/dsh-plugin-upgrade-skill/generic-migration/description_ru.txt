Фреймворк‑агностическая методология миграции плагина, расширения или интеграции через разрывной апстрим‑релиз — инвентаризация точек связывания, классификация изменений, поэтапная миграция и проверка в слоях. Используйте при обновлении любого плагина с одной версии хост‑фреймворка на другую без доступа к специфическим для фреймворка заметкам о миграции. Не заменяет примечания к выпуску поставщика; не содержит фактов, специфичных для фреймворка.
