Используйте, когда установленный веб-плагин DSH плохо себя ведет только во время выполнения в браузере — функции вставки/присоединения/компоновки, которые работают один раз, затем выходят из строя, чипы или панели показывают устаревшее состояние заполнителя, чипы обновления заявляют неправильную версию — и исправление должно быть диагностировано на основе точной семантики API хоста, а не угадываться по именам. Также используйте при проверке вызовов плагина на машину ввода или фасадные глаголы (вставка, потребление, удаление, подписка) перед выпуском.
