À utiliser lorsqu'un plugin Web DSH installé se comporte mal uniquement au moment de l'exécution dans le navigateur - fonctionnalités de collage/pièce jointe/composer qui fonctionnent une fois puis échouent, puces ou panneaux affichant un état d'espace réservé obsolète, puces de mise à jour revendiquant la mauvaise version - et le correctif doit être diagnostiqué par rapport à la sémantique exacte de l'API hôte plutôt que deviné à partir des noms. À utiliser également lors de la révision des appels d'un plugin dans des verbes de machine d'entrée ou de façade (insérer, consommer, supprimer, s'abonner) avant une version.
