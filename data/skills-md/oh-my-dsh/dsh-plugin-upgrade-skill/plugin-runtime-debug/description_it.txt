Da utilizzare quando un plug-in Web DSH installato si comporta in modo anomalo solo in fase di esecuzione nel browser: funzionalità di incolla/allegato/compositore che funzionano una volta e poi falliscono, chip o pannelli che mostrano uno stato di segnaposto obsoleto, chip di aggiornamento che dichiarano la versione sbagliata e la correzione deve essere diagnosticata rispetto all'esatta semantica dell'API host anziché dedotta dai nomi. Da utilizzare anche quando si esaminano le chiamate di un plugin nella macchina di input o i verbi di facciata (inserire, consumare, rimuovere, sottoscrivere) prima di un rilascio.
