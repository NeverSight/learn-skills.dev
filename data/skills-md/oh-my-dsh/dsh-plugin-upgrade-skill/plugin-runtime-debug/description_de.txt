Verwenden Sie es, wenn sich ein installiertes DSH-Web-Plugin nur zur Laufzeit im Browser schlecht verhält – Einfüge-/Anhangs-/Composer-Funktionen, die einmal funktionieren und dann fehlschlagen, Chips oder Panels einen veralteten Platzhalterstatus anzeigen, Update-Chips, die die falsche Version angeben – und der Fix anhand der genauen Host-API-Semantik diagnostiziert werden muss und nicht anhand von Namen erraten werden muss. Verwenden Sie es auch, wenn Sie die Aufrufe eines Plugins in Eingabemaschinen- oder Fassadenverben (einfügen, konsumieren, entfernen, abonnieren) vor einer Veröffentlichung überprüfen.
