Auditer la compatibilité externe entre deux versions de DSH (DeepSeek Harness) et détecter les retours, en produisant un répertoire de rapport de mise à niveau ; compare les balises git avec une extraction de source ou les packages npm publiés sans une. À utiliser chaque fois que l'utilisateur demande de vérifier/comparer/auditer deux versions de DSH ou si la mise à niveau est sûre — par ex. "plus de modifications ou d'annulations dans dsh-vX -> dsh-vY", "comparez les dernières modifications" - même avec seulement deux numéros de version et aucun emplacement source. Lecture seule en dehors du répertoire des rapports ; Le mode npm s'installe de manière isolée avec --ignore-scripts.
