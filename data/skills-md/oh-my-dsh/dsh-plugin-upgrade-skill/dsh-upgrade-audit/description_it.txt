Controlla la compatibilità esterna tra due versioni DSH (DeepSeek Harness) e rileva i ripristini, producendo una directory di report di aggiornamento; confronta i tag git con un checkout di origine o i pacchetti npm pubblicati senza uno. Da utilizzare ogni volta che l'utente chiede di controllare/confrontare/verificare due versioni DSH o se l'aggiornamento è sicuro, ad es. "ulteriori modifiche o ripristini in dsh-vX -> dsh-vY", "confronta le modifiche sostanziali" - anche con solo due numeri di versione e nessuna posizione di origine. Di sola lettura all'esterno della directory del report; La modalità npm si installa isolatamente con --ignore-scripts.
