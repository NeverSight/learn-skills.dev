두 DSH(DeepSeek Harness) 버전 간의 외부 호환성을 감사하고 되돌리기를 감지하여 업그레이드 보고서 디렉터리를 생성합니다. git 태그를 소스 체크아웃과 비교하거나, 소스 체크아웃 없이 게시된 npm 패키지를 비교합니다. 사용자가 두 개의 DSH 버전을 확인/비교/감사하거나 업그레이드가 안전한지 여부를 요청할 때마다 사용합니다. "dsh-vX -> dsh-vY에서 추가 변경 또는 되돌리기", "주요 변경 사항 비교" - 버전 번호가 두 개뿐이고 소스 위치가 없는 경우에도 마찬가지입니다. 보고서 디렉터리 외부에서는 읽기 전용입니다. npm 모드는 --ignore-scripts와 별도로 설치됩니다.
