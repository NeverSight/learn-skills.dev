Аудит внешней совместимости между двумя версиями DSH (DeepSeek Harness) и обнаружение возвратов с созданием каталога отчетов об обновлении; сравнивает теги git с извлечением исходного кода или опубликованные пакеты npm без них. Используйте всякий раз, когда пользователь просит проверить/сравнить/проверить две версии DSH или безопасно ли обновление — например. «больше изменений или откатов в dsh-vX -> dsh-vY», «сравните критические изменения» — даже при наличии только двух номеров версий и отсутствия местоположения источника. Доступно только для чтения вне каталога отчета; Режим npm устанавливается изолированно с --ignore-scripts.
