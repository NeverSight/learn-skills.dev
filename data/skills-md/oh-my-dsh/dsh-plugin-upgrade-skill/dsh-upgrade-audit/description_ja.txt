2 つの DSH (ディープシーク ハーネス) バージョン間の外部互換性を監査し、元に戻すことを検出して、アップグレード レポート ディレクトリを作成します。 git タグとソース チェックアウト、またはソース チェックアウトのない公開された npm パッケージを比較します。ユーザーが 2 つの DSH バージョンを確認/比較/監査するか、アップグレードが安全かどうかを要求する場合は常に使用します。例: 「dsh-vX -> dsh-vY でさらに変更または元に戻す」、「重大な変更を比較する」 - バージョン番号が 2 つだけで、ソースの場所がない場合でも。レポート ディレクトリ外では読み取り専用。 npm モードは、--ignore-scripts を使用して単独でインストールされます。
