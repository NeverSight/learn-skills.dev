Da utilizzare durante la scrittura o la revisione di test per plug-in DeepSeek Harness, pacchetti di plug-in DSH esterni o modifiche ai pacchetti nel repository deepseek-harness. Seleziona i livelli minimi sufficienti da test unitari, copertura, test end-to-end API reali, istantanee, test Web, composizioni reali e test del fumo con artefatti incorporati. Per le migrazioni delle versioni Harness, utilizza il flusso di lavoro di test a sette punti di contatto integrato di questa competenza e convalida l'esatto runtime della versione di destinazione.
