À utiliser lors de l'écriture ou de la révision de tests pour les plugins DeepSeek Harness, les packages de plugins DSH externes ou les modifications de packages dans le référentiel deepseek-harness. Sélectionnez les niveaux minimum suffisants parmi les tests unitaires, la couverture, les tests de bout en bout d'API réelles, les instantanés, les tests Web, les compositions réelles et les tests de fumée d'artefacts intégrés. Pour les migrations de versions Harness, utilisez le workflow de test à sept points de contact intégré à cette compétence et validez le runtime exact de la version cible.
