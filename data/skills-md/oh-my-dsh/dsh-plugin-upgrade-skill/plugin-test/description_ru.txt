Используйте при написании или проверке тестов для плагинов DeepSeek Harness, внешних пакетов плагинов DSH или изменений пакетов в репозитории deepseek-harness. Выберите минимально достаточные уровни из модульных тестов, покрытия, сквозных тестов реального API, снимков, веб-тестов, реальных композиций и дымовых тестов встроенных артефактов. Для миграции версий Harness используйте встроенный в этот навык рабочий процесс тестирования из семи точек взаимодействия и проверьте точную среду выполнения целевой версии.
