Utilice cuando el host DSH haya sido actualizado (o esté a punto de hacerlo) y toda la flota instalada de complementos Web/cliente deba comprobarse contra el nuevo host: una o más superficies se han roto, desaparecido o necesitan que se vuelva a verificar y volver a publicar su compatibilidad. También úselo después de una actualización del host para explorar rupturas silenciosas antes de que el usuario las informe, y para ejecutar el bucle de corrección/lanzamiento por complemento (rama, incremento, registro de cambios, etiqueta, espejos).
