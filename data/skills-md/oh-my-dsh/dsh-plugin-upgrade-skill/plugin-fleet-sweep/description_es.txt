Úsese cuando el host DSH haya sido actualizado (o esté a punto de hacerlo) y toda la flota instalada de complementos Web/cliente deba revisarse con respecto al nuevo host: una o más superficies se rompieron, desaparecieron o necesitan que su compatibilidad sea re‑verificada y re‑lanzada. También úselo después de una actualización del host para buscar rupturas silenciosas antes de que el usuario las informe y para ejecutar el ciclo de corrección/lanzamiento por complemento (rama, incremento, registro de cambios, etiqueta, espejos).
