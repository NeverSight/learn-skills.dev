Die einheitliche Design‑Engineering‑Fähigkeit zum Erstellen preisgekrönter, immersiver Websites und Web‑Interfaces in React. Wird eingesetzt, wann immer der Nutzer designen, bauen, neu gestalten, verfeinern, kritisieren oder animieren möchte – jede Frontend‑Komponente: Landing‑Pages, Portfolios, Marketing‑Sites, Produkt‑UI, Dashboards, Hero‑Sektionen, Navbars, Bento‑Grids, Karten, Formulare, Modale, Preistabellen, Footer, Testimonials – ODER 3D‑ und immersive Erlebnisse hinzufügen mit React Three Fiber, Three.js, WebGL, WebGPU, eigenen GLSL‑Shadern, scroll‑gesteuerter Animation, GSAP, Lenis oder Motion. Deckt UI‑Komponenten‑Muster, visuelles Design (Typografie, Farbe, Abstand, Layout, Grid, Hierarchie), Motion und Mikro‑Interaktionen, 3D/WebGL‑Szenen, Shader, Post‑Processing, Performance‑Budgets, Core Web Vitals, Barrierefreiheit und anti‑AI‑Slop‑Handwerk ab. Liefert produktionsbereiten Code im React + React Three Fiber + GSAP‑Stack. Dies ist die einzige Wahrheitsquelle für sämtliche Design‑, UI‑, Animations‑ und immersive 3D‑Arbeit und ersetzt separate UI/Design/Motion‑Skills.
