Единственное сочетание навыков дизайна и инженерии для создания отмеченных наградами иммерсивных веб‑сайтов и веб‑интерфейсов в React. Используется каждый раз, когда пользователь хочет спроектировать, построить, переработать, отполировать, критиковать или анимировать любой фронтенд — посадочные страницы, портфолио, маркетинговые сайты, UI продукта, дашборды, hero‑секции, навигационные панели, бенто‑сетки, карточки, формы, модальные окна, таблицы цен, футеры, отзывы — ИЛИ добавить 3D‑ и иммерсивные впечатления с помощью React Three Fiber, Three.js, WebGL, WebGPU, пользовательских GLSL‑шейдеров, анимации, управляемой прокруткой, GSAP, Lenis или Motion. Охватывает паттерны UI‑компонентов, визуальный дизайн (типографика, цвет, отступы, компоновка, сетка, иерархия), анимацию и микровзаимодействия, 3D/WebGL‑сцены, шейдеры, постобработку, бюджеты производительности, Core Web Vitals, доступность и практику против AI‑зависимых упрощений. Генерирует готовый к продакшну код на стеке React + React Three Fiber + GSAP. Это единственный источник истины для всего дизайна, UI, анимации и иммерсивной 3D‑работы, заменяющий отдельные навыки UI/дизайна/мошн.
