统一的设计工程技能，用于在 React 中构建获奖级别的沉浸式网站和网页界面。无论用户想要设计、构建、重新设计、打磨、评审或为任何前端动画——着陆页、作品集、营销站点、产品 UI、仪表盘、Hero 区块、导航栏、Bento 网格、卡片、表单、模态框、定价表、页脚、客户评价——或使用 React Three Fiber、Three.js、WebGL、WebGPU、自定义 GLSL 着色器、滚动驱动动画、GSAP、Lenis 或 Motion 添加 3D 与沉浸式体验。涵盖 UI 组件模式、视觉设计（排版、配色、间距、布局、网格、层级）、动效与微交互、3D/WebGL 场景、着色器、后期处理、性能预算、Core Web Vitals、可访问性以及防止 AI 低质量产出。生成基于 React + React Three Fiber + GSAP 堆栈的可投产代码。这是一切设计、UI、动画和沉浸式 3D 工作的唯一权威来源，取代了独立的 UI/设计/动效技能。
