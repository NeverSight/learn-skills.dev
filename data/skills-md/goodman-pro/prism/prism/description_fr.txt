La compétence unifiée de conception‑ingénierie pour créer des sites web et des interfaces immersives de niveau award en React. À utiliser chaque fois que l'utilisateur souhaite concevoir, développer, refondre, peaufiner, critiquer ou animer n'importe quel front‑end — pages d'atterrissage, portfolios, sites marketing, UI produit, tableaux de bord, sections héros, barres de navigation, grilles bento, cartes, formulaires, modaux, tableaux de tarification, pieds de page, témoignages — OU ajouter des expériences 3D et immersives avec React Three Fiber, Three.js, WebGL, WebGPU, shaders GLSL personnalisés, animation pilotée par le défilement, GSAP, Lenis ou Motion. Couvre les patterns de composants UI, le design visuel (typographie, couleur, espacement, mise en page, grille, hiérarchie), le motion et les micro‑interactions, les scènes 3D/WebGL, les shaders, le post‑processing, les budgets de performance, les Core Web Vitals, l’accessibilité et l’artisanat anti‑IA‑slop. Produit du code prêt pour la production sur la stack React + React Three Fiber + GSAP. Il s’agit de la source unique de vérité pour tout le design, l’UI, l’animation et le travail 3D immersif, et remplace les compétences séparées en UI/design/motion.
