Publica y mantiene artefactos auto‑contenidos en HTML, Markdown o React como URLs compartibles. Úsalo cuando un usuario solicite publicar un informe, escrito, panel, prototipo, visualización o documento; actualizar un artefacto existente; inspeccionar un artefacto publicado; o revisar la desviación de la fuente observada en .artifacts/manifest.json o manifest.local.json. Los artefactos admiten URLs de canales estables, historial de versiones, temas claro/oscuro, cifrado opcional de contraseñas del lado del cliente y compilaciones determinísticas de Recetas. Los cambios de fuente se detectan por estado y un hook opcional Claude Code Stop; no se editan ni republican automáticamente. No se active para cargas genéricas de archivos, capturas de pantalla, SBOM, paquetes de compilación, ítems de Linear o bloques de contenido de la API de Claude.

Responde siempre en el idioma del usuario.
