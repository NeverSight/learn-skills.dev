Pubblica e mantieni artefatti HTML, Markdown o React autonomi come URL condivisibili. Usalo quando un utente richiede di pubblicare un rapporto, una relazione, una dashboard, un prototipo, una visualizzazione o un documento; aggiornare un artefatto esistente; ispezionare un artefatto pubblicato; o rivedere il drift della sorgente monitorata in .artifacts/manifest.json o manifest.local.json. Gli artefatti supportano URL di canale stabile, cronologia delle versioni, temi chiaro/scuro, crittografia opzionale della password lato client e build Recipe deterministiche. Le modifiche al codice sorgente sono rilevate dallo stato e da un hook opzionale Claude Code Stop; non vengono modificate o ripubblicate automaticamente. Non attivare per caricamenti generici di file, screenshot, SBOM, tarball di build, elementi Linear o blocchi di contenuto dell'API Claude.
