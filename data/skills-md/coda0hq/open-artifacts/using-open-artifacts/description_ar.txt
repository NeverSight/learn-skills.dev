انشر وصيانة قطع أثرية مستقلة ذاتيًا بصيغة HTML أو Markdown أو React كعناوين URL قابلة للمشاركة. استخدمها عندما يطلب المستخدم نشر تقرير أو كتابة أو لوحة تحكم أو نموذج أولي أو تصور أو مستند؛ تحديث قطعة أثرية موجودة؛ فحص قطعة أثرية منشورة؛ أو مراجعة انحراف المصدر المراقَب في .artifacts/manifest.json أو manifest.local.json. تدعم القطع الأثرية عناوين URL ثابتة للقناة، تاريخ النسخ، سمات ساطعة/داكنة، تشفير كلمة مرور من جانب العميل اختياريًا، وبُنايات Recipe حتمية. يتم اكتشاف تغييرات المصدر عن طريق الحالة وخطاف Claude Code Stop اختياري؛ لا يتم تحريرها أو إعادة نشرها تلقائيًا. لا تُفعل للتحميلات العامة للملفات، لقطات الشاشة، SBOMs، أرشفات البَناء (tarballs)، عناصر Linear، أو كتل محتوى Claude API. يرجى دائمًا الرد بلغة المستخدم.
