Publiez et maintenez des artefacts HTML, Markdown ou React autonomes en tant qu’URL partageables. Utilisez‑le lorsqu’un utilisateur demande de publier un rapport, une rédaction, un tableau de bord, un prototype, une visualisation ou un document ; de mettre à jour un artefact existant ; d’inspecter un artefact publié ; ou de passer en revue les dérives de source surveillée dans .artifacts/manifest.json ou manifest.local.json. Les artefacts prennent en charge les URL de canal stable, l’historique des versions, les thèmes clair/sombre, le chiffrement optionnel du mot de passe côté client et les builds Recipe déterministes. Les changements de source sont détectés par le statut et un hook optionnel Claude Code Stop ; ils ne sont pas modifiés ni republiés automatiquement. Ne déclenchez pas cela pour les téléchargements de fichiers génériques, captures d’écran, SBOM, archives de construction, éléments Linear ou blocs de contenu de l’API Claude. Veuillez toujours répondre dans la langue de l'utilisateur.
