Aiuta gli utenti a scoprire e installare le skill dell’agente quando pongono domande come “come faccio a X”, “trova una skill per X”, “esiste una skill che può…”, o esprimono interesse nell’estendere le capacità. Questa skill dovrebbe essere usata quando l’utente cerca una funzionalità che potrebbe esistere come skill installabile. Per favore rispondi sempre nella lingua dell’utente.
