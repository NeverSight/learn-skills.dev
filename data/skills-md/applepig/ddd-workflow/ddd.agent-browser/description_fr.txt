Débogage E2E : utilisez la CLI agent-navigateur pour reproduire des scénarios, observer l'état et localiser la cause profonde des problèmes frontaux. Il est utilisé lorsque les tests E2E échouent, qu'une vérification visuelle du comportement de l'interface utilisateur est nécessaire ou lors du suivi des problèmes frontaux, généralement déclenchés dans /ddd.work. Déclencheur : « debug E2E », « check the page », « why is the test failed », « open the browser », « take a screenshot », « inspect the DOM », « E2E failure », « test broke », « inspect page », /ddd.agent-browser.
