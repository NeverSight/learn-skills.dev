Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Usala quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferiscila rispetto a un semplice git worktree, PTY ad hoc o Uso del Computer quando è coinvolto lo stato di Orca. Usa l’Uso del Computer solo quando è necessaria la gestione di una finestra visibile che una CLI, il filesystem o un’API non possono fare.

Rispondi sempre nella lingua dell'utente.
