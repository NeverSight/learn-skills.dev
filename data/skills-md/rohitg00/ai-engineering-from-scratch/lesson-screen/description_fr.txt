Ouvre un écran de leçon dans le navigateur à côté du terminal pendant qu’un tuteur de cours enseigne. Il affiche les figures enregistrées de la leçon, les traces de code avec les valeurs réelles et les prédictions cliquables. Il crée également une figure pour la leçon à la volée à l’aide des compétences de figure du cours et de toute compétence de figure installée sur l’hôte : un plan, un mécanisme, une machine isométrique ou un modèle 3D. Les clics sont renvoyés au tuteur sous forme d’événements. Phrases déclencheurs : « open the lesson screen », « show me this visually », « show this in 3D », « draw the architecture », « visualize this lesson », « build a figure for this lesson », « lesson screen ».
