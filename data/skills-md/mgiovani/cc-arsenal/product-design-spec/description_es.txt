Autoriza la especificación de diseño para un PRD aprobado (arquitectura de información, flujos de usuario, inventario de pantallas y especificaciones de estado e interacción por pantalla), reutilizando primero la biblioteca de componentes existente del proyecto y trazando cada pantalla de regreso a una ID de requisito del PRD. Enfoque lean por defecto: un design‑spec.md, especificaciones completas solo para las 2‑3 pantallas más críticas, WCAG 2.2 AA delegada a review‑design. Usar para “escribir una especificación de diseño”, “mapear los flujos de usuario”, “inventario de pantallas con estados” o “IA y estados de pantalla para esta característica”. No escribe código UI. No es para una crítica UX de una UI existente (usar review‑design), el sistema de tokens visuales (usar product‑design‑tokens) o la generación de maquetas y imágenes hero (usar codex‑imagegen).
