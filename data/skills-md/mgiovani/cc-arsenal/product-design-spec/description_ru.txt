Создаёт спецификацию дизайна для утверждённого PRD (информационная архитектура, пользовательские потоки, инвентарь экранов и спецификации состояний и взаимодействий для каждого экрана), сначала используя существующую библиотеку компонентов проекта и прослеживая каждый экран к идентификатору требования PRD. По умолчанию — экономичный подход: один файл design-spec.md, полные спецификации только для 2‑3 самых критичных экранов, требования WCAG 2.2 AA делегируются review-design. Используйте для «write a design spec», «map the user flows», «screen inventory with states» или «IA and screen states for this feature». Не пишет UI‑код. Не предназначено для UX‑критики существующего интерфейса (используйте review-design), визуальной системы токенов (используйте product-design-tokens) или создания мокапов и геро‑изображений (используйте codex-imagegen).
