قُم بدمج نماذج FASHN التوليدية للصور والفيديو في مجال الموضة داخل مشروع، أو قم بتشغيلها مباشرةً. استخدمها للتجربة الافتراضية، ربط المنتج بالنموذج، إنشاء/استبدال نموذج، تحويل الوجه إلى نموذج، التحرير، إعادة الإطار، إزالة الخلفية، وتحويل الصورة إلى فيديو، عبر واجهة برمجة التطبيقات REST الخاصة بـ FASHN، أو SDK TypeScript (fashn npm)، أو SDK Python (fashn pip). يرجى الرد دائمًا بلغة المستخدم.
