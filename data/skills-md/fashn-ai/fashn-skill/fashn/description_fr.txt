Intégrez les modèles génératifs d'images et de vidéos FASHN pour la mode dans un projet, ou exécutez‑les en ligne. Utilisez‑les pour l'essai virtuel, le produit‑vers‑modèle, la création/échange de modèle, le visage‑vers‑modèle, l'édition, le recadrage, la suppression d'arrière‑plan et l'image‑vers‑vidéo, via l'API REST FASHN, le SDK TypeScript (fashn npm) ou le SDK Python (fashn pip).
