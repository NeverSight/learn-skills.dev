在編輯、閱讀、產生或推理 Cocos Creator 3.x 專案內的檔案時皆請使用 — .prefab、.scene、.meta、.anim、.mtl、.effect、Marionette 的 .animgraph/.animask/.animgraphvari、3D 資產（.pmtl/.terrain/.mesh/FBX meta）、.fnt、.plist、.pac、.atlas（Spine）、DragonBones、.tmx/.tsx（TiledMap）、AssetBundle 目錄設定，以及專案目錄（library/temp/build/profiles/settings/native）或建置輸出。當中文或英文提及 cocos creator / cocos prefab / 預製件 / 場景 / 動畫 / 材質 / 著色器 / 圖集 / AssetBundle / meta file / UUID / fileId 時觸發。亦在使用者要求新增節點、重新命名預製件、調整材質參數、微調著色器 uniform、插入動畫關鍵幀、變更 bundle 優先級、為 Cocos 專案編寫 .gitignore，或修復損壞的 __id__/__uuid__ 參照時觸發。此技能提供黃金安全規則（哪些可手動編輯、哪些為工具生成、哪些禁止），JSON + __id__ 交叉參照協定，五種相似 ID 系統（uuid / 壓縮 uuid / fileId / classid / shortId），以及每種格式的編輯手冊，避免 Claude 損壞 UUID 或參照圖。
