Utilisez-le chaque fois que vous éditez, lisez, générez ou raisonnez sur des fichiers d’un projet Cocos Creator 3.x — .prefab, .scene, .meta, .anim, .mtl, .effect, Marionette .animgraph/.animask/.animgraphvari, actifs 3D (.pmtl/.terrain/.mesh/FBX meta), .fnt, .plist, .pac, .atlas (Spine), DragonBones, .tmx/.tsx (TiledMap), configuration de répertoire AssetBundle, ainsi que les répertoires du projet (library/temp/build/profiles/settings/native) ou la sortie du build. Déclenchez‑le sur les mentions en chinois ou en anglais de cocos creator / cocos prefab / 預製件 / 場景 / 動畫 / 材質 / 著色器 / 圖集 / AssetBundle / fichier meta / UUID / fileId. Déclenchez‑le également lorsque l’utilisateur demande d’ajouter un nœud, de renommer un prefab, d’ajuster les paramètres d’un matériau, de modifier les uniformes d’un shader, d’insérer des images‑clés d’animation, de changer la priorité d’un bundle, d’écrire un .gitignore pour un projet Cocos, ou de réparer des références __id__/__uuid__ cassées. La compétence fournit les règles de sécurité d’or (ce qui est éditable à la main versus généré par l’outil versus interdit), le protocole de référence croisée JSON + __id__, les cinq systèmes d’identifiants similaires (uuid / uuid compressé / fileId / classid / shortId), ainsi que des guides d’édition par format afin que Claude ne corrompe pas les UUID ou les graphes de références.
