Usa ogni volta che modifichi, leggi, generi o ragioni sui file all'interno di un progetto Cocos Creator 3.x — .prefab, .scene, .meta, .anim, .mtl, .effect, Marionette .animgraph/.animask/.animgraphvari, asset 3D (.pmtl/.terrain/.mesh/FBX meta), .fnt, .plist, .pac, .atlas (Spine), DragonBones, .tmx/.tsx (TiledMap), configurazione della cartella AssetBundle e le directory del progetto (library/temp/build/profiles/settings/native) o l'output di build. Attiva su menzioni in cinese o inglese di cocos creator / cocos prefab / 預製件 / 場景 / 動畫 / 材質 / 著色器 / 圖集 / AssetBundle / file meta / UUID / fileId. Attiva anche quando l'utente chiede di aggiungere un nodo, rinominare un prefab, regolare i parametri del materiale, modificare le uniformi dello shader, inserire fotogrammi chiave dell'animazione, cambiare la priorità del bundle, scrivere un .gitignore per un progetto Cocos o correggere riferimenti __id__/__uuid__ rotti. La skill fornisce le regole di sicurezza d'oro (cosa è modificabile a mano vs. generato dallo strumento vs. vietato), il protocollo di cross‑reference JSON + __id__, i cinque sistemi di identificazione simili (uuid / uuid compresso / fileId / classid / shortId) e i playbook di editing per formato affinché Claude non corrompa UUID o grafi di riferimento.
