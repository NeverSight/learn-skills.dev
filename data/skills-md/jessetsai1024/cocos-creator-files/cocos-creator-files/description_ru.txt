Используйте при любом редактировании, чтении, генерации или рассуждении о файлах внутри проекта Cocos Creator 3.x — .prefab, .scene, .meta, .anim, .mtl, .effect, Marionette .animgraph/.animask/.animgraphvari, 3D‑активы (.pmtl/.terrain/.mesh/FBX meta), .fnt, .plist, .pac, .atlas (Spine), DragonBones, .tmx/.tsx (TiledMap), конфигурацию каталогов AssetBundle и каталоги проекта (library/temp/build/profiles/settings/native) или вывод сборки. Срабатывает при упоминании на китайском или английском cocos creator / cocos prefab / 預製件 / 場景 / 動畫 / 材質 / 著色器 / 圖集 / AssetBundle / meta file / UUID / fileId. Также срабатывает, когда пользователь просит добавить узел, переименовать префаб, настроить параметры материала, изменить uniform‑ы шейдера, вставить ключевые кадры анимации, изменить приоритет бандла, написать .gitignore для проекта Cocos или исправить сломанные ссылки __id__/__uuid__. Навык предоставляет золотые правила безопасности (что можно редактировать вручную, а что генерируется инструментом или запрещено), протокол перекрестных ссылок JSON + __id__, пять схожих систем идентификаторов (uuid / сжатый uuid / fileId / classid / shortId) и пошаговые руководства по редактированию для каждого формата, чтобы Claude не повредил UUID или графы ссылок.
