استخدمه عند تحرير أو قراءة أو إنشاء أو التفكير حول الملفات داخل مشروع Cocos Creator 3.x — .prefab، .scene، .meta، .anim، .mtl، .effect، Marionette .animgraph/.animask/.animgraphvari، أصول 3D (.pmtl/.terrain/.mesh/FBX meta)، .fnt، .plist، .pac، .atlas (Spine)، DragonBones، .tmx/.tsx (TiledMap)، إعدادات دليل AssetBundle، ودلائل المشروع (library/temp/build/profiles/settings/native) أو ناتج البناء. يتم التفعيل عند ذكر cocos creator / cocos prefab / 預製件 / 場景 / 動畫 / 材質 / 著色器 / 圖集 / AssetBundle / ملف meta / UUID / fileId بالصينية أو الإنجليزية. كما يتم التفعيل عندما يطلب المستخدم إضافة عقدة، إعادة تسمية prefab، تعديل معلمات المادة، تعديل موحدات الـ shader، إدراج إطارات مفتاح للرسوم المتحركة، تغيير أولوية الحزمة، كتابة .gitignore لمشروع Cocos، أو إصلاح مراجع __id__/__uuid__ المكسورة. المهارة توفر قواعد الأمان الذهبية (ما يمكن تحريره يدويًا مقابل ما ينشئه الأداة وما هو ممنوع)، بروتوكول الإشارة المتقاطع JSON + __id__، أنظمة الهوية الخمسة المتشابهة (uuid / uuid مضغوط / fileId / classid / shortId)، ودلائل تحرير حسب كل تنسيق حتى لا يفسد Claude UUIDs أو رسومات الإشارة.
