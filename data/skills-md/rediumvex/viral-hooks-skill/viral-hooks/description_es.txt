Genera 3 variantes de ganchos de parada de desplazamiento para scripts de video de formato corto (Reels, TikTok, YouTube, LinkedIn, X). Se usa cuando el usuario está escribiendo un script para un video de formato corto, pide ideas de ganchos, necesita una línea de apertura para un carrete/publicación o pega un script y quiere ganchos alternativos. Extrae de una biblioteca de 100 fórmulas de gancho a través de 10 desencadenantes de psicología (curiosidad, contrarian, autoridad, emocional, listicle, pregunta, historia, negación, especificidad, confesión).
