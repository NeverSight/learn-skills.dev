Utilisez lorsque l'utilisateur souhaite interagir avec la blockchain Hedera : créer / transférer des jetons, gérer des NFT, déployer des contrats, gérer des topics, transférer des HBAR, signer des défis de paiement x402, configurer les réseaux. UTILISEZ également lorsque qu’une requête HTTP renvoie 402 avec un en‑tête PAYMENT-REQUIRED pour le schéma Hedera x402 (ou que l’utilisateur veut payer un point d’accès protégé par x402 sur Hedera) : lisez references/x402.md pour le flux complet GET→402→sign→retry. Fournit la spécification complète pour l’outil CLI hcli. Mots‑clés déclencheurs : hedera, hiero, hbar, token, nft, contract, topic, x402, 402, payment‑required, hcli, ledger.
