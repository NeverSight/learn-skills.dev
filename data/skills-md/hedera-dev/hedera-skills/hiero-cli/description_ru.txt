Используйте, когда пользователь хочет взаимодействовать с блокчейном Hedera: создавать/переводить токены, управлять NFT, развертывать контракты, управлять топиками, переводить HBAR, подписывать запросы оплаты x402, настраивать сети. ТАКЖЕ используйте, когда HTTP‑запрос возвращает 402 с заголовком PAYMENT-REQUIRED для схемы Hedera x402 (или пользователь хочет оплатить endpoint, защищённый x402, в Hedera): см. references/x402.md для полного потока GET→402→sign→retry. Предоставляет полную спецификацию для инструмента hcli CLI. Ключевые слова‑триггеры: hedera, hiero, hbar, token, nft, contract, topic, x402, 402, payment-required, hcli, ledger.
