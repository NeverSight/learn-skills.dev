Wie man Themen erstellt, Nachrichten übermittelt und sich in Echtzeit auf Nachrichtenströme von Hedera mit dem Hiero JavaScript SDK (@hiero-ledger/sdk) abonniert. Verwenden Sie diese Fähigkeit immer, wenn der Benutzer mit dem Hedera Consensus Service (HCS) arbeiten möchte, einschließlich Themenerstellung, Nachrichtenübermittlung, Pub/Sub-Messaging, Mirror‑Node‑Abonnements, chunkweise große Nachrichten, Themengebühren oder jeglicher konsensbezogener Vorgang in JavaScript oder TypeScript. Auch auslösen, wenn Nutzer @hashgraph/sdk‑Themenoperationen, Ereignisprotokollierung auf Hedera, dezentrale Kommunikation, Prüfpfade oder geordnete Nachrichtenströme erwähnen. Bitte immer in der Sprache des Benutzers antworten.
