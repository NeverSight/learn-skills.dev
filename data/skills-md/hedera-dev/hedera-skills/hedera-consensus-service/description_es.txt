Cómo crear temas, enviar mensajes y suscribirse a flujos de mensajes en tiempo real en Hedera usando el SDK de JavaScript Hiero (@hiero-ledger/sdk). Utiliza esta habilidad siempre que el usuario quiera trabajar con Hedera Consensus Service (HCS), incluyendo la creación de temas, el envío de mensajes, mensajería pub/sub, suscripciones a nodos espejo, mensajes grandes fragmentados, tarifas de temas o cualquier operación relacionada con el consenso en JavaScript o TypeScript. También actívala cuando los usuarios mencionen operaciones de temas de @hashgraph/sdk, registro de eventos en Hedera, mensajería descentralizada, rastros de auditoría o flujos de mensajes ordenados.

Por favor, responde siempre en el idioma del usuario.
