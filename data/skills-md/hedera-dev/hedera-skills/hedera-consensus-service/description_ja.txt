Hiero JavaScript SDK（@hiero-ledger/sdk）を使用して Hedera 上でトピックを作成し、メッセージを送信し、リアルタイムのメッセージストリームを購読する方法。ユーザーが Hedera Consensus Service（HCS）を利用したいときは、このスキルを使用してください。トピック作成、メッセージ送信、pub/sub メッセージング、ミラーノードの購読、チャンク化された大容量メッセージ、トピック手数料、あるいは JavaScript や TypeScript におけるコンセンサス関連の操作全般に対応します。また、ユーザーが @hashgraph/sdk のトピック操作、Hedera のイベントロギング、分散型メッセージング、監査トレイル、順序付けされたメッセージストリームなどに言及した場合にもトリガーしてください。

常にユーザーの言語で応答してください。
