Comment créer des sujets, envoyer des messages et s’abonner à des flux de messages en temps réel sur Hedera à l’aide du SDK JavaScript Hiero (@hiero-ledger/sdk). Utilisez cette compétence chaque fois que l’utilisateur souhaite travailler avec le Hedera Consensus Service (HCS), y compris la création de sujets, la soumission de messages, la messagerie pub/sub, les abonnements aux nœuds miroirs, les gros messages fragmentés, les frais de sujet ou toute opération liée au consensus en JavaScript ou TypeScript. Déclenchez également la compétence lorsque les utilisateurs mentionnent les opérations de sujet de @hashgraph/sdk, la journalisation d’événements sur Hedera, la messagerie décentralisée, les pistes d’audit ou les flux de messages ordonnés.
