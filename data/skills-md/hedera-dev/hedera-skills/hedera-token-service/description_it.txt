Come creare, gestire e trasferire token su Hedera usando l'SDK JavaScript Hiero (@hiero-ledger/sdk). Utilizza questa competenza ogni volta che l'utente desidera lavorare con token fungibili, NFT, creazione di token, minting, burning, trasferimenti, associazione di token, commissioni personalizzate (fisse, frazionarie, royalty), airdrop, operazioni KYC/freeze/wipe/pause, o qualsiasi operazione HTS (Hedera Token Service) in JavaScript o TypeScript. Attiva anche quando gli utenti menzionano le operazioni token di @hashgraph/sdk, equivalenti ERC‑20/ERC‑721 su Hedera, o la tokenizzazione sulla rete Hedera.
