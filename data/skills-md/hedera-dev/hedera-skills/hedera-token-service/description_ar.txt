كيفية إنشاء وإدارة وتحويل الرموز على Hedera باستخدام مكتبة Hiero JavaScript SDK (@hiero-ledger/sdk). استخدم هذه المهارة كلما أراد المستخدم العمل مع الرموز القابلة للاستبدال، NFTs، إنشاء الرموز، سكّها، حرقها، تحويلها، ربط الرموز، الرسوم المخصصة (ثابتة، جزئية، ملكية)، الإغلاقات الجوية، عمليات KYC/التجميد/المسح/الإيقاف المؤقت، أو أي عملية من خدمة رموز Hedera (HTS) في JavaScript أو TypeScript. كما يتم التفعيل عندما يذكر المستخدمون عمليات رموز @hashgraph/sdk، ما يعادل ERC‑20/ ERC‑721 على Hedera، أو الترميز على شبكة Hedera.
