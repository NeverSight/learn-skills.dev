HederaでHiero JavaScript SDK（@hiero-ledger/sdk）を使用してトークンを作成、管理、転送する方法。ユーザーが代替可能トークン、NFT、トークン作成、ミンティング、バーン、転送、トークンアソシエーション、カスタム手数料（固定、割合、ロイヤリティ）、エアドロップ、KYC／凍結／ワイプ／一時停止操作、またはJavaScriptやTypeScriptでのHTS（Hedera Token Service）操作を行いたいときにこのスキルを使用してください。また、ユーザーが @hashgraph/sdk のトークン操作、Hedera上のERC-20／ERC-721相当、またはHederaネットワークでのトークン化に言及したときにトリガーしてください。

常にユーザーの言語で回答してください。
