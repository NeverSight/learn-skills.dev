Как создавать, управлять и переводить токены в Hedera с помощью Hiero JavaScript SDK (@hiero-ledger/sdk). Используйте этот навык, когда пользователь хочет работать с взаимозаменяемыми токенами, NFT, создавать токены, чеканить, сжигать, выполнять переводы, ассоциировать токены, настраивать пользовательские комиссии (фиксированные, дробные, роялти), проводить airdrop’ы, операции KYC/заморозка/очистка/пауза, или любые операции HTS (Hedera Token Service) на JavaScript или TypeScript. Также активируйте, когда пользователи упоминают операции с токенами @hashgraph/sdk, эквиваленты ERC‑20/ERC‑721 в Hedera или токенизацию в сети Hedera.

Пожалуйста, всегда отвечайте на языке пользователя.
