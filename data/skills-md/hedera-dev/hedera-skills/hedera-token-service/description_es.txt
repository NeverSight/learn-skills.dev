Cómo crear, administrar y transferir tokens en Hedera usando el SDK de JavaScript Hiero (@hiero-ledger/sdk). Utiliza esta habilidad siempre que el usuario quiera trabajar con tokens fungibles, NFTs, creación de tokens, acuñación, quema, transferencias, asociación de tokens, tarifas personalizadas (fijas, fraccionarias, de regalías), airdrops, operaciones KYC/congelar/borrar/pausar, o cualquier operación HTS (Servicio de Tokens Hedera) en JavaScript o TypeScript. También actívala cuando los usuarios mencionen operaciones de tokens de @hashgraph/sdk, equivalentes ERC-20/ERC-721 en Hedera, o tokenización en la red Hedera.
