Comment créer, gérer et transférer des jetons sur Hedera en utilisant le SDK JavaScript Hiero (@hiero-ledger/sdk). Utilisez cette compétence chaque fois que l'utilisateur souhaite travailler avec des jetons fongibles, des NFT, la création de jetons, l’émission, la destruction, les transferts, l’association de jetons, les frais personnalisés (fixes, fractionnels, royalties), les airdrops, les opérations KYC/gel/effacement/pause, ou toute opération HTS (Hedera Token Service) en JavaScript ou TypeScript. Activez également la compétence lorsque les utilisateurs mentionnent les opérations de jetons @hashgraph/sdk, les équivalents ERC‑20/ERC‑721 sur Hedera, ou la tokenisation sur le réseau Hedera.

Veuillez toujours répondre dans la langue de l'utilisateur.
