Supprimez les traces d’écriture IA du texte. Utilisez-le lorsqu’un artefact textuel est le livrable ou une partie majeure de celui‑ci, comme la documentation, le texte d’une PR ou d’un commit, les notes de version, les rapports, les copies marketing, les commentaires de code, ou lorsqu’on vous demande de dés‑slop, d’humaniser ou de nettoyer le texte. Pas pour les réponses de chat, les mises à jour de statut ou les résumés de réalisation liés à une tâche non textuelle.

Veuillez toujours répondre dans la langue de l’utilisateur.
