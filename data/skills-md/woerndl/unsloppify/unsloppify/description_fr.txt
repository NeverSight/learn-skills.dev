Supprimez les indications d’écriture IA du texte. Utilisez‑le lorsque l’artefact textuel est le livrable ou une partie majeure de celui‑ci, comme la documentation, le texte d’une PR ou d’un commit, les notes de version, les rapports, le texte marketing, les commentaires de code, ou lorsqu’on vous demande de désloper, d’humaniser ou de nettoyer le texte. Pas pour les réponses de chat, les mises à jour de statut ou les résumés d’accomplissement liés à une tâche non textuelle.

Veuillez toujours répondre dans la langue de l’utilisateur.
