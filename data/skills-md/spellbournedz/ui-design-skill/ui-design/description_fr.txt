Concevoir, créer, redessiner, peaufiner ou réviser l’interface utilisateur d’un produit avec une direction visuelle propre au produit et un niveau d’exigence élevé. À utiliser pour les pages front‑end, les composants, les tableaux de bord, les formulaires, les surfaces Web responsives, les travaux de système de design, les implémentations à partir de captures d’écran ou de Figma, le nettoyage d’UI, les décisions d’interaction et d’animation, ou chaque fois qu’une interface risque d’avoir l’air générique, templatisée ou générée par IA. À éviter pour les travaux uniquement back‑end ou les modifications front‑end mécaniques qui n’affectent pas matériellement l’expérience utilisateur.
