Utilizza questa abilità ogni volta che un file di foglio di calcolo è l'input o l'output principale. Ciò significa qualsiasi compito in cui l'utente vuole: aprire, leggere, modificare o sistemare un file .xlsx, .xlsm, .xltx, .csv o .tsv esistente (ad esempio aggiungere colonne, calcolare formule, formattare, creare grafici, pulire dati disordinati); creare un nuovo foglio di calcolo da zero o da altre fonti di dati; o convertire tra formati di file tabulari. Attiva soprattutto quando l'utente fa riferimento a un file di foglio di calcolo per nome o percorso — anche casualmente (come “il xlsx nei miei download”) — e desidera che venga fatto qualcosa su di esso o prodotto da esso. Attiva anche per la pulizia o la ristrutturazione di file di dati tabulari disordinati (righe mal formate, intestazioni fuori posto, dati spazzatura) in fogli di calcolo corretti. Il risultato deve essere un file di foglio di calcolo. NON attivare quando il risultato principale è un documento Word, un report HTML, uno script Python autonomo, una pipeline di database o un'integrazione API di Google Sheets, anche se sono coinvolti dati tabulari.

Rispondi sempre nella lingua dell'utente.
