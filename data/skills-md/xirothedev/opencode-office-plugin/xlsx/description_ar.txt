استخدم هذه المهارة في أي وقت يكون ملف جدول البيانات هو المدخل أو المخرج الأساسي. يعني ذلك أي مهمة يرغب فيها المستخدم في: فتح، قراءة، تحرير، أو إصلاح ملف .xlsx أو .xlsm أو .xltx أو .csv أو .tsv موجود (مثل إضافة أعمدة، حساب الصيغ، تنسيق، إنشاء رسوم بيانية، تنظيف البيانات الفوضوية)؛ إنشاء جدول بيانات جديد من الصفر أو من مصادر بيانات أخرى؛ أو التحويل بين صيغ الملفات الجدولية. يجب تشغيلها خاصة عندما يشير المستخدم إلى ملف جدول بيانات بالاسم أو المسار — حتى بصورة عارضة (مثل "ملف الـ xlsx في التنزيلات") — ويريد القيام بشيء ما عليه أو إنتاج شيء منه. كما يجب تشغيلها لتنظيف أو إعادة هيكلة ملفات البيانات الجدولية الفوضوية (صفوف غير صحيحة، عناوين في غير موضعها، بيانات غير مرغوبة) إلى جداول بيانات صحيحة. يجب أن يكون الناتج ملف جدول بيانات. لا تُفعَّل عندما يكون الناتج الأساسي مستند Word أو تقرير HTML أو برنامج بايثون مستقل أو دورة معالجة قاعدة بيانات أو تكامل API مع Google Sheets، حتى وإن كان هناك بيانات جدولة متضمنة.
