Utiliza esta habilidad cada vez que un archivo de hoja de cálculo sea la entrada o salida principal. Esto implica cualquier tarea en la que el usuario quiera: abrir, leer, editar o corregir un archivo .xlsx, .xlsm, .xltx, .csv o .tsv existente (p. ej., añadir columnas, calcular fórmulas, formatear, crear gráficos, limpiar datos desordenados); crear una nueva hoja de cálculo desde cero o a partir de otras fuentes de datos; o convertir entre formatos de archivos tabulares. Activa especialmente cuando el usuario haga referencia a un archivo de hoja de cálculo por nombre o ruta — incluso de manera casual (como "el xlsx en mis descargas") — y quiera que se le haga algo o se genere a partir de él. También actívala para limpiar o reestructurar archivos de datos tabulares desordenados (filas malformadas, encabezados fuera de lugar, datos basura) en hojas de cálculo correctas. El entregable debe ser un archivo de hoja de cálculo. NO lo actives cuando el entregable principal sea un documento de Word, informe HTML, script Python independiente, canal de base de datos o integración con la API de Google Sheets, aunque se involucren datos tabulares.

Por favor, siempre responde en el idioma del usuario.
