استخدم هذه المهارة كلما كان ملف ‎.pptx أو ‎.potx مشاركًا بأي طريقة — كمدخل، مخرج، أو كلاهما. يشمل ذلك: إنشاء مجموعة شرائح أو عروض تقديمية؛ قراءة أو تحليل أو استخراج النص من أي ملف ‎.pptx أو ‎.potx (حتى إذا كان المحتوى المستخرج سيُستخدم في مكان آخر، مثل بريد إلكتروني أو ملخص)؛ تعديل أو تحديث العروض التقديمية الحالية؛ دمج أو تقسيم ملفات الشرائح؛ التعامل مع القوالب (.potx)، التخطيطات، ملاحظات المتحدث، أو التعليقات. يتم التفعيل كلما ذكر المستخدم كلمة «deck» أو «slides» أو «presentation» أو أشار إلى اسم ملف ‎.pptx أو ‎.potx، بغض النظر عما يخطط للقيام به بالمحتوى لاحقًا. إذا كان من الضروري فتح أو إنشاء أو تعديل ملف ‎.pptx أو ‎.potx، استخدم هذه المهارة.
