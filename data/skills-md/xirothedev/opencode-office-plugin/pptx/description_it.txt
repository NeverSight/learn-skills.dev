Usa questa competenza ogni volta che un file .pptx o .potx è coinvolto in qualsiasi modo — come input, output o entrambi. Ciò include: creare deck di diapositive, deck di presentazione o presentazioni; leggere, analizzare o estrarre testo da qualsiasi file .pptx o .potx (anche se il contenuto estratto sarà utilizzato altrove, ad esempio in una email o in un riepilogo); modificare, aggiornare o rivedere presentazioni esistenti; combinare o dividere file diapositive; lavorare con modelli (.potx), layout, note del presentatore o commenti. Attiva la competenza ogni volta che l'utente menziona "deck", "slides", "presentation" o fa riferimento a un nome di file .pptx o .potx, indipendentemente da ciò che intende fare con il contenuto successivamente. Se è necessario aprire, creare o manipolare un file .pptx o .potx, usa questa competenza.

Rispondi sempre nella lingua dell'utente.
