استخدم هذه المهارة كلما رغب المستخدم في إنشاء أو قراءة أو تعديل أو التعامل مع مستندات Word (.docx) أو قوالب Word (.dotx). تشمل عوامل التفعيل: أي إشارة إلى "Word doc" أو "word document" أو ".docx" أو ".dotx" أو طلبات إنتاج مستندات احترافية بتنسيق مثل فهارس المحتويات أو العناوين أو أرقام الصفحات أو رؤوس الرسائل. استخدمها أيضًا عند استخراج أو إعادة تنظيم المحتوى من ملفات .docx أو .dotx، وإدراج أو استبدال الصور في المستندات، وإجراء البحث والاستبدال في ملفات Word، والعمل مع التغييرات المتتبعة أو التعليقات، أو تحويل المحتوى إلى مستند Word مصقول. إذا طلب المستخدم "تقرير" أو "مذكرة" أو "رسالة" أو "قالب" أو أي مخرجات مشابهة بصيغة Word أو .docx، استخدم هذه المهارة. لا تستخدمها للملفات PDF أو جداول البيانات أو مستندات Google أو مهام البرمجة العامة غير المتعلقة بإنشاء المستندات.
