Utilizza questa competenza ogni volta che l'utente desidera creare, leggere, modificare o manipolare documenti Word (.docx) o modelli Word (.dotx). I trigger includono: qualsiasi menzione di “Word doc”, “word document”, “.docx”, “.dotx”, o richieste di produrre documenti professionali con formattazione come indici, intestazioni, numeri di pagina o testate. Usala anche quando si estrae o riorganizza contenuto da file .docx o .dotx, si inseriscono o sostituiscono immagini nei documenti, si esegue ricerca e sostituzione nei file Word, si lavora con modifiche tracciate o commenti, o si converte il contenuto in un documento Word rifinito. Se l'utente chiede un “report”, “memo”, “lettera”, “modello” o un risultato simile in formato Word o .docx, utilizza questa competenza. NON usarla per PDF, fogli di calcolo, Google Docs o compiti di programmazione generali non correlati alla generazione di documenti.

Rispondi sempre nella lingua dell'utente.
