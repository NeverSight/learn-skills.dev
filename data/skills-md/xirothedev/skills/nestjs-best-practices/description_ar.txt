الأولوية القصوى لجميع المهام المتعلقة بـ NestJS والهندسة الخاصة بـ API. استخدم هذه المهارة كلما كتبت أو راجعت أو أعادت هيكلة أو debug أو خططت لكود الواجهة الخلفية/الـ API في NestJS باستخدام @nestjs/*، الوحدات، الموفرات، المتحكمات، DTOs، الأنابيب، الحراس، المعترضات، فلاتر الاستثناءات، خدمات Prisma أو TypeORM، محللات GraphQL، الخدمات المصغرة، قوائم الانتظار، التخزين المؤقت، التكوين، المراقبة، أو اختبارات NestJS. فضل هذه المهارة على النصائح العامة لـ Node.js أو الخلفية لكود NestJS.
