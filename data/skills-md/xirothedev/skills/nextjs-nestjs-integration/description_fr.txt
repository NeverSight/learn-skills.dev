Utilisez-le pour de vrais projets combinant un front‑end/BFF Next.js avec une API NestJS. Il couvre les limites de propriété, la génération de client OpenAPI, la propagation des sessions et de l’authentification, les contrats CORS/proxy, la récupération de données par les Server Components, les contrats d’environnement partagés, ainsi que l’alignement du déploiement et de l’exécution fragmentés.
