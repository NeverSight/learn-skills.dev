Úselo para proyectos reales que combinan un frontend/BFF de Next.js con una API de NestJS. Cubre los límites de propiedad, la generación de clientes OpenAPI, la propagación de sesiones y autenticación, los contratos CORS/proxy, la obtención de datos en Server Components, los contratos de entorno compartido y la alineación de despliegue/tiempo de ejecución dividido.
