Создайте пользовательские потоки данных ArcGIS Enterprise (CDF) — поставщики Node.js/Koop, которые предоставляют внешнюю систему как сервис объектов ArcGIS. Используйте, когда пользователь пишет поставщика CDF или model.js (getData/editData/authorize/getMetadata), использует CLI cdf или хочет предоставить базу данных, API или другую внешнюю систему в качестве сервиса объектов в ArcGIS Enterprise.
