Crea ArcGIS Enterprise Custom Data Feeds (CDF): provider Node.js/Koop che espongono un sistema esterno come ArcGIS Feature Service. Utilizzare quando l'utente scrive un provider CDF o model.js (getData/editData/authorize/getMetadata), utilizza la CLI cdf o desidera esporre un database, un'API o un altro sistema esterno come servizio di funzionalità in ArcGIS Enterprise.
