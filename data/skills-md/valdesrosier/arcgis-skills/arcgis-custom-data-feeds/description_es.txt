Cree fuentes de datos personalizadas (CDF) de ArcGIS Enterprise: proveedores de Node.js/Koop que exponen un sistema externo como un servicio de funciones de ArcGIS. Úselo cuando el usuario escribe un proveedor CDF o model.js (getData/editData/authorize/getMetadata), usa la CLI cdf o desea exponer una base de datos, API u otro sistema externo como un servicio de entidades en ArcGIS Enterprise.
