Scrivi o modifica un codependix.config.ts — quali tipi di grafo vengono eseguiti, sovrascritture per progetto, pattern glob di inclusione ed esclusione, il grafo dell’intero workspace, dove finisce ogni esportazione e le regole di confine contro le quali ogni grafo costruito viene valutato. Utilizzalo quando un workspace non ha ancora una configurazione codependix, quando un’esecuzione non ha prodotto output perché tutto è stato risolto verso il target none, quando aggiungi una destinazione JSON o Markdown, quando scegli tra un blocco di ancoraggio e un file autonomo, quando una configurazione è rifiutata per una destinazione mancante o per un selettore vuoto, quando aggiungi una regola forbid, allow o acyclic, o quando decidi se una singola configurazione possa descrivere tutti i progetti in un workspace.
