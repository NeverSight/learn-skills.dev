Scrivi o modifica un codependix.config.ts — quali tipi di grafo vengono eseguiti, le sovrascritture per progetto, i glob di inclusione ed esclusione, il grafo dell’intero workspace, dove atterra ogni esportazione e le regole di confine contro le quali ogni grafo costruito viene valutato. Usalo quando un workspace non ha ancora una configurazione codependix, quando un’esecuzione non ha prodotto output perché tutto è stato risolto al target none, quando si aggiunge una destinazione JSON o Markdown, quando si sceglie tra un blocco di ancoraggio e un file autonomo, quando una configurazione viene rifiutata per destinazione mancante o selettore vuoto, quando si aggiunge una regola forbid, allow o acyclic, o quando si decide se una configurazione può descrivere tutti i progetti in un workspace.
