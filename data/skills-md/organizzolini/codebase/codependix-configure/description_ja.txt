codependix.config.ts を作成または編集する — 実行するグラフの種類、プロジェクトごとのオーバーライド、include と exclude の glob パターン、ワークスペース全体のグラフ、各エクスポート先、そして構築されたグラフが評価される境界ルールを指定します。ワークスペースにまだ codependix 設定がない場合、実行が何も出力しなかった（すべてが target none に解決された）場合、JSON や Markdown の出力先を追加する場合、アンカーブロックとスタンドアロンファイルのどちらかを選択する場合、設定が出力先の欠如や空のセレクタで拒否された場合、forbid、allow、または acyclic ルールを追加する場合、あるいは 1 つの設定がワークスペース内のすべてのプロジェクトを記述できるかどうかを判断する場合に使用します。
