Ajoutez ou modifiez un générateur conformetry, puis écrivez le modèle qu’il rend. Utilisez‑le lorsqu’un générateur nécessaire n’existe pas encore ; lors de l’édition d’un fichier de configuration conformetry ; lors de l’écriture ou de la modification de fichiers dans un répertoire de modèles ; lors du choix de placeholders ou de variantes de casse de nommage ; lorsqu’un fichier généré apparaît avec une valeur vide ou un segment de chemin étrange ; ou lorsqu’une commande conformetry refuse de s’exécuter parce que le plugin générateur émis est obsolète.

Veuillez toujours répondre dans la langue de l’utilisateur.
