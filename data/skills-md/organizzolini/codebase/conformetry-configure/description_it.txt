Aggiungi o modifica un generatore conformetry e scrivi il modello che genera. Usalo quando un generatore necessario non esiste ancora; quando modifichi un file di configurazione conformetry; quando scrivi o cambi file in una directory di template; quando scegli segnaposti o varianti di casse di denominazione; quando un file generato risulta con un valore vuoto o una parte di percorso strana; oppure quando un comando conformetry rifiuta di eseguire perché il plugin del generatore prodotto è obsoleto.
