執行 callidescope 並閱讀其輸出──整個工作區的追蹤、單一專案的 gate 判決，或是對一個或多個可呼叫項目（以 file#qualified-name 形式指定）執行 depth 與 breadth 指令。於以下情況使用：在執行 callidescope 或 npx callidescope 時、在閱讀呼叫堆疊或 breadth 行時、在閱讀每個專案的 gate 或 trace 目標所輸出的內容時、在閱讀專案 README 的 Limits 表格時、當 depth 以「≥ n」顯示需要解釋時、在閱讀已提交的 markdown 報告、mermaid 圖表或 JSON 報告時、當使用 --directories 縮小執行範圍卻報告出框架、堆疊或未指向的專案時、當 depth 移動卻沒有相應的編輯說明時、或是在詢問「是誰呼叫這個？」、「它會呼叫什麼？」、「此重新命名會影響哪些地方？」以及「在重構開始前，這個可呼叫項目應如何切分？」時。
