Esegui callidescope e leggi ciò che ha stampato — una traccia dell’intero spazio di lavoro, il verdetto del gate di un progetto o i comandi di profondità e ampiezza su una o più callable, ciascuna indicata come file#nome‑qualificato. Usa quando esegui callidescope o npx callidescope, quando leggi una stack di chiamate o una riga di ampiezza, quando leggi ciò che ha stampato un gate o un target di traccia per progetto, quando consulti la tabella Limits del README di un progetto, quando una profondità stampata come “≥ n” richiede interpretazione, quando leggi un report markdown committato, un diagramma mermaid o un report JSON, quando un’esecuzione limitata con --directories segnala un frame, una stack o un progetto a cui l’esecuzione non è mai stata indirizzata, quando una profondità è cambiata senza una modifica che lo spieghi, o quando chiedi chi lo chiama, cosa chiama, quali file verrebbero toccati da questa rinomina e dove dovrebbe essere suddivisa questa callable prima di avviare una refactoring.
