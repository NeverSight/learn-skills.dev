Ejecuta callidescope y lee lo que imprimió — una traza de todo el espacio de trabajo, el veredicto de la compuerta de un proyecto, o los comandos de profundidad y amplitud contra uno o más llamables, cada uno direccionado como archivo#nombre-calificado. Usa cuando ejecutes callidescope o npx callidescope, cuando leas una pila de llamadas o una fila de amplitud, cuando leas lo que imprimió una compuerta por proyecto o un objetivo de traza, cuando consultes la tabla Límites del README de un proyecto, cuando una profundidad impresa como "≥ n" requiera interpretación, cuando revises un informe markdown comprometido, un diagrama mermaid o un informe JSON, cuando una ejecución limitada con --directories informe un marco, una pila o un proyecto al que la ejecución nunca apuntó, cuando una profundidad cambie sin una edición que lo explique, o cuando preguntes quién llama a esto, qué llama, qué tocaría al renombrar esto y dónde debería dividirse este llamable antes de iniciar una refactorización.
