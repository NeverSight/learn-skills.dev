Ejecuta una verificación de conformidad de conformetry y actúa según lo que informe. Úsala cuando falle un objetivo conformetry-validate; cuando una ejecución compuesta de lint informe diferencias de conformidad; cuando un informe indique un archivo faltante, una declaración faltante, un comentario faltante, una instancia ambigua o una instancia no coincidente; al decidir si editar una instancia o regenerarla; o antes de afirmar que el código generado está terminado. Cubre tanto el plugin Nx como el host de línea de comandos de conformetry.
