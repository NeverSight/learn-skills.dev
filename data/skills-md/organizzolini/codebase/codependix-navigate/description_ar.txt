أجب عن أسئلة تنقل الاعتماديات والهندسة المعمارية باستخدام أوامر codependix CLI أو الرسوم البيانية الملتزم بها. استخدمها عند العثور على مسارات الاعتماديات بين المشاريع أو الملفات أو وحدات NestJS، وتتبع نطاق الانفجار، وتحديد ما يلمس أو يستورد ملفًا أو حزمة، واختيار أعلام التحديد لتقليل تكاليف التشغيل، أو قراءة مخططات README الملتزم بها عبر الحزم دون تشغيل الأوامر.
