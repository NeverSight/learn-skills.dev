codependix 의존성 그래프 내보내기 또는 경계 검사를 실행하고, `--check boundaries`, `--check reports`, `--write` 중 하나를 선택하며, 실행을 워크스페이스 루트나 설정 파일에 지정하거나 codependix 가 생성한 Mermaid 블록 또는 JSON 그래프를 읽습니다. codependix 혹은 `npx codependix` 를 실행할 때, 실행이 0을 반환하고 아무 것도 쓰지 않을 때, `--check` 가 값이 없어 거부될 때, 그래프 유형을 선택하는 플래그를 찾을 때, CI 단계에 codependix 를 연결할 때, 또는 내보낸 Nx Neighborhood, NestJS 모듈 그래프, 파일 수준 import 그래프를 읽을 때 사용합니다. 작업 실행기를 가정하지 않고 명령줄 호스트를 직접 다룹니다.
