Generiere Code mit einem Conformetry‑Generator, anstatt ihn von Hand zu schreiben. Verwende ihn, wenn du ein Modul, eine Komponente, einen Service, eine Anwendung oder ein Paket zu einem Workspace hinzufügst, der eine Conformetry‑Konfiguration besitzt; wenn du entscheiden möchtest, ob für die Form, die du erstellen willst, ein Generator existiert; wenn ein Generatorlauf Dateien überschrieben oder fehlerhaft abgelegt hat; oder wenn ein Conformance‑Durchlauf eine Datei meldet, die ein Generator hätte erzeugen sollen. Deckt sowohl das Nx‑Plugin als auch den Conformetry‑Kommandozeilen‑Host ab, deren Eingabeverträge unterschiedlich sind.
