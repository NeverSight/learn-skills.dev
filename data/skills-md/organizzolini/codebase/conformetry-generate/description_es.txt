Genera código con un generador conformetry en lugar de escribirlo a mano. Úsalo cuando añadas un módulo, componente, servicio, aplicación o paquete a un espacio de trabajo que tenga una configuración conformetry; cuando decidas si existe un generador para la forma que estás a punto de crear; cuando una ejecución de un generador sobrescriba o desplace archivos; o cuando una ejecución de conformidad informe sobre un archivo que un generador debería haber producido. Cubre tanto el plugin Nx como el host de línea de comandos conformetry, cuyos contratos de entrada difieren.
