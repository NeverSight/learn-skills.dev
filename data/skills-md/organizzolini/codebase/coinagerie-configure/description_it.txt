Usa quando scrivi o modifichi un coinagerie.config.ts, scegliendo quali file vengono scansionati, escludendo percorsi o parole, leggendo un altro glossario in exclude.words, unendo una famiglia di parole con fold, dichiarando le destinazioni del glossario in markdown o JSON, condividendo una configurazione di base tra cartelle, o quando una configurazione viene rifiutata, una lista di parole chiave non verrà importata, o una parola è elencata erroneamente nel glossario.
