Actúa ante una violación del límite del codómetro, una violación del presupuesto de comentarios, un informe comprometido obsoleto o una ejecución que falló directamente. Utilízalo cuando `codometer --check` devuelve un código de salida distinto de cero, cuando se supera un límite de tamaño o cantidad, cuando un bloque de comentarios excede su presupuesto de palabras, líneas o caracteres, cuando un informe comprometido resulta obsoleto frente a una medición nueva aunque nada haya cambiado, cuando un límite no se puede aplicar o una entrada no coincide con ningún archivo, o antes de intentar alcanzar el valor límite del repositorio para que una verificación fallida pase.
