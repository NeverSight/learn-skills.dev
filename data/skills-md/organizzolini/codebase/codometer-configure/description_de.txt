Erstellen oder bearbeiten Sie eine codometer.config.ts, in der Sie Eingaben, Grenzwerte, benutzerdefinierte Konventionszähler, Kommentarbudgets, Ausschlüsse oder Ausgabeziele deklarieren. Verwenden Sie sie, wenn ein Repository noch keine Codometer‑Konfiguration hat, wenn Sie ein Größen‑ oder Zähl‑Limit hinzufügen, wenn Sie begrenzen wollen, wie lang ein Kommentarblock oder ein JSDoc‑Kommentar sein darf, wenn Sie eine Eingabe für kompilierten oder generierten Output deklarieren, wenn Sie eine Namenskonvention zählen, die von keinem eingebauten Analyzer erkannt wird, wenn ein Limit nicht gebunden werden kann oder eine Eingabe keine Dateien trifft, oder wenn entschieden werden soll, ob eine Konfiguration jedes Projekt in einem Workspace beschreiben kann.
