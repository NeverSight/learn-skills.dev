Scrivi o modifica un file codometer.config.ts, dichiarando input, limiti, contatori per convenzioni personalizzate, budget per i commenti, esclusioni o destinazioni di output. Usalo quando un repository non ha ancora una configurazione codometer, quando aggiungi un limite di dimensione o di conteggio, quando limiti la lunghezza di un blocco di commento o di un commento JSDoc, quando dichiari un input per output compilati o generati, quando conti una convenzione di denominazione che nessun analizzatore integrato conosce, quando un limite non riesce a legarsi o un input non corrisponde a nessun file, o quando decidi se una configurazione può descrivere tutti i progetti in un workspace.
