Führen Sie eine Codometer‑Messung durch, entscheiden Sie, wohin ihr Bericht geht, oder lesen Sie einen Badge‑Block oder den von ihr erzeugten JSON‑Bericht. Verwenden Sie dies beim Ausführen von Codometer oder npx @codometer/cli, wenn Sie die Flags --output-json/--output-markdown und --check wählen, Codometer in einen CI‑Schritt einbinden, einen Badge‑Block in ein README einfügen oder die Metriken, Limits oder Fehler eines Codometer‑JSON‑Berichts auslesen. Deckt den Befehlszeilen‑Host direkt ab, ohne einen Task‑Runner anzunehmen.
