Führen Sie eine Codometermessung durch, entscheiden Sie, wohin der Bericht geht, oder lesen Sie einen von ihm erstellten Ausweisblock oder JSON-Bericht. Verwenden Sie diese Option, wenn Sie Codometer oder npx @ codometer/cli ausführen, --output-json/--output-markdown auswählen und --check flags, Codometer in einen CI-Schritt verdrahten, einen Ausweisblock in ein README spleißen oder die Metriken, Grenzen oder Fehler eines JSON-Berichts eines Codometers lesen. Deckt den Befehlszeilenhost direkt ab, ohne einen Task-Runner zu übernehmen.
