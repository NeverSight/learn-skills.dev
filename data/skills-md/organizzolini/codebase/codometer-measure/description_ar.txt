قم بتشغيل قياس codometer، قرّر إلى أين يذهب تقريره، أو اقرأ كتلة الشارة أو تقرير JSON الذي تم إنتاجه. يُستَخدم عند تشغيل codometer أو npx @codometer/cli، مع اختيار علامات ‎--output-json/--output-markdown‎ و ‎--check‎، ربط codometer بخطوة CI، إدراج كتلة الشارة في ملف README، أو قراءة مقاييس تقرير JSON الخاص بـ codometer أو حدوده أو فشله. يغطي مضيف سطر الأوامر مباشرةً، دون افتراض أي مدير مهام.
