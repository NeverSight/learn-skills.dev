Esegui una misurazione con codometer, decidi dove inviare il suo report o leggi un blocco badge o il report JSON prodotto. Usalo quando esegui codometer o npx @codometer/cli, scegliendo le opzioni --output-json/--output-markdown e il flag --check, integrando codometer in un passaggio CI, inserendo un blocco badge in un README o leggendo le metriche, i limiti o gli errori del report JSON di codometer. Copre direttamente l'host da riga di comando, senza presumere alcun task runner.
