Esegui una misurazione con codometer, decidi dove inviare il suo report o leggi un blocco badge o il report JSON che ha prodotto. Usalo quando esegui codometer o npx @codometer/cli, scegliendo le opzioni --output-json/--output-markdown e i flag --check, integrando codometer in uno step CI, inserendo un blocco badge in un README o leggendo le metriche, i limiti o i fallimenti di un report JSON di codometer. Copre l'host da riga di comando direttamente, senza presumere alcun task runner.
