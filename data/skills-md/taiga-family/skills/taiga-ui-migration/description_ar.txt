استخدم هذه المهارة عند نقل مشروع Taiga UI إلى نسخة رئيسية جديدة. قبل البدء، تأكد من المستخدم أي النسخ الرئيسية المتورطة (مثلاً v4 → v5). استبدل نسخة المصدر بـ CURRENT_MAJOR ونسخة الهدف بـ NEXT_MAJOR طوال سير العمل هذا. استدعِها أيضاً عند تشغيل مخططات الترحيل، ومعالجة مهام TODO المتبقية بعد `ng update` أو `nx migrate`، أو عندما يُطلب منك إصلاح مهام TODO، أو تنظيف ملاحظات الترحيل، أو حل تحذيرات الإهمال، أو العمل مع حزمة @taiga-ui/legacy. اتبع سير عمل الترحيل الكامل: جمع السياق، إعداد البيئة، تشغيل المخططات، مراجعة التغييرات، معالجة مهام TODO، وحل المشكلات الشائعة. حل كل مهمة TODO قابلة للتنفيذ فقط عندما يثبت الكود المحيط أن الإصلاح آمن؛ وإلا قم بفحص سياق إضافي أو استفسر من المستخدم قبل تغيير السلوك أو القوالب أو الأنماط أو السكريبتات.

يرجى دائمًا الرد بلغة المستخدم.
