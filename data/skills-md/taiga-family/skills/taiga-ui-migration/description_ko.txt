Taiga UI 프로젝트를 새로운 메이저 버전으로 마이그레이션할 때 이 스킬을 사용하세요. 시작하기 전에 어떤 메이저 버전이 연관되는지 사용자에게 확인하십시오(예: v4 → v5). 워크플로 전체에서 원본 버전을 CURRENT_MAJOR, 대상 버전을 NEXT_MAJOR로 대체합니다. `ng update` 또는 `nx migrate` 후 남은 마이그레이션 TODO를 처리하거나, TODO를 고쳐 달라고 요청받았을 때, 마이그레이션 노트를 정리할 때, 폐기 경고를 해결할 때, 혹은 @taiga-ui/legacy 패키지를 사용할 때도 이 스킬을 호출하세요. 전체 마이그레이션 워크플로를 따르세요: 컨텍스트 수집, 환경 준비, 스키매틱 실행, 변경 사항 검토, TODO 처리, 일반적인 문제 해결. 주변 코드가 수정이 안전함을 입증할 경우에만 실행 가능한 모든 TODO를 해결하고, 그렇지 않으면 더 많은 컨텍스트를 검사하거나 동작, 템플릿, 스타일, 스크립트를 변경하기 전에 사용자에게 물어보세요.

항상 사용자의 언어로 응답하십시오.
