Utiliza esta habilidad cuando migres un proyecto Taiga UI a una nueva versión mayor. Antes de comenzar, confirma con el usuario qué versiones mayores están involucradas (p. ej., v4 → v5). Sustituye la versión de origen como CURRENT_MAJOR y la versión de destino como NEXT_MAJOR a lo largo de este flujo de trabajo. También invócala al ejecutar esquemas de migración, manejar los TODO de migración que quedan después de `ng update` o `nx migrate`, cuando se solicite corregir TODOs, limpiar notas de migración, resolver advertencias de deprecación o trabajar con el paquete @taiga-ui/legacy. Sigue el flujo de migración completo: recopila contexto, prepara el entorno, ejecuta los esquemas, revisa los cambios, maneja los TODOs y soluciona problemas comunes. Resuelve cada TODO accionable solo cuando el código circundante demuestre que la corrección es segura; de lo contrario inspecciona más contexto o pregunta al usuario antes de cambiar el comportamiento, plantillas, estilos o scripts.

Por favor, responde siempre en el idioma del usuario.
