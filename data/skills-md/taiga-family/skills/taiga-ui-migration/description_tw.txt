使用此技能於將 Taiga UI 專案遷移至新主要版本時。開始前，先確認使用者涉及的主要版本（例如 v4 → v5）。在整個工作流程中，將來源版本替換為 CURRENT_MAJOR，目標版本替換為 NEXT_MAJOR。亦在執行遷移腳本、處理 `ng update` 或 `nx migrate` 後留下的遷移 TODO、被要求修復 TODO、清理遷移說明、解決棄用警告，或使用 @taiga-ui/legacy 套件時呼叫此技能。遵循完整的遷移工作流程：蒐集情境、準備環境、執行腳本、檢視變更、處理 TODO，並排除常見問題。僅在周邊程式碼證實修正安全時才解決每一個可執行的 TODO；若未確定，請檢查更多上下文或在變更行為、模板、樣式或腳本前詢問使用者。

請始終以使用者的語言回覆。
