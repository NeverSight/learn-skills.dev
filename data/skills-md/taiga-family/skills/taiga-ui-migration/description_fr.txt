Utilisez cette compétence lors de la migration d’un projet Taiga UI vers une nouvelle version majeure. Avant de commencer, confirmez avec l’utilisateur quelles versions majeures sont concernées (par ex. v4 → v5). Remplacez la version source par CURRENT_MAJOR et la version cible par NEXT_MAJOR tout au long de ce flux de travail. Activez également cette compétence lors de l’exécution des schématiques de migration, de la gestion des TODO de migration laissés après `ng update` ou `nx migrate`, lorsqu’on vous demande de corriger des TODO, de nettoyer les notes de migration, de résoudre les avertissements de dépréciation, ou de travailler avec le package @taiga‑ui/legacy. Suivez le flux de travail complet de migration : recueillir le contexte, préparer l’environnement, exécuter les schématiques, examiner les changements, gérer les TODO et résoudre les problèmes courants. Résolvez chaque TODO actionnable uniquement lorsque le code environnant prouve que la correction est sûre ; sinon, examinez davantage le contexte ou demandez à l’utilisateur avant de modifier le comportement, les modèles, les styles ou les scripts.

Veuillez toujours répondre dans la langue de l’utilisateur.
