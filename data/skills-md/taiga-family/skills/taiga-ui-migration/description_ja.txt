このスキルは、Taiga UI プロジェクトを新しいメジャーバージョンへ移行する際に使用してください。開始する前に、どのメジャーバージョンが関わっているかユーザーに確認してください（例: v4 → v5）。このワークフロー全体で、元のバージョンを CURRENT_MAJOR、対象バージョンを NEXT_MAJOR に置き換えて使用します。`ng update` や `nx migrate` 後に残るマイグレーション TODO、マイグレーションスキーマティクスの実行時、TODO の修正依頼、マイグレーションノートの整理、非推奨警告の解消、または @taiga-ui/legacy パッケージを扱う場合にもこのスキルを呼び出してください。完全なマイグレーションワークフローに従います：コンテキストの収集、環境の準備、スキーマティクスの実行、変更のレビュー、TODO の処理、一般的な問題のトラブルシューティング。周囲のコードが修正の安全性を示す場合にのみ、実行可能な TODO を解決してください。安全性が確認できない場合は、さらにコンテキストを確認するか、ユーザーに問い合わせてから、振る舞い、テンプレート、スタイル、スクリプトの変更を行ってください。

常にユーザーの言語で回答してください。
