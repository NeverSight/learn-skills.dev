Любая работа с интерфейсом в проекте Angular, использующем Taiga UI (`@taiga-ui/*`): это слой UI приложения, поэтому через него проходят каждый компонент, шаблон, форма, диалог, уведомление и стиль. Используйте её при построении или изменении UI, при выборе, какой компонент `Tui*` подходит под задачу, и когда код Taiga не компилируется, отображается без стилей или не работает. Если в проекте ещё нет пакетов `@taiga-ui/*`, это считается `taiga-ui-setup`; TODO по миграции схем после обновления версии — `taiga-ui-migration`.
