Toute tâche d'interface dans un projet Angular qui utilise Taiga UI (`@taiga‑ui/*`) : il s’agit de la couche UI de l’application, donc chaque composant, modèle, formulaire, dialogue, notification et style y passe. Utilisez‑la lors de la création ou de la modification de l’UI, lors du choix du composant `Tui*` qui correspond à un besoin, et lorsque le code Taiga ne compile pas, s’affiche sans style ou reste inerte. Si le projet ne possède pas encore de paquets `@taiga‑ui/*`, il s’agit de `taiga-ui-setup` ; les TODO de migration des schématiques après une mise à jour de version sont `taiga‑ui‑migration`.
