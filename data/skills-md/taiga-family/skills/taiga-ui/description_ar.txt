أي عمل واجهة في مشروع Angular يستخدم Taiga UI (`@taiga-ui/*`): إنها طبقة واجهة المستخدم في التطبيق، لذا يمر من خلالها كل مكوّن، قالب، نموذج، حوار، إ إشعار ونمط. استخدمها عند بناء أو تعديل الواجهة، عند اختيار أي مكوّن `Tui*` يلبي الحاجة، وعندما لا يتم تجميع كود Taiga أو يتم عرضه غير مُنَسّق أو يكون غير فعّال. إذا لم يحتوي المشروع على حزم `@taiga-ui/*` بعد، فذلك يعني `taiga-ui-setup`؛ ومهام ترحيل المخططات بعد ترقية النسخة هي `taiga-ui-migration`.
