Any interface work in an Angular project that uses Taiga UI (`@taiga-ui/*`): it is the app's UI layer, so every component, template, form, dialog, notification and style goes through it. Use when building or changing UI, when picking which `Tui*` component fits a need, and when Taiga code won't compile, renders unstyled or renders inert. If the project has no `@taiga-ui/*` packages yet, that is `taiga-ui-setup`; schematics migration TODOs after a version bump are `taiga-ui-migration`.
