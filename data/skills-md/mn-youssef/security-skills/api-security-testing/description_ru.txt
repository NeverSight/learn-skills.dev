Используйте при тестировании REST, GraphQL, gRPC или WebSocket API в соответствии с OWASP API Security Top 10 — авторизация на уровне объектов и функций (BOLA/BFLA), избыточное раскрытие данных, массовое присвоение, неограниченное потребление ресурсов и специфические злоупотребления GraphQL. Для приложений, которыми вы владеете или на которые имеете разрешение тестировать.
