Qualität des Backend-Codes für sauberen, produktionsbereiten und wartbaren Code. Passt sich an die vorhandene Sprache, das Framework und den Stil an. Behandelt Funktionen, Wiederverwendbarkeit, moderne Syntax, Fehlervermeidung, Lesbarkeit und Sicherheitsbewusstsein. Wird zum Schreiben, Überprüfen oder Refactoring von Backend-Code im Hinblick auf Qualität, Wartbarkeit oder Produktionsbereitschaft verwendet.
