بعد تعديل ملفات Python / Shell ، حدد ونفّذ التحقق اللاحق من المستوى L1–L4 (ruff / ty / pyrefly / pyright / mypy / bash -n) ، وبلغ بدقة عن الثغرات غير المُتحقَّق منها بسبب نقص الأدوات. استخدم ذلك بعد تعديل ملفات .py أو .sh ، قبل الادعاء بأن التغيير اكتمل أو الإبلاغ عن النجاح؛ وكذلك عندما يطلب المستخدم تشغيل فحوصات ما بعد التعديل، أو التدقيق النحوي، أو فحص الأنواع، أو التحقق من أن التغيير يمر بـ L1–L4.

يرجى الرد دائمًا بلغة المستخدم.
