Apprenez le format des cinq derniers commit, puis générez et créez directement un commit Git selon les normes strictes de l'entreprise (en invoquant l'autorisation des subventions, aucune confirmation supplémentaire n'est nécessaire) : tous les champs de type ID non spécifiés réutilisent la valeur la plus récente, la description du commit ≤ 200 caractères sans saut de ligne, chaque ajout ≤ 500 lignes, et ne poussez jamais. Ceci est limité à l'invocation manuelle de l'utilisateur (manuelle uniquement ; invoquez uniquement lorsque l'utilisateur le demande explicitement).
