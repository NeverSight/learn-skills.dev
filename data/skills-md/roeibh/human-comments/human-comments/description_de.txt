Schreibe Codekommentare so, wie ein Senior Engineer es tun würde – fast keine, und die wenigen, die übrig bleiben, sind kurze menschliche Fragmente, keine Sätze. Der Code dokumentiert sich selbst; ein Kommentar ist ein letzter Ausweg für das, was der Code wirklich nicht ausdrücken kann. Verwende das JEDERZEIT beim Schreiben oder Bearbeiten von Code in jeder Sprache, besonders wenn sich der Nutzer beschwert, dass Kommentare zu ausführlich, zu lang, zu laut, „KI‑klingend“, essayartig sind oder dass sie Zeilen zu einem Diff oder PR hinzufügen. Ausgelöst werden die Stichwörter „weniger Kommentare“, „kürzere Kommentare“, „aufhören zu überkommentieren“, „dies liest sich, als hätte KI sie geschrieben“, „Kommentare prägnant machen“, „der Code sollte sich selbst dokumentieren“ oder jedes Mal, wenn du kurz davor bist, einen Kommentar zum Code hinzuzufügen.

Bitte antworte immer in der Sprache des Nutzers.
