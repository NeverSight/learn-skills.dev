Artisanat au niveau du code pour les UI créées par agent : HTML sémantique, CSS piloté par des tokens (sans valeurs codées en dur), discipline de la spécificité, hygiène des composants, zéro style en ligne, aucun code mort. La moitié ingénierie de « conçu, pas généré » — une page magnifique est trahie par un balisage bâclé. À utiliser lors de la génération ou de l’audit de tout code frontend. S’appuyer sur la compétence centrale du goût du design.
