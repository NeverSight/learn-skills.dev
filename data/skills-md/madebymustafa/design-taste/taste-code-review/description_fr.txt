Examen structuré du code généré par un agent : un ordre de passage fixe (comportement → structure → goût → sécurité → performance → accessibilité), constatations classées par gravité, discipline du diff, et une liste de contrôle d’examen qui empêche « ça fonctionne » d’être le critère. À utiliser lors de l’audit de tout code généré ou modifié. S’appuyer sur la compétence centrale de design‑goût.
