Strukturierte Überprüfung von agentenerzeugtem Code: eine feste Durchgangsreihenfolge (Verhalten → Struktur → Geschmack → Sicherheit → Leistung → Barrierefreiheit), nach Schweregrad sortierte Befunde, Diff‑Disziplin und eine Prüfliste, die verhindert, dass „es funktioniert“ die Messlatte ist. Verwenden Sie diese bei der Prüfung jeglichen erzeugten oder geänderten Codes. Auf der Kernkompetenz Design‑Geschmack aufbauen.
