Mejores prácticas integrales, patrones de diseño y errores comunes para el desarrollo de ROS2 (Robot Operating System 2). Usa esta habilidad al crear nodos, paquetes, archivos de lanzamiento, componentes o al depurar sistemas ROS2. Activa cuando el usuario mencione ROS2, colcon, rclpy, rclcpp, DDS, QoS, nodos de ciclo de vida, nodos gestionados, lanzamiento ROS2, parámetros ROS2, acciones ROS2, nav2, MoveIt2, micro‑ROS o cualquier middleware de robótica de la era ROS2. También se activa para la configuración del espacio de trabajo ROS2, afinación de DDS, comunicación intra‑proceso, seguridad ROS2 o despliegue de ROS2 en producción. Además se activa para problemas de compilación con colcon, ament_cmake, ament_python, CMakeLists.txt para ROS2, dependencias en package.xml, rosdep, superposiciones de espacios de trabajo, generación de mensajes personalizados o solución de problemas de compilación ROS2. Cubre las distribuciones Humble, Iron, Jazzy y Rolling.
