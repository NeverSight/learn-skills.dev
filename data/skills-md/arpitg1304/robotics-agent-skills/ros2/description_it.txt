Pratiche consigliate complete, pattern di progettazione e comuni insidie per lo sviluppo di ROS2 (Robot Operating System 2). Usa questa competenza quando costruisci nodi ROS2, pacchetti, file di lancio, componenti o effettui il debug dei sistemi ROS2. Attiva quando l'utente menziona ROS2, colcon, rclpy, rclcpp, DDS, QoS, nodi del ciclo di vita, nodi gestiti, lancio ROS2, parametri ROS2, azioni ROS2, nav2, MoveIt2, micro-ROS o qualsiasi middleware robotico dell'era ROS2. Attiva anche per la configurazione dell'ambiente di lavoro ROS2, la sintonizzazione di DDS, la comunicazione intra-processo, la sicurezza ROS2 o il deployment di ROS2 in produzione. Attiva inoltre per problemi di build con colcon, ament_cmake, ament_python, CMakeLists.txt per ROS2, dipendenze package.xml, rosdep, overlay del workspace, generazione di messaggi personalizzati o la risoluzione dei problemi di build di ROS2. Copre le distribuzioni Humble, Iron, Jazzy e Rolling. 

Rispondi sempre nella lingua dell'utente.
