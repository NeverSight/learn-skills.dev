Créez et déployez des applications serverless modulaires en utilisant le générateur EasySAM de YAML vers SAM. Utilisez toujours cette compétence chaque fois que l'utilisateur demande de créer la structure d'un projet serverless, de configurer des ressources AWS (Lambda, DynamoDB, S3, SQS, SNS, poller EventBridge, OpenSearch Serverless, Kinesis, URL de fonction), de définir resources.yaml ou easysam.yaml, d’inspecter le schéma ou les paramètres cloud, de générer des modèles SAM ou de mettre en place des pipelines CI/CD GitHub Actions pour des applications serverless, même s’ils ne mentionnent pas explicitement « EasySAM ».

Veuillez toujours répondre dans la langue de l'utilisateur.
