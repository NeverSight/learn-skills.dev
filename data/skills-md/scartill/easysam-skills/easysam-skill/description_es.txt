Construye y despliega aplicaciones serverless modulares utilizando el generador EasySAM de YAML a SAM. Utiliza siempre esta habilidad siempre que el usuario solicite estructurar un proyecto serverless, configurar recursos de AWS (Lambda, DynamoDB, S3, SQS, SNS, poller de EventBridge, OpenSearch Serverless, Kinesis, URLs de funciones), definir resources.yaml o easysam.yaml, inspeccionar el esquema o la configuración de la nube, generar plantillas SAM o configurar pipelines CI/CD de GitHub Actions para aplicaciones serverless, incluso si no mencionan explícitamente “EasySAM”.

Por favor, responde siempre en el idioma del usuario.
