EasySAM YAML-to-SAM ジェネレーターを使用して、モジュラーサーバーレスアプリケーションを構築・デプロイします。ユーザーがサーバーレスプロジェクトのスキャフォールディング、AWS リソース（Lambda、DynamoDB、S3、SQS、SNS、EventBridge ポーラー、OpenSearch Serverless、Kinesis、Function URLs）の設定、resources.yaml または easysam.yaml の定義、スキーマやクラウド設定の検査、SAM テンプレートの生成、またはサーバーレスアプリケーション向けの GitHub Actions CI/CD パイプラインのセットアップを要求した場合は、たとえ「EasySAM」という言葉が明示されていなくても、常にこのスキルを使用してください。

常にユーザーの言語で応答してください。
