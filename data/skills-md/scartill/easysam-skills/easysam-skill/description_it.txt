Costruisci e distribuisci applicazioni serverless modulari usando il generatore EasySAM da YAML a SAM. Usa sempre questa competenza ogni volta che l'utente chiede di creare lo scaffolding di un progetto serverless, configurare risorse AWS (Lambda, DynamoDB, S3, SQS, SNS, EventBridge poller, OpenSearch Serverless, Kinesis, Function URLs), definire resources.yaml o easysam.yaml, ispezionare lo schema o le impostazioni cloud, generare template SAM o impostare pipeline CI/CD di GitHub Actions per applicazioni serverless, anche se non menzionano esplicitamente “EasySAM”.

Rispondi sempre nella lingua dell'utente.
