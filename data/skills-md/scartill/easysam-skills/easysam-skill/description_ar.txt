قم ببناء ونشر تطبيقات خالية من الخادم بشكلٍ معياري باستخدام مولّد EasySAM من YAML إلى SAM. استخدم هذه القدرة دائمًا كلما طلب المستخدم إنشاء هيكل لمشروع خالي من الخادم، أو تكوين موارد AWS (Lambda، DynamoDB، S3، SQS، SNS، EventBridge poller، OpenSearch Serverless، Kinesis، Function URLs)، أو تعريف resources.yaml أو easysam.yaml، أو فحص المخطط أو إعدادات السحابة، أو توليد قوالب SAM، أو إعداد خطوط أنابيب CI/CD باستخدام GitHub Actions لتطبيقات الخالية من الخادم، حتى وإن لم يذكروا صراحةً "EasySAM". يرجى دائمًا الرد بلغة المستخدم.
