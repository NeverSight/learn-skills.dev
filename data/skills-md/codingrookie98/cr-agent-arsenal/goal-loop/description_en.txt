Use when executing long-horizon engineering goals that span multiple files or modules, are expected to exceed ~10 minutes, or need durable cross-session state and a strict delivery gate. Triggers on multi-module refactors, cross-cutting feature work, long bug hunts, any task where tiered testing (L0–L3), checkpoint persistence, and an adversarial Zero-Blockers review are required, and legacy-system maintenance fixes whose triage needs the lightweight Maintenance-Patch track.
