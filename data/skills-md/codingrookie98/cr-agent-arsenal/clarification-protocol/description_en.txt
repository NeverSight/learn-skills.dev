Use when clarifying requirements with a user before planning or coding — sequencing which questions to ask (dependency strength × implementation impact), aligning terminology before eliciting scope, keeping a decision ledger (decided items / excluded boundaries / default assumptions), running the three-item convergence self-check (goals / boundaries / contradictions), and escalating when the question budget is exhausted. Triggers on ambiguous or macro-level goals, multi-round Q&A, decisions being re-opened under a new phrasing, and the choice between asking the user versus registering an explicit default assumption.
