استخدم عند توضيح المتطلبات مع المستخدم قبل التخطيط أو البرمجة — ترتيب الأسئلة التي يجب طرحها (قوة الاعتماد × تأثير التنفيذ)، مواءمة المصطلحات قبل استخراج نطاق العمل، الحفاظ على سجل القرارات (العناصر المقررة / الحدود المستبعدة / الافتراضات الافتراضية)، إجراء فحص التلاقي ذي الثلاثة عناصر (الأهداف / الحدود / التناقضات)، وتصعيد الأمر عندما ينفد ميزانية الأسئلة. يتم التفعيل عند وجود أهداف غامضة أو على مستوى كلي، أو أسئلة متعددة الجولات، أو إعادة فتح القرارات بصياغة جديدة، وكذلك عند الاختيار بين سؤال المستخدم أو تسجيل افتراض افتراضي صريح.
