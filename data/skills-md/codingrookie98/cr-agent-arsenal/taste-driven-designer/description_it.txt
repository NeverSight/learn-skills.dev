Usa quando l'utente desidera progettare o ridisegnare qualsiasi artefatto UI/UX — landing page, web app, interfacce mobile, UI di giochi o dashboard — e si aspetta risultati distintivi e di gusto invece di output generico dell'IA. Usalo anche quando si richiede di dare una personalità o una direzione artistica a un design, farlo apparire premium/unico/non generato dall'IA, criticare un'interfaccia esistente o fornire una direzione per lo sviluppo frontend. Si attiva su landing page, sezione hero, linguaggio di design, moodboard, direzione artistica, rifinitura UI, gusto.
