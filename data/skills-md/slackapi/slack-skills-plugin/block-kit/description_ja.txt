開発者が Slack メッセージ、モーダル、またはホーム タブのブロック キット レイアウト (メッセージ レイアウト、モーダル/フォーム/ダイアログ、ホーム タブ インターフェイス、インタラクティブ ボタンまたはメニュー) を構築または検証する場合、または既存のブロック キット JSON を変更する場合に使用します。また、任意の Slack UI コンポーネント (セクション、アクション、入力、ヘッダー、アラート、テーブル、カルーセル)、「ブロック」または「ブロック キット ビルダー」という単語、レンダリングされたブロックをプレビューするリクエスト、または「type」:「section」のような貼り付けられた JSON でもトリガーします。 blocks.validate API メソッドを介して検証します。
