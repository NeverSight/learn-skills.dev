Úselo cuando un desarrollador quiera crear o validar diseños de Block Kit para mensajes, modales o pestañas de Inicio de Slack: diseños de mensajes, modales/formularios/diálogos, interfaces de pestañas de Inicio, botones o menús interactivos, o modificar el JSON del Block Kit existente. También active cualquier componente de la interfaz de usuario de Slack (secciones, acciones, entradas, encabezados, alertas, tablas, carruseles), las palabras "bloques" o "Block Kit Builder", una solicitud para obtener una vista previa de los bloques renderizados o JSON pegado como "tipo": "sección". Valida a través del método API blocks.validate.
