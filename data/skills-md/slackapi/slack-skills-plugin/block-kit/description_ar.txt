يُستخدم عندما يريد المطور إنشاء تخطيطات Block Kit أو التحقق من صحتها لرسائل Slack أو الوسائط أو علامات التبويب الرئيسية: تخطيطات الرسائل أو الوسائط/النماذج/مربعات الحوار أو واجهات علامة التبويب الرئيسية أو الأزرار أو القوائم التفاعلية أو تعديل Block Kit JSON الموجود. قم أيضًا بتشغيل أي مكون من مكونات Slack UI (الأقسام، الإجراءات، المدخلات، الرؤوس، التنبيهات، الجداول، الرف الدائري)، الكلمات "كتل" أو "Block Kit Builder"، أو طلب لمعاينة الكتل المقدمة، أو لصق JSON مثل "type": "section". يتم التحقق من الصحة عبر طريقة block.validate API.
