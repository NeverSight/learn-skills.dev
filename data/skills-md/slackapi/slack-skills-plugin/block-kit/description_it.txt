Da utilizzare quando uno sviluppatore desidera creare o convalidare layout di Block Kit per messaggi Slack, modali o schede Home: layout di messaggi, modali/moduli/dialoghi di dialogo, interfacce della scheda Home, pulsanti o menu interattivi o modifica del JSON del Block Kit esistente. Attiva anche su qualsiasi componente dell'interfaccia utente Slack (sezioni, azioni, input, intestazioni, avvisi, tabelle, caroselli), le parole "blocchi" o "Block Kit Builder", una richiesta di visualizzare in anteprima i blocchi renderizzati o JSON incollato come "tipo": "sezione". Convalida tramite il metodo APIblocks.validate.
