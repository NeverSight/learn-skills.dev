À utiliser lorsqu'un développeur souhaite créer ou valider des mises en page Block Kit pour les messages Slack, les modaux ou les onglets Accueil : mises en page des messages, modaux/formulaires/boîtes de dialogue, interfaces de l'onglet Accueil, boutons ou menus interactifs, ou modification du JSON Block Kit existant. Déclenchez également sur n'importe quel composant de l'interface utilisateur Slack (sections, actions, entrées, en-têtes, alertes, tableaux, carrousels), les mots « blocs » ou « Block Kit Builder », une demande de prévisualisation des blocs rendus, ou du JSON collé comme « type » : « section ». Valide via la méthode API Blocks.validate.
