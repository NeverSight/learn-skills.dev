Verwenden Sie diese Option, wenn ein Entwickler Block Kit-Layouts für Slack-Nachrichten, Modalitäten oder Home-Tabs erstellen oder validieren möchte: Nachrichtenlayouts, Modalitäten/Formulare/Dialoge, Home-Tab-Schnittstellen, interaktive Schaltflächen oder Menüs oder die Änderung vorhandener Block Kit-JSON. Lösen Sie außerdem auf jeder Slack-UI-Komponente (Abschnitte, Aktionen, Eingaben, Kopfzeilen, Warnungen, Tabellen, Karussells) die Wörter „Blöcke“ oder „Block Kit Builder“ aus, eine Anfrage zur Vorschau gerenderter Blöcke oder eingefügtes JSON wie „Typ“: „Abschnitt“. Validiert über die API-Methode Blocks.validate.
