Úselo cuando un desarrollador quiera crear, desarrollar o iniciar una nueva aplicación o agente de Slack desde cero con la CLI de Slack. Cubre los requisitos previos, la configuración de la zona de pruebas, la autenticación y la creación y ejecución de un proyecto desde una plantilla de Bolt (JS o Python) localmente. Activar "crear una aplicación de Slack", "nueva aplicación de Bolt", "iniciar un agente de Slack".
