À utiliser lorsqu'un développeur souhaite créer, échafauder ou démarrer une nouvelle application ou un nouvel agent Slack à partir de zéro avec la CLI Slack. Couvre les prérequis, la configuration du bac à sable, l'authentification et la création et l'exécution d'un projet à partir d'un modèle Bolt (JS ou Python) localement. Déclenchez sur « créer une application Slack », « nouvelle application Bolt », « démarrer un agent Slack ».
