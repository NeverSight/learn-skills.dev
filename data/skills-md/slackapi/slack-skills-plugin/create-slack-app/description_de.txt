Verwenden Sie diese Option, wenn ein Entwickler eine neue Slack-App oder einen neuen Slack-Agenten mit der Slack-CLI von Grund auf erstellen, ein Gerüst erstellen oder booten möchte. Behandelt Voraussetzungen, Sandbox-Einrichtung, Authentifizierung und das lokale Erstellen und Ausführen eines Projekts aus einer Bolt-Vorlage (JS oder Python). Auslösen bei „Slack-App erstellen“, „Neue Bolt-App“, „Slack-Agent starten“.
