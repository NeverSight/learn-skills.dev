Da utilizzare quando uno sviluppatore lavora con la CLI Slack (comando slack) per creare, eseguire o gestire un'app Slack dal terminale: accedendo o autenticandosi (accesso Slack), aggiungendo un team o cambiando area di lavoro, eseguendo localmente (esecuzione Slack), distribuendo, modificando il manifesto dell'app, chiamando metodi API Web (API Slack) o cercando documenti Slack (ricerca documenti Slack).
