يُستخدم عندما يعمل مطور مع Slack CLI (أمر Slack) لإنشاء تطبيق Slack أو تشغيله أو إدارته من الوحدة الطرفية: تسجيل الدخول أو المصادقة (تسجيل الدخول Slack)، أو إضافة فريق أو تبديل مساحات العمل، أو التشغيل محليًا (تشغيل Slack)، أو النشر، أو تحرير بيان التطبيق، أو استدعاء أساليب Web API (slack api)، أو البحث في مستندات Slack (بحث مستندات Slack).
