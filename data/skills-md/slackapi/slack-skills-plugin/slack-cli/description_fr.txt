À utiliser lorsqu'un développeur travaille avec la CLI Slack (commande Slack) pour créer, exécuter ou gérer une application Slack à partir du terminal : connexion ou authentification (connexion Slack), ajout d'une équipe ou changement d'espace de travail, exécution locale (exécution Slack), déploiement, modification du manifeste de l'application, appel de méthodes d'API Web (API Slack) ou recherche de documents Slack (recherche de documents Slack).
