Úselo cuando un desarrollador trabaja con la CLI de Slack (comando de slack) para crear, ejecutar o administrar una aplicación de Slack desde la terminal: iniciar sesión o autenticarse (inicio de sesión de slack), agregar un equipo o cambiar espacios de trabajo, ejecutar localmente (ejecución de slack), implementar, editar el manifiesto de la aplicación, llamar a métodos de API web (api de slack) o buscar documentos de Slack (búsqueda de documentos de slack).
