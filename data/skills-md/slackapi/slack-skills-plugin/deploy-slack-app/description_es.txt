Úsese cuando un desarrollador desea desplegar, alojar o ejecutar una aplicación de Slack en algún lugar donde siga funcionando después de que el proceso local se detenga, o menciona Railway, Heroku, `railway up`, `git push heroku`, `slack deploy`, un hook `deploy` en `.slack/hooks.json`, alojar una aplicación Bolt en modo Socket o con URL de solicitud (HTTP), desplegar desde Windows, graduar una aplicación fuera de un sandbox de desarrollador, o desmantelar una aplicación desplegada.
