Verwenden, wenn ein Entwickler eine Slack‑App bereitstellen, hosten oder ausführen möchte, sodass sie weiter funktioniert, nachdem der lokale Prozess gestoppt wurde, oder Railway, Heroku, `railway up`, `git push heroku`, `slack deploy`, einen `deploy`‑Hook in `.slack/hooks.json`, das Hosting einer Socket‑Mode‑ oder Request‑URL‑(HTTP‑)Bolt‑App, das Deployen von Windows aus, das Graduieren einer App aus einer Entwickler‑Sandbox oder das Abschalten einer bereitgestellten App erwähnt.
