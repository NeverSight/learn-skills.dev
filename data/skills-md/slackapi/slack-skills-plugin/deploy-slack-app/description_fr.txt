À utiliser lorsqu'un développeur souhaite déployer, héberger ou exécuter une application Slack quelque part où elle continue de fonctionner après l'arrêt du processus local, ou lorsqu'il mentionne Railway, Heroku, `railway up`, `git push heroku`, `slack deploy`, un hook `deploy` dans `.slack/hooks.json`, l'hébergement d'une application Bolt en mode Socket ou via une URL de requête (HTTP), le déploiement depuis Windows, la promotion d'une application hors du bac à sable d'un développeur, ou le démontage d'une application déployée.
