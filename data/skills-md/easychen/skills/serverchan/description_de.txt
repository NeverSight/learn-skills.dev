Push-Nachrichtenbenachrichtigungen an WeChat/App über Server Chan (Fangtang). Verwenden Sie diese Fähigkeit, wenn Sie Ausführungsergebnisse, Warnungen, Aufgabenabschlussstatus usw. auf Ihr Telefon übertragen müssen (sowohl Server Chan Turbo SCT als auch Server Chan³ SC3 werden unterstützt und automatisch vom SendKey-Präfix erkannt). Unterstützt Titel, Markdown-Body und optionale Parameter wie Tags, Short und Channel.
