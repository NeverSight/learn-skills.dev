Отправляйте push‑уведомления в WeChat/App через Server Chan (Fangtang). Используйте этот навык, когда необходимо передать результаты выполнения, оповещения, статус завершения задач и аналогичную информацию на ваш телефон (поддерживается как Server Chan Turbo SCT, так и Server Chan³ SC3, автоматически распознаётся префиксом SendKey). Поддерживает заголовки, текст в формате Markdown и необязательные параметры, такие как теги, короткое сообщение и канал.
