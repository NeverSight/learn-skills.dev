分離された並行開発のために Git ワークツリーを作成、管理、比較、マージします：feature／hotfix ブランチ、スタッシュせずに PR のレビュー、並列差分、エージェントタスクの分離。ネイティブプラットフォームのワークツールを優先し、代替として `git worktree` を使用します。デフォルトディレクトリは衝突回避のため、業界標準の `.worktrees/<X>-<Y>/`（type‑slug）命名を使用します。重要／推奨／細部のレビュー項目チェックリストを含みます。

ユーザーがワークツリーの使用、ブランチの分離、スタッシュ回避、PR の並行レビュー、ブランチ間の実装比較、`.worktrees/` の設定、または git worktree add/list/remove/prune/repair の実行を求めたときにトリガーします。
