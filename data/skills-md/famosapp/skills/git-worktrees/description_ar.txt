إنشاء وإدارة ومقارنة ودمج شجرات عمل Git للعمل المتوازي المعزول: فروع المميزات/الإصلاح السريع، مراجعة طلبات السحب دون التخزين المؤقت (stashing)، اختلافات جنبًا إلى جنب، وعزل مهام الوكيل. يفضَّل أدوات شجرة العمل الأصلية للمنصة؛ ويعود إلى `git worktree` عند الحاجة. تستخدم الدلائل الافتراضية تسمية معيارية `.worktrees/<X>-<Y>/` (النوع‑الاختصار) لتجنب التعارضات. تتضمن قائمة مراجعة حرجة / موصى بها / تفصيلية.

يتم التحفيز عندما يطلب المستخدم استخدام شجرات العمل، عزل فرع، تجنب التخزين المؤقت، مراجعة طلب سحب بشكل متوازي، مقارنة تنفيذات عبر الفروع، إعداد `.worktrees/`، أو تشغيل أوامر git worktree add/list/remove/prune/repair.

الكلمات المفتاحية: git worktree، شجرة عمل مرتبطة، قفل الفرع، .worktrees، تسمية X‑Y، العزل، التطوير المتوازي، مراجعة طلب سحب، إصلاح سريع، مقارنة، دمج، cherry-pick، تقليم، EnterWorktree، orca worktree
