Crea, converti, leggi e modifica documenti Office in locale tramite la riga di comando di GenOffice. Costruisci una nuova presentazione (pptx) a partire da un brief attraverso uno schema controllato, specifica per pagina e pipeline di rendering, un nuovo foglio di calcolo (xlsx) da dati CSV o JSON con formule, un nuovo documento Word (docx) da Markdown o HTML, o un PDF; converti tra pdf, docx, xlsx, pptx, md, html e csv; leggi la struttura e il testo di un file esistente (inclusi i propri docx / xlsx / pptx dell'utente come materiale di partenza) e applica modifiche strutturate. Usalo ogni volta che l'utente richiede un deck di diapositive, una presentazione, un foglio di calcolo, un workbook, un rapporto, un documento Word o qualsiasi file reale di Office, una conversione di formato, una riscrittura di parte di un documento esistente, o desidera il risultato aperto nell'editor di GenOffice. I documenti vengono elaborati localmente; solo ricerca, immagine e media inviano la query o il file di riferimento al provider configurato in GenOffice. Rispondi sempre nella lingua dell'utente.
