Erstellen, konvertieren, lesen und bearbeiten Sie Office‑Dokumente lokal mit der Befehlszeile von GenOffice. Erstellen Sie eine neue Präsentation (pptx) aus einem Briefing über eine geprüfte Gliederung, eine Seiten‑Spezifikation und eine Rendering‑Pipeline, eine neue Tabelle (xlsx) aus CSV‑ oder JSON‑Daten mit Formeln, ein neues Word‑Dokument (docx) aus Markdown oder HTML oder ein PDF; konvertieren Sie zwischen pdf, docx, xlsx, pptx, md, html und csv; lesen Sie die Struktur und den Text einer bestehenden Datei (einschließlich der eigenen docx / xlsx / pptx‑Dateien des Nutzers als Ausgangsmaterial) und wenden Sie strukturierte Änderungen darauf an. Verwenden Sie dies immer, wenn der Nutzer nach einem Foliensatz, einer Präsentation, einer Tabelle, einem Arbeitsbuch, einem Bericht, einem Word‑Dokument oder einer beliebigen echten Office‑Datei, einer Formatkonvertierung, einer Überarbeitung eines Teils eines bestehenden Dokuments fragt oder das Ergebnis im GenOffice‑Editor öffnen möchte. Dokumente werden lokal verarbeitet; nur Suche, Bild und Medien senden die Anfrage oder die referenzierte Datei an den in GenOffice konfigurierten Anbieter.
