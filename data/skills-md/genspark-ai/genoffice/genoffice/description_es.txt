Crea, convierte, lee y edita documentos de Office localmente con la línea de comandos de GenOffice. Genera una nueva presentación (pptx) a partir de un brief mediante un esquema revisado, especificaciones por página y una cadena de renderizado; una nueva hoja de cálculo (xlsx) a partir de datos CSV o JSON con fórmulas; un nuevo documento de Word (docx) a partir de Markdown o HTML, o un PDF; convierte entre pdf, docx, xlsx, pptx, md, html y csv; lee la estructura y el texto de un archivo existente (incluyendo los docx/xlsx/pptx del propio usuario como material fuente) y aplica ediciones estructuradas. Utilízalo siempre que el usuario solicite una presentación de diapositivas, una presentación, una hoja de cálculo, un libro de trabajo, un informe, un documento de Word o cualquier archivo real de Office, una conversión de formato, una reescritura de parte de un documento existente, o quiera que el resultado se abra en el editor de GenOffice. Los documentos se procesan localmente; solo búsqueda, imágenes y medios envían la consulta o el archivo referenciado al proveedor configurado en GenOffice.
