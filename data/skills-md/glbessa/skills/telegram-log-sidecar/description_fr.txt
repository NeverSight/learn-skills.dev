Créez et configurez un conteneur sidecar de transfert de journaux vers Telegram pour les stacks Docker Compose. Il suit les journaux des services frères via le socket Docker et transmet les lignes filtrées à un chat Telegram via l’API Bot. Utilisez‑le lorsque l’utilisateur veut des alertes/notifications Telegram à partir des journaux de conteneurs, un sidecar d’expédition de logs, de l’observabilité via Telegram, ou qu’il demande « configurer les logs Telegram », « sidecar Telegram », « transférer les logs de conteneurs vers Telegram » ou « alertes de logs vers Telegram ».
