Создайте и настройте sidecar‑контейнер для пересылки логов в Telegram для стеков Docker Compose. Он читает (tail) логи соседних сервисов через Docker‑socket и пересылает отфильтрованные строки в чат Telegram через Bot API. Используйте, когда пользователь хочет получать оповещения/уведомления в Telegram из логов контейнеров, нужен sidecar для отправки логов, наблюдаемость через Telegram, или когда просят «настроить логи в Telegram», «Telegram sidecar», «переслать логи контейнера в Telegram», «оповещения о логах в Telegram».
