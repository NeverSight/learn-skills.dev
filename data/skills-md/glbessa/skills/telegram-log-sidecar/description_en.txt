Create and configure a Telegram log forwarding sidecar container for Docker Compose stacks. Tails logs from sibling services via the Docker socket and forwards filtered lines to a Telegram chat via Bot API. Use when the user wants Telegram alerts/notifications from container logs, a log shipping sidecar, observability via Telegram, or asks to "set up Telegram logs", "telegram sidecar", "forward container logs to Telegram", "log alerts to Telegram".
