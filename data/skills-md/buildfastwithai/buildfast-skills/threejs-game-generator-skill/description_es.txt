Construye, amplía o perfecciona juegos 3D originales para navegador y prototipos interactivos con Three.js. Utilízalo cuando un usuario quiere un juego WebGL jugable, una experiencia tipo juego con Three.js, un concepto 2D traducido a 3D, o un proyecto existente de Three.js al que se le añada un bucle completo, controles, cámara, colisiones, estados de UI, audio, persistencia, trabajo de rendimiento o verificación de compilación de producción. No lo actives para visores de productos 3D ordinarios, visualizaciones de datos o escenas de fondo decorativas, a menos que la solicitud incluya mecánicas de juego o interacción del jugador.

Por favor, responde siempre en el idioma del usuario.
