قم بتدقيق وتجديد واجهات الويب القائمة لتصبح تجارب مصقولة ومهنية ومخصصة للمنتج مع الحفاظ على السلوك والعمل ضمن مجموعة التقنية الأمامية الحالية. استخدم ذلك لتلبية الطلبات التي تهدف إلى تحسين واجهة مستخدم ذات طابع نمطي، عامة، شبيهة بالقالب، غير متسقة، قديمة، هاوية، أو واضحة بأنها مُولدة بالذكاء الاصطناعي؛ لإعادة تصميم صفحة أو تطبيق أو لوحة تحكم أو صفحة هبوط أو مكوّن موجود؛ لإرساء توجيه فني أقوى، هيكلية، طباعة، تباعد، ألوان، استجابة، إتاحة، حالات تفاعل، أو تماسك بصري؛ أو لإجراء تحسينات متميزة على واجهة المستخدم باستخدام HTML وCSS وJavaScript وReact وVue وSvelte وNext.js وغيرها من قواعد الكود الأمامية المشابهة.
