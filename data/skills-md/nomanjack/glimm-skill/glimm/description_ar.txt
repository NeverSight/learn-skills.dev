قم بتثبيت وربط وضبط glimm — انتقالات صفحات بألوان WebGL — في مشروع ويب، مع الإعداد الصحيح والنصائح الصادقة حول موضعه المناسب. استخدمه كلما أراد المستخدم انتقالات الصفحات، أو رسومًا متحركة لتغيّر المسارات، أو تنقلًا يبدو أكثر حيوية أو صقلا، أو ذكر glimm بالاسم، أو طلب “انتقالات عرض مع بعض اللون” في موقع Next.js أو React، حتى لو لم يذكر المكتبة. استخدمه أيضًا عند تخصيص تثبيت glimm موجود — تغيير اللوحات اللونية، مطابقة ألوان العلامة التجارية، تعديل توقيت أو اتجاه المسح، أو استثناء روابط محددة. واستخدمه عندما يجب أن يحصل لحظة واحدة داخل التطبيق على مسح، مثل ترقية الخطة، أو صفحة دفع، أو تغيير وضع، أو نتيجة مُولَّدة.
