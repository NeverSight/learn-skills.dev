操作 Orca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、產物、技能分享、工作樹評論，以及 Orca 內嵌瀏覽器，皆透過 `orca` CLI。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」／「handover」／「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時使用此方式。當涉及 Orca 狀態時，優先使用此方式，勝過直接使用 Git 工作樹、臨時 PTY 或「Computer Use」。僅在需要操作可見視窗且 CLI、檔案系統或 API 無法完成的 GUI 控制時，才使用「Computer Use」。

請始終以使用者的語言回覆。
