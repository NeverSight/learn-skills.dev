Orcaが管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そしてOrcaの組み込みブラウザを `orca` CLI で操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orcaの状態が関わる場合は、raw git worktree、ad hoc PTYs、あるいはComputer Useよりもこちらを優先します。CLI、ファイルシステム、APIでは対処できない可視ウィンドウの GUI 制御が必要なときだけComputer Useを使用してください。
