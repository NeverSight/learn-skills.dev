قم بتشغيل الأشجار العمل المُدارة بواسطة Orca وسياقات المجلدات والطرفيات والمستودعات والأتمتة والمنتجات ومشاركة المهارات وتعليقات الأشجار العمل ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضِّل ذلك على استخدام git worktree الخام أو PTYs العشوائية أو استخدام الحاسوب عندما تكون حالة Orca متورطة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة رسومية لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به.
