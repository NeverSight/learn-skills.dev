Compétence d'ingénieur principal Flutter pour auditer l'architecture des projets Flutter. Analyse la structure du projet, la séparation des couches, la modularisation des fonctionnalités, la stratégie de gestion d'état et les limites des dépendances afin de détecter les risques architecturaux et la dette technique. À utiliser pour des requêtes telles que « examiner l'architecture Flutter », « analyser la structure du projet », « auditer la base de code Flutter », « détecter les problèmes d'architecture », « évaluer la scalabilité de cette application Flutter » ou « identifier la dette technique dans le projet Flutter ».
