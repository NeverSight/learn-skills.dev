تشغيل الأشجار العاملة التي يديرها Orca، وسياقات المجلدات، والأطراف الطرفية، والمستودعات، والأتمتة، والملفات الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضِّل هذا على الاستعمال المباشر لأداة git worktree، أو PTYs المؤقتة، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم الحاسوب فقط عندما يتطلب التحكم في نافذة مرئية لا يمكن لسطر الأوامر أو نظام الملفات أو API التعامل معها.
