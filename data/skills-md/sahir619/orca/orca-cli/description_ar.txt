قم بتشغيل شجرات العمل المدارة بواسطة Orca، وسياقات المجلدات، والطراقات، والمستودعات، والأتمتة، والملفات الناتجة، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدمه عندما يذكر المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّله على git worktree العادي، أو PTYs المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متضمنة. استخدم "Computer Use" فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو الـ API القيام بذلك.
