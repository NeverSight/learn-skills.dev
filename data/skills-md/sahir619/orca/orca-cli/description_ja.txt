Orcaが管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、およびOrcaの組み込みブラウザを `orca` CLI を通じて操作します。  
ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」「handover」「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用します。Orca の状態が関与する場合は、生の git worktree や臨時の PTY、Computer Use（コンピュータ利用）よりもこちらを優先してください。GUI 操作が必要で、CLI、ファイルシステム、API だけでは対処できない可視ウィンドウがある場合にのみ、Computer Use を使用します。
