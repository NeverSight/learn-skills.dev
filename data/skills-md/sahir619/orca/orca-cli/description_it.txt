Operare worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Utilizzare quando l’utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff”/“handover”/“give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferirla rispetto a un worktree git grezzo, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Usare Computer Use solo quando è necessaria la gestione di una finestra visibile che una CLI, il filesystem o un’API non possono eseguire.
