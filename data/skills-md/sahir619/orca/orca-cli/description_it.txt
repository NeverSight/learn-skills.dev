Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser incorporato di Orca tramite la CLI `orca`. Usala quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferiscila rispetto a raw git worktree, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Usa Computer Use solo quando è necessaria la gestione GUI di una finestra visibile che una CLI, filesystem o API non possono fare.
