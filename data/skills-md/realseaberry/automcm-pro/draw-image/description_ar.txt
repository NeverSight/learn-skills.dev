قم بإنشاء مخططات ومخططات انسيابية ورسوم توضيحية مفاهيمية باستخدام OpenAI gpt-image-2 (افتراضي) أو gpt-image-1. يُستخدم من أجل: مخططات تدفق الخوارزمية/الكود، ورسومات بنية النظام، والرسوم التوضيحية المفاهيمية، وأي شكل لا يمثل مخرجات تنفيذ التعليمات البرمجية الفعلية (يجب أن يتم إنشاء مخططات البيانات، ونتائج النماذج، وما إلى ذلك عن طريق تشغيل كود Python). يتطلب التحقق من مؤسسة OPENAI_API_KEY وOpenAI عند استخدامه من مسار Claude Code / API. يمكن لمشتركي OpenAI Codex استخدام imagegen المدمج بدون مفتاح API.
