À utiliser pour : les diagrammes d'algorithme/de code, les croquis d'architecture système, les illustrations conceptuelles et toute figure qui ne représente PAS le résultat réel de l'exécution de code (les tracés de données, les résultats du modèle, etc. doivent toujours être générés en exécutant du code Python). Nécessite la vérification de l'organisation OPENAI_API_KEY et OpenAI lorsqu'il est utilisé à partir du chemin Claude Code/API. Les abonnés OpenAI Codex peuvent utiliser $imagegen intégré sans clé API.
