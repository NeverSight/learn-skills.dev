Создавайте диаграммы, блок-схемы и концептуальные иллюстрации с помощью OpenAI gpt-image-2 (по умолчанию) или gpt-image-1. Используется для: блок-схем алгоритмов/кода, эскизов системной архитектуры, концептуальных иллюстраций и любых рисунков, которые НЕ представляют собой фактические выходные данные выполнения кода (графики данных, результаты модели и т. д. все равно должны генерироваться путем запуска кода Python). Требуется OPENAI_API_KEY и проверка организации OpenAI при использовании из кода Claude/пути API. Подписчики OpenAI Codex могут использовать встроенный $imagegen без ключа API.
