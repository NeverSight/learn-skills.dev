Bibliothèque de références d'animations UI qui vous aide à ajouter les animations appropriées à votre produit. Pas besoin de comprendre le motion — il suffit de décrire le scénario de votre produit (chargement de page lent, le clic de l'utilisateur ne reçoit aucune réponse, vous souhaitez que la page paraisse plus sophistiquée), et elle recommande directement des solutions + du code. Mots‑clés déclencheurs : page sans animation, interaction sans retour, comment ajouter du motion, faire bouger la page, que faire quand le chargement est trop lent, vouloir que le produit ait un aspect plus haut de gamme, référence motion.
