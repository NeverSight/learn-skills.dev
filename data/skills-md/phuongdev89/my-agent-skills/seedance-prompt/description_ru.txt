Создание продвинутых видеоподсказок AI в жанре кино и списка планов для каждой сцены для модели Seedance 2.0. Активируется, когда пользователь хочет написать видеоподсказку, составить список планов, раскадровать видео, создать рекламный ролик, бренд‑фильм или упомянуть «Seedance», «prompt video», «viết prompt seedance», «kịch bản phân cảnh AI».
