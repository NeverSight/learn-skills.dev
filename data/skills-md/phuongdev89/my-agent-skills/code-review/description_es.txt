Revisa los cambios desde un punto fijo (commit, rama, etiqueta o merge‑base) a lo largo de dos ejes — Estándares (¿el código sigue los estándares de codificación documentados en este repositorio?) y Especificación (¿el código coincide con lo que pedía el issue/PRD original?). Ejecuta ambas revisiones en sub‑agentes paralelos y los muestra lado a lado. Úsalo cuando el usuario quiera revisar una rama, un PR, cambios en progreso o solicite “revisar desde X”.
