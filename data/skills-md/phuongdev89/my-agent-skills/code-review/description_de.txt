Überprüfe die Änderungen seit einem festen Punkt (Commit, Branch, Tag oder Merge‑Base) entlang zweier Achsen — Standards (entspricht der Code den dokumentierten Codierungsstandards dieses Repos?) und Spezifikation (stimmt der Code mit den Anforderungen des zugrunde liegenden Issues/PRD überein?). Führt beide Prüfungen in parallelen Sub‑Agents aus und stellt sie nebeneinander dar. Verwende diese Möglichkeit, wenn der Benutzer einen Branch, einen PR, laufende Änderungen prüfen möchte oder darum bittet, „seit X zu überprüfen“.
