Passez en revue les modifications depuis un point fixe (commit, branch, tag ou merge-base) le long de deux axes — Standards (le code suit-il les normes de codage documentées de ce repo ?) et Spec (le code correspond-il à ce que le problème/PRD d'origine a demandé ?). Exécute les deux revues en sous-agents parallèles et les rapporte côte à côte. À utiliser lorsque l'utilisateur souhaite revoir une succursale, une DA, des modifications de travaux en cours ou demande à « revoir depuis X ».
