مراجعة التغييرات منذ نقطة ثابتة (التزام، فرع، علامة، أو قاعدة دمج) على محورين — المعايير (هل يتبع الكود معايير الترميز الموثقة لهذا المستودع؟) والمواصفات (هل يتطابق الكود مع ما طلبته المشكلة/وثيقة المتطلبات الأصلية؟). يتم تشغيل كلتا المراجعتين في وكلاء فرعيين متوازيين وتُعرض النتائج جنبًا إلى جنب. يُستخدم عندما يرغب المستخدم في مراجعة فرع، أو طلب سحب، أو تغييرات قيد التقدم، أو يطلب «مراجعة منذ X».
