Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser incorporato di Orca tramite la CLI `orca`. Usala quando l’utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferiscila rispetto a git worktree grezzo, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Usa Computer Use solo quando una finestra visibile richiede un controllo GUI che una CLI, il filesystem o un’API non possono gestire.

Rispondi sempre nella lingua dell’utente.
