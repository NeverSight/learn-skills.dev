تشغيل شجرات العمل التي تديرها Orca، وسياقات المجلدات، والمحطات الطرفية، والمستودعات، والأتمتة، والمواد، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر واجهة الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّلها على شجرة git العادية أو PTYs المؤقتة أو استخدام الحاسوب عندما تكون حالة Orca متورطة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة رسومية لا يمكن لواجهة الأوامر أو نظام الملفات أو API القيام به.
