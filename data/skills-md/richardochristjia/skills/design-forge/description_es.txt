Planifica el trabajo de diseño UI con el usuario antes de escribir cualquier código. Analiza la aplicación, muestra las pantallas actuales, ofrece tres direcciones visuales para elegir y presenta un plan con una sección de diseño, una matriz responsiva y una puerta que aprueba‑plan y envía‑plan, llevándolos a una solicitud de extracción. Cubre nuevas páginas, pantallas y componentes de la aplicación, rediseños, reestilos y revisiones de diseño, flujos de usuario entre pantallas, limpieza del sistema de diseño y apps nativas para iOS y Android. Úsalo cuando el usuario quiera diseñar, rediseñar, revisar o pulir una UI, mejorar un flujo, hacer una página apta para móvil, ordenar colores y tamaños, o planificar pantallas para una app móvil, antes de implementarla. Para cambios que no sean de UI, usa forge.
