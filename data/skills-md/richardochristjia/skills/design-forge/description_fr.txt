Plans la conception UI avec l'utilisateur avant que tout code ne soit écrit. Analyse l'application, montre les écrans actuels, propose trois orientations visuelles parmi lesquelles choisir, et présente un plan comprenant une section design, une matrice responsive et une porte qui valide‑plan et livre‑plan pour aboutir à une pull request. Couvre les nouvelles pages, les écrans et composants d'application, les refontes, les restylages et les revues de design, les flux utilisateurs entre les écrans, le nettoyage du design‑system, ainsi que les applications natives iOS et Android. À utiliser lorsque l'utilisateur souhaite concevoir, refondre, revoir ou peaufiner une UI, améliorer un flux, rendre une page adaptée aux mobiles, harmoniser les couleurs et les tailles, ou planifier les écrans d'une application mobile, avant de l'implémenter. Pour les changements non liés à l'UI, utilisez forge.
