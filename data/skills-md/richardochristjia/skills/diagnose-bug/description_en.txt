Finds the cause of an everyday bug and proves it before anyone fixes it. Questions the ticket first, pins down what fails and how often, ranks the suspects with "not a bug" always among them, checks the cheapest first, reproduces the bug with a control, proves the smallest fix in that repro, and has a fresh helper try to break the answer. Ends with a short diagnosis and a fix plan for the user to approve. Never changes a checkout anyone works in. Use for a bug ticket, a Sentry issue or an error to explain, or for "diagnose this", "why does this happen", "find the root cause" or "is this a bug". Hard bugs and questions about a number go to orb's Research world.
