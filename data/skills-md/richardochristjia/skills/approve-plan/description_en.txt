Turns an approved plan into a spec (.plans/{task}/plan.md) and a task list (tasks.md), sized by the change's tier, then picks the task loop, model and effort and starts an unattended run with ship-plan in this checkout, which ends in the configured delivery (a pull request by default). Use right after the user approves a plan from forge or a fix plan from diagnose-bug, or says "approve", "ship it" or "go".
