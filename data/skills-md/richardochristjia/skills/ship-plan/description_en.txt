Takes an approved plan from implementation to an open pull request with nobody watching. Picks the depth of the run from the change's size, routes each step to a model, taste tests the build like a user against the repo's committed fixture, reviews it, has a falsifier argue against each finding, fixes what's proven in one round, opens the merge request, and reports back. Never merges. Use after approve-plan hands over a plan to finish unattended, or when the user says "ship this plan".
