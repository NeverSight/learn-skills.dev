Берёт одобренный план от реализации до открытого pull request, за которым никто не следит. Выбирает глубину выполнения по размеру изменения, направляет каждый шаг к модели, тестирует сборку как пользователь против зафиксированного фикстура репозитория, проверяет её, у него есть опровержитель, который спорит с каждым выводом, исправляет то, что доказано за один раунд, открывает merge request и сообщает обратно. Никогда не сливает. Используйте после approve‑plan, когда план передаётся для завершения без присмотра, или когда пользователь говорит «отправьте этот план».
