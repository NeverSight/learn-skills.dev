Erstellt eine kleine Zusammenfassung einer Änderung — das Diff, die betroffenen Dateien, die API‑Verträge und die Test‑Einstiegspunkte — damit Review‑Agenten diese lesen, anstatt das Repository erneut zu durchsuchen. Vor einer Review verwenden oder wenn mehrere Agenten sonst dieselben Dateien erneut lesen würden.
