Audita e recupera in modo sicuro spazio sul disco C di Windows con un registro di sola lettura dell'intero disco, analisi ricorsiva delle cartelle grandi, rilevamento di file di grandi dimensioni e duplicati, classificazione della cache delle applicazioni, conferma esplicita dei batch, cancellazione protetta e verifica post-pulizia. Usa questa funzionalità quando l'utente invoca esplicitamente $cclean-skill, chiede cosa occupa C:, vuole liberare spazio su disco, richiede un audit completo dello storage o desidera decidere cosa può essere eliminato senza perdere file personali, stato delle applicazioni o ambienti di sviluppo.
