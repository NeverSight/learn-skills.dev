Crea la estructura de un gráfico openalgo-charts funcional en un proyecto existente: detecta el host (React, Next.js, Vue, empaquetador «vanilla» o etiqueta «script» simple), instala los niveles adecuados y escribe un gráfico que muestra datos reales. Úselo cuando el usuario pida añadir un gráfico, configurar openalgo-charts o hacer que funcione un primer gráfico.
