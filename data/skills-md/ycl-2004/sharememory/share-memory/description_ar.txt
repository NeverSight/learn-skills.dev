الذاكرة المشتركة ذات نطاق المشروع لوكلاء الترميز الذكي (Claude Code + Codex) عبر AI_MEMORY/ واحد لكل مشروع. استخدمها عندما يقول المستخدم "init memory"، "update memory"، "sync memory"، "memory status"، "consolidate memory"، "repair memory"، "migrate memory"، "更新记忆"، "共享记忆"، أو عندما تكون AI_MEMORY/ مفقودة في مشروع ينبغي أن تكون موجودة فيه، أو لتسجيل العمل المكتمل للوكيل الآخر.  
لا تُستخدم لـ: ذاكرة الدردشة العامة، حالة مشتركة غير مشروع، ملخصات لمرة واحدة، تفضيلات شخصية عبر مشاريع، أرشفة مواد الكتابة، أو عمليات تدقيق للقراءة فقط. إذا منع المستخدم الكتابة ("don't modify anything"، "read-only audit"، "only write the report")، يتم إيقاف الكتابة التلقائية — لا تكتب AI_MEMORY/ واذكر ذلك في النهاية.
