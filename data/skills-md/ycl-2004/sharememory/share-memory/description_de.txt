Projektbezogener Shared Memory für KI‑Coding‑Agents (Claude Code + Codex) über ein AI_MEMORY/ pro Projekt. Verwenden, wenn der Nutzer sagt „init memory“, „update memory“, „sync memory“, „memory status“, „consolidate memory“, „repair memory“, „migrate memory“, „更新记忆“, „共享记忆“, wenn AI_MEMORY/ in einem Projekt fehlt, das es haben sollte, oder um erledigte Arbeit für den anderen Agenten zu protokollieren.  
NICHT verwenden für: allgemeinen Chat‑Speicher, nicht‑projektbezogenen geteilten Zustand, einmalige Zusammenfassungen, projektübergreifende persönliche Präferenzen, Archivierung von Schreibmaterialien oder rein lesende Audits. Wenn der Nutzer das Schreiben verbietet („don't modify anything“, „read‑only audit“, „only write the report“), wird das automatische Schreiben pausiert — AI_MEMORY/ nicht schreiben und am Ende darauf hinweisen.  

Bitte stets in der Sprache des Nutzers antworten.
