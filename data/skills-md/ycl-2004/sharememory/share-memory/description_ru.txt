Общая память, ограниченная проектом, для кодирующих агентов ИИ (Claude Code + Codex) через одну папку AI_MEMORY/ на проект. Использовать, когда пользователь говорит «init memory», «update memory», «sync memory», «memory status», «consolidate memory», «repair memory», «migrate memory», «更新记忆», «共享记忆», когда в проекте, где она должна быть, отсутствует AI_MEMORY/, или для записи завершённой работы для другого агента.  
Не использовать для: общей памяти беседы, общих состояний вне проекта, одноразовых резюме, личных предпочтений между проектами, архивирования материалов для письма или проверок только для чтения. Если пользователь запрещает запись («не изменяйте ничего», «проверка только для чтения», «только напишите отчёт»), автоматическая запись приостанавливается — не создавайте AI_MEMORY/ и укажите об этом в конце.  

Пожалуйста, всегда отвечайте на языке пользователя.
