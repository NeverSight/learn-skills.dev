Esegui il push del ramo corrente e crea una pull request su GitHub con gh CLI. Invocala esplicitamente come `gh-create-pr` o `$gh-create-pr`, o automaticamente ogni volta che il compito richiede l’apertura o l’aggiornamento di una pull request, anche senza nominare la skill.

Per favore rispondi sempre nella lingua dell'utente.
