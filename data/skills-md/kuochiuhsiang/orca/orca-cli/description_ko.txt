Orca가 관리하는 작업 트리, 폴더 컨텍스트, 터미널, 리포지토리, 자동화, 아티팩트, 스킬 공유, 작업 트리 댓글, 그리고 Orca의 내장 브라우저를 `orca` CLI를 통해 조작합니다. 사용자가 “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts”, 혹은 “share skills” 라고 말할 때 이를 사용합니다. Orca 상태가 관련된 경우에는 일반 git worktree, 임시 PTY, 또는 컴퓨터 사용보다 이를 우선합니다. CLI, 파일 시스템, API로 처리할 수 없는 GUI 제어가 필요한 눈에 보이는 창이 있을 때만 컴퓨터 사용을 사용합니다.
