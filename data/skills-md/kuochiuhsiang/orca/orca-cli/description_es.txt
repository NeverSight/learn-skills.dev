Opera los worktrees gestionados por Orca, los contextos de carpeta, terminales, repositorios, automatizaciones, artefactos, intercambio de habilidades, comentarios en los worktrees y el navegador integrado de Orca mediante la CLI `orca`. Utilízalo cuando el usuario diga "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Prefiérelo sobre un worktree git puro, PTYs ad hoc o el uso de la computadora cuando el estado de Orca está involucrado. Usa el uso de la computadora solo cuando una ventana visible necesite control GUI que una CLI, el sistema de archivos o una API no puedan realizar.
