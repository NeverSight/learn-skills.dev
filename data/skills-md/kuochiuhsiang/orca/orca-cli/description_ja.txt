Orca が管理するワークツリー、フォルダコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、純粋な git worktree、臨時の PTY、あるいは Computer Use よりもこちらを優先してください。GUI の制御が必要で、CLI、ファイルシステム、API では対処できない可視ウィンドウがあるときのみ Computer Use を使用します。

常にユーザーの言語で回答してください。
