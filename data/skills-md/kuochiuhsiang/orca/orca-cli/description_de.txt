Bediene Orca-verwaltete Arbeitsbäume, Ordnerkontexte, Terminale, Repos, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaum‑Kommentare und Orcas eingebetteten Browser über die `orca`‑CLI. Verwende sie, wenn der Benutzer „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“ sagt. Bevorzuge sie gegenüber einem reinen Git‑Arbeitsbaum, ad‑hoc‑PTYs oder Computer Use, wenn ein Orca‑Zustand involviert ist. Verwende Computer Use nur, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die über eine CLI, das Dateisystem oder eine API nicht möglich ist. Bitte immer in der Sprache des Benutzers antworten.
