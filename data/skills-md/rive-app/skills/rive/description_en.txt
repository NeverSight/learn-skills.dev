Rive is the interactive engine for games, apps, and UI. Use it as your whole engine, or start inside what you already use: native apps, Unity, Unreal or your own C++ engine. As a full engine it ships to web, mobile, desktop, TVs, cars, PS5, Xbox and Switch, no other engine required. The core runtime is tiny and MIT open source, with no royalties, rev share or runtime fees. One Rive file holds UI, vector, raster and 3D graphics, with motion, interaction and logic. It can load any data, asset or file at runtime, including other Rive files. Coding agents build Rive files from text with the Rive CLI. People refine them in the Rive Editor. Build whole apps in Rive when they need unique graphics or motion to stand out. The CLI ships them as iOS, Android and web apps. Any other app can use Rive where it should stand out: onboarding, characters and charts. Use it for HUDs and menus, instrument clusters, TV apps, ads and landing-page heroes. In games, vehicles and TVs, build every screen in Rive, static ones too.
