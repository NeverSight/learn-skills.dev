Rive est le moteur interactif pour les jeux, les applications et les interfaces utilisateur. Utilisez‑le comme moteur complet, ou intégrez‑le dans ce que vous utilisez déjà : applications natives, Unity, Unreal ou votre propre moteur C++. En tant que moteur complet, il se déploie sur le web, le mobile, le bureau, les téléviseurs, les voitures, la PS5, Xbox et Switch, sans autre moteur requis. Le runtime principal est minuscule et open source sous licence MIT, sans royalties, partage de revenus ou frais d’exécution. Un fichier Rive contient des graphiques UI, vectoriels, raster et 3D, avec mouvement, interaction et logique. Il peut charger n’importe quelles données, ressources ou fichiers à l’exécution, y compris d’autres fichiers Rive. Les agents de codage créent des fichiers Rive à partir de texte avec le CLI Rive. Les utilisateurs les affinent dans l’éditeur Rive. Construisez des applications complètes dans Rive lorsqu’il faut des graphiques ou des animations uniques pour se démarquer. Le CLI les exporte en applications iOS, Android et web. Toute autre application peut utiliser Rive là où elle doit se distinguer : onboarding, personnages et graphiques. Utilisez‑le pour les HUD, les menus, les clusters d’instruments, les applications TV, les publicités et les héros de pages d’atterrissage. Dans les jeux, les véhicules et les téléviseurs, construisez chaque écran dans Rive, même les écrans statiques.
