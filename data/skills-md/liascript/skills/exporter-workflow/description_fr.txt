Génère des workflows d’exportation LiaScript, des GitHub Actions et des fichiers project.yaml pour les dépôts LiaScript. À utiliser lorsqu’un utilisateur souhaite : exporter un cours LiaScript vers PDF / SCORM / IMS / ePub / DOCX / xAPI / Android ; créer ou mettre à jour un workflow GitHub Actions pour LiaScript ; construire un site de projet (page d’index) qui agrège plusieurs cours ; configurer le déploiement automatisé vers GitHub Pages ; ajouter des contrôles de qualité (orthographe / style) à un dépôt LiaScript ; ou poser toute question concernant le CLI liaex, @liascript/exporter ou le CI/CD de LiaScript.
