Genera flujos de trabajo de exportación de LiaScript, GitHub Actions y archivos project.yaml para repositorios de LiaScript. Úsalo cuando un usuario quiera: exportar un curso de LiaScript a PDF/SCORM/IMS/ePub/DOCX/xAPI/Android; crear o actualizar un flujo de trabajo de GitHub Actions para LiaScript; construir un sitio web de proyecto (página índice) que agregue múltiples cursos; configurar despliegue automatizado a GitHub Pages; añadir verificaciones de calidad (ortografía/estilo) a un repositorio de LiaScript; o preguntar cualquier cosa relacionada con el CLI liaex, @liascript/exporter o LiaScript CI/CD.
