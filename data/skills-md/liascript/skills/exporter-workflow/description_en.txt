Generates LiaScript export workflows, GitHub Actions, and project.yaml files for LiaScript repositories. Use when a user wants to: export a LiaScript course to PDF/SCORM/IMS/ePub/DOCX/xAPI/Android; create or update a GitHub Actions workflow for LiaScript; build a project website (index page) that aggregates multiple courses; set up automated deployment to GitHub Pages; add quality checks (spell/style) to a LiaScript repo; or asks anything involving the liaex CLI, @liascript/exporter, or LiaScript CI/CD.
