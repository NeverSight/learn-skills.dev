Génère des fichiers de métadonnées YAML compatibles OERSI (metadata.yml) pour les ressources éducatives ouvertes hébergées sur GitHub. À utiliser lorsqu’un utilisateur veut publier des OER sur OERSI, créer ou mettre à jour un fichier metadata.yml, a besoin d’aide avec les métadonnées Schema.org/LRMI/KIM, ou demande comment définir le sujet GitHub open-educational-resources pour l’indexation des OER.

Veuillez toujours répondre dans la langue de l’utilisateur.
