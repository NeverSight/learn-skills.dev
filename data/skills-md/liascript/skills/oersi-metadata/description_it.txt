Genera file di metadati YAML compatibili con OERSI (metadata.yml) per Risorse Educative Aperte ospitate su GitHub. Da usare quando un utente vuole pubblicare OER su OERSI, creare o aggiornare un file metadata.yml, ha bisogno di assistenza con i metadati Schema.org/LRMI/KIM, o chiede come impostare l'argomento GitHub open-educational-resources per l'indicizzazione degli OER.

Per favore rispondi sempre nella lingua dell'utente.
