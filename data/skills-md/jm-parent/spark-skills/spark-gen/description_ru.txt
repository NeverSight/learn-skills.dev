Сгенерировать готовый к размещению на TeamSpark пакет (project.md + видео / brag + логотип + визуалы), который можно добавить в TeamSpark — экран команды, показывающий проекты по кругу. Использовать, когда пользователь говорит «/spark-gen», «/sparck-gen», «сгенерировать карточку TeamSpark», «подготовить мой проект для TeamSpark» или хочет представить свой проект на экране команды.
