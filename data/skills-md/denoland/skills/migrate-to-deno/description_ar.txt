استخدم ذلك عند نقل مشروع Node.js أو npm أو Yarn أو pnpm أو Bun إلى Deno، أو عند اعتماد Deno تدريجيًا في قاعدة شفرة JavaScript أو TypeScript موجودة. يغطي الاستخدام كمدير حزم بديل، تشغيل سكريبتات package.json الحالية، مقارنة CommonJS و ESM، بنية node_modules، ترحيل ملف القفل، الأذونات، ما إذا كان ينبغي اعتماد سلسلة الأدوات المدمجة، وما يعادل أوامر كل أداة.
