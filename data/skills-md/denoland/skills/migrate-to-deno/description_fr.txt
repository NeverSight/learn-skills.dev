Utilisez-le lors du passage d’un projet Node.js, npm, Yarn, pnpm ou Bun à Deno, ou lors de l’adoption progressive de Deno dans une base de code JavaScript ou TypeScript existante. Il couvre l’utilisation de Deno comme gestionnaire de paquets de substitution, l’exécution des scripts package.json existants, CommonJS versus ESM, la structure de node_modules, la migration du fichier de verrouillage, les permissions, la décision d’adopter la chaîne d’outils intégrée, ainsi que les équivalents de commande pour chaque outil.
