Write or refresh a visual recap of a GitHub pull request for its reviewers, posted as one PR comment between pstack-recap markers. The recap opens with two sentences on why the change exists and what it changes, then one hand-drawn sketch of the changed mechanism, attached as an image, then one line on what the PR does not prove. Risk, SHAs, reading order, and file areas sit in a collapsed block below. Use after you open a PR or push to one, or when asked to "recap this PR", "visual recap", "PR recap", "diagram this PR", or "summarize this PR for reviewers". Skip trivial PRs.
