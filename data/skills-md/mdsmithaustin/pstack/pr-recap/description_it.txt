Scrivi o aggiorna un riepilogo visivo di una pull request di GitHub per i suoi revisori, pubblicato come un unico commento PR tra i marcatori `pstack-recap`. Il riepilogo si apre con due frasi sul perché il cambiamento esiste e cosa modifica, poi un disegno a mano libera del meccanismo modificato, allegato come immagine, e infine una riga su ciò che il PR non dimostra. Rischio, SHA, ordine di lettura e aree di file sono collocati in un blocco collassato sotto. Usalo dopo aver aperto una PR o avervi effettuato push, o quando ti viene chiesto di “riassumere questa PR”, “riepilogo visivo”, “riassunto PR”, “diagrammare questa PR” o “sintetizzare questa PR per i revisori”. Salta le PR banali.

Per favore, rispondi sempre nella lingua dell'utente.
