レビューア向けに、GitHub のプルリクエストの視覚的な要約を書き直す、または更新する。コメントは `pstack-recap` マーカーで囲んだ 1 つの PR コメントとして投稿する。要約は、変更が存在する理由と何が変わったかについての 2 文で始め、その後、変更された仕組みの手描きスケッチを画像として添付し、最後に PR が証明しないことを 1 行で記す。リスク、SHA、読み順、ファイル領域は下部の折りたたみブロックに入れる。PR を作成した直後やプッシュしたとき、または「recap this PR」「visual recap」「PR recap」「diagram this PR」「summarize this PR for reviewers」と求められたときに使用する。些細な PR はスキップする。

常にユーザーの言語で応答してください。
