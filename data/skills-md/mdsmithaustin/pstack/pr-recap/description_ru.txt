Создайте или обновите визуальный рекап пулреквеста GitHub для его рецензентов, разместив его как один комментарий PR между маркерами pstack-recap. Рекап начинается с двух предложений, объясняющих, почему изменение существует и что оно меняет, затем следует один нарисованный от руки скетч изменённого механизма, прикреплённый как изображение, затем одна строка о том, чего PR не доказывает. Риски, SHA‑хэши, порядок чтения и области файлов находятся в свернутом блоке ниже. Используйте после открытия PR или после пуша в него, либо когда вас просят «сделать recap этого PR», «визуальный recap», «PR recap», «схематизировать этот PR» или «суммировать этот PR для рецензентов». Пропускайте тривиальные PR.
