GitHub 풀 리퀘스트의 리뷰어를 위한 시각적 요약을 작성하거나 갱신하세요. pstack-recap 마커 사이에 하나의 PR 코멘트로 게시합니다. 요약은 변경이 존재하는 이유와 무엇을 변경하는지에 대한 두 문장으로 시작하고, 변경된 메커니즘의 손그림 스케치를 이미지로 첨부한 뒤, PR이 증명하지 못하는 내용 한 줄을 추가합니다. 위험 요소, SHA, 읽기 순서, 파일 영역은 아래의 접힌 블록에 배치합니다. PR을 열거나 푸시했을 때, 혹은 “recap this PR”, “visual recap”, “PR recap”, “diagram this PR”, “summarize this PR for reviewers”라는 요청을 받을 때 사용하세요. 사소한 PR은 건너뛰세요.

항상 사용자의 언어로 응답하십시오.
