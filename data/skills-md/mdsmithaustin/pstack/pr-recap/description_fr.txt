Écrivez ou actualisez un récapitulatif visuel d’une pull request GitHub pour ses réviseurs, publié comme un seul commentaire de PR entre les marqueurs pstack-recap. Le récapitulatif commence par deux phrases expliquant pourquoi le changement existe et ce qu’il modifie, suivi d’un croquis fait à la main du mécanisme modifié, joint sous forme d’image, puis d’une ligne indiquant ce que la PR ne prouve pas. Les risques, les SHA, l’ordre de lecture et les zones de fichiers se trouvent dans un bloc plié en dessous. Utilisez-le après avoir ouvert une PR ou effectué un push dessus, ou lorsqu’on vous demande de « récap ce PR », « récap visuel », « récap PR », « diagrammer ce PR » ou « résumer ce PR pour les réviseurs ». Ignorez les PR triviales. Veuillez toujours répondre dans la langue de l’utilisateur.
