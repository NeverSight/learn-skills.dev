Escribe o actualiza un resumen visual de una pull request de GitHub para sus revisores, publicado como un único comentario de PR entre marcadores `pstack-recap`. El resumen comienza con dos frases sobre por qué existe el cambio y qué modifica, seguido de un esquema dibujado a mano del mecanismo cambiado, adjunto como una imagen, y luego una línea sobre lo que la PR no prueba. Riesgo, SHAs, orden de lectura y áreas de archivos aparecen en un bloque colapsado debajo. Utilízalo después de abrir una PR o hacer push a una, o cuando te pidan “recap this PR”, “visual recap”, “PR recap”, “diagram this PR” o “summarize this PR for reviewers”. Omite PRs triviales.

Por favor, responde siempre en el idioma del usuario.
