Mappa le primitive di delega e di risorsa portatile di pstack all’attuale CLI (Claude Code, Codex, Hermes, Grok Build o qualsiasi altro harness). Copre come individuare le skill installate e le risorse trunk fresche, avviare un sottoagente, impostare un modello per-sottoagente, parallelizzare i rami, passare in modalità sola lettura, porre una domanda strutturata (AskQuestion), tenere traccia di una lista di lavoro, eseguire un ciclo e localizzare il deposito delle trascrizioni. Leggi ogni volta che una skill di pstack indica spawn, Task tool, subagent_type, modello per-sottoagente, AskQuestion o worklist, nomina una skill sorella che non riesci a trovare, o esegue un percorso da un playbook. Ogni primitive è denominata diversamente a seconda dell’harness, quindi leggi questo prima di concludere che il tuo harness non dispone di tale capacità o risorsa.
