Mapea las primitivas de delegación y recursos portátiles de pstack al CLI actual (Claude Code, Codex, Hermes, Grok Build o cualquier otro harness). Cubre cómo localizar habilidades instaladas y recursos de trunk frescos, generar un subagente, establecer un modelo por subagente, paralelizar brazos, pasar a modo de solo lectura, hacer una pregunta estructurada (AskQuestion), rastrear una lista de trabajo, bucle y localizar el almacén de transcripciones. Lea siempre que una habilidad de pstack indique spawn, Task tool, subagent_type, modelo por subagente, AskQuestion o worklist, nombre una habilidad hermana que no pueda encontrar, o ejecute una ruta desde un libro de jugadas. Cada primitiva tiene un nombre diferente según el harness, así que lea esto antes de concluir que su harness no tiene tal capacidad o recurso.
