يطابق تفويض pstack والبدائل القابلة للنقل للموارد مع واجهة سطر الأوامر الحالية (Claude Code أو Codex أو Hermes أو Grok Build أو أي نظام آخر). يغطي كيفية تحديد موقع المهارات المثبتة والموارد الجديدة من الشجرة، إنشاء وكيل فرعي، تعيين نموذج لكل وكيل فرعي، موازاة الأذرع، الانتقال إلى وضع القراءة فقط، طرح سؤال منظم (AskQuestion)، تتبع قائمة الأعمال، تنفيذ حلقة، وتحديد موقع مخزن النصوص. اقرأ كلما ذكرت مهارة pstack كلمات spawn أو أداة Task أو subagent_type أو نموذج لكل وكيل فرعي أو AskQuestion أو worklist، أو سُمّيت مهارة شقيقة لا يمكنك العثور عليها، أو تم تشغيل مسار من دليل التشغيل. كل بديل يُسمّى بشكل مختلف حسب النظام، لذا اقرأ هذا قبل الاستنتاج أن نظامك لا يمتلك هذه القدرة أو المورد.
