Anwenden beim Schreiben oder Überprüfen einer Spezifikation, Anforderungen, Akzeptanzkriterien, User Stories oder Tickets, bevor irgendein Code existiert. Zwei Durchläufe: ein Rand‑Check über einer geschlossenen Taxonomie von Datenform‑Grenzen und ein Verbot‑Check für das, was das Feature niemals stillschweigend werden darf. Jeder erhobene Punkt wird gelöst, mit einer Begründung verworfen oder als explizite Lücke beibehalten.
