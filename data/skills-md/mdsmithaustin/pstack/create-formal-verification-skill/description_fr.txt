Générez une compétence locale au projet qui vérifie formellement le code où un bug coûte le plus cher et où les tests atteignent le moins, dans n’importe quel langage, avec l’outil de vérification qui convient. Utilisez pour /create-formal-verification-skill, « model-check this race », « prove this invariant », ou lorsque la concurrence, les réessais, les machines d’état, les analyseurs ou le code non sécurisé nécessitent plus que des tests.

Veuillez toujours répondre dans la langue de l’utilisateur.
