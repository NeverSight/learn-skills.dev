Aplica cuando se solicite explícitamente sondear, ejercer presión, fuzzear o realizar pruebas caóticas a un producto, característica o PR para detectar errores no reportados, incluyendo la preparación de una entrega basada en el código fuente cuando el tiempo de ejecución no está disponible. No se aplique a revisiones estáticas ordinarias o a la investigación de un defecto conocido a menos que la solicitud también pida sondeos exploratorios en tiempo de ejecución. Dos pasadas: una taxonomía de sondeo cerrada, y luego una puerta de promoción que conserva solo los hallazgos accesibles al llamador.
