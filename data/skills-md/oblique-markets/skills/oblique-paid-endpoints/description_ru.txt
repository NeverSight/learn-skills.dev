Покупайте результаты API с оплатой за вызов на oblique.markets (https://api.oblique.markets/api/v1/paid/*) через HTTP 402 — x402 с USDC на Base или Solana или MPP/Tempo — без учетной записи и без ключа API. Используйте, когда агенту нужны рыночные данные x402 Bazaar, состояние цепочки Base или Solana (газ, блок, баланс USDC, статус передачи, приоритетные комиссии), веб-извлечение, настроения, изолированный Python, маршрутизация задач или вывод LLM и он может платить несколько десятых цента за вызов из своего собственного кошелька. Включает в себя сценарий расценок без использования кошелька, принтер для интерактивного каталога и автономного покупателя, который осуществляет реальный платеж x402.
