Úselo al crear o depurar publicaciones y suscripciones de Meteor (Meteor.publish, Meteor.subscribe). Activa las estrategias de publicación (SERVER_MERGE, NO_MERGE, NO_MERGE_NO_HISTORY), la API de publicación de bajo nivel (añadida/cambiada/eliminada), la autorización del cursor, las uniones reactivas, los documentos filtrados. Utilice esta habilidad cuando el usuario pregunte sobre pub/sub o pregunte sobre la obtención de datos reactivos.
