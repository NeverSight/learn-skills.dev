Используйте при настройке или оптимизации современного стека сборки Meteor 3: транспилер SWC, минификатор на базе SWC, современный @parcel/watcher, пропуск web‑arch в процессе разработки, .meteorignore и интеграцию бандлера Rspack через пакет Atmosphere rspack. Срабатывает при наличии в package.json «meteor»: { "modern": true }, .swcrc, swc.config.js, [Transpiler] Used Babel Fallback logs, rspack.config.js, rspack.config.ts, defineConfig из @meteorjs/rspack, вспомогательные функции Meteor.compileWith*, Meteor.extendConfig, Meteor.extendSwcConfig vs Meteor.replaceSwcConfig, Meteor.splitVendorChunk, Meteor.persistDevFiles, Meteor.disablePlugins, Meteor.enablePortableBuild, настройка HtmlRspackPlugin, RSPACK_DEVSERVER_PORT, TOOL_NODE_FLAGS, рабочие пространства pnpm, Rspack 2, выбор скелета, PWA, Workbox и настройка сборки сервис‑воркера. Используйте это умение, когда пользователь задаёт вопросы о сравнении SWC и Babel или о конфигурации Rspack. Перенаправляйте миграцию существующего приложения к бандлеру в migrate-to-rspack, создание PWA на Blaze в meteor-blaze и данные jam:offline в meteor-community-packages.
