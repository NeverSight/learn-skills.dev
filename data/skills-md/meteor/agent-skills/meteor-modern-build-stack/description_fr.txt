Utilisez‑le lors de la configuration ou du réglage de la pile de compilation moderne Meteor 3 : transpileur SWC, minificateur basé sur SWC, @parcel/watcher moderne, omission de web‑arch en développement, .meteorignore et l’intégration du bundler Rspack via le package Atmosphere rspack. Déclencheurs : `package.json` contenant `"meteor": { "modern": true }`, `.swcrc`, `swc.config.js`, `[Transpiler] Used Babel Fallback logs`, `rspack.config.js`, `rspack.config.ts`, `defineConfig` provenant de `@meteorjs/rspack`, aides `Meteor.compileWith*`, `Meteor.extendConfig`, `Meteor.extendSwcConfig` vs `Meteor.replaceSwcConfig`, `Meteor.splitVendorChunk`, `Meteor.persistDevFiles`, `Meteor.disablePlugins`, `Meteor.enablePortableBuild`, personnalisation de `HtmlRspackPlugin`, `RSPACK_DEVSERVER_PORT`, `TOOL_NODE_FLAGS`, espaces de travail pnpm, Rspack 2, sélection de squelette, PWA, Workbox et configuration de la construction du service‑worker. Utilisez cette compétence lorsque l’utilisateur pose des questions sur SWC vs Babel ou sur la configuration de Rspack. Orientez la migration du bundler d’une application existante vers `migrate-to-rspack`, le scaffolding Blaze PWA vers `meteor-blaze` et les données `jam:offline` vers les packages communautaires `meteor-community-packages`.
