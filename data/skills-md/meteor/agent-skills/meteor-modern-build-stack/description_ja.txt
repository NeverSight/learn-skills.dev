Meteor 3 のモダン ビルド スタックを構成または調整するときに使用します。SWC トランスパイラー、SWC ベースのミニファイアー、モダンな @parcel/watcher、開発中の Web アーチ スキップ、.meteorignore、rspack Atmosphere パッケージを介した Rspack バンドラーの統合。 package.json "meteor": { "modern": true }、.swcrc、swc.config.js、[Transpiler] 使用された Babel フォールバック ログ、rspack.config.js、rspack.config.ts、@meteorjs/rspack からのdefineConfig、Meteor.compileWith* ヘルパー、Meteor.extendConfig、Meteor.extendSwcConfig vs Meteor.replaceSwcConfig、Meteor.splitVendorChunk、Meteor.persistDevFiles、Meteor.disablePlugins、Meteor.enablePortableBuild、HtmlRspackPlugin カスタマイズ、RSPACK_DEVSERVER_PORT、TOOL_NODE_FLAGS、pnpm ワークスペース、Rspack 2、スケルトンの選択、PWA、Workbox、および Service-Worker のビルド セットアップ。このスキルは、ユーザーが SWC と Babel または Rspack の構成について尋ねたときに使用します。既存のアプリ バンドラーの移行を merge-to-rspack にルーティングし、Blaze PWA スキャフォールディングを meteor-blaze にルーティングし、jam:offline データを meteor-community-packages にルーティングします。
