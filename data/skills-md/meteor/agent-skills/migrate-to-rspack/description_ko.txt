기존 Meteor 앱을 Rspack(Meteor 3.4+)으로 마이그레이션하거나 Meteor 3.6 베타에서 Rspack 1을 2로 업그레이드할 때 사용합니다. 중첩된 가져오기, mainModule 진입점, 서버 전용 앱, fourseven:scss / meteor/less / Coffeescript / jorgenvatle:vite / zodern:melte를 로더로 교체, 업그레이드 후 Svelte/TypeScript 전처리 또는 Lingui SWC 플러그인 실패, CommonJS 기본 가져오기 상호 운용성, 클라이언트 그래프의 module.exports, 브라우저 코드의 노드 내장, _build / build-assets /에 대한 트리거 빌드 청크, 핸드오프 파일을 숨기는 .meteorignore, ROOT_URL 아래의 동적 청크, CSS/HTML용 meteor.modules,solv.symlinks 또는solve.alias 마이그레이션, 자동 종속성 업데이트 및 불변 CI/Docker 빌드. 사용자가 마이그레이션 호환성이나 빌드 플러그인의 Rspack 교체에 대해 문의할 때 이 기술을 사용하세요. 새로운 앱 설정 및 rspack.config.js 도우미의 경우 대신 meteor-modern-build-stack을 사용하세요.
