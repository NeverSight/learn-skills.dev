Используйте при миграции существующего приложения Meteor на Rspack (Meteor 3.4+), либо при обновлении Rspack 1 до 2 в бете Meteor 3.6. Срабатывает на вложенных импортах, точках входа mainModule, приложениях только для сервера, замене fourseven:scss / meteor/less / coffeescript / jorgenvatle:vite / zodern:melte загрузчиками, предобработке Svelte/TypeScript или ошибках плагина Lingui SWC после обновления, совместимости CommonJS default‑import, module.exports в клиентских графах, встроенных модулях Node в коде браузера, _build / build‑assets / build‑chunks, .meteorignore, скрывающем файлы handoff, динамических чанках под ROOT_URL, meteor.modules для CSS/HTML, миграции resolve.symlinks или resolve.alias, автоматических обновлениях зависимостей и неизменяемых CI/Docker‑сборках. Используйте этот навык, когда пользователь спрашивает о совместимости миграции или замене сборочного плагина на Rspack. Для настройки нового приложения и вспомогательных файлов rspack.config.js используйте meteor-modern-build-stack.
