Usa quando migri un’app Meteor esistente a Rspack (Meteor 3.4+) o aggiorni Rspack da 1 a 2 su Meteor 3.6 beta. Si attiva su import nidificati, punti di ingresso mainModule, app solo server, sostituzione di fourseven:scss / meteor/less / coffeescript / jorgenvatle:vite / zodern:melte con loader, pre‑elaborazione Svelte/TypeScript o errori del plugin Lingui SWC dopo l’aggiornamento, interoperabilità CommonJS default‑import, module.exports nei grafici client, built‑in di Node nel codice del browser, _build / build‑assets / build‑chunks, .meteorignore che nasconde i file di handoff, chunk dinamici sotto ROOT_URL, meteor.modules per CSS/HTML, migrazione di resolve.symlinks o resolve.alias, aggiornamenti automatici delle dipendenze e build CI/Docker immutabili. Usa questa skill quando l’utente chiede della compatibilità di migrazione o della sostituzione di un plugin di build con Rspack. Per la configurazione di nuove app e gli helper rspack.config.js, usa invece meteor-modern-build-stack.
