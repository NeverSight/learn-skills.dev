Используйте при подключении аутентификации в приложении Meteor 3. Триггеры по паролю учетной записи, базе учетных записей, OAuth (Google, Facebook, GitHub, Apple, Twitter, Meetup, Weibo), учетным записям-2fa, учетным записям без пароля, ServiceConfiguration.configurations.upsertAsync, Accounts.createUserAsync, Accounts.setPasswordAsync, Accounts.forgotPassword, Accounts.resetPassword, Accounts.verifyEmail, useHttpOnlyCookies, clientStorage, Meteor.loginWithPasswordAnd2faCode, проверка электронной почты. Используйте этот навык, когда пользователь спрашивает о регистрации, входе в систему или о хранении токенов по сравнению с файлами cookie HttpOnly.
