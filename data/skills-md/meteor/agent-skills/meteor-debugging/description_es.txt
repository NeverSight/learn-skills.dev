Úselo al diagnosticar una falla inexplicable en una aplicación Meteor 3 antes de que se conozca la capa defectuosa o la solución. Se desencadenan fallas del servidor, errores solo del cliente, suscripciones bloqueadas, desconexiones de DDP o WebSocket, discrepancias en los datos de Minimongo/servidor, pruebas colgantes o inestables, compilaciones lentas, --inspect, console.log, .only, seguimientos de Playwright o solicitudes para depurar una aplicación Meteor. Utilice esta habilidad cuando la evidencia deba distinguir la herramienta Meteor, el servidor, el cliente, los datos, la prueba, el navegador, el dispositivo móvil o los límites de producción. Para la configuración y creación de pruebas, utilice pruebas de meteoritos; Después de confirmar la causa del dominio, entregue la reparación a la habilidad propietaria.
