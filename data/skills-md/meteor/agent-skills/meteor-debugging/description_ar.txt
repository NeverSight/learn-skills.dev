يُستخدم عند تشخيص فشل غير مبرر في تطبيق Meteor 3 قبل معرفة الطبقة الفاشلة أو الإصلاح. المشغلات عند تعطل الخادم، أو أخطاء العميل فقط، أو الاشتراكات المتوقفة، أو قطع اتصال DDP أو WebSocket، أو عدم تطابق بيانات Minimongo/الخادم، أو الاختبارات المعلقة أو غير المستقرة، أو الإصدارات البطيئة، أو --inspect، أو console.log، أو .only، أو تتبعات Playwright، أو طلبات تصحيح أخطاء تطبيق Meteor. استخدم هذه المهارة عندما يجب أن تميز الأدلة أداة Meteor أو الخادم أو العميل أو البيانات أو الاختبار أو المتصفح أو الهاتف المحمول أو حدود الإنتاج. لإعداد الاختبار والتأليف، استخدم اختبار النيزك؛ بعد التأكد من سبب المجال، قم بتسليم الإصلاح إلى المهارة المالكة.
