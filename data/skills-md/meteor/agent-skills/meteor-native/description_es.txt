Úselo al crear o mantener aplicaciones Meteor 3 para Android/iOS mediante Cordova. Se activa con meteor add-platform, android-device, ios-device, mobile-config.js, complementos de Cordova, firma nativa o artefactos de tienda, y compatibilidad con mobile hot code push. Use esta habilidad cuando la tarea ya involucre el flujo de trabajo de la aplicación Cordova de Meteor; use meteor-debugging para una falla inexplicada de capa cruzada y meteor-deployment para el backend. React Native/Expo, Capacitor y complementos nativos de Node.js son flujos de trabajo separados. Siempre responda en el idioma del usuario.
