استخدم عند بناء أو صيانة تطبيقات Meteor 3 لنظامي Android/iOS عبر Cordova. يُفعَّل عند استعمال meteor add‑platform، android‑device، ios‑device، mobile‑config.js، إضافات Cordova، التوقيع الأصلي أو تخزين القطع، وتوافق الدفع الساخن للرمز على الأجهزة المحمولة. استخدم هذه المهارة عندما تكون المهمة بالفعل متعلقة بسير عمل تطبيق Cordova الخاص بـ Meteor؛ استخدم meteor‑debugging لفشل غير مفسّر عبر الطبقات وmeteor‑deployment للواجهة الخلفية. React Native/Expo، Capacitor، وإضافات Node.js الأصلية هي سيرات عمل منفصلة.  

يرجى دائمًا الرد بلغة المستخدم.
