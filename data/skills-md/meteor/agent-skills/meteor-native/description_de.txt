Verwenden Sie dies beim Erstellen oder Pflegen von Meteor 3 Android/iOS‑Apps über Cordova. Wird ausgelöst bei meteor add‑platform, android‑device, ios‑device, mobile‑config.js, Cordova‑Plugins, nativer Signatur oder Store‑Artefakten sowie bei Mobile‑Hot‑Code‑Push‑Kompatibilität. Nutzen Sie diese Fähigkeit, wenn die Aufgabe bereits den Cordova‑App‑Workflow von Meteor betrifft; verwenden Sie meteor‑debugging für ein unerklärliches Cross‑Layer‑Problem und meteor‑deployment für das Backend. React Native/Expo, Capacitor und native Node.js‑Addons sind separate Workflows.

Bitte immer in der Sprache des Benutzers antworten.
