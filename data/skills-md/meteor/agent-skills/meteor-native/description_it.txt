Usa quando si costruiscono o si mantengono app Meteor 3 per Android/iOS tramite Cordova. Si attiva su meteor add‑platform, android‑device, ios‑device, mobile‑config.js, plugin Cordova, firma nativa o artefatti di store, e compatibilità con mobile hot code push. Usa questa competenza quando il compito riguarda già il flusso di lavoro dell’app Cordova di Meteor; usa meteor‑debugging per un errore cross‑layer inspiegato e meteor‑deployment per il backend. React Native/Expo, Capacitor e gli addon nativi di Node.js sono flussi di lavoro separati.
