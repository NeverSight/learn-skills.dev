Используйте при разработке или поддержке приложений Meteor 3 для Android/iOS через Cordova. Срабатывает при meteor add‑platform, android‑device, ios‑device, mobile‑config.js, плагинах Cordova, нативной подписи или артефактах магазина, а также при совместимости с мобильным «горячим» обновлением кода. Применяйте этот навык, когда задача уже относится к рабочему процессу Cordova‑приложения Meteor; используйте meteor‑debugging для необъяснимого кросс‑уровневого сбоя и meteor‑deployment для бэкенда. React Native/Expo, Capacitor и нативные аддоны Node.js представляют отдельные рабочие процессы.
