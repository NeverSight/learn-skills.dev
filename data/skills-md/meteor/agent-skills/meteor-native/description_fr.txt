Utilisez-le lors de la création ou de la maintenance d’applications Meteor 3 Android/iOS via Cordova. Se déclenche sur meteor add‑platform, android‑device, ios‑device, mobile‑config.js, les plugins Cordova, la signature native ou les artefacts du store, et la compatibilité du mobile hot‑code‑push. Utilisez cette compétence lorsque la tâche concerne déjà le workflow d’application Cordova de Meteor ; utilisez meteor‑debugging pour un échec cross‑layer inexpliqué et meteor‑deployment pour le backend. React Native/Expo, Capacitor et les addons Node.js natifs sont des workflows séparés.

Veuillez toujours répondre dans la langue de l’utilisateur.
