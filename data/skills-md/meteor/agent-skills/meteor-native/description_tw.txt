在使用 Cordova 建置或維護 Meteor 3 Android/iOS 應用程式時使用。  
在 meteor add-platform、android-device、ios-device、mobile-config.js、Cordova 插件、原生簽署或商店產物，以及手機熱更新相容性時觸發。  
當任務已涉及 Meteor 的 Cordova 應用工作流程時使用此技能；若遇到無法說明的跨層失敗，請使用 meteor‑debugging；若需處理後端，請使用 meteor‑deployment。  
React Native/Expo、Capacitor 與原生 Node.js 插件屬於不同的工作流程。  
請始終以使用者的語言回覆。
