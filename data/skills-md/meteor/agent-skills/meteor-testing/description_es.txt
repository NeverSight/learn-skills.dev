Úselo al configurar, diseñar, escribir o reparar pruebas y arneses de prueba en una aplicación Meteor 3. Activadores de meteortesting:mocha, --driver-package, TEST_WATCH, TEST_BROWSER_DRIVER, MOCHA_GREP, meteor.testModule, pruebas enfocadas, .only, Meteor.server.method_handlers, Meteor.server.publish_handlers, DDP.connect, --modo de integración de aplicación completa, sinon, firmas de prueba asíncronas, Playwright/Cypress E2E. Utilice esta habilidad cuando el usuario pregunte sobre corredores de prueba, pregunte sobre publicaciones de prueba o pregunte sobre Jest vs Mocha en Meteor. Para una prueba fallida, bloqueada o inestable cuya capa fallida o causa raíz se desconoce, utilice la depuración de meteoritos antes de cambiar la prueba o la aplicación.
