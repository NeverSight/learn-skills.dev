À utiliser lors de la configuration, de la conception, de l'écriture ou de la réparation de tests et de faisceaux de tests dans une application Meteor 3. Déclencheurs sur meteortesting :mocha, --driver-package, TEST_WATCH, TEST_BROWSER_DRIVER, MOCHA_GREP, meteor.testModule, tests ciblés, .only, Meteor.server.method_handlers, Meteor.server.publish_handlers, DDP.connect, --full-app mode d'intégration, sinon, signatures de test asynchrones, Playwright/Cypress E2E. Utilisez cette compétence lorsque l'utilisateur pose des questions sur les exécuteurs de tests, sur les publications de tests ou sur Jest vs Mocha dans Meteor. Pour un test défaillant, suspendu ou instable dont la couche défaillante ou la cause première est inconnue, utilisez le débogage météore avant de modifier le test ou l'application.
