Da utilizzare durante l'impostazione, la progettazione, la scrittura o la riparazione di test e cablaggi di prova in un'app Meteor 3. Trigger su meteortesting:mocha, --driver-package, TEST_WATCH, TEST_BROWSER_DRIVER, MOCHA_GREP, meteor.testModule, test mirati, .only, Meteor.server.method_handlers, Meteor.server.publish_handlers, DDP.connect, modalità di integrazione --full-app, sinon, firme di test asincrone, Playwright/Cypress E2E. Utilizza questa abilità quando l'utente chiede informazioni sui test runner, sui test delle pubblicazioni o su Jest vs Mocha in Meteor. Per un test non riuscito, sospeso o instabile di cui non si conosce il livello o la causa principale del guasto, utilizzare il debug meteorico prima di modificare il test o l'app.
