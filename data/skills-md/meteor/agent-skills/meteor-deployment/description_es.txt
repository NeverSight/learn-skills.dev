Úselo al implementar una aplicación Meteor 3. Activadores de compilación de meteoritos, implementación de meteoritos, Galaxy Push to Deploy, modo Galaxy, modo de repositorio, DEPLOY_HOSTNAME, Docker, Kubernetes, settings.json, METEOR_SETTINGS, MONGO_URL, MONGO_OPLOG_URL, ROOT_URL, PORT, HTTP_FORWARDED_COUNT, NODE_OPTIONS, comprobaciones de estado, comandos previos a la implementación, inserción de código activo, --architecture os.linux.x86_64, --server-only o una versión implementada de Node.js no coincide. Utilice esta habilidad cuando el usuario pregunte sobre el envío de la aplicación, sobre la configuración de producción o sobre la creación de contenedores.
