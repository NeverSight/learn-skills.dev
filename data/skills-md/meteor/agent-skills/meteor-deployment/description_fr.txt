À utiliser lors du déploiement d'une application Meteor 3. Déclencheurs sur la construction de météore, le déploiement de météore, Galaxy Push to Deploy, Galaxy Mode, Repository Mode, DEPLOY_HOSTNAME, Docker, Kubernetes, settings.json, METEOR_SETTINGS, MONGO_URL, MONGO_OPLOG_URL, ROOT_URL, PORT, HTTP_FORWARDED_COUNT, NODE_OPTIONS, contrôles de santé, commandes de pré-déploiement, push de code chaud, --architecture os.linux.x86_64, --server-only ou une incompatibilité de version déployée de Node.js. Utilisez cette compétence lorsque l'utilisateur pose des questions sur l'expédition de l'application, sur la configuration de production ou sur la conteneurisation.
