Usa quando costruisci o fai il debug di interfacce Blaze in Meteor 3: meteor create --blaze, template Spacebars, helper ed eventi dei Template, hook del ciclo di vita, Tracker, ReactiveVar o ReactiveDict, sottoscrizioni dei template, helper Promise, stati async #let, Template.dynamic, Blaze.render e blaze‑hot HMR con il bundler di Meteor. Usa questa competenza quando l’utente chiede componenti Blaze riutilizzabili, lo scaffold PWA di Blaze, i pacchetti Blaze attuali, gli import di ingresso di Rspack o il testing dei template Blaze.
