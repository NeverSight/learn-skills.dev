在 Meteor 3 中構建或除錯 Blaze 介面時使用：meteor create --blaze、Spacebars 模板、Template 幫助函式與事件、生命週期掛鉤、Tracker、ReactiveVar 或 ReactiveDict、模板訂閱、Promise 幫助函式、#let 非同步狀態、Template.dynamic、Blaze.render，以及使用 Meteor bundler 的 blaze‑hot HMR。當出現過時的非同步幫助函式結果、await 後的反應性遺失、資料上下文查找的意外、HMR 後的 DOM 重複整合、Rspack 完全重新載入，或三重大括號中的原始 HTML 時會觸發。當使用者詢問可重用的 Blaze 元件、Blaze PWA 骨架、目前的 Blaze 套件、Rspack 入口匯入或測試 Blaze 模板時，請使用此技能。從 Meteor 2 升級至 3 時，請改用 migrate-to-meteor-3。
