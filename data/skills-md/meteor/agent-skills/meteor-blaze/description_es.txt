Úsese al crear o depurar interfaces Blaze en Meteor 3: meteor create --blaze, plantillas Spacebars, ayudantes y eventos de Template, ganchos del ciclo de vida, Tracker, ReactiveVar o ReactiveDict, suscripciones de plantilla, ayudantes de Promise, estados async con #let, Template.dynamic, Blaze.render y blaze‑hot HMR con el empaquetador de Meteor. Se activa con resultados obsoletos de ayudantes async, pérdida de reactividad tras await, sorpresas al buscar data‑context, integraciones DOM duplicadas después de HMR, recargas completas de Rspack o HTML sin procesar en triple llaves. Use esta habilidad cuando el usuario pregunte sobre componentes Blaze reutilizables, el scaffold PWA de Blaze, paquetes Blaze actuales, importaciones de entrada de Rspack o pruebas de plantillas Blaze. Para actualizaciones de Meteor 2 a 3, emplee migrate‑to‑meteor‑3.
