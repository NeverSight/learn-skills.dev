Meteor の文書化されたコミュニティ カタログからパッケージを選択、評価、採用、構成、デバッグする場合、またはコミュニティ パッケージからロールなどの昇格されたコア パッケージに移行する場合に使用します。コミュニティ パッケージの推奨事項、Atmosphere と npm の選択、Packosphere メンテナンス チェック、jam:* ヘルパー、Meteor.publish.once、Meteor.publish.stream、meteor-rpc、ワームホール、クラスター、およびメール プレビューをトリガーします。このスキルは、どの保守パッケージが適合するか、またはその文書化された統合がどのように機能するかをユーザーが尋ねたときに使用します。 Meteor 2-to-3 パッケージの失敗を meteor-3 への移行にルーティングし、基礎となるコア API 設計をその所有スキルにルーティングします。
