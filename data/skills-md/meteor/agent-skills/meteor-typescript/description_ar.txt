استخدمه عند إعداد أو إصلاح إعلانات تطبيق Meteor، أو تكوين TypeScript، أو IntelliSense للـ JavaScript، أو الفحص النوعي محليًا وعلى خوادم CI. يُفعَّل عند وجود أنواع meteor، أو استيرادات meteor/* التي تُحل إلى any، أو إعلانات مفقودة، أو معرفات Meteor مكررة، أو zodern:types، أو @types/meteor، أو .meteor/types، أو tsconfig.json، أو jsconfig.json، أو tsc --noEmit في تطبيق Meteor. استخدم هذه المهارة عند اختيار أو ترحيل مزودي الإعلانات دون تغيير وقت تشغيل التطبيق أو أداة التجميع. لترحيل وقت تشغيل من Meteor 2 إلى 3 استخدم migrate-to-meteor-3 أولًا؛ وللتحويل باستخدام SWC/Rspack استخدم meteor-modern-build-stack أو migrate-to-rspack. أسئلة اللغة العامة حول TypeScript ونشر إعلانات Atmosphere خارج نطاق هذا التطبيق.  

يرجى دائمًا الرد بلغة المستخدم.
