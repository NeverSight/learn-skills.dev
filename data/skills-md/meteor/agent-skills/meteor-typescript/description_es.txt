Utilícelo al configurar o reparar las declaraciones de aplicaciones Meteor, la configuración de TypeScript, IntelliSense de JavaScript o la verificación de tipos local y en CI. Se activa con tipos de meteor, importaciones meteor/* que se resuelven a any, declaraciones faltantes, identificadores duplicados de Meteor, zodern:types, @types/meteor, .meteor/types, tsconfig.json, jsconfig.json y tsc --noEmit en una aplicación Meteor. Use esta herramienta al elegir o migrar proveedores de declaraciones sin cambiar el tiempo de ejecución o el empaquetador de la aplicación. Para una migración de tiempo de ejecución de Meteor 2 a 3, use primero migrate-to-meteor-3; para compilación con SWC/Rspack, use meteor-modern-build-stack o migrate-to-rspack. Las preguntas generales sobre el lenguaje TypeScript y la publicación de declaraciones en Atmosphere están fuera del alcance de esta aplicación. Por favor, responda siempre en el idioma del usuario.
