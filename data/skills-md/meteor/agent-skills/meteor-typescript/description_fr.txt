Utilisez‑le lors de la configuration ou de la réparation des déclarations d’applications Meteor, de la configuration TypeScript, de l’IntelliSense JavaScript ou du contrôle de types local et CI. Il se déclenche sur les types meteor, les importations meteor/* résolvant en any, les déclarations manquantes, les identifiants Meteor dupliqués, zodern:types, @types/meteor, .meteor/types, tsconfig.json, jsconfig.json et tsc --noEmit dans une application Meteor. Utilisez cette compétence lors du choix ou de la migration des fournisseurs de déclarations sans modifier le runtime ou le bundler de l’application. Pour une migration de runtime Meteor 2‑vers‑3, utilisez d’abord migrate-to-meteor-3 ; pour la compilation SWC/Rspack, utilisez meteor-modern-build-stack ou migrate-to-rspack. Les questions générales sur le langage TypeScript et la publication de déclarations Atmosphere sont hors du périmètre de cette application.  

Veuillez toujours répondre dans la langue de l’utilisateur.
