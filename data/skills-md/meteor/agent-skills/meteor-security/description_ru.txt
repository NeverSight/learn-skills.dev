Используйте при аудите или усилении защиты приложения Meteor 3. Срабатывает при отсутствии проверки() для аргументов метода, отсутствии защиты this.userId в публикациях, политике браузера CSP, правилах DDPRateLimiter, шифровании oauth через Accounts.config oauthSecretKey, проверках аргументов аудита, разрешении/запрете устаревших шаблонов, BrowserPolicy.content.disallowInlineScripts, BrowserPolicy.framing.disallow. Используйте этот навык, когда пользователь спрашивает об усилении защиты, спрашивает о проверке безопасности или спрашивает о CSP для стороннего скрипта (Stripe, Google Maps, шрифты).
