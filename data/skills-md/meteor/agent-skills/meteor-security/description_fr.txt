À utiliser lors de l'audit ou du renforcement d'une application Meteor 3. Déclencheurs en cas de check() manquant sur les arguments de méthode, de protections this.userId manquantes sur les publications, de politique de navigateur CSP, de règles DDPRateLimiter, de cryptage oauth via Accounts.config oauthSecretKey, de vérifications d'arguments d'audit, d'autoriser/refuser les modèles hérités, BrowserPolicy.content.disallowInlineScripts, BrowserPolicy.framing.disallow. Utilisez cette compétence lorsque l'utilisateur pose des questions sur le renforcement, sur un examen de sécurité ou sur CSP pour un script tiers (Stripe, Google Maps, polices).
