Usa quando installi, localizzi, ripari, resetti o disinstalli il CLI di Meteor per lo sviluppo con Meteor 3. Si attiva su “meteor: command not found”, npx meteor, errori dell’installer, problemi di PATH, versioni specifiche di Meteor, richieste di reinstallazione pulita, meteor reset o bundle di sviluppo corrotti. Utilizza questa competenza quando l’utente chiede di configurare una nuova workstation o di rendere disponibile un comando Meteor locale. Per i fallimenti dell’applicazione dopo l’avvio del CLI, usa meteor‑debugging; per gli aggiornamenti del codice dell’applicazione, usa migrate‑to‑meteor‑3.

Per favore rispondi sempre nella lingua dell’utente.
