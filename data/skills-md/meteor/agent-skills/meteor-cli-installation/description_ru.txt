Используйте при установке, поиске, исправлении, сбросе или удалении Meteor CLI для разработки Meteor 3. Срабатывает при «meteor: command not found», npx meteor, ошибках установщика, проблемах с PATH, конкретных версиях Meteor, запросах на чистую переустановку, meteor reset или повреждённых пакетах разработки. Применяйте этот навык, когда пользователь спрашивает о настройке новой рабочей станции или о том, как сделать доступной локальную команду Meteor. Для сбоев приложения после запуска CLI используйте meteor‑debugging; для обновления кода приложения — migrate‑to‑meteor‑3.

Всегда отвечайте на языке пользователя.
