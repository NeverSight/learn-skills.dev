Utilícelo al instalar, localizar, reparar, restablecer o desinstalar el CLI de Meteor para el desarrollo de Meteor 3. Se activa con “meteor: command not found”, npx meteor, fallas del instalador, problemas de PATH, versiones específicas de Meteor, solicitudes de reinstalación limpia, meteor reset o paquetes de desarrollo corruptos. Use esta habilidad cuando el usuario pregunte sobre la configuración de una nueva estación de trabajo o cómo disponer de un comando local de Meteor. Para fallas de la aplicación después de que arranque el CLI, use meteor‑debugging; para actualizaciones del código de la aplicación, use migrate‑to‑meteor‑3.

Por favor, responda siempre en el idioma del usuario.
