以下の用途で使用してください：Meteor 3 開発用の Meteor CLI のインストール、場所の特定、修復、リセット、またはアンインストール時。「meteor: command not found」や npx meteor、インストーラの失敗、PATH の問題、特定の Meteor バージョン、クリーンな再インストール要求、meteor reset、または破損した dev バンドルがトリガーとなります。ユーザーが新しいワークステーションのセットアップやローカルの Meteor コマンドを利用可能にする質問をしたときにこのスキルを使用してください。CLI 起動後のアプリケーションの失敗については meteor‑debugging を、アプリケーションコードのアップグレードについては migrate‑to‑meteor‑3 を使用してください。

常にユーザーの言語で回答してください。
