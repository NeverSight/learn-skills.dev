Verwenden Sie dies beim Installieren, Auffinden, Reparieren, Zurücksetzen oder Deinstallieren des Meteor‑CLI für die Meteor 3‑Entwicklung. Ausgelöst wird es bei „meteor: command not found“, npx meteor, Installationsfehlern, PATH‑Problemen, bestimmten Meteor‑Versionen, Anfragen für eine saubere Neuinstallation, meteor reset oder beschädigten Entwicklungsbündeln. Nutzen Sie diese Fähigkeit, wenn der Benutzer nach einer frischen Workstation‑Einrichtung fragt oder den lokalen Meteor‑Befehl verfügbar machen möchte. Bei Anwendungsfehlern nach dem Start des CLI verwenden Sie meteor‑debugging; für Code‑Upgrades der Anwendung verwenden Sie migrate‑to‑meteor‑3.
