استخدم هذا عند تثبيت أو تحديد موقع أو إصلاح أو إعادة ضبط أو إلغاء تثبيت CLI الخاص بـ Meteor لتطوير Meteor 3. يُستدعى عند ظهور "meteor: command not found"، أو npx meteor، أو فشل المُثبت، أو مشاكل PATH، أو إصدارات معينة من Meteor، أو طلبات إعادة تثبيت نظيفة، أو meteor reset، أو حزم تطوير تالفة. استخدم هذه المهارة عندما يسأل المستخدم عن إعداد محطة عمل جديدة أو جعل أمر Meteor المحلي متاحًا. بالنسبة لفشل التطبيق بعد بدء تشغيل CLI، استخدم meteor‑debugging؛ بالنسبة لترقيات شفرة التطبيق، استخدم migrate‑to‑meteor‑3.

يرجى دائمًا الرد بلغة المستخدم.
