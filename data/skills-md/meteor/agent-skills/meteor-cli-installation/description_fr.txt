À utiliser lors de l'installation, la localisation, la réparation, la réinitialisation ou la désinstallation du CLI Meteor pour le développement Meteor 3. Se déclenche sur « meteor : commande introuvable », npx meteor, échecs d'installation, problèmes de PATH, versions spécifiques de Meteor, demandes de réinstallation propre, meteor reset ou bundles de développement corrompus. Utilisez cette compétence lorsque l'utilisateur demande une configuration d’ordinateur neuve ou la mise à disposition d’une commande Meteor locale. Pour les échecs d’application après le démarrage du CLI, utilisez meteor‑debugging ; pour les mises à jour du code d’application, utilisez migrate‑to‑meteor‑3.

Veuillez toujours répondre dans la langue de l’utilisateur.
