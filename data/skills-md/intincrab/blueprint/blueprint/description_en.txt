Make animated explainers drawn like a Victorian patent sheet on blueprint paper. A mechanism is built part by part, each numbered with a leader line, each added because the last one fell short ("but… so…"), while tokens travel along lines and a one-line caption tells the story. Output is a `<blueprint-scene>` element (or a standalone HTML page) with play, step and replay controls. Use when the user asks for a blueprint or patent-drawing explainer, an animated diagram of how a system, algorithm or process works, a "how X works" scene for docs, a README, a blog post or a talk, an explainer of an incident or postmortem, an explainer as a GIF, video, image or slides, or types /blueprint [topic].
