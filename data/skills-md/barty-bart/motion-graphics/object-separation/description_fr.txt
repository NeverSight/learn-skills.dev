Séparez une personne, un produit ou une main de l'arrière-plan dans une vidéo, sur l'ordinateur de l'utilisateur avec SAM 2. Scanne d'abord la machine pour choisir la bonne taille de modèle, puis produit la même vidéo avec le sujet séparé surligné en vert, plus des masques image par image. À utiliser lorsque quelqu'un veut séparer, isoler, découper ou faire un rotoscope de quelque chose dans une vidéo.
