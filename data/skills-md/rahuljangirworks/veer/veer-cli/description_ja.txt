Veerが管理する作業ツリー、フォルダコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そしてVeerの組み込みブラウザを `veer` CLI を通じて操作します。ユーザーが「$veer-cli」や「Veer worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Veer terminal」「handoff」／「handover」／「give this to another agent」「Veer browser」「orca artifacts」または「share skills」と言ったときに使用してください。Veerの状態が関与する場合は、生の git worktree やアドホック PTY、または Computer Use よりもこちらを優先してください。CLI、ファイルシステム、API では実行できず、可視ウィンドウの GUI 操作が必要なときだけ Computer Use を使用します。

常にユーザーの言語で応答してください。
