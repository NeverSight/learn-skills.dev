Manipulez les worktrees gérés par Veer, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré de Veer via la CLI `veer`. Utilisez-le lorsque l'utilisateur dit « $veer-cli », « Veer worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Veer terminal », « handoff » / « handover » / « give this to another agent », « Veer browser », « orca artifacts » ou « share skills ». Préférez-le aux worktrees git bruts, PTY ad hoc ou à l’Utilisation de l’Ordinateur lorsque l’état de Veer est impliqué. N’utilisez l’Utilisation de l’Ordinateur que lorsqu’une fenêtre visible nécessite un contrôle GUI qu’une CLI, le système de fichiers ou une API ne peuvent assurer.
