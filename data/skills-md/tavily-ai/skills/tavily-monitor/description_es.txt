Construye una búsqueda o extracción en Tavily que se ejecute con una cadencia, con una línea base guardada. Los monitores de búsqueda establecen max_age_hours al intervalo para que no se devuelva una copia en caché anterior. Úsalo cuando el usuario quiera monitorear, rastrear, observar o recibir una alerta cuando algo cambie, o solicite una verificación recurrente de una consulta o una página. Para un informe profundo y exhaustivo usa tavily-research. Para una búsqueda puntual usa tavily-search. Para una tabla puntual usa tavily-list.

Por favor, responde siempre en el idioma del usuario.
