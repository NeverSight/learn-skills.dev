Construye una tabla deduplicada de coincidencias para un conjunto, usando Tavily. La tabla muestra lo que devolvió la búsqueda, no todas las coincidencias que existen. Úsala cuando el usuario quiera una lista, todo de algo o una tabla con duplicados eliminados. Confirma las columnas y un límite antes de buscar. Para un registro de CRM, o un CSV de filas que ya tengan, usa tavily-entity. Para un informe profundo y completo usa tavily-research.
