Erstelle eine deduplizierte Tabelle von Übereinstimmungen für ein Set, mit Tavily. Die Tabelle enthält das, was die Suche zurückgegeben hat, nicht jede mögliche Übereinstimmung. Verwende sie, wenn der Benutzer eine Liste, alles von etwas oder eine Tabelle ohne Duplikate möchte. Bestätige die Spalten und ein Limit, bevor du suchst. Für einen einzelnen CRM‑Datensatz oder eine CSV von bereits vorhandenen Zeilen, verwende tavily‑entity. Für einen tiefgehenden, umfassenden Bericht verwende tavily‑research.
