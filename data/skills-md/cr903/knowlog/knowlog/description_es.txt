ZhiLu (knowlog) – para un proyecto de establecer o mantener un “sistema de documentación de desarrollo” – registros de tareas (diarios), base de conocimientos estructurada (knowledge), contexto de dominio (domain context), índice de dos niveles (segment + root), recuperación por palabras clave (.keyword‑map) e inyección de restricciones AGENTS.md; y permite que el agente registre automáticamente los logs, destile conocimientos y ejecute el control de acceso al índice al cerrar una tarea. Se usa cuando el usuario quiere configurar un sistema de documentación para un nuevo proyecto/repositorio, estandarizar los registros de desarrollo, crear una base de conocimientos, organizar el directorio docs, inyectar restricciones de contexto AGENTS.md/CLAUDE.md, o dice “ayúdame a registrar un log cuando esta tarea esté terminada”, “destila los errores de esto”, “registra este cambio en la base de conocimientos”, “la documentación está muy desordenada, ayúdame a organizarla”, “el índice no coincide”. También se emplea para verificaciones de salud/reparación de sistemas existentes (índices faltantes, enlaces rotos, logs dispersos, rutas no estándar). Usa esta habilidad siempre que el usuario quiera configurar o mantener un sistema de documentación del proyecto (logs de dev / base de conocimientos / contexto de dominio / índices de documentos / recuperación de contexto basada en palabras clave), registrar un registro de trabajo después de terminar una tarea, o destilar lecciones en una base de conocimientos. Por favor, responde siempre en el idioma del usuario.
