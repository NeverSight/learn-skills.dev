知录（knowlog）—— 为一项目建立或维护「开发文档体系」——任务日志(daily)、结构化知识库(knowledge)、领域上下文(domain context)、两级索引(分端+根)、关键词召回(.keyword-map)与 AGENTS.md 约束注入；并让 agent 在任务收尾时自动记录日志、沉淀知识、跑索引门禁。当用户要给新项目/新仓库搭文档体系、规范开发日志、建知识库、整理 docs 目录、注入 AGENTS.md/CLAUDE.md 上下文约束，或说"这个任务做完了帮我记一下日志""沉淀一下这次的坑""把这次改动记进知识库""文档太乱了帮我整理""索引对不上"时使用。也用于体检/修复已有体系（索引缺失、死链、日志散落、路径不规范）。Use this skill whenever the user wants to set up or maintain a project documentation system (dev logs / knowledge base / domain context / doc indexes / keyword-based context recall), record a work log after finishing a task, or distill lessons into a knowledge base.
