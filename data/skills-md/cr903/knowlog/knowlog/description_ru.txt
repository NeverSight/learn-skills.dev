ZhiLu (knowlog) — для проекта по созданию или поддержанию «системы документирования разработки» — ежедневные журналы задач, структурированная база знаний, контекст домена, двухуровневый индекс (segment + root), вспоминание по ключевым словам (.keyword‑map) и внедрение ограничений AGENTS.md; позволяет агенту автоматически записывать журналы, извлекать знания и управлять доступом к индексу при завершении задачи.  
Используется, когда пользователь хочет настроить систему документирования для нового проекта/репозитория, стандартизировать журналы разработки, построить базу знаний, организовать каталог docs, внедрить контекстные ограничения AGENTS.md/CLAUDE.md, либо говорит: «помоги мне записать журнал, когда эта задача будет завершена», «выдели из этого ошибки», «запиши это изменение в базу знаний», «документация слишком хаотична, помоги её организовать», «индекс не совпадает».  
Также используется для проверок состояния/ремонта существующих систем (отсутствующие индексы, мёртвые ссылки, разбросанные журналы, нестандартные пути).  
Применяйте эту функцию каждый раз, когда пользователь хочет создать или поддерживать систему документирования проекта (журналы разработки / база знаний / контекст домена / индексы документации / вспоминание контекста по ключевым словам), записать рабочий журнал после завершения задачи или извлечь уроки в базу знаний.
