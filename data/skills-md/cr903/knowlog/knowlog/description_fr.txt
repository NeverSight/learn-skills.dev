ZhiLu (knowlog) – pour un projet visant à établir ou à maintenir un « système de documentation de développement » – journaux de tâches (quotidiens), base de connaissances structurée (knowledge), contexte de domaine (domain context), index à deux niveaux (segment + root), rappel par mot‑clé (.keyword‑map) et injection de contraintes AGENTS.md ; et laisser l’agent enregistrer automatiquement les journaux, distiller les connaissances et gérer le contrôle d’accès à l’index lors de la clôture d’une tâche. Utilisé lorsque l’utilisateur souhaite mettre en place un système de documentation pour un nouveau projet/dépôt, standardiser les journaux de développement, créer une base de connaissances, organiser le répertoire docs, injecter les contraintes contextuelles AGENTS.md/CLAUDE.md, ou dit « aidez‑moi à enregistrer un journal quand cette tâche est terminée », « distillez les pièges de ceci », « enregistrez ce changement dans la base de connaissances », « la documentation est trop désordonnée, aidez‑moi à l’organiser », « l’index ne correspond pas ». Utilisé également pour les contrôles de santé/réparations des systèmes existants (index manquants, liens morts, journaux dispersés, chemins non standard). Utilisez cette compétence chaque fois que l’utilisateur veut mettre en place ou entretenir un système de documentation de projet (journaux de dev / base de connaissances / contexte de domaine / index de documentation / rappel contextuel basé sur des mots‑clés), enregistrer un journal de travail après avoir terminé une tâche, ou distiller les leçons dans une base de connaissances.
