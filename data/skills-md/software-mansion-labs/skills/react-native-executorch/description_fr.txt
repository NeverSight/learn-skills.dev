Créez des applications natives React avec React-native-executorch : utilisez des modèles d'IA et des crochets de tâches pré-exportés, intégrez des modèles ExecuTorch .pte personnalisés ou créez des pipelines d'inférence TypeScript à partir de contrats modèles PyTorch. Utiliser pour la configuration, la sélection de modèles, l'inférence, l'intégration d'exportation et le dépannage ; les flux de travail de contribution de référentiel utilisent les compétences internes de la bibliothèque.
