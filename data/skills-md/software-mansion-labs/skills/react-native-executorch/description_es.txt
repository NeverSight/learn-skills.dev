Construye aplicaciones React Native con react-native-executorch: utiliza modelos de IA preexportados y hooks de tareas, integra modelos personalizados ExecuTorch .pte, o crea pipelines de inferencia en TypeScript a partir de contratos de modelos PyTorch. Úsalo para configuración, selección de modelos, inferencia, integración de exportaciones y resolución de problemas; los flujos de trabajo de contribución al repositorio utilizan las habilidades internas de la biblioteca.
