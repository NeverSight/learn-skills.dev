ابنِ تطبيقات React Native باستخدام react-native-executorch: استخدم النماذج الذكية المصدَّرة مسبقًا وخطافات المهام، دمج نماذج ExecuTorch ‎.pte المخصصة، أو أنشئ خطوط أنابيب استدلال TypeScript من عقود نماذج PyTorch. استخدمه لإعداد، اختيار النماذج، الاستدلال، دمج التصدير وحل المشكلات؛ وتدفقات عمل مساهمة المستودع تستفيد من المهارات الداخلية للمكتبة.
