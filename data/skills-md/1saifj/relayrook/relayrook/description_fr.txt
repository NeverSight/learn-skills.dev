Déléguer la mise en œuvre, l'examen du code ou l'examen de la sécurité à un autre agent de codage installé localement (Devin, Kiro, OpenCode, Claude Code, Codex) par le biais d'une session structurée persistante. À utiliser lorsque l'utilisateur demande de confier le travail à un autre agent ou modèle, souhaite un réviseur indépendant, nomme une CLI ou un abonnement spécifique, ou souhaite poursuivre, diriger ou annuler le travail délégué. Ne pas utiliser pour expliquer ce qu'est un agent ou un protocole, ou pour une modification que vous pouvez faire vous-même.
