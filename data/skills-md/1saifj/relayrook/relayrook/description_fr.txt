Déleguer la mise en œuvre, la revue de code ou la revue de sécurité à un autre agent de codage installé localement (Devin, Kiro, OpenCode, Claude Code, Codex) via une session structurée persistante. Utilisez-le lorsque l'utilisateur demande de confier le travail à un autre agent ou modèle, souhaite un relecteur indépendant, mentionne un CLI ou un abonnement spécifique, ou veut continuer, orienter ou annuler le travail délégué. Ne l'utilisez pas pour expliquer ce qu'est un agent ou un protocole, ou pour une modification que vous pouvez faire vous-même.

Veuillez toujours répondre dans la langue de l'utilisateur.
