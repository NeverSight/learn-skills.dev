Delegieren Sie die Implementierung, Codeüberprüfung oder Sicherheitsüberprüfung über eine persistente strukturierte Sitzung an einen anderen lokal installierten Codierungsagenten (Devin, Kiro, OpenCode, Claude Code, Codex). Wird verwendet, wenn der Benutzer darum bittet, die Arbeit einem anderen Agenten oder Modell zu übergeben, einen unabhängigen Prüfer wünscht, eine bestimmte CLI oder ein bestimmtes Abonnement benennt oder die delegierte Arbeit fortsetzen, steuern oder stornieren möchte. Verwenden Sie es nicht, um zu erklären, was ein Agent oder ein Protokoll ist, oder für eine Bearbeitung, die Sie selbst vornehmen können.
