مراجعة وتدقيق وصياغة الوثائق المتعلقة بالامتثال للخصوصية وحماية البيانات عبر جميع الولايات القضائية - قانون الخصوصية الأسترالي لعام 1988 ومبادئه الـ13 للخصوصية الأسترالية، ولائحة حماية البيانات العامة للاتحاد الأوروبي (GDPR)، وقانون الذكاء الاصطناعي للاتحاد الأوروبي، وقانون البيانات للاتحاد الأوروبي، وقانون خصوصية المستهلك في كاليفورنيا (CCPA) ولوائحه التنفيذية. يُستَخدم عند التعامل مع البيانات الشخصية أو الحساسة، أو عند تصميم جمعها وتخزينها ومشاركتها واحتفاظها أو حذفها؛ أو تدقيق المتطلبات أو التصاميم أو الشيفرة أو الوثائق في أي مرحلة من دورة الحياة؛ أو إنشاء سياسات الخصوصية أو الإشعارات أو تدفقات الموافقة؛ أو تقييم عمليات النقل عبر الحدود؛ أو التخطيط للتعامل مع خروقات البيانات أو الاستجابة لها؛ أو مراجعة ميزات الذكاء الاصطناعي أو المنتجات المتصلة أو تقنيات الإعلان أو خدمات السحابة. ينتج عن ذلك ملاحظات أو تقارير تدقيق أو مسودات سياسات تُشير إلى القسم أو المادة أو الفقرة ذات الصلة في القوانين أو المبادئ المذكورة.
