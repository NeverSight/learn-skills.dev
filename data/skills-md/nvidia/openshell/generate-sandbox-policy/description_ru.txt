Создавайте политики безопасности песочницы из требований на естественном языке и при необходимости из документации REST API. Генерирует сетевые политики уровня L4 или детализированные политики уровня L7 и упорядоченную конфигурацию сетевого промежуточного программного обеспечения. Используйте для правил доступа к API, выбора хоста промежуточного программного обеспечения, поведения при сбоях или прикрепления встроенного и оператором управляемого промежуточного программного обеспечения. Ключевые слова‑триггеры — generate policy, create policy, update policy, change policy, sandbox policy, network policy, API policy, security policy, allow API, restrict API, network middleware, supervisor middleware.
