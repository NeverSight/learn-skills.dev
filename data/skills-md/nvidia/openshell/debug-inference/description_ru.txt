Отладка клиентов инференса, использующих подключённого провайдера и его собственный эндпоинт, включая размещённые API и локальные на хосте Ollama, vLLM, SGLang, TRT‑LLM, LM Studio или NIM. Используется для привязки провайдера, политики эндпоинтов, подстановки учётных данных, топологии и миграции с удалённого управляемого эндпоинта инференса. Ключевые слова‑триггеры — debug inference, managed inference endpoint, local inference, ollama, lm studio, vllm, sglang, trtllm, NIM, inference failing, model server unreachable, credential_endpoint_mismatch, host.openshell.internal.
