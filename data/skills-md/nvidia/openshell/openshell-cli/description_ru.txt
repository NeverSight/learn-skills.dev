Проведите агентов через использование CLI OpenShell (openshell) для управления песочницей, регистрации шлюза, настройки и обновления провайдера, управления профилями, итерации политик, настроек, экспозиции сервисов, рабочих процессов BYOC и вывода привязанного провайдера. Охватывает базовые и продвинутые многошаговые рабочие процессы. Ключевые слова‑триггеры — openshell, sandbox create, sandbox exec, sandbox connect, logs, provider create, profile list, profile describe, provider refresh, policy set, policy get, settings, service expose, forward, port forward, BYOC, bring your own container, inference, use openshell, run openshell, CLI usage, manage sandbox, manage provider, gateway add, gateway select.
