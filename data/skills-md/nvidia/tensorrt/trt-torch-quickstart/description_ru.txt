Соберите модель PyTorch в движок TensorRT с помощью Torch‑TensorRT — AOT или JIT — используя новый режим строгой типизации по умолчанию. Применяется, когда пользователь компилирует PyTorch в TensorRT без ONNX, сталкивается с ошибкой «enabled_precisions should not be used when use_explicit_typing=True», наблюдает разрывы графа Dynamo или откат к PyTorch, отлаживает ошибки ABI при импорте torch_tensorrt, или нуждается в совместимых версиях torch / torch_tensorrt / tensorrt‑cu13 для TensorRT 11. Триггеры: torch_tensorrt, torch_tensorrt.dynamo.compile, backend torch.compile = torch_tensorrt, pytorch в tensorrt, ExportedProgram, разрыв графа Dynamo, use_explicit_typing, enabled_precisions, torch_tensorrt.Input, min_block_size, truncate_double, tensorrt‑cu13, закрепление версии, совместимость версий. Смежные навыки: `trt-onnx-quickstart`, `trt-cpp-runtime-quickstart`. Генерация токенов LLM относится к TensorRT‑LLM.
