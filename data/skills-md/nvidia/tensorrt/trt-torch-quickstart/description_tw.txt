將 PyTorch 模型編譯成 TensorRT 引擎，透過 Torch‑TensorRT — AOT 或 JIT — 並使用全新的強型別預設。適用於使用者在未使用 ONNX 的情況下將 PyTorch 編譯成 TensorRT，遇到「enabled_precisions 應在 use_explicit_typing=True 時不使用」的錯誤、看到 Dynamo 圖形中斷或 PyTorch 回退、在 import torch_tensorrt 時除錯 ABI 錯誤，或需要相容的 torch / torch_tensorrt / tensorrt‑cu13 版本釘選以配合 TensorRT 11。觸發條件：torch_tensorrt、torch_tensorrt.dynamo.compile、torch.compile 後端 torch_tensorrt、pytorch to tensorrt、ExportedProgram、Dynamo 圖形中斷、use_explicit_typing、enabled_precisions、torch_tensorrt.Input、min_block_size、truncate_double、tensorrt‑cu13、版本釘選、版本相容性。相關技能：`trt-onnx-quickstart`、`trt-cpp-runtime-quickstart`。LLM token 生成屬於 TensorRT‑LLM。
