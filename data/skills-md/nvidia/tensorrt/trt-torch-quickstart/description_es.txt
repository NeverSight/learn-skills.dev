Compila un modelo de PyTorch a un motor TensorRT mediante Torch‑TensorRT — AOT o JIT — bajo la nueva configuración predeterminada de tipado fuerte. Úsalo cuando el usuario compile PyTorch a TensorRT sin ONNX, encuentre el error “enabled_precisions should not be used when use_explicit_typing=True”, vea rupturas del grafo Dynamo o un fallback de PyTorch, depure errores ABI al importar torch_tensorrt, o necesite los pins de versión compatibles de torch / torch_tensorrt / tensorrt‑cu13 para TensorRT 11. Activadores: torch_tensorrt, torch_tensorrt.dynamo.compile, backend torch.compile torch_tensorrt, pytorch a tensorrt, ExportedProgram, ruptura del grafo Dynamo, use_explicit_typing, enabled_precisions, torch_tensorrt.Input, min_block_size, truncate_double, tensorrt‑cu13, fijación de versiones, compatibilidad de versiones. Habilidades adyacentes: `trt-onnx-quickstart`, `trt-cpp-runtime-quickstart`. La generación de tokens LLM pertenece a TensorRT‑LLM.
