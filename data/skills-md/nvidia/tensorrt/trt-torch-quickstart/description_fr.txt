Compilez un modèle PyTorch en un moteur TensorRT via Torch‑TensorRT — AOT ou JIT — avec le nouveau réglage de typage fort par défaut. Utilisez‑le lorsque l’utilisateur compile PyTorch vers TensorRT sans ONNX, rencontre l’erreur « enabled_precisions should not be used when use_explicit_typing=True », constate des ruptures du graphe Dynamo ou un fallback PyTorch, débogue des erreurs ABI lors de l’import de torch_tensorrt, ou a besoin des versions compatibles torch / torch_tensorrt / tensorrt‑cu13 pour TensorRT 11. Déclencheurs : torch_tensorrt, torch_tensorrt.dynamo.compile, backend torch.compile torch_tensorrt, pytorch vers tensorrt, ExportedProgram, rupture du graphe Dynamo, use_explicit_typing, enabled_precisions, torch_tensorrt.Input, min_block_size, truncate_double, tensorrt‑cu13, épinglage de version, compatibilité de version. Compétences adjacentes : `trt-onnx-quickstart`, `trt-cpp-runtime-quickstart`. La génération de tokens LLM appartient à TensorRT‑LLM.
