Compila un modello PyTorch in un motore TensorRT tramite Torch‑TensorRT — AOT o JIT — con il nuovo valore predefinito di tipizzazione forte. Usalo quando l’utente compila PyTorch in TensorRT senza ONNX, incontra l’errore “enabled_precisions should not be used when use_explicit_typing=True”, osserva interruzioni del grafo Dynamo o fallback di PyTorch, esegue il debug di errori ABI all’importazione di torch_tensorrt, o necessita dei pin di versione compatibili per torch / torch_tensorrt / tensorrt‑cu13 per TensorRT 11.  
Trigger: torch_tensorrt, torch_tensorrt.dynamo.compile, backend torch.compile torch_tensorrt, pytorch to tensorrt, ExportedProgram, interruzione del grafo Dynamo, use_explicit_typing, enabled_precisions, torch_tensorrt.Input, min_block_size, truncate_double, tensorrt‑cu13, vincolo di versione, compatibilità di versione.  
Competenze adiacenti: `trt-onnx-quickstart`, `trt-cpp-runtime-quickstart`.  
La generazione di token LLM appartiene a TensorRT‑LLM.
