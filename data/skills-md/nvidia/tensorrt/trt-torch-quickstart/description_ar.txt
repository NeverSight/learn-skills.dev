قم بتجميع نموذج PyTorch إلى محرك TensorRT عبر Torch‑TensorRT — AOT أو JIT — تحت الإعداد الافتراضي الجديد للكتابة القوية. استخدمه عندما يقوم المستخدم بتجميع PyTorch إلى TensorRT دون ONNX، ويصادف الخطأ "enabled_precisions should not be used when use_explicit_typing=True"، أو يرى انكسارات في رسم بياني Dynamo أو fallback في PyTorch، أو يdebug أخطاء ABI عند استيراد torch_tensorrt، أو يحتاج إلى إصدارات متوافقة من torch / torch_tensorrt / tensorrt‑cu13 ل TensorRT 11. المشغلات: torch_tensorrt، torch_tensorrt.dynamo.compile، backend torch.compile torch_tensorrt، pytorch إلى tensorrt، ExportedProgram، انكسار رسم Dynamo، use_explicit_typing، enabled_precisions، torch_tensorrt.Input، min_block_size، truncate_double، tensorrt‑cu13، تثبيت الإصدارات، توافق الإصدارات. المهارات المجاورة: `trt-onnx-quickstart`، `trt-cpp-runtime-quickstart`. توليد رموز LLM يندرج تحت TensorRT‑LLM.
