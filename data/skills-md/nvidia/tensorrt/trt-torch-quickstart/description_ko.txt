새로운 강력한 타입 지정 기본 설정 하에서 Torch‑TensorRT를 사용하여 PyTorch 모델을 TensorRT 엔진으로 컴파일합니다 — AOT 또는 JIT —. 사용 사례: 사용자가 ONNX 없이 PyTorch를 TensorRT로 컴파일하고, “enabled_precisions should not be used when use_explicit_typing=True” 오류가 발생하거나, Dynamo 그래프가 중단되거나 PyTorch fallback이 발생하고, import torch_tensorrt 시 ABI 오류를 디버깅하거나, TensorRT 11에 맞는 호환되는 torch / torch_tensorrt / tensorrt‑cu13 버전 고정을 필요로 할 때. 트리거: torch_tensorrt, torch_tensorrt.dynamo.compile, torch.compile 백엔드 torch_tensorrt, pytorch to tensorrt, ExportedProgram, Dynamo 그래프 중단, use_explicit_typing, enabled_precisions, torch_tensorrt.Input, min_block_size, truncate_double, tensorrt‑cu13, 버전 고정, 버전 호환성. 관련 스킬: `trt-onnx-quickstart`, `trt-cpp-runtime-quickstart`. LLM 토큰 생성은 TensorRT‑LLM에 포함됩니다.
