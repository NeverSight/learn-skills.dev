使用 NVIDIA Compute Sanitizer 检测和诊断 CUDA 正确性错误。将 GPU 内存错误、共享内存数据竞争、未初始化内存读取以及同步/屏障错误路由到相应的子工具（memcheck、racecheck、initcheck、synccheck），并说明如何构建、运行以及阅读报告。调试非法内存访问、越界、未对齐访问、泄漏、WAW/WAR/RAW 竞争、__shared__ 危险、未初始化读取、垃圾结果、卡死、发散的 __syncthreads/__syncwarp，或 cuda::barrier / wgmma 问题时使用。不要用于主机/CPU 端错误（请使用 valgrind 或 AddressSanitizer）或全局内存数据竞争（超出范围）。触发关键词 - compute-sanitizer、memcheck、racecheck、initcheck、synccheck、CUDA 内存错误、OOB、竞争条件、未初始化内存、__syncthreads、屏障、死锁。
