使用 NVIDIA Compute Sanitizer 偵測與診斷 CUDA 正確性錯誤。將 GPU 記憶體錯誤、共享記憶體資料競爭、未初始化記憶體讀取以及同步/屏障錯誤導向正確的子工具（memcheck、racecheck、initcheck、synccheck），並說明如何編譯、執行與閱讀報告。適用於除錯非法記憶體存取、越界、未對齊存取、記憶體洩漏、WAW/WAR/RAW 競爭、__shared__ 危險、未初始化讀取、垃圾結果、程式掛起、分岔的 __syncthreads/__syncwarp，或 cuda::barrier / wgmma 問題。**請勿**將其用於主機/CPU 端的錯誤（請使用 valgrind 或 AddressSanitizer）或全域記憶體資料競爭（超出範圍）。觸發關鍵字 - compute-sanitizer、memcheck、racecheck、initcheck、synccheck、CUDA memory error、OOB、race condition、uninitialized memory、__syncthreads、barrier、deadlock。
