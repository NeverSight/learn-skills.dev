Калибруйте новый набор данных из живых потоков RTSP‑камер через REST API AutoMagicCalib. Используйте, когда пользователь предоставляет URL‑адреса RTSP или просит откалибровать живые камеры; VIOS записывает клипы, AMC их принимает, а затем выполняет калибровку. Пожалуйста, всегда отвечайте на языке пользователя.
