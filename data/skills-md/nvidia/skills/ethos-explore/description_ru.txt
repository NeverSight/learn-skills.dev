Фиксирует, что должен делать AI‑агент — его цель, границы и критерии успеха — в виде надёжного снимка для любого, кто будет его создавать, оценивать, проверять или менять. Сначала исследует кодовую базу и документацию пользователя, затем задаёт по одному вопросу о намерении для того, чего источник не может предоставить. Передаёт свои ответы в ethos‑write, который создаёт файл ethos.md. Предпочтительно использовать вместо общего мозгового штурма, когда цель — создать ethos.md агента.
