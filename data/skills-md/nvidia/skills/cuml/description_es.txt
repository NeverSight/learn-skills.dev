Utilice al escribir, ejecutar, depurar o actualizar código Python que use NVIDIA cuML (aprendizaje automático en GPU), cuml.accel (aceleración en GPU sin cambios de código de scikit-learn, umap-learn y hdbscan) o GPU UMAP/HDBSCAN/RandomForest/KMeans/SVC, incluso a través de bibliotecas que envuelven cuML (BERTopic, rapids-singlecell). Cubre APIs eliminadas o renombradas en las versiones 2025‑2026, verifica que el código realmente se ejecutó en la GPU, recetas de memoria para UMAP/HDBSCAN con grandes volúmenes de datos y la exportación de modelos entrenados. No es para trabajo con dataframes solo cuDF, PyTorch o XGBoost.
