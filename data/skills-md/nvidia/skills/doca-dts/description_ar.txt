نشر وتكوين خدمة NVIDIA DOCA Telemetry (DTS) كما يتم تشغيلها فعليًا: (أ) BlueField (بود ثابت مدمج)، (ب) المضيف (docker) على x86_64 / aarch64، أو (ج) DPF (DPUService / مخطط helm) — بالإضافة إلى طبقة التكوين المشتركة (`dts_config.ini`، الموفرين، المصدِّرين، تسميات المستوى) التي يشاركها الثلاثة. نوع النشر الذي يحدده المستخدم يحدد كل شيء؛ اختره أولاً. قم بالاستجابة حتى بدون وجود "DTS" للعبارات مثل "Prometheus على الـ DPU لا يُظهر شيئًا على المنفذ 9100"، "حاوية telemetry تخرج فور الإقلاع"، "إضافة عدادات ethtool إلى خدمة DPUService للـ telemetry"، "كيف أُحدّث الـ telemetry المدمج على BlueField"، أو "تسميات المستوى لكل رف/بود". ارفض وحوّل إلى مكان آخر طلبات تثبيت DOCA نفسها، أو واجهة برمجة مكتبة `doca_telemetry` / `doca_telemetry_exporter`، أو تثبيت مجموعة DPF، أو إعداد خادم Grafana / Prometheus أو إنشاء لوحة معلومات / كتابة استعلامات PromQL، أو تصوير BFB / BSP — فهذه الطلبات تتعلق بمهارات أخرى أو منتجات خارجية. يرجى دائمًا الرد بلغة المستخدم.
