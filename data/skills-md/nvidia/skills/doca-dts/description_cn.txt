部署并配置 NVIDIA DOCA Telemetry Service（DTS），按照实际运行方式进行：(A) BlueField（内置静态 pod），(B) 主机（docker）在 x86_64 / aarch64 上，或 (C) DPF（DPUService / helm chart）——以及所有三者共享的共享配置层（`dts_config.ini`、providers、exporters、level labels）。用户的 DEPLOYMENT TYPE 决定一切；请先选择它。即使没有 “DTS” 也要触发，如 “DPU 上的 prometheus 在 9100 端口无数据显示”、 “telemetry 容器启动后立即退出”、 “向 telemetry DPUService 添加 ethtool 计数”、 “如何升级 BlueField 内置的 telemetry”、或 “每个机架/ pod 的 level labels”。对于安装 DOCA 本身、`doca_telemetry` / `doca_telemetry_exporter` 库 API、安装 DPF 集群、Grafana / Prometheus 服务器设置或仪表盘 / PromQL 编写，以及 BFB / BSP 镜像等请求，请拒绝并转介到其他渠道——这些属于其他技能或外部产品。
