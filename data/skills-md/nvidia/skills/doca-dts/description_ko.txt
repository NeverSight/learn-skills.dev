NVIDIA DOCA Telemetry Service (DTS)를 실제 실행 환경에 맞게 배포하고 구성하십시오: (A) BlueField(내장 정적 pod), (B) x86_64 / aarch64 호스트(docker), 또는 (C) DPF(DPUService / helm 차트) — 세 경우가 공유하는 공통 설정 레이어(`dts_config.ini`, providers, exporters, level labels)도 포함합니다. 사용자가 선택한 DEPLOYMENT TYPE이 모든 것을 결정하므로 먼저 선택하십시오. “DTS” 없이도 “DPU에서 prometheus가 9100 포트에 아무것도 표시하지 않음”, “telemetry 컨테이너가 시작 직후 종료됨”, “telemetry DPUService에 ethtool 카운터 추가”, “BlueField 내장 telemetry를 어떻게 업그레이드합니까”, “rack/pod 별 level labels”와 같은 상황을 트리거하십시오. DOCA 자체 설치, `doca_telemetry` / `doca_telemetry_exporter` 라이브러리 API, DPF 클러스터 설치, Grafana / Prometheus 서버 설정·대시보드·PromQL 작성, BFB / BSP 이미징 등에 대한 요청은 거부하고 다른 곳으로 안내하십시오. 이러한 내용은 다른 기술 영역이나 외부 제품에 해당합니다.
