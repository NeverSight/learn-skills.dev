사용자가 사용자 정의 CDF 오케스트레이션 파이프라인을 설명할 때 사용합니다 — 예를 들어 증강만, 자동 라벨링만, 감지 + 캡션만, 또는 전체 자동 라벨링 없이 이미지 속성 증강과 같이 특정 순서의 단계 조합을 의미하며, airflow/dags/workflows/에 존재하는 기존 DAG가 이를 다루지 않을 경우 새 Kubernetes DAG를 요청하는 경우에 사용합니다. 또한 생성되었거나 기존 DAG의 모델/컨테이너/프롬프트 선택이 외부 사양 문서(예: CDF `launchable.md`)와 일치하는지 확인할 때도 사용합니다. 이미 기존 DAG가 다루고 있는 요청에는 사용하지 않습니다. 여기에는 입력, 엔드포인트, 모델, 변형 수와 같은 페이로드만 변경되는 경우도 포함됩니다 — 이러한 경우에는 해당 워크플로우 스킬로 라우팅하세요. 단, 사용자가 해당 DAG를 안내받은 후에도 별도의 DAG를 원한다면 예외입니다. 항상 사용자의 언어로 응답해 주세요.
