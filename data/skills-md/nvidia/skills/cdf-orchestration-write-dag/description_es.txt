Use cuando un usuario describe una canalización de Orquestación CDF personalizada — una combinación ordenada específica de etapas como solo aumento, solo autoetiquetado, solo detección + subtitulación, o aumento de atributos de imagen sin autoetiquetado completo — que no cubre ningún DAG existente en airflow/dags/workflows/ y solicita un nuevo DAG de Kubernetes. También se usa para verificar que las elecciones de modelo/contenedor/prompt de un DAG generado o existente coincidan con un documento de especificación externo (por ejemplo, un CDF `launchable.md`). No es para solicitudes que ya cubre un DAG existente, incluidos cambios solo de carga útil como diferentes entradas, puntos finales, modelos o recuentos de variantes; dirija esas a la habilidad de flujo de trabajo correspondiente, a menos que el usuario aún quiera un DAG separado después de ser dirigido a él.
