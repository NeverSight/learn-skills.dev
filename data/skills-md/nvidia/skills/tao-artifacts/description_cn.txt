TAO 的无 SDK 执行流水线的合约中心——四种类型工件（spec‑bundle、job‑record、results_dir 布局、best_rec）的权威 JSON Schema，外加固定的 job‑status 词汇表和嵌套而非点分隔的 spec 规则。用于在提交前编写或验证 spec‑bundle、写入或读取 .tao/jobs 中的 job‑record、确定结果落地点，或消费 AutoML 的 best_rec.json。触发短语包括“validate the spec bundle”（验证 spec‑bundle）、“job record schema”（job‑record schema）、“status vocabulary”（状态词汇表）、“results_dir layout”（results_dir 布局）以及“best_rec schema”（best_rec schema）。
