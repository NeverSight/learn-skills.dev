TAO の SDK フリー実行パイプラインの契約拠点 — 4 つの型付きアーティファクト（spec‑bundle、job‑record、results_dir レイアウト、best_rec）に対する権威的 JSON スキーマと、固定された job‑status 語彙、そして nested‑not‑dotted ルールです。提出前に spec‑bundle を作成・検証する時、.tao/jobs の job‑record を書き込む・読み込む時、結果の保存場所を決定する時、または AutoML の best_rec.json を利用する時に使用します。トリガーフレーズは「validate the spec bundle」「job record schema」「status vocabulary」「results_dir layout」「best_rec schema」などです。
