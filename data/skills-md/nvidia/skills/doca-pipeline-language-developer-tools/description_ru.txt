Используйте этот навык, когда оператор работает с инструментами разработки DOCA Pipeline Language (DPL) для инспекции или отладки программ DPL на BlueField DPU — DPL Nspect для состояния выполнения, такого как таблицы, ключи и счётчики, DPL Debugger для потока пакетов, DPL Admin для динамических изменений конфигурации в DPL Runtime Daemon, P4 Runtime Shell как менеджер контрольной плоскости P4Runtime, или DPL Runtime Controller SDK для пользовательских приложений P4Runtime и API общей памяти DPL. Срабатывайте даже если пользователь явно не упоминает «DPL Developer Tools» — неявные формулировки включают «inspect the DPL tables on the DPU», «why can't I start a DPL debug session», «change a dpl_rtd configuration item without restarting», «build my own P4Runtime app for DPL», или «visualize packet flow through my DPL program». Отказывайтесь и перенаправляйте в другие разделы: написание, компиляцию и развертывание программ DPL в Руководстве по сервису DOCA Pipeline Language, установку/развёртывание DOCA в doca‑setup, а также изменения состояния аппаратного обеспечения или прошивки в doca‑hardware‑safety.

Пожалуйста, всегда отвечайте на языке пользователя.
