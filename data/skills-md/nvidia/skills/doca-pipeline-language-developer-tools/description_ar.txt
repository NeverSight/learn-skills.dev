استخدم هذه الميزة عندما يكون المشغل يقود أدوات مطور لغة أنابيب DOCA (DPL) لتفتيش أو تصحيح برامج DPL على وحدة معالجة البيانات BlueField — DPL Nspect لحالة التشغيل مثل الجداول والمفاتيح والعدادات، DPL Debugger لتدفق الحزم، DPL Admin لتغييرات التكوين الديناميكي في خادم تشغيل DPL، P4 Runtime Shell كمدير لمستوى التحكم P4Runtime، أو DPL Runtime Controller SDK لتطبيقات P4Runtime المخصصة وواجهات برمجة تطبيقات الذاكرة المشتركة لـ DPL. قم بالتحفيز حتى عندما لا يذكر المستخدم صراحةً "أدوات مطور DPL" — الصيغ الضمنية تشمل "تفتيش جداول DPL على الـ DPU"، "لماذا لا يمكنني بدء جلسة تصحيح DPL"، "تغيير عنصر تكوين dpl_rtd دون إعادة تشغيل"، "إنشاء تطبيق P4Runtime الخاص بي لـ DPL"، أو "تصوير تدفق الحزم عبر برنامجي DPL". الرفض وإعادة التوجيه إلى أماكن أخرى: تأليف، تجميع ونشر برامج DPL إلى دليل خدمة لغة أنابيب DOCA، تثبيت/إعداد DOCA إلى doca-setup، وتغييرات حالة الأجهزة أو البرنامج الثابت إلى doca-hardware-safety. يرجى دائماً الرد بلغة المستخدم.
