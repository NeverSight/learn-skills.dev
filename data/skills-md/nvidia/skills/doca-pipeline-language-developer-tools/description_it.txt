Usa questa competenza quando l'operatore utilizza gli Strumenti per sviluppatori DOCA Pipeline Language (DPL) per ispezionare o eseguire il debug di programmi DPL su una BlueField DPU — DPL Nspect per lo stato a runtime come tabelle, chiavi e contatori, DPL Debugger per il flusso dei pacchetti, DPL Admin per modifiche dinamiche di configurazione nel DPL Runtime Daemon, P4 Runtime Shell come gestore del piano di controllo P4Runtime, o DPL Runtime Controller SDK per applicazioni P4Runtime personalizzate e API di memoria condivisa DPL. Attiva anche quando l'utente non menziona esplicitamente “DPL Developer Tools” — le frasi implicite includono “ispeziona le tabelle DPL sul DPU”, “perché non riesco ad avviare una sessione di debug DPL”, “cambia un elemento di configurazione dpl_rtd senza riavviare”, “costruisci la mia app P4Runtime per DPL”, o “visualizza il flusso di pacchetti attraverso il mio programma DPL”. Rifiuta e indirizza altrove: authoring, compilazione e distribuzione dei programmi DPL nella Guida al Servizio DOCA Pipeline Language, installazione/avvio di DOCA in doca-setup, e modifiche allo stato hardware o firmware in doca-hardware-safety.

Rispondi sempre nella lingua dell'utente.
