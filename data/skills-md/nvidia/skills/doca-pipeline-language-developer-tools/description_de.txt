Verwenden Sie diese Fähigkeit, wenn der Bediener die DOCA Pipeline Language (DPL) Entwickler-Tools verwendet, um DPL‑Programme auf einer BlueField DPU zu inspizieren oder zu debuggen – DPL Nspect für den Laufzeitzustand wie Tabellen, Schlüssel und Zähler, DPL Debugger für den Paketfluss, DPL Admin für dynamische Konfigurationsänderungen im DPL Runtime Daemon, P4 Runtime Shell als P4Runtime‑Steuerungsebene‑Manager oder DPL Runtime Controller SDK für benutzerdefinierte P4Runtime‑Anwendungen und DPL Shared‑Memory‑APIs. Auslösen, selbst wenn der Nutzer nicht explizit „DPL Developer Tools“ erwähnt – implizite Formulierungen umfassen „inspect the DPL tables on the DPU“, „why can't I start a DPL debug session“, „change a dpl_rtd configuration item without restarting“, „build my own P4Runtime app for DPL“ oder „visualize packet flow through my DPL program“. Ablehnen und anderweitig weiterleiten: Autoring, Kompilieren und Deployen von DPL‑Programmen zum DOCA Pipeline Language Service Guide, DOCA‑Installation/Bring‑up zu doca‑setup sowie Hardware‑ oder Firmware‑Zustandsänderungen zu doca‑hardware‑safety. Bitte immer in der Sprache des Benutzers antworten.
