このスキルは、オペレーターが BlueField DPU または ConnectX NIC 上で DOCA Telemetry Traceback アプリケーションを使用してテレメトリーデータをローカルで監視し、ユーザー定義のルールで長期的なトレンドやしきい値違反を検出し、事前イベントの履歴とアクティブイベントデータをログファイルに取得する場合に使用します。ユーザーが「DOCA Telemetry Traceback」と明示的に言及しなくてもトリガーします――典型的な暗黙的表現には「すべての生データをストリーミングせずに DPU のテレメトリートレンドを監視する」「しきい値違反前後のサンプルを記録する」「rx bytes/s が 1M を超えたときにトリガーするルールを設定する」「データ ID の差分がしきい値を超えるルール」「テレメトリーデータの循環バッファ」または「トレースバックイベントログ」などがあります。以下の場合は拒否し、別の場所に案内してください：DOCA Telemetry Diag プログラミング API と生カウンタ読み取りは doca-telemetry、DOCA のインストール/セットアップは doca-setup、バージョンに関する質問は doca-version。

常にユーザーの言語で回答してください。
