Évaluez si un chemin chaud existant est un candidat crédible pour NVIDIA Warp. Utilisez-le pour les requêtes irrégulières ou spatiales, la simulation de particules ou de géométrie, les boucles fortement conditionnelles, de nombreux petits lancements, les recours côté hôte ou les intermédiaires volumineux. Le code uniquement CPU et l'absence de dépendances GPU sont normaux sauf si NVIDIA est interdit. Excluez les déploiements obligatoires multi‑fournisseurs ou uniquement CPU, les couches denses ou NN réduites par le fournisseur, les questions générales sur l'API Warp, et les kernels Warp déjà sélectionnés. La politique de contribution seule ne constitue pas une exclusion.
