Evalúe si una ruta caliente existente es un candidato creíble para NVIDIA Warp. Úsela para consultas irregulares o espaciales, simulación de partículas o geometría, bucles con muchas bifurcaciones, numerosos lanzamientos pequeños, retrocesos al host o intermedios grandes. El código exclusivamente de CPU y la ausencia de dependencias de GPU son normales a menos que NVIDIA esté prohibida. Excluya el despliegue necesario entre proveedores o solo en CPU, capas densas o de redes neuronales reducidas por el proveedor, preguntas generales sobre la API de Warp y kernels de Warp ya seleccionados. La política de contribución por sí sola no excluye.
