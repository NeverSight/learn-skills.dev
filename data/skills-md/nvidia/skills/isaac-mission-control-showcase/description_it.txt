Esegui e convalida una dimostrazione end‑to‑end di Mission Control con Isaac Sim installato localmente, avviato nella sua finestra GUI e controllato tramite il server Python isaac‑sim‑remote, usando Nova Carter SIL. Utilizzalo per demo, replay di showcase, per far guidare Mission Control a un robot simulato o per diagnosticare lo scenario di piccolo magazzino integrato. Rileva le installazioni di Isaac Sim esistenti senza modificarle, seleziona automaticamente un runtime utilizzabile senza chiedere conferma quando è possibile verificare la compatibilità, e delega le richieste di installazione o di cambio versione a isaac‑sim‑installation. Imposta come predefinito un magazzino canonico Isaac 6.1 con percorso circolare deterministico quando l’utente non specifica un altro scenario.
