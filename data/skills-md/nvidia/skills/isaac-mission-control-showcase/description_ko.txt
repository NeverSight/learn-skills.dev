로컬에 설치된 Isaac Sim을 GUI 창에서 실행하고 isaac-sim-remote Python 서버를 통해 구동하며 Nova Carter SIL과 함께 엔드‑투‑엔드 Mission Control 쇼케이스를 실행하고 검증합니다. 데모, 쇼케이스 재생, Mission Control이 시뮬레이션 로봇을 제어하거나 통합된 소형 창고 시나리오를 진단하는 데 사용합니다. 기존 Isaac Sim 설치를 수정하지 않고 감지하며, 호환성이 확인되면 프롬프트 없이 사용할 수 있는 런타임을 자동으로 선택하고, 요청된 설치 또는 버전 변경은 isaac‑sim‑installation에 위임합니다. 사용자가 다른 시나리오를 지정하지 않을 경우 기본적으로 표준 Isaac 6.1 창고와 결정론적 원형 경로를 사용합니다. 항상 사용자의 언어로 답변해 주세요.
