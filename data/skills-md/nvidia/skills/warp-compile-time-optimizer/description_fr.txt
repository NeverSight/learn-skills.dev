Utilisez-le lorsqu le temps de compilation ou le temps de démarrage pose problème dans du code qui utilise Warp : une demande d’amélioration, d’optimisation ou de réduction des temps de compilation ; une application lente à démarrer ou qui se bloque au premier wp.launch ; quelques secondes de compilation avant que le travail réel ne commence ; des modules JIT recompilés à chaque exécution ou à chaque job CI. Ceci ne s’applique que lorsque le code optimisé utilise les noyaux Warp. Pas pour le temps d’exécution en régime permanent du noyau, la mémoire, la correction, la compilation de Warp lui‑même à partir des sources, ou les temps de construction nvcc/C++.
