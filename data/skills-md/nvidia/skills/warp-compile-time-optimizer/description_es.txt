Utilízalo cuando el tiempo de compilación o de inicio sea el problema en código que usa Warp: una solicitud para mejorar, optimizar o reducir los tiempos de compilación; una aplicación que arranca lenta o se detiene en el primer wp.launch; segundos de compilación antes de que comience el trabajo real; módulos JIT recompilándose en cada ejecución o en cada trabajo de CI. Solo se aplica cuando el código que se está optimizando usa kernels de Warp. No es para el tiempo de ejecución continuo del kernel, la memoria, la corrección, la compilación de Warp desde el código fuente, o los tiempos de compilación de nvcc/C++.
