TAO 작업을 위한 데이터 이동자는 저장 계층을 결정합니다 (A: 사전 배치된 마운트로 fetch 없이 / B: S3 볼륨 / C: 컴퓨트 내 일시적 fetch), 입력을 스테이징합니다 (대량 + annotation 선택적 + 아카이브 추출 + HF/NGC PTM), 자격 증명을 환경에 매핑하고, 출력은 업로드 제외와 함께 3방향으로 라우팅하며, compute‑frame 검증 게이트를 실행합니다. 지원 스킬 및 다른 플랫폼 스킬(docker, kubernetes, slurm, brev, virtualenv)은 TAO SDK 없이도 데이터 컨테이너와 주고받을 수 있도록 호출됩니다. 트리거 문구에는 “stage inputs”, “mount the dataset”, “upload TAO results”, “download only referenced files”, “resolve results_dir”, “verify the container can read the data”가 포함됩니다.
