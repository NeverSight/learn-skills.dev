TAOジョブ用のデータムーバーは、ストレージ階層（A: 事前配置されたマウントでフェッチなし / B: S3 からのボリューム / C: 計算中の一時フェッチ）を決定し、入力をステージング（バルク＋アノテーション選択的＋アーカイブ抽出＋HF/NGC PTM）し、認証情報を環境変数にマッピングし、出力をアップロード除外付きで 3 方向にルーティングし、コンピュートフレームの検証ゲートを実行します。サポートスキルや他プラットフォームスキル（docker、kubernetes、slurm、brev、virtualenv）を呼び出して、TAO SDK を使用せずにデータコンテナへの取得・送信を行います。トリガーフレーズには「stage inputs」「mount the dataset」「upload TAO results」「download only referenced files」「resolve results_dir」「verify the container can read the data」などがあります。
