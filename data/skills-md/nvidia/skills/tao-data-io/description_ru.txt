Перемещатель данных для задач TAO — определяет уровень хранилища (A — предварительно смонтированный без загрузки, B — том из S3, C — временная загрузка в процессе вычисления), подготавливает входные данные (массовые + выборочно по аннотациям + извлечение из архива + HF/NGC PTM), сопоставляет учётные данные с переменными окружения, перенаправляет вывод в три направления с исключением загрузки и запускает проверочный шлюз вычислительной среды. Поддерживающая функция и другие платформенные навыки (docker, kubernetes, slurm, brev, virtualenv) вызываются для передачи данных в вычислительный контейнер и из него без TAO SDK. Триггерные фразы включают «stage inputs», «mount the dataset», «upload TAO results», «download only referenced files», «resolve results_dir», «verify the container can read the data».
