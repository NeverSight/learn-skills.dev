Le data-mover pour les jobs TAO — décide du niveau de stockage (A montage pré‑positionné avec zéro récupération / B volume depuis S3 / C récupération éphémère en‑compute), prépare les entrées (volume massif + sélectif par annotation + extraction d’archive + PTM HF/NGC), associe les informations d’identification à l’environnement, dirige les sorties en trois voies avec exclusion des uploads, et exécute la porte de vérification du cadre de calcul. Une compétence de support parmi d’autres compétences de plateforme (docker, kubernetes, slurm, brev, virtualenv) est appelée pour obtenir les données vers et depuis le conteneur de calcul sans le SDK TAO. Les phrases déclencheuses comprennent « stage inputs », « mount the dataset », « upload TAO results », « download only referenced files », « resolve results_dir », « verify the container can read the data ».
