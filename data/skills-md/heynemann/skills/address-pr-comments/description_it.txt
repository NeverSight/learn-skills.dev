Affronta i commenti di revisione e i controlli falliti di una pull request su GitHub con il CLI gh. Risolve i controlli interrotti alla sorgente; per ogni commento lo risolve (commit, push, risposta citando il commit) o lo confuta nel proprio thread, quindi chiude la conversazione. Usalo quando ti viene chiesto di affrontare, gestire, rispondere o risolvere commenti di PR, feedback di revisione o controlli di PR falliti.
