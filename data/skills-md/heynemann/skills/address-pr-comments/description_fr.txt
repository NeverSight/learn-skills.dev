Traiter les commentaires d'examen d'une demande d'extraction GitHub et les vérifications infructueuses avec l'interface de ligne de commande gh. Corrige les vérifications brisées à la source ; pour chaque commentaire, il corrige (commit, push, réponse citant le commit) ou le réfute dans son propre fil de discussion, puis résout la conversation. À utiliser lorsqu'on vous demande d'adresser, de gérer, de répondre ou de résoudre les commentaires des RP, d'examiner les commentaires ou d'échouer aux vérifications des RP.
