Erstellt eine 3D-Kartenanimation für eine Walze. Eine saubere weiße Stadt mit Parks und einem Fluss, eine farbige Route, die sich von Anfang bis Ziel zieht, während die Kamera folgt, eine rote Nadel, die mit einem Sprung fällt, eine ETA-Karte, die herunterzählt, und eine Zielkarte. Wird verwendet, wenn der Benutzer eine animierte Route, eine "von A nach B" -Karte, eine Reise oder eine Pendleranimation ausführt/kartiert oder nach einer animierten Route fragt.
