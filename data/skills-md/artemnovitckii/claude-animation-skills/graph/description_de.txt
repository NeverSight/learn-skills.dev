Erstellt eine minimale Liniengrafik-Animation für eine Walze. Eine glatte schwarze Linie zieht sich auf Weiß (oder Weiß auf Schwarz), während eine große Zahl mit der Spitze hochzählt und dann auf dem Endwert landet. Wird verwendet, wenn der Benutzer ein Wachstumsdiagramm, eine Zahlenanimation "0 bis 100K" oder eine animierte Statistik ausführt /graphisch darstellt oder nach einem Wachstumsdiagramm fragt.
