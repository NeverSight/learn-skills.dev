Fait une animation de graphisme de ligne minimale pour un rouleau. Une ligne noire lisse se dessine sur le blanc (ou le blanc sur le noir) tandis qu'un grand nombre compte avec la pointe, puis atterrit sur la valeur finale. Utiliser lorsque l'utilisateur exécute /graphe ou demande un graphique de croissance, une animation numérique « 0 à 100K » ou une statistique animée.
