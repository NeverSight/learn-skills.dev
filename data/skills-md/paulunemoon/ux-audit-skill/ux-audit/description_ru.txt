Основанный на доказательствах UX‑аудит продукта, который уже существует — маркетинговый веб‑сайт, веб‑приложение, мобильное приложение или десктопное приложение. ЗАГРУЗКА, КОГДА запрос состоит в оценке, ревью, критике или диагностике существующего интерфейса: «аудировать UX этого приложения», «просмотреть этот поток», «просмотреть этот экран», «что не так с этим онбордингом», «почему пользователи отваливаются здесь», «аудировать наш текущий рабочий процесс», «это доступно», «критиковать этот продукт», «эвристический обзор», «аудит доступности (a11y)» — и те же намерения на французском («audite l'UX», «revois ce parcours / cet écran», «qu'est‑ce qui cloche dans cet onboarding», «pourquoi les utilisateurs abandonnent», «est‑ce accessible», «critique ce produit»). Работает с живым URL, Figma, скриншотами, исходным кодом или описанием; оценивает каждое найденное наблюдение по степени тяжести, уверенности и доказательствам. Добавляет модуль onchain/web3 только в том случае, если продукт находится в блокчейне. НЕ ЗАГРУЖАТЬ для создания, проектирования или построения нового UI с нуля — это другая задача. Пожалуйста, всегда отвечайте на языке пользователя.
