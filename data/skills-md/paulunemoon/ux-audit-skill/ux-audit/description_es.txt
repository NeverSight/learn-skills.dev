Auditoría de UX basada en evidencia de un producto que ya existe — sitio web de marketing, aplicación web, aplicación móvil o aplicación de escritorio. CARGAR CUANDO la solicitud sea evaluar, revisar, criticar o diagnosticar una interfaz existente: "auditar la UX de esta app", "revisar este flujo", "revisar esta pantalla", "qué está mal en este onboarding", "por qué los usuarios abandonan aquí", "auditar nuestro flujo de trabajo actual", "¿es accesible?", "criticar este producto", "revisión heurística", "auditoría de accesibilidad (a11y)" — y las mismas intenciones en francés ("audite l'UX", "revois ce parcours / cet écran", "qu'est-ce qui cloche dans cet onboarding", "pourquoi les utilisateurs abandonnent", "est-ce accessible", "critique ce produit"). Funciona a partir de una URL en vivo, Figma, capturas de pantalla, código fuente o una descripción; califica cada hallazgo por gravedad, confianza y evidencia. Añade un módulo onchain/web3 encima solo cuando el producto es onchain. NO CARGAR para crear, diseñar o construir una nueva UI desde cero — eso es otro trabajo.

Por favor, responde siempre en el idioma del usuario.
