Audit UX basé sur des données probantes d’un produit déjà existant — site Web marketing, application Web, application mobile ou application de bureau. CHARGER LORSQUE la demande consiste à évaluer, réviser, critiquer ou diagnostiquer une interface existante : « audit the UX of this app », « review this flow », « review this screen », « what's wrong with this onboarding », « why do users drop off here », « audit our current workflow », « is this accessible », « critique this product », « heuristic review », « a11y audit » — et les mêmes intentions en français (« audite l'UX », « revois ce parcours / cet écran », « qu'est-ce qui cloche dans cet onboarding », « pourquoi les utilisateurs abandonnent », « est‑ce accessible », « critique ce produit »). Fonctionne à partir d’une URL en direct, Figma, captures d’écran, code source ou description ; attribue à chaque constatation un niveau de gravité, de confiance et de preuve. Ajoute un module onchain/web3 uniquement lorsque le produit est onchain. NE PAS CHARGER pour créer, concevoir ou développer une nouvelle interface à partir de zéro — c’est un autre travail.

Veuillez toujours répondre dans la langue de l'utilisateur.
