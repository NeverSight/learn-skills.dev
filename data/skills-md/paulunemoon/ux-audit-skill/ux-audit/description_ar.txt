تدقيق تجربة المستخدم القائم على الأدلة لمنتج موجود بالفعل — موقع تسويقي، تطبيق ويب، تطبيق موبايل، أو تطبيق سطح مكتب. يتم التحميل عندما يكون الطلب تقييم، مراجعة، انتقاد أو تشخيص واجهة موجودة: "audit the UX of this app"، "review this flow"، "review this screen"، "what's wrong with this onboarding"، "why do users drop off here"، "audit our current workflow"، "is this accessible"، "critique this product"، "heuristic review"، "a11y audit" — وكذلك النوايا نفسها بالفرنسية ("audite l'UX"، "revois ce parcours / cet écran"، "qu'est-ce qui cloche dans cet onboarding"، "pourquoi les utilisateurs abandonnent"، "est-ce accessible"، "critique ce produit"). يعمل من عنوان URL حي، أو Figma، أو لقطات شاشة، أو الكود المصدري، أو وصف؛ يقيم كل ملاحظة حسب الخطورة، الثقة، والدليل. يضيف طبقة وحدة onchain/web3 فقط عندما يكون المنتج على السلسلة. لا يتم التحميل لإنشاء، تصميم أو بناء واجهة مستخدم جديدة من الصفر — فهذا عمل مختلف.
