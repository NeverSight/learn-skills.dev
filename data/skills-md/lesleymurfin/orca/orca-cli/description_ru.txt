Оперировать управляемыми Orca рабочими деревьями, контекстами папок, терминалами, репозиториями, автоматизацией, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Использовать, когда пользователь говорит "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" или "share skills". Предпочитать это вместо обычного git worktree, ад‑hoc PTY или использования компьютера, когда вовлечено состояние Orca. Использовать Computer Use только тогда, когда требуется управление видимым окном GUI, которое нельзя выполнить через CLI, файловую систему или API.
