`orca` CLI を使って、Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザを操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、単なる git worktree やその場しのぎの PTY、あるいは Computer Use よりもこちらを優先します。CLI、ファイルシステム、API では対応できず、可視ウィンドウの GUI 操作が必要な場合のみ Computer Use を使用してください。

常にユーザーの言語で回答してください。
