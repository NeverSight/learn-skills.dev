Verwalte Orca-verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaumkommentare und den eingebetteten Browser von Orca über die `orca`‑CLI. Verwende es, wenn der Nutzer „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“ sagt. Bevorzuge es gegenüber rohen Git‑Worktrees, ad‑hoc PTYs oder Computer Use, wenn ein Orca‑Zustand beteiligt ist. Nutze Computer Use nur, wenn ein sichtbares Fenster GUI‑Steuerung erfordert, die ein CLI, Dateisystem oder eine API nicht leisten kann.
