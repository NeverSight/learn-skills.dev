قم بتشغيل شجرات العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر واجهة سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضِّل ذلك على شجرة git العادية، أو PTYs العشوائية، أو استخدام الحاسوب عندما تكون حالة Orca متورطة. استخدم استخدام الحاسوب فقط عندما تتطلب نافذة مرئية تحكمًا رسوميًا لا يمكن لسطر الأوامر أو نظام الملفات أو API تحقيقه.
