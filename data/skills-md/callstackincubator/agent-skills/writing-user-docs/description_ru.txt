Стиль оформления пользовательской документации — голос, охват, структура и что исключать. Используйте это умение при написании, редактировании или проверке любого текста, который пользователь читает, чтобы узнать, как пользоваться инструментом — статьи справочного центра, руководства по началу работы, учебные материалы, документы по функциям, разделы README с примерами использования, справка в приложении, примечания к выпуску или ответы в FAQ. Применяйте его даже если запрос сформулирован просто — «документировать эту функцию», «напиши документы для X», «объясни это пользователям», «создай README для этой библиотеки», «преврати эти заметки в руководство» — и даже если не упоминаются правила стиля. Также используйте его для проверки существующей документации на соответствие тону, избыточность или утечку деталей реализации. Не применяйте его к внутренней инженерной документации, описаниям архитектуры, RFC или комментариям в коде.

Пожалуйста, всегда отвечайте на языке пользователя.
