Estilo interno para la documentación orientada al usuario — tono, alcance, estructura y lo que se debe omitir. Utiliza esta habilidad cada vez que redactes, edites o revises cualquier cosa que un usuario lea para aprender a usar una herramienta — artículos del centro de ayuda, guías de inicio, tutoriales, documentos de funciones, secciones de uso del README, ayuda dentro de la aplicación, notas de versión o entradas de preguntas frecuentes. Actívalo incluso cuando la solicitud esté formulada de manera sencilla — “documenta esta característica”, “escribe docs para X”, “explica esto a los usuarios”, “escribe un README para esta biblioteca”, “convierte estas notas en una guía” — y también cuando no se mencionen directrices de estilo. También utilízalo para revisar la documentación existente en busca de tono, redundancia o detalles de implementación filtrados. No lo uses para documentos internos de ingeniería, descripciones de arquitectura, RFCs o comentarios de código. Por favor, responde siempre en el idioma del usuario.
