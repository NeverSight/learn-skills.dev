نمط الكتابة للوثائق الموجهة للمستخدم — الصوت، النطاق، الهيكل، وما يجب استبعاده. استخدم هذه المهارة عند كتابة أو تحرير أو مراجعة أي شيء يقرؤه المستخدم لتعلم كيفية استخدام أداة — مقالات مركز المساعدة، أدلة البدء، الدروس التعليمية، وثائق المميزات، أقسام الاستخدام في ملف README، المساعدة داخل التطبيق، ملاحظات الإصدارات، أو مدخلات الأسئلة الشائعة. فعّلها حتى عندما يُصاغ الطلب بصورة بسيطة — "وثّق هذه الميزة"، "اكتب وثائق لـ X"، "اشرح هذا للمستخدمين"، "اكتب README لهذه المكتبة"، "حوّل هذه الملاحظات إلى دليل" — وحتى عندما لا تُذكر إرشادات الأسلوب. استخدمها أيضًا لمراجعة الوثائق الحالية من حيث النغمة، والإفراط، أو كشف تفاصيل التنفيذ. لا تستخدمها للوثائق الهندسية الداخلية، أو كتابة بنية النظام، أو طلبات المقترحات التقنية (RFCs)، أو تعليقات الشيفرة.
