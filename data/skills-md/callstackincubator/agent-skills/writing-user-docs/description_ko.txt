사용자용 문서의 내부 스타일 — 어조, 범위, 구조 및 제외할 내용. 도구 사용법을 배우기 위해 사용자가 읽는 모든 문서(헬프 센터 기사, 시작 가이드, 튜토리얼, 기능 문서, README 사용 섹션, 인앱 도움말, 릴리즈 노트, FAQ 항목 등)를 작성, 편집 또는 검토할 때마다 이 기술을 적용하세요. 요청이 단순히 “이 기능 문서화”, “X에 대한 문서 작성”, “사용자에게 설명”, “이 라이브러리용 README 작성”, “이 메모를 가이드로 전환” 등으로 표현되어도, 스타일 가이드가 언급되지 않더라도 트리거하세요. 또한 기존 문서의 어조, 과다한 내용, 구현 세부 정보 누출 여부를 검토하는 데에도 활용하십시오. 내부 엔지니어링 문서, 아키텍처 서술, RFC, 코드 주석 등에는 사용하지 마세요.

항상 사용자의 언어로 답변하시기 바랍니다.
