Stile di riferimento per la documentazione rivolta agli utenti — tono, ambito, struttura e ciò che va omesso. Usa questa competenza ogni volta che scrivi, editi o rivedi qualsiasi cosa un utente legga per imparare a usare uno strumento — articoli del centro assistenza, guide introduttive, tutorial, documentazione delle funzionalità, sezioni d'uso del README, aiuto in‑app, note di rilascio o voci FAQ. Attivalo anche quando la richiesta è formulata in modo semplice — “documenta questa funzionalità”, “scrivi la documentazione per X”, “spiega questo agli utenti”, “scrivi un README per questa libreria”, “trasforma queste note in una guida” — e anche quando non vengono menzionate linee guida di stile. Usalo anche per rivedere la documentazione esistente valutando tono, ridondanze o dettagli di implementazione trapelati. Non usarlo per documenti di ingegneria interna, descrizioni di architettura, RFC o commenti al codice.

Rispondi sempre nella lingua dell'utente.
