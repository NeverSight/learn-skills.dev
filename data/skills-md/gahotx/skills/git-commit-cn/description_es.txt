Ejecuta un commit de git, usando la especificación Conventional Commits para generar mensajes de commit en chino. Activa esto cuando el usuario solicite hacer commit de código, cree un commit de git o mencione “commit”. Soporta: (1) detectar automáticamente el tipo y alcance a partir de los cambios de código, (2) generar mensajes de commit convencionales en chino basados en el diff, con cada línea del cuerpo correspondiente a los cambios actuales, (3) admitir commits interactivos y tipo/alcance/descripción personalizados, (4) hacer staging de archivos de manera inteligente para lograr una agrupación lógica, (5) formatear el cuerpo para alinearse con los commits recientes en este repositorio; cuando coexistan varios estilos o la información original no sea estándar, enumera cada punto con un “-”. Por favor, responde siempre en el idioma del usuario.
