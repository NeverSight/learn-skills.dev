Выполните git‑коммит, используя спецификацию Conventional Commits для генерации сообщений коммита на китайском языке. Срабатывает, когда пользователь запрашивает коммит кода, создает git‑коммит или упоминает «commit». Поддерживает: (1) автоматическое определение типа и области изменения из кода, (2) генерацию китайских сообщений Conventional Commit на основе diff, при этом каждая строка тела соответствует текущему изменению, (3) интерактивные коммиты и пользовательский тип/область/описание, (4) интеллектуальное добавление файлов в индекс для логической группировки, (5) форматирование тела в соответствии с последними коммитами в этом репозитории; если в репозитории присутствуют несколько стилей или существующая информация нестандартна, перечисляйте каждый пункт с «-». Всегда отвечайте на языке пользователя.
