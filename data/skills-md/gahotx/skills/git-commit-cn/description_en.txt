Execute a git commit, using the Conventional Commits specification to generate Chinese commit messages. Trigger when the user requests to commit code, create a git commit, or mentions “commit.” Supports: (1) automatically detecting type and scope from code changes, (2) generating Chinese conventional commit messages based on the diff, with each body line corresponding to this change, (3) supporting interactive commits and custom type/scope/description, (4) smartly staging files to achieve logical grouping, (5) formatting the body to align with recent commits in this repository; when multiple styles coexist or existing information is non‑standard, list each point with a “-”.
