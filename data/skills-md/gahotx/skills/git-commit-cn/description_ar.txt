نفّذ عملية git commit باستخدام مواصفة Conventional Commits لتوليد رسائل التزام صينية. يُفعَّل عندما يطلب المستخدم ارتكاب كود، أو إنشاء git commit، أو يذكر كلمة “commit”. يدعم:  
1. الكشف التلقائي عن النوع والنطاق من تغييرات الكود.  
2. توليد رسائل التزام صينية تقليدية استناداً إلى الفرق، بحيث يتطابق كل سطر من النص مع التغييرات الحالية.  
3. دعم عمليات ارتكاب تفاعلية وتخصيص النوع/النطاق/الوصف.  
4. إعداد الملفات للمرحلة بذكاء لتحقيق تجميع منطقي.  
5. تنسيق النص ليتماشى مع الالتزامات الأخيرة في هذا المستودع؛ عندما تتواجد أنماط متعددة أو تكون المعلومات الحالية غير قياسية، يُدرَج كل بند باستخدام “‑”.  

يرجى دائماً الرد بلغة المستخدم.
