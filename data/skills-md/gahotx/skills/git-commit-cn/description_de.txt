Führen Sie einen Git‑Commit aus, wobei die Conventional‑Commits‑Spezifikation verwendet wird, um chinesische Commit‑Nachrichten zu erzeugen. Auslösen, wenn der Benutzer das Committen von Code anfordert, einen Git‑Commit erstellt oder „commit“ erwähnt. Unterstützt: (1) Automatisches Erkennen von Typ und Scope aus Code‑Änderungen, (2) Generierung chinesischer konventioneller Commit‑Nachrichten basierend auf dem Diff, wobei jede Body‑Zeile dieser Änderung entspricht, (3) Unterstützung interaktiver Commits und benutzerdefinierter Typ/Scope/Beschreibung, (4) Intelligentes Staging von Dateien zur logischen Gruppierung, (5) Angleichung der Body‑Formatierung an die neuesten Commits in diesem Repository; wenn mehrere Stile koexistieren oder vorhandene Informationen nicht standardkonform sind, listet jeder Punkt mit einem „-“ auf.

Bitte immer in der Sprache des Benutzers antworten.
