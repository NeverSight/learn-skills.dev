Conventional Commits 규격을 사용하여 중국어 커밋 메시지를 생성하면서 git 커밋을 실행합니다. 사용자가 코드를 커밋하려고 요청하거나 git 커밋을 만들거나 “commit”이라고 언급할 때 트리거됩니다. 지원 기능: (1) 코드 변경으로부터 유형과 범위를 자동으로 감지, (2) diff를 기반으로 현재 변경 사항에 대응하는 각 본문 줄을 포함한 중국어 Conventional Commit 메시지 생성, (3) 인터랙티브 커밋 및 사용자 정의 유형/범위/설명 지원, (4) 논리적 그룹화를 위해 파일을 지능적으로 스테이징, (5) 이 저장소의 최근 커밋과 본문 형식을 맞춤; 여러 스타일이 공존하거나 기존 정보가 비표준인 경우 “-”로 각 항목을 나열합니다.

항상 사용자의 언어로 응답하십시오.
