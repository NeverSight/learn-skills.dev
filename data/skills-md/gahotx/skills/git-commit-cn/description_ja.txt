Conventional Commits 仕様を使用して中国語のコミットメッセージを生成し、git commit を実行します。ユーザーがコードのコミットを要求したとき、git commit を作成したとき、または「commit」と言及したときにトリガーします。サポート内容: (1) コード変更からタイプとスコープを自動検出、(2) diff に基づいて中国語の Conventional Commit メッセージを生成し、本文の各行を現在の変更に対応させる、(3) インタラクティブコミットとカスタムタイプ／スコープ／説明をサポート、(4) 論理的なグルーピングを実現するためにファイルをインテリジェントにステージング、(5) 本文をリポジトリ内の最近のコミットに合わせてフォーマット；複数のスタイルが混在している場合や既存情報が標準でない場合は、各ポイントを “-” で列挙してください。

常にユーザーの言語で応答してください。
