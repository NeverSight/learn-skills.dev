Esegui un commit git, usando la specifica Conventional Commits per generare messaggi di commit in cinese. Attiva quando l'utente richiede di effettuare il commit del codice, crea un commit git o menziona “commit”. Supporta: (1) rilevamento automatico di tipo e ambito dalle modifiche al codice, (2) generazione di messaggi di commit convenzionali in cinese basati sul diff, con ogni riga del corpo corrispondente alla modifica corrente, (3) commit interattivo e tipo/ambito/descrizione personalizzati, (4) staging intelligente dei file per ottenere raggruppamenti logici, (5) formattazione del corpo per allinearsi ai commit recenti in questo repository; quando coesistono più stili o le informazioni esistenti non sono standard, elenca ogni punto con un “-”.  

Per favore rispondi sempre nella lingua dell'utente.
