Exécutez un commit git en utilisant la spécification Conventional Commits pour générer des messages de commit en chinois. Déclenchez‑le lorsque l’utilisateur demande de valider du code, crée un commit git ou mentionne « commit ». Prise en charge : (1) détecter automatiquement le type et la portée à partir des changements de code ; (2) générer des messages de commit conventionnels en chinois basés sur le diff, chaque ligne du corps correspondant au changement actuel ; (3) soutenir les commits interactifs et les type/portée/description personnalisés ; (4) mettre en scène les fichiers de façon intelligente pour obtenir un regroupement logique ; (5) aligner le format du corps avec les commits récents de ce dépôt ; lorsqu’il existe plusieurs styles ou que les informations existantes ne sont pas standard, répertorier chaque point avec un « - ». Veuillez toujours répondre dans la langue de l’utilisateur.
