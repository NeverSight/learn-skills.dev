Umschreibt ein nachträglich angefügtes Feature so, dass es wirkt, als wäre es immer Teil des ursprünglichen Designs gewesen. Verwende es, wenn ein Diff, Branch oder Commit ein Feature über Sonderfälle, Flags, Aliase, parallele Komponenten oder Erhaltungstests hinzufügt, anstatt den bestehenden Code neu zu gestalten.
