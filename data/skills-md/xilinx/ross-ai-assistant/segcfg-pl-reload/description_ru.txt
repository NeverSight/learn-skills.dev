Описывает рабочий процесс перезагрузки PL в сегментированной конфигурации Versal для создания и проверки нескольких независимо скомпилированных вариантов `pld.pdi` при фиксированном `boot.pdi`. Используйте, когда пользователь спрашивает, как настроить золотой дизайн перезагрузки PL, создать новый проект варианта PL, сохранить пути загрузки NoC с помощью `write_noc_solution`, подобрать размеры адресных отверстий для совместимости перезагрузки, выполнить `pr_verify -segcfg_only` или отладить несоответствия `unique_id` / `parent_unique_id`, отклонённые PLM.
