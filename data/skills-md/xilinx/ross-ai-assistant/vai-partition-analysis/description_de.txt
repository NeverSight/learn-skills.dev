Untersuchen Sie das Ergebnis einer VAIML‑Kompilation eines Mixed‑Precision‑ONNX‑Modells und reduzieren Sie die Anzahl der NPU‑Partitionen auf eine einzelne Partition. Parsen Sie die Compiler‑Operationsstatistiken (übereinstimmende Kernel / templatisierte Graphen), die Partitionsanzahl und die AIE/CPU‑Offload‑Aufteilung; wenn mehr als eine Partition erzeugt wird, lesen Sie die CpuBecause‑Meldungen und Kompilierungswarnungen, klassifizieren Sie diese und schlagen Sie Abhilfemaßnahmen vor. Die Abhilfemaßnahmen bevorzugen die korrekten Frontend‑Flags (fe_args) gegenüber Model‑Patching; wenn die Partitionierung durch Quantisierung verursacht wird, werden stattdessen Änderungen an der Quark‑Konfiguration vorgeschlagen. Jede vorgeschlagene Änderung wird durch eine erneute Kompilierung verifiziert, um das Ergebnis zu bewerten.
