Analiza el rendimiento de los modelos compilados con VAIML. Utiliza el SDK AI Analyzer para extraer tiempos detallados, métricas de operadores y resúmenes de rendimiento, y luego responde a cualquier pregunta sobre el rendimiento del modelo: tiempo por capa, costo de operaciones personalizadas, cuellos de botella, desglose de particiones, comparaciones entre ejecuciones y más. Requiere un entorno Python de Ryzen AI / Vitis AI con `dlanalyzer` disponible, ya sea activando un script de entorno virtual (`--t`) o ejecutándose dentro de un entorno preaprovisionado, como el contenedor Docker oficial de Vitis AI. Úsalo cuando el usuario quiera analizar el rendimiento del modelo, encontrar capas lentas, comparar ejecuciones de compilación, entender la sobrecarga de operaciones personalizadas o generar un informe de rendimiento.
