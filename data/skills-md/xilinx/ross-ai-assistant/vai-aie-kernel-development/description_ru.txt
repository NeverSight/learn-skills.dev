Всеобъемлющее руководство по разработке ядра AIE, охватывающее техники оптимизации на уровне архитектуры, анализ результатов и независимые от компилятора шаблоны. Описывает разбиение циклов для снижения давления на регистры, обновления «на месте», оптимизацию знаковости, учёт слотов VLIW, анализ результатов (дизассемблирование, карты DM, дерево вызовов, профилирование) и общие практики кодирования ядер. Поставляется файл aie_api_references.md — подробный каталог примитивов API AIE (поддержка типов данных, векторизация, типы аккумуляторов, сопоставление математических шаблонов с API). Для компилятор-специфичных директив Peano, подсказок к циклам, деталей программного конвейерования и замечаний по оптимизации см. навык vai-aie-compiler-oriented-optimizations.
