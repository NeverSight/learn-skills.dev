End-to-End-Entwicklung von benutzerdefinierten AIE-Operatoren für VAIML: Extrahiere einen Subgraphen aus einem ONNX‑Modell, entwickle einen benutzerdefinierten Kernel und Tiling, validiere mit x86sim gegenüber einer CPU‑Referenz und reintegriere den benutzerdefinierten Operator zurück in das gesamte Modell. Verwenden, wenn der Benutzer einen benutzerdefinierten Operator erstellen, einen Kernel schreiben, Tiling definieren, für AIE kompilieren, mit x86sim simulieren oder einen benutzerdefinierten Operator in ein Modell integrieren möchte.
