Développement d’opérateur AIE personnalisé de bout en bout pour VAIML : extraire un sous‑graphique d’un modèle ONNX, développer un noyau personnalisé et le tiling, valider avec x86sim contre une référence CPU, puis réintégrer l’opérateur personnalisé dans le modèle complet. Utilisez lorsque l’utilisateur souhaite créer un opérateur personnalisé, écrire un noyau, définir le tiling, compiler pour AIE, simuler avec x86sim ou intégrer un opérateur personnalisé dans un modèle.
