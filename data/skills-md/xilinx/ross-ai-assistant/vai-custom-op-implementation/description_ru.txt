Разработка пользовательского оператора AIE от начала до конца для VAIML: извлечь подграф из модели ONNX, разработать пользовательское ядро и тайлинг, проверить с помощью x86sim по сравнению с эталоном на CPU и повторно интегрировать пользовательский оператор в полную модель. Используйте, когда пользователь хочет создать пользовательский оператор, написать ядро, определить тайлинг, собрать для AIE, смоделировать с помощью x86sim или интегрировать пользовательский оператор в модель.
