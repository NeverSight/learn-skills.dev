"دليل تطوير جافا علي بابا (إصدار الجبل الأصفر)" نظرة عامة وإدخال التوجيه. يغطي سبعة أبعاد رئيسية: اصطلاحات الترميز، وتسجيل الاستثناءات، واختبار الوحدة، واتفاقيات الأمان، وقاعدة بيانات MySQL، وبنية المشروع، واتفاقيات التصميم. يُستخدم عند كتابة كود Java أو مراجعته أو تصميمه؛ التعامل مع الاستثناءات/التسجيل؛ كتابة SQL أو تصميم الجداول؛ اختبارات وحدة الكتابة؛ تصميم هندسة المشروع؛ أو عندما يتم تطبيق معايير Alibaba Java. تعمل هذه المهارة بمثابة جهاز توجيه للدليل؛ يمكن الرجوع إلى الاتفاقيات التفصيلية حسب الحاجة في ملفات الفصل المقابلة ضمن دليل البيانات/.
