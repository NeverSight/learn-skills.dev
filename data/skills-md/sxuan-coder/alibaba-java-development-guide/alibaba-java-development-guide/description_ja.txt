「Alibaba Java 開発マニュアル (Yellow Mountain Edition)」の概要とルーティング エントリ。コーディング規約、例外ログ、単体テスト、セキュリティ規約、MySQL データベース、プロジェクト構造、設計規約の 7 つの主要な側面をカバーします。 Java コードを作成、レビュー、または設計するときに使用します。例外の処理/ロギング。 SQL の作成またはテーブルの設計。単体テストを作成する。プロジェクトのアーキテクチャを設計する。または Alibaba Java 標準が適用される場合はいつでも。このスキルはディレクトリ ルーターとして機能します。詳細な規則は、data/ ディレクトリの下にある対応する章ファイルで必要に応じて参照できます。
