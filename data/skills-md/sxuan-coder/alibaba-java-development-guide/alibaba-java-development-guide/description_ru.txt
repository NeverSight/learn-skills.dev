«Руководство по разработке Java на Alibaba (издание Yellow Mountain)» Обзор и маршрутизация. Охватывает семь основных аспектов: соглашения о кодировании, регистрацию исключений, модульное тестирование, соглашения о безопасности, базу данных MySQL, структуру проекта и соглашения о проектировании. Используйте при написании, просмотре или разработке кода Java; обработка исключений/ведение журнала; написание SQL или проектирование таблиц; написание модульных тестов; проектирование архитектуры проекта; или когда применяются стандарты Alibaba Java. Этот навык служит маршрутизатором каталогов; с подробными соглашениями можно ознакомиться, если необходимо, в соответствующих файлах глав в каталоге data/.
