„Das Alibaba Java Development Manual (Yellow Mountain Edition)“ Übersicht und Routing-Eintrag. Deckt sieben Hauptdimensionen ab: Codierungskonventionen, Ausnahmeprotokollierung, Komponententests, Sicherheitskonventionen, MySQL-Datenbank, Projektstruktur und Designkonventionen. Verwendung beim Schreiben, Überprüfen oder Entwerfen von Java-Code; Behandlung von Ausnahmen/Protokollierung; SQL schreiben oder Tabellen entwerfen; Unit-Tests schreiben; Entwerfen von Projektarchitekturen; oder wann immer Alibaba Java-Standards gelten. Dieser Skill dient als Verzeichnisrouter; Detaillierte Konventionen können bei Bedarf in den entsprechenden Kapiteldateien im Verzeichnis data/ eingesehen werden.
