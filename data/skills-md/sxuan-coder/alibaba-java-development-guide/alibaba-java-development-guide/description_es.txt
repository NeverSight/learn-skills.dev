Manual de desarrollo de Java de Alibaba (edición Huangshan) Descripción general y entrada de enrutamiento. Cubre siete dimensiones: convenciones de codificación, registro de excepciones, pruebas unitarias, especificaciones de seguridad, base de datos MySQL, estructura del proyecto y especificaciones de diseño. Úselo al escribir, revisar o diseñar código Java; manejo de excepciones/registro; escribir SQL o diseñar tablas; escribir pruebas unitarias; diseñar arquitectura de proyectos; o cuando se apliquen los estándares Java de Alibaba. Esta habilidad sirve como enrutador de directorio; Las especificaciones detalladas se pueden consultar según sea necesario en los archivos del capítulo correspondiente en datos/.
