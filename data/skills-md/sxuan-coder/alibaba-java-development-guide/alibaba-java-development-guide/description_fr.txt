"Le manuel de développement Alibaba Java (Yellow Mountain Edition)" Présentation et entrée de routage. Couvre sept dimensions principales : les conventions de codage, la journalisation des exceptions, les tests unitaires, les conventions de sécurité, la base de données MySQL, la structure du projet et les conventions de conception. À utiliser lors de l'écriture, de la révision ou de la conception de code Java ; gestion des exceptions/journalisation ; écrire du SQL ou concevoir des tables ; rédiger des tests unitaires ; concevoir l'architecture du projet ; ou chaque fois que les normes Alibaba Java s'appliquent. Cette compétence sert de routeur d'annuaire ; les conventions détaillées peuvent être consultées selon les besoins dans les fichiers de chapitre correspondants sous le répertoire data/.
