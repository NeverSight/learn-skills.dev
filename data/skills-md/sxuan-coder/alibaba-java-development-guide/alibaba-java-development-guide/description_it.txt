Manuale di sviluppo Java Alibaba (edizione Huangshan) Panoramica e voce di routing. Copre sette dimensioni principali: convenzioni di codifica, registrazione delle eccezioni, test unitari, convenzioni di sicurezza, database MySQL, struttura del progetto e convenzioni di progettazione. Utilizzare durante la scrittura, la revisione o la progettazione del codice Java; gestione delle eccezioni/registrazione; scrivere SQL o progettare tabelle; scrivere test unitari; progettazione dell'architettura del progetto; o ogni volta che si applicano gli standard Java di Alibaba. Questa abilità funge da router del sommario; consultare i file dei capitoli corrispondenti nella sezione dati/ per specifiche dettagliate secondo necessità.
