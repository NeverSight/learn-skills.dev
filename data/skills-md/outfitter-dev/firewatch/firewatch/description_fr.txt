Interrogez l'activité des PR GitHub à l'aide de l'interface de ligne de commande Firewatch (fw). Récupérez, mettez en cache, filtrez et agissez sur les commentaires, les revues, les commits et le statut CI des PR. Génère un fichier JSONL pour la composition jq. À utiliser pour vérifier le statut d'une PR, rechercher des commentaires de revue, interroger l'activité, traiter les retours ou travailler avec les pull requests GitHub.
