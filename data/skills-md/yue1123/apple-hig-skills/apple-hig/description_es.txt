Directrices de Interfaz Humana de Apple condensadas para proyectos React Native, organizadas por plataforma (iOS, iPadOS, macOS, tvOS, visionOS, watchOS) con asignaciones concretas de implementación RN, métricas exactas y listas de verificación. Usa esta habilidad cada vez que construyas, revises o restilices cualquier UI que funcione en una plataforma Apple — pantallas, navegación, hojas, modales, alertas, listas, formularios, botones, barras de pestañas, barras de herramientas, tipografía, color, modo oscuro, Liquid Glass, animación, hápticos, áreas seguras, Dynamic Type, accesibilidad, VoiceOver, widgets, notificaciones o requisitos de la App Store como permisos y eliminación de cuentas. También utilízala cuando el usuario pregunte si algo “se siente nativo”, “parece una aplicación de Apple”, sigue las HIG, o debe adaptarse para iPad/Mac/TV/Vision Pro — y al portar un diseño de Android o web a iOS, donde a menudo se pierden las convenciones de la plataforma. Prioriza esta habilidad sobre la intuición de diseño general para cualquier decisión de UI en plataformas Apple, incluso cuando Apple o las HIG no se mencionen por nombre.  

Responde siempre en el idioma del usuario.
