صمم أو عزّز أو راجع ما يطلبه عامل Python Google ADK من النموذج لإصداره وأي نموذج وإعدادات تنتج ذلك: عقود مخطط الإخراج (output_schema) والتحقق منها، حلقات الإصلاح، مخطط الإخراج مع الأدوات، اختيار نموذج Gemini ودورة حياته، إعدادات التفكير والعينة، وفشل النموذج. استخدم ذلك للإخراج المهيكل الذي يأتي كنص، أو JSON محاط بحدود، أو بيانات غير صالحة، وتصميم مخطط الاستجابة، واختيار أو تصعيد نموذج Gemini، وإعادة محاولة الأخطاء 429 أو قيود الحصة الخاصة بالنموذج، أو قرارات نموذج الفشل الاحتياطي (FallbackModel). لا تُفعَّل لهذا الغرض لقياس الجودة على مجموعة مُعلّمة (adk-agent-evaluation)، أو مخططات أسلاك SQL (adk-sql-agent-engineering)، أو صياغة التعليمات (adk-agent-instructions)، أو مخططات معلمات الأدوات (adk-tool-interface-design)، أو زمن الاستجابة على مستوى الاستضافة (optimise-adk-on-google-cloud)، أو سياسة الميزانية والتدهور (adk-operational-guardrails)، أو إعادة محاولة واجهة برمجة تطبيقات الأدوات (safe-api-tool-calls) أو ترحيل نموذج الإصدار (adk-release-engineering).

يرجى دائمًا الرد بلغة المستخدم.
