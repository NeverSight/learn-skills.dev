本番環境で Python Google ADK エージェントを計装、モニタリング、アラート設定、デバッグする：ADK が出力するスパン、メトリクス、ログとそれらの環境ゲート、ホストごとのエクスポーター、SLI、SLO、Online Monitors、BigQuery Agent Analytics、フィードバック取得、プロダクショントレースを評価ケースに変換、トレースからセッションへのデバッグ、クライアントの IT チームへの運用引き継ぎ、責任追及のないエージェント事後検証。欠落または重複したテレメトリ、トークンやコストの会計、アラート設計、ダッシュボード、ADK エージェントに関する本番インシデントに使用する。以下の目的では有効化しないでください：コンテンツリダクションポリシー (protect‑adk‑sensitive‑data)、GKE エクスポーターのホワイトリストとカスタムスパン (optimise‑adk‑on‑google‑cloud)、評価設計 (adk‑agent‑evaluation)、予算の強制 (adk‑operational‑guardrails)、カナリアリリースとロールバック (adk‑release‑engineering)、初回デプロイ (deploy‑adk‑on‑google‑cloud)、テレメトリの Terraform および CLI スキャフォールディング (Google の agents‑cli スキル)。
