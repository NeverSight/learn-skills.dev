Costruisci, adatta o revisiona l'applicazione FastAPI attorno a un agente Python Google ADK – il Runner in‑processo o la topologia gateway, la dipendenza verified‑principal per IAP o Identity Platform, percorsi di dominio filtrati per proprietario, dati dell'applicazione e migrazioni accanto alle tabelle di sessione di ADK, il contratto OpenAPI pubblico e il client generato, la gestione degli errori, CORS e intestazioni di sicurezza, e la struttura del processo Cloud Run. Usalo per percorsi backend, dati o lavoro sul contratto API in un'applicazione web ADK, incluso un percorso di dominio che restituisce i record di un altro utente. Non attivare per gli endpoint di esecuzione, streaming e sessione dell'agente (adk-frontend-integration), credenziali di strumenti, OAuth delegato o uno strumento che agisce per l'utente sbagliato (adk-tool-auth-and-secrets), hosting e IAM (deploy-adk-on-google-cloud), né per lavori FastAPI non correlati a un'applicazione ADK.
