Construye, adapta o revisa la aplicación FastAPI alrededor de un agente Python Google ADK: el Runner en proceso o la topología de puerta de enlace, la dependencia verified‑principal para IAP o Identity Platform, rutas de dominio filtradas por propietario, datos de la aplicación y migraciones junto a las tablas de sesión de ADK, el contrato público OpenAPI y el cliente generado, manejo de errores, CORS y encabezados de seguridad, y la forma del proceso Cloud Run. Úsalo para rutas del backend, datos o trabajo de contrato API en una aplicación web ADK, incluida una ruta de dominio que devuelva los registros de otro usuario. No lo actives para los endpoints de ejecución, transmisión y sesión del agente (adk‑frontend‑integration), credenciales de herramienta, OAuth delegada o una herramienta que actúe como el usuario incorrecto (adk‑tool‑auth‑and‑secrets), hosting e IAM (deploy‑adk‑on‑google‑cloud), o trabajo de FastAPI no relacionado con una aplicación ADK.
