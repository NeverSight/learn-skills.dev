Python Google ADK エージェントを中心に FastAPI アプリケーションを構築、適応、またはレビューする – インプロセス Runner またはゲートウェイトポロジー、IAP または Identity Platform 用の verified‑principal 依存性、所有者でフィルタリングされたドメインルート、ADK のセッションテーブルと併せたアプリケーションデータとマイグレーション、公開 OpenAPI 契約と生成クライアント、エラーハンドリング、CORS およびセキュリティヘッダー、そして Cloud Run のプロセス形態。ADK Web アプリケーションにおけるバックエンドルート、データ、API 契約の作業に使用し、他ユーザーのレコードを返すドメインルートを含む。エージェントの run、stream、session エンドポイント（adk-frontend-integration）、ツール認証情報、委任 OAuth、または誤ったユーザーとして動作するツール（adk-tool-auth-and-secrets）、ホスティングと IAM（deploy‑adk‑on‑google‑cloud）、あるいは ADK アプリケーションと無関係な FastAPI の作業には適用しないでください。
