Construisez, adaptez ou examinez l'application FastAPI autour d'un agent Python Google ADK – le Runner intégré ou la topologie passerelle, la dépendance verified‑principal pour IAP ou Identity Platform, les routes de domaine filtrées par propriétaire, les données de l'application et les migrations à côté des tables de session d'ADK, le contrat OpenAPI public et le client généré, la gestion des erreurs, CORS et les en‑têtes de sécurité, ainsi que la forme du processus Cloud Run. Utilisez‑le pour les routes backend, les données ou le travail de contrat d'API dans une application web ADK, y compris une route de domaine qui renvoie les enregistrements d'un autre utilisateur. Ne l'activez pas pour les points de terminaison run, stream et session de l'agent (adk‑frontend‑integration), les identifiants d'outil, l’OAuth délégué ou un outil agissant pour le mauvais utilisateur (adk‑tool‑auth‑and‑secrets), l’hébergement et IAM (deploy‑adk‑on‑google‑cloud), ou le travail FastAPI qui n’est pas lié à une application ADK.
