ابنِ أو عدّل أو راجع تطبيق FastAPI حول وكيل Python Google ADK – مع مُشغِّل داخل العملية أو طوبولوجيا البوابة، واعتمادية verified-principal لـ IAP أو منصة الهوية، ومسارات النطاق المُفلترة حسب المالك، وبيانات التطبيق والهجرات إلى جانب جداول جلسات ADK، وعقد OpenAPI العام والعميل المُولد، ومعالجة الأخطاء، وCORS ورؤوس الأمان، وشكل عملية Cloud Run. استخدمه لمسارات الواجهة الخلفية أو البيانات أو عمل عقد API في تطبيق ويب ADK، بما في ذلك مسار نطاق يُعيد سجلات مستخدم آخر. لا تُفعِّل ذلك لنقاط تشغيل الوكيل، وتدفق وجلسات (adk-frontend-integration)، أو بيانات اعتماد الأدوات، أو OAuth المفوض أو أداة تتصرف باسم المستخدم الخطأ (adk-tool-auth-and-secrets)، أو الاستضافة وإدارة الهوية (deploy-adk-on-google-cloud)، أو أعمال FastAPI غير المتعلقة بتطبيق ADK.
