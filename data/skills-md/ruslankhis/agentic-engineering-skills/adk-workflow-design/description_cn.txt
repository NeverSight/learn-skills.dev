选择、实现或审查 Google ADK 工作流的控制流、事件消费、会话状态交接、回调和检查点。在以下情况下使用：在普通代码、顺序、并行、有界循环、图形或动态编排之间进行选择，或在现有代理中修复这些运行时契约：output_key 交接时后续代理的 {key} 占位符保持字面值或抛出 KeyError，在输入更改后重新使用已保存的阶段，检查点过大而超出存储容量，运行因审批等待数天而跨重启（ADK 恢复或持久化引擎），以及在代码中进行草稿一致性检查和仅警告的纠正。不要在以下情况下激活：与 UI 编辑无关、一般 LLM 解释、独立云部署、实现 RAG、内存或 SQL 服务、指令措辞或子代理描述（adk-agent-instructions）、远程 A2A 代理或 MCP 服务器（adk-agent-interoperability），或注入威胁模型（adk-agent-security）。
