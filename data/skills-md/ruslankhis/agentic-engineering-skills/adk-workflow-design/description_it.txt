Seleziona, implementa o rivedi il flusso di controllo del workflow di Google ADK, il consumo di eventi, i passaggi di stato della sessione, i callback e i checkpoint. Usa quando scegli tra codice ordinario, sequenziale, parallelo, cicli limitati, orchestrazione a grafo o dinamica, o quando ripari quei contratti di runtime in un agente esistente: passaggi output_key in cui il segnaposto {key} di un agente successivo rimane letterale o solleva KeyError, riutilizzo di fasi salvate dopo che un input è cambiato, un checkpoint troppo grande per il suo archivio, un'esecuzione che attende giorni per l'approvazione attraverso riavvii (ripresa ADK o motore persistente), controlli di coerenza in bozza nel codice e correzioni solo di avviso. Non attivare per modifiche UI non correlate, spiegazioni generali sui LLM, distribuzione cloud autonoma, implementazione di RAG, servizi di memoria o SQL, formulazione delle istruzioni o descrizioni dei sotto‑agenti (adk-agent-instructions), agenti A2A remoti o server MCP (adk-agent-interoperability), o un modello di minaccia di iniezione (adk-agent-security). Rispondi sempre nella lingua dell'utente.
