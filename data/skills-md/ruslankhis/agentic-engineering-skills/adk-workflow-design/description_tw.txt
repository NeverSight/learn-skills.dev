選擇、實作或審查 Google ADK 工作流程的控制流程、事件消費、會話狀態交接、回呼與檢查點。於以下情況使用：在普通程式碼、順序、平行、受限迴圈、圖形或動態協調之間做選擇，或在既有代理中修復這些執行時合約：output_key 交接時後續代理的 {key} 佔位符保持字面值或拋出 KeyError、在輸入變更後重新使用已保存的階段、檢查點過大而超出儲存空間、執行因審批等待數天而在重啟後仍持續（ADK 繼續或耐久引擎）、草稿一致性檢查及僅警告的修正。請勿在與此無關的 UI 編輯、一般 LLM 說明、獨立雲端部署、實作 RAG、記憶體或 SQL 服務、指令文字或子代理描述（adk-agent-instructions）、遠端 A2A 代理或 MCP 伺服器（adk-agent-interoperability），或注入威脅模型（adk-agent-security）時啟用。
