اعمل على المتطلبات والخيارات مع المستخدم لتصميم أو مراجعة بنية نظام تطبيق Python Google ADK على GCP، قبل التنفيذ. استخدم ذلك لتصميم تطبيق جديد، أو إعادة تصميم شاملة، أو مراجعة بنية عابرة للميزات، بما في ذلك تحديد نطاق إثبات المفهوم، أو أداة داخلية أو نموذج الحد الأدنى القابل للتطبيق وفقًا للوقت والأشخاص المتاحين وتخطيط ما يُطلق أولًا وما يتبعه، وتحويل التصميم والخطة إلى اقتراح للعميل أو بيان عمل أو طلب تغيير. لا تقم بالتنفيذ قبل اختيار حالة الاستخدام وقياسها (adk-discovery)، أو لعرض القرار، حزمة النشر أو تقرير القيمة (adk-presenter)، أو لميزة جديدة في تطبيق تم قبول تصميمه بالفعل (adk-engineer)، أو لتغيير مركّز على الذاكرة أو سير العمل أو الواجهة الأمامية أو النشر (استخدم ذلك المتخصص مباشرةً).
