Trabaje a través de los requisitos y compensaciones con el usuario para diseñar o revisar la arquitectura del sistema de una aplicación Python Google ADK en GCP, antes de la implementación. Úselo para el diseño de una nueva aplicación, una reestructuración sustancial o una revisión de arquitectura transversal, incluyendo la definición del alcance de una prueba de concepto, herramienta interna o MVP, según el tiempo y las personas disponibles, planificando qué se lanza primero y qué sigue, y convirtiendo el diseño y el plan en una propuesta para el cliente, una declaración de trabajo o una solicitud de cambio. No lo active antes de que se elija un caso de uso y su medida (adk-discovery), para una presentación de decisiones, paquete de despliegue o informe de valor (adk-presenter), para una nueva funcionalidad en una aplicación cuyo diseño ya está aceptado (adk-engineer), o para un cambio enfocado de memoria, flujo de trabajo, frontend o despliegue (utilice directamente a ese especialista).
