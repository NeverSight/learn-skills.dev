Python Google ADK 에이전트를 Cloud Run, Agent Runtime 또는 GKE에 배포하는 작업을 선택, 구현, 조정 또는 감사합니다. 여기에는 아이덴티티, 패키징, 브라우저 검증, 복구 및 소유 리소스 정리 등이 포함됩니다. ADK 호스팅 결정 및 배포 수명 주기 작업에 사용합니다. 일반 Kubernetes 관리, ADK가 아닌 애플리케이션, 카나리, 롤백 또는 이후 릴리스의 평가 게이트(adk-release-engineering), 측정된 성능 튜닝(optimise-adk-on-google-cloud), 텔레메트리 및 알림(adk-agent-observability), FastAPI 라우트 및 프로세스 형태(adk-fastapi-backend), 프롬프트 전용 변경(adk-agent-instructions가 프롬프트 문구를 소유), 또는 배포 작업이 없는 RAG 및 메모리 설계에는 활성화하지 마십시오. 항상 사용자의 언어로 응답해 주세요.
