اختر، نفّذ، عدّل أو تدقق نشر عوامل Python Google ADK على Cloud Run أو Agent Runtime أو GKE، بما في ذلك الهوية، التعبئة، التحقق من المتصفح، الاستعادة وتنظيف الموارد المملوكة. استخدم ذلك لاتخاذ قرارات استضافة ADK وعمل دورة حياة النشر. لا تُفعَّل لهذا الغرض في إدارة Kubernetes العامة، التطبيقات غير المرتبطة بـ ADK، استراتيجيات الكناري، الاسترجاع أو بوابات التقييم للإصدارات اللاحقة (adk‑release‑engineering)، ضبط الأداء المقاس (optimise‑adk‑on‑google‑cloud)، القياسات والتنبيهات (adk‑agent‑observability)، مسارات FastAPI وشكل العملية (adk‑fastapi‑backend)، التغييرات التي تقتصر على النصوص (adk‑agent‑instructions تملك صياغة النص)، أو تصميم RAG والذاكرة دون مهمة نشر.
