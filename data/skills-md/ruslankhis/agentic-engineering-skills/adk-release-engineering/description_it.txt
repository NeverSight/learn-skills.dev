Progetta, implementa o verifica il ciclo di vita del rilascio di un agente Python Google ADK: versionamento di prompt e configurazione, ID modello e giudice fissati, gate di valutazione in CI con soglia, politica di ripetizione e costo, migrazione di versione del modello con re-baseline, promozione a fasi e rollback congiunto di prompt, modello, schema degli strumenti e segreti, e aggiornamento dei set di valutazione da campioni di produzione. Usalo quando il problema è un rilascio, un gate CI, una notifica di deprecazione del modello, un canary, un rollback o un set di valutazione obsoleto. Non attivarlo per un primo deployment o packaging (deploy-adk-on-google-cloud), scrittura di casi di valutazione o ciclo di iterazione (adk-agent-evaluation), scelta delle impostazioni del modello (adk-model-and-output-contracts), formulazione del prompt (adk-agent-instructions) o monitoraggio in produzione (adk-agent-observability).
