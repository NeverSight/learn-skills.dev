تشخيص أو تنفيذ أو مراجعة تحسينات Python Google ADK على Cloud Run وAgent Runtime وGKE التي تشمل عمل النموذج/الأداة، تاريخ الجلسة ونمو السياق (التقليص، التلخيص)، إكمال البث، معالجة الجلسة، بدء التشغيل، التزامن أو توسيع حجم العمل. استخدم ذلك للتغييرات المقاسة أو خطط التحسين القابلة للتنفيذ. لا تُفعَّل لهذا الغرض عند اختيار الاستضافة أو النشر الأول فقط (deploy‑adk‑on‑google‑cloud)، ولا للإدارة العامة لـ Kubernetes، ولا للذاكرة عبر الجلسات أو بنية RAG (adk‑memory‑architecture)، ولا لاختيار النموذج أو إعدادات التفكير (adk‑model‑and‑output‑contracts)، ولا لتنبيهات الإنتاج ومستويات الخدمة (adk‑agent‑observability)، ولا لأعمال الأداء غير المتعلق بـ ADK، ولا لتعديلات غير ذات صلة على الطلب وواجهة المستخدم (adk‑agent‑instructions يملك صياغة الطلب).

يرجى دائمًا الرد بلغة المستخدم.
