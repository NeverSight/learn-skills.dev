تنفيذ أو مراجعة أدوات Google ADK المصادق عليها مع ملكية المستخدم/الجلسة المتحققة عند خطوة الأداة، وصول GCP بدون مفاتيح، Secret Manager وضوابط دورة حياة OAuth المفوضة. تُستَخدم لاختيار اعتماد الأداة، الوصول عبر مستخدمين مختلفين من خلال أداة، تدفقات الموافقة/التجديد/الانقطاع أو كشف الاعتماد في أحداث الوكيل. لا تقم بالتفعيل لواجهة تسجيل الدخول العامة، اعتماد المبدأ المتحقق أو طرق HTTP المفلترة وفق المالك (adk-fastapi-backend)، نقاط نهاية جلسة الوكيل (adk-frontend-integration)، توصيلات MCP أو A2A (adk-agent-interoperability)، نماذج تهديدات الوكيل الكاملة (adk-agent-security)، فحص المحتوى للبيانات الشخصية الحساسة أو الأسرار الملصوقة (protect-adk-sensitive-data)، إدارة IAM العامة أو استكشاف مشكلات الفوترة المتعلقة بمفتاح النموذج.
