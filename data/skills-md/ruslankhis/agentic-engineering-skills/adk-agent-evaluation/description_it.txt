Costruisci, adatta o verifica la strategia di test di un agente Python ADK: tool deterministico e test Runner, set di valutazione live, conversazioni simulate, replay di conformità, controlli rigorosi dei risultati e supporto per citazioni o riferimenti. Usalo per il comportamento dell'agente, la copertura di regressione, l'affidabilità della valutazione, la correzione di una fase fallita senza rieseguire quelle precedenti a pagamento, budget di holdout, analisi degli errori su un set di sviluppo etichettato per correggere decisioni sbagliate, la misurazione di ogni prompt, esempio o modifica del modello, e l'etichettatura da parte di esperti del dominio: tassonomia dei fallimenti, accordo inter‑valutatore e calibrazione dei giudici. Non attivare per test unitari non‑agente, benchmark autonomi del modello, distribuzione o pulizia singola, formulazione del prompt o progettazione dell'esempio (adk-agent-instructions), impostazioni del modello (adk-model-and-output-contracts), integrazione dei gate di valutazione nel CI (adk-release-engineering), telemetria di produzione (adk-agent-observability), suite avverse (adk-agent-security) o presentazione dei risultati (adk-presenter).
