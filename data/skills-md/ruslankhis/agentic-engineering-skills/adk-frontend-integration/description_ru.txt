Реализовать, адаптировать, просмотреть или выбрать веб‑интерфейс для агента Google ADK с использованием пользовательского JSON API или AG‑UI с CopilotKit, включая шлюзы к управляемому Agent Runtime. Использовать для контрактов агент‑браузер, владения запуском агента, потоковых и сессионных конечных точек (перечисление, возобновление, продолжение), потокового текста и отображения инструментов, состояний UI агента (таймлайн инструмента, одобрения, ошибки после частичного ответа), настройки дизайн‑системы интерфейса ADK из внутреннего DESIGN.md с shadcn и виджетов интерфейса, которые инструменты рендерят рядом с ответом (A2UI). Не активировать для изолированных правок стилей существующей страницы, доменных маршрутов и данных приложения (adk-fastapi-backend), учётных данных инструментов (adk-tool-auth-and-secrets), действий, требующих одобрения (adk-operational-guardrails), только для подсказок агенту (adk-agent-instructions отвечает за формулировку подсказки), общего облачного развертывания или чат‑приложений, не относящихся к ADK.
