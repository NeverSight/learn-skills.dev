Implementa, adatta, revisiona o seleziona un’interfaccia web per un agente Google ADK usando una JSON API personalizzata o AG‑UI con CopilotKit, includendo gateway al runtime gestito dell’agente. Usala per contratti agente‑browser, la proprietà dell’esecuzione dell’agente, endpoint di stream e sessione (elenco, ripresa, continuazione), streaming di testo e visualizzazioni degli strumenti, stati dell’interfaccia UI dell’agente (timeline degli strumenti, approvazioni, errori dopo una risposta parziale), impostazione del sistema di design dell’interfaccia ADK dal DESIGN.md interno con shadcn e widget dell’interfaccia che gli strumenti mostrano accanto alla risposta (A2UI). Non attivare per modifiche di stile isolate a una pagina esistente, rotte di dominio e dati dell’applicazione (adk‑fastapi‑backend), credenziali degli strumenti (adk‑tool‑auth‑and‑secrets), azioni che necessitano approvazione (adk‑operational‑guardrails), solo il prompting dell’agente (adk‑agent‑instructions controlla la formulazione del prompt), provisioning cloud generale o applicazioni di chat non ADK.
