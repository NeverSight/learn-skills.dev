Implementa, adapta, revisa o selecciona una interfaz web para un agente Google ADK usando una API JSON personalizada o AG-UI con CopilotKit, incluyendo pasarelas al Runtime de Agente gestionado. Úsala para contratos agente‑navegador, la propiedad de la ejecución del agente, los puntos finales de streaming y sesión (listado, reanudación, continuación), transmisión de texto y visualización de herramientas, estados de la UI del agente (línea de tiempo de herramientas, aprobaciones, errores después de una respuesta parcial), configurar el sistema de diseño de la interfaz ADK a partir del DESIGN.md interno con shadcn, y widgets de interfaz que las herramientas renderizan junto a la respuesta (A2UI). No lo actives para ajustes de estilo aislados en una página existente, rutas de dominio y datos de la aplicación (adk‑fastapi‑backend), credenciales de herramientas (adk‑tool‑auth‑and‑secrets), acciones que requieran aprobación (adk‑operational‑guardrails), solo la generación de prompts del agente (adk‑agent‑instructions posee la redacción del prompt), aprovisionamiento general en la nube o aplicaciones de chat que no sean ADK. Por favor, responde siempre en el idioma del usuario.
