Implémentez, adaptez, examinez ou sélectionnez une interface web pour un agent Google ADK en utilisant une API JSON personnalisée ou AG-UI avec CopilotKit, en incluant les passerelles vers le runtime d'agent géré. Utilisez‑la pour les contrats agent‑navigateur, la gestion de l’exécution de l’agent, les points d’accès de flux et de session (listage, reprise, continuation), le streaming de texte et les affichages d’outils, les états UI de l’agent (chronologie des outils, approbations, erreurs après une réponse partielle), la mise en place du système de design de l’interface ADK à partir du DESIGN.md interne avec shadcn, ainsi que les widgets d’interface que les outils affichent à côté de la réponse (A2UI). N’activez pas cette interface pour des ajustements de style isolés sur une page existante, les routes de domaine et les données d’application (adk‑fastapi‑backend), les identifiants d’outil (adk‑tool‑auth‑and‑secrets), les actions nécessitant une approbation (adk‑operational‑guardrails), le seul prompt de l’agent (adk‑agent‑instructions possède la formulation du prompt), le provisionnement cloud général ou les applications de chat non‑ADK.  

Veuillez toujours répondre dans la langue de l’utilisateur.
