نفّذ، عدّل، راجع أو اختر واجهة ويب لوكيل Google ADK باستخدام API JSON مخصص أو AG-UI مع CopilotKit، بما في ذلك البوابات إلى بيئة تشغيل الوكيل المدارة. استخدم ذلك لعقود الوكيل إلى المتصفح، ملكية تشغيل الوكيل، نقاط نهاية البث والجلسة (القائمة، الاستئناف، المتابعة)، بث النص وعروض الأدوات، حالات واجهة المستخدم للوكيل (خطّ الزمان للأداة، الموافقات، الأخطاء بعد إجابة جزئية)، إعداد نظام تصميم واجهة ADK من ملف DESIGN.md الداخلي باستخدام shadcn، وودجات الواجهة التي تُظهر الأدوات بجانب الرد (A2UI). لا تُفعّل لهذا لتعديلات نمطية معزولة لصفحة موجودة، مسارات النطاق وبيانات التطبيق (adk-fastapi-backend)، بيانات اعتماد الأدوات (adk-tool-auth-and-secrets)، الإجراءات التي تحتاج موافقة (adk-operational-guardrails)، توجيه الوكيل فقط (adk-agent-instructions يملك صياغة المطالبة)، توفير سحابي عام أو تطبيقات دردشة غير متعلقة بـ ADK.  

يرجى الرد دائمًا بلغة المستخدم.
