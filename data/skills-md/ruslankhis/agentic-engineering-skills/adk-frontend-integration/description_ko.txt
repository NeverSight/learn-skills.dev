Google ADK 에이전트를 위한 웹 인터페이스를 맞춤 JSON API 또는 AG-UI와 CopilotKit을 이용해 구현, 적용, 검토 혹은 선택하고, 관리되는 Agent Runtime으로의 게이트웨이를 포함합니다. 에이전트와 브라우저 간 계약, 에이전트 실행에 대한 소유권, 스트림 및 세션 엔드포인트(목록, 재개, 계속), 스트리밍 텍스트 및 도구 표시, 에이전트 UI 상태(도구 타임라인, 승인, 부분 답변 후 오류), house DESIGN.md에서 shadcn을 활용한 ADK 인터페이스 디자인 시스템 설정 및 도구가 답변 옆에 렌더링되는 인터페이스 위젯(A2UI)을 포함합니다. 기존 페이지의 스타일 미세 조정, 도메인 라우트 및 애플리케이션 데이터(adk-fastapi-backend), 도구 자격 증명(adk-tool-auth-and-secrets), 승인 필요 작업(adk-operational-guardrails), 에이전트 프롬프트만(adk-agent-instructions가 프롬프트 문구를 소유), 일반 클라우드 프로비저닝 또는 비-ADK 채팅 애플리케이션에는 활성화하지 마십시오.
