نفّذ أو عدّل أو راجع حدود الاستدعاء، ميزانيات الرموز، حماية الأدوات المتكررة، موافقة البشر (أي الإجراءات التي تنتظر، سجلات المراجعة الدائمة، تدفق التأكيد والاستئناف) وضوابط تكلفة التطبيق في وكلاء Python Google ADK. استخدم ذلك لمنع حلقات الوكيل المتفجرة، فرض الميزانية عبر الأدوار، الإجراءات الخطرة التي تنتظر المراجعة، معدلات التصعيد وحمل صف المراجعة، الاستمرارات المدفوعة بعد فقدان الاستجابة (سجلات المحاولات)، أو إغلاق التكلفة المرحلي. لا تقم بتنشيطه لسياسة إعادة محاولة HTTP واحدة أو لإعادة تشغيل كتابة موافقة مرة واحدة (safe‑api‑tool‑calls)، نمذجة التهديدات لتحديد الأدوات الخطرة (adk‑agent‑security)، واجهة الموافقة (adk‑frontend‑integration)، اختيار أداة خاطئ أو مخططات الأدوات (adk‑tool‑interface‑design)، التحويل بين النماذج (adk‑model‑and‑output‑contracts)، لوحات التحكم في التكلفة (adk‑agent‑observability)، النشر بمفرده، تعديل النصوص فقط (adk‑agent‑instructions يملك صياغة المطالبة)، أو إدارة الفوترة السحابية العامة.
