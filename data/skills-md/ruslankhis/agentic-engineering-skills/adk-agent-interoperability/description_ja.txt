MCP と A2A を使用して、プロセス境界を越えて Python Google ADK エージェントを接続、公開、または監査する：ツールソースの選択（FunctionTool、OpenAPIToolset、McpToolset、Toolbox、Application Integration）、MCP サーバーの利用（接続、ライフサイクル、tool_filter、プレフィックス、ヘッダー、確認フラグ、SDK ピン）、エージェントを MCP サーバーとして公開、サブエージェントとリモート A2A トポロジーの決定、RemoteA2aAgent を使用したリモートエージェントの利用（エージェントカード、タスク状態、ストリーミング、タイムアウト）、to_a2a による公開と Agent Runtime または Gemini Enterprise への登録。エージェントが別のサービスやフレームワークを呼び出す必要がある、または呼び出される場合、あるいは MCP と A2A の配線を確認する場合に使用する。MCP の脅威モデル、許可リストまたはピン留めポリシー（adk-agent-security）、プロセス内オーケストレーション（adk-workflow-design）、OAuth 配管（adk-tool-auth-and-secrets）、単一 API 呼び出しのリトライポリシー（safe-api-tool-calls）またはデプロイ（deploy-adk-on-google-cloud）のために有効化しないでください。
