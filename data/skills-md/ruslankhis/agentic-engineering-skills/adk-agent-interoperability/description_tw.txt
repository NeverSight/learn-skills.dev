使用 MCP 與 A2A 在跨程序邊界連接、暴露或稽核 Python Google ADK 代理程式：工具來源選擇（FunctionTool、OpenAPIToolset、McpToolset、Toolbox、Application Integration），消費 MCP 伺服器（connection、lifecycle、tool_filter、prefixes、headers、confirmation flag、SDK pin），將代理程式暴露為 MCP 伺服器，子代理與遠端 A2A 拓撲的決策，使用 RemoteA2aAgent 消費遠端代理程式（agent cards、task states、streaming、timeouts），透過 to_a2a 暴露並在 Agent Runtime 或 Gemini Enterprise 註冊。當代理程式必須呼叫或被其他服務或框架呼叫，或需要檢視 MCP 與 A2A 連線時使用。請勿在 MCP 威脅模型、允許清單或釘選政策（adk-agent-security）、內部流程編排（adk-workflow-design）、OAuth 管道（adk-tool-auth-and-secrets）、單一 API 呼叫的重試政策（safe-api-tool-calls）或部署（deploy-adk-on-google-cloud）中啟用。
