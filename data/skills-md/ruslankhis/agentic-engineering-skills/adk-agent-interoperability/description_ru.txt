Подключайте, раскрывайте или проверяйте Python‑агенты Google ADK через границы процессов с помощью MCP и A2A: выбор источника инструмента (FunctionTool, OpenAPIToolset, McpToolset, Toolbox, Application Integration), использование MCP‑серверов (соединение, жизненный цикл, tool_filter, префиксы, заголовки, флаг подтверждения, привязка SDK), раскрытие агента в виде MCP‑сервера, решение о под‑агентах против удалённой топологии A2A, использование удалённого агента через RemoteA2aAgent (карты агента, состояния задач, потоковая передача, тайм‑ауты), раскрытие с помощью to_a2a и регистрация в Agent Runtime или Gemini Enterprise. Применяйте, когда агент должен вызывать другой сервис или быть вызванным им, либо для обзора wiring‑а MCP и A2A. Не активируйте для модели угроз MCP, списков разрешённых или политики закрепления (adk-agent-security), оркестрации в процессе (adk-workflow-design), OAuth‑интеграции (adk-tool-auth-and-secrets), политики повторных попыток одного API‑вызова (safe-api-tool-calls) или развертывания (deploy-adk-on-google-cloud).
