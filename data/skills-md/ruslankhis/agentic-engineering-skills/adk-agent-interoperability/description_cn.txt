使用 MCP 和 A2A 跨进程边界连接、暴露或审计 Python Google ADK 代理：工具来源选择（FunctionTool、OpenAPIToolset、McpToolset、Toolbox、Application Integration），使用 MCP 服务器（连接、生命周期、tool_filter、前缀、头信息、确认标志、SDK 固定），将代理暴露为 MCP 服务器，子代理与远程 A2A 拓扑的决策，使用 RemoteA2aAgent 消费远程代理（代理卡片、任务状态、流式传输、超时），通过 to_a2a 暴露并在 Agent Runtime 或 Gemini Enterprise 上注册。当代理必须调用或被其他服务或框架调用，或需要审查 MCP 和 A2A 连接时使用。不要在 MCP 威胁模型、白名单或固定策略（adk-agent-security）、进程内编排（adk-workflow-design）、OAuth 管道（adk-tool-auth-and-secrets）、单次 API 调用的重试策略（safe-api-tool-calls）或部署（deploy-adk-on-google-cloud）下激活。
