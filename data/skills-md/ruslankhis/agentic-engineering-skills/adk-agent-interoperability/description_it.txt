Connetti, esponi o verifica agenti Python Google ADK attraverso i confini di processo con MCP e A2A: selezione della sorgente degli strumenti (FunctionTool, OpenAPIToolset, McpToolset, Toolbox, Application Integration), utilizzo dei server MCP (connessione, ciclo di vita, tool_filter, prefissi, intestazioni, flag di conferma, pin SDK), esposizione di un agente come server MCP, decisione sulla topologia sub‑agenti vs A2A remoto, consumo di un agente remoto con RemoteA2aAgent (schede agente, stati dei task, streaming, timeout), esposizione con to_a2a e registrazione su Agent Runtime o Gemini Enterprise. Usa quando un agente deve chiamare o essere chiamato da un altro servizio o framework, o per rivedere il cablaggio MCP e A2A. Non attivare per il modello di minaccia MCP, le whitelist o la policy di pinning (adk-agent-security), l’orchestrazione in‑processo (adk-workflow-design), la gestione OAuth (adk-tool-auth-and-secrets), la policy di retry di una chiamata API (safe-api-tool-calls) o il deployment (deploy-adk-on-google-cloud).
