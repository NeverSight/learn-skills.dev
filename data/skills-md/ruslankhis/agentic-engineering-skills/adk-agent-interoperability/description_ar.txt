الاتصال أو التعريض أو تدقيق وكلاء Python Google ADK عبر حدود العمليات باستخدام MCP و A2A: اختيار مصدر الأداة (FunctionTool، OpenAPIToolset، McpToolset، Toolbox، Application Integration)، استهلاك خوادم MCP (الاتصال، دورة الحياة، tool_filter، البوادئ، الرؤوس، علم التأكيد، تثبيت SDK)، تعريض وكيل كخادم MCP، قرار بين الوكلاء الفرعيين مقابل طوبولوجيا A2A البعيدة، استهلاك وكيل بعيد عبر RemoteA2aAgent (بطاقات الوكيل، حالات المهمة، البث، مهلات الوقت)، التعريض باستخدام to_a2a وتسجيله على Agent Runtime أو Gemini Enterprise. يُست‑خدم عندما يجب على الوكيل أن يستدعي خدمة أخرى أو يُستدعى منها، أو لمراجعة توصيلات MCP و A2A. لا تُفعَّل لنموذج تهديد MCP، قوائم السماح أو سياسة التثبيت (adk-agent-security)، التنسيق داخل العملية (adk-workflow-design)، توصيل OAuth (adk-tool-auth-and-secrets)، سياسة إعادة المحاولة لاستدعاء API واحد (safe-api-tool-calls) أو النشر (deploy-adk-on-google-cloud).
