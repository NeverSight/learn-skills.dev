Python Google ADK エージェントにおけるメモリと検索の設計、実装、適応、または監査を行う。会話セッション／状態、ガバナンスされた RAG、Agent Platform Memory Bank、スコープされた BigQuery 履歴を選択・組み合わせ、身元、同意、保持、再生、消去の境界を強制する。エージェントのメモリ、知識検索、検索用ドキュメントの準備（スキャン、テーブル、図面のページ単位インジェストのトリアージ、OCR やビジョン・ルーティング、カバレッジチェック）やセッション間の継続性作業に使用する。一般的なデータベース管理、自然言語 SQL エージェント（adk-sql-agent-engineering）、レイテンシやトークン削減のためのセッション内履歴のトリミングまたは要約（optimise‑adk‑on‑google‑cloud）、再試行時の外部書き込みの重複（safe‑api‑tool‑calls）、デプロイのみ、プロンプトのみの編集（adk‑agent‑instructions がプロンプト文言を所有）やエージェント以外のキャッシュには使用しない。
