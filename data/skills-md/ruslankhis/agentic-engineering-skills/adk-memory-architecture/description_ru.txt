Разрабатывайте, внедряйте, адаптируйте или проводите аудит памяти и извлечения данных в Python‑агентах Google ADK. Выбирайте и комбинируйте сеансы/состояния разговоров, управляемый RAG, Agent Platform Memory Bank и ограниченную историю BigQuery; обеспечивайте границы идентификации, согласия, удержания, воспроизведения и стирания. Используйте для памяти агента, поиска знаний, подготовки документов к извлечению (триаж постраничного загрузки сканов, таблиц и чертежей, OCR или маршрутизация по зрительным данным, проверка охвата) или для обеспечения непрерывности между сессиями. Не активируйте для общей администрирования баз данных, агентов естественного языка для SQL (adk-sql-agent-engineering), обрезки или суммирования истории в сеансе для снижения задержки или токенов (optimise-adk-on-google-cloud), дублирования внешних записей при повторных попытках (safe-api-tool-calls), только развертывания, редактирования только подсказок (adk-agent-instructions отвечает за формулировку подсказки) или кэширования без участия агента.
