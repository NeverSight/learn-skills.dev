تصميم، تنفيذ، تعديل أو تدقيق الذاكرة والاسترجاع في وكلاء Python Google ADK. اختيار ودمج جلسات/حالات المحادثة، RAG المحكم، بنك ذاكرة منصة الوكيل، وتاريخ BigQuery المخصص؛ تطبيق حدود الهوية، الموافقة، الاحتفاظ، الإعادة والمسح. الاستخدام للذاكرة الوكيلية، استرجاع المعرفة، إعداد المستندات للاسترجاع (تصنيف استهلاك الصفحات للماسحات، الجداول والرسومات، OCR أو توجيه الرؤية، فحص التغطية) أو عمل استمرارية عبر الجلسات. لا تُفعَّل للإدارة العامة لقواعد البيانات، وكلاء SQL بلغة طبيعية (adk-sql-agent-engineering)، تقليم أو تلخيص سجل الجلسة لتقليل الكمون أو الرموز (optimise-adk-on-google-cloud)، كتابة مكررة خارجية عند إعادة المحاولة (safe-api-tool-calls)، النشر بمفرده، تحرير الموجه فقط (adk-agent-instructions يملك صياغة الموجه) أو التخزين المؤقت غير الوكيل.

يرجى دائمًا الرد بلغة المستخدم.
