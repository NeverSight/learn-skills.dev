Ayuda a diseñar, construir, modificar o revisar una aplicación Python Google ADK seleccionando las habilidades especializadas de Ingeniería Agéntica correspondientes. Úsalo como punto de partida para una solicitud de ingeniería ADK cuando el usuario no haya elegido un especialista, o cuando un cambio abarque varios aspectos de ADK, incluido planificar una nueva función a través de la interfaz, el backend, las sesiones y el alojamiento de una aplicación existente (adk-system-designer es para una aplicación nueva o un rediseño sustancial). Para una tarea enfocada ya cubierta por un especialista activo, continúa directamente con esa habilidad.
