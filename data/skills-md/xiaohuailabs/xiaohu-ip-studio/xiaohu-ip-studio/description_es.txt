Habilidad de ilustración china de código abierto + biblioteca de personajes IP. Utilizando el método “seleccionar ancla cognitiva → crear metáfora al instante → revisión inversa de PPT”, genera ilustraciones para el texto principal de artículos chinos en profundidad / desgloses de métodos realizadas por personajes fijos (no ilustraciones genéricas, no selecciones de biblioteca de estilos). Incluye 31 personajes IP originales (15 bocetos lineales dibujados a mano + 16 juegos de palabras homófonos de memes); al ilustrar, elige un personaje que coincida con el tono del artículo o crea uno propio. Se usa cuando el usuario dice “ilustrar”, “ilustración del texto principal”, “ilustración IP”, “dar esta artículo una ilustración”, “ilustración metafórica”, “elegir un personaje para ilustrar” o “lista de tomas de ilustración”.

Por favor, siempre responda en el idioma del usuario.
