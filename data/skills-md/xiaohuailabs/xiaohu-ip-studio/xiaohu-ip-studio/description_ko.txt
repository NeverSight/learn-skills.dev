오픈소스 중국어 일러스트 스킬 + IP 캐릭터 라이브러리. “인지 앵커 선택 → 즉석에서 은유 만들기 → 역 PPT 자체 점검” 방식을 사용하여 고정된 캐릭터가 포함된 본문 일러스트를 생성합니다(일반 일러스트가 아니라 심층적인 중국어 기사나 방법론 분해용). 31개의 원본 IP 캐릭터(손으로 그린 라인 스케치 15개 + 동음이의어 밈 16개)가 제공되며, 일러스트를 만들 때 기사 톤에 맞는 캐릭터를 선택하거나 직접 캐릭터를 만들 수 있습니다. 사용자가 “일러스트 제작”, “본문 일러스트”, “IP 일러스트”, “이 기사에 일러스트 제공”, “은유 일러스트”, “일러스트용 캐릭터 선택”, “일러스트 샷 리스트”라고 말할 때 사용됩니다.
