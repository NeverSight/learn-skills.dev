Открытый навык китайской иллюстрации + библиотека IP‑персонажей. С помощью метода «выбрать когнитивный якорь → создать метафору → обратная проверка PPT» генерируются основные иллюстрации для углублённых китайских статей/разборов методов, с использованием фиксированных персонажей (не обычные стоковые изображения, не выбор из стиль‑библиотеки). Включает 31 оригинальный IP‑персонаж (15 вручную нарисованных линейных эскизов + 16 мемов‑каламбуров); при создании иллюстрации выбирайте персонажа, соответствующего тону статьи, либо можете создать своего. Это используется, когда пользователь говорит «иллюстрировать», «главная иллюстрация», «IP‑иллюстрация», «дать этой статье иллюстрацию», «иллюстрация‑метафора», «выбрать персонажа для иллюстрации» или «список кадров иллюстрации».
