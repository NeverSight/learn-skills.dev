Open-Source‑chinesische Illustrationsfähigkeiten + IP‑Charakterbibliothek. Mit der Methode „Kognitiven Anker auswählen → Sofort Metapher erstellen → Reverse‑PPT‑Selbstprüfung“ werden Haupttext‑Illustrationen für tiefgehende chinesische Artikel oder Methodenanalyse erstellt, ausgeführt von fest definierten Charakteren (keine generischen Illustrationen, keine Stil‑Auswahl aus einer Bibliothek). Sie enthält 31 originale IP‑Charaktere (15 handgezeichnete Linien‑Skizzen + 16 homophone Wort‑Spiel‑Memes); beim Illustrieren wähle einen Charakter, der zum Ton des Artikels passt, oder erstelle deinen eigenen Charakter. Verwende dies, wenn der Nutzer sagt „illustrate“, „text illustration“, „IP illustration“, „illustrate this article“, „metaphor illustration“, „choose a character illustration“ oder „illustration shot list“.

Bitte immer in der Sprache des Benutzers antworten.
