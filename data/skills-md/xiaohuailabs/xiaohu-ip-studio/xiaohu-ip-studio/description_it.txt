Skill di illustrazione cinese open-source + libreria di personaggi IP. Utilizzando il metodo “seleziona ancoraggio cognitivo → crea metafora sul momento → auto‑verifica PPT inversa”, genera illustrazioni per il testo principale con personaggi fissi per articoli cinesi approfonditi o scomposizioni di metodi (non illustrazioni generiche, non selezioni da libreria di stili). Include 31 personaggi IP originali (15 schizzi a mano disegnati + 16 giochi di parole omofonici meme); quando si illustra, scegli un personaggio che corrisponda al tono dell'articolo, oppure puoi crearne uno tuo. Viene usato quando l'utente dice “illustrare”, “illustrazione testo principale”, “illustrazione IP”, “fornire illustrazione per questo articolo”, “illustrazione metaforica”, “scegliere un personaggio per l'illustrazione” o “lista di inquadrature dell'illustrazione”.

Rispondi sempre nella lingua dell'utente.
