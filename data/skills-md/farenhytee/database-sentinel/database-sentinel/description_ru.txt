Многофункциональный аудитор безопасности баз данных с поддержкой нескольких бэкендов. Проверяет Supabase, Firebase (Firestore/RTDB/Storage/Functions/Remote Config), MongoDB (самостоятельно развернутый + Atlas), самостоятельный PostgreSQL и самостоятельный MySQL на наличие неправильных конфигураций RLS/правил, раскрытых учётных данных, обходов аутентификации, уязвимостей MongoBleed (CVE‑2025‑14847), pgBouncer CVE‑2025‑12819, дрейфа mysql_native_password, «призрачной» аутентификации и утечек хранилища. Используйте эту функцию каждый раз, когда пользователь упоминает безопасность баз данных, аудит RLS или правил, обзор безопасности, тестирование проникновения в приложение, проверку, раскрыта ли их БД, укрепление бэкенда, исправление правил безопасности или аудит приложений, построенных с помощью Lovable/Bolt/Replit/Cursor/Claude Code на любых из этих бэкендов. Активируется по фразам типа «мое приложение безопасно», «проверьте мою базу данных», «аудитировать мой Firebase», «аудитировать мой MongoDB», «аудитировать мой Postgres», «аудитировать мой Supabase», «моя БД раскрыта», или любой аналогичный запрос («аудитировать весь стек»).

Всегда отвечайте на языке пользователя.
