مدقق أمان قواعد البيانات متعدد الخلفيات. يدقق Supabase، Firebase (Firestore/RTDB/Storage/Functions/Remote Config)، MongoDB (المستضاف ذاتيًا + Atlas)، PostgreSQL المستضاف ذاتيًا، وMySQL المستضاف ذاتيًا لاكتشاف أخطاء تكوين RLS/القواعد، الاعتماديات المكشوفة، تجاوزات المصادقة، MongoBleed (CVE-2025-14847)، pgBouncer CVE-2025-12819، انحراف mysql_native_password، المصادقة الوهمية، وتسريبات التخزين. استخدم هذه المهارة كلما ذكر المستخدم أمان قواعد البيانات، تدقيق RLS أو القواعد، مراجعة أمان، اختبار اختراق لتطبيق مكتوب بـ vibe، التحقق مما إذا كانت قاعدة بياناته مكشوفة، تعزيز أمان الخلفية، إصلاح قواعد الأمان، أو تدقيق التطبيقات المبنية باستخدام Lovable/Bolt/Replit/Cursor/Claude Code على أي من هذه الخلفيات. يتم التفعيل عند عبارات مثل "هل تطبيقي آمن"، "تحقق من قاعدة بياناتي"، "تدقيق Firebase الخاص بي"، "تدقيق MongoDB الخاص بي"، "تدقيق Postgres الخاص بي"، "تدقيق Supabase الخاص بي"، "هل قاعدة بياناتي مكشوفة"، أو أي صيغة متعددة الخلفيات مثل "تدقيق كامل المكدس". 

يرجى دائمًا الرد بلغة المستخدم.
