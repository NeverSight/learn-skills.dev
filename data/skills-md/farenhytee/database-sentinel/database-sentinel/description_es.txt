Auditor de seguridad de bases de datos multi‑backend. Audita Supabase, Firebase (Firestore/RTDB/Storage/Functions/Remote Config), MongoDB (autohospedado + Atlas), PostgreSQL autohospedado y MySQL autohospedado en busca de configuraciones erróneas de RLS/reglas, credenciales expuestas, vulnerabilidades de elusión de autenticación, MongoBleed (CVE‑2025‑14847), pgBouncer CVE‑2025‑12819, desviación de mysql_native_password, autenticación fantasma y exposiciones de almacenamiento. Usa esta habilidad siempre que el usuario mencione seguridad de bases de datos, auditorías de RLS o de reglas, revisión de seguridad, pruebas de penetración de una aplicación codificada con Vibe, verificación de si su base de datos está expuesta, endurecimiento de un backend, corrección de reglas de seguridad o auditoría de aplicaciones construidas con Lovable/Bolt/Replit/Cursor/Claude Code en cualquiera de estos backends. Se activa con frases como “¿mi app es segura?”, “revisa mi base de datos”, “audita mi Firebase”, “audita mi MongoDB”, “audita mi Postgres”, “audita mi Supabase”, “¿mi BD está expuesta?” o cualquier variante multi‑backend (“audita mi stack completo”).
