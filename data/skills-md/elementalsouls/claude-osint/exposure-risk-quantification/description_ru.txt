Количественная оценка воздействия, согласованная с FAIR: превращает кучу результатов разведки в оправданную оценку риска организации 0-100 + A-F (Вероятность x Влияние, три фактора, учитывающие право собственности: подверженность/угроза/воздействие), предел понижения в должности с доказательством владения и доказательства, чтобы недоказанные или слабо владеемые результаты не могли завышать число, выраженная в долларах оценка FAIR FAIR (диапазоны стоимости каждой записи IBM/Ponemon, дедупликация записей из разных источников, ежегодная обработка факторов угроз), усиление пути атаки (кураторский каталог цепочки красной команды + общий механизм обхода по графу, с цепочкой убийств и воротами честности с общей судьбой) и готовый к доске одностраничный результат (геройский доллар + буквенная оценка + топ-3 вывода + главный путь атаки + вопрос). Расширяет рубрику серьезности osint-методологии и шаблоны результатов для клиентов с помощью количественной оценки. Только пассивный анализ — работает на основе уже собранных результатов, без целевого трафика и ключей API. Используйте, когда вас просят оценить риск, количественно оценить степень риска, оценить стоимость нарушения, составить отчет для совета директоров, перевести технические выводы в доллары или объяснить, почему оценка в долларах оказалась именно такой.
