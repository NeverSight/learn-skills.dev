Сопоставление структуры идентификации на уровне организации: снятие отпечатков пальцев клиента/федерации и методология Oracle ENUMERATION перед аутентификацией пользователя — только перечисление и отпечаток пальца, но не отправка учетных данных. Охватывает разрешение домен-арендатор (Microsoft getuserrealm.srf проверка управляемого/федеративного пространства имен, извлечение GUID клиента метаданных Entra OIDC, Autodiscover v2), сопоставление федерации арендаторов Microsoft без ключа (GetFederationInformation SOAP -> обнаружение родственных доменов, ROE только для обнаружения, граница происхождения FEDERATED_WITH удерживается вне поворота пути атаки), Okta org-slug деривация + отпечаток OIDC + управляемое перечисление пользовательского домена, пассивный/активный отпечаток ADFS + выведение версии, обнаружение, связанное с Google Workspace MX, общее обнаружение OIDC (Auth0/Keycloak/Ping Identity/OneLogin/Duo), метаданные SAML (5 путей), обнаружение вызова Azure AD Seamless-SSO Negotiate, Microsoft Defender for Identity (MDI) проверка присутствия датчика-API, методология Oracle перечисления пользователей для Microsoft GetCredentialType (семантика IfExistsResult: существует/не существует/существует в федеративном клиенте/регулируется) и Okta /api/v1/authn (дифференциал errorCode), дисциплина средней обнаруживаемости с жестким ограничением в 20 кандидатов на каждого арендатора и ранжированием на основе интересов администратора/роли, а также синтезом имени x подтвержденного шаблона электронной почты это FAILS CLOSED с нулевым выходом, когда ни одна организационная структура не подтверждена. Основано непосредственно на модулях sso_idp.py, tenant_recon.py и core/email_patterns.py производственной реализации ASM. Углубляет, а не дублирует, ссылку на конечную точку Identity Fabric навыка нападения-осинта с помощью MAP федерации арендаторов, WORKFLOW оракула и методологии кандидата-СИНТЕЗА, которой нет в ссылке. Используйте при снятии отпечатков пальцев с поставщика удостоверений организации, сопоставлении ее границ клиента/федерации, запуске авторизованного прохода перечисления пользователей перед аутентификацией или синтезе кандидатов для входа на основе собранных имен для передачи этому оракулу — никогда для распыления паролей, отправки учетных данных или обхода аутентификации.
