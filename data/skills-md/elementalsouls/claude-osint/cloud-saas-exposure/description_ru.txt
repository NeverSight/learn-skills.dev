Обнаружение поверхностей атак в облаке и цепочке поставок на уровне организации: обнаружение корзины BLOB-объектов S3/GCS/Azure с помощью анализа наблюдаемых имен (CNAME/cert-SAN/Wayback) и ограниченной двухклассовой перестановки (6 префиксов x 15 суффиксов в доверенных токенах, ограниченное целевое расширение в основах поддоменов), существование (HEAD/GET) и подтверждение публичного списка, сортировка ключей объекта по 9 уровням значений. (дампы базы данных, учетные данные, состояние IaC, kubeconfig, каталоги VCS, конфигурация, архивы, PII, журналы), обнаружение захвата корзины висячего CNAME и модель серьезности на основе владения, которая не позволяет общедоступной корзине, не имеющей атрибутов, стать ложным КРИТИЧЕСКИМ; полностью автономное восстановление идентификатора аккаунта AWS из утекшего ключа доступа AKIA/ASIA/AROA (декодирование base32, работоспособная stdlib Python, канонический тестовый вектор, проверка идентификатора примера документации AWS); подтверждение путаницы зависимостей для npm/PyPI (классификатор внутреннего сигнала — привязка частного реестра и соответствие пространства имен организации — в сочетании с проверкой 404 общедоступного реестра только для чтения и нюансом возможности утверждения области npm, который API общедоступного поиска пропускает); и пассивное снятие отпечатков пальцев на уровне облака/контейнера/Kubernetes/CI (URL-адреса Lambda, шлюз API, Cloud Run, служба приложений, kubelet/etcd/K8s API/панель мониторинга, компакт-диск Jenkins/GitLab/Argo) в качестве поверхности для атрибуции организации и воздействия. Только пассивное/обнаружение – без эксплуатации, без отправки учетных данных, без активного подтверждения плоскости управления (активный уровень validate_cloud этапа 6 описан, но выходит за рамки). Используйте при подсчете объема целевого облачного хранилища, восстановлении идентификатора учетной записи AWS из утекшего ключа, подтверждении вектора путаницы в зависимостях цепочки поставок или снятии отпечатков пальцев облачной инфраструктуры/инфраструктуры K8s/CI для авторизованного внешнего разведывательного взаимодействия.
