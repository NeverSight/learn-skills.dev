Превращает однократную внешнюю разведку в программу непрерывного мониторинга. Охватывает запланированный цикл повторного сканирования и сравнения (базовый снимок -> интервал ожидания -> повторное сканирование -> дельта актива/поиска -> оповещение веб-перехватчика с пороговым значением), механизм сравнения сканирования (новые/удаленные/измененные активы по таблице отслеживаемых атрибутов, новые/обнаруженные результаты по стабильному отпечатку перекрестного сканирования), мониторинг CTI/информации противника по шести общедоступным каналам (ransomwatch, ransomware.live, Поиск HackerNews Algolia, RSS-субреддит безопасности Reddit, поиск кода GitHub Gist, очистка общедоступных каналов Telegram) с механизмом серьезности с учетом типа источника (уровни сайта утечки/форума/telegram/вставки, КРИТИЧЕСКИЙ через INFO), сопоставление шаблонов списков наблюдения по буквам/глобам/регулярным выражениям, полный захват с ретроактивным повторным сканированием новых записей списка наблюдения, дисциплина отслеживания инфраструктуры с течением времени (прозрачность сертификатов, пассивный DNS, порты/сервисы и периодичность перенумерации опечаток, а также то, как выглядит настоящее событие «дрейфа периметра» в выходных данных различий), конечный автомат жизненного цикла поиска с пятью состояниями (открытый/сортированный/риск_принятый/разрешенный/ложный_положительный) с соглашением об уровне обслуживания для каждой серьезности и дедупликацией перекрестного сканирования на основе отпечатков пальцев и правилами автоматического разрешения/повторного открытия, ловушка усталости предупреждений, когда правило, не учитывающее жизненный цикл, повторно активируется при уже принятом обнаружении, устойчивый шаблон повторной попытки/отсрочки отправки оповещений («в очереди не доставлен») и копирование и вставка рецептов bash-cron плюс PowerShell-Scheduled-Task для цикла повторного сканирования + сравнения с формой полезной нагрузки веб-перехватчика, совместимой со Slack. Только пассивный OSINT и анализ — никаких новых методов активного вторжения. Используйте при настройке постоянного мониторинга для участия в контракте или MSSP, настройке пороговых значений оповещений, чтобы избежать утомления, сортировке статуса жизненного цикла обнаружения, расследовании болтовни противников о бренде, составлении отчета «что изменилось по периметру с прошлой недели» или принятии решения о том, следует ли повторное оповещение о сохраняющемся обнаружении.
