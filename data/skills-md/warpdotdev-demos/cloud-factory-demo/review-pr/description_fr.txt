Examinez une PR à partir des artefacts de diff annotés locaux et rédigez un review.json validé pour le workflow de publication. Utilisez-le pour une révision de PR lisible par machine au lieu de la publier directement sur GitHub. Optionnellement, intégrez les résultats de vérification du comportement d’utilisation de l’ordinateur dans le même review.json pour les changements d’interface utilisateur.

Veuillez toujours répondre dans la langue de l’utilisateur.
