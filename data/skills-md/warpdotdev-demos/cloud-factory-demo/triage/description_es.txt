Triar un problema entrante de GitHub, Jira, Linear u otro rastreador de incidencias contra la base de código actual y los problemas abiertos relacionados, y luego devolver una decisión estructurada con exactamente un estado de preparación para la implementación. Utilízalo siempre que el usuario solicite triage, clasificar, evaluar, priorizar o etiquetar un problema para determinar su preparación para la implementación, especialmente cuando se proporcione una URL, clave o número del problema en la solicitud. Para errores de UI o interactivos, opcionalmente invoca la habilidad verify‑behavior como subagente de uso de la nube para reproducir el problema antes de decidir.

Por favor, responde siempre en el idioma del usuario.
