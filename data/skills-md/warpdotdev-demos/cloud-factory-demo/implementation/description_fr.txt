Implémentez un correctif ou une fonctionnalité depuis un ticket GitHub, Jira, Linear ou tout autre outil de suivi d'incidents en récupérant le contexte du ticket, en inspectant le code actuel, en apportant des modifications au code, en les validant, en vérifiant le comportement visuel de l'interface utilisateur avec la compétence verify-behavior de l'outil d'utilisation de l'ordinateur lorsqu'applicable, en ouvrant une pull request sur GitHub et en rapportant l'avancement au ticket original.

Veuillez toujours répondre dans la langue de l'utilisateur.
