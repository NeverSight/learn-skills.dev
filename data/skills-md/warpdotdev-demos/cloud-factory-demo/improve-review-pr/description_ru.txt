Ежедневный внешний цикл, который анализирует реакции людей на автоматические комментарии review‑pr, синтезирует устойчивые организационные знания и открывает PR для обновления навыка review‑pr, когда обратная связь стоит запомнить. Используйте при улучшении качества код‑ревью на основе человеческой обратной связи, проведении запланированного ретроспективного обзора навыка review или внедрении исправлений мейнтейнеров в рекомендации по ревью.
