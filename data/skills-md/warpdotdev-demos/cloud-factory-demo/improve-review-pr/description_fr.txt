Boucle externe quotidienne qui examine les réactions humaines aux commentaires automatisés de review‑pr, synthétise des connaissances organisationnelles durables et ouvre une PR pour mettre à jour la compétence review‑pr lorsque le feedback mérite d’être conservé. À utiliser pour améliorer la qualité des revues de code à partir des retours humains, réaliser une rétrospective planifiée de la compétence de revue ou intégrer les corrections des mainteneurs dans les directives de revue.
