Пятнадцать Картинах Царства — руководство по созданию короткометражных анимаций MG с помощью кода. Пользователь указывает желаемое чувство (техничное, мощное, изысканное, милое …); вы определяете стиль, технику и инструменты для создания оригинального короткометражного ролика. Текущие карточки стилей включают: плоский вектор, одинарный штрих, изометрический 2.5D, 3D‑текстура, покадровая рисованная анимация, коллаж, жидкость, морфинг, Баухаус, ретро‑неон/VHS, матовое стекло, типографика названия шоу‑варьете, образовательный стикер, пиксель‑арт, кибер‑HUD, бумажный силуэт‑тень; если нужного стиля нет в карточках, сначала создайте черновую карточку по шаблону, а затем приступайте к работе. Каждый элемент контента создаётся заново, не основывается на готовом шаблоне. Инструменты подбираются для каждой сцены: в основном Canvas 2D; истинный 3D реализуется через Three.js; карточки линз из video‑shotcraft рендерятся отдельно с помощью Remotion; существующие видеоматериалы вставляются напрямую. Предоставляется каркас (покадровый рендеринг, экспорт в MP4, композиция музыки, автоматическая проверка качества, склейка нескольких сегментов, сравнение рядом), а также референсные работы. Используйте это, когда пользователь хочет создать анимированный короткометражный ролик, MG‑анимацию, промо‑видео, заставку, образовательный объяснительный ролик, интро для TikTok, сборник стилей или любой из перечисленных стилей.
