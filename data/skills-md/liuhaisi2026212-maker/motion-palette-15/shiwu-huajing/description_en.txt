Fifteen Paintings Realm — a craft guide for creating MG short‑form animation videos with code. The user states the desired feeling (techy, impactful, sophisticated, cute, …); you determine the style, technique, and tools to produce an original short. Current style cards include: flat vector, single‑stroke line, isometric 2.5D, 3D texture, frame‑by‑frame hand‑drawn, collage, liquid, morphing, Bauhaus, retro neon/VHS, frosted glass, variety‑show title typography, educational sticker, pixel art, cyber HUD, paper‑cut shadow‑puppet; for styles not in the cards, first draft a card using the template before proceeding. Each piece of content is new every time, not based on a template. Tools are chosen per scene: primarily Canvas 2D; true 3D uses Three.js; lens cards from video‑shotcraft are rendered separately with Remotion; existing videos are spliced in directly. A scaffold is provided (frame‑by‑frame rendering, MP4 export, music composition, automated health‑check, multi‑segment stitching, side‑by‑side comparison) together with reference works. Use this when the user wants to make an animated short, MG animation, promo video, opening sequence, educational explainer animation, TikTok intro, style compilation, or any of the listed styles.
