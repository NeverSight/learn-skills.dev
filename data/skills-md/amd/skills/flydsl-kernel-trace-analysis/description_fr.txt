Profiler les kernels GPU avec rocprofv3 pour collecter des traces au niveau des instructions ATT, puis analyser les données de trace avec hotspot_analyzer.py afin d’identifier les K principaux points de blocage (VMEM‑load, VMEM‑wait, LDS/SMEM‑wait, barrière, blocages MFMA) mappés aux lignes source, et produire un plan d’optimisation exploitable. Analyse également les CSV de compteurs PMC de rocprofv3 (taux de hit L2, lectures partielles, sur‑fetch). Utilisation : /kernel-trace-analysis <cmd> Peut aussi analyser directement un répertoire de dispatch existant : /kernel-trace-analysis --dir <path>
