Perfilado de kernels GPU con rocprofv3 para recopilar trazas de instrucciones a nivel ATT, luego analizar los datos de trazas usando hotspot_analyzer.py para identificar los top‑K hotspots de stalls (VMEM-load, VMEM-wait, LDS/SMEM-wait, barrier, MFMA stalls) mapeados a las líneas de código fuente y producir un plan de optimización accionable. También analiza los CSV de contadores PMC de rocprofv3 (tasa de aciertos L2, lecturas parciales, over‑fetch). Uso: /kernel-trace-analysis <cmd> También puede analizar directamente un directorio de dispatch existente: /kernel-trace-analysis --dir <path>
