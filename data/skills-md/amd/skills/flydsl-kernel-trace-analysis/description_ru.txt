Профилирование GPU‑ядра с использованием rocprofv3 для сбора трассировок инструкций уровня ATT, затем анализ данных трассировки с помощью hotspot_analyzer.py для выявления топ‑K точек задержки (VMEM‑load, VMEM‑wait, LDS/SMEM‑wait, барьер, задержки MFMA), сопоставленных с строками исходного кода, и составления практического плана оптимизации. Также анализирует CSV‑файлы счётчиков PMC rocprofv3 (коэффициент попадания в L2, частичные чтения, переборы). Использование: /kernel-trace-analysis <cmd> Можно также проанализировать существующий каталог диспетчеров напрямую: /kernel-trace-analysis --dir <path>
