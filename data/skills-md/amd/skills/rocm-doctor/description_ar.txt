يشخّص سبب تعطل ROCm أو مجموعة تطوير HIP أو PyTorch أو llama.cpp على بطاقة AMD GPU في لينكس أو ويندوز أو WSL2، ثم يطبّق إصلاحًا منخفض المخاطرة بموافقة المستخدم أو يقدّم الخطوة التالية الدقيقة. كما يوجه مشكلات Lemonade و LM Studio و Ollama إلى القناة الأصلية المناسبة. يُستَخدم عندما يُبلّغ المستخدم أن ROCm أو HIP "لا يعمل"، أو أن torch.cuda.is_available() تُعيد False، أو أن rocminfo / hipInfo لا يمكنهما رؤية الـ GPU، أو يصادف الأخطاء hipErrorNoBinaryForGpu، HSA_STATUS_ERROR_INVALID_ISA، "invalid device function"، "no kernel image is available"، عدم القدرة على فتح /dev/kfd، رفض الإذن على /dev/kfd، "ROCk module is NOT loaded"، فقدان libamdhip64.so / amdhip64_6.dll / hipblas.dll / vcruntime140_1.dll، خطأ صفحة HSA_OVERRIDE_GFX_VERSION، تعطل iGPU+dGPU، حاوية لا ترى الـ GPU، أو فشل amdgpu-install / DKMS. مدعوم بأوامر سطر التحكم `rocm` (`rocm examine` / `rocm diagnose` / `rocm fix`)؛ هذه المهارة واجهة خفيفة فوق تلك الأوامر، ليست إعادة تنفيذ.  
الرجاء دائمًا الرد بلغة المستخدم.
