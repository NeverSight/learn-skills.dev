Диагностирует, почему ROCm, SDK HIP, PyTorch или llama.cpp не работают на графическом процессоре AMD в Linux, Windows или WSL2, затем применяет мало­рисковое исправление с согласия пользователя или сообщает точный следующий шаг. Также перенаправляет проблемы Lemonade, LM Studio и Ollama в соответствующий upstream‑канал. Используется, когда пользователь сообщает, что ROCm или HIP «не работает», torch.cuda.is_available() возвращает False, rocminfo/hipInfo не видит GPU, появляется ошибка hipErrorNoBinaryForGpu, HSA_STATUS_ERROR_INVALID_ISA, «invalid device function», «no kernel image is available», невозможно открыть /dev/kfd, отказ в доступе к /dev/kfd, «ROCk module is NOT loaded», отсутствует libamdhip64.so / amdhip64_6.dll / hipblas.dll / vcruntime140_1.dll, сбой страницы HSA_OVERRIDE_GFX_VERSION, падение iGPU+dGPU, контейнер не видит GPU или ошибка amdgpu‑install / DKMS. Поддерживается CLI‑утилитой `rocm` (`rocm examine` / `rocm diagnose` / `rocm fix`); данное умение представляет собой простой драйвер над этими командами, а не пере­реализацию.
