Diagnostica perché ROCm, l'SDK HIP, PyTorch o llama.cpp non funzionano su una GPU AMD su Linux, Windows o WSL2, quindi applica una correzione a basso rischio con consenso o restituisce il passo successivo esatto. Inoltra inoltre i problemi di Lemonade, LM Studio e Ollama al canale upstream corretto. Utilizzare quando l'utente segnala che ROCm o HIP "non funzionano", torch.cuda.is_available() restituisce False, rocminfo / hipInfo non vedono la GPU, o si verificano errori come hipErrorNoBinaryForGpu, HSA_STATUS_ERROR_INVALID_ISA, "invalid device function", "no kernel image is available", impossibilità di aprire /dev/kfd, permesso negato su /dev/kfd, "ROCk module is NOT loaded", una libreria mancante libamdhip64.so / amdhip64_6.dll / hipblas.dll / vcruntime140_1.dll, un page fault HSA_OVERRIDE_GFX_VERSION, un crash iGPU+dGPU, un container che non vede la GPU, o un fallimento di amdgpu‑install / DKMS. Supportato dalla CLI `rocm` (`rocm examine` / `rocm diagnose` / `rocm fix`); questa skill è un driver sottile su quei comandi, non una reimplementazione.

Rispondi sempre nella lingua dell'utente.
