Linux, Windows 또는 WSL2에서 AMD GPU에 대해 ROCm, HIP SDK, PyTorch 또는 llama.cpp가 작동하지 않는 원인을 진단하고, 사용자의 동의를 받아 위험이 낮은 해결책을 적용하거나 정확한 다음 단계를 제공한다. 또한 Lemonade, LM Studio 및 Ollama 문제를 적절한 상위 채널로 라우팅한다. 사용자가 ROCm 또는 HIP가 “작동하지 않는다”, `torch.cuda.is_available()` 가 False, `rocminfo` / `hipInfo` 가 GPU를 인식하지 못함, `hipErrorNoBinaryForGpu`, `HSA_STATUS_ERROR_INVALID_ISA`, “invalid device function”, “no kernel image is available”, `/dev/kfd` 를 열 수 없음, `/dev/kfd` 권한 거부, “ROCk module is NOT loaded”, `libamdhip64.so` / `amdhip64_6.dll` / `hipblas.dll` / `vcruntime140_1.dll` 누락, `HSA_OVERRIDE_GFX_VERSION` 페이지 폴트, iGPU+dGPU 충돌, GPU를 인식하지 못하는 컨테이너, 혹은 `amdgpu-install` / DKMS 실패 등의 상황에 사용한다. `rocm` CLI(`rocm examine` / `rocm diagnose` / `rocm fix`)를 기반으로 하며, 이 스킬은 해당 명령들을 얇게 감싸는 드라이버일 뿐 재구현이 아니다.
