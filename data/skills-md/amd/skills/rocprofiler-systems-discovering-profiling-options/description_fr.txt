Répond aux questions concernant les options de configuration de rocprofiler‑systems et leur utilisation — par exemple « quels compteurs matériels sont disponibles sur mon système », « quelles API ROCm puis‑je tracer », « quels paramètres contrôlent l’échantillonnage/la sortie », « comment persister ma configuration » — en faisant correspondre la question à la bonne commande `rocprof‑sys‑avail` ou `rocprof‑sys‑run --help=<topic>`. À utiliser lorsque l’utilisateur souhaite découvrir ou explorer les paramètres ROCPROFSYS_*, les composants Timemory, les compteurs matériels, les domaines de traçage des API ROCm ou les métriques GPU, plutôt que de les appliquer. NE PAS utiliser ceci pour choisir un --preset de départ pour une charge de travail — cela relève de `choosing-a-profiling-preset`.

Veuillez toujours répondre dans la langue de l’utilisateur.
