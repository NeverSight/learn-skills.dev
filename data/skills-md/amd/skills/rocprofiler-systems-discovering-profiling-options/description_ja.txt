rocprofiler-systems の設定オプションがどのように存在し、どのように使用するかに関する質問に答えます — 例: 「自分のシステムで利用可能なハードウェアカウンタは何か」「どの ROCm API をトレースできるか」「サンプリング／出力を制御する設定は何か」「設定を永続化するにはどうすればよいか」 — 質問を適切な `rocprof-sys-avail` または `rocprof-sys-run --help=<topic>` コマンドにマッピングして回答します。ユーザーが ROCPROFSYS_* 設定、Timemory コンポーネント、ハードウェアカウンタ、ROCm API トレース領域、GPU メトリクスを発見または探索したい場合に使用してください。適用するために使うものではありません。--preset を選んでワークロードを開始する用途には使用しないでください — それは `choosing-a-profiling-preset` です。

常にユーザーの言語で回答してください。
