rocprofiler-systems 구성 옵션이 무엇이 있는지, 그리고 어떻게 사용하는지에 대한 질문에 답변합니다 — 예: “내 시스템에서 사용할 수 있는 하드웨어 카운터는 무엇인가요”, “어떤 ROCm API를 추적할 수 있나요”, “샘플링/출력을 제어하는 설정은 무엇인가요”, “구성을 어떻게 영구 저장하나요” — 질문을 적절한 `rocprof-sys-avail` 또는 `rocprof-sys-run --help=<topic>` 명령에 매핑하여 답합니다. 사용자가 ROCPROFSYS_* 설정, Timemory 구성 요소, 하드웨어 카운터, ROCm API 추적 도메인 또는 GPU 메트릭을 탐색하거나 발견하고자 할 때 사용합니다. 워크로드에 대한 시작 --preset을 선택하려면 사용하지 마세요 — 그것은 `choosing-a-profiling-preset` 입니다.

항상 사용자의 언어로 응답하십시오.
