Отвечает на вопросы о том, какие параметры конфигурации rocprofiler‑systems существуют и как их использовать — например «какие аппаратные счётчики доступны в моей системе», «какие API ROCm я могу трассировать», «какие настройки контролируют семплирование/вывод», «как сохранить мою конфигурацию» — сопоставляя вопрос с нужной командой `rocprof-sys-avail` или `rocprof-sys-run --help=<topic>`. Используйте, когда пользователь хочет обнаружить или исследовать параметры ROCPROFSYS_*, компоненты Timemory, аппаратные счётчики, домены трассировки API ROCm или метрики GPU, а не применять их. НЕ используйте это для выбора стартового --preset для задачи — для этого предназначен `choosing-a-profiling-preset`.

Всегда отвечайте на языке пользователя.
