Établit le profil d'une application cible à l'aide de rocprofv3 avec l'échantillonnage du compteur de programme activé, puis analyse les résultats. À utiliser lorsque l'utilisateur dispose d'un programme qui s'exécute sur un GPU AMD et demande d'effectuer un échantillonnage PC, de déterminer les caractéristiques de performance d'exécution de son application, de déterminer les raisons du décrochage ou de déterminer les points chauds dans le code.
