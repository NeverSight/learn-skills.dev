Profiliert eine Zielanwendung mit rocprofv3 mit aktivierter Programmzählerabtastung und analysiert dann die Ergebnisse. Wird verwendet, wenn der Benutzer über ein Programm verfügt, das auf einer AMD GPU ausgeführt wird und zur Durchführung von PC-Sampling, zur Bestimmung der Laufzeitleistungsmerkmale seiner Anwendung, zur Bestimmung von Verzögerungsgründen oder zur Bestimmung von Hotspots im Code auffordert.
