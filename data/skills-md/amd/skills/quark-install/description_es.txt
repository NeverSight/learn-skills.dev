Instala o verifica AMD Quark y asegura que el entorno Python seleccionado cuente con un PyTorch compatible con el acelerador. Se aplica a “install Quark”, “set up Quark”, “pip install amd‑quark”, fallos de dependencias o importaciones de Quark, ModuleNotFoundError para quark y errores del compilador del kernel de Quark. Por defecto utiliza GPU y requiere confirmación explícita antes de pasar al modo CPU. Cubre instalaciones universales de PyPI, nativas exactamente coincidentes, ruedas locales y fuentes locales. No maneja solicitudes de PyTorch independientes, configuraciones solo con ONNX Runtime o cuantización.
