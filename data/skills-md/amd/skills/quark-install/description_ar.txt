يقوم بتثبيت أو التحقق من AMD Quark ويضمن أن بيئة بايثون المختارة تحتوي على PyTorch متطابق مع المسرّع. ينطبق على "install Quark" و"set up Quark" و"pip install amd‑quark" وفشل تبعية أو استيراد Quark، وخطأ ModuleNotFoundError للـ quark، وأخطاء مترجم نواة Quark. الافتراضي هو GPU ويتطلب تأكيدًا صريحًا قبل وضعية CPU. يغطي تثبيتات PyPI العامة، والمتطابقة تمامًا مع الأصلية، وتثبيتات العجلة المحلية، وتثبيتات المصدر المحلي. لا يتعامل مع طلبات PyTorch المستقلة، أو إعداد ONNX Runtime فقط، أو التكميم.
