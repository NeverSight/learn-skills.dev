AMD Quark をインストールまたは検証し、選択された Python 環境にアクセラレータにマッチした PyTorch があることを保証します。「install Quark」や「set up Quark」や「pip install amd‑quark」、Quark の依存関係やインポート失敗、quark の ModuleNotFoundError、Quark カーネルコンパイラエラーに適用されます。デフォルトは GPU で、CPU モードに切り替える場合は明示的な確認が必要です。PyPI のユニバーサル、正確にマッチしたネイティブ、ローカルホイール、ローカルソースインストールをカバーします。スタンドアロンの PyTorch リクエスト、ONNX Runtime のみのセットアップ、または量子化は扱いません。
