Installa o verifica AMD Quark e garantisce che l'ambiente Python selezionato disponga di un PyTorch corrispondente all'acceleratore. Si applica a “install Quark”, “set up Quark”, “pip install amd‑quark”, problemi di dipendenza o di importazione di Quark, ModuleNotFoundError per quark e errori del compilatore del kernel Quark. Il valore predefinito è GPU e richiede conferma esplicita prima di passare alla modalità CPU. Copre installazioni universali PyPI, nativamente corrispondenti, wheel locali e installazioni da sorgente locale. Non gestisce richieste di PyTorch autonome, configurazioni solo ONNX Runtime o quantizzazione.
