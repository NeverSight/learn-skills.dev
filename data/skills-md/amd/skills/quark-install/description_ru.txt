Устанавливает или проверяет AMD Quark и гарантирует, что выбранная среда Python имеет PyTorch, соответствующий ускорителю. Применяется к «install Quark», «set up Quark», «pip install amd‑quark», проблемам с зависимостями Quark или ошибкам импорта, ModuleNotFoundError для quark и ошибкам компилятора ядра Quark. По умолчанию используется GPU и требуется явное подтверждение перед переходом в режим CPU. Охватывает универсальные установки из PyPI, точно совпадающие нативные, установки из локального wheel и из локального исходного кода. Не обрабатывает запросы на отдельный PyTorch, настройку только ONNX Runtime или квантизацию. Пожалуйста, всегда отвечайте на языке пользователя.
