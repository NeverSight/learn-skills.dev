Installe ou vérifie AMD Quark et s’assure que l’environnement Python sélectionné possède un PyTorch correspondant à l’accélérateur. S’applique à « install Quark », « set up Quark », « pip install amd‑quark », aux échecs de dépendance ou d’importation de Quark, aux ModuleNotFoundError pour quark, et aux erreurs du compilateur du noyau Quark. Le mode par défaut est GPU et une confirmation explicite est requise avant de passer en mode CPU. Couvre les installations universelles PyPI, les installations natives exactement correspondantes, les wheels locales et les installations depuis le code source local. Ne gère pas les requêtes PyTorch autonomes, la configuration uniquement ONNX Runtime, ni la quantisation.
