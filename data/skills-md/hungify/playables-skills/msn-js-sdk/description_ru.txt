Интегрирует JavaScript SDK от MSN (`window.$msstart`) в JavaScript‑игры, работающие на Microsoft Start. Обрабатывает инициализацию SDK, аутентификацию игрока, облачное сохранение ключ‑значение, отображение баннеров и межстраничных/вознаграждаемых реклам, нативный обмен, отправку результатов в таблицу лидеров и внутриигровые покупки. Используйте, когда пользователь упоминает настройку MSN SDK, интеграцию рекламы MSN, монетизацию игр с помощью MSN, добавление функций MSN в JavaScript‑игру, `$msstart`, скрипт `msstart`, облачное сохранение MSN или покупки в приложении MSN.
