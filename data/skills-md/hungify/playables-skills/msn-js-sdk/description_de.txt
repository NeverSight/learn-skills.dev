Integriert das MSN JavaScript SDK (`window.$msstart`) in JavaScript‑Spiele, die auf Microsoft Start laufen. Handhabt die SDK‑Initialisierung, Spieler‑Authentifizierung, Cloud‑Speicher für Schlüssel‑/Wert‑Paare, das Anzeigen von Banner‑ und Interstitial‑/Rewarded‑Ad‑Lebenszyklen, natives Teilen, das Einreichen von Ranglistenwerten und In‑App‑Käufe. Verwenden Sie es, wenn der Benutzer MSN‑SDK‑Setup, MSN‑Werbeintegration, Spiel‑Monetarisierung mit MSN, das Hinzufügen von MSN‑Funktionen zu einem JavaScript‑Spiel, `$msstart`, `msstart`‑Skript, MSN‑Cloud‑Speicher oder MSN‑IAP erwähnt. Bitte immer in der Sprache des Benutzers antworten.
