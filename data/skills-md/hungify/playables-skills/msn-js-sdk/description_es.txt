Integra el SDK de JavaScript de MSN (`window.$msstart`) en juegos JavaScript que se ejecutan en Microsoft Start. Gestiona la inicialización del SDK, la autenticación del jugador, el almacenamiento en la nube de pares clave/valor, la visualización de banners y ciclos de vida de anuncios intersticiales/recompensados, el uso compartido nativo, la presentación de puntuaciones en la tabla de líderes y las compras dentro de la aplicación. Úsalo cuando el usuario mencione la configuración del SDK de MSN, la integración de anuncios de MSN, la monetización de juegos con MSN, agregar funciones de MSN a un juego JavaScript, `$msstart`, el script `msstart`, el guardado en la nube de MSN o las IAP de MSN.
