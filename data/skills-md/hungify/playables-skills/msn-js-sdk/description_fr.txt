Intègre le SDK JavaScript de MSN (`window.$msstart`) aux jeux JavaScript fonctionnant sur Microsoft Start. Gère l'initialisation du SDK, l'authentification du joueur, le stockage cloud clé/valeur, l'affichage des bannières et les cycles de vie des publicités interstitielles/récompensées, le partage natif, la soumission de scores au classement et les achats intégrés. Utilisez‑le lorsqu’un utilisateur mentionne la configuration du SDK MSN, l’intégration des publicités MSN, la monétisation de jeu avec MSN, l’ajout de fonctionnalités MSN à un jeu JavaScript, `$msstart`, le script `msstart`, la sauvegarde cloud MSN ou les achats in‑app MSN.  

Veuillez toujours répondre dans la langue de l’utilisateur.
