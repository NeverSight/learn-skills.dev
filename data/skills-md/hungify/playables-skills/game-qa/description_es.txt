Pruebas de QA de juegos con Playwright — regresión visual, verificación de jugabilidad, rendimiento y accesibilidad para juegos de navegador. Úselo al escribir o ejecutar pruebas de juego, depurar fallos de pruebas o crear infraestructura de QA. Esta es la habilidad de referencia — use qa-game para el comando orientado al usuario.
