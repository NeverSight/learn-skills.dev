Intègre le SDK JavaScript Yandex Games (YaGames) aux jeux JavaScript. Initialise le SDK et les hooks du cycle de vie, gère l’authentification et l’autorisation du joueur, gère le stockage cloud par joueur, contrôle les emplacements publicitaires (interstitiel, vidéo récompensée, bannière persistante), implémente les achats in‑app et les classements, récupère les drapeaux de configuration distante, et prend en charge les fonctionnalités sociales telles que les invites d’avis et les raccourcis d’écran d’accueil. À utiliser lorsque l’utilisateur mentionne Yandex Games, YaGames, le SDK Yandex, le déploiement d’un jeu sur la plateforme Yandex.Games, ou l’intégration de fonctionnalités comme la publicité, les classements, les achats in‑app ou l’authentification du joueur dans un jeu JavaScript hébergé par Yandex.
