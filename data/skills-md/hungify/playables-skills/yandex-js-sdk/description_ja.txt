Yandex Games の JavaScript SDK（YaGames）を JavaScript ゲームに統合します。SDK とライフサイクルフックを初期化し、プレイヤーの認証と認可を管理し、プレイヤーごとのクラウドストレージを処理し、広告配置（インタースティシャル、リワード動画、スティッキーバナー）を制御し、インアプリ購入とリーダーボードを実装し、リモートコンフィグフラグを取得し、レビュー促進やホーム画面ショートカットといったソーシャル機能をサポートします。ユーザーが Yandex Games、YaGames、yandex sdk、Yandex.Games プラットフォームへのゲーム配信、または広告、リーダーボード、インアプリ購入、プレイヤー認証などの機能を Yandex ホストの JavaScript ゲームに統合すると言及したときに使用してください。常にユーザーの言語で回答してください。
