Integriert das Yandex Games JavaScript SDK (YaGames) in JavaScript‑Spiele. Initialisiert das SDK und Lifecycle‑Hooks, verwaltet die Authentifizierung und Autorisierung von Spielern, behandelt cloudbasierten Speicher pro Spieler, steuert Anzeigenplatzierungen (Interstitial, Rewarded Video, Sticky Banner), implementiert In‑App‑Käufe und Ranglisten, ruft Remote‑Config‑Flags ab und unterstützt soziale Funktionen wie Bewertungsaufforderungen und Verknüpfungen zum Homescreen. Verwenden Sie dies, wenn der Nutzer Yandex Games, YaGames, Yandex‑SDK, das Deployen eines Spiels auf der Yandex.Games‑Plattform oder die Integration von Funktionen wie Werbung, Ranglisten, In‑App‑Käufen oder Spieler‑Authentifizierung in ein von Yandex gehostetes JavaScript‑Spiel erwähnt.
