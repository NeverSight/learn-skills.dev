Intègre le SDK JavaScript de CrazyGames (v3) dans un jeu navigateur ou HTML5. Gère l'initialisation du SDK, l'authentification des utilisateurs et la récupération du profil, le stockage persistant clé/valeur, les pauses publicitaires interstitielles et récompensées, la détection d'AdBlock, les bannières publicitaires responsives, les hooks du cycle de vie du jeu (loadingStart/Stop, gameplayStart/Stop, happytime), ainsi que les achats in‑app optionnels via Xsolla Pay Station avec suivi analytique des commandes. À utiliser lorsque l'utilisateur mentionne CrazyGames, souhaite publier ou intégrer un jeu sur CrazyGames, ou a besoin d'ajouter des fonctionnalités du SDK comme les publicités, les comptes utilisateurs, les événements de jeu, le stockage ou les achats intégrés à un jeu navigateur/HTML5/JavaScript.
