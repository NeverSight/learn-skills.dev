Poki JavaScript SDK(PokiSDK)를 JavaScript 브라우저 게임에 통합합니다. PokiSDK를 초기화하고 전면 광고와 보상형 광고 브레이크(commercialBreak, rewardedBreak)를 구성하며, 게임 플레이 라이프사이클 이벤트(gameplayStart, gameplayStop)를 관리하고, 로딩 진행 상황 추적(gameLoadingFinished)을 설정합니다. 사용자가 Poki, PokiSDK, 웹 게임 수익화, 게임 포털 통합, 브라우저 게임 내 광고 브레이크, 또는 Poki 플랫폼에 HTML5 게임을 배포한다고 언급할 때 활용합니다.
