Analysez un jeu, identifiez ce qui nécessite du travail et implémentez les améliorations ayant le plus d’impact. Utilisez‑le lorsque l’utilisateur dit « améliorer mon jeu », « rendre mon jeu meilleur », « réparer mon jeu », « quel est le problème avec mon jeu » ou « polir mon jeu ». Exécutez‑le de façon répétée — chaque passe trouve la prochaine amélioration la plus impactante à corriger. N’UTILISEZ PAS cet outil pour ajouter des fonctionnalités spécifiques (utilisez add‑feature) ou pour la création initiale d’un jeu (utilisez viral‑game pour les constructions d’un seul coup, make‑game pour les projets à étapes).  

Veuillez toujours répondre dans la langue de l’utilisateur.
