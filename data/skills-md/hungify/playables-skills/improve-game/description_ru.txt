Анализируйте игру, находите, что требует доработки, и внедряйте улучшения с наибольшим влиянием. Используйте, когда пользователь говорит «улучши мою игру», «сделай мою игру лучше», «почини мою игру», «что не так с моей игрой» или «полиши мою игру». Выполняйте многократно — каждый проход ищет следующую самую значимую вещь для исправления. НЕ используйте для добавления конкретных новых функций (используйте add-feature) или для начального создания игры (используйте viral-game для однократных построений, make-game для проектов с этапами).

Пожалуйста, всегда отвечайте на языке пользователя.
