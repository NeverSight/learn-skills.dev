Utilisez‑le lors de l’intégration du SDK JavaScript Lagged dans un jeu HTML5 publié sur Lagged.com, pour ajouter les classements Lagged, gérer les emplacements publicitaires Lagged ou configurer l’authentification des utilisateurs via l’API Lagged. Initialise le SDK Lagged (window.LaggedAPI), récupère les données de profil du joueur, soumet les scores aux classements natifs, débloque les succès et intègre les publicités interstitielles et récompensées pour les jeux sur le portail Lagged.com.
