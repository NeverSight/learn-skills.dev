Úsese al integrar el SDK de JavaScript de Lagged en un juego HTML5 publicado en Lagged.com, al añadir tablas de clasificación de Lagged, gestionar ubicaciones de anuncios de Lagged o configurar la autenticación de usuarios a través de la API de Lagged. Inicializa el SDK de Lagged (window.LaggedAPI), recupera los datos del perfil del jugador, envía puntuaciones a las tablas de clasificación nativas, desbloquea logros e integra anuncios intersticiales y recompensados para juegos en el portal de juegos Lagged.com.
