Используется при интеграции JavaScript SDK Lagged в HTML5‑игру, опубликованную на Lagged.com, добавлении лидербордов Lagged, обработке рекламных размещений Lagged или настройке аутентификации пользователей через API Lagged. Инициализирует SDK Lagged (window.LaggedAPI), получает данные профиля игрока, отправляет результаты в нативные лидерборды, разблокирует достижения и интегрирует интерстициальную и вознаграждающую рекламу для игр на игровом портале Lagged.com.
