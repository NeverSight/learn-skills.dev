Utilízalo al diseñar o implementar una UI de juego, HUD, menú, pantalla o componente interactivo para web, React/Vue/Svelte/Angular, móvil, escritorio o un motor. Construye en un estilo de contorno de tinta, botón de bloque grueso con colores brillantes. Pregunta al usuario antes de construir. Incluye un kit, estándares de código, paletas y revisiones visuales.
