معايير ترميز الواجهة الأمامية بـ React + TypeScript: مجموعة التقنية (مكتبة مكوّنات مشتركة @workspace/ui، Sonner، Tailwind CSS، Jotai، React Query/jotai-tanstack-query)، بنية مشروع تعتمد على الصفحات، صيغة استجابة موحدة للواجهة الأمامية والخلفية، معالجة الأخطاء، إدارة الحالة. مناسبة للبناء وإعادة الهيكلة ومراجعة مشاريع الواجهة الأمامية بـ React.
