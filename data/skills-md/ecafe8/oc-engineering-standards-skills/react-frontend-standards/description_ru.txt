Стандарты кодирования фронтенда на React + TypeScript: технологический стек (общая библиотека компонентов @workspace/ui, Sonner, Tailwind CSS, Jotai, React Query/jotai‑tanstack‑query), проектная структура на основе страниц, единый формат ответов для фронтенда и бэкенда, обработка ошибок, управление состоянием. Подходит для создания, рефакторинга и ревью проектов фронтенда на React.
