Запрашивать данные маркетплейса OpenSea — листинги, предложения, продажи/события, минимальные цены, статистику коллекций, дропы, черты — и выполнять сделки Seaport через официальный `@opensea/cli` и OpenSea REST API на Ethereum, Base, Arbitrum, Optimism, Polygon и других сетях. Включает поиск по коллекциям, NFT, токенам и аккаунтам. НЕ предназначено для общих чтений метаданных NFT (название, изображение, черты, владение), метаданных токенов, текущих балансов кошельков, истории транзакций или живых RPC‑запросов — для этого используйте `alchemy-cli` (live), `alchemy-mcp`, `alchemy-api` (в коде приложения) или `agentic-gateway` (без API‑ключа). Для чистых кросс‑чейн токен‑свапов (без контекста маркетплейса) предпочтительно использовать навык экосистемы `lifi`. Требуется `OPENSEA_API_KEY` (мгновенно через API).
