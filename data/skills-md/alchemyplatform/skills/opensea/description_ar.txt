استعلام بيانات سوق OpenSea — القوائم، العروض، المبيعات / الأحداث، أسعار الأرضية، إحصائيات المجموعة، الإصدارات، السمات — وتنفيذ صفقات Seaport عبر الـ`@opensea/cli` الرسمي وواجهة OpenSea REST API عبر Ethereum، Base، Arbitrum، Optimism، Polygon، وأكثر. يتضمن البحث عبر المجموعات / NFTs / الرموز / الحسابات. ليس للاستخدام العام لقراءة بيانات NFT (الاسم، الصورة، السمات، الملكية)، بيانات الرموز، أرصدة المحافظ الحالية، تاريخ المعاملات، أو قراءات RPC الحية — لهذه الأغراض استخدم `alchemy-cli` (في الوقت الفعلي)، `alchemy-mcp`، `alchemy-api` (كود التطبيق)، أو `agentic-gateway` (بدون مفتاح API). لتبديلات الرموز عبر السلاسل بدون سياق السوق، يُفضَّل مهارة نظام `lifi`. يتطلب `OPENSEA_API_KEY` (متاح فوراً عبر API).
