OpenSeaマーケットプレイスデータ（出品、オファー、販売／イベント、フロア価格、コレクション統計、ドロップ、属性）を検索し、公式 `@opensea/cli` と OpenSea REST API を使用して、Ethereum、Base、Arbitrum、Optimism、Polygon などのチェーン上で Seaport 取引を実行します。コレクション／NFT／トークン／アカウント横断検索も含まれます。一般的な NFT メタデータの読み取り（名前、画像、属性、所有権）、トークンメタデータ、現在のウォレット残高、取引履歴、ライブ RPC 読み取りには使用しないでください。その場合は `alchemy-cli`（ライブ）、`alchemy-mcp`、`alchemy-api`（アプリコード）または `agentic-gateway`（API キー不要）をご利用ください。マーケットプレイスコンテキストのない純粋なクロスチェーントークンスワップには `lifi` エコシステムのスキルを推奨します。`OPENSEA_API_KEY` が必要です（API で即時取得可能）。
