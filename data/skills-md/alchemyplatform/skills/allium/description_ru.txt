Запрашивайте API Allium для получения PnL кошелька (текущий + исторический, по кошельку и по токену), истории временных рядов активов, торговых данных Hyperliquid HyperCore (информация, исполнения, ордера, книга ордеров) и пользовательской аналитики SQL по более чем 70 цепочкам. НЕ предназначено для цен токенов, метаданных токенов, текущих снимков баланса кошелька, истории трансферов транзакций или метаданных NFT — для этого используйте `alchemy-cli` (работа в реальном времени), `alchemy-mcp`, `alchemy-api` (код приложения) или `agentic-gateway` (без API‑ключа). Требуются учетные данные Allium в `~/.allium/credentials`.
