Quand l'utilisateur veut implémenter GRASP — construction gloutonne randomisée à plusieurs démarreurs avec une liste de candidats restreinte suivie d'une recherche locale — y compris le réglage d'alpha, le GRASP réactif et les hybrides de reliaison de chemins. Utiliser également lorsque l'utilisateur mentionne « GRASP », « greedy randomized », « restricted candidate list », « RCL », « multi-start », « semi-greedy », ou lorsqu'une bonne heuristique gloutonne existe mais que son biais déterministe doit être contourné par des redémarrages randomisés. Pour la phase d'amélioration, voir local-search-and-neighborhoods ; pour l'intensification du jeu d'élite, voir scatter-search-path-relinking.

Veuillez toujours répondre dans la langue de l'utilisateur.
