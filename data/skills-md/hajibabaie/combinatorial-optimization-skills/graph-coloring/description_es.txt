Cuando el usuario desea asignar colores (etiquetas, franjas, frecuencias) a los vértices de un grafo de modo que los vértices adyacentes difieran, minimizar el número de colores usados, o acotar el número cromático con métodos exactos o heurísticos. También se usa cuando el usuario menciona “graph coloring”, “chromatic number”, “DSATUR”, “tabucol”, “Kempe chains”, “coloring conflicts”, o cuando los elementos deben compartir recursos escasos sujetos a conflictos pares (horarios de exámenes, registros de CPU, frecuencias de radio). Para modelos completos de planificación de horarios con restricciones blandas, vea timetabling‑and‑rostering; para profundidad de modelado CP‑SAT, vea constraint‑programming.
