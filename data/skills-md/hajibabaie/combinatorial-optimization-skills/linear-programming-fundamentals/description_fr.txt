Lorsque l'utilisateur veut formuler des programmes linéaires, les résoudre avec les méthodes du simplexe ou de barrière, et interpréter le résultat via la dualité — prix d’ombre, coûts réduits, intervalles de sensibilité, dégénérescence. Utilisez également cela lorsque l'utilisateur mentionne « programmation linéaire », « valeurs duales », « prix d’ombre », « analyse de sensibilité », « coût réduit », « duals de relaxation PL », ou lorsqu'il faut expliquer ou décomposer un modèle en indiquant le prix économique d’une contrainte. Pour les modèles à variables mixtes entières, voir milp‑modeling‑gurobi ; pour les PL dont les colonnes doivent être valorisées à la demande, voir column‑generation.

Veuillez toujours répondre dans la langue de l'utilisateur.
