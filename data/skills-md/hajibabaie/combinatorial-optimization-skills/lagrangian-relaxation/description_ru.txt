Когда пользователь хочет вычислить сильные двойственные границы для целочисленных программ, дублируя осложняющие ограничения, оптимизируя лагранжеву двойственную задачу методами субградиента и восстанавливая допустимые решения с помощью лагранжевых эвристик. Также используйте, когда пользователь упоминает «Lagrangian relaxation», «subgradient», «Lagrangian bound», «dualize constraints», «Lagrangian heuristic» или когда задача MIP была бы простой, если бы не несколько связывающих ограничений. Для основ двойственности линейного программирования см. linear-programming-fundamentals; для взгляда на ту же границу через генерацию столбцов см. dantzig-wolfe-decomposition.
