Cuando el usuario quiere implementar un algoritmo de ramificación y acotamiento personalizado — diseñando funciones de cota, reglas de ramificación, selección de nodos (profundidad primero vs mejor primero), reglas de dominancia y gestión del incumbente — o decidir cuándo el B&B personalizado supera a un solver MIP. También usar cuando el usuario menciona "custom branch and bound", "bounding function", "branching rule", "node selection", "best-first search", o cuando la relajación de cota es combinatoria en lugar de una PL. Para B&B interno del solver y brechas MIP, consulte integer-programming-techniques; para árboles de branch-and-price, consulte column-generation.
