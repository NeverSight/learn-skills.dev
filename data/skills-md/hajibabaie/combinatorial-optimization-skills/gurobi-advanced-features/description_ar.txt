عندما يرغب المستخدم في استغلال Gurobi بما يتجاوز بناء النموذج البسيط — الاستدعاءات الراجعة للقيود المتكاسلة، قطع المستخدم، حقن الحلول التجريبية، وإنهاء مبكر؛ حساب IIS لتشخيص نموذج غير قابل للتنفيذ؛ مجموعة الحلول؛ واجهة برمجة التطبيقات متعددة الأهداف؛ واجهة برمجة التطبيقات للمصفوفات (addMVar/addMConstr)؛ بدايات MIP؛ وضبط المعاملات باستخدام أداة الضبط المدمجة. يُستخدم أيضًا عندما يذكر المستخدم "Gurobi callback"، أو "lazy constraints"، أو "IIS"، أو "solution pool"، أو "Gurobi parameters"، أو "infeasible model"، أو "MIP start". للتعرف على بناء النموذج الأساسي، انظر milp-modeling-gurobi؛ ولعائلات القطع ونظرية الفصل، انظر cutting-planes-valid-inequalities.
