Когда пользователь хочет использовать Gurobi за пределами простого построения модели — обратные вызовы для ленивых ограничений, пользовательских разрезов, внедрения эвристических решений и раннего завершения; вычисление IIS для диагностики невозможной модели; пул решений; API многокритериального оптимизирования; API матрицы (addMVar/addMConstr); стартовые решения MIP; и настройку параметров с помощью встроенного инструмента настройки. Также использовать, когда пользователь упоминает «Gurobi callback», «lazy constraints», «IIS», «solution pool», «Gurobi parameters», «infeasible model» или «MIP start». Для базового построения модели см. milp-modeling-gurobi; для семей разрезов и теории разделения см. cutting-planes-valid-inequalities.
