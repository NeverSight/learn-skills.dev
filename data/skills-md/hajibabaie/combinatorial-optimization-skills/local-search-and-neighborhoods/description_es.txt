Cuando el usuario quiere diseñar o implementar una búsqueda local basada en vecindarios: elegir movimientos (intercambio, inserción, 2‑opt, Or‑opt, intercambio), escribir una evaluación delta de O(1)/O(n), mejora primero vs mejor, orden de escaneo y estructuras de datos de los movimientos. También se aplica cuando el usuario menciona “búsqueda local”, “2‑opt”, “vecindario”, “evaluación delta”, “hill climbing”, “first improvement”, o cuando una heurística recalcula el objetivo completo después de cada movimiento. Para aceptar movimientos que empeoran y escapar de óptimos locales, véase simulated‑annealing; para envoltorios de perturbación y reinicio, véase iterated‑local‑search.
