Когда пользователь хочет разработать и реализовать динамическое программирование для комбинаторной оптимизации — проектирование пространства состояний, рекурсии Беллмана, мемоизация против табуляции, восстановление решения и алгоритмы маркировки для кратчайших путей с ограничениями ресурсов. Также использовать, когда пользователь упоминает «dynamic programming», «Bellman recursion», «state space», «Held‑Karp», «labeling algorithm», «memoization», или когда задача разбивается на стадии с перекрывающимися подзадачами. Для ценовых циклов, вызывающих орэк DP, см. column‑generation; для поиска в дереве, управляемого границами DP, см. branch‑and‑bound.
