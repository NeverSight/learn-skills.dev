Когда пользователь хочет записывать, хранить и агрегировать результаты вычислительных экспериментов для оптимизационных алгоритмов с помощью pandas — аккуратные таблицы «одна строка на запуск», метаданные запуска (инстанс, seed, алгоритм, параметры, время выполнения, целевая функция), атомарная запись в CSV/parquet, агрегация по инстансам и seed‑ам, и сводные таблицы для статей. Также использовать, когда пользователь упоминает «результаты эксперимента», «dataframe результатов», «агрегировать запуски», «отслеживание экспериментов», «CSV результатов», «parquet результатов», или когда тысячи сырых запусков должны стать одной убедительной таблицей для статьи. Для статистического сравнения алгоритмов см. algorithm-benchmarking-statistics; для преобразования таблиц результатов в графики см. matplotlib-optimization-visualization.
