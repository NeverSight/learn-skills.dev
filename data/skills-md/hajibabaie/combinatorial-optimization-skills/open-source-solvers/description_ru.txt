Когда пользователь хочет решать задачи LP, MIP или CP без коммерческой лицензии — выбирая среди HiGHS, SCIP, CBC, OR‑Tools (CP‑SAT и MathOpt), PuLP, Pyomo и python‑mip, сравнивая лицензии, устанавливая реалистичные ожидания по производительности по сравнению с Gurobi и мигрируя модели gurobipy в открытую стек. Также использовать, когда пользователь упоминает «open-source solver», «HiGHS», «SCIP», «PuLP», «Pyomo», «CBC», «free solver» или «no Gurobi license». Для построения моделей gurobipy см. milp‑modeling‑gurobi; для глубокого моделирования CP‑SAT см. constraint‑programming.
