Cuando el usuario quiere asignar agentes a tareas al mínimo costo: asignación lineal mediante el algoritmo húngaro, dualidad de LP o linear_sum_assignment; asignación generalizada (GAP) mediante MIP, relajación lagrangiana y búsqueda local; asignación de cuello de botella (min‑max). Úselo también cuando el usuario mencione «problema de asignación», «algoritmo húngaro», «asignación generalizada», «GAP», «linear_sum_assignment», «emparejamiento», o cuando cada tarea requiera un agente bajo límites de capacidad. Para formulaciones de flujo, consulte network‑flow‑optimization; para costos de interacción entre pares asignados, consulte quadratic‑assignment‑problem.

Por favor, responda siempre en el idioma del usuario.
