Когда пользователь хочет собрать наборы задач для экспериментальных исследований по оптимизации, анализируя стандартные наборы данных (TSPLIB, CVRPLIB/Solomon, OR‑Library, MIPLIB, QAPLIB, Taillard), писать генераторы с контролируемой сложностью, сообщать характеристики задач или формировать разбиения train/test для настройки. Также используйте, когда пользователь упоминает «benchmark instances», «TSPLIB», «Solomon instances», «OR-Library», «instance generator», «test instances» или когда исследованию нужен обоснованный тестовый набор. Для статистического сравнения см. algorithm-benchmarking-statistics; для проверки выполнимости см. solution-validation-testing.
