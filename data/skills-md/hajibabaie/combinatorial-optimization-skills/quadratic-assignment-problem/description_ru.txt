Когда пользователь хочет моделировать или решить задачу квадратичного назначения — распределения n объектов по n местам с целью минимизации общей стоимости «поток × расстояние» — с помощью линейризованных МИП‑моделей или надёжного табу‑поиска, построенного на оценке delta‑изменения за O(n) при обмене. Также используйте, когда пользователь упоминает «quadratic assignment», «QAP», «flow distance», «QAPLIB», «facility layout» или «Koopmans‑Beckmann», либо когда парные затраты взаимодействия зависят от перестановки. Для линейного назначения без взаимодействий см. assignment‑problems; для выбора среди линейзаций произведения см. linearization‑techniques.
