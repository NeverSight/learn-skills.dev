Cuando el usuario desea modelar o resolver el problema de asignación cuadrática — asignar n instalaciones a n ubicaciones para minimizar el costo total de flujo por distancia — con modelos MIP linealizados o búsqueda tabú robusta basada en la evaluación del delta de intercambio O(n). También úsese cuando el usuario menciona “asignación cuadrática”, “QAP”, “flujo‑distancia”, “QAPLIB”, “disposición de instalaciones” o “Koopmans‑Beckmann”, o cuando los costos de interacción por pares dependen de una permutación. Para asignación lineal sin términos de interacción, consulte assignment‑problems; para elegir entre linealizaciones de producto, consulte linearization‑techniques.
