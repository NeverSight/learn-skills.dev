Quand l'utilisateur veut modéliser ou résoudre le problème d'affectation quadratique — assigner n installations à n emplacements afin de minimiser le coût total flux‑fois‑distance — avec des modèles MIP linéarisés ou une recherche tabou robuste basée sur une évaluation delta d'échange en O(n). Utilisez également lorsque l'utilisateur mentionne « quadratic assignment », « QAP », « flow distance », « QAPLIB », « facility layout » ou « Koopmans‑Beckmann », ou lorsque les coûts d'interaction par paires dépendent d'une permutation. Pour l'affectation linéaire sans termes d'interaction, voir assignment-problems ; pour choisir parmi les linéarisation de produits, voir linearization-techniques.

Veuillez toujours répondre dans la langue de l'utilisateur.
