Когда пользователь хочет разработать, реализовать или настроить итеративный локальный поиск (ILS) — цикл локального поиска + возмущения + принятия, который является самым сильным простым базовым решением для задач перестановок и маршрутизации. Также используйте, когда пользователь упоминает «итеративный локальный поиск», «ILS», «возмущение», «ударное перемещение», «двойной мост», «итеративный жадный», «стратегию перезапуска», или когда восходящий поиск постоянно возвращает один и тот же локальный оптимум и требуется принципиальный механизм выхода. Для разработки окрестностей и дельта‑оценки смотрите local-search-and-neighborhoods; для рандомизированного многократного стартового построения — смотрите grasp.
