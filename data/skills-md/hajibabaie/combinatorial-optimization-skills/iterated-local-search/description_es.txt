Cuando el usuario desea diseñar, implementar o afinar la búsqueda local iterada (ILS) — el bucle de búsqueda local + perturbación + aceptación que constituye la base simple más fuerte para problemas de permutación y rutas. También utilícelo cuando el usuario mencione "búsqueda local iterada", "ILS", "perturbación", "movimiento de impulso", "doble puente", "greedy iterado", "estrategia de reinicio", o cuando un escalador de colinas sigue devolviendo el mismo óptimo local y necesita un mecanismo de escape fundamentado. Para el diseño de vecindarios y evaluación delta, consulte local-search-and-neighborhoods; para la construcción aleatoria de múltiples inicios, consulte grasp.
