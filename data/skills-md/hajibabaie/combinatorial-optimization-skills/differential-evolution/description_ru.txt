Когда пользователь хочет решать непрерывные или смешанные задачи черного ящика с помощью дифференциальной эволюции, выбирайте среди стратегий DE (rand/1/bin, best/1/bin, current-to-best), настраивайте параметры F и CR или адаптируйте DE к задачам перестановки с помощью случайных ключей. Также используйте, когда пользователь упоминает «дифференциальную эволюцию», «DE/rand/1», «коэффициент мутации», «коэффициент кроссовера CR», «SHADE», «jDE» или когда требуется метод популяционной оптимизации без производных для пространства с ограниченными по коробке непрерывными переменными. Для адаптации ковариационной матрицы и селекции (μ+λ) см. эволюционные стратегии; для поиска со скоростным роем — см. оптимизацию роя частиц.
