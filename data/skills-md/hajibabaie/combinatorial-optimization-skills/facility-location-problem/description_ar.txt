عندما يرغب المستخدم في اختيار مواقع المرافق وتعيين العملاء لها — UFLP أو CFLP أو p‑median أو p‑center — باستخدام صيغ MIP قوية، أو مسارات حل باندرس أو لاجرانج، وكذلك خوارزميات جشعة أو تبادلية أو VNS. استخدم هذا أيضًا عندما يذكر المستخدم "facility location" أو "p-median" أو "p-center" أو "open facilities" أو "location-allocation" أو "UFLP" أو "warehouse location"، أو عندما يكون هناك مقايضة بين تكاليف الفتح الثابتة وتكاليف التعيين أو النقل. للتفكيك باستخدام قطع التحسين على نطاق واسع، راجع benders-decomposition؛ وللتعامل مع عدم اليقين في الطلب، راجع stochastic-optimization.
