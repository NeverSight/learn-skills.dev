Cuando el usuario desea resolver programas lineales o enteros cuyo conjunto de variables es demasiado grande para enumerarlo, iterando entre un problema maestro restringido y un problema de precios de costo reducido, hasta llegar a branch-and-price completo. También úselo cuando el usuario mencione “column generation”, “pricing problem”, “restricted master problem”, “branch-and-price”, “Gilmore‑Gomory”, o cuando el problema tenga exponencialmente muchas variables como patrones, rutas o horarios de tripulación. Para derivar el maestro a partir de un modelo compacto, consulte dantzig-wolfe-decomposition; para algoritmos de etiquetado usados en precios, consulte dynamic-programming.
