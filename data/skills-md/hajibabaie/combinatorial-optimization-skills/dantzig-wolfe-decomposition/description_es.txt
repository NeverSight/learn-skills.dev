Cuando el usuario quiere reformular un PL o PMI estructurado mediante la descomposición de Dantzig‑Wolfe — detectar estructura bloque‑angular, construir el maestro con restricciones de convexidad, valorar columnas a partir de subproblemas independientes y relacionar la cota DW con las cotas de PL y lagrangiana. También usarlo cuando el usuario menciona “Dantzig‑Wolfe”, “bloque‑angular”, “estructura decomponible”, “convexificación”, “reformulación del problema maestro”, o cuando un modelo se divide en bloques unidos por unas pocas restricciones de enlace. Para el bucle de valoración y branch‑and‑price, ver generación de columnas; para cotas duales subgradiente, ver relajación lagrangiana.
