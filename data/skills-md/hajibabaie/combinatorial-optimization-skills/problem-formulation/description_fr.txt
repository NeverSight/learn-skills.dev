Lorsque l'utilisateur veut traduire un problème en mots ou une situation de planification du monde réel en un modèle d'optimisation formel — identifier les variables de décision, la fonction objectif et les contraintes, choisir le type de modèle (LP, MIP, CP ou heuristique), estimer la taille du modèle et auditer les données avant que tout code de solveur ne soit écrit. Utilisez également cela lorsque l'utilisateur mentionne « formuler », « modéliser ce problème », « variables de décision », « fonction objectif », « traduire en optimisation », ou lorsqu'un problème arrive sous forme de texte brut sans structure mathématique. Pour implémenter le MIP résultant, voir milp-modeling-gurobi ; pour les termes non linéaires qui doivent devenir linéaires, voir linearization-techniques.
