Cuando el usuario quiere traducir un problema en palabras o una situación de planificación del mundo real a un modelo de optimización formal — identificando variables de decisión, función objetivo y restricciones, eligiendo el tipo de modelo (LP, MIP, CP o heurístico), estimando el tamaño del modelo y auditando los datos antes de escribir cualquier código de solver. También usarlo cuando el usuario menciona “formulate”, “model this problem”, “decision variables”, “objective function”, “translate to optimization”, o cuando un problema llega como prosa sin estructura matemática todavía. Para implementar el MIP resultante, consulte milp‑modeling‑gurobi; para términos no lineales que deben volverse lineales, consulte linearization‑techniques.

Por favor, responda siempre en el idioma del usuario.
