Lorsque l'utilisateur veut ajuster les paramètres d'une métaheuristique ou d'un solveur avec Optuna, y compris la définition de l'espace de recherche, l'échantillonnage TPE, l'élagage précoce des configurations faibles, les objectifs multi‑instance (moyenne/médiane sur un ensemble d'instances) et la validation sur un jeu tenu de côté contre le surapprentissage. Utilisez également lorsque l'utilisateur mentionne « Optuna », « hyperparameter tuning », « parameter tuning », « tune metaheuristic », « TPE sampler », « algorithm configuration », ou lorsque les résultats rapportés dépendent de valeurs de paramètres choisies manuellement. Pour la comparaison statistique des configurations ajustées, voir algorithm-benchmarking-statistics ; pour décider quels paramètres une algorithme doit exposer, voir metaheuristic-design-principles.

Veuillez toujours répondre dans la langue de l'utilisateur.
