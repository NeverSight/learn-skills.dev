Когда пользователь хочет решить одноразмерные задачи раскроя — вырезать требуемые ширины изделий из стандартных заготовочных рулонов с минимальным использованием рулонов или потерями кромки — с использованием моделей на основе шаблонов (Gilmore‑Gomory) или компактных MIP‑моделей, генерации столбцов с ценообразованием задачи рюкзака и целочисленного округления. Также используйте, когда пользователь упоминает «cutting stock», «trim loss», «cutting patterns», «stock rolls», «pattern generation», «Gilmore‑Gomory», или когда покрывающая модель имеет по одному столбцу на каждый выполнимый шаблон раскроя. Для общего механизма ограниченного мастера/ценообразования см. column‑generation; для однотребовательного аналога этой задачи см. bin‑packing.
