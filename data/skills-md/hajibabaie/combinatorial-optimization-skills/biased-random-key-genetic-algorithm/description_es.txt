Cuando el usuario quiera diseñar, implementar o afinar un algoritmo genético sesgado de claves aleatorias (BRKGA), donde los cromosomas son vectores de claves aleatorias en [0,1), la evolución usa particionamiento elite/mutante con cruce uniforme sesgado, y un decodificador es el único componente específico del problema. También se debe usar cuando el usuario mencione “BRKGA”, “claves aleatorias”, “codificación de claves aleatorias”, “cruce sesgado”, “decodificador”, o cuando los operadores genéticos nunca deben producir soluciones inviables. Para patrones de diseño de decodificadores, vea representaciones basadas en decodificadores; para operadores y selección genéticos generales, vea algoritmos genéticos.
