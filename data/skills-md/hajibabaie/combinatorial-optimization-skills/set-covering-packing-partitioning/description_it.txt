Quando l'utente vuole modellare o risolvere problemi di set covering, set packing o set partitioning con modelli MIP esatti, l'euristica greedy e la sua garanzia ln(n), l'arrotondamento LP o le euristiche basate sul Lagrangiano nello stile Caprara‑Fischetti‑Toth. Usare anche quando l'utente menziona “set covering”, “set partitioning”, “set packing”, “crew scheduling”, “covering constraint”, “winner determination”, o quando ogni riga deve essere colpita almeno una volta, esattamente una volta o al massimo una volta dalle colonne selezionate. Per la determinazione dei prezzi delle colonne di enormi master di set‑partitioning, vedere la generazione di colonne; per i percorsi dietro quelle colonne, vedere il vehicle‑routing‑problem.
