Lorsque l'utilisateur souhaite modéliser ou résoudre des problèmes de « set covering », de « set packing » ou de « set partitioning » avec des modèles MIP exacts, utilisez l'heuristique gloutonne et sa garantie ln(n), l'arrondi LP ou les heuristiques basées sur la lagrangienne à la manière de Caprara‑Fischetti‑Toth. Utilisez également ces approches lorsque l'utilisateur mentionne « set covering », « set partitioning », « set packing », « crew scheduling », « covering constraint », « winner determination », ou lorsque chaque ligne doit être touchée au moins une fois, exactement une fois ou au plus une fois par les colonnes sélectionnées. Pour la tarification des colonnes de maîtres de partition d'ensemble de grande taille, consultez la génération de colonnes ; pour les itinéraires derrière ces colonnes, consultez le problème de routage de véhicules.

Veuillez toujours répondre dans la langue de l'utilisateur.
