Cuando el usuario quiere modelar o resolver problemas de cobertura de conjuntos, empaquetado de conjuntos o partición de conjuntos con modelos MIP exactos, la heurística codiciosa y su garantía ln(n), el redondeo LP o heurísticas basadas en Lagrange al estilo Caprara‑Fischetti‑Toth. También usar cuando el usuario mencione “set covering”, “set partitioning”, “set packing”, “crew scheduling”, “covering constraint”, “winner determination”, o cuando cada fila deba ser cubierta al menos una vez, exactamente una vez o como máximo una vez por columnas seleccionadas. Para valorar las columnas de enormes maestros de partición de conjuntos, vea generación de columnas; para las rutas detrás de esas columnas, vea problema de ruteo de vehículos.
