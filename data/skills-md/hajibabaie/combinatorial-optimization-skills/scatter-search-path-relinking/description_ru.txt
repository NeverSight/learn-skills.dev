Когда пользователь хочет реализовать scatter search (управление референсным набором, генерация диверсификации, комбинация подмножеств, метод улучшения) или path relinking как интенсивизацию между элитными решениями, самостоятельную или внутри GRASP. Также используйте, когда пользователь упоминает «scatter search», «path relinking», «reference set», «RefSet», «elite solutions», «solution combination», «relinking», либо когда небольшая явно управляемая элитная популяция должна заменить большую стохастическую. Для жадного рандомизированного построения и мульти‑старта смотрите GRASP; для рекомбинации большой популяции — генетические алгоритмы.
