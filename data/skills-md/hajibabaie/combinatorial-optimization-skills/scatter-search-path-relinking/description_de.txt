Wenn der Benutzer Scatter Search (Verwaltung des Referenzsatzes, Diversifikationsgenerierung, Teilmengenkombination, Verbesserungsmethode) oder Path Relinking als Intensivierung zwischen Elite‑Lösungen implementieren möchte, eigenständig oder innerhalb von GRASP. Auch verwenden, wenn der Benutzer „scatter search“, „path relinking“, „reference set“, „RefSet“, „elite solutions“, „solution combination“, „relinking“ erwähnt oder wenn eine kleine, explizit verwaltete Elite‑Population eine große stochastische ersetzen soll. Für greedy‑randomisierte Konstruktion und Multi‑Start siehe GRASP; für Rekombination großer Populationen siehe Genetic‑Algorithms.
