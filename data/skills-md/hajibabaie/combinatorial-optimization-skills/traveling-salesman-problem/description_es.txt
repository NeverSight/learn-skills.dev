Cuando el usuario quiere modelar o resolver el problema del viajante - formulaciones exactas MIP (MTZ vs DFJ con cortes de eliminación de subtours perezosos), heurísticas de construcción (vecino más cercano, arista codiciosa, Christofides), mejora 2-opt/3-opt/Or-opt y movimientos al estilo Lin‑Kernighan. También se debe usar cuando el usuario mencione «TSP», «traveling salesman», «subtour elimination», «tour», «2-opt», «TSPLIB», «Hamiltonian cycle», o cuando un solo vehículo debe visitar cada nodo exactamente una vez y regresar. Para múltiples vehículos, capacidades o ventanas de tiempo, vea vehicle‑routing‑problem; para ingeniería de delta‑evaluación, vea local‑search‑and‑neighborhoods. Por favor, responde siempre en el idioma del usuario.
