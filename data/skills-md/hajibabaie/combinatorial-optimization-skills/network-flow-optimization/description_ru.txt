Когда пользователь хочет решать задачи потоков в сети — max‑flow/min‑cut, min‑cost flow, multicommodity flow или задачи кратчайших путей с помощью алгоритмов Дейкстры, Беллмана‑Форда и методов корректировки меток — используя networkx, gurobipy или специализированные алгоритмы, включая случаи, когда полная унимодулярность делает решения ЛП целочисленными бесплатно. Также применять, когда пользователь упоминает «network flow», «min‑cost flow», «max flow», «multicommodity», «shortest path», «flow conservation» или когда ограничения имеют структуру баланса потока в графе. Для задач одно‑к‑одному см. assignment‑problems; для сведений о двойственности и чувствительности — linear‑programming‑fundamentals.
