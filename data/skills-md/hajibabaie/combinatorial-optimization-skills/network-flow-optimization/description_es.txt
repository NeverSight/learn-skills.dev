Cuando el usuario quiera resolver problemas de flujo en una red - max‑flow/min‑cut, flujo de costo mínimo, flujo multicomodidad o caminos más cortos mediante Dijkstra, Bellman‑Ford y métodos de corrección de etiquetas - usando networkx, gurobipy o algoritmos especializados, incluido cuando la unimodalidad total hace que las soluciones de PL sean integrales de forma gratuita. También úselo cuando el usuario mencione "network flow", "min-cost flow", "max flow", "multicommodity", "shortest path", "flow conservation", o cuando las restricciones tengan una estructura de balance de flujo en un grafo. Para emparejamiento uno a uno, vea assignment‑problems; para antecedentes de dualidad y sensibilidad, vea linear‑programming‑fundamentals.
