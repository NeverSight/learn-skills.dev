Когда пользователь хочет обрабатывать ограничения внутри метаэвристик, выбирая среди функций штрафов (статических, динамических, адаптивных), операторов исправления, операторов, сохраняющих выполнимость, декодеров, обеспечивающих выполнимость, стохастического ранжирования и правил выполнимости Дэба. Также использовать, когда пользователь упоминает «constraint handling», «penalty function», «repair operator», «infeasible solutions», «feasibility rules», «adaptive penalty», или когда метаэвристика постоянно возвращает невыполнимые решения. Для выбора представления см. solution-encodings; для декодеров, обеспечивающих выполнимость, см. decoder-based-representations.
