Vérifiez si un compte ShiftCare est correctement configuré et fournissez une carte de pointage de configuration avec l'étape suivante pour chaque lacune. Couvre les clients, le personnel, les groupes de paie, les éléments de paie, le premier quart, les qualifications, les types de quart, les formulaires, les lieux et les équipes. Distinguie les données d'exemple avec lesquelles chaque nouveau compte est créé des données réellement saisies par une personne. Utilisez ceci lorsque l'utilisateur est nouveau sur ShiftCare, demande « mon compte est‑il configuré », « qu’est‑il reste à configurer » ou souhaite une liste de contrôle d’intégration.
