Rédigez une note sur un client ShiftCare, en choisissant correctement entre une communication client (dans le dossier du client) et une note de progression (sur un quart). Résout le client, lit ses quarts récents et ses notes pour assurer la continuité, propose une note personnalisée que vous dictez ou une note guidée qui interroge sur les lacunes de sécurité qu’une note laisse souvent ouvertes, avertit lorsque la formulation déclenchera un Signal de Soins, lit l’ensemble de la note pour une confirmation explicite, puis écrit une fois et vérifie. À utiliser pour « ajouter une note au dossier de Mary concernant l’appel de sa fille », « rédiger ce qui s’est passé pendant le quart de mardi », « consigner les retours de la famille », « enregistrer un numéro de référence pour ce client ». Pas pour modifier ou supprimer une note existante, lister les communications passées d’un client, ajouter une pièce jointe, enregistrer un kilométrage ou effacer un Signal de Soins — MCP n’expose aucune de ces fonctions, et cette compétence le signalera et s’arrêtera. Écrit les données ; jamais sans confirmation.

Veuillez toujours répondre dans la langue de l'utilisateur.
