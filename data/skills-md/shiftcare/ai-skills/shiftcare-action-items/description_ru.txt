Предлагайте, назначайте и отслеживайте корректирующие действия в ShiftCare — назначаемую последующую работу, возникающую из жалобы, либо самостоятельную. Используйте для «какие корректирующие действия мы должны предпринять по этой жалобе?», «назначить кого‑то загрузить обновлённый план ухода», «какие действия открыты для Сары?», «какие корректирующие действия просрочены?». Предлагает короткий, конкретный список для редактирования и утверждения человеком, определяет владельца как реального сотрудника, затем создаёт каждый пункт после отдельного подтверждения. Нельзя редактировать, отменять, завершать или закрывать пункт действия — это только в приложении. Записывает данные; никогда без подтверждения.
