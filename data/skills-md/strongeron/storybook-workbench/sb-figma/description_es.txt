El puente Figma↔Storybook, en ambas direcciones, a través del Figma MCP nativo. diseño→código: asigne tokens de base (color/espaciado/tipo) a partir de variables de Figma con diseño↔paridad de código + deriva, y entregue componentes de Figma aprobados (extraer → construir → incrustar), creando historias a través de las reglas de sb-stories. código → diseño: cree asignaciones de Code Connect a partir de componentes + historias + paridad de tokens + uso para que el modo Figma Dev muestre el código real. Úselo para 'sincronizar mis tokens Figma', 'asignar variables Figma a mi sistema de diseño', 'entregar este diseño Figma aprobado', 'verificar diseño↔paridad de tokens de código', 'conectar mis componentes a Figma/conectar código'. NO para crear prototipos/iterar un diseño indeciso (eso es sb-explore).
