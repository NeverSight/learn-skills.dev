Figma↔Storybook ブリッジ (ネイティブ Figma MCP 経由の両方向)。デザイン→コード: デザイン↔コード パリティ + ドリフトを使用して Figma 変数から基盤トークン (色/間隔/タイプ) をマップし、承認された Figma コンポーネント (抽出 → ビルド → 埋め込み) を提供し、sb-stories のルールに従ってストーリーをオーサリングします。コード→デザイン: コンポーネント + ストーリー + トークン パリティ + 使用法から Code Connect マッピングを構築し、Figma 開発モードで実際のコードを表示します。 「Figma トークンを同期する」、「Figma 変数を設計システムにマッピングする」、「この承認された Figma 設計を提供する」、「設計↔コード トークン パリティを確認する」、「コンポーネントを Figma / コード接続に接続する」ために使用します。未決定の設計のプロトタイピング/反復用ではありません (sb-explore です)。
