Le pont Figma↔Storybook, dans les deux sens, via le MCP natif Figma. conception → code : mapper les jetons de fondation (couleur/espacement/type) à partir des variables Figma avec la parité conception↔code + dérive, et fournir des composants Figma approuvés (extraire → construire → intégrer), en créant des histoires via les règles de sb-stories. code → conception : créez des mappages Code Connect à partir de composants + histoires + parité de jetons + utilisation afin que le mode Figma Dev affiche le vrai code. Utiliser pour « synchroniser mes jetons Figma », « mapper les variables Figma à mon système de conception », « livrer cette conception Figma approuvée », « vérifier la parité des jetons de conception↔code », « connecter mes composants à Figma/code connect ». PAS pour le prototypage/itération d'une conception indécise (c'est sb-explore).
