기본 Figma MCP를 통해 Figma ← Storybook 브리지, 양방향. 디자인→코드: 디자인→코드 패리티 + 드리프트를 사용하여 Figma 변수의 기반 토큰(색상/간격/유형)을 매핑하고 승인된 Figma 구성 요소(추출 → 빌드 → 포함)를 전달하고 SB-Stories 규칙을 통해 스토리를 작성합니다. 코드→디자인: 구성 요소 + 스토리 + 토큰 패리티 + 사용법으로 Code Connect 매핑을 구축하여 Figma Dev Mode에서 실제 코드를 표시합니다. '나의 Figma 토큰 동기화', '내 디자인 시스템에 Figma 변수 매핑', '이 승인된 Figma 디자인 전달', '디자인←코드 토큰 패리티 확인', '내 구성 요소를 Figma에 연결/코드 연결'에 사용합니다. 결정되지 않은 디자인(sb-explore)의 프로토타입화/반복에는 적합하지 않습니다.
