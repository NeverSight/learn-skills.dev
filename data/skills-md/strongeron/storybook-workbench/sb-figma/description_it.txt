Il ponte Figma↔Storybook, in entrambe le direzioni, tramite il nativo Figma MCP. design→codice: mappa i token di base (colore/spaziatura/tipo) dalle variabili Figma con parità di design↔codice + deriva e fornisce componenti Figma approvati (estrai → costruisci → incorpora), creando storie tramite le regole di sb-stories. codice → progettazione: crea mappature Code Connect da componenti + storie + parità token + utilizzo in modo che Figma Dev Mode mostri il codice reale. Utilizzare per "sincronizzare i miei token Figma", "mappare le variabili Figma sul mio sistema di progettazione", "consegnare questo progetto Figma approvato", "controllare la parità dei token di progettazione↔codice", "collegare i miei componenti a Figma/connessione codice". NON per prototipare/iterare un progetto indeciso (questo è sb-explore).
