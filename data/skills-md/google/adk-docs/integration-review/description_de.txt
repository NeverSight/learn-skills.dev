Überprüft eine ADK‑Integrationsdokumentationsseite (eine Markdown‑Datei unter docs/integrations/) oder einen Integrations‑Pull‑Request auf Korrektheit, Struktur, Stil, funktionierenden Code, gültige Links und Katalog‑Konventionen. Erstellt einen priorisierten Review‑Bericht, eine empfohlene Entscheidung (genehmigen, Änderungen anfordern oder PR schließen), eine übergeordnete Review‑Antwort und Entwurfs‑Kommentare mit Zeilenverankerung; behebt Probleme nur, wenn ausdrücklich darum gebeten wird. Wird ausgelöst durch „integration‑review“, „review integration page“, „review integration PR“, „review this integration“, „check integration docs“.

Bitte immer in der Sprache des Benutzers antworten.
