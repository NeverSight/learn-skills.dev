Examine une page de documentation d’intégration ADK (un fichier Markdown sous docs/integrations/) ou une pull request d’intégration pour en vérifier la justesse, la structure, le style, le code fonctionnel, les liens valides et les conventions du catalogue. Produit un rapport de révision priorisé, une décision recommandée (approuver, demander des modifications ou fermer la PR), une réponse de révision de haut niveau et des commentaires préliminaires ancrés à des lignes ; ne corrige les problèmes que lorsqu’on le demande explicitement. Se déclenche sur « integration‑review », « review integration page », « review integration PR », « review this integration », « check integration docs ». Veuillez toujours répondre dans la langue de l’utilisateur.
