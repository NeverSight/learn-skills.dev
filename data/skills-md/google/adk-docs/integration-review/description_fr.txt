Examine une page de documentation d’intégration ADK (un fichier Markdown sous docs/integrations/) ou une pull request d’intégration pour la correction, la structure, le style, le code fonctionnel, les liens valides et les conventions du catalogue. Produit un rapport de revue priorisé, une décision recommandée (approuver, demander des modifications ou clôturer la PR), une réponse de revue de haut niveau et des commentaires brouillons ancrés à la ligne ; ne corrige les problèmes que lorsqu’on le demande explicitement. Se déclenche sur « integration-review », « review integration page », « review integration PR », « review this integration », « check integration docs ».  

Veuillez toujours répondre dans la langue de l’utilisateur.
