ADK統合ドキュメントページ（docs/integrations/ 配下の Markdown ファイル）または統合プルリクエストを、正確性・構成・スタイル・動作コード・有効なリンク・カタログ規約に沿ってレビューします。優先度付けされたレビュー報告書、推奨決定（承認、変更要求、または PR クローズ）、上位レベルのレビュー応答、そしてドラフトの行アンカーコメントを作成します；問題は明示的に指示された場合にのみ修正します。「integration-review」「review integration page」「review integration PR」「review this integration」「check integration docs」でトリガーされます。

常にユーザーの言語で応答してください。
