ADK統合ドキュメントページ（docs/integrations/以下のMarkdownファイル）または統合プルリクエストを、正確性、構造、スタイル、動作コード、リンクの有効性、カタログ規約に基づいてレビューします。優先順位付けされたレビュー報告書、推奨決定（承認、変更要求、またはPRクローズ）、トップレベルのレビュー応答、そしてドラフトの行位置コメントを作成します；問題の修正は明示的に要請された場合のみ行います。「integration‑review」「review integration page」「review integration PR」「review this integration」「check integration docs」のいずれかでトリガーされます。
