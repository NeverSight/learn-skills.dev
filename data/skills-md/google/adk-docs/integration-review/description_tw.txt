審查 ADK 整合文件頁面（位於 docs/integrations/ 目錄下的 Markdown 檔）或整合的 pull request，檢查正確性、結構、風格、可執行程式碼、有效連結以及目錄慣例。產出優先排序的審查報告、建議的決策（批准、要求變更或關閉 PR）、頂層審查回應，以及草稿式的行內註解；僅在明確要求時才修正問題。觸發關鍵字包括「integration‑review」、「review integration page」、「review integration PR」、「review this integration」以及「check integration docs」。請始終以使用者的語言回應。
