審查 ADK 整合文件頁面（位於 docs/integrations/ 之下的 Markdown 檔案）或整合的 Pull Request，檢查其正確性、結構、風格、可執行程式碼、有效連結以及目錄慣例。產出優先排序的審查報告、建議的決策（批准、要求變更或關閉 PR）、最高層級的審查回覆，以及草稿形式的行內註解；僅在明確要求時才修正問題。觸發詞包括「integration‑review」、「review integration page」、「review integration PR」、「review this integration」與「check integration docs」。請始終以使用者的語言回覆。
