يتحقق من أن كل كتلة كود بايثون في ملف ماركداون تُترجم وتُنفَّذ فعليًا، عبر استخراج كل كتلة إلى ملف مؤقت، وتشغيلها في عملية فرعية معزولة، وكتابة تقرير نجاح/فشل مع تغطية لكل مقطع. يُستَخدم عندما يطلب المستخدم التحقق أو اختبار أو تصديق عينات الكود في ملف README أو دليل أو صفحة توثيق؛ أو يريد معرفة أي المقاطع في ملف ماركداون مكسورة أو قديمة؛ أو يطلب تقرير تحقق من المقاطع. لا تُستَخدم لتشغيل مجموعة اختبارات المشروع (شغّل pytest مباشرة)، أو للتحقق من نمط الكود أو تنسيقه (استخدم `adk-style`)، أو لإنشاء عينة عامل قابلة للتنفيذ جديدة (استخدم `adk-sample-creator`).
