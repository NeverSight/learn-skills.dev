Vérifie que chaque bloc de code Python dans un fichier Markdown se compile et s’exécute réellement, en extrayant chaque bloc dans un fichier temporaire, en l’exécutant dans un sous‑processus isolé, et en rédigeant un rapport de réussite/échec avec une couverture par extrait. À utiliser lorsque l’utilisateur demande de vérifier, tester ou valider les exemples de code dans un README, un guide ou une page de documentation ; veut savoir quels extraits d’un fichier Markdown sont cassés ou obsolètes ; ou demande un rapport de vérification d’extraits. Ne pas utiliser pour exécuter la suite de tests du projet (exécutez pytest directement), pour vérifier le style ou le formatage du code (utilisez `adk-style`), ou pour créer un nouvel agent d’exemple exécutable (utilisez `adk-sample-creator`).
