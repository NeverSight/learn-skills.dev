Vérifie que chaque bloc de code Python dans un fichier Markdown se compile et s’exécute réellement, en extrayant chaque bloc dans un fichier temporaire, en l’exécutant dans un sous‑processus isolé, et en rédigeant un rapport de succès/échec avec la couverture par extrait. À utiliser lorsque l’utilisateur demande à vérifier, tester ou valider les exemples de code dans un README, un guide ou une page de documentation ; souhaite savoir quels extraits d’un fichier Markdown sont cassés ou périmés ; ou demande un rapport de vérification d’extraits. Ne pas l’utiliser pour exécuter la suite de tests du projet (exécuter pytest directement), pour vérifier le style ou le format du code (utiliser `adk-style`), ni pour créer un nouvel agent d’exemple exécutable (utiliser `adk-sample-creator`).
