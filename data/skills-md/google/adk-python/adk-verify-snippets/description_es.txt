Comprueba que cada bloque de código Python en un archivo Markdown realmente se compile y ejecute, extrayendo cada bloque a un archivo temporal, ejecutándolo en un subproceso aislado y generando un informe de aprobado/reprobado con cobertura por fragmento. Úsalo cuando el usuario solicite verificar, probar o validar los ejemplos de código en un README, una guía o una página de documentación; quiera saber qué fragmentos en un archivo Markdown están rotos o desactualizados; o pida un informe de verificación de fragmentos. No lo uses para ejecutar la suite de pruebas del proyecto (ejecuta pytest directamente), para comprobar el estilo o formateo del código (usa `adk-style`), o para crear un nuevo agente de muestra ejecutable (usa `adk-sample-creator`).
