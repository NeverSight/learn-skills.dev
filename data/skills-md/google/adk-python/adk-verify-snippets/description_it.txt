Verifica che ogni blocco di codice Python in un file Markdown sia effettivamente compilabile ed eseguibile, estraendo ciascun blocco in un file temporaneo, eseguendolo in un processo isolato e redigendo un rapporto di esito positivo/negativo con copertura per singolo snippet. Da utilizzare quando l'utente richiede di verificare, testare o convalidare i campioni di codice in un README, una guida o una pagina di documentazione; desidera sapere quali snippet in un file Markdown sono rotti o obsoleti; o richiede un rapporto di verifica degli snippet. Non usarlo per eseguire l'insieme dei test del progetto (eseguire direttamente pytest), per controllare lo stile o la formattazione del codice (usare `adk-style`), o per creare un nuovo agente di esempio eseguibile (usare `adk-sample-creator`).
