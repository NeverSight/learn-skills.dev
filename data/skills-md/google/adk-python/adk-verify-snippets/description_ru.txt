Проверяет, что каждый блок кода Python в файле Markdown действительно компилируется и исполняется, извлекая каждый блок во временный файл, запускает его в изолированном подпроцессе и формирует отчёт о прохождении/провале с покрытием по каждому фрагменту. Используйте, когда пользователь просит проверить, протестировать или валидировать примеры кода в README, руководстве или странице документации; хочет узнать, какие фрагменты в Markdown‑файле сломаны или устарели; или запрашивает отчёт о проверке фрагментов. Не используйте для запуска тестового набора проекта (запускайте pytest напрямую), для проверки стиля или форматирования кода (используйте `adk-style`) или для создания нового исполняемого образца агента (используйте `adk-sample-creator`).
