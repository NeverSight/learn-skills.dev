Markdown 파일의 모든 Python 코드 블록이 실제로 컴파일되고 실행되는지 확인합니다. 각 블록을 임시 파일에 추출하고, 격리된 하위 프로세스에서 실행한 뒤, 스니펫별 커버리지를 포함한 통과/실패 보고서를 작성합니다. 사용자는 README, 가이드, 문서 페이지의 코드 샘플을 검증, 테스트, 또는 확인하고 싶을 때; Markdown 파일에서 어느 스니펫이 깨졌거나 오래되었는지 알고 싶을 때; 혹은 스니펫 검증 보고서를 요청할 때 사용합니다. 프로젝트의 테스트 스위트를 실행할 때는 사용하지 마세요(pytest를 직접 실행). 코드 스타일이나 포맷을 확인할 때는 `adk-style`을 사용하고, 새로운 실행 가능한 샘플 에이전트를 작성할 때는 `adk-sample-creator`를 사용하세요.
