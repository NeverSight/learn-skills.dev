Это умение следует использовать, когда пользователь просит реализовать, добавить или набросать новую функцию, роутер или эндпоинт в бекэнде FastAPI — например, «FastAPI에 게시글 API 추가해줘», «이 엔드포인트 구현해줘», «add a new FastAPI router/endpoint», «implement this backend feature in FastAPI». Оно генерирует файлы роутера/схемы/модели/сервиса в соответствии со стандартной структурой проекта FastAPI. Не использовать для не‑FastAPI бекендов, фронтенд‑работы или простых исправлений багов.
