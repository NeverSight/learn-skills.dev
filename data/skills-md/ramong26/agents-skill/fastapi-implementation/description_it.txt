Questa funzionalità dovrebbe essere usata quando l'utente chiede di implementare, aggiungere o creare lo scheletro di una nuova feature, router o endpoint in un backend FastAPI — ad esempio "FastAPI에 게시글 API 추가해줘", "이 엔드포인트 구현해줘", "add a new FastAPI router/endpoint", "implement this backend feature in FastAPI". Genera file router/schema/model/service seguendo il layout standard di un progetto FastAPI. Non usarla per backend non FastAPI, lavoro di frontend o semplici correzioni di bug.

Rispondi sempre nella lingua dell'utente.
