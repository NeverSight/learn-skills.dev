Cette compétence doit être utilisée lorsque l'utilisateur demande à implémenter, ajouter ou générer la structure d'une nouvelle fonctionnalité, d'un routeur ou d'un point de terminaison dans un backend FastAPI — par exemple « FastAPI에 게시글 API 추가해줘 », « 이 엔드포인트 구현해줘 », « add a new FastAPI router/endpoint », « implement this backend feature in FastAPI ». Elle génère les fichiers router/schema/model/service en suivant la disposition standard d'un projet FastAPI. Ne pas l'utiliser pour des backends non FastAPI, du travail frontend ou des corrections de bugs simples.

Veuillez toujours répondre dans la langue de l'utilisateur.
