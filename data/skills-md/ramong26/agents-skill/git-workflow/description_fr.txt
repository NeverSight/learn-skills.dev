Cette compétence doit être utilisée lorsque l'utilisateur demande à créer ou renommer une branche, choisir un nom de branche, rédiger ou valider un message de commit, commettre des changements, préparer ou ouvrir une pull request, ou vérifier les conventions de branche, de commit ou de PR. Elle applique les messages de commit coréens, les commits de type‑scope‑sujet conventionnels, la nomenclature des branches et le format de PR [nom‑de‑branche] - résumé.

Veuillez toujours répondre dans la langue de l'utilisateur.
