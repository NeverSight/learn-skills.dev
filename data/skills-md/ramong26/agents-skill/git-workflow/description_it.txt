Questa funzionalità dovrebbe essere usata quando l'utente chiede di creare o rinominare un branch, scegliere un nome per il branch, scrivere o convalidare un messaggio di commit, effettuare il commit delle modifiche, preparare o aprire una pull request, o verificare le convenzioni di branch, commit o PR. Applica messaggi di commit in coreano, commit convenzionali tipo‑scope‑soggetto, denominazione dei branch e il formato PR [nome-branch] - riepilogo.

Rispondi sempre nella lingua dell'utente.
