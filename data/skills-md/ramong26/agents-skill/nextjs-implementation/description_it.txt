Questa competenza dovrebbe essere utilizzata quando l'utente chiede di implementare, aggiungere o creare uno scheletro di una nuova pagina, funzionalità o sezione UI in un frontend Next.js (App Router) — ad es. "새 페이지 만들어줘", "게시글 목록 화면 구현해줘", "이 API 연결하는 화면 만들어줘", "add a new page/feature to the Next.js app". Genera file app/page/widgets/entities/shared seguendo il layering del Feature‑Sliced Design con TanStack Query. Non usarla per frontend non Next.js, lavoro backend o semplici ritocchi di stile.

Rispondi sempre nella lingua dell'utente.
