Esta habilidad debe usarse cuando el usuario solicite implementar, agregar o crear una nueva página, funcionalidad o fragmento de UI en un frontend de Next.js (App Router), por ejemplo: "새 페이지 만들어줘", "게시글 목록 화면 구현해줘", "이 API 연결하는 화면 만들어줘", "add a new page/feature to the Next.js app". Genera archivos app/page/widgets/entities/shared siguiendo la capa de Feature‑Sliced Design con TanStack Query. No debe usarse para frontends que no sean Next.js, trabajo de backend, o ajustes simples de estilo.
