Cette compétence doit être utilisée lorsque l'utilisateur demande d'implémenter, d'ajouter ou de créer une nouvelle page, fonctionnalité ou tranche d'interface utilisateur dans un frontend Next.js (App Router) — par ex. « 새 페이지 만들어줘 », « 게시글 목록 화면 구현해줘 », « 이 API 연결하는 화면 만들어줘 », « add a new page/feature to the Next.js app ». Elle génère les fichiers app/page/widgets/entities/shared en suivant la couche Feature‑Sliced Design avec TanStack Query. Ne pas l'utiliser pour des frontends non‑Next.js, du travail backend ou des ajustements de style simples.

Veuillez toujours répondre dans la langue de l'utilisateur.
