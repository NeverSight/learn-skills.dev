Этот навык следует использовать, когда пользователь просит реализовать, добавить или создать шаблон новой страницы, функции или UI‑среза во фронтенде Next.js (App Router) — например, «새 페이지 만들어줘», «게시글 목록 화면 구현해줘», «이 API 연결하는 화면 만들어줘», «add a new page/feature to the Next.js app». Он генерирует файлы app/page/widgets/entities/shared согласно слоистости Feature‑Sliced Design с TanStack Query. Не используйте его для не‑Next.js фронтендов, бэкенд‑работы или простых правок стилей.

Пожалуйста, всегда отвечайте на языке пользователя.
