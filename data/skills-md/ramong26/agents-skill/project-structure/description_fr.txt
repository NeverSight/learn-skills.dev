Cette compétence doit être utilisée lorsque l'utilisateur demande comment organiser ou structurer le code. Elle impose une structure où chaque tâche correspond à un dossier : dossiers de domaine colocés, imports uniquement descendants, accès inter‑domaine via une interface publique, et partagé uniquement pour le code utilisé par deux domaines ou plus. Ne l’utilisez pas pour implémenter la logique de la fonctionnalité elle‑même.

Veuillez toujours répondre dans la langue de l’utilisateur.
