Cette compétence doit être utilisée lorsque l'utilisateur demande « 관련 스킬 찾아줘 », « 어떤 스킬을 써야 해? », « 스킬 후보 보여줘 », « 이 작업에 맞는 스킬 추천해줘 », « 스킬 조합을 골라줘 », « find relevant skills », « show skill candidates », ou « which skills should I use », ou qu'il sollicite une implémentation multi‑domaine telle qu’une API backend et une intégration frontend. Elle présente jusqu’à trois candidats de compétence avec leurs rôles et l’ordre recommandé, puis attend le choix de l’utilisateur. Ne pas l’utiliser pour des modifications simples d’un seul fichier.
