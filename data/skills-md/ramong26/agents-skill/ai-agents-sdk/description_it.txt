Questa competenza dovrebbe essere utilizzata quando l'utente richiede di costruire o adattare un'app OpenAI Agents SDK, creare un prototipo di agente, aggiungere strumenti o passaggi, collegare un flusso di lavoro Codex a un agente o aggiungere valutazioni di agente mirate. Non si applica alla scrittura generica di prompt o al normale debug dell'API OpenAI.
