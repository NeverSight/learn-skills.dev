تشغيل شجرات العمل المدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، ومستودعات الأكواد، والأتمتة، والملفات الناتجة، وتبادل المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على شجرة git الخام، أو PTYs العشوائية، أو الاستخدام الحاسوبي عندما تكون حالة Orca متضمنة. استخدم الاستخدام الحاسوبي فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية لا يمكن لسطر الأوامر أو نظام الملفات أو واجهة برمجة التطبيقات القيام به.
