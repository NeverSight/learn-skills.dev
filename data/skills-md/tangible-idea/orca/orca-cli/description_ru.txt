Оперировать управляемыми Orca рабочими деревьями, контекстами папок, терминалами, репозиториями, автоматизациями, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Использовать, когда пользователь говорит "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" или "share skills". Предпочитать его перед чистым git worktree, ad hoc PTY или использованием компьютера, когда вовлечено состояние Orca. Использовать Computer Use только тогда, когда требуется управлять видимым окном GUI, которое нельзя контролировать через CLI, файловую систему или API.
