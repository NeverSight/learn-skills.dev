Analyser de bout en bout une base de code transmise et répertorier ses processus métier, son inventaire des fonctionnalités, son architecture, ses flux d’exécution, son modèle de données et ses risques techniques dans un rapport Markdown ainsi que dans un rapport HTML interactif. À utiliser lorsque l’utilisateur souhaite comprendre un projet hérité ou peu familier, s’approprier une base de code, préparer un document de transfert ou demander comment le système fonctionne sur la base du code existant.
