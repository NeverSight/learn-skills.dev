Analizar de principio a fin una base de código entregada y reflejar sus procesos empresariales, su inventario de funciones, su arquitectura, sus flujos de tiempo de ejecución, su modelo de datos y sus riesgos técnicos en un informe Markdown, además de en un informe HTML interactivo. Utilícelo cuando el usuario quiera comprender un proyecto heredado o desconocido, familiarizarse con una base de código, preparar un documento de traspaso o preguntar cómo funciona el sistema a partir del código existente.
