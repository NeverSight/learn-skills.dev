A skill to append “what was done and what was decided” to the daily log at each work milestone. Only the trigger timing (trigger conditions) and the content to record are defined. Apply it proactively during work without waiting for a user request. Formatting, append procedures, and file selection are delegated to [[obsidian‑log]], while the storage location, file name, and timestamp are left to [[obsidian‑config]]. Do not aggregate, summarize, or generate reports from the logs (the work is to generate them as separate notes).
