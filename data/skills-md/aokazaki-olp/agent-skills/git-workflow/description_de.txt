Vor der Durchführung von Git/GitHub-Aktionen (Commit, Branch Creation, Merge, Push, PR) geltende Betriebsrichtlinien. Definiert das Commit-Nachrichtenformat, die Zweighierarchie, die Merge-Richtlinie und die Verwendung der gh CLI. Beziehen Sie sich darauf, wenn ein Benutzer einen Commit/Branch/Merge/Push/PR anfordert oder bevor er Änderungen staging/committet. Es führt kein Code-Design, keine Überprüfung oder Dateibearbeitung selbst durch (diese werden separat behandelt).
