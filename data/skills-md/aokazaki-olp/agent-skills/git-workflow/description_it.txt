Abilità per applicare le regole operative prima di eseguire operazioni git/GitHub (commit, creazione di branch, merge, push, PR). Definisce il formato del messaggio di commit, la gerarchia dei branch, la policy di merge e come utilizzare il CLI gh. Viene richiamata quando un utente richiede un commit/branch/merge/push/PR, o prima di effettuare lo staging/commit delle modifiche. Non esegue la progettazione del codice, la revisione o la modifica dei file stessi (questi sono gestiti separatamente).

Rispondi sempre nella lingua dell'utente.
