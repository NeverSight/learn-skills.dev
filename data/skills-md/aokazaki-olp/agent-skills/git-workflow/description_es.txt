Directrices operativas que se aplicarán antes de realizar acciones de Git/GitHub (commit, creación de sucursales, fusión, push, PR). Define el formato del mensaje de confirmación, la jerarquía de ramas, la política de fusión y cómo usar la CLI de gh. Consulte estas pautas cuando un usuario solicite un commit/branch/merge/push/PR, o antes de organizar/confirmar cambios. No realiza el diseño de código, la revisión o la edición de archivos por sí mismo (estos se manejan por separado).
