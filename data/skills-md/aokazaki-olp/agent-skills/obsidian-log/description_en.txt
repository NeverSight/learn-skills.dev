Skill for writing/reading “append-type daily logs” in an Obsidian vault. Append entries chronologically to a single file per day (`{date}.md`). Use it for things like work records, operation logs, and accumulating context—“collect each time to compile later.” Before using, always resolve the vault path, storage folder, date/time, and time zone with [[obsidian-config]]. Creating a new note per entry (with title, no overwriting, conflict numbering) is not handled by this skill but delegated to [[obsidian-config]] + [[obsidian-markdown]]. It also does not perform log aggregation, summarization, or report generation (that’s the caller’s or a reporting skill’s job).
