Навык для написания/чтения «дневных журналов‑добавок» в хранилище Obsidian. Для каждого дня используется отдельный файл (`{date}.md`), в который записи добавляются хронологически. Он служит для таких целей, как рабочие записи, операционные журналы и накопление контекста — по сути «сохраняй каждую запись сейчас, чтобы собрать их позже». Перед использованием всегда определяйте путь к хранилищу, папку назначения, дату/время и часовой пояс с помощью [[obsidian-config]]. Создание новой заметки для каждой записи (с заголовком, без перезаписи, с номером конфликта) не реализовано этим навыком, а делегируется [[obsidian-config]] + [[obsidian-markdown]]. Этот навык не агрегирует, не резюмирует и не генерирует отчёты из журналов (это задача вызывающего или отдельного навыка генерации отчётов).
