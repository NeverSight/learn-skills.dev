Générez un fichier de transfert de session autonome afin que le travail puisse se poursuivre dans un autre outil d’IA sans aucune réexplication. Déclenchez le mode OUTPUT chaque fois que l’utilisateur dit « handoff », « /handoff », « write a handoff », « I'm about to run out of messages », « session limit », « continue this somewhere else », « hand this off », demande de créer un point de contrôle/enregistrer l’état avant une réinitialisation du contexte ou une coupure de limite d’usage, ou montre des signes clairs d’atteindre une limite d’usage dans une conversation qui contient déjà des décisions réelles ou du travail en cours à préserver. Déclenchez le mode INTAKE chaque fois qu’un message inclut ou fait référence à un fichier joint correspondant au nom de fichier/matière du transfert (voir le corps) — la présence de ce fichier est le signal décisif, dans n’importe quelle langue et quel que soit le verbe accompagnant (« intake », « resume », « use this », « ingest », « acquisisci », « importa », « leggi », etc., non exhaustif). Consultez le corps pour les règles complètes des deux modes, y compris quand NE PAS déclencher.

Veuillez toujours répondre dans la langue de l’utilisateur.
