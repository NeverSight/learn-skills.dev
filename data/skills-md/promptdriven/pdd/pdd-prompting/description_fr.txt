Le guide des prompts PDD. À utiliser lorsque vous rédigez, modifiez ou relisez une invite de module (*.prompt.md), un scénario ou des cas de test, lorsque la personne demande comment rédiger des invites dans PDD, ou demande de configurer une vérification du comportement réel pour un dépôt. Dans PDD, les prompts sont la source et le code les suit.
