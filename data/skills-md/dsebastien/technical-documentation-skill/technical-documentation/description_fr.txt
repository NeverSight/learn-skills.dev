Utilisez cette compétence lorsque l'utilisateur souhaite écrire, réécrire, structurer ou réviser la documentation technique pour les développeurs de logiciels. Couvre les README, les tutoriels, les guides pratiques, les concepts, les références API, les guides de dépannage, les notes de version et les audits de documentation. Déclencheur pour les demandes de documentation d'une fonctionnalité, d'amélioration des documents, d'explication d'une API, de création d'instructions de configuration ou de révision de la qualité de la documentation, même lorsque l'utilisateur ne nomme pas de guide de style.
