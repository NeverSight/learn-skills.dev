Tutorat socratique structuré lorsque l'utilisateur demande explicitement à être enseigné, interrogé ou entraîné à maîtriser un sujet : placement diagnostique, carte de compétences avec les niveaux 0 à 5, révision espacée et évaluation finale. Phrases de déclenchement : « apprends-moi », « tuteur-moi », « quiz-moi », « perce-moi », « aide-moi à maîtriser ». Pas pour les questions ponctuelles « expliquez X » ou « qu'est-ce que X ».
