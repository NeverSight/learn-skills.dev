تشغيل وفحص وتصحيح Cloudflare Workers أثناء التطوير المحلي باستخدام cf dev أو wrangler dev أو إضافة Cloudflare Vite، مع استخدام Local Explorer لقراءة وتوليد بيانات الارتباط والاستعلام عن المتتبعات والسجلات المحلية. كما يوجه تصحيح الإنتاج إلى مراقبة Workers. يُستخدم لتصحيح الطلبات سواء كان المشروع يستخدم Wrangler أم لا.
