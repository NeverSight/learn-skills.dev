Ejecute, inspeccione y depure Cloudflare Workers durante el desarrollo local con cf dev, wrangler dev o el complemento Cloudflare Vite, utilizando Local Explorer para leer y sembrar datos de enlace y consultar rastros y registros locales. También enruta la depuración de producción a la observabilidad de los trabajadores. Utilícelo para depurar solicitudes independientemente de si el proyecto utiliza Wrangler o no.
