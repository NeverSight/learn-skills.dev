Obtenga una aplicación Cloudflare Workers a una solicitud local de trabajo conectando sus enlaces, secretos y datos iniciales, y luego verificando el comportamiento real de la aplicación. Úselo para la configuración o incorporación de aplicaciones después de que exista el proyecto; use frameworks-on-cloudflare o cf-cli para crear o configurar el proyecto, y wrangler o cf-cli para comandos aislados.
