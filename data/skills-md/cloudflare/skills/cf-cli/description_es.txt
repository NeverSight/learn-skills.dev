CLI oficial cf de Cloudflare (beta) para los proyectos públicos Cloudflare API y Workers. Se utiliza para buscar y ejecutar comandos de Cloudflare desde el terminal: inicio de sesión y perfiles, cf cli search, cf schema, cf deploy/dev/build, comandos de recursos para DNS, zonas, D1, KV y R2, y para elegir entre cf y Wrangler en un proyecto.
