Cloudflare's official cf CLI (beta) for the public Cloudflare API and Workers projects. Utilisé pour rechercher et exécuter des commandes Cloudflare à partir du terminal — connexion et profils, cf cli search, cf schema, cf deploy/dev/build, commandes de ressources pour DNS, zones, D1, KV et R2 — et pour choisir entre cf et Wrangler dans un projet.
