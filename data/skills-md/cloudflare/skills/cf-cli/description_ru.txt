Официальный cf CLI (бета) Cloudflare для публичного API Cloudflare и проектов Workers. Используется для поиска и выполнения команд Cloudflare из терминала — вход в систему и профили, поиск cf cli, cf schema, cf deploy/dev/build, команды ресурсов для DNS, зон, D1, KV и R2 — а также для выбора между cf и Wrangler в проекте.
