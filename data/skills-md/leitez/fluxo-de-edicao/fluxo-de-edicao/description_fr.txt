Guide la personne pour créer son propre flux de montage vidéo avec Claude Code (YouTube, reels, vidéo narrée ou autre format) : interview sur le type de vidéo, le programme de révision (ou aucun), la transcription, le motion, la caméra et le son ; analyse ses références pour créer le style ; et rédige les compétences de chaque étape, la compétence maîtresse, les règles communes et le cahier d’apprentissages, à partir d’un flux de 8 étapes déjà testé sur des vidéos réelles. Utilise /fluxo-de-edicao, ou lorsque la personne demande de monter, d’adapter ou de poursuivre son flux de montage.
