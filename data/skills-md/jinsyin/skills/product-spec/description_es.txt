Gestionar especificaciones funcionales del producto—listas de funciones, lógica de interacción y adiciones y registros de cambios versionados al estilo Flyway—produciendo archivos de especificación que pueden ser alimentados directamente a herramientas de diseño de IA como Claude Design, v0, Figma Make, Lovable, etc. Las especificaciones se colocan bajo products/specs/<línea de producto>/, con una cadena V (V1__baseline, V2__xxx) que documenta la evolución; el CURRENT.md sintetizado es el punto de entrada único para alimentar las herramientas de diseño. Se utiliza cuando el usuario dice “crear especificación funcional del producto”, “escribir especificaciones funcionales”, “registrar este cambio de producto”, “generar especificaciones para herramientas de diseño”, “sincronizar CURRENT.md”, “product‑spec”, y también para inicializar especificaciones para una nueva línea de producto o cuando la divergencia entre especificación e implementación requiere verificación.
