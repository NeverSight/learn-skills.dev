مراجعة ودمج الـ PRs المفتوحة على GitHub بطريقة squash واحدة تلو الأخرى عبر `gh`، مع اتخاذ المستخدم للقرار لكل منها. يُستخدم عندما يرغب المستخدم في مراجعة أو فرز أو دمج الـ PRs المفتوحة، بما في ذلك الـ PRs المفتوحة بـ `self-improve`. الوسائط `[<pr#>] [-R <owner/repo>]`.

يرجى دائمًا الرد بلغة المستخدم.
