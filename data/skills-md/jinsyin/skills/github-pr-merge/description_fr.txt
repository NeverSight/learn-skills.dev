Examinez et fusionnez en squash les PR GitHub ouvertes une à une via `gh`, l'utilisateur décide de chacune. Utilisez-le lorsque l'utilisateur souhaite examiner, trier ou fusionner les PR ouvertes, y compris les PR `self-improve` ouvertes. Args `[<pr#>] [-R <owner/repo>]`.

Veuillez toujours répondre dans la langue de l'utilisateur.
