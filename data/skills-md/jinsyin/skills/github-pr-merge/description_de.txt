Überprüfen und Squash-Zusammenführen offener GitHub-PRs nacheinander über "gh", wobei der Benutzer jeweils entscheidet. Wird verwendet, wenn der Benutzer offene PRs überprüfen, sortieren oder zusammenführen möchte, einschließlich geöffneter PRs zur Selbstverbesserung. Args `[<pr#>] [-R<owner/repo>]`.
