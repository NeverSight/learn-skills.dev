Use when work splits into two or more independent parallel sub-agent tracks — exhaustive review or audit, inventorying an unknown-size surface, broad research needing cross-checked claims, codebase mapping, migration or sweep work, adversarial critique of a decision — or when the user asks to fan out, run a team, or cross-check work across independent agents. Near miss: a single bounded sub-agent task, work the main agent can finish in a handful of tool calls, and overlapping mutators without disjoint ownership or isolation.
