Verwenden Sie diese Option, wenn der Benutzer fragt, ob ein Design, eine Modulgrenze, eine API, ein Datenfluss, ein Designdokument oder eine Änderungsform solide ist, Bestand hat oder einer kritischen Prüfung standhält – eine Beurteilung auf der Grundlage von Prinzipien, kein Merge-Gate.
