Erstellen, überarbeiten oder analysieren Sie die Dateien AGENTS.md (und CLAUDE.md) und/oder README.md eines Repositorys als ergänzende Einstiegspunkte. Verwenden Sie diese Anweisung, wenn Sie diese Dateien schreiben, verkleinern, aufteilen oder überprüfen, wenn AGENTS.md überladen oder widersprüchlich ist, wenn Sie entscheiden, ob ein Repository neben AGENTS.md eine CLAUDE.md benötigt, oder wenn eine README-Datei die Benutzer nicht vom Quellcode fernhalten kann. Beinahe-Fehler: Nicht für das Verfassen von SKILL.md, ADRs, API-Referenzen als primäres Artefakt, nur CONTRIBUTING.md, Blogbeiträge oder die Implementierung von Produktfunktionen.
