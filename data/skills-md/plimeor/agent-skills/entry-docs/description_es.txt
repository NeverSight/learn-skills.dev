Crear, refactorizar o analizar el archivo AGENTS.md (y CLAUDE.md) y/o el archivo README.md de un repositorio como puntos de entrada complementarios. Úselo al redactar, reducir, dividir o revisar esos archivos, cuando AGENTS.md esté saturado o sea contradictorio, al decidir si un repositorio necesita un CLAUDE.md junto con AGENTS.md o cuando un README no pueda evitar que los usuarios accedan al código fuente. Situación similar: no es adecuado para la creación de SKILL.md, los ADR, la referencia de la API como artefacto principal, CONTRIBUTING.md por sí solo, las publicaciones de blog ni la implementación de funciones del producto.
