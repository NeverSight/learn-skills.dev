Mettez de l’authentification, une limitation du débit, des restrictions d’IP, des règles d’en‑tête ou une réponse personnalisée devant un point de terminaison ngrok à l’aide d’une politique de trafic, sans modifier le code de l’application. Cela couvre l’exigence d’une connexion (OAuth/OIDC), le verrouillage à des IP spécifiques, le blocage ou le refus de requêtes, le renvoi d’une page de maintenance ou d’une réponse personnalisée, ainsi que l’injection ou la suppression d’en‑têtes. À utiliser quand l’utilisateur veut protéger, filtrer, réguler ou ajouter une couche de passerelle API à un point de terminaison. À appliquer lorsque l’utilisateur dit « ajouter de l’authentification à mon URL ngrok », « exiger une connexion Google », « limiter le débit de mon point de terminaison », « restreindre par IP », « bloquer un chemin » ou « mettre une page de maintenance ».
