Metti l'autenticazione, il rate limiting, le restrizioni IP, le regole sugli header o una risposta personalizzata davanti a un endpoint ngrok usando una Politica di Traffico, senza modificare il codice dell'applicazione. Copre la richiesta di login (OAuth/OIDC), il vincolo a IP specifici, il blocco o il rifiuto delle richieste, il ritorno di una pagina di manutenzione o di una risposta personalizzata, e l'iniezione o la rimozione di header. Usalo quando l'utente vuole proteggere, filtrare, limitare o aggiungere uno strato di API‑gateway a un endpoint. Usalo quando l'utente dice “aggiungi auth al mio URL ngrok”, “richiedi login Google”, “rate limit il mio endpoint”, “restrivi per IP”, “blocca un percorso” o “mostra una pagina di manutenzione”.
