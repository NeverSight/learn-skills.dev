ضع المصادقة وتحديد معدل الطلبات وتقييد عناوين IP وقواعد الرؤوس أو استجابة مخصصة أمام نقطة نهاية ngrok باستخدام سياسة المرور، دون تعديل كود التطبيق. يغطي طلب تسجيل الدخول (OAuth/OIDC)، القفل على عناوين IP محددة، حجب أو رفض الطلبات، إرجاع صفحة صيانة أو استجابة مخصصة، وإدراج أو إزالة الرؤوس. استخدم ذلك عندما يرغب المستخدم في حماية أو تقييد أو تنظيم أو إضافة طبقة بوابة API إلى نقطة النهاية. استخدمه عندما يقول المستخدم “أضف المصادقة إلى عنوان URL الخاص بي على ngrok”، “اطلب تسجيل الدخول عبر Google”، “حدد معدل الطلبات لنقطة النهاية الخاصة بي”، “قيد الوصول بواسطة IP”، “احظر مساراً”، أو “اعرض صفحة صيانة”.
