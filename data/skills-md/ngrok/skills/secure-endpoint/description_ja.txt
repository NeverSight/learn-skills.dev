アプリケーションコードを変更せずに、Traffic Policy を使用して ngrok エンドポイントの前に認証、レート制限、IP 制限、ヘッダー規則、またはカスタムレスポンスを配置します。OAuth/OIDC によるログイン要求、特定 IP へのロック、リクエストのブロックや拒否、メンテナンスページやカスタムレスポンスの返却、ヘッダーの注入や除去をカバーします。エンドポイントを保護、ゲート、スロットリング、または API ゲートウェイ層を追加したい場合に使用します。「ngrok の URL に認証を追加して」「Google ログインを必須にして」「エンドポイントにレートリミットを設定して」「IP で制限して」「特定のパスをブロックして」「メンテナンスページを表示して」などの要望があるときに使用します。
