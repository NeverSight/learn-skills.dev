開発中のMCP（Model Context Protocol）サーバーを、ClaudeやOpenAIなどのAIモデルプロバイダーに対するリモートテスト用に公開し、プロバイダーごとの認証とトラフィック検査を行います。ローカルのMCPサーバーの前にクラウドエンドポイントを配置し、Vault を介して各プロバイダーのベアラートークンで認証し、パブリックインターネットから切り離されたサーバーへ転送します。ユーザーが MCP サーバーを構築またはテストしていて、リモート AI クライアントからアクセスする必要がある場合に使用します。ユーザーが「MCP サーバーをテストして」「MCP サーバーを Claude に公開して」「MCP サーバーを OpenAI に接続して」または「MCP サーバーのフロントドア」と言ったときに使用してください。
