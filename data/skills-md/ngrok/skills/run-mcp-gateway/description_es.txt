Exponer un servidor MCP (Modelo de Protocolo de Contexto) en desarrollo para pruebas remotas contra proveedores de modelos de IA como Claude y OpenAI, con autenticación por proveedor e inspección de tráfico. Coloca un endpoint en la nube delante de tu servidor MCP local, autentica a cada proveedor con su propio token bearer a través de Vaults y lo reenvía a tu servidor mantenido fuera de Internet público. Úsalo cuando el usuario está construyendo o probando un servidor MCP y necesita que un cliente de IA remoto lo alcance. Úsalo cuando el usuario dice “prueba mi servidor MCP”, “expón mi servidor MCP a Claude”, “conecta mi servidor MCP a OpenAI” o “puerta de entrada para mi servidor MCP”.
