Expose un serveur MCP (Model Context Protocol) en cours de développement pour des tests à distance avec des fournisseurs de modèles d'IA comme Claude et OpenAI, avec authentification par fournisseur et inspection du trafic. Place un point de terminaison cloud devant votre serveur MCP local, authentifie chaque fournisseur avec son propre jeton d’accès via Vaults, et le transmet à votre serveur maintenu hors d’Internet public. Utilisez‑le lorsque l’utilisateur construit ou teste un serveur MCP et a besoin qu’un client IA distant y accède. Utilisez‑le lorsque l’utilisateur dit « tester mon serveur MCP », « exposer mon serveur MCP à Claude », « connecter mon serveur MCP à OpenAI » ou « porte d’entrée pour mon serveur MCP ».
