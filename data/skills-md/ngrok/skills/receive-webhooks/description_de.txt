Empfangen und verifizieren Sie eingehende Webhooks von Anbietern wie Stripe, GitHub, Twilio, Slack oder Shopify und leiten Sie sie an einen lokalen oder privaten Dienst weiter, ohne diesen Dienst dem öffentlichen Internet auszusetzen. Verifizieren Sie Signaturen am Edge ohne Anwendungs‑Code; leiten Sie Drittanbieter‑Callbacks an einen Dienst hinter einer Firewall weiter, einschließlich regulierter (HIPAA/PCI) Umgebungen oder eines zentralen Webhook‑Gateways, das von Teams gemeinsam genutzt wird. Verwenden Sie dies, wenn der Nutzer Webhooks lokal empfangen, testen oder debuggen muss, die Signaturverifizierung ohne eigenen Code wünscht oder Callbacks an einen privaten Dienst weiterleiten muss.
