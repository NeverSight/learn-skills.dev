Esporre un servizio locale su Internet pubblico usando ngrok. Avvia un tunnel, opzionalmente aggiunge OAuth o WAF tramite Traffic Policy. Gestisce servizi HTTP e TCP grezzo (SSH, RDP, database). Usare quando richiesto di esporre, tunnellare, condividere o rendere un servizio locale accessibile pubblicamente, oppure per raggiungere una macchina senza IP pubblico. Include anche la condivisione di lavori in corso con una persona specifica e le stranezze del server di sviluppo che interrompono un’anteprima condivisa.
