قم بإنشاء نفق ل exposing خدمة محلية إلى الإنترنت العام باستخدام ngrok. يبدأ نفقًا، ويمكنه إضافة OAuth أو WAF عبر سياسة المرور. يدعم خدمات HTTP و TCP الخام (SSH، RDP، قواعد البيانات). يُستَخدم عندما يُطلب منك إظهار، نفق، مشاركة أو جعل خدمة محلية متاحة للجمهور، أو للوصول إلى جهاز لا يملك عنوان IP عام. كما يغطي مشاركة العمل الجاري مع شخص محدد والخصائص الخاصة بخادم التطوير التي قد تُعرِّض معاينة مشتركة للفشل.
