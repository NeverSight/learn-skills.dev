Erstelle und fülle Sumsub-Clientlisten — die benannten Mengen von Schlüsseln, gegen die Workflow‑Bedingungen und KYT‑Regeln abgeglichen werden (`clientLists.<name>`). TRIGGER, wenn der Nutzer eine Hochrisikoländerliste aufbauen, Einträge hinzufügen oder entfernen, prüfen will, ob ein Schlüssel in einer Liste ist, einen Listennamen in seine ID auflösen oder einen Bewerber von der Blockliste nehmen möchte. SKIP für das Blockieren eines Bewerbers (das ist `POST /resources/applicants/{id}/blacklist`, nicht das Schreiben einer Liste) und für das Schreiben der Regeln, die sich auf eine Liste beziehen (`sumsub-create-kyt-rules`, `sumsub-create-workflow`).
