Crear y poblar listas de clientes de Sumsub — los conjuntos nombrados de claves contra los que coinciden las condiciones del flujo de trabajo y las reglas KYT (`clientLists.<nombre>`). TRIGGER cuando el usuario quiere crear una lista de países de alto riesgo, agregar o eliminar entradas, comprobar si una clave está en una lista, resolver el nombre de una lista a su id, o eliminar a un solicitante de la lista de bloqueados. SKIP para bloquear a un solicitante (es decir `POST /resources/applicants/{id}/blacklist`, no una escritura de lista) y para escribir las reglas que hacen referencia a una lista (`sumsub-create-kyt-rules`, `sumsub-create-workflow`).
