Crea e popola le liste client di Sumsub — i set nominati di chiavi contro le quali le condizioni del flusso di lavoro e le regole KYT effettuano il match (`clientLists.<name>`). TRIGGER quando l'utente vuole costruire una lista di paesi ad alto rischio, aggiungere o rimuovere voci, verificare se una chiave è in una lista, risolvere un nome di lista al suo ID o rimuovere un candidato dalla blacklist. SKIP per inserire un candidato nella blacklist (cioè `POST /resources/applicants/{id}/blacklist`, non una scrittura su lista) e per scrivere le regole che fanno riferimento a una lista (`sumsub-create-kyt-rules`, `sumsub-create-workflow`).
