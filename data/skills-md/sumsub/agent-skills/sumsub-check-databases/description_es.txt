Descubra las bases de datos (fuentes de verificación) que Sumsub ofrece para un país, si cada una está habilitada para el inquilino y cómo la verificación de base de datos / sin documentos (eKYC) encaja en un nivel de verificación. Use CUANDO un usuario pregunte qué fuentes de verificación de base de datos / sin documentos están disponibles para un país, si están habilitadas, o cómo añadir la validación de base de datos / identidad sin documento / verificación de dirección sin documento a un nivel. También se llama desde sumsub-create-level antes de colocar esas fuentes. NO lo use para verificación solo de documentos o comprobaciones de derechos (use sumsub-check-permissions).

Por favor, siempre responda en el idioma del usuario.
