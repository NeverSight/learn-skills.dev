Découvrez les bases de données (sources de contrôle) que Sumsub propose pour un pays, si chacune est activée pour le locataire, et comment la vérification base de données / non-document (eKYC) s’intègre dans un niveau de vérification. Utilisez‑le lorsqu’un utilisateur demande quelles sources de contrôle base de données / non‑document sont disponibles pour un pays, si elles sont activées, ou comment ajouter la validation de base de données / l’identité non‑doc / la vérification d’adresse non‑doc à un niveau. Également appelé par sumsub‑create‑level avant de placer ces sources. NE PAS l’utiliser pour la vérification uniquement de documents ou les contrôles d’éligibilité (utilisez sumsub‑check‑permissions).

Veuillez toujours répondre dans la langue de l’utilisateur.
