Выполнить аудит UI/UX запущенного веб‑приложения — прохождение с Playwright на трёх размерах экрана, сканирование axe‑core по WCAG 2.1 AA и мобильный аудит Lighthouse. Создаёт ./audit/report.md, скриншоты, дымовой тест Playwright в ./tests/ и (для проектов Expo/Vite) сравнение Lighthouse между dev‑ и prod‑сборками. Запускается по запросам «audit ui/ux», «ui audit», «ux audit», «ux review», «a11y audit», «accessibility audit», «lighthouse audit» или любому запросу на аудит URL localhost / staging.
