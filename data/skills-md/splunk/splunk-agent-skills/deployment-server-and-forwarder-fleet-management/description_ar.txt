شرح وتخطيط وتشخيص سلوك أسطول Splunk Enterprise Deployment Server و10.x Agent Management من الوثائق العامة والأدلة المعقمة. يُستخدم للمصطلحات، وتطبيقات النشر، وفئات الخادم، ومرشحات العميل، والهاتف المنزلي، والمهمة الفعالة، والتحقق من الطرح، وذاكرة التخزين المؤقت أو سلوك إعادة التحميل، وضبط النطاق، ورؤية الأسطول، وتسليم Deployment Server لمحتوى Splunk Remote Upgrader؛ لا تستخدمه لتدفق بيانات معيد التوجيه غير ذي الصلة، أو HEC، أو عمل حزمة/ناشر الكتلة، أو الطفرات الحية.
