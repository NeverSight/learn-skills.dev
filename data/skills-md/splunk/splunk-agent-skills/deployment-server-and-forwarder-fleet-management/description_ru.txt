Объясняйте, планируйте и диагностируйте поведение сервера Splunk Enterprise Deployment Server и управления агентами 10.x на основе общедоступной документации и проверенных доказательств. Используйте для терминологии, приложений развертывания, классов серверов, клиентских фильтров, домашнего телефона, эффективного назначения, проверки развертывания, поведения кэширования или перезагрузки, настройки масштабирования, видимости парка и доставки контента Splunk Remote Upgrader на сервер развертывания; не используйте для несвязанного потока данных пересылки, HEC, работы кластерного пакета/развертывания или живых мутаций.
