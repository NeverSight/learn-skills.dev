Expliquez, planifiez et diagnostiquez le comportement de la flotte de Splunk Enterprise Deployment Server et de gestion des agents 10.x à partir de la documentation publique et de preuves épurées. À utiliser pour la terminologie, les applications de déploiement, les classes de serveur, les filtres client, le téléphone d'accueil, l'affectation efficace, la vérification du déploiement, le comportement de mise en cache ou de rechargement, le réglage de l'échelle, la visibilité de la flotte et la livraison sur le serveur de déploiement du contenu Splunk Remote Upgrader ; ne pas utiliser pour un flux de données de transitaire non lié, HEC, un travail de regroupement/déployeur de cluster ou des mutations en direct.
