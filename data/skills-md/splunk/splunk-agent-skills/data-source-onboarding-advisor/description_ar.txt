تنظيم مصدر بيانات Splunk جديد من المتطلبات واختيار طريقة الجمع المدعومة عبر المصدر، نوع المصدر، المضيف، الطابع الزمني، حدود الحدث، الحدث المفهرس، الملكية، والتحقق من القبول. يُستخدم لتدخل مصدر Splunk Cloud Platform أو Splunk Enterprise، قرارات القابلية للتطبيق، الجاهزية، عقود القبول، وتسليمات التنفيذ الدقيقة؛ لا يُستخدم لإعداد نقطة النهاية، استكشاف مشاكل الإدخال، نشر الأسطول، بنية خط الأنابيب، تنفيذ الحقول أو CIM، التكوين، النشر، التحوير، أو الإصلاح.
