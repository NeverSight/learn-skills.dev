صمم خطوط أنابيب استيعاب Splunk جاهزة للتنفيذ بناءً على متطلبات المصدر المعروفة. استخدمها لاختيار المدخل وجامع البيانات، وتحديد موضع المعالج، والتحليل أثناء الاستيعاب، والتحويل، والفلترة، والتوجيه، والسعة، والموثوقية، والأمان، والتحقق، والملكية، وتسليم التنفيذ لمنصة Splunk Cloud أو Splunk Enterprise. لا تستخدمها لاكتشاف انضمام المصدر، أو تكوين الإنتاج، أو SPL، أو عمل نقطة نهاية HEC، أو نشر الأسطول، أو النشر، أو التغيير، أو معالجة الحوادث النشطة.
