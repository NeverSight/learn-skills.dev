Entwerfen Sie implementierungsbereite Splunk-Ingestion-Pipelines auf Basis bekannter Quellanfordernisse. Verwenden Sie sie für die Auswahl von Eingaben und Collector, die Platzierung von Prozessoren, das Parsen zur Ingestionszeit, Transformation, Filterung, Routing, Kapazität, Zuverlässigkeit, Sicherheit, Validierung, Eigentumszuweisung und die Übergabe der Implementierung für Splunk Cloud Platform oder Splunk Enterprise. Nicht verwenden für Quell‑Onboarding‑Entdeckung, Produktionskonfiguration, SPL, HEC‑Endpoint‑Arbeiten, Flotten‑Rollout, Bereitstellung, Mutation oder aktive Vorfallbehebung.
