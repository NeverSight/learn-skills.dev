أنشئ صفحة إعداد أول تشغيل متوافقة مع معايير الشهادة لتطبيق أو مكوّن إضافي لـ Splunk يجمع الإعدادات غير السرية عبر نقطة النهاية REST للتكوين والسرّيات عبر storage/passwords، ويربط app.conf/default.meta بشكل صحيح، ويتجنب آلية setup.xml القديمة. استخدمها عندما يرغب المستخدم في شاشة "إعداد تطبيقك"، أو معالج التكوين الأول، أو طريقة لجمع نقطة نهاية/بيانات اعتماد/رمز API لتطبيق أو TA من Splunkbase. حول الإرشادات العامة حول تجميع التطبيق، التوافق، الترقية أو إزالة دورة الحياة غير المتعلقة بصفحة الإعداد نفسها إلى app-and-add-on-lifecycle-advisor، والحكم الأوسع على كائنات المعرفة خارج default.meta الخاص بهذا التطبيق إلى knowledge-object-governance.
