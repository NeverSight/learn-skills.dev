Créez une page de configuration initiale conforme à la certification pour une application ou un add‑on Splunk qui collecte les paramètres non secrets via le point de terminaison REST des configurations et les secrets via storage/passwords, raccorde correctement app.conf/default.meta, et évite le mécanisme obsolète setup.xml. Utilisez‑la lorsque l'utilisateur souhaite un écran « Configurez votre application », un assistant de configuration à la première exécution, ou un moyen de recueillir un endpoint/identifiant/jeton API pour une application ou TA Splunkbase. Orientez les conseils généraux sur l’empaquetage d’application, la compatibilité, la mise à niveau ou la suppression du cycle de vie, qui ne concernent pas la page de configuration elle‑même, vers app-and-add-on-lifecycle-advisor, et la gouvernance plus large des objets de connaissance au‑delà du default.meta propre à cette application vers knowledge-object-governance.
