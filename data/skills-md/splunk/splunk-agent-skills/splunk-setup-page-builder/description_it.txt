Costruisci una pagina di configurazione iniziale conforme alla certificazione per un’app o add‑on Splunk che raccolga le impostazioni non segrete tramite l’endpoint REST delle configurazioni e i segreti tramite storage/passwords, colleghi correttamente app.conf/default.meta ed eviti il meccanismo deprecato setup.xml. Usala quando l’utente desidera una schermata “Configura la tua app”, una procedura guidata di configurazione al primo avvio, o un modo per raccogliere endpoint, credenziali o token API per un’app o TA di Splunkbase. Reindirizza le indicazioni generali su packaging dell’app, compatibilità, aggiornamento o rimozione del ciclo di vita non correlate alla pagina di configurazione stessa a **app-and-add-on-lifecycle-advisor**, e la governance più ampia degli oggetti di conoscenza al di là del default.meta dell’app a **knowledge-object-governance**.

Si prega di rispondere sempre nella lingua dell’utente.
