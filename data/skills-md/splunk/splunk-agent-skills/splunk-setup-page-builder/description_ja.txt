認証要件に準拠した Splunk アプリまたはアドオン用の初回実行セットアップページを構築します。このページは、非機密設定を configurations REST エンドポイントで、機密情報を storage/passwords で取得し、app.conf と default.meta を正しく配線し、廃止予定の setup.xml メカニズムは使用しません。ユーザーが「アプリの設定」画面、初回設定ウィザード、または Splunkbase アプリや TA のエンドポイント・認証情報・API トークンを収集したい場合に使用します。セットアップページ自体に関係しない一般的なアプリのパッケージング、互換性、アップグレード、削除に関するライフサイクルガイダンスは app-and-add-on-lifecycle-advisor に、アプリ固有の default.meta を超える包括的なナレッジオブジェクトガバナンスは knowledge-object-governance に振り分けてください。
