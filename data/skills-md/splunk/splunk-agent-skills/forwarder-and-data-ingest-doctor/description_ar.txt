تشخيص مسارات موصل Splunk وإدخال البيانات من أدلة مُعقَّمة للقراءة فقط. يُستخدم لنقل عبر Universal أو Heavy Forwarder، وتأثيرات عميل النشر على الإدخال، وHEC وغيرها من المدخلات، والتحليل الزمني والطوابع، وحدود الأحداث، والتوجيه، وتعارضات نوع المصدر أو الفهرس، والأحداث المفقودة أو المتأخرة أو المكررة أو المسقطة، والطوابير أو الضغط العكسي في منصة Splunk Cloud أو Splunk Enterprise؛ لا يُستخدم للتعديل الحي، أو البنية العامة، أو سياسة الأسطول، أو إدارة رموز HEC، أو استخراج وقت البحث، أو الإصلاح المملوك للمزود.
