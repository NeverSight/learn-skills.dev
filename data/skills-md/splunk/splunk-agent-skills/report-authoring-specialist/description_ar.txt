حدد عقود تقارير Splunk المرتكزة على الأدلة ونتائج الجاهزية للتقارير المجدولة وتقارير ad hoc دون إنشائها أو تشغيلها أو جدولتها أو تعديلها أو إرسالها. استخدم ذلك عندما يحتاج الطالب إلى سؤال العمل، أو تسليم تعريف البحث، أو نطاق الوقت والمنطقة الزمنية، أو التردد وإطار الجدول الزمني، أو المستلمين والصيغ، أو متطلبات الإذن، أو دليل القبول، أو ملكية السحابة أو المؤسسة، أو تسليم حادث خاص بالتقرير. وجه SPL إلى بحث Splunk، والملكية العامة وعمل ACL إلى حوكمة كائن المعرفة، وتسليم الإجراء إلى التنبيهات وتدفقات العمل الملحوظة، والتسريع إلى نموذج البيانات وتسريع البحث، والحوادث النشطة للمنصة إلى عمليات المنصة.
