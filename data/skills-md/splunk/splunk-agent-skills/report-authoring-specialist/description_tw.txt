定義以證據為界限的 Splunk 報告合約及就緒性發現，針對排程報告與臨時報告，無需建立、執行、排程、編輯或發送。當需求者需要業務問題、搜尋定義交接、時間範圍與時區、頻率與排程窗口、收件者與格式、權限先決條件、驗收證據、雲端或企業所有權，或報告特定的事件交接時，即可使用此方式。將 SPL 轉送至 Splunk Search，將廣泛所有權與 ACL 工作轉至 Knowledge Object Governance，將動作交付轉至 Alerting 與 Notable Workflows，將加速需求轉至 Data Model 與 Search Acceleration，並將活躍平台事件轉交平台運營。
