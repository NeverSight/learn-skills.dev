証拠制限された Splunk レポート契約と準備状況の調査結果を、レポートを作成、実行、スケジュール設定、編集、送信せずに定期レポートおよびアドホックレポート向けに定義する。依頼者がビジネス課題、検索定義の引き渡し、時間範囲とタイムゾーン、実行頻度とスケジュールウィンドウ、受信者とフォーマット、権限前提条件、受諾証拠、クラウドまたはエンタープライズ所有権、またはレポート固有のインシデント引き渡しが必要な場合に使用する。SPL は Splunk Search に、広範な所有権と ACL の作業は Knowledge Object Governance に、アクション配信は Alerting と Notable Workflows に、加速は Data Model と Search Acceleration に、アクティブなプラットフォームインシデントはプラットフォーム運用にそれぞれルーティングする。
