Diagnostique incidentes de Splunk de varios componentes posteriores al triage a partir de un paquete diagnóstico revisado por privacidad suministrado. Úselo para alinear relojes y síntomas, preservar el impacto y las contradicciones, mapear dependencias, clasificar y probar hipótesis causales competidoras, solicitar el discriminador de solo lectura más pequeño y seguro, validar hallazgos delimitados y entregar fallas de componentes confirmadas a especialistas exactos. No lo utilice para recopilar diagnósticos sin procesar, solucionar problemas o remediar un solo componente, configurar, reiniciar, mutar, realizar pruebas de estrés o afirmar una causa o recuperación no verificada.
