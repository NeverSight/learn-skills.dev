Agent Skill that explains concepts, mechanisms, procedures, and data flow with “moving diagrams.” It outputs either an animated SVG (a single loop that can be embedded in README/Markdown) or a single HTML file (a walkthrough with a player that allows pause, fast‑forward, and step‑by‑step playback) as one file. Use it for requests such as “illustrate,” “explain with animation,” “show the motion,” “make it a moving diagram,” “turn it into an SVG animation,” “create an explanation that can be viewed at double speed,” “illustrate this article/document/design,” “summarize the current discussion with dpgk,” “with dpgk,” or whenever you want to turn an article, document, URL, or conversation into a moving diagram, or when you need to visually explain protocols, algorithms, architectures, process flows, or state transitions. The motion is not decorative; it is used solely to convey order, causality, flow, and change.
