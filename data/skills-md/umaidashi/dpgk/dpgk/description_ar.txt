مهارة الوكيل التي تشرح المفاهيم والآليات والإجراءات وتدفق البيانات باستخدام “مخططات ديناميكية”. تُنتج إما SVG متحرك (حلقة واحدة يمكن تضمينها في README أو Markdown) أو ملف HTML واحد (شرح مع مشغل يتيح الإيقاف المؤقت، التقديم السريع، والتنقل خطوةً بخطوة) كملف واحد. تُستخدم للطلبات مثل “ارسم ذلك”، “اشرحه بالرسوم المتحركة”، “أظهره يتحرك”، “اجعله مخططًا متحركًا”، “حوّله إلى رسوم SVG متحركة”، “أنشئ شرحًا يمكن تقديمه سريعًا”، “ارسم هذا المقال/الوثيقة/المواصفة”، “لخص النقاش الحالي بـ dpgk”، أو أي حالة تريد فيها تحويل مقال أو وثيقة أو عنوان URL أو محادثة إلى مخطط متحرك، أو عندما تحتاج إلى شرح بصري للبروتوكولات أو الخوارزميات أو الهندسة المعمارية أو تدفقات العمليات أو انتقالات الحالة. الحركة ليست زخرفية؛ تُستخدم فقط لنقل الترتيب والسببية والتدفق والتغيير.

يرجى دائمًا الرد بلغة المستخدم.
