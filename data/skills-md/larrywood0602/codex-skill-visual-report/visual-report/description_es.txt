Convierta texto, imágenes y archivos en informes web visuales interactivos. Utilice esta habilidad cuando un usuario quiera crear materiales de presentación, generar informes visuales, formatear contenido como PPT/PDF, crear infografías o visualizar actas, datos o documentos de reuniones. Las palabras clave incluyen: informe, presentación, visualización, PPT, PDF, infografía, panel, lienzo, estilo servilleta, visualización de datos. Incluso si el usuario simplemente dice "ayúdame a formatear esto bien" o "necesito enviárselo a mi jefe", se debe considerar esta habilidad.
