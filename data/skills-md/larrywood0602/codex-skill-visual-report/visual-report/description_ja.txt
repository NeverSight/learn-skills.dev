テキスト、画像、ファイルをインタラクティブなビジュアル Web レポートに変換します。このスキルは、ユーザーがプレゼンテーション資料の作成、視覚的なレポートの生成、コンテンツの PPT/PDF への整理、インフォグラフィックの作成、または会議議事録、データ、またはドキュメントの視覚的な表示を行う場合に使用します。キーワードには、レポート、プレゼンテーション、視覚化、PPT、PDF、インフォグラフィック、ダッシュボード、キャンバス、ナプキン スタイル、データ表示が含まれます。ユーザーが単に「きれいにフォーマットするのを手伝ってください」または「これを上司に送信する必要があります」と言った場合でも、このスキルを考慮する必要があります。
