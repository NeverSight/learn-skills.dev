テキスト、画像、ファイルをインタラクティブなビジュアル Web レポートに変換します。ユーザーがプレゼンテーション資料の作成、視覚的なレポートの生成、コンテンツを PPT/PDF としてフォーマットする、インフォグラフィックを作成する、または会議の議事録、データ、またはドキュメントを視覚化する場合は、このスキルを使用します。キーワードには、レポート、プレゼンテーション、視覚化、PPT、PDF、インフォグラフィック、ダッシュボード、キャンバス、ナプキン スタイル、データ表示が含まれます。ユーザーが単に「これをきれいにフォーマットするのを手伝ってください」または「上司に送信する必要があります」と言った場合でも、このスキルを考慮する必要があります。
