تحويل النصوص والصور والملفات إلى تقارير ويب مرئية تفاعلية. استخدم هذه المهارة عندما يريد المستخدم إنشاء مواد عرض تقديمي، أو إنشاء تقارير مرئية، أو تنظيم المحتوى في ملف PPT/PDF، أو إنشاء رسوم بيانية، أو تصور محاضر الاجتماع أو البيانات أو المستندات. الكلمات الرئيسية تشمل: تقرير، عرض تقديمي، تصور، PPT، PDF، مخطط معلوماتي، لوحة معلومات، قماش، نمط المناديل، عرض البيانات. حتى لو قال المستخدم ببساطة "ساعدني في تنسيقها بشكل جيد" أو "أحتاج إلى إرسالها إلى الرئيس"، فيجب أخذ هذه المهارة بعين الاعتبار. استخدم هذه المهارة للتقارير المرئية التفاعلية ولوحات المعلومات والملخصات التنفيذية الجاهزة والرسوم البيانية وصادرات PPT/PPDF المبنية من الملاحظات أو المستندات أو لقطات الشاشة أو الجداول أو مجموعات البيانات.
