Diseñar e implementar interfaces para iPhone y iPad con un estilo visual coherente y un comportamiento de interacción nativo. Establecer una dirección visual o perfeccionar las pantallas existentes para eliminar el estilo genérico de la IA. Utiliza esta habilidad para el diseño visual de iOS, las interfaces de SwiftUI o UIKit y los retoques visuales. No uses esta habilidad para juegos, capturas de pantalla de marketing, sitios web o mantenimiento no visual.
