Générez un document de capacité métier (règles BR‑XXX sous forme Given/When/Then) à partir d’une description de contexte métier, avant que tout code n’existe. Utilisez‑le chaque fois que l’utilisateur dit « capability doc », « capability document », « BR‑XXX rules », « business rules doc », ou demande de transformer une description de fonctionnalité, une exigence ou une explication métier en documentation structurée de règles métier pour un service. Utilisez‑le également lorsque l’utilisateur décrit un nouveau module ou une modification d’un flux existant et souhaite que l’intention métier soit capturée dans un document — même s’il ne prononce pas le mot « capability ». Préfixe de déclenchement : capability‑doc :

Veuillez toujours répondre dans la langue de l'utilisateur.
