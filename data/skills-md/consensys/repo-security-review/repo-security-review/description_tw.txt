完整自動化的程式碼庫安全審查流水線。每當使用者要求以下任務時，請使用此技能：審查程式庫的安全問題、執行安全稽核、找出程式碼基礎的漏洞、進行安全評估、檢查 OWASP Top 10 與 OWASP API Top 10 問題、掃描機密資訊或外洩的憑證、審核相依性以尋找 CVE，或分析架構中的安全缺陷。即使是隨意的說法，如「能不能幫我檢查這個程式庫的安全問題」或「對這個執行安全掃描」也要觸發。本技能會依序執行七個階段：機密資訊掃描、架構分析、帶可達性驗證的相依性 CVE 掃描、程式碼層級的 OWASP 分析、結果驗證，以及最終報告產出。PoC 產生（可選的透過 Docker 執行執行時驗證）需使用 `--poc` 旗標自行啟用。亦支援針對單一 Pull Request 差異進行安全問題審查（`--pr` 旗標）——觸發語句如「審查這個 PR 的安全問題」或「在合併前進行安全審查這個差異」——此為快速、僅差異範圍的模式，無需事先掃描整個程式庫。

請始終以使用者的語言回覆。
