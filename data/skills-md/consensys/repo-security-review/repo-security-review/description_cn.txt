用于代码仓库的全自动安全审查流水线。  
在用户要求以下任何操作时使用此技能：审查仓库的安全问题、执行安全审计、寻找代码库中的漏洞、进行安全评估、检查 OWASP Top 10 和 OWASP API Top 10 问题、扫描密钥或泄露的凭证、审计依赖项的 CVE，或分析架构的安全缺陷。  
即使是类似“你能检查一下这个仓库的安全问题吗”或“对这个进行安全扫描”之类的随意表述也会触发。  
此技能按照 7 个顺序阶段进行：密钥扫描、架构分析、带可达性验证的依赖项 CVE 扫描、代码层面的 OWASP 分析、发现验证以及最终报告生成。  
PoC 生成（可选的通过 Docker 进行运行时验证）需通过 `--poc` 标志主动开启。  
还支持针对单个 Pull Request 的差异进行安全问题审查（`--pr` 标志）——可通过类似“审查此 PR 的安全问题”或“在合并前进行安全审查差异”等表述触发——一种快速、仅针对差异的模式，无需事先对仓库进行全量扫描。  
请始终使用用户的语言作答。
