코드 저장소를 위한 완전 자동화된 보안 검토 파이프라인입니다. 사용자는 다음과 같은 요청을 할 때마다 이 기능을 사용하십시오: 저장소의 보안 문제 검토, 보안 감사 실행, 코드베이스 내 취약점 찾기, 보안 평가 수행, OWASP Top 10 및 OWASP API Top 10 문제 확인, 비밀이나 노출된 자격 증명 스캔, 의존성의 CVE 감사, 또는 아키텍처 보안 결함 분석. “can you check this repo for security issues” 혹은 “run security on this”와 같은 일상적인 문구에도 트리거됩니다. 이 기능은 7단계 순차적 과정을 조정합니다: 비밀 스캔, 아키텍처 분석, 도달 가능성 검증을 포함한 의존성 CVE 스캔, 코드 수준 OWASP 분석, 결과 검증, 최종 보고서 생성. PoC 생성(도커를 통한 선택적 런타임 검증 포함)은 `--poc` 플래그를 통해 옵션으로 선택할 수 있습니다. 또한 단일 풀 리퀘스트(diff)의 보안 문제를 검토하는 기능(`--pr` 플래그)도 지원합니다 — “review this PR for security issues” 혹은 “security review this diff before merge”와 같은 문구에 트리거되며, 사전에 저장소 전체 스캔이 필요 없는 빠른 diff‑스코프 모드입니다.

항상 사용자의 언어로 응답하십시오.
