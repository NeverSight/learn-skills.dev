Pipeline di revisione della sicurezza totalmente automatizzata per un repository di codice. Usa questa capacità ogni volta che l'utente chiede di: revisionare un repository per problemi di sicurezza, eseguire un audit di sicurezza, trovare vulnerabilità in una codebase, effettuare una valutazione della sicurezza, controllare i problemi OWASP Top 10 e OWASP API Top 10, scansionare per segreti o credenziali esposte, auditare le dipendenze per CVE o analizzare l'architettura per difetti di sicurezza. Si attiva anche per frasi informali come “puoi controllare questo repository per problemi di sicurezza” o “esegui una scansione di sicurezza su questo”. Questa capacità orchestra 7 fasi sequenziali: scansione dei segreti, analisi architetturale, scansione delle dipendenze per CVE con validazione della raggiungibilità, analisi del codice a livello OWASP, validazione dei risultati e generazione del rapporto finale. La generazione di PoC (con validazione opzionale a runtime via Docker) è opt-in tramite il flag `--poc`. Gestisce anche la revisione di un singolo pull request diff per problemi di sicurezza (`--pr`): si attiva con frasi come “revisiona questo PR per problemi di sicurezza” o “revisione di sicurezza di questo diff prima del merge” — una modalità veloce, limitata al diff, che non richiede che il repository sia stato scansionato prima.
