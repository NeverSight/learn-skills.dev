Pipeline d'examen de sécurité entièrement automatisé pour un dépôt de code. Utilisez cette compétence chaque fois que l'utilisateur demande : examiner un dépôt pour des problèmes de sécurité, exécuter un audit de sécurité, trouver des vulnérabilités dans une base de code, réaliser une évaluation de sécurité, vérifier les 10 principaux points OWASP et les 10 principaux points OWASP API, scanner les secrets ou les identifiants exposés, auditer les dépendances pour les CVE, ou analyser l'architecture à la recherche de failles de sécurité. Déclenchez même pour des formulations informelles comme « pouvez‑vous vérifier ce dépôt pour des problèmes de sécurité » ou « lancez la sécurité sur ceci ». Cette compétence orchestre 7 phases séquentielles : scan des secrets, analyse architecturale, scan des CVE des dépendances avec validation de portée, analyse OWASP au niveau du code, validation des découvertes, et génération du rapport final. La génération de PoC (avec validation d’exécution optionnelle via Docker) est activée via le drapeau `--poc`. Elle gère également la révision du diff d’une unique pull request pour les problèmes de sécurité (`--pr` drapeau) — déclenchée par des formulations comme « examiner ce PR pour des problèmes de sécurité » ou « révision de sécurité de ce diff avant la fusion » — un mode rapide, limité au diff, qui ne nécessite pas que le dépôt ait été scanné auparavant.
