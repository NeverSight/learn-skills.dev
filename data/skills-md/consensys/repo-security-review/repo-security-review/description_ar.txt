خط أنابيب مراجعة أمنية مؤتمتة بالكامل لمستودع الشيفرة. استخدم هذه المهارة كلما طلب المستخدم: مراجعة مستودع للعثور على مشكلات أمنية، تشغيل تدقيق أمني، اكتشاف الثغرات في قاعدة الشيفرة، إجراء تقييم أمني، التحقق من مشكلات OWASP Top 10 و OWASP API Top 10، فحص الأسرار أو الاعتمادات المكشوفة، تدقيق التبعيات للبحث عن CVE، أو تحليل الهندسة المعمارية للعثور على عيوب أمنية. يتم التحفيز حتى للعبارات العارضة مثل "can you check this repo for security issues" أو "run security on this". تنسق هذه المهارة 7 مراحل متتالية: فحص الأسرار، التحليل المعماري، فحص CVE للتبعيات مع تحقق القابلية للوصول، تحليل OWASP على مستوى الشيفرة، التحقق من النتائج، وإنشاء التقرير النهائي. إنشاء PoC (مع التحقق الاختياري من وقت التشغيل عبر Docker) يتم عبر علم `--poc`. كما تتعامل مع مراجعة الفرق في طلب سحب واحد للعثور على مشكلات أمنية (`--pr` علم) — يتم التحفيز على عبارات مثل "review this PR for security issues" أو "security review this diff before merge" — وضع سريع يقتصر على الفرق ولا يتطلب أن يكون المستودع قد فُحص مسبقًا.
