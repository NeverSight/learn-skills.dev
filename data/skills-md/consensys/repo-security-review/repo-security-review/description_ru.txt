Полностью автоматизированный конвейер проверки безопасности для репозитория кода. Используйте эту возможность всякий раз, когда пользователь просит: проверить репозиторий на наличие проблем безопасности, провести аудит безопасности, найти уязвимости в кодовой базе, выполнить оценку безопасности, проверить наличие проблем OWASP Top 10 и OWASP API Top 10, просканировать на наличие секретов или открытых учётных данных, проанализировать зависимости на CVE, или проанализировать архитектуру на предмет уязвимостей. Срабатывает даже при неформальных формулировках типа «можешь проверить этот репозиторий на безопасность» или «запусти проверку безопасности». Эта возможность управляет семью последовательными фазами: сканирование секретов, архитектурный анализ, сканирование зависимостей на CVE с проверкой достижимости, анализ кода на соответствие OWASP, валидация найденных проблем и формирование окончательного отчёта. Генерация PoC (с необязательной проверкой выполнения через Docker) включается по флагу `--poc`. Также поддерживается проверка отличий одного pull‑request на наличие проблем безопасности (`--pr` флаг) — срабатывает на фразы вроде «проверь этот PR на безопасность» или «проведи проверку безопасности этого диффа перед слиянием» — быстрый режим, ограниченный только диффом, не требующий предварительного сканирования репозитория.

Всегда отвечайте на языке пользователя.
