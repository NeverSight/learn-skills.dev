コードリポジトリ向けの完全自動化セキュリティレビュー パイプライン。ユーザーが次のように依頼した場合にこのスキルを使用する：リポジトリのセキュリティ問題のレビュー、セキュリティ監査の実行、コードベースの脆弱性の検出、セキュリティ評価の実施、OWASP Top 10 および OWASP API Top 10 の問題チェック、シークレットや露出した認証情報のスキャン、依存関係の CVE 監査、アーキテクチャのセキュリティ欠陥分析。たとえば「このリポジトリのセキュリティ問題を確認して」や「これをセキュリティチェックして」などのカジュアルな表現でもトリガーされる。このスキルは 7 つの連続フェーズをオーケストレーションする：シークレットスキャン、アーキテクチャ分析、到達性検証付き依存関係 CVE スキャン、コードレベルの OWASP 分析、検出結果の検証、最終レポート生成。PoC の生成（Docker によるオプションの実行時検証付き）は `--poc` フラグでオプトイン可能。また、単一プルリクエストの差分に対するセキュリティ問題のレビューも扱う（`--pr` フラグ）—「この PR のセキュリティ問題をレビューして」や「マージ前にこの差分をセキュリティレビュー」などの表現でトリガーされる — 事前にリポジトリ全体をスキャンする必要のない高速な差分スコープモード。
