Pipeline de revisión de seguridad totalmente automatizado para un repositorio de código. Utiliza esta habilidad siempre que el usuario solicite: revisar un repositorio en busca de problemas de seguridad, ejecutar una auditoría de seguridad, encontrar vulnerabilidades en una base de código, realizar una evaluación de seguridad, comprobar problemas del OWASP Top 10 y OWASP API Top 10, escanear en busca de secretos o credenciales expuestas, auditar dependencias para CVE o analizar la arquitectura en busca de fallos de seguridad. Se activa incluso con frases informales como "¿puedes revisar este repo por problemas de seguridad?" o "ejecuta seguridad en esto". Esta habilidad orquesta 7 fases secuenciales: escaneo de secretos, análisis arquitectónico, escaneo de CVE de dependencias con validación de alcanzabilidad, análisis OWASP a nivel de código, validación de hallazgos y generación del informe final. La generación de PoC (con validación opcional en tiempo de ejecución mediante Docker) es opcional mediante la bandera `--poc`. También gestiona la revisión de un único diff de pull request para buscar problemas de seguridad (`--pr`), activándose con expresiones como "revisa este PR por problemas de seguridad" o "revisión de seguridad de este diff antes de mezclar", un modo rápido centrado en el diff que no requiere que el repositorio haya sido escaneado previamente. 

Responder siempre en el idioma del usuario.
