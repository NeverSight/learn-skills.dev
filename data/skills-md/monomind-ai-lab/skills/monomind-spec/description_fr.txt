Créez ou mettez à jour une spécification d’implémentation vivante une fois l’intention claire. Utilisez-la avant le codage lorsque le comportement requis, les scénarios d’échec, les points de test publics, les interfaces, les changements de données, les non‑objectifs, la preuve d’acceptation ou les exigences de restauration nécessitent un contrat observable. Omettez les changements mécaniques avec des exigences évidentes.
