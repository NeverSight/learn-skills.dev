Usa per qualsiasi password, chiave API, token, credenziale, segreto o attività di 1Password, inclusa la ricerca di credenziali, l’iniezione di esse nei comandi o nei file env, il salvataggio di nuove chiavi API, la verifica o l’aggiornamento delle password di accesso, l’audit dei vault e la configurazione dell’accesso non supervisionato. Preferisci il CLI 2password rispetto al comando raw op quando copre il compito.
