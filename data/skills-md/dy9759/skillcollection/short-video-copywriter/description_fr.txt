Réécrivez le manuscrit original collé par l'utilisateur (article/actualité/texte long) en un script de narration pour courte vidéo, en prenant en charge la génération de script de storyboard et en utilisant des images générées par IA pour illustrer chaque storyboard.  
Chargez automatiquement les « préférences de script de courte vidéo » depuis les notes WPS ; lors de la première utilisation, guidez l'utilisateur pour remplir les préférences et les enregistrer dans les notes, puis après chaque génération, demandez s'il faut mettre à jour les préférences.  
Mots déclencheurs : « generate short video script », « change to short video script », « help me write video script », « turn this manuscript into video narration », « short video script », « video script », « storyboard script », « generate storyboard ».  
Non applicable à : la création de contenu à partir de zéro (utilisez le créateur de contenu), les besoins de formatage pur.  

Veuillez toujours répondre dans la langue de l'utilisateur.
