Travaillez avec Altium Designer via le CLI `akcli` — Altium est la surface d’importation en lecture seule d’`akcli` dans le flux « KiCad‑first » : analysez les fichiers .SchDoc/.SchLib/.PcbDoc d’Altium, exportez du JSON normalisé et des netlists Protel/KiCad/CSV, transmettez les modifications de schéma retour dans Altium (instructions de dessin humaines hors ligne + netlist importable — il n’existe aucune voie d’écriture vers Altium), et migrez les conceptions Altium vers KiCad avec une vérification de diff de netlist. Utilisez cette compétence chaque fois que la tâche implique : la lecture, l’exportation ou la conversion d’un fichier Altium ; extraire un design d’Altium vers un autre outil ; introduire des changements dans un schéma Altium ; ou une migration ou vérification d’équivalence Altium‑to‑KiCad. Déclencheurs sur les mots‑clés : Altium, Altium Designer, SchDoc, SchLib, PcbDoc, netlist Protel, OLE2/CFBF, export Altium, import Altium, migration vers KiCad, AD vers KiCad.
