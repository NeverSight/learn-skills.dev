Lavora con Altium Designer tramite la riga di comando `akcli` — Altium è la superficie di importazione in sola lettura di akcli nel flusso KiCad-first: analizza i file .SchDoc/.SchLib/.PcbDoc di Altium, esporta JSON normalizzato e netlist Protel/KiCad/CSV, restituisce modifiche allo schema in Altium (istruzioni di disegno offline per l'umano + netlist importabile — non esiste alcun percorso di scrittura in Altium) e migra i progetti Altium verso KiCad con verifica mediante diff delle netlist. Usa questa competenza ogni volta che il compito prevede: lettura, esportazione o conversione di un file Altium; estrazione di un progetto da Altium verso un altro strumento; inserimento di modifiche in uno schema Altium; o una migrazione o verifica di equivalenza Altium‑to‑KiCad. Parole chiave di attivazione: Altium, Altium Designer, SchDoc, SchLib, PcbDoc, netlist Protel, OLE2/CFBF, esportazione Altium, importazione Altium, migrare a KiCad, AD a KiCad.
