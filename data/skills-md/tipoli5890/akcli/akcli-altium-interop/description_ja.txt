Altium Designer を `akcli` CLI で操作する — Altium は akcli の読み取り専用インポートインターフェースで、KiCad 優先のフローに組み込まれます。Altium の .SchDoc/.SchLib/.PcbDoc ファイルを解析し、正規化された JSON と Protel/KiCad/CSV ネットリストをエクスポートし、回路図の編集内容を Altium に戻す（オフラインの手描き指示＋インポート可能なネットリストで提供、Altium への書き込みパスは一切ありません）、そしてネットリスト差分検証を用いて Altium 設計を KiCad に移行します。以下のタスクがある場合にこのスキルを使用してください：Altium ファイルの読み取り、エクスポート、変換；Altium から別ツールへの設計の取り出し；Altium 回路図への変更の反映；または Altium から KiCad への移行や等価性チェック。トリガーキーワード：Altium、Altium Designer、SchDoc、SchLib、PcbDoc、Protel ネットリスト、OLE2/CFBF、Altium エクスポート、Altium インポート、KiCad への移行、AD から KiCad へ。
