تشغيل حساب ProxyLane للوكيل السكني عبر API الخاص به. استخدمه عندما يطلب المستخدم التحقق من حركة المرور أو الرصيد، شراء حركة مرور سكنية، إنشاء مستخدم فرعي (تسجيل دخول بحد GB الخاص به) لمكتب أو زميل أو عميل، إضافة أو استرجاع GB للمستخدم الفرعي، إيقاف أو حذف مستخدم فرعي، توليد قوائم بروكسي، أو الإبلاغ عن استخدام حركة المرور لكل مستخدم فرعي.
