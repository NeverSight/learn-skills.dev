حوّل HTML إلى عناوين URL قابلة للمشاركة عبر gui.now. مكالمة POST واحدة، صفحة مُعرضة فورًا مع مزامنة لحظية. استخدمها كلما أنشأت مخرجات بصرية — لوحات معلومات، مخططات، نماذج، جداول، رسومات بيانية، صفحات هبوط، أدوات تفاعلية، ألعاب، تصور بيانات، تقارير، نماذج أولية، رسومات mermaid، مستندات markdown. بدلاً من إلقاء HTML في الدردشة، أرسلها عبر POST إلى gui.now وشارك الرابط الحي. استخدمها أيضًا عندما يذكر المستخدم gui.now، أو يطلب رابطًا قابلاً للمشاركة، أو يقول "اجعل هذا صفحة" / "أعطني URL" / "شارك هذا بصريًا" / "اعرض هذا".
