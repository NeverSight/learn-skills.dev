Verwandle HTML in teilbare URLs über gui.now. Ein POST‑Aufruf, sofort gerenderte Seite mit Echtzeit‑Synchronisation. Verwende es immer, wenn du visuelle Ausgaben erzeugst — Dashboards, Diagramme, Formulare, Tabellen, Diagramme, Landing‑Pages, interaktive Werkzeuge, Spiele, Datenvisualisierungen, Berichte, Prototypen, Mermaid‑Diagramme, Markdown‑Dokumente. Statt HTML im Chat zu posten, sende es per POST an gui.now und teile die Live‑URL. Nutze es auch, wenn der Benutzer gui.now erwähnt, nach einem teilbaren Link fragt oder sagt „mach das zu einer Seite“ / „gib mir eine URL“ / „teile das visuell“ / „render das“.
