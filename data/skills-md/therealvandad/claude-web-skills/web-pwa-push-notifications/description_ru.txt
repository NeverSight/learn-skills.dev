Добавьте Web Push в PWA – генерация VAPID‑ключей, поток запроса разрешения, который возникает после действия пользователя, а не при загрузке, `pushManager.subscribe`, обработчики `push` и `notificationclick` в сервис‑воркере, а также отправитель на Node с зафиксированным пакетом `web-push`. Используйте, когда пользователь говорит «push notifications», «notify users when», «send alerts to the app», «notification permission» или «web push».
