أضف إشعارات الويب إلى تطبيق PWA - توليد مفتاح VAPID، وتدفق إذن يطلب بعد إجراء المستخدم بدلاً من التحميل، `pushManager.subscribe`، ومعالجات عامل الخدمة `push` و `notificationclick`، ومُرسل Node مع حزمة `web-push` المثبتة. استخدم عندما يقول المستخدم "push notifications" أو "notify users when" أو "send alerts to the app" أو "notification permission" أو "web push".
