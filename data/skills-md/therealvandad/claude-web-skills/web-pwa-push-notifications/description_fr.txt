Ajouter le Web Push à une PWA - génération de clé VAPID, un flux d’autorisation qui se déclenche après une action utilisateur plutôt qu’au chargement, `pushManager.subscribe`, les gestionnaires `push` et `notificationclick` du service worker, ainsi qu’un expéditeur Node avec le package `web-push` épinglé. Utiliser lorsque l’utilisateur dit « notifications push », « avertir les utilisateurs quand », « envoyer des alertes à l’application », « autorisation de notification » ou « web push ».
