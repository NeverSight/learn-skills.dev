Plane und führe manuelle Tests der laufenden App des Projekts durch. Startet eine Sitzung in einem von fünf Modi: explorativ, Verifizierung, Smoke‑Test, Bewertung (UX, Lokalisierung, Barrierefreiheit, Verbesserungs‑Review) oder KI‑Probe. Erstellt außerdem einen manuellen Testplan, der nur das enthält, was automatisierte Tests nicht beurteilen können. Verwende dies immer, wenn der Nutzer in beliebiger Sprache um einen manuellen Test oder einen manuellen Testplan bittet – „manual test“, „exploratory test“, „bug hunt“, „verify the bug fix“, „smoke test“, „QA this screen“, „review this screen's UX“, „what would you improve“, „check the localized copy“, „test the AI agent's answers“, „write manual test cases“, „kịch bản test manual“ – oder wenn Testdesign, Testplan oder Test‑Fall‑IDs per Hand zugewiesen werden sollen. Nicht zum Schreiben automatisierter Tests.

Bitte antworte stets in der Sprache des Benutzers.
