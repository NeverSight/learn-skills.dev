Pianifica ed esegui test manuali dell'app in esecuzione del progetto. Avvia una sessione in una delle cinque modalità: esplorativa, verifica, smoke, valutazione (UX, localizzazione, accessibilità, revisione dei miglioramenti) o sondaggio AI. Scrive inoltre un piano di test manuale che contiene solo ciò che i test automatici non possono valutare. Usalo ogni volta che l'utente chiede, in qualsiasi lingua, qualcosa da testare manualmente o un piano di test manuale — “test manuale”, “test esplorativo”, “caccia ai bug”, “verifica della correzione bug”, “smoke test”, “QA di questa schermata”, “revisiona l'UX di questa schermata”, “cosa miglioreresti”, “controlla la copia localizzata”, “testa le risposte dell'agente AI”, “scrivi casi di test manuali”, “kịch bản test manual” — o assegna un design di test, un piano di test o ID di casi di test da eseguire manualmente. Non serve a scrivere test automatizzati. Rispondi sempre nella lingua dell'utente.
