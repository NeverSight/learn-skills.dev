Un estudio completo de escritura de ficción, gestionado como un equipo de agentes especialistas con nombre, que guía al autor desde una idea inicial hasta un manuscrito de prosa pulido. Usa esta habilidad siempre que el usuario quiera escribir, planear o revisar ficción — una novela, novela corta, cuento o serie. Activa la respuesta ante solicitudes como «ayúdame a escribir una novela», «tengo una idea para una historia», «desarrolla mis personajes», «construye un mundo para mi fantasía», «esboza mi trama», «corrige esta escena», «mi diálogo suena plano», «dame comentarios de lector beta», o cualquier momento en que el usuario esté creando una narración y se beneficie de una guía estructurada y consciente del oficio. También actívala cuando el usuario mencione a un miembro del estudio (Homer, Aristóteles, Fyodor, Tolkien, Scheherazade, Oscar, Max, Virginia, Borges, Bloom) o solicite cambiar roles creativos / incorporar a un especialista.
