建立互動式簡報網站——投影至會議室的投影片組，由單一簡報者控制。無論使用者何時想要建立、打造或設計簡報、投影片組、演講，或是「bài thuyết trình / slide / trình chiếu」，以及在他們要求新增/編輯投影片、重新樣式化投影片組、搭建新簡報專案、在其他程式庫中重用簡報設定、使用手機控制投影片（遠端、QR 代碼、「điều khiển slide bằng điện thoại」），或匯出投影片為 PDF 時，都請使用此技能──即使他們沒有說「slide」這個詞，只要明確需要投影演講視覺（例如「我下週要演講，需要視覺素材」；「dựng deck cho buổi chia sẻ」；「làm mấy trang chiếu cho hội thảo」），也同樣適用。支援兩種模式：零建置的單一 HTML 檔案，或 Vite + React 專案。請勿將其用於列印文件、一般網頁應用程式或面向個別使用者互動的儀表板。 

請始終以使用者的語言回覆。
