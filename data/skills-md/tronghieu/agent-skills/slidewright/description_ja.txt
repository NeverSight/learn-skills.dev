インタラクティブなプレゼンテーションウェブサイトを構築します — 部屋に投影され、1人のプレゼンターが操作するスライドデッキです。ユーザーがプレゼンテーション、スライドデッキ、講演、または「bài thuyết trình / slide / trình chiếu」を作成、構築、デザインしたいとき、スライドの追加/編集、デックの再スタイル、 新しいプレゼンテーションプロジェクトの雛形作成、別のリポジトリでプレゼン設定を再利用、電話からスライドを操作（リモート、QRコード、「điều khiển slide bằng điện thoại」）、スライドをPDFにエクスポートしたいときに、このスキルをいつでも使用してください — 「スライド」という言葉が出てこなくても、投影用のビジュアルが明確に必要な場合（例：「来週講演があるのでビジュアルが必要」「dựng deck cho buổi chia sẻ」「làm mấy trang chiếu cho hội thảo」）にも適用します。ゼロビルドの単一HTMLファイルまたは Vite + React プロジェクトの2つのトラックをサポートします。印刷用文書、通常のウェブアプリ、個々のユーザーが操作するダッシュボードには使用しないでください。
