أنشئ مواقع عرض تقديمية تفاعلية — مجموعات شرائح تُعرض في غرفة، يتم التحكم فيها بواسطة مقدم واحد. استخدم هذه المهارة كلما أراد المستخدم إنشاء أو بناء أو تصميم عرض تقديمي أو مجموعة شرائح أو حديث، أو "bài thuyết trình / slide / trình chiếu"، وكذلك عندما يطلب إضافة/تحرير شرائح، إعادة تنسيق مجموعة، إنشاء هيكل مشروع عرض تقديمي جديد، إعادة استعمال إعداد العرض في مستودع آخر، التحكم في الشرائح عبر الهاتف (عن بُعد، رمز QR، "điều khiển slide bằng điện thoại")، أو تصدير الشرائح إلى PDF — حتى لو لم يذكر كلمة "slide" لكن يحتاج بوضوح إلى مرئيات لعرض مرئي (مثال: "سأقدم حديثًا الأسبوع المقبل وأحتاج إلى مرئيات"، "dựng deck cho buổi chia sẻ"، "làm mấy trang chiếu cho hội thảo"). تدعم مسارين: ملف HTML واحد بدون بناء، أو مشروع Vite + React. لا تستخدمها للوثائق القابلة للطباعة، أو تطبيقات الويب العادية، أو لوحات التحكم الموجهة للمستخدمين الفرديين للتفاعل.
