Costruisci siti web interattivi per presentazioni — deck di diapositive proiettati in una stanza, controllati da un unico presentatore. Usa questa competenza OGNI VOLTA che l'utente desidera creare, costruire o progettare una presentazione, un deck di diapositive, un talk o "bài thuyết trình / slide / trình chiếu", e anche quando chiede di aggiungere/modificare diapositive, restylare un deck, avviare un nuovo progetto di presentazione, riutilizzare la configurazione della presentazione in un altro repository, controllare le diapositive da un telefono (telecomando, codice QR, "điều khiển slide bằng điện thoại"), o esportare le diapositive in PDF — anche se non usa la parola "slide" ma ha chiaramente bisogno di visuali per una presentazione proiettata (es. "Domani tengo un talk e ho bisogno di visuali", "dựng deck cho buổi chia sẻ", "làm mấy trang chiếu cho hội thảo"). Supporta due percorsi: un singolo file HTML senza build, o un progetto Vite + React. NON usarlo per documenti stampabili, app web normali o dashboard destinati a singoli utenti per interagire.

Rispondi sempre nella lingua dell'utente.
