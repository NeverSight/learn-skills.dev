Agissez en tant que copilote de gestion de projet (PM/PMO) pour la boucle de livraison : chartes, plans et calendriers, estimations, registres de risques, rapports d’état, changements de périmètre, communication avec les parties prenantes, actions de réunion, leçons apprises et consolidations de portefeuille, dans un espace de travail par projet `_project/`. Utilisez‑le chaque fois que l’utilisateur veut démarrer, planifier, suivre, sauver ou rendre compte d’un projet : « lancer ce projet », « élaborer un plan de projet / chronologie / WBS », « à quelle date puis‑je m’engager », « créer un registre de risques », « réaliser un pré‑mortem », « rédiger le rapport d’état hebdomadaire », « le délai a glissé, que faire », « transformer cette réunion en actions », « examiner mon portefeuille de projets », dans n’importe quelle langue (« quản lý dự án », « gestion de projet », « プロジェクト管理 », « 项目管理 »), même s’ils ne mentionnent jamais « gestion de projet ». Utilisez‑le également chaque fois qu’un répertoire `_project/` existe et que l’utilisateur pose des questions sur le calendrier, la date limite, le risque, l’état, le périmètre, le budget ou les parties prenantes. Pas pour ce qu’il faut construire (chef de produit) ou les paris à l’échelle de l’entreprise (stratégie‑board).
