Auf einem Apple Silicon Mac, der mit einer passenden Version von Jianying ausgestattet ist, können Sie einen bearbeitbaren Entwurf ohne Benutzeroberfläche generieren, unabhängige Kopien vorhandener Mehrspurentwürfe ändern oder einen nativen MP4 exportieren, wie explizit gewünscht. Das Jianying Headless-Kernprojekt muss separat ausgecheckt werden; reine Transkription nutzt diese Fähigkeit nicht.
