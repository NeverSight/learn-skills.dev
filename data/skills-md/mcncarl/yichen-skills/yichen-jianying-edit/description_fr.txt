Sur un Mac Apple Silicon équipé d'une version correspondante de Jianying, vous pouvez générer un brouillon modifiable sans interface utilisateur, modifier des copies indépendantes de brouillons multipistes existants ou exporter un fichier MP4 natif comme explicitement demandé. Le projet de base Jianying Headless doit être vérifié séparément ; la transcription pure n'utilise pas cette compétence.
