Coffre numérique d’actifs locaux WeChat : analyse complète/incrémentale pour Mac 4.x, plus requêtes expérimentales de snapshots hors ligne décryptés sous Windows. Les snapshots Windows doivent être accédés via la sous‑commande `snapshot` et ne déclenchent pas le rafraîchissement incrémental sur Mac. Le mode Mac gère l’extraction des clés, le décryptage complet, le rafraîchissement incrémental, l’exportation de contacts/groupes spécifiques, la révision des relations, le suivi client et la consolidation du contenu pour les enregistrements de discussions WeChat locaux, les contacts, les discussions de groupe, les Moments, les favoris et les index de voix/pièces jointes. Mots‑clés déclencheurs : analyse WeChat, WeChat complet, WeChat incrémental, enregistrements de discussion, exportation de discussion, analyse Moments, analyse des favoris, suivi client, yichen‑wechat‑local‑vault.
