Volcano Engine transcripción de audio‑video + corte preliminar automático para narración hablada. Se utiliza para convertir voz a texto, video a texto, reconocimiento de audio, generación de marcas de tiempo/subtítulos SRT, así como para ayudarme a editar segmentos narrados, corte preliminar automático, eliminar repeticiones, eliminar pausas, eliminar errores y generar un MP4 de corte preliminar.

Escenarios de activación: se usa cuando el usuario dice “Ayúdame a transcribir este video”, “Audio‑video a texto”, “Reconoce este audio”, “Ayúdame a editar la narración” o “Edición automática”.
