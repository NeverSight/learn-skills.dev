Herramienta experimental de consulta y exportación de solo lectura local de instantáneas de bases de datos en texto plano de Windows WeChat. Se usa para verificar que el usuario ha autorizado, descifrado y tomado una instantánea estática separada del cliente en ejecución, listar sesiones, consultar/buscar chats por ID de sesión anónima a nivel de instantánea y exportar a Markdown. Explícitamente no lee el proceso Weixin.exe, no extrae ni guarda claves, no descifra la base de datos, no descubre rutas de origen, no controla la interfaz de WeChat y no se conecta a internet. Palabras clave: instantánea de texto plano de Windows WeChat, análisis de solo lectura de WeChat, consultar instantánea de WeChat, exportar chat de WeChat, yichen‑wechat‑windows‑reader.
