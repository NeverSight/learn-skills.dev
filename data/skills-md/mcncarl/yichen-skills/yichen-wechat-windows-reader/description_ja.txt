実験的な Windows WeChat プレーンテキスト データベース スナップショットのローカル読み取り専用クエリおよびエクスポートツール。ユーザーが認可し、復号し、実行中クライアントから切り離された静的スナップショットを取得したことを検証し、セッションを一覧表示し、スナップショットレベルの匿名セッション ID によってチャットをクエリ／検索し、Markdown にエクスポートできる。Weixin.exe プロセスを読み取らず、キーを抽出・保存せず、データベースを復号せず、ソースパスを検出せず、WeChat インターフェースを制御せず、インターネットにも接続しないことを明示的に保証する。トリガーワード: Windows WeChat プレーンテキスト スナップショット、WeChat 読み取り専用分析、WeChat スナップショットのクエリ、WeChat チャットのエクスポート、yichen‑wechat‑windows‑reader。
