Экспериментальный локальный инструмент для только‑чтения и экспорта снимка открытой базы данных WeChat для Windows. Используется для проверки того, что пользователь получил авторизацию, расшифровал и создал статический снимок, отделённый от работающего клиента, перечислил сеансы, выполнил запрос/поиск чатов по анонимному ID сеанса уровня снимка и экспортировал их в Markdown. Очевидно, он не читает процесс Weixin.exe, не извлекает и не хранит ключи, не расшифровывает базу данных, не обнаруживает исходные пути, не управляет интерфейсом WeChat и не подключается к интернету. Триггерные слова: Windows WeChat plaintext snapshot, WeChat read‑only analysis, query WeChat snapshot, export WeChat chats, yichen‑wechat‑windows‑reader.
