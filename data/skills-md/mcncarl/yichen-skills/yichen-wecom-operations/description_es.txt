Punto de entrada oficial de operación wecom‑cli de Enterprise WeChat. Se utiliza para crear documentos ordinarios o inteligentes a partir de Markdown local, generar documentos inteligentes que incluyan imágenes locales después de que el usuario configure un asistente de carga de imágenes, leer o sobrescribir documentos de Enterprise WeChat, crear y gestionar elementos de tareas, y—cuando los permisos empresariales están habilitados—programar, consultar, actualizar o cancelar reuniones y eventos de calendario. Se invoca cuando los usuarios mencionan “Enterprise WeChat document”, “smart document”, “upload Markdown”, “schedule meeting”, “Enterprise WeChat meeting”, “Enterprise WeChat calendar” o “Enterprise WeChat to‑do”; no se utiliza para el envío de mensajes ni para operaciones del cliente de Enterprise WeChat.
