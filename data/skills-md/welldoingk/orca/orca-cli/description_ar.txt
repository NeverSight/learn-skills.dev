تشغيل مسارات العمل التي تديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات الفنية، مشاركة المهارات، تعليقات مسار العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل ذلك على مسار git العادي، أو PTYs المؤقتة، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم استخدام الحاسوب فقط للنوافذ الخارجية أو واجهة سطح المكتب التي تحتاج إلى التحكم على مستوى نظام التشغيل، واستخدم Playwright أو CDP للصفحات الخارجية. يرجى دائماً الرد بلغة المستخدم.
