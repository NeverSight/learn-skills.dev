تشغيل شجرة العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، ومستودعات الأكواد، والأتمتة، والقطع الأثرية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج من خلال سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل ذلك على git worktree الخام، أو PTYs العشوائية، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية ولا يستطيع سطر الأوامر أو نظام الملفات أو الـ API القيام بذلك.
