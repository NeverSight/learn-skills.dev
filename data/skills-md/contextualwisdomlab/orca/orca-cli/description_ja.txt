Orcaが管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そしてOrcaの組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree、アドホック PTY、あるいは Computer Use よりもこれを優先します。CLI、ファイルシステム、API では操作できない可視ウィンドウの GUI 制御が必要な場合にのみ Computer Use を使用してください。

常にユーザーの言語で回答してください。
