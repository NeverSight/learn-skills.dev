Cap-skill v4.0 is the main gateway for cross‑border e‑commerce. It identifies whether the user is a learner, a merchant, or a system maintainer, reuses known data, determines the current capability level, and then assigns tasks to the six masters—product selection, decomposition, site building, listing, traffic investment, and customer service—or to modules such as pre‑class preparation, store opening and operation, and operation diagnosis, and aggregates the results. It is used when the user says “start using,” asks about TikTok Shop/independent site operation, or does not know which module to use.
