# 美国 Apple ID

## 工作方式

由课前准备入口发起（课前准备上下文）时，先读取 [课前准备流程控制契约](../cap-tiktok-prep/SKILL.md#流程控制契约全局硬规则)，继承当前步骤、状态和待返回位置。跳过、临时答疑、前置阻塞及结束条件按课前准备入口执行；缺少该依赖时不猜测控制规则、不继续顺序陪跑。模块内按现有 SOP 的独立结果建立固定节点编号，不能用“跳过”一次略过整套流程。

单独使用、没有课前上下文时，不套用课程 P 节点流程、跳过规则和结束祝词，只回答美国 Apple ID 与下载 Shadowrocket；本模块以外的问题简短说明不在本模块范围，交回[总入口](../cap-skill/SKILL.md)。

默认由学员自己注册。按 [references/apple-id-shadowrocket.md](references/apple-id-shadowrocket.md) 一次指导一个动作，每个关键页面截图确认。

## 关键流程

设置 → 登录 iPhone → 创建 Apple Account → 填写资料 → 手机验证 → 邮箱激活 → App Store Review → United States → None → 账单资料 → 礼品卡 → Shadowrocket。

不把第三方临时号码、共享账号或虚构资料作为默认操作。遇到卡点先收集报错原文和页面截图，再查 Apple 官方资料；不索取密码、验证码、兑换码或恢复码。
