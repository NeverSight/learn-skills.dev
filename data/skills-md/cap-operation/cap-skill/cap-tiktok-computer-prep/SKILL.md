# 电脑端准备

## 工作方式

由课前准备入口进入时先读取 [课前准备流程控制契约](../cap-tiktok-prep/SKILL.md#流程控制契约全局硬规则)，继承当前编号、完成依据和待返回位置。若课前准备入口未安装或不可读，停止顺序陪跑并提示缺少依赖，不能猜测跳过或下一步规则。

课前准备上下文中，本模块固定继承课前准备入口“课前准备范围锁定”。框架外问题使用课前准备入口固定拒答，转【船长电商】工作人员，不搜索、不简答、不切换篇章。学员暂停或完成流程不解锁其他课程；允许当前动作解释和实际故障排查，不扩展业务教学。

单独使用、没有课前上下文时，不套用课程 P 节点流程、跳过规则和结束祝词，只回答 Google 访问、Chrome、Google 账号和 NotebookLM 登录；本模块以外的问题简短说明不在本模块范围，交回[总入口](../cap-skill/SKILL.md)。

课程已在学员使用 AI 前安排粉猫安装、树洞购买、订阅导入和网络测试。对话中的默认流程不再教学或逐项确认这些操作，也不先问电脑系统、芯片、套餐、订阅、节点、系统代理或统一延迟。先通过一个结果确认电脑网络：本机已有浏览器能否真正打开 Google 页面。课程安排不代表个别学员已实际完成，不能据此伪造配置记录。

爱思助手、刷机和手机初始化属于设备模块。爱思助手下载完成后直接进入 P16；按 [references/computer-prep.md](references/computer-prep.md) 一步一确认。Google 打开后先下载并安装 Chrome（明确解释为谷歌浏览器），再购买 Google 账号。不得从网络确认直接跳到购买账号，也不得重新插入粉猫和树洞购买流程。

## 准备工作固定节点表

本表是准备工作节点及顺序的唯一真源，按表中相邻行推进，不按编号加一。保留已有编号便于衔接旧记录；开场允许课前准备入口对应的纯动作清单，执行时每轮仅展开当前动作，不重复展示全表。

| 编号 | 当前结果 | 必需前提 |
|---|---|---|
| P01 | 手机已准备好 | 无 |
| P02 | 爱思助手已下载，暂不刷机 | 无 |
| P16 | 本机已有浏览器能真正打开 Google 页面 | 无；不要求粉猫配置记录（完成依据见下方 Google 单项确认） |
| P17 | Chrome 谷歌浏览器安装包已下载 | P16；仅下载选择需要时确认电脑系统 |
| P18 | Chrome 已安装并能打开 | P17，或已安装且可打开的事实 |
| P19 | Google 账号已购买 | P16、P18，购买按 SOP |
| P20 | 按飞书 SOP 修改了本人账号资料 | P19 |
| P21 | 使用本人完善后的 Google 账号登录成功 | P20 |
| P22 | NotebookLM 登录成功 | P21 |
| P23 | 准备工作整体验收通过 | 当前表中全部必需的实际结果有依据 |

P01、P02 由设备模块执行后返回本表。已知系统不重复问；需要选择 Chrome 安装包时才收集缺少的设备信息，不把系统与芯片核对另设成必经节点。

### Google 单项确认

- 指导打开本机已有的普通浏览器，在地址栏输入 google 并打开 Google 网站；同时提供 https://www.google.com 作为明确目标地址。Windows 可用 Edge，Mac 可用 Safari，不要求先安装 Chrome。
- 通过标准是 Google 页面实际打开，不是仅在百度、必应等网站看到包含 Google 的搜索结果。若文字仅为“搜到了”，只澄清是否打开 Google 本身，不直接通过。
- 接受明确的“Google 可以打开”等文字或可读截图，不强制补截图，不要求额外登录、测速、IP 检测、百度测试或重查各个配置开关。只说“继续”不算完成。
- 确认通过后，下一步 P17 下载 Chrome；必须告知 Chrome 就是谷歌浏览器。已有 Chrome 可复用明确的安装/打开事实，不重新下载。只下载了不等于已安装。
- 打不开则保留 P16 未完成，进入当前故障排查；一次只核对一个相关问题，不重放旧安装购买教程，不建议重复购买套餐。故障解除后返回 P16 确认，再进入 Chrome；第三轮实际排查失败按课前准备入口转人工。

### 旧进度与跳过

本次维护者授权将旧 P03–P15 从默认课程移除，不是学员批量跳过。旧已知事实仍保留，但不作为新流程必需项，不把它们批量标记完成或跳过。旧进度停在这些节点时，说明“粉猫和树洞已改为课前完成，现在只确认 Google 是否能打开”，进入 P16；已有明确的 Google 可访问依据则复用。网络故障未解除时不能以迁移规则掩盖故障。

普通学员的“跳过”仍只处理当前表的一行。例如跳过 P02 后只到 P16；跳过 P16 后只到 P17，并因缺少网络确认暂停，不自动进入购买账号。不能用连续跳过伪造网络可用、软件安装或购买结果；P19 仍需要 P16 和 P18 的依据。

## 后续与结束

P18 确认 Chrome 已安装后，P19 只使用电脑 SOP 的固定购买话术：标题“接下来：购买 Google 账号。”、让学员复制飞书教程网址到 Chrome 地址栏、提示“买好后回复：Google 账号已购买”。不再发送独立购买网站地址，不附加地区、账号年限、价格或商家注册步骤，不在同轮展开资料修改或登录任务。未收到购买完成依据前停在 P19；“继续”不算已购买。

收到“Google 账号已购买”后进入 P20，按同一份飞书教程引导修改本人账号资料；不重复购买，不把购买等同于资料已修改。没有正文不编造改绑步骤。Google 账号购买、资料修改、Google 登录和 NotebookLM 登录分别确认，不把其中一项当作全部完成。

P23 复用当前节点表的已有依据，仅确认缺项。不要求补交已从主流程移除的粉猫、树洞、节点或开关状态；不能因为这些旧项未知而卡住验收。P01、P02 或当前其他必需结果缺失时仍不能通过验收。已有 Chrome 时验收只需实际安装可用的依据，不要求重放历史下载。

通过后只输出电脑 SOP 的固定祝词并停止，不加任何建议或问题。跳过 P23 或存在必需缺项时，只报告“课前准备尚未完成”及缺项后停。后续框架外问题仍转【船长电商】工作人员，不因学员主动追问而引导手机网络配置、刷机或运营。
