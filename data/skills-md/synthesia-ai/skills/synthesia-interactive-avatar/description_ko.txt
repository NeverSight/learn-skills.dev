Synthesia Interactive Avatar를 LiveKit 에이전트에 끝‑끝으로 통합합니다 — 사용자의 기존 LiveKit 설정을 감지하고 세 줄 패턴으로 아바타를 연결하거나, 설정이 없을 경우 완전한 보일러플레이트 음성 에이전트를 자동으로 구성합니다. 다음 상황에서 사용합니다: (1) 실시간, 인터랙티브, 대화형 또는 립싱크 아바타를 LiveKit 에이전트, 앱, 사이트에 추가하거나 세션 중에 아바타를 전환·교체할 때, (2) 사용자가 Synthesia 아바타 플러그인, livekit-plugins-synthesia, synthesia.AvatarSession, 또는 Interactive Avatar를 언급할 때, (3) 다른 아바타 제공업체(HeyGen LiveAvatar, Tavus, Beyond Presence, Hedra)에서 Synthesia로 마이그레이션할 때, (4) Synthesia 아바타 문제를 디버깅할 때 — SynthesiaError( type AUTH, UNKNOWN_AVATAR, TIMEOUT, …), 아바타가 전혀 참여하지 않거나 참여는 하지만 립싱크가 없을 때, (5) 사용자가 명시적으로 Synthesia를 언급하지 않더라도 인간 얼굴이 필요한 모든 음성 에이전트를 구축할 때.
