Überprüfen Sie einen Pull Request oder einen Branch für eine Package-Spezifikation auf Vollständigkeit und Richtigkeit. Verwenden Sie diese Option, wenn der Benutzer darum bittet, einen PR zu überprüfen, zu prüfen, ob sein Branch für den Merge bereit ist, zu verifizieren, ob er die erforderlichen Änderungen nicht übersehen hat, oder wenn er eine Checkliste für die Einreichung wünscht. Akzeptiert eine PR-Nummer, einen Branch-Namen oder kein Argument (aktueller Branch vs. Main).
