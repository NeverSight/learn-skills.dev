Revisar una solicitud de incorporación de cambios o una rama de especificaciones de paquetes para comprobar que estén completas y sean correctas. Úselo cuando el usuario pida que se revise una solicitud de PR, que se compruebe que su rama está lista para fusionarse, que se verifique que no se ha olvidado de realizar los cambios necesarios o que desee una lista de comprobación previa a la presentación. Acepta un número de PR, un nombre de rama o ningún argumento (rama actual frente a rama principal).
