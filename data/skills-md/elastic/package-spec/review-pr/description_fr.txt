Examiner une requête pull ou une branche de spécification de package pour vérifier qu'elle est complète et correcte. À utiliser lorsque l'utilisateur demande de réviser une PR, de vérifier que sa branche est prête à être fusionnée, de vérifier qu'il n'a pas oublié les modifications requises ou qu'il souhaite obtenir une liste de contrôle préalable à la soumission. Accepte un numéro de PR, un nom de branche ou aucun argument (branche actuelle par rapport à la branche principale).
