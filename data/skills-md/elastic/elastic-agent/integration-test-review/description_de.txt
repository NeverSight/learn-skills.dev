Überprüfe die Änderungen an den Integrationstests für den Elastic Agent (testing/integration/**) vor dem Mergen auf Risiken von Unzuverlässigkeit. Verwende diese Option, wenn du einen PR, einen Diff oder einen Commit überprüfst, der Integrationstests hinzufügt oder ändert, oder wenn du gefragt wirst, ob ein Integrationstest in der CI stabil sein wird.
