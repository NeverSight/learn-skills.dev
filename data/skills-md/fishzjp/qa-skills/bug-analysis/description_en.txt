Used when performing root‑cause identification, impact analysis, and regression recommendations for confirmed bugs — reproduce → read the code to locate the root cause → five‑aspect impact analysis → regression recommendation, with entries (root cause / impact / severity basis / fix suggestion / regression suggestion, five extended fields) stored as bug records. Not for: merely collecting bug evidence (automated e2e testing / API testing) or suspected but indeterminate defects (Cx records from test‑case writing).
