Utilisé lors de l'identification de la cause première, de l'analyse d'impact et des recommandations de régression pour les bogues confirmés : reproduire → lire le code pour localiser la cause première → analyse d'impact à cinq aspects → recommandation de régression. L'entrée (avec cinq champs étendus : cause première, impact, base de gravité, suggestion de correctif, recommandation de régression) est conservée en tant qu'enregistrement de bogue. Non utilisé pour simplement collecter des preuves de bogues (tests e2e automatisés / tests API) ou des défauts indéterminés suspectés (enregistrements Cx issus de l'écriture de cas de test).
