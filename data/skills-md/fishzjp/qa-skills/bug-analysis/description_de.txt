Wird für die Ursachenermittlung, Auswirkungsanalyse und Regressionsempfehlungen bei bestätigten Fehlern verwendet – reproduzieren → Code lesen, um die Grundursache zu lokalisieren → Auswirkungsanalyse mit fünf Aspekten → Regressionsempfehlung; Der Eintrag (Grundursache/Auswirkung/Schweregradbasis/Korrekturempfehlung/Regressionsempfehlung, fünf erweiterte Felder) wird als Fehlerdatensatz gespeichert. Gilt nicht für: lediglich das Sammeln von Fehlernachweisen (automatisierte E2E-Tests/API-Tests) oder vermutete unbestimmte Fehler (Cx-Datensätze aus der Erstellung von Testfällen).
