Wird bei der Ursachenermittlung, Auswirkungsanalyse und Regressionsempfehlungen für bestätigte Fehler verwendet – reproduzieren → Code lesen, um die Grundursache zu lokalisieren → Auswirkungsanalyse mit fünf Aspekten → Regressionsempfehlung, wobei Einträge (Grundursache/Auswirkung/Schweregradbasis/Behebungsvorschlag/Regressionsvorschlag, fünf erweiterte Felder) als Fehlerdatensätze gespeichert werden. Nicht zum bloßen Sammeln von Fehlernachweisen (automatisierte E2E-Tests/API-Tests) oder vermuteten, aber unbestimmten Fehlern (Cx-Datensätze aus dem Schreiben von Testfällen).
