Используется при выявлении первопричины, анализе воздействия и выработке рекомендаций по регрессии для подтвержденных ошибок — воспроизвести → прочитать код, чтобы найти первопричину → пятиаспектный анализ воздействия → рекомендации по регрессии, с записями (основная причина / влияние / основа серьезности / предложение по исправлению / предложение по регрессии, пять расширенных полей), хранящимися в виде записей об ошибках. Не для: простого сбора свидетельств об ошибках (автоматическое тестирование e2e/тестирование API) или предполагаемых, но неопределенных дефектов (записи Cx из написания тестовых сценариев).
