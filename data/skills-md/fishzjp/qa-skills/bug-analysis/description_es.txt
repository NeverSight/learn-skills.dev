Se utiliza para errores confirmados al realizar la identificación de la causa raíz, el análisis de impacto y las recomendaciones de regresión: reproducir → leer el código para localizar la causa raíz → análisis de impacto de cinco aspectos → recomendación de regresión. La entrada (causa raíz/impacto/base de gravedad/sugerencia de solución/sugerencia de regresión: cinco campos extendidos) se almacena como un registro de error. No se utiliza para: simplemente recopilar evidencia de errores (pruebas e2e automatizadas/pruebas API) o defectos no deterministas sospechosos (registros Cx de la redacción de casos de prueba).
