Se utiliza al realizar la identificación de la causa raíz, el análisis de impacto y las recomendaciones de regresión para errores confirmados: reproducir → leer el código para localizar la causa raíz → análisis de impacto de cinco aspectos → recomendación de regresión, con entradas (causa raíz / impacto / gravedad / sugerencia de corrección / sugerencia de regresión, cinco campos extendidos) almacenadas como registros de errores. No para: simplemente recopilar evidencia de errores (pruebas e2e automatizadas/pruebas API) o defectos sospechosos pero indeterminados (registros Cx de la redacción de casos de prueba).
