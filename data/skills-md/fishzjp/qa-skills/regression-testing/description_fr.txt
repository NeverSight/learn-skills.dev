Après un changement de code (diff/correction/changement d'exigence), décidez ce que vous souhaitez tester par régression : fichiers modifiés → fonctions → fonctionnalités → traçabilité des cas ; génère une liste classée. Pas pour : l'édition de dossiers (test-case-writing), la stratégie à long terme (test-stratégie). 代码变更后判断回归哪些测试：沿改动分析链产出分级回归清单。不用于：用例增量修改、长期策略。
