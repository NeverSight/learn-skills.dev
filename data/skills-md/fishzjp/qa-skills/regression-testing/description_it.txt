Dopo una modifica al codice (modifica di differenze/correzioni/requisiti), decidere cosa sottoporre a test di regressione: file modificati → funzioni → caratteristiche → tracciabilità dei casi; restituisce un elenco classificato. Non per: modificare file di casi (scrittura di casi di test), strategia a lungo termine (strategia di test). 代码变更后判断回归哪些测试：沿改动分析链产出分级回归清单。不用于：用例增量修改、长期策略。
