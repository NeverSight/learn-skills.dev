Modéliser une exigence/un système : extraire les objectifs, la portée, les rôles, les règles, les exceptions, les dépendances du PRD, la documentation, les bogues, le code ; génère un modèle structuré avec des clarifications. Pas pour : la rédaction de cas, les décisions stratégiques, le pipeline. 建模需求/系统：从PRD、文档、Bug、代码提炼目标/范围/角色/规则/异常/依赖。不用于：直接写用例、策略、流水线。
