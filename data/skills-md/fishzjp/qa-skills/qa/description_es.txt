Entrada de control de calidad de un extremo a otro: "probar esta característica completamente" organiza requisitos, estrategia, casos, revisión, ejecución, errores, regresión, informe; reanudable. Las tareas de una sola etapa utilizan su habilidad escénica. El único punto de entrada para las pruebas de un extremo a otro: cuando dice "Ayúdame a probar este requisito/característica", orquesta los requisitos → estrategia → casos de prueba → revisión → ejecución → análisis de errores → regresión → informe, con resultados persistentes para ejecuciones reanudables; Las solicitudes de una sola etapa utilizan directamente la habilidad de etapa correspondiente.
