Prueba de entrada única de un extremo a otro: cuando dice "Ayúdame a probar este requisito/característica", se organiza el requisito → estrategia → caso de prueba → revisión → ejecución → análisis de errores → regresión → informe, y los resultados se conservan para ejecuciones reanudables; Las solicitudes de una sola etapa utilizan la habilidad de etapa correspondiente directamente.
