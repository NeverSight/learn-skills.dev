Сквозная запись QA: «полностью протестируйте эту функцию» координирует требования, стратегию, случаи, проверку, выполнение, ошибки, регрессию, отчет; возобновляемый. Одноэтапные задания используют свой сценический навык. Единственная точка входа для сквозного тестирования: когда вы говорите «Помогите мне протестировать это требование/функцию», он организует требования → стратегию → тестовые примеры → обзор → выполнение → анализ ошибок → регрессию → отчет, с сохранением результатов для возобновляемых запусков; одноэтапные запросы напрямую используют соответствующий этапный навык.
