Entrée d'assurance qualité de bout en bout : « tester entièrement cette fonctionnalité » orchestre les exigences, la stratégie, les cas, la révision, l'exécution, les bogues, la régression, le rapport ; reprise. Les tâches en une seule étape utilisent leur compétence scénique. Le seul point d'entrée pour les tests de bout en bout : lorsque vous dites « Aidez-moi à tester cette exigence/fonctionnalité », il orchestre exigences → stratégie → cas de test → révision → exécution → analyse de bogues → régression → rapport, avec des résultats conservés pour les exécutions pouvant être reprises ; les requêtes en une seule étape utilisent directement la compétence d’étape correspondante.
