Take an existing pull request from proposed change to verified, merge-ready completion.ユーザーが PR URL のみを提供する場合でも、PR の終了、終了、レスキュー、復活、更新、ブロック解除、ベビーシッター、シェパード、または完了までの処理を要求する場合は常に使用します。 First independently verify that the underlying problem is still real and important and that the proposed solution is directionally correct;変更されていない場合は、変更する前に停止してください。次に、PR をそのベース ブランチで更新し、競合と有効なレビュー フィードバックを解決し、関連する CI の障害を修復し、プロジェクトの完全な検証を実行して、本当にマージ準備ができているかどうかを報告します。
