Führen Sie eine vorhandene Pull-Anfrage von der vorgeschlagenen Änderung zum verifizierten, zusammenführungsbereiten Abschluss. Verwenden Sie es immer dann, wenn der Benutzer eine PR fertigstellen, finalisieren, retten, wiederbeleben, aktualisieren, entsperren, beaufsichtigen, betreuen oder zum Abschluss bringen möchte – auch wenn er nur eine PR-URL angibt. Überprüfen Sie zunächst unabhängig, ob das zugrunde liegende Problem noch real und wichtig ist und ob die vorgeschlagene Lösung richtungsweisend ist. Hören Sie auf, bevor Sie etwas ändern, wenn dies nicht der Fall ist. Aktualisieren Sie dann den PR mit seinem Basiszweig, lösen Sie Konflikte und überprüfen Sie gültiges Feedback, reparieren Sie relevante CI-Fehler, führen Sie die vollständige Validierung des Projekts durch und melden Sie, ob es wirklich für die Zusammenführung bereit ist.
