Take an existing pull request from proposed change to verified, merge-ready completion. Use whenever the user asks to finish, finalize, rescue, revive, update, unblock, babysit, shepherd, or take a PR to completion—even if they only provide a PR URL. First independently verify that the underlying problem is still real and important and that the proposed solution is directionally correct; stop before changing anything when it is not. Then update the PR with its base branch, resolve conflicts and valid review feedback, repair relevant CI failures, run the project’s full validation, and report whether it is truly merge-ready.
