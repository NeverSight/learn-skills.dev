Obligatorisches Abschlusstor für Softwarearbeiten. Rufen Sie IMMER auf, bevor Sie den Code als fertig, validiert, zur Überprüfung oder für die nächste Phase bereit erklären und wann immer Sie eine Codierungsaufgabe überprüfen, abschließen oder finalisieren. Wenn für aufgabenrelevante, nicht festgeschriebene Änderungen keine frische Überprüfung erforderlich ist, rufen Sie „code-review-changes“ einmal auf und validieren Sie dann den festgelegten Code. Nicht für Forschungs-, Diagnose-, Planungs- oder Änderungsprüfungsaufgaben verwenden.
