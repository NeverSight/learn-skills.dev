Puerta de finalización obligatoria para el trabajo de software. SIEMPRE invoque antes de declarar el código terminado, validado, listo para revisión o la siguiente fase, y siempre que verifique, finalice o finalice una tarea de codificación. Si los cambios no confirmados relevantes para la tarea carecen de una revisión exhaustiva, invoque code-review-changes una vez y luego valide el código establecido. No lo utilice para tareas de investigación, diagnóstico, planificación o revisión sin cambios.
