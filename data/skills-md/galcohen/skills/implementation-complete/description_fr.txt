Porte d'achèvement obligatoire pour les travaux logiciels. TOUJOURS appeler avant de déclarer le code terminé, validé, prêt pour la révision ou la phase suivante, et chaque fois que vous vérifiez, terminez ou finalisez une tâche de codage. Si les modifications non validées pertinentes pour la tâche ne font pas l’objet d’un examen neuf, invoquez une fois les modifications de révision du code, puis validez le code réglé. Ne pas utiliser pour des tâches de recherche, de diagnostic, de planification ou d’examen sans changement.
