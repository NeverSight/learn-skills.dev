Integrieren Sie Arcjet Guard in Python Claude Managed Agents – prüfen Sie „user.message“ mit „guard_events“ vor „sessions.events.send“ und steuern Sie benutzerdefinierte Tools auf „agent.custom_tool_use“ mit „guard_custom_tool“ ein. Verwenden Sie diese Option, wenn Sie aufgefordert werden, Arcjet zu gehosteten Claude Managed Agents, anthropischen Beta-Sitzungen, benutzerdefinierten Tools zur Ratenbegrenzung hinzuzufügen oder die Eingabeaufforderung für gehostete Sitzungen zu blockieren. Nicht Claude Agent SDK local query() / PreToolUse.
