Интегрируйте Arcjet Guard в управляемые агенты Python Claude — проверяйте user.message с помощью Guard_events перед сеансами.events.send и закрывайте пользовательские инструменты в агенте Agent.custom_tool_use с помощью Guard_custom_tool. Используйте, когда вас попросят добавить Arcjet к размещенным агентам Claude Managed Agent, антропным бета-сессиям, пользовательским инструментам ограничения скорости или заблокировать внедрение подсказок в размещенных сеансах. Не локальный запрос Claude Agent SDK()/PreToolUse.
