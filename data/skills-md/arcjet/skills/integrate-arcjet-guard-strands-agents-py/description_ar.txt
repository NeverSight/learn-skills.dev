قم بدمج Arcjet Guard في Python Strands Agents - قم بلف @tool المؤلف باستخدام Guard_tool، ثم ضع Guard_hooks على Agent(hooks=) للأدوات غير المغلفة / MCP عبر BeforeToolCallEvent.cancel_tool. استخدمه عندما يُطلب منك إضافة Arcjet إلى الوكلاء/السلاسل، أو تحديد معدل تلك الأدوات، أو فحص الرسائل الواردة، أو حظر الحقن الفوري/معلومات تحديد الهوية الشخصية (PII). هذه خيوط Python، وليست JS @strands-agents/sdk.
