Intégrez Arcjet Guard dans les agents Python Strands - encapsulez @tool créé avec guard_tool et placez guard_hooks sur Agent (hooks =) pour les outils non emballés / MCP via BeforeToolCallEvent.cancel_tool. À utiliser lorsqu'on vous demande d'ajouter Arcjet aux brins/agents de brins, de limiter le débit de ces outils, de filtrer les messages entrants ou de bloquer l'injection d'invite/PII. Il s'agit de brins Python, pas de JS @strands-agents/sdk.
