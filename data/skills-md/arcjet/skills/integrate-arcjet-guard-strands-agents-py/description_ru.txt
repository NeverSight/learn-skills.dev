Интегрируйте Arcjet Guard в агенты Python Strands — оберните авторский @tool с помощью Guard_tool и поместите Guard_hooks в Agent(hooks=) для развернутых инструментов / MCP через BeforeToolCallEvent.cancel_tool. Используйте, когда вас попросят добавить Arcjet к нитям / трандам-агентам, ограничить скорость этих инструментов, проверить входящие сообщения или заблокировать вставку подсказок / PII. Это нити Python, а не JS @strands-agents/sdk.
