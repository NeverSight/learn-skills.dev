Integrieren Sie Arcjet Guard in Python LangChain – umschließen Sie ein von Ihnen aufgerufenes BaseTool mit Guard_tool, setzen Sie ArcjetMiddleware + ToolPolicy auf create_agent oder beobachten Sie eine Kette mit ArcjetCaptureHandler. Verwenden Sie diese Option, wenn Sie aufgefordert werden, Arcjet zu LangChain, create_agent, Langchain-Core-Tools hinzuzufügen, die Rate dieser Tools zu begrenzen, eingehende Nachrichten zu überprüfen oder Prompt-Injection/PII zu blockieren. Dies ist Python LangChain, nicht LangChain JS createAgent und nicht LangGraph JS.
