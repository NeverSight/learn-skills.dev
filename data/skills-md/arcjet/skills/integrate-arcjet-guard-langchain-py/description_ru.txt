Интегрируйте Arcjet Guard в Python LangChain — оберните вызываемый вами BaseTool с помощью Guard_tool, поместите ArcjetMiddleware + ToolPolicy в create_agent или наблюдайте за цепочкой с помощью ArcjetCaptureHandler. Используйте, когда вас попросят добавить Arcjet в LangChain, create_agent, инструменты langchain-core, ограничить скорость этих инструментов, отфильтровать входящие сообщения или заблокировать внедрение подсказок/личных данных. Это Python LangChain, а не LangChain JS createAgent и не LangGraph JS.
