Intégrez Arcjet Guard dans Python LangChain : enveloppez un BaseTool que vous appelez avec guard_tool, placez ArcjetMiddleware + ToolPolicy sur create_agent ou observez une chaîne avec ArcjetCaptureHandler. À utiliser lorsqu'on vous demande d'ajouter Arcjet à LangChain, create_agent, les outils langchain-core, de limiter le débit de ces outils, de filtrer les messages entrants ou de bloquer l'injection d'invites/PII. Il s'agit de Python LangChain, pas de LangChain JS createAgent et non de LangGraph JS.
