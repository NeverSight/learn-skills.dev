Integrieren Sie Arcjet Guard in das Python Claude Agent SDK – umschließen Sie das erstellte @tool mit „guard_tool“ und verwenden Sie „guard_hooks“ für den eingehenden UserPromptSubmit sowie „PreToolUse“ für nicht umschlossene integrierte Funktionen/MCP. Verwenden Sie diese Option, wenn Sie aufgefordert werden, Arcjet zu claude-agent-sdk hinzuzufügen, die Rate dieser Tools zu begrenzen, eingehende Eingabeaufforderungen zu überprüfen oder Eingabeaufforderungsinjektion/PII zu blockieren. Dies ist Python claude-agent-sdk, nicht der JS-Adapter und keine von Claude Managed Agents gehosteten Sitzungen.
