Intégrez Arcjet Guard dans le SDK Python Claude Agent - encapsulez @tool créé avec guard_tool et utilisez guard_hooks pour UserPromptSubmit entrant plus PreToolUse sur les éléments intégrés/MCP non emballés. À utiliser lorsqu'on vous demande d'ajouter Arcjet à claude-agent-sdk, de limiter le débit de ces outils, d'afficher les invites entrantes ou de bloquer l'injection d'invites/PII. Il s'agit de Python claude-agent-sdk, pas de l'adaptateur JS ni des sessions hébergées par Claude Managed Agents.
