Интегрируйте Arcjet Guard в SDK Python Claude Agent — оберните авторский @tool с помощью Guard_tool и используйте Guard_hooks для входящего UserPromptSubmit плюс PreToolUse для развернутых встроенных модулей / MCP. Используйте, когда вас попросят добавить Arcjet в claude-agent-sdk, ограничить скорость этих инструментов, отфильтровать входящие запросы или заблокировать внедрение запросов/личных данных. Это Python claude-agent-sdk, а не адаптер JS и не сеансы, размещаемые агентами Claude Managed Agents.
