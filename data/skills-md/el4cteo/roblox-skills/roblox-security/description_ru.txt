Анти‑эксплойт‑проектирование — никогда не доверяйте клиенту, проверяйте каждый удалённый аргумент (NaN, поддельные экземпляры, строки), ограничение частоты запросов, злоупотребление ProximityPrompt/ClickDetector, сетевое владение, валидация перемещений и попаданий, дублирование экономики/торговли, конфиденциальность кода, защищённые телепортации, эвристика, API бана. Используйте при написании серверных обработчиков клиентского ввода, боевых/экономических/торговых систем или при проверке на наличие эксплойтов.
