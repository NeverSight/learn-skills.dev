Визуализация в Blender 5.2 с использованием Cycles/EEVEE/Workbench — предустановки качества, настройка GPU, адаптивная выборка, шумоподавление, световые пути, управление цветом (AgX, Khronos PBR Neutral, ACES), вывод в PNG/EXR/MP4, проходы, API композитора 5.0, командная строка и пакетный рендеринг с несколькими камерами. Подходит для любого статичного изображения, анимации или вращающегося рендера.
