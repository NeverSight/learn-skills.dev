Игровые окружения в Blender 5.2 — ландшафт из шума или карт высот (эрозия, террасы, игровые зоны, материалы по наклону/высоте, 16‑битные карты высот + сплат‑карты для UE/Unity), распределение биомов по наклону/высоте/маске с пуассоновским интервалом, метрики и валидация модульного набора (сеточная система, опорные точки, стыки, плотность текстель). Использовать для уровней, ландшафтов, лесов, модульных зданий, подземелий.
