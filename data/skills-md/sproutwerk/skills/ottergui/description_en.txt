Build, debug, and extend FFXIV Dalamud plugins using OtterGui, including code used by Puni.sh plugins such as AutoRetainer and Artisan. Use to set up OtterGui and its nested OtterGuiInternal submodule, fix a plugin not compiling because of OtterGui or SDK mismatches, adapt code between Limiana, upstream, and Artisan pins, or implement tables, selectors, combo controls, clipping, buttons, and color pickers with ImUtf8, ImRaii, ItemSelector, Table and Column, FileSystemSelector, FilterComboCache, and ImGuiClip. Luna and ImSharp are separate successor APIs.
