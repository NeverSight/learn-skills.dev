Build FFXIV Dalamud plugin windows, migrate ImGuiNET code, manage drawing lifetimes, and debug ImGui interfaces. Use with Dalamud.Bindings.ImGui, API 13+ migration, ImU8String overloads, WindowSystem, Window, ImRaii scopes, fonts, textures, tables and clipping, SeString rendering, notifications, drag-drop, file dialogs, ImPlot, or ImGuizmo. Covers the stock Dalamud UI layer; Luna and ImSharp use a separate API.
