Entwerfen, prüfen oder überarbeiten Sie datenintensive Dashboards, Admin-Tools, Betriebskonsolen, Analyseprodukte und Unternehmensschnittstellen als Entscheidungsschnittstellen und nicht als Metriksammlungen. Wird verwendet, wenn ein Benutzer darum bittet, ein Dashboard, eine KPI-Seite, eine BI-Ansicht, eine Analyse-Benutzeroberfläche, eine Betriebskonsole, eine Überwachungsschnittstelle, eine Datenvisualisierung oder einen anderen Bildschirm zu erstellen oder zu verbessern, auf dem eine Person priorisieren, diagnostizieren, vergleichen, entscheiden oder handeln muss.
