Codia Design Skills と Codia Open API を利用して、画像・デザインリソース・ビジュアルアセットの作成、編集、強化、変換、管理を行います。ユーザーが画像、ポスター、キャンペーンクリエイティブ、商品リスト画像、EC 資産、バナー、サムネイル、またはソーシャルバリアントの生成を依頼した際に使用します。背景除去、背景差し替え、オブジェクト消去、許可された透かしの除去、アップスケーリング、リフレーミング、リミックス、参照画像の利用による画像編集も可能です。スクリーンショット、UI モックアップ、画像、PDF、レポート、ドキュメントを編集可能なデザインデータ、レイヤー、PPTX スライド、または SVG／ベクターアセットに変換できます。画像の検査や説明も行えます。さらに、Codia CLI の設定、認証、クレジット、利用状況、上限、自動リチャージの管理も行えます。
