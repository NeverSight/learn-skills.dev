Imponi un design UI/UX pulito quando generi codice frontend. Previene anti‑pattern di stile come colori omogenei, icona in quadrato arrotondato, abuso di emoji, font serif eccessivi, glassmorphism, gradienti/ombreggiature gratuiti, animazioni rotte e scarsa gerarchia visuale. Usalo quando costruisci qualsiasi UI rivolta agli utenti, landing page, dashboard o componente.

Si prega di rispondere sempre nella lingua dell'utente.
