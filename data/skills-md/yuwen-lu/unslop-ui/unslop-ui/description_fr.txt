Applique un design UI/UX épuré lors de la génération du code frontend. Empêche les anti‑patterns de type vibe tels que les couleurs homogènes, les icônes dans des carrés arrondis, l’abus d’émojis, les polices à empattement excessives, le glassmorphisme, les dégradés ou ombres superflus, les animations cassées et une mauvaise hiérarchie visuelle. À utiliser lors de la création de toute interface utilisateur, page d’atterrissage, tableau de bord ou composant destiné aux utilisateurs.
