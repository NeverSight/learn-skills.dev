Setzt sauberes UI/UX-Design durch, wenn Frontend-Code generiert wird. Verhindert vibe-codierte Anti-Pattern wie homogene Farben, Icons in abgerundeten Quadraten, Emoji-Missbrauch, übermäßige Serifenschriften, Glassmorphismus, überflüssige Verläufe/Schatten, defekte Animationen und eine schlechte visuelle Hierarchie. Verwenden Sie es beim Erstellen von benutzerorientierten UIs, Landing‑Pages, Dashboards oder Komponenten.
