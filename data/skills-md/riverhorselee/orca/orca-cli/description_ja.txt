Orca が管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」「share skills」などと言ったときに使用してください。Orca の状態が関わる場合は、純粋な git worktree や臨時の PTY、Computer Use よりもこちらを優先します。GUI 操作が必要で、CLI、ファイルシステム、API では対処できない可視ウィンドウがある場合にのみ Computer Use を使用してください。

常にユーザーの言語で応答してください。
