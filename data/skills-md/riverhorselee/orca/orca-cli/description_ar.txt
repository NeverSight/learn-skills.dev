تشغيل شجرة العمل المدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، ومستودعات الكود، والأتمتة، والملفات، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على شجرة Git العادية، أو PTYs المؤقتة، أو الاستخدام الحاسوبي عندما تكون حالة Orca متضمنة. استخدم الاستخدام الحاسوبي فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة المستخدم الرسومية لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به. يرجى دائمًا الرد بلغة المستخدم.
