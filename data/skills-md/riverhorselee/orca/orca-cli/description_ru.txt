Управляйте рабочими деревьями, контекстами папок, терминалами, репозиториями, автоматизациями, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Используйте это, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff» / «handover» / «give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочитайте его вместо обычного git worktree, произвольных PTY или Computer Use, когда задействовано состояние Orca. Используйте Computer Use только когда необходимо управлять видимым окном GUI, которое нельзя контролировать через CLI, файловую систему или API.
