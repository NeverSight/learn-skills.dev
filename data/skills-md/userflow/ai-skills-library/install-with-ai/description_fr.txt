Installe Userflow.js dans de nouvelles applications ou des applications existantes. L'installation par défaut comprend uniquement init() + identify() (après connexion/inscription) + reset(). Utilisez-le lorsqu'une personne souhaite installer Userflow, ajouter Userflow.js ou intégrer Userflow dans une base de code. Installation uniquement — la vérification d'une installation existante ou la recommandation d'attributs est hors périmètre.
