Installe Userflow.js dans des applications nouvelles ou existantes. L'installation par défaut est init() + identify() (après connexion/inscription) + reset() uniquement. À utiliser lorsqu’une personne veut installer Userflow, ajouter Userflow.js ou intégrer Userflow dans une base de code. Installation uniquement — vérifier une installation existante ou recommander des attributs n’est pas dans le périmètre.
