Installiert Userflow.js in neue oder bestehende Anwendungen. Die Standardinstallation besteht nur aus init() + identify() (nach Anmeldung/Registrierung) + reset(). Verwenden, wenn jemand Userflow installieren, Userflow.js hinzufügen oder Userflow in einen Codebestand einbinden möchte. Nur Installation – die Überprüfung einer bestehenden Installation oder das Empfehlen von Attributen liegt außerhalb des Umfangs.
