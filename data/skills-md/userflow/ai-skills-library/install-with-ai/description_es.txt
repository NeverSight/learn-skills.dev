Instala Userflow.js en aplicaciones nuevas o existentes. La instalación predeterminada es init() + identify() (después de iniciar sesión/registrarse) + reset() únicamente. Se usa cuando alguien quiere instalar Userflow, añadir Userflow.js o integrar Userflow en una base de código. Solo instalación — verificar una instalación existente o recomendar atributos está fuera del alcance.
