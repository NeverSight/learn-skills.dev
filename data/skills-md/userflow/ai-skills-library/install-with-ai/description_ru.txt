Устанавливает Userflow.js в новые или существующие приложения. По умолчанию установка включает только init() + identify() (после входа/регистрации) + reset(). Используется, когда кто‑то хочет установить Userflow, добавить Userflow.js или интегрировать Userflow в кодовую базу. Только установка — проверка существующей установки или рекомендация атрибутов выходит за рамки.
