Reglas de diseño de Rust que se deben aplicar al escribir, editar o refactorizar código Rust — forma de la API, errores y pánicos, propiedad, traits, módulos, documentación, unsafe/FFI, async y nomenclatura — compiladas a partir de las Microsoft Pragmatic Rust Guidelines, la Google Rust Style Guide, los patrones rust‑unofficial y el Gang of Four en Rust. rustc y clippy cubren las verificaciones mecánicas; esta habilidad cubre las decisiones de diseño que ellos no pueden.
