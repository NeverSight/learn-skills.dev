Правила проектирования Rust, которые следует применять при написании, редактировании или рефакторинге кода на Rust — форма API, ошибки и паники, владение, трейты, модули, документация, unsafe/FFI, async и именование — собраны из Microsoft Pragmatic Rust Guidelines, Google Rust Style Guide, rust-unofficial patterns и Gang of Four в Rust. rustc и clippy покрывают механические проверки; этот навык охватывает решения по дизайну, которые они не могут.
