Prepare y cree solicitudes de extracción de GitHub para el trabajo de implementación validado y comprometido localmente después de g-implement-repository-work. Úselo cuando Codex deba inspeccionar los compromisos de implementación, agrupar los problemas implementados en un PR coherente, verificar la trazabilidad del SDLC y el seguimiento del estado local, redactar un título/cuerpo del PR, requerir aprobación explícita antes de enviar o crear el PR, ejecutar gh pr create, informar la URL del PR y evitar el cierre de problemas, movimientos de proyectos, etiquetas, asignaciones, fusiones o forzar envíos a menos que se aprueben por separado.
