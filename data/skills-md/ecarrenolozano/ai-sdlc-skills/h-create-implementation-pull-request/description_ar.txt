قم بإعداد وإنشاء طلبات سحب (Pull Requests) على GitHub للعمل المنفذ محليًا والمُعتمد بعد g-implement-repository-work. استخدم ذلك عندما يحتاج Codex إلى فحص الالتزامات التنفيذية، وتجميع القضايا المنفذة في طلب سحب متماسك، والتحقق من تتبع القابلية للتتبع في دورة حياة تطوير البرمجيات (SDLC) وتتبع الحالة المحلي، وصياغة عنوان/محتوى طلب السحب، وطلب موافقة صريحة قبل الدفع أو إنشاء الطلب، تشغيل ‎gh pr create‎، الإبلاغ عن رابط الطلب، وتجنب إغلاق القضايا، نقل المشاريع، العلامات، التعيينات، الدمج، أو الدفع القسري ما لم يتم الموافقة عليها بشكل منفصل.  

يرجى دائمًا الرد بلغة المستخدم.
