قم بإعداد وإنشاء طلبات سحب GitHub لأعمال التنفيذ الملتزمة محليًا والتي تم التحقق من صحتها بعد عمل g-implement-repository. يُستخدم عندما يجب على Codex فحص التزامات التنفيذ، وتجميع المشكلات المنفذة في علاقات عامة متماسكة، والتحقق من إمكانية تتبع SDLC وتتبع الحالة المحلية، وصياغة عنوان/نص العلاقات العامة، وطلب موافقة صريحة قبل دفع أو إنشاء العلاقات العامة، وتشغيل إنشاء العلاقات العامة، والإبلاغ عن عنوان URL للعلاقات العامة، وتجنب إغلاق المشكلات، أو نقل المشروع، أو التسميات، أو التعيينات، أو الدمج، أو الدفع القسري ما لم تتم الموافقة على ذلك بشكل منفصل.
