Preparare e creare richieste pull GitHub per il lavoro di implementazione convalidato e impegnato a livello locale dopo g-implement-repository-work. Da utilizzare quando il Codex deve ispezionare gli impegni di implementazione, raggruppare i problemi implementati in un PR coerente, verificare la tracciabilità dell'SDLC e il monitoraggio dello stato locale, redigere un titolo/corpo del PR, richiedere l'approvazione esplicita prima di inviare o creare il PR, eseguire gh pr create, segnalare l'URL del PR ed evitare la chiusura del problema, spostamenti di progetti, etichette, assegnazioni, unioni o forzature se non approvati separatamente.
