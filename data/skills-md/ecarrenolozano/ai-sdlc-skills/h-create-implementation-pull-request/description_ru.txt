Подготовьте и создайте запросы на включение GitHub для локально подтвержденной и проверенной работы по реализации после g-implement-repository-work. Используйте, когда Кодексу необходимо проверить коммиты по реализации, сгруппировать реализованные проблемы в согласованный PR, проверить прослеживаемость SDLC и отслеживание локального статуса, составить проект заголовка/тела PR, потребовать явного утверждения перед отправкой или созданием PR, запустить gh pr create, сообщить URL-адрес PR и избежать закрытия проблем, перемещения проекта, маркировки, присвоения, слияния или принудительной отправки, если это не одобрено отдельно.
