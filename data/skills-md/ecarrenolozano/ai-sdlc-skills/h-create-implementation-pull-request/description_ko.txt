g-implement-repository-work 이후 로컬에서 커밋되고 검증된 구현 작업에 대한 GitHub 풀 요청을 준비하고 생성합니다. Codex가 구현 커밋을 검사하고, 구현된 문제를 일관된 PR로 그룹화하고, SDLC 추적성 및 로컬 상태 추적을 확인하고, PR 제목/본문 초안을 작성하고, PR을 푸시하거나 생성하기 전에 명시적인 승인을 요구하고, gh pr create를 실행하고, PR URL을 보고하고, 별도로 승인되지 않는 한 문제 종결, 프로젝트 이동, 레이블, 할당, 병합 또는 강제 푸시를 피해야 하는 경우에 사용합니다.
