g-implement-repository-work の後に、ローカルでコミットされ検証された実装作業用の GitHub プル リクエストを準備して作成します。 Codex が実装のコミットを検査し、実装された問題を一貫した PR にグループ化し、SDLC のトレーサビリティとローカル ステータスの追跡を検証し、PR のタイトル/本文をドラフトし、PR をプッシュまたは作成する前に明示的な承認を要求し、pr create を実行し、PR URL を報告し、個別に承認されない限り問題のクローズ、プロジェクトの移動、ラベル、割り当て、マージ、または強制プッシュを回避する必要がある場合に使用します。
