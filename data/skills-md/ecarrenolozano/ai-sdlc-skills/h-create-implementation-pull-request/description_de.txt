Bereiten Sie GitHub-Pull-Requests für lokal festgeschriebene, validierte Implementierungsarbeiten nach der g-implement-repository-work vor und erstellen Sie sie. Verwenden Sie Codex, wenn Codex Implementierungs-Commits überprüfen, implementierte Probleme in einer kohärenten PR gruppieren, SDLC-Rückverfolgbarkeit und lokale Statusverfolgung überprüfen, einen PR-Titel/-Körper entwerfen, eine ausdrückliche Genehmigung vor dem Pushen oder Erstellen der PR erfordern, gh pr create ausführen, die PR-URL melden und Issue-Schließungen, Projektverschiebungen, Beschriftungen, Zuweisungen, Zusammenführungen oder erzwungene Pushs vermeiden müssen, sofern nicht separat genehmigt.
