Anima componentes de React con Animate UI (primitivas animadas basadas en Motion para Radix UI, Base UI y React Aria). Para componentes shadcn/ui, ejecuta el codemod `@animate-ui/cli` que reemplaza sus primitivas por las de Animate UI; para componentes construidos directamente sobre Radix UI, Base UI o React Aria, cambia la importación a `@animate-ui/react`; para cualquier otra cosa (componentes personalizados, marcado simple, otras librerías), aplica las reglas de movimiento, tokens (springs, curvas, escalas, desenfoque, desplazamientos) y recetas de Animate UI con Motion (motion/react). También revisa el movimiento existente con el comando `audit`, migra proyectos de Animate UI v1 y convierte cualquier ícono (Lucide, Hugeicons, Tabler, Phosphor, un SVG personalizado) en un ícono animado compatible con `AnimateIcon`. Úsalo cuando se solicite animar un componente, hacer que shadcn/ui sea "animado", añadir animaciones de entrada/salida, presión o intercambio, configurar Animate UI, animar un ícono, cambiar el ritmo de la animación, revisar si el movimiento sigue las reglas de Animate UI o encontrar animaciones lentas y entrecortadas.  

Por favor, responde siempre en el idioma del usuario.
