使用 Animate UI 为 React 组件添加动画（基于 Motion 的动画原语，适用于 Radix UI、Base UI 和 React Aria）。对于 shadcn/ui 组件，运行 `@animate-ui/cli` 的代码转换工具，将它们的原语替换为 Animate UI 的；对于直接基于 Radix UI、Base UI 或 React Aria 构建的组件，则将导入换成 `@animate-ui/react`；对于其他情况（自定义组件、普通标记、其他库），则应用 Animate UI 的运动规则、代币（弹簧、曲线、比例、模糊、位移）以及 Motion（motion/react）的配方。同时使用 `audit` 命令审查现有的运动，迁移 Animate UI v1 项目，并将任何图标（Lucide、Hugeicons、Tabler、Phosphor 或自定义 SVG）转换为兼容 `AnimateIcon` 的动画图标。在以下情境中使用：被要求为组件添加动画、将 shadcn/ui “动画化”、添加进出、点击或切换动画、设置 Animate UI、为图标添加动画、改变动画速度、审查运动是否遵循 Animate UI 规则，或发现缓慢且卡顿的动画。
