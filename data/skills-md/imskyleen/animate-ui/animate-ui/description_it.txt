Anima i componenti React con Animate UI (primitive animate basati su Motion per Radix UI, Base UI e React Aria). Per i componenti shadcn/ui, esegui il codemod `@animate-ui/cli` che sostituisce le loro primitive con quelle di Animate UI; per i componenti costruiti direttamente su Radix UI, Base UI o React Aria, cambia l’importazione a `@animate-ui/react`; per qualsiasi altra cosa (componenti personalizzati, markup semplice, altre librerie), applica le regole di motion di Animate UI, i token (spring, curve, scale, blur, shift) e le ricette con Motion (motion/react). Inoltre esegue la revisione del motion esistente con il comando `audit`, migra i progetti da Animate UI v1 e trasforma qualsiasi icona (Lucide, Hugeicons, Tabler, Phosphor, un SVG personalizzato) in un’icona animata compatibile con `AnimateIcon`. Usa questo strumento quando ti viene chiesto di animare un componente, rendere shadcn/ui “animato”, aggiungere animazioni di entrata/uscita, pressione o scambio, configurare Animate UI, animare un’icona, modificare il ritmo dell’animazione, verificare se il motion segue le regole di Animate UI o trovare animazioni lente e scattose.
