Anima componenti React con Animate UI (primitive animate basate su Motion per Radix UI, Base UI e React Aria). Per i componenti shadcn/ui, esegue il codemod `@animate-ui/cli` che sostituisce le loro primitive con quelle di Animate UI; per i componenti costruiti direttamente su Radix UI, Base UI o React Aria, sostituisce l’importazione con `@animate-ui/react`; per tutto il resto (componenti personalizzati, markup semplice, altre librerie), applica le regole di motion di Animate UI, i token (spring, curve, scale, blur, shift) e le ricette con Motion (motion/react). Inoltre revisiona il motion esistente con il comando `audit`, migra progetti Animate UI v1 e trasforma qualsiasi icona (Lucide, Hugeicons, Tabler, Phosphor, un SVG personalizzato) in un’icona animata compatibile con `AnimateIcon`. Usalo quando ti viene chiesto di animare un componente, rendere shadcn/ui “animato”, aggiungere animazioni di entrata/uscita, pressione o scambio, configurare Animate UI, animare un’icona, modificare il ritmo dell’animazione, verificare se il motion segue le regole di Animate UI o individuare animazioni lente e scattose.

Rispondi sempre nella lingua dell’utente.
