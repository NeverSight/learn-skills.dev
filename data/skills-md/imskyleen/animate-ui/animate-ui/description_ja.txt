Animate UI を使って React コンポーネントにアニメーションを付けます（Radix UI、Base UI、React Aria 用のモーションベースのアニメーションプリミティブ）。shadcn/ui コンポーネントに対しては、`@animate-ui/cli` の codemod を実行し、プリミティブを Animate UI のものに置き換えます；Radix UI、Base UI、React Aria 上に直接構築されたコンポーネントについては、インポート先を `@animate-ui/react` に変更します；それ以外（カスタムコンポーネント、プレーンマークアップ、他のライブラリ）に対しては、Animate UI のモーションルール、トークン（スプリング、曲線、スケール、ぼかし、シフト）と Motion（motion/react）を使ったレシピを適用します。`audit` コマンドで既存のモーションをレビューし、Animate UI v1 プロジェクトを移行し、任意のアイコン（Lucide、Hugeicons、Tabler、Phosphor、カスタム SVG）を `AnimateIcon` に対応したアニメーションアイコンに変換します。コンポーネントにアニメーションを付ける、shadcn/ui を「アニメート」させる、enter/exit や press、swap アニメーションを追加する、Animate UI をセットアップする、アイコンをアニメーション化する、アニメーション速度を変更する、モーションが Animate UI のルールに従っているかレビューする、あるいは遅くてぎくしゃくしたアニメーションを見つけるときに使用してください。
