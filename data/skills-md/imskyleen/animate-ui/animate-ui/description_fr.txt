Animez les composants React avec Animate UI (primitifs animés basés sur Motion pour Radix UI, Base UI et React Aria). Pour les composants shadcn/ui, exécutez le codemod `@animate-ui/cli` qui remplace leurs primitives par celles d’Animate UI ; pour les composants construits directement sur Radix UI, Base UI ou React Aria, remplacez l’importation par `@animate-ui/react` ; pour tout le reste (composants personnalisés, balisage simple, autres bibliothèques), appliquez les règles de motion d’Animate UI, les tokens (springs, courbes, échelles, flou, décalages) et les recettes avec Motion (motion/react). Vous pouvez également examiner le motion existant avec la commande `audit`, migrer les projets Animate UI v1 et transformer n’importe quelle icône (Lucide, Hugeicons, Tabler, Phosphor, un SVG personnalisé) en une icône animée compatible avec `AnimateIcon`. Utilisez cela lorsqu’on vous demande d’animer un composant, de rendre shadcn/ui « animé », d’ajouter des animations d’entrée/sortie, de pression ou d’échange, de configurer Animate UI, d’animer une icône, de modifier le rythme de l’animation, de vérifier que le motion respecte les règles d’Animate UI, ou de détecter des animations lentes et saccadées.
