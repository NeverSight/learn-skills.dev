Animieren Sie React‑Komponenten mit Animate UI (motion‑basierte animierte Primitive für Radix UI, Base UI und React Aria). Für shadcn/ui‑Komponenten führt das `@animate-ui/cli`‑Codemod aus, das deren Primitive durch die von Animate UI ersetzt; für Komponenten, die direkt auf Radix UI, Base UI oder React Aria aufbauen, wird der Import zu `@animate-ui/react` ausgetauscht; für alles andere (maßgeschneiderte Komponenten, reines Markup, andere Bibliotheken) wendet es die Bewegungsregeln, Tokens (Springs, Kurven, Skalierungen, Unschärfe, Verschiebungen) und Rezepte von Animate UI mit Motion (motion/react) an. Außerdem prüft es bestehende Bewegungen mit dem `audit`‑Befehl, migriert Animate UI‑v1‑Projekte und verwandelt jedes Icon (Lucide, Hugeicons, Tabler, Phosphor, ein benutzerdefiniertes SVG) in ein animiertes Icon, das mit `AnimateIcon` kompatibel ist. Verwenden Sie es, wenn Sie aufgefordert werden, eine Komponente zu animieren, shadcn/ui „animiert“ zu machen, Ein‑/Ausblend‑, Druck‑ oder Austausch‑Animationen hinzuzufügen, Animate UI einzurichten, ein Icon zu animieren, das Animations‑Tempo zu ändern, zu prüfen, ob Bewegungen den Regeln von Animate UI entsprechen, oder langsame und ruckelige Animationen zu finden.
