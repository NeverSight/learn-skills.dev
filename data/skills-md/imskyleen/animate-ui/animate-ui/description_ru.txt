Анимируйте React‑компоненты с Animate UI (анимированные примитивы на основе Motion для Radix UI, Base UI и React Aria). Для компонентов shadcn/ui запускает codemod `@animate-ui/cli`, который заменяет их примитивы на примитивы Animate UI; для компонентов, построенных непосредственно на Radix UI, Base UI или React Aria, заменяет импорт на `@animate-ui/react`; для всего остального (кастомные компоненты, простая разметка, другие библиотеки) применяет правила анимации Animate UI, токены (пружины, кривые, масштабы, размытие, сдвиги) и рецепты с Motion (motion/react). Также проверяет существующее движение с помощью команды `audit`, мигрирует проекты Animate UI v1 и превращает любой значок (Lucide, Hugeicons, Tabler, Phosphor, пользовательский SVG) в анимированный значок, совместимый с `AnimateIcon`. Используйте, когда просят анимировать компонент, сделать shadcn/ui «анимированным», добавить анимации входа/выхода, нажатия или замены, настроить Animate UI, анимировать значок, изменить темп анимации, проверить, соответствует ли движение правилам Animate UI, или найти медленные и дерганые анимации.
