Анимируйте React‑компоненты с помощью Animate UI (анимированные примитивы на основе Motion для Radix UI, Base UI и React Aria). Для компонентов shadcn/ui запускает кодмод `@animate-ui/cli`, который заменяет их примитивы на примитивы Animate UI; для компонентов, построенных напрямую на Radix UI, Base UI или React Aria, меняет импорт на `@animate-ui/react`; для всего остального (кастомных компонентов, чистой разметки, других библиотек) применяет правила движения Animate UI, токены (пружины, кривые, масштабы, размытие, сдвиги) и рецепты с Motion (motion/react). Также проверяет существующее движение с помощью команды `audit`, мигрирует проекты с Animate UI v1 и превращает любой значок (Lucide, Hugeicons, Tabler, Phosphor, пользовательский SVG) в анимированный значок, совместимый с `AnimateIcon`. Используйте, когда просят анимировать компонент, сделать shadcn/ui «анимированным», добавить анимацию входа/выхода, нажатия или замены, настроить Animate UI, анимировать значок, изменить темп анимации, проверить, соответствует ли движение правилам Animate UI, или найти медленные и «пришарканные» анимации.
