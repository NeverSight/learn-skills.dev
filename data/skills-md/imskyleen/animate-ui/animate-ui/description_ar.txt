قم بتحريك مكونات React باستخدام Animate UI (فرا primitives متحركة تعتمد على Motion لـ Radix UI وBase UI وReact Aria). بالنسبة لمكونات shadcn/ui، يتم تشغيل تعديل الكود `@animate-ui/cli` الذي يستبدل primitives الخاصة بها ببدائل Animate UI؛ بالنسبة للمكونات المبنية مباشرةً على Radix UI أو Base UI أو React Aria، يتم استبدال الاستيراد إلى `@animate-ui/react`؛ أما بالنسبة لأي شيء آخر (مكونات مخصصة، ترميز بسيط، مكتبات أخرى) فَتُطبّق قواعد الحركة، والرموز (springs، curves، scales، blur، shifts) ووصفات Animate UI باستخدام Motion (motion/react). كما يتم مراجعة الحركة الحالية بأمر `audit`، وترحيل مشاريع Animate UI v1، وتحويل أي أيقونة (Lucide، Hugeicons، Tabler، Phosphor، SVG مخصص) إلى أيقونة متحركة متوافقة مع `AnimateIcon`. استخدم ذلك عندما يُطلب منك تحريك مكون، أو جعل shadcn/ui «متحركًا»، أو إضافة دخول/خروج، أو ضغط أو تبديل الرسوم المتحركة، أو إعداد Animate UI، أو تحريك أيقونة، أو تغيير وتيرة الرسوم المتحركة، أو مراجعة ما إذا كانت الحركة تتبع قواعد Animate UI، أو العثور على رسوم متحركة بطيئة ومهتزّة.
