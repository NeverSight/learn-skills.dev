تحريك مكوّنات React باستخدام Animate UI (بدائل متحركة تعتمد على Motion لـ Radix UI وBase UI وReact Aria). بالنسبة لمكوّنات shadcn/ui، يتم تشغيل أداة codemod `@animate-ui/cli` التي تستبدل بدائلها ببدائل Animate UI؛ بالنسبة للمكوّنات المبنية مباشرةً على Radix UI أو Base UI أو React Aria، يتم استبدال الاستيراد بـ `@animate-ui/react`؛ أما بالنسبة لأي شيء آخر (مكوّنات مخصصة، ترميز بسيط، مكتبات أخرى)، فيُطبّق قواعد الحركة والرموز (الزنابِك، المنحنيات، المقاييس، التشويش، التحولات) ووصفات Animate UI باستخدام Motion (motion/react). كما يتم مراجعة الحركة الحالية بأمر `audit`، وترحيل مشاريع Animate UI النسخة 1، وتحويل أي أيقونة (Lucide أو Hugeicons أو Tabler أو Phosphor أو SVG مخصص) إلى أيقونة متحركة متوافقة مع `AnimateIcon`. يُستخدم ذلك عند طلب تحريك مكوّن، أو جعل shadcn/ui "متحرك"، أو إضافة دخول/خروج أو ضغط أو تبادل الرسوم المتحركة، أو إعداد Animate UI، أو تحريك أيقونة، أو تغيير وتيرة الحركة، أو مراجعة ما إذا كانت الحركة تتبع قواعد Animate UI، أو العثور على رسومات متحركة بطيئة ومتقطعة.
