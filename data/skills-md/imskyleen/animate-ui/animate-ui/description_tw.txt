使用 Animate UI 為 React 元件加入動畫（基於 Motion 的動畫基元，支援 Radix UI、Base UI 與 React Aria）。對於 shadcn/ui 元件，執行 `@animate-ui/cli` 代碼調整工具，將其基元換成 Animate UI 提供的；對於直接以 Radix UI、Base UI 或 React Aria 建構的元件，將匯入改為 `@animate-ui/react`；對於其他任何情況（自訂元件、純標記、其他函式庫），套用 Animate UI 的運動規則、代幣（彈簧、曲線、縮放、模糊、位移）以及使用 Motion（motion/react）的配方。亦可使用 `audit` 指令檢查現有的動畫、遷移 Animate UI v1 專案，並將任何圖示（Lucide、Hugeicons、Tabler、Phosphor 或自訂 SVG）轉換為相容於 `AnimateIcon` 的動畫圖示。當需要為元件加入動畫、讓 shadcn/ui 「動起來」、新增進出、按壓或切換動畫、設定 Animate UI、為圖示加上動畫、調整動畫速度、檢查動畫是否符合 Animate UI 規則，或找出緩慢且卡頓的動畫時，即可使用本工具。
