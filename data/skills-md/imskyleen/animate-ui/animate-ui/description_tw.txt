使用 Animate UI 為 React 元件添加動畫（基於 Motion 的動畫原語，適用於 Radix UI、Base UI 與 React Aria）。對於 shadcn/ui 元件，執行 `@animate-ui/cli` 代碼修改工具，將其原語替換為 Animate UI 的；對於直接基於 Radix UI、Base UI 或 React Aria 架構的元件，將匯入切換至 `@animate-ui/react`；對於其他情況（自訂元件、純標記、其他函式庫），套用 Animate UI 的運動規則、代幣（彈簧、曲線、縮放、模糊、位移）以及 Motion（motion/react）提供的配方。還可使用 `audit` 指令檢查現有動畫、遷移 Animate UI v1 專案，並將任何圖示（Lucide、Hugeicons、Tabler、Phosphor 或自訂 SVG）轉換為相容於 `AnimateIcon` 的動畫圖示。當需要為元件添加動畫、將 shadcn/ui「動畫化」、加入進入/退出、按壓或切換動畫、設定 Animate UI、為圖示添加動畫、調整動畫速度、檢查動畫是否符合 Animate UI 規則，或找出緩慢且卡頓的動畫時，請使用本工具。
