Безопасность смарт‑контрактов Move на Sui. Используйте при проверке кода Move на уязвимости, проектировании шаблонов контроля доступа, безопасном управлении возможностями, обеспечении безопасности использования случайных чисел, проверке инвариантов, планировании управления обновлениями, управлении ключами или аудите привилегированных операций. Также используйте, когда пользователь задаёт вопросы о безопасности UpgradeCap, отзыве возможностей, авторизации совместных объектов, ограничениях использования случайных чисел в ончейне, проверке данных оракула, экстренных контролях или безопасности подписи транзакций на клиентской стороне.  
Для основ языка Move см. навык `sui-move`. Для модели объектов и владения — навык `object-model`. Для публикации и обновления пакетов — навык `sui-publish`.  

Пожалуйста, всегда отвечайте на языке пользователя.
