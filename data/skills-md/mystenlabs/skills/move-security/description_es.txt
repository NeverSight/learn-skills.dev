Seguridad de contratos inteligentes Move en Sui. Úsalo al revisar código Move en busca de vulnerabilidades de seguridad, diseñar patrones de control de acceso, manejar capacidades de forma segura, asegurar el uso de aleatoriedad, validar invariantes, planificar la gobernanza de actualizaciones, gestionar claves o auditar operaciones privilegiadas. También úsalo cuando el usuario pregunte sobre la seguridad de UpgradeCap, revocación de capacidades, autorización de objetos compartidos, restricciones de aleatoriedad en cadena, validación de datos de oráculos, controles de emergencia o seguridad en la firma de transacciones del front‑end.

Para los fundamentos del lenguaje Move, consulta la habilidad `sui-move`. Para el modelo de objetos y la propiedad, consulta la habilidad `object-model`. Para publicar y actualizar paquetes, consulta la habilidad `sui-publish`.

Por favor, responde siempre en el idioma del usuario.
