Move 스마트 계약 보안을 Sui에서. 보안 취약점 검토, 접근 제어 패턴 설계, 권한을 안전하게 다루기, 난수 사용 보호, 불변식 검증, 업그레이드 거버넌스 계획, 키 관리, 혹은 특권 작업 감사를 할 때 사용하세요. 또한 사용자가 UpgradeCap 보안, 권한 취소, 공유 객체 인증, 온체인 난수 제한, 오라클 데이터 검증, 비상 제어, 프론트엔드 트랜잭션 서명 안전성 등에 대해 물어볼 때도 사용합니다.  
Move 언어 기본 사항은 `sui-move` 스킬을 참고하세요. 객체 모델 및 소유권은 `object-model` 스킬을, 패키지 게시 및 업그레이드는 `sui-publish` 스킬을 확인하세요.  

항상 사용자의 언어로 응답하세요.
