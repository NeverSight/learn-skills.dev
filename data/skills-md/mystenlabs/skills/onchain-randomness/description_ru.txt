Ончейн‑рандомность в Sui. Используйте при генерации случайных значений в смарт‑контрактах Move, работая с объектом Random (0x8) или RandomGenerator, защищая функции, использующие случайность, от атак композиции, PTB‑атак или утечки состояния, реализуя паттерн commit‑reveal, балансируя газ между ветками выполнения или интегрируя случайность из TypeScript.  
Для общих шаблонов безопасности Move см. навык `move-security`. Для фундаментальных аспектов языка Move см. навык `sui-move`. Для шаблонов SDK TypeScript см. навык `sui-sdks`.
