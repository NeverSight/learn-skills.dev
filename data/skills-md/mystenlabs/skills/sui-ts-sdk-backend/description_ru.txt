Sui TypeScript SDK для бекенд‑сервисов и автономных агентов. Используйте при построении бекенда, агента или сервиса, который взаимодействует с Sui программно без CLI — создание пары ключей, пополнение из крана, настройка клиента, построение и подпись транзакций, публикация пакетов из кода, спонсируемые транзакции, выполнение транзакций в масштабе с помощью исполнителей, подпись через облачный KMS (AWS/GCP) и многоподписные рабочие процессы. Также используйте, когда пользователь спрашивает, как инициализировать Sui‑агента, построить бекенд‑службу подписания или запустить конвейеры транзакций высокой пропускной способности.  
Для разработки фронтенд‑dApp с кошельками смотрите навык `frontend-apps`. Для выбора SDK (TS vs Rust vs community) — навык `sui-sdks`. Для семантики PTB и справочника команд — навык `ptbs`. Для разработки смарт‑контрактов Move — навык `sui-move`.  

Пожалуйста, всегда отвечайте на языке пользователя.
