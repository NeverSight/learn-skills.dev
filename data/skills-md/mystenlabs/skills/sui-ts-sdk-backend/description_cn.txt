Sui TypeScript SDK 用于后端服务和自主代理。在构建与 Sui 进行编程交互且不依赖 CLI 的后端、代理或服务时使用——包括密钥对创建、领取水龙头资金、客户端设置、交易构建与签名、从代码发布包、赞助交易、大规模执行器运行交易、云 KMS 签名（AWS/GCP）以及多签工作流。用户询问如何引导 Sui 代理、构建后端签名服务或运行高吞吐量交易流水线时也应使用此 SDK。  

前端 dApp 开发与钱包集成，请参阅 `frontend-apps` 技能。关于 SDK 选择（TS、Rust 或社区实现），请参阅 `sui-sdks` 技能。关于 PTB 语义和命令参考，请参阅 `ptbs` 技能。关于 Move 智能合约开发，请参阅 `sui-move` 技能。
