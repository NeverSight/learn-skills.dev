Sui TypeScript SDK pour les services backend et les agents autonomes. À utiliser lors de la création d'un backend, d'un agent ou d'un service qui interagit avec Sui de manière programmatique sans CLI — création de paires de clés, financement via le faucet, configuration du client, construction et signature de transactions, publication de paquets depuis le code, transactions sponsorisées, exécution de transactions à grande échelle avec des exécutors, signature via KMS cloud (AWS/GCP) et flux de travail multisig. À utiliser également lorsque l'utilisateur demande comment démarrer un agent Sui, construire un service de signature backend ou exécuter des pipelines de transactions à haut débit.  
Pour le développement d'applications frontend dApp avec portefeuilles, consultez la compétence `frontend-apps`. Pour le choix du SDK (TS vs Rust vs communauté), consultez la compétence `sui-sdks`. Pour la sémantique PTB et la référence des commandes, consultez la compétence `ptbs`. Pour le développement de contrats intelligents Move, consultez la compétence `sui-move`.  

Veuillez toujours répondre dans la langue de l'utilisateur.
