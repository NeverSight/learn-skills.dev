Sui TypeScript SDK 用於後端服務與自主代理。適用於構建與 Sui 以程式方式交互且不使用 CLI 的後端、代理或服務——密鑰對創建、測試水龍頭資金補給、客戶端設定、交易建構與簽署、從程式碼發布套件、贊助交易、使用執行器大規模運行交易、雲端 KMS 簽署（AWS/GCP）以及多簽工作流程。當使用者詢問如何啟動 Sui 代理、建立後端簽名服務或運行高吞吐量交易管道時，也請使用本 SDK。  
前端 dApp 開發與錢包相關，請參考 `frontend-apps` 技能。關於 SDK 選擇（TS、Rust 與社群），請參考 `sui-sdks` 技能。關於 PTB 語意與指令參考，請參考 `ptbs` 技能。關於 Move 智能合約開發，請參考 `sui-move` 技能。  

請始終以使用者的語言回覆。
