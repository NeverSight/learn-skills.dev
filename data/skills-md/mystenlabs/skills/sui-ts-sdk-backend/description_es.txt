SDK de Sui en TypeScript para servicios backend y agentes autónomos. Úselo al crear un backend, agente o servicio que interactúe con Sui programáticamente sin CLI — creación de pares de claves, financiación de faucet, configuración del cliente, construcción y firma de transacciones, publicación de paquetes desde código, transacciones patrocinadas, ejecución de transacciones a gran escala con ejecutores, firma con KMS en la nube (AWS/GCP) y flujos de trabajo multisig. También úselo cuando el usuario pregunte cómo iniciar un agente Sui, construir un servicio de firma backend o ejecutar canalizaciones de transacciones de alto rendimiento.  
Para desarrollo de dApps frontend con carteras, consulte la habilidad `frontend-apps`. Para la selección del SDK (TS vs Rust vs comunidad), consulte la habilidad `sui-sdks`. Para la semántica PTB y referencia de comandos, consulte la habilidad `ptbs`. Para el desarrollo de contratos inteligentes Move, consulte la habilidad `sui-move`.  

Por favor, responda siempre en el idioma del usuario.
