Sui TypeScript SDK는 백엔드 서비스와 자율 에이전트를 위한 것입니다. CLI 없이 프로그래밍 방식으로 Sui와 상호작용하는 백엔드, 에이전트, 또는 서비스를 구축할 때 사용합니다 — 키페어 생성, 파우셋 자금 공급, 클라이언트 설정, 트랜잭션 빌드 및 서명, 코드에서 패키지 배포, 스폰서 트랜잭션, 실행기를 사용한 대규모 트랜잭션 실행, 클라우드 KMS 서명(AWS/GCP), 멀티시그 워크플로 등. 또한 사용자가 Sui 에이전트를 부트스트랩하는 방법, 백엔드 서명 서비스 구축, 혹은 고처리량 트랜잭션 파이프라인 실행 방법을 문의할 때도 사용합니다.

지갑을 활용한 프론트엔드 dApp 개발은 `frontend-apps` 스킬을 참고하십시오. SDK 선택(TS vs Rust vs 커뮤니티)은 `sui-sdks` 스킬을, PTB 의미론 및 명령어 참조는 `ptbs` 스킬을, Move 스마트 계약 개발은 `sui-move` 스킬을 확인하세요.

항상 사용자의 언어로 답변하십시오.
