مجموعة أدوات Sui TypeScript SDK للخدمات الخلفية والوكلاء المستقلين. استخدمها عند بناء خلفية أو وكيل أو خدمة تتفاعل مع Sui برمجةً دون سطر الأوامر — إنشاء زوج مفاتيح، تمويل الصنبور، إعداد العميل، بناء وتوقيع المعاملات، نشر الحزمة من الشيفرة، المعاملات الممولة، تشغيل المعاملات على نطاق واسع باستخدام المنفّذات، توقيع KMS السحابي (AWS/GCP)، وسير عمل متعددة التوقيعات. واستخدمها أيضًا عندما يسأل المستخدم عن كيفية تمهيد وكيل Sui، بناء خدمة توقيع خلفية، أو تشغيل خطوط أنابيب معاملات عالية الإنتاجية.  
لتطوير تطبيقات dApp الواجهة الأمامية مع المحافظ، انظر مهارة `frontend-apps`. لاختيار مجموعة الأدوات (TS مقابل Rust مقابل المجتمع)، انظر مهارة `sui-sdks`. للمعاني المرجعية لأوامر PTB، انظر مهارة `ptbs`. لتطوير عقود Move الذكية، انظر مهارة `sui-move`.  

يرجى دائمًا الرد بلغة المستخدم.
