Интеграция TypeScript SDK DeepBook V3. Используйте при создании торговых приложений, ботов или скриптов, которые взаимодействуют с пулами DeepBook с помощью SDK @mysten/deepbook-v3. Охватывает настройку клиента, жизненный цикл BalanceManager, размещение лимитных и рыночных ордеров, свапы, запросы к книге ордеров, управление ордерами и обработку комиссий.  
Для архитектуры DeepBook и адресов контрактов см. навык `deepbook-overview`. Для интеграции смарт‑контрактов Move см. навык `deepbook-move`.
