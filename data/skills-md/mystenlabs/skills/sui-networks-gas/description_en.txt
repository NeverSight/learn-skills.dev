Sui network environments and gas economics. Use when the user asks about Mainnet, Testnet, Devnet, or Localnet differences, gas cost calculations (computation + storage - rebate), gas budgets, epochs, or how the Sui network operates at a high level. This skill covers network concepts, not CLI commands.
For CLI client setup, address management, faucets, and explorers, see the `sui-client` skill. For installing the Sui CLI, see the `sui-install` skill.
