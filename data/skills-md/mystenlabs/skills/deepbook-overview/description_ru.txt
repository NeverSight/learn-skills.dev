Общий обзор DeepBook V3 на Sui — архитектура, ключевые концепции, модели интеграции, адреса контрактов, поддерживаемые монеты и информация о пулах. Используйте при объяснении DeepBook новичку, сравнении подходов к интеграции (Move vs SDK vs read‑only), поиске адресов контрактов в mainnet/testnet или понимании дизайна Pool/Book/State/Vault.

Для использования TypeScript SDK и торговли см. навык `deepbook-sdk`. Для интеграции смарт‑контрактов Move см. навык `deepbook-move`.
