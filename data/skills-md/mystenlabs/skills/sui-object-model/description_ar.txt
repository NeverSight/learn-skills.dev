إشارة متعمقة لنموذج كائنات Sui: أنواع الملكية، قدرات الكائن، الحقول الديناميكية، المجموعات، الإصدار، أنماط النقل، والكائنات المشتقة. استخدم هذه المهارة كلما سأل المستخدم عن كائنات Sui، ملكية الكائن (مملوك للعنوان، مشترك، ثابت، ملفوف)، كيفية نقل أو مشاركة أو تجميد الكائنات، الحقول الديناميكية مقابل حقول الكائن الديناميكية، Table مقابل Bag مقابل VecMap، إصدار الكائن، التغليف وفك التغليف، نوع الاستلام، قواعد النقل المخصصة، نمط "البطاطا الساخنة"، نمط القدرة، حذف الكائن، عرض الكائن، أو كيفية نمذجة البيانات (المخزونات، السجلات، العناصر المتداخلة) في Sui Move. أيضًا استخدمها عندما يحتاج المستخدم إلى الاختيار بين أنواع الملكية أو أنماط التخزين لحالته.
