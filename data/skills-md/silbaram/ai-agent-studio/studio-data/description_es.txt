Herramientas compartidas para las habilidades de diseño de juego: un script de entrada (studio.py) y un paquete de Python que validan registros de conceptos, ítems, mejoras permanentes, enemigos, cálculos de combate, construcciones de crecimiento en ejecución, presupuestos de estadísticas, mejora y artesanía, flujo de moneda y registros de pruebas de juego, generan borradores de ítems y enemigos a partir de curvas de presupuesto, simulan la meta‑progresión de roguelike, verifican etiquetas de procedencia numérica en documentos de diseño, sirven un visor de navegador de solo lectura que muestra todos los datos de diseño de un proyecto con resultados de validación, e instalan un agente de juez de solo lectura y ganchos de verificación de datos para Claude Code. Úsalo al ver, comprobar o simular datos de diseño de juego, al configurar los ganchos de Claude Code para un proyecto de juego, o cuando otra habilidad en este repositorio te indique ejecutar una verificación.
