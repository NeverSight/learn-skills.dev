Общий инструментарий для навыков геймдизайна: один входной скрипт (studio.py) и один пакет Python, который проверяет записи концепций, предметы, постоянные улучшения, врагов, расчёты боя, сборки роста в процессе игры, бюджеты статов, усиления и крафт, поток валюты и записи плейтестов, создает черновики предметов и врагов по бюджетным кривым, симулирует мета‑прогрессию в рогалик‑играх, проверяет числовые метки происхождения в дизайнерской документации, предоставляет только‑для‑чтения браузерный просмотрщик, показывающий все данные дизайна проекта с результатами валидации, и устанавливает только‑для‑чтения агента‑судью и хуки проверки данных для Claude Code. Используйте при просмотре, проверке или симуляции данных геймдизайна, при настройке хуков Claude Code для игрового проекта или когда другой навык в этом репозитории предлагает выполнить проверку.
