Strumenti condivisi per le skill di game design: uno script di ingresso (studio.py) e un pacchetto Python che convalidano i record di concetto, gli oggetti, gli upgrade permanenti, i nemici, i calcoli di combattimento, le build di crescita in‑run, i budget di statistiche, il potenziamento e il crafting, il flusso di valuta e i record di playtest, generano bozze di oggetti e nemici da curve di budget, simulano la meta‑progresione roguelike, verificano i tag di provenienza numerica nei documenti di design, forniscono un visualizzatore web in sola lettura che mostra tutti i dati di design di un progetto con i risultati della convalida e installano un agente giudice in sola lettura e hook di verifica dei dati per Claude Code. Usalo quando visualizzi, verifichi o simuli i dati di design di un gioco, quando configuri i hook di Claude Code per un progetto di gioco, o quando un'altra skill in questo repository ti chiede di eseguire una verifica.
