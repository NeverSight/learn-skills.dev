ゲームデザインスキル向けの共有ツール：エントリースクリプト（studio.py）1つと、コンセプトレコード、アイテム、永続的アップグレード、敵、戦闘計算、ラン中の成長ビルド、ステータス予算、強化・クラフト、通貨フロー、プレイテストレコードを検証するPythonパッケージです。また、予算曲線からアイテムや敵のドラフトを作成し、ローグライクのメタプロgressionをシミュレートし、設計ドキュメント内の数値的由来タグをチェックし、プロジェクト全体の設計データと検証結果を表示する読み取り専用のブラウザビューアを提供し、Claude Code 用の読み取り専用ジャッジエージェントとデータチェックフックをインストールします。ゲームデザインデータの閲覧、チェック、シミュレーション時、ゲームプロジェクトの Claude Code フックを設定する際、あるいはこのリポジトリ内の別のスキルがチェック実行を指示したときに使用してください。
