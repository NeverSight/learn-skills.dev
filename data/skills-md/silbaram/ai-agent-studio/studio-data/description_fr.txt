Outils partagés pour les compétences de conception de jeu : un script d’entrée (studio.py) et un package Python qui valident les enregistrements de concepts, les objets, les améliorations permanentes, les ennemis, les calculs de combat, les constructions de croissance en cours de partie, les budgets de statistiques, l’amélioration et l’artisanat, le flux de monnaie et les enregistrements de playtest, élaborent des objets et des ennemis à partir des courbes budgétaires, simulent la méta‑progression roguelike, vérifient les balises de provenance numérique dans les documents de conception, offrent un visualiseur navigateur en lecture seule affichant toutes les données de conception d’un projet avec les résultats de validation, et installent un agent juge en lecture seule ainsi que des hooks de vérification de données pour Claude Code. À utiliser lors de la visualisation, de la vérification ou de la simulation des données de conception de jeu, lors de la configuration des hooks Claude Code pour un projet de jeu, ou lorsqu’une autre compétence de ce dépôt vous indique d’exécuter une vérification.
