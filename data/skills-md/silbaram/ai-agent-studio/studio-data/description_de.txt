Gemeinsame Werkzeuge für die Game‑Design‑Fähigkeiten: ein Einstiegsskript (studio.py) und ein Python‑Paket, das Konzeptdatensätze, Gegenstände, permanente Upgrades, Gegner, Kampfberechnungen, Wachstums‑Builds im Lauf, Stat‑Budgets, Verbesserungen und Handwerk, Geldfluss und Playtest‑Aufzeichnungen validiert, Gegenstände und Gegner aus Budgetkurven entwirft, Roguelike‑Meta‑Progression simuliert, numerische Herkunftstags in Designdokumenten prüft, einen schreibgeschützten Browser‑Viewer bereitstellt, der alle Design‑Daten eines Projekts mit Validierungsergebnissen anzeigt, und einen schreibgeschützten Richter‑Agenten sowie Datenprüfhooks für Claude Code installiert. Verwenden Sie es beim Betrachten, Prüfen oder Simulieren von Game‑Design‑Daten, beim Einrichten von Claude‑Code‑Hooks für ein Spielprojekt oder wenn eine andere Fähigkeit in diesem Repository Sie auffordert, eine Prüfung durchzuführen.
