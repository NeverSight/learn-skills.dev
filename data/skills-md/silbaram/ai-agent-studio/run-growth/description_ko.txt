모델 인-런 성장: 스탯 증가와 선택 제한이 있는 레벨업 선택지, 각 레벨마다 무작위로 제공되는 선택지, 그리고 플레이어가 무엇을 취할지 결정하는 빌드 정책(우선순위 또는 분산). 시드된 시뮬레이션을 실행해 각 빌드의 전투 단계별 기대 스탯을 구하고, 이를 전투 계산에 추가한 뒤, 살해와 생존에 필요한 타수로 빌드를 비교하며, 어느 단계에서든 한 빌드가 최소한 동일하게 좋을 경우 경고한다. 레벨업 특전, 카드, 혹은 업그레이드 선택지를 설계할 때, 빌드가 구별되는지 확인하거나 인-런 성장이 난이도에 어떤 영향을 미치는지 확인할 때, 어떤 장르와 엔진에서도 사용한다. 항상 사용자의 언어로 응답하십시오.
