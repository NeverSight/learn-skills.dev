Chrome MV3 확장 프로그램을 구축하여 사용자가 로그인한 브라우저 세션 내부에서 공개 API가 없거나 제한된 외부 웹 서비스에 작동하도록 합니다. 사이트의 JSON 트래픽을 관찰하고, 인증 헤더를 재생하여 데이터를 가져오고 쓰며, 오프라인에서 버퍼링하고, 기록을 올리고 명령을 내려주는 하나의 폴링 엔드포인트를 통해 호스트 앱과 동기화합니다. 사용 사례: (1) 제품이 API도 없고 OAuth도 없으며 내보내기도 제공하지 않는 서드파티 사이트에서 데이터 추출 또는 액션이 필요하고, 사용자의 비밀번호를 이용한 서버 측 스크래핑이 불가능한 경우, (2) 기존 커넥터 확장 프로그램을 강화해야 할 때: 서비스 워커가 죽거나, 알람이 절대 트리거되지 않거나, 콘텐츠 스크립트가 죽은 채 배포되었거나, 레코드가 사라지거나, 실행되지 않은 채 명령이 실패로 표시되는 경우, (3) 사용자가 언급한 경우: 브라우저 확장 커넥터, Chrome 확장 통합, API 없음, 로그인 세션에서 스크래핑, MV3 서비스 워커, 콘텐츠 스크립트 MAIN world, fetch/XHR 가로채기, 인증 헤더 재생, 오프라인 버퍼, 페어링 PIN, “<사이트>에서 예약 동기화”, “API 없이 <사이트>에 게시”. 컴파일되고 테스트된 런타임(tap, relay, worker, queue, pairing, diagnostics)과 벤더 중립 어댑터 시임을 제공합니다; 호스트 앱의 엔드포인트는 문서화된 계약입니다. Chrome MV3; 호스트 비종속적. 서비스별 어댑터가 아니라, 그 위에 별도의 스킬이 필요합니다.
