Создайте расширение Chrome MV3, которое взаимодействует с внешним веб‑сервисом без (или с ограниченным) публичным API из текущей пользовательской сессии браузера, наблюдая за JSON‑трафиком сайта, воспроизводя его заголовки аутентификации для запросов и записей, буферизуя данные офлайн и синхронизируя их с хост‑приложением через один опрашиваемый эндпоинт, передающий записи вверх и команды вниз. Используйте, когда: (1) продукту нужны данные из стороннего сайта или действия на нём, а сайт не предоставляет API, OAuth и экспорт, а серверный скрапинг с паролем пользователя невозможен; (2) существующее расширение‑коннектор требует усиления: сервис‑воркер падает, сигнализация никогда не срабатывает, контент‑скрипт оказался нерабочим, записи пропадают, команды помечаются как неуспешные без выполнения; (3) пользователь упоминает: коннектор в виде браузерного расширения, интеграция Chrome‑расширения, отсутствие API, скрапинг из залогиненной сессии, MV3 сервис‑воркер, контент‑скрипт в MAIN‑мире, перехват fetch/XHR, воспроизведение заголовков аутентификации, офлайн‑буфер, парный PIN, «синхронизация бронирований с <сайт>», «публикация на <сайт> без API». Поставьте скомпилированный, протестированный рантайм (перехват, ретрансляция, воркер, очередь, паринг, диагностика) и нейтральный адаптер‑шов; эндпоинты хост‑приложения описаны в документированном контракте. Chrome MV3; независим от хоста. Не адаптер под каждый сервис; такие адаптеры — отдельные навыки.
