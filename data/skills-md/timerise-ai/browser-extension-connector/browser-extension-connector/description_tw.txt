構建一個 Chrome MV3 擴充功能，讓它在使用者已登入的瀏覽器工作階段內，對外部網站（該網站沒有（或僅提供有限）公開 API）進行操作，觀察站點的 JSON 流量，重放其驗證標頭以執行讀取與寫入，離線緩衝，並透過一個輪詢端點與主機應用程式同步，上傳記錄、下發指令。適用情境：（1）產品需要從第三方網站取得資料或執行動作，而該網站不提供 API、OAuth 或匯出功能，且使用使用者密碼的伺服器端爬蟲不可行；（2）現有的連接器擴充功能需要加固：服務工作者會異常終止、警報從未觸發、內容腳本已失效、記錄遺失、指令標記為失敗卻未實際執行；（3）使用者提到：瀏覽器擴充連接器、Chrome 擴充整合、無 API、從已登入的會話中抓取、MV3 服務工作者、內容腳本主世界、攔截 fetch/XHR、重放驗證標頭、離線緩衝、配對 PIN、「同步 <網站> 的預訂」、「在沒有 API 的情況下發佈至 <網站>」。提供編譯、測試過的執行時環境（攔截、轉發、工作者、佇列、配對、診斷）以及供應商中立的介面接合層；主機應用程式的端點以文件化合約為依據。Chrome MV3；與主機無關。不是針對單一服務的適配器；那類適配器屬於額外技能。
