构建一个 Chrome MV3 扩展，从用户已登录的浏览器会话内部对外部 Web 服务进行操作，即使该服务没有（或仅有有限的）公共 API，监控站点的 JSON 流量，重放其身份验证头部以进行读取和写入，离线缓冲，并通过单一轮询端点与宿主应用同步，该端点上行记录、下行指令。使用场景：  
1）产品需要从没有 API、没有 OAuth 且没有导出功能的第三方站点获取数据或执行操作，且服务器端使用用户密码进行抓取不可行；  
2）现有的连接器扩展需要加固：服务工作线程崩溃、警报从不触发、内容脚本发布时已失效、记录丢失、指令标记为失败但实际未执行；  
3）用户提到的关键词：浏览器扩展连接器、Chrome 扩展集成、无 API、从已登录会话抓取、MV3 服务工作线程、内容脚本 MAIN 世界、拦截 fetch/XHR、重放身份验证头部、离线缓冲、配对 PIN、“从 <site> 同步预订”、 “在没有 API 的情况下发布到 <site>”。  

交付一个已编译、经过测试的运行时（tap、relay、worker、queue、pairing、diagnostics）以及一个供应商中立的适配器接口；宿主应用的端点遵循文档化合同。Chrome MV3；宿主无关。不是针对单一服务的适配器；那类适配器是另外的技能。
