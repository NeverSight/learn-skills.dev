Construye una extensión Chrome MV3 que actúe sobre un servicio web externo sin (o con una API pública limitada) desde la sesión de navegador del usuario ya autenticado, observando el tráfico JSON del sitio, reproduciendo sus encabezados de autenticación para lecturas y escrituras, almacenando en búfer offline y sincronizando con una aplicación host a través de un único endpoint sondado que transporta registros ascendente y comandos descendente. Úsala cuando: (1) un producto necesita extraer datos o realizar acciones en un sitio de terceros que no ofrece API, OAuth ni exportación, y el scraping del lado del servidor con la contraseña del usuario no es una opción; (2) una extensión conector existente necesita robustecerse: un service worker que falla, una alarma que nunca se dispara, un script de contenido que salió defectuoso, registros que desaparecen, comandos marcados como fallidos sin haberse ejecutado; (3) el usuario menciona: conector de extensión de navegador, integración de extensión Chrome, sin API, raspar desde la sesión iniciada, service worker MV3, script de contenido en el mundo MAIN, interceptar fetch/XHR, reproducir encabezados de auth, búfer offline, PIN de emparejamiento, "sincronizar reservas de <site>", "publicar en <site> sin una API". Entrega un runtime compilado y probado (tap, relay, worker, queue, pairing, diagnostics) y una interfaz de adaptador neutral para el proveedor; los endpoints de la aplicación host están definidos en un contrato documentado. Chrome MV3; independiente del host. No es un adaptador por servicio; esos son habilidades separadas.
