Construisez une extension Chrome MV3 qui agit sur un service web externe sans (ou avec une API publique limitée) depuis la session connectée de l'utilisateur, en observant le trafic JSON du site, en rejouant ses en‑têtes d’authentification pour les lectures et écritures, en tamponnant hors ligne, et en synchronisant avec une application hôte via un point de terminaison sondé qui transporte les enregistrements vers le haut et les commandes vers le bas. Utilisez‑la quand : (1) un produit a besoin de données provenant d’un site tiers qui n’offre aucune API, aucun OAuth et aucune exportation, et le scraping côté serveur avec le mot de passe de l’utilisateur est exclu, (2) un connecteur d’extension existant nécessite un durcissement : un service worker qui meurt, une alarme qui ne se déclenche jamais, un script de contenu livré mort, des enregistrements qui disparaissent, des commandes marquées comme échouées sans avoir été exécutées, (3) l’utilisateur mentionne : connecteur d’extension de navigateur, intégration d’extension Chrome, pas d’API, scraping depuis la session connectée, service worker MV3, script de contenu MONDE principal, intercepter fetch/XHR, rejouer les en‑têtes d’authentification, tampon hors ligne, appairage PIN, « synchroniser les réservations depuis <site> », « publier sur <site> sans API ». Livrez un runtime compilé et testé (tap, relay, worker, queue, pairing, diagnostics) ainsi qu’une interface adaptateur neutre vis‑à‑vis du fournisseur ; les points de terminaison de l’application hôte sont un contrat documenté. Chrome MV3 ; agnostique vis‑à‑vis de l’hôte. Pas d’adaptateur par service ; ceux‑ci sont des compétences séparées.
