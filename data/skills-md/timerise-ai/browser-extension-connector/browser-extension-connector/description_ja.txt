Chrome MV3 拡張機能を構築し、ユーザーがサインインしたブラウザセッション内から、公開 API がない（または制限された）外部ウェブサービスに作用させます。サイトの JSON トラフィックを観測し、取得や書き込みの際に認証ヘッダーを再生し、オフライン時にバッファリングし、レコードを送信しコマンドを受信する単一のポーリングエンドポイントを介してホストアプリと同期します。利用シーンは次の通りです。(1) 製品が API も OAuth もエクスポートも提供しないサードパーティサイトからデータ取得や操作を行う必要があり、ユーザーのパスワードを用いたサーバー側スクレイピングが不可能な場合、(2) 既存のコネクタ拡張がハード化を要するケース：サービスワーカーが停止する、アラームが発火しない、コンテンツスクリプトが機能しない、レコードが失踪する、実行されていないのに失敗とマークされたコマンドがある、(3) ユーザーが以下のように述べている場合：ブラウザ拡張コネクタ、Chrome 拡張統合、API なし、ログインセッションからのスクレイピング、MV3 サービスワーカー、コンテンツスクリプトの MAIN ワールド、fetch/XHR をタップ、認証ヘッダーを再生、オフラインバッファ、ペアリング PIN、“<サイト> から予約を同期”、 “API なしで <サイト> に公開”。コンパイル済みでテスト済みのランタイム（tap、relay、worker、queue、pairing、diagnostics）とベンダーニュートラルなアダプターシームを提供し、ホストアプリのエンドポイントは文書化された契約です。Chrome MV3、ホスト非依存。サービスごとのアダプターではなく、上位の別スキルとして扱います。
