Crea un’estensione Chrome MV3 che opera su un servizio web esterno senza (o con una API pubblica limitata) dall’interno della sessione del browser dell’utente autenticato, osservando il traffico JSON del sito, riproducendo i suoi header di autenticazione per letture e scritture, bufferizzando offline e sincronizzando con un’app host attraverso un unico endpoint sondato che trasporta i record in upload e i comandi in download. Usala quando: (1) un prodotto necessita di dati da, o azioni su, un sito di terze parti che non offre API, né OAuth né esportazione, e lo scraping lato server con la password dell’utente è fuori discussione; (2) un’estensione connettore esistente ha bisogno di robustezza: un service worker che muore, un alarm che non parte mai, uno script di contenuto distribuito rotto, record che scompaiono, comandi contrassegnati come falliti senza essere eseguiti; (3) l’utente menziona: connettore per estensione del browser, integrazione estensione Chrome, nessuna API, scraping dalla sessione autenticata, service worker MV3, content script mondo MAIN, intercettare fetch/XHR, riprodurre gli header di autenticazione, buffer offline, abbinamento PIN, “sincronizza prenotazioni da <sito>”, “pubblica su <sito> senza API”. Fornisce un runtime compilato e testato (tap, relay, worker, queue, pairing, diagnostics) e una giunzione adattatore neutra rispetto al fornitore; gli endpoint dell’app host sono un contratto documentato. Chrome MV3; host‑agnostic. Non è un adattatore per servizio specifico; quelli sono competenze separate sopra.
