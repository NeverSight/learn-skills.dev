Build a Chrome MV3 extension that acts on an external web service with no (or a limited) public API from inside the user's own signed-in browser session, observing the site's JSON traffic, replaying its auth headers for pulls and writes, buffering offline, and syncing with a host app through one polled endpoint that carries records up and commands down. Ships a compiled, tested runtime (tap, relay, worker, queue, pairing, diagnostics) and a vendor-neutral adapter seam; the host app's endpoints are a documented contract. Chrome MV3; host-agnostic. Not a per-service adapter; those are separate skills on top.
