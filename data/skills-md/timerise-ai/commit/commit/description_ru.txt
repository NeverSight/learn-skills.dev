Преобразуйте изменения в рабочем дереве git в чистые Conventional Commits: прочитайте diff, запустите собственную проверку репозитория, проиндексируйте по пути, разделите несвязанные изменения на отдельные коммиты, напишите сообщение и проверьте, что попало. Используйте, когда: (1) пользователь хочет выполнить коммит, сохранить прогресс, зафиксировать WIP или завершить задачу, (2) рабочее дерево содержит несвязанные изменения, которые должны стать отдельными коммитами, (3) изменение ломает существующее использование и инструменты релиза должны это увидеть, (4) пользователь упоминает: commit, commit this, commit my changes, save progress, WIP commit, conventional commit, commit message, git add, staged, untracked, BREAKING CHANGE, feat!, Co‑Authored‑By, pre‑commit hook, «split this into commits». Содержит правила индексации, исключающие секреты и артефакты сборки, маркеры breaking‑change, которые `bumpv` читает для выбора МАЖОРного релиза, правила хуков и amend, а также post‑commit‑проверку, что не попал атрибуционный трейлер. Любой git‑репозиторий и любой стек; собственная проверка репозитория и документированные конвенции — это стыковка. Не является инструментом релиза, не пишет changelog и не участвует в процессе push или pull‑request.
