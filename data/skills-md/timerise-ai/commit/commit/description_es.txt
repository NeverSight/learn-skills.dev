Convierte los cambios en un árbol de trabajo de git en commits limpios siguiendo Conventional Commits: lee el diff, ejecuta la propia verificación del repositorio, añade al staging por ruta, separa los cambios no relacionados en commits distintos, escribe el mensaje y verifica lo que quedó. Úsalo cuando: (1) el usuario quiere hacer commit, guardar progreso, registrar WIP o cerrar una tarea terminada, (2) un árbol de trabajo mezcla cambios no relacionados que deberían convertirse en commits separados, (3) un cambio rompe el uso existente y la herramienta de lanzamiento debe detectarlo, (4) el usuario menciona: commit, commit this, commit my changes, save progress, WIP commit, conventional commit, commit message, git add, staged, untracked, BREAKING CHANGE, feat!, Co‑Authored‑By, pre‑commit hook, "split this into commits". Lleva las reglas de staging que excluyen secretos y artefactos de compilación, los marcadores de breaking‑change que `bumpv` lee para elegir una versión MAJOR, las reglas de hook y enmienda, y una verificación post‑commit de que no se haya incluido ningún trailer de atribución. Cualquier repositorio git y cualquier pila; la propia verificación del repositorio y las convenciones documentadas son la unión. No es una herramienta de lanzamiento, ni un generador de changelog, ni un flujo de push o pull request.
