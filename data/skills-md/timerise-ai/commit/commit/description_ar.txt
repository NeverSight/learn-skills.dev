حوّل التغييرات في شجرة عمل Git إلى التزامات Conventional Commit نظيفة: اقرأ الفرق، شغّل الفحص الخاص بالمستودع، حضّر حسب المسار، افصل التغييرات غير المرتبطة إلى التزامات منفصلة، اكتب الرسالة، وتحقق مما تم إدراجه. استخدم ذلك عندما: (1) يرغب المستخدم في الالتزام، حفظ التقدم، تسجيل WIP أو إكمال مهمة منتهية، (2) شجرة العمل تمزج تغييرات غير مرتبطة يجب أن تصبح التزامات منفصلة، (3) يسبب التغيير كسرًا في الاستخدام الحالي ويجب على أدوات الإصدار رؤيته، (4) يذكر المستخدم: commit، commit this، commit my changes، save progress، WIP commit، conventional commit، commit message، git add، staged، untracked، BREAKING CHANGE، feat!، Co‑Authored‑By، pre‑commit hook، "split this into commits". تتضمن قواعد التحضير التي تُبقي الأسرار ومخرجات البناء خارج الشجرة، وعلامات كسر التغيّر التي يقرأها `bumpv` لاختيار إصدار MAJOR، وقواعد الخطاف (hook) والتعديل، وفحص ما بعد الالتزام للتأكد من عدم وجود ترايل إسناد. أي مستودع Git وأي مجموعة؛ الفحص الخاص بالمستودع والعادات الموثقة هو الفاصل. ليس أداة إصدار، ولا كاتب سجل تغييرات، ولا تدفق دفع أو طلب سحب.
