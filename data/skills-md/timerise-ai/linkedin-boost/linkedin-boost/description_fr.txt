Rédigez un playbook pour booster un seul post de page d'entreprise LinkedIn qui fait la promotion d’un article de blog : ce qu’un boost permet d’obtenir et ce qu’il ne peut pas faire, un budget à vie proportionnel à la durée, l’image, le texte du post et le premier commentaire contenant le lien, les 90 premières minutes, les reposts du fondateur et les messages directs vers le réseau, la construction dans le Campaign Manager d’une campagne d’engagement autour d’un post existant, une checklist de pré‑lancement où chaque élément est attribué à une personne nommée, des règles de décision hebdomadaires, et la ligne de résultats de fin de mois.  

Utilisez ce playbook lorsque :  
1️⃣ un post de page d’entreprise avec le lien dans le premier commentaire doit bénéficier d’une portée payante,  
2️⃣ un playbook de campagne de post existe déjà et le boost est le test initial le moins coûteux,  
3️⃣ la date de publication change et le boost, les reposts et les messages directs doivent être décalés en conséquence,  
4️⃣ l’utilisateur mentionne : boost, boost this post, boosted post, sponsor the company page post, engagement campaign, link in the first comment, founder repost, repost with your thoughts, DM to our network, **BOOST-01**, **utm_content=boost-01**, « who owns this task », « move the post to tomorrow ».  

Le playbook doit exposer le compromis avec une campagne de visites de site web, détailler les étapes de création que le bouton Boost masque, gérer la cascade de dates, et appliquer la règle selon laquelle aucune tâche ne doit rester sans responsable.  

Le chemin vers le fichier Markdown de l’article de blog est un argument obligatoire ; le script s’arrête s’il n’est pas fourni.  

Ce document est rédigé pour un site marketing basé sur Next.js App Router dont les posts sont stockés au format Markdown dans le dépôt ; les personnes du host, le vocabulaire de conversion, les langues et le dossier des runbooks constituent le point d’attache.  

**LinkedIn uniquement.** Pas de campagne de visites de site web (ad-campaign-runbook), pas de rédacteur de post pour profil personnel, pas de client API publicitaire.
