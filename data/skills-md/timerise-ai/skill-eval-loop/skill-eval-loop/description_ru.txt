Укрепить навык агента на основе его автоматических оценок: оценить каждый запуск оценки по фиксированному критерию точности, читаемому из журнала самого агента, исправить навык по коренной причине каждого отклонения, выпустить патч, позволить выпущенному патчу повторно запустить оценки и повторять процесс, пока каждый агент не получит полный балл. Применять, когда: (1) все оценки навыка «проходят», но агенты всё равно патчируют его шаблоны, переписывают тесты, расширяют значения по умолчанию или пропускают передачу, (2) у навыка есть workflow оценки, который запускает Claude Code, Codex и Gemini при каждом опубликованном релизе, (3) пользователь упоминает: исправить навык на основе оценок, цикл оценок, итерация до полного балла, оценка запусков, критерий, отклонения агента, «на основе последних оценок исправить навык», «цикл до полного балла», «большинство 2 к 1». Включает критерий, чтители журналов для трёх агентов, таблицу коренных причин отклонений, рецепт релиза и правило остановки. Репозитории навыков с CHANGELOG, помеченными релизами и папкой `evals/`; GitHub Actions и CLI gh. Не предназначено для написания нового навыка и не предназначено для изменения тестовой оболочки.
