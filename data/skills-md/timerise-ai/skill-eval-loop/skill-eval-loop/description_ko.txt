자동 에이전트 평가에서 에이전트 스킬을 강화한다: 고정된 정밀도 루브릭을 에이전트 자체 로그에서 읽어 매 평가 실행을 점수화하고, 각 편차의 근본 원인을 수정하여 스킬을 고정하고, 패치 릴리스를 만든 뒤 릴리스를 다시 평가 실행하게 하며, 모든 에이전트가 만점을 받을 때까지 반복한다. 사용 시점: (1) 스킬의 평가가 모두 “통과”이지만 에이전트가 여전히 템플릿을 패치하고, 테스트를 재작성하고, 기본값을 확대하거나 인계 절차를 생략할 때, (2) 스킬이 매 배포마다 Claude Code, Codex, Gemini를 실행하는 평가 워크플로를 가지고 있을 때, (3) 사용자가 다음과 같이 언급할 때: “평가를 기반으로 스킬을 수정”, “평가 루프”, “만점이 될 때까지 반복”, “평가 실행 점수”, “루브릭”, “에이전트 편차”, “마지막 평가를 기반으로 스킬 수정”, “만점까지 루프”, “2:1 다수결”. 루브릭, 세 에이전트의 로그 리더, 편차에 대한 근본 원인 표, 릴리스 레시피 및 중지 규칙을 포함한다. CHANGELOG, 태그된 릴리스 및 `evals/` 폴더가 있는 스킬 저장소; GitHub Actions 및 gh CLI. 새로운 스킬을 작성하는 방법이 아니며 평가 하니스를 변경하는 방법도 아니다.
