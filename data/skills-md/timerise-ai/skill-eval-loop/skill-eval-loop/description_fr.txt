Durcir une compétence d'agent à partir de ses évaluations automatiques : noter chaque exécution d'évaluation par rapport à une grille de fidélité fixe lue dans le journal de l'agent, corriger la compétence à la cause première de chaque déviation, créer une version correctrice, laisser la version relancer les évaluations, et répéter jusqu'à ce que chaque agent obtienne le score complet. Utiliser lorsque : (1) les évaluations d'une compétence sont toutes « pass » mais les agents modifient encore ses modèles, réécrivent ses tests, élargissent ses valeurs par défaut ou contournent son transfert, (2) une compétence possède un flux de travail d'évaluation qui exécute Claude Code, Codex et Gemini à chaque version publiée, (3) l'utilisateur mentionne : corriger la compétence sur la base des évaluations, boucle d'évaluation, itérer jusqu'au score complet, noter les exécutions d'évaluation, grille, déviations d'agent, « based on last evals fix skill », « loop to full score », « 2:1 majority ». Transporte la grille, les lecteurs de journal pour trois agents, un tableau des causes premières des déviations, la recette de version et la règle d'arrêt. Dépôts de compétences avec un CHANGELOG, des versions balisées et un dossier `evals/` ; GitHub Actions et l'interface gh CLI. Ce n'est pas un moyen d'écrire une nouvelle compétence et pas un moyen de modifier le harnais d'évaluation.
