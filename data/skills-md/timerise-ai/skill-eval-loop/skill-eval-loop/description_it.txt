Rinforza una Skill di Agente dalle sue valutazioni automatiche: assegna un punteggio a ogni esecuzione di valutazione confrontandola con una rubrica di fedeltà fissa letta dal log dell'agente stesso, correggi la skill alla radice di ogni deviazione, crea una release patch, lascia che la release riesegua le valutazioni e ripeti finché ogni agente ottiene il punteggio massimo. Usa quando: (1) le valutazioni di una skill sono tutte "pass" ma gli agenti continuano a modificare i suoi template, riscrivere i suoi test, ampliare i suoi valori predefiniti o saltare il suo handover, (2) una skill ha un workflow di valutazione che esegue Claude Code, Codex e Gemini su ogni release pubblicata, (3) l'utente menziona: correggi la skill basandoti sulle valutazioni, ciclo di valutazione, itera finché non raggiungi il punteggio pieno, punteggia le esecuzioni di valutazione, rubrica, deviazioni dell'agente, "basato sulle ultime valutazioni correggi la skill", "ciclo fino al punteggio pieno", "maggioranza 2:1". Include la rubrica, i lettori di log per tre agenti, una tabella di causa radice per le deviazioni, la ricetta della release e la regola di arresto. Repository di skill con un CHANGELOG, release taggate e una cartella `evals/`; GitHub Actions e la CLI gh. Non è un modo per scrivere una nuova skill e non è un modo per modificare l'harness di valutazione.
