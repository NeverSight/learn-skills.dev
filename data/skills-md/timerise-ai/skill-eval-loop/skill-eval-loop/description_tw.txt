加固一個代理技能以應對其自動代理評估：根據從代理自身日誌中讀取的固定忠實度評分標準，對每一次評估執行進行打分，針對每個偏差的根本原因修正技能，製作補丁發布，讓該發布重新執行評估，並重複此過程直至每個代理都取得滿分。使用時機：（1）技能的所有評估都顯示「通過」，但代理仍會修改其範本、重寫測試、擴大預設或跳過交接；（2）技能有一個評估工作流程，在每次發布時執行 Claude Code、Codex 與 Gemini；（3）使用者提到：根據評估修正技能、評估迴圈、迭代直至滿分、對評估執行打分、評分標準、代理偏差、「根據上一次評估修正技能」、「迴圈至滿分」、「2:1 多數」等。包含評分標準、三個代理的日誌讀取器、偏差根因表、發布配方與停止規則。技能儲存庫須有 CHANGELOG、標記式發布與 `evals/` 資料夾；使用 GitHub Actions 與 gh CLI。這不是用來編寫新技能的方式，也不是用來更改評估框架的方式。
