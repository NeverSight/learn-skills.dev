Ein Agenten‑Skill aus seinen automatischen Agent‑Bewertungen härten: Jede Bewertungsdurchführung gegen ein festes Treue‑Rubrik bewerten, das aus dem eigenen Log des Agenten gelesen wird, den Skill an der Grundursache jeder Abweichung korrigieren, ein Patch‑Release erstellen, das Release die Bewertungen neu ausführen lassen und wiederholen, bis jeder Agent die volle Punktzahl erreicht. Anwendung: (1) Die Bewertungen eines Skills ergeben alle „Pass“, aber Agenten patchen trotzdem seine Vorlagen, schreiben seine Tests neu, erweitern seine Vorgaben oder überspringen die Übergabe, (2) ein Skill hat einen Bewertungs‑Workflow, der Claude Code, Codex und Gemini bei jedem veröffentlichten Release ausführt, (3) der Nutzer erwähnt: Skill basierend auf Bewertungen korrigieren, Bewertungs‑Schleife, iterieren bis volle Punktzahl, Bewertungen bewerten, Rubrik, Agenten‑Abweichungen, „basierend auf letzten Bewertungen Skill fixen“, „Schleife bis volle Punktzahl“, „2:1‑Mehrheit“. Enthält die Rubrik, die Log‑Reader für drei Agenten, eine Ursachen‑Tabelle für Abweichungen, das Release‑Rezept und die Stop‑Regel. Skill‑Repositories mit einem CHANGELOG, markierten Releases und einem `evals/`‑Ordner; GitHub Actions und das gh‑CLI. Kein Weg, einen neuen Skill zu schreiben und kein Weg, das Bewertungs‑Framework zu ändern.
