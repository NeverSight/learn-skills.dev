تقوية مهارة الوكيل من خلال تقييماته التلقائية: احسب درجة كل تشغيل للتقييم مقابل مقياس ثابت للموثوقية يُقرأ من سجل الوكيل نفسه، أصلح المهارة عند السبب الجذري لكل انحراف، أطلق نسخة تصحيحية، دع النسخة تُعيد تشغيل التقييمات، وكرر العملية حتى يحصل كل وكيل على الدرجة الكاملة. استخدم ذلك عندما: (1) جميع تقييمات المهارة "ناجحة" لكن الوكلاء ما زالوا يحدّثون قوالبها، يعيدون كتابة اختباراتهم، يوسّعون الإعدادات الافتراضية أو يتخطون عملية التسليم، (2) للمهارة سير عمل تقييم يشغّل Claude Code وCodex وGemini في كل نسخة منشورة، (3) يذكر المستخدم: "أصلح المهارة بناءً على التقييمات"، "حلقة التقييم"، "كرر حتى الدرجة الكاملة"، "احسب تشغيلات التقييم"، "المقياس"، "انحرافات الوكيل"، "استناداً إلى آخر تقييمات أصلح المهارة"، "حلقة حتى الدرجة الكاملة"، "أغلبية 2:1". يتضمن المقياس، قوارئ السجلات لثلاثة وكلاء، جدول السبب الجذري للانحرافات، وصفة الإصدار وقاعدة الإيقاف. مستودعات المهارات تحتوي على CHANGELOG وإصدارات معنونة ومجلد `evals/`؛ GitHub Actions وواجهة gh CLI. ليست طريقة لكتابة مهارة جديدة ولا طريقة لتغيير هيكل التقييم.
