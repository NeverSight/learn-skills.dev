记录谁在何时、从何处、使用何种设备打开了什么，在 Next.js App Router 应用的服务器端：为每一次真实的共享资源页面访问以及生命周期事件（请求登录链接、创建账户、登录成功）记录 IP、边缘地理位置以及解析后的浏览器指纹，存储于 Postgres/Supabase 或 Firestore，按会话分组，并提供首次打开公告和管理员历史面板。使用场景：  
1️⃣ 销售、客服或所有者需要了解是否以及何时有人打开演示、提案、报价、报告或共享链接；  
2️⃣ 注册时需要获取“来自哪个位置和设备”信息；  
3️⃣ 用户常提到的关键词：访问日志、访客跟踪、将访问记录写入数据库、地理位置头信息（x-vercel-ip-city、x-forwarded-for、cf-ipcountry）、User‑Agent 解析、userAgent()、isBot、设备类型、“谁打开了链接”、"客户打开了演示" 的 Slack 提示、访问历史、最后一次在线、注册地点。  

功能包括：过滤掉预取和 Server Actions 的页面访问、对框架默认列表遗漏的机器人进行检测、NULL 安全的重复访客匹配、针对单个访客的公告限速、忠实截断的摘要以及 Supabase 的首次登录陷阱。适用于在 Vercel 或 Cloudflare 上运行的 Next.js App Router；存储层是可插拔的。**不是产品分析、不是客户端追踪、也不是同意管理器。**
