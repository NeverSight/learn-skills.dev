記錄誰在什麼時候、從哪裡、使用什麼裝置開啟了什麼內容，於 Next.js App Router 應用的伺服器端：對每一次真實的共享資源頁面檢視以及生命周期事件（請求登入連結、帳號建立、登入）捕捉 IP、邊緣地理位置與解析過的瀏覽器指紋，並存入 Postgres/Supabase 或 Firestore，依會話分組，提供首次開啟公告與管理員歷史面板。使用情境：  
1️⃣ 銷售、成功團隊或所有者需得知是否以及何時有人開啟了示範、提案、報價、報告或共享連結；  
2️⃣ 註冊時需取得「從哪裡註冊」的地點與裝置資訊；  
3️⃣ 使用者提及：訪問日誌、訪客追蹤、將訪問寫入資料庫、地理位置標頭（x‑vercel‑ip‑city、x‑forwarded‑for、cf‑ipcountry）、User‑Agent 解析、userAgent()、isBot、裝置類型、"誰開啟了連結"、"客戶開啟了示範" Slack 通知、訪問歷史、最後一次出現、註冊地點。  

具備過濾實際頁面檢視的功能，會排除預取 (prefetch) 與 Server Actions，提供框架列表未捕捉的機器人偵測、NULL 安全的重複訪客匹配、每位訪客的公告節流、誠實的截斷摘要，以及 Supabase 首次登入陷阱。適用於 Vercel 或 Cloudflare 上的 Next.js App Router；資料存取層為可插拔介面。這不是產品分析、不是客戶端追蹤、也不是同意管理器。
