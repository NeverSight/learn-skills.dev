为场馆构建自助触摸屏预订终端：一步步的现场办理流程，从服务、日期和时间段，经过站点和参与者姓名、设备和耗材，直至摘要和确认；配备屏幕键盘、无操作自动重置、柜台付款或二维码付款、实时可用性刷新以及查找并编辑预订的流程。适用场景：（1）场馆（健身房、卡丁车、保龄球、攀岩、密室逃脱、诊所）需要无人值守的预订终端；（2）已有在线预订功能的应用需要 kiosk 模式；（3）现有终端需要依据硬性规则进行审计；（4）用户提及：kiosk mode、self-service kiosk、touch screen booking、walk-up terminal、on-screen keyboard、inputMode none、inactivity reset、counter payment、PENDING_COUNTER_PAYMENT、x-kiosk-api-key、SET_SLOT、REFRESH_SLOT、PROMO_INVALID、stock lock。携带会话 reducer 及其 14 条测试套件、屏幕合约和字典键树、具备防护表的服务器定价幂等 API 合约，在每条失败路径上释放库存锁，并支持针对局域网服务器的离线容错。使用 Next.js App Router 与 React context；KioskBackend 接口是对接点，预订存储、支付提供商和实时通道由宿主提供。不是员工 POS，不是数字标牌，也不是本地备用服务器本身。
