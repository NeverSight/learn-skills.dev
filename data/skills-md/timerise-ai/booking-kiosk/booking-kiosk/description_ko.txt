장소용 셀프서비스 터치스크린 예약 키오스크 구축: 서비스, 날짜·시간 슬롯 → 스테이션·참가자 이름 → 장비·소모품 → 요약·확인 순으로 단계적인 워크업 흐름을 제공하고, 화면 내 키보드, 비활성 자동 초기화, 카운터 결제 또는 QR 결제, 실시간 가용성 새로고침 및 예약 찾기·편집 흐름을 포함합니다. 사용 사례: (1) 체육관, 카트 레이싱, 볼링, 클라이밍, 탈출 방, 클리닉 등에서 무인 예약 단말이 필요할 때, (2) 이미 온라인 예약 기능이 있는 앱에 키오스크 모드가 필요할 때, (3) 기존 키오스크가 엄격한 규칙에 따라 감사를 받아야 할 때, (4) 사용자가 “키오스크 모드”, “셀프서비스 키오스크”, “터치스크린 예약”, “워크업 터미널”, “스크린 키보드”, “inputMode none”, “비활성 초기화”, “카운터 결제”, “PENDING_COUNTER_PAYMENT”, “x-kiosk-api-key”, “SET_SLOT”, “REFRESH_SLOT”, “PROMO_INVALID”, “stock lock” 등을 언급할 때. 세션 리듀서를 14개의 테스트 스위트와 화면 계약, 딕셔너리 키 트리와 함께 제공하며, 가드 테이블이 포함된 서버‑가격 아이디멀턴트 API 계약, 실패 경로마다 해제되는 재고 잠금, LAN 서버에 대한 오프라인 장애 복구를 지원합니다. Next.js App Router와 React 컨텍스트 사용; KioskBackend 인터페이스가 접점(seam)이며, 예약 스토어, 결제 제공자, 실시간 채널은 호스트가 제공합니다. 직원 POS가 아니며, 디지털 사이니지도 아니고, 온프레미스 백업 서버 자체도 아닙니다.
