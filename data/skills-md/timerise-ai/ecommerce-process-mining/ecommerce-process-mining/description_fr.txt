Construisez un processus de mining des employés pour le back‑office d’un e‑commerce : une extension de navigateur consentie Manifest V3 qui capture les événements DOM plutôt que les pixels depuis les outils d’administration déjà utilisés par le personnel (administrateur boutique, panneaux vendeur marketplace, portails transporteurs, helpdesk, WMS, ERP), plus un formulaire de capture des lacunes pour le travail qu’un navigateur ne peut pas voir, alimentant une chaîne d’IA qui rédige des SOP par rôle et classe les candidats à l’automatisation. Utilisez‑le lorsque : (1) vous documentez comment le travail de commande, de retour, de mise en ligne, de fournisseur et de support est réellement effectué, pour l’onboarding, l’audit ou le cadrage de l’automatisation, (2) vous construisez ou auditez une extension de capture d’activité des employés, son modèle de consentement, son nettoyage des données personnelles (PII), ou son flux de connexion PKCE, (3) l’utilisateur mentionne : process mining, task mining, génération de SOP, « documenter ce que les employés font », capture de routine, capture par extension de navigateur, capture d’événements DOM, MutationObserver, captureVisibleTab, chrome.identity launchWebAuthFlow, bascule de consentement, domaines exclus, nettoyeur PII, dom_confidence, hachage perceptuel, comité d’entreprise, RGPD art. 88. Elle intègre un nettoyeur qui distingue une carte d’un code EAN, un filtre d’exclusion partagé entre l’extension et le serveur, un échange atomique de code à usage unique, un registre de consentement en mode ajout‑seulement, et des statistiques d’inscription agrégées uniquement, chacun maintenu par les tests et les vérifications SQL fournies. Orientée Next.js App Router et PostgreSQL ; le backend est une couture. Ce n’est pas de l’analyse produit, ni du replay de session, ni de l’enregistrement d’écran, ni du minage de journaux d’événements provenant des tables ERP.
