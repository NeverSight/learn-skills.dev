在 Next.js App Router 应用中构建基于 Markdown 的帮助中心：使用前置元数据文章的分类文件夹，静态渲染主页、分类页、标签页和文章页，客户端搜索支持排序和键盘导航，具备区域感知路由并使用默认语言回退，标签采用 slug 作为标识并提供每个标签的页面，关联文章，面包屑，JSON-LD 和站点地图条目，以及用于 CI 的内容验证器。适用场景：(1) 从仓库中的 Markdown 文件构建或扩展帮助中心、知识库、文档区、支持文章或 FAQ 中心；(2) 添加文章搜索、标签页或标签芯片、带回退的翻译文章、hreflang / canonical 规则、关联链接或可折叠的文章侧边栏；(3) 用户提到的关键词：帮助中心、知识库、文档站点、支持文章、Markdown 内容、frontmatter、gray-matter、content/help、validate:help、标签、文章搜索、hreflang、i18n 内容、“help articles”。配备加载器和 CI 验证器，若文章不可访问或格式错误则构建失败，搜索容忍尾随空格、标点和变音符号，标签按 slug 分组，使所有拼写变体指向同一页面。Next.js App Router；内容来源通过一个 getHelpIndex(locale) 接口抽象，可由 CMS 替换文件系统。不是博客技能，也不是 CMS 集成，更不是从代码生成的文档。
