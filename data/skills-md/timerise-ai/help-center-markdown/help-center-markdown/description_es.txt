Construye un centro de ayuda respaldado por markdown en una aplicación Next.js App Router: carpetas de categorías con artículos frontmatter, páginas de aterrizaje, categoría, etiqueta y artículo renderizadas estáticamente, búsqueda del lado del cliente con ranking y navegación con teclado, enrutamiento sensible a la localización con fallback al locale predeterminado, etiquetas con identidad slug y páginas por etiqueta, artículos relacionados, migas de pan, entradas JSON‑LD y sitemap, además de un validador de contenido para CI. Úsalo cuando: (1) construyas o amplíes un centro de ayuda, base de conocimiento, sección de documentación, artículos de soporte o hub de FAQ a partir de archivos markdown en el repositorio, (2) añadas búsqueda de artículos, páginas de etiquetas o chips de etiquetas, artículos traducidos con fallback, reglas hreflang/canonical, enlaces relacionados, o una barra lateral de artículos colapsable, (3) el usuario mencione: centro de ayuda, base de conocimiento, sitio de docs, artículos de soporte, contenido markdown, frontmatter, gray‑matter, content/help, validate:help, etiquetas, búsqueda de artículos, hreflang, contenido i18n, “help articles”. Incluye un cargador con un validador CI que haga fallar la compilación ante artículos inaccesibles o malformados, búsqueda que tolera espacios finales, puntuación y diacríticos, y etiquetas agrupadas por slug de modo que cada variante ortográfica llegue a una única página. Next.js App Router; la fuente de contenido es un punto de inserción detrás de una única getHelpIndex(locale), de modo que un CMS pueda reemplazar el sistema de archivos. No es una habilidad de blog, no es una integración CMS y no es documentación generada a partir de código.
