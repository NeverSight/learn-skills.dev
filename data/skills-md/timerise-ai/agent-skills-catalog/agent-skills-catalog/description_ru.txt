Создайте публичный каталог Agent Skills в сайте на Next.js App Router, генерируемый во время сборки из файлов каждого репозитория навыка: скрипт синхронизации, который зеркалирует SKILL.md, README.md, CHANGELOG.md, provenance.md и каталог evals/ в репозиторий; загрузчик, читающий правила, выпуски и реестр provenance из этих файлов; страницу каталога с поиском и фильтром по категориям, отдельную страницу для каждой категории и каждого навыка, результаты оценок агентов (самый новый запуск для каждого агента и подсказки, включая проваленные запуски), JSON‑LD, элементы карты сайта и валидатор содержимого. Используйте, когда: (1) сайт должен перечислять Agent Skills, публикуемые организацией на GitHub, с командами установки, правилами, версиями и результатами оценок агентов; (2) страницы навыков показывают старую версию после релиза, либо запуск оценки никогда не появляется на странице; (3) необходимо добавить результаты оценок агентов, подсказки или реестр provenance к уже существующим страницам навыков; (4) пользователь упоминает: skills catalog, Agent Skills page, skill directory, SKILL.md, skills.sh, npx skills add, evals/prompts.md, eval results, agent evals, Claude Code, Codex CLI, Gemini CLI, skills:sync, sync.json, raw.githubusercontent.com, provenance.md, CHANGELOG.md, Keep a Changelog, TechArticle, SoftwareSourceCode. Включает синхронизацию, которая читает каждый файл навыка в одном коммите и полностью заменяет зеркальную копию, загрузчик, который никогда не делает запросов, парсер оценок, который отклоняет malformed‑запуск с указанием причины вместо просто игнорировать его, и валидатор, который проваливает тесты при обнаружении ошибок. Next.js App Router; источник навыков — это точка стыка (GitHub или локальные чек-ауты), а макет раздела, который он читает, представляет собой одну таблицу. Это не способ писать навык, не runner оценок и не регистр пакетов.
