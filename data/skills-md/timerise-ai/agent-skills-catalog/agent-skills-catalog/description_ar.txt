ابنِ كاتالوجًا عامًا لمهارات الوكيل (Agent Skills) في موقع يستخدم Next.js App Router، يتم إنشاؤه وقت البناء من ملفات كل مستودع مهارة بنفسه: برنامج مزامنة يطابق SKILL.md وREADME.md وCHANGELOG.md وprovenance.md ومجلد evals/ داخل المستودع، أداة تحميل تقرأ القواعد والإصدارات وسجل الأصل (provenance ledger) منها، صفحة كاتالوج تحتوي على بحث وتصفية حسب الفئة، صفحة واحدة لكل فئة ولكل مهارة، نتائج تقييم الوكيل (أحدث تشغيل لكل وكيل ومطالبة، شاملًا التشغيلات الفاشلة)، JSON‑LD، إدخالات خريطة الموقع (sitemap) ومحقق محتوى. استخدم عندما: (1) يجب على الموقع سرد مهارات الوكيل التي تنشرها مؤسسة على GitHub، مع أوامر التثبيت والقواعد والإصدارات ونتائج تقييم الوكيل، (2) تظهر صفحات المهارة نسخة قديمة بعد إصدار جديد، أو لا يظهر تشغيل تقييم على الإطلاق في الصفحة، (3) إضافة نتائج تقييم الوكيل أو المطالبات أو سجل الأصل إلى صفحات المهارات القائمة، (4) يذكر المستخدم: skills catalog، Agent Skills page، skill directory، SKILL.md، skills.sh، npx skills add، evals/prompts.md، eval results، agent evals، Claude Code، Codex CLI، Gemini CLI، skills:sync، sync.json، raw.githubusercontent.com، provenance.md، CHANGELOG.md، Keep a Changelog، TechArticle، SoftwareSourceCode. يحتوي على مزامنة تقرأ كل ملف من مهارة في التزام واحد وتستبدل المرآة بالكامل، أداة تحميل لا تجلب أي شيء، محلل تقييم يرفض تشغيلًا مشوهًا مع إظهار السبب بدلاً من حذفه، ومحقق يفشل الاختبارات بسببه. Next.js App Router؛ مصدر المهارات هو نقطة وصل (GitHub أو نسخ محلية) وتخطيط القسم الذي يقرؤه هو جدول واحد. ليس طريقة لكتابة مهارة، ولا مُنفذ تقييم، ولا سجل حزم.
