Next.js App Router 사이트에서 빌드 시 각 스킬 저장소의 파일들을 기반으로 Agent Skills의 공개 카탈로그를 구축합니다. SKILL.md, README.md, CHANGELOG.md, provenance.md 및 evals/ 를 저장소에 복제하는 동기화 스크립트, 이 파일들에서 규칙·릴리스·프로베넌스 원장을 읽어오는 로더, 검색 및 카테고리 필터가 있는 카탈로그 페이지, 카테고리별·스킬별 페이지, 에이전트 평가 결과(에이전트와 프롬프트별 최신 실행, 실패한 실행 포함), JSON‑LD, 사이트맵 엔트리 및 콘텐츠 검증기 등을 포함합니다. 사용 사례: (1) 조직이 GitHub에 공개하는 Agent Skills를 설치 명령어·규칙·버전·에이전트 평가 결과와 함께 목록화해야 할 때, (2) 스킬 페이지가 릴리스 후에도 이전 버전을 보여주거나 평가 실행이 페이지에 나타나지 않을 때, (3) 기존 스킬 페이지에 에이전트 평가 결과·프롬프트·프로베넌스 원장을 추가해야 할 때, (4) 사용자가 “skills catalog”, “Agent Skills page”, “skill directory”, “SKILL.md”, “skills.sh”, “npx skills add”, “evals/prompts.md”, “eval results”, “agent evals”, “Claude Code”, “Codex CLI”, “Gemini CLI”, “skills:sync”, “sync.json”, “raw.githubusercontent.com”, “provenance.md”, “CHANGELOG.md”, “Keep a Changelog”, “TechArticle”, “SoftwareSourceCode” 등을 언급할 때. 전체 커밋에서 스킬의 모든 파일을 읽어 한 번에 전체 미러를 교체하는 동기화를 수행하고, 파일을 전혀 가져오지 않는 로더, malformed된 실행을 삭제하지 않고 이유와 함께 거부하는 평가 파서, 그리고 테스트를 실패시키는 검증기를 포함합니다. Next.js App Router; 스킬이 오는 곳은 GitHub 혹은 로컬 체크아웃이라는 시점(seam)이며, 섹션 레이아웃은 하나의 테이블 형태로 읽습니다. 스킬을 작성하는 방법도, 평가 실행기도, 패키지 레지스트리도 아닙니다.
