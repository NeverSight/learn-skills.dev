Next.js の App Router サイトでエージェントスキルの公開カタログを構築し、ビルド時に各スキルリポジトリのファイルから生成します。具体的には、SKILL.md、README.md、CHANGELOG.md、provenance.md、evals/ をリポジトリにミラーリングする sync スクリプト、そこからルール、リリース、プロヴァナンス台帳を読み取るローダー、検索とカテゴリフィルターを備えたカタログページ、カテゴリごとおよびスキルごとに 1 ページずつ、エージェントの評価結果（エージェントとプロンプトごとの最新実行、失敗した実行も含む）、JSON‑LD、サイトマップエントリ、コンテンツバリデーターを用意します。使用シーンは次のとおりです：(1) 組織が GitHub に公開しているエージェントスキルをインストールコマンド、ルール、バージョン、エージェント評価結果とともに一覧表示したい場合、(2) スキルページがリリース後に古いバージョンを表示したり、評価実行がページに現れない場合、(3) 既存のスキルページにエージェント評価結果、プロンプト、プロヴァナンス台帳を追加したい場合、(4) ユーザーが「skills catalog」「Agent Skills page」「skill directory」「SKILL.md」「skills.sh」「npx skills add」「evals/prompts.md」「eval results」「agent evals」「Claude Code」「Codex CLI」「Gemini CLI」「skills:sync」「sync.json」「raw.githubusercontent.com」「provenance.md」「CHANGELOG.md」「Keep a Changelog」「TechArticle」「SoftwareSourceCode」などを言及した場合。

このシステムは、スキルのすべてのファイルを 1 つのコミットで読み取り、ミラー全体を入れ替える sync を実行し、ファイル取得を行わないローダー、形式が不正な実行を削除せずに理由とともに拒否する評価パーサ、テストで失敗させるバリデーターを備えます。Next.js App Router を使用し、スキルの出所はシーム（GitHub またはローカルチェックアウト）で、読み取るセクションレイアウトは 1 つのテーブルです。スキルの書き方や評価ランナー、パッケージレジストリの提供は行いません。
