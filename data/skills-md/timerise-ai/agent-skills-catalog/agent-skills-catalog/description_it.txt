Crea un catalogo pubblico di Agent Skills in un sito Next.js App Router, generato al momento della build a partire dai file propri di ciascun repository di skill: uno script di sincronizzazione che replica SKILL.md, README.md, CHANGELOG.md, provenance.md e evals/ nel repository, un loader che legge regole, release e il registro di provenienza da essi, una pagina catalogo con ricerca e filtro per categoria, una pagina per categoria e per skill, i risultati delle valutazioni degli agenti (l'esecuzione più recente per agente e prompt, comprese le esecuzioni fallite), JSON‑LD, voci di sitemap e un validatore di contenuti. Da utilizzare quando: (1) un sito deve elencare le Agent Skills che un’organizzazione pubblica su GitHub, con comandi di installazione, regole, versioni e risultati delle valutazioni degli agenti, (2) le pagine delle skill mostrano una versione vecchia dopo una release, o un’esecuzione di valutazione non appare mai nella pagina, (3) si aggiungono risultati di valutazione degli agenti, prompt o un registro di provenienza a pagine di skill esistenti, (4) l’utente menziona: catalogo delle skill, pagina Agent Skills, directory delle skill, SKILL.md, skills.sh, npx skills add, evals/prompts.md, risultati della valutazione, valutazioni degli agenti, Claude Code, Codex CLI, Gemini CLI, skills:sync, sync.json, raw.githubusercontent.com, provenance.md, CHANGELOG.md, Keep a Changelog, TechArticle, SoftwareSourceCode. Include una sincronizzazione che legge ogni file di una skill in un commit e sostituisce l’intero mirror, un loader che non effettua mai fetch, un parser di valutazione che rifiuta un’esecuzione malformata con la relativa motivazione invece di scartarla, e un validatore che falla i test su di essa. Next.js App Router; da dove provengono le skill è un punto di integrazione (GitHub o checkout locali) e il layout della sezione che legge è una tabella. Non è un modo per scrivere una skill, né un runner di valutazione né un registro di pacchetti.
