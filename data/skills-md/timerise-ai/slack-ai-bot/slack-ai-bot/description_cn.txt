在 Next.js App Router 应用中使用 Chat SDK 和 AI SDK 构建双向 Slack AI 机器人：用户提及或私信机器人时，LLM 使用针对其应用账号范围的工具进行回答，应用自行向频道发布报告，风险较高的操作则放在 “批准/取消” 按钮后，点击事件会返回应用。适用场景：(1) 添加一个能够回答产品数据问题并为提问用户执行操作的 Slack 助手；(2) 应用必须向 Slack 推送消息并响应按钮点击（人机交互审批、草稿后发送）；(3) 审计已有的 Slack 机器人，发现其遗漏后续、重复回复或无法识别用户；(4) 用户提及的关键词包括：Slack bot、AI Slack assistant、two‑way Slack、@mention bot、app_mention、thread follow‑up、onSubscribedMessage、Slack interactivity、block_actions、Approve button、Block Kit 按钮、response_url、Slack OAuth install、users:read.email、x-slack-signature、“bot stops replying in threads”、“couldn't match your Slack account”、“operation timed out”（Slack 按钮超时）。该机器人实现了从 Slack 邮箱到应用用户的身份桥接、用户作用域的工具、能够抵御双击的单次审批、3 秒确认规则、无服务器状态捕获以及 Markdown 到 mrkdwn 的转换器，配有 31 条测试。可在 Vercel 或任何 Node 主机上运行 Next.js App Router；存储、认证、模型和领域工具均为可替换层。本文不是 Chat SDK API 参考，也不是 Slack 频道读取器。
