Next.js App Router アプリ内で Chat SDK と AI SDK を使用して、双方向 Slack AI ボットを構築する：ユーザーがボットにメンションまたは DM を送ると、LLM がそのユーザーのアプリアカウントにスコープされたツールで回答し、アプリは自動的にチャンネルにレポートを投稿し、リスクのある操作は「承認 / キャンセル」ボタンの背後に待たせ、クリックはアプリに返ってくる。使用シーン：① 製品データに関する質問に答え、質問者のためにアクションを実行する Slack アシスタントを追加したいとき、② アプリが Slack にメッセージをプッシュし、ボタンのクリックに応答する必要があるとき（ヒューマン・イン・ザ・ループ承認、下書き→送信）、③ フォローアップを逃したり二重に回答したり、ユーザーを特定できない既存の Slack ボットを監査したいとき、④ ユーザーが言及するキーワード：Slack bot、AI Slack assistant、two‑way Slack、@mention bot、app_mention、thread follow‑up、onSubscribedMessage、Slack interactivity、block_actions、承認ボタン、Block Kit ボタン、response_url、Slack OAuth install、users:read.email、x‑slack‑signature、「bot stops replying in threads」「couldn't match your Slack account」「operation timed out」などの Slack ボタン。Slack のメールアドレスとアプリユーザーを結ぶアイデンティティブリッジ、ユーザースコープのツール、二重クリックに耐える単一クレーム承認、3 秒の ACK ルール、サーバーレスのステートトラップ、Markdown から mrkdwn へのコンバータを備え、テストは 31 件。Next.js App Router は Vercel または任意の Node ホストで動作し、ストア、認証、モデル、ドメインツールはシームとして扱われる。Chat SDK の API 参照でも Slack チャンネルリーダーでもない。
