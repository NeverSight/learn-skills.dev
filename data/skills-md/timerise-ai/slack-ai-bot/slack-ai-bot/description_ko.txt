Chat SDK와 AI SDK를 활용해 Next.js App Router 애플리케이션 안에 양방향 Slack AI 봇을 구축합니다: 사용자가 봇을 멘션하거나 DM을 보내면 LLM이 해당 앱 계정에 스코프된 도구로 답변하고, 앱은 스스로 채널에 보고서를 게시하며, 위험한 작업은 Approve / Cancel 버튼 뒤에 대기하고 버튼 클릭은 앱으로 다시 전달됩니다. 사용 시점: (1) 제품 데이터에 대한 질문에 답하고 요청한 사용자에게 작업을 실행하는 Slack 어시스턴트를 추가할 때, (2) 앱이 Slack에 메시지를 푸시하고 버튼 클릭에 반응해야 할 때(인간이 개입하는 승인, 초안 후 전송), (3) 팔로업을 놓치고, 두 번 답변하거나 사용자를 식별하지 못하는 기존 Slack 봇을 감사할 때, (4) 사용자가 언급하는 항목: Slack bot, AI Slack assistant, two-way Slack, @mention bot, app_mention, thread follow‑up, onSubscribedMessage, Slack interactivity, block_actions, Approve button, Block Kit buttons, response_url, Slack OAuth install, users:read.email, x-slack-signature, “bot stops replying in threads”, “couldn’t match your Slack account”, Slack 버튼에서 “operation timed out”. Slack 이메일에서 앱 사용자로 연결되는 신원 브리지, 사용자 범위 도구, 중복 클릭에도 살아남는 단일 승인, 3초 ACK 규칙, 서버리스 상태 트랩, Markdown을 mrkdwn으로 변환하는 컨버터를 제공하며 테스트 31개를 포함합니다. Vercel이나 기타 Node 호스트에서 Next.js App Router 사용; 저장소, 인증, 모델 및 도메인 도구는 시점(seam)입니다. Chat SDK API 레퍼런스가 아니며 Slack 채널 리더도 아닙니다.
