建立一個基於檔案的多語系部落格，使用 markdown 內容：以語系分割的文章、每個語系的 slug 透過共享的 translationKey 連結、標籤頁面、相關文章、封面圖、RSS、站點地圖與 hreflang。適用情境：(1) 用 markdown 檔案而非 CMS 新增部落格、變更紀錄、新聞或文章區段；(2) 讓現有的 markdown 部落格變為多語系，或加入標籤頁面、hreflang、資訊來源或相關文章；(3) 內容存放在倉庫資料夾且必須靜態產生；(4) 使用者提及：markdown 部落格、MDX 部落格、frontmatter、gray‑matter、content/blog、translationKey、標籤頁面、hreflang、相關文章、generateStaticParams（用於文章）、部落格 RSS feed。具備跨語系 slug 模型、標籤 slug 衝突規則、能處理智慧引號的 frontmatter 解析器，以及透過 loader 記憶化減少高達 71 倍的建置時間讀取放大。以 Next.js App Router 為導向；內容來源是一個接點，讓 CMS 能取代檔案系統。不是 CMS 整合技能，也不是文件／說明中心技能。
