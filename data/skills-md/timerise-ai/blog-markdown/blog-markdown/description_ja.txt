Markdown コンテンツからファイルベースの多言語ブログを構築します：ロケール別に分割された投稿、共通の translationKey で結合されたロケールごとのスラッグ、タグページ、関連記事、カバーアート、RSS、サイトマップ、hreflang。使用シーン：(1) CMS ではなく Markdown ファイルで支えるブログ、チェンジログ、ニュース、記事セクションを追加する場合、(2) 既存の Markdown ブログを多言語化する、またはタグページ、hreflang、フィード、関連記事を追加する場合、(3) コンテンツがリポジトリのフォルダ内にあり、静的生成が必要な場合、(4) ユーザーが次の用語に言及している場合：markdown blog、MDX blog、frontmatter、gray-matter、content/blog、translationKey、tag pages、hreflang、related posts、generateStaticParams for posts、blog RSS feed。クロスロケールスラッグモデル、タグスラッグ衝突ルール、スマートクオートに耐える frontmatter パーサー、そしてビルド時の読み取り増幅を 71 倍削減するローダーのメモ化を備えています。Next.js App Router 向けで、コンテンツソースはシームとして扱われるため、CMS がファイルシステムを置き換えることが可能です。CMS 統合スキルでもドキュメント／ヘルプセンタースキルでもありません。
