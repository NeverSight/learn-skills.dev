从 markdown 内容构建基于文件的多语言博客：按语言分区的文章、通过共享 translationKey 关联的各语言 slug、标签页、相关文章、封面图片、RSS、站点地图和 hreflang。适用场景：(1) 在不使用 CMS 的情况下添加博客、变更日志、新闻或文章版块，使用 markdown 文件作为后端；(2) 将已有的 markdown 博客做多语言化，或添加标签页、hreflang、订阅源或相关文章；(3) 内容存放在仓库文件夹中，需要静态生成；(4) 用户提到的关键词：markdown blog、MDX blog、frontmatter、gray-matter、content/blog、translationKey、标签页、hreflang、相关文章、为文章生成 generateStaticParams、博客 RSS feed。实现跨语言 slug 模型、标签‑slug 冲突规则、能够容错智能引号的 frontmatter 解析器，以及通过加载器记忆化消除约 71 倍的构建时读取放大。面向 Next.js App Router；内容来源是一个可替换的接点，CMS 可以替代文件系统。不是 CMS 集成技能，也不是文档/帮助中心技能。
