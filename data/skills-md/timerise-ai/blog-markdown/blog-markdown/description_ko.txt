마크다운 콘텐츠를 기반으로 파일 기반 다국어 블로그를 구축합니다: 로케일별 파티션된 포스트, 공유 번역 키로 연결된 로케일별 슬러그, 태그 페이지, 관련 포스트, 커버 아트, RSS, 사이트맵, hreflang. 사용 상황: (1) CMS 대신 마크다운 파일로 지원되는 블로그, 체인지로그, 뉴스 또는 기사 섹션을 추가할 때, (2) 기존 마크다운 블로그를 다국어화하거나 태그 페이지, hreflang, 피드, 관련 포스트를 추가할 때, (3) 콘텐츠가 저장소 폴더에 존재하며 정적으로 생성되어야 할 때, (4) 사용자가 다음을 언급할 때: markdown blog, MDX blog, frontmatter, gray-matter, content/blog, translationKey, tag pages, hreflang, related posts, generateStaticParams for posts, blog RSS feed. 크로스 로케일 슬러그 모델, 태그‑슬러그 충돌 규칙, 스마트 인용 부호를 견디는 frontmatter 파서, 그리고 71배에 달하는 빌드 시간 읽기 증폭을 제거한 로더 메모이제이션을 포함합니다.
