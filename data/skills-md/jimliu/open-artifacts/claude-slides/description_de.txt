Erstellen und überarbeiten Sie Folienpräsentationen im Slides-Artefaktformat (project/deck.json plus eine HTML-Datei pro Folie) als lokale Dateien und öffnen Sie sie dann in einem lokalen Folieneditor, in dem der Benutzer sie präsentieren, neu eingeben, verschieben und als PDF, HTML oder PowerPoint exportieren kann. Verwenden Sie diese Option, wenn der Benutzer eine bearbeitbare Foliensammlung oder Präsentation in diesem Format anfordert, claude-slides oder den Typ „Slides“ nennt oder einen Ordner überarbeiten möchte, der project/deck.json enthält. Nicht für eine einmalige HTML-Präsentation oder einen Prototyp in einer einzigen Datei.
