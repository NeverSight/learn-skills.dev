Cree y revise presentaciones de diapositivas en el formato de artefacto Slides (project/deck.json más un archivo HTML por diapositiva) como archivos locales, y luego ábralas en un editor de diapositivas local donde el usuario pueda presentarlas, reescribirlas, arrastrarlas y exportarlas en formato PDF, HTML o PowerPoint. Utilícelo cuando el usuario solicite una presentación o una serie de diapositivas editables en este formato, mencione claude-slides o el tipo Slides, o quiera revisar una carpeta que contenga project/deck.json. No es para una presentación HTML o un prototipo únicos de un solo archivo.
