Crea e revisiona i progetti nel formato Design (canvas) (artifact) (project/canvas.json più un file .dc.html Design Component per artboard) come file locali, quindi aprili in un editor canvas locale dove l'utente può visualizzare le tavole affiancate, riscrivere copie e apportare aggiustamenti. Usa questo quando l'utente richiede una tela modificabile delle tavole in questo formato, denominata claude-design o del tipo Design (canvas), o vuole revisionare una cartella che contiene project/canvas.json. Un prototipo HTML unico o un'esplorazione di design al di fuori di questo formato è di baoyu-design.
