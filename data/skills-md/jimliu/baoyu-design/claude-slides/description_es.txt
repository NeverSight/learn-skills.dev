Haz y revisa presentaciones de diapositivas en el formato de artefacto Slides (project/deck.json más un archivo HTML por diapositiva) como archivos locales, luego ábrelas en un editor de diapositivas local donde el usuario pueda presentar, volver a escribir, arrastrar y exportar a PDF, HTML o PowerPoint. Úsalo cuando el usuario solicite una presentación de diapositivas editable o una presentación en este formato, mencione claude‑slides o el tipo Slides, o quiera revisar una carpeta que contenga project/deck.json. Una presentación HTML de un solo archivo o prototipo es de baoyu‑design.

Por favor, responde siempre en el idioma del usuario.
