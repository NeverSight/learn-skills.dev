Creare e revisionare presentazioni nel formato di artefatto Slides (project/deck.json più un file HTML per ogni diapositiva) come file locali, quindi aprirle in un editor di slide locale dove l’utente può presentare, riscrivere, trascinare e esportare in PDF, HTML o PowerPoint. Usare quando l’utente richiede una presentazione modificabile o un deck di slide in questo formato, nomina claude‑slides o il tipo Slides, o desidera revisionare una cartella che contiene project/deck.json. Un deck HTML monofile occasionale o un prototipo è di baoyu‑design.

Rispondi sempre nella lingua dell’utente.
