Usa questo per un dashboard locale basato sui dati, una pagina di metriche, un tracker KPI, una scheda, una visualizzazione dei dati o un report ricorrente che si apre nell'editor live integrato: una pagina o una storia a scorrimento di grafici, numeri e tabelle su set di dati (un file CSV/TSV/JSON che l'utente possiede, o dati che raccogli e alleghi), con un pannello Fonti che mostra da dove proviene ogni numero. Leggilo quando lo crei, lo compili, lo aggiorni o lo rivedi. Scrivi i set di dati, poi la pagina in HTML puro, nel repository del dashboard con lo script di questa skill. Non è destinato a un mockup HTML statico o a un'immagine di un dashboard: quello è la skill baoyu-design.
