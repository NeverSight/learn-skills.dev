Utiliza esto para un panel local respaldado por datos, una página de métricas, un rastreador KPI, una tarjeta de resultados, una visualización de datos o un informe recurrente que se abre en el editor en vivo incluido: una página o historia desplazable de gráficos, números y tablas sobre conjuntos de datos (un archivo CSV/TSV/JSON que tenga el usuario, o datos que recopiles y adjuntes), con un panel de Fuentes que muestra de dónde proviene cada número. Léelo al crear, rellenar, actualizar o revisar uno. Escribes los conjuntos de datos y luego la página como HTML plano, en el almacén propio del panel con el script de esta habilidad. No es para un mockup estático de HTML o una imagen de un panel: esa es la habilidad baoyu‑design.
