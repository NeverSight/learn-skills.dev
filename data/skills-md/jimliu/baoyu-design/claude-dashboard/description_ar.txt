استخدم هذا لإنشاء لوحة تحكم محلية مدعومة بالبيانات، أو صفحة مقاييس، أو متتبع مؤشرات الأداء (KPI)، أو بطاقة تقدير، أو تصور بيانات، أو تقرير متكرر يُفتح في المحرر المباشر المدمج: صفحة أو قصة تمرير تحتوي على مخططات وأرقام وجداول مبنية على مجموعات بيانات (ملف CSV/TSV/JSON يملكه المستخدم، أو بيانات تقوم بجمعها وإرفاقها)، مع لوحة مصادر تُظهر من أين يأتي كل رقم. اقرأها عند الإنشاء أو الملء أو التحديث أو المراجعة. تكتب مجموعات البيانات، ثم الصفحة كـ HTML بسيط، داخل مخزن اللوحة الخاص بها باستخدام سكريبت هذه المهارة. ليست لإنشاء نموذج HTML ثابت أو صورة للوحة التحكم: تلك هي مهارة baoyu-design.
