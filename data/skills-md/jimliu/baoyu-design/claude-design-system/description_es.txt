Crear y revisar sistemas de diseño en el formato de artefacto Design System (project/design-system.json, tokens.json, un README brand book, vistas previas de componentes, fuentes y grupos de recursos) como archivos locales, luego abrirlos en una página local de design-system donde el usuario pueda explorar y editar tokens, tipografía, componentes y recursos. Usar cuando el usuario solicite un sistema de diseño o kit de marca en este formato, creado a partir de un repositorio de código, una herramienta de diseño o desde cero, con los nombres claude-design-system o el tipo Design System, o quiera revisar una carpeta que contiene project/design-system.json. claude‑slides y claude‑design instalan estos sistemas. Una guía de estilo HTML de formato libre, kit UI o página de tokens es de baoyu‑design.

Por favor, responde siempre en el idioma del usuario.
