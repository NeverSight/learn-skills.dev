创建并修改符合 Design System 工件格式的设计系统（project/design-system.json、tokens.json、README 品牌手册、组件预览、字体和资产组）为本地文件，然后在本地 design-system 页面中打开，用户可以浏览和编辑 token、排版、组件和资产。当用户请求此格式的设计系统或品牌套件，且来源于代码仓库、设计工具或从头开始，名称为 claude-design-system 或 Design System 类型，或想要修改包含 project/design-system.json 的文件夹时，请使用此方法。claude-slides 和 claude-design 安装这些系统。自由形式的 HTML 样式指南、UI kit 或 token 页面属于 baoyu-design。
