Crea e revisiona i sistemi di design nel formato di artefatto Design System (project/design-system.json, tokens.json, un README brand book, anteprime dei componenti, font e gruppi di asset) come file locali, quindi aprili in una pagina locale design-system dove l'utente può navigare e modificare token, tipografia, componenti e asset. Usa questa procedura quando l'utente richiede un sistema di design o un kit di brand in questo formato, costruito da un repository di codice, da uno strumento di design o da zero, con i nomi claude-design-system o il tipo Design System, o vuole revisionare una cartella che contiene project/design-system.json. claude‑slides e claude‑design installano questi sistemi. Una guida di stile HTML libera, un UI kit o una pagina di token è di baoyu‑design.
