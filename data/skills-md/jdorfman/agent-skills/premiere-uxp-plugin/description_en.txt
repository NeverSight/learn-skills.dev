Scaffold, build, debug, and package Adobe UXP plugins (panels) for Premiere Pro, Photoshop, and other Creative Cloud apps. Use when the user wants to create or fix an Adobe plugin/panel/extension, mentions UXP, manifest.json, UDT / UXP Developer Tool, a .ccx package, the `premierepro` or `photoshop` scripting module, or is migrating from deprecated CEP/ExtendScript. Covers the panel scaffold, the manifest v5 schema, the lockedAccess+executeTransaction action pattern, DevTools logging, and packaging to .ccx.
