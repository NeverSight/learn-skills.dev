Preparar el ordenador de sobremesa para trabajar con Hyperliquid: instalar los SDK, elegir la red de pruebas o la red principal, verificar la conectividad y (solo cuando el usuario lo solicite) proporcionar una cartera API solo para operaciones a través del almacén seguro de secretos y verificar que esté aprobada. Utilícelo durante la configuración del escritorio, al pasar de un nivel de investigación a otro de red de pruebas o de red principal, cuando se rote una clave o cuando falle cualquier llamada de Hyperliquid debido a un problema del entorno.
