Convenciones de diagramación SVG que combinan una apariencia técnica con una tipografía compatible con CJK. Úselo al crear diagramas de flujo, diagramas de arquitectura y figuras SVG similares. Para la generación de una sola vez, prefiera invocarlo desde un subagente para que el contexto principal no tenga que llevar esta habilidad más el XML SVG; para ajustes de varias rondas, úselo directamente en el contexto principal.
