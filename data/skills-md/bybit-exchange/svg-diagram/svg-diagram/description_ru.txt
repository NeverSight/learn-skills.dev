Соглашения по построению диаграмм SVG, сочетающие технический вид с типографикой, удобной для CJK. Используйте при создании блок-схем, архитектурных диаграмм и подобных изображений SVG. Для однократной генерации предпочтительнее вызывать ее из субагента, чтобы основной контекст не переносил этот навык плюс XML SVG; для многораундовой настройки используйте ее непосредственно в основном контексте.
