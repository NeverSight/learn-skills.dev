Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Usalo quando l'utente dice "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferiscilo rispetto a un worktree git grezzo, PTY ad hoc o l'uso del Computer quando è coinvolto lo stato di Orca. Usa l'uso del Computer solo quando una finestra visibile richiede un controllo GUI che una CLI, il filesystem o un'API non possono gestire. Per favore rispondi sempre nella lingua dell'utente.
