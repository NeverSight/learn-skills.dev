قم بتشغيل شجرات العمل المُدارة من قبل Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضِّل ذلك على شجرة Git العادية، أو PTY المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متورطة. استخدم "Computer Use" فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة رسومية لا يمكن لسطر الأوامر أو نظام الملفات أو API تنفيذه.
