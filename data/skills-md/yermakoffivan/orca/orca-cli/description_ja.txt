Orca が管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そして Orca の埋め込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」「handover」「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、raw git worktree や adhoc PTY、Computer Use よりもこれを優先します。CLI、ファイルシステム、API では対応できない可視ウィンドウの GUI 操作が必要なときだけ Computer Use を使用してください。

必ずユーザーの言語で回答してください。
