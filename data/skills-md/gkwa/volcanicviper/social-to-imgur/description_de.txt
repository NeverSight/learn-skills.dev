Laden Sie das Miniaturbild/Titelbild von einem Social-Media-Beitrag (Instagram, Facebook oder einer anderen von yt-dlp unterstützten Plattform) herunter und laden Sie es auf Imgur hoch, wobei Sie eine permanente URL zurückgeben. Wird verwendet, wenn der Benutzer eine Social-Media-URL teilt und einen permanenten Bildlink wünscht.
