Добавьте продукт в список покупок для магазина, установив логическое значение front matter этого магазина в true в заметке продукта в хранилище Obsidian, предварительно создав заметку продукта, если она ещё не существует. Если магазин не указан, продукт попадает в общий список amazon_fresh. Используйте эту инструкцию, когда просят добавить что‑либо в список покупок, с указанием магазина или без него, чтобы добавить пункт в список для конкретного магазина или отметить продукт для покупки в Trader Joe’s, Costco, PCC или любом другом магазине.
