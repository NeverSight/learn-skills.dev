Diagnostic et correction des erreurs de site web sur un hébergement cPanel — lecture des logs d’erreur, vérification des fichiers, version de PHP, cron, correction des erreurs 500/écran blanc. Utilisé lorsque le site rencontre une erreur, renvoie un code 500, affiche une page blanche, ou que l’utilisateur doit déboguer une application s’exécutant sur un hébergement cPanel.
