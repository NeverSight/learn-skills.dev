التعامل مع حزمة استضافة cPanel للمستخدم عبر رمز API — فحص الاتصال، استدعاء أي دالة UAPI/API2، وتُعد نقطة الانطلاق لجميع مهام cPanel (قاعدة البيانات، النطاق، النشر، التصحيح، cron، البريد الإلكتروني). يُستخدم عندما يذكر المستخدم cPanel أو الاستضافة أو حزمة الاستضافة أو نطاقًا إضافيًا، أو يحتاج إلى تنفيذ عمليات على حساب الاستضافة.
