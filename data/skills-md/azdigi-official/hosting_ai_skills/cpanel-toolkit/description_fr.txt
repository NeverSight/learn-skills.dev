Opérations sur le forfait d’hébergement cPanel d’un utilisateur via un jeton API — vérifier la connexion, appeler n’importe quelle fonction UAPI/API2, et servir de point de départ à toutes les tâches cPanel (base de données, domaine, déploiement, débogage, cron, e‑mail). Utilisé lorsque l’utilisateur mentionne cPanel, hébergement, forfait d’hôte, domaine supplémentaire ou a besoin d’intervenir sur le compte d’hébergement.
