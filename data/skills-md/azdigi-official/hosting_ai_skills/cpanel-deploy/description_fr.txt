Déployer le code source du site web sur un hébergement cPanel via API — site statique, PHP + MySQL, WordPress complet, Node.js (Passenger) et clonage Git. Upload/décompression d’archive, déplacement de fichiers, écriture de la configuration. Utilisé lorsque l’utilisateur doit déployer/installer un site web ou une application (WordPress, PHP, statique, Node.js, Laravel) sur un hébergement cPanel, téléverser le code source ou cloner un dépôt Git sur l’hébergement.
