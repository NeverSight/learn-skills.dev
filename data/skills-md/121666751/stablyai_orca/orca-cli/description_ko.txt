Orca가 관리하는 워크트리, 폴더 컨텍스트, 터미널, 저장소, 자동화, 아티팩트, 기술 공유, 워크트리 주석 및 Orca의 내장 브라우저를 `orca` CLI를 통해 운영합니다. 사용자가 “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts”, 또는 “share skills” 라고 말할 때 사용합니다. Orca 상태가 관련된 경우 원시 git 워크트리, 임시 PTY, 또는 Computer Use보다 이를 우선합니다. 외부 창이나 OS 수준 제어가 필요한 데스크톱 UI에 대해서만 Computer Use를 사용하고, 외부 페이지에는 Playwright 또는 CDP를 사용합니다.
