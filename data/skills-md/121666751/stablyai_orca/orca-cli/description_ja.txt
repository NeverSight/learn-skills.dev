`orca` CLI を使用して、Orca が管理するワークツリー、フォルダーコンテキスト、端末、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザを操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」「handover」「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree やアドホック PTY、Computer Use よりもこれを優先してください。Computer Use は、OS レベルの制御が必要な外部ウィンドウやデスクトップ UI のみで使用し、外部ページには Playwright や CDP を使用してください。

常にユーザーの言語で応答してください。
