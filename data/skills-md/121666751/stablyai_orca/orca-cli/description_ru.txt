Оперировать рабочими деревьями, управляемыми Orca, контекстами папок, терминалами, репозиториями, автоматизациями, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Использовать, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff» / «handover» / «give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочтительно вместо обычного git worktree, произвольных PTY или Computer Use, когда вовлечено состояние Orca. Использовать Computer Use только для внешних окон или пользовательского интерфейса рабочего стола, требующих управления на уровне ОС, а Playwright или CDP — для внешних страниц.
