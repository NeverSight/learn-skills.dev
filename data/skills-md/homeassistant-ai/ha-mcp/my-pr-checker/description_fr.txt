Gérez vos propres pull requests GitHub : vérifiez le statut de l'intégration continue, les commentaires de revue intégrés, les commentaires au niveau de la PR, résolvez les fils de discussion de revue, corrigez les problèmes et itérez jusqu'à ce que toutes les vérifications soient réussies et que les fils de discussion soient résolus. À utiliser pour gérer vos propres PR (et non les contributions externes). Se déclenche avec « vérifier ma PR », « vérifier la PR », « /my-pr-checker <number>».
