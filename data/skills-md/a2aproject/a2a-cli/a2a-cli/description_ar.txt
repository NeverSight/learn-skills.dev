قم بتفويض العمل إلى وكلاء A2A (Agent2Agent) من سطر الأوامر باستخدام أداة `a2a` CLI (github.com/a2aproject/a2a-cli). استخدمها عندما تحتاج إلى تسليم مهمة إلى وكيل متخصص أو بعيد، جلب بطاقة الوكيل، إرسال رسالة إلى وكيل عبر URL، بث أو استقصاء مهمة قيد التشغيل، أو التحقق، سرد، استئناف أو إلغاء مهمة A2A. لا تُستَخدم لبناء أو تشغيل وكيل A2A، ولا لاستدعاء واجهات HTTP غير A2A.
