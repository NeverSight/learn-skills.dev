Делегируйте работу агентам A2A (Agent2Agent) из командной строки с помощью CLI `a2a` (github.com/a2aproject/a2a-cli). Используйте, когда нужно передать задачу специализированному или удалённому агенту, получить карточку агента, отправить сообщение агенту по URL, трансляровать или опрашивать выполняющуюся задачу, а также проверить, перечислить, возобновить или отменить задачу A2A. Не предназначено для создания или обслуживания агента A2A, а также для вызова не‑A2A HTTP API.
