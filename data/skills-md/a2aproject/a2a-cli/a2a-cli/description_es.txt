Delegue el trabajo a los agentes A2a (Agent2Agent) desde la línea de comandos con la CLI `a2a` (github.com/a2aproject/a2a-cli). Úselo cuando necesite entregar una tarea a un agente especializado o remoto, obtener la tarjeta de un agente, enviar un mensaje a un agente en una URL, transmitir o sondear una tarea en ejecución, o verificar, enumerar, reanudar o cancelar una tarea A2a. No para crear o servir a un agente A2a, ni para llamar a API HTTP que no sean A2A.
