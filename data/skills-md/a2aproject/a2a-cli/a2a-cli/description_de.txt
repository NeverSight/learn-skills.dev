Delegieren Sie die Arbeit an A2A-Agenten (Agent2Agent) über die Befehlszeile mit der CLI `a2a` (github.com/a2aproject/a2a-cli). Verwenden Sie diese Option, wenn Sie eine Aufgabe an einen spezialisierten oder Remote-Agenten übergeben, die Karte eines Agenten abrufen, eine Nachricht an einen Agenten unter einer URL senden, eine ausgeführte Aufgabe streamen oder abfragen oder eine A2A-Aufgabe überprüfen, auflisten, fortsetzen oder abbrechen müssen. Nicht zum Erstellen oder Bereitstellen eines A2A-Agenten oder zum Aufrufen von Nicht-A2A-HTTP-APIs.
