Déléguez le travail aux agents A2A (Agent2Agent) à partir de la ligne de commande avec la CLI `a2a` (github.com/a2aproject/a2a-cli). À utiliser lorsque vous devez confier une tâche à un agent spécialisé ou distant, récupérer la carte d'un agent, envoyer un message à un agent à une URL, diffuser ou interroger une tâche en cours d'exécution, ou vérifier, répertorier, reprendre ou annuler une tâche A2A. Pas pour construire ou servir un agent A2A, ou pour appeler des API HTTP non-A2A.
