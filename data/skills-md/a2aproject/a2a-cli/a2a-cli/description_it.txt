Delegare il lavoro ad agenti A2A (Agent2Agent) dalla riga di comando con il CLI `a2a` (github.com/a2aproject/a2a-cli). Da utilizzare quando è necessario affidare un compito a un agente specializzato o remoto, recuperare la scheda di un agente, inviare un messaggio a un agente tramite un URL, trasmettere in streaming o interrogare un’attività in esecuzione, o verificare, elencare, riprendere o annullare un’attività A2A. Non è destinato alla creazione o al servizio di un agente A2A, né per chiamare API HTTP non A2A.
