「a 2 a」CLI （ github.com/a2aproject/a2a-cli ）を使用して、コマンドラインからA 2 A （ Agent 2 Agent ）エージェントに作業を委任します。専門のエージェントまたはリモートエージェントにタスクを渡す必要がある場合、エージェントのカードを取得する必要がある場合、URLでエージェントにメッセージを送信する必要がある場合、実行中のタスクをストリーミングまたはポーリングする必要がある場合、またはA 2 Aタスクを確認、リスト、再開、またはキャンセルする必要がある場合に使用します。A 2 Aエージェントを構築または提供するため、または非A 2 A HTTP APIを呼び出すためではありません。
