Prenez une PR de la revue jusqu’à la fusion — exécutez la compétence de revue de code du dépôt dessus dans une boucle (revue, correction, re‑revue) jusqu’à ce qu’il ne reste plus rien à corriger, en appliquant TOUTES les corrections sur la branche de la PR, attendez que le CI devienne vert, puis effectuez un squash‑merge. Utilisez‑le lorsqu’on vous demande « ship it », « ship PR ». Veuillez toujours répondre dans la langue de l’utilisateur.
