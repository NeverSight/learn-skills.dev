Zeichnen Sie eine animierte Figur (Kästchen, Pfeile, bewegliche Daten) als ein in sich geschlossenes SVG für einen GitHub README-, PR-, Issue- oder Blog-Post. Verwenden Sie es, wenn eine Änderung oder eine Erklärung ein Diagramm benötigt — wie eine Anfrage abläuft, was ein Hintergrundjob tut, was ein Feature geändert hat — oder wenn der Benutzer nach einem Diagramm, einer Figur, einer Animation fragt oder "es visuell zeigt". Die Docs-Site verwendet stattdessen die interaktiven React-Figuren.
