Créez une figure animée (boîtes, flèches, données en mouvement) sous forme d’un SVG autonome pour un README GitHub, une PR, une issue ou un article de blog. Utilisez‑la lorsqu’un changement ou une explication nécessite un diagramme — comment une requête circule, ce qu’un job en arrière‑plan fait, ce qu’une fonctionnalité a modifié — ou lorsque l’utilisateur demande un diagramme, une figure, une animation ou « montrez‑le visuellement ». Le site de documentation utilise à la place les figures React interactives.
