Cette compétence doit être utilisée lorsque l'utilisateur demande de « dessiner chaque image en JavaScript », « créer une animation sans ressources d'image », « animer cela en code / sur un canvas », « réaliser une vidéo animée au style dessin à la main », « transformer cela en court métrage d'animation », « créer une animation explicative dessinée en code », « faire une histoire animée / un livre d'images à partir de mes photos », ou « produire une animation sans ressources comme les œuvres Opus 5.5 ». Produit un fichier HTML autonome dont les images sont calculées sur un canvas HTML (cherchable, déterministe), le rend en MP4 et vérifie le résultat de façon autonome. Se combine avec la compétence de bande‑son pour de la musique synthétisée par code. PAS pour les graphiques à partir de données (utilisez chart‑animation), le mouvement de texte pur (utilisez kinetic‑typography), ou la 3D/WebGL (utilisez threejs‑animation / shader‑glsl des compétences webgl‑animation).

Veuillez toujours répondre dans la langue de l'utilisateur.
