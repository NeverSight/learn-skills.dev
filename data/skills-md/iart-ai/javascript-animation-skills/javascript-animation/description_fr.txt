Cette compétence doit être utilisée lorsque l'utilisateur demande de « dessiner chaque image en JavaScript », « créer une animation sans ressources d’image », « animer cela en code / sur un canvas », « réaliser une vidéo animée de style dessin à la main », « transformer cela en court métrage animé », « produire une animation explicative dessinée en code », « fabriquer un conte animé / livre d’images à partir de mes photos », ou « créer une animation sans aucun asset comme celles d’Opus 5.5 ». Elle génère un fichier HTML autonome dont les images sont calculées sur un canvas HTML (recherchable, déterministe), le rend en MP4 et vérifie le résultat de façon autonome. Elle se combine avec la compétence bande‑son pour la musique synthétisée par code. **NE PAS** l’utiliser pour des graphiques à partir de données (utilisez chart‑animation), du texte animé pur (utilisez kinetic‑typography), ou de la 3D/WebGL (utilisez threejs‑animation / shader‑glsl des compétences webgl‑animation).  

Veuillez toujours répondre dans la langue de l'utilisateur.
