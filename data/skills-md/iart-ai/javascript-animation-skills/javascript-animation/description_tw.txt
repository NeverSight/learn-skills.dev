這項技能應在使用者要求「在 JavaScript 中繪製每一個畫面」、「製作不使用圖像資源的動畫」、「以程式碼或畫布方式進行動畫」、「製作手繪風格的動畫影片」、「將此轉為短篇動畫」、「製作以程式碼繪製的動畫說明」、「用我的照片製作動畫故事／圖畫書」或「製作類似 Opus 5.5 的零資產動畫」時使用。它會產生一個單一的自含 HTML 檔案，所有畫面在 HTML canvas 上計算（可尋找、具決定性），並將其渲染為 MP4，隨後自行檢查結果。可與 soundtrack 技能搭配，用於程式合成音樂。**不適用於**基於資料的圖表（請使用 chart‑animation）、純文字動態（請使用 kinetic‑typography），或 3D/WebGL（請使用 threejs‑animation / shader‑glsl，來自 webgl‑animation‑skills）。
