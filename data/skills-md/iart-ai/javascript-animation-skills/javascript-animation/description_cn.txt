此技能应在用户请求“用 JavaScript 绘制每一帧”、“制作无需图像资源的动画”、“在代码/画布上进行动画化”、“制作手绘风格的动画视频”、“将其转化为短篇动画电影”、“制作用代码绘制的动画解说视频”、“制作我的照片的动画故事/绘本”，或“制作类似 Opus 5.5 的零资源动画”等情形下使用。它会生成一个包含所有帧在 HTML canvas 上计算的单一独立 HTML 文件（可搜索、确定性），并将其渲染为 MP4，同时自行检查结果。可与配乐技能配合，用代码合成音乐。**不适用于**基于数据的图表（使用 chart‑animation）、纯文本运动（使用 kinetic‑typography）或 3D/WebGL（使用 threejs‑animation / shader‑glsl，来自 webgl‑animation‑skills）。请始终使用用户的语言作答。
