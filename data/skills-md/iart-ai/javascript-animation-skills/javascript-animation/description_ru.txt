Этот навык следует использовать, когда пользователь просит «рисовать каждый кадр в JavaScript», «создать анимацию без графических ресурсов», «анимировать это в коде/на холсте», «сделать анимационное видео в стиле ручного рисунка», «превратить это в короткий анимационный фильм», «создать анимационный объясняющий ролик, нарисованный в коде», «сделать анимационную историю/картинную книгу из моих фотографий» или «создать анимацию без ресурсов, как у Opus 5.5». Генерирует единый автономный HTML‑файл, в котором кадры вычисляются на HTML‑canvas (перематываемый, детерминированный), затем рендерит его в MP4 и самостоятельно проверяет результат. Комбинируется с навыком саундтрека для синтезированной в коде музыки. НЕ предназначен для графиков из данных (используйте chart‑animation), чистой текстовой анимации (используйте kinetic‑typography) или 3D/WebGL (используйте threejs‑animation / shader‑glsl из webgl‑animation‑skills).  

Пожалуйста, всегда отвечайте на языке пользователя.
