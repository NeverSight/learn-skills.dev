Эту функцию следует использовать, когда пользователь просит «рисовать каждый кадр на JavaScript», «создать анимацию без графических ресурсов», «анимировать это в коде/на холсте», «сделать анимированное видео в стиле рукописного рисунка», «превратить это в короткий анимационный фильм», «сделать анимационный объяснитель, нарисованный в коде», «создать анимированную историю/книжку из моих фотографий» или «создать анимацию без ресурсов, подобную Opus 5.5». Генерирует один самодостаточный HTML‑файл, кадры которого вычисляются на HTML‑canvas (поисковый, детерминированный), экспортирует его в MP4 и проверяет результат. Сочетается с навыком саундтрека для синтезированной в коде музыки. НЕ предназначена для построения графиков из данных (используйте chart‑animation), чистого текстового движения (используйте kinetic‑typography) или 3D/WebGL (используйте threejs‑animation / shader‑glsl из webgl‑animation‑skills).

Пожалуйста, всегда отвечайте на языке пользователя.
