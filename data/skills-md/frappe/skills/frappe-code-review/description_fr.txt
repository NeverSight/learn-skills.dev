Passez en revue le code de toute application Frappe — une liste de contrôle distillée à partir d'années de pratique en ingénierie sur l'exactitude, la sécurité, les performances, la simultanéité, la lisibilité, la conception d'API et les tests. Utilisez-le lors de la révision d'un diff, d'une RP ou d'un code pour la qualité et la sécurité, ou lorsque vous souhaitez que la liste de contrôle d'un évaluateur s'appuie sur des leçons Frappe/ERPNext durement gagnées.
