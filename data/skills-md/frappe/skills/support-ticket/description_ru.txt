Обрабатывайте заявки поддержки клиентов Frappe/ERPNext: проводите триаж сообщённой проблемы/ошибки, запрашивайте данные сайта через безопасные фрагменты System Console в песочнице, отслеживайте пути кода и исправляйте их с помощью безопасного ветвления/коммита. Используйте эту инструкцию каждый раз, когда пользователь вставляет клиентскую проблему, симптом или журнал ошибок, указывает номер заявки для чтения или просит код для получения данных с сайта клиента — например, «клиент говорит, что баланс по складу не совпадает», «вот заявка», «проверьте заявку 78690», «дайте скрипт для проверки X на их сайте», или вставляет диалог клиента/агента или трассировку стека. Также используйте её для обновления контекста из последних сообщений — «проверьте последний ответ клиента», «есть новый ответ по заявке», «обновить тему». 

Пожалуйста, всегда отвечайте на языке пользователя.
