Обрабатывайте заявки поддержки клиентов Frappe/ERPNext: сортируйте полученную проблему/ошибку, запрашивайте данные сайта через безопасные фрагменты System Console в песочнице, отслеживайте пути кода и исправляйте их с помощью безопасного ветвления/коммитов. Используйте эту инструкцию каждый раз, когда пользователь вставляет проблему, симптом или журнал ошибки, сообщённые клиентом, указывает номер заявки для чтения или просит код для получения данных с сайта клиента — например, «клиент говорит, что остатки в журнале не совпадают», «вот заявка», «проверьте заявку 78690», «дайте скрипт для проверки X на их сайте», или вставляет разговор клиента/агента или трассировку стека. Также используйте её для обновления контекста по последним сообщениям — «проверьте последний ответ клиента», «есть ли новый ответ по заявке», «обновите ветку». 

Пожалуйста, всегда отвечайте на языке пользователя.
