Gérez les tickets de support client Frappe/ERPNext : triez un problème/une erreur signalée, demandez les données du site via des extraits de la console système sécurisés pour le sandbox, suivez les chemins du code et corrigez avec un flux de branche/commit sûr. Utilisez cela chaque fois que l'utilisateur colle un problème signalé par le client, un symptôme ou un journal d'erreur, fournit un numéro de ticket à lire, ou demande du code pour extraire des données du site d'un client — par ex. « le client dit que le registre de stock ne correspond pas », « voici le ticket », « vérifier le ticket 78690 », « donnez‑moi un script pour vérifier X sur leur site », ou colle une conversation client/agent ou une trace d'erreur. Utilisez également pour actualiser le contexte à partir de la dernière communication — « vérifier la dernière réponse du client », « y a‑t‑il une nouvelle réponse sur le ticket », « rafraîchir le fil ». Veuillez toujours répondre dans la langue de l'utilisateur.
