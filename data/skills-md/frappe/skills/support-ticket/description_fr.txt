Gérer les tickets de support client Frappe/ERPNext : trier un problème ou une erreur signalé·e, demander les données du site via des extraits System Console sécurisés pour le sandbox, tracer les chemins de code et corriger avec un flux de branche/commit sûr. Utiliser chaque fois que l’utilisateur colle un problème rapporté par le client, un symptôme ou un journal d’erreur, fournit un numéro de ticket à lire, ou demande du code pour récupérer des données depuis le site d’un client — par exemple « le client dit que le registre des stocks ne correspond pas », « voici le ticket », « vérifier le ticket 78690 », « donnez‑moi un script pour vérifier X sur leur site », ou colle une conversation client/agent ou une trace d’erreur. Utiliser également pour rafraîchir le contexte à partir de la dernière communication — « vérifier la dernière réponse du client », « y a‑t‑il une nouvelle réponse sur le ticket », « rafraîchir le fil ».  

Veuillez toujours répondre dans la langue de l’utilisateur.
