Corrigez un bug signalé dans une issue GitHub ou un fichier markdown, sans laisser le bruit et les suppositions du rapport envahir le contexte principal. Prend en argument un numéro d'issue, une URL d'issue ou un chemin de fichier. Utilisez‑le lorsqu'on vous demande de corriger, d'enquêter ou de reproduire un bug signalé.

Veuillez toujours répondre dans la langue de l'utilisateur.
