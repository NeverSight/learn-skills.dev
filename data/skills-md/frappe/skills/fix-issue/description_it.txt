Correggi un bug segnalato in un issue su GitHub o in un file markdown, senza introdurre il rumore e le ipotesi del report nel contesto principale. Accetta come argomento un numero di issue, un URL dell'issue o un percorso di file. Utilizzalo quando ti viene chiesto di correggere, investigare o riprodurre un bug segnalato.

Rispondi sempre nella lingua dell'utente.
