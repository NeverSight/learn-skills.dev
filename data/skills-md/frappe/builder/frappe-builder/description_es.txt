Administre un sitio web creado con Frappe Builder en un sitio de Frappe desde fuera del editor. Se utiliza para crear o editar páginas de Builder, crear o cambiar componentes de Builder (props, scripts, datos), volver a tematizar un sitio, crear páginas basadas en datos o de enrutamiento dinámico a partir de DocTypes del sitio, crear formularios que guarden, agregar scripts de página o publicar, cuando el sitio ejecuta la aplicación Builder.
