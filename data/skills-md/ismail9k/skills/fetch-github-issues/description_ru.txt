Извлекайте и отображайте открытые задачи GitHub, включая их полные тела и метаданные, из репозитория, записанного в docs/agents/issue-tracker.md, или из репозитория, имя которого явно указано пользователем. Используйте, когда пользователь просит перечислить, показать или просмотреть открытые проблемы; этот навык доступен только для чтения и не создает, не редактирует, не закрывает и не сортирует проблемы.
