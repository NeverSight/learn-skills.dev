Obtenga y muestre problemas abiertos de GitHub, incluidos sus cuerpos completos y metadatos, desde el repositorio registrado en docs/agents/issue-tracker.md o desde un repositorio cuyo nombre de usuario sea explícito. Úselo cuando el usuario solicite enumerar, mostrar o revisar problemas abiertos; Esta es una habilidad de solo lectura y no crea, edita, cierra ni clasifica problemas.
