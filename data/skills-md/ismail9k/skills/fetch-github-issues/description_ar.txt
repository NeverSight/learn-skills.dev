قم بإحضار وعرض مشكلات GitHub المفتوحة، بما في ذلك نصوصها الكاملة وبياناتها التعريفية، من المستودع المسجل في docs/agents/issue-tracker.md أو من مستودع أسماء المستخدمين بشكل صريح. يُستخدم عندما يطلب المستخدم إدراج المشكلات المفتوحة أو عرضها أو مراجعتها؛ هذه مهارة للقراءة فقط ولا تؤدي إلى إنشاء مشكلات أو تحريرها أو إغلاقها أو فرزها.
