Récupérez et affichez les problèmes GitHub ouverts, y compris leurs corps complets et leurs métadonnées, à partir du référentiel enregistré dans docs/agents/issue-tracker.md ou à partir d'un référentiel avec les noms d'utilisateur explicites. À utiliser lorsque l'utilisateur demande à répertorier, afficher ou examiner les problèmes ouverts ; il s'agit d'une compétence en lecture seule qui ne crée, ne modifie, ne ferme ni ne trie les problèmes.
