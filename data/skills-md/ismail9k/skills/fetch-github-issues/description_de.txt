Rufen Sie offene GitHub-Probleme ab und zeigen Sie sie an, einschließlich ihrer vollständigen Texte und Metadaten, aus dem in docs/agents/issue-tracker.md aufgezeichneten Repository oder aus einem Repository, das der Benutzer explizit nennt. Verwenden Sie diese Option, wenn der Benutzer offene Probleme auflisten, anzeigen oder überprüfen möchte. Hierbei handelt es sich um eine schreibgeschützte Fähigkeit, die keine Probleme erstellt, bearbeitet, schließt oder selektiert.
