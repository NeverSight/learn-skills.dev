Recupera e visualizza i problemi GitHub aperti, inclusi i relativi corpi completi e metadati, dal repository registrato in docs/agents/issue-tracker.md o da un repository i cui nomi utente sono esplicitamente. Da utilizzare quando l'utente chiede di elencare, mostrare o rivedere i problemi aperti; questa è una capacità di sola lettura e non crea, modifica, chiude o valuta problemi.
