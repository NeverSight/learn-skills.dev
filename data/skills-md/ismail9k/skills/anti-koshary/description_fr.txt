Audit et nettoyage en deux passes pour une base de code qui a commencé à se figer – code spaghetti, ou « code koshary », où les couches se sont effondrées : la logique métier réside dans le contrôleur, la même validation se trouve dans cinq fichiers, et personne ne veut ouvrir celui de 800 lignes. Passer 1 signale l'effondrement de la couche, la duplication qui dérivera, les fonctions que personne ne lit et le code mort comme liste prioritaire et ne change rien ; Passez 2 correctifs dans un ordre sûr une fois que l'utilisateur a approuvé. Les failles de sécurité et les dépendances vulnérables sont également couvertes, dans une section ultérieure plutôt que dans le titre. Utilisez-le chaque fois que l'utilisateur demande à auditer, réviser ou nettoyer une base de code - et également lorsqu'il dit « cette base de code est un gâchis », « code spaghetti », « dette technique », « ceci n'est pas maintenable », « logique dupliquée », « code mort », « qu'est-ce qui ne va pas avec mon code » ou demande un examen de sécurité. Déclenchez-le même s'ils n'utilisent jamais le mot « audit ».
