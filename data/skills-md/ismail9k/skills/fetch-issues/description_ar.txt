استخدم عندما يطلب المستخدم سرد أو عرض أو مراجعة القضايا المفتوحة — من المتعقّب المسجل في docs/agents/issue‑tracker.md، سواء كان GitHub أو Jira أو markdown محلي أو أي نظام خلفي آخر، أو من مستودع أو مشروع يحدده المستخدم. للقراءة فقط: ليس لإنشاء أو تعديل أو إغلاق أو تصنيف القضايا.

يرجى دائمًا الرد بلغة المستخدم.
