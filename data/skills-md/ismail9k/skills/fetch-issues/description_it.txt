Usa quando l'utente chiede di elencare, mostrare o rivedere le issue aperte — dal tracker registrato in docs/agents/issue-tracker.md, sia esso GitHub, Jira, markdown locale o un altro backend, o da un repository o progetto nominato dall'utente. Sola lettura: non serve per creare, modificare, chiudere o gestire le issue.

Rispondi sempre nella lingua dell'utente.
