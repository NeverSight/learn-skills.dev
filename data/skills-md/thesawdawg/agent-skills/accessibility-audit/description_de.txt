Führen Sie eine WCAG 2.2 (AA und höher) Barrierefreiheitsprüfung einer Live-Web-App durch – automatisiertes Axe-Core-Scannen mit Querverweisen zur aktuellen WCAG-Erfolgskriterientabelle sowie manuelle Überprüfung dessen, was automatisierte Tools strukturell nicht überprüfen können (Tastaturbedienbarkeit, Fokusreihenfolge, Alt-Text-Qualität, Timing/Bewegung). Erstellt einen Konformitätsbericht pro Kriterium. Verwenden Sie diese Option, wenn der Benutzer eine Prüfung der Barrierefreiheit/eines Jahres oder eine WCAG-Konformitätsprüfung wünscht oder vor dem Versand wissen möchte, ob eine Website die AA-Anforderungen erfüllt.
