Después de confirmar, verifique si el cambio necesita documentación, redacte las actualizaciones de documentos para su aprobación y, una vez aprobadas, publíquelas en un repositorio de documentación separado (rama + PR de forma predeterminada) o en un árbol de documentos en este repositorio para proyectos que no tienen un repositorio de documentos separado. Utiliza una configuración comprometida para la ubicación del documento, un índice de documento comprometido para mantener las consultas económicas y sincronizadas, y reglas definidas por el usuario para lo que garantiza y lo que no garantiza una actualización del documento. Úselo cuando el usuario ejecuta commit-documentor o solicita documentar, sincronizar o verificar documentos para sus confirmaciones recientes.
