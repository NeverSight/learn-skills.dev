Après la validation, vérifiez si la modification nécessite une documentation, rédigez les mises à jour de la documentation pour approbation et, une fois approuvées, publiez-les — dans un référentiel de documentation distinct (branche + PR par défaut) ou dans une arborescence de documents dans ce dépôt pour les projets qui n'ont pas de dépôt de documents distinct. Utilise une configuration validée pour l'emplacement du document, un index de document validé pour maintenir les requêtes bon marché et synchronisées, ainsi que des règles définies par l'utilisateur pour ce qui justifie ou non une mise à jour du document. À utiliser lorsque l'utilisateur exécute commit-documentor ou demande à documenter, synchroniser ou vérifier les documents pour leurs validations récentes.
