После фиксации проверьте, требуется ли для изменения документация, напишите обновления документов для утверждения и после утверждения опубликуйте их — в отдельный репозиторий документации (ветвь + PR по умолчанию) или в дерево документации в этом репозитории для проектов, у которых нет отдельного репозитория документации. Использует зафиксированную конфигурацию для местоположения документа, зафиксированный индекс документа для обеспечения экономичности и синхронизации запросов, а также определяемые пользователем правила для того, что требует и не требует обновления документа. Используйте, когда пользователь запускает commit-documentor или просит задокументировать, синхронизировать или проверить документы на наличие недавних коммитов.
