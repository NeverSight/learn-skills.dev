After committing, check whether the change needs documentation, draft the doc updates for approval, and on approval publish them — to a separate documentation repository (branch + PR by default), or to a docs tree in this repo for projects that have no separate docs repo. Uses a committed config for the doc location, a committed doc index to keep queries cheap and in sync, and user-defined rules for what does and does not warrant a doc update. Use when the user runs commit-documentor, or asks to document, sync, or check docs for their recent commits.
