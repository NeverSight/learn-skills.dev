Dopo aver effettuato il commit, controlla se la modifica necessita di documentazione, redige gli aggiornamenti del documento per l'approvazione e, dopo l'approvazione, pubblicali in un repository di documentazione separato (ramo + PR per impostazione predefinita) o in un albero di documenti in questo repository per progetti che non hanno un repository di documenti separato. Utilizza una configurazione confermata per la posizione del documento, un indice del documento confermato per mantenere le query economiche e sincronizzate e regole definite dall'utente per ciò che garantisce e non garantisce un aggiornamento del documento. Da utilizzare quando l'utente esegue commit-documentor o chiede di documentare, sincronizzare o controllare i documenti per i commit recenti.
