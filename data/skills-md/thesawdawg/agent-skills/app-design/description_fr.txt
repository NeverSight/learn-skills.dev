À utiliser lorsque l'utilisateur souhaite comprendre, auditer ou améliorer une application qui existe déjà. Déclencheurs sur "comprendre cette base de code et l'améliorer", "analyser cette application et trouver des bugs", "auditer et planifier les prochaines étapes", "que dois-je corriger en premier". Cycle de vie axé sur les questions — analyser → vérifier avec l'utilisateur → tester → trier → proposer des améliorations. Utilise la compétence dogfood pour le contrôle qualité d'exécution. Pour un projet qui n’existe pas encore, utilisez plutôt la compétence d’idéateur.
