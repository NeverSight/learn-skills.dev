Verwenden Sie diese Option, wenn der Benutzer eine App-Struktur entwerfen, eine Backend-Architektur auswählen oder Abhängigkeitsempfehlungen erhalten möchte. Auslöser für „Entwerfen der Architektur“, „Strukturieren meines Backends“, „Welche Abhängigkeiten benötige ich“, „Wie soll ich dieses Projekt organisieren“. Nimmt eine Projektbeschreibung (von Ideator oder vom Benutzer bereitgestellt) entgegen und erstellt ein Architekturdokument, eine Ordnerstruktur und Abhängigkeitsempfehlungen. Kann sich bei sicherheitsrelevanten Architekturentscheidungen mit DataSecurer abstimmen.
