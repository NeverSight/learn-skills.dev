Используйте, когда пользователь хочет спроектировать структуру приложения, выбрать серверную архитектуру или получить рекомендации по зависимостям. Триггеры: «спроектировать архитектуру», «структурировать мой бэкэнд», «какие зависимости мне нужны», «как мне организовать этот проект». Берет краткое описание проекта (от Ideator или предоставленное пользователем) и создает документ об архитектуре, структуру папок и рекомендации по зависимостям. Может координировать свои действия с DataSecurer по вопросам архитектуры, чувствительной к безопасности.
