Verwenden Sie diese Option, wenn der Benutzer Daten sichern, ein Bedrohungsmodell für ein System erstellen, Redundanz/Backup planen oder die Architektur auf Sicherheit und Zuverlässigkeit überprüfen möchte. Löst auf „Meine Daten sichern“, „Bedrohungsmodell dies“, „Redundanzplan“, „Datenschutz“, „Meine Architektur auf Sicherheit überprüfen“ und „Was passiert, wenn dies fehlschlägt“ aus. Erstellt eine Projektbeschreibung und/oder ein Architekturdokument und erstellt ein Bedrohungsmodell, einen Sicherheitsplan und eine Redundanzstrategie. Kann sich mit dem Konstrukteur bei Architekturentscheidungen mit Auswirkungen auf die Sicherheit abstimmen.
