سير العمل الشخصي لسوير، والبوابة، والقواعد الهندسية. يُطبق عند كتابة التعليمات البرمجية أو مراجعتها أو إعادة هيكلتها؛ تشغيل أوامر git أو إنشاء التزامات؛ أو البدء بأي مهمة غير تافهة. يفرض مبدأ "عدم الدفع مطلقًا"، والتأليف المشترك فقط عند الموافقة، وطرح 1-5 أسئلة توضيحية قبل العمل، وتصميم OOP جاف/معياري، وتلميحات ونصوص مستندات كاملة، وتعليمات برمجية واضحة ومطولة. يتزاوج مع مهارة أسلوب الترميز للاصطلاحات الخاصة باللغة.
