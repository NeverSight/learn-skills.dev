Le flux de travail personnel, git et les règles d'ingénierie de Sawyer. Appliquer chaque fois que vous écrivez, révisez ou refactorisez du code ; exécuter des commandes git ou générer des commits ; ou démarrer toute tâche non triviale. Applique "jamais git push", co-auteur uniquement sur approbation, posant 1 à 5 questions de clarification avant le travail, conception POO DRY/modulaire, astuces de type et chaînes de documentation complètes, et code propre sur verbeux. S'associe à la compétence de style de codage pour les conventions spécifiques au langage.
