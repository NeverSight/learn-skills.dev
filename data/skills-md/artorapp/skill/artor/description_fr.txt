Utilisez ce texte lorsqu’un utilisateur veut publier, déployer, livrer ou versionner un prototype, un diaporama ou une application web sur Artor, ou dit « publish this », « deploy this prototype », « put this online », « ship a version », « ship a deck », « get me a preview/demo link » ; lorsqu’il veut le partager publiquement (« share this », « send this to my team », « public link ») ; lorsqu’il veut forker ou copier le prototype de quelqu’un (« remix this », « fork this ») ; lorsqu’il demande ce que les évaluateurs ont dit ou souhaite agir sur les commentaires de révision (« what did reviewers say », « address the feedback ») ; lorsqu’il veut restaurer, renommer ou organiser un prototype ou un diaporama ; ou lorsqu’il mentionne l’CLI Artor, .artor/project.json ou une URL de prévisualisation Artor.

Veuillez toujours répondre dans la langue de l’utilisateur.
