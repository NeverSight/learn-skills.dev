Ejecuta el paso de compactación del atelier en la memoria del agente de un repositorio, los diarios de lecciones (.claude/LESSONS.md, .claude/lessons.local.md), .claude/PLAN.md, CLAUDE.md y la carpeta de memoria propia del agente, cuando superan su límite o el usuario pide limpiarlos. Da a cada entrada un veredicto con evidencia (mantener, reforzar, combinar, graduar al portal o documento que lo impone, archivar, mover, eliminar un duplicado, promover), informa antes de escribir nada, aplica solo lo que el usuario aprueba, archiva antes de eliminar y contabiliza cada entrada original después. Úsalo cuando el usuario diga “clean up the lessons”, “LESSONS.md is too long”, “prune / compact / tidy the journal”, “dedupe my memory files”, o acepte la oferta de la habilidad principal del atelier cuando un diario supera su límite. NUNCA lo uses para capturar nuevas lecciones al final de la sesión (la habilidad principal del atelier propone esas), para añadir contenido a CLAUDE.md (la habilidad principal del atelier), para revisar código o un diff (atelier‑review‑me), o para editar un README o CHANGELOG.
