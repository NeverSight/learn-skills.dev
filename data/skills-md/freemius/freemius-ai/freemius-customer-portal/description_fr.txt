Construisez le Portail Client Freemius dans une application React — une interface en libre-service où un utilisateur connecté gère son abonnement (mise à niveau / changement de plan), résilie (avec un coupon de rétention pour réduire le churn), modifie les informations de facturation, et visualise les paiements & télécharge les factures. Utilisez-le lors de l’ajout d’une page « Compte », « Facturation », « Gestion d’abonnement » ou « Factures ». Cela couvre le composant Portail Client du React Starter Kit et le processeur de portail sans tête du SDK (`freemius.customerPortal`) ; la synchronisation serveur du paiement / des droits est `freemius-core`.
