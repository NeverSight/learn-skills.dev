Rétroconcevez le style visuel d'une ou plusieurs images de référence pour en faire une requête réutilisable de génération d'images par IA. À utiliser lorsque l'utilisateur demande d'analyser un style d'image, d'extraire une esthétique, de conserver l'aspect tout en changeant le sujet, ou de produire une invite générale dépourvue de personnages, de textes, de marques ou de détails scénaristiques spécifiques.
