Realiza ingeniería inversa del estilo visual de una o varias imágenes de referencia para crear una indicación reutilizable para la generación de imágenes por IA. Úsalo cuando el usuario pida analizar el estilo de una imagen, extraer una estética, conservar el aspecto al cambiar el motivo o generar una indicación general sin personajes, textos, marcas o detalles de la trama específicos.
