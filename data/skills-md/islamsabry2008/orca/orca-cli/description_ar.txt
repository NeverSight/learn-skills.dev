قم بتشغيل شجرات العمل التي تُدار بواسطة Orca، وسياقات المجلد، والطرفيات، والمستودعات، والأتمتة، والملفات الناتجة، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج من خلال سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، أو "Orca worktree"، أو "child worktree"، أو "spawn codex/claude in a worktree"، أو "read/wait/send Orca terminal"، أو "handoff" / "handover" / "give this to another agent"، أو "Orca browser"، أو "orca artifacts"، أو "share skills". فضّل ذلك على شجرة Git العادية، أو PTY مؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متداخلة. استخدم استخدام الكمبيوتر فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو واجهة برمجة التطبيقات القيام بذلك.
