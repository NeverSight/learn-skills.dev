Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関与する場合は、生の git worktree や臨時の PTY、Computer Use よりもこちらを優先してください。GUI が必要で、CLI、ファイルシステム、API だけでは制御できない可視ウィンドウがある場合にのみ Computer Use を使用します。

常にユーザーの言語で回答してください。
