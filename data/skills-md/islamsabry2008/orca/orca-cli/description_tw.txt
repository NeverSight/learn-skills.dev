透過 `orca` CLI 操作 Orca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、產出物、技能分享、工作樹註解，以及 Orca 內建的瀏覽器。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時，請使用此方式。在涉及 Orca 狀態時，優先使用它，而非原始的 git worktree、即時 PTY 或 Computer Use。僅在需要 GUI 控制的可見視窗、且 CLI、檔案系統或 API 無法完成時才使用 Computer Use。
