Pilote d'abord les modifications de code ; un test ciblé doit échouer pour la raison prévue avant toute modification de production, puis le plus petit changement le fait passer. À utiliser avant d'écrire un code de production pour une nouvelle application, un nouveau projet, une nouvelle fonctionnalité, un nouveau point de terminaison, un changement de comportement ou une correction de bogue, y compris un nouveau travail dans un référentiel vide.
