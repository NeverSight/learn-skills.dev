Teaches beginners and vibe coders how their own project works in plain, simple English. Explains the architecture, what each file and folder does, how the frontend, backend, database and API connect, how a click becomes a request, and what the runtime is (for example Node.js). Gives a transparent code quality score out of 100, security red flags, a prioritized fix list with ready-to-paste prompts, big-tech best practices, and feature ideas, all as structured cards and tables. Use when the user asks to explain, understand, tour, map, review, score, rate or improve their codebase, asks what a file does or what happens when a button is clicked, asks if their app is safe, or mentions vibe teacher.
