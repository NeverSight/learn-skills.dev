Enseña a principiantes y a programadores de vibe cómo funciona su propio proyecto en un inglés sencillo y claro. Explica la arquitectura, lo que hace cada archivo y carpeta, cómo se conectan el frontend, el backend, la base de datos y la API, cómo un clic se convierte en una solicitud y cuál es el runtime (por ejemplo, Node.js). Proporciona una puntuación transparente de calidad de código sobre 100, indicadores de alertas de seguridad, una lista de correcciones priorizadas con prompts listos para copiar, mejores prácticas de las grandes tecnológicas e ideas de funcionalidades, todo como tarjetas y tablas estructuradas. Úsalo cuando el usuario solicite explicar, entender, recorrer, mapear, revisar, puntuar, calificar o mejorar su base de código, pregunte qué hace un archivo o qué ocurre al hacer clic en un botón, pregunte si su aplicación es segura o mencione a vibe teacher.
