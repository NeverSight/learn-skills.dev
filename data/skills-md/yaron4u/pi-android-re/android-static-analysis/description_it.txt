Decompila file Android APK, XAPK, JAR e AAR usando jadx o Fernflower/Vineflower. Esegui il reverse engineering delle app Android, estrai gli endpoint API HTTP (Retrofit, OkHttp, Volley), traccia i flussi di chiamata dall'interfaccia utente al livello di rete, analizza il codice offuscato. Utilizza quando l'utente vuole decompilare, analizzare o fare reverse engineering di pacchetti Android, trovare endpoint API, seguire i flussi di chiamata o eseguire analisi statica sulle applicazioni Android.
