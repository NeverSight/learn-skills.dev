Decompila file Android APK, XAPK, JAR e AAR usando jadx o Fernflower/Vineflower. Effettua il reverse engineering delle app Android, estrai gli endpoint API HTTP (Retrofit, OkHttp, Volley), traccia i flussi di chiamata dall'interfaccia utente allo strato di rete, analizza il codice offuscato. Usa quando l'utente desidera decompilare, analizzare o fare reverse engineering di pacchetti Android, trovare gli endpoint API, seguire i flussi di chiamata o eseguire analisi statica sulle applicazioni Android.
