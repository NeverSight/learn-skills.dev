Descompila archivos Android APK, XAPK, JAR y AAR usando jadx o Fernflower/Vineflower. Realiza ingeniería inversa de aplicaciones Android, extrae los puntos finales de API HTTP (Retrofit, OkHttp, Volley), rastrea los flujos de llamadas desde la UI hasta la capa de red y analiza código ofuscado. Utilízalo cuando el usuario quiera descompilar, analizar o hacer ingeniería inversa de paquetes Android, encontrar puntos finales de API, seguir flujos de llamadas o realizar análisis estático de aplicaciones Android.
