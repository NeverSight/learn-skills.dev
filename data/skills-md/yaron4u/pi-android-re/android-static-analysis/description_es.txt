Descompila archivos Android APK, XAPK, JAR y AAR usando jadx o Fernflower/Vineflower. Ingeniería inversa de aplicaciones Android, extrae los puntos finales de la API HTTP (Retrofit, OkHttp, Volley), rastrea los flujos de llamadas desde la UI hasta la capa de red, analiza el código ofuscado. Úsalo cuando el usuario desee descompilar, analizar o hacer ingeniería inversa de paquetes Android, encontrar puntos finales de la API, seguir flujos de llamadas o realizar análisis estático de aplicaciones Android.
