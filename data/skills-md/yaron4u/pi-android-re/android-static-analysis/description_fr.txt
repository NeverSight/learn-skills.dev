Décompiler les fichiers Android APK, XAPK, JAR et AAR à l'aide de jadx ou Fernflower/Vineflower. Ingénierie inverse des applications Android, extraire les points de terminaison d’API HTTP (Retrofit, OkHttp, Volley), tracer les flux d’appels de l’interface utilisateur à la couche réseau, analyser le code obfusqué. Utiliser lorsque l’utilisateur souhaite décompiler, analyser ou faire de l’ingénierie inverse sur des paquets Android, trouver les points de terminaison d’API, suivre les flux d’appels ou effectuer une analyse statique des applications Android.
