Décompiler les fichiers Android APK, XAPK, JAR et AAR à l’aide de jadx ou Fernflower/Vineflower. Faire de l’ingénierie inverse d’applications Android, extraire les points de terminaison d’API HTTP (Retrofit, OkHttp, Volley), tracer les flux d’appels de l’interface utilisateur à la couche réseau, analyser le code obfusqué. Utiliser lorsque l’utilisateur veut décompiler, analyser ou faire de l’ingénierie inverse sur des paquets Android, trouver les points de terminaison d’API, suivre les flux d’appels ou réaliser une analyse statique des applications Android. Veuillez toujours répondre dans la langue de l’utilisateur.
