jadx 또는 Fernflower/Vineflower를 사용하여 Android APK, XAPK, JAR 및 AAR 파일을 디컴파일합니다. Android 앱을 리버스 엔지니어링하고, HTTP API 엔드포인트(Retrofit, OkHttp, Volley)를 추출하며, UI에서 네트워크 계층까지의 호출 흐름을 추적하고, 난독화된 코드를 분석합니다. 사용자가 디컴파일, 분석 또는 Android 패키지를 리버스 엔지니어링하고, API 엔드포인트를 찾거나, 호출 흐름을 따라가거나, Android 애플리케이션에 대한 정적 분석을 수행하려는 경우에 사용합니다.
