Maneja automatizaciones activadas por eventos para Pipa. Usa esto siempre que el usuario quiera que Pipa ejecute un flujo de trabajo cuando ocurre un evento externo, como la apertura de una pull request en GitHub, la creación de un issue en Linear, un cambio en un canal de Slack, la llegada de un nuevo ticket, o solicite listar, inspeccionar o eliminar disparadores de eventos existentes. Esta habilidad se encarga de la propuesta de disparadores, la confirmación y las llamadas a la API de suscripción a disparadores del gateway.

Por favor, responde siempre en el idioma del usuario.
