Utilisez lorsque l'utilisateur souhaite gérer la configuration de Pipa à travers la configuration du profil, les connecteurs, le cerveau ou la mémoire de l'entreprise, les permissions, les automatisations, les déclencheurs, les boucles ou les audits d'accès. Dirigez la configuration du profil vers pipa-setup et la configuration/état des connecteurs vers pipa-connectors. Ne pas utiliser pour le travail métier ou une action d'application déjà connectée.

Veuillez toujours répondre dans la langue de l'utilisateur.
