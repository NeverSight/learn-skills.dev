Workflow de tests QA pour le navigateur CamoFox — tests systématiques avec capture de la console, détection des erreurs et traçage Playwright. À utiliser lorsque l'utilisateur doit tester une application Web, effectuer une validation QA, réaliser des tests exploratoires ou vérifier le comportement d'une application Web. Les déclencheurs incluent « tester ce site Web », « assurance qualité », « dogfood », « tests exploratoires », « rechercher des bugs » ou toute demande visant à tester systématiquement une application Web.
