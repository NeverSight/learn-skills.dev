Flujo de trabajo de pruebas de control de calidad para el navegador CamoFox: pruebas sistemáticas con captura de consola, detección de errores y seguimiento de Playwright. Utilízalo cuando el usuario necesite probar una aplicación web, realizar una validación de control de calidad, llevar a cabo pruebas exploratorias o verificar el comportamiento de una aplicación web. Los desencadenantes incluyen «probar este sitio web», «control de calidad», «dogfood», «pruebas exploratorias», «encontrar errores» o cualquier solicitud para probar sistemáticamente una aplicación web.
