QS-Test-Workflow für den CamoFox-Browser – systematische Tests mit Konsolenerfassung, Fehlererkennung und Playwright-Tracing. Verwenden Sie diesen Workflow, wenn der Benutzer eine Webanwendung testen, eine QS-Validierung durchführen, explorative Tests durchführen oder das Verhalten einer Webanwendung überprüfen muss. Zu den Triggern gehören „Diese Website testen“, „QS“, „Dogfood“, „Exploratives Testen“, „Bugs finden“ oder jede Anfrage, eine Webanwendung systematisch zu testen.
