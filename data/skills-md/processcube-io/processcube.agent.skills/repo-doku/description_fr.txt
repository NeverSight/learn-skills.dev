Crée ou met à jour la documentation (généralement README.md, et pour les projets plus importants, également DEVELOPMENT.md) directement dans le dépôt source — en tant que source de vérité. Les sources sont la documentation existante, les fichiers de changelog, les commits Git depuis le dernier état de la documentation et le code source. Utilisez cette compétence lorsque l'utilisateur souhaite rédiger la documentation dans un dépôt, mettre à jour le README, documenter de nouvelles fonctionnalités/modifications ou mettre la documentation à jour. Termes déclencheurs : créer la documentation, mettre à jour le README, documenter, mettre la documentation à jour, documenter le changelog.
