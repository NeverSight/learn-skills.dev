Crea o aggiorna la documentazione (di solito README.md, per progetti più grandi anche DEVELOPMENT.md) direttamente nel repository di origine — come fonte della verità. Le fonti sono la documentazione esistente, i file ChangeLog, i commit Git dall'ultimo stato della documentazione e il codice sorgente. Usa questa competenza quando l'utente vuole scrivere la documentazione in un repository, aggiornare il README, documentare nuove funzionalità/modifiche o allineare la documentazione allo stato attuale. Termini di attivazione: creare documentazione, aggiornare README, documentare, allineare documentazione, documentare ChangeLog.
