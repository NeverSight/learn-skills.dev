Construye una animación desde cero, tomando las decisiones en el orden que determina si se siente bien: si debe animarse en absoluto, con qué propósito, qué herramienta, qué propiedades, qué curva y duración, cómo interrumpe y cómo finaliza. Escribe la implementación. Úsalo cuando se solicite animar algo, añadir movimiento, hacer que un componente se sienta vivo o crear una transición. Para criticar movimiento existente utiliza review‑animations; para auditar todo un código base emplea improve‑animations.
