Costruisci animazioni in React Native ed Expo, prendendo le decisioni nell'ordine che determina se risultano corrette — deve animare, su quale thread viene eseguita, quali proprietà, spring o timing, come il gesto passa il controllo, come degrada. Scrivi l'implementazione con Reanimated, Gesture Handler, Expo Router e expo‑haptics. Usala quando animi qualsiasi elemento in un’app Expo, aggiungendo gesture, sheet, transizioni tra schermate, feedback di pressione o haptic, o correggendo movimenti che si bloccano sul dispositivo. Per l’animazione sul web usa `animate`.
