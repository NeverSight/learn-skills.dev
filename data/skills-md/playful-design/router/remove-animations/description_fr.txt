Trouvez les animations dont une interface n’a pas besoin et supprimez‑les — le mouvement lors des actions du clavier, les surfaces à haute fréquence, les données fonctionnelles et la décoration inutile — puis nettoyez ce qu’il reste. Modifie le code, mais seulement pour soustraire ; il n’ajoute jamais ni ne retouche le mouvement. Utilisez‑le quand l’utilisateur dit que l’application « semble lente », « a trop d’animation », « est sur‑animée », veut « diminuer le mouvement », ou demande quelles animations supprimer. Pour repérer les endroits qui devraient être animés, utilisez find‑animation‑opportunities ; pour corriger les animations qui doivent rester, utilisez improve‑animations ou review‑animations.

Veuillez toujours répondre dans la langue de l’utilisateur.
