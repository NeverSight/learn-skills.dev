実際の製品のように見えるフェイクプロダクト UI を、静止イラストまたはカーソル付きアニメーションデモとして作成します。ブラウザやアプリウィンドウ、ダッシュボード、スマートフォン、通知、ターミナル、弁当グリッド、カーソルによるウォークスルーなどを、マーケティングページや機能カード、ドキュメントのヒーローが求める形でフレーム、マスク、トリミングします。誰かが偽の UI やモックアップ UI、プロダクトデモやウォークスルーアニメーション、アプリのヒーローや機能カードのイラスト、洗練されたマーケティングサイト風のプロダクトショット、インターフェース上で動くアニメーションカーソルを求めたときに、たとえ「フェイク UI」という言葉が出なくても使用してください。React とプレーン CSS を使用します。
