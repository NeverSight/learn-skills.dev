웹 애니메이션을 프레임 예산 안에 유지하세요 — 합성 전용 속성만 애니메이션하고, 페이지가 바쁠 때는 모션을 메인 스레드에서 벗어나게 하며, 프레임이 떨어지는 경우 원인을 찾습니다. 레이아웃·페인팅·합성 파이프라인, 더 저렴한 속성 교체, CSS vs WAAPI vs requestAnimationFrame, Motion의 하드웨어 가속 경로, 프레임당 React 재렌더링, 상속된 CSS 변수 재계산, 블러 비용, 그리고 `will-change`가 실제로 도움이 되는 경우를 다룹니다. 애니메이션이 끊기고, 거칠거나, 버벅거리거나 프레임이 떨어질 때; 어떤 속성을 애니메이션할지 선택할 때; 성능 관점에서 CSS와 JavaScript 애니메이션 중 어느 쪽을 선택할지 결정할 때; 혹은 `will-change`나 GPU 레이어를 사용할 때 활용하세요. 이징, 지속 시간, 혹은 애니메이션 자체를 할지 말지를 선택할 때는 `animate`를, 전체 모션을 검토할 때는 `review‑animations`를 사용합니다.
