Mantieni le animazioni web entro il budget di fotogrammi — anima solo proprietà composite, tieni il movimento fuori dal thread principale quando la pagina è occupata e individua la causa quando un'animazione perde fotogrammi. Copre la pipeline layout/pittura/composite, gli scambi di proprietà a basso costo, CSS vs WAAPI vs requestAnimationFrame, il percorso hardware‑accelerato di Motion, il ri‑rendering di React per frame, il ricalcolo delle variabili CSS ereditate, il costo del blur e quando `will-change` è davvero utile. Usalo quando un'animazione è traballante, scattosa, si blocca o perde fotogrammi; quando scegli quale proprietà animare; quando decidi tra animazione CSS e JS per motivi di prestazioni; o quando ricorri a `will-change` o ai layer GPU. Per scegliere easing, durata o se animare affatto usa **animate**; per rivedere il motion nel suo insieme usa **review-animations**.
