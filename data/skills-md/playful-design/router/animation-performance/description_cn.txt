将网页动画控制在帧预算之内——仅对可合成的属性进行动画，在页面繁忙时让动画脱离主线程，并在动画掉帧时找出原因。涵盖布局/绘制/合成流水线、更低成本的属性切换、CSS 与 WAAPI 与 requestAnimationFrame 的比较、Motion 的硬件加速路径、React 每帧的重新渲染、继承的 CSS 变量重新计算、模糊的开销，以及何时 `will-change` 真正起作用。适用于动画卡顿、跳动、停滞或掉帧时；在选择动画属性时；在基于性能考虑在 CSS 与 JS 动画之间做决定时；或在考虑使用 `will-change` 或 GPU 图层时。选择缓动、时长或是否进行动画时使用 animate；整体审视运动时使用 review-animations。
