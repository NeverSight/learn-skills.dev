احتفظ برسوم الويب ضمن ميزانية الإطار — حرّك خصائص التركيب فقط، أبقِ الحركة خارج الخيط الرئيسي عندما تكون الصفحة مشغولة، وابحث عن السبب عندما تُسقط الرسوم الإطارات. يغطي خط أنابيب التخطيط/الطلاء/التركيب، تبادلات الخصائص الأرخص، CSS مقابل WAAPI مقابل requestAnimationFrame، المسار المعجل بالأجهزة في Motion، إعادة渲染 React لكل إطار، إعادة حساب متغيرات CSS الموروثة، تكلفة الضبابية، ومتى يكون `will-change` مفيدًا فعلًا. استخدمه عندما تكون الرسوم متقطعة، غير سلسة، تتعطّل، أو تُسقط إطارات؛ عند اختيار أي خاصية تحريك؛ عند اتخاذ قرار بين الرسوم بـ CSS أو JavaScript من منظور الأداء؛ أو عند اللجوء إلى `will-change` أو طبقات GPU. لاختيار التسهيل، المدة، أو ما إذا كان ينبغي التحريك على الإطلاق استخدم animate؛ لمراجعة الحركة ككل استخدم review-animations.
