Mantén las animaciones web dentro del presupuesto de fotogramas: anima solo propiedades de composición, mantén el movimiento fuera del hilo principal cuando la página está ocupada y encuentra la causa cuando una animación pierde fotogramas. Cubre la cadena de procesamiento layout/pintado/composición, intercambios de propiedades más baratos, CSS vs WAAPI vs requestAnimationFrame, la ruta de aceleración por hardware de Motion, el re‑renderizado de React por fotograma, la recalculación de variables CSS heredadas, el costo del blur y cuándo `will-change` realmente ayuda. Úsalo cuando una animación sea temblorosa, irregular, tartamudeante o pierda fotogramas; al elegir qué propiedad animar; al decidir entre animación CSS y JavaScript por motivos de rendimiento; o al recurrir a `will-change` o capas GPU. Para elegir easing, duración o si animar en absoluto, usa `animate`; para revisar el motion en su totalidad, usa `review-animations`.
