Оценить анимационный и движковый код в кодовой базе в роли старшего советника по движению, затем создать приоритетный аудит и самостоятельные планы реализации для других агентов (или более дешевых моделей) для исполнения. Только чтение исходного кода — планирует улучшения, но не применяет их. Используйте, когда пользователь просит «улучшить анимацию», «аудировать движение», «сделать приложение более приятным» или хочет дорожную карту исправлений анимации, а не обзор одного дифа.
