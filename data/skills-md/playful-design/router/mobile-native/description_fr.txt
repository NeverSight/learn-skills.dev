Faites en sorte qu’une application web donne l’impression d’être native sur un téléphone — les petits correctifs CSS et méta‑tags qui distinguent « un site web dans un navigateur » de quelque chose qui semble installé. Cela couvre les états de survol persistants, les flashs de mise en évidence au toucher, le bug du 100 vh, les champs qui zooment la page, les tapotements tardifs, le pull‑to‑refresh qui détourne le défilement, le contenu sous l’encoche, la sélection du texte du bouton lors d’un appui long, les carrousels qui défilent dans la mauvaise direction, les barres d’état incohérentes, et la règle de tester sur du matériel réel. À utiliser lorsqu’une application web est développée ou revue sur mobile, lorsqu’un élément « fonctionne dans Chrome mais semble faux sur mon téléphone », lors de la création d’une PWA, d’un bottom sheet, d’un carrousel, d’une mise en page plein écran ou de toute interaction tactile. Pour le mouvement, utilisez **animate** ; pour React Native, utilisez **animate‑expo**.
