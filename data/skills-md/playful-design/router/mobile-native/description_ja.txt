Web アプリをスマートフォン上でネイティブに感じさせる――「ブラウザ内のウェブサイト」と、まるでインストールされたもののような感覚を分ける小さな CSS と meta タグの調整です。スティッキーなホバー状態、タップ時のハイライトがちらつく問題、100vh バグ、入力フィールドがページをズームしてしまう現象、タップ遅延、プル・トゥ・リフレッシュがスクロールを奪う、ノッチの下にコンテンツが隠れる、長押しでボタンテキストが選択される、カルーセルが逆方向にスクロールする、ステータスバーが一致しない、そして実機でテストするという原則を網羅しています。モバイル向けに Web アプリを構築・レビューする際、"Chrome では動くけどスマホでは違和感がある" といったケース、PWA、ボトムシート、カルーセル、フルスクリーンレイアウト、またはあらゆるタッチ操作を作るときに使用してください。モーション自体には animate を、React Native には animate‑expo を使用してください。
