Eine Web‑App auf dem Telefon nativ wirken lassen – die kleinen CSS‑ und Meta‑Tag‑Fixes, die „eine Website im Browser“ von etwas unterscheiden, das sich wie installiert anfühlt. Behandelt Haft‑Hover‑Zustände, Tap‑Highlight‑Flashes, den 100‑vh‑Bug, Eingaben, die die Seite hereinzoomen, verzögerte Taps, Pull‑to‑Refresh, das das Scrollen übernimmt, Inhalte unter der Notch, Long‑Press‑Auswahl von Button‑Text, Karussells, die in die falsche Richtung scrollen, nicht passende Status‑Bars und die Regel, dass du auf echter Hardware testest. Verwenden, wenn eine Web‑App für mobile Geräte gebaut oder geprüft wird, wenn etwas „in Chrome funktioniert, aber auf meinem Telefon falsch wirkt“, beim Erstellen einer PWA, eines Bottom‑Sheets, eines Karussells, eines Vollbild‑Layouts oder jeder Touch‑Interaktion. Für Motion selbst „animate“ verwenden; für React Native „animate‑expo“.
