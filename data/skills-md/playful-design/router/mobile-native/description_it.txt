Rendi un'app web simile a un'app nativa su telefono — le piccole correzioni CSS e dei meta‑tag che separano “un sito web nel browser” da qualcosa che sembra installato. Include stati hover persistenti, flash di evidenziazione al tocco, il bug dei 100 vh, input che ingrandiscono la pagina, tocchi laggosi, il pull‑to‑refresh che dirotta lo scorrimento, contenuti sotto il notch, selezione del testo del pulsante con pressione prolungata, caroselli che scorrono nella direzione sbagliata, barre di stato non corrispondenti e la regola di testare su hardware reale. Usalo quando un'app web viene sviluppata o valutata su mobile, quando qualcosa “funziona in Chrome ma sembra strano sul mio telefono”, quando si costruisce una PWA, un foglio laterale, un carosello, un layout a schermo intero o qualsiasi interazione tattile. Per le animazioni usa animate; per React Native usa animate‑expo.
