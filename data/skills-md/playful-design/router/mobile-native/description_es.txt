Haz que una aplicación web se sienta nativa en un teléfono — los pequeños ajustes de CSS y metaetiquetas que separan “un sitio web en un navegador” de algo que parece instalado. Incluye estados hover persistentes, destellos de resaltado al tocar, el error de 100 vh, inputs que hacen zoom en la página, toques con retraso, pull‑to‑refresh secuestrando el desplazamiento, contenido bajo la muesca, pulsación larga que selecciona el texto del botón, carruseles que se desplazan en la dirección equivocada, barras de estado desincronizadas y la regla de probar en hardware real. Úsalo cuando se construye o revisa una web app en móvil, cuando algo “funciona en Chrome pero se siente mal en mi teléfono”, al crear una PWA, una hoja inferior, un carrusel, un diseño a pantalla completa o cualquier interacción táctil. Para el movimiento usa animate; para React Native usa animate‑expo.
