Verifies GDScript and scenes with the Godot 4 command line instead of trusting that code looks right - parse-checking scripts with --check-only, running a scene headless with --quit-after, writing a SceneTree test script with an exit code, and reading the output, because Godot exits with code 0 even when scripts fail at runtime. Use after writing or editing any GDScript, .tscn or project.godot, before telling the user a change works, and when a fix needs evidence from the engine rather than from reading code.
