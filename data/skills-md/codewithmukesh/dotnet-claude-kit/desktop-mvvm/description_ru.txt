MVVM для настольных приложений .NET (WPF, Avalonia, WinForms, MAUI) с CommunityToolkit.Mvvm 8.4+ генераторами кода: частичные свойства [ObservableProperty], асинхронные команды [RelayCommand], Generic Host + DI, диспетчинг UI‑потока, навигация, обмен сообщениями и тестируемые модели представления. Загружать, когда пользователь упоминает «MVVM», «ViewModel», «WPF», «desktop app», «ObservableProperty», «RelayCommand», «ICommand», «INotifyPropertyChanged», «Dispatcher» или «UI thread».
