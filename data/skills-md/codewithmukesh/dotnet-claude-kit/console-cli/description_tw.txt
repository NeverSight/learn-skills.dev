.NET 10 上的控制台應用程式與 CLI 工具：System.CommandLine 2.x（RootCommand、Option<T>、SetAction、InvokeAsync）、在控制台應用程式中使用通用主機 + DI、退出代碼、stdout/stderr 規範、Ctrl+C 取消、交互式與管道使用、dotnet 工具封裝，以及 `dotnet run app.cs` 基於檔案的應用程式。當使用者提及「console app」「CLI」「command line」「System.CommandLine」「dotnet tool」「exit code」「stdin」「args parsing」或「file-based app」時載入。
