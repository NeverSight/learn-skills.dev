Descubre de forma proactiva los proyectos del ecosistema Binance Agent ID / Agentic Wallet dentro de Grok Bot, combinando el sitio web oficial y la evidencia disponible públicamente en la cadena para estudiar el juego, los costos, los productos y los riesgos clave, y proporcionar explicaciones concisas directamente en el chat. Se utiliza para el descubrimiento de una sola vez, la investigación de proyectos específicos, las preguntas de seguimiento y el descubrimiento programado configurado por el usuario; no realiza operaciones de billetera o transacción.
