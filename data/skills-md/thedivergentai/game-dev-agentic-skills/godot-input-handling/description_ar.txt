أنماط متخصصة لمعالجة الإدخال تغطي إجراءات InputMap ومعالجة InputEvent ودعم أجهزة التحكم وإعادة التعيين ومناطق الفقد والخرطوشة الإدخالية. استخدمها عند إعداد تحكمات اللاعب، أو تنفيذ أنظمة الإدخال، أو إضافة ميزات لوحة التحكم/إمكانية الوصول. الكلمات المفتاحية: InputMap، InputEvent، لوحة التحكم، جهاز التحكم، إعادة التعيين، منطقة الفقد، مخزن الإدخال.
