Modelli esperti per la gestione degli input che coprono le azioni InputMap, l'elaborazione di InputEvent, il supporto al controller, il ri‑mappamento, le zone morte e il buffering degli input. Da usare quando si configurano i controlli del giocatore, si implementano sistemi di input o si aggiungono funzionalità di gamepad/accessibilità. Parole chiave: InputMap, InputEvent, gamepad, controller, ri‑mappamento, zona morta, buffer di input.
