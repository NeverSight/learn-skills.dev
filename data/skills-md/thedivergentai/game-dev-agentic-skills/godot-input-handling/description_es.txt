Patrones avanzados para la gestión de entrada que cubren acciones de InputMap, procesamiento de InputEvent, soporte de controlador, reasignación, zonas muertas y almacenamiento en búfer de entrada. Úsalo al configurar los controles del jugador, implementar sistemas de entrada o añadir características de gamepad/accesibilidad. Palabras clave: InputMap, InputEvent, gamepad, controller, rebinding, deadzone, input buffer.
