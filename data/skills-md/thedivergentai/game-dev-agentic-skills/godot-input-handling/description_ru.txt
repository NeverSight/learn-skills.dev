Экспертные шаблоны обработки ввода, охватывающие действия InputMap, обработку InputEvent, поддержку контроллеров, переназначение, «мертвыe зоны» и буферизацию ввода. Используйте при настройке управления игрока, реализации систем ввода или добавлении функций геймпада/доступности. Ключевые слова: InputMap, InputEvent, gamepad, controller, rebinding, deadzone, input buffer.
