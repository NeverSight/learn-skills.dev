Plan directeur expert pour les jeux en monde ouvert incluant le streaming basé sur des chunks (chargement/déchargement dynamique des régions), l'origine flottante (prévenir le jitter de précision au-delà de 5000 unités), HLOD (LOD hiérarchique pour les maillages lointains), l'état persistant (suivre les changements d'entités dans les chunks déchargés), les systèmes de découverte de POI (boussole, marqueurs), et le chargement multithread (éviter les saccades). À utiliser pour les RPG, les sandboxes ou les jeux d'exploration. Mots‑clés déclencheurs : open_world, chunk_streaming, floating_origin, HLOD, persistent_state, POI_discovery, threaded_loading.
