モジュラー型 Godot 4.7+ CLI 自動化とヘッドレスビルドオーケストレーション向けのエキスパートレベルツールキットです。次の場合に使用します：(1) 複雑なシーンツリーや UI レイアウトをプログラムで構築する、(2) エキスパート向け 3D アセットパイプラインを自動化する（glTF → コリジョン）、(3) ヘッドレス環境で手続き的ジオメトリを最適化する（CSG → 静的メッシュ）、または (4) 本番レベルの CI/CD パイプラインを構築する。カスタムエンジンの場所を指定するには GODOT_PATH 環境変数を設定してください。キーワード：Godot CLI、ヘッドレス、CI、エクスポート、ビルダー、4.7。
