Toolkit di livello esperto per l'automazione modulare CLI di Godot 4.7+ e l'orchestrazione di build headless. Da usare quando serve: (1) Costruire alberi di scena complessi o layout UI programmaticamente, (2) Automatizzare pipeline di asset 3D avanzate (glTF → Collision), (3) Ottimizzare geometria procedurale in modalità headless (CSG → Mesh statico), o (4) Progettare pipeline CI/CD di livello produzione. Impostare la variabile d'ambiente GODOT_PATH per la posizione personalizzata del motore. Parole chiave: Godot CLI, headless, CI, export, builder, 4.7.
