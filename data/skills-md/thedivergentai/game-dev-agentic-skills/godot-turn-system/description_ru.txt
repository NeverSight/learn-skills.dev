Экспертный план для пошаговых боевых систем с порядком ходов, очками действий, управлением фазами и таймлайн‑системами для стратегических/РПГ‑игр. Охватывает инициативу, основанную на скорости, прерывания и одновременные ходы. Применяется при реализации пошаговых боёв или тактических систем. Ключевые слова: пошаговый, инициатива, очки действий, фаза, раунд, порядок ходов, бой.
