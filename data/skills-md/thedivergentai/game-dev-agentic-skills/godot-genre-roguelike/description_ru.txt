Экспертный план для рогаликов, включающий процедурную генерацию (метод Уокера, BSP‑комнаты), перманентную смерть с мета‑прогрессией (постоянные разблокировки), разделение состояния пробега и мета‑состояния, генератор случайных чисел с сидом (делимые пробеги), системы лута/реликвий (модификаторы на основе хуков) и масштабирование сложности (прогрессия по этажам). Применимо для dungeon crawler‑ов, экшн‑рогаликов или рогулитов. Ключевые слова‑триггеры: roguelike, procedural_generation, permadeath, meta_progression, seeded_RNG, relic_system, run_state.
