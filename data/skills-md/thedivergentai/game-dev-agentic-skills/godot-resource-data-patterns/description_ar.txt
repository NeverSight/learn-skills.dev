مخطط خبير لتصميم موجه للبيانات باستخدام فئات Resource/RefCounted (قواعد بيانات العناصر، إحصاءات الشخصيات، هياكل بيانات قابلة لإعادة الاستخدام). يغطي المصفوفات ذات النوع، التسلسل، الموارد المتداخلة، والتخزين المؤقت للموارد. يُستخدم عند تنفيذ أنظمة البيانات أو قواعد بيانات الجرد/الإحصاءات/الحوار. الكلمات المفتاحية: Resource، RefCounted، ItemData، CharacterStats، قاعدة بيانات، تسلسل، @export، مصفوفات ذات النوع.
