Schema esperto per la progettazione orientata ai dati usando classi Resource/RefCounted (database di oggetti, statistiche dei personaggi, strutture dati riutilizzabili). Copre array tipizzati, serializzazione, risorse nidificate e caching delle risorse. Da utilizzare quando si implementano sistemi di dati O database di inventario/statistiche/dialoghi. Parole chiave: Resource, RefCounted, ItemData, CharacterStats, database, serializzazione, @export, array tipizzati.
