Экспертный план разработки, ориентированной на данные, с использованием классов Resource/RefCounted (базы данных предметов, характеристики персонажей, переиспользуемые структуры данных). Охватывает типизированные массивы, сериализацию, вложенные ресурсы и кэширование ресурсов. Используйте при реализации систем данных ИЛИ баз данных инвентаря/характеристик/диалогов. Ключевые слова: Resource, RefCounted, ItemData, CharacterStats, database, serialization, @export, typed arrays.
