Plan d'expert pour la conception orientée données utilisant les classes Resource/RefCounted (bases de données d’objets, statistiques de personnages, structures de données réutilisables). Couvre les tableaux typés, la sérialisation, les ressources imbriquées et la mise en cache des ressources. À utiliser lors de la mise en œuvre de systèmes de données OU de bases de données d’inventaire/statistiques/dialogues. Mots‑clés : Resource, RefCounted, ItemData, CharacterStats, database, serialization, @export, typed arrays.
