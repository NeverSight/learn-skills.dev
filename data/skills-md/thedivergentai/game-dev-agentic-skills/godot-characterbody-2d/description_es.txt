Patrones avanzados para CharacterBody2D que incluyen movimiento de plataformas (tiempo de coyote, buffering de salto, altura de salto variable), movimiento top‑down (8 direcciones, controles tipo tanque), manejo de colisiones, plataformas de un solo sentido y máquinas de estados. Úsalo para personajes controlados por el jugador, NPCs o enemigos. Palabras clave de activación: CharacterBody2D, move_and_slide, is_on_floor, coyote_time, jump_buffer, velocity, get_slide_collision, one_way_platforms, state_machine.
