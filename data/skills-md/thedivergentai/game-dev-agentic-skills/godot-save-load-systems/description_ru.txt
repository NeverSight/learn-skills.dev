Экспертный план для систем сохранения/загрузки с использованием сериализации JSON/бинарных данных, паттерна группы PERSIST, версионирования и миграции. Охватывает прогресс игрока, настройки, постоянство состояния игры и восстановление после ошибок. Используйте при реализации систем сохранения ИЛИ постоянства данных. Ключевые слова: save, load, JSON, FileAccess, user://, сериализация, миграция версий, группа PERSIST.
