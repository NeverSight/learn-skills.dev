Plan détaillé d'expert pour les hôtes multijoueurs dédiés / sans interface : ENet/DTLS, validation d'autorité, décodage sécurisé des paquets, transfert du matchmaker et télémétrie de santé. À utiliser lors de la construction de serveurs d'autorité, d'hôtes --headless, ou pour renforcer le réseau de l'hôte. Mots‑clés : serveur dédié, headless, ENet, DTLS, autorité, safe_packet_decoder, hôte multijoueur, WebSocketMultiplayerPeer.
