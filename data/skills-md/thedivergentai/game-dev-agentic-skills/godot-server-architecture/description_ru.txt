Экспертный план для выделенных / безголовых хостов многопользовательских игр: ENet/DTLS, проверка полномочий, безопасная декодировка пакетов, передача матчмейкера и телеметрия состояния. Используйте при создании авторитетных серверов, безголовых хостов или усилении сетевого взаимодействия хоста. Ключевые слова: выделенный сервер, безголовый, ENet, DTLS, полномочия, safe_packet_decoder, хост многопользовательской игры, WebSocketMultiplayerPeer.
