Экспертный план для игр в жанре tower defense (Bloons TD, Kingdom Rush, Fieldrunners), охватывающий управление волнами, логику выбора целей для башен, алгоритмы построения путей, баланс экономики и механику создания лабиринтов. Используйте при разработке TD, защиты по полосе или стратегий размещения башен. Ключевые слова: tower defense, wave spawner, pathfinding, targeting priority, mazing, NavigationServer baking.
