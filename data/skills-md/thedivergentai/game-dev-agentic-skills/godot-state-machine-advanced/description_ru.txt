Экспертный шаблон для иерархических конечных автоматов (HSM) и автоматов с магазинной памятью для сложных поведений ИИ/персонажей. Охватывает стеки состояний, под‑состояния, проверку переходов и передачу контекста состояния. Применяется, когда базовых конечных автоматов недостаточно ИЛИ при реализации многоуровневого ИИ. Ключевые слова: конечный автомат, HSM, иерархический, автомат с магазинной памятью, стек состояний, FSM, поведение ИИ.
