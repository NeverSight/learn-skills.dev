Экспертные шаблоны для AnimationTree, включающие переходы StateMachine, BlendSpace2D для направленного движения, BlendTree для слоистых анимаций, корневое движение, условия переходов, выражения advance и под‑состояния машины состояний. Используйте для сложных систем анимации персонажей с смешиванием движений и управлением состояниями. Ключевые слова‑триггеры: AnimationTree, AnimationNodeStateMachine, BlendSpace2D, BlendSpace1D, BlendTree, transition_request, blend_position, advance_expression, AnimationNodeAdd2, AnimationNodeBlend2, root_motion.
