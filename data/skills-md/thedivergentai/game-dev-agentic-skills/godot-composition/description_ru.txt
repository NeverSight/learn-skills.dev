Экспертные архитектурные стандарты для создания масштабируемых ИГР в Godot (RPG, платформеры, шутеры) с использованием паттерна композиции (Entity-Component). Применяйте при проектировании контроллеров игрока, NPC, врагов, оружия или сложных игровых систем. Обеспечивает отношения «Has-A» для игровых сущностей. Ключевые слова‑триггеры: Entity-Component, ECS, Gameplay, Actors, NPCs, Enemies, Weapons, Hitboxes, Game Loop, Level Design.
