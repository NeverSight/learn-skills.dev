Modelli esperti per la fisica 2D di Godot, includendo layer/mask di collisione, trigger Area2D, raycasting e query PhysicsDirectSpaceState2D. Da utilizzare quando si implementa il rilevamento delle collisioni, zone di trigger, sistemi di line‑of‑sight o query fisiche manuali. Parole chiave dei trigger: CollisionShape2D, CollisionPolygon2D, collision_layer, collision_mask, set_collision_layer_value, set_collision_mask_value, Area2D, body_entered, body_exited, RayCast2D, force_raycast_update, PhysicsPointQueryParameters2D, PhysicsShapeQueryParameters2D, direct_space_state, move_and_collide, move_and_slide.
