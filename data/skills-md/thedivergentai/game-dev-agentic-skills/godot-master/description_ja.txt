プロフェッショナルな Godot 4.7+ ゲームおよびアプリケーション開発のための統合エキスパートライブラリ。アーキテクチャワークフロー、アンチパターンカタログ、パフォーマンス予算、サーバー API パターンを通じて 92 のドメインスキルをオーケストレーションします。使用シーン: (1) 新しい Godot プロジェクトを開始する時、(2) ゲームまたはアプリのアーキテクチャを設計する時、(3) エンティティ/コンポーネントシステムを構築する時、(4) パフォーマンスまたは物理の問題をデバッグする時、(5) 2D と 3D のアプローチを選択する時、(6) マルチプレイヤーを実装する時、(7) 描画コールやスクリプト実行時間を最適化する時、(8) プラットフォーム間でポーティングする時、(9) 4.6 から 4.7 へ移行する時。すべての Godot 開発タスクの主要エントリーポイント。キーワード: Godot 4.7、AreaLight3D、HDR、Asset Store、godot-master。
