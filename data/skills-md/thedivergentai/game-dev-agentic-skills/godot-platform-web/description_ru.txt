Экспертный план экспорта HTML5/веб с учётом совместимости (WebGL 2.0): JavaScriptBridge, обёртка localStorage, собственные загрузочные оболочки, хосты COOP/COEP, относительные пути, beforeunload, пауза при потере видимости и оптимизация размеров. WebGPU не учитывается. Ключевые слова: web, HTML5, WebGL, совместимость, JavaScriptBridge, localStorage, COOP, COEP, canvas, API браузера.
