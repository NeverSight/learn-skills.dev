Schema esperto per la generazione procedurale di contenuti (dungeon, terreni, bottini, livelli) utilizzando FastNoiseLite, camminate casuali, alberi BSP, Wave Function Collapse e randomizzazione con seme. Da usare nella creazione di roguelike, giochi sandbox o contenuti dinamici. Parole chiave: procedurale, generazione, FastNoiseLite, rumore Perlin, BSP, camminata dell'ubriaco, Wave Function Collapse, semina.
