Экспертный план создания процедурного контента (подземелья, ландшафты, лут, уровни) с использованием FastNoiseLite, случайных блужданий, BSP‑деревьев, Wave Function Collapse и посева случайных чисел. Применяйте при создании рогаликов, песочниц или динамического контента. Ключевые слова: процедурный, генерация, FastNoiseLite, шум Перлина, BSP, блуждание пьяницы, Wave Function Collapse, посев.
