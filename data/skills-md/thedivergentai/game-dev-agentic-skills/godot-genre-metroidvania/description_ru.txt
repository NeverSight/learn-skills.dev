Экспертный план для метроидваний, включающий исследование, открываемое способностями (замки/ключи), дизайн взаимосвязанного мира (возврат с короткими путями), отслеживание постоянного состояния (коллекционные предметы, победы над боссами), переходы между комнатами (бесшовная загрузка), системы карт (раскрытие по сетке) и универсальность способностей (бой + перемещение). Используйте для исследовательских платформеров или экшен‑приключенческих игр. Триггерные ключевые слова: metroidvania, ability_gating, interconnected_world, backtracking, map_system, persistent_state, room_transition, soft_locks.
