GDAS-reader trasforma un albero sorgente, un bundle web, una cartella di asset, un modulo WASM o un file PE/ELF in un registro delle evidenze per godot-rea o bevy-rea. Usalo prima di emettere una ricostruzione Godot o Bevy. Parole chiave: GDAS-reader, registro, read_artifact, ricostruzione, evidenza.
