Экспертный план для головоломок, включающий системы отката (шаблон Command для обратного изменения состояния), сеточную логику (механика в стиле Сокобана), невербальные обучающие уровни (обучение через дизайн уровней), проверку условий победы, управление состоянием и визуальную обратную связь (мгновенное подтверждение допустимых ходов). Используется для логических головоломок, физических головоломок или игр типа «три в ряд». Ключевые слова‑триггеры: puzzle_game, undo_system, command_pattern, grid_logic, non_verbal_tutorial, state_management.
