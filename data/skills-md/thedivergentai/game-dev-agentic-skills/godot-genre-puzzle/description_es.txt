Plan maestro experto para juegos de puzzles que incluye sistemas de deshacer (patrón Command para revertir el estado), lógica basada en cuadrícula (mecánicas estilo Sokoban), tutoriales no verbales (enseñar mediante el diseño de niveles), verificación de condiciones de victoria, gestión de estado y retroalimentación visual (confirmación instantánea de movimientos válidos). Úsalo para puzzles lógicos, puzzles de física o juegos de match‑3. Palabras clave activadoras: puzzle_game, undo_system, command_pattern, grid_logic, non_verbal_tutorial, state_management.
