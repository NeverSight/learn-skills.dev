مخطط خبير لـ RichTextLabel مع تنسيق BBCode (عريض، مائل، ألوان، صور، روابط قابلة للنقر) وتأثيرات مخصصة. يغطي علامات meta، تظليل RichTextEffect، والمحتوى الديناميكي. يُستخدم عند تنفيذ أنظمة الحوارات أو النصوص المنسقة. الكلمات المفتاحية: RichTextLabel، BBCode، [b]، [color]، [url]، meta_clicked، RichTextEffect، الحوار.
