Patrones expertos para economías de juego que incluyen gestión de moneda (multimoneda, sistema de billetera), sistemas de tienda (precios de compra/venta, límites de stock), precios dinámicos (oferta/demanda), tablas de botín (caídas ponderadas, niveles de rareza) y equilibrio económico (control de inflación, sumideros de moneda). Uso para RPG, juegos de comercio o sistemas de gestión de recursos. Palabras clave de activación: EconomyManager, currency, shop_item, loot_table, dynamic_pricing, buy_sell_spread, currency_sink, inflation, item_rarity.
