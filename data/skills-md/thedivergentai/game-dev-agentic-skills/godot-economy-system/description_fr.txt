Modèles experts pour les économies de jeu, incluant la gestion de la monnaie (multimonnaie, système de portefeuille), les systèmes de boutique (prix d’achat/vente, limites de stock), la tarification dynamique (offre/demande), les tables de butin (butins pondérés, niveaux de rareté) et l’équilibre économique (contrôle de l’inflation, puits de monnaie). À utiliser pour les RPG, les jeux de commerce ou les systèmes de gestion de ressources. Mots‑clés déclencheurs : EconomyManager, currency, shop_item, loot_table, dynamic_pricing, buy_sell_spread, currency_sink, inflation, item_rarity.
