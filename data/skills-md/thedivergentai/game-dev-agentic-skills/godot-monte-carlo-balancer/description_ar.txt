استخدمه عند تدقيق أو إعادة معايرة توازن اللعبة: أنشئ مختبر توازن يعتمد على مونت كارلو باستخدام Rust + rayon يقوم باستخراج بيانات اللعبة الحية، محاكاة أساليب لعب اللاعبين (AFK→محترف)، وإصدار أحكام حول معدل الفوز/الاقتصاد مع فواصل ثقة، وضبط المعلمات بالقوة. يتم التفعيل عند وجود مستويات غير عادلة، متاجر غير قابلة للوصول، استغلال الزراعة، منحدرات منحنى الفائدة، إعادة معايرة ما بعد المحتوى، أو اختلافات JSON لتوازن CI. الكلمات المفتاحية: مختبر التوازن، مونت كارلو، معدل الفوز، منحنى الصعوبة، مسار الاقتصاد، محاكاة أسلوب اللعب، استخراج الموارد، محلل GDScript، ضبط بالقوة.
