مخطط خبير لتصميم سمات واجهة المستخدم باستخدام موارد Theme، وStyleBoxes، وخطوط مخصصة، وتجاوزات السمات لضمان تنسيق بصري موحد. يغطي StyleBoxFlat/Texture، وراثة السمات، التبديل الديناميكي للسمات، وتنوع الخطوط. يُستخدم عند تنفيذ تنسيق موحد لواجهة المستخدم أو دعم عدة سمات. الكلمات المفتاحية: Theme، StyleBox، StyleBoxFlat، add_theme_override، font، theme inheritance، dark mode.
