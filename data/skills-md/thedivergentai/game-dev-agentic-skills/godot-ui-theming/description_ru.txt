Экспертный план для UI‑тем, использующий ресурсы Theme, StyleBox, пользовательские шрифты и переопределения тем для согласованного визуального оформления. Охватывает StyleBoxFlat/Texture, наследование тем, динамическую смену тем и варианты шрифтов. Применяется при реализации согласованного UI‑оформления ИЛИ поддержке нескольких тем. Ключевые слова: Theme, StyleBox, StyleBoxFlat, add_theme_override, font, наследование тем, тёмный режим.
