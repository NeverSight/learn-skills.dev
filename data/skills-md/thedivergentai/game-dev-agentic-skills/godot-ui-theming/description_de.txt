Expertenplan für UI-Themen unter Verwendung von Theme‑Ressourcen, StyleBoxes, benutzerdefinierten Schriftarten und Theme‑Overrides für ein konsistentes visuelles Styling. Deckt StyleBoxFlat/Texture, Theme‑Vererbung, dynamischen Theme‑Wechsel und Schriftvarianten ab. Verwenden, wenn ein einheitliches UI‑Styling implementiert ODER mehrere Themes unterstützt werden sollen. Schlüsselwörter: Theme, StyleBox, StyleBoxFlat, add_theme_override, Schrift, Theme‑Vererbung, Dark Mode.
