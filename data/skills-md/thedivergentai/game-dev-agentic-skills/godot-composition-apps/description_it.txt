Standard architetturali esperti per applicazioni Godot scalabili, strumenti, EditorPlugin e UI pesanti di Control usando la composizione (Has‑A Orchestrator + componenti). Da utilizzare quando si costruiscono dashboard, finestre di strumenti, moduli, pannelli impostazioni o UI di EditorPlugin. NON usarlo per entità di gioco (Player/Enemy/Weapon/Hitbox) — indirizzarle a godot‑composition. Parole chiave di attivazione: Control, EditorPlugin, UI di tool, Orchestrator, VLS, rock test, AuthComponent, ThemeManager, componente Saveable, dependency injection. Per favore rispondi sempre nella lingua dell'utente.
