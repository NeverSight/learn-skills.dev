Экспертные архитектурные стандарты масштабируемых приложений Godot, инструментов, EditorPlugin‑ов и UI, насыщенных элементами Control, с использованием композиции (Has‑A Orchestrator + компоненты). Применяйте при создании дашбордов, окон инструментов, форм, панелей настроек или UI EditorPlugin‑ов. НЕ используйте для игровых сущностей (Player/Enemy/Weapon/Hitbox) — направляйте их в godot-composition. Ключевые слова‑триггеры: Control, EditorPlugin, tool UI, Orchestrator, VLS, rock test, AuthComponent, ThemeManager, Saveable component, dependency injection.
