スケーラブルな Godot アプリ、ツール、EditorPlugin、そしてコンポジション（Has‑A Orchestrator + components）を使用したコントロール中心の UI に関するエキスパート建築基準です。ダッシュボード、ツールウィンドウ、フォーム、設定パネル、または EditorPlugin の UI を構築する際に使用してください。ゲームプレイエンティティ（Player/Enemy/Weapon/Hitbox）には使用しないでください—それらは godot‑composition にルーティングしてください。トリガーキーワード：Control、EditorPlugin、tool UI、Orchestrator、VLS、rock test、AuthComponent、ThemeManager、Saveable component、dependency injection。
