Patrones avanzados para sistemas de combate que incluyen arquitectura de hitbox/hurtbox, cálculo de daño (clase DamageData), componentes de salud, máquinas de estado de combate, sistemas de combo, enfriamiento de habilidades y notificaciones de daño. Uso para juegos de acción, RPG o juegos de lucha. Palabras clave de activación: Hitbox, Hurtbox, DamageData, HealthComponent, combat_state, combo_system, ability_cooldown, invincibility_frames, damage_popup.
