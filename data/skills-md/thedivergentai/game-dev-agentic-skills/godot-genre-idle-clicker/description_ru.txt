Экспертный план разработки idle/clicker‑игр, включающий работу с большими числами (система мантисса + экспонента), экспоненциальные кривые роста (коэффициент роста стоимости 1,15×), системы генераторов (автопродуценты), расчёт прогресса в офлайн‑режиме, системы престижа (сброс для постоянных множителей), форматирование чисел (суффиксы K/M/B, научная нотация). Использовать для инкрементальных игр, idle‑игр или производных от Cookie Clicker. Триггерные ключевые слова: idle_game, big_number, exponential_growth, generator_system, offline_progress, prestige_system, number_formatting.
