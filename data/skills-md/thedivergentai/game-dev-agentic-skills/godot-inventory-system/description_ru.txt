Экспертный план системы инвентаря (Diablo, Resident Evil, Minecraft), охватывающий контейнеры на основе ячеек, логику складывания, ограничения по весу, системы экипировки и UI перетаскивания. Используйте при создании RPG‑инвентарей, управления предметами в выживании или систем лута. Ключевые слова: инвентарь, ячейка, стек, экипировка, крафт, предмет, ресурс, перетаскивание.
