Plan d'expert pour des mises en page UI réactives utilisant les nœuds Container (HBoxContainer, VBoxContainer, GridContainer, MarginContainer, ScrollContainer, HFlowContainer, SubViewportContainer). Couvre les indicateurs de taille, les ancres, les conteneurs fractionnés, le pool virtual_list, les aperçus stretch_shrink et les mises en page dynamiques. À utiliser lors de la création d'interfaces adaptatives OU de la mise en œuvre de menus réactifs. Mots‑clés : Container, HBoxContainer, VBoxContainer, GridContainer, HFlowContainer, SubViewportContainer, virtual_list, stretch_shrink, size_flags, EXPAND_FILL, anchors, responsive.
