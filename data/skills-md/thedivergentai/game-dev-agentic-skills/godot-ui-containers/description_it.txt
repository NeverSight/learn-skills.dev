Progetto esperto per layout UI reattivi usando i nodi Container (HBoxContainer, VBoxContainer, GridContainer, MarginContainer, ScrollContainer, HFlowContainer, SubViewportContainer). Copre flag di dimensione, ancoraggi, contenitori divisi, pooling di virtual_list, anteprime stretch_shrink e layout dinamici. Da utilizzare quando si costruiscono interfacce adattive O si implementano menu reattivi. Parole chiave: Container, HBoxContainer, VBoxContainer, GridContainer, HFlowContainer, SubViewportContainer, virtual_list, stretch_shrink, size_flags, EXPAND_FILL, anchors, responsive.
