Экспертный план для систем отслеживания квестов (цели, прогресс, награды, ветвящиеся цепочки) с использованием квестов на основе ресурсов, обновлений, управляемых сигналами, и менеджеров AutoLoad. Применяется при реализации RPG‑квестов или миссионных систем. Ключевые слова: квест, цели, Quest Resource, QuestObjective, signal-driven, branching, rewards, AutoLoad.
