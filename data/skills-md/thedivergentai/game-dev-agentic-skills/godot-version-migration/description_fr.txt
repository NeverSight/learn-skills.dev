Hub complet de migration des versions Godot. À utiliser lors de la mise à jour de tout projet Godot vers la cible de la bibliothèque (actuellement 4.7) — depuis les ères legacy 1.x/2.x jusqu’à 3→4 et, pas à pas, les versions mineures 4.x — ou pour trouver des notes de migration ciblées par Domaine de compétence. Mots‑clés déclencheurs : upgrade Godot, migrate Godot version, Godot 3 to 4, Godot 2 to 3, upgrading_to_godot, version migration, breaking changes, convert-3to4, TileMapLayer, AnimationMixer, engine.cfg, project.godot.
