Полноисторический центр миграции версий Godot. Используйте при обновлении любого проекта Godot к целевой версии библиотеки (в данный момент 4.7) — от эпох наследия 1.x/2.x через переход 3→4 и пошаговые обновления минорных версий 4.x — или для поиска заметок по миграции в рамках Domain Skill. Ключевые слова‑триггеры: upgrade Godot, migrate Godot version, Godot 3 to 4, Godot 2 to 3, upgrading_to_godot, version migration, breaking changes, convert-3to4, TileMapLayer, AnimationMixer, engine.cfg, project.godot.
