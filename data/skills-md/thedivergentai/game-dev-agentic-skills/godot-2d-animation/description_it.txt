Modelli esperti per l'animazione 2D in Godot usando AnimatedSprite2D e rig scheletrici cutout. Da utilizzare quando si implementano animazioni di frame sprite, animazione procedurale (squash/stretch), gerarchie ossee cutout o sistemi di timing a frame perfetti. Parole chiave di attivazione: AnimatedSprite2D, SpriteFrames, animation_finished, animation_looped, frame_changed, frame_progress, set_frame_and_progress, animazione cutout, skeletal 2D, Bone2D, animazione procedurale, macchina a stati di animazione, advance(0).
