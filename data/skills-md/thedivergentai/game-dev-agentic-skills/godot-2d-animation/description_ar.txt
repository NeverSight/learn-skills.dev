نماذج متقدمة للرسوم المتحركة ثنائية الأبعاد في Godot باستخدام AnimatedSprite2D وهياكل عظام القطع. استخدمها عند تنفيذ رسوم متحركة لإطارات السبرايت، الرسوم المتحركة الإجرائية (الضغط/التمدد)، تسلسلات عظام القطع، أو أنظمة توقيت دقيقة للإطار. الكلمات المفتاحية للتفعيل: AnimatedSprite2D، SpriteFrames، animation_finished، animation_looped، frame_changed، frame_progress، set_frame_and_progress، cutout animation، skeletal 2D، Bone2D، procedural animation، animation state machine، advance(0).
