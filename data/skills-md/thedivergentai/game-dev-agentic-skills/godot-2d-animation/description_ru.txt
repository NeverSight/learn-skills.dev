Экспертные шаблоны для 2D‑анимации в Godot с использованием AnimatedSprite2D и скелетных cutout‑ригов. Применяйте при реализации анимаций спрайтов по кадрам, процедурной анимации (squash/stretch), иерархий костей cutout или систем точного по‑кадрового тайминга. Ключевые слова‑триггеры: AnimatedSprite2D, SpriteFrames, animation_finished, animation_looped, frame_changed, frame_progress, set_frame_and_progress, cutout animation, skeletal 2D, Bone2D, procedural animation, animation state machine, advance(0).
