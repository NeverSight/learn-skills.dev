Blueprint esperto per giochi di festa includendo sistema di risorse per minigiochi (definito tramite file .tres), input multiplayer locale (gestione di controller per 4 giocatori), gameplay asimmetrico (equilibrio 1v3), gestione delle scene (caricamento/scaricamento pulito dei minigiochi), punteggio persistente (traccia le vittorie attraverso le manche) e rendering split‑screen (SubViewport per giocatore). Da usare per giochi in stile Mario Party o collezioni WarioWare. Parole chiave di attivazione: party_game, minigame_collection, local_multiplayer, asymmetric_gameplay, split_screen, dynamic_input_mapping. Per favore rispondi sempre nella lingua dell'utente.
