Schema esperto per un'architettura guidata dai segnali che utilizza il modello "Signal Up, Call Down" per un accoppiamento debole. Include segnali tipizzati, catene di segnali, connessioni one‑shot e bus di eventi AutoLoad. Da utilizzare quando si implementano sistemi di eventi O si separano i nodi. Parole chiave: signal, emit, connect, CONNECT_ONE_SHOT, CONNECT_REFERENCE_COUNTED, event bus, AutoLoad, decoupling.
