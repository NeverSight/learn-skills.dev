Experten‑Blueprint für signalgesteuerte Architektur mit dem Muster „Signal Up, Call Down“ zur losen Kopplung. Behandelt typisierte Signale, Signalketten, Einmalverbindungen und AutoLoad‑Ereignisbussen. Verwenden Sie es beim Implementieren von Ereignissystemen ODER bei der Entkopplung von Nodes. Schlüsselwörter: signal, emit, connect, CONNECT_ONE_SHOT, CONNECT_REFERENCE_COUNTED, event bus, AutoLoad, decoupling.
