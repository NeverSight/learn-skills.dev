Экспертный план построения сигнально‑ориентированной архитектуры с использованием паттерна «Signal Up, Call Down» для слабой связности. Охватывает типизированные сигналы, цепочки сигналов, одноразовые соединения и автобусы событий AutoLoad. Применяется при реализации систем событий И разъединении узлов. Ключевые слова: signal, emit, connect, CONNECT_ONE_SHOT, CONNECT_REFERENCE_COUNTED, event bus, AutoLoad, decoupling.
