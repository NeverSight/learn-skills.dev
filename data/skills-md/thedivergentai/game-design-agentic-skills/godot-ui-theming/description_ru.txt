Экспертный план создания UI‑тем с использованием ресурсов Theme, StyleBox, пользовательских шрифтов и переопределений темы для обеспечения единообразного визуального оформления. Охватывает StyleBoxFlat/Texture, наследование тем, динамическую смену тем и варианты шрифтов. Применяется при реализации согласованного стилирования UI ИЛИ поддержке нескольких тем. Ключевые слова: Theme, StyleBox, StyleBoxFlat, add_theme_override, шрифт, наследование тем, темный режим.
