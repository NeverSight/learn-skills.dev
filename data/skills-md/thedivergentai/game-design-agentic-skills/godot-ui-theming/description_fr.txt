Plan d'expert pour les thèmes UI utilisant les ressources Theme, les StyleBoxes, les polices personnalisées et les surcharges de thème pour un style visuel cohérent. Couvre StyleBoxFlat/Texture, l'héritage de thème, le basculement dynamique de thème et les variations de police. À utiliser lors de la mise en œuvre d’un style UI cohérent OU du support de plusieurs thèmes. Mots‑clés : Theme, StyleBox, StyleBoxFlat, add_theme_override, police, héritage de thème, mode sombre.
