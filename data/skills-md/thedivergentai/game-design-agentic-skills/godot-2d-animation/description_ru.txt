Экспертные паттерны для 2D‑анимации в Godot с использованием AnimatedSprite2D и скелетных вырезных ригов. Применяйте при реализации анимации смены спрайтов, процедурной анимации (сквош/стретч), иерархий вырезных костей или систем точного по кадрам тайминга. Ключевые слова‑триггеры: AnimatedSprite2D, SpriteFrames, animation_finished, animation_looped, frame_changed, frame_progress, set_frame_and_progress, cutout animation, skeletal 2D, Bone2D, procedural animation, animation state machine, advance(0).
