Godot 中使用 AnimatedSprite2D 和骨骼切割装置的 2D 动画专家模式。适用于实现精灵帧动画、程序化动画（压缩/拉伸）、切割骨骼层级或帧精确计时系统。触发关键词：AnimatedSprite2D、SpriteFrames、animation_finished、animation_looped、frame_changed、frame_progress、set_frame_and_progress、cutout animation、skeletal 2D、Bone2D、procedural animation、animation state machine、advance(0)。
