在 Godot 中使用 AnimatedSprite2D 與骨骼切割綁定的 2D 動畫專家模式。適用於實作精靈幀動畫、程序式動畫（壓縮/拉伸）、切割骨骼層級或幀級精確計時系統。觸發關鍵字：AnimatedSprite2D、SpriteFrames、animation_finished、animation_looped、frame_changed、frame_progress、set_frame_and_progress、cutout animation、skeletal 2D、Bone2D、procedural animation、animation state machine、advance(0)。
