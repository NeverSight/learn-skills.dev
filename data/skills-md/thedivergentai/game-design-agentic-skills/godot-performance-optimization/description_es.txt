Guía experta para el perfilado y optimización del rendimiento (caídas de fotogramas, fugas de memoria, llamadas de dibujo) usando Godot Profiler, agrupación de objetos, recorte de visibilidad e identificación de cuellos de botella. Utilízala al diagnosticar retrasos, optimizar para FPS objetivo o reducir el uso de memoria. Palabras clave: profiling, Godot Profiler, bottleneck, object pooling, VisibleOnScreenNotifier, draw calls, MultiMesh.
