プロフェッショナルな Godot 4.7+ のゲーム・アプリ開発向けに統合されたエキスパートライブラリ。アーキテクチャワークフロー、アンチパターンカタログ、パフォーマンス予算、Server API パターンを通じて 92 のドメインスキルを統括します。使用シーン：(1) 新規 Godot プロジェクトの開始、(2) ゲームまたはアプリのアーキテクチャ設計、(3) エンティティ／コンポーネントシステムの構築、(4) パフォーマンスや物理のデバッグ、(5) 2D と 3D の選択、(6) マルチプレイヤー実装、(7) 描画コールやスクリプト時間の最適化、(8) プラットフォーム間の移植、(9) 4.6 から 4.7 への移行。すべての Godot 開発タスクの主要エントリーポイント。キーワード: Godot 4.7、AreaLight3D、HDR、Asset Store、godot-master。
