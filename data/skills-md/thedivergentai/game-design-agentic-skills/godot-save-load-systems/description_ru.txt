Экспертный план для систем сохранения/загрузки с использованием JSON/бинарной сериализации, шаблона группы PERSIST, версионирования и миграции. Охватывает прогресс игрока, настройки, сохранение состояния игры и восстановление после ошибок. Применяется при реализации систем сохранения ИЛИ постоянного хранения данных. Ключевые слова: save, load, JSON, FileAccess, user://, сериализация, миграция версий, группа PERSIST.
