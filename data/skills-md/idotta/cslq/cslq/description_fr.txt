Requêtes sémantiques C#/.NET — exécutez `cslq` au lieu de grep, ripgrep, Select‑String ou de lire les fichiers pour toute question portant sur la signification plutôt que sur le texte. Utilisez‑le pour « trouver tous les appelants », « qui utilise », « où X est défini », « aller à la définition », « ce qui se trouve dans ce fichier », « cela compile‑t‑il », « des erreurs », « ce que cette classe expose », « impact du renommage », « est‑ce encore utilisé », « code mort », « qui implémente cette interface », « qui la surcharge », « trouver un symbole par son nom », « c’est quoi », « quel type est‑ce », « quels sont les paramètres », « dans quel projet cela se trouve » — et sur tout identifiant C# nommé sans chemin de fichier. Aussi avant de modifier un fichier C# inconnu.
