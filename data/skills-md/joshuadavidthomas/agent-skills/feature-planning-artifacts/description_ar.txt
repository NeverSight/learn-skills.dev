استخدم ذلك عند إنشاء أو تعديل مخرجات التخطيط المرحلية لميزة معقدة: مناقشة التصميم، مخطط الهيكل، الخطة النهائية للمنفذ، أو الأبحاث الداعمة/الأسئلة البحثية. كما يُستَخدم عند التصميم قبل الترميز، تقسيم العمل إلى شرائح رأسية، أو تعميق عنصر خارطة طريق عالي القيمة، تحسين الخطة NNN، مرشح بنية، أو مهمة بأسلوب HumanLayer.
