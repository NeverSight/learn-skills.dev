Examinez une base de code en tant que conseiller senior et transformez les constatations à plus forte valeur ajoutée en plans de mise en œuvre pour que d’autres agents les exécutent — en lecture seule du code source, sans jamais implémenter quoi que ce soit vous-même. À utiliser lorsqu’on vous demande d’auditer une base de code, de repérer des opportunités d’amélioration (bugs, sécurité, performances, couverture de tests, dette technique, architecture, migrations, expérience développeur), de suggérer des fonctionnalités ou une direction de feuille de route, ou de générer des plans de passation pour qu’un autre agent les réalise.
