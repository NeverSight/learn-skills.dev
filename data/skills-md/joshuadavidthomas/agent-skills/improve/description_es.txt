Examinar una base de código como asesor senior y convertir los hallazgos de mayor valor en planes de implementación para que otros agentes los ejecuten — estrictamente en modo solo lectura sobre el código fuente, sin implementar nada por sí mismo. Utilízalo cuando se solicite auditar una base de código, encontrar oportunidades de mejora (errores, seguridad, rendimiento, cobertura de pruebas, deuda técnica, arquitectura, migraciones, experiencia de desarrollador), sugerir características o dirección del roadmap, o generar planes de entrega para que otro agente los implemente.
