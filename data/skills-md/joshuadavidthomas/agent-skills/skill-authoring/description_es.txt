Usa esto al redactar, crear, refinar o solucionar problemas de habilidades del agente — estructurar SKILL.md y el frontmatter, escribir y optimizar la descripción del disparador, organizar el cuerpo con divulgación progresiva, validar la estructura y probar o depurar la activación. También al crear una nueva habilidad desde cero, cuando una habilidad no se dispara, se carga incorrectamente o el agente la ignora por completo. Usa esto cuando una habilidad se comportó mal en la sesión actual y necesita ajustes basados en lo aprendido.
