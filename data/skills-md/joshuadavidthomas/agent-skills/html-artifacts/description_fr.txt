Utilisez ce modèle lorsque l'utilisateur demande de créer, générer, visualiser ou transformer du contenu en un artefact HTML autonome, un rapport .html auto‑contenu ou à fichier unique, un explicateur interactif, une illustration ou visualisation interactive, une démonstration visuelle ou un livrable, ou une présentation HTML ou un diaporama. Il prend en charge les bases de code et l’architecture ancrées dans le source, les fonctionnalités, les PR ou diff, le récapitulatif d’implémentation, la chronologie d’incident, la comparaison d’options, les explications causales et les rapports de données. À ne pas utiliser pour les analyses ou revues uniquement en prose, les applications web de production ou tableaux de bord, les sites web, les e‑mails HTML, ou les implémentations classiques de frontend/UI.
