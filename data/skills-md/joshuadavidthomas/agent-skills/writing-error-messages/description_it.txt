Usa quando scrivi, rivedi o riscrivi messaggi di errore destinati agli utenti, messaggi di validazione, errori di modulo, stati vuoti o di errore, errori di autenticazione, notifiche di fallimento, testi di ripetizione/supporto, errori da riga di comando o errori API che gli esseri umani leggeranno. Aiuta a rendere gli errori specifici, azionabili, non colpevolizzanti, accessibili e sicuri, senza divulgare dettagli sensibili.
