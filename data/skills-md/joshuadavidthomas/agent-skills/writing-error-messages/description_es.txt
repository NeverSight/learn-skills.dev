Úselo al redactar, revisar o reescribir mensajes de error dirigidos al usuario, mensajes de validación, errores de formularios, estados vacíos o de error, errores de autenticación, notificaciones de fallos, copias de reintento/soporte, errores de CLI o errores de API que leerán los humanos. Ayuda a que los errores sean específicos, accionables, no culpables, accesibles y seguros sin filtrar detalles sensibles.
