Используйте при написании, проверке или переписывании сообщений об ошибках, видимых пользователю, сообщений валидации, ошибок форм, состояний пустоты/ошибок, ошибок аутентификации, уведомлений о сбоях, текста для повторных попыток/поддержки, ошибок командной строки или ошибок API, которые читают люди. Помогает сделать ошибки конкретными, пригодными для действий, без обвинения, доступными и безопасными, не раскрывая конфиденциальную информацию.
