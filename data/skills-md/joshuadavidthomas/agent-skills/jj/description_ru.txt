Jujutsu (jj) — система контроля версий, совместимая с Git. Активируется ТОЛЬКО при наличии каталога .jj/ в проекте или когда явно указано jj/jujutsu. НЕ активировать для обычных репозиториев Git без .jj/. Использовать для любых операций VCS в проектах, управляемых jj: commit, push, pull, branch, bookmark, rebase, squash, merge, diff, log, status, working copy, change ID, revset, fileset, template, configuration, workspaces.
