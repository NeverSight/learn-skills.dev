Jujutsu (jj) — el sistema de control de versiones compatible con Git. Actívalo SÓLO cuando exista un directorio .jj/ en el proyecto o cuando se mencione explícitamente jj/jujutsu. NO lo actives para repositorios Git simples sin .jj/. Úsalo para cualquier operación de VCS en proyectos gestionados por jj: commit, push, pull, branch, bookmark, rebase, squash, merge, diff, log, status, copia de trabajo, change ID, revset, fileset, template, configuration, workspaces.
