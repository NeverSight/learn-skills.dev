Jujutsu (jj) — le système de contrôle de version compatible avec Git. Activez‑LE UNIQUEMENT lorsqu’un répertoire .jj/ est présent dans le projet ou lorsque jj/jujutsu est explicitement mentionné. NE L’ACTIVEZ PAS pour des dépôts Git simples sans .jj/. Utilisez‑le pour toutes les opérations VCS dans les projets gérés par jj : commit, push, pull, branche, signet, rebase, squash, merge, diff, log, status, copie de travail, identifiant de changement, revset, fileset, modèle, configuration, espaces de travail.
