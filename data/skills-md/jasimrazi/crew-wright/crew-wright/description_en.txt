Build and run a coordinated multi-agent crew of specialist sub-agents for non-trivial software engineering tasks. Activate this skill whenever the user asks for a crew, team of agents, multi-agent execution, parallel sub-agents, or "plan/build/review/test" workflow, or gives a request substantial enough to require independent planning, interface design, modular coding, blind review, and evidence-based testing passes. Do not use this skill for trivial, single-file edits, minor script tweaks, or quick one-turn questions where spawning multiple agents introduces unnecessary overhead.
