Azure DevOps에 인증하고 인증 문제를 해결하세요 — 다른 모든 ado-* 기술이 의존하는 공유 기본 요소입니다. ADO 인증 설정이 불확실할 때는 물론, 생성/쿼리 전에는 반드시 이것을 사용하고, ADO 호출이 비정상적으로 동작할 때마다 사용하세요: REST 호출이 401 또는 403을 반환하거나, “az not logged in” / 토큰 만료, 결과가 잘못된 조직에서 오거나 비어 있거나, “A potentially dangerous Request.Path value was detected (:)” 오류가 발생할 경우 등. 지원되는 두 가지 방법(`az`를 통한 Entra 토큰 또는 AZDO_PAT), 프로젝트 API에 대한 한 줄 PowerShell 검증 스니펫, 그리고 401/403/잘못된 조직 문제 해결 표를 포함합니다. 누군가가 “Azure DevOps에서 401 오류가 발생한다”, “create-backlog이 토큰을 가져올 수 없다”, “ado 인증 실패”, 혹은 “실행하기 전에 내 ADO 로그인 확인해 주세요” 라고 말할 때 호출하세요.
