Azure DevOps に認証し、認証問題を解決する — すべての他の ado-* スキルが依存する共通のプリミティブです。ADO の認証設定が不確かである場合や、作成・クエリの前に必ずこれを使用し、ADO 呼び出しが正常に動作しないとき（REST 呼び出しが 401 または 403 を返す、"az not logged in" / トークンが期限切れ、結果が間違った組織から返ってくるまたは空、あるいは "A potentially dangerous Request.Path value was detected (:)" が出る）に活用します。サポートされている 2 つの方法（Entra トークン via `az`、または AZDO_PAT）をカバーし、プロジェクト API に対する 1 行の PowerShell 検証スニペットと、401/403/間違った組織のトラブルシューティング表を提供します。誰かが「Azure DevOps で 401 が返ってきた」「create-backlog がトークン取得できないと言っている」「ado auth が失敗している」「実行前に ADO ログインを確認したい」などと言ったときに呼び出してください。
