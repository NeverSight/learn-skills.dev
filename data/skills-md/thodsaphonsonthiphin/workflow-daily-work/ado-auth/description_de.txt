Authentifizieren Sie sich bei Azure DevOps und beheben Sie Authentifizierungsprobleme – die gemeinsam genutzte Grundfunktion, von der jede andere ado-*-Fähigkeit abhängt. Verwenden Sie dies VOR jedem Erstellen/Abfragen, wenn die ADO‑Auth‑Einrichtung unsicher ist, und immer dann, wenn ein ADO‑Aufruf fehlerhaft ist: ein REST‑Aufruf gibt 401 oder 403 zurück, „az not logged in“ / Token abgelaufen, Ergebnisse kommen aus der falschen Organisation oder sind leer, oder Sie erhalten „A potentially dangerous Request.Path value was detected (:)“. Behandelt die beiden unterstützten Methoden (Entra‑Token via `az` oder AZDO_PAT), ein einzeiliges PowerShell‑Verifizierungs‑Snippet gegen die Projects‑API und eine Troubleshooting‑Tabelle für 401/403/falsche Organisation. Aufrufen, wenn jemand sagt: „Ich erhalte ein 401 von Azure DevOps“, „create-backlog sagt, es kann kein Token holen“, „ado auth failing“ oder „prüfe mein ADO‑Login, bevor wir starten“.
