對 Azure DevOps 進行驗證並修復認證問題——所有其他 ado-* 技能依賴的共享基礎。當 ADO 認證設定不確定時，或在任何建立/查詢之前，請先使用此方法；亦在 ADO 呼叫異常時使用：REST 呼叫回傳 401 或 403、出現「az not logged in」/ 令牌過期、結果來自錯誤的組織或為空，或出現「檢測到潛在危險的 Request.Path 值 (:)」的情形。涵蓋兩種支援的方式（透過 `az` 的 Entra 令牌，或 AZDO_PAT）、對 projects API 的單行 PowerShell 驗證片段，以及 401/403/錯誤組織的故障排除表。當有人說「我從 Azure DevOps 收到 401」、「create-backlog 說它無法取得令牌」、「ado auth 失敗」或「在執行前檢查我的 ADO 登入」時，請呼叫此方法。
