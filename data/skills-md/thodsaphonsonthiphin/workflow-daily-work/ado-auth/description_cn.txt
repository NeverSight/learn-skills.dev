对 Azure DevOps 进行身份验证并修复身份验证问题——所有其他 ado-* 技能都依赖的共享原语。 在 ADO 身份验证设置不确定时以及在任何创建/查询之前使用此方法，并在 ADO 调用出现异常时使用：REST 调用返回 401 或 403，“az not logged in”/令牌过期，结果来自错误的组织或为空，或出现 “检测到潜在危险的 Request.Path 值 (:)”。 本指南涵盖两种受支持的方法（通过 `az` 获取的 Entra 令牌，或 AZDO_PAT），以及一个针对项目 API 的单行 PowerShell 验证脚本和一个 401/403/错误组织的故障排除表。 当有人说“我在 Azure DevOps 收到 401”、 “create-backlog 提示无法获取令牌”、 “ado auth failing”、或 “在运行前检查我的 ADO 登录” 时，请调用此步骤。
