进入每日工作弧线的唯一入口——混合式菜单/参数路由器。当用户调用 /dev-workflows:daily、输入 /daily、询问“我现在应该做什么”“我上次在哪里”“开始我的一天”“今天接下来做什么”“结束我的一天”或不确定哪项技能适合当前的每日工作情境时触发。未带参数的调用会显示一个五站菜单（开始 / 工作 / 归档发现 / 报告 / 收尾）；带参数（start | work | file | report | wrap，接受同义词）则直接跳转到对应站点并交给合适的技能：ado-backlog:my-work、情境工具箱（grill-then-plan、debug-mantra、study-design-verify、naming-audit、fit-gap-analysis、problem-description、ticket-trace、scrutinize、review-pr、dual-verifier、drive-to-legacy、crm-archaeology、generating-test-cases）、findings-to-ado-backlog 或 ado-create-work-items（按需提供 github-backlog 副本）、management-talk 或 invoice-generator。
