Der einzige Einstiegspunkt in den täglichen Arbeitsbogen — ein hybrider Menü/Argument‑Router. Auslösen, wann immer der Benutzer /dev-workflows:daily aufruft, /daily tippt, fragt „what should I do now“, „where was I“, „start my day“, „what's next today“, „wrap up my day“, „end my day“ oder unsicher ist, welche Fähigkeit zu seinem aktuellen Daily‑Work‑Moment passt. Ohne Argument wird ein 5‑Stationen‑Menü angezeigt (starting / working / filing findings / reporting / wrapping up); mit einem Argument (start | work | file | report | wrap, Synonyme akzeptiert) springt es direkt zur jeweiligen Station und übergibt an die passende Skill: ado-backlog:my‑work, die situative Toolbox (grill‑then‑plan, debug‑mantra, study‑design‑verify, naming‑audit, fit‑gap‑analysis, problem‑description, ticket‑trace, scrutinize, review‑pr, dual‑verifier, drive‑to‑legacy, crm‑archaeology, generating‑test‑cases), findings‑to‑ado‑backlog oder ado‑create‑work‑items (github‑backlog‑Twins auf Anfrage), management‑talk oder invoice‑generator.
