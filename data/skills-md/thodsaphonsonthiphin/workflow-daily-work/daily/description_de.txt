Der einzige Einstiegspunkt in den täglichen Arbeitsablauf — ein hybrider Menü-/Argumentrouter. Auslösen, wann immer der Benutzer /dev-workflows:daily aufruft, /daily eingibt, fragt „was soll ich jetzt tun“, „wo war ich“, „mein Tag beginnen“, „was steht heute als Nächstes an“, „mein Tag abschließen“, „mein Tag beenden“ oder unsicher ist, welche Fähigkeit zu seinem aktuellen täglichen Arbeitsmoment passt. Ein einfacher Aufruf zeigt ein 5‑Stationen‑Menü (Starten / Arbeiten / Befunde ablegen / Berichten / Abschließen); mit einem Argument (start | work | file | report | wrap, Synonyme akzeptiert) springt er direkt zur jeweiligen Station und leitet an die passende Fähigkeit weiter: ado-backlog:my-work, die situative Werkzeugkiste (grill‑then‑plan, debug‑mantra, study‑design‑verify, naming‑audit, fit‑gap‑analysis, problem‑description, ticket‑trace, scrutinize, review‑pr, dual‑verifier, drive‑to‑legacy, crm‑archaeology, generating‑test‑cases), findings‑to‑ado‑backlog oder ado‑create‑work‑items (github‑backlog‑Zwillinge auf Anfrage), management‑talk oder invoice‑generator. Bitte immer in der Sprache des Benutzers antworten.
