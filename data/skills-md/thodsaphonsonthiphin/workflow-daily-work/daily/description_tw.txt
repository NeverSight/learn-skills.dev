進入每日工作弧線的唯一入口——一個混合式選單/參數路由器。當使用者呼叫 /dev-workflows:daily、輸入 /daily、詢問「現在該做什麼」、「我剛才在哪裡」、「開始我的一天」、「今天接下來是什麼」、「結束我的一天」或對目前的每日工作情境不確定哪個技能適用時，即觸發。未帶參數的呼叫會顯示五站式選單（開始 / 工作 / 建檔 / 報告 / 收尾）；若附帶參數（start │ work │ file │ report │ wrap，接受同義詞），則直接跳至對應站點，並交接給相應的技能：ado‑backlog:my‑work、情境工具箱（grill‑then‑plan、debug‑mantra、study‑design‑verify、naming‑audit、fit‑gap‑analysis、problem‑description、ticket‑trace、scrutinize、review‑pr、dual‑verifier、drive‑to‑legacy、crm‑archaeology、generating‑test‑cases）、findings‑to‑ado‑backlog 或 ado‑create‑work‑items（視需求提供 github‑backlog 雙生）、management‑talk，或 invoice‑generator。
