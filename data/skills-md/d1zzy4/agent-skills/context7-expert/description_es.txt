Carga automáticamente siempre que la respuesta dependa de una biblioteca externa, framework, SDK, API, CLI o servicio en la nube, y recupera la documentación actual y precisa por versión a través de Context7. Se activa al configurar o instalar una tecnología nombrada, firmas de API, comportamientos específicos de una versión, trabajos de migración, uso de dependencias o errores que se originan en una biblioteca concreta. Antes de cualquier consulta, proponga la búsqueda al usuario con opciones de modo y versión y espere la confirmación. Prefiera la documentación local del proyecto y las versiones explícitamente suministradas cuando sean más autoritativas. No se invoque para conceptos de programación independientes de bibliotecas, refactorizaciones ordinarias o código cuya corrección no dependa del comportamiento de una API externa.

Por favor, responda siempre en el idioma del usuario.
