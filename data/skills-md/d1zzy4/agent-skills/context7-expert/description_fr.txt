Se charge automatiquement chaque fois que la réponse dépend d’une bibliothèque externe, d’un framework, d’un SDK, d’une API, d’une CLI ou d’un service cloud, et récupère la documentation actuelle, précise au niveau de la version, via Context7. Se déclenche lors de l’installation ou de la configuration d’une technologie nommée, des signatures d’API, du comportement spécifique à une version, des travaux de migration, de l’utilisation de dépendances ou des erreurs provenant d’une bibliothèque spécifique. Avant toute recherche, proposez la requête à l’utilisateur avec les options de mode et de version et attendez la confirmation. Privilégiez la documentation locale du projet et les versions explicitement fournies lorsqu’elles sont plus fiables. N’intervenez pas pour des concepts de programmation indépendants d’une bibliothèque, des refactorisations ordinaires ou du code dont la correction ne dépend pas du comportement d’une API externe.
