Experiencia integral de Redis que cubre modelado de datos y nomenclatura de claves, conexiones de cliente (pooling, pipelining, caché del lado del cliente, timeouts), clustering y replicación, Redis Search (FT.CREATE, búsqueda vectorial e híbrida, pipelines RAG), observabilidad y triage de incidentes, endurecimiento de seguridad en producción y caché semántico para respuestas de LLM a través de LangCache. Úsalo siempre que diseñes, escribas, revises o depures cualquier cosa que toque Redis: elegir una estructura de datos, nombrar claves, configurar un cliente, shardear a través de un clúster, crear o ajustar un índice de búsqueda, monitorear o diagnosticar rendimiento, endurecer una implementación o cachear completaciones de LLM. Adaptado del repositorio oficial de agent-skills de Redis, Inc. (https://github.com/redis/agent-skills, licencia MIT), fusionado en una sola habilidad para que el dominio correcto se cargue automáticamente sin necesidad de elegir entre siete separadas.
