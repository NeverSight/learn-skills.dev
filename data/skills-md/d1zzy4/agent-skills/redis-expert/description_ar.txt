خبرة شاملة في Redis تغطي نمذجة البيانات وتسميات المفاتيح، اتصالات العملاء (التجميع، الأنابيب، التخزين المؤقت على جانب العميل، مهلات الوقت)، التجميع والنسخ المتماثل، Redis Search (FT.CREATE، البحث المتجه والبحث الهجين، خطوط أنابيب RAG)، الرصد وإدارة الحوادث، تعزيز أمان الإنتاج، والتخزين المؤقت الدلالي لاستجابات LLM عبر LangCache. استخدمها دائمًا عند تصميم أو كتابة أو مراجعة أو تصحيح أي شيء يتعلق بـ Redis: اختيار بنية بيانات، تسمية المفاتيح، تكوين عميل، التقسيم عبر مجموعة، بناء أو ضبط فهرس بحث، مراقبة أو تشخيص الأداء، تعزيز النشر، أو التخزين المؤقت لإكمالات LLM. مقتبسة من مستودع مهارات الوكيل الرسمي لشركة Redis, Inc. (https://github.com/redis/agent-skills، مرخص بموجب MIT)، مدمجة في مهارة واحدة بحيث يتم تحميل المجال المناسب تلقائيًا دون الحاجة للاختيار بين سبع مهارات منفصلة.
