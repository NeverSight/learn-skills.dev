Créez des fichiers README.md complets et bien structurés pour les projets logiciels. Déclenchez l'action lorsqu'un projet a besoin d'un README, lorsqu'une documentation d'intégration manque, lorsqu'un dépôt ne fournit pas d'instructions d'utilisation claires, ou lorsque le contenu du README est en cours d'examen ou de réécriture. Suivez le style et le public propres au projet ; n'imposez pas de modèles génériques de README lorsque le projet possède déjà des conventions solides.
