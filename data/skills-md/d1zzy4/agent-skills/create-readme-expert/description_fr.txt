Créez des fichiers README.md complets et bien structurés pour les projets logiciels. Se déclenche lorsqu'un projet a besoin d'un README, lorsque la documentation d'intégration est manquante, lorsqu'un référentiel manque d'instructions d'utilisation claires ou lorsque le contenu README est en cours de révision ou de réécriture. Suivez le style et le public du projet ; n'imposez pas de modèles README génériques lorsque le projet a déjà des conventions fortes.
