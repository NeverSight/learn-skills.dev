Crea file README.md completi e ben strutturati per progetti software. Attiva quando un progetto ha bisogno di un README, quando manca la documentazione di onboarding, quando un repository non ha istruzioni di utilizzo chiare o quando il contenuto del README viene rivisto o riscritto. Segui lo stile e il pubblico del progetto; non imporre modelli generici di README dove il progetto ha già forti convenzioni.

Rispondi sempre nella lingua dell'utente.
