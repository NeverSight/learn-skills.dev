Cree archivos README.md completos y bien estructurados para proyectos de software. Actúe cuando un proyecto necesite un README, cuando falte la documentación de incorporación, cuando un repositorio carezca de instrucciones de uso claras o cuando el contenido del README esté siendo revisado o reescrito. Siga el estilo y la audiencia propios del proyecto; no imponga plantillas genéricas de README donde el proyecto ya tenga convenciones sólidas.
