Erstelle umfassende, gut strukturierte README.md-Dateien für Softwareprojekte. Auslösen, wenn ein Projekt ein README benötigt, wenn Onboarding‑Dokumentation fehlt, wenn ein Repository keine klaren Nutzungsanweisungen enthält oder wenn README‑Inhalte überprüft oder neu geschrieben werden. Halte dich an den Stil und die Zielgruppe des Projekts; setze keine generischen README‑Vorlagen ein, wenn das Projekt bereits starke Konventionen hat.
