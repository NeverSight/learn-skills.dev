Erstellen Sie umfassende, gut strukturierte README.md-Dateien für Softwareprojekte. Triggern, wenn ein Projekt eine README benötigt, wenn Onboarding-Dokumentation fehlt, wenn einem Repository klare Nutzungsanweisungen fehlen oder wenn README-Inhalte überprüft oder neu geschrieben werden. Folgen Sie dem eigenen Stil und Publikum des Projekts; erzwingen Sie keine generischen README-Vorlagen, wenn das Projekt bereits starke Konventionen hat.
