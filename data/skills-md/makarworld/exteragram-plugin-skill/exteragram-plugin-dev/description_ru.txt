Создавайте плагины exteraGram (Python на базе SDK BasePlugin 1.4.4.3, exteraGram 12.5.1+, Python 3.11 через Chaquopy v16). Используйте при написании или редактировании файлов .plugin, реализации хуков (on_send_message_hook, pre_request_hook, post_request_hook, on_update_hook), создании настроек плагина (ui.settings: Header/ Switch/ Selector/ Input/ Text/ Custom), отправке сообщений (send_text/ send_photo/ send_document/ edit_message), хук‑инге методов Xposed (MethodHook/ HookFilter), прокси‑классов Java (java_subclass/ joverride/ jmethod), обработчиках файлов (FilesController), бюллетенях (BulletinHelper), диалогах (AlertDialogBuilder), интентах (IntentsManager), структурированных плагинах Elyx (refmap/ metainfo/ assets/ strings), рефлексии (hook_utils find_class/ get_private_field) или отладке dev‑сервера (127.0.0.1:42690). Охватывает масштабирование на несколько аккаунтов, форматирование текста, зависимости PIP и конвенции репозитория awesome‑plugins (.plugin — исходный файл, docs.md, releases/, Ruff).
