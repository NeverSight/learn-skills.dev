BasePlugin SDK 1.4.4.3, exteraGram 12.5.1+, Chaquopy v16을 통해 Python 3.11을 사용하여 exteraGram 플러그인을 구축합니다. .plugin 파일을 작성하거나 편집할 때, 훅 구현(on_send_message_hook, pre_request_hook, post_request_hook, on_update_hook), 플러그인 설정 만들기(ui.settings: Header/ Switch/ Selector/ Input/ Text/ Custom), 메시지 전송(send_text / send_photo / send_document / edit_message), Xposed 메서드 훅(MethodHook/HookFilter), Java 클래스 프록시(java_subclass / joverride / jmethod), 파일 핸들러(FilesController), 공지(BulletinHelper), 대화 상자(AlertDialogBuilder), 인텐트(IntentsManager), Elyx 구조 플러그인(refmap / metainfo / assets / strings), 리플렉션(hook_utils find_class / get_private_field) 또는 개발 서버 디버깅(127.0.0.1:42690) 등에 사용합니다. 다중 계정 범위, 텍스트 포맷팅, PIP 종속성 및 awesome-plugins 저장소 규칙(.plugin은 소스, docs.md, releases/, Ruff)도 포함합니다. 항상 사용자의 언어로 답변해 주세요.
