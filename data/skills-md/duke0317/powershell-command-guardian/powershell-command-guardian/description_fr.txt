Examiner, diagnostiquer et réécrire les commandes Windows PowerShell 5.1 et PowerShell 7+ pour la compatibilité des versions, les devis, les chemins, l'encodage, les arguments exécutables natifs, la propagation des erreurs et la sécurité des opérations destructives. À utiliser lorsqu'un utilisateur demande de convertir des commandes shell en PowerShell, de corriger une commande ou une erreur PowerShell, de vérifier si une commande est sûre sous Windows ou de faire fonctionner un script dans les versions PowerShell.
