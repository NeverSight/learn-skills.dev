Revise, diagnostique y reescriba los comandos de Windows PowerShell 5.1 y PowerShell 7+ para la compatibilidad de versiones, citas, rutas, codificación, argumentos ejecutables nativos, propagación de errores y seguridad de operación destructiva. Se usa cuando un usuario solicita convertir comandos de shell a PowerShell, corregir un comando o error de PowerShell, verificar si un comando es seguro en Windows o hacer que un script funcione en todas las versiones de PowerShell.
