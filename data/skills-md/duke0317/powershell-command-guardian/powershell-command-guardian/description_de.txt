Überprüfen, diagnostizieren und überschreiben Sie Windows PowerShell 5.1- und PowerShell 7+ -Befehle auf Versionskompatibilität, Anführungszeichen, Pfade, Codierung, native ausführbare Argumente, Fehlerausbreitung und Sicherheit des destruktiven Betriebs. Wird verwendet, wenn ein Benutzer anfordert, Shell-Befehle in PowerShell zu konvertieren, einen PowerShell-Befehl oder Fehler zu beheben, zu überprüfen, ob ein Befehl unter Windows sicher ist, oder ein Skript über PowerShell-Versionen hinweg funktionieren zu lassen.
