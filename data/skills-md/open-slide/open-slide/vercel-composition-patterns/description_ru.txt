Шаблоны композиции React, которые масштабируются. Используйте при рефакторинге компонентов с избыточным количеством булевых пропов, построении гибких библиотек компонентов или проектировании переиспользуемых API. Применяется в задачах, связанных с составными компонентами, render props, контекстными провайдерами или архитектурой компонентов. Включает изменения API React 19.
