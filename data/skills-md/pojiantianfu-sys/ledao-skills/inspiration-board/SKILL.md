# 选题灵感工作台

把一个对标账号拆成两类可复用资产：
1. **可点击的灵感台**（HTML，直接跳原片/原笔记）
2. **句式对版表**（左：对标原句；右：用户照着这个句式能说的话）

## 核心原则（踩过的坑，必须遵守）

1. **用他的句式，不是他的主题。** 不要"模仿他的风格"，要直接复刻他的句子结构，把内容换成用户自己的。
2. **只晒用户自己的事。** 不要把对标账号 PPT 里的行业案例、第三方故事，当成用户的学员案例。
3. **平台决定风格。** 抖音是口播钩子（短、冲、下判断）；小红书是情绪型/反常识型/身份代入型标题（"被XX震撼到"、"劝你别XX"、"i人怎么XX"）。不要把抖音的干货体搬到小红书，也不要把小红书的情绪标题搬到抖音。
4. **时效性是硬门槛。** 小红书爆款生命周期只有1-2周，超过1个月的选题写了也不爆。只看最近30天内的内容。
5. **数据门槛。** 只参考百赞以上的笔记/视频。几十赞的没有参考价值。
6. **洗稿=原句式一个字不改。** 除了人群词，其他字一个都不动。改了就不是爆款句式了。
7. **"AI重讲"法。** 如果用户的差异化是"AI+某个赛道"（比如AI+知识IP、AI+高客单），就把对标账号的原选题前面加"AI"，或者把人群换成"咨询师/知识IP"。
8. **不要 AI 味。** 避免排比、对仗、金句堆砌、"赋能/抓手/闭环"这类词。
9. **B端/C端必须分清楚。** B端=教从业者/老板获客、变现、做IP（客户是咨询师、疗愈师、教练、老板这类从业者）；C端=直接做内容给消费者/来访者看。开工前先确认用户做哪一端，只找同一端的对标：B端用户找"教从业者变现"的账号（教培招生、律师获客、AI+老板IP、高客单成交陪跑等），C端用户找"内容直接打动消费者"的账号（冥想引导、情感内容、心理科普等）。混端对标是最大的浪费——C端爆款对B端用户毫无参考价值，反之亦然。
10. **跨行业找对标，AI类要占比例。** 很少找同行业的做对标（同行业互相抄，容易陷入"她抄我"的泥潭）；优先跨行业找"同打法"的对标。如果用户差异化是"AI+赛道"，AI类对标（AI+商业、AI+IP、AI+获客、AI+一人公司）至少要占对标池的1/3以上，不要只给一两个。
11. **每日选题=对标爆款+全网采集。** 每日推荐不能只看对标账号，还要用关键词全网搜其他爆款（不限于对标），两部分合并分析；最终给1个推荐选题，并注明适合**视频**还是**图文**（视频=钩子强/需口播/情绪冲击/反常识判断；图文=清单型/收藏型/避坑型/方法论拆解）。
12. **工作台是快照，不是系统。** HTML 工作台按需生成、用完即弃，**不回头维护旧的**（改一个点会出一堆 bug，反复调效率极低）；需求变了就重新生成一版新的。干活靠 skill 一句话触发直接拿结果，工作台只用于"看"和"展示"（用户自己挑选题、给学员当交付物/门面）。
13. **定位硬约束（最高优先级）。** 任何涉及"出选题 / 每日推荐 / 找灵感 / 做灵感台 / 帮我想内容方向 / 帮我找对标"的请求：**必须先问清定位**（行业、产品/服务、客单价、目标人群、做 B 端还是 C 端）。在拿到定位之前，**不得输出任何选题、标题、方向或推荐内容**，只能继续问定位（单次最多 5 个关键问题）。"打开工作台 / 打开导航 / 看使用说明 / 打开灵感台页面"类请求不受此约束，直接给出链接或打开页面即可。

## 运作流程（自动闭环总览）

本 skill 按以下闭环运作。**定位不预设、不写死**——每次从用户输入获取，任何用户（本人、同事、学员）给定位即可跑通全流程。

> **B端/C端硬约束（勿混端）**：**不要默认使用者是 B 端或 C 端**——每次以使用者自己给的定位判断业务端：B 端用户找"教从业者变现"的对标，C 端用户找"内容直接打动消费者"的对标（见核心原则 9），绝不混端。判断定位时先问清"你服务的是从业者/老板，还是直接给消费者做内容"。

1. **收定位**：确认 赛道 / 业务端（B端还是C端）/ 客单价 / 目标人群 / 差异化（如"AI+某赛道"）。没有定位先问定位——没有定位，关键词和对标判断都无的放矢。
2. **生成搜索关键词**：按关键词规则输出分组词 + 组合词——人群质量＞变现结构＞内容表现；关键词优先指向能力/状态/选择/结果（而非纯问题词）；B端/C端分开搜；差异化是"AI+赛道"时 AI 类词≥1/3；搜索词只负责召回，正文/主页/评论核验后才通过。规则详见 `keyword-generator` 技能与 `benchmark-advisor` 的 `references/keyword-rules.md`。
3. **每天 9 点自动采集**（配合定时任务）：对标账号爆款 + 全网关键词爆款，最近 30 天百赞以上，按 5 个内容方向分类，Top3 改写，每日推荐 1 条（4 要素）。到点自动执行并推送，无需手动触发；也可随时手动触发同一流程。
4. **对标判断 + 优先级**（采集后必做）：调用 `benchmark-advisor`，按"人群质量＞变现结构＞内容表现"对每个候选给出四选一结论——值得对标 / 不值得对标 / 不可放大 / 待补证据。**不值得对标的即使点赞再高也淘汰，不进后续推荐**。再按"人群匹配度 × 变现链路 × 结构可复制性"排出优先级（哪些最值得做、先做哪个）。
5. **输出**：对标爆款 + 全网爆款（每条附判断结论 + 优先级），每日推荐 1 条——**只从"值得对标 + 高优先级"中选**，含原标题一字不改/原平台/原账号/原赞数/为什么推荐/视频图文标注。

**衔接**：`keyword-generator`（定位→关键词）、`benchmark-finder`（找对标）、`daily-picks`（每日推荐）、`benchmark-advisor`（判断值不值得对标）都是本流程的单点能力；本 skill 是总入口。

## 工作流

### 第 0 步：先问定位，再问平台、业务端和对标账号

**先问定位（最重要，没有定位后面都白搭）：**
1. **你是干嘛的？** 行业+产品，比如：做家庭教育的、做婚姻情感的、做心理咨询的、做教培的
2. **客单价多少？** 比如：低价引流课、中等价位陪跑、高价闭门会
3. **你有什么真实数据吗？** 有的话告诉我（粉丝量、成交、学员数），没有也没关系

**再问平台和对标：**
5. 你主要在哪个平台发？抖音还是小红书？
6. 你做的是 **B端（服务从业者/老板，教他们获客、变现、做IP）** 还是 **C端（直接做内容给消费者/来访者看）**？——这决定找什么样的对标，混端必错。
7. 你有没有想对标的账号？

- **有对标账号**：直接走第0.5步（小红书）或第1步（抖音）
- **没有对标账号**：走第0.3步，先帮她找

### 第 0.3 步：如果用户没有对标账号，先帮她找

**目的**：通过关键词搜索，找到同赛道、同客单价、同平台、**同业务端（B端/C端一致）** 的爆款账号。

**操作**：
1. 先问清楚用户的定位：赛道是什么？客单价多少？主要服务谁？**做B端还是C端？**
2. 按业务端定搜索关键词：
   - **B端用户**搜"教XX获客/变现/陪跑/做IP"（XX覆盖多个跨行业从业者：教培老师、律师、咨询师、美业、房产、保险、老板、知识IP……）
   - **C端用户**搜"XX赛道爆款内容/博主"（XX=用户所在内容领域）
   - 用户差异化是"AI+赛道"时，额外用"AI+商业/AI+IP/AI+获客/AI+一人公司"补齐AI类对标，**AI类至少占对标池1/3**
3. 按"最多点赞"排序，看前20条爆款笔记/视频
4. 统计这些爆款是谁发的，出现频率最高的3-5个博主就是最值得对标的
5. 把这3-5个博主列给用户，让她挑1-2个最对味的

**注意**：
- **B端用户只看B端账号**（教从业者/老板变现的），C端账号（直接做给消费者看的内容号）直接跳过；反之亦然。判断方法：看这个账号教的是"从业者怎么获客变现"还是"给最终用户做内容"。
- **跨行业优先**：不要只搜用户所在行业，还要搜其他行业里"同打法"的账号（比如用户做咨询师陪跑，可以对标教培招生、律师获客、AI+老板IP的账号）。
- 不要只看粉丝量，要看最近30天的赞数——有些小号最近爆了，比大号更值得对标
- 如果某个博主在这个平台赞数很低（说明主战场不在这），直接跳过
- 推荐时简单说一句每个博主的特点（比如"鲁细细：21万粉，专做知识IP变现"）
- 从全网（抖音/官网/文章）找到的候选，如果用户要求，需逐一核实其在小红书/目标平台的实际账号和流量，确认没号/没流量的筛掉

**筛选标准**：
- 最近30天有百赞以上的爆款
- 内容方向和用户的赛道/客单价匹配
- **业务端一致（B端对B端，C端对C端）**
- **跨行业优先，AI类占1/3以上（若用户是AI+赛道）**
- 平台一致（不要拿抖音大V对小红书）

### 第 0.5 步：小红书实战流程（如果用户主战场是小红书）

**不要搜泛关键词**（"高客单知识IP"这种搜出来的内容太泛），直接搜用户给的对标博主名字。

用 `mac_computer_use_tool`（plane="bu"）上小红书：

```python

bu.wait_for_load()
bu.scroll(500, 400, "down", amount=2)
bu.wait_for_load(timeout=3)

# 抓取所有笔记：标题、链接、博主、日期、赞数

const results = [];
items.forEach(item => {

    const authorEl = item.querySelector('a.author');

    results.push({

"""
print(bu.js(js_code))
```

**筛选规则：**
- 只保留最近30天内发布的
- 只保留百赞以上的
- 给用户列成表格：标题、博主、日期、赞数、可点击链接
- 让用户自己点链接看原文，挑"哪个句式能洗"

### 第 1 步：确认对标账号（抖音/通用）

- 用户给账号名时，先用 `general_search` 搜"账号名 + 平台 + 关键词"，确认账号主体、平台、定位简介。
- 搜 10-15 条该账号的代表性视频公开链接。

### 第 2 步：按方向分类

把搜到的内容按方向归堆：

| 方向 | 内容特征 |
|---|---|
| 认知升维 | 反常识判断、行业趋势、重新定义大词 |
| 做IP方法论 | 怎么做内容、怎么做分层、怎么涨粉 |
| 组织/一人公司 | 配工具、蒸馏员工、组织重构 |
| 变现/赚钱逻辑 | 学员结果、案例拆解、高客单打法 |
| 落地实操/见证 | 真实客户、现场演示、工作台录屏 |

每条标注：标题、一句话内容、钩子类型、跳转链接。

### 第 3 步：生成灵感台 HTML

**小红书平台**：用 `assets/xiaohongshu-idea-board.html` 模板。
- 按**内容方向**分类（不是按博主），5个方向：
  1. 反常识认知（"越拍自己越火不了"）
  2. 做IP方法论（"如何做一个以赚钱为目的的账号"）
  3. 高客单成交（"如何吸引高端客户看一眼就买"）
  4. AI+商业（"我把AI工具免费公开为什么更赚钱"）
  5. 搞钱变现（"博主赚钱有4个层次"）
- 每条卡片必须有：
  - 标题（原标题，不改字）
  - 一句话提炼（这个钩子为什么能爆）
  - 钩子类型标签（反常识否定/数字+结果/自曝结果/秘密感/情绪冲击……）
  - 可点链接（直接跳原笔记）
  - 赞数标注
- 不要按博主分类，用户不关心是谁发的，关心的是选题方向。

**抖音/通用平台**：用 `assets/inspiration-board.html` 模板。
- 按5个方向分类：认知升维/做IP方法论/组织一人公司/变现逻辑/落地实操。

**通用要求**：
- 每张卡片就是一个 `<a>`，href 直接填原片/原笔记链接，target="_blank"。
- 跑 `html` skill 的 `scripts/shot.py` 自检。
- 用 `present_files` 交付 HTML。

### 第 4 步：问用户定位

1. 你是干嘛的（行业、产品、服务谁）
2. 你有什么真实数据（粉丝量、成交、学员数、年限）
3. 你想让视频带来什么（涨粉/卖课/接咨询）

### 第 5 步：出句式对版表（核心交付）

- 挑出钩子最冲、最有辨识度的 8-12 条原句。
- 两列表格：左列原句，右列用户版本。
- 右列只用用户自己的真实素材，不能编。
- 如果用户的差异化是"AI+赛道"，用"AI重讲"法：原句式前面加"AI"，或把人群换成用户的受众。

详细方法见 `references/pattern-matching.md`。

### 第 6 步：用户挑完后写逐字稿

- 用户挑 1-3 条后，每条写完整内容（抖音60秒口播 / 小红书图文笔记）。
- 写完让用户念/看，标出"不像我会说的"，继续调。

### 第 7 步：每日选题推荐（定时任务 / 日更场景用）

每天输出固定结构，两部分选题 + 1 个推荐：

1. **对标账号爆款**：对标池账号最近30天百赞以上的爆款，按5个内容方向分类，标注：标题、平台、账号名、点赞数、核心观点。
2. **全网采集爆款**：用关键词在平台全网搜索最近30天百赞以上的其他爆款（不限于对标账号），同样按5个方向分类标注。
3. **每日推荐 1 个选题**：从两部分中挑最适合用户的那一条，改写为用户的风格（测评获客、高客单方向），**必须包含以下要素，缺一不可**：
   - ① **我的版本**：完整标题 + 钩子 + 内容方向
   - ② **原标题**：被洗的爆款原句，一字不改，标注原平台 + 原账号 + 原点赞数（用户要靠"原标题+原赞数"判断这条值不值得洗）
   - ③ **为什么推荐**：2-3 句理由——原爆款爆在哪（钩子类型/数字反差）、和用户的匹配点（人群/客单价/打法）
   - ④ **形式标注**：适合"视频"还是"图文"：
     - **视频**：钩子强、需要口播/画面/情绪冲击（反常识判断、自曝结果、观点挑衅、现场演示）
     - **图文**：清单型、收藏型、避坑型、方法论拆解（数字清单、分层讲解、步骤教程、案例拆解）
     - 判断依据：选题的钩子靠"说出来的冲击力"还是靠"读起来可收藏的结构"。

### 第 8 步：衔接洗稿智能体（独立 skill / 用户自有智能体）

- **洗稿是独立能力，不塞进本 skill**：本 skill 负责"找选题 + 出句式对版表 + 每日推荐"，中间产物=原句 + 用户版本 + 原标题/原赞数/推荐理由/形式标注。
- 把每日推荐或对版表里挑中的那一条，**交接给洗稿智能体**（用户自己的智能体，或独立洗稿 skill）：它基于用户的真实素材（粉丝数、营收、学员数、产品价格）写成完整稿，并去 AI 味。
- **分工**：本 skill 管"洗哪条"，洗稿智能体管"怎么洗成稿"。
- **架构参考 dbs 家族**：总入口编排 + 单点能力独立（一个总入口 + 几十个单点 skill，每个只干一件事）。多个 skill 在同一聊天窗口自动切换——用户说人话，Agent 自动调用对应能力，无需手动切换；不要做"一个 HTML 全流程工作台"当系统维护。

### 第 9 步：起标题（可选衔接，不依赖 dbs）

成稿或每日推荐需要标题候选时：
- 若用户已安装 `dbs-xhs-title`（dbs 的 75 个标题公式库）→ 调用它生成标题候选；
- **未安装 dbs 也跑得通**——用本 skill 内置的"小红书爆款标题类型"（6 类公式，见下文）生成标题。

## 小红书爆款标题类型（参考）

| 类型 | 公式 | 例子 |
|---|---|---|
| 情绪冲击 | "被[价格][人群]的思路深深震撼到" | 被高客单疗愈师的思路深深震撼到 |
| 反常识/否定 | "劝你别XX" / "千万别XX" | 劝你别做高客单IP，除非你想清楚这3件事 |
| 身份代入 | "[身份标签]怎么[做某事]" | i人咨询师怎么接高客单？ |
| 数字结果 | "[时间]做到[数字]，我做对了什么" | 1万粉成交8位数，我到底做对了什么 |
| 对比反差 | "同样[事]，为什么[她]3倍" | 同样做咨询，为什么她1个月顶你半年 |
| 踩坑血泪 | "踩过[数量]个坑后总结的" | 陪跑1000个咨询师后，穷的都有同一个毛病 |

详细方法见 `references/hook-taxonomy.md`。
