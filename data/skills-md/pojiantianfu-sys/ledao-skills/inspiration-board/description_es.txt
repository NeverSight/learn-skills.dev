Workbench de Inspiración de Temas. Encuentra automáticamente cuentas de referencia (distinguiendo B2B/C‑end, priorizando cross‑industry, proporción de categoría IA), busca su contenido representativo, lo clasifica por estilo de plataforma y dirección de contenido, y genera un tablero de inspiración HTML clicable; luego, combinado con el posicionamiento propio del usuario, utiliza las estructuras de frase nativas de las cuentas de referencia para generar temas adecuados para él. Soporta el método de reescritura “AI Re‑tell”: mantiene intacta la frase original, solo cambia el término de audiencia y añade elementos de IA. Recomendación diaria = hits de referencia + hits recopilados a nivel web, con título original / número de likes original / razón de recomendación / anotaciones de video‑texto. Se usa cuando el usuario dice “Ayúdame a revisar una cuenta determinada,” “Quiero tomar como referencia una cuenta determinada,” “Dame inspiración de temas,” “Crea un tablero de inspiración,” “Encuentra dirección a partir de una cuenta determinada,” “Ayúdame a reescribir temas de Xiaohongshu,” “Ayúdame a encontrar cuentas de referencia.”
