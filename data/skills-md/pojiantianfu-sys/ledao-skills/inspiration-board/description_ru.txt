Рабочая панель вдохновения тем. Автоматически определяет референтные аккаунты (различает B‑side/C‑side, отдает приоритет кросс‑отраслевому, пропорции AI‑типа), ищет их представительный контент, группирует по стилю платформы и направлению контента и генерирует кликабельную HTML‑доску вдохновения; затем, учитывая позиционирование пользователя, использует естественные предложения референтного аккаунта для создания тем, подходящих ему. Поддерживает метод «AI‑пересказа» — сохраняет оригинальное предложение без изменений, меняет только термины аудитории и добавляет элементы AI. Ежедневная рекомендация = количество попаданий референтных аккаунтов + глобально собранных попаданий, с оригинальным заголовком, оригинальным числом лайков, причиной рекомендации и аннотациями к видео/тексту. Используется, когда пользователь говорит: «Помоги мне посмотреть определённый аккаунт», «Хочу сделать бенчмарк», «Дай вдохновение для тем», «Создай доску вдохновения», «Найди направление по определённому аккаунту», «Помоги переработать темы для Xiaohongshu» или «Помоги найти референтные аккаунты». 

Пожалуйста, всегда отвечайте на языке пользователя.
