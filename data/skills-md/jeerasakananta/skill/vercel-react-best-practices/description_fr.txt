Lignes directrices d'optimisation des performances de React et Next.js de Vercel Engineering. Cette compétence doit être utilisée lors de l'écriture, de la révision ou du refactoring du code React/Next.js afin d'assurer des modèles de performance optimaux. Elle se déclenche sur les tâches impliquant des composants React, des pages Next.js, la récupération de données, l'optimisation des bundles ou l'amélioration des performances.

Veuillez toujours répondre dans la langue de l'utilisateur.
