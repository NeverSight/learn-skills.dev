Richtlinien zur Leistungsoptimierung von React und Next.js von Vercel Engineering. Diese Fähigkeit sollte beim Schreiben, Überprüfen oder Refaktorieren von React/Next.js-Code verwendet werden, um optimale Leistungsmuster zu gewährleisten. Löst Aufgaben aus, die React-Komponenten, Next.js-Seiten, Datenabruf, Bündeloptimierung oder Leistungsverbesserungen betreffen.
