Passez en revue les modifications depuis un point fixe (commit, branche, tag ou merge‑base) selon deux axes : Standards (le code suit‑il les standards de codage documentés de ce dépôt ?) et Spécification (le code correspond‑il à ce que demandait le ticket ou la spécification d’origine ?). Exécutez les deux revues en parallèle via des sous‑agents et présentez‑les côte à côte. Utilisez‑le lorsque l’utilisateur veut examiner une branche, une PR, des changements en cours ou demande de « revoir depuis X ».
