Überprüfe die Änderungen seit einem festen Punkt (Commit, Branch, Tag oder Merge‑Base) entlang zweier Achsen: Standards (entspricht der Code den in diesem Repository dokumentierten Codierungsstandards?) und Spezifikation (stimmt der Code mit dem überein, was das zugrunde liegende Issue/Spec verlangt hat?). Führt beide Prüfungen in parallel arbeitenden Sub‑Agenten durch und stellt sie nebeneinander dar. Verwende dies, wenn der Benutzer einen Branch, einen Pull‑Request, Änderungen in Arbeit prüfen möchte oder um „Review seit X“ bittet.
