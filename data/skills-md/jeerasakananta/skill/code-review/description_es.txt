Revisa los cambios desde un punto fijo (commit, rama, etiqueta o merge‑base) a lo largo de dos ejes: Estándares (¿el código sigue los estándares de codificación documentados en este repositorio?) y Especificación (¿el código coincide con lo que pidió el issue/especificación original?). Ejecuta ambas revisiones en subagentes paralelos y las muestra lado a lado. Úsalo cuando el usuario quiera revisar una rama, un PR, cambios en progreso o pida “revisar desde X”.
