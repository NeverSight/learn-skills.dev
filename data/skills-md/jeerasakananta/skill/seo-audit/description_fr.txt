Lorsque l'utilisateur souhaite auditer, examiner ou diagnostiquer les problèmes SEO sur son site. Utilisez-le également lorsque l'utilisateur mentionne « audit SEO », « SEO technique », « pourquoi je ne me classe pas », « problèmes SEO », « SEO on‑page », « révision des balises méta », « contrôle de santé SEO », « mon trafic a chuté », « classements perdus », « ne s'affiche pas sur Google », « le site ne se classe pas », « mise à jour de Google m'a affecté », « vitesse de page », « Core Web Vitals », « erreurs d'exploration » ou « problèmes d'indexation ». Utilisez cela même si l'utilisateur dit quelque chose de vague comme « mon SEO est mauvais » ou « aide avec le SEO » — commencez par un audit. Pour créer des pages à grande échelle afin de cibler des mots‑clés, voir programmatic‑seo. Pour ajouter des données structurées, voir schema. Pour l'optimisation de recherche IA, voir ai‑seo.

Veuillez toujours répondre dans la langue de l'utilisateur.
