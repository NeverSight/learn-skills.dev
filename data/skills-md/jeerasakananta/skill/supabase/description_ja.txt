Supabase に関わるすべてのタスクで使用してください。トリガー: Supabase 製品（Database、Auth、Edge Functions、Realtime、Storage、Vectors、Cron、Queues）；Next.js、React、SvelteKit、Astro、Remix におけるクライアントライブラリと SSR 統合（supabase‑js、@supabase/ssr）；認証関連の問題（ログイン、ログアウト、セッション、JWT、クッキー、getSession、getUser、getClaims、RLS）；Supabase CLI または MCP サーバー；スキーマ変更、マイグレーション、宣言的スキーマ、セキュリティ監査、Postgres 拡張機能（pg_graphql、pg_cron、pg_vector）；Supabase プロジェクトでのエラーや予期せぬ挙動のデバッグとトラブルシューティング（HTTP エラー、Postgres エラー、RLS の予期せぬ挙動、permission denied、スキーマキャッシュ問題、タイムアウト、Edge Function のクラッシュ、Realtime の停止、Storage の失敗）およびログの閲覧やクエリ（Logs Explorer、ClickHouse）。
