Utilisez-le lors de TOUTE tâche impliquant Supabase. Déclencheurs : produits Supabase (Base de données, Auth, Edge Functions, Realtime, Stockage, Vecteurs, Cron, Queues) ; bibliothèques clientes et intégrations SSR (supabase-js, @supabase/ssr) dans Next.js, React, SvelteKit, Astro, Remix ; problèmes d'authentification (connexion, déconnexion, sessions, JWT, cookies, getSession, getUser, getClaims, RLS) ; CLI Supabase ou serveur MCP ; changements de schéma, migrations, schémas déclaratifs, audits de sécurité, extensions Postgres (pg_graphql, pg_cron, pg_vector) ; débogage et résolution de problèmes ou comportements inattendus sur les projets Supabase (erreurs HTTP, erreurs Postgres, surprises RLS, permission refusée, problèmes de cache de schéma, délais d'attente, plantages d'Edge Functions, pannes de Realtime, échecs de stockage) et lecture ou interrogation des journaux (Explorateur de journaux, ClickHouse).
