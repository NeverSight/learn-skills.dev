Esegui git commit con analisi dei messaggi conventional commit, staging intelligente e generazione del messaggio. Usalo quando l’utente richiede di effettuare un commit, crea un git commit o menziona “/commit”. Supporta: (1) Rilevamento automatico di tipo e ambito dalle modifiche, (2) Generazione di messaggi conventional commit dal diff, (3) Commit interattivo con sovrascritture opzionali di tipo/ambito/descrizione, (4) Staging intelligente dei file per raggruppamenti logici

Per favore rispondi sempre nella lingua dell’utente.
