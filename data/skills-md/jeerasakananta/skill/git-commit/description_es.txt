Ejecución de git commit con análisis de mensajes convencionales, staging inteligente y generación de mensajes. Use cuando el usuario solicite confirmar cambios, crear un commit de git o mencione "/commit". Soporta: (1) Detección automática del tipo y alcance a partir de los cambios, (2) Generación de mensajes de commit convencionales desde el diff, (3) Commit interactivo con sobrescritura opcional de tipo/alcance/descripción, (4) Staging inteligente de archivos para agrupación lógica

Por favor, responda siempre en el idioma del usuario.
