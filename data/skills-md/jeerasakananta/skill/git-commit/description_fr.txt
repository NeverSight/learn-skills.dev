Exécuter un commit git avec analyse de message de commit conventionnel, mise en scène intelligente et génération de message. À utiliser lorsque l'utilisateur demande de valider des changements, de créer un commit git, ou mentionne « /commit ». Prend en charge : (1) Détection automatique du type et du périmètre à partir des changements, (2) Génération de messages de commit conventionnels à partir du diff, (3) Commit interactif avec des surcharges optionnelles du type/périmètre/description, (4) Mise en scène intelligente des fichiers pour un regroupement logique

Veuillez toujours répondre dans la langue de l'utilisateur.
