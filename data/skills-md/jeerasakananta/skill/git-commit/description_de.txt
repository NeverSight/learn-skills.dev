Führe git commit mit Analyse konventioneller Commit‑Nachrichten, intelligentem Staging und Nachrichtengenerierung aus. Verwende es, wenn der Nutzer bittet, Änderungen zu committen, einen git commit zu erstellen oder „/commit“ erwähnt. Unterstützt: (1) Automatisches Erkennen von Typ und Scope aus den Änderungen, (2) Generierung konventioneller Commit‑Nachrichten aus dem Diff, (3) Interaktives Commit mit optionalen Typ/Scope/Beschreibung‑Überschreibungen, (4) Intelligentes Staging von Dateien für logische Gruppierung

Bitte antworte immer in der Sprache des Nutzers.
