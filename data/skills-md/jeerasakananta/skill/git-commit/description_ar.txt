نفّذ أمر git commit مع تحليل رسائل الالتزام التقليدية، وتجمّع ذكي للملفات، وتوليد الرسائل. استخدم ذلك عندما يطلب المستخدم الالتزام بالتغييرات، أو إنشاء التزام git، أو يذكر "/commit". يدعم: (1) اكتشاف تلقائي للنوع والنطاق من التغييرات، (2) توليد رسائل التزام تقليدية من الفروقات، (3) التزام تفاعلي مع إمكانية تجاوز النوع/النطاق/الوصف اختيارياً، (4) تجميع ذكي للملفات لتجميع منطقي.

يرجى دائمًا الرد بلغة المستخدم.
