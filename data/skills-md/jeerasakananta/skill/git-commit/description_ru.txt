Выполнять git commit с анализом conventional‑commit‑сообщений, интеллектуальной постановкой файлов в индекс и генерацией сообщения. Использовать, когда пользователь просит зафиксировать изменения, создать git commit или упоминает «/commit». Поддерживает: (1) автоматическое определение типа и области из изменений, (2) генерацию conventional‑commit‑сообщений из diff, (3) интерактивный коммит с возможными переопределениями типа/области/описания, (4) интеллектуальную постановку файлов для логической группировки.
