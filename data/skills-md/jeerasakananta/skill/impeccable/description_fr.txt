Utilisez-le lorsque l'utilisateur veut concevoir, redessiner, façonner, critiquer, auditer, peaufiner, clarifier, distiller, renforcer, optimiser, adapter, animer, coloriser, extraire ou autrement améliorer une interface front‑end. Cela couvre les sites web, les pages d’atterrissage, les tableaux de bord, les UI produit, les coquilles d’application, les composants, les formulaires, les paramètres, l’onboarding et les états vides. Il prend en charge la révision UX, la hiérarchie visuelle, l’architecture de l’information, la charge cognitive, l’accessibilité, les performances, le comportement réactif, le theming, les anti‑patterns, la typographie, les polices, les espacements, la mise en page, l’alignement, la couleur, le mouvement, les micro‑interactions, le texte UX, les états d’erreur, les cas limites, l’i18n et les systèmes de design réutilisables ou les jetons. Utilisez-le également pour des designs fades qui doivent devenir plus audacieux ou plus agréables, des designs trop criards qui doivent être atténués, des itérations en direct dans le navigateur sur les éléments UI, ou des effets visuels ambitieux qui doivent paraître techniquement extraordinaires. Pas pour les tâches purement back‑end ou non‑UI.

Veuillez toujours répondre dans la langue de l’utilisateur.
