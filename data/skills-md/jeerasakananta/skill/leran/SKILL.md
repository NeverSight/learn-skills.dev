# Learning Progress Tracker

## Overview
ช่วยจดบันทึกว่าเรียนอะไรไปแล้ว และอัปเดตไฟล์ .md แสดงความก้าวหน้าให้อัตโนมัติ

## When to Use
- user พิมพ์ว่า จดให้หน่อย, เรียนอะไรไปแล้ว, อัปเดตความก้าวหน้า, สรุปที่เรียน, บันทึกการเรียน
- user อยากได้ไฟล์ .md เก็บสิ่งที่เรียน

## วิธีทำงาน
1. ถามหรือดูจากบทสนทนาว่า: วันนี้เรียนเรื่องอะไร? หัวข้ออะไร? เข้าใจระดับไหน (1-5)?
2. หาไฟล์ log: ถ้ามี `PROGRESS.md` หรือ `LEARNING.md` ให้ใช้ต่อ ถ้าไม่มีให้สร้างใหม่
3. รูปแบบไฟล์ที่ต้องเขียน:
```md
# บันทึกการเรียน

## วันที่ 2026-09-13
- เรียน: [หัวข้อ]
- สรุปที่ได้: [3 ข้อสั้นๆ]
- ระดับความเข้าใจ: ⭐⭐⭐⭐ (4/5)
- ต้องทบทวน: [เรื่องที่ยังไม่แม่น]

## ความก้าวหน้ารวม
- เริ่ม: [วันแรก] -> ตอนนี้: [X%]
- เรียนไปแล้ว: [รายการหัวข้อ]
- เหลือ: [รายการที่ยังไม่ได้เรียน]
```
4. ทุกครั้งที่ user บอกว่าเรียนจบ 1 เรื่อง ให้ append ลงไฟล์เดิม + อัปเดตส่วนความก้าวหน้ารวม ห้ามลบของเก่า
5. ตอบกลับสั้นๆ เป็นภาษาไทยว่า จดแล้ว + สรุปความก้าวหน้าปัจจุบัน

## ห้ามทำ
- ห้ามลบประวัติเก่า
- ห้ามเขียนยาวเวิ่นเว้อ เน้นสั้น อ่านง่าย
- โค้ด/คำสั่งคงภาษาอังกฤษเดิม
