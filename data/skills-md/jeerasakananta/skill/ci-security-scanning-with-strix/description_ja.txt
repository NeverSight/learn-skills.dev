Strix を使って CI/CD にセキュリティスキャンを追加します — GitHub Actions、GitLab CI、または任意のパイプラインで — これにより、すべてのプルリクエストに差分スコープの AI ペンテストが実行され、マージ前に脆弱なコードをブロックし、結果は PR コメントとして表示され、SARIF 形式でコードスキャンにアップロードされます。セルフホスト型のオープンソース CLI（ランナー内で実行）と、マネージドの app.strix.ai プラットフォーム（GitHub/GitLab アプリまたは API、ランナーインフラ不要）の両方に対応しています。CI パイプライン、プリアップロードゲート、または PR ワークフローにセキュリティスキャン、SAST/DAST、ペンテスト、脆弱性チェック、または自動セキュリティレビューを追加したい場合に使用してください。
