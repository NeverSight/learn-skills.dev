Добавьте сканирование безопасности в CI/CD с помощью Strix — GitHub Actions, GitLab CI или любого другого конвейера — чтобы каждый запрос на слияние получал дифф‑ориентированный AI‑пенетест, блокирующий уязвимый код до его слияния, а результаты отображались в виде комментариев к запросу и SARIF‑отчётов, загружаемых в сканирование кода. Поддерживаются как самохостинговый open‑source CLI (работает в вашем runner’е), так и управляемая платформа app.strix.ai (приложение или API для GitHub/GitLab, без инфраструктуры runner). Используйте, когда пользователь просит добавить сканирование безопасности, SAST/DAST, пенетест, проверку уязвимостей или автоматический обзор безопасности в свой CI‑конвейер, предмерджинговый шлюз или workflow PR.
