أضف فحص الأمان إلى CI/CD باستخدام Strix — GitHub Actions أو GitLab CI أو أي خط أنابيب — بحيث يحصل كل طلب سحب على اختبار اختراق AI موجه إلى الاختلافات يمنع الكود الضعيف قبل دمجه، وتكون النتائج كتعليقات على طلب السحب وملف SARIF يتم رفعه إلى فحص الكود. يغطي كل من الأداة السطرية المفتوحة المصدر المستضافة ذاتيًا (تعمل في المشغّل الخاص بك) ومنصة app.strix.ai المدارة (تطبيق GitHub/GitLab أو API، بدون بنية تحتية للمشغّلات). استخدمه عندما يطلب المستخدم إضافة فحص أمان أو SAST/DAST أو اختبار اختراق أو فحوصات ثغرات أو مراجعة أمان تلقائية إلى خط أنابيب CI الخاص بهم، أو بوابة ما قبل الدمج، أو سير عمل طلب السحب.
