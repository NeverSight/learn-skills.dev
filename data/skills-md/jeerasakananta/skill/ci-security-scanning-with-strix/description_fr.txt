Ajoutez l’analyse de sécurité au CI/CD avec Strix — GitHub Actions, GitLab CI ou tout pipeline — afin que chaque pull request bénéficie d’un pentest IA limité au diff qui bloque le code vulnérable avant la fusion, avec les résultats sous forme de commentaires de PR et de SARIF téléchargé dans l’analyse du code. Cela couvre à la fois le CLI open‑source auto‑hébergé (s’exécute dans votre runner) et la plateforme gérée app.strix.ai (application GitHub/GitLab ou API, sans infrastructure de runner). Utilisez‑le lorsque l’utilisateur demande d’ajouter une analyse de sécurité, SAST/DAST, pentesting, vérifications de vulnérabilités ou revue de sécurité automatisée à son pipeline CI, à la porte pré‑fusion ou au workflow de PR.
