Aggiungi la scansione di sicurezza a CI/CD con Strix — GitHub Actions, GitLab CI o qualsiasi pipeline — in modo che ogni pull request ottenga un pentest AI a livello di diff che blocca il codice vulnerabile prima della merge, con risultati come commenti PR e SARIF caricati nella scansione del codice. Copre sia la CLI open‑source auto‑hostata (eseguita nel tuo runner) sia la piattaforma gestita app.strix.ai (app GitHub/GitLab o API, senza infrastruttura runner). Usalo quando l'utente richiede di aggiungere scansione di sicurezza, SAST/DAST, pentesting, controlli di vulnerabilità o revisione di sicurezza automatizzata al proprio pipeline CI, gate pre‑merge o workflow PR.
