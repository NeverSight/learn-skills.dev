Mejores prácticas de Postgres mantenidas por Supabase, para Postgres ejecutándose en cualquier lugar. Carga esta habilidad ANTES de escribir o modificar cualquier cosa que viva en una base de datos Postgres: crear o alterar tablas y columnas (incluyendo la elección de tipos de columna), diseño de esquemas, migraciones y archivos de esquemas declarativos, políticas RLS y las pruebas que las verifican, índices, triggers, funciones de base de datos, colas y trabajos programados (pg_cron, pgmq), búsqueda vectorial/semántica (pgvector), y restaurar dumps (pg_restore) o importar datos. También cárgala al diagnosticar consultas lentas, alto consumo de CPU, timeouts, planes EXPLAIN, agotamiento de conexiones, bloqueos, bloat, o filas visibles para el usuario o inquilino incorrecto. Esto no es solo una guía de rendimiento: tareas de esquema, migración, seguridad y redacción de SQL también requieren estas reglas, incluso para un cambio de una sola columna o una única consulta.
