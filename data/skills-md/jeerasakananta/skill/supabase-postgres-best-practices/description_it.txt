Best practice per Postgres mantenute da Supabase, per Postgres in esecuzione ovunque. Carica questa competenza PRIMA di scrivere o modificare qualsiasi cosa che risieda in un database Postgres: creazione o modifica di tabelle e colonne (inclusa la scelta dei tipi di colonna), progettazione dello schema, migrazioni e file di schema dichiarativi, politiche RLS e i test che le verificano, indici, trigger, funzioni di database, code e job programmati (pg_cron, pgmq), ricerca vettoriale/semantica (pgvector) e ripristino di dump (pg_restore) o importazione di dati. Caricala anche quando diagnostichi query lente, alto utilizzo CPU, timeout, piani EXPLAIN, esaurimento delle connessioni, blocchi, gonfiore, o righe visibili all'utente o al tenant sbagliato. Non è solo una guida alle prestazioni — anche le attività di schema, migrazione, sicurezza e scrittura SQL seguono queste regole, anche per una modifica di una sola colonna o una singola query.
