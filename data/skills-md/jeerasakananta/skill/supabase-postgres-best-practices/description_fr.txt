Meilleures pratiques Postgres maintenues par Supabase, pour Postgres fonctionnant partout. Chargez cette compétence AVANT d’écrire ou de modifier quoi que ce soit qui vit dans une base de données Postgres : créer ou modifier des tables et des colonnes (y compris le choix des types de colonnes), la conception du schéma, les migrations et les fichiers de schéma déclaratifs, les politiques RLS et les tests qui les vérifient, les index, les déclencheurs, les fonctions de base de données, les files d’attente et les travaux planifiés (pg_cron, pgmq), la recherche vectorielle/sémantique (pgvector), ainsi que la restauration de dumps (pg_restore) ou l’importation de données. Chargez‑la également lors du diagnostic de requêtes lentes, d’une forte utilisation du CPU, de time‑outs, de plans EXPLAIN, d’épuisement des connexions, de blocages, de gonflement, ou de lignes visibles par le mauvais utilisateur ou locataire. Ce n’est pas seulement un guide de performance — les tâches de schéma, de migration, de sécurité et de rédaction SQL nécessitent aussi ces règles, même pour une modification d’une seule colonne ou une requête unique.
