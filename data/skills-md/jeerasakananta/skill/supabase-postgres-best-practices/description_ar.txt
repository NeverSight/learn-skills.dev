أفضل ممارسات PostgreSQL التي تُديرها Supabase، لتشغيل PostgreSQL في أي مكان. احمِل هذه المهارة قبل كتابة أو تعديل أي شيء موجود في قاعدة بيانات PostgreSQL: إنشاء أو تعديل الجداول والأعمدة (بما في ذلك اختيار أنواع الأعمدة)، تصميم المخطط، الهجرات وملفات المخطط التصريحية، سياسات RLS والاختبارات التي تتحقق منها، الفهارس، المشغلات، الدوال في قاعدة البيانات، قوائم الانتظار والوظائف المجدولة (pg_cron، pgmq)، البحث المتجه/الدلالي (pgvector)، واستعادة النسخ الاحتياطية (pg_restore) أو استيراد البيانات. كما يجب تحميلها عند تشخيص الاستعلامات البطيئة، استهلاك مرتفع للمعالج، مهلات الوقت، خطط EXPLAIN، استنفاد الاتصالات، القفل، التضخم، أو الصفوف الظاهرة للمستخدم أو المستأجر الخطأ. هذه ليست مجرد دليل للأداء — فمهام تصميم المخطط، والهجرة، والأمان، وتأليف SQL تحتاج هذه القواعد أيضاً، حتى لتغيير عمود واحد أو استعلام واحد.
