اكتب أو راجع أو حسّن عناوين طلبات السحب (Pull Request) وأوصافها باتباع أفضل الممارسات — تنسيق عنوان واضح، وصف منظم (ما/لماذا/كيف/الاختبار)، ربط القضايا، وقائمة مراجعة صديقة للمراجعين. استخدم ذلك كلما طلب المستخدم كتابة طلب سحب، فتح طلب سحب، صياغة وصف طلب سحب، مراجعة جودة طلب السحب، أو تحضير فرع للدمج. كما يتم التفعيل عند العبارات مثل "เขียน PR"، "وصف PR"، "رسالة الالتزام لطلب السحب"، أو "جاهز للدمج؟".
