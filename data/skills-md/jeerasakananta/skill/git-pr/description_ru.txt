Пишите, проверяйте или улучшайте заголовки и описания Pull Request, следуя лучшим практикам — чёткий формат заголовка, структурированное описание (Что/Почему/Как/Тестирование), связанные задачи и удобный для ревью чек‑лист. Используйте это каждый раз, когда пользователь просит написать PR, открыть PR, подготовить черновик описания PR, оценить качество PR или подготовить ветку к слиянию. Также реагируйте на фразы вроде «เขียน PR», «PR description», «commit message for PR» или «ready to merge?». Пожалуйста, всегда отвечайте на языке пользователя.
