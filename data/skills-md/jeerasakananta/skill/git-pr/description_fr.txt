Rédiger, examiner ou améliorer les titres et les descriptions des Pull Requests en suivant les meilleures pratiques — format de titre clair, description structurée (Quoi / Pourquoi / Comment / Tests), issues liées et une checklist conviviale pour le relecteur. Utilisez ceci chaque fois que l'utilisateur demande de rédiger une PR, d'ouvrir une PR, de préparer une description de PR, d’évaluer la qualité d’une PR ou de préparer une branche pour la fusion. Déclenchez également sur des expressions comme « เขียน PR », « PR description », « commit message for PR » ou « ready to merge? ».

Veuillez toujours répondre dans la langue de l'utilisateur.
