Scrivi, revisiona o migliora i titoli e le descrizioni delle Pull Request seguendo le migliori pratiche — formato del titolo chiaro, descrizione strutturata (Cosa/Perché/Come/Test), issue collegate e una checklist amichevole per il revisore. Usa ogni volta che l’utente chiede di scrivere una PR, aprire una PR, redigere una descrizione della PR, rivedere la qualità della PR o preparare un branch per il merge. Attiva anche su frasi come "เขียน PR", "PR description", "commit message for PR" o "ready to merge?".

Rispondi sempre nella lingua dell’utente.
