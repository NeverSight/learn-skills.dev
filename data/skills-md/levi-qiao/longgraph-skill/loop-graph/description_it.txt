Compila un ciclo grafico durevole in esecutore, registro, direttive, operazioni e artefatti del supervisore in una directory ".longgraph" datata, quindi presenta prompt host pronti per la copia. Utilizzare direttamente per una forma multi-round personalizzata con traguardi delimitati, controllo indipendente, esecuzione tra host o stato durevole; i pacchetti gemelli mirati gestiscono la convergenza del codice, la fornitura dei requisiti e la ricerca basata sull'evidenza. I nodi di runtime esistenti sono autonomi.
