Créez et éventuellement lancez directement une exécution de graphique en boucle à deux nœuds dont l'étoile polaire est la convergence du code : supprimez le code inutilisé, fusionnez les doublons, réutilisez, amincissez. À utiliser lorsque l'utilisateur invoque /loop-converge ou demande de faire une boucle sur du code mort, une duplication, des exportations inutilisées, un nettoyage à sec ou la fusion d'implémentations jumelles. Commence immédiatement l’entretien avec le propriétaire (portée/autorité/lancement) ; un superviseur est requis. Pas pour ajouter des fonctionnalités ou un rangement unique. N'exécutez pas et ne reprenez pas les fichiers de nœud d'exécution existants à partir de cette compétence de création.
