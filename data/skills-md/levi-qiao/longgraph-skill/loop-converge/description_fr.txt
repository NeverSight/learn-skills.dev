Rédiger et éventuellement lancer directement une exécution à deux nœuds d’un graphe de boucle dont l’étoile polaire est la convergence du code — supprimer le code inutilisé, fusionner les doublons, réutiliser, alléger. Utiliser lorsque l’utilisateur invoque /loop-converge, ou demande de boucler sur du code mort, des duplications, des exportations inutilisées, un nettoyage DRY ou la fusion d’implémentations jumelles. Démarre immédiatement l’interview du propriétaire (portée / autorité / lancement) ; un superviseur est requis. Ce n’est pas destiné à ajouter des fonctionnalités ou à un nettoyage ponctuel. Ne pas exécuter ou reprendre les fichiers de nœuds d’exécution existants à partir de cette compétence d’auteur.
