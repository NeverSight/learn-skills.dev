Автоматизирует чтение, поиск, составление и отправку электронных писем И событий календаря в классическом Outlook для Windows с помощью локальной автоматизации COM. Используйте этот навык, когда пользователь просит обрабатывать электронные письма Outlook, создавать черновики, отправлять сообщения, сохранять вложения, управлять событиями календаря, создавать собрания или отвечать на приглашения из сеанса Outlook с аутентификацией в своем Windows Devbox. Для работы требуется классический Outlook (а не новый Outlook).
