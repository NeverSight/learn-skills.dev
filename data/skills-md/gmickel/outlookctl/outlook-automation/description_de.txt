Automatisiert das Lesen, Suchen, Verfassen und Senden von E-Mails UND Kalenderereignissen im klassischen Outlook unter Windows mithilfe der lokalen COM-Automatisierung. Verwenden Sie diese Fähigkeit, wenn der Benutzer Outlook-E-Mails verarbeiten, Entwürfe erstellen, Nachrichten senden, Anhänge speichern, Kalenderereignisse verwalten, Besprechungen erstellen oder auf Einladungen aus der authentifizierten Outlook-Sitzung auf seiner Windows Devbox antworten möchte. Erfordert die Ausführung von Classic Outlook (nicht New Outlook).
