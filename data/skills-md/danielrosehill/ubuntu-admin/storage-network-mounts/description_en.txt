Set up, check and repair NFS and SMB/CIFS network mounts on Ubuntu — client packages, discovering exports and shares, testing a mount, persistent fstab or systemd automount entries that don't hang boot, credentials files, ownership mapping, and stale-handle recovery. Use when asked "mount the NAS", "add an NFS share", "mount a Samba/Windows share", "my network drive is not mounted", "stale file handle", "boot hangs on a network mount", or "check NFS mounts". Works on the local machine or a remote host over SSH.
