Inventory and set up a developer environment on Ubuntu — Python (system python3 vs uv, pipx, pyenv, venv and conda detection; never pip into the system interpreter), Node.js (nvm/fnm vs apt/snap, version check), Java and other SDKs via SDKMAN, other toolchains on PATH, and git global configuration (identity, default branch, pull strategy, global gitignore) plus gh authentication. Use when asked "what Python environments do I have", "set up pyenv / uv", "which node version", "install npm", "what SDKs are installed", "check my git config", "set up a global gitignore". Works on the local machine or a remote host over SSH.
