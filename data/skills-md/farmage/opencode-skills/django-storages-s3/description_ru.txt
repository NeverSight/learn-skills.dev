Используется при настройке Django для хранения статических и медиа‑файлов в AWS S3 с помощью django-storages. Применяется при работе с параметром STORAGES, корзинами S3, подписанными URL, CloudFront или файловым хранилищем на основе boto3 в settings.py. Настраивает словарь STORAGES в Django 4.2+, пользовательские бэкенды для публичного/приватного доступа, подписанные GET/POST URL, политики IAM и моделирование S3 для тестов. Триггерные термины: django-storages, S3, boto3, S3Boto3Storage, STORAGES, подписанный URL, CloudFront, медиа‑файлы, collectstatic, AWS_STORAGE_BUCKET_NAME.
