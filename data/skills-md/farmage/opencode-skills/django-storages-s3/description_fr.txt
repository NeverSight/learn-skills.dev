Utilisé lors de la configuration de Django pour stocker les fichiers statiques et médias sur AWS S3 avec django-storages. À invoquer lors de la manipulation du paramètre STORAGES, des compartiments S3, des URL présignées, de CloudFront ou du stockage de fichiers basé sur boto3 dans settings.py. Configure le dictionnaire STORAGES de Django 4.2+, les backends personnalisés publics/privés, les URL GET/POST présignées, les politiques IAM et le mock S3 pour les tests. Termes déclencheurs : django-storages, S3, boto3, S3Boto3Storage, STORAGES, URL présignée, CloudFront, fichiers médias, collectstatic, AWS_STORAGE_BUCKET_NAME.
