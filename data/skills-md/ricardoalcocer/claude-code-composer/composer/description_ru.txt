Создайте проект Reaper (.RPP) + портативные MIDI‑файлы на основе короткого описания аккордовой прогрессии в различных мелодических стилях — мелодический инструментальный рок (Satriani/Vai/Plini/Polyphia), кинематический/эмоциональный/грустный (Hisaishi/Zimmer/Ólafur), испанский/фригийский/фламенко, пост‑рок/атмосферный, djent/prog‑metal, synthwave/retro, jazz‑funk/fusion (Jack Thammarat/Coltrane changes), math rock/Midwest emo (American Football/TTNG). Используйте, когда пользователь просит аккордовую подложку, набросок песни, «виб», чтобы импровизировать, куплет/припев/мост в определённой тональности или стиле («испанский мост», «грустная пианиновая пьеса», «synthwave‑луп», «math‑rock‑луп») либо «MIDI для джема». Вывод сразу вставляется в Reaper, используя пользовательский шаблон проекта.
