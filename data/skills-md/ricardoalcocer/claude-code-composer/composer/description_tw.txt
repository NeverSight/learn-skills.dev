根據和弦進行簡報，生成 Reaper 專案 (.RPP) 並產出可攜式 MIDI 檔案，支援多種旋律風格——旋律式器樂搖滾（Satriani/Vai/Plini/Polyphia）、電影／情感／悲情（久石讓／Zimmer／Ólafur）、西班牙／弗里吉亞／弗拉明戈、後搖滾／氛圍、djent／前衛金屬、合成波／復古、爵士放克／融合（Jack Thammarat／Coltrane 變化）、數學搖滾／中西部 emo（American Football／TTNG）。  
當使用者要求和弦底層、歌曲草圖、即興氛圍、特定調性或風格的 verse／chorus／bridge（例如「西班牙橋段」、「悲傷鋼琴曲」、「合成波迴路」、「數學搖滾迴路」）或「可即興演奏的 MIDI」時，即可使用。輸出會直接匯入 Reaper，使用使用者設定的專案模板。
