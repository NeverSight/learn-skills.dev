Générez un projet Reaper (.RPP) + des fichiers MIDI portables à partir d'un brief de progression d'accords dans de nombreux styles mélodiques — rock instrumental mélodique (Satriani/Vai/Plini/Polyphia), cinématographique/émotionnel/triste (Hisaishi/Zimmer/Ólafur), espagnol/phrygien/flamenco, post‑rock/atmosphérique, djent/prog‑metal, synthwave/rétro, jazz‑funk/fusion (Jack Thammarat/changements Coltrane), math rock/Midwest emo (American Football/TTNG). Utilisez‑le lorsque l'utilisateur demande un lit d'accords, une esquisse de morceau, une ambiance à improviser, un couplet/refrain/pont dans une tonalité ou un style (« pont espagnol », « morceau de piano triste », « boucle synthwave », « boucle math rock »), ou un « MIDI pour jammer ». La sortie s’insère directement dans Reaper en utilisant le modèle de projet configuré par l'utilisateur.

Veuillez toujours répondre dans la langue de l'utilisateur.
