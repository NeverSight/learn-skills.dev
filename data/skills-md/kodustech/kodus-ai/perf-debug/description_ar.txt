تصحيح الأداء من الطرف الأمامي إلى الخلفية بالكامل لتطبيق كودوس الويب. يُستخدم عندما تكون الشاشة بطيئة أو فارغة أو تتكرر، أو عندما تحتاج إلى تتبع مشكلة أداء واجهة المستخدم إلى استعلام الـ API. يُشغّل Playwright/Chrome MCP لفتح الشاشة وقياسها، ثم يقرأ حالة الاستخدام/المستودع للـ API وقاعدة البيانات (فهارس Postgres/Mongo، شرح) لإيجاد السبب الجذري وإصلاحه، مع التحقق مباشرة.
