Сквозная отладка производительности от фронтенда к бэкенду для веб‑приложения Kodus. Используется, когда экран работает медленно, пустой, зацикливается или необходимо отследить проблему UI‑производительности до запроса API. Запускает Playwright/Chrome MCP для открытия и измерения экрана, затем анализирует используемый кейс/репозиторий API и базу данных (индексы Postgres/Mongo, explain), чтобы найти и устранить коренную причину, проверяя результат в реальном времени.
