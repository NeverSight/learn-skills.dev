Depuración de rendimiento front→back de extremo a extremo para la aplicación web Kodus. Úsalo cuando una pantalla es lenta, está en blanco, se repite, o necesitas rastrear un problema de rendimiento de UI hasta la consulta API. Controla Playwright/Chrome MCP para abrir y medir la pantalla, luego lee el caso de uso/repositorio de la API y la base de datos (índices de Postgres/Mongo, explain) para encontrar y corregir la causa raíz, verificando en vivo.
