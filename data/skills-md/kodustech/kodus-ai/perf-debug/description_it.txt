Debugging delle prestazioni end‑to‑end dal front‑end al back‑end per l'app web Kodus. Da utilizzare quando una schermata è lenta, bianca, in loop, o quando è necessario tracciare un problema di performance UI fino alla query API. Avvia Playwright/Chrome MCP per aprire e misurare la schermata, quindi legge il caso d'uso/repository dell'API e il DB (indici Postgres/Mongo, explain) per trovare e correggere la causa radice, verificando in tempo reale.
