Débogage de performance de bout en bout du front au back pour l’application web Kodus. À utiliser lorsqu’un écran est lent, blanc, boucle, ou que vous devez tracer un problème de performance UI jusqu’à la requête API. Pilote Playwright/Chrome MCP pour ouvrir + mesurer l’écran, puis lit le cas d’utilisation/référentiel API et la BD (index Postgres/Mongo, EXPLAIN) afin de trouver et corriger la cause racine, en vérifiant en direct.
