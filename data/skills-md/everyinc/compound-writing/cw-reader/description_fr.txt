Réviser le texte comme le ferait un lecteur visé le découvrant pour la première fois, sans accès au contexte implicite de l’auteur. Identifier les formulations confuses, les explications manquantes, les connaissances supposées, les attentes brisées, les moments qui sapent la confiance ou qui rebutent, et les points où le lecteur pourrait s’arrêter. Utiliser pour les lectures à froid, les revues à œil neuf, les perspectives de premier lecteur, les vérifications du parcours du lecteur, ou les retours sur ce qui paraît confuse, incomplet, aliénant ou difficile à suivre.

Veuillez toujours répondre dans la langue de l’utilisateur.
