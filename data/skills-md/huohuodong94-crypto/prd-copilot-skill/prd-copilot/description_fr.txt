Flux de travail des exigences produit pour les chefs de produit et les fondateurs. À utiliser lorsque l'utilisateur souhaite concevoir un agent IA, un produit IA, un assistant IA, un service habilité à l'IA, ou toute exigence produit à partir d'une idée vague, d'une demande de fonctionnalité, de notes de réunion, d'un PRD existant, d'une analyse concurrentielle, ou de phrases telles que « 我要做一个 AI Agent », « 我要设计一个 AI 产品 », « 我要做一个AI外卖 », « 我要做一个AI旅游助手 ». D'abord, déterminer si l'entrée est liée aux exigences produit ; sinon, ne pas appliquer ce flux de travail. Lorsque les exigences sont vagues, clarifier avant de générer un PRD. Produire des PRD concis en Markdown et les sections PRD sélectionnées pour les agents de codage ou les discussions produit.

Veuillez toujours répondre dans la langue de l'utilisateur.
