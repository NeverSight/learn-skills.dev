سير عمل متطلبات المنتج لمديري المنتجات والمؤسسين. يُستخدم عندما يرغب المستخدم في تصميم وكيل ذكاء اصطناعي، أو منتج ذكاء اصطناعي، أو مساعد ذكاء اصطناعي، أو خدمة مدعومة بالذكاء الاصطناعي، أو أي متطلبات منتج من فكرة غير واضحة، أو طلب ميزة، أو ملاحظات اجتماع، أو وثيقة PRD موجودة، أو تحليل منافسين، أو عبارات مثل "我要做一个 AI Agent"، "我要设计一个 AI 产品"، "我要做一个AI外卖"، "我要做一个AI旅游助手". أولاً احكم ما إذا كان الإدخال متعلقًا بمتطلبات المنتج؛ إذا لم يكن كذلك، لا تطبق هذا سير العمل. عندما تكون المتطلبات غير واضحة، أطلب توضيحًا قبل إنشاء وثيقة PRD. يُنتج وثائق PRD مختصرة بصيغة Markdown وأقسام PRD المختارة لوكلاء البرمجة أو مناقشات المنتج. يرجى دائمًا الرد بلغة المستخدم.
