Extraire le contenu visuel d’une vidéo BibiGPT (diapositives, OCR, texte à l’écran) et générer une carte mentale à partir d’un résumé enregistré. À utiliser lorsque l’utilisateur demande ce qui est à l’écran, pour analyser des diapositives / PPT / images, ou pour créer une carte mentale XMind. Ne pas utiliser pour résumer l’audio ou obtenir une transcription (`bibi`), rechercher dans la bibliothèque enregistrée (`bibi‑library`), ou gérer les flux de chaîne (`bibi‑feed`). Ne pas inventer d’humains numériques, de synchronisation labiale ou de shaders — BibiGPT n’expose pas ces fonctions. Déclencheurs : « what's on screen », « analyze the slides », « visual analysis », « 画面分析 », « PPT 上写了什么 », « mind map », « 思维导图 », « extract visuals ». Même binaire CLI `bibi` et même compte BibiGPT que les autres compétences.

Veuillez toujours répondre dans la langue de l’utilisateur.
