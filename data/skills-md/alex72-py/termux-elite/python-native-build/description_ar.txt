تشخيص فشل تثبيت Python على Termux أو Android (أخطاء المترجم أو رؤوس الملفات، بناءات Rust أو maturin، عدم وجود wheel لهذه المنصة، wheels الخاصة بـ glibc التي تفشل عند الاستيراد، البيئة المُدارة خارجيًا) واختيار أصغر حل، مع تفضيل مكتبات Termux المعبأة (المستودع الرئيسي، ثم tur-repo بعد الموافقة) على بناء المصدر. استخدم ذلك عندما يفشل pip أو uv، عندما يذكر خطأ البناء clang أو cc أو cargo أو rustc أو ملف .h مفقود، أو عندما يفشل الاستيراد مباشرةً بعد تثبيت ناجح. لا تستخدمه لتنزيلات بطيئة، أو حزم pure-Python التي تثبت بنجاح، أو مشكلات Node (انظر node-native-build). يرجى دائمًا الرد بلغة المستخدم.
