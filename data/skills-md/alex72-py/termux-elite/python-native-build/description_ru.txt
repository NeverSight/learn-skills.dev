Диагностировать неудачную установку Python в Termux или Android (ошибки компилятора или заголовков, сборки Rust или maturin, отсутствие wheel для этой платформы, wheel с glibc, которые не импортируются, внешнее управление окружением) и выбрать наименьшее исправление, отдавая предпочтение библиотекам, упакованным в Termux (основному репозиторию, затем tur‑repo с согласия), а не сборкам из исходного кода. Используется, когда pip или uv завершаются с ошибкой, когда ошибка сборки содержит clang, cc, cargo, rustc или отсутствует файл .h, либо когда импорт падает сразу после успешной установки. Не использовать для медленных загрузок, чисто‑Python пакетов, которые устанавливаются без проблем, или проблем с Node (см. node-native-build). 

Всегда отвечайте на языке пользователя.
