Diagnostiquez une installation Python échouée sur Termux ou Android (erreurs de compilateur ou d’en‑tête, builds Rust ou maturin, absence de roue pour cette plateforme, roues glibc qui échouent à l’importation, environnement géré extérieurement) et choisissez la solution la plus petite, en privilégiant les bibliothèques fournies par Termux (le dépôt principal, puis le tur‑repo avec consentement) plutôt que les builds à partir du code source. Utilisez‑le lorsque pip ou uv échoue, lorsqu’une erreur de build mentionne clang, cc, cargo, rustc ou un fichier .h manquant, ou lorsqu’un import échoue immédiatement après une installation réussie. NE l’utilisez PAS pour les téléchargements lents, les paquets pure‑Python qui s’installent correctement, ou les problèmes Node (voir node‑native‑build).

Veuillez toujours répondre dans la langue de l’utilisateur.
