Diagnose von git-Klon-, Abruf- und Push-Authentifizierungsfehlern von Termux ohne Offenlegung von Token oder privaten Schlüsseln (HTTPS-Token, SSH-Schlüssel, Host-Schlüsselaufforderungen, falsches Konto, fehlende Bereiche). Verwendung für Authentifizierung fehlgeschlagen, HTTP 403, Berechtigung verweigert (publickey), wiederholte Eingabeaufforderungen für Anmeldeinformationen oder Schlüsselberechtigungswarnungen. NICHT für Netzwerkausfälle, falsche Remote-Namen oder Ablehnungen von Nicht-Authentifizierungen wie Nicht-Schnellvorlauf verwenden.
