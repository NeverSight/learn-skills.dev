Diagnostica i fallimenti di autenticazione di git clone, fetch e push da Termux senza esporre token o chiavi private (token HTTPS, chiavi SSH, richieste di chiave host, account errato, scope mancanti). Usa per Authentication failed, HTTP 403, Permission denied (publickey), richieste ripetute di credenziali o avvisi sui permessi delle chiavi. NON usare per interruzioni di rete, nomi remote errati o rifiuti non legati all’autenticazione come non‑fast‑forward.
