Diagnostiquer les échecs d'authentification git clone, fetch et push de Termux sans exposer de jetons ou de clés privées (jetons HTTPS, clés SSH, invites de clé hôte, compte incorrect, étendues manquantes). Échec de l'utilisation pour l'authentification, HTTP 403, autorisation refusée (clé publique), invites d'authentification répétées ou avertissements d'autorisation de clé. Ne PAS utiliser pour des pannes de réseau, des noms à distance incorrects ou des rejets de non-authentification tels que des transferts non rapides.
