Diagnostiquer les installations npm et Node qui échouent sur Termux (erreurs node-gyp telles que android_ndk_path, compilateurs manquants, paquets sans binaire android, dépendances de plate-forme optionnelles, builds hors mémoire) et choisir le plus petit correctif, y compris les solutions de repli WASM. À utiliser lorsque l'installation de npm, yarn, pnpm ou node-gyp échoue, ou lorsqu'un package signale un androïde de plate-forme non pris en charge. Ne PAS utiliser pour les builds Python (voir python-native-build) ou pour les erreurs de logique JavaScript.
