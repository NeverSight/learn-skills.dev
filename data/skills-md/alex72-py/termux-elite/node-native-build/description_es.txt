Diagnostique las instalaciones de npm y Node que fallan en Termux (errores de gyp de nodo como android_ndk_path, compiladores faltantes, paquetes sin binario de android, dependencias de plataforma opcionales, compilaciones fuera de memoria) y elija la solución más pequeña, incluidos los fallos de WASM. Utilícelo cuando la instalación de npm, yarn, pnpm o node-gyp falle, o un paquete informe de una plataforma Android no compatible. NO LO utilice para compilaciones de Python (consulte python-native-build) o para errores lógicos de JavaScript.
