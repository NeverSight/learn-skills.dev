Диагностировать установки npm и Node, которые проваливаются в Termux (ошибки node-gyp, такие как android_ndk_path, отсутствие компиляторов, пакеты без android‑бинарника, необязательные зависимости платформы, сборки, заканчивающиеся нехваткой памяти), и выбирать наименьшее решение, включая варианты с WASM. Использовать, когда npm install, yarn, pnpm или node-gyp завершаются ошибкой, либо пакет сообщает о неподдерживаемой платформе android. НЕ использовать для сборок Python (см. python-native-build) или для ошибок логики JavaScript.
