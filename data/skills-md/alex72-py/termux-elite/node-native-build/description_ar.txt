تشخيص تثبيتات npm وNode التي تفشل على Termux (أخطاء node-gyp مثل android_ndk_path، نقص المترجمات، حزم لا تحتوي على نسخة Android، اعتماديات منصة اختيارية، عمليات بناء تنفد فيها الذاكرة) واختيار أصغر حل، بما في ذلك حلول بديلة عبر WASM. استخدمه عندما يفشل npm install أو yarn أو pnpm أو node-gyp، أو عندما تُبلّغ حزمة عن منصة Android غير مدعومة. لا تستخدمه لبناءات Python (انظر python-native-build) أو لأخطاء منطق JavaScript.

يرجى الرد دائمًا بلغة المستخدم.
