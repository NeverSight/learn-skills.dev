Diagnostica problemi di rete all'interno di Termux (DNS, errori di certificato TLS, sfasamento dell'orologio, proxy, porte di binding, accesso a un server Termux dal telefono o dalla LAN) considerando le restrizioni di Android su interfacce e porte basse. Usalo quando curl, pip, git o un server locale non riescono a connettersi, quando ifconfig o netstat non mostrano nulla, o quando TLS segnala un certificato non ancora valido. NON usarlo per guasti Wi‑Fi o del provider al di fuori del dispositivo, né per specifiche di sshd (vedi termux-sshd). Per favore, rispondi sempre nella lingua dell'utente.
