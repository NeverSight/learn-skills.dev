Diagnosticar problemas de red dentro de Termux (DNS, errores de certificado TLS, sesgo del reloj, proxies, puertos vinculantes, llegar a un servidor Termux desde el teléfono o LAN) dadas las restricciones de Android en interfaces y puertos bajos. Utilícelo cuando curl, pip, git o un servidor local no puedan conectarse, cuando ifconfig o netstat no muestren nada o cuando TLS informe que un certificado aún no es válido. NO LO use para Wi-Fi o fallas del operador fuera del dispositivo, o para detalles de sshd (consulte termux-sshd).
