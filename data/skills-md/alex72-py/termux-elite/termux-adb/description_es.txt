Configura y depura adb desde Termux al mismo teléfono usando depuración inalámbrica (código de emparejamiento, puerto de conexión, dispositivos no autorizados u offline) para las pocas tareas que requieren acceso a nivel de shell. Utilízalo cuando el usuario mencione adb pair, adb connect, depuración inalámbrica, android-tools, adb devices mostrando no autorizado u offline, o cuando otra habilidad transfiera una configuración del sistema que necesite adb. NO lo uses para errores de permisos de Termux:API (ver termux‑api), para depuración USB desde una PC, o para cambiar una configuración del sistema sin confirmación.
