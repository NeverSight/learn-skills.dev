Diagnosticar fallos de pkg y apt en Termux (incapaz de localizar el paquete, espejos obsoletos o incorrectos, desajuste de reloj, discrepancia de hash, dpkg interrumpido, bibliotecas que fallan al enlazarse después de una actualización parcial) y separarlos de los fallos de compilación. Utilízalo cuando pkg o apt muestre un error, cuando falte el nombre de un paquete de Debian o Ubuntu, o cuando un comando falle con CANNOT LINK EXECUTABLE. NO lo uses para ejecutar actualizaciones amplias, cambiar espejos o limpiar cachés antes de capturar el error exacto, y no lo uses para errores de compilación (ver python‑native‑build).
