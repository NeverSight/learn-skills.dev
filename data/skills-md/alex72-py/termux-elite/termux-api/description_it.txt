Attribuisci un comando termux-* che si blocca, è vuoto o fallisce allo strato corretto (app Termux:API, pacchetto termux-api o un permesso di runtime Android) prima di fare affidamento su di esso. Usalo quando termux-battery-status, termux-notification, termux-clipboard-get, termux-location o comandi simili si bloccano, non producono output o segnalano un errore di permesso. NON usarlo per i collegamenti di storage (vedi storage-permissions), per i comandi all'interno di proot o per normali errori della shell.
