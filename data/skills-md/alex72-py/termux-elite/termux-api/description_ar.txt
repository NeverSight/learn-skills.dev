عيّن أمر termux-* المتجمد أو الفارغ أو الفاشل إلى الطبقة المناسبة (تطبيق Termux:API، حزمة termux‑api، أو إذن تشغيل Android) قبل الاعتماد عليه. استخدم ذلك عندما يتعطل termux‑battery‑status أو termux‑notification أو termux‑clipboard‑get أو termux‑location أو أوامر مشابهة، أو لا تُظهر أي مخرجات، أو تُبلغ عن خطأ في الإذن. لا تستخدمه لروابط التخزين (انظر أذونات التخزين)، أو للأوامر داخل proot، أو لأخطاء الصدفة العادية.
