Attribuez une commande termux- * suspendue, vide ou défaillante à la bonne couche (Termux : application API, package termux-api ou autorisation d'exécution Android) avant de vous y fier. À utiliser lorsque les commandes termux-battery-status, termux-notification, termux-clipboard-get, termux-location ou similaires sont suspendues, n'impriment rien ou signalent une erreur d'autorisation. Ne PAS utiliser pour les liens de stockage (voir les permissions de stockage), pour les commandes à l'intérieur de proot ou pour les pannes de shell ordinaires.
