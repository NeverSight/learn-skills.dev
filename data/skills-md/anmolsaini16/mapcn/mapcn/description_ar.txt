بناء خرائط في React باستخدام mapcn، مكونات خريطة قابلة للتخصيص بنمط shadcn على MapLibre GL وTailwind CSS. استخدمها عندما يرغب المستخدم في إضافة أو تخصيص أو تطبيق سمة على الخريطة: علامات، نوافذ منبثقة، تلميحات أدوات، طرق، أقواس، طبقات GeoJSON أو طبقات كوروبليث، تجميعات، كرة أرضية، أنماط خريطة أساسية مخصصة أو سمة فاتحة/داكنة، أو صفحة خريطة كاملة (لوحة تحليلات، متتبع توصيل، محدد موقع المتجر) في مشروع React أو Next.js أو Vite باستخدام shadcn/ui أو Tailwind. استخدمها أيضًا عندما يسأل المستخدم أين يمكن أن تتناسب الخريطة في تطبيقه.

الرجاء دائمًا الرد بلغة المستخدم.
