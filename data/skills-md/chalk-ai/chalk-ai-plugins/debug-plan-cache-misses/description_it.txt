Trovare e fare il debug dei mancati cache dei piani di query di Chalk dai log del motore. Usare quando una query viene ripianificata ad ogni richiesta, appare l’avviso “ad-hoc query request missed the plan cache”, si registrano picchi di latenza a causa della pianificazione ripetuta, o qualcuno si chiede perché due query apparentemente identiche non condividono un piano in cache. Guida la ricerca CLI `chalk logs`.
