Trova e debugga le mancate cache dei piani di query Chalk dai log del motore. Usalo quando una query viene ricompilata ad ogni richiesta, appare un avviso “ad‑hoc query request missed the plan cache”, si verificano picchi di latenza a causa della pianificazione ripetuta, o qualcuno chiede perché due query apparentemente identiche non condividono un piano nella cache. Alimenta la ricerca CLI `chalk logs`.
