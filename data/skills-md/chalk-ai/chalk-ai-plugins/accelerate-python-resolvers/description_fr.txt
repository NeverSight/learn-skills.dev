Rendre les résolveurs Chalk Python accélérables statiquement. À utiliser lorsque l'utilisateur demande d'accélérer les résolveurs, de corriger les diagnostics d'accélération statique, de vérifier pourquoi un résolveur « ne peut pas être accéléré » ou d'accélérer les pipelines de fonctionnalités Python dans un projet Chalk (un repo avec chalk.yaml/chalk.yml).
