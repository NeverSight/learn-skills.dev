웹 앱 UI에 일러스트레이션이나 이미지를 추가할 때 — 빈 상태, 온보딩, 오류 페이지(404/500), 성공 순간 — 혹은 이미지가 화면을 돕는지 방해하는지 판단할 때 사용합니다. 라이선스 준수를 포함한 기존 무료 라이브러리(unDraw, Storyset, LottieFiles)에서 소스를 확보하고, SVG를 디자인 토큰으로 색상 변환하여 라이트·다크 테마에 맞게 적용하고, React/Vite에 SVG를 올바르게 통합(인라인 vs img, 레이아웃 시프트와 번들 관리)하며, 애니메이션 이미지(Lottie)를 reduced‑motion 접근성을 고려해 사용하고, 빈 상태 구성(해부학, 변형, 일관성)을 다룹니다. 키워드: 일러스트레이션, 빈 상태, 이미지, SVG, unDraw, Storyset, Lottie, 다크 모드 일러스트레이션, 온보딩 아트, 오류 페이지 일러스트레이션, alt 텍스트, 장식 이미지.
