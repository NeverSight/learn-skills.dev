Úsalo al agregar ilustraciones o imágenes a la interfaz de una aplicación web — estados vacíos, incorporación, páginas de error (404/500), momentos de éxito — o al decidir si la imagen ayuda o entorpece una pantalla. Incluye obtener recursos de las bibliotecas gratuitas establecidas (unDraw, Storyset, LottieFiles) con cumplimiento de licencias, recolorear SVGs a tus tokens de diseño para que sigan los temas claro/oscuro, integrar SVG en React/Vite correctamente (inline vs img, desplazamiento de diseño y disciplina de empaquetado), imágenes animadas (Lottie) con accesibilidad de movimiento reducido, y la creación de estados vacíos (anatomía, variantes, consistencia). Palabras clave: ilustración, estado vacío, imagen, SVG, unDraw, Storyset, Lottie, ilustración modo oscuro, arte de incorporación, ilustración de página de error, texto alternativo, imagen decorativa.
