Utiliser lors de l'ajout d'illustrations ou d'images à l’interface d’une application web — états vides, onboarding, pages d’erreur (404/500), moments de succès — ou lorsqu’on décide si l’imagerie aide ou encombre un écran. Couvre la recherche dans les bibliothèques gratuites établies (unDraw, Storyset, LottieFiles) avec conformité aux licences, le recolorisation des SVG selon vos tokens de design afin qu’ils suivent les thèmes clair/sombre, l’intégration correcte des SVG dans React/Vite (inline vs img, layout‑shift et discipline du bundle), l’imagerie animée (Lottie) avec accessibilité réduction du mouvement, et le travail sur les états vides (anatomie, variantes, cohérence). Mots‑clé : illustration, état vide, imagerie, SVG, unDraw, Storyset, Lottie, illustration mode sombre, art d’onboarding, illustration de page d’erreur, texte alternatif, image décorative.
