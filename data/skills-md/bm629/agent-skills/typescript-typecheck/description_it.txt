Usalo quando configuri o esegui il type‑checking di TypeScript come un gate di qualità autonomo — scrivendo o inasprendo un `tsconfig.json` rigoroso, aggiungendo un controllo `tsc --noEmit` (o `tsc -b --noEmit`) che gira separatamente dalla build, integrando tale controllo nel CI, o configurando i riferimenti di progetto di TypeScript per un monorepo multi‑pacchetto (pnpm/Turborepo). Copre perché un gate di type‑checking dedicato è obbligatorio (i bundler e i transpiler rimuovono i tipi senza verificarli), il set di opzioni del compilatore strict che vale la pena abilitare oltre a `strict: true`, il layout della configurazione divisa di Vite e la risoluzione dei tipi tra pacchetti tramite riferimenti di progetto compositi. TypeScript 5.x.
