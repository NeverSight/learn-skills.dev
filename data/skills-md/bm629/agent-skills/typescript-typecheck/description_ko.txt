TypeScript 타입 검사를 독립적인 품질 게이트로 설정하거나 실행할 때 사용합니다 — 엄격한 tsconfig.json을 작성하거나 강화하고, 빌드와 별도로 실행되는 `tsc --noEmit`(또는 `tsc -b --noEmit`) 검사를 추가하고, 해당 검사를 CI에 연결하거나, 다중 패키지(pnpm/Turborepo) 모노레포를 위한 TypeScript 프로젝트 참조를 구성할 때 사용합니다. 전용 타입‑체크 게이트가 필수적인 이유(번들러와 트랜스파일러가 타입을 검사 없이 제거함), `strict: true`를 넘어 활성화할 가치가 있는 엄격한 컴파일러 옵션 세트, Vite의 분할 구성 레이아웃, 그리고 복합 프로젝트 참조를 통한 패키지 간 타입 해상에 대해 다룹니다. TypeScript 5.x.
