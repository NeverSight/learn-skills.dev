Utilisez‑le lors de la configuration ou de l’exécution du contrôle de typage TypeScript en tant que porte de qualité autonome — rédaction ou renforcement d’un tsconfig.json strict, ajout d’une vérification `tsc --noEmit` (ou `tsc -b --noEmit`) qui s’exécute séparément de la build, intégration de cette vérification dans le CI, ou configuration des références de projets TypeScript pour un monorepo multi‑paquets (pnpm/Turborepo). Explique pourquoi une porte de contrôle de typage dédiée est indispensable (les bundlers et transpileurs suppriment les types sans les vérifier), le jeu d’options du compilateur strict à activer au‑delà de `strict: true`, la disposition de la configuration scindée de Vite, et la résolution de types inter‑paquets via les références de projets composites. TypeScript 5.x.
