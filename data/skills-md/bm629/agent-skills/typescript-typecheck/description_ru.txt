Используйте при настройке или запуске проверки типов TypeScript как отдельного качества‑шлюза — написании или ужесточении строгого tsconfig.json, добавлении проверки `tsc --noEmit` (или `tsc -b --noEmit`), которая выполняется отдельно от сборки, интеграции этой проверки в CI, либо конфигурировании ссылок на проекты TypeScript для многопакетного (pnpm/Turborepo) монорепозитория. Описывается, почему выделенный шлюз проверки типов обязателен (сборщики и транспиляторы удаляют типы без их проверки), набор строгих параметров компилятора, который стоит включить помимо `strict: true`, раздельная конфигурация Vite и разрешение типов между пакетами с помощью составных ссылок на проекты. TypeScript 5.x.
