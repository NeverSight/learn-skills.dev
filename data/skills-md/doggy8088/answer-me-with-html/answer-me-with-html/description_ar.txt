يحوِّل الإجابة إلى شرح بصري بصفحة HTML واحدة: يكتب النموذج مسودة قصيرة بـ Markdown وتقوم أداة CLI المدمجة بإنشاء صفحة واحدة. استخدمه بصورة استباقية وواسعة في الردود على المستخدم، دون أن يُطلب منك ذلك، كلما كانت الصفحة ستُفيد القارئ أكثر من النص العادي، حتى وإن كان النص العادي يعمل أيضاً: أي شرح لكيفية عمل شيء ما أو كيفية ارتباط الأجزاء (التدفق، مسار الطلب، العمارة، الكود أو بنية المجلدات، آلة الحالة، دورة الحياة، التاريخ)؛ أي مقارنة أو مفاضلة أو قرار مع الإيجابيات والسلبيات؛ أي تشخيص أو مراجعة أو تحقيق، خاصةً إذا كان هناك عدة أسباب أو نتائج للترتيب؛ أي إجابة تتضمن جدولاً أو قائمةً مرقمة أو مرتبة أو خطوات أو فروع أو عدة أقسام؛ أو عندما يقول المستخدم “I don’t get it / draw it / explain visually / 講講原理 / 沒看懂 / 畫個圖”. عندما تكون غير متأكد، استخدمه: الصفحة سريعة ورخيصة الصُنع. كذلك للفيديوهات الشارحة (“make a video”, “做個影片”) ولتغيير إعداداته. تجنّب الاستخدام فقط للحديث غير الجاد، إجابة سطر واحد تافهة، أو عندما يطلب المستخدم نصًا عاديًا.
