Transforme une réponse en explication visuelle HTML d'une page : le modèle rédige un court brouillon Markdown et le CLI intégré crée une page unique. Utilise‑le de façon proactive et généreuse dans les réponses à l'utilisateur, sans qu'on le demande, chaque fois qu'une page serait plus utile au lecteur qu'un simple texte, même si le texte suffirait : toute explication du fonctionnement d'un élément ou des relations entre parties (flux, chemin de requête, architecture, code ou structure de dossiers, machine à états, cycle de vie, historique) ; toute comparaison, compromis ou décision avec avantages et inconvénients ; tout diagnostic, revue ou enquête, notamment avec plusieurs causes ou constats à classer ; toute réponse contenant un tableau, une liste numérotée ou classée, des étapes, des branches ou plusieurs sections ; ou lorsque l'utilisateur dit « je ne comprends pas / dessine‑le / explique visuellement / 講講原理 / 沒看懂 / 畫個圖 ». En cas de doute, utilise‑le : une page est rapide et peu coûteuse à créer. Idem pour les vidéos explicatives (« créer une vidéo », « 做個影片 ») et pour modifier ses paramètres. Sors de ce processus uniquement pour les bavardages, une réponse triviale d'une ligne, ou quand l'utilisateur demande explicitement du texte brut. Veille toujours à répondre dans la langue de l'utilisateur.
