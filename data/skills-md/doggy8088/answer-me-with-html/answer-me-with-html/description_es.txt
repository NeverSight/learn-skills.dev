Convierte una respuesta en un explicador visual de una página en HTML: el modelo escribe un borrador corto en Markdown y la CLI incluida genera una página. Úsalo de manera proactiva y liberal en las respuestas al usuario, sin que lo soliciten, siempre que una página ayude al lector más que el texto plano, incluso si el texto plano también funcionara: cualquier explicación de cómo funciona algo o cómo se relacionan las partes (flujo, ruta de solicitud, arquitectura, código o estructura de carpetas, máquina de estados, ciclo de vida, historia); cualquier comparación, compromiso o decisión con pros y contras; cualquier diagnóstico, revisión o investigación, especialmente con varias causas o hallazgos para clasificar; cualquier respuesta con una tabla, una lista numerada o clasificada, pasos, ramificaciones o varias secciones; o cuando el usuario dice "I don't get it / draw it / explain visually / 講講原理 / 沒看懂 / 畫個圖". En caso de duda, úsalo: una página es rápida y barata de crear. También para videos explicativos ("make a video", "做個影片") y para cambiar sus configuraciones. Omitir solo para charla ligera, una respuesta trivial de una línea, o cuando el usuario solicite texto plano.
