Этап проверки и тестирования миграции базы данных AI-DLC. Используйте после утверждения конструкции или когда пользователь запрашивает проверку, тестирование, согласование или проверку миграции базы данных — чтобы доказать, что преобразованная цель ведет себя так же, как источник. Загружает тестовые данные (однократно через dbmig для разработки/тестирования или использует данные, уже загруженные через AWS DMS), согласовывает количество строк и запускает сгенерированные LLM тесты эквивалентности для функций/процедур/пакетов — тот же ввод → то же возвращаемое значение (функции) и тот же конечный эффект (процедуры) — выполняется внутри транзакции с откатом. Вы (Киро) генерируете тестовые спецификации на основе выборочных реальных данных. Сбои регистрируются для последующего наблюдения (тихий режим) или запроса (интерактивный режим). Записывает артефакты в файлmigrations/<project>/03-validation/.
