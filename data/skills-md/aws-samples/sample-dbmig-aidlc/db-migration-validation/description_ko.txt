AI-DLC 데이터베이스 마이그레이션의 검증 및 테스트 단계입니다. 구성이 승인된 후 또는 사용자가 데이터베이스 마이그레이션의 유효성 검사, 테스트, 조정 또는 확인을 요청할 때 사용하여 변환된 대상이 소스와 동일하게 작동하는지 증명합니다. 테스트 데이터를 로드하고(개발/테스트를 위해 dbmig를 통해 일회성 로드하거나 AWS DMS를 통해 이미 로드된 데이터 사용) 행 수를 조정하고 함수/프로시저/패키지에 대해 LLM 생성 동등성 테스트를 실행합니다. 동일한 입력 → 동일한 반환 값(함수) 및 동일한 순 효과(프로시저)가 롤백된 트랜잭션 내에서 실행됩니다. 당신(Kiro)은 샘플링된 실제 데이터로부터 테스트 사양을 생성합니다. 후속 조치(자동 모드) 또는 프롬프트(대화형 모드)에 대해 실패가 기록됩니다. migrations/<project>/03-validation/에 아티팩트를 씁니다.
