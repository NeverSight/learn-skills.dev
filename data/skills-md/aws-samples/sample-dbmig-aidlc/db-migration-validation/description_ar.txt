مرحلة التحقق من الصحة والاختبار لترحيل قاعدة بيانات AI-DLC. يُستخدم بعد الموافقة على الإنشاء، أو عندما يطلب المستخدم التحقق من صحة ترحيل قاعدة البيانات أو اختبارها أو توفيقها أو التحقق منها - لإثبات أن الهدف المحول يتصرف بنفس سلوك المصدر. تحميل بيانات الاختبار (تحميل مرة واحدة عبر dbmig للتطوير/الاختبار، أو استهلاك البيانات التي تم تحميلها بالفعل عبر AWS DMS)، وتسوية أعداد الصفوف، وتشغيل اختبارات التكافؤ التي تم إنشاؤها بواسطة LLM للوظائف/الإجراءات/الحزم - نفس الإدخال ← نفس قيمة الإرجاع (الوظائف) ونفس التأثير الصافي (الإجراءات) - يتم تنفيذها داخل معاملة التراجع. أنت (كيرو) تقوم بإنشاء مواصفات الاختبار من عينات البيانات الحقيقية. يتم تسجيل حالات الفشل للمتابعة (الوضع الصامت) أو المطالبة (الوضع التفاعلي). يكتب العناصر إلى عمليات الترحيل/<project>/03-validation/.
