Fase di validazione e test di una migrazione del database AI-DLC. Da utilizzare dopo l'approvazione della costruzione o quando l'utente chiede di convalidare, testare, riconciliare o verificare la migrazione di un database, per dimostrare che la destinazione convertita si comporta allo stesso modo dell'origine. Carica i dati di test (caricamento una tantum tramite dbmig per sviluppo/test o consuma dati già caricati tramite AWS DMS), riconcilia i conteggi di righe ed esegue test di equivalenza generati da LLM per funzioni/procedure/pacchetti - stesso input → stesso valore restituito (funzioni) e stesso effetto netto (procedure) - eseguito all'interno di una transazione di roll-back. Tu (Kiro) generi le specifiche del test da dati reali campionati. Gli errori vengono registrati per il follow-up (modalità silenziosa) o richiesti (modalità interattiva). Scrive gli artefatti in migrazioni/<progetto>/03-validation/.
