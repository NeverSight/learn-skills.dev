Fase de validación y prueba de una migración de base de datos AI-DLC. Úselo después de que se apruebe la construcción, o cuando el usuario solicite validar, probar, conciliar o verificar una migración de base de datos, para demostrar que el destino convertido se comporta igual que la fuente. Carga datos de prueba (carga única a través de dbmig para desarrollo/prueba, o consume datos ya cargados a través de AWS DMS), concilia recuentos de filas y ejecuta pruebas de equivalencia generadas por LLM para funciones/procedimientos/paquetes (misma entrada → mismo valor de retorno (funciones) y mismo efecto neto (procedimientos)) ejecutados dentro de una transacción revertida. Usted (Kiro) genera las especificaciones de prueba a partir de datos reales muestreados. Las fallas se registran para seguimiento (modo silencioso) o se solicitan (modo interactivo).
