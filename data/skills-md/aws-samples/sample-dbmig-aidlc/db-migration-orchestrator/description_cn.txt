AI-DLC 式数据库迁移的入口点。当用户想要迁移数据库或在引擎之间转换架构，或者说“开始数据库迁移”、“将 Oracle 迁移到 PostgreSQL”、“将 SQL Server 迁移到 MySQL”、“将我的 SQL Server 架构转换为 Postgres”或“帮助我移动数据库”时使用。支持 Oracle 和 SQL Server 源到 PostgreSQL 和 MySQL 目标。运行导入面试（源/目标引擎、连接文件、要迁移的内容），通过 Python 驱动程序测试连接（无本机客户端工具），然后通过初始 → 构建 → 验证 → 操作阶段，每个阶段之间都有人工批准门。将阶段工作委托给 db-migration-inception、db-migration-construction、db-migration-validation 和 db-migration-operations。
