Точка входа для миграции базы данных в стиле AI-DLC. Используйте, когда пользователь хочет перенести базу данных или преобразовать схему между механизмами или говорит что-то вроде «начать миграцию базы данных», «перенести Oracle на PostgreSQL», «перенести SQL Server на MySQL», «конвертировать мою схему SQL Server в Postgres» или «помогите мне переместить мою базу данных». Поддерживает источники Oracle и SQL Server для целей PostgreSQL и MySQL. Запускает входное собеседование (исходный/целевой механизм, файл подключения, что нужно перенести), тестирует возможность подключения через драйверы Python (без собственных клиентских инструментов), затем проходит через этапы «Начало» → «Строительство» → «Валидация» → «Эксплуатация» с шлюзом утверждения человеком между каждым из них. Делегирует этапную работу db-migration-inception, db-migration-construction, db-migration-validation и db-migration-operations.
