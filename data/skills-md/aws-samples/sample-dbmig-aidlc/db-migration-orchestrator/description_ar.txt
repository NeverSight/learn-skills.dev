نقطة الدخول لترحيل قاعدة البيانات بنمط AI-DLC. يُستخدم عندما يريد المستخدم ترحيل قاعدة بيانات أو تحويل مخطط بين المحركات، أو يقول أشياء مثل "بدء ترحيل قاعدة البيانات"، أو "ترحيل Oracle إلى PostgreSQL"، أو "ترحيل SQL Server إلى MySQL"، أو "تحويل مخطط SQL Server الخاص بي إلى Postgres"، أو "مساعدتي في نقل قاعدة البيانات الخاصة بي". يدعم مصادر Oracle وSQL Server لأهداف PostgreSQL وMySQL. تشغيل مقابلة القبول (محركات المصدر/الهدف، ملف الاتصال، ما سيتم ترحيله)، واختبار الاتصال عبر برامج تشغيل Python (لا توجد أدوات عميل أصلية)، ثم التوجيه عبر مراحل البداية → البناء → التحقق من الصحة → مراحل العمليات مع بوابة موافقة بشرية بين كل منها. يقوم المندوبون بمرحلة العمل إلى db-migration-inception، وdb-migration-construction، وdb-migration-validation، وdb-migration-operations.
