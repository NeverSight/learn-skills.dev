Point d'entrée pour une migration de base de données de type AI-DLC. À utiliser lorsque l'utilisateur souhaite migrer une base de données ou convertir un schéma entre moteurs, ou dit des choses comme « démarrer une migration de base de données », « migrer Oracle vers PostgreSQL », « migrer SQL Server vers MySQL », « convertir mon schéma SQL Server vers Postgres » ou « aidez-moi à déplacer ma base de données ». Prend en charge les sources Oracle et SQL Server vers les cibles PostgreSQL et MySQL. Exécute l'entretien d'admission (moteurs source/cible, fichier de connexion, ce qu'il faut migrer), teste la connectivité via les pilotes Python (pas d'outils clients natifs), puis achemine les phases Création → Construction → Validation → Opérations avec une porte d'approbation humaine entre chacune. Les délégués travaillent en phase sur db-migration-inception, db-migration-construction, db-migration-validation et db-migration-operations.
