AI-DLC 스타일 데이터베이스 마이그레이션의 진입점입니다. 사용자가 데이터베이스를 마이그레이션하거나 엔진 간에 스키마를 변환하려고 하거나 "데이터베이스 마이그레이션 시작", "Oracle을 PostgreSQL로 마이그레이션", "SQL Server를 MySQL로 마이그레이션", "SQL Server 스키마를 Postgres로 변환" 또는 "데이터베이스 이동을 도와주세요"와 같은 말을 할 때 사용합니다. PostgreSQL 및 MySQL 대상에 대한 Oracle 및 SQL Server 소스를 지원합니다. 접수 인터뷰(소스/대상 엔진, 연결 파일, 마이그레이션 대상)를 실행하고 Python 드라이버(기본 클라이언트 도구 없음)를 통해 연결을 테스트한 다음 각 단계 사이에 사람 승인 게이트를 사용하여 Inception → Construction → Validation → Operations 단계를 통해 라우팅합니다. 단계 작업을 db-migration-inception, db-migration-construction, db-migration-validation 및 db-migration-Operations에 위임합니다.
