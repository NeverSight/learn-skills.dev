AI-DLC 式資料庫遷移的入口點。當使用者想要遷移資料庫或在引擎之間轉換架構，或說「開始資料庫遷移」、「將 Oracle 遷移到 PostgreSQL」、「將 SQL Server 遷移到 MySQL」、「將我的 SQL Server 架構轉換為 Postgres」或「幫助我移動資料庫」時使用。支援 Oracle 和 SQL Server 來源到 PostgreSQL 和 MySQL 目標。執行導入面試（來源/目標引擎、連接檔案、要遷移的內容），透過 Python 驅動程式測試連接（無本機用戶端工具），然後透過初始 → 建置 → 驗證 → 操作階段，每個階段之間都有人工批准閘。將階段工作委託給 db-migration-inception、db-migration-construction、db-migration-validation 和 db-migration-operations。
