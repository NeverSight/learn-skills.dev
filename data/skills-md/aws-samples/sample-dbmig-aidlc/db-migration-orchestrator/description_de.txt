Einstiegspunkt für eine Datenbankmigration im AI-DLC-Stil. Verwenden Sie diese Option, wenn der Benutzer eine Datenbank migrieren oder ein Schema zwischen Engines konvertieren möchte oder Dinge sagt wie „Datenbankmigration starten“, „Oracle zu PostgreSQL migrieren“, „SQL Server zu MySQL migrieren“, „mein SQL Server-Schema in Postgres konvertieren“ oder „Helfen Sie mir, meine Datenbank zu verschieben“. Unterstützt Oracle- und SQL Server-Quellen für PostgreSQL- und MySQL-Ziele. Führt das Aufnahmeinterview durch (Quell-/Ziel-Engines, Verbindungsdatei, was migriert werden soll), testet die Konnektivität über Python-Treiber (keine nativen Client-Tools) und leitet dann die Phasen „Inception“ → „Konstruktion“ → „Validierung“ → „Betrieb“ mit einem menschlichen Genehmigungs-Gate dazwischen weiter. Delegiert die Phasenarbeit an db-migration-inception, db-migration-construction, db-migration-validation und db-migration-operations.
