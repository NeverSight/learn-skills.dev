Punto de entrada para una migración de base de datos estilo AI-DLC. Úselo cuando el usuario quiera migrar una base de datos o convertir un esquema entre motores, o diga cosas como "iniciar una migración de base de datos", "migrar Oracle a PostgreSQL", "migrar SQL Server a MySQL", "convertir mi esquema de SQL Server a Postgres" o "ayúdame a mover mi base de datos". Admite fuentes de Oracle y SQL Server para destinos de PostgreSQL y MySQL. Ejecuta la entrevista de admisión (motores de origen/destino, archivo de conexión, qué migrar), prueba la conectividad a través de controladores Python (sin herramientas de cliente nativas) y luego pasa por las fases de Inicio → Construcción → Validación → Operaciones con una puerta de aprobación humana entre cada una. Delega el trabajo de fase a db-migration-inception, db-migration-construction, db-migration-validation y db-migration-operations.
