AI-DLC スタイルのデータベース移行のエントリ ポイント。ユーザーがデータベースの移行やエンジン間でのスキーマの変換を希望する場合、または「データベースの移行を開始する」、「Oracle を PostgreSQL に移行する」、「SQL Server を MySQL に移行する」、「SQL Server スキーマを Postgres に変換する」、または「データベースの移行を手伝ってください」などのことを言う場合に使用します。 Oracle および SQL Server ソースから PostgreSQL および MySQL ターゲットまでをサポートします。インテーク インタビュー (ソース/ターゲット エンジン、接続ファイル、移行対象) を実行し、Python ドライバー経由で接続をテストします (ネイティブ クライアント ツールなし)。その後、人間による承認ゲートを介して、開始→構築→検証→運用の各フェーズをルーティングします。委任フェーズの作業は db-migration-inception、db-migration-construction、db-migration-validation、db-migration-operations に行われます。
