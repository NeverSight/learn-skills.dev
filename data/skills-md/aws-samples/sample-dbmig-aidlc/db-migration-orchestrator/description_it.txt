Punto di ingresso per una migrazione del database in stile AI-DLC. Da utilizzare quando l'utente desidera migrare un database o convertire uno schema tra motori oppure dice cose come "avviare una migrazione del database", "migrare Oracle a PostgreSQL", "migrare SQL Server a MySQL", "convertire il mio schema SQL Server in Postgres" o "aiutami a spostare il mio database". Supporta origini Oracle e SQL Server su destinazioni PostgreSQL e MySQL. Esegue il colloquio di assunzione (motori di origine/destinazione, file di connessione, cosa migrare), testa la connettività tramite driver Python (nessun strumento client nativo), quindi passa attraverso le fasi di Inizio → Costruzione → Convalida → Operazioni con un cancello di approvazione umana tra ciascuna. Delega il lavoro della fase all'inizio della migrazione del database, alla costruzione della migrazione del database, alla convalida della migrazione del database e alle operazioni di migrazione del database.
