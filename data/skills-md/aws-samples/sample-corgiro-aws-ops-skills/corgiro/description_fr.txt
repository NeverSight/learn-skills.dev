Assistant d'opérations Cloud AWS pour les organisations multi-comptes. Inspectez et gérez les comptes AWS au sein d'une organisation AWS complète — événements de santé, analyse de fin de support, couverture des comptes et configuration inter-comptes. Utilisez ce service lorsque l'utilisateur mentionne les événements de santé AWS, RDS, EKS ou la fin de support d'ElastiCache, l'examen du posture de sécurité ou la carte de pointage de sécurité, l'examen de la sécurité IAM ou l'audit de la clé API Bedrock, le probe de couverture de compte, la configuration multi-comptes, ou les types /corgiro <mode>. Chaque mode est documenté dans modes/<name>/MODE.md.
