Assistente per le operazioni cloud AWS per organizzazioni a più account. Ispeziona e gestisci gli account AWS all'interno di un'intera Organizzazione AWS — eventi di salute, analisi di fine supporto, copertura degli account e configurazione cross‑account. Usalo quando l'utente menziona eventi di salute AWS, fine supporto di RDS, EKS o ElastiCache, revisione della postura di sicurezza o scheda di valutazione della sicurezza, revisione della sicurezza IAM o audit della chiave API Bedrock, sondaggio di copertura degli account, configurazione multi‑account o i comandi /corgiro <mode>. Ogni modalità è documentata in modes/<name>/MODE.md.

Rispondi sempre nella lingua dell'utente.
