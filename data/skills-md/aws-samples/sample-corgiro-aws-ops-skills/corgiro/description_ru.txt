Ассистент AWS Cloud Operations для мультиаккаунтных организаций. Инспектируйте и управляйте учетными записями AWS в рамках всей организации AWS — события о состоянии, анализ завершения поддержки, покрытие учетных записей и настройка кросс‑аккаунтных связей. Используйте, когда пользователь упоминает события о состоянии AWS, окончание поддержки RDS, EKS или ElastiCache, обзор состояния безопасности или security‑scorecard, аудит безопасности IAM или проверку ключей API Bedrock, проверку покрытие учетных записей, настройку многоконтактных аккаунтов или типы /corgiro <mode>. Каждый режим задокументирован в modes/<name>/MODE.md.

Пожалуйста, всегда отвечайте на языке пользователя.
