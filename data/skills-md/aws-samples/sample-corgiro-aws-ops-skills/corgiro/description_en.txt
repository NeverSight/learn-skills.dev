AWS Cloud Operations assistant for multi-account organizations. Inspect and manage AWS accounts across an entire AWS Organization — health events, end-of-support analysis, account coverage, and cross-account setup. Use when the user mentions AWS health events, RDS, EKS, or ElastiCache end-of-support, security posture review or security scorecard, IAM security review or Bedrock API key audit, account coverage probe, multi-account setup, or types /corgiro <mode>. Each mode is documented in modes/<name>/MODE.md.
