Costruisci una facciata OAuth + MCP davanti al Bedrock AgentCore Gateway o Runtime affinché i client MCP rigidi (Claude Code, Cursor, Amazon Quick, mcp-remote) possano connettersi. Usala quando un client MCP non riesce nella scoperta OAuth ("Correggi i campi evidenziati", errori DCR), quando gli strumenti oltre i 30 scompaiono silenziosamente (paginazione tools/list del Gateway), quando le chiamate agli strumenti restituiscono 404 o "Strumento sconosciuto" (session-id duale, prefisso del nome dello strumento), o quando si adatta Cognito ai metadati RFC 9728/8414, alla riscrittura del redirect_uri o ai limiti dello schema del Gateway.
