Bauen Sie eine OAuth + MCP‑Protokoll‑Fassade vor dem Bedrock AgentCore Gateway oder Runtime, damit strenge MCP‑Clients (Claude Code, Cursor, Amazon Quick, mcp‑remote) eine Verbindung herstellen können. Verwenden Sie sie, wenn ein MCP‑Client die OAuth‑Discovery nicht besteht („Fix highlighted fields“, DCR‑Fehler), wenn Werkzeuge über 30 stillschweigend verschwinden (Gateway tools/list‑Paginierung), wenn Werkzeugaufrufe 404 oder „Unknown tool“ zurückgeben (doppelte session‑id, Werkzeugnamen‑Präfix) oder beim Anpassen von Cognito an die Metadaten von RFC 9728/8414, das Umschreiben von redirect_uri oder die Grenzen des Gateway‑Schemas.
