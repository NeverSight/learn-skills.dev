Construisez une façade protocolaire OAuth + MCP devant Bedrock AgentCore Gateway ou Runtime afin que les clients MCP stricts (Claude Code, Cursor, Amazon Quick, mcp-remote) puissent se connecter. Utilisez‑la lorsqu’un client MCP échoue à la découverte OAuth (« Fix highlighted fields », erreurs DCR), lorsqu’un nombre d’outils supérieur à 30 disparaît silencieusement (pagination de la liste d’outils du Gateway), lorsque les appels d’outils renvoient un 404 ou « Unknown tool » (double session-id, préfixe du nom de l’outil), ou lors de l’adaptation de Cognito aux métadonnées RFC 9728/8414, à la réécriture du redirect_uri, ou aux limites du schéma du Gateway.
