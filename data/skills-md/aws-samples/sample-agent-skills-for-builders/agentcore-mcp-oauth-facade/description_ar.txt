أنشئ واجهة بروتوكول OAuth + MCP أمام بوابة Bedrock AgentCore أو Runtime بحيث يتمكن عملاء MCP الصارمون (Claude Code، Cursor، Amazon Quick، mcp-remote) من الاتصال. استخدمها عندما يفشل عميل MCP في اكتشاف OAuth (“إصلاح الحقول المظللة”، أخطاء DCR)، عندما تختفي الأدوات التي تزيد عن 30 بصمت (ترقيم صفحات أدوات/قائمة البوابة)، عندما تُرجع استدعاءات الأدوات حالة 404 أو “أداة غير معروفة” (معرف جلسة مزدوج، بادئ اسم الأداة)، أو عند تعديل Cognito لتتوافق مع بيانات التعريف RFC 9728/8414، وإعادة كتابة redirect_uri، أو حدود مخطط البوابة.
