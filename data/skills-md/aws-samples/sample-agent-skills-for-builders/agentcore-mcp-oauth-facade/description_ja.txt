Bedrock AgentCore Gateway または Runtime の前に OAuth + MCP プロトコルのファサードを構築し、厳格な MCP クライアント（Claude Code、Cursor、Amazon Quick、mcp-remote）が接続できるようにします。MCP クライアントが OAuth ディスカバリーに失敗した場合（「Fix highlighted fields」や DCR エラー）、ツールが 30 を超えて静かに消失する場合（Gateway tools/list のページング）、ツール呼び出しが 404 や「Unknown tool」を返す場合（dual session-id、ツール名プレフィックス）、あるいは Cognito を RFC 9728/8414 のメタデータや redirect_uri の書き換え、Gateway のスキーマ制限に適合させる場合に使用します。
