Создайте фасад протокола OAuth + MCP перед Bedrock AgentCore Gateway или Runtime, чтобы строгие MCP‑клиенты (Claude Code, Cursor, Amazon Quick, mcp-remote) могли подключаться. Пожалуйста, всегда отвечайте на языке пользователя.
