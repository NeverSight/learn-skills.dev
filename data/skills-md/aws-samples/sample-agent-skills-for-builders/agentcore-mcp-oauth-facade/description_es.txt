Construya una fachada de protocolo OAuth + MCP frente a Bedrock AgentCore Gateway o Runtime para que los clientes MCP estrictos (Claude Code, Cursor, Amazon Quick, mcp-remote) puedan conectarse. Úsela cuando un cliente MCP falle en el descubrimiento OAuth («Corregir campos resaltados», errores DCR), cuando las herramientas superiores a 30 desaparezcan silenciosamente (paginación de tools/list en Gateway), cuando las llamadas a herramientas devuelvan 404 o «Herramienta desconocida» (session‑id dual, prefijo del nombre de la herramienta), o al adaptar Cognito a los metadatos de RFC 9728/8414, la reescritura de redirect_uri o los límites del esquema del Gateway.
