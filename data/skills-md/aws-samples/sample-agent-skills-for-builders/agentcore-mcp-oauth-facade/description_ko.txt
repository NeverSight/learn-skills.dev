Bedrock AgentCore Gateway 또는 Runtime 앞에 OAuth + MCP 프로토콜 파사드를 구축하여 엄격한 MCP 클라이언트(Claude Code, Cursor, Amazon Quick, mcp-remote)가 연결할 수 있도록 합니다. MCP 클라이언트가 OAuth 탐색에 실패할 때(“Fix highlighted fields”, DCR 오류), 30개 이상의 도구가 조용히 사라질 때(Gateway 도구/목록 페이지네이션), 도구 호출이 404 또는 “Unknown tool”을 반환할 때(이중 session-id, 도구 이름 접두사), 또는 Cognito를 RFC 9728/8414 메타데이터, redirect_uri 재작성, Gateway 스키마 제한에 맞게 조정할 때 사용합니다.
