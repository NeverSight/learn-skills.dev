Migrationsleitfaden für traditionelle Listing‑Metadaten und Produktsuche zu Taxonomy API, Sell Metadata APIs, Catalog API, Charity API und Kompatibilitäts‑ bzw. Produktmetadaten‑Oberflächen.

Auslöser, wenn der Benutzer erwähnt: GeteBayDetails/GetCategories/GetCategoryFeatures/GetCategoryMappings/GetSuggestedCategories; ProductDetails/findProducts/getProductDetails/addProducts; Kompatibilitätssuche oder Kompatibilitätswert‑Operationen; GetCharities; oder fragt „Wie migriere ich Kategoriedaten vor dem Listing?“.

Umfasst 22 traditionelle Operationen, einschließlich Marktplatz‑Metadaten, Taxonomie, Kategorierichtlinien, Kompatibilitäts‑ und Katalogabfragen, Charity‑Entdeckung und vieler stillgelegter Metadaten‑Zeilen.

Nicht verwenden für das Erstellen, Ändern oder Beenden von Listings bzw. für Order‑/Account‑Workflows.

Bitte immer in der Sprache des Benutzers antworten.
