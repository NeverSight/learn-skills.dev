Guida alla migrazione dei metadati tradizionali degli annunci e della scoperta dei prodotti verso Taxonomy API, Sell Metadata API, Catalog API, Charity API e le interfacce di metadati compatibilità o prodotto.

Attiva quando l'utente menziona: GeteBayDetails/GetCategories/GetCategoryFeatures/GetCategoryMappings/GetSuggestedCategories; ProductDetails/findProducts/getProductDetails/addProducts; ricerca di compatibilità o operazioni su valori di compatibilità; GetCharities; oppure chiede "come migrare i metadati della categoria prima dell'inserimento".

Copre 22 operazioni tradizionali, inclusi metadati del marketplace, tassonomia, politiche di categoria, ricerca di compatibilità e catalogo, scoperta di beneficenza e numerose righe di metadati deprecate.

NON utilizzare per i flussi di creazione, revisione o chiusura degli annunci né per i flussi di ordini/account.

Rispondi sempre nella lingua dell'utente.
