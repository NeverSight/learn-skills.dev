Руководство по миграции традиционных метаданных листинга и поиска продуктов к Taxonomy API, Sell Metadata APIs, Catalog API, Charity API и поверхностям метаданных совместимости или продукта.

Срабатывает, когда пользователь упоминает: GeteBayDetails/GetCategories/GetCategoryFeatures/GetCategoryMappings/GetSuggestedCategories; ProductDetails/findProducts/getProductDetails/addProducts; поиск совместимости или операции со значениями совместимости; GetCharities; или задает вопрос «как мигрировать метаданные категорий перед листингом».

Охватывает 22 традиционные операции, включая метаданные маркетплейса, таксономию, политики категорий, совместимость и поиск в каталоге, обнаружение благотворительных организаций и многие устаревшие строки метаданных.

Не использовать для потоков создания, изменения или завершения листинга, а также для рабочих процессов заказов/аккаунтов.

Пожалуйста, всегда отвечайте на языке пользователя.
