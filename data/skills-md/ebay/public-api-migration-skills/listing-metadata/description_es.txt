Guía de migración para los metadatos tradicionales de publicación y el descubrimiento de productos a Taxonomy API, Sell Metadata APIs, Catalog API, Charity API y superficies de metadatos de compatibilidad o de producto.

Activar cuando el usuario mencione: GeteBayDetails/GetCategories/GetCategoryFeatures/GetCategoryMappings/GetSuggestedCategories; ProductDetails/findProducts/getProductDetails/addProducts; búsqueda de compatibilidad u operaciones de valores de compatibilidad; GetCharities; o pregunte “¿cómo migrar los metadatos de categoría antes de publicar?”.

Cubre 22 operaciones tradicionales, incluyendo metadatos del mercado, taxonomía, políticas de categoría, compatibilidad y consulta de catálogo, descubrimiento de organizaciones benéficas y muchas filas de metadatos descontinuados. NO lo use para flujos de creación, revisión o finalización de listados ni para flujos de pedidos o cuentas.

Por favor, responda siempre en el idioma del usuario.
