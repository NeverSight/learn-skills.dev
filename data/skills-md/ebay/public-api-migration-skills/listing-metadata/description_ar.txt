دليل الترحيل للبيانات الوصفية التقليدية للقوائم واكتشاف المنتجات إلى واجهة برمجة تطبيقات Taxonomy، وواجهات برمجة تطبيقات Sell Metadata، وواجهة Catalog، وواجهة Charity، والأسطح المتعلقة بالتوافق أو بيانات المنتجات الوصفية.

يتم التفعيل عندما يذكر المستخدم: GeteBayDetails / GetCategories / GetCategoryFeatures / GetCategoryMappings / GetSuggestedCategories؛ ProductDetails / findProducts / getProductDetails / addProducts؛ عمليات بحث التوافق أو قيم التوافق؛ GetCharities؛ أو يسأل «كيف أقوم بترحيل بيانات الفئة قبل الإدراج».

يغطي 22 عملية تقليدية تشمل بيانات السوق الوصفية، والتصنيف، وسياسات الفئات، والتوافق والبحث في الكتالوج، واكتشاف الجمعيات الخيرية، والعديد من صفوف البيانات الوصفية التي تم إيقافها.

لا يُستخدم لهذا الغرض في تدفقات إنشاء أو تعديل أو إنهاء القوائم أو في تدفقات الطلبات/الحسابات. 

يرجى الرد دائمًا بلغة المستخدم.
