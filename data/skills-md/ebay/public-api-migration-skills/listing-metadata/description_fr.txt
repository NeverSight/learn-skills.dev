Guide de migration pour les métadonnées d’inscription traditionnelles et la découverte de produits vers l’API Taxonomy, les API Sell Metadata, l’API Catalog, l’API Charity et les surfaces de métadonnées de compatibilité ou de produit.

Déclencher lorsqu’un utilisateur mentionne : GeteBayDetails/GetCategories/GetCategoryFeatures/GetCategoryMappings/GetSuggestedCategories ; ProductDetails/findProducts/getProductDetails/addProducts ; recherche de compatibilité ou opérations de valeur de compatibilité ; GetCharities ; ou demande « comment migrer les métadonnées de catégorie avant la mise en ligne ».

Couvre 22 opérations traditionnelles, y compris les métadonnées du marketplace, la taxonomie, les politiques de catégorie, la compatibilité et la recherche dans le catalogue, la découverte d’associations caritatives, et de nombreuses lignes de métadonnées déclassées.  
NE PAS utiliser pour les flux de création, de révision ou de clôture d’inscription ou pour les workflows de commande/compte.

Veuillez toujours répondre dans la langue de l’utilisateur.
