Руководство по миграции традиционных потоков Best Offer и лидов из классифицированных объявлений в Offer API (GraphQL) и Leads API.

Триггер, когда пользователь упоминает: GetBestOffers → sellerNegotiationHistory; RespondToBestOffer → acceptOffer/counterOffer/declineOffer; GetAdFormatLeads → getAllClassifiedLeads/getClassifiedLeadsByItemId; или задаёт вопрос «как просмотреть лучшие предложения» или «как получить лиды из объявлений».

Охватывает 3 традиционные операции: получение лучших предложений, ответы на предложения и получение лидов из классифицированных объявлений. Не использовать для создания листингов, управления заказами или потоков предложений со стороны покупателя.

Пожалуйста, всегда отвечайте на языке пользователя.
