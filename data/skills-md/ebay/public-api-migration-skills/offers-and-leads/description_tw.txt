傳統「最佳出價」與分類廣告潛在客戶流程遷移至 Offer API（GraphQL）和 Leads API 的指南。

當使用者提及以下內容時觸發：GetBestOffers → sellerNegotiationHistory；RespondToBestOffer → acceptOffer / counterOffer / declineOffer；GetAdFormatLeads → getAllClassifiedLeads / getClassifiedLeadsByItemId；或詢問「如何檢視最佳出價」或「如何取得分類廣告潛在客戶」。

涵蓋最佳出價取得、最佳出價回應以及分類廣告潛在客戶取得三項傳統操作。請勿用於商品上架、訂單管理或買方出價流程。
