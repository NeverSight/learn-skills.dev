Guide de migration pour les opérations VeRO traditionnelles et les utilitaires résiduels vers l’API VeRO ou des décisions explicites de nettoyage sans remplacement.

Déclencher lorsque l’utilisateur mentionne : GetVeROReasonCodeDetails → getVeroReasonCode/getVeroReasonCodes ; GetVeROReportStatus/VeROReportItems → getVeroReport/getVeroReportItems ; suppression ou refonte de GeteBayOfficialTime ; ou demande « comment migrer les appels de statut VeRO ou de code de raison ».

Couvre 4 opérations traditionnelles, y compris la recherche de codes de raison VeRO, le suivi des rapports VeRO et la ligne GeteBayOfficialTime sans remplacement.

Ne PAS utiliser pour les flux de travail de compte, d’inscription, de messagerie ou de gestion des commandes.

Veuillez toujours répondre dans la langue de l’utilisateur.
