傳統通知 API 呼叫與傳統平台通知事件遷移至通知 API 主題與訂閱資源的指導說明。

當使用者提及以下項目時觸發：GetNotificationPreferences、SetNotificationPreferences、GetNotificationsUsage，或平台事件如 BestOffer、BidPlaced、FeedbackReceived、EndOfAuction、My Messages 通知、關注清單通知，或詢問如何將交易平台通知遷移至通知 API 主題。

涵蓋 3 個傳統通知 API 呼叫、具體對映的平台事件（含捆綁證據），以及對剩餘通知列的明確未解決狀態清單。

請勿用於訂單檢索、清單建立或非通知遷移的任務。
