دليل الترحيل لاستدعاءات واجهة برمجة التطبيقات التقليدية للإشعارات وأحداث منصة الإشعارات التقليدية إلى مواضيع واجهة برمجة التطبيقات للإشعارات وموارد الاشتراك.

التفعيل عندما يذكر المستخدم: GetNotificationPreferences، SetNotificationPreferences، GetNotificationsUsage، أو أحداث المنصة مثل BestOffer، BidPlaced، FeedbackReceived، EndOfAuction، إشعارات My Messages، إشعارات قائمة المراقبة، أو يسأل عن كيفية ترحيل إشعارات منصة التداول إلى مواضيع واجهة برمجة التطبيقات للإشعارات.

يغطي 3 استدعاءات تقليدية لواجهة برمجة التطبيقات للإشعارات، أحداث منصة ملموسة مرفقة بأدلة مجمعة، وجرد صريح بحالة غير محلولة لبقية صفوف الإشعارات.
لا يُستخدم لاسترجاع الطلبات، إنشاء القوائم، أو مهام ترحيل غير متعلقة بالإشعارات.
