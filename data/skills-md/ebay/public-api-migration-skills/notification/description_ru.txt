Руководство по миграции традиционных вызовов Notification API и традиционных событий уведомлений платформы на темы Notification API и ресурсы подписки.

Срабатывает, когда пользователь упоминает: GetNotificationPreferences, SetNotificationPreferences, GetNotificationsUsage, или события платформы, такие как BestOffer, BidPlaced, FeedbackReceived, EndOfAuction, уведомления «Мои сообщения», уведомления списка наблюдения, либо задаёт вопрос, как перенести уведомления торговой платформы на темы Notification API.

Охватывает 3 традиционных вызова Notification API, конкретно сопоставленные события платформы с объединёнными доказательствами и явный список уведомлений со статусом «неразрешено» для оставшихся строк уведомлений. Не использовать для получения заказов, создания листингов или задач, не связанных с миграцией уведомлений.

Всегда отвечайте на языке пользователя.
