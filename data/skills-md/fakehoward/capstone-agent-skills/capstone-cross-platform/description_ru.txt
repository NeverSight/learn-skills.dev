Руководит кросс‑компиляцией Capstone и платформенно‑специфическими заметками по CMake для целей Linux, Android NDK, Windows и macOS. Используйте при кросс‑сборке Capstone, работе с файлами цепочки инструментов cross_configs, дымовых тестах QEMU, сборке Android ABI, сборке Windows с MSVC/CMake или универсальных/тонких бинарных файлов macOS.
