Описывает ограничения производительности и конкурентности Capstone для API 6 alpha: предпочтительно использовать cs_disasm_iter в горячих циклах, избегать CS_OPT_SYNTAX_CS_REG_ALIAS при масштабировании, использовать один дескриптор на поток и рассматривать хуки CS_OPT_MEM как глобальные для процесса. Применяется при оптимизации пропускной способности Capstone, многопоточной дизассемблизации или подключении пользовательских аллокаторов.
