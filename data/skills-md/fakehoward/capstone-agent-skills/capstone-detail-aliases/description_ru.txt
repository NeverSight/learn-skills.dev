Объясняет параметры Capstone CS_OPT_DETAIL, CS_OPT_DETAIL_REAL, функции is_alias, alias_id и usesAliasDetails в API 6 alpha. Используйте при включении детализации инструкций, выборе алиасов вместо реальных операндов, отладке подробностей, которые нельзя отключить, или обработке алиасов инструкций Capstone.
