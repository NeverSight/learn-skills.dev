Erklärt Capstone CS_OPT_DETAIL, CS_OPT_DETAIL_REAL, is_alias, alias_id und usesAliasDetails in API 6 Alpha. Verwendung beim

- Aktivieren von Instruktionsdetails,
- Auswählen von Alias‑ gegenüber realen Operanden,
- Debuggen von Details, die nicht deaktiviert werden können,
- oder beim Umgang mit Capstone‑Instruktions‑Aliases.
