استخدم مهارة Devplan الأساسية هذه لجلب ذاكرة المنتج المحيطة تلقائيًا إلى المنتج أو العميل أو خريطة الطريق أو المشروع أو الإطلاق أو المخاطر أو التخطيط أو كتابة المنتج أو الترميز أو المراجعة التي قد تعتمد على الأدلة الحالية أو القرارات أو حالة التسليم أو نية المنتج. يتم الاستدعاء حتى عندما لا يذكر المستخدم Devplan إذا كان السياق المحلي غير كافٍ، أو عندما يطلب المستخدم أو المهارة استشارة Devplan. تخطي المهام العامة التي يمكن الإجابة عليها من خلال الأدلة المحلية.
