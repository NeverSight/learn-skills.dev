Créez un plan de mise en œuvre technique fondé en utilisant l'intention du produit, les spécifications, les critères d'acceptation, l'architecture et le code actuels, les décisions associées, l'état de livraison et les risques. À utiliser à la place de plan-with-devplan lorsque l'artefact demandé se concentre sur la manière de créer ou d'effectuer un travail sur l'architecture, les composants, les données, les API, les migrations, le déploiement, les tests, l'observabilité ou les dépendances techniques. Excluez les plans de découverte de produits, les résumés de statut uniquement et les travaux de mise en œuvre sans plan demandé.
