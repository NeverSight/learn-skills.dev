Управляйте рабочими деревьями, контекстами папок, терминалами, репозиториями, автоматизацией, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Используйте, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff» / «handover» / «give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочтите это вместо обычного git worktree, ad hoc PTY или Computer Use, когда задействовано состояние Orca. Используйте Computer Use только тогда, когда нужен контроль над видимым окном GUI, который нельзя выполнить через CLI, файловую систему или API.
