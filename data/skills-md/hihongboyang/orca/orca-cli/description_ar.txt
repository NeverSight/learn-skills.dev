قم بتشغيل شجرات العمل التي تديرها Orca وسياقات المجلدات والطرفيات والمستودعات والأتمتة والقطع الفنية ومشاركة المهارات وتعليقات شجرة العمل والمتصفح المدمج في Orca عبر سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل ذلك على شجرة git الخام، أو PTY المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متورطة. استخدم "Computer Use" فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو API القيام بذلك.
