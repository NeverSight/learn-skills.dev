透過 `orca` CLI 操作由 Orca 管理的工作樹、資料夾情境、終端機、儲存庫、自動化、產物、技能分享、工作樹評論以及 Orca 內嵌瀏覽器。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時使用。涉及 Orca 狀態時，優先使用此方式而非原始 git worktree、即時 PTY 或 Computer Use。僅在需要控制可見視窗且 CLI、檔案系統或 API 無法完成時，才使用 Computer Use。
