Специализируясь на числовом дизайне игр, этот навык разрабатывает первоначальные значения баланса, диагностирует и настраивает существующие системы, а также оценивает предложения по балансу, создавая и запуская исполняемые модели, симуляторы, параметрические переборы и проверки доказательств. Используется для боя, прогрессии, экономик, предметов/сборок, PvP/мета‑игр и случайных наград, когда задача требует конкретных цифр или обоснованного решения. Не используйте для широких качественных критических оценок дизайна без числового или системного решения по балансу.
