Genera immagini tramite l'API Immagine dedicata di OpenRouter. Usa questa funzionalità ogni volta che l'utente desidera creare, renderizzare, generare o salvare immagini con OpenRouter, includendo testo‑a‑immagine, immagine‑a‑immagine/immagini di riferimento, la scelta dei modelli immagine di OpenRouter, l'elenco dei modelli immagine, l'impostazione di risoluzione/rapporto d'aspetto/qualità/formato di output, o il passaggio di opzioni immagine specifiche del provider. Preferisci lo script Python incluso così le opzioni API vengono passate esplicitamente come argomenti da riga di comando anziché tramite richieste curl ad‑hoc scritte a mano.

Rispondi sempre nella lingua dell'utente.
