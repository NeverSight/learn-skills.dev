Генерируйте изображения с помощью специального Image API от OpenRouter. Используйте этот навык каждый раз, когда пользователь хочет создавать, рендерить, генерировать или сохранять изображения с OpenRouter, включая текст‑в‑изображение, изображение‑в‑изображение/референсные изображения, выбор моделей изображений OpenRouter, перечисление моделей изображений, настройку разрешения, соотношения сторон, качества, формата вывода или передачу специфичных для провайдера параметров изображения. Предпочтительно использовать поставляемый скрипт на Python, чтобы параметры API передавались явно в виде аргументов командной строки, а не в виде вручную составленных curl‑запросов.

Всегда отвечайте на языке пользователя.
