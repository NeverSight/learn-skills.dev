OpenRouter の専用画像 API を使用して画像を生成します。ユーザーが OpenRouter で画像を作成、レンダリング、生成、保存したい場合は、テキストから画像への変換、画像から画像への変換／参照画像、OpenRouter 画像モデルの選択、画像モデルの一覧表示、解像度・アスペクト比・品質・出力フォーマットの設定、またはプロバイダー固有の画像オプションの指定など、常にこのスキルを使用してください。API オプションは、手書きの ad‑hoc curl リクエストではなく、コマンドライン引数として明示的に渡すことができるバンドルされた Python スクリプトを優先してください。

常にユーザーの言語で応答してください。
