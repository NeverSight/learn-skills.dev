قم بإنشاء وتنزيل مقاطع الفيديو عبر واجهة برمجة التطبيقات غير المتزامنة المخصصة للفيديو من OpenRouter. استخدم هذه الميزة كلما أراد المستخدم إنشاء أو إنتاج أو توليد أو الاستعلام أو استئناف أو حفظ فيديو من OpenRouter، بما في ذلك النص إلى فيديو، تحويل الإطار الأول/الأخير من صورة إلى فيديو، المرجع إلى فيديو، اختيار أو سرد نماذج الفيديو، ضبط المدة/الدقة/نسبة العرض إلى الارتفاع/الصوت/البذرة، التحقق من حالة المهمة، تنزيل المخرجات المكتملة، تكوين ردود النداء، أو تمرير خيارات الفيديو الخاصة بالمزود. يُفضَّل استخدام البرنامج النصي Python المرفق حتى تُعامل الوظائف غير المتزامنة وخيارات API بشكل متسق.
