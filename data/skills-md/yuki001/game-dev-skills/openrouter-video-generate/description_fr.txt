Générez et téléchargez des vidéos via l’API Vidéo asynchrone dédiée d’OpenRouter. Utilisez cette fonction chaque fois que l’utilisateur souhaite créer, rendre, générer, interroger, reprendre ou sauvegarder une vidéo OpenRouter, y compris texte‑vers‑vidéo, image (première/dernière image)‑vers‑vidéo, référence‑vers‑vidéo, choisir ou lister les modèles vidéo, définir la durée/la résolution/le format d’image‑aspect/l’audio/le seed, vérifier l’état du travail, télécharger les sorties terminées, configurer les callbacks ou transmettre des options vidéo spécifiques au fournisseur. Préférez le script Python fourni afin que les travaux asynchrones et les options d’API soient gérés de façon cohérente.

Veuillez toujours répondre dans la langue de l’utilisateur.
