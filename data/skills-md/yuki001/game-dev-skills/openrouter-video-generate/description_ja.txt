OpenRouter の専用非同期 Video API を使用して動画を生成・ダウンロードします。テキストから動画への変換、先頭／最後フレームの画像から動画への変換、リファレンスから動画への変換、動画モデルの選択や一覧取得、長さ・解像度・アスペクト比・音声・シードの設定、ジョブのステータス確認、完了した出力のダウンロード、コールバックの設定、プロバイダー固有の動画オプションの指定など、ユーザーが OpenRouter の動画（作成、レンダリング、生成、ポーリング、再開、保存）を行う際にこのスキルを使用してください。非同期ジョブと API オプションを一貫して処理できるよう、バンドルされた Python スクリプトの使用を推奨します。
