Создавайте и загружайте видео через специализированный асинхронный Video API OpenRouter. Используйте эту возможность каждый раз, когда пользователь хочет создать, отрендерить, сгенерировать, опросить, возобновить или сохранить видео OpenRouter, включая текст‑видео, изображение‑в‑первом/последнем кадре в видео, референс‑в‑видео, выбор или перечисление видеомоделей, задавание длительности/разрешения/соотношения сторон/аудио/сида, проверку статуса задачи, загрузку готовых выводов, настройку обратных вызовов или передачу специфических для провайдера параметров видео. Предпочтительно использовать включённый скрипт на Python, чтобы асинхронные задачи и параметры API обрабатывались последовательно.
