Procesamiento de imágenes en la línea de comandos con ImageMagick 7 de forma integral para inspeccionar, convertir, redimensionar, recortar, componer, enmascarar, dibujar, anotar, corregir color, cuantizar, filtrar, aplicar morfología, distorsionar, animar, montar, comparar, manejar metadatos, automatizar por lotes y análisis avanzado de píxeles. Utilícelo siempre que una tarea mencione ImageMagick, `magick`, `identify`, `mogrify`, conversión de imágenes raster o manipulación de imágenes por lotes, o cuando una canalización CLI reproducible sea preferible a una GUI o enlace de lenguaje. También úselo para depurar comandos de ImageMagick, portar la sintaxis de `convert` de ImageMagick 6 a la versión 7, elegir opciones de codificador/delegado y procesar de forma segura imágenes no confiables o de gran tamaño. No lo use simplemente para editar un SVG existente como fuente vectorial o cuando el usuario solicite explícitamente una herramienta de imágenes diferente.
