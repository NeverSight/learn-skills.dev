معالجة شاملة للصور عبر سطر الأوامر باستخدام ImageMagick 7 للتفتيش، التحويل، تغيير الحجم، القص، التركيب، القناع، الرسم، التعليق، تصحيح الألوان، الكمّية، الترشيح، الشكلية، التشويه، الرسوم المتحركة، التجميع، المقارنة، البيانات الوصفية، الأتمتة الدُفعية، والتحليل المتقدم للبكسل. استخدمه كلما ذُكرت مهمة تتعلق بـ ImageMagick أو `magick` أو `identify` أو `mogrify` أو تحويل الصور النقطية أو التلاعب بالصور على دفعات، أو عندما يكون خط أنابيب CLI القابل لإعادة الإنتاج مفضلاً على الواجهة الرسومية أو ربط اللغة. كما يُستَخدم لتصحيح أخطاء أوامر ImageMagick، نقل صيغ ImageMagick 6 `convert` إلى النسخة 7، اختيار خيارات المشفر/المندوب، ومعالجة الصور غير الموثوقة أو الكبيرة بأمان. لا تستخدمه مجرداً لتحرير SVG موجود كمصدر متجه أو عندما يطلب المستخدم صراحةً أداة صور مختلفة.
