إنشاء أوصاف نصية محسّنة للذكاء الاصطناعي للمكوّنات، مُنسقة لخادم MCP في فيغما واستهلاك نماذج اللغة الكبيرة. ينتج هذا أوصافًا نثرية بصيغة مكوّنة من ستة أقسام (الغرض، الخصائص، الأنماط المضادة، التركيب، إمكانية الوصول، أمثلة)، وليس مخططات JSON أو ملفات بيانات مُهيكلة. يُفعل عند قول أحدهم: كتابة وصف مكوّن للذكاء الاصطناعي، وصف MCP لفيغما، كتابة الوصف لقراءة كلود، وصف من ستة أقسام، وصف هذا المكوّن للذكاء الاصطناعي، أو أي شيء يتعلق بكتابة نص يجعل المكوّنات واضحة للنماذج اللغوية الكبيرة. لا تُفعّل عند طلب مخططات metadata بصيغة JSON، ملفات قيود مُهيكلة، أو بيانات أدوات برمجية — استخدم metadata-schema-generator لتلك.
