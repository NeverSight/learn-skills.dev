Générez des descriptions textuelles optimisées pour l'IA des composants, formatées pour le serveur MCP de Figma et la consommation par les LLM. Cela produit des descriptions en prose dans un format à six sections (objectif, propriétés, anti‑patrons, composition, accessibilité, exemples), PAS de schémas JSON ni de fichiers de données structurées. Déclenchez la génération lorsqu’une personne dit : « écrire une description de composant pour l'IA », « description MCP Figma », « rédiger la description pour Claude à lire », « description à six sections », « décrire ce composant pour l'IA », ou tout ce qui concerne la rédaction de texte rendant les composants lisibles par les LLM. NE déclenchez PAS pour les schémas de métadonnées JSON, les fichiers de contraintes structurées ou les données d'outils programmatiques — utilisez « metadata-schema-generator » pour ceux‑ci.

Veuillez toujours répondre dans la langue de l'utilisateur.
