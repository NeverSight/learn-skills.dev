Это генерирует прозаические описания в шестиразделном формате (цель, свойства, антипаттерны, композиция, доступность, примеры), а НЕ JSON‑схемы или файлы структурированных данных. Срабатывайте, когда кто‑то говорит: написать описание компонента для ИИ, описание MCP Figma, написать описание для чтения Claude, шестиразделное описание, описать этот компонент для ИИ или что‑угодно о написании текста, который делает компоненты читаемыми для LLM. НЕ срабатывайте на JSON‑метаданные схем, файлы структурированных ограничений или программные данные‑инструменты — используйте для этого metadata-schema-generator.
