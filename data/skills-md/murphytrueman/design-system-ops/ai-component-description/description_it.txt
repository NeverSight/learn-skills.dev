Questo produce descrizioni in prosa in un formato a sei sezioni (scopo, proprietà, anti-pattern, composizione, accessibilità, esempi), NON schemi JSON o file di dati strutturati. Attiva quando qualcuno dice: scrivi descrizione del componente per l'IA, descrizione MCP di Figma, scrivi la descrizione per Claude da leggere, descrizione a sei sezioni, descrivi questo componente per l'IA, o qualsiasi cosa riguardante la scrittura di testo che renda i componenti leggibili ai LLM. NON attivare per schemi di metadati JSON, file di vincoli strutturati o dati di strumenti programmatici — usa metadata-schema-generator per quelli.

Rispondi sempre nella lingua dell'utente.
