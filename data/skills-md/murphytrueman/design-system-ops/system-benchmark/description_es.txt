Realiza un benchmark de un sistema de diseño contra los estándares de la industria y sistemas públicos comparables, produciendo una comparación cualitativa a lo largo de dimensiones con puntos de referencia específicos y nombrados. Va más allá de una evaluación interna de salud para responder a “¿cómo se compara nuestro sistema con lo que se considera bueno ahí fuera?”. Se activa cuando alguien dice: benchmark nuestro sistema, ¿cómo nos comparamos?, comparación de industria, califica nuestro sistema contra otros, ¿dónde estamos?, compárenos con Material Design, cuán maduro es nuestro sistema, ¿estamos atrasados o avanzados?, evaluación competitiva de nuestro sistema de diseño, o cualquier cosa relacionada con comparar la madurez o calidad de un sistema de diseño contra benchmarks externos. NO se active para una verificación interna de salud sin comparación externa — use system-health para eso. NO se active para auditar una dimensión específica — use la habilidad de auditoría específica para eso.  
Por favor, responda siempre en el idioma del usuario.
