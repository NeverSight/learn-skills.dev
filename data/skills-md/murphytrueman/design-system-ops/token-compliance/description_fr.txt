Vérifiez une base de code ou une implémentation pour la conformité des jetons — en recherchant des valeurs codées en dur, des références de jetons de mauvais niveau et une application incohérente des jetons dans le code consommateur. Cela vérifie comment les jetons sont utilisés dans le code, PAS comment les jetons eux‑mêmes sont définis ou structurés. Déclenchez lorsque quelqu’un dit : utilisons‑nous correctement les jetons, trouvez les valeurs codées en dur, vérification de conformité des jetons, trouvez les valeurs brutes, mauvaise utilisation des jetons, y a‑t‑il des valeurs hexadécimales dans le code, vérification de l’utilisation des jetons, ou tout ce qui concerne le fait que les jetons soient utilisés de manière cohérente et correcte. NE déclenchez PAS pour auditer les définitions des jetons elles‑mêmes — utilisez token‑audit pour cela. Veuillez toujours répondre dans la langue de l’utilisateur.
