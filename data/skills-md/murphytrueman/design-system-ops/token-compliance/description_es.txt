Revisa una base de código o implementación para el cumplimiento de tokens — encontrando valores codificados, referencias a tokens de nivel incorrecto y aplicación inconsistente de tokens en el código que los consume. Esto verifica cómo se usan los tokens en el código, NO cómo se definen o estructuran los propios tokens. Activa la respuesta cuando alguien diga: ¿estamos usando los tokens correctamente?, encontrar valores codificados, verificación de cumplimiento de tokens, encontrar valores crudos, uso indebido de tokens, ¿hay valores hexadecimales en el código?, verificar el uso de tokens, o cualquier cosa relacionada con si los tokens se están usando de manera consistente y correcta. NO actives la respuesta para auditar las definiciones de los tokens en sí — usa token-audit para eso.

Por favor, responde siempre en el idioma del usuario.
