تدقيق واجهات برمجة التطبيقات للمكونات من حيث الاتساق، والتغييرات المكسرة، وتغطية TypeScript، والامتثال للعقود عبر مكتبة المكونات. يتم التفعيل عندما يقول أحدهم: مراجعة خصائص المكون، التحقق من تصدير أنواع المكون، تدقيق واجهة برمجة تطبيقات المكون، فحص واجهات مكوننا، هل خصائصنا متسقة، فحص اتساق الواجهة، مراجعة تسميات الخصائص، اكتشاف التغييرات المكسرة، أو أي شيء يتعلق بالتحقق مما إذا كانت واجهات برمجة التطبيقات للمكونات صالحة هيكليًا ومتسقة عبر المكتبة. يرجى دائمًا الرد بلغة المستخدم.
