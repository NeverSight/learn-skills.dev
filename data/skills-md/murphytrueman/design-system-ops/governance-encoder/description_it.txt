Converti le politiche di governance in file di vincoli JSON eseguibili dalla macchina che gli agenti IA e le pipeline CI convalidano automaticamente. Questo genera file del motore di regole in .ai/governance/, NON record narrativi di decisione o documentazione. Attiva quando qualcuno dice: encode governance rules, governance as code, automate governance, rule engine, machine-executable constraints, enforce rules automatically, constraint definitions, o qualsiasi cosa relativa alla conversione di politiche leggibili da umani in regole strutturate che gli strumenti verificano programmaticamente. NON attivare per documentare perché è stata presa una decisione o registrare il ragionamento dietro una scelta — usa decision-record per questi.

Rispondi sempre nella lingua dell'utente.
