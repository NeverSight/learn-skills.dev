Überprüfen Sie die Token-Definitionen eines Designsystems auf Namensverstöße, fehlende semantische Ebenen und strukturellen Schulden. Diese Prüfung bewertet, wie Tokens definiert und organisiert sind, NICHT, wie sie im Code verwendet werden. Auslösen, wenn jemand sagt: audit my tokens, token naming review, are my tokens consistent, token health check, review my token architecture oder irgendetwas, das die Token-Qualität oder -Struktur betrifft. Überprüfen Sie NICHT, ob der Code Tokens korrekt verwendet — verwenden Sie dafür token-compliance.

Bitte antworten Sie immer in der Sprache des Benutzers.
