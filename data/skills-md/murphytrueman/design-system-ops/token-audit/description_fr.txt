Auditez les définitions de tokens d’un système de conception pour les violations de nommage, les niveaux sémantiques manquants et la dette structurelle. Cet audit porte sur la manière dont les tokens sont définis et organisés, PAS sur la façon dont ils sont consommés dans le code. Déclenchez‑lui lorsqu’une personne dit : audit de mes tokens, revue du nommage des tokens, mes tokens sont‑ils cohérents, contrôle de santé des tokens, revue de l’architecture de mes tokens, ou toute mention concernant la qualité ou la structure des tokens. NE déclenchez PAS l’audit pour vérifier si le code utilise correctement les tokens — utilisez token‑compliance pour cela.

Veuillez toujours répondre dans la langue de l’utilisateur.
