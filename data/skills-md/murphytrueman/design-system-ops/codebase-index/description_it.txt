Genera un indice di componenti pre‑calcolato da una codebase di sistema di design — file di infrastruttura YAML contenenti un inventario dei componenti, un grafo delle relazioni e statistiche riepilogative che gli agenti AI e i server MCP consumano. Questo produce file di indice leggibili da macchine in .ai/index/, NON un rapporto di salute o una valutazione di qualità. Attiva quando qualcuno dice: indicizza la mia codebase, costruisci un grafo delle relazioni, crea una mappa dei componenti, indice della codebase, cosa dipende da cosa, grafo delle dipendenze, mappa le relazioni dei componenti, o qualsiasi cosa relativa alla produzione di file di infrastruttura interrogabili per gli agenti AI o gli strumenti per sviluppatori. NON attivare per valutazioni della salute dei componenti, punteggi di qualità o rapporti di audit — usa component-audit per quelli.

Rispondi sempre nella lingua dell'utente.
