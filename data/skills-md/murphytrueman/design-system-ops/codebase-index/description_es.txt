Genera un índice de componentes precomputado a partir de una base de código de sistema de diseño — archivos de infraestructura YAML que contienen un inventario de componentes, un grafo de relaciones y estadísticas resumidas que consumen los agentes de IA y los servidores MCP. Esto produce archivos de índice legibles por máquina en .ai/index/, NO un informe de salud o evaluación de calidad. Activa cuando alguien dice: indexa mi base de código, construye un grafo de relaciones, crea un mapa de componentes, índice de base de código, qué depende de qué, grafo de dependencias, mapa de relaciones de componentes, o cualquier cosa sobre producir archivos de infraestructura consultables para agentes de IA o herramientas de desarrollo. NO actives para evaluaciones de salud de componentes, puntuaciones de calidad o informes de auditoría — usa component-audit para esos.

Por favor, responde siempre en el idioma del usuario.
