Générez un index de composants pré‑calculé à partir d’une base de code de système de conception — fichiers d’infrastructure YAML contenant un inventaire de composants, un graphe de relations et des statistiques résumées que les agents IA et les serveurs MCP consomment. Cela produit des fichiers d’index lisibles par machine dans .ai/index/, PAS un rapport de santé ou une évaluation de qualité. Déclenchez lorsque quelqu’un dit : indexe mon code, construis un graphe de relations, crée une carte des composants, index de la base de code, qui dépend de quoi, graphe de dépendances, cartographie des relations de composants, ou tout ce qui concerne la production de fichiers d’infrastructure interrogeables pour les agents IA ou les outils de développeur. Ne déclenchez PAS pour les évaluations de santé des composants, les scores de qualité ou les rapports d’audit — utilisez component-audit pour ceux‑ci.

Veuillez toujours répondre dans la langue de l’utilisateur.
