Escribe guías de uso para un componente específico y nombrado — cubriendo cuándo usarlo, cuándo no usarlo, casos límite y anti‑patrones para ese componente. Esto documenta CÓMO usar un componente que ya has elegido, NO cómo elegir entre componentes. Activa la respuesta cuando alguien diga: escribe guías de uso para [componente], cosas que se deben y no se deben hacer para [componente], cómo debería usarse [componente], reglas de uso, escribe las directrices para [componente], o cualquier cosa sobre crear una guía prescriptiva para un único componente nombrado. NO actives la respuesta para elegir entre componentes — usa component-decision-tree para eso. NO actives la respuesta para documentar patrones de múltiples componentes — usa pattern-documentation para eso. Por favor, responde siempre en el idioma del usuario.
