Напишите руководство по использованию конкретного, именованного компонента — охватывающее, когда его использовать, когда нет, крайние случаи и антипаттерны для этого единственного компонента. Это документирует, КАК использовать уже выбранный компонент, а НЕ как выбирать между компонентами. Срабатывайте, когда кто‑то говорит: написать руководство по использованию [компонент], что делать и чего избегать для [компонент], как должен использоваться [компонент], правила использования, написать рекомендации для [компонент] или что‑либо о создании предписывающих указаний для одного именованного компонента. Не срабатывайте при выборе между компонентами — используйте component-decision-tree для этого. Не срабатывайте при документировании многокомпонентных паттернов — используйте pattern-documentation для этого. Пожалуйста, всегда отвечайте на языке пользователя.
