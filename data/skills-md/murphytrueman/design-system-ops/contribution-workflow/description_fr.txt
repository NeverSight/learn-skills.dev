Créer ou documenter un flux de travail de contribution pour un système de conception — le processus à plusieurs étapes permettant d’évaluer, d’accepter et d’accompagner les nouvelles contributions jusqu’à leur publication. Déclencher lorsque quelqu’un dit : comment quelqu’un devrait contribuer, processus de contribution, ajout d’un nouveau composant, directives de contribution, quel est le processus pour ajouter quelque chose, comment nous gérons les contributions, ou tout ce qui concerne le processus d’introduction de nouveaux travaux dans le système de conception. NE PAS déclencher pour convertir les constats d’audit en tickets de backlog — utilisez backlog-generator pour cela.

Veuillez toujours répondre dans la langue de l’utilisateur.
