Construye árboles de decisión consultables que ayuden a agentes y equipos a elegir entre componentes — archivos YAML estructurados que asignan las intenciones del usuario al componente correcto mediante una secuencia de preguntas que van afinando. Esto produce lógica de selección para elegir ENTRE componentes, NO directrices de uso para un solo componente. Activa cuando alguien dice: árbol de decisión de componentes, ¿qué componente debo usar?, ayúdame a escoger entre, guía de selección, marco de decisión, modal vs diálogo, mapeo intención‑a‑componente, o cualquier cosa relacionada con crear lógica estructurada para seleccionar el componente correcto entre alternativas. NO actives para guías de uso de un componente específico — usa directrices de uso para eso.

Por favor, responde siempre en el idioma del usuario.
