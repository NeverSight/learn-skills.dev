Создавайте запросные деревья решений, которые помогают агентам и командам выбирать между компонентами — структурированные файлы YAML, сопоставляющие намерения пользователей с правильным компонентом через последовательность уточняющих вопросов. Это создаёт логику выбора ДЛЯ ПОЛЬЗОВАНИЯ МЕЖДУ компонентами, а НЕ рекомендации по использованию отдельного компонента. Срабатывайте, когда кто‑то говорит: «дерево решений по компоненту», «какой компонент мне использовать», «помогите выбрать между», «руководство по выбору», «рамки принятия решения», «modal vs dialog», «сопоставление намерения с компонентом» или любые запросы о создании структурированной логики для выбора правильного компонента из альтернатив. НЕ срабатывайте на запросы о рекомендациях по использованию конкретного компонента — используйте для этого рекомендации по использованию.
