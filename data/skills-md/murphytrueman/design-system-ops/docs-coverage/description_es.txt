Audita si la superficie de documentación de un sistema de diseño se mantiene al día con su biblioteca de componentes — brechas de cobertura (componentes sin docs), obsolescencia (docs que preceden al último cambio de código del componente) y docs huérfanas. Funciona sin integración alguna del código base y con una compilación de Storybook; Zeroheight, Supernova y sitios de docs personalizados son capas opcionales. Activa cuando alguien dice: cobertura de docs, auditoría de documentación, ¿están actualizados nuestros docs?, qué componentes no están documentados, ¿nuestra documentación se mantiene al día?, verificación de docs obsoletos, salud de la documentación, cobertura de Storybook, o cualquier cosa sobre si la superficie de documentación coincide con los componentes. NO actives para ESCRIBIR documentación — usa usage‑guidelines, pattern‑documentation, token‑documentation o ai‑component‑description para eso. NO actives para salud general del sistema (usa system‑health) o para uso/analítica de documentación (usa adoption‑report).
