디자인 시스템 채택 보고서를 작성하되, 커버리지를 실제 채택과 구분하고, 추세 방향과 위험 플래그를 포함하세요. 다음과 같은 말을 들을 때 트리거하세요: adoption report(채택 보고서), how much is the system being used(시스템이 얼마나 사용되고 있는지), usage metrics(사용 메트릭), adoption status(채택 상태), coverage report(커버리지 보고서), which teams are using the system(어떤 팀이 시스템을 사용하고 있는지), who's not using the system(누가 시스템을 사용하지 않는지), 혹은 디자인 시스템이 얼마나 널리 사용되는지를 측정하거나 보고하는 모든 내용. 여기서 'coverage'는 채택 커버리지를 의미하며(팀이 실제로 시스템을 얼마나 사용하는지). 문서 커버리지나 문서 노후화에 대해서는 트리거하지 마세요 — docs-coverage는 문서 표면이 컴포넌트와 맞춰지는지를 나타냅니다. 항상 사용자의 언어로 응답해 주세요.
