Générez des schémas de métadonnées JSON structurés pour les composants d’un système de conception — des définitions de contraintes lisibles par machine qui codent les propriétés, les règles comportementales, les contraintes de composition, les combinaisons interdites et les contrats d’accessibilité sous forme de données programmatiques. Cela produit des fichiers JSON pour les outils (serveurs MCP, linters, générateurs de code, cadres de test), et NON des descriptions textuelles pour les humains ou Figma. Déclenchez lorsque quelqu’un dit : générer un schéma de métadonnées, schéma JSON pour les composants, contrat de composant en JSON, métadonnées structurées pour les outils, contraintes de propriétés sous forme de données, règles de composants lisibles par machine, ou tout ce qui concerne la production de JSON/données structurées que les outils consomment programmatiquement. NE déclenchez PAS pour les descriptions Figma, la documentation des composants ou le texte lisible par IA — utilisez ai-component-description pour ceux‑ci.

Veuillez toujours répondre dans la langue de l’utilisateur.
