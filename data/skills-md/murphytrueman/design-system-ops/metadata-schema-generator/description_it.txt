Genera schemi di metadati JSON strutturati per i componenti del design system — definizioni di vincoli leggibili da macchina che codificano proprietà, regole comportamentali, vincoli di composizione, combinazioni proibite e contratti di accessibilità come dati programmatici. Questo produce file JSON per gli strumenti (server MCP, lint, generatori di codice, framework di test), NON descrizioni testuali per esseri umani o Figma. Attiva quando qualcuno dice: genera schema di metadati, schema JSON per componenti, contratto del componente come JSON, metadati strutturati per gli strumenti, vincoli delle proprietà come dati, regole di componente leggibili da macchina, o qualsiasi cosa relativa alla produzione di JSON/dati strutturati che gli strumenti consumano programmaticamente. NON attivare per descrizioni Figma, documentazione dei componenti o testo leggibile da IA — usa ai-component-description per questi.

Rispondi sempre nella lingua dell'utente.
