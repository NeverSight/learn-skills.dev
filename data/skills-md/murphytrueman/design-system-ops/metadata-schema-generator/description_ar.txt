توليد مخططات تعريف البيانات الوصفية بتنسيق JSON منظم لمكونات نظام التصميم — تعريفات قيود قابلة للقراءة آليًا تُشفّر الخصائص، القواعد السلوكية، قيود التركيب، التوليفات المحظورة، واتفاقيات الوصول كبيانات برمجية. ينتج هذا ملفات JSON للأدوات (خوادم MCP، أدوات التدقيق، مولّدات الشيفرة، أطر الاختبار)، وليس أوصافًا نصية للبشر أو Figma. يتم التحفيز عندما يقول أحدهم: توليد مخطط بيانات وصفية، مخطط JSON للمكونات، عقد المكوّن كـ JSON، بيانات وصفية منظمة للأدوات، قيود الخصائص كبيانات، قواعد المكوّن القابلة للقراءة آليًا، أو أي شيء يتعلق بإنتاج JSON/بيانات منظمة تستهلكها الأدوات برمجيًا. لا تُحفّز للواصفات الخاصة بـ Figma، وثائق المكوّن، أو النص القابل للقراءة للذكاء الاصطناعي — استخدم ai-component-description لتلك.
