Erstelle strukturierte JSON‑Metadaten‑Schemas für Design‑System‑Komponenten – maschinenlesbare Constraint‑Definitionen, die Props, Verhaltensregeln, Zusammensetzungs‑Constraints, verbotene Kombinationen und Barrierefreiheits‑Verträge als programmierbare Daten kodieren. Dies erzeugt JSON‑Dateien für Werkzeuge (MCP‑Server, Linter, Code‑Generatoren, Test‑Frameworks), NICHT Textbeschreibungen für Menschen oder Figma. Auslösen, wenn jemand sagt: generate metadata schema, JSON schema for components, component contract as JSON, structured metadata for tooling, prop constraints as data, machine‑readable component rules oder irgendetwas über das Erzeugen von JSON/strukturierten Daten, die Werkzeuge programmatisch konsumieren. Nicht auslösen für Figma‑Beschreibungen, Komponentendokumentation oder KI‑lesbaren Text – dafür ai‑component‑description verwenden.
