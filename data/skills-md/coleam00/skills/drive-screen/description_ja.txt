デスクトップを実際に制御し、ウィンドウの一覧表示やフォーカス、入力、貼り付け、クリック、スクロール、スクリーンショットを行うことができます（Windows、macOS、Linux 対応）。ターミナルで実行中の他のコーディングエージェントセッションも操作できます。画面やその日のセットアップを依頼されたとき、アプリやリポジトリのセットを開いて配置する、録画前にライブデモを準備・実行する、ヘッドレス環境がなくデスクトップアプリのテストを行う、別ウィンドウで Claude Code セッションを起動・操作する、証拠として画面上の内容をキャプチャする、などの用途に使用してください。「画面をセットアップして」「デモの準備をして」「画面を操作して」「デスクトップを制御して」「これらのリポジトリを開いて開始して」「このデスクトップアプリをテストして」「マシンでこれを実行して見せて」などのフレーズでトリガーされます。ブラウザ自動化には、専用のヘッドレスツールがありますので、こちらは対象外です。
