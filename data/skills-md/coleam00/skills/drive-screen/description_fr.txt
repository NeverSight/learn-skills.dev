Prenez le contrôle réel du bureau – listez et focalisez les fenêtres, tapez, collez, cliquez, faites défiler et prenez des captures d’écran – sous Windows, macOS ou Linux, et pilotez d’autres sessions d’agents de codage s’exécutant dans des terminaux. Utilisez‑le lorsqu’on vous demande de configurer l’écran ou la journée, d’ouvrir et d’arranger un ensemble d’applications ou de dépôts, de préparer ou d’exécuter une démonstration en direct avant l’enregistrement, de tester une application de bureau qui n’a pas de harness sans tête, de lancer ou de diriger une session Claude Code dans une autre fenêtre, ou de capturer ce qui se trouve à l’écran comme preuve. Déclencheurs sur « set up my screen », « get my demo ready », « drive the screen », « control my desktop », « open these repos and start », « test this desktop app », « run this on my machine and show me ». Pas pour l’automatisation de navigateur, qui possède ses propres outils sans tête.
