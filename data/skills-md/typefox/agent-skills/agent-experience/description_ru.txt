Подготовьте кодовый репозиторий к работе с агентами, используя передовой AX (Agent Experience): проведите аудит и настройте AGENTS.md / CLAUDE.md и документы агента, подключите датчики проверки с сообщениями самокоррекции и создайте docs-as-memory (документы архитектуры, ADR, планы выполнения). Используйте, когда пользователь хочет сделать репозиторий готовым к агентам или AI‑дружественным, подключить кодирующие агенты, создать/просмотреть/улучшить AGENTS.md, CLAUDE.md или другие файлы инструкций для агентов, настроить проект для разработки, ориентированной на агентов, задаёт вопрос, почему агент продолжает повторять ошибку, задаёт любой вопрос по AX (общий или проектный) или упоминает «harness engineering», «agent readiness», «context engineering» (его репозиториальная часть) или «AX». Не предназначено для построения рантаймов агентов или кода оркестрации, а также не для создания отдельного навыка агента — используйте для этого skill‑creator.
