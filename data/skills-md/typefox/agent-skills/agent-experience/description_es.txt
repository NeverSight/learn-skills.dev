Haz que un repositorio de código esté listo para agentes con la última AX (Experiencia de Agente): audita y configura AGENTS.md / CLAUDE.md y la documentación de agentes, conecta sensores de verificación con mensajes de autocorrección y crea docs-como-memoria (documentos de arquitectura, ADRs, planes de ejecución). Úsalo cuando el usuario quiera que un repo sea apto para agentes o amigable con IA, incorporar agentes de codificación, crear/revisar/mejorar AGENTS.md, CLAUDE.md u otros archivos de instrucción para agentes, configurar un proyecto para desarrollo orientado a agentes, preguntar por qué un agente sigue repitiendo un error, hacer cualquier pregunta sobre AX (general o específica del proyecto), o mencionar "ingeniería de arneses", "preparación de agentes", "ingeniería de contexto" (su parte del repositorio) o "AX". No es para crear entornos de ejecución de agentes ni código de orquestación, ni para redactar una única habilidad de agente — usa skill-creator para eso.
