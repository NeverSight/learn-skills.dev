Rendez un référentiel de code prêt pour les agents avec l'AX (Agent Experience) de pointe : auditez et configurez AGENTS.md / CLAUDE.md et la documentation des agents, branchez des capteurs de vérification avec des messages d’auto‑correction, et créez des docs‑as‑memory (documents d’architecture, ADR, plans d’exécution). Utilisez‑le lorsque l’utilisateur veut rendre un dépôt agent‑ready ou AI‑friendly, intégrer des agents de codage, créer / examiner / améliorer AGENTS.md, CLAUDE.md ou d’autres fichiers d’instructions d’agent, mettre en place un projet pour un développement « agent‑first », se demander pourquoi un agent répète une erreur, poser n’importe quelle question sur l’AX (générale ou propre à un projet), ou mentionner « harness engineering », « agent readiness », « context engineering » (sa partie côté dépôt) ou « AX ». Ce n’est pas destiné à la construction de runtimes d’agents ou de code d’orchestration, ni à la rédaction d’une compétence d’agent unique — utilisez skill‑creator pour cela.

Veuillez toujours répondre dans la langue de l’utilisateur.
