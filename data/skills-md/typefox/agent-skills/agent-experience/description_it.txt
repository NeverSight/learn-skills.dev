Rendi un repository di codice pronto per gli agenti con l'AX (Agent Experience) all’avanguardia: verifica e configura AGENTS.md / CLAUDE.md e la documentazione degli agenti, collega sensori di verifica con messaggi di autoconcorrezione e costruisci documenti‑come‑memoria (documentazione architetturale, ADR, piani esecutivi). Usa quando l’utente vuole rendere un repo pronto per gli agenti o AI‑friendly, integrare agenti di programmazione, creare/revisionare/migliorare AGENTS.md, CLAUDE.md o altri file di istruzioni per agenti, impostare un progetto per lo sviluppo agent‑first, chiedere perché un agente continua a ripetere un errore, porre qualsiasi domanda su AX (generale o specifica di progetto) o menzionare “harness engineering”, “agent readiness”, “context engineering” (la sua porzione lato repository) o “AX”. Non è destinato alla costruzione di runtime per agenti o codice di orchestrazione, né alla creazione di una singola skill per agente — usa skill‑creator per quello.

Rispondi sempre nella lingua dell’utente.
