Mache ein Code-Repository agentenbereit mit modernster AX (Agent Experience): prüfe und richte AGENTS.md / CLAUDE.md und Agentendokumentationen ein, verbinde Verifikationssensoren mit Selbstkorrekturmeldungen und erstelle Docs-as-Memory (Architekturdokumente, ADRs, Ausführungspläne). Verwende dies, wenn der Benutzer das Repository agentenbereit oder KI‑freundlich machen möchte, Coding‑Agents einbinden, AGENTS.md, CLAUDE.md oder andere Agenten‑Instruktionsdateien erstellen/überprüfen/verbessern, ein Projekt für agenten‑zuerst‑Entwicklung einrichten, fragt, warum ein Agent einen Fehler immer wieder wiederholt, eine AX‑Frage (allgemein oder projektspezifisch) stellt oder „harness engineering“, „agent readiness“, „context engineering“ (sein Repository‑seitiger Ausschnitt) oder „AX“ erwähnt. Nicht zum Erstellen von Agent‑Runtimes oder Orchestrierungscode, noch zum Verfassen einer einzelnen Agenten‑Fähigkeit — dafür bitte skill-creator verwenden.
