최신 AX(Agent Experience)를 활용해 코드 저장소를 에이전트 준비 상태로 만들기: AGENTS.md / CLAUDE.md와 에이전트 문서를 감사하고 설정하며, 자체 수정 메시지를 포함한 검증 센서를 연결하고, 문서를 메모리처럼 구축하기(아키텍처 문서, ADR, 실행 계획). 다음과 같은 경우에 사용하십시오: 사용자가 저장소를 에이전트‑준비 또는 AI‑친화적으로 만들고 싶을 때, 코딩 에이전트를 온보딩할 때, AGENTS.md, CLAUDE.md 또는 기타 에이전트 지시 파일을 생성·검토·개선할 때, 에이전트‑우선 개발을 위해 프로젝트를 설정할 때, 에이전트가 실수를 반복하는 이유를 질문할 때, 일반 또는 프로젝트‑특정 AX 질문을 할 때, 혹은 “harness engineering”, “agent readiness”, “context engineering”(저장소 측면) 또는 “AX”를 언급할 때. 에이전트 런타임이나 오케스트레이션 코드를 만들거나 단일 에이전트 스킬을 작성하는 데는 사용하지 마십시오—그 경우에는 skill-creator를 사용하십시오. 항상 사용자의 언어로 응답하십시오.
