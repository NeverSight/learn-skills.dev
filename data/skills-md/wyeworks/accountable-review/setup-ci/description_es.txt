Configura un repositorio para que Accountable Review genere automáticamente un Review Map en CI — un flujo de trabajo de GitHub Actions que se ejecuta cuando una pull request se vuelve revisable por primera vez, omite borradores, forks, bots y cambios con muy poco código de aplicación para tener un orden de lectura, cancela ejecuciones supersedidas, sube el HTML estático resultante como un artefacto de compilación que todo el equipo puede abrir y comenta el enlace en la pull request. Usa esto cuando alguien quiere que los mapas de revisión se generen automáticamente en lugar de a mano, solicita añadir Accountable Review a CI o a GitHub Actions, desea que el mapa de revisión se comparta con su equipo en lugar de publicarse desde un solo portátil, o pregunta cómo ejecutarlo en cada PR. Invócala con /accountable-review:setup-ci. Inspecciona el repositorio antes de escribir cualquier cosa, confirma cuándo se generarán los mapas y qué puede hacer el flujo de trabajo, prefiere un flujo de trabajo dedicado, nunca modifica CI no relacionado y es seguro ejecutarla dos veces. No es para generar un mapa de revisión — eso es review‑map — y la configuración en sí no publica nada en GitHub.
