Configura un repository in modo che Accountable Review generi automaticamente una Review Map nella CI — un workflow di GitHub Actions che si avvia quando una pull request diventa per la prima volta revisionabile, salta bozze, fork, bot e modifiche con troppo poco codice applicativo per avere un ordine di lettura, annulla le esecuzioni sovrascritte, carica l'HTML statico risultante come artefatto di build che l'intero team può aprire e commenta il link sulla pull request. Usa questo quando qualcuno desidera mappe di revisione generate automaticamente anziché manualmente, chiede di aggiungere Accountable Review alla CI o a GitHub Actions, vuole condividere la mappa di revisione con il proprio team invece di pubblicarla da un singolo laptop, o chiede come eseguirla su ogni PR. Invocare con /accountable-review:setup-ci. Ispeziona il repository prima di scrivere qualsiasi cosa, conferma quando le mappe saranno generate e cosa potrà fare il workflow, preferisce un workflow dedicato, non modifica mai CI non correlata e può essere eseguito in sicurezza due volte. Non serve a generare una review map — quello è review‑map — e la configurazione stessa non pubblica nulla su GitHub.
