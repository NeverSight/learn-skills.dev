將儲存庫設定為在 CI 中自動產生 Accountable Review 的 Review Map —— 這是一個 GitHub Actions 工作流程，會在拉取請求首次變為可審查時執行，略過草稿、fork、機器人，以及變更內容過少而無法產生閱讀順序的程式碼，取消被取代的執行，將產生的靜態 HTML 上傳為全團隊可開啟的建置產物，並在拉取請求上留下連結的評論。當有人希望自動產生 review map 而非手動、要求將 Accountable Review 加入 CI 或 GitHub Actions、希望 review map 在團隊間共享而非只在單一筆記本電腦上發布，或詢問如何在每個 PR 上執行此功能時，請使用此指令。以 /accountable-review:setup-ci 呼叫。它會在寫入任何內容前先檢查儲存庫，確認何時會產生 map 以及工作流程可能執行的動作，偏好使用獨立的工作流程，絕不修改不相關的 CI，且可安全執行兩次。此指令不是用來產生 review map（那是 review‑map），設定本身不會向 GitHub 發布任何訊息。
