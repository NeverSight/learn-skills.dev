配置仓库，使 Accountable Review 在 CI 中自动生成 Review Map —— 一个 GitHub Actions 工作流，在拉取请求首次可审查时运行，跳过草稿、fork、机器人以及代码量过少、没有阅读顺序的更改，取消已被取代的运行，将生成的静态 HTML 作为构建产物上传，供全团队打开，并在拉取请求中评论该链接。  
当有人希望自动生成审查地图而不是手动生成，要求将 Accountable Review 添加到 CI 或 GitHub Actions，想要将审查地图共享给团队而不是只在一台笔记本上发布，或询问如何在每个 PR 上运行此功能时使用它。  
使用 `/accountable-review:setup-ci` 调用。它在写入任何内容之前检查仓库，确认何时生成地图以及工作流可能执行的操作，倾向使用专用工作流，永不修改无关的 CI，并且可以安全地运行两次。此指令并非用于生成审查地图——那是 `review‑map` —— 设置本身不会向 GitHub 发帖。
