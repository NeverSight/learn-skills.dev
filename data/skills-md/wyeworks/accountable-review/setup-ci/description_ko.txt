레포지토리를 설정하여 Accountable Review가 CI에서 자동으로 Review Map을 생성하도록 구성합니다 — 풀 리퀘스트가 처음 리뷰 가능해질 때 실행되는 GitHub Actions 워크플로이며, 초안, 포크, 봇, 그리고 읽기 순서를 만들기에 충분하지 않은 애플리케이션 코드가 적은 변경은 건너뛰고, 이전 실행을 취소하며, 결과물인 정적 HTML을 팀 전체가 열어볼 수 있는 빌드 아티팩트로 업로드하고, 풀 리퀘스트에 링크를 댓글로 남깁니다. 손으로 직접 리뷰 맵을 만들기보다 자동으로 생성하고 싶을 때, CI 혹은 GitHub Actions에 Accountable Review를 추가해 달라고 요청할 때, 리뷰 맵을 한 대의 노트북에서 공개하는 대신 팀과 공유하고 싶을 때, 혹은 모든 PR에서 이 작업을 실행하는 방법을 물어볼 때 사용합니다. `/accountable-review:setup-ci` 로 호출합니다. 이 명령은 아무것도 쓰기 전에 레포지토리를 검사하고, 언제 맵이 생성될지와 워크플로가 수행할 수 있는 일을 확인하며, 전용 워크플로를 선호하고, 관련 없는 CI를 절대 수정하지 않으며, 두 번 실행해도 안전합니다. 리뷰 맵을 생성하기 위한 것이 아니라 — 그 역할은 `review‑map` 입니다 — 설정 자체는 GitHub에 아무것도 게시하지 않습니다.
