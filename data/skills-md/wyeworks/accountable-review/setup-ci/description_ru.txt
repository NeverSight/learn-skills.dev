Настраивает репозиторий так, чтобы Accountable Review автоматически генерировал Review Map в CI — workflow GitHub Actions, который запускается, когда pull‑request впервые становится доступным для обзора, пропускает черновики, форки, ботов и изменения с слишком небольшим объёмом кода приложения, чтобы иметь порядок чтения, отменяет устаревшие запуски, загружает полученный статический HTML как артефакт сборки, доступный всей команде, и оставляет комментарий со ссылкой в pull‑request. Используйте это, когда кто‑то хочет, чтобы карты обзора генерировались автоматически, а не вручную, просит добавить Accountable Review в CI или в GitHub Actions, хочет, чтобы карта обзора была доступна всей команде, а не опубликована с одного ноутбука, или спрашивает, как запустить это для каждого PR. Вызывается командой /accountable-review:setup-ci. Он проверяет репозиторий перед тем, как что‑то записать, подтверждает, когда карты будут генерироваться и что может делать workflow, предпочитает отдельный workflow, никогда не изменяет несвязанный CI и безопасен при повторном запуске. Не предназначен для генерации карты обзора — это делает review‑map — а сама настройка ничего не публикует в GitHub.
