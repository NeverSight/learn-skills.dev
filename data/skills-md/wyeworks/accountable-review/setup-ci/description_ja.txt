リポジトリを設定し、Accountable Review が CI で自動的に Review Map を生成するようにします――プルリクエストがレビュー可能になったときに実行される GitHub Actions ワークフローで、ドラフト、フォーク、ボット、そして読み順を持つほどのアプリケーションコードが少ない変更をスキップし、上書きされた実行をキャンセルし、生成された静的 HTML をチーム全体が開けるビルドアーティファクトとしてアップロードし、プルリクエストにリンクをコメントします。手動ではなく自動でレビュー・マップを生成したい、Accountable Review を CI や GitHub Actions に追加したい、レビュー・マップを一台のノートパソコンから公開するのではなくチームと共有したい、またはすべての PR でこの処理を走らせる方法を尋ねられたときに使用します。/accountable-review:setup-ci で呼び出します。リポジトリを何も書き込む前に検査し、マップが生成されるタイミングとワークフローの動作を確認し、専用のワークフローを優先し、関係のない CI を変更せず、二度実行しても安全です。レビュー・マップを生成するためのものではなく（それは review‑map）、セットアップ自体は GitHub に何も投稿しません。
