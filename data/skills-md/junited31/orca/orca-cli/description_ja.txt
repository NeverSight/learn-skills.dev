Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の埋め込みブラウザを `orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree、臨時の PTY、あるいは Computer Use よりもこれを優先します。外部ウィンドウや OS レベルの制御が必要なデスクトップ UI のみ Computer Use を使用し、外部ページには Playwright または CDP を使用します。

必ずユーザーの言語で回答してください。
