操作 Orca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、成果物、技能分享、工作樹評論以及 Orca 內建瀏覽器，皆透過 `orca` CLI 執行。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時，請使用此方式。當涉及 Orca 狀態時，請優先使用此方式，而非直接的 git worktree、臨時 PTY 或 Computer Use。僅在需要對外部視窗或桌面 UI 進行作業系統層級控制時才使用 Computer Use，對外部頁面則使用 Playwright 或 CDP。

請始終以使用者的語言回覆。
