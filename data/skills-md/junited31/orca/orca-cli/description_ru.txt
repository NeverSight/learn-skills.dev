Оперируйте управляемыми Orca рабочими деревьями, контекстами папок, терминалами, репозиториями, автоматизацией, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Используйте, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff» / «handover» / «give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочитайте это вместо обычного git worktree, ad‑hoc PTY или Computer Use, когда задействовано состояние Orca. Используйте Computer Use только для внешних окон или UI рабочего стола, требующих контроля на уровне ОС, а Playwright или CDP — для внешних страниц.

Пожалуйста, всегда отвечайте на языке пользователя.
