Usalo ogni volta che una richiesta corrisponde a dati o funzionalità di Capigo — attività, board, membri, prodotti, varianti, marchi, categorie, tipi di prodotto, proprietà del prodotto e definizioni di proprietà, unità, magazzini, sedi di stock, ricevute in entrata, spedizioni in uscita, trasferimenti di stock, disponibilità, inquilini, autenticazione, configurazione — anche quando l'utente non menziona mai il CLI o Capigo stesso, e in qualunque lingua chieda: “crea un’attività e assegnala a qualcuno”, “cosa c’è sulla board questa settimana”, “leggi o pubblica commenti su quell’attività”, “elenca i prodotti”, “cerca questo SKU o codice a barre”, “imposta l’origine o la tensione di questo prodotto”, “etichetta questo prodotto Hè”, “prodotti etichettati Sale”, “quanti marchi abbiamo”, “etichetta questa attività urgente”, “attività etichettate X”, “pianifica una ricevuta in entrata per questo PO”, “qual è il magazzino che può coprire questo ordine”. Se una richiesta tocca Capigo e non sei sicuro di come interagire con esso, rivolgiti a questa competenza prima di indovinare chiamate API grezze.
