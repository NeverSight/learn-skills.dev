Работайте с платформой Capigo через установленный CLI `capigo` — точку входа для любой работы агента с арендатором в Capigo. Используйте его всякий раз, когда запрос относится к данным или возможностям Capigo — задачи, доски, участники, товары, варианты, бренды, категории, типы товаров, свойства товаров и определения свойств, единицы измерения, склады, места хранения, входящие поступления, исходящие отгрузки, перемещения запасов, доступность, арендаторы, аутентификация, конфигурация — даже если пользователь никогда не упоминает CLI или Capigo, и на любом языке, которым он задаёт вопрос: «создать задачу и назначить её кому‑то», «что на доске на этой неделе», «прочитать или оставить комментарий к задаче», «список товаров», «поиск по артикулу или штрихкоду», «установить происхождение или напряжение товара», «отметить товар как Hè», «товары с тегом Sale», «сколько у нас брендов», «отметить эту задачу как срочную», «задачи с меткой X», «планировать входящее поступление для этого заказа», «какой склад может покрыть этот заказ». Также это ссылка на то, как работает сам CLI: обнаружение установки, вход в систему, выбор арендатора, коды завершения, вывод в JSON и само‑диагностика некорректных команд. Если запрос касается Capigo и вы не уверены, как с ней взаимодействовать, сначала используйте это умение, а не пытайтесь угадывать прямые API‑вызовы.
