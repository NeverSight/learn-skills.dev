Conduce la plataforma Capigo a través del CLI `capigo` instalado — el punto de entrada para cualquier trabajo de Capigo que un agente realice para un inquilino. Utiliza esto siempre que una solicitud se relacione con datos o capacidades de Capigo — tareas, tableros, miembros, productos, variantes, marcas, categorías, tipos de producto, propiedades de producto y definiciones de propiedades, unidades, almacenes, ubicaciones de stock, recibos de entrada, envíos de salida, transferencias de stock, disponibilidad, inquilinos, autenticación, configuración — incluso cuando el usuario nunca menciona el CLI o Capigo directamente, y en cualquier idioma que lo solicite: "crear una tarea y asignarla a alguien", "qué hay en el tablero esta semana", "leer o publicar comentarios en esa tarea", "listar productos", "buscar este SKU o código de barras", "establecer el origen o voltaje de este producto", "etiquetar este producto Hè", "productos etiquetados Venta", "cuántas marcas tenemos", "etiquetar esta tarea como urgente", "tareas etiquetadas X", "planificar un recibo de entrada para esta orden de compra", "qué almacén puede cubrir este pedido". También sirve como referencia de cómo funciona el propio CLI: detección de la instalación, inicio de sesión, selección de inquilino, códigos de salida, salida JSON y autordiagnóstico de un comando que no funciona correctamente. Si una solicitud toca Capigo y no estás seguro de cómo comunicarte con él, recurre a esta habilidad primero en lugar de adivinar llamadas API sin procesar.
