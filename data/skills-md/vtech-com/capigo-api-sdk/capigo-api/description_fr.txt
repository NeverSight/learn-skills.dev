Piloter la plateforme Capigo via le CLI `capigo` installé — le point d'entrée pour tout travail Capigo qu'un agent effectue pour un locataire. Utilisez-le chaque fois qu’une requête correspond aux données ou aux capacités de Capigo — tâches, tableaux, membres, produits, variantes, marques, catégories, types de produit, propriétés de produit et définitions de propriétés, unités, entrepôts, emplacements de stock, réceptions entrantes, expéditions sortantes, transferts de stock, disponibilité, locataires, authentification, configuration — même lorsque l’utilisateur ne cite jamais le CLI ou Capigo lui‑même, et quel que soit le langage qu’il utilise : « créer une tâche et l’assigner à quelqu’un », « quoi sur le tableau cette semaine », « lire ou publier des commentaires sur cette tâche », « lister les produits », « chercher ce SKU ou ce code‑à‑barres », « définir l’origine ou la tension de ce produit », « taguer ce produit Hè », « produits tagués Vente », « combien de marques avons‑nous », « taguer cette tâche urgent », « tâches étiquetées X », « planifier une réception entrante pour ce bon de commande », « quel entrepôt peut couvrir cette commande ». Aussi la référence sur le fonctionnement du CLI lui‑même : détection de l’installation, connexion, sélection d’un locataire, codes de sortie, sortie JSON et auto‑diagnostic d’une commande défaillante. Si une requête touche Capigo et que vous n’êtes pas sûr de la façon de communiquer avec elle, utilisez d’abord cette compétence plutôt que de deviner des appels d’API bruts.

Veuillez toujours répondre dans la langue de l’utilisateur.
