`capigo` CLI を通じて Capigo プラットフォームを操作します――テナント向けにエージェントが行うすべての Capigo 作業のエントリーポイントです。リクエストが Capigo のデータや機能（タスク、ボード、メンバー、製品、バリアント、ブランド、カテゴリ、製品タイプ、製品プロパティとプロパティ定義、単位、倉庫、在庫ロケーション、入荷受領、出荷、在庫移動、在庫可用性、テナント、認証、設定）に対応する場合は必ずこれを使用してください。たとえユーザーが CLI や Capigo の名前を挙げなくても、どんな言語で質問しても構いません。「タスクを作成して誰かに割り当てて」「今週のボードは何がある？」「そのタスクのコメントを読んだり投稿したりしたい」「製品を一覧表示して」「この SKU やバーコードを検索して」「この製品の原産地や電圧を設定して」「この製品に Hè タグを付けて」「Sale タグが付いた製品」「ブランドは何件あるか」「このタスクに緊急タグを付けて」「X ラベルのタスク」「この PO の入荷受領を計画して」「どの倉庫がこの注文に対応できるか」といった要望にも対応します。また、CLI の動作参考として、インストールの検出、ログイン、テナントの選択、終了コード、JSON 出力、そして不調コマンドの自己診断方法も含まれます。リクエストが Capigo に関わる場合で、どのように呼び出すべきか不明なときは、生の API 呼び出しを推測するのではなく、まずこのスキルを利用してください。
