透過已安裝的 `capigo` CLI 驅動 Capigo 平台——這是代理人在租戶上執行任何 Capigo 工作的入口點。每當請求對應到 Capigo 的資料或功能時，都使用它──任務、看板、成員、產品、變體、品牌、類別、產品類型、產品屬性與屬性定義、單位、倉庫、庫存位置、入庫收貨、出庫發貨、庫存轉移、可用性、租戶、身份驗證、設定──即使使用者從未提及 CLI 或 Capigo 本身，且以任何語言提出需求，例如：「建立一個任務並指派給某人」、「本週看板上有什麼」、「讀取或發表該任務的評論」、「列出產品」、「查詢此 SKU 或條碼」、「設定此產品的產地或電壓」、「標記此產品 Hè」、「標記為 Sale 的產品」、「我們有多少個品牌」、「將此任務標記為緊急」、「標記為 X 的任務」、「為此採購單規劃入庫收貨」、「哪個倉庫可以覆蓋此訂單」。同時也作為 CLI 本身運作的參考：偵測安裝、登入、選擇租戶、退出代碼、JSON 輸出，以及自行診斷異常指令。如果請求涉及 Capigo，而你不確定如何與之溝通，請先使用此技能，而不是猜測原始 API 呼叫。
