Steuere die Capigo-Plattform über das installierte `capigo`‑CLI – den Einstiegspunkt für jede Capigo‑Arbeit, die ein Agent für einen Mandanten ausführt. Verwende es immer dann, wenn eine Anfrage auf Capigo‑Daten oder -Funktionen abzielt – Aufgaben, Boards, Mitglieder, Produkte, Varianten, Marken, Kategorien, Produkttypen, Produkteigenschaften und Eigenschaftsdefinitionen, Einheiten, Lagerhäuser, Bestandsorte, Eingangsbelege, Ausgangslieferungen, Bestandsumbuchungen, Verfügbarkeit, Mandanten, Authentifizierung, Konfiguration – selbst wenn der Nutzer das CLI oder Capigo nicht namentlich erwähnt, und in jeder Sprache, in der er fragt: „erstelle eine Aufgabe und weise sie jemandem zu“, „was steht diese Woche auf dem Board“, „lies oder poste Kommentare zu dieser Aufgabe“, „liste Produkte auf“, „suche diese SKU oder den Barcode“, „setze den Ursprung oder die Spannung dieses Produkts“, „tagge dieses Produkt Hè“, „Produkte getaggt Sale“, „wie viele Marken haben wir“, „tagge diese Aufgabe dringend“, „Aufgaben mit dem Label X“, „plane einen Eingangsbeleg für diese Bestellung“, „welches Lager kann diese Bestellung abdecken“. Außerdem die Referenz dafür, wie das CLI selbst funktioniert: Erkennen der Installation, Anmelden, Auswahl eines Mandanten, Exit‑Codes, JSON‑Ausgabe und Selbstdiagnose bei fehlerhaften Befehlen. Wenn eine Anfrage Capigo berührt und du dir unsicher bist, wie du damit kommunizieren sollst, greife zuerst auf diese Fähigkeit zurück, anstatt rohe API‑Aufrufe zu raten.
