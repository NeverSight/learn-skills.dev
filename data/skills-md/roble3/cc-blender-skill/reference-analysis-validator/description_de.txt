Messen und validieren Sie die bereitgestellten Referenzbilder, Wireframes, Texturatlanten und Blender-Renderings, bevor Sie eine Rekonstruktion als 1:1 deklarieren. Verwenden Sie diese Option, wenn ein Asset mit einer Vorlage übereinstimmen muss, wenn das visuelle Feedback darauf hinweist, dass das Ergebnis nicht stimmt, wenn die Anzahl der Teile genau sein muss oder bevor Sie eine Rekonstruktion eines Markenmaskottchens/Logos exportieren. Kann mit Reference-to-3D, Contour-to-Mesh, Orthographic-Registration, Atlas-UV-Fitting und Blender MCP kombiniert werden.
