Usa quando l'utente richiede documentazione dell'architettura, diagrammi C4, i flussi principali delle richieste di un codebase come diagrammi di sequenza, una panoramica di deployment, API o configurazione, un grafo o diagramma delle dipendenze, o una spiegazione di come i progetti, i pacchetti o i moduli di un repository si integrano. Funziona su percorsi di repository locali (.NET, Java/Kotlin, Go, Node.js/TypeScript, Python). Non è adatto per una domanda rapida su un singolo file o import, per modificare codice, o per diagrammi non correlati a un codebase.

Rispondi sempre nella lingua dell'utente.
