Utilisez cela lorsque l'utilisateur demande une documentation d'architecture, des diagrammes C4, les flux de requêtes clés d’une base de code sous forme de diagrammes de séquence, un aperçu du déploiement, de l’API ou de la configuration, un graphe ou diagramme de dépendances, ou une explication de la façon dont les projets, packages ou modules d’un référentiel s’articulent. Fonctionne sur les chemins de référentiel local (.NET, Java/Kotlin, Go, Node.js/TypeScript, Python). Pas pour une question rapide sur un seul fichier ou import, pour modifier du code, ou pour des diagrammes sans rapport avec une base de code.

Veuillez toujours répondre dans la langue de l'utilisateur.
