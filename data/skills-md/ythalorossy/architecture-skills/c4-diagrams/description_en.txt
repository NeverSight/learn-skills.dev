Use when the user asks for architecture documentation, C4 diagrams, the key request flows of a codebase as sequence diagrams, a deployment, API or configuration overview, a dependency graph or diagram, or an explanation of how a repository's projects, packages or modules fit together. Works on local repository paths (.NET, Java/Kotlin, Go, Node.js/TypeScript, Python). Not for a quick question about one file or import, for changing code, or for diagrams unrelated to a codebase.
