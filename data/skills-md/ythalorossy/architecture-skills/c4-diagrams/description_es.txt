Úselo cuando el usuario solicite documentación de arquitectura, diagramas C4, los flujos clave de solicitudes de un código como diagramas de secuencia, una visión general de despliegue, API o configuración, un grafo o diagrama de dependencias, o una explicación de cómo encajan los proyectos, paquetes o módulos de un repositorio. Funciona con rutas de repositorios locales (.NET, Java/Kotlin, Go, Node.js/TypeScript, Python). No es para una pregunta rápida sobre un solo archivo o importación, para cambiar código, o para diagramas no relacionados con un codebase.

Por favor, responda siempre en el idioma del usuario.
