Usar cuando el usuario solicita una revisión crítica de la arquitectura de un repositorio — donde el diseño es arriesgado o frágil, qué corregir primero, acoplamientos ocultos, seguridad, supuestos de datos y despliegue, o donde los documentos y el código no coinciden. Se basa en la salida de c4-diagrams. No es para generar diagramas o documentación de arquitectura (use c4-diagrams), una pregunta rápida sobre un archivo, revisar un diff o pull request, o cambiar código.
