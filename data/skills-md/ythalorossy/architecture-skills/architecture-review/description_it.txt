Usa quando l'utente richiede una revisione critica dell'architettura di un repository — dove il design è rischioso o fragile, cosa sistemare per primo, accoppiamenti nascosti, sicurezza, ipotesi su dati e deployment, o dove i documenti e il codice non sono d'accordo. Si basa sull'output di c4-diagrams. Non è per generare diagrammi o documentazione architetturale (usa c4-diagrams), per una domanda rapida su un singolo file, per revisionare un diff o una pull request, o per modificare il codice.

Rispondi sempre nella lingua dell'utente.
