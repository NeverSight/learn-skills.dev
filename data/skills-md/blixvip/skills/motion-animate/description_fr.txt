Le vocabulaire de mouvement qui sépare l'animation premium du slop AI — texte pop-blur-fade, décalages séquentiels, caméras assouplies toujours en mouvement, entrées d'objets et tables de chronométrage/d'assouplissement derrière elles. Inclut le code Ready pour Remotion (interpolé/Spring) et HyperFrames (GSAP). À utiliser lors de l'animation d'images conçues, lorsque le mouvement « se sent raide », « rebondissant », « nerveux », « trop rapide », « trop uniforme », ou lors de l'écriture de tout code de synchronisation/d'assouplissement pour la vidéo.
