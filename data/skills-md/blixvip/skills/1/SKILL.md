# /1 — Quick

Complete the task as quickly as possible while preserving the normal quality bar.

## Timebox

Target completion in under 3 minutes. This command changes execution strategy, not expected quality.

## Behavior

- Start immediately.
- Use the simplest correct solution.
- Do not over-plan or over-explain.
- Avoid unnecessary exploration, refactors, research, or optional improvements.
- Make reasonable assumptions when low-risk.
- Prefer editing directly over discussing intended edits.
- Test the exact behavior changed.
- Fix obvious issues discovered during testing.
- Do not expand the task beyond the request.

If several valid approaches exist, choose the strongest straightforward option and execute it. Finish with a very short summary of what changed and whether verification passed.
