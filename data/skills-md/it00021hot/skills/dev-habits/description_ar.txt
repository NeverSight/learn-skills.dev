اكتب الشفرة، عدّل الشفرة، راجعها، أعد هيكلتها، ناقش الحلول، تحقق وسلم — الدستور الهندسي العابر للمشروعات الذي يجب قراءته قبل كل عملية Git commit، كما أنه يحكم التعاون بين البشر والوكالات؛ مهارة مستوى المشروع هي ملحق، ليست بديلاً، ويجب قراءة كليهما. عند تعريف أو تعديل واجهة برمجة التطبيقات أو عقد IPC، أو التعامل مع حدود التسلسل، أو كتابة السجلات، أو استكشاف الأخطاء، أو إنشاء الجداول وإجراء ترحيلات قواعد البيانات، أو التعامل مع الأمن والمفاتيح، أو كتابة الاختبارات، أو تحسين الأداء أو التزامن، أو كتابة أو تعديل الدوال غير البسيطة، أو اتخاذ قرار بشأن ملكية النوع والوحدة، يجب أولاً قراءة المراجع المحددة في قائمة التحكم بالوصول. يحدد طرق العمل، جودة الشفرة، الأمن، الاختبار، البيانات، استكشاف أخطاء السجلات، وطرق التواصل، دون فرض مجموعة التكنولوجيا؛ تُحل النزاعات وفقاً لهرمية التحكيم — الاتفاقيات الخاصة بالمشروع دائماً لها الأولوية، ولا يمكن تجاوز الأمن والامتثال.
