أعد مسودة أو راجع أو دقق النصوص الموجهة للبشر لإزالة الأنماط الواضحة للكتابة بالذكاء الاصطناعي مع الحفاظ على المعنى والصوت. استخدم ذلك عندما يستدعي المستخدم صراحةً النص الأدبي أو يطلب فحص الكتابة لاكتشاف إشارات الذكاء الاصطناعي مثل الشرطات الطويلة، نقاط التحول المتباينة، القوائم الثلاثية المفروضة، الكليشيهات المجردة، التشويق الزائف، التشبيهات المتعالية، عبارات الربط المتكبرة، الدفء العام، أو الخاتمات الضخمة.

يرجى دائمًا الرد بلغة المستخدم.
