Rédiger, réviser ou auditer des textes destinés aux humains afin d’éliminer les tropes d’écriture d’IA évidents tout en préservant le sens et la voix. À utiliser lorsque l’utilisateur invoque explicitement la prose ou demande de vérifier le texte pour des indices d’IA tels que les tirets cadratins, les pivots contrastifs, les listes forcées de trois éléments, les clichés abstraits, le faux suspense, les analogies condescendantes, les phrases de liaison pompeuses, la chaleur générique ou les conclusions grandioses.

Veuillez toujours répondre dans la langue de l’utilisateur.
