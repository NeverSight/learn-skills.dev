قم بدمج أو بناء أو توسيع أو مراجعة واجهات الويب باستخدام لغة تصميم ak-ui المتكيفة مع العلامة التجارية وأسستها CSS. استخدم ذلك عندما يطلب المستخدم تثبيت ak-ui، أو إنشاء واجهة مستوحاة من لعبة Arknights دون نسخ أي أصول اللعبة، أو تنسيق المكونات الأصلية أو المكونات غير المصممة مثل Reka UI، أو تحويل صفحة موجودة إلى ak-ui، أو تدقيق ما إذا كان التنفيذ يتبع رموز ak-ui، والهندسة، وحالات التفاعل، والاستجابة، وإمكانية الوصول.
