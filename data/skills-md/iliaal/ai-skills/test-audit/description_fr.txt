Auditez si les tests détectent les régressions dans le comportement qu’ils prétendent protéger. Trouvez les sujets moqués, les assertions faibles ou circulaires, les fixtures non discriminantes, les échecs avalés et les tests manquants dans les portes. Utilisez-le pour les audits de qualité des tests, les soupçons de fausse confiance dans les tests générés et la révision des nouveaux tests. Utilisez ia‑writing‑tests pour écrire les tests.
