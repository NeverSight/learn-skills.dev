Générez une source de livre TRNovel (trnovel-booksource/v2 JSON) à partir de l'URL d'un nouveau site Web. Utilisez cette option lorsqu'un utilisateur fournit un site de roman/lecture et souhaite l'intégrer à TRNovel, créer une source de livre, adapter une source de livre ou effectuer une ingénierie inverse du catalogue/du contenu d'un site, par exemple, « créer une source de livre pour ce site https://… », « générer une source de livre pour X », « connecter ce site Web de roman à trnovel », « m'aider à analyser les chapitres/recherches de ce site », même s'il ne dit pas explicitement « source de livre ». Cette compétence détectera le site réel, procédera à l'ingénierie inverse des sélecteurs CSS/JSONPath pour la recherche, la navigation, les détails du livre, le catalogue (y compris les volumes) et le contenu, gérera les jeux de caractères et l'anti-scraping Cloudflare, produira le JSON et utilisera « trn doctor » pour la validation complète du processus, en itérant avec ✓/✗ jusqu'à ce qu'il réussisse.
