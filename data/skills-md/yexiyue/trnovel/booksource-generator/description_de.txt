Generieren Sie eine TRNovel-Buchquelle (trnovel-booksource/v2 JSON) aus einer Roman-Website-URL. Verwenden Sie dies, wenn ein Benutzer eine Roman-/Leseseite bereitstellt und diese in TRNovel integrieren, eine Buchquelle erstellen, eine Buchquelle anpassen oder den Katalog/Inhalt einer Seite zurückentwickeln möchte – z. B. „Erstelle eine Buchquelle für diese Seite https://…“, „generiere eine Buchquelle für Dieser Skill erkennt die reale Site, entwickelt die CSS/JSONPath-Selektoren für Suche, Browsing, Buchdetails, Katalog (einschließlich Bände) und Inhalt zurück, verarbeitet Zeichensätze und Cloudflare-Anti-Scraping, schreibt den JSON und validiert ihn dann vollständig mit „trn doctor“, wobei er mit ✓/✗ iteriert, bis er erfolgreich ist.
