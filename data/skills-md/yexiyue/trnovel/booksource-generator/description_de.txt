Generieren Sie eine TRNovel-Buchquelle (trnovel-booksource/v2 JSON) aus einer Novel-Website-URL. Verwenden Sie dies, wenn ein Benutzer eine Roman-/Leseseite bereitstellt und diese in TRNovel integrieren, eine Buchquelle erstellen, eine Buchquelle anpassen oder den Katalog/Inhalt einer Seite zurückentwickeln möchte – zum Beispiel „Erstellen Sie eine Buchquelle für diese Seite https://…“, „generieren Sie eine Buchquelle für Dieser Skill erkennt die tatsächliche Site, entwickelt die CSS/JSONPath-Selektoren für Suche, Browsing, Buchdetails, Katalog (einschließlich Bände) und Inhalt zurück, verarbeitet Zeichensätze und Cloudflare-Anti-Scraping, erstellt den JSON und verwendet „trn doctor“ für die vollständige Prozessvalidierung, wobei er mit ✓/✗ iteriert, bis er erfolgreich ist.
