Genere una fuente de libro TRNovel (trnovel‑booksource/v2 JSON) a partir de la URL de un sitio web novedoso. Utilice esto cuando un usuario proporciona un sitio de novela/lectura y desea integrarlo con TRNovel, crear una fuente de libro, adaptar una fuente de libro o aplicar ingeniería inversa al catálogo/contenido de un sitio; por ejemplo, "crear una fuente de libro para este sitio https://...", "generar una fuente de libro para X", "conectar este sitio de novela a trnovel", "ayúdame a analizar los capítulos/búsqueda de este sitio", incluso si no dicen explícitamente "fuente de libro". Esta habilidad detecta el sitio real, aplica ingeniería inversa a los selectores CSS/JSONPath para búsqueda, navegación, detalles del libro, catálogo (incluidos los volúmenes) y contenido, maneja conjuntos de caracteres y anti-scraping de Cloudflare, escribe el JSON y usa `trn doctor` para la validación del proceso completo, iterando con ✓/✗ hasta que pasa.
