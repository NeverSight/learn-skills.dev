Создайте исходный код книги TRNovel (trnovel-booksource/v2 JSON) на основе URL-адреса нового веб-сайта. Используйте это, когда пользователь предоставляет сайт романа/чтения и хочет интегрировать его с TRNovel, создать источник книги, адаптировать источник книги или провести реверс-инжиниринг каталога/контента сайта — например, «создать источник книги для этого сайта https://…», «создать источник книги для X», «подключить этот сайт романа к trnovel», «помогите мне проанализировать главы/поиск этого сайта», даже если они явно не говорят «источник книги». Этот навык позволит обнаружить реальный сайт, выполнить реверс-инжиниринг селекторов CSS/JSONPath для поиска, просмотра, сведений о книге, каталога (включая тома) и контента, обрабатывать наборы символов и защиту Cloudflare, создавать JSON и использовать trn Doctor для полной проверки процесса, повторяя с помощью ✓/✗, пока он не пройдет.
