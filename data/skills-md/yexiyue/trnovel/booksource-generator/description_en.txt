Generate a TRNovel book source (trnovel-booksource/v2 JSON) from a novel website URL. Use this when a user provides a novel/reading site and wants to integrate it with TRNovel, create a book source, adapt a book source, or reverse‑engineer a site’s catalog/content—for example, “make a book source for this site https://…”, “generate a book source for X”, “connect this novel website to trnovel”, “help me parse this site’s chapters/search”, even if they don’t explicitly say “book source”. This skill will detect the actual site, reverse‑engineer the CSS/JSONPath selectors for search, browsing, book details, catalog (including volumes), and content, handle character sets and Cloudflare anti‑scraping, produce the JSON, and use `trn doctor` for full‑process validation, iterating with ✓/✗ until it passes.
