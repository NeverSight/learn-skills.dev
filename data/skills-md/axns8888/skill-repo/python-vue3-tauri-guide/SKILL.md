# Python + Vue 3 + Tauri 开发流程指南

将用户目标转成可执行计划、真实实现和可追溯证据。面向已有仓库的增量开发，也支持新项目启动。默认用中文输出，跟随用户指定语言。

使用与分享见 [快速上手](README.md)；需要完整阶段指令时查看 [开发流程提示词集](references/prompt-kit.md)。

## 入口判断

1. 先确认本次是“整理流程/生成提示词”“只做方案”“执行开发”“自动复核”“人工通过后结案”还是“构建发布”。只产出提示词的请求不触发安装、业务修改或打包。
2. 阅读目标项目 `AGENTS.md`、现行开发基线、任务记录、依赖清单/锁文件及相关源码。已有规范优先复用；本 skill 的目录和命令仅作可配置范例。
3. 已有任务先恢复范围、授权、计划版本、实际 diff 和仍有效的证据。用户已有执行授权时继续推进，不为普通实现选择或阶段切换重复索要同一授权。
4. 只做用户交付的阶段；用户要求贯穿时连续推进至该范围完成。明确要求独立交接时保留角色边界，不自行创建代理、选择工具型号或宣称已完成用户验收。

## 核心约束

- **三端职责明确**：Python 承担领域业务、校验、持久化和任务；Vue 承担交互与类型化调用；Tauri 承担桌面窗口、本机能力及 Sidecar 生命周期。避免在 Rust 或前端复制领域业务。
- **批量写必须一次提交服务端**：前端一次提交稳定主键集合和操作参数；禁止循环、并发池、`Promise.all` 或分片调用单项写接口。接口缺失时实现服务端批量入口。上限超出时明确拒绝或使用服务端批量任务，不能客户端分片降级。
- **跨端配置只有一个所有者**：端口、服务地址、目录、应用版本和 Sidecar 参数从明确事实源派生；不手工改生成配置，不用默认值覆盖消费者已保存设置。
- **依赖与协议按项目事实确定**：先核对锁文件、真实导出、接口和脚本，再写代码或执行命令。不要从来源项目复制固定版本、端口、HTTP 方法、时间格式、凭据策略或兼容政策。
- **实现与验证闭合**：成功标准逐项关联证据；跨越最易断裂的真实内部边界，不能 mock 掉被修复的内部接线后宣称整链通过。
- **保护已有工作**：记录任务开始时未提交改动；只改当前范围，不借机清理、全仓格式化或回滚无关内容。
- **真实状态分别记录**：已实现、自检/自动复核结果、可否交验、用户确认和结案不是同一个状态。未执行项写未执行。
- **相称验证**：日常开发做相关测试、类型和受改范围静态检查；纯文档只查文档。生产构建、Nuitka/Tauri 打包放在用户要求的构建或发布任务内。

## 执行步骤

### 1. 建立项目与任务上下文

已有项目复用当前文档与目录；新项目从项目基线模板提炼必要内容。核实以下信息，缺失项区分可查事实、可先采用的明确假设和真正阻断的决策：

- 产品目标、成功标准、非目标、当前阶段与工作区基线。
- 目标平台及 CPU 架构，Python 环境、Vue 工具链、Tauri/Rust 版本及锁文件。
- 后端框架、数据库、通信方式、数据目录、运行配置、开发与发布入口。
- 现有公共组件、领域模块、接口契约、测试方式和用户验收安排。

### 2. 规划与实施

用用户可观察结果建立 R 编号，画清入口 → 状态 → 调用 → 持久化/任务 → 回读展示；按工作流形成唯一实施计划与适度复杂度评估。实现按契约和依赖顺序推进，不把新建项目误读为必须一次实现所有基础设施。

涉及批量操作必读批量契约；涉及页面必读前端约束；涉及启动、配置或桌面能力必读跨端架构；涉及迁移或发行必读数据库与发布。

### 3. 验证与交接

保存真实命令、退出码、业务断言、受测源码/配置身份与隔离边界。修复本轮新增问题和阻断目标的旧问题；复用仍有效的证据。交付实现范围、已做/待做验证、未关闭项、当前状态和必要的接续提示词。

独立复核只判断已有实现及证据，发现核心缺陷交回开发；用户明确要求复核并修复时，可分别记录这两个阶段并完成授权范围。

### 4. 人工验收与结案

用户明确确认的日期、版本和范围才构成人工通过。明确通过可覆盖对应范围待执行的自动复核，但保留真实历史，不将未执行改成自动通过；部分通过只结算对应范围。

按目标项目规则更新现行基线、演进、验收归档和任务索引；仅在存在受管迁移流程时执行已授权的迁移验收合并。冻结、发布、删除过程目录或清理现场按目标项目要求处理，不从本 skill 推导额外授权。

## 提示词交付

所有供用户复制执行的指令各用一个独立的 `text` 围栏代码块。提供完整指令，并替换已知的任务号、路径和计划版本；只有尚未提供的输入保留 `〈变量〉`。说明、链接和状态放在代码块外。需要通用流程时使用提示词集；需要项目专属提示词时先填项目基线和任务上下文，再裁剪到本次授权范围。
