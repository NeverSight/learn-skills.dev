# Make App 审批生成与发起侧适配

把已确认的功能方案转为审批导航决策，并让业务表单随运行时配置启用审批新建和状态展示。每个应用只保留一个“我的审批”；业务对象仍使用自己的记录列表。

## 工作顺序

1. 从已确认的方案提取业务对象、用户实际写入动作及审批处理能力，读取 [默认生成规则](references/generation-rules.md)。先给出生成或不生成的业务依据，不能只搜“表单”“提交”等词。方案未说明是否存在写入/审批能力时，只确认这一缺失事实，不擅自补功能。
2. 调研宿主导航与路由、Schema 适配、普通新建和详情、字段渲染器、请求层、记录创建/附件/Lookup 链路及测试。说明拟改文件、复用点和验证方案；保留现有业务列表、布局和分层。
3. 方案触发生成且含业务新建能力时，即使当前尚无流程绑定，也读取 [发起侧合同](references/initiation-contract.md) 并生成运行时双分支；具备业务列表/详情时读取 [流程状态展示](references/status-display.md)。单项接入按对应合同处理。先区分“生成适配能力”和“当前对象允许首次发起”，不能因生成时没有 key 就省略适配代码。仅审批处理、没有新建页的方案不新增业务新建功能。
4. 在现有 UI → Service → Make 调用链中接入。审批配置和保存编排放在 Hook/Service，字段集合与状态转换保持纯逻辑；桌面和手机共享业务逻辑、分别复用已有 View。
5. 按 [验证场景](references/verification.md) 先补失败测试，再最小实现；核对普通新建回归与审批字段授权在 UI/Service 一致。报告实际执行的检查和未验证项，不把文档检查当作真实审批联调。

## 必须保持的边界

- **导航是方案决策。** 业务新增、录入、编辑保存，或明确审批处理需求即可触发；不要求先绑定流程。无任务、全部流程停用或解绑后仍保留已生成入口及历史访问路径。
- **新建是运行时决策。** 成功取得的 Schema 对象含有效 `bpmDefinitionKey` 才进入审批新建分支。配置读取失败是错误态，不能等同未绑定。
- **审批新建字段独立授权。** 使用 `bpm-start-config.fields` 的完整字段元数据和 `readable/editable`，不再与普通 IAM 字段集合或 `createFields` 求交。应用、对象、新建操作、关联目标和后台最终授权仍保留。
- **保存与首次发起分开。** 普通保存不发起；用户选择保存并发起时先取得已保存记录 ID，再首次发起。失败恢复不得重复创建或上传，配置变化不得自动提交历史记录。
- **状态来自记录。** `qfei_process_instance_status` 是只读系统字段；不新建同名 DSL 业务字段，不用业务状态、任务结果、锁字段或当前绑定推导流程状态。
- **已有记录编辑保留既有合同。** 不把新建发起字段权限扩展到普通编辑；审批中、退回运行态或明确锁定的记录不得通过普通编辑、快捷编辑或批量入口绕过锁。终态编辑政策沿用宿主已确认合同，本 skill 不另行改写。

## 与现有 Skill 配合

| 落点 | 责任 |
| --- | --- |
| [makeui](../makeui/SKILL.md) | Shell、导航位置、Drawer/手机任务页、现有字段控件及 Tag 外观；本 skill 决定审批分支和字段来源 |
| [make-app-permission](../make-app-permission/SKILL.md) | 普通 IAM、应用/对象/操作权限；本 skill 定义审批新建字段分支，不替换普通权限算法 |
| [make-app-service](../make-app-service/SKILL.md) | API 合同、适配、缓存隔离、错误和取消；本 skill 提供 Workflow 发起参数与失败语义 |
| [make-app-actions](../make-app-actions/SKILL.md) | 普通记录操作入口、预检及批量能力；消费同一锁判断，不复制审批任务动作 |
| [canvas-table-integration](../canvas-table-integration/SKILL.md) | 桌面列表的只读系统列；手机沿用卡片，不为状态展示新增表格 |
| [makedsl](../makedsl/SKILL.md) | 业务对象建模；不为流程状态或锁补业务字段，不生成流程定义 |

## 本期交付范围

交付导航生成决策及宿主入口、审批新建字段、保存/首次发起、业务列表和详情的流程状态字段、详情标题后的状态 Tag。

撤销/撤回按钮与接口、我的审批 npm 包安装升级、任务列表/办理详情、审批意见与动作、审批历史及流程图均不在本期。已有任务中心只接回现有路由；没有任务中心时按默认生成规则保留真实的能力边界，不复制一套页面或添加未经核验的 npm API。
