Apply when building, reviewing or publishing a Tiendanube / Nuvemshop app with a merchant-facing panel: integrated apps loaded in an Admin iframe through Nexo (connect, iAmReady, ACTION_NAVIGATE_SYNC, getSessionToken, ErrorBoundary) and built with the Nimbus design system, or external apps with their own panel. Covers the official Node and React templates, Developer Mode, design guidelines and UX writing, the homologation artifacts and design checklist, App Store publication data, private versus App Store distribution, and charging merchants with the billing model and the Billing API (plans, subscriptions, charges). Use for starting an Admin app, fixing an embedded app that never loads, preparing a homologation request, or wiring plan upgrades.
