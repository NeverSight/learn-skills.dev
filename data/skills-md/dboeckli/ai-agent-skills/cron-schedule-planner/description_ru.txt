Создаёт обзор cron‑выражений `schedule` в GitHub Actions по нескольким репозиториям и помогает распределить ресурсоёмкие задачи (Docker Compose, Testcontainers, Kind/k3s, matrix‑сборки) в менее загруженные слоты. Используется, когда пользователь задаёт вопросы типа «Когда запускаются мои cron‑действия?», «Пересекаются ли мои запланированные сборки?», «Когда следует выполнять сборку Testcontainers?», либо хочет получить обзор/отчёт о распределении cron‑расписаний по репозиториям. Сканирует через `gh` (без необходимости локальных чек‑аутов) или локальные чек‑ауты, конвертирует время из UTC в локальный часовой пояс, классифицирует интенсивность задач и пишет отчёт в Markdown с гистограммой по часам, конфликтами и конкретными рекомендациями по перераспределению cron‑расписаний.
