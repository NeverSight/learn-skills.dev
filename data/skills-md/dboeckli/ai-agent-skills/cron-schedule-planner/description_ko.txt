다중 리포지토리에서 GitHub Actions `schedule` 크론 표현식을 개요하고 CPU 집약적인 작업(Docker Compose, Testcontainers, Kind/k3s, 매트릭스 빌드)을 덜 경쟁이 치열한 슬롯으로 분산하도록 도와줍니다. 사용자는 “내 크론 액션은 언제 실행되나요?”, “내 예약 빌드가 충돌하나요?”, “Testcontainers 빌드는 언제 실행해야 하나요?”와 같이 질문하거나 리포지토리 전반에 걸친 크론 스케줄 개요·분배 보고서를 원할 때 사용합니다. `gh`를 통해(로컬 체크아웃 필요 없음) 또는 로컬 체크아웃으로 스캔하며, UTC를 로컬 시간대로 변환하고, 작업 강도를 분류한 뒤, 시간별 히스토그램, 충돌 및 구체적인 크론 재분배 제안을 포함한 마크다운 보고서를 작성합니다.
