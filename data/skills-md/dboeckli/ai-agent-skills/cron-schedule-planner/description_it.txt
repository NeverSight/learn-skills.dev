Costruisce una panoramica delle espressioni cron `schedule` di GitHub Actions su più repository e aiuta a distribuire i job ad alta intensità CPU (Docker Compose, Testcontainers, Kind/k3s, build matriciali) in slot meno contesi. Da utilizzare quando l'utente chiede “when do my cron actions run?”, “do my scheduled builds collide?”, “when should the Testcontainers build run?” o desidera una panoramica della programmazione cron/un report di distribuzione tra i repository. Scansiona tramite `gh` (non sono richiesti checkout locali) o checkout locali, converte l'UTC in un fuso orario locale, classifica l'intensità del job e genera un report Markdown con un istogramma orario, collisioni e suggerimenti concreti per la redistribuzione dei cron.
