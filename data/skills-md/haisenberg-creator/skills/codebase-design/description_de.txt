Gemeinsamer Wortschatz für die Gestaltung tiefgreifender Module. Verwenden, wenn der Nutzer das Interface eines Moduls entwerfen oder verbessern, Vertiefungsmöglichkeiten finden, entscheiden möchte, wo eine Naht liegt, den Code testbarer oder KI‑navigierbarer machen will oder wenn eine andere Fähigkeit den Deep‑Module‑Wortschatz benötigt.
