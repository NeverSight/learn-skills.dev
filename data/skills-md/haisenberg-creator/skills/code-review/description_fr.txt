Examinez les changements depuis un point fixe (commit, branche, tag ou base de fusion) selon deux axes : Normes (le code respecte‑t‑il les standards de codage documentés de ce dépôt ?) et Spécifications (le code correspond‑il à ce que la demande/specification d’origine exigeait ?). Exécute les deux revues en parallèle via des sous‑agents et les présente côte à côte. Utilisez‑le lorsque l’utilisateur veut examiner une branche, une PR, des modifications en cours ou demande « examiner depuis X ».
