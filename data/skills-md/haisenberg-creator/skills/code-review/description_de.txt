Überprüfe die Änderungen seit einem festen Punkt (Commit, Branch, Tag oder Merge‑Base) entlang zweier Achsen: Standards (entspricht der Code den in diesem Repository dokumentierten Kodierungsstandards?) und Spezifikation (entspricht der Code dem, was das zugrundeliegende Issue/Spec gefordert hat?). Führt beide Prüfungen in parallelen Sub‑Agents aus und stellt sie nebeneinander dar. Verwende dies, wenn der Nutzer einen Branch, einen PR, laufende Änderungen prüfen möchte oder „review since X“ verlangt.
