Настройте хуки Claude Code, чтобы блокировать опасные команды git (push, reset --hard, clean, branch -D и т.д.) до их выполнения. Используйте, когда пользователь хочет предотвратить разрушительные операции git, добавить хуки безопасности git или заблокировать git push/reset в Claude Code.
