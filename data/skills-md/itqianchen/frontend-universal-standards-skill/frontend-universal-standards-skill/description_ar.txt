مواصفات التطوير والهندسة الحديثة للواجهة الأمامية وتوصيلها ككامل‑المكدس. تُطبق على بنية المشروع، تطوير منطق الصفحات والمكوّنات، تغليف احترافي لطلبات الشبكة (Axios/uni.request)، توجيه أذونات ديناميكي بناءً على RBAC، إدارة الحالة والاستمرارية عبر المنصات لـ Vue 3 (Composition API/Vite/Pinia)، React 18/19 (Hooks/Zustand/RTK/Tailwind CSS)، Uni‑app/WeChat Mini‑Program عبر المنصات، ومشروعات Vue 2 القديمة؛ تشمل تقطيع الملفات الكبيرة مع النقل الفوري، عقود TypeScript، خمس مستويات من نقاط تفتيش جودة الشيفرة (ESLint/Prettier/Husky)، والمهام المرتبطة. يركّز على بنية الهندسة، التواصل الشبكي، وتدفق الحالة (مرجع الجماليات البصرية الصافية: frontend‑design؛ مرجع استخراج نظام التصميم: ui‑ux‑pro‑max؛ مرجع تدقيق إمكانية الوصول: web‑design‑guidelines).
