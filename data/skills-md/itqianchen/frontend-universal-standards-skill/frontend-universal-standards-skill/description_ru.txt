Современная фронтенд‑инженерная разработка и поставка полно‑стековой спецификации. Она применяется к архитектуре проекта, разработке логики страниц и компонентов, промышленному инкапсулированию сетевых запросов (Axios/uni.request), динамической маршрутизации разрешений RBAC, управлению состоянием и кросс‑платформенной персистентности для Vue 3 (Composition API/Vite/Pinia), React 18/19 (Hooks/Zustand/RTK/Tailwind CSS), кросс‑платформенных проектов Uni‑app/WeChat mini‑program, а также к наследуемым кодовым базам Vue 2; охватывает мгновенную передачу больших файлов кусками, контракты TypeScript, пятиуровневые контрольные точки качества кода (ESLint/Prettier/Husky) и связанные задачи. Сфокусировано на инженерной архитектуре, сетевом взаимодействии и потоке состояния (визуально‑эстетическая ссылка: frontend‑design; ссылка на вывод дизайн‑системы: ui‑ux‑pro‑max; ссылка на проверку доступности: web‑design‑guidelines).
