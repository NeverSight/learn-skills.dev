Интегрируйте эффекты Canvas UI на веб‑сайт, когда пользователь запрашивает Canvas UI или конкретное взаимодействие с canvas/WebGL. Охватывает выбор эффектов, компоненты реестра, интеграцию с фреймворком или без неё (vanilla) и доступные резервные варианты; обычная работа с UI не требует этой библиотеки.
