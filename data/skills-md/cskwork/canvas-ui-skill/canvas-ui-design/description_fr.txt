Intégrez les effets de l'interface utilisateur Canvas dans un site Web lorsque l'utilisateur demande une interface utilisateur Canvas ou une interaction spécifique Canvas/WebGL. Couvre la sélection des effets, les composants du registre, l'intégration du cadre ou de la vanille et les solutions de repli accessibles ; le travail ordinaire de l'interface utilisateur ne nécessite pas cette bibliothèque.
