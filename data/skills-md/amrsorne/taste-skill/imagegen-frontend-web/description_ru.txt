Элитный навык фронтенд‑ориентированного изображения для создания премиальных, ориентированных на конверсию референсов дизайна веб‑сайтов. КРИТИЧЕСКОЕ ПРАВИЛО ВЫВОДА — генерировать ОДНУ отдельную горизонтальную картинку ДЛЯ КАЖДОГО раздела. Лендинг‑страница с 8 разделами должна давать 8 изображений. Никогда не сжимать несколько разделов в одно изображение. Обеспечивает разнообразие композиций (не всегда текст слева / изображение справа), свободу фоновых изображений, разнообразные CTA, разные масштабы героев (гигантский / средний / мини‑минималистичный), повествовательный концептуальный стержень, моменты повторного прочтения и единую согласованную палитру во всех изображениях. Оптимизировано для лендингов, маркетинговых сайтов и продуктовых композиций, которые разработчики или модели кода могут точно воспроизвести.
