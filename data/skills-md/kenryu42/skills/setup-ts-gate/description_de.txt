Setzen Sie ein TypeScript-Projekt hinter ein statisches Gate, das verhindert, dass Agenten schlechten Code landen. Oxlint mit typbewussten Regeln, Oxfmt, jscpd, Knip, TypeScript 7 und ein Kommentar-Lint werden alle von einem "Check" -Skript ausgeführt. Installiert oder migriert die Werkzeuge, löscht jeden vorhandenen Befund lokal und schreibt einen Ship-Stack-Plan, der die Fixes zuerst und das Gate zuletzt landet, so dass der Koffer nie rot wird. Hält am Plan zur Genehmigung an; lässt inkompatible Projekte unverändert.
