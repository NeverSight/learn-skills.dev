Put a TypeScript project behind a static gate that stops agents from landing bad code. Oxlint with type-aware rules, Oxfmt, jscpd, Knip, TypeScript 7, and a comment lint all run from one `check` script. Installs or migrates the tooling, clears every existing finding locally, and writes a ship-stack plan that lands the fixes first and the gate last, so trunk never goes red. Stops at the plan for approval; leaves incompatible projects unchanged.
