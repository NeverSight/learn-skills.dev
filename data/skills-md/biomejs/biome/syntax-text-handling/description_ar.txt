استخدم هذه المهارة عند استخراج أو تخزين نص مصدر Biome AST/CST، والعمل مع أي `SyntaxNode` أو `SyntaxToken` أو `TokenText` أو السلاسل المقتبسة أو النطاقات النسبية للرموز أو قيم خصائص اللغة المضمنة، أو تشخيص مشاكل الـ trivia أو التخصيص أو النطاق أو الاستعارة المؤقتة. لا تستخدمها لتنفيذ المحلل أو وضع تعليقات المنسق.
