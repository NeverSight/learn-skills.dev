Utilizzalo quando devi eseguire i comandi del sottosistema Blue Shield DevOps tramite `bk-cli devops pipeline`, `bk-cli devops codecc` o `bk-cli devops stream`. È adatto per scenari quali l'esecuzione di query e il funzionamento di build di pipeline, il recupero di collegamenti di download di artefatti, la visualizzazione di dettagli o statistiche sugli allarmi CodeCC, l'interrogazione di informazioni sulla pipeline di flusso e l'attivazione di pipeline di flusso. Ogni volta che l'utente fornisce identificatori DevOps come `pipelineId`, `buildId`, `taskId`, `gongfengId`, `gitProjectId`, `yamlPath` o menziona esplicitamente Blue Shield, CodeCC, Stream, pipeline o un progetto Gongfeng, a questa competenza dovrebbe essere data priorità.
