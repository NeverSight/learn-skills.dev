When you need to use Blue Shield DevOps subsystem commands via `bk-cli devops pipeline`, `bk-cli devops codecc`, or `bk-cli devops stream`. It is suitable for scenarios such as querying and operating pipeline builds, retrieving artifact download links, viewing CodeCC alarm details or statistics, querying Stream pipeline information, and triggering Stream pipelines. Whenever a user provides DevOps identifiers like `pipelineId`, `buildId`, `taskId`, `gongfengId`, `gitProjectId`, `yamlPath`, or explicitly mentions Blue Shield, CodeCC, Stream, pipeline, or Gongfeng project, this skill should be used preferentially.
