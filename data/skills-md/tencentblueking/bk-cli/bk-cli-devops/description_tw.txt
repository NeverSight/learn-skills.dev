當需要透過 `bk-cli devops pipeline`、`bk-cli devops codecc` 或 `bk-cli devops stream` 執行 Blue Shield DevOps 子系統指令時使用此功能。適用於查詢與管理流水線建置、取得制品下載連結、查看 CodeCC 警報詳細資訊或統計、查詢 Stream 流水線資訊以及觸發 Stream 流水線等情境。只要使用者提供 DevOps 識別碼，如 `pipelineId`、`buildId`、`taskId`、`gongfengId`、`gitProjectId` 或 `yamlPath`，或明確提及 Blue Shield、CodeCC、Stream、流水線或 Gongfeng 專案，即應優先使用此技能。
