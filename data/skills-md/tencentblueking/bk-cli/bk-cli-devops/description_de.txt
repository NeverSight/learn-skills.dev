Verwenden Sie es, wenn Sie Blue Shield DevOps-Subsystembefehle über „bk-cli devopspipeline“, „bk-cli devops codecc“ oder „bk-cli devops stream“ ausführen müssen. Es eignet sich für Szenarien wie das Abfragen und Betreiben von Pipeline-Builds, das Abrufen von Artefakt-Download-Links, das Anzeigen von CodeCC-Alarmdetails oder -Statistiken, das Abfragen von Stream-Pipeline-Informationen und das Auslösen von Stream-Pipelines. Solange der Benutzer DevOps-Identifikatoren wie „pipelineId“, „buildId“, „taskId“, „gongfengId“, „gitProjectId“ oder „yamlPath“ bereitstellt oder explizit Blue Shield, CodeCC, Stream, Pipeline oder Gongfeng-Projekt erwähnt, sollte diese Fähigkeit bevorzugt verwendet werden.
