عندما تحتاج إلى استخدام أوامر النظام الفرعي Blue Shield DevOps عبر `bk-cli devops Pipeline` أو `bk-cli devops codecc` أو `bk-cli devopsstream`. وهو مناسب لسيناريوهات مثل الاستعلام عن إنشاءات خطوط الأنابيب وتشغيلها، واسترداد روابط تنزيل العناصر، وعرض تفاصيل أو إحصائيات إنذار CodeCC، والاستعلام عن معلومات خطوط أنابيب الدفق، وتشغيل خطوط أنابيب الدفق. طالما أن المستخدم يوفر معرفات DevOps مثل `pipelineId` أو `buildId` أو `taskId` أو `gongfengId` أو `gitProjectId` أو `yamlPath` أو يذكر بشكل صريح Blue Shield أو CodeCC أو Stream أو خط الأنابيب أو مشروع Gongfeng، فيجب استخدام هذه المهارة بشكل تفضيلي.
