Utiliza esta habilidad cuando necesites descubrir todos los gateways públicos en BlueKing API Gateway mediante `bk-cli apigateway`, explorar la lista de APIs/recursos públicos de un gateway específico, obtener el OpenAPI/esquema, determinar cómo llamar a una interfaz concreta o decidir entre el subcomando `apigateway` y `bk-cli api`. Es especialmente útil cuando los usuarios no saben o no están seguros de qué gateway o interfaz pública llamar, cuál podría ser el nombre de la interfaz, y solo cuentan con el objetivo del negocio, una palabra clave o un fragmento del nombre del recurso—busca primero, luego confirma, en lugar de adivinar la interfaz directamente.
