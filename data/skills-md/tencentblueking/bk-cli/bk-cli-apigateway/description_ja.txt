「bk-cli apigateway」経由で BlueKing API Gateway 内のすべてのパブリック ゲートウェイを検出する必要がある場合、特定のゲートウェイのパブリック API/リソースのリストを参照する必要がある場合、OpenAPI/スキーマを取得する必要がある場合、特定のインターフェイスを呼び出す方法を決定する場合、または「apigateway」サブコマンドと「bk-cli api」のどちらを使用するかを決定する必要がある場合に使用します。特に、ユーザーがどのゲートウェイまたはパブリック インターフェイスを呼び出すか、インターフェイス名が何なのかを知らない、または確信が持てず、ビジネス目標/キーワード/リソース名の断片しか持っていない場合は、インターフェイスを直接推測するのではなく、このスキルを優先する必要があります (最初に検索してから確認します)。
