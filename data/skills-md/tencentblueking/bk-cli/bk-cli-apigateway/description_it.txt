Quando devi scoprire tutti i gateway pubblici nel gateway API BlueKing utilizzando "bk-cli apigateway", sfogliare l'elenco di API/risorse pubbliche per un gateway specifico, ottenere OpenAPI/schema, determinare come deve essere chiamata una particolare interfaccia o scegliere tra il sottocomando "apigateway" e "bk-cli api", utilizzare questo approccio. Soprattutto quando un utente non sa o non è sicuro quale gateway o interfaccia pubblica chiamare, quale potrebbe essere il nome dell'interfaccia e conosce solo l'obiettivo aziendale, la parola chiave o un frammento del nome della risorsa, questa abilità dovrebbe avere la priorità: prima cercare, poi confermare, piuttosto che indovinare l'interfaccia a priori.
