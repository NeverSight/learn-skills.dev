`bk-cli apigateway`를 통해 BlueKing API Gateway에서 모든 공용 게이트웨이를 검색해야 하는 경우 게이트웨이의 공용 API/리소스 목록을 찾아보고, OpenAPI/스키마를 검색하고, 특정 인터페이스를 호출하는 방법을 결정하거나, `apigateway` 하위 명령과 `bk-cli api` 중에서 선택하고 이 접근 방식을 사용하세요. 특히 사용자가 호출할 게이트웨이나 공용 인터페이스, 인터페이스 이름이 무엇인지 모르거나 확실하지 않고 비즈니스 목표, 키워드 또는 리소스 이름의 일부만 알고 있는 경우 인터페이스를 완전히 추측하기보다는 먼저 검색한 다음 확인하는 등 이 기술을 우선시해야 합니다.
