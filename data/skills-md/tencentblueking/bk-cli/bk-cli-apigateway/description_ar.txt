عندما تحتاج إلى اكتشاف جميع البوابات العامة في BlueKing API Gateway عبر `bk-cli apigateway`، أو تصفح قائمة واجهات برمجة التطبيقات/الموارد العامة لبوابة معينة، أو استرداد OpenAPI/schema، أو تحديد كيفية استدعاء واجهة معينة، أو الاختيار بين الأمر الفرعي `apigateway` و`bk-cli api`، استخدم هذا. خاصة عندما لا يعرف المستخدم أو يكون غير متأكد من البوابة أو الواجهة العامة التي يجب الاتصال بها، وما هو اسم الواجهة، ويعرف فقط جزء اسم الهدف/الكلمة الرئيسية/المورد، يجب عليك إعطاء الأولوية لاستخدام هذه المهارة: ابحث أولاً ثم قم بالتأكيد، بدلاً من تخمين الواجهة مباشرة.
