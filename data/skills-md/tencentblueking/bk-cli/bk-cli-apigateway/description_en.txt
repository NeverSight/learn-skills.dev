Use it when you need to discover all public gateways in BlueKing API Gateway via `bk-cli apigateway`, browse the list of a gateway’s public APIs/resources, retrieve the OpenAPI/Schema, determine how to call a specific interface, or choose between the `apigateway` subcommand and `bk-cli api`. Especially when the user doesn’t know or is unsure which gateway or public interface to call, what the interface name might be, and only knows the business goal/keyword/resource name fragment, you should prioritize this skill—search first, then confirm, rather than guessing the interface outright.
