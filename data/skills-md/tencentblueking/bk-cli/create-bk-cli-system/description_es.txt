Al ampliar las capacidades del sistema para bk-cli, ya sea agregando un sistema de nivel superior, agregando una acción a un sistema existente o agregando una capa de subsistema a un sistema grande, debe usar esta herramienta primero. Verificará si el sistema/subsistema de destino ya existe y, cuando se le presente una lista de API de múltiples módulos, le pedirá al usuario que elija entre un formulario de comando de acción plana o un formulario de comando de subsistema de una sola capa, luego reutilizará las convenciones compartidas de selección, registro, prueba y documentación de YAML/Go.
