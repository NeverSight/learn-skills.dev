استخدم هذه المهارة عند توسيع إمكانات النظام لـ bk-cli: سواء كنت تضيف نظامًا عالي المستوى، أو تضيف إجراءً إلى نظام موجود، أو تضيف طبقة نظام فرعي إلى نظام كبير، فيجب عليك أولاً استخدام هذه المهارة. تتحقق المهارة أولاً مما إذا كان النظام/النظام الفرعي المستهدف موجودًا بالفعل؛ عند مواجهة قائمة واجهة برمجة التطبيقات متعددة الوحدات، فإنها تطالب المستخدم بالاختيار بين نموذج أمر الإجراء المسطح ونموذج أمر النظام الفرعي ذو المستوى الواحد، ثم تعيد استخدام اختيار YAML/Go المشترك، والتسجيل، والاختبار، واصطلاحات التوثيق.
