Use this skill when you need to extend the system capabilities of bk‑cli: whether adding a top‑level system, adding an action to an existing system, or adding a subsystem layer to a large system, you should first invoke this skill. The skill first checks whether the target system/subsystem already exists; when encountering a multi‑module API list, it prompts the user to choose between a flat action and a one‑level subsystem command form, then reuses the shared YAML/Go selection, registration, testing, and documentation conventions.
