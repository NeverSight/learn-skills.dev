Utilizza questa funzionalità quando estendi la funzionalità di sistema per bk-cli: che si tratti di aggiungere un sistema di livello superiore, di aggiungere un'azione a un sistema esistente o di aggiungere un livello di sottosistema a un sistema di grandi dimensioni, dovresti prima applicare questa abilità. La competenza controlla innanzitutto se il sistema/sottosistema di destinazione esiste già e, quando incontra un elenco API multi-modulo, richiede all'utente di scegliere tra un modulo di comando ad azione semplice e un modulo di comando di sottosistema a un livello, quindi riutilizza le convenzioni condivise di selezione, registrazione, test e documentazione YAML/Go.
