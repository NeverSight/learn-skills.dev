Nutzen Sie diese Fähigkeit, wenn Sie die Systemfunktionen von bk-cli erweitern: Ganz gleich, ob Sie ein Top-Level-System hinzufügen, eine Aktion zu einem vorhandenen System hinzufügen oder eine Subsystemebene zu einem großen System hinzufügen, Sie sollten diese Fähigkeit zuerst anwenden. Der Skill prüft zunächst, ob das Zielsystem/Subsystem bereits existiert; Wenn es auf eine API-Liste mit mehreren Modulen stößt, wird der Benutzer aufgefordert, zwischen einem flachen Aktionsbefehlsformular und einem einstufigen Subsystemformular zu wählen, und verwendet dann die gemeinsamen YAML/Go-Auswahl-, Registrierungs-, Test- und Dokumentationskonventionen wieder.
