Utilisez cette compétence lorsque vous avez besoin d'étendre les capacités du système de bk‑cli : qu'il s'agisse d'ajouter un système de niveau supérieur, d'ajouter une action à un système existant ou d'ajouter une couche de sous-système à un grand système, vous devez d'abord utiliser cette compétence. La compétence vérifie d'abord si le système/sous-système cible existe déjà ; lorsqu'il rencontre une liste d'API multi-modules, il permet à l'utilisateur de choisir entre une action plate et un formulaire de commande de sous-système à un niveau, puis réutilise les conventions partagées de sélection, d'enregistrement, de test et de documentation YAML/Go.
