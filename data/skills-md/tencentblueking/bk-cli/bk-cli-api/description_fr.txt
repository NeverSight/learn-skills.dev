Utilisez-le lorsque vous devez effectuer un appel HTTP brut vers n'importe quelle passerelle API BlueKing via `bk-cli api`, en particulier lorsque les sous-commandes système existantes ne couvrent pas encore la fonctionnalité, lorsque vous devez reproduire avec précision une URL/requête/chemin/corps/en-tête spécifique, effectuer un essai à sec pour valider la construction de la requête ou déboguer directement l'enveloppe d'entrée et de réponse de la requête. Tant que l'utilisateur effectue explicitement une « requête API brute » plutôt que d'utiliser une sous-commande métier existante, cette compétence doit être utilisée en premier.
