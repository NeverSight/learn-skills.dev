Utilizzalo quando devi effettuare chiamate HTTP non elaborate a qualsiasi gateway API BlueKing tramite "bk-cli api". È particolarmente adatto quando i sottocomandi di sistema esistenti non hanno ancora coperto la funzionalità, quando è necessario riprodurre con precisione un URL/query/percorso/corpo/intestazione specifico, eseguire un'esecuzione a prova per verificare la costruzione della richiesta o eseguire direttamente il debug dell'input della richiesta e della busta di risposta. Finché l'utente effettua esplicitamente una "richiesta API grezza" anziché utilizzare un sottocomando aziendale già pronto, questa abilità dovrebbe essere utilizzata preferenzialmente.
