استخدمه عندما تحتاج إلى إجراء مكالمة HTTP أولية إلى أي بوابة BlueKing API عبر `bk-cli api`. إنها مناسبة بشكل خاص للحالات التي لا تغطي فيها أوامر النظام الفرعية الموجودة العملية بعد، وتحتاج إلى إعادة إنتاج عنوان URL/استعلام/مسار/نص/رأس محدد بدقة، أو إجراء عملية تشغيل تجريبية للتحقق من إنشاء الطلب، أو تصحيح أخطاء إدخال الطلب ومظروف الاستجابة مباشرةً. وطالما أن المستخدم يقوم بشكل صريح بتقديم "طلب API أولي" بدلاً من استخدام أمر فرعي جاهز للأعمال، فيجب تفضيل هذه المهارة.
