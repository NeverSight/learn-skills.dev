Use it when you need to make a raw HTTP call to any BlueKing API Gateway via `bk-cli api`, especially when existing system sub‑commands don’t cover the case, when you need to precisely reproduce a specific URL/query/path/body/header, perform a dry‑run to verify request construction, or directly debug the request input and response envelope. As long as the user is explicitly making a “raw API request” rather than using an existing business sub‑command, this skill should be used preferentially.
