Use esto cuando necesite iniciar una llamada HTTP sin procesar a cualquier puerta de enlace API de BlueKing a través de `bk-cli api`, especialmente si los subcomandos del sistema existentes aún no cubren la operación, necesita reproducir con precisión una URL/consulta/ruta/cuerpo/encabezado específico, realizar una ejecución en seco para verificar la construcción de la solicitud o depurar directamente la entrada de la solicitud y el sobre de respuesta. Siempre que el usuario realice explícitamente una "solicitud de API sin procesar" en lugar de usar un subcomando comercial existente, esta habilidad debe usarse primero.
