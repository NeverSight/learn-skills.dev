Verwenden Sie dies, wenn Sie über „bk-cli api“ einen rohen HTTP-Aufruf an ein beliebiges BlueKing API Gateway durchführen müssen, insbesondere wenn vorhandene Systemunterbefehle den Endpunkt noch nicht abdecken, wenn Sie eine bestimmte URL/Abfrage/Pfad/Text/Header präzise reproduzieren, einen Probelauf durchführen müssen, um die Anforderungskonstruktion zu überprüfen, oder Anforderungseingaben und Antwortumschläge direkt debuggen müssen. Immer wenn der Benutzer explizit eine „Roh-API-Anfrage“ stellt, anstatt einen vorgefertigten Geschäftsunterbefehl zu verwenden, sollte diese Fähigkeit zuerst verwendet werden.
