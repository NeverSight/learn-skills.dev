Используйте его, когда вам нужно выполнить необработанный HTTP-вызов к любому шлюзу API BlueKing через `bk-cli api`, особенно если существующие системные подкоманды не охватывают этот случай, когда вам нужно точно воспроизвести определенный URL-адрес/запрос/путь/тело/заголовок, выполнить пробный прогон для проверки конструкции запроса или напрямую отладить ввод запроса и конверт ответа. Пока пользователь явно делает «необработанный запрос API», а не использует существующую бизнес-подкоманду, этот навык следует использовать предпочтительно.
