Interaktives Testen und Erkunden von Blue Whale CLI-Befehlen (bk-cli). Verwenden Sie diese Fähigkeit, wenn ein Benutzer bk-cli testen, die Blue Whale-Plattform-API erkunden, die bk-cli-Funktionalität überprüfen oder schreibgeschützte Befehle auf verschiedenen Blue Whale-Systemen (cmdb, gse, job, sops, nodeman, devops usw.) ausführen möchte. Zu den Triggerphrasen gehören „测试 bk-cli“, „test bk-cli“, „探索 bk-cli 命令“, „查看 bk-cli 接口“ oder jedes Szenario, das das Testen von bk-cli-Unterbefehlen beinhaltet.
