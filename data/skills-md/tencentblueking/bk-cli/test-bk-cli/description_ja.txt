Blue Whale CLI (bk-cli) コマンドの対話型のテストと探索。このスキルは、ユーザーが bk-cli のテスト、Blue Whale プラットフォーム API の調査、bk-cli 機能の検証、またはさまざまな Blue Whale システム (cmdb、gse、job、sops、nodeman、devops など) で読み取り専用コマンドの実行を行う場合に使用します。トリガー フレーズには、「测试 bk-cli」、「test bk-cli」、「探索 bk-cli コマンド」、「查看 bk-cli 接続」、または bk-cli サブコマンドのテストに関連するシナリオが含まれます。
