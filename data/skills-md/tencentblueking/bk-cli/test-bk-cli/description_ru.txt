Интерактивное тестирование и исследование команд CLI Blue Whale (bk-cli). Используйте этот навык, когда пользователи хотят протестировать bk-cli, изучить API платформы Blue Whale, проверить функциональность bk-cli или выполнить команды только для чтения в различных системах Blue Whale (cmdb, gse, job, sops, nodeman, devops и т. д.). Триггерные фразы включают «test bk-cli», «test bk-cli», «исследовать команды bk-cli», «просмотреть интерфейс bk-cli» или любой сценарий, включающий тестирование подкоманд bk-cli.
