Utilisez-le lorsque vous devez utiliser des sous-commandes système liées à CMDB via `bk-cli cmdb`, ou lorsque vous choisissez entre la sous-commande `cmdb` et `bk-cli api bk-cmdb…`. Il est particulièrement adapté aux scénarios tels que l'interrogation des entreprises, la topologie, les relations entre hôtes, les migrations d'hôtes ou le dépannage pour savoir si une requête d'API ouverte CMDB est construite correctement.
