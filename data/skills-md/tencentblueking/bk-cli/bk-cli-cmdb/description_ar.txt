استخدم هذا عندما تحتاج إلى تشغيل الأوامر الفرعية المرتبطة بـ CMDB عبر `bk-cli cmdb`، أو عند الاختيار بين الأمر الفرعي `cmdb` و`bk-cli api bk-cmdb...`. وهو مناسب بشكل خاص لسيناريوهات مثل الاستعلام عن الشركات، أو الهيكل، أو علاقات المضيف، أو عمليات ترحيل المضيف، أو استكشاف الأخطاء وإصلاحها فيما إذا كان طلب CMDB Open API قد تم إنشاؤه بشكل صحيح.
