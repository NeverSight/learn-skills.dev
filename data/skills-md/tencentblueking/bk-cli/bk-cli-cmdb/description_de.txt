Wenn Sie CMDB-bezogene Systemunterbefehle über „bk-cli cmdb“ verwenden müssen, oder wählen Sie zwischen dem Unterbefehl „cmdb“ und „bk-cli api bk-cmdb ...“. Es eignet sich besonders für Szenarien wie die Abfrage von Unternehmen, Topologie, Hostbeziehungen, Hostmigrationen oder die Fehlerbehebung, ob die CMDB-Open-API-Anforderungskonstruktion korrekt ist.
