Используйте, когда вам нужно вызвать системные подкоманды, связанные с CMDB, через `bk-cli cmdb` или при выборе между подкомандой `cmdb` и `bk-cli api bk-cmdb ...`. Он особенно подходит для таких сценариев, как запросы к предприятиям, топологии, взаимосвязям между хостами, миграции хостов или диагностике правильности построения запроса открытого API CMDB.
