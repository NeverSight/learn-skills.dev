Cuando necesite utilizar subcomandos del sistema relacionados con CMDB a través de `bk-cli cmdb`, o elegir entre el subcomando `cmdb` y `bk-cli api bk-cmdb ...`. Es especialmente adecuado para escenarios como consultas de negocios, topologías, relaciones de host, migraciones de host o resolución de problemas sobre si una solicitud de API abierta de CMDB se construyó correctamente.
