Quando è necessario utilizzare i sottocomandi di sistema relativi a CMDB tramite `bk-cli cmdb` o scegliere tra il sottocomando `cmdb` e `bk-cli api bk-cmdb ...`. È particolarmente adatto per scenari quali query su aziende, topologie, relazioni host, migrazioni host o risoluzione dei problemi relativi alla correttezza della costruzione della richiesta API aperta CMDB.
