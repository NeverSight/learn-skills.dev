Convertir un jeu de données robotique multimodal (MCAP, HDF5, LeRobot, parquet, vidéo brute) en enregistrements Rerun en couches (.rrd) et en un jeu de données prêt pour le catalogue. Utilisez-le chaque fois que l'utilisateur souhaite convertir ou ingérer un jeu de données dans Rerun, faire réviser ou étendre un pipeline de conversion, ou enrichir un jeu de données existant avec une nouvelle couche — même lorsqu'il se contente de dire « convertir X en rrd », « ingérer ce jeu de données », « enrichir ce jeu de données » ou « ajouter une couche ». Dirigez vers les compétences rerun-* pour la mécanique de Rerun. Veuillez toujours répondre dans la langue de l'utilisateur.
