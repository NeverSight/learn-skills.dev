Ensambla las entradas de cambios por PR en docs/content/changelog/upcoming/ dentro del archivo changeset‑0‑XX.md de una versión y genera las secciones detalladas del CHANGELOG.md. Úsalo en el momento del lanzamiento cuando el usuario quiera crear o finalizar el changelog o changeset para una versión de Rerun, o fusionar las entradas de upcoming/. Se invoca mediante /assemble‑changelog o “ensambla el changelog para 0.x.y”.
