Raggruppa le voci dei changeset per PR presenti in **docs/content/changelog/upcoming/** in un file **changeset-0-XX.md** della release e genera le sezioni dettagliate di **CHANGELOG.md**. Utilizzalo al momento del rilascio quando l'utente desidera costruire o finalizzare il changelog o il changeset per una release Rerun, oppure unire le voci di **upcoming/**. Viene invocato tramite **/assemble-changelog** o con il comando “assemble the changelog for 0.x.y”.

Per favore rispondi sempre nella lingua dell'utente.
