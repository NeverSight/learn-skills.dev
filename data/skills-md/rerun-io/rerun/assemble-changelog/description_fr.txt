Rassemblez les entrées de changeset par PR présentes dans docs/content/changelog/upcoming/ dans le fichier changeset‑0‑XX.md d’une version et générez les sections détaillées du CHANGELOG.md. Utilisez‑les lors du moment de la version lorsque l’utilisateur souhaite créer ou finaliser le changelog ou le changeset pour une version Rerun, ou fusionner les entrées du répertoire upcoming/. Invoqué via /assemble‑changelog ou « assemble the changelog for 0.x.y ».
