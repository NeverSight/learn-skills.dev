Wende es an, wenn du einen Test schreibst, änderst oder beibehältst. Rufe den Code so auf, wie seine Benutzer es tun, und prüfe das beobachtete Ergebnis gegen einen wörtlichen erwarteten Wert. Wenn der Test immer noch bestehen würde, wenn jede importierte Funktion `undefined` zurückgibt, schreibe die Assertion um oder lösche den Test.
