Trouvez les erreurs que les agents répètent dans ce dépôt et rendez chacune impossible. Commencez par l’architecture, puis les types, ensuite un lint dont le message d’erreur indique la correction, puis un test, et rédigez enfin la documentation. Prouvez que chaque vérification échoue sur une vraie erreur passée. Répétez cela chaque fois que l’opérateur vous corrige. Utilisez pour /correct.

Veuillez toujours répondre dans la langue de l’utilisateur.
