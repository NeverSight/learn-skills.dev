Wenden Sie die Testpyramide auf eine Funktion an — teilen Sie Testszenarien über Ebenen (Einheit, Integration, e2e) auf, ordnen Sie jedes Szenario der günstigsten ausreichenden Ebene zu und erstellen Sie eine Aufteilung der Abdeckung pro Ebene. Verwenden Sie, wenn Sie gefragt werden: "Einheit, Integration oder e2e?", "Welches Niveau sollte dieser Test haben?", "Wie sollen wir diese Funktion testen?", "Welche Testabdeckung benötigen wir?", oder um die Testpyramide auf eine Funktion oder ein Projekt anzuwenden.
