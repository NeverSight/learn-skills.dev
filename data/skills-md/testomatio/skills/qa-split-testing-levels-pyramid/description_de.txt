Wenden Sie die Testpyramide auf eine Funktion an – teilen Sie Testszenarien auf Ebenen auf (Einheit, Integration, E2E), weisen Sie jedes Szenario der günstigsten ausreichenden Ebene zu und erstellen Sie eine Aufteilung der Abdeckung pro Ebene. Verwenden Sie diese Option, wenn Sie gefragt werden: „Einheit, Integration oder E2E?“, „Welche Ebene soll dieser Test haben?“, „Wie sollen wir diese Funktion testen?“, „Welche Testabdeckung benötigen wir?“ oder um die Testpyramide auf eine Funktion oder ein Projekt anzuwenden.
