Genera casi di test e liste di controllo per il test del software. Utilizza questa competenza ogni volta che l'utente chiede di creare casi di test, scenari di test, piani di test, liste di controllo, documentazione QA o menziona attività di test come "scrivere test per funzionalità", "creare una lista di controllo di test", "generare scenari di test dai requisiti" o simili. Questa abilità funziona meglio se l'utente fornisce documentazione, requisiti, ecc. oppure può creare casi di test basati sulla richiesta dell'utente senza alcun contesto aggiuntivo.
