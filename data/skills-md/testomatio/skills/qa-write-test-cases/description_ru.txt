Создавайте тестовые примеры и контрольные списки для тестирования программного обеспечения. Используйте этот навык всякий раз, когда пользователь просит создать тестовые примеры, сценарии тестирования, планы тестирования, контрольные списки, документацию по обеспечению качества или упоминает такие действия по тестированию, как «написание тестов для функции», «создание контрольного списка тестирования», «создание сценариев тестирования на основе требований» и тому подобное. Этот навык работает лучше, если пользователь предоставляет документацию, требования и т. д. или может создавать тестовые примеры на основе запроса пользователя без какого-либо дополнительного контекста.
