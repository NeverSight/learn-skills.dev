Examiner une pull request en tant qu’ingénieur QA — vérifier si la modification résout réellement le problème indiqué, signaler les ruptures de rétrocompatibilité et les risques, et lister les scénarios à valider avant la fusion. Utilisez cette consigne lorsqu’on demande « review this PR as QA », « what should we test in this PR ? » ou « is this PR safe to merge ? ». Veuillez toujours répondre dans la langue de l’utilisateur.
