Revisiona una pull request come ingegnere QA — verifica se la modifica risolve realmente il problema indicato, segnala eventuali rotture di compatibilità retroattiva e i rischi, ed elenca gli scenari che devono essere verificati prima del merge. Usalo quando ti chiedono “review this PR as QA”, “what should we test in this PR?” o “is this PR safe to merge?”.
