Bereiten Sie Testdaten für eine Funktion vor und übertragen Sie sie in eine Zielumgebung. Analysiert die Implementierung der Funktion, schlägt Datenkategorien vor, die reguläre Fälle und Randfälle abdecken, und füllt die Umgebung über vorhandene Seed-Mechanismen, Codezugriff, REST, MCP. Verwenden Sie diese Option, wenn der Benutzer Testdaten bereitstellen, eine Test- oder Staging-Umgebung füllen, Daten für manuelle/QA-Tests einer Funktion vorbereiten, einen Datensatz für eine Funktion generieren oder Vorrichtungen in einer Umgebung erstellen möchte.
