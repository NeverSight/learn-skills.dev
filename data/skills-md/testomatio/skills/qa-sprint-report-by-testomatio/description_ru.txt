Создайте сводный отчёт о прогрессе QA‑спринта на основе данных Testomat.io TMS. Используйте, когда пользователь хочет подготовить структурированный отчёт в конце спринта, охватывающий покрытие тестового дизайна, результаты выполнения, тенденции дефектов и сигналы качества. Навык считывает данные через инструменты Testomat.io MCP, сопоставляет их с разделами отчёта и по умолчанию выводит файл `.html` (или `.md`, если явно запрошено).

Всегда отвечайте на языке пользователя.
