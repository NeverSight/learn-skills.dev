Genera un report di sintesi del progresso della QA Sprint dai dati del TMS Testomat.io. Usalo quando l'utente desidera produrre un report di fine sprint strutturato che copra la copertura della progettazione dei test, i risultati dell'esecuzione, le tendenze dei difetti e i segnali di qualità. La funzionalità legge i dati tramite gli strumenti MCP di Testomat.io, li mappa alle sezioni del report e genera un file `.html` per impostazione predefinita (o `.md` se richiesto esplicitamente).

Rispondi sempre nella lingua dell'utente.
