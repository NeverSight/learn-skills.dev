Installieren und konfigurieren Sie das Testomat.io‑Reporting in einem Testautomatisierungsprojekt, wenn ein Benutzer seine Tests mit Testomat.io integrieren muss. Erkennen Sie das Testframework (z. B. Playwright, CodeceptJS, Jest, Mocha, WebdriverIO, JUnit, Pytest, XML usw.) und richten Sie automatisch den passenden Reporter ein, sodass Testergebnisse an das Testomat.io‑TMS gesendet werden.
