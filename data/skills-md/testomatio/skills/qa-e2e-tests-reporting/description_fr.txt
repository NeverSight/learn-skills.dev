Installez et configurez le reporting Testomat.io dans un projet d’automatisation de tests lorsqu’un utilisateur doit intégrer ses tests avec Testomat.io. Détectez le framework de test (par ex. : Playwright, CodeceptJS, Jest, Mocha, WebdriverIO, JUnit, Pytest, XML, etc.) et configurez automatiquement le reporter approprié afin que les résultats des tests soient envoyés au TMS Testomat.io.

Veuillez toujours répondre dans la langue de l’utilisateur.
