Сопоставьте тестовые случаи — вручную (уценка) и автоматически e2e (Playwright, Cypress, WebdriverIO, CodeceptJS, Puppeteer, Appium) — с файлами исходного кода и создайте сопоставление «coverage.tests.yml», используемое «@testomatio/reporter --filter «coverage:...»». Используйте этот навык, когда пользователь хочет запустить только те тесты, на которые повлияло изменение кода, создать файл покрытия (вручную, e2e или и то, и другое), построить матрицу прослеживаемости между тестами и исходным кодом или настроить регрессию с учетом изменений.
