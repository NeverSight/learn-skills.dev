Mappare i casi di test — manuali (markdown) e automatizzati e2e (Playwright, Cypress, WebdriverIO, CodeceptJS, Puppeteer, Appium) — per creare file di codice sorgente e produrre una mappatura `coverage.tests.yml` utilizzata da `@testomatio/reporter --filter "coverage:..."`. Utilizzare questa capacità quando l'utente desidera eseguire solo i test interessati da una modifica del codice, generare un file di copertura (manuale, e2e o entrambi), creare una matrice di tracciabilità tra test e codice sorgente o impostare una regressione in base al cambiamento.
