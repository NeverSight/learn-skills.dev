Asigne casos de prueba (e2e manual (markdown) y automatizado (Playwright, Cypress, WebdriverIO, CodeceptJS, Puppeteer, Appium)) a archivos de código fuente y produzca un mapeo `coverage.tests.yml` consumido por `@testomatio/reporter --filter "coverage:..."`. Utilice esta habilidad cuando el usuario quiera ejecutar solo las pruebas afectadas por un cambio de código, generar un archivo de cobertura (manual, e2e o ambos), crear una matriz de trazabilidad entre las pruebas y el código fuente, o configurar una regresión con reconocimiento de cambios.
