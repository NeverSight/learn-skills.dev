تعيين حالات الاختبار - يدويًا (تخفيض السعر) وe2e الآلي (Playwright، Cypress، WebdriverIO، CodeceptJS، Puppeteer، Appium) - لملفات التعليمات البرمجية المصدر وإنتاج رسم خرائط `coverage.tests.yml` يستهلكه `@testomatio/reporter --filter "coverage:..."`. استخدم هذه المهارة عندما يريد المستخدم تشغيل الاختبارات المتأثرة بتغيير التعليمات البرمجية فقط، أو إنشاء ملف تغطية (يدوي، أو e2e، أو كليهما)، أو إنشاء مصفوفة تتبع بين الاختبارات والتعليمات البرمجية المصدر، أو إعداد انحدار مدرك للتغيير.
