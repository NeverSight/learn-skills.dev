Ordnen Sie Testfälle – manuell (Markdown) und automatisiert e2e (Playwright, Cypress, WebdriverIO, CodeceptJS, Puppeteer, Appium) – Quellcodedateien zu und erstellen Sie eine „coverage.tests.yml“-Zuordnung, die von „@testomatio/reporter --filter „coverage:…““ verwendet wird. Verwenden Sie diese Fähigkeit, wenn der Benutzer nur die von einer Codeänderung betroffenen Tests ausführen, eine Coverage-Datei (manuell, e2e oder beides) generieren, eine Rückverfolgbarkeitsmatrix zwischen Tests und Quellcode erstellen oder eine änderungsbewusste Regression einrichten möchte.
