Mappez les cas de test — manuels (markdown) et automatisés e2e (Playwright, Cypress, WebdriverIO, CodeceptJS, Puppeteer, Appium) — avec les fichiers de code source et produisez un mappage `coverage.tests.yml` consommé par `@testomatio/reporter --filter "coverage:..."`. Utilisez cette compétence lorsque l'utilisateur souhaite exécuter uniquement les tests affectés par une modification de code, générer un fichier de couverture (manuel, e2e ou les deux), créer une matrice de traçabilité entre les tests et le code source ou configurer une régression prenant en compte les modifications.
