Crea e avvia le esecuzioni di test di Testomat.io con la CLI `@testomatio/reporter`. Copre le esecuzioni manuali per i tester, le esecuzioni miste manuali+automatiche, l'esecuzione dei test locali con risultati riportati e i lanci remoti tramite un profilo CI Testomat.io (`--remote`). Le esecuzioni possono includere l'intera suite o essere filtrate per tag, piano, etichetta, ticket Jira o file di origine modificati. Da utilizzare quando l'utente chiede di avviare o creare un'esecuzione di test dalla riga di comando, eseguire un gruppo filtrato di test, avviare test in remoto o riportare i risultati in un'esecuzione esistente.
