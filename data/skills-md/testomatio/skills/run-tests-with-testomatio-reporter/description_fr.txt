Créez et lancez des exécutions de tests Testomat.io avec la CLI `@testomatio/reporter`. Couvre les exécutions manuelles pour les testeurs, les exécutions mixtes manuelles et automatisées, l'exécution de tests locaux avec les résultats rapportés et les lancements à distance via un profil Testomat.io CI (`--remote`). Les exécutions peuvent inclure l'intégralité de la suite ou être filtrées par balise, plan, étiquette, ticket Jira ou fichiers sources modifiés. À utiliser lorsque l'utilisateur demande à démarrer ou à créer une exécution de test à partir de la ligne de commande, à exécuter un groupe de tests filtré, à lancer des tests à distance ou à rapporter les résultats dans une exécution existante.
