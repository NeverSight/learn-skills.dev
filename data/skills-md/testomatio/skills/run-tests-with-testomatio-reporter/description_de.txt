Erstellen und starten Sie Testomat.io-Testläufe mit der „@testomatio/reporter“-CLI. Umfasst manuelle Läufe für Tester, gemischte manuelle und automatisierte Läufe, lokale Testausführung mit gemeldeten Ergebnissen und Remote-Starts über ein Testomat.io-CI-Profil („--remote“). Läufe können die gesamte Suite umfassen oder nach Tag, Plan, Label, Jira-Ticket oder geänderten Quelldateien gefiltert werden. Verwenden Sie diese Option, wenn der Benutzer einen Testlauf über die Befehlszeile starten oder erstellen, eine gefilterte Gruppe von Tests ausführen, Tests remote starten oder Ergebnisse in einen vorhandenen Lauf melden möchte.
