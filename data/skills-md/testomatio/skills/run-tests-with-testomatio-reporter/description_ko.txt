`@testomatio/reporter` CLI를 사용하여 Testomat.io 테스트 실행을 생성하고 시작합니다. 테스터를 위한 수동 실행, 수동+자동 실행 혼합, 보고된 결과가 있는 로컬 테스트 실행, Testomat.io CI 프로필(`--remote`)을 통한 원격 실행을 다룹니다. 실행에는 전체 제품군이 포함되거나 태그, 계획, 레이블, Jira 티켓 또는 변경된 소스 파일을 기준으로 필터링될 수 있습니다. 사용자가 명령줄에서 테스트 실행을 시작 또는 생성하거나, 필터링된 테스트 그룹을 실행하거나, 원격으로 테스트를 실행하거나, 결과를 기존 실행에 보고하도록 요청할 때 사용합니다.
