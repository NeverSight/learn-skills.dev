Cree e inicie ejecuciones de prueba de Testomat.io con la CLI `@testomatio/reporter`. Cubre ejecuciones manuales para probadores, ejecuciones mixtas manuales y automatizadas, ejecución de pruebas locales con resultados informados y lanzamientos remotos a través de un perfil de CI Testomat.io (`--remote`). Las ejecuciones pueden incluir todo el conjunto o filtrarse por etiqueta, plan, etiqueta, ticket de Jira o archivos fuente modificados. Úselo cuando el usuario solicite iniciar o crear una ejecución de prueba desde la línea de comando, ejecutar un grupo filtrado de pruebas, iniciar pruebas de forma remota o informar los resultados de una ejecución existente.
