Analice el contexto de una solicitud de extracción (título, descripción, comentarios, problemas vinculados, esquemas/imágenes adjuntos) para comprender la intención original, verificar el alcance con el ticket vinculado, sacar a la luz ambigüedades y casos extremos, y producir un resumen de requisitos estructurado con criterios de aceptación comprobables. Utilice esta habilidad cuando el usuario quiera entender QUÉ se supone que debe hacer un PR (no solo qué código cambió), verificar si el PR coincide con su ticket/tarea vinculado o generar criterios de aceptación a partir del contexto del PR/ticket en lugar de código.
