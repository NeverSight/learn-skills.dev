Un asesor estratégico para procesos de QA, calidad, pruebas y automatización. Actúa como líder senior de QA. Primero entrevista al usuario y escanea el proyecto para construir un contexto rico, luego identifica las brechas de mayor impacto y entrega una hoja de ruta priorizada paso a paso, canalizando la ejecución a habilidades especializadas. Active esta habilidad cuando el usuario quiera configurar QA desde cero, mejorar un proceso existente, establecer automatización de pruebas, decidir por dónde comenzar con las pruebas o realizar una revisión de madurez de QA — por ejemplo, "configurar QA para este proyecto", "mejorar nuestro proceso de QA/pruebas/automatización", "por dónde deberíamos empezar con las pruebas", "no tenemos pruebas, ayuda", "revisar nuestro proceso de calidad". También active esta habilidad cuando el usuario describa problemas como "baja calidad", "faltan/muchos errores", "sin pruebas".
