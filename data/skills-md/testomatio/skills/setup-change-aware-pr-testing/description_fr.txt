Configurez CI pour que chaque demande d'extraction reçoive une exécution Testomat.io limitée au code qu'elle modifie. Un travail s'exécute après le déploiement : il crée l'exécution et y lance les tests concernés. À utiliser lorsque l'utilisateur souhaite intégrer des exécutions Testomat.io dans un pipeline CI, créer des exécutions de tests par demande d'extraction ou configurer des tests sensibles aux modifications qui déclenchent les tests concernés à partir d'événements CI.
