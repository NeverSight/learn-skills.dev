Richten Sie CI so ein, dass jede Pull-Anfrage einen Testomat.io-Lauf erhält, der auf den geänderten Code beschränkt ist. Ein Job wird nach der Bereitstellung ausgeführt – er erstellt den Lauf und startet die betroffenen Tests darin. Verwenden Sie diese Option, wenn der Benutzer Testomat.io-Läufe in eine CI-Pipeline integrieren, Testläufe per Pull-Anfrage erstellen oder änderungsbewusste Tests einrichten möchte, die betroffene Tests durch CI-Ereignisse auslösen.
