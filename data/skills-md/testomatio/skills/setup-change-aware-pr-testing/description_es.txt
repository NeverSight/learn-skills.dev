Configure CI para que cada solicitud de extracción obtenga una ejecución de Testomat.io centrada en el código que cambia. Un trabajo se ejecuta después de la implementación: crea la ejecución y lanza en ella las pruebas afectadas. Úselo cuando el usuario desee integrar ejecuciones de Testomat.io en una canalización de CI, crear ejecuciones de prueba por solicitud de extracción o configurar pruebas con reconocimiento de cambios que activen pruebas afectadas a partir de eventos de CI.
