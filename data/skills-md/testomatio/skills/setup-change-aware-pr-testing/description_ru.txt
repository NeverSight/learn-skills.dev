Настройте CI так, чтобы каждый запрос на вытягивание запускался Testomat.io с привязкой к изменяемому коду. Одно задание запускается после развертывания — оно создает прогон и запускает в него затронутые тесты. Используйте, когда пользователь хочет интегрировать запуски Testomat.io в конвейер CI, создавать тестовые запуски для каждого запроса на извлечение или настроить тестирование с учетом изменений, которое запускает затронутые тесты из событий CI.
