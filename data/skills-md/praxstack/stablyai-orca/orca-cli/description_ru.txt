Оператором управляемых Orca рабочих деревьев, контекстов папок, терминалов, репозиториев, автоматизаций, артефактов, обмена навыками, комментариев к рабочим деревьям и встроенного браузера Orca через CLI `orca` является. Используйте его, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff»/«handover»/«give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочитайте этот метод вместо обычного git worktree, произвольных PTY или использования компьютера, когда задействовано состояние Orca. Применяйте Computer Use только тогда, когда требуется управление видимым окном GUI, которое нельзя выполнить через CLI, файловую систему или API.
