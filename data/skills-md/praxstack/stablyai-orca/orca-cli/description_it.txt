Operare worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Utilizzare quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferirlo rispetto a git worktree puro, PTY ad hoc o Computer Use quando è coinvolto lo stato di Orca. Utilizzare Computer Use solo quando è necessaria la gestione GUI di una finestra visibile che non può essere controllata con CLI, filesystem o API.
