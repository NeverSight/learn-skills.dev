Verwenden Sie diese Option, wenn Sie eine lokale Seite oder ein Dashboard erstellen, deren Schaltflächen authentifizierte json an einen Webhook-Dienst im Besitz des Benutzers senden. Nicht für nicht genehmigtes öffentliches Hosting, die Verarbeitung von Anmeldeinformationen oder die Einrichtung externer Automatisierung verwenden.
