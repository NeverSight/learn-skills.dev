عند كتابة أو تحرير الوثائق الصينية الرسمية أو مراجعة تنسيقها بشكل محدد، يجب توحيد أنماط الطباعة المختلطة وعلامات الترقيم والأسماء الصحيحة. لا تُطبّق هذه القاعدة تلقائيًا على الدردشة اليومية أو الأسئلة الفنية والأجوبة أو الترجمات العشوائية أو الملاحظات غير الرسمية أو نسخ الواجهة القصيرة؛ كما أنها لا تُستخدم فقط للقراءة أو التلخيص أو مراجعة المحتوى.

يرجى دائمًا الرد بلغة المستخدم.
