全面的 Zephyr Shell 子系統專業知識，適用於建立與管理 CLI 命令。當您需要以下情況時，使用此技能：(1) 使用 SHELL_CMD_REGISTER 或 SHELL_CMD_ARG_REGISTER 建立或註冊新 Shell 命令，(2) 定義靜態或動態子命令，(3) 使用 shell_print、shell_error、shell_warn 實作命令處理函式，(4) 建立字典命令以進行字串到值的對映，(5) 設定 Shell 後端（UART、RTT、USB、Telnet、BLE NUS），(6) 啟用 Shell Kconfig 選項（CONFIG_SHELL_*），(7) 解析命令參數或使用 getopt，(8) 偵錯 Shell 命令問題或了解 Shell 架構。  

請始終以使用者的語言回覆。
