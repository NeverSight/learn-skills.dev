Competenza completa nel sottosistema Zephyr Shell per creare e gestire comandi CLI. Usa questa abilità quando hai bisogno di: (1) Creare o registrare nuovi comandi shell con SHELL_CMD_REGISTER o SHELL_CMD_ARG_REGISTER, (2) Definire sottocomandi statici o dinamici, (3) Implementare gestori di comando con output shell_print/shell_error/shell_warn, (4) Creare comandi dizionario per mappature stringa‑valore, (5) Configurare i backend della shell (UART, RTT, USB, Telnet, BLE NUS), (6) Abilitare le opzioni Kconfig della shell (CONFIG_SHELL_*), (7) Analizzare gli argomenti del comando o usare getopt, (8) Debuggare i problemi dei comandi shell o comprendere l'architettura della shell.
