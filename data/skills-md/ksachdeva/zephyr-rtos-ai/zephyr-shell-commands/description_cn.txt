全面的 Zephyr Shell 子系统专业知识，用于创建和管理 CLI 命令。需要时请使用此技能：(1) 使用 SHELL_CMD_REGISTER 或 SHELL_CMD_ARG_REGISTER 创建或注册新 shell 命令；(2) 定义静态或动态子命令；(3) 使用 shell_print / shell_error / shell_warn 实现命令处理函数；(4) 创建字典命令，实现字符串到数值的映射；(5) 配置 shell 后端（UART、RTT、USB、Telnet、BLE NUS）；(6) 启用 shell Kconfig 选项（CONFIG_SHELL_*）；(7) 解析命令参数或使用 getopt；(8) 调试 shell 命令问题或了解 shell 架构。请始终使用用户的语言回复。
