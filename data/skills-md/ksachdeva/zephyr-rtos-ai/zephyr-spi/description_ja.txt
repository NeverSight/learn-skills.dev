シリアル周辺機器通信のための包括的な Zephyr SPI サブシステムの知識。使用例: (1) devicetree や Kconfig を使った SPI コントローラまたはデバイスの設定、(2) spi_transceive / spi_read / spi_write による同期 SPI 転送の実装、(3) spi_transceive_cb または spi_transceive_signal を用いた非同期 SPI の実装、(4) SPI モードの設定（CPOL、CPHA、ワードサイズ、ビット順序）、(5) GPIO またはハードウェア CS によるチップセレクトの管理、(6) マルチパートトランザクションのための scatter‑gather バッファの使用、(7) 使いどころに応じた同期 API と非同期 API の選択、(8) SPI 通信のトラブルシューティング（クロック極性、CS タイミング、データ破損）。
