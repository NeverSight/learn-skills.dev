Serialización y deserialización de JSON en Zephyr RTOS usando la biblioteca JSON basada en descriptores. Úsela al codificar estructuras C a cadenas JSON, al analizar JSON en estructuras C, al trabajar con objetos o arreglos anidados, al manejar protocolos de nube/IoT (cargas útiles MQTT, HTTP, CoAP), o al implementar APIs REST en dispositivos integrados.
