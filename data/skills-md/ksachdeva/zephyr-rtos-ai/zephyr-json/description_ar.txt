تسلسل JSON وإلغاء تسلسله في نظام Zephyr RTOS باستخدام مكتبة JSON المعتمدة على الوصف. استخدمها عند ترميز هياكل C إلى سلاسل JSON، أو عند تحليل JSON إلى هياكل C، أو عند التعامل مع كائنات أو مصفوفات متداخلة، أو عند معالجة بروتوكولات السحابة/إنترنت الأشياء (حمولات MQTT، HTTP، CoAP)، أو عند تنفيذ واجهات برمجة التطبيقات REST على الأجهزة المدمجة.
