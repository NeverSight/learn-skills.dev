Serializzazione e deserializzazione JSON in Zephyr RTOS mediante la libreria JSON basata su descrittori. Da utilizzare quando si codificano strutture C in stringhe JSON, si analizza JSON in strutture C, si lavora con oggetti o array nidificati, si gestiscono protocolli cloud/IoT (payload MQTT, HTTP, CoAP) o si implementano API REST su dispositivi embedded.
