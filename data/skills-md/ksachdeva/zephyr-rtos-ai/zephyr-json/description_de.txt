Json Serialisierung und Deserialisierung in Zephyr RTOS unter Verwendung der Deskriptor-basierten JSON-Bibliothek. Verwendung beim Codieren von C-Strukturen in JSON-Zeichenfolgen, beim Parsen von json in C-Strukturen, beim Arbeiten mit verschachtelten Objekten oder Arrays, beim Umgang mit Cloud-/IoT-Protokollen (MQTT-, HTTP-, CoAP-Nutzlasten) oder beim Implementieren von REST-APIs AUF eingebetteten Geräten.
