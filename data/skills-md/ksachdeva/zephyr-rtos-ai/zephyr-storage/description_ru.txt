Прямое хранение пар «ключ‑значение» с использованием подсистем NVS (Non-Volatile Storage) и ZMS (Zephyr Memory Storage) в Zephyr OS. Применяется при записи данных непосредственно во флеш‑память с числовыми идентификаторами (а не строковыми ключами), выборе между NVS и ZMS, настройке разделов флеш‑памяти для хранения, расчёте износа флеш‑памяти и срока службы устройства, а также при работе с API хранения (mount, read, write, delete). Для высокоуровневой персистентности с строковыми ключами используйте модуль zephyr-settings.
