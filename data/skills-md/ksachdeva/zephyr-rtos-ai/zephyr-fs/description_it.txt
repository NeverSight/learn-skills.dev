Supporto al file system in Zephyr OS, inclusi VFS API, LittleFS, FAT, ext2 e FCB. Da utilizzare quando si lavora con operazioni di I/O su file, montaggio di file system, lettura/scrittura di file, operazioni su directory, formattazione della memoria, scelta tra diversi tipi di file system, configurazione delle partizioni flash per i file system o implementazione di storage persistente basato su file. Per lo storage chiave‑valore con ID numerici, utilizzare zephyr-storage. Per la persistenza delle impostazioni con chiavi stringa, utilizzare zephyr-settings.
