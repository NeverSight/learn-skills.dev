Guía completa para pruebas unitarias y de integración de aplicaciones Zephyr RTOS. Utiliza esta habilidad cuando necesites: (1) Crear suites de pruebas usando el framework Ztest, (2) Escribir casos de prueba con fixtures, aserciones y expectativas, (3) Configurar testcase.yaml para el ejecutor de pruebas Twister, (4) Simular funciones usando FFF (Fake Function Framework), (5) Ejecutar pruebas con Twister en emuladores o hardware, (6) Depurar pruebas que fallan o configurar la infraestructura de pruebas, (7) Implementar pruebas de integración basadas en pytest.
