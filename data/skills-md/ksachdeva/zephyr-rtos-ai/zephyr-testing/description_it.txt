Guida completa per il test unitario e il test di integrazione delle applicazioni Zephyr RTOS. Usa questa competenza quando devi: (1) Creare suite di test usando il framework Ztest, (2) Scrivere casi di test con fixture, asserzioni e aspettative, (3) Configurare testcase.yaml per il runner di test Twister, (4) Mockare le funzioni usando FFF (Fake Function Framework), (5) Eseguire i test con Twister su emulatori o hardware, (6) Debuggare i test falliti o configurare l'infrastruttura di test, (7) Implementare test di integrazione basati su pytest. Per favore rispondi sempre nella lingua dell'utente.
