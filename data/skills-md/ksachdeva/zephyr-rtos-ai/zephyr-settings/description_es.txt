Conocimiento integral para el almacenamiento persistente de configuración en Zephyr OS. Cubre el subsistema Settings, manejadores, backends (NVS, ZMS, FCB, File) y la API en tiempo de ejecución. Úsalo cuando necesites almacenar la configuración del dispositivo, el estado de ejecución, datos de calibración o implementar manejadores de settings. Facilita la selección del backend (eligiendo entre NVS/ZMS/FCB/File), la resolución de problemas de persistencia y la integración con otros subsistemas de Zephyr (Bluetooth, Shell, Logging).
