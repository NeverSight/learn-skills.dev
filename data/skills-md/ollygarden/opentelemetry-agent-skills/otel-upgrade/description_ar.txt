تقييم ترقيات حزمة OpenTelemetry وجمع البيانات عبر الأنظمة. استخدم ذلك عند اختيار أو التحقق من إصدارات API أو SDK أو الأدوات الوسيطة أو المصدّر أو توزيع Collector أو المكوّن أو الصورة أو المخطط أو المشغّل أو بناء OCB أو إصدارات التكوين، بما في ذلك التوافق، والتغييرات المطلوبة، والسلوك التتبعي وسلوك وقت التشغيل، ومخاطر النشر.
