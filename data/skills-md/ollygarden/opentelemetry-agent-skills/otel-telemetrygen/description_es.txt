Construye comandos seguros con versión fija de telemetrygen para trazas, métricas y registros OTLP sintéticos. Úsalo para “enviar trazas de muestra a este colector”, “realizar pruebas de carga a un punto final OTLP”, “generar tráfico para verificar un procesador, una transformación OTTL o un muestreo posterior”, y “producir datos de prueba para paneles”. También utilízalo al elegir transporte, TLS, atributos, recuentos, duración o tasa en telemetrygen. No es para instrumentación de SDK de aplicación ni para recopilación en producción que no use telemetrygen.
