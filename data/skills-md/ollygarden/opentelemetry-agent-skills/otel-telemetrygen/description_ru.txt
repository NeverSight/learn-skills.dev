Создавайте безопасные команды telemetrygen с фиксированной версией для синтетических OTLP‑трассировок, метрик и логов. Используйте их для «отправки примерных трассировок в этот коллектор», «нагрузочного тестирования OTLP‑конечной точки», «генерации трафика для проверки процессора, трансформации OTTL или tail‑sampling» и «создания тестовых данных для дашбордов». Также применяйте при выборе транспорта telemetrygen, TLS, атрибутов, количества, длительности или скорости. Не предназначено для инструментирования SDK приложений или продакшн‑сбора, не использующего telemetrygen.
