OCB(OpenTelemetry Collector Builder)를 사용하여 맞춤형 OpenTelemetry Collector 배포판을 빌드합니다. builder.yaml과 같은 빌더 매니페스트를 작성하거나 디버깅할 때, 구성 요소와 제공자 버전을 선택할 때, 맞춤형 또는 배포판 외부 구성 요소를 포함하는 컬렉터를 빌드할 때, 배포판의 CI 또는 Docker 빌드를 설정할 때, 혹은 OCB 빌드 실패를 해결할 때 사용합니다. “ocb”, “collector builder”, “custom collector distribution”, “builder manifest”, “builder-config”, 그리고 OCB 빌드에서 발생하는 버전 불일치 오류에 대해 트리거됩니다.
