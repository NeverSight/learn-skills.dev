使用 OCB（OpenTelemetry Collector Builder）构建自定义的 OpenTelemetry Collector 发行版。在编写或调试 builder manifest（builder.yaml）、选择组件和提供者版本、构建包含自定义或非发行版组件的 Collector、设置发行版的 CI 或 Docker 构建，或排查 OCB 构建失败时使用。触发词包括 “ocb”、 “collector builder”、 “custom collector distribution”、 “builder manifest”、 “builder-config” 以及 OCB 构建中出现的版本不匹配错误。请始终使用用户的语言作答。
