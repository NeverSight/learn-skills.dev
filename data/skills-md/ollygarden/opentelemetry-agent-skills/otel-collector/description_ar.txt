تكوين مكوّن OpenTelemetry Collector. يُستخدم عند كتابة أو مراجعة أو تصحيح ملفات YAML الخاصة بـ Collector لمستقبل أو معالج أو مصدر تصدير أو موصل أو امتداد محدد — مفاتيح التكوين، القيم الافتراضية، قواعد التحقق، دعم الإشارات، مستويات الثبات، ومصاعب مستوى المكوّن. يطلق عند أسئلة حول مكوّنات Collector بما فيها المستقبلات، المعالجات، الصادرات، الموصلات، الامتدادات، إعادة تسمية المكوّنات، دعم الإشارات، وتوصيل الأنابيب.
