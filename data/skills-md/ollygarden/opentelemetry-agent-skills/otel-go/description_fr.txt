OpenTelemetry en Go — configuration du SDK, surface de l’API, changements incompatibles, bibliothèques d’instrumentation contrib (otelhttp, otelgrpc, otelmongo), instrumentation zéro‑code à la compilation (otelc) et optimisation des performances. À utiliser lors de l’ajout, de la révision ou de la configuration d’OpenTelemetry dans un service Go. S’active avec « setup otel in go », « go telemetry », « go tracing », « otelconf go », « otelhttp », « otelgrpc », « TracerProvider go », « MeterProvider go », « otelc », « compile-time instrumentation go », « zero-code go instrumentation », « go build instrumentation », ou toute question OTel liée à Go. Veuillez toujours répondre dans la langue de l’utilisateur.
