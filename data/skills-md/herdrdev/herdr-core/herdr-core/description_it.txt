Usa herdr-core (la sua CLI è hc) ogni volta che desideri sub‑agent, per parlare o coordinare altri agenti, eseguire attività o server in background, lanciare comandi a lunga durata, leggere o controllare terminali, o lavorare su un’altra macchina; anche per mostrare o organizzare elementi nella finestra di Herdr o creare mod e layout di Herdr. Preferiscilo rispetto al tuo strumento per sub‑agent, alla shell “&”, a nohup o a tmux.
