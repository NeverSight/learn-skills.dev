Используйте эту функцию после развертывания рецепта CloudWeaver v2 (через cloud‑weaver‑repo‑setup + конвейер GitHub Actions), чтобы убедиться, что приложение действительно запущено, и помочь диагностировать его, если это не так. Она опрашивает endpoint проверки состояния приложения до получения HTTP 200 с повторными попытками и экспоненциальным откатом, а при сбое собирает SSH‑диагностику с виртуальной машины.
