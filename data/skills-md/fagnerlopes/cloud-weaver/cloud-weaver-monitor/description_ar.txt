استخدم هذه المهارة بعد نشر وصفة CloudWeaver v2 (عبر Cloud-weaver-repo-setup + GitHub Actions Pipeline) للتأكد من أن التطبيق يعمل بالفعل وللمساعدة في تشخيصه عندما لا يكون كذلك. فهو يستقصي نقطة نهاية سلامة التطبيق حتى HTTP 200 مع عمليات إعادة المحاولة والتراجع، وفي حالة الفشل، يجمع تشخيصات SSH من الجهاز الظاهري.
