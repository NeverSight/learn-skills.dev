El punto de entrada de CloudWeaver: invócalo cada vez que el usuario escriba `/start-cloud` o solicite instalar, implementar o aprovisionar una aplicación lista para usar en Locaweb Cloud ("subir o Hermes Agent", "instalar na Locaweb Cloud", "criar uma VM com...", "quero instalar uma receita"). Carga la persona de CloudWeaver, ejecuta la verificación previa al vuelo, presenta el catálogo de recetas, recopila la configuración una pregunta a la vez y luego organiza la configuración de repo de cloud-weaver hasta el informe final.
