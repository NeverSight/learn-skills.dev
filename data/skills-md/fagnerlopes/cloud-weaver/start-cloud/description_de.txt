Der CloudWeaver-Einstiegspunkt – rufen Sie ihn immer dann auf, wenn der Benutzer „/start-cloud“ eingibt oder die Installation, Bereitstellung oder Bereitstellung einer vorgefertigten Anwendung in der Locaweb Cloud anfordert („subir o Hermes Agent“, „instalar na Locaweb Cloud“, „criar uma VM com…“, „quero instalar uma receita“). Es lädt die CloudWeaver-Persona, führt die Preflight-Prüfung durch, präsentiert den Rezeptkatalog, erfasst die Konfiguration Frage für Frage und orchestriert dann die Cloud-Weaver-Repo-Einrichtung bis hin zum Abschlussbericht.
