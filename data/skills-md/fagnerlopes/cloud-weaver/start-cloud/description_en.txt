The CloudWeaver entry point — invoke it whenever the user types `/start-cloud` or asks to install, deploy or provision a ready-made application on the Locaweb Cloud ("subir o Hermes Agent", "instalar na Locaweb Cloud", "criar uma VM com...", "quero instalar uma receita"). It loads the CloudWeaver persona, runs the pre-flight check, presents the recipe catalog, collects configuration one question at a time, then orchestrates cloud-weaver-repo-setup through to the final report.
