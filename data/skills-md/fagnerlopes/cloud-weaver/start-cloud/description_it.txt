Il punto di ingresso di CloudWeaver — invocarlo ogni volta che l'utente digita `/start-cloud` o chiede di installare, distribuire o provisionare un'applicazione pronta sulla Locaweb Cloud ("subir o Hermes Agent", "instalar na Locaweb Cloud", "criar uma VM com...", "quero instalar uma receita"). Carica la persona di CloudWeaver, esegue il controllo preliminare, presenta il catalogo delle ricette, raccoglie la configurazione una domanda alla volta, quindi orchestra cloud‑weaver‑repo‑setup fino al report finale.

Rispondi sempre nella lingua dell'utente.
