Formato dei messaggi di commit, dei nomi dei branch, dei titoli delle PR e dei titoli delle issue secondo la specifica Conventional Commits 1.0.0. Usa PRIMA di eseguire `git commit`, `git checkout -b`/`git branch`, `gh pr create` o `gh issue create`; prima di scrivere qualsiasi messaggio di commit, nome di branch, titolo di PR o titolo di issue; e ogni volta che si preparano modifiche da committare o si richiede di “commit”, “creare una PR”, “aprire un issue” o “creare un branch” — o quando un'altra skill ha bisogno di un messaggio di commit conforme alla specifica.

Rispondi sempre nella lingua dell'utente.
