Formatea los mensajes de commit, los nombres de rama, los títulos de PR y los títulos de issue según la especificación Conventional Commits 1.0.0. Usa ANTES de ejecutar `git commit`, `git checkout -b`/`git branch`, `gh pr create` o `gh issue create`; antes de escribir cualquier mensaje de commit, nombre de rama, título de PR o título de issue; y siempre que estés preparando cambios para commit o se solicite “commit”, “crear un PR”, “abrir un issue” o “crear una rama”, o cuando otra herramienta necesite un mensaje de commit que cumpla con la especificación.

Por favor, responde siempre en el idioma del usuario.
