커밋 메시지, 브랜치 이름, PR 제목, 그리고 이슈 제목을 Conventional Commits 1.0.0 사양에 맞게 포맷하세요. `git commit`, `git checkout -b`/`git branch`, `gh pr create`, `gh issue create`를 실행하기 **전**에; 커밋 메시지, 브랜치 이름, PR 제목, 이슈 제목을 작성하기 **전**에; 그리고 변경 사항을 스테이징하여 커밋하거나 “commit”, “make a PR”, “open an issue”, “create a branch” 라고 요구받을 때마다 — 혹은 다른 스킬이 사양에 맞는 커밋 메시지를 필요로 할 때마다.

항상 사용자의 언어로 응답해주세요.
