Formate les messages de commit, les noms de branches, les titres de PR et les titres d’issues selon la spécification Conventional Commits 1.0.0. Utilise AVANT d’exécuter `git commit`, `git checkout -b`/`git branch`, `gh pr create` ou `gh issue create` ; avant d’écrire tout message de commit, nom de branche, titre de PR ou titre d’issue ; et chaque fois que tu mets en scène des changements à committer ou que l’on te demande de « commit », « faire une PR », « ouvrir une issue » ou « créer une branche » — ou lorsqu’une autre compétence a besoin d’un message de commit conforme aux spécifications.

Veuillez toujours répondre dans la langue de l’utilisateur.
