Construire ou modifier des formulaires avec @falcondev-oss/form — la bibliothèque de formulaires typée, réactive et basée sur un schéma (paquets form‑core, form‑react, form‑vue) construite sur @vue/reactivity. À utiliser lorsqu’on travaille avec useForm / useFormCore, les accesseurs form.fields, $use(), field.value / field.handleChange / field.model, form.data, ou un formulaire à schéma standard (zod v4 / arktype) dans une base de code React ou Vue.
