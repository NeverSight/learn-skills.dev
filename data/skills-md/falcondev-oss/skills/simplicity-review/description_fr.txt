Examen à froid d’un diff pour la complexité qu’il peut révéler, chaque constat indiquant ce qu’il faut couper et ce qui le remplace. À utiliser lorsqu’on demande ce qui peut être supprimé ou simplifié dans une branche, une PR ou des changements locaux, si le code est sur‑ingénieré, ou lorsqu’une autre compétence déclenche une revue de simplicité.
