Caricamenti di file tipizzati in modo sicuro tramite tRPC con @falcondev-oss/trpc-typed-form-data. Da utilizzare quando si caricano file / FormData attraverso una procedura tRPC, o si lavora con typedFormData(), createTypedFormData(), typedFormDataLink, createTypedFormDataPlugin, il validatore file() / tipo FileValue (un’alternativa stabile a z.file()), o con caricamenti di file ReactNativeFile / Expo tramite tRPC.
