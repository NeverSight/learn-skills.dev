Télécargements de fichiers sécurisés par le typage via tRPC avec @falcondev-oss/trpc-typed-form-data. À utiliser lors du téléversement de fichiers / FormData via une procédure tRPC, ou en travaillant avec typedFormData(), createTypedFormData(), typedFormDataLink, createTypedFormDataPlugin, le validateur file() / le type FileValue (une alternative stable à z.file()), ou les téléversements de fichiers ReactNativeFile / Expo via tRPC.
