Fournissez un changement sous forme de pull request verte, prête à être mergée. Utilisez‑le lorsque l'utilisateur dit « implement » à propos d’une URL d’issue, d’un chemin de fichier, ou d’un changement discuté précédemment dans la conversation, ou qu’il demande que le changement soit « merge ready ». Veuillez toujours répondre dans la langue de l’utilisateur.
