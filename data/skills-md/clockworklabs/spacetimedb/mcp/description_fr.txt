Manipulez une base de données SpacetimeDB en cours d’exécution via les outils MCP plutôt que via la CLI : listez les bases de données, lisez les schémas, exécutez du SQL et appelez les réducteurs. À utiliser lorsque le client expose les outils MCP de SpacetimeDB et que la tâche consiste à inspecter ou à modifier les données d’une base de données en direct.
