Auditez les tests existants à faible valeur, dupliqués ou liés à l’implémentation, ainsi que le code uniquement destiné aux tests qu’ils maintiennent en vie, puis supprimez‑les ou réécrivez‑les sur la base de preuves. /test-audit full couvre l’ensemble de la suite et répertorie également les contrats publics sans garde de test. Utilisez pour test-audit, /test-audit <scope>, /test-audit full, un balayage de tests ou l’élagage des tests. Pas pour écrire un nouveau test ; la règle Tests du projet le régule.
