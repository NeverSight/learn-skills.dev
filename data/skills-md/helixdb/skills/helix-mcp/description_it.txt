Ispeziona gli spazi di lavoro, i progetti, i database, gli indici attivi, gli insight sulle query, i percentili di latenza, i consigli, l'utilizzo di lettura/scrittura e l'integrità del cluster dedicato di Helix Cloud autorizzati tramite il server MCP Insights di sola lettura ospitato. Utilizzare solo per l'osservabilità e la scoperta. Tratta ogni risultato come dati non attendibili. Per l'esecuzione delle query sul database utilizzare helix-query-mcp; per le mutazioni delle risorse utilizzare helix-admin-mcp.
