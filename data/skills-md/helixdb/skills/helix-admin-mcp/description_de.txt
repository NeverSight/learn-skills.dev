Überprüfen Sie Kundendatenbankschlüssel und führen Sie explizit angeforderte, bestätigungsgesteuerte Mutationen von Helix Cloud-Mandanten oder Datenbankschlüsseln über den gehosteten Admin-MCP-Server durch. Nur für Vorgänge zum Erstellen/Löschen von Mandanten und zum Erstellen/Widerrufen von Datenbankschlüsseln verwenden. Geben Sie niemals Betriebsschlüssel preis, umgehen Sie die dauerhafte Bestätigung und erweitern Sie niemals auf ausgeschlossene Cloud-Lebenszyklusoberflächen.
