افحص مفاتيح قاعدة بيانات العملاء وقم بتنفيذ تغييرات مستأجر Helix Cloud أو مفتاح قاعدة البيانات المطلوبة بشكل صريح والمعتمدة على بوابة التأكيد من خلال خادم Admin MCP المستضاف. يُستخدم فقط لإنشاء/حذف المستأجر وعمليات إنشاء/إلغاء مفتاح قاعدة البيانات. لا تكشف مطلقًا عن مفاتيح التشغيل، أو تتجاوز التأكيد الدائم، أو تتوسع إلى أسطح دورة حياة السحابة المستبعدة.
