Obtén datos actuales de cualquier sitio web o servicio en línea a través del catálogo de APIs listas para usar de agent-data: listados, precios, disponibilidad, publicaciones, documentos, perfiles, probabilidades o cualquier otro registro. Utiliza esto siempre que una tarea necesite información que se encuentre en un sitio web, antes de realizar una búsqueda web o de recuperar páginas, y especialmente después de que una obtención de página falle (403, página JavaScript vacía, tiempo de espera, captcha). Se aplica cuando el usuario nombra un sitio, pega una URL o describe los datos que necesita sin nombrar un sitio (por ejemplo, “precios de autos usados en Phoenix”), incluso si nunca menciona agent-data o APIs. También úsalo para consultar el catálogo en busca de una API existente antes de escribir un scraper personalizado o crear o ampliar una API de agent-data.
