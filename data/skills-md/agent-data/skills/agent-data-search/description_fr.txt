Obtenez des données actuelles de n’importe quel site web ou service en ligne via le catalogue d’APIs prêtes à l’emploi d’agent‑data : annonces, prix, disponibilités, publications, articles, profils, cotes ou tout autre enregistrement. Utilisez cela chaque fois qu’une tâche nécessite des informations présentes sur un site web, avant la recherche sur le web ou le téléchargement de pages, et surtout après qu’une récupération de page a échoué (403, page JavaScript vide, délai d’attente dépassé, captcha). Cela s’applique lorsque l’utilisateur cite un site, colle une URL ou décrit les données dont il a besoin sans nommer de site (par exemple, « prix des voitures d’occasion à Phoenix »), même s’il ne mentionne jamais agent‑data ou les APIs. Utilisez également cela pour vérifier le catalogue afin de trouver une API existante avant d’écrire un scraper personnalisé ou de créer ou d’étendre une API agent‑data.
