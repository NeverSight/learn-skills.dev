Ottieni dati aggiornati da qualsiasi sito web o servizio online tramite il catalogo di API pronte all'uso di agent-data: annunci, prezzi, disponibilità, post, documenti, profili, quote o qualsiasi altro tipo di record. Usa questa risorsa ogni volta che un compito richiede informazioni presenti su un sito, prima di effettuare ricerche sul web o recuperare pagine, e soprattutto dopo che il recupero di una pagina è fallito (403, pagina JavaScript vuota, timeout, captcha). Si applica quando l'utente indica un sito, incolla un URL o descrive i dati di cui ha bisogno senza nominare un sito (ad esempio, “prezzi auto usate a Phoenix”), anche se non menziona mai agent-data o le API. Utilizzala anche per controllare il catalogo alla ricerca di un'API esistente prima di scrivere uno scraper personalizzato o di creare o estendere un'API di agent-data.
