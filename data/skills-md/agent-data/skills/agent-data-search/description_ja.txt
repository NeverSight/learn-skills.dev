エージェントデータの既成APIカタログを通じて、任意のウェブサイトやオンラインサービスから最新データを取得できます：リスティング、価格、在庫状況、投稿、論文、プロフィール、オッズ、その他あらゆる記録。タスクがウェブ上に存在する情報を必要とする際は、ウェブ検索やページ取得の前に、特にページ取得が失敗したとき（403、空のJavaScriptページ、タイムアウト、キャプチャ）にこれを使用してください。ユーザーがサイト名を挙げる場合、URL を貼り付ける場合、あるいはサイト名を挙げずに必要なデータを説明する場合（例：「フェニックスの中古車価格」）でも、エージェントデータや API に言及がなくても適用されます。また、カスタムスクレイパーを作成したり、エージェントデータ API を新規作成・拡張する前に、カタログに既存の API があるか確認するためにも活用してください。

常にユーザーの言語で回答してください。
