agent-data의 준비된 API 카탈로그를 통해 모든 웹사이트나 온라인 서비스에서 최신 데이터를 가져오세요: 목록, 가격, 재고, 게시물, 논문, 프로필, 확률 등 모든 기록. 작업에 웹사이트에 있는 정보가 필요할 때, 웹 검색이나 페이지를 가져오기 전에, 특히 페이지 가져오기가 실패했을 때(403, 빈 JavaScript 페이지, 타임아웃, 캡차) 사용합니다. 사용자가 사이트를 지정하거나 URL을 붙여넣거나 사이트를 명시하지 않고 데이터 요구를 설명할 때(예: “피닉스의 중고차 가격”)에도 적용되며, 사용자가 agent-data나 API를 언급하지 않아도 됩니다. 또한 사용자 정의 스크래퍼를 작성하거나 agent-data API를 만들거나 확장하기 전에 기존 API가 있는지 카탈로그를 확인하는 데에도 사용하십시오.
