Holen Sie aktuelle Daten von jeder Website oder Online‑Dienst über den Katalog von agent‑data mit fertigen APIs: Angebote, Preise, Verfügbarkeit, Beiträge, Dokumente, Profile, Quoten oder sonstige Datensätze. Verwenden Sie dies immer dann, wenn eine Aufgabe Informationen benötigt, die auf einer Website liegen, bevor Sie eine Websuche durchführen oder Seiten abrufen, und besonders, wenn ein Seitenabruf fehlschlägt (403, leere JavaScript‑Seite, Timeout, Captcha). Es gilt, wenn der Benutzer eine Seite nennt, eine URL einfügt oder die benötigten Daten beschreibt, ohne eine Seite zu nennen (z. B. „Gebrauchtwagenpreise in Phoenix“), selbst wenn er agent‑data oder APIs nie erwähnt. Nutzen Sie es außerdem, um im Katalog nach einer bestehenden API zu suchen, bevor Sie einen eigenen Scraper schreiben oder eine agent‑data‑API erstellen bzw. erweitern.
