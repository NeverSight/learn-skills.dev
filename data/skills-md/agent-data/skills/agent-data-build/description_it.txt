Crea un'API agent-data quando l'utente vuole trasformare un sito web in un'API o necessita di dati di un sito che le API esistenti non possono fornire. Descrivi il flusso di lavoro previsto, invia la build e valida l'API pubblicata. Usa agent-data-extend per le funzionalità mancanti in un'API esistente. Rispondi sempre nella lingua dell'utente.
