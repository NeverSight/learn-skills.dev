قم بإنشاء واجهة برمجة تطبيقات (API) للوكيل-البيانات عندما يرغب المستخدم في تحويل موقع ويب إلى واجهة برمجة تطبيقات أو يحتاج إلى بيانات الموقع التي لا تستطيع الواجهات البرمجية الحالية توفيرها. صِف سير العمل المقصود، قدّم عملية الإنشاء، وتحقق من صحة الواجهة البرمجية المنشورة. استخدم agent-data-extend للقدرات المفقودة في واجهة برمجة التطبيقات الحالية.
