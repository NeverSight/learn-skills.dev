راقب بيانات المواقع وقم بتشغيل سير العمل المتكرر باستخدام واجهات برمجة تطبيقات agent-data. استخدمه لتتبع الأسعار أو التوفر، تنبيهات الوظائف، الاستماع الاجتماعي، الاستخبارات التنافسية، ملخصات الأبحاث، وغيرها من الطلبات لمراقبة التغييرات أو إرسال تقارير دورية — حتى دون ذكر agent-data. يتحكم في اختيار المصدر، حالة الاسترجاع، كشف التغيّر، الجدولة، والتسليم. يستخدم agent-data-search عندما يحتاج إلى مصدر بيانات.
