Отслеживайте данные веб‑сайтов и запускайте повторяющиеся рабочие процессы с помощью API agent‑data. Используйте для мониторинга цен или наличия, оповещений о вакансиях, социального слуха, конкурентной разведки, исследовательских дайджестов и других запросов, чтобы следить за изменениями или отправлять периодические отчёты — даже без упоминания agent‑data. Управляет выбором источников, состоянием получения, обнаружением изменений, планированием и доставкой. При необходимости источника данных использует agent‑data‑search.
