Surveillez les données du site Web et exécutez des flux de travail récurrents avec des API de données d'agent. À utiliser pour le suivi des prix ou de la disponibilité, les alertes emploi, l'écoute sociale, la veille concurrentielle, les résumés de recherche et d'autres demandes pour surveiller les changements ou envoyer des rapports récurrents, même sans mentionner les données de l'agent. Possède la sélection de la source, l'état de récupération, la détection des changements, la planification et la livraison. Utilise la recherche de données d'agent lorsqu'il a besoin d'une source de données.
