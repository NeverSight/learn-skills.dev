Supervise los datos del sitio web y ejecute flujos de trabajo recurrentes con API de datos del agente. Úselo para el seguimiento de precios o disponibilidad, alertas de trabajo, escucha social, inteligencia competitiva, resúmenes de investigación y otras solicitudes para estar atento a los cambios o enviar informes recurrentes, incluso sin mencionar los datos del agente. Posee la selección de la fuente, el estado de recuperación, la detección de cambios, la programación y la entrega. Utiliza la búsqueda de datos del agente cuando necesita un origen de datos.
