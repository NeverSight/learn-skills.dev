Monitora i dati dei siti web ed esegui flussi di lavoro ricorrenti con le API agent-data. Usalo per il monitoraggio di prezzi o disponibilità, avvisi di lavoro, ascolto social, intelligence competitiva, sintesi di ricerca e altre richieste per osservare variazioni o inviare report ricorrenti—anche senza menzionare agent-data. Gestisce la selezione della fonte, lo stato di recupero, il rilevamento dei cambiamenti, la programmazione e la consegna. Utilizza agent-data-search quando ha bisogno di una fonte dati.
