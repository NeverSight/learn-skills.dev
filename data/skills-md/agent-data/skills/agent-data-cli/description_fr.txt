Installez, authentifiez, mettez à jour et dépannez l'interface de ligne de commande agent-data. À utiliser pour la syntaxe des commandes agent-data, les requêtes API tapées, l'inspection des comptes, la notification, la gestion des sorties et la récupération des erreurs. D'autres compétences agent-données utilisent cette compétence lorsqu'elles ont besoin d'une mécanique CLI partagée.
