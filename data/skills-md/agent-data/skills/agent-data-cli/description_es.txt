Instalar, autenticar, actualizar y solucionar problemas de la CLI de datos del agente. Utilícelo para la sintaxis del comando de datos del agente, las solicitudes de API escritas, la inspección de la cuenta, la notificación, el manejo de la salida y la recuperación de errores. Otras habilidades de datos de agentes utilizan esta habilidad cuando necesitan una mecánica de CLI compartida.
