适用于 React 和 Next.js 的生产级动画 UI 组件库，使用 Motion（Framer Motion）和 Tailwind CSS 构建。包含 339 个交互式组件，分为 4 类：Motion 基元（80 个组件）、AI 代理界面（17 个组件）、块与小部件（33 个组件）以及工艺与表面组件（209 个组件：触感 3D 按钮、拟物化控件、设备模型、背景渐变与图案、日历小部件、数据表格、编辑排版以及交互卡片）。支持 6 种美学风格预设（minimal、origin、enterprise、glow、ios、brutalist）。附带本地 Codex 安装说明、完整的设计系统指南以及 AI 代理安装提示。
