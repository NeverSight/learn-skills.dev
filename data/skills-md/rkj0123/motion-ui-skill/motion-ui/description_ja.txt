React と Next.js 用の、Motion（Framer Motion）と Tailwind CSS で構築された、実稼働可能なアニメーション UI コンポーネントライブラリです。4 つのカテゴリーにわたる 339 のインタラクティブコンポーネントを含みます：Motion Primitives（80 コンポーネント）、AI エージェントサーフェス（17 コンポーネント）、ブロック＆ウィジェット（33 コンポーネント）、Craft & Surface Components（209 コンポーネント：触覚的 3D ボタン、ニューモーフィックコントロール、デバイスモックアップ、背景グラデーション＆パターン、カレンダーウィジェット、データテーブル、エディトリアルタイポグラフィ、インタラクティブカード）。6 つの美的スタイルプリセット（minimal、origin、enterprise、glow、ios、brutalist）をサポート。ローカル Codex インストール手順、包括的なデザインシステムガイド、AI エージェント インストールプロンプトを含みます。
