Production-ready animated UI component library for React and Next.js built with Motion (Framer Motion) and Tailwind CSS. Includes 339 interactive components across 4 categories: Motion Primitives (80 components), AI Agent Surfaces (17 components), Blocks & Widgets (33 components), and Craft & Surface Components (209 components: tactile 3D buttons, neumorphic controls, device mockups, background gradients & patterns, calendar widgets, data tables, editorial typography, and interactive cards). Supports 6 aesthetic style presets (minimal, origin, enterprise, glow, ios, brutalist). Includes local Codex installation instructions, comprehensive design system guides, and an AI-agent install prompt.
