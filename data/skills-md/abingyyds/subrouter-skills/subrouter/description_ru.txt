Подключите AI‑агента (Claude Code, Cursor, Codex и т.д.) к SubRouter — совместимому с OpenAI/Anthropic шлюзу AI‑API с интеллектуальной маршрутизацией и прозрачным ценообразованием. Используйте этот навык для авторизации агента через поток устройства, получения API‑ключа, выбора модели по цене и настройки клиента. Также позволяет владельцу распределительной станции (分站站长) управлять своей станцией: размещать или снимать модели, устанавливать цены, управлять пакетами и настройками. Триггеры: «接入 SubRouter», «配置 SubRouter», «SubRouter API key», «用 SubRouter 的模型», «管理我的分站», «分站上架», «分站套餐».
