AIエージェント（Claude Code、Cursor、Codex など）を SubRouter に接続します — スマートルーティングと透明な価格設定を備えた、OpenAI/Anthropic 互換の AI API ゲートウェイです。このスキルを使用してデバイスフローでエージェントを認証し、API キーを取得し、価格に基づいてモデルを選択し、クライアントを構成します。また、分站站长 がステーションを運営できるようにします：モデルのリスト登録・削除、価格設定、パッケージと設定の管理。トリガー："接入 SubRouter"、"配置 SubRouter"、"SubRouter API key"、"用 SubRouter 的模型"、"管理我的分站"、"分站上架"、"分站套餐"。
