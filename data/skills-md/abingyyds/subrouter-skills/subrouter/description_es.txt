Conecta un agente de IA (Claude Code, Cursor, Codex, etc.) a SubRouter — una puerta de enlace de API de IA compatible con OpenAI/Anthropic con enrutamiento inteligente y precios transparentes. Usa esta función para autorizar el agente mediante flujo de dispositivo, obtener una clave API, elegir un modelo por precio y configurar el cliente. También permite que el propietario de una estación distribuidora (分站站长) gestione su estación: listar o retirar modelos, establecer precios, administrar paquetes y configuraciones.
