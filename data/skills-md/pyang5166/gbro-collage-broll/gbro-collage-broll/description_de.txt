Erstellen Sie eine fortgeschrittene redaktionelle Halbton-Papiercollage/Halbton-Papiercollage-B-Rolle aus einem etwa 5 Sekunden langen gesprochenen Skript, einem Meinungssatz oder einem abstrakten Konzept. Wenn der Benutzer „Collage-B-Roll“, „Papier-Collage-B-Roll“, „Halbton-Collage“, „Visuals im Collage-Stil“, „Mit diesem Skript eine Collage-Animation erstellen“, „gbro-Collage-Broll“ sagt oder einen Satz in eine visuelle Collage-Metapher umwandeln möchte, muss diese Fähigkeit verwendet werden. Erzwingen Sie einen dreistufigen Genehmigungsprozess: Schlagen Sie zunächst nur die visuelle Metapher vor. Generieren Sie nach der Bestätigung durch den Benutzer einen farbigen statischen Collagenrahmen. Nachdem der statische Frame erneut bestätigt wurde, wird Gemini Omni Flash automatisch aufgerufen, um die Eröffnungs- und Schlussframes zu generieren und die Animation zusammenzustellen. Das Standardvideomodell ist auf Gemini-Omni-Flash-Vorschau festgelegt und nicht mehr standardmäßig auf Veo; Wechseln Sie nur, wenn der Benutzer explizit ein anderes Modell angibt.
