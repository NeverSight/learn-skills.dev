[المهارة الداخلية للمجموعة • عادةً لا يحتاج المستخدمون كامل العملية إلى الاستدعاء مباشرة؛ فقط أبدِ الطلب إلى وحدة التحكم الرئيسية مخرج الدراما القصيرة، وستقوم وحدة التحكم بتوجيهه تلقائيًا إلى هذه المهارة] [مجموعة مان دراما لاو لي V7.4.26 • مهارة فرعية] محرك تخصص لوحات قصة السرد/الدراما اليومية (إصدار بصري للدراما القصيرة): نظام كاميرا بصري للدراما القصيرة + اقتصاد اللقطة + قيود الأداء + أبعاد خماسية لربط داخل القطاعات وخمس وضعيات حركة الكاميرا، تحويل نص الرواية/السيناريو الأصلي إلى نصوص لوحة قصة فائقة الاختصار؛ **وتوليد صور لوحة قصة (★أصول المخرجات القياسية): لوحة متعددة الأجزاء لكل قطاع، مقسمة إلى سبع مراحل من الفعل (البدء / العملية / الاتصال / القمة / النتيجة / الرد / الخروج)؛ عدد اللوحات يحدد بحسب تعقيد الفعل وليس وفق شبكة ثابتة 3×3، إطار الخروج = إطار دخول القطاع التالي، نسخة CLEAN_GRID النظيفة للصور الخام + نسخة اختيارية مع توضيحات تقنية**. **★ يجب إدراك وتثبيت القاعدة البصرية للنمط (مباشر / 2D / 3D / حبر صيني) وتكييف زوايا اللقطات القريبة للوجه وفقًا لذلك — الأنماط ثلاثية الأبعاد/الفوتوريالية تحظر تركيبات “لقطة قريبة × من الأمام مباشرة”، وتتطلب رؤى جانبية مائلة (مباشر محدود إلى حصة 1/3، ويمكن دمج 2D في المشهد نفسه حتى 2)**. كلمات التحفيز: لوحة قصة، لوحة قصة نصية، لوحة قصة فيلمية، إنشاء لوحة قصة، ساعدني في إنشاء لوحة قصة، لوحة قصة مخرج، نص اللقطة، لوحة قصة، ربط اللقطات، ربط حركة الكاميرا، لوحة القصة، نسخة القصة، صورة لوحة قصة، لوحة جزء من لوحة قصة، سلسلة اللوحات، لوحة قصة من 4 أجزاء، لوحة قصة شبكة 4، لوحة قصة شبكة 6، لوحة قصة شبكة 9، لوحة قصة 2×2. هذه المهارة عضو في المجموعة؛ العملية الكاملة تبدأ من وحدة التحكم الرئيسية مخرج الدراما القصيرة.
