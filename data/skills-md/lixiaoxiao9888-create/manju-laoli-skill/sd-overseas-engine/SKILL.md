# sd-overseas-engine · 海外剧剧本专精引擎（赛道②）

## 一、角色定位

为**海外剧赛道**（非中文正文 / 真实地域口语 / 多语 / 方言项目）提供剧本层规则集。它**不产出**一整套新剧本流程——上游创作仍由 `sd-script-engine` 六阶段链承载；本引擎负责的是**叠加在这条链上的语言与本土化纪律**。

一句话概括本引擎存在的理由：

> **模型并不知道"当地人到底怎么说"。** 它可以写清楚可演的英语工作稿，但**不能**凭地点、姓氏、族裔、职业推断口音、换语和权限，也**不能**把模型判断冒充真人审校。本引擎的全部规则都从这个前提生长出来。

## 二、与总控和套装的关系

- **赛道来源**：本引擎只在总控〇·0 赛道分流锁**选定 ② 海外剧**时挂载。赛道未选定时不激活。
- **进入方式**：完整流程从总控 **short-drama-director** 进入；总控锁系统（〇·0 赛道 → A·模型 / B·画幅 / C·交付 / D·段缝）先锁定，再进入剧本层。
- **与其他子技能的关系**：
  - 与 `sd-script-engine` 是**叠加**关系——后者的六阶段链（来源登记 → IP 开发 → 全剧圣经 → 分集规划 → 正式剧本 → 圆桌审核）**照常执行**，本引擎在其上补语言与本土化纪律。**不替代、不覆盖**。
  - 与 `sd-decision-engine`（决策层）、`sd-asset-engine`（资产）、`sd-storyboard-engine`（分镜）、`sd-feed-engine`（投喂）、`sd-qc-engine`（质检）是**下游传递**关系——本引擎产出的语言校准状态，必须逐阶段传递（见 §九）。
- **不拥有**：投喂格式（七段式 / H3）、机检脚本、资产编号、语速自检引擎——这些权威都在总控。本引擎只在需要时**按目标语言**给出适配口径。

## 三、触发词与进入

**触发词**：海外剧、英文剧本、北美英语、美式对白、多语、方言、本土化、换语、localization、ESL、字幕。

**用户直接说触发词时**，若尚未在完整管线中，先声明一句：

> 完整制作（资产、分镜、视频）请从总控 `short-drama-director` 进入；赛道请先按总控〇·0 确认（1 国内剧 / 2 海外剧 / 3 解说类 / 4 其他）。本引擎负责海外剧的剧本层规则。

**进入前提**：已确认赛道为 ② 海外剧，且已明确**目标语言**。目标语言未知时，先停下追问——**"做英语的"与"做西语的"是两条不同的合同**。

## 四、语言与风格合同（前置 · 第一句对白前建立）

**在生成第一句对白之前**确定最小合同，字段与状态定义见 [language-contract.md](references/language-contract.md)：

```
style_mode / target_language / country_or_region / character_origin_and_current_place /
family_or_work_languages / audience / language_status / evidence_used /
prohibited_inference / protected_style / multilingual_participants /
unresolved / local_review_needed
```

四条硬铁律：

1. **合同必须在构思和写句面之前生效**——不许写完再倒填。用户明确要求"只给剧本正文"时，合同存入**交接记录**；**末尾临时补一行状态不能算已完成前置路由**。
2. **允许读者说明时**，在第一个场头前用**一句面向读者的自然语言**说明风格、校准状态、覆盖范围与证据边界；**结构化字段只用于内部评测或交接**，不塞进剧本正文。
3. **只在真正需要的项目上建立**——普通中文任务（赛道①）**不填表**；本引擎不适用于国内剧。
4. **来源与推断必须分开**——`evidence_used` 只列**实际读到**且与人物、关系、活动相近的材料；用户指定的虚构设定与现实证据分开记录。

## 五、三级校准状态与更新权限

`language_status` 只能取三项之一，**逐阶段传递，不得自行升级**：

| 状态 | 含义 | 谁能写 |
|---|---|---|
| `region_unvalidated` | 只有宽泛地点或证据不足 → 产出**清楚可演的英语工作稿**，不宣称"当地人就这么说"，不模仿强方言 | 任何阶段（无证据时的默认起点） |
| `evidence_calibrated` | 有与**人物、关系、活动**相近的语言材料 → **只使用证据支持的窄特征** | 研究 / 创作阶段补证据后 |
| `human_reviewed` | 相关地区或语言社群的**合适复核者实际审过当前版本** | **只有真实复核者审过当前版本后** |

**禁止升级项（任一条都不能证明已达到某状态）**：

- 模型生成的内容读起来很顺；
- 模型盲评 / 双模型一致；
- 网页搜索、公开视频字幕、社交平台评论；
- 演员身份、族裔、出生地的猜测；
- 舞台标注（如剧本里写 `(in Spanish)`）、英文占位释义、或另一角色"似乎接得上"。

**降级是允许的**：证据失效、复核意见与正文冲突、或身份 / 权限前提被推翻时，**主动降级**并写明原因。**升级需要可追溯的新证据或真实复核记录。**

## 六、剧本层执行规则

### 6.1 两轴对白（核心方法）

**先把两个轴分开决定，再写台词：**

- **信息立场**：直接说清 / 部分直说 / 策略性回避。
- **句法状态**：完整 / 压缩 / 被打断 / 自我修正 / 沉默。

**两条轴互不绑定**——直接可以很短，间接也可以句法完整。危急救援、命令、工作交接、边界声明、角色主动选择**可以直接且完整**；潜台词只在人物**确有**隐瞒、试探、礼貌压力或关系风险时使用。

**禁止的过度修复（四种）**：

1. 所有人都说碎句；
2. 每句都藏信息；
3. 每个地区都塞俚语；
4. 每个双语人物都随机切语。

**以及相反方向的退化**：把英语写成无地域、无职业、无关系差异的**中性功能对白**。

### 6.2 风格保护（不得被"自然口语化"打碎）

**风格化长句、礼貌威胁、重复、仪式性称呼、喜剧节奏都可能是项目选择。** 不能因为"真人不会总这样说"就把它们统一压成碎句。

完整句不等于书面，碎句也不自动等于自然。评估标准是**节奏与角色功能是否成立**，不是"像不像录音"。

### 6.3 不从身份推权限（本条与创作、评审、修复全程相关）

**地点、姓氏、外貌、族裔、年龄、职业、州省 / 城市、亲属身份，都不自动生成**：

- 口音 / 方言 / 影视刻板语汇；
- 换语（会说两种语言 ≠ 此刻应该说另一种）；
- 钥匙、进入权、系统权限、设备操作权；
- 专业资格、法定处置权。

**决定性行动必须得到可见、明确的授权**，不能用含混的画外指示补齐。任务若依赖未给出的访问权 / 知识 / 授权，让人物保留未知、改用其真实可做的动作，或**把权限本身写成阻力**。

**判据**：一句台词里的人物知识，必须能追溯到"他在场看见了什么 / 谁明确告诉过他 / 已建立的设定"。三个都没有，就是**凭空知识**。

### 6.4 单语听者边界（多语项目的安全线）

多语能力只说明"**能够**切换"，不说明"**此刻应该**切换"。每次切换都需回答五问：

1. 谁听得懂？
2. 什么触发？
3. 完成什么功能？
4. 是否排除现场某人？
5. 对关系或行动造成什么后果？

**铁律**：英语单语者在场时，涉及其**钱、货物、安全、责任、下一步行动**的关键信息，必须**立即回到共同语言**，并让被排除产生**可见反应**。没有真实关系用法或语料证据时，默认使用任务的目标语言。

### 6.5 地方细节的准入

地名、品牌、体育队、食物、热梗**只在影响选择、误解、筹码或关系时**进入台词。

**旅游清单式本地细节不能证明本土化。** 一个可被任意普通物件替换的地方标记，不能反复出现来证明地点；也不能先解除主要冲突，再用它制造较小的尾梗。**语言适配不增加额外节拍来展示本地性。**

## 七、语速与容量（海外口径）

**中文语速基准不适用于非中文正文。** 计费与时长估算按目标语言换算：

| 语言 | 基准语速 | 备注 |
|---|---|---|
| 中文 | `3.5~6 字/秒` | 见总控 `short-drama-director/references/dialogue-speed-check.md`（**本引擎不改动它**） |
| 英文 | 约 `2.2~3.0 词/秒`（≈130~180 wpm） | 快速对话可达 3.0 词/秒；**按词计，不按字计** |
| 其他语言 | 按该语言的实际音节密度换算 | 无可靠换算依据时，**标注为估算**并说明方法 |

**英文台词的时长倒推**：`镜长 ≥ 词数 ÷ 3.0 + 停顿补偿`（停顿补偿同总控口径）。**禁止**把中文的字/秒公式直接套到英文台本上。

**禁止**：用行数换算分钟；未桌读就写"精确 90 秒"。字数不是时长——出声、动作与停顿可重叠，应按实际演出进程估算。

## 九、跨阶段交接（本引擎的主要输出）

锁稿或跨阶段传递时，**必须**携带：

```
language_status: region_unvalidated | evidence_calibrated | human_reviewed
coverage: 实际覆盖的国家 / 地区 / 社区
evidence_used: 实际读到的材料（虚构设定与现实证据分列）
prohibited_inference: 本次明确禁止的外推项
protected_style: 受保护的风格特征
multilingual_participants: 谁懂哪些语言、谁在场、关键事实必须让谁听懂
unresolved / local_review_needed: 未决项与待复核项
```

**下游纪律**：

- `sd-asset-engine`：人物形象不得依据族裔 / 地域做刻板化设计；形象与角色语言能力无关。
- `sd-storyboard-engine` / `sd-feed-engine`：台词字段写**目标语言逐字稿**；字幕另标并逐字锁定；语速按本引擎 §七 口径复核。
- `sd-qc-engine`：核对**声明与正文是否相符**，**不自行升级**语言状态；制作阶段不得因"排了字幕"或"读起来顺"改写证据等级。

## 十、禁止越界

- **不**替代 `sd-script-engine` 的六阶段链，**不**另立剧本流程；
- **不**另立投喂格式、资产编号、机检脚本（权威在总控）；
- **不**在无证据时自造方言、口音、俚语、地方称呼；
- **不**把模型判断、网页检索、双模型一致写成 `human_reviewed`；
- **不**从身份标签推出语言能力、权限、资格、性格；
- **不**因"追求自然"打碎项目选择成立的完整句、冷面笑话、礼貌威胁与类型化节奏；
- **不**把某个平台的投放规范外推成所有项目格式；
- **不**越过赛道边界——国内剧任务不套本引擎。
