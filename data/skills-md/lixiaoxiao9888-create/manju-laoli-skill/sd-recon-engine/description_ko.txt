[스위트 내부 스킬 · 전체 프로세스에서 사용자는 일반적으로 직접 호출할 필요가 없으며, 요구 사항을 중앙 컨트롤러인 쇼트‑드라마‑디렉터에게 말하면 컨트롤러가 자동으로 이 스킬로 라우팅합니다] [맨 드라마 라오리 V7.4.26 스위트 · 서브스킬 · 〇·1 자료 출처 잠금 · 벤치마크 현장 조사] 자료 현장 조사 및 벤치마크 인텔리전스 엔진(라이트 버전): 사용자가 “특정 히트를 벤치마크하고 싶다”고 말하면 전체 웹(해외 사이트 포함)에서 드라마의 공개 정보를 수집하여 고정 형식의 벤치마크 인텔리전스 카드로 전달합니다. 핵심 기능 – 쇼트‑드라마 출처 단계별 목록(플랫폼 공식 순위 / 데이터 인덱스 사이트 / 업계 매체 / 소셜‑미디어 논의 / 해외 인덱스), 4단계 현장 조사(목표 설정 → 출처 설정 → 검색 → 카드), 13개 필드(양도 가능·양도 불가 포인트 포함)를 가진 벤치마크 인텔리전스 카드 템플릿, 6가지 증거 규칙(조작 금지 / 타임스탬프 표기 필수 / 출처 표기 필수 / 원본 정보와 인용 정보를 구분 / 사실과 추론을 구분 / 독립 출처 수를 인기 참고 지표로 사용). 트리거 단어: 벤치마크 히트, 파헤치다, 현장 조사, 자료 찾기, 정보 수집, 핫스팟, 히트 분석, 이것을 참조, 테마 조사, 트랙 조사, 시장 조사. 이 스킬은 스위트의 구성원이며, 전체 프로세스는 중앙 컨트롤러 쇼트‑드라마‑디렉터를 통해 시작되고, 〇·1 자료 출처 잠금은 중앙 컨트롤러에 의해 선택됩니다.
