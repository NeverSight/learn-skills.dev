틱톡/레드 프루트 트렌딩 단편 드라마 산업 스크립트 작성 슈퍼 시스템 v4.9.1. 순수 스크립트 엔진 (모든 트랙에 대한 공개 범용 버전, 제작 인계 없이). 핵심: 동적 주문형 마운팅 매트릭스 (8가지 인터랙션 모드 × 핵심 파일만 마운트, 컨텍스트 폭발 방지), 감정 계약 유닛 체인 라운드트립 방식, 40개의 트랙 장르 전체 맵 (남성 지향 12 / 여성 지향 14 / 중성 14), 여섯 가지 전형 훅 라이브러리 (돌이킬 수 없는 박탈의 핵심 트럼프 카드 포함) + 다섯 가지 주요 파편 공식, A–I 9유형 트위스트 기술 회전 매트릭스 + 온‑콜드 원장 레이어링, 세 가지 길이 단계 (표준 90–120초 / 본문 480–850자; 장편 150–195초 유연 / 820–1,400자; 만화 스타일 60–90초 / 330–620자), 단일 에피소드 15초 기어‑시프트 네 비트 진행표 (관객 끌어오기 → 최전선 충돌 → 카드 뒤집기 공개 → 사후 훅), 세 가지 주요 시각 앵커가 있는 강한 시각 지원 (매 2–4문장마다 강한 시각 △ 삽입, E24 블록은 잡담 붕괴 / E26 블록은 비효율적 마이크로 행동), 평이한 언어 동일 라운드 직접 전달 및 빠‑느린 속도 규칙 (증거 + 결론을 같은 라운드에 명확히 / 설정 단어를 자연스러운 문장으로 번역, E25 블록은 수수께끼/암호 슬랭 금지), “유사성, 동일성 아님” 3계층 추상 재작성 방법 (금지된 외피 단어 제거 → 드라마 공식 정제 → 차원 교차 스킨 스와프), 기간 변환 앵커 (작성 시 목표 말 속도 4.5자/초 + 검증 하한 4.5자/초로 거짓 주장 방지), 15초 윈도우 ≤95자 제작 측 검증, 행동 구간 ≤40자 소프트 제약, 대사/행동 골든 비율 25%–70%, 첫 세 에피소드 비트 카드, 네 가지 유료벽 변형, 에피소드 간 연속성 원장, 웹소설 변환 파이프라인, 캐릭터 바이블, 드라마 공예 레이어, 독백 및 보이스오버를 위한 제어 절차, 표현 구문 사양 (시각 용어 | 톤 단어), 리뷰 및 이슈 수정 카드, 보호용 반예시 수집, 방송 규정 제16조에 따른 11가지 컴플라이언스 레드라인, 계층별 스크립트 자동 검사 (E1–E26) + 전드라마 원장 자동 검사 (S1–S8). 트리거: 단편 드라마 작성 / 단편 드라마 개요 / 프로젝트 시작 / 체크포인트 / 에피소드 분할 / 장편 작성 / 스크립트 닥터 / 파인 튜닝 / 내면 독백 / 보이스오버 / 오프스크린 내레이션 / 빠른 단편 드라마 / 컴플라이언스 리뷰 / 지속적 작성.
