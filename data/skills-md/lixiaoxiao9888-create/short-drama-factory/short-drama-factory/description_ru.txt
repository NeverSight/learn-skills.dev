Douyin/Red Fruit бестселлер коротких драм — индустриальная система сценарного письма супер‑система v4.9.1. Чистый движок сценариев (универсальная версия для всех дорожек, без привязки к производству). Ядро: динамическая монтировочная матрица по запросу (8 режимов взаимодействия × только монтировать core‑файлы, предотвращая всплеск контекста), цепочка единиц эмоционального контракта метод «вперёд‑назад», полная карта из 40 жанров дорожек (мужские‑ориентированные 12 / женские‑ориентированные 14 / нейтральные 14), библиотека из шести «мама‑типов» крючков (включая необратимые core‑туповые крючки) плюс пять основных формул сегментов, матрица вращения из девяти категорий приёмов обратного хода A–I + слой горячих/холодных реестров, три уровня длительности (стандартный 90–120 с / основной текст 480–850 символов; длинный 150–195 с гибко / 820–1400 символов; комический 60–90 с / 330–620 символов), таблица прогрессии четырёх тактов за эпизодный 15‑секундный переключатель скоростей (захват внимания → прямое противостояние → переворот карты‑разгадки → последующий эффект‑крючок), сильная визуальная поддержка с тремя основными визуальными якорями (вставлять сильный визуальный △ каждые 2–4 предложения, E24 блокирует перебои в чате / E26 блокирует неэффективные микродействия), простая языковая доставка в том же раунде с правилом быстрый‑медленный темп (доказательство + вывод уточняются в том же раунде / слова‑установки переводятся в естественные предложения, E25 блокирует загадки и сленг), метод имитации трёхслойной абстракции «похожесть‑не‑форма» (снять запрещённые внешние слова → уточнить драматическое уравнение → мультиверсионная смена «кожи»), анкеры конвертации длительности (целевой темп речи 4,5 симв./с для написания + нижняя граница проверки 4,5 симв./с, чтобы избежать ложных меток), проверка со стороны производства: 15‑секундное окно ≤ 95 символов, мягкое ограничение на одиночный сегмент ≤ 40 символов, золотое соотношение диалога/действия 25 %–70 %, карточки битов первых трёх эпизодов, четыре варианта платного доступа, реестр преемственности между эпизодами, конвейер адаптации веб‑новеллы, библия персонажей, слой драматургии, контролируемые процедуры для монолога и озвучивания, спецификации выражений‑фраз (визуальные слова | модальные частицы), карточки обзора и исправления проблем, набор защитных контр‑примеров, одиннадцать линий соответствия красных линий Регламента вещания № 16, многоуровневые автоматические проверки сценария (E1–E26) + полные автоматические проверки реестра (S1–S8). Триггеры: написать короткую драму / контур короткой драмы / инициация проекта / контрольная точка / секционирование эпизода / написание длинной формы / скрипт‑доктор / тонкая настройка / внутренний монолог / нарратив / озвучка вне кадра / ультра‑быстрая короткая драма / проверка соответствия / непрерывное написание.
