製作短篇產品／技能動態影片（10–30 秒，旁白功能示範最長約 60 秒），以高階上市短片的手法——動感排版、以真實 UI 為素材、手部觸發每個反應、節拍相互銜接而非互相取代、僅在有意義的地方使用硬切——不使用 HyperFrames 或 Remotion。單一 HTML 組合，所有數值皆為時間的純函數，根據測量過的動作庫（彈簧、進場、承接、接觸、攝影機）建構，逐格渲染並加入真實快門動態模糊（1080p30 草稿，4K60 最終），搭配同一空間的合成音效，並讓預言者在有人觀看前即失敗於投影片播放。用於 做個動效短片／產品宣傳片／介紹影片／發布影片／15 秒 launch video／給 skill 或 app 做個影片／promo／teaser，將真實書頁或螢幕錄製轉為剪輯，製作產品功能示範（產品功能演示／功能展示動效），將 UI 從截圖以 HTML 重建而非錄製螢幕（不錄屏／復刻介面／截圖還原 UI），製作配有旁白與字幕的剪輯（配音／字幕／換配音）以及同一影片的其他語言版本（日語版／多語言／本地化），用於添加動效詞彙（動效庫／轉場／銜接），以及審核為何動態影片看起來像投影片（像 PPT／沒節奏／一個一個展示／轉場生硬）。
