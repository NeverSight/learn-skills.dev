أنشئ مقاطع فيديو حركية قصيرة للمنتج أو المهارة (10–30 ثانية، عروض مميزات مُسَلَّطة تصل إلى حوالي 60 ثانية) بالطريقة التي تُصنع بها مقاطع الإطلاق عالية الجودة — نمط حركي، واجهة مستخدم حقيقية كمادة، يد تُحدث كل رد فعل، إيقاعات تنتقل إلى بعضها بدلاً من استبدال بعضها، قطع حادة فقط عندما يكون لها معنى — دون استخدام HyperFrames أو Remotion. تركيبة HTML واحدة تكون فيها كل قيمة دالة نقية للوقت، مبنية من مكتبة حركات مقاسة (نُسَّات، دخول، حمل، تواصل، كاميرا)، تُرَسَّم إطارًا بإطار مع ضبابية حركة عدسة حقيقية (مسودات 1080p30، نهائي 4K60)، مع مؤثرات صوتية مُصَنَّعة تشارك مساحة واحدة وoracle يفشل عرض الشرائح قبل أن يحتاج إنسان لمشاهدته. استخدم لـ عمل مقطع تحريك قصير / فيديو ترويج للمنتج / فيديو تقديم / فيديو نشر / فيديو إطلاق 15 ثانية / لإنشاء فيديو للمهارة أو التطبيق / ترويج / دعابة، لتحويل الصفحات الحقيقية أو تسجيلات الشاشة إلى مقطع مقطوع، لعروض مميزات المنتج (عرض ميزات المنتج / عرض تأثيرات الميزة) حيث يُعاد بناء الواجهة في HTML من لقطات الشاشة بدلاً من التسجيل (دون تسجيل الشاشة / إعادة بناء الواجهة / استعادة الواجهة من لقطات الشاشة)، للمقاطع المروية مع التعليق الصوتي والترجمات (تعليق صوتي / ترجمة / تغيير التعليق الصوتي) ولنفس الفيلم بلغات أخرى (الإصدار الياباني / متعدد اللغات / التوطين)، لإضافة مفردات الحركة (مكتبة تأثيرات / انتقالات / وصلات)، وللتدقيق لماذا يبدو فيديو الحركة كعرض شرائح (مثل PPT / بدون إيقاع / عرض واحد تلو الآخر / انتقالات صلبة).
