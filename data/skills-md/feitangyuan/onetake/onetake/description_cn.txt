制作短小的产品/技能动效视频（10–30 秒，配有旁白的功能演示可达约 60 秒），采用高端发布短片的制作手法——动感排版、以真实 UI 为素材、手部触发每一次交互、节拍相互衔接而非相互取代、只有在有意义的地方才使用硬切——且不使用 HyperFrames 或 Remotion。整个作品为单一的 HTML 组合体，所有数值均为时间的纯函数，由测量好的动作库（弹簧、进入、承接、接触、摄像机）构建，逐帧渲染并加入真实快门运动模糊（1080p30 草稿，4K60 成片），配以合成音效共享同一声场，并设有在观众观看前即失效的幻灯片预言机。适用于 做个动效短片 / 产品宣传片 / 介绍视频 / 发布视频 / 15 秒 launch video / 给 skill 或 app 做个视频 / promo / teaser，适用于将真实页面或屏幕录制转化为剪辑，适用于产品功能演示（产品功能演示 / 功能展示动效），在该情境下 UI 通过截图在 HTML 中重建而非录屏（不录屏 / 复刻界面 / 截图还原 UI），适用于配有配音和字幕的旁白剪辑（配音 / 字幕 / 换配音），以及同一影片的多语言版本（日语版 / 多语言 / 本地化），适用于添加动效词库（动效库 / 转场 / 衔接），也适用于审计动效视频为何像 PPT（像 PPT / 没节奏 / 一个一个展示 / 转场生硬）。
