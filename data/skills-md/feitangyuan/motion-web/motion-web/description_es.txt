Diseña y construye sitios web creativos centrados en el movimiento: diseño de página (estructura, escala tipográfica, paleta, espaciado) más coreografía de interacciones: animación al hacer scroll, Framer Motion, GSAP y 3D ligero mediante Three.js/R3F. Úsalo para landing pages animadas, portafolios creativos, exhibiciones de productos, escenas WebGL ligeras y auditorías de movimiento. También sirve para afinar la sensación de interacción (手感差/太生硬/不跟手), replicar movimiento de un video o referencia URL (复刻), crear profundidad 3D a partir de imágenes planas (伪3D/抠图), diagnosticar segmentos muertos de scroll‑timeline, mezclar audio de escena, auditar la descubribilidad (点不开/没人会发现), construir sondas de verificación sin cabeza, o corregir una página que se mueve bien pero parece generada (不好看/像AI做的/没设计感). Igualmente para construir un sitio completo desde cero (从0到1做个网页/落地页/官网/作品集): elección de stack, secciones y copy, componentes (导航/hero/表单/卡片/定价表) y pulido de producción (favicon/OG/404/空状态/暗色模式). No es para paneles de control, UI de administración o generación completa de escenas 3D.
