以运动为首的创意网站设计与构建——页面设计（结构、排版尺度、配色、间距）加上交互编排：滚动动画、Framer Motion、GSAP，以及通过 Three.js/R3F 实现的轻量级 3D。用于动画落地页、创意作品集、产品展示、WebGL‑lite 场景和运动审计。当需要调校交互手感（手感差/太生硬/不跟手）、从视频或 URL 参考复刻运动、从平面图像资产构建 3D 深度（伪3D/抠图）、诊断失效的 scroll‑timeline 拉伸、混音场景音频、审查可发现性（点不开/没人会发现）、构建无头验证探针，或修复页面虽动感良好但看起来是生成的（不好看/像 AI 做的/没设计感）时也适用。同样适用于从零到一打造完整网站（从0到1做个网页/落地页/官网/作品集）：技术栈选择、章节与文案、组件（导航/hero/表单/卡片/定价表），以及生产级打磨（favicon/OG/404/空状态/暗色模式）。不适用于仪表盘、后台 UI 或完整的 3D 场景生成。
