تحليل صور المستندات (الشرائح، المسحات، النماذج، الجداول، المخططات، الصفحات المصوَّرة) إلى صيغة markdown منظمة عبر نقطة النهاية المكوَّنة document-parse، التي تخدم عائلة نماذج nemotron-parse. يُستخدم كلما طلب المستخدم استخراج أو OCR أو تحليل نص من صورة مستند أو صفحة مصورة؛ أو لتحليل دفعة من دليل يحتوي على صور صفحات؛ أو لتشغيل تحليل المستندات عبر بوابة أو واجهة برمجة تطبيقات التحليل؛ أو لتدقيق/التحقق من دقة مخرجات التحليل مقارنةً بالصورة الأصلية. العبارات المشغّلة: "parse this document/slide/image/page"، "extract text from this image"، "OCR these pages"، "document parsing"، "nemotron-parse"، "parse through the router"، "audit this parse output"، "transcribe this slide". لا تُستَخدم لتدقيق واجهات المستخدم المصورة أو تكوين الأعمال الفنية (مسار visual-judge / image-analysis يتولى ذلك)، ولا لتفريغ الصوت/الفيديو، ولا لإدخال PDF كملف ثنائي — العائلة تقبل صورة صفحة واحدة مصورة لكل استدعاء، لذا يجب تحويل ملفات PDF إلى صور صفحات أولاً.
