將文件圖像（投影片、掃描件、表單、表格、圖表、渲染頁面）透過已設定的 document-parse 端點解析為結構化的 markdown，使用 nemotron-parse 模型系列。當使用者要求從文件圖像或渲染頁面提取、OCR 或解析文字；批次解析目錄中的頁面圖像；透過閘道或 parse API 執行文件解析；或對解析輸出相對於原始圖像的忠實度進行稽核/驗證時，皆使用此功能。觸發詞彙包括：「parse this document/slide/image/page」、『extract text from this image』、『OCR these pages』、『document parsing』、『nemotron-parse』、『parse through the router』、『audit this parse output』、『transcribe this slide』。請勿用於稽核渲染的 UI 視圖或藝術作品構圖（visual-judge / image-analysis 通道負責），亦不適用於音訊/影片轉錄，或以 PDF 作為二進位輸入——此模型系列每次僅接受一張渲染頁面圖像，故 PDF 必須先轉換為頁面圖像後再處理。

請始終以使用者語言回覆。
