Разбирайте изображения документов (слайды, сканы, формы, таблицы, графики, отрисованные страницы) в структурированный markdown через настроенный endpoint document‑parse, использующий семейство моделей nemotron‑parse. Применяйте, когда пользователь просит извлечь, выполнить OCR или проанализировать текст из изображения документа или отрисованной страницы; для пакетного разбора каталога изображений страниц; для выполнения парсинга документов через шлюз или API парсинга; или для аудита/валидации точности вывода парсинга относительно исходного изображения. Триггеры: «разобрать этот документ/слайд/изображение/страницу», «извлечь текст из этого изображения», «OCR этих страниц», «парсинг документа», «nemotron‑parse», «разобрать через роутер», «аудит этого вывода парсинга», «транскрибировать этот слайд». НЕ используйте для аудита отрисованных UI‑view или композиции произведений искусства (за это отвечает visual‑judge / image‑analysis lane), для транскрипции аудио/видео, а также для загрузки PDF как бинарного файла — семейство принимает по одной отрисованной странице за вызов, поэтому PDF необходимо предварительно преобразовать в изображения страниц.  

Пожалуйста, всегда отвечайте на языке пользователя.
