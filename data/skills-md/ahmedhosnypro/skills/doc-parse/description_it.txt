Analizza le immagini di documenti (diapositive, scansioni, moduli, tabelle, grafici, pagine renderizzate) in markdown strutturato tramite l'endpoint document-parse configurato, utilizzando la famiglia di modelli nemotron-parse. Usa ogni volta che l'utente chiede di estrarre, fare OCR o analizzare il testo da un'immagine di documento o da una pagina renderizzata; per l'analisi batch di una directory di immagini di pagine; per eseguire il parsing del documento tramite un gateway o un'API di parsing; o per verificare/validare la fedeltà dell'output del parsing rispetto all'immagine di origine. Trigger: “analizza questo documento/diapositiva/immagine/pagina”, “estrai il testo da questa immagine”, “OCR queste pagine”, “parsing del documento”, “nemotron-parse”, “analizza tramite il router”, “verifica questo output di parsing”, “trascrivi questa diapositiva”. NON utilizzare per audit di viste UI renderizzate o composizione di opere d'arte (la corsia visual-judge / image-analysis se ne occupa), per trascrizione audio/video, o per l’ingestione di PDF come binario — la famiglia accetta un’immagine di pagina renderizzata per chiamata, quindi i PDF devono essere prima convertiti in immagini di pagina.
