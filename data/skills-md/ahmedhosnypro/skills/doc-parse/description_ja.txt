設定された document-parse エンドポイントを介して、ドキュメント画像（スライド、スキャン、フォーム、テーブル、チャート、レンダリングされたページ）を構造化された Markdown に変換し、nemotron-parse モデルファミリーを提供します。ユーザーがドキュメント画像やレンダリングページからテキストの抽出、OCR、またはパースを求めたとき、ページ画像のディレクトリをバッチでパースしたいとき、ゲートウェイや parse API 経由でドキュメントパースを実行したいとき、あるいはパース結果の忠実度を元画像と照合して監査・検証したいときに使用します。トリガー例：「このドキュメント/スライド/画像/ページをパースして」「この画像からテキストを抽出して」「これらのページを OCR して」「ドキュメントパース」「nemotron-parse」「ルーター経由でパース」「このパース結果を監査して」「このスライドを文字起こしして」などです。レンダリングされた UI ビューやアートワークの構成の監査（visual-judge / image-analysis が担当）、音声・動画の文字起こし、PDF をバイナリとして直接取り込む用途には使用しないでください。ファミリーは呼び出しごとに 1 ページのレンダリング画像を受け取るため、PDF は事前にページ画像に変換する必要があります。
