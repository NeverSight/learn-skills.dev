Analiza imágenes de documentos (diapositivas, escaneos, formularios, tablas, gráficos, páginas renderizadas) en markdown estructurado mediante el endpoint document-parse configurado, utilizando la familia de modelos nemotron-parse. Úsalo siempre que el usuario solicite extraer, hacer OCR o analizar texto de una imagen de documento o página renderizada; para analizar en lote un directorio de imágenes de páginas; para ejecutar el análisis de documentos a través de un gateway o API de parse; o para auditar/validar la fidelidad de la salida del parse respecto a su imagen fuente. Disparadores: “analiza este documento/diapositiva/imagen/página”, “extrae texto de esta imagen”, “OCR estas páginas”, “análisis de documentos”, “nemotron-parse”, “analiza a través del router”, “audita esta salida de parse”, “transcribe esta diapositiva”. NO lo uses para auditar vistas UI renderizadas o composición artística (la vía visual-judge / análisis de imágenes se encarga de eso), para transcripción de audio/video, ni para ingestión de PDF como binario — la familia toma una imagen de página renderizada por llamada, por lo que los PDFs deben renderizarse a imágenes de página primero.

Por favor, responde siempre en el idioma del usuario.
