Analiza imágenes de documentos (diapositivas, escaneos, formularios, tablas, gráficos, páginas renderizadas) en markdown estructurado mediante el endpoint configurado document-parse, que utiliza la familia de modelos nemotron-parse. Utilízalo siempre que el usuario solicite extraer, hacer OCR o analizar texto de una imagen de documento o página renderizada; para analizar en lote un directorio de imágenes de páginas; para ejecutar el análisis de documentos a través de un gateway o API de parseo; o para auditar/validar la fidelidad de la salida del parseo respecto a su imagen de origen. Disparadores: "parse this document/slide/image/page", "extract text from this image", "OCR these pages", "document parsing", "nemotron-parse", "parse through the router", "audit this parse output", "transcribe this slide". NO lo uses para auditar vistas UI renderizadas o composición de obras de arte (esa tarea corresponde a la vía visual-judge / image-analysis), para transcripción de audio/video, ni para ingestión de PDF como binario; la familia procesa una sola imagen de página renderizada por llamada, por lo que los PDFs deben convertirse primero en imágenes de página.

Responde siempre en el idioma del usuario.
