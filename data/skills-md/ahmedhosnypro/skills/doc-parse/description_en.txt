Parse document images (slides, scans, forms, tables, charts, rendered pages) into structured markdown through the configured document-parse endpoint, serving the nemotron-parse model family. Use whenever the user asks to extract, OCR, or parse text from a document image or rendered page; to batch-parse a directory of page images; to run document parsing through a gateway or parse API; or to audit/validate a parse output's fidelity against its source image. Triggers: "parse this document/slide/image/page", "extract text from this image", "OCR these pages", "document parsing", "nemotron-parse", "parse through the router", "audit this parse output", "transcribe this slide". Do NOT use for auditing rendered UI views or artwork composition (the visual-judge / image-analysis lane owns that), for audio/video transcription, or for PDF-as-binary ingestion — the family takes one rendered page image per call, so PDFs must be rendered to page images first.
