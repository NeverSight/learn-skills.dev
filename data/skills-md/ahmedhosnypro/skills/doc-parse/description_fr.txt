Analysez les images de documents (diapositives, numérisations, formulaires, tableaux, graphiques, pages rendues) en markdown structuré via le point de terminaison document‑parse configuré, en utilisant la famille de modèles nemotron‑parse. Utilisez‑le chaque fois que l’utilisateur demande d’extraire, de faire de l’OCR ou d’analyser du texte à partir d’une image de document ou d’une page rendue ; pour analyser en lot le contenu d’un répertoire d’images de pages ; pour exécuter l’analyse de documents via une passerelle ou une API d’analyse ; ou pour auditer / valider la fidélité d’une sortie d’analyse par rapport à son image source. Déclencheurs : « analyser ce document/diapositive/image/page », « extraire le texte de cette image », « OCR ces pages », « analyse de document », « nemotron‑parse », « analyser via le routeur », « auditer cette sortie d’analyse », « transcrire cette diapositive ». NE PAS utiliser pour auditer les vues UI rendues ou la composition d’œuvres d’art (la voie visual‑judge / image‑analysis en est responsable), pour la transcription audio/vidéo, ou pour l’ingestion de PDF en tant que binaire — la famille prend une image de page rendue par appel, donc les PDF doivent d’abord être rendus en images de pages. Veuillez toujours répondre dans la langue de l’utilisateur.
