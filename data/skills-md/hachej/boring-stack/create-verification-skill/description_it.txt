Genera una skill di verifica locale al progetto che controlla la tua app come farebbe un utente — in qualsiasi linguaggio, framework o piattaforma. Utilizzala per /create-verification-skill, “crea una skill di controllo per questo repository”, o quando un progetto non ha un modo scriptato per dimostrare il comportamento dell'UI/CLI/servizio.

Per favore rispondi sempre nella lingua dell'utente.
