Générez une compétence de vérification locale au projet qui pilote votre application comme le fait un utilisateur — quel que soit le langage, le framework ou la plateforme. Utilisez‑la pour /create-verification-skill, « créez une compétence de contrôle pour ce dépôt », ou lorsqu’un projet ne dispose d’aucune méthode scriptée pour prouver le comportement UI/CLI/service.
