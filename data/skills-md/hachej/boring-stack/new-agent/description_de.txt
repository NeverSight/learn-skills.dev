Fügen Sie eine Funktion einer langweiligen App hinzu oder ändern Sie sie - einen Agenten, einen Auftrag, einen Chat, ein Tool, eine Ansicht oder eine Seite - und entscheiden Sie, ob Sie sie in boring.json freigeben möchten. Wird verwendet, wenn eine Aufgabe nach einem neuen Agenten oder Ausgabefeld fragt, eine Änderung an der Eingabeaufforderung, den Regeln, dem Modell oder der Ausgabe eines Agenten, einer Arbeit, die mehrere Agenten ausführt, einem Chat, einem Tool, das ein Agent oder der Hub anruft, oder einer Ansicht der Hub-Frames. Listet die zu erstellenden Dateien, die zu behaltenden Verträge, die auszuführenden Tests und den zu aktualisierenden Feature-Map-Eintrag auf.
