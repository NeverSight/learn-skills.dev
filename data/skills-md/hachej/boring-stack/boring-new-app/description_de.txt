Richten Sie ein neues App-Repository für die Boring Factory Ende-zu-Ende ein — erstellen Sie es aus der App-Vorlage (hachej/boring-app), legen Sie seine Geheimnisse und Einstellungen fest, laden Sie den Experten ein, überprüfen Sie die ersten Durchläufe und geben Sie dem Experten die nächsten Schritte. Wird verwendet, wenn der Betreuer darum bittet, eine neue App oder ein neues Repository für die Factory zu erstellen, zu booten oder einzurichten oder ein vorhandenes Repository damit zu verbinden.
