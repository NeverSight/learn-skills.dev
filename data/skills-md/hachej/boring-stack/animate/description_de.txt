Erstellen Sie eine Animation von Grund auf neu und treffen Sie die Entscheidungen in der Reihenfolge, die bestimmt, ob sie sich richtig anfühlt — sollte sie überhaupt animieren, welchen Zweck, welches Werkzeug, welche Eigenschaften, welche Kurve und Dauer, wie sie unterbricht, wie sie austritt. Schreibt die Implementierung. Verwenden Sie diese Option, wenn Sie aufgefordert werden, etwas zu animieren, Bewegung hinzuzufügen, eine Komponente lebendig zu machen oder einen Übergang zu erstellen. Für die Kritik an bestehenden Anträgen verwenden Sie Review-Animationen; für die Prüfung einer ganzen Codebasis verwenden Sie Improve-Animationen.
