Haz que una aplicación web se sienta nativa en un teléfono — los pequeños ajustes de CSS y metaetiquetas que separan “un sitio web en el navegador” de algo que parece instalado. Cubre estados hover persistentes, destellos de resaltado al tocar, el error de 100 vh, campos que hacen zoom a la página, toques con retraso, el pull‑to‑refresh que secuestra el desplazamiento, contenido bajo la muesca, pulsación larga que selecciona el texto del botón, carruseles que se desplazan en la dirección equivocada, barras de estado desajustadas y la regla de probar en hardware real. Úsalo cuando una web app se está construyendo o revisando en móvil, cuando algo “funciona en Chrome pero se siente mal en mi teléfono”, al crear una PWA, una hoja inferior, un carrusel, un diseño a pantalla completa o cualquier interacción táctil. Para animaciones usa animate; para React Native usa animate‑expo.
