Fai sentire un'app web nativa su un telefono — le piccole correzioni CSS e meta‑tag che separano “un sito web in un browser” da qualcosa che sembra installato. Include stati hover persistenti, lampeggiamenti di evidenziazione al tap, il bug dei 100 vh, input che zoomano la pagina, tocchi lenti, pull‑to‑refresh che dirotta lo scroll, contenuto sotto il notch, pressione prolungata che seleziona il testo dei pulsanti, carousel che scorrono nella direzione sbagliata, barre di stato non corrispondenti e la regola di testare su hardware reale. Da usare quando si costruisce o si revisiona un'app web su mobile, quando qualcosa “funziona in Chrome ma sembra strano sul mio telefono”, quando si crea una PWA, un bottom sheet, un carousel, un layout a schermo intero o qualsiasi interazione tattile. Per il motion usa animate; per React Native usa animate‑expo.
