Eine Web‑App auf dem Handy wie native wirken lassen – die kleinen CSS‑ und Meta‑Tag‑Fixes, die „eine Website im Browser“ von etwas, das sich installiert anfühlt, trennen. Behandelt klebende Hover‑Zustände, Tap‑Highlight‑Flashes, den 100‑vh‑Bug, Eingaben, die die Seite zoomen, verzögerte Taps, Pull‑to‑Refresh, das das Scrollen kapert, Inhalte unter der Notch, langes Drücken, das Button‑Text auswählt, Karussells, die in die falsche Richtung scrollen, nicht passende Status‑Bars und die Regel, dass man auf echter Hardware testet. Verwenden, wenn eine Web‑App für mobile Geräte gebaut oder dort geprüft wird, wenn etwas „in Chrome funktioniert, aber auf meinem Handy falsch wirkt“, beim Aufbau einer PWA, eines Bottom‑Sheets, eines Karussells, eines Vollbild‑Layouts oder jeder Touch‑Interaktion. Für Bewegungen selbst animate verwenden; für React Native animate‑expo.
