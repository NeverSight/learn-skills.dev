讓 Web 應用在手機上感受如原生應用——透過小幅的 CSS 與 meta 標籤調整，將「瀏覽器內的網站」與「安裝感」區分開來。涵蓋黏性 hover 狀態、點擊高亮閃爍、100vh 錯誤、輸入框導致頁面縮放、點擊遲緩、下拉刷新劫持捲動、內容被凹槽（notch）遮蔽、長按選取按鈕文字、輪播方向錯誤、狀態列不匹配，以及必須在實體裝置上測試的規則。適用於在行動裝置上開發或審核 Web 應用、當「在 Chrome 上正常，但在手機上感覺不對」的情況、構建 PWA、底部抽屜、輪播、全螢幕佈局或任何觸控互動時。對於動畫本身使用 animate；對於 React Native 使用 animate‑expo。
