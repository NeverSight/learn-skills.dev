Faire ressentir une application web comme native sur un téléphone — les petites corrections CSS et meta‑tags qui séparent « un site web dans un navigateur » de quelque chose qui semble installé. Couvre les états hover collants, les flashs de surbrillance au tap, le bug du 100 vh, les champs qui zooment la page, les tapotements lents, le pull‑to‑refresh qui détourne le défilement, le contenu sous l’encoche, la sélection du texte du bouton au long‑press, les carrousels qui défilent dans le mauvais sens, les barres d’état incompatibles, et la règle de tester sur du matériel réel. À utiliser lorsqu’une application web est en cours de création ou d’évaluation sur mobile, lorsqu’un élément « fonctionne dans Chrome mais semble incorrect sur mon téléphone », lors de la construction d’une PWA, d’une feuille de bas, d’un carrousel, d’une mise en page plein écran ou de toute interaction tactile. Pour le motion, utilisez animate ; pour React Native, utilisez animate‑expo.
