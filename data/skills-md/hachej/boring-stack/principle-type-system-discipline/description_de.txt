Verwenden Sie dies, wenn Sie Typen entwerfen, eine Funktionssignatur prüfen oder Code in einer beliebigen statisch typisierten Sprache schreiben. Machen Sie illegale Zustände nicht darstellbar, versehen Sie semantische Primitive mit Marken, parsen Sie externe Daten an den Grenzen, weigern Sie sich, den Compiler zu täuschen, erschöpfen Sie Varianten, leiten Sie von autoritativen Schemata ab. Bitte antworten Sie stets in der Sprache des Benutzers.
