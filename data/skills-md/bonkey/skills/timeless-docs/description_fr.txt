Améliorez la documentation et la prose des commentaires afin qu'ils décrivent directement l'état actuel du code et se lisent clairement dans un langage simple, en coupant l'historique, les transitions et les détails triviaux. Fonctionne selon deux modes : sur les modifications en cours (modifications de session, travail non validé ou différence de branche) ou sur les fichiers/dossiers nommés. À utiliser lorsque l'utilisateur souhaite nettoyer, resserrer ou améliorer des documents ou des commentaires — dans un fichier, un dossier, un projet ou dans ce qui vient d'être modifié (« ranger les commentaires dans cette différence », « nettoyer les documents que nous venons de modifier », « corriger les documents avant de les valider ») — rendre les documents plus clairs / plus concis / plus lisibles, supprimer la formulation « précédemment / maintenant / plus / migré de / au lieu de », rendre les documents intemporels ou demande d'"améliorer la prose des documents".
