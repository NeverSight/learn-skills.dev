Erstellt Cloud Storage (Google Cloud Storage, oder GCS) Buckets. Analysiert die Arbeitslast (sensible Daten, Medienhosting, Datenaufnahme, Webhosting, Archivierung, Backup, Protokollierung, Analytik, KI/ML oder allgemeine Zwecke), validiert Sicherheitseinstellungen auf Projektebene und entwirft eine standardmäßig sichere, kosteneffiziente Konfiguration (Standort, Speicherklasse, einheitlicher Bucket‑Ebene‑Zugriff, Verhinderung des öffentlichen Zugriffs, Soft‑Delete, Lebenszyklus), bevor er erstellt wird. Verwenden, wann immer ein Nutzer einen Bucket erstellen, anlegen, einrichten, bereitstellen oder hochfahren möchte oder Objekt­speicher für eine Anwendung, einen Dienst, eine Pipeline oder einen Datensatz benötigt – sogar einen „einfachen“ oder „Standard“-Bucket – oder wenn die Bucket‑Erstellung ein Schritt in einem größeren Workflow ist. Gibt die Erstellung aus oder führt sie aus über gcloud, die JSON/REST‑API, Terraform oder SDK‑Client‑Bibliotheken (C++, Java, Python, Go). Nicht für etwas anderes als das Erstellen neuer Buckets verwenden – für Uploads, Downloads, Zugriffsänderungen oder das Neukonfigurieren bestehender Buckets, verwenden Sie google-cloud-storage-basics.
