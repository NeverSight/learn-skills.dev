Crea buckets de Cloud Storage (Google Cloud Storage, o GCS). Analiza la carga de trabajo (datos sensibles, alojamiento de medios, ingestión, alojamiento web, archivado, copias de seguridad, registro, análisis, IA/ML o uso general), valida la configuración de seguridad a nivel de proyecto y diseña una configuración segura por defecto y rentable (ubicación, clase de almacenamiento, acceso uniforme a nivel de bucket, prevención de acceso público, eliminación suave, ciclo de vida) antes de crearla. Úsalo siempre que un usuario quiera crear, hacer, configurar, aprovisionar o lanzar un bucket, o necesite almacenamiento de objetos para una aplicación, servicio, canal de datos o conjunto de datos, incluso un bucket “simple” o “predeterminado”, o cuando la creación del bucket sea un paso dentro de un flujo de trabajo más amplio. Genera o ejecuta la creación mediante gcloud, la API JSON/REST, Terraform o las bibliotecas cliente del SDK (C++, Java, Python, Go). No lo uses para nada más que crear nuevos buckets; para cargas, descargas, cambios de acceso o reconfiguración de buckets existentes, utiliza google‑cloud‑storage‑basics. Por favor, responde siempre en el idioma del usuario.
