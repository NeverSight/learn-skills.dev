يُنشئ دلّاحات تخزين سحابي (Google Cloud Storage، أو GCS). يحلّل عبء العمل (البيانات الحساسة، استضافة الوسائط، الاستيعاب، استضافة الويب، الأرشفة، النسخ الاحتياطية، السجلات، التحليلات، الذكاء الاصطناعي/التعلم الآلي، أو الاستخدام العام)، يتحقق من إعدادات الأمان على مستوى المشروع، ويصمم تكوينًا آمنًا بشكل افتراضي وفعّال من حيث التكلفة (الموقع، فئة التخزين، الوصول الموحد على مستوى الدلو، منع الوصول العام، الحذف الناعم، دورة الحياة) قبل إنشائه. يُستخدم كلما أراد المستخدم إنشاء، صنع، إعداد، توفير، أو تشغيل دلو، أو يحتاج إلى تخزين كائنات لتطبيق، خدمة، خط أنابيب، أو مجموعة بيانات — حتى "دلو بسيط" أو "دلو افتراضي"، أو عندما يكون إنشاء الدلو خطوةً واحدة في سير عمل أكبر. يُخرج أو ينفّذ الإنشاء عبر gcloud، واجهة برمجة التطبيقات JSON/REST، Terraform، أو مكتبات عميل SDK (C++، Java، Python، Go). لا تُستخدم إلا لإنشاء دلّاءات جديدة — للتحميلات، التنزيلات، تغييرات الوصول، أو إعادة تكوين الدلّاءات القائمة، استخدم google-cloud-storage-basics.
