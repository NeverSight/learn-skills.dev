创建 Cloud Storage（Google Cloud Storage，简称 GCS）存储桶。分析工作负载（敏感数据、媒体托管、数据摄取、网站托管、归档、备份、日志、分析、AI/ML 或通用用途），验证项目级安全设置，并在创建之前设计默认安全、成本效益高的配置（位置、存储类别、统一桶级访问、公共访问防护、软删除、生命周期）。在用户想要创建、生成、设置、配置或启动存储桶，或需要为应用、服务、流水线或数据集提供对象存储——即使是“简单”或“默认”存储桶，或存储桶创建是更大工作流中的一步时使用。通过 gcloud、JSON/REST API、Terraform 或 SDK 客户端库（C++、Java、Python、Go）输出或执行创建。不要用于除创建新存储桶之外的任何操作——对上传、下载、访问更改或重新配置现有存储桶，请使用 google-cloud-storage-basics。
