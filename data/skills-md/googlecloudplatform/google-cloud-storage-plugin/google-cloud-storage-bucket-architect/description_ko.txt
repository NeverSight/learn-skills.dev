Cloud Storage(Google Cloud Storage, 또는 GCS) 버킷을 생성합니다. 워크로드(민감한 데이터, 미디어 호스팅, 인제션, 웹 호스팅, 아카이빙, 백업, 로깅, 분석, AI/ML, 또는 일반 목적)를 분석하고, 프로젝트 수준 보안 설정을 검증한 뒤, 버킷을 만들기 전에 위치, 스토리지 클래스, 일관된 버킷 수준 액세스, 공개 액세스 방지, 소프트 삭제, 라이프사이클 등 기본적으로 보안이 확보되고 비용 효율적인 구성을 설계합니다. 사용자가 버킷을 만들거나, 설정하거나, 프로비저닝하거나, 스핀업하려는 경우, 혹은 애플리케이션, 서비스, 파이프라인, 데이터셋을 위한 객체 스토리지가 필요할 때(“단순” 또는 “기본” 버킷이라 할지라도) 또는 버킷 생성이 더 큰 워크플로우의 한 단계인 경우에 사용합니다. gcloud, JSON/REST API, Terraform, SDK 클라이언트 라이브러리(C++, Java, Python, Go)를 통해 생성 작업을 출력하거나 실행합니다. 새 버킷을 생성하는 경우 외에는 사용하지 마세요—업로드, 다운로드, 접근 권한 변경, 기존 버킷 재구성 등은 google-cloud-storage-basics를 사용하십시오.
