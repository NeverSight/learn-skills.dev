Cloud Storage（Google Cloud Storage、または GCS）のバケットを作成します。ワークロード（機密データ、メディアホスティング、取り込み、Web ホスティング、アーカイブ、バックアップ、ロギング、分析、AI/ML、または汎用）を分析し、プロジェクトレベルのセキュリティ設定を検証したうえで、作成前にデフォルトで安全かつコスト効果の高い構成（リージョン、ストレージクラス、統一バケットレベルアクセス、パブリックアクセス防止、ソフトデリート、ライフサイクル）を設計します。ユーザーがバケットの作成、生成、セットアップ、プロビジョニング、または起動を希望する場合、アプリ・サービス・パイプライン・データセットのオブジェクトストレージが必要な場合、たとえ「シンプル」や「デフォルト」バケットであっても、あるいはバケット作成が大規模ワークフローの一ステップである場合に使用してください。作成は gcloud、JSON/REST API、Terraform、または SDK クライアントライブラリ（C++、Java、Python、Go）を通じて出力または実行します。新しいバケットの作成以外の用途（アップロード、ダウンロード、アクセス変更、既存バケットの再構成）には google-cloud-storage-basics を使用してください。
