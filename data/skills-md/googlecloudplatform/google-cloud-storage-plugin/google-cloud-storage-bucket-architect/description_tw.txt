建立 Cloud Storage（Google Cloud Storage，簡稱 GCS）儲存桶。分析工作負載（敏感資料、媒體託管、資料攝取、網站託管、歸檔、備份、日誌、分析、AI/ML 或一般用途），驗證專案層級的安全設定，並於建立前設計預設安全、具成本效益的配置（位置、儲存類別、統一存儲桶層級存取、公共存取防護、軟刪除、生命週期）。在使用者需要建立、製作、設定、配置或啟動儲存桶，或需要為應用程式、服務、管線或資料集提供物件儲存時使用——即使是「簡單」或「預設」的儲存桶，或當儲存桶建立是更大工作流程中的一步。透過 gcloud、JSON/REST API、Terraform 或 SDK 客戶端程式庫（C++、Java、Python、Go）輸出或執行建立。請僅用於建立新儲存桶——上傳、下載、存取變更或重新配置既有儲存桶請使用 google-cloud-storage-basics。
