Crée des buckets Cloud Storage (Google Cloud Storage, ou GCS). Analyse la charge de travail (données sensibles, hébergement de médias, ingestion, hébergement web, archivage, sauvegarde, journalisation, analytique, IA/ML ou usage général), valide les paramètres de sécurité au niveau du projet et conçoit une configuration sécurisée par défaut et économique (emplacement, classe de stockage, accès uniforme au niveau du bucket, prévention d’accès public, suppression douce, cycle de vie) avant de le créer. À utiliser chaque fois qu’un utilisateur veut créer, fabriquer, configurer, provisionner ou lancer un bucket, ou a besoin de stockage d’objets pour une application, un service, un pipeline ou un jeu de données — même un bucket « simple » ou « par défaut », ou lorsque la création du bucket représente une étape d’un flux de travail plus large. Génère ou exécute la création via gcloud, l’API JSON/REST, Terraform ou les bibliothèques clientes SDK (C++, Java, Python, Go). Ne l’utilisez pas pour autre chose que la création de nouveaux buckets — pour les téléchargements, les transferts, les modifications d’accès ou la reconfiguration de buckets existants, utilisez google-cloud-storage-basics.
