Crea bucket di Cloud Storage (Google Cloud Storage, o GCS). Analizza il carico di lavoro (dati sensibili, hosting multimediale, ingestione, hosting web, archiviazione, backup, logging, analytics, AI/ML o uso generale), valida le impostazioni di sicurezza a livello di progetto e progetta una configurazione sicura per impostazione predefinita, economica (posizione, classe di archiviazione, accesso uniforme a livello di bucket, prevenzione dell'accesso pubblico, cancellazione soft, ciclo di vita) prima di crearla. Usalo ogni volta che un utente vuole creare, realizzare, impostare, provisionare o lanciare un bucket, o ha bisogno di storage di oggetti per un’app, servizio, pipeline o dataset — anche per un bucket “semplice” o “predefinito”, o quando la creazione del bucket è un passaggio in un flusso di lavoro più ampio. Produce o esegue la creazione tramite gcloud, l’API JSON/REST, Terraform o le librerie client SDK (C++, Java, Python, Go). Non usarlo per altro che creare nuovi bucket — per upload, download, modifiche di accesso o riconfigurazione di bucket esistenti, usa google‑cloud‑storage‑basics.
