Choisissez les bibliothèques d'IA JavaScript et TypeScript actuelles et maintenues. À utiliser avant d'ajouter, de modifier, de mettre à niveau ou de recommander un package d'IA dans un projet JS/TS : les SDK de modèles (OpenAI, Anthropic, Gemini), le SDK d'IA Vercel, les cadres d'agents et de flux de travail (Mastra, LangGraph, LangChain.js), les serveurs et clients MCP, les bases de données RAG et vectorielles, les intégrations et le ML dans le navigateur (Transformers.js, TensorFlow.js, WebLLM).
