Выполняет структурированный, всесторонний обзор кода в изменениях git.  
Автоматически определяет стек и архитектуру, применяет соответствующие правила, специфичные для стека/шаблона, и сообщает о находках по уровню тяжести.  
Использовать, когда пользователь запускает /code-review, /review-pr или просит «провести обзор моих изменений».  

Пожалуйста, всегда отвечайте на языке пользователя.
