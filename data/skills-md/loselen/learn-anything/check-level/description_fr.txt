Déterminez ce qu’une personne peut et ne peut pas faire dans un sujet, ainsi que les raisons de chaque échec. Utilisez‑le pour les tests de placement ou de diagnostic, « quel sujet devrais‑je apprendre ensuite », pour identifier les lacunes ou les idées fausses, ou lorsqu’une personne se trompe constamment. Normalement appelé par map‑topic.
