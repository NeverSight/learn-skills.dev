Анализ стоимостного инвестирования с использованием методик Грэма (NCAV/нет‑нет/защитный инвестор) и Баффета (экономический «ров»/ROE/FCF). Охватывает диагностику отдельных акций и пакетный скрининг по критериям Грэма «сигаретный окурок» и Баффета «качественный компаундер». Выполняет согласование данных из разных отчетов перед оценкой. Данные берутся сначала из CLI акций, затем из MCP, WebSearch используется только для реальных пробелов.
