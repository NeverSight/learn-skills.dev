Создавайте пользовательские анимации аватара (сценические эмоции) для игрока в Blender на официальном риге аватара Decentraland, экспортируйте их как `_emote.glb`, проверяйте и передавайте в сцену — включая клипы только для верхней части тела (маскированные). Используйте, когда пользователь хочет кастомную эмоцию, новую анимацию аватара, анимировать игрока/аватара, заставить аватар выполнить конкретное действие (сидеть, держать карты, нести ящик, бросать, радоваться), работать с ригом аватара в Blender, создать сценическую эмоцию .glb или анимацию верхней части тела / сидения / удержания для игрока. НЕ используйте для воспроизведения анимаций, запечённых в модели (см. animations-tweens), для простого запуска уже существующих эмоций (см. player-avatar) или для анимации NPC (см. npcs).
