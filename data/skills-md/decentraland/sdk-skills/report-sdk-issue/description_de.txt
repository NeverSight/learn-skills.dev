Melde einen Decentraland‑SDK‑Fehler, eine Engine/Explorer‑Laufzeitbeschränkung oder eine Lücke in der Dokumentation an das SDK‑Team, BEVOR du einen Workaround anwendest. Nutze dies immer dann, wenn du oder der Benutzer feststellt, dass eine SDK7‑API, Komponente, der Explorer, das Creator Hub oder die `@dcl/sdk`‑Toolchain nicht wie dokumentiert funktioniert, etwas fehlt, das eine Szene vernünftigerweise benötigt, oder ein Workaround nötig wird – selbst wenn der Workaround einfach ist. Frage den Benutzer einmal pro Szene um Zustimmung, dann melde das Problem automatisch und sende dieselbe Meldung nie zweimal. Verwende dies NICHT für Fehler im eigenen Szenen‑Code des Benutzers, für Fragen zum Funktionsweise einer API oder für Probleme, die ein Skill bereits als bekannte Einschränkung dokumentiert.
