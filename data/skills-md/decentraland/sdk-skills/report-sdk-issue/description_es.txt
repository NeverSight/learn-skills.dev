Informar de un error del SDK de Decentraland, una limitación del motor/Explorador en tiempo de ejecución o una laguna en la documentación al equipo del SDK ANTES de aplicar una solución provisional. Usar siempre que tú o el usuario encuentren que una API de SDK7, un componente, el Explorador, el Creator Hub o la cadena de herramientas `@dcl/sdk` no se comporta como está documentado, le falta algo que una escena razonablemente necesita, o obliga a una solución provisional — incluso cuando la solución es fácil. Preguntar al usuario su consentimiento una vez por escena, luego reportar automáticamente y nunca enviar el mismo problema dos veces. NO usar para errores en el código propio de la escena del usuario, para preguntas sobre cómo funciona una API, o para problemas que una skill ya documenta como una limitación conocida.

Por favor, responde siempre en el idioma del usuario.
