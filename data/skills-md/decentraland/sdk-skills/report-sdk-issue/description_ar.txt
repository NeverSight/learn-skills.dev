أبلغ عن خطأ في SDK الخاص بـ Decentraland أو قيود وقت تشغيل المحرك/Explorer أو فجوة في الوثائق إلى فريق SDK قبل تطبيق حل مؤقت له. استخدم ذلك كلما وجدت أنت أو المستخدم أن API من SDK7 أو مكوّنًا أو Explorer أو Creator Hub أو سلسلة أدوات `@dcl/sdk` لا تعمل كما هو موثَّق، أو يفتقد شيئًا يلزم المشهد بشكل معقول، أو يفرض حلاً مؤقتًا — حتى عندما يكون الحل المؤقت سهلًا. اطلب موافقة المستخدم مرة واحدة لكل مشهد، ثم قم بالإبلاغ تلقائيًا ولا ترسل نفس المشكلة مرتين. لا تُستخدم لهذه الأخطاء في شفرة المشهد الخاصة بالمستخدم، أو لأسئلة حول كيفية عمل API، أو للمشكلات التي يوثقها النظام بالفعل كقيد معروف.
