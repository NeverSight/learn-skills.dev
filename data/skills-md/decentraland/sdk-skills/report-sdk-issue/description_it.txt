Segnala un bug del Decentraland SDK, una limitazione del runtime engine/Explorer o una lacuna nella documentazione al team SDK PRIMA di applicare una soluzione alternativa. Usa questa procedura ogni volta che tu o l'utente riscontrate che un'API SDK7, un componente, l'Explorer, il Creator Hub o la toolchain `@dcl/sdk` non si comporta come documentato, manca di qualcosa di ragionevolmente necessario per una scena o costringe a una soluzione alternativa — anche quando la soluzione è semplice. Chiedi all'utente il consenso una sola volta per scena, quindi segnala automaticamente e non inviare mai lo stesso problema due volte. NON usarla per bug nel codice della scena dell'utente, per domande sul funzionamento di un'API o per problemi che una skill già documenta come limitazione nota.

Rispondi sempre nella lingua dell'utente.
