Signalez un bug du SDK Decentraland, une limitation du moteur/Explorateur à l’exécution, ou une lacune de documentation à l’équipe du SDK AVANT d’appliquer une solution de contournement. Utilisez-le chaque fois que vous ou l’utilisateur constatez qu’une API SDK7, un composant, l’Explorer, le Creator Hub ou la chaîne d’outils `@dcl/sdk` ne se comporte pas comme documenté, qu’il manque quelque chose dont une scène a raisonnablement besoin, ou qu’il impose une solution de contournement — même lorsque celle‑ci est simple. Demandez le consentement de l’utilisateur une fois par scène, puis signalez automatiquement et n’envoyez jamais le même problème deux fois. N’UTILISEZ PAS cet outil pour les bugs dans le code de la scène de l’utilisateur, pour des questions sur le fonctionnement d’une API, ou pour des problèmes que la compétence documente déjà comme une limitation connue.

Veuillez toujours répondre dans la langue de l’utilisateur.
