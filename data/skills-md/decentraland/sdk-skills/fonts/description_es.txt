Fuentes para texto en escenas de Decentraland SDK7: las tres caras integradas y las fuentes TTF personalizadas enviadas con la escena (`fontSrc`) en TextShape, UiText, Label, Button, Input y Dropdown. Se utiliza cuando el usuario quiere un tipo de letra personalizado, de marca o temático, quiere cambiar la fuente del texto 3D o de la interfaz de usuario, quiere enviar un .ttf con una escena o pregunta por qué no se muestra una fuente personalizada. NO LO utilice para el diseño de texto, el tamaño o la estructura de la interfaz de usuario (consulte build-ui) o para colocar texto 3D en el mundo (consulte renderizado avanzado).
