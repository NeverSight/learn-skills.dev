الخطوط للنص في مشاهد Decentraland SDK7 — الوجوه المدمجة الثلاثة والخطوط المخصصة بصيغة TTF التي تُشحن مع المشهد (`fontSrc`) على TextShape و UiText و Label و Button و Input و Dropdown. يُستخدم عندما يرغب المستخدم في خط مخصص أو علامة تجارية أو نمط معين، أو يرغب في تغيير خط النص ثلاثي الأبعاد أو واجهة المستخدم، أو يرغب في تضمين ملف .ttf مع المشهد، أو يسأل لماذا لا يظهر الخط المخصص. لا يُستخدم لتخطيط النص أو حجمه أو بنية واجهة المستخدم (انظر build‑ui) أو لوضع نص ثلاثي الأبعاد في العالم (انظر advanced‑rendering).

يرجى دائمًا الرد بلغة المستخدم.
