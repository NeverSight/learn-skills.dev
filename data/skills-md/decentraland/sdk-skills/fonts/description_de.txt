Schriftarten für Text in Decentraland SDK7-Szenen — die drei integrierten Gesichter und benutzerdefinierten TTF-Schriftarten, die mit der Szene (`fontSrc`) auf TextShape, UiText, Label, Button, Input und Dropdown ausgeliefert werden. Verwenden, wenn der Benutzer eine benutzerdefinierte, gebrandete oder thematische Schriftart wünscht, die Schriftart von 3D- oder UI-Text ändern möchte, eine .ttf mit einer Szene versenden möchte oder fragt, warum eine benutzerdefinierte Schriftart nicht angezeigt wird. Verwenden Sie ES NICHT für Textlayouts, Größen oder UI-Strukturen (siehe Build-ui) oder zum Platzieren von 3D-Text in der Welt (siehe Advanced-Rendering).
