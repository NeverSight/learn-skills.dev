Decentraland シーンのエンティティ、コンポーネント、スマート アイテム、シーン設定は、assets/scene/main.composite を手動で編集するのではなく、Creator Hub の MCP サーバーを通じてライブで編集できます。 Creator Hub でシーンが開いているとき、セッションで「mcp__creator-hub__*」ツール (scene_state、create_entity、set_component、place_smart_item など) が使用できるとき、ユーザーが Creator Hub AI アシスタントまたはその MCP サーバーに言及したとき、または main.composite、main.crdt、または scene.json を編集する前に使用します。
