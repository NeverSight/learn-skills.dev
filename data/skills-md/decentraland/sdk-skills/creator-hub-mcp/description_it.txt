Modifica le entità, i componenti, gli elementi intelligenti e le impostazioni della scena di una scena Decentraland in tempo reale attraverso il server MCP dell'Hub Creatore invece di modificare manualmente asset/scene/main.composite. Da utilizzare ogni volta che una scena è aperta nell'Hub Creator, ogni volta che gli strumenti `mcp__creator-hub__*` (scene_state, create_entity, set_component, place_smart_item, ...) sono disponibili nella sessione, quando l'utente menziona l'assistente AI Creator Hub o il relativo server MCP o prima di QUALSIASI modifica a main.composite, main.crdt o scene.json.
