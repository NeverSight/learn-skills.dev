Modifiez les entités, les composants, les éléments intelligents et les paramètres de scène d'une scène Decentraland en direct via le serveur MCP du Creator Hub au lieu de modifier manuellement les actifs/scene/main.composite. À utiliser chaque fois qu'une scène est ouverte dans le Creator Hub, chaque fois que les outils `mcp__creator-hub__*` (scene_state, create_entity, set_component, place_smart_item, …) sont disponibles dans la session, lorsque l'utilisateur mentionne l'assistant Creator Hub AI ou son serveur MCP, ou avant TOUTE modification vers main.composite, main.crdt ou scene.json.
