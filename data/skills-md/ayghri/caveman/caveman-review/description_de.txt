Ultrakomprimierte Kommentare zur Codeüberprüfung. Reduziert unnötige Informationen aus dem PR-Feedback, während die umsetzbaren Hinweise erhalten bleiben. Jeder Kommentar besteht aus einer Zeile: Stelle, Problem, Lösung. Verwenden Sie diese Funktion, wenn der Benutzer „Diesen PR überprüfen“, „Codeüberprüfung“, „Den Diff überprüfen“, „/review“ sagt oder /caveman-review aufruft. Wird bei der Überprüfung von Pull Requests automatisch ausgelöst.
