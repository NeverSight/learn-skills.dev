Commentaires de revue de code ultra-compressés. Élimine le superflu des commentaires sur les PR tout en conservant les informations exploitables. Chaque commentaire tient en une ligne : emplacement, problème, correction. À utiliser lorsque l'utilisateur dit « examiner cette PR », « revoir le code », « examiner le diff », « /review » ou invoque /caveman-review. Se déclenche automatiquement lors de l'examen des pull requests.
