Prüft ein NestJS‑Feature anhand seiner dokumentierten Roadmap in einem bestimmten Git‑Branch und liefert einen evidenzbasierten Bericht über Implementierung, Lücken, Legacy, Fehler und Blocker. Verwenden Sie es, wenn Sie ein Feature auditieren, die Feature‑Vollständigkeit validieren, Code mit einer Roadmap oder einem Akzeptanzplan vergleichen, eine Feature‑Lückenanalyse durchführen, den Migrationsstatus prüfen oder /audit_feature mit einem Feature‑Namen und optionalem Branch aufrufen möchten. Es stoppt, wenn keine klare Roadmap verfügbar ist, und implementiert keine Fixes. Wenn auch andere Fähigkeiten zutreffen, klären Sie die Zuständigkeit vor einer Änderung.
