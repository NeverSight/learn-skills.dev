يقوم بتدقيق مستودع NestJS موجود مع إرشاد دلالي مدمج ومهارات تخصصية اختيارية ويُعيد تقرير جودة الكود مُرتّبًا حسب الأولوية ومدعومًا بالأدلة. يُستخدم عندما يُطلب فحص قاعدة شفرة NestJS كاملة أو مجلد محدد للتحقق من المشكلات المتعلقة بالصياغة، TypeScript، lint، حدود الوحدات، الاعتمادات، رائحة التصميم، الأمان، الاختبار، الأداء، الاعتمادية، أو جاهزية الإنتاج. هذا تدفق عمل مراجعة للقراءة فقط: لا يقوم بإصلاح الكود، أو تثبيت الاعتمادات، أو تشغيل عمليات الترحيل، أو النشر. عندما تنطبق مهارات أخرى، يجب التوفيق بين الملكية قبل أي تعديل.
