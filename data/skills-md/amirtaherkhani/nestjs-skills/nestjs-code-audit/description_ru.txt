Аудитирует существующий репозиторий NestJS с включёнными семантическими рекомендациями и при необходимости специализированными навыками, возвращая один приоритетный, подкреплённый доказательствами отчёт о качестве кода. Используйте, когда просят проверить весь код NestJS или отдельную папку на наличие проблем с синтаксисом, TypeScript, линтингом, границами модулей, зависимостями, запахами дизайна, безопасностью, тестированием, производительностью, надёжностью или готовностью к продакшн. Это процесс рецензирования только для чтения: он не исправляет код, не устанавливает зависимости, не запускает миграции и не развёртывает приложение. Когда применимы и другие навыки, согласуйте владение перед изменением.
