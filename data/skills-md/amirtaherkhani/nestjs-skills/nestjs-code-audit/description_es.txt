Audita un repositorio NestJS existente con guía semántica integrada y habilidades especializadas opcionales, y devuelve un informe de calidad de código priorizado y respaldado por evidencia. Úselo cuando se solicite revisar todo el código base de NestJS o una carpeta específica para problemas de sintaxis, TypeScript, lint, límites de módulos, dependencias, malos olores de diseño, seguridad, pruebas, rendimiento, confiabilidad o preparación para producción. Este es un flujo de trabajo de revisión solo de lectura: no corrige código, ni instala dependencias, ni ejecuta migraciones, ni despliega. Cuando también apliquen otras habilidades, concilie la propiedad antes de cualquier mutación.
