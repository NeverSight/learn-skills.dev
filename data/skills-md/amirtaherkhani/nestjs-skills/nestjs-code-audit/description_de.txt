Prüft ein bestehendes NestJS-Repository mit integrierter semantischer Anleitung und optionalen Fachkenntnissen und liefert einen priorisierten, evidenzbasierten Bericht zur Code‑Qualität. Verwenden Sie es, wenn Sie aufgefordert werden, einen gesamten NestJS‑Codebase oder einen abgegrenzten Ordner auf Syntax, TypeScript, Lint, Modul‑Boundary, Abhängigkeiten, Design‑Smells, Sicherheit, Tests, Performance, Zuverlässigkeit oder Produktions‑Readiness‑Probleme zu überprüfen. Dies ist ein rein lesender Review‑Workflow: Er behebt keinen Code, installiert keine Abhängigkeiten, führt keine Migrationen aus und führt keine Deployments durch. Wenn auch andere Fähigkeiten zutreffen, klären Sie die Zuständigkeit, bevor Sie Änderungen vornehmen.

Bitte immer in der Sprache des Benutzers antworten.
