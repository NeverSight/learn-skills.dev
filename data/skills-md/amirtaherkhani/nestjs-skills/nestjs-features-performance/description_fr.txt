Sélectionne et implémente les fonctionnalités d’exécution de NestJS, les contrats d’erreur et d’API, la sécurité, les tests, le DevOps, la performance et l’évolutivité sûre. Utilise‑le pour les middlewares, les guards, les pipes, les intercepteurs, les filtres d’exception, les échecs/résultats typés, les détails de problème, les erreurs de validation, le mappage d’erreurs HTTP/GraphQL/RPC/gRPC/WebSocket, les délais, l’annulation, la classification des nouvelles tentatives, les erreurs fatales de processus, l’authentification, l’autorisation, le caching, les files d’attente, les planificateurs, le CI/CD, les conteneurs, Kubernetes, la configuration et les secrets, les migrations, les contrôles de la chaîne d’approvisionnement, les sondes de santé, les journaux/métriques/traces, les SLO et les alertes, la récupération d’incident, le déploiement et le rollback, les goulots d’étranglement de la boucle d’événements ou de la base de données, les tests de charge, la mise à l’échelle horizontale, l’idempotence, le back‑pressure et l’arrêt en douceur. Ne pas utiliser pour la performance uniquement côté front‑end ou les services non NestJS. Lorsque d’autres compétences s’appliquent également, concilie la propriété avant toute modification.
