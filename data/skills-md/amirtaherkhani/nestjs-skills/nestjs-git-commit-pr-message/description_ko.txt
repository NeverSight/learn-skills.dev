NestJS 프로젝트를 위한 의도된 Git 변경을 준비하고 배포합니다. 사용자는 커밋, 푸시, 풀 리퀘스트 생성 또는 업데이트, changelog 혹은 릴리스 텍스트 준비, 공개 후 GitHub Pages 배포 확인을 요청할 때 사용합니다. 전체 diff를 검사하고, 관련 없는 작업을 보존하며, 스테이징된 내용에 비밀 정보가 있는지 스캔하고, 저장소 커밋 규칙에 맞추며, 관련 검사를 실행하고, 명시적으로 요청된 원격 작업만 수행합니다. 다른 스킬도 적용되는 경우, 변경 작업을 수행하기 전에 소유권을 조정합니다. 항상 사용자의 언어로 응답하세요.
