يقوم بإعداد ونشر تغييرات Git مقصودة لمشاريع NestJS. يُستَخدم عندما يطلب المستخدم إجراء commit أو push أو إنشاء أو تحديث طلب سحب، أو إعداد سجل التغييرات أو نص الإصدار، أو التحقق من نشر GitHub Pages بعد النشر. يتفحص الفرق الكامل، يحافظ على الأعمال غير المتعلقة، يفحص المحتوى المرحَّل للبحث عن أسرار، يطابق اتفاقيات الالتزام في المستودع، ينفّذ الفحوصات ذات الصلة، ويقوم فقط بالإجراءات البعيدة التي طلبها المستخدم صراحة. عندما تنطبق مهارات أخرى، يتم التوفيق بين الملكية قبل تعديل أي شيء.
