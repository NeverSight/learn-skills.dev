Подготавливает и публикует преднамеренные изменения Git для проектов NestJS. Используйте, когда пользователь просит выполнить commit, push, создать или обновить pull request, подготовить changelog или текст релиза, или проверить развертывание GitHub Pages после публикации. Он проверяет полный diff, сохраняет несвязанные работы, сканирует подготовленное содержимое на наличие секретов, сопоставляет соглашения о коммитах репозитория, запускает соответствующие проверки и выполняет только явно запрошенные удалённые действия. Если применимы и другие навыки, согласуйте владение перед изменением.

Пожалуйста, всегда отвечайте на языке пользователя.
