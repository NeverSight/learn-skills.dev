Prepara e pubblica modifiche Git intenzionali per progetti NestJS. Usalo quando l'utente chiede di fare commit, push, creare o aggiornare una pull request, preparare il changelog o il testo di rilascio, o verificare una distribuzione su GitHub Pages dopo la pubblicazione. Esamina l'intero diff, preserva il lavoro non correlato, scansiona i contenuti in staging alla ricerca di segreti, rispetta le convenzioni di commit del repository, esegue i controlli pertinenti e compie solo le azioni remote espressamente richieste. Quando altre competenze si applicano, concilia la proprietà prima della mutazione.
