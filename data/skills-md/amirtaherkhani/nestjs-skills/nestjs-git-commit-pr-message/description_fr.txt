Prépare et publie des changements Git intentionnels pour les projets NestJS. Utilisez-le lorsque l'utilisateur demande de commettre, de pousser, de créer ou de mettre à jour une pull request, de préparer le changelog ou le texte de version, ou de vérifier un déploiement GitHub Pages après publication. Il inspecte le diff complet, préserve le travail non lié, analyse le contenu mis en scène à la recherche de secrets, respecte les conventions de commit du dépôt, exécute les vérifications pertinentes et effectue uniquement les actions à distance explicitement demandées. Lorsque d'autres compétences s'appliquent également, réconciliez la propriété avant toute mutation.
