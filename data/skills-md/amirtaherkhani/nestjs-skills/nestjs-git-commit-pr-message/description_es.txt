Prepara y publica cambios intencionales de Git para proyectos NestJS. Úselo cuando el usuario solicite hacer commit, push, crear o actualizar un pull request, preparar el changelog o el texto de la versión, o verificar una implementación de GitHub Pages después de la publicación. Inspecciona el diff completo, preserva el trabajo no relacionado, escanea el contenido preparado en busca de secretos, coincide con las convenciones de commits del repositorio, ejecuta verificaciones relevantes y realiza únicamente las acciones remotas solicitadas explícitamente. Cuando otras habilidades también apliquen, concilie la propiedad antes de la mutación. Por favor, siempre responda en el idioma del usuario.
