Prepara y publica cambios intencionales de Git para proyectos NestJS. Úsalo cuando el usuario solicite confirmar, subir, crear o actualizar una solicitud de extracción, preparar notas de cambios o texto de lanzamiento, o verificar una implementación de GitHub Pages después de la publicación. Inspecciona el diff completo, preserva el trabajo no relacionado, escanea el contenido preparado en busca de secretos, coincide con las convenciones de commit del repositorio, ejecuta verificaciones relevantes y realiza solo las acciones remotas explícitamente solicitadas. Cuando otras habilidades también apliquen, concilia la propiedad antes de la mutación. Por favor, responde siempre en el idioma del usuario.
