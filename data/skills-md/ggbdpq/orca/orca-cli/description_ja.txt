Orcaが管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そしてOrcaの組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree、臨時の PTY、または Computer Use よりもこれを優先します。CLI、ファイルシステム、API では実行できない可視ウィンドウの GUI 操作が必要なときだけ Computer Use を使用します。

常にユーザーの言語で応答してください。
