Рабочий процесс разработки, ориентированный на спецификацию, для реализации функций со структурированной документацией. Использовать при начале новой функции, задачи или реализации, которые выигрывают от предварительного планирования. Триггеры: /sdd, spec-driven, create spec, implementation plan или когда пользователь описывает функцию/задачу для реализации.
