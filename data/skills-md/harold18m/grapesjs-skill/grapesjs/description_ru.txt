GrapesJS — веб‑фреймворк для построения страниц. Используется при работе с редактором GrapesJS, компонентами, блоками, менеджером стилей, темизацией, пользовательскими типами компонентов, плагинами, хранилищем, панелями, командами, трейдами, канвасом (масштаб/панорамирование/перетаскивание), слоями, ассетами, адаптивным дизайном, модальными окнами, страницами, источниками данных, i18n, RTE, раскладками клавиш, отменой/повтором, скриптами компонентов, символами, CssComposer, свойствами изменения размеров/перетаскивания/приёма/блокировки, или любой задачей по построению страниц методом drag‑and‑drop с GrapesJS.
