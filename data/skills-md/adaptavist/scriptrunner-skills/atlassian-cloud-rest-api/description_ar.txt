مهارة البحث في واجهة برمجة التطبيقات REST السحابية المحلية لأتلانتيان (OpenAPI) لـ Confluence Cloud الإصدار 1/2، منصة Jira Cloud الإصدار 3، Jira Software Cloud، Jira Service Management Cloud، وAssets Cloud. استخدمها عندما يطلب المستخدمون مسارات REST أو المعلمات أو أجسام الطلب أو مخططات الاستجابة.

الرجاء دائمًا الرد بلغة المستخدم.
