Implement Flutter UI against a project-owned design system instead of stock Material 3 / Cupertino chrome. Covers ThemeExtension tokens, 1:1 token discipline, a house Pressable that replaces ink ripples, branded type/spacing, and detecting an existing system before inventing a new one. Use when the app has custom tokens, a *Pressable, a ThemeExtension, Figma/CSS token files, or the user says custom design system, branded UI, no Material look, no ripple; or when they run /flutter-custom-design-system.
