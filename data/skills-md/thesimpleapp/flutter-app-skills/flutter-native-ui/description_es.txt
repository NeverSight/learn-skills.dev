Construye pantallas Flutter con apariencia nativa usando Material 3 y Cupertino. Cubre tematización, controles adaptativos, go_router, SafeArea/MediaQuery, slivers, sheets, animaciones, iconos y convenciones de plataforma basadas en la documentación estable actual de Flutter (3.47+ / Dart 3.13+). Úsalo al crear UI de Flutter, widgets, temas, navegación, pantallas, listas, formularios, diálogos o sheets; al hacer que una aplicación se sienta nativa en iOS o Android; o cuando el usuario ejecuta /flutter-native-ui. Si el proyecto ya tiene una ThemeExtension personalizada, Pressable propio o archivo de tokens de marca, usa flutter‑custom‑design‑system en lugar de restilizar a Material.
