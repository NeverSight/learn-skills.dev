Build native-feeling Flutter screens with Material 3 and Cupertino. Covers theming, adaptive controls, go_router, SafeArea/MediaQuery, slivers, sheets, animations, icons, and platform conventions grounded in current Flutter stable docs (3.47+ / Dart 3.13+). Use when building Flutter UI, widgets, themes, navigation, screens, lists, forms, dialogs, or sheets; when making an app feel native on iOS or Android; or when the user runs /flutter-native-ui. If the project already has a custom ThemeExtension / house Pressable / branded token file, use flutter-custom-design-system instead of restyling to Material.
