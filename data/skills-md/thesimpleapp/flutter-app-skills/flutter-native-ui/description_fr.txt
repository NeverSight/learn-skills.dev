Créez des écrans Flutter à l’aspect natif avec Material 3 et Cupertino. Cela couvre la thématisation, les contrôles adaptatifs, go_router, SafeArea/MediaQuery, les slivers, les feuilles, les animations, les icônes et les conventions de plateforme, le tout basé sur la documentation stable actuelle de Flutter (3.47+ / Dart 3.13+). Utilisez‑le lors de la construction d’interfaces Flutter, de widgets, de thèmes, de navigation, d’écrans, de listes, de formulaires, de dialogues ou de feuilles ; lorsqu’il s’agit de rendre une application native sur iOS ou Android ; ou lorsque l’utilisateur exécute /flutter-native-ui. Si le projet possède déjà une ThemeExtension personnalisée / une classe Pressable maison / un fichier de jetons de marque, utilisez flutter‑custom‑design‑system au lieu de restyler avec Material.

Veuillez toujours répondre dans la langue de l’utilisateur.
