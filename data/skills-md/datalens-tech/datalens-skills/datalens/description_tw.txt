在任務尚未決定使用哪種工具，或問題是關於 DataLens 本身而不是在其中執行某些操作時，請從此處開始了解 Yandex DataLens：DataLens 是什麼以及它能做什麼；正在使用哪種部署方式 — Yandex Cloud、內部部署（on‑premise）或 Yandex 團隊內部的部署 — 以及它們在主機、認證和功能上有何不同；什麼是 collection、workbook、connection、dataset、chart 或 dashboard，以及它們之間的關係；以及是使用 MCP 伺服器、Python SDK、HTTP API 還是 Web UI。用它來定位並引導到執行工作的相應技能。**不**用於在選定方法後執行實際工作——那是 Python 的 `datalens‑sdk` 和獨立 HTML 報告的 `datalens‑html‑pages`——也不用於解讀業務指標值的意義。

請始終以使用者的語言回覆。
