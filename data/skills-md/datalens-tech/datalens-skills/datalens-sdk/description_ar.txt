استخدم هذه المهارة لأي مهمة أتمتة Yandex DataLens عبر حزمة Python `datalens-sdk`. يتم التفعيل عند: DataLens، datalens، даталенс، chart، чарт، график، dashboard، дашборд، dataset، датасет، connection، подключение، workbook، воркбук، collection، коллекция، wizard chart، QL chart، editor chart، BI automation، автоматизация DataLens، "create a dashboard"، "построй дашборд"، "создай чарт"، "export dataset"، أو "clone dashboard"؛ معرفات الكيانات مثل dataset_id، chart_id، dashboard_id، أو workbook_id؛ والطلبات لإنشاء، تحديث، فحص، استيراد، تصدير، نسخ، أو تشخيص كائنات DataLens باستخدام الشيفرة. لا تستخدم لهذه الغاية: الأسئلة التجارية حول قيم المقاييس؛ عرض أو أخذ لقطة شاشة لواجهة الويب الخاصة بـ DataLens؛ التضمين أو iframes؛ تحليلات SQL/YQL الخام التي لا تدير كيانات DataLens؛ مكالمات HTTP API الخام؛ صفحات HTML أو تقارير مستقلة، إلا إذا كانت للنشر أو الإدارة من خلال هذا SDK.
