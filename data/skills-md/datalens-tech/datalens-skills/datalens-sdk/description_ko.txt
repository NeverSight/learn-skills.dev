이 기능은 Python 패키지 `datalens-sdk`를 통해 Yandex DataLens 자동화 작업에 사용하십시오. 트리거 키워드: DataLens, datalens, даталенс, chart, чарт, 그래프, dashboard, дашборд, dataset, датасет, connection, подключение, workbook, воркбук, collection, коллекция, wizard chart, QL chart, editor chart, BI automation, 자동화 DataLens, "create a dashboard", "построй дашборд", "создай чарт", "export dataset", "clone dashboard"; dataset_id, chart_id, dashboard_id, workbook_id와 같은 엔터티 ID; 그리고 코드로 DataLens 객체를 생성, 업데이트, 검사, 가져오기, 내보내기, 복사 또는 진단하는 요청. 해당되지 않는 경우: 메트릭 값에 대한 비즈니스 질문; DataLens 웹 UI 보기 또는 스크린샷 캡처; 임베딩 또는 iframe 사용; DataLens 엔터티를 관리하지 않는 순수 SQL/YQL 분석; 순수 HTTP API 호출; 독립형 HTML 페이지 또는 보고서(단, 이 SDK를 통해 게시하거나 관리하는 경우는 제외).
