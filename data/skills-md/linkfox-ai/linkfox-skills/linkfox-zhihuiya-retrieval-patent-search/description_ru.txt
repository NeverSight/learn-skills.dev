Получите список патентов из базы данных PatSnap (SmartBud) с помощью аналитического запроса (например, TACD: keyword), возвращая идентификатор патента, номер публикации и общее количество совпадений. Эта функция активируется, когда пользователь упоминает поиск запросов патентов, поиск выражений патентов, аналитический запрос, поиск TACD, поиск по ключевому слову патента, поиск патентов по запросу, семантический поиск патентов, поиск выражений патентов, синтаксис запросов патентов, аналитический запрос, поиск TACD, PatSnap или поиск патентов SmartBud. Даже если пользователь явно не упоминает «запрос» или «SmartBud», при условии, что он намерен использовать синтаксис запросов/выражений для получения списка патентов в базе данных, эта функция должна быть активирована.
