Code-Review von geänderten, gestagten, letzten Commits und Merge- oder PR-Arbeiten im Hinblick auf die Anforderungen und den Styleguide des Repositorys. Verwenden Sie diese Option, wenn Sie aktuelle Arbeiten, zwischengespeicherte Änderungen, den letzten Commit, einen Branch, einen Merge oder einen Pull Request überprüfen. Verwenden Sie für eine Stilprüfung der gesamten Codebasis stattdessen ng-review-style-guide.
