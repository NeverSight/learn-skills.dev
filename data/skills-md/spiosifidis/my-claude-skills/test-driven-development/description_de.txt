Red‑Green‑Refactor‑Disziplin – schreibe den fehlschlagenden Test, bevor du irgendeinen Implementierungscode schreibst. Verwende sie beim Implementieren von Features oder Bugfixes, immer dann, wenn der Benutzer um das Hinzufügen von Funktionalität, das Beheben eines Fehlers oder das Ändern des Verhaltens bittet, VOR dem Schreiben von Implementierungscode – selbst wenn der Benutzer keine Tests erwähnt.
