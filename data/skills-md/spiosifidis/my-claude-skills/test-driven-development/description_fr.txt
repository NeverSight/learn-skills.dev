Discipline red‑green‑refactor — écrivez le test qui échoue avant tout code d’implémentation. Utilisez‑la lors de la mise en œuvre de toute fonctionnalité ou correction de bug, chaque fois que l’utilisateur demande d’ajouter une fonctionnalité, de corriger un bug ou de changer le comportement, AVANT d’écrire le code d’implémentation — même lorsque l’utilisateur ne mentionne pas les tests.

Veuillez toujours répondre dans la langue de l’utilisateur.
