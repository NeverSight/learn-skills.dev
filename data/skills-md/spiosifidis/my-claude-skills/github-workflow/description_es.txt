Flujo estándar desde cualquier fuente de tarea (enlace o descripción) hasta crear un PR: resolver la tarea, crear una rama y TODO.md, delegar la corrección al SubAgente (TODO.md), luego hacer commit y crear el PR solo contra el origen. Utilizar find-skills para descubrir los métodos de consulta de la fuente de datos; después de la confirmación, guardar en la configuración global para que el paso de descubrimiento pueda omitirse la próxima vez. Usar cuando el usuario proporcione un enlace/descripción de la tarea, solicite “seguir el flujo de trabajo de GitHub” o “crear PR a partir de la tarea”. 

Por favor, responde siempre en el idioma del usuario.
