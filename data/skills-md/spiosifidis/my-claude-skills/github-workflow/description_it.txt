Flusso standard da qualsiasi fonte di task (link o descrizione) alla creazione di una PR: risolvere il task, creare un branch e TODO.md, delegare la correzione a SubAgent (TODO.md), quindi effettuare il commit e creare la PR solo sull'origine. Usa find‑skills per scoprire i metodi di query del data‑source; dopo la conferma salva nella configurazione globale così il passo di scoperta può essere omesso la prossima volta. Utilizzare quando l'utente fornisce un link o una descrizione del task, chiede di “seguire il workflow GitHub” o di “creare PR dal task”.

Rispondi sempre nella lingua dell'utente.
