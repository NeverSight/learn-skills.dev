Flux standard de n'importe quelle source de tâche (lien ou description) vers la création d'une PR : résoudre la tâche, créer la branche et TODO.md, déléguer le correctif au sous-agent (TODO.md), puis valider et créer la PR par rapport à l'origine uniquement. Utilisez les compétences de recherche pour découvrir les méthodes de requête de source de données ; après confirmation, enregistrez dans la configuration globale afin que l'étape de découverte puisse être ignorée la prochaine fois. À utiliser lorsque l'utilisateur fournit un lien/une description de tâche, demande de « suivre le flux de travail GitHub » ou de « créer une RP à partir d'une tâche ».
