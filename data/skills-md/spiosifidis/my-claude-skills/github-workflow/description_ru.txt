Стандартный поток от любого источника задачи (ссылка или описание) до создания PR: решить задачу, создать ветку и файл TODO.md, делегировать исправление SubAgent (TODO.md), затем выполнить коммит и создать PR только в оригинальном репозитории. Используйте find‑skills для обнаружения методов запросов к источникам данных; после подтверждения сохраните в глобальную конфигурацию, чтобы шаг обнаружения можно было пропустить в следующий раз. Применяйте, когда пользователь предоставляет ссылку/описание задачи, просит «следовать GitHub workflow» или «создать PR из задачи».
