Crea changelogs dirigidos al usuario a partir de commits de Git — analiza el historial de commits, categoriza los cambios y reescribe los commits técnicos en notas de lanzamiento claras y amigables para el cliente. Úsalo cuando el usuario solicite un changelog, notas de lanzamiento, “qué cambió desde” una versión o fecha, o un resumen dirigido al usuario de los commits recientes.

Por favor, responde siempre en el idioma del usuario.
