اُستخدم عند بناء قوالب بريد إلكتروني بصيغة HTML باستخدام مكوّنات React، أو إضافة محرّـر بريد إلكتروني بصري إلى تطبيق باستخدام محرّر البريد الإلكتروني البصري لـ React، أو تحويل الرسائل إلى HTML، أو إرسال رسائل بريد إلكتروني باستخدام Resend. يشمل رسائل الترحيب، وإعادة تعيين كلمة المرور، والإشعارات، وتأكيد الطلبات، والنشرات الإخبارية، والرسائل المعاملاتية، ومكوّن محرّر البريد الإلكتروني القابل للتضمين.
