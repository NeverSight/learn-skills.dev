Configurazione testata in produzione per Tailwind CSS v4 con shadcn/ui, Vite e React. Da usare quando: si avviano progetti React con Tailwind v4, si imposta shadcn/ui, si implementa la modalità scura, si debugga problemi di variabili CSS, si corregge lo scambio del tema, si migra da Tailwind v3 o si riscontrano problemi di colore/tematizzazione. Include: pattern inline @theme, architettura delle variabili CSS, modalità scura con ThemeProvider, composizione dei componenti, configurazione vite.config, comuni insidie di v4 e pattern testati in produzione.
