Elabora un documento di origine (specifica funzionale, documento tecnico, ADR, verbali di riunioni, intervista, workshop, glossario) in conoscenza curata sotto /knowledge. Utilizza quando ti viene chiesto di curare, estrarre, decomporre o strutturare un documento aziendale, o quando la curazione è menzionata insieme a un percorso file o allegato o a una fonte non documentale (intervista, workshop). Un file o allegato da solo, senza intento di curazione, non attiva questa regola — ad esempio una domanda su o un riassunto di un documento.

Rispondi sempre nella lingua dell'utente.
