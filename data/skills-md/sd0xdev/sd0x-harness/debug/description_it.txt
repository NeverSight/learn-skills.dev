Flusso di lavoro di debug interattivo con ciclo di sondaggio guidato da ipotesi. Da utilizzare quando: bug sconosciuti, errori di script, fallimenti silenziosi, risoluzione dei problemi. Non per: bug noti (usare bug-fix), analisi di issue su GitHub (usare issue-analyze), comprensione del codice (usare code-explore). Output: rapporto di debug con diario di sondaggio + causa radice + correzione.
