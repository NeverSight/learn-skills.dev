Интерактивный процесс отладки с гипотезо‑ориентированным циклом проб. Использовать, когда: неизвестные баги, ошибки скриптов, тихие сбои, устранение неполадок. Не использовать для: известных багов (использовать bug-fix), анализа проблем на GitHub (использовать issue-analyze), понимания кода (использовать code-explore). Вывод: отчёт об отладке с журналом проб + коренная причина + исправление.
