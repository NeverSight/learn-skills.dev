Gestiona el perfil de rendimiento y la depuración de Android. Se activa cuando el usuario solicita registrar o analizar datos de rendimiento de Android, como rastreos del sistema, volcados de memoria dinámica, grabaciones de métodos, muestras de callstack, asignaciones de memoria o investigar cuellos de botella, jank, fugas de memoria y problemas de inicio de aplicaciones en Android, o cuando el usuario solicita escribir, depurar o ejecutar consultas SQL ad-hoc. Se aplica tanto a aplicaciones o servicios de usuario como de sistema.
