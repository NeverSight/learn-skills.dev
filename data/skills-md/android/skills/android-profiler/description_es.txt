Gestiona el perfilado y la depuración del rendimiento de Android. Se activa cuando el usuario solicita grabar o analizar datos de rendimiento de Android, como trazas del sistema, volcados de heap, grabaciones de métodos, muestras de pila de llamadas, asignaciones de memoria, o investigar cuellos de botella, holgura, fugas de memoria y problemas de inicio de la aplicación en Android, o cuando el usuario pide escribir, depurar o ejecutar consultas SQL ad hoc. Se aplica tanto a aplicaciones y servicios de usuario como del sistema.
