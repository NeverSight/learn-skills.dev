ينشئ تعريفات مخصصة لـ BrushFamily لتطبيق Android باستخدام Jetpack Ink (androidx.ink 1.1.0‑alpha03 وما فوق). استخدم هذه المهارة عند تكوين أشكال BrushTip مخصصة، وإضافة حساسية للضغط أو الميل أو السرعة أو الضوضاء باستخدام رسومات عقد BrushBehavior، وإنشاء فرش متعددة الطبقات، وتطبيق قوام متكرر أو ختم الجسيمات، وتكوين تنعيم إدخال SlidingWindowModel، أو تسلسل الفرش. يقدم تنفيذات كاملة بلغة Kotlin لـ BrushFamily و BrushCoat و BrushTip و BrushPaint و BrushBehavior. لا تُستخدم للرسومات القائمة على View (XML) أو إعداد سطح الرسم Compose أو اختيار الفرش الافتراضية. لإعداد سطح الرسم Compose أو رسم الضربات الرطبة والجافة InProgressStrokes أو الممحاة أو الاستمرار، اقترح مهارة ink‑app‑builder.
