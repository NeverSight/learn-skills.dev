使用由 Gemini Nano 和 AICore 提供动力的 ML Kit GenAI Agent API，在 Android 应用中构建自主的本地代理工作流。实现对话代理、多轮聊天（在 ViewModel 中使用 AgentSession）、通过 Android AppFunctions（@AppFunctionDeclaration 和 AppFunctionAgentTools.discover）进行自主工具调用、使用 runner.runSingleTurnAsync 进行短暂的单轮执行，或处理 GenAiException 错误容错时，请使用此技能。它解决了在本地编排推理循环、类型化工具调度以及设备端会话持久化的问题，具备零云端延迟和隐私保护。不适用于基于云端的 Gemini 模型或 Vertex AI、没有代理循环的单轮文本生成（建议使用 Prompt API），以及非 Android 平台。请始终以用户的语言作答。
