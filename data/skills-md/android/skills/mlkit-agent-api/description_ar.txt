يبني تدفقات عمل مستقلة على الجهاز في تطبيقات Android باستخدام واجهة برمجة تطبيقات ML Kit GenAI Agent المدعومة بـ Gemini Nano و AICore. استخدم هذه الميزة عند تنفيذ وكلاء محادثة، دردشة متعددة الأدوار باستخدام AgentSession في ViewModel، استدعاء أدوات تلقائي باستخدام Android AppFunctions (@AppFunctionDeclaration و AppFunctionAgentTools.discover)، تنفيذ مؤقت لحركة واحدة باستخدام runner.runSingleTurnAsync، أو التعامل مع صلابة الأخطاء عبر GenAiException. يحل المشكلة المتعلقة بتنظيم حلقات التفكير المحلية، وتوزيع الأدوات المكتوبة، واستمرار الجلسة على الجهاز دون أي تأخير سحابي مع الحفاظ على الخصوصية. لا تستخدمه مع نماذج Gemini السحابية أو Vertex AI، أو توليد نص وحيد الدور دون حلقات الوكيل (يُنصح بواجهة Prompt API)، أو على منصات غير Android.
