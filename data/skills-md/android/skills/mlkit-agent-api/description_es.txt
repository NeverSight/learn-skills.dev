Construye flujos de trabajo autónomos basados en agentes dentro del dispositivo en aplicaciones Android usando la API ML Kit GenAI Agent impulsada por Gemini Nano y AICore. Utiliza esta habilidad al implementar agentes conversacionales, chat de varios turnos con AgentSession en un ViewModel, llamadas autónomas a herramientas usando Android AppFunctions (@AppFunctionDeclaration y AppFunctionAgentTools.discover), ejecución efímera de un solo turno con runner.runSingleTurnAsync, o manejo de la resiliencia a errores con GenAiException. Resuelve el problema de orquestar bucles de razonamiento local, despacho tipado de herramientas y persistencia de sesión en el dispositivo con latencia cero en la nube y preservación de la privacidad. No lo uses para modelos Gemini basados en la nube o Vertex AI, generación de texto de un solo turno sin bucles de agente (sugerir Prompt API), o plataformas que no sean Android.
