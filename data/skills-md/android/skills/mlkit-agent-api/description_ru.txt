Создаёт автономные агентные рабочие процессы на устройстве в Android‑приложениях, используя ML Kit GenAI Agent API на базе Gemini Nano и AICore. Используйте эту возможность при реализации разговорных агентов, многотурового чата с AgentSession во ViewModel, автономного вызова инструментов с помощью Android AppFunctions (@AppFunctionDeclaration и AppFunctionAgentTools.discover), одноразового одношагового выполнения с runner.runSingleTurnAsync или обработки ошибок GenAiException. Она решает проблему оркестрации локальных циклов рассуждения, типизированной диспетчеризации инструментов и постоянства сеанса на устройстве без задержек облака и с сохранением конфиденциальности. Не используйте для облачных моделей Gemini или Vertex AI, одношаговой генерации текста без агентных циклов (рекомендуется Prompt API) или для платформ, не являющихся Android.
