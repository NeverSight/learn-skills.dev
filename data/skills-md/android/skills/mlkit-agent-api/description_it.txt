Costruisce flussi di lavoro agentici autonomi sul dispositivo nelle app Android utilizzando l'API ML Kit GenAI Agent, alimentata da Gemini Nano e AICore. Usa questa funzionalità quando implementi agenti conversazionali, chat a più turni con AgentSession in un ViewModel, chiamate autonome a tool tramite Android AppFunctions (@AppFunctionDeclaration e AppFunctionAgentTools.discover), esecuzioni effimere a turno singolo con runner.runSingleTurnAsync, o la gestione resiliente degli errori tramite GenAiException. Risolve il problema dell’orchestrazione di loop di ragionamento locali, della distribuzione tipizzata dei tool e della persistenza della sessione sul dispositivo, con latenza zero dal cloud e preservazione della privacy. Non usarla per modelli Gemini basati sul cloud o Vertex AI, generazione di testo a turno singolo senza loop agentici (suggerisci Prompt API), o per piattaforme non Android.
