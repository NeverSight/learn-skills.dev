Proporciona conocimientos y flujos de trabajo para implementar la función Restaurar credenciales de Android utilizando la biblioteca androidx.credentials. Utilice esta habilidad para crear, iniciar sesión con y eliminar las claves de restauración, lo que permite el inicio de sesión silencioso del usuario en nuevos dispositivos después de una restauración. Cubre la compatibilidad de versiones, las dependencias, los requisitos previos del lado del servidor y la implementación completa del lado del cliente para crear, recuperar y borrar claves de restauración.
