提供將 Android TV 應用程式從傳統 Leanback UI 工具包、Android View 或 Support Fragment 遷移至 Jetpack Compose for TV（androidx.tv）的說明與架構模式。使用此技能進行 Leanback 到 Compose 的遷移，包括瀏覽畫面、設定畫面、驗證畫面、登入畫面或影片播放畫面的遷移，或在取代 BrowseSupportFragment、LeanbackSettingsFragment、PreferenceFragment、BaseLeanbackPreferenceFragmentCompat、VideoSupportFragment、GuidedStepSupportFragment、SearchSupportFragment、VerticalGridSupportFragment、Presenter、ArrayObjectAdapter 或 CursorMapper 為現代 Compose 等價物時，實作具焦點記憶的沉浸式輪播、使用 Media3 與 PlayerSurface 的影片播放，或自訂 10‑foot hero 版面配置。
