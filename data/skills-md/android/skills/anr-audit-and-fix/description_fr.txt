Audite les bases de code Android pour les risques ANR et diagnostique les décharges de piles ANR. Utilisez cette compétence lors de la numérisation du code Android pour détecter les risques ANR ou trier les décharges de piles ANR. Ne pas utiliser pour les plantages non-ANR, les images perdues, le profilage général du processeur ou les traces du système Perfetto.
