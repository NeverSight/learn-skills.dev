Fangen Sie Gesten ab und führen Sie Predictive Back-Animationen mit der Bibliothek NavigationEvent (androidx.navigationevent) in Compose Android aus. Kümmert sich um das Aktivitäts-Setup, das Scoping des Eltern-Kind-Dispatchers in "ViewPagers" oder Registerkarten, das Verfassen von "NavigationBackHandler" und die Migration von älteren "BackHandler" auf SDK 36+.
