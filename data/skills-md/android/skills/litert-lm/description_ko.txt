CPU 또는 GPU에서 디바이스 내 오픈 텍스트 LLM을 실행하는 Android 앱을 LiteRT‑LM Kotlin API (com.google.ai.edge.litertlm:litertlm-android)로 구축합니다. Hugging Face litert‑community(Gemma, Qwen, Llama, Phi)에서 제공하는 .litertlm 모델을 사용해 채팅, 요약, 추출 기능을 만들 때 이 스킬을 사용하세요. 여기에는 Gradle 종속성, GPU 매니페스트 항목, 모델 파일을 디바이스에 배치하기, 메인 스레드가 아닌 곳에서 엔진 초기화, sendMessageAsync를 활용한 스트리밍 다중 턴 대화, AndroidViewModel 및 Compose 화면 구현이 포함됩니다. .tflite 비전, 오디오, 임베딩 모델을 CompiledModel API로 실행하거나 이미지·오디오 입력, 툴 호출, NPU 백엔드, 모델 변환 용도로는 사용하지 마세요.

항상 사용자의 언어로 응답하세요.
