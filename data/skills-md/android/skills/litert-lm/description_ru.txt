Создаёт Android‑приложение, которое запускает открытую текстовую LLM на устройстве, на CPU или GPU, с помощью Kotlin‑API LiteRT‑LM (com.google.ai.edge.litertlm:litertlm-android). Используйте этот навык при создании функции чата, суммирования или извлечения с моделью .litertlm из сообщества Hugging Face litert‑community (Gemma, Qwen, Llama, Phi), включая Gradle‑зависимость, записи в манифесте для GPU, загрузку файла модели на устройство, инициализацию движка не в основном потоке, потоковую многоходовую беседу с sendMessageAsync, а также AndroidViewModel и экран Compose. Не используйте для запуска .tflite моделей компьютерного зрения, аудио или эмбеддингов с API CompiledModel, для ввода изображений или аудио, вызова инструментов, бэкендов NPU или конвертации моделей.
