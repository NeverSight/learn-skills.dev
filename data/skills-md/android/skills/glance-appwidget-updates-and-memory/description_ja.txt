Jetpack Glance（androidx.glance:glance-appwidget）と AppWidgetProvider レシーバーを使用して、Android 17（API 37）上で Android AppWidget の状態更新、バックグラウンド同期、RemoteViews のビットマップメモリ制限を管理します。Android 17（API レベル 37）の compileSdk/targetSdk と AndroidManifest.xml のウィジェットレシーバーを設定する際、CoroutineWorker の DataStore 設定更新（updateAppWidgetState）後に凍結または古くなった Glance ウィジェット UI をリフレッシュしたり、SizeMode.Responsive、SizeMode.Exact、または LazyColumn 用に WindowMetrics のメモリ上限内で画像をダウンサンプリングしたり、FileProvider を介して content:// URI を共有したり、WorkManager と組み合わせて ActionCallback の NoSuchMethodException や AppWidgetProvider の ForegroundServiceStartNotAllowedException のクラッシュを修正したりするときにこのスキルを使用してください。Glance のレイアウトテンプレートには（glance-canonical-layouts スキルを推奨）使用せず、アプリ内の Compose 画面でも使用しないでください。
