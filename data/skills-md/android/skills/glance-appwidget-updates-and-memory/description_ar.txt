يدير تحديثات حالة Android AppWidget، والمزامنات الخلفية، وحدود ذاكرة bitmap في RemoteViews باستخدام Jetpack Glance (androidx.glance:glance-appwidget) ومستقبلات AppWidgetProvider على Android 17 (API 37). استخدم هذه المهارة عند تكوين compileSdk/targetSdk للإصدار Android 17 (مستوى API 37) ومستقبلات الودجيت في AndroidManifest.xml، وتحديث واجهة Glance widget المتجمدة أو القديمة بعد تحديث تفضيلات DataStore عبر CoroutineWorker (updateAppWidgetState)، وتقليل حجم الصور لتناسب حد ذاكرة WindowMetrics لـ SizeMode.Responsive أو SizeMode.Exact أو LazyColumn، ومشاركة عناوين URI من النوع content:// مع FileProvider، أو إصلاح الأعطال المتعلقة بـ ActionCallback NoSuchMethodException وAppWidgetProvider ForegroundServiceStartNotAllowedException عند استخدام WorkManager. لا تستخدمها لقوالب تخطيط Glance (اقترح مهارة glance-canonical-layouts) أو لشاشات Compose داخل التطبيق.
