Управляет обновлениями состояния Android AppWidget, фоновыми синхронизациями и ограничениями памяти битмапов RemoteViews с помощью Jetpack Glance (androidx.glance:glance-appwidget) и приёмниками AppWidgetProvider на Android 17 (API 37). Используйте этот навык при настройке compileSdk/targetSdk Android 17 (уровень API 37) и приёмников виджетов в AndroidManifest.xml, обновлении «застывшего» или устаревшего UI Glance‑виджета после обновления предпочтений DataStore в CoroutineWorker (updateAppWidgetState), понижающем разрешение изображений в пределах ограничения памяти WindowMetrics для SizeMode.Responsive, SizeMode.Exact или LazyColumn, совместном использовании URI вида content:// с FileProvider, а также при исправлении сбоев ActionCallback NoSuchMethodException и AppWidgetProvider ForegroundServiceStartNotAllowedException при работе с WorkManager. Не используйте для шаблонов макетов Glance (рекомендуется навык glance-canonical-layouts) или экранов Compose внутри приложения.
