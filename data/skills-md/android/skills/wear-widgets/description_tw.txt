在 Android 專案中使用 Glance Wear 與 Remote Compose 來建立、遷移、更新與驗證 Wear OS 小工具。實作 GlanceWearWidget、GlanceWearWidgetService、WearWidgetDocument、Remote Compose UI 原件（RemoteColumn、RemoteRow、RemoteBox、RemoteText、RemoteImage、RemoteButton）、使用 rememberMutableRemoteInt 與 valueChange 的本地狀態、透過 pendingIntentAction 的點擊動作、widget provider XML 容器（SMALL 與 LARGE）、矩形小工具挑選器 PNG 預覽，或將舊有 ProtoLayout TileService 磁磚遷移為 Wear OS 小工具時使用此技能。請勿將其用於行動裝置主畫面的 AppWidgetProvider 或 GlanceAppWidget 實作、手錶錶面佈件，或全螢幕 Wear OS 活動。
