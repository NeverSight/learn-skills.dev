Crear, migrar, actualizar y verificar widgets de Wear OS usando Glance Wear y Remote Compose en un proyecto Android. Utiliza esta habilidad al implementar GlanceWearWidget, GlanceWearWidgetService, WearWidgetDocument, los componentes de UI de Remote Compose (RemoteColumn, RemoteRow, RemoteBox, RemoteText, RemoteImage, RemoteButton), manejar estado local con rememberMutableRemoteInt y valueChange, definir acciones de clic con pendingIntentAction, usar contenedores XML de proveedor de widgets (SMALL y LARGE), generar vistas previas PNG rectangulares para el selector de widgets, o migrar tiles heredados de ProtoLayout TileService a widgets de Wear OS. No lo uses para implementaciones de AppWidgetProvider o GlanceAppWidget en la pantalla de inicio móvil, complicaciones de esferas de reloj o actividades de pantalla completa de Wear OS.
