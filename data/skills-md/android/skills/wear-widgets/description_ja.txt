Glance Wear と Remote Compose を使用して Android プロジェクトで Wear OS ウィジェットを作成、移行、更新、検証します。GlanceWearWidget、GlanceWearWidgetService、WearWidgetDocument、Remote Compose UI プリミティブ（RemoteColumn、RemoteRow、RemoteBox、RemoteText、RemoteImage、RemoteButton）、rememberMutableRemoteInt と valueChange を用いたローカル状態、pendingIntentAction によるクリックアクション、ウィジェットプロバイダ XML コンテナ（SMALL と LARGE）、矩形ウィジェットピッカー PNG プレビュー、またはレガシー ProtoLayout TileService タイルを Wear OS ウィジェットに移行する際にこのスキルを使用してください。モバイルのホーム画面 AppWidgetProvider や GlanceAppWidget 実装、ウォッチフェイスコンプリケーション、フルスクリーン Wear OS アクティビティには使用しないでください。
