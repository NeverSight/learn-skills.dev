在 Android 上使用 Kotlin 並透過 CompiledModel API 在 CPU 與 GPU 上配置與實作 LiteRT（.tflite）裝置端推論。此技能可用於任何 Android LiteRT 或 .tflite 任務，包括 Gradle 設定、影像分類或視覺／音訊／嵌入輔助工具、TensorBuffer 重用、CPU 記憶體最佳化、Bitmap 前處理、AndroidViewModel GPU 至 CPU 的回退（於單執行緒 dispatcher 上預熱）、Google Play 服務中的 LiteRT（play‑services‑litert）、從舊版 org.tensorflow.lite.Interpreter、GpuDelegate 或 play‑services‑tflite 移植，以及延遲效能基準測試。請勿用於執行使用 .litertlm 檔案的生成式文字 LLM，或用於 Python 模型轉換。
