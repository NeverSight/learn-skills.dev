Настраивает и реализует on‑device инференс LiteRT (.tflite) на Android на Kotlin с использованием API CompiledModel на CPU и GPU. Используйте этот навык для любой задачи Android LiteRT или .tflite, включая настройку Gradle, классификацию изображений или вспомогательные функции зрения/аудио/эмбеддингов, повторное использование TensorBuffer, оптимизацию памяти CPU, предобработку Bitmap, AndroidViewModel с переключением GPU‑на‑CPU при отказе и прогревом на однопоточном диспетчере, LiteRT в Google Play services (play‑services‑litert), миграцию с устаревшего org.tensorflow.lite.Interpreter, GpuDelegate или play‑services‑tflite, а также бенчминг задержек. Не используйте для запуска генеративных текстовых LLM с файлами .litertlm или для конвертации моделей Python.
