配置并在 Android 上使用 Kotlin 通过 CompiledModel API 实现 LiteRT（.tflite）设备端推理，可在 CPU 与 GPU 上运行。此技能适用于任何 Android LiteRT 或 .tflite 任务，包括 Gradle 配置、图像分类或视觉/音频/嵌入辅助工具、TensorBuffer 重用、CPU 内存优化、Bitmap 预处理、AndroidViewModel 的 GPU‑to‑CPU 回退（在单线程调度器上预热），以及在 Google Play 服务（play‑services‑litert）中的 LiteRT、从旧版 org.tensorflow.lite.Interpreter、GpuDelegate 或 play‑services‑tflite 迁移，以及延迟基准测试。请勿用于运行带有 .litertlm 文件的生成式文本 LLM 或用于 Python 模型转换。
