Configura e implementa inferencia en dispositivo con LiteRT (.tflite) en Android usando Kotlin y la API CompiledModel en CPU y GPU. Utiliza esta habilidad para cualquier tarea de Android LiteRT o .tflite, incluyendo configuración de Gradle, clasificación de imágenes o asistentes de visión/audio/incrustaciones, reutilización de TensorBuffer, optimización de memoria en CPU, preprocesamiento de Bitmap, AndroidViewModel con fallback de GPU a CPU con calentamiento en un despachador de un solo hilo, LiteRT en los servicios de Google Play (play‑services‑litert), migración desde el legado org.tensorflow.lite.Interpreter, GpuDelegate o play‑services‑tflite, y pruebas de latencia. No lo uses para ejecutar LLM generativos de texto con archivos .litertlm o para la conversión de modelos en Python. Por favor, siempre responde en el idioma del usuario.
