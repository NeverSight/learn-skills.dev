تصميم وتنفيذ ومراجعة واجهة مستخدم احترافية للهاتف المحمول لـ React Native وExpo، مع تصميم مدرك للنظام الأساسي وتوجيهات المراجعة لنظامي التشغيل iOS وAndroid. يُستخدم عندما تتضمن المهمة شاشات الهاتف المحمول، أو المكونات، أو التنقل، أو التوجيه المرئي، أو أنظمة التصميم، أو إمكانية الوصول، أو الإيماءات، أو اللمس، أو الرسوم المتحركة، أو الطباعة، أو اللون، أو الوضع الداكن، أو المناطق الآمنة، أو النوافذ التكيفية، أو الترجمة، أو اصطلاحات النظام الأساسي، أو App Store أو تحسين جودة التشغيل، أو iOS HIG، أو تصميم المواد، أو Expo Router، أو React Navigation، أو Reanimated، أو Gesture Handler، أو نقد UX المحمول.
