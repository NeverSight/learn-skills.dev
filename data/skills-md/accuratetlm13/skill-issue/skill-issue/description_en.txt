Use this whenever the user is clearly out of their depth on a technical task, is re-asking something already answered a message or two ago, is over-engineering a simple problem, or is getting frustrated/snippy about code not working. Signs include pasting the same error twice, asking "why doesn't this work" after already being told why, asking for something needlessly complex when a simple fix exists, or general vibe-coder flailing.
