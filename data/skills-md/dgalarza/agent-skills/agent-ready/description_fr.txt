Rendez une base de code prête pour les agents en créant la structure AGENTS.md, ARCHITECTURE.md et le répertoire docs/, en installant des portes de qualité sensibles aux régressions, et en recommandant des compétences locales au projet et spécifiques à la stack. Analyse la structure de la base de code, génère des artefacts de documentation suivant des schémas de divulgation progressive, installe les commandes de porte de qualité report/check/baseline avec une CI consciente du merge‑base et une base de référence révisée par des humains, et audite les artefacts existants pour détecter l’obsolescence et la cohérence. À utiliser lors de l’amélioration d’une base de code pour le travail d’agents IA.
