Этот навык следует использовать для проведения оценки кодовой базы, готовой к работе с агентом, — оценки кодовой базы по 8 измерениям, получения взвешенного балла (0‑100), оценочного диапазона и дорожной карты улучшений. Выполняйте четыре прохода оценки параллельно, когда среда выполнения поддерживает субагентов, и последовательно в текущем агенте в противном случае. Поддерживает Ruby, Python, PHP, TypeScript, JavaScript, Go, Java, Scala и Rust.

Пожалуйста, всегда отвечайте на языке пользователя.
