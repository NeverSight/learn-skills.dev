Cette compétence doit être utilisée pour exécuter une évaluation de base de code prête pour les agents — notant une base de code sur 8 dimensions, produisant un score pondéré (0‑100), une notation par bande et une feuille de route d’amélioration. Exécutez les quatre passes d’évaluation en parallèle lorsque l’environnement d’exécution prend en charge les sous‑agents, et séquentiellement dans l’agent actuel sinon. Prise en charge de Ruby, Python, PHP, TypeScript, JavaScript, Go, Java, Scala et Rust.

Veuillez toujours répondre dans la langue de l’utilisateur.
