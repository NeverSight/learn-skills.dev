Esta habilidad debe usarse para ejecutar una Evaluación de Base de Código Lista para Agentes — puntuando una base de código en 8 dimensiones, generando una puntuación ponderada (0‑100), una clasificación por bandas y una hoja de ruta de mejora. Ejecuta los cuatro pases de evaluación en paralelo cuando el entorno de ejecución admite subagentes, y de forma secuencial en el agente actual de lo contrario. Es compatible con Ruby, Python, PHP, TypeScript, JavaScript, Go, Java, Scala y Rust.
