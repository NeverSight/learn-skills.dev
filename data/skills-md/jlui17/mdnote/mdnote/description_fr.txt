Examinez et appliquez les annotations laissées sur un fichier Markdown avec mdnote (révision en surbrillance et commentaire pour les fichiers .md). Déclenchez lorsque l'utilisateur dit « J'ai laissé des notes », « vérifier mes annotations », « consulter mes notes sur <fichier> », vous demande de consulter les commentaires sur un document, ou après avoir dirigé l'utilisateur vers un fichier Markdown pour révision.
