Rivedi e applica le annotazioni lasciate su un file Markdown con mdnote (revisione di evidenziazioni e commenti per file .md). Si attiva quando l'utente dice "Ho lasciato note", "controlla le mie annotazioni", "rivedi le mie note su <file>", ti chiede di esaminare il feedback su un documento o dopo aver indirizzato l'utente a un file Markdown per la revisione.
