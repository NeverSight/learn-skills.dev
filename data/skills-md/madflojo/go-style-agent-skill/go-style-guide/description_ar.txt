يُقدِّم إرشادات هندسة Go (Golang) لتصميم الحزم والخدمات وواجهات سطر الأوامر. يُستَخدم كلما كانت المهمة تتضمن تنفيذ Go أو إعادة هيكلة أو مراجعات كود أو تصميم API أو تنظيم الحزمة أو الواجهات أو المُنشئات/الإعدادات أو معالجة الأخطاء أو التسجيل أو اختيار الاعتمادات أو الإطار أو توصيل HTTP/الخدمات أو التزامن/دورة الحياة أو الاختبارات أو المعايير أو godoc أو قرارات الصيانة.
