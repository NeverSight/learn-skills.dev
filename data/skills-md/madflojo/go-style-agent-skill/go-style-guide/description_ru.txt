Предоставляет рекомендации по инженерии Go (Golang) для проектирования пакетов, сервисов и CLI. Используйте, когда задача включает реализацию на Go, рефакторинг, ревью кода, проектирование API, структуру пакетов, интерфейсы, конструкторы/конфигурацию, обработку ошибок, логирование, выбор зависимостей или фреймворка, настройку HTTP/сервисов, конкуренцию/жизненный цикл, тесты, бенчмарки, godoc или решения по поддерживаемости.
