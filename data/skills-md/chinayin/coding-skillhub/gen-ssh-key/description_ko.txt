팀 표준에 따라 SSH 키를 생성하고 공개키를 반환합니다. 기본은 Ed25519이며, 대체로 RSA 4096을 사용합니다 (RSA 2048은 절대 허용되지 않음); 개인키는 chmod 600이며 서비스 이름으로 파일명을 지정합니다. 사용자가 서비스나 머신용 SSH 키, 키페어, 배포 키, 로그인 키를 원하거나 ssh‑keygen/puttygen을 언급할 때마다 이 기능을 사용하십시오 — 예: “ssh 키 생성”, “ssh 키페어 만들기”, “서비스 xxx용 로그인 키 만들기”, “배포 키 생성” — 팀 표준을 언급하지 않더라도 적용됩니다. puttygen(.ppk/.pem/.pub)을 우선 사용하고, 필요 시 ssh‑keygen으로 대체합니다.
