Generieren Sie SSH-Schlüssel gemäß Teamstandards und geben Sie den öffentlichen Schlüssel zurück. Ed25519 standardmäßig, RSA 4096 als Fallback (RSA 2048 ist niemals zulässig); Private Schlüssel sind chmod 600 und nach dem Dienst benannt. Verwenden Sie diesen Skill immer dann, wenn der Benutzer einen SSH-Schlüssel, ein Schlüsselpaar, einen Bereitstellungsschlüssel oder einen Anmeldeschlüssel für einen Dienst oder eine Maschine möchte oder ssh-keygen/puttygen erwähnt – z. B. „SSH-Schlüssel generieren“, „SSH-Schlüsselpaar erstellen“, „Anmeldeschlüssel für Dienst xxx erstellen“, „Bereitstellungsschlüssel generieren“ – auch wenn darin keine Teamstandards erwähnt werden. Bevorzugt Puttygen (.ppk/.pem/.pub); Fällt auf ssh-keygen zurück.
