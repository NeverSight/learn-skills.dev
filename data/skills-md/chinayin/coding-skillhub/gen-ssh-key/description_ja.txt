チーム標準に従って SSH 鍵を生成し、公開鍵を返す。デフォルトは Ed25519、フォールバックは RSA 4096（RSA 2048 は絶対に許可しない）；秘密鍵は chmod 600 に設定し、サービス名で命名する。ユーザーが SSH 鍵、鍵ペア、デプロイ鍵、またはサービスやマシン用のログイン鍵を求める場合、あるいは ssh‑keygen／puttygen に言及した場合は常にこのスキルを使用する—例として「generate ssh key」「create an ssh keypair」「make a login key for service xxx」「generate a deploy key」など、チーム標準が言及されていなくても。puttygen（.ppk/.pem/.pub）を優先し、ssh‑keygen にフォールバックする。

常にユーザーの言語で応答してください。
