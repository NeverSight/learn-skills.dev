根据团队标准生成 SSH 密钥并返回公钥。默认使用 Ed25519，回退使用 RSA 4096（RSA 2048 永不允许）；私钥权限设为 chmod 600，文件名按服务命名。每当用户需要 SSH 密钥、密钥对、部署密钥或服务/机器的登录密钥，或提及 ssh-keygen/puttygen 时，都使用此技能——例如 “generate ssh key”、 “create an ssh keypair”、 “make a login key for service xxx”、 “generate a deploy key”，即使用户未提及团队标准。首选 puttygen（.ppk/.pem/.pub），如不可用则回退到 ssh-keygen。

请始终使用用户的语言回复。
