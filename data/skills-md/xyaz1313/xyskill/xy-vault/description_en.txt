[Knowledge Base] Turn the local folders a user has (client files, inventory tables, social media materials, course transcripts, historical versions of agency policies, live broadcast reviews, etc.) into a knowledge base that AI can reliably search, store, and version-check: if there’s no data, first build the minimal structure; if there is data, generate a “knowledge base navigation” that only points the way, then handle adding new data, finding answers, identifying the latest version, health checks, and slimming down. When the user says “set up a knowledge base,” “let AI understand this pile of documents,” “put this into the knowledge base,” “search the knowledge base,” “which is the latest version,” “update the knowledge base,” or “the navigation is too long, shrink it,” it triggers.
