[Knowledge Base] Transform the local folders the user has (client files, inventory tables, social media materials, course transcripts, historical versions of agency policies, live broadcast reviews, etc.) into a knowledge base that AI can reliably search, reliably store, and reliably handle versioning. If there is no data, first create the minimal structure; if there is data, generate a "knowledge base navigation" that only points the way. Afterwards, it is responsible for adding new data, finding answers, recognizing the latest version, health checks, and slimming down. The user triggers this by saying “set up a knowledge base,” “let AI understand this pile of documents,” “put this into the knowledge base,” “search the knowledge base,” “which one is the latest version,” “update the knowledge base,” “the navigation is too long, trim it.” Trigger words: /xy-vault, /knowledgebase. | Produced by Xiaoye
