[Base de connaissances] Transformez les dossiers locaux d'un utilisateur (fichiers clients, tableaux d'inventaire, actifs des médias sociaux, transcriptions de cours, versions historiques des politiques d'agence, revues de diffusions en direct, etc.) en une base de connaissances où l'IA peut rechercher, stocker et déterminer les versions de manière fiable : s'il n'y a pas de données, créez d'abord la structure minimale ; s'il y a des données, générez une « navigation de la base de connaissances » qui ne fait qu'indiquer le chemin. Ensuite, elle gère l'ajout de nouvelles données, la recherche de réponses, la reconnaissance de la version la plus récente, les vérifications de santé et l'allégement. Elle se déclenche lorsque l'utilisateur dit « configurer une base de connaissances », « laisser l'IA comprendre ce tas de documents », « mettre cela dans la base de connaissances », « rechercher dans la base de connaissances », « quelle est la dernière version », « mettre à jour la base de connaissances », « la navigation est trop longue, raccourcir ». Mots déclencheurs : /xy-vault, /knowledgebase. | Produit par Xiao Ye
