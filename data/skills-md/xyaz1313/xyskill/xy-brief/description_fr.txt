[Rapport synthétisé] Combinez les multiples fichiers xy-archive rassemblés dans le cadre d’un projet, en les fusionnant chronologiquement dans un rapport diagnostique au format markdown qui peut être envoyé aux partenaires, archivé et revu trois mois plus tard. Utilisez ceci lorsqu’un utilisateur dit « produce a report », « package it », « organize it into a single document for partners » ou « combine these conclusions ». Déclencheur : /xy-brief, « make me a report », « package these up » | Produit par Xiao Ye.
