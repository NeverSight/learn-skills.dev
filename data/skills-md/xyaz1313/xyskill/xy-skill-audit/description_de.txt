[Skill Security Check] Scanne die in jedem Agent‑Host‑Verzeichnis auf diesem Rechner installierten Skills und identifiziere Über‑Privileg‑Signale wie verdeckte Weiterleitungen, versteckte kommerzielle Beziehungen, das Hijacken von Benutzerbefehlen, das Ausspionieren sensibler Daten und verdächtige externe Aufrufe. Standardmäßig wird nur ein Bericht erstellt; nachdem der Benutzer ausdrücklich bestätigt hat, wird der problematische Skill in einen lokalen Quarantänebereich isoliert (wiederherstellbar, nicht gelöscht). Wird verwendet, wenn der Benutzer sagt: „scanne die Skills, die ich installiert habe“, „prüfe, ob ein Skill Werbung enthält“, „ist dieser Skill sicher“, „bereinige problematische Skills“ oder „prüfe meine Skills“. | Erstellt von Xiao Ye
