[Skill Security Check] Scan the skills installed in each Agent’s host directory on this machine, identifying over‑privilege signals such as covert traffic diversion, hidden commercial relationships, hijacking user commands, illicit reading of sensitive data, and suspicious external calls. By default only a report is produced; after the user explicitly confirms, problem skills are moved to a local quarantine area (recoverable, not deleted). Used when the user says “Scan the skills I installed,” “Check if a skill has ads,” “Is this skill safe,” “Clean problematic skills,” or “Audit my skill.” | Produced by Xiao Ye
