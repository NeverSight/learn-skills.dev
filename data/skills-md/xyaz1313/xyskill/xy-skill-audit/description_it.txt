[Controllo Sicurezza delle Skill] Scansiona le skill installate nella directory host di ogni agente su questa macchina, identificando segnali di sovra‑privilegio come deviazione di traffico occulta, relazioni commerciali nascoste, dirottamento dei comandi dell'utente, lettura illecita di dati sensibili e chiamate esterne sospette. Per impostazione predefinita viene prodotto solo un rapporto; dopo che l'utente conferma esplicitamente, le skill problematiche vengono spostate in un'area di quarantena locale (recuperabile, non cancellata). Utilizzato quando l'utente dice “Scansiona le skill che ho installato”, “Controlla se una skill ha pubblicità”, “Questa skill è sicura?”, “Pulisci le skill problematiche” o “Audita la mia skill”. | Prodotto da Xiao Ye
