【Comprobación de Seguridad de Habilidades】 Escanee las habilidades instaladas en el directorio host de cada Agente en esta máquina, localice señales no autorizadas como desvío encubierto de tráfico, relaciones comerciales ocultas, secuestro de comandos del usuario, espionaje de datos sensibles y llamadas externas sospechosas; por defecto solo se genera un informe, y la habilidad problemática se traslada a un área de cuarentena local (recuperable, no eliminada) solo después de que el usuario confirme explícitamente. Se utiliza cuando el usuario dice “escanea las habilidades que instalé”, “comprueba si la habilidad tiene anuncios”, “¿esta habilidad es segura?”, “elimina habilidades problemáticas” o “audita mis habilidades”. | Producido por Xiao Ye.
