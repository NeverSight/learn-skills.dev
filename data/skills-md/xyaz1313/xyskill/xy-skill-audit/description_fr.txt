[Contrôle de sécurité des compétences] Analysez les compétences installées dans le répertoire hôte de chaque agent sur cette machine, en identifiant les signaux de sur‑autorisations tels que la redirection furtive, les relations commerciales cachées, le détournement des commandes de l'utilisateur, le vol de données sensibles et les appels externes suspects ; par défaut, seul un rapport est généré, et ce n'est qu'après que l'utilisateur confirme explicitement que les compétences problématiques sont isolées dans une zone de quarantaine locale (réversible, non supprimée). Il est utilisé lorsque l'utilisateur dit « scan the skills I’ve installed », « check if a skill has ads », « is this skill safe », « clean problematic skills » ou « audit my skills ». | Produit par Xiaoye

Veuillez toujours répondre dans la langue de l'utilisateur.
