Guía completa del ciclo de vida — desde una única función decorada hasta una incorporación de 12 pasos al código base — para agregar Traigent a un código base de agente cliente existente y mejorar de manera medible la precisión, el costo, la latencia o la fiabilidad. Utilícela cuando se solicite agregar Traigent a un código base de agente existente, incorporar este agente a Traigent de extremo a extremo, ejecutar un ciclo de vida completo de construcción del agente, conectar un evaluador y optimizar un agente con código para instrumentar, aumentar la precisión/costo de un agente existente, seleccionar TVARs con generate_config() en el código del agente, elegir perillas compuestas según la forma del agente, instrumentar @traigent.optimize en el código del agente, validar en modo simulación, ejecutar la optimización real con presupuestos, inspeccionar resultados, iterar para refinar un agente existente o validar una configuración promocionada. Para usuarios completamente nuevos sin un código base de agente existente, consulte traigent-setup-quickstart. SIEMPRE comience con una ejecución en seco (modo simulación) para validar todo el pipeline, y cambie a ejecución real solo cuando el usuario lo solicite explícitamente.
