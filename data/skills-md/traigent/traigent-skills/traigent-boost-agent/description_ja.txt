エンドツーエンドのライフサイクルプレイブック — 1つのデコレートされた関数から、12ステップのコードベースオンボーディング全体まで — 既存のクライアントエージェントコードベースに Traigent を追加し、精度、コスト、レイテンシ、または信頼性を測定可能に向上させるためのものです。既存のエージェントコードベースに Traigent を追加し、このエージェントをエンドツーエンドで Traigent にオンボードし、エージェント構築ライフサイクルをフルに実行し、評価器を組み込み、コードに計測用インストゥルメントを追加して精度・コストを向上させる、agent code 上で generate_config() を用いて TVAR を選択する、エージェントの形状に応じた複合ノブを選ぶ、@traigent.optimize をエージェントコードに組み込む、モックモードで検証する、予算付きで本番最適化を実行する、結果を検査する、既存エージェントを洗練させるために反復する、またはプロモートされた設定をゲートする、という場合に使用してください。既存のエージェントコードベースがない全く新しいユーザーは、traigent-setup-quickstart を参照してください。必ず最初にドライラン（モックモード）でパイプライン全体を検証し、ユーザーが明示的に要求したときだけ実際の実行に切り替えてください。
