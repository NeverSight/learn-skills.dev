Guide complet du cycle de vie — d’une fonction décorée unique à une intégration en 12 étapes du code — pour ajouter Traigent à une base de code d’agent client existante et augmenter de manière mesurable la précision, le coût, la latence ou la fiabilité. À utiliser lorsqu’on vous demande d’ajouter Traigent à une base de code d’agent existante, d’intégrer cet agent à Traigent de bout en bout, d’exécuter un cycle complet de construction d’agent, de connecter un évaluateur et d’optimiser un agent avec du code à instrumenter, d’améliorer la précision/le coût d’un agent existant, de sélectionner des TVAR avec generate_config() sur le code de l’agent, de choisir des réglages composites selon la forme de l’agent, d’instrumenter @traigent.optimize dans le code de l’agent, de valider en mode simulation, d’exécuter une optimisation réelle avec des budgets, d’inspecter les résultats, d’itérer pour affiner un agent existant, ou de valider une configuration promue. Pour les nouveaux utilisateurs ne disposant pas d’une base de code d’agent, voir traigent-setup-quickstart. TOUJOURS commencer par un test à sec (mode simulation) pour valider l’ensemble du pipeline, puis passer à l’exécution réelle uniquement lorsque l’utilisateur le demande explicitement.
