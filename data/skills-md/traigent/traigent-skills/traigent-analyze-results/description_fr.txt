Analyse et rapporte les résultats d'optimisation de Traigent depuis le terminal — sans ouvrir les onglets du portail. Utilise lorsqu'un utilisateur demande d'analyser une exécution, « comment s'est passée ma run ? », « analyse ma dernière exécution dans le projet X », quel est le gagnant, ou pour lire les champs de résultats, les rapports, les classements, les compromis de Pareto, les corrélations, ou les insights sur les paramètres/exemples. Les questions de décision sont dirigées vers `traigent-analyze-guidance` (Mode B pour les runs suivis par le portail, Mode C pour hors ligne/local). Couvre également l'objet local OptimizationResult : lecture de results.best_config, comparaison des essais, vérification de stop_reason, application automatique de la meilleure configuration, exportation de candidats, accès à total_cost ou total_tokens, ou compréhension des raisons de l'arrêt de l'optimisation.
