Installez et intégrez le SDK Traigent dans un projet existant, puis récupérez la première valeur. Utilisez-le lorsque l'utilisateur souhaite installer Traigent, configurer sa première optimisation, créer un jeu de données d’évaluation ou se lancer avec @traigent.optimize ; un tout nouveau utilisateur disposant d’un agent à optimiser bénéficie davantage de la première exécution guidée (Traigent/traigent-first-run), à laquelle cette compétence renvoie. Couvre l’installation via pip, la configuration de la clé API, le mode mock, un guide pas à pas linéaire pour obtenir la première valeur, et le lancement d’une première optimisation.
