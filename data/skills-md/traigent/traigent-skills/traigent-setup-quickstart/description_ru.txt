Установите и подключите SDK Traigent в существующий проект, получив из него первое значение. Используйте, когда пользователь хочет установить Traigent, настроить свою первую оптимизацию, создать набор данных для оценки или начать работу с @traigent.optimize; новому пользователю с агентом для оптимизации лучше подходит пошаговый первый запуск (Traigent/traigent-first-run), на который указывает эта функция. Охватывает установку через pip, настройку API‑ключа, режим имитации, линейный пошаговый ввод первого значения и запуск первой оптимизации.
