Configurez et exécutez l'optimisation native JavaScript/TypeScript avec @traigent/sdk. Utilisez‑le lorsqu’un utilisateur demande d’optimiser une fonction d’agent JS/TS : utilisez optimize(spec)(agentFn), configurez les espaces de recherche param.*, définissez les métriques evaluation.data/loadData, utilisez getTrialParam/getTrialConfig, ou rédigez des spécifications d’espace de configuration routées par le backend pour les services compatibles Traigent.

Veuillez toujours répondre dans la langue de l’utilisateur.
