Crea e migliora un dataset di valutazione Traigent / set di valutazione JSONL. Usalo quando ti viene chiesto di creare un dataset di valutazione, verifica se gli esempi sono sufficientemente buoni, sintetizza più esempi, espandi il dataset, assegna un punteggio agli esempi dopo un’esecuzione, ispeziona la qualità del dataset, progetta una suddivisione di holdout, evita perdite nei dati di valutazione, rifletti sugli esempi difficili, lavora sugli ID di esempi difficili o difettosi segnalati dal server, mappa gli ID degli esempi segnalati al contenuto locale o esegui il ciclo di riflessione sul contenuto dopo un’esecuzione. 

Rispondi sempre nella lingua dell'utente.
