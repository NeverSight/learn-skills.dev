Cree o revise las especificaciones del producto vivo de un proyecto (docs/product.md), la forma actual prevista del producto y la descripción general necesaria para el lector (docs/overview.md), una breve página ilustrada para las personas. Utilícelo cuando el usuario pida redactar o actualizar las especificaciones o la descripción general del producto, o cuando una decisión tomada cambie lo que debería ser el producto. No es para el plan de un cambio (plan-work) ni para el estado de progreso (wayfinder).
