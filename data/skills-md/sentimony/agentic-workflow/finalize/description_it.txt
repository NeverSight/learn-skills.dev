DEVI usarlo quando un lavoro verificato attende una decisione su come lasciare il branch - fondendolo, spingendolo, aprendo una pull request (PR), mantenendo il branch, scartando il branch o pulendo un worktree o un workspace - in qualsiasi repository. Non è per lavoro non ancora verificato (verify), risultati di revisione aperti (cr-received), un semplice commit senza decisione di integrazione o lavoro di rilascio con la propria checklist. Sostituisce devflow branch-finish.

Rispondi sempre nella lingua dell'utente.
