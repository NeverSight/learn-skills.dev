DEBE usar esto antes de ejecutar un comando de GitHub CLI con alcance de proyecto (gh pr, issue, repo, api, release, run) contra github.com, nuevamente antes de cada comando gh posterior en la misma sesión, después de que un comando gh falle con un error de acceso como "Could not resolve to a Repository", y cuando se le solicite verificar o cambiar la cuenta gh para el proyecto actual. Cambia gh a la cuenta ya iniciada cuyo nombre está en GH_ACC en el .env/.env del proyecto y reporta el cambio en una sola línea. No es para operaciones git o SSH simples, salida de ayuda o versión de gh, iniciar sesión, o hosts diferentes a github.com.
