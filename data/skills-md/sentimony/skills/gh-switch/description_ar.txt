يجب عليك استخدام هذا قبل تشغيل أمر GitHub CLI نطاقه مشروع (gh pr، issue، repo، api، release، run) ضد github.com، ثم مرة أخرى قبل كل أمر gh لاحق في نفس الجلسة، بعد فشل أمر gh مع خطأ وصول مثل «Could not resolve to a Repository»، وعند طلب التحقق أو تبديل حساب gh للمشروع الحالي. يقوم بتحويل gh إلى الحساب المسجَّل الدخول بالفعل والمسمي بـ GH_ACC في ملف .env/.env الخاص بالمشروع ويُبلغ عن التحويل في سطر واحد. ليس لأوامر git العادية أو عمليات SSH، أو لمساعدة gh أو مخرجات الإصدار، أو تسجيل الدخول، أو للمضيفين غير github.com.
