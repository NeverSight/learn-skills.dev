DEVI usare questo prima di eseguire un comando GitHub CLI a livello di progetto (gh pr, issue, repo, api, release, run) contro github.com, di nuovo prima di ogni successivo comando gh nella stessa sessione, dopo che un comando gh è fallito con un errore di accesso come “Could not resolve to a Repository”, e quando ti viene chiesto di controllare o cambiare l’account gh per il progetto corrente. Cambia gh sull’account già connesso denominato da GH_ACC nei file .env/.env del progetto e segnala il cambiamento in una sola riga. Non vale per operazioni git o SSH normali, per l’aiuto o l’output della versione di gh, per il login o per host diversi da github.com.
