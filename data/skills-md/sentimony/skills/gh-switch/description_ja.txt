プロジェクトスコープの GitHub CLI コマンド（gh pr、issue、repo、api、release、run）を github.com に対して実行する前に、同じセッション内で後の gh コマンドを実行するたびに、または「Could not resolve to a Repository」などのアクセスエラーで gh コマンドが失敗した後に、さらに現在のプロジェクトで gh アカウントの確認や切り替えが求められたときに、これを必ず使用しなければなりません。これにより、プロジェクトの .env/.env に記載された GH_ACC で指定された既にログイン済みのアカウントに gh を切り替え、切り替えを一行で報告します。純粋な git や SSH 操作、gh help やバージョン出力、ログイン、github.com 以外のホストには適用されません。
