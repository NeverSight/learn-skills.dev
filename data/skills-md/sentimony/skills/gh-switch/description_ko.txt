이것은 github.com에 대해 프로젝트 범위의 GitHub CLI 명령(gh pr, issue, repo, api, release, run)을 실행하기 전에 반드시 사용해야 하며, 동일 세션에서 이후의 모든 gh 명령을 실행하기 전에도 다시 사용해야 하고, “Could not resolve to a Repository”와 같은 접근 오류로 gh 명령이 실패했을 때, 그리고 현재 프로젝트의 gh 계정을 확인하거나 전환하라는 요청이 있을 때 사용해야 합니다. 그것은 프로젝트의 .env/.env에 정의된 GH_ACC 변수에 의해 지정된 이미 로그인된 계정으로 gh를 전환하고, 전환 사항을 한 줄로 보고합니다. 일반 git이나 SSH 작업, gh 도움말이나 버전 출력, 로그인 과정, github.com이 아닌 호스트에 대해서는 적용되지 않습니다. 항상 사용자의 언어로 답변해 주세요.
