Vous DEVEZ l’utiliser avant d’exécuter une commande GitHub CLI liée au projet (gh pr, issue, repo, api, release, run) contre github.com, de nouveau avant chaque commande gh ultérieure dans la même session, après qu’une commande gh échoue avec une erreur d’accès telle que « Could not resolve to a Repository », et lorsqu’on vous demande de vérifier ou de changer le compte gh pour le projet actuel. Elle passe gh au compte déjà connecté nommé par GH_ACC dans le .env/.env du projet et indique le changement en une ligne. Pas pour les opérations git ou SSH simples, l’aide ou la sortie de version de gh, la connexion, ou les hôtes autres que github.com.
