DEVI usarlo quando utilizzi credenziali da file .env, variabili d'ambiente o configurazioni per chiamare servizi reali (API, CLI, database), quando verifichi l'esistenza delle chiavi richieste, quando ti viene chiesto di mostrare i valori delle credenziali o dell'ambiente, o quando scrivi testi di commit, PR, issue o log dopo che le credenziali sono state usate nella sessione – così i valori segreti rimangono fuori dall'output dell'agente mentre il lavoro viene comunque eseguito.
