Devi usare questo quando crei, migliori, valuti o ottimizzi una skill di agente, decidi se un workflow necessita di una skill riutilizzabile, definisci la sua capacità, il limite di trigger, l'architettura, il contratto di output, il livello di verifica, la strategia di valutazione, il baseline o le evidenze, o decidi se dividere, unire, semplificare, ritirare o sostituire una skill. Questo include domande poco specificate su come trasformare un workflow ripetuto in una skill, scegliere la verifica per una skill proposta o mostrare evidenze che un miglioramento ha cambiato il comportamento. Quando una di queste decisioni di crafting è presente, invoca la creazione della skill prima di rispondere o chiedere chiarimenti. Instrada la manutenzione dell'architettura delle istruzioni AGENTS.md, CLAUDE.md o SKILL.md verso maintaining-agent-context, i piani di implementazione definiti verso plan-crafting e le correzioni del comportamento del codice verso tdd.

Per favore rispondi sempre nella lingua dell'utente.
