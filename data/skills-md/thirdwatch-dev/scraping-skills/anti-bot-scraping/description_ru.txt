Используйте, когда сайт блокирует ваш скрейпер и вам нужно обойти это — 403 Forbidden при первом запросе, JS‑челленджи, CAPTCHA, Cloudflare Turnstile, DataDome, Akamai, PerimeterX, «Just a moment…», отказ в доступе, блокировки IP или пустая/скелетная страница вместо данных. Охватывает диагностику временных сбоев versus реальные блокировки, лестницу техник от самого дешевого (обычный HTTP → подделка отпечатка TLS → stealth‑браузер → полноценный браузер), подделку TLS с помощью impit/curl_cffi, настройку stealth‑браузера Camoufox, клик по iframe Cloudflare Turnstile, прогрев домашней страницы для защиты на основе куки, повторное использование куки браузера, перехват XHR, выбор прокси (резидентный vs дата‑центрический vs SERP) и какие цели действительно противостоят доступным обходам. Срабатывает на запросы типа «сайт меня блокирует», «получаю 403», «Cloudflare», «DataDome», «Turnstile», «CAPTCHA», «обойти анти‑бот», «скрейпер перестал работать», «заблокирован».
