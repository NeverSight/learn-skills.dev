Usa quando avvii qualsiasi attività di web scraping o estrazione di dati strutturati e devi decidere COME ottenere i dati — se chiamare un'API, utilizzare uno scraper pronto all'uso o crearne uno personalizzato. Copre la scala di tecniche “cost‑first” (HTTP semplice → spoofing dell’impronta TLS → browser stealth → browser completo), la decisione costruire vs acquistare, l’ordine di priorità dell’estrazione dei dati, le scelte di proxy, il rate limiting e le basi legali/compliance. Si attiva con “scrape”, “estrarre dati da sito web”, “crawl”, “come ottengo dati da X”, “esiste uno scraper per X”.
