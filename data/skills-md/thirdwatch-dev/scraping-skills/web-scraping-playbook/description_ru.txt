Используйте при начале любой задачи веб‑скрапинга или извлечения структурированных данных, когда нужно решить, КАК получить данные — вызывать API, использовать готовый скрапер или создавать собственный. Охватывает лестницу техник с приоритетом экономии (обычный HTTP → подделка TLS‑отпечатка → скрытый браузер → полноценный браузер), решение «строить или покупать», порядок приоритетов извлечения данных, выбор прокси, ограничение скорости и основы правовых/комплаенс вопросов. Срабатывает на запросы «scrape», «extract data from website», «crawl», «how do I get data from X», «is there a scraper for X».
