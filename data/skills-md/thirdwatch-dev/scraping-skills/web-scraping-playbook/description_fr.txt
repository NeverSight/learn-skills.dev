Utilisez-le lors du lancement de toute tâche de scraping Web ou d'extraction de données structurées et lorsque vous devez décider COMMENT obtenir les données — qu'il s'agisse d'appeler une API, d'exécuter un scraper prêt à l'emploi ou d'en créer un sur mesure. Couvre l'échelle de techniques axée sur le coût (HTTP simple → usurpation d'empreinte TLS → navigateur furtif → navigateur complet), la décision de construire ou d'acheter, l'ordre de priorité d'extraction des données, les choix de proxy, la limitation du débit et les bases juridiques/compliance. Se déclenche sur « scrape », « extraire des données d'un site web », « crawler », « comment obtenir des données de X », « existe-t-il un scraper pour X ».
