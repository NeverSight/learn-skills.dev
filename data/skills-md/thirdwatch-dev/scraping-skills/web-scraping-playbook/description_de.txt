Verwenden Sie dies, wenn Sie eine Web‑Scraping‑ oder strukturierte‑Daten‑Extraktionsaufgabe starten und entscheiden müssen, WIE Sie die Daten erhalten — ob Sie eine API aufrufen, einen fertigen Scraper einsetzen oder einen eigenen bauen. Deckt die kosten‑first‑Technik‑Leiter ab (plain HTTP → TLS‑Fingerprint‑Spoof → Stealth‑Browser → Full‑Browser), die Build‑vs‑Buy‑Entscheidung, die Prioritätsreihenfolge für die Datenerfassung, Proxy‑Optionen, Rate‑Limiting und die Grundlagen zu Rechts‑ und Compliance‑Aspekten. Wird ausgelöst bei „scrape“, „extract data from website“, „crawl“, „how do I get data from X“, „is there a scraper for X“.
