Webスクレイピングや構造化データ抽出タスクを開始する際に、データ取得方法―APIを呼び出すか、既製のスクレイパーを使用するか、カスタムスクレイパーを作成するか―を決定する必要があるときに使用します。コスト優先の技術階層（プレーンHTTP → TLS指紋偽装 → ステルスブラウザ → フルブラウザ）、自作か購入かの判断、データ抽出の優先順位、プロキシの選択、レートリミット、法務・コンプライアンスの基本を網羅しています。「scrape」「extract data from website」「crawl」「how do I get data from X」「is there a scraper for X」などに反応します。
