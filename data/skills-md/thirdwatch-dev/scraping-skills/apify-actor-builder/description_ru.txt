Используйте, когда хотите упаковать веб‑скрейпер в развертываемый, монетизируемый Apify Actor на Python — настроить структуру каталогов, выбрать шаблон выполнения (HTTP / impit / Playwright / Camoufox), написать схемы входных/выходных данных и набора данных, развернуть с помощью apify CLI и настроить ценообразование «pay‑per‑event». Срабатывает по триггерам «создать Apify actor», «развернуть/опубликовать скрейпер в Apify», «монетизировать скрейпер», «ценообразование pay‑per‑event», «схема входных данных Apify», «схема выходных данных Apify», «actor.json».
