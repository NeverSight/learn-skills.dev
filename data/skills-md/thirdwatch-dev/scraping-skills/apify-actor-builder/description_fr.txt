Utilisez lorsque vous souhaitez empaqueter un scraper web en tant qu’Apify Actor déployable et monétisable en Python — configurez la structure de répertoires, choisissez un modèle d’exécution (HTTP / impit / Playwright / Camoufox), rédigez les schémas d’entrée/sortie/dataset, déployez avec le CLI apify et configurez la tarification pay‑per‑event. Déclencheurs sur « build an Apify actor », « deploy/publish a scraper to Apify », « monetize a scraper », « pay-per-event pricing », « Apify input schema », « Apify output schema », « actor.json ».
