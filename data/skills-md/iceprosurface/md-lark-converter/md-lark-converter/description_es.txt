Conversión bidireccional entre documentos Markdown y Feishu (Lark) utilizando las herramientas CLI md2fs y fs2md. Utilice esta habilidad siempre que el usuario mencione las URL de Feishu, Lark, 飞书, feishu.cn, md2fs, fs2md, md-lark-converter, pegar documentos en Feishu, exportar desde Feishu, convertir hacia/desde el formato Feishu, sincronizar contenido con Feishu, configurar cookies de Feishu o cualquier flujo de trabajo que involucre documentos Markdown y Feishu, incluso si no dicen explícitamente "convertir". También se activa cuando el usuario comparte un enlace feishu.cn o lark.
