Barry Student Profile Section 1 (Personal Basic Information) – collection and update. A 10–20 minute guided deep interview that digs into the learner’s work context, pain points, goals, time commitment, and learning history, written to `~/.barry-english/profile.md`. Newcomers’ first run is launched by barry‑onboarding; existing learners invoke it themselves to refresh the profile (when changing jobs, roles, or adjusting goals). Trigger phrases: basic information, update profile, update basic information, I changed jobs, profile update.
