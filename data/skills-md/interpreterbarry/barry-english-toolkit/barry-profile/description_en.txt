Barry Student Profile – Section 1 (Personal Basic Information) Collection and Update. Conduct a guided, in‑depth interview lasting 10–20 minutes to thoroughly explore the learner’s work context, pain points, goals, time commitment, and learning history, then write the findings to `~/.barry-english/profile.md`. New users start with a run initiated by barry‑onboarding; returning learners invoke it themselves to refresh the profile (e.g., after changing jobs, roles, or goals). Trigger phrases: basic information, update profile, update basic information, I changed jobs, profile update.
