À utiliser lorsque l’utilisateur demande d’améliorer, d’ajouter ou de nettoyer les commentaires de code, en privilégiant le POURQUOI plutôt que le QUOI. Lit les fichiers spécifiés (ou ceux récemment modifiés), ajoute des commentaires en ligne stratégiques pour la logique non évidente, supprime les commentaires redondants et convertit les commentaires de type QUOI en commentaires de type POURQUOI. Accepte des $ARGUMENTS facultatifs pour les fichiers cibles.
