Úselo cuando se acumulen ramas de Git obsoletas después de que se fusionen las solicitudes de extracción: ramas locales marcadas como [gone], ramas fusionadas mediante squash que `git branch --merged` no enumera o ramas remotas sobrantes en un repositorio sin eliminación automática. Úselo también cuando el usuario indique las ramas que deben purgarse o solicite limpiar, eliminar o purgar ramas.
