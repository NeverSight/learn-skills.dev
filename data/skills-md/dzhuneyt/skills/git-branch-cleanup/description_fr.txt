À utiliser lorsque des branches Git obsolètes s'accumulent après la fusion de pull requests : branches locales marquées [gone], branches fusionnées par squash que `git branch --merged` n'indique pas, ou branches distantes restantes dans un dépôt sans suppression automatique. À utiliser également lorsque l'utilisateur nomme des branches à purger ou demande de nettoyer, d'élaguer ou de purger des branches.
