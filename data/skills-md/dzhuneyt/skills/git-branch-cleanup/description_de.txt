Verwenden Sie diese Option, wenn sich nach dem Mergen von Pull Requests veraltete Git-Branches ansammeln – lokale Branches, die mit [gone] gekennzeichnet sind, Squash-Merged-Branches, die nicht von `git branch --merged` aufgelistet werden, oder übrig gebliebene Remote-Branches in einem Repository ohne automatische Löschung. Verwende diese Option auch, wenn der Benutzer Branches benennt, die gelöscht werden sollen, oder darum bittet, Branches zu bereinigen, zu bereinigen oder zu löschen.
