Déleguez une tâche de codage au MiniMax Code CLI (`mcode`) en tant qu'implémenteur en arrière-plan, puis examinez son diff et intégrez‑le vous‑même. Utilisez cela chaque fois que l’utilisateur veut confier le travail d’implémentation à MiniMax Code ou à un modèle MiniMax — des formulations comme « faire faire X à MiniMax », « déléguer ceci à mcode », « le faire passer par MiniMax Code » ou « utiliser MiniMax pour implémenter/corriger/refactoriser » — ou pour exécuter une file d’attente de tâches de codage via MiniMax Code tout en restant le relecteur. NE L’UTILISEZ PAS pour des tâches suffisamment petites pour être faites en ligne, ou lorsque l’utilisateur souhaite que le code soit écrit directement sans délégation.

Veuillez toujours répondre dans la langue de l’utilisateur.
