فوض مهمة ترميز إلى واجهة سطر أوامر MiniMax Code (`mcode`) كمنفذ خلفي، ثم راجع فرق التغييرات (diff) ودمّجها بنفسك. استخدم هذا كلما أراد المستخدم تسليم عمل التنفيذ إلى MiniMax Code أو نموذج MiniMax — عبارات مثل «اجعل MiniMax يقوم بـ X»، «فوض هذا إلى mcode»، «شغّله عبر MiniMax Code»، أو «استخدم MiniMax للتنفيذ/الإصلاح/إعادة الهيكلة» — أو لتشغيل طابور من مهام الترميز عبر MiniMax Code مع البقاء كمراجع. لا تُستخدم للمهام الصغيرة التي يمكن إنجازها مباشرة، أو عندما يريد المستخدم كتابة الكود مباشرةً دون تفويض.
