Delega un compito di programmazione al MiniMax Code CLI (`mcode`) come implementatore in background, quindi rivedi il suo diff e applicalo tu stesso. Usa questo ogni volta che l'utente vuole affidare il lavoro di implementazione a MiniMax Code o a un modello MiniMax — espressioni come “far fare X a MiniMax”, “delegare questo a mcode”, “eseguirlo tramite MiniMax Code” o “usare MiniMax per implementare/fissare/rifattorizzare” — o per eseguire una coda di compiti di codifica attraverso MiniMax Code mantenendo il ruolo di revisore. NON USARE per compiti troppo piccoli da fare inline, o quando l'utente desidera il codice scritto direttamente senza delegare.

Rispondi sempre nella lingua dell'utente.
