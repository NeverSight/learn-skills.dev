Делегируйте задачу по коду CLI MiniMax Code (`mcode`) как фонового исполнителя, затем проверьте её diff и примените её сами. Используйте это каждый раз, когда пользователь хочет передать работу по реализации MiniMax Code или модели MiniMax — фразы типа «попросить MiniMax сделать X», «делегировать это mcode», «запустить через MiniMax Code» или «использовать MiniMax для реализации/исправления/рефакторинга» — или чтобы запустить очередь задач через MiniMax Code, оставаясь ревьюером. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточных для выполнения в строке, или когда пользователь хочет получить код напрямую без делегирования.

Всегда отвечайте на языке пользователя.
