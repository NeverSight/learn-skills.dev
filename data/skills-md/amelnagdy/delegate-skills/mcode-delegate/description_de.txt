Delegiere eine Programmieraufgabe an die MiniMax Code CLI (`mcode`) als Hintergrundimplementierer, prüfe anschließend den Diff und führe sie selbst aus. Verwende dies immer, wenn der Nutzer Implementierungsarbeit an MiniMax Code oder ein MiniMax‑Modell übergeben möchte – Formulierungen wie „lasse MiniMax X machen“, „delegiere das an mcode“, „führe es durch MiniMax Code aus“ oder „nutze MiniMax, um zu implementieren/fixieren/refaktorisieren“ – oder um eine Warteschlange von Programmieraufgaben durch MiniMax Code laufen zu lassen, während du der Reviewer bleibst. NICHT VERWENDEN für Aufgaben, die klein genug sind, um inline erledigt zu werden, oder wenn der Nutzer den Code direkt ohne Delegation geschrieben haben möchte.
