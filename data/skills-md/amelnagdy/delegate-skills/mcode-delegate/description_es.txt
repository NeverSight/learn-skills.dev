Delega una tarea de codificación al CLI MiniMax Code (`mcode`) como implementador en segundo plano, luego revisa su diff y aplícala tú mismo. Usa esto siempre que el usuario quiera encargar el trabajo de implementación a MiniMax Code o a un modelo MiniMax — expresiones como “hacer que MiniMax haga X”, “delegar esto a mcode”, “pasarlo por MiniMax Code” o “usar MiniMax para implementar/arreglar/refactorizar” — o para ejecutar una cola de tareas de codificación a través de MiniMax Code mientras permaneces como revisor. NO LO UTILICES para tareas lo suficientemente pequeñas como para hacerlas directamente, o cuando el usuario quiera el código escrito sin delegar.
