Делегируйте задачу по кодированию Muse Code (`muse`) как фоновому исполнителю, а затем самостоятельно просмотрите её дифф и примените изменения. Используйте это каждый раз, когда пользователь хочет передать работу по реализации Muse — формулировки типа «попросить Muse сделать X», «делегировать это Muse», «пропустить через Muse» или «использовать Muse для реализации/исправления/рефакторинга» — или когда пользователь хочет запустить очередь задач по кодированию через Muse, оставаясь при этом ревьюером. Предпочтительно использовать, когда пользователь будет просматривать дифф и самостоятельно делать коммит. Это применяется только когда пользователь хочет отдельный запуск `muse exec`: если вы сами Muse и пользователь просто просит вас написать код, делайте это напрямую. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы выполнить их непосредственно.
