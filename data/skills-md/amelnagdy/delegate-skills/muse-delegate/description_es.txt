Delegar una tarea de codificación a Muse Code (`muse`) como implementador en segundo plano, luego revisar su diff y aplicar los cambios tú mismo. Utilízalo siempre que el usuario quiera encargar el trabajo de implementación a Muse — expresiones como “hacer que Muse haga X”, “delegar esto a Muse”, “pasarlo por Muse” o “usar Muse para implementar/arreglar/refactorizar” — o quiera ejecutar una cola de tareas de codificación a través de Muse mientras sigue siendo el revisor. Prefiérelo cuando el usuario revisará el diff y lo comprometerá él mismo. Solo se aplica cuando el usuario desea ejecutar ese implementador separado `muse exec`: si tú eres Muse y el usuario simplemente te pide que escribas el código, hazlo directamente. NO LO UTILICES para tareas lo suficientemente pequeñas como para hacerse en línea.

Por favor, responde siempre en el idioma del usuario.
