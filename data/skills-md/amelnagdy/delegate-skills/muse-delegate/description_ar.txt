قم بتفويض مهمة برمجية إلى Muse Code (`muse`) كمنفّذ خلفي، ثم راجع الفرق (diff) الخاص به ودمّجه بنفسك. استخدم ذلك كلما أراد المستخدم تسليم عمل التنفيذ إلى Muse — عبارات مثل «اجعل Muse يقوم بـ X»، «فَوِّض هذا إلى Muse»، «شغّله عبر Muse»، أو «استخدم Muse للتنفيذ/الإصلاح/إعادة الهيكلة» — أو أراد تشغيل طابور من مهام البرمجة عبر Muse مع البقاء كمراجع. يفضَّل ذلك عندما سيُراجِع المستخدم الفرق ويلتزم به بنفسه. ينطبق فقط عندما يرغب المستخدم في تشغيل منفّذ `muse exec` منفصل: إذا كنت أنت Muse نفسه وطلب منك المستخدم ببساطة كتابة الكود، فقم بذلك مباشرة. لا تستخدمه للمهام الصغيرة التي يمكن تنفيذها مباشرة.

الرجاء دائمًا الرد بلغة المستخدم.
