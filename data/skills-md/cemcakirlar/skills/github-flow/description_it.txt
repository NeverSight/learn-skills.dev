Automatizza l'intero ciclo di vita di un issue su GitHub, avviando il lavoro, i controlli di qualità, l'apertura di PR con collegamento issue via GraphQL, lo squash‑merge, la sincronizzazione dello stato della board di progetto e i webhook di deployment post‑merge. Usalo per la presa in carico standardizzata degli issue, il collegamento delle PR e i flussi di deployment tra progetti. Si attiva su flow.sh, flusso di issue, avvia issue, spedisce PR, collega PR, hook di deployment e richieste di workflow del ciclo di vita di GitHub.
