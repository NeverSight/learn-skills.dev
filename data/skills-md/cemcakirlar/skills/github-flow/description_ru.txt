Использовать для стандартизированного выбора задач, привязки PR‑ов и потоков развертывания в разных проектах. Триггеры: flow.sh, issue flow, start issue, ship PR, link PR, deploy hook и запросы рабочего процесса жизненного цикла GitHub.
