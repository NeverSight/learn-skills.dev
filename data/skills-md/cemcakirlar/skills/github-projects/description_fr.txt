Travaillez avec GitHub Projects v2 à partir de la ligne de commande en utilisant gh project et GraphQL via gh api. À utiliser pour les tableaux, les champs personnalisés, les itérations, l'ajout de problèmes ou de demandes d'extraction en tant qu'éléments, la modification de l'état et de la priorité, la liste et la requête d'éléments. Déclenchements sur le projet GitHub, le tableau de bord de projet, le projet gh, l'ajout au projet, le champ de sprint, l'élément de projet, le tableau de bord de feuille de route et les demandes similaires de projets v2.
