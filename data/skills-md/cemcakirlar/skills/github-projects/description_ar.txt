العمل مع GitHub Projects v2 من سطر الأوامر باستخدام gh project و GraphQL عبر gh api. استخدمه للوحّات، الحقول المخصَّصة، الفترات، إضافة القضايا أو طلبات السحب كعناصر، تعديل الحالة والأولوية، سرد واستعلام العناصر. المشغلات على مشروع GitHub، لوحة المشروع، gh project، إضافة إلى المشروع، حقل السبرينت، عنصر المشروع، لوحة خريطة الطريق، وما إلى ذلك من طلبات Projects v2 المشابهة. يرجى دائماً الرد بلغة المستخدم.
