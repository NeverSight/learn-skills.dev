Travaillez sur les référentiels GitHub à partir de la ligne de commande avec git et l'interface de ligne de commande gh officielle. À utiliser pour le clonage, la branche, la validation, le push, les problèmes, les demandes de pull, les révisions, les vérifications, les versions, les exécutions d'actions, les forks, la recherche de code et les appels d'API GitHub. Déclencheurs sur GitHub, gh, git repo, ouvrez une RP, créez un problème, fusionnez la demande de tirage, examinez la RP, l'api gh, la version, le flux de travail, le fork et les demandes de flux de travail similaires.
