اعمل على مستودعات GitHub من سطر الأوامر باستخدام git وواجهة gh الرسمية. استخدمها للنسخ (clone) والفروع والالتزام (commit) والدفع (push) والقضايا وطلبات السحب والمراجعات والفحوصات والإصدارات وتشغيل الإجراءات (Actions) والفُروع المنقولة (forks) والبحث في الشيفرة واستدعاءات واجهة برمجة تطبيقات GitHub. تُستَ triggers على GitHub، gh، مستودع git، فتح طلب سحب، إنشاء قضية، دمج طلب سحب، مراجعة طلب سحب، gh api، الإصدار، تشغيل سير العمل، الفُرْع، وطلبات مماثلة للمستودع وسير العمل.
