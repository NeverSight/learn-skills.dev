قم بإعداد عملية إصدار آمنة لحزمة مفتوحة المصدر بحيث لا يوجد رمز نشر طويل الأمد يمكن سرقته. يغطي النشر الموثوق باستخدام OIDC، وإثبات بناء المصدر، وسير عمل إصدارات معتمد على الموافقة لـ npm و PyPI و RubyGems و crates.io و NuGet و Maven Central و Hex و pub.dev وصور الحاوية، بالإضافة إلى تدفق النشر عبر العلامة لوحدات Go و Packagist، على كل من GitHub Actions و GitLab CI/CD. استخدمه لأي طلب نشر حزمة أو صورة حاوية، لتأمين أو تعزيز عملية الإصدار، لإعداد النشر الموثوق أو إثبات المصدر، لإنشاء SBOM، لتوقيع ثنائيات الإصدار، لنشر قيم التحقق (checksums) لأصول الإصدار، أو لإنشاء سير عمل إصدار.
