Configura un proceso de lanzamiento seguro para un paquete de código abierto de modo que no exista un token de publicación de larga duración que pueda ser robado. Cubre la publicación confiable con OIDC, la procedencia de compilación y flujos de trabajo de lanzamiento con aprobación para npm, PyPI, RubyGems, crates.io, NuGet, Maven Central, Hex, pub.dev y contenedores, además del flujo de publicación por etiqueta para módulos Go y Packagist, tanto en GitHub Actions como en GitLab CI/CD. Úsalo para cualquier solicitud de publicación de un paquete o una imagen de contenedor, asegurar o endurecer un proceso de lanzamiento, configurar publicación confiable o procedencia, generar un SBOM, firmar binarios de lanzamiento, publicar sumas de verificación para los activos de lanzamiento o crear un flujo de trabajo de lanzamiento.
