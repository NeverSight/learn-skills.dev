Crea los archivos de comunidad y gobernanza que necesita un proyecto de código abierto: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY.md, formularios de incidencia y plantillas de pull request, CODEOWNERS, FUNDING y el archivo de licencia, y configura la descripción del proyecto en la forja, los temas y la página principal. Úsalo al iniciar un nuevo proyecto de código abierto, al abrir un repositorio privado al público, cuando un repositorio carece de sus archivos de salud comunitaria, o cuando sus plantillas de incidencia recogen informes que aún no pueden ser triajeados. Cubre GitHub y GitLab. La estructura del README pertenece a oss-readme.
