Создайте файлы сообщества и управления, необходимые открытом проекту: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY.md, формы создания задач и шаблоны запросов на слияние, CODEOWNERS, FUNDING и файл лицензии, а также задайте описание проекта в форджe, темы и домашнюю страницу. Используйте при запуске нового открытого проекта, открытии приватного репозитория для публичного доступа, когда репозиторий не имеет файлов здоровья сообщества, или когда шаблоны задач собирают отчёты, которые всё ещё нельзя обработать. Охватывает GitHub и GitLab. Структура README относится к oss-readme.
