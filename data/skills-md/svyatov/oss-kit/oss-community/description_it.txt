Crea i file di comunità e governance di cui ha bisogno un progetto open source: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY.md, moduli per le issue e modelli per le pull request, CODEOWNERS, FUNDING e il file della licenza, e imposta la descrizione, i topic e la homepage del progetto sulla piattaforma. Usalo quando inizi un nuovo progetto open source, quando apri un repository privato al pubblico, quando un repository è privo dei file di community health, o quando i modelli di issue raccolgono segnalazioni che non possono ancora essere gestite. Copre GitHub e GitLab. La struttura del README appartiene a oss-readme.
