Écrivez ou améliorez un README.md pour un projet open source. Utilisez ceci pour toute demande de création, de réécriture, de révision ou de polissage d’un README, d’une description de projet ou de documents de mise en route pour une bibliothèque, un framework ou un outil, ou pour rendre un projet open source plus attractif pour les utilisateurs. Couvre la structure et l’ordre des sections. Pour les phrases elles‑mêmes, oss‑writing détermine le style. N’UTILISEZ PAS pour la documentation interne ou privée d’un dépôt, la génération de références API, ou les fichiers CHANGELOG et CONTRIBUTING.

Veuillez toujours répondre dans la langue de l’utilisateur.
