Scrivi o migliora un file README.md per un progetto open source. Usa questo per qualsiasi richiesta di creare, riscrivere, revisionare o perfezionare un README, una descrizione del progetto o la documentazione di avvio rapido per una libreria, un framework o uno strumento, o per rendere un progetto open source più attraente per gli utenti. Copre la struttura e l'ordine delle sezioni. Per le frasi stesse, oss‑writing definisce lo stile. NON usare per documenti interni o privati del repository, generazione di riferimenti API, o file CHANGELOG e CONTRIBUTING.

Rispondi sempre nella lingua dell'utente.
