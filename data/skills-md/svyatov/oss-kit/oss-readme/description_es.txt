Escribe o mejora un README.md para un proyecto de código abierto. Usa esto para cualquier solicitud de crear, reescribir, revisar o pulir un README, descripción del proyecto o documentación de inicio rápido para una biblioteca, framework o herramienta, o para hacer que un proyecto de código abierto sea más atractivo para los usuarios. Cubre la estructura y el orden de las secciones. En cuanto a las frases, oss‑writing define el estilo. NO lo uses para documentación interna o de repositorios privados, generación de referencias de API, o archivos CHANGELOG y CONTRIBUTING.

Por favor, siempre responde en el idioma del usuario.
