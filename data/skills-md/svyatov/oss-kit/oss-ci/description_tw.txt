為開源專案在 GitHub Actions 或 GitLab CI/CD 上設定持續整合（CI）。當使用者要求設定 CI、建立工作流程或管線、在 push 和 pull request 時加入自動測試、建置或 lint，或部署文件與其他靜態網站至 GitHub Pages 或 GitLab Pages，或審查既有 CI 設定時使用此說明。即使使用者未明確提及 CI，只要提到自動化測試、在 PR 上執行檢查、或建置矩陣等情況，也適用此說明。說明會涵蓋執行內容。這些工作流程的安全立場屬於 **oss-harden**，而發布相關則屬於 **oss-publish**。

請始終以使用者的語言回覆。
