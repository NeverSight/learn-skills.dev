Configura l'integrazione continua per un progetto open source su GitHub Actions o GitLab CI/CD. Usa questa istruzione quando l'utente chiede di impostare CI, creare workflow o pipeline, aggiungere test automatizzati, build o linting su push e pull request, distribuire una documentazione o altro sito statico su GitHub Pages o GitLab Pages, o rivedere la configurazione CI esistente. Usala anche quando l'utente menziona l'automazione dei test, l'esecuzione di controlli su PR o una matrice di build, anche senza menzionare CI. Copre ciò che viene eseguito. La postura di sicurezza di questi workflow appartiene a oss-harden, e la pubblicazione appartiene a oss-publish.

Per favore rispondi sempre nella lingua dell'utente.
