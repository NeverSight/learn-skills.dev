Configurer l'intégration continue pour un projet open source sur GitHub Actions ou GitLab CI/CD. Utiliser lorsque l'utilisateur demande de mettre en place CI, de créer des workflows ou pipelines, d'ajouter des tests automatisés, de la construction ou du linting sur les push et pull requests, de déployer une documentation ou autre site statique sur GitHub Pages ou GitLab Pages, ou de vérifier la configuration CI existante. Utiliser également lorsque l'utilisateur mentionne l'automatisation des tests, l'exécution de vérifications sur les PR ou une matrice de construction, même sans évoquer CI. Couvre ce qui s'exécute. La posture de sécurité de ces workflows appartient à oss-harden, et la publication appartient à oss-publish.

Veuillez toujours répondre dans la langue de l'utilisateur.
