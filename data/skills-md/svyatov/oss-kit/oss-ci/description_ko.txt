GitHub Actions 또는 GitLab CI/CD에서 오픈 소스 프로젝트의 지속적 통합을 설정합니다. 사용자가 CI 설정, 워크플로우 또는 파이프라인 생성, 푸시 및 풀 리퀘스트 시 자동 테스트, 빌드 또는 린트 추가, 문서 또는 기타 정적 사이트를 GitHub Pages 혹은 GitLab Pages에 배포, 혹은 기존 CI 구성을 검토 요청할 때 사용합니다. 사용자가 테스트 자동화, PR 검사 실행, 빌드 매트릭스 등을 언급할 경우에도 CI라고 명시하지 않아도 적용됩니다. 실행되는 내용에 대해 다룹니다. 해당 워크플로우의 보안 자세는 oss‑harden에 속하고, 배포는 oss‑publish에 속합니다.

항상 사용자의 언어로 응답하십시오.
