GitHub Actions または GitLab CI/CD を使用して、オープンソースプロジェクトの継続的インテグレーションを設定します。ユーザーが CI の設定、ワークフローやパイプラインの作成、プッシュやプルリクエスト時の自動テスト、ビルド、リントの追加、Docs やその他の静的サイトを GitHub Pages や GitLab Pages にデプロイ、既存の CI 設定のレビューを求めたときに使用します。また、ユーザーがテストの自動化、PR のチェック実行、ビルドマトリックスなどを言及した場合（CI と明示しなくても）に適用します。実行内容をカバーします。これらのワークフローのセキュリティ姿勢は oss‑harden が担当し、公開は oss‑publish が担当します。

必ずユーザーの言語で応答してください。
