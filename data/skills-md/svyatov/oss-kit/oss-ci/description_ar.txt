إعداد التكامل المستمر لمشروع مفتوح المصدر على GitHub Actions أو GitLab CI/CD. استخدم ذلك عندما يطلب المستخدم إعداد CI، أو إنشاء سير عمل أو خطوط أنابيب، أو إضافة اختبارات آلية، أو بناء، أو فحص (linting) عند الدفع وطلبات السحب، أو نشر وثائق أو موقع ثابت آخر على GitHub Pages أو GitLab Pages، أو مراجعة إعداد CI الحالي. استخدم أيضًا عندما يذكر المستخدم أتمتة الاختبارات، أو تشغيل الفحوصات على طلبات السحب، أو مصفوفة بناء، حتى لو لم يذكر كلمة CI. يغطي ما يتم تشغيله. موقف الأمان لتلك سير العمل ينتمي إلى oss-harden، والنشر ينتمي إلى oss-publish.

يرجى دائمًا الرد بلغة المستخدم.
