Construye un activo 3D listo para juegos en Blender a partir de imágenes de referencia (arte conceptual, fotos, vistas giratorias, bocetos, capturas de pantalla) para cualquier categoría, incluidos personajes, criaturas, arquitectura, vehículos, objetos, armas y piezas de entorno, mediante fases controladas con evidencia renderizada comparada con la referencia. Usa esto siempre que un usuario proporcione o mencione una imagen de referencia y desee un modelo 3D o activo de juego creado a partir de ella (modelado, bloqueado, esculpido, retopologizado, texturizado, riggeado, animado o exportado para un motor de juego), incluso cuando Blender no se mencione. Incluye scripts bpy para calibración de escena, renders de revisión alineados con la cámara de referencia, medición de siluetas, validación, horneado, exportación GLB/FBX con manifiestos y reimportación limpia.
