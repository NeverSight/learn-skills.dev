À utiliser lorsque DaVinci Resolve présente un dysfonctionnement spécifique : indicateur de lecture rouge, médias manquants, clips hors ligne, audio désynchronisé, plantages du GPU/du rendu ou file d'attente de rendu bloquée. Les symptômes déclencheurs incluent des expressions telles que « Resolve perd des images », « média hors ligne », « les clips affichent une diagonale rouge », « l'audio dérive », « Resolve plante lors du rendu », « erreur GPU », ou toute question de type « pourquoi X ne fonctionne pas » concernant DaVinci Resolve.
