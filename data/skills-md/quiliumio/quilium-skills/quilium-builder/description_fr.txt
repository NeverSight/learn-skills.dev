Charge lors de la construction ou de la restructuration d’un site Quilium CMS — architecture (types de pages, types de contenu, ItemSets, champs globaux), schémas YAML, routes et pages de détail, modèles Liquid, portage d’un prototype HTML, images, la page 404, la boucle CLI (init, run, push, dictionary) et contenu depuis le shell (importations en masse, champs longs édités comme des fichiers). Déclencheurs sur « nouveau site Quilium », « construire ce site », « concevoir l’architecture », « créer un type de contenu », « ajouter un type de page », « générer un modèle », « porter ce prototype », « page de détail », « les liens pointent vers la mauvaise page », « les images manquent », « la 404 ne fonctionne pas », « configurer le projet », « quilium init », « quilium push », « quilium content », « quilium item », « importer cela dans le CMS », « le site ne rend pas », « wysiwyg ou repeat », « styles wysiwyg personnalisés », « palette de styles de l’éditeur ». Chargez quilium‑webmaster EN PLUS DE cette compétence — chaque construction se termine par une phase de contenu (étape 5). Pour le travail de contenu sur un site déjà en fonctionnement, quilium‑webmaster seul suffit.
