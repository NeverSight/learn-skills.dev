Gérez et dépannez les ressources de téléphonie Volcano Cloud à l’aide d’une interface en ligne de commande Python locale et d’un client OpenAPI. Cet outil convient pour interroger les instances et les ressources, prendre des captures d’écran, exécuter des commandes, afficher les tâches, vérifier les applications, la capacité des hôtes et des centres de données, les balises, le DNS, le routage, et gérer les instances de test de téléphonie cloud autorisées.
