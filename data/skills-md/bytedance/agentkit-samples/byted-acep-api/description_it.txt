Gestisci e risolvi i problemi delle risorse mobili di Volcano Cloud tramite la CLI Python locale e il client OpenAPI. Supporta l'interrogazione di istanze e risorse, la cattura di screenshot, l'esecuzione di comandi, la visualizzazione delle attività, il controllo delle applicazioni, della capacità dell'host e del data center, dei tag, del DNS, del routing e l'operatività di istanze di test cloud mobili autorizzate.
