Управляйте и устраняйте неисправности мобильных ресурсов Volcano Cloud с помощью локального CLI на Python и клиента OpenAPI. Он поддерживает запросы к экземплярам и ресурсам, захват скриншотов, выполнение команд, просмотр задач, инспекцию приложений, ёмкость хостов и дата‑центров, теги, DNS, маршрутизацию и эксплуатацию уполномоченных тестовых облачных мобильных экземпляров.
