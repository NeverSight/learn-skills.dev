Administra y soluciona problemas de los recursos móviles de Volcano Cloud mediante la CLI local de Python y el cliente OpenAPI. Permite consultar instancias y recursos, tomar capturas de pantalla, ejecutar comandos, ver tareas, inspeccionar aplicaciones, capacidad de hosts y centros de datos, etiquetas, DNS, enrutamiento y operar instancias móviles de prueba en la nube autorizadas.
