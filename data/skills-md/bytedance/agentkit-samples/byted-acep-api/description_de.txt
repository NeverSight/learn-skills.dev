Verwalten und Fehlersuchen bei Volcano‑Cloud‑Telefonressourcen mit einer lokalen Python‑CLI und einem OpenAPI‑Client. Es unterstützt das Abfragen von Instanzen und Ressourcen, das Aufnehmen von Screenshots, das Ausführen von Befehlen, das Anzeigen von Aufgaben, das Inspizieren von Anwendungen, die Host‑ und Rechenzentrums‑Kapazität, Tags, DNS, Routing und das Betreiben autorisierter Test‑Cloud‑Telefoninstanzen.
