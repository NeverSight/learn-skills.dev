Servicio de Funciones Volcano Engine: Cuando un usuario desea desplegar un front‑end local, Node.js, Python, sitio estático o servicio API en línea, puede crear una aplicación sin servidor a partir de plantillas, integrar un proyecto existente en veFaaS, ver la dirección de acceso en línea, configurar variables de entorno de producción, comandos de compilación, comandos de inicio o puertos, publicar, revertir, invocar y depurar funciones en línea, ver registros, el estado de la instancia o configuraciones de recursos, extraer/subir el código de la función en la nube, crear y gestionar instancias sandbox y solucionar problemas como fallos de despliegue, fallos de autenticación, errores de detección de framework o pasarelas faltantes. Llamar directamente a la OpenAPI de veFaaS es necesario para operaciones avanzadas, así como para la incorporación inicial a veFaaS, aprender sobre conceptos/capacidades/selección/precios de veFaaS, consultar la documentación oficial desde la terminal o usar el SDK o la OpenAPI de veFaaS para el desarrollo de código.
