Volcengine Function Service: Quando gli utenti desiderano distribuire front‑end locali, Node.js, Python, siti statici o servizi API online, possono creare un’applicazione serverless da un modello, integrare un progetto esistente con veFaaS, visualizzare l’URL di accesso online, configurare le variabili d’ambiente di produzione, i comandi di build, i comandi di avvio o le porte, ed eseguire la pubblicazione, il rollback, l’invocazione e il debug delle funzioni online. Gli utenti possono anche visualizzare i log, lo stato delle istanze o le configurazioni delle risorse; scaricare/caricare il codice delle funzioni cloud; creare e gestire istanze sandbox; e risolvere problemi come errori di distribuzione, errori di autenticazione, errori di rilevamento del framework o gateway mancanti. Per operazioni avanzate sono necessarie chiamate dirette all’OpenAPI di veFaaS, oppure per l’onboarding iniziale—comprendere i concetti di veFaaS, le capacità, i criteri di selezione, la fatturazione, consultare la documentazione ufficiale nel terminale e integrare l’S DK o l’OpenAPI di veFaaS per lo sviluppo del codice.
