Service de fonctions Volcengine : lorsque les utilisateurs souhaitent déployer des front‑ends locaux, Node.js, Python, des sites statiques ou des services API en ligne, ils peuvent créer des applications serverless à partir de modèles, intégrer des projets existants dans veFaaS, voir l’adresse d’accès en ligne, configurer les variables d’environnement de production, les commandes de construction, les commandes de démarrage ou les ports, publier, revenir en arrière, invoquer et déboguer les fonctions en ligne, consulter les journaux, l’état des instances ou les configurations de ressources, récupérer/pousser le code des fonctions cloud, créer et gérer des instances sandbox, et résoudre les échecs de déploiement, les échecs d’authentification, les erreurs de détection de framework, les passerelles manquantes et d’autres problèmes. Les opérations avancées nécessitent d’appeler directement l’OpenAPI de veFaaS, tandis que les débutants peuvent commencer avec veFaaS, découvrir ses concepts, ses capacités, ses critères de sélection et sa tarification, consulter la documentation officielle depuis le terminal, ou intégrer le SDK veFaaS ou l’OpenAPI pour le développement de code.
