火山引擎函數服務：當使用者想要部署本地前端、Node.js、Python、靜態網站或 API 服務至線上時，他們可以從範本建立無伺服器應用程式，將現有專案整合至 veFaaS，查看線上存取位址，設定生產環境變數，建置指令、啟動指令或埠號，發布、回滾、調用與除錯線上函式，檢視日誌、實例狀態或資源配置，拉取/推送雲函式程式碼，建立與管理沙盒實例，排除部署失敗、驗證失敗、框架偵測錯誤、缺少閘道等問題。進階操作需要直接呼叫 veFaaS OpenAPI，或在初次使用 veFaaS 時，了解 veFaaS 的概念、功能、選型、計費，在終端機中查閱官方文件，或整合 veFaaS SDK 或 OpenAPI 進行程式開發。
