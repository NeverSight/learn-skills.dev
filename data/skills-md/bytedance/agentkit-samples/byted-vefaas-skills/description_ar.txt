خدمة وظائف محرك فولكانو: عندما يرغب المستخدمون في نشر الواجهات الأمامية المحلية أو Node.js أو Python أو المواقع الثابتة أو خدمات API عبر الإنترنت، يمكنهم إنشاء تطبيقات بدون خادم من القوالب، دمج المشاريع القائمة في veFaaS، عرض عنوان URL للوصول عبر الإنترنت، تكوين متغيرات بيئة الإنتاج، أوامر البناء، أوامر التشغيل أو المنافذ، النشر، الاسترجاع، الاستدعاء، وتصحيح وظائف الإنترنت، عرض السجلات، حالة المثيل، أو تكوينات الموارد، سحب/دفع كود الوظيفة السحابية، إنشاء وإدارة مثيلات الصندوق الرمل، وحل المشكلات مثل فشل النشر، فشل المصادقة، أخطاء اكتشاف الإطار، أو نقص البوابات. للعمليات المتقدمة، يحتاج المستخدمون إلى استدعاء OpenAPI الخاص بـ veFaaS مباشرةً، أو عند الانضمام الأول—التعرف على مفاهيم veFaaS، القدرات، الاختيار، الفوترة، استشارة الوثائق الرسمية من الطرفية، وتكامل SDK أو OpenAPI الخاص بـ veFaaS لتطوير الكود.
