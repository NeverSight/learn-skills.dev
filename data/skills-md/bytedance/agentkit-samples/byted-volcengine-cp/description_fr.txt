Dans les environnements de production Volcano Engine ou BytePlus Continuous Delivery (CP), gérez le cycle complet CI/CD, y compris les espaces de travail, les pipelines CI et les journaux d’exécution, les déclencheurs, les étapes personnalisées, les connexions de services, les ressources de déploiement et les applications hébergées en CD. Prend en charge les régions de production cn-beijing et ap-southeast-1. Utilisez-le lorsqu’un utilisateur demande explicitement d’opérer les pipelines CI/CD CP en ligne, en production ou prod, les constructions, les déploiements, les espaces de travail, les Webhooks, les déclencheurs, les étapes personnalisées, les connexions de services, les ressources de déploiement, les applications hébergées, l’état d’exécution ou les journaux. Seuls les environnements de production sont pris en charge ; il ne doit pas être utilisé pour les environnements pré, pré‑release ou de test.
