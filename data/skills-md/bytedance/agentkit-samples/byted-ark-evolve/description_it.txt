Sistema di auto‑evoluzione dell'agente. Raccoglie segnali dal feedback dell'utente, memorizza le traiettorie di esecuzione (coppie golden + correzione), analizza i pattern, propone mutazioni ai file dello spazio di lavoro e genera report HTML. Attivalo con "/evolve" o quando l'utente chiede di migliorare il comportamento dell'agente. Usalo anche quando l'utente dice "ricorda questo pattern", "non fare più X" o "quell'approccio è stato buono, salvalo". Rispondi sempre nella lingua dell'utente.
