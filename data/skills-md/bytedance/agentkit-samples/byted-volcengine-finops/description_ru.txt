Возможность анализа биллинга Cost Center в Volcano Engine, которая, исходя из пользовательских сценариев, использует Python SDK для запросов деталей биллинга, детализации затрат, сводок по аккаунтам, сводок по продуктам и раздельного биллинга, поддерживая многомерный анализ биллинга по периоду выставления счета, месяцу распределения, дате, продукту, аккаунту, инстансу и элементам разделения.
