ByteHouse data quality inspection tool. When users provide cluster connection information, database name, and table name, this capability is used to check for null values and zero values in the columns used for sorting keys, primary keys, and partition keys, to determine whether there are abnormal distributions, and to detect duplicate sorting keys and primary keys. It is suitable for requirements such as "data quality inspection," "sorting key / primary key / partition key analysis," "null value analysis," "zero value analysis," "duplicate key check," and "top distribution."
