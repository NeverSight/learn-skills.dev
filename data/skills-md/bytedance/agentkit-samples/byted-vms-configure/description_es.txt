Skill “Configuración General” de Volcano Cloud Communication (capa general). Es responsable únicamente de consultas de llamabilidad entre negocios, control de riesgo y autenticación del llamante, como QueryRiskDenyInfo, QueryCanCall y QueryAuth. Tenga en cuenta que todas las operaciones de plantillas TTS (crear / actualizar / eliminar / consultar), así como la gestión de archivos de voz y recursos generales (create_voice, query_voice, delete_voice, get_upload_url, submit_upload, list_resource, list_usable, update_resource, delete_resource), se han migrado a la skill byted‑vms‑voice‑notify (notificación de voz), y esta skill ya no ofrece puntos de entrada para TTS ni para voz/recursos.
