Volcengine Cloud Communication “General Configuration” Skill (general layer). It is only responsible for cross‑service number reachability, risk control, and caller‑authentication queries such as QueryRiskDenyInfo, QueryCanCall, and QueryAuth. Note that all TTS template operations (create/update/delete/query) as well as voice file and generic resource management (create_voice, query_voice, delete_voice, get_upload_url, submit_upload, list_resource, list_usable, update_resource, delete_resource) have been migrated to the byted‑vms‑voice‑notify (voice notification) skill; this skill no longer provides any TTS or voice/resource entry points.
