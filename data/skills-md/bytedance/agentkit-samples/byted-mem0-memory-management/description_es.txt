Administra los elementos de memoria y la memoria a largo plazo del repositorio de memoria Volcano Engine Mem0. Se utiliza cuando un usuario necesita consultar elementos de Mem0, recuperar estrategias, direcciones de conexión o información de la clave API existente, así como añadir, listar, leer, buscar, actualizar, eliminar memorias y consultar tareas asincrónicas. El plano de control solo admite operaciones de lectura; no está destinado a la configuración de implementación autogestionada de código abierto de mem0, a la operación y mantenimiento interno de MemoryBase, ni a consultas de registros.
