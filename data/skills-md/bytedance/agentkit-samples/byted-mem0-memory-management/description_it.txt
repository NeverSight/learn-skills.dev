Gestisci gli elementi di memoria e la memoria a lungo termine nel repository di memoria Mem0 di Volcano Engine. Viene utilizzato quando gli utenti devono interrogare gli elementi Mem0, recuperare le politiche, gli indirizzi di connessione o le informazioni sulle chiavi API esistenti, nonché aggiungere, elencare, leggere, cercare, aggiornare, eliminare memorie e interrogare le attività asincrone. Il piano di controllo supporta solo operazioni di lettura; non è destinato alla configurazione di distribuzione di Mem0 open‑source auto‑costruito, alle operazioni interne di MemoryBase o alle query dei log.
