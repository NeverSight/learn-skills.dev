Volcano Engine Cloud Database VeDB MySQL Edition (abgekürzt als vedbm) Management‑Fähigkeit. Wenn ein Benutzer VEDB‑Instanzen erstellen, die VEDB‑Instanzliste abfragen, Instanzdetails anzeigen, Datenbankkonten verwalten, Verbindungsadressen (Endpoints) der Instanz abrufen oder die Instanzspezifikationen auf‑ bzw. herabstufen muss, wird diese Fähigkeit verwendet. Enthält spezifische Schlüsselwörter: Volcano Engine Cloud Database, VEDBM, VeDB MySQL.
