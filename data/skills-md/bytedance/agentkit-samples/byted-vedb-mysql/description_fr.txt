Compétence de gestion Volcano Engine Cloud Database VeDB édition MySQL (désignée sous le nom de vedbm). Cette compétence est utilisée lorsque les utilisateurs ont besoin de créer des instances VEDB, d’interroger la liste des instances VEDB, de consulter les détails d’une instance, de gérer les comptes de base de données, d’obtenir les adresses de connexion des instances (Endpoints), ou de mettre à niveau / rétrograder les spécifications d’une instance. Inclut les mots‑clés spécifiques : Volcano Engine Cloud Database, VEDBM, VeDB MySQL.
