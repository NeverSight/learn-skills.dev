Навык управления Volcano Engine Cloud Database VeDB MySQL (именуемый VEDBM). Когда пользователям необходимо создать экземпляр VEDB, запросить список экземпляров VEDB, просмотреть детали экземпляра, управлять учетными записями базы данных, получить адреса подключения к экземпляру (Endpoints) или выполнить повышение/понижение спецификаций экземпляра, они используют этот навык. Включает специальные ключевые слова: Volcano Engine Cloud Database, VEDBM, VeDB MySQL.
