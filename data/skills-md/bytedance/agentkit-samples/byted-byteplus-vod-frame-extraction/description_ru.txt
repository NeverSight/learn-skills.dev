Загрузка видео/аудио медиа в хранилище BytePlus VOD (Video on Demand) с возвратом Vid и ссылок для воспроизведения; поддерживает загрузку локального файла (ApplyUploadInfo + TOS + CommitUploadInfo) и загрузку по URL (UploadMediaByUrl); также отправляет задания по извлечению кадров из загруженных медиа (StartExecution / Operation.Task.Snapshot), включая указание времени, фиксированный интервал, указанный кадр, смену сцены, спрайт‑изображение и режимы вывода индекса. Ключевые слова‑триггеры: VOD frame extraction, frame extraction, extract frames, video snapshot, thumbnail, screenshot from video, StartExecution Snapshot.
