Used for agent evaluation-related needs, including assessing an agent’s capabilities and performance, designing evaluation plans, comparing different agents or the same agent’s model, skill, and tool configurations, as well as preparing evaluation data, configuring execution strategies, running evaluations, querying and analyzing results, diagnosing failures, canceling, rerunning and rescoring, analyzing historical rescoring and scorer stability, importing external evidence, scoring existing outputs or trajectories, and handling issues and experience feedback during evaluation use. Use when users mention needs such as “evaluate agent,” “test agent performance,” or “compare agent performance,” without needing to specify platform or tool names. Specific operations are performed via the agent-eval CLI interfacing with the Agent Eval Lab service.
