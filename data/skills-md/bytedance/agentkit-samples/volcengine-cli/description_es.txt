Crea y gestiona recursos en la nube de Volcengine utilizando el CLI de Volcengine (`ve` command). Soporta todos los servicios de Volcengine, incluidos ECS, VPC, CLB, RDS, Redis y más. Activa esta habilidad cada vez que el usuario solicite crear, consultar, modificar o eliminar recursos en la nube de Volcengine, mencione el comando `ve`, diga “volcengine CLI”, o describa tareas de infraestructura como “crear una instancia ECS”, “configurar una VPC”, “listar grupos de seguridad”, “asignar una EIP”. También se activa cuando el usuario se encuentre con errores de los comandos `ve` y necesite ayuda para solucionarlos.

Por favor, responde siempre en el idioma del usuario.
