Comprime y descomprime objetos de archivo almacenados en Volcengine TOS mediante trabajos asíncronos de procesamiento de datos de TOS. Usa esta habilidad cuando el usuario necesite crear archivos zip, descomprimir archivos, crear archivos tar o zstd, extraer archivos comprimidos, empaquetar varios objetos TOS en un solo archivo, agrupar archivos o distribuirlos como un paquete, aunque no mencione explícitamente “compresión”, “archivo”, “打包” o “压缩”. Por favor, responde siempre en el idioma del usuario.
