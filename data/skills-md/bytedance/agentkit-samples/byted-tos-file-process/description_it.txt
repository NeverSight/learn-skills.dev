Comprimi e decomprimi oggetti file memorizzati in Volcengine TOS tramite lavori asincroni di elaborazione dati TOS. Usa questa funzionalità quando l'utente ha bisogno di comprimere file, estrarre archivi, creare archivi tar o zstd, estrarre file compressi, raggruppare più oggetti TOS in un unico archivio, aggregare file insieme o distribuire file come pacchetto — anche se non menzionano esplicitamente “compressione”, “archivio”, “打包” o “压缩”.

Rispondi sempre nella lingua dell'utente.
