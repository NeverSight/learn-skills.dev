Perform change risk analysis for scenarios such as code changes, configuration changes, scaling up or down, network policy adjustments, and entry switching. Whenever a user asks questions like “How big is the risk of this change?”, “What will this change affect?”, or “Which upstream or downstream services/resources will be impacted?”, this skill should be used; even if the user only provides a natural‑language description of the change, you should proactively try to infer the scope of impact by combining it with topology.json, and output the risk conclusions along with a textual description of the upstream and downstream impact.
