An automated tool for large model training tasks based on ark_sdk. It helps users create and submit Ark model training tasks using natural language, supports SFT training with user-provided data, RFT + GRPO and direct GRPO strategies, and guides users through training, status tracking, and evaluation loops. Use case: triggered when users need to perform large‑model SFT supervised fine‑tuning, RLHF training, GRPO training, RFT training, or require an automated training workflow.
