Compétence d'orientation d'utilisation du modèle Volcano Ark Seedance. Lorsque les utilisateurs s'interrogent sur l'intégration des modèles de la série Seedance tels que Seedance/seedance2.0/doubao-seedance-2-0/doubao-seedance-2-0-fast/seedance2.0-mini avec Volcano Ark — y compris les appels d'API, les paramètres, la création de tâches, la requête de tâches, la récupération de résultats, l'activation de la facturation, le dépannage d'erreurs, le SDK et les meilleures pratiques — cette compétence doit être invoquée en premier ; lorsqu'un utilisateur fournit un lien de documentation officielle Volcengine (sous la forme https://www.volcengine.com/docs/*) et demande une interprétation, un résumé, une extraction, des requêtes de règles ou des réponses basées sur le document, cette compétence doit également être invoquée et récupérer le document complet via fetch ; les questions ordinaires doivent utiliser ServiceCodes : ark pour récupérer la documentation officielle de Volcano Ark.

Veuillez toujours répondre dans la langue de l'utilisateur.
