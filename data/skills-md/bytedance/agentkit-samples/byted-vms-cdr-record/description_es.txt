Habilidad de consulta de registro de llamadas / grabaciones de Volcano Cloud Communication. Se invoca cuando el usuario solicita “Consultar el registro de llamada para callId xxx” o “Descargar la grabación para xxx”. Tenga en cuenta que la API TOP solo admite consultas exactas por CallId y no admite búsquedas inversas por SingleOpenId, número de teléfono o intervalo de tiempo. Por favor, responda siempre en el idioma del usuario.
