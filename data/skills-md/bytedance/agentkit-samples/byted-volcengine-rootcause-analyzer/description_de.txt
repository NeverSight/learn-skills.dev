Wenn eine Monitoring‑Plattform, Log‑Plattform, ein On‑Call‑Gespräch oder eine nach‑Änderungs‑Anomalie eine bestimmte Ressource, einen Domainnamen, eine IP‑Adresse oder ein geschäftliches Phänomen aufdeckt, wird eine Upstream‑Downstream‑Topologie automatisch um das Alarmziel erweitert. Korrelierte Anomalien innerhalb derselben Topologie werden untersucht, und Ursprungsalarme, abgeleitete Alarme sowie Rauschalarme werden zusammengeführt, wodurch Kandidaten für die Grundursache, der Umfang der Auswirkungen und eine strukturierte Diagnoseszusammenfassung entstehen.
