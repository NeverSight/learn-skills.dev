Habilidad de capa de capacidad general de Volcano Cloud Communication. Pool de números / número / calificación, tres tipos de gestión de recursos. Se invoca cuando el usuario pregunta qué pools de números existen, desea crear un nuevo pool de números, consulta/habilita o deshabilita números, o envía o consulta calificaciones. La habilidad de la capa de negocio también reutiliza esta habilidad durante la fase de pre‑verificación. Por favor, siempre responda en el idioma del usuario.
