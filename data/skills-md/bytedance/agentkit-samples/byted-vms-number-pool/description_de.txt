Volcano Cloud Communication allgemeine Fähigkeitsschicht. Verwaltung von drei Ressourcentypen: Nummernpool / Nummern / Qualifikationen. Sie wird aufgerufen, wenn der Benutzer fragt, welche Nummernpools verfügbar sind, einen neuen Nummernpool erstellen möchte, Nummern abfragen/aktivieren/deaktivieren oder Qualifikationen einreichen bzw. abfragen will.
