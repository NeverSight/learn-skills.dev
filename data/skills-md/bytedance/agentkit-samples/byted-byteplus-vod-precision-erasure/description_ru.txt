Загружайте видео‑ и аудиофайлы в хранилище BytePlus VOD (Video on Demand), получая Vid и ссылки для воспроизведения; поддерживаются загрузка локального файла (ApplyUploadInfo + TOS + CommitUploadInfo) и загрузка по URL (UploadMediaByUrl); также отправляются задачи точного стирания обработанных медиа (StartExecution / Operation.Task.Erase): только автоматический OCR — по умолчанию стираются лишь субтитры, опционально полное удаление текста на экране, опционально EraseOption ClipFilter (пропустить/выбрать); NewVid всегда равно true; опционально WithEraseInfo. Ключевые слова‑триггеры: точное стирание, precise erase, загрузка VOD, удаление субтитров, OCR‑субтитры, удаление текста на экране, стирание текста, StartExecution Erase.
