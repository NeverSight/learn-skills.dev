Volcengine Cloud Detect (云拨测) API 통합은 감지 작업 생성, 결과 조회, 보고서 생성 및 감지 노드 관리를 위해 제공됩니다. 사용자는 다음과 같은 경우에 사용합니다: (1) 네트워크 감지/다이얼 작업(拨测任务) 생성, (2) 작업 결과 확인 또는 감지 보고서 생성, (3) 감지 노드(拨测节点) 목록 조회 또는 검색, (4) 기존 작업 관리(목록/중지/재시작/삭제). 트리거는 웹사이트 모니터링, 네트워크 지연 시간 테스트, HTTP 감지, ping 테스트, DNS 테스트, 노드 조회 또는 Volcengine Cloud Detect 서비스의 보고서 생성을 위한 자연어 요청을 포함합니다.

항상 사용자의 언어로 응답하십시오.
