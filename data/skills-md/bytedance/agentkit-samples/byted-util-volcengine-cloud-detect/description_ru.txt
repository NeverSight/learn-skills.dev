Интеграция API Volcengine Cloud Detect (云拨测) для создания задач обнаружения, получения результатов, генерации отчётов и управления узлами обнаружения. Используйте, когда пользователь хочет (1) создать задачи сетевого обнаружения/набора (拨测任务), (2) проверить результаты задач или сгенерировать отчёты об обнаружении, (3) перечислить или искать узлы обнаружения (拨测节点), (4) управлять существующими задачами (список/остановить/перезапустить/удалить). Триггеры включают запросы на естественном языке о мониторинге веб‑сайтов, тестировании сетевой задержки, HTTP‑проверке, ping‑тестах, DNS‑тестах, запросах узлов или генерации отчётов для службы Volcengine Cloud Detect.
