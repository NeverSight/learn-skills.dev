Integrazione API di Volcengine Cloud Detect (云拨测) per la creazione di task di rilevamento, il recupero dei risultati, la generazione di report e la gestione dei nodi di rilevamento. Da utilizzare quando l'utente desidera (1) creare task di rilevamento di rete/dialing (拨测任务), (2) controllare i risultati dei task o generare report di rilevamento, (3) elencare o cercare i nodi di rilevamento (拨测节点), (4) gestire i task esistenti (elencare/fermare/riprendere/eliminare). I trigger includono richieste in linguaggio naturale relative al monitoraggio di siti web, test di latenza di rete, rilevamento HTTP, test ping, test DNS, interrogazioni sui nodi o generazione di report per il servizio Volcengine Cloud Detect. Rispondi sempre nella lingua dell'utente.
