Intégration de l'API Volcengine Cloud Detect (云拨测) pour créer des tâches de détection, récupérer les résultats, générer des rapports et gérer les nœuds de détection. À utiliser lorsque l'utilisateur souhaite (1) créer des tâches de détection/réglage réseau (拨测任务), (2) vérifier les résultats des tâches ou générer des rapports de détection, (3) lister ou rechercher des nœuds de détection (拨测节点), (4) gérer les tâches existantes (lister/arrêter/redémarrer/supprimer). Les déclencheurs comprennent des requêtes en langage naturel concernant la surveillance de sites Web, les tests de latence réseau, la détection HTTP, les tests ping, les tests DNS, les requêtes de nœuds ou la génération de rapports pour le service Volcengine Cloud Detect. Veuillez toujours répondre dans la langue de l'utilisateur.
