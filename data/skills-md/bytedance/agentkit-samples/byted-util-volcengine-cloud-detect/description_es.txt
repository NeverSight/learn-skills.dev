Integración API de Volcengine Cloud Detect (云拨测) para crear tareas de detección, recuperar resultados, generar informes y gestionar nodos de detección. Úselo cuando el usuario desea (1) crear tareas de detección/red de marcación (拨测任务), (2) consultar resultados de tareas o generar informes de detección, (3) listar o buscar nodos de detección (拨测节点), (4) gestionar tareas existentes (listar/detener/reiniciar/eliminar). Los desencadenantes incluyen solicitudes en lenguaje natural sobre monitoreo de sitios web, pruebas de latencia de red, detección HTTP, pruebas de ping, pruebas DNS, consultas de nodos o generación de informes para el servicio Volcengine cloud detect.
