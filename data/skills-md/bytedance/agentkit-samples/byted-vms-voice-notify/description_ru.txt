Навык голосовых уведомлений Volcano Cloud Communication. Вызывается, когда пользователь упоминает «голосовое уведомление / голосовая трансляция / автоматическое исходящее уведомление звонком / голосовое напоминание» и предоставляет номер вызываемого и содержание трансляции. Поддерживает однократную отправку (SingleBatchAppend) и пакетные задачи (CreateTask). Это также единственная точка входа для всех операций с шаблонами TTS (создание / обновление / удаление / запрос), а также управления записными файлами / общими ресурсами (создание / запрос / удаление / прямая загрузка / список / доступные ресурсы / переименование / удаление).
