Volcano Cloud Communication Voice Notification Skill. Invoked when the user mentions “voice notification / voice broadcast / automatic outbound call notification / voice reminder” and provides the callee number and broadcast content. Supports single sends (SingleBatchAppend) and batch tasks (CreateTask). It also serves as the sole entry point for all TTS template operations (create / update / delete / query) and for recording file / general resource management (create / query / delete / direct upload / list / available resources / rename / delete).
