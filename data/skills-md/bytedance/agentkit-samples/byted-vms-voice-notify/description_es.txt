Habilidad de Notificación de Voz de Volcano Cloud Communication. Se invoca cuando el usuario menciona “notificación de voz / emisión de voz / notificación automática de llamada saliente / recordatorio de voz” y proporciona el número llamado y el contenido de la emisión. Soporta envío único (SingleBatchAppend) y tareas por lotes (CreateTask). También es el único punto de entrada para todas las operaciones de plantillas TTS (crear / actualizar / eliminar / consultar) así como la gestión de archivos de grabación / recursos genéricos (crear / consultar / eliminar / carga directa / listar / recursos disponibles / renombrar / eliminar).
