Volcano Cloud Communication Voice Notification Skill. Viene attivata quando l'utente menziona “notifica vocale / trasmissione vocale / notifica di chiamata in uscita automatica / promemoria vocale” e fornisce il numero chiamato e il contenuto della trasmissione. Supporta l'invio singolo (SingleBatchAppend) e i compiti batch (CreateTask). È anche l'unico punto d'ingresso per tutte le operazioni sui modelli TTS (crea / aggiorna / elimina / consulta) nonché per la gestione di file di registrazione / risorse generiche (crea / consulta / elimina / upload diretto / elenca / risorse disponibili / rinomina / elimina).
