ميزة الإشعارات الصوتية في سحابة فولكانو للاتصالات. يتم استدعاؤها عندما يذكر المستخدم “إشعار صوتي / بث صوتي / إشعار صادري تلقائي / تذكير صوتي” ويزود برقم المتصل ومحتوى البث. تدعم الإرسال الفردي (SingleBatchAppend) والمهام الجماعية (CreateTask). كما أنها النقطة الوحيدة للدخول لجميع عمليات قوالب تحويل النص إلى كلام (إنشاء / تحديث / حذف / استعلام) وإدارة ملفات الصوت/الموارد العامة (إنشاء / استعلام / حذف / رفع مباشر / قائمة / الموارد المتاحة / إعادة تسمية / حذف).
