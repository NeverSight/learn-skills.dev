Volcengine Cloud Communication Sprachbenachrichtigungs‑Skill. Wird aufgerufen, wenn der Benutzer „Sprachbenachrichtigung / Sprachübertragung / automatische ausgehende Anrufbenachrichtigung / Sprach‑Erinnerung“ erwähnt und die angerufene Nummer sowie den Wiedergabebereich angibt. Unterstützt das Senden einzelner Nachrichten (SingleBatchAppend) und Batch‑Aufgaben (CreateTask). Es ist zudem der zentrale Einstiegspunkt für alle TTS‑Vorlagenoperationen (erstellen / aktualisieren / löschen / abfragen) sowie für das Management von Audiodateien / allgemeinen Ressourcen (erstellen / abfragen / löschen / Direkt‑Upload / Auflisten / verfügbare Ressourcen / umbenennen / löschen).
