كتابة ملفات تكوين j-menu والحفاظ عليها (.j-menu.yaml / .toml / .json) - يتم الوصول إلى قائمة TUI لكل مشروع عن طريق كتابة `j`. يُستخدم عند إضافة أو تحرير أو تصحيح إدخالات القائمة، أو القوائم الفرعية، أو الوسائط المطلوبة، أو تشغيل الأوامر بالتوازي، أو سلوك الدمج أو المشغلات التلقائية، أو عندما يذكر المستخدم قائمة j، أو `.j-menu.yaml`، أو يطلب وضع أمر "في قائمة j".
