Scrivi e gestisci i file di configurazione del menu j (.j-menu.yaml / .toml / .json): il menu TUI per progetto raggiungibile digitando "j". Da utilizzare quando si aggiungono, si modificano o si esegue il debug di voci di menu, sottomenu, argomenti guidati, comandi eseguiti in parallelo, comportamento di unione o lanciatori automatici o quando l'utente menziona j-menu, `.j-menu.yaml` o chiede di inserire un comando "nel menu j".
