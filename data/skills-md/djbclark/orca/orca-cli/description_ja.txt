Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」「share skills」と言ったときに使用してください。Orca の状態が関与している場合は、生の git worktree や ad‑hoc PTY、Computer Use よりもこちらを優先します。CLI、ファイルシステム、API では対応できない可視ウィンドウの GUI 制御が必要なときだけ Computer Use を利用してください。
