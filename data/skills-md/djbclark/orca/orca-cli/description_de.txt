Betriebe von Orca verwaltete Worktrees, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Wissensaustausch, Worktree‑Kommentare und den in Orca eingebetteten Browser über die `orca`‑CLI. Verwende sie, wenn der Nutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzuge sie gegenüber rohen git‑Worktrees, ad‑hoc‑PTYs oder Computer‑Use, wenn ein Orca‑Zustand beteiligt ist. Setze Computer‑Use nur ein, wenn ein sichtbares Fenster GUI‑Steuerung erfordert, die eine CLI, das Dateisystem oder eine API nicht leisten können.
