تشغيل الأشجار العاملة المُدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الأثرية، ومشاركة المهارات، وتعليقات الأشجار العاملة، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على شجرة git الخام، أو PTYs المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متورطة. استخدم استخدام الكمبيوتر فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية التي لا يستطيع سطر الأوامر أو نظام الملفات أو API تنفيذها.
