Gérez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via la ligne de commande `orca`. Utilisez‑le lorsque l’utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Préférez‑le au worktree Git brut, aux PTY ad hoc ou à l’Utilisation d’Ordinateur lorsque l’état d’Orca est en jeu. N’utilisez l’Utilisation d’Ordinateur que lorsqu’une fenêtre visible nécessite un contrôle GUI qu’une CLI, le système de fichiers ou une API ne peuvent assurer.
