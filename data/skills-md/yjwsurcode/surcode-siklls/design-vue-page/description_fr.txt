Générez des composants de fichier unique (SFC) Vue 3 prêts pour la production à partir de descriptions, de maquettes de conception, d'images ou d'URL. Utilisez cette compétence chaque fois que l'utilisateur souhaite : créer une page ou un composant Vue 3, convertir une conception/maquette/capture d'écran en code Vue, générer une interface utilisateur à partir d'une description, créer une page Vue avec des données dynamiques ou échafauder un composant Vue avec une réactivité appropriée. Déclenchez même si l'utilisateur dit des choses comme "créez-moi une page Vue", "convertissez cette conception en Vue", "construisez cette interface utilisateur dans Vue", "écrivez un composant Vue pour...", "J'ai un Figma/design/capture d'écran, transformez-le en Vue", ou toute variante de génération Vue/UI. Utilisez toujours cette compétence pour les tâches de génération de code Vue 3 – ne vous fiez pas uniquement aux connaissances générales.
