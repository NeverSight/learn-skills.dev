Generieren Sie produktionsbereite Vue 3 Single File Components (SFC) aus Beschreibungen, Designmodellen, Bildern oder URLs. Verwenden Sie diese Fähigkeit, wann immer der Benutzer eine Vue 3-Seite oder -Komponente erstellen, ein Design/Mockup/Screenshot in Vue-Code konvertieren, eine Benutzeroberfläche aus einer Beschreibung generieren, eine Vue-Seite mit dynamischen Daten erstellen oder eine Vue-Komponente mit der richtigen Reaktivität aufbauen möchte. Wird auch dann ausgelöst, wenn der Benutzer Dinge sagt wie „Erstelle mir eine Vue-Seite“, „Konvertiere dieses Design in Vue“, „Erstelle diese Benutzeroberfläche in Vue“, „Schreibe eine Vue-Komponente für ...“, „Ich habe ein Figma/Design/Screenshot, verwandle es in Vue“ oder eine beliebige Variation der Vue/UI-Generierung. Verwenden Sie diese Fähigkeit immer für Aufgaben zur Vue 3-Codegenerierung – verlassen Sie sich nicht nur auf Allgemeinwissen.
