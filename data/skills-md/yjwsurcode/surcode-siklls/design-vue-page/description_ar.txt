توليد مكونات Vue 3 أحادية الملف (SFC) جاهزة للإنتاج من الأوصاف أو نماذج التصميم أو الصور أو الروابط. استخدم هذه الميزة كلما أراد المستخدم: بناء صفحة أو مكوّن Vue 3، تحويل تصميم/نموذج/لقطة شاشة إلى كود Vue، إنشاء واجهة مستخدم من وصف، إنشاء صفحة Vue ببيانات ديناميكية، أو إعداد هيكل مكوّن Vue مع تفاعل صحيح. قم بالتفعيل حتى إذا قال المستخدم شيئًا مثل "اعطني صفحة Vue"، "حوّل هذا التصميم إلى Vue"، "ابنِ هذه الواجهة في Vue"، "اكتب مكوّن Vue لـ..."، "لدي ملف Figma/تصميم/لقطة شاشة، حوّله إلى Vue"، أو أي صيغة أخرى لتوليد Vue/واجهة مستخدم. استخدم هذه الميزة دائمًا لمهام توليد كود Vue 3 — لا تعتمد على المعرفة العامة فقط.
