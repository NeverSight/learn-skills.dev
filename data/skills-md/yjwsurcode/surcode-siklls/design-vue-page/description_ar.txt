قم بإنشاء مكونات ملف واحد (SFC) Vue 3 جاهزة للإنتاج من الأوصاف أو نماذج التصميم أو الصور أو عناوين URL. استخدم هذه المهارة عندما يريد المستخدم: إنشاء صفحة أو مكون Vue 3، أو تحويل تصميم/نموذج بالحجم الطبيعي/لقطة شاشة إلى رمز Vue، أو إنشاء واجهة مستخدم من الوصف، أو إنشاء صفحة Vue ببيانات ديناميكية، أو دعم مكون Vue بالتفاعل المناسب. قم بالتشغيل حتى إذا قال المستخدم أشياء مثل "اجعلني صفحة Vue"، أو "تحويل هذا التصميم إلى Vue"، أو "إنشاء واجهة المستخدم هذه في Vue"، أو "اكتب مكون Vue لـ..."، أو "لدي Figma/design/لقطة شاشة، أو حولها إلى Vue"، أو أي شكل مختلف من إنشاء Vue/UI. استخدم هذه المهارة دائمًا لمهام إنشاء التعليمات البرمجية لـ Vue 3 - لا تعتمد على المعرفة العامة وحدها.
