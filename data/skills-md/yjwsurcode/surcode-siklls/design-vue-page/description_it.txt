Genera componenti a file singolo (SFC) Vue 3 pronti per la produzione da descrizioni, modelli di progettazione, immagini o URL. Utilizza questa competenza ogni volta che l'utente desidera: creare una pagina o un componente Vue 3, convertire un design/mockup/screenshot in codice Vue, generare un'interfaccia utente da una descrizione, creare una pagina Vue con dati dinamici o impalcare un componente Vue con la reattività adeguata. Si attiva anche se l'utente dice cose come "creami una pagina Vue", "converti questo disegno in Vue", "crea questa interfaccia utente in Vue", "scrivi un componente Vue per...", "Ho un Figma/disegno/screenshot, trasformalo in Vue" o qualsiasi variazione della generazione di Vue/interfaccia utente. Utilizza sempre questa competenza per le attività di generazione del codice Vue 3: non fare affidamento solo sulla conoscenza generale.
