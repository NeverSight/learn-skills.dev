Genere componentes de archivo único (SFC) de Vue 3 listos para producción a partir de descripciones, maquetas de diseño, imágenes o URL. Utilice esta habilidad siempre que el usuario quiera: crear una página o componente de Vue 3, convertir un diseño/maqueta/captura de pantalla en código de Vue, generar una interfaz de usuario a partir de una descripción, crear una página de Vue con datos dinámicos o desarrollar un componente de Vue con la reactividad adecuada. Se activa incluso si el usuario dice cosas como "hazme una página de Vue", "convierte este diseño a Vue", "construye esta interfaz de usuario en Vue", "escribe un componente de Vue para...", "Tengo un Figma/diseño/captura de pantalla, conviértelo en Vue", o cualquier variación de la generación de Vue/UI. Utilice siempre esta habilidad para las tareas de generación de código de Vue 3; no confíe únicamente en el conocimiento general.
