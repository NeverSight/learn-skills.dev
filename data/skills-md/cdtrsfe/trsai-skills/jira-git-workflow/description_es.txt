Use esto cuando un usuario esté manejando una tarea de Jira y mencione completar, concluir, enviar, confirmar, enviar o enviar a control remoto, o necesita generar un mensaje de confirmación de Git del equipo a partir de capturas de pantalla o texto de Jira; infiere hazaña/corrección, número de Jira y título a partir de la información de Jira, confirma antes de confirmar y confirma después de confirmar si se debe enviar al control remoto.
