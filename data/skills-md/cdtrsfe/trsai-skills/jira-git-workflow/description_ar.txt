استخدمه عندما يتعامل المستخدم مع مهمة Jira ويذكر إكمالها أو اختتامها أو إرسالها أو الالتزام بها أو دفعها أو دفعها إلى جهاز التحكم عن بُعد، أو يحتاج إلى إنشاء رسالة التزام Git للفريق من لقطات شاشة/نص Jira؛ يتم استخدامه لاستنتاج العمل الفذ/الإصلاح ورقم Jira والعنوان من معلومات Jira والتأكيد قبل الالتزام والتأكيد بعد الالتزام ما إذا كان سيتم الدفع إلى جهاز التحكم عن بعد.
