Utilisez-le lorsqu'un utilisateur gère une tâche Jira et mentionne avoir terminé, conclu, soumis, validé, poussé ou poussé vers une télécommande, ou doit générer un message de validation Git d'équipe à partir de captures d'écran ou de texte Jira ; il déduit l'exploit/le correctif, le numéro Jira et le titre à partir des informations Jira, confirme avant la validation et confirme après la validation s'il faut pousser vers le distant.
