Úsalo al crear aplicaciones C# con .NET 8+, API de ASP.NET Core o aplicaciones web Blazor. Invócalo para C#, .NET, ASP.NET Core, Blazor, Entity Framework, EF Core, API mínima, MAUI, SignalR.
