À utiliser lors de la création d’applications C# avec .NET 8+, d’API ASP.NET Core ou d’applications Web Blazor. Crée des API REST à l’aide d’un routage minimal ou basé sur des contrôleurs, configure l’accès aux bases de données avec Entity Framework Core, implémente des modèles asynchrones et l’annulation, structure les applications avec CQRS via MediatR et génère des composants Blazor avec gestion d’état. À utiliser pour C#, .NET, ASP.NET Core, Blazor, Entity Framework, EF Core, Minimal API, MAUI, SignalR.
