# 小说活人感写作总装（novel-live-writing）

把三个活人感 skill 的能力拧成一股，专门服务「写小说 / 网文」。目标是让朱雀判定为真人写作，同时文字有活人温度、不 OOC、有节奏。

> 本仓库即 `novel-humanize` 的升级版：在原有（融合 anti-zhuque + ultra-remove-ai + wechat-ai-detox）基础上，进一步整合 `huoren-write` 与 `human-writing`，做成写小说默认调用的活人感总装。

## 三源能力与分工

- **novel-humanize**：朱雀真人率核心。一句一句细改、破折号清零、对话强制「」、长短错落、可玩梗/电影桥段、L1–L4 自检。→ 本 skill 的「去味主力」。
- **huoren-write**：表达层打磨。保剧情事实、保人物声口与格式、AI 痕迹库（连接词/三连词/金句升华/万能安抚腔）、检查脚本。→ 本 skill 的「打磨质检」。
- **human-writing**：通用活人感原则（材料先行、说话位置、不写翻案腔、不穿论坛装）。→ 本 skill 的「创作基调」（但小说场景放宽其标点限制，见下）。

## 核心原则（写小说时全程遵守）

1. **一句一句细改，骨架打散，不换皮**。减空洞修辞（景物堆砌、心理标签、华丽排比），加生活颗粒（闲笔、无用道具、感官偏见、私人印记）。
2. **保剧情、不 OOC**：只改「怎么说」，不改「说什么」。改写前锁动机-阻碍-动作-结果链，人物语气全程一致。
3. **对话强制「」**：中文直角引号，半角双引号 `""` 清零，嵌套用『』。
4. **破折号清零**：用逗号或句号代替（三源一致，小说场景同样执行）。
5. **标点节奏（用户明确要求，重点）**——连贯叙述要有语流，但绝不机械：
   - **连贯句子少用句号**：叙述连贯处用逗号、分号连成语流，避免每句一个句号把文气切碎；**但不无脑合并成超长句**——情绪高点、转折、段落末仍用句号断句（参考密度每百字 5–8 个句号，宁少勿碎）。
   - **适当用感叹号**：情绪、语气、强调、对白自然处用，不堆砌（不句句都「！」）。
   - **适当用问号**：内心独白、对白反问、悬疑勾子、制造互动感处用。
   - **冒号分两类**：解释式提示冒号（「核心是：」「值得注意的是：」「一句话总结：」）仍避免，属 AI 味；**对话引导冒号（「他说：」）、自然列举冒号可用**，且必须自然、不突兀。
   - 整体标点服务于语感与情绪，不炫技、不机械。
6. **长短错落**：禁止连续 3 句以上长度/结构相近；段落有变化（长段/短段交替），偶尔一句独立成段。
7. **可以有梗、可电影桥段化**（镜头感、蒙太奇、台词化对白、场景跳切），但不强行、不 OOC、不为梗牺牲剧情。
8. **人情味基调**：糙话、走神、记错、碎对话、不完美角色。让文字有活人温度。

## 工作流

```
Step 0 通读锁上下文 → 小说类型 / 动机-阻碍-动作-结果链 / 文风基调 / 朱雀风险初判
Step 1 诊断 → AI 痕迹 + 朱雀 6 特征 + 五维风险（参照 novel-humanize 诊断框架）
Step 2 定档 → 轻 / 中 / 重，决定处理力度
Step 3 一句一句改 → 减空洞加颗粒，电影桥段/玩梗视情境，保人物声口
Step 4 标点与硬清零 → 破折号清零、对话「」、禁用词清零、连贯句少句号 + ！？：自然化
Step 5 L1–L4 终审 → 活人感 / 一致性 / 误伤核查
Step 6 输出 → 报告 + 改写全文
```

## 硬约束

- 不改剧情 / 人设 / 事实 / 核心意思；不 OOC；长度浮动 ±20%。
- 对话「」、破折号清零、禁用词清零（清单见 `references/banned-words.md`）。
- **连贯句少句号 + 感叹号/问号/冒号自然化（用户明确要求，不得省略）**。
- 骨架必须打散：段落结构、叙事顺序、信息组织都要动，不能只换词汇句式。

## 触发

写小说正文、网文章节、人物对白、正文润色、去 AI 味改写时**默认调用**本 skill。
非小说场景（公众号 / 学术 / 新闻）请用专用 skill（wechat-ai-detox / human-writing）。
