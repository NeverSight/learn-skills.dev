Habilidad sólo explícita. Crea diagramas explicativos para documentos como archivos SVG de coordenadas manuales en figures/<nombre>.svg y genera PNGs si es necesario. Trátalos como componentes independientes del formato que pueden referenciarse desde cualquier lugar—Markdown, HTML o DOCX. Úsalos solo cuando el usuario lo especifique explícitamente, por ejemplo “/svg‑figure” o “use svg‑figure”. No se activan automáticamente solo porque alguien diga “make a diagram” o “illustrate”. No se emplean para wireframes de pantalla ni para gráficos numéricos.

Por favor, responde siempre en el idioma del usuario.
