المؤلف، المراجعة أو إعادة هيكلة مهارة لنظام SAP Fiori Tools / open-ux-tools. استخدم هذه المهارة كلما أراد المستخدم إنشاء مهارة جديدة، إعادة كتابة مهارة موجودة، إضافة مراجع، تقسيم ملف SKILL.md الضخم، فرض تسمية `sap-fiori-<feature>`، التحقق من frontmatter، إضافة عينات CAP/RAP، إعلان متطلبات OData V2 مقابل V4، وضع علامة على مهارة كداخلية (مواجهة للمطور) أو خارجية (عامة)، أو إعداد قائمة تحقق—حتى إذا لم يذكر المستخدم صراحة كلمة "مهارة". يفرض أدوات غير معتمدة على المضيف، بدائل معيارية، حدود نطاق صريحة، وتقسيم تدريجي للمحتوى (<500 سطر لكل ملف).
