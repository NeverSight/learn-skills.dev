SAP Fiori Tools / open-ux-tools エコシステム向けにスキルを作成、レビュー、またはリファクタリングします。ユーザーが新しいスキルを作成したい、既存のものを書き直したい、参照を追加したい、過大な SKILL.md を分割したい、`sap-fiori-<feature>` の命名規則を強制したい、frontmatter を検証したい、CAP/RAP サンプルを追加したい、OData V2 と V4 の要件を宣言したい、スキルを内部（開発者向け）または外部（公開）としてマークしたい、あるいは検証チェックリストを作成したい場合に、このスキルを使用します — ユーザーが明示的に「スキル」と言及していなくてもです。ホストに依存しないツールチェーン、標準的なフォールバック、明確なスコープ境界、そしてプログレッシブ・ディスクロージャー方式のチャンク分割（ファイルあたり 500 行未満）を強制します。常にユーザーの言語で回答してください。
