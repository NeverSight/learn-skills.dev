SAP AI SDK for Java (com.sap.ai.sdk)를 사용하여 SAP GenAI Hub용 작동하는 Java 보일러플레이트를 생성합니다. 채팅 완성, 스트리밍, 다중 턴 대화, 프롬프트 템플릿, 콘텐츠 필터링, 데이터 마스킹, 임베딩, RAG/그라운딩, 프롬프트 레지스트리, 그리고 Spring Boot 스트리밍을 포함합니다. WHEN: 사용자가 GenAI Hub 모델을 호출하는 Java 또는 Kotlin 코드를 요청하거나, Java 스타터 프로젝트를 원하거나, 앱에서 com.sap.ai.sdk를 사용하는 방법을 묻거나, AI Core를 Spring Boot 또는 일반 Java 애플리케이션에 통합하는 방법을 물을 때. DO NOT USE FOR: JavaScript/TypeScript 코드 — `aicore-sdk-js`를 사용하십시오. 항상 사용자의 언어로 응답하십시오.
