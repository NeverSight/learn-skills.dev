Générez du boilerplate Java fonctionnel pour SAP GenAI Hub en utilisant le SDK IA SAP pour Java (com.sap.ai.sdk). Couvre la complétion de chat, le streaming, les conversations à plusieurs tours, les modèles de prompt, le filtrage de contenu, le masquage de données, les embeddings, le RAG/grounding, le registre de prompts et le streaming Spring Boot. QUAND : l'utilisateur demande du code Java ou Kotlin qui appelle un modèle GenAI Hub, souhaite un projet de démarrage Java, demande comment utiliser com.sap.ai.sdk dans son application, ou demande comment intégrer AI Core dans une application Spring Boot ou Java standard. NE PAS UTILISER POUR : du code JavaScript/TypeScript — utilisez `aicore-sdk-js`. Veuillez toujours répondre dans la langue de l'utilisateur.
