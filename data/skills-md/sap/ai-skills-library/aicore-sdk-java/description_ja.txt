Java 用 SAP GenAI Hub の動作するボイラープレートを、SAP AI SDK for Java（com.sap.ai.sdk）を使用して生成します。チャット完了、ストリーミング、マルチターン会話、プロンプトテンプレート、コンテンツフィルタリング、データマスキング、埋め込み、RAG/グラウンディング、プロンプトレジストリ、Spring Boot ストリーミングをカバーします。WHEN: ユーザーが GenAI Hub モデルを呼び出す Java または Kotlin のコードを求めている、Java スタータープロジェクトが欲しい、com.sap.ai.sdk の使い方を質問している、または AI Core を Spring Boot やプレーンな Java アプリケーションに統合する方法を尋ねている場合。DO NOT USE FOR: JavaScript/TypeScript のコード — `aicore-sdk-js` を使用してください。

常にユーザーの言語で応答してください。
