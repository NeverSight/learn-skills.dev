Genera boilerplate Java funzionante per SAP GenAI Hub utilizzando l'SAP AI SDK per Java (com.sap.ai.sdk). Copre il completamento della chat, lo streaming, le conversazioni a più turni, i modelli di prompt, il filtraggio dei contenuti, la mascheratura dei dati, gli embeddings, il RAG/grounding, il registro dei prompt e lo streaming in Spring Boot. QUANDO: l'utente richiede codice Java o Kotlin che chiama un modello GenAI Hub, vuole un progetto starter Java, chiede come usare com.sap.ai.sdk nella sua app o come integrare AI Core in un’applicazione Spring Boot o Java pura. NON USARE PER: codice JavaScript/TypeScript — usa `aicore-sdk-js`.  

Rispondi sempre nella lingua dell'utente.
