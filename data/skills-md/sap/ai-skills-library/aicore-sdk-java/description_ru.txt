Создайте работающий шаблон Java для SAP GenAI Hub, используя SAP AI SDK для Java (com.sap.ai.sdk). Охватывает завершение чата, потоковую передачу, многоручные диалоги, шаблоны подсказок, фильтрацию контента, маскирование данных, эмбеддинги, RAG/grounding, реестр подсказок и потоковую передачу в Spring Boot. КОГДА: пользователь запрашивает код Java или Kotlin, вызывающий модель GenAI Hub, хочет стартовый проект Java, интересуется, как использовать com.sap.ai.sdk в своём приложении, или как интегрировать AI Core в Spring Boot или обычное Java‑приложение. НЕ ДЛЯ: кода JavaScript/TypeScript — используйте `aicore-sdk-js`. Всегда отвечайте на языке пользователя.
