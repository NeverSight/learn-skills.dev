Erstelle funktionierenden Java-Boilerplate-Code für SAP GenAI Hub unter Verwendung des SAP AI SDK für Java (com.sap.ai.sdk). Deckt Chat-Completion, Streaming, mehrstufige Unterhaltungen, Prompt-Vorlagen, Inhaltsfilterung, Datenmaskierung, Embeddings, RAG/Grundlagen, Prompt-Register und Spring‑Boot‑Streaming ab. WANN: Der Nutzer fragt nach Java‑ oder Kotlin-Code, der ein GenAI Hub‑Modell aufruft, möchte ein Java‑Starter‑Projekt, fragt, wie man com.sap.ai.sdk in seiner Anwendung nutzt, oder wie man AI Core in eine Spring‑Boot‑ oder reine Java‑Anwendung integriert. NICHT VERWENDEN FÜR: JavaScript/TypeScript‑Code — verwenden Sie `aicore-sdk-js`.
