توليد قالب Java عملي لـ SAP GenAI Hub باستخدام SAP AI SDK لـ Java (com.sap.ai.sdk). يغطي إكمال الدردشة، البث، المحادثات متعددة الأدوار، قوالب المطالبات، تصفية المحتوى، إخفاء البيانات، التضمينات، RAG/التثبيت على أسس واقعية، سجل المطالبات، والبث في Spring Boot. متى: عندما يطلب المستخدم كود Java أو Kotlin يستدعي نموذج GenAI Hub، أو يرغب في مشروع بدائي بـ Java، أو يسأل عن كيفية استخدام com.sap.ai.sdk في تطبيقه، أو يسأل عن كيفية دمج AI Core في تطبيق Spring Boot أو تطبيق Java عادي. لا تُستَخدم لـ: كود JavaScript/TypeScript — استخدم `aicore-sdk-js`.

يرجى دائمًا الرد بلغة المستخدم.
