إنشاء قالب عمل TypeScript/JavaScript لـ SAP GenAI Hub باستخدام @sap-ai-sdk/orchestration، @sap-ai-sdk/foundation-models، @sap-ai-sdk/openai (SDK الأصلي لـ OpenAI)، @sap-ai-sdk/langchain (LangChain)، @sap-ai-sdk/document-grounding (RAG)، @sap-ai-sdk/prompt-registry، @sap-ai-sdk/llm-batch (وظائف الدفعة)، @sap-ai-sdk/rpt (التنبؤ الجدولي)، أو @sap-ai-sdk/context-registry (وجهات البيانات، القطع الجدولية، تكوينات السيناريو). عند: يطلب المستخدم TypeScript أو JavaScript أو Node.js أو كود JS/TS يستدعي نموذج GenAI Hub، أو يريد مشروعًا تمهيديًا بـ TypeScript، أو يسأل عن كيفية استخدام @sap-ai-sdk في تطبيقه، أو يسأل عن كيفية استخدام LangChain (JS/TS) مع SAP AI Core، أو يريد كود JS/TS لـ RAG/تأصيل المستندات، قوالب المطالبات، وظائف دفعات LLM، التنبؤ الجدولي (RPT)، أو إدارة وجهات البيانات/القطع الجدولية/تكوينات السيناريو عبر سجل السياق. لا يُستخدم لـ: كود جافا — استخدم `aicore-sdk-java`. يرجى دائمًا الرد بلغة المستخدم.
