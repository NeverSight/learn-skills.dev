Generiere funktionierendes TypeScript/JavaScript‑Boilerplate für SAP GenAI Hub unter Verwendung von @sap-ai-sdk/orchestration, @sap-ai-sdk/foundation-models, @sap-ai-sdk/openai (nativer OpenAI‑SDK), @sap-ai-sdk/langchain (LangChain), @sap-ai-sdk/document-grounding (RAG), @sap-ai-sdk/prompt-registry, @sap-ai-sdk/llm-batch (Batch‑Jobs), @sap-ai-sdk/rpt (tabellarische Vorhersage) oder @sap-ai-sdk/context-registry (Datenziele, tabellarische Artefakte, Szenario‑Konfigurationen). WANN: Der Nutzer fragt nach TypeScript‑, JavaScript‑, Node.js‑ oder JS/TS‑Code, der ein GenAI Hub‑Modell aufruft, möchte ein TypeScript‑Starter‑Projekt, fragt, wie @sap-ai-sdk in seiner Anwendung verwendet wird, wie LangChain (JS/TS) mit SAP AI Core genutzt wird, oder wünscht JS/TS für RAG/Dokument‑Grounding, Prompt‑Templates, Batch‑LLM‑Jobs, tabellarische (RPT) Vorhersage oder das Verwalten von Datenzielen / tabellarischen Artefakten / Szenario‑Konfigurationen über das Context Registry. NICHT VERWENDEN FÜR: Java‑Code – verwenden Sie `aicore-sdk-java`.
