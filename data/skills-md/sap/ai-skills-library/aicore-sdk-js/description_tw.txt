產生可運作的 TypeScript/JavaScript 樣板程式碼，用於 SAP GenAI Hub，使用 @sap-ai-sdk/orchestration、@sap-ai-sdk/foundation-models、@sap-ai-sdk/openai（原生 OpenAI SDK）、@sap-ai-sdk/langchain（LangChain）、@sap-ai-sdk/document-grounding（RAG）、@sap-ai-sdk/prompt-registry、@sap-ai-sdk/llm-batch（批次工作）、@sap-ai-sdk/rpt（表格預測）或 @sap-ai-sdk/context-registry（資料目的地、表格資產、情境設定）。  
何時使用：使用者要求 TypeScript、JavaScript、Node.js 或 JS/TS 程式碼以呼叫 GenAI Hub 模型、想要 TypeScript 入門專案、詢問如何在應用程式中使用 @sap-ai-sdk、詢問如何在 SAP AI Core 中使用 LangChain（JS/TS），或需要用於 RAG/文件基礎、提示範本、批次 LLM 工作、表格（RPT）預測，或透過 Context Registry 管理資料目的地／表格資產／情境設定的 JS/TS 程式碼。  
不要用於：Java 程式碼 — 請使用 `aicore-sdk-java`。
