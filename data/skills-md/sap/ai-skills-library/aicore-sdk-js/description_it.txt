Genera boilerplate funzionante TypeScript/JavaScript per SAP GenAI Hub utilizzando @sap-ai-sdk/orchestration, @sap-ai-sdk/foundation-models, @sap-ai-sdk/openai (SDK OpenAI nativo), @sap-ai-sdk/langchain (LangChain), @sap-ai-sdk/document-grounding (RAG), @sap-ai-sdk/prompt-registry, @sap-ai-sdk/llm-batch (lavori batch), @sap-ai-sdk/rpt (predizione tabellare) o @sap-ai-sdk/context-registry (destinazioni dati, artefatti tabellari, configurazioni di scenario). 

QUANDO: l'utente richiede codice TypeScript, JavaScript, Node.js o JS/TS che chiama un modello GenAI Hub, desidera un progetto starter TypeScript, chiede come usare @sap-ai-sdk nella propria app, chiede come usare LangChain (JS/TS) con SAP AI Core, o vuole JS/TS per RAG/document‑grounding, template di prompt, lavori batch LLM, predizione tabellare (RPT) o la gestione di destinazioni dati / artefatti tabellari / configurazioni di scenario tramite il Context Registry. 

NON USARE PER: codice Java — usare `aicore-sdk-java`. 

Rispondi sempre nella lingua dell'utente.
