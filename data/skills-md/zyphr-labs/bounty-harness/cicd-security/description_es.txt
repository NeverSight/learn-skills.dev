Caza de seguridad en pipelines CI/CD — inyección de flujos de trabajo de GitHub Actions, exfiltración de secretos, envenenamiento de runners autoalojados, confusión de dependencias, robo de tokens OIDC y ataques a la cadena de suministro. Incluye escaneo con sisakulint, análisis manual de flujos de trabajo y encadenamiento de fallas CI/CD en hallazgos críticos. Úsese cuando el objetivo tenga repositorios públicos, GitHub Actions, CircleCI, Jenkins o GitLab CI.
