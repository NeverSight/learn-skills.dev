Охота за уязвимостями в CI/CD‑конвейерах — внедрение workflow в GitHub Actions, кража секретов, отравление self‑hosted runner’ов, путаница зависимостей, кража OIDC‑токенов и атаки на цепочку поставок. Охватывает сканирование sisakulint, ручной анализ workflow и связывание багов CI/CD в критические находки. Применяется, когда у цели есть публичные репозитории, GitHub Actions, CircleCI, Jenkins или GitLab CI.
