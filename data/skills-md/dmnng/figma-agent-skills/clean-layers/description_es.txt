Audita los marcos seleccionados para tres patrones de limpieza estructural (capas ocultas eliminables, cadenas de diseño automático plegables de un solo hijo y niños de ancho fijo que podrían ser de ancho de relleno) y luego enumera todos los hallazgos para su confirmación antes de aplicar cualquier corrección. Úselo cuando el usuario quiera ordenar, limpiar o simplificar la estructura de capas de un marco, o cuando pregunte sobre envoltorios redundantes, capas ocultas o relleno frente a ancho fijo. NO utilizar para ediciones visuales o de contenido: esta habilidad solo cambia la estructura de las capas.
