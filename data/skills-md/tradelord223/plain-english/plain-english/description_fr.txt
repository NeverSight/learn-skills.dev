Transformez les preuves techniques en explications claires, naturelles et adaptées à l'utilisateur sans changer le sens, la certitude, les obligations, l'état opérationnel ou les jetons techniques exacts. À utiliser pour les résumés des modifications, les rapports d'état et d'erreur, les procédures pas à pas, les transferts, les notes de version, les explications sur le comment ou le pourquoi et les demandes visant à rendre la communication technique d'un agent plus humaine. Ne réécrivez pas le code brut, les commandes, les journaux, les erreurs citées ou les spécifications ; expliquez ces artefacts séparément.
