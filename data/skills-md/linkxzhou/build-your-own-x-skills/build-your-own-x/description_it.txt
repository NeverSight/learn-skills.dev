Punto di ingresso per apprendere ricostruendo software reale da zero (build‑your‑own‑x): Git, Redis/database, una shell, Docker/container, un interprete/compilatore, un sistema operativo, un emulatore, un server web, un browser, un motore di regex o di template, un ray tracer, un gioco, una rete neurale, blockchain, un LLM, malloc, una CPU e molto altro. Usalo ogni volta che qualcuno vuole capire come funziona uno strumento costruendone uno proprio, chiede un progetto pratico per apprendere competenze di sistema, vuole sapere quale progetto “build‑your‑own” avviare, oppure è bloccato/debugga a metà della propria implementazione da zero (ad es. “il mio Git produce hash diversi da Git reale”, “il mio ray tracer ha shadow acne”, “il mio CHIP‑8 disegna spazzatura”, “il mio kernel giocattolo provoca triple fault”). Trigger cinesi: 从零实现、自己动手写一个 X、手写 Redis/Git/Shell/Docker/解释器/操作系统、造轮子学原理、我自己写的 X 出 bug/卡在第 N 步、项目式学习、推荐一个练手项目. Il sistema sceglie l’argomento, la lingua e il tutorial, passa al percorso di competenza corrispondente nella sezione skills/ e fornisce una guida passo passo anziché scaricare una soluzione completa. 

Rispondi sempre nella lingua dell’utente.
