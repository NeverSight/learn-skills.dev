從零重建真實軟體以學習的入口（自行實作 X）：Git、Redis/資料庫、Shell、Docker/容器、直譯器/編譯器、作業系統、模擬器、Web 伺服器、瀏覽器、正則表達式或模板引擎、光線追蹤器、遊戲、神經網路、區塊鏈、大型語言模型（LLM）、malloc、CPU 等等。 在任何人想透過自行構建來了解工具運作、需要動手專案以學習系統技能、詢問該從哪個自行實作專案開始，或是在自行從頭實作的過程中卡住/除錯（例如「我的 Git 雜湊與官方 Git 不同」「我的光線追蹤器出現陰影痘痘」「我的 CHIP‑8 顯示雜訊」「我的玩具核心三次故障」）時，都可以使用它。 中文觸發詞：從零實現、自己動手寫一個 X、手寫 Redis/Git/Shell/Docker/解釋器/作業系統、造輪子學原理、我自己寫的 X 出 bug/卡在第 N 步、專案式學習、推薦一個練手專案。 它會自動挑選主題、語言與教學內容，交由 skills/ 目錄下相應的技能軌道，並一步步指導，而不是直接提供完整答案。 請始終以使用者的語言回覆。
