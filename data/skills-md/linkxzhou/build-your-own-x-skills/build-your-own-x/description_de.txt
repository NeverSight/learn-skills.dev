Einstiegspunkt für das Lernen, indem man reale Software von Grund auf neu erstellt (build‑your‑own‑x): Git, Redis/Datenbanken, eine Shell, Docker/Container, ein Interpreter/Compiler, ein Betriebssystem, ein Emulator, ein Web‑Server, ein Browser, eine Regex‑ oder Template‑Engine, ein Ray‑Tracer, ein Spiel, ein neuronales Netzwerk, Blockchain, ein LLM, malloc, eine CPU und mehr. Verwende es immer, wenn jemand verstehen will, wie ein Werkzeug funktioniert, indem er sein eigenes baut, nach einem Praxisprojekt fragt, um Systemfähigkeiten zu lernen, wissen möchte, welches Build‑your‑own‑Projekt er starten soll, oder feststeckt/bei der Fehlersuche mitten in seiner eigenen Implementierung von Grund auf (z. B. „der Hash meines eigenen Git unterscheidet sich vom echten Git“, „mein Ray‑Tracer hat Schattenakne“, „mein CHIP‑8 zeichnet Müll“, „mein Spiel‑Kernel verursacht Triple‑Faults“). Chinesische Auslöser: 从零实现、自己动手写一个 X、手写 Redis/Git/Shell/Docker/解释器/操作系统、造轮子学原理、我自己写的 X 出 bug/卡在第 N 步、项目式学习、推荐一个练手项目. Es wählt das Thema, die Sprache und das Tutorial aus, leitet an die passende Track‑Fähigkeit unter skills/ weiter und coacht Schritt für Schritt, anstatt eine fertige Lösung zu liefern. Bitte antworte immer in der Sprache des Nutzers.
