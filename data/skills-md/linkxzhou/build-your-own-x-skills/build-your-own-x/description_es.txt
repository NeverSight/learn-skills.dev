Punto de entrada para aprender reconstruyendo software real desde cero (construye‑tu‑propio‑x): Git, Redis/bases de datos, una shell, Docker/contenedores, un intérprete/compilador, un SO, un emulador, un servidor web, un navegador, un motor de expresiones regulares o de plantillas, un trazador de rayos, un juego, una red neuronal, blockchain, un LLM, malloc, una CPU y más. Úsalo siempre que alguien quiera entender cómo funciona una herramienta construyendo la suya propia, solicite un proyecto práctico para aprender habilidades de sistemas, pregunte por qué proyecto de “construye‑tu‑propio” comenzar, o esté atascado/debugueando a mitad de su propia implementación desde cero (p. ej. “el hash de mi propio git difiere del git real”, “mi trazador de rayos tiene acne de sombras”, “mi CHIP‑8 dibuja basura”, “mi kernel de juguete produce triple‑faults”). Disparadores en chino: 从零实现、自己动手写一个 X、手写 Redis/Git/Shell/Docker/解释器/操作系统、造轮子学原理、我自己写的 X 出 bug/卡在第 N 步、项目式学习、推荐一个练手项目. Selecciona el tema, el lenguaje y el tutorial, lo dirige a la pista de habilidades correspondiente en skills/, y guía paso a paso en lugar de entregar una solución terminada.
