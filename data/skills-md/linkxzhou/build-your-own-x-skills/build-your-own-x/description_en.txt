Entry point for learning by rebuilding real software from scratch (build-your-own-x): Git, Redis/databases, a shell, Docker/containers, an interpreter/compiler, an OS, an emulator, a web server, a browser, a regex or template engine, a ray tracer, a game, a neural network, blockchain, an LLM, malloc, a CPU, and more. Use it whenever someone wants to understand how a tool works by building their own, asks for a hands-on project to learn systems skills, asks which build-your-own project to start with, OR is stuck/debugging midway through their own from-scratch implementation (e.g. 'my own git’s hash differs from real git', 'my ray tracer has shadow acne', 'my CHIP-8 draws garbage', 'my toy kernel triple-faults'). Chinese triggers: 从零实现、自己动手写一个 X、手写 Redis/Git/Shell/Docker/解释器/操作系统、造轮子学原理、我自己写的 X 出 bug/卡在第 N 步、项目式学习、推荐一个练手项目. It picks the topic, language and tutorial, hands off to the matching track skill under skills/, and coaches step by step instead of dumping a finished solution.
