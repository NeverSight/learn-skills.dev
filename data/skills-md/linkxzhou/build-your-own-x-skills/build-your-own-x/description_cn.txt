从零重建真实软件的学习入口（自行实现 X）：Git、Redis/数据库、Shell、Docker/容器、解释器/编译器、操作系统、模拟器、Web 服务器、浏览器、正则或模板引擎、光线追踪器、游戏、神经网络、区块链、大语言模型、malloc、CPU 等。每当有人想通过自己动手构建来了解工具原理，或需要动手项目学习系统技能，询问该从哪个自行实现项目入手，或在自己从零实现的过程中卡住/调试（例如“我的 Git 哈希与真实 Git 不同”“我的光线追踪器出现阴影痤疮”“我的 CHIP‑8 绘制乱码”“我的玩具内核三次故障”），都可以使用它。中文触发词：从零实现、自己动手写一个 X、手写 Redis/Git/Shell/Docker/解释器/操作系统、造轮子学原理、我自己写的 X 出 bug/卡在第 N 步、项目式学习、推荐一个练手项目。它会挑选主题、语言和教程，转接到 skills/ 下对应的技能路径，并一步步辅导，而不是直接给出完整答案。
