壊れた Notte Function を診断・修復します。デプロイ済みまたはスケジュールされた Function が失敗し始めたり、空や誤った結果を返すようになった場合に使用します。例: 「my function fn_... が現在空を返す」「スクレイパー関数を修復して」「サイト変更後に Indeed 関数が壊れた」「この失敗した関数実行を修正して」「スケジュールされた関数が動かなくなった原因を診断して」など。ユーザーが壊れた Function を提供すると、このスキルが根本原因を特定し、変更された対象を再探索し、単体で修正を検証した上で、確認ゲートを通して展開します。Notte Functions を構築する **notte-functions-build** と連携して使用します。
