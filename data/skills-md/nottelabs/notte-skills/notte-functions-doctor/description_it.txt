Diagnostica e ripara una Notte Function rotta. Usa quando una Function distribuita o programmata ha iniziato a fallire o a restituire risultati vuoti/errati — ad esempio “la mia function fn_… restituisce ora vuoto”, “ripara la mia function scraper”, “la function Indeed si è rotta dopo che il sito è cambiato”, “correggi questa esecuzione di function fallita”, o “diagnostica perché la mia function programmata ha smesso di funzionare”. L’utente fornisce la Function rotta; questa skill individua la causa radice, riesplora la superficie modificata, verifica una correzione in isolamento e la promuove dietro un cancello di conferma. Si abbina a notte‑functions‑build, che costruisce le Functions.  

Rispondi sempre nella lingua dell’utente.
