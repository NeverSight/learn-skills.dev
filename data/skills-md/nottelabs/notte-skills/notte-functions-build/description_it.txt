Esplora un sito web una volta, individua il percorso dati stabile e distribuiscilo come una Notte Function riutilizzabile e parametrizzata (un endpoint HTTP chiamabile che può essere programmato ed eseguito su larga scala). Usalo quando un utente vuole costruire, creare, generare o “cuocere” uno scraper riutilizzabile o un’automazione del browser per un sito, trasformare uno scraping funzionante in un’API/endpoint/job, o dice cose come “eseguirò N parole chiave più tardi”, “rendi questo riutilizzabile”, “estrai tutti gli elenchi”, “automatizza questo sito ogni giorno” o “costruisci una funzione che estrae X da Y”. Si abbina a notte-functions-doctor, che ripara una Funzione costruita quando il sito cambia.
