استكشف موقعًا واحدًا، حدد مسار البيانات المستقر، وانشره كدالة Notte قابلة لإعادة الاستخدام وبارامترية (نقطة وصول HTTP قابلة للاستدعاء يمكن جدولتها وتشغيلها على نطاق واسع). استخدمها عندما يرغب المستخدم في بناء أو إنشاء أو توليد أو "خبز" أداة استخراج أو أتمتة متصفح قابلة لإعادة الاستخدام لموقع ما، أو تحويل استخراج عامل إلى API/نقطة وصول/مهمة، أو يقول عبارات مثل "سأُنفّذ N كلمة مفتاحية لاحقًا"، "اجعل هذا قابلًا لإعادة الاستخدام"، "اسحب جميع القوائم"، "أتمت هذا الموقع كل يوم"، أو "أنشئ دالة تستخرج X من Y". تتكامل مع notte-functions-doctor، الذي يُصلح الدالة المُنشأة عندما يتغيّر الموقع.
