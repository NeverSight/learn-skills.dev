Erkunde eine Website einmal, finde den stabilen Datenpfad und setze sie als wiederverwendbare, parametrisierte Notte Function ein (ein aufrufbarer HTTP‑Endpunkt, der geplant und in großem Umfang ausgeführt werden kann). Verwende sie, wenn ein Benutzer eine wiederverwendbare Scraper‑ oder Browser‑Automatisierung für eine Seite erstellen, generieren oder „baken“ möchte, einen funktionierenden Scrape in eine API/Endpoint/Job umwandeln will oder Formulierungen wie „Ich werde später N Schlüsselwörter ausführen“, „Mach das wiederverwendbar“, „Alle Einträge abrufen“, „Diese Seite jeden Tag automatisieren“ oder „Eine Funktion erstellen, die X aus Y extrahiert“ verwendet. Passt zu notte‑functions‑doctor, das eine erstellte Funktion repariert, wenn sich die Seite ändert.
