Explora un sitio web una vez, encuentra la ruta de datos estable y despliega una Notte Function reutilizable y parametrizada (un endpoint HTTP invocable que se puede programar y ejecutar a gran escala). Usa esto cuando un usuario quiera construir, crear, generar o “hornear” un scraper o automatización de navegador reutilizable para un sitio, convertir un raspado funcional en una API/endpoint/tarea, o diga cosas como “Ejecutaré N palabras clave más tarde”, “haz esto reutilizable”, “extrae todos los listados”, “automatiza este sitio todos los días”, o “crea una función que extraiga X de Y”. Se combina con notte-functions-doctor, que repara una Función construida cuando el sitio cambia.
