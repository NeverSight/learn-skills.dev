Explorez un site web une fois, trouvez le chemin de données stable et déployez‑le comme une Notte Function réutilisable et paramétrée (un point de terminaison HTTP appelable qui peut être planifié et exécuté à grande échelle). À utiliser lorsqu’un utilisateur veut construire, créer, générer ou « baker » un scraper ou une automatisation de navigateur réutilisable pour un site, transformer un scrape fonctionnel en API/endpoint/job, ou dit des choses comme « Je lancerai N mots‑clés plus tard », « rendre ceci réutilisable », « extraire toutes les annonces », « automatiser ce site chaque jour » ou « créer une fonction qui extrait X de Y ». Se combine avec notte‑functions‑doctor, qui répare une fonction construite lorsque le site change.
