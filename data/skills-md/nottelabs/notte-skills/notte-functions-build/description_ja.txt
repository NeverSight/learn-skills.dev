ウェブサイトを一度だけ探索し、安定したデータパスを見つけ、再利用可能でパラメータ化された Notte Function としてデプロイします（スケジュール可能で大規模に実行できる呼び出し可能な HTTP エンドポイント）。ユーザーがサイト用の再利用可能なスクレイパーやブラウザ自動化を構築・作成・生成、あるいは「ベイク」したいとき、動作するスクレイプを API／エンドポイント／ジョブに変換したいとき、または「後で N キーワードを実行する」「これを再利用可能にする」「すべてのリストを取得する」「このサイトを毎日自動化する」「X から Y を抽出する関数を作る」などと言ったときに使用します。サイトが変わったときに構築された関数を修復する notte‑functions‑doctor とペアで使用します。
