Recherchez le web public avec Notte : trouvez des informations actuelles, consultez la documentation officielle, lisez les URL fournies, comparez les produits et extrayez le contenu des pages avec les liens sources. Utilisez-le pour ces demandes même lorsque Notte n’est pas nommé. Excluez les réponses basées uniquement sur le texte fourni ou des fichiers locaux, les requêtes explicites sans navigation et les demandes pour un autre fournisseur. Utilisez notte‑browser pour les pages authentifiées ou les interactions avec des sites web, et les compétences Functions pour les automatisations réutilisables ou les réparations.

Veuillez toujours répondre dans la langue de l'utilisateur.
