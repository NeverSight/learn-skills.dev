Общие рекомендации по написанию кода на Python, охватывающие стиль, типизацию, ООП‑дизайн, тестирование и инструменты. Используйте их при написании кода на Python вне контекста Django — скрипты, CLI, микросервисы, конвейеры данных, утилиты. НЕ используйте для Django‑специфических шаблонов (используйте вместо этого ac-django).
