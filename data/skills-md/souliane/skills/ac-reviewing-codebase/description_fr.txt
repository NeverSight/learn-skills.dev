Revue unifiée du code — audite la qualité des compétences, la santé du code, l’alignement de l’infrastructure et la cohérence transversale d’un portefeuille de dépôts. Exécute des métriques déterministes (ruff, couverture, complexité, TODO, obsolescence des dépendances) et un jugement architectural piloté par LLM. À utiliser lorsque l’utilisateur dit « revue des compétences », « audit des compétences », « audit du code », « qualité du code », « état du dépôt », « ce qui doit être poussé », « aligner les dépôts », « backport », « mettre à jour les dépendances », « évaluer le code », « vérification de santé », ou souhaite un passage complet de qualité sur les compétences et/ou le code.
