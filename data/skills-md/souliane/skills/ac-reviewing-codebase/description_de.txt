Einheitliche Codebasis-Überprüfung – prüft die Qualität von Skills, die Code‑Gesundheit, die Ausrichtung der Infrastruktur und die übergreifende Konsistenz in einem Portfolio von Repos. Führt deterministische Metriken aus (ruff, Coverage, Komplexität, TODOs, Veralten von Abhängigkeiten) und LLM‑gesteuertes architektonisches Urteil. Handhabt außerdem den Lieferstatus, das Zusammenfassen von Commits, die Harmonisierung der Infrastruktur und das Backporting von Boilerplate. Verwenden Sie dies, wenn der Benutzer sagt „review skills“, „audit skills“, „audit codebase“, „code quality“, „repo status“, „what needs pushing“, „align repos“, „backport“, „upgrade deps“, „assess codebase“, „health check“ oder einen gründlichen Qualitäts‑Durchlauf für Skills und/oder Code wünscht.
