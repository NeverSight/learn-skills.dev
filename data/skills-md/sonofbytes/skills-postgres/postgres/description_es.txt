Utilícelo al diseñar, escribir o modificar cualquier cosa que interactúe con una base de datos PostgreSQL en una aplicación — elegir tipos de columnas y claves, modelar entidades, tenancy y estado, escribir restricciones, añadir o auditar índices, redactar consultas (paginación, upserts, EXPLAIN), transacciones y bloqueo, colas de trabajo con SKIP LOCKED, búsqueda de texto completo, pgvector, particionamiento, escribir migraciones seguras ante bloqueos, roles y seguridad a nivel de fila, agrupación de conexiones, configuración del servidor, copias de seguridad, observabilidad y pruebas de la capa de datos. Determina primero la versión principal de Postgres, la forma de despliegue y la capa de acceso (pgx, Npgsql/EF Core, sqlc), y luego dirige a una referencia con fuente. Cada regla cita la documentación oficial o una autoridad reconocida. Para revisar una base de datos existente, use el agente postgres-quality-reviewer.
