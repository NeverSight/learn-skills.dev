Guide de portage d’une application Flutter existante vers DartNative. À utiliser lorsque : migration d’un projet ou d’un écran Flutter, le port ne compile pas, l’application s’ouvre sur un écran blanc, les builds iOS échouent avec des erreurs pod/deployment‑target/Swift‑symbol, ou un package plante au démarrage avec « Setting a message handler before the FlutterEngine has been run ». Couvre la migration Dart, le remplacement des packages et la chirurgie du projet iOS pour les ports sur place. Associez-le à la compétence dart‑native pour les différences d’API au niveau des widgets.  

Veuillez toujours répondre dans la langue de l’utilisateur.
