Manuale per la migrazione di un’app Flutter esistente a DartNative. Da utilizzare quando: si migra un progetto o una schermata Flutter, una porta non si compila, l’app si avvia con una schermata bianca, le compilazioni iOS falliscono con errori pod/deployment-target/Swift‑symbol, oppure un pacchetto va in crash all’avvio con “Setting a message handler before the FlutterEngine has been run”. Copre la migrazione Dart, la sostituzione dei pacchetti e l’intervento sul progetto iOS per le migrazioni in loco. Abbinalo alla skill dart‑native per le differenze API a livello di widget.

Rispondi sempre nella lingua dell’utente.
