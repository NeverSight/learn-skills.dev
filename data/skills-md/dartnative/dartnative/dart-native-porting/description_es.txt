Guía para portar una aplicación Flutter existente a DartNative. Usar cuando: se migra un proyecto o pantalla Flutter, un puerto no compila, la aplicación se lanza con una pantalla blanca, las compilaciones de iOS fallan con errores de pod/deployment-target/Símbolos de Swift, o un paquete se bloquea al iniciar con “Setting a message handler before the FlutterEngine has been run”. Cubre la migración a Dart, los reemplazos de paquetes y la cirugía del proyecto iOS para puertos in situ. Combínalo con la habilidad dart-native para las diferencias de API a nivel de widget.
