Руководство по переносу существующего приложения Flutter на DartNative. Используйте, когда: мигрируете проект или экран Flutter, порт не компилируется, приложение запускается с белым экраном, сборки iOS падают из‑за ошибок pod/deployment-target/Swift-symbol, или пакет падает при запуске с ошибкой «Setting a message handler before the FlutterEngine has been run». Охватывает миграцию на Dart, замену пакетов и «операцию» над проектом iOS для прямых портов. Сочетайте со знанием dart-native для различий в API на уровне виджетов.
