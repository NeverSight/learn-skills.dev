Playbook for porting an existing Flutter app to DartNative. Use when: migrating a Flutter project or screen, a port doesn't compile, the app launches to a white screen, iOS builds fail with pod/deployment-target/Swift-symbol errors, or a package crashes at startup with 'Setting a message handler before the FlutterEngine has been run'. Covers the Dart migration, package replacements, and the iOS project surgery for in-place ports. Pair with the dart-native skill for the widget-level API differences.
