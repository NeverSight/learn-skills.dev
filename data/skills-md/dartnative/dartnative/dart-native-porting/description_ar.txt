دليل خطوات نقل تطبيق Flutter موجود إلى DartNative. استخدمه عندما: تقوم بترحيل مشروع أو شاشة Flutter، أو لا يتم تجميع النسخة المنقولة، أو يفتح التطبيق بشاشة بيضاء، أو تفشل بنواتج iOS مع أخطاء pod/target النشر/رموز Swift، أو تتحطم حزمة عند بدء التشغيل برسالة "Setting a message handler before the FlutterEngine has been run". يغطي ترحيل Dart، واستبدال الحزم، وجراحة مشروع iOS للنسخ داخل الموقع. استخدم مهارة dart-native لتعامل مع اختلافات API على مستوى الواجهة.
