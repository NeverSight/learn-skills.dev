Expert knowledge for building apps with DartNative — the framework that renders Flutter-API Dart code as real native views (UIKit on iOS, the View system on Android). Use when: writing DartNative screens and widgets, checking what is and isn't Flutter-compatible, looking up widget APIs and their native lowerings, or migrating Flutter code. For porting an existing Flutter app (project setup, build failures, white screens), also load the dart-native-porting skill.
