Conocimiento experto para crear aplicaciones con DartNative — el framework que renderiza código Dart de la API de Flutter como vistas nativas reales (UIKit en iOS, el sistema de vistas en Android). Úsalo cuando: estés escribiendo pantallas y widgets DartNative, verificando qué es y qué no es compatible con Flutter, consultando APIs de widgets y sus equivalentes nativos, o migrando código Flutter. Para portar una app Flutter existente (configuración del proyecto, fallos de compilación, pantallas blancas), también carga la habilidad dart-native-porting.
