Connaissance experte pour créer des applications avec DartNative — le framework qui rend le code Dart de l'API Flutter sous forme de vues natives réelles (UIKit sur iOS, le système de vues sur Android). À utiliser lorsque : vous écrivez des écrans et des widgets DartNative, que vous vérifiez ce qui est ou n’est pas compatible avec Flutter, que vous recherchez les API des widgets et leurs implémentations natives, ou que vous migrez du code Flutter. Pour porter une application Flutter existante (configuration du projet, échecs de compilation, écrans blancs), chargez également la compétence dart-native-porting.
