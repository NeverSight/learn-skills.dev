Conoscenza esperta per sviluppare app con DartNative — il framework che trasforma il codice Dart dell'API Flutter in vere viste native (UIKit su iOS, il sistema View su Android). Usalo quando: scrivi schermate e widget DartNative, verifichi cosa è o non è compatibile con Flutter, cerchi le API dei widget e le loro implementazioni native, o migri codice Flutter. Per il porting di un’app Flutter esistente (configurazione del progetto, errori di compilazione, schermate bianche), carica anche la skill dart-native-porting.
