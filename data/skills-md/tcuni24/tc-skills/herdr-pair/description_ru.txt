Используйте, когда пользователь запрашивает запуск задачи с двумя агентами Herdr, отделяющими планирование/проверку от выполнения — «你负责规划和审核，让 X 执行», «协同两个 Agent», «把活派给 herdr 里的 X，你把关», «让它把结论返回给你», «你拆一下任务再派给X». Роли не зависят от типа агента — любая сторона может быть Клодом, Опенкодом, Кодексом, Дроидом, Курсором, Гермесом, ОМП, Кими, Пи, Гроком или кем-либо еще из списка. Охватывает ролевые контракты, разбиение работы на проверяемые раунды, автономные запросы на передачу, ограничение подсказки в 131 071 байт и восстановление «слишком длинного списка аргументов», проверку на основе артефактов с помощью git и без нее, аудит объяснений исполнителя, а не только его чисел, опасность одновременной записи и качественное аварийное отключение. Не для одноразовых реле — для них используйте herdr-handoff.
