Configura y usa el módulo nuxt-users para Nuxt 3 y Nuxt 4. Úsalo al añadir autenticación, gestión de usuarios, roles, restablecimiento de contraseña, configuración de la base de datos (SQLite/MySQL/PostgreSQL) o comandos CLI (migrate, create-user). Cubre nuxt.config (nuxtUsers), composables (useAuthentication, useUsers, usePublicPaths, usePasswordValidation, useNuxtUsersLocale), componentes (NUsersLoginForm, NUsersLogoutLink, etc.) y autorización (lista blanca, permisos).
