قُم بتهيئة واستخدام وحدة nuxt-users لـ Nuxt 3 و Nuxt 4. استخدمها عند إضافة المصادقة، إدارة المستخدمين، الأدوار، إعادة تعيين كلمة المرور، إعداد قاعدة البيانات (SQLite/MySQL/PostgreSQL)، أو أوامر سطر الأوامر (migrate، create-user). تشمل nuxt.config (nuxtUsers)، composables (useAuthentication، useUsers، usePublicPaths، usePasswordValidation، useNuxtUsersLocale)، المكونات (NUsersLoginForm، NUsersLogoutLink، إلخ)، وكذلك التفويض (القائمة البيضاء، الأذونات). يرجى دائمًا الرد بلغة المستخدم.
