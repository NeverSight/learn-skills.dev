Nitro est la boîte à outils serveur indépendante du framework (alimentant Nuxt) pour créer et déployer des serveurs web partout. Utilisez‑le lorsque vous travaillez avec nitro.config, les routes serveur/gestionnaires d'événements, les règles de routage, le caching, le stockage, les tâches, les websockets ou le déploiement sur Node/Bun/Deno/Cloudflare/Vercel.
