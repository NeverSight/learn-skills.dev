Usalo quando l'utente ha bisogno di accedere in remoto a un server Linux, riutilizzare le informazioni del server memorizzate localmente, eseguire comandi remoti singoli o in parallelo, o, dopo un errore iniziale di connessione/login, fornire l'indirizzo del server e le credenziali mancanti.

Per favore, rispondi sempre nella lingua dell'utente.
