Генерация, условленная позой, в RunComfy через CLI `runcomfy`. Направляет запросы к Kling 2‑6 Motion Control Pro / Standard (перенос движения/блокировки из референтного видео на целевого персонажа), к сообществу Wan 2‑2 Animate (анимация персонажа, управляемая аудио, с условием позы) и к Z‑Image Turbo ControlNet LoRA (генерация изображения, условленная позой, из изображения управления OpenPose / DWPose / canny / depth). Выбирает правильный маршрут в зависимости от видео vs статичного изображения и стилизованного vs фотореалистичного результата. Срабатывает на запросы «controlnet», «control net», «pose control», «openpose», «DWPose», «transfer pose», «motion control», «pose driven», «character pose», «depth control», «canny edge», «use this pose» или любой явный запрос условить генерацию позой / скелетом / движением / глубиной / canny‑референтом.
