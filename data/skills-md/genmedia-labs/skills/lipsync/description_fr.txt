Synchronisez les lèvres d’un visage avec une piste audio spécifique sur RunComfy via la CLI `runcomfy`. Dirigez vers ByteDance OmniHuman (avatar plein corps piloté par l’audio à partir d’un portrait + audio), Sync Labs sync v2 / Pro (synchronisation labiale de pointe sur une vidéo), Kling lipsync (audio‑vers‑vidéo et texte‑vers‑vidéo avec parole synchronisée), et Creatify lipsync. La compétence choisit le bon point de terminaison selon l’intention réelle de l’utilisateur — portrait fixe + audio (style avatar), vidéo source + audio (échange de bouche sur une séquence existante), ou générer‑et‑synchroniser à partir d’un script. Se déclenche sur « lip sync », « lipsync », « make this video speak », « match audio to mouth », « dub video », « sync lips to voice », « Sync Labs », « voiceover sync », ou toute demande explicite de faire bouger la bouche d’un visage à partir d’une piste audio.
