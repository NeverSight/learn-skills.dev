在命令列上執行任何 RunComfy 模型。`runcomfy` CLI 是單一執行檔、單一認證，支援數百個模型端點——圖像生成、圖像編輯、視頻生成、圖像轉視頻、唇形同步、臉部交換、視頻編輯、修復、延伸繪圖、ControlNet、重新光照、升級、LoRA 訓練等。提交請求、輪詢狀態、下載輸出。此技能教導代理如何安裝、驗證、發現模型結構、呼叫模型、串流／輪詢／不等待、以 JSON 輸出模式編寫腳本，並處理錯誤。觸發詞包括「runcomfy cli」「install runcomfy」「runcomfy login」「runcomfy run」「runcomfy whoami」「runcomfy api」或任何明確要求從腳本或終端呼叫 RunComfy 模型的請求。兄弟技能（ai-image-generation、ai-video-generation、image-edit、video-edit、face-swap、lipsync、image-to-video、image-inpainting、image-outpainting、video-extend、controlnet-pose、relight）皆透過此 CLI 發送。
