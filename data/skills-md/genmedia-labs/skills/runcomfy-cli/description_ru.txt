Запускайте любую модель на RunComfy из командной строки. CLI `runcomfy` — один бинарный файл, одна аутентификация, сотни конечных точек моделей: генерация изображений, редактирование изображений, генерация видео, перевод изображения в видео, синхронизация губ, замена лица, редактирование видео, ретуширование (inpainting), расширение границ (outpainting), увеличение (extend), ControlNet, переосвещение (relight), апскейл, обучение LoRA и многое другое. Отправьте запрос, опросите статус, скачайте результат. Этот навык обучает агента устанавливать, аутентифицироваться, обнаруживать схемы моделей, вызывать модели, использовать потоковую передачу / опрос / без ожидания, писать скрипты в режиме вывода JSON и обрабатывать ошибки. Срабатывает на фразы «runcomfy cli», «install runcomfy», «runcomfy login», «runcomfy run», «runcomfy whoami», «runcomfy api» или любой явный запрос вызвать модель RunComfy из скрипта или терминала. Сопутствующие навыки (ai-image-generation, ai-video-generation, image-edit, video-edit, face-swap, lipsync, image-to-video, image-inpainting, image-outpainting, video-extend, controlnet-pose, relight) все работают через этот CLI.
