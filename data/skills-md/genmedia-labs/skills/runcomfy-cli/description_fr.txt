Exécutez n'importe quel modèle sur RunComfy depuis la ligne de commande. Le CLI `runcomfy` est un seul binaire, une seule authentification, des centaines de points de terminaison de modèles — génération d’images, édition d’images, génération vidéo, image‑vers‑vidéo, synchronisation labiale, échange de visage, édition vidéo, inpainting, outpainting, extension, ControlNet, rééclairage, upscaling, entraînement LoRA et bien plus encore. Soumettez une requête, interrogez le statut, téléchargez le résultat. Cette compétence enseigne à l’agent comment installer, s’authentifier, découvrir les schémas de modèles, invoquer les modèles, diffuser / interroger / sans attente, script en mode sortie JSON, et gérer les erreurs. Elle se déclenche sur « runcomfy cli », « install runcomfy », « runcomfy login », « runcomfy run », « runcomfy whoami », « runcomfy api », ou toute requête explicite d’appeler un modèle RunComfy depuis un script ou un terminal. Les compétences sœurs (ai-image-generation, ai-video-generation, image-edit, video-edit, face-swap, lipsync, image-to-video, image-inpainting, image-outpainting, video-extend, controlnet-pose, relight) sont toutes dispatchées via ce CLI.
