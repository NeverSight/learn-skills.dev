Genera canciones completas y pistas instrumentales con ElevenLabs Music en RunComfy a través del CLI `runcomfy`. ElevenLabs Music convierte una descripción de estilo más letras estructuradas en audio estéreo de calidad de estudio a 44,1 kHz —de 5 segundos a 5 minutos— con control a nivel de secciones (Intro / Verso / Coro / Puente), voces multilingües y salida apta para uso comercial. Genera una pista de acompañamiento, una canción completa con voces, un jingle, una introducción de podcast, un bucle de juego o una base instrumental. Ejecuta `runcomfy run elevenlabs/elevenlabs/music-generation` a través del CLI local de RunComfy. Se activa con “generate music”, “make a song”, “AI music”, “background music”, “instrumental track”, “ElevenLabs Music”, “soundtrack”, “jingle”, “theme music”, “royalty‑free music”, “compose”, o cualquier solicitud explícita de generar música o una canción a partir de una descripción de texto.
