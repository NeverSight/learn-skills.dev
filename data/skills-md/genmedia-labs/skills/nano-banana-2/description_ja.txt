RunComfy上でGoogle Nano Banana 2（Geminiファミリーのフラッシュティアテキスト‑ツー‑イメージ）を使って画像を生成します——モデルの公式プロンプトパターンが同梱されているため、同じモデルへのナイーブなプロンプトよりも洗練された出力が得られます。Nano Banana 2 の強み（高速反復、画像内タイポグラフィの描画、予測可能なフレーミング、オプションでウェブ情報を活用したコンテキスト）や、解像度ティアごとの価格設定、安全性許容度ダイヤル、そして Nano Banana Pro / GPT Image 2 / Flux 2 / Seedream に切り替えるべきタイミングを文書化しています。ローカルの RunComfy CLI を通じて `runcomfy run google/nano-banana-2/text-to-image` を呼び出します。トリガーワードは「nano banana」「nano-banana-2」「nano banana 2」「google image gen」「gemini image」またはこのモデルでの生成を明示的に要求するものです。
