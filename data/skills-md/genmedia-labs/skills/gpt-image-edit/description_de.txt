Bearbeite Bilder mit OpenAI GPT Image 2 (dem `/edit`‑Endpunkt von ChatGPT Images 2.0) in RunComfy – inklusive der dokumentierten Prompt‑Muster des Modells, sodass die Fähigkeit schärfere Ergebnisse liefert als naive Prompt‑Verwendung desselben Modells. Dokumentiert die Stärken von GPT Image Edit (Sprach‑Erhaltung, mehrsprachige Textbearbeitung im Bild, Multi‑Referenz bis zu 10 Bilder, Layout‑/Typografie‑Präzision), das Schema und wann stattdessen zu Nano Banana Edit / Flux Kontext / GPT Image 2 t2i weitergeleitet werden soll. Ruft `runcomfy run openai/gpt-image-2/edit` über das lokale RunComfy‑CLI auf. Wird ausgelöst durch „gpt image edit“, „gpt-image-edit“, „chatgpt image edit“, „edit with gpt image 2“ oder jede explizite Anfrage, dieses Modell zum Bearbeiten zu verwenden.
