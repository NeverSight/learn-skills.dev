RunComfy で OpenAI GPT Image 2（ChatGPT Images 2.0 の `/edit` エンドポイント）を使用して画像を編集します — モデルの公式プロンプトパターンが同梱されているため、同じモデルに対してナイーブなプロンプトを行うよりも、より鋭い出力が得られます。GPT Image Edit の強み（保存言語、マルチリンガルな画像内テキスト編集、最大 10 枚までのマルチリファレンス、レイアウト／タイポグラフィの精度）やスキーマ、そして Nano Banana Edit／Flux Kontext／GPT Image 2 t2i に切り替えるタイミングを文書化しています。ローカルの RunComfy CLI を通じて `runcomfy run openai/gpt‑image‑2/edit` を呼び出します。「gpt image edit」「gpt-image-edit」「chatgpt image edit」「edit with gpt image 2」またはこのモデルで編集する旨の明示的な要求があるとトリガーされます。
