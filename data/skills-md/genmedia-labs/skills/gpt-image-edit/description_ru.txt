Редактировать изображения с помощью OpenAI GPT Image 2 (эндпоинт `/edit` в ChatGPT Images 2.0) в RunComfy — вместе с задокументированными шаблонами запросов модели, чтобы навык обеспечивал более точный результат, чем наивное использование той же модели. Описывает сильные стороны GPT Image Edit (сохранение языка, многоязычное редактирование текста внутри изображения, поддержка до 10 ссылочных изображений, точность макета/типографии), схему и случаи, когда следует переключаться на Nano Banana Edit / Flux Kontext / GPT Image 2 t2i. Вызывает `runcomfy run openai/gpt-image-2/edit` через локальный CLI RunComfy. Срабатывает по командам «gpt image edit», «gpt-image-edit», «chatgpt image edit», «edit with gpt image 2» или любому явному запросу редактировать с этой моделью.
