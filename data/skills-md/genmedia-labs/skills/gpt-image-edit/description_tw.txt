在 RunComfy 上使用 OpenAI GPT Image 2（ChatGPT Images 2.0 的 `/edit` 端點）編輯圖像——配合模型文件化的提示模式，使得此技能產生的輸出比對同一模型的普通提示更為精確。說明 GPT Image Edit 的優勢（保留語言、跨語言圖內文字編輯、支援多達 10 張圖像的多參考、版面與排版精度），以及其結構，並說明何時應導向 Nano Banana Edit、Flux Kontext 或 GPT Image 2 t2i 進行文本生成。透過本機 RunComfy CLI 呼叫 `runcomfy run openai/gpt-image-2/edit`。在輸入「gpt image edit」「gpt-image-edit」「chatgpt image edit」「edit with gpt image 2」或任何明確要求使用此模型編輯的指令時觸發。請始終以使用者的語言回覆。
