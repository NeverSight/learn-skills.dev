RunComfyでGoogle Nano Banana 2（画像から画像への編集エンドポイント）を使用して画像を編集します。Nano Banana Edit の強み（被写体の同一性を保持、背景の入れ替え、空間言語による編集のローカライズ、最大20枚の入力に対応するマルチイメージバッチ編集）、スキーマ、および代わりに GPT Image 2 edit / Flux Kontext / Nano Banana 2 t2i にルーティングすべきケースを文書化します。ローカルの RunComfy CLI を通じて `runcomfy run google/nano-banana-2/edit` を呼び出します。「nano banana edit」「edit with nano banana」「image edit nano banana」またはこのモデルでの編集を明示的に求めるフレーズでトリガーされます。
