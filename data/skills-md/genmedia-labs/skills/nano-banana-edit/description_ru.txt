Редактирование изображений с помощью Google Nano Banana 2 (эндпоинт редактирования изображений) на RunComfy. Описываются сильные стороны Nano Banana Edit (сохранение идентичности субъекта, замена фона, локализация правок с помощью пространственного языка, пакетное редактирование нескольких изображений до 20 входов), схема и случаи, когда следует переключаться на редактирование GPT Image 2 / Flux Kontext / Nano Banana 2 t2i. Вызывает `runcomfy run google/nano-banana-2/edit` через локальный CLI RunComfy. Срабатывает по запросам «nano banana edit», «edit with nano banana», «image edit nano banana» или любой явной просьбе отредактировать с помощью этой модели.
