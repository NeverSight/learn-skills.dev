在 RunComfy 上的 Kling 3.0 視頻生成。

Kling 3.0（亦稱 Kling V3.0）是快手科技的第三代多鏡頭視頻模型，具備原生同步音頻和跨鏡頭一致的角色身份。

此技能涵蓋全部六個 Kling 3.0 端點，涵蓋三個渲染等級（Standard、Pro、4K）以及兩種模式（文字生成視頻、圖像生成視頻）。

通過本地 RunComfy CLI 呼叫 `runcomfy run kling/kling-3.0/<tier>/<mode>`。

當出現 “kling”、 “kling 3.0”、 “kling v3”、 “kling pro”、 “kling 4k”、 “kling text to video”、 “kling image to video” 或任何明確請求使用 Kling 3.0 生成或動畫的指令時觸發。

請始終以使用者的語言回覆。
