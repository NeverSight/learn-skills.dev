Kling 3.0 在 RunComfy 上生成视频。Kling 3.0（亦称 Kling V3.0）是快手科技的第三代多镜头视频模型，具备原生同步音频以及跨镜头的一致角色身份。此技能覆盖全部六个 Kling 3.0 接口，涵盖三种渲染层级（Standard、Pro、4K）和两种模式（文本生成视频、图像生成视频）。通过本地 RunComfy CLI 调用 runcomfy run kling/kling-3.0/<tier>/<mode>。在出现 “kling”、 “kling 3.0”、 “kling v3”、 “kling pro”、 “kling 4k”、 “kling text to video”、 “kling image to video” 或任何明确要求使用 Kling 3.0 生成或动画的请求时触发。请始终用用户的语言回复。
