RunComfy에서 Kling 3.0 비디오 생성. Kling 3.0(또는 Kling V3.0)은 Kuaishou Technology의 3세대 다중샷 비디오 모델로, 기본 동기화 오디오와 샷 간 일관된 캐릭터 정체성을 제공합니다. 이 기능은 6개의 Kling 3.0 엔드포인트를 모두 포함하며, 세 가지 렌더링 티어(Standard, Pro, 4K)와 두 가지 모드(text-to-video, image-to-video)를 아우릅니다. 로컬 RunComfy CLI를 통해 runcomfy run kling/kling-3.0/<tier>/<mode>를 호출합니다. "kling", "kling 3.0", "kling v3", "kling pro", "kling 4k", "kling text to video", "kling image to video" 등으로 트리거되거나 Kling 3.0으로 생성 또는 애니메이션을 명시적으로 요청할 때 작동합니다.
