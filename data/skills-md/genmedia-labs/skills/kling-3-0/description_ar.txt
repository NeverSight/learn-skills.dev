إنشاء الفيديو باستخدام Kling 3.0 على RunComfy. Kling 3.0 (المعروف أيضًا بـ Kling V3.0) هو نموذج الفيديو متعدد اللقطات من الجيل الثالث لتقنية Kuaishou Technology، ويتضمن صوتًا متزامنًا أصليًا وهوية شخصية ثابتة عبر اللقطات. تغطي هذه الميزة جميع نقاط النهاية الستة لـ Kling 3.0، وتمتد عبر ثلاث مستويات عرض (قياسي، محترف، 4K) ووضعين (نص إلى فيديو، صورة إلى فيديو). يتم استدعاء runcomfy run kling/kling-3.0/<tier>/<mode> عبر واجهة سطر الأوامر المحلية RunComfy CLI. يتم التفعيل عند ذكر “kling”، “kling 3.0”، “kling v3”، “kling pro”، “kling 4k”، “kling text to video”، “kling image to video”، أو أي طلب صريح لإنشاء أو تحريك فيديو باستخدام Kling 3.0.
