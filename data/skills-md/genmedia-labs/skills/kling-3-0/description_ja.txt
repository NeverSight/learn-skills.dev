RunComfy上でのKling 3.0ビデオ生成。Kling 3.0（Kling V3.0とも呼ばれる）は、Kuaishou Technologyの第3世代マルチショットビデオモデルで、ネイティブの同期音声とショット間で一貫したキャラクターアイデンティティを提供します。このスキルは、3つのレンダリング階層（Standard、Pro、4K）と2つのモード（text-to-video、image-to-video）に跨る、全部で6つのKling 3.0エンドポイントをカバーします。ローカルのRunComfy CLIを通じて `runcomfy run kling/kling-3.0/<tier>/<mode>` を呼び出します。「kling」「kling 3.0」「kling v3」「kling pro」「kling 4k」「kling text to video」「kling image to video」またはKling 3.0で生成・アニメーションする明示的なリクエストでトリガーされます。
