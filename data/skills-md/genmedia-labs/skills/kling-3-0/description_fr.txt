Génération de vidéos Kling 3.0 sur RunComfy. Kling 3.0 (également appelé Kling V3.0) est le modèle vidéo multi‑shot de troisième génération de Kuaishou Technology, avec audio synchronisé natif et identité de personnage cohérente d’une séquence à l’autre. Cette compétence couvre les six points de terminaison Kling 3.0, répartis sur trois niveaux de rendu (Standard, Pro, 4K) et deux modes (texte‑vers‑vidéo, image‑vers‑vidéo). Les appels utilisent runcomfy run kling/kling-3.0/<tier>/<mode> via l’interface en ligne de commande locale RunComfy. Elle se déclenche avec « kling », « kling 3.0 », « kling v3 », « kling pro », « kling 4k », « kling text to video », « kling image to video », ou toute demande explicite de générer ou d’animer avec Kling 3.0.

Veuillez toujours répondre dans la langue de l'utilisateur.
