RunComfy の `runcomfy` CLI を使用したビデオフレーム間の領域編集 ― 複数フレームにわたって現れるオブジェクトの削除、ワイヤーやウォーターマークのクリーンアップ、動きに合わせた領域の置き換え。Wan 2‑7 の edit‑video（デフォルト、空間言語によるプロンプト駆動の領域編集）、Lucy Edit Restyle（同一性を保つ領域認識リスタイル）、Seedream 4‑0 の edit‑sequential（クリップをフレームスタックとして扱う場合）にルーティング。変更が文章ベースか、同一性ロックか、フレームごとの静止インペイントをビデオに連結する必要があるかに応じて最適なルートを選択。以下の語句でトリガーされます: 「video inpaint」「video inpainting」「remove from video」「mask region in video」「clean up video」「remove object from clip」「video patch」「frame-by-frame edit」「remove watermark from video」「remove passing person」またはビデオフレーム全体にわたる領域編集の明示的な要求。
