Редактировать изображения с помощью Flux 1 Kontext Pro (точной модели локального редактирования изображений от Black Forest Labs) в RunComfy — в комплекте с задокументированными шаблонами подсказок модели, чтобы навык давал более чёткий результат, чем наивное применение подсказок к той же модели. Описывает сильные стороны Flux Kontext (точные локальные правки по единственному референсу, сильный контроль подсказок, последовательные выводы высокого качества), схему (одно изображение + подсказка) и когда следует переключаться на Nano Banana Edit / GPT Image 2 Edit / Flux 2 Klein. Вызывает `runcomfy run blackforestlabs/flux-1-kontext/pro/edit` через локальный CLI RunComfy. Срабатывает на запросы «flux kontext», «flux‑kontext», «flux 1 kontext», «kontext», «BFL kontext» или любой явный запрос на редактирование этой моделью.
