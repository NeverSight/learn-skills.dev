RunComfy上的 Codex 宠物生成器。 从单张参考图像生成兼容 Codex 的 Codex 宠物 spritesheet.webp + pet.json，放入 `${CODEX_HOME:-$HOME/.codex}/pets/<name>/`，Codex 会将其识别为自定义 Codex 宠物，与你的 8 个内置宠物并列。 此技能生成 Codex 所需的精确宠物图集（1536x1872 PNG/WebP，8 列 × 9 行，单元格 192×208，9 种动画状态——idle、running‑right、running‑left、waving、jumping、failed、waiting、running、review）。 通过本地 RunComfy CLI 使用 `runcomfy run openai/gpt-image-2/edit` 调用 OpenAI GPT Image 2 edit 一次，生成标准的 Codex 宠物姿势，然后使用 ImageMagick 微变换以程序化方式组装全部 9 行动画——无需 Codex Pro、无需 `$imagegen`、无需 OPENAI_API_KEY，仅需 RUNCOMFY_TOKEN。 当出现 “codex pet”、 “create codex pet”、 “make codex pet”、 “hatch codex pet”、 “/hatch image”、 “desktop pet codex”、 “codex pets”、 “spritesheet.webp” 或任何明确请求为 OpenAI Codex 构建自定义宠物的指令时触发。
