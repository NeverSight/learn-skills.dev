Générateur de Codex Pet sur RunComfy. Créez un spritesheet.webp compatible Codex Pet + pet.json à partir d’une image de référence unique, déposez‑le dans `${CODEX_HOME:-$HOME/.codex}/pets/<name>/` et Codex le récupère comme un Codex Pet personnalisé à côté des 8 intégrés. Cette compétence produit exactement l’atlas Codex Pet que Codex attend (PNG/WebP 1536×1872, 8 colonnes × 9 rangées, cellules de 192×208, 9 états d’animation — idle, running‑right, running‑left, waving, jumping, failed, waiting, running, review). Elle appelle OpenAI GPT Image 2 edit UNE FOIS via le CLI local RunComfy en tant que `runcomfy run openai/gpt-image-2/edit` pour générer une pose canonique de Codex Pet, puis assemble les 9 rangées d’animation de façon programmatique avec des micro‑transformations ImageMagick — pas de Codex Pro, pas de `$imagegen`, pas de OPENAI_API_KEY requis, seulement RUNCOMFY_TOKEN.
