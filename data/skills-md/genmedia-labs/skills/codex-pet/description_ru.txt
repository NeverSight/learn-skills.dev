Генератор Codex Pet на RunComfy. Создаёт совместимый с Codex спрайтшит Codex Pet (spritesheet.webp) и файл pet.json из одного референсного изображения, помещайте их в `${CODEX_HOME:-$HOME/.codex}/pets/<name>/`, и Codex подхватит их как пользовательского Codex Pet рядом с 8 встроенными. Эта возможность генерирует точный атлас Codex Pet, который ожидает Codex (1536×1872 PNG/WebP, 8 колонок × 9 строк, ячейки 192×208, 9 состояний анимации — idle, running-right, running-left, waving, jumping, failed, waiting, running, review). Один раз вызывается OpenAI GPT Image 2 edit через локальный CLI RunComfy командой `runcomfy run openai/gpt-image-2/edit` для получения канонической позы Codex Pet, после чего программно собираются все 9 строк анимации с помощью микротрансформаций ImageMagick — без Codex Pro, без `$imagegen`, без требования OPENAI_API_KEY, нужен только RUNCOMFY_TOKEN. Срабатывает на команды «codex pet», «create codex pet», «make codex pet», «hatch codex pet», «/hatch image», «desktop pet codex», «codex pets», «spritesheet.webp» или любой явный запрос создать кастомного питомца для OpenAI Codex.
