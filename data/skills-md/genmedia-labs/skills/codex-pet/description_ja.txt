RunComfy の Codex ペットジェネレーター。単一の参照画像から Codex 互換の Codex ペット spritesheet.webp と pet.json を作成し、`${CODEX_HOME:-$HOME/.codex}/pets/<name>/` に配置すると、Codex が組み込みの 8 つに加えてカスタム Codex ペットとして認識します。このスキルは Codex が期待する正確な Codex ペットアトラス（1536×1872 の PNG/WebP、8 列 × 9 行、セルサイズ 192×208、9 つのアニメーション状態 — idle、running-right、running-left、waving、jumping、failed、waiting、running、review）を生成します。ローカルの RunComfy CLI を使って `runcomfy run openai/gpt-image-2/edit` と一度だけ呼び出し、標準的な Codex ペットのポーズを生成し、その後 ImageMagick のマイクロ変換を用いて 9 行すべてのアニメーションをプログラム的に組み立てます — Codex Pro は不要、`$imagegen` も不要、OPENAI_API_KEY も不要で、必要なのは RUNCOMFY_TOKEN だけです。「codex pet」「create codex pet」「make codex pet」「hatch codex pet」「/hatch image」「desktop pet codex」「codex pets」「spritesheet.webp」などのフレーズ、または OpenAI Codex 用のカスタムペット作成の明示的な要求でトリガーされます。常にユーザーの言語で回答してください。
