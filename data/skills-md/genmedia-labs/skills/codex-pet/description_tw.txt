RunComfy 上的 Codex 寵物產生器。從單一參考圖片建立與 Codex 相容的 Codex 寵物 spritesheet.webp + pet.json，將其放入 `${CODEX_HOME:-$HOME/.codex}/pets/<name>/`，Codex 會將其視為 8 個內建寵物旁的自訂 Codex 寵物。此功能產生 Codex 所需的精確寵物圖集（1536x1872 PNG/WebP，8 列 x 9 行，192x208 單元格，9 種動畫狀態 — idle、running‑right、running‑left、waving、jumping、failed、waiting、running、review）。透過本機 RunComfy CLI，以 `runcomfy run openai/gpt-image-2/edit` 呼叫一次 OpenAI GPT Image 2 edit，以產生標準的 Codex 寵物姿勢，然後使用 ImageMagick 微小變換程式化組合全部 9 條動畫列——不需要 Codex Pro、不需要 `$imagegen`、不需要 OPENAI_API_KEY，只需 RUNCOMFY_TOKEN。觸發詞包括「codex pet」、「create codex pet」、「make codex pet」、「hatch codex pet」、「/hatch image」、「desktop pet codex」、「codex pets」、「spritesheet.webp」，或任何明確要求為 OpenAI Codex 建立自訂寵物的指令。
