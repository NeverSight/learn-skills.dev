Destila el estilo de prosa de ficción de un autor a partir de muestras de novelas proporcionadas por el usuario en un perfil de estilo local reutilizable para la escritura de novelas posteriores. Úselo cuando el usuario solicite destilar, falsificar, extraer, analizar o crear una habilidad/perfil de estilo de escritura a partir de una novela, corpus de autor, capítulo o muestra de ficción.
