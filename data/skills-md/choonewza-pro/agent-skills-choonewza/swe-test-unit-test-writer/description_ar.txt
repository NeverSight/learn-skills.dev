يرشد وكيلات الذكاء الاصطناعي إلى كتابة اختبارات وحدة TypeScript عالية الجودة باستخدام Jest أو Vitest. يغطي نمط Arrange‑Act‑Assert، مبادئ FIRST، تصميم السيناريوهات (سعيد/سلبي/خطأ/حدي)، استراتيجيات المحاكاة، قواعد التسمية، والأنماط المضادة. يُستَخدم عندما يطلب المستخدم “write unit tests”، “เขียน test”، “เพิ่ม test”، “สร้าง test file”، أو عندما يحتاج وكيل إلى إنشاء ملفات .test.ts أو .spec.ts. يركز على اختبارات الوحدة فقط — بالنسبة لاختبارات التكامل، استخدم مهارة اختبار تكامل مخصصة.
