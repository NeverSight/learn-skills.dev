Помогает AI‑агентам писать качественные модульные тесты на TypeScript с использованием Jest или Vitest. Охватывает паттерн Arrange-Act-Assert, принципы FIRST, проектирование сценариев (позитивные/негативные/ошибочные/пределы), стратегии мокирования, правила именования и антипаттерны. Использовать, когда пользователь просит «write unit tests», «เขียน test», «เพิ่ม test», «สร้าง test file» или когда агенту нужно создать файлы .test.ts или .spec.ts. Сосредоточено только на модульных тестах — для интеграционных тестов используйте отдельный навык интеграционного тестирования. Пожалуйста, всегда отвечайте на языке пользователя.
