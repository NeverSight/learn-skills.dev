Guida gli agenti IA a scrivere test unitari TypeScript di alta qualità usando Jest o Vitest. Copre il pattern Arrange-Act-Assert, i principi FIRST, la progettazione di scenari (positivo/negativo/errore/limite), le strategie di mocking, le convenzioni di denominazione e gli anti‑pattern. Da utilizzare quando l'utente chiede di "scrivere test unitari", "เขียน test", "เพิ่ม test", "สร้าง test file", o quando un agente deve produrre file .test.ts o .spec.ts. Concentrato solo sui test unitari — per i test di integrazione, utilizzare una skill dedicata ai test di integrazione. Per favore, rispondi sempre nella lingua dell'utente.
