Leitet KI-Agenten an, hochwertige TypeScript‑Unit‑Tests mit Jest oder Vitest zu schreiben. Behandelt das Arrange‑Act‑Assert‑Muster, die FIRST‑Prinzipien, das Szenariodesign (happy/negative/error/boundary), Mocking‑Strategien, Benennungskonventionen und Anti‑Pattern. Verwenden, wenn der Benutzer nach "write unit tests", "เขียน test", "เพิ่ม test", "สร้าง test file" fragt oder wenn ein Agent .test.ts‑ oder .spec.ts‑Dateien erzeugen muss. Fokussiert ausschließlich auf Unit‑Tests — für Integrationstests sollte ein spezielles Integrationstest‑Skill verwendet werden. Bitte immer in der Sprache des Benutzers antworten.
