Guide les agents IA pour écrire des tests unitaires TypeScript de haute qualité en utilisant Jest ou Vitest. Couvre le modèle Arrange‑Act‑Assert, les principes FIRST, la conception de scénarios (heureux, négatif, erreur, limite), les stratégies de moquage, les conventions de nommage et les anti‑patterns. À utiliser lorsque l’utilisateur demande « write unit tests », « เขียน test », « เพิ่ม test », « สร้าง test file », ou lorsqu’un agent doit produire des fichiers *.test.ts* ou *.spec.ts*. Focalisé uniquement sur les tests unitaires — pour les tests d’intégration, utilisez une compétence dédiée aux tests d’intégration.
