Cubre el patrón Arrange-Act-Assert, los principios FIRST, el diseño de escenarios (feliz/negativo/error/limite), estrategias de simulación (mocking), convenciones de nombres y anti‑patrones. Úselo cuando el usuario solicite "escribir pruebas unitarias", "เขียน test", "เพิ่ม test", "สร้าง test file", o cuando un agente necesite producir archivos .test.ts o .spec.ts. Enfocado únicamente en pruebas unitarias; para pruebas de integración, utilice una habilidad dedicada a pruebas de integración.
