يرشد عوامل الذكاء الاصطناعي إلى كتابة اختبارات تكامل عالية الجودة بلغة TypeScript باستخدام Jest أو Vitest مع قواعد بيانات حقيقية (Prisma، Drizzle، TypeORM)، ونقاط نهاية HTTP (Supertest، Fastify، Next.js App Router، NestJS)، Testcontainers، وMSW للخدمات الخارجية. يغطي الاختبار الاجتماعي، دورات حياة قاعدة البيانات (truncate vs rollback)، توافر العاملين المتزامن، factory fixtures، والنظافة عند إغلاق الاختبارات. يُستخدم عندما يُطلب “write integration tests”، “เขียน integration test”، “เทสต์ API กับ DB”، “สร้าง integration test”، أو لإنتاج ملفات .integration.test.ts.
