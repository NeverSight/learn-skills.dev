Руководит AI‑агентов в написании высококачественных интеграционных тестов на TypeScript с использованием Jest или Vitest и реальных баз данных (Prisma, Drizzle, TypeORM), HTTP‑эндпоинтов (Supertest, Fastify, Next.js App Router, NestJS), Testcontainers и MSW для внешних сервисов. Охватывает социальное тестирование, жизненные циклы базы данных (truncate vs rollback), конкурентность воркеров, фабричные фикстуры и чистоту завершения тестов. Использовать, когда просят «write integration tests», «เขียน integration test», «เทสต์ API กับ DB», «สร้าง integration test» или требуется создать файлы .integration.test.ts.
