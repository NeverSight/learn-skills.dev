Guide les agents IA pour écrire des tests d’intégration TypeScript de haute qualité en utilisant Jest ou Vitest avec de vraies bases de données (Prisma, Drizzle, TypeORM), des points de terminaison HTTP (Supertest, Fastify, Next.js App Router, NestJS), Testcontainers et MSW pour les services externes. Couvre les tests sociables, les cycles de vie des bases de données (troncature vs rollback), la concurrence des workers, les fixtures de fabrique et l’hygiène du teardown. À utiliser lorsqu’on demande « write integration tests », « เขียน integration test », « เทสต์ API กับ DB », « สร้าง integration test », ou pour produire des fichiers *.integration.test.ts.
