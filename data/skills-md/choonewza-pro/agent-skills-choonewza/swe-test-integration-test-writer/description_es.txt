Guía a los agentes de IA para escribir pruebas de integración de TypeScript de alta calidad usando Jest o Vitest con bases de datos reales (Prisma, Drizzle, TypeORM), endpoints HTTP (Supertest, Fastify, Next.js App Router, NestJS), Testcontainers y MSW para servicios externos. Cubre pruebas sociables, ciclos de vida de la base de datos (truncar vs rollback), concurrencia de workers, fixtures de fábrica y higiene de desmontaje. Úsalo cuando se solicite “escribir pruebas de integración”, “เขียน integration test”, “เทสต์ API กับ DB”, “สร้าง integration test”, o para producir archivos *.integration.test.ts.
