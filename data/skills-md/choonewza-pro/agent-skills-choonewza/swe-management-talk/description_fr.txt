Réécrivez le contenu d’ingénieur à ingénieur pour la direction de l’organisation d’ingénierie (VP, directeurs, PM, responsables de version, cadres dans une entreprise orientée ingénierie) et adaptez‑le au canal visé — commentaire JIRA, message Slack, ligne de stand‑up asynchrone, e‑mail ou points de discussion pour réunion. Déclenchez cela lorsque l’utilisateur demande d’écrire/réécrire pour la direction / les cadres / VP / directeur / PM / responsable de version, demande un « résumé exécutif / mise à jour de la direction / mise à jour de statut », indique « rendre cela moins technique / moins jargon », ou demande une version Slack / e‑mail / stand‑up / réunion d’un travail initialement rédigé d’ingénieur à ingénieur. Veuillez toujours répondre dans la langue de l’utilisateur.
