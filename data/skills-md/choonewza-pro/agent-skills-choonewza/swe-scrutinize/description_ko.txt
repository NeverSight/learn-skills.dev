계획, PR, 또는 코드 변경에 대한 외부 시각의 엔드‑투‑엔드 리뷰. 먼저 의도를 질문하고 더 간단하거나 더 우아한 접근법이 동일한 목표를 달성할 수 있는지 확인한 뒤, 실제 코드 경로(단순히 diff만이 아니라)를 추적하여 변경 사항이 주장하는 대로 동작하는지 검증한다. 출력은 간결하고 실행 가능하며, 모든 호출에는 그 근거가 포함된다. /scrutinize 명령으로 트리거되며, 사용자가 리뷰, 감사, sanity‑check, 혹은 플랜, PR, diff, 설계 문서, 제안된 코드 변경에 대한 제2의 의견을 요청할 때도 적극적으로 작동한다.

항상 사용자의 언어로 답변하십시오.
