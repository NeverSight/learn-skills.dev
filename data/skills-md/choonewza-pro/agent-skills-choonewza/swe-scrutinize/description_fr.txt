Examen de bout en bout d’un plan, d’une PR ou d’un changement de code sous l’angle d’un extérieur. On commence par questionner l’intention et se demander si une approche plus simple ou plus élégante permettrait d’atteindre le même objectif, puis on suit le chemin réel du code (pas seulement le diff) pour vérifier que le changement fait ce qu’il promet. Le résultat est concis, exploitable, et chaque appel comporte sa justification. Déclenchement sur /scrutinize et de façon proactive chaque fois que l’utilisateur demande de réviser, auditer, vérifier la cohérence ou obtenir un second avis sur un plan, une PR, un diff, un document de conception ou un changement de code proposé.

Veuillez toujours répondre dans la langue de l’utilisateur.
