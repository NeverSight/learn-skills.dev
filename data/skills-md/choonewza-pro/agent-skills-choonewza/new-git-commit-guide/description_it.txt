Usa questa funzionalità quando effettui commit di codice, scrivi messaggi di commit o rivedi la cronologia di Git in questo progetto Next.js. Si attiva su: “commit this”, “write a commit message”, “what should my commit say”, “git commit” o qualsiasi richiesta di aggiungere e fare commit delle modifiche. Fornisce il formato di commit convenzionale specifico del progetto, le convenzioni di commenti in lingua tailandese e le regole di ambito corrispondenti alla struttura di questo codebase.

Per favore rispondi sempre nella lingua dell'utente.
