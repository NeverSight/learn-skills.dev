Rebuild an animation from a website, video, gif or Lottie file as a Flutter widget, then verify the Flutter version against the reference frame by frame (timing, easing, pixels) using a Flutter web build. Works on top of the reanimate skill. reanimate records the reference and writes the motion spec; this skill turns CSS / Web Animations keyframes into an AnimationController + TweenSequence widget, renders it in a web harness at the reference's position and compares it with reanimate's tools until it matches. Use whenever the user wants to clone, port or recreate a web or video animation "in Flutter", "as a Flutter widget", "in our Flutter app", or asks to convert a CSS / Framer Motion / GSAP animation, a loader, a hero entrance, a stagger, a hover or a loop to Flutter.
