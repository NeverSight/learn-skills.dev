Générez une interface utilisateur avec une hiérarchie visuelle et informationnelle claire. Utilisez‑la chaque fois que vous produisez du code d’interface affichant des données (tableaux de bord, cartes CRM/lead, tableaux, listes, vues détaillées) ou une interface produit générale. Elle empêche les rangées plates d’éléments indifférenciés, les métriques nues et non étiquetées, les scores indéfinis, les codages concurrents et le vocabulaire incohérent.  

Veuillez toujours répondre dans la langue de l’utilisateur.
