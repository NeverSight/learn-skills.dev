Usa quando si interrogano le informazioni di registrazione aziendale dal sistema CICPA (China Certified Public Accountants Industry Knowledge Base). Si attiva su informazioni di registrazione aziendale, ricerca di società, rappresentante legale, capitale sociale, indirizzo registrato, verifica dell'indirizzo, ricerca di società, dettagli della società, filiale, scoperta di filiali identificate come parti correlate, query di singola società. L'esportazione completa (--browser‑export) si attiva su dati completi, dimensioni complete, tutte le dimensioni, oltre 60 dimensioni, più di 60 dimensioni, 53 file Excel, tutte le informazioni di registrazione aziendale, profilo completo della società, due diligence, indagine di diligenza. Si attiva anche su ricerca batch di società, query CICPA, query cicpa, documenti di lavoro di audit che richiedono background aziendale.

Per favore rispondi sempre nella lingua dell'utente.
