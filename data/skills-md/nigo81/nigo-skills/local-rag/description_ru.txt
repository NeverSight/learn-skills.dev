Локальная векторная база знаний, поддерживающая управление документами (docx/doc/pdf/md) по проектам и семантический поиск. По умолчанию использует бесплатный основанный на кремнии Flow API, не требующий установки модели. Поддерживает изоляцию многопроектных сред, специализированную нарезку китайских нормативных документов и двухэтапный процесс поиска, комбинирующий эмбеддинги и переранжирование. Триггерные слова: база знаний, векторный поиск, RAG, поиск политик, загрузка документов, семантический поиск, локальный RAG, поиск политик, просмотр пунктов, поиск документов, поиск внутри документов, семантическое сопоставление. Даже если пользователь просто скажет «Помогите найти положения о XX в этих файлах» или «Сравните различия между двумя политиками», эту функцию следует использовать.
