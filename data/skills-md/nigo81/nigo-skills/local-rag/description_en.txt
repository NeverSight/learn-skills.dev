Local vector knowledge base that supports project-based document management (docx/doc/pdf/md) and semantic search. By default it uses a free silicon‑based API, requiring no model installation to use. It supports multi‑project isolation, dedicated slicing for Chinese policy documents, and a two‑stage retrieval with Embedding + Rerank. Trigger keywords: knowledge base, vector retrieval, RAG, policy search, document ingestion, semantic search, local rag, policy lookup, clause check, document retrieval, search within documents, semantic matching. Even if a user simply says “help me find the regulations about XX in these files” or “compare the differences between two policies,” this skill should be used.
