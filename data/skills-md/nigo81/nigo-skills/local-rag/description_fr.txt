Base de connaissances vectorielle locale qui prend en charge la gestion de documents par projet (docx/doc/pdf/md) et la recherche sémantique. Par défaut, elle utilise une API gratuite basée sur le silicium, ne nécessitant aucune installation de modèle pour être utilisée. Elle supporte l’isolation multi‑projet, le découpage dédié pour les documents de politique chinois, et une récupération en deux étapes avec Embedding + Rerank. Mots‑clés déclencheurs : base de connaissances, récupération vectorielle, RAG, recherche de politiques, ingestion de documents, recherche sémantique, RAG local, recherche de politiques, vérification de clause, récupération de documents, recherche dans les documents, correspondance sémantique. Même si un utilisateur dit simplement « aidez‑moi à trouver les réglementations concernant XX dans ces fichiers » ou « comparez les différences entre deux politiques », cette compétence doit être utilisée.

Veuillez toujours répondre dans la langue de l'utilisateur.
