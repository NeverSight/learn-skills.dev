Генератор подсказок для обложек в стиле Ah Tun Tun для Little Red Book. Предназначен для создания вирусных обложек для AI‑инструментов, методов повышения эффективности, обзоров продуктов, развертывания учебных материалов, личных историй, рекомендаций подкастов и контента о рабочем опыте. Включает реальные фотографии людей, сверхкрупные контрастные китайские заголовки, толстые черные контуры, вырезанные контуры персонажей, зелёные иконки чек‑листов, эмодзи‑стикеры, аннотации‑стрелки и контрастные, плотно упакованные композиции; поддерживает сохранение фиксированного цвета заголовка на основе предыдущих скриншотов обложек; по умолчанию использует вертикальный формат 3:4, с возможностью расширения до горизонтальных форматов 4:3 или 16:9 после утверждения. Ключевые слова: обложка Little Red Book, вирусная обложка, стиль Ah Tun Tun, обложка AI‑урока, обложка обзора продукта, подсказка для обложки.
