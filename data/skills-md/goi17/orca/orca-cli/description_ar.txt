قم بتشغيل أشجار العمل التي تديرها Orca، وسياقات المجلدات، والمحطات الطرفية، واتفاقيات إعادة الشراء، والأتمتة، والتحف، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المضمن من خلال واجهة سطر الأوامر "orca". يُستخدم عندما يقول المستخدم "$orca-cli"، أو "Orca Worktree"، أو "فرع العمل"، أو "نشر المخطوطة/كلود في شجرة عمل"، أو "قراءة/انتظار/إرسال محطة Orca"، أو "تسليم" / "تسليم" / "إعطاء هذا إلى وكيل آخر"، أو "متصفح Orca"، أو "عناصر Orca"، أو "مشاركة المهارات". قم بتفضيله على شجرة عمل git الأولية، أو PTYs المخصصة، أو استخدام الكمبيوتر عندما يتعلق الأمر بحالة Orca. استخدم استخدام الكمبيوتر فقط للنوافذ الخارجية أو واجهة مستخدم سطح المكتب التي تحتاج إلى تحكم على مستوى نظام التشغيل، وPlaywright أو CDP للصفحات الخارجية.
