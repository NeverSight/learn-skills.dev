Opera los worktrees gestionados por Orca, los contextos de carpetas, terminales, repositorios, automatizaciones, artefactos, intercambio de habilidades, comentarios de worktree y el navegador integrado de Orca a través del CLI `orca`. Úsalo cuando el usuario diga "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Prefiérelo sobre un worktree git bruto, PTYs ad hoc o Computer Use cuando el estado de Orca esté involucrado. Usa Computer Use solo para ventanas externas o UI de escritorio que necesiten control a nivel de SO, y Playwright o CDP para páginas externas.
