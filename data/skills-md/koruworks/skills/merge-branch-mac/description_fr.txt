Fusionnez une branche de travail Windows‑first (et Android) dans la branche mac, en vous assurant que chaque modification soit adaptée à macOS ou consignée comme n’étant pas encore réalisée. Utilisez ceci lorsque l’utilisateur demande de fusionner dans mac, fusionnez la branche mac, rattrapez mac ou transférez le travail Windows vers mac. Respectez pleinement la porte d’examen de merge‑branch, puis ajoutez une passe de traduction mac dont le verdict pour chaque modification — traduite, nécessite du travail mac ou différée — est enregistré dans le suivi de mise à jour des plateformes du projet (CATCHUP.md sauf si le projet le conserve ailleurs), afin qu’aucun comportement Windows ne manque silencieusement sur un Mac.

Veuillez toujours répondre dans la langue de l’utilisateur.
