Слейте ветку с работой, ориентированной в первую очередь на Windows (и Android), в ветку mac, убедившись, что каждое изменение адаптировано под macOS или зафиксировано как ещё не реализованное. Делайте это, когда пользователь просит выполнить слияние в mac, сливайте ветку mac, доводите mac до актуального состояния или переносите работу, сделанную для Windows, в mac. Полностью соблюдайте проверочный шлюз merge‑branch, затем добавьте проход мак‑трансляции, чей вывод для каждого изменения — «переведено», «требует работы для mac» или «отложено» — фиксируется в трекере отставания платформ проекта (CATCHUP.md, если только проект не хранит его в другом месте), чтобы поведение Windows не исчезло без следа на Mac.
