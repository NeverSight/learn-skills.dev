Merge a branch of Windows-first (and Android) work into the mac branch, making sure every change translates to macOS or is written down as not yet doing so. Use when the user asks to merge into mac, merge the mac branch, catch mac up, or bring Windows work over to mac. Follows merge-branch's review gate in full, then adds a mac-translation pass whose verdict for each change — translated, needs mac work, or deferred — is recorded in the project's platform catch-up tracker (CATCHUP.md unless the project keeps it elsewhere), so no Windows behaviour goes silently missing on a Mac.
