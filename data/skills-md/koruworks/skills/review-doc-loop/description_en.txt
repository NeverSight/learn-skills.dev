Run the reviewer's half of the document review loop without the user relaying each round — review the current <DOC>.revN.md into <DOC>.revN.notes.md, commit the closed round, wait for the author's rev(N+1), and repeat until the document is ready for final, a round cap is hit, or only the user can move it forward. Use after rev1 exists, when the user invokes /review-doc-loop <feature> [max-rounds] in a fresh session that did not write the document. Its counterpart is answer-notes-loop in the author's session.
