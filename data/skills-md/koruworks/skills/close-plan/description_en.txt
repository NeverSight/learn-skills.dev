Close out a finished <DOC>.final.md — fold what landed into the docs that already exist, carry what is still owed into <DOC>-V2.rev1.md, and delete the planning artifacts the tree no longer needs. Use when the user invokes /close-plan <feature>, or asks to clean up or retire a small feature's docs after execute-plan or build-feature has finished. Reviews ACCEPTANCE.md check by check before calling anything landed, then triages every phase as landed, pending, deferred or dropped. The smaller sibling of close-roadmap — works for any stem (PLAN, TECHNICAL, …); a plan usually does not earn its own folder of permanent documentation, so the default is to add a paragraph to a page that exists rather than create a new one.
