Utilisez‑le après l’existence de rev1, lorsque l’utilisateur invoque /answer‑notes‑loop <feature> [max‑rounds] dans la session qui a rédigé le plan, la feuille de route, le document technique ou d’expérience. Son pendant est review‑doc‑loop dans une nouvelle session.

Veuillez toujours répondre dans la langue de l’utilisateur.
