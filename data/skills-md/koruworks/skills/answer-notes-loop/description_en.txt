Run the author's half of the document review loop without the user relaying each round — wait for the reviewer's <DOC>.revN.notes.md, answer it with <DOC>.rev(N+1).md, and repeat until the reviewer says ready for final, a round cap is hit, or only the user can move it forward. Use after rev1 exists, when the user invokes /answer-notes-loop <feature> [max-rounds] in the session that authored the plan, roadmap, technical or experience document. Its counterpart is review-doc-loop in a fresh session.
