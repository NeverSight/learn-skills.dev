Publica la siguiente versión estable mediante el propio proceso estable del proyecto: verifica que la rama principal esté verde, elige la versión y escribe sus notas (a través de write-release-notes), publica manualmente las plataformas que aún requieran hacerlo, luego empuja la etiqueta de versión una vez que el usuario tenga las notas, vigila la compilación y comprueba qué se publicó y cuál lanzamiento está marcado como el más reciente. Úsalo cuando el usuario solicite lanzar, cortar, enviar o publicar una versión estable, empujar una etiqueta de versión, o invoque /release-stable. Se detiene ante una rama principal roja o una instrucción faltante en lugar de adivinar; nunca mueve, elimina ni fuerza el empuje de una etiqueta de versión.
