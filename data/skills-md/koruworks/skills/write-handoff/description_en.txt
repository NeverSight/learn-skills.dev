Write docs/<feature>/HANDOFF.md — the briefing a fresh agent session needs to pick up unfinished work with none of the conversation, covering where the branch and checkout are, what is pushed, what to merge first, what was built and which documents are authoritative, where to resume, and the traps that cost this session time. Use when an implementing run (execute-plan, execute-roadmap, build-feature) stops with work still owed, when context is about to run out, or when the user invokes /write-handoff <feature> or asks to hand work to another agent or session. For handing finished work to a person to test and accept, use write-acceptance instead.
