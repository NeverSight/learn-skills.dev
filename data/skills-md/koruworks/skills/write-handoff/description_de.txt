Write docs/<feature>/HANDOFF.md — das Briefing, das eine neue Agentensitzung benötigt, um unbeendete Arbeit ohne das vorherige Gespräch aufzunehmen, inklusive wo sich Branch und Checkout befinden, was gepusht wurde, was zuerst gemerged werden soll, was gebaut wurde und welche Dokumente maßgeblich sind, wo fortgesetzt wird und welche Fallen dieser Sitzung Zeit kosten. Verwenden Sie es, wenn ein Implementierungslauf (execute-plan, execute-roadmap, build-feature) mit noch ausstehender Arbeit stoppt, wenn der Kontext fast erschöpft ist oder wenn der Benutzer /write-handoff <feature> aufruft oder darum bittet, Arbeit an einen anderen Agenten oder eine andere Sitzung zu übergeben. Für das Übergeben fertiggestellter Arbeit an eine Person zum Testen und Akzeptieren, verwenden Sie stattdessen write-acceptance.
