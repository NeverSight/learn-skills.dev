Corrigez les bugs et apportez de petites améliorations tout en laissant la base de code meilleure qu'elle ne l'était. Utilisez cela lorsque l'utilisateur demande de corriger un bug, de nettoyer quelque chose ou d'apporter une amélioration mineure. Chaque correction explique la cause racine pour le relecteur, justifie la solution choisie par rapport aux alternatives, recherche la simplification que le bug indique — et demande avant toute décision produit, tout changement d’envergure ou toute modification persistante de schéma/format.

Veuillez toujours répondre dans la langue de l'utilisateur.
