Execute a signed-off PLAN.final.md for a single feature yourself, phase by phase, on the current branch — you are the engineer, not a delivery lead. Use when the user invokes /execute-plan, or asks to implement, build or continue an approved plan that is small enough for one person, e.g. "/execute-plan spell-check", "/execute-plan spell-check p1-p3", "build the rest of the plan while I sleep". Resolves the requested phases against the final doc, builds each as its own verified increment, runs its verification before the next begins, and commits each landed phase without waiting for approval. Questions that need the user are recorded with a recommendation instead of blocking. For a roadmap large enough to want parallel sub-agents, use execute-roadmap instead.
