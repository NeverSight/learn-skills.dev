Pubblica la prossima build nightly utilizzando il processo nightly proprio del progetto — controlla che il ramo principale sia verde e che il tag nightly sia aggiornato, scrivi il file di note unico di cui ha bisogno la build (tramite write-release-notes), effettua il commit, sposta e push il tag una volta che l'utente ha le note, quindi osserva la build e verifica cosa ha pubblicato. Usalo quando l'utente chiede di rilasciare, tagliare, pubblicare o aggiornare il nightly, per spostare o aggiornare il tag nightly, o invoca /release-nightly. Si ferma se il ramo principale è rosso o manca un'istruzione invece di indovinare; non forzare mai il push di nulla tranne il tag nightly.
