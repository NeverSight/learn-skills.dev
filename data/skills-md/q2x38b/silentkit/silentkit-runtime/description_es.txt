Referencia de ingeniería para la capa de tiempo de ejecución/cargador de un cliente fantasma JVM: agentes Java e Instrumentación, cargadores de clases personalizados, carga de clases a partir de bytes en memoria, un patrón de recarga en caliente con cargador hijo desechable, inyección de recursos/activos, desmontaje limpio y soporte multi‑versión con una única base de código (una fachada Compat con MethodHandles en caché + una constante de versión en tiempo de ejecución). Sólo mecanismos estándar de JVM — esta habilidad excluye deliberadamente cualquier material de evasión de detección/anti‑forense. Neutral respecto a marcas y agnóstico de frameworks.
