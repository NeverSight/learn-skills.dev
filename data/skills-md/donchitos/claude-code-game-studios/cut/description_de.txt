Schlägt Kürzungen und eine Liste mit Verbesserungen vor, um das Spiel auf der Grundlage des Briefings und dessen, was bereits entwickelt wurde, fertigzustellen; die Person wählt jede Kürzung aus. Ein Spiel, das verkauft werden soll, erhält auch ein Veröffentlichungsdatum und einen Funktionsstopp. Anwenden, wenn gefragt wird, was gestrichen werden soll, wie das Spiel fertiggestellt oder ausgeliefert werden soll, oder wenn eine Liste mit Verbesserungen gewünscht wird.
