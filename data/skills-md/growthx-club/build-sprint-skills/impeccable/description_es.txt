Utilízalo cuando el usuario quiera diseñar, rediseñar, dar forma, criticar, auditar, pulir, clarificar, destilar, endurecer, optimizar, adaptar, animar, colorear, extraer o, en general, mejorar una interfaz frontend. Cubre sitios web, páginas de aterrizaje, tableros, UI de producto, shells de aplicaciones, componentes, formularios, ajustes, incorporación y estados vacíos. Gestiona revisión de UX, jerarquía visual, arquitectura de la información, carga cognitiva, accesibilidad, rendimiento, comportamiento responsivo, tematización, anti‑patrones, tipografía, fuentes, espaciado, disposición, alineación, color, movimiento, micro‑interacciones, texto UX, estados de error, casos límite, i18n y sistemas de diseño o tokens reutilizables. También se emplea para diseños aburridos que necesitan volverse más audaces o agradables, diseños ruidosos que deben volverse más sutiles, iteración en vivo en el navegador de elementos UI, o efectos visuales ambiciosos que deben sentirse técnicamente extraordinarios. No es para tareas exclusivamente de backend o sin interfaz de usuario.
