À utiliser lorsque l'utilisateur souhaite concevoir, redessiner, façonner, critiquer, auditer, polir, clarifier, distiller, durcir, optimiser, adapter, animer, coloriser, extraire ou améliorer autrement une interface frontend. Couvre les sites web, les pages d'atterrissage, les tableaux de bord, les UI produit, les coquilles d'application, les composants, les formulaires, les paramètres, l’onboarding et les états vides. Gère la revue UX, la hiérarchie visuelle, l’architecture de l’information, la charge cognitive, l’accessibilité, la performance, le comportement réactif, la thématisation, les anti‑patterns, la typographie, les polices, l’espacement, la mise en page, l’alignement, la couleur, le motion, les micro‑interactions, le texte UX, les états d’erreur, les cas limites, l’i18n et les systèmes de design ou tokens réutilisables. À utiliser également pour les designs ternes qui doivent devenir plus audacieux ou plus agréables, les designs criards qui devraient être plus discrets, les itérations en direct dans le navigateur sur les éléments UI, ou les effets visuels ambitieux qui doivent paraître techniquement extraordinaires. Non destiné aux tâches uniquement backend ou non‑UI.
