Структурированный анализ скриншотов для реализации UI и критики. Анализирует каждый скриншот пользовательского интерфейса с помощью 5×5 пространственной сетки, полного инвентаря элементов и извлечения дизайн‑системы — факты и вкусы вместе, каждый раз. При необходимости переходит к полному плану реализации. Срабатывает на любой файл изображения цифрового интерфейса (png, jpg, gif, webp — веб‑сайты, приложения, дашборды, макеты, вайрфреймы) или команды типа «проанализировать этот скриншот», «перестроить это», «сопоставить этот дизайн», «клонировать это». Пропускает изображения, не относящиеся к UI (фото, мемы, диаграммы), если только пользователь явно не хочет создать UI из них. НЕ срабатывает на HTML‑исходный код, CSS, SVG или любой код, вставленный как текст.

Пожалуйста, всегда отвечайте на языке пользователя.
