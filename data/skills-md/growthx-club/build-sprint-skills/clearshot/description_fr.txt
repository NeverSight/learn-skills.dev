Analyse structurée des captures d’écran pour la mise en œuvre et la critique d’UI. Analyse chaque capture d’écran d’interface utilisateur avec une grille spatiale 5×5, un inventaire complet des éléments et l’extraction du système de conception — faits et goût réunis, à chaque fois. Passe à un plan d’implémentation complet lors de la construction. Se déclenche sur tout fichier image d’interface numérique (png, jpg, gif, webp — sites web, applications, tableaux de bord, maquettes, wireframes) ou sur des commandes telles que « analyse cette capture d’écran », « reconstruis‑cela », « fait correspondre ce design », « clone ceci ». Ignore les images non UI (photos, mèmes, graphiques) à moins que l’utilisateur ne veuille explicitement créer une UI à partir de celles‑ci. Ne se déclenche PAS sur le code source HTML, le CSS, les SVG ou tout code collé sous forme de texte.

Veuillez toujours répondre dans la langue de l’utilisateur.
