Análisis estructurado de capturas de pantalla para implementación y crítica de UI. Analiza cada captura de pantalla de UI con una cuadrícula espacial 5×5, inventario completo de elementos y extracción del sistema de diseño — hechos y gusto juntos, cada vez. Escala a un plano completo de implementación al construir. Se activa con cualquier archivo de imagen de interfaz digital (png, jpg, gif, webp — sitios web, aplicaciones, paneles, maquetas, wireframes) o comandos como “analiza esta captura”, “reconstruye esto”, “igualar este diseño”, “clonar esto”. Omitir para imágenes que no sean UI (fotos, memes, gráficos) a menos que el usuario indique explícitamente que desea crear una UI a partir de ellas. NO se activa con código fuente HTML, CSS, SVGs, o cualquier código pegado como texto.
