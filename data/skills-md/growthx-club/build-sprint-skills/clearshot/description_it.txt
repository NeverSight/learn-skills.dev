Analisi strutturata degli screenshot per implementazione UI e critica. Analizza ogni screenshot UI con una griglia spaziale 5×5, inventario completo degli elementi ed estrazione del sistema di design — fatti e gusto insieme, ogni volta. Passa a un progetto di implementazione completo quando si costruisce. Si attiva su qualsiasi file immagine di interfaccia digitale (png, jpg, gif, webp — siti web, app, dashboard, mockup, wireframe) o comandi come “analizza questo screenshot”, “ricostruisci questo”, “abbina questo design”, “clona questo”. Ignora le immagini non UI (foto, meme, grafici) a meno che l’utente non voglia esplicitamente creare una UI da esse. NON si attiva su codice sorgente HTML, CSS, SVG o su qualsiasi codice incollato come testo. Rispondi sempre nella lingua dell’utente.
