امنح المشروع وجهة نظر بصرية واحدة، ثم أنشئ الصور وفقًا لها. استخدم ذلك قبل توليد أو تعديل أو استبدال أي عنصر صورة — صورة البطل، og:image، توضيح، حالة فارغة، صورة شخصية، خلفية، فن البطاقة، مصدر أيقونة الموقع. استخدمه أيضًا عندما تبدو الصور المولدة عامة، أو "ذكاء اصطناعي"، أو غير متوافقة مع العلامة التجارية، أو عندما لا يبدو أن مجموعة الصور تنتمي لنفس المنتج. تجنّب ذلك لتصميم تخطيط واجهة المستخدم، CSS وعمل المكونات، التي تخص تصميم الواجهة الأمامية وتكون بلا عيوب.
