Transformez un répertoire de projet ou l’URL d’un site Web en une courte vidéo de lancement partageable avec musique, animation et texte de partage. Un seul fichier, aucune ressource groupée — généré entièrement par le modèle avec les outils déjà disponibles sur la machine. Utilisez‑le quand quelqu’un dit « /brag-slim », « let’s /brag about this », « brag about <url> », « make a launch video » ou veut montrer ce qu’il a construit. Si la compétence /brag est également installée, laissez /brag gérer ces expressions ; elle passe la main ici sur Opus 5.5.

Veuillez toujours répondre dans la langue de l’utilisateur.
