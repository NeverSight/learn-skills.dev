Позвольте ИИ действительно понять крупные кодовые базы. Для проектов, охватывающих несколько репозиториев, множество микросервисов и годы итераций, применяйте обратный инжиниринг архитектуры + графовые RAG‑карты + CLI‑инструмент с многоязычным AST, чтобы сжать огромный код в структурированную базу знаний — каждое заключение можно проследить до строк исходного кода, а каждое отношение помечено оценкой достоверности.

Применимый сценарий: проекты с более чем 10 репозиториями или микросервисами, где прямое чтение кода ИИ не позволяет достичь глобального понимания, приводит к неточным ответам и вызывает высокие токен‑затраты.

Выводы: N дизайн‑документов компонентов + обзор архитектуры + документация мостов + графовые RAG‑карты (G1~G9) + _manifest.json + граф извлечения teamAI (teamwiki/).

Триггер: team-wiki-codebase, code-to-knowledge, code knowledge base, architecture analysis, architecture reverse engineering  
Требования: доступные каталоги с исходным кодом (поддержка мульти‑репо); каталоги `references/` и `scripts/` внутри этого навыка.
