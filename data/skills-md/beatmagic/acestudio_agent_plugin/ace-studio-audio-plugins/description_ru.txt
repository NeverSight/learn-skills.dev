Как управлять аудиоплагинами, которые хостит ACE Studio — сторонними инструментами и эффектами VST3/AU, а также встроенными эффектами Studio — через встроенный в Studio компьютер для собственного интерфейса плагина, одновременно с инструментами параметров и состояний/пресетов. Загружайте их в любой момент, когда пользователь хочет загрузить, изменить, применить пресет или иным образом контролировать плагин, запросить использование компьютера для одного из них, либо когда задача требует управления, доступного только в пользовательском интерфейсе плагина. Комбинируйте с `ace-studio-features` для выбора звукового источника.
