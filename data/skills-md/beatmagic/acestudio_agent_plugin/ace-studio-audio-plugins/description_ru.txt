Как использовать аудиоплагины в ACE Studio — сторонние инструменты и эффекты VST3/AU, а также встроенные эффекты Studio — через встроенные возможности компьютера Studio для собственного интерфейса плагина, вместе с инструментами параметров и состояний/пресетов. Загружайте плагин каждый раз, когда пользователь хочет загрузить, настроить, сохранить пресет или иным образом управлять плагином, запрашивайте использование компьютера в одном случае, либо когда задача требует контроля, доступного только в пользовательском интерфейсе плагина. Сочетайте с `ace-studio-features` для выбора звукового источника.
