Cómo conducir los plugins de audio ACE Studio hosts — instrumentos y efectos VST3/AU de terceros, y los propios efectos incorporados de Studio — a través del uso informático incorporado de Studio para la interfaz propia de un plugin, junto con las herramientas de parámetros y estado/preestablecidas. Cargar siempre que el usuario quiera cargar, modificar, preestablecer o controlar de otro modo un plugin, solicite el uso del ordenador en uno o un trabajo necesite un control que solo exista dentro de la interfaz de usuario de un plugin. Combínalo con `ace-studio-features` para elegir una fuente de sonido.
