Wie man die Audio‑Plugins, die ACE Studio hostet — Drittanbieter‑VST3/AU‑Instrumente und ‑effekte sowie Studios eigene integrierte Effekte — über die in Studio eingebaute Computernutzung für die eigene Plugin‑Benutzeroberfläche steuert, zusammen mit den Parameter‑ und Zustands‑/Preset‑Werkzeugen. Laden, wann immer der Nutzer ein Plugin laden, anpassen, ein Preset setzen oder anderweitig steuern möchte, wenn die Computernutzung für ein Plugin angefordert wird oder ein Vorgang eine Steuerung erfordert, die nur in der UI des Plugins existiert. Kombinieren Sie das mit `ace-studio-features`, um eine Klangquelle auszuwählen.
