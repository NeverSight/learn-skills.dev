ACE Studio가 호스팅하는 오디오 플러그인 — 서드파티 VST3/AU 악기와 이펙트, 그리고 Studio 자체 내장 이펙트 — 의 인터페이스를 플러그인 자체 UI와 함께 파라미터 및 상태/프리셋 도구와 연동해 Studio의 내장 컴퓨터 사용을 통해 제어하는 방법. 사용자가 플러그인을 로드, 조정, 프리셋 적용하거나 기타 방식으로 제어하고자 할 때 언제든 로드하고, 하나에 대해 컴퓨터 사용을 요청하거나, 작업에 플러그인 UI 내부에만 존재하는 제어가 필요할 때. 사운드 소스를 선택하려면 `ace-studio-features`와 함께 사용하세요.
