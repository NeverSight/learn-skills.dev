ACE Studio 的功能有哪些以及在何時使用每項功能 —— 軌道類型及其發聲方式、音訊效果、Vocal Synth 與其語音庫、AI 樂器、第三方樂器插件、生成套件（Inspire Me、Music Enhancer、Add A Layer）以及實用工具（Stem Splitter、Voice Changer、Vocal to MIDI、Doubles、標記軌、檔案匯入）。在使用者想要於 ACE Studio 中建立、變更或了解任何事物時載入：新增聲音或樂器、選擇歌手、生成音樂、分離音軌、轉換人聲，或詢問某個功能的用途。請搭配 `ace-studio-workflows` 以了解執行步驟的順序。
