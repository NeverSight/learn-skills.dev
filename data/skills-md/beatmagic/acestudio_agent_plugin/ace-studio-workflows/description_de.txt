Empfohlene End-to-End-Workflows in ACE Studio — die Reihenfolge, in der Features ausgeführt werden, welches Feature in jedem Schritt verwendet wird und an welchen Stellen die Arbeit das Studio für ein externes Tool verlassen muss. Beinhaltet das Erzeugen eines kompletten Songs und das Ausrichten des Projekts darauf, das Überarbeiten eines Songs aus einer importierten Audiodatei (Beat-Alignment, Stem‑Aufspaltung, Transkription zurück zu MIDI) und das Umwandeln eines fertigen Projekts in druckbare Noten. Laden Sie dies, wenn die Anfrage des Benutzers mehr als einen Schritt umfasst oder Formulierungen wie „Schreibe mir ein Lied“, „Ich habe diese Audiodatei und möchte …“ oder „Ich brauche dafür ein Notenblatt“ enthält. Kombinieren Sie es mit `ace-studio-features`, um zu sehen, was jedes Feature macht.
