Flujos de trabajo recomendados de extremo a extremo en ACE Studio — el orden para ejecutar las funciones, qué función usar en cada paso y dónde el trabajo debe salir de Studio hacia una herramienta externa. Cubre la generación de una canción completa y la alineación del proyecto con ella, el retrabajo de una canción a partir de un archivo de audio importado (alineación del ritmo, separación de stems, transcripción de vuelta a MIDI), y la conversión de un proyecto terminado en partituras imprimibles. Cárgalo siempre que la solicitud del usuario abarque más de un paso, o diga cosas como “escríbeme una canción”, “tengo este audio y quiero…”, o “necesito una partitura para esto”. Combínalo con `ace-studio-features` para saber qué hace cada función.
