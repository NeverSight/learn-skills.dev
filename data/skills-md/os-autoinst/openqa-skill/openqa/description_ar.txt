إنشاء وتعديل وتصحيح اختبارات openQA ومراجعة نتائج openQA. يُستخدم ذلك كلما ذكر المستخدم openQA أو o3 أو os‑autoinst أو isotovideo أو استدعاءات testapi مثل assert_script_run أو assert_screen أو الإبر (needles) أو رابط وظيفة مثل openqa.opensuse.org/tests/123 أو مجموعة وظائف أو بناء openQA أو الفشل الناعم (soft‑failures) أو force_result أو عمليات التحقق، أو سأل لماذا فشلت وظيفة openQA، أو كيف يكتب أو يجدول أو يشغّل أو يُصلّح اختبار openQA أو يراجع طلب سحب اختبار، أو لمراجعة أو وضع علامة على نتائج openQA.  
الاختبارات: وحدات اختبار os‑autoinst بلغة Perl أو Python، جداول YAML، بيانات الاختبار، طلبات سحب إلى os‑autoinst‑distri‑opensuse أو توزيع اختبار مخصص.  
النتائج: تصنيف وظائف فاشلة أو غير مكتملة أو متوقفة عن التوقيت من سجلاتها، تجميع مجموعة وظائف أو بناء، تمييز الأخطاء بين عيب في المنتج أو مشكلة اختبار أو بنية تحتية، صياغة تقارير الأخطاء وتعليقات الوظائف التي تحتوي على مراجع الأخطاء (bugrefs) والوسوم وتحليل openQA المتواصل.  
ليس للخطأ في بناء حزم OBS، أو التحقق من التحديثات الصيانة باستخدام mtui، أو أعمال تتبع الأخطاء البسيطة، أو أنظمة CI أخرى، أو أسئلة عامة حول Perl.
