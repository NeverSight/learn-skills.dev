Crea, modifica y depura pruebas openQA y revisa los resultados de openQA. Utilízalo siempre que el usuario mencione openQA, o3, os-autoinst, isotovideo, llamadas a testapi como assert_script_run o assert_screen, needles, una URL de trabajo como openqa.opensuse.org/tests/123, un grupo de trabajos o compilación de openQA, soft‑failures, force_result o ejecuciones de verificación, o pregunte por qué falló un trabajo de openQA, cómo escribir, programar, ejecutar o arreglar una prueba openQA o revisar una PR de prueba, o para revisar o etiquetar resultados de openQA.  

Pruebas: módulos de prueba os‑autoinst en Perl o Python, programaciones YAML, datos de prueba, pull requests a os‑autoinst‑distri‑opensuse o una distribución de pruebas personalizada.  

Resultados: triage de un trabajo fallado, incompleto o con tiempo agotado a partir de sus logs, rastreo de un grupo de trabajos o compilación, clasificación de error de producto vs problema de prueba vs infraestructura, borradores de informes de errores y comentarios de trabajos cuyos bugrefs, etiquetas y análisis de openQA se transfieran.  

No es para fallos de compilación de paquetes OBS, validación de actualizaciones de mantenimiento con mtui, trabajo puro de rastreador de errores, otros sistemas CI o preguntas generales de Perl.
