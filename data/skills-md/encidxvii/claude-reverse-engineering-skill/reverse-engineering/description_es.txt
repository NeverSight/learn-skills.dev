Ingenera inversamente software compilado y los internos de aplicaciones para investigación de seguridad autorizada, CTFs, análisis de malware, interoperabilidad y depuración. Úsalo siempre que el usuario quiera entender, descompilar, desensamblar, desempaquetar o rastrear un artefacto que posea o pueda estudiar: binarios nativos (ELF/PE/Mach‑O, .so/.dll/.dylib), APK/AAB/DEX de Android, aplicaciones iOS/macOS, bytecode .NET o Java, paquetes JavaScript/Electron/WASM, compilaciones de Python/Go/Rust/Flutter/React Native/Unity, instaladores, imágenes de firmware o la API de red o el formato de archivo de una aplicación. Se activa con frases como “qué hace este binario”, “descompila este APK”, “crackme”, “reversión de CTF”, “analiza esta muestra”, “extrae este firmware”, “recupera el formato de archivo”, “qué API llama esta app” o “cómo funciona esta app”, incluso cuando no se menciona ingeniería inversa. Incluye scripts de triaje, detección de herramientas, exportación de descompilador sin cabeza y extracción de puntos finales, además de guías operativas por plataforma.
