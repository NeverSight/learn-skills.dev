Ingénierie inverse du logiciel compilé et des internes d’application pour la recherche en sécurité autorisée, les CTF, l’analyse de logiciels malveillants, l’interopérabilité et le débogage. Utilisez-le chaque fois que l’utilisateur souhaite comprendre, décompiler, désassembler, décompresser ou tracer un artefact qu’il possède ou qu’il étudie : binaires natifs (ELF/PE/Mach‑O, .so/.dll/.dylib), APK/AAB/DEX Android, applications iOS/macOS, bytecode .NET ou Java, bundles JavaScript/Electron/WASM, builds Python/Go/Rust/Flutter/React Native/Unity, installateurs, images de firmware, ou l’API réseau ou le format de fichier d’une application. Se déclenche sur des expressions comme « quel est le rôle de ce binaire », « décompiler cet APK », « crackme », « reverse CTF », « analyser cet échantillon », « extraire ce firmware », « récupérer le format de fichier », « quelle API cette application appelle » ou « comment fonctionne cette application », même lorsque l’ingénierie inverse n’est pas nommée. Fournit des scripts de triage, de détection d’outils, d’exportation de décompilateur sans tête et d’extraction d’endpoint ainsi que des playbooks par plateforme.

Veuillez toujours répondre dans la langue de l’utilisateur.
