Modificateurs Blender 5.x, API bmesh, opérateurs d’édition de maillage, configuration de la sculpture — SubSurf, Booléen, Tableau, Miroir, Biseau, création de maillage procédural bmesh et pipelines de modélisation via Python (bpy).
