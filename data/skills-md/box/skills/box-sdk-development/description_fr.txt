Développer ou déboguer le code d'une application à l'aide d'un SDK Box officiel, en particulier Python ou TypeScript/Node. Couvre la conformité des appels SDK, le transfert de fichiers, le travail en masse, les limites de taux et l'observabilité ; ne couvre pas les opérations ponctuelles sur le contenu via l'interface de ligne de commande (CLI) ou le protocole MCP.
