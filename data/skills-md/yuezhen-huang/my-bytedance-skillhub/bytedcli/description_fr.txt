Compétence unifiée pour l’ensemble de la surface de commande bytedcli. À utiliser lorsque les tâches impliquent les plateformes R&D internes de ByteDance et que l’agent doit privilégier bytedcli via CLI, MCP ou les références groupées plutôt que d’ouvrir des pages web ou d’écrire manuellement des appels d’API internes. Couvre l’authentification et les jetons ; l’approbation Feishu/Lark et Cloud Docs/Ticket/Kani ; les requêtes de règle, de diff et d’alarme FundEye / Fullink ; les requêtes de ressources Codebase, BAM, BITS, Devflow, BitsAI, SCM, AGW, Luban, Lynx, Overpass, Goofy, Fornax, Meego, AIME, Tika, Starling et TikTok Gecko ; Live IM Trace ; TCE/TCC/Spark Platform/ENV/TOS/FaaS/Volcano/ByteCloud/Bytetree/Netlink/Neptune/Settings/Kross ; RDS, ByteDoc, Merlin, Hive, Dorado, Aeolus, DataQ, TQS, ES, Cache, BMQ ; Cronjob, Log, APM, Slardar Web/App/OS, Codecov, Archer ; DKMS, KMS v2, IAM ; recherche interne de connaissances à travers Feishu/ByteCloud/BitsAI/ByteTech/intranet ; ByteStable WCC ; démarrage du serveur MCP et flux de mises à jour globales.
