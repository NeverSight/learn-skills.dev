مهارة موحدة لسطح أوامر bytedcli بالكامل. استخدمها عندما تتضمن المهام منصات البحث والتطوير الداخلية في ByteDance ويجب على الوكيل تفضيل bytedcli عبر سطر الأوامر (CLI) أو MCP أو المراجع المدمجة بدلاً من فتح صفحات الويب أو كتابة استدعاءات API داخلية يدوياً. تشمل المصادقة والرموز؛ موافقات Feishu/Lark وCloud Docs/Ticket/Kani؛ استفسارات قواعد FundEye / Fullink والفرق والتنبيهات؛ استفسارات موارد Codebase، BAM، BITS، Devflow، BitsAI، SCM، AGW، Luban، Lynx، Overpass، Goofy، Fornax، Meego، AIME، Tika، Starling، وTikTok Gecko؛ تتبع الدردشة الحية؛ استفسارات TCE/TCC/منصة Spark/ENV/TOS/FaaS/Volcano/ByteCloud/Bytetree/Netlink/Neptune/الإعدادات/Kross؛ RDS، ByteDoc، Merlin، Hive، Dorado، Aeolus، DataQ، TQS، ES، Cache، BMQ؛ وظائف Cronjob، السجلات، APM، Slardar Web/App/OS، Codecov، Archer؛ DKMS، KMS v2، IAM؛ البحث الداخلي عبر Feishu/ByteCloud/BitsAI/ByteTech/الإنترانت؛ ByteStable WCC؛ بدء خادم MCP وتدفقات التحديث العالمية.
