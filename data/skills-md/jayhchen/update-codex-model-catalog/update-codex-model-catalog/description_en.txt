Update Codex model catalog: When Codex authenticates with an API key (custom model provider), it fetches the model catalog from the provider’s /models endpoint and synchronizes it to the file pointed to by model_catalog_json. Use this when the user needs to update the Codex model catalog, sync the model list, the server‑side models have additions or deletions, or when model_catalog_json is referenced. In OAuth (ChatGPT login) mode, Codex automatically retrieves the catalog, so this does not apply.
