Aggiorna catalogo dei modelli Codex: quando Codex si autentica con una chiave API (fornitore di modelli personalizzati), recupera il catalogo dei modelli dal endpoint /models del fornitore e lo sincronizza nel file indicato da model_catalog_json. Usa questa opzione quando l'utente deve aggiornare il catalogo dei modelli Codex, sincronizzare l'elenco dei modelli, i modelli lato server hanno aggiunte o rimozioni, o quando model_catalog_json è referenziato. In modalità OAuth (accesso ChatGPT), Codex recupera automaticamente il catalogo, quindi questa opzione non è applicabile.
