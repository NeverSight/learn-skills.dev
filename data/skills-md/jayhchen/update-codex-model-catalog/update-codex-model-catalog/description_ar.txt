تحديث فهرس نماذج Codex: عندما يقوم Codex بالمصادقة باستخدام مفتاح API (مزوّد نماذج مخصص)، فإنه يجلب فهرس النماذج من نقطة النهاية /models الخاصة بالمزوّد ويُزامنه مع الملف المشار إليه بـ model_catalog_json. استخدم هذا عندما يحتاج المستخدم إلى تحديث فهرس نماذج Codex، أو مزامنة قائمة النماذج، أو عندما تكون هناك إضافات أو حذف للنماذج على جانب الخادم، أو عندما يتم الإشارة إلى model_catalog_json. في وضع OAuth (تسجيل الدخول عبر ChatGPT) يقوم Codex باسترجاع الفهرس تلقائيًا، لذا لا ينطبق هذا.
