Mettez à jour le catalogue de modèles Codex : lorsque Codex s’authentifie avec une clé API (fournisseur de modèles personnalisé), il récupère le catalogue de modèles depuis le point de terminaison /models du fournisseur et le synchronise avec le fichier référencé par model_catalog_json. Utilisez cela lorsque l’utilisateur doit mettre à jour le catalogue de modèles Codex, synchroniser la liste des modèles, gérer les ajouts ou suppressions de modèles côté serveur, ou lorsque model_catalog_json est référencé. En mode OAuth (connexion ChatGPT), Codex récupère automatiquement le catalogue, donc cela ne s’applique pas.
