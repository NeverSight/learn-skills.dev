Сбор живого образца (от явления к пригодному образцу): когда у цели нет независимого процесса и образец не записывается на диск, основным носителем локализации является «abnormal execution memory + the execution context that reaches that memory», и извлечение происходит в режиме выполнения. Охватывает четыре модели наблюдения: Windows (VAD/поток/ETW), Linux (VMA/BPF LSM), macOS (Mach VM/Endpoint Security) и seL4 (происхождение возможностей). Триггерные термины: получение образца, живой сбор, отсутствие образца, только явление, недисковый, без файла, инъекция, память‑резидентный полезный код, захват во время выполнения, образец, извлечённый из памяти. Английские триггеры: sample acquisition, live acquisition, no sample, fileless, injected code, memory‑resident, runtime capture.
