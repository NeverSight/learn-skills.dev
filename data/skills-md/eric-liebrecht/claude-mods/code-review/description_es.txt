Revise los cambios desde un punto fijo (commit, branch, tag o merge-base) a lo largo de dos ejes: Estándares (¿el código sigue los estándares de codificación documentados de este repositorio?) y Especificaciones (¿el código coincide con lo que solicitó el problema/especificación de origen?). Ejecuta ambas revisiones en subagentes paralelos y los informa uno al lado del otro. Se utiliza cuando el usuario quiere revisar una sucursal, un PR, cambios de trabajo en curso o pide "revisar desde X".
