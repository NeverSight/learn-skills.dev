Diseña, implementa, repara, refactoriza, revisa y prueba código de programa mantenible en varios lenguajes y marcos. Úsalo siempre que Codex modifique el comportamiento ejecutable más allá de un formato trivial, incluyendo trabajo de funcionalidades, correcciones de errores, APIs, scripts, concurrencia, persistencia, integraciones, límites de seguridad, rutas sensibles al rendimiento o pruebas. Aplica descubrimiento priorizando el repositorio, contratos de comportamiento explícitos, cambios coherentes y mínimos, manejo seguro de límites, pruebas centradas en el comportamiento y revisión independiente de diferencias.
