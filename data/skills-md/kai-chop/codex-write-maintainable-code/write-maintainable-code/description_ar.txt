صمّم، نفّذ، أصلح، أعد هيكلة، راجع، واختبر شفرة البرامج القابلة للصيانة عبر اللغات والأطر. استخدم ذلك كلما غيّر Codex سلوك التنفيذ بما يتجاوز التنسيق التافه، بما في ذلك عمل الميزات، إصلاح الأخطاء، واجهات برمجة التطبيقات، السكريبتات، التزامن، التخزين الدائم، التكاملات، حدود الأمان، المسارات الحساسة للأداء، أو الاختبارات. افرض اكتشافًا أولاً عبر المستودع، وعقودًا سلوكية صريحة، وتغييرات متماسكة قليلة، ومعالجة آمنة للحدود، واختبارات مركزة على السلوك، ومراجعة مستقلة للفروقات.
