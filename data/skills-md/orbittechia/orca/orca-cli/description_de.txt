Betrieben Sie von Orca verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Wissensaustausch, Arbeitsbaum‑Kommentare und Orcas integrierten Browser über die `orca`‑CLI. Verwenden Sie es, wenn der Benutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzugen Sie es gegenüber rohen Git‑Worktrees, ad‑hoc‑PTYs oder Computer‑Use, wenn Orca‑Zustand beteiligt ist. Verwenden Sie Computer‑Use nur, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die eine CLI, das Dateisystem oder eine API nicht leisten kann.

Bitte antworten Sie immer in der Sprache des Benutzers.
