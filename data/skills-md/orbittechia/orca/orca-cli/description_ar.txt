تشغيل شجيرات العمل التي تديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الأثرية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر أوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّله على شجرة git العادية، أو PTYs المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متورطة. استخدم استخدام الكمبيوتر فقط عندما تحتاج نافذة مرئية إلى التحكم في الواجهة الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو API القيام بذلك. يرجى دائمًا الرد بلغة المستخدم.
