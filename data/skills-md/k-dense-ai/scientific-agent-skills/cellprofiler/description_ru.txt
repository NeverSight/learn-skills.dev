Запускает воспроизводимые конвейеры микроскопии CellProfiler для сегментации ядер, подсчёта клеток и измерения флюоресценции по каждому объекту. Поддерживает манифесты изображений/каналов, безголовый пакетный запуск, наложения сегментации и контроль качества измерений для 2‑мерных флюоресцентных анализов.
