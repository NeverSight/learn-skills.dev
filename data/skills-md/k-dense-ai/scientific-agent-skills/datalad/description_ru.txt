Извлекайте, редактируйте и публикуйте наборы научных данных с помощью DataLad и git-annex, а также фиксируйте происхождение вычислений с помощью запуска, повторного запуска и запуска контейнеров с помощью datalad. Используйте при клонировании или получении данных из OpenNeuro, DANDI, datasets.datalad.org или любого набора данных DataLad; когда файл в наборе данных читается как неработающая символическая ссылка или небольшой указатель вместо реальных данных; когда для анализа требуется машиночитаемая запись о том, как был получен каждый результат, чтобы его можно было выполнить повторно; или при публикации набора данных для одноуровневых элементов, таких как репозиторий GitHub и удаленное хранилище. Также используйте для выбора между DataLad и простым Git для хранилища данных.
