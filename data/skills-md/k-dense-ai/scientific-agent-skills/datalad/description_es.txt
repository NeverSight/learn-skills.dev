Recupera, versiona y publica conjuntos de datos científicos con DataLad y git-annex, y captura la procedencia computacional con datalad run, rerun y containers‑run. Úsalo al clonar o obtener datos de OpenNeuro, DANDI, datasets.datalad.org o cualquier conjunto de datos de DataLad; cuando un archivo en un conjunto de datos aparece como un enlace simbólico roto o como un puntero pequeño en lugar de los datos reales; cuando un análisis necesita un registro legible por máquinas de cómo se produjo cada salida para poder volver a ejecutarlo; o al publicar un conjunto de datos en repositorios secundarios como un repositorio de GitHub más un almacenamiento remoto. También utilízalo para decidir entre DataLad y Git puro para un repositorio que lleva datos.
