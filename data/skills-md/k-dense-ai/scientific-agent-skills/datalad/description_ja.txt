DataLad と git-annex を使用して科学データセットを取得、バージョン管理、公開し、datalad の実行、再実行、およびコンテナーの実行で計算の来歴を取得します。 OpenNeuro、DANDI、datasets.datalad.org、または任意の DataLad データセットからデータをクローン作成またはフェッチするときに使用します。データセット内のファイルが実際のデータではなく壊れたシンボリックリンクまたは小さなポインタとして読み取られる場合。分析で再実行できるように、各出力がどのように生成されたかについての機械可読な記録が必要な場合。または、GitHub リポジトリとストレージ リモートなどの兄弟にデータセットを公開する場合。データを運ぶリポジトリとして DataLad とプレーン Git のどちらを使用するかを決定するためにも使用します。
