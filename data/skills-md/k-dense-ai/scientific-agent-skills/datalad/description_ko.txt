DataLad 및 git-annex를 사용하여 과학 데이터 세트를 검색, 버전화 및 게시하고, datalad 실행, 재실행 및 컨테이너 실행을 통해 계산 출처를 캡처합니다. OpenNeuro, DANDI, Datasets.datalad.org 또는 모든 DataLad 데이터세트에서 데이터를 복제하거나 가져올 때 사용합니다. 데이터 세트의 파일이 실제 데이터 대신 깨진 심볼릭 링크나 작은 포인터로 읽혀지는 경우 분석에서 재실행을 위해 각 출력이 어떻게 생성되었는지에 대한 기계 판독 가능한 기록이 필요한 경우 또는 GitHub 저장소와 원격 저장소와 같은 형제자매에게 데이터 세트를 게시할 때. 또한 데이터 운반 저장소로 DataLad와 일반 Git 중에서 결정하는 데에도 사용됩니다.
