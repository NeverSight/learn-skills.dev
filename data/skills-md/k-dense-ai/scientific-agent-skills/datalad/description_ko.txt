DataLad와 git‑annex를 사용해 과학 데이터 세트를 검색하고, 버전 관리하며, 배포하고, datalad run, rerun 및 containers‑run으로 계산 프로벤런스를 캡처합니다. OpenNeuro, DANDI, datasets.datalad.org 또는 모든 DataLad 데이터 세트에서 복제하거나 데이터를 가져올 때; 데이터 세트 내 파일이 실제 데이터가 아닌 깨진 심볼릭 링크나 작은 포인터로 표시될 때; 각 출력이 어떻게 생성되었는지 기계가 읽을 수 있는 기록이 필요해 재실행이 가능한 분석을 수행할 때; 또는 GitHub 저장소와 저장소 원격지와 같은 형제(sibling) 저장소에 데이터 세트를 게시할 때 사용하십시오. 또한 데이터가 포함된 저장소에 대해 DataLad와 일반 Git 중 어느 것을 사용할지 결정할 때에도 활용합니다.
