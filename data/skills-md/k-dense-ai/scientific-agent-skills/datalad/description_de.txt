Rufen Sie wissenschaftliche Datensätze mit DataLad und git-annex ab, versionieren und veröffentlichen Sie sie und erfassen Sie die rechnerische Provenienz mit datalad run, rerun und containers‑run. Verwenden Sie das, wenn Sie Daten von OpenNeuro, DANDI, datasets.datalad.org oder einem beliebigen DataLad‑Datensatz klonen oder holen; wenn eine Datei in einem Datensatz als defekter Symlink oder als kleiner Zeiger statt echter Daten erscheint; wenn eine Analyse einen maschinenlesbaren Nachweis darüber benötigt, wie jedes Ergebnis erzeugt wurde, damit es erneut ausgeführt werden kann; oder wenn Sie einen Datensatz zu Nebenrepositorien wie einem GitHub‑Repository plus einem Speicher‑Remote veröffentlichen. Auch zur Entscheidung zwischen DataLad und reinem Git für ein datenhaltendes Repository.
