Rufen Sie wissenschaftliche Datensätze mit DataLad und Git-Annex ab, versionieren und veröffentlichen Sie sie und erfassen Sie die Herkunft der Berechnungen mit Datalad Run, Rerun und Container-Run. Wird zum Klonen oder Abrufen von Daten aus OpenNeuro, DANDI, datasets.datalad.org oder einem beliebigen DataLad-Datensatz verwendet. wenn eine Datei in einem Datensatz als defekter Symlink oder kleiner Zeiger statt als echte Daten gelesen wird; wenn eine Analyse eine maschinenlesbare Aufzeichnung darüber benötigt, wie jede Ausgabe erzeugt wurde, damit sie erneut ausgeführt werden kann; oder beim Veröffentlichen eines Datensatzes auf Geschwistern wie einem GitHub-Repository und einem Remote-Speicher. Verwenden Sie es auch, um zwischen DataLad und einfachem Git für ein datentragendes Repository zu entscheiden.
