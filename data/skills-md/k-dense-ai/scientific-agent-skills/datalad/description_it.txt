Recupera, esegui versioni e pubblica set di dati scientifici con DataLad e git-annex e acquisisci la provenienza computazionale con datalad run, rerun e container-run. Da utilizzare durante la clonazione o il recupero di dati da OpenNeuro, DANDI, datasets.datalad.org o qualsiasi set di dati DataLad; quando un file in un set di dati viene letto come un collegamento simbolico interrotto o come un piccolo puntatore invece che come dati reali; quando un'analisi necessita di una registrazione leggibile dalla macchina di come è stato prodotto ciascun output in modo che possa essere rieseguita; o quando si pubblica un set di dati su fratelli come un repository GitHub più uno spazio di archiviazione remoto. Utilizzalo anche per decidere tra DataLad e Git semplice per un repository che trasporta dati.
