Spree 6 の管理画面（React ダッシュボード（`@spree/dashboard`、Developer Preview））を `apps/dashboard/` 内でプロジェクトからカスタマイズするときに使用します。`src/plugins.ts` の `defineDashboardPlugin`、サイドバー／設定ナビゲーション、カスタムページ／ルート、組み込みページ上のスロットウィジェット、テーブルの列／フィルタ、拡張フォームフィールドとカスタムフィールドウィジェット、権限によるゲート、Admin API の呼び出し（`adminClient`、ストアスコープのクエリキー、422 マッピング）、新しい属性のエンドツーエンドでの公開、テーマトークン、翻訳、Vitest／Playwright テストとデプロイをカバーします。よく使われるフレーズには「管理画面にページを追加する」「管理サイドバーメニュー項目」「商品テーブルに列を追加する」「商品ページにカードを追加する」「商品フォームのカスタムフィールド」「権限でメニュー項目を非表示にする」「管理画面のスタイルを変更する」「ダッシュボードプラグイン」「spree add dashboard」「React admin」「spree_admin はどこへ行ったか」などがあります。
