Используйте при настройке админки Spree 6 — React‑панели (`@spree/dashboard`, Developer Preview) в `apps/dashboard/` — изнутри проекта. Охватывает `defineDashboardPlugin` в `src/plugins.ts`, навигацию боковой панели/настройки, пользовательские страницы/маршруты, виджеты‑слоты на встроенных страницах, столбцы/фильтры таблиц, поля формы расширения и пользовательские виджеты полей, ограничение доступа по правам, вызовы Admin API (`adminClient`, ключи запросов, привязанные к магазину, маппинг 422), раскрытие нового атрибута от конца до конца, токены темизации, переводы, тесты Vitest/Playwright и развертывание. Распространённые формулировки включают «добавить страницу в админку», «элемент боковой панели админки», «добавить столбец в таблицу товаров», «добавить карточку на страницу товара», «пользовательское поле в форме товара», «скрыть пункт меню по праву», «перестилизовать админку», «плагин дашборда», «spree add dashboard», «React admin», «где исчез spree_admin».
