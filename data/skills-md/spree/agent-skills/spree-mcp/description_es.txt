Úsalo al conectar un cliente de IA al servidor Admin MCP de una tienda Spree 6, al operar una tienda mediante sus herramientas o al agregar herramientas de agente. Cubre `/api/v3/admin/mcp` (`spree_mcp`), inicio de sesión OAuth y consentimiento (se rechazan claves secretas), las herramientas genéricas (`describe_resource`, `search_resources`, `create_resource`/`update_resource`, `query_report`, `curate_products`, `set_stock`, importaciones, exportaciones), las herramientas de acción generadas a partir de cada acción documentada de la API Admin, `parent_id`, y herramientas personalizadas — un endpoint admin documentado se convierte en una herramienta sin registro (`agent_tool false, reason:`, la especificación del contrato), o una `Spree::AgentTool` escrita a mano en `Spree.admin_agent_tools`. Frases comunes incluyen "Spree MCP", "admin MCP", "connect Claude to my store", "custom MCP tool", "agent tools", "expose my endpoint to agents", "Spree::AgentTool", "why can't the agent see this tool". No el servidor MCP de la documentación (`spree-docs`).
