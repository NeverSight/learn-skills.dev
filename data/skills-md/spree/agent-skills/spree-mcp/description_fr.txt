Utilisez lorsqu’on connecte un client IA au serveur Admin MCP d’une boutique Spree 6, que l’on exploite une boutique via ses outils, ou que l’on ajoute des outils d’agent. Couvre `/api/v3/admin/mcp` (`spree_mcp`), l’identification OAuth et le consentement (les clés secrètes sont refusées), les outils génériques (`describe_resource`, `search_resources`, `create_resource`/`update_resource`, `query_report`, `curate_products`, `set_stock`, imports, exports), les outils d’action générés à partir de chaque action documentée de l’API Admin, `parent_id`, et les outils personnalisés — un point de terminaison admin documenté devient un outil sans enregistrement (`agent_tool false, reason:`, la spécification du contrat), ou un `Spree::AgentTool` écrit à la main dans `Spree.admin_agent_tools`. Les formulations courantes incluent « Spree MCP », « admin MCP », « connect Claude to my store », « custom MCP tool », « agent tools », « expose my endpoint to agents », « Spree::AgentTool », « why can't the agent see this tool ». Pas le serveur docs MCP (`spree-docs`).
