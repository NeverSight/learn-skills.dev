Use when connecting an AI client to a Spree 6 store's Admin MCP server, operating a store through its tools, or adding agent tools. Covers `/api/v3/admin/mcp` (`spree_mcp`), OAuth sign-in and consent (secret keys are refused), the generic tools (`describe_resource`, `search_resources`, `create_resource`/`update_resource`, `query_report`, `curate_products`, `set_stock`, imports, exports), action tools generated from every documented Admin API action, `parent_id`, and custom tools — a documented admin endpoint becomes a tool with no registration (`agent_tool false, reason:`, the contract spec), or a hand-written `Spree::AgentTool` in `Spree.admin_agent_tools`. Common phrasings include "Spree MCP", "admin MCP", "connect Claude to my store", "custom MCP tool", "agent tools", "expose my endpoint to agents", "Spree::AgentTool", "why can't the agent see this tool". Not the docs MCP server (`spree-docs`).
