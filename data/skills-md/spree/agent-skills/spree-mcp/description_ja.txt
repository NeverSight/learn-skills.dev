Spree 6 ストアの Admin MCP サーバーに AI クライアントを接続する、ツールで店舗を運営する、またはエージェントツールを追加する際に使用します。対象は `/api/v3/admin/mcp`（`spree_mcp`）、OAuth サインインと同意（シークレットキーは拒否されます）、汎用ツール（`describe_resource`、`search_resources`、`create_resource`/`update_resource`、`query_report`、`curate_products`、`set_stock`、インポート、エクスポート）、すべての文書化された Admin API アクションから生成されたアクションツール、`parent_id`、およびカスタムツールです — 文書化された管理エンドポイントは登録なしでツールになります（`agent_tool false, reason:`、契約仕様）、あるいは `Spree.admin_agent_tools` 内の手書き `Spree::AgentTool` です。一般的な表現には「Spree MCP」「admin MCP」「Claude を私のストアに接続」「カスタム MCP ツール」「agent tools」「エンドポイントをエージェントに公開」「Spree::AgentTool」「なぜエージェントはこのツールを見れないのか」などがあります。ドキュメント用 MCP サーバー（`spree-docs`）は対象外です。
