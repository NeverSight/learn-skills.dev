Используйте при подключении AI‑клиента к серверу Admin MCP магазина Spree 6, управлении магазином через его инструменты или добавлении инструментов агенту. Охватывает `/api/v3/admin/mcp` (`spree_mcp`), OAuth‑вход и согласие (секретные ключи отклоняются), общие инструменты (`describe_resource`, `search_resources`, `create_resource`/`update_resource`, `query_report`, `curate_products`, `set_stock`, импорты, экспорты), инструменты‑действия, генерируемые из каждого задокументированного действия Admin API, `parent_id` и пользовательские инструменты — задокументированный админ‑конечный пункт становится инструментом без регистрации (`agent_tool false, reason:`, спецификация контракта) или вручную написанным `Spree::AgentTool` в `Spree.admin_agent_tools`. Распространённые формулировки включают «Spree MCP», «admin MCP», «connect Claude to my store», «custom MCP tool», «agent tools», «expose my endpoint to agents», «Spree::AgentTool», «why can't the agent see this tool». Не относится к серверу документации MCP (`spree-docs`).
