Usa quando si collega un client IA al server Admin MCP di un negozio Spree 6, si gestisce un negozio tramite i suoi strumenti o si aggiungono strumenti per gli agenti. Copre `/api/v3/admin/mcp` (`spree_mcp`), l'accesso OAuth e il consenso (le chiavi segrete vengono rifiutate), gli strumenti generici (`describe_resource`, `search_resources`, `create_resource`/`update_resource`, `query_report`, `curate_products`, `set_stock`, importazioni, esportazioni), gli strumenti di azione generati da ogni azione documentata dell'Admin API, `parent_id` e gli strumenti personalizzati — un endpoint amministrativo documentato diventa uno strumento senza registrazione (`agent_tool false, reason:`, la specifica del contratto), o un `Spree::AgentTool` scritto a mano in `Spree.admin_agent_tools`. Le frasi comuni includono “Spree MCP”, “admin MCP”, “connect Claude to my store”, “custom MCP tool”, “agent tools”, “expose my endpoint to agents”, “Spree::AgentTool”, “why can’t the agent see this tool”. Non il server MCP della documentazione (`spree-docs`).
