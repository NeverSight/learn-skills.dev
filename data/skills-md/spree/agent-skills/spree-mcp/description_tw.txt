在將 AI 客戶端連接至 Spree 6 商店的管理 MCP 伺服器、透過其工具操作商店，或加入代理工具時使用。涵蓋 `/api/v3/admin/mcp`（`spree_mcp`）、OAuth 登入與同意（拒絕使用密鑰）、通用工具（`describe_resource`、`search_resources`、`create_resource`/`update_resource`、`query_report`、`curate_products`、`set_stock`、匯入、匯出）、由每個已記錄的 Admin API 動作產生的行動工具、`parent_id` 以及自訂工具──已記錄的管理端點會直接成為工具，無需註冊（`agent_tool false, reason:`，合約規格），或是寫在 `Spree.admin_agent_tools` 中的手寫 `Spree::AgentTool`。常見用語包括「Spree MCP」、「admin MCP」、「connect Claude to my store」、「custom MCP tool」、「agent tools」、「expose my endpoint to agents」、「Spree::AgentTool」、「why can't the agent see this tool」。不包括文件 MCP 伺服器（`spree-docs`）。
