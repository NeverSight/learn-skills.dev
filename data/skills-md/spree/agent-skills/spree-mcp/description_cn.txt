在将 AI 客户端连接到 Spree 6 商店的 Admin MCP 服务器、通过其工具运营商店或添加代理工具时使用。本节涵盖 `/api/v3/admin/mcp`（`spree_mcp`）、OAuth 登录和授权（拒绝使用密钥）、通用工具（`describe_resource`、`search_resources`、`create_resource`/`update_resource`、`query_report`、`curate_products`、`set_stock`、导入、导出）、从每个已记录的 Admin API 操作生成的动作工具、`parent_id` 以及自定义工具——已记录的管理员端点会自动成为无需注册的工具（`agent_tool false, reason:`，合同规范），或者在 `Spree.admin_agent_tools` 中手写的 `Spree::AgentTool`。常见表达包括 “Spree MCP”“admin MCP”“connect Claude to my store”“custom MCP tool”“agent tools”“expose my endpoint to agents”“Spree::AgentTool”“why can't the agent see this tool”。不针对文档 MCP 服务器（`spree-docs`）。
