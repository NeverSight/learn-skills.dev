استخدم هذا عند ربط عميل ذكاء اصطناعي بخادم الإدارة MCP لمتجر Spree 6، أو تشغيل المتجر عبر أدواته، أو إضافة أدوات للوكيل. يغطي `/api/v3/admin/mcp` (`spree_mcp`)، وتسجيل الدخول عبر OAuth والموافقة (تُرفض مفاتيح السر)، الأدوات العامة (`describe_resource`، `search_resources`، `create_resource`/`update_resource`، `query_report`، `curate_products`، `set_stock`، الاستيراد، التصدير)، أدوات الإجراء التي تُنشأ من كل عملية موثقة في واجهة برمجة تطبيقات الإدارة، `parent_id`، والأدوات المخصصة — تصبح نقطة النهاية الإدارية الموثقة أداة دون تسجيل (`agent_tool false, reason:`، مواصفات العقد)، أو أداة `Spree::AgentTool` مكتوبة يدوياً في `Spree.admin_agent_tools`. العبارات الشائعة تشمل "Spree MCP"، "admin MCP"، "connect Claude to my store"، "custom MCP tool"، "agent tools"، "expose my endpoint to agents"، "Spree::AgentTool"، "why can't the agent see this tool". ليس خادم الوثائق MCP (`spree-docs`).
