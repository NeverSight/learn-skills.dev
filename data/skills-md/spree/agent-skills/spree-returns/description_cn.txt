在 Spree 6 中处理购买后流程时使用——退货（返款）、换货（不同商品）以及索赔（损坏/缺失/错误商品，退款或更换但无需退回商品）。涵盖 Spree::Return / Spree::Exchange / Spree::Claim、它们的状态和工作流、各市场的退货窗口以及员工覆盖、通过 returns.create.validate 钩子自定义退货政策、收货和重新入库（可转售）、原支付方式退款与店铺积分、预付退货标签、退货和索赔原因、事件，以及 Store/Admin API 端点。常用短语包括 “RMA”、 “退货窗口”、 “30 天退货”、 “特卖品不可退货”、 “重新入库退货商品”、 “退款退货”、 “店铺积分退款”、 “换成不同尺码”、 “商品到货损坏”、 “发送替换品”、 “退货标签”、 “ReturnAuthorization”、 “CustomerReturn”、 “Reimbursement”。
