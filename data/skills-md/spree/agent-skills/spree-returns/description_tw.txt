在使用 Spree 6 的購後流程時使用 — 退貨（退款）、換貨（不同商品）以及索賠（商品損壞／缺少／錯誤，退款或不退回商品的換貨）。涵蓋 Spree::Return / Spree::Exchange / Spree::Claim、它們的狀態與工作流程、各市場的退貨期限與員工覆寫、透過 returns.create.validate 鉤子自訂退貨政策、收貨與重新入庫（可再售）、原付款方式退款與店鋪信用、預付退貨標籤、退貨與索賠原因、事件，以及 Store/Admin API 端點。常用語包括「RMA」、「退貨期限」、「30 天退貨」、「最終特賣商品不得退貨」、「重新入庫退回商品」、「退貨退款」、「店鋪信用退款」、「換成不同尺寸」、「商品到貨損壞」、「寄送替換品」、「退貨標籤」、「ReturnAuthorization」、「CustomerReturn」、「Reimbursement」。
