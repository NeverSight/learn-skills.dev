Spree 6 の購入後フロー（返金、交換、クレーム）で使用します — 返金（金銭返還）、交換（別の商品）、クレーム（破損・欠品・誤商品、商品を戻さずに返金または交換）。Spree::Return / Spree::Exchange / Spree::Claim、これらのステータスとワークフロー、市場ごとの返品ウィンドウとスタッフの上書き、returns.create.validate フックによるカスタム返品ポリシー、受領と再入荷（再販可能）、元の支払いへの返金とストアクレジットへの返金、プリペイド返品ラベル、返品・クレーム理由、イベント、そして Store/Admin API エンドポイントをカバーします。一般的な表現には「RMA」「返品ウィンドウ」「30日返品」「最終販売商品は返品できません」「返品商品を再入荷」「返品の返金」「ストアクレジット返金」「別サイズへの交換」「商品が破損して到着」「代替品を送付」「返品ラベル」「ReturnAuthorization」「CustomerReturn」「Reimbursement」などがあります。
