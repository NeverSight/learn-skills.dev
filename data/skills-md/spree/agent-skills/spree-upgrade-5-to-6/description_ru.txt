Используйте при обновлении приложения Spree версии 5.x до Spree 6.0 или при исправлении кода, который перестал работать после такого обновления. Распространённые формулировки включают «обновить до Spree 6», «перейти с 5.6 на 6.0», «изменения, ломающие Spree 6», «checkout_flow / state machine исчезли», «Spree::Adjustment не найден», «удален master variant», «PermissionSets NameError», «сотрудники заблокированы после обновления», «что заменило Shipment / Taxon / ReturnAuthorization / metafields», «spree_admin gem не найден». Охватывает предположения (сначала 5.6, Rails 8.1, замены в Gemfile, роли как данные), порядок обратных заполнений данных 5.6 → 6.0, grep‑рецепты для кода, который необходимо изменить, и чек‑лист проверки поведения.
