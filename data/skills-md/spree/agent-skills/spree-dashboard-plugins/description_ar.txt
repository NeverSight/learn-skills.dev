استخدمه عند تعبئة تخصيصات لوحة تحكم React في Spree 6 كملف npm قابل لإعادة التوزيع (يمكن إقرانه اختياريًا بجوهرة امتداد Rails) بحيث تقوم المتاجر الأخرى في Spree بتثبيته — التهيئة باستخدام `npx @spree/cli plugin new`، مسارات الملفات وصراعات المسارات، peerDependencies مقابل `@spree/dashboard-core`/`-ui`، النشر كملف مبني مسبقًا مقابل النشر من المصدر، `sideEffects`، علامة `spree.dashboard.plugin` في ملف package.json، الاكتشاف التلقائي عبر `virtual:spree-dashboard-plugins` مقابل القائمة البيضاء الصريحة، مسح فئات Tailwind، مصانع `definePlugin(config)`، Changesets، ونصف الجوهرة الخلفية. العبارات الشائعة تشمل "نشر ملحق لوحة تحكم"، "حزمة npm لإدارة Spree"، "spree plugin new"، "مشاركة شاشات الإدارة عبر المتاجر"، "الملحق لا يظهر"، "صراع مسار لوحة التحكم"، "أنماط الملحق مفقودة"، "امتداد سوق مع واجهة إدارية".
