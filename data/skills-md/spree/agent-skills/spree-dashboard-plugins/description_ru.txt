Используется при упаковке кастомизаций React‑дашборда Spree 6 в переиспользуемый npm‑плагин (опционально в паре с Ruby‑gem‑расширением для Rails), который устанавливают другие магазины Spree — создание каркаса с помощью `npx @spree/cli plugin new`, файловые роуты и их конфликты, peerDependencies к `@spree/dashboard-core`/`-ui`, публикация в виде готовых сборок vs исходного кода, `sideEffects`, маркер `spree.dashboard.plugin` в package.json, автодисковери через `virtual:spree-dashboard-plugins` против явного whitelist‑а, сканирование классов Tailwind, фабрики `definePlugin(config)`, Changesets и часть с бэкенд‑gem. Распространённые формулировки включают «publish a dashboard plugin», «npm package for the Spree admin», «spree plugin new», «share admin screens across stores», «plugin not showing up», «Dashboard route collision», «plugin styles missing», «marketplace extension with admin UI».
