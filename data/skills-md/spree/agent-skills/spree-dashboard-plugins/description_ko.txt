Spree 6 React 대시보드 커스터마이징을 재배포 가능한 npm 플러그인(선택적으로 Rails 확장 gem과 함께)으로 패키징할 때 사용합니다 — `npx @spree/cli plugin new` 로 스캐폴딩, 파일 라우트와 라우트 충돌, `@spree/dashboard-core`/`-ui`에 대한 peerDependencies, 사전 빌드와 소스 게시 방식 선택, `sideEffects`, `spree.dashboard.plugin` package.json 마커, `virtual:spree-dashboard-plugins` 를 통한 자동 발견 vs 명시적 화이트리스트, Tailwind 클래스 스캔, `definePlugin(config)` 팩터리, Changesets, 그리고 백엔드 gem 부분을 포함합니다. 흔히 쓰이는 문구로는 “대시보드 플러그인 배포”, “Spree admin용 npm 패키지”, “spree plugin new”, “스토어 간 관리자 화면 공유”, “플러그인 표시 안 됨”, “Dashboard 라우트 충돌”, “플러그인 스타일 누락”, “관리자 UI가 포함된 마켓플레이스 확장” 등이 있습니다.
