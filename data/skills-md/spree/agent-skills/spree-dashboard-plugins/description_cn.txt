在将 Spree 6 React 仪表盘定制打包为可再分发的 npm 插件（可选地配合 Rails 扩展 gem）供其他 Spree 店铺安装时使用——使用 `npx @spree/cli plugin new` 进行脚手架，文件路由和路由冲突，针对 `@spree/dashboard-core`/`-ui` 的 peerDependencies，预编译与源码发布，`sideEffects`，`spree.dashboard.plugin` package.json 标记，通过 `virtual:spree-dashboard-plugins` 自动发现与显式白名单的比较，Tailwind 类扫描，`definePlugin(config)` 工厂，Changesets，以及后端 gem 部分。常见表述包括 “publish a dashboard plugin”、 “npm package for the Spree admin”、 “spree plugin new”、 “share admin screens across stores”、 “plugin not showing up”、 “Dashboard route collision”、 “plugin styles missing”、 “marketplace extension with admin UI”。
