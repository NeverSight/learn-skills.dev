Usa quando impacchetti le personalizzazioni della dashboard React di Spree 6 come un plugin npm ridistribuibile (facoltativamente associato a una gemma di estensione Rails) che altri negozi Spree installano — scaffolding con `npx @spree/cli plugin new`, percorsi dei file e collisioni di route, peerDependencies contro `@spree/dashboard-core`/`-ui`, pubblicazione precompilata vs sorgente, `sideEffects`, il marcatore `spree.dashboard.plugin` in package.json, scoperta automatica tramite `virtual:spree-dashboard-plugins` rispetto a una whitelist esplicita, scansione delle classi Tailwind, factory `definePlugin(config)`, Changesets e la parte gem del backend. Le frasi comuni includono "publish a dashboard plugin", "npm package for the Spree admin", "spree plugin new", "share admin screens across stores", "plugin not showing up", "Dashboard route collision", "plugin styles missing", "marketplace extension with admin UI".
