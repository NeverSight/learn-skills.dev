在將 Spree 6 React 儀表板客製化打包成可重新分發的 npm 插件（可選與 Rails 擴充 gem 配合）供其他 Spree 商店安裝時使用 — 使用 `npx @spree/cli plugin new` 生成腳手架、檔案路由與路由衝突、對 `@spree/dashboard-core`／`-ui` 的 peerDependencies、預建 vs 原始碼發佈、`sideEffects`、`spree.dashboard.plugin` package.json 標記、透過 `virtual:spree-dashboard-plugins` 自動發現或顯式白名單、Tailwind 類別掃描、`definePlugin(config)` 工廠、Changesets，以及後端 gem 部分。常見說法包括「publish a dashboard plugin」、「npm package for the Spree admin」、「spree plugin new」、「share admin screens across stores」、「plugin not showing up」、「Dashboard route collision」、「plugin styles missing」、「marketplace extension with admin UI」。
