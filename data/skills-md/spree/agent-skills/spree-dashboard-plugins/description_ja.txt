Spree 6 React ダッシュボードのカスタマイズを、他の Spree ストアがインストールできる再配布可能な npm プラグイン（オプションで Rails 拡張 gem と組み合わせても可）としてパッケージ化する際に使用します — `npx @spree/cli plugin new` によるスキャフォールディング、ファイルルートとルート衝突、`@spree/dashboard-core`/`-ui` に対する peerDependencies、ビルド済みとソース公開の選択、`sideEffects`、`spree.dashboard.plugin` package.json マーカー、`virtual:spree-dashboard-plugins` による自動検出と明示的ホワイトリストの比較、Tailwind クラスのスキャン、`definePlugin(config)` ファクトリ、Changesets、そしてバックエンド gem 部分。一般的なフレーズとしては「ダッシュボードプラグインを公開する」「Spree 管理者用 npm パッケージ」「spree plugin new」「ストア間で管理画面を共有する」「プラグインが表示されない」「ダッシュボードのルート衝突」「プラグインのスタイルが欠如している」「管理 UI を持つマーケットプレイス拡張」などがあります。
