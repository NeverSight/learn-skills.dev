Uso al empaquetar personalizaciones del panel React de Spree 6 como un plugin npm redistribuible (opcionalmente acompañado de una gema de extensión Rails) que otras tiendas Spree instalan — scaffolding con `npx @spree/cli plugin new`, rutas de archivos y colisiones de rutas, peerDependencies contra `@spree/dashboard-core`/`-ui`, publicación precompilada vs desde el código fuente, `sideEffects`, el marcador `spree.dashboard.plugin` en package.json, autodetección mediante `virtual:spree-dashboard-plugins` frente a una lista blanca explícita, escaneo de clases Tailwind, fábricas `definePlugin(config)`, Changesets y la mitad de la gema backend.
