À utiliser lors de la connexion de Spree 6 à un système externe via un contrat de fournisseur — un moteur de taxes, la comparaison de tarifs de transporteurs, un WMS/3PL ou un fournisseur d’étiquettes, une passerelle de paiement, un moteur de recherche (Meilisearch, Typesense, Algolia), les paiements aux vendeurs, les téléchargements numériques/clés de licence, SSO/OpenID Connect ou un émetteur JWT personnalisé, OpenTelemetry/APM, ou un ERP/PIM/DAM. Formulations courantes - « custom tax provider », « Avalara », « delivery rate provider », « EasyPost », « fulfillment provider », « custom payment method », « search provider », « payout provider », « digital asset provider », « SSO », « Okta/Entra login », « Spree::Integration », « store credentials for a provider », « Spree.integrations », « which registry do I append to ».
