Использовать при построении B2B или оптовой коммерции на Spree 6 — сквозная настройка «создать B2B‑магазин», компании/организации покупателей (дерево компаний, подразделения, участники, приглашения, адресная книга компании, покупки от имени компании), каталоги и согласованные цены (ассортименты, собственные прайс‑листы, процентные корректировки, назначение каталогов компаниям или группам клиентов, каталоги по умолчанию для канала), группы клиентов, закрытые витрины (`storefront_access` login_required / prices_hidden), оптовый портал на Next.js, минимальное количество заказа / кратные количества заказа / минимальные заказы, номера PO и заказы в счёт (оплата по счёту, черновики заказов, вводимые сотрудниками с согласованными ценами, `payment_pending`), а также грузовые перевозки (коробки, поддоны, тарифы без цены). Распространённые формулировки включают «B2B», «оптовый», «создать B2B‑магазин», «оплата по счёту», «нетто‑условия», «согласованная цена строки», «черновой заказ для компании», «торговые клиенты», «корпоративный счёт», «Spree::Company», «подразделение», «организация‑покупатель», «согласованные цены», «ценообразование для конкретного клиента», «каталог», «прайс‑лист компании», «MOQ», «минимальное количество заказа», «кратное количество», «упаковка в короб», «минимальный заказ», «номер PO», «ссылка на покупочный заказ», «логин для просмотра цен», «магазин только для участников», «оптовый портал», «X-Spree-Channel», «грузоперевозка», «поддон», «коробка».
