Générez des messages de commit Git au format Conventional Commits à partir des modifications du référentiel. Utilisez-le lorsque Codex doit écrire, réécrire, examiner ou valider un message de commit à partir de diff mis en scène ou non, tout en déduisant le type, la portée, le sujet et le corps facultatif corrects à partir du référentiel actuel plutôt qu'en supposant des portées fixes.
