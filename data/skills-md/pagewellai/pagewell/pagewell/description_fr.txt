Rédigez et publiez un document conçu — un article, un rapport — ou un artefact d’une page qui s’exécute dans le navigateur : un explicateur de principe, une histoire verticale qui se lit toute seule comme un diaporama narré (Qwen TTS), un petit jeu ; fournissez un lien. Une histoire ou un jeu peut être enregistré en MP4 avec OBS. Utilisez-le pour « write an article », « explain X with a demo », « make it vertical », « make a game », « publish », « voiceover », « record a video » (« 写篇文章 », « 竖屏 », « 小游戏 », « 配音 », « 录成视频 ») ; aussi modèles, graphiques, brouillons X (« 发到 X 长文 »).
