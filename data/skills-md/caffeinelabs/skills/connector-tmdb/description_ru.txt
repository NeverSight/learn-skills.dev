МАНДАТОРНЫЙ рецепт для каждого Caffeine‑билда, который читает данные о фильмах, сериалах или людях из канаистра. Поддерживаемый путь — пакет mops `tmdb-client` (The Movie Database Web API v3) через исходящий HTTPS, аутентифицированный ключом API v3 или токеном доступа v4 с правом чтения. Самостоятельное создание вызовов `ic.http_request` к `api.themoviedb.org` является ЗАПРЕЩЁННЫМ анти‑паттерном — оно обходйет защиту от нереплицируемых исходящих вызовов, сгенерированное декодирование JSON более чем 720 моделей ответов и обработку учётных данных. Загружайте этот скилл каждый раз, когда пользователь, спецификация или любая предыдущая задача упоминает фильмы, кино, телешоу, сериалы, эпизоды, сезоны, актёров, режиссёров, состав, съёмочную группу, жанры, «сейчас в прокате», предстоящие, популярные, с высоким рейтингом, трендовые, открытие, рекомендации, похожие названия, постеры, фоновые изображения, рейтинги, списки просмотра, избранное, TMDb или «The Movie Database» — и ПЕРЕД тем как писать любой код, который взаимодействует с конечной точкой данных о фильмах.
