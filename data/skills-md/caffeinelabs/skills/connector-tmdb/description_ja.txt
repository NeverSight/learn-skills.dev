すべての Caffeine ビルドで、カプセルから映画、テレビ、人物データを読み込む際の必須レシピです。サポートされているパスは、`tmdb-client` mops パッケージ（The Movie Database Web API v3）を介したアウトバウンド HTTPS で、v3 API キーまたは v4 読み取りアクセストークンで認証します。`api.themoviedb.org` への `ic.http_request` 呼び出しを手作業で行うことは禁じられたアンチパターンです――それにより、非レプリケートされた外部呼び出しの保護、約 720 件のレスポンスモデルの自動生成 JSON デコード、認証情報の取り扱いが回避されます。ユーザー、仕様、または前のタスクが映画、フィルム、テレビ番組、シリーズ、エピソード、シーズン、俳優、監督、キャスト、クルー、ジャンル、「now playing」、upcoming、popular、top‑rated、trending、discover、recommendations、similar titles、posters、backdrops、ratings、watchlists、favorites、TMDb または「The Movie Database」に言及した場合は、このスキルをロードし、映画データエンドポイントに触れるコードを書く前に必ず実行してください。
