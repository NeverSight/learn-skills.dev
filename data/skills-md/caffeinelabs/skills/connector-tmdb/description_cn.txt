每个读取电影、电视或人物数据的 Caffeine 构建都必须使用的配方。支持的路径是 `tmdb-client` mops 包（The Movie Database Web API v3），通过出站 HTTPS，使用 v3 API 密钥或 v4 读取访问令牌进行身份验证。手动编写对 `api.themoviedb.org` 的 `ic.http_request` 调用是被禁止的反模式——它绕过了非复制的外部调用安全检测、约 720 个响应模型的生成式 JSON 解码以及凭证处理。每当用户、规范或任何先前任务提及电影、影片、电视节目、系列、剧集、季、演员、导演、演员阵容、工作人员、类型、“正在上映”、即将上映、热门、评分最高、趋势、发现、推荐、相似标题、海报、背景图、评分、观看列表、收藏、TMDb 或 “The Movie Database” 时，都要加载此技能，并且在编写任何涉及电影数据端点的代码之前。

请始终使用用户的语言作答。
