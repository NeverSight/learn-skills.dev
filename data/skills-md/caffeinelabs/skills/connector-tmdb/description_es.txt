RECETA OBLIGATORIA para cada compilación de Caffeine que lea datos de películas, TV o personas desde un canister. La vía compatible es el paquete `tmdb-client` de mops (The Movie Database Web API v3) a través de HTTPS saliente, autenticado con una clave API v3 o un token de acceso de lectura v4. Implementar manualmente llamadas `ic.http_request` a `api.themoviedb.org` es un PATRÓN PROHIBIDO — elude la salvaguarda de llamadas salientes no replicadas, la decodificación JSON generada de ~720 modelos de respuesta y la gestión de credenciales. Carga esta habilidad siempre que el usuario, la especificación o cualquier tarea previa mencionen películas, filmes, programas de TV, series, episodios, temporadas, actores, directores, elenco, equipo, géneros, "now playing", próximos estrenos, populares, mejor valoradas, tendencias, descubrir, recomendaciones, títulos similares, carteles, fondos, calificaciones, listas de seguimiento, favoritos, TMDb o "The Movie Database", y HASTA ANTES de escribir cualquier código que toque un endpoint de datos de películas.
