الوصفة الإلزامية لكل بنية Caffeine تقرأ بيانات الأفلام أو التلفاز أو الأشخاص من حاوية. المسار المدعوم هو حزمة `tmdb-client` في mops (واجهة برمجة تطبيقات قاعدة بيانات الأفلام الويب v3) عبر HTTPS الصادر، مع المصادقة باستخدام مفتاح API من النوع v3 أو رمز وصول للقراءة من النوع v4. كتابة استدعاءات `ic.http_request` يدوياً إلى `api.themoviedb.org` تُعد نمطًا ممنوعًا — فهي تتجاوز آلية الحماية من الاستدعاءات غير المتكررة، وفك تشفير JSON المولّد لحوالي 720 نموذج استجابة، ومعالجة الاعتمادات. احمِل هذه المهارة كلما ذكر المستخدم أو المواصفات أو أي مهمة سابقة الأفلام، الأفلام السينمائية، عروض التلفاز، السلسلة، الحلقات، المواسم، الممثلين، المخرجين، الطاقم، الأنواع، "المعرض الآن"، القادمة، الشعبية، الأعلى تقييماً، المتصدرة، الرائجة، الاكتشاف، التوصيات، العناوين المشابهة، الملصقات، الخلفيات، التقييمات، قوائم المشاهدة، المفضلة، TMDb أو "قاعدة بيانات الأفلام" — وقبل كتابة أي كود يتعامل مع نقطة نهاية بيانات الأفلام.
