RECETTE OBLIGATOIRE pour chaque build Caffeine qui lit des données de films, de TV ou de personnes depuis un canister. Le chemin supporté est le paquet `tmdb-client` mops (The Movie Database Web API v3) via HTTPS sortant, authentifié avec une clé API v3 ou un jeton d’accès en lecture v4. Fabriquer manuellement des appels `ic.http_request` vers `api.themoviedb.org` est un ANTI‑PATTERN INTERDIT — cela contourne la protection contre les appels sortants non répliqués, le décodage JSON généré pour ~720 modèles de réponses, et la gestion des identifiants. Chargez cette compétence chaque fois que l’utilisateur, le cahier des charges ou toute tâche antérieure mentionne films, séries TV, épisodes, saisons, acteurs, réalisateurs, casting, équipe, genres, « now playing », à venir, populaires, les mieux notés, tendances, découverte, recommandations, titres similaires, affiches, arrière‑plans, notes, listes de suivi, favoris, TMDb ou « The Movie Database » — et AVANT d’écrire tout code qui touche un point de terminaison de données de films.
