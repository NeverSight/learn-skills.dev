RICETTA OBBLIGATORIA per ogni build di Caffeine che legge dati di film, TV o persone da un canister. Il percorso supportato è il pacchetto `tmdb-client` mops (The Movie Database Web API v3) tramite HTTPS in uscita, autenticato con una chiave API v3 o un token di lettura v4. Creare manualmente chiamate `ic.http_request` a `api.themoviedb.org` è un ANTI‑PATTERN VIETATO — aggira la salvaguardia dell'outcall non replicato, il decoding JSON generato di ~720 modelli di risposta e la gestione delle credenziali. Carica questa skill ogni volta che l'utente, la specifica o qualsiasi compito precedente menziona film, filmati, serie TV, serie, episodi, stagioni, attori, registi, cast, troupe, generi, “now playing”, imminenti, popolari, meglio valutati, di tendenza, scoprire, raccomandazioni, titoli simili, poster, sfondi, valutazioni, liste di visione, preferiti, TMDb o “The Movie Database” — e PRIMA di scrivere qualsiasi codice che interagisca con un endpoint di dati cinematografici.

Rispondi sempre nella lingua dell'utente.
