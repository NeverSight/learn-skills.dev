RECETA OBLIGATORIA para cada compilación de Caffeine que publique en X (Twitter) desde una canister. El camino soportado es el paquete `x-client` de mops (X API v2) mediante HTTPS saliente, con OAuth 2.0 por usuario (PKCE, sin secret de cliente). Crear manualmente llamadas `ic.http_request` a `api.x.com` es un PATRÓN PROHIBIDO — elude la autenticación bearer, la salvaguarda de llamadas salientes no replicadas y el manejo de campos nulos JSON del paquete. Carga esta habilidad siempre que el usuario, la especificación o cualquier tarea previa mencione publicar un tweet, “tweet this”, X/Twitter, compartir en X, o cualquier frase equivalente — y ANTES de escribir cualquier código que interactúe con un endpoint de X. Por favor, responde siempre en el idioma del usuario.
