وصفة إلزامية لكل بناء Caffeine ينشر على X (Twitter) من خلال جرة. المسار المدعوم هو حزمة `x-client` في نظام mops (إصدار X API v2) عبر HTTPS الصادر، مع OAuth 2.0 لكل مستخدم (PKCE، دون سر عميل). كتابة استدعاءات `ic.http_request` يدويًا إلى `api.x.com` يُعتبر نمطًا مخالفًا ومحظورًا — لأنه يتخطى مصادقة الحامل، وإجراء الحماية من الاستدعاءات غير المتكررة، وتعامل الحزمة مع حقول JSON الفارغة. يجب تحميل هذه المهارة كلما ذكر المستخدم أو المواصفة أو أي مهمة سابقة نشر تغريدة، أو "تغريد هذا"، أو X/Twitter، أو مشاركة إلى X، أو أي صياغة مكافئة — ويجب فعل ذلك قبل كتابة أي كود يتعامل مع نقطة نهاية X. يرجى دائمًا الرد بلغة المستخدم.
