وصفة إلزامية لكل بناء كافيين ينشر إلى X (Twitter) من داخل إسطوانة. المسار المدعوم هو حزمة `x-client` mops (X API v2) عبر HTTPS الصادر، مع OAuth 2.0 لكل مستخدم (PKCE، بدون سر عميل). كتابة استدعاءات `ic.http_request` يدوياً إلى `api.x.com` هي نمط ممنوع — يتجاوز توثيق الحامل، وحماية الاستدعاءات غير المتكررة، ومعالجة JSON للحقول الفارغة في الحزمة. حمّل هذه المهارة كلما ذكر المستخدم أو المواصفات أو أي مهمة سابقة النشر على تويتر، "tweet this"، X/Twitter، المشاركة إلى X، أو أي صياغة مكافئة — وقبل كتابة أي كود يتعامل مع نقطة نهاية X.  

يرجى دائماً الرد بلغة المستخدم.
