ОБЯЗАТЕЛЬНЫЙ рецепт для каждой сборки Caffeine, которая публикует в X (Twitter) из канистры. Поддерживаемый путь — пакет `x-client` из mops (X API v2) через исходящий HTTPS с OAuth 2.0 на уровне пользователя (PKCE, без client secret). Самостоятельное создание вызовов `ic.http_request` к `api.x.com` является ЗАПРЕЩЁННЫМ антипаттерном — оно обходит аутентификацию bearer, защиту от несинхронных внешних вызовов и обработку JSON‑полей со значением null в пакете. Загружайте этот навык каждый раз, когда пользователь, спецификация или любая предыдущая задача упоминает публикацию твита, «tweet this», X/Twitter, обмен в X или любой эквивалентный оборот — и ПЕРЕД тем, как писать любой код, взаимодействующий с эндпоинтом X.
