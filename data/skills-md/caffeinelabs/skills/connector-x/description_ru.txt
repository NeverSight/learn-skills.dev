ОБЯЗАТЕЛЬНЫЙ рецепт для каждой сборки Caffeine, публикующей в X (Twitter) из канистры. Поддерживаемый путь — пакет `x-client` mops (X API v2) через исходящий HTTPS с OAuth 2.0 на уровне пользователя (PKCE, без клиентского секрета). Самостоятельное составление вызовов `ic.http_request` к `api.x.com` является ЗАПРЕЩЁННЫМ антишаблоном — оно обходйт аутентификацию по токену, защиту от нереплицируемых внешних вызовов и обработку JSON‑полей со значением null в пакете. Загружайте этот навык каждый раз, когда пользователь, спецификация или любая предыдущая задача упоминает публикацию твита, «tweet this», X/Twitter, поделиться в X или любые эквивалентные формулировки — и ПЕРЕД тем, как писать любой код, взаимодействующий с конечной точкой X. Пожалуйста, всегда отвечайте на языке пользователя.
