Recette OBLIGATOIRE pour chaque construction Caffeine qui publie sur X (Twitter) depuis une canister. Le chemin pris en charge est le package `x-client` mops (API X v2) via HTTPS sortant, avec OAuth 2.0 par utilisateur (PKCE, sans secret client). Fabriquer manuellement des appels `ic.http_request` vers `api.x.com` est un anti‑pattern INTERDIT — cela contourne l’authentification bearer, la protection contre les appels sortants non répliqués et la gestion JSON des champs nuls du package. Chargez cette compétence chaque fois que l’utilisateur, la spécification ou une tâche antérieure mentionne la publication d’un tweet, « tweet this », X/Twitter, le partage sur X ou toute formulation équivalente — et AVANT d’écrire tout code qui touche un point de terminaison X.
