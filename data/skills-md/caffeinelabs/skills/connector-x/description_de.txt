VERPFLICHTENDE Anleitung für jede Caffeine‑Build, die von einem Canister aus zu X (Twitter) postet. Der unterstützte Weg ist das `x-client`‑Mops‑Paket (X API v2) über ausgehendes HTTPS, mit OAuth 2.0 pro Nutzer (PKCE, kein Client‑Secret). Das eigenständige Erstellen von `ic.http_request`‑Aufrufen zu `api.x.com` ist ein VERBOTENES Anti‑Pattern – es umgeht die Bearer‑Authentifizierung, die Nicht‑repizierte‑Outbound‑Call‑Sicherung und die Null‑Feld‑JSON‑Verarbeitung des Pakets. Lade diese Fähigkeit, sobald der Benutzer, das Spec oder eine vorherige Aufgabe das Posten eines Tweets, „tweet this“, X/Twitter, das Teilen auf X oder eine gleichwertige Formulierung erwähnt – und zwar VOR dem Schreiben von Code, der einen X‑Endpunkt berührt.
