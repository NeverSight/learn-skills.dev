每個從罐子發佈到 X（Twitter）的 Caffeine 構建都必須遵守的配方。支援的路徑是透過出站 HTTPS 使用 `x-client` mops 套件（X API v2），並以每位使用者的 OAuth 2.0（PKCE，無客戶端密鑰）進行驗證。自行手動呼叫 `ic.http_request` 連至 `api.x.com` 是被禁止的反模式——它會繞過 bearer 認證、非複寫的外部呼叫保護機制，以及套件的 null‑field JSON 處理。每當使用者、規格或任何先前任務提到發佈推文、"tweet this"、X/Twitter、分享至 X，或任何等同表述時，都要載入此技能，且必須在撰寫任何觸及 X 端點的程式碼之前進行。
