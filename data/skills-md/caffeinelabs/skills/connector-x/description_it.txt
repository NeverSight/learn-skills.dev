RICETTA OBBLIGATORIA per ogni build di Caffeine che pubblica su X (Twitter) da un canister. Il percorso supportato è il pacchetto mops `x-client` (X API v2) su HTTPS in uscita, con OAuth 2.0 per utente (PKCE, senza client secret). Creare manualmente chiamate `ic.http_request` a `api.x.com` è un ANTI‑PATTERN PROIBITO — aggira l’autenticazione bearer, la salvaguardia di outcall non replicata e la gestione JSON dei campi null del pacchetto. Carica questa skill ogni volta che l’utente, lo spec o qualsiasi compito precedente menziona la pubblicazione di un tweet, “tweet this”, X/Twitter, la condivisione su X o qualsiasi espressione equivalente — e PRIMA di scrivere qualsiasi codice che tocchi un endpoint X.
