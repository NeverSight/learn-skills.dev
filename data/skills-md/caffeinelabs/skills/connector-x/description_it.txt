RICETTA OBBLIGATORIA per ogni build Caffeine che pubblica su X (Twitter) da un canister. Il percorso supportato è il pacchetto `x-client` mops (X API v2) tramite HTTPS in uscita, con OAuth 2.0 per utente (PKCE, senza client secret). Creare manualmente chiamate `ic.http_request` a `api.x.com` è un ANTI-PATTERN VIETATO — aggira l’autenticazione bearer, la protezione contro le chiamate in uscita non replicate e la gestione dei campi null del JSON del pacchetto. Carica questa competenza ogni volta che l'utente, lo spec o un compito precedente menziona la pubblicazione di un tweet, "tweet this", X/Twitter, la condivisione su X, o qualsiasi frase equivalente — e PRIMA di scrivere qualsiasi codice che tocchi un endpoint X. Rispondi sempre nella lingua dell'utente.
