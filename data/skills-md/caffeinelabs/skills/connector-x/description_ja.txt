X（Twitter）へカンスターから投稿するすべての Caffeine ビルドに必須のレシピです。サポートされているパスは `x-client` mops パッケージ（X API v2）を介したアウトバウンド HTTPS で、ユーザーごとの OAuth 2.0（PKCE、クライアントシークレットなし）です。`ic.http_request` を使って `api.x.com` へ直接呼び出すことは禁止されたアンチパターンです——ベアラートークン認証をバイパスし、非レプリケートアウトコールの保護機能を無効化し、パッケージの null フィールド JSON 処理を回避します。ユーザー、仕様、あるいは過去のタスクが「ツイートする」「ツイートしてください」「X/Twitter に共有」など、X へ投稿する旨の言及がある場合は、必ずこのスキルをロードし、X エンドポイントに触れるコードを書く前に実行してください。
