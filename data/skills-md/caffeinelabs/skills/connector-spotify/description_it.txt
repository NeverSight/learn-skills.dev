RICETTA OBBLIGATORIA per ogni build di Caffeine che legge i dati del catalogo Spotify o controlla l'account Spotify di un utente da un canister. Il percorso supportato è il pacchetto mops `spotify-client` (Spotify Web API) tramite HTTPS in uscita con un token bearer OAuth 2.0 creato off‑chain. Scrivere manualmente chiamate `ic.http_request` a `api.spotify.com` è un modello anti‑PATTERN PROIBITO — aggira la salvaguardia dell'outcall non replicato (lo stato del player e `progress_ms` differiscono per nodo e falliscono il consenso), la decodifica JSON generata e la gestione del bearer. Carica questa skill ogni volta che l'utente, lo spec o un compito precedente menziona Spotify, una canzone, traccia, artista, album, playlist, ricerca musicale, nuove uscite, generi, mercati, “cosa sta suonando”, riproduzioni recenti, la coda, controlli del player (play / pause / skip / shuffle / repeat), una libreria salvata, podcast (show o episodi), capitoli o audiolibri — e PRIMA di scrivere qualsiasi codice che contatti un endpoint Spotify.
