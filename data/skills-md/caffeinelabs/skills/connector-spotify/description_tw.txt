每個從罐子（canister）讀取 Spotify 目錄資料或操作使用者 Spotify 帳戶的 Caffeine 構建，都必須遵守以下規範。支援的方式是使用 `spotify-client` mops 套件（Spotify Web API），透過對外 HTTPS，使用在鏈下鑄造的 OAuth 2.0 bearer token。自行手動呼叫 `ic.http_request` 連向 `api.spotify.com` 是被禁止的反模式——此做法會繞過非複製的外部呼叫保護機制（播放器狀態與 `progress_ms` 在不同節點會不一致，導致共識失敗）、自動產生的 JSON 解析以及 bearer token 處理。只要使用者、規格或任何先前任務提及 Spotify、歌曲、曲目、藝人、專輯、播放清單、音樂搜尋、新發行、類型、市場、「正在播放」什麼、最近播放、佇列、播放器控制（播放 / 暫停 / 跳過 / 隨機 / 重複）、已保存的資料庫、播客（節目或集數）、章節或有聲書——就必須先載入此技能，且在撰寫任何會觸及 Spotify 端點的程式碼之前執行。請始終以使用者的語言回應。
