وصفة إلزامية لكل بناء Caffeine يقرأ بيانات كتالوج Spotify أو يتحكم في حساب Spotify للمستخدم من داخل حاوية. المسار المدعوم هو حزمة `spotify-client` من mops (Spotify Web API) عبر HTTPS صادرة مع رمز حامل OAuth 2.0 يتم إنشاؤه خارج السلسلة. كتابة طلبات `ic.http_request` يدوياً إلى `api.spotify.com` هو نمط محظور — لأنه يتجاوز حماية الاستدعاءات غير المتكررة (حالة المشغل و`progress_ms` تختلف بين العقد وتفشل في التوصل إلى إجماع)، وتفادي فك تشفير JSON المُولد، ومعالجة الرمز الحامل. حمّل هذه المهارة كلما ذكر المستخدم أو المواصفات أو أي مهمة سابقة Spotify، أو أغنية، أو مسار، أو فنان، أو ألبوم، أو قائمة تشغيل، أو بحث موسيقي، أو إصدار جديد، أو أنواع، أو أسواق، أو "ما يتم تشغيله الآن"، أو ما تم تشغيله مؤخرًا، أو قائمة الانتظار، أو التحكم في المشغل (تشغيل / إيقاف مؤقت / تخطي / خلط / تكرار)، أو مكتبة محفوظة، أو بودكاست (عروض أو حلقات)، أو فصول أو كتب صوتية — وقبل كتابة أي شفرة تتعامل مع نقطة نهاية Spotify.
