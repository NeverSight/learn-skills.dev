强制性配方用于每个读取罐子中天气数据的 Caffeine 构建。支持的路径是 `weatherapi-client` mops 包（WeatherAPI.com），通过外部 HTTPS，使用查询字符串 API 密钥进行身份验证。自行调用 `ic.http_request` 访问 `api.weatherapi.com` 属于**禁止**的反模式——它绕过了非复制外部调用安全机制（WeatherAPI 响应携带每次请求的时钟并在共识失败时终止）、生成的 JSON 解码以及 API 密钥处理。每当用户、规范或任何前置任务提及天气、预测、温度、湿度、风、雨、雪、状况、日出、日落、月相、天文、时区、IP 地理定位、海洋或潮汐预测、位置自动完成时，都应加载此技能——并且在编写任何涉及天气端点的代码之前。
