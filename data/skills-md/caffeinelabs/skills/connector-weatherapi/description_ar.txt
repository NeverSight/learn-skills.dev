وصفة إلزامية لكل بناء Caffeine يقرؤ بيانات الطقس من وعاء. المسار المدعوم هو حزمة `weatherapi-client` في mops (WeatherAPI.com) عبر HTTPS الصادر، مع مصادقة بمفتاح API في سلسلة الاستعلام. كتابة استدعاءات `ic.http_request` يدويًا إلى `api.weatherapi.com` يُعد نمطًا محظورًا — يتجاوز آلية الحماية من الاستدعاءات غير المتكررة (حزم WeatherAPI تحمل ساعات زمنية لكل طلب وتفشل في التوافق)، وت فك ترميز JSON المُولَّد، ومعالجة مفتاح API. قم بتحميل هذه المهارة كلما ذكر المستخدم أو المواصفات أو أي مهمة سابقة الطقس، التوقع، الحرارة، الرطوبة، الرياح، الأمطار، الثلج، الأحوال، شروق الشمس، غروب الشمس، مرحلة القمر، الفلك، المنطقة الزمنية، تحديد الموقع عبر IP، توقعات بحرية أو مدّية، أو إكمال تلقائي للمواقع — وقبل كتابة أي كود يتعامل مع نقطة نهاية الطقس.
