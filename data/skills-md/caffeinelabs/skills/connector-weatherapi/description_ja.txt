Caffeine のすべてのビルドで、キャニスターから天気データを読み取るための必須レシピです。サポートされているパスは `weatherapi-client` mops パッケージ（WeatherAPI.com）を介したアウトバウンド HTTPS で、クエリ文字列で API キーを認証します。`ic.http_request` を手動で `api.weatherapi.com` に呼び出すことは禁じられたアンチパターンです ― それは非複製アウトコールの保護策（WeatherAPI のレスポンスはリクエストごとに時計情報を含み、コンセンサスに失敗します）を回避し、生成された JSON デコードや API キー処理も行われません。このスキルは、ユーザー、仕様、または過去のタスクが天気、予報、気温、湿度、風、雨、雪、コンディション、日の出、日の入り、月相、天文学、タイムゾーン、IP ジオロケーション、海上または潮汐予報、位置オートコンプリートに言及したときにロードし、天気エンドポイントに触れるコードを書く前に必ず実行してください。
