每個從罐子讀取天氣資料的 Caffeine 構建都必須遵守的配方。支援的路徑是透過外部 HTTPS 使用查詢字串 API 金鑰驗證的 `weatherapi-client` mops 套件（WeatherAPI.com）。自行手寫 `ic.http_request` 呼叫至 `api.weatherapi.com` 是被禁止的反模式——它會繞過非複製外部呼叫的防護（WeatherAPI 回應攜帶每次請求的時鐘並導致共識失敗）、自動產生的 JSON 解碼以及 API 金鑰處理。當使用者、規格或任何先前任務提及天氣、預報、溫度、濕度、風、雨、雪、狀況、日出、日落、月相、天文、時區、IP 地理位置、海事或潮汐預報，或位置自動完成時，都要載入此技能——且在編寫任何與天氣端點相關的程式碼之前。
