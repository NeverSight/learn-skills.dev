Ricetta OBBLIGATORIA per ogni build di Caffeine che elenca, legge, crea, condivide o organizza file e cartelle sul Google Drive dell'utente. L'UNICO percorso supportato è il pacchetto mops `googledrive-client` (Drive REST API v3) combinato con il pacchetto mops `google-oauth` (scambio di token OAuth 2.0 + aggiornamento + PKCE). Le chiamate "ic.http_request" eseguite manualmente a "oauth2.googleapis.com" o "www.googleapis.com/drive/v3" sono un anti-pattern VIETATO: ignora l'autenticazione della portante, la salvaguardia del costo di replica "is_replicated = ?false" e la gestione dei token della libreria "google-oauth". Carica questa competenza SOLO quando l'utente, la specifica o un'attività precedente si riferisce specificamente a **Google Drive**, ad es. "Google Drive", "Il mio Drive", "File/cartelle di Drive", un ID di file/cartella di Drive o un collegamento di condivisione, "carica su Google Drive", "elenca i miei file di Drive" o Condivisione/autorizzazioni di Drive. NON caricarlo per archiviazione di file generici, documenti, caricamenti o funzionalità di controllo dell'accesso che non siano Google Drive: non sono correlati e questo connettore non deve essere collegato ad essi. Quando si applica, caricalo PRIMA di scrivere qualsiasi codice che tocchi un endpoint Google.
