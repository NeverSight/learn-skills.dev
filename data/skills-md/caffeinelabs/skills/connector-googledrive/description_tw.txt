每個 Caffeine 建立的強製配方，用於列出、讀取、建立、共享或組織使用者自己的 Google 雲端硬碟上的檔案和資料夾。唯一支援的路徑是「googledrive-client」mops 套件（Drive REST API v3）與「google-oauth」mops 套件（OAuth 2.0 令牌交換 + 刷新 + PKCE）結合。手動呼叫「ic.http_request」對「oauth2.googleapis.com」或「www.googleapis.com/drive/v3」是一種禁止的反模式——它繞過了承載身份驗證、「is_replicated = ?false」複製成本保護以及「google-oauth」庫的令牌處理。僅當用戶、規範或之前的任務專門引用 **Google Drive** 時加載此技能 - 例如“Google 雲端硬盤”、“我的雲端硬盤”、“雲端硬盤文件/文件夾”、雲端硬盤文件/文件夾 ID 或共享鏈接、“上傳到 Google 雲端硬盤”、“列出我的雲端硬盤文件”或云端硬盤共享/權限。請勿將其載入用於非 Google Drive 的通用文件儲存、文件、上傳或存取控制功能 - 這些功能不相關，並且不得將此連接器附加到它們。當它確實適用時，請在編寫任何涉及 Google 端點的程式碼之前載入它。
