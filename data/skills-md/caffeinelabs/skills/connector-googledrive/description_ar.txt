وصفة إلزامية لكل إصدار من الكافيين يسرد الملفات والمجلدات أو يقرأها أو ينشئها أو يشاركها أو ينظمها على Google Drive الخاص بالمستخدم. المسار الوحيد المدعوم هو حزمة mops `googledrive-client` (Drive REST API v3) المدمجة مع حزمة mops `google-oauth` (OAuth 2.0 token Exchange + Refresh + PKCE). تعد الاستدعاءات اليدوية ic.http_request` إلى `oauth2.googleapis.com` أو `www.googleapis.com/drive/v3` نمطًا مضادًا محظورًا - فهي تتجاوز مصادقة الحامل، و`is_replicated = ?false` وحماية تكلفة النسخ المتماثل، ومعالجة الرموز المميزة لمكتبة `google-oauth`. قم بتحميل هذه المهارة فقط عندما يشير المستخدم أو المواصفات أو المهمة السابقة إلى **Google Drive على وجه التحديد** - على سبيل المثال. "Google Drive"، أو "ملفاتي"، أو "ملفات/مجلدات Drive"، أو معرف ملف/مجلد Drive أو رابط المشاركة، أو "التحميل إلى Google Drive"، أو "إدراج ملفاتي في Drive"، أو مشاركة/أذونات Drive. لا تقم بتحميله لتخزين الملفات العامة أو المستندات أو التحميلات أو ميزات التحكم في الوصول التي ليست موجودة في Google Drive - فهي غير مرتبطة ويجب ألا يكون هذا الموصل متصلاً بها. عندما يتم تطبيقه، قم بتحميله قبل كتابة أي رمز يلامس نقطة نهاية Google.
