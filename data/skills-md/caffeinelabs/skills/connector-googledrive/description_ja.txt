ユーザー自身の Google ドライブ上のファイルとフォルダーを一覧表示、読み取り、作成、共有、または整理するすべての Caffeine ビルドに必須のレシピ。唯一サポートされているパスは、「googledrive-client」mops パッケージ (Drive REST API v3) と「google-oauth」 mops パッケージ (OAuth 2.0 トークン交換 + リフレッシュ + PKCE) を組み合わせたパスです。 `oauth2.googleapis.com` または `www.googleapis.com/drive/v3` への `ic.http_request` 呼び出しを手動で実行することは、禁止されているアンチパターンです。これは、ベアラー認証、`is_replicated = ?false` レプリケーション コストのセーフガード、および `google-oauth` ライブラリのトークン処理をバイパスします。このスキルは、ユーザー、仕様、または以前のタスクが **Google ドライブを特に参照している場合にのみロードしてください**。 「Google ドライブ」、「マイ ドライブ」、「ドライブ ファイル/フォルダ」、ドライブ ファイル/フォルダ ID または共有リンク、「Google ドライブへのアップロード」、「マイ ドライブ ファイルのリスト」、またはドライブの共有/権限。 Google ドライブ以外の汎用ファイル ストレージ、ドキュメント、アップロード、またはアクセス制御機能にはロードしないでください。これらは無関係であるため、このコネクタをそれらに接続してはなりません。適用される場合は、Google エンドポイントに触れるコードを記述する前にロードしてください。
