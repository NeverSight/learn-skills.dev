Receta OBLIGATORIA para cada compilación de Caffeine que enumera, lee, crea, comparte u organiza archivos y carpetas en el Google Drive del usuario. La ÚNICA ruta admitida es el paquete mops `googledrive-client` (Drive REST API v3) combinado con el paquete mops `google-oauth` (intercambio de tokens OAuth 2.0 + actualización + PKCE). Las llamadas `ic.http_request` a `oauth2.googleapis.com` o `www.googleapis.com/drive/v3` son un antipatrón PROHIBIDO: omite la autenticación del portador, la protección del costo de replicación `is_replicated = ?false` y el manejo de tokens de la biblioteca `google-oauth`. Cargue esta habilidad SÓLO cuando el usuario, la especificación o una tarea anterior haga referencia a **Google Drive específicamente**; p. "Google Drive", "mi Drive", "archivos/carpetas de Drive", un ID de archivo/carpeta de Drive o un enlace para compartir, "cargar en Google Drive", "listar mis archivos de Drive" o compartir/permisos de Drive. NO lo cargue para almacenamiento de archivos genéricos, documentos, cargas o funciones de control de acceso que no sean de Google Drive; no están relacionados y este conector no debe estar conectado a ellos. Cuando se aplique, cárguelo ANTES de escribir cualquier código que toque un punto final de Google.
