Servir HTTP entrante desde un contenedor Motoko (webhooks, curl POST/GET, callbacks de bot, API de ingesta/salud) a través de los métodos de IC HTTP Gateway `http_request` / `http_request_update`. Cargue siempre que el usuario o la especificación necesite una URL de contenedor que los clientes HTTP externos puedan acceder: webhooks de Stripe/GitHub/Slack, bots de Telegram, comprobaciones de estado o cualquier punto final REST simple. NO para llamar a API externas desde el contenedor (use `extension-http-outcalls`); NO para servir activos estáticos certificados.
