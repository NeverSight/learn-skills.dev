Fornisci HTTP in entrata da un canister Motoko (webhook, curl POST/GET, callback bot, API di ingest/health) tramite i metodi del gateway HTTP IC `http_request` / `http_request_update`. Utilizzalo quando l'utente o le specifiche richiedono un URL del canister che i client HTTP esterni possono colpire — webhook di Stripe/GitHub/Slack, bot di Telegram, controlli di salute o qualsiasi endpoint REST‑ish semplice. NON è destinato a chiamare API esterne dal canister (usa `extension-http-outcalls`); NON è per servire asset statici certificati.
