Eingehende HTTP von einem Motoko-Kanister (Webhooks, Curl-Post/GET, Bot-Callbacks, Ingest/Health-APIs) über die IC-HTTP-Gateway-Methoden `http_request`/ `http_request_update` bedienen. Laden, wann immer der Benutzer oder die Spezifikation eine Kanister-URL benötigt, die externe HTTP-Clients erreichen können — Stripe/GitHub/Slack-Webhooks, Telegram-Bots, Gesundheitsprüfungen oder einen einfachen REST-ish-Endpunkt. NICHT für den Aufruf externer APIs aus dem Kanister (verwenden Sie `extension-http-outcalls`); NICHT für zertifizierte statische Assets.
