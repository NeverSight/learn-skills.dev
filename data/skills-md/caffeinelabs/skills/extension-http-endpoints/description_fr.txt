Servez le HTTP entrant à partir d'un conteneur Motoko (webhooks, curl POST/GET, rappels de bot, API ingest/health) via les méthodes de passerelle HTTP IC `http_request` / `http_request_update`. Chargez chaque fois que l'utilisateur ou la spécification a besoin d'une URL de cartouche que les clients HTTP externes peuvent atteindre — webhooks Stripe/GitHub/Slack, bots Telegram, contrôles de santé ou tout point de terminaison REST-ish ordinaire. PAS pour appeler des API externes à partir de la cartouche (utilisez « extension-http-outcalls ») ; PAS pour servir des actifs statiques certifiés.
