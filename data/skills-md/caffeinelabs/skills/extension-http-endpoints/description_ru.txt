Обслуживание входящего HTTP из канистры Motoko (вебхуки, curl POST/GET, обратные вызовы ботов, API для ingest/health) через методы HTTP‑шлюза IC `http_request` / `http_request_update`. Используйте, когда пользователю или спецификации нужен URL канистры, доступный внешним HTTP‑клиентам — вебхуки Stripe/GitHub/Slack, боты Telegram, проверки работоспособности или любой простой REST‑подобный эндпоинт. НЕ предназначено для вызова внешних API из канистры (используйте `extension-http-outcalls`); НЕ предназначено для сертифицированной выдачи статических ресурсов.

Пожалуйста, всегда отвечайте на языке пользователя.
