قدّم خدمة HTTP الواردة من حاوية Motoko (webhooks، curl POST/GET، ردود الروبوت، APIs الإدخال/الصحة) عبر طرق بوابة HTTP الخاصة بـ IC `http_request` / `http_request_update`. استخدمها كلما احتاج المستخدم أو المواصفة إلى عنوان URL للحاوية يمكن للعملاء الخارجيين الوصول إليه — webhooks من Stripe/GitHub/Slack، بوتات Telegram، فحوصات الصحة، أو أي نقطة نهاية REST بسيطة. ليس للاستدعاء الخارجي للـ APIs من الحاوية (استخدم `extension-http-outcalls`)؛ ليس لتقديم أصول ثابتة معتمدة.
