Аудит токенно‑гигиеничности постоянно загруженного стека контекста — CLAUDE.md, AGENTS.md, автопамяти MEMORY.md и файлов идентичности, сгенерированных при загрузке (SOUL.md, USER.md, ACCESS_POLICY.md, HEARTBEAT.md) или их эквивалентов‑обёрток. Находит избыточность, противоречия, устаревшее содержание, кандидаты на сжатие и кандидаты на извлечение навыков; формирует ранжированный список действий, отсортированный по экономии токенов, с указанием класса риска для каждого обнаружения. ТОЛЬКО ОТЧЁТ: этот навык никогда не редактирует проверяемые файлы. Рекомендации для файлов, сгенерированных при загрузке, ориентированы на банк ответов / шаблоны интервью, а не на уже отрендеренный вывод. Оценка маршрутов производится через `gbrain eval cross-modal` (по умолчанию один недорогой модел, полная панель из нескольких моделей доступна только при явном согласии).
