Filtrer les questions d'identité vers l'utilisateur. Avant que toute question du type « qui est X ? » (ou question de rôle / relation) n'atteigne l'utilisateur, épuiser la chaîne de recherche du cerveau : réfléchir → chercher + lire la page → sources montées → chronologie / graphe → web. Si l'escalade survit à la chaîne, poser la question AVEC une hypothèse, jamais un inconnu pur. Applique également la règle « pas de placeholders à l'ingestion » : les pages créées lors de l'ingestion en masse voient leur relation / rôle résolu immédiatement.

Veuillez toujours répondre dans la langue de l'utilisateur.
