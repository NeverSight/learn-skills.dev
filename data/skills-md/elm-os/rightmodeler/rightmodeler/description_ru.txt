Найдите, где в конвейере агента можно заменить передовые модели на более дешёвые без потери качества. Управляйте установленным CLI rightmodeler на TypeScript через его возобновляемый конвейер, интерпретируйте его машинный протокол, предоставляйте вердикты по каждой семье и открывайте проверенный pull request на замену модели, когда доказательства этому подтверждают. Используйте, когда пользователь хочет сократить расходы на модели, подобрать модели под задачи, протестировать более дешёвые замены моделей или проанализировать агентный конвейер для оптимизации расходов.
