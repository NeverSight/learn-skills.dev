قم بتشغيل شجرة العمل المدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج من خلال سطر أوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّله على شجرة git الخام، PTYs المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متضمنة. استخدم استخدام الكمبيوتر فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو API القيام بذلك.
