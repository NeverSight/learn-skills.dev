通过 `orca` CLI 操作 Orca 管理的工作树、文件夹上下文、终端、仓库、自动化、制品、技能共享、工作树注释以及 Orca 嵌入式浏览器。用户在说“$orca-cli”“Orca worktree”“child worktree”“spawn codex/claude in a worktree”“read/wait/send Orca terminal”“handoff”“handover”“give this to another agent”“Orca browser”“orca artifacts”或“share skills”等时使用。涉及 Orca 状态时，优先使用它，而不是原始 git worktree、临时 PTY 或 Computer Use。当需要对可见窗口进行 GUI 控制且 CLI、文件系统或 API 无法实现时，才使用 Computer Use。请始终使用用户的语言作答。
