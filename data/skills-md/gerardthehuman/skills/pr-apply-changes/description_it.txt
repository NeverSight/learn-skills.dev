Applicare le modifiche provenienti dalla conversazione corrente, da un piano di implementazione, dal feedback della revisione, dalle segnalazioni di problemi o dal lavoro di follow‑up di una PR, quindi integrarle nei commit corretti. Usare quando l'utente chiede di applicare le modifiche richieste, implementare un piano concordato, correggere i problemi trovati in revisione, affrontare il feedback dei problemi o inserire le correzioni di follow‑up in un branch o PR.
