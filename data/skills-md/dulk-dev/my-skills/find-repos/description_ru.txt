Находит и оценивает открытые репозитории‑референсы с помощью GitHub CLI и веб‑поиска, а также прослеживает реальные реализации из исходного кода с помощью Grep MCP. Используйте, когда пользователи запрашивают референс‑проекты, конкурирующие реализации, репозитории GitHub, примеры использования кода или при подготовке к реализации общих функций с нуля.
