Создаёт каркас, обеспечивает подготовку и развёртывает корпоративную бессерверную многокомпонентную RAG‑систему в Google Cloud Platform, используя Google ADK, Vertex AI Agent Runtime (Agent Engine), сервисы Vertex AI Session & Memory Bank, Cloud DLP, Pub/Sub, удалённые модели BigQuery ML и Vertex AI Search. Применяется при построении или развертывании корпоративных многокомпонентных систем на GCP, добавлении конфиденциальности‑сохраняющего RAG или настройке управляемой памяти агентов.
