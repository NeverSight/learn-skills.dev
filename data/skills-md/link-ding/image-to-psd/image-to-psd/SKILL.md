# image-to-psd

保留画风、颜色、姿势、位置和画布大小。只交付分层 PSD，标准为 19 层。部件参考图、透明 PNG 和审核预览只用于制作和检查。默认仅保留原画嘴型，不自动加入五元音。缺失部件保留为空层。需要让手与道具分别移动、且有前后交错遮挡时，按部件规范使用可选的 20 层布局。

## 工作流

1. 查看原画；有参考 PSD 时读取尺寸、图层名称、顺序、偏移、透明通道和独立蒙版。先检查用户已有文件以避免重复创建。附件使用已提供的本地副本。
2. 读取 [部件规范](references/layers.md)，确定英文名称和归属。区分分割、遮挡补形、文件转换与动画绑定；不要宣称某一步自动完成其他步骤。
3. 新原画拆层时，先按 [部件参考图与混合拆层](references/layer-review.md#部件参考图与混合拆层) 用 ImageGen 生成部件参考图，再开始分割和导出。用户已提供同角色、同姿势的合适部件图时直接复用。单独修复已有图层或转换合格 SVG 时，按对应流程处理。
4. 为当前图建立部件边界及遮挡关系。在放大的原画局部共同标注相邻部件的可见边界与线稿归属，再据此分层。优先处理手／袖口／道具、头饰／头发与刘海／脸。先读取 [浅色部件与透明度检查](references/transparency.md)：不能按白色或近白色阈值直接删除背景；衣服、袖子、头发等浅色实体必须保留实色底形。生成式补画或位图编辑使用当前适用的图像工具与规范。不要把上一角色的绝对坐标套在新图上。
5. 从原画分割可见轮廓、五官、纹理和笔触。用通过审核的生成部件对齐原画坐标后，限在遮挡或确有缺损的区域补形。合成后按原画复核表情、手势和可见轮廓。把脸补成连续底形，眉毛、鼻子、嘴下面不得镂空；用共同眼裂边界拆分眼白、虹膜与睫毛，按[眼部专项验收](references/layer-review.md#眼部专项验收)补全眼白并检查串层。补后发、脖子、衣服接缝，注明是推补。不要凭空扩展未入画的身体。
6. 单独检查每层：不能把同一整张图复制成不同名称；各层须有正确透明度，不能用全白蒙版冒充部件分割。左右眉毛、眼白、瞳孔、睫毛分别同层，保留左右两个不相连区域。
7. 用全画布同坐标的透明部件 PNG，通过 `psd-png` 直接导出 PSD。已有合格的分层 SVG 可以作为输入，通过 `psd` 转成 PSD。按需安装 `pillow numpy psd-tools`，读取 SVG 输入时还需 `cairosvg`。

   ```bash
   python <skill_root>/scripts/layered_assets.py psd-png parts.json character.psd --report qa.json
   python <skill_root>/scripts/layered_assets.py psd existing.svg character.psd --report qa.json
   ```

8. 为每个部件保留独立的 RGBA 像素层与同尺寸灰度蒙版。像素 alpha 保留原有边缘和半透明材质，蒙版只标记像素是否属于该层的可见覆盖范围（alpha 大于零为 255，其余为 0）。导出后重读，核对有效像素、alpha、蒙版及合成。保留空层。PSD 像素与蒙版均可单独编辑。
9. **交付前自查。** 将首次导出的 PSD 视为初稿。重新读取 PSD，按[交付前自查清单](references/layer-review.md#交付前自查清单)依次验证文件结构、原位合成、逐层内容和遮挡位移。眼部有虹膜时必须单看眼白、关闭虹膜看合成、左右移动虹膜。
10. 自查发现问题时，定位到串层、误裁、遮挡缺失或格式转换。修正部件源或出错的导出环节，重新导出 PSD，重读新文件，复验修复区域、相邻层及原位合成。先检查已有部件参考图是否能用于补形，必要时按规范调用 ImageGen 生成局部候选。现有 PSD 若为唯一可编辑源，保留各层的像素、蒙版和坐标再修复。
11. 用户报告缺层或碎片时读取 [兼容性排查](references/compatibility.md)。不同解析器读取成功不等于目标动画软件已验证；不把缺蒙版说成未经确认的唯一根因。
12. 按当前文件规范保存 PSD；修复已有文件保留其持久化身份。只提供 PSD，简述生成式补形、仍有疑点的部位和目标软件验证的实际限度。不附带内部 QA、临时 PNG、脚本或原画，除非用户要求。

## PNG 输入清单

使用 UTF-8 JSON。每张 PNG 与画布同尺寸、同位置，背景透明。`layers` 从后到前排列；未出现的标准名称自动补空层，省略 `png` 也表示空层。需要前后交错的手与道具时，省略 `handwear`，按后到前明确列出 `handwear back`、`objects`、`handwear front`。路径相对于清单。

```json
{"width":1254,"height":1254,"layers":[
  {"name":"back hair","png":"parts/back_hair.png"},
  {"name":"face","png":"parts/face.png"},
  {"name":"front hair","png":"parts/front_hair.png"}
]}
```

尺寸仅为示例。每张新图重新判断语义边界。本技能提供流程与可靠导出，不承诺任意原画一键精准拆层或直接达到生产级绑定质量。
