Verwende diese Fähigkeit, wenn der nächste Schritt darin besteht, Code zu finden oder zu verfolgen, den du noch nicht gefunden hast: wo etwas definiert ist, wer es aufruft, wie ein Feature End‑zu‑End verkabelt ist, jedes Vorkommen eines Strings oder Flags in einem Repository, oder welche öffentliche Oberfläche eine Datei hat. Sie wählt eine Such‑Stufe (Repo‑Graph, LSP‑Symbole, ripgrep, grep) aus dem, was tatsächlich für die betroffenen Dateitypen gebaut ist, und fällt dann die Leiter hinunter, anstatt ein Tool erneut zu fragen, das nichts zurückgegeben hat. Greife darauf zurück, bevor du dein erstes grep, rg, find oder Graph/LSP‑Abfrage in einer Sitzung ausführst, und erneut in dem Moment, in dem ein semantisches Tool leer zurückkommt. Verwende sie nicht, wenn der Nutzer bereits die Datei und das Symbol nennt und die Arbeit das Editieren selbst ist, wenn die Frage die Flags oder die Einrichtung eines Suchwerkzeugs betrifft, wenn die Aufgabe das Profiling oder Beschleunigen einer Funktion ist, die zufällig „Suche“ heißt, oder wenn das Ziel Logs, Commit‑Zusammenfassungen oder nicht‑Code‑Daten statt Quellcode sind.
