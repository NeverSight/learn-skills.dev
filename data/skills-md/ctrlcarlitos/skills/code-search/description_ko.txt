다음 단계가 아직 찾지 못한 코드를 찾거나 추적해야 할 때 이 기술을 사용하세요: 어디에 정의되어 있는지, 누가 호출하는지, 기능이 처음부터 끝까지 어떻게 연결되는지, 레포 전체에서 문자열이나 플래그가 등장하는 모든 위치, 혹은 파일의 공개 인터페이스가 무엇인지 등을 찾을 때입니다. 파일 유형에 실제로 구축된 검색 방법(레포 그래프, LSP 심볼, ripgrep, grep) 중 하나를 선택하고, 아무 것도 반환하지 않은 도구에 다시 묻는 대신 단계별로 진행합니다. 세션에서 첫 번째 grep, rg, find, 또는 graph/LSP 쿼리를 실행하기 전에, 그리고 의미론적 도구가 빈 결과를 반환하는 순간에 이 기술을 사용하세요. 사용자가 이미 파일과 심볼을 지정했고 작업이 편집 자체인 경우, 질문이 검색 도구의 플래그나 설정에 관한 경우, 작업이 프로파일링이나 검색이라고 불리는 기능을 가속화하는 경우, 혹은 대상이 로그, 커밋 요약, 또는 비코드 데이터인 경우에는 사용하지 마세요.
