다음 단계가 아직 찾지 못한 코드를 찾거나 추적할 때 이 스킬을 사용하십시오: 어떤 것이 정의된 위치, 누가 호출하는지, 기능이 전체적으로 어떻게 연결되는지, 레포 전체에서 문자열이나 플래그가 나타나는 모든 경우, 혹은 파일의 공개 인터페이스가 무엇인지 등입니다. 이 스킬은 실제로 해당 파일 유형에 대해 구축된 검색 단계(레포 그래프, LSP 심볼, ripgrep, grep) 중 하나를 선택한 뒤, 아무 것도 반환하지 않은 도구에 다시 묻는 대신 사다리를 내려갑니다. 세션에서 처음으로 grep, rg, find 또는 그래프/LSP 쿼리를 실행하기 전에, 그리고 의미론적 도구가 빈 결과를 반환하는 순간에 이 스킬을 활용하십시오. 사용자가 이미 파일과 심볼을 지정하고 작업이 직접 편집인 경우, 질문이 검색 도구의 플래그나 설정에 관한 경우, 작업이 프로파일링이거나 검색이라고 불리는 기능을 가속화하는 경우, 혹은 대상이 로그, 커밋 요약, 비코드 데이터 등 소스가 아닌 경우에는 사용하지 마십시오.
