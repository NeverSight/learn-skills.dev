Usa questa competenza quando il passo successivo è individuare o tracciare del codice che non hai ancora trovato: dove qualcosa è definito, chi lo chiama, come una funzionalità è collegata end‑to‑end, ogni occorrenza di una stringa o di un flag in tutto il repository, o qual è la superficie pubblica di un file. Sceglie un livello di ricerca (graph del repo, simboli LSP, ripgrep, grep) in base a ciò che è realmente costruito per i tipi di file coinvolti, poi scende lungo la gerarchia invece di richiedere nuovamente uno strumento che non ha restituito risultati. Richiamala prima del tuo primo grep, rg, find o query graph/LSP in una sessione, e di nuovo non appena uno strumento semantico restituisce vuoto. Non usarla quando l'utente ha già indicato il file e il simbolo e il lavoro è la modifica stessa, quando la domanda riguarda i flag o la configurazione di uno strumento di ricerca, quando il compito è il profiling o l'ottimizzazione di una funzionalità che per caso si chiama ricerca, o quando il target è log, sommari di commit o dati non di codice piuttosto che il sorgente.
