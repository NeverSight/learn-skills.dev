Utiliza esta habilidad cuando el siguiente paso sea localizar o rastrear código que aún no has encontrado: dónde se define algo, quién lo llama, cómo está conectada de extremo a extremo una funcionalidad, cada aparición de una cadena o bandera en todo el repositorio, o cuál es la superficie pública de un archivo. Selecciona un nivel de búsqueda (grafo del repositorio, símbolos LSP, ripgrep, grep) basado en lo que realmente se ha construido para los tipos de archivo involucrados, y luego continúa sin volver a preguntar a una herramienta que no devolvió resultados. Recógela antes de tu primer grep, rg, find o consulta de grafo/LSP en una sesión, y nuevamente en el momento en que una herramienta semántica regrese vacía. No la uses cuando el usuario ya indica el archivo y el símbolo y el trabajo es la propia edición, cuando la pregunta trata sobre las banderas o la configuración de una herramienta de búsqueda, cuando la tarea es perfilar o acelerar una funcionalidad que casualmente se llama búsqueda, o cuando el objetivo son registros, resúmenes de commits o datos no relacionados con el código fuente.
