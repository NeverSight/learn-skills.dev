Utiliza esta habilidad cuando el siguiente paso sea localizar o rastrear código que aún no has encontrado: dónde se define algo, quién lo llama, cómo se conecta una funcionalidad de extremo a extremo, cada ocurrencia de una cadena o bandera en todo el repositorio, o cuál es la superficie pública de un archivo. Selecciona una capa de búsqueda (grafo del repo, símbolos LSP, ripgrep, grep) basada en lo que realmente está construido para los tipos de archivo involucrados, y luego continúa en la escalera en lugar de volver a preguntar a una herramienta que no devolvió resultados. Recurre a ella antes de tu primer grep, rg, find o consulta graph/LSP en una sesión, y nuevamente en el momento en que una herramienta semántica no devuelve nada. No la uses cuando el usuario ya nombra el archivo y el símbolo y el trabajo consiste en la edición misma, cuando la pregunta trata sobre las banderas o la configuración de una herramienta de búsqueda, cuando la tarea es perfilar o acelerar una funcionalidad que casualmente se llama búsqueda, o cuando el objetivo son logs, resúmenes de commits o datos no de código en lugar del código fuente.
