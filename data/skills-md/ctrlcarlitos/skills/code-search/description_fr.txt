Utilisez cette compétence lorsque l'étape suivante consiste à localiser ou tracer du code que vous n’avez pas encore trouvé : où quelque chose est défini, qui l’appelle, comment une fonctionnalité est câblée de bout en bout, chaque occurrence d’une chaîne ou d’un drapeau dans un dépôt, ou quelle est la surface publique d’un fichier. Elle sélectionne une couche de recherche (graph du dépôt, symboles LSP, ripgrep, grep) parmi ce qui est réellement disponible pour les types de fichiers concernés, puis descend l’échelle au lieu de redemander un outil qui n’a rien renvoyé. Servez‑vous en avant votre premier grep, rg, find ou requête graph/LSP dans une session, et de nouveau dès qu’un outil sémantique ne donne aucun résultat. Ne l’utilisez pas lorsque l’utilisateur indique déjà le fichier et le symbole et que le travail consiste en l’édition elle‑même, lorsque la question porte sur les options ou la configuration d’un outil de recherche, lorsque la tâche est le profilage ou l’accélération d’une fonctionnalité qui s’appelle « search », ou lorsque la cible est des journaux, des résumés de commits ou des données non‑code plutôt que du code source.
