Modifier le texte pour supprimer les références à l’IA et ajouter une voix humaine : exagération, tirets cadratins, « pas seulement X mais Y », listes à en-tête intégrées, règle du trio, remplissage et atténuation. Utiliser avant de livrer tout texte que quelqu’un d’autre lira : titre ou description de pull request, notes de version ou journal des changements, README ou autre documentation, page publiée, corps d’un ticket ou d’un problème, document de conception ou proposition, texte d’interface utilisateur, courriel ou annonce. L’utiliser également lorsqu’on demande d’écrire, de réécrire, de resserrer, de raccourcir ou de « rendre cela moins IA », lors de la révision du brouillon de quelqu’un d’autre, et quand une autre compétence restitue du texte pour diffusion. Pas pour le code ou la sortie de commandes.
