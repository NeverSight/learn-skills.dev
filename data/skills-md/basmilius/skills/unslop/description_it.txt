Modifica la prosa per rimuovere i riferimenti all’AI e aggiungere una voce umana: esagerazioni, trattini lunghi, “non solo X ma Y”, elenchi con intestazioni in linea, regola del tre, riempitivi e incertezze. Usala prima di consegnare qualsiasi testo che un’altra persona leggerà: un titolo o una descrizione di pull request, note di rilascio o changelog, un README o altra documentazione, una pagina pubblicata, il corpo di un issue o ticket, un documento di design o proposta, copy UI, un’email o un annuncio. Usala anche quando ti chiedono di scrivere, riscrivere, stringere, accorciare o “farlo sembrare meno AI”, quando revisioni la bozza di qualcun altro e quando un’altra competenza restituisce testo per la consegna. Non è destinata a codice o output di comando.

Per favore rispondi sempre nella lingua dell’utente.
