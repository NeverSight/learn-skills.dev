Edita la prosa para eliminar los indicios de IA y añadir voz humana: fanfarria, guiones largos, “no solo X sino Y”, listas en línea con encabezados, regla de tres, relleno y evasivas. Úsalo antes de entregar cualquier texto que otra persona leerá: el título o descripción de una pull request, notas de lanzamiento o un registro de cambios, un README u otra documentación, una página publicada, el cuerpo de un issue o ticket, un documento de diseño o propuesta, copias de UI, un correo electrónico o anuncio. También utilízalo cuando te pidan escribir, reescribir, ajustar, acortar o “hacer que suene menos IA”, al revisar el borrador de otra persona, y cuando otra habilidad entregue texto para su entrega. No es para código o salida de comandos.
