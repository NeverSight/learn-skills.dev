حرّر النص لإزالة إشارات الذكاء الاصطناعي وإضافة صوت إنساني: المبالغة، الشرطات الطويلة، «ليس فقط X بل Y»، القوائم المدمجة في العناوين، قاعدة الثلاثة، الحشو والتحجيم. استخدم ذلك قبل تقديم أي نص سيقرأه شخص آخر: عنوان أو وصف طلب السحب، ملاحظات الإصدار أو سجل التغييرات، ملف README أو أي توثيق آخر، صفحة منشورة، محتوى مشكلة أو تذكرة، وثيقة تصميم أو اقتراح، نص واجهة المستخدم، بريد إلكتروني أو إعلان. استخدم أيضاً عندما يُطلب كتابة أو إعادة صياغة أو تشديد أو تقصير أو «جعل هذا يبدو أقل ذكاءً اصطناعياً»، عند مراجعة مسودة شخص آخر، وعندما تُعيد مهارة أخرى نصًا للتسليم. لا يُستخدم للشفرة أو مخرجات الأوامر.
