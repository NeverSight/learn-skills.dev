استخدمه عندما يعتمد مشروع على حزمة في نطاق npm `@basmilius` (من Bas Milius): `@basmilius/utils` (مساعدات مستقلة تعتمد على Luxon للتعامل مع التاريخ، الأعداد، الألوان، التحميل، DOM، التوقيت، الجغرافيا ومولد الأعداد العشوائية)، `@basmilius/http-client` (طبقة البيانات DTO المكتوبة بأنواع) و`@basmilius/common` (بدءيات تطبيق Vue 3 على Pinia وVue Router). يتم التفعيل عند أي استيراد `@basmilius/*`؛ عند `formatDate` / `formatNumber`، `hexToRGB` / `hslToRGB`، `debounce` / `waitFor`، `downloadBlob`، `mulberry32`، `getSeason` / `getMoonPhase`؛ عند `@dto` / `@adapter`، `HttpClient`، `RequestBuilder`، `BaseService`، `BaseResponse`، `Paginated`، `.runAdapter`، `RequestError` / `ValidationError`، `serialize` / `deserialize`، إضافة Vite `dtoNames`؛ عند `defineStore` التي تُعيد مرجع، `useService` / `guarded`، `useDataTable` / `useDataReport`، `useDtoForm`، `useUrlState`، `persistentRef`، مكوّناتها (useClickOutside، useHotKey، …)، مساعدات الراوتر (useRouteParam، useNavigate، …) والاستثناءات (ForbiddenException، HandledException، …). لا تستخدمه مع `@flux-ui/*` (انظر `flux-ui`); `@basmilius/vite-preset` مستبعد مقصداً.
