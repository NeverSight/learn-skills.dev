プロジェクトが `@basmilius` npm スコープ（Bas Milius 製）のパッケージに依存している場合に使用します：`@basmilius/utils`（Luxon ベースの単体の日付、数値、カラー、ダウンロード、DOM、タイミング、ジオ、PRNG ヘルパー）、`@basmilius/http-client`（型付けされた DTO データ層）および `@basmilius/common`（Pinia と Vue Router 上の Vue 3 アプリプリミティブ）。任意の `@basmilius/*` インポート時、`formatDate`／`formatNumber`、`hexToRGB`／`hslToRGB`、`debounce`／`waitFor`、`downloadBlob`、`mulberry32`、`getSeason`／`getMoonPhase`、`@dto`／`@adapter`、`HttpClient`、`RequestBuilder`、`BaseService`、`BaseResponse`、`Paginated`、`.runAdapter`、`RequestError`／`ValidationError`、`serialize`／`deserialize`、`dtoNames` Vite プラグイン、ref を返す `defineStore`、`useService`／`guarded`、`useDataTable`／`useDataReport`、`useDtoForm`、`useUrlState`、`persistentRef`、それらのコンポーザブル（`useClickOutside`、`useHotKey`、…）、ルータヘルパー（`useRouteParam`、`useNavigate`、…）および例外（`ForbiddenException`、`HandledException`、…）に対してトリガーします。`@flux-ui/*`（`flux-ui` を参照）には適用しません。`@basmilius/vite-preset` は意図的に対象外です。
