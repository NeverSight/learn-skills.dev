当项目依赖于 `@basmilius` npm 范围（由 Bas Milius 提供）的包时使用：`@basmilius/utils`（基于 Luxon 的独立日期、数字、颜色、下载、DOM、计时、地理和伪随机数工具），`@basmilius/http-client`（类型化 DTO 数据层）以及 `@basmilius/common`（基于 Pinia 和 Vue Router 的 Vue 3 应用原语）。在任何 `@basmilius/*` 导入时触发；在 `formatDate` / `formatNumber`、`hexToRGB` / `hslToRGB`、`debounce` / `waitFor`、`downloadBlob`、`mulberry32`、`getSeason` / `getMoonPhase` 时触发；在 `@dto` / `@adapter`、`HttpClient`、`RequestBuilder`、`BaseService`、`BaseResponse`、`Paginated`、`.runAdapter`、`RequestError` / `ValidationError`、`serialize` / `deserialize`、`dtoNames` Vite 插件时触发；在返回 `ref` 的 `defineStore`、`useService` / `guarded`、`useDataTable` / `useDataReport`、`useDtoForm`、`useUrlState`、`persistentRef` 以及其组合函数（`useClickOutside`、`useHotKey`、…）、路由器帮助函数（`useRouteParam`、`useNavigate`、…）和异常（`ForbiddenException`、`HandledException`、…）时触发。**不适用于** `@flux-ui/*`（见 `flux-ui`）；`@basmilius/vite-preset` 故意不在范围内。
