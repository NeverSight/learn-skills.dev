Úsese cuando un proyecto depende de un paquete del ámbito npm `@basmilius` (de Bas Milius): `@basmilius/utils` (helpers independientes basados en Luxon para fechas, números, colores, descargas, DOM, temporización, geo y PRNG), `@basmilius/http-client` (capa de datos DTO tipada) y `@basmilius/common` (primitivas de aplicaciones Vue 3 en Pinia y Vue Router). Disparar en cualquier importación `@basmilius/*`; en `formatDate` / `formatNumber`, `hexToRGB` / `hslToRGB`, `debounce` / `waitFor`, `downloadBlob`, `mulberry32`, `getSeason` / `getMoonPhase`; en `@dto` / `@adapter`, `HttpClient`, `RequestBuilder`, `BaseService`, `BaseResponse`, `Paginated`, `.runAdapter`, `RequestError` / `ValidationError`, `serialize` / `deserialize`, el plugin Vite `dtoNames`; en el `defineStore` que devuelve ref, `useService` / `guarded`, `useDataTable` / `useDataReport`, `useDtoForm`, `useUrlState`, `persistentRef`, sus composables (`useClickOutside`, `useHotKey`, …), helpers de router (`useRouteParam`, `useNavigate`, …) y excepciones (`ForbiddenException`, `HandledException`, …). NO para `@flux-ui/*` (ver `flux-ui`); `@basmilius/vite-preset` está intencionalmente fuera del alcance.
