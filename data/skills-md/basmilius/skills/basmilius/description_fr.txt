Utilisez lorsque un projet dépend d’un paquet dans l’espace de noms npm `@basmilius` (par Bas Milius) : `@basmilius/utils` (helpers autonomes basés sur Luxon pour les dates, nombres, couleurs, téléchargement, DOM, temporisation, géo et PRNG), `@basmilius/http-client` (la couche de données DTO typée) et `@basmilius/common` (primitives d’application Vue 3 sur Pinia et Vue Router). Déclenchez sur tout import `@basmilius/*` ; sur `formatDate` / `formatNumber`, `hexToRGB` / `hslToRGB`, `debounce` / `waitFor`, `downloadBlob`, `mulberry32`, `getSeason` / `getMoonPhase` ; sur `@dto` / `@adapter`, `HttpClient`, `RequestBuilder`, `BaseService`, `BaseResponse`, `Paginated`, `.runAdapter`, `RequestError` / `ValidationError`, `serialize` / `deserialize`, le plugin Vite `dtoNames` ; sur le `defineStore` retournant une ref, `useService` / `guarded`, `useDataTable` / `useDataReport`, `useDtoForm`, `useUrlState`, `persistentRef`, ses composables (`useClickOutside`, `useHotKey`, …), les aides du routeur (`useRouteParam`, `useNavigate`, …) et les exceptions (`ForbiddenException`, `HandledException`, …). PAS pour `@flux-ui/*` (voir `flux-ui`) ; `@basmilius/vite-preset` est volontairement hors de portée.
