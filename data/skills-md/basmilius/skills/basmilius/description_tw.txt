當專案依賴 `@basmilius` npm 範圍內的套件（由 Bas Milius 提供）時使用：`@basmilius/utils`（獨立的基於 Luxon 的日期、數字、顏色、下載、DOM、計時、地理與 PRNG 輔助工具）、`@basmilius/http-client`（具類型的 DTO 資料層）以及 `@basmilius/common`（基於 Pinia 與 Vue Router 的 Vue 3 應用原始件）。  
在任何 `@basmilius/*` 匯入時觸發；在 `formatDate` / `formatNumber`、`hexToRGB` / `hslToRGB`、`debounce` / `waitFor`、`downloadBlob`、`mulberry32`、`getSeason` / `getMoonPhase` 時觸發；在 `@dto` / `@adapter`、`HttpClient`、`RequestBuilder`、`BaseService`、`BaseResponse`、`Paginated`、`.runAdapter`、`RequestError` / `ValidationError`、`serialize` / `deserialize`、`dtoNames` Vite 插件時觸發；在返回 ref 的 `defineStore`、`useService` / `guarded`、`useDataTable` / `useDataReport`、`useDtoForm`、`useUrlState`、`persistentRef`、其組合式函式（`useClickOutside`、`useHotKey`、……），路由輔助函式（`useRouteParam`、`useNavigate`、……）以及例外類別（`ForbiddenException`、`HandledException`、……）時觸發。  
不適用於 `@flux-ui/*`（請參見 `flux-ui`）；`@basmilius/vite-preset` 故意不在範圍內。
