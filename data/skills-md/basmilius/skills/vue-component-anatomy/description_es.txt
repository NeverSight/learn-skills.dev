Úsese al escribir, editar o revisar un único Single File Component de Vue 3 (un archivo `.vue` con `<script setup lang="ts">`). Cubre el orden de los bloques y la raíz del template, el orden de los macros del compilador (defineEmits → defineModel → defineProps → defineSlots, defineExpose al final), el orden dentro de `<script setup>` (imports → macros → constants → stores → state → composables → computed → watch → lifecycle → functions), el estilo de función vs. arrow, la tipificación de props y emits, v‑model mediante defineModel, y los estilos scoped/módulo. Se activa al editar cualquier archivo `.vue`, al usar defineProps/defineEmits/defineModel/defineSlots, ante preguntas sobre el orden en script‑setup y al tipar props. División a nivel de característica: `vue-build-feature`; biblioteca Flux UI: `flux-ui`. Por favor, siempre responda en el idioma del usuario.
