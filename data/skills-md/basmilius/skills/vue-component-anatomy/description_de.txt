Verwenden, wenn Sie eine einzelne Vue 3‑Single‑File‑Component (eine `.vue`‑Datei mit `<script setup lang="ts">`) schreiben, bearbeiten oder prüfen. Deckt die Blockreihenfolge und das Template‑Root‑Element ab, die Reihenfolge der Compiler‑Macros (defineEmits → defineModel → defineProps → defineSlots, defineExpose zuletzt), die Anordnung innerhalb von `<script setup>` (imports → macros → constants → stores → state → composables → computed → watch → lifecycle → functions), Funktions‑ vs. Pfeil‑Style, Typisierung von Props und Emits, v‑model via defineModel und Scoped/Module‑Styling. Wird ausgelöst beim Bearbeiten jeder `.vue`‑Datei, bei defineProps/defineEmits/defineModel/defineSlots, bei Fragen zur script‑setup‑Reihenfolge und bei Prop‑Typisierung. Feature‑level‑Aufteilung: `vue-build-feature`; Flux UI‑Bibliothek: `flux-ui`.
