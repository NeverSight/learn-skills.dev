Usa quando scrivi, modifichi o revisioni un singolo Vue 3 Single File Component (un file `.vue` con `<script setup lang="ts">`). Copre l'ordine dei blocchi e la radice del template, l'ordine delle macro del compilatore (defineEmits → defineModel → defineProps → defineSlots, defineExpose per ultimo), l'ordinamento all'interno di `<script setup>` (imports → macros → constants → stores → state → composables → computed → watch → lifecycle → functions), lo stile funzione vs arrow, la tipizzazione di prop e emit, v‑model tramite defineModel e lo styling scoped/module. Si attiva modificando qualsiasi file `.vue`, su defineProps/defineEmits/defineModel/defineSlots, su domande di ordine nello script‑setup e su tipizzazione di prop. Suddivisione a livello di funzionalità: `vue-build-feature`; libreria UI Flux: `flux-ui`.  

Rispondi sempre nella lingua dell'utente.
