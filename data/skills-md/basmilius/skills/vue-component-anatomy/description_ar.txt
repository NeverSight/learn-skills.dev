استخدم عند كتابة أو تعديل أو مراجعة مكوّن Vue 3 Single File Component (ملف `.vue` يحتوي على `<script setup lang="ts">`). يغطي ترتيب الكتل وجذر القالب، ترتيب ماكرو المترجم (defineEmits → defineModel → defineProps → defineSlots، defineExpose في الأخير)، الترتيب داخل `<script setup>` (imports → macros → constants → stores → state → composables → computed → watch → lifecycle → functions)، نمط الدوال مقابل السهام، كتابة نوع الخصائص (prop) والإنبعاثات (emit)، v‑model عبر defineModel، وتنسيق scoped/module. يُفَعَّل عند تعديل أي ملف `.vue`، عند استخدام defineProps/defineEmits/defineModel/defineSlots، عند أسئلة ترتيب script‑setup، وعند كتابة نوع الخصائص. تقسيم على مستوى الميزة: `vue-build-feature`؛ مكتبة Flux UI: `flux-ui`.
