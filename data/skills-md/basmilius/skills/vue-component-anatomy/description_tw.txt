用於編寫、編輯或審核單一 Vue 3 單檔元件（`.vue` 檔案，內含 `<script setup lang="ts">`）。涵蓋區塊順序與 template 根節點、編譯巨集順序（defineEmits → defineModel → defineProps → defineSlots，最後是 defineExpose）、`<script setup>` 內的排序（imports → macros → constants → stores → state → composables → computed → watch → lifecycle → functions）、函式與箭頭函式風格、prop 與 emit 的型別、透過 defineModel 的 v-model，以及 scoped/module 樣式。觸發條件包括編輯任何 `.vue` 檔案、使用 defineProps/defineEmits/defineModel/defineSlots、詢問 script‑setup 排序問題以及 prop 型別。功能層級分割：`vue-build-feature`；Flux UI 函式庫：`flux-ui`。
