Используется при написании, редактировании или проверке отдельного Vue 3 Single File Component (файла `.vue` с `<script setup lang="ts">`). Охватывает порядок блоков и корень шаблона, порядок компилятор‑макросов (defineEmits → defineModel → defineProps → defineSlots, defineExpose последним), порядок внутри `<script setup>` (imports → macros → constants → stores → state → composables → computed → watch → lifecycle → functions), стиль функций vs стрелочных функций, типизацию prop и emit, v‑model через defineModel и scoped/module‑стилизацию. Срабатывает при редактировании любого файла `.vue`, при использовании defineProps/defineEmits/defineModel/defineSlots, при вопросах о порядке в script‑setup и при типизации prop. Деление по функциям: `vue-build-feature`; библиотека UI: `flux-ui`.
