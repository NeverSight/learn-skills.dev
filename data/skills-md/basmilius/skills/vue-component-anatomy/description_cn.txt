在编写、编辑或审查单个 Vue 3 单文件组件（带有 `<script setup lang="ts">` 的 `.vue` 文件）时使用。涵盖块顺序和模板根、编译器宏顺序（defineEmits → defineModel → defineProps → defineSlots，最后是 defineExpose）、`<script setup>` 内的顺序（imports → macros → constants → stores → state → composables → computed → watch → lifecycle → functions）、函数与箭头函数风格、prop 和 emit 的类型、通过 defineModel 实现 v-model，以及 scoped/module 样式。触发条件包括编辑任何 `.vue` 文件、使用 defineProps/defineEmits/defineModel/defineSlots、关于 script-setup 顺序的提问，以及 prop 类型化。特性级别拆分：`vue-build-feature`；Flux UI 库：`flux-ui`。请始终使用用户语言回复。
