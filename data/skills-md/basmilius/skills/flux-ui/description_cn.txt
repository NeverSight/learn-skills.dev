在使用 Flux（作者 Bas Milius）构建、编辑或审查 Vue 3 UI 时使用：@flux-ui/components（文档位于 flux-ui.dev）以及其兄弟包 @flux-ui/application（应用壳/仪表盘）和 @flux-ui/statistics（关键指标/图表）。对以 Flux 为前缀的组件（FluxPrimaryButton、FluxFormField、FluxPane）、FluxRoot、showConfirm、showSnackbar、showPrompt、showAlert、其 composables（useBreakpoints、useFluxStore、use*Injection）或任何来自 @flux-ui/* 的导入进行触发。这指的是 Vue 3 的 Flux（basmilius），而不是 fluxui.dev 上的 Livewire/Blade Flux，也不是 Flux Web‑components 库；切勿混用它们的语法。

请始终使用用户的语言作答。
