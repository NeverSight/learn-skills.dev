Flux（Bas Milius 作）で Vue 3 UI を構築、編集、またはレビューする際に使用してください：@flux-ui/components（ドキュメントは flux-ui.dev）と、その兄弟パッケージである @flux-ui/application（アプリシェル／ダッシュボード）および @flux-ui/statistics（KPI／チャート）。Flux プレフィックスが付いたコンポーネント（FluxPrimaryButton、FluxFormField、FluxPane）、FluxRoot／showConfirm／showSnackbar／showPrompt／showAlert、またはそのコンポーザブル（useBreakpoints、useFluxStore、use*Injection）や @flux-ui/* からのインポートに対してトリガーします。これは Vue 3 用の Flux（basmilius）であり、fluxui.dev の Livewire/Blade 用 Flux でもなく、Flux Web Components ライブラリでもありません。構文を混在させないでください。常にユーザーの言語で回答してください。
