Используйте при построении, редактировании или просмотре UI Vue 3 с Flux (от Bas Milius): @flux-ui/components (документация на flux-ui.dev) и его сестринские пакеты @flux-ui/application (коробка приложения / дашборды) и @flux-ui/statistics (KPIs / диаграммы). Срабатывает на компонентах с префиксом Flux (FluxPrimaryButton, FluxFormField, FluxPane), на FluxRoot / showConfirm / showSnackbar / showPrompt / showAlert, на его composables (useBreakpoints, useFluxStore, use*Injection) или любом импорте из @flux-ui/*. Это Vue 3 Flux (basmilius), НЕ Livewire/Blade Flux с fluxui.dev и НЕ библиотека веб‑компонентов Flux; никогда не смешивайте их синтаксис.

Пожалуйста, всегда отвечайте на языке пользователя.
