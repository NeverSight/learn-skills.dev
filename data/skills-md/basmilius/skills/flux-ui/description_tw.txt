在使用 Flux（由 Bas Milius 開發）構建、編輯或審查 Vue 3 UI 時使用：@flux-ui/components（文件位於 flux-ui.dev）以及其相關套件 @flux-ui/application（應用程式外殼 / 儀表板）和 @flux-ui/statistics（KPI / 圖表）。針對以 Flux 為前綴的元件（FluxPrimaryButton、FluxFormField、FluxPane）、FluxRoot / showConfirm / showSnackbar / showPrompt / showAlert、其 composables（useBreakpoints、useFluxStore、use*Injection）或任何來自 @flux-ui/* 的匯入進行觸發。這是 Vue 3 的 Flux（basmilius），不是 fluxui.dev 上的 Livewire/Blade Flux，也不是 Flux Web Components 函式庫；切勿混用它們的語法。

請始終以使用者的語言回覆。
