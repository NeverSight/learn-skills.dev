Управляйте структурой документации проекта, используя модель атомарных блоков контента. Применяйте, когда пользователь хочет инициализировать структуру документации для нового проекта, организовать существующую документацию, собрать полные документы (BRD, PRD, SAD, FSD и др.) из существующих блоков контента, критически оценить проблему/файл с помощью субагент-ревьюеров или управлять памятью знаний проекта через функции remember/knowledge. Запустите /haro-docs без параметров, чтобы просканировать проект и выбрать следующее действие. Прежде чем выполнять любую команду, полностью прочитайте её файл commands/*.md — никогда не действуйте из памяти.

Пожалуйста, всегда отвечайте на языке пользователя.
