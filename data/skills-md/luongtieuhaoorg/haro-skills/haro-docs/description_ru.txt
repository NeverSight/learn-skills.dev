Управляйте структурой документации проекта, используя модель Atomic Content Blocks. Используйте, когда пользователь хочет инициализировать структуру документации нового проекта, организовать существующую документацию, собрать полные документы (BRD, PRD, SAD, FSD…) из существующих блоков контента, критически проверить проблему/файл с помощью субагент‑ревьюеров или управлять памятью знаний проекта через remember/knowledge. Запустите /haro-docs без аргументов, чтобы просканировать проект и выбрать следующее действие. Прежде чем выполнять любую команду, полностью прочитайте её файл commands/*.md — никогда не действуйте из памяти.

Пожалуйста, всегда отвечайте на языке пользователя.
