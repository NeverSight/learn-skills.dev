Gestiona la estructura de documentación del proyecto usando el modelo de Bloques de Contenido Atómicos. Úsalo cuando el usuario quiera iniciar una estructura de documentación para un nuevo proyecto, organizar la documentación existente, agrupar documentos completos (BRD, PRD, SAD, FSD…) a partir de bloques de contenido existentes, revisar críticamente un problema/archivo mediante revisores subagente, o gestionar la memoria de conocimiento del proyecto mediante remember/knowledge. Ejecuta /haro-docs sin argumentos para escanear el proyecto y elegir la siguiente acción. Antes de ejecutar cualquier comando, lee completamente su archivo commands/*.md; nunca actúes solo con la memoria.

Por favor, responde siempre en el idioma del usuario.
