@ dawod/thmanyah-font-web npm 패키지 또는 CDN 링크를 통해 Thmanyah (ثمانية) 아랍어 글꼴 패밀리를 웹 프로젝트에 추가하고 프로젝트가 로컬로 필요할 때 원시 .woff2 파일을 다운로드합니다. 사용자가 Thmanyah,ثمانية, @ dawod/thmanyah-font-web을 언급하거나 HTML, CSS, React, Vue, Next.js 또는 프론트엔드 스택에 아랍어 웹폰트 (Thmanyah Sans, Thmanyah Serif Display, Thmanyah Serif Text) 를 설치, 다운로드 또는 사용하고자 할 때 사용합니다.
