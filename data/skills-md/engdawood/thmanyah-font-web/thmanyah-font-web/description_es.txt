Agregue la familia tipográfica árabe Thmanyah (ثمانية) a proyectos web a través del paquete npm @ dawod/thmanyah-font-web o enlaces CDN, y descargue los archivos .woff2 sin formato cuando un proyecto los necesite localmente. Úselo cuando el usuario mencione Thmanyah,ثمانية, @dawod/thmanyah-font-web, o quiera fuentes web árabes (Thmanyah Sans, Thmanyah Serif Display, Thmanyah Serif Text) instaladas, descargadas o utilizadas en HTML, CSS, React, Vue, Next.js o cualquier pila de frontend.
