@ dawod/thmanyah - font - web npmパッケージまたはCDNリンクを介してWebプロジェクトにThmanyah （ثمانية ）アラビア語フォントファミリーを追加し、プロジェクトがローカルで必要なときに生の.woff 2ファイルをダウンロードします。ユーザーがThmanyahثمانية、@ dawod/thmanyah - font - webに言及している場合、またはアラビア語のWebフォント(Thmanyah Sans、Thmanyah Serif Display、Thmanyah Serif Text)をインストール、ダウンロード、またはHTML、CSS、React、Vue、Next.js、または任意のフロントエンドスタックで使用する場合に使用します。
