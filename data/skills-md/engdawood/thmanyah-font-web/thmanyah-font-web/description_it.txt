Aggiungi la famiglia di font arabi Thmanyah (ثمانية) ai progetti web tramite il pacchetto npm @dawod/thmanyah-font-web o i collegamenti CDN, e scarica i file .woff2 grezzi quando un progetto ne ha bisogno localmente. Usa quando l'utente menziona Thmanyah, ثمانية, @dawod/thmanyah-font-web, o desidera font web arabi (Thmanyah Sans, Thmanyah Serif Display, Thmanyah Serif Text) installati, scaricati o utilizzati in HTML, CSS, React, Vue, Next.js o in qualsiasi stack frontend.

Per favore, rispondi sempre nella lingua dell'utente.
