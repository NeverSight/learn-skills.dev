Créer des comptes pour un agent sur des services tiers avec AgentID, en utilisant une boîte de réception AgentMail comme identité de l'agent, et voir où chaque boîte a déjà un compte. Utilisez pour TOUTE demande comme « créer un compte sur Firecrawl », « inscrire mon agent à Turso », « obtenir une API de recherche web pour mon agent », « reconnecter mon agent à Firecrawl », « quels services cette boîte de réception a-t-elle inscrits ? », ou parcourir le marché des fournisseurs d’AgentID. Ne pas utiliser pour l’envoi ou la lecture d’e‑mails (agentmail-send-email, agentmail-check-email), la gestion du cycle de vie d’une boîte de réception seule (agentmail-manage-inboxes), ou la configuration de connexion MCP (agentmail-mcp).

Veuillez toujours répondre dans la langue de l'utilisateur.
