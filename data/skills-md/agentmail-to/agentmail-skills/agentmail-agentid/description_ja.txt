AgentID を使用して、エージェントの本人確認として AgentMail の受信トレイを利用し、サードパーティサービスでエージェントのアカウントを作成し、各受信トレイが既にどのサービスにアカウントを持っているかを確認します。「Firecrawl にアカウントを作成する」「エージェントを Turso に登録する」「エージェントにウェブ検索 API を取得させる」「エージェントを Firecrawl に再ログインさせる」「この受信トレイが登録されているサービスはどれか？」といった任意のリクエストや、AgentID プロバイダーのマーケットプレイスの閲覧に使用してください。メールの送受信（agentmail-send-email、agentmail-check-email）、受信トレイの単独管理（agentmail-manage-inboxes）、または MCP 接続設定（agentmail-mcp）には使用しないでください。
