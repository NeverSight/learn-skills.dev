Создавайте учетные записи для агента в сторонних сервисах с помощью AgentID, используя почтовый ящик AgentMail в качестве идентификации агента, и проверяйте, где каждый ящик уже имеет учетную запись. Используйте для ЛЮБЫХ запросов типа «создать учетную запись в Firecrawl», «зарегистрировать моего агента в Turso», «получить моему агенту API веб‑поиска», «войти моему агенту в Firecrawl», «какие сервисы подключены к этому ящику?», или для просмотра рыночной площадки провайдеров AgentID. Не используйте для отправки или чтения почты (agentmail‑send‑email, agentmail‑check‑email), управления жизненным циклом ящика (agentmail‑manage‑inboxes) или настройки соединения MCP (agentmail‑mcp).

Пожалуйста, всегда отвечайте на языке пользователя.
