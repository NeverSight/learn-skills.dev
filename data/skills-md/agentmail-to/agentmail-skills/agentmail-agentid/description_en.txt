Create accounts for an agent at third-party services with AgentID, using an AgentMail inbox as the agent's identity, and see where each inbox already has an account. Use for ANY request like "create an account at Firecrawl", "sign my agent up for Turso", "get my agent a web search API", "log my agent back in to Firecrawl", "which services is this inbox signed up for?", or browsing the AgentID provider marketplace. Do not use for sending or reading mail (agentmail-send-email, agentmail-check-email), inbox lifecycle on its own (agentmail-manage-inboxes), or MCP connection setup (agentmail-mcp).
