Audit a pull request, a stack of pull requests, or a branch, pick the changes that need human judgment, and open them as ordered, annotated tours of small stops grouped into tracks in the Hunk diff viewer, one tour per stack layer. Use for "guided review", "tour this PR", "review tour", "walk me through this PR", or a PR link, branch name, or shared tour JSON file with a request to review it in hunk. Posts to GitHub only the stops the reviewer chooses with Post finding to PR and the comments the reviewer writes with Comment on PR.
