Archivieren Sie eine OpenSpec‑Änderung von Anfang bis Ende. Diese Fähigkeit ruft openspec-archive-change oder openspec-bulk-archive-change selbst auf, um das native Merge auszuführen, und folgt dann sofort mit dem Cross‑Capability‑Linking und dem Erstellen von Indizes, die OpenSpec nicht von selbst erzeugt – indem jede Capability, die eine Änderung berührt hat, über eine gemeinsame `related:`‑Frontmatter‑Liste verknüpft wird, `openspec/specs/INDEX.md` aktuell gehalten wird und eine Zeile an `openspec/changes/archive/INDEX.md` angehängt wird. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Änderung archivieren möchte, sagt „archive this change“, „bulk archive these changes“, „run openspec-archive-change“, „run openspec-bulk-archive-change“, „update the specs index“, „cross-link the specs“ oder den archivierten Änderungs‑Changelog aktuell halten will. Diese Fähigkeit ist rein additiv auf der Verknüpfungs‑Seite – sie entfernt niemals einen `related:`‑Eintrag und ändert die Spalte `Status` einer Änderung nach dem ersten Schreiben nicht; das Pruning/Synthese‑Arbeiten gehören zu `accelint-archive-synthesis`.
