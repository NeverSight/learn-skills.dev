Archivar un cambio de OpenSpec de extremo a extremo. Esta habilidad invoca openspec-archive-change o openspec-bulk-archive-change para realizar la fusión nativa y luego sigue inmediatamente con el enlace entre capacidades y la generación de índices que OpenSpec no construye por sí mismo — vinculando cada capacidad que un cambio tocó mediante una lista compartida `related:` en el frontmatter, manteniendo actualizado `openspec/specs/INDEX.md` y añadiendo una fila a `openspec/changes/archive/INDEX.md`. Use esta habilidad siempre que el usuario quiera archivar un cambio, diga "archive this change", "bulk archive these changes", "run openspec-archive-change", "run openspec-bulk-archive-change", "update the specs index", "cross-link the specs", o quiera que el registro de cambios archivado se mantenga actualizado. Esta habilidad es puramente aditiva en el lado del enlace — nunca elimina una entrada `related:` ni cambia la columna `Status` de un cambio después de la escritura inicial; ese trabajo de poda/síntesis pertenece a `accelint-archive-synthesis`.
