문서 세트에서 내부 용어, 약어, 속기 및 전문 용어를 추출한 다음 JARGON.md에서 프로젝트 용어집을 구축하거나 업데이트합니다. 기존 JARGON.md가 이미 존재하는 경우 저장소의 어느 위치에서나 재사용합니다. 그렇지 않으면 기본적으로 repo 루트가 사용됩니다. 입력 파일당 하나의 하위 에이전트를 생성하여 일반 영어 정의로 용어에 플래그를 지정한 다음 단일 감소 하위 에이전트가 결합된 결과를 상관시키고 중복을 제거하고 알파벳순으로 정렬하여 용어집에 쓰기 전에 겹치는 정의를 지능적으로 병합합니다. 사용자가 전문 용어 추출, 용어집 작성 또는 업데이트, 카탈로그 약어, 내부 용어 문서화, 정의되지 않은 용어 플래그 지정, 이름으로 JARGON.md 파일 언급 등을 요청할 때마다 이 기술을 사용하세요. 예를 들어 '이 디자인 문서를 살펴보고 신입 사원이 알지 못하는 내용을 꺼내세요' 또는 '이 저장소의 마크다운 파일을 스캔하여 용어 목록을 작성하세요'와 같이 아무렇지도 않게 표현하더라도 이 기술을 사용하세요. 또한 사용자가 여러 문서를 넘겨주고 문서 전체에 어떤 전문 어휘나 속기가 나타나는지 묻는 경우에도 트리거됩니다.
