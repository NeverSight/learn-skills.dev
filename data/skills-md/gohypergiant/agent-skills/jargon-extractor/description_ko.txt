문서 집합에서 내부 용어, 약어, 약식 및 전문 용어를 추출한 뒤 JARGON.md에 프로젝트 용어집을 만들거나 업데이트합니다. 레포지토리 내에 기존 JARGON.md 파일이 이미 존재하면 해당 파일을 재사용하고, 없을 경우 레포 루트에 기본 위치로 사용합니다. 입력 파일마다 하나의 하위 에이전트를 생성하여 용어와 평이한 영어 정의를 표시하고, 이후 단일 리듀스 하위 에이전트가 결과를 상호 연관시키고 중복을 제거하며 알파벳 순으로 정렬합니다. 겹치는 정의가 있을 경우 지능적으로 병합한 뒤 용어집에 기록합니다. 사용자가 전문 용어를 추출하거나, 용어집을 만들·업데이트하거나, 약어를 정리하거나, 내부 용어를 문서화하거나, 정의되지 않은 용어를 표시하라는 요청을 할 때, 혹은 JARGON.md 파일을 이름으로 언급할 때(예: “이 디자인 문서를 살펴보고 신입이 모를 만한 내용을 뽑아 주세요” 혹은 “레포의 마크다운 파일을 스캔해 용어 목록을 만들어요”) 언제든 이 기능을 사용합니다. 또한 사용자가 여러 문서를 제공하고 그 안에 나타나는 특수 어휘나 약식이 무엇인지 물어볼 때도 트리거됩니다.
