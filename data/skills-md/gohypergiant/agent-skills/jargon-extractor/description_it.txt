Estrai terminologia interna, acronimi, abbreviazione e gergo da una serie di documenti, quindi crea o aggiorna un glossario di progetto in JARGON.md. Riutilizzare un JARGON.md esistente ovunque nel repository se ne esiste già uno; in caso contrario, viene utilizzata per impostazione predefinita la radice del repository. Genera un subagente per file di input per contrassegnare i termini con definizioni in inglese semplice, quindi un singolo subagente di riduzione correla, deduplica e mette in ordine alfabetico i risultati combinati, unendo in modo intelligente eventuali definizioni sovrapposte prima di scriverle nel glossario. Utilizza questa capacità ogni volta che l'utente chiede di estrarre termini tecnici, creare o aggiornare un glossario, catalogare acronimi, documentare la terminologia interna, contrassegnare termini non definiti o menzionare un file JARGON.md per nome, anche se formulato in modo casuale, ad esempio "esamina questi documenti di progettazione ed estrai tutto ciò che un nuovo assunto non saprebbe" o "scansiona i file di markdown di questo repository e crea un elenco di termini". Si attivano anche quando l'utente consegna diversi documenti e chiede quale vocabolario specializzato o abbreviazione appare in essi.
