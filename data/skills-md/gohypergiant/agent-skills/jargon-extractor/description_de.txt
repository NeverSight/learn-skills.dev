Extrahieren Sie interne Terminologie, Akronyme, Kurzschriften und Fachjargon aus einer Reihe von Dokumenten und erstellen oder aktualisieren Sie dann ein Projektglossar in JARGON.md. Verwenden Sie eine vorhandene JARGON.md an einer beliebigen Stelle im Repo wieder, falls bereits eine vorhanden ist. andernfalls wird standardmäßig das Repo-Stammverzeichnis verwendet. Erzeugt einen Subagenten pro Eingabedatei, um Begriffe mit einfachen englischen Definitionen zu kennzeichnen. Anschließend korreliert, dedupliziert und alphabetisiert ein einzelner Subagent die kombinierten Ergebnisse und führt alle überlappenden Definitionen intelligent zusammen, bevor er sie in das Glossar schreibt. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Fachjargon extrahieren, ein Glossar erstellen oder aktualisieren, Akronyme katalogisieren, interne Terminologie dokumentieren, undefinierte Begriffe kennzeichnen oder eine JARGON.md-Datei namentlich erwähnen möchte, auch wenn dies beiläufig formuliert ist, zum Beispiel „Gehen Sie diese Designdokumente durch und ziehen Sie alles heraus, was ein neuer Mitarbeiter nicht wissen würde“ oder „Scannen Sie die Markdown-Dateien dieses Repos und erstellen Sie eine Begriffsliste“. Wird auch ausgelöst, wenn der Benutzer mehrere Dokumente übergibt und fragt, welches Fachvokabular oder welche Kurzschrift darin enthalten ist.
