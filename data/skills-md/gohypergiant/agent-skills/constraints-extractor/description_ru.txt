Извлеките явные и неявные ограничения (соответствие, безопасность, хостинг, инструменты, заинтересованные стороны, область действия и границы внешних зависимостей) из документации проекта, а затем создайте или обновите канонический файл CONSTRAINTS.md. Создает по одному субагенту на каждый исходный документ для обозначения навязанных извне границ с помощью ссылок на доказательства и рейтингов достоверности, затем коррелирует, дедуплицирует и упорядочивает результаты по категориям перед записью их в CONSTRAINTS.md. Используйте этот навык всякий раз, когда пользователь упоминает «CONSTRAINTS.md», «извлечь ограничения», «найти наши ограничения», «ограничения документа», «ограничения соответствия», «что ограничивает этот проект», «синтезировать ограничения» или хочет зафиксировать наложенные извне границы (правовые, безопасность, соответствие требованиям, заинтересованные стороны, поставщики), которые определяют, что и как может построить проект. Всегда отдавайте предпочтение этому навыку документации по специальным ограничениям.
