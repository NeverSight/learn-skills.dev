Integrieren Sie ein Repository in die agentengesteuerte Entwicklung, indem Sie ein vollständiges AGENTS.md oder CLAUDE.md durch verhaltensorientierte Erkennung, strukturierte Interviews, driftbewusste Aktualisierungen, konfliktbewusste Synthese, proportionale Aktualisierungen und Vorschau vor dem Schreiben erstellen oder aktualisieren. Verwenden Sie diese Option, wenn der Benutzer AGENTS.md- oder CLAUDE.md-Anleitungen erstellen, ersetzen, aktualisieren, importieren, umstrukturieren, anhängen, trocken ausführen oder überprüfen möchte, Agentenverhalten, Anweisungen, Leitplanken, Arbeitsabläufe, Claude-Code-Konventionen, Agentendateien auf Paketebene oder Monorepo-Vererbung erwähnt oder fragt, wie er einem KI-Codierungsagenten mitteilen kann, wie er sich in einem Projekt verhalten soll. Verwenden Sie es auch, wenn der Benutzer möchte, dass Verhaltensregeln von der Projekt-DNA „openspec/config.yml“ oder „openspec/config.yaml“ getrennt bleiben. Verwenden Sie es nicht für OpenSpec-Konfigurations-Onboarding, Architekturdokumente oder einzeilige Bearbeitungen von AGENTS.md oder CLAUDE.md, die keine Erkennung, Synthese oder Überprüfung auf Abschnittsebene erfordern.
