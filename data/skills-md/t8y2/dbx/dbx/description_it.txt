DBX CLI per l'esplorazione dello schema del database e query in sola lettura. Quando l'utente ha bisogno di elencare le connessioni, esplorare le tabelle, descrivere gli schemi, eseguire query o generare un contesto di schema amichevole per l'IA dai database gestiti da DBX. NON utilizzare per operazioni di scrittura a meno che l'utente non confermi esplicitamente con --allow-writes.

Rispondi sempre nella lingua dell'utente.
