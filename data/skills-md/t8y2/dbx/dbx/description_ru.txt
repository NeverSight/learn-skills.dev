DBX CLI для исследования схемы базы данных и выполнения запросов только для чтения. Когда пользователю нужно вывести список подключений, исследовать таблицы, описать схемы, выполнить запросы или сгенерировать контекст схемы, удобный для ИИ, из управляемых DBX баз данных. НЕ используйте для операций записи, если только пользователь явно не подтвердит это параметром --allow-writes.
