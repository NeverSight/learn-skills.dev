Migrate an entire Gradle Kotlin/JVM project to Kotlin Toolchain — module.yaml + project.yaml, dependency-catalog reuse, CI rewrite, and local plugins replacing Gradle plugins with no Toolchain equivalent. TRIGGER when converting/migrating/porting a whole Gradle project (build.gradle/.kts, Gradle wrapper) to Kotlin Toolchain or Amper, not just one plugin; when replacing Gradle plugins (`application`, axion-release, jib, detekt/ktlint, custom `processResources`/codegen); when adapting CI (`./gradlew build`/`check`/`release`) to `./kotlin` commands; when translating `gradle/libs.versions.toml` incl. `[bundles]`; when `buildSrc`/`build-logic` or `allprojects`/`subprojects` must become module templates. SKIP for porting one Gradle plugin (`gradle-to-kotlin-toolchain-plugin`), authoring a new plugin (`kotlin-toolchain-plugin-authoring`), and general Toolchain work with Gradle already gone (`kotlin-toolchain`).
