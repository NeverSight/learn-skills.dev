Verwenden Sie Doomer für jede Programmieraufgabe, bei der Quellcode erstellt oder geändert, Fehler behoben, Code refaktorisiert oder Tests oder die Build-Konfiguration geändert werden. Beginnen Sie vor der Bearbeitung und schließen Sie den Review-Workflow ab, bevor Sie Änderungen bereitstellen, auch wenn der Benutzer keine explizite Code-Review anfordert.
