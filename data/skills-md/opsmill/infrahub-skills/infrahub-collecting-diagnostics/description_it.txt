Raccolta di un pacchetto diagnostico locale redatto (log, configurazione, versione, stato) per il passaggio a un esperto OpsMill. ATTIVARE quando: Infrahub è rotto/fallisce/produce errori, l'utente chiede aiuto per il debug, desidera raccogliere log/diagnostica, prepara un passaggio per il supporto OpsMill, o riporta un crash/timeout/problema di connessione (errore di upgrade, ramo bloccato, contenitore CrashLoopBackOff, errori 500, OOM). NON ATTIVARE quando: si sta facendo il debug di un check, trasformazione, generatore, menu o schema nel repository (usare le competenze infrahub-managing-*), è già stato raccolto un pacchetto e l'utente vuole che venga analizzato (usare infrahub-analyzing-diagnostics), si sta aprendo un issue pubblico su GitHub (usare infrahub-reporting-issues), si stanno eseguendo query operative (usare infrahub-analyzing-data), o si sta pianificando un upgrade che non è ancora stato eseguito (usare infrahub-planning-upgrades). Rispondi sempre nella lingua dell'utente.
