Erstellt, validiert, formatiert und modifiziert Infrahub‑Schema‑YAML‑Dateien — Knoten, Generics, Attribute, Beziehungen und Erweiterungen. Prüft außerdem den Infrahub Marketplace auf ein bereits veröffentlichtes Schema, das wiederverwendet werden kann, bevor ein Domain‑Modell von Grund auf neu erstellt wird. AUSLÖSEN bei: Entwurf von Datenmodellen, Hinzufügen von Schema‑Knoten, Validierung von Schema‑Definitionen, Planung von Schema‑Migrationen, Modifikation oder Erweiterung eines bestehenden Schemas, Änderung eines Attributs oder einer Beziehung einer Knotentyp‑Klasse, Fehlersuche, warum ein Schema nicht geladen wird oder eine Migration abgelehnt wird, Suche im Marketplace nach einem fertigen Schema, Modellierung von Dateiobjekten / Anhängen / Uploads (PDFs, Bilder, Zertifikate, Dokumente), Formatierung von Schema‑Dateien, Kanonisierung der Schema‑Schlüsselreihenfolge oder Ausführung von `infrahubctl schema format` (einschließlich als CI‑Gate). NICHT AUSLÖSEN bei: Befüllung oder Bearbeitung von Objekt‑Daten­dateien (verwende infrahub-managing-objects), Schreiben von Checks/Generatoren/Transformationen, Abfragen von Live‑Daten, Planung eines Infrahub‑Versions‑Upgrades (verwende infrahub-planning-upgrades).
