Crea, valida, formatta e modifica i file YAML dello schema Infrahub — nodi, generici, attributi, relazioni ed estensioni. Controlla inoltre l'Infrahub Marketplace per uno schema pubblicato esistente da riutilizzare prima di modellare un dominio da zero. **ATTIVARE** quando: si progettano modelli di dati, si aggiungono nodi di schema, si convalidano le definizioni di schema, si pianificano migrazioni di schema, si modifica o si estende uno schema esistente, si cambia un attributo o una relazione su un tipo di nodo, si fa debugging del motivo per cui uno schema non si carica o una migrazione viene respinta, si verifica il marketplace per uno schema pronto all'uso, si modellano oggetti file/allegati/caricamenti (PDF, immagini, certificati, documenti), si formattano i file di schema, si canonicalizza l'ordine delle chiavi dello schema, o si esegue `infrahubctl schema format` (anche come gate CI). **NON ATTIVARE** quando: si popolano o si modificano file di dati oggetto (usare infrahub-managing-objects), si scrivono controlli/generatori/trasformazioni, si interrogano dati live, si pianifica un aggiornamento della versione di Infrahub (usare infrahub-planning-upgrades).
