Crea, valida, formatea y modifica archivos YAML del esquema Infrahub — nodos, genéricos, atributos, relaciones y extensiones. También verifica el Marketplace de Infrahub en busca de un esquema publicado existente para reutilizar antes de modelar un dominio desde cero. DISPARAR cuando: diseñar modelos de datos, añadir nodos de esquema, validar definiciones de esquema, planificar migraciones de esquema, modificar o ampliar un esquema existente, cambiar un atributo o relación en un tipo de nodo, depurar por qué un esquema no se carga o una migración es rechazada, consultar el marketplace para encontrar un esquema listo para usar, modelar objetos de archivo / adjuntos / cargas (PDF, imágenes, certificados, documentos), formatear archivos de esquema, canonizar el orden de claves del esquema, o ejecutar `infrahubctl schema format` (incluido como una puerta de CI). NO DISPARAR cuando: poblar o editar archivos de datos de objetos (use infrahub‑managing‑objects), escribir comprobaciones/generadores/transformaciones, consultar datos en vivo, planificar una actualización de versión de Infrahub (use infrahub‑planning‑upgrades).
