Infrahub 스키마 YAML 파일(노드, 제네릭, 속성, 관계 및 확장)을 생성하고, 검증하며, 포맷하고, 수정합니다. 또한 도메인을 처음부터 모델링하기 전에 재사용할 수 있는 기존에 공개된 스키마가 있는지 Infrahub Marketplace를 확인합니다. TRIGGER when: 데이터 모델을 설계할 때, 스키마 노드를 추가할 때, 스키마 정의를 검증할 때, 스키마 마이그레이션을 계획할 때, 기존 스키마를 수정하거나 확장할 때, 노드 종류의 속성이나 관계를 변경할 때, 스키마가 로드되지 않거나 마이그레이션이 거부되는 이유를 디버깅할 때, 마켓플레이스에서 오프‑더‑쉘프 스키마를 확인할 때, 파일 객체/첨부파일/업로드(PDF, 이미지, 인증서, 문서)를 모델링할 때, 스키마 파일을 포맷할 때, 스키마 키 순서를 정규화할 때, 또는 `infrahubctl schema format`을 실행할 때( CI 게이트 포함). DO NOT TRIGGER when: 객체 데이터 파일을 채우거나 편집할 때( infrahub-managing-objects 사용), 검사/제너레이터/변환을 작성할 때, 실시간 데이터를 쿼리할 때, Infrahub 버전 업그레이드를 계획할 때( infrahub-planning-upgrades 사용).
