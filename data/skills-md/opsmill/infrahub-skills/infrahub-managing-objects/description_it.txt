Crea, modifica e gestisce i file YAML dei dati degli oggetti Infrahub per popolare istanze dell'infrastruttura — dispositivi, sedi, organizzazioni e moduli. ATTIVARE quando: si creano istanze di dispositivi, si popolano file dati, si definiscono sedi o organizzazioni, si aggiungono oggetti dell'infrastruttura, si modifica o si estende un file dati esistente, si aggiornano i valori degli attributi o i collegamenti relazionali su oggetti già definiti in un file dati, si fa debugging per capire perché un oggetto non si carica. NON ATTIVARE quando: si progetta o si modifica gli schemi, incluso cambiare la definizione di un attributo o di una relazione su un tipo di nodo (usare infrahub‑managing‑schemas), si scrivono controlli/generatori Python, si interrogano dati in tempo reale.
