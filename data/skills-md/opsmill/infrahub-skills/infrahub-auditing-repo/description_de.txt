Überprüft ein Infrahub-Repository anhand von Best Practices und Regeln und erstellt einen strukturierten Compliance-Bericht. AUSLÖSEN, wenn: Überprüfung des Repositorys auf Compliance, Onboarding in ein bestehendes Projekt, Validierung vor der Bereitstellung, Erkennung von Problemen. NICHT AUSLÖSEN, wenn: Schemas erstellt werden, Prüfungen/Generatoren geschrieben werden, Live-Daten abgefragt werden, Objekte befüllt werden, ein Upgrade der Infrahub-Version geplant wird (verwenden Sie infrahub-planning-upgrades).
