Trasforma l'attrito da una sessione di skill Infrahub in una issue di GitHub revisionata sulla guida di una skill Infrahub. Le skill Infrahub falliscono silenziosamente: una regola mancante o poco chiara non provoca un crash, ma genera round‑trip aggiuntivi e sollecitazioni ripetute all'utente. Questa skill raccoglie le prove di tale attrito, controlla il tracker per un report esistente, determina se il problema è della skill o del prodotto sottostante e redige una proposta di modifica della regola. Non invia mai nulla autonomamente: consegna la bozza redatta a infrahub‑reporting‑issues, che la mostra all'utente e ottiene un'approvazione esplicita prima di qualsiasi invio. ATTIVA quando: si accetta un'offerta di attrito, l'utente dice “report skill friction”, chiede perché una skill Infrahub continua a fallire o ha richiesto così tanti tentativi, o vuole segnalare una lacuna nella guida di una skill Infrahub. NON ATTIVA quando: si segnala un bug in Infrahub stesso o in qualsiasi altro prodotto opsmill/infrahub‑* (usare infrahub‑reporting‑issues), o per lavori ordinari su Infrahub in cui non si è verificato alcun problema.
