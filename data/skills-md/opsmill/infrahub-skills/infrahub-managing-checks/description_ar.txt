ينشئ ويعدِّل ويصوِّب تعريفات فحص Infrahub — منطق التحقق باستخدام بايثون، استعلامات GraphQL، واختبارات مدفوعة بـ YAML لأنابيب التغيير المقترحة. يُفَعَّل عندما: كتابة فحوصات التحقق، إنشاء فحوصات بايثون، بناء حراس جودة البيانات للتغييرات المقترحة، كتابة أو تشغيل اختبارات لفحص، تعديل أو توسيع فحص موجود، تصحيح سبب فشل الفحص، مرور الفحص عندما لا يجب، أو الإشارة إلى العقد الخاطئة. لا يُفَعَّل عندما: تصميم المخططات، استعلام البيانات الحية، بناء التحويلات أو المولدات.
