ينشئ ويعدل ويفحص تحويلات Infrahub التي تحول البيانات إلى JSON أو نص أو CSV أو تكوينات الأجهزة باستخدام قوالب Python أو Jinja2، مع اختبارات مدفوعة بـ YAML. يُفعل عندما: بناء توليد التكوين، تصدير البيانات، تحويل الصيغ، قوالب Jinja2، خطوط أنابيب القطع الأثرية، كتابة أو تشغيل اختبارات لتحويل، تعديل أو توسيع تحويل أو قالب موجود، تصحيح السبب وراء إظهار تحويل مخرجات غير صحيحة أو فشل قطعة أثرية في الإنشاء. لا يُفعل عندما: تصميم المخططات، كتابة فحوصات التحقق، إنشاء المولدات، استعلام البيانات الحية.
