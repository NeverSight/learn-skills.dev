Crea, modifica e debugga le trasformazioni Infrahub che convertono i dati in JSON, testo, CSV o configurazioni di dispositivi utilizzando template Python o Jinja2, con test guidati da YAML. ATTIVA quando: generazione di configurazioni, esportazione di dati, conversione di formati, template Jinja2, pipeline di artefatti, scrittura o esecuzione di test per una trasformazione, modifica o estensione di una trasformazione o template esistente, debug di una trasformazione che produce output errato o di un artefatto che non si genera. NON ATTIVARE quando: progetti schemi, scrivi controlli di validazione, crei generatori, interroghi dati in tempo reale.
