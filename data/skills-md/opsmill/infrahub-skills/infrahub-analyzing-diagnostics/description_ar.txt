حلل حزمة التشخيص التي تم جمعها مسبقًا باستخدام infrahub-collect — تتبع الأخطاء وتصنيف الفشل عبر سجلات الخدمات، وربط الحوادث، ومطابقة المشكلات المعروفة مع قضايا GitHub الخاصة بـ opsmill/infrahub. يُفَعَّل عندما: يقول المستخدم أنه جمع حزمة تشخيص، أو يزودك بمسار الحزمة، أو يلصق محتويات الحزمة — ويسأل ما الخطأ، أو يريد تحليل السجلات أو تتبع الأخطاء، أو يسأل «ماذا تقول هذه الحزمة»، أو يريد تصنيف/ربط الأخطاء، أو يسأل ما إذا كان العطل مشكلة معروفة. لا يُفَعَّل عندما: لا توجد حزمة بعد — اجمع واحدة أولًا (استخدم infrahub-collecting-diagnostics)، أو عند تقديم التقرير عن المشكلة نفسها (استخدم infrahub-reporting-issues)، أو عند الاستعلام عن البيانات الحية (استخدم infrahub-analyzing-data). يرجى دائمًا الرد بلغة المستخدم.
