قم بتخزين مخرجات مهام وكيل الذكاء الاصطناعي والحوار المتعلق بالمهمة كذاكرة للمشروع في ملف .memory. استخدمها للتعاون بين الإنسان والوكيل، والاستمرار عبر السياقات، وتسليم العمل، والصيانة المستقبلية بعد تنفيذ أو إصلاح أو إعادة هيكلة أو إكمال ميزة/متطلب. عند التحميل، اقرأ فقط سجلات .memory والوثائق ذات الصلة بالمشروع، استخلص الحوار المهم للمهمة، قرر ما إذا كان يجب إنشاء أو تحديث الذاكرة قبل الانتهاء، وقم بتحسين/ضغط/تنظيم/أرشفة سجلات .memory عند الطلب. عندما يستدعي المستخدم battle-memory مع init أو initialization أو install أو initialize، قدم إرشادات المشروع عن طريق تحديث ملفي AGENTS.md و CLAUDE.md بتعليمات التحميل التلقائي لذاكرة المعركة.
