Résoudre les faits externes actuels, la documentation officielle, les comportements des bibliothèques et les contrats d’API en se référant aux sources primaires avant l’implémentation. Utiliser lors de la consultation de la documentation d’une bibliothèque, de la vérification des changements incompatibles, de l’investigation d’API externes ou de la validation des versions du framework — même si l’utilisateur ne mentionne pas explicitement « fable-research » (par exemple « vérifier la documentation la plus récente », « quelle est l’API pour X dans la version Y », « chercher les spécifications du SDK », « vérifier le support de la bibliothèque »). NE PAS l’utiliser pour l’exploration de code locale au dépôt (utiliser fable-discover) ou pour écrire du code d’implémentation directement (utiliser fable-tdd ou fable-execute).

Veuillez toujours répondre dans la langue de l’utilisateur.
