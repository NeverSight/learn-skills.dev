Risolvi i fatti esterni attuali, la documentazione ufficiale, i comportamenti delle librerie e i contratti API confrontandoli con le fonti primarie prima dell'implementazione. Usalo quando consulti la documentazione di una libreria, verifichi modifiche incompatibili, indaghi API esterne o controlli le versioni del framework — anche se l'utente non menziona esplicitamente “fable‑research” (ad es. “controlla la documentazione più recente”, “qual è l'API per X nella versione Y”, “cerca le specifiche SDK”, “verifica il supporto della libreria”). NON usarlo per l’esplorazione del codice locale del repository (usa fable‑discover) né per scrivere direttamente codice di implementazione (usa fable‑tdd o fable‑execute).

Rispondi sempre nella lingua dell'utente.
