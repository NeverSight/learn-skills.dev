Klärung aktueller externer Fakten, offizieller Dokumentation, Bibliotheksverhalten und API‑Verträge anhand primärer Quellen vor der Implementierung. Verwenden Sie dies, wenn Sie Bibliotheksdokumentation konsultieren, Breaking Changes prüfen, externe APIs untersuchen oder Framework‑Versionen verifizieren – selbst wenn der Benutzer nicht explizit „fable-research“ sagt (z. B. „prüfe die neuesten Docs“, „wie lautet die API für X in Version Y“, „suche SDK‑Spezifikationen nach“, „verifiziere Bibliotheksunterstützung“). NICHT für die repository‑lokale Code‑Erkundung verwenden (verwenden Sie fable-discover) oder für das direkte Schreiben von Implementierungscode (verwenden Sie fable-tdd oder fable-execute).

Bitte immer in der Sprache des Benutzers antworten.
