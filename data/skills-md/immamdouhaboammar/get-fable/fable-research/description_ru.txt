Уточняйте текущие внешние факты, официальную документацию, поведение библиотек и контракты API, сверяясь с первоисточниками, прежде чем приступать к реализации. Используйте это при обращении к документации библиотек, проверке несовместимых изменений, расследовании внешних API или проверке версий фреймворков — даже если пользователь явно не упоминает «fable-research» (например, «проверьте последние документы», «какой API для X в версии Y», «найдите спецификации SDK», «проверьте поддержку библиотеки»). Не используйте для исследования кода в репозитории (используйте fable-discover) и для непосредственного написания кода реализации (используйте fable-tdd или fable-execute).
