Esegui modellazione delle minacce, valutazioni delle vulnerabilità, sanitizzazione dei segreti e revisioni di sicurezza attraverso i confini di fiducia, i flussi di autenticazione e gli input non attendibili. Usalo quando auditi la logica di autenticazione/autorizzazione, ispetti le API per rischi di injection/CORS/CSRF, controlli credenziali hard‑coded o rivedi diff sensibili alla sicurezza — anche se l'utente non dice esplicitamente “fable-security” (ad es. “audit di sicurezza di questo codice”, “controlla le vulnerabilità”, “verifica la logica di auth”, “scansiona per segreti trapelati”). NON usarlo per revisioni di stile generali (usa fable-review) o per correzioni di bug non legati alla sicurezza (usa fable-tdd).

Rispondi sempre nella lingua dell’utente.
