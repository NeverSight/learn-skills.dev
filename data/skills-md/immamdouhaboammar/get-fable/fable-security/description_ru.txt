Проводите моделирование угроз, оценку уязвимостей, очистку секретов и проверки безопасности на границах доверия, в потоках аутентификации и при вводе недоверенных данных. Используйте при аудите логики аутентификации/авторизации, проверке API на уязвимости типа внедрения, CORS, CSRF, поиске жестко закодированных учетных данных или при ревью диффов, чувствительных к безопасности — даже если пользователь явно не упоминает «fable-security» (например: «провести аудит безопасности этого кода», «проверить на уязвимости», «проверить логику auth», «сканировать на утечки секретов»). НЕ используйте для общих стилистических проверок (используйте fable-review) или для исправления не-секурных багов (используйте fable-tdd).
