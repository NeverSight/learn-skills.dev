Gérez une mémoire persistante basée sur des fichiers, en indexant les préférences utilisateur, les retours et les contraintes architecturales entre les sessions dans des dépôts structurés MEMORY.md. Utilisez‑le lors de l’enregistrement des retours utilisateur, du stockage des conventions du projet, du rappel des contraintes architecturales entre les sessions, ou de l’indexation d’une mémoire de projet durable — même si l’utilisateur ne dit pas explicitement « fable‑memory » (par ex. « remember this preference », « save to memory », « what are my project rules », « recall user feedback »). NE l’utilisez PAS pour l’état de tâche volatile stocké dans .fable/state.json.

Veuillez toujours répondre dans la langue de l’utilisateur.
