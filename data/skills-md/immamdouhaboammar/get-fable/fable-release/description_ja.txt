リポジトリのマージおよびリリースの準備状況を、必要な品質ゲート、クリーンな Git ワーキングツリー、検証済みの配布アーティファクトに対して監査・認証します。リリースタグの作成、リリースチェックリスト項目の検証、npm / PyPI パッケージの公開、またはブランチのマージ認証を行う際に使用してください — ユーザーが明示的に「fable‑release」と言っていなくても（例: 「リリースを準備する」「これでマージできるか？」「本番に出荷する」「パッケージを公開する」）使用します。検証が古い、失敗している、または欠落している場合は使用しないでください（まず fable‑verify を使用してください）。
