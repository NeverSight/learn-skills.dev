Resolver conflictos de fusión o reajuste de git en curso por intención rastreada a fuentes primarias. Úselo cuando se encuentre con conflictos de fusión, marcadores de CONFLICTO en archivos, pausas de rebase o cuando git le pida que resuelva trozos en conflicto, incluso si el usuario solo dice "arreglar esta fusión". NO utilizar para crear nuevas ramas o rebases de rutina sin conflictos.
