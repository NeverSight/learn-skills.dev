Risolvi i conflitti di merge o rebase di git in corso basandoti sull'intento tracciato alle fonti primarie. Usa quando incontri conflitti di merge, marcatori CONFLICT nei file, pause del rebase, o quando git chiede di risolvere i blocchi in conflitto — anche se l'utente dice semplicemente “fix this merge”. NON usarlo per creare nuovi rami o per rebase di routine senza conflitti. Per favore rispondi sempre nella lingua dell'utente.
