Conciliez ce que disent les chiffres avec ce que disent les utilisateurs, et concevez l’étude qui résout le problème plutôt que de le reformuler. Utilisez cela lorsque les données comportementales et les résultats de recherche pointent dans des directions différentes. Pour lire les données seules, utilisez `behavioural-analytics` ; pour synthétiser les entretiens seuls, utilisez `affinity-diagram`.
