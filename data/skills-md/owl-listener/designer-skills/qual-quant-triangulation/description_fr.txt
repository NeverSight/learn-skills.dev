Conciliez ce que les chiffres disent avec ce que les utilisateurs disent, et concevez l’étude qui le résout plutôt que le répéter. Utilisez lorsque les données comportementales et les résultats de recherche pointent dans des directions différentes. Pour lire les données seules, utilisez `behavioural-analytics` ; pour synthétiser les entretiens seuls, utilisez `affinity-diagram`.
