Lee embudos, curvas de retención y datos de eventos como diseñador, separando un problema de diseño de un artefacto de seguimiento. Utilice cuando le entreguen datos de productos que no diseñó y pregunte por qué la gente los deja. Para elegir qué medir, use `metrics-definition' (ux-strategy); para ejecutar una prueba controlada, use `a-b-test-design` (prototyping-testing).
