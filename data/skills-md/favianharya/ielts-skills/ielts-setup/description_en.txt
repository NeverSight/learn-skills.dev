Install, set up, check, repair, update or uninstall the IELTS coach (the ielts-preparation skill) on this machine: installs the skills, links them for Claude Code and omp, downloads the official IELTS band-descriptor PDFs, picks Claude models that work here and adds an `ielts` shell alias, then runs the learner intake to create the profile. Use when the user wants to install or set up IELTS preparation, moves to a new computer, asks to check or fix the setup, or when ielts-preparation reports its CLI or profile is missing.
