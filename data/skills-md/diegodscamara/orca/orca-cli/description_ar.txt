تشغيل أشجار العمل التي تديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر أوامر `orca` CLI. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". يُفضَّل ذلك على استخدام شجرة Git العادية، أو PTYs المؤقتة، أو Computer Use عندما تكون حالة Orca متداخلة. استخدم Computer Use فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة رسومية لا يمكن لسطر الأوامر أو نظام الملفات أو الـ API تحقيقه.
