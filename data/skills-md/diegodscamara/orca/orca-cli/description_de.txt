Verwende dies, wenn der Benutzer „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“ sagt. Bevorzuge es gegenüber rohen Git‑Worktrees, ad‑hoc PTYs oder Computer‑Use, wenn Orca‑Zustand involviert ist. Nutze Computer‑Use nur, wenn ein sichtbares Fenster eine GUI‑Steuerung erfordert, die eine CLI, das Dateisystem oder eine API nicht leisten kann.
