Richiedi l'accesso a un'API pubblicata nel portale API Experience Hub creando un contratto tra una delle tue applicazioni e una specifica istanza/livello dell'API. Utilizza questa funzione quando un consumatore del portale deve scoprire i livelli disponibili e i tipi di concessione, creare un contratto, rivedere i contratti esistenti o modificare il livello SLA di un contratto attivo.
