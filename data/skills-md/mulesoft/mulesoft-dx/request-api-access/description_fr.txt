Demander l’accès à une API publiée dans un portail API Experience Hub en créant un contrat entre l’une de vos applications et une instance/niveau d’API spécifique. À utiliser lorsqu’un consommateur du portail doit découvrir les niveaux et types d’octroi disponibles, créer un contrat, examiner les contrats existants ou modifier le niveau SLA d’un contrat actif.
