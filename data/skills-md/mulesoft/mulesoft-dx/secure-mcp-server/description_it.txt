Proteggi un server MCP applicando una policy dal catalogo. Gestisce più punti di partenza: da un'istanza esistente di API Manager, da un asset del server MCP in Exchange o da zero pubblicando prima il server MCP. Da utilizzare quando l'utente desidera proteggere un server MCP, aggiungere limitazione di velocità, applicare OAuth2, imporre una whitelist di IP o proteggere qualsiasi server MCP con una policy, indipendentemente dal punto in cui si trovi nel processo di configurazione.
