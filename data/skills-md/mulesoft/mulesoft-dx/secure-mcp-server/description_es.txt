Asegure un servidor MCP aplicando una política del catálogo. Maneja múltiples puntos de partida: desde una instancia existente de API Manager, desde un activo de servidor MCP en Exchange o, desde cero, publicando primero el servidor MCP. Úselo cuando el usuario quiera asegurar un servidor MCP, añadir limitación de velocidad, aplicar OAuth2, imponer listas blancas de IP o proteger cualquier servidor MCP con una política, sin importar en qué etapa del proceso de configuración se encuentren.
