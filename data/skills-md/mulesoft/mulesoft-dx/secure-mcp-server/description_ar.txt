تأمين خادم MCP عبر تطبيق سياسة من الكتالوج. يدعم نقاط بدء متعددة: من مثيل مدير API موجود، من أصل خادم MCP في Exchange، أو من الصفر عن طريق نشر خادم MCP أولاً. يُستخدم عندما يرغب المستخدم في تأمين خادم MCP، إضافة تحديد معدل الطلبات، تطبيق OAuth2، فرض السماح لقوائم IP، أو حماية أي خادم MCP بسياسة — بغض النظر عن مرحلة الإعداد التي يكونون فيها.
