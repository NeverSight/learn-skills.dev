Sécurisez un serveur MCP en appliquant une politique du catalogue. Gère plusieurs points de départ : à partir d’une instance existante d’API Manager, d’un actif serveur MCP dans Exchange, ou à partir de zéro en publiant d’abord le serveur MCP. À utiliser lorsque l’utilisateur souhaite sécuriser un serveur MCP, ajouter une limitation de débit, appliquer OAuth2, imposer une liste blanche d’IP ou protéger tout serveur MCP avec une politique — quel que soit le stade du processus d’installation.
