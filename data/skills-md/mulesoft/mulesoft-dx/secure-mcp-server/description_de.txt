Sichern Sie einen MCP-Server, indem Sie eine Richtlinie aus dem Katalog anwenden. Unterstützt mehrere Ausgangspunkte: von einer bestehenden API‑Manager‑Instanz, von einem MCP‑Server‑Asset in Exchange oder von Grund auf, indem Sie den MCP‑Server zuerst veröffentlichen. Verwenden Sie dies, wenn der Benutzer einen MCP‑Server sichern, eine Ratenbegrenzung hinzufügen, OAuth2 anwenden, die IP‑Whitelist durchsetzen oder jeden MCP‑Server mit einer Richtlinie schützen möchte – unabhängig davon, in welcher Phase des Einrichtungsprozesses er sich befindet.
