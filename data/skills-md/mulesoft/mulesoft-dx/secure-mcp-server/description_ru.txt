Защитите сервер MCP, применив политику из каталога. Поддерживает несколько точек начала: из существующего экземпляра API Manager, из актива MCP‑сервера в Exchange или с нуля, публикуя сервер MCP первым. Используйте, когда пользователь хочет защитить сервер MCP, добавить ограничение скорости, применить OAuth2, внедрить белый список IP‑адресов или защитить любой сервер MCP политикой — независимо от того, на каком этапе настройки он находится.
