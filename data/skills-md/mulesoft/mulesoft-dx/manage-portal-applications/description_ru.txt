Управляйте приложениями, содержащими учетные данные API, внутри портала API Experience Hub. Используйте, когда потребителю портала нужно получить список своих приложений, проверить доступность имени, создать новое приложение, обновить метаданные, сменить клиентский секрет или удалить приложение, которым он больше не пользуется.
