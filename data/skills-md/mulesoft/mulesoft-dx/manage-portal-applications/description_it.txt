Gestisci le applicazioni che contengono credenziali API all'interno di un portale API Experience Hub. Utilizza questa funzionalità quando un consumatore del portale deve elencare le proprie applicazioni, verificare se un nome è disponibile, creare una nuova applicazione, aggiornare i metadati, ruotare il segreto client o eliminare un'applicazione che non utilizza più.
