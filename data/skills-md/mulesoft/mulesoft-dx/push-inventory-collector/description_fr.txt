Générez un script de collecteur hébergé par le client qui répertorie les agents, les serveurs MCP ou les API REST, télécharge chaque ZIP d’actif avec POST /push, puis se termine par POST /commit. DÉCLENCHER lorsque : l'utilisateur demande de pousser l’inventaire, de générer un script de poussée, « How to Push », scanner auto‑géré ou de télécharger la compétence du collecteur. Les phrases déclencheuses incluent « push inventory », « generate a push script », « How to Push », « self-managed scanner », « collector skill », « POST /push », « POST /commit ». NE PAS DÉCLENCHER lorsqu’on crée un scanner pull (compétence setup-service-scanner) ou qu’on exécute un scan hébergé (compétence run-service-scan-and-view-results). Veuillez toujours répondre dans la langue de l’utilisateur.
