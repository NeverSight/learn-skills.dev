Genera uno script collector ospitato dal cliente che elenchi agenti, server MCP o API REST, carichi ogni archivio ZIP di asset con POST /push e termini con POST /commit. ATTIVA quando: l'utente chiede di pushare l'inventario, generare uno script push, How to Push, scanner auto‑gestito o scaricare la collector skill. Le frasi di attivazione includono "push inventory", "generate a push script", "How to Push", "self-managed scanner", "collector skill", "POST /push", "POST /commit". NON ATTIVARE quando: si crea uno scanner pull (skill setup-service-scanner) o si esegue una scansione hostata (skill run-service-scan-and-view-results). Rispondi sempre nella lingua dell'utente.
