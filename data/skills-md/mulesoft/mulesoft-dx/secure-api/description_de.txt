Sichern Sie eine API, indem Sie eine Richtlinie aus dem Katalog anwenden. Verarbeitet mehrere Startpunkte:
Punkten: von einer vorhandenen API-Manager-Instanz, von einem Exchange-Asset, das eine
eine Instanz benötigt, oder von Grund auf neu. Zu verwenden, wenn der Benutzer eine API sichern,
eine Ratenbegrenzung hinzufügen, OAuth2 anwenden, IP-Allowlisting erzwingen oder eine beliebige API mit
einer Richtlinie schützen möchte – unabhängig davon, an welchem Punkt des Einrichtungsprozesses er sich befindet.
