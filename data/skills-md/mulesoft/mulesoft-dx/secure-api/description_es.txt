Proteja una API aplicando una política del catálogo. Gestiona varios puntos de partida:
de partida: desde una instancia existente de API Manager, desde un activo de Exchange que necesita
una instancia o desde cero. Úselo cuando el usuario quiera proteger una API, añadir
una limitación de tasa, aplicar OAuth2, aplicar una lista de direcciones IP permitidas o proteger cualquier API con
una política, independientemente de en qué punto se encuentren del proceso de configuración.
