Sécuriser une API en appliquant une politique du catalogue. Prend en charge plusieurs points de départ :
de départ : à partir d'une instance API Manager existante, à partir d'une ressource Exchange qui nécessite
d'une instance, ou à partir de zéro. À utiliser lorsque l'utilisateur souhaite sécuriser une API, ajouter
une limitation de débit, appliquer OAuth2, appliquer une liste d'autorisations IP ou protéger n'importe quelle API avec
une politique, quelle que soit l'étape du processus de configuration à laquelle ils se trouvent.
