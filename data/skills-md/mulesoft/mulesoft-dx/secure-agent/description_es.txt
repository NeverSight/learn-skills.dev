Proteja un agente aplicando una política del catálogo. Gestiona varios
puntos de partida: desde una instancia existente de API Manager, desde un activo de agente
en Exchange, o desde cero publicando primero el agente. Utilícelo cuando el usuario
quiere proteger un agente, añadir una limitación de tasa, aplicar OAuth2, aplicar una lista de IP
de IP o proteger cualquier agente con una política, independientemente de en qué punto
se encuentren en el proceso de configuración.
