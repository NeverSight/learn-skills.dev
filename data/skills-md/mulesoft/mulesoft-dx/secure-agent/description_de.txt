Sichern Sie einen Agenten, indem Sie eine Richtlinie aus dem Katalog anwenden. Verarbeitet mehrere
Ausgangspunkte: von einer vorhandenen API-Manager-Instanz, von einem Agent-Asset
in Exchange oder von Grund auf neu, indem der Agent zuerst veröffentlicht wird. Verwenden, wenn der Benutzer
einen Agenten sichern, eine Ratenbegrenzung hinzufügen, OAuth2 anwenden, IP-Allowlisting erzwingen
einer IP-Whitelist durchsetzen oder einen beliebigen Agenten mit einer Richtlinie schützen möchte – unabhängig davon, wo er sich
sich im Einrichtungsprozess befinden.
