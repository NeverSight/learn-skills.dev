Sécurisez un agent en appliquant une politique du catalogue. Gère plusieurs
points de départ : à partir d’une instance API Manager existante, à partir d’une ressource d’agent
dans Exchange, ou à partir de zéro en publiant d’abord l’agent. À utiliser lorsque l'utilisateur
souhaite sécuriser un agent, ajouter une limitation de débit, appliquer OAuth2, appliquer une liste d'adresses IP
d'adresses IP, ou de protéger n'importe quel agent à l'aide d'une politique, quelle que soit l'étape
se trouvent dans le processus de configuration.
