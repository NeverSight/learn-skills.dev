답변이 복잡할 경우, 이를 한 페이지짜리 시각적 HTML 설명서로 렌더링합니다: 모델은 짧은 확장 마크다운 초안만 작성하고, 번들된 CLI가 템플릿, 컴포넌트, SVG 자동 레이아웃 및 STE 제어 작성 검사를 처리하여 한 번의 호출로 단일 파일 페이지를 생성합니다.  
사용자가 설명 영상을 요청할 때도 사용합니다(예: “3b1b 스타일 비디오”, “make a video”, “做个视频”, “讲成视频”): 동일한 초안 형식에 내레이션 라인을 추가하여 애니메이션과 내레이션이 포함된 플레이어 페이지를 생성하고, 옵션으로 MP4 파일도 만들 수 있습니다.  
사용자가 `/answer-me-with-html config` 라고 말하거나 설정을 변경하고 싶을 때도 사용합니다(자동 브라우저 열기, 항상 켜짐 모드, 기본 테마 등).  
답변에 다음 중 하나라도 포함될 경우, 사용자가 요청하지 않아도 적극적으로 사용합니다: 3개 이상의 상호 연관된 개념; 분기나 다중 행위자가 있는 흐름/프로토콜/아키텍처; 3개 이상의 차원을 갖는 비교 또는 트레이드오프; 계층 구조(디렉터리, 모듈, 분류 체계); 진화 또는 단계; 혹은 사용자가 “작동 원리를 설명해 주세요 / 이해가 안 돼요 / 다이어그램을 그려 주세요 / 이 코드베이스를 설명해 주세요 / 시각적으로 설명해 주세요 / 讲讲原理 / 没看懂 / 画个图 / 用 HTML 讲”이라고 말할 때.  
다음 경우에는 사용하지 마세요: 짧은 Q&A(≈150단어 이하로 명확히 답변될 경우), 즉시 복사하여 실행할 명령, 순수 코드 변경, 혹은 사용자가 일반 텍스트만 요청할 때.  
항상 사용자의 언어로 답변해 주세요.
