عندما يكون الجواب معقدًا، يُقدَّم كشرح بصري بصفحة HTML واحدة: يُكتب النموذج مسودة مختصرة بامتداد Markdown ممتد؛ يتولى CLI المدمج القوالب والمكوّنات وتخطيط SVG تلقائيًا وفحص كتابة يتحكم به STE، فينتج صفحة ملف واحد في نداء واحد. استخدم ذلك أيضًا عندما يطلب المستخدم فيديو شرحي ("فيديو بأسلوب 3b1b"، "اصنع فيديو"، "做个视频"، "讲成视频"): نفس تنسيق المسودة مضافًا إليه سطور السرد لتوليد صفحة مشغل متحركة مع رواية وربما ملف MP4. واستخدمه كذلك عندما يكتب المستخدم `/answer-me-with-html config` أو يرغب في تعديل الإعدادات (فتح المتصفح تلقائيًا، وضع دائم، السمة الافتراضية). استعمله بصورة استباقية دون طلب عندما يتضمن الجواب أيًا من: أكثر من ثلاثة مفاهيم مترابطة؛ تدفق/بروتوكول/هيكلية مع فروع أو عدة فاعلين؛ مقارنة أو موازنة عبر ثلاثة أبعاد أو أكثر؛ تسلسل هرمي (دليل، وحدات، تصنيفات)؛ تطور أو مراحل؛ أو عندما يقول المستخدم "اشرح كيف يعمل / لا أفهم / ارسم مخططًا / اشرح قاعدة الشيفرة هذه / اشرح بصريًا / 讲讲原理 / 没看懂 / 画个图 / 用 HTML 讲". لا تستخدمه لأجل: أسئلة وإجابات قصيرة (واضحة في أقل من ~150 كلمة)، أو أوامر نسخ وتنفيذ فورًا، أو تغييرات شفرة بحتة، أو عندما يطلب المستخدم نصًا عاديًا. يرجى دائمًا الرد بلغة المستخدم.
