Quando una risposta è complessa, renderizzala come un spiegatore visivo HTML su una pagina: il modello scrive solo una breve bozza in Markdown esteso; il CLI incorporato gestisce template, componenti, layout automatico SVG e un controllo di scrittura STE, producendo una pagina a file unico in una sola chiamata. Usalo anche quando l'utente richiede un video esplicativo ("video stile 3b1b", "crea un video", "做个视频", "讲成视频"): lo stesso formato di bozza più le righe di narrazione genera una pagina player animata e narrata e, opzionalmente, un MP4. Usalo inoltre quando l'utente dice `/answer-me-with-html config` o vuole modificare le impostazioni (apertura automatica del browser, modalità always‑on, tema predefinito). Impiegalo proattivamente, senza che venga chiesto, quando la risposta coinvolge uno dei seguenti casi: 3 o più concetti interrelati; un flusso / protocollo / architettura con rami o più attori; un confronto o trade‑off su tre o più dimensioni; una gerarchia (directory, moduli, tassonomie); un'evoluzione o fasi; o l'utente dice "spiega come funziona / non capisco / disegna un diagramma / spiega questo codebase / spiega visivamente / 讲讲原理 / 没看懂 / 画个图 / 用 HTML 讲". Non usarlo per: domande‑risposte brevi (chiare in meno di ~150 parole), comandi da copiare ed eseguire immediatamente, sole modifiche di codice, o quando l'utente richiede solo testo semplice.

Rispondi sempre nella lingua dell'utente.
