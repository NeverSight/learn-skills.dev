Cuando una respuesta es compleja, renderízala como un explicador visual en HTML de una página: el modelo escribe solo un borrador corto en Markdown extendido; el CLI incluido maneja plantillas, componentes, auto‑layout SVG y una verificación de escritura controlada por STE, produciendo una página de archivo único en una sola llamada. También úsalo cuando el usuario solicite un video explicativo ("video estilo 3b1b", "haz un video", "做个视频", "讲成视频"): el mismo formato de borrador más líneas de narración genera una página de reproductor animada y narrada y, opcionalmente, un MP4. También utilízalo cuando el usuario escriba `/answer-me-with-html config` o quiera cambiar la configuración (apertura automática del navegador, modo siempre activo, tema predeterminado). Empléalo proactivamente, sin que lo pidan, cuando la respuesta involucre cualquiera de: más de 3 conceptos interrelacionados; un flujo / protocolo / arquitectura con ramificaciones o múltiples actores; una comparación o compromiso en más de 3 dimensiones; una jerarquía (directorios, módulos, taxonomías); una evolución o fases; o cuando el usuario diga “explica cómo funciona / no lo entiendo / dibuja un diagrama / explica este código / explica visualmente / 讲讲原理 / 没看懂 / 画个图 / 用 HTML 讲”. No lo uses para: preguntas cortas y respuestas (claras en menos de ~150 palabras), comandos para copiar y ejecutar inmediatamente, cambios de código puro, o cuando el usuario solicite texto plano.

Por favor, responde siempre en el idioma del usuario.
