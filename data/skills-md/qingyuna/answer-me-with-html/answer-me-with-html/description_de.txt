Wenn eine Antwort komplex ist, wird sie als einseitiger visueller HTML‑Erklärer dargestellt: Das Modell erstellt nur einen kurzen erweiterten Markdown‑Entwurf; das mitgelieferte CLI verarbeitet Vorlagen, Komponenten, SVG‑Auto‑Layout und eine STE‑gesteuerte Schreibprüfung und erzeugt in einem Aufruf eine einseitige Datei. Verwende es auch, wenn der Nutzer nach einem Erklärvideo fragt („3b1b‑Stil‑Video“, „make a video“, „做个视频“, „讲成视频“): Das gleiche Entwurfsformat plus Erzählzeilen rendert eine animierte, vertonte Player‑Seite und optional ein MP4. Ebenso anwenden, wenn der Nutzer `/answer-me-with-html config` eingibt oder Einstellungen ändern möchte (Browser automatisch öffnen, Always‑On‑Modus, Standard‑Theme). Nutze es proaktiv, ohne dass man danach fragt, wenn die Antwort irgendeines der folgenden beinhaltet: mehr als drei miteinander verbundene Konzepte; ein Ablauf/Protokoll/Architektur mit Verzweigungen oder mehreren Akteuren; ein Vergleich oder ein Trade‑off über mehr als drei Dimensionen; eine Hierarchie (Verzeichnisse, Module, Taxonomien); eine Entwicklung oder Phasen; oder der Nutzer sagt „explain how it works“ / „I don’t get it“ / „draw a diagram“ / „explain this codebase“ / „explain visually“ / „讲讲原理“ / „没看懂“ / „画个图“ / „用 HTML 讲“. Nicht verwenden für: kurze Frage‑Antwort‑Paare (klar in unter ca. 150 Wörtern), sofort auszuführende Kopier‑und‑Einfüge‑Befehle, reine Code‑Änderungen oder wenn der Nutzer reinen Text verlangt.

Bitte immer in der Sprache des Nutzers antworten.
