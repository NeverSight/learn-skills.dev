قم بتزويد وكلاء الذكاء الاصطناعي بمواصفات مكونات HTML ذات ملف واحد ونظام القالب استنادًا إلى الجمالية الحديثة البسيطة لـ shadcn/ui. عندما يطلب المستخدمون سيناريوهات مثل "إنشاء صفحة/صفحة ويب بتنسيق HTML"، و"لوحة معلومات/لوحة مرئية للواجهة الأمامية"، و"مقابلة/تحليل/تقرير اختبار"، و"مصفوفة المقارنة/مقارنة الحلول"، و"تصور نتائج المراجعة كصفحة"، و"تقرير مراجعة التعليمات البرمجية"، و"عدم إخراج جدران تخفيض السعر/عدم إخراج جدران نصية"، و"تحويل نتائج التحليل إلى صفحة ويب تفاعلية ذات ملف واحد"، وما إلى ذلك، يجب استخدام هذه المهارة. بناء صفري، صفر npm، يحظر بشدة تضمين شبكات CDN الخارجية (لا يوجد خطر ظهور شاشة فارغة عند عدم الاتصال بالإنترنت)، HTML/CSS/SVG أصلي خالص، يدعم الوضع المظلم والفتح الفوري بنقرة مزدوجة.
