Fornire agli agenti AI una specifica del componente HTML a file singolo e un sistema di modelli basato sull'estetica moderna e minimalista di shadcn/ui. Quando gli utenti richiedono scenari come "generare una pagina/sito Web HTML", "dashboard/bacheca visiva frontend", "rapporto di intervista/analisi/test", "matrice di confronto/confronto di soluzioni", "visualizzare i risultati della revisione come una pagina", "report di revisione del codice", "non generare un muro di markdown/non produrre un muro di testo", "trasformare i risultati dell'analisi in una pagina Web interattiva a file singolo", ecc., è necessario utilizzare questa abilità. Zero build, zero npm, vieta severamente l'introduzione di CDN esterni (nessun rischio di schermata bianca a causa della perdita della rete), HTML/CSS/SVG nativo puro, supporto della modalità oscura e apertura istantanea con un doppio clic.
