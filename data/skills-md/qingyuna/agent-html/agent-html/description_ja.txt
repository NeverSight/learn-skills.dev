AI エージェントに単一ファイルの HTML コンポーネント仕様と、shadcn/ui のミニマリストでモダンな美学に基づくマスター テンプレート システムを提供します。ユーザーが「HTML ページ/Web ページの生成」、「フロントエンドのビジュアル ダッシュボード/ボード」、「インタビュー/分析/テスト レポート」、「比較マトリックス/ソリューションの比較」、「レビュー結果をページとして視覚化」、「コード レビュー レポート」、「マークダウン ウォールを出力しない/テキスト ウォールを生成しない」、「分析結果をインタラクティブな単一ファイルの Web ページに変換する」などのシナリオを要求する場合は、必ずこのスキルを使用してください。ゼロビルド、ゼロ npm、外部 CDN のインポートを厳しく禁止 (オフライン時に空白の画面が表示されるリスクなし)、純粋なネイティブ HTML/CSS/SVG、ダーク モードをサポートし、ダブルクリックで瞬時に開きます。
