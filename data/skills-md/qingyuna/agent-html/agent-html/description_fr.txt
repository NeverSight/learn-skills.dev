Fournir aux agents IA une spécification de composant HTML à fichier unique et un système de modèles basés sur l’esthétique moderne et minimaliste de shadcn/ui. Lorsque les utilisateurs demandent des scénarios tels que « générer une page/un site Web HTML », « un tableau de bord/un tableau visuel frontal », « un rapport d'entretien/d'analyse/de test », « une matrice de comparaison/comparaison de solutions », « visualiser les résultats de l'examen sous forme de page », « rapport de révision de code », « ne pas afficher de mur de démarques/ne pas afficher de mur de texte », « transformer les résultats de l'analyse en une page Web interactive à fichier unique », etc., cette compétence doit être utilisée. Zéro build, zéro npm, interdiction formelle d'introduire des CDN externes (aucun risque d'écran blanc dû à une perte de réseau), HTML/CSS/SVG natif pur, prise en charge du mode sombre et ouverture instantanée par double-clic.
