Bereitstellung einer Einzeldatei-HTML-Komponentenspezifikation und eines Vorlagensystems für KI-Agenten basierend auf der minimalistischen, modernen Ästhetik von shadcn/ui. Wenn Benutzer Szenarios wie „HTML-Seite/Website generieren“, „visuelles Frontend-Dashboard/Board“, „Interview/Analyse/Testbericht“, „Vergleichsmatrix/Lösungsvergleich“, „Überprüfungsergebnisse als Seite visualisieren“, „Codeüberprüfungsbericht“, „Keine Markdown-Wand/keine Textwand ausgeben“, „Analyseergebnisse in eine interaktive Einzeldatei-Webseite umwandeln“ usw. anfordern, muss diese Fähigkeit verwendet werden. Null Build, null NPM, striktes Verbot der Einführung externer CDNs (kein Risiko eines weißen Bildschirms aufgrund von Netzwerkverlust), reines natives HTML/CSS/SVG, Unterstützung des Dunkelmodus und sofortiges Öffnen mit einem Doppelklick.
