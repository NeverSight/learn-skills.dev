Genera tileset 2D pronti per il motore, pacchetti di oggetti, mappe a livelli, metadati di collisione e anteprime composte. Usalo quando l'utente richiede tiles, una tilemap, terreno, mappe 2D per Tiled/Godot/Unity o prop di atlante controllati per le cuciture. Non usarlo per fogli di animazione dei personaggi o per l'arte chiave dello store.

Per favore, rispondi sempre nella lingua dell'utente.
