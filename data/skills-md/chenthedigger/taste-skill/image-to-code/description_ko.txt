Codex를 위한 엘리트 웹사이트 이미지‑투‑코드 기술. 시각적으로 중요한 웹 작업에서는 먼저 디자인 이미지(들)를 직접 생성하고 이를 깊이 분석한 뒤, 가능한 한 최대한 일치하도록 웹사이트를 구현해야 합니다. Codex에서는 작은 압축 보드 대신 크고 가독성이 높으며 섹션별 이미지를 선호하고, 기존 이미지를 자르는 대신 섹션이나 상세 뷰용 새로운 독립 이미지를 생성해야 하며, 게으른 부족 생성을 피하고, 카드 안에 카드 안에 카드 형태의 UI를 피하며, 히어로 영역은 작고 깔끔하고 넓으며 가독성이 좋고 작은 노트북에서도 보이도록 유지해야 합니다.
