Compétence d'élite de conversion d'image en code pour les sites Web dans Codex. Pour les tâches web visuellement importantes, il doit d'abord générer lui‑même les images de conception, les analyser en profondeur, puis implémenter le site Web pour les reproduire aussi fidèlement que possible. Dans Codex, il doit privilégier les images grandes, lisibles et spécifiques à chaque section plutôt que de petits tableaux compressés, créer de nouvelles images autonomes pour les sections ou les vues détaillées au lieu de recadrer d'anciennes, éviter la sous‑génération paresseuse, éviter les interfaces cartes‑dans‑cartes‑dans‑cartes, et garder le hero propre, spacieux, lisible et visible sur un petit ordinateur portable.
