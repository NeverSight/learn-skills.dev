Create, edit, check and export diagrams with dg, a diagram-as-code tool with an HCL model, automatic layout and routed arrows, through its command line or MCP tools. Use whenever a project holds dg.hcl or views/*.layout.yaml, whenever the user mentions dg, and whenever they ask for an architecture, C4, infrastructure, network, flowchart, swimlane, entity-relationship, class or state machine diagram and the project doesn't already use another diagram tool.
