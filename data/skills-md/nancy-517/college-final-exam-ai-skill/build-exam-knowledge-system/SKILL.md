# 考试知识系统构建器 / Build Exam Knowledge System

把零散资料转化为可检索、可训练、可上考场的复习系统。在忠于老师课程口径的前提下，根据学科、题型、目标分数和剩余时间调整深度。

## 核心原则

1. 把老师重点、课堂 PPT、考试大纲、往年题、教材和补充资料视为不同证据层。
2. 默认优先级：老师明确重点 > 老师 PPT 与课堂例题 > 往年题 > 指定教材 > AI 补充。
3. 不编造课程专属结论。重要判断尽量标注文件名、页码、幻灯片或章节。
4. 材料不足时明确说明缺什么，不把通用知识伪装成老师口径。
5. 区分三类结论：
   - **已确认 / Confirmed**：老师明确讲授、指定或实际考过；
   - **高频推断 / Inferred high-frequency**：由重复题目、强调频次或课程结构推断；
   - **补充知识 / Supplementary**：有助于理解，但材料未证明属于考试范围。
6. 在时间约束下优先拿分，不为了“完整”牺牲得分效率。
7. 用通俗语言解释概念，同时保留学科精度、适用条件和边界。
8. 不静默丢弃用户笔记；发现错误时指出原说法、修正结果与依据。

## 工作流程 / Workflow

### 1. 建立考试约束

提取或合理推断考试日期、有效复习时间、题型分值、开闭卷规则、考试范围、老师重点、资料缺口、用户进度、薄弱点和目标分数。

时间极少时直接进入**紧急模式**，不要用大量澄清问题拖延。先声明必要假设，再给最高收益路线。

### 2. 盘点并排序资料

先形成来源表：

| 资料 | 覆盖范围 | 权威程度 | 最适合用途 | 缺口 |
|---|---|---:|---|---|

确定优先级前检查全部资料。长文档先提取目录、标题、重复术语、例题、老师标记和总结页。

### 3. 逆向分析考试

从往年题和老师重点分析：

- 题型及所属章节；
- 认知任务：记忆、解释、推导、计算、比较、应用或评价；
- 出现频率与分值；
- 常见措辞和触发词；
- 陷阱和必须写出的中间步骤。

综合重复度、分值、老师强调、前置价值和短期得分效率建立优先级：

`优先级 = 重复度 × 分值权重 × 老师强调 × 前置价值 × 得分效率`

证据不足时使用高、中、低三级，不伪造精确数字。

### 4. 构建课程骨架

建立三层结构：

1. **学科总问题**：这门课核心解决什么问题？
2. **模块逻辑**：章节之间如何连接？
3. **考试单元**：哪些概念、机制、公式、案例或论证能独立出题？

每个考试单元包含核心概念或公式、适用条件、机制或推导、常见问法、采分点、易混概念和来源定位。

### 5. 建立快速定位表

| 关键词 / 名言 / 数据特征 | 对应章节 | 理论或公式 | 必要推理 | 常见陷阱 |
|---|---|---|---|---|

理论型课程加入名言、材料主题和现实应用；计算型课程加入数据形态、命令词、公式选择信号和前提检查。

### 6. 把知识转化为答案

按题型生成具体模板：

- **名词解释/概念题**：定义 → 边界或条件 → 机制 → 例子或含义。
- **材料分析题**：定位理论 → 引用材料 → 解释机制 → 对照材料 → 结论。
- **比较评价题**：比较维度 → 异同 → 条件 → 权衡 → 判断。
- **推导计算题**：已知 → 目标 → 公式条件 → 分步计算 → 单位/含义 → 检查。
- **论述政策题**：问题 → 理论 → 机制 → 证据 → 反向条件 → 启示。

模板必须能直接用于考试，包含得分动词、公式槽位和中间步骤，避免空洞“万能句”。

### 7. 完成往年题与训练闭环

练习只能来自已经确认的范围。每题提供来源、考查单元、建议时间、完整思路、明确采分点、常见错误和一道迁移变式。

有往年题时模仿其题型比例、措辞和难度，不从通用题库随意拼题。

### 8. 生成分层复习包

按深度递减输出：

- **完整知识系统**：课程框架和来源地图；
- **考场定位表**：关键词到章节、题型和答法；
- **答案模板表**：题型结构、公式与采分点；
- **高频训练**：代表题、答案和变式；
- **最后冲刺**：必会内容、公式条件、陷阱和个人易错点。

生成完整复习包时读取 [references/output-blueprints.md](references/output-blueprints.md)。

### 9. 沉淀学科 Profile

考试后记录课程类型、考核模式、有效来源优先级、重复题型、有效模板、错误预测、高收益模块和下一轮改进。

通用 Skill 不收录未经授权的校内课件或试卷；只保存可复用方法、结构和用户有权公开的总结。

## 模式选择 / Modes

- **框架模式 / Framework**：课程结构和章节逻辑；
- **定位模式 / Localization**：关键词、名言、材料 → 章节与理论；
- **答题模式 / Answer**：采分模板和标准答案；
- **模拟模式 / Mock**：依据用户资料生成预测或训练卷；
- **紧急模式 / Emergency**：保分路线、高频重点、模板和最后十分钟清单；
- **沉淀模式 / Skill Capture**：把有效复习过程转成学科 Profile。

适配理论型、经济管理型和数量型课程时读取 [references/subject-adaptation.md](references/subject-adaptation.md)。

## 紧急模式

出现“明天考试”“今晚速成”“还有 30 分钟”“不要问我”等信号时：

1. 不进行宽泛访谈；
2. 用现有资料判断题型和优先级；
3. 输出“必须拿下 / 值得尝试 / 暂时放弃”；
4. 给出计算题流程或主观题采分骨架；
5. 根据用户之前错误生成最后提醒；
6. 对不确定内容标注证据等级。

## 质量检查 / Quality Gate

交付前确认：

- 每个“必须复习”判断都有依据；
- PPT 独有例子不会因教材目录没有出现而被遗漏；
- 章节地图和答题模板覆盖已知题型；
- 公式包含前提、变量含义和检查方法；
- 理论答案同时包含准确概念和材料应用；
- 已确认、高频推断、补充知识清晰分开；
- 输出符合真实剩余时间；
- 最短复习层可脱离长报告独立使用。
