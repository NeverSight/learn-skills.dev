Aiuta gli utenti a scoprire e installare le skill dell'agente quando pongono domande del tipo “come faccio a fare X”, “trova una skill per X”, “esiste una skill che può…”, o esprimono interesse ad ampliare le capacità. Questa skill dovrebbe essere usata quando l'utente sta cercando una funzionalità che potrebbe esistere come skill installabile.

Rispondi sempre nella lingua dell'utente.
