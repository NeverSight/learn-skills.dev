Revisione della sicurezza per i plugin Omarchy Quattro (widget della barra Quickshell/QML con helper bash, python o node) prima dell'invio al marketplace dei plugin. Da utilizzare durante la scrittura, il controllo o il rafforzamento di un plug-in Omarchy, quando un problema del mercato viene risolto con necessità o correzioni con esigenze di sicurezza, quando si prepara un invio di [Plugin] o [Verifica] o quando l'utente chiede se un plug-in è sicuro da pubblicare. Basato su ogni commento di revisione del manutentore nel repository del marketplace.
