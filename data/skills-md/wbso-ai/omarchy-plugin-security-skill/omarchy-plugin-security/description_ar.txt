المراجعة الأمنية لمكونات Omarchy Quattro الإضافية (أدوات شريط Quickshell/QML مع مساعدي bash أو python أو العقدة) قبل إرسالها إلى سوق المكونات الإضافية. يُستخدم عند كتابة مكون إضافي لـ Omarchy أو تدقيقه أو تقويته، أو عندما تحصل مشكلة في السوق على إصلاحات للاحتياجات أو إصلاحات لاحتياجات أمنية، أو عند إعداد إرسال [Plugin] أو [Verify]، أو عندما يسأل المستخدم عما إذا كان المكون الإضافي آمنًا للنشر. بناءً على كل تعليق لمراجعة المشرف في مستودع السوق.
