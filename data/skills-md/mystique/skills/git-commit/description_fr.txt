À utiliser lorsque l'utilisateur demande à créer ou à prévisualiser une validation Git, à rédiger un message de validation à partir des modifications actuelles, à valider un message proposé ou à diviser les modifications en validations logiques. Distinguer les demandes de message uniquement, de prévisualisation et d'exécution ; suivre les conventions de validation du référentiel ; préserver les limites de rassemblement existantes ; ne jamais organiser ni commettre de changements sans rapport ; interdire strictement l'auto-attribution des agents, les filigranes IA ou les co-auteurs d'agents ; et vérifiez chaque commit créé.
