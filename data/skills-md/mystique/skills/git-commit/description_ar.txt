يُستخدم عندما يطلب المستخدم إنشاء التزام Git أو معاينته، ​​أو كتابة رسالة التزام من التغييرات الحالية، أو التحقق من صحة الرسالة المقترحة، أو تقسيم التغييرات إلى التزامات منطقية. التمييز بين طلبات الرسائل فقط والمعاينة والتنفيذ؛ اتبع اتفاقيات التزام المستودع؛ الحفاظ على حدود التدريج الحالية؛ لا تقم مطلقًا بإجراء أو ارتكاب تغييرات غير ذات صلة؛ يُمنع بشدة الإسناد الذاتي للوكيل، أو العلامات المائية للذكاء الاصطناعي، أو المؤلفين المشاركين للوكيل؛ والتحقق من كل التزام تم إنشاؤه.
