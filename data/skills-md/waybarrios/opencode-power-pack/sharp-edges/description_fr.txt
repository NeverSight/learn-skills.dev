Identifiez les API sujettes aux erreurs, les configurations dangereuses et les conceptions d'armes à feu qui permettent des erreurs de sécurité. Utiliser pour l'ergonomie de l'API, la résistance à une mauvaise utilisation, les valeurs par défaut sécurisées ou les revues des puits de succès ; utiliser la revue de code pour les défauts généraux.
