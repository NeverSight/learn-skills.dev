Migrar un módulo personalizado de Odoo (o una carpeta completa de addons) de Odoo 14, 15, 16, 17, 18 o 19 a Odoo 20 y demostrar que se instala y funciona. Copia el módulo en un árbol de addons independiente de Odoo 20, ejecuta de forma segura los scripts upgrade_code propios de Odoo 20, escanea cada cambio ruptura conocido de 14→20 (manifest, Python/ORM, firmas de sobrescritura, xmlids y campos renombrados, controladores, vistas, t‑esc de QWeb del servidor, seguridad ir.access, JS backend Owl 3, publicWidget→Interactions, eliminación de jQuery/Font Awesome/Bootstrap 4, constructor de sitios web, eCommerce, portal, recorridos y pruebas, secretos), verifica cada importación de JS y Python contra el código real de Odoo 20, corrige el resto manualmente con subagentes paralelos por área, luego repite instalación + pruebas de humo con navegador sin cabeza y recorridos de flujo sobre una base de datos desechable hasta que quede limpio, y finaliza con una revisión de código. Úselo cuando el usuario diga "migrate <module> to 20", "make it installable on Odoo 20", "port to v20", "upgrade module from 16/17/18 to 20", o invoque /odoo-migrate-to-20.
