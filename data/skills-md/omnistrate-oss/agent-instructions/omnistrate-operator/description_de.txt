Verwenden Sie dies, wenn Sie einen auf Kubernetes-Operatoren basierenden Service (CRDs + Controller, z. B. CloudNativePG, Strimzi, KubeAI, ECK) auf der Omnistrate-Plattform einbinden; wenn Sie eine Omnistrate ServicePlanSpec mit systemWorkflows schreiben oder überprüfen; oder wenn eine Operator-/Helm+CR-Bereitstellung zu einem verwalteten SaaS-Angebot mit dem Lebenszyklus Erstellen/Ändern/Stoppen/Sichern/Wiederherstellen werden soll. Verwenden Sie für Docker-Compose-Services omnistrate-fde; verwenden Sie für das Debuggen fehlgeschlagener Instanzen omnistrate-sre.
