Rendre des documents, articles ou notes sous forme de HTML à une seule page, précisément formaté, avec les PDF et les images longues exportés par le modèle à l’aide de scripts/export.mjs (la page ne comporte plus de bouton d’exportation ; les exportations pour les comptes publics WeChat ne sont pas fournies — utilisez wechat‑formatter pour la mise en page des comptes publics). Utilisez cela lorsqu’un utilisateur souhaite formater un document en page Web, ou mentionne « mise en page », « générer une page Web », « créer une page » ou « Page Skill ».

Veuillez toujours répondre dans la langue de l’utilisateur.
