Renderiza documentos, artículos o notas en un HTML de una sola página finamente maquetado; los PDF y las imágenes largas son exportados por el modelo usando `scripts/export.mjs` (la página ya no incluye un botón de exportación; la exportación para cuentas públicas de WeChat no está disponible—utiliza `wechat-formatter` para el formato de WeChat). Utilízalo cuando el usuario necesite formatear un documento en una página web, o mencione “maquetación”, “generar página web”, “crear una página” o “Habilidad de página”.  

Por favor, responde siempre en el idioma del usuario.
