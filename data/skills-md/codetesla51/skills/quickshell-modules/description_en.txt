Build, fix, and verify quickshell modules in ~/dotfiles without killing the bar. Every module's UI is designed in HTML/CSS first BY DEFAULT, unless the user says to skip it: 3-5 options, all shown at once, opened with xdg-open in the user's default browser for them to pick, then ported to QML in the Bento design language using ONLY the system (Matugen) theme colors. Every module uses Matugen colors (at least two accent roles) and the shared glass format. Ported layouts get a height budget and a planned visual hierarchy up front and are verified by a text dump of the item tree, not by screenshots
