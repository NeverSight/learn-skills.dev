# rule-workbench

1. Link each rule to one context, source, stable ID, scope, and status.
2. Keep AGENTS.md as a short index; keep one canonical glossary and do not duplicate facts across documents.
3. Separate canonical terms from customer display mappings and preserve old IDs when meaning changes.
4. Use an ADR only for an irreversible, cross-boundary, or surprising decision.
5. Run pure rule checks and report conflicts, missing evidence, assumptions, and pending decisions.

Do not promote one-off code or feedback into a universal rule without evidence.
