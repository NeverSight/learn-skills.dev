Управляйте рабочими деревьями, управляемыми Orca, контекстами папок, терминалами, репозиториями, автоматизациями, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Используйте, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff» / «handover» / «give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочитайте этот способ вместо обычного git worktree, ad hoc PTY или использования компьютера, когда задействовано состояние Orca. Используйте Computer Use только тогда, когда требуется управлять видимым окном GUI, которое нельзя контролировать через CLI, файловую систему или API.
