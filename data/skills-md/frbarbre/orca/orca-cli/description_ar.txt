قم بتشغيل شجرات العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر سطر الأوامر `orca`. استخدمه عندما يقول المستخدم “$orca-cli”، “Orca worktree”، “child worktree”، “spawn codex/claude in a worktree”، “read/wait/send Orca terminal”، “handoff” / “handover” / “give this to another agent”، “Orca browser”، “orca artifacts”، أو “share skills”. فضّله على شجرة git العادية، PTYs العشوائية، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية الذي لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به.
