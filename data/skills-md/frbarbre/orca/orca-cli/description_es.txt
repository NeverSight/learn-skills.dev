Operar los worktrees gestionados por Orca, los contextos de carpetas, terminales, repositorios, automatizaciones, artefactos, intercambio de habilidades, comentarios de worktree y el navegador integrado de Orca a través del CLI `orca`. Utilizarlo cuando el usuario diga "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferirlo sobre git worktree sin gestionar, PTY ad hoc o Uso de Computadora cuando el estado de Orca está involucrado. Utilizar Uso de Computadora solo cuando una ventana visible necesite control GUI que un CLI, sistema de archivos o API no pueda hacer.
