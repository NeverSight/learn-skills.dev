Используйте этот навык каждый раз, когда используется файл .pptx — в качестве входного, выходного или того и другого. Охватывает создание, редактирование, колоды на основе шаблонов, извлечение контента, рекомендации по дизайну, правила борьбы с монотонностью и контроль качества. Запускается всякий раз, когда пользователь упоминает «колоду», «слайды», «презентацию», «pptx», «PowerPoint» или просит прочитать/создать/редактировать/проверить файл .pptx. Запускается локально в Windows с использованием Microsoft PowerPoint (COM) для рендеринга и контроля качества; НЕ зависит от LibreOffice/OpenOffice.
