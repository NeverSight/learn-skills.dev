Utilice esta habilidad siempre que se trate de un archivo .pptx, como entrada, salida o ambos. Cubre la creación, edición, presentaciones basadas en plantillas, extracción de contenido, orientación de diseño, reglas antimonotonía y control de calidad. Se activa cada vez que el usuario menciona "plataforma", "diapositivas", "presentación", "pptx", "PowerPoint" o solicita leer/compilar/editar/inspeccionar un archivo .pptx. Se ejecuta localmente en Windows usando Microsoft PowerPoint (COM) para renderizado y control de calidad; NO depende de LibreOffice/OpenOffice.
