Crea o riscrivi i file AGENTS.md nel rigoroso linguaggio politico inglese. Utilizza questa abilità ogni volta che l'utente richiede di creare AGENTS.md, agenti.md, istruzioni dell'agente, file di policy del repository, guardrail dei contributori o regole di esecuzione per gli agenti di codifica. Questa abilità impone un linguaggio di comando assoluto, rimuove le parole ritagliate e conferma che il file AGENTS.md finale utilizza DEVE, MAI, RICHIESTO e VIETATO invece di un linguaggio più morbido.
