Rust async 수명 주기를 위한 구조적 동시성 패턴: RAII(객체가 리소스이자 핸들러), TaskScope/AsyncClose, 그리고 상위에서 취소를 선택하는 spawn+select 패턴. 다음 경우에 사용하세요 (1) 모든 tokio::spawn / select! 를 “spawn는 밖에서, select 취소는 상위에서, 함수는 순수하게 유지” 원칙에 맞게 감사하거나 수정할 때; (2) 핸들/리소스 분리, 함수 내부에 파묻힌 select, 중첩된 spawn+select 체인, 또는 abort() 를 일상적인 취소로 사용하는 안티패턴을 리팩토링할 때; (3) 백그라운드 작업, 수신 루프, 우아한 종료, 리소스 배출을 설계할 때. 트리거: 동시성 감사, spawn/select 검토, 작업 누수, CancellationToken, TaskScope, 구조적 동시성, 우아한 종료.
