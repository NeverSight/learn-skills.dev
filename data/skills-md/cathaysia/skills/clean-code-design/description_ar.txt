توجيه تصميم الكود نحو بنية بسيطة وقابلة للصيانة قبل التنفيذ أو أثناءه. يُستخدم عندما تقوم Codex بتصميم وحدة نمطية جديدة، أو إضافة واجهات برمجة التطبيقات، أو إعادة هيكلة التعليمات البرمجية المعقدة، أو تقسيم الملفات، أو تقليل الحالة العامة، أو تحديد ما إذا كان سيتم تقديم تجريدات، أو تقييم ما إذا كان تعقيد الميزة مبررًا.
