Concevoir, mettre en œuvre ou réviser des interfaces frontales de production avec une direction visuelle claire, une grande convivialité, une interaction accessible, un comportement réactif et une utilisation disciplinée du système de conception existant. À utiliser chaque fois que l'utilisateur demande à créer, reconcevoir, peaufiner ou réviser une page Web, un composant, un tableau de bord, un formulaire ou une application ; traduire une maquette en code ; améliorer la hiérarchie visuelle ou le style ; ou rendre une interface moins générique, même lorsque la demande est présentée comme un refactoring de composant. Ne pas utiliser pour un travail uniquement backend ou pour des modifications purement mécaniques du frontend sans décision d'interface utilisateur.
