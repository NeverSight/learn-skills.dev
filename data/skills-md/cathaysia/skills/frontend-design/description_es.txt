Diseñe, implemente o revise interfaces de interfaz de producción con una dirección visual clara, gran usabilidad, interacción accesible, comportamiento receptivo y uso disciplinado del sistema de diseño existente. Úselo siempre que el usuario solicite crear, rediseñar, pulir o revisar una página web, componente, panel, formulario o aplicación; traducir una maqueta a código; mejorar la jerarquía visual o el estilo; o hacer que una interfaz parezca menos genérica, incluso cuando la solicitud se formula como una refactorización de componentes. No lo utilice para trabajos de backend únicamente o cambios de frontend puramente mecánicos sin una decisión de interfaz de usuario.
