Entwerfen, implementieren oder überprüfen Sie Produktions-Frontend-Schnittstellen mit einer klaren visuellen Ausrichtung, starker Benutzerfreundlichkeit, zugänglicher Interaktion, reaktionsfähigem Verhalten und disziplinierter Nutzung des vorhandenen Designsystems. Verwenden Sie es immer dann, wenn der Benutzer eine Webseite, Komponente, ein Dashboard, ein Formular oder eine Anwendung erstellen, neu gestalten, verfeinern oder überprüfen möchte. ein Modell in Code übersetzen; Verbesserung der visuellen Hierarchie oder des Stils; Oder sorgen Sie dafür, dass sich ein Frontend weniger allgemein anfühlt – selbst wenn die Anfrage als Komponenten-Refactoring formuliert ist. Nicht für reine Backend-Arbeiten oder rein mechanische Frontend-Änderungen ohne UI-Entscheidung verwenden.
