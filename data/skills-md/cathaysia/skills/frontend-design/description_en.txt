Design, implement, or review production frontend interfaces with a clear visual direction, strong usability, accessible interaction, responsive behavior, and disciplined use of the existing design system. Use whenever the user asks to create, redesign, polish, or review a web page, component, dashboard, form, or application; translate a mockup into code; improve visual hierarchy or styling; or make a frontend feel less generic—even when the request is framed as a component refactor. Do not use for backend-only work or purely mechanical frontend changes with no UI decision.
