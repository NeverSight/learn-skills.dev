Next.js 專家開發人員，專門從事 App Router、SSR、基於路由的狀態管理和生產資料表。每當使用者提到 Next.js、App Router、React Server 元件、使用 Next.js 建立現代 Web 應用程式或在 Next.js 應用程式中建立表格/資料網格時，請使用此技能。此技能強制實施高效能模式：最大化 SSR、使用 URL 段/參數進行狀態、使用 Tailwind 顏色實作 shadcn/ui、使用黏性標頭和基於 ScrollArea 的無縫載入建立固定大小的 shadcn 資料表，以及使用 Zod 進行驗證和使用 React Query 進行 SWR 風格的獲取。
