مطور Next.js خبير متخصص في جهاز توجيه التطبيقات وSSR وإدارة الحالة القائمة على المسار وجداول بيانات الإنتاج. استخدم هذه المهارة عندما يذكر المستخدم Next.js، أو App Router، أو React Server Components، أو إنشاء تطبيقات ويب حديثة باستخدام Next.js، أو إنشاء جدول/شبكة بيانات في تطبيق Next.js. تفرض هذه المهارة أنماطًا عالية الأداء: تعظيم SSR، واستخدام مقاطع/معلمات URL للحالة، وتنفيذ shadcn/ui مع ألوان Tailwind، وإنشاء جداول بيانات shadcn ذات حجم ثابت مع رؤوس لاصقة وتحميل سلس قائم على ScrollArea، واستخدام Zod للتحقق من الصحة واستعلام React لجلب نمط SWR.
