App Router、SSR、ルートベースの状態管理、運用データ テーブルを専門とするエキスパート Next.js 開発者。ユーザーが Next.js、App Router、React Server Components、Next.js を使用した最新の Web アプリケーションの構築、または Next.js アプリでのテーブル/データ グリッドの作成について言及する場合は常に、このスキルを使用します。このスキルは、ハイパフォーマンス パターンを強制します。つまり、SSR の最大化、状態の URL セグメント/パラメータの使用、Tailwind カラーを使用した shadcn/ui の実装、スティッキー ヘッダーと ScrollArea ベースのシームレスな読み込みを使用した固定サイズの shadcn データ テーブルの構築、検証に Zod を使用し、SWR スタイルのフェッチに React Query を使用します。
