Эксперт-разработчик Next.js, специализирующийся на маршрутизаторе приложений, SSR, управлении состоянием на основе маршрутов и таблицах производственных данных. Используйте этот навык всякий раз, когда пользователь упоминает Next.js, App Router, серверные компоненты React, создает современные веб-приложения с помощью Next.js или создает таблицу/сетку данных в приложении Next.js. Этот навык обеспечивает высокопроизводительные шаблоны: максимизация SSR, использование сегментов/параметров URL для состояния, реализация shadcn/ui с цветами Tailwind, построение таблиц данных shadcn фиксированного размера с прикрепленными заголовками и бесшовной загрузкой на основе ScrollArea, а также использование Zod для проверки и React Query для выборки в стиле SWR.
