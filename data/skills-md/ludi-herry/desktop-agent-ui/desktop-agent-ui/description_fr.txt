Concevoir, implémenter et examiner la coquille de fenêtre, le flux d’état de session, la boîte de saisie, le retour d’exécution d’outil et la disposition de l’espace de travail des applications modernes d’Agent/IA de bureau ; extraire les pratiques d’ingénierie de bureau approfondies et leurs écueils, en se concentrant sur la gestion du rognage d’ombre, les performances de défilement, la protection des méthodes d’entrée, les états multi‑fenêtres et la sémantique native du bureau. Les pages marketing ordinaires, les versions purement mobiles et les vidéos autonomes n’utilisent pas ce point d’accès ; seuls les changements d’animation suivent le schéma d’animation du projet.
