صمم ونفّذ وراجع هيكل النافذة، تدفق حالة الجلسة، صندوق الإدخال، ملاحظات تنفيذ الأدوات، وتخطيط مساحة العمل لتطبيقات الوكيل/الذكاء الاصطناعي المكتبية الحديثة؛ استخلص ممارسات الهندسة المكتبية المتقدمة وتجارب تجنب الأخطاء، مع التركيز على قص الظلال، أداء التمرير، حماية طريقة الإدخال، حالات النوافذ المتعددة، ودلالات سطح المكتب الأصلية. الصفحات التسويقية العادية، النسخة النقية للهواتف المحمولة، والفيديوهات المستقلة لا تستخدم نقطة الدخول هذه؛ فقط تغييرات الرسوم المتحركة تتبع مخطط الرسوم المتحركة للمشروع.
