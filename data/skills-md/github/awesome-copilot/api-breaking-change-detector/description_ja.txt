C# Web API コントローラ／DTO と、対応する TypeScript／JavaScript のコンシューマ（React、Angular、Vue、Svelte、Node.js、あるいは手書き・自動生成された HTTP クライアント（Fetch、Axios、NSwag など））を相互参照し、双方向の契約ドリフトを検出します。具体的には、バックエンドの変更でクライアントアプリケーションが壊れる（JSON キーのリネーム・削除、新しい必須パラメータ、ステータスコードの変更）ケースや、フロントエンド側がバックエンドがもはや読み取らないフィールドを送信しているケースです。エクスポートされた OpenAPI 仕様ファイルではなく、ソースコードに直接作用します。ユーザーが API の破壊的変更をチェックしたいとき、フロントエンドとバックエンドの契約同期を検証したいとき、またはマージ前に DTO／コントローラの変更をその TypeScript／JS コンシューマに対して監査したいときに使用します。仕様から新しい API コードを生成する目的（openapi-to-application-code 参照）や、新しいエンドポイントをスキャフォールドする目的（aspnet-minimal-api-openapi 参照）には使用しません。
