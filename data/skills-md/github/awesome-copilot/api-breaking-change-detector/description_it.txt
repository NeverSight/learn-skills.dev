Confronta i controller/DTO di C# Web API con i loro consumatori TypeScript/JavaScript (React, Angular, Vue, Svelte, Node.js o client HTTP scritti a mano/auto‑generati come Fetch, Axios, NSwag) per intercettare le deviazioni di contratto in entrambe le direzioni: modifiche al backend che rompono le applicazioni client (chiavi JSON rinominate/rimosse, nuovi parametri obbligatori, cambi di codice di stato) e codice frontend che invia campi che il backend non legge più. Funziona direttamente sul codice sorgente, non sui file di specifica OpenAPI esportati. Da usare quando l'utente chiede di verificare cambiamenti API che potrebbero rompere, verificare la sincronizzazione del contratto frontend/backend o revisionare una modifica a DTO/controller rispetto ai suoi consumatori TypeScript/JS prima del merge. Non serve a generare nuovo codice API da una specifica (vedi openapi-to-application-code) né a scaffolding di nuovi endpoint (vedi aspnet-minimal-api-openapi).
