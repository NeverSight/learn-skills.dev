يقوم بربط متقاطع بين وحدات التحكم/DTOs في C# Web API ومستهلكيها في TypeScript/JavaScript (React، Angular، Vue، Svelte، Node.js، أو عملاء HTTP المكتوبين يدوياً أو المُولّدين تلقائياً مثل Fetch، Axios، NSwag) لاكتشاف انزلاق العقد في كلا الاتجاهين: تغييرات في الخلفية تُكسر تطبيقات العميل (إعادة تسمية/إزالة مفاتيح JSON، معلمات جديدة مطلوبة، تغيرات في رموز الحالة) وكذلك شفرة الواجهة الأمامية التي ترسل حقولاً لم يعد الخادم يقرأها. يعمل مباشرةً على شفرة المصدر، وليس على ملفات مواصفات OpenAPI المُصدَّرة. يُستخدم عندما يطلب المستخدم التحقق من تغييرات API مكسرة، أو التحقق من توافق عقد الواجهة الأمامية/الخلفية، أو تدقيق تغيير DTO/المتحكم مقابل مستهلكي TypeScript/JS قبل الدمج. ليس لإنشاء كود API جديد من مواصفة (انظر openapi-to-application-code) أو لإنشاء نقاط نهاية جديدة (انظر aspnet-minimal-api-openapi).
