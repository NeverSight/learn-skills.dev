交叉引用 C# Web API 控制器/DTO 与其 TypeScript/JavaScript 消费者（React、Angular、Vue、Svelte、Node.js，或手写/自动生成的 HTTP 客户端如 Fetch、Axios、NSwag），以捕获双向的契约漂移：后端更改导致客户端应用崩溃（JSON 键被重命名/删除、新的必需参数、状态码变动），以及前端代码发送后端已不再读取的字段。直接针对源代码工作，而不是导出的 OpenAPI 规范文件。当用户要求检查破坏性 API 更改、验证前后端契约同步，或在合并前审计 DTO/控制器的更改相对于其 TypeScript/JS 消费者时使用。不用于从规范生成新的 API 代码（见 openapi-to-application-code）或脚手架新端点（见 aspnet-minimal-api-openapi）。
