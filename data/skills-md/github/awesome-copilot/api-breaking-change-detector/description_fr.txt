Croise les contrôleurs/DTOs d'API Web C# avec leurs consommateurs TypeScript/JavaScript (React, Angular, Vue, Svelte, Node.js, ou clients HTTP écrits à la main/générés automatiquement comme Fetch, Axios, NSwag) afin de détecter les dérives de contrat dans les deux sens : modifications du backend qui cassent les applications clientes (clés JSON renommées/supprimées, nouveaux paramètres obligatoires, changements de codes d’état) et code frontend qui envoie des champs que le backend ne lit plus. Fonctionne directement sur le code source, pas sur les fichiers de spécification OpenAPI exportés. À utiliser lorsque l’utilisateur demande de vérifier les changements d’API incompatibles, de confirmer la synchronisation du contrat frontend/backend, ou d’auditer une modification de DTO/contrôleur par rapport à ses consommateurs TypeScript/JS avant de fusionner. Ne sert pas à générer du nouveau code d’API à partir d’une spécification (voir openapi-to-application-code) ou à créer de nouveaux points de terminaison (voir aspnet-minimal-api-openapi).
