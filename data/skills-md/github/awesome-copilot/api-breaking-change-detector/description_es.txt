Cruza referencias de los controladores/DTOs de C# Web API con sus consumidores TypeScript/JavaScript (React, Angular, Vue, Svelte, Node.js o clientes HTTP escritos a mano/auto‑generados como Fetch, Axios, NSwag) para detectar desviaciones del contrato en ambas direcciones: cambios en el backend que rompen aplicaciones cliente (claves JSON renombradas o eliminadas, nuevos parámetros obligatorios, cambios en códigos de estado) y código frontend que envía campos que el backend ya no lee. Funciona directamente sobre el código fuente, no sobre archivos de especificación OpenAPI exportados. Úselo cuando el usuario solicite comprobar cambios de API que rompan el contrato, verificar la sincronización del contrato frontend/backend, o auditar un cambio en un DTO/controlador contra sus consumidores TypeScript/JS antes de fusionar. No es para generar nuevo código API a partir de una especificación (ver openapi-to-application-code) ni para generar automáticamente nuevos endpoints (ver aspnet-minimal-api-openapi).
