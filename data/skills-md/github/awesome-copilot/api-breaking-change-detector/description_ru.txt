Перекрестно проверяет контроллеры/DTO C# Web API против их потребителей TypeScript/JavaScript (React, Angular, Vue, Svelte, Node.js или вручную написанных/автогенерированных HTTP‑клиентов, таких как Fetch, Axios, NSwag), чтобы обнаружить отклонения контракта в обоих направлениях: изменения на стороне бекенда, ломающие клиентские приложения (переименованные/удалённые JSON‑ключи, новые обязательные параметры, сдвиги кодов статуса), и фронтенд‑код, отправляющий поля, которые бекенд больше не читает. Работает напрямую с исходным кодом, а не с экспортированными файлами спецификации OpenAPI. Используется, когда пользователь просит проверить наличие разрушающих изменений API, убедиться в синхронизации контракта фронтенда/бекенда или провести аудит изменения DTO/контроллера относительно его потребителей TypeScript/JS перед слиянием. Не предназначено для генерации нового кода API из спецификации (см. openapi-to-application-code) и не для scaffold‑инга новых эндпоинтов (см. aspnet-minimal-api-openapi).
