將 C# Web API 控制器/DTO 與其 TypeScript/JavaScript 消費者（React、Angular、Vue、Svelte、Node.js，或手寫/自動產生的 HTTP 客戶端如 Fetch、Axios、NSwag）交叉比對，以捕捉雙向的合約漂移：後端變更導致客戶端程式錯誤（JSON 鍵名重新命名／移除、新增必填參數、狀態碼變更）以及前端送出後端已不再讀取的欄位。直接對原始程式碼進行比對，而非匯出的 OpenAPI 規格檔。適用於使用者要求檢查破壞性 API 變更、驗證前後端合約同步，或在合併前審核 DTO／控制器變更與其 TypeScript/JS 消費者的相容性。並非用於從規格產生新 API 程式碼（請參閱 openapi-to-application-code）或腳手架新端點（請參閱 aspnet-minimal-api-openapi）。
