C# Web API 컨트롤러/DTO를 TypeScript/JavaScript 소비자(React, Angular, Vue, Svelte, Node.js 또는 Fetch, Axios, NSwag와 같은 수동/자동 생성 HTTP 클라이언트)와 교차 검증하여 양방향 계약 변동을 포착합니다: 백엔드 변경으로 인해 클라이언트 애플리케이션이 깨지는 경우(이름이 바뀌거나 삭제된 JSON 키, 새로운 필수 매개변수, 상태 코드 변동)와 프런트엔드 코드가 백엔드가 더 이상 읽지 않는 필드를 보내는 경우. 내보낸 OpenAPI 명세 파일이 아니라 소스 코드를 직접 대상으로 동작합니다. 사용자는 API 파괴적 변경을 확인하거나 프런트엔드/백엔드 계약 동기화를 검증하거나 병합 전 DTO/컨트롤러 변경을 해당 TypeScript/JS 소비자와 감사할 때 사용합니다. 명세에서 새로운 API 코드를 생성하는 용도는 아니며(openapi-to-application-code 참조) 새로운 엔드포인트를 스캐폴딩하는 용도도 아닙니다(aspnet-minimal-api-openapi 참조).
