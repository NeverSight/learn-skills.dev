قم بإجراء تدقيق للانحراف في المستندات بنظام القراءة فقط لميزة أو طلب سحب أو فرع أو إصدار أو API أو تغيير تكوين أو سير عمل أو سطر أوامر أو حزمة أو منطقة في المستودع. استخدمه عندما يسأل المستخدم ما إذا كانت المستندات قديمة أو مفقودة أو غير متناسقة مع الشيفرة أو تحتاج إلى تحديثات بعد تغييرات الشيفرة. يتفقد ملفات README، أدلة الإعداد، وثائق API، وثائق البيئة، سجلات التغييرات، الأمثلة، التعليقات، الوثائق المولدة، وتعليمات المستخدم. هذا ليس مراجعة شيفرة عامة؛ بل يقارن ما تدعيه المستندات مع ما تقوم به الشيفرة. يرجى دائمًا الرد بلغة المستخدم.
