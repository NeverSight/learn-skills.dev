Lancez un audit de dérive de documentation en lecture seule pour une fonctionnalité, une PR, une branche, une version, une API, un changement de configuration, un workflow, un CLI, un paquet ou une zone de référentiel. Utilisez-le lorsque l’utilisateur se demande si la documentation est obsolète, manquante, incohérente avec le code, ou si elle nécessite des mises à jour après des changements de code. Vérifie les fichiers README, les guides d’installation, la documentation API, la documentation d’environnement, les changelogs, les exemples, les commentaires, la documentation générée et les instructions destinées aux utilisateurs. Ce n’est pas une revue de code générale ; il compare ce que la documentation affirme à ce que le code fait.

Veuillez toujours répondre dans la langue de l’utilisateur.
