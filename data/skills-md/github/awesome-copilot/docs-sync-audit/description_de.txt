Führen Sie eine schreibgeschützte Dokumentations‑Drift‑Prüfung für ein Feature, einen Pull‑Request, Branch, Release, API, Konfigurationsänderung, Workflow, CLI, Paket oder einen Repository‑Bereich durch. Verwenden Sie sie, wenn der Benutzer fragt, ob Dokumente veraltet, fehlend, inkonsistent zum Code sind oder nach Code‑Änderungen aktualisiert werden müssen. Überprüft README‑Dateien, Installationsanleitungen, API‑Dokumentation, Umgebungs‑Docs, Changelogs, Beispiele, Kommentare, generierte Dokumente und benutzerseitige Anweisungen. Dies ist kein allgemeiner Code‑Review; er vergleicht, was die Dokumentation behauptet, mit dem, was der Code tatsächlich tut.

Bitte immer in der Sprache des Benutzers antworten.
