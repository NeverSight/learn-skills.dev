Выполните проверку отклонения документации в режиме только для чтения для функции, PR, ветки, релиза, API, изменения конфигурации, рабочего процесса, CLI, пакета или области репозитория. Используйте, когда пользователь спрашивает, устарела ли документация, отсутствует, несоответствует коду или нуждается в обновлении после изменений кода. Проверяются файлы README, руководства по настройке, API‑документация, документация окружения, changelog’и, примеры, комментарии, сгенерированная документация и инструкции, направленные пользователю. Это не общий обзор кода; он сравнивает заявления документации с тем, что делает код.
