Esegui un audit in sola lettura del drift della documentazione per una funzionalità, PR, branch, rilascio, API, cambiamento di configurazione, workflow, CLI, pacchetto o area del repository. Usalo quando l'utente chiede se la documentazione è obsoleta, mancante, incoerente con il codice o necessita di aggiornamenti dopo modifiche al codice. Controlla i file README, le guide di installazione, la documentazione API, la documentazione dell'ambiente, i changelog, gli esempi, i commenti, la documentazione generata e le istruzioni rivolte agli utenti. Non si tratta di una revisione generale del codice; confronta ciò che la documentazione afferma con ciò che il codice effettua.

Per favore, rispondi sempre nella lingua dell'utente.
