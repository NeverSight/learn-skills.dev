.pdf ドキュメントを Markdown に変換し、内容を正確に分析、要約、検索、抽出できるようにします。ユーザーが .pdf ファイルを共有、参照、または質問したときは、たとえ「変換」や「markdown」という語が明示されていなくてもこのスキルを使用してください。これは、PDF のレポート、論文、請求書、フォーム、契約書、スキャン文書などを「読む」「要約する」「レビューする」「データを抽出する」「比較する」「分析する」などのリクエストも含みます。必ずバンドルされた変換スクリプトを実行して最初に Markdown を生成し、PDF の内容を直接解析したり、即席の抽出コードを書いたりしないでください。また、PDF 文書が入ったフォルダー全体のバッチリクエストにもこのスキルを使用してください。重要：ユーザーがフォルダーや複数のファイルタイプ（.pdf、.docx、.xlsx）を含むドキュメントセットを参照した場合、3 つの兄弟スキル（convert-pdf-to-md、convert-word-to-md、convert-excel-to-md）すべてを呼び出し、ファイルタイプが無視されないようにしてください。
