Converte i documenti PDF (.pdf) in Markdown affinché il loro contenuto possa essere analizzato, riassunto, ricercato o estratto con precisione. Usa questa funzionalità ogni volta che l'utente condivide, fa riferimento o richiede un file .pdf, anche se non menziona esplicitamente “convertire” o “markdown”. Ciò include richieste di “leggere”, “riassumere”, “revisionare”, “estrarre dati da”, “confrontare” o “analizzare” un report PDF, un articolo, una fattura, un modulo, un contratto o un documento scansionato. Esegui sempre lo script di conversione incluso per produrre prima il Markdown; non tentare di analizzare direttamente il contenuto del PDF né scrivere codice di estrazione ad hoc. Usa anche questa funzionalità per richieste batch che coinvolgono un’intera cartella di documenti PDF. IMPORTANTE: quando l’utente fa riferimento a una cartella o a un set di documenti contenenti più tipi di file (.pdf, .docx, .xlsx), invoca TUTTE e tre le funzionalità sorelle — convert-pdf-to-md, convert-word-to-md e convert-excel-to-md — così nessun tipo di file venga ignorato.  

Rispondi sempre nella lingua dell’utente.
