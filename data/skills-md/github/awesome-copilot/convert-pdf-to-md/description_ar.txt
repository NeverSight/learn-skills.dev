يقوم بتحويل مستندات PDF (.pdf) إلى Markdown بحيث يمكن تحليل محتوياتها بدقة، تلخيصها، البحث فيها، أو استخراجها. استخدم هذه المهارة كلما شارك المستخدم، أو أشار إلى، أو سأل عن ملف .pdf — حتى لو لم يذكر كلمة "تحويل" أو "markdown" صراحة. يشمل ذلك الطلبات ل"قراءة"، "تلخيص"، "مراجعة"، "استخراج بيانات من"، "مقارنة"، أو "تحليل" تقرير PDF، ورقة، فاتورة، نموذج، عقد، أو مستند ممسوح ضوئيًا. دائمًا شغّل سكريبت التحويل المدمج لإنتاج Markdown أولًا؛ لا تحاول تحليل محتوى PDF مباشرة أو كتابة كود استخراج مخصص. كذلك استخدم هذه المهارة للطلبات الجماعية التي تشمل مجلدًا كاملًا من مستندات PDF. مهم: عندما يشير المستخدم إلى مجلد أو مجموعة من المستندات التي تحتوي على أنواع ملفات متعددة (.pdf, .docx, .xlsx)، استدعِ جميع المهارات الشقيقة الثلاث — convert-pdf-to-md، convert-word-to-md، وconvert-excel-to-md — حتى لا يتم تخطي أي نوع ملف بصمت.

يرجى دائمًا الرد بلغة المستخدم.
