Convierte documentos PDF (.pdf) a Markdown para que su contenido pueda ser analizado, resumido, buscado o extraído con precisión. Usa esta habilidad siempre que el usuario comparta, haga referencia o pregunte sobre un archivo .pdf, incluso si no dice «convertir» o «markdown» explícitamente. Esto incluye solicitudes de «leer», «resumir», «revisar», «extraer datos de», «comparar» o «analizar» un informe, artículo, factura, formulario, contrato o documento escaneado en PDF. Siempre ejecuta el script de conversión incluido para producir Markdown primero; no intentes analizar el contenido del PDF directamente ni escribir código de extracción ad hoc. También utiliza esta habilidad para solicitudes por lotes que involucren una carpeta completa de documentos PDF. IMPORTANTE: Cuando el usuario haga referencia a una carpeta o conjunto de documentos que contenga varios tipos de archivo (.pdf, .docx, .xlsx), invoca LAS TRES habilidades hermanas —convert-pdf-to-md, convert-word-to-md y convert-excel-to-md— para que no se omita silenciosamente ningún tipo de archivo.

Por favor, responde siempre en el idioma del usuario.
