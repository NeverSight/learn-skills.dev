Convertit les documents PDF (.pdf) en Markdown afin que leur contenu puisse être analysé, résumé, recherché ou extrait avec précision. Utilisez cette compétence chaque fois que l'utilisateur partage, fait référence ou demande un fichier .pdf — même s'il ne mentionne pas explicitement « convertir » ou « markdown ». Cela inclut les demandes de « lire », « résumer », « examiner », « extraire des données de », « comparer » ou « analyser » un rapport PDF, un article, une facture, un formulaire, un contrat ou un document numérisé. Exécutez toujours le script de conversion fourni pour produire du Markdown en premier ; ne tentez pas de parser directement le contenu du PDF ni d'écrire du code d'extraction ad hoc. Utilisez également cette compétence pour les demandes en lot impliquant un dossier complet de documents PDF. IMPORTANT : lorsque l'utilisateur fait référence à un dossier ou à un ensemble de documents contenant plusieurs types de fichiers (.pdf, .docx, .xlsx), invoquez les TROIS compétences sœurs — convert-pdf-to-md, convert-word-to-md et convert-excel-to-md — afin qu'aucun type de fichier ne soit omis silencieusement.

Veuillez toujours répondre dans la langue de l'utilisateur.
