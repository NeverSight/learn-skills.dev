SwiftUI または AppKit を使用して、ネイティブな macOS 27 Golden Gate インターフェースを設計、実装、レビュー、またはリファクタリングします。Mac アプリが Apple の現在の macOS 27 UI キットと控えめな Liquid Glass 言語に合わせる必要がある場合に使用します：統合されたウィンドウ、フルハイトのサイドバー、ネイティブツールバー、フラットなリスト、テーブル、フォーム、明確なペイン境界、アクセシブルな素材、そして不要なネストされたカード、フレームパネル、またはガラスモルフィズムの除去。また、Figma の macOS 27 デザインからコードへの変換作業や、箱入り感のあるインターフェースの監査にも使用します。常にユーザーの言語で回答してください。
