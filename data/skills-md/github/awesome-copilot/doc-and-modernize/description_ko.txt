로컬에 클론된 코드베이스를 위한 두 개의 관련 워크플로우가 하나의 스킬에 있습니다. Documentation 모드는 주로 디스크에 있는 파일들을 읽어(로컬 우선) 단일하고 포괄적이며 검증 가능한 아키텍처 문서를 생성합니다 — 사용자가 코드베이스를 이해하거나, 매핑하거나, 문서화하거나, 조사하거나, 온보딩하고 싶을 때 사용합니다(예: “이 저장소 조사하기”, “아키텍처 작성하기”, “아키텍처 깊이 파헤치기”, “이 코드베이스가 어떻게 동작하는지 문서화”, “시스템 설계 매핑”, “온보딩 문서 만들기”). Modernization 모드는 레거시 시스템을 현대화, 마이그레이션, 업그레이드 혹은 재작성하기 위한 단계별 계획을 생성합니다(예: “이것을 현대화”, “마이그레이션 계획”, “이걸 어떻게 재작성할까”, “이 레거시 스택에서 어떻게 벗어날까”). 아키텍처 문서가 아직 존재하지 않으면 먼저 Documentation 모드를 실행한 뒤 바로 계획 단계로 진행합니다. 레거시 스택이 중단될 수 있다고 가정하고, 시간 제한이 있는 타당성 스파이크를 수행하며, 사전에 완전한 레거시 CI 게이트를 요구하는 대신 안전 사다리에서 달성 가능한 가장 높은 단계( rung)를 선택합니다. 항상 사용자의 언어로 답변해 주세요.
