Zwei verwandte Workflows für ein lokal geklontes Code‑Repository, in einer einzigen Fähigkeit. Der Dokumentationsmodus erstellt ein einziges, umfassendes, verifizierbares Architekturdokument, indem er hauptsächlich die Dateien auf der Festplatte liest (lokal zuerst) — benutze ihn, wann immer der Nutzer das Repository verstehen, abbilden, dokumentieren, erforschen oder sich einarbeiten möchte („research this repo“, „write up the architecture“, „do an architecture deep dive“, „document how this codebase works“, „map the system design“, „create an onboarding doc“). Der Modernisierungsmodus erzeugt einen schrittweisen Plan, um ein Legacy‑System zu modernisieren, zu migrieren, zu upgraden oder neu zu schreiben („modernize this“, „plan the migration“, „how would we rewrite this“, „how do we get off this legacy stack“); existiert noch kein Architekturdokument, wird zunächst der Dokumentationsmodus ausgeführt, danach wird direkt mit dem Plan fortgefahren. Er geht davon aus, dass der Legacy‑Stack möglicherweise nicht mehr aktiv ist, führt einen zeitlich begrenzten Machbarkeits‑Spike durch und wählt die höchstmögliche erreichbare Stufe einer Sicherheitsskala, anstatt zu Beginn ein vollständig grünes Legacy‑CI‑Gate zu verlangen.
