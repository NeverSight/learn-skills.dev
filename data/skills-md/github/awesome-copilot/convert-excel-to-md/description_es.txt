Convierte libros de Excel (.xlsx) a Markdown para que su contenido pueda ser analizado, resumido, buscado o extraído con precisión. Usa esta habilidad siempre que el usuario comparta, haga referencia o pregunte sobre un archivo .xlsx, incluso si no dice "convertir" o "markdown" explícitamente. Esto incluye solicitudes de "leer", "resumir", "revisar", "extraer datos de", "comparar", "graficar" o "analizar" una hoja de cálculo, libro de trabajo, presupuesto, exportación de datos o rastreador. Siempre ejecuta el script de conversión incluido para producir Markdown primero; no intentes analizar el contenido .xlsx directamente ni escribir código de extracción ad hoc. También usa esta habilidad para solicitudes por lotes que involucren una carpeta completa de libros de Excel. IMPORTANTE: Cuando el usuario haga referencia a una carpeta o conjunto de documentos que contengan varios tipos de archivo (.pdf, .docx, .xlsx), invoca las TRES habilidades hermanas — convert-pdf-to-md, convert-word-to-md y convert-excel-to-md — para que ningún tipo de archivo quede excluido silenciosamente.

Por favor, responde siempre en el idioma del usuario.
