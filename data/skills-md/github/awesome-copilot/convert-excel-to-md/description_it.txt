Converte le cartelle di lavoro Excel (.xlsx) in Markdown in modo che i loro contenuti possano essere analizzati, sintetizzati, ricercati o estratti con precisione. Usa questa abilità ogni volta che l'utente condivide, fa riferimento o domanda qualcosa su un file .xlsx — anche se non dice esplicitamente “converti” o “markdown”. Questo include richieste di “leggere”, “sintetizzare”, “revisionare”, “estrarre dati da”, “confrontare”, “creare grafici” o “analizzare” un foglio di calcolo, una cartella di lavoro, un bilancio, un'esportazione di dati o un tracker. Esegui sempre lo script di conversione integrato per produrre prima il Markdown; non tentare di analizzare direttamente il contenuto .xlsx o scrivere codice di estrazione ad hoc. Usa anche questa abilità per richieste batch che coinvolgono un’intera cartella di cartelle di lavoro Excel. IMPORTANTE: quando l’utente fa riferimento a una cartella o a un insieme di documenti contenenti più tipi di file (.pdf, .docx, .xlsx), invoca TUTTE e tre le abilità correlate — convert-pdf-to-md, convert-word-to-md e convert-excel-to-md — in modo che nessun tipo di file venga saltato silenziosamente.
