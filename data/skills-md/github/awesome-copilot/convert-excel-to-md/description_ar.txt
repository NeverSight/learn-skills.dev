يقوم بتحويل دفاتر عمل Excel (.xlsx) إلى تنسيق Markdown بحيث يمكن تحليل محتوياتها بدقة، تلخيصها، البحث فيها، أو استخراجها. استخدم هذه المهارة كلما شارك المستخدم ملف .xlsx أو أشار إليه أو سأل عنه — حتى لو لم يذكر صراحةً كلمة "تحويل" أو "Markdown". يشمل ذلك الطلبات لقراءة، تلخيص، مراجعة، استخراج البيانات من، مقارنة، إنشاء مخطط، أو تحليل جدول بيانات، دفتر عمل، ميزانية، تصدير بيانات، أو متتبع. يجب دائمًا تشغيل برنامج التحويل المدمج لإنتاج Markdown أولاً؛ لا تحاول تحليل محتوى .xlsx مباشرةً أو كتابة كود استخراج مؤقت. استخدم هذه المهارة أيضًا للطلبات الجماعية التي تتضمن مجلدًا كاملًا من دفاتر عمل Excel. مهم: عندما يشير المستخدم إلى مجلد أو مجموعة من المستندات تحتوي على أنواع ملفات متعددة (.pdf, .docx, .xlsx)، استدعِ جميع المهارات الشقيقة الثلاث — convert-pdf-to-md، convert-word-to-md، وconvert-excel-to-md — حتى لا يتم تخطي أي نوع ملف بصمت.

يرجى دائمًا الرد بلغة المستخدم.
