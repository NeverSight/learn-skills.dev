Convertit les classeurs Excel (.xlsx) en Markdown afin que leur contenu puisse être analysé, résumé, recherché ou extrait avec précision. Utilisez cette compétence chaque fois que l'utilisateur partage, fait référence ou demande un fichier .xlsx — même s’il ne dit pas explicitement « convertir » ou « markdown ». Cela inclut les demandes de « lire », « résumer », « examiner », « extraire des données de », « comparer », « créer un graphique » ou « analyser » une feuille de calcul, un classeur, un budget, une exportation de données ou un suivi. Exécutez toujours le script de conversion intégré pour produire d’abord le Markdown ; n’essayez pas d’analyser directement le contenu .xlsx ou d’écrire du code d’extraction ad hoc. Utilisez également cette compétence pour les requêtes par lot impliquant un dossier complet de classeurs Excel. IMPORTANT : lorsque l'utilisateur fait référence à un dossier ou à un ensemble de documents contenant plusieurs types de fichiers (.pdf, .docx, .xlsx), invoquez les TROIS compétences sœurs — convert-pdf-to-md, convert-word-to-md et convert-excel-to-md — afin qu’aucun type de fichier ne soit ignoré silencieusement.

Veuillez toujours répondre dans la langue de l'utilisateur.
