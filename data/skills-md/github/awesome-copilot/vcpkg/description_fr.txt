Guide d'installation de vcpkg dans des projets C++, de gestion des versions des dépendances et de compilation croisée. Couvre l'initialisation du manifeste, l'intégration avec CMake et Visual Studio, la migration du mode classique au manifeste, le verrouillage de version, les bases de référence, les surcharges, les triplets et la compilation croisée. À utiliser lorsqu'un utilisateur travaille sur la configuration d'un projet vcpkg, l'installation, la gestion des versions ou les builds multiplateformes. Pour des tâches spécialisées, des références supplémentaires couvrent les registres personnalisés et les ports superposés (references/registries.md), l'intégration continue/déploiement continu et la mise en cache binaire (references/ci.md), ainsi que le dépannage et le cycle de vie des dépendances (references/troubleshooting.md).
