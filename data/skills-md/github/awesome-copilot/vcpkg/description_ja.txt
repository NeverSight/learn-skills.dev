C++ プロジェクトで vcpkg を設定し、依存関係のバージョン管理やクロスコンパイルを行うためのガイドです。マニフェストの初期化、CMake および Visual Studio との統合、classic から manifest への移行、バージョン固定、ベースライン、オーバーライド、トリプレット、クロスコンパイルをカバーしています。ユーザーが vcpkg のプロジェクト設定、インストール、バージョン管理、またはクロスプラットフォームビルドを行う際に使用してください。専門的なタスクについては、カスタムレジストリとオーバーレイポート（references/registries.md）、CI/CD とバイナリキャッシュ（references/ci.md）、トラブルシューティングと依存関係のライフサイクル（references/troubleshooting.md）に関する追加リファレンスをご参照ください。
