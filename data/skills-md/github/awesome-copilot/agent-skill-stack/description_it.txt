Trova, valuta e assembla il più piccolo insieme compatibile di AI Agent Skills per un obiettivo di linguaggio naturale end‑to‑end. Utilizza quando un utente vuole Skills per un flusso di lavoro a più fasi, chiede quali Skills si adattano a un progetto, ha bisogno di un audit delle Skills installate o di un controllo dei conflitti, ha una scarsa memoria delle Skills, desidera assistenti indiretti come umanizzatori o verifiche di conformità, o vuole uno Stack di Skills specifico per il progetto con installazione controllata. Cerca Skills locali, registri, GitHub e OpenCLI; confronta adozione, idoneità verificata, sicurezza e sovrapposizione. Non usarlo per trovare una Skill nota o comune; utilizza il flusso di lavoro generico di ricerca Skills.

Rispondi sempre nella lingua dell'utente.
