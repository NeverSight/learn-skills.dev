Finde, bewerte und stelle das kleinste kompatible Set von KI‑Agent‑Skills für ein End‑to‑End‑Ziel in natürlicher Sprache zusammen. Verwende es, wenn ein Nutzer Skills für einen mehrstufigen Workflow benötigt, fragt, welche Skills zu einem Projekt passen, ein Audit oder eine Konfliktprüfung der installierten Skills wünscht, eine geringe Skill‑Abrufrate hat, indirekte Helfer wie Humanisierer oder Compliance‑Checks möchte oder einen projektspezifischen Skill‑Stack mit kontrollierter Installation benötigt. Durchsuche lokale Skills, Registries, GitHub und OpenCLI; vergleiche Adoption, verifizierte Passform, Sicherheit und Überschneidungen. Verwende es nicht, um einen bekannten oder gängigen Skill zu finden; nutze stattdessen den generischen Find‑Skills‑Workflow.
