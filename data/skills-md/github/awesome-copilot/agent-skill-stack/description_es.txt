Encuentre, evalúe y ensamble el conjunto más pequeño y compatible de habilidades de agente de IA para un objetivo de lenguaje natural de extremo a extremo. Úselo cuando un usuario quiere habilidades para un flujo de trabajo de varios pasos, pregunta qué habilidades encajan en un proyecto, necesita una auditoría de habilidades instaladas o una verificación de conflictos, tiene baja recordación de habilidades, desea ayudantes indirectos como humanizadores o verificaciones de cumplimiento, o quiere una pila de habilidades específica del proyecto con instalación controlada. Busque habilidades locales, registros, GitHub y OpenCLI; compare adopción, ajuste verificado, seguridad y solapamiento. No lo use para localizar una habilidad conocida o común; emplee el flujo de trabajo genérico de búsqueda de habilidades.

Por favor, responda siempre en el idioma del usuario.
