Parcourez les commentaires de révision de PR un par un, en décidant pour chacun s’il faut agir sur le retour ou répondre avec un raisonnement, puis élaborez un plan de résolution approuvable avant de modifier quoi que ce soit. Utilisez cette approche lorsque l’utilisateur veut traiter, répondre ou trier les commentaires de révision de PR.

Veuillez toujours répondre dans la langue de l’utilisateur.
