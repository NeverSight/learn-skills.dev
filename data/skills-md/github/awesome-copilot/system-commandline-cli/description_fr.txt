Utilisez cette compétence lors de l'ajout, de la modification ou de la révision des commandes CLI dans un projet .NET construit avec System.CommandLine. Les déclencheurs incluent : créer une nouvelle commande CLI, ajouter des options ou des arguments, raccorder les gestionnaires de commande, enregistrer des sous‑commandes, construire des groupes de commandes, ou toute décision d’architecture concernant la structure des commandes CLI. Utilisez‑la également lorsque l’utilisateur mentionne « System.CommandLine », « CommandBase », « SetAction », « ParseResult », « RootCommand », « subcommand », ou demande d’ajouter un verbe à la CLI. NE L’UTILISEZ PAS pour le code C# général, les API Web, le travail d’interface utilisateur ou les projets qui ne sont pas centrés sur la CLI.

Veuillez toujours répondre dans la langue de l’utilisateur.
