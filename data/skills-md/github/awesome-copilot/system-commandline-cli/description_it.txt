Usa questa competenza quando aggiungi, modifichi o rivedi i comandi CLI in un progetto .NET costruito con System.CommandLine. I trigger includono: creare un nuovo comando CLI, aggiungere opzioni o argomenti, collegare i gestori dei comandi, registrare sottocomandi, costruire gruppi di comandi o qualsiasi decisione architetturale relativa alla struttura dei comandi CLI. Usala anche quando l'utente menziona “System.CommandLine”, “CommandBase”, “SetAction”, “ParseResult”, “RootCommand”, “subcommand” o chiede di aggiungere un verbo alla CLI. NON usarla per la programmazione C# generica, API web, lavoro UI o progetti non CLI.

Rispondi sempre nella lingua dell'utente.
