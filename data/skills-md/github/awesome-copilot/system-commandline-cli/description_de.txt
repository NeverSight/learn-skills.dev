Verwenden Sie diese Fähigkeit, wenn Sie CLI‑Befehle in einem .NET‑Projekt hinzufügen, ändern oder überprüfen, das mit System.CommandLine erstellt wurde. Auslöser sind unter anderem: das Erstellen eines neuen CLI‑Befehls, das Hinzufügen von Optionen oder Argumenten, das Verbinden von Befehls‑Handlern, das Registrieren von Unterbefehlen, das Erstellen von Befehlsgruppen oder jede architektonische Entscheidung zur Struktur von CLI‑Befehlen. Verwenden Sie sie auch, wenn der Benutzer „System.CommandLine“, „CommandBase“, „SetAction“, „ParseResult“, „RootCommand“, „subcommand“ erwähnt oder darum bittet, ein Verb zur CLI hinzuzufügen. Verwenden Sie sie KEINEN FALL für allgemeine C#‑Programmierung, Web‑APIs, UI‑Arbeiten oder Nicht‑CLI‑Projekte.

Bitte antworten Sie immer in der Sprache des Benutzers.
