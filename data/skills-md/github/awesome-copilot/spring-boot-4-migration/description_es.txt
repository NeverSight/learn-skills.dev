Migrar una aplicación Spring Boot 3.x a Spring Boot 4.0 (Spring Framework 7, Jackson 3, «starters» modulares, JSpecify). Utilícelo únicamente para una migración explícita de Boot 3.x a 4, o para corregir errores de compilación o de pruebas causados por ella, o para revisar una. No es para actualizaciones de parches de 3.x ni para actualizaciones de 4.0 a 4.1; para estas, siga las notas de la versión de Boot de destino y la guía de actualización. Abarca Maven y Gradle (Kotlin DSL, catálogos de versiones).
