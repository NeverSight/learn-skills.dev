Migrer une application Spring Boot 3.x vers Spring Boot 4.0 (Spring Framework 7, Jackson 3, starters modulaires, JSpecify). À utiliser uniquement pour une migration explicite de Boot 3.x vers Boot 4, ou pour corriger des échecs de compilation ou de test causés par cette migration, ou pour en examiner un. Ne convient pas aux mises à jour de correctifs 3.x ni aux mises à niveau de 4.0 à 4.1 ; suivez les notes de version et le guide de mise à niveau de la version Boot cible pour ces cas. Couvre Maven et Gradle (Kotlin DSL, catalogues de versions).
