Migration einer Spring Boot 3.x-Anwendung auf Spring Boot 4.0 (Spring Framework 7, Jackson 3, modulare Starter, JSpecify). Nur für eine explizite Migration von Boot 3.x auf 4 verwenden, um dadurch verursachte Build- oder Testfehler zu beheben oder um eine solche Migration zu überprüfen. Nicht für Patch-Updates von 3.x oder Upgrades von 4.0 auf 4.1; befolgen Sie für diese die Versionshinweise und den Upgrade-Leitfaden der Zielversion von Boot. Umfasst Maven und Gradle (Kotlin DSL, Versionskataloge).
