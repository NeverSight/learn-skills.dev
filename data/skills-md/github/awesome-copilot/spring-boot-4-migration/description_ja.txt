Spring Boot 3.xアプリケーションをSpring Boot 4.0（Spring Framework 7、Jackson 3、モジュラー・スターター、JSpecify）に移行します。明示的なBoot 3.xから4への移行、またはそれによって生じたビルドやテストの失敗を修正するため、あるいはそれらをレビューするためにのみ使用してください。3.xのパッチのバージョンアップや4.0から4.1へのアップグレードには使用しないでください。これらについては、ターゲットのBootバージョンのリリースノートとアップグレードガイドに従ってください。MavenとGradle（Kotlin DSL、バージョンカタログ）に対応しています。
