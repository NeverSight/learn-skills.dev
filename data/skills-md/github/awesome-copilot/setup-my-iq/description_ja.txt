個人コンテキストポートフォリオを作成、設定、または更新します：あなたが誰であるか、どのように働くか、チーム、ツール／ADO の構成を記述した構造化された Markdown ファイルです。初回設定や更新のための対象編集を行うインタビュー・ワークフローを実行します。

ユーザーがコンテキストの設定、コンテキストポートフォリオの作成または更新、 「create my IQ」「set up my IQ」 などを求めたときにこのスキルをトリガーします。また、プロフィールの編集、ステークホルダーの追加・削除、ADO 設定の更新、チーム情報の変更、ピラーの更新、またはプラグイン設定のいずれかを行うときにもトリガーします。他のスキルがコンテキスト（ファイル欠如や TODO マーカー）を見つけられず、コンテキストの補充が必要な場合にもトリガーします。さらに、ユーザーが「マネージャーが変わった」「チームに誰かを追加した」などと軽く言及したときにも、コンテキストファイルの更新を提案します。

「誰が私のチームにいるのか？」や「ADO の設定は何か？」といった読み取り専用の質問にはトリガーしないでください。これらはロードされたカスタム指示で参照されているコンテキストファイルから直接回答され、スキルは不要です。

常にユーザーの言語で回答してください。
