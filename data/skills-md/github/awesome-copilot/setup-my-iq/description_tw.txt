建立、設定或更新個人情境投資組合：結構化的 markdown 檔案，用於描述你是誰、你的工作方式、你的團隊以及你的工具/ADO 設定。執行面試工作流程，以便首次設定或針對更新進行特定編輯。

在使用者要求以下操作時觸發此技能：設定他們的情境、建立或更新情境投資組合、"create my IQ"、"set up my IQ"、編輯個人檔案、增減利害關係人、更新 ADO 設定、變更團隊資訊、更新支柱，或設定任何插件配置。當其他技能因缺少情境（檔案遺失或 TODO 標記）而無法找到情境且需要填充情境時，也會觸發。此外，當使用者在敘述中提及情境變動（例如 "我的主管變了"、"我們新增了團隊成員"）時，也會主動提供更新情境檔案的建議。

**請勿**在僅詢問只讀資訊的情況下觸發，例如 "我的團隊成員有哪些？" 或 "我的 ADO 設定是什麼？"。此類問題直接從已載入的自訂說明中引用的情境檔案取得答案，無需使用任何技能。

請始終以使用者的語言回覆。
