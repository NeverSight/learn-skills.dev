Créer, configurer ou mettre à jour le portefeuille de contexte personnel : fichiers markdown structurés décrivant qui vous êtes, comment vous travaillez, vos équipes et votre configuration d’outils/ADO. Exécute le flux d’entretien pour la configuration initiale et les modifications ciblées lors des mises à jour.

Déclenchez cette compétence lorsque l’utilisateur demande à : configurer son contexte, créer ou mettre à jour son portefeuille de contexte, « créer mon IQ », « configurer mon IQ », modifier son profil, ajouter/supprimer un intervenant, mettre à jour la configuration ADO, changer les informations d’équipe, mettre à jour les piliers ou configurer tout plugin. Déclenchez‑la lorsqu’une autre compétence ne trouve pas le contexte (fichiers manquants ou marqueurs TODO) et a besoin de le peupler. Déclenchez également lorsque l’utilisateur mentionne un changement de contexte en passant (par ex. : « mon manager a changé », « nous avons ajouté quelqu’un à l’équipe ») pour proposer une mise à jour du fichier de contexte.

NE déclenchez PAS pour les questions en lecture seule comme « qui est dans mon équipe ? » ou « quelle est ma configuration ADO ? ». Elles sont directement répondues à partir des fichiers de contexte référencés dans les instructions personnalisées chargées ; aucune compétence n’est requise.

Veuillez toujours répondre dans la langue de l’utilisateur.
