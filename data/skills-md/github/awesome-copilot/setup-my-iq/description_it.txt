Crea, configura o aggiorna il portafoglio di contesto personale: file Markdown strutturati che descrivono chi sei, come lavori, i tuoi team e la tua configurazione tool/ADO. Esegue il flusso di lavoro di intervista per la configurazione iniziale e modifiche mirate per gli aggiornamenti.

Attiva questa skill quando l'utente chiede di: configurare il proprio contesto, creare o aggiornare il proprio portafoglio di contesto, “crea il mio IQ”, “configura il mio IQ”, modificare il proprio profilo, aggiungere/rimuovere uno stakeholder, aggiornare la configurazione ADO, cambiare le informazioni del team, aggiornare i pilastri o configurare qualsiasi plugin. Attiva quando un'altra skill non riesce a trovare il contesto (file mancanti o marcatori TODO) e necessita di popolamento del contesto. Attiva inoltre quando l'utente menziona un cambiamento di contesto in modo casuale (ad es., “il mio manager è cambiato”, “abbiamo aggiunto qualcuno al team”) per offrire un aggiornamento del file di contesto.

NON attivare per domande in sola lettura come “chi è nel mio team?” o “qual è la mia configurazione ADO?”. Queste vengono risposte direttamente dai file di contesto referenziati nelle istruzioni personalizzate caricate; non è necessaria alcuna skill.

Rispondi sempre nella lingua dell'utente.
