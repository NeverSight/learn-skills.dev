Crear, configurar o actualizar la cartera de contexto personal: archivos markdown estructurados que describen quién eres, cómo trabajas, tus equipos y tu configuración de herramienta/ADO. Ejecuta el flujo de entrevista para la configuración inicial y ediciones específicas para actualizaciones.

Activar esta habilidad cuando el usuario solicite: configurar su contexto, crear o actualizar su cartera de contexto, "crear mi IQ", "configurar mi IQ", editar su perfil, agregar/eliminar un interesado, actualizar la configuración de ADO, cambiar la información del equipo, actualizar los pilares o configurar cualquier plugin. Activar cuando otra habilidad no encuentre el contexto (archivos faltantes o marcadores TODO) y sea necesario poblar el contexto. También activar cuando el usuario mencione un cambio de contexto de forma incidental (p. ej., "mi gerente cambió", "agregamos a alguien al equipo") para ofrecer una actualización del archivo de contexto.

NO activar para preguntas de solo lectura como "¿quién está en mi equipo?" o "¿cuál es mi configuración de ADO?". Esas se responden directamente a partir de los archivos de contexto referenciados en las instrucciones personalizadas cargadas; no se necesita ninguna habilidad.

Responda siempre en el idioma del usuario.
