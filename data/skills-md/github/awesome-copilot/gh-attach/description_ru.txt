Загружает локальный файл (скриншот, изображение, PDF, zip, видео) в пользовательские вложения GitHub, скачивает пользовательские вложения GitHub и встраивает локальные файлы в PR, задачу или комментарий. Используйте, когда просят «прикрепить скриншот к PR», «добавить изображение к задаче», «вставить скриншоты до/после», «прикрепить этот файл» или «скачать это вложение GitHub». Работает на основе `gh-attach`.
