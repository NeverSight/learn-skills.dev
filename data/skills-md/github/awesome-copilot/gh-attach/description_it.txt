Carica un file locale (screenshot, immagine, PDF, zip, video) su GitHub user‑attachments, scarica gli allegati utente di GitHub e incorpora file locali in una PR, issue o commento. Usalo quando ti viene chiesto di “allegare uno screenshot alla PR”, “aggiungere un’immagine all’issue”, “incorporare screenshot prima/dopo”, “allegare questo file” o “scaricare questo allegato GitHub”. Realizzato con `gh-attach`.
