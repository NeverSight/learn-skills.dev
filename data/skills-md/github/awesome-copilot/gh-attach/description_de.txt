Lädt eine lokale Datei (Screenshot, Bild, PDF, ZIP, Video) zu den GitHub‑Benutzeranhängen hoch, lädt GitHub‑Benutzeranhänge herunter und bettet lokale Dateien in einen PR, ein Issue oder einen Kommentar ein. Verwenden Sie es, wenn Sie aufgefordert werden, „einen Screenshot zum PR hinzufügen“, „ein Bild zum Issue hinzufügen“, „Vorher‑/Nachher‑Screenshots einbetten“, „diese Datei anhängen“ oder „dieses GitHub‑Attachment herunterladen“. Angetrieben von `gh-attach`.

Bitte immer in der Sprache des Benutzers antworten.
