Téléverse un fichier local (capture d’écran, image, PDF, zip, vidéo) vers les pièces jointes d’utilisateur GitHub, télécharge les pièces jointes d’utilisateur GitHub et intègre les fichiers locaux dans une PR, une issue ou un commentaire. Utilisez‑le lorsqu’on vous demande « joindre une capture d’écran à la PR », « ajouter une image à l’issue », « intégrer des captures d’écran avant/après », « joindre ce fichier » ou « télécharger cette pièce jointe GitHub ». Fonctionne grâce à `gh-attach`.
