Используется, когда пользователь просит персонализировать помощника GitHub Copilot CLI, адаптировать Copilot к своему стилю, использовать vardoger или проанализировать историю разговоров Copilot CLI. Читает локальный каталог сессий по пути `~/.copilot/session-state/`, извлекает повторяющиеся предпочтения и соглашения и записывает блок персонализации в файл `~/.copilot/copilot-instructions.md` в виде fenced‑блока. Выполняется полностью на машине пользователя через локальный CLI `vardoger` (`pipx install vardoger`); без сетевых вызовов и загрузок. Триггеры: 'personalize my copilot', 'analyze my copilot history', 'tailor copilot to me', 'run vardoger', 'update my copilot instructions from history', 'make copilot learn my style'.

Пожалуйста, всегда отвечайте на языке пользователя.
