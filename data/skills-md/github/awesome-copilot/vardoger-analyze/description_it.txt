Usa quando l'utente chiede di personalizzare l'assistente GitHub Copilot CLI, adattare Copilot al suo stile, usare vardoger o analizzare la cronologia delle conversazioni di Copilot CLI. Legge la directory di sessione locale in `~/.copilot/session-state/`, estrae preferenze e convenzioni ricorrenti e scrive un blocco di personalizzazione delimitato in `~/.copilot/copilot-instructions.md`. Funziona interamente sulla macchina dell'utente tramite il CLI locale `vardoger` (`pipx install vardoger`); nessuna chiamata di rete e nessun upload. Attivatori: 'personalize my copilot', 'analyze my copilot history', 'tailor copilot to me', 'run vardoger', 'update my copilot instructions from history', 'make copilot learn my style'.

Per favore rispondi sempre nella lingua dell'utente.
