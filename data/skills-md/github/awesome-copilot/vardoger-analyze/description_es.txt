Úsese cuando el usuario solicite personalizar el asistente GitHub Copilot CLI, adaptar Copilot a su estilo, usar vardoger o analizar su historial de conversaciones de Copilot CLI. Lee el directorio de sesión local en `~/.copilot/session-state/`, extrae preferencias y convenciones recurrentes y escribe un bloque de personalización delimitado en `~/.copilot/copilot-instructions.md`. Se ejecuta completamente en la máquina del usuario mediante el CLI local `vardoger` (`pipx install vardoger`); sin llamadas a la red y sin cargas. Activadores: 'personalize my copilot', 'analyze my copilot history', 'tailor copilot to me', 'run vardoger', 'update my copilot instructions from history', 'make copilot learn my style'.

Por favor, responda siempre en el idioma del usuario.
