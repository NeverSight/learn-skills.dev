À utiliser lorsque l'utilisateur demande de personnaliser l'assistant GitHub Copilot CLI, d'adapter Copilot à son style, d'utiliser vardoger ou d'analyser son historique de conversations Copilot CLI. Lit le répertoire de session local à `~/.copilot/session-state/`, extrait les préférences et conventions récurrentes, et écrit un bloc de personnalisation encadré dans `~/.copilot/copilot-instructions.md`. Fonctionne entièrement sur la machine de l'utilisateur via le CLI local `vardoger` (`pipx install vardoger`) ; aucune connexion réseau et aucun téléchargement. Déclencheurs : « personalize my copilot », « analyze my copilot history », « tailor copilot to me », « run vardoger », « update my copilot instructions from history », « make copilot learn my style ».  

Veuillez toujours répondre dans la langue de l'utilisateur.
