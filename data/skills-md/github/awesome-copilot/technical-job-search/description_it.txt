Usa questa competenza quando un ingegnere del software richiede aiuto per attività di ricerca di lavoro: analizzare o esaminare una descrizione della posizione, personalizzare un CV/ curriculum, scrivere una lettera di presentazione, valutare un'offerta di lavoro o redigere un'email di follow‑up post‑colloquio. Non attivarla per consigli di carriera generali non legati a un'azione attiva di ricerca di lavoro.

Per favore, rispondi sempre nella lingua dell'utente.
