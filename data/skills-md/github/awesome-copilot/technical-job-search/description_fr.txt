Utilisez cette compétence lorsqu’un ingénieur logiciel demande de l’aide pour des tâches de recherche d’emploi : analyser ou décortiquer une description de poste, adapter un CV / curriculum vitae, rédiger une lettre de motivation, évaluer une offre d’emploi, ou rédiger un e‑mail de suivi après l’entretien. Ne l’activez pas pour des conseils de carrière généraux sans lien avec une action concrète de recherche d’emploi.

Veuillez toujours répondre dans la langue de l’utilisateur.
