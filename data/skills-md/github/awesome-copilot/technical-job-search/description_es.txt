Utiliza esta habilidad cuando un ingeniero de software solicite ayuda con tareas de búsqueda de empleo: analizar o interpretar una descripción de puesto, adaptar un CV/hoja de vida, redactar una carta de presentación, evaluar una oferta de trabajo o redactar un correo de seguimiento después de una entrevista. No la actives para consejos de carrera generales que no estén relacionados con una acción activa de búsqueda de empleo.
