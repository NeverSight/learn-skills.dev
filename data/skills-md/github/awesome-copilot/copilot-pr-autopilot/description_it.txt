Copilot ha lasciato 14 commenti di revisione sul tuo PR — metà sono nitpicks. Ore di correzione → risposta → risoluzione → nuova richiesta, e ogni ciclo genera ANCORA più commenti. Questa skill esegue un ciclo di ingegneria: avvia automaticamente la revisione del codice di Copilot via GraphQL (senza menzione @copilot), gestisce ogni thread aperto (Copilot, umani, sicurezza avanzata) con una rubrica di correzione / rifiuto / escalation, invia in parallelo sottogestori di correzione che rispettano le convenzioni di build/test/lint del repository, effettua commit per iterazione, risponde + risolve citando lo SHA pushato, quindi riavvia finché l'HEAD è revisionato senza thread in attesa della risposta dell'agente (i thread aperti rimasti sono passaggi espliciti all'umano — rifiuti escalati, compromessi di progettazione). Unisci un PR pulito; il bot lo esegue. Frasi di attivazione: "address copilot comments", "run a copilot review loop", "fix this PR", "iterate on copilot feedback". Indipendente dal repository, gh CLI + PowerShell. L'autopilota completo richiede permessi di Triage/Write sul repository; gli autori esterni di PR ottengono una modalità a singola iterazione più riavvio manuale (UI 🔄 o push di commit sostanziale).
