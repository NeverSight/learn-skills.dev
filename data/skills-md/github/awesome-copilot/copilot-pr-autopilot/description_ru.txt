Copilot оставил 14 комментариев к вашему PR — половина из них мелкие замечания. Часы исправления → ответ → решение → повторный запрос, и каждый раунд добавляет ЕЩЁ больше комментариев. Эта функция реализует цикл инженерии: автоматически инициирует обзор кода Copilot через GraphQL (без упоминания @copilot), обрабатывает каждую откры‑тую ветку (Copilot, люди, advanced‑security) по шкале «исправить / отклонить / эскалировать», запускает параллельные суб‑агенты исправлений, которые соблюдают конвенции репозитория по сборке/тестированию/линтингу, делают коммиты за каждую итерацию, отвечают и решают, ссылаясь на запушенный SHA, затем повторно инициируют процесс, пока HEAD не будет проверен без открытых веток, ожидающих ответ агента (оставшиеся открытые ветки — явные передачи человеку — эскалированные отклонения, компромиссы в дизайне). Вы сливаете чистый PR; бот его исполняет. Фразы‑триггеры: «address copilot comments», «run a copilot review loop», «fix this PR», «iterate on copilot feedback». Не зависящий от репозитория, работает с gh CLI + PowerShell. Полный автопилот требует прав Triage/Write в репозитории; внешние авторы PR получают режим одной итерации плюс ручной повторный запуск (UI 🔄 или пуш значимого коммита).
