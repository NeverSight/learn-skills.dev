Copilot a laissé 14 commentaires de révision sur votre PR — la moitié sont des détails. Des heures de correctif → réponse → résolution → nouvelle demande, et chaque tour génère PLUS de commentaires. Cette compétence exécute une boucle d’ingénierie : déclenche automatiquement la revue de code Copilot via GraphQL (sans mention @copilot), triage chaque fil ouvert (Copilot, humains, advanced‑security) selon un ruban de correction / refus / escalade, envoie des sous‑agents de correction parallèles qui respectent les conventions de build/test/lint du dépôt, commite à chaque itération, répond + résout en citant le SHA poussé, puis relance jusqu’à ce que le HEAD soit revu sans aucun fil en attente de la réponse de l’agent (les fils restants ouverts sont des transferts explicites aux humains — refus escaladés, compromis de conception). Vous fusionnez une PR propre ; le bot l’exécute. Phrases déclencheurs : « address copilot comments », « run a copilot review loop », « fix this PR », « iterate on copilot feedback ». Indépendant du dépôt, gh CLI + PowerShell. L’autopilote complet nécessite les autorisations Triage/Write sur le dépôt ; les auteurs externes de PR obtiennent un mode à itération unique avec re‑déclenchement manuel (UI 🔄 ou push de commit substantiel).
