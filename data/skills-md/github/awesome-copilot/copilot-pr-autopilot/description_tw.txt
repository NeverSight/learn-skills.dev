Copilot 在你的 PR 上留下了 14 條審查意見——其中一半是瑣碎問題。花了數小時去修復 → 回覆 → 解決 → 重新請求，而每一輪都會產生更多評論。此技能實現了循環工程：透過 GraphQL 自動觸發 Copilot 程式碼審查（無需 @copilot 提及），對每個未解決的討論串（Copilot、人類、advanced‑security）依照「修復 / 拒絕 / 升級」準則分流，派遣遵循倉庫 build/test/lint 規範的平行修復子代理人，逐次提交、回覆並解決，並引用已推送的 SHA，然後重新觸發，直到 HEAD 被審查且沒有任何討論串在等待代理人的回覆（剩餘未解決的討論串視為明確交給人類處理——升級的拒絕、設計取捨）。你合併乾淨的 PR 後，機器人會執行它。觸發語句包括：「address copilot comments」、「run a copilot review loop」、「fix this PR」、「iterate on copilot feedback」。與倉庫無關，使用 gh CLI + PowerShell。完整自動駕駛需要倉庫的 Triage/Write 權限；外部 PR 作者則採單次迭代模式，並可手動重新觸發（UI 🔄 或實質提交推送）。
