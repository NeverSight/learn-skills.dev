Copilot이 PR에 14개의 리뷰 댓글을 남겼어요 — 절반은 사소한 지적입니다. 수정 → 답변 → 해결 → 재요청을 몇 시간씩 반복하면 매 라운드마다 더 많은 댓글이 쌓입니다. 이 스킬은 루프 엔지니어링을 수행합니다: GraphQL을 통해 자동으로 Copilot Code Review를 트리거하고(@copilot 멘션 없이), 모든 열린 스레드(Copilot, 인간, advanced-security)를 수정/거절/에스컬레이션 루브릭에 따라 분류하며, 저장소의 빌드/테스트/린트 규칙을 따르는 병렬 수정 서브 에이전트를 디스패치하고, 반복마다 커밋하고, 푸시된 SHA를 인용해 답변·해결한 뒤, HEAD가 에이전트의 답변을 기다리는 스레드가 전혀 없을 때까지 다시 트리거합니다(남아있는 열린 스레드는 인간에게 명시적인 인계 – 에스컬레이션 된 거절, 설계 트레이드오프). 깨끗한 PR을 머지하면 봇이 실행됩니다. 트리거 구문: "address copilot comments", "run a copilot review loop", "fix this PR", "iterate on copilot feedback". 저장소에 독립적이며 gh CLI와 PowerShell을 사용합니다. 완전 자동 파일럿을 위해서는 저장소에 트라이아지/쓰기 권한이 필요하고, 외부 PR 작성자는 단일 반복 모드와 수동 재트리거(UI 🔄 또는 실질적인 커밋 푸시)를 사용할 수 있습니다.
