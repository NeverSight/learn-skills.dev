Copilot があなたの PR に 14 件のレビューコメントを残しました — うち半分は細かい指摘です。修正に何時間もかかり → 返信 → 解決 → 再要求、そして各ラウンドでさらに多くのコメントが付く。このスキルはループエンジニアリングを実行します：GraphQL 経由で Copilot Code Review を自動トリガー（@copilot のメンション不要）、すべてのオープンスレッド（Copilot、ヒューマン、advanced‑security）を「修正 / 拒否 / エスカレーション」のルーブリックでトリアージし、リポジトリのビルド／テスト／リント規約に従う並列修正サブエージェントを配備、イテレーションごとにコミットし、プッシュした SHA を引用して返信＋解決し、エージェントの返信を待つスレッドがゼロになるまで HEAD がレビューされるまで再トリガーします（残っているオープンスレッドは人間への明示的なハンドオフ ‑ エスカレーションされた拒否、設計上のトレードオフ）。クリーンな PR をマージすると、ボットがそれを実行します。トリガーフレーズ：「address copilot comments」「run a copilot review loop」「fix this PR」「iterate on copilot feedback」。リポジトリに依存せず、gh CLI と PowerShell を使用。完全自動操縦にはリポジトリのトリアージ／書き込み権限が必要；外部 PR 作成者には単一イテレーションモードと手動再トリガー（UI 🔄 または実質的なコミットプッシュ）が提供されます。
