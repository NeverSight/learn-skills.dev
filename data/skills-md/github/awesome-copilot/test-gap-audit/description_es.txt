Ejecuta una auditoría de solo lectura para detectar cobertura de pruebas faltante, débil, obsoleta o mal delimitada. Si el usuario no menciona un alcance, audita todo el repositorio e identifica rutas de código importantes, rutas, funcionalidades, servicios, flujos de trabajo y contratos que carecen de pruebas adecuadas. Si el usuario nombra una funcionalidad, PR, rama, ruta, flujo de trabajo, servicio, corrección de error, API, ruta sensible a la seguridad o cambio de código arriesgado, concéntrate solo en ese alcance específico. Utilízalo cuando el usuario pregunte qué pruebas faltan, si la cobertura es suficiente, qué pruebas de regresión añadir o cómo demostrar que un cambio es seguro. Esto no es una auditoría general de errores ni una revisión de seguridad; evalúa si el comportamiento está cubierto por pruebas.

Por favor, responde siempre en el idioma del usuario.
