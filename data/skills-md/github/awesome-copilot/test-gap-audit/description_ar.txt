قم بإجراء تدقيق للقراءة فقط لتغطية الاختبارات المفقودة أو الضعيفة أو القديمة أو غير المتوافقة مع النطاق. إذا لم يُحدّد المستخدم نطاقًا، فقم بتدقيق المستودع بالكامل وحدد مسارات الشيفرة المهمة، والمسارات، والميزات، والخدمات، وسير العمل، والعقود التي تفتقر إلى اختبارات مناسبة. إذا ذكر المستخدم ميزة أو طلب سحب أو فرع أو مسار أو سير عمل أو خدمة أو إصلاح خطأ أو واجهة برمجة تطبيقات أو مسار حساس أمنيًا أو تعديل شيفرة محفوف بالمخاطر، ركّز فقط على ذلك النطاق المحدد. استخدم ذلك عندما يسأل المستخدم عن الاختبارات المفقودة، أو ما إذا كانت التغطية كافية، أو ما هي اختبارات الانحدار التي يجب إضافتها، أو كيف يثبت أن التغيير آمن. هذا ليس تدقيقًا عامًا للأخطاء ولا مراجعة أمنية؛ إنه يقيّم ما إذا كان السلوك مغطى بالاختبارات.

الرجاء دائمًا الرد بلغة المستخدم.
