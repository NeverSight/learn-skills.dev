Проверяет изменения кода Spec Kit на соответствие применимым проектным документам, покрытие положительными и отрицательными тестами, наличие доказательств регрессии для исправлений ошибок и единообразную терминологию репозитория. Используется при обзоре диффа или pull‑request. Не используется для внедрения изменений или размещения действий обзора на GitHub.
