Web UI を構築またはレビューする際の CSS アーキテクチャとデザイントークンに対するフレームワーク非依存のレビュー レンズ：カスケードレイヤーとフラットな特異性、プリミティブ／セマンティック／コンポーネントトークン パイプライン、トークンの再定義によるテーマ化とダークモード、CSS Modules とユーティリティ と CSS-in-JS の選択、固有のレスポンシブレイアウト、コンテナクエリ、そして流動的なタイポグラフィと間隔。`react`、`angular`、`vue`、アクセシビリティと組み合わせて使用できる。ユーザーが CSS、スタイリング、デザイントークン、テーマ化、ダークモード、デザインシステム、コンテナクエリ、メディアクエリ、レスポンシブレイアウト、流動的なタイポグラフィ、"clamp"、Tailwind、CSS Modules、CSS-in-JS、カスケードレイヤー、または "@layer" に言及したときに使用してください。
