Нейтральный к фреймворкам обзорный подход для архитектуры CSS и дизайн‑токенов при построении или проверке веб‑интерфейса: каскадные слои и плоская специфичность, конвейер токенов примитив/семантика/компонент, темизация и тёмный режим путём переопределения токенов, выбор между CSS Modules, utility‑классами и CSS‑in‑JS, встроенный адаптивный макет, контейнерные запросы и плавные типографика и отступы. Сочетается с `react`, `angular`, `vue` и доступностью. Используйте его, когда пользователь упоминает CSS, стилизацию, дизайн‑токены, темизацию, тёмный режим, систему дизайна, контейнерные запросы, медиазапросы, адаптивный макет, плавный тип, «clamp», Tailwind, CSS Modules, CSS‑in‑JS, каскадные слои или «@layer».
