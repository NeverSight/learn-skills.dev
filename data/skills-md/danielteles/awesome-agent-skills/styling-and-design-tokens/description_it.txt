Una lente di revisione neutrale rispetto al framework per l'architettura CSS e i token di design quando si costruisce o si rivede un'interfaccia web: livelli di cascata e specificità piatta, una pipeline di token primitivo/semantico/componente, tematizzazione e modalità scura mediante ridefinizione dei token, la decisione tra CSS Modules, utility e CSS‑in‑JS, layout responsivo intrinseco, query di contenitore e tipografia e spaziatura fluidi. Si compone con `react`, `angular`, `vue` e `accessibility`. Usala quando l'utente menziona CSS, styling, design tokens, tematizzazione, modalità scura, un design system, query di contenitore, media query, layout responsivo, tipografia fluida, "clamp", Tailwind, CSS Modules, CSS‑in‑JS, livelli di cascata o "@layer".
