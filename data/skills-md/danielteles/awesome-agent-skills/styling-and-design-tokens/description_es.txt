Una lente de revisión neutral al framework para la arquitectura CSS y los tokens de diseño al crear o revisar UI web: capas de cascada y especificidad plana, un pipeline de tokens primitivo/semántico/componente, tematización y modo oscuro mediante redefinición de tokens, la decisión entre CSS Modules, utilidades o CSS‑in‑JS, diseño responsivo intrínseco, consultas de contenedor y tipografía y espaciado fluidos. Se compone con `react`, `angular`, `vue` y `accessibility`. Úsala cuando el usuario mencione CSS, estilado, design tokens, tematización, modo oscuro, un sistema de diseño, container queries, media queries, diseño responsivo, tipografía fluida, "clamp", Tailwind, CSS Modules, CSS‑in‑JS, cascade layers o "@layer".
