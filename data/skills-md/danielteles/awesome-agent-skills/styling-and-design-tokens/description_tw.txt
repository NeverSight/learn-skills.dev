一個框架中立的審視視角，用於在構建或檢視 Web UI 時的 CSS 架構與設計標記：層疊層（cascade layers）與扁平特異性（flat specificity）、原始／語意／元件標記管線、透過標記重新定義實現主題與暗色模式、CSS Modules 與 utility 與 CSS‑in‑JS 的抉擇、固有回應式佈局、容器查詢（container queries）以及流體字型與間距。可與 `react`、`angular`、`vue` 以及無障礙（accessibility）共用。當使用者提到 CSS、樣式、設計標記、主題、暗色模式、設計系統、容器查詢、媒體查詢、回應式佈局、流體字型、"clamp"、Tailwind、CSS Modules、CSS‑in‑JS、層疊層或 "@layer" 時，請使用此框架。
