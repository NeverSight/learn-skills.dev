Framework-unabhängige Standards für die Qualität eines einzelnen automatisierten Tests in TypeScript: Auf Verhalten statt Implementation prüfen, sinnvolle Assertions, pro Test ein nach Ergebnis benanntes Szenario, Builder statt gemeinsam genutzte Fixtures, Test-Doubles, die ihre Berechtigung verdienen, deterministische, Reihenfolge‑unabhängige Tests, Coverage als Karte des Unverifizierten lesen. Verwende sie beim Schreiben von Tests für neuen oder geänderten Code, beim Review der Tests in einem Pull‑Request oder beim Beheben eines schwachen, zerbrechlichen oder flüchtigen Tests — oder wenn der Nutzer sagt „Testqualität“, „Unit‑Test‑Review“, „diese Tests sind zerbrechlich“, „flüchtiger Test“, „Over‑Mocking“, „Testing von Implementierungsdetails“, „AAA“, „Arrange Act Assert“ oder „Auf Verhalten prüfen“.
