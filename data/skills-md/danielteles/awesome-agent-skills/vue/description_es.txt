Convenciones modernas de Vue 3 para escribir, revisar, refactorizar o migrar Vue: `<script setup>` y la Composition API, `defineProps` / `defineEmits` / `defineModel`, `ref` vs `reactive` y advertencias sobre pérdida de reactividad, composables para lógica compartida, `provide` / `inject` y Pinia dentro de los niveles de estado, plantillas y listas con claves, `<Suspense>` y componentes asíncronos, el límite del servidor en Nuxt y pruebas por rol. Se basa en `core-typescript` y `architecture-and-design`. Úsalo cuando el usuario mencione Vue, Nuxt, `script setup`, Composition API, `ref`, `reactive`, `computed`, `watch`, composables, Pinia, `defineModel`, `v-model`, `provide`/`inject`, o desajuste de hidratación.
