モダンな Vue 3 の慣習として、Vue の記述・レビュー・リファクタリング・マイグレーション時に `<script setup>` と Composition API、`defineProps` / `defineEmits` / `defineModel`、`ref` と `reactive` の比較とリアクティビティ喪失に関する注意点、共有ロジック向けの composable、状態層における `provide` / `inject` と Pinia、テンプレートとキー付きリスト、`<Suspense>` と非同期コンポーネント、Nuxt のサーバーバウンダリ、そしてロール別テストを採用します。`core-typescript` と `architecture-and-design` を基盤としています。ユーザーが Vue、Nuxt、`script setup`、Composition API、`ref`、`reactive`、`computed`、`watch`、composable、Pinia、`defineModel`、`v-model`、`provide`/`inject`、または hydration mismatch に言及したときに使用してください。
