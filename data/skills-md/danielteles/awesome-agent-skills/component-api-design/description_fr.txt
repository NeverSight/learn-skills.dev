Normes neutres vis-à-vis du framework pour l'API publique d'un composant UI réutilisable : un contrat de props minimal et stable, les slots et la composition versus les props de configuration, les paires de valeurs contrôlées et non contrôlées, le pattern du composant composé, et l’évolution d’un composant partagé sans casser ses consommateurs. Se situe entre `architecture-and-design` et les compétences framework. Utilisez-le lorsque l’utilisateur mentionne l’API d’un composant, la conception des props, une bibliothèque de composants ou un système de design, les slots, les render props, contrôlé vs non contrôlé, les composants composés, une « explosion de props booléennes », ou la version d’un composant partagé.
