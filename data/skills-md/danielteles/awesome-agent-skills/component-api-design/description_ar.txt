معايير محايدة للإطار لواجهة برمجة التطبيقات العامة لمكوّن UI قابل لإعادة الاستخدام: عقد خصائص (props) الحد الأدنى والمستقر، الفتحات (slots) والتركيب مقابل خصائص التكوين، أزواج القيم المتحكم فيها وغير المتحكم فيها، نمط المكوّن المركب، وتطوير مكوّن مشترك دون كسر مستهلكيه. يقع بين `architecture-and-design` ومهارات الإطار. استخدمه عندما يذكر المستخدم واجهة برمجة المكوّن، تصميم الخصائص، مكتبة مكوّنات أو نظام تصميم، الفتحات، خصائص العرض (render props)، المتحكم فيه مقابل غير المتحكم فيه، المكوّنات المركبة، "انفجار الخصائص المنطقية"، أو إصدار مكوّن مشترك.
