再利用可能な UI コンポーネントの公開 API に関するフレームワークに依存しない標準：最小かつ安定した props 契約、スロットとコンポジション対構成 props、制御された値と非制御の値のペア、コンパウンドコンポーネントパターン、そして利用者を壊さずに共有コンポーネントを進化させる方法。`architecture-and-design` とフレームワークスキルの間に位置する。ユーザーがコンポーネント API、props 設計、コンポーネントライブラリやデザインシステム、スロット、レンダープロップス、制御 vs 非制御、コンパウンドコンポーネント、「ブール型プロップの爆発」や共有コンポーネントのバージョニングについて言及したときに使う。
