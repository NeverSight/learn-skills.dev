Framework-unabhängige Standards für die öffentliche API einer wiederverwendbaren UI‑Komponente: ein minimaler und stabiler Props‑Vertrag, Slots und Composition versus Konfigurations‑Props, kontrollierte und unkontrollierte Wertepaare, das Compound‑Component‑Pattern und die Weiterentwicklung einer geteilten Komponente, ohne deren Verbraucher zu brechen. Verwenden Sie es, wenn der Nutzer Komponenten‑API, Props‑Design, eine Komponenten‑Bibliothek oder ein Design‑System, Slots, Render‑Props, kontrolliert vs. unkontrolliert, Compound‑Komponenten, eine „boolean prop explosion“ oder die Versionierung einer geteilten Komponente erwähnt.
