Estándares neutrales respecto al framework para la API pública de un componente UI reutilizable: un contrato de props mínimo y estable, slots y composición frente a props de configuración, pares de valores controlados e incontrolados, el patrón de componente compuesto y la evolución de un componente compartido sin romper a sus consumidores. Se sitúa entre `architecture-and-design` y las habilidades del framework. Úsalo cuando el usuario mencione API de componentes, diseño de props, una biblioteca de componentes o sistema de diseño, slots, render props, controlado vs incontrolado, componentes compuestos, una “explosión de props booleanas”, o versionado de un componente compartido.
