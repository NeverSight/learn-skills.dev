Фреймворк‑нейтральные стандарты публичного API переиспользуемого UI‑компонента: минимальный и стабильный контракт пропсов, слоты и композиция вместо конфигурационных пропсов, пары управляемых и неуправляемых значений, паттерн составного компонента и эволюция общего компонента без нарушения работы его потребителей. Находится между `architecture-and-design` и навыками работы с фреймворком. Используйте, когда пользователь упоминает API компонента, дизайн пропсов, библиотеку компонентов или систему дизайна, слоты, render props, управляемый vs неуправляемый, составные компоненты, «взрыв булевых пропсов» или версионирование общего компонента.
