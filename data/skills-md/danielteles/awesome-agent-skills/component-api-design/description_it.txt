Standard neutrali rispetto al framework per l'API pubblica di un componente UI riutilizzabile: un contratto di props minimo e stabile, slot e composizione rispetto alle props di configurazione, coppie di valori controllati e non controllati, il pattern del componente composto e l'evoluzione di un componente condiviso senza rompere i suoi consumatori. Si colloca tra `architecture-and-design` e le competenze di framework. Usalo quando l'utente menziona l'API del componente, la progettazione dei props, una libreria di componenti o un design system, slot, render props, controllato vs non controllato, componenti composti, un “esplosione di prop booleani” o il versionamento di un componente condiviso.
