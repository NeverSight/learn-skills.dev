Una meta‑habilidad que orquesta una revisión de código frontend: dado un diff, elige cuáles de las demás habilidades se aplican, las ejecuta en un orden lógico, fusiona sus hallazgos en una lista ordenada y elimina duplicados de un problema que dos habilidades reportan. No contiene reglas de ingeniería propias — redirige a `core-typescript`, `architecture-and-design`, las habilidades de framework y los lentes. Úsala cuando el usuario solicite una revisión completa de código de un pull request o un diff, diga “revisa este cambio”, “ejecuta todas las habilidades”, “qué habilidades se aplican aquí”, o quiera los hallazgos de varias habilidades combinados sin duplicación.

Por favor, responde siempre en el idioma del usuario.
