Une méta‑compétence qui orchestre une revue de code frontend : à partir d’un diff, elle choisit les compétences applicables, les exécute dans un ordre logique, regroupe leurs conclusions en une liste ordonnée et élimine les doublons lorsqu’un même problème est signalé par deux compétences. Elle ne possède aucune règle d’ingénierie propre — elle redirige vers `core-typescript`, `architecture-and-design`, les compétences du framework et les lenses. Utilisez‑la lorsque l’utilisateur demande une revue complète d’une pull request ou d’un diff, dit « revoyez ce changement », « exécutez toutes les compétences », « quelles compétences s’appliquent ici », ou souhaite des conclusions provenant de plusieurs compétences combinées sans duplication.
