Una meta‑skill che orchestra una revisione del codice frontend: dato un diff, sceglie quali delle altre skill si applicano, le esegue in un ordine sensato, unisce i loro risultati in un elenco ordinato e de‑duplica un problema segnalato da due skill. Non contiene regole ingegneristiche proprie — reindirizza a `core-typescript`, `architecture-and-design`, le skill del framework e le lenti. Usala quando l’utente richiede una revisione completa di una pull request o di un diff, dice “review this change”, “run all the skills”, “which skills apply here”, o vuole risultati combinati provenienti da diverse skill senza duplicazioni.
