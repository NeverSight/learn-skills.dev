Метаскил, который организует фронтенд‑ревью кода: получив дифф, он определяет, какие из других скиллов применимы, запускает их в разумном порядке, объединяет их выводы в один упорядоченный список и удаляет дублирование проблем, о которых сообщают два скилла. Он не содержит собственных инженерных правил — перенаправляет к `core-typescript`, `architecture-and-design`, скиллам фреймворков и линзам. Используйте его, когда пользователь просит полный код‑ревью пул‑реквеста или диффа, говорит «review this change», «run all the skills», «which skills apply here», или хочет получить результаты нескольких скиллов, объединённые без дублирования.
