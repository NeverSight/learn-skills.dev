Eine Meta‑Fähigkeit, die ein Frontend‑Code‑Review orchestriert: Gegeben ein Diff wählt sie aus, welche der anderen Fähigkeiten anwendbar sind, führt sie in einer sinnvollen Reihenfolge aus, fasst deren Ergebnisse zu einer geordneten Liste zusammen und eliminiert Duplikate, wenn zwei Fähigkeiten denselben Fehler melden. Sie enthält keine eigenen ingenieurtechnischen Regeln – sie leitet weiter an `core-typescript`, `architecture-and-design`, die Framework‑Fähigkeiten und die Lenses. Verwende sie, wenn der Benutzer nach einem vollständigen Code‑Review eines Pull‑Requests oder eines Diffs fragt, „review this change“, „run all the skills“, „which skills apply here“ sagt oder Ergebnisse mehrerer Fähigkeiten ohne Duplikate kombiniert haben möchte.

Bitte antworte immer in der Sprache des Benutzers.
