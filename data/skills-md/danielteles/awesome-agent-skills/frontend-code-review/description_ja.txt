フロントエンドコードレビューをオーケストレーションするメタスキル：diff が与えられると、どの他のスキルが適用できるかを選択し、適切な順序で実行し、結果を一つの順序付けされたリストに統合し、二つのスキルが報告した同一の問題を重複除去します。独自のエンジニアリング規則は持たず、`core-typescript`、`architecture-and-design`、フレームワークスキル、そしてレンズへルーティングします。ユーザーがプルリクエストまたは diff のフルコードレビューを依頼したり、「この変更をレビューして」「すべてのスキルを実行して」「ここで適用できるスキルはどれか」などと言ったとき、あるいは複数のスキルの結果を重複なく組み合わせて欲しいときに使用してください。
