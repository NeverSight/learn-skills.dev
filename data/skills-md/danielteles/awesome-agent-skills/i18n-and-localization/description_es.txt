Una lente de revisión neutral respecto al framework para internacionalizar una UI web: mensajes ICU MessageFormat indexados por significado, selección de plural y género según CLDR, formato de fecha, número, moneda y listas dependiente del locale con `Intl`, texto de derecha a izquierda y bidireccional, locale en la URL con negociación y `hreflang`, y el ciclo de vida del catálogo de mensajes (fallback, carga diferida, pseudo‑localización). Se combina con `react`, `angular` y `vue` para la API de la librería i18n. Úsalo cuando el usuario mencione i18n, l10n, internacionalización, localización, traducción, ICU MessageFormat, plurales, `Intl`, RTL, bidi, enrutamiento por locale, `hreflang`, `Accept-Language` o un catálogo de mensajes.
