Нейтральный к фреймворкам обзорный фильтр для интернационализации веб‑интерфейса: сообщения ICU MessageFormat, индексируемые по смыслу, выбор множественного числа и пола согласно CLDR, локаль‑aware форматирование дат, чисел, валют и списков с помощью `Intl`, поддержка текста справа‑налево и двунаправленного текста, указание локали в URL с переговорами и `hreflang`, а также жизненный цикл каталога сообщений (fallback, отложенная загрузка, псевдолокализация). Совместим с `react`, `angular` и `vue` для API библиотеки i18n. Используйте его, когда пользователь упоминает i18n, l10n, internationalization, localization, translation, ICU MessageFormat, plurals, `Intl`, RTL, bidi, locale routing, `hreflang`, `Accept-Language` или каталог сообщений.
