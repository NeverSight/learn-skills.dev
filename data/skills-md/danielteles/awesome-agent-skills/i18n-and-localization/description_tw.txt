一個框架中立的檢視鏡頭，用於將 Web UI 國際化：以意義為鍵的 ICU MessageFormat 訊息、CLDR 複數與性別選擇、具備語系感知的日期、數字、貨幣與清單格式化（使用 `Intl`），右至左與雙向文字、URL 中的語系與協商及 `hreflang`，以及訊息目錄的生命週期（回退、延遲載入、偽本地化）。可與 `react`、`angular`、`vue` 組合使用，提供 i18n 函式庫 API。當使用者提及 i18n、l10n、internationalization、localization、translation、ICU MessageFormat、plurals、`Intl`、RTL、bidi、locale routing、`hreflang`、`Accept-Language` 或訊息目錄時使用本工具。
