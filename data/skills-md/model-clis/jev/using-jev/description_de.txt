Verwenden Sie das jev‑CLI, wenn ein Skript, eine Pipeline, ein CI‑Job oder ein Agent‑Workflow eine schnelle typisierte semantische Bewertung anstelle von generiertem Text benötigt: das Weiterleiten oder Klassifizieren von Text zu vordefinierten Labels, Ja/Nein‑Gatekeeping mit kalibrierter Wahrscheinlichkeit, Bewertung entlang geordneter Stufen, Ranking von Kandidatentexten oder das Prüfen einer Bedingung, die sonst einen fragilen Prompt‑und‑Parse‑Schritt erfordern würde. Nutzen Sie es auch immer dann, wenn der Benutzer Jev, TypeSafe, System One, kalibrierte Bewertungen oder semantische Tore in der Automation erwähnt. Verwenden Sie es nicht für Textgenerierung, mehrstufiges Schließen oder offene Fragen.

Bitte antworten Sie immer in der Sprache des Benutzers.
