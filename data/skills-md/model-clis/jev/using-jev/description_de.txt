Verwenden Sie das jev‑CLI, wenn ein Skript, eine Pipeline, ein CI‑Job oder ein Agenten‑Workflow ein schnelles, typisiertes semantisches Urteil anstelle von generiertem Text benötigt: Text zu vordefinierten Labels weiterleiten oder klassifizieren, Ja/Nein‑Gate mit kalibrierter Wahrscheinlichkeit, Bewertung auf geordneten Stufen, Ranking von Kandidaten‑Texten oder Überprüfung einer Bedingung, die sonst einen fragilen Prompt‑und‑Parse‑Schritt erfordern würde. Verwenden Sie es außerdem immer dann, wenn der Nutzer Jev, TypeSafe, System One, kalibrierte Urteile oder semantische Gates in der Automatisierung erwähnt. Verwenden Sie es nicht für Textgenerierung, mehrstufiges Schließen oder offene Fragen.
