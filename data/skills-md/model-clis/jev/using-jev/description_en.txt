Use the jev CLI when a script, pipeline, CI job, or agent workflow needs a fast typed semantic judgment instead of generated text: routing or classifying text to predefined labels, yes/no gating with calibrated probability, rating along ordered levels, ranking candidate texts, or checking a condition that would otherwise require a fragile prompt-and-parse step. Also use whenever the user mentions Jev, TypeSafe, System One, calibrated judgments, or semantic gates in automation. Do not use it for text generation, multi-step reasoning, or open-ended questions.
