Установите нужную библиотеку анимации в совместимый проект и создайте профессиональный, анимированный UI/UX. Четыре движка: Framer Motion (пакет `motion`, декларативная анимация в React), GSAP (таймлайны + ScrollTrigger, любой фреймворк), anime.js v4 (лёгковесный, любой фреймворк) и Three.js (3D/WebGL, `@react-three/fiber` в React); плюс Lenis для плавной прокрутки и morphicons для переходов иконка‑в‑иконку. Определяет стек и менеджер пакетов и выбирает подходящий движок перед установкой — GSAP/anime.js/Three.js/Lenis/morphicons работают в React, Next, Vite, Vue, Svelte, Astro или в чистом JavaScript; Framer Motion — только в React. Содержит справочник по таймингам/эвэйзингам/хореографии, чтобы анимация выглядела продуманной, а не прикрученной. Получает компоненты в гибридном режиме: Magic MCP от 21st.dev при подключении, открытые реестры shadcn (Cult UI, Watermelon UI, Skiper UI) дальше, встроенные рецепты в остальных случаях. Два режима управления: подтверждать каждый шаг (по умолчанию) и --auto (опциональный сквозной). Действия: animate, add motion, add framer motion, add gsap, add anime.js, add three.js, add lenis, smooth scroll, scroll animation, 3D scene, WebGL, icon morph, make it professional, polish UI, design landing page, build animated components, motion‑ui. Триггеры: «add animations», «install framer motion», «install gsap», «use anime.js», «add three.js / a 3D scene», «smooth scrolling», «scroll‑triggered animation», «morph this icon», «make this look professional», «animate this», «use 21st.dev», «--auto».
