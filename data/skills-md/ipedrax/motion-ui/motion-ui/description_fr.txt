Quatre moteurs : Framer Motion (le package `motion`, animation déclarative React), GSAP (timelines + ScrollTrigger, tous frameworks), anime.js v4 (léger, tous frameworks) et Three.js (3D/WebGL, `@react-three/fiber` sous React) ; ainsi que Lenis pour le défilement fluide et morphicons pour les transitions d'icône à icône. Détecte la pile technologique + le gestionnaire de paquets et sélectionne un moteur utilisable avant l'installation — GSAP/anime.js/Three.js/Lenis/morphicons fonctionnent sous React, Next, Vite, Vue, Svelte, Astro ou en vanilla ; Framer Motion est uniquement pour React. Intègre une référence de timing/easing/chorégraphie afin que le mouvement paraisse conçu plutôt qu'ajouté artificiellement. Source les composants en mode hybride : Magic MCP de 21st.dev lorsqu'il est connecté, puis les registres ouverts shadcn (Cult UI, Watermelon UI, Skiper UI), sinon les recettes intégrées. Deux modes de contrôle : confirm-each-step (par défaut) et --auto (opt-in de bout en bout).
