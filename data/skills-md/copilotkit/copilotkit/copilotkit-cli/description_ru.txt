Используйте для CLI CopilotKit — `npx copilotkit@latest`. Охватывает проверку связности проекта с помощью «verify» перед отладкой чего-либо вручную, создание шаблонов с помощью «create», вход в систему и выбор размещенного проекта Intelligence, адаптацию существующего приложения с помощью агента, генерацию типобезопасных идентификаторов агентов и импорт истории потоков. Если приложение CopilotKit не работает, сначала используйте команду «Проверить».
