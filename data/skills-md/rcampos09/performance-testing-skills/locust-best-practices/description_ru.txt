Помогает разработчикам и тестировщикам писать, исправлять и структурировать сценарии нагрузочных тестов Locust на Python. Используйте этот навык всякий раз, когда пользователь упоминает Locust, locustfile, HttpUser, TaskSet, нагрузочное тестирование с помощью Python, виртуальных пользователей, скорость появления, wait_time, catch_response, LoadTestShape, этапы наращивания или хочет протестировать API или сервис с помощью Locust — даже если он явно не говорит «Locust» или «нагрузочный тест».
