Guía a los desarrolladores y evaluadores en la escritura, corrección y estructuración de scripts de prueba de carga de Locust en Python. Utilice esta habilidad siempre que el usuario mencione Locust, locustfile, HttpUser, TaskSet, pruebas de carga con Python, usuarios virtuales, tasa de generación, tiempo de espera, catch_response, LoadTestShape, etapas de aceleración o quiera comparar una API o servicio usando Locust, incluso si no dice explícitamente "Locust" o "prueba de carga".
