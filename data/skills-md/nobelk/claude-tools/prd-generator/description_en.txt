Reverse-engineer a codebase into a formal Product Requirements Document (PRD) structured for Jira work item creation. Use when the user wants to analyze an existing codebase to document all features, identify missing functionality, catalog bugs and technical debt, generate epics/stories/tasks for Jira, or create formal product documentation from source code. Triggers on requests containing "generate PRD", "analyze codebase", "document requirements", "reverse-engineer features", "prepare Jira epics from code", "what does this software do", or "create product requirements".
