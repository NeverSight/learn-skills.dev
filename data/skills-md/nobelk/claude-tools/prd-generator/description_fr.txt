Ingénierie inverse d’une base de code en un Document de Spécifications Produit (PRD) formel structuré pour la création d’éléments de travail Jira. À utiliser lorsque l’utilisateur souhaite analyser une base de code existante afin de documenter toutes les fonctionnalités, identifier les fonctions manquantes, répertorier les bogues et la dette technique, générer des épopées/histoires/tâches pour Jira, ou créer une documentation produit formelle à partir du code source. Se déclenche sur les requêtes contenant « generate PRD », « analyze codebase », « document requirements », « reverse-engineer features », « prepare Jira epics from code », « what does this software do » ou « create product requirements ».

Veuillez toujours répondre dans la langue de l’utilisateur.
