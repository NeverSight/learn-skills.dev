Usa quando il server awwwards MCP o le sue funzioni vengono invocati per la prima volta in una sessione o su una nuova macchina — quando non esistono ancora preferenze awwwards, o l'utente chiede di impostare, configurare o modificare le impostazioni awwwards-mcp (densità dei risultati, viewport, catture live, indice locale, monitoraggio dei vincitori). L'onboarding iniziale pone all'utente una breve serie di domande sulle preferenze, le salva in ~/.awwwards-mcp/preferences.json ed esegue eventuali installazioni una tantum a cui l'utente sceglie di aderire.
