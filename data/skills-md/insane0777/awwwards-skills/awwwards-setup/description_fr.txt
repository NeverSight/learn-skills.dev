À utiliser lorsque le serveur MCP awwwards ou ses compétences sont invoqués pour la première fois dans une session ou sur une nouvelle machine — lorsqu'il n'existe pas encore de préférences awwwards, ou lorsque l'utilisateur demande de configurer ou de modifier les paramètres awwwards-mcp (densité des résultats, fenêtre d'affichage, captures en direct, index local, montres gagnantes). La première intégration pose à l'utilisateur un court ensemble de questions sur les préférences, les persiste dans ~/.awwwards-mcp/preferences.json et exécute toutes les installations ponctuelles auxquelles il choisit de participer.
