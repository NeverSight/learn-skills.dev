Используйте при воссоздании или перестройке многосекционной страницы с референсного сайта — стройте секцию за секцией, а не всю сразу. Обучает карте цикла (analyze_page_structure → capture_component по секции → build → section gate из захваченной геометрии и скриншотов → lock → next), правилам резервного выбора селекторов, полученным из реальных захватов, когда страницу нужно рассматривать как единое целое (общий WebGL‑canvas), и дисциплине «lock‑before‑next», предотвращающей накопление дрейфа. Сочетается с awwwards-motion-study (рецепт анимации по секции) и verify_build (агрегированные доказательства, а не оценка по секциям).
