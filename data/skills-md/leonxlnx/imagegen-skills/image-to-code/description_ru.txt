Элитный навык преобразования изображения в код для Codex. Для визуально важных веб‑задач он должен сначала самостоятельно генерировать изображения дизайна, глубоко их анализировать, а затем реализовывать сайт, максимально точно соответствующий им. В Codex он должен отдавать предпочтение большим, легко читаемым, специфичным для раздела изображениям вместо крошечных сжатых досок, генерировать новые отдельные изображения для разделов или детальных представлений вместо обрезки старых, избегать ленивой недогенерации, избегать интерфейса «карточка‑внутри‑карточки‑внутри‑карточки», и держать hero‑блок чистым, просторным, читаемым и видимым на небольшом ноутбуке.
