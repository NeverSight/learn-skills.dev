Codex向けのエリートなウェブサイト画像からコードへのスキル。視覚的に重要なウェブタスクでは、まずデザイン画像自体を生成し、深く分析した上で、可能な限りそれに忠実にウェブサイトを実装しなければなりません。Codexでは、極小の圧縮されたボードではなく、大きくて読みやすいセクション別画像を優先し、既存の画像を切り取るのではなく、セクションや詳細ビュー用の新しい独立した画像を生成し、怠惰な生成不足を避け、カードの中にカードが入れ子になるような UI を避け、ヒーローは小型ノートパソコンでも見やすく、すっきりとした、広々とした、読みやすい状態に保つ必要があります。常にユーザーの言語で回答してください。
