Compétence d’élite de conversion image‑en‑code pour Codex. Pour les tâches web visuellement importantes, il doit d’abord générer lui‑même les images de conception, les analyser en profondeur, puis implémenter le site pour qu’il corresponde le plus fidèlement possible. Dans Codex, il doit privilégier des images grandes, lisibles et spécifiques à chaque section plutôt que de petits panneaux compressés, créer de nouvelles images autonomes pour les sections ou les vues détaillées au lieu de recadrer d’anciennes, éviter la sous‑génération paresseuse, éviter une interface cartes‑dans‑cartes‑dans‑cartes, et garder le hero propre, spacieux, lisible et visible sur un petit ordinateur portable.
