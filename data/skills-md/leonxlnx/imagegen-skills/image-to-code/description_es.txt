Habilidad élite de imagen a código para sitios web en Codex. Para tareas web visualmente importantes, debe primero generar la(s) imagen(es) de diseño por sí mismo, analizarlas a fondo y luego implementar el sitio web para que coincida lo más posible. En Codex, debe preferir imágenes grandes, legibles y específicas de cada sección en lugar de tableros diminutos y comprimidos, generar imágenes nuevas e independientes para secciones o vistas de detalle en lugar de recortar las antiguas, evitar una generación perezosa insuficiente, evitar una interfaz de tarjetas dentro de tarjetas dentro de tarjetas, y mantener el hero limpio, espacioso, legible y visible en una laptop pequeña. Por favor, siempre responde en el idioma del usuario.
