Abilità d'élite nella direzione delle immagini per il frontend per generare riferimenti di design web premium, orientati alla conversione. REGOLE DI OUTPUT CRITICHE — genera UN'immagine orizzontale separata PER OGNI sezione. Una landing page con 8 sezioni produce 8 immagini. Non comprimere mai più sezioni in un'unica immagine. Garantisce varietà nella composizione (non sempre testo a sinistra / immagine a destra), libertà nell'uso di immagini di sfondo, CTA variegate, scala dei hero variabile (gigante / media / mini minimalista), spina narrativa del concetto, momenti di seconda lettura e una palette unica e coerente per tutte le immagini. Ottimizzato per landing page, siti di marketing e composizioni di prodotto che sviluppatori o modelli di codifica possano ricreare accuratamente. Per favore rispondi sempre nella lingua dell'utente.
