Элитный навык генерации изображений мобильных приложений для создания премиальных, нативных концепций экранов и потоков. Предназначен для iOS, Android и кроссплатформенных мобильных продуктов. Приоритет отдается чистой иерархии, удобочитаемому тексту, сильной согласованности между экранами, контролируемым цветовым палитрам, нетипичному креативному направлению, текстурированным поверхностям, композиции, ориентированной на изображения, вкусной пользовательской иконографии и чистой рамке макета телефона. По умолчанию экраны должны отображаться внутри тонкого премиального макета iPhone или аналогичного телефона с видимой рамкой, при этом основной акцент остаётся на содержимом самого приложения. Этот навык генерирует только изображения. Он не пишет код.
