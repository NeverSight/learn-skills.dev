Créez des projets Arduino et embarqués complets via l’IDE Arduino, l’interface en ligne de commande Arduino CLI, PlatformIO et les chaînes d’outils spécifiques aux fournisseurs. Utilisez‑le lorsque les utilisateurs demandent une application combinant firmware, capteurs, actionneurs, réseau, alimentation ou déploiement plutôt qu’un extrait de code. Le squelette fourni cible les cartes UNO, ESP32 et Raspberry Pi Pico ; utilisez le profil de carte et documentez les limitations pour les autres cibles.
