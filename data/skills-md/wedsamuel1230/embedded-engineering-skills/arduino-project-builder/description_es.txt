Construye proyectos completos de Arduino y sistemas embebidos utilizando Arduino IDE, Arduino CLI, PlatformIO y toolchains específicos de proveedores. Úsalo cuando los usuarios soliciten una aplicación que combine firmware, sensores, actuadores, redes, energía o despliegue, en lugar de un fragmento de código. El esqueleto incluido está dirigido a UNO, ESP32 y Raspberry Pi Pico; emplea el perfil de placa y documenta las limitaciones para otros objetivos.
