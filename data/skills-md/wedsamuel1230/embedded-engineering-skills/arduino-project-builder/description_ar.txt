قم بإنشاء مشاريع Arduino ومشروعات مضمنة كاملة عبر Arduino IDE وArduino CLI وPlatformIO وسلاسل الأدوات الخاصة بالمورد. استخدمه عندما يطلب المستخدمون تطبيقًا يجمع بين البرامج الثابتة، والمستشعرات، والمحركات، والشبكات، والطاقة، أو النشر بدلاً من مقتطف شفرة. الهيكل المدمج يستهدف UNO وESP32 وRaspberry Pi Pico؛ استخدم ملف تعريف اللوحة ووثّق القيود للأنواع الأخرى.
