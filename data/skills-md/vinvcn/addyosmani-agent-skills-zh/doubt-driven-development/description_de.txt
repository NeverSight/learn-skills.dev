Bevor irgendeine nicht triviale Entscheidung getroffen wird, führen Sie eine gegnerische Überprüfung mit einem völlig neuen Kontext durch. Nutzen Sie dies, wenn Sie jede Annahme vor dem Fortfahren kritisch prüfen möchten, den Plan stark belasten wollen, um verborgene Fehlermodi aufzudecken, Korrektheit über Geschwindigkeit priorisieren, unbekannten Code behandeln, mit Hochrisikosituationen (Produktionsauthentifizierung, sicherheitskritische Logik, risikoreiche Migrationen, irreversible Vorgänge) umgehen wollen oder wann immer Sie sicher sind, dass die Validierung des Outputs jetzt günstiger ist als späteres Debuggen.
