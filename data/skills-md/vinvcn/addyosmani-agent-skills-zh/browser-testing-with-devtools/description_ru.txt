Тестировать в реальном браузере. Используйте при разработке или отладке любого кода, работающего в браузере. Применяйте, когда нужно проверять DOM через Chrome DevTools MCP, фиксировать ошибки консоли, анализировать сетевые запросы, оценивать производительность или проверять визуальный вывод с реальными данными выполнения. Требуется настроенный сервер Chrome DevTools MCP.
