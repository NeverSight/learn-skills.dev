Prueba en un navegador real. Úsalo cuando estés construyendo o depurando cualquier cosa que se ejecute en un navegador. Utilízalo cuando necesites inspeccionar el DOM, capturar errores de consola, analizar solicitudes de red, analizar el rendimiento o validar la salida visual con datos de tiempo de ejecución reales a través de Chrome DevTools MCP. Requiere un servidor MCP de chrome-devtools configurado.
