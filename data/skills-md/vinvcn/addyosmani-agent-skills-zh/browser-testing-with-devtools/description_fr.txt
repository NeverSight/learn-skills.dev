Testez dans un vrai navigateur. Utilisez-le lors de la création ou du débogage de tout ce qui s'exécute dans le navigateur. Utilisez-le lorsque vous devez inspecter le DOM via Chrome DevTools MCP, capturer les erreurs de console, analyser les requêtes réseau, analyser les performances ou valider la sortie visuelle avec des données d'exécution réelles. Nécessite un serveur MCP chrome‑devtools configuré.
