Gestire la deprecazione e la migrazione. Utilizzato quando si rimuovono sistemi, API o funzionalità obsolete; quando si migrano gli utenti da un'implementazione all'altra; quando si migra uno schema di database in produzione (ad esempio, rinominando o eliminando colonne senza tempi di inattività, ovvero espansione/contrazione); e quando si decide se mantenere o ritirare il codice esistente.
