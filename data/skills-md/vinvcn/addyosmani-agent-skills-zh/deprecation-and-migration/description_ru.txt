Управляйте устареванием и миграцией. Используйте это при удалении старых систем, API или функций; при переводе пользователей с одной реализации на другую; при миграции схем баз данных в продакшене (например, переименовании или удалении столбцов без простоя, т.е. расширении/сжатии); и при принятии решения о том, поддерживать ли существующий код или вывести его из эксплуатации.
