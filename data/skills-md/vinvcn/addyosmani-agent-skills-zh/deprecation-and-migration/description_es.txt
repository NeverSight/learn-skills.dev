Gestionar la deprecación y la migración. Se usa al eliminar sistemas, APIs o funcionalidades antiguas; se usa al migrar usuarios de una implementación a otra; se usa al migrar esquemas de bases de datos en producción (p. ej., renombrar o eliminar columnas sin tiempo de inactividad, es decir, expandir/contraer); se usa para decidir si mantener o retirar el código existente.
