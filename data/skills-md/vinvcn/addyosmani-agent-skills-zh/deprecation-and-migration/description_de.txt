Verwalten von Veralterungen und Migrationen. Wird eingesetzt, wenn alte Systeme, APIs oder Funktionen entfernt werden; wenn Nutzer von einer Implementierung zur anderen migriert werden; beim Migrieren von Datenbankschemata in der Produktion (z. B. Umbenennen oder Entfernen von Spalten ohne Ausfallzeit, also Expand/Contract); und um zu entscheiden, ob bestehender Code beibehalten oder ausgemustert werden soll.
