Hardening code against vulnerabilities. Used to audit whether a particular input‑handling function has flaws when processing user input, authentication, data storage, or external integration, or to check whether the login flow is secure and complies with the OWASP Top Ten. Used when building any functionality that accepts untrusted data, manages user sessions, or interacts with third‑party services. Used to audit known vulnerabilities in dependencies, the audit results of package managers, or to assess supply‑chain risk of new packages. Also used when personal data or privacy compliance (GDPR, CCPA) is involved.
