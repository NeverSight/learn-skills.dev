Fortalezca el código para prevenir vulnerabilidades. Úselo para auditar si una función específica de manejo de entradas tiene fallas al procesar la entrada del usuario, la autenticación, el almacenamiento de datos o la integración externa, o para comprobar si el flujo de inicio de sesión es seguro y cumple con el OWASP Top Ten. Úselo al desarrollar cualquier funcionalidad que acepte datos no confiables, gestione sesiones de usuarios o interactúe con servicios de terceros. Úselo para auditar vulnerabilidades conocidas en dependencias, los resultados de auditoría de los gestores de paquetes o para evaluar el riesgo de la cadena de suministro de nuevos paquetes. También se utiliza cuando están involucrados datos personales o cumplimiento de privacidad (GDPR, CCPA).
