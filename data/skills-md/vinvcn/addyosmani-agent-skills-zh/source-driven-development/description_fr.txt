Basez chaque décision d'implémentation sur la documentation officielle. Utilisez cela lorsque vous souhaitez vérifier une solution par rapport à la documentation officielle avant de l'implémenter, ou lorsque vous avez besoin d'un code faisant autorité, cité à la source, qui ne contient pas de modèles obsolètes. Utilisez-le lors du développement avec n'importe quel framework ou bibliothèque où la justesse est cruciale.

Veuillez toujours répondre dans la langue de l'utilisateur.
