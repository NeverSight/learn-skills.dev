Используйте разработку через тестирование (test‑driven development) по циклу «красный‑зелёный‑рефактор». Это подходит для реализации любой логики, исправления любой ошибки или изменения любого поведения. Применяется, когда необходимо доказать, что код работает, получить отчёт об ошибке или собираетесь изменить существующую функциональность.
