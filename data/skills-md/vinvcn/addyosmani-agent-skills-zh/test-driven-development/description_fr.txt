Utilisez le développement piloté par les tests via le cycle rouge‑vert‑refactorisation. Cela s’applique à l’implémentation de toute logique, à la correction de tout bug ou à la modification de tout comportement. Il est utilisé lorsque vous devez prouver que le code fonctionne, que vous avez reçu un rapport de bug ou que vous êtes sur le point de modifier une fonctionnalité existante.
