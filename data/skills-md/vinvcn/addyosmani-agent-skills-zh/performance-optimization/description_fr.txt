Optimisez les performances du front‑end, du back‑end, des requêtes et de la base de données d’une application. Utilisez cela lorsqu’il existe des exigences de performance, des régressions de performance suspectées, le besoin d’améliorer les Core Web Vitals ou les temps de chargement, le besoin de corriger les motifs de requêtes N+1, ou lorsque le profilage révèle des goulets d’étranglement.
