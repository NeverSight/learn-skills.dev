Ottimizza le prestazioni del front‑end, del back‑end, delle query e del database di un’applicazione. Usalo quando ci sono requisiti di performance, sospette regressioni di prestazioni, i Core Web Vitals o i tempi di caricamento hanno bisogno di miglioramento, i pattern di query N+1 devono essere corretti o il profiling rivela colli di bottiglia.
