Vorbereitung für ein Produktions‑Release. Wird verwendet, wenn die Bereitstellung in die Produktionsumgebung vorbereitet wird oder wenn nachgefragt wird, was vor einem Release bereit sein muss; wird auch benutzt, wenn eine Vor‑Release‑Checkliste, ein Monitoring‑Setup, die Planung einer gestaffelten Ausrollung oder eine Rollback‑Strategie erforderlich sind.
