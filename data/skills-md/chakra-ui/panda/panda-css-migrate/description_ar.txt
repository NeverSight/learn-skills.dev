قم بترقية مشروع Panda CSS من الإصدار v1 إلى v2، أو تصحيح مشروع كان يعمل على 1.x ويتعطل على 2.x. استخدم ذلك عند ترقية @pandacss/dev إلى v2، عندما يفشل البناء بعد الترقية، عندما تتوقف وصلات الإعداد (config hooks)، أو createStyleContext، أو أنماط القالب الحرفي، أو panda ship، أو panda mcp، أو --cpu-prof عن العمل، أو عندما يتغيّر ناتج CSS بعد الترقية. لا تُستخدم لهذا الغرض لكتابة الأنماط (استعمل panda‑css)، أو لتصميم الرموز والوصفات (استعمل panda‑css‑theming)، أو للترحيل من Tailwind، Emotion، أو styled‑components.
