Aggiorna un progetto Panda CSS da v1 a v2, o risolvi i problemi di un progetto che funzionava su 1.x e si rompe su 2.x. Usa quando aggiorni @pandacss/dev a v2, quando una build fallisce dopo l'aggiornamento, quando i config hooks, createStyleContext, gli stili con template literal, panda ship, panda mcp o --cpu-prof smettono di funzionare, o quando l'output CSS cambia dopo l'aggiornamento. Non usarlo per scrivere stili (usa panda-css), progettare token e ricette (usa panda-css-theming), o migrare da Tailwind, Emotion o styled-components.
