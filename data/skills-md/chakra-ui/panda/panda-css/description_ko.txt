Panda CSS를 사용하는 프로젝트에서 스타일을 작성하고 편집합니다. css (), cva (), sva (), 패턴, 레시피, 토큰, 조건 또는 JSX 스타일 소품을 호출하는 코드를 생성, 변경 또는 검토할 때, 스타일이 클래스 이름을 렌더링하지만 CSS가 없는 경우 또는 스타일이 전혀 적용되지 않는 경우 사용합니다. Panda v2 (2.x) 및 v1 (1.x) 에 적용됩니다. 테마를 디자인하거나 무언가가 레시피 또는 슬롯 레시피가 되는 시기를 결정하는 데 (panda-css-theming 사용) 또는 v1을 v2로 업그레이드하는 데 (panda-css-migrate 사용) 사용하지 마십시오.
