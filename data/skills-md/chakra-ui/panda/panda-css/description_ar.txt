اكتب وحرّر الأنماط في مشروع يستخدم Panda CSS. استخدمه عند إنشاء أو تعديل أو مراجعة الكود الذي يستدعي css()، cva()، sva()، الأنماط، الوصفات، الرموز، الشروط، أو خصائص نمط JSX، عندما يُظهر النمط اسم فئة دون وجود CSS، أو عندما لا تُطبق الأنماط على الإطلاق. يغطي Panda v2 (2.x) وv1 (1.x). لا تستخدمه لتصميم السمة أو لتحديد متى يصبح شيء ما وصفة أو وصفة فتحة (استخدم panda‑css‑theming)، أو لترقية v1 إلى v2 (استخدم panda‑css‑migrate).
