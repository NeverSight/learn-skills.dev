Escribir y editar estilos en un proyecto que utilice Panda CSS. Utilícelo al crear, cambiar o revisar código que llame a css(), cva(), sva(), patrones, recetas, tokens, condiciones o accesorios de estilo JSX, cuando un estilo representa un nombre de clase pero no CSS, o cuando los estilos no se aplican en absoluto. Cubre Panda v2 (2.x) y v1 (1.x). No lo use para diseñar el tema o decidir cuándo algo se convierte en una receta o receta de ranura (use panda-css-theming), o para actualizar v1 a v2 (use panda-css-migrate).
