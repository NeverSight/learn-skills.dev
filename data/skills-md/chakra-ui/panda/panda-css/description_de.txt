Schreiben und bearbeiten Sie Stile in einem Projekt, das Panda CSS verwendet. Verwenden Sie diese Option, wenn Sie Code erstellen, ändern oder überprüfen, der css(), cva (), sva(), Muster, Rezepte, Token, Bedingungen oder JSX-Stil-Requisiten aufruft, wenn ein Stil einen Klassennamen, aber kein CSS wiedergibt oder wenn Stile überhaupt nicht zutreffen. Deckt Panda v2 (2.x) und v1 (1.x) ab. Verwenden Sie es nicht, um das Theme zu entwerfen oder zu entscheiden, wann etwas zu einem Rezept oder Slot-Rezept wird (verwenden Sie panda-css-theming) oder um v1 auf v2 zu aktualisieren (verwenden Sie panda-css-migrate).
