設計 Panda CSS 專案的主題與元件樣式架構。於以下情況使用：設定主題、加入品牌色、配置暗色模式或色彩模式切換、透過 theme.themes、staticCss.themes、data-panda-theme 或 injectTheme 發佈多個主題、命名或重構設計 token、判斷哪些應放在 tokens、semanticTokens、textStyles 或 recipe 中、設計元件的 variant API，或決定某項應使用 css() 呼叫、cva、config recipe 或 slot recipe，亦包括將 recipe 轉換為 slot recipe。也可於 token 或 recipe 變得雜亂且需要清理計畫時使用。不要用於對已存在系統撰寫樣式（請使用 panda‑css），或升級 v1 到 v2（請使用 panda‑css‑migrate）。
