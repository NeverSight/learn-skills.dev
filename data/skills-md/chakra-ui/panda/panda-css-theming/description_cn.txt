设计 Panda CSS 项目的主题和组件样式架构。用于设置主题、添加品牌颜色、接入暗模式或颜色模式切换、通过 theme.themes、staticCss.themes、data-panda-theme 或 injectTheme 发布多个主题、命名或重构设计令牌、决定哪些应放在 tokens、semanticTokens、textStyles 或 recipe 中、设计组件的 variant API，或决定某个东西应使用 css() 调用、cva、config recipe 或 slot recipe，包括将 recipe 转换为 slot recipe。也可用于 token 或 recipe 变得混乱需要清理计划的情况。不要用于对已有系统编写样式（使用 panda-css），也不要用于从 v1 升级到 v2（使用 panda-css-migrate）。
