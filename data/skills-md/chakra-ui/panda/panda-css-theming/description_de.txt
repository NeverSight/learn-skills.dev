Entwerfen Sie das Theme und die komponentenbasierte Architektur eines Panda‑CSS‑Projekts. Verwenden Sie es, wenn Sie das Theming einrichten, Markenfarben hinzufügen, Dark‑Mode oder einen Color‑Mode‑Umschalter einbinden, mehr als ein Theme mit theme.themes, staticCss.themes, data-panda-theme oder injectTheme ausliefern, Design‑Tokens benennen oder neu strukturieren, entscheiden, was in tokens gegenüber semanticTokens, textStyles oder einem recipe gehört, die Varianten‑API einer Komponente entwerfen oder festlegen, ob etwas ein css()‑Aufruf, ein cva, ein config‑recipe oder ein slot‑recipe sein soll, inklusive der Umwandlung eines recipe in ein slot‑recipe. Nutzen Sie es auch, wenn Tokens oder Recipes unübersichtlich geworden sind und einen Aufräum‑Plan benötigen. Nicht verwenden zum Schreiben von Styles gegen ein bereits bestehendes System (verwenden Sie panda-css) oder zum Upgrade von v1 auf v2 (verwenden Sie panda-css-migrate).
