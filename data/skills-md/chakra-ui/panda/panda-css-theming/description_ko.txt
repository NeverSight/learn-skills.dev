Panda CSS 프로젝트의 테마와 컴포넌트 스타일 아키텍처를 설계합니다. 테마 설정, 브랜드 색상 추가, 다크 모드 또는 컬러‑모드 토글 연결, theme.themes, staticCss.themes, data‑panda‑theme 또는 injectTheme을 사용해 여러 테마를 제공, 디자인 토큰의 명명이나 재구성, 토큰 vs semanticTokens vs textStyles vs 레시피에 무엇을 넣을지 결정, 컴포넌트의 variant API 설계, 혹은 어떤 것이 css() 호출, cva, config recipe, slot recipe가 될지 결정(레시피를 slot recipe로 변환 포함)할 때 사용합니다. 또한 토큰이나 레시피가 난잡해져 정리 계획이 필요할 때도 사용합니다. 이미 존재하는 시스템에 스타일을 작성할 때는 사용하지 마세요(panda‑css 사용) 또는 v1에서 v2로 업그레이드할 때는 사용하지 마세요(panda‑css‑migrate 사용).
