Diseña el tema y la arquitectura de estilos de componentes de un proyecto Panda CSS. Utilízalo al configurar la tematización, agregar colores de marca, implementar el modo oscuro o un interruptor de modo de color, lanzar más de un tema con theme.themes, staticCss.themes, data-panda-theme o injectTheme, nombrar o reestructurar tokens de diseño, decidir qué pertenece a tokens vs semanticTokens vs textStyles vs una receta, diseñar la API de variantes de un componente, o decidir si algo debe ser una llamada a css(), un cva, una receta de configuración o una receta de ranura, incluida la conversión de una receta en una receta de ranura. También úsalo cuando los tokens o las recetas se han vuelto desordenados y necesitan un plan de limpieza. No lo uses para escribir estilos contra un sistema que ya existe (usa panda‑css), ni para actualizar de v1 a v2 (usa panda‑css‑migrate). Por favor, responde siempre en el idioma del usuario.
