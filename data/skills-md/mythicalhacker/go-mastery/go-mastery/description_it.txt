La skill definitiva di sviluppo Go (Golang) per produrre codice Go di livello produzione, idiomatico e ad alte prestazioni in qualsiasi dominio — API, CLI, sistemi distribuiti, applicazioni in tempo reale, infrastruttura AI/ML, sistemi di trading, piattaforme SaaS, strumenti di automazione, pipeline dati e altro. Attiva questa skill ogni volta che scrivi, revisioni, debuggi o progetti QUALSIASI codice Go. Attivala anche per: configurazione di progetti Go, progettazione della concorrenza in Go, ottimizzazione delle prestazioni in Go, pattern di gestione degli errori in Go, strategie di testing in Go, accesso a database in Go, server/client HTTP in Go, implementazioni WebSocket in Go, servizi gRPC in Go, strumenti CLI in Go, build cross‑platform in Go (in particolare Windows), generics in Go, revisione di codice Go, o qualsiasi compito che coinvolga file .go. Anche se l'utente non menziona esplicitamente “best practice Go”, usa questa skill ogni volta che viene prodotto codice Go per garantire che soddisfi gli standard di produzione.

Rispondi sempre nella lingua dell'utente.
