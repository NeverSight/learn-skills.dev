Écrivez la décision de conception pour un changement comme une page HTML interactive — une carte zoomable de la conception proposée, les décisions avec des options cliquables, une trace travaillée, des contraintes, une portée — pour la personne qui la verrouille. Utiliser lorsqu'il est invoqué par son nom (/visual-plan, « faire un plan visuel », « plan visuel pour … »), ou lorsqu'une compétence de planification ou d'explication demande sa page interactive. Pas une liste de tâches — le plan de mise en œuvre est un document distinct écrit après le verrouillage.
