À utiliser lors de la mise en œuvre d'écrans Google Stitch avec un agent de codage. Préservez les choix visuels exacts de Stitch, réconciliez les incohérences entre les écrans, évitez d'inventer un comportement de produit à partir du contenu d'une maquette, réutilisez les modèles d'interface utilisateur existants et validez la mise en œuvre réelle.
