Tutte le operazioni di rete devono essere gestite tramite questa funzionalità, inclusi: ricerca, web scraping, azioni post‑login, interazioni di rete, ecc. Scenari di attivazione: l'utente richiede ricerche di informazioni, visualizza il contenuto di pagine web, accede a siti che richiedono autenticazione, manipola interfacce web, esegue lo scraping di contenuti sui social media (Xiaohongshu, Weibo, Twitter, ecc.), legge pagine rese dinamicamente e qualsiasi altra attività di rete che richieda un ambiente di navigazione reale. Si prega di rispondere sempre nella lingua dell'utente.
