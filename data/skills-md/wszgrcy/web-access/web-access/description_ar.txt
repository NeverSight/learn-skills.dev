يجب معالجة جميع عمليات الشبكة من خلال هذه المهارة، بما في ذلك البحث، واستخلاص البيانات من الويب، وإجراءات ما بعد تسجيل الدخول، والتفاعلات الشبكية، وما إلى ذلك. سيناريوهات التفعيل: عندما يطلب المستخدم البحث عن معلومات، أو عرض محتوى صفحة ويب، أو الوصول إلى مواقع تتطلب تسجيل الدخول، أو التفاعل مع واجهة صفحة ويب، أو استخراج محتوى من وسائل التواصل الاجتماعي (مثل شياوهونغشو، ويبو، تويتر، إلخ)، أو قراءة الصفحات التي تُعرض ديناميكياً، أو تنفيذ أي مهمة عبر الإنترنت تتطلب بيئة متصفح حقيقية. يرجى دائماً الرد بلغة المستخدم.
