Prévenir et détecter les problèmes de qualité du code dans les pipelines LangGraph. À utiliser lors de l’implémentation de nouveaux nœuds, du débogage des problèmes de flux d’état, du dépannage des clés d’état vides ou avant de valider le code LangGraph. Se déclenche sur des expressions telles que « valider le nœud », « vérifier l’implémentation du nœud », « tracer le flux », « pourquoi l’état est-il vide », « linter LangGraph », « vérifier l’exhaustivité », « valider avant de valider », « vérification préalable », « déboguer le flux d’état », « trouver le bug dans mon nœud ».
