Set up and run Bugpatrol, a QA team of AI agents that explores a web, Electron, iOS, or Android app, finds bugs, fixes them, and opens GitHub PRs and issues. Use this skill when the user wants to add Bugpatrol to a repo, write or fix .bugpatrol/bugpatrol.yml, run an explore, judge, fix, or patrol cycle, or look at the bugs that Bugpatrol found.
