Convert information-dense content into structured, readable, self-contained HTML—research reports, comparison matrices, checklists, data dashboards, decision pages. Trigger when the Agent needs to output large blocks of information, comparisons, metrics, timelines, or when the user says “make it a webpage/visual report/HTML report”. The product is a single .html file that can be opened with a double‑click. For formal PDF/resume/PPT/landing‑page delivery, use kami; for video/animation, use hyperframes; deployment is outside the scope of this skill.
