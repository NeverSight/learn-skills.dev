Converti contenuti ricchi di informazioni in HTML strutturato, leggibile e autonomo — rapporti di ricerca, matrici comparative, checklist, dashboard di dati, pagine decisionali. Attiva quando l'Agente deve fornire blocchi grandi di informazioni, confronti, metriche, linee temporali, o quando l'utente dice “rendilo una pagina web/rapporto visuale/rapporto HTML”. Il prodotto è un singolo file .html che può essere aperto con un doppio clic. Per la consegna formale di PDF/curriculum/PPT/landing‑page, usa kami; per video/animazione, usa hyperframes; il deployment è fuori dall’ambito di questa competenza.

Rispondi sempre nella lingua dell'utente.
