Konvertiere informationsreiche Inhalte in strukturiertes, lesbares, eigenständiges HTML — Forschungsberichte, Vergleichsmatrizen, Checklisten, Daten‑Dashboards, Entscheidungsseiten. Auslösen, wenn der Agent große Informationsblöcke, Vergleiche, Kennzahlen, Zeitpläne ausgeben muss oder wenn der Benutzer sagt: „mach daraus eine Webseite/visuellen Bericht/HTML‑Report“. Das Ergebnis ist eine einzelne .html‑Datei, die per Doppelklick geöffnet werden kann. Für formelle PDF/Resume/PPT/Landing‑Page‑Auslieferungen verwende kami; für Video/Animation verwende hyperframes; die Bereitstellung liegt außerhalb des Umfangs dieser Fähigkeit.

Bitte immer in der Sprache des Benutzers antworten.
