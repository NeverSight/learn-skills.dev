Obtenga el contenido principal de la URL de un solo artículo o de una página de índice/archivo de un artículo y guárdelo localmente como Markdown. Cuando el usuario menciona "marcar artículo", "guardar página web", "obtener artículos por lotes de una página", "extraer los primeros N elementos de esta página de archivo" o "guardar en Obsidian/Recortes/localmente", este método debe usarse como prioridad. Es especialmente adecuado para páginas web públicas, Substack, páginas de artículos de blogs y páginas de archivo de artículos. Si encuentra listas cargadas de forma diferida, páginas dinámicas o raspado estático incompleto, primero use un navegador para recopilar las URL de los artículos y luego ejecute un script para descargarlas por lotes, priorizando la tasa de éxito.
