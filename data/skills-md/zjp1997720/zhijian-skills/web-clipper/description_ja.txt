単一の記事 URL または記事インデックス/アーカイブ ページからメイン コンテンツを取得し、Markdown としてローカルに保存します。ユーザーが「記事をブックマークする」、「ウェブページを保存する」、「ページから記事をバッチフェッチする」、「このアーカイブ ページから最初の N 項目をプルダウンする」、または「Obsidian / Clippings / ローカルに保存する」と述べた場合、このメソッドを優先して使用する必要があります。これは、公開 Web ページ、サブスタック、ブログ記事ページ、記事アーカイブ ページに特に適しています。遅延読み込みされたリスト、動的ページ、または不完全な静的スクレイピングが発生した場合は、まずブラウザを使用して記事の URL を収集し、次にスクリプトを実行してそれらを一括ダウンロードし、成功率を優先します。
