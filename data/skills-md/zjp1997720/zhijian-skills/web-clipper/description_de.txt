Rufen Sie den Hauptinhalt von einer einzelnen Artikel-URL oder einer Artikelindex-/Archivseite ab und speichern Sie ihn lokal als Markdown. Wenn der Benutzer „Artikel mit Lesezeichen versehen“, „Webseite speichern“, „Artikel im Stapelbetrieb von einer Seite abrufen“, „Die ersten N Elemente von dieser Archivseite abrufen“ oder „in Obsidian/Clippings/lokal speichern“ erwähnt, muss diese Methode vorrangig verwendet werden. Es eignet sich besonders für öffentliche Webseiten, Substacks, Blog-Artikelseiten und Artikelarchivseiten. Wenn Sie auf verzögert geladene Listen, dynamische Seiten oder unvollständiges statisches Scraping stoßen, erfassen Sie zunächst die Artikel-URLs mit einem Browser und führen Sie dann ein Skript aus, um sie stapelweise herunterzuladen, wobei Sie die Erfolgsquote priorisieren.
