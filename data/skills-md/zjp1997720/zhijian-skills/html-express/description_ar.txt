قم بتحويل المحتوى كثيف المعلومات إلى HTML منظم وقابل للقراءة ومكتفي بذاته - تقارير بحثية ومصفوفات مقارنة وقوائم مرجعية ولوحات معلومات البيانات وصفحات القرار. قم بتشغيل هذا عندما يحتاج الوكيل إلى إخراج مجموعات كبيرة من المعلومات أو المقارنات أو المقاييس أو الجداول الزمنية أو عندما يطلب المستخدم "اجعلها صفحة ويب/تقرير مرئي/تقرير HTML". والنتيجة هي ملف .html واحد يمكن فتحه بالنقر المزدوج. بالنسبة لعمليات التسليم الرسمية بتنسيق PDF/السيرة الذاتية/PPT/الصفحة المقصودة، استخدم Kami؛ بالنسبة للفيديو/الرسوم المتحركة، استخدم الإطارات التشعبية؛ النشر عبر الإنترنت يقع خارج نطاق هذه المهارة.
