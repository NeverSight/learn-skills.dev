Wandeln Sie informationsreiche Inhalte in strukturiertes, lesbares, eigenständiges HTML um – Forschungsberichte, Vergleichsmatrizen, Checklisten, Daten-Dashboards, Entscheidungsseiten. Lösen Sie dies aus, wenn der Agent große Informationsblöcke, Vergleiche, Metriken oder Zeitleisten ausgeben muss oder wenn der Benutzer anfordert, „daraus eine Webseite/einen visuellen Bericht/einen HTML-Bericht zu erstellen“. Das Ergebnis ist eine einzelne .html-Datei, die durch Doppelklick geöffnet werden kann. Für formelle PDF-/Lebenslauf-/PPT-/Landingpage-Übermittlungen verwenden Sie Kami; Verwenden Sie für Videos/Animationen Hyperframes. Die Online-Bereitstellung liegt außerhalb des Umfangs dieser Fertigkeit.
