Преобразуйте насыщенный информацией контент в структурированный, читаемый, автономный HTML — отчеты об исследованиях, матрицы сравнения, контрольные списки, информационные панели данных, страницы решений. Запускайте это, когда агенту необходимо вывести большие блоки информации, сравнения, показатели, сроки или когда пользователь запрашивает «сделать это веб-страницей/визуальным отчетом/отчетом HTML». В результате получается один HTML-файл, который можно открыть двойным щелчком мыши. Для формальной доставки PDF/резюме/PPT/целевых страниц используйте Kami; для видео/анимации используйте Hyperframes; онлайн-развертывание выходит за рамки этого навыка.
