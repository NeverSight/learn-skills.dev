Converti contenuti ricchi di informazioni in HTML strutturato, leggibile e autonomo: rapporti di ricerca, matrici di confronto, liste di controllo, dashboard di dati, pagine decisionali. Attivalo quando l'agente deve generare grandi blocchi di informazioni, confronti, metriche, sequenze temporali o quando l'utente richiede "crealo in una pagina Web/report visivo/report HTML". Il risultato è un singolo file .html che può essere aperto facendo doppio clic. Per consegne formali di PDF/curriculum/PPT/pagina di destinazione, utilizzare Kami; per video/animazioni, utilizzare Hyperframe; la distribuzione online non rientra nell'ambito di questa competenza.
