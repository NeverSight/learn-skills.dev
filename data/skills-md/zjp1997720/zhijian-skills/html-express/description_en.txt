Convert information-dense content into structured, readable, self-contained HTML—research reports, comparison matrices, checklists, data dashboards, decision pages. Trigger this when the Agent needs to output large blocks of information, comparisons, metrics, timelines, or when the user requests “make it a webpage/visual report/HTML report.” The result is a single .html file that can be opened by double‑clicking. For formal PDF/resume/PPT/landing‑page deliveries, use Kami; for video/animation, use Hyperframes; online deployment is outside the scope of this skill.
