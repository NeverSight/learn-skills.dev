Из WorkBuddy, Claude Code или других локальных агентов вызывайте сервер приложений Codex без головы, чтобы создавать видимые, именованные, постоянные потоки Codex, а также выполнять последующие опросы, запросы статуса, получение, отмену и открытие результатов. Это используется для сложных исследований, межпроектного поиска, обзора глав, детерминированного проектирования или принятия важных решений; однократные проверки формата и небольшие извлечения, не требующие сохранения контекста, по-прежнему используют `codex exec --ephemeral`, а внутреннее взаимодействие внутри Кодекса не проходит через этот навык.
