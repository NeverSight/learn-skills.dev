Desde WorkBuddy, Claude Code u otros agentes locales, invoque el servidor de aplicaciones Codex sin cabeza para crear subprocesos Codex visibles, con nombre y persistentes, y realizar preguntas de seguimiento, consultas de estado, recuperación, cancelación y apertura de resultados. Esto se utiliza para investigaciones complejas, abastecimiento entre proyectos, revisión de capítulos, ingeniería determinista o toma de decisiones importantes; Las comprobaciones de formato únicas y las pequeñas extracciones que no requieren preservar el contexto siguen utilizando "codex exec --ephemeral", y el equipo interno dentro del Codex no utiliza esta habilidad.
