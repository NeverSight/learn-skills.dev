Diagnosticar y arreglar un sitio web en el alojamiento web de Hostinger (planes Compartidos, Cloud o Agencia) que esté caído, lento, con errores, inseguro o que falle al compilar. Verifica el sitio desde el exterior, lee builds, registros de tiempo de ejecución, salud de WordPress, SSL, caché y configuraciones PHP a través del MCP de Hostinger, nombra la causa con evidencia y aplica la solución una vez que el usuario esté de acuerdo. Disparadores: mi sitio está caído, el sitio no carga, error 500 / 502 / 503, pantalla blanca, error al establecer una conexión a la base de datos, el sitio es lento, advertencia de SSL o certificado, no seguro, cambios que no se muestran, compilación de Node.js fallida, la aplicación sigue fallando.
