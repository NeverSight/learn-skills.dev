Diagnostiziere und repariere eine Website auf Hostinger-Webhosting (Shared-, Cloud- oder Agency-Pläne), die offline, langsam, fehlerhaft, unsicher ist oder beim Build scheitert. Prüft die Seite von außen, liest Builds, Laufzeitprotokolle, WordPress-Gesundheitsstatus, SSL, Cache und PHP‑Einstellungen über das Hostinger MCP, benennt die Ursache mit Beweisen und wendet die Korrektur an, sobald der Nutzer zustimmt. Auslöser: Meine Seite ist offline, Seite lädt nicht, 500 / 502 / 503‑Fehler, Weißer Bildschirm, Fehler beim Herstellen einer Datenbankverbindung, Seite ist langsam, SSL‑ oder Zertifikatswarnung, nicht sicher, Änderungen werden nicht angezeigt, Node.js‑Build fehlgeschlagen, App stürzt ständig ab.  

Bitte antworte immer in der Sprache des Benutzers.
