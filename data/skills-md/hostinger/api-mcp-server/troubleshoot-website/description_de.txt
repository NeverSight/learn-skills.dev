Diagnostiziere und behebe eine Website beim Hostinger-Webhosting (Shared-, Cloud- oder Agency‑Pläne), die nicht erreichbar, langsam, fehlerhaft, unsicher ist oder beim Build scheitert. Prüft die Seite von außen, liest Build‑ und Laufzeit‑Logs, WordPress‑Gesundheit, SSL, Cache‑ und PHP‑Einstellungen über das Hostinger‑MCP, benennt die Ursache mit Belegen und wendet die Lösung an, sobald der Nutzer zustimmt. Auslöser: Meine Seite ist down, Seite lädt nicht, 500 / 502 / 503‑Fehler, weißer Bildschirm, Fehler beim Herstellen einer Datenbankverbindung, Seite ist langsam, SSL‑ oder Zertifikatswarnung, nicht sicher, Änderungen werden nicht angezeigt, Node.js‑Build fehlgeschlagen, App stürzt ständig ab.
