Hostinger のウェブホスティング（共有、クラウド、またはエージェンシープラン）上で、サイトがダウンしたり、遅くなったり、エラーが出たり、不安定になったり、ビルドに失敗したりした場合に診断・修正します。外部からサイトをチェックし、ビルドやランタイムログ、WordPress のヘルス、SSL、キャッシュ、PHP 設定を Hostinger MCP 経由で確認し、証拠をもとに原因を特定し、ユーザーが同意すれば修正を適用します。トリガー：サイトがダウン、サイトが読み込めない、500／502／503 エラー、白画面、データベース接続エラー、サイトが遅い、SSL または証明書の警告、不安全、変更が反映されない、Node.js ビルド失敗、アプリがクラッシュし続ける。
