Diagnostiquer et réparer un site web hébergé chez Hostinger (plans Shared, Cloud ou Agency) qui est en panne, lent, génère des erreurs, n’est pas sécurisé ou échoue lors de la construction. Vérifie le site depuis l’extérieur, lit les builds, les journaux d’exécution, la santé de WordPress, le SSL, le cache et les paramètres PHP via le MCP de Hostinger, nomme la cause avec des preuves, et applique la correction une fois que l’utilisateur accepte. Déclencheurs : mon site est en panne, le site ne charge pas, erreur 500 / 502 / 503, écran blanc, erreur d’établissement de la connexion à la base de données, site lent, avertissement SSL ou certificat, non sécurisé, changements qui ne s’affichent pas, échec de build Node.js, l’application plante constamment.
