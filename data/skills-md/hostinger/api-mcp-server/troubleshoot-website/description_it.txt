Diagnostica e risolve un sito web su Hostinger (piani Shared, Cloud o Agency) che è offline, lento, presenta errori, è insicuro o non riesce a compilare. Controlla il sito dall’esterno, legge le build, i log di runtime, lo stato di salute di WordPress, SSL, cache e impostazioni PHP tramite l’Hostinger MCP, individua la causa con le prove e applica la correzione una volta che l'utente è d'accordo. Trigger: il mio sito è offline, sito non si carica, errore 500 / 502 / 503, schermo bianco, errore di connessione al database, sito lento, avviso SSL o certificato, non sicuro, modifiche non visualizzate, compilazione Node.js fallita, l’app si blocca continuamente.
