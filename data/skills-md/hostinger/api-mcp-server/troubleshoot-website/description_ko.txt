Hostinger 웹 호스팅(공유, 클라우드 또는 에이전시 플랜)에서 다운되었거나, 느리거나, 오류가 발생했거나, 보안이 취약하거나 빌드에 실패한 웹사이트를 진단하고 수정합니다. 외부에서 사이트를 확인하고, 빌드, 런타임 로그, 워드프레스 상태, SSL, 캐시 및 PHP 설정을 Hostinger MCP를 통해 읽어 원인을 증거와 함께 명시하고, 사용자가 동의하면 해결책을 적용합니다. 트리거: 내 사이트가 다운됨, 사이트 로드 안 됨, 500 / 502 / 503 오류, 흰 화면, 데이터베이스 연결 오류, 사이트가 느림, SSL 또는 인증서 경고, 보안이 안 됨, 변경 사항이 표시되지 않음, Node.js 빌드 실패, 앱이 계속 충돌.
