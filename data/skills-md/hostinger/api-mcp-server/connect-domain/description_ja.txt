Hostingerのウェブホスティング（共有、クラウド、またはエージェンシープラン）で、カスタムドメインをウェブサイトにエンドツーエンドで接続する方法：ドメインをサイトに添付し、既存のメールや検証レコードを壊さずにDNSをHostingerに向け、SSLをインストールし、HTTPSリダイレクトを有効にし、解決を確認します。Hostingerで登録したドメインや他社で登録したドメイン、無料サブドメイン（*.hostingersite.com）からの移行、サブドメインやエイリアスにも対応します。トリガー例：ドメインを接続したい、ドメインをサイトにポイントしたい、自分のドメインを使いたい、無料サブドメインから移行したい、サブドメインを追加したい、ドメインをパークしたい、ドメインエイリアスを追加したい、ドメインが機能しない。
