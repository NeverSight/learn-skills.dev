Collega un dominio personalizzato a un sito web su Hostinger (piani Shared, Cloud o Agency) dall'inizio alla fine: associa il dominio al sito, punta il DNS su Hostinger senza interrompere le email o i record di verifica esistenti, installa SSL, attiva il reindirizzamento HTTPS e verifica che risolva. Gestisce domini registrati su Hostinger o altrove, spostando un sito dal suo sottodominio gratuito *.hostingersite.com, sottodomini e alias. Attivatori: collegare il mio dominio, puntare il mio dominio al mio sito, usare il mio dominio personale, uscire dal sottodominio gratuito, aggiungere un sottodominio, parcheggiare un dominio, aggiungere un alias di dominio, il mio dominio non funziona.
