API доменов Hostinger для управления портфелем доменов, проверки доступности, переадресации, профилей WHOIS, имен серверов, блокировки домена, защиты конфиденциальности и проверок доступа к домену. Используйте при регистрации доменов, проверке их доступности, управлении делегированием DNS, настройке перенаправлений, работе с контактной информацией WHOIS или проверке статуса верификации домена.
