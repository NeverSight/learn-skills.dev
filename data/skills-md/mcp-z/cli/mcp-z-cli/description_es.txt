Usa @mcp-z/cli para descubrir y llamar a las herramientas, indicaciones y recursos de MCP desde una terminal usando el .mcp.json de un proyecto. Carga para comandos mcp-z o z, acceso MCP basado en CLI o descubrimiento de capacidades bajo demanda. El código de aplicación que utiliza @ mcp-z/client pertenece a la habilidad del cliente.
