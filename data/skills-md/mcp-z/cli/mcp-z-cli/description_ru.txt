Используйте @mcp-z/cli для обнаружения и вызова инструментов MCP, подсказок и ресурсов из терминала с помощью файла .mcp.json проекта. Загружайте для команд mcp‑z или z, доступа к MCP через CLI или динамического обнаружения возможностей по запросу. Код приложения, использующий @mcp-z/client, относится к клиентскому навыку.
