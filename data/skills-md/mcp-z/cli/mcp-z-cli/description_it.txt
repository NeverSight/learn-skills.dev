Usa @mcp-z/cli per scoprire e chiamare gli strumenti, i prompt e le risorse MCP da un terminale utilizzando il .mcp.json di un progetto. Carica per i comandi mcp-z o z, accesso MCP basato su CLI o scoperta delle capacità su richiesta. Il codice dell'applicazione che utilizza @mcp-z/client appartiene alla skill del client.
