Utilisez @mcp-z/cli pour découvrir et appeler les outils, prompts et ressources MCP depuis un terminal en utilisant le fichier .mcp.json d’un projet. Chargez‑le pour les commandes mcp-z ou z, l’accès MCP via la CLI, ou la découverte de capacités à la demande. Le code d’application utilisant @mcp-z/client appartient à la compétence client.
