Machen Sie den Code schneller oder finden Sie heraus, warum er langsam ist, anhand von Messungen und nicht von Vermutungen. Lesen Sie diese Fähigkeit, bevor Sie den Code ändern, um ihn schneller zu machen oder weniger Speicher zu verwenden. Nutzen Sie sie, wenn der Benutzer langsamen Code, hohe Latenz oder hohen Speicherverbrauch meldet. Verwenden Sie sie zudem, um eine Geschwindigkeitsbehauptung zu überprüfen oder die Geschwindigkeit zweier Optionen zu vergleichen. Setzen Sie sie ein, um einen langsamen oder hängenden Prozess, ein Profil oder eine Trace‑Datei zu diagnostizieren.
