يقوم بمراجعة إمكانية الوصول إلى الويب والتطبيقات وفقًا لمعياري WCAG 2.2 AA والقانون الأوروبي لإمكانية الوصول (EAA، سيسري اعتبارًا من يونيو 2025). يغطي HTML الدلالي، واستخدام ARIA، والتنقل عبر لوحة المفاتيح، وإدارة التركيز، وتباين الألوان، وتوافق قارئ الشاشة، وعلامات النماذج وأخطائها، والنص البديل، وتفضيلات الحركة والرسوم المتحركة، وجودة التعريب والتوطين، وتكامل أدوات الاختبار (axe، pa11y، Lighthouse، Playwright a11y). يُستخدم عندما يطرح المستخدم سؤالًا عن "إمكانية الوصول"، "a11y"، "WCAG"، "قارئ الشاشة"، "EAA"، "التنقل عبر لوحة المفاتيح"، أو يستدعي ‎/accessibility‑audit، أو عندما يوكّل المنسق على تطبيقات موجهة للمستخدمين. النهج غير مقيد بنظام معين؛ إرشادات خاصة بالأطر مثل React / Vue / Angular / Svelte / HTML العادي.
