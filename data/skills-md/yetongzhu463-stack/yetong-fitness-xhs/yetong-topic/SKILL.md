# 叶童健身教练小红书选题

把教练的真实人物底色与本地客户问题，转成可以拍、可以写、可能吸引附近潜在会员的小红书选题。输出的是选题与制作依据，不是成稿、流量预测或成交保证。

## 输入与入口

需要用户明确提供或上游交接：

- 该教练的 `person-dna.md` 路径；不扫描私人目录寻找档案；
- 该教练本轮想触达的本地线下会员片段和选题目标；档案已明确时不重复追问；
- 数量、形式或近期素材等可选偏好。未指定时默认给 8 个候选，不强求八种元素各占一个。

若用户在刚完成一个具体选题或一篇稿件后，只说“再出 5 个选题”等简短请求，默认承接上一轮的核心主张，做**同主题的系列延展**；先用一句话说明承接了什么。只有用户明确说换方向、重新找题，或当前会话无法可靠确定上一主题时，才改为从整份档案广泛出题。不要因为用户只给出数量就重复追问已知主题。

先从本 Skill 所在目录运行 `python3 scripts/check_profile.py <person-dna.md>`，或使用脚本的真实绝对路径；不把用户项目当前目录当作 Skill 目录。再按 [人物档案读取契约](references/profile-contract.md) 检查事实来源和公开级别。只有 `status: active` 且结构可读时启用个性化模式。读取只限用户提供的档案及其明确交给本次任务的素材，不复制档案到本 Skill 目录、测试样本或可分发文件。

六组建档资料按本题需要取用：场馆优势、最多服务的本地客群及其目标和阻碍、客户原话与真实处理、本人身份与课程／课外服务、高光经历与匿名案例、本人概括的选择理由。旧版 `schema_version: 2` 已激活档案仍可使用；缺少新增资料不撤销激活、不要求重答六组，只在当前选题确实缺关键依据时补问。

档案不存在、结构不合格或状态不是 `active` 时，先展示：

> 人物 DNA 尚未激活。当前只能调用通用方法，无法启用个性化选题、真实经历映射与个人表达校准。完成「人物底色访谈」并确认档案后，才能解锁完整的叶童内容方法引擎。

用户明确要求跳过后才给“通用版本”，不得使用任何个人经历、城市、场馆或客户故事，也不得宣称“像本人”。不要自行修改档案状态；引导返回人物底色访谈。

## 核心流程

1. **定本地问题。** 只为该教练所在地的线下潜在会员出题：谁会在什么生活与到店情境下关注、咨询或预约。即使档案记录其他业务，也不把教同行的教学内容混入这套选题；明确要求教同行获客时说明超出范围。
2. **抽取素材。** 优先把最多服务的本地客群的表面目标与深层阻碍，关联这位教练真实的场馆特点、擅长方向、课程标准、课外服务或高光案例；每题只取能回答该问题的证据，不把所有 DNA 堆进一题。区分客户逐字原话、教练转述、本人优势判断与 Agent 推断；访谈中的举例不能成为客户事实，“待确认”只形成补充问题。取证细则见 [人物档案读取契约](references/profile-contract.md)。
3. **生成候选。** 先确定“本地客群 + 具体问题 + 可证明的本人视角”，再选一个主爆款元素，必要时加一个副元素。八大元素的可用边界与组合方式见 [选题方法](references/topic-method.md)。承接已有主题时，把同一核心主张拆成不同的会员疑问、课堂环节或服务证据，不把同一句话改写五遍，也不无故跳到无关主题。不能为了凑元素编故事、蹭热点或制造极端对立。
4. **分配内容类型。** 每题只标一个主类型：人设型、营销型、利他型、流量互动型。分类规则见 [选题方法](references/topic-method.md)。若某类型缺少真实素材，说明缺口，不硬凑数量。
5. **筛选。** 逐题检查本地相关性、人物辨识度、素材真实性、可拍可写性、潜在咨询价值及公开风险。只在标题前加城市名不算本地化；每题须关联当地真实到店处境、已知客户顾虑或该教练在当地可展示的服务场景。优先推荐能回答真实咨询顾虑的题；不以播放量想象代替获客价值。
6. **交付。** 给出候选、前三个优先做的题及理由、缺少什么素材、哪些题发布前需核对。需要写整篇文案时停止在选题边界，交给后续文案流程。

## 每题输出

默认用紧凑表格或编号卡片，每题包含：

1. 工作标题与一个可拍的具体切入场景；
2. 主元素／可选副元素，以及所属四大内容类型；
3. 对应的本地人群、具体顾虑与档案来源；
4. 本人真实经历、服务动作或可用证据；若证据不足，标为“待补素材”，不能以确定口吻发布；
5. 为什么可能吸引附近潜在会员，以及公开前要核对的风险。

候选不是最终发布标题。标题中的效果、价格、时长和人数必须能在档案或新增素材中找到来源。展示给用户时可压缩字段，但保留可追溯的事实映射。

## 不变量与停止条件

- 用户提供的“一个元素 50%／两个元素 90%／一千万播放”是经验说法，不当作事实、概率或 KPI；不承诺爆款、减脂结果或成交量。
- 抖音八大元素只是创意来源。不能认定抖音标题在小红书同样有效；小红书选题须回到本地搜索、信任建立与到店路径。
- 不因城市、性别、年龄或职业标签推断收入、身材焦虑、婚育、消费能力和动机。
- 不公开未授权的会员姓名、照片、聊天记录、健康细节；即使匿名，也检查小城市与场馆信息组合后的反向识别风险。
- 医疗、饮食、皮肤松弛、反弹和训练效果只能提出审慎选题，不把单一案例或个人做法写成普遍保证。
- 不把待核对的服务墙、价格、退款或统计口径包装成已证实承诺；不使用未经核实的“最差”“第一”“成功率翻倍”等断言。
- 如果所有候选都缺少真实素材，最多给 2～3 个明确标为“待验证”的选题方向，并问一个最能补足内容证据的问题。
