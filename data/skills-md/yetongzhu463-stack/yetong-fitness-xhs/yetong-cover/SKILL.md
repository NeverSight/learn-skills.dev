# 叶童原版小红书封面｜公开包接入

这是一层本地健身业务接入，不是另一套封面方法。用户已明确选择把个人版 `yetong-xhs-cover` 原样放进 YETONG：完整原文见 [原版封面工作流](original-cover-workflow.md)，视觉规范见 [原版视觉语言](references/visual-language.md)，构图见 [原版构图模板](references/layout-templates.md)。三份原文保留原样，公开调用短名仍为 `yetong-cover`。只分发方法文字，不内置叶童或任何教练的照片、外貌、场馆、人物档案和私人素材。

## 进入前检查

1. 使用本次用户明确交接的本人 `person-dna.md` 路径，先从本 Skill 所在目录运行 `python3 scripts/check_profile.py <person-dna.md>`。只缺路径时只问路径，不扫描私人目录。档案须结构有效且为 `active`，身份须匹配；预检不证明单条事实、图片授权或效果。旧版已激活 `schema_version: 2` 档案仍可使用，不为新问题缺字段重访。
2. 本模块服务这位教练所在城市的线下潜在会员。须有具体选题、正文或能说清正文承诺的内容概要；只有“做个健身封面”时交回选题。只有标题但不清楚具体内容时，按原版第 0 步只索取内容，不据标题编故事。数字、城市、课程标准和服务频率只用已确认且可公开事实。
3. 六组 DNA 是按篇取材依据，不是另一套视觉模板：从本篇相关的场馆特点、主力客群、客户原话、身份与交付、可公开高光、本人选择理由取事实；不把问卷例子当事实，不把自述改成会员评价。视觉与问答按原版，不用旧的健身五模式、中性配色或无人物海报取代它。
4. 用户已明确给出的标题默认原样作为本张封面文字，不要求另加“封面”标签；只有用户明确说明它仅用于笔记发布标题，并另外要求封面候选时，才视为未提供封面文字。可安排换行和上下分区，但不删改字词。没有给定标题时，按原版生成三个编号候选，仅处理本张封面，不擅自改笔记发布标题。含无依据效果保证、虚假价格、医疗断言或越权隐私时，只说明具体问题和需核对的依据，停止正式制作；不在封面模块另拟替代标题或追问是否采用替代句。用户另行要求改题时再交标题／文案模块，不静默改标题、换成人物故事或用小字辟谣绕过。

档案不存在、无效或未激活时，停止个性化，原样提示：

> 人物 DNA 尚未激活。当前只能调用通用方法，无法启用个性化选题、真实经历映射与个人表达校准。完成「人物底色访谈」并确认档案后，才能解锁完整的叶童内容方法引擎。

仅用户明确跳过访谈时，可讲不含个人事实的“通用版本”原版流程；不以别人的城市、长相或故事做其本人封面，不替用户激活。

## 执行原版，不并行运行旧方法

检查通过后，**完整读取 [原版封面工作流](original-cover-workflow.md)**，实际按其中第 0～6 步执行。原文中的科技／产品示例保留，不重新改写成健身模板；在本地业务里只把内容槽位填成用户真实的训练主题、器械、计划本或服务场景。无实体产品时可选原版“单人口播教学风”，不强造产品。

- 一次只问一个当前问题，等回答后继续，顺序保持原版第0→1→2→3→4→5→6步。即使用户先说明没有图1，构图尚未确认时也先给第1步构图选择；选好构图后才停在第2步上传图1，不能先要照片后再补选构图。构图、辅助素材、动作、背景和无给定标题的选择都按原版编号。已提供的信息直接记录并跳过，包括用户已明确授权系统推荐的那一步；不能把没有选择伪装成已选。标题给定就不再问标题，字体和标题效果不再额外追问。
- 记录当前步骤、已选构图、素材账、动作、背景、原样标题和输出状态。用户回复数字或上传图片时回到同一封面阶段，不重开选题或问卷；上下文无法判断数字含义时只核对该数字对应哪一步。
- 图1是本人的人物参考素材组，多张记为图1a／图1b／图1c；图2起是辅助素材。将这套逻辑编号逐项对应到工具真实附件／路径，不把第二张人物照当产品。未实际收到可读取图片，不声称已经看图。
- 缺人物参考图就停在原版上传图1这一步。即使不露脸也需本人的手部、背影、侧脸或局部参考，不能靠档案文字生出陌生脸，也不换成纯信息海报冒充完成。不扫描相册替用户找照片。
- 产品／辅助素材在健身语境可理解为实际器械、训练计划、流程或场馆素材，但保持原版选项。缺精确参考时只允许原版已有的通用无品牌物件，不补造器械型号、功能、Logo、证书、评分、聊天或服务证据。
- 场馆或会员图片逐项核对来源与本次用途。匿名不等于有公开授权；身体对比只允许使用获授权真实原图，不生成或篡改身材变化。可以按原版选创意背景，但必须明确它是创意合成，不把生成背景当真实门店、实拍旧经历或效果证据。
- 收集完成后再完整读取 [原版视觉语言](references/visual-language.md)，只取 [原版构图模板](references/layout-templates.md) 中已选模板。原版固定3:4、人物实拍质感、上下巨字、白色 `#FFFFFF`／暖橙黄 `#F5A623`、柔和投影和少量手写标注；这是选用模板的设计规范，不声称是每位教练原有的场馆品牌色。不调用旧 `cover-method.md` 或 `layout-patterns.md`。

## 提示词与成图接续

按原版交付顺序：**方案摘要 → 完整生图提示词 → 文字排版清单 → 生成约束**。默认文字写入提示词；仅用户明确要无字底图时才留安全区，把准确文字留在排版清单。不将有待补图片的计划称为完整成品，不把跨窗口复制文字说成已经传递参考图。

这是原版唯一附加的接续动作，不改其前面问答：交付可执行完整提示词后，当前工具、参考素材和授权齐备且用户尚未明确要求生成时，问：

> 需要根据这份提示词完成封面吗？回复“直接生成”，或选择“继续优化提示词”。

用户明确只要提示词／不生成时，不重复催问；当前无生图能力或无法传入必要参考图时，说明实际缺口，只保留可执行的提示词优化选项，不承诺当前能生成。用户本轮已明确要最终图片且条件齐备时，沿用原版直接制作，不重复征求同一动作。

“直接生成”仅授权本轮成图，不授权公开人物素材或发布笔记。再次核对本篇提示词和素材后使用当前可用生图能力，并检查人物／器械一致性、手指、3:4、汉字、数字、地名和标题不遮挡关键部位。文字不准时用可用编辑／叠字能力修正；无法完成就说明是未完成草稿，不能称可直接发布。“继续优化提示词”只修改本篇提示词，不擅自生成图片。需要用户选调整方向时按原版用一个编号问题。
