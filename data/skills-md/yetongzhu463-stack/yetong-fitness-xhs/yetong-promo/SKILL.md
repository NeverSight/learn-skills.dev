# yetong-promo：课程朋友圈营销

解决“有一门课程，但不知道卖给谁、怎样说明价值、每天朋友圈发什么”的反复问题。用叶童的方法组织内容，用当前教练自己的城市、产品、经历、服务动作和表达习惯填入事实，不给所有人套同一个人的故事。

## 入口与停止条件

1. 仅处理面向本人本地到店会员的课程推广。只写小红书时交回 `yetong-copy`；只做人设朋友圈、教同行或经营诊断，不冒称本模块已覆盖，交回主入口判断。
2. 个性化产品定位、排期和文案均须先读取用户明确提供的已激活 `person-dna.md`，或本轮由建档模块确认并交接的等价完整档案；不搜索其他人的私人目录。可执行脚本时运行 `python3 scripts/check_profile.py <用户明确指定的档案路径>`（相对于本 Skill 目录）。退出 0 仅表示结构及激活通过，不证明事实与授权；退出 2／3 时停止个性化输出，转 `yetong-dna`。无脚本环境时逐项核 schema_version=2、本人身份、本地城市和客群、status=active、confirmed_at、产品、表达、权限和 DNA 摘要；只声称“已激活”而无可读档案不算通过。
3. 未激活时提示：“你的人物 DNA 尚未激活，个性化课程营销暂未解锁。先完成并确认本人建档，才能把课程优势、当地客群与真实表达连接起来。”可说明方法或给空白资料卡，不生成伪个性化成稿，不用叶童档案顶替。
4. 已有档案复用，不为每门新课重访人物生平。新增课程走本次产品资料卡；只有姓名、城市、职业身份、资质或核心业务发生冲突才交回 DNA 核实相关字段。
5. 不替用户发朋友圈、私信、收款、建群、改变产品价格或承诺。不生成收款截图、客户评价、效果对比图或排队事实。没有发布权限也不以“可直接发布”暗示已经完成核对。

## 先选任务，再按需读方法

通过激活门槛后，读取 [产品资料与证据卡](references/product-card.md)，只补会改变当前输出的产品事实。开始定位或排期时完整读取 [营销方法](references/marketing-method.md)；推荐具体写法或写稿前完整读取 [框架与自动匹配](references/copy-frameworks.md)。三份引用共同约束事实与权限，不依赖原 PDF、图片或 DBS 文件。

| 用户要什么 | 本轮交付 | 不强加的东西 |
| --- | --- | --- |
| 只有课程名称，不知道怎么推 | 最少产品补充问题；已知部分整理为资料卡 | 不凭名称推断功效、人数、价格和课程机制 |
| 只要营销思路／定位 | 产品 → 本地优先客群 → 表面目标与深层顾虑 → 优势证据链 → 四板块思路及行动 | 不默认生成几十条成稿 |
| 一整套推广方案 | 事实卡、指定周期排期、各条框架与素材状态、对应文案或明确标识的提纲 | 不把素材缺口藏在“热销”“蜕变”成稿里 |
| 今天发什么 | 用户指定条数的推荐与文案；未指定默认 4 条 | 不延伸成完整长周期活动 |
| 单条朋友圈／改现有稿 | 对该条选框架、核事实权限、交一条成稿与必要核对 | 不重做所有已确认资料 |
| 沿用既有推广计划，写下一天 | 核当前日期／日序、产品变化和新增素材，沿用同一计划接续 | 不把同一案例当作当天新增结果 |

草案产品可做内部定位与条件排期，不能写成已经开售、已发生体验或已有成效。已确认的真实课程才可给面向会员的成稿；暂停／失效产品不继续招募，先确认当前交付。缺少非必要价格或结果不阻止真实课程介绍，不将“草案不得冒充事实”误读成“新品必须先有成功案例才能推广”。

## 从 DNA 到这门课的购买理由

1. 从本人 DNA 摘取：准确城市／服务半径与场馆优势、最多服务的本地人群、表面目标、深层顾虑及原话、身份年限与真实资质、专业优势、课上标准、课下服务、已授权高光和表达指纹。只用本条相关字段，资料未覆盖就不猜。
2. 从产品资料卡摘取本课程：提供什么、如何交付、适用条件、当前真实规则、阶段与期望行动、可用素材及授权。课程未确认的功能只保留为内部假设；旧产品规则不自动迁移。
   “本轮未提供／不知道”只说明资料缺口，不证明事实不存在或尚未确定。未给价格、时间或权益就不写，不能在成稿中改成“价格还没定”“没有课后服务”等新事实；用户明确说未定／没有才可如此表述。
3. 将每个优势写成“具体顾虑 → 已确认动作／标准 → 对会员的实际帮助 → 可核对来源”。场馆历史、个人历史和本课程历史分开；案例变化是该个案，不保证别人得到相同结果。证书和康复能力不能凭课程名补出。
4. 人群适配属于策划判断：优先本人现有本地客群；新细分人群标“建议验证”。不把宝妈、女性、上班族自动等同某种心理或身体状况，不臆测周边客流。

## 自动配文案并落到每天

三个维度分别标，不混用：

- 推广板块 P1 产品硬广、P2 选择理由、P3 使用感受／变化、P4 真实新购／复购／预约；
- 原包四大主内容类型：人设型、营销型、利他型、流量互动型；
- 图片结构 I1～I5，以及写法 F01～F05／营销子类 M01 客户咨询、M02 客户反馈、M03 转账截图、M04 会员蜕变。

按目的与真实证据选主框架。真实咨询才用 M01；授权反馈才用 M02／F04；真实新购或复购才用 M03，只有预约用 F05；本课程已核对的变化才用 M04。没有客户事件改用 F01 介绍、F02 标准或 F03 有界科普，不捏造“会员问”“会员都说”。排期中一条选一个主框架，辅助证据不必拼齐所有步骤。

每天持续组织 A1 课程标签、A2 过程标准、A3 客户结果、A4 真实选择、A5 本人打卡，不写成第 1～5 天各做一次的漏斗。用户指定周期／频率优先；完整方案未指定时，可先给“7 天、每天 4 条”的可调整示例，明确是排期假设，不是课程期限或已验证最佳频率。叶童每天约 4～5 条的经验不构成爆品或成交保证。

每天 4 条时合并 A2＋A5，5 条时另列本人打卡。结果／交易／当天打卡证据缺失时，标原槽位“未满足”，另给能用已确认事实写出的替代内容，并标替代后的真实 P 和类型；不把替代科普假标成客户反馈或成交。计划采集素材是待做任务，不写成已发生。

## 交付与发布前自检

- 资料摘要：这门课提供什么、优先卖给谁、场景与顾虑、为什么考虑、下一步行动；每项事实可回指 DNA／产品卡／具体素材。
- 每条推荐：主 P、运营动作 A、主内容类型、F／M、I、目的、素材状态及来源。分类备注放在文案外，不把内部编号写进客户看到的朋友圈。
- 成稿：像本人说话，短句和长短节奏从真实表达来；语气待校准时标“试写待口吻校准”，不宣称高度还原。结尾仅使用已存在的咨询／预约路径，不自造赠课、折扣、名额或时限。
- 排期：日序／日期、条目、主题、框架、目的、所需素材、状态、成稿或采集后才能写的提纲、发布前禁写点；只要思路不必出排期。用户要完整逐日稿就完成各日，不只交模板；缺口提纲与当天真实可发替代稿分开。
- 对客户反馈、聊天截图、身体照片、交易截图分别核授权和脱敏。匿名不等于授权；不公开付款标识、联系方式和可反向识别的组合信息。允许文字事实不等于允许截图或照片。
- 核服务频率、产品归属、起止时间及数字计算；新购不叫复购、预约不叫成交、旧课效果不叫新品效果。没有证据不写“抢疯”“排满”“保证瘦”“不反弹”。
- 最后给下一步：今天可用哪些真实稿；缺什么素材、如何取得公开许可、哪条暂缓。用户已给足的事实与权限不反复问。

输出可执行且边界清楚的方案后结束。产品定位建议、发圈频率和案例反馈不等于营销效果保证。
