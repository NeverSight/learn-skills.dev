エージェント駆動のローカルプロジェクト起動アシスタント：Java/Spring Boot（スタンドアロン JRebel を含む）、Python、Vue/React/Vite などの Node フロントエンドや主流スタックのプロジェクトを識別・起動し、ログを表示し、ホットリロードを検証します。ローカルサービス／プロジェクトを開始したり、JRebel を設定・トラブルシュートしたり、ランタイムログを閲覧したり、ローカル Web 管理コンソール（マネージャ UI、デフォルトは http://127.0.0.1:8199）を開く際に使用します。プロジェクト間のランタイム管理および読み取り専用管理コンソール（manager.mjs の list/status/start/stop/restart/remove/prune/logs/ui）も実装されており、使用方法は第 8 章をご参照ください（references/manager.md）。
