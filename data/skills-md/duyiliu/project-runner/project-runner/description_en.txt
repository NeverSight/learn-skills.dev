Agent-driven local project launch assistant: recognizes and starts Java/Spring Boot (including standalone JRebel), Python, Vue/React/Vite and other Node front‑ends as well as other mainstream stack projects, launches them, views logs, and verifies hot reload. It is used when the user wants to start a local service/project, configure or troubleshoot JRebel, view runtime logs, or open the local web management console (manager UI, default fixed at http://127.0.0.1:8199); cross‑project runtime management and read‑only management console (manager.mjs list/status/start/stop/restart/remove/prune/logs/ui) have been implemented, usage see Chapter 8 (see references/manager.md).
