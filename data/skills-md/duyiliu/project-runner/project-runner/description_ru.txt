Помощник по запуску локального проекта, управляемый агентом: определяет и запускает Java/Spring Boot (включая отдельный JRebel), Python, Vue/React/Vite и другие фронтенды на Node, а также прочие проекты из популярных стеков, запускает их, просматривает логи и проверяет горячую перезагрузку. Используется, когда пользователь хочет запустить локальный сервис/проект, настроить или отладить JRebel, просмотреть журналы выполнения или открыть локальную веб‑консоль управления (интерфейс менеджера, по умолчанию фиксирован по адресу http://127.0.0.1:8199); реализовано кросс‑проектное управление временем выполнения и консоль только для чтения (manager.mjs list/status/start/stop/restart/remove/prune/logs/ui). См. главу 8 для использования (см. references/manager.md).
