Crea, controlla l'integrità, esegui, esegui sondaggi e scarica i risultati per le sperimentazioni in-silico di Jinkō tramite jinko-sdk. Utilizza questa competenza ogni volta che l'utente desidera impostare una prova da un modello computazionale e un set di output semplice, facoltativamente allegare un vpop, un protocollo, una tabella dati o un set di output di punteggio avanzato, avviare una prova, attendere il completamento, ispezionare le prove completate o scaricare i risultati TimeSeries e Scalar come DataFrames panda. Non utilizzare questa competenza per la modifica di modelli, la creazione di vpop, la creazione di progetti di protocolli, il caricamento di tabelle di dati, la creazione/modifica di set di output o la visualizzazione di prove.
