Cree, verifique, ejecute, sondee y descargue resultados para pruebas in-silico de Jinkō a través de jinko-sdk. Utilice esta habilidad siempre que el usuario desee configurar una prueba a partir de un modelo computacional y un conjunto de resultados simple, opcionalmente adjuntar un vpop, un protocolo, una tabla de datos o un conjunto de resultados de puntuación avanzada, iniciar una prueba, esperar a que se complete, inspeccionar las pruebas completadas o descargar resultados de TimeSeries y Scalar como Pandas DataFrames. No utilice esta habilidad para la edición de modelos, la creación de vpop, la creación de diseños de protocolos, la carga de tablas de datos, la creación/edición de conjuntos de resultados o la visualización de pruebas.
