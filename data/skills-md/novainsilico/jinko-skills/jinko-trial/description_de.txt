Erstellen Sie Ergebnisse für Jinkō-In-silico-Studien, überprüfen Sie sie auf Plausibilität, führen Sie sie aus, führen Sie Umfragen durch und laden Sie sie über das jinko-sdk herunter. Verwenden Sie diese Fertigkeit immer dann, wenn der Benutzer einen Versuch aus einem Rechenmodell und einem einfachen Ausgabesatz einrichten, optional einen VPOP, ein Protokoll, eine Datentabelle oder einen erweiterten Bewertungsausgabesatz anhängen, einen Versuch starten, auf den Abschluss warten, abgeschlossene Versuche prüfen oder TimeSeries- und Scalar-Ergebnisse als Pandas-DataFrames herunterladen möchte. Verwenden Sie diese Fertigkeit nicht für die Modellbearbeitung, VPO-Erstellung, Protokollentwurfserstellung, Hochladen von Datentabellen, Erstellung/Bearbeitung von Ausgabesätzen oder Testvisualisierung.
