قم بإنشاء النتائج وفحصها وتشغيلها واستطلاعها وتنزيلها لتجارب Jinkō in-silico عبر jinko-sdk. استخدم هذه المهارة عندما يريد المستخدم إعداد تجربة من نموذج حسابي ومجموعة مخرجات بسيطة، أو إرفاق vpop، أو بروتوكول، أو جدول بيانات، أو مجموعة مخرجات تسجيل متقدمة، أو تشغيل تجربة، أو انتظار الاكتمال، أو فحص التجارب المكتملة، أو تنزيل نتائج TimeSeries وScalar كـ pandas DataFrames. لا تستخدم هذه المهارة لتحرير النماذج، أو إنشاء vpop، أو تأليف تصميم البروتوكول، أو تحميل جدول البيانات، أو إنشاء/تحرير مجموعة المخرجات، أو التصور التجريبي.
