Autentica e configura l'accesso a un progetto Jinkō tramite jinko-sdk. Utilizza questa competenza ogni volta che l'utente desidera connettersi a Jinkō, installare l'SDK, impostare le credenziali o un file .env, verificare l'accesso all'API, verificare rapidamente che JINKO_API_KEY e JINKO_PROJECT_ID funzionino o eseguire il debug di ConfigurationError, AuthenticationError o AuthorizationError dall'SDK. Non utilizzare questa competenza per creare modelli, vpop, protocolli, set di output o prove.
