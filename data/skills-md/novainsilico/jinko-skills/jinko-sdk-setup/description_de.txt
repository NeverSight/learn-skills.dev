Authentifizieren und konfigurieren Sie den Zugriff auf ein Jinkō-Projekt über das Jinko-SDK. Verwenden Sie diesen Skill immer dann, wenn der Benutzer eine Verbindung zu Jinkō herstellen, das SDK installieren, Anmeldeinformationen oder eine .env-Datei einrichten, den API-Zugriff überprüfen, ausfallsicher prüfen möchte, ob ein JINKO_API_KEY und eine JINKO_PROJECT_ID funktionieren, oder ConfigurationError, AuthenticationError oder AuthorizationError aus dem SDK debuggen möchte. Verwenden Sie diese Fertigkeit nicht zum Erstellen von Modellen, VPOs, Protokollen, Ausgabesätzen oder Versuchen.
