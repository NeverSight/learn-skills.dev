Autenticar y configurar el acceso a un proyecto Jinkō a través de jinko-sdk. Utilice esta habilidad siempre que el usuario quiera conectarse a Jinkō, instalar el SDK, configurar credenciales o un archivo .env, verificar el acceso a la API, verificar rápidamente que JINKO_API_KEY y JINKO_PROJECT_ID funcionen, o depurar ConfigurationError, AuthenticationError o AuthorizationError del SDK. No utilice esta habilidad para crear modelos, vpops, protocolos, conjuntos de resultados o pruebas.
