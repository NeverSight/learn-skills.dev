Extraiga o digitalice valores biomédicos informados de artículos, figuras, tablas, suplementos, imágenes o fuentes web en CSV/Markdown rastreable, opcionalmente como una tabla de datos Jinkō lista para calibración. Úselo cuando la evidencia numérica deba transcribirse, normalizarse, convertirse en unidades o vincularse a observables del modelo. No lo utilice para descubrimiento de literatura, síntesis de evidencia o invención de valores ausentes de la fuente.
