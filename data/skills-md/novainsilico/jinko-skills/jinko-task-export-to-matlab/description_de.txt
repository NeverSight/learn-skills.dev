Exportieren Sie ein Jinkō-Rechenmodell nach SimBiology, wenden Sie die exportierten Simulationseinstellungen in MATLAB an und vergleichen Sie ausgewählte Zeitreihen mit den Ergebnissen von Jinkō simple_solve. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein Jinkō-Modell nach MATLAB/SimBiology übertragen, einen Excel-basierten SimBiology-Export gegen Jinkō validieren, eine einfache Jinkō-Lösung in SimBiology reproduzieren oder die Divergenz zwischen den beiden Solvern untersuchen möchte. Verwenden Sie es auch dann, wenn der Benutzer nur eine Modellkurz-ID oder einen Link angibt und einen SimBiology-Vergleich anfordert.
