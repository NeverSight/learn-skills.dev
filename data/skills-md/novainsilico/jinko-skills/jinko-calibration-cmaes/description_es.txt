Cree, ejecute, sondee e inspeccione resultados para calibraciones de Jinkō CMA-ES a través de jinko-sdk: adjunte tablas de datos y/o un conjunto de salida avanzado como fuentes de funciones de fitness, establezca opciones y parámetros previos de CMA-ES, inicie y supervise la ejecución, y lea cargas útiles de rendimiento/resultados. Úselo siempre que el usuario necesite la mecánica del SDK para construir o controlar un objeto de calibración. No utilice esta habilidad para reglas comerciales de calibración (valores predeterminados, diagnósticos, reglas de entrega). No utilice esta habilidad para la creación de diseños de puntuación/conjuntos de resultados avanzados; utilice jinko-output-set. No utilice esta habilidad para la creación de tablas de datos o comprobaciones validForFitnessFunction; utilice jinko-data-table. No utilice esta habilidad para la creación de modelos o protocolos; utilice jinko-model/jinko-protocol. No utilice esta habilidad para la orquestación del plan de calibración o el flujo de trabajo de iteración.
