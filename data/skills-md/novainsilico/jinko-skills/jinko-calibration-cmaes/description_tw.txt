透過 jinko-sdk 建立、運行、輪詢和檢查 Jinkō CMA-ES 校準的結果：附加資料表和/或進階輸出集作為適應度函數來源，設定 CMA-ES 選項和參數先驗，啟動和監控運行，以及讀取效能/結果有效負載。當使用者需要建置或驅動校準物件的 SDK 機制時使用。請勿將此技能用於校準業務規則（預設值、診斷、可交付規則）。不要將此技能用於高級輸出集/評分設計創作 - 使用 jinko-output-set。不要將此技能用於資料表建立或 validForFitnessFunction 檢查 - 使用 jinko-data-table。不要將此技能用於模型或協議創作 - 使用 jinko-model / jinko-protocol。請勿將此技能用於校準計劃編排或迭代工作流程。
