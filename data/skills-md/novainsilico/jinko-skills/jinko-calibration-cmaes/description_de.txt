Erstellen, ausführen, abfragen und prüfen Sie Ergebnisse für Jinkō CMA-ES-Kalibrierungen über das jinko-sdk: Hängen Sie Datentabellen und/oder einen erweiterten Ausgabesatz als Fitness-Funktionsquellen an, legen Sie CMA-ES-Optionen und Parameter-Prioritäten fest, starten und überwachen Sie den Lauf und lesen Sie Leistungs-/Ergebnisnutzlasten. Verwenden Sie es immer dann, wenn der Benutzer die SDK-Mechanik zum Erstellen oder Fahren eines Kalibrierungsobjekts benötigt. Verwenden Sie diese Fähigkeit nicht zur Kalibrierung von Geschäftsregeln (Standards, Diagnose, Lieferregeln). Verwenden Sie diese Fertigkeit nicht für die Erstellung fortgeschrittener Ausgabesätze/Bewertungsdesigns – verwenden Sie jinko-output-set. Verwenden Sie diesen Skill nicht für die Erstellung von Datentabellen oder für validForFitnessFunction-Prüfungen – verwenden Sie jinko-data-table. Verwenden Sie diese Fertigkeit nicht für die Modell- oder Protokollerstellung – verwenden Sie jinko-model / jinko-protocol. Verwenden Sie diese Fähigkeit nicht für die Orchestrierung von Kalibrierungsplänen oder den Iterationsworkflow.
