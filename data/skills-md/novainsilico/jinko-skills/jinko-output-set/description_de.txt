Erstellen, prüfen, validieren und bearbeiten Sie inkrementell Jinkō-Ausgabesätze über das jinko-sdk: einfache Ausgabesätze (Maßentwürfe), die aus Modellausgaben abgeleitete skalare Maße auflisten, und erweiterte Ausgabesätze (Bewertungsentwürfe), die Einschränkungen, Skalare und gewichtete Ziele für die Bewertung virtueller Populationen definieren. Validieren Sie Scoring-Ausdrücke und lesen Sie Diagnosen, bevor Sie einen Ausgabesatz an anderer Stelle anhängen. Verwenden Sie diese Fertigkeit nicht, um einen einfachen oder erweiterten Ausgabesatz an eine Testversion anzuhängen und auszuführen. Verwenden Sie dazu Jinko-Trial. Verwenden Sie diesen Skill nicht für die Erstellung von Datentabellen oder Fitness-Funktionsmetadaten. Verwenden Sie dazu Jinko-Data-Table. Verwenden Sie diesen Skill nicht für die Kalibrierungseinrichtung oder CMA-ES-Optionen.
