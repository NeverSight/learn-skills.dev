Crea, ispeziona, convalida e modifica in modo incrementale i set di output Jinkō tramite jinko-sdk: set di output semplici (progetti di misure) che elencano misure scalari derivate dagli output del modello e set di output avanzati (progetti di punteggio) che definiscono vincoli, scalari e obiettivi ponderati per il punteggio delle popolazioni virtuali. Convalida le espressioni di punteggio e leggi la diagnostica prima di allegare un set di output altrove. Non utilizzare questa funzionalità per allegare un set di output semplice o avanzato a una versione di prova ed eseguirla; usa jinko-trial per quello. Non utilizzare questa competenza per la creazione di tabelle di dati o metadati di funzioni fitness; usa jinko-data-table per quello. Non utilizzare questa Skill per l'impostazione della calibrazione o le opzioni CMA-ES.
