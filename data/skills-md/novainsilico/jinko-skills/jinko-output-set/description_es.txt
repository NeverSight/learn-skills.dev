Cree, inspeccione, valide y edite incrementalmente conjuntos de resultados de Jinkō a través de jinko-sdk: conjuntos de resultados simples (diseños de medidas) que enumeran medidas escalares derivadas de los resultados del modelo y conjuntos de resultados avanzados (diseños de puntuación) que definen restricciones, escalares y objetivos ponderados para calificar poblaciones virtuales. Valide las expresiones de puntuación y lea los diagnósticos antes de adjuntar un conjunto de resultados en otro lugar. No utilice esta habilidad para adjuntar un conjunto de resultados simple o avanzado a una prueba y ejecutarlo; usa jinko-trial para eso. No utilice esta habilidad para la creación de tablas de datos o metadatos de funciones de aptitud; use jinko-data-table para eso. No utilice esta habilidad para la configuración de calibración ni para las opciones de CMA-ES.
