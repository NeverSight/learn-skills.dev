Erstellen oder aktualisieren Sie ein Jinkō-Dokument vom Markdown über das Jinko-SDK, einschließlich Überschriften, Tabellen, Codeblöcken, Links zu Jinkō-Projektelementen, hochgeladenen Bildern und Links zu vorhandenen Jinkō-Referenzen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen lokalen Markdown in ein Jinkō-Dokument umwandeln, ein vorhandenes Dokument aus dem bearbeiteten Markdown aktualisieren, einen Markdown vorbereiten möchte, damit Jinkō Karten und Bilder korrekt rendert, oder vorhandene Projektreferenzen zitieren möchte.
