Erstellen, Aktualisieren, Überprüfen, Plausibilitätsprüfung und Abrufen von Jinkō-TrialVisualization-Projektelementen für abgeschlossene oder laufende Tests. Verwenden Sie diese Skill, wenn der Benutzer eine Testvisualisierung, eine Test-Viz, eine Einrichtung von Zeitreihendiagrammen, skalare Ergebnisdiagramme, Streudiagramme, eine Beitragsanalyse, eine Überlebensanalyse, Datenüberlagerungen oder das Abrufen des aktuellen Visualisierungs-JSON wünscht. Das SDK stellt eine typisierte TrialVisualization-API bereit: Erstellungshilfen sowie einen Unterdienst pro Abschnitt für jeden Diagrammtyp.
