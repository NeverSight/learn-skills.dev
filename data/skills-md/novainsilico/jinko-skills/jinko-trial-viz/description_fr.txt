Créer, mettre à jour, inspecter, vérifier la cohérence et récupérer les éléments du projet Jinkō TrialVisualization pour les essais terminés ou en cours. Utilisez cette compétence chaque fois que l'utilisateur souhaite obtenir une visualisation d'essai, une visualisation d'essai, une configuration de graphique de séries temporelles, des graphiques de résultats scalaires, des nuages de points, une analyse de contribution, une analyse de survie, des superpositions de données ou pour récupérer le JSON de visualisation actuel. Le SDK expose une API TrialVisualization typée : des assistants de création ainsi qu’un sous-service par section pour chaque type de graphique.
