Crea o esamina le tabelle di dati Jinkō tramite jinko-sdk. Utilizzare questa abilità ogni volta che l'utente desidera caricare dati osservati per sovrapposizioni di prova o obiettivi di calibrazione da CSV, SQLite o panda DataFrame; controllare le colonne dello schema della tabella dati; ispezionare le tabelle dati esistenti; oppure verifica metadata.public.validForFitnessFunction. Non utilizzare questa abilità per i set di output; usa jinko-output-set per quello.
