Créez ou inspectez les tables de données Jinkō via le jinko-sdk. Utilisez cette compétence chaque fois que l'utilisateur souhaite télécharger des données observées pour des superpositions d'essais ou des objectifs d'étalonnage à partir de CSV, SQLite ou pandas DataFrame ; vérifier les colonnes du schéma de la table de données ; inspecter les tableaux de données existants ; ou vérifiez metadata.public.validForFitnessFunction. N'utilisez pas cette compétence pour les ensembles de sorties ; utilisez jinko-output-set pour cela.
