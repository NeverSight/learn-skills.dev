Erstellen oder überprüfen Sie Jinkō-Datentabellen über das Jinko-SDK. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer beobachtete Daten für Testüberlagerungen oder Kalibrierungsziele aus CSV, SQLite oder Pandas DataFrame hochladen möchte. Überprüfen Sie die Schemaspalten der Datentabelle. Überprüfen Sie vorhandene Datentabellen. oder überprüfen Sie metadata.public.validForFitnessFunction. Verwenden Sie diese Fertigkeit nicht für Ausgabesätze; Verwenden Sie dazu jinko-output-set.
