Cree o inspeccione tablas de datos de Jinkō a través de jinko-sdk. Utilice esta habilidad siempre que el usuario desee cargar datos observados para superposiciones de prueba u objetivos de calibración desde CSV, SQLite o pandas DataFrame; comprobar las columnas del esquema de la tabla de datos; inspeccionar tablas de datos existentes; o verificar metadata.public.validForFitnessFunction. No utilices esta habilidad para conjuntos de salida; use jinko-output-set para eso.
