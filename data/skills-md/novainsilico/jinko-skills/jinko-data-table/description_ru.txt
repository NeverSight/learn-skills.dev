Создайте или проверьте таблицы данных Jinkō с помощью jinko-sdk. Используйте этот навык всякий раз, когда пользователь хочет загрузить наблюдаемые данные для наложений испытаний или целей калибровки из CSV, SQLite или Pandas DataFrame; проверить столбцы схемы таблицы данных; проверить существующие таблицы данных; или проверьте метаданные.public.validForFitnessFunction. Не используйте этот навык для выходных наборов; используйте для этого jinko-output-set.
