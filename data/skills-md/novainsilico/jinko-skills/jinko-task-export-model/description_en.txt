Export a Jinkō computational model to another modeling tool and check the export numerically against Jinkō simple_solve. Targets: SBML, SimBiology code (a MATLAB script that uses SimBiology), SimBiology XLSX, Julia (DifferentialEquations.jl), and nlmixr2/rxode2 in R. Use this skill whenever the user wants to download, export, transfer, or convert a Jinkō model to SBML, MATLAB, SimBiology, Julia, R, nlmixr2, or rxode2, to run a Jinkō model outside Jinkō, to check that an exported model reproduces Jinkō, or to investigate why another solver diverges from Jinkō. Use it even when the user gives only a model link or short ID and names the tool.
