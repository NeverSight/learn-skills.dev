Import a model built in another modeling tool into Jinkō, check that Jinkō accepts and solves it, and, when the user asks, check it numerically against the source tool. Sources: SBML, SimBiology XLSX, a Monolix structural model, a Monolix project (.mlxtran), and a NONMEM run (.mod, .ctl, .lst, .ext, .phi, data set), which becomes a model, vpop, protocol design, output set, and trial checked against a declared reference. Routes a published paper to jinko-task-paper2model. Use this skill whenever the user wants to import, upload, port, translate, or migrate a model file or a NONMEM run into Jinkō, to bring a BioModels, COPASI, SimBiology, Monolix, or NONMEM model to Jinkō, to reproduce a population-PK model that exists as NONMEM code, or to check that an imported model reproduces its source tool, even when the user only gives a file path. Use jinko-model to author a model from scratch and jinko-task-export-model to go from Jinkō to another tool.
