Erstellen, prüfen, laden und organisieren Sie Jinkō-Referenz-PDFs und deren Auszüge über das Jinko-SDK. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen Aufsatz oder eine Quell-PDF-Datei in ein Jinkō-Projekt hochladen, ein Referenz-PDF abrufen möchte, das sich bereits im Projekt befindet, damit es gelesen werden kann, Texthervorhebungen aus einer zitierten Passage erstellen, rechteckige Auszüge oder Formelauszüge erstellen, die Bibliographie eines Aufsatzes oder vorhandene Auszüge überprüfen oder beim Reproduzieren einer Veröffentlichung eine Projektreferenz verwenden möchte. Verwenden Sie es nicht für die Literatursuche, die Modellerstellung oder die Erstellung von Datentabellen.
