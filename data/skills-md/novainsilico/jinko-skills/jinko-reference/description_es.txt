Cree, inspeccione, descargue y organice archivos PDF de referencia de Jinkō y sus extractos a través de jinko-sdk. Utilice esta habilidad siempre que el usuario quiera cargar un artículo o un PDF fuente a un proyecto Jinkō, recuperar un PDF de referencia que ya esté en el proyecto para poder leerlo, crear textos resaltados a partir de un pasaje citado, crear extractos rectangulares o de fórmulas, inspeccionar la bibliografía de un artículo o extractos existentes, o usar una referencia del proyecto mientras reproduce una publicación. No lo utilice para búsqueda de literatura, creación de modelos o creación de tablas de datos.
