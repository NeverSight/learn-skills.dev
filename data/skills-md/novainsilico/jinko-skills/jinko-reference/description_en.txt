Create, inspect, download, and organize Jinkō reference PDFs and their extracts through the jinko-sdk. Use this skill whenever the user wants to upload a paper or source PDF to a Jinkō project, retrieve a reference PDF already in the project so it can be read, create textual highlights from a quoted passage, create rectangular or formula extracts, inspect a paper's bibliography or existing extracts, or use a project reference while reproducing a publication. Do not use it for literature search, model authoring, or data-table creation.
