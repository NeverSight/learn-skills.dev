Eseguire una calibrazione CMA-ES da input Jinkō confermati: assemblare il modello, il protocollo, i set di output, le tabelle dei dati di fitness, i parametri a priori e le opzioni dell'ottimizzatore; creare ed eseguire la calibrazione; e restituire i risultati supportati. Utilizzare quando l'utente desidera eseguire una calibrazione CMA-ES, non quando deve scegliere una strategia di calibrazione, dedurre criteri a priori, obiettivi di progettazione o decidere se i risultati sono accettabili.
