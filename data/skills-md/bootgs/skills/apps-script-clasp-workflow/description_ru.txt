Документирует workflow CLI clasp для проектов Google Apps Script — вход в систему, создание/клонирование проекта, push vs deploy, версионирование и настройки многосредовой (dev/staging/prod) инфраструктуры. Используется при настройке CI/CD для проекта Apps Script, публикации новой версии или переключении между несколькими ID скриптов. Не зависит от фреймворка — применяется как с bootgs, так и без них. Не предназначено для публикации в Marketplace и ревью (`apps-script-marketplace-publish`) и не относится к тому, почему триггер не срабатывает (`apps-script-triggers`).
