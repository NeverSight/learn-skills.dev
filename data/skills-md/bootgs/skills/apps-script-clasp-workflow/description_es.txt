Documenta el flujo de trabajo de la CLI de CLASSP para los proyectos de Google Apps Script: inicio de sesión, creación/clonación de proyectos, push vs deploy, control de versiones y configuraciones de múltiples entornos (dev/staging/prod). Utilícelo al configurar CI/CD para un proyecto de Apps Script, publicar una nueva versión o cambiar entre varios ID de script. Agnóstico de marco: se aplica con o sin bootgs. No apto para anuncios y reseñas de Marketplace (`apps-script-marketplace-publish`), ni por qué no se activa un disparador (`apps-script-triggers`).
