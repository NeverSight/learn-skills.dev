Patrones idiomáticos y seguros en cuanto a cuotas para los servicios integrados y el tiempo de ejecución de Google Apps Script — lecturas/escrituras por lotes de SpreadsheetApp, PropertiesService/CacheService para el estado, LockService para la seguridad de concurrencia, UrlFetchApp con reintentos/retroceso, brechas en la API del runtime V8 y restricciones de funciones personalizadas de hoja de cálculo. Úsalos cuando el código de Apps Script es lento, excede cuotas o genera errores por límites de velocidad, tiene condiciones de carrera por ejecuciones concurrentes de disparadores, o necesita una API de navegador/Node que no exista en Apps Script. Independiente del framework — se aplica con o sin bootgs. No es para menús, barras laterales o diálogos (`apps‑script‑ui`), ni para el registro de disparadores y preguntas de simple vs instalable (`apps‑script‑triggers`).
