Modèles idiomatiques, sûrs pour les quotas, pour les services intégrés et le runtime de Google Apps Script — lectures/écritures groupées de SpreadsheetApp, PropertiesService/CacheService pour l’état, LockService pour la sécurité de la concurrence, UrlFetchApp avec retry/backoff, lacunes de l’API du runtime V8, et contraintes des fonctions personnalisées de feuille de calcul. À utiliser lorsque le code Apps Script est lent, atteint les limites de quota ou de débit, rencontre des conditions de course dues à des exécutions de déclencheurs concurrentes, ou nécessite une API navigateur/Node qui n’existe pas dans Apps Script. Indépendant du framework — s’applique avec ou sans bootgs. Pas pour les menus, barres latérales ou dialogues (`apps‑script‑ui`), ni pour l’enregistrement des déclencheurs et les questions simple vs installable (`apps‑script‑triggers`).
