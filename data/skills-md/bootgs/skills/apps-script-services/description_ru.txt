Идиоматичные, безопасные с точки зрения квот шаблоны для встроенных сервисов и среды выполнения Google Apps Script — пакетные чтения/записи SpreadsheetApp, PropertiesService/CacheService для состояния, LockService для обеспечения безопасной конкурентности, UrlFetchApp с повторными попытками/экспоненциальным откатом, пробелы в API V8 runtime, а также ограничения пользовательских функций таблиц. Используйте, когда код Apps Script работает медленно, превышает квоты или сталкивается с ограничениями частоты запросов, возникают гонки из‑за одновременного выполнения триггеров или требуется API браузера/Node, которого нет в Apps Script. Не зависят от фреймворка — работают с bootgs и без них. Не предназначены для меню, боковых панелей или диалогов (`apps-script-ui`), а также для регистрации триггеров и вопросов о простых vs устанавливаемых триггерах (`apps-script-triggers`).
