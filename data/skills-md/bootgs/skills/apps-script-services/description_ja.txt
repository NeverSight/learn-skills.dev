Google Apps Script の組み込みサービスとランタイム向けの、クォータに安全なイディオムパターン — SpreadsheetApp のバッチ読み書き、状態管理のための PropertiesService / CacheService、同時実行安全性のための LockService、リトライ/バックオフ付きの UrlFetchApp、V8 ランタイムの API ギャップ、カスタムスプレッドシート関数の制約。Apps Script のコードが遅い、クォータやレートリミットエラーに達する、トリガーの同時実行による競合状態が発生する、または Apps Script には存在しないブラウザ／Node API が必要なときに使用する。フレームワークに依存しない — bootgs の有無に関わらず適用できる。メニュー、サイドバー、ダイアログ（`apps‑script‑ui`）や、トリガー登録やシンプルトリガーとインストール可能トリガーの違いに関する質問（`apps‑script‑triggers`）には対象外。
