Cuando el usuario desea implementar datos estructurados de LocalBusiness, esquema de ubicación o marcado JSON-LD específico local. También se usa cuando el usuario menciona "esquema local", "esquema LocalBusiness", "datos estructurados para local", "JSON-LD para empresa", "esquema NAP" o "marcado de empresa local." Para el esquema general, consulte habilidad de marcado de esquema. Para el trabajo de perfil de GBP, consulte optimización de gbp.
