Quando l'utente desidera implementare dati strutturati LocalBusiness, schema di località o markup JSON‑LD specifico per il locale. Usare anche quando l'utente menziona "schema locale", "schema LocalBusiness", "dati strutturati per locale", "JSON‑LD per azienda", "schema NAP" o "markup per attività locale". Per schema generale, vedere la skill schema-markup. Per il lavoro sul profilo GBP, vedere gbp-optimization.

Per favore rispondi sempre nella lingua dell'utente.
