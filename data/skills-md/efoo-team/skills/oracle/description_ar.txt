تشغيل Oracle CLI في وضع متصفح ChatGPT لطلب نموذج سحابي خارجي لتوفير التفكير على مستوى عالي، أو التفصيل، أو المراجعة، أو التقييم النهائي. يُستخدم عندما يحتاج وكيل إلى نموذج ثانٍ لتحليل تعارضات معقدة، أو فحص خطة، أو تقييم فرق، أو تصحيح مشكلة صعبة، أو كشف افتراضات مفقودة. عالج كل تشغيل لـ Oracle كطلب مستقل لا يحتفظ بالحالة، وأرسل النص المطلوب والملفات الضرورية صراحةً لأن Oracle لا يمكنه الوصول إلى موارد الجهاز المحلي أو سياق تشغيل Oracle السابق ما لم يتم توفيرها.
