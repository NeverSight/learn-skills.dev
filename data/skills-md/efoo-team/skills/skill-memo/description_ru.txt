Использовать только когда пользователь явно вызывает /skill-memo (или $skill-memo в Codex). Никогда не вызывайте автоматически. Навык, который записывает проблемы и выводы о рассуждениях и поведении агента, которые вы замечаете и хотите сохранить, в задачу GitHub в репозитории efoo-team/skills. Место записи фиксировано как efoo-team/skills, и если уже существует задача по той же проблеме, он добавляет комментарий как повторение. Сообщение о багах продукта или запросов в репозиторий каждого проекта — это роль issue-report-dev / issue-report-user, и этот навык ограничивается сбором материала для улучшения навыков и файлов инструкций.
