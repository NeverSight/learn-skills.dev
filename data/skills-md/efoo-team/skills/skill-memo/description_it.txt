Usare solo quando l'utente invoca esplicitamente /skill-memo (o $skill-memo in Codex). Mai attivare automaticamente.  
Una skill che registra eventuali problemi osservati nel ragionamento o nel comportamento dell’agente, o qualsiasi intuizione che si desidera conservare, come una issue su GitHub nel repository efoo‑team/skills. La destinazione della registrazione è fissata a efoo‑team/skills e, se esiste già una issue per lo stesso problema, aggiungere un commento come occorrenza ripetuta. Segnalare bug di prodotto o richieste di funzionalità al repository di ciascun progetto è compito di issue‑report‑dev / issue‑report‑user; questa skill è limitata ad accumulare materiale per migliorare i file di skill e di istruzioni.  

Rispondi sempre nella lingua dell’utente.
