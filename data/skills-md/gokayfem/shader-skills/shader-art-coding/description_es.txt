Escribe, depura y dirige artísticamente shaders de fragmento GLSL procedurales (Shadertoy mainImage, WebGL2 / GLSL ES 3.00): raymarching SDF, edificios/ciudades procedurales, gráficos 2D de campos de distancia, ruido / fBm / warping de dominio, terreno, óptica de agua oceánica/costal, nubes y otros volúmenes, iluminación PBR, color y tonemapping. Proporciona una biblioteca verificada de bloques de construcción GLSL con un empaquetador y verificador. Úsalo cuando el usuario solicite un shader, Shadertoy, código GLSL/.frag/.glsl, un raymarcher, una escena SDF, una textura procedural o visual generativo, o quiera un shader corregido, optimizado, portado o explicado. No es para HLSL/Unity ShaderLab ni para cómputo GPU que no sea gráfico.
