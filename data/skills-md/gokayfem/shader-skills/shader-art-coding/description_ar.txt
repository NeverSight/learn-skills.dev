يكتب، يكتشف الأخطاء، ويُدير فنياً شادرزّات شظايا GLSL الإجرائية (Shadertoy mainImage، WebGL2 / GLSL ES 3.00): تتبع أشعة SDF، مبانٍ/مدن إجرائية، رسومات حقل مسافة 2D، الضوضاء / fBm / تشويه المجال، تضاريس، بصرية مياه المحيط/الساحل، سحب وحجوم أخرى، إضاءة PBR، تلوين وتدرج لوني. يُرسل مكتبة كتل بناء GLSL مُتحققة مع مُجمّع ومُدقق. استخدمه عندما يطلب المستخدم شادر، Shadertoy، كود GLSL/.frag/.glsl، متعقّب أشعة، مشهد SDF، نسيج إجرائي أو بصري توليدي، أو يريد تعديل شادر، تحسينه، نقله أو شرحه. ليس مخصصًا لـ HLSL/Unity ShaderLab أو الحوسبة العامة للمعالج الرسومي غير المتعلق بالرسوميات. يرجى دائمًا الرد بلغة المستخدم.
