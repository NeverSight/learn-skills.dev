Recherchieren Sie Architektur-Entscheidungen und erstellen Sie Architektur-Entscheidungs-Protokolle (ADRs). Verwenden Sie diese Methode, wenn Sie vor komplexen technischen Entscheidungen stehen, die eine gründliche Recherche, eine Analyse der Optionen und eine formelle Dokumentation erfordern. Behandelt den Benutzer wie einen CTO für eine kollaborative Entscheidungsfindung. Unterstützt eine evolutionäre Architektur – kann frühere Entscheidungen infrage stellen, wenn es dafür Belege gibt.
