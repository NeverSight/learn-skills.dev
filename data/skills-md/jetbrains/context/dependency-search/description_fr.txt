Recherche expérimentale de dépendances jbcontext à l’échelle de l’organisation dans plusieurs référentiels. À utiliser lorsqu'il est nécessaire de rechercher des API dans d'autres référentiels ou lorsque la configuration des dépendances est utilisée dans les référentiels pour les mises à niveau, les suppressions, les CVE, les migrations ou la découverte de propriété.
