Localizza i test esistenti per una determinata classe e metodo C# utilizzando i dati di copertura dei test forniti dall'IDE. Si attiva SOLO per il codice di produzione C# (`.cs` file in una soluzione Rider .NET) quando si generano nuovi test, si aggiunge copertura di test, si cercano test esistenti, o quando l'utente menziona linee non coperte, file di test o suite di test. Deve essere usato prima di scrivere o modificare codice di test C# quando è necessario trovare test già esistenti. NON attivare per linguaggi non C# — lo strumento sottostante comprende solo simboli C# e non restituirà risultati utili.

Rispondi sempre nella lingua dell'utente.
