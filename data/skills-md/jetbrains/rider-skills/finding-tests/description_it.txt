Localizza i test esistenti per una determinata classe e metodo C# utilizzando i dati di copertura dei test forniti dall'IDE. Si attiva SOLO per il codice di produzione C# (file `.cs` in una soluzione .NET di Rider) durante la generazione di nuovi test, l'aggiunta di copertura dei test, la ricerca di test esistenti o quando l'utente menziona linee non coperte, file di test o suite di test. Deve essere usato prima di scrivere o modificare codice di test C# quando è necessario trovare test già esistenti. NON invocare per linguaggi non C# — lo strumento sottostante comprende solo simboli C# e non restituirà risultati utili.

Rispondi sempre nella lingua dell'utente.
