Findet vorhandene Tests für eine gegebene C#‑Klasse und Methode mithilfe der vom IDE bereitgestellten Testabdeckungsdaten. Wird NUR bei C#‑Produktcode (`.cs`‑Dateien in einer Rider .NET‑Lösung) ausgelöst, wenn neue Tests generiert, Testabdeckung hinzugefügt, vorhandene Tests gefunden werden oder der Benutzer nicht abgedeckte Zeilen, Testdateien oder Testsuiten erwähnt. Muss verwendet werden, bevor C#‑Testcode geschrieben oder bearbeitet wird, wenn das Finden bereits vorhandener Tests erforderlich ist. Nicht für Nicht‑C#‑Sprachen aufrufen – das zugrunde liegende Werkzeug versteht nur C#‑Symbole und liefert keine nützlichen Ergebnisse.
