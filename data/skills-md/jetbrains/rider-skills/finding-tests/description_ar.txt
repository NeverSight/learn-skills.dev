يقوم بتحديد الاختبارات الموجودة لفئة C# معينة وطريقة معينة باستخدام بيانات تغطية الاختبار التي يوفرها بيئة التطوير المتكاملة. يتم تشغيله فقط على شفرة الإنتاج C# (ملفات `.cs` في حل Rider .NET) عند إنشاء اختبارات جديدة، إضافة تغطية اختبار، العثور على الاختبارات الحالية، أو عندما يذكر المستخدم أسطرًا غير مغطاة أو ملفات اختبار أو مجموعة اختبارات. يجب استعماله قبل كتابة أو تعديل شفرة اختبار C# عندما يكون العثور على الاختبارات الموجودة أمرًا ضروريًا. لا تقم بتفعيل الأداة للغات غير C# — الأداة الأساسية لا تفهم سوى رموز C# ولن تُعيد نتائج مفيدة. يرجى دائمًا الرد بلغة المستخدم.
