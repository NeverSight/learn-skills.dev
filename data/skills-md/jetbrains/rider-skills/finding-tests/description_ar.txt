يحدد الاختبارات الموجودة لفئة C# وطريقة معينة باستخدام بيانات تغطية الاختبار التي يوفرها IDE. يتم تفعيلها فقط لكود الإنتاج C# (ملفات `.cs` في حل Rider .NET) عند إنشاء اختبارات جديدة، إضافة تغطية اختبار، البحث عن الاختبارات الموجودة، أو عندما يذكر المستخدم أسطرًا غير مغطاة، ملفات اختبار، أو مجموعات اختبار. يجب استخدامها قبل كتابة أو تعديل كود اختبار C# عندما يكون من الضروري العثور على الاختبارات الموجودة بالفعل. لا تستخدمها للغات غير C# — الأداة الأساسية لا تفهم سوى رموز C# ولن تعطي نتائج مفيدة.

يرجى دائمًا الرد بلغة المستخدم.
