Localiza pruebas existentes para una clase y método C# dados utilizando los datos de cobertura de pruebas suministrados por el IDE. Se activa SOLO para código de producción C# (archivos `.cs` en una solución .NET de Rider) al generar nuevas pruebas, añadir cobertura de pruebas, encontrar pruebas existentes, o cuando el usuario menciona líneas sin cubrir, archivos de prueba o suites de prueba. Debe usarse antes de escribir o editar código de pruebas C# cuando sea necesario encontrar pruebas ya existentes. NO lo invoques para lenguajes que no sean C# — la herramienta subyacente solo entiende símbolos de C# y no devolverá resultados útiles.
