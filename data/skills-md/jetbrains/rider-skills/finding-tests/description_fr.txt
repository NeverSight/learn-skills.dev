Localise les tests existants pour une classe et une méthode C# données en utilisant les données de couverture de tests fournies par l'IDE. Se déclenche UNIQUEMENT pour le code de production C# (fichiers `.cs` dans une solution Rider .NET) lors de la génération de nouveaux tests, de l'ajout de couverture de test, de la recherche de tests existants, ou lorsque l'utilisateur mentionne des lignes non couvertes, des fichiers de test ou des suites de test. Doit être utilisé avant d'écrire ou de modifier du code de test C# lorsque la recherche de tests déjà existants est nécessaire. Ne PAS invoquer pour des langages non C# — l'outil sous-jacent ne comprend que les symboles C# et ne renverra pas de résultats utiles.

Veuillez toujours répondre dans la langue de l'utilisateur.
