Находит существующие тесты для указанного класса и метода C# с использованием данных о покрытии тестами, предоставленных IDE. Срабатывает ТОЛЬКО для производственного кода C# (файлы `.cs` в решении Rider .NET) при генерации новых тестов, добавлении покрытия тестами, поиске существующих тестов или когда пользователь упоминает незакрытые строки, файлы тестов или наборы тестов. Должен использоваться перед написанием или редактированием кода тестов C#, когда необходимо найти уже существующие тесты. Не вызывайте для нереляционных языков — базовый инструмент понимает только символы C# и не вернёт полезных результатов.
