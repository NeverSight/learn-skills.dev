Находит существующие тесты для заданного класса и метода C# с использованием данных о покрытии тестами, предоставляемых IDE. Срабатывает ТОЛЬКО для производственного кода C# (файлы `.cs` в решении Rider .NET) при создании новых тестов, добавлении покрытия тестами, поиске существующих тестов или когда пользователь упоминает непокрытые строки, тестовые файлы или наборы тестов. Должен использоваться перед написанием или редактированием кода тестов C# в случаях, когда необходимо найти уже существующие тесты. НЕ вызывайте для языков, отличных от C# — базовый инструмент понимает только символы C# и не вернёт полезных результатов.  

Пожалуйста, всегда отвечайте на языке пользователя.
