Шаблоны эндпоинтов API Django Ninja, включая роутеры, уровни аутентификации, типизированные запросы и модели ввода/вывода Pydantic.  
Используйте при написании или рецензировании эндпоинтов API Django Ninja, роутеров или конфигурации аутентификации. Также используйте при создании новых модулей API или добавлении эндпоинтов.  
Не используйте для: представлений Django, возвращающих HTML (используйте навык Django), FastAPI, DRF (Django REST Framework) или общих шаблонов Django.
