أنماط نقاط النهاية في Django Ninja API بما في ذلك الموجهات، طبقات المصادقة، الطلبات المطبقة بالنوع، ونماذج الإدخال/الإخراج من Pydantic.  
استخدمه عند كتابة أو مراجعة نقاط النهاية في Django Ninja API أو الموجهات أو تكوين المصادقة. كما يُستعمل عند إنشاء وحدات API جديدة أو إضافة نقاط نهاية.  
لا تستخدمه لـ: العروض في Django التي تُعيد HTML (استخدم مهارة Django)، FastAPI، DRF (إطار عمل Django REST)، أو الأنماط العامة في Django.  
يرجى دائمًا الرد بلغة المستخدم.
