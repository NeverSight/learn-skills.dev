Audita, progetta o aggiorna la configurazione di GitHub Dependabot in `.github/dependabot.yml`. Usalo quando esamini se Dependabot è configurato correttamente, riducendo il rumore delle PR di dipendenze, raggruppando gli aggiornamenti, impostando pianificazioni o cooldown, coprendo monorepo ed ecosistemi di pacchetti, o documentando aggiornamenti bloccati. Usalo anche quando ti chiedono le migliori pratiche per Dependabot o perché Dependabot apre troppe o troppe poche PR. NON usarlo per elaborare, testare, correggere o fondere una coda esistente di pull request di Dependabot; usa la skill dependabot‑prs per questo.
