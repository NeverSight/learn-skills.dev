Auditar, diseñar o actualizar la configuración de GitHub Dependabot en `.github/dependabot.yml`.  
Utilícelo al revisar si Dependabot está configurado correctamente, reducir el ruido de PRs de dependencias, agrupar actualizaciones, establecer horarios o periodos de enfriamiento, cubrir monorepos y ecosistemas de paquetes, o documentar actualizaciones bloqueadas. También úselo cuando le soliciten las mejores prácticas de Dependabot o por qué Dependabot abre demasiados o muy pocos PRs.  
NO lo use para procesar, probar, corregir o fusionar una cola existente de pull requests de Dependabot; use la skill dependabot‑prs para eso.
