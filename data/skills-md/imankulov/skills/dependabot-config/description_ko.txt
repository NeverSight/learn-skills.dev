`.github/dependabot.yml` 파일에서 GitHub Dependabot 설정을 감사하고, 설계하거나 업데이트합니다.  
Dependabot이 올바르게 설정되었는지 검토하고, 의존성 PR 소음을 줄이며, 업데이트를 그룹화하고, 일정이나 쿨다운을 설정하며, 모노리포와 패키지 생태계를 포괄하거나 차단된 업그레이드를 문서화할 때 사용하십시오.  
또한 Dependabot 모범 사례를 요청받거나 Dependabot이 너무 많거나 너무 적은 PR을 여는 이유에 대해 질문받을 때도 사용하십시오.  
기존 Dependabot 풀 요청 큐를 처리, 테스트, 수정 또는 병합하는 데는 사용하지 마세요; 해당 작업은 dependabot-prs 스킬을 사용하십시오.  
항상 사용자의 언어로 응답해 주세요.
