`.github/dependabot.yml` にある GitHub Dependabot の設定を監査、設計、または更新します。Dependabot が正しく設定されているかのレビューや、依存関係 PR のノイズ削減、更新のグループ化、スケジュールやクールダウンの設定、モノレポやパッケージエコシステムへの対応、ブロックされたアップグレードの文書化を行う際に使用してください。また、Dependabot のベストプラクティスや、なぜ Dependabot が PR を多すぎる・少なすぎるのかといった質問にも使用します。既存の Dependabot プルリクエストのキューを処理・テスト・修正・マージする目的で使用しないでください。その場合は dependabot‑prs スキルを使用してください。
