Normes de test Pytest mettant l’accent sur le modèle AAA, les fixtures et la paramétrisation.  
À utiliser lors de l’écriture ou de la révision de tests Python avec pytest, y compris les tests Django.  
Couvre l’organisation des fixtures, les modèles d’accès à la base de données, les tests d’API et les clients factices.  
Ne PAS utiliser pour : les tests JavaScript/TypeScript, les tests de type unittest ou les frameworks non pytest.
