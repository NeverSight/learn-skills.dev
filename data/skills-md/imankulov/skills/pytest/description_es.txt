Estándares de pruebas con pytest que enfatizan el patrón AAA, fixtures y parametrización.  
Úsese al escribir o revisar pruebas de Python con pytest, incluidas pruebas de Django.  
Cubre la organización de fixtures, patrones de acceso a bases de datos, pruebas de API y clientes simulados.  
NO usar para: pruebas de JavaScript/TypeScript, pruebas estilo unittest o frameworks que no sean pytest.
