Standard di test Pytest che enfatizzano il pattern AAA, i fixture e la parametrizzazione.  
Da utilizzare quando si scrivono o si revisionano test Python con pytest, inclusi i test Django.  
Copre l'organizzazione dei fixture, i pattern di accesso al database, il testing delle API e i client mock.  
NON utilizzare per: test JavaScript/TypeScript, test in stile unittest o framework non pytest.
