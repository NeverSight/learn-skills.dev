Esegue un audit di un codebase per i cinque fallimenti di sicurezza più comuni lasciati dal codice generato da IA — tabelle Supabase/Firebase senza Row Level Security, autorizzazione gestita nel frontend, rotte API che recuperano dati per ID senza verificare la proprietà (IDOR/BOLA), chiavi API e segreti esposti nel bundle o nella cronologia Git, e input utente non validati (XSS, upload senza restrizioni, nessun limite di velocità). Usa questa capacità ogni volta che l'utente richiede di revisionare, auditare, rinforzare o “controllare la sicurezza di” un’applicazione — soprattutto prima di qualsiasi deploy, lancio o domanda “è sicuro rilasciare?”. Usala anche quando l'utente menziona vibe coding, Supabase, RLS, chiavi API trapelate, test di penetrazione della propria app, o segnala che uno scanner ha identificato un problema. Produce un report di riscontri con file, riga, gravità ed evidenza; non modifica il codice — abbinalo a vibe‑fix per la correzione.

Rispondi sempre nella lingua dell'utente.
