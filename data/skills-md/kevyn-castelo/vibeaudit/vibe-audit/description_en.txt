Audits a codebase for the five security failures that AI-generated code leaves behind most often — Supabase/Firebase tables without Row Level Security, authorization decided in the frontend, API routes that fetch by ID without checking ownership (IDOR/BOLA), API keys and secrets exposed in the bundle or Git history, and unvalidated user input (XSS, unrestricted upload, no rate limit). Use this skill whenever the user asks to review, audit, harden, or "check the security of" an application — and especially before any deploy, launch, or "is this safe to ship?" question. Also use it when the user mentions vibe coding, Supabase, RLS, leaked API keys, penetration testing their own app, or says a scanner flagged something. It produces a findings report with file, line, severity and evidence; it does not modify code — pair it with vibe-fix for remediation.
