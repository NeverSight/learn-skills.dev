Audite une base de code pour les cinq failles de sécurité que le code généré par IA laisse le plus souvent — tables Supabase/Firebase sans sécurité au niveau des lignes (Row Level Security), autorisation décidée côté front, routes API qui récupèrent par ID sans vérifier la propriété (IDOR/BOLA), clés API et secrets exposés dans le bundle ou l’historique Git, et entrées utilisateur non validées (XSS, téléchargement sans restriction, aucune limitation de débit). Utilisez cette compétence chaque fois que l’utilisateur demande de réviser, auditer, renforcer ou « vérifier la sécurité de » une application — et surtout avant tout déploiement, lancement ou question du type « est‑ce sûr à livrer ? ». Utilisez‑la également lorsque l’utilisateur mentionne le codage vibe, Supabase, RLS, des clés API fuitées, des tests de pénétration de sa propre application, ou signale qu’un scanner a détecté quelque chose. Elle produit un rapport de constatations avec le fichier, la ligne, la gravité et les preuves ; elle ne modifie pas le code — combinez‑la avec vibe‑fix pour la remédiation.
