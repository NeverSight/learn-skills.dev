يقوم بتدقيق قاعدة الشيفرة للعثور على الأخطاء الأمنية الخمسة التي يتركها الكود المولّد بواسطة الذكاء الاصطناعي في أغلب الأحيان — جداول Supabase/Firebase بدون أمان على مستوى الصف، اتخاذ قرارات التفويض في الواجهة الأمامية، مسارات API التي تستخرج بالمعرف دون التحقق من الملكية (IDOR/BOLA)، مفاتيح API والسرية المكشوفة في الحزمة أو سجل Git، ومدخلات المستخدم غير المُتحقّق منها (XSS، رفع غير مقيد، عدم وجود حد للسرعة). استخدم هذه المهارة كلما طلب المستخدم مراجعة، تدقيق، تعزيز، أو "التحقق من أمان" تطبيق — وخاصةً قبل أي نشر، إطلاق، أو سؤال "هل هذا آمن للإصدار؟". كذلك استخدمها عندما يذكر المستخدم برمجة vibe، Supabase، RLS، مفاتيح API المسربة، اختبار اختراق لتطبيقه الخاص، أو عندما يقول إن الماسح الضوئي أشار إلى شيء ما. تنتج تقريرًا بالنتائج يشتمل على الملف، السطر، الخطورة والدليل؛ ولا تقوم بتعديل الشيفرة — اجمعها مع vibe-fix لتصحيح الثغرات.
