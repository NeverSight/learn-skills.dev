프로젝트 위키에서 설계된 기능 또는 ChangeRequest에 대해 추적 가능한 테스트 스위트와 테스트 케이스를 설계합니다. 요구사항이 초안이거나 합의된 상태일 때—단위, 통합, e2e, 부하 또는 보안 스위트, 위험을 포함한 파일당 하나의 케이스, 번호가 매겨진 구체적인 데이터, 요청 및 응답 페이로드와 명시적인 검증 단계, 그리고 스위트별로 생성된 체크리스트를 제공하여 모든 요구사항, 계약 및 실패 분기를 포괄합니다. QA, 개발자, 보안 또는 성능 담당자가 설계에서 테스트 설계나 테스트 커버리지가 필요할 때, 혹은 사양이 테스트 설계 이후 변경될 때 사용합니다. 실행 가능한 테스트 코드를 작성하지 않으며, 요구사항, 아키텍처 또는 작업을 위한 것이 아닙니다.
