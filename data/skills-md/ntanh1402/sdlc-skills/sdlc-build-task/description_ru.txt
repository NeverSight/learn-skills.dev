Напишите код и модульные тесты для одной задачи из вики в одном репозитории, ориентируясь на вики проекта — прочитайте критерии приемки задачи и её запланированный объём, контракты файлов дизайна, которые она охватывает, и конвенции приложения, спланируйте файлы, создайте их в git‑worktree на отдельной ветке, проверьте соответствие вики и выполните коммит с трейлером задачи, не отправляя изменения. Используйте, когда разработчик просит построить, реализовать или закодировать задачу из вики проекта. Не предназначено для кодирования без задачи из вики, для изменения вики, для запуска тестов, для пуша или открытия pull‑request, а также для завершения задачи.
