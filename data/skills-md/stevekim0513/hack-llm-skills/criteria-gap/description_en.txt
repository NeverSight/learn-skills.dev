In conversations with an LLM, identify points where the user delegated tasks without a judgment standard (e.g., source-selection criteria, standards for good results), ask for the criteria, compare them with the implicit criteria the AI generated, and have the AI provide them again if needed. This is used for requests such as “Analyze the conversation,” “Check if the criteria are missing,” “What did I ask for without realizing?,” “Review this session,” and “Verify before delegating.” Storing and retrieving criteria is done with the criteria skill.
