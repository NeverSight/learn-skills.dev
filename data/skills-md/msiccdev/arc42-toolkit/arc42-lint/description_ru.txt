Проверяет согласованность ID между разделами в документации arc42, соответствующей конвенциям этого инструментария. Проверяет ID интерфейсов toolkit IF-xx (Раздел 3↔Раздел 5), покрытие развертывания блоков построения (Раздел 5↔Раздел 7), трассируемость тега качества Q42 (Раздел 1↔Раздел 10), ссылки на риски ADR инструментария (Раздел 9↔Раздел 11) и связь с целевыми сценариями (Раздел 10↔Раздел 11). Запускает автоматический скрипт линтера, если он доступен, либо применяет правила вручную, если нет.
