Vous avez créé un jeu. gg. Transforme un jeu web en une courte bande‑annonce jouée en direct dans son propre moteur : Claude écrit le film, l’ouvre dans un studio pour que vous le modifiiez, puis exporte le MP4 avec sa musique, son affiche et son texte de partage. Utilisez‑le quand quelqu’un dit « /gg » ou « let's gg this », ou lorsqu’on demande une bande‑annonce, un teaser, une vidéo de lancement, un montage de gameplay, un clip « coming soon », un écran de fin ou une révélation de logo pour un jeu web (three.js, React Three Fiber, canvas, Phaser, DOM). Utilisez‑le aussi pour ajouter ou corriger une prise dans le studio de bande‑annonce.
