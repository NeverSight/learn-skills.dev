Utiliza esta habilidad cuando una solicitud implique el diseño de la topología de mensajes de RabbitMQ, el análisis de la fiabilidad, las operaciones del agente, la configuración del clúster o de la seguridad, la monitorización, la resolución de problemas o la optimización del rendimiento. Utiliza RabbitMQ 4.3 estable de forma predeterminada y mantén las directrices de desarrollo independientes del lenguaje. No utilice esta habilidad para API de cliente específicas de un lenguaje, para la implementación de sitios web ni para el contenido de blogs.
