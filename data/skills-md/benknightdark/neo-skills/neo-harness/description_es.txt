Utiliza esta habilidad cuando necesites inspeccionar la base de código de un proyecto objetivo y generar o mejorar un archivo AGENTS.md personalizado y completo (especificación del flujo de trabajo de Harness) que imponga reglas estrictas para el uso de agentes de IA, sensores de retroalimentación, procedimientos operativos estándar de ejecución, topologías de orquestación y límites de seguridad. Admite la ejecución de scripts no interactivos a través de scripts/generate-agents-md.py. El archivo AGENTS.md generado NO DEBE superar los 32 KiB de tamaño.
