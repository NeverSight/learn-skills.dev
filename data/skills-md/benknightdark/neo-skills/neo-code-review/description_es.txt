Utiliza esta habilidad cuando el usuario pida revisar o auditar el código fuente, una solicitud de PR, un diff, una confirmación o cambios recientes en busca de errores, problemas de seguridad, rendimiento, pruebas, compatibilidad o mantenibilidad, código o lógica duplicados en varios archivos o valores codificados de forma rígida. Úsala también cuando un agente de IA termine de modificar el código para inspeccionar el árbol de trabajo actual sin confirmar antes de entregarlo e informar de los hallazgos procesables con pruebas de archivos y líneas.
