Utilisez cette compétence lorsque l’utilisateur demande d’examiner ou d’auditer le code source, une PR, un diff, une validation ou des modifications récentes pour détecter des bugs, des problèmes de sécurité, de performance, de tests, de compatibilité ou de maintenabilité, du code ou une logique dupliqués dans plusieurs fichiers, ou des valeurs codées en dur. Utilisez-la également lorsqu'un agent d'IA a fini de modifier du code afin d'inspecter l'arborescence de travail actuelle non validée avant le transfert et de signaler les résultats exploitables avec des preuves au niveau des fichiers et des lignes.
