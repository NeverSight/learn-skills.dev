AI Diff Reviewer GitHub Action 的本地和 CI 伴侣（GitHub 上的 DailybotHQ/ai-diff-reviewer、市场上的“AI Diff Reviewer”）。具有五种功能的路由器 - (1) 使用与 CI 操作相同的方法对当前分支的 diff 进行本地审查，(2) 通过 `generate-extension` 子技能生成 repo 定制的 `.review/extension.md`，(3) 通过 `setup` 子技能在尚未包含 GitHub Action 的存储库中安装和配置 GitHub Action 本身（也兼作每个 `action.yml` 输入的参考手册）， (4) 通过“open-pr”子技能从当前分支的 diff（常规提交标题推断、结构化正文、PR 模板合并、“gh pr create”/“edit”）编写记录良好的拉取请求，(5) 阅读当前分支的开放 PR 上发布的 CI 操作的 AI 审查，以与本地审查相同的格式呈现发现结果，并可选择引导开发人员完成每个发现以应用/推迟/跳过（多分支感知、通过“apply-review”子技能，每次发现同意，不提交/推送）。自动检测`.review/extension.md`（或`.github/ai-diff-reviewer/extension.md`作为后备）并将其分层在提供的默认提示之上，以实现完整的本地↔CI奇偶校验。当开发人员想要在推送之前进行本地飞行前审查、询问“对我当前的更改运行代码审查”、想要自定义此存储库的审查者、询问“如何设置 ai diff 审查者？”、询问有关任何操作输入的参考式问题、要求“打开 PR”、“创建拉取请求”或“编写 PR 正文”时使用，或者询问“CI 审查说了什么？”、“应用 AI审查的修复”，或“引导我了解审查结果”。
