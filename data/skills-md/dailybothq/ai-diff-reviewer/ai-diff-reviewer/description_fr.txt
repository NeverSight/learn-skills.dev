Compagnon local et CI de l'action GitHub AI Diff Reviewer (DailybotHQ/ai-diff-reviewer sur GitHub, "AI Diff Reviewer" sur le Marketplace). Routeur pour cinq fonctionnalités — (1) exécuter une révision locale du diff de la branche actuelle en utilisant la MÊME méthodologie que l'action CI, (2) générer un dépôt `.review/extension.md` personnalisé via la sous-compétence `generate-extension`, (3) installer et configurer l'action GitHub elle-même dans un dépôt qui ne l'a pas encore via la sous-compétence `setup` (qui sert également de manuel de référence pour chaque `action.yml`), (4) rédiger une demande d'extraction bien documentée à partir du diff de la branche actuelle (inférence de titre Conventional-Commits, corps structuré, fusion de modèles PR, `gh pr create`/`edit`) via la sous-compétence `open-pr`, (5) lire la revue d'IA que l'action CI a publiée sur le PR ouvert de la branche actuelle, présenter les résultats dans le même format que la revue locale et éventuellement guider le développeur à travers chaque découverte pour appliquer/différer/ignorer (consentement par recherche multi-étapes, pas de validation/push) via la sous-compétence « appliquer-réviser ». Détecte automatiquement `.review/extension.md` (ou `.github/ai-diff-reviewer/extension.md` comme solution de secours) et le superpose à l'invite par défaut fournie pour une parité locale↔CI complète. À utiliser lorsque le développeur souhaite une révision locale préalable avant de pousser, demande « exécuter une révision de code sur mes modifications actuelles », souhaite personnaliser le réviseur pour ce dépôt, demande « comment configurer un réviseur de diff ai ? correctifs », ou « expliquez-moi les résultats de l'examen ».
