Локальный и CI-компаньон для действия AI Diff Reviewer GitHub Action (DailybotHQ/ai-diff-reviewer на GitHub, «AI Diff Reviewer» на торговой площадке). Маршрутизатор для пяти возможностей: (1) запустить локальную проверку различий текущей ветки, используя ТОТ ЖЕ методологию, что и действие CI, (2) создать адаптированный для репозитория `.review/extension.md` с помощью поднавыка `generate-extension`, (3) установить и настроить само действие GitHub в репозитории, в котором его еще нет, с помощью поднавыка `setup` (также служит справочным руководством для каждого ввод `action.yml`), (4) создать хорошо документированный запрос на извлечение из различий текущей ветки (вывод заголовка с использованием обычных коммитов, структурированное тело, слияние PR-шаблонов, `gh pr create`/`edit`) с помощью поднавыка `open-pr`, (5) прочитать ИИ, просмотреть действие CI, опубликованное обратно в открытом PR текущей ветки, представить результаты в том же формате, что и локальный обзор, и, при необходимости, помочь разработчику пройти через каждый вывод, чтобы применить/отложить/пропустить (с учетом нескольких этапов, согласие по каждому обнаружению, без фиксации/нажатия) с помощью поднавыка Apply-Review. Автоматически определяет `.review/extension.md` (или `.github/ai-diff-reviewer/extension.md` как запасной вариант) и накладывает его поверх поставляемого приглашения по умолчанию для полной четности local↔CI. Используйте, когда разработчик хочет провести локальную предполетную проверку перед отправкой, просит «провести проверку кода моих текущих изменений», хочет настроить рецензента для этого репозитория, спрашивает «как мне настроить ai diff Reviewer?», задает справочный вопрос о любых входных данных действия, просит «открыть запрос на включение», «создать запрос на включение» или «написать тело PR» для текущей ветки или спрашивает: «Что сказано в обзоре CI?», «применить AI». исправления обзора» или «познакомьте меня с выводами обзора».
