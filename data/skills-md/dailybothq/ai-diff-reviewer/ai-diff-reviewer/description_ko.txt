AI Diff Reviewer GitHub Action의 로컬 및 CI 동반자(GitHub의 DailybotHQ/ai-diff-reviewer, Marketplace의 "AI Diff Reviewer"). 5가지 기능을 위한 라우터 — (1) CI 작업으로 SAME 방법론을 사용하여 현재 분기의 diff에 대한 로컬 검토 실행, (2) `generate-extension` 하위 기술을 통해 저장소 맞춤형 `.review/extension.md` 생성, (3) `setup` 하위 기술을 통해 아직 포함되지 않은 저장소에 GitHub Action 자체를 설치 및 구성(또한 모든 `action.yml` 입력에 대한 참조 매뉴얼로도 사용됨), (4) `open-pr` 하위 기술을 통해 현재 분기의 diff(기존 커밋 제목 추론, 구조화된 본문, PR 템플릿 병합, `gh pr create`/`edit`)에서 잘 문서화된 끌어오기 요청을 작성하고, (5) 현재 분기의 공개 PR에 다시 게시된 CI 작업의 AI 검토를 읽고, 결과를 로컬 검토와 동일한 형식으로 제시하고, 선택적으로 각 결과를 통해 개발자에게 적용/연기/건너뛰기를 안내합니다. (다단계 인식, 결과별 동의, 커밋/푸시 없음) '적용-검토' 하위 기술을 통해. '.review/extension.md'(또는 대체 수단으로 '.github/ai-diff-reviewer/extension.md')를 자동 감지하고 전체 로컬 CIS 패리티를 위해 제공된 기본 프롬프트 위에 레이어를 추가합니다. 개발자가 푸시하기 전에 로컬 사전 검토를 원할 때, "현재 변경 사항에 대한 코드 검토 실행", 이 리포지토리에 대한 검토자를 사용자 정의하고 싶을 때, "AI 차이점 검토자를 어떻게 설정합니까?"라고 묻고, 작업 입력에 대해 참조 스타일 질문을 하고, 현재 분기에 대해 "PR 열기", "풀 요청 생성" 또는 "PR 본문 작성"을 요청하거나, "CI 검토에서 뭐라고 말했습니까?", "AI 검토 적용"을 묻는 경우에 사용합니다. 수정' 또는 '검토 결과를 안내해 드립니다.'
