AI Diff Reviewer GitHub Action (GitHub 上の DailybotHQ/ai-diff-reviewer、Marketplace 上の「AI Diff Reviewer」) のローカルおよび CI コンパニオン。 5 つの機能を備えたルーター — (1) CI アクションと同じ方法論を使用して現在のブランチの差分のローカル レビューを実行する、(2) `generate-extension` サブスキルを介してリポジトリに合わせた `.review/extension.md` を生成する、(3) まだ存在しないリポジトリに GitHub アクション自体を `setup` サブスキルを介してインストールおよび設定する (すべてのアクションのリファレンス マニュアルとしても機能します) (4) 「open-pr」サブスキルを使用して、現在のブランチの差分 (従来型コミットのタイトル推論、構造化ボディ、PR テンプレートのマージ、「gh pr create」/「edit」) から十分に文書化されたプル リクエストを作成します。(5) 現在のブランチのオープン PR にポストバックされた CI アクションの AI レビューを読み取り、ローカル レビューと同じ形式で結果を提示し、オプションで開発者は、「apply-review」サブスキルを介して、各検出結果を適用/延期/スキップすることができます (マルチレッグ対応、検出ごとの同意、コミット/プッシュなし)。 `.review/extension.md` (またはフォールバックとして `.github/ai-diff-reviewer/extension.md`) を自動検出し、完全な local↔CI パリティの出荷時のデフォルト プロンプトの上に重ねます。開発者がプッシュする前にローカルのプリフライト レビューが必要な場合、「現在の変更に対してコード レビューを実行する」、このリポジトリに対してレビューアーをカスタマイズしたい場合、「AI 差分レビューアーを設定するにはどうすればよいですか?」、アクションの入力に関する参照形式の質問、現在のブランチの「PR を開く」、「プル リクエストを作成する」、または「PR ボディを作成する」、または「CI レビューで何と言われたか?」、「AI を適用する」を尋ねる場合に使用します。レビューの修正」または「レビューの結果を説明してください」。
