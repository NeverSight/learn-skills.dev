Transport Lore fonctionne entre le dépôt local et les dépôts Git distants via fetch et push sur refs/lore/*. Utilisez-le lorsque l'utilisateur demande de synchroniser le lore, pousser le lore, récupérer le lore, tirer le lore, partager le lore ou vérifier l'état du lore par rapport à un dépôt distant.
