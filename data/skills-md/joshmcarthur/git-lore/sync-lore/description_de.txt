Transport Lore funktioniert zwischen dem lokalen Repository und Git‑Remotes über fetch und push auf refs/lore/*. Verwenden Sie es, wenn der Benutzer nach dem Synchronisieren von Lore, Pushen von Lore, Holen von Lore, Pullen von Lore, Teilen von Lore oder dem Prüfen des Lore‑Status gegenüber einem Remote fragt.
