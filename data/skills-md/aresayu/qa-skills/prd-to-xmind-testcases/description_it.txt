Genera una struttura a mappa mentale dei casi di test che possa essere importata in XMind basata su documenti di requisiti o PRD. Può leggere i file di requisito (PRD/PDF, ecc.) dalla cartella requirements di questa skill, oppure generare da un percorso fornito dall'utente o da contenuto incollato. Suddividi per funzione/modulo, con punti di test sotto ogni voce (titolo + brevi passaggi/risultati attesi). Se interfacce o prestazioni non sono menzionate, imposta come predefinito la generazione secondo le specifiche generali di test; se il testing di interfaccia o di prestazioni è menzionato, carica le specifiche corrispondenti dalle referenze. Usa questo quando l'utente dice “leggi il file di requisito e genera i casi di test,” “genera casi di test in mappa mentale,” ecc. Supporta .docx, .pdf, .txt, .md.

Rispondi sempre nella lingua dell'utente.
