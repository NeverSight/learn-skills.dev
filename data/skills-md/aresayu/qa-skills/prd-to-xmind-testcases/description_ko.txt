요구사항 문서나 PRD를 기반으로 XMind에 가져올 수 있는 테스트 케이스 마인드맵 개요를 생성합니다. Skill의 requirements 디렉터리에서 요구사항 파일(PRD/PDF 등)을 읽어오거나, 사용자가 제공한 경로나 붙여넣은 내용으로 생성할 수 있습니다. 기능/모듈별로 구분하고, 각 항목에 테스트 포인트(제목 + 간단한 단계/예상 결과)를 나열합니다. 인터페이스나 성능에 대한 언급이 없을 경우 일반 테스트 표준에 따라 기본 생성하고, 인터페이스 또는 성능 테스트가 언급된 경우 참고 문서에서 해당 사양을 로드합니다. 사용자가 “요구사항 파일을 읽고 테스트 케이스 생성”, “마인드맵 테스트 케이스 생성” 등이라고 말할 때 사용합니다. .docx, .pdf, .txt, .md를 지원합니다.
