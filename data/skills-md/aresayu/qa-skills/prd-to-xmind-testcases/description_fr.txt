Générez une esquisse de carte mentale de cas de test qui peut être importée dans XMind à partir de documents d’exigences ou de PRD. Elle peut lire les fichiers d’exigences (PRD/PDF, etc.) depuis le répertoire requirements de cette compétence, ou générer à partir d’un chemin fourni par l’utilisateur ou d’un contenu collé. Divisez par fonction/module, avec des points de test sous chaque élément (titre + brèves étapes/résultats attendus). Si les interfaces ou la performance ne sont pas mentionnées, générez par défaut selon les spécifications de test générales ; si les tests d’interface ou de performance sont mentionnés, chargez les spécifications correspondantes depuis les références. Utilisez cela lorsque l’utilisateur dit « lire le fichier d’exigences et générer des cas de test », « générer des cas de test sous forme de carte mentale », etc. Prise en charge des .docx, .pdf, .txt, .md.
