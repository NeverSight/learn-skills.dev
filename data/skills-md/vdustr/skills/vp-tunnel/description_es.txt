Usa cuando algo fuera de esta máquina debe acceder a un servicio local: una página desplegada o pública cuyas peticiones a localhost, un proxy local o un WebSocket local se bloquean, se quedan colgadas o fallan con net::ERR_BLOCKED_BY_CLIENT (Chrome Local Network Access); un webhook; un proveedor OAuth que rechaza redirecciones a localhost; un teléfono fuera de la LAN; un navegador remoto o en la nube; o un compañero o cliente que visualiza una demo. También úsalo cuando se solicite exponer o compartir localhost, obtener una URL pública o comparar ngrok, cloudflared, trycloudflare, tmole o sus alternativas. Decide si se necesita un túnel, controla la exposición y elige la herramienta. Límite: no es para clientes locales que acceden a localhost, para iniciar servidores de desarrollo, ni para usar un túnel como infraestructura de producción; la documentación de cada herramienta cubre sus comandos, y vp-long-running-processes es responsable del proceso.
