Manage Celigo Storage -- the file and folder store built into integrator.io that flows, MCP servers, trading partners and people share -- plus Storage Query (read-only SQL over stored files) and the Celigo-hosted SFTP file server. Covers stable item ids, integration system folders, upload, move, copy, merge and replace, the recycle bin and the storage quota. Use when uploading, finding, organizing, restoring or purging stored files, reading the storage quota, querying a stored CSV, JSON or Parquet file, or giving a trading partner SFTP access.
