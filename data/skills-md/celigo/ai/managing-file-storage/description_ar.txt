إدارة تخزين Celigo — مخزن الملفات والمجلدات المدمج في integrator.io والذي يشاركه التدفقات وخوادم MCP والشركاء التجاريون والأشخاص — بالإضافة إلى استعلام التخزين (SQL للقراءة فقط على الملفات المخزنة) وخادم ملفات SFTP المستضاف من قبل Celigo. يغطي معرفات العناصر المستقرة، ومجلدات نظام التكامل، والرفع، والنقل، والنسخ، والدمج والاستبدال، وسلة المهملات، وحصة التخزين. يُستخدم عند رفع الملفات المخزنة، أو العثور عليها، أو تنظيمها، أو استعادتها أو تنظيفها، أو قراءة حصة التخزين، أو استعلام ملف CSV أو JSON أو Parquet مخزن، أو منح شريك تجاري وصول SFTP.
