Gestisci Celigo Storage — l'archivio di file e cartelle integrato in integrator.io che i flussi, i server MCP, i partner commerciali e le persone condividono — oltre a Storage Query (SQL di sola lettura sui file archiviati) e al server SFTP ospitato da Celigo. Include ID elemento stabili, cartelle di sistema di integrazione, caricamento, spostamento, copia, unione e sostituzione, il cestino e la quota di archiviazione. Utilizzare per caricare, trovare, organizzare, ripristinare o eliminare i file archiviati, leggere la quota di archiviazione, interrogare un file CSV, JSON o Parquet memorizzato, o concedere a un partner commerciale l'accesso SFTP.
