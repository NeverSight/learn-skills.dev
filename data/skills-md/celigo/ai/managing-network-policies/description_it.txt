Gestisci le politiche di rete Celigo – elenchi di IP consentiti e negati che limitano da dove possono connettersi i token API, i server MCP e le credenziali di accesso degli utenti della workspace o degli utenti finali. Include come viene decisa una politica, i quattro luoghi dove viene assegnata, le modifiche di tipo patch rispetto a quelle di sostituzione completa, l’eliminazione di una politica ancora assegnata e come evitare di bloccare se stessi. Da utilizzare quando si limita un server MCP, un token o l’accesso a reti conosciute, si modifica o elimina una politica, o si verifica se una politica spiega un chiamante rifiutato.
