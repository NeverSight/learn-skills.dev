Gestisci gli utenti finali di Celigo MCP — le persone che usano i server MCP di un account senza accesso all'area di lavoro — e i gruppi, i ruoli, i set di capacità e le concessioni che decidono quali strumenti, API, prompt e risorse ciascuno può chiamare. Include l'invito e la revoca, la concessione per server, i gruppi e i ruoli, cosa comporta la rimozione di un set di capacità sulle concessioni, l'accesso efficace compilato e le connessioni proprie degli utenti finali. Da usare quando si concede a persone o team l'accesso a un server Celigo OAuth MCP, si modifica o rimuove tale accesso, o si indaga perché qualcuno può o non può chiamare uno strumento.
