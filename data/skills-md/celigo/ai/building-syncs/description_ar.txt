بناء مزامنة Celigo (Celigo Data Ingestion) — خطوط أنابيب مُدارة تُعيد نسخ العديد من الجداول من تطبيق المصدر إلى مستودع البيانات، مع تعبئة تاريخية، وتشغيلات متزايدة، ومعالجة انحراف المخطط. يغطي الفرق بين المزامنة والتدفق، تكامل المزامنة، مجموعات البيانات، الوجهات، بوابات التفعيل والرخص، التشغيلات وإعادة المزامنة، ووظائف المزامنة، الأخطاء والفعاليات. يُستخدم عند نسخ بيانات التطبيق إلى Snowflake أو Google BigQuery أو Microsoft SQL Server أو NetSuite Analytics Warehouse، أو عند بناء أو تشغيل أو استكشاف مشكلة في المزامنة.
