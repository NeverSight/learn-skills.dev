Erstellen Sie Celigo‑Synchronisierungen (Celigo Data Ingestion) – verwaltete Pipelines, die zahlreiche Tabellen einer Quellanwendung in ein Data Warehouse replizieren, mit historischer Rückfüllung, inkrementellen Läufen und der Handhabung von Schema‑Drift. Behandelt Sync versus Flow, die Sync‑Integration, Datasets, Ziele, die Aktivierungs‑ und Lizenzschranken, Läufe und Resynchronisierungen sowie Sync‑Jobs, Fehler und Ereignisse. Verwenden Sie dies, wenn Anwendungsdaten in Snowflake, Google BigQuery, Microsoft SQL Server oder NetSuite Analytics Warehouse repliziert werden sollen, oder wenn Sie eine Synchronisierung erstellen, ausführen oder Fehlersuche betreiben.
