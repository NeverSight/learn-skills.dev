Tunnele/stelle einen Localhost-Dienst aus einer Cloud-VM heraus dem Internet zur Verfügung — erhalte eine stabile öffentliche HTTPS-URL (https://<box>-<port>.on.ascii.dev) mit integriertem TLS und Token-Gating, ohne separaten Daemon oder Account wie ngrok. Das dedizierte IPv4 der VM ermöglicht auch RAW-TCP/UDP und Bring-Your-Own-Domain. Verwenden Sie diese Option, um eine Vorschau freizugeben, ein Webhook-Ziel freizugeben oder einen Port zu öffnen.
