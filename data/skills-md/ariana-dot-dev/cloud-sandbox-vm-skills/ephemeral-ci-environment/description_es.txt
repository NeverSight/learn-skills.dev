Obtenga un entorno efímero limpio y reproducible para CI y pruebas: una nueva máquina virtual Ubuntu raíz con todas las principales cadenas de herramientas y Docker preinstaladas, su repositorio GitHub autoclonado y todo lo demás desechado después. La facturación por segundo hace que cada ejecución cueste centavos. Úselo para ejecutar pruebas, reproducir un error o validar una compilación en un entorno prístino sin contaminar el host.
