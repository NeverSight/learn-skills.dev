Генерируйте облачные архитектурные схемы (AWS, GCP, Azure, Kubernetes, on‑prem) в виде кода с помощью библиотеки Python `diagrams` (mingrammer/diagrams). Предоставляет рекомендации по механизмам размещения, атрибутам графа, дизайну кластеров и маршрутизации ребер для инфраструктурных схем производственного качества, а также галерею исполняемых примеров.
