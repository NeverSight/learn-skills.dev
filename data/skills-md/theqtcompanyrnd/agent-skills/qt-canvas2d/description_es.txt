Aplica las mejores prácticas de Qt Canvas2D (QtCanvas2D / Qt Canvas Painter, Qt 6.12+) al producir o trabajar con código fuente QML de Canvas2D. Úsalo siempre que Canvas2D, Canvas2DContext, path2d, boxshadow2d, boxgradient2d, gridpattern2d, conicalgradient2d o transform2d sea el tema: escritura, revisión, corrección, optimización o migración del código de dibujo de Qt Quick Canvas / HTML5 canvas a Canvas2D. También es apropiado para dibujo 2D imperativo acelerado por GPU en QML — medidores, diales, gráficos, formas de onda, osciloscopios, relojes, dibujo a mano alzada — incluyendo la elección entre Canvas2D y Shape/ShapePath cuando aún no se ha decidido el renderizador. NO lo actives para trabajos simples de Qt Quick Canvas que deben permanecer en el antiguo elemento CPU, ni para revisar código existente de Shape/ShapePath donde el renderizador ya está definido.
