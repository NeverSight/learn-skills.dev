在產生或處理 Canvas2D QML 原始碼時，套用 Qt Canvas2D（QtCanvas2D / Qt Canvas Painter，Qt 6.12+）的最佳實踐。每當 Canvas2D、Canvas2DContext、path2d、boxshadow2d、boxgradient2d、gridpattern2d、conicalgradient2d 或 transform2d 為主題時使用：編寫、審查、修正、優化或將 Qt Quick Canvas / HTML5 canvas 繪圖程式碼移植到 Canvas2D。也可用於 QML 中的 GPU 加速指令式 2D 繪圖——儀表、刻度盤、圖表、波形、示波器、時鐘、自由手繪——包括在尚未決定渲染器時，在 Canvas2D 與 Shape/ShapePath 之間做選擇。請勿在必須保留於舊的 CPU 元素的純 Qt Quick Canvas 工作，或在已確定渲染器的現有 Shape/ShapePath 程式碼審查時觸發。
