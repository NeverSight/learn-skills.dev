Applique les meilleures pratiques Qt Canvas2D (QtCanvas2D / Qt Canvas Painter, Qt 6.12+) lors de la création ou de la manipulation de code source Canvas2D QML. Utilise-les chaque fois que Canvas2D, Canvas2DContext, path2d, boxshadow2d, boxgradient2d, gridpattern2d, conicalgradient2d ou transform2d est concerné : rédaction, révision, correction, optimisation ou portage du code de dessin Qt Quick Canvas / HTML5 canvas vers Canvas2D. Utilise‑les également pour le dessin 2D impératif accéléré par GPU en QML — jauges, cadrans, graphiques, formes d’onde, oscilloscopes, horloges, dessin à main levée — y compris le choix entre Canvas2D et Shape/ShapePath lorsqu’il n’y a pas encore de rendu défini. NE PAS appliquer pour un travail Qt Quick Canvas simple qui doit rester sur l’ancien élément CPU, ou pour la révision d’un code Shape/ShapePath existant où le rendu est déjà fixé.
