Qt Canvas2D (QtCanvas2D / Qt Canvas Painter, Qt 6.12+) 모범 사례를 Canvas2D QML 소스 코드를 만들거나 작업할 때 적용합니다. Canvas2D, Canvas2DContext, path2d, boxshadow2d, boxgradient2d, gridpattern2d, conicalgradient2d 또는 transform2d가 주제인 경우—작성, 검토, 수정, 최적화, 또는 Qt Quick Canvas/HTML5 캔버스 그리기 코드를 Canvas2D로 포팅할 때 사용합니다. 또한 QML에서 GPU 가속 명령형 2D 그리기(게이지, 다이얼, 차트, 파형, 오실로스코프, 시계, 자유 손그리기 등)를 위해 사용하며, 렌더러가 아직 결정되지 않은 경우 Canvas2D와 Shape/ShapePath 중 선택할 때도 포함됩니다. 기존 CPU 요소에 머물러야 하는 일반 Qt Quick Canvas 작업이나 렌더러가 이미 정해진 기존 Shape/ShapePath 코드를 검토할 때는 사용하지 마십시오.
