Erstellt ein KI‑generiertes (oder beliebiges) flaches Motion‑Design‑Video als sauberen, editierbaren Code neu: Inline‑SVG‑Formen, die über eine einzige GSAP‑Timeline animiert werden, frame‑weise durchsuchbar, nahtlos in Endlosschleife, Seite an Seite mit dem Original überprüft; und optional wird eine Interface‑Aufnahme in eine echte interaktive Website verwandelt (GSAP ScrollTrigger, echte Klicks). Stellt Skripte zur Analyse des Videos bereit (Frames, Schnitte, Kontaktbogen, exakte Farbpalette), rendert den Code über anim.seek zu MP4/GIF, vergleicht ihn frameweise mit dem Original und prüft die Schleifennaht sowie den Seiten‑Contract. Verwenden, wenn der Nutzer ein Video, GIF, Lottie‑ähnlichen Clip, Motion‑Design‑Aufnahme, animiertes Logo, UI‑Screen‑Recording oder ein KI‑Video „im Code neu erstellt“, „in SVG/GSAP konvertiert“, „zu einer HTML‑Animation gemacht“ oder „zu einer echten Website gemacht“ möchte. Nicht geeignet für fotografisches Filmmaterial, 3D‑Renderings oder Videoschnitt.
