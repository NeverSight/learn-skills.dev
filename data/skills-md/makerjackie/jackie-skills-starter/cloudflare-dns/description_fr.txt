Configure et dépannez les enregistrements DNS Cloudflare ainsi que les liaisons de domaines personnalisés pour Cloudflare Pages. Utilisez ceci lorsqu’un utilisateur demande d’ajouter/modifier/supprimer des enregistrements DNS, de mapper un domaine personnalisé à Cloudflare Pages/Workers, de vérifier la propagation ou de corriger des erreurs de validation de domaine. Lors de la première utilisation, demandez la configuration d’un jeton API avec les autorisations de modification DNS avant d’effectuer les changements.

Veuillez toujours répondre dans la langue de l’utilisateur.
