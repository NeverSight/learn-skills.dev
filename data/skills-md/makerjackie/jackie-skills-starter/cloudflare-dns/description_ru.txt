Настраивайте и устраняйте неполадки записей DNS Cloudflare и привязок пользовательских доменов к Cloudflare Pages. Используйте, когда пользователь просит добавить/изменить/удалить записи DNS, привязать пользовательский домен к Cloudflare Pages/Workers, проверить распространение или исправить ошибки проверки домена. При первом использовании запросите настройку токена API с разрешениями на редактирование DNS перед внесением изменений.
