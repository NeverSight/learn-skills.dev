Configura y soluciona problemas de los registros DNS de Cloudflare y de las vinculaciones de dominios personalizados en Pages. Úsalo cuando un usuario solicite agregar/editar/eliminar registros DNS, mapear un dominio personalizado a Cloudflare Pages/Workers, verificar la propagación o corregir errores de validación de dominio. En el primer uso, solicita la configuración del token API con permisos de edición de DNS antes de realizar cambios.
