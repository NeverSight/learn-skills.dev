انقل حلقات Python الحساسة للأداء في Django إلى العمليات الحسابية على جانب قاعدة البيانات باستخدام التعليقات التوضيحية والتجميعات والتجميعات المصفاة وتعبيرات F والوظائف والاستعلام الفرعي وOuterRef وExists وتعبيرات Window وdb_default وGeneratedField. يُستخدم عندما يقوم كود Django بحساب أو جمع أو تصفية أو وضع علامات أو ترتيب أو اشتقاق القيم في Python بعد جلب الصفوف.
