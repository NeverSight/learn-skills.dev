Expliquer et appliquer les mathématiques fondamentales pour le développement front-end, y compris l'arithmétique, l'algèbre, les ratios, les exposants, les racines, les équations linéaires, les inégalités, la géométrie, la trigonométrie, les coordonnées et le choix des mathématiques CSS par rapport aux mathématiques JavaScript. À utiliser lorsqu'un calcul de conception Web nécessite une explication des principes fondamentaux avant d'appliquer des compétences CSS, JavaScript, Grid, Flexbox, responsive ou spécifiques aux couleurs.
