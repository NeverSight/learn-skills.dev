Explique y aplique las matemáticas fundamentales para el desarrollo de aplicaciones para el usuario, incluidas la aritmética, el álgebra, las proporciones, los exponentes, las raíces, las ecuaciones lineales, las desigualdades, la geometría, la trigonometría, las coordenadas y la elección de matemáticas CSS frente a JavaScript. Úselo cuando un cálculo de diseño web necesite una explicación de los primeros principios antes de aplicar habilidades CSS, JavaScript, Grid, Flexbox, responsivas o específicas de color.
