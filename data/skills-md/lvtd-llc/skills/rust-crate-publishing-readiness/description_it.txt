Prepara i crate Rust per la pubblicazione con metadati Cargo, controllo delle versioni, README e controlli delle licenze, prove di pacchetto, verifica delle funzionalità, disponibilità di docs.rs, esempi, note del registro delle modifiche e accessi di rilascio segreti. Da utilizzare prima della pubblicazione del carico, dei PR di rilascio delle casse o della condivisione di una libreria Rust riutilizzabile.
