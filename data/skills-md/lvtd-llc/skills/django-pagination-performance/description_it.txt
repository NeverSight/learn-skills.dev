Migliora l'impaginazione di Django e Django REST Framework per set di query di grandi dimensioni utilizzando dimensioni di pagina limitate, ordinamento stabile, ordinamento indicizzato, limiti di offset, impaginazione di set di chiavi, DRF CursorPagination e compromessi sul conteggio delle query. Da utilizzare quando le pagine degli elenchi, le visualizzazioni di amministrazione, le API, le esportazioni o lo scorrimento infinito diventano lenti, incoerenti o utilizzano molta memoria man mano che i set di risultati crescono.
