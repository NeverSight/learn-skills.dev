تحسين ترقيم الصفحات Django وDjango REST Framework لمجموعات الاستعلام الكبيرة باستخدام أحجام الصفحات المحدودة، والترتيب المستقر، والترتيب المفهرس، وحدود الإزاحة، وترقيم الصفحات لمجموعة المفاتيح، وDRF CursorPagination، ومقايضات استعلام العد. يُستخدم عندما تصبح صفحات القائمة أو طرق عرض المسؤول أو واجهات برمجة التطبيقات أو عمليات التصدير أو التمرير اللانهائي بطيئة أو غير متسقة أو مثقلة بالذاكرة مع نمو مجموعات النتائج.
