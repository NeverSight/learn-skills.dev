Mejore la paginación de Django y Django REST Framework para conjuntos de consultas grandes utilizando tamaños de página limitados, ordenamiento estable, ordenamiento indexado, límites de desplazamiento, paginación de conjuntos de claves, DRF CursorPagination y compensaciones de recuento de consultas. Úselo cuando las páginas de lista, las vistas de administración, las API, las exportaciones o el desplazamiento infinito se vuelven lentos, inconsistentes o consumen mucha memoria a medida que crecen los conjuntos de resultados.
