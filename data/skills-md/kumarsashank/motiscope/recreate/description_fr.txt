Recréez une animation analysée sous la forme d'un code Web fonctionnel : GSAP (JavaScript), CSS/animations Web, Framer Motion (React) ou Lottie/SVG. À utiliser après /motiscope:analyze, ou lorsque l'utilisateur demande de « créer/recréer cette animation dans <framework>». Lit les spécifications de l'animation motiscope et génère un composant exécutable.
