Erstellen Sie eine komplette Landingpage/eine Website mit mehreren Abschnitten anhand einer Bildschirmaufzeichnung, in der durch die Seite gescrollt oder sie durchlaufen wird. Verwenden Sie diese Option, wenn der Benutzer eine Aufzeichnung einer GESAMTEN Seite (nicht einer einzelnen Animation) hat und möchte, dass die gesamte Seite neu erstellt wird – Layout, Abschnitte, Text, Designsystem und Scroll-Animationen. Orchestriert die Analyse (gemessene Zeitvorgaben + Abschnittsstruktur + kuratierte Frames) + die Generierung von Assets + einen vollständigen Build mit mehreren Abschnitten. Verwenden Sie stattdessen /motiscope:recreate für eine einzelne Animation.
