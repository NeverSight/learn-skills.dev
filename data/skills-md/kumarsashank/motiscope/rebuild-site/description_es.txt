Reconstruye una página de destino completa o un sitio web con varias secciones a partir de una grabación de pantalla que se desplaza o recorre la página. Úsalo cuando el usuario tenga una grabación de una página ENTERA (no de una sola animación) y quiera recrear la página completa: diseño, secciones, texto, sistema de diseño y animaciones de desplazamiento. Coordina el análisis (duración medida + estructura de las secciones + fotogramas seleccionados) + la generación de elementos + la creación completa de un sitio web con varias secciones. Para una animación aislada, usa /motiscope:recreate en su lugar.
