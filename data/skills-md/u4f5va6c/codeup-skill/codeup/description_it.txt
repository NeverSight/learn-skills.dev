Gestire i repository Codeup e le merge request, i requisiti ProjeX, i difetti e le attività, le pipeline Flow e i record di test Testhub all'interno di Alibaba Cloud CloudEffect. Viene utilizzato per tracciare gli elementi di lavoro, inviare commit, creare o rivedere PR/MR, ispezionare CI, gestire le attività di rilascio e integrare le competenze ingegneristiche di Matt Pocock in CloudEffect. Le normali operazioni Git locali che non coinvolgono CloudEffect non richiedono il suo utilizzo.
