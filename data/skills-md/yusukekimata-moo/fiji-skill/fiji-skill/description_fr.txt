Utilisez Fiji/ImageJ via Fiji MCP, Fiji Macro Bridge ou des scripts macro ImageJ en employant les commandes natives de Fiji et les flux de travail documentés. À utiliser lorsqu’un agent doit ouvrir, traiter, mesurer, segmenter, appliquer un seuillage, filtrer, enregistrer, visualiser, exporter, traiter par lot ou analyser des images dans Fiji/ImageJ, notamment lorsque la tâche doit s’appuyer sur les menus de Fiji, les plugins, les commandes de type Macro Recorder, la Table des résultats, le Gestionnaire de ROI, Bio‑Formats, les piles, les hyperpiles ou les fonctionnalités d’analyse standard d’ImageJ/Fiji plutôt que sur du code de traitement de pixels personnalisé.  

Veuillez toujours répondre dans la langue de l’utilisateur.
