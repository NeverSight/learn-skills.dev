Haz videos con código (Canvas / HTML‑CSS‑SVG / sombreadores WebGL / Three.js / Remotion / HyperFrames / Manim + sonido sintetizado por código), renderizados fotograma a fotograma con Playwright + FFmpeg. Pregunta qué quiere crear el usuario (una idea, contenido fuente como un artículo, guion, página de producto o base de código, o un video de referencia), propone tres planes de video distintos con resúmenes visuales toma por toma, genera una imagen clave o una vista previa de unos segundos para cada uno, y después de que el usuario confirme uno, escribe el brief completo y construye el MP4 final. Usa esto siempre que alguien quiera que Claude haga, anime o renderice un video, un gráfico en movimiento, un explicativo animado, un promo de producto, una pieza de tipografía cinética, una animación pixel‑art o retro, una demo de movimiento de UI, o reproduzca el aspecto de un video de referencia con código — incluyendo peticiones en chino como 「做个视频」「用代码做视频」「做个动效」「做个宣传片」「帮我复刻这个视频」 「Opus 做视频」。 También utilízalo cuando el usuario tenga clips de personajes generados por IA (croma) y quiera crear escenas alrededor de ellos con código. No es para generar metraje con modelos de video, editar en Premiere/CapCut/AE, o subtitular un video existente.
