يتكيف ويراجع تطبيقات SwiftUI لجهاز iPhone Duo ويغير أحجام النوافذ باستمرار. يُستخدم عند دعم iPhone Duo القابل للطي، أو التخطيط المفصلي أو المطوي، أو ArrangementView، أو المناطق المحجوزة، أو ملحقات المشهد، أو الشاشة الخارجية أو الداخلية، أو NavigationSplitView، أو TabView التكيفي، أو ViewThatFits، أو AnyLayout، أو عند استبدال فروع تخطيط UIDevice / UIScreen / idiom / الاتجاه.
