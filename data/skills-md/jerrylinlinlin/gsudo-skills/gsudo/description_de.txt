Spickzettel für gsudo – ein sudo für Windows – um Befehle erhöht (als Administrator) auszuführen oder die aktuelle Shell vor Ort zu erhöhen, ohne ein separates Administrator‑Fenster. Verwende es für praktisch jede gsudo‑/„sudo on Windows“‑Aufgabe: Erhöhung der aktuellen CMD‑/PowerShell‑/WSL‑/Git‑Bash‑Shell, Reduzieren von UAC‑Pop‑ups mittels Credential‑Cache, Ausführen als System / TrustedInstaller / ein anderer Benutzer / ein gewähltes Integritätslevel, Erhöhung in einem neuen Fenster, die PowerShell‑Syntax `gsudo { ScriptBlock }` / `Invoke-gsudo` / `$using:` , Skripte, die sich selbst erhöhen, Erkennung der Erhöhung mit `gsudo status`, Droppen von Rechten mit `-i` und Feinabstimmung über `gsudo config`. Ausgelöst wird auf Formulierungen wie „run as admin from the terminal“, „elevate this command“, „sudo on Windows“, „gsudo“, „run as SYSTEM / TrustedInstaller“, „fewer UAC prompts“, „make a script self‑elevate“ oder „am I running elevated“. Es wird angenommen, dass gsudo installiert ist und im PATH liegt. Deckt CMD / PowerShell / WSL / Git‑Bash / MSYS2 ab.
