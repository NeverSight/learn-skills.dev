gsudo（Windows 用 sudo）のチートシート — 別ウィンドウを開かずに管理者権限でコマンドを実行したり、現在のシェルをその場で昇格させたりするためのものです。基本的にあらゆる gsudo / 「Windows 上の sudo」タスクに使用できます：現在の CMD / PowerShell / WSL / Git‑Bash シェルの昇格、認証情報キャッシュによる UAC ポップアップの削減、System / TrustedInstaller / 別ユーザー / 任意の整合性レベルでの実行、新しいウィンドウでの昇格、PowerShell の `gsudo { ScriptBlock }` / `Invoke-gsudo` / `$using:` 構文、自己昇格スクリプト、`gsudo status` での昇格状態検出、`-i` での権限降格、`gsudo config` による設定調整など。以下のような表現でトリガーできます：「run as admin from the terminal」「elevate this command」「sudo on Windows」「gsudo」「run as SYSTEM / TrustedInstaller」「fewer UAC prompts」「make a script self-elevate」「am I running elevated」。gsudo がインストールされ、PATH に含まれていることを前提としています。対象は CMD / PowerShell / WSL / Git‑Bash / MSYS2 です。
