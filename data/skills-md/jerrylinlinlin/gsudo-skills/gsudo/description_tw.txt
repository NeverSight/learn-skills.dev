gsudo 快速指南 — Windows 版 sudo — 用於以提升權限（管理員）執行指令或在原地提升當前 shell，而不需開啟獨立的管理員視窗。可用於幾乎所有 gsudo／「Windows 上的 sudo」任務：提升當前的 CMD／PowerShell／WSL／Git‑Bash shell、利用憑證快取減少 UAC 彈窗、以 System／TrustedInstaller／其他使用者／指定的完整性等級執行、在新視窗中提升、PowerShell 的 `gsudo { ScriptBlock }`／`Invoke-gsudo`／`$using:` 語法、會自行提升的腳本、使用 `gsudo status` 檢測提升狀態、使用 `-i` 降低權限，以及透過 `gsudo config` 調整設定。當出現類似「從終端以管理員身分執行」、「提升此指令」、「Windows 上的 sudo」、「gsudo」、「以 SYSTEM／TrustedInstaller 身分執行」、「減少 UAC 提示」、「讓腳本自行提升」或「我是否已提升」等語句時，即可觸發。本說明假設已安裝 gsudo 且已加入 PATH。涵蓋 CMD／PowerShell／WSL／Git‑Bash／MSYS2。
