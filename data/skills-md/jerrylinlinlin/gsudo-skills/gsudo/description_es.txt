Hoja de referencia rápida para gsudo — un sudo para Windows — para ejecutar comandos con privilegios elevados (como administrador) o elevar el shell actual en el mismo lugar, sin una ventana de administrador separada. Úsalo para prácticamente cualquier tarea de gsudo / “sudo en Windows”: elevar el shell actual de CMD / PowerShell / WSL / Git‑Bash, eliminar los diálogos emergentes de UAC usando la caché de credenciales, ejecutar como System / TrustedInstaller / otro usuario / un nivel de integridad elegido, elevar en una nueva ventana, la sintaxis de PowerShell `gsudo { ScriptBlock }` / `Invoke-gsudo` / `$using:`, scripts que se auto‑elevan, detectar la elevación con `gsudo status`, reducir privilegios con `-i`, y ajustar la configuración mediante `gsudo config`. Se activa con expresiones como “ejecutar como admin desde la terminal”, “elevar este comando”, “sudo en Windows”, “gsudo”, “ejecutar como SYSTEM / TrustedInstaller”, “menos diálogos UAC”, “hacer que un script se auto‑eleve”, o “¿estoy ejecutando con privilegios elevados?”. Se asume que gsudo está instalado y en el PATH. Cubre CMD / PowerShell / WSL / Git‑Bash / MSYS2.
