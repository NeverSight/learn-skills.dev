Cheatsheet per gsudo — un sudo per Windows — per eseguire comandi elevati (come amministratore) o elevare la shell corrente in loco, senza una finestra amministrativa separata. Usalo per praticamente qualsiasi operazione gsudo / “sudo on Windows”: elevare la shell CMD / PowerShell / WSL / Git‑Bash corrente, eliminare i popup UAC grazie alla cache delle credenziali, eseguire come System / TrustedInstaller / un altro utente / un livello di integrità scelto, elevare in una nuova finestra, la sintassi PowerShell `gsudo { ScriptBlock }` / `Invoke-gsudo` / `$using:` , script che si auto‑elevano, rilevare l’elevazione con `gsudo status`, ridurre i privilegi con `-i`, e configurare via `gsudo config`. Attiva su frasi come “run as admin from the terminal”, “elevate this command”, “sudo on Windows”, “gsudo”, “run as SYSTEM / TrustedInstaller”, “fewer UAC prompts”, “make a script self-elevate”, o “am I running elevated”. Si presume che gsudo sia installato e presente nel PATH. Copre CMD / PowerShell / WSL / Git‑Bash / MSYS2.
