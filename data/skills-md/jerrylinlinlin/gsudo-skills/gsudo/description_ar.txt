ورقة الغش لـ gsudo — sudo لنظام Windows — لتشغيل الأوامر بصلاحيات مرتفعة (كمسؤول) أو رفع صلاحيات الصندوق الحالي في مكانه، دون نافذة مسؤول منفصلة. استخدمها لأي مهمة تقريبًا تتعلق بـ gsudo / “sudo على Windows”: رفع صلاحيات الصندوق الحالي CMD / PowerShell / WSL / Git‑Bash، تقليل نوافذ UAC باستخدام ذاكرة الاعتماد، التشغيل كـ System / TrustedInstaller / مستخدم آخر / مستوى نزاهة مختار، الرفع في نافذة جديدة، صيغ PowerShell `gsudo { ScriptBlock }` / `Invoke-gsudo` / `$using:`، السكربتات التي ترفع نفسها، اكتشاف الرفع باستخدام `gsudo status`، خفض الصلاحيات باستخدام `-i`، وضبط الإعدادات عبر `gsudo config`. يتم التحفيز عند عبارات مثل “تشغيل كمسؤول من الطرفية”، “رفع هذا الأمر”، “sudo على Windows”، “gsudo”، “تشغيل كـ SYSTEM / TrustedInstaller”، “قليل من نوافذ UAC”، “اجعل السكربت يرفع نفسه”، أو “هل أعمل بصلاحيات مرتفعة”. يفترض أن gsudo مثبت وموجود في PATH. يغطي CMD / PowerShell / WSL / Git‑Bash / MSYS2.
