Fiche de référence pour gsudo — un sudo pour Windows — permettant d’exécuter des commandes en élévation (en tant qu’administrateur) ou d’élever le shell actuel sur place, sans ouvrir de fenêtre administrateur séparée. Utilisez‑le pour pratiquement toute tâche gsudo / « sudo sous Windows » : élever le shell CMD, PowerShell, WSL ou Git‑Bash actuel, supprimer les fenêtres UAC grâce au cache d’identifiants, s’exécuter en tant que System, TrustedInstaller, un autre utilisateur ou un niveau d’intégrité choisi, élever dans une nouvelle fenêtre, la syntaxe PowerShell `gsudo { ScriptBlock }`, `Invoke‑gsudo` ou `$using:`, les scripts qui s’auto‑élèvent, détecter l’élévation avec `gsudo status`, abandonner les privilèges avec `-i`, et ajuster via `gsudo config`. Déclencheur sur des formulations telles que « exécuter en tant qu’administrateur depuis le terminal », « élever cette commande », « sudo sous Windows », « gsudo », « exécuter en tant que SYSTEM / TrustedInstaller », « moins d’invites UAC », « rendre un script auto‑élevé » ou « suis‑je en élévation ». Supposant que gsudo est installé et présent dans le PATH. Couvre CMD, PowerShell, WSL, Git‑Bash et MSYS2.
