gsudo 小抄 — Windows 版 sudo — 用于以提升权限（管理员）运行命令或在原地提升当前 shell，无需打开单独的管理员窗口。几乎所有 gsudo / “Windows 上的 sudo” 场景均可使用：提升当前 CMD / PowerShell / WSL / Git‑Bash shell，使用凭据缓存削减 UAC 弹窗，作为 System / TrustedInstaller / 其他用户 / 指定完整性级别运行，在新窗口中提权，PowerShell 的 `gsudo { ScriptBlock }` / `Invoke-gsudo` / `$using:` 语法，脚本自我提升，通过 `gsudo status` 检测是否已提升，使用 `-i` 降低权限，通过 `gsudo config` 调优。可响应类似 “在终端以管理员身份运行”、 “提升此命令”、 “Windows 上的 sudo”、 “gsudo”、 “以 SYSTEM / TrustedInstaller 运行”、 “减少 UAC 提示”、 “让脚本自提升”、 “我是否在提升权限下运行” 等表达。假设已安装 gsudo 并加入 PATH。涉及 CMD / PowerShell / WSL / Git‑Bash / MSYS2。
