Шпаргалка по gsudo — sudo для Windows — для запуска команд с повышенными правами (как администратор) или повышения текущей оболочки на месте, без отдельного окна администратора. Используйте её для практически любой задачи gsudo / «sudo в Windows»: повышение текущей оболочки CMD / PowerShell / WSL / Git‑Bash, уменьшение всплывающих окон UAC с помощью кэша учётных данных, запуск от имени System / TrustedInstaller / другого пользователя / выбранного уровня целостности, повышение в новом окне, PowerShell‑синтаксис `gsudo { ScriptBlock }` / `Invoke-gsudo` / `$using:` , скрипты, которые сами повышаются, определение повышенных прав с помощью `gsudo status`, понижение привилегий с `-i` и настройка через `gsudo config`. Ориентируйтесь на фразы типа «запустить от админа из терминала», «повысить эту команду», «sudo в Windows», «gsudo», «запустить как SYSTEM / TrustedInstaller», «меньше запросов UAC», «сделать скрипт самоповышающимся» или «я запущен с повышенными правами». Предполагается, что gsudo установлен и находится в PATH. Охватывает CMD / PowerShell / WSL / Git‑Bash / MSYS2.
