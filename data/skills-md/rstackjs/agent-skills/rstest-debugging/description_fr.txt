Déboguez systématiquement les problèmes de démarrage, de build, d’exécution, de journalisation et de mémoire de Rstest. À utiliser lorsque Rstest est plus lent que Jest/Vitest ou une ligne de base précédente ; lorsque le mur runner/build/tests/CLI n'est pas d'accord ; lorsque la configuration/collecte ou le chargement du module Node domine ; lorsque les modules simulés entrent toujours dans les bundles ; lorsque la couverture groupée expérimentale ou l’utilisation des actifs doivent être inspectées ; ou lorsque le regroupement de dépendances, les actifs, les pools, l'isolation, les journaux ou la mémoire nécessitent un réglage basé sur des preuves.
