Recommandations Rslib avisées pour la conception de packages JS/TS npm modernes couvrant l'ESM pur, le TypeScript strict, les exportations explicites, les petites API stables, les dépendances pragmatiques, les effets secondaires précis, les déclarations correctes, la validation du package, la provenance, README.md et AGENTS.md. À utiliser lorsque l'utilisateur souhaite rendre un package JS/TS plus moderne, vérifier si la configuration actuelle du package est saine, examiner package.json/exports/types/dependencies/docs/release readiness ou appliquer une référence de bibliothèque moderne.
