Raccomandazioni Rslib supponenti per la progettazione moderna di pacchetti JS/TS npm che coprono ESM puro, TypeScript rigoroso, esportazioni esplicite, piccole API stabili, dipendenze pragmatiche, effetti collaterali accurati, dichiarazioni corrette, convalida dei pacchetti, provenienza, README.md e AGENTS.md. Da utilizzare quando l'utente desidera rendere un pacchetto JS/TS più moderno, verificare se la configurazione corrente del pacchetto è integra, rivedere la disponibilità di package.json/exports/types/dependencies/docs/release o applicare una linea di base della libreria moderna.
