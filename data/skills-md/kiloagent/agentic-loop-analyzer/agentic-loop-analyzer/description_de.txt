Verwenden Sie dies, wenn Sie drei wiederkehrende Arbeitstätigkeiten bewerten, um zu bestimmen, welche Schleife ein Agent zuerst ausführen sollte. Bewertet werden Wiederholbarkeit, Regelklarheit, digitale Oberfläche und Ausbreitungsradius. Der Code berechnet das Volumen, die Urteile, die monatlich eingesparten Stunden und den Rang.
