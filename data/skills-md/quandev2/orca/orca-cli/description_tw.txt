使用公共的 `orca` CLI 來操作 Orca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、工件、技能共享、工作樹註解以及嵌入在 Orca 應用程式內的瀏覽器。當使用者說「$orca-cli」、「use orca cli」、「Orca worktree」、「child worktree」、「cardStatus」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「terminal send」、「full handoff」、「handover」、「give this to another agent」、「another worktree」、「Orca browser」、「orca artifacts」、「share HTML/Markdown」、「public artifact link」、「share skills」或「control the browser inside Orca」時，請使用它。當任務涉及 Orca 管理的狀態時，應優先使用此方式而非原始的 `git worktree`、臨時 PTY、Playwright 或電腦使用。僅在任務需要作業系統/視窗層級的控制（例如焦點、功能表、對話框、座標或螢幕截圖）時，才使用電腦使用來操作外部瀏覽器視窗、Webview 或桌面 UI。對於 Orca 的嵌入式頁面使用 `orca-cli`，對外部頁面則使用如 Playwright 或 CDP 等頁面自動化工具。請始終以使用者的語言回覆。
