أعد إنشاء أو إعادة إنشاء الواجهة الأمامية لموقع الويب من عنوان URL مرجعي معتمد أو لقطات شاشة أو صفحة موجودة. استخدمه عندما يُطلب منك استنساخ تخطيط موقع ويب، أو مطابقة لقطة شاشة، أو إعادة إنتاج واجهة مستخدم، أو تعديل تصميم مرجعي إلى تعليمات برمجية قابلة للتحرير مع التحقق السريع والمرئي. استخدمه أيضًا عندما يُطلب منك صراحةً إنشاء موقع ويب جديد أو تحسين واجهة المستخدم/تجربة المستخدم الأمامية بدون الرموز التعبيرية أو تصميم الذكاء الاصطناعي العام. التكيف مع لغة المشروع والعارض؛ العمل الخلفي غير ذي الصلة خارج النطاق.
