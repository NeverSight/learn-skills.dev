Úselo cuando se le solicite clonar el diseño de un sitio web, hacer coincidir una captura de pantalla, reproducir una interfaz de usuario o adaptar un diseño de referencia en código editable con verificación visual y responsiva. Úselo también cuando se le solicite explícitamente crear un nuevo sitio web o mejorar la interfaz de usuario/UX sin emoji ni estilos genéricos de IA.
