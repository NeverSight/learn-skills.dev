Ricostruisci o ricrea il frontend di un sito web da un URL di riferimento autorizzato, screenshot o una pagina esistente. Da utilizzare quando viene richiesto di clonare il layout di un sito web, abbinare uno screenshot, riprodurre un'interfaccia utente o adattare un progetto di riferimento in codice modificabile con verifica reattiva e visiva. Da utilizzare anche quando viene richiesto esplicitamente di creare un nuovo sito Web o migliorare l'interfaccia utente/UX del frontend senza emoji o stili AI generici. Adattarsi al linguaggio e al renderer del progetto; il lavoro di backend non correlato non rientra nell'ambito.
