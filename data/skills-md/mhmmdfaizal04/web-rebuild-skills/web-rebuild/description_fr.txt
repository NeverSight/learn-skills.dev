Reconstruisez ou recréez une interface de site Web à partir d'une URL de référence autorisée, de captures d'écran ou d'une page existante. À utiliser lorsqu'on vous demande de cloner la mise en page d'un site Web, de faire correspondre une capture d'écran, de reproduire une interface utilisateur ou d'adapter une conception de référence en code modifiable avec une vérification réactive et visuelle. À utiliser également lorsqu'on vous demande explicitement de créer un nouveau site Web ou d'améliorer l'interface utilisateur/UX du frontend sans emoji ni style d'IA générique. S'adapter au langage et au moteur de rendu du projet ; le travail backend sans rapport est hors de portée.
