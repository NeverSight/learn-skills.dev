Gestión multiplataforma (Windows, macOS, Linux) del flujo de desarrollo y compilación de doudou‑ai‑coding. Incluye dos modos principales: (1) modo de desarrollo/depuración (activado por palabras clave como “debug / develop / start / run / run locally / dev”), que inicia doudou‑eggjs (npm run dev) y doudou‑vue3 (pnpm dev), proporcionando detección de puertos y entorno, instalación automática de dependencias, registro concurrente y apagado ordenado; (2) modo de compilación para producción (activado por palabras clave como “package / build / compile artifact / production build / build / build:prod”), que ejecuta doudou‑eggjs (npm run build, es decir, rec build ‑o dist) y doudou‑vue3 (pnpm run build:prod, es decir, vite build) para generar los artefactos de lanzamiento.
