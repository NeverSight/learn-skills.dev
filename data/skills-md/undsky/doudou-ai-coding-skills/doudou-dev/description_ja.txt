Cross‑platform（Windows、macOS、Linux）での doudou‑ai‑coding の開発とビルドワークフローの管理。2 つのコアモードがある：(1) 開発/デバッグモード（「debug / develop / start / run / run locally / dev」などのキーワードでトリガー）、doudou‑eggjs（npm run dev）と doudou‑vue3（pnpm dev）を起動し、ポートと環境の検出、自動依存インストール、同時ログ出力、優雅なシャットダウンを提供する；(2) 本番ビルドモード（「package / build / compile artifact / production build / build / build:prod」などのキーワードでトリガー）、doudou‑eggjs（npm run build、すなわち rec build ‑o dist）と doudou‑vue3（pnpm run build:prod、すなわち vite build）を実行してリリースアーティファクトを生成する。
