Plattformübergreifendes (Windows, macOS, Linux) Management des doudou‑ai‑coding Entwicklungs‑ und Build‑Workflows. Es umfasst zwei Kernmodi: (1) Entwicklungs‑/Debug‑Modus (ausgelöst durch Schlüsselwörter wie „debug / develop / start / run / run locally / dev“), der doudou‑eggjs (npm run dev) und doudou‑vue3 (pnpm dev) startet, Port‑ und Umgebungs­erkennung bietet, automatische Abhängigkeitsinstallation, gleichzeitige Protokollierung und ein elegantes Herunterfahren ermöglicht; (2) Produktions‑Build‑Modus (ausgelöst durch Schlüsselwörter wie „package / build / compile artifact / production build / build / build:prod“), der doudou‑eggjs (npm run build, d. h. rec build ‑o dist) und doudou‑vue3 (pnpm run build:prod, d. h. vite build) ausführt, um die Release‑Artefakte zu erzeugen.
