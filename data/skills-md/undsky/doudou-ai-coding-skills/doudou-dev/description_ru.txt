Кроссплатформенное (Windows, macOS, Linux) управление процессом разработки и сборки doudou‑ai‑coding. Включает два основных режима: (1) режим разработки/отладки (активируется командами «debug / develop / start / run / run locally / dev» и т.п.), который запускает doudou‑eggjs (npm run dev) и doudou‑vue3 (pnpm dev), обеспечивая определение порта и окружения, автоматическую установку зависимостей, конкурентный вывод логов и корректное завершение; (2) режим сборки для продакшена (активируется командами «build / compile / production bundle / build:prod» и т.п.), который запускает doudou‑eggjs (npm run build, т.е. rec build ‑o dist) и doudou‑vue3 (pnpm run build:prod, т.е. vite build) для создания артефактов релиза.
