Gestione multipiattaforma (Windows, macOS, Linux) del flusso di sviluppo e build di doudou‑ai‑coding. Include due modalità principali: (1) Modalità sviluppo/debug (attivata da parole chiave come “debug / develop / start / run / run locally / dev”), che avvia doudou‑eggjs (npm run dev) e doudou‑vue3 (pnpm dev), fornendo rilevamento della porta e dell’ambiente, installazione automatica delle dipendenze, registrazione concorrente e spegnimento graduale; (2) Modalità build di produzione (attivata da parole chiave come “package / build / compile artifact / production build / build / build:prod”), che esegue doudou‑eggjs (npm run build, cioè rec build ‑o dist) e doudou‑vue3 (pnpm run build:prod, cioè vite build) per generare gli artefatti di rilascio.
