跨平台（Windows、macOS、Linux）管理 doudou‑ai‑coding 的開發與建置工作流程。它包括兩種核心模式：(1) 開發/除錯模式（由「debug / develop / start / run / run locally / dev」等關鍵字觸發），會啟動 doudou‑eggjs（npm run dev）與 doudou‑vue3（pnpm dev），提供埠與環境偵測、自動安裝依賴、並行日誌以及優雅關閉；(2) 生產建置模式（由「package / build / compile artifact / production build / build / build:prod」等關鍵字觸發），會執行 doudou‑eggjs（npm run build，即 rec build ‑o dist）與 doudou‑vue3（pnpm run build:prod，即 vite build），生成發佈產出物。
