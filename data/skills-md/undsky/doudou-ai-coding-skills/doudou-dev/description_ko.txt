doudou‑ai‑coding 개발 및 빌드 워크플로우를 Windows, macOS, Linux에서 크로스‑플랫폼으로 관리합니다. 두 가지 핵심 모드를 포함합니다: (1) 개발/디버그 모드(“debug / develop / start / run / run locally / dev”와 같은 키워드에 의해 트리거됨)로, doudou‑eggjs (npm run dev)와 doudou‑vue3 (pnpm dev)를 실행하여 포트 및 환경 감지, 자동 의존성 설치, 동시 로깅, 우아한 종료를 제공합니다; (2) 프로덕션 빌드 모드(“package / build / compile artifact / production build / build / build:prod”와 같은 키워드에 의해 트리거됨)로, doudou‑eggjs (npm run build, 즉 rec build ‑o dist)와 doudou‑vue3 (pnpm run build:prod, 즉 vite build)를 실행해 릴리스 아티팩트를 생성합니다.
