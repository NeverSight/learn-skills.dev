Cross‑platform (Windows, macOS, Linux) management of the doudou‑ai‑coding development and build workflow. It includes two core modes: (1) Development/debug mode (triggered by keywords such as “debug / develop / start / run / run locally / dev”), which launches doudou‑eggjs (npm run dev) and doudou‑vue3 (pnpm dev), providing port and environment detection, automatic dependency installation, concurrent logging, and graceful shutdown; (2) Production build mode (triggered by keywords such as “package / build / compile artifact / production build / build / build:prod”), which runs doudou‑eggjs (npm run build, i.e., rec build ‑o dist) and doudou‑vue3 (pnpm run build:prod, i.e., vite build) to generate the release artifacts.
