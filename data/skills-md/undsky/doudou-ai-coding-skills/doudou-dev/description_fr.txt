Gestion multiplateforme (Windows, macOS, Linux) du flux de travail de développement et de construction de doudou‑ai‑coding. Elle comprend deux modes principaux : (1) Mode développement/debug (déclenché par des mots‑clés tels que « debug / develop / start / run / run locally / dev »), qui lance doudou‑eggjs (npm run dev) et doudou‑vue3 (pnpm dev), offrant la détection de port et d’environnement, l’installation automatique des dépendances, la journalisation concurrente et l’arrêt gracieux ; (2) Mode de construction en production (déclenché par des mots‑clés tels que « package / build / compile artifact / production build / build / build:prod »), qui exécute doudou‑eggjs (npm run build, c’est‑à‑dire rec build ‑o dist) et doudou‑vue3 (pnpm run build:prod, c’est‑à‑dire vite build) pour générer les artefacts de publication.
