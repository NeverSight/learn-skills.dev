Upload local images to an image hosting service and obtain a public CDN link or Markdown image syntax, with three modes: public image hosting API mode (scripts/upload-api.mjs), direct upload to a GitHub repository mode (scripts/upload-github.mjs), and direct upload to Cloudflare R2 mode (scripts/upload-r2.mjs). The unified entry point scripts/upload.mjs supports intelligent automatic scheduling. When GitHub and R2 are not configured, the public image hosting API is used automatically; if they are configured, the configured mode is used for uploading automatically. Whenever a user mentions uploading an image, sending an image to an image host, converting an image to a Markdown link, needing an external/CDN URL for an image, generating an article illustration link, publishing a screenshot/local image publicly for others to view or embed in documents/chat, or explicitly specifying uploading to a GitHub repository/Cloudflare R2 bucket, this skill is used — even if they don’t say “image host” or “CDN”.
