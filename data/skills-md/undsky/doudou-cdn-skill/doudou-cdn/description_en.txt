把本地图片上传到图床并获取公开 CDN 链接或 Markdown 图片语法，共三种模式：公共图床 API 模式 (scripts/upload-api.mjs)、GitHub 仓库直传模式 (scripts/upload-github.mjs)、Cloudflare R2 直传模式 (scripts/upload-r2.mjs)，统一入口 scripts/upload.mjs 支持智能自动调度。当没有配置 GitHub、R2 时，自动使用公共图床 API；如果配置了，那么自动使用配置的模式上传。只要用户提到上传图片、传图到图床、把图片转成 Markdown 链接、要给图片配个外链/CDN URL、生成文章配图链接、把截图/本地图片公开发布以供他人浏览或嵌进文档/聊天，或明确点名传到 GitHub 仓库 / Cloudflare R2 存储桶时，就使用这个 skill —— 哪怕他们没说“图床”或“CDN”。
