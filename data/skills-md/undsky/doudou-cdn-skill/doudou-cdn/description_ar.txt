قم بتحميل الصور المحلية إلى خدمة استضافة صور والحصول على رابط CDN عام أو صيغة صورة Markdown، مع ثلاثة أوضاع: وضع واجهة برمجة التطبيقات العامة لاستضافة الصور (scripts/upload-api.mjs)، وضع التحميل المباشر إلى مستودع GitHub (scripts/upload-github.mjs)، ووضع التحميل المباشر إلى Cloudflare R2 (scripts/upload-r2.mjs). نقطة الإدخال الموحدة scripts/upload.mjs تدعم الجدولة الذكية التلقائية. عندما لا تكون إعدادات GitHub وR2 مُكوَّنة، يتم استخدام واجهة برمجة التطبيقات العامة لاستضافة الصور تلقائيًا؛ إذا تم تكوينها، يُستخدم الوضع المُكوَّن للتحميل تلقائيًا. كلما ذكر المستخدم تحميل صورة، إرسال صورة إلى مستضيف صور، تحويل صورة إلى رابط Markdown، الحاجة إلى عنوان URL خارجي/CDN لصورة، إنشاء رابط توضيحي لمقال، نشر لقطة شاشة/صورة محلية علنًا ليتصفحها الآخرين أو يدمجوها في مستندات/دردشة، أو تحديد صريح للتحميل إلى مستودع GitHub/دلو Cloudflare R2، يتم استخدام هذه الميزة — حتى لو لم يذكروا "مستضيف صور" أو "CDN". يرجى دائمًا الرد بلغة المستخدم.
