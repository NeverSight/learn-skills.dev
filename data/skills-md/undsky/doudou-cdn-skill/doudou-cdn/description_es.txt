Cargar imágenes locales a un servicio de alojamiento de imágenes y obtener un enlace CDN público o la sintaxis de imagen Markdown, con tres modos: modo de API de alojamiento de imágenes público (scripts/upload-api.mjs), modo de carga directa a un repositorio GitHub (scripts/upload-github.mjs) y modo de carga directa a Cloudflare R2 (scripts/upload-r2.mjs). El punto de entrada unificado scripts/upload.mjs admite programación automática inteligente. Cuando GitHub y R2 no están configurados, se usa automáticamente la API pública de alojamiento de imágenes; si están configurados, se usa automáticamente el modo configurado para la carga. Cada vez que un usuario menciona subir una imagen, enviar una imagen a un host de imágenes, convertir una imagen a un enlace Markdown, necesitar una URL externa/CDN para una imagen, generar un enlace de ilustración de artículo, publicar una captura de pantalla/imágen local públicamente para que otros la vean o la incrusten en documentos/chat, o especifica explícitamente subir a un repositorio GitHub o a un bucket Cloudflare R2, se utiliza esta habilidad — incluso si no dice “host de imágenes” o “CDN”.
