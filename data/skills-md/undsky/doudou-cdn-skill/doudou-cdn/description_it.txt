Carica immagini locali su un servizio di hosting di immagini e ottieni un link CDN pubblico o la sintassi Markdown per immagini, con tre modalità: modalità API di hosting di immagini pubbliche (scripts/upload-api.mjs), modalità di caricamento diretto su un repository GitHub (scripts/upload-github.mjs) e modalità di caricamento diretto su Cloudflare R2 (scripts/upload-r2.mjs). Il punto di ingresso unificato scripts/upload.mjs supporta la programmazione automatica intelligente. Quando GitHub e R2 non sono configurati, viene utilizzata automaticamente l'API di hosting di immagini pubbliche; se sono configurati, la modalità configurata viene utilizzata automaticamente per il caricamento. Ogni volta che un utente menziona il caricamento di un'immagine, l'invio di un'immagine a un host di immagini, la conversione di un'immagine in un link Markdown, la necessità di un URL esterno/CDN per un'immagine, la generazione di un link di illustrazione per un articolo, la pubblicazione di uno screenshot/immagine locale in modo pubblico affinché altri possano visualizzarla o incorporarla in documenti/chat, o specifica esplicitamente il caricamento su un repository GitHub/bucket Cloudflare R2, questa funzionalità viene utilizzata — anche se non menzionano “host di immagini” o “CDN”. Rispondi sempre nella lingua dell'utente.
