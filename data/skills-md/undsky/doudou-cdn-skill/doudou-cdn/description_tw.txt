將本機圖片上傳到圖像寄存服務，取得公開的 CDN 連結或 Markdown 圖片語法，提供三種模式：公共圖像寄存 API 模式（scripts/upload-api.mjs）、直接上傳至 GitHub 倉庫模式（scripts/upload-github.mjs）以及直接上傳至 Cloudflare R2 模式（scripts/upload-r2.mjs）。統一入口 scripts/upload.mjs 支援智慧自動排程。當 GitHub 與 R2 未設定時，會自動使用公共圖像寄存 API；若已設定，則自動使用所設定的模式上傳。每當使用者提及上傳圖片、將圖片傳送至圖像寄存、將圖片轉換為 Markdown 連結、需要圖片的外部/CDN URL、產生文章插圖連結、公開發佈螢幕截圖／本機圖片以供他人觀看或嵌入文件／聊天，或明確指定上傳至 GitHub 倉庫／Cloudflare R2 儲存桶時，皆會使用此功能——即使他們未說「圖像寄存」或「CDN」。
