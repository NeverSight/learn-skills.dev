将本地图片上传到图床服务并获取公共 CDN 链接或 Markdown 图片语法，提供三种模式：公共图床 API 模式（scripts/upload-api.mjs）、直接上传至 GitHub 仓库模式（scripts/upload-github.mjs）以及直接上传至 Cloudflare R2 模式（scripts/upload-r2.mjs）。统一入口 scripts/upload.mjs 支持智能自动调度。当 GitHub 和 R2 未配置时，自动使用公共图床 API；若已配置，则自动使用配置好的模式进行上传。无论用户在何时提及上传图片、将图片发送到图床、将图片转换为 Markdown 链接、需要图片的外部/CDN URL、生成文章插图链接、公开发布截图/本地图片供他人查看或嵌入文档/聊天，或明确指定上传至 GitHub 仓库/Cloudflare R2 桶，都会使用此技能——即使他们未说“图床”或“CDN”。
