Lade lokale Bilder zu einem Bild‑Hosting‑Dienst hoch und erhalte einen öffentlichen CDN‑Link oder die Markdown‑Bildsyntax. Dabei stehen drei Modi zur Verfügung: öffentlicher Bild‑Hosting‑API‑Modus (scripts/upload-api.mjs), direkter Upload in ein GitHub‑Repository (scripts/upload-github.mjs) und direkter Upload zu Cloudflare R2 (scripts/upload-r2.mjs). Ein einheitlicher Einstiegspunkt, scripts/upload.mjs, unterstützt intelligente automatische Planung. Ist GitHub oder R2 nicht konfiguriert, wird automatisch die öffentliche Bild‑Hosting‑API verwendet; ist eine Konfiguration vorhanden, wird der angegebene Modus zum Hochladen genutzt. Immer wenn ein Nutzer das Hochladen eines Bildes erwähnt, ein Bild zu einem Bild‑Host sendet, ein Bild in einen Markdown‑Link umwandelt, eine externe/CDN‑URL für ein Bild benötigt, einen Link für eine Artikeldarstellung erzeugt, einen Screenshot / lokales Bild öffentlich veröffentlicht, damit andere es ansehen oder in Dokumenten / Chats einbetten können, oder explizit das Hochladen in ein GitHub‑Repository / Cloudflare R2‑Bucket nennt, wird diese Fähigkeit verwendet – selbst wenn sie nicht „Bild‑Host“ oder „CDN“ sagen.

Bitte immer in der Sprache des Benutzers antworten.
