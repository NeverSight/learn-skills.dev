Téléchargez des images locales sur un service d’hébergement d’images et obtenez un lien CDN public ou la syntaxe d’image Markdown, avec trois modes : mode API d’hébergement d’images publiques (scripts/upload‑api.mjs), téléchargement direct vers un dépôt GitHub (scripts/upload‑github.mjs) et téléchargement direct vers Cloudflare R2 (scripts/upload‑r2.mjs). Le point d’entrée unifié scripts/upload.mjs prend en charge une planification intelligente et automatique. Lorsque GitHub et R2 ne sont pas configurés, il utilise automatiquement l’API d’hébergement d’images publiques ; s’ils sont configurés, il utilise automatiquement le mode configuré pour le téléchargement. Chaque fois qu’un utilisateur mentionne le téléchargement d’une image, l’envoi d’une image à un hébergeur, la conversion d’une image en lien Markdown, le besoin d’un lien externe/URL CDN pour une image, la génération de liens d’illustration d’article, la publication publique d’une capture d’écran/image locale pour que d’autres puissent la voir ou l’intégrer dans des documents/chat, ou spécifie explicitement le téléchargement vers un dépôt GitHub ou un bucket Cloudflare R2, cette compétence est utilisée — même s’ils ne disent pas « hébergeur d’images » ou « CDN ».  

Veuillez toujours répondre dans la langue de l’utilisateur.
