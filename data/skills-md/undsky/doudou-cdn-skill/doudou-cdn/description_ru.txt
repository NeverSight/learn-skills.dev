Загружайте локальные изображения на хост изображений и получайте публичную CDN‑ссылку или синтаксис изображения Markdown, используя три режима: режим публичного API хоста изображений (scripts/upload-api.mjs), прямую загрузку в репозиторий GitHub (scripts/upload-github.mjs) и прямую загрузку в Cloudflare R2 (scripts/upload-r2.mjs). Унифицированная точка входа scripts/upload.mjs поддерживает интеллектуальное автоматическое планирование. Если GitHub или R2 не настроены, автоматически используется публичный API хоста изображений; если они настроены, автоматически используется сконфигурированный режим загрузки. Каждый раз, когда пользователь упоминает загрузку изображения, отправку изображения на хост, преобразование изображения в ссылку Markdown, необходимость внешней ссылки/URL CDN для изображения, генерацию ссылки на иллюстрацию статьи, публичное опубликование скриншота/локального изображения для просмотра другими или встраивания в документы/чаты, либо явно указывает загрузку в репозиторий GitHub/корзину Cloudflare R2, это умение будет использовано — даже если они не сказали «хост изображений» или «CDN».
