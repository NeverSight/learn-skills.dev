Diagnostiquez et corrigez les bugs d’exécution reproductibles à l’aide de journaux structurés temporaires, de preuves de cause première, de vérifications et de nettoyages. Utilisez‑les pour les demandes explicites en mode débogage ou de débogage instrumenté. Poursuivez les sessions actives à travers les réponses de reproduction. Employez le mode trace lorsque l’objectif s’arrête à un emplacement précis du code.
