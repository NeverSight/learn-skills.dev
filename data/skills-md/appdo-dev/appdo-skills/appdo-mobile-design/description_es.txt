Diseñar, implementar y revisar pantallas y flujos móviles en plantillas de Appdo, especialmente Expo y React Native. Se utiliza para crear una pantalla nativa, mejorar un flujo existente, investigar la interfaz de usuario móvil y los patrones de movimiento de 60 fps, o verificar la navegación y los estados visuales. Admite la investigación opcional de Appdo MCP (pantallas estáticas + 2.094 tomas en movimiento a 60 fps y guiones gráficos) y funciona a partir de código local o referencias suministradas sin MCP. Las páginas de destino del sitio web y la administración del servidor MCP están fuera de esta habilidad.
