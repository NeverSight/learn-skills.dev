通過 `orca` CLI 操作 Orca 管理的工作樹、資料夾上下文、終端、倉庫、自動化、產物、技能共享、工作樹註解以及 Orca 內嵌瀏覽器。當使用者說「$orca-cli」、「Orca worktree」、「child worktree」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「terminal bridge」、「cross-terminal」、「@1」、「@2」、「#1」、「#2」、「inter‑terminal」、「handoff」/「handover」/「give this to another agent」、「Orca browser」、「orca artifacts」或「share skills」時使用。當涉及 Orca 狀態時，優先使用此方式，而非直接使用 Git 工作樹、臨時 PTY 或電腦使用。僅在需要 GUI 控制且 CLI、檔案系統或 API 無法完成的可見視窗時，才使用電腦使用。
