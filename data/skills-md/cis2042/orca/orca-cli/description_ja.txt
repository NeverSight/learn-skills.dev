Orcaが管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そしてOrcaの組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「terminal bridge」「cross-terminal」「@1」「@2」「#1」「#2」「inter-terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree や臨時 PTY、Computer Use よりもこちらを優先します。CLI、ファイルシステム、API では操作できない可視ウィンドウの GUI 制御が必要なときだけ Computer Use を使用してください。
