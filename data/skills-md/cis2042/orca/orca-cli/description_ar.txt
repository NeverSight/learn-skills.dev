تشغيل شجرات العمل التي تديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca من خلال سطر أوامر `orca`. استخدمه عندما يذكر المستخدم "$orca-cli"، أو "Orca worktree"، أو "child worktree"، أو "spawn codex/claude in a worktree"، أو "read/wait/send Orca terminal"، أو "terminal bridge"، أو "cross-terminal"، أو "@1"، أو "@2"، أو "#1"، أو "#2"، أو "inter-terminal"، أو "handoff" / "handover" / "give this to another agent"، أو "Orca browser"، أو "orca artifacts"، أو "share skills". فضّل استخدامه على شجرة git العادية، أو PTYs المؤقتة، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم "Computer Use" فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة المستخدم الرسومية لا يمكن لسطر الأوامر أو نظام الملفات أو API تحقيقه. الرجاء الرد دائمًا بلغة المستخدم.
