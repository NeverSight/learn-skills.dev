Exploitez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via la CLI `orca`. Utilisez‑le lorsque l’utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « terminal bridge », « cross-terminal », « @1 », « @2 », « #1 », « #2 », « inter-terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Privilégiez‑le plutôt qu’un worktree git brut, des PTY ad‑hoc ou l’utilisation de l’ordinateur lorsque l’état d’Orca est impliqué. N’utilisez l’ordinateur que lorsqu’une fenêtre visible requiert un contrôle GUI qu’une CLI, le système de fichiers ou une API ne peuvent assurer.

Veuillez toujours répondre dans la langue de l’utilisateur.
