通过 `orca` CLI 操作 Orca 管理的工作树、文件夹上下文、终端、仓库、自动化、制品、技能共享、工作树评论以及 Orca 的嵌入式浏览器。当用户说 “$orca-cli”、 “Orca worktree”、 “child worktree”、 “spawn codex/claude in a worktree”、 “read/wait/send Orca terminal”、 “terminal bridge”、 “cross-terminal”、 “@1”、 “@2”、 “#1”、 “#2”、 “inter-terminal”、 “handoff”/“handover”/“give this to another agent”、 “Orca browser”、 “orca artifacts” 或 “share skills” 时使用。涉及 Orca 状态时，优先使用它而非原始 git worktree、临时 PTY 或电脑使用。只有在需要对可见窗口进行 GUI 控制且 CLI、文件系统或 API 无法完成时才使用电脑使用。
