Implementa e corregge le integrazioni dell'API Translator del browser in app web JavaScript o TypeScript. Usalo quando aggiungi controlli di supporto del Translator, flussi di disponibilità delle coppie di lingue, UX di download del modello, creazione di sessioni, chiamate a translate() o translateStreaming(), misurazione dell'uso dell'input o gestione della permissions‑policy per la traduzione on‑device. Non usarlo per SDK di traduzione lato server, servizi di traduzione cloud o pipeline di contenuti multilingue generici.

Rispondi sempre nella lingua dell'utente.
