Реализует и отлаживает интеграцию браузерного API Translator в веб‑приложениях на JavaScript или TypeScript. Используйте при добавлении проверок поддержки Translator, потоков проверки доступности пар языков, интерфейса загрузки модели, создания сессии, вызовов translate() или translateStreaming(), измерения использования ввода или обработки политики разрешений для перевода на устройстве. Не используйте для серверных SDK перевода, облачных сервисов перевода или общих многоязычных конвейеров контента.

Пожалуйста, всегда отвечайте на языке пользователя.
