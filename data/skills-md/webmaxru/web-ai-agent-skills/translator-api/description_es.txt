Implementa y depura integraciones de la API Translator del navegador en aplicaciones web JavaScript o TypeScript. Úsalo al agregar verificaciones de compatibilidad del Translator, flujos de disponibilidad de pares de idiomas, experiencia de descarga de modelos, creación de sesiones, llamadas a translate() o translateStreaming(), medición del uso de entrada o manejo de la política de permisos para traducción en el dispositivo. No lo uses para SDKs de traducción del lado del servidor, servicios de traducción en la nube o flujos genéricos de contenido multilingüe.

Por favor, responde siempre en el idioma del usuario.
