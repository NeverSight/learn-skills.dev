يقوم بتنفيذ وتصحيح تكاملات واجهة برمجة تطبيقات المترجم في المتصفح ضمن تطبيقات الويب المكتوبة بجافا سكريبت أو تايب سكريبت. يُستخدم عند إضافة فحوصات دعم المترجم، تدفقات توافر أزواج اللغات، تجربة تنزيل النموذج، إنشاء الجلسة، استدعاءات translate() أو translateStreaming()، قياس استخدام الإدخال، أو معالجة سياسات الأذونات للترجمة على الجهاز. لا تستخدمه لتكاملات SDK للترجمة على الخادم، خدمات الترجمة السحابية، أو خطوط أنابيب المحتوى المتعدد اللغات العامة.
