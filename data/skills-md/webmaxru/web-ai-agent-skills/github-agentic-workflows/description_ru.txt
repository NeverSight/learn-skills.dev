Авторы, ревью, установка и отладка GitHub Agentic Workflows в репозиториях, включая markdown рабочих процессов, frontmatter, компиляцию и запуск gh aw, безопасные выводы, меры безопасности и операционные шаблоны. Используйте при создании или поддержке автоматизации GH‑AW. Не используйте для стандартных детерминированных GitHub Actions YAML, общих CI‑конвейеров или автоматизации вне GitHub.
