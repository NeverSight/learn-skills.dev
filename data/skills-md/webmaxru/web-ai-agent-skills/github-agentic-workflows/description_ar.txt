المؤلفون، المراجعون، المثبتون ومصححو الأخطاء لعمليات GitHub Agentic Workflows في المستودعات، بما في ذلك markdown الخاص بسير العمل، البيانات الأولية، تجميع وتشغيل تدفقات gh aw، المخرجات الآمنة، حواجز الأمان، والأنماط التشغيلية. استخدمه عند إنشاء أو صيانة أتمتة GH-AW. لا تستخدمه للـ GitHub Actions العادي المحدد بـ YAML، أو أنابيب CI العامة، أو أنظمة الأتمتة غير التابعة لـ GitHub.
