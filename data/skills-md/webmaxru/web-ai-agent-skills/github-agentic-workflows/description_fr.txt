Écrit, examine, installe et débogue les GitHub Agentic Workflows dans les dépôts, y compris le markdown des workflows, le front‑matter, la compilation et l’exécution des flux gh aw, les sorties sécurisées, les garde‑fous de sécurité et les modèles opérationnels. À utiliser lors de la création ou de la maintenance de l’automatisation GH‑AW. Ne pas utiliser pour les YAML GitHub Actions standards et déterministes, les pipelines CI génériques ou les systèmes d’automatisation hors GitHub.
