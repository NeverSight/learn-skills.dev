Utilisez lorsque qu'un agent doit créer une vidéo HyperFrames d'un morceau de live‑coding Strudel, où le code même constitue l'image et chaque jeton s’allume sur la note qu’il joue. Déclencheur : « strudel video », « live coding video », « show my code playing », « make a video of this track with the code », « prod by claude ». Couvre la composition du morceau, l’enregistrement hors ligne depuis le Strudel épinglé, et la création de la vidéo 1080 x 1080 (ouverture tapée, parties qui s’allument, changements réels de thème Strudel, chutes d’ASCII graffiti, clôture tapée). Veuillez toujours répondre dans la langue de l'utilisateur.
