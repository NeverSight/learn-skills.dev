Используется, когда агенту необходимо создать HyperFrames‑видео трека Strudel в стиле live‑coding, где сам код является картинкой, а каждый токен светится в момент проигрывания ноты. Запуск по команде: «strudel video», «live coding video», «show my code playing», «make a video of this track with the code», «prod by claude». Охватывает композицию трека, его офлайн‑запись из закреплённого Strudel и сборку видео 1080×1080 (набираемый открывающий кадр, части, включающиеся, реальные переключения тем Strudel, граффити‑ASCII‑вставки, набираемый завершающий текст).
