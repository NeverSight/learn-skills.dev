Nutzung, wenn ein Agent ein HyperFrames‑Video eines Strudel‑Live‑Coding‑Tracks erstellen muss, bei dem der Code selbst das Bild ist und jedes Token bei der gespielten Note aufleuchtet. Auslösen mit: „strudel video“, „live coding video“, „show my code playing“, „make a video of this track with the code“, „prod by claude“. Deckt das Komponieren des Tracks, das Aufzeichnen offline vom angepinnten Strudel und das Erstellen des 1080 × 1080‑Videos ab (getippter Einstieg, Teile schalten ein, echte Strudel‑Themenwechsel, Graffiti‑ASCII‑Drops, getippter Abschluss).
