Online search tool – simultaneously calls Doubao Search and Parallel, deduplicates and merges the results, then compresses the output according to the character budget. Dual sources operate in parallel by default with equal-weight fusion: Doubao provides Chinese sites, Volcano Ruyi cards, and industry filters, while Parallel supplements English and long-tail sources. Supports web search, image search, and full-text extraction. All results are saved to disk as JSON for follow‑up queries.
