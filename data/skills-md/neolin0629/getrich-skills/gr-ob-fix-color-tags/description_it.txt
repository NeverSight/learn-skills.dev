Avvolgi in batch i codici colore esadecimali nelle note Obsidian (ad es., prompt raw‑image generati da grandi modelli) con parentesi a larghezza intera (#FFFFFF → （#FFFFFF）) per evitare che # venga riconosciuto come tag. Scansiona i file .md in una directory specificata dall'utente, saltando automaticamente i blocchi di codice, i collegamenti, il frontmatter e gli elementi già avvolti. Compatibile con macOS / Linux.  
Comandi di attivazione: /gr-ob-fix-color-tags, /gr-fix-color-tags, /escape-color-codes, “fix color tags”.  

Rispondi sempre nella lingua dell'utente.
