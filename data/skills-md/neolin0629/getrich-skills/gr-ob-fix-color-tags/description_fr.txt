Enveloppez en lot les codes couleur hexadécimaux dans les notes Obsidian (par exemple, les invites d’images brutes générées par de grands modèles) avec des crochets pleine largeur (#FFFFFF → （#FFFFFF）) afin d'empêcher « # » d’être reconnu comme une étiquette. Analysez les fichiers *.md* d’un répertoire spécifié par l’utilisateur, en sautant automatiquement les blocs de code, les liens, le front‑matter et les éléments déjà enveloppés. Fonctionne sous macOS / Linux.  
Commandes déclenchées : /gr-ob-fix-color-tags, /gr-fix-color-tags, /转义颜色代码, « fix color tags ».
