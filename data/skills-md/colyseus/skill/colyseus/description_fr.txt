Colyseus 0.18 serveurs et clients de jeux multijoueurs : salles, synchronisation d’état Schema, callbacks d’état, reconnexion, matchmaking, SDK client, prédiction côté client. Utilisez‑le lorsque colyseus, @colyseus/schema, @colyseus/sdk ou colyseus.js apparaît dans la tâche ou dans le package.json, avant d’écrire tout code Room ou Schema, et lorsqu’un projet contient du code pré‑0.17 tel que getStateCallbacks(), génériques Room<State>, onLeave(client, consented), @filter() ou new Server().
