Run /oversee to implement coding work through worker subagents, such as a task, a ready plan, or findings to fix. The manager plans, briefs workers, waits without polling, then checks their changes and runs the checks itself. Implementation only. Never use it to audit, review, map, research, or explain a codebase, and a finished run does not carry over to later requests. Activate only for an actual /oversee invocation, the host's equivalent skill selection, or an explicit request to oversee delegated coding work. Discussing the skill, quoting invocations, and ordinary coding questions do not activate it.
