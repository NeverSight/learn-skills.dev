Generar visualizaciones de texto narrativo estructurado a partir de datos utilizando la sintaxis T8. Se utiliza cuando los usuarios desean crear informes de interpretación de datos, resúmenes o artículos estructurados con anotaciones de entidades semánticas. T8 está diseñado para la visualización de datos no estructurados, donde T significa Texto y 8 representa un byte de 8 bits, que simboliza información profunda debajo del texto.
