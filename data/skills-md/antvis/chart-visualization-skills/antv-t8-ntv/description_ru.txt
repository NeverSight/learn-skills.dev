Создавайте структурированные повествовательные текстовые визуализации из данных с помощью синтаксиса T8. Используйте, когда пользователи хотят создавать отчёты по интерпретации данных, резюме или структурированные статьи с семантической аннотацией сущностей. T8 предназначен для визуализации неструктурированных данных, где T означает Text, а 8 представляет байт из 8 бит, символизируя глубокие инсайты, скрытые за текстом.
