Use cuando el código debe ser verificado, no asumido: rastrear conexiones (llamadores, importaciones, cableado entre repos, qué se rompe si lo cambio), localizar comportamiento, mapear un sistema, diagnosticar una falla, RCA. También para repositorios externos, paquetes npm, arte previo/ascendente y investigación general. Planifique un flujo de codificación antes de escribir, valídelo después. Se activa con “research this” o “use octocode”. Proporciona evidencia exacta de archivo:línea/PR/commit con confianza. Omitir ediciones triviales cuyo radio de explosión ya se conoce. No es para redactar o corregir los documentos mismos, ni para crear carpetas de habilidades: entregable de docs → octocode-documentation; carpetas SKILL.md → octocode-skills.

Por favor, responda siempre en el idioma del usuario.
