À utiliser lorsque les documents sont manquants, incorrects, obsolètes ou mal rédigés, ou lorsqu'ils doivent être révisés conformément au guide de style de Google : README, référence d'API, runbook, CONTRIBUTING, journal des modifications, onboarding, AGENTS.md/CLAUDE.md, ADR, guide de migration, Diátaxis ou restructuration de l'ensemble de la base de code, docstrings, texte alternatif, vérification de la qualité rédactionnelle. Ne concerne pas le code, les commits ou les textes marketing. Analyse du code → octocode-research ; dossiers SKILL.md → octocode-skills.
