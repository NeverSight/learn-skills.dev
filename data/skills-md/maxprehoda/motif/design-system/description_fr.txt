Construit un système de design pour une base de code et le maintient appliqué, en exécutant cinq phases dans l’ordre : mesurer les espacements, les polices et les valeurs de couleur utilisées, finaliser les décisions de conception avec l’utilisateur, les écrire sous forme de tokens, mettre à jour le code pour qu’il utilise les tokens, puis installer un linter. À utiliser lorsque l’utilisateur veut un système de design, indique que son interface est incohérente ou demande de standardiser les espacements, la typographie ou les couleurs.
