Erstellt ein Designsystem für eine Codebasis und sorgt für dessen Durchsetzung, indem fünf Phasen nacheinander durchgeführt werden: die Abstände, Schriftarten und Farbwerte messen, die Designentscheidungen mit dem Benutzer abstimmen, sie als Tokens festlegen, den Code aktualisieren, um die Tokens zu verwenden, und einen Linter installieren. Verwenden, wenn der Benutzer ein Designsystem wünscht, seine UI als inkonsistent bezeichnet oder die Standardisierung von Abstand, Schrift oder Farbe fordert.
