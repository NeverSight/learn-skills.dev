Construye un sistema de diseño para una base de código y lo mantiene aplicado, ejecutando cinco fases en orden: medir el espaciado, los valores de tipografía y color en uso, acordar las decisiones de diseño con el usuario, escribirlas como tokens, actualizar el código para usar los tokens e instalar un linter. Úsalo cuando el usuario quiera un sistema de diseño, indique que su UI es inconsistente o solicite estandarizar el espaciado, la tipografía o el color.
