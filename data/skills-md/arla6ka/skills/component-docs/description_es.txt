Escribe la entrada de documentación de un componente desde su código, historias y sitios de llamadas reales, en un orden de página de estilo Geist. Utilícelo para "documentar el botón", "escribir documentos para Seleccionar", "qué estados tiene Toast", reglas de uso para un componente o un componente nuevo o modificado. Omita los fundamentos, las páginas de descripción general y los patrones de múltiples componentes. Los documentos para todo un sistema de diseño van a design-system-boss.
