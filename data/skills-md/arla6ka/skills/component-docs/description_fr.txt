Écrit l'entrée de documentation d'un composant à partir de son code, de ses histoires et de ses sites d'appels réels, dans un ordre de page de style Geist. Utilisez pour "documenter le bouton", "écrire des documents pour Select", "quels sont les états de Toast", les règles d'utilisation d'un composant ou d'un composant nouveau ou modifié. Ignorez les fondations, les pages d'aperçu et les motifs multi-composants. Les documents pour un système de conception complet vont à design-system-boss.
