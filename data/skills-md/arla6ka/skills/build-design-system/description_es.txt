Se usa cuando una pregunta nombra una fase del trabajo del sistema de diseño, como "extraer tokens de la aplicación" o "agregar estados y especificaciones a nuestro botón", o para un repositorio vacío, como "iniciar un sistema de diseño desde cero". Una solicitud de aplicación completa en una aplicación enviada ("necesitamos un sistema de diseño") se envía al jefe del sistema de diseño cuando está instalada. Mover una aplicación a un sistema existente es migrate-design-system.
