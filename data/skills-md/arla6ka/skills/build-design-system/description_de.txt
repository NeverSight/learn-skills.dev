Wird verwendet, wenn eine Anfrage eine Phase der Arbeit des Designsystems benennt, z. B. „Token aus der App extrahieren“ oder „Zustände und Spezifikationen zu unserer Schaltfläche hinzufügen“, oder für ein leeres Repo, z. B. „ein Designsystem von Grund auf neu starten“. Eine vollständige App-Anfrage zu einer ausgelieferten App („Wir brauchen ein Designsystem“) geht bei der Installation an den Chef des Designsystems. Das Verschieben einer App auf ein bestehendes System ist migrate-design-system.
