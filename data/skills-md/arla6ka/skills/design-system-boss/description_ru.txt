Используется для неопределённых запросов по всей системе дизайна в приложении, которое уже поставляет UI, например «наш UI — бардак, исправьте его», «нам нужна система дизайна», «мы везде хард‑кодим цвета», «сделайте кнопки одинаковыми для upstream PR», «документируйте всю нашу систему дизайна» или «проверьте приложение перед релизом». Приоритизирует (триажирует) приложение, затем последовательно запускает навыки design.how. Один названный экран отправляется в ui-review, один компонент — в component-docs, пустой репозиторий — в build-design-system. Пожалуйста, всегда отвечайте на языке пользователя.
