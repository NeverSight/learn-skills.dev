Utilícelo para un vago sistema de diseño de aplicaciones completas en una aplicación que ya incluye la interfaz de usuario, como "nuestra interfaz de usuario es un desastre, arréglalo", "necesitamos un sistema de diseño", "codificamos colores en todas partes", "hacemos que los botones sean consistentes para un PR ascendente", "documente todo nuestro sistema de diseño" o "verifique la aplicación antes de enviarla". Triaja la aplicación y luego ejecuta las habilidades de design.how en orden. Una pantalla con nombre va a ui-review, un componente a component-docs, un repositorio vacío a build-design-system.
