Verwenden Sie für vage ganze App-Design-System fragt auf einer App, die bereits UI versendet, wie "unsere UI ist ein Chaos, beheben Sie es", "wir brauchen ein Design-System", "wir Hardcode-Farben überall", "machen die Schaltflächen konsistent für eine Upstream-PR", "dokumentieren unser ganzes Design-System" oder "überprüfen Sie die App, bevor ich versende". Triagiert die App und führt dann die design.how-Fähigkeiten in der richtigen Reihenfolge aus. Ein benannter Bildschirm geht an ui-review, eine Komponente an component-docs, ein leerer Repo an build-design-system.
