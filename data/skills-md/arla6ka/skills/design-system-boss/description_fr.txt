Utilisez pour les demandes vagues de système de conception d'applications complètes sur une application qui est déjà livrée avec une interface utilisateur, comme « notre interface utilisateur est un gâchis, corrigez-la », « nous avons besoin d'un système de conception », « nous codons en dur les couleurs partout », « rendons les boutons cohérents pour une PR en amont », « documentez tout notre système de conception » ou « vérifiez l'application avant de l'expédier ». Trie l'application, puis exécute les compétences design.how dans l'ordre. Un écran nommé passe à ui-review, un composant à component-docs, un repo vide à build-design-system.
