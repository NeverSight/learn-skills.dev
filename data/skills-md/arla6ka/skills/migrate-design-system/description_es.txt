Se utiliza cuando una aplicación tiene que pasar a un sistema de diseño que ya existe, como "migrar la aplicación a nuestro sistema de diseño", "mover todas las pantallas a los nuevos componentes", una implementación o una auditoría de adopción. Cuando se instala design-system-boss y nadie ha verificado las especificaciones del sistema, el jefe se clasifica primero, ya que una migración copia las brechas de un sistema débil en todas partes. No para hacer el sistema.
