Usa quando un'app deve passare a un sistema di design già esistente, ad esempio “migrare l'app al nostro sistema di design”, “spostare ogni schermata sui nuovi componenti”, un rollout o un audit di adozione. Quando design-system-boss è installato e nessuno ha verificato le specifiche del sistema, il boss gestisce le priorità per primo, poiché una migrazione copia le lacune di un sistema debole ovunque. Non serve per creare il sistema.
