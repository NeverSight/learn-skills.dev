Zeigt an, wie hartcodierte Stilwerte auf einer Seite, einer Datei oder einem Diff die vorhandenen Design-Token eines Projekts abbilden, zuerst den Zweck und dann den Wert. Verwenden Sie für "verwenden wir unsere Token hier", "welche hartcodierten Farben auf welche Token abgebildet werden", ein Token-Audit oder die Planung einer Token-Migration. Es bearbeitet niemals und erstellt oder benennt niemals Token um. Korrekturen und Konsistenz der gesamten App gehen an design-system-boss.
