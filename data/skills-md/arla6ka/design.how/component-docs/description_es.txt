Usa para escribir la entrada de documentación de un componente a partir de su código, historias y sitios de llamada reales, como “documentar el botón”, “escribir docs para Select”, “qué estados tiene Toast”, o reglas de uso para un componente nuevo o modificado. No es para fundamentos o páginas que abarcan varios componentes, lo cual ninguna habilidad aquí escribe, ni para cambiar el componente, lo cual es build-design-system.
