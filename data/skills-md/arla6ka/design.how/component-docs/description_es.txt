Utilícelo para escribir la entrada de documentación de un componente desde su código, historias y sitios de llamadas reales, como "documentar el botón", "escribir documentos para Select", "qué estados tiene Toast" o reglas de uso para un componente nuevo o modificado. No para fundaciones o páginas que abarcan componentes, que ninguna habilidad aquí escribe, ni para cambiar el componente, que es build-design-system.
