Используется для написания документации к отдельному компоненту на основе его кода, историй и реальных мест вызова, например «документировать кнопку», «написать docs для Select», «какие состояния у Toast», или правила использования нового или изменённого компонента. Не предназначено для фундаментальных элементов или страниц, охватывающих несколько компонентов, которые здесь не описываются, и не для изменения самого компонента, что относится к build-design-system.
