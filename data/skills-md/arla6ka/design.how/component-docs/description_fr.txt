Utilisé pour rédiger l’entrée de documentation d’un composant à partir de son code, de ses stories et de ses appels réels, par exemple « documenter le bouton », « rédiger la doc pour Select », « quels états possède Toast » ou les règles d’usage d’un nouveau composant ou d’un composant modifié. Pas pour les fondations ou les pages qui couvrent plusieurs composants, ce que aucune compétence ici n’écrit, ni pour modifier le composant, qui relève de build‑design‑system.

Veuillez toujours répondre dans la langue de l’utilisateur.
