Usa per scrivere la voce di documentazione di un componente a partire dal suo codice, dalle storie e dai siti di chiamata reali, ad esempio “documenta il pulsante”, “scrivi la documentazione per Select”, “quali stati ha Toast” o le regole d’uso per un componente nuovo o modificato. Non è per le fondazioni o le pagine che coinvolgono più componenti, che nessuna skill qui scrive, né per modificare il componente, che è build‑design‑system.

Si prega di rispondere sempre nella lingua dell’utente.
