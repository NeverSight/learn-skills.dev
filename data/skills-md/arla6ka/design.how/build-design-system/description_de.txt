Verwenden Sie diese Option, wenn jemand ein Designsystem aus der Benutzeroberfläche erstellen möchte, das bereits von einer App ausgeliefert wird, oder eine Phase davon, z. B. „Token aus der App extrahieren“, „Zustände zu unserer Schaltfläche hinzufügen“, „die hartcodierten Farben durch Token ersetzen“ oder „ein Designsystem starten“. Das Verschieben von Bildschirmen auf die Komponenten eines bestehenden Systems ist ein Migrate-Design-System. Eine vage Frage in der gesamten App geht an den Chef des Design-Systems.
