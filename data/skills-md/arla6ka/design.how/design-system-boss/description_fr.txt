Utilisé pour les demandes vagues de système de design à l'échelle de l'application sur une appli qui possède déjà une UI, telles que « notre UI est un désordre, corrigez‑le », « nous avons besoin d’un système de design », « nous codons en dur les couleurs partout », « uniformisez les boutons » ou « vérifiez l’appli avant que je la déploie ». Un écran nommé va vers ui‑review, un composant vers component‑docs, un rapport de tokens vers token‑mapping. Un dépôt sans UI pour l’instant est hors de portée.

Veuillez toujours répondre dans la langue de l'utilisateur.
