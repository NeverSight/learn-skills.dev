Utilisez pour les demandes vagues de système de conception d'applications complètes sur une application qui fournit déjà une interface utilisateur, telles que « notre interface utilisateur est un gâchis, corrigez-la », « nous avons besoin d'un système de conception », « nous codons les couleurs partout », « rendons les boutons cohérents » ou « vérifiez l'application avant de l'expédier ». Un écran nommé passe à ui-review, un composant à component-docs, un rapport de jeton à token-mapping. Un repo sans interface utilisateur est hors de portée.
