Verwenden Sie für vage Fragen zum gesamten App‑Designsystem bei einer App, die bereits UI ausliefert, wie z. B. „Unsere UI ist ein Chaos, behebe das“, „Wir brauchen ein Designsystem“, „Wir hardcoden überall Farben“, „Mach die Buttons konsistent“ oder „Überprüfe die App, bevor ich sie ausliefere“. Ein benannter Screen geht zu ui‑review, eine Komponente zu component‑docs, ein Token‑Report zu token‑mapping. Ein Repository ohne UI ist nicht im Umfang.

Bitte immer in der Sprache des Benutzers antworten.
