Verwenden Sie für vage ganze App-Design-System fragt auf einer App, die bereits UI versendet, wie "unsere UI ist ein Chaos, beheben Sie es", "wir brauchen ein Design-System", "wir Hardcode-Farben überall", "machen die Schaltflächen konsistent" oder "überprüfen Sie die App, bevor ich versende". Ein benannter Bildschirm geht an ui-review, eine Komponente an component-docs, ein Token-Report an token-mapping. Ein Repo ohne UI ist noch nicht im Scope.
