Используется для размытых запросов по целой системе дизайна в приложении, которое уже имеет UI, например: «наш UI — бардак, исправьте», «нам нужна система дизайна», «мы везде хардкодим цвета», «сделайте кнопки одинаковыми» или «проверьте приложение перед выпуском». Один названный экран отправляется в ui‑review, один компонент — в component‑docs, отчёт по токенам — в token‑mapping. Репозиторий без UI пока выходит за рамки.
