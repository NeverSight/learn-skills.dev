Usa per richieste vaghe di design system a livello di tutta l'app su un'app che già distribuisce UI, come „la nostra UI è un caos, sistemala“, „ci serve un design system“, „hardcodiamo i colori ovunque“, „rendete i pulsanti coerenti“ o „controlla l'app prima di rilasciarla“. Una schermata denominata va a ui‑review, un componente a component‑docs, un report sui token a token‑mapping. Un repository senza UI è fuori ambito.

Per favore rispondi sempre nella lingua dell'utente.
