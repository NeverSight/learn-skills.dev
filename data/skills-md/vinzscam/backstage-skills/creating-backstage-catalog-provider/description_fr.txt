Utilisez-le lors de la création d’un module backend de catalogue qui ingère des entités provenant d’une source externe (par ex. Azure DevOps, API interne, fichier JSON). Couvre à la fois le fournisseur d’entités standard et l’IncrementalEntityProvider pour les sources à gros volume, ainsi que le raccordement du module via catalogProcessingExtensionPoint ou incrementalIngestionProvidersExtensionPoint. Se déclenche sur des expressions telles que « catalog provider », « ingérer des entités depuis X », « importer des entités depuis <source> » ou « ingestion incrémentielle ».
