Usa quando si costruisce un modulo backend del catalogo che ingerisce entità da una fonte esterna (ad es. Azure DevOps, API interna, file JSON). Copre sia l'EntityProvider normale sia l'IncrementalEntityProvider per sorgenti di grande volume, oltre al collegamento del modulo tramite catalogProcessingExtensionPoint o incrementalIngestionProvidersExtensionPoint. Si attiva con frasi come “catalog provider”, “ingest entities from X”, “import entities from <source>”, o “incremental ingestion”.
