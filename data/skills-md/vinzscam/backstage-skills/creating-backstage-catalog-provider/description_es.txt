Úselo al crear un módulo de backend de catálogo que ingiere entidades de una fuente externa (p. ej., Azure DevOps, API interna, archivo JSON). Cubre tanto el EntityProvider normal como el IncrementalEntityProvider para fuentes de gran volumen, además del cableado del módulo mediante catalogProcessingExtensionPoint o incrementalIngestionProvidersExtensionPoint. Se activa con frases como "catalog provider", "ingest entities from X", "import entities from <source>" o "incremental ingestion".
