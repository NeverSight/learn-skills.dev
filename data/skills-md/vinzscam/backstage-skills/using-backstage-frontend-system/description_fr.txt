Utilisez-le lors de la définition ou de la création d’extensions pour un plugin frontend Backstage dans le nouveau système frontend. Couvre **createFrontendPlugin**, les références de routes provenant de **@backstage/frontend-plugin-api**, **ApiBlueprint**, **PageBlueprint**, **SubPageBlueprint** et l’utilisation des hooks. S’active sur les imports depuis **@backstage/frontend-plugin-api** ou lors de l’écriture de **src/plugin.tsx**, **src/routes.ts**, **src/apis.ts**, **src/extensions.tsx**.

Veuillez toujours répondre dans la langue de l’utilisateur.
