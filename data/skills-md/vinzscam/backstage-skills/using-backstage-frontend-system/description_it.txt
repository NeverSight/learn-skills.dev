Usa quando definisci o crei estensioni per un plugin frontend di Backstage nel nuovo sistema frontend. Copre `createFrontendPlugin`, i riferimenti di rotta da `@backstage/frontend-plugin-api`, `ApiBlueprint`, `PageBlueprint`, `SubPageBlueprint` e l'uso degli hook. Si attiva su import da `@backstage/frontend-plugin-api` o quando scrivi `src/plugin.tsx`, `src/routes.ts`, `src/apis.ts`, `src/extensions.tsx`.
