Verwenden Sie es beim Definieren oder Erstellen von Erweiterungen für ein Backstage-Frontend-Plugin im neuen Frontendsystem. Deckt createFrontendPlugin, Route‑Refs aus @backstage/frontend-plugin-api, ApiBlueprint, PageBlueprint, SubPageBlueprint und die Verwendung von Hooks ab. Wird ausgelöst bei Importen aus @backstage/frontend-plugin-api oder beim Schreiben von src/plugin.tsx, src/routes.ts, src/apis.ts, src/extensions.tsx.
