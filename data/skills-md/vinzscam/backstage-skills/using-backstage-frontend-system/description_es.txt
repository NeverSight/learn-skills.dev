Utilízalo al definir o crear extensiones para un plugin frontend de Backstage en el nuevo sistema frontend. Cubre createFrontendPlugin, referencias de rutas de @backstage/frontend-plugin-api, ApiBlueprint, PageBlueprint, SubPageBlueprint y el uso de hooks. Se activa con importaciones de @backstage/frontend-plugin-api o al escribir src/plugin.tsx, src/routes.ts, src/apis.ts, src/extensions.tsx.
