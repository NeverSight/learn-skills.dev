Используется при определении или разработке расширений для фронтенд‑плагина Backstage в новой системе фронтенда. Охватывает createFrontendPlugin, ссылки на маршруты из @backstage/frontend-plugin-api, ApiBlueprint, PageBlueprint, SubPageBlueprint и использование хуков. Срабатывает при импортах из @backstage/frontend-plugin-api либо при работе с src/plugin.tsx, src/routes.ts, src/apis.ts, src/extensions.tsx.
