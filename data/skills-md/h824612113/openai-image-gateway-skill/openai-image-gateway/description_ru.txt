Используйте OpenAI-совместимый шлюз изображений для преобразования текста в изображение или создания эталонного изображения с одноразовой локальной конфигурацией. Запускается, когда пользователь запрашивает создание изображения через настроенный шлюз, использование эталонного изображения, проверку подключения шлюза, обновление настроек шлюза или сохранение созданных выходных данных по указанному локальному пути.
