Utilizza un gateway immagine compatibile con OpenAI per la generazione di testo in immagine o immagine di riferimento con configurazione locale una tantum. Si attiva quando l'utente chiede di generare un'immagine tramite un gateway configurato, utilizzare un'immagine di riferimento, testare la connettività del gateway, aggiornare le impostazioni del gateway o salvare l'output generato in un percorso locale specificato.
