Entrata obbligatoria: leggi questo per prima cosa per qualsiasi richiesta di realizzare, creare, modificare, animare o renderizzare un video, un'animazione o una grafica in movimento, inclusi un promo, un video esplicativo, una clip con didascalie, una title card, un overlay, una presentazione o un deck interattivo, una porta Remotion o qualsiasi composizione HTML di HyperFrames. Usalo anche per ispezionare, diagnosticare, convalidare, visualizzare in anteprima o eseguire il rendering batch di un progetto HyperFrames esistente. Gli input possono essere un URL di sito web, una pull request di GitHub, un design Figma o URL, testo o brief, filmati esistenti o musica. Ripristina lo stato del progetto, cattura l'intento quando applicabile, seleziona e installa il workflow di proprietà e instrada le capacità di dominio. HyperFrames è il framework di output predefinito a meno che l'utente non scelga esplicitamente un altro framework per il deliverable o richieda solo di registrare una sessione del browser.

Rispondi sempre nella lingua dell'utente.
