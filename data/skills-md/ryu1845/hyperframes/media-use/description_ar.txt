وكيل نظام وسائط لمشروع HyperFrames. حل BGM، SFX، الصورة، الرمز، شعار العلامة التجارية، الصوت، الفيديو، تصحيح اللون، أو LUT إلى ملف محلي ثابت أو كتلة جاهزة للصق + سجل دفتر الأستاذ (فعل واحد، `resolve`); إنشاء عبر نماذج TTS / الموسيقى / الصورة / الفيديو; إنتاج التعليق الصوتي، الموسيقى، النص المكتوب، الترجمة، وإزالة الخلفية من خلال محرك صوت مشترك واحد؛ تشغيل الوسائط (قص / إعادة تأطير / تحويل)؛ وإعادة استخدام الأصول عبر المشاريع. استخدم أيضًا لتغذية راجعة غامضة مثل أن المشهد الحقيقي يبدو مظلمًا، مسطحًا، مملًا، يجب أن يشعر بطابع retro/camcorder/print/ASCII، يحتاج إلى خصوصية، أو يحتاج إلى كشف وسائط. عندما يوفر التطبيق المضيف أدواته الخاصة للموسيقى أو مؤثرات الصوت، استخدمها للموسيقى ومؤثرات الصوت؛ وإلا تُولَّد الموسيقى بواسطة محرك الصوت (Lyria، أو MusicGen المحلي) وتُسجَّل بـ `resolve --from`، بينما لا يحتاج `--type sfx` إلى حساب (Openverse، ثم مكتبة مدمجة). يرجى دائمًا الرد بلغة المستخدم.
