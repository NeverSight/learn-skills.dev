Agent Media OS 用于 HyperFrames 项目。将 BGM、SFX、图像、图标、品牌标志、语音、视频、颜色分级或 LUT 解析为冻结的本地文件或可粘贴块 + 账本记录（单一动词 `resolve`）；通过 TTS / 音乐 / 图像 / 视频模型生成；通过同一音频引擎生成配音、音乐、转录、字幕和背景去除；对媒体进行剪切 / 重新构图 / 变换操作；并在项目之间复用资产。也可用于对模糊反馈的处理，例如真实画面显得暗淡、平坦、乏味，需呈现复古/摄像机/印刷/ASCII 风格，需要隐私，或需要媒体揭示。当宿主应用提供自己的音乐或音效工具时，使用它们进行音乐和音效；否则音乐由音频引擎（Lyria 或本地 MusicGen）生成，并使用 `resolve --from` 记录，而 `--type sfx` 则无需账户（Openverse，然后是捆绑库）。
