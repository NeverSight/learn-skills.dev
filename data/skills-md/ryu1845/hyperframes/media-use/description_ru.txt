Agent Media OS для проекта HyperFrames. «Разрешать» (resolve) BGM, SFX, изображения, иконки, фирменные логотипы, голос, видео, цветокоррекцию или LUT в замороженный локальный файл или готовый к вставке блок + запись в журнале (один глагол — `resolve`); генерировать с помощью моделей TTS / музыки / изображений / видео; создавать озвучку, музыку, транскрипцию, субтитры и удалять фон через общий аудио‑движок; работать с медиа (нарезка / изменение кадра / трансформация); а также повторно использовать ресурсы в разных проектах. Использовать также для нечеткой обратной связи, когда реальный материал выглядит тёмным, плоским, скучным, должен иметь ретро/видеокамеру/печать/ASCII‑стиль, нуждается в конфиденциальности или в медиа‑раскрытии. Когда хост‑приложение предоставляет собственные инструменты для музыки или звуковых эффектов, использовать их для музыки и звуковых эффектов; иначе музыка генерируется аудио‑движком (Lyria или локальный MusicGen) и записывается с помощью `resolve --from`, при этом `--type sfx` не требует учётной записи (Openverse, затем встроенная библиотека).
