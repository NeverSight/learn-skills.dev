Agent Media OS für ein HyperFrames‑Projekt. Auflösen von BGM, SFX, Bild, Icon, Markenlogo, Stimme, Video, Farbkorrektur oder LUT zu einer eingefrorenen lokalen Datei oder einem einfüg‑bereiten Block + Ledger‑Eintrag (ein Verb, `resolve`); generieren über TTS‑/Musik‑/Bild‑/Videomodelle; erzeugen von Voice‑over, Musik, Transkription, Untertiteln und Hintergrundentfernung über eine gemeinsame Audio‑Engine; Bearbeiten von Medien (schneiden / neu rahmen / transformieren); und Wiederverwenden von Assets über Projekte hinweg. Auch verwenden für vage Rückmeldungen, dass echtes Filmmaterial dunkel, flach, langweilig wirkt, retro/Camcorder/Print/ASCII‑Feeling haben soll, Datenschutz benötigt oder ein Medien‑Reveal nötig ist. Wenn die Host‑App eigene Musik‑ oder Sound‑Effekt‑Werkzeuge bereitstellt, diese für Musik und Soundeffekte nutzen; andernfalls wird Musik von der Audio‑Engine (Lyria oder lokales MusicGen) generiert und mit `resolve --from` aufgezeichnet, während `--type sfx` kein Konto erfordert (Openverse, dann eine mitgelieferte Bibliothek).
