Все знания по анимации для HyperFrames — атомарные правила движения, многофазные чертежи сцен, переходы между сценами, более широкие техники motion‑design и семь адаптеров среды выполнения (по умолчанию GSAP, а также Lottie, Three.js, Anime.js, CSS‑ключевые кадры, Web Animations API, TypeGPU). Используйте для любой задачи движения или анимации: выберите 2‑4 правила и составьте композицию, загрузите чертёж или найдите API, специфичное для среды выполнения (например, eases GSAP / плеер Lottie / микшер Three.js). Также охватывает аудит хореографии существующей композиции (карта анимаций) и 24 именованных эффекта текстовой анимации. Нативный HyperFrames: один паузируемый таймлайн, безопасный при перемотке, детерминистический.
