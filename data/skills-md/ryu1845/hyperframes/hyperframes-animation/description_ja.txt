HyperFrames のすべてのアニメーション知識 — 原子レベルのモーションルール、マルチフェーズシーンの設計図、シーン遷移、幅広いモーションデザイン技法、そして 7 つのランタイムアダプタ（GSAP デフォルト、Lottie、Three.js、Anime.js、CSS キーフレーム、Web Animations API、TypeGPU）。任意のモーションやアニメーションタスクに使用できる：2〜4 個のルールを選んで構成するか、設計図を読み込むか、ランタイム固有の API を参照する（例：GSAP イーズ / Lottie プレーヤー / Three.js ミキサー）。既存コンポジションの振付（アニメーションマップ）監査や、24 種類の名前付きテキストアニメーション効果も網羅。HyperFrames ネイティブ：単一の一時停止タイムライン、シーク安全、決定的。
