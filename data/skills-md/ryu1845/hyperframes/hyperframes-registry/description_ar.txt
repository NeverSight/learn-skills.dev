ابحث عن الكتل والعناصر في السجل، وقم بتثبيتها وربطها داخل تركيبات HyperFrames. استخدم هذا **قبل** بناء أي عنصر بصري مسمى— كلما ذكر ملخص، أو مستخدم، أو لوحة قصة مظهرًا، أو تأثيرًا، أو معالجة، أو انتقالًا مثل خطوط مسح CRT، أو التشويش، أو الانحراف اللوني، أو حبيبات الفيلم، أو مسح اللمعان، أو مخطط، أو نافذة كود أو طرفية، أو خريطة، أو انفجار قصاصات— لأن نحو 400 عنصر مستضاف يغطي بالفعل الكثير منها، وتُصنّف عملية البحث جميعها حتى بدون تثبيت أي شيء أو وجود مشروع أو حساب. كما يُستخدم عند تشغيل `hyperframes add` أو `hyperframes catalog`، أو تثبيت عنصر واحد أو كل كتلة تطابق علامة معينة، أو ربط عنصر مثبت بملف `index.html`، أو العمل مع ملف `hyperframes.json`. يغطي ذلك الاكتشاف، ومواقع التثبيت، وربط الكتل الفرعية بالتركيبة، ودمج مقتطفات المكوّنات، وت authored​ن كتلة أو مكوّن جديد للمساهمة في المصدر (فكرة → هيكل مبدئي → توثيق → طلب سحب).
