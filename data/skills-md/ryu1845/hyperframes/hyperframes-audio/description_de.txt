Verwenden, wenn bereits in einer HyperFrames‑Komposition platzierte Audiodaten gemischt werden müssen: Fade‑In/Fade‑Out, Crossfade, Spuren‑Gain oder Lautstärke, Lautstärke‑Automation, Ducking, ein Musikbett, das einer Voiceover entgegenwirkt (Voiceover‑Carve), Effekte auf einer Spur (EQ, Kompressor, Limiter, Gate, Saturation, Delay, Reverb, Chorus, Phaser, Bitcrush), Automatisierungshüllkurven, die auf die Lautstärke einer Spur oder einen beliebigen Effektparameter gezeichnet werden, oder ein Submix‑Bus, der eine Kette, einen Fader und einen Automatisierungs‑Clock für mehrere Spuren gleichzeitig trägt (`<hf-audio-group>`). Nicht verwenden zum Beschaffen oder Erzeugen von Audio — das Finden von BGM, SFX oder das Erstellen eines Voiceovers ist `/media-use`. Nicht verwenden für Clip‑Timing oder Spur‑Layout, das ist `/hyperframes-core`.
