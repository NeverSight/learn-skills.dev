À utiliser lors de la génération de contrôleurs, de services, de référentiels ou de DTO dans une application Symfony. Applique les limites des couches : HTTP dans les contrôleurs, logique métier dans les services, accès aux données dans les référentiels et mappage des DTO entre eux. Interdit les entités dans les réponses et l’accès aux référentiels à partir des contrôleurs.
