Biblioteca de referencia de 74 sistemas de diseño de marcas del mundo real (Claude, Linear, Stripe, Vercel, Figma, Apple, Tesla, Spotify, Notion, Supabase y más) capturados como archivos DESIGN.md — colores, tipografía, componentes, diseño, elevación. Úsala cuando el usuario quiera una UI, una página de destino o un componente que coincida con el aspecto de una marca específica; quiera elegir una dirección de diseño a partir de sistemas de diseño reales; diga “como <marca>”, “haz que se sienta como Linear / Stripe / Apple”; o necesite un punto de partida concreto de tokens de diseño antes del trabajo frontend. Se combina con frontend-design y tailwind-design-system.
