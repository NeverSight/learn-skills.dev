# 参考图壁纸工作室

这是平台无关的工作流程，不依赖 Codex 的特定工具名、私有路径或其他 Skill。使用当前 Agent 实际具备的看图、生图、文件和终端能力。默认一人完成；“跨 Agent 平台”不意味着启动多个 Agent。安装与能力降级见 [跨平台使用](references/portability.md)。

## 入口与状态

常用入口：用户上传图片并说“现在我要做壁纸，这是我的参考图”。相近表达也可触发；只有这句话但没有可访问图片时，请用户补充图片，不能编造分析。

1. **分析参考图**：直接看图，生成分析与反推提示词。没有看图能力时请用户描述画面，注明属于描述分析。这个阶段不自动生图。
2. **等待更改方案**：用一句话邀请用户说明希望改哪些内容。用户若同一条消息已给出方案并要求生成，则继续执行，不重复确认。
3. **生成第一版**：基于参考图及方案，完成新设计并自动调用可用生图能力。默认手机壁纸、竖版约 9:20、满版、一张。用户指定题材、尺寸、设备、风格、张数时优先遵循。
4. **局部迭代**：默认以上一轮最新成功交付的生成图为编辑目标，同时沿用原始参考的风格基准。用户指定其他版本、原始参考或新参考时按指定执行。失败任务、未完成图片、未交付草稿不能成为新基准。

分析、构图与提示词的细则见 [制作流程](references/workflow.md)；只在需要历史案例时读 [项目经验](references/project-lessons.md)。

## 第一次看参考图

先定位真正的壁纸画面。参考可能是锁屏截图、小红书截图、拼图或样机：把时间、日期、状态栏、按钮、平台文字、边框等叠层排除出生成内容。原图被遮挡的部分视为未知，不声称知道其原始细节；多张参考明确各图的用途，不擅自拼合。

输出紧凑的视觉分析：题材与主体、主次与坐标、疏密和留白、配色、画风与材质、光线，以及空间层次。坐标相对壁纸画布估计，左上为原点，x 与 y 各为 0–100%；截图取色和位置只能称为估计。

分别判断：画面纵深（透视、遮挡、尺度、明暗）、镜头虚化、锁屏时间遮挡。参考没有明显时间遮挡就如实说明，不为了迎合需求虚构。生成原图不绘制系统时间；静态壁纸不能保证设备一定启用景深、空间或动态效果。

给出完整、可复制的基础提示词及必要排除项，保留可识别的材质特征，不机械加入“摄影、微距、超写实、3D、虚化”。反推得到的是合理的生成描述，不是找回原作者的真实提示词。默认用中文交流与提示词；仅在接口或模型需要时翻译，保留语义。

## 接收更改方案

把用户的更改转为明确的“保留项＋修改项＋目标构图＋排除项”。用户没有要求改的属性保持原样；解释关键假设即可，不把每轮变成审批问卷。

“上方留白再高 20%”默认指当前留白高度乘 1.2，不是增加 20 个画布百分点；“饱和度降 10%”经生成模型实现只能视为视觉目标。结合最新图判断，不承诺精确像素或色值控制。指代不清或几项要求无法兼容时才追问。

第一版参考是风格和构图基准，后续版本是编辑目标；在调用中明确每张输入图的角色。用户要求创新时同时改变其指定的题材、形态、枝叶或构图等，不自行换掉已锁定的主体；不把“换花名”说成侵权风险已经消除。

## 选择生图通道

1. 用户指定的可用通道优先；否则使用平台内置生图。按当前工具说明传图片，编辑前先查看目标图。不假定工具一定支持本地路径、蒙版、精确尺寸或输出位置。
2. 没有内置生图，且已有用户配置的 API 时，使用 [API 接入](references/api.md) 和 `scripts/image_api.py`。本 Skill 的请求授权只包含当前生成或编辑，不包含无限重试、自动换供应商、公开上传或发布。
3. 没有可用通道时完成分析和最终提示词，说明缺少的能力，指导配置；不要把提示词、HTML 或占位图片当成已生成壁纸。密钥让用户在本地环境或平台密钥管理中设置，不要求粘贴到聊天。

API 配置按协议而不是品牌路由：OpenAI Images（JSON 生成、multipart 编辑）、Gemini 原生多模态、通用 JSON 同步/异步。模型 ID、地域、编辑能力和尺寸来自用户配置及厂商文档，不根据名称猜测。“兼容 OpenAI 聊天接口”不代表兼容图片接口。未经确认不改用别的模型。

## 检查与交付

看实际生成结果，对照主体、材质、主次、留白、要求改的属性与不变项。检查误生文字/UI、畸形结构、过曝、过度虚化、风格漂移。无视觉查看能力时明确只能检查文件和尺寸。

默认每轮一次生成。内置工具发现明显偏差可追加一次有针对性的精修；付费自配 API 不自动追加收费请求，除非用户已授权本轮修正额度。达到额度就交付现有结果和偏差说明。网络超时或未知状态不能直接再次 POST；异步任务先查询或恢复已有任务。

比例以实际文件为准。模型仅支持其他比例时先说明采用最近可用竖幅，写明实际尺寸；影响使用则询问裁切/扩图选择。禁止拉伸或把提示词中的“9:20、4K”当作实测结果。

保存每轮原图、完整生成/编辑提示词、修改与保留清单、实际尺寸、通道/模型、输入角色、父版本与检查结论。会话结构和可选管理脚本见 [会话与版本](references/session.md)。数据存入当前项目或用户目录，不能写入安装的 Skill 目录；保留旧版本。

交付图片预览或可访问文件、提示词位置和简短修改说明。如有偏差说明偏差。平台工具返回的文件先保存到项目内再交付；不要把尚未完成的任务说成成功。发布小红书、外部消息和作品上传须用户另行提出。
