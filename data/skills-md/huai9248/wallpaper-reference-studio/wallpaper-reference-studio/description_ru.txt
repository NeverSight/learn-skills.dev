На основе анализа композиции, материала, цветовой схемы и слоёв блокировки эталонного референсного изображения выводятся ключевые слова для подсказки обоев; генерируются обои для телефона после получения плана модификации от пользователя и выполняется частичная итерация на основе последней версии. При получении сообщения «Я хочу сейчас сделать обои, это моё референсное изображение» вместе с изображением или явного запроса создать или отредактировать обои с использованием референсного изображения, использовать его. Поддерживает встроенную в платформу генерацию необработанных изображений и пользовательский API модели изображений.

Пожалуйста, всегда отвечайте на языке пользователя.
