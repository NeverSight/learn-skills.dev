Creator Store에서 에셋 ID로 로블록스 게임용 사운드를 찾아 검증하고 연결합니다 — 발소리, 총소리, 동물 소리, UI 클릭, 배경음, 음악 등 — 업로드 없이, Open Cloud 오디오 할당량 없이, API 키 없이 수행합니다. 스튜디오 자체 오디오 탭이 사용하는 동일한 인증되지 않은 툴박스 엔드포인트를 검색한 뒤, 후보마다 스튜디오에서 (IsLoaded와 측정된 Sound.TimeLength를 통해) 검증합니다. 툴박스의 지속시간 필드가 자주 잘못되어 위험하기 때문입니다. SoundBank 데이터 모듈, 무활성화된 Sfx 런타임 헬퍼, 그리고 즉시 열린 장소에서 사운드뱅크를 들을 수 있게 하는 설치 스크립트를 출력합니다. 사용자는 로블록스 게임에 효과음, 오디오, SFX, 음악 또는 배경음이 필요할 때, 손으로 직접 끌어다 놓는 대신 찾아서 연결된 사운드를 원할 때, 빌드를 위한 오디오를 선택할 때, 혹은 사운드가 무음이거나 길이가 없거나 로드되지 않는 이유를 물을 때 언제든 사용할 수 있습니다.
