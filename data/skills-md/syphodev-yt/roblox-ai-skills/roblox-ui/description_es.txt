Construye la UI de juegos de Roblox sin interfaz: superposiciones HUD, tiendas, inventarios, listas de misiones, configuraciones, a partir de una especificación JSON, y genera el conjunto de íconos que la acompaña. Produce un mockup PNG, un archivo Rojo .model.json y un creador Luau a partir de UN árbol resuelto, de modo que la vista previa no se desvíe de lo que se enviará. Úsalo siempre que el usuario necesite una GUI de Roblox, un menú, una UI de tienda, HUD, pantalla de inventario o mockup de UI creado en lugar de ensamblado manualmente en Studio, quiera generar íconos del juego, quiera una UI construida a partir de un archivo de tema, o pregunte por qué su UI se ve plana, falla en móvil o se renderiza de forma diferente en Studio que en el diseño.
