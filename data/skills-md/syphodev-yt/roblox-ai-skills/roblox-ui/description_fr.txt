Construisez l'interface utilisateur d'un jeu Roblox en mode headless — superpositions HUD, boutiques, inventaires, listes de quêtes, paramètres — à partir d’une spécification JSON, et générez le jeu d’icônes qui l’accompagne. Produit une maquette PNG, un fichier Rojo .model.json et un constructeur Luau à partir d’UN arbre résolu, afin que la prévisualisation ne s’écarte jamais du résultat final. Utilisez-le chaque fois que l’utilisateur veut une interface Roblox, un menu, une boutique, un HUD, un écran d’inventaire ou une maquette d’interface générés plutôt que assemblés manuellement dans Studio, souhaite générer des icônes de jeu, veut une interface construite à partir d’un fichier de thème, ou se demande pourquoi son interface semble plate, se casse sur mobile ou rend différemment dans Studio que dans la conception.

Veuillez toujours répondre dans la langue de l’utilisateur.
