Создайте UI Roblox‑игры без графической среды — HUD‑оверлеи, магазины, инвентари, списки квестов, настройки — из JSON‑спецификации и сгенерируйте набор иконок, который в него помещается. Генерирует PNG‑макет, Rojo .model.json и Luau‑билдер из ОДНОГО разрешённого дерева, чтобы превью не отклонялось от того, что будет отправлено. Используйте, когда пользователь хочет GUI Roblox, меню, UI магазина, HUD, экран инвентаря или макет UI, созданный автоматически, а не собранный вручную в Studio; хочет сгенерировать игровые иконки, построить UI из файла темы, или спрашивает, почему их UI выглядит плоским, ломается на мобильных устройствах или отображается иначе в Studio, чем в дизайне.
