JSON 사양에서 헤드리스 방식으로 Roblox 게임 UI를 구축합니다 — HUD 오버레이, 상점, 인벤토리, 퀘스트 목록, 설정 등 — 그리고 그에 필요한 아이콘 세트를 생성합니다. 하나의 해결된 트리에서 PNG 목업, Rojo .model.json 및 Luau 빌더를 출력하여 미리보기가 실제 배포와 달라지지 않도록 합니다. 사용자는 Studio에서 클릭하여 만든 것이 아니라 Roblox GUI, 메뉴, 상점 UI, HUD, 인벤토리 화면 또는 UI 목업이 필요할 때, 게임 아이콘을 생성하고 싶을 때, 테마 파일로 UI를 만들고 싶을 때, 혹은 UI가 평면적으로 보이거나 모바일에서 깨지거나 Studio와 디자인에서 다르게 렌더링되는 이유를 물을 때 언제든 사용할 수 있습니다.
