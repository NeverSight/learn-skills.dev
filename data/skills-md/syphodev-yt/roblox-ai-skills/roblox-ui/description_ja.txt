JSON 仕様からヘッドレスに Roblox ゲーム UI を構築します――HUD オーバーレイ、ショップ、インベントリ、クエストリスト、設定など――そしてそれに含まれるアイコンセットを生成します。1 つの解決されたツリーから PNG のモックアップ、Rojo の .model.json、Luau ビルダーを出力するので、プレビューが実際の出荷物とずれることはありません。ユーザーが Roblox の GUI、メニュー、ショップ UI、HUD、インベントリ画面、または UI のモックアップを Studio でクリックして作るのではなく、JSON テーマファイルから生成したいとき、ゲーム用アイコンの生成を求めるとき、テーマファイルから UI を構築したいとき、あるいは UI が平面に見える、モバイルで壊れる、Studio とデザインで表示が異なるといった問題を質問したときに使用します。
