編寫 Roblox 遊戲的 Luau 程式碼，使其在實際玩家測試中能順利運行——伺服器權威、Knit 服務與控制器、普通 RemoteEvents、所有可調參數皆放在 Config 中、所有可純粹實現的規則都寫成純 Core 模組並帶有無頭規格 —— 並在 Studio 看到之前就先在磁碟上驗證，通過四個檢查點（rojo build、lune run test、selene、stylua），每個檢查點約在一秒內完成且完全不需要 Studio。先搭建一個完整的專案範本，使其在四項檢查全部通過且呈綠色狀態，甚至在寫下任何遊戲程式碼之前就完成。隨時可用於使用者想要：

- 編寫 Roblox 遊戲程式碼  
- 設置遊戲專案  
- 配置 Rojo/Wally/Knit  
- 建構玩法系統或服務  
- 檢視程式碼是否存在可被利用或複製的漏洞  

或是當使用者詢問以下問題時提供協助：

- 為何遠端事件被觸發卻沒有任何反應  
- 為何腳本編輯後沒有生效  
- 為何出現重複的模組  
- 為何角色與自己的移動程式碼產生衝突。
