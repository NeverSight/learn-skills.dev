Настройте бесплатные навыки создания игр в Roblox НА ЭТОМ компьютере — проверьте, какие инструменты установлены (Python, Rojo, Wally, Lune, Selene, StyLua, Blender, MCP Roblox Studio), проведите пользователя через всё недостающее, затем создайте для каждого навыка персональный файл LOCAL.md (папки, пути к инструментам, файл рига, расположение библиотеки VFX, имена переменных окружения для ключей), спросив пользователя и автоматически определив то, что возможно, и завершите дымовым тестом. Используйте это при первом запуске после установки навыков, каждый раз, когда навык сообщает «LOCAL.md not found», когда пользователь перемещает папки или устанавливает новый инструмент, либо когда он спрашивает «how do I set these skills up», «what do I need installed» или «why can’t the skill find Blender/Rojo/my library».
