Fähigkeit zur tiefgreifenden Code‑Analyse und automatisierten Bereinigung. Entfernt toten Code, ungenutzte Importe, nicht referenzierte Dateien und duplizierte Logik aus jedem Code‑Base. Vereinfacht übermäßig komplexen oder schwer wartbaren Code. Sichert stets vor Änderungen und validiert anschließend mit Tests.  
Verwenden, wenn der Nutzer fragt nach: – „clean up“, „remove dead code“, „purge unused code“ – „find and delete unused files/folders“ – „remove duplicate code“ oder „refactor duplicated logic“ – „simplify this codebase“ oder „the code is too complex“ – „do a cleanup pass“ oder „code hygiene“ – „remove everything that's not used“
