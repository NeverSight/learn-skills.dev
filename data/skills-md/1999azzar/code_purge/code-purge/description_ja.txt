深層コード解析と自動クリーンアップ機能。死んだコード、未使用のインポート、参照されていないファイル、重複したロジックをあらゆるコードベースから除去します。過度に複雑または保守が難しいコードをシンプルにします。変更前に必ずバックアップを取り、変更後はテストで検証します。

以下のような要望がある場合に使用してください：
- 「クリーンアップ」や「デッドコードの削除」「未使用コードのパージ」
- 「未使用のファイル/フォルダーを見つけて削除」
- 「重複コードの削除」や「重複ロジックのリファクタリング」
- 「このコードベースをシンプルに」や「コードが複雑すぎる」
- 「クリーンアップパスを実行」や「コード衛生」
- 「使われていないものすべてを削除」
