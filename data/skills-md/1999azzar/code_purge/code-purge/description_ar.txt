مهارة التحليل العميق للكود والتنظيف الآلي. تزيل الكود الميت، الاستيرادات غير المستخدمة، الملفات غير المرجعية، والمنطق المكرر من أي قاعدة كود. تُبسّط الكود المعقد جدًا أو الصعب الصيانة. دائمًا تقوم بعمل نسخة احتياطية قبل التغييرات وتتحقق من صحتها بالاختبارات بعد ذلك.  
استخدام عندما يطلب المستخدم:  
- "تنظيف"، "إزالة الكود الميت"، "مسح الكود غير المستخدم"  
- "العثور على ملفات/مجلدات غير مستخدمة وحذفها"  
- "إزالة الكود المكرر" أو "إعادة هيكلة المنطق المكرر"  
- "تبسيط قاعدة الكود هذه" أو "الكود معقد جدًا"  
- "إجراء تمريرة تنظيف" أو "نظافة الكود"  
- "إزالة كل ما لا يُستَخدم"  

الرد دائمًا بلغة المستخدم.
