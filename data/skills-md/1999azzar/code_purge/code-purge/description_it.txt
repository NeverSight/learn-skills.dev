Abilità di analisi approfondita del codice e pulizia automatizzata. Rimuove codice morto, import inutilizzati, file non referenziati e logica duplicata da qualsiasi base di codice. Semplifica codice eccessivamente complesso o difficile da mantenere. Esegue sempre un backup prima delle modifiche e valida con i test dopo.  
Usare quando l'utente richiede di: - “pulire”, “rimuovere codice morto”, “eliminare codice inutilizzato” - “trovare ed eliminare file/cartelle inutilizzati” - “rimuovere codice duplicato” o “rifattorizzare logica duplicata” - “semplificare questa base di codice” o “il codice è troppo complesso” - “eseguire una fase di pulizia” o “igiene del codice” - “rimuovere tutto ciò che non è usato”.
