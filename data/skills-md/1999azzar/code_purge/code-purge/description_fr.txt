Analyse approfondie du code et compétence de nettoyage automatisé. Supprime le code mort, les imports inutilisés, les fichiers non référencés et la logique dupliquée de n’importe quelle base de code. Simplifie le code trop complexe ou difficile à entretenir. Effectue toujours une sauvegarde avant les modifications et valide avec les tests par la suite.  
Utilisez lorsque l’utilisateur demande de : - « nettoyer », « supprimer le code mort », « purger le code inutilisé » - « trouver et supprimer les fichiers/dossiers inutilisés » - « supprimer le code dupliqué » ou « refactoriser la logique dupliquée » - « simplifier cette base de code » ou « le code est trop complexe » - « faire un passage de nettoyage » ou « hygiène du code » - « supprimer tout ce qui n’est pas utilisé ».  
Veuillez toujours répondre dans la langue de l’utilisateur.
