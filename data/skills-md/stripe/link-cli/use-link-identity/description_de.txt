Verwenden Sie die Identitätsbefehle von Link CLI, wenn ein Dienst ein Link‑Agent‑Attestation‑Token (AAT) oder signierte Benutzeransprüche wie E‑Mail anfordert. Dabei geht es um das Erwerben und Verwalten von Attestierungen, das Abrufen von Identitätsnachweisen und das Präsentieren ausgewählter Ansprüche an einen Prüfer mittels HTTP‑Client oder Browser‑Automatisierung.
