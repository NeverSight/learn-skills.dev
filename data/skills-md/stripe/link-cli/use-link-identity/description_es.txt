Utilice los comandos de identidad de Link CLI cuando un servicio solicite un Token de Atestación de Agente Link (AAT) o reclamaciones de usuario firmadas, como el correo electrónico. Incluye la adquisición y gestión de atestaciones, la obtención de credenciales de identidad y la presentación de reclamaciones seleccionadas a un verificador mediante un cliente HTTP o automatización de navegador.
