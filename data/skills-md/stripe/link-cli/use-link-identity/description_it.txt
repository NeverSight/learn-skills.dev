Utilizza i comandi di identità di Link CLI quando un servizio richiede un Token di Attestazione dell'Agente Link (AAT) o rivendicazioni utente firmate come l'email. Copre l'acquisizione e la gestione delle attestazioni, l'ottenimento delle credenziali di identità e la presentazione delle rivendicazioni selezionate a un verificatore tramite un client HTTP o automazione del browser.
