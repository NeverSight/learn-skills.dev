Genera un set coerente di immagini di prodotto multiangolo (davanti, dietro, lato sinistro/destro, sopra, 45°, dettaglio macro, confezione, in mano) con illuminazione e sfondo identici, eventualmente combinato in una griglia. Da utilizzare per 多角度图, 多视角套图, visualizzazione a 360°, set di angoli, immagini della galleria.
