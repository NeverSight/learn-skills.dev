'orca' CLI를 통해 Orca 관리 작업 트리, 폴더 컨텍스트, 터미널, 저장소, 자동화, 아티팩트, 기술 공유, 작업 트리 주석 및 Orca 내장 브라우저를 운영합니다. 사용자가 "$orca-cli", "Orca 작업 트리", "하위 작업 트리", "작업 트리에서 코덱스/클로드 생성", "Orca 터미널 읽기/대기/전송", "핸드오프" / "핸드오버" / "다른 에이전트에게 제공", "오르카 브라우저", "오르카 아티팩트" 또는 "기술 공유"라고 말할 때 사용합니다. Orca 상태가 관련된 경우 원시 Git 작업 트리, 임시 PTY 또는 컴퓨터 사용보다 선호합니다. 컴퓨터 사용 OS 수준의 제어가 필요한 외부 창이나 데스크톱 UI에만 사용하고, 외부 페이지에는 Playwright 또는 CDP를 사용합니다.
