通过“orca” CLI 操作 Orca 管理的工作树、文件夹上下文、终端、存储库、自动化、工件、技能共享、工作树注释和 Orca 的嵌入式浏览器。当用户说“$orca-cli”、“Orca 工作树”、“子工作树”、“在工作树中生成 codex/claude”、“读取/等待/发送 Orca 终端”、“移交”/“移交”/“将其交给另一个代理”、“Orca 浏览器”、“orca 工件”或“共享技能”时使用。当涉及 Orca 状态时，比原始 git worktree、ad hoc PTY 或计算机使用更喜欢它。使用计算机 仅用于需要操作系统级控制的外部窗口或桌面 UI，以及用于外部页面的 Playwright 或 CDP。
