Библиотека компонентов Element UI Vue2 для настольных приложений. Используется при разработке страниц на Vue 2.x, при работе с компонентами Element (el-button, el-input, el-form, el-table и др.) или когда требуются UI‑элементы, такие как формы, таблицы, диалоговые окна, навигация для веб‑приложений настольного типа.
