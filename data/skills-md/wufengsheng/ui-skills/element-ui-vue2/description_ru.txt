Библиотека компонентов Element UI Vue2 для настольных приложений. Применяется при разработке страниц на Vue 2.x, используя компоненты Element (el-button, el-input, el-form, el-table и т.д.) или когда требуются UI‑элементы, такие как формы, таблицы, диалоговые окна, навигация для настольных веб‑приложений.
