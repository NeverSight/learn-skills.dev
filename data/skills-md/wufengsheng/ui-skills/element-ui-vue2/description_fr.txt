Bibliothèque de composants de bureau Element UI pour Vue 2. Utilisez‑la lors du développement de pages Vue 2.x, en employant les composants Element (el-button, el‑input, el‑form, el‑table, etc.), ou lorsqu’il faut des éléments d’interface utilisateur tels que formulaires, tableaux, boîtes de dialogue et navigation pour les applications web de bureau.
