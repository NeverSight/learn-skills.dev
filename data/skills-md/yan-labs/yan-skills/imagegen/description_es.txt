Genera todos los activos visuales necesarios para un sitio web y su contenido—cuando los usuarios solicitan generar imágenes, ilustraciones, una sola foto, un conjunto de imágenes, logotipos, mascotas, portadas, carteles, imágenes og, imágenes para compartir, imágenes fuente de favicon, imágenes de escenarios de usuario, imágenes de personas reales (“una persona sentada frente a una computadora”), ilustraciones de estilo dibujado a mano/crayón/acuarela, imágenes promocionales de productos, escenas de estilo cinematográfico, “el sitio web necesita imágenes acompañantes”, generación de imágenes, imagegen, etc. También cubre los casos de flujo de trabajo de construcción de sitios “rankup”, como “página sin imágenes, uso de marcadores de posición, og:image faltante, cada página necesita su propia imagen para compartir, favicon aún no creado”—en estos escenarios no se permiten marcadores de posición; se deben generar imágenes reales, siempre usando esta habilidad. El motor subyacente utiliza la herramienta de generación de imágenes de OpenAI incorporada en Codex; esta habilidad traduce la solicitud en prompts efectivos, ejecuta la generación, valida, comprime y guarda los archivos.
