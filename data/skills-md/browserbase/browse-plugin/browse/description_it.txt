Utilizza il CLI browse per l'automazione del browser di Browserbase, le API cloud di Browserbase, le Funzioni di Browserbase, i modelli, il recupero/ricerca web, la diagnostica e la scoperta/installazione di skill Browse.sh. Usalo quando l'utente richiede di navigare pagine, ispezionare lo stato del browser, avviare sessioni browser locali o remote, gestire le risorse di Browserbase, chiamare le Funzioni di Browserbase, sfogliare o creare modelli Browserbase, recuperare o cercare contenuti web, diagnosticare la configurazione di browse, trovare o installare una skill per un compito su un sito web, scoprire skill Browse.sh specifiche per il sito, o installare/aggiornare questa skill di browse.

Per favore, rispondi sempre nella lingua dell'utente.
