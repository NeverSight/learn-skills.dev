Utilisez le CLI browse pour l’automatisation de navigateur Browserbase, les API cloud Browserbase, les fonctions Browserbase, les modèles, la récupération/recherche Web, le diagnostic et la découverte/installation de compétences Browse.sh. Utilisez‑le lorsque l’utilisateur demande de naviguer sur des pages, d’inspecter l’état du navigateur, d’exécuter des sessions de navigateur locales ou à distance, de gérer les ressources Browserbase, d’appeler des fonctions Browserbase, de parcourir ou de générer des modèles Browserbase, de récupérer ou de rechercher du contenu Web, de diagnostiquer la configuration de navigation, de trouver ou d’installer une compétence pour une tâche sur un site, de découvrir des compétences Browse.sh spécifiques à un site, ou d’installer/actualiser cette compétence de navigation. 
Veuillez toujours répondre dans la langue de l'utilisateur.
