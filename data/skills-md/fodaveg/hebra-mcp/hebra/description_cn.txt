通过 MCP `hebra`（hebra-mcp）查询和写入 Hebra 笔记库（本地优先的 Markdown 笔记应用，支持加密同步）：搜索、列出、读取笔记、标签、文件夹和链接；创建笔记、在末尾添加文本、通过精确替换编辑笔记的部分内容、移动笔记到已有文件夹、标记为收藏、存档、放入回收站或恢复、查看或恢复其历史版本，以及查看其附件（图片、PDF、文本）。当用户提到 Hebra 或其笔记时使用：“在 Hebra 中搜索”“我在笔记里关于 X 有什么”“记在 Hebra”“在 Hebra 中创建笔记”“把这个加到笔记 Y”“纠正/更改笔记 Z 中的 X”“把笔记移动到文件夹 W”“存档笔记”“把笔记扔进回收站”“恢复昨天的版本”“笔记 X 的 PDF 上写了什么”。不用于永久删除或清空回收站、添加或更改附件，也不用于创建、重命名或移动文件夹（MCP 不支持），也不用于任务（交给 Lumbre），也不用于开发 Hebra 或 hebra‑mcp 的代码。
