Consultez et écrivez dans la bibliothèque de notes de Hebra (application de notes Markdown local‑first avec synchronisation chiffrée) via le MCP `hebra` (hebra‑mcp) : rechercher, lister, lire les notes, les étiquettes, les dossiers et les liens ; créer des notes, ajouter du texte à la fin, modifier des parties d’une note par des substitutions exactes, la déplacer vers un dossier existant, la marquer comme favorite, l’archiver, la mettre à la corbeille ou la restaurer, voir ou restaurer ses versions antérieures, et voir ses pièces jointes (images, PDF, texte). Utilisez‑le lorsque l’utilisateur mentionne Hebra ou ses notes Hebra : « cherche dans Hebra », « qu’est‑ce que j’ai dans mes notes sur X », « note‑le dans Hebra », « crée une note dans Hebra », « ajoute ceci à la note Y », « corrige/changer X dans la note Z », « déplace la note vers le dossier W », « archive la note », « jette la note à la corbeille », « récupère la version d’hier », « que dit le PDF de la note X ». NE sert pas à supprimer de façon définitive ni à vider la corbeille, à ajouter ou modifier des pièces jointes, ni à créer, renommer ou déplacer des dossiers (le MCP ne le permet pas), ni pour les tâches (elles vont à Lumbre), ni pour développer le code de Hebra ou de hebra‑mcp.
