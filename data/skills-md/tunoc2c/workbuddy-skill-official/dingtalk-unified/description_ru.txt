Набор DingTalk CLI All‑in‑One, построенный на официальном DingTalk Workspace CLI (dws), позволяет выполнять операции с сообщениями DingTalk, групповыми чатами, адресной книгой, календарём, задачами, утверждениями, посещаемостью, журналами, DING, AI‑таблицами, документами DingTalk, DingDisk, AI‑заметками к встречам, электронной почтой и документацией открытой платформы. Пользователи используют его для поиска контактов, отправки сообщений, создания групп, управления расписанием, создания задач, обработки утверждений, просмотра посещаемости, чтения/записи документов, работы с AI‑таблицами, поиска заметок к встречам или вызова возможностей открытой платформы DingTalk.
