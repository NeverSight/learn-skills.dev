驱动 pollo-cli 通过 Pollo 平台开放 API 生成图像和视频——发现模型，读取其输入字段，使用本地或托管的图像输入提交生成请求，并轮询获取完成的 URL。当用户请求生成/创建/制作图像或视频、对照片进行动画处理、进行图像到视频/文本到视频/参考到视频、查询 Pollo 信用余额或估算一次生成的信用消耗，或询问可用的 Pollo 模型时，都使用此功能——即使用户没有明确提到 “pollo-cli” 或 “pollo”，如“把这张照片变成视频”或“我还有多少信用”，也会触发。⚠️ 该技能不用于构建平台 API 本身（服务器端模型曝光——使用 expose‑platform‑model‑api 技能）或将模型接入网页前端（使用 add‑model 技能）。

请始终使用用户的语言作答。
