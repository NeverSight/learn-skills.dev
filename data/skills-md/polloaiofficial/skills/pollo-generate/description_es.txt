Conduce el pollo-cli para generar imágenes y videos a través de la API abierta de la plataforma Pollo — descubre un modelo, lee sus campos de entrada, envía una generación con imágenes locales o alojadas y haz polling hasta obtener una URL final. Usa esto siempre que el usuario solicite generar/crear/hacer una imagen o video, animar una foto, hacer image‑to‑video / text‑to‑video / reference‑to‑video, comprobar el saldo de créditos de Pollo o estimar el coste en créditos de una generación, o pregunte qué modelos de Pollo están disponibles — se activa incluso si no nombran explícitamente “pollo‑cli” o “pollo”, por ejemplo “convierte esta foto en un video” o “¿cuántos créditos me quedan?”. No es para construir la API de la plataforma (exposición del modelo del lado del servidor — usa la habilidad expose‑platform‑model‑api) ni para integrar un modelo en el frontend web (usa la habilidad add‑model).  

Por favor, responde siempre en el idioma del usuario.
