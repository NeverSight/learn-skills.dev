Guida il pollo-cli per generare immagini e video tramite l'API aperta della piattaforma Pollo — scopri un modello, leggi i suoi campi di input, invia una generazione con input di immagine locali o ospitati e ottieni l'URL finale. Usa questo ogni volta che l'utente chiede di generare/creare/fare un’immagine o un video, animare una foto, fare image-to-video / text-to-video / reference-to-video, controllare il saldo crediti Pollo o stimare il costo in crediti di una generazione, o chiede quali modelli Pollo sono disponibili — attivalo anche se non nominano esplicitamente “pollo-cli” o “pollo”, ad esempio “trasforma questa foto in un video” o “quanti crediti mi rimangono”. NON per costruire l'API della piattaforma stessa (esposizione del modello lato server — usa la skill expose‑platform‑model‑api) o per collegare un modello al frontend web (usa la skill add‑model).

Rispondi sempre nella lingua dell'utente.
