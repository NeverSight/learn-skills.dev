Pollo プラットフォームのオープン API を介して画像や動画を生成するために pollo‑cli を操作します — モデルを発見し、入力フィールドを確認し、ローカルまたはホストされた画像入力で生成を送信し、完成した URL までポーリングします。ユーザーが画像や動画の生成・作成・作成を依頼したとき、写真をアニメーション化したいとき、image‑to‑video / text‑to‑video / reference‑to‑video を行いたいとき、Pollo のクレジット残高を確認したいとき、生成にかかるクレジットコストを見積もりたいとき、または利用可能な Pollo モデルを尋ねるときに使用します — 「pollo‑cli」や「pollo」という名前が明示されていなくてもトリガーします。例: 「この写真を動画に変えて」や「残りのクレジットは何枚？」など。プラットフォーム API 自体の構築（サーバー側モデルの公開 — expose‑platform‑model‑api スキルを使用）や、モデルをウェブフロントエンドに組み込むこと（add‑model スキルを使用）には使用しないでください。
