透過 Pollo 平台開放 API 操作 pollo‑cli 生成影像與影片 — 探索模型、讀取其輸入欄位、以本機或託管的影像作為輸入提交生成，並輪詢取得完成的 URL。當使用者要求產生/建立/製作影像或影片、為照片製作動畫、執行 image‑to‑video / text‑to‑video / reference‑to‑video、檢查 Pollo 點數餘額或估算生成所需點數，或詢問有哪些 Pollo 模型可用時，都使用此功能 — 即使使用者未明確提及「pollo‑cli」或「pollo」，亦會觸發，例如「把這張照片變成影片」或「我還剩多少點數」。此功能不適用於建構平台 API 本身（伺服器端模型暴露 — 請使用 expose‑platform‑model‑api 技能）或將模型接入網頁前端（請使用 add‑model 技能）。請始終以使用者的語言回覆。
