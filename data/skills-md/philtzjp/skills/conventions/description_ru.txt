Валидатор форматирования сообщений коммитов, вызываемый из хука Git commit‑msg. Окончательная спецификация находится в файле conventions.yml в репозитории philtzjp/.github. Используйте его, когда хук останавливается с сообщением «No format validator», когда вас не устраивают результаты валидации или при настройке хука. Следуйте рекомендациям GitHub относительно того, как должен быть написан сам формат.
