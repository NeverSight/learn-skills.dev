Ein Commit-Message-Format-Validator, der vom Commit-Message-Hook von git aufgerufen wird. Die maßgeblichen Konventionen sind in philtzjp/.github's conventions.yml. Verwenden Sie es, wenn der Haken mit "No format validator" abbricht, wenn Sie mit den Validierungsergebnissen nicht zufrieden sind oder wenn Sie den Haken konfigurieren. Das Format selbst sollte den Richtlinien von GitHub entsprechen.
