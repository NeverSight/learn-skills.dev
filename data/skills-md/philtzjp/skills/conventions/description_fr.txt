Un validateur pour le formatage desmessages de validation qui est appelé à partir du crochet commit-msg de git. La spécification définitive est le fichier conventions.yml dans philtzjp/.github. Utilisez-le lorsque le crochet abandonne avec « aucun validateur de format », lorsque vous n'êtes pas satisfait des résultats de validation ou lorsque vous configurez le crochet. Le format lui-même doit suivre les directives de GitHub.
