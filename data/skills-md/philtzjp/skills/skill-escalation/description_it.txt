Proponi miglioramenti a una skill nel repository principale. Definisci l'approccio da adottare quando la skill non progredisce come previsto, quando ricerche web o altre fonti forniscono informazioni che differiscono o aggiornano la skill, o quando seguire rigorosamente le condizioni della skill non porta al risultato migliore. Questo include non modificare direttamente la skill in Home, assegnare la destinazione della proposta e fornire un modello per il titolo e il corpo dell'Issue. Usa questa procedura quando hai dubbi sul contenuto di una skill o quando proponi miglioramenti a una skill.
