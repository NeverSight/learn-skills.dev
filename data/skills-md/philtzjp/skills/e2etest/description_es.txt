Crea y ejecuta pruebas E2E. Utiliza principalmente agent-browser, recurriendo a Playwright solo para las interacciones que no pueda manejar. Define las condiciones de cuándo escribir pruebas y cuándo no, prohíbe la dependencia de tiempos basada en sleep y utiliza condiciones de espera explícitas. Utiliza esto para añadir flujos de usuario importantes, realizar cambios UI significativos o cuando se modifiquen los criterios de éxito de flujos existentes.

Por favor, responde siempre en el idioma del usuario.
