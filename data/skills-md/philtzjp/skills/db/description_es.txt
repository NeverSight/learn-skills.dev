Selección de base de datos, definición de esquema, conexión y migración. Para Postgres, use Neon; para SQLite, use Cloudflare D1; el ORM es Drizzle. Separe el objetivo de conexión y el rol con app_migrations y app_application. La migración de datos se realiza en el orden de obtener recuentos de registros, dry‑run, verificación, ejecución en producción y eliminación de la API. Utilice esto cuando necesite cambiar el esquema, ejecutar migraciones, convertir masivamente registros existentes o agregar/modificar/revisar la configuración de conexión a la base de datos.
