Database selection, schema definition, connection, migration. If using Postgres, Neon; if using SQLite, Cloudflare D1; the ORM is Drizzle. Separate the destination and role with app_migrations and app_application. Data migration is performed in the order of count retrieval, dry run, verification, production execution, and API deletion. Use this when asked to make schema changes, migrations, bulk conversion of existing records, or to add, modify, or review DB connection settings.
