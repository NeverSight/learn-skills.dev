Flujo estándar desde la creación del issue hasta el ramificado, la implementación, la solicitud de extracción y la fusión, junto con las convenciones de operación de Git/GitHub. Incluye el formato del mensaje de confirmación tipo(alcance), cómo determinar el alcance, el manejo de --author, la verificación de las direcciones del autor y del committer, la prohibición de Co‑Authored‑By y git add ., fusiones squash realizadas por el bot philtz‑organizer‑bot mediante etiquetas de fusión, la comprobación del estado adelantado/atrasado, y las directrices para escribir comentarios de issues y versiones. Se utiliza al confirmar, empujar, crear y cambiar de rama, fusionar, rebasear y crear issues, PRs, comentarios y versiones.
