Aggiorna le skill all'ultima versione, migra le copie delle skill che rimangono nel repository di destinazione e riconcilia i file originali delle skill, i collegamenti simbolici e il manifesto delle skill. Definisci il controllo e l'aggiornamento delle skill locali usando `npx skills`, proponi l'eliminazione delle copie di `philtzjp/skills`, gestisci le modifiche locali ed esegui controlli di integrità tra le skill specifiche del repository e il repository principale `philtzjp/skills`. Usa questo approccio all'avvio del lavoro, quando si reimportano le skill dall'upstream, quando una skill con lo stesso nome di una presente in `philtzjp/skills` è trovata in `.agents/skills` o `.claude/skills`, e quando si aggiungono, eliminano o rinominano le skill.
