Concevez et implémentez des API HTTP avec Hono. Conformez-vous à OpenAPI en utilisant @hono/zod-openapi, utilisez les erreurs problem+json conformément à la RFC 9457, appliquez le versionnage par chemin, l’authentification Bearer et la vérification d’origine pour les services de boucle locale, les contrôles de santé, le linting Spectral et @hono/mcp. Utilisez ceci lorsque l’on vous demande d’ajouter, de modifier ou d’examiner les points de terminaison d’API, le routage, les schémas OpenAPI, les méthodes d’authentification, les réponses d’erreur et le serveur MCP.

Veuillez toujours répondre dans la langue de l’utilisateur.
