Créez de courtes vidéos axées sur les graphismes, le texte ou les animations d’interface utilisateur à l’aide de code (généralement de 5 à 60 secondes, les vidéos musicales pures pouvant durer jusqu’à environ 2 minutes), en produisant des fichiers MP4 et le code source éditable : clips promotionnels de produits, portfolios de motion‑graphics, démonstrations d’animations UI, typographies dynamiques et points d’accents de citations, animations de logos et génériques d’ouverture, boucles d’art génératif, courts métrages rétrospectifs. Options musicales : générées par le code ou synchronisées avec une piste fournie par l’utilisateur. Utilisé lorsque les utilisateurs souhaitent réaliser ce type de vidéo courte ou de motion‑graphic, par exemple « créer une vidéo motion de 15 secondes », « créer une animation ou ouverture de logo », « créer un clip promotionnel de produit », « créer une vidéo avec du code ». Pas destiné aux : vidéos longues avec voix‑off explicative, prototypes web et interactifs, séquences réalistes d’humains ou prises de vue en direct, montage de vidéos existantes.
