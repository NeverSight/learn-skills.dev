Sistema UI/UX de escritorio limpio basado en tokens para rediseñar o crear interfaces de aplicaciones Svelte 5 con shadcn-svelte, Bits UI, Tailwind v4 e íconos lucide. Úselo para sistemas visuales de aplicaciones de escritorio, estilo de componentes, diseños de shell, barras laterales, pantallas de configuración, tarjetas, menús, pestañas, formularios, cuadros de diálogo, paneles de terminal/editor, densidad compacta, capas de superficies neutras, tipografía Geist (variable humanista sin), líneas suavizadas y para hacer que una interfaz se sienta pulida, moderna, precisa, suave y menos robótica sin cambiar las bibliotecas de UI.
