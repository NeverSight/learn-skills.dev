Système UI/UX de bureau propre piloté par jetons pour la refonte ou la création d'interfaces d'application Svelte 5 avec shadcn-svelte, Bits UI, Tailwind v4 et des icônes lucide. À utiliser pour les systèmes visuels d'applications de bureau, le style des composants, les dispositions de coque, les barres latérales, les écrans de paramètres, les cartes, les menus, les onglets, les formulaires, les boîtes de dialogue, les volets de terminal/éditeur, la densité compacte, la superposition de surface neutre, la typographie Geist (sans variable humaniste), les lignes de cheveux adoucies et pour donner à une interface une sensation soignée, moderne, précise, douce et moins robotique sans modifier les bibliothèques d'interface utilisateur.
