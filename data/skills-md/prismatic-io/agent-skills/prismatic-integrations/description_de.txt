Erstellen, aktualisieren und verifizieren Sie eine Prismatic Code Native Integration (CNI), einschließlich lokaler Prüfungen und iterativer Plattformtests. Verwenden Sie sie für neue Integrationsanforderungen, die fortlaufende CNI‑Entwicklung und das Debuggen von Flow‑Ausführungen. Für die Bewertung oder den Austausch eines bestehenden nicht‑Prismatic‑Integrationssystems bevorzugen Sie prismatic‑migrate, sofern verfügbar.
