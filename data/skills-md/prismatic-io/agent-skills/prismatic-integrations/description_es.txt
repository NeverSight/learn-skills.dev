Construye, actualiza y verifica una Integración Nativa de Código Prismatic (CNI), incluyendo verificaciones locales y pruebas iterativas en la plataforma. Úsala para nuevos requisitos de integración, desarrollo continuo de CNI y depuración de ejecuciones de flujos. Para evaluar o reemplazar un sistema de integración no Prismatic existente, prefiere prismatic-migrate cuando esté disponible.
