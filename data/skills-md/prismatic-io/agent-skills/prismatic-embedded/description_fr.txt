Intégrer Prismatic dans une application web destinée aux clients, y compris un point de terminaison backend qui signe les JWT des utilisateurs intégrés, la configuration frontend du SDK @prismatic-io/embedded, ainsi que le marketplace d’intégration ou d’autres écrans intégrés. À utiliser lorsqu’un utilisateur veut que ses clients trouvent, activent ou configurent des intégrations au sein de sa propre application, ou lorsqu’il pose des questions sur l’authentification intégrée, les clés de signature ou le SDK intégré.
