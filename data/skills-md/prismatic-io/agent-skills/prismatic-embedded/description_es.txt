Incruste Prismatic en una aplicación web orientada al cliente, incluyendo un endpoint backend que firma JWTs de usuario incrustado, la configuración frontend del SDK @prismatic-io/embedded y el marketplace de integraciones u otras pantallas incrustadas. Utilícelo cuando un usuario quiera que sus clientes encuentren, activen o configuren integraciones dentro de la propia aplicación del usuario, o pregunte sobre autenticación incrustada, claves de firma o el SDK incrustado.
