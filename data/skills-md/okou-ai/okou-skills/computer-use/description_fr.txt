Exploitez des applications sur un hôte de bureau via l'utilisation de l'ordinateur, qu'elles soient apparues sous le nom d'Okou Desktop ou de l'ancien Zero Desktop toujours pris en charge, lorsque les API ne suffisent pas. Pas pour les sessions de navigateur à distance (« utilisation du navigateur okou »), a fait surface en tant que navigateur Okou ou navigateur Zero hérité.
