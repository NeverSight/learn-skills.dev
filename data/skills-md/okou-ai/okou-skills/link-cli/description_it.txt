CLI del portafoglio agente di Stripe Link. Usalo quando l'utente vuole che un agente effettui pagamenti per suo conto, crei carte virtuali monouso, spenda tramite il Machine Payments Protocol (MPP) o gestisca il suo portafoglio Link. Si attiva con le menzioni di “acquista con Link”, “pagamento agente”, “portafoglio Link”, “richiesta di spesa” o “link-cli”.
