Stripe Link agent wallet CLI. À utiliser lorsque l'utilisateur souhaite qu'un agent effectue des paiements en son nom, crée des cartes virtuelles à usage unique, dépense via le protocole de paiement automatique (MPP) ou gère son portefeuille Link. Déclenche les mentions « acheter avec Link », « paiement de l'agent », « Link wallet », « demande de dépense » ou « link-cli ».
