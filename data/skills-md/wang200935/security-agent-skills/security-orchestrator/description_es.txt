Enrutador para operaciones de seguridad entre dominios. Úsalo cuando una tarea abarque varios dominios de seguridad (p. ej., flujo completo de pentest, cadena de ataque multi‑dominio, orquestación de CTF, reconocimiento paralelo). Para tareas de dominio único, deja que el descubrimiento nativo de habilidades gestione el enrutamiento.
