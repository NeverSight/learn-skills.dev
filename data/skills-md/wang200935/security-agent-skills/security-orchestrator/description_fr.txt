Routeur pour les opérations de sécurité inter‑domaines. À utiliser lorsqu’une tâche s’étend sur plusieurs domaines de sécurité (par ex. flux complet de pentest, chaîne d’attaque multi‑domaines, orchestration CTF, reconnaissance parallèle). Pour les tâches à domaine unique, laissez la découverte native des compétences gérer le routage à la place.
