Маршрутизатор для кроссдоменных операций безопасности. Используйте, когда задача охватывает несколько доменов безопасности (например, полный процесс пентеста, цепочка атак в нескольких доменах, оркестрация CTF, параллельная разведка). Для задач в одном домене позволяйте встроенному обнаружению навыков выполнять маршрутизацию.
