По умолчанию подготовьте запрос на извлечение GitHub в локальной ветке; используйте изолированное рабочее дерево, когда это явно необходимо, и при необходимости объедините последнюю базовую ветку. Повторно используйте ядро ​​проверки для точного аудита удаленного кода и подтверждения состояния потока; отключить удаленную запись, когда пользователь запрашивает доступ только для чтения. Подходит для PR-обзора на GitHub.
