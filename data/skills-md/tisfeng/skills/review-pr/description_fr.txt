Par défaut, préparez la pull request GitHub sur une branche locale ; utilisez un arbre de travail isolé lorsque cela est explicitement requis et fusionnez éventuellement la dernière branche de base. Réutilisez le noyau de révision pour auditer avec précision le code distant et maintenir l'état du thread avec des preuves ; désactiver les écritures à distance lorsque l'utilisateur demande un accès en lecture seule.
