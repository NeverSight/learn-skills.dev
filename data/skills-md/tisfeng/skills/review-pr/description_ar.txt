بشكل افتراضي، قم بإعداد طلب سحب GitHub على فرع محلي؛ استخدم شجرة عمل معزولة عندما يكون ذلك مطلوبًا بشكل صريح، وقم بشكل اختياري بدمج أحدث فرع أساسي. إعادة استخدام جوهر المراجعة لتدقيق التعليمات البرمجية عن بعد بدقة والحفاظ على حالة مؤشر الترابط بالأدلة؛ تعطيل الكتابة عن بعد عندما يطلب المستخدم الوصول للقراءة فقط. مناسبة لمراجعة GitHub للعلاقات العامة.
