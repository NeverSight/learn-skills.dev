بشكل افتراضي، قم بإعداد طلب سحب GitHub على فرع محلي؛ عندما يكون ذلك مطلوبًا بشكل صريح، استخدم شجرة عمل معزولة وقم بشكل اختياري بدمج أحدث فرع أساسي. إعادة استخدام المراجعة الأساسية لفحص التعليمات البرمجية عن بعد بدقة والحفاظ على حالة مؤشر الترابط مع الأدلة؛ تعطيل الكتابة عن بعد عندما يطلب المستخدم الوصول للقراءة فقط. مناسبة لمراجعة GitHub للعلاقات العامة.
