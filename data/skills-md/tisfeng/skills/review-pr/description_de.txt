Bereiten Sie die GitHub-Pull-Anfrage standardmäßig in einem lokalen Zweig vor. Wenn dies ausdrücklich erforderlich ist, verwenden Sie einen isolierten Arbeitsbaum und führen Sie optional den neuesten Basiszweig zusammen. Verwenden Sie den Überprüfungskern erneut, um Remote-Code genau zu überprüfen und den Thread-Status anhand von Beweisen aufrechtzuerhalten. Deaktivieren Sie Remote-Schreibvorgänge, wenn der Benutzer schreibgeschützten Zugriff anfordert. Geeignet für GitHub PR-Rezension.
