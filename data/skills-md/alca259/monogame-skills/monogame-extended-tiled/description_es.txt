Guía MonoGame.Extended Tilemaps: carga, renderización y consulta de mapas de mosaicos creados con Tile (.tmx), LDtk (.ldtk) u Ogmo Editor a través de la API v6 unificada. Utilice esta habilidad cada vez que el usuario mencione el mapa de mosaicos, el archivo tmx, el mapa de mosaicos, el conjunto de mosaicos, el nivel basado en mosaicos, TiledMapRenderer, el renderizado de mapas ortogonales, la canalización de mapas, el desove de capas de objetos o quiera cargar un nivel hecho en mosaico, incluso si solo dice "Tengo un archivo .tmx" o "¿cómo renderizo un mapa de mosaicos?".
