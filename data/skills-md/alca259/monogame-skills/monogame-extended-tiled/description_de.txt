MonoGame.Extended Tilemaps Guide — Laden, Rendern und Abfragen von Kachelkarten, die mit Tiled (.tmx), LDtk (.ldtk) oder Ogmo Editor über die einheitliche v6-API erstellt wurden. Verwenden Sie diese Fähigkeit, wenn der Benutzer Tiled Map, tmx file, tilemap, tileset, tile-based level, TiledMapRenderer, orthogonal map render, map pipeline, object layer spawn erwähnt oder eine in Tiled erstellte Ebene laden möchte — auch wenn er nur sagt: "Ich habe eine .tmx-Datei" oder "Wie rendere ich eine Kachelkarte".
