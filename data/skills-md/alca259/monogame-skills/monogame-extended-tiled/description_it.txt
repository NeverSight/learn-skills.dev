Guida a MonoGame.Extended Tilemaps — caricamento, rendering e interrogazione di mappe di tile create con Tiled (.tmx), LDtk (.ldtk) o Ogmo Editor tramite l'API unificata v6. Usa questa abilità ogni volta che l'utente menziona mappa tiled, file .tmx, tilemap, tileset, livello basato su tile, TiledMapRenderer, rendering di mappa ortogonale, pipeline della mappa, spawn di layer oggetti, o vuole caricare un livello realizzato in Tiled — anche se dice semplicemente “Ho un file .tmx” o “come faccio a renderizzare una mappa di tile”.
