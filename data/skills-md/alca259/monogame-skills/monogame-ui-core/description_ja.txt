MonoGame UI システム アーキテクチャ ガイド — ビジュアルツリー、UIElement 基底クラス、UIContainer、ペインターのアルゴリズムによるレンダリング、そして UI がゲームワールドとは別の独自の SpriteBatch に存在するという基本ルール。ユーザーが MonoGame で UI システム、HUD、メニュー、オーバーレイ、または画面上のインターフェースの構築について質問したときは、この知識を常に使用してください — たとえ「ゲームの上に UI を描く方法」や「メニューを作る方法」「ビジュアルツリーとは何か」や「UI にゲームエンティティを使うべきか」などと言ってもです。また、実用的な Stardew Valley 風アプローチ（IClickableMenu / ClickableComponent）も代替案としてカバーしています。
