MonoGame UI system architecture guide — visual tree, UIElement base class, UIContainer, painter's algorithm rendering, and the foundational rule that UI lives in its own SpriteBatch separate from the game world. Use this skill whenever the user asks about building a UI system, HUD, menus, overlays, or any on-screen interface in MonoGame — even if they just say "how do I draw UI over my game", "how do I make a menu", "what is a visual tree", or "should I use game entities for UI". Also covers the pragmatic Stardew Valley–style approach (IClickableMenu / ClickableComponent) as an alternative.
