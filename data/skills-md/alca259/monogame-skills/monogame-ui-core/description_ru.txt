Руководство по архитектуре UI‑системы MonoGame — визуальное дерево, базовый класс UIElement, UIContainer, рендеринг по алгоритму художника и фундаментальное правило, что UI живёт в отдельном SpriteBatch, отделённом от игрового мира. Используйте эти знания, когда пользователь задаёт вопросы о построении UI‑системы, HUD, меню, наложений или любого интерфейса на экране в MonoGame — даже если он просто говорит «как нарисовать UI поверх игры», «как сделать меню», «что такое визуальное дерево» или «нужно ли использовать игровые сущности для UI». Также рассматривается практический подход в стиле Stardew Valley (IClickableMenu / ClickableComponent) как альтернатива.
