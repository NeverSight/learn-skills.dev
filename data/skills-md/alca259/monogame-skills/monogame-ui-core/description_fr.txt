Guide d'architecture du système UI de MonoGame — arbre visuel, classe de base UIElement, UIContainer, rendu par l'algorithme du peintre, et la règle fondamentale que l’UI vit dans son propre SpriteBatch séparé du monde du jeu. Utilisez cette compétence chaque fois que l’utilisateur demande comment construire un système UI, HUD, menus, superpositions ou toute interface à l’écran dans MonoGame — même s’il dit simplement « comment dessiner l’UI sur mon jeu », « comment créer un menu », « qu’est‑ce qu’un arbre visuel » ou « faut‑il utiliser les entités du jeu pour l’UI ». Cela couvre également l’approche pragmatique à la Stardew Valley (IClickableMenu / ClickableComponent) comme alternative.
