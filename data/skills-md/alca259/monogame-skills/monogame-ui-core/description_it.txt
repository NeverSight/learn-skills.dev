Guida all'architettura del sistema UI di MonoGame — albero visuale, classe base UIElement, UIContainer, rendering con l'algoritmo del pittore e la regola fondamentale che l'UI vive nel proprio SpriteBatch separato dal mondo di gioco. Usa questa competenza ogni volta che l'utente chiede come costruire un sistema UI, HUD, menu, overlay o qualsiasi interfaccia a schermo in MonoGame — anche se dicono solo “how do I draw UI over my game”, “how do I make a menu”, “what is a visual tree” o “should I use game entities for UI”. Copre anche l'approccio pragmatico in stile Stardew Valley (IClickableMenu / ClickableComponent) come alternativa.
