Guía de arquitectura del sistema UI de MonoGame — árbol visual, clase base UIElement, UIContainer, renderizado con el algoritmo del pintor y la regla fundamental de que la UI vive en su propio SpriteBatch separado del mundo del juego. Utiliza esta habilidad siempre que el usuario pregunte sobre la construcción de un sistema de UI, HUD, menús, superposiciones o cualquier interfaz en pantalla en MonoGame — incluso si solo dice "cómo dibujo UI sobre mi juego", "cómo hago un menú", "qué es un árbol visual" o "debería usar entidades del juego para UI". También incluye el enfoque pragmático al estilo Stardew Valley (IClickableMenu / ClickableComponent) como alternativa.
