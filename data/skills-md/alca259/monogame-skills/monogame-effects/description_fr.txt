Guide des effets personnalisés MonoGame couvrant le runtime MGFX, les effets intégrés (BasicEffect, SpriteEffect, etc.), la compilation de shaders multiplateforme (HLSL vs GLSL), les cibles de modèle de shader, les symboles du préprocesseur et les pièges de portabilité. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur les effets personnalisés, MGFX, les effets intégrés, les shaders multiplateformes, la compatibilité des modèles de shader, le portage d’un shader vers MonoGame, les conditionnels du préprocesseur dans les fichiers .fx, ou rencontre des erreurs de compilation de shaders — même s’il se contente de dire « mon shader ne fonctionne pas sous Linux » ou « quel modèle de shader devrais‑je utiliser ». Veuillez toujours répondre dans la langue de l'utilisateur.
