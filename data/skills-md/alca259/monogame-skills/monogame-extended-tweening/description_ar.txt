دليل MonoGame.Extended للتمرير — تحريك الخصائص مع مرور الوقت دون تخصيص باستخدام فئة Tweener ودوال التسهيل (EasingFunctions). استخدم هذه المهارة كلما ذكر المستخدم كلمة tween أو tweening أو easing أو lerp مع الزمن، أو طلب تحريك خاصية واجهة المستخدم، أو رسوم متحركة مرنة أو ارتدادية، أو انتقال تلاشي في الشيفرة، أو تغيير سهل للخصائص، أو Tweener — حتى لو قالوا فقط «اجعل هذا الزر يرتد عند النقر» أو «اجعل اللوحة تتلاشى بسلاسة».
