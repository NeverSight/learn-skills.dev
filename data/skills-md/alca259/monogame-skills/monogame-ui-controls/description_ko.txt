MonoGame UI 컴포넌트 라이브러리 — 라벨, 버튼(호버 애니메이션 포함), 진행 바/헬스 바, 스크롤 뷰(시저 클리핑 사용), 패널, 스프라이트(텍스처 표시), 그리고 체크박스. 사용자가 특정 UI 컴포넌트에 대해 질문할 때마다 이 지식을 활용하십시오 — 버튼, 라벨, 텍스트 표시, 헬스 바, 진행 바, 스크롤 뷰, 인벤토리 슬롯, 대화 상자, 툴팁, 패널, UI 내 이미지/스프라이트, 체크박스, 토글, 혹은 MonoGame에서 “특정 컴포넌트를 어떻게 만들까”와 같은 질문이라면 — 사용자가 단순히 “버튼이 필요해”, “헬스 바를 만드는 방법”, 혹은 “UI에 이미지를 표시하는 방법”이라고 말하더라도 적용하십시오.
