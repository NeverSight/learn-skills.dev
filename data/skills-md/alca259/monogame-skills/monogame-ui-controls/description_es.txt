Librería de componentes UI para MonoGame — Etiqueta, Botón (con animación al pasar el cursor), Barra de progreso/barra de salud, ScrollView con recorte de tijeras, Panel, Sprite (visualización de textura) y Casilla de verificación. Utiliza esta habilidad siempre que el usuario pregunte sobre componentes UI específicos: botones, etiquetas, visualización de texto, barras de salud, barras de progreso, vistas de desplazamiento, ranuras de inventario, cuadros de diálogo, tooltips, paneles, imagen/sprite en UI, casilla de verificación, alternar, o «¿cómo construyo un componente específico?» en MonoGame, incluso si solo dicen «Necesito un botón», «¿cómo hago una barra de salud?» o «¿cómo muestro una imagen en mi UI?».
