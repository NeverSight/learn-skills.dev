MonoGame UI 布局引擎 — 双遍测量与排列系统、StackPanel、Canvas、FlowLayoutPanel、锚点、脏标记失效以及分辨率无关的 UI 缩放。只要用户询问 UI 元素定位、按钮居中、构建 StackPanel、FlowLayout 或网格布局、将元素锚定到屏幕边缘、为不同分辨率缩放 UI，或任何关于“如何排列/布局 UI”的问题（即使他们只说“如何居中我的血条”“如何像 CSS flexbox 那样流式布局”“我的 UI 在不同分辨率下出现错位”），都请使用此技能。对于 XAML 风格的具有行列的 Grid，请参阅 monogame-ui-grid。

请始终使用用户的语言回复。
