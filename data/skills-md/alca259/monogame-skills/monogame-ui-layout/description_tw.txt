MonoGame UI 版面引擎 — Measure & Arrange 兩階段系統、StackPanel、Canvas、FlowLayoutPanel、錨點、dirty‑flag 無效化，以及與解析度無關的 UI 縮放。每當使用者詢問 UI 元素定位、按鈕置中、建立 StackPanel、FlowLayout 或格線佈局、將元素錨定到螢幕邊緣、不同解析度的 UI 縮放，或任何關於「如何排列/佈局 UI」的問題時，都請使用此技能——即使他們只說「如何置中我的生命條」、「如何像 CSS flexbox 那樣流動項目」或「我的 UI 在不同解析度下崩潰」。關於具有行列的 XAML 風格 Grid，請參考 monogame‑ui‑grid。
