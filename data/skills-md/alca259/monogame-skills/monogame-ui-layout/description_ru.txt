MonoGame UI layout engine — система измерения и размещения в два прохода, StackPanel, Canvas, FlowLayoutPanel, привязка (anchoring), инвалидизация по флагу dirty, и масштабирование UI, независимое от разрешения. Используйте эти навыки каждый раз, когда пользователь задаёт вопросы о позиционировании UI‑элементов, центрировании кнопки, построении StackPanel, FlowLayout или сеточного макета, привязке элементов к краям экрана, масштабировании UI под разные разрешения, либо о любом вопросе вида «как разместить/упорядочить UI» в MonoGame — даже если они просто говорят «как центрировать мой индикатор здоровья», «как расположить элементы, как в CSS flexbox», или «мой UI ломается при разных разрешениях». Для XAML‑подобной сетки Grid с строками и столбцами см. monogame‑ui‑grid.
