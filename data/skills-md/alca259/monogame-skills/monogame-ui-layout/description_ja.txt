MonoGame UI レイアウトエンジン — Measure & Arrange の二段階システム、StackPanel、Canvas、FlowLayoutPanel、アンカリング、ダーティーフラグによる無効化、解像度に依存しない UI スケーリング。ユーザーが UI 要素の配置、ボタンの中央寄せ、StackPanel・FlowLayout・グリッドレイアウトの構築、要素を画面端にアンカーすること、異なる解像度向けの UI スケーリング、あるいは MonoGame で「UI をどう配置/レイアウトすればいいか」といった質問をしたときは、常にこのスキルを使用してください。たとえ「ヘルスバーを中央にしたい」や「CSS の flexbox のようにアイテムを流したい」「異なる解像度で UI が崩れる」だけでも構いません。XAML スタイルの行と列を持つ Grid については、monogame-ui-grid を参照してください。
