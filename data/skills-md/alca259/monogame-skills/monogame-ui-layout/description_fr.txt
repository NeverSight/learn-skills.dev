Moteur de mise en page UI MonoGame — système à deux passes Measure & Arrange, StackPanel, Canvas, FlowLayoutPanel, ancrage, invalidation par drapeau sale et mise à l’échelle UI indépendante de la résolution. Utilisez cette compétence chaque fois que l’utilisateur pose une question sur le positionnement des éléments UI, le centrage d’un bouton, la création d’un StackPanel, d’un FlowLayout ou d’une disposition en grille, l’ancrage des éléments aux bords de l’écran, la mise à l’échelle de l’UI pour différentes résolutions, ou toute interrogation du type « comment agencer / disposer l’UI » dans MonoGame — même s’il dit simplement « comment centrer ma barre de santé », « comment disposer les éléments comme le flexbox CSS », ou « mon UI se casse sur différentes résolutions ». Pour une grille de style XAML avec lignes et colonnes, voir monogame‑ui‑grid. Veuillez toujours répondre dans la langue de l’utilisateur.
