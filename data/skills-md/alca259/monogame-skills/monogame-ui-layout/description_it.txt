Motore di layout UI di MonoGame — sistema a due passaggi Measure & Arrange, StackPanel, Canvas, FlowLayoutPanel, ancoraggio, invalidazione tramite flag sporco e scalatura UI indipendente dalla risoluzione. Usa questa competenza ogni volta che l'utente chiede informazioni sul posizionamento degli elementi UI, centrare un pulsante, costruire uno StackPanel, FlowLayout o layout a griglia, ancorare gli elementi ai bordi dello schermo, scalare l'UI per diverse risoluzioni, o qualsiasi domanda su “come organizzo/layout UI” in MonoGame — anche se dicono solo “come centro la mia barra della salute”, “come dispongo gli elementi come CSS flexbox” o “la mia UI si rompe con risoluzioni diverse”. Per una Grid in stile XAML con righe e colonne, consulta monogame-ui-grid. Rispondi sempre nella lingua dell'utente.
