تحكم القائمة المنسدلة / صندوق الجمع في MonoGame UI — رأس مُطوى يُظهر العنصر المحدد مع سهم، قائمة خيارات قابلة للتوسيع كطبقة غلافية، تنقل باستخدام لوحة المفاتيح/العصا، وتحديد موقع تلقائي للبقاء داخل حدود الشاشة. استخدم هذه الميزة كلما سأل المستخدم عن القائمة المنسدلة أو صندوق الجمع أو قائمة الاختيار أو مُحدد الخيارات أو "كيف أجعل المستخدم يختار من قائمة خيارات" في واجهة المستخدم، أو أي عنصر تحكم يُطوى ويُوسّع للاختيار في MonoGame UI. يرجى دائماً الرد بلغة المستخدم.
