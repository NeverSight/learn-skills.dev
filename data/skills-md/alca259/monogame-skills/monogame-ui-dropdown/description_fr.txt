Contrôle MonoGame UI Dropdown / ComboBox — en-tête réduit montrant l'élément sélectionné plus une flèche, une liste d'options de superposition extensible, une navigation sur le clavier/la manette de jeu et un positionnement automatique pour rester dans les limites de l'écran. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur une liste déroulante, une zone de liste déroulante, une liste de sélection, un sélecteur d'options, « comment puis-je laisser l'utilisateur choisir parmi une liste d'options » dans une interface utilisateur ou tout contrôle de sélection d'extension réduit dans MonoGame UI.
