MonoGame UI Dropdown / ComboBox control: encabezado contraído que muestra el elemento seleccionado más una flecha, lista de opciones de superposición expandible, navegación por teclado/gamepad y posicionamiento automático para mantenerse dentro de los límites de la pantalla. Use esta habilidad cada vez que el usuario pregunte sobre un menú desplegable, cuadro combinado, lista de selección, selector de opciones, "cómo dejo que el usuario elija de una lista de opciones" en una interfaz de usuario o cualquier control de selección de expansión contraída en la interfaz de usuario de MonoGame.
