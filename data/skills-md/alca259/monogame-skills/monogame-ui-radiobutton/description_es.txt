Controles MonoGame UI RadioButton y RadioGroup: selectores de opciones mutuamente excluyentes donde al seleccionar un botón se deseleccionan todos los demás en el mismo grupo. Utilice esta habilidad cada vez que el usuario pregunte sobre botones de radio, opciones mutuamente excluyentes, grupos de opciones, "solo se puede seleccionar uno", "cómo hago que solo se pueda seleccionar una opción a la vez" en la interfaz de usuario de MonoGame o cualquier control de selección agrupado.
