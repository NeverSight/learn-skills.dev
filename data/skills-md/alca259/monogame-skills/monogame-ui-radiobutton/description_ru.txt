Элементы управления RadioButton и RadioGroup в MonoGame UI — взаимно исключающие переключатели, при выборе одной кнопки все остальные в той же группе автоматически снимаются. Используйте эту информацию, когда пользователь спрашивает о радиокнопках, взаимно исключающих вариантах, группах опций, «можно выбрать только один», «как сделать так, чтобы одновременно можно было выбрать лишь один вариант» в MonoGame UI или любом групповом элементе выбора.
