دليل نظام الجسيمات MonoGame.Extended — المؤثرات البصرية (نار، دخان، انفجارات، بريق، سحر) باستخدام مُنبِّهات الجسيمات صفر تخصيص مع مخازن الجسيمات المُجمَّعة. استخدم هذه المهارة كلما ذكر المستخدم نظام الجسيمات أو مُنبِّه الجسيمات أو تأثير الانفجار البصري أو الدخان أو تأثير النار أو ParticleEffect extended أو chispas أو partículas أو انفجار الارتطام أو تأثير الأثر، أو أراد إضافة تأثير بصري ديناميكي — حتى وإن قال فقط "أريد انفجارًا عندما يموت الأعداء" أو "كيف أصنع نارًا في MonoGame".
