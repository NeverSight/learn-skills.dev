Configuration unique pour l'absolu : interrogez comment vous voulez qu'elle se comporte (style de sortie, autonomie, rigueur TDD, répertoire de spécifications, familles) + détectez la pile une fois, puis écrivez `.absolute.config.json` (projet, validé) et `~/.absolute/config.json` (valeurs par défaut de l'utilisateur + remplacements par projet). Toutes les autres commandes absolues-* le lisent au lieu de le re-détecter ; non bloquant - les commandes s'exécutent sans cela et le recommandent doucement. Déclencheurs sur "initialisation absolue", "configuration absolue", "initialisation absolue", "configuration absolue", "première configuration", "mémoriser mes conventions pour ce dépôt".
