Одноразовая настройка для абсолютного: узнайте, как вы хотите, чтобы он вёл себя (стиль вывода, автономность, строгость TDD, каталог спецификаций, семейства) + один раз определите стек, затем напишите `.absolute.config.json` (проект, зафиксированный) и `~/.absolute/config.json` (пользовательские настройки по умолчанию + переопределения для каждого проекта). Любая другая команда Absolute-* считывает его вместо повторного обнаружения; неблокирующий — команды выполняются без него и мягко рекомендуют его. Триггеры по «абсолютной инициализации», «настройке абсолютной», «инициализации абсолютной», «настройке абсолютной», «первой настройке», «запомните мои соглашения для этого репозитория».
