Verwenden Sie diese Option, wenn der Benutzer Code vereinfachen, bereinigen, umgestalten, aufräumen oder verfeinern möchte – seine bereitgestellten/nicht bereitgestellten Git-Änderungen oder eine Zieldatei/einen Zielpfad. Reduziert die Komplexität, vereinfacht die Verschachtelung, entfernt Redundanz und toten Code, bewertet jede Änderung nach Wert (unter Berücksichtigung der Abwanderung von geringem Wert) und führt dann Tests durch, um zu beweisen, dass nichts kaputt gegangen ist. Aufrufen bei: „vereinfachen“, „vereinfachen“, „meinen Code/meine Änderungen vereinfachen“, „aufräumen“, „aufräumen“, „meine Änderungen aufräumen“, „umgestalten“, „sauberer machen“, „aufräumen“, „Komplexität reduzieren“, „abflachen“, „toten Code entfernen“, „besser lesbar machen“, „vor Festschreiben polieren“ oder „absolute Vereinfachung“. Wirkt auf Ihr Arbeitsdifferenzial; für Repo-weiten toten Code verwenden Sie absolute-prune; Für Flusen/Schulden vom Typ „Absolute Debt“ verwenden.
