Usalo quando esegui un workflow di Layer Blueprint salvato anziché una singola generazione: scopri quali workflow ha uno spazio di lavoro, leggi lo schema di input di un workflow, stima ed esegui un run, monitora i suoi passaggi o annullalo. È valido anche quando esiste una pipeline multi‑step ripetibile per un’attività, quando l’utente nomina un workflow o quando l’input di un workflow richiede uno stile o un file. Parole chiave: workflow, blueprint, pipeline, app, multi‑step, run, grafico dei nodi.
