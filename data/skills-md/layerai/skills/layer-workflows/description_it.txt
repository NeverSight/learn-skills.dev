Usa quando esegui un workflow salvato di Layer Blueprint anziché una singola generazione: scopri quali workflow ha un workspace, leggi lo schema di input di un workflow, stima ed esegui un run, controlla i suoi passaggi o annullalo. Inoltre, quando esiste una pipeline multistep ripetibile per un compito, quando l'utente nomina un workflow o quando l'input di un workflow richiede uno stile o un file. Parole chiave: workflow, blueprint, pipeline, app, multi-step, run, node graph.
