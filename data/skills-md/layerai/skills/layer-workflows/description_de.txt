Verwendung beim Ausführen eines gespeicherten Layer Blueprint-Workflows anstelle einer einzelnen Generation: Ermitteln, welche Workflows ein Arbeitsbereich hat, Lesen des Eingabeschemas eines Workflows, Schätzen und Ausführen eines Laufs, Abfragen seiner Schritte oder Abbrechen. Auch wenn eine wiederholbare mehrstufige Pipeline für eine Aufgabe vorhanden ist, wenn der Benutzer einen Workflow benennt oder wenn eine Workflow-Eingabe einen Stil oder eine Datei erwartet. Keywords: Workflow, Blueprint, Pipeline, App, Multi-Step, Run, Node Graph.
