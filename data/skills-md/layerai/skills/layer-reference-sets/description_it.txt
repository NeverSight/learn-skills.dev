Utilizzare quando un aspetto deve rimanere coerente attraverso molte generazioni di Layer: addestrare uno stile personalizzato o un LoRA sull'opera dello studio, curare le immagini che compongono un set di riferimento, scegliere la categoria di addestramento, affinare il peso del set di riferimento durante un'esecuzione, o decidere se addestrare del tutto invece di allegare un riferimento di stile. Anche quando uno stile addestrato produce risultati deboli, incoerenti o ignorati silenziosamente. Parole chiave: LoRA, modello personalizzato, stile addestrato, set di riferimento, coerenza, on-model, direzione artistica, dataset.
