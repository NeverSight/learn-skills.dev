Utiliser lors de la génération d’une image fixe avec Layer : concept art, key art, illustrations, images marketing, icônes ou toute exécution texte‑à‑image. Aussi lorsque le prompt ne fonctionne pas, lorsque le rapport d’aspect ou la résolution est incorrect(e), lorsqu’une référence de style ou de pose doit orienter le résultat, lorsqu’un texte lisible doit apparaître dans l’image, ou lorsque plusieurs images doivent partager le même rendu. Mots‑clés : txt2img, texte à image, prompt, rapport d’aspect, prompt négatif, référence de style, seed.
