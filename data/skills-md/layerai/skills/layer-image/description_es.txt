Úsese al generar una imagen estática con Capa: arte conceptual, arte clave, ilustraciones, imágenes de marketing, íconos o cualquier ejecución de texto a imagen. También cuando un prompt no funciona, cuando la relación de aspecto o la resolución es incorrecta, cuando una referencia de estilo o pose debe guiar el resultado, cuando debe aparecer texto legible en la imagen, o cuando varias imágenes deben compartir el mismo aspecto. Palabras clave: txt2img, texto a imagen, prompt, relación de aspecto, prompt negativo, referencia de estilo, seed.
