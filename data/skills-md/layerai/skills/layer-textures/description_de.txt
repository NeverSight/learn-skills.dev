Verwenden Sie es, wenn Sie mit Layer eine Textur erzeugen, die sich ohne sichtbare Naht wiederholen muss: Boden, Gelände, Wände, Stoff, Laub, Stein, Holz, Musterfüllungen oder ein Fliesenmaterial für eine Spiel-Engine. Auch wenn eine erzeugte Textur Nähte an ihren Rändern zeigt, ein sich offensichtlich wiederholendes Motiv auf einer Oberfläche oder eingebrannte Beleuchtung, die den Motor bekämpft. Schlüsselwörter: Fliesen, nahtlos, Fliesen, Textur, Material, Muster, Zierblech, Gelände, wiederholen.
