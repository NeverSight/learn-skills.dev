Usa quando porti un workflow realizzato in un altro strumento in Layer: un file di workflow esportato, un JSON di grafo dei nodi da qualsiasi editor di nodi, uno screenshot di una canvas di nodi o una pipeline descritta in prosa. Valido anche per convertire, trasferire, migrare o ricostruire una pipeline come workflow Blueprint di Layer. Parole chiave: importare workflow, file di esportazione, grafo dei nodi, editor di nodi, convertire, trasferire, migrare, ricostruire, blueprint.
