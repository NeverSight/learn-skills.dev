Usar al trasladar un flujo de trabajo creado en otra herramienta a Layer: un archivo de flujo de trabajo exportado, un JSON de grafo de nodos de cualquier editor de nodos, una captura de pantalla de un lienzo de nodos o un pipeline descrito en prosa. También al convertir, portar, migrar o reconstruir un pipeline como un flujo de trabajo de Blueprint de Layer. Palabras clave: importar flujo de trabajo, archivo exportado, grafo de nodos, editor de nodos, convertir, portar, migrar, reconstruir, blueprint.
