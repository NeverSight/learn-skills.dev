Usa quando generi o modifichi asset di gioco e intrattenimento su Layer tramite MCP: immagini, video, mesh 3D, audio, sprite, texture o contenuti marketing. Inoltre, quando scegli un modello di base Layer, calcoli il costo di un’esecuzione in Creative Units prima di spenderli, carichi file di riferimento, interroghi una generazione, applichi uno stile addestrato o recuperi da MODEL_NOT_FOUND, INSUFFICIENT_BALANCE, RATE_LIMITED o da un set di riferimenti degradato silenziosamente. Rispondi sempre nella lingua dell’utente.
