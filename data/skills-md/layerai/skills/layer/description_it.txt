Usa quando generi o modifichi asset di gioco e intrattenimento su Layer tramite MCP: immagini, video, mesh 3D, audio, sprite, texture o materiale creativo per il marketing. Anche quando scegli un modello di base di Layer, calcoli il costo di un'esecuzione in Creative Units prima di spenderle, carichi file di riferimento, interroghi una generazione, applichi uno stile addestrato o recuperi da MODEL_NOT_FOUND, INSUFFICIENT_BALANCE, RATE_LIMITED o un set di riferimento degradato silenziosamente.

Rispondi sempre nella lingua dell'utente.
