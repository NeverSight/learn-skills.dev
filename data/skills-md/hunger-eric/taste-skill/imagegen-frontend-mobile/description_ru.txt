Элитный навык создания изображений для мобильных приложений для создания премиальных, удобных для приложений концепций и потоков экрана. Разработано для iOS, Android и кроссплатформенных мобильных продуктов. Отдает приоритет чистой иерархии, удобно читаемому тексту, четкой многоэкранной согласованности, контролируемым цветовым палитрам, нестандартному творческому направлению, текстурированным поверхностям, композиции на основе изображений, изящной индивидуальной иконографии и чистому рамке макета телефона. По умолчанию экраны должны отображаться внутри тонкого макета iPhone премиум-класса или аналогичного телефона с видимой рамкой, в то время как основное внимание уделяется самому контенту приложения. Этот навык генерирует только изображения. Он не пишет код.
