Навыки создания имиджа премиум-класса для создания высококачественных досок с рекомендациями по бренду, систем логотипов, презентаций визуального мира. Обучался работе с минималистическими, кинематографическими, редакционными, темными технологиями, роскошными, культурными, охранными, игровыми, инструментами для разработчиков и бренд-системами потребительских приложений. Оптимизирован для продуманной концепции логотипа, изысканной композиции, скудной типографики, сильного символического значения, макетов премиум-класса, художественных изображений и гибких макетов сетки.
