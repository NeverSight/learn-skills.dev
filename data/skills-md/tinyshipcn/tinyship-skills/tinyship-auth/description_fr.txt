Configurez les fournisseurs d'authentification pour TinyShip : Google OAuth, GitHub OAuth, connexion WeChat, SMS OTP et e‑mail/mot de passe avec vérification. Utilisez ceci lorsque l'utilisateur demande « ajouter la connexion Google », « configurer l'auth GitHub », « configurer la connexion WeChat », « ajouter la connexion SMS », « configurer l'authentification », « ajouter OAuth » ou « ajouter une connexion sociale ».
