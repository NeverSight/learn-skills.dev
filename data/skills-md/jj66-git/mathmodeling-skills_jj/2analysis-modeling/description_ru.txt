Анализ проблем конкуренции по математическому моделированию и этап интеграции проектирования моделирования. Используется для чтения постановки задачи и вложений, полной декомпозиции подзадач, понимания данных, предварительной проверки гипотез, определения переменных, формулировки модели, целевой функции, ограничений, стратегии решения и отчета о моделировании, готового к реализации кода.
