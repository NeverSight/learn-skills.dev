Fase de integración del diseño de modelado y análisis de problemas de competencia de modelado matemático. Se utiliza para leer el enunciado del problema y los archivos adjuntos, completar la descomposición de subproblemas, comprender los datos, validar previamente hipótesis, definir variables, formular modelos, funciones objetivo, restricciones, estrategias de solución y producir un informe de modelado que se puede entregar a la implementación del código.
