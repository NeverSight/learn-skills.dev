На основе файлов ANALYSIS_MODELING_REPORT.md, RESULTS_REPORT.md и рисунков/*.pdf выберите шаблон конкурса и механизм набора текста, организуйте разделы, вставьте рисунки и таблицы и создайте обоснованное заявление об использовании инструмента искусственного интеллекта с подробностями использования для соответствующих документов Национального конкурса по математическому моделированию для студентов.
