В момент принятия решения задайте 2–3 вопроса, на которые может ответить только человек-моделист, сформулированные как компромиссы, а не ответы, и откажитесь на них отвечать. Обратная ситуация «ИИ отвечает, человек подтверждает»: здесь ИИ спрашивает, человек отвечает, затем ИИ помогает с последствиями.
