هندسة عكسية متخصصة لألعاب PS2 ونقل أنابيب PS2Recomp. يُستخدم لاستخراج ISO/ELF، تحليل MIPS R5900، تكوين TOML، استبدال استدعاءات النظام، تصحيح وقت تشغيل C++، وتفاعل GhydraMCP. استخدمه عندما يذكر المستخدم PS2Recomp، ps2xRuntime، بناء cmake المتزايد، SLES، SLUS، out_*.cpp، runner/*.cpp، إعادة تجميع MIPS، تجاوز اللعبة، نقل PS2، أو أي مهمة تجميع ثابتة لـ PlayStation 2.  

يرجى دائمًا الرد بلغة المستخدم.
