パブリック `orca` CLI を使用して、Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、ワークツリーコメント、そして Orca アプリ内に埋め込まれたブラウザを操作します。ユーザーが「$orca-cli」や「use orca cli」「Orca worktree」「child worktree」「cardStatus」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「terminal send」「full handoff」「handover」「give this to another agent」「another worktree」「Orca browser」「control the browser inside Orca」と言ったときに使用してください。タスクが Orca 管理下の状態に関わる場合は、生の `git worktree`、アドホック PTY、Playwright、または Computer Use よりもこれを優先してください。Orca の埋め込みブラウザ以外のブラウザウィンドウ、Webview、デスクトップ UI については Computer Use を使用してください。
