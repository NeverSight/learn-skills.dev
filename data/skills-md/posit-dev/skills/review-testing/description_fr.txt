Examinez le code de test pour la qualité, la conception et l'exhaustivité après avoir implémenté une fonctionnalité ou corrigé un bug. Utilisez-le lorsque l'utilisateur demande « revoyez mes tests », « vérifiez la qualité de mes tests », « ces tests sont-ils suffisants », « revoyez les tests », ou après avoir terminé une implémentation de fonctionnalité incluant des tests. Utilisez-le également lorsque les tests semblent fragiles, instables ou superficiels. Il recoupe le code de production pour identifier les lacunes de couverture. Veuillez toujours répondre dans la langue de l'utilisateur.
