Distribuisci o pubblica contenuti Python e R su un server Posit Connect usando rsconnect‑python o il pacchetto R rsconnect. Gestisce app e dashboard interattive, API web, documenti renderizzati e bundle/manifeste preparati. Usa questa indicazione ogni volta che l’utente richiede di distribuire, pubblicare o ridistribuire contenuti su Posit Connect, o menziona rsconnect. Consulta questa skill invece di indovinare flag o comandi.

Per favore rispondi sempre nella lingua dell'utente.
