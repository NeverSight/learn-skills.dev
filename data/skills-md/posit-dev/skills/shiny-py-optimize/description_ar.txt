تشخيص وإصلاح مشكلات الأداء في تطبيقات Shiny for Python — بدء تشغيل بطيء، تفاعلات بطيئة، عمليات حجب، وتطبيقات تُعاني عند تجاوز عدد قليل من المستخدمين المتزامنين. يُستخدم عندما يكون تطبيق Shiny for Python بطيئًا، يتجمد، يُعيد الحسابات بشكل مفرط، ينتهي مهله، أو يحتاج إلى دعم عدد أكبر من المستخدمين؛ عندما يطلب المستخدم "تسريع"، "تحسين"، أو "جعل" تطبيق Shiny بلغة Python أسرع؛ أو عند إعداد تطبيق نموذجي للتعامل مع حركة مرور حقيقية.
