Diagnosticar y corregir problemas de rendimiento en aplicaciones Shiny para Python — inicio lento, interacciones torpes, operaciones bloqueantes y aplicaciones que se ven superadas más allá de unos pocos usuarios concurrentes. Úsese cuando una aplicación Shiny para Python es lenta, se cuelga, recalcula en exceso, se agota el tiempo de ejecución o debe admitir más usuarios; cuando el usuario solicita "acelerar", "optimizar" o "hacer más rápida" una aplicación Shiny en Python; o al preparar una aplicación prototipo para tráfico del mundo real.
