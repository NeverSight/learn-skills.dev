Diagnostiquez et corrigez les problèmes de performance des applications Shiny for Python — démarrage lent, interactions lentes, opérations bloquantes et applications qui peinent au‑delà de quelques utilisateurs simultanés. Utilisez‑le lorsqu’une application Shiny for Python est lente, se bloque, recompute trop, dépasse le délai d’attente ou doit prendre en charge davantage d’utilisateurs ; lorsque l’utilisateur demande de « speed up », « optimize » ou « make faster » une application Python Shiny ; ou lors de la préparation d’une application prototype pour un trafic réel.
