Diagnosticar y solucionar problemas de rendimiento en aplicaciones Shiny para R — arranque lento, interacciones lentas, operaciones bloqueantes de larga duración y aplicaciones que se ven sobrepasadas más allá de unos pocos usuarios concurrentes. Utilízalo cuando una aplicación Shiny es lenta, se queda colgada, recalcula demasiado, expira, o necesita admitir más usuarios; cuando el usuario solicita "acelerar", "optimizar" o "hacer más rápida" una aplicación Shiny existente; o al preparar una aplicación prototipo para tráfico del mundo real.
