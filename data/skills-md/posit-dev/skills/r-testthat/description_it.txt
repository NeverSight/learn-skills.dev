Le migliori pratiche per scrivere test di pacchetti R con testthat versione 3+. Usa questa competenza quando scrivi o organizzi test per un pacchetto R o quando migliori test esistenti che utilizzano testthat. Copre la struttura dei test e le aspettative, la progettazione di test autonomi, la corretta pulizia con withr, i fixture, il mocking di dipendenze esterne, i test snapshot e i pattern BDD di tipo describe/it.
