Meilleures pratiques pour écrire des tests de packages R avec testthat version 3+. Utilisez cette compétence lors de la rédaction ou de l’organisation des tests d’un package R ou lors de l’amélioration de tests existants utilisant testthat. Elle couvre la structure des tests et les attentes, la conception de tests autonomes, le nettoyage approprié avec withr, les fixtures, le mock des dépendances externes, les tests de snapshots, ainsi que les motifs BDD de type describe/it.
