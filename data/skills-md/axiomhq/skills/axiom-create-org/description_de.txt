Stellen Sie eine temporäre Axiom-Organisation mit einem nicht authentifizierten API-Aufruf bereit, speichern Sie ihr einmaliges Token sicher und übergeben Sie die Anspruchs-URL an den Benutzer. Wird verwendet, wenn ein Agent eine Axiom-Organisation benötigt und der Benutzer keine konfiguriert hat oder nach einer neuen oder Wegwerf-Organisation fragt.
