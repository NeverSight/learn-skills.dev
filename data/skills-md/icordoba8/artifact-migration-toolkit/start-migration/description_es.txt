Iniciar, reanudar o avanzar una migración persistente de código legado a código objetivo, un punto de control validado a la vez, usando ayudantes de confirmación y ejecución en dos fases, trazabilidad de requisitos OpenSpec y puertas obligatorias respaldadas por evidencia fresca antes de que cualquier punto de control o la migración completa pueda marcarse como concluida. Utilice esto siempre que el usuario quiera migrar, portar, reescribir o modernizar un módulo, característica o aplicación heredada a un código base o arquitectura objetivo diferente a través de múltiples sesiones — incluyendo reanudar una migración interrumpida, refrescar después de que el código legado cambió, ejecutar en modo de fuente de datos `--mock`, verificar el `--status` de la migración, actualizar un contrato de migración persistente más antiguo, o invocar una revisión/auditoría Ponytail al finalizar. Active esto incluso cuando el usuario simplemente diga "continúa la migración", "¿Cuál es el estado de la migración X?" o describa querer mover el comportamiento de un repositorio antiguo a uno nuevo sin usar explícitamente la palabra "migración".
