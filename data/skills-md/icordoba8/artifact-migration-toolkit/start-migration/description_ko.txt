검증된 체크포인트마다 두 단계 확인‑실행 도우미, OpenSpec 요구사항 추적성, 그리고 체크포인트 혹은 전체 마이그레이션을 완료로 표시하기 전에 반드시 새로운 증거 기반 게이트를 사용하여 지속된 레거시‑대‑대상 코드베이스 마이그레이션을 시작, 재개 또는 진행하십시오. 사용자는 레거시 모듈, 기능 또는 앱을 다른 대상 코드베이스나 아키텍처로 여러 세션에 걸쳐 마이그레이션, 포팅, 재작성, 현대화하고자 할 때마다 이 기능을 사용하십시오 — 중단된 마이그레이션을 재개하거나, 레거시 코드가 변경된 후 새로 고치거나, `--mock` 데이터 소스 모드로 실행하거나, 마이그레이션 `--status`를 확인하거나, 오래된 지속된 마이그레이션 계약을 업그레이드하거나, 마무리 시 Ponytail 검토/감사를 호출하는 경우 등. 사용자가 단지 “마이그레이션을 계속해 주세요”, “X 마이그레이션 상태가 뭐죠” 라고 말하거나, “구 저장소의 동작을 새 저장소로 옮기고 싶다” 라고 명시적으로 “마이그레이션”이라는 단어를 쓰지 않더라도 이 기능을 트리거하십시오.
