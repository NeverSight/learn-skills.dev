Utilisez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les artefacts, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via la CLI `orca`. Employez‑le lorsque l’utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser », « orca artifacts » ou « share skills ». Privilégiez‑le plutôt que le worktree Git brut, les PTY ad hoc ou l’utilisation de l’ordinateur lorsqu’un état Orca est impliqué. N’utilisez l’ordinateur que pour les fenêtres externes ou l’interface de bureau nécessitant un contrôle au niveau du système d’exploitation, et Playwright ou CDP pour les pages externes.
