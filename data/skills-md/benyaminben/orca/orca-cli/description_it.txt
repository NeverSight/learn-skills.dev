Gestisci i worktree gestiti da Orca, i contesti di cartelle, i terminali, i repository, le automazioni, gli artefatti, la condivisione di competenze, i commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Usalo quando l'utente pronuncia "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Preferiscilo rispetto a un worktree git grezzo, PTY ad‑hoc o Computer Use quando è coinvolto lo stato di Orca. Usa Computer Use solo per finestre esterne o interfacce desktop che richiedono controllo a livello di sistema operativo, e Playwright o CDP per pagine esterne.

Rispondi sempre nella lingua dell'utente.
