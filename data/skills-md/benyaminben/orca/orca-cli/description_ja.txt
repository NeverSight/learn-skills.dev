Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の埋め込みブラウザを `orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関与する場合は、生の git worktree、アドホック PTY、または Computer Use よりもこちらを優先してください。Computer Use は、OS レベルの制御が必要な外部ウィンドウやデスクトップ UI にのみ使用し、外部ページには Playwright または CDP を使用します。

常にユーザーの言語で回答してください。
