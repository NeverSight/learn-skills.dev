تشغيل شجرة العمل المدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على استخدام git worktree العادي أو PTYs المؤقتة أو استخدام الكمبيوتر عندما تكون حالة Orca متضمنة. استخدم استخدام الكمبيوتر فقط للنوافذ الخارجية أو واجهة سطح المكتب التي تحتاج إلى تحكم على مستوى نظام التشغيل، واستخدم Playwright أو CDP للصفحات الخارجية. يرجى دائمًا الرد بلغة المستخدم.
