Usa esto cuando el usuario diga "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts" o "share skills". Prefiérelo sobre git worktree puro, PTYs ad hoc o Uso de Computadora cuando esté involucrado el estado de Orca. Usa Uso de Computadora solo para ventanas externas o UI de escritorio que requieran control a nivel de SO, y Playwright o CDP para páginas externas.
