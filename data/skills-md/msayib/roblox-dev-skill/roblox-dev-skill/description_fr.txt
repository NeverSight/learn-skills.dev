Compétence fondamentale en script et moteur pour le développement de jeux Roblox. Couvre le développement complet du cycle de vie : architecture, script Luau, débogage, sécurité, performances, persistance des données, réseau et environnement Roblox Studio. DOIT utiliser cette compétence chaque fois que l'utilisateur mentionne : « Roblox », « Luau », « Roblox Studio », « ServerScriptService », « ReplicatedStorage », « DataStoreService », « RemoteEvent », ou lorsqu'il travaille avec les outils MCP de Roblox Studio tels que execute_luau, search_game_tree. Remarque : pour la conception UI/UX, se référer à roblox-design-skill et roblox-design-intelligence. Pour l’audio, les effets visuels ou la monétisation, se référer à leurs compétences respectives dans la suite.
