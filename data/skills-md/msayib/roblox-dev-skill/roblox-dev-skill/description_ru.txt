Основные навыки скриптинга и работы с движком для разработки игр в Roblox. Охватывает полный цикл разработки: архитектуру, скриптинг на Luau, отладку, безопасность, производительность, сохранение данных, сетевое взаимодействие и среду Roblox Studio. НЕОБХОДИМО использовать этот навык каждый раз, когда пользователь упоминает: «Roblox», «Luau», «Roblox Studio», «ServerScriptService», «ReplicatedStorage», «DataStoreService», «RemoteEvent», либо работает с инструментами MCP в Roblox Studio, такими как execute_luau, search_game_tree. Примечание: для дизайна UI/UX см. roblox-design-skill и roblox-design-intelligence. Для аудио, VFX или монетизации обращайтесь к соответствующим навыкам в наборе.
