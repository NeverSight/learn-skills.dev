Applique les bonnes pratiques d’egui et d’eframe lors de l’écriture, de la correction, du refactoring ou du débogage de code d’interface graphique Rust utilisant egui. Corrige les API supprimées ou renommées dans egui 0.36 (App::update, SidePanel, Frame::none) et les erreurs courantes en mode immédiat : conflits d’identifiants, rafraîchissements manquants, blocage du cadre, création de ressources par cadre. Ne convient pas aux questions purement conversationnelles sans code.
