تشغيل أشجار العمل المُدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات أشجار العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يذكر المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضَّل ذلك على استخدام git worktree العادي، أو PTYs العشوائية، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم "Computer Use" فقط عندما يتطلب التحكم في واجهة رسومية نافذة مرئية لا يمكن لسطر الأوامر أو نظام الملفات أو الواجهة البرمجية (API) التعامل معها.
