Orcaが管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そしてOrcaの組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、純粋な git worktree や臨時の PTY、あるいは Computer Use よりもこちらを優先してください。GUI が必要で CLI、ファイルシステム、API だけでは操作できない可視ウィンドウがある場合にのみ Computer Use を使用します。
