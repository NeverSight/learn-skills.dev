Analizar e instrumentar repositorios para la observabilidad con Traceway. Utilizar cuando el usuario desea planificar, agregar, migrar o verificar la monitorización con Traceway o OpenTelemetry para backend, navegador, full‑stack, móvil o iOS, o software de agente de IA, incluyendo la topología del proyecto y la creación de un plan de configuración aprobado por el usuario. Los backends usan OTLP/HTTP; los frontends de navegador y los clientes móviles liberados de forma independiente utilizan proyectos de SDK de Traceway por separado. Aceptar ya sea un token de proyecto existente y la URL de la instancia o un token de configuración de organización (`tws_...`) y URL; si no hay token, analizar primero y guiar la adquisición del token de configuración. Tratar cualquier token `tws_` como un token de configuración.
