Analizza e strumenta i repository per l'osservabilità Traceway. Usalo quando l'utente desidera pianificare, aggiungere, migrare o verificare il monitoraggio Traceway o OpenTelemetry per backend, browser, full‑stack, mobile o iOS, o software di agenti AI, includendo la topologia del progetto e la creazione di un piano di configurazione approvato dall'utente. I backend utilizzano OTLP/HTTP; i front‑end del browser e i client mobile rilasciati autonomamente usano progetti SDK Traceway separati. Accetta sia un token di progetto esistente e l'URL dell'istanza, sia un token di configurazione organizzativa (`tws_...`) e URL; senza token, analizza prima e guida l'acquisizione del token di configurazione. Considera qualsiasi token `tws_` come token di configurazione. Si prega di rispondere sempre nella lingua dell'utente.
