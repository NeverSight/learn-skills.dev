Traceway 가시성을 위해 저장소를 분석하고 계측하십시오. 사용자가 백엔드, 브라우저, 풀스택, 모바일 또는 iOS, AI 에이전트 소프트웨어에 대한 Traceway 또는 OpenTelemetry 모니터링을 계획, 추가, 마이그레이션, 검증하려는 경우에 사용합니다. 여기에는 프로젝트 토폴로지와 사용자가 승인한 설정 계획 생성이 포함됩니다. 백엔드는 OTLP/HTTP를 사용하고, 브라우저 프론트엔드와 별도로 배포되는 모바일 클라이언트는 별도의 Traceway SDK 프로젝트를 사용합니다. 기존 프로젝트 토큰과 인스턴스 URL 또는 조직 설정 토큰(`tws_...`)과 URL 중 하나를 허용합니다; 토큰이 없을 경우 먼저 분석하고 설정 토큰 획득을 안내합니다. 모든 `tws_` 토큰은 설정 토큰으로 간주합니다.
