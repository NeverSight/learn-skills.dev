Se utiliza al crear o revisar habilidades (Habilidades del agente) para GitHub Copilot. Se activa ante solicitudes como "Quiero crear una nueva habilidad" o "Quiero mejorar una habilidad existente". El proceso procede de la siguiente manera: recopilación de requisitos → diseño de divulgación por etapas → creación deSKILL.md → diseño de recursos → verificación. Enfatiza un diseño conciso que considera los límites de contexto de GitHub Copilot (límite de token).
