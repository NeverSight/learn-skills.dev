Utilizzato durante la creazione o la revisione delle competenze (competenze dell'agente) per GitHub Copilot. Attivato per richieste del tipo “Voglio creare una nuova competenza” o “Voglio migliorare una competenza esistente”. Il flusso di lavoro procede come: raccolta dei requisiti → progettazione graduale dell'informativa → stesura di SKILL.md → progettazione delle risorse → convalida. Enfatizza un design conciso che considera i limiti del contesto di GitHub Copilot (tetto token).
