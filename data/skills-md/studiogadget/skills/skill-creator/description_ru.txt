Используется при создании или изменении навыков (Agent Skills) для GitHub Copilot. Он запускается такими запросами, как «Я хочу создать новый навык» или «Я хочу улучшить существующий навык». Рабочий процесс происходит следующим образом: сбор требований → проектирование поэтапного раскрытия информации → создание SKILL.md → проектирование ресурса → проверка. Особое внимание уделяется лаконичному дизайну, учитывающему контекстные ограничения GitHub Copilot (ограничения токенов).
