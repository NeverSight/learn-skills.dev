Wird beim Erstellen oder Überarbeiten von Skills (Agent Skills) für GitHub Copilot verwendet. Es wird durch Anfragen wie „Ich möchte eine neue Fähigkeit erstellen“ oder „Ich möchte eine bestehende Fähigkeit verbessern“ ausgelöst. Der Arbeitsablauf geht weiter mit der Anforderungserfassung → dem gestaffelten Offenlegungsentwurf → der Erstellung von SKILL.md → dem Ressourcenentwurf → der Verifizierung. Der Schwerpunkt liegt auf einem prägnanten Design, das die Kontextgrenzen von GitHub Copilot (Token-Obergrenze) berücksichtigt.
