Planifier, diriger et produire des graphiques animés 2D/3D générés par code ainsi que des vidéos montées (reels, accroches, explications SaaS/produit, montages talk‑head) sur la machine locale de l'utilisateur via n'importe quel agent de codage disposant d'un terminal et d'un accès aux fichiers (Claude Code, Codex, Cursor, Claude Desktop, agents VS Code, etc.). Workflow : expliquer le processus → l'utilisateur fournit des références + un scénario → rédiger un script de voix off ElevenLabs prêt à coller → l'utilisateur génère et renvoie le MP3 → construire, prévisualiser, rendre. Utilise Canvas/SVG/p5.brush/Three.js/GSAP rendu dans Chrome sans tête, Motion Canvas/Revideo, ffmpeg, petits modèles IA locaux (découpage, transcription), ainsi que LottieFiles, Freesound, Pexels/Pixabay, Firecrawl et les MCP d’ElevenLabs, et le MCP Playwright pour parcourir visuellement n'importe quel site Web (Pinterest, Behance, Dribbble, sites de marques) et récupérer automatiquement les actifs image/vidéo. À utiliser lorsque l'utilisateur demande de créer, monter, animer, légender, ajouter une voix ou concevoir le son d'une vidéo.

Veuillez toujours répondre dans la langue de l'utilisateur.
