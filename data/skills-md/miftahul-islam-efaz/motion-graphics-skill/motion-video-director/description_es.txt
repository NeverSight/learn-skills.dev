Planifica, dirige y produce gráficos en movimiento 2D/3D generados por código y videos editados (reels, hooks, explicaciones de SaaS/productos, ediciones de talking‑head) en la máquina local del usuario mediante cualquier agente de codificación que tenga acceso a terminal + archivos (Claude Code, Codex, Cursor, Claude Desktop, agentes de VS Code, etc.). Flujo de trabajo: explicar el proceso → el usuario aporta referencias + historia → redactar un guion de voz de ElevenLabs listo para pegar → el usuario genera y devuelve el MP3 → construir, previsualizar, renderizar. Utiliza Canvas/SVG/p5.brush/Three.js/GSAP renderizado en Chrome sin cabeza, Motion Canvas/Revideo, ffmpeg, pequeños modelos locales de IA (recorte, transcripción), además de LottieFiles, Freesound, Pexels/Pixabay, Firecrawl y los MCP de ElevenLabs, y el MCP de Playwright para navegar visualmente cualquier sitio web (Pinterest, Behance, Dribbble, sitios de marcas) y capturar por sí mismo recursos de imagen/video. Úsalo cuando el usuario solicite crear, editar, animar, subtitular, añadir voz o diseñar sonido para un video.
