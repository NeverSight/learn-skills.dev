# apple-product-motion — runtime entry

Premium product-launch and app-feature motion for Apple-like product films.

## Trigger
Use when the brief is a premium hardware/product launch, app feature reveal, or polished product explainer.

## Runtime rules
- Read this entry first; do not load the full guide unless this skill is selected for the current task.
- Start from the brief, source material, platform, runtime, and delivery constraints. State one creative objective and the intended viewer response.
- Create a short shot/beat plan. Select only the techniques that serve that objective; mandatory-looking catalogues are options, not a feature quota.
- Build one representative shot or 5–15 second vertical slice, render it, inspect actual output, and correct the visual system before scaling.
- Keep story, hierarchy, pacing, legibility, continuity, and sound above decorative complexity.
- Preserve source assets and project editability. Record model/tool versions and validate generated assets before use.
- Check the final rendered video, not only source code or a plan. Disclose any review that could not be performed.
