Un studio headless pour créer, éditer, diriger, rendre, inspecter et réviser des vidéos documentaires professionnelles entièrement depuis le terminal. Blender pour les scènes 3D, la cinématographie, l'animation, les VFX et le rendu ; Remotion pour les graphiques animés 2D, la typographie, les graphiques et le compositing ; FFmpeg pour le traitement multimédia, l'assemblage et l’audio ; Python pour l’orchestration ; MCP lorsqu’il est disponible pour un accès structuré aux outils ; analyse visuelle des images rendues pour un contrôle qualité itératif. Ne dépend jamais d’une interface graphique. À utiliser pour des documentaires, des vidéos explicatives et du motion‑graphics qui doivent être construits de manière déterministe et améliorés par le rendu et l’inspection.
