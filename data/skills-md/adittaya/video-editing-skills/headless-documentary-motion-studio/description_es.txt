Un estudio sin cabeza para crear, editar, dirigir, renderizar, inspeccionar y revisar videos documentales profesionales completamente desde la terminal. Blender para escenas 3D, cinematografía, animación, VFX y renderizado; Remotion para gráficos en movimiento 2D, tipografía, diagramas y composición; FFmpeg para procesamiento de medios, ensamblaje y audio; Python para orquestación; MCP donde esté disponible para acceso estructurado a herramientas; análisis visual de fotogramas renderizados para control de calidad iterativo. Nunca depende de una interfaz gráfica. Úsalo para trabajos documentales, explicativos y de motion‑graphics que deben construirse de manera determinista y mejorarse mediante renderizado e inspección.
