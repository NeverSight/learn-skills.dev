Erstelle, passe an und deploye eine produktive Buchungswebsite auf der von Opencals gehosteten API, indem du von einer der offiziellen Open‑Source‑Next.js‑Vorlagen (Salon, Friseursalon, Klinik, Padel‑/Squash‑Club) und dem @opencals/storefront-sdk ausgehst. Verwende sie, wenn der Benutzer eine Buchungs‑/Termin‑/Planungsseite, ein Opencals‑Storefront möchte, dir eine Geschäftsidee + Inspiration gibt und dich bittet, die Buchungsseite zu bauen, oder sagt „bauen Sie mir eine Buchungswebsite“. Deckt die Auswahl einer Vorlage, das Scaffolding, das Verbinden von Services + Verfügbarkeit + Checkout, das Rebranding und das Deployen zu Vercel ab. Für die genauen API/SDK‑Aufruf‑Formate benutze den zugehörigen `opencals-storefront-api`‑Skill.

Bitte antworte immer in der Sprache des Benutzers.
