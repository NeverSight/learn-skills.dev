Erstelle, passe an und deploye eine produktionsreife Buchungs‑Website auf der von Opencals gehosteten API, indem du von einer der offiziellen Open‑Source‑Next.js‑Vorlagen (Salon, Friseursalon, Klinik, Padel‑/Squash‑Club) und dem @opencals/storefront‑SDK ausgehst. Verwende sie, wenn der Nutzer eine Buchungs‑/Terminplanungs‑Website, einen Opencals‑Storefront möchte, dir eine Geschäftsidee + Inspiration gibt und dich bittet, die Buchungs‑Site zu bauen, oder sagt: „Erstelle mir eine Buchungs‑Website“. Deckt die Auswahl einer Vorlage, das Scaffolding, das Verbinden von Services + Verfügbarkeit + Checkout, das Rebranding und das Deployen zu Vercel ab. Für die genauen API‑/SDK‑Aufrufformen verwende den Begleit‑Skill `opencals-storefront-api`.
