Construye, personaliza y despliega un sitio web de reservas en producción en la API alojada de Opencals, comenzando a partir de una de las plantillas oficiales de código abierto de Next.js (salón, barbería, clínica, club de pádel/squash) y el @opencals/storefront-sdk. Úsalo cuando el usuario quiera un sitio de reservas/citas/programación, una tienda Opencals, te dé una idea de negocio + inspiración y te pida que construyas el sitio de reservas, o diga "constrúyeme un sitio web de reservas". Cubre la elección de una plantilla, el scaffolding, la integración de servicios + disponibilidad + checkout, el rebranding y el despliegue a Vercel. Para los formatos exactos de llamadas a la API/SDK, utiliza la habilidad complementaria `opencals-storefront-api`.

Por favor, responde siempre en el idioma del usuario.
