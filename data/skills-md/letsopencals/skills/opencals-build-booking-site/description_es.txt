Construye, personaliza y despliega un sitio web de reservas en producción en la API alojada por Opencals, comenzando a partir de una de las plantillas oficiales de código abierto de Next.js (salón, barbería, clínica, club de pádel/squash) y el @opencals/storefront-sdk. Úsalo cuando el usuario quiera un sitio de reservas/citas/programación, un storefront de Opencals, te dé una idea de negocio + inspiración y te pida que construyas el sitio de reservas, o diga “construye un sitio web de reservas”. Cubre la selección de una plantilla, el scaffolding, la conexión de servicios + disponibilidad + checkout, el rebranding y el despliegue a Vercel. Para las formas exactas de llamadas a la API/SDK, utiliza la skill complementaria `opencals-storefront-api`.
