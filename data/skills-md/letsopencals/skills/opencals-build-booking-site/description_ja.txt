公式のオープンソース Next.js テンプレート（サロン、理容室、診療所、パデル/スクッシュクラブ）と @opencals/storefront-sdk を使用して、Opencals がホストする API 上に本番用予約サイトを構築、カスタマイズ、デプロイします。ユーザーが予約・アポイントメント・スケジューリングサイトや Opencals ストアフロントを求め、ビジネスアイデアやインスピレーションを提供し、予約サイトの構築を依頼したり、「予約サイトを作って」と言ったときに利用します。テンプレートの選択、スキャフォールディング、サービス＋空き状況＋チェックアウトの接続、リブランディング、Vercel へのデプロイをカバーします。正確な API/SDK の呼び出し形状については、コンパニオンの `opencals-storefront-api` スキルを使用してください。
