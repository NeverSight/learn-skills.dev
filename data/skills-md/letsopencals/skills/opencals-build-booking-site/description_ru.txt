Создайте, настройте и разверните производственный сайт бронирования на API Opencals, начиная с одного из официальных открытых шаблонов Next.js (салон, парикмахерская, клиника, падел/сквош‑клуб) и @opencals/storefront-sdk. Используйте, когда пользователь хочет сайт бронирования/записи/расписания, витрину Opencals, предоставляет вам бизнес‑идею + вдохновение и просит построить сайт бронирования, или говорит «создай мне сайт бронирования». Включает выбор шаблона, генерацию структуры, подключение сервисов + доступности + оформления заказа, ребрендинг и развертывание на Vercel. Для точных форм вызовов API/SDK используйте сопутствующий навык `opencals-storefront-api`.
