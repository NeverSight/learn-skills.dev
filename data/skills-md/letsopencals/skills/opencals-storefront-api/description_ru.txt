Авторитетный справочный материал для создания интеграций с размещённым API бронирования Opencals с использованием @opencals/storefront-sdk. Используйте его каждый раз, когда пишете, проверяете или отлаживаете код, взаимодействующий с Opencals — доступность, корзины, встречи, оформление/платежи, учётные записи клиентов (самообслуживание), гости и участники, пользовательские длительности, скидки (автоматические/коды/балансный кредит), перенос и отмена, адреса и согласие на маркетинг, либо при возникновении ошибок 429 / ограничений скорости. Работает вместе с навиком `opencals-build-booking-site` (который создаёт полную структуру сайта), но применим к любой технологической среде: шаблону, приложению с нуля, встраиванию в существующий сайт или сборке v0/Lovable/Bolt.
