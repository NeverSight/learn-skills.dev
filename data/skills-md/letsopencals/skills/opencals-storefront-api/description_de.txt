Echte Referenz für den Aufbau von Integrationen mit der von Opencals gehosteten Buchungs‑API mithilfe von @opencals/storefront-sdk. Verwenden Sie sie immer, wenn Sie Code schreiben, prüfen oder debuggen, der mit Opencals kommuniziert – Verfügbarkeit, Warenkörbe, Termine, Checkout/Zahlungen, Kundenkonten (Self‑Service), Gäste und Teilnehmende, benutzerdefinierte Zeiträume, Rabatte (automatisch / Codes / Guthaben), Umbuchungen und Stornierungen, Adressen und Marketing‑Einwilligungen oder wenn Sie 429‑Fehler/Rate‑Limits erhalten. Sie funktioniert zusammen mit dem `opencals-build-booking-site`‑Skill (der eine komplette Seite erstellt), gilt jedoch für JEDEN Stack: eine Vorlage, eine von Grund auf neu erstellte App, eine Einbettung in eine bestehende Seite oder ein v0/Lovable/Bolt‑Build.
