@opencals/storefront-sdk を使用した Opencals がホストする予約 API の統合構築のための根拠リファレンスです。Opencals とやり取りするコード（可用性、カート、予約、チェックアウト/支払い、顧客アカウント（セルフサービス）、ゲスト・参加者、カスタム期間、割引（自動／コード／残高クレジット）、再スケジュールやキャンセル、住所とマーケティング同意、あるいは 429 エラーやレートリミットに遭遇したとき）を書いたり、レビューしたり、デバッグしたりするときに使用してください。`opencals-build-booking-site` スキル（サイト全体をスキャフォールドする）と併用できますが、スタックは問いません：テンプレート、ゼロからのアプリ、既存サイトへの埋め込み、または v0/Lovable/Bolt ビルドなどに適用できます。
