Ground-truth reference for building integrations on the Opencals hosted booking API with @opencals/storefront-sdk. Use whenever you are writing, reviewing or debugging code that talks to Opencals — availability, carts, appointments, checkout/payments, customer accounts (self-service), guests and attendees, custom durations, discounts (automatic / codes / balance credit), rescheduling and cancellation, addresses and marketing consent, or when you hit 429s / rate limits. Works alongside the `opencals-build-booking-site` skill (which scaffolds a whole site) but applies to ANY stack: a template, a from-scratch app, an embed on an existing site, or a v0/Lovable/Bolt build.
