Referencia de verdad fundamental para construir integraciones en la API de reservas alojada por Opencals con @opencals/storefront-sdk. Úsala siempre que estés escribiendo, revisando o depurando código que se comunique con Opencals — disponibilidad, carritos, citas, checkout/pagos, cuentas de cliente (autoservicio), invitados y asistentes, duraciones personalizadas, descuentos (automáticos / códigos / crédito de saldo), reprogramación y cancelación, direcciones y consentimiento de marketing, o cuando recibas códigos 429 / límites de velocidad. Funciona junto con la skill `opencals-build-booking-site` (que genera un sitio completo) pero se aplica a CUALQUIER stack: una plantilla, una aplicación desde cero, un embed en un sitio existente, o una construcción v0/Lovable/Bolt.
