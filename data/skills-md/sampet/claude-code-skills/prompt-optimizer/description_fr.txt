**Ne pas déclencher** lorsque l’utilisateur veut que la tâche soit exécutée directement, ou dit « just do it » / « 直接做 ». Ne pas déclencher non plus si l’utilisateur dit « 优化代码 », « 优化性能 », « optimize performance », « optimize this code » — ce sont des tâches de refactorisation/performance, pas d’optimisation d’invite.  

Veuillez toujours répondre dans la langue de l’utilisateur.
