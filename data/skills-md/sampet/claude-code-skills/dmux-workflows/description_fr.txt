Orchestration multi-agents à l'aide de dmux (gestionnaire de panneaux tmux pour les agents IA). Modèles pour les flux de travail parallèles d'agents à travers Claude Code, Codex, OpenCode et d'autres harnesses. À utiliser lors de l'exécution de plusieurs sessions d'agents en parallèle ou pour coordonner les flux de travail de développement multi-agents.
