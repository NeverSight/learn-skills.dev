Convierte un diseño estático (un marco de Figma, un panel de control, un conjunto de tarjetas, una pantalla de aplicación o una UI sobre un fondo fotográfico) en una réplica HTML exacta a nivel de píxel que carga desde un estado vacío, luego hace que cada elemento visual actúe según lo que hace (un gráfico siendo leído, una lista recibiendo elementos, un mensaje siendo escrito) en un bucle continuo, y exporta un MP4 para X, un GIF para la web y un GIF de 800 × 500. Usa esta habilidad siempre que el usuario pida animar un diseño, un enlace de Figma, una captura de pantalla, tarjetas UI, un panel de control o una imagen hero, para crear una animación de carga o aparición, un bucle de presentación, un mockup en movimiento o un video o GIF de un diseño, incluso cuando solo dice “animar esto”. También utilízala en páginas de destino y sitios web para tarjetas bento y de características que combinan texto con un visual, y para mockups de productos o paneles de control. Siempre consúltala antes de exportar capas, elegir qué se moverá, construir la introducción, redactar los bucles de la historia visual o codificar videos y GIFs.
