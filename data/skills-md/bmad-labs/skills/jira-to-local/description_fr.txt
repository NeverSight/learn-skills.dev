Utilisez lorsque l'utilisateur souhaite extraire les tickets Jira sur le disque sous forme de fichiers locaux — « pull PROJ-123 », « fetch this story », « get that ticket locally », « download the bug », « save this issue and its comments », « grab the NFR », « read this ticket offline » ou une URL Jira browse collée sans autre demande. Aussi pour plusieurs tickets à la fois — « sync all tickets in sprint 62 », « pull every bug in the sprint », « fetch the whole backlog locally », « download all of team X's issues ». Couvre tous les types de tickets — story, bug, epic, sous‑tâche ou tout type que le projet a inventé pour lui-même. Même lorsque le ticket lie une page Confluence qui doit être récupérée avec lui, ou lorsque l’historique des modifications du ticket est demandé — qui a changé quoi, et quand. Cette compétence ne fait que lire : pour créer, modifier, faire évoluer, commenter, rechercher ou pousser quoi que ce soit vers Jira, utilisez un outil qui écrit dans Jira à la place.
