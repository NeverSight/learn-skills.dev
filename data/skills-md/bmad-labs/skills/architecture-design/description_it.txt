Utilizzare quando l'utente richiede un pacchetto di design, una cartella dei design, design dettagliato, design di soluzione o contratti di un sistema o servizio prima che sia costruito — C4, struttura del progetto, design del modulo, ERD o modello dati, eventi di dominio, API di ingresso o uscita (REST, gRPC, Kafka, Pub/Sub, SQL), diagrammi di sequenza, classe, stato o pipeline di dati — a livello di dettaglio alto, medio o basso; o quando richiede di revisionare, correggere o aggiornare un pacchetto di design esistente rispetto ai suoi requisiti.

Rispondi sempre nella lingua dell'utente.
