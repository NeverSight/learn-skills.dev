Se utiliza cuando el usuario solicita un paquete de diseño, carpeta de diseños, diseño detallado, diseño de soluciones o contratos de un sistema o servicio antes de que se construya: C4, estructura del proyecto, diseño del módulo, ERD o modelo de datos, eventos de dominio, API de entrada o salida (REST, gRPC, Kafka, Pub/Sub, SQL), secuencia, clase, estado o diagramas de canalización de datos, a un nivel de detalle alto, medio o bajo; o solicita revisar, corregir o actualizar un paquete de diseño existente en función de sus requisitos.
