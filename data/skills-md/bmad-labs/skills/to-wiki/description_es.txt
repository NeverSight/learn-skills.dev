Usa cuando conviertes una fuente transcrita — una tesis, artículo, norma, manual o una carpeta de capítulos Markdown bajo docs/references — en una base de conocimiento tipo wiki LLM al estilo Karpathy: páginas interconectadas de concepto, entidad, fuente y síntesis con un index.md, un log.md solo‑append y un archivo de esquema, donde cada afirmación debe rastrearse hasta el texto original. Usa cuando el usuario dice construir una wiki, base de conocimiento, wiki Karpathy, ingerir esta fuente, o solicita consultar o lintar una docs/wiki existente. También úsalo cuando una wiki construida por otra persona necesita una puerta de calidad antes de la entrega.
