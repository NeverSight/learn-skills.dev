Usa quando si trasforma una fonte trascritta — una tesi, un articolo, uno standard, un manuale o una cartella di capitoli Markdown sotto docs/references — in una wiki di conoscenza LLM in stile Karpathy: pagine interconnesse di concetto, entità, fonte e sintesi con un index.md, un log.md in sola aggiunta e un file di schema, dove ogni affermazione deve rintracciare il testo originale. Usa quando l'utente dice di costruire una wiki, una base di conoscenza, una Karpathy wiki, di ingerire questa fonte, o chiede di interrogare o controllare (lint) una docs/wiki esistente. Usa anche quando una wiki costruita da qualcun altro necessita di un checkpoint di qualità prima del trasferimento.
