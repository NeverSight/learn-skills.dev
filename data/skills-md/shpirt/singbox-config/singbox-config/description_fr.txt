Générez, modifiez, migrez et déboguez les fichiers de configuration client sing‑box compatibles avec les versions v1.13 et v1.14. Couvre les modes TUN et proxy système pour les appareils des utilisateurs finaux (SFM/SFA/SFI/CLI), les modèles TUN RealIP vs FakeIP, les règles de fractionnement DNS/routage, le téléchargement de jeux de règles à distance, les sélecteurs de l’API Clash, et la conversion de nœuds pour VLESS/VMess/Shadowsocks/Trojan/Hysteria2/TUIC/ShadowTLS/AnyTLS. À utiliser lorsque l’utilisateur mentionne sing‑box, singbox, SFM/SFA/SFI, la configuration TUN/proxy système, le routage fractionné, le détournement DNS, FakeIP, le comportement du sélecteur, le routage par application, la stratégie réseau, la fragmentation TLS/ECH, l’enchaînement de proxy, ou demande de créer, mettre à jour, migrer ou dépanner une configuration client. Ne couvre pas la configuration d’entrée du proxy côté serveur. Veuillez toujours répondre dans la langue de l’utilisateur.
