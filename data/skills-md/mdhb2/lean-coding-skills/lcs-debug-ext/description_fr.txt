utilisez cette compétence lorsque l'utilisateur demande un débogage uniquement sous forme de rapport, un diagnostic basé sur des preuves ou une proposition de correctif sans appliquer de modifications de code pour un bug, un échec, une erreur, un comportement défectueux, un comportement intermittent ou une régression de performance. déclenchez‑la notamment pour des invites telles que « faites un rapport de débogage », « diagnostiquez ceci mais ne modifiez pas les fichiers », « proposez uniquement un correctif », « investiguer ce bug sans appliquer de modifications » ou « pourquoi cela échoue ? créez un rapport ». ne la déclenchez pas pour une révision de code générale, un audit de sécurité, la mise en œuvre d’une fonctionnalité, une documentation d’architecture large, un débogage classique qui doit mettre à jour .lcs/work-items/{timestamp}-{slug-work-item}/debug.md, ou une application directe de correctif sauf si l'utilisateur demande explicitement un diagnostic uniquement sous forme de rapport. 

veuillez toujours répondre dans la langue de l'utilisateur.
