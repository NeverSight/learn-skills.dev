Utiliza esta habilidad cuando el usuario solicite depuración sólo de informe, diagnóstico basado en evidencia o una propuesta de parche sin aplicar cambios de código para un error, falla, comportamiento roto, comportamiento intermitente o regresión de rendimiento. Activa especialmente para indicaciones como “haz un informe de depuración”, “diagnostica esto pero no edites archivos”, “propón sólo un parche”, “investiga este error sin aplicar cambios” o “¿por qué falla? crea un informe”. No la actives para revisión general de código, auditoría de seguridad, implementación de funcionalidades, documentación amplia de arquitectura, depuración normal que deba actualizar `.lcs/work-items/{timestamp}-{slug-work-item}/debug.md`, o aplicación directa de parches, a menos que el usuario solicite explícitamente un diagnóstico sólo de informe.

Por favor, siempre responde en el idioma del usuario.
