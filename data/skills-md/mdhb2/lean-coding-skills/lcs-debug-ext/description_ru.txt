Используйте это умение, когда пользователь запрашивает отладку только в виде отчёта, диагностику, основанную на доказательствах, или предложение патча без применения изменений кода для ошибки, сбоя, неправильного поведения, непостоянного поведения или регрессии производительности. Срабатывайте особенно на запросы типа «сделайте отчёт об отладке», «диагностировать это, но не изменять файлы», «предложить только патч», «исследовать эту ошибку без внесения изменений» или «почему это падает? создать отчёт». Не срабатывайте для общего ревью кода, аудита безопасности, реализации функции, обширной архитектурной документации, обычной отладки, которая должна обновлять .lcs/work-items/{timestamp}-{slug‑work‑item}/debug.md, или прямого применения патча, если только пользователь явно не просит только отчётную диагностику.
