Usa questa abilità quando l'utente richiede un debug solo a scopo di report, una diagnosi basata su evidenze o una proposta di patch senza applicare modifiche al codice per un bug, un fallimento, un errore, un comportamento rotto, un comportamento instabile o una regressione delle prestazioni. Attivalo soprattutto per richieste come “make a debug report”, “diagnose this but do not edit files”, “propose a patch only”, “investigate this bug without applying changes” o “why is this failing? create a report”. Non attivarlo per review generale del codice, audit di sicurezza, implementazione di funzionalità, documentazione architetturale ampia, debug normale che dovrebbe aggiornare .lcs/work‑items/{timestamp}-{slug-work-item}/debug.md, o applicazione diretta di patch, a meno che l'utente non richieda esplicitamente una diagnosi solo a scopo di report.

Rispondi sempre nella lingua dell'utente.
