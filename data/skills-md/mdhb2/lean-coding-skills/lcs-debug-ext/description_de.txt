Verwende diese Fähigkeit, wenn der Benutzer um reines Debugging‑Reporting, evidenzbasierte Diagnose oder einen Patch‑Vorschlag ohne Anwendung von Codeänderungen für einen Bug, Ausfall, Fehler, fehlerhaftes Verhalten, flüchtiges Verhalten oder eine Leistungsregression bittet. Lösen Sie insbesondere bei Aufforderungen wie „make a debug report“, „diagnose this but do not edit files“, „propose a patch only“, „investigate this bug without applying changes“ oder „why is this failing? create a report“ aus. Nicht auslösen bei allgemeiner Code‑Review, Sicherheitsaudit, Feature‑Implementierung, breiter Architekturdokumentation, normalem Debugging, das .lcs/work-items/{timestamp}-{slug‑work‑item}/debug.md aktualisieren sollte, oder direkter Patch‑Anwendung, es sei denn, der Benutzer fordert ausdrücklich eine Diagnose‑nur‑Berichtstellung an.
