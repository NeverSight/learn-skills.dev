Utilisez cette compétence lorsque l'utilisateur demande explicitement de cartographier, documenter, inspecter, analyser, comprendre ou s'intégrer à une base de code ou à un dépôt existant. Déclenchez pour des requêtes telles que « map this codebase », « document this architecture », « onboard me to this repo », « create codebase docs », « analyze this repository » ou « help me understand this codebase ». Ne déclenchez pas pour la mise en œuvre de fonctionnalités de routine, les corrections de bugs, les modifications de code limitées, les refactorisations d'un seul fichier ou les questions de programmation isolées, sauf si l'utilisateur demande une découverte au niveau du dépôt.

Veuillez toujours répondre dans la langue de l'utilisateur.
