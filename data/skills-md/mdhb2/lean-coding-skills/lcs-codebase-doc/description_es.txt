Utiliza esta habilidad cuando el usuario solicite explícitamente mapear, documentar, inspeccionar, analizar, comprender o incorporarse a una base de código o repositorio existente. Activa la habilidad para indicaciones como “mapear este código”, “documentar esta arquitectura”, “incorporarme a este repo”, “crear documentación del código”, “analizar este repositorio” o “ayúdame a entender este código”. No la actives para implementaciones rutinarias de funciones, corrección de errores, ediciones de código limitadas, refactorizaciones de un solo archivo o preguntas de programación aisladas, a menos que el usuario solicite un descubrimiento a nivel de repositorio.

Por favor, siempre responde en el idioma del usuario.
