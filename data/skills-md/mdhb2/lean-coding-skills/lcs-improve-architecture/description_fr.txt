Générez des plans d'amélioration d'architecture visuelle en analysant les fonctionnalités de la base de code, en identifiant les préoccupations dupliquées et en proposant un refactoring unifié avec une répartition des tâches. Utilisez cela lorsque l'utilisateur demande « améliorer l'architecture », « unifier les systèmes dupliqués », « refactoriser l'architecture », « trouver les duplications entre les fonctionnalités », « proposer une architecture unifiée », ou avant de grands travaux de refactorisation. PAS pour : implémentation de nouvelles fonctionnalités, refactorisation d'un seul fichier, corrections de bugs ou révision de code routinière.

Veuillez toujours répondre dans la langue de l'utilisateur.
