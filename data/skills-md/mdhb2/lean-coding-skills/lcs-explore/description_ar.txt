استخدم هذه المهارة كلما احتاج المستخدم إلى استكشاف، أو عصف ذهني، أو توضيح، أو تشكيل فكرة برمجية قبل وثيقة المتطلبات (PRD) أو التنفيذ. قم بتفعيلها عند الطلبات التي تذكر الاستكشاف، أو العصف الذهني، أو تقييم الخيارات، أو مقارنة الموازين، أو الجدوى، أو طلب الاتجاه الموصى به. استخدم هذه المهارة حتى عندما لا يطلب المستخدم صراحةً وثيقة المتطلبات ولكنه يريد خيارات أو تحليل للموازين. لا تُفعّلها في الحالات التالية: كتابة وثيقة المتطلبات (استخدم lcs‑toprd)، تقسيم المهام (استخدم lcs‑task‑slicer)، مراجعة الشيفرة (استخدم lcs‑code‑review)، التحقيق في الأخطاء (استخدم lcs‑debug)، أو التنفيذ (استخدم lcs‑task‑executor). الاستكشاف مخصص فقط للتفكير الإبداعي، وليس للتنفيذ.

يرجى دائماً الرد بلغة المستخدم.
