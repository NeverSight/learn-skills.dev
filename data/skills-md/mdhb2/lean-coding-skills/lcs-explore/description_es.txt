Utiliza esta habilidad siempre que el usuario necesite explorar, generar ideas, clarificar o dar forma a una idea de código antes de un PRD o implementación. Activa la habilidad en solicitudes que mencionen explorar, generar ideas, evaluar opciones, comparar compensaciones, factibilidad o que pidan una dirección recomendada. Usa esta habilidad incluso cuando el usuario no solicite explícitamente un PRD pero quiera opciones o un análisis de compensaciones. NO la actives para: redacción de PRD (usa lcs-toprd), segmentación de tareas (usa lcs-task-slicer), revisión de código (usa lcs-code-review), investigación de errores (usa lcs-debug) o implementación (usa lcs-task-executor). Explorar es solo para ideación, no para ejecución.

Por favor, responde siempre en el idioma del usuario.
