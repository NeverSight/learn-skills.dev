Utilisez cette compétence chaque fois que l'utilisateur demande de réviser, renforcer ou vérifier la sécurité d'un PRD existant. Déclenchez‑la avec des expressions comme « review prd », « audit prd », « harden prd », « security review of prd ». Cette compétence recherche de façon agressive les critères d'acceptation ambigus, les tests manquants et les zones/fichiers affectés manquants, puis écrit le résultat renforcé/révisé dans **prd‑enhanced.md**. Ne PAS déclencher pour : création de nouveaux PRD (utilisez **lcs‑toprd**), revue de code (utilisez **lcs‑code‑review**), exécution de tâches (utilisez **lcs‑task‑executor**) ou brainstorming (utilisez **lcs‑explore**). Le réviseur ne fait que renforcer les PRD existants, il ne crée ni n'implémente.
