Utilisez cette compétence chaque fois que l'utilisateur demande de produire un PRD léger, axé sur l'implémentation, à partir d'explorations, de notes de débogage ou d'exigences directes.  
Activez-la sur les requêtes « créer PRD », « écrire PRD », « planifier une fonctionnalité », ou lorsqu'un utilisateur demande les critères d'acceptation, la stratégie de test ou l'approche technique.  
Privilégiez les PRD concis, prêts pour les développeurs, qui incluent les zones affectées / fichiers afin de limiter les lectures de code.  
Veuillez toujours répondre dans la langue de l'utilisateur.
