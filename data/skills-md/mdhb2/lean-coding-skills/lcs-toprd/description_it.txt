Usa questa competenza ogni volta che l'utente chiede di produrre un PRD snello, focalizzato sull'implementazione, a partire da esplorazione, note di debug o requisiti diretti. Attiva su richieste come "create PRD", "write PRD", "plan feature", o quando l'utente chiede criteri di accettazione, strategia di test o approccio tecnico. Preferisci PRD concisi, pronti per gli sviluppatori, che includano Aree Interessate / File per limitare la lettura del codice.

Rispondi sempre nella lingua dell'utente.
