Используйте этот навык в качестве единой точки входа / маршрутизатора для всего рабочего процесса Lean Coding Skills (LCS). Активируйте его, когда пользователь хочет «начать», «старт», «что мне делать дальше», «направьте меня», имеет неоднозначный запрос по LCS или иначе нуждается в правильном выборе и вызове соответствующего навыка LCS. lcs-master активно анализирует намерения пользователя, распознаёт стартовые ситуации (въезды), рекомендует следующий навык с богатым контекстуальным руководством и работает либо в режиме подтверждения (запрашивает каждый шаг), либо в режиме автопилота (цепочкой вызывая навыки, останавливаясь в критических точках). Применяет общий контракт (правила пути, точный роутинг по имени навыка, журнал решений) при каждом передаде. Поддерживает управление несколькими рабочими элементами (список, переключение, возобновление, согласование). НЕ активируйте его, если запрос явно указывает конкретный downstream‑навык (например, «run lcs‑toprd») — вызывайте этот навык напрямую.

Пожалуйста, всегда отвечайте на языке пользователя.
