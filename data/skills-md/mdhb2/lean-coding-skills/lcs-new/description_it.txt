Registra un elemento di lavoro vuoto senza creare artefatti di esplorazione, PRD, SRS, attività, codice o documentazione. Usa quando l'utente chiede di creare un nuovo elemento di lavoro, registrare un elemento di lavoro, avviare una nuova attività, buat work item baru o daftarkan pekerjaan baru prima di qualsiasi esplorazione o pianificazione. NON attivare quando l'utente chiede di fare brainstorming, creare un PRD, fare debug, eseguire attività, revisionare il codice o effettuare qualsiasi altra azione di workflow direttamente.

Rispondi sempre nella lingua dell'utente.
