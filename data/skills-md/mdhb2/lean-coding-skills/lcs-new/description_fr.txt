Enregistrez un élément de travail vierge sans créer d'artefacts d'exploration, de PRD, de SRS, de tâche, de code ou de documentation. Utilisez-le lorsque l'utilisateur demande de créer un nouvel élément de travail, d'enregistrer un élément de travail, de démarrer une nouvelle tâche, de « buat work item baru » ou de « daftarkan pekerjaan baru » avant toute exploration ou planification. NE PAS déclencher lorsque l'utilisateur demande de brainstormer, de créer un PRD, de déboguer, d'exécuter des tâches, de réviser le code ou d'effectuer toute autre action de workflow directement.

Veuillez toujours répondre dans la langue de l'utilisateur.
