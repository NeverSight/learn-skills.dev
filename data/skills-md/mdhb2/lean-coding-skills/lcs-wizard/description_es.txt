Utiliza esta habilidad para generar scripts bash interactivos para procedimientos manuales con intervención humana (configuración de infraestructura, migraciones, despliegues). Se activa con 'wizard', 'setup script', 'manual procedure', 'walk me through' y 'interactive script'. NO se activa para: cambios de código (usa lcs-task-executor), revisión de arquitectura (usa lcs-codebase-doc) o documentación (usa lcs-doc-finalizer). Por favor, responde siempre en el idioma del usuario.
