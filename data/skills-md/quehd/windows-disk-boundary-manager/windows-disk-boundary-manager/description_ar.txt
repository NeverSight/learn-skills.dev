إدارة ضغط قرص C في Windows وحدود التخزين لعمل البرمجة بالذكاء الاصطناعي. استخدم عندما يحتاج Codex إلى فحص استخدام القرص على C:، وتحديد المجلدات الكبيرة أو الذاكرات المؤقتة المرتبطة بالذكاء الاصطناعي، ومعاينة المرشحين للتنظيف الآمن، وتصنيف المسارات على C: كمسارات مسموح بها أو محفوفة بالمخاطر، وتحديد حدود الحد الأدنى للمساحة الفارغة والميزانيات التخزينية، أو نقل المستودعات والنماذج والذاكرات المؤقتة والبيانات المؤقتة بعيدًا عن قرص النظام.
