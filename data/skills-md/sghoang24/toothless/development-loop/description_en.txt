Use to build one feature's tasks, from an approved task list to landed, verified, reviewed code. The goal is to own the loop [implement -> verify -> review] per unit — usually one task, or a batch of small same-shape tasks: dispatch a fresh implementer subagent (which writes tests first and proves them green), then a fresh reviewer subagent, cap the cycles, and run a final whole-branch review. You are not allowed to let a unit skip verify or review, to waive a Critical/Important finding, or to exceed the cycle cap without asking the human. Trigger phrases: build the feature, run the loop, implement the tasks, start development, work through tasks.md, dev loop, batch small tasks.
