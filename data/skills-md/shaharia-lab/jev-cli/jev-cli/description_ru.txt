Используйте утилиту командной строки `jev` (неофициальный, открытый CLI для модели Jev от TypeSafe AI), чтобы получать калиброванные вероятности для типизированных вопросов о тексте или JSON: да/нет (noul), один из нескольких вариантов (choice) или позицию по рубрике (score). Охватывает обнаружение CLI с помощью `jev spec`, создание файлов запросов из `jev schema`, их проверку офлайн с помощью `jev validate`, запуск с выводом JSON, ветвление по кодам выхода, управление shell‑скриптами и CI на основе ответа, маркирование множества записей с помощью `jev batch run`, а также выбор между CLI и инструментом `jev mcp serve`. Применяйте, когда задача требует семантической оценки какого‑либо контента (классификация, маршрутизация, обнаружение, оценка, проверка) и доступен `jev`, либо при написании скрипта или шага CI, вызывающего `jev`.
