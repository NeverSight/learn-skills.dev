Verwende das Befehlszeilen‑Tool `jev` (ein inoffizielles, Open‑Source‑CLI für TypeSafe AI’s Jev‑Modell), um kalibrierte Wahrscheinlichkeiten für typisierte Fragen zu Text oder JSON zu erhalten: Ja/Nein (noul), eine von mehreren Optionen (choice) oder eine Position auf einer Skala (score). Es umfasst das Entdecken des CLI mit `jev spec`, das Erstellen von Anforderungsdateien aus `jev schema`, das Offline‑Überprüfen mit `jev validate`, das Ausführen mit JSON‑Ausgabe, das Verzweigen basierend auf Rückgabecodes, das Steuern von Shell‑Skripten und CI anhand einer Antwort, das Beschriften vieler Datensätze mit `jev batch run` und die Wahl zwischen dem CLI und den `jev mcp serve`‑Werkzeugen. Verwende es, wenn eine Aufgabe ein semantisches Urteil über Inhalt benötigt (klassifizieren, routen, erkennen, bewerten, verifizieren) und `jev` verfügbar ist, oder beim Schreiben eines Skripts oder CI‑Schritts, das `jev` aufruft.
