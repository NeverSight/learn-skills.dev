`jev` コマンドラインツール（TypeSafe AI の Jev モデル向けの非公式・オープンソース CLI）を使用して、テキストや JSON に関する型付き質問に対し、較正された確率を取得します：はい/いいえ（noul）、複数の選択肢のいずれか（choice）、またはルーブリック上のスコア（score）です。`jev spec` で CLI を探索し、`jev schema` でリクエストファイルを作成し、`jev validate` でオフライン検証し、JSON 出力で実行、終了コードで分岐、シェルスクリプトや CI を回答でゲートし、`jev batch run` で多数のレコードにラベル付けし、CLI と `jev mcp serve` ツールのどちらかを選択できます。タスクがコンテンツに対する意味的判断（分類、ルーティング、検出、評価、検証）を必要とし、かつ `jev` が利用可能な場合、または `jev` を呼び出すスクリプトや CI ステップを作成する際に使用してください。

常にユーザーの言語で回答してください。
