Utilisez l’outil en ligne de commande `jev` (un CLI non officiel et open‑source pour le modèle Jev de TypeSafe AI) pour obtenir des probabilités calibrées pour des questions typées sur du texte ou du JSON : oui/non (noul), l’une de plusieurs options (choice) ou une position sur une grille (score). Cela couvre la découverte du CLI avec `jev spec`, la création de fichiers de requête à partir de `jev schema`, leur validation hors ligne avec `jev validate`, leur exécution avec sortie JSON, le branchement selon les codes de sortie, le verrouillage des scripts shell et CI sur une réponse, l’étiquetage de nombreux enregistrements avec `jev batch run`, et le choix entre le CLI et les outils `jev mcp serve`. À utiliser lorsqu’une tâche nécessite un jugement sémantique sur un contenu (classer, acheminer, détecter, évaluer, vérifier) et que `jev` est disponible, ou lors de l’écriture d’un script ou d’une étape CI appelant `jev`.
