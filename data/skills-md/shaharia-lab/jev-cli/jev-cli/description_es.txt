Utiliza la herramienta de línea de comandos `jev` (un CLI no oficial y de código abierto para el modelo Jev de TypeSafe AI) para obtener probabilidades calibradas para preguntas tipadas sobre texto o JSON: sí/no (noul), una de varias opciones (choice) o una posición en una rúbrica (score). Incluye descubrir el CLI con `jev spec`, crear archivos de solicitud a partir de `jev schema`, verificarlos sin conexión con `jev validate`, ejecutarlos con salida JSON, ramificar según códigos de salida, proteger scripts de shell y CI basándose en una respuesta, etiquetar muchos registros con `jev batch run` y elegir entre el CLI y las herramientas `jev mcp serve`. Úsalo cuando una tarea requiera un juicio semántico sobre algún contenido (clasificar, enrutar, detectar, calificar, verificar) y `jev` esté disponible, o al escribir un script o paso de CI que invoque `jev`.

Por favor, responde siempre en el idioma del usuario.
