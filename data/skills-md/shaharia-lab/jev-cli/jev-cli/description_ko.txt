`jev` 명령줄 도구(비공식 오픈소스 CLI, TypeSafe AI의 Jev 모델) 를 사용하여 텍스트나 JSON에 대한 질문에 대해 보정된 확률을 얻을 수 있습니다: 예/아니오(​noul), 여러 옵션 중 하나 선택(choice), 혹은 루브릭상의 점수(score). `jev spec` 으로 CLI 를 탐색하고, `jev schema` 로 요청 파일을 만들고, `jev validate` 로 오프라인에서 검증하며, JSON 출력으로 실행하고, 종료 코드로 분기하고, 셸 스크립트와 CI 를 답변에 따라 제어하고, `jev batch run` 으로 다수 레코드를 라벨링하고, CLI 와 `jev mcp serve` 도구 중 선택합니다. 내용에 대한 의미 판단이 필요한 작업(분류, 라우팅, 감지, 평가, 검증)이며 `jev` 를 사용할 수 있거나 스크립트·CI 단계에서 `jev` 를 호출해야 할 때 사용하십시오.
