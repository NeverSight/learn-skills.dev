استعلم عن واجهة برمجة التطبيقات (API) القابلة للقراءة فقط لـ Nx Cloud للحصول على بيانات مساحة العمل. استخدم هذه المهارة عندما يطلب المستخدم فحص أو استرجاع CIPEs، مجموعات التشغيل، عمليات التشغيل، المهام، سير الأعمال، الوكلاء، إحصاءات المهام، المهام المتقلبة، بيانات التخزين المؤقت، أو تفاصيل نقاط النهاية للواجهة البرمجية. استخدم هذه المهارة قبل استدعاءات الواجهة البرمجية المباشرة. إنها توفر خطوات آمنة لاستعادة المصادقة. لا تستخدمها للمراقبة الحية لـ CI.
