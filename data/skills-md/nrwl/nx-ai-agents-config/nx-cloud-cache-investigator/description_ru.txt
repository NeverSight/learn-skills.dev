Исследуйте конкретный сбой кэша Nx, ошибку загрузки или извлечения артефакта, отсутствие повторного воспроизведения при одинаковом хэше или подозрение на небезопасное повторное воспроизведение кэша. Используйте этот навык всякий раз, когда пользователь задаёт вопрос, почему задача Nx не использовала кэш, почему восстановление артефакта кэша не удалось, почему кэшированный результат восстановил устаревшие или неправильные данные, либо для сравнения двух выполнений кэшированных задач. Применяйте навык nx-cloud-api для каждого чтения Nx Cloud. Этот навык поддерживает только API‑расследования, сохраняет строгие ограничения доказательств хэша и запрашивает локальную конфигурацию только тогда, когда это требуется вопросом.
