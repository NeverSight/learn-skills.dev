Usare quando l 'uttente chiede di documentare un repository, scrivere o rifare il README o il documento di un servizio, spiegare come si avvia in locale o come va in produzione, descrivere variabili d' ambiente, deploy e troubleshooting, allineare documentazione obsoleta al codice attuale, o segnala che nessuno sa più come far partire il progetto. Non per documentazione di prodotto, API reference generabile dal codice o testi commerciali.
