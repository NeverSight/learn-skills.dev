قم بتشخيص سبب فشل جلسة Claude Code الحالية (أو مراجعة سيرها بشكل عام) باستخدام إطار عمل الفجوات الثلاث (الفهم / الموا Specification / التنفيذ: السياق / الأدوات / التفكير). يقوم MAIN بإنشاء فرع لتشخيص المشكلة، يعرض النتائج، ويطبق أي تعديل على الملفات فقط بعد الحصول على موافقة صريحة من المستخدم — الفرع يرث سياق المحادثة ولكنه لا يقوم بالتحرير. يتم التفعيل عندما يقول المستخدم: "الوكيل أخطأ"، "هذا لا يعمل"، "تشخيص هذه الجلسة"، "لماذا أخطأ Claude"، "تصحيح هذه الجلسة"، "ما الخطأ"، "مراجعة هذه الجلسة"، "كيف سارت الجلسة"، "/debug-agent"، أو يسأل عن سبب إنتاج الجلسة الحالية مخرجات سيئة. يرجى دائماً الرد بلغة المستخدم.
