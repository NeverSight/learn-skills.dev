Diagnostiquez pourquoi la session Claude Code actuelle a mal fonctionné (ou, plus généralement, examinez comment elle s’est déroulée) en utilisant le cadre des Trois Lacunes (Compréhension / Spécification / Exécution : Contexte / Outils / Raisonnement). MAIN génère un processus fils pour diagnostiquer, présente les constats et applique toute correction de fichier uniquement après l’approbation explicite de l’utilisateur — le processus fils hérite du contexte de la conversation mais ne modifie jamais. DÉCLENCHEUR lorsque : l’utilisateur dit « l’agent s’est trompé », « ça ne fonctionne pas », « diagnostiquer cette session », « pourquoi Claude a-t-il foiré », « déboguer cette exécution », « que s’est‑il passé », « réviser cette session », « comment s’est déroulée cette session », « /debug-agent », ou demande pourquoi la session actuelle a produit une sortie médiocre.  

Veuillez toujours répondre dans la langue de l’utilisateur.
