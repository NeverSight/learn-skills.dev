Диагностировать, почему приложение, развернутое с помощью qwencloud-deploy в Alibaba Cloud International (alibabacloud.com), недоступно или работает медленно, и — только после явного подтверждения пользователя — выполнить безопасное восстановление и проверить результат. Читает локальный файл состояния .qwencloud-deploy для определения ресурсов ECS (и при необходимости RDS MySQL), проводит минимальную только‑чтение диагностику, затем предлагает по одному действию восстановления за раз (запуск ECS, перезапуск сервиса приложения, перезагрузка Nginx), каждое из которых требует подтверждения, указывающего на влияние на состояние. Использовать, когда: пользователь сообщает, что приложение не работает / возвращает 502 / не может подключиться к базе данных, или просит перезапустить и проверить приложение. Не использовать, когда: отсутствует файл состояния .qwencloud-deploy, цель — Aliyun China (использовать qianwenai‑operate), или пользователь хочет лишь обзор статуса/затрат (использовать qwencloud‑observe).

Пожалуйста, всегда отвечайте на языке пользователя.
