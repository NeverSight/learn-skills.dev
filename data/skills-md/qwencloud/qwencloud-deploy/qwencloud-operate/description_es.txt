Diagnosticar por qué una aplicación implementada por qwencloud-deploy en Alibaba Cloud International (alibabacloud.com) no está disponible o es lenta, y —solo después de la confirmación explícita del usuario— realizar una recuperación segura y verificar el resultado. Lee el archivo de estado local .qwencloud-deploy para identificar los recursos ECS (y opcionalmente RDS MySQL), ejecuta diagnósticos mínimos de solo lectura, luego propone una acción de recuperación a la vez (iniciar ECS, reiniciar el servicio de la aplicación, recargar Nginx), cada una condicionada a una confirmación que indique el impacto. Úselo cuando: el usuario indique que la aplicación está caída / devuelve 502 / no puede conectar a la base de datos, o solicite reiniciar y verificar la aplicación. No lo use cuando: no exista el archivo de estado .qwencloud-deploy, el objetivo sea Aliyun China (use qianwenai-operate), o el usuario solo quiera un resumen de estado/costos (use qwencloud-observe).
