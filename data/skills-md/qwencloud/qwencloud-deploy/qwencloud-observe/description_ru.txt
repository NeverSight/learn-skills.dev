Отчет о состоянии здоровья, производительности, статусе ресурсов и фактической стоимости приложения, развернутого с помощью qwencloud-deploy в Alibaba Cloud International (alibabacloud.com), простым языком и без открытия консоли. Читает локальный файл состояния .qwencloud-deploy для идентификации приложения и его ресурсов ECS (и при желании RDS MySQL), затем запрашивает только‑чтение облачных API, чтобы суммировать доступность приложения, производительность ECS/RDS и стоимость в долларах США. Использовать, когда пользователь спрашивает, как работает развернутое приложение, хочет обзор здоровья/производительности/стоимости, интересуется загрузкой CPU/памяти/соединениями/риском медленного SQL или запрашивает ежемесячную стоимость приложения, развернутого через qwencloud. Не использовать, когда файл состояния .qwencloud-deploy отсутствует, цель — Aliyun China (использовать qianwenai-observe) или пользователь хочет изменить/восстановить ресурсы (использовать qwencloud-operate). Пожалуйста, всегда отвечайте на языке пользователя.
