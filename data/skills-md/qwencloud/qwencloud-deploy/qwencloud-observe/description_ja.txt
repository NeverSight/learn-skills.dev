qwencloud-deploy によって Alibaba Cloud International (alibabacloud.com) にデプロイされたアプリケーションの健康状態、パフォーマンス、リソースステータス、実際の請求コストを、コンソールを開かずに平易な言葉で報告します。ローカルの .qwencloud-deploy ステートファイルを読み取り、アプリとその ECS（およびオプションの RDS MySQL）リソースを特定し、読み取り専用のクラウド API を問い合わせて、アプリケーションの可用性、ECS/RDS のパフォーマンス、米ドルでのコストを要約します。使用するケース：ユーザーがデプロイ済みアプリの状況を尋ねる、健康・パフォーマンス・コストの概要が欲しい、CPU/メモリ/接続数/遅延 SQL リスクについて質問する、または qwencloud デプロイアプリの月間コストを尋ねる場合。使用しないケース：.qwencloud-deploy ステートファイルが存在しない、対象が Aliyun China（中国阿里雲）の場合（qianwenai-observe を使用）、またはユーザーがリソースの変更／復旧を希望する場合（qwencloud-operate を使用）。常にユーザーの言語で回答してください。
