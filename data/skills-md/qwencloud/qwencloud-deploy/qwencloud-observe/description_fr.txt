Rapportez la santé, les performances, l’état des ressources et le coût facturé réel d’une application déployée par qwencloud-deploy sur Alibaba Cloud International (alibabacloud.com), en langage clair et sans ouvrir la console. Lit le fichier d’état local .qwencloud-deploy pour identifier l’application et ses ressources ECS (et éventuellement RDS MySQL), puis interroge les API cloud en lecture seule afin de résumer la disponibilité de l’application, les performances ECS/RDS et le coût en USD. À utiliser lorsque : l’utilisateur demande comment se porte son application déployée, souhaite un aperçu santé/performance/coût, s’interroge sur le CPU/mémoire/connexions/risque de SQL lent, ou demande le coût mensuel d’une application déployée avec qwencloud. À ne pas utiliser lorsque : aucun fichier d’état .qwencloud-deploy n’existe, la cible est Aliyun China (utilisez qianwenai-observe), ou l’utilisateur veut modifier/récupérer des ressources (utilisez qwencloud‑operate).

Veuillez toujours répondre dans la langue de l’utilisateur.
