qwencloud-deploy를 통해 Alibaba Cloud International(alibabacloud.com)에 배포된 애플리케이션의 상태, 성능, 리소스 현황 및 실제 청구 비용을 콘솔을 열지 않고 평이한 언어로 보고합니다. 로컬 .qwencloud-deploy 상태 파일을 읽어 애플리케이션과 해당 ECS(및 선택적인 RDS MySQL) 리소스를 식별한 뒤, 읽기 전용 클라우드 API를 호출해 애플리케이션 가용성, ECS/RDS 성능 및 USD 비용을 요약합니다. 사용 상황: 사용자가 배포된 앱의 현재 상황을 묻거나, 상태·성능·비용 개요를 원하거나, CPU·메모리·연결·느린 SQL 위험에 대해 질문하거나, qwencloud‑deploy로 배포된 앱의 월간 비용을 물을 때. 사용하지 말아야 할 경우: .qwencloud-deploy 상태 파일이 없거나, 대상이 알리바바 클라우드 중국(Alibaba Cloud China)일 경우(qianwenai-observe 사용), 혹은 사용자가 리소스를 변경·복구하려는 경우(qwencloud-operate 사용).
