Paquete de habilidades integral de diseño web para crear sitios profesionales, accesibles y bien diseñados. Independiente del framework — funciona con Tailwind, CSS puro, CSS‑in‑JS o cualquier stack. Utiliza esta habilidad siempre que construyas cualquier interfaz web — páginas de destino, aplicaciones web, paneles de control, portafolios, sitios de comercio electrónico o cualquier proyecto frontend. Activa cuando el agente tome decisiones de diseño sobre la disposición, tipografía, color, espaciado, componentes, comportamiento responsivo, accesibilidad, patrones de interacción, estructura de contenido o implementación frontend. Este paquete de habilidades debe consultarse al INICIO de cualquier proyecto web, no como un pensamiento posterior.

Por favor, responde siempre en el idioma del usuario.
