プロフェッショナルでアクセスしやすく、優れたデザインの Web サイトを構築するための包括的な Web デザイン スキル パック。フレームワークに依存しない — Tailwind、バニラ CSS、CSS-in-JS、または任意のスタックで動作します。ランディング ページ、Web アプリ、ダッシュボード、ポートフォリオ、電子商取引サイト、またはフロントエンド プロジェクトなど、Web インターフェイスを構築するときは常にこのスキルを使用します。エージェントがレイアウト、タイポグラフィ、色、間隔、コンポーネント、応答性の動作、アクセシビリティ、インタラクション パターン、コンテンツ構造、またはフロントエンドの実装に関してデザイン上の決定を下すたびにトリガーされます。このスキル パックは、後から考えるのではなく、Web プロジェクトの開始時に参照する必要があります。
