حزمة مهارات شاملة لتصميم الويب لبناء مواقع ويب احترافية وسهلة الوصول ومصممة بشكل جيد. إطار عمل حيادي - يعمل مع Tailwind، أو Vanilla CSS، أو CSS-in-JS، أو أي مكدس. استخدم هذه المهارة عند إنشاء أي واجهة ويب — الصفحات المقصودة، أو تطبيقات الويب، أو لوحات المعلومات، أو المحافظ، أو مواقع التجارة الإلكترونية، أو أي مشروع واجهة أمامية. يتم التشغيل عندما يتخذ الوكيل قرارات التصميم بشأن التخطيط أو الطباعة أو اللون أو التباعد أو المكونات أو السلوك سريع الاستجابة أو إمكانية الوصول أو أنماط التفاعل أو بنية المحتوى أو تنفيذ الواجهة الأمامية. يجب الرجوع إلى حزمة المهارات هذه عند بداية أي مشروع ويب، وليس كفكرة لاحقة.
