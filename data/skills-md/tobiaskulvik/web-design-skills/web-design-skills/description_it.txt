Pacchetto completo di competenze di web design per la creazione di siti Web professionali, accessibili e ben progettati. Indipendente dal framework: funziona con Tailwind, Vanilla CSS, CSS-in-JS o qualsiasi stack. Utilizza questa competenza ogni volta che crei un'interfaccia web: pagine di destinazione, app web, dashboard, portfolio, siti di e-commerce o qualsiasi progetto frontend. Si attiva ogni volta che l'agente prende decisioni di progettazione relative a layout, tipografia, colore, spaziatura, componenti, comportamento reattivo, accessibilità, modelli di interazione, struttura del contenuto o implementazione del frontend. Questo pacchetto di competenze dovrebbe essere consultato all'INIZIO di qualsiasi progetto web, non come ripensamento.
