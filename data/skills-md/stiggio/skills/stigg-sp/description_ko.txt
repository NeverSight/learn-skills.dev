Stigg가 프로비저닝 중이거나 Stripe 프로젝트를 통해 방금 프로비저닝된 경우에 사용합니다. `stripe projects add stigg/environment`, `stripe projects Catalog`, `stripe projects Rotate`/`remove`, Stigg에 대해 `.env`에 이미 Stripe Projects가 작성한 `STIGG_SERVER_API_KEY` / `STIGG_CLIENT_API_KEY`가 포함된 경우입니다. 또한 사용자가 이미 Stripe 프로젝트를 사용하고 있는 앱에 가격, 자격, 기능 제한 또는 사용량 측정을 추가하도록 요청하는 경우에도 사용합니다. 그러면 브라우저에 가입하는 대신 터미널에서 환경이 프로비저닝됩니다. 프로비저닝된 자격 증명이 무엇인지, 서버와 클라이언트 SDK의 첫 번째 연결을 다룹니다. Stripe 프로젝트와 관련 없는 Stigg 작업을 건너뛰십시오. 대신 'stigg' 우산과 기둥을 로드하세요.
