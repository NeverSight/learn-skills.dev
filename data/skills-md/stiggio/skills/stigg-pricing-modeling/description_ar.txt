مهارة التنفيذ — تُستخدم عندما يقوم المستخدم **بإنشاء** كتالوج منتجات Stigg (تم اختيار النموذج بالفعل). يغطي الميزات (المنطقية / المقاسة / التكوين)، والخطط (مجانية / مدفوعة / مخصصة)، والإضافات، والمنتجات، والرسوم (ثابتة / لكل وحدة / الدفع أولاً بأول / الالتزام مقدمًا / الحد الأدنى للإنفاق / الأرصدة)، والزيادة، والكوبونات، وعملات الائتمان المخصصة، وتوطين الأسعار. تتضمن المشغلات "إنشاء خطة"، أو "إضافة وظيفة إضافية"، أو "تحديد ميزة"، أو "نموذج التسعير الخاص بي في Stigg"، أو "إعداد التسعير على أساس الاستخدام"، أو "تكوين المبالغ الزائدة"، أو "نشر خطة"، أو "نشر مسودة"، أو "تحرير خطة منشورة"، أو "إضافة رسوم"، أو "إنشاء قسيمة"، أو "إعداد توطين الأسعار"، أو أي طفرة في كتالوج Stigg. MCP-first — يتم تنفيذ عمل الكتالوج من خلال Stigg MCP، وليس عن طريق الكتابة اليدوية REST. قم بالتخطي عندما يكون المستخدم لا يزال **ينتقي** النموذج — وهذا هو خبير التسعير. انتقل إلى فحوصات استحقاق وقت التشغيل (استحقاقات stigg) ودورة حياة الاشتراك (اشتراكات stigg).
