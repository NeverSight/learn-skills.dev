実装スキル — ユーザーが Stigg 製品カタログを**構築**するときに使用します (モデルはすでに選択されています)。機能 (ブール / 従量制 / 構成)、プラン (無料 / 有料 / カスタム)、アドオン、製品、料金 (フラット / ユニットごと / 従量課金制 / 事前契約 / 最低使用量 / クレジット)、超過料金、クーポン、カスタム クレジット通貨、価格のローカリゼーションをカバーします。トリガーには、「プランの作成」、「アドオンの追加」、「機能の定義」、「Stigg での価格設定のモデル化」、「使用量ベースの価格設定」、「超過料金の構成」、「プランの公開」、「下書きの公開」、「公開されたプランの編集」、「料金の追加」、「クーポンの作成」、「価格のローカリゼーションの設定」、または Stigg カタログの変更が含まれます。 MCP ファースト — カタログ作業は、手書きの REST ではなく、Stigg MCP を通じて実行されます。ユーザーがまだモデルを**選択**している場合はスキップします。これが stigg-pricing-expert です。実行時の資格チェック (stigg-entitlements) とサブスクリプションのライフサイクル (stigg-subscriptions) についてはスキップしてください。
