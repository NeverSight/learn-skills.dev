Compétence MISE EN ŒUVRE — à utiliser lorsque l'utilisateur **crée** un catalogue de produits Stigg (le modèle est déjà choisi). Couvre les fonctionnalités (booléennes / mesurées / configuration), les forfaits (gratuits / payants / personnalisés), les modules complémentaires, les produits, les frais (fixes / par unité / paiement à l'utilisation / engagement à l'avance / dépenses minimales / crédits), les excédents, les coupons, les devises de crédit personnalisées, la localisation des prix. Les déclencheurs incluent « créer un forfait », « ajouter un module complémentaire », « définir une fonctionnalité », « modéliser ma tarification dans Stigg », « configurer une tarification basée sur l'utilisation », « configurer les dépassements », « publier un forfait », « publier un brouillon », « modifier un forfait publié », « ajouter des frais », « créer un coupon », « configurer la localisation des prix » ou toute mutation du catalogue Stigg. MCP-first : le travail de catalogue s'effectue via le Stigg MCP, et non en écrivant manuellement REST. Ignorer lorsque l'utilisateur est encore en train de **sélectionner** le modèle - c'est stigg-pricing-expert. Ignorez les vérifications des droits d'exécution (stigg-entitlements) et le cycle de vie des abonnements (stigg-subscriptions).
