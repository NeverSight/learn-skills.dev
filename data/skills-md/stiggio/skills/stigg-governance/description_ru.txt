Используется для работы по бюджетированию и контролю расходов по каждому объекту в Stigg Governance — обеспечение соблюдения лимитов использования в любой иерархии подразделений, которые клиент должен бюджетировать (модель объекта определяется клиентом, а не фиксированная) — определение типов объектов с помощью ключей атрибуции, построение собственного дерева клиента, назначение лимитов на объект для функции или кредитной валюты, определение размерной области, запрос к дереву управления для балансов и принудительное выполнение во время выполнения. Триггеры включают в себя «бюджет на единицу», «лимит расходов на команду», «ограничение токенов на агента», «ограничения центров затрат», «лимиты субклиентов», «бюджет на проект», «тип сущности», «ключи атрибуции», «дерево управления», «принудительное соблюдение бюджета», «ограниченное назначение», «GovernanceNotEnabled», «сохранять синхронизацию объектов», «переродительский объект», «CannotReportUsageForEntitlementWithMeterError». Пропустите кредитные гранты/пулы/регистры на уровне учетной записи (стигг-кредиты), ограничение функций без иерархии сущностей (стигг-права) или моделирование каталога (стигг-ценообразование-моделирование).
