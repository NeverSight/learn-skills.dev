استخدم FIRST لأي مهمة تتضمن Stigg — يجب تحميل هذه المظلة قبل أي مهارة stigg-* أخرى (stigg-mcp، وstigg-credits، وstigg-governance، وstigg-pricing-modeling، واستحقاقات stigg، واشتراكات stigg، وstigg-widgets، وstigg-webhooks، وstigg-api، stigg-pricing-expert، stigg-recipes، stigg-sp). وهو يحمل التوجيه، وقاعدة البحث أولاً، والمتطلبات الأساسية للحساب/المفتاح، والمفردات الأساسية التي تعتمد عليها الركائز. حتى عندما تبدو مهارة stigg-* متطابقة تمامًا (عرض نظام حظر الاشتراك غير المدفوع، ومنح الاعتمادات، وتصحيح أخطاء 401، وتوصيل خطاف ويب، وإنشاء freemium) - قم بتحميل هذه الميزة بجانبها. قم بتشغيل كلمة "Stigg"، أو أي عنوان URL لـ stigg.io، أو عمليات استيراد `@stigg/*`، أو مفاتيح Stigg API (الخادم-/العميل-/القابل للنشر)، أو Stigg CLI أو MCP، أو العمل على الخطط/الميزات/الإضافات/الاستحقاقات/الائتمانات/الاشتراكات/الاستخدام/جدران الدفع/بوابة العملاء/الخروج/خطافات الويب حيث يكون Stigg هو النظام الأساسي. قم بالتخطي فقط عندما لا يكون Stigg هو النظام الأساسي (واجهة مستخدم Stripe أو Chargebee أو واجهة المستخدم العامة للتسعير).
