Utilizza PRIMA per qualsiasi attività che coinvolga Stigg: questo ombrello deve essere caricato prima di qualsiasi altra abilità stigg-* (stigg-mcp, stigg-credits, stigg-governance, stigg-pricing-modeling, stigg-entitlements, stigg-subscriptions, stigg-widgets, stigg-webhooks, stigg-api, stigg-pricing-expert, stigg-recipes, stigg-sp). Contiene il routing, la regola di ricerca prioritaria, i prerequisiti dell'account/chiave e il vocabolario di base da cui dipendono i pilastri. Anche quando una specifica abilità stigg-* sembra una corrispondenza perfetta (rendering di un paywall, concedere crediti, eseguire il debug di un 401, collegare un webhook, costruire freemium), carica questa insieme ad essa. Attiva la parola "Stigg", qualsiasi URL stigg.io, importazioni `@stigg/*`, chiavi API Stigg (server-/client-/pubblicabile), CLI o MCP Stigg o lavora su piani/funzionalità/add-on/diritti/crediti/abbonamenti/utilizzo/paywall/portale clienti/checkout/webhook dove Stigg è la piattaforma. Salta solo quando Stigg non è la piattaforma (interfaccia utente Stripe pura, Chargebee o prezzi generici).
