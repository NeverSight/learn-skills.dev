Stigg に関係するタスクには FIRST を使用します。このアンブレラは、他の stigg-* スキル (stigg-mcp、stigg-credits、stigg-governance、stigg-pricing-modeling、stigg-entitlements、stigg-subscriptions、stigg-widgets、stigg-webhooks、stigg-api、 stigg-pricing-expert、stigg-recipes、stigg-sp)。これには、ルーティング、検索優先ルール、アカウント/キーの前提条件、および柱が依存する中心的な語彙が含まれます。特定の stigg-* スキルが完全に一致しているように見える場合でも (ペイウォールのレンダリング、クレジットの付与、401 のデバッグ、Webhook の接続、フリーミアムの構築)、これを一緒にロードします。 「Stigg」という単語、任意の stigg.io URL、「@stigg/*」インポート、Stigg API キー (サーバー/クライアント/公開可能)、Stigg CLI または MCP でトリガーするか、Stigg がプラットフォームであるプラン/機能/アドオン/資格/クレジット/サブスクリプション/使用法/ペイウォール/カスタマー ポータル/チェックアウト/ウェブフックで作業します。 Stigg がプラットフォーム (純粋な Stripe、Chargebee、または汎用の価格設定 UI) ではない場合にのみスキップします。
