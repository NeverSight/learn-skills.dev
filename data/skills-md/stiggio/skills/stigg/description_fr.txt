Utilisez EN PREMIER pour toute tâche impliquant Stigg — ce parapluie doit être chargé avant toute autre compétence stigg-* (stigg-mcp, stigg-credits, stigg-governance, stigg-pricing-modeling, stigg-entitlements, stigg-subscriptions, stigg-widgets, stigg-webhooks, stigg-api, stigg-pricing-expert, stigg-recettes, stigg-sp). Il contient le routage, la règle de recherche en premier, les prérequis de compte/clé et le vocabulaire de base dont dépendent les piliers. Même lorsqu'une compétence stigg-* spécifique semble correspondre parfaitement (rendre un paywall, accorder des crédits, déboguer un 401, câbler un webhook, créer du freemium), chargez celle-ci à côté. Déclenchez sur le mot "Stigg", n'importe quelle URL stigg.io, les importations `@stigg/*`, les clés API Stigg (serveur-/client-/publiable), la CLI ou MCP Stigg, ou travaillez sur des plans/fonctionnalités/compléments complémentaires/droits/crédits/abonnements/usage/paywalls/portail client/checkout/webhooks où Stigg est la plate-forme. Ignorer uniquement lorsque Stigg n'est pas la plate-forme (pure Stripe, Chargebee ou interface utilisateur de tarification générique).
