对于任何涉及 Stigg 的任务，请使用 FIRST - 这把伞必须在任何其他 stigg-* 技能（stigg-mcp、stigg-credits、stigg-governance、stigg-pricing-modeling、stigg-entitlements、stigg-subscriptions、stigg-widgets、stigg-webhooks、stigg-api、stigg-pricing-expert、斯蒂格食谱，斯蒂格-sp）。它承载路由、搜索优先规则、帐户/密钥先决条件以及支柱所依赖的核心词汇。即使某个特定的 stigg-* 技能看起来完美匹配（渲染付费墙、授予积分、调试 401、连接 Webhook、构建免费增值），也可以将其与它一起加载。触发单词“Stigg”、任何 stigg.io URL、`@stigg/*` 导入、Stigg API 密钥（服务器/客户端/可发布）、Stigg CLI 或 MCP，或者处理计划/功能/插件/权利/积分/订阅/使用/付费墙/客户门户/结帐/webhooks（其中 Stigg 是平台）。仅当 Stigg 不是平台时才跳过（纯 Stripe、Chargebee 或通用定价 UI）。
