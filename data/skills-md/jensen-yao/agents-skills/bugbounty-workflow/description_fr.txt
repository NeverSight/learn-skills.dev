Dans le cadre autorisé (par exemple, plateformes de primes telles que BuTian/SRC), le flux de travail complet pour la recherche de vulnérabilités est le suivant : reconnaissance → découverte → vérification → reporting. Utilisez-le lorsque l'utilisateur demande « creuser des trous », « trouver des vulnérabilités », « tester une cible », « des tests d'intrusion », « marquer des points » ou « soumettre à SRC/BuTian ».
