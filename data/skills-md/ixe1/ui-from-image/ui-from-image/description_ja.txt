1つ以上のウェブページ/アプリの UI スクリーンショットを、高精細でレスポンシブな実装に変換します。単体のページとして作成するか、既存のフロントエンドを適用して実装します。正確なビューポートの一致、タイポグラフィ／アイコンの監査、明示的な余白とカラーの一致、ブラウザスクリーンショットの比較、そして目立つ不一致がなくなるまでの繰り返しリファインを最優先します。不足しているアセットは、提供されたファイルを使用し、利用可能な場合は direct image_gen で足りないラスタアセットを生成して対処します。可能であれば、複数の関連アセットをまとめた抽出可能なアセットシートとして生成し、そうできない場合はプレースホルダーを使用し、残りの各アセットにつき単一のコピー＆ペースト可能なコードブロックにスタンドアロン生成プロンプトを1つずつ含めます。常にユーザーの言語で応答してください。
