Chargez cette compétence chaque fois que vous rédigez, examinez ou générez des rapports de bugs d’accessibilité — que ce soit à partir de la sortie d’outils automatisés, de tests manuels ou d’analyses d’agents IA. Le but de cette compétence est de rendre les erreurs d’accessibilité plus faciles à signaler avec précision, afin que les développeurs puissent les reproduire, les comprendre et les corriger sans aller‑retour supplémentaire. Incluez absolument toujours les champs obligatoires (URL, XPath, extrait HTML, critère WCAG, ID de règle, sévérité, fréquence) dans chaque rapport. En aucun cas ne soumettez un rapport vague qui omet l’élément fautif, le critère WCAG ou les étapes de reproduction.
