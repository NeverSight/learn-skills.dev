Installez et configurez DocsPress pour un référentiel GitHub et sa cible de publication WordPress. À utiliser lorsqu'un agent doit publier une arborescence de documentation Markdown existante, activer les demandes d'extraction de propositions WordPress vers GitHub, créer ou réparer le flux de travail DocsPress GitHub Actions, configurer WordPress.com OAuth ou un point de terminaison WordPress de jeton de support existant, préparer le thème et le plug-in de blocs DocsPress associés, vérifier un essai ou déplacer en toute sécurité la documentation du brouillon vers les pages publiées.
