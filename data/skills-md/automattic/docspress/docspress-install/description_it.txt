Installa e configura DocsPress per un repository GitHub e il suo target di pubblicazione WordPress. Da utilizzare quando un agente deve pubblicare un albero di documentazione Markdown esistente, abilitare richieste pull di proposte da WordPress a GitHub, creare o riparare il flusso di lavoro DocsPress GitHub Actions, configurare WordPress.com OAuth o un endpoint WordPress con token di connessione esistente, preparare il tema DocsPress associato e il plug-in di blocchi, verificare un'esecuzione di prova o spostare in sicurezza la documentazione dalla bozza alle pagine pubblicate.
