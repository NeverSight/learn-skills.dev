GitHub 저장소와 WordPress 게시 대상을 위한 DocsPress를 설치하고 구성합니다. 에이전트가 기존 Markdown 문서 트리를 게시하고, WordPress-GitHub 제안 풀 요청을 활성화하고, DocsPress GitHub Actions 워크플로를 생성 또는 복구하고, WordPress.com OAuth 또는 기존 전달자 토큰 WordPress 엔드포인트를 구성하고, 동반 DocsPress 테마 및 차단 플러그인을 준비하고, 연습 실행을 확인하거나 문서를 초안에서 게시된 페이지로 안전하게 이동해야 하는 경우에 사용합니다.
