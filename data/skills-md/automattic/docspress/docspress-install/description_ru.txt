Установите и настройте DocsPress для репозитория GitHub и его цели публикации WordPress. Используйте, когда агент должен опубликовать существующее дерево документации Markdown, включить запросы на извлечение предложений WordPress-to-GitHub, создать или исправить рабочий процесс DocsPress GitHub Actions, настроить WordPress.com OAuth или существующую конечную точку WordPress с токеном на предъявителя, подготовить сопутствующую тему DocsPress и плагин блоков, проверить пробный прогон или безопасно переместить документацию из черновика на опубликованные страницы.
