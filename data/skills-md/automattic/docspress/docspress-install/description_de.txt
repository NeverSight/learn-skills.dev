Installieren und konfigurieren Sie DocsPress für ein GitHub-Repository und sein WordPress-Veröffentlichungsziel. Wird verwendet, wenn ein Agent einen vorhandenen Markdown-Dokumentationsbaum veröffentlichen, WordPress-zu-GitHub-Vorschlags-Pull-Requests aktivieren, den DocsPress GitHub Actions-Workflow erstellen oder reparieren, WordPress.com OAuth oder einen vorhandenen Bearer-Token-WordPress-Endpunkt konfigurieren, das begleitende DocsPress-Theme und das Blocks-Plugin vorbereiten, einen Probelauf überprüfen oder Dokumentation sicher vom Entwurf auf veröffentlichte Seiten verschieben muss.
