قم بتثبيت DocsPress وتكوينه لمستودع GitHub وهدف نشر WordPress الخاص به. يُستخدم عندما يتعين على الوكيل نشر شجرة وثائق Markdown موجودة، أو تمكين طلبات سحب مقترحات WordPress-to-GitHub، أو إنشاء سير عمل DocsPress GitHub Actions أو إصلاحه، أو تكوين WordPress.com OAuth أو نقطة نهاية WordPress الحالية للرمز المميز، أو إعداد سمة DocsPress المصاحبة وحظر المكونات الإضافية، أو التحقق من التشغيل الجاف، أو نقل الوثائق بأمان من المسودة إلى الصفحات المنشورة.
