GitHub リポジトリとその WordPress 公開ターゲット用に DocsPress をインストールして構成します。エージェントが既存の Markdown ドキュメント ツリーの公開、WordPress から GitHub へのプロポーザル プル リクエストの有効化、DocsPress GitHub Actions ワークフローの作成または修復、WordPress.com OAuth または既存のベアラー トークン WordPress エンドポイントの構成、コンパニオン DocsPress テーマとブロック プラグインの準備、予行演習の検証、ドキュメントをドラフトから公開ページに安全に移動する必要がある場合に使用します。
