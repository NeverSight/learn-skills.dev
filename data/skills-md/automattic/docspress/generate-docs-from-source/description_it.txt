Genera documentazione Markdown accurata compatibile con DocsPress da un repository di codice sorgente esistente, comprese le versioni API mantenute quando richiesto. Da utilizzare quando un progetto presenta documentazione incompleta, obsoleta o assente e un agente deve ricavare installazione, configurazione, guide, riferimenti API o CLI, architettura, risoluzione dei problemi, blocchi DocsPress Gutenberg e un flusso di lavoro di pubblicazione sicuro da codice e test.
