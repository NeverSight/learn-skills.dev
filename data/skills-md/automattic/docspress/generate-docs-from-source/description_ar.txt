قم بإنشاء وثائق Markdown دقيقة ومتوافقة مع DocsPress من مستودع التعليمات البرمجية المصدر الحالي، بما في ذلك إصدارات واجهة برمجة التطبيقات (API) التي تم الحفاظ عليها عند الحاجة. يُستخدم عندما يكون المشروع غير مكتمل أو قديم أو لا يحتوي على وثائق ويجب على الوكيل استخلاص التثبيت والتكوين والأدلة ومراجع API أو CLI والهندسة المعمارية واستكشاف الأخطاء وإصلاحها وكتل DocsPress Gutenberg وسير عمل النشر الآمن من التعليمات البرمجية والاختبارات.
