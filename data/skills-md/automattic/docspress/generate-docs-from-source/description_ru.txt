Создавайте точную документацию Markdown, совместимую с DocsPress, из существующего репозитория исходного кода, включая поддерживаемые версии API, когда это необходимо. Используйте, когда проект имеет неполную, устаревшую документацию или не имеет ее вообще, и агент должен получить установку, конфигурацию, руководства, ссылки на API или CLI, архитектуру, устранение неполадок, блоки DocsPress Gutenberg и безопасный рабочий процесс публикации из кода и тестов.
