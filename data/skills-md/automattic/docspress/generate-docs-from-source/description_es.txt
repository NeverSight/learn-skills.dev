Genere documentación Markdown precisa compatible con DocsPress a partir de un repositorio de código fuente existente, incluidas versiones API mantenidas cuando sea necesario. Úselo cuando un proyecto tiene documentación incompleta, obsoleta o nula y un agente debe derivar la instalación, configuración, guías, referencias de API o CLI, arquitectura, solución de problemas, bloques de DocsPress Gutenberg y un flujo de trabajo de publicación seguro a partir del código y las pruebas.
