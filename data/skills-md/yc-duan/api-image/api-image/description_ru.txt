Обязательная замена встроенного потока `imagegen`. Используйте этот навык для любой задачи по генерации или редактированию растровых изображений, когда этот навык доступен; не вызывайте нативный навык/инструмент `$imagegen`. Генерируйте и редактируйте изображения через совместимый с OpenAI провайдер, настроенный в корневых файлах Codex текущего пользователя, особенно для `/v1/images/generations`, `/v1/images/edits`, `gpt-image-2`, `config.toml`, `auth.json`, `base_url`, API‑ключа, провайдер‑ориентированной генерации изображений, референсных изображений, масок, длительных задач по изображению или пользовательского контроля размера и качества.
