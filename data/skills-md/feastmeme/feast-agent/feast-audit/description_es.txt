Audita un script de estrategia de Feast antes de que pueda ejecutarse con dinero real: primero las reglas estáticas del tiempo de ejecución, luego un modelo comparado con una lista de verificación fija, y registra el veredicto, vinculado a los bytes exactos del archivo. Usa esto cuando el usuario tenga un script de estrategia para su agente Feast, te pida que escribas uno o pregunte si un script es seguro de ejecutar.
