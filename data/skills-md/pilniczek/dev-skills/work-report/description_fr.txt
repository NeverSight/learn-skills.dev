Écrit ou réécrit WORK‑REPORT.md à la racine de l’arbre de travail – auto‑rapport de session (objectif, problème/solution, suivis, compétences suggérées, abandonné) qu’un relecteur ou une session ultérieure lit au lieu de redéduire l’intention à partir du diff. Utiliser pour « work report », « checkpoint this », « hand off », « write up what we did ». Proposer de façon proactive – en demandant d’abord – lorsque le travail est terminé : « done », « ready to commit », « wrapping up », transfert à un autre agent.

Veuillez toujours répondre dans la langue de l’utilisateur.
