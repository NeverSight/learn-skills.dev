Transformez les problèmes d’une personne en une carte de travail Stellar exploitable, avec un arbre basé sur les objectifs, un graphe de relations et un inspecteur d’état. Utilisez‑la pour cartographier le travail sur Linear, GitHub Issues ou les instantanés fournis, réviser le regroupement d’un utilisateur ou actualiser une carte précédente tout en préservant les choix enregistrés. Produisez un fichier HTML autonome local avec le visualiseur intégré.
