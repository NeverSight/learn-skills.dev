Trasforma le issue di una persona in una mappa di lavoro Stellar esplorabile con un albero basato sullo scopo, un grafo di relazioni e un ispettore di stato. Usala per mappare il lavoro su Linear, GitHub Issues o snapshot forniti, rivedere il raggruppamento di un utente o aggiornare una mappa precedente mantenendo le scelte salvate. Genera HTML locale autonomo con il visualizzatore integrato.
