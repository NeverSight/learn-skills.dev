Crea o aggiorna Componenti Dinamici Avonni. Usalo quando l'utente chiede di costruire, generare o modificare un componente dinamico, o quando lavori con JSON di Componenti Dinamici, query, risorse o file di metadati. NON usarlo quando la richiesta riguarda più tipi di artefatti Avonni o descrive un caso d'uso end‑to‑end (un componente più il flusso che avvia, una pagina portal, ecc.) — utilizza invece la skill avonni‑architect.

Rispondi sempre nella lingua dell'utente.
