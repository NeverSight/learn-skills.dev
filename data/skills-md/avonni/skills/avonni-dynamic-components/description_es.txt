Crear o actualizar componentes dinámicos de Avonni. Se utiliza cuando el usuario solicita crear, generar o modificar un componente dinámico, o cuando trabaja con JSON de componentes dinámicos, consultas, recursos o archivos de metadatos. NO LO use cuando la solicitud abarque varios tipos de artefactos de Avonni o describa un caso de uso de extremo a extremo (un componente más el flujo que inicia, una página de portal, etc.); use la habilidad avonni-architect en su lugar.
