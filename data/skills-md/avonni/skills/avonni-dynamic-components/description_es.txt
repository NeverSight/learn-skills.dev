Crea o actualiza componentes dinámicos de Avonni. Úsalo cuando el usuario solicite construir, generar o modificar un componente dinámico, o cuando trabaje con JSON de componentes dinámicos, consultas, recursos o archivos de metadatos. NO lo uses cuando la solicitud abarque varios tipos de artefactos de Avonni o describa un caso de uso de extremo a extremo (un componente más el flujo que lanza, una página de portal, etc.) — utiliza la habilidad avonni‑architect en su lugar.

Por favor, responde siempre en el idioma del usuario.
