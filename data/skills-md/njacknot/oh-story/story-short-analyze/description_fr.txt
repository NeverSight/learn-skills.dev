Analyse du texte web de nouvelles. Déconstruire le noyau, la structure, l’arc émotionnel, les rebondissements, les techniques d’écriture et les niveaux de résonance des genres de nouvelles populaires (Tomato Short Stories / Story Collections / Zhihu Selected / Pursuing the Wife / World Affairs / Rebirth / Cruel Revenge, etc.).  
Pipeline de désassemblage complet unique : après avoir terminé les Étapes 2‑6, produire un rapport d’analyse complet et l’enregistrer dans `analysis_library/{book_title}/`.  
En aval, `story-short-write` lit le rapport d’analyse, les points de l’intrigue, les techniques d’écriture, le texte original et le _meta.json pour rédiger la prochaine pièce.  
Commandes de déclenchement : /story-short-analyze, /短篇拆文, “拆短篇”, “拆这篇短文”, “短篇拆文”, “精细拆解短篇”, “8000 字短篇拆解”, “番茄短篇拆文”, “故事会拆解”, “盐言故事拆解”, “分析这篇短篇” — toutes alimentent le même pipeline.

Veuillez toujours répondre dans la langue de l’utilisateur.
