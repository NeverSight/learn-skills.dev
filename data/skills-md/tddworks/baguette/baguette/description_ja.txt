`baguette` CLI を使って iOS シミュレータをプログラムから操作できます — タップ、スワイプ、マルチフィンガージェスチャ、ハードウェアボタン（Home / Lock / Volume / Action / Power）、ASCII キーボードテキスト、フレームキャプチャが可能で、Xcode を開く必要はありません。  

使用例:  
1. エージェントがスクリプトから起動中の iOS シミュレータを操作する必要がある場合 — 座標をタップ、スワイプ、テキスト入力。  
2. シミュレータ上でスモークテスト、デモ、エンドツーエンド UI フローを構築する場合。  
3. iOS 開発者と Claude Code を組み合わせてコード変更後の画面状態を検証する場合。  
4. ユーザーが「iPhone のジェスチャを自動化したい」「iOS シミュレータをプログラム的に制御したい」「Xcode を使わずにシミュレータを操作したい」と求めている場合。  
5. ユーザーが `baguette`、`baguette input`、`baguette tap`、`baguette serve`、`baguette stream` と言及している場合。  
6. SwiftUI の検証で、静的コードのチェックだけでなく実行中のアプリに触れる必要がある場合。  

単に「iOS シミュレータを開く」や「Xcode をインストールする」だけの質問には適用しません — それらは Xcode 自体に関する質問であり、シミュレータ操作とは無関係です。
