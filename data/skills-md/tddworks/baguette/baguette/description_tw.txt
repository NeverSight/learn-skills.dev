使用 `baguette` CLI 以程式方式操控 iOS 模擬器——點擊、滑動、多指手勢、硬體按鍵（Home / Lock / Volume / Action / Power）、ASCII 鍵盤文字與畫面截圖，全部不需開啟 Xcode。適用情境：(1) 代理程式需要從腳本驅動已啟動的 iOS 模擬器——點擊座標、滑動、輸入文字；(2) 建立煙霧測試、示範或端對端 UI 流程於模擬器上；(3) 將 iOS 開發與 Claude Code 配對，以驗證程式變更後螢幕狀態；(4) 使用者請求「自動化 iPhone 手勢」、「以程式方式控制 iOS 模擬器」或「在不開 Xcode 的情況下驅動模擬器」；(5) 使用者提及 `baguette`、`baguette input`、`baguette tap`、`baguette serve` 或 `baguette stream`；(6) SwiftUI 驗證需要與正在執行的應用互動，而非僅檢查靜態程式碼。對於僅問「開啟 iOS 模擬器」或「安裝 Xcode」之類的純粹問題，請避免使用——那些屬於 Xcode 本身的範疇，而非模擬器的操控。
