Guida i simulatori iOS in modo programmato tramite la CLI `baguette` — tap, swipe, gesti multi‑dito, pulsanti hardware (Home / Lock / Volume / Action / Power), testo da tastiera ASCII e acquisizione di frame, tutto senza aprire Xcode.  
Usa quando: (1) un agente deve controllare un simulatore iOS avviato da uno script — toccare una coordinata, strisciare, digitare testo; (2) costruire un test rapido, demo o flusso UI end‑to‑end su un simulatore; (3) accoppiare lo sviluppatore iOS con Claude Code per verificare lo stato a schermo dopo una modifica al codice; (4) l’utente richiede di “automatizzare i gesti iPhone”, “controllare il simulatore iOS programmaticamente” o “guidare il simulatore senza Xcode”; (5) l’utente menziona `baguette`, `baguette input`, `baguette tap`, `baguette serve` o `baguette stream`; (6) una verifica SwiftUI richiede di interagire con l’app in esecuzione, non solo ispezionare il codice statico.  
Evita per domande semplici come “apri il simulatore iOS” / “installa Xcode” — quelle riguardano Xcode stesso, non il controllo di un simulatore.
