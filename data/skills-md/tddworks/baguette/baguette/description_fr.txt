Piloter les simulateurs iOS par programme via l’interface en ligne de commande `baguette` — taps, glissements, gestes multi‑doigts, boutons matériels (Accueil / Verrouillage / Volume / Action / Alimentation), texte clavier ASCII et capture d’image, le tout sans ouvrir Xcode.  
Utiliser quand : (1) un agent doit piloter un simulateur iOS démarré depuis un script — taper une coordonnée, glisser, saisir du texte ; (2) créer un test de type smoke, une démo ou un flux UI de bout en bout sur un simulateur ; (3) associer un développeur iOS à Claude Code pour vérifier l’état à l’écran après une modification de code ; (4) l’utilisateur demande « automatiser les gestes iPhone », « contrôler le simulateur iOS par programme » ou « piloter le simulateur sans Xcode » ; (5) l’utilisateur mentionne `baguette`, `baguette input`, `baguette tap`, `baguette serve` ou `baguette stream` ; (6) une vérification SwiftUI nécessite d’interagir avec l’application en cours d’exécution, et non simplement d’inspecter du code statique.  
À éviter pour les questions simples « ouvrir le simulateur iOS » / « installer Xcode » — celles‑ci concernent Xcode lui‑même, pas la conduite d’un simulateur.
