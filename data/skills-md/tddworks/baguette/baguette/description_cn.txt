通过 `baguette` CLI 编程驱动 iOS 模拟器——点击、滑动、多指手势、硬件按钮（Home / Lock / Volume / Action / Power）、ASCII 键盘文本以及帧捕获，全部无需打开 Xcode。适用场景：(1) 需要从脚本驱动已启动的 iOS 模拟器的代理——点击坐标、滑动、输入文本；(2) 在模拟器上构建冒烟测试、演示或端到端 UI 流程；(3) 将 iOS 开发与 Claude Code 配对，以在代码更改后验证屏幕状态；(4) 用户请求 “自动化 iPhone 手势”、 “以编程方式控制 iOS 模拟器” 或 “在不打开 Xcode 的情况下驱动模拟器”；(5) 用户提到 `baguette`、`baguette input`、`baguette tap`、`baguette serve` 或 `baguette stream`；(6) SwiftUI 验证需要触及运行中的应用，而不仅仅是检查静态代码。避免用于单纯的 “打开 iOS Simulator” / “安装 Xcode” 问题——这些属于 Xcode 本身，而不是驱动模拟器。
