`baguette` CLI를 통해 iOS 시뮬레이터를 프로그래밍 방식으로 제어 — 탭, 스와이프, 멀티‑핑거 제스처, 하드웨어 버튼(홈 / 잠금 / 볼륨 / 액션 / 전원), ASCII 키보드 텍스트, 프레임 캡처 등을 Xcode를 열지 않고 수행합니다.  
사용 사례: (1) 스크립트에서 부팅된 iOS 시뮬레이터를 제어해야 하는 에이전트 — 좌표 탭, 스와이프, 텍스트 입력; (2) 시뮬레이터에서 스모크 테스트, 데모, 엔드‑투‑엔드 UI 흐름 구축; (3) iOS 개발자를 Claude Code와 연결해 코드 변경 후 화면 상태 검증; (4) 사용자가 “iPhone 제스처 자동화”, “iOS 시뮬레이터를 프로그래밍적으로 제어”, “Xcode 없이 시뮬레이터 구동”을 요청할 때; (5) 사용자가 `baguette`, `baguette input`, `baguette tap`, `baguette serve`, `baguette stream` 등으로 언급할 때; (6) SwiftUI 검증이 정적 코드 검토가 아니라 실행 중인 앱을 직접 터치해야 할 때.  
단순히 “iOS 시뮬레이터 열기” 혹은 “Xcode 설치”와 같은 질문에는 사용하지 마세요 — 이는 Xcode 자체에 관한 것이며 시뮬레이터 제어와는 무관합니다.
