Controla simuladores iOS programáticamente a través del CLI `baguette` — toques, deslizamientos, gestos multí‑dedo, botones de hardware (Home / Bloqueo / Volumen / Acción / Encendido), texto de teclado ASCII y captura de fotogramas, todo sin abrir Xcode.  
Úsalo cuando: (1) un agente necesita manipular un simulador iOS arrancado desde un script — tocar una coordenada, deslizar, escribir texto; (2) crear una prueba rápida, demo o flujo UI de extremo a extremo en un simulador; (3) emparejar a un desarrollador iOS con Claude Code para verificar el estado en pantalla después de un cambio de código; (4) el usuario pide “automatizar gestos de iPhone”, “controlar simulador iOS programáticamente” o “manejar simulador sin Xcode”; (5) el usuario menciona `baguette`, `baguette input`, `baguette tap`, `baguette serve` o `baguette stream`; (6) una verificación SwiftUI necesita interactuar con la app en ejecución, no solo inspeccionar código estático.  
Evita usarlo para preguntas simples de “abrir el simulador iOS” / “instalar Xcode”, ya que esas tratan sobre Xcode mismo, no sobre manejar un simulador.
