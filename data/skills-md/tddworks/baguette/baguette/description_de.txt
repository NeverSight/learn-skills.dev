Steuere iOS‑Simulatoren programmgesteuert über die `baguette`‑CLI — Taps, Swipes, Multi‑Finger‑Gesten, Hardware‑Buttons (Home / Lock / Volume / Action / Power), ASCII‑Tastaturtext und Frame‑Capture, alles ohne Xcode zu öffnen.  
Verwenden, wenn: (1) ein Agent einen gestarteten iOS‑Simulator aus einem Skript steuern muss — Koordinate antippen, wischen, Text eingeben; (2) ein Smoke‑Test, Demo oder End‑to‑End‑UI‑Flow auf einem Simulator gebaut wird; (3) iOS‑Entwicklung mit Claude Code gepaart wird, um nach einer Code‑Änderung den Bildschirminhalt zu verifizieren; (4) der Nutzer nach „iPhone‑Gesten automatisieren“, „iOS‑Sim programmatisch steuern“ oder „Simulator ohne Xcode steuern“ fragt; (5) der Nutzer `baguette`, `baguette input`, `baguette tap`, `baguette serve` oder `baguette stream` nennt; (6) eine SwiftUI‑Verifikation die laufende App berühren muss, nicht nur statischen Code prüfen.  
Vermeiden bei reinen Fragen wie „iOS‑Simulator öffnen“ / „Xcode installieren“ — diese betreffen Xcode selbst, nicht das Steuern eines Simulators.
