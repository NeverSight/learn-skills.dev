Acquisisce lo schermo macOS dell'utente, una finestra o una regione con il CLI integrato `screencapture`, quindi legge l'immagine così l'agente può vedere quello che vede l'utente. Usalo quando l'utente chiede di controllare l'aspetto di un'app macOS nativa (SwiftUI, AppKit, Electron, Qt, Tk, Java Swing), verificare che una finestra sia stata renderizzata correttamente dopo una build o una modifica al codice, diagnosticare un bug visivo descritto in un'app desktop, confermare lo stato di un menu, dialogo o layout, o chiede “puoi vedere questo?” riguardo a qualsiasi cosa al di fuori di un browser, anche se non dice “screenshot”. Le pagine web e le web app appartengono a uno strumento di automazione del browser.

Rispondi sempre nella lingua dell'utente.
