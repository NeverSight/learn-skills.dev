Capture l'écran macOS de l'utilisateur, une fenêtre ou une région à l'aide de l'outil en ligne de commande intégré `screencapture`, puis lit l'image afin que l'agent puisse voir ce que l'utilisateur voit. Utilisez-le lorsque l'utilisateur demande de vérifier l'apparence d'une application native macOS (SwiftUI, AppKit, Electron, Qt, Tk, Java Swing), de confirmer qu'une fenêtre s'est correctement rendue après une compilation ou une modification de code, de diagnostiquer un bug visuel qu'il décrit dans une application de bureau, de confirmer l'état d'un menu, d'une boîte de dialogue ou d'une mise en page, ou lorsqu'il demande « pouvez‑vous voir ça ? » concernant tout ce qui se trouve en dehors d'un navigateur, même s'il ne dit pas « capture d'écran ». Les pages Web et les applications Web relèvent d'un outil d'automatisation de navigateur.

Veuillez toujours répondre dans la langue de l'utilisateur.
