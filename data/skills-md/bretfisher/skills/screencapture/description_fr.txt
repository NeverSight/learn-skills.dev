Capture l'écran macOS de l'utilisateur, une fenêtre ou une région avec l'outil en ligne de commande intégré `screencapture`, puis lit l'image afin que l'agent puisse voir ce que voit l'utilisateur. Utilisez‑le lorsque l'utilisateur demande de vérifier l'apparence d'une application native macOS (SwiftUI, AppKit, Electron, Qt, Tk, Java Swing), de confirmer qu'une fenêtre a été rendue correctement après une compilation ou une modification du code, de diagnostiquer un bug visuel décrit dans une application de bureau, de confirmer l'état d'un menu, d'une boîte de dialogue ou d'une mise en page, ou lorsqu'il demande « peux‑tu voir ça ? » concernant quoi que ce soit hors du navigateur, même s'il ne dit pas « capture d’écran ». Les pages web et les applications web relèvent d'un outil d'automatisation de navigateur.

Veuillez toujours répondre dans la langue de l'utilisateur.
