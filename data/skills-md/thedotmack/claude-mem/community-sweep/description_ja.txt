thedotmack/claude-mem のコントリビューターとしてコミュニティのプルリクエストをマージし、コミュニティの課題に回答します。オープン中のすべての PR（オーナー自身のものも含むが、オーナーが実験的とマークしたものは除く）とコミュニティ課題を把握し、オーナーのマージ方針と cmem.ai のホストサービス境界に照らし合わせて優先順位を付けます。ある程度方針に合致した PR はコントリビューター自身のブランチで仕上げ、スクワッシュマージによりメインブランチ上でもコミット作者がコントリビューターのままになるようにします。名前を挙げて感謝し、解決した課題は報告者と修正者へクレジットを付けてクローズします。プライベート台帳とコントリビューターロスターを最新に保ち、判断内容を報告します。以下のように依頼されたときに使用してください。「PR を確認する」「コントリビューターの PR をマージする」「コントリビューターの PR を手伝う」「新しいコミュニティ PR をマージする」「新しい課題と PR をトリアージする」「コミュニティの一括処理を実行する」「勢いを保つ」「コミュニティを成長させる」。
