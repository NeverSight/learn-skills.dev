Führen Sie das CI-Gate auf Ihrem Computer aus, damit es mit dem Runner übereinstimmt – leiten Sie den genauen Befehl, die Pfade, Markierungen und die Umgebung aus der Workflow-Datei statt aus dem Makefile ab, entsperren Sie Gate-Schritte, die kurzschließen und den nächsten Fehler verbergen, fixieren Sie die von CI aufgelöste Linter-Version, erstellen Sie die Interpreter-/Toolchain-Umgebung, die der Runner erstellt, und bestätigen Sie, dass der Lauf grün ist, anstatt einen roten Job zu erklären. Verwenden Sie diese Option, wenn eine Prüfung lokal erfolgreich ist, aber in CI fehlschlägt (oder umgekehrt), wenn ein Lint-/Formatierungsauftrag für eine unberührte Datei rot wird, wenn Sie eine lokale Entwicklungsschleife für ein unbekanntes Repo einrichten oder bevor Sie einen Zweig verschieben, den Sie zusammenführen möchten.
