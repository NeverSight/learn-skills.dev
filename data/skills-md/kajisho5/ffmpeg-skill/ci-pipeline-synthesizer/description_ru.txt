Создавайте конфигурации конвейера CI/CD GitHub Actions для автоматического создания и тестирования проектов библиотек и пакетов. Используйте при создании или обновлении рабочих процессов CI для пакетов npm, пакетов Python, модулей Go, контейнеров Rust или других библиотечных проектов, которым требуются автоматизированные конвейеры сборки и тестирования. Включает шаблоны для распространенных экосистем пакетов с лучшими практиками кэширования зависимостей, матричного тестирования и публикации артефактов.
