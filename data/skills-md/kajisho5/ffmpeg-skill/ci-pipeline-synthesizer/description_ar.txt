قم بإنشاء تكوينات خطوط أنابيب GitHub Actions CI/CD لبناء واختبار مشروعات المكتبة والحزم بشكل آلي. يُستخدم عند إنشاء أو تحديث مسارات عمل CI لحزم npm أو حزم Python أو وحدات Go أو صناديق Rust أو مشاريع المكتبات الأخرى التي تحتاج إلى مسارات إنشاء واختبار تلقائية. يتضمن قوالب للأنظمة البيئية للحزمة المشتركة مع أفضل الممارسات للتخزين المؤقت للتبعية واختبار المصفوفة ونشر العناصر.
