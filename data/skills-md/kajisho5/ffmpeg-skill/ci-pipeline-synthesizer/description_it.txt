Genera configurazioni della pipeline CI/CD di GitHub Actions per la creazione e il test automatizzati di progetti di librerie e pacchetti. Da utilizzare durante la creazione o l'aggiornamento di flussi di lavoro CI per pacchetti npm, pacchetti Python, moduli Go, contenitori Rust o altri progetti di libreria che necessitano di pipeline di compilazione e test automatizzate. Include modelli per ecosistemi di pacchetti comuni con best practice per la memorizzazione nella cache delle dipendenze, il test delle matrici e la pubblicazione degli artefatti.
