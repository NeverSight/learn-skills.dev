Genere configuraciones de canalización de CI/CD de GitHub Actions para la creación y prueba automatizadas de proyectos de bibliotecas y paquetes. Úselo al crear o actualizar flujos de trabajo de CI para paquetes npm, paquetes Python, módulos Go, cajas Rust u otros proyectos de biblioteca que necesitan procesos de compilación y prueba automatizados. Incluye plantillas para ecosistemas de paquetes comunes con mejores prácticas para el almacenamiento en caché de dependencias, pruebas matriciales y publicación de artefactos.
