استخدمه عندما يعمل وكيل الترميز في مستودع يتوفر فيه Jujutsu (jj) (دليل `.jj/`) — تشغيل أوامر jj، إجراء تعديلات تجريبية، تقسيم التغييرات، الاستعادة باستخدام سجل العمليات (jj undo / jj op restore)، نقل طلب سحب (PR) إلى Git/GitHub/GitLab، تحديث طلب السحب بعد المراجعة، أو تنسيق الوكلاء المتوازيين. يستخدم jj كطبقة إدارة تغييرات محلية مع إبقاء Git كواجهة عن بُعد معيارية، وطلبات سحب، وCI، وواجهة تدقيق. كما يُستعمل لتجنّب مشاكل وكيل jj (تعليق العارض/المحرر، امتصاص الالتزام، عدم تزامن git/jj المتجاور) أو لاستبدال استعادة git الهشة (reset/checkout/stash/rebase) بعمليات jj القابلة للعكس.
