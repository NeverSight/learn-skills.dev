Jujutsu（jj）が利用可能なリポジトリ（`.jj/` ディレクトリがある）でコーディングエージェントが作業する際に使用します — jj コマンドの実行、仮の編集、変更の分割、操作ログによるリカバリ（jj undo / jj op restore）、Git/GitHub/GitLab へのプルリクエストの引き継ぎ、レビュー後のプルリクエストの更新、または並行エージェントの調整などです。Git を正規のリモート、PR、CI、監査インターフェースとして保持しつつ、ローカルの変更管理層として jj を使用します。また、jj のエージェント特有の落とし穴（ページャ／エディタのハング、コミットの吸収、git と jj の同期ずれ）を回避したり、脆弱な git reset／checkout／stash／rebase のリカバリを可逆的な jj 操作に置き換えるためにも使用します。
