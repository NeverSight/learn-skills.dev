Jujutsu(jj)가 사용 가능한(`.jj/` 디렉터리) 저장소에서 코딩 에이전트가 작업할 때 사용합니다 — jj 명령 실행, 추측 편집 수행, 변경 사항 분할, 작업 로그로 복구(jj undo / jj op restore), PR을 Git/GitHub/GitLab에 넘기기, 리뷰 후 PR 업데이트, 혹은 병렬 에이전트 조정 등. Git을 정규 원격, PR, CI, 감사 인터페이스로 유지하면서 로컬 변경 관리 계층으로 jj를 사용합니다. 또한 jj의 에이전트 함정(페이지/편집기 멈춤, 커밋 흡수, git/jj 동기화 불일치)을 피하거나, 취약한 git reset/checkout/stash/rebase 복구를 되돌릴 수 있는 jj 작업으로 대체하기 위해 사용합니다.
