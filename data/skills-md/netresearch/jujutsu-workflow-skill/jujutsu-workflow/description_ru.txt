Используйте, когда кодирующий агент работает в репозитории, где доступен Jujutsu (jj) (каталог `.jj/`) — выполнение команд jj, внесение спекулятивных правок, разбиение изменений, восстановление с помощью журнала операций (jj undo / jj op restore), передача PR в Git/GitHub/GitLab, обновление PR после ревью или координация параллельных агентов. Использует jj как локальный слой управления изменениями, при этом Git остаётся каноничным удалённым репозиторием, интерфейсом для PR, CI и аудита. Также применяется, чтобы избежать подводных камней агента jj (зависание пейджера/редактора, поглощение коммитов, рассинхронизация совместно расположенных git/jj) или заменять хрупкое восстановление git reset/checkout/stash/rebase на обратимые операции jj.
