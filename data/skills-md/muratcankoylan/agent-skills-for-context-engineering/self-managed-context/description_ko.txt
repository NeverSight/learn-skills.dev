이 기술은 모델이 하네스가 스케줄링하는 압축 정책 대신 자체 실시간 컨텍스트 창에 대한 읽기‑쓰기 제어를 얻을 때 사용해야 합니다: 코드 도구로 모델이 재작성하는 편집 가능한 파일로 노출되는 컨텍스트, 모델 주도형 폐기 및 제자리 업데이트, 자체 편집을 안전하게 유지하는 하네스 불변 조건(고정된 접두사, 편집 게이트, 편집 영수증, 예산 조회, 오버플로우 시 롤백), 중간 컨텍스트 편집의 접두사‑캐시 비용, 그리고 모델 자체의 컨텍스트 편집 전략을 조정하거나 훈련하는 것. 노트 내용과 고정 임계값 요약은 컨텍스트‑압축으로, 하네스 제어 하의 캐시‑안정 레이아웃은 컨텍스트‑최적화로, 파일 오프로드는 파일시스템‑컨텍스트로, 루프 거버넌스는 자기‑향상‑루프로 라우팅합니다.
