Этот навык следует использовать, когда цель оптимизации — сама обвязка, каркас, рабочий процесс или оптимизатор: рекурсивные петли самосовершенствования (RSI), мета‑обвязки, самосовершенствующиеся обвязки, которые извлекают собственные ошибки и предлагают ограниченные правки, эволюционный или популяционный поиск по агентским каркасам, шлюзы приёма для самомодифицирующихся систем и эволюция агентского контекста, где механизм создания контекста версионируется и развивается. Управление маршрутом единственной автономной петли (запертые поверхности, долговременные журналы, откат, шлюзы новизны, границы одобрения) направлять к инженерии обвязок, измерениям и проектированию качественных шлюзов для оценки, проектированию судей для продвинутой оценки, а также к удалённой песочнице инфраструктуры для размещённых агентов.
