Utilisez le CLI public `orca` pour manipuler les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, les commentaires de worktree et le navigateur intégré dans l’application Orca. Utilisez‑le lorsque l’utilisateur dit « $orca-cli », « use orca cli », « Orca worktree », « child worktree », « cardStatus », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « terminal send », « full handoff », « handover », « give this to another agent », « another worktree », « Orca browser » ou « control the browser inside Orca ». Préférez cela aux commandes brutes `git worktree`, PTY ad hoc, Playwright ou Computer Use lorsque la tâche touche un état géré par Orca. Utilisez Computer Use pour les fenêtres de navigateur, les webviews ou l’interface utilisateur du bureau en dehors du navigateur intégré d’Orca.

Veuillez toujours répondre dans la langue de l’utilisateur.
