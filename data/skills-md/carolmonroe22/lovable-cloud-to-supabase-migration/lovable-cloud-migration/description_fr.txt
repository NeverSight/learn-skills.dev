Guide pour migrer de Lovable Cloud vers votre propre projet Supabase. À utiliser lorsque les utilisateurs demandent comment exporter des données depuis Lovable Cloud, supprimer ou déconnecter Lovable Cloud, suspendre Lovable Cloud, restaurer une exportation de sauvegarde Lovable Cloud, migrer vers leur propre Supabase, extraire des données de la base de données Lovable gérée, passer de Lovable Cloud à une Supabase externe, connecter leur propre Supabase à un projet Lovable ou limiter Lovable Cloud (pas d'accès à l'éditeur SQL, pas d'e-mails d'authentification personnalisés, pas d'accès direct au tableau de bord Supabase, pas de clé de rôle de service).
