Leitfaden für die Migration von Lovable Cloud zu Ihrem eigenen Supabase-Projekt. Wird verwendet, wenn Benutzer Fragen zum Exportieren von Daten aus Lovable Cloud, zum Entfernen oder Trennen von Lovable Cloud, zum Anhalten von Lovable Cloud, zum Wiederherstellen eines Lovable Cloud-Backup-Exports, zur Migration zu ihrer eigenen Supabase, zum Abrufen von Daten aus der verwalteten Lovable-Datenbank, zum Wechsel von Lovable Cloud zu externer Supabase, zum Verbinden ihrer eigenen Supabase mit einem Lovable-Projekt oder zu Lovable Cloud-Einschränkungen (kein SQL-Editor-Zugriff, keine benutzerdefinierten Authentifizierungs-E-Mails, kein direktes Supabase-Dashboard) stellen Zugriff, kein Servicerollenschlüssel).
