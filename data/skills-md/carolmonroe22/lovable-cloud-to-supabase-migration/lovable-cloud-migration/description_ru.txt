Руководство по переходу из Lovable Cloud в ваш собственный проект Supabase. Используйте, когда пользователи спрашивают об экспорте данных из Lovable Cloud, удалении или отключении Lovable Cloud, приостановке Lovable Cloud, восстановлении экспорта резервной копии Lovable Cloud, переходе на собственную Supabase, получении данных из управляемой базы данных Lovable, переключении с Lovable Cloud на внешнюю Supabase, подключении собственной Supabase к проекту Lovable или ограничениях Lovable Cloud (нет доступа к редактору SQL, нет настраиваемых электронных писем для аутентификации, нет прямого доступа к панели управления Supabase, нет ключ роли службы).
