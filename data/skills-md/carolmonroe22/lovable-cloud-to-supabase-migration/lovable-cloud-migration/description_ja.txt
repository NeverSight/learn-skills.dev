Lovable Cloud から独自の Supabase プロジェクトに移行するためのガイド。 Lovable Cloud からのデータのエクスポート、Lovable Cloud の削除または切断、Lovable Cloud の一時停止、Lovable Cloud .backup エクスポートの復元、独自の Supabase への移行、管理されている Lovable データベースからのデータの取得、Lovable Cloud から外部 Supabase への切り替え、独自の Supabase の Lovable プロジェクトへの接続、または Lovable Cloud の制限 (SQL エディターへのアクセスなし、カスタム認証メールなし、Supabase ダッシュボードへの直接アクセスなし、サービス ロール キーなし) についてユーザーが質問するときに使用します。
