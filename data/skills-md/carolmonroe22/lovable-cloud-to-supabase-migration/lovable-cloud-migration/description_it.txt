Guida per migrare da Lovable Cloud al tuo progetto Supabase. Da utilizzare quando gli utenti chiedono informazioni sull'esportazione di dati da Lovable Cloud, rimozione o disconnessione di Lovable Cloud, sospensione di Lovable Cloud, ripristino di un'esportazione .backup di Lovable Cloud, migrazione al proprio Supabase, estrazione di dati dal database Lovable gestito, passaggio da Lovable Cloud a Supabase esterno, connessione del proprio Supabase a un progetto Lovable o limitazioni di Lovable Cloud (nessun accesso all'editor SQL, nessuna email di autenticazione personalizzata, nessun accesso diretto alla dashboard di Supabase, nessun servizio ruolo chiave).
