UI アニメーションやマイクロインタラクションを磨き上げるための詳細なルール。正確な期間、イージング、スケール、変形原点、そしてコピー可能な CSS / Motion（Framer Motion）コードを提供します。依存関係のない監査ツール、モーショントークン、プリセット、リファレンス、インタラクティブなビフォー／アフター例を同梱。ユーザーが UI モーション（CSS トランジション、Framer Motion / Motion、React、SwiftUI、ドロップダウン、ポップオーバー、モーダル、ボタン、トグル、タブ、リスト、ドラッグインタラクション）の作成・レビュー・修正を行う時、またはアニメーションが不自然、ぎこちない、遅い、浮いたよう、安っぽい、ロボット的、あるいは「滑らかでない」と感じたとき（たとえ「アニメーションガイドライン」と言及されなくても）に使用してください。
