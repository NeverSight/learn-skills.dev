Reglas detalladas para lograr que las animaciones de UI y micro‑interacciones se perciban pulidas, con duraciones exactas, curvas de aceleración, escalas, orígenes de transformación y código CSS / Motion (Framer Motion) listo para copiar. Incluye un auditor sin dependencias, tokens de movimiento, preajustes, referencias y ejemplos interactivos antes/después. Utilízalo siempre que el usuario esté redactando, revisando o corrigiendo animaciones de UI (transiciones CSS, Framer Motion / Motion, React, SwiftUI, menús desplegables, popovers, modales, botones, conmutadores, pestañas, listas, interacciones de arrastre), o indique que una animación se siente desajustada, entrecortada, lenta, flotante, barata, robótica o “no suave”, aunque nunca mencione “directrices de animación”.
