قواعد تفصيلية لجعل حركات واجهة المستخدم والتفاعلات الدقيقة تبدو مصقولة، مع مدّات دقيقة، وتيسيرات (easings)، ومقاييس، وأصول التحويل، وكود CSS / Motion (Framer Motion) جاهز للنسخ. يتضمن مدققًا بلا تبعية، رموز حركة، إعدادات مسبقة، مراجع، وأمثلة تفاعلية قبل/بعد. يُستخدم كلما كان المستخدم يكتب أو يراجع أو يصلح حركة واجهة المستخدم (تحولات CSS، Framer Motion / Motion، React، SwiftUI، القوائم المنسدلة، النوافذ المنبثقة، النماذج، الأزرار، المفاتيح، الألسنة، القوائم، تفاعلات السحب)، أو يقول إن الحركة تبدو غير صحيحة، متقطعة، بطيئة، عائمة، رخيصة، آلية أو "غير سلسة"، حتى لو لم يذكر أبدًا "إرشادات الحركة". يرجى دائمًا الرد بلغة المستخدم.
