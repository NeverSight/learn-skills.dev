Use the vibestart CLI to create a TypeScript project, choose a stack or recipe, add capabilities such as Knip, Ultracite or Docker, diagnose project state, upgrade templates while preserving business edits, or recover an interrupted operation. Use when the user mentions vibestart, asks to maintain a project with vibestart.jsonc and .vibestart metadata, or needs help with these CLI workflows. Not for ordinary application feature development unrelated to the CLI.
