Utilice la CLI de vibestart para crear un proyecto TypeScript, elegir una pila o receta, agregar capacidades como Knip, Ultracite o Docker, diagnosticar el estado del proyecto, actualizar plantillas mientras se conservan las ediciones comerciales o recuperar una operación interrumpida. Se utiliza cuando el usuario menciona vibestart, solicita mantener un proyecto con metadatos vibestart.jsonc y .vibestart, o necesita ayuda con estos flujos de trabajo de CLI. No para el desarrollo de características de aplicaciones ordinarias no relacionadas con la CLI.
