Генерирует тесты TestNG на Java с группами, провайдерами данных, параллельным выполнением, конфигурацией XML‑suite и слушателями. Использовать, когда пользователь упоминает «TestNG», «@DataProvider», «testng.xml», «groups». Срабатывает на: «TestNG», «@DataProvider», «testng.xml», «TestNG suite», «parallel tests Java». Пожалуйста, всегда отвечайте на языке пользователя.
