Construisez des applications avec l'API Claude ou le SDK Anthropic. DÉCLENCHER lorsque : le code importe `anthropic`/`@anthropic-ai/sdk`/`claude_agent_sdk`, ou que l'utilisateur demande à utiliser l'API Claude, les SDK Anthropic ou le SDK Agent. NE PAS DÉCLENCHER lorsque : le code importe `openai`/un autre SDK IA, programmation générale ou tâches de ML/science des données.

Veuillez toujours répondre dans la langue de l'utilisateur.
