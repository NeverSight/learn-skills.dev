Conecta un agente de codificación IA (Claude Code, Codex, Cursor, Copilot) a un Roblox Studio en ejecución mediante su servidor MCP incorporado y úsalo de forma segura: primero el plugin oficial de Roblox, una entrada manual en caso contrario, nunca dos; verifica la conexión con list_roblox_studios; ejecuta el bucle de prueba‑y‑verificación (start_stop_play, execute_luau, get_console_output); accede a las habilidades del Studio de Roblox a través de la herramienta de habilidades; elude los errores conocidos (desconexiones, el sandbox execute_luau, lecturas obsoletas antes de multi_edit). Usa esto siempre que el usuario pida “conectar Claude a Roblox Studio”, “configurar el Roblox MCP”, “dejar que el agente vea mi lugar”, “pruébalo para mí”, “por qué Claude no puede insertar scripts”, informe de que el MCP del Studio se desconecta o no lista el Studio, pregunte qué servidor Roblox MCP usar, o diga “refresh roblox‑agent‑studio”. El código en disco es roblox‑agent‑project; las verificaciones sin Studio son roblox‑agent‑checks.

Por favor, responde siempre en el idioma del usuario.
