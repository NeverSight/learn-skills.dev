Подключите AI‑агента по программированию (Claude Code, Codex, Cursor, Copilot) к работающему Roblox Studio через встроенный MCP‑сервер и используйте его безопасно: сначала используйте официальный плагин Roblox, в остальных случаях допускается лишь один ручной ввод, никогда два; подтвердите соединение с помощью list_roblox_studios; запустите цикл тест‑игры и проверки (start_stop_play, execute_luau, get_console_output); получайте доступ к навыкам Roblox Studio через инструмент skill; обойдите известные баги (разрывы соединения, песочница execute_luau, устаревшие чтения перед multi_edit). Применяйте, когда пользователь просит «подключить Claude к Roblox Studio», «настроить Roblox MCP», «позволить агенту видеть мой мир», «провести тест‑игру за меня», «почему Claude не может вставлять скрипты», сообщает об отключении MCP Studio или отсутствии списка Studio, спрашивает, какой сервер Roblox MCP использовать, или говорит «refresh roblox-agent-studio». Код на диске находится в roblox-agent-project; проверки без Studio находятся в roblox-agent-checks.

Пожалуйста, всегда отвечайте на языке пользователя.
