Connectez un agent de codage IA (Claude Code, Codex, Cursor, Copilot) à un Roblox Studio en cours d’exécution via son serveur MCP intégré et utilisez‑le en toute sécurité : commencez d’abord avec le plugin officiel de Roblox, une saisie manuelle sinon, jamais deux ; prouvez la connexion avec list_roblox_studios ; exécutez la boucle test‑et‑vérification (start_stop_play, execute_luau, get_console_output) ; accédez aux compétences du Studio Roblox via l’outil de compétences ; contournez les bugs connus (déconnexions, le bac à sable execute_luau, lectures obsolètes avant multi_edit). Utilisez‑le chaque fois que l’utilisateur demande « connect Claude to Roblox Studio », « set up the Roblox MCP », « let the agent see my place », « playtest it for me », « why can’t Claude insert scripts », signale le MCP du Studio qui se déconnecte ou n’affiche pas le Studio, demande quel serveur Roblox MCP utiliser, ou dit « refresh roblox-agent-studio ». Le code sur le disque est roblox‑agent‑project ; les vérifications sans Studio sont roblox‑agent‑checks.

Veuillez toujours répondre dans la langue de l’utilisateur.
