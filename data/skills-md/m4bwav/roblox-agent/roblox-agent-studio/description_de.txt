Verbinde einen KI‑Coding‑Agent (Claude Code, Codex, Cursor, Copilot) mit einem laufenden Roblox Studio über dessen eingebauten MCP‑Server und nutze ihn sicher: Zuerst das offizielle Roblox‑Plugin, sonst ein manueller Eintrag, nie zwei; beweise die Verbindung mit list_roblox_studios; führe die Playtest‑und‑Verifizierungs‑Schleife aus (start_stop_play, execute_luau, get_console_output); greife über das Skill‑Tool auf Roblox‑Studios Fähigkeiten zu; umgehe bekannte Bugs (Verbindungsabbrüche, die execute_luau‑Sandbox, veraltete Lesevorgänge vor multi_edit). Verwende dies immer, wenn der Nutzer fragt, „Claude mit Roblox Studio verbinden“, „das Roblox MCP einrichten“, „dem Agenten meinen Ort zeigen“, „spiele es für mich durch“, „warum kann Claude keine Skripte einfügen“, Meldungen über einen trennenden Studio‑MCP oder dass das Studio nicht gelistet wird, nach dem zu verwendenden Roblox‑MCP‑Server fragt oder sagt „refresh roblox‑agent‑studio“. Der Code auf der Festplatte heißt roblox‑agent‑project; Prüfungen ohne Studio heißen roblox‑agent‑checks.

Bitte immer in der Sprache des Benutzers antworten.
