قم بربط وكيل البرمجة الذكي (Claude Code، Codex، Cursor، Copilot) ببرنامج روبلوكس ستوديو قيد التشغيل عبر خادم MCP المدمج واستخدامه بأمان: ابدأ أولاً بالمكوّن الإضافي الرسمي من روبلوكس، ثم إدخال يدوي واحد إذا لزم الأمر، ولا تستخدم إدخالين أبداً؛ أثبت الاتصال باستخدام list_roblox_studios؛ شغّل حلقة الاختبار والتحقق (start_stop_play، execute_luau، get_console_output)؛ استخدم مهارات ستوديو روبلوكس عبر أداة المهارات؛ تجنّب الأخطاء المعروفة (انقطاعات، بيئة تنفيذ execute_luau، قراءات قديمة قبل multi_edit). استخدم ذلك كلما طلب المستخدم “ربط Claude بـ Roblox Studio”، “إعداد Roblox MCP”، “دع الوكيل يرى مشروعي”، “اختبره لي”، “لماذا لا يستطيع Claude إدراج السكربتات”، أو أبلغ عن انقطاع MCP للستوديو أو عدم ظهور الستوديو في القائمة، أو سأل عن أي خادم Roblox MCP يستخدم، أو قال “تحديث roblox-agent‑studio”. الكود على القرص هو roblox-agent-project؛ الفحوصات بدون ستوديو هي roblox-agent-checks.
