생성 후 또는 초안에서 준비로 전환한 후 에이전트가 생성한 끌어오기 요청을 유지합니다. 검토 가능한 초안 PR을 준비됨으로 표시하고, CI를 폴링하고 gh로 주석을 검토하고, 동일한 작업 트리/세션에서 오류를 복구하고, 일본어로 응답하고, 설계 루프를 에스컬레이션하고, 안전할 때 스쿼시 병합합니다. 이 기술은 유지 관리 정책(수리 대상, 병합/확장 시기)을 정의합니다. 사람이 다시 시작하지 않고 스스로 일정을 조정하는 자동 재폴링 LOOP는 pr-autoloop에 있습니다. PR을 생성한 후 또는 PR 유지 관리 자동화를 계속하도록 요청받은 경우에 사용합니다.
