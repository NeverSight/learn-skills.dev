作成後またはドラフトから準備完了への移行後に、エージェントが作成したプル リクエストを維持します。レビュー可能なドラフト PR を準備完了としてマークし、CI をポーリングして gh でコメントを確認し、同じワークツリー/セッション内の障害を修復し、日本語で返信し、デザイン ループをエスカレートし、安全な場合はマージをスカッシュします。このスキルは、メンテナンス ポリシー (何を修復するか、いつマージ/エスカレーションするか) を定義します。人間による再起動なしで自動的に再スケジュールされる自律的な再ポーリング LOOP は、pr-autoloop 内に存在します。 PR の作成後、または PR メンテナンスの自動化を継続するように求められた場合に使用します。
