Effettua il refactoring delle importazioni a livello di modulo di dipendenze native pesanti (torch, tensorflow, jax) in importazioni pigre interne alla funzione. Da utilizzare quando l'importazione di una libreria attiva SIGSEGV o un avvio lento in ambienti in cui la versione nativa non può essere inizializzata completamente (ad esempio, driver CUDA assente, segfault dell'estensione C triton, GPU mancante). Prevede gli effetti collaterali del test dagli attributi del modulo rimossi.
