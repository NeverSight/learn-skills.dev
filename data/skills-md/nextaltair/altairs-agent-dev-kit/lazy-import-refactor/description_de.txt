Refaktorieren Sie Importe starker nativer Abhängigkeiten (Torch, Tensorflow, Jax) auf Modulebene in funktionsinterne Lazy-Importe. Wird verwendet, wenn ein Bibliotheksimport SIGSEGV oder einen langsamen Start in Umgebungen auslöst, in denen die native Dep nicht vollständig initialisiert werden kann (z. B. fehlender CUDA-Treiber, Segfault der Triton-C-Erweiterung, fehlende GPU). Prognostiziert testseitige Auswirkungen entfernter Modulattribute.
