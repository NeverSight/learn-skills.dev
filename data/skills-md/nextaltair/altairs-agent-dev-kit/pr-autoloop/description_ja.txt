エージェントが PR を作成するか、ドラフト PR がレビューの準備ができたら、PR メンテナンスを完了まで自動的に実行します。人間が各ポーリング サイクルを再開するのを待たずに、gh で CI とボット レビューのポーリングを継続し、障害を修復して同じワークツリー内で日本語で応答し、設計ループをエスカレートし、安全なときにスカッシュ マージします。エージェントが作成した PR が存在するか、ドラフトから準備完了に移行した直後に使用します。人間が作成した PR には使用しないでください。また、ここで修復/マージ/エスカレーション ポリシーを再定義しないでください (pr-maintainer に存在します)。
