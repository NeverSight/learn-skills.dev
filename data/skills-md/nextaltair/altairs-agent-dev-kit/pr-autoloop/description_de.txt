Führen Sie die PR-Wartung automatisch bis zum Abschluss aus, nachdem ein Agent eine PR erstellt hat oder ein PR-Entwurf zur Überprüfung bereit ist: Führen Sie weiterhin CI-Abfragen und Bot-Überprüfungen mit gh durch, beheben Sie Fehler und antworten Sie auf Japanisch im selben Arbeitsbaum, eskalieren Sie Entwurfsschleifen und quetschen Sie die Zusammenführung, wenn dies sicher ist, ohne darauf warten zu müssen, dass ein Mensch jeden Abfragezyklus neu startet. Verwenden Sie es direkt, nachdem ein vom Agenten erstellter PR vorhanden ist oder vom Entwurf in den betriebsbereiten Zustand übergeht. NICHT für von Menschen erstellte PRs verwenden und hier NICHT die Reparatur-/Zusammenführungs-/Eskalationsrichtlinie neu definieren (die sich im PR-Maintainer befindet).
