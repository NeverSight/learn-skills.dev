Wie der Eigentümer Features ausliefert – zuerst der Planmodus (kein Plan, kein Start), dann Tickets, dann ein gestapelter PR pro vertikalem Slice über `gh stack`. Ein neuer Subagent implementiert, ein neuer Reviewer‑Subagent prüft jeden Slice, ein Gate‑Subagent führt Lint, Tests, Build und E2E aus, der Main‑Agent merged und aktualisiert das Ticket. Verwende das für jede Implementierungsaufgabe, die größer ist als eine einzeilige Korrektur. Teste den Plan unter Stress mit references/interrogating.md.
