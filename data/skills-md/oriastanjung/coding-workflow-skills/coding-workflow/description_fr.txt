Comment le propriétaire livre les fonctionnalités — d'abord le mode plan (pas de plan, pas de démarrage), puis les tickets, puis une PR empilée par tranche verticale via `gh stack`. Un sous‑agent frais implémente, un sous‑agent réviseur frais examine chaque tranche, un sous‑agent passerelle exécute le lint, les tests, la construction et les e2e, l'Agent Principal fusionne et met à jour le ticket. Utilisez‑le pour toute tâche d'implémentation plus grande qu'un correctif d'une ligne. Testez à la charge le plan avec references/interrogating.md.
