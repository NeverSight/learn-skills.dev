How the owner ships features — plan mode first (no plan, no start), then tickets, then one stacked PR per vertical slice via `gh stack`. A fresh subagent implements, a fresh reviewer subagent reviews every slice, a gate subagent runs lint, test, build and e2e, Main Agent merges and updates the ticket. Use for any implementation task larger than a one-line fix. Stress-test the plan with references/interrogating.md.
