Как владелец выпускает функции — сначала режим планирования (без плана — без старта), затем тикеты, затем один «stacked» PR на каждый вертикальный срез через `gh stack`. Свежий субагент реализует, свежий субагент‑рецензент проверяет каждый срез, субагент‑ворота запускает линт, тесты, сборку и e2e, главный агент сливает и обновляет тикет. Используйте для любой задачи реализации, превышающей исправление в одну строку. Проведите стресс‑тест плана с помощью references/interrogating.md.
