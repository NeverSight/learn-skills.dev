Auditar presentaciones en PowerPoint, PDF, exportaciones de Keynote o HTML de lienzo fijo para la trama, evidencia, jerarquía visual, legibilidad, recorte, solapamiento, fallos de recursos, consistencia y preparación para la entrega. Úselo para revisión final, comprobaciones previas al envío, críticas de diapositivas o QA de regresión; diagnostique primero y solo modifique la presentación cuando el usuario también solicite correcciones.
