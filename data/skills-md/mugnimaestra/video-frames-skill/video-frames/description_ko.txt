AI/LLM 분석을 위해 ffmpeg를 사용하여 비디오 파일에서 프레임을 추출합니다. (1) 사용자가 비디오 파일을 분석, 설명 또는 요약하려고 할 때, (2) 사용자가 비디오에서 프레임이나 스크린샷을 추출하려고 할 때, (3) 사용자가 비디오 파일(.mp4, .mov, .avi, .mkv, .webm 등)을 제공하고 해당 시각적 콘텐츠에 대해 질문할 때, (4) 사용자가 비디오에서 장면, 객체 또는 이벤트를 식별하려고 할 때, (5) 사용자가 시간적 참조를 위해 추출된 프레임에 오버레이된 타임스탬프를 원할 때 사용합니다. 비디오를 LLM 프롬프트에 이미지로 첨부할 수 있는 JPEG 프레임으로 변환합니다. PATH에 ffmpeg가 필요합니다. 장면 변경 감지, 모델 인식 최적화(Claude/OpenAI/Gemini), 품질 사전 설정(효율적/균형/상세/ocr), 회색조 및 고대비 OCR 모드, --max-frames를 통한 자동 FPS 계산을 지원합니다.
