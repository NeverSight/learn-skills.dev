Reylo를 사용하여 .sql 파일을 가져오는 프로젝트에서, tsconfig.json에 contentMappers가 reylo로 지정되어 있거나 .reylo.yaml 파일 또는 Reylo 의존성이 있는 경우 다음과 같은 작업을 수행합니다: .sql 쿼리를 작성하거나 수정하고, 해당 쿼리의 .run(), .runSync() 또는 .with()를 호출하며, 데이터베이스 클라이언트를 전달하고, 쿼리를 추적하거나 로깅하고, .sql 파일에서 타입 검사 오류를 수정하거나, 프로젝트의 쿼리를 Prisma Client에서 Reylo로 이동하는 것을 평가, 계획 또는 실행합니다.
