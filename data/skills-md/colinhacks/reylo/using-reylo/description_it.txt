Utilizzo in un progetto che importa file .sql con Reylo, dove un tsconfig.json il cui contentMappers si chiama reylo, un .reylo.yaml o una dipendenza di reylo mostrano: scrivere o modificare una query .sql, chiamare il suo .run(), .runSync() o .with(), passargli un client di database, tracciare o registrare le sue query, correggere un errore segnalato dal type check in un file .sql, oppure valutare, pianificare o eseguire il trasferimento delle query di un progetto da Prisma Client a Reylo.
