Uso en un proyecto que importa archivos .sql con Reylo, que tiene un tsconfig.json cuyo contentMappers se llama reylo, un archivo .reylo.yaml o una dependencia de reylo muestra: escribir o modificar una consulta .sql, llamar a su .run(), .runSync() o .with(), pasarle un cliente de base de datos, rastrear o registrar sus consultas, corregir un error que el verificador de tipos informa en un archivo .sql, o evaluar, planificar o llevar a cabo la migración de las consultas de un proyecto a Reylo desde Prisma Client.
