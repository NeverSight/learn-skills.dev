Современное управление секретами для создания и аудита программного обеспечения. Используйте, когда задача связана с созданием, хранением, внедрением, ротацией или сканированием учётных данных — или проверкой кода/инфраструктуры на утечки и неправильное использование секретов. Режим BUILD: реализация обработки секретов; режим AUDIT: сканирование репозитория на предмет утекших, захардкоженных или неправильно обработанных секретов. Ключевые слова‑триггеры: секрет, управление секретами, учётные данные, API‑ключ, токен, пароль, закрытый ключ, подписывающий ключ, JWT‑секрет, TLS‑ключ, SSH‑ключ, пароль базы данных, строка подключения, .env, dotenv, переменная окружения, Vault, OpenBao, AWS Secrets Manager, GCP Secret Manager, Azure Key Vault, KMS, шифрование оболочкой, SOPS, age, sealed‑secrets, external‑secrets, идентификация нагрузки, федерация OIDC, SPIFFE, SPIRE, роль IAM, GitHub Actions OIDC, краткосрочные учётные данные, ротация, отзыв, истечение срока действия ключа, gitleaks, trufflehog, сканирование секретов, утекший ключ, захардкоженный секрет, зафиксированный секрет, очистка истории git, honeytoken, pre‑commit‑hook, ротация kid.
