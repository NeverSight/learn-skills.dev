Современные методы изоляции и создания песочниц (2026). Используйте при проектировании изоляции для ненадёжного кода, парсинга ненадёжного ввода, многопользовательских нагрузок или выполнения ИИ/агентов — а также при аудите существующих систем на наличие пробелов в изоляции. Охватывает принцип наименьших привилегий, защиту в глубину, выбор границы изоляции (VM/микроVM/gVisor/контейнер/процесс/WASM), primitives Linux (пространства имён, cgroups v2, seccomp‑bpf, Landlock, AppArmor/SELinux, capabilities), укрепление Docker/OCI и Kubernetes, разделение привилегий и паттерны брокеров, гигиену подпроцессов и ограничение инструментов/выхода агентов. Ключевые слова‑триггеры — sandboxing, sandbox, isolation, least privilege, container hardening, container escape, seccomp, Landlock, namespaces, gVisor, Kata, Firecracker, microVM, pod security, untrusted code, untrusted input processing, risky parser, privilege separation, WASM sandbox, V8 isolate, agent code execution, egress allowlist, multi-tenant isolation.
