Современная инженерия Python как для написания нового кода, так и для аудита существующего. Охватывает инструменты на основе uv и настройку проекта, строгую типизацию, идиомы и подводные камни, структурную конкуренцию asyncio, безопасность (инъекции, десериализация, цепочка поставок), производительность и практику FastAPI/Django/pytest. Используйте, когда задача связана с исходным кодом Python, pyproject.toml, файлами requirements или инструментарием Python — разработка функций, создание каркаса проекта, ревью PR или поиск багов/уязвимостей. Ключевые слова‑триггеры: Python, pip, uv, pyproject, asyncio, Django, FastAPI, pytest, подсказки типов, mypy, ruff, pydantic, SQLAlchemy, venv.
