最先端の Python エンジニアリングは、新規の Python コード作成と既存コードの監査の両方に対応します。uv ベースのツールとプロジェクト設定、厳格な型付け、イディオムと落とし穴、asyncio による構造化並行処理、セキュリティ（インジェクション、逆シリアライズ、サプライチェーン）、パフォーマンス、そして FastAPI/Django/pytest の実践をカバーします。Python ソース、pyproject.toml、requirements ファイル、または Python ツール類が関わるタスク全般—機能実装、プロジェクトの足場作り、プルリクエストのレビュー、バグや脆弱性の検出—に使用してください。トリガーキーワード: Python, pip, uv, pyproject, asyncio, Django, FastAPI, pytest, type hints, mypy, ruff, pydantic, SQLAlchemy, venv.
