安全程式設計與安全稽核規則。於以下情況均使用——在建立或修改跨越信任邊界的程式碼時，包括端點、處理程式、驗證/登入/註冊、會話、JWT/OAuth、檔案上傳、付款、多租戶功能、加密/機密處理、解析器、CLI/執行包裝、LLM 代理或工具呼叫——以及在對程式碼進行安全稽核時（安全檢閱、漏洞搜尋、加固、OWASP、CWE、機密外洩、「此程式碼是否安全」）——以及當已有控制措施存在且需要判斷其是否真的有執行任何限制時（永不失敗的門檻、空的比較對象），即使該控制位於 Shell 腳本、CI 步驟或設定檔中。觸發關鍵字：secure、security、vulnerability、audit、authn、authz、authentication、authorization、crypto、TLS、sanitize、validate、injection、SQLi、XSS、CSRF、SSRF、IDOR、JWT、OAuth、upload、rate limit、prompt injection、feed、parser、decompression bomb、webhook、deserialization、silent failure、fail‑open、no‑op control、business logic。
