安全编码与安全审计规则。适用于在构建或修改跨越信任边界的代码时——包括端点、处理程序、认证/登录/注册、会话、JWT/OAuth、文件上传、支付、多租户功能、加密/密钥处理、解析器、CLI/执行包装器、LLM 代理或工具调用——以及在审计代码安全性时（安全评审、漏洞搜寻、加固、OWASP、CWE、密钥泄露、“这段代码安全吗”），并且在已有控制已存在且需判断其是否真正生效时（例如永不失败的门、空比较值），即使该控制位于 Shell 脚本、CI 步骤或配置文件中。触发关键字：secure、security、vulnerability、audit、authn、authz、authentication、authorization、crypto、TLS、sanitize、validate、injection、SQLi、XSS、CSRF、SSRF、IDOR、JWT、OAuth、upload、rate limit、prompt injection、feed、parser、decompression bomb、webhook、deserialization、silent failure、fail-open、no‑op control、business logic。
