Ingeniería de rendimiento de última generación para construir sistemas rápidos y auditar código existente en busca de cuellos de botella. Úsalo cuando la tarea implique rendimiento, optimización, latencia, perfilado, código lento, uso de memoria, caché o rendimiento: diseñar presupuestos de latencia, corregir patrones N+1 y cuadráticos accidentales, ajustar la presión de asignación/GC, eficiencia de red y E/S, arquitectura de caché, Core Web Vitals, o configurar benchmarks y puertas de regresión. No es para corrección de concurrencia (condiciones de carrera, deadlocks, cancelación): usa sota-async-concurrency. Palabras clave activadoras: rendimiento, optimización, latencia, perfilado, lento, uso de memoria, caché, rendimiento, cuello de botella, p99, flamegraph, Core Web Vitals.
