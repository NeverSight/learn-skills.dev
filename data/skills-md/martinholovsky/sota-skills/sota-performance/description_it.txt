Ingegneria delle prestazioni all’avanguardia per costruire sistemi veloci e controllare il codice esistente alla ricerca di colli di bottiglia. Da utilizzare quando il compito riguarda prestazioni, ottimizzazione, latenza, profiling, codice lento, uso della memoria, caching o throughput — progettazione di budget di latenza, correzione di pattern N+1 e quadratici accidentali, ottimizzazione della pressione di allocazione/GC, efficienza di rete e I/O, architettura della cache, Core Web Vitals, o configurazione di benchmark e gate di regressione. Non per la correttezza della concorrenza (race, deadlock, cancellazione) — usare sota-async-concurrency. Parole chiave di attivazione: performance, optimization, latency, profiling, slow, memory usage, caching, throughput, bottleneck, p99, flamegraph, Core Web Vitals.
