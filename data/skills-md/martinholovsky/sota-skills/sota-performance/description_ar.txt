هندسة الأداء المتطورة لبناء أنظمة سريعة وتدقيق الشيفرة الحالية للعثور على الاختناقات. يُستَخدم عندما تتضمن المهمة الأداء، التحسين، زمن الاستجابة، التحليل (profiling)، الشيفرة البطيئة، استهلاك الذاكرة، التخزين المؤقت، أو معدل الإرسال — تصميم ميزانيات زمن الاستجابة، إصلاح أنماط N+1 والأنماط التربيعية غير المقصودة، ضبط ضغط التخصيص/GC، كفاءة الشبكة وإدخال/إخراج البيانات، بنية الكاش، Core Web Vitals، أو إعداد معايير القياس وبوابات الانحدار. ليس للأمان الصحيح في التزامن (سباقات، حالات توقف، الإلغاء) — استخدم sota-async-concurrency. الكلمات المفتاحية للمحفز: performance, optimization, latency, profiling, slow, memory usage, caching, throughput, bottleneck, p99, flamegraph, Core Web Vitals.
