빠른 시스템 구축 및 기존 코드의 병목 현상 감사를 위한 최첨단 성능 엔지니어링. 작업이 성능, 최적화, 지연 시간, 프로파일링, 느린 코드, 메모리 사용, 캐싱 또는 처리량과 관련될 때 사용 — 지연 예산 설계, N+1 및 우연한 2차 패턴 수정, 할당/GC 압력 튜닝, 네트워크 및 I/O 효율성, 캐시 아키텍처, Core Web Vitals, 혹은 벤치마크와 회귀 게이트 설정. 동시성 정확성(경쟁, 교착 상태, 취소)에는 사용하지 않음 — sota-async-concurrency 사용. 트리거 키워드: performance, optimization, latency, profiling, slow, memory usage, caching, throughput, bottleneck, p99, flamegraph, Core Web Vitals.
