Leistungs‑Engineering auf dem neuesten Stand, um schnelle Systeme zu bauen und bestehenden Code auf Engpässe zu prüfen. Verwenden, wenn die Aufgabe Performance, Optimierung, Latenz, Profiling, langsamen Code, Speicherverbrauch, Caching oder Durchsatz beinhaltet — zur Gestaltung von Latenzbudgets, zur Behebung von N+1‑ und unbeabsichtigten quadratischen Mustern, zum Abstimmen von Speicherzuweisungen/GC‑Druck, zur Optimierung von Netzwerk‑ und I/O‑Effizienz, Cache‑Architektur, Core Web Vitals oder zum Einrichten von Benchmarks und Regressions‑Gates. Nicht für nebenläufige Korrektheit (Race‑Conditions, Deadlocks, Abbrüche) — verwenden Sie sota-async-concurrency.
