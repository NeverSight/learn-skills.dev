Современная инженерия производительности для создания быстрых систем и аудита существующего кода на наличие узких мест. Используйте, когда задача связана с производительностью, оптимизацией, задержкой, профилированием, медленным кодом, использованием памяти, кэшированием или пропускной способностью — проектирование бюджетов задержек, исправление паттернов N+1 и случайных квадратичных зависимостей, настройка давления распределения/GC, эффективность сети и ввода‑вывода, архитектура кэша, Core Web Vitals, или настройка бенчмарков и регрессионных ворот. Не предназначено для проверки корректности конкуренции (гонки, взаимные блокировки, отмена) — используйте sota-async-concurrency. Триггерные ключевые слова: performance, optimization, latency, profiling, slow, memory usage, caching, throughput, bottleneck, p99, flamegraph, Core Web Vitals.
