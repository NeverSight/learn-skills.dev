Guide de documentation et de collaboration d'ingénierie à la pointe de la technologie (2026) couvrant l'architecture de la documentation (Diátaxis, docs-as-code, README, runbooks, onboarding, documentation lisible par l'IA), les docs API/référence et les journaux des changements, ainsi que le flux de travail d'équipe autour du code : pull requests, conduite des revues de code, discipline des commits, branchement et releases. Utilisez‑le lors de la rédaction ou de la structuration de toute documentation ET lors de l’audit de la qualité des docs, ainsi que lors de la conception ou de l’audit du flux de collaboration. Ne pas utiliser pour le microtexte UI intégré au produit (utilisez sota‑ux‑writing) ou pour le texte marketing/de page d’atterrissage (utilisez sota‑copywriting). Mots‑clés déclencheurs : documentation, docs, README, docs API, docstring, changelog, notes de version, guide de migration, revue de code, pull request, description de PR, messages de commit, commits conventionnels, branchement, semver, onboarding, runbook, AGENTS.md, llms.txt, développement piloté par les spécifications, SDD, Spec Kit, Kiro, spécification, critères d’acceptation, fichiers de pilotage.
