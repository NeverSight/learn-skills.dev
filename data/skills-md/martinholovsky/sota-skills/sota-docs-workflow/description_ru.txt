Современное руководство по документированию и инженерному сотрудничеству (2026), охватывающее архитектуру документации (Diátaxis, docs-as-code, README, runbooks, onboarding, AI‑readable docs), API/референсные документы и журналы изменений, а также рабочий процесс команды по коду: pull‑request’ы, порядок проведения code review, дисциплина коммитов, ветвление и релизы. Использовать при написании или структурировании любой документации И при аудите качества docs, а также при проектировании или аудите рабочего процесса сотрудничества. Не предназначено для микрокопира в пользовательском интерфейсе (используйте sota-ux-writing) или для маркетинговых/лендинговых текстов (используйте sota-copywriting). Триггерные ключевые слова: documentation, docs, README, API docs, docstring, changelog, release notes, migration guide, code review, pull request, PR description, commit messages, conventional commits, branching, semver, onboarding, runbook, AGENTS.md, llms.txt, spec-driven development, SDD, Spec Kit, Kiro, specification, acceptance criteria, steering files.
