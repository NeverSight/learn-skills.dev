Guía de documentación y colaboración de ingeniería de vanguardia (2026) que cubre la arquitectura de documentación (Diátaxis, docs-as-code, README, runbooks, incorporación, documentos legibles por IA), documentación API/referencia y registros de cambios, y el flujo de trabajo del equipo alrededor del código: pull requests, conducta de revisión de código, disciplina de commits, ramificación y versiones. Úsala al redactar o estructurar cualquier documentación Y al auditar la calidad de los docs, y al diseñar o auditar el flujo de trabajo de colaboración. No es para microcopy de UI dentro del producto (usa sota-ux-writing) ni para copys de marketing/páginas de aterrizaje (usa sota-copywriting). Palabras clave disparadoras: documentation, docs, README, API docs, docstring, changelog, release notes, migration guide, code review, pull request, PR description, commit messages, conventional commits, branching, semver, onboarding, runbook, AGENTS.md, llms.txt, spec-driven development, SDD, Spec Kit, Kiro, specification, acceptance criteria, steering files.
