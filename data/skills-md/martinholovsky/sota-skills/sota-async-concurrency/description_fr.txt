Règles de pointe pour écrire et auditer du code asynchrone et concurrent sur différents environnements (Python asyncio, JS/Node, Go, Rust, JVM). À utiliser lors de la création de tout ce qui utilise async/await, threads, processus, boucles d'événements, groupes de tâches, canaux ou files d’attente — et lors de l’audit de code existant pour les conditions de course, les interblocages, les tâches fuitées, les boucles d’événements bloquées, les annulations manquantes ou les échecs de rétroaction. Pas pour le profilage et l’optimisation de latence/débit — utilisez sota-performance. Mots‑clés déclencheurs : async, await, concurrency, parallelism, threads, race condition, deadlock, event loop, channels, queues, semaphore, mutex, cancellation, timeout, backpressure, task group, goroutine, tokio, asyncio.
