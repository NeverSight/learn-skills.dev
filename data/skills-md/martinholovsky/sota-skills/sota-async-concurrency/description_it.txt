Regole all’avanguardia per scrivere e revisionare codice asincrono e concorrente su diversi runtime (Python asyncio, JS/Node, Go, Rust, JVM). Da utilizzare quando si sviluppa qualsiasi cosa con async/await, thread, processi, loop di eventi, gruppi di task, canali o code — e quando si revisiona il codice esistente per condizioni di race, deadlock, task persi, loop di eventi bloccati, cancellazioni mancanti o fallimenti di backpressure. Non è destinato al profiling e all’ottimizzazione di latenza/throughput — utilizzare sota‑performance. Parole‑chiave di attivazione: async, await, concurrency, parallelism, threads, race condition, deadlock, event loop, channels, queues, semaphore, mutex, cancellation, timeout, backpressure, task group, goroutine, tokio, asyncio.
