Modellazione delle minacce all’avanguardia sia per la progettazione di nuovi sistemi sia per l’audit di quelli esistenti. Da usare quando si progetta una funzionalità, servizio, integrazione o architettura che interagisce con input non attendibili, nuovi confini di fiducia, dati sensibili o dipendenze di terze parti (modalità BUILD), e quando si revisiona, audita o si definisce l’ambito di un penetration test di un codice esistente per ricostruire il suo modello di minaccia implicito e trovare lacune (modalità AUDIT). Non è destinata alla revisione di vulnerabilità a livello di codice — utilizzare sota‑code‑security. Parole chiave di attivazione: threat model, STRIDE, LINDDUN, PASTA, attack tree, kill chain, data flow diagram, DFD, trust boundary, attack surface, abuse case, security design review, security architecture review, risk rating, DREAD, CVSS, security requirements, secure design, security audit, gap analysis, prompt injection, excessive agency, threat catalog, mitigations, residual risk.
