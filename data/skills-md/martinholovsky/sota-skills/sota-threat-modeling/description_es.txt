Modelado de amenazas de última generación tanto para diseñar sistemas nuevos como para auditar los existentes. Úselo al diseñar una funcionalidad, servicio, integración o arquitectura que implique entrada no confiable, nuevos límites de confianza, datos sensibles o dependencias de terceros (modo BUILD), y al revisar, auditar o delimitar pruebas de penetración de una base de código existente para reconstruir su modelo de amenazas implícito y encontrar brechas (modo AUDIT). No es para revisión de vulnerabilidades a nivel de código — use sota-code-security. Palabras clave disparadoras: modelo de amenazas, STRIDE, LINDDUN, PASTA, árbol de ataques, cadena de muerte, diagrama de flujo de datos, DFD, límite de confianza, superficie de ataque, caso de abuso, revisión de diseño de seguridad, revisión de arquitectura de seguridad, calificación de riesgo, DREAD, CVSS, requisitos de seguridad, diseño seguro, auditoría de seguridad, análisis de brechas, inyección de prompt, agencia excesiva, catálogo de amenazas, mitigaciones, riesgo residual.
