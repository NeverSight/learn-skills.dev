Используется, когда реальный урок, анализ, объяснение запуска или ресурс требуют структурированного X‑треда вместо одного поста. Фразовые триггеры включают «сделай из этого X‑тред», «создай схему треда», «разбей это для X», «преврати это исследование в тред» и «какой угол треда?». Не используйте это для создания горячих мнений, публикации непроверенных новостей или создания длинного блога; используйте content‑research для исходного материала, campaign‑brief для скоординированного запуска и linkedin‑thought‑leadership для аргумента, ориентированного на LinkedIn.
