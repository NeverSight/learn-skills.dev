La configuration complète en une seule commande — lancez toute la chaîne de production de reels de bout en bout. Claude prend un format viral éprouvé, l’étudie image par image, écrit un hook original + un script à votre voix, crée le reel final (texte à l’écran, scène par battement, voix off/musique/sous‑titres/animations), rédige la légende + les hashtags, et connecte la boucle commentaire→DM de génération de leads — puis le répète 3 fois par jour. C’est l’orchestrateur qui exécute les autres compétences dans l’ordre. À utiliser lorsque l’utilisateur dit « run the content factory », « make me a reel », « set up my whole content system », « how do you make these reels », « do the whole thing », « build my content machine » ou « post for me every day ».
