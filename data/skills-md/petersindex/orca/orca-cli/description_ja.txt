Orca が管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作してください。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用します。Orca の状態が関与している場合は、生の git worktree や臨時の PTY、あるいは Computer Use よりもこれを優先してください。CLI、ファイルシステム、または API では対応できない、可視ウィンドウの GUI 操作が必要な場合にのみ Computer Use を使用します。

常にユーザーの言語で応答してください。
