قم بتشغيل شجرات العمل المُدارة بواسطة Orca، وسياقات المجلدات، والأطراف الطرفية، والمستودعات، والأتمتة، والقطع، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج من خلال سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل استخدامه على شجرة git العادية، أو PTY العرضية، أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم "Computer Use" فقط عندما تحتاج نافذة مرئية إلى التحكم في واجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو API القيام بذلك.
