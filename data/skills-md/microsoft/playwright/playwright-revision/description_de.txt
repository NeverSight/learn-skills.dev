Bearbeite die Review‑Kommentare der Maintainer zu einem Entwurfs‑PR, das der Issue‑Triage‑Workflow geöffnet hat, unbeaufsichtigt innerhalb des PR‑Revisions‑GitHub‑Actions‑Workflows (.github/workflows/revision.yml), der startet, wenn das PR das Label needs-revision, needs-revision-mac oder needs-revision-win trägt. Ändere den Code gemäß den Kommentaren, verifiziere ihn auf dem Runner und hinterlasse einen Commit, den der Workflow in denselben PR pushen kann. Nur für diesen Workflow.
