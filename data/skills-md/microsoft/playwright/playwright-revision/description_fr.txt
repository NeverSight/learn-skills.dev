Répondez aux commentaires de revue des mainteneurs sur une PR brouillon ouverte par le workflow de tri des tickets, non prise en charge à l'intérieur du workflow de révision de PR GitHub Actions (.github/workflows/revision.yml), qui démarre lorsqu’un label needs-revision, needs-revision-mac ou needs-revision‑win est appliqué à la PR. Modifiez le code conformément aux commentaires, vérifiez-le sur le runner et laissez un seul commit que le workflow poussera sur la même PR. Uniquement pour ce workflow.
