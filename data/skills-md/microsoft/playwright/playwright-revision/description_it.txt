Affronta i commenti di revisione dei manutentori su una PR in bozza aperta dal workflow di triage delle issue, non gestita all’interno del workflow di revisione della PR di GitHub Actions (.github/workflows/revision.yml), che parte quando la PR ha un’etichetta needs‑revision, needs‑revision‑mac o needs‑revision‑win. Modifica il codice come richiesto nei commenti, verificalo sul runner e lascia un unico commit affinché il workflow lo spinga sulla stessa PR. Solo per quel workflow.
