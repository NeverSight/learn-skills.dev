Abordar los comentarios de revisión de los mantenedores en un PR en borrador que el flujo de trabajo de clasificación de incidencias abrió, sin atención dentro del flujo de trabajo de revisión de PR de GitHub Actions (.github/workflows/revision.yml), que se inicia cuando el PR tiene una etiqueta needs-revision, needs-revision-mac o needs-revision-win. Cambiar el código según lo soliciten los comentarios, verificarlo en el runner y dejar un único commit para que el flujo de trabajo lo envíe al mismo PR. Sólo para ese flujo de trabajo.
