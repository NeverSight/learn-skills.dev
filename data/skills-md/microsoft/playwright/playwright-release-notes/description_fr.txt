Rédigez les notes de version pour une version de Playwright – les notes Node.js dans docs/src/release-notes-js.md ainsi que les traductions Python, Java et .NET, et le markdown GitHub pour chaque version linguistique. Utilisez ceci lorsqu’on vous demande d’écrire, de traduire ou de publier des notes de version.

Veuillez toujours répondre dans la langue de l’utilisateur.
