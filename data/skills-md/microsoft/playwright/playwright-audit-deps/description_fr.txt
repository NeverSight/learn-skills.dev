Mettez à jour les dépendances d’exécution que npm audit signale avec un avis modéré ou plus élevé vers des versions sûres datant d’au moins 8 jours, puis validez‑les avec un tableau récapitulatif de chaque paquet modifié dans le fichier lock (ancienne et nouvelle version, date de publication, téléchargements hebdomadaires). Utilisez cela lorsqu’on vous demande de corriger les constats d’audit, de mettre à jour les dépendances d’exécution vulnérables ou obsolètes, ou de mettre à jour package‑lock.json pour un avis.

Veuillez toujours répondre dans la langue de l’utilisateur.
