Создайте артефакт «Обзор API Playwright 1.xx» для диапазона коммитов — добавления в публичный API, а также ломающие или изменяющие поведение изменения, которые затрагивают существующих пользователей, с момента последнего обзора API или последнего релиза, упорядоченные по степени воздействия, каждый с ссылками, фрагментами до/после и проверкой документации. Охватывает microsoft/playwright (Node.js) и порты для Python, Java и .NET. Используйте при запросе обзора API, для анализа изменений API или для проверки, что изменилось в публичном API с релиза или с последнего обзора.
