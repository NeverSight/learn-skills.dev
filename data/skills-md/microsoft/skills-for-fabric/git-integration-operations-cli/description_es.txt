Ejecuta el ciclo de vida de la integración de Fabric Git a través de la API de Fabric o de az rest, lo que incluye conectar un espacio de trabajo a Azure DevOps o GitHub, confirmar cambios, actualizar desde Git, leer el estado de la sincronización, resolver conflictos, desconectar un espacio de trabajo conectado y automatizar la sincronización con una entidad de servicio. Para la promoción de etapas, utilice deployment-pipelines-authoring-cli. El cambio de rama, fab deploy, fabric-cicd y la reasociación entre áreas de trabajo quedan fuera del ámbito de aplicación.
