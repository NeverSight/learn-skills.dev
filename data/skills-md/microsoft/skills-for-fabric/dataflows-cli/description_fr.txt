Gère les éléments Fabric Dataflow Gen2, notamment la création, l’édition M, les connexions, les destinations de sortie, l’inspection getDefinition et updateDefinition, executeQuery, l’historique des actualisations et les mises à niveau Gen1 vers Gen2 via saveAsNativeArtifact. À utiliser pour les éléments Dataflow ou les définitions Power Query M. Pour le JSON de pipeline, utilisez pipeline-migration ; pour les transformations Spark ou Warehouse, utilisez leurs propres compétences.
