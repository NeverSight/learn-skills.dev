Gestiona y organiza el catálogo de Microsoft Fabric OneLake a través de las API REST de Fabric Admin, Core y Power BI. Utilícelo para las auditorías de gobernanza de los inquilinos o de los propietarios de los datos y para la corrección controlada de los dominios, la asignación de espacios de trabajo, la capacidad, las etiquetas, las definiciones de etiquetas, las etiquetas de los espacios de trabajo, la certificación, la actualización y la identidad de los elementos, así como para que los propietarios supervisen la descripción, el nombre, las etiquetas y las descripciones de las tablas y las columnas de un elemento. La detección de elementos pertenece a search-consumption-cli.
