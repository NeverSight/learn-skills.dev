Migra las canalizaciones de Synapse Data Factory a Fabric Data Factory, convirtiendo los servicios vinculados en conexiones de Fabric, integrando los conjuntos de datos en las actividades, convirtiendo los parámetros globales en bibliotecas de variables y asignando SynapseNotebook a TridentNotebook. Úselo para el JSON de la canalización. Para el código del bloc de notas de Synapse Spark, utilice synapse-migration.
