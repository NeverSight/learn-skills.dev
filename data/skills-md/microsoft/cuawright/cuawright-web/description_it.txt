Risolvi un compito web specificato dall'utente in stile code‑as‑action guidando un browser locale Playwright attraverso un comando bash alla volta, salvando screenshot e un registro delle azioni in `final_runs/run_<id>/`, e verificando visivamente il risultato. Usa questo approccio quando l'utente chiede di automatizzare un compito web (ricerca, filtro, compilazione di moduli, flusso multi‑step, estrazione dati) e desidera script riutilizzabili più evidenze screenshot piuttosto che una risposta una tantum.

Rispondi sempre nella lingua dell'utente.
