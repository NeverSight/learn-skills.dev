Architektur und hart erarbeitete Debugging-Lektionen für die Anpassungsaktivierung (Plugins, MCP-Server, Agenten, Fähigkeiten, Anweisungen) im Agent-Host. Verwenden Sie diese Option, wenn Sie ändern, wie Anpassungen entdeckt, veröffentlicht, aktiviert/deaktiviert oder an ein Anbieter-SDK übergeben werden, wenn eine Anpassung den falschen aktivierten Zustand in der Benutzeroberfläche anzeigt oder wenn ein deaktivierter MCP-Server oder -Plugin das Modell immer noch erreicht.
