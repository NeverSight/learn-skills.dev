À utiliser lors de l'ajout, de la modification ou de la révision de survols ou d'info-bulles sur les widgets VS Code et les éléments de l'interface utilisateur, y compris les boutons, les actions, les barres d'outils, les listes et les arborescences. Couvre les info-bulles personnalisées par rapport aux info-bulles natives, le placement hoverDelegate, HoverStyle, les pointeurs, les survols retardés d'IHoverService, groupId et le comportement de survol instantané partagé sur les widgets adjacents.
