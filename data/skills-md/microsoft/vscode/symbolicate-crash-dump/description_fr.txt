Symbolisez un vidage forcé VS Code natif (.dmp) à l'aide d'un minidump électronique. Utilisez lorsqu'on vous donne un fichier de vidage de plantage, qu'on vous demande de symboliser un plantage, de résoudre les noms de méthodes manquants dans une trace de plantage native ou de joindre des fichiers de symboles Electron/Insiders/Stable. Membres de l'équipe VS Code uniquement ; nécessite macOS ou Linux.
