Diagnostiquer les défaillances intermittentes des tests de fumée VS Code Electron à partir du pipeline Azure DevOps Flaky Smoke Tests (définition 700). Couvre la recherche d'itérations échouées, le téléchargement de journaux de tâches et d'artefacts de plate-forme avec Azure CLI, la corrélation des journaux d'exécution cumulés, le traçage de la validation d'introduction et la mise en file d'attente des exécutions de validation ciblées.
