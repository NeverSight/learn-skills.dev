Triage y corregir un problema de microsoft/playwright-cli, o realizar una tarea de mantenedor, sin asistencia dentro del flujo de trabajo de GitHub Actions de triage de issues (.github/workflows/triage.yml), que se inicia con una etiqueta needs‑triage, needs‑triage‑mac o needs‑triage‑win, o que un mantenedor inicia manualmente con un issue, una tarea o ambos. Reproducir el problema en el runner y luego dejar una propuesta de corrección verificada para que el flujo de trabajo abra un PR borrador, ya sea en este repositorio o en microsoft/playwright donde está el código fuente del CLI, o una nota de investigación para publicarla en el issue. Sólo para ese flujo de trabajo.
