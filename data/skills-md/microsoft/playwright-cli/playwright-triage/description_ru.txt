Триаж и исправление одной проблемы microsoft/playwright-cli или выполнение задачи мейнтейнера без участия человека внутри workflow GitHub Actions по триажу Issue (.github/workflows/triage.yml), который запускается меткой needs-triage, needs-triage-mac или needs-triage-win, либо мейнтейнер запускает его вручную с issue, задачей или обоими вместе. Воспроизводит проблему на раннере, затем оставляет проверенное предложение исправления, чтобы workflow открыл его как черновой PR в этом репозитории или в microsoft/playwright, где находится исходный код CLI, либо оставляет заметку с расследованием для публикации в issue. Только для этого workflow.
