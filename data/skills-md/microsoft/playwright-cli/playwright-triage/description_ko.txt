microsoft/playwright-cli 문제 하나를 분류하고 수정하거나, Issue triage GitHub Actions 워크플로우(.github/workflows/triage.yml) 안에서 유지관리자의 작업을 자동으로 수행합니다. 이 워크플로우는 needs‑triage, needs‑triage‑mac 또는 needs‑triage‑win 라벨이 달리면 시작되며, 유지관리자가 직접 이슈, 작업 혹은 둘 모두를 시작할 수도 있습니다. 러너에서 해당 이슈를 재현한 뒤, 워크플로우가 초안 PR로 열도록 검증된 수정 제안을 이 레포지토리 또는 CLI 소스가 있는 microsoft/playwright에 남기거나, 이슈에 게시할 조사 메모를 남깁니다. 해당 워크플로우에만 적용됩니다.
