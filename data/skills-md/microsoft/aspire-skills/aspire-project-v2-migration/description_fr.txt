**COMPÉTENCE DE FLUX DE TRAVAIL** - Migre en toute sécurité les AppHosts Aspire 13.6+ éligibles des API ProjectResource héritées vers les API expérimentales DotnetProjectResource après une évaluation par ressource et une approbation explicite des modifications exactes. UTILISER POUR : évaluer ou migrer les ressources existantes AddProject, addProject, AddCSharpApp, addCSharpApp ou AddBlazorGateway vers le Projet v2 ; migrer ProjectResource vers DotnetProjectResource ; nettoyer les arêtes ProjectReference d’AppHost devenues obsolètes. NE PAS UTILISER POUR : mettre à jour la version d’Aspire, créer/brancher un nouvel AppHost, migration Azure Functions, modernisation générique du code source, câblage ordinaire de ressources C# ou ajouter une nouvelle ressource AddProject (utiliser aspireify), publication, ou diagnostics de construction/cycle de vie. INVOQUE : recherche dans la documentation/API d’Aspire, aspire add/restore/start/wait, modifications d’AppHost et de paquets. POUR DES OPÉRATIONS UNIQUES : évaluer d’abord ; ne jamais modifier à partir d’une simple demande de migration générique.
