**WORKFLOW SKILL** - Migra in modo sicuro gli AppHost Aspire 13.6+ idonei dalle API legacy ProjectResource alle API sperimentali DotnetProjectResource dopo una valutazione per risorsa e l'approvazione esplicita delle modifiche esatte. USA PER: valutare o migrare le risorse esistenti AddProject, addProject, AddCSharpApp, addCSharpApp o AddBlazorGateway verso Project v2; migrare ProjectResource in DotnetProjectResource; pulire i riferimenti obsoleti AppHost ProjectReference. NON USARE PER: aggiornare le versioni di Aspire, creare/collegare un nuovo AppHost, migrazione di Azure Functions, modernizzazione generica del codice sorgente, collegamento ordinario di risorse C# o aggiungere una nuova risorsa AddProject (usa aspireify), pubblicazione o diagnostica di build/ciclo di vita. INVOCHE: ricerca nella documentazione/API di Aspire, aspire add/restore/start/wait, modifiche ad AppHost e pacchetti. PER OPERAZIONI SINGOLE: valutare prima; non modificare mai partendo solo da una richiesta di migrazione generica.
