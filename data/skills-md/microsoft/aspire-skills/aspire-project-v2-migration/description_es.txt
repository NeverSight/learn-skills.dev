**HABILIDAD DE FLUJO DE TRABAJO** - Migra de forma segura los AppHosts elegibles de Aspire 13.6+ desde las API heredadas de ProjectResource a las API experimentales de DotnetProjectResource después de una evaluación por recurso y la aprobación explícita de las ediciones exactas. USAR PARA: evaluar o migrar recursos existentes AddProject, addProject, AddCSharpApp, addCSharpApp o AddBlazorGateway a Project v2; migrar ProjectResource a DotnetProjectResource; limpiar los bordes obsoletos de ProjectReference del AppHost resultantes. NO USAR PARA: actualizar versiones de Aspire, crear/conectar un nuevo AppHost, migración de Azure Functions, modernización genérica del código fuente, cableado ordinario de recursos C# o añadir un nuevo recurso AddProject (use aspireify), publicación o diagnósticos de compilación/ciclo de vida. INVOCACIONES: búsqueda en la documentación/API de Aspire, aspire add/restore/start/wait, ediciones de AppHost y paquetes. PARA OPERACIONES ÚNICAS: evaluar primero; nunca editar a partir de una solicitud de migración genérica sola.
