**مهارة سير العمل** - تقوم بأمان بترحيل AppHosts المؤهلة لإصدار Aspire 13.6+ من واجهات برمجة التطبيقات القديمة ProjectResource إلى واجهات DotnetProjectResource التجريبية بعد تقييم كل مورد وموافقة صريحة على التعديلات الدقيقة. **يُستخدم لـ:** تقييم أو ترحيل موارد AddProject وaddProject وAddCSharpApp وaddCSharpApp أو AddBlazorGateway الحالية إلى Project v2؛ ترحيل ProjectResource إلى DotnetProjectResource؛ تنظيف وصلات ProjectReference القديمة الخاصة بـ AppHost. **لا يُستخدم لـ:** ترقية إصدارات Aspire، إنشاء/ربط AppHost جديد، ترحيل Azure Functions، تحديث المصدر بشكل عام، ربط موارد C# عادية أو إضافة مورد AddProject جديد (استخدم aspireify)، النشر، أو تشخيصات البناء/الدورة الحياتية. **يستدعي:** توثيق/بحث API الخاص بـ Aspire، أوامر aspire add/restore/start/wait، تعديلات AppHost والحزمة. **للعمليات المفردة:** قُم بالتقييم أولاً؛ لا تقم بالتعديل بناءً على طلب ترحيل عام فقط.
