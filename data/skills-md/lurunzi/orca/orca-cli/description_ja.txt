Orcaが管理するワークツリー、フォルダーコンテキスト、端末、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そしてOrcaの組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、生の git worktree やアドホック PTY、あるいは Computer Use よりもこちらを優先してください。GUI が必要で、CLI、ファイルシステム、API だけでは操作できない可視ウィンドウがあるときだけ Computer Use を使います。

常にユーザーの言語で回答してください。
