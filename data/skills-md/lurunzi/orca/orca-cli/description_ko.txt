`orca` CLI를 통해 Orca가 관리하는 워크트리, 폴더 컨텍스트, 터미널, 저장소, 자동화, 아티팩트, 기술 공유, 워크트리 코멘트 및 Orca 내장 브라우저를 운영합니다. 사용자가 “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff”/“handover”/“give this to another agent”, “Orca browser”, “orca artifacts”, 또는 “share skills”라고 말할 때 사용합니다. Orca 상태가 관련된 경우에는 원시 git 워크트리, 임시 PTY, 혹은 Computer Use보다 이를 우선합니다. CLI, 파일 시스템, API로는 제어할 수 없는 가시적인 창이 필요할 때만 Computer Use를 사용합니다.

항상 사용자의 언어로 응답하십시오.
