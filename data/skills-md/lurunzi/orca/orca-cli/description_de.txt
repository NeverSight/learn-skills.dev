Betreibe von Orca verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, das Teilen von Fähigkeiten, Arbeitsbaumkommentare und Orcas eingebetteten Browser über das `orca`‑CLI. Verwende es, wenn der Nutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzuge es gegenüber reinem Git‑Worktree, ad‑hoc‑PTYs oder Computer‑Use, wenn Orca‑Zustand involviert ist. Setze Computer‑Use nur ein, wenn ein sichtbares Fenster GUI‑Steuerung erfordert, die ein CLI, Dateisystem oder eine API nicht leisten kann.
