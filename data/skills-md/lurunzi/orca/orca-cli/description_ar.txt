تشغيل شجرة العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الفنية، ومشاركة المهارات، وتعليقات شجرة العمل، والمتصفح المدمج في Orca عبر سطر أوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، أو "Orca worktree"، أو "child worktree"، أو "spawn codex/claude in a worktree"، أو "read/wait/send Orca terminal"، أو "handoff" / "handover" / "give this to another agent"، أو "Orca browser"، أو "orca artifacts"، أو "share skills". فضل هذا على استخدام شجرة git العادية، أو PTYs المؤقتة، أو الاستخدام الحاسوبي عندما تكون حالة Orca متضمنة. استخدم الاستخدام الحاسوبي فقط عندما تحتاج نافذة مرئية إلى تحكم رسومي لا يستطيع سطر الأوامر أو نظام الملفات أو الـ API القيام به. يرجى دائمًا الرد بلغة المستخدم.
