يقوم بإعداد وتشغيل ذاكرة وكيل TencentDB (MemoryCore + MemoryHub + MemoryProxy + MemoryPanel، من AnEntrypoint/agent-memory) — نظام ذاكرة ومعرفة دائم وعابر للجلسات لوكلاء الذكاء الاصطناعي. ذاكرة الدردشة (L0 محادثة → L1 ذرة → L2 سيناريو → L3 شخصية)، مكتبة مهارات مُصدَّرة من الأعمال السابقة ومُصدَّرة بإصدارات، خريطة معرفة Wiki + CodeGraph تغطي الوثائق والكود، ولوحة مراجعة يتحكم فيها البشر. يُستخدم عندما يرغب المستخدم في أن يتشارك فريق الوكلاء الذاكرة/المهارات/المعرفة عبر الجلسات وعبر أطر عمل متعددة (ليس فقط جلسة Claude Code هذه)، عندما يذكرون “محور الذاكرة”، “ذاكرة الفريق”، “ذاكرة الدردشة”، “مكتبة المهارات”، “ويكي”، “كودجراف”، أو يطلبون تثبيت/تكوين/استكشاف أخطاء إضافة memory‑tencentdb، أو عند دمج وكيل جديد في خبرة الفريق المتراكمة. اعتبارًا من إضافة tencentdb_backend الخاصة بـ gm، يمكن أن يكون تنسيق هذا النظام أيضًا خلفية gm الخاصة بالتذكر/الاسترجاع/تشغيل‑التذكر/تقليم‑التذكر لمجال أسماء مختار (انظر memory.tencentdb_backend في gm.config.json) — عندما يتم تمكين ذلك، يبقى السطح الفعلي للفعل الذي يعرفه الوكيل دون تغيير؛ فقط هدف التخزين يتغير. استخدم هذه المهارة للنشر المستقل (Docker Compose، واجهة لوحة التحكم، مراجعة الفريق) أو عندما لا تكون الخلفية الخاصة بـ gm هي المطلوبة.  

يرجى دائمًا الرد بلغة المستخدم.
