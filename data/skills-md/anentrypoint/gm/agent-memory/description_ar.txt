يقوم بتثبيت وتشغيل وكيل ذاكرة TencentDB (MemoryCore + MemoryHub + MemoryProxy + MemoryPanel، من AnEntrypoint/agent-memory) — نظام ذاكرة ومعرفة ثابت وعابر للجلسات للوكالات الذكائية. ذاكرة الدردشة (محادثة L0 → ذرة L1 → سيناريو L2 → شخصية L3)، مكتبة مهارات مُصدرة ومُصدَّرَة من الأعمال السابقة، خريطة معرفة Wiki + CodeGraph تغطي الوثائق والشفرة، ولوحة مراجعة يتحكم فيها البشر. يُستَخدم عندما يرغب المستخدم في فريق من الوكالات لمشاركة وتراكم الذاكرة/المهارات/المعرفة عبر الجلسات وعبر أطر وكالات متعددة (ليس فقط جلسة Claude Code الحالية)، عندما يذكر المصطلحات مثل "memory hub"، "team memory"، "chat memory"، "skill library"، "wiki"، "codegraph"، أو يطلب تثبيت/تهيئة/استكشاف أخطاء مكوّن إضافة memory‑tencentdb، أو عند دمج وكيل جديد في خبرة فريق موجودة مُجمَّعة. مع إضافة gm’s tencentdb_backend، يمكن أن يكون تنسيق هذا النظام أيضًا هو backend الخاص بـ gm للذاكرة/الاسترجاع/التذكر‑الإطلاق/تقليم‑التذكر لنطاق اسم مُختار (انظر gm.config.json’s memory.tencentdb_backend) — عندما يُفعَّل، يبقى الفعل الظاهر للوكيل كما هو؛ يتغير فقط هدف التخزين. استخدم هذه المهارة للنشر المستقل (Docker Compose، واجهة لوحة التحكم، مراجعة الفريق) أو عندما لا يكون backend الخاص بـ gm هو المطلوب.
