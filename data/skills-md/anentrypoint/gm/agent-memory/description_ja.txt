TencentDB Agent Memory（MemoryCore＋MemoryHub＋MemoryProxy＋MemoryPanel、AnEntrypoint/agent-memory から）をセットアップし、駆動します――AI エージェント向けの永続的でセッション間をまたぐメモリと知識のシステムです。Chat Memory（L0 会話 → L1 アトム → L2 シナリオ → L3 パーソナ）、過去の作業から抽出したバージョン管理されたスキルライブラリ、ドキュメントとコード上の Wiki＋CodeGraph 知識マップ、そして人間が管理するレビュー パネルがあります。ユーザーがエージェントチームにセッション間・複数のエージェントフレームワーク（この Claude Code セッションだけでなく）でメモリ／スキル／知識を共有・蓄積させたい場合、または「memory hub」「team memory」「chat memory」「skill library」「wiki」「codegraph」と言及したり、memory‑tencentdb プラグインのインストール／設定／トラブルシュートを求めたり、既存チームの蓄積された経験に新しいエージェントをオンボーディングする場合に使用します。gm の tencentdb_backend 追加により、このシステムの形式は gm 独自の memorize／recall／memorize‑fire／memorize‑prune バックエンドとしても利用でき（オプトインした名前空間を参照、gm.config.json の memory.tencentdb_backend を参照）、有効化されている場合はエージェントがすでに知っている動詞表層は変わらず、保存先だけが変わります。スタンドアロン展開（Docker Compose、パネル UI、チームレビュー）や、gm の独自バックエンドが求められていない場合にこのスキルを使用してください。常にユーザーの言語で応答してください。
