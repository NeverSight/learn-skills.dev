TencentDBエージェントメモリ（MemoryCore + MemoryHub + MemoryProxy + MemoryPanel、AnEntrypoint/agent-memory から）をセットアップし、駆動します――AIエージェント向けの永続的でセッション間を跨ぐメモリおよび知識システムです。Chat Memory（L0 会話 → L1 アトム → L2 シナリオ → L3 ペルソナ）、過去の成果から抽出したバージョン管理されたスキルライブラリ、ドキュメントとコード上の Wiki + CodeGraph 知識マップ、そして人間が管理するレビュー パネルが含まれます。ユーザーがエージェントチームにセッション間および複数のエージェントフレームワーク（この Claude Code セッションだけでなく）でメモリ／スキル／知識を共有・蓄積させたいと望むとき、または「memory hub」「team memory」「chat memory」「skill library」「wiki」「codegraph」と言及したとき、あるいは memory‑tencentdb プラグインのインストール・設定・トラブルシュートを求めたとき、さらに既存チームの蓄積経験に新しいエージェントをオンボーディングする際に使用します。gm の tencentdb_backend が追加されたことにより、このシステムのフォーマットは gm の独自 memorize/recall/memorize‑fire/memorize‑prune バックエンドをオプトインした名前空間でも利用可能です（gm.config.json の memory.tencentdb_backend を参照）。このオプションが有効な場合、エージェントが既に知っている動詞表現は変わらず、保存先だけが変更されます。このスキルはスタンドアロン展開（Docker Compose、パネル UI、チームレビュー）や、gm の独自バックエンドが求められていない場合に使用してください。
