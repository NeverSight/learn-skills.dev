Configura y controla el Agente de Memoria de TencentDB (MemoryCore + MemoryHub + MemoryProxy + MemoryPanel, de AnEntrypoint/agent-memory): un sistema de memoria y conocimiento persistente y multiplataforma para agentes de IA. Memoria de Chat (conversación L0 → átomo L1 → escenario L2 → persona L3), una biblioteca de habilidades versionada extraída de trabajos anteriores, un mapa de conocimiento Wiki + CodeGraph sobre documentos y código, y un panel de revisión controlado por humanos. Úsalo cuando el usuario quiera que un equipo de agentes comparta y acumule memoria/habilidades/conocimiento a lo largo de sesiones y de múltiples marcos de agentes (no solo esta sesión de Claude Code), cuando mencione “memory hub”, “team memory”, “chat memory”, “skill library”, “wiki”, “codegraph”, o solicite instalar/configurar/solucionar problemas del plugin memory‑tencentdb, o al integrar un nuevo agente en la experiencia acumulada de un equipo existente. A partir de la adición de tencentdb_backend por parte de gm, el formato de este sistema también puede ser el backend propio de gm para memorizar/recuperar/memorize‑fire/memorize‑prune en un espacio de nombres opt‑in (ver gm.config.json → memory.tencentdb_backend); cuando está habilitado, el verbo que el agente ya conoce no cambia, solo cambia el objetivo de almacenamiento. Usa esta habilidad para el despliegue independiente (Docker Compose, interfaz del panel, revisión del equipo) o cuando el backend propio de gm no es lo que se está solicitando.
