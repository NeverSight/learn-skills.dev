Configura y controla la memoria del agente TencentDB (MemoryCore + MemoryHub + MemoryProxy + MemoryPanel, de AnEntrypoint/agent‑memory) — un sistema de memoria y conocimiento persistente y de sesión cruzada para agentes de IA. Memoria de chat (L0 conversación → L1 átomo → L2 escenario → L3 personalidad), una biblioteca de habilidades versionada extraída de trabajos anteriores, un mapa de conocimiento Wiki + CodeGraph sobre documentos y código, y un panel de revisión controlado por humanos. Úsalo cuando el usuario quiera que un equipo de agentes comparta y acumule memoria/habilidades/conocimiento a través de sesiones y de múltiples marcos de agentes (no solo esta sesión de Claude Code), cuando mencione “memory hub”, “team memory”, “chat memory”, “skill library”, “wiki”, “codegraph”, o solicite instalar/configurar/solucionar problemas del plugin memory‑tencentdb, o al incorporar un nuevo agente a la experiencia acumulada de un equipo existente. A partir de la incorporación del tencentdb_backend de gm, el formato de este sistema también puede ser el backend propio de gm para memorizar/recuperar/memorize‑fire/memorize‑prune en un espacio de nombres opt‑in (ver memory.tencentdb_backend en gm.config.json) — cuando está habilitado, la superficie verbal que ya conoce un agente no cambia; solo se desplaza el objetivo de almacenamiento. Usa esta habilidad para el despliegue independiente (Docker Compose, interfaz del panel, revisión del equipo) o cuando el backend propio de gm no es lo que se está solicitando.
