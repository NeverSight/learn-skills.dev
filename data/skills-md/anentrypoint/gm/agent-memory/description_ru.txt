Настраивает и управляет TencentDB Agent Memory (MemoryCore + MemoryHub + MemoryProxy + MemoryPanel, из AnEntrypoint/agent-memory) — постоянной, кросс‑сеансовой системой памяти и знаний для AI‑агентов. Chat Memory (L0 разговор → L1 атом → L2 сценарий → L3 персона), версионная библиотека навыков, извлечённая из прошлой работы, Wiki + CodeGraph карта знаний по документам и коду, а также панель ручного контроля. Используйте, когда пользователь хочет, чтобы команда агентов делилась и накапливала память/навыки/знания между сеансами и между несколькими фреймворками агентов (не только в этой сессии Claude Code), когда они упоминают «memory hub», «team memory», «chat memory», «skill library», «wiki», «codegraph», или просят установить/настроить/исправить плагин memory‑tencentdb, либо при вводе нового агента в уже накопленный опыт команды. Начиная с добавления tencentdb_backend от gm, формат этой системы может также служить как собственный backend gm для memorize/recall/memorize‑fire/memorize‑prune в выбранном пространстве имён (см. gm.config.json → memory.tencentdb_backend) — когда он включён, глагольный интерфейс, который агент уже знает, не меняется; меняется только цель хранения. Используйте этот навык для самостоятельного развёртывания (Docker Compose, UI панели, командный обзор) или когда собственный backend gm не является тем, о чём спрашивают.
