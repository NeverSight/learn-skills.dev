Настраивает и управляет памятью агента TencentDB (MemoryCore + MemoryHub + MemoryProxy + MemoryPanel, из AnEntrypoint/agent-memory) — постоянной системой памяти и знаний для AI‑агентов, работающей между сеансами. Чат‑память (L0 разговор → L1 атом → L2 сценарий → L3 персона), версия библиотеки навыков, извлечённая из прошлых работ, карта знаний Wiki + CodeGraph по документам и коду, а также панель рецензирования, управляемая людьми. Использовать, когда пользователь хочет, чтобы команда агентов делилась и накапливала память/навыки/знания между сеансами и между разными фреймворками агентов (не только в текущей сессии Claude Code), когда он упоминает «memory hub», «team memory», «chat memory», «skill library», «wiki», «codegraph» или просит установить/настроить/исправить плагин memory‑tencentdb, либо при вводе нового агента в уже накопленный опыт команды. Начиная с добавления tencentdb_backend от gm, формат этой системы может также быть бекендом gm для функций memorize/recall/memorize‑fire/memorize‑prune в выбранном пространстве имён (см. gm.config.json → memory.tencentdb_backend) — при включённом режиме глагольный интерфейс, знакомый агенту, остаётся прежним; меняется лишь место хранения. Применять этот навык при автономном развертывании (Docker Compose, UI панели, командный обзор) или когда речь не идёт о собственном бекенде gm.
