设置并驱动 TencentDB 代理记忆（MemoryCore + MemoryHub + MemoryProxy + MemoryPanel，来源于 AnEntrypoint/agent-memory）——一个面向 AI 代理的持久化、跨会话记忆与知识系统。聊天记忆（L0 对话 → L1 原子 → L2 场景 → L3 角色），以及从以往工作中提取的版本化技能库、覆盖文档和代码的 Wiki + CodeGraph 知识图谱和由人工控制的审查面板。当用户希望代理团队在会话之间、跨多个代理框架（不仅限于当前的 Claude Code 会话）共享并累积记忆/技能/知识时使用；当他们提到“memory hub”“team memory”“chat memory”“skill library”“wiki”“codegraph”，或请求安装/配置/排查 memory‑tencentdb 插件，亦或在将新代理加入已有团队的累计经验时使用。自 gm 添加 tencentdb_backend 起，该系统的格式也可作为 gm 自己的 memorize/recall/memorize‑fire/memorize‑prune 后端用于已选命名空间（见 gm.config.json 的 memory.tencentdb_backend）——启用后，代理已知的动词表保持不变，只有存储目标迁移。使用此技能进行独立部署（Docker Compose、面板 UI、团队审查）或当问题不涉及 gm 自己的后端时。
