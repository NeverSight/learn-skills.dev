Installe et gère la Mémoire d'Agent TencentDB (MemoryCore + MemoryHub + MemoryProxy + MemoryPanel, provenant de AnEntrypoint/agent-memory) — un système de mémoire et de connaissance persistant, intersession, pour les agents IA. Mémoire de Chat (conversation L0 → atome L1 → scénario L2 → persona L3), une bibliothèque de compétences versionnée extraite de travaux antérieurs, une carte de connaissance Wiki + CodeGraph couvrant les documents et le code, et un panneau de révision contrôlé par des humains. À utiliser lorsque l'utilisateur souhaite qu'une équipe d'agents partage et accumule mémoire/compétences/connaissances sur plusieurs sessions et sur plusieurs cadres d'agents (pas uniquement cette session Claude Code), lorsqu'il mentionne « memory hub », « team memory », « chat memory », « skill library », « wiki », « codegraph », ou demande d'installer/configurer/diagnostiquer le plugin memory‑tencentdb, ou lors de l'intégration d'un nouvel agent dans l'expérience accumulée d'une équipe existante. Depuis l'ajout du tencentdb_backend de gm, le format de ce système peut également être le backend propre à gm (memorize/recall/memorize-fire/memorize-prune) pour un espace de noms opt‑in (voir memory.tencentdb_backend dans gm.config.json) — lorsque cela est activé, la surface verbale déjà connue de l'agent reste inchangée ; seul le support de stockage change. Utilisez cette compétence pour le déploiement autonome (Docker Compose, interface du panneau, révision d'équipe) ou lorsque le backend propre à gm n'est pas celui demandé.
