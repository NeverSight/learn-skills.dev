Installe et pilote la Mémoire d'Agent TencentDB (MemoryCore + MemoryHub + MemoryProxy + MemoryPanel, provenant de AnEntrypoint/agent‑memory) — un système de mémoire et de connaissances persistant, multi‑session, destiné aux agents IA. Mémoire de Chat (conversation L0 → atome L1 → scénario L2 → persona L3), une bibliothèque de compétences versionnée extraite de travaux précédents, une carte de connaissances Wiki + CodeGraph couvrant les documents et le code, et un panel de révision contrôlé par des humains. À utiliser lorsque l'utilisateur souhaite qu'une équipe d'agents partage et accumule des mémoires/compétences/connaissances à travers les sessions et plusieurs frameworks d'agents (pas seulement cette session Claude Code), lorsqu'il mentionne « memory hub », « team memory », « chat memory », « skill library », « wiki », « codegraph », ou demande d'installer/configurer/dépanner le plugin memory‑tencentdb, ou lors de l'intégration d'un nouvel agent dans l'expérience accumulée d'une équipe existante. Depuis l'ajout du tencentdb_backend de gm, le format de ce système peut EN PLUS être le backend propre de gm (memorize/recall/memorize‑fire/memorize‑prune) pour un espace de noms opt‑in (voir memory.tencentdb_backend dans gm.config.json) — lorsque cela est activé, la surface verbale qu'un agent connaît déjà reste inchangée ; seul le cible de stockage bouge. Utilisez cette compétence pour le déploiement autonome (Docker Compose, UI du panel, révision d'équipe) ou lorsque le backend propre de gm n'est pas celui demandé.
