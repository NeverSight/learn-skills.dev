設置並驅動 TencentDB Agent Memory（MemoryCore + MemoryHub + MemoryProxy + MemoryPanel，來源於 AnEntrypoint/agent-memory）——一個持久的跨會話記憶與知識系統，供 AI 代理使用。Chat Memory（L0 對話 → L1 原子 → L2 情境 → L3 人格），一個從過往工作中提取的具版本化的技能庫，還有覆蓋文檔與程式碼的 Wiki + CodeGraph 知識圖譜，以及由人工控制的審核面板。當使用者希望代理團隊在多個會話、跨多個代理框架（不僅限於本次 Claude Code 會話）共享與累積記憶／技能／知識，或提及「memory hub」、「team memory」、「chat memory」、「skill library」、「wiki」、「codegraph」，或要求安裝／配置／排除 memory‑tencentdb 插件的問題，或在將新代理加入已有團隊的累積經驗時，使用此功能。自 gm 的 tencentdb_backend 新增後，該系統的格式亦可作為 gm 自己的 memorize/recall/memorize‑fire/memorize‑prune 後端，供選擇性命名空間使用（見 gm.config.json 中的 memory.tencentdb_backend）——啟用時，代理已知的動詞表面保持不變，僅存儲目標改變。當需要獨立部署（Docker Compose、面板 UI、團隊審核）或 gm 自有後端並非所詢問的情境時，請使用此技能。
