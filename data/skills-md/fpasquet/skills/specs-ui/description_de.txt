Erstellt und pflegt UI‑Spezifikationen, die in HTML + Tailwind CSS modelliert sind: annotierte Desktop‑ und Mobile‑Screens, Nutzerflüsse, funktionale Regeln, offene Punkte und Iterationsprotokoll, um an einer Anwendung oder einem Tool vor der Entwicklung zu iterieren. Wenn die Oberfläche noch nicht genehmigt ist, werden zunächst drei Varianten vorgeschlagen, die sich in der Anordnung (Navigation, Bildschirmanordnung) und im Design (Farben, Typografie, Formen) unterscheiden, zum Auswählen oder Kombinieren. Kann auch von einer bestehenden Website oder vorhandenem Code ausgehen, um dessen Stil zu übernehmen und neue Funktionen zu spezifizieren. Verwenden, sobald jemand über Mockups, Wireframes, UI‑Specs, funktionale Spezifikationen mit Screens, Interface‑Prototyp, zu modellierende Flüsse, Styleguide oder grafische Richtung für eine App oder neue Funktion auf einer bestehenden Website spricht, selbst wenn nicht das Wort „Specs“ genannt wird. Auch während der Entwicklung, um die Specs mit der Implementierung aktuell zu halten (Screen‑Status, Abweichungen).
