Crea y hace evolucionar especificaciones UI maquetadas en HTML + Tailwind CSS: pantallas de escritorio y móvil anotadas, recorridos, reglas funcionales, puntos abiertos y registro de iteraciones, para iterar sobre una aplicación o herramienta antes del desarrollo. Si la interfaz aún no está validada, propone primero tres opciones que difieren en la disposición (navegación, organización de pantallas) y en el tema (colores, tipografía, formas), para elegir o combinar. También puede partir de un sitio o código existente para retomar su estilo y especificar nuevas funcionalidades. Utilizar siempre que la persona hable de maquetas, wireframes, specs UI, especificaciones funcionales con pantallas, prototipo de interfaz, recorrido a maqueter, guía o dirección gráfica para una app, o nueva funcionalidad a maqueter en un sitio existente, incluso sin pronunciar la palabra «specs». También durante los desarrollos, para mantener las specs actualizadas con la implementación (estado de las pantallas, desviaciones).
