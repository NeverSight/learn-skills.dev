HTML + Tailwind CSS로 만든 UI 사양을 생성하고 진화시킵니다: 주석이 달린 데스크톱 및 모바일 화면, 플로우, 기능 규칙, 열린 이슈와 반복 일지를 포함하여, 개발 전에 애플리케이션이나 도구를 반복합니다. 인터페이스가 아직 승인되지 않은 경우, 레이아웃(네비게이션, 화면 구성)과 테마(색상, 타이포그래피, 형태)에서 차별화된 세 가지 제안을 먼저 제시하고, 선택하거나 결합하도록 합니다. 기존 사이트나 코드를 기반으로 스타일을 이어받아 새로운 기능을 명세할 수도 있습니다. 사용자가 모델, 와이어프레임, UI 스펙, 화면이 포함된 기능 명세, 인터페이스 프로토타입, 모델링해야 할 플로우, 앱을 위한 차트나 그래픽 방향, 혹은 기존 사이트에 추가할 새로운 기능 등에 대해 언급하면 바로 활용하십시오. ‘specs’라는 단어를 쓰지 않아도 됩니다. 또한 개발 중에도 구현 상황에 맞춰 사양을 최신 상태로 유지합니다(화면 상태, 차이점).
