أنشئ أو صلِّن أو انقل نظام التصميم لتطبيق React باستخدام Tailwind CSS v4: رموز (tokens) بمصدر موحَّد، سمة shadcn/ui وdaisyUI موجهة إلى الرموز، فئات دلالية (btn، btn-primary، card) للمشروع أو daisyUI موضوعة عبر متغيّرات CVA للمكوّنات (shadcn/ui على Radix أو Base UI)، بدون data-slot، مجلد واحد لكل مكوّن، Storybook (صفحات الرموز والفئات، قابلية الوصول عائق)، وتدقيق (lint) الفئات (بدون قيمة عشوائية ولا لون من اللوحة). استخرج الرموز والفئات من الشيفرة الحالية، نظم المكوّنات التي أضيفت عبر CLI الخاص بـ shadcn، وقم بقياس الفجوة عن المعايير من خلال تدقيق. استخدم ذلك كلما تحدث الشخص عن نظام التصميم أو الرموز أو Storybook أو shadcn/ui أو daisyUI أو Radix أو Base UI أو الفئات الدلالية أو السمة أو الوضع الداكن أو توحيد الواجهة أو نقل الأنماط (Tailwind v3، وحدات CSS، مكتبة مكوّنات) أو إضافة مكوّن واجهة مشترك، حتى وإن لم يذكر «نظام التصميم».
