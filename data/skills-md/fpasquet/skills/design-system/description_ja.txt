React アプリケーションのデザインシステムを Tailwind CSS v4 で作成、維持、または移行する：トークンは単一ソース、テーマは shadcn/ui と daisyUI がトークンを参照、プロジェクトまたは daisyUI のセマンティッククラス（btn、btn‑primary、card）はコンポーネントの CVA バリアント（shadcn/ui が Radix または Base UI 上）で配置、data‑slot は使用せず、コンポーネントごとにフォルダを作成、Storybook（Tokens と Classes のページ、アクセシビリティが阻害要因）とクラスの lint（任意の値やパレットカラーは不可）。既存コードからトークンとクラスを抽出し、shadcn の CLI で追加されたコンポーネントを整理し、監査で規約との乖離を測定する。デザインシステム、トークン、Storybook、shadcn/ui、daisyUI、Radix、Base UI、セマンティッククラス、テーマまたはダークモード、インターフェースの統一、スタイルの移行（Tailwind v3、CSS モジュール、コンポーネントライブラリ）や共有インターフェースコンポーネントの追加について言及されたら、たとえ「デザインシステム」と言わなくても使用する。
