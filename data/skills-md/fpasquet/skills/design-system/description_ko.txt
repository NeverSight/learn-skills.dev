React 애플리케이션의 디자인 시스템을 Tailwind CSS v4로 생성, 유지 또는 마이그레이션합니다: 단일 소스 토큰, 토큰을 가리키는 shadcn/ui 테마와 daisyUI, 프로젝트 또는 daisyUI의 의미론적 클래스(btn, btn-primary, card)를 구성 요소의 CVA 변형(shadcn/ui on Radix 또는 Base UI)으로 배치, data‑slot 없이, 구성 요소당 하나의 폴더, Storybook(토큰 및 클래스 페이지, 차단되는 접근성) 및 클래스 린트(임의 값이나 팔레트 색상 없음). 기존 코드에서 토큰과 클래스를 추출하고, shadcn CLI로 추가된 구성 요소를 정리하며, 감사를 통해 규칙과의 차이를 측정합니다. 디자인 시스템, 토큰, Storybook, shadcn/ui, daisyUI, Radix, Base UI, 의미론적 클래스, 테마 또는 다크 모드, 인터페이스 통일, 스타일 마이그레이션(Tailwind v3, CSS 모듈, 컴포넌트 라이브러리) 또는 공유 UI 컴포넌트 추가에 대해 언급하면, “디자인 시스템”이라고 말하지 않아도 사용합니다.
