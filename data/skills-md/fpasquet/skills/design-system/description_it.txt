Crea, mantiene o migra il design system di un'applicazione React con Tailwind CSS v4: token in fonte unica, tema shadcn/ui e daisyUI puntato sui token, classi semantiche (btn, btn-primary, card) del progetto o di daisyUI impostate dalle varianti CVA dei componenti (shadcn/ui su Radix o Base UI), senza data-slot, una cartella per componente, Storybook (pagine Tokens e Classes, accessibilità bloccante) e lint delle classi (né valore arbitrario né colore della palette). Estrai i token e le classi dal codice esistente, organizza i componenti aggiunti dalla CLI di shadcn e misura lo scostamento dalle convenzioni tramite un audit. Utilizzare non appena la persona parla di design system, di token, di Storybook, di shadcn/ui, di daisyUI, di Radix, di Base UI, di classi semantiche, di tema o di modalità scura, di uniformare l'interfaccia, di migrare stili (Tailwind v3, CSS modules, libreria di componenti) o di aggiungere un componente di interfaccia condiviso, anche senza dire «design system».
