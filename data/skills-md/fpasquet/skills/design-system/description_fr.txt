Crée, maintient ou migre le design system d'une application React avec Tailwind CSS v4 : tokens en source unique, thème shadcn/ui et daisyUI pointé sur les tokens, classes sémantiques (btn, btn-primary, card) du projet ou de daisyUI posées par les variantes CVA des composants (shadcn/ui sur Radix ou Base UI), sans data-slot, un dossier par composant, Storybook (pages Tokens et Classes, accessibilité bloquante) et lint des classes (ni valeur arbitraire ni couleur de la palette). Tire les tokens et les classes du code existant, range les composants ajoutés par la CLI de shadcn, et mesure l'écart aux conventions par un audit. Utiliser dès que la personne parle de design system, de tokens, de Storybook, de shadcn/ui, de daisyUI, de Radix, de Base UI, de classes sémantiques, de thème ou de mode sombre, d'uniformiser l'interface, de migrer des styles (Tailwind v3, CSS modules, bibliothèque de composants) ou d'ajouter un composant d'interface partagé, même sans dire « design system ».
