創建、維護或遷移使用 Tailwind CSS v4 的 React 應用程式的設計系統：單一來源的 token、指向 token 的 shadcn/ui 與 daisyUI 主題、由組件的 CVA 變體（shadcn/ui 基於 Radix 或 Base UI）提供的語意化類別（btn、btn-primary、card），不使用 data‑slot，每個組件一個資料夾，Storybook（Tokens 與 Classes 頁面，無障礙性為必須）以及類別 lint（無任意值或調色盤顏色）。從現有程式碼中提取 token 與類別，整理由 shadcn CLI 新增的組件，並透過審核測量與慣例的差距。只要有人提到設計系統、token、Storybook、shadcn/ui、daisyUI、Radix、Base UI、語意化類別、主題或深色模式、統一介面、遷移樣式（Tailwind v3、CSS modules、元件庫）或加入共享介面元件，即使未說「設計系統」也要使用此規則。
