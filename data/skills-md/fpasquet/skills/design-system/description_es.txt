Crear, mantener o migrar el design system de una aplicación React con Tailwind CSS v4: tokens en una única fuente, tema shadcn/ui y daisyUI apuntando a los tokens, clases semánticas (btn, btn-primary, card) del proyecto o de daisyUI definidas por las variantes CVA de los componentes (shadcn/ui sobre Radix o Base UI), sin data‑slot, una carpeta por componente, Storybook (páginas Tokens y Clases, accesibilidad bloqueante) y lint de las clases (ni valor arbitrario ni color de la paleta). Extrae los tokens y las clases del código existente, organiza los componentes añadidos por la CLI de shadcn, y mide la desviación de las convenciones mediante una auditoría. Utilizar siempre que la persona hable de design system, de tokens, de Storybook, de shadcn/ui, de daisyUI, de Radix, de Base UI, de clases semánticas, de tema o modo oscuro, de uniformizar la interfaz, de migrar estilos (Tailwind v3, CSS modules, biblioteca de componentes) o de añadir un componente de interfaz compartido, incluso sin decir «design system».
