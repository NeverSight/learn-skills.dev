创建、维护或迁移使用 Tailwind CSS v4 的 React 应用的设计系统：单一来源的 token、基于 token 的 shadcn/ui 与 daisyUI 主题、项目或 daisyUI 提供的语义类（btn、btn‑primary、card），通过组件的 CVA 变体（shadcn/ui 基于 Radix 或 Base UI）实现，无 data‑slot，每个组件一个文件夹，Storybook（Tokens 与 Classes 页面，阻塞性可访问性）以及类的 lint（不允许任意值或调色板颜色）。从现有代码中提取 token 和类，整理由 shadcn CLI 添加的组件，并通过审计测量与规范的差距。只要有人提到设计系统、token、Storybook、shadcn/ui、daisyUI、Radix、Base UI、语义类、主题或暗模式、统一界面、迁移样式（Tailwind v3、CSS modules、组件库）或添加共享界面组件，即使未说“设计系统”，也应使用此规则。
