# 用图说明系统

使用随 Skill 提供的 TypeScript 接口，交付可离线阅读的 HTML 和生成它的内容脚本。

## 内容组织

结构问题用架构图，调用、异步消息和并发交互用时序图，跨负责方的活动流转用泳道图，条目或版本的延续与分叉用演化图。需要多种组件视角时，按实际身份跨图复用对象。每张图围绕一个问题组织，图外文字说明背景和结论，图内名称与关系标签保持简短、具体。

多图报告让各节保持一致的阅读顺序，通常先用标题和一句要点引出图，再展开细节。架构图中未接入主图的节点或小组，应说明它们与当前问题的关系；根据实际依赖补连线，或明确其独立用途，不为连通图形虚构依赖。

按需查阅 [API 索引](references/api.md)：[架构图](references/architecture.md)、[时序图](references/sequence.md)、[泳道图](references/swimlane.md)、[演化图](references/evolution.md)、[Markdown](references/markdown.md)。组合示例见 [self-explanation.ts](examples/self-explanation.ts)，流程示例见 [swimlane.ts](examples/swimlane.ts)，历史示例见 [evolution.ts](examples/evolution.ts)。

架构和时序对象表示实际组件，泳道对象表示流程活动；不要把执行者与其执行的活动当作同一对象。演化图使用本图内的历史记录，不进入共享对象表。

各类图表定义自己的组织方式。架构图使用专属的分区，按共同职责或归属对组件分组，具体规则见[架构图](references/architecture.md#分区)。泳道图使用泳道，按活动的负责方分组，具体规则见[泳道图](references/swimlane.md)。时序图通过参与者、消息、互斥与并发片段组织交互过程。

架构、时序和泳道的节点尺寸，以及架构与泳道节点位置由内容脚本声明；泳道还声明共用宽度和各自高度，可通过图表级 `headerWidth` 调整标题栏宽度。生成器保留声明的几何尺寸与位置；页面将整图等比例适应可用宽度。时序同步调用必须配对返回；异步消息使用 `kind: 'async'`，不带 `replyTo`，也不自动生成执行条。`kind: 'parallel'` 的各分支独立配对同步调用，外层调用在片段后返回。并发分支上下排列不表示先后，片段结束不自动等待异步后台工作。泳道回退使用普通方向关系。

演化图按 `entries` 的声明顺序从上向下排列，通过 `parent` 指定更早的来源。每条记录直接声明 `id`、`label`、`time`，文字贴在其历史线旁，排版由生成器负责。`time` 仅为显示标签，不解析或排序；行距不代表实际时长。`branches` 的 `head` 指定具名分支末端，名称直接附在记录旁，`current` 指定初始浏览位置。点击记录选择完整来源路径。当前支持单来源的树形历史，不表达合并或状态机。

声明架构图和泳道图时，先确定主要流程的行列中心线，再按节点尺寸计算位置。上下直连的节点对齐水平中心，左右直连的节点对齐垂直中心；宽高不同时，只对齐左边缘或上边缘会让边中点错开，产生不必要的小折线。跨分区或泳道比较时使用画布坐标，具体计算见各图表的坐标说明。分支、回退和避障所需的转折可以保留。

## 生成

需要 Node.js 22.18+，直接运行源码，无需安装依赖或 build。

在用户工作目录编写 `report.ts`：从本 Skill 的 `src/index.ts` 导入接口，相对路径以 `report.ts` 所在目录为基准，默认导出由 `document().markdown(...).diagram(...)` 组合的文档。只追加一张图即可生成单图。

将 `<skill>` 替换为本 Skill 目录的路径，运行。命令中的相对路径以终端当前目录为基准：

```sh
node "<skill>/src/cli.ts" report.ts -o report.html
```

生成时自动检查内容与布局。失败后按诊断修改内容脚本，再次运行；不要修改生成的 HTML 来绕过问题。

## 检查与交付

打开 HTML，在宽屏和窄屏检查正文自然换行、整图适应宽度，以及文字、连线、分区、泳道边界、调用顺序、异步箭头、并发片段和历史来源，以及节点详情与关联定位。演化图还应检查切换条目后的完整路径与分支名称。修改后重新生成。交付 HTML 和内容脚本的链接；HTML 已内嵌样式与交互，无需服务器。

若预期直连的节点出现折线，先检查画布中的中心线，再检查标签能否放入连接间隙、分区标题是否挡住路径。按原因调整声明；跨分区的留白安排见[架构图坐标说明](references/architecture.md#坐标与尺寸)。
