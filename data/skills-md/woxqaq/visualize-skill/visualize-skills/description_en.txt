Create interactive HTML for offline reading that captures system architecture, component dependencies, synchronous and asynchronous interactions, cross‑responsibility processes, and historical evolution. It is used when users need to draw architecture diagrams, sequence diagrams, swimlane diagrams, evolution diagrams, or combine charts with textual explanations of technical solutions. It supports single‑image, multi‑image reports and node‑link navigation, and is not intended for statistical charts or web page interface design.
