Intégrez OpenGeni dans un produit externe, un site Web, un backend, une interface en ligne de commande ou une automatisation. Par défaut, intégrez la conversation complète React derrière le proxy de session du SDK empaqueté. Utilisez‑le pour la découverte, la connexion de dépôts et de ressources, les choix SDK/API et React, l’implémentation, la vérification et le transfert dans le cadre d’un déploiement OpenGeni géré, auto‑hébergé ou local, y compris les capacités de l’agent, l’identité, la confidentialité des discussions et la migration de sessions archivées uniquement côté serveur. Ne l’utilisez pas pour modifier les internes d’OpenGeni ou monter son runtime à l’intérieur du processus du client.
