OpenGeni を外部製品、ウェブサイト、バックエンド、CLI、または自動化に統合します。デフォルトでは、パッケージ化された SDK セッションプロキシの背後に完全な React 会話を埋め込みます。発見、リポジトリやリソースの接続、SDK/API および React の選択、実装、検証、引き渡しに使用し、管理された環境、セルフホスト、またはローカルの OpenGeni デプロイに対して、エージェントの機能、アイデンティティ、チャットのプライバシー、サーバー専用のアーカイブセッション移行を含みます。OpenGeni の内部を変更したり、顧客プロセス内にランタイムをマウントしたりするためのものではありません。
