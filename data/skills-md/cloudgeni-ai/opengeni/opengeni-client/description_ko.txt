OpenGeni를 외부 제품, 웹사이트, 백엔드, CLI 또는 자동화에 통합합니다. 기본값은 패키징된 SDK 세션 프록시 뒤에 전체 React 대화를 포함하는 것입니다. 관리형, 자체 호스팅 또는 로컬 OpenGeni 배포에 대해 탐색, 저장소 및 리소스 연결, SDK/API 및 React 선택, 구현, 검증 및 인수인계를 위해 사용하며, 여기에는 에이전트의 기능, 정체성, 채팅 프라이버시 및 서버 전용 보관 세션 마이그레이션이 포함됩니다. OpenGeni 내부를 변경하거나 고객 프로세스 내부에 런타임을 마운트하는 용도가 아닙니다.
