Opérez les worktrees gérés par Orca, les contextes de dossiers, les terminaux, les dépôts, les automatisations, le partage de compétences, les commentaires de worktree et le navigateur intégré d’Orca via le CLI `orca`. Utilisez-le lorsque l'utilisateur dit « $orca-cli », « Orca worktree », « child worktree », « spawn codex/claude in a worktree », « read/wait/send Orca terminal », « handoff » / « handover » / « give this to another agent », « Orca browser » ou « share skills ». Privilégiez-le plutôt que le worktree Git brut, les PTY ad hoc ou l’Utilisation d’Ordinateur lorsque l’état d’Orca est impliqué. N’utilisez l’Utilisation d’Ordinateur que lorsqu’une fenêtre visible nécessite un contrôle GUI qu’un CLI, le système de fichiers ou une API ne peuvent assurer.  

Veuillez toujours répondre dans la langue de l'utilisateur.
