Betreibe von Orca verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Skill‑Sharing, Arbeitsbaum‑Kommentare und Orcas eingebetteten Browser über die `orca`‑CLI. Verwende sie, wenn der Benutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“/„handover“/„give this to another agent“, „Orca browser“ oder „share skills“. Bevorzuge sie gegenüber rohen Git‑Worktrees, ad‑hoc‑PTYs oder Computer Use, wenn ein Orca‑Zustand beteiligt ist. Nutze Computer Use nur, wenn ein sichtbares Fenster GUI‑Steuerung benötigt, die ein CLI, Dateisystem oder eine API nicht leisten kann.

Bitte antworte immer in der Sprache des Benutzers.
