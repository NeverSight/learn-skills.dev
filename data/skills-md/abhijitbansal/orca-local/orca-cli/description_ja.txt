Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、スキル共有、ワークツリーコメント、そして Orca の組み込みブラウザーを `orca` CLI で操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」「handover」「give this to another agent」「Orca browser」または「share skills」というときに使用してください。Orca の状態が関わる場合は、生の git worktree や臨時の PTY、Computer Use よりもこれを優先してください。CLI、ファイルシステム、API では実現できない GUI 操作が必要で、可視ウィンドウを制御しなければならない場合にのみ Computer Use を使用します。必ずユーザーの言語で応答してください。
