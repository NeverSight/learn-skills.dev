قم بتشغيل أشجار العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، ومشاركة المهارات، وتعليقات أشجار العمل، ومتصفح Orca المدمج عبر واجهة سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، أو "share skills". فضل ذلك على استخدام git worktree الخام أو PTY المتاح عشوائيًا أو استخدام الحاسوب عندما تكون حالة Orca متضمنة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة مستخدم رسومية لا يمكن لسطر الأوامر أو نظام الملفات أو الـ API القيام به.
