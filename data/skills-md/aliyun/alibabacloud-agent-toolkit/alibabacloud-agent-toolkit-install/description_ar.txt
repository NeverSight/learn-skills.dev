قم بتثبيت مجموعة أدوات Alibaba Cloud Agent من البداية إلى النهاية: تحقق من المتطلبات الأساسية وقم بإعدادها (uv، Alibaba Cloud CLI، المصادقة، مكونات CLI الإضافية، MCP Server Core، تبادل الرمز المميز للحامل)، ثم قم بتثبيت مجموعة الأدوات عبر openplugin. يُستخدم عندما: تثبيت مجموعة أدوات وكيل alibabacloud، والتحقق من البيئة، والتحقق من المتطلبات الأساسية، وإعداد alibabacloud، وتثبيت البرنامج المساعد، وإعداد مجموعة الأدوات، وإعداد mcp الأساسي، وإعداد aliyun CLI.
