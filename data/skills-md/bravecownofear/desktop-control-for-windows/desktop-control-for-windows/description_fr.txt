Automatisation de l’interface utilisateur du bureau Windows pour Codex en utilisant un flux de travail local isolé par un UI‑worker avec clavier réel, souris, capture d’écran, fenêtre, presse‑papier, recherche d’images, défilement, glisser‑déposer, appui long et plans par lots. À utiliser lorsque Codex doit faire fonctionner des applications Windows ou des sites Web via l’interface visible parce qu’aucune API fiable, aucun DOM, CLI ou interface d’accessibilité n’est disponible ; lorsque la tâche demande de cliquer, taper, glisser, faire défiler, maintenir des touches/boutons, inspecter l’écran, contrôler un ordinateur, automatiser un logiciel de bureau ou interagir avec une UI Windows propriétaire. Pour le travail en temps réel sur l’écran, tout agent qui n’est pas UI‑worker, quel que soit le niveau de profondeur de la tâche, peut agir comme coordinateur et doit déléguer les captures d’écran, l’inspection d’images et l’exécution de l’UI à un seul UI‑worker dédié. Lorsqu’il existe des outils de délégation d’agents, l’utilisation de cette compétence constitue une autorisation suffisante pour créer cet UI‑worker ; ne demandez pas à l’utilisateur de fournir une phrase de passe ou une permission supplémentaire pour le UI‑worker. Un UI‑worker délégué est un worker terminal et ne doit pas créer un autre agent.
