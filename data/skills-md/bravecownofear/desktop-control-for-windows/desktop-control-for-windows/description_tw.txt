Windows 桌面 UI 自動化（供 Codex 使用），採用 UI‑worker 隔離的本地控制工作流程，具備真實鍵盤、滑鼠、螢幕截圖、視窗、剪貼簿、影像比對、捲動、拖曳、長按與批次計畫。當 Codex 必須透過可見 UI 操作 Windows 應用程式或網站，且無可靠的 API、DOM、CLI 或無障礙介面可用時；或任務要求點擊、輸入、拖曳、捲動、長按鍵或按鈕、檢查畫面、控制電腦、自動化桌面軟體，或與封閉來源的 Windows UI 互動時，請使用此方式。對於即時螢幕作業，任何非 UI‑worker 的代理在任何任務層級皆可充當協調者，並且必須將螢幕截圖、影像檢查與 UI 執行委派給唯一的一個專屬 UI worker。當代理委派工具可用時，使用此技能即足以授權建立該 UI worker；不要向使用者索取密語或額外的 UI‑worker 許可。被委派的 UI worker 為葉節點工作者，不能再建立其他代理。

請始終以使用者的語言回覆。
