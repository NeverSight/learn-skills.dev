أتمتة واجهة المستخدم لسطح المكتب Windows لـ Codex باستخدام سير عمل محلي معزول بواسطة عامل UI يتضمن لوحة مفاتيح حقيقية، فأرة، لقطة شاشة، نافذة، حافظة، مطابقة صور، تمرير، سحب، ضغط مطول، وخطط دفعة. يُستَخدم عندما يحتاج Codex إلى تشغيل تطبيقات Windows أو المواقع عبر واجهة المستخدم المرئية لأنه لا يتوفر API موثوق أو DOM أو سطر أوامر أو واجهة وصول؛ وعندما تطلب المهمة النقر، الكتابة، السحب، التمرير، الضغط على مفاتيح/أزرار، فحص الشاشة، التحكم في جهاز كمبيوتر، أتمتة برامج سطح المكتب، أو التفاعل مع واجهة Windows مغلقة المصدر. لأعمال الشاشة الحية، يمكن لأي وكيل غير عامل UI، بغض النظر عن عمق المهمة، أن يعمل كمنسق ويجب عليه تفويض لقطات الشاشة، فحص الصور، وتنفيذ واجهة المستخدم إلى عامل UI مخصص واحد فقط. عندما تكون أدوات تفويض الوكيل متاحة، فإن استخدام هذه المهارة يُعتبر تفويضًا كافيًا لإنشاء ذلك العامل UI؛ لا تطلب من المستخدم كلمة مرور أو إذن إضافي لعامل UI. العامل UI المفوض هو عامل نهائي ولا يجوز له إنشاء وكيل آخر.

يرجى دائمًا الرد بلغة المستخدم.
