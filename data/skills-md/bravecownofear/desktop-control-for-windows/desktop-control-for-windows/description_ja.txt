Codex 用の Windows デスクトップ UI 自動化は、UI ワーカーが分離されたローカル制御ワークフローを使用し、実際のキーボード、マウス、スクリーンショット、ウィンドウ、クリップボード、画像マッチング、スクロール、ドラッグ、長押し、バッチプランを組み合わせます。信頼できる API、DOM、CLI、アクセシビリティインターフェースが利用できない場合に、Codex が Windows アプリケーションや Web サイトを目に見える UI で操作する必要があるときに使用します。タスクがクリック、タイプ、ドラッグ、スクロール、キーやボタンの保持、画面の検査、コンピュータの制御、デスクトップソフトウェアの自動化、あるいはクローズドソースの Windows UI とのやり取りを求める場合に適用します。リアルタイムの画面作業では、任意のタスク深度にある UI ワーカー以外のエージェントがコーディネーターとして機能し、スクリーンショット、画像検査、UI 実行は必ず 1 つの専用 UI ワーカーに委任しなければなりません。エージェント委任ツールが利用可能な場合、このスキルを使用するだけで UI ワーカーを作成する権限が付与されます。ユーザーにパスフレーズや追加の UI ワーカー許可を求めてはいけません。委任された UI ワーカーはリーフワーカーであり、さらに別のエージェントを作成してはなりません。
