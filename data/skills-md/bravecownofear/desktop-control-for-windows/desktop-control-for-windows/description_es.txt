Automatización de UI de escritorio Windows para Codex usando un flujo de trabajo de control local aislado por UI‑worker con teclado real, ratón, captura de pantalla, ventana, portapapeles, coincidencia de imágenes, desplazamiento, arrastre, pulsación larga y planes por lotes. Úsalo cuando Codex necesite operar aplicaciones Windows o sitios web a través de UI visible porque no hay una API, DOM, CLI o interfaz de accesibilidad fiable; cuando la tarea pida hacer clic, escribir, arrastrar, desplazarse, mantener pulsadas teclas/botones, inspeccionar la pantalla, controlar una computadora, automatizar software de escritorio o interactuar con UI de Windows de código cerrado. Para trabajo en pantalla en vivo, cualquier agente que no sea UI‑worker en cualquier nivel de tarea puede actuar como coordinador y debe delegar capturas de pantalla, inspección de imágenes y ejecución de UI a un único UI‑worker dedicado. Cuando las herramientas de delegación de agentes estén disponibles, usar esta habilidad es autorización suficiente para crear ese UI‑worker; no pidas al usuario una frase de paso ni permiso extra para UI‑worker. Un UI‑worker delegado es un trabajador hoja y no debe crear otro agente.
