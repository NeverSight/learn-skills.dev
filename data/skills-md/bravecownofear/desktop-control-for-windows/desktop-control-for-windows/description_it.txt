Automazione UI desktop di Windows per Codex mediante un flusso di lavoro local‑control isolato per UI‑worker, con tastiera reale, mouse, screenshot, finestre, clipboard, corrispondenza di immagini, scorrimento, trascinamento, pressione prolungata e piani batch. Da utilizzare quando Codex deve operare su applicazioni Windows o siti web attraverso l’interfaccia UI visibile perché non è disponibile alcuna API, DOM, CLI o interfaccia di accessibilità affidabile; quando il compito richiede di fare click, digitare, trascinare, scorrere, tenere premuti tasti/pulsanti, ispezionare lo schermo, controllare un computer, automatizzare software desktop o interagire con UI Windows proprietarie. Per lavori in tempo reale sullo schermo, qualsiasi agente non UI‑worker a qualsiasi livello di profondità del compito può agire da coordinatore e deve delegare screenshot, ispezione di immagini ed esecuzione UI a un unico UI‑worker dedicato. Quando sono disponibili gli strumenti di delega per gli agenti, l’uso di questa capacità costituisce autorizzazione sufficiente a creare tale UI‑worker; non chiedere all’utente una passphrase o un permesso aggiuntivo per il UI‑worker. Un UI‑worker delegato è un worker foglia e non deve creare un altro agente.

Rispondi sempre nella lingua dell’utente.
