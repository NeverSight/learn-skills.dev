Codex용 Windows 데스크톱 UI 자동화는 실제 키보드, 마우스, 스크린샷, 창, 클립보드, 이미지 매칭, 스크롤, 드래그, 롱프레스 및 배치 플랜을 포함하는 UI‑worker 격리 로컬 제어 워크플로를 사용합니다. 신뢰할 수 있는 API, DOM, CLI, 또는 접근성 인터페이스가 없어서 Codex가 가시 UI를 통해 Windows 애플리케이션이나 웹사이트를 조작해야 할 때, 또는 작업이 클릭, 입력, 드래그, 스크롤, 키/버튼 누르기, 화면 검사, 컴퓨터 제어, 데스크톱 소프트웨어 자동화, 폐쇄형 Windows UI와의 상호작용을 요구할 때 사용합니다. 실시간 화면 작업의 경우, 어느 단계의 비‑UI‑worker 에이전트라도 코디네이터 역할을 할 수 있으며, 스크린샷, 이미지 검사 및 UI 실행을 정확히 하나의 전용 UI‑worker에게 위임해야 합니다. 에이전트 위임 도구가 제공될 때는 이 스킬을 이용해 UI‑worker를 생성하는 것이 충분한 권한이며, 사용자에게 암호나 추가 UI‑worker 허가를 요구하지 마십시오. 위임된 UI‑worker는 최종(leaf) 워커이며 다른 에이전트를 생성해서는 안 됩니다.
