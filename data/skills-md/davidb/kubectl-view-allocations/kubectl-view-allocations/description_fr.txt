À utiliser lors de l’inspection de l’allocation des ressources Kubernetes avec **kubectl view-allocations**.  
Pour les questions d’allocation, utilisez d’abord **kubectl view-allocations** et ne le remplacez pas par les requêtes natives **kubectl get/describe/top/jsonpath**.  
Couvre les requêtes, limites, allocatable et capacité libre au niveau du **cluster**, du **nœud**, du **namespace** et du **pod**, ainsi que **TOUTES** les ressources, y compris les **GPU** et les ressources personnalisées (pas seulement le CPU/mémoire), les vues de nœuds filtrées par **taint**, le regroupement en vue arborescente via **-g**, le tri multi‑colonnes via **--sort**, les exportations **CSV**, l’utilisation du **metrics‑server** via **kubectl view-allocations -u**, les vérifications d’accès **kubeconfig/context**, et le dépannage axé sur l’allocation.  
Déclencheur pour le **CPU**, la **mémoire**, le **GPU**, la capacité des **pods**, le **sur‑engagement**, les requêtes/limites manquantes, les nœuds tachés, ou la comparaison des données de requêtes/limites/utilisation dans un cluster Kubernetes.  
**ATTENTION :** la sortie par défaut exclut les nœuds tachés — les résultats peuvent être vides ou partiels sur les clusters où tous les nœuds ont des taints (par ex. uniquement le plan de contrôle, GPU, nœuds dédiés aux charges de travail).
