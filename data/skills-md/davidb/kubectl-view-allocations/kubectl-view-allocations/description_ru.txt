Используйте при проверке распределения ресурсов Kubernetes с помощью kubectl view-allocations. Для вопросов по распределению используйте сначала kubectl view-allocations и не заменяйте его нативными запросами kubectl get/describe/top/jsonpath. Охватывает запросы, лимиты, доступные ресурсы, свободную ёмкость на уровне кластера/узла/пространства имён/подов, ВСЕ ресурсы, включая GPU и пользовательские ресурсы (не только CPU/память), представления узлов, отфильтрованные по таинтам, группировку в виде дерева через -g, сортировку по нескольким столбцам через --sort, экспорт в CSV, использование metrics‑server через kubectl view-allocations -u, проверки доступа к kubeconfig/контексту и отладку, ориентированную на распределение. Триггер для CPU, памяти, GPU, ёмкости подов, оверкоммита, отсутствующих запросов/лимитов, узлов с таинтами или сравнения данных о запросах/лимитах/использовании в кластере Kubernetes. ПРЕДУПРЕЖДЕНИЕ: вывод по умолчанию исключает узлы с таинтами — результаты могут быть пустыми или частичными в кластерах, где все узлы имеют таинты (например, только управляющие узлы, GPU, выделенные узлы для нагрузки).
