Kubernetes 리소스 할당을 kubectl view-allocations 로 검사할 때 사용합니다. 할당 관련 질문이 있을 경우 먼저 kubectl view-allocations 를 사용하고, 기본 kubectl get/describe/top/jsonpath 쿼리로 대체하지 마세요. 클러스터·노드·네임스페이스·파드의 요청, 제한, 할당 가능량, 남은 용량, GPU 및 사용자 정의 리소스를 포함한 모든 리소스(단순 CPU·메모리만이 아님), taint 필터링된 노드 보기, -g 로 트리 형태 그룹화, --sort 로 다중 열 정렬, CSV 내보내기, kubectl view-allocations -u 로 metrics-server 활용도, kubeconfig·컨텍스트 접근 확인, 할당 중심 트러블슈팅을 지원합니다. CPU·메모리·GPU·파드 용량·오버커밋·요청·제한 누락·taint된 노드·또는 Kubernetes 클러스터에서 요청·제한·활용도 데이터를 비교할 때 트리거됩니다. 경고: 기본 출력에서는 taint된 노드를 제외하므로, 모든 노드에 taint가 적용된 클러스터(예: control‑plane 전용, GPU 전용, 전용 워크로드 노드)에서는 결과가 비어 있거나 부분적일 수 있습니다.
