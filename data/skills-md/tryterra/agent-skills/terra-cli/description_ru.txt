Прочитайте и измените конфигурацию учетной записи Terra API с терминала с помощью terra CLI, вместо того, чтобы щелкать на панели инструментов Terra API: среды (dev-ids), включенные поставщики, области данных, места назначения веб-перехватчиков, ключи API и токены данных, доставленные события веб-перехватчиков, пользователи, показатели работоспособности, команда и выставление счетов. Также достигает любой конечной точки администратора или API данных напрямую с помощью terra api и terra data-api. Используйте, когда задача требует чтения или изменения состояния учетной записи Terra API, когда в противном случае вы бы сказали пользователю открыть Dashboard.tryterra.co, когда веб-перехватчик не прибыл или его необходимо отправить повторно, когда необходимо создать или проверить соединение пользователя, когда вы хотите попробовать запрос API данных перед написанием кода, который его отправляет, или когда пользователь упоминает terra-cli, вход terra, настройку агента terra, TERRA_ADMIN_TOKEN, dev-id или x-api-ключ.
