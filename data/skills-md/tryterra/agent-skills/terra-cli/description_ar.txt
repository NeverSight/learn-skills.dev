قم بقراءة وتغيير تكوين حساب Terra API من الجهاز الطرفي باستخدام terra CLI، بدلاً من النقر على لوحة معلومات Terra API: البيئات (dev-ids)، والموفرون الممكّنون، ونطاقات البيانات، ووجهات خطاف الويب، ومفاتيح واجهة برمجة التطبيقات ورموز البيانات، وأحداث خطاف الويب التي تم تسليمها، والمستخدمون، ونتائج الصحة، والفريق، والفوترة. يصل أيضًا إلى أي نقطة نهاية لواجهة برمجة تطبيقات المشرف أو البيانات مباشرة باستخدام terra api وterra data-api. يُستخدم عندما تحتاج مهمة ما إلى قراءة حالة حساب Terra API أو تغييرها، أو عندما تطلب من المستخدم فتح Dashboard.tryterra.co، أو عندما لا يصل خطاف الويب أو يجب إعادة إرساله، أو عندما يتعين إنشاء اتصال مستخدم أو التحقق منه، أو عندما تريد تجربة طلب API بيانات قبل كتابة الرمز الذي يرسله، أو عندما يذكر المستخدم terra-cli، أو تسجيل دخول terra، أو إعداد وكيل terra، أو TERRA_ADMIN_TOKEN، أو معرف dev، أو x-api-مفتاح.
