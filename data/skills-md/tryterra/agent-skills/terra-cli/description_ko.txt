Terra API 대시보드를 클릭하는 대신 Terra API 대시보드를 클릭하는 대신 Terra CLI를 사용하여 터미널에서 Terra API 계정 구성(환경(dev-id), 활성화된 공급자, 데이터 범위, 웹훅 대상, API 키 및 데이터 토큰, 전달된 웹훅 이벤트, 사용자, 상태 점수, 팀 및 청구)을 읽고 변경합니다. 또한 terra api 및 terra data-api를 사용하여 모든 관리 또는 데이터 API 엔드포인트에 직접 도달합니다. 작업에서 Terra API 계정 상태를 읽거나 변경해야 할 때, 사용자에게 Dashboard.tryterra.co를 열도록 지시할 때, 웹후크가 도착하지 않았거나 다시 보내야 할 때, 사용자 연결을 생성하거나 확인해야 할 때, 데이터 API 요청을 전송하는 코드를 작성하기 전에 시도하려고 할 때, 사용자가 terra-cli, terra 로그인, terra 에이전트 설정, TERRA_ADMIN_TOKEN, dev-id 또는 x-api-키.
