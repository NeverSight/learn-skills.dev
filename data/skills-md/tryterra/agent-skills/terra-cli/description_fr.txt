Lisez et modifiez la configuration du compte Terra API depuis le terminal avec la CLI terra, au lieu de cliquer dans le tableau de bord de l'API Terra : environnements (identifiants de développement), fournisseurs activés, étendues de données, destinations de webhook, clés API et jetons de données, événements de webhook livrés, utilisateurs, scores d'intégrité, équipe et facturation. Atteint également n'importe quel point de terminaison d'administrateur ou d'API de données directement avec terra api et terra data-api. À utiliser lorsqu'une tâche nécessite la lecture ou la modification de l'état du compte API Terra, lorsque vous diriez autrement à l'utilisateur d'ouvrir Dashboard.tryterra.co, lorsqu'un webhook n'est pas arrivé ou doit être renvoyé, lorsqu'une connexion utilisateur doit être créée ou vérifiée, lorsque vous souhaitez essayer une requête API de données avant d'écrire le code qui l'envoie, ou lorsque l'utilisateur mentionne terra-cli, terra login, terra agent setup, TERRA_ADMIN_TOKEN, un identifiant de développement ou un clé x-api.
