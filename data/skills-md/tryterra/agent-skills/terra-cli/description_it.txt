Leggi e modifica la configurazione dell'account Terra API dal terminale con la CLI terra, invece di fare clic sulla dashboard dell'API Terra: ambienti (dev-id), provider abilitati, ambiti dati, destinazioni webhook, chiavi API e token dati, eventi webhook forniti, utenti, punteggi di integrità, team e fatturazione. Raggiunge anche qualsiasi endpoint API di amministrazione o dati direttamente con terra api e terra data-api. Da utilizzare quando un'attività richiede la lettura o la modifica dello stato dell'account API Terra, quando altrimenti diresti all'utente di aprire dashboard.tryterra.co, quando un webhook non è arrivato o deve essere inviato nuovamente, quando è necessario creare o verificare una connessione utente, quando vuoi provare una richiesta API dati prima di scrivere il codice che la invia o quando l'utente menziona terra-cli, terra login, terra agent setup, TERRA_ADMIN_TOKEN, un dev-id o una x-api-key.
