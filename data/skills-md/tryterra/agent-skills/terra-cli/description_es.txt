Lea y cambie la configuración de la cuenta Terra API desde la terminal con Terra CLI, en lugar de hacer clic en el panel de Terra API: entornos (dev-ids), proveedores habilitados, alcances de datos, destinos de webhook, claves API y tokens de datos, eventos de webhook entregados, usuarios, puntuaciones de estado, equipo y facturación. También llega a cualquier punto final de API de datos o administrador directamente con terra api y terra data-api. Úselo cuando una tarea necesite leer o cambiar el estado de la cuenta Terra API, cuando de lo contrario le diría al usuario que abra Dashboard.tryterra.co, cuando un webhook no llegó o debe reenviarse, cuando se debe crear o verificar una conexión de usuario, cuando desea probar una solicitud de API de datos antes de escribir el código que la envía, o cuando el usuario menciona terra-cli, terra login, terra agent setup, TERRA_ADMIN_TOKEN, un dev-id o un x-api-clave.
