Lesen und ändern Sie die Terra-API-Kontokonfiguration vom Terminal aus mit der Terra-CLI, anstatt in das Terra-API-Dashboard zu klicken: Umgebungen (Entwickler-IDs), aktivierte Anbieter, Datenbereiche, Webhook-Ziele, API-Schlüssel und Daten-Tokens, übermittelte Webhook-Ereignisse, Benutzer, Gesundheitsbewertungen, Team und Abrechnung. Erreicht mit terra api und terra data-api auch jeden Admin- oder Daten-API-Endpunkt direkt. Verwenden Sie diese Option, wenn für eine Aufgabe das Lesen oder Ändern des Terra-API-Kontostatus erforderlich ist, wenn Sie dem Benutzer andernfalls sagen würden, dass er Dashboard.tryterra.co öffnen soll, wenn ein Webhook nicht angekommen ist oder erneut gesendet werden muss, wenn eine Benutzerverbindung erstellt oder überprüft werden muss, wenn Sie eine Daten-API-Anfrage testen möchten, bevor Sie den Code schreiben, der sie sendet, oder wenn der Benutzer Terra-Cli, Terra-Login, Terra-Agent-Setup, TERRA_ADMIN_TOKEN, eine Entwickler-ID oder eine andere erwähnt x-API-Schlüssel.
