使用 terra CLI 从终端读取和更改 Terra API 帐户配置，而不是在 Terra API 仪表板中单击：环境 (dev-ids)、启用的提供程序、数据范围、webhook 目标、API 密钥和数据令牌、交付的 webhook 事件、用户、运行状况评分、团队和计费。还可以使用 terra api 和 terra data-api 直接到达任何管理或数据 API 端点。当任务需要读取或更改 Terra API 帐户状态时，当您以其他方式告诉用户打开仪表板.tryterra.co 时，当 Webhook 未到达或必须重新发送时，当必须创建或验证用户连接时，当您想在编写发送数据 API 的代码之前尝试数据 API 请求时，或者当用户提及 terra-cli、terra 登录、terra 代理设置、TERRA_ADMIN_TOKEN、dev-id 或 x-api-key 时。
