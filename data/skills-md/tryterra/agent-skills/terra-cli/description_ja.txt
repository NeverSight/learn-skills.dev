Terra API ダッシュボードをクリックする代わりに、terra CLI を使用してターミナルから Terra API アカウント構成 (環境 (dev-id)、有効なプロバイダー、データ スコープ、Webhook 宛先、API キーとデータ トークン、配信された Webhook イベント、ユーザー、ヘルス スコア、チーム、請求) を読み取り、変更します。また、terra api および terra data-api を使用して、管理またはデータ API エンドポイントに直接到達します。タスクでTerra APIアカウントの状態の読み取りまたは変更が必要な場合、ユーザーにdashboard.tryterra.coを開くように指示する場合、Webhookが到着しなかった場合または再送信する必要がある場合、ユーザー接続を作成または検証する必要がある場合、データAPIリクエストを送信するコードを記述する前にデータAPIリクエストを試行したい場合、またはユーザーがterra-cli、terraログイン、terraエージェントセットアップ、TERRA_ADMIN_TOKEN、dev-id、またはX-API キー。
