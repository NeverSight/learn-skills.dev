قم بتشغيل نماذج Terra API الصحية (نافذة النوم، ومتتبع الدورة الشهرية، والتعبئة الذكية) عبر بيانات مستخدم متصل لنطاق زمني لإرجاع رؤى صحية جاهزة للاستخدام. يُستخدم عند الإنشاء باستخدام نماذج Terra API، أو نقاط النهاية /v2/models أو /v2/models/run، أو تسعير model_run، أو تحويل بيانات Terra API الخاصة بالمستخدم إلى جدول نوم أو دورة شهرية أو رؤية مقاييس مليئة بالفجوات.
