Esegui modelli di salute dell'API Terra (finestra del sonno, monitoraggio del ciclo mestruale, Smart Fill) sui dati di un utente connesso per un intervallo di date per restituire informazioni sul benessere pronte all'uso. Da utilizzare durante la creazione con Terra API Models, gli endpoint /v2/models o /v2/models/run, i prezzi di model_run o la trasformazione dei dati API Terra di un utente in informazioni dettagliate sulla pianificazione del sonno, sul ciclo mestruale o sulle metriche per colmare le lacune.
