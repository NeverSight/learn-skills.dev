Запускайте модели здоровья Terra API (Окно сна, Трекер менструального цикла, Smart Fill) на основе данных подключенного пользователя за определенный диапазон дат, чтобы получить готовые к использованию данные о состоянии здоровья. Используйте при создании моделей Terra API, конечных точек /v2/models или /v2/models/run, ценах model_run или превращении данных Terra API пользователя в данные о графике сна, менструальном цикле или показателях заполнения пробелов.
