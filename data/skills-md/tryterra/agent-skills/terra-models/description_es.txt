Ejecute modelos de salud Terra API (Sleep Window, Menstrual Cycle Tracker, Smart Fill) sobre los datos de un usuario conectado durante un rango de fechas para obtener información sobre bienestar lista para usar. Úselo cuando cree con modelos Terra API, los puntos finales /v2/models o /v2/models/run, precios model_run o convierta los datos de Terra API de un usuario en información sobre el horario de sueño, el ciclo menstrual o las métricas llenas de brechas.
