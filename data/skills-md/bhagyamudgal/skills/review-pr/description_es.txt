Revisa un PR de GitHub y, a continuación, solicita automáticamente cambios para detectar cualquier hallazgo o aprueba una revisión limpia. Utilícelo en una URL de relaciones públicas cuando la solicitud sea para producir y enviar hallazgos; cuando los hallazgos ya existan y la solicitud sea para actuar en consecuencia, use /fix-pr-review. El modo por lotes cubre más de 2 PR o "revisar todas las PR abiertas". Para cambios locales no comprometidos, use /parallel-review.
