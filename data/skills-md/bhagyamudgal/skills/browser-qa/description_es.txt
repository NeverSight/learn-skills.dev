Conduzca un navegador real a través de un flujo de interfaz de usuario, o ejecute API y control de calidad de punto final e informe los resultados de las pruebas estructuradas. Se usa cuando el usuario nombra un flujo o un punto final para probar contra una URL, al verificar filtros, paginación, manejo de errores, autenticación o recuento en una API, o después de que una interfaz de usuario o un cambio de backend aterrice y deba verificarse en el navegador.
