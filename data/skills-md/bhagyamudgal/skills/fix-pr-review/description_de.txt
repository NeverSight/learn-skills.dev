Triage und behebe Überprüfungsergebnisse, die bereits auf einer GitHub-PR vorhanden sind, antworte dann und löse die Threads. Verwenden Sie es für eine CodeRabbit-Bewertungs-URL, eine PR, deren Bewertungskommentare noch bearbeitet werden müssen, oder eine lokale /review-pr Befunddatei. Wenn die PR noch keine Ergebnisse hat, erstellt/review-pr diese zuerst.
