Esegui il triage e correggi i risultati della revisione che già esistono su una PR di GitHub, poi rispondi e risolvi le discussioni. Usa un URL di revisione CodeRabbit, una PR i cui commenti di revisione devono ancora essere gestiti, o un file locale di risultati /review-pr. Quando la PR non presenta ancora risultati, /review-pr li genera prima.

Per favore, rispondi sempre nella lingua dell'utente.
