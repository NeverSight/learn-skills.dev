Recherchez avant d'écrire, balayez avant de terminer. Utilisez AVANT de créer un utilitaire, un type, un schéma, un composant, un crochet, une constante, un module ou un package ; AVANT de coder en dur un littéral qui peut être une constante exportée ; lorsque vous êtes sur le point de copier-coller un code similaire ; et en tant que porte d'achèvement sur chaque fichier que la tâche a touché, pas seulement le diff.
