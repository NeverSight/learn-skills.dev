La base architettonica per le competenze Stratos. Definisce la metodologia di Progressive Disclosure, il modello a quattro livelli di complessità API (da Troposfera a Termosfera) e i criteri di rifiuto per gli anti‑pattern come le Trappole Booleane. Da utilizzare nella progettazione delle API o nella revisione del codice per garantire la conformità a Stratos.
