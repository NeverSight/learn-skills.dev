Die architektonische Grundlage für Stratos‑Fähigkeiten. Definiert die Progressive‑Disclosure‑Methodik, das vierlagige API‑Komplexitätsmodell (Troposphäre bis Thermosphäre) und Ablehnungskriterien für Anti‑Pattern wie Boolean‑Traps. Verwenden Sie dies beim Entwerfen von APIs oder beim Überprüfen von Code auf Stratos‑Konformität.
