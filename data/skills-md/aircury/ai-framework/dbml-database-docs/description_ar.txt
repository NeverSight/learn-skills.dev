استخدم DBML كالصيغة القياسية لتوثيق مخطط قاعدة البيانات. طبّق ذلك كلما قمت بإنشاء أو تحديث أو مراجعة أو إصلاح مستندات قواعد البيانات، مخططات ERD، مخططات المخطط، جرد الجداول، ملخصات الترحيلات، تغييرات ترحيل Doctrine، مستندات مخطط SQL، مستندات نماذج ORM، أو حالات فشل انحراف مخطط CI. فضلًا عن db/schema.dbml على Mermaid أو مخطط Prisma أو جداول Markdown العشوائية أو توثيق قاعدة البيانات النصي فقط ما لم يطلب المستخدم صراحةً صيغةً أخرى.

الرجاء دائمًا الرد بلغة المستخدم.
