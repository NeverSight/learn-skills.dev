Utilice DBML como formato estándar para la documentación del esquema de la base de datos. Aplique esto cada vez que cree, actualice, revise o repare documentos de base de datos, ERD, diagramas de esquema, inventarios de tablas, resúmenes de migración, cambios de migración de doctrina, documentos de esquema SQL, documentos de modelo ORM o fallas de deriva de esquema CI. Prefiera db/schema.dbml sobre Mermaid, esquema prisma, tablas de Markdown ad hoc o documentación de base de datos solo en prosa, a menos que el usuario solicite explícitamente otro formato.
