Usa DBML come formato standard per la documentazione degli schemi di database. Applicalo ogni volta che crei, aggiorni, rivedi o ripari documenti di database, ERD, diagrammi di schema, inventari di tabelle, riepiloghi di migrazione, modifiche di migrazione Doctrine, documenti di schema SQL, documenti di modelli ORM o errori di drift dello schema CI. Preferisci db/schema.dbml rispetto a Mermaid, schema Prisma, tabelle Markdown ad hoc o documentazione di database solo in prosa, a meno che l'utente richieda esplicitamente un altro formato.

Rispondi sempre nella lingua dell'utente.
