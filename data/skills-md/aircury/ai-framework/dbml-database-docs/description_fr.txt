Utilisez DBML comme format standard pour la documentation du schéma de base de données. Appliquez ceci chaque fois que vous créez, mettez à jour, révisez ou réparez des documents de base de données, des ERD, des diagrammes de schéma, des inventaires de table, des résumés de migration, des modifications de migration de Doctrine, des documents de schéma SQL, des documents de modèle ORM ou des échecs de dérive de schéma CI. Préférez db/schema.dbml à Mermaid, Prisma schema, aux tables Markdown ad hoc ou à la documentation de base de données en prose uniquement, sauf si l'utilisateur demande explicitement un autre format.
