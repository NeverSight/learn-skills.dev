Extrahiere UI‑Design‑Stile von einer laufenden Website (URL), einem Code‑Repository (lokaler Pfad oder Git‑Adresse), Bildern (Screenshots/Design‑Mockups) oder Designdokumenten (Markdown/PDF); erstelle/importiere/aktualisiere das portable Paket `design-system/v1` und pflege die Vorlagenbibliothek. Eingaben nach dem Legacy‑Schema v2 werden nur über eine explizite Migration verarbeitet. Dies wird verwendet für „Vorlagen erstellen / UI‑Vorlagen importieren / Design‑Spezifikationen extrahieren / Vorlagen aktualisieren“. Seiten, die gemäß einer Vorlage implementiert wurden, sollten an ui-template-apply übergeben werden.
