Estrai gli stili di design UI da un sito web operativo (URL), da un repository di codice (percorso locale o indirizzo Git), da immagini (screenshot/progetti) o da documenti di design (Markdown/PDF); crea, importa o aggiorna il pacchetto portatile `design-system/v1` e mantieni i template/libreria di template. Gli input del vecchio schema v2 subiscono solo una migrazione esplicita. Questo viene utilizzato per “creare template / importare template UI / estrarre specifiche di design / aggiornare i template.” Le pagine implementate sulla base dei template devono essere consegnate a ui‑template‑apply.  

Rispondi sempre nella lingua dell'utente.
