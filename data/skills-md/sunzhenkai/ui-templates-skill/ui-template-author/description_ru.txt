Извлекать стили UI‑дизайна с работающего веб‑сайта (URL), репозитория кода (локальный путь или Git‑адрес), изображений (скриншоты/эскизы дизайна) или дизайн‑документов (Markdown/PDF), создавать/импортировать/обновлять переносимый пакет `design-system/v1` и поддерживать библиотеку шаблонов; вводы по старой схеме v2 проходят только явную миграцию. Это используется для «создания шаблонов/импорта UI‑шаблонов/извлечения спецификаций дизайна/обновления шаблонов»; страницы, реализованные согласно шаблоном, следует передать ui-template-apply.
