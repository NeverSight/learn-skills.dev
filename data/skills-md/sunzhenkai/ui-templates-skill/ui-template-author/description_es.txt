Extrae estilos de diseño UI de sitios web en funcionamiento (URL), repositorios de código (ruta local o dirección Git), imágenes (capturas de pantalla/borradores de diseño) o documentos de diseño (Markdown/PDF); crea, importa o actualiza el paquete portátil `design-system/v1` y mantiene la biblioteca de plantillas. Las entradas del esquema v2 antiguo solo deben someterse a una migración explícita. Esto se utiliza para “crear plantillas / importar plantillas UI / extraer especificaciones de diseño / actualizar plantillas”, y las páginas implementadas según las plantillas deben entregarse a ui‑template‑apply.
