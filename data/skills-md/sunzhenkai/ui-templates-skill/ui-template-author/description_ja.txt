実行中のウェブサイト（URL）、コードリポジトリ（ローカルパスまたは Git アドレス）、画像（スクリーンショット／デザイン草案）やデザイン文書（Markdown／PDF）から UI デザインスタイルを抽出し、`design-system/v1` ポータブルパッケージを作成／インポート／更新し、テンプレートライブラリを維持します；古いスキーマ v2 の入力は明示的なマイグレーションのみを通ります。 「テンプレートの作成／UI テンプレートのインポート／デザイン仕様の抽出／テンプレートの更新」に使用され、テンプレートに従って実装されたページは ui-template-apply に引き継がれるべきです。
