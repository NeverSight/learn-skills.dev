استخرج أنماط تصميم واجهة المستخدم من المواقع الحية (URL)، ومستودعات الكود (المسار المحلي أو عنوان Git)، أو الصور (لقطات شاشة/نماذج)، أو وثائق التصميم (Markdown/PDF)؛ أنشئ أو استورد أو حدّث حزمة `design-system/v1` القابلة للنقل واحتفظ بمكتبة القوالب. تُخضع مدخلات المخطط القديم v2 فقط إلى هجرة صريحة. يُستخدم هذا لـ “إنشاء القوالب / استيراد قوالب واجهة المستخدم / استخراج مواصفات التصميم / تحديث القوالب”؛ يجب تسليم الصفحات التي تم تنفيذها وفقًا لقالب إلى `ui-template-apply`. يرجى الرد دائمًا بلغة المستخدم.
