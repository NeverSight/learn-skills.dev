Dans la création, l'adoption, le refactoring, l'itération et le gel d’une instance active `design-system/v1` pour les projets de consommation (incluant le cœur portable, la liaison de projet, la projection de jetons, le type Primitive/Pattern/Page, la galerie et la preuve de navigateur). Elle est utilisée pour « construire des systèmes de conception / un framework UI unifié / extraire des jetons et des modèles de pages / refactoriser la dérive visuelle du front‑end / fournir une couche de composants prête à l’assemblage pour les agents ». Cette compétence doit également être appliquée lorsqu’il n’y a aucun paquet ou lorsque `ui-template-author` ou `ui-template-apply` ne sont pas installés. Publiez le paquet vers `ui-template-author` ; livrez l’implémentation des pages métier à `ui-template-apply`.
