В процессе создания, принятия, рефакторинга, итерации и заморозки активного экземпляра `design-system/v1` (переносимое ядро, привязка проекта, проекция токенов, примитив/паттерн/тип страницы, галерея и браузерные доказательства) для потребительского проекта он используется для «создания дизайн‑системы / унификации UI‑фреймворка / извлечения токенов и шаблонов страниц / рефакторинга отклонившихся фронтенд‑визуалов / предоставления компонентоориентированного уровня сборки для Agent». Этот навык необходимо применять даже при отсутствии пакета или когда ui-template-author или ui-template-apply не установлены. Опубликуйте пакет в ui-template-author; доставьте реализацию бизнес‑страниц в ui-template-apply.
