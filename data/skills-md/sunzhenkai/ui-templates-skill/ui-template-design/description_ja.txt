`design-system/v1` アクティブインスタンス（ポータブルコア、プロジェクトバインディング、トークンプロジェクション、プリミティブ／パターン／ページタイプ、ギャラリー、ブラウザエビデンス）の消費プロジェクト作成、採用、リファクタリング、イテレーション、凍結において使用されます。これは「デザインシステムの構築／統一 UI フレームワークの構築／トークンとページテンプレートの抽出／フロントエンドの視覚的ドリフトのリファクタリング／エージェント向けの組み立て可能なコンポーネント層の提供」のために利用されます。このスキルは、パッケージや ui-template-author、ui-template-apply がインストールされていない場合でも使用しなければなりません。パッケージを ui-template-author にリリースし、ビジネスページの実装を ui-template-apply に提供してください。
