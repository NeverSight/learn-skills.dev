Méthode et outils pour auditer la courbe de lancement d’un token sur BSC — courbe de liaison ou IEO tranche, filtrage Agent‑ID ou liste blanche, enchères en séquestre, graduation vers un pool, émissions hors‑chaîne couplées. Modélise le trajet de prix, fixe le déploiement, exécute les invariants du cycle de vie, évalue le carnet d’ordres adverse, et renvoie un verdict expédier/maintenir/bloquer avec un registre des constats. À utiliser pour « auditer ce lancement », « cet IEO est‑il sûr », « examiner la courbe de liaison », « vérifier le lancement avant qu’il n’ouvre », « ont‑ils brûlé le LP », « le propriétaire peut‑il changer la courbe ». Déclencheur pour toute courbe tarifée / courbe de liaison / IEO tranche / vente pré‑lancement séquestrée sur BSC, pré‑lancement ou pré‑investissement ; pas pour le risque de trading post‑cotation (utiliser bsc‑contract‑audit).
