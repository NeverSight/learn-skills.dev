À utiliser pour « audit this contract », « is this token a scam or rug », « check this BSC token before buying », « is the LP locked », « did the owner renounce », « should I mint this NFT », « is this NFT drop legit », « should I lock BNB/USDT for this allocation », « is this 24h lock/refund legit ».
