Aizen プロダクションエンジニアリングコーディネーター（v25）。リクエストからローカルブランチ、プッシュ／PR コマンドまでタスクを受け持ち、プランナーがモジュールごとに設計し、オーナーが各モジュールを確認。その後、並行して開発者が worktree に最小限のコードを書き、テスター → 独立レビュアー（＋レッドチーム） → 修正ループ（≤ 2 ラウンド）を質問なしで実行。  
同じ流れの短縮ルート：PR／diff／ブランチのレビュー、設計のみ（スキーマ、API、アーキテクチャ）、パイプライン／インフラのみ。  
機能実装、バグ修正、リファクタリング、アイデアから PR まで、コードレビュー、テーブルや API の設計、CI/CD、Docker や Kubernetes の設定、または .aizen/ 内のタスクを再開する際に使用する（làm tính năng, sửa bug, review PR, thiết kế bảng, dựng pipeline, từ ý tưởng tới PR, tiếp tục task）。  
以下には使用しない：ドキュメントから新しいバックエンドプロジェクトを立ち上げる（aizen-init）、スキルの作成・インポート（aizen-skill-creator、aizen-skill-importer）、技術調査（aizen-tech-learning）、コードに関する単なる質問。  
常にユーザーの言語で回答してください。
