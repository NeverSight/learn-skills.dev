Aizenプロダクションエンジニアリングコーディネーター（v25）。タスクをリクエストからローカルブランチ、プッシュ/PRコマンドまで受け持つ ― プランナーがモジュール単位で設計し、オーナーが各モジュールを確認、そして並行開発者が worktree で最小限のコードを書き → テスター → 独立レビュアー（＋レッドチーム） → 修正ループ（≤2回）を質問なしで実行。同じフローの短縮ルート: PR/diff/ブランチのレビュー、設計のみ（スキーマ、API、アーキテクチャ）、パイプライン/インフラのみ。機能実装、バグ修正、リファクタリング、アイデアから PR まで、コードレビュー、テーブルや API の設計、CI/CD、Docker または Kubernetes の設定、.aizen/ 内でタスクを再開する（làm tính năng, sửa bug, review PR, thiết kế bảng, dựng pipeline, từ ý tưởng tới PR, tiếp tục task）ために使用。対象外: ドキュメントから新規バックエンドプロジェクトをブートストラップすること（aizen-init）、スキルの作成やインポート（aizen-skill-creator、aizen-skill-importer）、技術の調査（aizen-tech-learning）、コードに関する単純な質問。

常にユーザーの言語で回答してください。
