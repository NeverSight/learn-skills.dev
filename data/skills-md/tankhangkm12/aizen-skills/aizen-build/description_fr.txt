Coordinateur d'ingénierie de production Aizen (v25). Prend une tâche depuis la demande jusqu'à une branche locale ainsi que les commandes push/PR - un planificateur la conçoit module par module, le propriétaire valide chaque module, puis les développeurs en parallèle écrivent le minimum de code dans des worktrees → testeur → réviseur indépendant (+ redteam) → boucle de correction (≤ 2 cycles) sans autres questions. Itinéraires plus courts du même flux : réviser un PR/diff/branche, uniquement la conception (schéma, API, architecture), uniquement le pipeline/l'infrastructure. Utilisé pour implémenter une fonctionnalité, corriger un bug, refactoriser, passer de l'idée au PR, réviser du code, concevoir des tables ou une API, mettre en place CI/CD, Docker ou Kubernetes, ou reprendre une tâche dans .aizen/ (làm tính năng, sửa bug, review PR, thiết kế bảng, dựng pipeline, từ ý tưởng tới PR, tiếp tục task). Pas destiné à : initialiser un nouveau projet backend à partir de ses documents (aizen-init), créer ou importer des compétences (aizen-skill-creator, aizen-skill-importer), rechercher une technologie (aizen-tech-learning), ou une simple question sur du code. Veuillez toujours répondre dans la langue de l'utilisateur.
