Создайте бэкенд‑проект для команды из репозитория GitHub/GitLab и проектных документов, используя 11 строгих последовательных шагов с контрольными точками проверки (v3) — Git Flow (develop + feature‑ветки), утверждённый план в `.aizen/runs/init/plans/`, скелет бэкенда с `/health` и `/health/ready`, многоступенчатый Dockerfile + compose со всей инфраструктурой, `.env/.env.example` + единый центральный конфиг, быстрый отказ при ошибках соединений инфраструктуры, адаптеры за интерфейсами (логгер включён), AOP‑слои, middleware request‑id, аутентификация/авторизация, полный README, затем графический (graphify) обзор в соответствии с документами перед передачей. Используйте при запуске/инициализации нового бэкенд‑проекта для команды (khởi tạo dự án backend, dựng khung backend, init backend, setup docker compose + health check, bắt đầu dự án backend cho team). Не подходит для: функции, исправления ошибки, пайплайна или схемы в существующем проекте (aizen‑build).
