GitHub/GitLab 저장소와 프로젝트 문서를 기반으로 팀 백엔드 프로젝트를 부트스트랩합니다. 11개의 엄격한 순차 단계와 검토 체크포인트(v3)를 포함합니다 - Git Flow( develop + feature 브랜치), .aizen/runs/init/plans/에 승인된 계획, /health 및 /health/ready 엔드포인트를 갖춘 백엔드 스켈레톤, 모든 인프라를 포함한 다중 단계 Dockerfile + compose, .env/.env.example와 하나의 중앙 구성, 빠르게 실패하는 인프라 연결, 인터페이스 뒤에 위치한 어댑터(로거 포함), AOP 레이어, request-id 미들웨어, 인증/인가, 전체 README, 그리고 인계 전에 문서와의 그래프화된 검토. 팀의 새로운 백엔드 프로젝트를 시작/부트스트랩할 때 사용합니다( khởi tạo dự án backend, dựng khung backend, init backend, setup docker compose + health check, bắt đầu dự án backend cho team). 적용 대상이 아닌 경우: 기존 프로젝트의 기능, 버그 수정, 파이프라인 또는 스키마(aizen-build).
