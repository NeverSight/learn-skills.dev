ابدأ مشروع خلفية لفريق من مستودع GitHub/GitLab ومستندات المشروع، في 11 خطوة متسلسلة صارمة مع نقاط مراجعة (الإصدار 3) - Git Flow (develop + فروع المميزات)، خطة معتمدة في .aizen/runs/init/plans/، هيكل أساسي للباك إند مع /health و /health/ready، Dockerfile متعدد المراحل + compose مع جميع البنية التحتية، .env/.env.example + تكوين مركزي واحد، اتصالات بنية تحتية فشل سريع، محولات خلف الواجهات (بما في ذلك السجل)، طبقات AOP، middleware لمعرّف الطلب، المصادقة/التفويض، ملف README كامل، ثم مراجعة graphify مقابل المستندات قبل التسليم. استخدم ذلك عند بدء/تهيئة مشروع باك إند جديد لفريق (khởi tạo dự án backend, dựng khung backend, init backend, إعداد docker compose + فحص الصحة, بدء مشروع باك إند للفريق). ليس للميزات أو إصلاح الأخطاء أو خطوط الأنابيب أو المخططات في مشروع موجود (aizen-build). يرجى دائمًا الرد بلغة المستخدم.
