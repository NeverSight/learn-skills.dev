Inicia un proyecto backend de equipo desde un repositorio GitHub/GitLab y los documentos del proyecto, en 11 pasos secuenciales estrictos con puntos de control de revisión (v3) - Git Flow (develop + ramas de características), un plan aprobado en .aizen/runs/init/plans/, esqueleto backend con /health y /health/ready, Dockerfile multi‑etapa + compose con toda la infraestructura, .env/.env.example + una configuración central, conexiones de infraestructura de falla rápida, adaptadores detrás de interfaces (logger incluido), capas AOP, middleware request‑id, autenticación/autorización, un README completo, y luego una revisión graphify contra los documentos antes de la entrega. Úsalo al iniciar/bootstrapping un nuevo proyecto backend para un equipo (khởi tạo dự án backend, dựng khung backend, init backend, setup docker compose + health check, bắt đầu dự án backend cho team). No es para: una característica, corrección de errores, pipeline o esquema en un proyecto existente (aizen-build).
