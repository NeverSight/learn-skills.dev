Inicializa un proyecto backend de equipo a partir de un repositorio de GitHub/GitLab y los documentos del proyecto, en 11 pasos secuenciales estrictos con puntos de control de revisión (v3) - Git Flow (develop + ramas feature), un plan aprobado en .aizen/runs/init/plans/, esqueleto backend con /health y /health/ready, Dockerfile multi‑etapa + compose con toda la infraestructura, .env/.env.example + una configuración central, conexiones de infraestructura fail‑fast, adaptadores detrás de interfaces (incluido el logger), capas AOP, middleware de request‑id, autenticación/autorización, un README completo, y luego una revisión graphify contra los documentos antes de la entrega. Úsalo al iniciar/inicializar un nuevo proyecto backend para un equipo (khởi tạo dự án backend, dựng khung backend, init backend, setup docker compose + health check, bắt đầu dự án backend cho team). No es para: una característica, corrección de errores, pipeline o esquema en un proyecto existente (aizen‑build).
