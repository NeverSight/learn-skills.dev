Verwandle ein Video in eine wiederverwendbare Agenten‑Fähigkeit. Es akzeptiert einen öffentlichen YouTube‑Link oder eine lokale Video‑/Audio‑Datei, extrahiert den gesprochenen Inhalt (zuerst vorhandene Untertitel, andernfalls ffmpeg, mp3, dann Speech‑to‑Text) und destilliert diesen Inhalt in einen neuen, standards‑konformen Fähigkeits‑Ordner (SKILL.md + Skripte + Referenzen), den jeder Agent nutzen kann. Verwende dies jedes Mal, wenn der Nutzer eine YouTube‑URL oder eine Video‑/Audio‑Datei teilt und eine Fähigkeit, einen Workflow, ein Playbook, eine SOP, eine Checkliste oder „Agenten‑Anweisungen“ daraus haben möchte, oder Formulierungen wie „aus diesem Video lernen“, „eine Fähigkeit aus diesem Tutorial erstellen“, „dieses Video in Anweisungen für Agenten umwandeln“ verwendet, selbst wenn das Wort „Fähigkeit“ nie genannt wird. Nicht geeignet für: das Importieren einer bestehenden Fähigkeit von GitHub (aizen-skill-importer) oder das Schreiben einer Fähigkeit aus eigenem Wissen (aizen-skill-creator).
