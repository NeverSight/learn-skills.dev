Verwandle ein Video in eine wiederverwendbare Agenten‑Fähigkeit. Akzeptiert einen öffentlichen YouTube‑Link oder eine lokale Video‑/Audiodatei, extrahiert den gesprochenen Inhalt (zuerst vorhandene Untertitel, sonst ffmpeg, mp3, dann Speech‑to‑Text) und destilliert diesen Inhalt anschließend in einen neuen, standardkonformen Fähigkeits‑Ordner (SKILL.md + Skripte + Referenzen), den jeder Agent nutzen kann. Verwende dies immer, wenn der Nutzer eine YouTube‑URL oder eine Video‑/Audiodatei teilt und eine Fähigkeit, einen Workflow, ein Playbook, ein SOP, eine Checkliste oder „Agenten‑Anweisungen“ daraus haben möchte, oder Sätze wie „aus diesem Video lernen“, „eine Fähigkeit aus diesem Tutorial erstellen“, „dieses Video in Anweisungen für Agenten umwandeln“ verwendet, selbst wenn er das Wort „Fähigkeit“ nie erwähnt. Nicht geeignet für: das Importieren einer bestehenden Fähigkeit von GitHub (aizen-skill-importer) oder das Erstellen einer Fähigkeit aus eigenem Wissen (aizen-skill-creator).

Bitte immer in der Sprache des Benutzers antworten.
