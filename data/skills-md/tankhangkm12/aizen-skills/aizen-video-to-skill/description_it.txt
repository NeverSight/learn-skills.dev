Trasforma un video in una skill riutilizzabile per l'agente. Accetta un link pubblico di YouTube o un file video/audio locale, estrae il contenuto parlato (prima i sottotitoli esistenti, altrimenti ffmpeg, mp3, poi speech‑to‑text), quindi distilla quel contenuto in una nuova cartella skill conforme agli standard (SKILL.md + script + riferimenti) che qualsiasi agente può utilizzare. Usa questa funzionalità ogni volta che l'utente condivide un URL di YouTube o un file video/audio e desidera una skill, un flusso di lavoro, un playbook, una SOP, una checklist o “istruzioni per l'agente” create da esso, o dice cose come “impara da questo video”, “crea una skill da questo tutorial”, “trasforma questo video in istruzioni per gli agenti”, anche se non usa mai la parola “skill”. Non è per: importare una skill esistente da GitHub (aizen‑skill‑importer) o scrivere una skill dalla tua conoscenza (aizen‑skill‑creator).

Rispondi sempre nella lingua dell'utente.
