Trasforma un video in una skill riutilizzabile per l'agente. Accetta un collegamento pubblico di YouTube o un file video/audio locale, estrae il contenuto parlato (prima i sottotitoli esistenti, altrimenti ffmpeg, mp3, poi speech-to-text), quindi distilla quel contenuto in una nuova cartella di skill conforme agli standard (SKILL.md + script + riferimenti) che qualsiasi agente può utilizzare. Usa questa procedura ogni volta che l'utente condivide un URL di YouTube o un file video/audio e desidera una skill, un flusso di lavoro, un playbook, una SOP, una checklist o “istruzioni per l'agente” costruite da esso, o dice cose come “impara da questo video”, “crea una skill da questo tutorial”, “trasforma questo video in istruzioni per gli agenti”, anche se non usa mai la parola “skill”. Non è destinata a: importare una skill esistente da GitHub (aizen‑skill‑importer) o scrivere una skill basandoti sulla tua conoscenza (aizen‑skill‑creator).

Rispondi sempre nella lingua dell'utente.
