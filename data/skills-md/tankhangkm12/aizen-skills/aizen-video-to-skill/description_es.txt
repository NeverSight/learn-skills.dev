Convierte un video en una skill reutilizable para el agente. Acepta un enlace público de YouTube o un archivo de video/audio local, extrae su contenido hablado (primero los subtítulos existentes, de lo contrario ffmpeg, mp3, luego reconocimiento de voz) y luego destila ese contenido en una nueva carpeta de skill que cumpla con los estándares (SKILL.md + scripts + referencias) que cualquier agente pueda usar. Utilízalo siempre que el usuario comparta una URL de YouTube o un archivo de video/audio y quiera una skill, flujo de trabajo, playbook, SOP, lista de verificación o “instrucciones para agentes” construidas a partir de él, o diga cosas como “aprende de este video”, “crea una skill a partir de este tutorial”, “convierte este video en instrucciones para agentes”, incluso si nunca menciona la palabra “skill”. No es para: importar una skill existente desde GitHub (aizen-skill-importer) o crear una skill a partir de tu propio conocimiento (aizen-skill-creator).

Por favor responde siempre en el idioma del usuario.
