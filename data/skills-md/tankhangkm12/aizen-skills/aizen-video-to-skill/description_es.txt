Convierte un video en una habilidad reutilizable para agentes. Toma un enlace público de YouTube o un archivo de video/audio local, extrae su contenido hablado (primero subtítulos existentes, de lo contrario ffmpeg, mp3, luego reconocimiento de voz), y luego destila ese contenido en una nueva carpeta de habilidad que cumpla con los estándares (SKILL.md + scripts + referencias) que cualquier agente pueda usar. Usa esto siempre que el usuario comparta una URL de YouTube o un archivo de video/audio y quiera una habilidad, flujo de trabajo, manual, SOP, lista de verificación o “instrucciones para agentes” construidas a partir de ello, o diga cosas como “aprende de este video”, “crea una habilidad a partir de este tutorial”, “convierte este video en instrucciones para agentes”, incluso si nunca menciona la palabra “habilidad”. No es para: importar una habilidad existente desde GitHub (aizen‑skill‑importer) o escribir una habilidad desde tu propio conocimiento (aizen‑skill‑creator).

Por favor, responde siempre en el idioma del usuario.
