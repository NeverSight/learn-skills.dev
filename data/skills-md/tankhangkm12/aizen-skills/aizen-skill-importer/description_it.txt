Porta conoscenza esterna dentro Aizen (v4) – sia una skill completa da una cartella GitHub o da un percorso locale (copia, normalizza allo standard Aizen, attribuisci la fonte e la licenza, personalizza con l'utente, dimostra che supera l'originale in un test A/B) o una best practice upstream aggiunta a un pacchetto esistente come conoscenza vendorizzata fissata (vendor.lock.json + bin/vendor.js). Usalo quando l'utente fornisce un link a una skill o una cartella da clonare, importare, forkare o adattare, oppure vuole imparare da un repository di skill popolare (clona skill, chép skill, lấy skill từ GitHub, học theo skill nhiều sao). Non è previsto per: scrivere una skill da zero o migliorare una già presente nel repo (aizen-skill-creator), o solo valutare una skill (aizen-skill-eval).
