Porta conoscenze esterne in Aizen (v4) – oppure un’intera skill da una cartella GitHub o da un percorso locale (copia, normalizza allo standard Aizen, accredita la fonte e la licenza, personalizza con l’utente, dimostra che supera l’originale in un test A/B) o best practice a monte aggiunte a un pacchetto esistente come conoscenza vendorizzata fissata (vendor.lock.json + bin/vendor.js). Usa quando l’utente fornisce un link a una skill o una cartella da clonare, importare, forkare o adattare, oppure vuole imparare da un repository di skill popolare (clone skill, chép skill, lấy skill từ GitHub, học theo skill nhiều sao). Non è per: scrivere una skill da zero o migliorare una già presente nel repository (aizen‑skill‑creator), o solo valutare una skill (aizen‑skill‑eval).

Rispondi sempre nella lingua dell’utente.
