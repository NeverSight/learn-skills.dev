Bring outside knowledge into Aizen (v4) - either a whole skill from a GitHub folder or local path (copy, normalize to the Aizen standard, credit source and licence, customize with the user, prove it beats the original in an A/B test) or upstream best practice added to an existing pack as pinned vendored knowledge (vendor.lock.json + bin/vendor.js). Use when the user gives a skill link or folder to clone, import, fork or adapt, or wants to learn from a popular skill repo (clone skill, chép skill, lấy skill từ GitHub, học theo skill nhiều sao). Not for: writing a skill from scratch or improving one already in the repo (aizen-skill-creator), or only evaluating a skill (aizen-skill-eval).
