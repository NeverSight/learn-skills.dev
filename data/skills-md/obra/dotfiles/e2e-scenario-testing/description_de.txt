Wird verwendet, wenn eine laufende Anwendung Ende-zu-Ende über ihre reale Schnittstelle — eine Web-Benutzeroberfläche, eine CLI oder eine TUI — überprüft wird, indem von Agenten ausgeführte "Szenario-Karten" gegen eine neu erstellte Instanz mit falsifizierbaren Behauptungen geschrieben und ausgeführt werden. Trigger auf "Ende-zu-Ende testen", "beweisen, dass die Benutzeroberfläche tatsächlich funktioniert", "ein Szenario schreiben/ausführen" oder nachdem eine Änderung eine benutzerorientierte Oberfläche berührt, die Unit-Tests nicht vollständig abdecken können. Nicht für Komponententests, reine Codeüberprüfungen oder reine API-Prüfungen.
