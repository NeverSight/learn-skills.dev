À utiliser lors de la vérification de bout en bout d'une application en cours d'exécution via son interface réelle (une interface utilisateur Web, une CLI ou une TUI) en écrivant et en exécutant des « cartes de scénario » exécutées par un agent sur une instance fraîchement construite avec des assertions falsifiables. Déclenchez-le sur « tester de bout en bout », « prouver que l'interface utilisateur fonctionne réellement », « écrire/exécuter un scénario » ou après qu'une modification touche une surface orientée utilisateur que les tests unitaires ne peuvent pas couvrir entièrement. Pas pour les tests unitaires, la révision pure du code ou les vérifications API uniquement.
