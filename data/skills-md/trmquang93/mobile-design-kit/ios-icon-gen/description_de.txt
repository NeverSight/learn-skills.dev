Generieren Sie iOS-App-Symbole als PNG-Bildsätze für Xcode-Asset-Kataloge. Zwei Quellen verfügbar – SF Symbols (in macOS integriert, über 5000 Symbole) und Iconify API (über 275.000 Open-Source-Symbole aus über 200 Sammlungen wie Material Design, Lucide, Tabler, Phosphor). Wird verwendet, wenn der Benutzer „Symbole generieren“, „Symbol-Assets erstellen“, „Symbole zum Asset-Katalog hinzufügen“ oder „nach Symbolen suchen“ auffordert oder PNG-Symbole für ein iOS-Projekt benötigt.
