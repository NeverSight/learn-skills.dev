iOS アプリのアイコンを Xcode アセット カタログ用の PNG イメージセットとして生成します。 SF Symbols (macOS 組み込み、5000 以上のアイコン) と Iconify API (マテリアル デザイン、Lucide、Tabler、Phosphor などの 200 以上のコレクションからの 275,000 以上のオープン ソース アイコン) の 2 つのソースが利用可能です。ユーザーが「アイコンの生成」、「アイコン アセットの作成」、「アセット カタログへのアイコンの追加」、「アイコンの検索」を要求する場合、または iOS プロジェクトで PNG アイコンが必要な場合に使用します。
