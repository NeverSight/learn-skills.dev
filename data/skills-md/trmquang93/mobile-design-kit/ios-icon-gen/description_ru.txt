Создавайте значки приложений iOS в виде наборов изображений PNG для каталогов ресурсов Xcode. Доступны два источника — SF Символы (встроенные в macOS, более 5000 значков) и Iconify API (более 275 тысяч значков с открытым исходным кодом из более чем 200 коллекций, таких как Material Design, Lucid, Tabler, Phosphor). Используйте, когда пользователь просит «создать значки», «создать ресурсы значков», «добавить значки в каталог ресурсов», «поиск значков» или ему нужны значки PNG для проекта iOS.
