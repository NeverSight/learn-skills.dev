Implemente un problema de GitHub o el trabajo acordado en la conversación como una solicitud de extracción, luego revíselo con agentes independientes, resuelva cada comentario de revisión y verifique cada ronda de correcciones antes de enviarlo. Úselo cuando el usuario le pida que envíe un problema o cambie de extremo a extremo, o que lo construya y luego cuide el PR. Para abrir solo la PR, use `implement-to-pr`.
