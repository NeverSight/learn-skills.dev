Интерактивный навык карты SRHR (пилот). Режим обновления преобразует новые внутренние файлы drop‑in в короткую рабочую книгу обзора, затем записывает ответы коллеги в новое издание реестра карты. Режим публикации помещает утверждённое издание реестра в наборы карт и создаёт из него рабочую книгу данных, набор данных Power BI и веб‑карту. Вызывается только по имени.
