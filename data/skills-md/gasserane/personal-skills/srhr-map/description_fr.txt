Compétence cartographique interactive SDSR (pilote). Le mode d'actualisation transforme les nouveaux fichiers internes en un bref classeur de révision, puis écrit les réponses d'un collègue dans une nouvelle édition du registre de cartes. Le mode Publier place une édition de registre approuvée dans les decks de carte et construit le classeur de données, le jeu de données Power BI et la carte Web à partir de celui-ci. Appeler uniquement par nom.
