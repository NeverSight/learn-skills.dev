Donnez à une application iOS un langage de mouvement cohérent : un petit ensemble de minuteries, de ressorts et d'haptiques nommés dans un seul Motion.swift, dérivé du propre code de l'application et de vraies applications expédiées avec la même sensation. À utiliser lorsqu'on vous demande de rendre les animations d'une application cohérentes, de créer des jetons de mouvement ou un système de mouvement, de nettoyer les valeurs d'animation dispersées ou de définir comment l'application doit se déplacer. SwiftUI, iOS uniquement.
