Crear, actualizar y trabajar con notas de tareas de Obsidian usando el plugin TaskNotes.  
Utiliza esta habilidad siempre que el usuario quiera: crear una nueva tarea, añadir algo a su lista de tareas, actualizar una tarea (estado, prioridad, fecha de vencimiento, agregar pasos), marcar una tarea como completada, archivar una tarea o consultar qué tareas tiene (abiertas, vencidas, importantes, por proyecto). También se activa cuando el usuario está dentro de una nota de tarea y necesita ayuda — por ejemplo, “agregar un paso a esta tarea”, “marcar esto como en progreso”, “¿qué está vencido?”, “¿qué debería hacer? ”, “Tengo 2 horas, ¿qué puedo abordar?”. Se activa cada vez que la gestión de tareas está involucrada en la bóveda de Obsidian.  

Por favor, responde siempre en el idioma del usuario.
