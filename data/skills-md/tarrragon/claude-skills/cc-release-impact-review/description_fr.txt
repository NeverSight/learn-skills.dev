Outil d'évaluation d'impact du cadre des notes de version Claude Code. Comparez la dernière version révisée pour filtrer les nouvelles versions, classez chaque élément (utile pour le cadre / nécessite une évaluation / aucun impact / non applicable) et orientez les éléments d'adoption afin de mettre en œuvre ANA + WRAP + spawn. Utilisation : exécuter /release-notes pour voir les nouvelles versions, vérifier régulièrement les mises à jour CC, évaluer l'impact des nouvelles fonctionnalités sur le cadre du projet. Déclencheurs : notes de version, release-notes, mises à jour CC, mises à jour de Claude Code, évaluation des mises à jour de version, évaluation des nouvelles fonctionnalités, évaluation d'impact du cadre. Veuillez toujours répondre dans la langue de l'utilisateur.
