Strumento di valutazione dell'impatto del framework per le note di rilascio di Claude Code. Confronta l'ultima versione revisionata per filtrare le nuove versioni, classifica ogni elemento (utile per il framework / necessita di valutazione / nessun impatto / non applicabile) e guida gli elementi di adozione per implementare ANA + WRAP + spawn. Utilizzare quando: si esegue /release-notes e si osserva una nuova versione, si controllano regolarmente gli aggiornamenti CC, si valuta l'impatto delle nuove funzionalità sul framework del progetto. Trigger: note di rilascio, release-notes, aggiornamenti CC, aggiornamenti del codice Claude, valutazione dell'aggiornamento di versione, valutazione di nuove funzionalità, valutazione dell'impatto del framework.

Si prega di rispondere sempre nella lingua dell'utente.
