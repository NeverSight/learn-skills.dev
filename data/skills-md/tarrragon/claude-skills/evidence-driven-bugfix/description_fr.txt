Processus de débogage basé sur les preuves. Utilisation : (1) Flux de travail structuré de correction de bugs (reproduire → test échouant → cause racine → correction minimale → protection contre les régressions), (2) Prévenir les conjectures aveugles lors des corrections, (3) Garantir que chaque correction est vérifiable, traçable et cumulative. À utiliser lorsqu : réception d’un rapport de bug, échecs de tests nécessitant une investigation, problèmes en environnement de production à corriger, toute modification de code qui n’est pas une nouvelle fonctionnalité.
