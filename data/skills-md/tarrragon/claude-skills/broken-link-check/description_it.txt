Strumento di rilevamento dei link rotti. Scansiona tutti i file Markdown nella directory `.claude/` per riferimenti di percorso e individua i link interrotti. Uso per: (1) scansione una tantum di tutti i link rotti, (2) monitoraggio periodico insieme a `/loop`, (3) verifica dell’integrità dei percorsi dopo aver modificato i file rule/methodology/agent. Da utilizzare quando: l’utente esegue `/broken-link-check`, oppure lo esegue periodicamente con `/loop`, o dopo aver riscontrato un errore di link rotto.
