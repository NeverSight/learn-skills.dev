Broken-link detection tool. Scans all Markdown files in the .claude/ directory for path references and detects broken links. Use for: (1) one-time scanning of all broken links, (2) periodic monitoring together with /loop, (3) verifying path integrity after modifying rule/methodology/agent files. Use when: the user runs /broken-link-check, or runs it periodically with /loop, or after discovering a broken-link error.
