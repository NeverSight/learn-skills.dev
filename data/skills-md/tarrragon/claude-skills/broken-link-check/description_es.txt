Herramienta de detección de enlaces rotos. Analiza las referencias de rutas en todos los archivos Markdown dentro del directorio .claude/ para detectar enlaces rotos. Uso: (1) escaneo único de todos los enlaces rotos, (2) monitoreo periódico con /loop, (3) verificar la integridad de rutas tras modificar archivos de regla/metodología/agente. Se emplea cuando el usuario ejecuta /broken-link-check, lo combina con /loop para una ejecución regular, o descubre un error de enlace roto.
