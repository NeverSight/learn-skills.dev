Инструмент проверки при запуске сеанса, восстанавливающий отложенные задачи передачи, проверяющий окружение Git и подтверждающий состояние разработки. Использовать для: (1) проверки окружения при старте сеанса, (2) обнаружения отложенных задач передачи для возобновления, (3) подтверждения статуса Git и среды разработки.
