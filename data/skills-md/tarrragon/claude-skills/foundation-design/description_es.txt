El punto de entrada único y la capa de enrutamiento para el trabajo de base. Determine “cuáles son los entregables de base de este proyecto” dimensión por dimensión; la autoridad solo proporciona entregables predeterminados, y cuando el formato no coincide, reescriba el entregable en lugar de omitir la dimensión. Las dimensiones incluyen UI, testing, base de datos, DevOps, observabilidad y arbitraje de flujos de eventos, nombrando cada una la autoridad existente y especificando el manejo cuando la autoridad está ausente. Aplicable de manera uniforme a proyectos nuevos y antiguos: al tomar el control de un proyecto ajeno, primero inventariar, extraer, luego renombrar y consolidar. Palabras clave: foundation, foundation wave, component library, design token, fixture, seed, migration, scaffold, scaffolding, taking over an old project. No usar para la configuración del entorno (use project‑init).
