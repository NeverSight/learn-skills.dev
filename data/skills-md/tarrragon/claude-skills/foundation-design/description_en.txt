A single entry point and routing layer for foundation work. Determine “what the foundation artifacts of this project are” dimension by dimension; the authority only provides default artifacts, and when the form does not match, it rewrites the artifact rather than skipping the dimension. Dimensions include UI, testing, database, DevOps, observability, and event‑stream arbitration, each naming an existing authority and specifying the handling when the authority is absent. Applicable to both new and legacy projects as a unified approach: when taking over someone else’s project, first inventory and extract, then rename and solidify. Trigger words: foundation, foundation wave, component library, design token, fixture, seed, migration, scaffold, scaffolding, takeover of old project. Do NOT use for environment setup (use project‑init).
