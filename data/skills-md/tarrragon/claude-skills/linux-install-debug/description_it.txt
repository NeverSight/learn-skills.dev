Protocollo diagnostico standardizzato per l'installazione di un nuovo Linux (VM o fisico) o per la risoluzione di problemi di sistemi Linux/macOS. La disciplina fondamentale è leggere lo stato autorevole, non fare affidamento su ipotesi visive: prima determinare le coordinate della piattaforma (distribuzione / architettura / gestore pacchetti), poi consultare la fonte autorevole corrispondente in base ai sintomi. Copre SSH che non si collega, output del terminale illeggibile, servizio fallito o ciclo di riavvio, processo attivo ma sottosistemi morti, permesso negato, fallimenti del gestore pacchetti, disco pieno e filesystem in sola lettura, audio silenzioso, schermo nero VT, terminazione per OOM, e trasformare i fallimenti in avvisi push. Trigger: installazione di Linux, nuova VM, verifica al primo avvio, ssh che non si collega, connessione rifiutata, timeout di connessione, terminale illeggibile, systemctl status, journalctl, servizio fallito, ciclo di riavvio, processo attivo ma non risponde, pgrep fuorviante, permesso negato, EACCES, operazione non permessa, comando non trovato, impossibile individuare il pacchetto, blocco dpkg, blocco db pacman, aggiornamento parziale, variabile non definita, script shell portabile, bash 3.2, timeout non trovato, contenitore senza sudo, keyring scaduto, PATH non rilevato, disco pieno, filesystem in sola lettura, OOM, exit 137, dmesg, schermo nero, getty, chvt, nessun suono, wpctl, errore di risoluzione DNS, macchina non responsiva, avviso di servizio, OnFailure, ntfy, monitoraggio heartbeat, installazione Linux, debug Linux, systemd, stato autorevole.
