用于新建 Linux（虚拟机或实机）或排查 Linux/macOS 系统问题的标准化诊断方案。核心原则是读取权威状态，而非依赖肉眼猜测：首先确定平台坐标（发行版 / 架构 / 包管理器），随后根据症状查阅对应的权威来源。涵盖 SSH 连接失败、终端输出乱码、服务启动失败或重启循环、进程仍在但子系统死亡、权限被拒、包管理器错误、磁盘已满并导致文件系统只读、声音无声、虚拟终端黑屏、被 OOM 杀死，以及将故障转化为推送告警。触发场景包括：安装 Linux、新建 VM、首次启动验证、ssh 无法连接、连接被拒绝、连接超时、终端乱码、systemctl status、journalctl、服务失败、重启循环、进程存活但无响应、pgrep 误导、权限被拒、EACCES、操作不被允许、命令未找到、无法定位软件包、dpkg 锁、pacman 数据库锁、部分升级、未绑定变量、可移植 shell 脚本、bash 3.2、timeout 未找到、容器无 sudo、密钥环过期、PATH 未生效、磁盘满、文件系统只读、OOM、退出码 137、dmesg、黑屏、getty、chvt、无声、wpctl、DNS 解析失败、机器无响应、服务告警、OnFailure、ntfy、心跳监控、Linux 安装、Linux 调试、systemd、权威状态。
