Protocole de diagnostic standard pour l'installation d'un nouveau Linux (VM ou machine physique) ou le diagnostic de problèmes système sous Linux/macOS. La discipline centrale consiste à lire l'état autoritaire, sans se fier aux suppositions visuelles : déterminer d'abord les coordonnées de la plateforme (distribution/architecture/gestionnaire de paquets), puis consulter les sources autoritaires correspondantes en fonction des symptômes. Couvre les échecs de connexion SSH, la sortie terminale illisible, les services qui échouent ou entrent en boucles de redémarrage, les processus vivants mais les sous‑systèmes morts, les refus de permission, les échecs du gestionnaire de paquets, le disque plein et le système de fichiers en lecture‑seule, l'audio muet, l'écran noir VT, les terminaisons par OOM, et la transformation des échecs en alertes push. Déclencheurs : installation de Linux, nouvelle VM, vérification du premier démarrage, ssh ne se connecte pas, connexion refusée, délai d’attente de connexion, terminal illisible, systemctl status, journalctl, service échoué, boucle de redémarrage, processus vivant mais non réactif, pgrep trompeur, permission refusée, EACCES, opération non autorisée, commande introuvable, impossible de localiser le paquet, verrou dpkg, verrou base de données pacman, mise à jour partielle, variable non liée, script shell portable, bash 3.2, timeout introuvable, conteneur sans sudo, trousseau expiré, PATH non défini, disque plein, système de fichiers en lecture‑seule, OOM, sortie 137, dmesg, écran noir, getty, chvt, absence de son, wpctl, échec de résolution DNS, machine non réactive, alerte de service, OnFailure, ntfy, surveillance heartbeat, installation Linux, débogage Linux, systemd, état autoritaire.
