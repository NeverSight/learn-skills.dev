一套標準化的診斷流程，用於安裝新的 Linux（虛擬機或實體機）或排除 Linux/macOS 系統問題。核心原則是讀取權威狀態，而非依賴視覺猜測：首先確定平台坐標（發行版、架構、套件管理器），然後根據症狀查閱相應的權威來源。涵蓋 SSH 連線失敗、終端輸出雜亂、服務失敗或處於重啟迴圈、進程存活但子系統死亡、權限被拒、套件管理器失敗、磁碟滿與唯讀檔案系統、無聲音、VT 黑屏、被 OOM 殺死，以及將失敗轉為推送警報。

觸發條件：安裝 Linux、新建 VM、首次開機驗證、ssh 無法連線、連線被拒絕、連線逾時、終端雜亂、systemctl status、journalctl、服務失敗、重啟迴圈、進程存活但無回應、pgrep 欺騙、權限被拒、EACCES、操作不允許、指令找不到、無法定位套件、dpkg 鎖定、pacman db 鎖定、部分升級、未綁定變數、可移植 shell 腳本、bash 3.2、找不到 timeout、容器未使用 sudo、金鑰環過期、PATH 未被取得、磁碟滿、唯讀檔案系統、OOM、退出碼 137、dmesg、黑屏、getty、chvt、無聲音、wpctl、DNS 無法解析、主機無回應、服務警報、OnFailure、ntfy、心跳監控、linux 安裝、linux 除錯、systemd、權威狀態。
