Protocolo de diagnóstico estandarizado para la instalación de un nuevo Linux (VM o físico) o la resolución de problemas en sistemas Linux/macOS. La disciplina central es leer el estado autorizado, no basarse en conjeturas visuales: primero determinar las coordenadas de la plataforma (distribución / arquitectura / gestor de paquetes), luego consultar la fuente autorizada que coincida con los síntomas. Incluye SSH que no se conecta, caracteres garbled en el terminal, servicio fallado o bucle de reinicio, proceso activo pero subsistema muerto, permiso denegado, fallos del gestor de paquetes, disco lleno y sistema de archivos de solo lectura, sin audio, pantalla negra del VT, ser asesinado por OOM y convertir fallos en alertas push. Disparadores: instalación de Linux, nueva VM, verificación del primer arranque, ssh que no se conecta, conexión rechazada, tiempo de espera de conexión, terminal garbled, systemctl status, journalctl, servicio fallado, bucle de reinicio, proceso activo pero no responde, pgrep engañoso, permiso denegado, EACCES, operación no permitida, comando no encontrado, no se puede localizar el paquete, bloqueo de dpkg, bloqueo de la base de datos de pacman, actualización parcial, variable no vinculada, script de shell portátil, bash 3.2, timeout no encontrado, contenedor sin sudo, anillo de claves expirado, PATH no heredado, disco lleno, sistema de archivos de solo lectura, OOM, salida 137, dmesg, pantalla negra, getty, chvt, sin sonido, wpctl, DNS no puede resolver, máquina no responde, alerta de servicio, OnFailure, ntfy, monitorización de latidos, instalación de Linux, depuración de Linux, systemd, estado autorizado.
