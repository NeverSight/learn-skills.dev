Extrae patrones reutilizables de sesiones de Claude Code y captura el conocimiento con una priorización en tiempo de captura: los aprendizajes relevantes para el marco (que siguen siendo válidos después de cambiar nombres/rutas de proyectos) van directamente a la capa canónica del marco (patrones de error/reglas/metodologías/referencias), los aprendizajes relevantes para el proyecto van a docs/CLAUDE.md, y los hallazgos exclusivos de la sesión no se registran. La memoria nativa de Claude Code se excluye como destino — esta capa de patrones de error del marco la reemplaza para reutilización entre proyectos. Úsalo cuando la sesión finalice (hook de Stop), al registrar decisiones técnicas, ideas de implementación o lecciones aprendidas. Gestiona la detección automática de patrones y la captura estructurada de conocimiento con enlaces interconectados, evitando que los principios entre proyectos queden atrapados en un almacenamiento de un solo proyecto.
