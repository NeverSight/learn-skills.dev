Claude Code 세션에서 재사용 가능한 패턴을 추출하고 캡처 시점에서 트리아지를 통해 지식을 기록합니다: 프레임워크와 관련된 학습 내용(프로젝트 이름·경로를 바꾸어도 여전히 유효한 것)은 바로 정형 프레임워크 계층(오류‑패턴·규칙·방법론·참고자료)으로 이동하고, 프로젝트와 관련된 학습 내용은 docs/CLAUDE.md에 저장되며, 세션 전용 결과는 기록되지 않습니다. Claude Code의 기본 메모리는 저장 대상으로 제외되며, 이 프레임워크의 오류‑패턴 계층이 교차 프로젝트 재사용을 위해 이를 대체합니다. 세션이 종료될 때(Stop 훅), 기술적 결정·구현 인사이트·학습 내용을 기록할 때 사용합니다. 자동 패턴 감지와 구조화된 지식 캡처를 상호 연결된 링크와 함께 처리하여 교차 프로젝트 원칙이 단일 프로젝트 저장소에 갇히는 것을 방지합니다.
