يستخرج الأنماط القابلة لإعادة الاستخدام من جلسات Claude Code ويسجل المعرفة عبر فرز وقت الالتقاط: تُوجه التعلمات المتعلقة بالإطار (التي تظل صحيحة بعد تغيير أسماء/مسارات المشاريع) مباشرة إلى طبقة الإطار المبدئية (أنماط الأخطاء/القواعد/المنهجيات/المراجع)، بينما تُسجل التعلمات الخاصة بالمشروع في docs/CLAUDE.md، ولا تُسجل الاكتشافات الخاصة بالجلسة فقط. تُستبعد الذاكرة الأصلية لـ Claude Code كوجهة — حيث تحل طبقة أنماط الأخطاء في هذا الإطار محلها لإعادة الاستخدام عبر المشاريع. يُستخدم عند انتهاء الجلسة (قابض الإيقاف)، عند تسجيل القرارات التقنية، أو الأفكار التنفيذية، أو الدروس المستفادة. يتعامل مع الكشف التلقائي عن الأنماط وتسجيل المعرفة المهيكلة بروابط مترابطة، مما يمنع حجز المبادئ عبر المشروع في تخزين خاص بمشروع واحد.
