Извлекает переиспользуемые шаблоны из сессий Claude Code и фиксирует знания с триажем в момент захвата: учебные материалы, относящиеся к фреймворку (по‑прежнему актуальные после замены названий/путей проектов), напрямую попадают в канонический слой фреймворка (error‑patterns/правила/методологии/ссылки), релевантные проекту знания сохраняются в docs/CLAUDE.md, а находки, относящиеся только к сессии, не записываются. Родная память Claude Code исключена в качестве места назначения — слой error‑patterns данного фреймворка заменяет её для межпроектного повторного использования. Используется при завершении сессии (hook Stop), при фиксации технических решений, инсайтов реализации или извлечённых уроков. Обеспечивает автоматическое обнаружение шаблонов и структурированный захват знаний со взаимосвязанными ссылками, не позволяя межпроектным принципам застревать в хранилище отдельного проекта.
