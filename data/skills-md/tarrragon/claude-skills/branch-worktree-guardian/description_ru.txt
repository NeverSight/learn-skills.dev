Branch Worktree Guardian — инструмент для управления ветками и рабочими деревьями Git. Используется для: (1) создания изолированных веток для новых требований разработки, (2) применения механизма worktree для избежания конфликтов веток, (3) проверки корректности текущей рабочей ветки, (4) предотвращения разработки в неправильной ветке.
