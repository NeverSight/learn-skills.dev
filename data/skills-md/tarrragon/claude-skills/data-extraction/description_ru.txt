Разрабатывает стратегии веб‑скрейпинга/извлечения данных: анализ DOM, многоуровневые селекторы с резервными вариантами, валидация, отображение трансформаций, планирование производительности. Используйте при планировании скрейпинга сайта, извлечении структурированных данных из HTML/DOM или обработке пагинации/защиты от скрейпинга. Триггеры: 資料提取, 抓取策略, web scraping, 選擇器設計, 爬蟲規劃. Не используйте для реализации кода скрейпера.
