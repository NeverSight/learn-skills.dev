Fonctions de gestion d'événements Dart et vérification de la traçabilité des annotations dans la couche UseCase/Domaine. Utilisé pour : (1) scanner automatiquement, après une écriture/modification, les fonctions de gestion d'événements et les widgets autonomes dépourvus d'annotations de traçabilité ; (2) générer des rapports de qualité incluant des modèles d'annotations suggérés ; (3) prendre en charge les vérifications d'annotations multilingues, principalement pour Dart avec JavaScript/TypeScript en second. Scénario de déclenchement : Hook PostToolUse (correspondance : Write | Edit), revue de code dans une architecture orientée événements.
