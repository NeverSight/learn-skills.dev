Includes multi‑round‑review completeness checks, split‑axis selection, pending blockedBy bound to a version, and foundation tickets opened first. The sequence is an order, not a gate, and does not tie to full Agile. Trigger words: version planning, version sequence, integration test order, schedule version, ticket planning, milestone, roadmap. Use when the specification is finished, before writing the first implementation ticket. Do NOT use for planning waves within a single version (use version‑bootstrap).
