Tool zur Aufteilung von Unteraufgaben und Auslagerung des Kontexts. Teile eine große Aufgabe, die in N Unter‑Tickets aufgeteilt werden kann, wobei jedes unabhängig von einem Agenten ausgeführt wird und die Schlussfolgerungen direkt in das Ticket geschrieben werden, ohne an den Hauptthread zurückzumelden. Verwendung für: Batch‑Dateievaluierung, Aufteilung großer Prüfungsaufgaben, jede Aufgabe, die das Lesen großer Datenmengen erfordert, deren Ergebnisse jedoch in ein Ticket eingetragen werden können.
