منهجية كتابة دليل الترحيل عبر البائعين: تدقيق أبعاد الفرق في 6 أبعاد (المخطط / التشغيلي / النموذجية / المكونات / تغير التطبيق / طوبولوجيا البيانات) + 6 نماذج هيكلية (النوع A ترجمة مرحلية / النوع B دمج مباشر / النوع C هجين تشغيلي / النوع D تدفقات متوازية / النوع E تحول نموذجي / النوع F إعادة تنظيم الطوبولوجيا) + تخطيط متغير المرحلة 0 (يشمل التخطيط متعدد العناصر) + نمط تدقيق بأربعة مراجع + قيود ذاتية الوعي. الكلمات المفتاحية: دليل الترحيل، ترحيل عبر البائعين، النوع A B C D E F، تدقيق أبعاد الفرق، تدقيق طوبولوجيا البيانات، متغير المرحلة 0، تخطيط متغير متعدد العناصر، هيكل الترحيل، عملية عبر البائعين، إعادة تنظيم النوع F، ترقية النسخة الرئيسية، إعادة تقسيم الشرائح، إعادة تصميم الأقسام، الترحيل المدفوع بالسياسة، دمج الاستحواذ، ترحيل دليل الأدلة الامتثال. يُفعل عند كتابة محتوى دليل الترحيل / عملية عبر البائعين.
