Инструмент контроля стиля и текста проекта Dart/Flutter: сканирует сырые коды цветов, сырые отступы, сырые размеры шрифтов, сырые радиусы углов и жёстко закодированный текст; указывает, какой токен или i18n‑ключ следует использовать вместо них; и блокирует новые нарушения с помощью хуka PostEdit. Триггерные слова: raw value, hard‑coded color, hard‑coded text, style violation, style guardian, unused token, i18n missing translation. НЕ используйте его для создания системы токенов (используйте foundation‑design) или проектирования контракта компонентов (используйте component‑contract‑design).
