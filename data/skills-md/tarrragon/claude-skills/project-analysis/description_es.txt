Procedimiento de análisis al asumir o colaborar en el proyecto de otra persona: declarar al inicio que no está en modo de proyecto del framework, compilar inventario, funcionalidad, pruebas y observabilidad, y consolidar todo en una lista de ítems de trabajo para la entrega. Palabras clave: tomar el proyecto, análisis del proyecto, inventario del repositorio de otra persona, proyecto colaborativo, carpeta externa, la otra parte no tiene sistema de tickets. No aplicable a proyectos que se incorporarán a este framework para desarrollo continuo.
