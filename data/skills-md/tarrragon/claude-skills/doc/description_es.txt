Sistema de seguimiento de documentos de requisitos (propuestas/especificaciones/casos de uso) para consulta, creación, navegación y gestión. Uso para: (1) consultar documentos de propuestas, especificaciones y casos de uso; (2) crear nuevas propuestas/especificaciones/casos de uso (a partir de plantillas); (3) navegación cruzada de documentos (encontrar especificación/ticket a partir de un caso de uso); (4) consultas de mapas de dominio; (5) gestión del índice de seguimiento; (6) verificación del mapeo de pruebas de casos de uso; (7) evaluación y revisión de propuestas; (8) consultas de la matriz de trazabilidad de pruebas (estado de cobertura UC↔prueba); (9) gobernanza de numeración de casos de uso (la lista de UC enumera UCs válidos / la verificación de lista blanca de UC permite la adjunción CI / rastreo de referencias de trazas de UC / despacho de contexto de UC para localizar UC). Uso cuando: el usuario menciona PROP‑, UC‑, SPEC‑, 功能, requirement, feature, issue, proposal, use case, specification, requirement document, requirement tracking, test coverage, traceability, test‑map, UC number, number verification, uc verify, pseudo UC, o una lista de UC válida.
