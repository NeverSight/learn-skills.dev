Chrome 擴充功能實機測試與除錯工作流程，使用 chrome‑devtools‑mcp 為核心工具。使用情境：(1) 完成功能後，執行實機驗證／手動測試／試玩／執行測試／驗證功能；(2) 擴充功能除錯／彈出視窗無法運作／內容腳本未注入／Service Worker 錯誤／背景問題；(3) 安裝未打包的擴充功能／載入未打包／載入未捆綁的程式碼；(4) 檢視 console／network／log／檢查請求；(5) 功能更新後重新載入擴充功能／重新建置並重新載入／重新載入擴充功能。涵蓋 Manifest V3 Service Worker、內容腳本、彈出視窗與設定頁面的 chrome‑devtools‑mcp 工具呼叫流程。此工具不取代 Puppeteer 或 Playwright 的自動化 E2E（CI 用），僅用於開發期間的手動驗證與 LLM 輔助除錯。
