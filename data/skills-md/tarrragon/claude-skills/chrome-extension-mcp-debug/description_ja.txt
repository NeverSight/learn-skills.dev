Chrome拡張機能の実機テストとデバッグワークフローで、chrome‑devtools‑mcp をコアツールとして使用します。使用する場面: (1) 機能実装が完了した後に、実機での検証／手動テスト／試してみる／テスト実行／機能の確認を行うとき； (2) 拡張機能のデバッグ（ポップアップが動作しない／コンテンツスクリプトが注入されない／サービスワーカーエラー／バックグラウンドの問題）が必要なとき； (3) パックされていない拡張機能をインストール／アンパックされた拡張機能を読み込む／非パッケージ拡張機能をロードするとき； (4) コンソール／ネットワーク／ログを確認／コンソールを表示／リクエストを検査するとき； (5) 機能を更新した後に、拡張機能をリロード／再ビルドしてリロード／拡張機能を再読み込みするとき。  

Manifest V3 のサービスワーカー、コンテンツスクリプト、ポップアップ、オプションページに対する chrome‑devtools‑mcp ツールの呼び出しフローを網羅しています。  

Puppeteer／Playwright による自動化E2E（CI 用）を置き換えるものではなく、開発中の手動検証および LLM 補助デバッグを目的としています。
