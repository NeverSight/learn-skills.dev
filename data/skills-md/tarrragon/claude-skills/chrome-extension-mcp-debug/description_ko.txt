Chrome Extension 실기기 테스트 및 디버깅 워크플로우, 핵심 도구로 chrome‑devtools‑mcp 사용. 사용 상황: (1) 기능을 완료한 후 실기기 검증·수동 테스트·시도·실행·기능 검증, (2) 확장 디버그·팝업 작동 안 함·콘텐츠 스크립트 미주입·서비스 워커 오류·백그라운드 문제, (3) 언팩된 확장 설치·언팩 로드·패키지되지 않은 로드, (4) 콘솔 보기·네트워크 보기·로그 보기·요청 검사, (5) 기능 업데이트 후 확장 재로드·재빌드 재로드·확장 재로드. Manifest V3 서비스 워커·콘텐츠 스크립트·팝업·옵션 페이지에 대한 chrome‑devtools‑mcp 호출 흐름을 다룸. Puppeteer·Playwright 자동 E2E(CI)를 대체하지 않으며, 개발 중 수동 검증 및 LLM‑지원 디버깅을 위해 사용.
