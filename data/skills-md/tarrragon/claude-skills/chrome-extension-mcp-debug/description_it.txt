Flusso di lavoro per il test e il debug di estensioni Chrome su dispositivi reali, con chrome-devtools-mcp come strumento principale. Da usare quando: (1) verifica su un dispositivo reale dopo aver completato una funzionalità / test manuale / provarla / eseguirla / verificare la funzionalità, (2) debug dell’estensione / popup non funzionante / content script non iniettato / errore del service worker / problemi di background, (3) installazione di un’estensione unpacked / load unpacked / caricare un’estensione non impacchettata, (4) visualizzare console / visualizzare network / visualizzare log / ispezionare le richieste, (5) ricaricare l’estensione dopo l’aggiornamento di una funzionalità / rebuild reload / reload extension. Copre il flusso di invocazione dello strumento chrome-devtools-mcp per Manifest V3 service worker / content script / popup / options page. Non sostituisce l’automazione E2E di Puppeteer / Playwright (per CI); è destinato alla verifica manuale durante lo sviluppo e al debug assistito da LLM.
