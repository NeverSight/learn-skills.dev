سير عمل اختبار ملحق Chrome على الجهاز الفعلي وتصحيح الأخطاء، باستخدام chrome‑devtools‑mcp كأداة أساسية. يُستَخدم عندما: (1) التحقق من الميزة بعد الانتهاء / اختبار يدوي / تجربة الفعلية / تشغيل اختبار / التحقق من الميزة، (2) تصحيح الملحق / عدم عمل النافذة المنبثقة / عدم حقن سكريبت المحتوى / خطأ في خدمة العامل / مشاكل الخلفية، (3) تثبيت ملحق غير مضغوط / تحميل غير مضغوط / تحميل غير معبأ، (4) عرض وحدة التحكم / عرض الشبكة / عرض السجل / فحص الطلبات، (5) إعادة تحميل الملحق بعد تحديث الميزة / إعادة بناء وإعادة تحميل / إعادة تحميل الملحق. يغطي تدفق استدعاء أداة chrome‑devtools‑mcp لخدمة العامل / سكريبت المحتوى / النافذة المنبثقة / صفحة الخيارات في Manifest V3. ليس بديلاً عن Puppeteer / Playwright للأتمتة المتكاملة (للـ CI)؛ يهدف إلى التحقق اليدوي أثناء التطوير وتصحيح الأخطاء بمساعدة نموذج اللغة كبير.
