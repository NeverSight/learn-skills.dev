Chrome‑Extension‑Testing und Debug‑Workflow auf Realgeräten, wobei chrome-devtools-mcp als Kernwerkzeug verwendet wird. Einsatzmöglichkeiten: (1) Nach Abschluss eines Features reale Geräte‑Verifizierung / manueller Test / ausprobieren / ausführen / Feature prüfen, (2) Extension‑Debugging / Popup funktioniert nicht / Content‑Script nicht injiziert / Service‑Worker‑Fehler / Hintergrundproblem, (3) Ungepackte Extension installieren / ungepackt laden / entpackt laden, (4) Konsole ansehen / Netzwerk ansehen / Log ansehen / Anfragen inspizieren, (5) Nach einem Feature‑Update die Extension neu laden / neu bauen & neu laden / Extension neu laden. Beschreibt den Aufrufablauf des Tools chrome-devtools-mcp für Manifest V3 Service‑Worker / Content‑Script / Popup / Options‑Seite. Ersetzt nicht Puppeteer / Playwright automatisierte E2E‑Tests (für CI); es ist für manuelle Verifikation während der Entwicklung und LLM‑unterstützte Fehlersuche gedacht.
