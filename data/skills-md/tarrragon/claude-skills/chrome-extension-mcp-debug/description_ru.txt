Рабочий процесс тестирования и отладки Chrome‑расширения на реальном устройстве, где в качестве основного инструмента используется chrome-devtools-mcp. Применяется, когда: (1) после завершения разработки функции выполнить проверку на реальном устройстве / ручное тестирование / попробовать / запустить / проверить функцию; (2) отладка расширения / не работает всплывающее окно / скрипт содержимого не внедряется / ошибка сервис‑воркера / проблема фонового процесса; (3) установка неупакованного расширения / загрузка непакетированного; (4) просмотр консоли / мониторинг сети / просмотр журнала / инспекция запросов; (5) после обновления функции перезагрузить расширение / пересобрать и перезагрузить / перезагрузить расширение. Охватывает поток вызовов инструмента chrome-devtools-mcp для сервис‑воркера, скрипта содержимого, всплывающего окна и страницы настроек в Manifest V3. Не заменяет автоматизированные E2E‑тесты Puppeteer / Playwright (для CI); предназначен для ручной проверки в процессе разработки и отладки с поддержкой LLM.
