Flux de travail de test sur appareil réel et de débogage d’extension Chrome, avec chrome-devtools-mcp comme outil principal. À utiliser lorsque : (1) après avoir terminé une fonctionnalité, effectuer une vérification sur appareil réel / test manuel / l’essayer / l’exécuter / valider la fonctionnalité, (2) débogage d’extension / popup qui ne fonctionne pas / script de contenu non injecté / erreur de service worker / problème en arrière‑plan, (3) installer une extension non empaquetée / charger non empaqueté / charger une extension non packagée, (4) consulter la console / le réseau / le journal / inspecter les requêtes, (5) après une mise à jour de fonctionnalité, recharger l’extension / reconstruire et recharger / recharger l’extension. Couvre le flux d’invocation de l’outil chrome-devtools-mcp pour le service worker, le script de contenu, le popup et la page d’options de Manifest V3. Il ne remplace pas les tests E2E automatisés avec Puppeteer / Playwright (pour CI) ; il est destiné à la vérification manuelle pendant le développement et au débogage assisté par LLM.
