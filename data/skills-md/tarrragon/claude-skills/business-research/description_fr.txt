Cette compétence doit être utilisée lorsque des recherches sont nécessaires avant de rédiger une analyse commerciale — collecter des données financières, vérifier des affirmations, trouver des références sectorielles ou vérifier les faits dans les discussions commerciales sur les réseaux sociaux. Déclencheurs : « find the financial data », « verify this claim », « search for company financials », « check if this is true », « gather industry data », « fact-check », « find the source », « what does the financial report say », « pull the numbers », « is this accurate », « research before writing », « collect data for analysis ». Fournit un flux de travail systématique de collecte et de vérification des données afin de prévenir les hallucinations et de garantir que l’analyse repose sur des données publiques.
