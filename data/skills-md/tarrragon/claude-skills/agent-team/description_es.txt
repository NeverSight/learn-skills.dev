Guía de Despacho de Colaboración de Equipos de Agentes. Use cuando: (1) los hallazgos del Agente A cambian el trabajo que el Agente B está realizando actualmente, (2) el usuario solicita el uso de un equipo/enjambre, (3) varios agentes necesitan negociar una interfaz compartida o un contrato de API en tiempo real. Cubre la creación de equipos, el puente entre tickets y tareas, la incorporación de compañeros de equipo y la gestión del ciclo de vida.

Por favor, responda siempre en el idioma del usuario.
