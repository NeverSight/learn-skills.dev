دليل توزيع التعاون بين فرق الوكلاء. يُستخدم عندما: (1) اكتشاف الوكيل A سيغيّر العمل الذي يقوم به الوكيل B حالياً، (2) يطلب المستخدم استخدام فريق/سرب، (3) يحتاج عدة وكلاء إلى التفاوض على واجهات مشتركة أو عقود API في الوقت الفعلي. يغطي إنشاء الفريق، ربط التذاكر بالمهام، إعداد الزملاء الجدد، وإدارة دورة الحياة.
