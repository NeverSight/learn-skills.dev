Фреймворк оценки дизайна утверждений для проблем со «хрупкостью» и качеством дизайна. Используйте его при написании тестов, проверке утверждений, диагностике «хрупких» тестов или при решении, подходит ли утверждение о времени/числах с плавающей точкой/кэше. НЕ используйте его для синтаксиса API или рефакторинга.
