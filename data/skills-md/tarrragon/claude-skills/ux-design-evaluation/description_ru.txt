Систематическая оценка UX/UI‑дизайна: перенесите тип пробелов «пользователь застревает» из живого тестирования в фазу проектирования. Каждое из шести измерений имеет механически исполняемую таблицу — матрица состояний экрана, откат шлюза, механизм ввода, восстановление после ошибки, навигация, интерактивная обратная связь; пустая ячейка указывает на пробел. Триггерные слова: UX‑дизайн, матрица состояний, путь выхода, тупик, шлюз, IME, сообщение об ошибке, повтор, понижение, глубокая ссылка, поведение назад, индикатор загрузки, SnackBar, выбранное состояние, переполнение. НЕ использовать для контрактов уровня компонентов (используйте component‑contract‑design).
