설정 가이드 / 런북 / 온보딩 / 부트스트랩이 “낯선 사람에 의해 매번 완전히 재현될 수 있는지”를 검증하는 방법: 사전 지식이 없는 콜드리드 에이전트를 파견하고, 그들이 일회용 청정 환경에서 가이드를 따라하도록 하며, 사실 확인을 위해 문서를 캡처하고, 실제 하드웨어 실행만이 하드코딩된 가정, 환경 드리프트 또는 검증자의 버그를 드러내게 한다.  

다섯 단계: 완전성 감사 → 자동 검증 → 콜드리드 에이전트의 실제 실행 → 청정 환경 재검증 → 발견 및 수정.  

트리거 단어: 설정 가이드 검증, 런북 검증, 온보딩 테스트, 부트스트랩 테스트, 골든 패스 / 포장 도로 검증, 매번 재현 가능, 콜드리드 테스트, 콜드리드, 낯선 사람이 따라함, 실제 실행 검증, 설정 가이드 검증, 네이티브(비시뮬레이션), 검증자도 검증되어야 함.  

콜드리드 에이전트가 일회용 청정 환경에서 실행함으로써 따라하기 설정 / 온보딩 / 부트스트랩 가이드가 실제로 신입에게 작동하는지를 검증할 때 트리거한다.
