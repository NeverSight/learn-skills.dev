Methode zur Überprüfung, ob eine Setup‑Anleitung / Runbook / Onboarding / Bootstrap vollständig jedes Mal von einem Fremden reproduzierbar ist: Kaltlese‑Agenten ohne Vorkenntnisse zuweisen, die Anweisungen in einer entbehrlichen sauberen Umgebung zu befolgen, die Dokumentation für die Faktenprüfung festzuhalten und hartkodierte Annahmen / Umgebungsdrift / die eigenen Fehler des Verifizierers aufzudecken, die nur auf echter Hardware auftreten.  

Fünf Stufen: Vollständigkeitsprüfung → automatisierte Verifizierung → Ausführung des Kaltlese‑Agents auf echter Hardware → Nachprüfung in einer sauberen Umgebung → Entdeckung und Behebung.  

Auslöse‑Schlüsselwörter: Setup‑Guide validieren, Runbook‑Verifizierung, Onboarding‑Test, Bootstrap‑Test, Golden‑Path / Paved‑Road‑Verifizierung, jedes Mal reproduzierbar, Kaltlese‑Test, Kaltlese, Fremder folgt den Anweisungen, Verifizierung der Ausführung auf echter Hardware, Validierung der Installationsanleitung, native (nicht‑simulierte), Verifizierer muss ebenfalls getestet werden.  

Auslösen, wenn überprüft wird, ob ein begleiteter Setup‑/‑Onboarding‑/‑Bootstrap‑Leitfaden tatsächlich für einen Neuling funktioniert, indem Kaltlese‑Agenten ihn in entbehrlichen sauberen Umgebungen ausführen.
