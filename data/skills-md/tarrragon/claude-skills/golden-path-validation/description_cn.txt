验证设置指南 / 运行手册 / 入职 / 引导是否能够“每次都被陌生人完整复现”的方法：指派一名没有任何先前知识的冷读代理，让其在一次性干净的环境中执行指南，捕捉文档事实检查，揭露仅硬件层面的假设、环境漂移或仅在真实机器上出现的验证者自身错误。五个阶段：完整性审计 → 自动化验证 → 冷读代理真实机器执行 → 清洁环境重新验证 → 发现并循环。触发词：验证设置指南、运行手册验证、入职测试、引导测试、黄金路径 / 铺设道路验证、每次可复现、冷读测试、冷读、陌生人跟随、真实机器执行验证、设置指南校验、原生非模拟、验证者也必须被验证。触发情境：在验证随行的设置/入职/引导指南实际对新人有效时，通过冷读代理在一次性清洁环境中执行来进行。
