Оркестратор волны планирования версии: разворачивает предложение версии в исполняемые задачи, не пропуская сравнение обучения между ними. Последовательно обрабатывает список предложений и проверку зависимостей, спецификацию, карту домена, договор данных, сравнение обучения, UC, фундаментальную волну (только UI‑версия), тестирование «красный свет», агрегированное создание задач; каждый этап имеет контрольную точку, и PM должен подтвердить перед переходом. Триггерные слова: planning wave, version launch, bootstrap, proposal expansion, ticket creation, foundation wave. Не используйте для определения, к какой версии относится задача (используйте version‑sequencing) или для инвентаризации фундамента по измерениям (используйте foundation‑design).
