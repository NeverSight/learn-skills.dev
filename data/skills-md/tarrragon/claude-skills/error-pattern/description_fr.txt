Outil de gestion de la base de connaissances des modèles d’erreur. À utiliser pour : (1) Interroger les expériences d’erreur existantes et les mesures de protection (requête), (2) Enregistrer les nouveaux modèles d’erreur découverts et les leçons tirées (ajout), (3) Interroger les problèmes historiques avant d’ouvrir un ticket afin d’éviter les récurrences, (4) Gérer systématiquement les expériences d’apprentissage liées aux erreurs. À utiliser lorsque : l’utilisateur mentionne modèle d’erreur, 錯誤模式, 教訓, 經驗記錄, 學習經驗, 防護措施, 錯誤紀錄, ou a besoin d’éviter les problèmes récurrents.
