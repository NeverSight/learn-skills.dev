Herramienta de gestión de la base de conocimientos de patrones de error. Uso para: (1) Consultar experiencias de error existentes y medidas de protección (consulta), (2) Registrar patrones de error recién descubiertos y lecciones aprendidas (añadir), (3) Antes de iniciar un ticket, consultar problemas históricos para evitar su recurrencia, (4) Gestionar sistemáticamente las experiencias de aprendizaje de errores. Usar cuando: el usuario menciona patrón de error, lección, registro de experiencia, experiencia de aprendizaje, medidas de protección, registro de error o necesita evitar problemas recurrentes.
