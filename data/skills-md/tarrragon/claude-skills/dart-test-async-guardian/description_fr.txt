Gardien de la gestion des ressources asynchrones pour les tests Flutter/Dart. Utilisé pour : (1) diagnostiquer les problèmes de blocage des tests, (2) examiner le nettoyage des ressources asynchrones dans le code de test, (3) fournir les meilleures pratiques pour le tearDown, (4) analyser les risques potentiels de fuites de ressources. Scénarios de déclenchement : blocage des tests, rédaction de nouveaux tests, revue de code du code de test, analyse automatique avant l'exécution de flutter test.
