Flutter/Dart-Test-Guardian für asynchrones Ressourcenmanagement. Verwendungszwecke: (1) Diagnose von hängenden Tests, (2) Überprüfung der asynchronen Ressourcenbereinigung im Testcode, (3) Bereitstellung von Best Practices für tearDown, (4) Scannen nach potenziellen Risiken von Ressourcenlecks. Auslöseszenarien: Hängenbleiben von Tests, Schreiben neuer Tests, Code‑Review von Testcode, automatisches Scannen vor dem Ausführen von flutter test.
