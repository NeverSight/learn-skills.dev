Инструмент интеграции выпуска версии. Использовать для: (1) Выпуска новой версии (слияние в main, создание тега, push), (2) Предрелизной проверки состояния (все задачи выполнены? Обновлён ли CHANGELOG?), (3) Обновления документации версии (статус журнала работы, CHANGELOG). Использовать, когда: готовитесь к выпуску версии, запускаете проверку /version‑release для подтверждения предрелизного статуса или подводите итоги после завершения всех задач.
