Outil d'intégration de version de publication. Utilisation : (1) Publier une nouvelle version (fusionner dans la branche principale, taguer, pousser), (2) Vérification de santé avant publication (tous les tickets sont‑ils terminés ? CHANGELOG mis à jour ?), (3) Mettre à jour la documentation de version (statut du journal de travail, CHANGELOG). Quand l’utiliser : lors de la préparation d’une version, en exécutant la vérification /version‑release pour confirmer le statut avant publication, ou à la clôture après que tous les tickets sont terminés.
