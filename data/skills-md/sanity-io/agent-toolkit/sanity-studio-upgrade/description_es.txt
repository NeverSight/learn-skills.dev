Utiliza esta habilidad siempre que alguien quiera actualizar, migrar o modernizar un Sanity Studio a través de una o más versiones mayores a partir de v3, pregunte qué se romperá si actualiza el paquete `sanity`, pregunte por qué su Studio se rompió después de una actualización, o pregunte cuán retrasado está su Studio. Se activa con "upgrade sanity studio", "migrate our studio to v6", "bump sanity", "what breaks if we upgrade", "our studio is on an old version", "sanity upgrade plan", "is our studio out of date", "we are several majors behind". NO se carga para actualizar dependencias que no sean de Sanity, para preguntas del `apiVersion` de Content Lake, para migraciones de contenido o esquemas que cambien documentos, o para crear un nuevo proyecto Sanity.
