Configure documentos singleton en un Sanity Studio usando el registro document.singletons. Úselo cuando un desarrollador quiera un documento con ID fijo (configuración, navegación, pie de página) editado in situ, oculto de la lista de contenido predeterminada, sin opciones de “crear nuevo” o “duplicar”, o al migrar una implementación de singleton creada por el usuario o un plugin singleton de terceros (p. ej., sanity-plugin-singleton-management) a la API de primera clase.
