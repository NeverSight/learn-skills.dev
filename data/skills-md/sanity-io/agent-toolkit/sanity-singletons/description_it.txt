Configura i documenti singleton in un Sanity Studio utilizzando il registro document.singletons. Usalo quando uno sviluppatore desidera un documento a ID fisso (impostazioni, navigazione, footer) modificabile in loco, nascosto dall’elenco di contenuti predefinito, senza le opzioni “crea nuovo” o “duplica” — o quando si migra un’implementazione singleton utente o un plugin singleton di terze parti (ad es. sanity‑plugin‑singleton‑management) verso l’API di prima classe.
