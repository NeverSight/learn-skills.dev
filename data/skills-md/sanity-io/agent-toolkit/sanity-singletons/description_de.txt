Konfigurieren Sie Singleton‑Dokumente in einem Sanity Studio mithilfe des document.singletons‑Registers. Verwenden Sie dies, wenn ein Entwickler ein Dokument mit fester ID (Einstellungen, Navigation, Footer) direkt bearbeiten möchte, das aus der Standard‑Inhaltsliste ausgeblendet ist und keine „Neu erstellen“‑ oder „Duplizieren“‑Optionen bietet – oder wenn Sie eine benutzerdefinierte Singleton‑Implementierung oder ein Drittanbieter‑Singleton‑Plugin (z. B. sanity‑plugin‑singleton‑management) auf die First‑Class‑API migrieren.
