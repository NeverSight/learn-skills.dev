Утвердительные стандарты разработки бэкенда для микросервисов на Node.js + Express + TypeScript. Охватывают слойную архитектуру, паттерн BaseController, внедрение зависимостей, репозитории Prisma, валидацию Zod, unifiedConfig, отслеживание ошибок Sentry, безопасность асинхронного кода и дисциплину тестирования.
