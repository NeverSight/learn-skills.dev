مهارة شاملة لتطوير الواجهة الكاملة لبناء تطبيقات ويب متكاملة باستخدام React و Next.js و Node.js و GraphQL و PostgreSQL. تشمل إعداد هيكلية المشروع، تحليل جودة الشيفرة، أنماط الهندسة المعمارية، وإرشادات كاملة لتقنية المكدس. استخدمها عند بناء مشاريع جديدة، تحليل جودة الشيفرة، تنفيذ أنماط التصميم، أو إعداد تدفقات عمل التطوير.
