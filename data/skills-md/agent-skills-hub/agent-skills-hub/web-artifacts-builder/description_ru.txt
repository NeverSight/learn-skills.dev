Набор инструментов для создания сложных, многокомпонентных HTML‑артефактов claude.ai с использованием современных фронтенд‑технологий (React, Tailwind CSS, shadcn/ui). Применяйте для комплексных артефактов, требующих управления состоянием, роутинга или компонентов shadcn/ui — не для простых однофайловых HTML/JSX артефактов.
