Suite di strumenti per creare artefatti HTML elaborati e multi‑componente per claude.ai, utilizzando le moderne tecnologie web frontend (React, Tailwind CSS, shadcn/ui). Da usare per artefatti complessi che richiedono gestione dello stato, routing o componenti shadcn/ui — non per semplici artefatti HTML/JSX monofile.

Si prega di rispondere sempre nella lingua dell'utente.
