Le système de type avancé de Master TypeScript, y compris les génériques, les types conditionnels, les types mappés, les littéraux de modèle et les types d'utilitaires pour la construction d'applications à sécurité de type. À utiliser lors de la mise en œuvre d'une logique de type complexe, de la création d'utilitaires de type réutilisables ou de la garantie de la sécurité du type au moment de la compilation dans les projets TypeScript.
