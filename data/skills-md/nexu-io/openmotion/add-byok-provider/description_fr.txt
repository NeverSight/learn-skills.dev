Ajouter ou gérer un fournisseur de médias BYOK intégré dans le référentiel OpenMotion, y compris la recherche d'API officielles, les identifiants, la découverte de modèles, les adaptateurs de génération, la configuration de l'éditeur, les références du fournisseur et la vérification. À utiliser pour les demandes des contributeurs visant à intégrer un fournisseur ; la génération de médias ordinaire utilise les consignes de production existantes.
