Crea l'archivio di caricamento per un payload del plugin in questo repository di distribuzione. Da utilizzare quando viene richiesto di creare il pacchetto del plug-in, produrre il file zip di invio, tagliare un artefatto di rilascio del plug-in o preparare il caricamento del portale del plug-in Codex/OpenAI. Riguarda la selezione dell'host, i controlli pre-volo e cosa fare una volta che l'archivio esiste.
