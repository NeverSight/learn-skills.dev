Flujo de contribución de un clic para Open Design (nexu-io/open-design) — incluso para no programadores. Elige una de las cuatro tarjetas (publicar una Skill o un Sistema de Diseño que hayas creado con OD; traducir documentación; corregir un error tipográfico / escribir un blog; reportar un error), el agente valida y abre un PR (o issue) por ti. Palabras clave: contribute to open design, ship my OD skill, ship my OD design system, translate OD docs, report an OD bug, od-contribute.
