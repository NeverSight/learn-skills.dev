Manage a private SSH device inventory, connection metadata, and verified host keys, and securely validate and render SSH, Ansible, DDNS, or hosts output via auto‑config. Whenever a user requests adding, modifying, searching, auditing, decommissioning remote machines, maintaining devices.toml/known_hosts, handling SSH alias/hostname/user/port/ForwardAgent, or generating, comparing, applying fleet configuration, this should be used. By default it is read‑only and does not connect to the remote; inventory, trust, connection, and apply permissions are independent within this skill, and Git topology and delivery are uniformly delegated to git‑workstreams, with the two permission sets not deriving from each other.
