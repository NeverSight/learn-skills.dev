إدارة جرد أجهزة SSH خاصة، وبيانات تعريف الاتصال، ومفاتيح المضيف التي تم التحقق منها، والتحقق الآمن وعرض مخرجات SSH أو Ansible أو DDNS أو المضيفين عبر التكوين التلقائي. كلما طلب مستخدم إضافة أو تعديل أو بحث أو تدقيق أو إلغاء تشغيل آلات بعيدة، أو صيانة devices.toml/known_hosts، أو معالجة alias/hostname/user/port/ForwardAgent في SSH، أو توليد أو مقارنة أو تطبيق تكوين الأسطول، يجب استخدام هذا. بشكل افتراضي هو للقراءة فقط ولا يتصل بالبعيد؛ أذونات الجرد والثقة والاتصال والتطبيق مستقلة داخل هذه المهارة، وتُفوض بنية Git والتسليم بالكامل إلى git‑workstreams، ولا تستمد مجموعتا الأذونات بعضها من الآخر.
