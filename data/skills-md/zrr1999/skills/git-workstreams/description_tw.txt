使用 Git/GitHub 來組織變更工作流程的檢出/工作樹拓撲、其相依分支/PR 堆疊，以及統一的交付邊界：識別標準化的倉庫，預設將常規實作隔離在擁有的工作樹中；明確的 PR 請求也預設允許使用工作樹。之後依照使用者明確指定的端點執行，標準化的倉庫預設為 Draft PR，非標準化的倉庫則僅在本地決定提交、推送與 PR。從 main/master 安全釋出，並追蹤現有的 PR 衝突、CI 以及本地提交/推送。適用於工作樹的建立、遷移、安全清理、「分支已檢出」情況、實作完成後的 Git 交付、切分堆疊/相依 PR、使用 `gh stack` 建立、檢視、同步或合併堆疊，以及處理 PR 合併衝突、檢查失敗、修正至可合併或未提交/未推送的修正。此工具僅管理 Git 拓撲與交付，並不接管領域實作或專案設計；`gh stack` 的確切語法可從本地 `--help` 中查詢。預設的交付不授權隱式切換主工作區分支、Ready、合併、重新目標、釋出或強制推送。
