إرفاق أدوات المتصفح الوكيل (playwright‑cli، chrome‑devtools‑mcp) بمتصفح Helium قيد التشغيل باستخدام ملف تعريف المستخدم الحقيقي. استخدم ذلك عند العمل مع متصفح Helium، وعندما ينبغي لـ playwright‑cli أو chrome‑devtools‑mcp التحكم في متصفح مفتوح بالفعل بدلاً من تشغيل نسخة جديدة، وعند فشل الإرفاق عبر CDP/remote‑debugging مع Helium، أو عندما تُعيد نقاط النهاية HTTP ‎/json على منفذ تصحيح Chromium رسالة 404. يغطي خادم التصحيح عبر WebSocket فقط، واكتشاف DevToolsActivePort، ومسارات ملفات التعريف وفقًا لكل نظام تشغيل.
