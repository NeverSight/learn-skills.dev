Allega gli strumenti agente del browser (playwright-cli, chrome‑devtools‑mcp) a un browser Helium in esecuzione con il profilo reale dell’utente. Usalo quando lavori con il browser Helium, quando playwright‑cli o chrome‑devtools‑mcp devono controllare un browser già aperto invece di avviare una nuova istanza, quando il collegamento CDP/remote‑debugging fallisce con Helium, o quando gli endpoint HTTP /json restituiscono 404 su una porta di debug di Chromium. Copre il server di debug solo WebSocket, la scoperta di DevToolsActivePort e i percorsi del profilo per piattaforma.
