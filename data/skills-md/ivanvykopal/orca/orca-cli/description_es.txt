Operar los worktrees gestionados por Orca, los contextos de carpetas, terminales, repos, automatizaciones, artefactos, intercambio de habilidades, comentarios de worktree y el navegador integrado de Orca a través del CLI `orca`. Usar cuando el usuario dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Prefiérelo sobre git worktree sin gestión, PTYs ad hoc o Uso de Computadora cuando el estado de Orca está involucrado. Utiliza Uso de Computadora solo cuando una ventana visible requiere control GUI que el CLI, el sistema de archivos o la API no pueden realizar.
