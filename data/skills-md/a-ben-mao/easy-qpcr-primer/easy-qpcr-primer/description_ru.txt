Простой конвейер разработки и проверки qPCR‑праймеров для Claude Code. Поиск в PrimerBank + проверка NCBI BLAST + поиск по реальной литературе (Google Scholar через Chrome MCP или WebSearch). Поддерживает поиск праймеров для множества генов и видов. Используйте, когда пользователь запрашивает: разработку праймеров, qPCR‑праймеры, поиск в PrimerBank, проверку BLAST, проверку специфичности праймеров, поиск литературы по праймерам. Срабатывает по запросам: 引物设计, qPCR引物, 引物搜索, 引物验证, PrimerBank, BLAST验证, 多基因引物, 引物特异性验证, 文献检索引物.
