Évaluez n'importe quel site web comme le ferait un jury Awwwards, uniquement à partir des preuves. Capturez des captures d'écran de chaque type de page sur ordinateur de bureau, sur un téléphone limité en bande passante et avec motion réduite, mesurez le LCP, le CLS, les FPS, axe, le focus clavier et le retour au survol, auditez le SEO et les métadonnées, puis un critique frais qui ne voit jamais le code note le Design, la Convivialité, la Créativité, le Contenu et les six domaines développeur, avec une liste de correctifs classés. Utilisez-le lorsque quelqu'un demande de revoir, critiquer, évaluer, noter ou railler un site web, un portfolio ou une landing page, se demande si un site est suffisamment bon pour les Awwwards ou le Site du Jour, ou souhaite une QA design d'une URL en ligne ou d'une version locale. Ce n'est pas pour construire ou redessiner un site ; utilisez /awwwards pour cela.

Veuillez toujours répondre dans la langue de l'utilisateur.
