Spieltheorie für Geschäftsstrategie, Verhandlung, Preisgestaltung, Mittelbeschaffung, Partnerschaften und Wettbewerbsentscheidungen. Konstruiert das Modell Phase für Phase durch Dialog: Spieler, Anreize, Strategieraum, Gleichgewicht, Empfehlung, Anpassung. Auslöser: Spieltheorie, was ist ihr Anreiz, wie werden sie reagieren, Modell dieser Situation, strategischer Schachzug, /Spieltheoretiker.
