Théorie des jeux pour la stratégie commerciale, la négociation, la tarification, la collecte de fonds, les partenariats et les décisions concurrentielles. Construit le modèle étape par étape par le dialogue : acteurs, incitations, espace stratégique, équilibre, recommandation, adaptation. Déclencheurs : théorie des jeux, quelle est leur incitation, comment vont-ils réagir, modéliser cette situation, mouvement stratégique, /théoricien du jeu.
