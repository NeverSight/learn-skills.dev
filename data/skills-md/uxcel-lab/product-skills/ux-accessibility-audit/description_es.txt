Realice una auditoría estructurada de accesibilidad WCAG 2.1 AA en un diseño, una pantalla, un componente o una página. Genera una lista de problemas priorizados: cada hallazgo cita el criterio de las WCAG infringido, una calificación de gravedad (crítica/mayor/menor) y una solución concreta. Úselo cuando realice una auditoría para comprobar el cumplimiento de las pautas de accesibilidad o como paso de validación después de generar la interfaz de usuario.
