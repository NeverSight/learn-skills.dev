Mejores prácticas para crear prompts para cualquier modelo de texto a imagen (p. ej. Imagen, Gemini Image, GPT Image, DALL·E, Stable Diffusion, Flux, Ideogram, Leonardo, Midjourney) que produzcan imágenes predecibles y de calidad profesional. Usa esta habilidad siempre que la tarea implique llamar a una API de generación de imágenes, generar imágenes programáticamente, escribir o revisar prompts para modelos de imagen, producir ilustraciones/fotos/logotipos/carteles/maquetas/infografías/capturas de UI con IA, o depurar resultados de imagen deficientes. Aplícalo incluso cuando el usuario solo diga "generar una imagen de X": los prompts bien estructurados superan dramáticamente a los breves en todos los modelos actuales, y el coste de un mal prompt casi siempre se paga en reintentos.

Por favor, responde siempre en el idioma del usuario.
