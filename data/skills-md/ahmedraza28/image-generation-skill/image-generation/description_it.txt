Migliori pratiche per formulare prompt per qualsiasi modello di testo‑a‑immagine (ad es. Imagen, Gemini Image, GPT Image, DALL·E, Stable Diffusion, Flux, Ideogram, Leonardo, Midjourney) al fine di produrre immagini prevedibili e di qualità professionale. Utilizza questa competenza ogni volta che il compito prevede la chiamata a un'API di generazione di immagini, la creazione di immagini in modo programmatico, la scrittura o la revisione di prompt per i modelli di immagine, la produzione di illustrazioni / foto / loghi / poster / mockup / infografiche / schermate UI con l'IA, o il debug di uscite di immagine scadenti. Applica questa regola anche quando l'utente dice semplicemente “genera un'immagine di X” — i prompt ben strutturati superano di gran lunga quelli concisi su tutti i modelli attuali, e il costo di un prompt errato è quasi sempre pagato in ritentativi.
