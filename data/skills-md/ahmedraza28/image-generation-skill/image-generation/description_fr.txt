Bonnes pratiques pour formuler des invites pour tout modèle texte‑à‑image (par ex. Imagen, Gemini Image, GPT Image, DALL·E, Stable Diffusion, Flux, Ideogram, Leonardo, Midjourney) afin de produire des images prévisibles et de qualité production. Utilisez cette compétence chaque fois que la tâche implique d’appeler une API de génération d’images, de générer des images de façon programmée, d’écrire ou de réviser des prompts pour les modèles d’image, de créer des illustrations / photos / logos / affiches / maquettes / infographies / captures d’interface UI avec l’IA, ou de déboguer des sorties d’image médiocres. Appliquez‑la même lorsque l’utilisateur se contente de dire « génère une image de X » — des invites bien structurées surpassent largement les invites concises sur tous les modèles actuels, et le coût d’un mauvais prompt se traduit presque toujours en nouvelles tentatives.

Veuillez toujours répondre dans la langue de l'utilisateur.
