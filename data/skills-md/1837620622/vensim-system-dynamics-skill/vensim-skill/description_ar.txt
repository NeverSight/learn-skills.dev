بناء، ترتيب، فحص ومحاكاة نماذج ديناميات الأنظمة في Vensim (.mdl). يُستخدم عندما يرغب المستخدم في مخطط مخزون وتدفق أو مخطط حلقة سببية في Vensim، أو يحتاج إلى تعديل نموذج MDL موجود (تداخل التسميات، أسهم متقاطع، عروض فوضوية)، أو يريد فحوصات القطبية وحلقات R/B، أو يحتاج إلى محاكاة قابلة لإعادة الإنتاج، سيناريو، حساسية، معايرة أو تشغيل سياسات مع رسومات Python ذات جودة للنشر. أسماء المتغيرات بالصينية بشكل افتراضي؛ ويندوز، macOS ولينكس.
