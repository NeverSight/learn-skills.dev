Wählen Sie ein kleines, renommiertes Set von Agentenfähigkeiten für ein Repository aus und installieren Sie es. Verwenden Sie es beim Einrichten von Repository‑Fähigkeiten oder bei der Überprüfung von Passung, Duplikaten und Konflikten. Prüfen Sie den tatsächlichen Stack und bestehende Installationen, empfehlen Sie ponytail und git‑commit als Basis und fügen Sie Spezialisten nur bei nachgewiesenem Bedarf hinzu. Installieren Sie nur innerhalb eines ausdrücklich genehmigten Umfangs.
