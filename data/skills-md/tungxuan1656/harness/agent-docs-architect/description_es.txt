Diseña o audita el sistema de conocimiento del repositorio orientado a agentes para un proyecto de software. Utilízalo cuando un usuario necesite decidir qué documentos de producto, dominio, arquitectura, integración, datos, seguridad, fiabilidad, ejecución, referencia generada o navegación requiere un repositorio; sus rutas, nombres, titularidad, rutas de lectura y contratos de mantenimiento; o cómo debe cambiar ese sistema según la etapa del proyecto, la topología, la pila tecnológica, las integraciones, el riesgo y la coordinación. Úsalo antes de redactar un conjunto de documentación de varios documentos. Combínalo con agent‑docs‑writer para crear documentos aprobados. No lo uses para redactar un documento ya seleccionado ni para tomar decisiones de producto o arquitectura no aprobadas.
