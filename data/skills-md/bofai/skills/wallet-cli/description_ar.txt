تشغيل سطر أوامر محفظة TRON المكتوبة بـ TypeScript لإدارة الحسابات، التحويلات، الستاكينغ، الحوكمة، العقود، التوقيع، استعلامات السلسلة، وإدخال كلمة المرور باستخدام wallet-cli الإصدار 4.13.0. رفض كلمات مرور المحفظة في argv وإلزام استخدام قناة stdin المدعومة. بالنسبة لطلبات Java REPL، رفض هذا الإدخال وتقديم سطر أوامر TypeScript الواحد؛ توجيه سلاسل أخرى وسير عمل SunSwap/DEX إلى مكان آخر.
