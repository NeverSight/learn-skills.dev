Utilizza la CLI del wallet TypeScript TRON per conti, trasferimenti, staking, governance, contratti, firme, query della catena e inserimento della password con wallet-cli 4.13.0. Rifiuta le password del wallet passate tramite argv e richiedi il canale stdin supportato. Per le richieste Java REPL, rifiuta quell'ingresso e offri la CLI TypeScript one‑shot; indirizza altre catene e i flussi di lavoro SunSwap/DEX altrove.

Rispondi sempre nella lingua dell'utente.
