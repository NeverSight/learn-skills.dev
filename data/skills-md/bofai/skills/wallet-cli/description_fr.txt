Utilisez le CLI du portefeuille TRON en TypeScript pour les comptes, les transferts, le staking, la gouvernance, les contrats, la signature, les requêtes de chaîne et la saisie du mot de passe avec wallet‑cli 4.13.0. Refusez les mots de passe du portefeuille dans argv et exigez le canal stdin pris en charge. Pour les requêtes REPL Java, refusez cette entrée et proposez le CLI TypeScript à usage unique ; orientez les autres chaînes et les flux de travail SunSwap/DEX ailleurs.
