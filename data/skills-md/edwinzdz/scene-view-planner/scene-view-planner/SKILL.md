# 场景视角规划器（Scene View Planner）

把"一张场景图"变成"可指方向的俯视平面图"，再按用户指定方向产出**同一空间**的新视角图。
全程闭环，几何关系必须可追溯，禁止凭空想象空间布局。

## 闭环总览

0. **阶段 A0（冷启动反推与确认，信息不足时必做）**：用户只给一张图、没说是什么场景/画面外布局时，
   先反推"这是什么场所的哪个功能分区、其余方向应该是什么区"，向用户陈述推断并**取得确认后**再画平面图。
1. **阶段 A（成图）**：场景图 → 视觉分析 → 结构化平面 JSON → `scripts/floorplan.py` 渲染黑白俯视 CAD 平面图 → 交付用户。
2. **阶段 B（出视角）**：用户在平面图上画箭头 / 说方向 → 解析新机位 → 几何推演可见内容 → 以原图为参考图生成新视角静态图 → 对照平面图回查。用户可就同一张平面图反复指定方向，重复阶段 B。
3. **阶段 C（四宫格总检）**：所需视角（反打/左/右等）都出齐后，用 `scripts/make_grid.py` 拼一张
   2×2 四宫格总览，统一检索四个视角的位置关系是否错乱、风格色调是否一致，发现问题回到阶段 B 修正后重拼。

---

## 阶段 A0：冷启动——先反推场景，请用户确认（信息不足时必做）

### A0-1. 判断是否需要
- 用户只发图、未说明场所类型 / 当前分区 / 画面外布局，或只拍到某个局部功能区、你对场所判断没把握时，
  **先走 A0，不得直接画 CAD**。
- 用户已说清空间类型与画面外布局时可跳过，但交付平面图时仍要复述理解。

### A0-2. 三步反推（方法与先验库见 `references/scene_inference.md`）
1. **识别场所与当前分区**：从设备家具、标识文字、材质装修、采光开口取证，结论要具体到
   "什么场所的哪个功能分区"（如"咖啡店的吧台制作区"，而不是"一个房间"）。
2. **以原机位为中心推断四方向**：正前方延伸到哪、反打（身后）通常是什么分区、左右各连接什么、
   画面外可能还有什么区。
3. **区分事实与推断**：画面里看到的是事实；画面外一律用"预计/通常/可能"，低置信方向单独点名。

### A0-3. 陈述并等待确认（门控）
- 用 `references/scene_inference.md` 第 4 节的模板，一次性给出"场所+四方向推断+待确认问题"，
- **未拿到用户"确认/可以"或针对性纠正前，不进入阶段 A、不渲染平面图。**
- 用户说"你看着办"视为授权按推断走，但要在平面图上把所有推断项标注清楚。
- 确认后的分区结论要落进阶段 A 的 plan JSON，作为后续反打/侧视的依据。

---

## 阶段 A：场景图 → 俯视 CAD 平面图

### A1. 读图与补信息
- 完整查看用户场景图，确定：原机位位置与视线方向、房间轮廓与长宽比、各面墙上的门/窗/固定物、
  主要家具及其沿墙位置。
- **画面外信息必须补齐**：原图拍不到机位背后与侧后方，而反打/侧视恰恰要看到这些。
  用户若已用文字补充（如"对面是墙还有一道门"）务必纳入；没有说明又影响目标视角时，先向用户问清，
  不要编造背后布局。

### A2. 抽象为平面 JSON
- 严格按 `references/cad_symbols.md` 的坐标约定（北朝上、x 东 y 北、相对比例即可）与图块清单，
  把空间写成 plan JSON。拿不准的尺寸用相对比例估计并在回复中标注"推断"。
- 矩形房间用 `room.bounds`，门/窗放 `openings`（脚本自动在墙线开洞），家具与隔断放 `elements`。
- 未内置的家具用 `rect/circle/wall` 组合成俯视外轮廓近似，保持统一黑白线稿。

### A3. 渲染并回读
- 运行（依赖 matplotlib，缺失则 `python -m pip install matplotlib`）：

```bash
python scripts/floorplan.py plan.json -o floorplan.png --svg floorplan.svg
```

- **必须回读输出的 PNG**，对照原图核对：原机位朝向、门所在墙与开合、左右排布是否一致，
  有无图块出界/重叠/中文方块；不对就改 JSON 重渲染。
- 风格硬性要求：白底、近黑等粗线稿、无填充无阴影无写实纹理、正俯视、北朝上；默认画面干净。
  是否叠加原机位三角/指北针视需要而定（顶层 `camera`、`style.compass` 控制）。

### A4. 交付并引导指定方向
- 交付平面图，并用极简文字说明：原机位在哪、各符号对应什么、哪些来自用户补充/推断。
- 明确告诉用户两种指定方向的方式：① 在这张图上画箭头（**箭头尖指向=想看到的那面**）后发回；
  ② 直接说"反打 / 左侧 / 右侧 / 左转 X 度 / 朝某方向"。

---

## 阶段 B：指定方向 → 新视角图

### B1. 解析方向
- **方向语义铁律：箭头尖指向或用户所报方向 = 相机新朝向 = 最终画面正前方看到的那面；
  相机站在目标墙的对侧、朝目标看。**
- 口头方向按 `references/camera_geometry.md` 的对照表换算（反打=180°；左=原朝向顺时针 90°、
  右=逆时针 90°，左右以原拍摄者为准，并用"你原图的左手边/右手边"复述确认）。
- 箭头图：读出箭头尖方位向量，归到八方位，新机位 = 场景中心沿箭头反方向退到墙边。
  可用 `floorplan.py --arrow x,y,DIR` 重绘带红箭头的标注图自检；方向含糊先确认，不硬猜。

### B2. 几何推演新画面
按 `references/camera_geometry.md` 第 4 节，站到新机位列清：正中尽头是什么、新左右各是什么、
哪些物体进/出画面、纵深与遮挡顺序。**反打必须套用左右互换（点绕中心 180°：(x,y)→(2Cx−x,2Cy−y)），
原左变新右、原右变新左；侧视注意沿墙物体从"纵深排列"变"正面展开"。**

### B3. 生成新视角静态图
- 使用图像编辑/图生图能力，**以原始场景图为首要参考图**；可把平面图/箭头标注图作为**布局参考**，
  但只借几何、绝不把黑白线稿风格带进成图。
- 按 `references/camera_geometry.md` 第 6 节的五段模板组织提示词：空间与风格锚点 → 新机位 →
  画面布局 → 反打/侧视几何关系 → 一致性约束。
- 一致性硬约束：同一户型/门窗/固定物数量样式、同一墙地砖与材质、同一色温光照与画风、
  相近视高与焦段；**只换机位朝向，不重新装修、不新增风格不符物体**。
- 默认产出**静态场景图**。用户明确要镜头运动视频时，再转交视频生成能力，机位几何推演不变。

### B4. 回查与迭代
- 把成图与新机位平面图对照：正中是否为该看到的墙、左右是否符合几何、数量/开合/材质色调是否一致。
- 不符就改"几何/布局描述"重生成（左右错→补 180° 互换；看到原尽头→站位没转过去；风格漂移→强化锚点并确保原图为首要参考）。
- 交付后提示可继续在同一平面图指定下一方向。

---

## 阶段 C：四宫格总览与一致性自检（视角出齐后必做）

### C1. 拼四宫格
- 当反打 / 左侧 / 右侧等用户要的视角都生成完，运行（纯 Pillow）：

```bash
python scripts/make_grid.py --front 原图.png --reverse 反打.png --left 左.png --right 右.png -o grid.png
# 某视角未生成可省略该参数，对应格留"未生成"占位
```

- **固定排布**（与机位方位一致，勿改顺序）：左上=原视角、右上=反打、左下=左侧、右下=右侧。

### C2. 对着四宫格做三项检索（细则见 `references/camera_geometry.md` 第 8 节）
1. **位置关系**：相邻格相差 90°，共用墙/物体应在相邻边缘衔接；对角的原视角与反打应左右互换、
   不应看到同一尽头；沿长轴的左右两格应互为反向纵深。
2. **风格统一**：色温色调、材质、光照方向与强度、视高焦段、画风四格一致，没有哪一格"像另一个空间"。
3. **数量一致**：门窗、固定物、灯具等跨视角数量与样式对得上。
- 发现错乱先定位是哪个机位、回平面图重推几何，**改该视角后重新拼图复检**，直到四格自洽再整体交付。

## 关键规则（不可违反）

1. 信息不足（只给图、没说场所与画面外布局）时先走阶段 A0 反推并取得用户确认，**未确认不画平面图**。
2. 平面图必须是脚本渲染的**标准黑白正俯视线稿**，不要用绘画模型生成示意俯视图（方位与标注不可靠）。
3. 画面外（机位背后/侧后）布局只能来自用户确认/补充或原图可合理延伸，缺失先问、不得编造。
4. 方向一律按"箭头尖=相机朝向=画面正前方"解释；口头左右以原拍摄者为准并复述确认。
5. 反打必做左右互换，侧视重做可见性与纵深；几何关系先在平面图上推清再生成。
6. 新视角与原图必须是同一空间：材质、光照、色调、视高、焦段一致，仅机位改变。
7. 每次渲染/生成后都要实际回读结果再交付，不允许只看命令成功就交付。
8. 全部视角出齐后必须拼四宫格做位置/风格/数量总检，发现错乱修正并重拼后再整体交付。

## 资源

- `scripts/floorplan.py`：plan JSON → 黑白俯视 CAD 图（PNG，可选 SVG、可选叠加红箭头）。图块参数与完整示例见该脚本头部文档字符串。
- `scripts/make_grid.py`：多视角 → 固定排布的 2×2 四宫格总览（阶段 C 自检，纯 Pillow）。
- `references/scene_inference.md`：阶段 A0 冷启动——场所/分区反推三步法、常见空间先验库、确认陈述模板与门控、咖啡店实例。
- `references/cad_symbols.md`：透视图反推平面的方法、plan JSON 字段、全部图块参数、常见家具映射、示例与自检。
- `references/camera_geometry.md`：方向换算表、箭头解析、反打/侧视可见性推演、一致性约束、图生图提示词模板与实例、第 8 节四宫格总检清单、回查清单。
