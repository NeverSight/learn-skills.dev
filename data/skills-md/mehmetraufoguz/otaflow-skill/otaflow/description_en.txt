Publish, promote, roll back and pause over-the-air (OTA) updates for an Expo app with Otaflow and its `otaflow` command line. Use when the user wants to ship a JavaScript update to installed Expo apps without a store release, set up Otaflow for a project (login, link an app, create the code-signing key, configure expo-updates, channels and runtime versions), publish to preview or production, approve or request a promotion, undo a bad update, pause a channel, create CI keys, or debug an Otaflow error or an update that does not reach devices.
