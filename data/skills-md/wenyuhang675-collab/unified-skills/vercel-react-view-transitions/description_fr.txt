Guide pour implémenter des animations fluides et natives à l'aide de l'API View Transition de React (composant `<ViewTransition>`, `addTransitionType` et pseudo-éléments de transition de vue CSS). Utilisez cette compétence chaque fois que l'utilisateur souhaite ajouter des transitions de page, animer des changements d'itinéraire, créer des animations d'éléments partagés, animer l'entrée/sortie de composants, animer la réorganisation de la liste, implémenter des animations de navigation directionnelles (avant/arrière) ou intégrer des transitions de vue dans Next.js. À utiliser également lorsque l'utilisateur mentionne les transitions de vue, « startViewTransition », « ViewTransition », les types de transition ou pose des questions sur l'animation entre les états de l'interface utilisateur dans React sans bibliothèques d'animation tierces.
