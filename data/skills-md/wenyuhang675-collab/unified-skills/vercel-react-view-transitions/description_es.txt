Guía para implementar animaciones fluidas y con sensación nativa utilizando la API View Transition de React (componente `<ViewTransition>`, `addTransitionType` y pseudoelementos de transición de vista CSS). Utilice esta habilidad siempre que el usuario desee agregar transiciones de página, animar cambios de ruta, crear animaciones de elementos compartidos, animar la entrada/salida de componentes, animar el reordenamiento de listas, implementar animaciones de navegación direccionales (adelante/atrás) o integrar transiciones de vista en Next.js. Úselo también cuando el usuario mencione transiciones de vista, `startViewTransition`, `ViewTransition`, tipos de transición o pregunte sobre la animación entre estados de la interfaz de usuario en React sin bibliotecas de animación de terceros.
