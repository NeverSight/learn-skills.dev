React의 View Transition API(`<ViewTransition>` 컴포넌트, `addTransitionType` 및 CSS 뷰 전환 의사 요소)를 사용하여 부드럽고 네이티브 느낌의 애니메이션을 구현하기 위한 가이드입니다. 사용자가 페이지 전환 추가, 경로 변경 애니메이션, 공유 요소 애니메이션 생성, 구성 요소의 시작/종료 애니메이션, 목록 재정렬 애니메이션, 방향(앞/뒤) 탐색 애니메이션 구현 또는 Next.js의 보기 전환 통합을 원할 때마다 이 기술을 사용하세요. 또한 사용자가 뷰 전환, `startViewTransition`, `ViewTransition`, 전환 유형을 언급하거나 타사 애니메이션 라이브러리 없이 React에서 UI 상태 간 애니메이션에 대해 묻는 경우에도 사용합니다.
