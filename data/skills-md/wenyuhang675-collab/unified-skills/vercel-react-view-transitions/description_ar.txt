دليل لتنفيذ رسوم متحركة سلسة وذات طابع أصلي باستخدام React's View Transition API (مكون `<ViewTransition>` و`addTransitionType` وعناصر انتقال عرض CSS الزائفة). استخدم هذه المهارة عندما يريد المستخدم إضافة انتقالات للصفحة، أو تحريك تغييرات المسار، أو إنشاء رسوم متحركة للعناصر المشتركة، أو تحريك الإدخال/الخروج للمكونات، أو تحريك إعادة ترتيب القائمة، أو تنفيذ رسوم التنقل الاتجاهية (للأمام/الخلف)، أو دمج انتقالات العرض في Next.js. يُستخدم أيضًا عندما يذكر المستخدم انتقالات العرض، أو `startViewTransition`، أو `ViewTransition`، أو أنواع الانتقال، أو يسأل عن الرسوم المتحركة بين حالات واجهة المستخدم في React بدون مكتبات الرسوم المتحركة التابعة لجهات خارجية.
