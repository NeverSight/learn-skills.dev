Leitfaden zum Implementieren flüssiger, nativer Animationen mit der View Transition API von React (Komponente „<ViewTransition>“, „addTransitionType“ und CSS-Pseudoelemente für den Ansichtsübergang). Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Seitenübergänge hinzufügen, Routenänderungen animieren, gemeinsame Elementanimationen erstellen, das Ein-/Aussteigen von Komponenten animieren, die Neuordnung von Listen animieren, Richtungsnavigationsanimationen (vorwärts/zurück) implementieren oder Ansichtsübergänge in Next.js integrieren möchte. Verwenden Sie es auch, wenn der Benutzer Ansichtsübergänge, „startViewTransition“, „ViewTransition“ oder Übergangstypen erwähnt oder nach der Animation zwischen UI-Zuständen in React ohne Animationsbibliotheken von Drittanbietern fragt.
