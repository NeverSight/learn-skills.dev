React の View Transition API (`<ViewTransition>` コンポーネント、`addTransitionType`、および CSS ビュー遷移擬似要素) を使用して、スムーズでネイティブな感覚のアニメーションを実装するためのガイド。ユーザーがページ遷移の追加、ルート変更のアニメーション化、共有要素アニメーションの作成、コンポーネントの出入りのアニメーション化、リストの並べ替えのアニメーション化、方向 (進む/戻る) ナビゲーション アニメーションの実装、または Next.js でのビュー遷移の統合を行う場合は、このスキルを使用します。ユーザーがビュー遷移、`startViewTransition`、`ViewTransition`、遷移タイプについて言及したり、サードパーティのアニメーション ライブラリを使用しない React での UI 状態間のアニメーションについて質問したりする場合にも使用します。
