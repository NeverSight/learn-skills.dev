Локальный регрессионный/бенчмарк‑скилл для сопровождающих ui-clone-skills.  
Запускает стандартный pipeline обратного инженеринга UI против канонического справочного сайта (https://realfood.gov) и записывает AE/SSIM, количество итераций, количество провалов шлюзов и результат в benchmark/history.csv, чтобы дрейф подсказок / поддокументов / версии модели проявлялся как тенденция.  
Триггерные фразы: «run benchmark», «regression benchmark», «benchmark clone». В Makefile больше нет цели `benchmark` — настройка выполняется встроенным bash‑скриптом в этом скилле (см. Шаг 1 ниже).  
Внутренний: НЕ зарегистрирован в `.claude-plugin/plugin.json` → `skills`. Не является частью публичного рыночного слоя 3‑скиллов. Только инструменты для сопровождающих.
