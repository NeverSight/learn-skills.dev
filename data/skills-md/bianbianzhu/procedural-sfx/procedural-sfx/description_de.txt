Synthesisiere Soundeffekte aus Code (numpy/scipy, keine Sample‑Bibliotheken), prüfe sie numerisch und mische sie frame‑genau unter ein Video oder eine Animation mit Voice‑Ducking‑ und Maskierungs‑Checks, dann mastere sie mit einem einzigen linearen Gain auf ein Lautstärke‑Ziel für reine Audio‑ oder Videoausgabe. Nutze es immer dann, wenn jemand Soundeffekte oder Foley für ein mit Code gerendertes Video, eine Animation, ein Erklärvideo, ein Motion‑Graphic oder einen Spiel‑Prototyp benötigt; wenn er einen spezifischen Klang aus Code erzeugen will (枪声, 爆炸, 脚步, 音效, 拟音, ein Laser, ein Türknallen); wenn SFX ohne Drittanbieter‑Sample‑Lizenzen gebraucht werden; oder wenn Audio synchron zu Animationsereignissen sein muss, selbst wenn nie das Wort „prozedural“ verwendet wird. Nicht zum Komponieren von Musik oder zum Finden von aufgenommenen Samples.
