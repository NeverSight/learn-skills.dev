Выпустите НОВУЮ возможность для vigiles, чтобы она действительно дошла до пользователя — новый экспорт, публичную функцию, подпуть, флаг CLI или слово‑словарь хука. Используйте, когда собираетесь добавить или только что добавили функцию/экспорт/публичный API в этот репозиторий. Выполняет проверку исполняемого файла, которую не делает зелёный `npm run check` — доступно из публичного входа, чтение diff публичного API‑поверхности, публичный домашний документ, экспериментальное решение, шлюз на замороженном дереве. НЕ предназначено для исправления багов, рефакторинга, правок только в документации или только в тестах.
