Envía una NUEVA capacidad a vigiles para que realmente llegue a un usuario — una nueva exportación, función pública, subruta, bandera CLI o palabra del vocabulario de hooks. Úsalo cuando estés a punto de añadir, o acabes de añadir, una característica / exportación / API pública a este repositorio. Ejecuta las comprobaciones ejecutables que un `npm run check` verde NO hace — accesible desde una puerta pública, diff de superficie de API, lectura, un hogar de documentación público, la decisión experimental, una puerta en un árbol congelado. NO es para correcciones de errores, refactorizaciones, ediciones solo de documentación o solo de pruebas.
