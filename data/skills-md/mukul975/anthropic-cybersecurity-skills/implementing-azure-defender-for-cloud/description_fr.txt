Activez Microsoft Defender pour Cloud (CSPM + CWPP) sur les machines virtuelles, les conteneurs, SQL, le stockage et Key Vault, en utilisant Azure Policy pour l'évaluation, Log Analytics pour la télémétrie, Azure Arc pour la couverture hybride et Logic Apps pour la réponse automatisée. À utiliser pour la surveillance de la sécurité Azure, la correction adaptative ou l'évaluation de la conformité réglementaire ; pas pour une protection ou une défense d’identité non uniquement Azure (Defender for Identity).
