Habilite Microsoft Defender para la nube (CSPM + CWPP) en máquinas virtuales, contenedores, SQL, almacenamiento y Key Vault, utilizando Azure Policy para evaluación, Log Analytics para telemetría, Azure Arc para cobertura híbrida y Logic Apps para respuesta automatizada. Úselo para la supervisión de la seguridad de Azure, la corrección adaptativa o la evaluación del cumplimiento normativo; no para protección o defensa de identidad que no sea exclusiva de Azure (Defender for Identity).
