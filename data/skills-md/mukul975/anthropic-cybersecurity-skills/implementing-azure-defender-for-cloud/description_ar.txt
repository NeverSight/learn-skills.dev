قم بتمكين Microsoft Defender for Cloud (CSPM + CWPP) عبر الأجهزة الافتراضية والحاويات وSQL والتخزين وKey Vault، باستخدام Azure Policy للتقييم، وLog Analytics للقياس عن بعد، وAzure Arc للتغطية المختلطة، وLogic Apps للاستجابة التلقائية. الاستخدام لمراقبة أمان Azure أو المعالجة التكيفية أو تقييم الامتثال التنظيمي؛ ليس للحماية غير المتعلقة بـ Azure فقط أو الدفاع عن الهوية (Defender for Identity).
