Abilita Microsoft Defender for Cloud (CSPM + CWPP) su VM, contenitori, SQL, archiviazione e Key Vault, usando criteri di Azure per la valutazione, Log Analytics per la telemetria, Azure Arc per la copertura ibrida e app per la logica per la risposta automatizzata. Utilizzare per il monitoraggio della sicurezza di Azure, la correzione adattiva o la valutazione della conformità normativa; non per la protezione o la difesa dell'identità non solo di Azure (Defender for Identity).
