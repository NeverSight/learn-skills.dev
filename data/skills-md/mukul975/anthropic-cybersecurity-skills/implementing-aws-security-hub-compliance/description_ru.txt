Разверните AWS Security Hub на базе AWS Config, чтобы агрегировать данные GuardDuty, Inspector, Macie, Firewall Manager и Prowler в организациях AWS с несколькими аккаунтами, активировать такие стандарты, как CIS AWS Foundations и PCI DSS, а также автоматизировать исправления с помощью EventBridge и Lambda. Используйте для централизации мониторинга соответствия AWS или информационных панелей соответствия требованиям руководителей; не для обнаружения угроз (GuardDuty) или классификации данных (Macie).
