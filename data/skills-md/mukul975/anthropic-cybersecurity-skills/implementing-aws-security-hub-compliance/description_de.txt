Stellen Sie AWS Security Hub mit Unterstützung von AWS Config bereit, um Ergebnisse von GuardDuty, Inspector, Macie, Firewall Manager und Prowler in AWS-Organisationen mit mehreren Konten zu aggregieren, Standards wie CIS AWS Foundations und PCI DSS zu aktivieren und die Behebung über EventBridge und Lambda zu automatisieren. Verwendung zur Zentralisierung der AWS-Compliance-Überwachung oder von Compliance-Dashboards für Führungskräfte; nicht zur Bedrohungserkennung (GuardDuty) oder Datenklassifizierung (Macie).
