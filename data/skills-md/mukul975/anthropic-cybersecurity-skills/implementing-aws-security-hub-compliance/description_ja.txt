AWS Config に支えられた AWS Security Hub をデプロイして、GuardDuty、Inspector、Macie、Firewall Manager、Prowler からの調査結果をマルチアカウント AWS Organizations 全体で集約し、CIS AWS Foundations や PCI DSS などの標準を有効にし、EventBridge と Lambda による修復を自動化します。 AWS コンプライアンス監視またはエグゼクティブコンプライアンスダッシュボードを一元化するために使用します。脅威検出 (GuardDuty) やデータ分類 (Macie) 用ではありません。
