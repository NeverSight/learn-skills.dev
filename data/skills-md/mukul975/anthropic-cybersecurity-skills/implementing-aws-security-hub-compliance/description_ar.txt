انشر AWS Security Hub، المدعوم بـ AWS Config، لتجميع النتائج من GuardDuty وInspector وMacie وFirewall Manager وProwler عبر مؤسسات AWS متعددة الحسابات، وتمكين معايير مثل CIS AWS Foundations وPCI DSS، وأتمتة المعالجة عبر EventBridge وLambda. يُستخدم لمراقبة امتثال AWS مركزيًا أو لوحات معلومات الامتثال التنفيذي؛ ليس لاكتشاف التهديدات (GuardDuty) أو تصنيف البيانات (Macie).
