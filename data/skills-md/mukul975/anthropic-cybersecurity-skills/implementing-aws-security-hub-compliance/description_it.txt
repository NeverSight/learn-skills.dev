Distribuisci AWS Security Hub, supportato da AWS Config, per aggregare i risultati di GuardDuty, Inspector, Macie, Firewall Manager e Prowler in organizzazioni AWS con più account, abilitare standard come CIS AWS Foundations e PCI DSS e automatizzare la correzione tramite EventBridge e Lambda. Da utilizzare per centralizzare il monitoraggio della conformità AWS o i dashboard di conformità esecutiva; non per il rilevamento delle minacce (GuardDuty) o la classificazione dei dati (Macie).
