Implemente AWS Security Hub, respaldado por AWS Config, para agregar hallazgos de GuardDuty, Inspector, Macie, Firewall Manager y Prowler en organizaciones de AWS con múltiples cuentas, habilite estándares como CIS AWS Foundations y PCI DSS, y automatice la corrección a través de EventBridge y Lambda. Úselo para centralizar el monitoreo de cumplimiento de AWS o los paneles de control de cumplimiento ejecutivo; no para detección de amenazas (GuardDuty) o clasificación de datos (Macie).
