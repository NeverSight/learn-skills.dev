Déployez AWS Security Hub, soutenu par AWS Config, pour agréger les résultats de GuardDuty, Inspector, Macie, Firewall Manager et Prowler à travers des organisations AWS multi‑comptes, activer des normes telles que CIS AWS Foundations et PCI DSS, et automatiser les actions de remédiation via EventBridge et Lambda. Utilisez-le pour centraliser la surveillance de conformité AWS ou les tableaux de bord de conformité exécutifs ; pas pour la détection des menaces (GuardDuty) ou la classification des données (Macie).
