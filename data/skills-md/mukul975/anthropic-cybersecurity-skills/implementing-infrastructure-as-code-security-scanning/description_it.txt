Implementa la scansione di sicurezza automatizzata per Infrastructure as Code utilizzando Checkov, tfsec e KICS per rilevare configurazioni errate in Terraform, CloudFormation, manifest Kubernetes e grafici Helm, oltre a governance basata su policy e integrazione CI/CD. Da utilizzare durante la convalida dell'infrastruttura cloud prima della distribuzione o il blocco di modifiche non sicure (bucket S3 pubblici, gruppi di sicurezza aperti) nelle richieste pull.
