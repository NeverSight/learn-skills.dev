Реализует автоматическое сканирование безопасности для инфраструктуры как кода с использованием Checkov, tfsec и KICS для обнаружения неправильных конфигураций в Terraform, CloudFormation, манифестах Kubernetes и диаграммах Helm, а также управление на основе политик и интеграцию CI/CD. Используйте при проверке облачной инфраструктуры перед развертыванием или блокировании небезопасных изменений (общедоступные корзины S3, открытые группы безопасности) в запросах на включение.
