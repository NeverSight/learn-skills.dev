Implémente une analyse de sécurité automatisée pour Infrastructure as Code à l'aide de Checkov, tfsec et KICS pour détecter les erreurs de configuration dans Terraform, CloudFormation, les manifestes Kubernetes et les graphiques Helm, ainsi qu'une gouvernance basée sur des politiques et une intégration CI/CD. À utiliser lors de la validation de l'infrastructure cloud avant le déploiement ou du blocage des modifications non sécurisées (compartiments S3 publics, groupes de sécurité ouverts) dans les demandes d'extraction.
