Implementiert automatisierte Sicherheitsscans für Infrastructure as Code mit Checkov, tfsec und KICS, um Fehlkonfigurationen in Terraform, CloudFormation, Kubernetes-Manifesten und Helm-Charts zu erkennen, sowie richtlinienbasierte Governance und CI/CD-Integration. Zur Validierung der Cloud-Infrastruktur vor der Bereitstellung oder zum Blockieren unsicherer Änderungen (öffentliche S3-Buckets, offene Sicherheitsgruppen) in Pull-Anfragen.
