Запускает наборы проб NVIDIA Garak (jailbreak, внедрение запросов, утечка данных, токсичность и др.) против конечной точки LLM — модели Hugging Face, совместимые с OpenAI API или Bedrock — а затем интерпретирует полученный отчёт о коэффициенте успеха для триажа. Используется при базовой оценке безопасности LLM до и после развертывания, проверке того, что ограничительные механизмы или дообучение снижают успешность jailbreak/внедрения, или для предоставления доказательств в оценке рисков ИИ.
