Ejecuta las suites de pruebas garak de NVIDIA (jailbreak, inyección de prompts, fuga de datos, toxicidad y más) contra un endpoint LLM —modelos de Hugging Face, APIs compatibles con OpenAI o Bedrock— y luego interpreta el informe de tasa de aciertos resultante para triage. Úsalo al establecer la línea base de seguridad del LLM antes/después del despliegue, al validar que una salvaguarda o ajuste fino reduce las tasas de éxito de jailbreak/inyección, o al producir evidencia para una evaluación de riesgos de IA.
