Esegue le suite di probe garak di NVIDIA (jailbreak, iniezione di prompt, perdita di dati, tossicità e altro) contro un endpoint LLM — modelli Hugging Face, API compatibili con OpenAI o Bedrock — e poi interpreta il report sul tasso di rilevamento per la triage. Da usare per stabilire una baseline della sicurezza LLM prima/dopo il deployment, per verificare che una guardrail o un fine-tuning riducano i tassi di successo di jailbreak/iniezione, o per produrre prove per una valutazione del rischio AI.
