Exécute les suites de sondes Garak de NVIDIA (jailbreak, injection d’instructions, fuite de données, toxicité, etc.) contre un point d’accès LLM — modèles Hugging Face, API compatibles OpenAI ou Bedrock — puis interprète le rapport de taux de réussite obtenu pour le triage. À utiliser lors de l’établissement d’une base de référence de la sécurité des LLM avant/après le déploiement, pour valider qu’un garde-fou ou un affinement réduit les taux de succès des jailbreaks/injections, ou pour fournir des preuves dans le cadre d’une évaluation des risques IA.
