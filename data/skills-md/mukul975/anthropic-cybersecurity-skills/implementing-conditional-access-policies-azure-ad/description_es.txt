Configura las políticas de Acceso Condicional de Microsoft Entra ID (Azure AD) para el control de acceso de confianza cero, abarcando el diseño de políticas basadas en señales, requisitos de cumplimiento de dispositivos, autenticación basada en riesgos, ubicaciones nombradas y controles de sesión alineados con NIST SP 1800‑35. Úsalo al implementar o reforzar políticas de acceso condicional, al construir una arquitectura de seguridad de confianza cero en Entra ID o al prepararse para una evaluación de seguridad de los controles de acceso de Azure AD.
