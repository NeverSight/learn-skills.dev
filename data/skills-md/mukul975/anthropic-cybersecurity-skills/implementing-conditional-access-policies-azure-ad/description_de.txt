Konfiguriert Microsoft Entra ID (Azure AD) Conditional Access‑Richtlinien für Zero‑Trust‑Zugriffskontrolle, einschließlich signalbasierter Richtliniengestaltung, Geräte‑Compliance‑Anforderungen, risikobasierter Authentifizierung, benannter Standorte und Sitzungssteuerungen, die an NIST SP 1800‑35 ausgerichtet sind. Verwenden Sie dies beim Bereitstellen oder Härten von Conditional Access‑Richtlinien, beim Aufbau einer Zero‑Trust‑Sicherheitsarchitektur in Entra ID oder bei der Vorbereitung einer Sicherheitsbewertung der Azure AD‑Zugriffskontrollen.
