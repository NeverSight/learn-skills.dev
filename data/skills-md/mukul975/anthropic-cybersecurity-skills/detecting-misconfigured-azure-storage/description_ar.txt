قم بتدقيق حسابات Azure Storage لحاويات البيانات كبيرة الحجم العامة، والتشفير المفقود، ورموز SAS شديدة التساهل، والتسجيل المعطل، وانتهاكات الوصول إلى الشبكة باستخدام Azure CLI، وPowerShell، وMicrosoft Defender للتخزين. يُستخدم لعمليات تدقيق أمان التخزين عبر الاشتراكات، أو الاستجابة لتنبيهات الوصول المجهول لـ Defender for Storage، أو التحقق من ضوابط الامتثال، أو تعيين خطوط الأساس للأمان عند إعداد الاشتراك.
