Audite las cuentas de Azure Storage para detectar contenedores de blobs públicos, falta de cifrado, tokens SAS demasiado permisivos, registros deshabilitados e infracciones de acceso a la red mediante la CLI de Azure, PowerShell y Microsoft Defender para almacenamiento. Úselo para auditorías de seguridad de almacenamiento en todas las suscripciones, respondiendo a alertas de acceso anónimo de Defender for Storage, verificando controles de cumplimiento o estableciendo líneas de base de seguridad al incorporar una suscripción.
