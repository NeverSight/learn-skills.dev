Проведите аудит учетных записей хранения Azure на наличие общедоступных контейнеров больших двоичных объектов, отсутствующего шифрования, слишком разрешительных токенов SAS, отключенного ведения журнала и нарушений доступа к сети с помощью Azure CLI, PowerShell и Microsoft Defender для хранилища. Используйте для аудита безопасности хранилища в подписках, реагирования на оповещения об анонимном доступе Защитника для хранилища, проверки соответствия требованиям или установки базовых показателей безопасности при подключении подписки.
