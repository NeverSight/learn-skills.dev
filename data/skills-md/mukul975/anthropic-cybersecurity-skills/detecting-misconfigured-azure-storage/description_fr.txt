Auditez les comptes de stockage Azure pour détecter les conteneurs d'objets blob publics, le chiffrement manquant, les jetons SAS trop permissifs, la journalisation désactivée et les violations d'accès réseau à l'aide d'Azure CLI, PowerShell et Microsoft Defender pour le stockage. À utiliser pour les audits de sécurité du stockage sur tous les abonnements, pour répondre aux alertes d’accès anonyme de Defender for Storage, pour vérifier les contrôles de conformité ou pour définir des lignes de base de sécurité lors de l’intégration d’un abonnement.
