Überwachen Sie Azure Storage-Konten auf öffentliche Blob-Container, fehlende Verschlüsselung, übermäßig freizügige SAS-Tokens, deaktivierte Protokollierung und Netzwerkzugriffsverletzungen mithilfe von Azure CLI, PowerShell und Microsoft Defender for Storage. Wird für abonnementübergreifende Speichersicherheitsüberprüfungen, zur Reaktion auf Warnungen zum anonymen Zugriff von Defender for Storage, zur Überprüfung von Compliance-Kontrollen oder zum Festlegen von Sicherheitsgrundsätzen beim Onboarding eines Abonnements verwendet.
