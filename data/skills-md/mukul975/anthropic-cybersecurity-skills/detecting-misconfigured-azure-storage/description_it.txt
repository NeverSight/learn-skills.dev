Controlla gli account di archiviazione di Azure per rilevare contenitori BLOB pubblici, crittografia mancante, token SAS eccessivamente permissivi, registrazione disabilitata e violazioni dell'accesso alla rete utilizzando l'interfaccia della riga di comando di Azure, PowerShell e Microsoft Defender for Storage. Utilizzalo per controlli di sicurezza dello storage tra abbonamenti, rispondendo agli avvisi di accesso anonimo di Defender for Storage, verificando i controlli di conformità o impostando linee di base di sicurezza durante l'onboarding di un abbonamento.
