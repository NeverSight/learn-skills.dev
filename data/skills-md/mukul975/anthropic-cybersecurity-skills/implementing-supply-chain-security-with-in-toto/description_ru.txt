Реализует проверку целостности цепочки поставок для сборок контейнеров с помощью платформы in-toto: генерирует ключи подписи, определяет схему цепочки поставок, записывает этапы конвейера в виде метаданных подписанных ссылок, проверяет перед развертыванием, обеспечивает принудительное выполнение при допуске Kubernetes и интеграцию с SLSA. Используйте при подтверждении этапов конвейера CI/CD, проверке соответствия образа утвержденному процессу сборки или проверке происхождения при допуске. Ключевые слова: in-toto, макет, метаданные ссылки, шаг, проверка, SLSA, происхождение, допуск. Не используйте для подписи и проверки изображений с помощью Cosign — используйтеimplementation-image-provenance-verification-with-cosign.
