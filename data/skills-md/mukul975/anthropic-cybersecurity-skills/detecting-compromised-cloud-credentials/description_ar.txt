اكتشف بيانات الاعتماد السحابية المخترقة عبر AWS وAzure وGCP من خلال تحليل نشاط واجهة برمجة التطبيقات الشاذ وأنماط السفر المستحيل ومؤشرات حشو بيانات الاعتماد باستخدام GuardDuty وMicrosoft Defender for Identity وGoogle SCC Event Threat Detection. يُستخدم عند التحقق من التنبيهات حول نشاط Cloud API من مواقع غير مألوفة، أو الاستجابة لإشعار بيانات الاعتماد المكشوفة، أو تحديد نطاق اختراق بيانات الاعتماد.
