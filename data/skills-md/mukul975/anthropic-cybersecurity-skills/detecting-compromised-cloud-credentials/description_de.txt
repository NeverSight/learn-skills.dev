Erkennen Sie kompromittierte Cloud-Anmeldeinformationen in AWS, Azure und GCP, indem Sie mithilfe von GuardDuty, Microsoft Defender for Identity und Google SCC Event Threat Detection anomale API-Aktivitäten, unmögliche Reisemuster und Anmeldeinformationen-Stuffing-Indikatoren analysieren. Verwenden Sie diese Option, wenn Sie Warnungen zu Cloud-API-Aktivitäten von unbekannten Standorten untersuchen, auf eine Benachrichtigung über offengelegte Anmeldeinformationen reagieren oder den Umfang einer Kompromittierung von Anmeldeinformationen ermitteln möchten.
