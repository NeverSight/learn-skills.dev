El Modelo Diamante de Análisis de Intrusiones proporciona un marco estructurado para analizar intrusiones cibernéticas al examinar cuatro características principales: adversario, capacidad, infraestructura y víctima. Esta habilidad cubre la implementación programática del Modelo Diamante para clasificar y correlacionar eventos de intrusión, construir hilos de actividad y generar inteligencia lista para pivote.
