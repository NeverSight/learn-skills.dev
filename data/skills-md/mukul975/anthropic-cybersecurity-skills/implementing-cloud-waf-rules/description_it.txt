Distribuisce e ottimizza le regole del Web Application Firewall su AWS WAF, Azure WAF e Cloudflare, coprendo set di regole gestite, regole di logica aziendale personalizzate, limitazione di velocità, gestione dei bot e riduzione dei falsi positivi. Da utilizzare quando si distribuiscono nuove app dietro un WAF cloud, quando i pentest rivelano difetti di injection/XSS, quando si affronta traffico di bot o di riempimento delle credenziali o quando la conformità (ad esempio PCI-DSS) impone un WAF.
