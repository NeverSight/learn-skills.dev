Stellt Web Application Firewall-Regeln auf AWS WAF, Azure WAF und Cloudflare bereit und optimiert sie. Dabei werden verwaltete Regelsätze, benutzerdefinierte Geschäftslogikregeln, Ratenbegrenzung, Bot-Management und die Reduzierung falsch positiver Ergebnisse abgedeckt. Verwenden Sie diese Option, wenn Sie neue Apps hinter einer Cloud-WAF bereitstellen, wenn Pentests Injektions-/XSS-Fehler aufdecken, wenn Bot- oder Credential-Stuffing-Verkehr auftritt oder wenn Compliance (z. B. PCI-DSS) eine WAF vorschreibt.
