قم بتجميع وتحليل الأدلة الجنائية السحابية باستخدام AWS CLI، أو Azure CLI، أو gcloud لالتقاط وحدات التخزين، والتقاط بيانات تعريف المثيل وتكوينات مجموعة الأمان، والاحتفاظ بالسجلات السحابية الأصلية (CloudTrail، وسجل النشاط، وسجل التدقيق). يُستخدم عند التحقيق في انتهاك مشتبه به في AWS أو Azure أو GCP، أو تتبع الوصول غير المصرح به من خلال سجلات واجهة برمجة التطبيقات، أو تحليل جهاز افتراضي أو حاوية أو وظيفة بدون خادم مخترقة.
