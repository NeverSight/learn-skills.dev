Raccogli e analizza prove forensi sul cloud utilizzando AWS CLI, Azure CLI o gcloud per eseguire snapshot di volumi, acquisire metadati di istanze e configurazioni di gruppi di sicurezza e conservare log nativi del cloud (CloudTrail, registro attività, registro di controllo). Da utilizzare quando si indaga su una sospetta violazione in AWS, Azure o GCP, si traccia l'accesso non autorizzato tramite i log API o si analizza una VM, un container o una funzione serverless compromessa.
