Sammeln und analysieren Sie cloudforensische Beweise mit AWS CLI, Azure CLI oder gcloud, um Snapshots von Volumes zu erstellen, Instanzmetadaten und Sicherheitsgruppenkonfigurationen zu erfassen und cloudnative Protokolle (CloudTrail, Aktivitätsprotokoll, Audit-Protokoll) aufzubewahren. Verwenden Sie es, wenn Sie einen mutmaßlichen Verstoß in AWS, Azure oder GCP untersuchen, unbefugten Zugriff über API-Protokolle verfolgen oder eine kompromittierte VM, einen Container oder eine serverlose Funktion analysieren.
