Collectez et analysez les preuves médico-légales dans le cloud à l'aide de l'AWS CLI, d'Azure CLI ou de gcloud pour capturer des volumes, capturer les métadonnées d'instance et les configurations de groupes de sécurité et conserver les journaux natifs du cloud (CloudTrail, journal d'activité, journal d'audit). À utiliser pour enquêter sur une violation suspectée dans AWS, Azure ou GCP, traquer un accès non autorisé via les journaux d'API ou analyser une VM, un conteneur ou une fonction sans serveur compromis.
