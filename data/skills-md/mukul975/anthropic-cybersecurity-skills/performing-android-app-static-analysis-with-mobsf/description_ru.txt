Выполняет автоматический статический анализ Android‑приложений с помощью Mobile Security Framework (MobSF) для выявления жёстко закодированных секретов, небезопасных разрешений, уязвимых компонентов, слабой криптографии и уязвимостей уровня кода без запуска приложения. Используется при оценке файлов Android APK/AAB на предмет уязвимостей безопасности до развертывания, во время тестирования на проникновение или в рамках проверок безопасности CI/CD. Активируется при запросах, связанных со статическим анализом Android, сканированием MobSF, оценкой безопасности APK или ревью кода мобильных приложений.
