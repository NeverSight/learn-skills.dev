Effectue une analyse statique automatisée des applications Android à l’aide du Mobile Security Framework (MobSF) pour identifier les secrets codés en dur, les autorisations non sécurisées, les composants vulnérables, la cryptographie faible et les défauts de sécurité au niveau du code, sans exécuter l’application. À utiliser lors de l’évaluation des fichiers APK/AAB Android pour des vulnérabilités de sécurité avant le déploiement, pendant les tests d’intrusion ou dans le cadre des contrôles de sécurité CI/CD. S’active pour les requêtes portant sur l’analyse statique Android, le scan MobSF, l’évaluation de la sécurité des APK ou la révision du code d’application mobile.
