Realiza análisis estático automatizado de aplicaciones Android usando Mobile Security Framework (MobSF) para identificar secretos codificados, permisos inseguros, componentes vulnerables, criptografía débil y fallas de seguridad a nivel de código sin ejecutar la aplicación. Utilízalo al evaluar archivos APK/AAB de Android en busca de vulnerabilidades de seguridad antes del despliegue, durante pruebas de penetración o como parte de puertas de seguridad CI/CD. Se activa para solicitudes que involucren análisis estático de Android, escaneo con MobSF, evaluación de seguridad de APK o revisión de código de aplicaciones móviles.
