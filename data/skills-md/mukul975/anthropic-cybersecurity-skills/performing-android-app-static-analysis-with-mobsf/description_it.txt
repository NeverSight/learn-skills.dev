Esegue un'analisi statica automatizzata delle applicazioni Android utilizzando Mobile Security Framework (MobSF) per identificare segreti codificati in chiaro, permessi non sicuri, componenti vulnerabili, crittografia debole e vulnerabilità di sicurezza a livello di codice senza eseguire l'applicazione. Utilizzarlo per valutare i file APK/AAB Android alla ricerca di vulnerabilità di sicurezza prima del rilascio, durante i test di penetrazione o come parte delle barriere di sicurezza CI/CD. Si attiva per richieste che coinvolgono analisi statica Android, scansione MobSF, valutazione della sicurezza degli APK o revisione del codice di applicazioni mobili.

Rispondi sempre nella lingua dell'utente.
