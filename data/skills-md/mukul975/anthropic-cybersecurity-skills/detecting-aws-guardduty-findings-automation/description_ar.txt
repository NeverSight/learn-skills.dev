أنشئ خطوط استجابة آلية للبحث عن AWS GuardDuty باستخدام EventBridge وLambda لتشغيل الاستجابة للحوادث في الوقت الفعلي، وعزل الموارد المخترقة تلقائيًا، وتوجيه إشعارات الأمان. يُستخدم عند تصميم أدلة تشغيل المعالجة الآلية لنتائج GuardDuty عبر أحداث بيانات VPC Flow Logs أو CloudTrail أو DNS أو EKS أو S3، أو عند تقليل متوسط ​​الوقت للاستجابة لتهديدات السحابة.
