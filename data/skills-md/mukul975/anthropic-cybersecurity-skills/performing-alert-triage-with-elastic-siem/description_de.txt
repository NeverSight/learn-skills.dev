Führen Sie eine systematische Warnungstriage in Elastic Security SIEM durch – klassifizieren, priorisieren und untersuchen Sie Warnungen mithilfe von Kibana, ES|QL-Abfragen und ECS-normalisierten Daten –, um die Arbeitsabläufe von SOC-Analysten voranzutreiben. Verwenden Sie diese Option, wenn Sie eingehende Elastic Security-Erkennungen selektieren, die Alarmwarteschlange eines Analysten priorisieren oder Alarme während SOC-Vorgängen untersuchen.
