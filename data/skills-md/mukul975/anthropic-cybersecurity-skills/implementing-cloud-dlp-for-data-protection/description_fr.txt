Implémentez le cloud DLP à l'aide d'Amazon Macie, de l'API Google Cloud DLP, de Microsoft Purview, d'Azure Information Protection et de Nightfall AI pour découvrir, classer, étiqueter, anonymiser et protéger les données sensibles (PII, PHI, données financières) dans le stockage cloud, les bases de données et les pipelines. Utilisation pour la découverte de données RGPD/HIPAA/PCI DSS, la gouvernance des données cloud ou l'analyse DLP CI/CD ; pas pour le DLP au niveau du point de terminaison, de la messagerie électronique ou du réseau.
