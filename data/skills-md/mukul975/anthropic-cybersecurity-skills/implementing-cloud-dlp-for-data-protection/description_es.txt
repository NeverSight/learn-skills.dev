Implemente DLP en la nube utilizando Amazon Macie, Google Cloud DLP API, Microsoft Purview, Azure Information Protection y Nightfall AI para descubrir, clasificar, etiquetar, desidentificar y proteger datos confidenciales (PII, PHI, datos financieros) en el almacenamiento, las bases de datos y las canalizaciones en la nube. Úselo para descubrimiento de datos GDPR/HIPAA/PCI DSS, gobernanza de datos en la nube o escaneo CI/CD DLP; no para DLP de nivel de red, correo electrónico o endpoint.
