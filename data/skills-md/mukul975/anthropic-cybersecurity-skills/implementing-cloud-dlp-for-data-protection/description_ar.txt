قم بتنفيذ DLP السحابي باستخدام Amazon Macie، وGoogle Cloud DLP API، وMicrosoft Purview، وAzure Information Protection، وNightfall AI لاكتشاف البيانات الحساسة وتصنيفها وتصنيفها وإلغاء تعريفها وحمايتها (معلومات تحديد الهوية الشخصية (PII) والمعلومات الصحية المحمية (PHI) والبيانات المالية) عبر التخزين السحابي وقواعد البيانات وخطوط الأنابيب. يُستخدم لاكتشاف بيانات القانون العام لحماية البيانات/HIPAA/PCI DSS، أو إدارة البيانات السحابية، أو مسح CI/CD DLP؛ وليس لنقطة النهاية أو البريد الإلكتروني أو DLP على مستوى الشبكة.
