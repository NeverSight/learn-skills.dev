Déployez AWS Security Hub en tant que plate-forme CSPM centralisée, soutenue par AWS Config, en agrégeant les résultats de GuardDuty, Inspector, Macie et d'outils tiers ; activez les normes cis Foundations, PCI-DSS et NIST ; automatisez la correction via EventBridge/Systems Manager ; et produisez des preuves d'Audit Manager. À utiliser pour un tableau de bord des résultats centralisé ou des éléments probants d'audit de conformité ; pas pour la détection des menaces ou l'analyse des conteneurs.
