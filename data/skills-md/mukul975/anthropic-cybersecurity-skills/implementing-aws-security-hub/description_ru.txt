Разверните AWS Security Hub в качестве централизованной платформы CSPM на базе AWS Config, объединяющей данные GuardDuty, Inspector, Macie и сторонних инструментов; включить стандарты CIS Foundation, PCI-DSS и NIST; автоматизировать исправление через EventBridge/Systems Manager; и предоставить доказательства Менеджера аудита. Используйте для централизованной информационной панели результатов или доказательств аудита соответствия; не для обнаружения угроз или сканирования контейнеров.
