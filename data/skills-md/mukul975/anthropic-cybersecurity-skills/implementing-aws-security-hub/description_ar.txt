نشر AWS Security Hub كمنصة مركزية لـ CSPM، مدعومة بـ AWS Config، وتجميع النتائج من GuardDuty وInspector وMacie وأدوات الطرف الثالث؛ تمكين أسس CIS، PCI-DSS، ومعايير NIST؛ أتمتة المعالجة عبر EventBridge/Systems Manager؛ وإنتاج أدلة مدير التدقيق. تستخدم للوحة معلومات النتائج المركزية أو أدلة تدقيق الامتثال؛ ليس للكشف عن التهديدات أو فحص الحاويات.
