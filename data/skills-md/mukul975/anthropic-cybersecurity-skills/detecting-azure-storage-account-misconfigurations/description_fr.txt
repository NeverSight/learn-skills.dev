Auditez les comptes de stockage Azure Blob et ADLS pour détecter l'exposition à l'accès public, les jetons SAS faibles ou de longue durée, le chiffrement manquant au repos, le trafic HTTPS uniquement désactivé et les versions TLS obsolètes, à l'aide du SDK Python azure-mgmt-storage pour générer un rapport d'évaluation des risques. À utiliser lors de l'évaluation des comptes de stockage d'un abonnement Azure pour une mauvaise configuration, de la création de contrôles de sécurité du cloud ou de l'enquête sur une exposition suspectée de données via un accès blob public.
