Überprüfen Sie Azure Blob- und ADLS-Speicherkonten auf Gefährdung durch öffentlichen Zugriff, schwache oder langlebige SAS-Token, fehlende Verschlüsselung im Ruhezustand, deaktivierten Nur-HTTPS-Datenverkehr und veraltete TLS-Versionen. Verwenden Sie dazu das Python-SDK „azure-mgmt-storage“, um einen risikobewerteten Bericht zu erstellen. Verwenden Sie diese Option, wenn Sie die Speicherkonten eines Azure-Abonnements auf Fehlkonfigurationen überprüfen, Cloud-Sicherheitsstatusprüfungen erstellen oder eine vermutete Datengefährdung über den Zugriff auf öffentliche Blobs untersuchen.
