تدقيق حسابات تخزين Azure Blob وADLS للكشف عن الوصول العام، ورموز SAS الضعيفة أو طويلة العمر، والتشفير المفقود في حالة عدم النشاط، وحركة مرور HTTPS المعطلة فقط، وإصدارات TLS القديمة، باستخدام Azure-mgmt-storage Python SDK لإنشاء تقرير درجات المخاطر. يُستخدم عند تقييم حسابات تخزين اشتراك Azure بحثًا عن التكوين الخاطئ، أو إنشاء عمليات فحص لموقف أمان السحابة، أو التحقيق في تعرض مشتبه به للبيانات عبر الوصول إلى البيانات الثنائية الكبيرة الحجم العامة.
