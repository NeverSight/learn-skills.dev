Controllare gli account BLOB di Azure e di archiviazione ADLS per esposizione all'accesso pubblico, token SAS deboli o di lunga durata, crittografia mancante a riposo, traffico solo HTTPS disabilitato e versioni TLS obsolete, usando l'SDK Python azure-mgmt-storage per generare un report con punteggio di rischio. Da utilizzare quando si valutano gli account di archiviazione di una sottoscrizione di Azure per eventuali errori di configurazione, si creano controlli sullo stato di sicurezza del cloud o si esamina una sospetta esposizione dei dati tramite l'accesso BLOB pubblico.
