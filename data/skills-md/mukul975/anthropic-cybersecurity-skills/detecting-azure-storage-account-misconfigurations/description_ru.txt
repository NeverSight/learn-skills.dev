Проведите аудит учетных записей хранения Azure Blob и ADLS на предмет открытого доступа, слабых или долгоживущих токенов SAS, отсутствия шифрования в состоянии покоя, отключенного трафика только HTTPS и устаревших версий TLS, используя пакет Python SDK azure-mgmt-storage для создания отчета с оценкой рисков. Используйте при оценке учетных записей хранения подписки Azure на предмет неправильной конфигурации, построении проверок состояния облачной безопасности или расследовании предполагаемого раскрытия данных через доступ к общедоступным BLOB-объектам.
