تحقق من اختراق حساب AWS عن طريق الاستعلام عن CloudTrail باستخدام LookupEvents الخاص بـ boto3 أو AWS Athena SQL عبر السجلات التي تم تسليمها بواسطة S3، وتصفية وكلاء المستخدم المشبوهين، وعناوين IP المصدر، وأسماء الأحداث لإعادة إنشاء مخطط زمني للمهاجم. يُستخدم عند تتبع مكالمات API غير المصرح بها، أو استخراج بيانات S3، أو تصعيد امتيازات IAM، أو الكشف عن بيانات الاعتماد، وإنشاء تقرير جنائي بالنتائج وخطوات الإصلاح.
