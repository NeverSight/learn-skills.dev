Esamina la compromissione degli account AWS eseguendo query su CloudTrail con LookupEvents di boto3 o AWS Athena SQL su log forniti da S3, filtrando su agenti utente sospetti, IP di origine e nomi di eventi per ricostruire la sequenza temporale dell'aggressore. Da utilizzare quando si tracciano chiamate API non autorizzate, esfiltrazione di dati S3, escalation di privilegi IAM o esposizione di credenziali e si crea un report forense dei risultati e delle fasi di risoluzione.
