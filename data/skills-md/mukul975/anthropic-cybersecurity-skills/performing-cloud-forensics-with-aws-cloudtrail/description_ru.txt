Расследуйте компрометацию учетной записи AWS, запрашивая CloudTrail с помощью LookupEvents boto3 или AWS Athena SQL через журналы, доставленные S3, фильтруя подозрительные пользовательские агенты, исходные IP-адреса и имена событий, чтобы восстановить временную шкалу злоумышленника. Используйте при отслеживании несанкционированных вызовов API, краже данных S3, повышении привилегий IAM или раскрытии учетных данных, а также при создании аналитического отчета о результатах и ​​действиях по устранению.
