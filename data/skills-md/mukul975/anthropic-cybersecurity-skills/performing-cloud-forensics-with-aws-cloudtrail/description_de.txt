Untersuchen Sie die Kompromittierung von AWS-Konten, indem Sie CloudTrail mit LookupEvents von boto3 oder AWS Athena SQL über von S3 bereitgestellte Protokolle abfragen und nach verdächtigen Benutzeragenten, Quell-IPs und Ereignisnamen filtern, um die Zeitleiste eines Angreifers zu rekonstruieren. Verwenden Sie es, wenn Sie nicht autorisierte API-Aufrufe, S3-Datenexfiltration, IAM-Berechtigungseskalation oder Offenlegung von Anmeldeinformationen verfolgen und einen forensischen Bericht über Ergebnisse und Korrekturschritte erstellen.
