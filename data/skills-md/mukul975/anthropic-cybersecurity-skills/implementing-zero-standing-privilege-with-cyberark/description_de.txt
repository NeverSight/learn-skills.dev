Setzen Sie CyberArk Secure Cloud Access (SCA) ein, um ständige Privilegien in AWS, Azure und GCP zu beseitigen, indem Sie flüchtige, bereichsbezogene Rollen auf Just-in-Time-Basis bereitstellen, die durch das TEA-Framework (Zeit, Berechtigungen, Genehmigungen) geregelt werden. Verwenden Sie diese Option beim Entwerfen oder Implementieren von Zero-Steing-Privilege-/Just-in-Time-Privilege-Zugriffsmodellen mit CyberArk oder beim Ersetzen persistenter Cloud-Administratorrollen durch zeitgebundene, genehmigungsgesteuerte Sitzungen.
