Разверните сервер Velociraptor и его агенты, затем создайте артефакты VQL (Velociraptor Query Language) и запустите их в виде масштабных охот по всему парку, форензик‑сборов по запросу или автономных офлайн‑коллекторов. Используйте это при поиске TTP на сотнях‑тысячах конечных точек, собирая судебно‑технические артефакты в ходе реагирования на инциденты без переимиджинга, либо создавая коллекторы для неуправляемых/изолированных устройств.
