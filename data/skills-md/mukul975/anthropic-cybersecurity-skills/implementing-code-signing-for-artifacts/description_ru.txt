Реализует подпись кода для артефактов сборки (двоичные файлы, пакеты, контейнеры) с использованием GPG, Sigstore и инструментов подписи для конкретной платформы, создавая цепочки доверия и проверяя подписи в конвейерах развертывания. Используйте при проверке целостности артефактов на предмет несанкционированного вмешательства в цепочку поставок, подтверждении подлинности клиентам, построении конвейеров с нулевым доверием, которые отклоняют неподписанные артефакты, или при выполнении требований SLSA уровня 2+ по происхождению.
