Разрабатывает зоны безопасности и каналы для систем промышленного управления (IACS) в соответствии с IEC 62443-3-2 — разделение зон на основе риска, назначение целевого уровня безопасности (SL‑T), управление каналами и микросегментация межсетевого экрана, проверенная по модели Purdue Reference Model. Используется при проектировании OT‑сетевых зон для нового объекта, при интеграции зон в плоскую OT‑сеть или при обновлении сегментации только на основе VLAN для соответствия IEC 62443-3-2.
