Exploita pods privilegiados, montajes de host, vulnerabilidades de runC y sockets de Docker expuestos para salir de un contenedor y alcanzar el host subyacente durante una evaluación de seguridad de contenedores autorizada. Úsalo al ejecutar una prueba de escape aprobada, demostrando el impacto real de una carga de trabajo privilegiada o hostPath, o validando que las mitigaciones de escape realmente funcionan. Palabras clave: container breakout, privileged, hostPath, docker.sock, runC CVE-2019-5736, CVE-2024-21626, release_agent, nsenter. No lo uses para la detección defensiva de estas técnicas; usa detecting-container-escape-attempts.
