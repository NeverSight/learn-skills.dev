Запустите Chainsaw по собранным файлам Windows EVTX, чтобы проводить охоту с помощью набора правил SigmaHQ, встроенных правил обнаружения и быстрого поиска по ключевым словам/регулярным выражениям, а также анализировать shimcache, SRUM и пробелы в журналах событий, выводя цветные таблицы, CSV или JSON. Используйте при первой реакции на триаж для офлайн‑детекции без SIEM по журналам событий Windows или для быстрой проверки гипотезы охоты и создания отчётных данных.
