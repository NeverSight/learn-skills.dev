Configura x18n (`@x18n/cli`) en un proyecto, o migra desde i18n-ally. Úsalo cuando un proyecto no tenga aún configuración de x18n, cuando x18n detecte archivos de idioma o biblioteca incorrectos, cuando el usuario solicite añadir, instalar o configurar x18n, o cuando `.vscode/settings.json` contenga configuraciones `i18n-ally.*`.

Por favor, responde siempre en el idioma del usuario.
