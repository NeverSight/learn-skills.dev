Gestisci le traduzioni di un progetto con x18n (`@x18n/cli`). Usalo quando l'attività riguarda i file di localizzazione o le chiavi di traduzione: aggiungere, rinominare o eliminare chiavi, trovare la chiave dietro un testo mostrato nell'app, individuare chiavi mancanti o inutilizzate, tradurre messaggi mancanti, revisionare le traduzioni, estrarre stringhe hard‑coded, mantenere un glossario di termini.

Per favore, rispondi sempre nella lingua dell'utente.
