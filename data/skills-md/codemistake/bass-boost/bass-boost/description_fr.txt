À utiliser lorsqu'une tâche nécessite quelque chose que l'agent de codage ne peut pas faire par lui-même et qu'un modèle externe peut : générer ou remplacer une image raster, un espace réservé, une icône ou une texture ; analyser une vidéo ou un enregistrement d'écran ; transcrire un audio ou une note vocale ; recherchez une page ou un sujet que les outils Web intégrés ne peuvent pas atteindre ; obtenir un deuxième avis indépendant sur une décision non conforme au code ; ou déplacez les lectures intensives vers un modèle moins cher lorsque l'utilisateur déclare que ses limites d'abonnement sont faibles. À utiliser également lorsque l'utilisateur demande quel modèle externe choisir pour une tâche ou combien coûterait un appel.
