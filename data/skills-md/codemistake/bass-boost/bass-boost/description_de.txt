Verwenden Sie diese Option, wenn eine Aufgabe etwas erfordert, das der Codierungsagent nicht selbst erledigen kann und ein externes Modell Folgendes tun kann: ein Rasterbild, einen Platzhalter, ein Symbol oder eine Textur generieren oder ersetzen; eine Video- oder Bildschirmaufnahme analysieren; Audio oder eine Sprachnotiz transkribieren; Recherchieren Sie eine Seite oder ein Thema, die die integrierten Web-Tools nicht erreichen können. Holen Sie sich eine unabhängige Zweitmeinung zu einer Nicht-Code-Entscheidung ein; oder verlagern Sie intensives Lesen auf ein günstigeres Modell, wenn der Benutzer angibt, dass sein Abonnementlimit zur Neige geht. Verwenden Sie es auch, wenn der Benutzer fragt, welches externe Modell er für eine Aufgabe auswählen soll oder was ein Anruf kosten würde.
