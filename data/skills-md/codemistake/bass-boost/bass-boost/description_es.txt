Úselo cuando una tarea necesita algo que el agente de codificación no puede hacer por sí solo y un modelo externo puede: generar o reemplazar una imagen rasterizada, marcador de posición, icono o textura; analizar un vídeo o una grabación de pantalla; transcribir audio o una nota de voz; investigar una página o tema que las herramientas web integradas no pueden alcanzar; obtener una segunda opinión independiente sobre una decisión no relacionada con el código; o trasladar la lectura intensa a un modelo más económico cuando el usuario dice que sus límites de suscripción se están agotando. También se utiliza cuando el usuario pregunta qué modelo externo elegir para una tarea o cuánto costaría una llamada.
