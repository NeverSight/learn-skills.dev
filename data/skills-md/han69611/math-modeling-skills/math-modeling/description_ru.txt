Поощрительная версия национального конкурса по математическому моделированию — Основная концепция: отказ от шаблонов, пять инновационных путей (перспектива / улучшение / комбинация / перевод / саморефлексия), шаблон таблицы сравнения моделей, код анализа чувствительности с двумя параметрами, пять шаблонных недугов, которые не нравятся судьям, контрольный список трассировки независимого мышления. Включает деревья решений, шаблоны кода Python, бумажные визуализации, шаблон LaTeX, 72-часовое боевое руководство. Новые дополнения: подробное руководство по написанию рефератов (шаблоны предложений + аннотированный образец + список для самопроверки), теория игр, VIKOR, серый реляционный анализ, глубокая эвристическая оптимизация, SVM/XGBoost/LightGBM/Prophet, ансамбль моделей, программирование ограничений, вейвлет-анализ, клеточные автоматы, системная динамика и т. д. Применимо к CUMCM/MCM/ICM.
