Utilice la CLI oh-gc para gestionar los repositorios de GitCode — incluyendo autenticación, incidencias, PRs, revisores, probadores, etiquetas, versiones y configuración del repositorio. Esta habilidad se usa cuando un usuario desea realizar un commit de código, crear una incidencia, crear un PR, actualizar un PR y ejecutar otras acciones relacionadas con el sitio web de GitCode.

Por favor, responda siempre en el idioma del usuario.
