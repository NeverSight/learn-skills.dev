Utilizza l’interfaccia a riga di comando oh-gc per gestire i repository GitCode — includendo autenticazione, segnalazioni, PR, revisori, tester, tag, release e configurazione del repository. Questa funzionalità viene usata quando un utente vuole effettuare un commit di codice, creare una segnalazione, aprire una PR, aggiornare una PR e svolgere altre azioni relative al sito GitCode.

Rispondi sempre nella lingua dell’utente.
