Utilisez le CLI oh‑gc pour gérer les dépôts GitCode — y compris l’authentification, les tickets, les PR, les réviseurs, les testeurs, les labels, les versions et la configuration du dépôt. Cette compétence est utilisée lorsqu’un utilisateur souhaite soumettre du code, créer un ticket, créer une PR, mettre à jour une PR ou effectuer d’autres opérations impliquant l’interface Web de GitCode.

Veuillez toujours répondre dans la langue de l’utilisateur.
