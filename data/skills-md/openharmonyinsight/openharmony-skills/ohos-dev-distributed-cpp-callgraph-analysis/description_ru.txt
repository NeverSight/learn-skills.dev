Используйте, когда необходимо проверить полноту цепочки вызовов при изменении C++ кода в OpenHarmony, особенно для распространения данных, путей IPC/прокси/заглушек, виртуальных переопределений, обратных вызовов или границ dlopen/dlsym. Генерирует таблицы доказательств и матрицы охвата модификаций; вспомогательный скрипт только обнаруживает возможные ребра.
