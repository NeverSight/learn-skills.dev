Generar casos de prueba unitarios para código OpenHarmony C/C++. Utilizar cuando: (1) el usuario solicita generar pruebas unitarias para un subsistema/módulo/archivo/función; (2) se escriben casos de prueba HWTEST/HWTEST_F; (3) se crea ohos_unittest; (4) el usuario menciona “generar casos de prueba”, “escribir pruebas unitarias”, HWTEST o ohos_unittest. Palabras clave: HWTEST, ohos_unittest, prueba unitaria, pruebas en C++, generación de pruebas unitarias.
