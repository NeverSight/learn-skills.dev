Инструмент проверки качества кода тестов OpenHarmony XTS. Сканирует 23 правила проверки (Критические + Предупреждения), автоматически генерирует отчёт в Excel, обнаруживает низкоуровневые проблемы и нарушения стандартов кодирования. Используйте эту возможность для проверки качества кода тестов XTS, сканирования проблем стандартов кодирования, валидации тестовых случаев, обнаружения низкоуровневых проблем, проверки использования интерфейса getSync, проверки формата утверждения кода ошибки, проверки дублирующихся тестовых случаев, проверки соглашений о наименовании HAP, сканирования проблем конфигурации BUILD.gn и проверки уровней APL сертификата подписи. Триггерные ключевые слова: XTS, качество тестов, проверка кода, стандарты кодирования, проверка тестовых случаев, ACTS, DCTS, HATS.
