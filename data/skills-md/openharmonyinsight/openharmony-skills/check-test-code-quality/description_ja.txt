OpenHarmony XTS テストコード品質検査ツール。23 の検査ルール（Critical + Warning）をスキャンし、Excel レポートを自動生成し、低レベルの問題やコーディング標準違反を検出します。この機能を使って XTS テストコードの品質をチェックし、コーディング標準の問題をスキャンし、テストケースを検証し、低レベルの問題を発見し、getSync インターフェースの使用状況を確認し、エラーコードアサーション形式を検証し、重複テストケースを検出し、HAP の命名規則をチェックし、BUILD.gn 設定の問題をスキャンし、署名・証明書の APL レベルを検証するなどが可能です。トリガーキーワード：XTS、テスト品質、コード検査、コーディング基準、テストケース検査、ACTS、DCTS、HATS。
