Herramienta de inspección de calidad de código de pruebas XTS de OpenHarmony. Escanea 23 reglas de inspección (Críticas + Advertencias), genera automáticamente un informe en Excel y detecta problemas de bajo nivel y violaciones de los estándares de codificación. Utilice esta funcionalidad para comprobar la calidad del código de pruebas XTS, escanear problemas de estándares de codificación, verificar casos de prueba, descubrir problemas de bajo nivel, revisar el uso de la interfaz getSync, validar el formato de aserción de códigos de error, buscar casos de prueba duplicados, comprobar las convenciones de nomenclatura HAP, escanear problemas de configuración de BUILD.gn y verificar el nivel APL del certificado de firma, etc. Palabras clave activadoras: XTS, calidad de pruebas, inspección de código, estándares de codificación, inspección de casos de prueba, ACTS, DCTS, HATS.
