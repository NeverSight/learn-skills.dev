Outil d'inspection de la qualité du code de test OpenHarmony XTS. Analyse 23 règles d'inspection (Critiques + Avertissements), génère automatiquement un rapport Excel, détecte les problèmes de bas niveau et les violations des normes de codage. Utilisez cette fonctionnalité pour inspecter la qualité du code de test XTS, scanner les problèmes de normes de codage, valider les cas de test, découvrir les problèmes de bas niveau, vérifier l’utilisation de l’interface getSync, valider le format d’assertion des codes d’erreur, détecter les cas de test en double, vérifier les conventions de nommage HAP, analyser les problèmes de configuration BUILD.gn et contrôler les niveaux APL du certificat de signature, etc. Mots‑clés déclencheurs : XTS, qualité des tests, inspection de code, normes de codage, inspection des cas de test, ACTS, DCTS, HATS.
