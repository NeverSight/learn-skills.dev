OpenHarmony C/C++ 기반 유닛 테스트 케이스에 따라 코드 커버리지 보고서를 생성하며, 전체와 증분 커버리지 분석을 모두 지원하고 hdc를 통해 테스트 디바이스에 연결해야 합니다. 사용 시점: (1) 사용자가 서브시스템·컴포넌트·모듈·테스트 스위트·테스트 케이스에 대한 전체 코드 커버리지를 요청할 때; 보고서 경로가 제공되면 이를 --output 경로로 해석합니다. (2) 사용자가 컴포넌트·모듈·테스트 스위트·테스트 케이스에 대한 증분 코드 커버리지를 요청할 때, git‑diff 파일이 필요합니다; 보고서 경로가 제공되면 이를 --output 경로로 해석합니다. 참고: 증분 커버리지는 서브시스템 수준 분석을 지원하지 않습니다. 테스트 실행을 위해 OpenHarmony 디바이스와 연결이 필요할 때 활성화합니다.
