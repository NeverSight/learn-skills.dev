Fournir la génération de rapports de couverture de code pour OpenHarmony C/C++ à partir de cas de test unitaires, en prenant en charge à la fois l’analyse de couverture complète et incrémentielle, nécessitant une connexion aux appareils de test via hdc. Utiliser lorsque : (1) l’utilisateur demande la génération de la couverture de code complète pour un sous‑système/composant/module/suite de tests/cas de test ; si un chemin de rapport est fourni, il est interprété comme le chemin --output ; (2) l’utilisateur demande la génération de la couverture de code incrémentielle pour un composant/module/suite de tests/cas de test, nécessitant un fichier diff git ; si un chemin de rapport est fourni, il est interprété comme le chemin --output. Remarque : la couverture incrémentielle ne prend pas en charge l’analyse au niveau du sous‑système. Activer lorsqu’il est nécessaire de se connecter à un dispositif OpenHarmony pour exécuter les tests.
