Proporciona la generación de informes de cobertura de código para OpenHarmony C/C++ basada en casos de prueba unitarios, admite tanto análisis de cobertura completa como incremental, y requiere conectar al dispositivo de prueba mediante hdc. Uso cuando: (1) el usuario solicita cobertura de código completa para un subsistema/componente/módulo/conjunto de pruebas/caso de prueba; si se suministra una ruta de informe, se interpreta como la ruta --output; (2) el usuario solicita cobertura de código incremental para un componente/módulo/conjunto de pruebas/caso de prueba, requiriendo un archivo git‑diff; si se suministra una ruta de informe, se interpreta como la ruta --output. Nota: la cobertura incremental no admite análisis a nivel de subsistema. Activar cuando se necesita una conexión a un dispositivo OpenHarmony para ejecutar las pruebas.
