Fornisce la generazione del report di copertura del codice per OpenHarmony C/C++ basata sui casi di test unitari, supportando sia l'analisi completa che quella incrementale della copertura, e richiede la connessione al dispositivo di test tramite hdc. Uso quando: (1) l'utente richiede la copertura completa del codice per un sottosistema/componente/modulo/suite di test/caso di test; se viene fornito un percorso per il report, viene interpretato come il percorso --output; (2) l'utente richiede la copertura incrementale del codice per un componente/modulo/suite di test/caso di test, richiedendo un file git‑diff; se viene fornito un percorso per il report, viene interpretato come il percorso --output. Nota: la copertura incrementale non supporta l'analisi a livello di sottosistema. Attiva quando è necessaria una connessione a un dispositivo OpenHarmony per eseguire i test.
