Provides code coverage report generation for OpenHarmony C/C++ based on unit test cases, supporting both full and incremental coverage analysis, and requires connecting to the test device via hdc. Use when: (1) the user requests full code coverage for a subsystem/component/module/test suite/test case; if a report path is supplied, it is parsed as the --output path; (2) the user requests incremental code coverage for a component/module/test suite/test case, requiring a git‑diff file; if a report path is supplied, it is parsed as the --output path. Note: incremental coverage does not support subsystem‑level analysis. Activate when a connection to an OpenHarmony device is needed to run the tests.
