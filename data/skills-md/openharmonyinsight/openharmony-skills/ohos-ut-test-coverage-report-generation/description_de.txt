Liefere die Erstellung von Code‑Coverage‑Berichten für OpenHarmony C/C++ basierend auf Unit‑Test‑Fällen, unterstütze sowohl vollständige als auch inkrementelle Coverage‑Analyse und erfordere eine Verbindung zum Testgerät über hdc. Verwende es, wenn: (1) der Benutzer vollständige Code‑Coverage für ein Subsystem/Komponente/Modul/Test‑Suite/Test‑Fall anfordert; wenn ein Berichtspfad angegeben wird, wird er als --output‑Pfad interpretiert; (2) der Benutzer inkrementelle Code‑Coverage für eine Komponente/Modul/Test‑Suite/Test‑Fall anfordert, wobei eine Git‑Diff‑Datei erforderlich ist; wenn ein Berichtspfad angegeben wird, wird er als --output‑Pfad interpretiert. Hinweis: Inkrementelle Coverage unterstützt die Subsystem‑Ebene nicht. Aktivieren, wenn eine Verbindung zu einem OpenHarmony‑Gerät zum Ausführen von Tests erforderlich ist.
