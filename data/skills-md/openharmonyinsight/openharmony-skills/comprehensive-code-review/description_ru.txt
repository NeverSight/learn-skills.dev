Код‑ревью для ACE Engine (OpenHarmony ArkUI), охватывающее C++/JS/TS/ArkTS. Анализирует более 19 измерений: стабильность, производительность, многопоточность, безопасность, память, современные практики C++, принципы SOLID, шаблоны проектирования, надёжность, тестируемость, поддерживаемость, наблюдаемость, дизайн API, технический долг, обратную совместимость. Формирует отчёты с уровнями тяжести, рекомендациями по рефакторингу и проверками ACE Engine (Pattern/Model/Property, жизненный цикл компонентов, RefPtr/WeakPtr, четырёхуровневая архитектура). Применяется при: обзоре pull‑request’ов, анализе качества кода, соблюдении стандартов, выявлении технического долга, валидации архитектуры, генерации отчётов о качестве.
