Code‑Review für die ACE Engine (OpenHarmony ArkUI) mit Abdeckung von C++/JS/TS/ArkTS. Analysiert über 19 Dimensionen: Stabilität, Leistung, Threading, Sicherheit, Speicher, moderne C++‑Praktiken, SOLID‑Prinzipien, Entwurfsmuster, Robustheit, Testbarkeit, Wartbarkeit, Beobachtbarkeit, API‑Design, technische Schulden, Abwärtskompatibilität. Gibt Schweregrade, Refactoring‑Vorschläge und ACE‑Engine‑Checks (Pattern/Model/Property, Komponentenlebenszyklus, RefPtr/WeakPtr, Vier‑Schichten‑Architektur) aus. Anwendung: bei der Überprüfung von PRs, Analyse der Codequalität, Durchsetzung von Standards, Identifizierung technischer Schulden, Validierung der Architektur, Erstellung von Qualitätsberichten.
