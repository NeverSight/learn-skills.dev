Использовать при управлении репозиториями GitCode из терминала с помощью CLI oh‑gc — аутентификация, задачи, пул‑запросы, ревьюверы, тестировщики, метки, релизы и настройки репозитория. Срабатывает при командах oh‑gc, управлении задачами/пул‑запросами GitCode или когда пользователь хочет взаимодействовать с GitCode без браузера.
