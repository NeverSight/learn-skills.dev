Генерировать тестовые случаи LLVM libFuzzer FUZZ для проектов C/C++, проводить 26 обзоров спецификаций безопасности и создавать семантические семенные данные. Совместимо с системами сборки OpenHarmony, Linux и Android. Ключевые слова‑триггеры: fuzz testing, generate fuzzer, create fuzz test case, fuzz specification check, fuzz_test, LLVMFuzzerTestOneInput, seed data/corpus.
