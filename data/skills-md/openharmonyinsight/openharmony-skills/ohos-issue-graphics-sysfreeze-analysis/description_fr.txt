Utilisez-le lors de l'analyse des journaux sysfreeze/appfreeze d'OpenHarmony pour diagnostiquer les blocages de processus et les problèmes de blocage de threads. Il se déclenche sur SERVICE_BLOCK, THREAD_BLOCK_6S, un deadlock IPC, le blocage de la file d’attente des tâches, ou lorsque l’utilisateur demande une analyse de sysfreeze/processus bloqué.

Veuillez toujours répondre dans la langue de l’utilisateur.
