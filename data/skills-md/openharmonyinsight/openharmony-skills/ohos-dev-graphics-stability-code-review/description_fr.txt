Cadre d'examen de la stabilité du code C/C++, couvrant cinq catégories de stabilité (gestion des exceptions, stabilité de la concurrence, gestion des ressources, conditions limites, stabilité graphique) avec un total de 34 règles. Scénarios de déclenchement : analyses de stabilité à l’échelle du dépôt, inspection locale avant la validation du code dans le référentiel, audits de stabilité, revues de prévention des fautes, revues de code, analyses de stabilité OpenHarmony, et chaque fois que les utilisateurs demandent la vérification des risques de stabilité du code C/C++, cette capacité doit être utilisée.
