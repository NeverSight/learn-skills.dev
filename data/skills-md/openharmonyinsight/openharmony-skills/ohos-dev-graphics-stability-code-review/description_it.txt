Framework di revisione del codice di stabilità C/C++, che copre cinque categorie di stabilità (gestione delle eccezioni, stabilità della concorrenza, gestione delle risorse, condizioni di confine, stabilità della grafica) con un totale di 34 regole. Scenari di attivazione: scansioni dell’intero repository per progetti di stabilità, ispezioni locali prima della sottomissione del codice, audit di stabilità, ispezioni di prevenzione dei guasti, revisioni del codice, scansioni di stabilità OpenHarmony e, ogni volta che gli utenti richiedono di verificare i rischi di stabilità del codice C/C++, questa capacità dovrebbe essere utilizzata.
