Marco de revisión de código de estabilidad para C/C++, que cubre cinco categorías de estabilidad (manejo de excepciones, estabilidad de concurrencia, gestión de recursos, condiciones de límite, estabilidad gráfica) con un total de 34 reglas. Escenarios de activación: escaneos de todo el repositorio para proyectos de estabilidad, inspecciones locales antes de la entrega del código, auditorías de estabilidad, inspecciones de prevención de fallos, revisiones de código, escaneos de estabilidad de OpenHarmony, y siempre que los usuarios soliciten verificar los riesgos de estabilidad del código C/C++, se debe utilizar esta capacidad.
