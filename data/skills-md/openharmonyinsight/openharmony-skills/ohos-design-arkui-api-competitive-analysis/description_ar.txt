إجراء تحليل تنافسي قابل للتدقيق للقدرات والمواصفات لواجهة برمجة التطبيقات العامة لـ ArkUI مقارنةً بـ Android (Compose/View) و iOS (SwiftUI/UIKit). ينطبق ذلك على مراجعات تصميم الواجهة، سد فجوات القدرات، تقييمات ترحيل Android/iOS إلى ArkUI، قياس أداء API، وتحليل فجوات القدرات، مع تغطية إدخال اللمس/المؤشر، اختصارات لوحة المفاتيح، الإيماءات، المكونات، التخطيط، الحالة، والرسوم المتحركة. يجب تثبيت النطاق والإصدار، باستخدام `interface_sdk-js` كمصدر موثوق للواجهات العامة لـ ArkUI، مع إعطاء الأولوية للوثائق الرسمية لـ Android/iOS، وتمييز علاقات التكافؤ، وإنتاج تقرير يتضمن دليلًا مفصَّلاً، وتأثيرًا، وتوصيات ذات أولوية.
