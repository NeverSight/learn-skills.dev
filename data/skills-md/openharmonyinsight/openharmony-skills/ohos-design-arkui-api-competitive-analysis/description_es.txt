Realice un análisis competitivo auditado de capacidad y especificación de la API pública de UI de ArkUI frente a Android (Compose/View) e iOS (SwiftUI/UIKit). Esto es aplicable para revisiones de diseño de interfaces, eliminación de brechas de capacidad, evaluaciones de migración de Android/iOS a ArkUI, benchmarking de API y análisis de brechas, abarcando entrada táctil/puntero, atajos de teclado, gestos, componentes, diseño, estado y animación. El alcance y la versión deben quedar bloqueados, usando `interface_sdk-js` como fuente autorizada de las interfaces públicas de ArkUI, dando prioridad a la documentación oficial de Android/iOS, distinguiendo relaciones de equivalencia y generando un informe que incluya evidencia itemizada, impacto y recomendaciones priorizadas.
