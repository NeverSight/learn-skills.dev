Проведите аудиторно проверяемый конкурентный анализ возможностей и спецификаций публичного UI API ArkUI по сравнению с Android (Compose/View) и iOS (SwiftUI/UIKit). Это применимо к обзору дизайна интерфейса, завершению возможностей, оценке миграции Android/iOS и ArkUI, сравнительному тестированию API и анализу пробелов в возможностях, охватывая ввод касаний/указателя, клавиатурные сочетания, жесты, компоненты, макет, состояние и анимацию. Объём и версия должны быть зафиксированы, в качестве авторитетного источника публичных интерфейсов ArkUI использовать interface_sdk-js, отдавая приоритет ссылкам на официальную документацию Android/iOS, различая отношения эквивалентности и предоставляя отчёт с пунктуальными доказательствами, оценкой влияния и рекомендациями по приоритетам.
