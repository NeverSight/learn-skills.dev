ArkUI のパブリック UI API と Android（Compose/View）および iOS（SwiftUI/UIKit）を対象に、監査可能な機能および仕様の競合分析を実施してください。これはインターフェース設計レビュー、機能実装の確認、Android/iOS から ArkUI への移行評価、API ベンチマーク、機能ギャップ分析に適しています。対象はタッチ/ポインタ入力、キーボードショートカット、ジェスチャー、コンポーネント、レイアウト、ステート、アニメーションです。スコープとバージョンは固定し、ArkUI パブリックインターフェースの権威ある情報源として interface_sdk-js を使用し、Android/iOS 公式ドキュメントへの参照を優先し、等価関係を区別して、項目ごとのエビデンス、影響、優先度の推奨事項を含むレポートを提供してください。
