تشغيل عندما يطلب المستخدم "سير عمل Falcon Fusion مستقل" لا يحتاج إلى تطبيق Foundry — مجرد مشغل بالإضافة إلى الإجراءات الموجودة بالفعل في CID الخاص بهم، دون واجهة مستخدم أو وظيفة أو مجموعة أو تكامل API مخصص للبناء. لا تشغل عندما يتطلب الطلب بناء أي شيء (إجراء مخصص، صفحة واجهة مستخدم، وظيفة، مجموعة) — فهذا يعتبر تطبيق Foundry وتملك عملية التطوير ذلك. هذه المهارة موجودة بحيث يعمل التحويل دون روابط ويُحيل إلى المكوّن الإضافي الحقيقي Falcon Fusion عندما يتم تحميلهما معًا.
