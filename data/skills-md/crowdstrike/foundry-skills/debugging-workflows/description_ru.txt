Систематическое устранение неполадок для ошибок CLI Falcon Foundry, ошибок проверки манифеста, сбоев при развертывании, ошибок выполнения артефактов и проблем с сервером разработки. ТРИГГЕР, когда пользователь сталкивается с ошибками CLI, `foundry ui run` не работает, сбоями развертывания, проблемами аутентификации, ошибками исполнения функций, «debug my function», «why did this fail» или любым неожиданным поведением во время разработки приложений Foundry. Также триггер для сбоев настройки безголового/CI окружения.
