استكشاف الأخطاء المنهجي لأخطاء CLI في Falcon Foundry، فشل التحقق من صحة البيان، فشل النشر، أخطاء تشغيل الـartifact، ومشكلات خادم التطوير. يتم التفعيل عندما يواجه المستخدم أخطاء CLI، أو عدم عمل `foundry ui run`، أو فشل النشر، أو مشكلات المصادقة، أو فشل تنفيذ الدوال، أو عبارات مثل «debug my function» أو «why did this fail» أو أي سلوك غير متوقع أثناء تطوير تطبيقات Foundry. كما يتم التفعيل عند فشل إعداد بيئات Headless/CI. يرجى دائمًا الرد بلغة المستخدم.
