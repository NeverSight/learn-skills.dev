Risoluzione sistematica dei problemi per errori CLI di Falcon Foundry, fallimenti di validazione del manifesto, errori di distribuzione, errori di runtime degli artefatti e problemi del server di sviluppo. ATTIVA quando l'utente incontra errori CLI, `foundry ui run` non funziona, fallimenti di distribuzione, problemi di autenticazione, fallimenti di esecuzione delle funzioni, "debug my function", "why did this fail", o qualsiasi comportamento inatteso durante lo sviluppo dell'app Foundry. Attiva anche per fallimenti nella configurazione di ambienti headless/CI.
