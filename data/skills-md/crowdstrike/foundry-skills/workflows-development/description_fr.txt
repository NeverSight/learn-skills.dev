Créer et configurer le YAML de workflow Falcon Fusion SOAR pour les applications Falcon Foundry. DÉCLENCHER lorsque l'utilisateur demande de « créer un workflow », « créer une automatisation », « configurer Fusion SOAR », « ajouter un workflow à la demande », exécute `foundry workflows create`, ou a besoin d'aide avec la syntaxe YAML de Fusion, les déclencheurs, les actions ou les références de variables. NE PAS DÉCLENCHER pour les pages UI, les fonctions ou les schémas de collection — utilisez la sous‑compétence appropriée. Veuillez toujours répondre dans la langue de l'utilisateur.
