إنشاء وتكوين ملف YAML لتدفق عمل Falcon Fusion SOAR لتطبيقات Falcon Foundry. يُ Trigger عندما يطلب المستخدم «إنشاء تدفق عمل»، «بناء أتمتة»، «تكوين Fusion SOAR»، «إضافة تدفق عمل حسب الطلب»، ينفذ الأمر `foundry workflows create`، أو يحتاج مساعدة في ص syntax YAML الخاص بـ Fusion، المشغلات، الإجراءات أو مراجع المتغيرات. لا تُ Trigger للصفحات UI أو الدوال أو مخططات التجميع — استخدم المهارة الفرعية المناسبة.
