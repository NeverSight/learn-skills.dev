Откройте внешние API в Falcon Foundry с помощью спецификаций OpenAPI. ТРИГГЕР, когда пользователь просит «создать интеграцию API», «адаптировать спецификацию OpenAPI для Foundry», «разместить API в рабочих процессах», «подключиться к стороннему API» или выполняет `foundry api-integrations create`. Также триггер, когда у пользователя есть спецификация OpenAPI/Swagger и он хочет, чтобы она работала в Falcon Foundry. НЕ ТРИГГЕР, когда пользователь хочет вызвать API платформы Falcon из кода функции — используйте вместо этого functions-falcon-api.

Пожалуйста, всегда отвечайте на языке пользователя.
