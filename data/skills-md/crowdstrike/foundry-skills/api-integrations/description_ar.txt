تعرض واجهات برمجة التطبيقات الخارجية إلى Falcon Foundry عبر مواصفات OpenAPI. يتم التفعيل عندما يطلب المستخدم "إنشاء تكامل API"، "تكييف مواصفة OpenAPI لـ Foundry"، "تعرض API للعملية"، "الاتصال بواجهة برمجة تطبيقات طرف ثالث"، أو ينفذ `foundry api-integrations create`. كما يتم التفعيل عندما يكون لدى المستخدم مواصفة OpenAPI/Swagger ويريد تشغيلها في Falcon Foundry. لا يتم التفعيل عندما يرغب المستخدم في استدعاء واجهات برمجة تطبيقات منصة Falcon من رمز الدالة — استخدم functions-falcon-api بدلاً من ذلك.

يرجى الرد دائمًا بلغة المستخدم.
