Externe APIs über OpenAPI-Spezifikationen der Falcon Foundry zur Verfügung stellen. AUSLÖSEN, wenn der Benutzer nach "Erstellen einer API-Integration", "Anpassen einer OpenAPI-Spezifikation für Foundry", "Aussetzen einer API für Workflows", "Verbinden mit einer Drittanbieter-API" oder "Erstellen von Foundry-API-Integrationen" fragt. Wird auch ausgelöst, wenn der Benutzer eine OpenAPI/Swagger-Spezifikation hat und möchte, dass sie in der Falcon Foundry funktioniert. NICHT AUSLÖSEN, wenn der Benutzer die Falcon-Plattform-APIs aus dem Funktionscode aufrufen möchte — verwenden Sie stattdessen functions-falcon-api.
