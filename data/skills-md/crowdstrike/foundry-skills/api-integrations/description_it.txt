Esporre API esterne a Falcon Foundry tramite specifiche OpenAPI. ATTIVARE quando l'utente chiede di "creare un'integrazione API", "adattare una specifica OpenAPI per Foundry", "esporre un'API ai workflow", "connettersi a un'API di terze parti", o esegue `foundry api-integrations create`. Attivare anche quando l'utente ha una specifica OpenAPI/Swagger e desidera farla funzionare in Falcon Foundry. NON ATTIVARE quando l'utente vuole chiamare le API della piattaforma Falcon dal codice della funzione — usare invece functions-falcon-api. Per favore rispondi sempre nella lingua dell'utente.
