Exposer les API externes à Falcon Foundry via les spécifications OpenAPI. DÉCLENCHEUR lorsque l'utilisateur demande de « créer une intégration d'API », « adapter une spécification OpenAPI pour Foundry », « exposer une API à des flux de travail », « se connecter à une API tierce » ou exécute « Foundry api-integrations create ». Se déclenche également lorsque l'utilisateur dispose d'une spécification OpenAPI/Swagger et souhaite qu'elle fonctionne dans Falcon Foundry. NE PAS DÉCLENCHER lorsque l'utilisateur souhaite appeler les API de la plate-forme Falcon à partir du code de fonction — utilisez plutôt les fonctions-falcon-api.
