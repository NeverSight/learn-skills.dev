Exponga las API externas a Falcon Foundry a través de las especificaciones OpenAPI. se ACTIVA cuando el usuario solicita "crear una integración de API", "adaptar una especificación de OpenAPI para Foundry", "exponer una API a flujos de trabajo", "conectarse a una API de terceros" o ejecuta `foundry api-integrations create`. También se activa cuando el usuario tiene una especificación OpenAPI/Swagger y quiere que funcione en Falcon Foundry. NO SE ACTIVE CUANDO EL usuario quiera llamar a las API de la plataforma Falcon desde el código de función; use functions-falcon-api en su lugar.
