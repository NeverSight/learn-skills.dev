Appelez les API de la plate-forme CrowdStrike Falcon (détections, alertes, hôtes, RTR) à partir des gestionnaires de fonctions Foundry. DÉCLENCHEUR lorsque l'utilisateur demande « d'appeler les API Falcon à partir d'une fonction », « d'utiliser FalconPy dans une fonction », « d'utiliser gofalcon dans une fonction », ou doit intégrer les API de la plate-forme Falcon dans le code de la fonction sans serveur. NE PAS DÉCLENCHER lorsque l'utilisateur souhaite exposer des API tierces externes à Foundry — utilisez plutôt des intégrations API.
