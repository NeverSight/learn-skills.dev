Chiama le API della piattaforma CrowdStrike Falcon (rilevamenti, avvisi, host, RTR) dall'interno dei gestori di funzioni di Foundry. ATTIVA quando l'utente chiede di “chiamare le API Falcon da una funzione”, “usare FalconPy in una funzione”, “usare gofalcon in una funzione”, o ha bisogno di integrare le API della piattaforma Falcon nel codice di una funzione serverless. NON ATTIVARE quando l'utente vuole esporre API di terze parti esterne a Foundry — usa invece api-integrations. Rispondi sempre nella lingua dell'utente.
