Rufen Sie CrowdStrike Falcon-Plattform-APIs (Erkennungen, Warnungen, Hosts, RTR) über Foundry-Funktionshandler auf. AUSLÖSEN, wenn der Benutzer „Falcon-APIs aus einer Funktion aufrufen“, „FalconPy in einer Funktion verwenden“, „gofalcon in einer Funktion verwenden“ oder Falcon-Plattform-APIs in den serverlosen Funktionscode integrieren muss. NICHT AUSLÖSEN, wenn der Benutzer externe Drittanbieter-APIs Foundry zur Verfügung stellen möchte — verwenden Sie stattdessen API-Integrationen.
