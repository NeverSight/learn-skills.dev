Llame a las API de la plataforma CrowdStrike Falcon (detecciones, alertas, hosts, RTR) desde los controladores de funciones de Foundry. se ACTIVA cuando el usuario solicita "llamar a las API de Falcon desde una función", "usar FalconPy en una función", "usar gofalcon en una función" o necesita integrar las API de la plataforma Falcon dentro del código de función sin servidor. NO SE ACTIVE cuando el usuario quiera exponer API de terceros externos a Foundry; en su lugar, use integraciones de API.
