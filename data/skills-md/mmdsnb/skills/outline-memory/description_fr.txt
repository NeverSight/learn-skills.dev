La base de connaissances partagée à long terme entre agents (Outline) est la seule capacité autoritaire de lecture/écriture.  

**Écriture :** Lorsque l'utilisateur demande à « incorporer », « enregistrer », « se souvenir », « archiver », « résumer un post‑mortem », « écrire dans la base de connaissances », ou lorsqu'une tâche se termine avec des configurations/décisions vérifiées, ou que l'utilisateur corrige des faits obsolètes, proposez proactivement de consolider.  

**Lecture :** Lorsque l'utilisateur évoque des repères historiques tels que « la dernière fois », « avant », « précédemment », « pourquoi était‑ce ainsi », ou que la tâche implique des faits à long terme confirmés concernant le contexte du projet, l'environnement machine/réseau, les actifs externes, le domaine de connaissance, ou les préférences de règles personnelles, vous devez consulter d'abord l'Outline avant de répondre.  

Sauf pour les conventions d'ingénierie spécifiques au projet qui ne s'appliquent qu'à ce projet (écrire dans le fichier AGENTS.md à la racine du projet) et lorsque l'utilisateur désigne explicitement un fichier local particulier pour écrire, cette capacité prévaut sans condition sur MEMORY.md ou les règles du journal local. Les progrès temporaires, les propositions non vérifiées et les mots de passe/clé sont exclus.  

Veuillez toujours répondre dans la langue de l'utilisateur.
