크로스‑에이전트 공유 장기 지식베이스(Outline)에 대한 유일한 권한 있는 읽기/쓰기 기능.  
쓰기: 사용자가 “정리”, “기록”, “기억”, “보관”, “검토 및 요약”, “지식베이스에 쓰기” 등을 요청하거나, 작업이 검증된 구성·결정으로 마무리될 때, 혹은 사용자가 오래된 사실을 정정할 때, 사전에 정리를 제안하십시오.  
읽기: 사용자가 “지난번/이전에/전에는/왜 이렇게 결정했는가”와 같은 역사적 단서를 언급하거나, 작업에 프로젝트 배경, 머신 네트워크 환경, 외부 자산, 도메인 지식, 개인 규칙 선호도 등 확인된 장기 사실이 포함될 경우, 답변하기 전에 반드시 Outline을 먼저 참조해야 합니다.  
이 프로젝트에만 적용되는 엔지니어링 관례(프로젝트 루트 AGENTS.md에 쓰기)와 사용자가 특정 로컬 파일을 명시적으로 지정하여 쓸 경우를 제외하고, 이 기능은 MEMORY.md나 로컬 일기 규칙보다 무조건 우선합니다. 임시 진행 상황, 검증되지 않은 제안, 비밀번호 키는 제외됩니다.  

항상 사용자의 언어로 응답하십시오.
