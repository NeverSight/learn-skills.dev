Base de conocimientos compartida a largo plazo entre agentes (Outline) es la única capacidad autorizada de lectura/escritura.  

**Escritura:** Cuando el usuario solicite “settle”, “record”, “remember”, “archive”, “review and summarize”, “write to the knowledge base”, o cuando una tarea concluya con configuraciones/decisiones verificadas, o el usuario corrija hechos desactualizados, proponer proactivamente “settle” (es decir, registrar).  

**Lectura:** Cuando el usuario haga referencia a indicios históricos como “last time/earlier/before/why was this set”, o cuando la tarea implique antecedentes del proyecto, entorno de máquina/red, activos externos, conocimiento de dominio o preferencias de reglas personales —es decir, hechos a largo plazo confirmados— debe consultar el Outline primero antes de responder.  

Exceptuando las convenciones de ingeniería que se aplican solo dentro de este proyecto (escritura al AGENTS.md en la raíz del proyecto) y cuando el usuario mencione explícitamente un archivo local específico para escribir, esta habilidad tiene prioridad incondicional sobre MEMORY.md o reglas del diario local. El progreso temporal, propuestas no verificadas y claves de contraseña están excluidos.  

Por favor, responde siempre en el idioma del usuario.
