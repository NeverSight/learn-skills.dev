قاعدة المعرفة المشتركة طويلة الأمد بين الوكلاء (Outline) هي القدرة الوحيدة الموثوقة للقراءة والكتابة.  

**الكتابة:** عندما يطلب المستخدم “دمج”، “تسجيل”، “تذكر”، “أرشفة”، “تلخيص تقرير ما بعد الفشل”، “الكتابة إلى قاعدة المعرفة”، أو عندما تنتهي مهمة مع تكوينات/قرارات تم التحقق منها، أو يصحح المستخدم حقائق قديمة، اقترح بشكل استباقي دمجها.  

**القراءة:** عندما يذكر المستخدم إشارات تاريخية مثل “المرة الأخيرة / قبل / سابقاً / لماذا تم ضبطه بهذه الطريقة”، أو تتضمن المهمة حقائق طويلة الأمد مؤكدة عن خلفية المشروع، بيئة الآلة/الشبكة، الأصول الخارجية، معرفة المجال، أو تفضيلات القواعد الشخصية، يجب عليك استشارة Outline أولاً قبل الإجابة.  

باستثناء الاتفاقيات الهندسية الخاصة بالمشروع والتي تُطبق فقط داخل هذا المشروع (الكتابة إلى ملف AGENTS.md في جذر المشروع) وعندما يحدد المستخدم صراحةً ملفًا محليًا معينًا للكتابة، فإن هذه القدرة تتفوق دون شرط على MEMORY.md أو قواعد اليومية المحلية. يتم استثناؤها التقدم المؤقت، المقترحات غير المُتحقق منها، وكلمات المرور/المفاتيح.  

يرجى دائمًا الرد بلغة المستخدم.
