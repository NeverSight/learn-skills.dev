La base di conoscenza condivisa a lungo termine inter‑agente (Outline) è l'unica capacità autorevole di lettura/scrittura.  

**Scrivi:** Quando l'utente chiede di “incorporare”, “registrare”, “ricordare”, “archiviare”, “riassumere un post‑mortem”, “scrivere nella base di conoscenza”, o quando un compito si chiude con configurazioni/decisioni verificate, o l'utente corregge fatti obsoleti, proponi proattivamente di consolidare.  

**Leggi:** Quando l'utente menziona indizi storici come “l'ultima volta / prima / precedentemente / perché è stato impostato in quel modo”, o il compito riguarda fatti a lungo termine confermati sul contesto del progetto, l'ambiente macchina/rete, le risorse esterne, la conoscenza di dominio, o le preferenze di regole personali, devi consultare prima l'Outline prima di rispondere.  

Fatta eccezione per le convenzioni ingegneristiche specifiche del progetto che si applicano solo all'interno di questo progetto (scrivi nel file AGENTS.md nella radice del progetto) e quando l'utente indica esplicitamente un file locale specifico per la scrittura, questa capacità prevale incondizionatamente su MEMORY.md o le regole del diario locale. I progressi temporanei, le proposte non verificate e le password/chiavi sono esclusi.  

Per favore, rispondi sempre nella lingua dell'utente.
