كود نظيف. طبق قواعد مارتن للتسمية والوظائف والتعليقات والأخطاء والاختبارات والرائحة على كل تعديل. استخدمها عند كتابة أو تحرير أو مراجعة أو إعادة هيكلة أي ملف مصدر، أو عندما يذكر المستخدم التسمية أو الدوال أو التعليقات أو التكرار أو كشاف الفتيان أو الروائح أو الكود النظيف. يرجى دائمًا الرد بلغة المستخدم.
