Azure Synapse Analytics の開発に関する専門知識（トラブルシューティング、ベストプラクティス、意思決定、アーキテクチャとデザインパターン、制限とクォータ、セキュリティ、構成、統合とコーディングパターン、デプロイメントを含む）。Synapse ワークスペース、SQL/専用プール、サーバーレス SQL、Spark プール、または Cosmos DB 用の Synapse Link、その他 Azure Synapse Analytics 関連の開発タスクを設計する際に使用してください。Azure Data Factory 用ではありません（azure-data-factory を使用）、Azure Data Explorer 用でもありません（azure-data-explorer を使用）、Azure Databricks 用でもありません（azure-databricks を使用）、Azure HDInsight 用でもありません（azure-hdinsight を使用）。
