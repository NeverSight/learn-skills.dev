معرفة خبيرة لتطوير Azure Synapse Analytics تشمل استكشاف الأخطاء وإصلاحها، أفضل الممارسات، اتخاذ القرار، الأنماط المعمارية وتصميم الأنظمة، الحدود والحصص، الأمن، التكوين، التكاملات وأنماط الترميز، والنشر. يُستخدم عند تصميم مساحات عمل Synapse، مجموعات SQL/المخصصة، SQL بدون خادم، مجموعات Spark، أو Synapse Link لقاعدة Cosmos DB، وغيرها من مهام التطوير المتعلقة بـ Azure Synapse Analytics. غير مخصص لـ Azure Data Factory (استخدم azure-data-factory)، Azure Data Explorer (استخدم azure-data-explorer)، Azure Databricks (استخدم azure-databricks)، Azure HDInsight (استخدم azure-hdinsight).  

يرجى دائمًا الرد بلغة المستخدم.
