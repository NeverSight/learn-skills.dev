Revisa un cambio de código con tres revisores independientes (bugs, los estándares escritos del repositorio, la especificación de origen), intenta refutar cada hallazgo y solo informa lo que se mantiene. Aplica las correcciones elegidas al propio cambio del usuario; para los de otros, escribe sugerencias y puede publicarlas como comentarios en el PR. Úsalo cuando el usuario solicite revisar, comprobar o echar un segundo vistazo a un cambio: "review my changes", "review PR 285" o "!482", "review against DESIGN.md", "is this ready?", review‑changes por nombre, o hallazgos de revisión pegados para manejar. No es para auditorías de todo el repositorio, descripciones de PR, explicar un diff, o cuando el usuario menciona otra herramienta de revisión.
