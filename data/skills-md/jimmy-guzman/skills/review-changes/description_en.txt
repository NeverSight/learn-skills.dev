Reviews a code change with three independent reviewers (bugs, the repo's written standards, the spec it came from), tries to disprove each finding, and reports only what holds. Applies chosen fixes to the user's own change; for anyone else's, writes suggestions and can post them as PR comments. Use when the user asks to review, check, or take a second look at a change: "review my changes", "review PR 285" or "!482", "review against DESIGN.md", "is this ready?", review-changes by name, or pasted review findings to handle. Not for whole-repo audits, PR descriptions, explaining a diff, or when the user names another review tool.
