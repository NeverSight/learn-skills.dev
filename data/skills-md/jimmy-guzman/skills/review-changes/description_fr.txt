Examine un changement de code avec trois réviseurs indépendants (bugs, les normes écrites du dépôt, la spécification d’origine), tente de réfuter chaque constat et ne rapporte que ce qui tient. Applique les corrections choisies au changement de l’utilisateur ; pour celui d’un autre, écrit des suggestions et peut les publier en commentaires de PR. À utiliser lorsque l’utilisateur demande de revoir, vérifier ou jeter un deuxième œil sur un changement : « review my changes », « review PR 285 » ou « !482 », « review against DESIGN.md », « is this ready? », review‑changes par nom, ou constats de révision collés à traiter. Pas pour les audits complets du dépôt, les descriptions de PR, l’explication d’un diff, ou lorsque l’utilisateur cite un autre outil de révision.
