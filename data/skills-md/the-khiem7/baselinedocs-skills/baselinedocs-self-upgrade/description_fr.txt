Mettez à jour les compétences baselinedocs installées elles‑mêmes, jamais un pack, vers la dernière version GitHub sur chaque agent de cette machine (Claude, Codex, Gemini, Kiro, Kilo, Crush et autres). Trouve le dernier tag de version, localise chaque compétence baselinedocs installée, compare les versions semver, indique quels agents sont obsolètes et, après confirmation, les met à jour. Utilisez‑le explicitement lorsque l'utilisateur demande de mettre à jour, d'upgrader ou de rafraîchir baselinedocs, interroge sur l'existence d'une version plus récente, ou suspecte que les compétences installées sont obsolètes. Pour synchroniser les documents d'un pack avec le code, utilisez `baselinedocs-sync-codebase` à la place.

Veuillez toujours répondre dans la langue de l'utilisateur.
