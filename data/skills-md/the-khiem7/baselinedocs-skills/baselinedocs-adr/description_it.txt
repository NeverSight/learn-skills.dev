Stila un Architectural Decision Record nel formato AWS Prescriptive Guidance a partire da una decisione chiusa presente nel documento di allucinazione di un baseline pack, redatto come file autonomo nella cartella docs/adr/. Utilizza esplicitamente quando l'utente desidera trasformare una decisione chiusa di un doc pack in un ADR per il repository o per la promozione a un repository di produzione.
