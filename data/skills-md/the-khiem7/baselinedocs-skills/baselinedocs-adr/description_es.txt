Redacta un Registro de Decisión Arquitectónica en el formato de AWS Prescriptive Guidance a partir de una decisión cerrada en el documento de alucinación de un paquete base, escrito como un archivo independiente bajo `docs/adr/`. Utilízalo explícitamente cuando el usuario quiera una decisión cerrada de un paquete de documentación convertida en un ADR para el repositorio o para su promoción a un repositorio de producción.

Por favor, responde siempre en el idioma del usuario.
