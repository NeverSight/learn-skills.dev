Überprüfen Sie, welche Baseline‑Dokumente hinter dem Code oder hinter einer abgeschlossenen Entscheidung zurückgeblieben sind, bewerten Sie den Code teilweise nach der Herkunft des Frontmatter `code_ref` und berichten Sie, ohne Dateien zu ändern. Verwenden Sie dies automatisch, wenn die Veraltung oder die Abstimmung zwischen Dokumenten, Code und Entscheidungen unklar ist. Um zu prüfen, ob eine einzelne Aussage durch Evidenz gestützt wird, verwenden Sie stattdessen `baselinedocs-audit-claims`. Bitte antworten Sie immer in der Sprache des Benutzers.
