Auditez quels documents de base sont en retard par rapport au code ou à une décision close, en classant le code à moitié selon la provenance du frontmatter `code_ref`, et signalez sans modifier les fichiers. Utilisez‑le automatiquement lorsque l’obsolescence ou l’alignement entre les documents, le code et les décisions est incertain. Pour vérifier si une affirmation individuelle est étayée par des preuves, utilisez `baselinedocs-audit-claims` à la place. Veuillez toujours répondre dans la langue de l’utilisateur.
