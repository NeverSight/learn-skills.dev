ارسم مخطط نشر AWS تفاعلي صفحة واحدة - أيقونات بنية AWS الرسمية على ورقة رسم بيضاء، صناديق حساب / منطقة / VPC / شبكة فرعية / مجموعة متداخلة، تدفقات مرقمة ملونة يبرزها صف شريحة وتتحرك الجدول الزمني سهمًا بعد سهم، وبطاقة تشرح كل مكون عند النقر. استخدمه عندما يطلب المستخدم مخطط بنية AWS، أو صفحة لمحة عامة عن نشر AWS، أو صورة لكيفية تشغيل نظام على AWS، أو يرغب في تعديل صفحة مخطط AWS موجودة. ينتج ملف HTML من مواصفات JSON عبر مُرمّز بايثون في المكتبة القياسية؛ ليس للأشواط العامة، أو السحب غير AWS، أو مخططات البيانات.
