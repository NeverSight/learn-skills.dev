Dibuja un diagrama de implementación de AWS de una sola página interactiva, usando los íconos oficiales de Arquitectura de AWS en una hoja de dibujo blanca, con cajas anidadas de cuenta / región / VPC / subred / clúster, flujos numerados y codificados por colores que una fila de chips resalta y una línea de tiempo recorre flecha por flecha, y una tarjeta que explica cada componente al hacer clic. Utilízalo cuando el usuario solicite un diagrama de arquitectura de AWS, una página de visión general de implementación de AWS, una imagen de cómo funciona un sistema en AWS, o quiera modificar una página de diagrama de AWS existente. Genera un archivo HTML a partir de una especificación JSON mediante un renderizador Python de la biblioteca estándar; no es para diagramas de flujo genéricos, nubes que no sean AWS o gráficos de datos.
