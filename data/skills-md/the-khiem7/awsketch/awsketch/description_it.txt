Disegna un diagramma di distribuzione AWS interattivo a pagina singola – icone ufficiali di AWS Architecture su un foglio bianco, riquadri annidati di account / regione / VPC / subnet / cluster, flussi numerati e colorati che una riga di chip evidenzia e una timeline che avanza freccia per freccia, e una scheda che spiega ogni componente al clic. Usalo quando l'utente richiede un diagramma di architettura AWS, una pagina di panoramica della distribuzione AWS, un'immagine di come un sistema funziona su AWS, o desidera modificare una pagina di diagramma AWS esistente. Produce un file HTML da una specifica JSON attraverso un renderer Python della libreria standard; non è destinato a diagrammi di flusso generici, cloud non AWS o grafici di dati.

Rispondi sempre nella lingua dell'utente.
