Используйте, когда необходимо установить встроенные команды проекта в каталоги команд (.github/commands, .claude/commands, .cursor/command, .codex/commands), выбирая место назначения интерактивно и копируя определения встроенных команд из ресурсов проекта. Это должно срабатывать для запросов, таких как Установить встроенные команды; Bootstrap .cursor/command; Bootstrap .claude/commands; Копировать команды проекта; Установить набор команд проекта.
