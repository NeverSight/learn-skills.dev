À utiliser lorsque vous devez installer les commandes de projet intégrées dans des répertoires de commandes (.github/commandes, .claude/commandes, .cursor/commande, .codex/commandes), en sélectionnant la destination de manière interactive et en copiant les définitions des commandes intégrées à partir des ressources du projet. Cela devrait déclencher des requêtes telles que Installer les commandes intégrées ; Bootstrap .cursor/commande ; Bootstrap .claude/commandes ; Copier les commandes du projet ; Installer la suite de commandes du projet.
