Usa cuando necesites escribir pruebas unitarias para aplicaciones Micronaut — Mockito primero con @ExtendWith(MockitoExtension.class), @MicronautTest con @MockBean, aserciones HttpClient @Client(/), sobrescrituras @Property, @ParameterizedTest y nomenclatura *Test vs *IT. Para Java agnóstico al framework usa @131-java-testing-unit-testing. Esto debería activarse para solicitudes como Añadir o mejorar pruebas unitarias en un proyecto Micronaut; Reducir el uso innecesario de @MicronautTest con pruebas Mockito primero; Escribir pruebas unitarias Mockito primero para servicios Micronaut; Mockear colaboradores de beans Micronaut en pruebas unitarias; Revisar pruebas rápidas de Micronaut sin contexto de aplicación.
