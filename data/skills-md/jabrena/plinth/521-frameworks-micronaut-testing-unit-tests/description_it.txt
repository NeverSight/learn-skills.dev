Usa quando hai bisogno di scrivere test unitari per applicazioni Micronaut — prima Mockito con @ExtendWith(MockitoExtension.class), @MicronautTest con @MockBean, asserzioni HttpClient @Client(/), sovrascritture @Property, @ParameterizedTest e denominazione *Test vs *IT. Per Java indipendente dal framework utilizza @131-java-testing-unit-testing. Questo dovrebbe attivarsi per richieste come aggiungere o migliorare i test unitari in un progetto Micronaut; ridurre l'uso non necessario di @MicronautTest con test prima di Mockito; scrivere test unitari prima di Mockito per i servizi Micronaut; mockare i bean collaboratori di Micronaut nei test unitari; revisionare test Micronaut rapidi senza contesto dell'applicazione.
