Micronaut アプリケーションのユニットテストを書く必要があるときに使用します — @ExtendWith(MockitoExtension.class) を使用した Mockito ファースト、@MockBean と組み合わせた @MicronautTest、HttpClient @Client(/) のアサーション、@Property のオーバーライド、@ParameterizedTest、*Test と *IT の命名規則など。フレームワークに依存しない Java では @131-java-testing-unit-testing を使用します。これにより、Micronaut プロジェクトでユニットテストを追加または改善する、Mockito ファーストテストで不要な @MicronautTest の使用を減らす、Micronaut サービス向けに Mockito ファーストユニットテストを書く、ユニットテストで Micronaut ビーンのコラボレータをモックする、アプリケーションコンテキストなしで高速な Micronaut テストをレビューする、というリクエストがトリガーされます。Plinth Toolkit の一部です
