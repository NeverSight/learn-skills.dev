Используйте, когда нужно писать модульные тесты для приложений Micronaut — подход Mockito‑first с @ExtendWith(MockitoExtension.class), @MicronautTest с @MockBean, проверки HttpClient @Client(/), переопределения @Property, @ParameterizedTest и различие в именовании *Test vs *IT. Для независимых от фреймворка Java используйте @131-java-testing-unit-testing. Это должно срабатывать для запросов, таких как «Добавить» или «улучшить модульные тесты в проекте Micronaut»; «Сократить избыточное использование @MicronautTest с тестами Mockito‑first»; «Писать модульные тесты Mockito‑first для сервисов Micronaut»; «Мокировать коллаборации bean‑ов Micronaut в модульных тестах»; «Просматривать быстрые тесты Micronaut без контекста приложения».
