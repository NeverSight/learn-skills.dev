Utilisez lorsque vous devez écrire des tests unitaires pour des applications Micronaut — Mockito en priorité avec @ExtendWith(MockitoExtension.class), @MicronautTest avec @MockBean, assertions HttpClient @Client(/), remplacements @Property, @ParameterizedTest, et la nomenclature *Test vs *IT. Pour du Java indépendant du cadre, utilisez @131-java-testing-unit-testing. Cela doit se déclencher pour des requêtes telles que Ajouter ou améliorer les tests unitaires dans un projet Micronaut ; Réduire l’utilisation inutile de @MicronautTest avec des tests Mockito en priorité ; Écrire des tests unitaires Mockito en priorité pour les services Micronaut ; Mock les collaborateurs de beans Micronaut dans les tests unitaires ; Examiner des tests Micronaut rapides sans contexte d’application. Partie du Plinth Toolkit.
