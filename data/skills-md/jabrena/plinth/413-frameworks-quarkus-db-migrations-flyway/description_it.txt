Usa quando devi aggiungere o revisionare le migrazioni di database Flyway in un’applicazione Quarkus — estensione quarkus-flyway, script db/migration, configurazione quarkus.flyway.*, migrate-at-start e allineamento con JDBC o Panache. Questo dovrebbe attivarsi per richieste come aggiungere o revisionare migrazioni Flyway in un progetto Quarkus; configurare il layout quarkus-flyway o db/migration; aggiungere migrazioni SQL Flyway versionate per Quarkus; revisionare l’ordine delle migrazioni del database Quarkus; configurare Flyway clean migrate o baseline in Quarkus. Parte del Plinth Toolkit.
