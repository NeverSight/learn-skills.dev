Utilisez‑le lorsque vous devez ajouter ou examiner les migrations de base de données Flyway dans une application Quarkus — extension quarkus‑flyway, scripts db/migration, configuration quarkus.flyway.*, migrate‑at‑start et alignement avec JDBC ou Panache. Cela doit se déclencher pour des requêtes telles que : ajouter ou examiner des migrations Flyway dans un projet Quarkus ; configurer la disposition quarkus‑flyway ou db/migration ; ajouter des migrations SQL Flyway versionnées pour Quarkus ; examiner l’ordre des migrations de base de données Quarkus ; configurer le nettoyage, la migration ou les repères Flyway dans Quarkus.
