Utilízalo cuando necesites agregar o revisar migraciones de bases de datos Flyway en una aplicación Quarkus — extensión quarkus‑flyway, scripts db/migration, configuración quarkus.flyway.*, migrate‑at‑start y alineación con JDBC o Panache. Esto debe activarse para solicitudes como agregar o revisar migraciones Flyway en un proyecto Quarkus; configurar quarkus‑flyway o la estructura db/migration; añadir migraciones SQL versionadas de Flyway para Quarkus; revisar el orden de migraciones de base de datos en Quarkus; configurar Flyway clean, migrate o baselines en Quarkus.
