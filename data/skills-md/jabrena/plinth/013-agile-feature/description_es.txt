Guía la creación de documentación detallada de funciones ágiles a partir de un épico existente. Úsela cuando el usuario quiera dividir un épico en archivos de funciones, derivar funciones con alcance y criterios de aceptación, o planificar la documentación de funciones para interesados o ingeniería. Esto debe activarse para solicitudes como Crear funciones a partir de un épico; Dividir épico en funciones; Archivos de funciones a partir de un épico; Derivar funciones de un épico; Desglosar un épico ágil en funciones entregables. Parte del Toolkit Plinth. Por favor, responda siempre en el idioma del usuario.
