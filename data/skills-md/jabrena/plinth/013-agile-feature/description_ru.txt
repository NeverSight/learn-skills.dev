Помогает создать подробную документацию по agile‑фичам на основе существующего эпика. Используется, когда пользователь хочет разбить эпик на файлы фич, вывести фичи с их областью охвата и критериями приёма, либо спланировать документацию фич для стейкхолдеров или инженерного отдела. Это должно срабатывать на запросы типа: Создать фичи из эпика; Разбить эпик на фичи; Файлы фич из эпика; Вывести фичи из эпика; Разбить agile‑эпик на реализуемые фичи. Часть набора инструментов Plinth Toolkit
