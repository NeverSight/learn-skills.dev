Utilisez‑le lorsque vous devez générer des diagrammes de projet Java — y compris les diagrammes de séquence UML, les diagrammes de classe UML, les diagrammes du modèle C4, les diagrammes d’état UML, les diagrammes de déploiement UML, les diagrammes ER (Entity Relationship) et les diagrammes de contexte limité — à travers un processus interactif modulaire, basé sur des étapes, qui s’adapte à vos besoins de visualisation spécifiques. Cela doit s’activer pour des demandes telles que : Générer un diagramme UML ; Créer un diagramme de séquence ; Créer un diagramme de classe ; Créer un diagramme d’état ; Créer un diagramme de déploiement ; Créer un diagramme C4 ; Créer un diagramme de contexte limité ; Créer un diagramme de carte de contexte. Fait partie de la boîte à outils Plinth. Veuillez toujours répondre dans la langue de l’utilisateur.
