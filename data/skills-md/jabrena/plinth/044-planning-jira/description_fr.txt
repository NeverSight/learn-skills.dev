Utilisez-le lorsque vous avez besoin d’aide pour l’installation/l’authentification du CLI Jira (`jira`) et d’un flux de travail d’inventaire des tickets Jira rédigé par le mainteneur. L’agent n’ingère pas directement les tickets Jira bruts ni la sortie JQL ; il demande au mainteneur/opérateur du projet Jira de rédiger des résumés de tickets nettoyés avant l’analyse ou le transfert vers @014-agile-user-story. Cela doit se déclencher pour des demandes telles que : jira issue list ; List Jira issues ; Jira JQL issue query ; Jira CLI issue workflow. Fait partie de Plinth Toolkit. Veuillez toujours répondre dans la langue de l’utilisateur.
