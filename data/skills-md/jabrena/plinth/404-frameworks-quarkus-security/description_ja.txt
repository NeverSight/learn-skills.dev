Quarkus アプリケーションのセキュリティを設計、レビュー、または改善する必要がある場合に使用します — JWT/OIDC を使用した Quarkus Security、ベーシック認証、@RolesAllowed / @Authenticated / @PermitAll、SecurityIdentity、権限チェック、設定でのパスベースの認可、認証失敗時の例外マッピング、機密データ安全なロギングなどを含みます。これらは「Quarkus のセキュリティサポートを追加」「Quarkus のセキュリティ設定をレビュー」「Quarkus の API 認可を改善」「Quarkus に JWT/OIDC セキュリティを追加」「Quarkus の認可ルールを強化」などのリクエストに対してトリガーされるべきです。Plinth Toolkit の一部です。
