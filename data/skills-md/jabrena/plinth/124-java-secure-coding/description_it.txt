Usa quando è necessario applicare le migliori pratiche di sicurezza nella programmazione Java — includendo la validazione di input non attendibili, la difesa contro attacchi di injection con query parametrizzate, la riduzione della superficie di attacco tramite il principio del minimo privilegio, l'applicazione di algoritmi crittografici robusti, la gestione sicura delle eccezioni senza esporre dati sensibili, la gestione dei segreti a runtime, l'evitare la deserializzazione non sicura e la codifica dell'output per prevenire XSS. Questo dovrebbe attivarsi per richieste come Revisionare il codice Java per la sicurezza; Individuare rischi di validazione degli input nel codice Java; Revisionare il codice Java per vulnerabilità di injection; Migliorare la gestione sicura degli errori nei servizi Java; Rinforzare il codice Java contro le comuni falle di sicurezza.
