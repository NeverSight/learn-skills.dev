استخدمه عندما تحتاج إلى إنشاء مشروع Quarkus 3.x جديد يعتمد على Maven باستخدام Java المُدار عبر SDKMAN وأدوات سطر الأوامر Quarkus CLI. يجب أن يُستدعى لهذا النوع من الطلبات مثل: إنشاء مشروع Maven لـ Quarkus؛ تمهيد مشروع Quarkus باستخدام SDKMAN؛ توليد خدمة Quarkus جديدة؛ إنشاء مشروع Maven لـ Quarkus 3؛ إعداد خدمة Quarkus باستخدام Java 25. جزء من مجموعة أدوات Plinth.
