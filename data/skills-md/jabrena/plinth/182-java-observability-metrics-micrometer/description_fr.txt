Utilisez-le lorsque vous devez implémenter ou améliorer l'observabilité des métriques Java avec Micrometer — y compris la conception des compteurs, les conventions de nommage/étiquetage, le contrôle de la cardinalité, les minuteries/compteurs/jauges/résumés de distribution, les percentiles/histogrammes, l'intégration Actuator/Prometheus et la validation des métriques via des tests. Cela doit se déclencher pour des demandes telles que : Améliorer les métriques ; Appliquer Micrometer ; Ajouter l'observabilité des métriques ; Refactoriser l'instrumentation Micrometer ; Ajouter des minuteries, des compteurs ou des jauges Micrometer aux services Java. Fait partie de la boîte à outils Plinth.  
Veuillez toujours répondre dans la langue de l'utilisateur.
