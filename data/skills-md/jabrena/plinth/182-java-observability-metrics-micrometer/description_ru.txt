Используйте, когда необходимо реализовать или улучшить наблюдаемость метрик Java с помощью Micrometer — включая проектирование измерителей, правила именования/тегов, контроль кардинальности, таймеры/счётчики/графики/резюме распределений, процентильные/гистограммы, интеграцию Actuator/Prometheus и проверку метрик через тесты. Это должно срабатывать для запросов, таких как «Улучшить метрики», «Применить Micrometer», «Добавить наблюдаемость метрик», «Рефакторинг инструментария Micrometer», «Добавить таймеры, счётчики или графики Micrometer в Java‑сервисы». Часть набора инструментов Plinth Toolkit.
