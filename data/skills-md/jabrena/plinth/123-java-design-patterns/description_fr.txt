Utilisez-le lorsque vous devez sélectionner, examiner ou mettre en œuvre des modèles de conception et d'intégration Java — y compris les modèles de conception Java classiques, les modèles d’API REST, les modèles Kafka et orientés événement, les modèles de base de données et de persistance, ainsi que les modèles d’intégration transversaux. Cela doit être déclenché pour des demandes telles que : appliquer les modèles de conception Java ; examiner les modèles d’API REST ; concevoir des modèles d’événements Kafka ; améliorer les modèles de persistance de bases de données ; ajouter des modèles d’intégration résilients. Fait partie du Plinth Toolkit.
