Use cuando necesite acceso a datos con Quarkus Hibernate ORM Panache — incluyendo PanacheEntity / PanacheEntityBase, PanacheRepository, consultas nombradas, JPQL, SQL nativo, proyecciones DTO (project(Class)), paginación (Page.of()), evitación de N+1 (JOIN FETCH), bloqueo optimista (@Version / OptimisticLockException), @NamedQuery para consultas reutilizables validadas, transacciones, @TestTransaction para aislamiento de pruebas y patrones compatibles con la inmutabilidad. Esto es el análogo de Quarkus a Spring Data para persistencia relacional.
