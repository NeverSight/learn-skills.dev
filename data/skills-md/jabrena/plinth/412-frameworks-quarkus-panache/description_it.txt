Usa quando hai bisogno di accesso ai dati con Quarkus Hibernate ORM Panache — includendo PanacheEntity / PanacheEntityBase, PanacheRepository, query nominate, JPQL, SQL nativo, proiezioni DTO (project(Class)), paginazione (Page.of()), evitamento del problema N+1 (JOIN FETCH), locking ottimistico (@Version / OptimisticLockException), @NamedQuery per query riutilizzabili validate, transazioni, @TestTransaction per l’isolamento dei test e pattern amichevoli dell’immutabilità. Questo è l’analogo di Quarkus a Spring Data per la persistenza relazionale. Dovrebbe attivarsi per richieste come: revisionare le entità o i repository Panache in Quarkus; migliorare l’accesso ai dati di Hibernate ORM con Panache; aggiungere proiezioni DTO, JOIN FETCH, paginazione o locking ottimistico alle query Panache; risolvere i problemi di query N+1 o aggiungere il controllo di concorrenza @Version in Quarkus Panache; migliorare il design attivo record vs repository di Panache.
