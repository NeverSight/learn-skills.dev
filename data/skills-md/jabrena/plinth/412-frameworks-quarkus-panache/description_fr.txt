Utilisez-le lorsque vous avez besoin d'accès aux données avec Quarkus Hibernate ORM Panache — y compris PanacheEntity / PanacheEntityBase, PanacheRepository, les requêtes nommées, JPQL, SQL natif, les projections DTO (project(Class)), la pagination (Page.of()), l’évitement du N+1 (JOIN FETCH), le verrouillage optimiste (@Version / OptimisticLockException), @NamedQuery pour des requêtes réutilisables validées, les transactions, @TestTransaction pour l’isolation des tests, et les modèles favorisant l’immutabilité. C’est l’équivalent Quarkus de Spring Data pour la persistance relationnelle. Cela doit se déclencher pour des demandes telles que : examiner les entités ou les dépôts Panache dans Quarkus ; améliorer l’accès aux données Hibernate ORM avec Panache ; ajouter des projections DTO, JOIN FETCH, la pagination ou le verrouillage optimiste aux requêtes Panache ; corriger les problèmes de requêtes N+1 ou ajouter le contrôle de concurrence @Version dans Quarkus Panache ; améliorer la conception entre le modèle actif Panache et le dépôt. Fait partie du Plinth Toolkit.
