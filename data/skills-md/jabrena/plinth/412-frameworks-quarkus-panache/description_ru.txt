Используйте, когда требуется доступ к данным с помощью Quarkus Hibernate ORM Panache — включая PanacheEntity / PanacheEntityBase, PanacheRepository, именованные запросы, JPQL, нативный SQL, проекции DTO (project(Class)), пагинацию (Page.of()), устранение проблемы N+1 (JOIN FETCH), оптимистичную блокировку (@Version / OptimisticLockException), @NamedQuery для проверенных переиспользуемых запросов, транзакции, @TestTransaction для изоляции тестов и паттерны, дружелюбные к неизменяемым объектам. Это аналог Spring Data в Quarkus для реляционного постоянства. Должно срабатывать для запросов типа: обзор сущностей или репозиториев Panache в Quarkus; улучшение доступа к данным Hibernate ORM с Panache; добавление проекций DTO, JOIN FETCH, пагинации или оптимистичной блокировки в запросы Panache; исправление проблем N+1‑запросов или добавление контроля конкурентности через @Version в Quarkus Panache; улучшение дизайна активной записи против репозитория Panache. Часть набора инструментов Plinth Toolkit.
