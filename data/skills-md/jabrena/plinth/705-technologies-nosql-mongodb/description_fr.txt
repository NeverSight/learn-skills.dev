Utilisez‑le lorsque vous avez besoin de conseils indépendants de tout framework sur MongoDB et les bases de données non relationnelles — conception de schémas de documents, modélisation de collections, validation JSON Schema, index, pipelines d’agrégation, performance des requêtes, compromis de cohérence, transactions et sécurité opérationnelle — sans choisir Spring Boot, Quarkus ou Micronaut. Cela doit se déclencher pour des demandes telles que : concevoir des schémas de documents MongoDB ; examiner les requêtes et les index MongoDB ; améliorer les performances des pipelines d’agrégation ; modéliser les modèles d’accès aux données non relationnelles ; examiner les compromis de cohérence et de transaction NoSQL. Fait partie du Plinth Toolkit.
