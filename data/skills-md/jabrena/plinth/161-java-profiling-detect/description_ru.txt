Используйте, когда необходимо настроить профилирование Java‑приложения для обнаружения и измерения проблем производительности — включая надёжную предустановленную настройку async‑profiler v4.x, профилирование, ориентированное на задачу (CPU, память, потоки, GC, ввод/вывод), интерактивные скрипты профилирования, интеграцию JFR с Java 25 (JEP 518, JEP 520) или сбор данных профилирования с помощью flamegraph‑ов и записей JFR. Это должно срабатывать для запросов, таких как «Улучшить код с профилированием», «Применить профилирование», «Рефакторить код с профилированием», «Добавить поддержку профилирования», «Собрать данные JFR или async‑profiler для производительности Java».
