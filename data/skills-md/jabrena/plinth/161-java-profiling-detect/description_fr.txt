Utilisez‑le lorsque vous devez configurer le profilage d’une application Java afin de détecter et mesurer les problèmes de performance — y compris la configuration fiable d’async‑profiler v4.x préinstallé, le profilage orienté problème (CPU, mémoire, threading, GC, I/O), des scripts de profilage interactifs, l’intégration de JFR avec Java 25 (JEP 518, JEP 520), ou la collecte de données de profilage avec des flamegraphs et des enregistrements JFR. Cela doit se déclencher pour des demandes telles que : améliorer le code avec du profilage ; appliquer le profilage ; refactoriser le code avec du profilage ; ajouter le support du profilage ; collecter des données JFR ou async‑profiler pour la performance Java. Partie du Plinth Toolkit.
