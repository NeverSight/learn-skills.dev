استخدمه عندما تحتاج إلى إعداد تتبع أداء تطبيق Java لاكتشاف وقياس مشاكل الأداء — بما في ذلك إعداد async‑profiler v4.x الموثوق والمثبت مسبقًا، تتبع موجه بالمشكلة (CPU، الذاكرة، الخيوط، GC، I/O)، سكريبتات تتبع تفاعلية، دمج JFR مع Java 25 (JEP 518، JEP 520)، أو جمع بيانات التتبع باستخدام مخططات الشعلات وتسجيلات JFR. يجب أن يتم تحفيزه للطلبات مثل تحسين الكود باستخدام التتبع؛ تطبيق التتبع؛ إعادة هيكلة الكود باستخدام التتبع؛ إضافة دعم التتبع؛ جمع بيانات JFR أو async‑profiler لأداء Java. جزء من مجموعة أدوات Plinth.
