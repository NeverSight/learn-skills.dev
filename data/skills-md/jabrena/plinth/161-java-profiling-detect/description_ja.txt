Java アプリケーションのプロファイリングを設定してパフォーマンス問題を検出・測定する必要があるときに使用します — 信頼できるプリインストール済み async-profiler v4.x のセットアップ、問題主導型プロファイリング（CPU、メモリ、スレッド、GC、I/O）、インタラクティブなプロファイリングスクリプト、Java 25（JEP 518、JEP 520）との JFR 統合、またはフレームグラフや JFR 録画によるプロファイルデータの収集を含みます。これらは「プロファイリングでコードを改善する」「プロファイリングを適用する」「プロファイリングでコードをリファクタリングする」「プロファイリングサポートを追加する」「Java のパフォーマンスのために JFR または async-profiler データを収集する」等のリクエストに対してトリガーされるべきです。Plinth Toolkit の一部です。
