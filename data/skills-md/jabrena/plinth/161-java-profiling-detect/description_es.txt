Úsese cuando necesite configurar el perfilado de aplicaciones Java para detectar y medir problemas de rendimiento — incluyendo la configuración confiable del async‑profiler v4.x preinstalado, perfilado orientado a problemas (CPU, memoria, hilos, GC, E/S), scripts interactivos de perfilado, integración de JFR con Java 25 (JEP 518, JEP 520), o la recopilación de datos de perfilado con flamegraphs y grabaciones JFR. Esto debería activarse para solicitudes como Mejorar el código con perfilado; Aplicar perfilado; Refactorizar el código con perfilado; Añadir soporte de perfilado; Recopilar datos de JFR o async‑profiler para el rendimiento de Java.
