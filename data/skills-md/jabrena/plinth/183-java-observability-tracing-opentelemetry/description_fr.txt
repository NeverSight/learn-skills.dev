Utilisez-le lorsque vous devez implémenter ou améliorer le tracing distribué avec OpenTelemetry en Java — incluant la modélisation des traces/spans, la propagation du contexte, les conventions sémantiques, les attributs/événements/statut des spans, la stratégie d’échantillonnage, l’utilisation du baggage, les mesures de protection de la vie privée et l’intégration du backend avec les collecteurs OTLP. Cela doit se déclencher pour des requêtes telles que : améliorer le tracing ; appliquer le tracing OpenTelemetry ; ajouter le tracing distribué ; refondre l’instrumentation du tracing ; instrumenter les services Java avec des spans OpenTelemetry.
