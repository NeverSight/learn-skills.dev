استخدمه عندما تحتاج إلى تنفيذ أو تحسين التتبع الموزَّع باستخدام OpenTelemetry في Java — بما في ذلك نمذجة التتبع/النطاق، نشر السياق، الاتفاقيات الدلالية، سمات النطاق/الأحداث/الحالة، استراتيجية أخذ العينات، استخدام الأمتعة، إجراءات حماية الخصوصية، وتكامل الخلفية مع مجمّعات OTLP. يجب أن يتم تفعيل هذا للطلبات مثل تحسين التتبع؛ تطبيق تتبع OpenTelemetry؛ إضافة تتبع موزَّع؛ إعادة هيكلة أدوات التتبع؛ تجهي‑ز خدمات Java بنطاقات OpenTelemetry. جزء من مجموعة أدوات Plinth.
