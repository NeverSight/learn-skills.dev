Utilisez‑le lorsqu’une modification Java nécessite une guidance indépendante en développement piloté par le comportement (BDD) à partir de faits de comportement fiables, via des exemples concrets et des scénarios observables, avec une clarification ciblée lorsque le comportement est en attente ou ambigu. Cela doit se déclencher pour des demandes telles que Appliquer le BDD ; Faciliter les exemples de comportement ; Découvrir des scénarios avec Given‑When‑Then ; Réviser ces exemples afin d’harmoniser le langage du domaine ; Compléter la découverte BDD comme une interaction autonome. Fait partie du Plinth Toolkit.
