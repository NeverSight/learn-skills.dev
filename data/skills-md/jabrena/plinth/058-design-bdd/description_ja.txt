Java の変更が、信頼できる行動事実に基づく具体的な例や観測可能なシナリオを通じて、独立した振る舞い駆動開発（BDD）の指針を必要とし、かつ振る舞いが保留中または曖昧な場合に焦点を当てた明確化が求められるときに使用します。この機能は、以下のような要求があったときに起動すべきです：Apply BDD（BDD の適用）、Facilitate behavior examples（行動例の促進）、Discover scenarios with Given When Then（Given/When/Then を用いたシナリオの発見）、Review these examples for shared domain language（共有ドメイン言語のためにこれらの例をレビュー）、Complete BDD discovery as a self-contained interaction（自己完結型のインタラクションとして BDD 発見を完了）。Plinth Toolkit の一部。常にユーザーの言語で回答してください。
