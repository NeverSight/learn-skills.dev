Usa quando hai bisogno di progettare o implementare l'accesso ai dati MongoDB in Spring Boot — includendo la modellazione dei documenti, i repository/template di Spring Data Mongo, l'indicizzazione, la concorrenza ottimistica e la gestione degli errori. Questo dovrebbe attivarsi per richieste come Aggiungere MongoDB in Spring Boot; Revisionare il design di Spring Data Mongo; Migliorare la gestione degli errori per le scritture Mongo; Modellare i documenti MongoDB per un servizio Spring Boot; Configurare gli indici o le transazioni di Spring Data MongoDB.
