Utilisez-le lorsque vous devez concevoir ou implémenter l’accès aux données MongoDB dans Spring Boot — y compris la modélisation des documents, les référentiels/modèles Spring Data Mongo, l’indexation, la concurrence optimiste et la gestion des erreurs. Cela doit être déclenché pour des demandes telles que : Ajouter MongoDB dans Spring Boot ; Réviser la conception Spring Data Mongo ; Améliorer la gestion des erreurs pour les écritures Mongo ; Modéliser les documents MongoDB pour un service Spring Boot ; Configurer les index ou les transactions Spring Data MongoDB.
