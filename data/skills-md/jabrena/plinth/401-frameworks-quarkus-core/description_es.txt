Úsese al crear o revisar aplicaciones centrales de Quarkus con beans y alcances CDI, SmallRye Config y perfiles, ciclo de vida, interceptores y eventos, hilos virtuales y diseño amigable para pruebas. Esto debería activarse para solicitudes como revisar código Java para la estructura de la aplicación Quarkus y CDI; aplicar mejores prácticas para la configuración y los beans de Quarkus; mejorar interceptores CDI, eventos o inyección programática en Quarkus; añadir configuración de hilos virtuales o ajustar el ciclo de vida CDI; revisar el ciclo de vida y la configuración del bean CDI de Quarkus. Parte del Toolkit Plinth.
