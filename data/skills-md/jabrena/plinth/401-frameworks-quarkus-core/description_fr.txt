Utilisez-le lors de la création ou de la révision d’applications Quarkus essentielles avec des beans CDI et leurs portées, SmallRye Config et les profils, le cycle de vie, les intercepteurs et les événements, les threads virtuels et une conception adaptée aux tests. Cela doit se déclencher pour des demandes telles que : revoir le code Java de la structure d’application Quarkus et CDI ; appliquer les meilleures pratiques pour la configuration et les beans Quarkus ; améliorer les intercepteurs CDI, les événements ou l’injection programmatique dans Quarkus ; ajouter une configuration de thread virtuel ou ajuster le cycle de vie CDI ; revoir le cycle de vie des beans CDI Quarkus et leur configuration. Partie du Plinth Toolkit.
