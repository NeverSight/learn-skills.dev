استخدمه عند بناء أو مراجعة تطبيقات Quarkus الأساسية التي تتضمن حبوب CDI والنطاقات، SmallRye Config والملفات التعريفية، دورة الحياة، الاعتراضات والأحداث، الخيوط الافتراضية، وتصميمًا صديقًا للاختبار. يجب أن يُستدعى هذا للطلبات مثل مراجعة شفرة Java لهياكل تطبيق Quarkus وCDI؛ تطبيق أفضل الممارسات لتكوين Quarkus والحوبيات؛ تحسين اعتراضات CDI أو الأحداث أو الحقن البرمجي في Quarkus؛ إضافة تكوين الخيوط الافتراضية أو ضبط دورة حياة CDI؛ مراجعة دورة حياة حبة CDI في Quarkus وتكوينها. جزء من مجموعة أدوات Plinth.
