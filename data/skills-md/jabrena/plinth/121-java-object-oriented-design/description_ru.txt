Используйте при обзоре, улучшении или рефакторинге объектно‑ориентированного дизайна Java, включая применение принципов SOLID, DRY или YAGNI; улучшении классов и интерфейсов; исправлении инкапсуляции, наследования или полиморфизма; устранении God Class, Feature Envy или Data Clumps; а также оптимизации создания объектов, методов или контрактов исключений. Триггеры включают обзор Java OOD, рефакторинг Java OOD, улучшение Java OOD, исправление неправильного использования ООП и выявление запахов кода Java. Часть набора инструментов Plinth Toolkit.
