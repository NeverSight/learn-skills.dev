Utilisé lors de la révision, de l'amélioration ou de la refactorisation de la conception orientée objet Java, y compris l'application de SOLID, DRY ou YAGNI ; l'amélioration des classes et des interfaces ; la correction de l'encapsulation, de l'héritage ou du polymorphisme ; la résolution du God Class, du Feature Envy ou des Data Clumps ; et l'amélioration de la création d'objets, des méthodes ou des contrats d'exception. Les déclencheurs comprennent : revue Java OOD, refactorisation Java OOD, amélioration Java OOD, correction d'abus de la POO et identification des odeurs de code Java. Fait partie du Plinth Toolkit.
