Da utilizzare quando si esamina, migliora o si refattorizza il design orientato agli oggetti Java, compresa l’applicazione di SOLID, DRY o YAGNI; il miglioramento di classi e interfacce; la correzione di incapsulamento, ereditarietà o polimorfismo; la risoluzione di God Class, Feature Envy o Data Clumps; e l’ottimizzazione della creazione di oggetti, dei metodi o dei contratti delle eccezioni. I trigger includono review Java OOD, refactor Java OOD, improve Java OOD, fix OOP misuse e identify Java code smells. Parte del Plinth Toolkit.
