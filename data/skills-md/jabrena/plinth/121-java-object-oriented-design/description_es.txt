Úsese al revisar, mejorar o refactorizar el diseño orientado a objetos de Java, incluyendo la aplicación de SOLID, DRY o YAGNI; mejorar clases e interfaces; corregir encapsulación, herencia o polimorfismo; resolver God Class, Feature Envy o Data Clumps; y mejorar la creación de objetos, métodos o contratos de excepciones. Los disparadores incluyen revisar Java OOD, refactorizar Java OOD, mejorar Java OOD, corregir mal uso de OOP e identificar olores de código Java. Parte del Plinth Toolkit.
