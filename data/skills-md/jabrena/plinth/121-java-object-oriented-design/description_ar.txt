يُستخدم عند مراجعة أو تحسين أو إعادة هيكلة تصميم كائني للغة جافا، بما في ذلك تطبيق مبادئ SOLID أو DRY أو YAGNI؛ تحسين الفئات والواجهات؛ تصحيح التغليف أو الوراثة أو التعددية الشكلية؛ معالجة فئة الإله (God Class) أو الحسد الوظيفي (Feature Envy) أو تجميع البيانات (Data Clumps)؛ وتحسين إنشاء الكائنات أو الأساليب أو عقود الاستثناءات.  
تشمل المشغلات مراجعة تصميم كائني لجافا، إعادة هيكلة تصميم كائني لجافا، تحسين تصميم كائني لجافا، إصلاح سوء استخدام البرمجة الكائنية، وتحديد رائحة الكود في جافا.
