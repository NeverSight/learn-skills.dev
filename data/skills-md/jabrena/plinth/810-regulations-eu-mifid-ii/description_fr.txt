Utilisez-le lors de l’examen des preuves Java d’entreprise pour les services d’investissement MiFID II, les activités d’investissement, la classification des clients, l’adéquation, la pertinence, les preuves de traitement des ordres, les preuves de meilleure exécution, les preuves de gouvernance du trading algorithmique, les preuves de gouvernance de l’accès au marché, les preuves de transaction, la conservation des enregistrements, la surveillance ou le transfert de responsabilité de conformité. Cela doit se déclencher pour des demandes telles que : examiner une plateforme de services d’investissement Java pour les preuves MiFID II ; évaluer les preuves d’adéquation, de pertinence, de traitement des ordres ou de meilleure exécution ; documenter les lacunes d’audit, de surveillance ou de synchronisation d’horloge pour la gouvernance du trading algorithmique ; évaluer les preuves d’ingénierie du service d’investissement avant la mise en production. Fait partie de Plinth Toolkit.
