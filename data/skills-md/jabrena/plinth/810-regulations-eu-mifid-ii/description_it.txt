Usa quando si revisionano le evidenze enterprise Java per i servizi di investimento MiFID II, le attività di investimento, la classificazione dei clienti, l’idoneità, l’adeguatezza, le evidenze di gestione degli ordini, le evidenze di best‑execution, le evidenze di governance del trading algoritmico, le evidenze di governance dell’accesso al mercato, le evidenze di transazione, la conservazione dei registri, il monitoraggio o il passaggio di consegne al responsabile della conformità. Questo dovrebbe attivarsi per richieste come: revisionare una piattaforma di servizi di investimento Java per le evidenze MiFID II; valutare l’idoneità, l’adeguatezza, le evidenze di gestione degli ordini o le evidenze di best‑execution; documentare lacune di audit, monitoraggio o sincronizzazione dell’orologio per la governance del trading algoritmico; valutare le evidenze ingegneristiche del servizio di investimento prima del rilascio in produzione.
