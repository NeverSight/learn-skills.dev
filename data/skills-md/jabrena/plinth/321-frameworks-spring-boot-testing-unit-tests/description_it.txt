Da utilizzare quando è necessario scrivere unit test per le applicazioni Spring Boot, inclusi unit test puri con @ExtendWith(MockitoExtension.class) per @Service/@Component, slice test con @WebMvcTest e @MockitoBean per controller, @JsonTest per la serializzazione JSON, test parametrizzati con @CsvSource/@MethodSource, profili di test e @TestConfiguration. Per Java indipendente dal framework utilizzare @ 131-java-testing-unit-testing. Per i test di integrazione utilizzare @ 322-frameworks-spring-boot-testing-integration-tests. Ciò dovrebbe attivarsi per richieste come Review Java code for Spring Boot unit test; Applicare le migliori pratiche per gli unit test Spring Boot nel codice Java; Scrivere test unitari Mockito-first per i servizi Spring Boot; Evitare @SpringBootTest non necessari negli unit test Spring; Esaminare la progettazione del test dell'unità senza slice Spring Boot.
