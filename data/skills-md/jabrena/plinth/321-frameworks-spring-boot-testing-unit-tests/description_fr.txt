À utiliser lorsque vous devez écrire des tests unitaires pour les applications Spring Boot, notamment des tests unitaires purs avec @ExtendWith(MockitoExtension.class) pour @Service/@Component, des tests slice avec @WebMvcTest et @MockitoBean pour les contrôleurs, @JsonTest pour la sérialisation JSON, des tests paramétrés avec @CsvSource/@MethodSource, des profils de test et @TestConfiguration. Pour Java indépendant du framework, utilisez @131-java-testing-unit-testing. Pour les tests d'intégration, utilisez @322-frameworks-spring-boot-testing-integration-tests. Cela devrait se déclencher pour des requêtes telles que Réviser le code Java pour les tests unitaires Spring Boot ; Appliquer les meilleures pratiques pour les tests unitaires Spring Boot en code Java ; Écrivez des tests unitaires Mockito-first pour les services Spring Boot ; Évitez les @SpringBootTest inutiles dans les tests unitaires Spring ; Examinez la conception des tests unitaires sans tranche de Spring Boot.
