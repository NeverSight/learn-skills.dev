Úselo cuando necesite escribir pruebas unitarias para aplicaciones Spring Boot, incluidas pruebas unitarias puras con @ExtendWith(MockitoExtension.class) para @Service/@Component, pruebas de corte con @WebMvcTest y @MockitoBean para controladores, @JsonTest para serialización JSON, pruebas parametrizadas con @CsvSource/@MethodSource, perfiles de prueba y @TestConfiguration. Para Java independiente del marco, utilice @131-java-testing-unit-testing. Para pruebas de integración, utilice @322-frameworks-spring-boot-testing-integration-tests. Esto debería activar solicitudes como Revisar el código Java para las pruebas unitarias de Spring Boot; Aplicar las mejores prácticas para las pruebas unitarias de Spring Boot en código Java; Escriba las primeras pruebas unitarias de Mockito para los servicios Spring Boot; Evite @SpringBootTest innecesario en las pruebas unitarias de Spring; Revise el diseño de prueba unitaria sin sectores de Spring Boot.
