Verwenden Sie diese Option, wenn Sie Unit-Tests für Spring Boot-Anwendungen schreiben müssen – einschließlich reiner Unit-Tests mit @ExtendWith(MockitoExtension.class) für @Service/@Component, Slice-Tests mit @WebMvcTest und @MockitoBean für Controller, @JsonTest für JSON-Serialisierung, parametrisierte Tests mit @CsvSource/@MethodSource, Testprofile und @TestConfiguration. Für Framework-unabhängiges Java verwenden Sie @131-java-testing-unit-testing. Für Integrationstests verwenden Sie @322-frameworks-spring-boot-testing-integration-tests. Dies sollte für Anfragen wie „Java-Code für Spring Boot-Komponententests überprüfen“ ausgelöst werden; Wenden Sie Best Practices für Spring Boot-Komponententests in Java-Code an. Schreiben Sie Mockito-First-Unit-Tests für Spring Boot-Dienste. Vermeiden Sie unnötiges @SpringBootTest in Spring-Unit-Tests; Sehen Sie sich das Slice-freie Unit-Test-Design von Spring Boot an.
