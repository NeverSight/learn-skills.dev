Используйте, когда вам нужно написать модульные тесты для приложений Spring Boot, включая чистые модульные тесты с @ExtendWith(MockitoExtension.class) для @Service/@Component, срезовые тесты с @WebMvcTest и @MockitoBean для контроллеров, @JsonTest для сериализации JSON, параметризованные тесты с @CsvSource/@MethodSource, тестовые профили и @TestConfiguration. Для Java, не зависящего от платформы, используйте @131-java-testing-unit-testing. Для интеграционных тестов используйте @322-frameworks-spring-boot-testing-integration-tests. Это должно срабатывать для таких запросов, как «Просмотр кода Java для модульных тестов Spring Boot»; Применять лучшие практики для модульных тестов Spring Boot в коде Java; Написание модульных тестов Mockito-first для служб Spring Boot; Избегайте ненужного @SpringBootTest в модульных тестах Spring; Ознакомьтесь с дизайном модульного теста Spring Boot без срезов.
