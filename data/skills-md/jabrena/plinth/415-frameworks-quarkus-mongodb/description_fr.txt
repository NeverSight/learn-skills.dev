Utilisez-le lorsque vous avez besoin de persistance MongoDB dans Quarkus — y compris les entités/référentiels Panache Mongo, la conception de documents, les index, les transactions le cas échéant et la gestion des erreurs. Cela doit se déclencher pour des demandes telles que : ajouter MongoDB dans Quarkus ; revoir la conception Quarkus Mongo Panache ; améliorer la gestion des erreurs Mongo dans les services Quarkus ; modéliser les documents MongoDB pour un service Quarkus ; configurer les codecs ou les transactions des clients MongoDB de Quarkus. Fait partie de la boîte à outils Plinth.
