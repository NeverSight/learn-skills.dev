Da utilizzare quando è necessario progettare, rivedere o migliorare la sicurezza nelle applicazioni Spring Boot, tra cui SecurityFilterChain, modelli di server di risorse OAuth2/JWT, nozioni di base sull'accesso ai moduli, sicurezza dei metodi (@PreAuthorize), CSRF e CORS per API, correzione delle sessioni, intestazioni di sicurezza, gestione delle eccezioni, codifica delle password e registrazione sicura dei dati sensibili. Ciò dovrebbe attivare richieste come l'aggiunta del supporto di sicurezza Spring Boot; Esaminare la configurazione di sicurezza di Spring Boot; Migliorare l'autorizzazione API in Spring Boot; Aggiunta la sicurezza del server di risorse JWT in Spring Boot; Rafforzare le intestazioni di sicurezza Spring Boot e le impostazioni CSRF. Parte del kit di strumenti Plinth
