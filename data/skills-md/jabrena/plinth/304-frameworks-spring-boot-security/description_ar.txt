استخدمه عندما تحتاج إلى تصميم أو مراجعة أو تحسين الأمان في تطبيقات Spring Boot - بما في ذلك SecurityFilterChain، وأنماط خادم الموارد OAuth2/JWT، وأساسيات تسجيل الدخول للنموذج، وأمن الطريقة (@PreAuthorize)، وCSRF وCORS لواجهات برمجة التطبيقات، وتثبيت الجلسة، ورؤوس الأمان، ومعالجة الاستثناءات، وترميز كلمة المرور، والتسجيل الآمن للبيانات الحساسة. يجب أن يؤدي هذا إلى تشغيل طلبات مثل دعم أمان Add Spring Boot؛ مراجعة تكوين أمان Spring Boot؛ تحسين ترخيص API في Spring Boot؛ إضافة أمان خادم موارد JWT في Spring Boot؛ رؤوس أمان Harden Spring Boot وإعدادات CSRF. جزء من مجموعة أدوات القاعدة
