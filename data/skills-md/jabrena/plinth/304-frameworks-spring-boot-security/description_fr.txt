À utiliser lorsque vous devez concevoir, réviser ou améliorer la sécurité des applications Spring Boot, notamment SecurityFilterChain, les modèles de serveur de ressources OAuth2/JWT, les bases de la connexion par formulaire, la sécurité des méthodes (@PreAuthorize), CSRF et CORS pour les API, la fixation de session, les en-têtes de sécurité, la gestion des exceptions, le codage des mots de passe et la journalisation sécurisée des données sensibles. Cela devrait déclencher des demandes telles que l'ajout de la prise en charge de la sécurité Spring Boot ; Examinez la configuration de sécurité de Spring Boot ; Améliorer l'autorisation API dans Spring Boot ; Ajoutez la sécurité du serveur de ressources JWT dans Spring Boot ; Renforcez les en-têtes de sécurité Spring Boot et les paramètres CSRF. Fait partie de la boîte à outils Plinth
