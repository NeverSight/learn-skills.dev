Utilizzare quando si revisiona, progetta o modifica sistemi enterprise Java che espongono, scambiano, memorizzano, elaborano, esportano o trasferiscono dati tra utenti, aziende, prodotti connessi, fornitori di cloud, API, flussi di eventi, pipeline di dati IA, spazi di dati o piattaforme SaaS e necessitano di controlli ingegneristici secondo l'EU Data Act. Questo dovrebbe attivarsi per richieste come: revisionare una piattaforma Java per i controlli dell'EU Data Act; progettare prove di accesso e portabilità dei dati; aggiungere flussi di lavoro per le richieste di condivisione dei dati, formati di esportazione, interoperabilità, metadati, log di audit, supporto al cambio di cloud, salvaguardie per dati non personali o trasferimenti di segreti commerciali; valutare la prontezza ingegneristica al Data Act prima del rilascio in produzione. Parte del Plinth Toolkit.
