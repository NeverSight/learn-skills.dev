Quarkus 애플리케이션에 대한 빠른 단위 테스트를 작성해야 할 때 사용합니다 — @ExtendWith(MockitoExtension.class) 를 이용한 순수 테스트, 전체 CDI 모크 교체를 위한 @InjectMock이 포함된 @QuarkusTest, 부분 CDI 빈 모킹을 위한 @InjectSpy, 리소스 중심 테스트를 위한 REST Assured, @CsvSource / @MethodSource 와 함께 사용하는 @ParameterizedTest, 테스트 전용 설정 오버라이드를 위한 QuarkusTestProfile, 그리고 네이밍 규칙 (*Test → Surefire, *IT → Failsafe) 등을 포함합니다. 프레임워크에 구애받지 않는 Java의 경우 @131-java-testing-unit-testing을 사용하십시오. 이는 Quarkus 프로젝트에서 단위 테스트 추가 또는 개선, Mockito 우선 테스트로 느린 @QuarkusTest 사용 감소, Quarkus 테스트에서 @InjectSpy 부분 모킹 또는 QuarkusTestProfile 설정 추가, 반복되는 테스트 메서드를 @CsvSource 또는 @MethodSource 를 이용한 @ParameterizedTest 로 변환, Quarkus 서비스에 대한 빠른 순수 단위 테스트 작성 등의 요청에 트리거됩니다.
