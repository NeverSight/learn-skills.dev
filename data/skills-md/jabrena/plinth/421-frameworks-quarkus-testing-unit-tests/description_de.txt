Verwenden, wenn Sie schnelle Unit‑Tests für Quarkus‑Anwendungen schreiben müssen – einschließlich reiner Tests mit @ExtendWith(MockitoExtension.class), @QuarkusTest mit @InjectMock für vollständigen CDI‑Mock‑Ersatz, @InjectSpy für partielles CDI‑Bean‑Mocking, REST Assured für ressourcen‑fokussierte Tests, @ParameterizedTest mit @CsvSource / @MethodSource, QuarkusTestProfile für test‑spezifische Konfigurations‑Overrides und Namenskonventionen (*Test → Surefire, *IT → Failsafe). Für framework‑agnostisches Java verwenden Sie @131-java-testing-unit-testing. Das sollte bei Anfragen wie „Add or improve unit tests in a Quarkus project“, „Reduce slow @QuarkusTest usage with Mockito‑first tests“, „Add @InjectSpy partial mocking or QuarkusTestProfile configuration in Quarkus tests“, „Convert repeated test methods to @ParameterizedTest with @CsvSource or @MethodSource“, „Write fast pure unit tests for Quarkus services“ ausgelöst werden. Teil des Plinth Toolkits.
