Quarkus アプリケーションの高速ユニットテストを書く必要があるときに使用します — @ExtendWith(MockitoExtension.class) を使った純粋テスト、@InjectMock を伴う @QuarkusTest による CDI の完全モック置換、@InjectSpy による部分的な CDI ビーンのモック、REST Assured を使ったリソース指向テスト、@CsvSource / @MethodSource を使用した @ParameterizedTest、テスト固有の設定上書きのための QuarkusTestProfile、そして命名規則（*Test → Surefire、*IT → Failsafe）を含みます。フレームワークに依存しない Java には @131-java-testing-unit-testing を使用してください。このタグは、Quarkus プロジェクトでユニットテストを追加・改善する、@QuarkusTest の遅い使用を減らし Mockito 主導のテストに置き換える、Quarkus テストで @InjectSpy の部分モックや QuarkusTestProfile 設定を追加する、繰り返しのテストメソッドを @CsvSource または @MethodSource を使った @ParameterizedTest に変換する、Quarkus サービス向けに高速な純粋ユニットテストを書く、などのリクエストに対してトリガーされます。Plinth Toolkit の一部です。
