Используйте, когда необходимо быстро писать unit‑тесты для приложений Quarkus — включая чистые тесты с @ExtendWith(MockitoExtension.class), @QuarkusTest с @InjectMock для полной замены CDI‑моков, @InjectSpy для частичного мокирования CDI‑бинов, REST Assured для тестов, сфокусированных на ресурсах, @ParameterizedTest с @CsvSource / @MethodSource, QuarkusTestProfile для переопределения конфигурации, специфичной для тестов, а также соглашения об именовании (*Test → Surefire, *IT → Failsafe). Для фреймворк‑независимого Java используйте @131-java-testing-unit-testing. Это должно срабатывать для запросов типа «Добавить или улучшить unit‑тесты в проекте Quarkus»; «Снизить медленное использование @QuarkusTest с помощью тестов, основанных на Mockito»; «Добавить частичное мокирование @InjectSpy или конфигурацию QuarkusTestProfile в тестах Quarkus»; «Преобразовать повторяющиеся методы тестов в @ParameterizedTest с @CsvSource или @MethodSource»; «Писать быстрые чистые unit‑тесты для сервисов Quarkus».
