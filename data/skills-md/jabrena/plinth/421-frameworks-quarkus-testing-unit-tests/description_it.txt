Da utilizzare quando è necessario scrivere test unitari rapidi per applicazioni Quarkus — includendo test puri con @ExtendWith(MockitoExtension.class), @QuarkusTest con @InjectMock per la sostituzione completa dei mock CDI, @InjectSpy per il mocking parziale dei bean CDI, REST Assured per test focalizzati sulle risorse, @ParameterizedTest con @CsvSource / @MethodSource, QuarkusTestProfile per sovrascritture di configurazione specifiche ai test e le convenzioni di denominazione (*Test → Surefire, *IT → Failsafe). Per Java indipendente dal framework usare @131-java-testing-unit-testing. Questo dovrebbe attivarsi per richieste come Aggiungere o migliorare i test unitari in un progetto Quarkus; Ridurre l'uso lento di @QuarkusTest con test incentrati su Mockito; Aggiungere mocking parziale @InjectSpy o configurazione QuarkusTestProfile nei test Quarkus; Convertire metodi di test ripetuti in @ParameterizedTest con @CsvSource o @MethodSource; Scrivere test unitari puri e rapidi per i servizi Quarkus. Parte del Plinth Toolkit.
