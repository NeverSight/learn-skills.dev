当需要为 Quarkus 应用编写快速单元测试时使用——包括使用 `@ExtendWith(MockitoExtension.class)` 的纯测试，使用 `@QuarkusTest` 搭配 `@InjectMock` 进行完整的 CDI Mock 替换，使用 `@InjectSpy` 进行部分 CDI Bean Mock，使用 REST Assured 进行面向资源的测试，使用带有 `@CsvSource`／`@MethodSource` 的 `@ParameterizedTest`，使用 `QuarkusTestProfile` 进行针对测试的配置覆盖，以及命名约定（`*Test` → Surefire，`*IT` → Failsafe）。对框架无关的 Java 使用 `@131-java-testing-unit-testing`。此标签应在以下请求时触发，例如在 Quarkus 项目中添加或改进单元测试；通过以 Mockito 为首的测试减少缓慢的 `@QuarkusTest` 使用；在 Quarkus 测试中添加 `@InjectSpy` 部分 Mock 或 `QuarkusTestProfile` 配置；将重复的测试方法转换为带有 `@CsvSource` 或 `@MethodSource` 的 `@ParameterizedTest`；为 Quarkus 服务编写快速的纯单元测试。属于 Plinth Toolkit 的一部分。
