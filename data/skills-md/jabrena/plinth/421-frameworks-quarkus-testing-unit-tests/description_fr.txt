À utiliser lorsque vous devez rédiger rapidement des tests unitaires pour des applications Quarkus — incluant des tests purs avec @ExtendWith(MockitoExtension.class), @QuarkusTest avec @InjectMock pour un remplacement complet des mocks CDI, @InjectSpy pour le moquage partiel des beans CDI, REST Assured pour des tests centrés sur les ressources, @ParameterizedTest avec @CsvSource / @MethodSource, QuarkusTestProfile pour des surcharges de configuration propres aux tests, et les conventions de nommage (*Test → Surefire, *IT → Failsafe). Pour du Java indépendant du framework, utilisez @131-java-testing-unit-testing. Cela doit se déclencher pour des requêtes telles que : ajouter ou améliorer les tests unitaires dans un projet Quarkus ; réduire l’utilisation lente de @QuarkusTest avec des tests privilégiant Mockito ; ajouter un moquage partiel @InjectSpy ou une configuration QuarkusTestProfile dans les tests Quarkus ; convertir des méthodes de test répétées en @ParameterizedTest avec @CsvSource ou @MethodSource ; rédiger des tests unitaires purs et rapides pour les services Quarkus. Fait partie de Plinth Toolkit.
