استخدمه عندما تحتاج إلى كتابة اختبارات وحدة سريعة لتطبيقات Quarkus — بما في ذلك الاختبارات النقية باستخدام @ExtendWith(MockitoExtension.class)، @QuarkusTest مع @InjectMock لاستبدال كامل لتقنية CDI، @InjectSpy لتقليد جزئي لحبوب CDI، REST Assured لاختبارات مركزة على الموارد، @ParameterizedTest مع @CsvSource / @MethodSource، QuarkusTestProfile لتجاوز إعدادات التكوين الخاصة بالاختبار، ومعايير التسمية (*Test → Surefire، *IT → Failsafe). لاستخدام Java غير المرتبط بإطار عمل استخدم @131-java-testing-unit-testing. يجب أن يتم تفعيل هذا عند طلبات مثل إضافة أو تحسين اختبارات الوحدة في مشروع Quarkus؛ تقليل الاستخدام البطيء لـ @QuarkusTest عبر اختبارات تعتمد أولاً على Mockito؛ إضافة تقليد جزئي باستخدام @InjectSpy أو تكوين QuarkusTestProfile في اختبارات Quarkus؛ تحويل طرق الاختبار المتكررة إلى @ParameterizedTest مع @CsvSource أو @MethodSource؛ كتابة اختبارات وحدة نقية وسريعة لخدمات Quarkus. جزء من مجموعة أدوات Plinth Toolkit
