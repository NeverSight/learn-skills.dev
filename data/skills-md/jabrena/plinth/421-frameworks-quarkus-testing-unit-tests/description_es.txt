Úsalo cuando necesites escribir pruebas unitarias rápidas para aplicaciones Quarkus — incluyendo pruebas puras con @ExtendWith(MockitoExtension.class), @QuarkusTest con @InjectMock para reemplazo completo de mocks CDI, @InjectSpy para simulación parcial de beans CDI, REST Assured para pruebas centradas en recursos, @ParameterizedTest con @CsvSource / @MethodSource, QuarkusTestProfile para sobrescribir la configuración específica de pruebas y convenciones de nombres (*Test → Surefire, *IT → Failsafe). Para Java independiente del framework usa @131-java-testing-unit-testing. Esto debería activarse para solicitudes como Añadir o mejorar pruebas unitarias en un proyecto Quarkus; Reducir el uso lento de @QuarkusTest con pruebas basadas en Mockito; Añadir simulación parcial con @InjectSpy o configuración QuarkusTestProfile en pruebas Quarkus; Convertir métodos de prueba repetidos a @ParameterizedTest con @CsvSource o @MethodSource; Escribir pruebas unitarias puras y rápidas para servicios Quarkus.
