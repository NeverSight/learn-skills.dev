Utilisez-le lorsque vous devez écrire ou améliorer des tests d’intégration pour Quarkus — y compris @QuarkusTest, Dev Services pour le provisionnement automatique de conteneurs, Testcontainers via QuarkusTestResourceLifecycleManager, WireMock pour les stubs HTTP externes, @QuarkusIntegrationTest pour les tests boîte noire contre les artefacts empaquetés, REST Assured, les stratégies d’isolation des données (@TestTransaction vs nettoyage @BeforeEach), et la répartition à trois niveaux de Maven Surefire/Failsafe (*Test, *IT, *AT). Cela doit se déclencher pour des requêtes telles que : ajouter ou améliorer des tests d’intégration dans un projet Quarkus ; configurer Testcontainers ou Dev Services pour les tests Quarkus ; ajouter des stubs WireMock pour les dépendances HTTP externes dans les tests d’intégration Quarkus ; mettre en place @QuarkusIntegrationTest pour les artefacts empaquetés ou les tests de binaires natifs ; corriger l’isolation des données de test ou configurer la répartition Maven Surefire/Failsafe.
