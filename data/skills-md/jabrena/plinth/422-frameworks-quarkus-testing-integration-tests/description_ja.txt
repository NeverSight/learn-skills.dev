Quarkus の統合テストを書いたり改善したりする必要があるときに使用してください — @QuarkusTest、コンテナの自動プロビジョニングのための Dev Services、QuarkusTestResourceLifecycleManager を介した Testcontainers、外部 HTTP スタブ用の WireMock、パッケージ化された成果物に対するブラックボックステストのための @QuarkusIntegrationTest、REST Assured、データ分離戦略（@TestTransaction と @BeforeEach のクリーンアップの比較）、そして Maven Surefire/Failsafe の三層分割（*Test、*IT、*AT）を含みます。この機能は、以下のようなリクエストでトリガーされるべきです：Quarkus プロジェクトで統合テストを追加または改善する；Quarkus テスト用に Testcontainers または Dev Services を設定する；Quarkus 統合テストで外部 HTTP 依存関係のために WireMock スタブを追加する；パッケージ化成果物またはネイティブバイナリのテスト用に @QuarkusIntegrationTest を設定する；テストデータの分離を修正するまたは Maven Surefire/Failsafe の分割を構成する。Plinth Toolkit の一部です。
