استخدم ذلك عندما تحتاج إلى كتابة أو تحسين اختبارات التكامل لـ Quarkus — بما في ذلك @QuarkusTest، وخدمات التطوير للتزويد التلقائي بالحاويات، وTestcontainers عبر QuarkusTestResourceLifecycleManager، وWireMock لتقليد طلبات HTTP الخارجية، و@QuarkusIntegrationTest لاختبار الصندوق الأسود ضد الحزم المجمعة، وREST Assured، واستراتيجيات عزل البيانات (@TestTransaction مقابل تنظيف @BeforeEach)، وتقسيم Maven Surefire/Failsafe إلى ثلاث طبقات (*Test، *IT، *AT). يجب أن يتفاعل مع طلبات مثل إضافة أو تحسين اختبارات التكامل في مشروع Quarkus؛ تكوين Testcontainers أو خدمات التطوير لاختبارات Quarkus؛ إضافة استنساخات WireMock للاعتمادات الخارجية HTTP في اختبارات التكامل؛ إعداد @QuarkusIntegrationTest للاختبار ضد الحزمة أو الثنائي الأصلي؛ إصلاح عزل بيانات الاختبار أو تكوين تقسيم Maven Surefire/Failsafe. جزء من مجموعة أدوات Plinth.
