Usa quando devi scrivere o migliorare i test di integrazione per Quarkus — includendo @QuarkusTest, Dev Services per il provisioning automatico dei container, Testcontainers tramite QuarkusTestResourceLifecycleManager, WireMock per stub HTTP esterni, @QuarkusIntegrationTest per test black‑box su artefatti confezionati, REST Assured, strategie di isolamento dei dati (@TestTransaction vs pulizia @BeforeEach) e la divisione a tre livelli di Maven Surefire/Failsafe (*Test, *IT, *AT). Questo dovrebbe attivarsi per richieste come aggiungere o migliorare i test di integrazione in un progetto Quarkus; configurare Testcontainers o Dev Services per i test Quarkus; aggiungere stub WireMock per dipendenze HTTP esterne nei test di integrazione Quarkus; impostare @QuarkusIntegrationTest per testare l'artefatto confezionato o il binario nativo; risolvere problemi di isolamento dei dati di test o configurare la divisione Maven Surefire/Failsafe. Parte del Plinth Toolkit.
