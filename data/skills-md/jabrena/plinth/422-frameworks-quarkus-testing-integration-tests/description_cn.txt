当需要为 Quarkus 编写或改进集成测试时使用——包括 @QuarkusTest、用于自动容器供应的 Dev Services、通过 QuarkusTestResourceLifecycleManager 使用 Testcontainers、用于外部 HTTP 存根的 WireMock、用于对打包产物进行黑盒测试的 @QuarkusIntegrationTest、REST Assured、数据隔离策略（@TestTransaction 与 @BeforeEach 清理），以及 Maven Surefire/Failsafe 的三层划分（*Test、*IT、*AT）。此情形应在以下请求时触发：在 Quarkus 项目中添加或改进集成测试；为 Quarkus 测试配置 Testcontainers 或 Dev Services；为 Quarkus 集成测试的外部 HTTP 依赖添加 WireMock 存根；为打包产物或本机二进制文件设置 @QuarkusIntegrationTest；修复测试数据隔离或配置 Maven Surefire/Failsafe 划分。属于 Plinth Toolkit 的一部分。
