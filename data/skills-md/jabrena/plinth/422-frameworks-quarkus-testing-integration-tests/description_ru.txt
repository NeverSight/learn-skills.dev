Используйте, когда необходимо писать или улучшать интеграционные тесты для Quarkus — включая @QuarkusTest, Dev Services для автоматического provision контейнеров, Testcontainers через QuarkusTestResourceLifecycleManager, WireMock для внешних HTTP‑заглушек, @QuarkusIntegrationTest для black‑box тестирования упакованных артефактов, REST Assured, стратегии изоляции данных (@TestTransaction vs очистка в @BeforeEach) и трёхуровневое разделение Maven Surefire/Failsafe (*Test, *IT, *AT). Это должно срабатывать для запросов, таких как: добавить или улучшить интеграционные тесты в проекте Quarkus; настроить Testcontainers или Dev Services для тестов Quarkus; добавить заглушки WireMock для внешних HTTP‑зависимостей в интеграционных тестах Quarkus; настроить @QuarkusIntegrationTest для тестирования упакованного артефакта или нативного бинарника; исправить изоляцию тестовых данных или настроить разделение Maven Surefire/Failsafe. Часть Plinth Toolkit.
