Micronaut アプリケーションでバリデーションの設計、レビュー、または改善が必要なときに使用します — @Controller メソッド上の Bean Validation、@Body @Valid、クエリ／パスパラメータのバリデーション、@ConfigurationProperties のバリデーション、カスタム制約、入れ子 DTO のバリデーション、制約違反の ExceptionHandler マッピングを含みます。これには、Micronaut にバリデーションサポートを追加する、Micronaut のバリデーションルールをレビューする、Micronaut REST API のリクエストバリデーションを改善する、Micronaut にカスタムバリデーション制約を追加する、Micronaut の設定プロパティをバリデートする、などのリクエストがトリガーされます。Plinth Toolkit の一部です。
