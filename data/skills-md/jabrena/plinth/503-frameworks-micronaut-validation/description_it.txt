Usa quando hai bisogno di progettare, revisionare o migliorare la validazione nelle applicazioni Micronaut — inclusa la Bean Validation sui metodi @Controller, @Body @Valid, la validazione di parametri query/percorso, la validazione di @ConfigurationProperties, vincoli personalizzati, la validazione di DTO nidificati e la mappatura di ExceptionHandler per violazioni di vincoli. Questo dovrebbe attivarsi per richieste come: aggiungere supporto alla validazione in Micronaut; revisionare le regole di validazione di Micronaut; migliorare la validazione delle richieste nelle API REST di Micronaut; aggiungere vincoli di validazione personalizzati in Micronaut; validare le proprietà di configurazione di Micronaut. Parte di Plinth Toolkit.
