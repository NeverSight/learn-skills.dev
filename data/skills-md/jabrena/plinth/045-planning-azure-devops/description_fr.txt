Utilisez-le lorsque vous avez besoin d’orientations sur la CLI Azure DevOps pour vérifier l’installation, configurer le contexte d’organisation et de projet, découvrir les ID d’éléments de travail via des filtres WIQL optionnels, et exécuter des opérations sûres de création/mise à jour d’éléments de travail. Utilise une porte d’installation interactive : si `az` ou l’extension Azure DevOps est manquante, demander si l’on doit afficher les instructions d’installation avant toute commande d’élément de travail. Cela doit se déclencher pour des requêtes telles que : liste d’éléments de travail Azure DevOps ; lister les ID d’éléments de travail Azure Boards ; requête WIQL Azure DevOps ; flux de travail de planification CLI Azure DevOps. Fait partie de la boîte à outils Plinth. Veuillez toujours répondre dans la langue de l’utilisateur.
