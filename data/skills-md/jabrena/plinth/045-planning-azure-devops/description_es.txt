Úsalo cuando necesites orientación sobre la CLI de Azure DevOps para verificar la instalación, configurar el contexto de organización y proyecto, descubrir ID de elementos de trabajo mediante filtros WIQL opcionales y ejecutar operaciones seguras de crear/actualizar elementos de trabajo. Utiliza una puerta de instalación interactiva: si falta `az` o la extensión de Azure DevOps, pregunta si se debe mostrar la guía de instalación antes de cualquier comando de elemento de trabajo. Esto debe activarse para solicitudes como lista de elementos de trabajo de Azure DevOps; listar IDs de elementos de trabajo de Azure Boards; consulta WIQL de Azure DevOps; flujo de trabajo de planificación con la CLI de Azure DevOps. Parte del Toolkit Plinth.
