استخدمه عندما تحتاج إلى إرشادات Azure DevOps CLI للتحقق من التثبيت، وتكوين سياق المؤسسة والمشروع، واكتشاف معرفات عناصر العمل باستخدام فلاتر WIQL اختيارية، وتنفيذ عمليات إنشاء/تحديث عناصر العمل بأمان.  
يستخدم بوابة تثبيت تفاعلية - إذا كان `az` أو إضافة Azure DevOps مفقودة، يطلب ما إذا كان ينبغي عرض إرشادات التثبيت قبل أي أوامر لعناصر العمل.  
يجب أن يتم تفعيل ذلك للطلبات مثل: قائمة عناصر عمل Azure DevOps؛ قائمة معرفات عناصر عمل Azure Boards؛ استعلام WIQL في Azure DevOps؛ سير عمل تخطيط Azure DevOps CLI.
