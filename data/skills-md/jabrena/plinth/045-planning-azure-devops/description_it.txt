Usa quando hai bisogno di indicazioni sul CLI di Azure DevOps per verificare l'installazione, configurare il contesto dell'organizzazione e del progetto, scoprire gli ID degli elementi di lavoro tramite filtri WIQL opzionali e eseguire operazioni sicure di creazione/aggiornamento degli elementi di lavoro. Utilizza un gate di installazione interattivo: se `az` o l'estensione Azure DevOps non sono presenti, chiedi se mostrare le istruzioni di installazione prima di qualsiasi comando sugli elementi di lavoro. Questo dovrebbe attivarsi per richieste come elenco degli elementi di lavoro di Azure DevOps; elenca gli ID degli elementi di lavoro di Azure Boards; query WIQL di Azure DevOps; flusso di lavoro di pianificazione del CLI di Azure DevOps.
