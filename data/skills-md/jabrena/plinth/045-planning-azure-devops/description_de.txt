Verwenden Sie dies, wenn Sie eine Azure‑DevOps‑CLI‑Anleitung benötigen, um die Installation zu überprüfen, die Organisations‑ und Projekt‑Kontexte zu konfigurieren, Work‑Item‑IDs anhand optionaler WIQL‑Filter zu ermitteln und sichere Work‑Item‑Erstell‑/Aktualisierungsvorgänge auszuführen. Verwendet eine interaktive Installationsprüfung – wenn `az` oder die Azure‑DevOps‑Erweiterung fehlt, wird gefragt, ob Installationshinweise angezeigt werden sollen, bevor irgendwelche Work‑Item‑Befehle ausgeführt werden. Dies sollte bei Anfragen wie Azure DevOps Work‑Item‑Liste; Azure Boards‑Work‑Item‑IDs auflisten; Azure DevOps‑WIQL‑Abfrage; Azure DevOps‑CLI‑Planungs‑Workflow ausgelöst werden.
