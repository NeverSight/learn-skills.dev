當您需要設計、審查或改進 Spring Boot 的 REST API 時使用——包括 HTTP 方法、資源 URI、狀態碼、DTO、版本控制、棄用與終止標頭、內容協商（JSON 與廠商媒體類型）、DTO 中的 ISO-8601 時間點、分頁/排序/過濾、邊界的 Bean Validation、冪等性、ETag 並發、HTTP 快取、錯誤處理、安全性、契約優先的 OpenAPI（OpenAPI Generator）、Controller Advice 以及錯誤的 Problem Details。此功能應在以下請求時觸發，例如：審查 Spring Boot REST API 的 Java 程式碼；在 Java 程式碼中套用 Spring Boot REST API 的最佳實踐；設計 Spring Boot REST 控制器與 DTO；在 Spring Boot REST 中加入 Problem Details 錯誤回應；改進 Spring API 的分頁驗證或冪等性。屬於 Plinth Toolkit 的一部分。
