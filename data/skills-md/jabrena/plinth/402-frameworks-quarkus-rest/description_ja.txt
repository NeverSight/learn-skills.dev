Quarkus REST（Jakarta REST）で REST API を設計、レビュー、または改善する必要があるときに使用します — リソースクラス、HTTP メソッド、ステータスコード、リクエスト/レスポンス DTO、Bean Validation、例外マッパー、オプションのランタイム OpenAPI 公開（SmallRye）、OpenAPI からのコントラクトファースト生成、コンテンツネゴシエーション、ページング、ソート・フィルタリング、API バージョニング、冪等性（Idempotency-Key）、楽観的同時実行制御（ETag / If-Match）、HTTP キャッシュ（Cache‑Control）、API 廃止（Sunset / Deprecation ヘッダー）、RFC 7807 Problem Details、契約における ISO‑8601 時間表記、セキュリティを考慮した境界 などが含まれます。以下のようなリクエストでトリガーされます：Quarkus プロジェクトで JAX‑RS リソースをレビューまたは改善する、Quarkus 上で検証とエラーハンドリングを備えた HTTP API を設計する、API バージョニング、冪等性、ETag 同時実行制御、または廃止ヘッダーを追加する、ページング、ソート、あるいは RFC 7807 Problem Details のエラーレスポンスを実装する、Quarkus REST リソースと例外マッパーを改善する。Plinth Toolkit の一部です。
