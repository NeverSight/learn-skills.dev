Используйте, когда нужно проектировать, проверять или улучшать REST‑API с помощью Quarkus REST (Jakarta REST) — включая классы ресурсов, HTTP‑методы, коды статусов, DTO запросов/ответов, Bean Validation, мапперы исключений, опциональное раскрытие OpenAPI во время выполнения (SmallRye), генерацию из контракта по OpenAPI, согласование контента, пагинацию, сортировку и фильтрацию, версионирование API, идемпотентность (Idempotency‑Key), оптимистичную конкуренцию (ETag / If‑Match), HTTP‑кеширование (Cache‑Control), депрецирование API (заголовки Sunset / Deprecation), детали проблемы RFC 7807, ISO‑8601 для времени в контрактах и границы, учитывающие безопасность. Это должно срабатывать для запросов, таких как проверка или улучшение JAX‑RS‑ресурсов в проекте Quarkus; проектирование HTTP‑API с валидацией и обработкой ошибок в Quarkus; добавление версионирования API, идемпотентности, конкуренции ETag или заголовков депрецирования; реализация пагинации, сортировки или ответов об ошибках RFC 7807 Problem Details; улучшение ресурсов Quarkus REST и мапперов исключений. Часть Plinth Toolkit.
