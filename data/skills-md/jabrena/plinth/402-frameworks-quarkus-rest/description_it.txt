Usa quando è necessario progettare, revisionare o migliorare le API REST con Quarkus REST (Jakarta REST) — includendo classi di risorsa, metodi HTTP, codici di stato, DTO di richiesta/risposta, Bean Validation, mapper di eccezioni, esposizione opzionale di OpenAPI a runtime (SmallRye), generazione contract‑first da OpenAPI, negoziazione del contenuto, paginazione, ordinamento e filtraggio, versionamento delle API, idempotenza (Idempotency‑Key), concorrenza ottimistica (ETag / If‑Match), caching HTTP (Cache‑Control), deprecazione delle API (intestazioni Sunset / Deprecation), RFC 7807 Problem Details, ISO‑8601 per il tempo nei contratti e confini consapevoli della sicurezza. Questo dovrebbe attivarsi per richieste come revisionare o migliorare le risorse JAX‑RS in un progetto Quarkus; progettare API HTTP con validazione e gestione degli errori su Quarkus; aggiungere versionamento dell’API, idempotenza, concorrenza ETag o intestazioni di deprecazione; implementare paginazione, ordinamento o risposte di errore RFC 7807 Problem Details; migliorare le risorse REST di Quarkus e i mapper di eccezioni. Parte del Plinth Toolkit.
