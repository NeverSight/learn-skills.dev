Utilisez-le lorsque vous devez concevoir, examiner ou améliorer des API REST avec Quarkus REST (Jakarta REST) — y compris les classes de ressources, les méthodes HTTP, les codes d’état, les DTO de requête/réponse, la validation Bean, les mappeurs d’exception, l’exposition runtime optionnelle d’OpenAPI (SmallRye), la génération contract‑first depuis OpenAPI, la négociation de contenu, la pagination, le tri et le filtrage, la version d’API, l’idempotence (Idempotency‑Key), la concurrence optimiste (ETag / If‑Match), la mise en cache HTTP (Cache‑Control), la dépréciation d’API (en‑têtes Sunset / Deprecation), les détails de problème RFC 7807, ISO‑8601 pour le temps dans les contrats, et les frontières conscientes de la sécurité. Cela doit se déclencher pour des demandes telles que : examiner ou améliorer les ressources JAX‑RS dans un projet Quarkus ; concevoir des API HTTP avec validation et gestion des erreurs sur Quarkus ; ajouter la version d’API, l’idempotence, la concurrence ETag ou les en‑têtes de dépréciation ; implémenter la pagination, le tri ou les réponses d’erreur RFC 7807 Problem Details ; améliorer les ressources Quarkus REST et les mappeurs d’exception.
