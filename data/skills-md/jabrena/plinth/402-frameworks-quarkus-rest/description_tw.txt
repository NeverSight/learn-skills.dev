在需要設計、審查或改進使用 Quarkus REST（Jakarta REST）的 REST API 時使用——包括資源類別、HTTP 方法、狀態碼、請求/回應 DTO、Bean Validation、例外映射器、可選的執行時 OpenAPI 曝露（SmallRye）、從 OpenAPI 進行合約優先生成、內容協商、分頁、排序與過濾、API 版本管理、冪等性（Idempotency‑Key）、樂觀併發控制（ETag / If‑Match）、HTTP 快取（Cache‑Control）、API 棄用（Sunset / Deprecation 標頭）、RFC 7807 問題細節、合約中的 ISO‑8601 時間，以及安全意識的邊界。此提示應在以下請求時觸發，例如：審查或改進 Quarkus 專案中的 JAX‑RS 資源；在 Quarkus 上設計具驗證與錯誤處理的 HTTP API；加入 API 版本管理、冪等性、ETag 併發控制或棄用標頭；實作分頁、排序或 RFC 7807 問題細節錯誤回應；改進 Quarkus REST 資源與例外映射器。屬於 Plinth Toolkit 的一部分。
