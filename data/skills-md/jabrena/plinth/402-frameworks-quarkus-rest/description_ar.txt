استخدم عندما تحتاج إلى تصميم أو مراجعة أو تحسين واجهات برمجة التطبيقات REST باستخدام Quarkus REST (Jakarta REST) — بما في ذلك فئات الموارد، أساليب HTTP، رموز الحالة، كائنات نقل البيانات (DTO) للطلب والاستجابة، التحقق من صحة الـ Bean، مخرجات الاستثناءات، إظهار OpenAPI أثناء التشغيل كخيار (SmallRye)، الإنشاء الأولي من العقد باستخدام OpenAPI، التفاوض على المحتوى، الترقيم، الفرز والتصفية، إصدارات API، عدم التكرار (Idempotency‑Key)، التزامن المتفائل (ETag / If‑Match)، التخزين المؤقت لـ HTTP (Cache‑Control)، إيقاف API (Sunset / رؤوس الإيقاف)، تفاصيل المشكلة وفق RFC 7807، ISO‑8601 للوقت في العقود، والحدود الواعية بالأمان. يجب أن يُفعَّل هذا للطلبات مثل مراجعة أو تحسين موارد JAX‑RS في مشروع Quarkus؛ تصميم واجهات HTTP مع التحقق من الصحة ومعالجة الأخطاء على Quarkus؛ إضافة إصدارات API، عدم التكرار، تزامن ETag أو رؤوس الإيقاف؛ تنفيذ الترقيم أو الفرز أو استجابات الأخطاء وفق RFC 7807؛ تحسين موارد Quarkus REST ومخرجات الاستثناءات. جزء من مجموعة أدوات Plinth.
