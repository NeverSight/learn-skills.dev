當您需要在 Spring Boot 應用程式中設計、審查或改進驗證時使用——包括對請求 DTO 的 Bean Validation、API 邊界的 @Valid/@Validated、約束組、自訂約束、@ConfigurationProperties 的驗證、巢狀 DTO 驗證，以及一致的驗證錯誤處理。此功能應在以下請求時觸發，例如：在 Spring Boot 中加入驗證支援；審查 Spring Boot 的驗證規則；改進 Spring Boot REST API 的請求驗證；在 Spring Boot 中加入自訂 Bean Validation 約束；驗證 Spring Boot 中的組態屬性。屬於 Plinth Toolkit 的一部分。
