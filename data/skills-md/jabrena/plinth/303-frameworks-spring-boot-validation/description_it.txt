Usa quando devi progettare, revisionare o migliorare la validazione nelle applicazioni Spring Boot — includendo Bean Validation sui DTO di richiesta, @Valid/@Validated ai confini dell’API, gruppi di vincoli, vincoli personalizzati, validazione di @ConfigurationProperties, validazione di DTO annidati e gestione coerente degli errori di validazione. Questo dovrebbe attivarsi per richieste come Aggiungi il supporto alla validazione in Spring Boot; Revisiona le regole di validazione di Spring Boot; Migliora la validazione delle richieste nelle API REST di Spring Boot; Aggiungi vincoli Bean Validation personalizzati in Spring Boot; Valida le proprietà di configurazione in Spring Boot. Parte del Plinth Toolkit.
