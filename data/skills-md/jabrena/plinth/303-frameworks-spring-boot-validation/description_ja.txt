Spring Boot アプリケーションでバリデーションを設計、レビュー、または改善する必要があるときに使用します — リクエスト DTO の Bean Validation、API 境界での @Valid/@Validated、制約グループ、カスタム制約、@ConfigurationProperties のバリデーション、ネストされた DTO のバリデーション、そして一貫したバリデーションエラー処理を含みます。この機能は、以下のようなリクエストでトリガーされるべきです：Spring Boot にバリデーションサポートを追加する、Spring Boot のバリデーションルールをレビューする、Spring Boot REST API のリクエストバリデーションを改善する、Spring Boot にカスタム Bean Validation 制約を追加する、Spring Boot の設定プロパティをバリデートする。Plinth Toolkit の一部です。常にユーザーの言語で回答してください。
