Utilisez-le lorsque vous devez concevoir, examiner ou améliorer la validation dans les applications Spring Boot — y compris la validation Bean sur les DTO de requête, @Valid/@Validated aux frontières de l’API, les groupes de contraintes, les contraintes personnalisées, la validation des @ConfigurationProperties, la validation des DTO imbriqués et la gestion cohérente des erreurs de validation. Cela doit se déclencher pour des requêtes telles que : Ajouter la prise en charge de la validation dans Spring Boot ; Examiner les règles de validation de Spring Boot ; Améliorer la validation des requêtes dans les API REST Spring Boot ; Ajouter des contraintes Bean Validation personnalisées dans Spring Boot ; Valider les propriétés de configuration dans Spring Boot. Partie de Plinth Toolkit.
