Utilícese cuando necesite configurar pruebas de rendimiento Gatling para un proyecto Java Maven — incluyendo agregar dependencias de Gatling y el plugin Maven de Gatling, crear simulaciones en Java, ejecutar gatling:test, configurar una clase de simulación y revisar los informes generados. Esto debe activarse para solicitudes como Añadir pruebas de rendimiento Gatling; Aplicar pruebas de rendimiento Gatling; Crear una simulación Gatling; Añadir soporte Gatling; Revisar aserciones y feeders de pruebas de rendimiento Gatling.
