استخدم عندما تحتاج إلى إعداد اختبار الأداء Gatling لمشروع Java Maven — بما يشمل إضافة تبعيات Gatling وإضافة المكوّن الإضافي Gatling Maven، إنشاء محاكيات Java، تشغيل gatling:test، تكوين فئة المحاكاة، ومراجعة التقارير المُولدة. يجب أن يتم تشغيله للطلبات مثل إضافة اختبار أداء Gatling؛ تطبيق اختبار أداء Gatling؛ إنشاء محاكاة Gatling؛ إضافة دعم Gatling؛ مراجعة تأكيدات اختبار الأداء Gatling ومغذّياته. جزء من مجموعة أدوات Plinth.
