Utilisez‑le lors de la construction ou de la révision d’applications Micronaut — démarrage Micronaut.run, @Singleton/@Prototype, beans @Factory, @ConfigurationProperties, environnements, @Requires, @Controller vs services, @Scheduled, arrêt gracieux, @ExecuteOn pour le travail bloquant, et API compatibles Jakarta. Cela doit se déclencher pour des requêtes telles que : revoir le code Java pour la structure et les beans d’une application Micronaut ; appliquer les meilleures pratiques pour la configuration Micronaut, @Requires et les factories ; améliorer la planification, l’arrêt ou le threading dans les services Micronaut ; revoir les scopes d’injection de dépendances et les factories Micronaut ; configurer les conditions @Requires de Micronaut pour les environnements.
