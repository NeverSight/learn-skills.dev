Micronaut アプリケーションの構築またはレビュー時に使用します — Micronaut.run ブートストラップ、@Singleton/@Prototype、@Factory ビーン、@ConfigurationProperties、環境、@Requires、@Controller とサービスの違い、@Scheduled、優雅なシャットダウン、ブロッキング作業用の @ExecuteOn、そして Jakarta 準拠 API。これらは、次のようなリクエストに対してトリガーされるべきです：Micronaut アプリケーションの構造とビーンに関する Java コードのレビュー、Micronaut 設定、@Requires、ファクトリのベストプラクティスの適用、Micronaut サービスにおけるスケジューリング、シャットダウン、スレッド処理の改善、Micronaut の依存性注入スコープとファクトリのレビュー、環境向けの Micronaut @Requires 条件の設定。Plinth Toolkit の一部です。
