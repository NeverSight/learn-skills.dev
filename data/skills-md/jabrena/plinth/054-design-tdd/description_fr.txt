Utilisez lorsque le travail d’implémentation Java doit être guidé par le développement piloté par les tests (TDD), y compris la tenue d’une liste de tests, le choix du comportement suivant, l’écriture d’un test qui échoue d’abord, l’implémentation du strict nécessaire pour faire passer le test, et le refactoring tout en maintenant les tests verts. Cela doit se déclencher pour des demandes telles que : Appliquer le TDD ; Utiliser le développement piloté par les tests ; Conduire ce changement Java avec des tests ; Écrire le test qui échoue d’abord ; Refactoriser en rouge‑vert cette fonctionnalité. Fait partie du Plinth Toolkit.
