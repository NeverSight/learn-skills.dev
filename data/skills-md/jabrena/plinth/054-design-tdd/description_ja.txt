テスト駆動開発（TDD）に基づいて Java 実装作業を行うべき場合に使用します。テストリストの管理、次に実装すべき動作の選択、失敗するテストを最初に作成し、合格するために必要最低限の本番コードだけを実装し、テストが緑のままリファクタリングを行うことを含みます。以下のようなリクエストでトリガーされます：Apply TDD、Use test-driven development、Drive this Java change with tests、Write the failing test first、Red‑green‑refactor this feature。Plinth Toolkit の一部です。
