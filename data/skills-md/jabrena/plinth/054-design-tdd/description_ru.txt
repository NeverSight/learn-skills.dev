Используйте, когда работа по реализации на Java должна руководствоваться разработкой через тестирование (TDD), включая ведение списка тестов, выбор следующего поведения, написание сначала падающего теста, реализацию только необходимого кода для прохождения теста и рефакторинг при сохранении всех тестов в зеленом статусе. Это должно срабатывать на запросы вроде: «Применить TDD», «Использовать разработку через тестирование», «Вести изменения в Java с помощью тестов», «Сначала написать падающий тест», «Red‑green‑refactor эту функцию». Часть набора инструментов Plinth.
