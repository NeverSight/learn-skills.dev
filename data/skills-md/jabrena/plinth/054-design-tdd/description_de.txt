Verwenden Sie dies, wenn die Java‑Implementierungsarbeit durch testgetriebene Entwicklung (Test‑Driven Development, TDD) geleitet werden soll, einschließlich der Pflege einer Testliste, der Auswahl des nächsten Verhaltens, dem Schreiben eines zunächst fehlschlagenden Tests, der Implementierung gerade genug Produktionscode, um den Test zu bestehen, und dem Refactoring, wobei die Tests grün bleiben. Dies sollte bei Anfragen wie „Apply TDD“, „Use test‑driven development“, „Drive this Java change with tests“, „Write the failing test first“, „Red‑green‑refactor this feature“ ausgelöst werden.
