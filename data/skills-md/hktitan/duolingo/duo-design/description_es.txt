Patrones de UI del sistema de diseño de Duolingo — animación jugosa, el sistema de personajes como canal emocional, tokens de diseño (color/tipo/espaciado), el sonido como superficie de UX, accesibilidad como predeterminado, no como lista de verificación, y el detalle de “error‑como‑deleite”. Úsalo cuando el usuario esté diseñando una pantalla para un producto gamificado o de aprendizaje, revisando un diseño para “¿por qué esto se siente plano?”, eligiendo un sistema de animación, creando una mascota de personaje o auditando la accesibilidad. Esta habilidad posee la *racionalidad* del diseño; la artesanía de píxeles (valores de easing, ratios de contraste, propiedades de componentes) se dirige a la habilidad de diseño‑ingeniería.
