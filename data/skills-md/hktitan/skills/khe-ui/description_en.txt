Builds or judges a screen against exact values and ends a review with a verdict. Use when someone says "review this component", "is this well built", "it works but feels unfinished", "make it feel right", "this looks AI-generated", "which easing", "the page jumps", "is this accessible", "feels like a website on my phone", "are we ready to ship", or is building a screen, a form, a card or a page, or styling one built on Vercel's UI SDK. For an SVG use `khe-svg`; for sound use `khe-sound`; for a launch video use `khe-launch-film`; for a `.design` file or DESIGN.md use `khe-design-tokens`.
