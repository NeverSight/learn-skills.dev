The mode that runs the rest. Reads a request, picks a playbook or the one or two skills that own it, says why in a line, then does the work in order. Covers every skill in this collection: the khe skills (UI craft, design tokens, SVG, diagrams, sound, launch films), the skills by Emil Kowalski and Benji Taylor linked beside them, Vercel's `ui-sdk` and agent skills, and the engineering skills of Lauren Tan (poteto) and Matt Pocock. Use when a request names no skill, spans several, or someone says "auto", "which skill", "where do I start", "what order", "list the skills", "make this better", "I need a launch video", "build this screen", "build it with ui-sdk", "we ship Thursday", "the agent keeps doing this". When the request already names a skill, use that skill.
