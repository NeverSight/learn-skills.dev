사용자의 클립보드에 있는 이미지를 대화에 끌어와 실제로 확인할 수 있게 합니다. 로컬 브리지는 클립보드를 사용자별 Unix 소켓($HOME/.clipboard.sock; CLIPBOARD_SOCKET 로 재정의 가능)으로 노출합니다; 이 기능은 바이트 데이터를 가져와 실제 이미지 파일로 저장하고 해당 파일을 컨텍스트에 읽어들입니다. 사용자가 여러분이 볼 수 없는 시각적 자료를 가리킬 때마다 사용하세요—“내 클립보드 보세요”, “방금 스크린샷을 찍었어요”, “이 오류 좀 봐”, “왜 이렇게 보이죠”, “디자인이에요”, “붙여넣기를 보세요” 등— 사용자가 복사했다고 암시만 할 때도, 파일 경로를 제공하지 않고 화면 내용을 설명할 때도 포함합니다. 추측하거나 사진을 설명해 달라고 요청하거나 먼저 파일을 저장해 달라고 요구하는 대신 이 기능을 사용하세요.

항상 사용자의 언어로 답변해 주세요.
