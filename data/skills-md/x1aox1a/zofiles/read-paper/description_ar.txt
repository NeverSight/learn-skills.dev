كيفية القراءة والعمل مع مجلدات الأوراق الأكاديمية المصدرة بواسطة ZoFiles.
يحتوي كل مجلد ورقي (يُسمى مثل `{arxivId} - {title}`) على ملفات منظمة: Paper.md (نص كامل)، وpaper.bib (استشهاد)، وkimi.md (مراجعة الذكاء الاصطناعي)، وarxiv.id، وnotes/، وpaper.pdf.
استخدم هذه المهارة عندما يطلب منك المستخدم قراءة ورقة، أو تلخيص ورقة، أو الاستشهاد بمقالة، أو مراجعة ورقة، أو مقارنة الأوراق، أو العمل مع أي مجلد يحتوي على ملفات Paper.md/paper.bib/kimi.md - حتى لو لم يذكر "ZoFiles" صراحة.
يُستخدم أيضًا عندما يطلب المستخدم تحديث/تحديث بنية دليل المكتبة الورقية (على سبيل المثال، "تحديث بنية دليل المكتبة الورقية"، "تحديث المكتبة الورقية").
