اعتماد (إرسال مراجعة موافقة) ودمج PR بنظام squash باستخدام رقمها فقط، مع الرفض إذا كانت بوابة QA أو تسمية حظر تمنع ذلك. يتم توجيه العوائق القابلة للإصلاح إلى xez-auto-fix-pr (CI أحمر عبر وضع ‎--ci-only‎ الخاص به، أو النزاعات ومشكلات المراجعة عبر الحلقة الكاملة). يمكن اختيارياً فتح قضية متابعة في الوقت نفسه. استخدم ذلك عندما يقول المستخدم «اعتمد ودمج PR 123»، «أرسل PR 123»، أو يقدّم رقم PR بنية الدمج.
