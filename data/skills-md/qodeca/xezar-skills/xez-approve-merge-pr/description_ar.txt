قم بالموافقة (تقديم مراجعة موافقة) ودمج PR باستخدام squash عندما يُعطى رقم PR فقط، مع الرفض إذا حظرت بوابة QA أو علامة حظر ذلك. يتم توجيه العوائق القابلة للإصلاح إلى xez-auto-fix-pr (CI أحمر عبر وضعه ‎--ci-only‎، أو النزاعات ومشكلات المراجعة عبر الحلقة الكاملة). يمكن اختيارياً إنشاء قضية متابعة في الوقت نفسه. استخدم ذلك عندما يقول المستخدم "وافق ودمج PR 123"، أو "أرسل PR 123"، أو يزوّد برقم PR بنية الدمج.
