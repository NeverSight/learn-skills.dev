Aprobar (enviar una revisión aprobatoria) y hacer squash‑merge de un PR dado solo su número, rechazando cuando la puerta de QA o una etiqueta bloqueadora lo prohiben. Dirige los bloqueadores corregibles a xez-auto-fix-pr (CI roja mediante su modo --ci-only, o conflictos y problemas de revisión mediante el bucle completo). Opcionalmente crea un issue de seguimiento al mismo tiempo. Úsalo cuando el usuario dice "approve and merge PR 123", "ship PR 123", o proporciona un número de PR con intención de fusionarlo.
