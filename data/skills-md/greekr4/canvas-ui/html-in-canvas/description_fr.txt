Travail global de rendu d’un DOM vivant sur canvas/WebGL/three.js en utilisant l’API HTML‑dans‑Canvas (drawElementImage). Utilisé pour les requêtes liées à « HTML dans canvas », « drawElementImage », « dessin du DOM sur canvas », « entrée dans le canvas », « DOM comme texture » et à la bibliothèque CanvasUI. Fournit des règles d’évitement de pièges soigneusement vérifiées et un code squelette standard.

Veuillez toujours répondre dans la langue de l’utilisateur.
