العملية العامة لرسم DOM حي على canvas/WebGL/three.js باستخدام واجهة HTML‑in‑Canvas API (drawElementImage). تُستخدم لطلبات تتعلق بـ “HTML في canvas”، “drawElementImage”، “رسم DOM على canvas”، “الإدخال داخل canvas”، “DOM كنسيج”، ومكتبة CanvasUI. توفر قواعد تجنب الفخاخ التي تم التحقق منها تجريبياً وكود هيكلي قياسي.
