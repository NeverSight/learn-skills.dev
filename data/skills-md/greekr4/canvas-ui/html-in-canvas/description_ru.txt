Общий процесс отрисовки живого DOM на canvas/WebGL/three.js с использованием API HTML‑in‑Canvas (drawElementImage). Используется для запросов, связанных с «HTML в canvas», «drawElementImage», «отрисовка DOM на canvas», «ввод внутри canvas», «DOM в виде текстуры» и библиотекой CanvasUI. Предоставляет эмпирически проверенные правила избегания ловушек и стандартный шаблонный код.
