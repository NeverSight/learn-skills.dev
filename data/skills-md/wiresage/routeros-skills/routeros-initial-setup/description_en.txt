First-time setup and configuration management for a MikroTik RouterOS device. Covers reaching a new or reset router, the factory default configuration, building the network by hand when there is none (bridge, LAN address, DHCP server), WAN setup with DHCP client, static address or PPPoE, source NAT and port forwarding, the hardening checklist (users, passwords, services, MAC access, neighbor discovery), backup and restore, export and import, undo, safe mode, and configuration reset. Use when setting up, resetting, hardening, backing up or cloning a router, or when asked how a router should be configured out of the box.
