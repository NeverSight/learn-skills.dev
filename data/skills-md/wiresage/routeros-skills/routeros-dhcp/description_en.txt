DHCP on MikroTik RouterOS 7. Covers the DHCPv4 server (servers, pools, networks, leases, static leases, rate limits, options and option sets, DNS entries for clients, RADIUS, rogue-server alerts), the DHCPv4 client (default route, peer DNS and NTP, scripts for multi-WAN), DHCP relay, and DHCPv6 client and server with prefix delegation and router advertisements. Use when handing out or obtaining addresses, reserving an address for a host, sending custom options, relaying across routers, requesting an IPv6 prefix from an ISP, or when clients do not get an address or get the wrong settings.
