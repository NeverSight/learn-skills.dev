Optional network services on MikroTik RouterOS 7. Covers the MikroTik cloud (IP Cloud DDNS, time update, cloud backup, Back To Home VPN, File Share) and which connections RouterOS makes to MikroTik servers, the web proxy and transparent proxy, the HTTPS reverse proxy, the SOCKS server and Socksify, and OpenFlow. Use when giving a router a dynamic DNS name, reaching a router behind NAT, storing a cloud backup, publishing web servers by host name, filtering or caching web requests, running or consuming a SOCKS proxy, or disabling cloud and proxy services during hardening.
