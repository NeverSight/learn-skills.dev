DNS on MikroTik RouterOS 7. Covers using the router as the network's resolver and cache, upstream and dynamic servers, static entries (A, AAAA, CNAME, MX, TXT, NXDOMAIN, FWD, regular expressions), forwarders and per-domain forwarding, address lists filled from DNS names, ad blocking with adlists, DNS over HTTPS, the mDNS repeater, VRF, cache and timeout settings, closing the open-resolver hole, and the RFC 2136 DNS update tool. Use when clients cannot resolve names, when setting upstream or local names, blocking or redirecting domains, using domain names in firewall or routing rules, or hardening a router that answers DNS.
