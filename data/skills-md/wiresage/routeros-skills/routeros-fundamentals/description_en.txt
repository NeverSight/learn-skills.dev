Core knowledge for working with MikroTik RouterOS 7, the entry point to the other routeros-* skills. Covers CLI syntax and the menu hierarchy, item names versus numbers, print and find filters, argument types, safe mode, undo and redo, export and import, and the rules for changing a live router without locking yourself out. Use when starting any RouterOS or MikroTik task, when unsure which RouterOS skill applies, when asked what a console command or argument type means, or before running configuration commands on a real device.
