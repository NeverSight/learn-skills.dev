User Manager on MikroTik RouterOS 7, the built-in RADIUS server and user database. Covers enabling it and its package and licence limits, registering routers (NAS devices) with shared secrets and RadSec, users and groups, allowed outer and inner authentication methods (PAP, CHAP, MS-CHAP, EAP-TLS, TTLS, PEAP), profiles with limitations (rate, traffic, uptime, time windows), assigning profiles to users, RADIUS attributes (static IP, address pool, rate limit), sessions and accounting, vouchers and batch users, TOTP, the /um web interface and PayPal payments, and migration from RouterOS 6. Use when a RouterOS device should act as the RADIUS server for HotSpot, PPP, wireless 802.1X or DHCP, or when selling or limiting access by time and volume.
