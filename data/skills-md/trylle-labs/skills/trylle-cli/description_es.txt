Operar la plataforma git Trylle con la CLI oficial `try`. Utilícelo cuando un agente necesite autenticarse en Trylle; inspeccionar o gestionar repositorios, pull requests, incidencias, PR apilados, CI, secretos o variables de acciones, organizaciones, perfiles, claves SSH, automatizaciones o bots; imprimir URLs web de Trylle; llamar a un endpoint de API pública no cubierto; o usar la IA de Trylle, los comandos explain, draft y diff.
