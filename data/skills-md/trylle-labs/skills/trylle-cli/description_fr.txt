Utilisez la plateforme Git Trylle avec le CLI officiel `try`. Utilisez-le lorsqu'un agent doit s'authentifier à Trylle ; inspecter ou gérer les dépôts, les pull requests, les tickets, les PR empilées, le CI, les secrets ou variables d’actions, les organisations, les profils, les clés SSH, les automatisations ou les bots ; afficher les URL web de Trylle ; appeler un point de terminaison d’API public non couvert ; ou utiliser l’IA de Trylle, les commandes explain, draft et diff.

Veuillez toujours répondre dans la langue de l'utilisateur.
