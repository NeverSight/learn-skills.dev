تشغيل منصة Trylle للـ git باستخدام سطر الأوامر الرسمي `try`. استخدمه عندما يحتاج وكيل إلى المصادقة على Trylle؛ فحص أو إدارة المستودعات، طلبات السحب، القضايا، طلبات السحب المتسلسلة، CI، أسرار الإجراءات أو متغيراتها، المنظمات، الملفات الشخصية، مفاتيح SSH، الأتمتة أو الروبوتات؛ طباعة عناوين URL لموقع Trylle؛ استدعاء نقطة نهائية عامة غير مُغطَّاة؛ أو استخدام الذكاء الاصطناعي الخاص بـ Trylle، وأوامر الشرح، والمسودة، والفرق.
