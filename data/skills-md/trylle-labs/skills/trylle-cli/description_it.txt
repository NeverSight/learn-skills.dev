Operare la piattaforma git Trylle con il CLI ufficiale `try`. Usare quando un agente deve autenticarsi a Trylle; ispezionare o gestire repository, pull request, issue, PR impilati, CI, segreti o variabili delle actions, organizzazioni, profili, chiavi SSH, automazioni o bot; stampare gli URL web di Trylle; chiamare un endpoint API pubblico non coperto; oppure utilizzare l'IA di Trylle e i comandi explain, draft e diff.
