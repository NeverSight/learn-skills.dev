Verwenden Sie diese Option, wenn eine Anfrage eine umfassende Begründung, die Zusammenfassung von Belegen, die Beseitigung von Unsicherheiten, eine Planung oder die Abwägung sinnvoller Alternativen erfordert, unabhängig vom Bereich und davon, ob das Ergebnis eine Antwort, eine Empfehlung, ein Artefakt oder eine Handlung ist. Verwenden Sie es auch für explizites Brainstorming, Stresstests einer Idee oder Entscheidung oder ein geführtes Gespräch, um einen Plan zu klären. Lassen Sie einfache Nachschläge von Fakten und offensichtliche mechanische Aufgaben aus.
