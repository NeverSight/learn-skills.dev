Utilícelo cuando una solicitud requiera un razonamiento sustancial, la síntesis de evidencias, la resolución de incertidumbres, la planificación o la evaluación de alternativas significativas, independientemente del ámbito o de si el resultado es una respuesta, una recomendación, un producto o una acción. Úselo también para hacer una lluvia de ideas explícita, poner a prueba una idea o una decisión o realizar una entrevista guiada para aclarar un plan. Omita las búsquedas sencillas de datos y las tareas mecánicas obvias.
