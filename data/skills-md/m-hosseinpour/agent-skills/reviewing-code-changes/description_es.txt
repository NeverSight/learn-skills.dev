Utilícese al revisar un PR, una solicitud de fusión, una rama, un parche o cambios no confirmados en busca de defectos, regresiones, cumplimiento de requisitos o idoneidad para la fusión; cuando se solicite una revisión independiente de un cambio; o antes de efectuar cambios de gran alcance en el comportamiento, contratos públicos, seguridad o datos persistentes. No es para auditorías de código sin modificaciones, recorridos solo explicativos, formateo de hallazgos existentes, recibir retroalimentación de revisión o ediciones mecánicas rutinarias sin una solicitud de revisión.
