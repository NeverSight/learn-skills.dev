Utilizzare quando si esamina un PR, una merge request, un branch, una patch o modifiche non ancora commesse per difetti, regressioni, conformità ai requisiti o prontezza al merge; quando viene richiesto un controllo indipendente di una modifica; o prima di apportare cambiamenti consequenziali al comportamento, ai contratti pubblici, alla sicurezza o ai dati persistenti. Non per audit di codice invariato, walkthrough solo esplicativi, formattazione dei risultati esistenti, ricezione di feedback di revisione o modifiche meccaniche di routine senza una richiesta di revisione.
