Verwenden Sie dies, wenn Sie einen Pull‑Request, Merge‑Request, Branch, Patch oder nicht committete Änderungen auf Fehler, Regressionen, Anforderungskonformität oder Merge‑Bereitschaft prüfen; wenn Sie um eine unabhängige Begutachtung einer Änderung gebeten werden; oder bevor Sie folgerichtige Änderungen am Verhalten, an öffentlichen Schnittstellen, an der Sicherheit oder an persistierten Daten vornehmen. Nicht verwenden für Audits unveränderten Codes, rein erklärende Durchläufe, das Formatieren bestehender Befunde, das Empfangen von Review‑Feedback oder routinemäßige mechanische Änderungen ohne Review‑Anfrage.

Bitte immer in der Sprache des Benutzers antworten.
