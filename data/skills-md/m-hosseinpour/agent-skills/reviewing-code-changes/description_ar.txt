يُستخدم عند مراجعة طلب سحب (PR) أو طلب دمج أو فرع أو تصحيح أو تغييرات غير مُلتزمة للتحقق من العيوب أو الانحدارات أو توافق المتطلبات أو جاهزية الدمج؛ عند طلب مراجعة مستقلة لتغيير ما؛ أو قبل إكمال تغييرات ذات تبعات على السلوك أو العقود العامة أو الأمان أو البيانات المُخزنة. لا يُستخدم لتدقيقات الكود غير المتغير، أو شروحات توضيحية فقط، أو تنسيق النتائج الحالية، أو استلام ملاحظات المراجعة، أو تعديلات ميكانيكية روتينية دون طلب مراجعة.
