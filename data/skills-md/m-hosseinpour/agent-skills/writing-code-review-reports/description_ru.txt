Используйте, когда результаты существующего код‑ревью требуют отчёта для автора, исправлений, точного перевода или консолидации мнений разных рецензентов; также на этапе составления отчёта по запросу «ревью‑и‑отчёт», включая ревью без найденных проблем. Не предназначено для проверки кода, исправления найденных проблем, ответа на обратную связь по ревью, объяснительных проходов без кода или краткого ответа на ревью без запрашиваемой передачи.
