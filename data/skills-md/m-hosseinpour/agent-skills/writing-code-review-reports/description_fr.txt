À utiliser lorsque les résultats d’une revue de code existants nécessitent un rapport de remise destiné à l’auteur, une révision, une traduction fidèle ou une consolidation entre les réviseurs ; également à l’étape de reporting d’une demande de revue‑et‑rapport, y compris les revues sans constats. Pas pour inspecter le code, corriger les constats, répondre aux retours de la revue, des passages explicatifs uniquement, ou une réponse brève à la revue sans remise demandée.

Veuillez toujours répondre dans la langue de l’utilisateur.
