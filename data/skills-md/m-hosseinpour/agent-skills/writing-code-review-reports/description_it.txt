Utilizzare quando i risultati della revisione del codice esistenti richiedono un rapporto di consegna rivolto all'autore, una revisione, una traduzione fedele o un consolidamento tra revisori; anche nella fase di report di una richiesta di revisione‑e‑rapporto, incluse le revisioni senza riscontri. Non è destinato a ispezionare il codice, correggere i riscontri, rispondere al feedback della revisione, walkthrough solo esplicativi o a una breve risposta di revisione senza una consegna richiesta.
