Verwenden Sie diese Option, wenn das Abrufen einer Seite fehlschlägt, weil die Website in diesem Netzwerk blockiert, geoblockiert oder sanktioniert ist (Timeouts, Verbindungsabbrüche, 403 aus der Region) – unabhängig davon, ob das Abrufen von einem MCP-Server, einem Browser oder dem in das Harness integrierten Seitenleser erfolgte; wenn eine über den Tunnel geleitete Domain weiterhin fehlschlägt und das Gateway, die geleiteten Domains oder die Verkabelung überprüft werden müssen; oder wenn der Benutzer darum bittet, eine Domain über seine VLESS-/Trojan-Konfigurationen zu erreichen, ohne das gesamte System zu tunneln.
