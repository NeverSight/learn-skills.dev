À utiliser lorsqu’une récupération de page échoue parce que le site est bloqué, soumis à des restrictions géographiques ou sanctionné sur ce réseau (dépassements de délai, réinitialisations de connexion, code 403 de la région), que la récupération provienne d’un serveur MCP, d’un navigateur ou du lecteur de page intégré du harness ; lorsqu’un domaine acheminé via le tunnel échoue toujours et que la passerelle, les domaines acheminés ou le câblage doivent être vérifiés ; ou lorsque l’utilisateur demande à accéder à un domaine via ses configurations VLESS/Trojan sans tunneliser l’ensemble du système.
