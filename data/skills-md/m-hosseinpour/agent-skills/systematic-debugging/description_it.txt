Usa durante l'investigazione o la correzione di un bug, regressione, test falloso o instabile, errore di build o di distribuzione, problema di prestazioni o output errato; anche quando ti chiedono perché è avvenuto un fallimento. Non è destinato alla progettazione di funzionalità, alla spiegazione di codice senza errori, né all'applicazione di una correzione già verificata senza nuove incertezze. Per favore rispondi sempre nella lingua dell'utente.
