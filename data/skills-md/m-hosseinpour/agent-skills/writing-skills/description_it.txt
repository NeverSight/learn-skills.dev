Usare quando si crea, si revisiona o si migliora una skill di agente; si trasforma un flusso di lavoro ripetibile in una skill; si indaga su caricamenti di skill mancati o indesiderati; o si modifica il file SKILL.md, i riferimenti o gli script di supporto di una skill in modi che influiscono sull'uso. Non è destinato all'installazione o all'applicazione di una skill esistente, alla spiegazione del formato o a modifiche meccaniche che ne preservano il significato e il comportamento.

Rispondi sempre nella lingua dell'utente.
