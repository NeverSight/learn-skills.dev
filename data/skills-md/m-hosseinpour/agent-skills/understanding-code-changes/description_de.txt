Verwende diese Methode, wenn du einen Pull Request, einen Merge Request, einen Branch oder einen Diff verstehen oder erklären musst, anstatt ihn zu beurteilen – insbesondere, wenn du dich mit unbekanntem Code befasst, eine Änderung in der Architektur des Projekts ausfindig machst oder dich vor der Überprüfung einer großen Änderung orientieren möchtest.
