Verwenden Sie dies, wenn Delegation verfügbar und erlaubt ist und eine Aufgabe mehrere wesentliche Arbeitsstränge hat, die unabhängig sein können, wenn parallele Agentenarbeit angefordert wird oder bevor Sie einen Sub‑Agenten zusammen mit Ihrer eigenen Arbeit oder anderen Sub‑Agenten ausführen. Nicht für kleine mehrstufige Aufgaben, parallele Werkzeugaufrufe oder einen einzigen Delegaten, auf den Sie einfach warten werden.
