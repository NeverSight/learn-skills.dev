Полный набор SDK протокола Switchboard Oracle для Solana — децентрализованное решение Oracle для ценовых фидов, данных по запросу, случайности VRF и потоковой передачи в реальном времени через Surge. Охватывает SDK на TypeScript, интеграцию с Rust, Oracle Quotes и все инструменты Switchboard.
