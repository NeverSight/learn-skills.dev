Curve Finance AMM — пулы StableSwap для привязанных активов, CryptoSwap (Tricrypto) для волатильных пар, стейблкойн crvUSD с мягкой ликвидацией LLAMMA, голосование по gauge для эмиссии CRV, фабричные пулы и стейкинг LP‑токенов. Включает интерфейсы пулов (exchange, add_liquidity, remove_liquidity), Router для оптимального маршрутизации и систему gauge в сети Ethereum mainnet.
