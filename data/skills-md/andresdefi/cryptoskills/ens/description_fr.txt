Développement ENS (Ethereum Name Service) — résolution de nom, enregistrement via commit-reveal, enregistrements de texte/adresse, résolution inverse, récupération d'avatar, sous-domaines et intégration Name Wrapper. Couvre les actions ENS intégrées de viem, les modèles de résolveur, la CCIP-Read pour les données hors chaîne et les interactions contractuelles avec le registre ENS sur le réseau principal Ethereum.
