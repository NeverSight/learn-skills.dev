Разработка ENS (Ethereum Name Service) — разрешение имён, регистрация через commit‑reveal, текстовые/адресные записи, обратное разрешение, получение аватара, субдомены и интеграция Name Wrapper. Охватывает встроенные действия ENS в viem, шаблоны резольверов, CCIP‑Read для офчейн‑данных и взаимодействие с реестром ENS в основной сети Ethereum.
