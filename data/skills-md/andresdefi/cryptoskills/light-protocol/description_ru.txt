Полное руководство по Light Protocol на Solana — включает ZK‑компрессию для бесплатных сжатых токенов и PDA с использованием доказательств с нулевым разглашением, а также Light Token Program — высокопроизводительный токен‑стандарт (в 200 раз дешевле, чем SPL). Охватывает TypeScript SDK, методы JSON RPC и полные шаблоны интеграции.
