Полностью автоматический режим — для каждой проблемы запускается tdd2, а затем aacpd, одна задача полностью завершается (внедрить+проверить+объединить+push+deploy) перед запуском следующей, без пакетной обработки и без запроса в середине выполнения. Без номеров задач перечисляет все, что осталось в Issues/, и один раз спрашивает, нужно ли просмотреть все это. При желании каждая задача запускается в отдельном рабочем дереве git (ключевое слово «worktree») для изоляции — по-прежнему по одной задаче за раз, каждая из которых объединяется с основной сразу перед запуском следующей. Используйте, когда пользователь говорит «/autotdd», «autotdd».
