「package:path」と「package:file」を使用した、クロスプラットフォームのファイルとディレクトリのパス操作、セグメント分割、拡張子の抽出、およびコンテキスト変換。ファイル パス、ディレクトリ名、または拡張子の書き込み、検査、結合、分割、リファクタリングを行う場合、または生の文字列パス操作 (`.split('/')`、`'$dir/$file'`、`.endsWith('.ext')`、`.replaceAll('\\'、'/')`) を置換する場合に使用します。 HTTP ネットワーク URI ルーティング、データベース クエリ文字列、またはパス文字列以外の処理には使用しないでください。
