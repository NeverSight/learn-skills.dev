معالجة مسار الملفات والدليل عبر الأنظمة الأساسية، وتقسيم المقاطع، واستخراج الامتدادات، وتحويل السياق باستخدام `package:path` و`package:file`. يُستخدم عند كتابة مسارات الملفات أو أسماء الدلائل أو الامتدادات أو فحصها أو ضمها أو تقسيمها أو إعادة هيكلتها، أو استبدال عمليات مسار السلسلة الأولية (`.split('/')`, `'$dir/$file'`, `.endsWith('.ext')`, `.replaceAll('\\', '/')`). لا تستخدمه لتوجيه URI لشبكة HTTP، أو سلاسل استعلام قاعدة البيانات، أو معالجة سلسلة غير المسار.
