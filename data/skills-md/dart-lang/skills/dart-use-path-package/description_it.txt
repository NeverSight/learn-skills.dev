Manipolazione di percorsi di file e directory multipiattaforma, suddivisione di segmenti, estrazione di estensioni e conversione del contesto utilizzando "pacchetto:percorso" e "pacchetto:file". Da utilizzare durante la scrittura, l'ispezione, l'unione, la divisione o il refactoring di percorsi di file, nomi di directory o estensioni oppure durante la sostituzione di operazioni di percorso di stringhe non elaborate (`.split('/')`, `'$dir/$file'`, `.endsWith('.ext')`, `.replaceAll('\\', '/')`). Non utilizzare per il routing dell'URI di rete HTTP, le stringhe di query del database o l'elaborazione di stringhe diverse dal percorso.
