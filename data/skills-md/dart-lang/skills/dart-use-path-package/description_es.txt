Manipulación de rutas de directorios y archivos multiplataforma, división de segmentos, extracción de extensiones y conversión de contexto utilizando `paquete:ruta` y `paquete:archivo`. Úselo al escribir, inspeccionar, unir, dividir o refactorizar rutas de archivos, nombres de directorios o extensiones, o al reemplazar operaciones de rutas de cadenas sin formato (`.split('/')`, `'$dir/$file'`, `.endsWith('.ext')`, `.replaceAll('\\', '/')`). No lo use para enrutamiento de URI de red HTTP, cadenas de consulta de bases de datos o procesamiento de cadenas sin ruta.
