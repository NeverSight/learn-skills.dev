How to write Conventional Commits (v1.0.0 spec, https://www.conventionalcommits.org/en/v1.0.0/) - project-agnostic. Covers the type(scope) message grammar, the type vocabulary, how BREAKING CHANGE is expressed, and how this maps directly to SemVer bumps. Use when writing a commit message, setting up commit-lint tooling, or reviewing commit history for a release.
