So schreiben Sie konventionelle Commits (v1.0.0-Spezifikation, https://www.conventionalcommits.org/en/v1.0.0/) – projektunabhängig. Behandelt die Typ-(Umfangs-)Nachrichtengrammatik, das Typvokabular, wie BREAKING CHANGE ausgedrückt wird und wie dies direkt auf SemVer-Bumps abgebildet wird. Verwenden Sie diese Option, wenn Sie eine Commit-Nachricht schreiben, Commit-Lint-Tools einrichten oder den Commit-Verlauf für eine Version überprüfen.
