So schreiben und pflegen Sie eine CHANGELOG.md im Keep a Changelog 1.1.0-Format (https://keepachangelog.com/en/1.1.0/) – projektunabhängig. Deckt die sechs Änderungskategorien, den Abschnitt „Unveröffentlicht“, Versions-/Datumsüberschriften, Vergleichslinks und gelöschte Veröffentlichungen ab. Verwenden Sie diese Option, wenn Sie eine neue CHANGELOG.md erstellen, einen Eintrag für eine Version hinzufügen oder eine Version auf Formatkonformität überprüfen.
