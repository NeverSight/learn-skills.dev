Cómo aplicar y hacer referencia al Estándar de verificación de seguridad de aplicaciones (ASVS) de OWASP v5.0.0 (https://owasp.github.io/www-project-application-security-verification-standard/): independiente del proyecto. Cubre los tres niveles de verificación (L1/L2/L3) y cómo elegir uno, los 17 capítulos de requisitos (codificación, validación, interfaz, API, manejo de archivos, autenticación, administración de sesiones, autorización, tokens, OAuth/OIDC, criptografía, comunicación segura, configuración, protección de datos, codificación segura, registro, WebRTC), la numeración `<capítulo>.<sección>.<requisito>` y el formato de referencia versionada, requisitos de documentación versus implementación. requisitos y cómo se verifica realmente el cumplimiento. Úselo al diseñar los controles de seguridad de una aplicación, decidir qué requisitos de seguridad se aplican a una característica o base de código, escribir o revisar una lista de verificación de requisitos de seguridad, asignar hallazgos a ID de requisitos de ASVS o evaluar/informar el cumplimiento de ASVS.
