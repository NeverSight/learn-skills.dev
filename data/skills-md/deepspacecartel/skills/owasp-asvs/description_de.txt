So wenden Sie den OWASP Application Security Verification Standard (ASVS) v5.0.0 (https://owasp.github.io/www-project-application-security-verification-standard/) an und referenzieren ihn – projektunabhängig. Behandelt die drei Verifizierungsstufen (L1/L2/L3) und wie man eine auswählt, die 17 Anforderungskapitel (Kodierung, Validierung, Frontend, API, Dateiverarbeitung, Authentifizierung, Sitzungsverwaltung, Autorisierung, Tokens, OAuth/OIDC, Kryptografie, sichere Kommunikation, Konfiguration, Datenschutz, sichere Kodierung, Protokollierung, WebRTC), die Nummerierung „<chapter>.<section>.<requirement>“ und das versionierte Referenzformat, Dokumentationsanforderungen vs. Umsetzungsanforderungen und wie die Einhaltung tatsächlich überprüft wird. Verwenden Sie diese Option, wenn Sie die Sicherheitskontrollen einer Anwendung entwerfen, entscheiden, welche Sicherheitsanforderungen für eine Funktion oder Codebasis gelten, eine Checkliste für Sicherheitsanforderungen schreiben oder überprüfen, Ergebnisse ASVS-Anforderungs-IDs zuordnen oder die ASVS-Konformität bewerten/melden.
