OWASP Application Security Verification Standard (ASVS) v5.0.0 (https://owasp.github.io/www-project-application-security-verification-standard/) を適用および参照する方法 - プロジェクトに依存しない。 3 つの検証レベル (L1/L2/L3) とその選択方法、17 の要件の章 (エンコーディング、検証、フロントエンド、API、ファイル処理、認証、セッション管理、認可、トークン、OAuth/OIDC、暗号化、安全な通信、構成、データ保護、安全なコーディング、ロギング、WebRTC)、「<章>.<セクション>.<要件>」の番号付けとバージョン参照形式、ドキュメントをカバーします。要件と実装要件、およびコンプライアンスが実際にどのように検証されるか。アプリケーションのセキュリティ制御の設計、機能またはコードベースに適用するセキュリティ要件の決定、セキュリティ要件チェックリストの作成またはレビュー、結果を ASVS 要件 ID にマッピングする場合、または ASVS コンプライアンスの評価/報告する場合に使用します。
