OWASP 애플리케이션 보안 검증 표준(ASVS) v5.0.0(https://owasp.github.io/www-project-application-security-verification-standard/)을 적용하고 참조하는 방법 - 프로젝트에 구애받지 않습니다. 세 가지 검증 수준(L1/L2/L3)과 하나를 선택하는 방법, 17개 요구 사항 장(인코딩, 검증, 프런트엔드, API, 파일 처리, 인증, 세션 관리, 승인, 토큰, OAuth/OIDC, 암호화, 보안 통신, 구성, 데이터 보호, 보안 코딩, 로깅, WebRTC), `<장>.<섹션>.<요구 사항>` 번호 지정 및 버전 참조 형식, 문서 요구 사항과 구현 요구 사항 및 방법을 다룹니다. 실제로 규정 준수가 확인되었습니다. 애플리케이션의 보안 제어를 설계하고, 기능이나 코드베이스에 적용할 보안 요구 사항을 결정하고, 보안 요구 사항 체크리스트를 작성 또는 검토하고, 결과를 ASVS 요구 사항 ID에 매핑하거나 ASVS 규정 준수를 평가/보고할 때 사용합니다.
