Comment concevoir et examiner les charges utiles d'événements selon la spécification CloudEvents v1.0 (https://cloudevents.io/, un projet gradué CNCF) - indépendant du projet. Couvre les attributs de contexte requis/facultatifs/d'extension (id, source, specversion, type, time, subject, datacontenttype, dataschema), le système de types abstraits, le format d'événement JSON (mode structuré ou batch, data vs data_base64), les liaisons de protocole (en-têtes HTTP binaires/structurés, Kafka, AMQP, MQTT, NATS, WebSockets), les extensions documentées (traçage distribué, partitionnement, séquence, sampledrate, dataref) et les conseils de versionnage de l’amorce. À utiliser lors de la conception ou de la révision d'un schéma d'événement, d'une charge utile de webhook, d'un format de message de file d'attente de messages/bus d'événements ou de toute « enveloppe » pour les systèmes pilotés par des événements/pub-sub, ou lorsqu'il est demandé de rendre les événements interopérables entre producteurs/consommateurs/courtiers.
