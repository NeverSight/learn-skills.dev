Cómo diseñar y revisar cargas útiles de eventos según la especificación CloudEvents v1.0 (https://cloudevents.io/, un proyecto graduado de CNCF): independiente del proyecto. Cubre los atributos de contexto requeridos/opcionales/de extensión (id, fuente, versión de especificación, tipo, hora, asunto, tipo de contenido de datos, esquema de datos), el sistema de tipos abstractos, el formato de evento JSON (modo estructurado versus modo por lotes, datos versus base de datos64), enlaces de protocolo (encabezados de modo binario/estructurado HTTP, Kafka, AMQP, MQTT, NATS, WebSockets), extensiones documentadas (rastreo distribuido, partición, secuencia, frecuencia de muestreo, dataref) y guía de versiones del manual. Úselo al diseñar o revisar un esquema de evento, carga útil de webhook, formato de mensaje de cola de mensajes/bus de eventos o cualquier "sobre" para sistemas impulsados ​​por eventos/pub-sub, o cuando se le solicite que los eventos sean interoperables entre productores/consumidores/corredores.
