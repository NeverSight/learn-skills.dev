How to design and review event payloads per the CloudEvents specification v1.0 (https://cloudevents.io/, a CNCF graduated project) - project-agnostic. Covers the required/optional/extension context attributes (id, source, specversion, type, time, subject, datacontenttype, dataschema), the abstract type system, the JSON event format (structured vs. batched mode, data vs. data_base64), protocol bindings (HTTP binary/structured mode headers, Kafka, AMQP, MQTT, NATS, WebSockets), documented extensions (distributed tracing, partitioning, sequence, sampledrate, dataref), and versioning guidance from the primer. Use when designing or reviewing an event schema, webhook payload, message-queue/event-bus message format, or any "envelope" for event-driven/pub-sub systems, or when asked to make events interoperable across producers/consumers/brokers.
