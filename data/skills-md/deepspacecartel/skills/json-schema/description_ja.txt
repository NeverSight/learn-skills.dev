2020-12 仕様 (https://json-schema.org/draft/2020-12) に従って JSON スキーマ ドキュメントを作成およびレビューする方法 - プロジェクトに依存しない。ブールスキーマ、コア語彙 ($schema、$id、$ref、$anchor、$dynamicRef/$dynamicAnchor、$defs、$vocabulary、$comment)、各 JSON タイプの検証キーワード、アプリケーター (allOf/anyOf/oneOf/not/if-then-else)、unevaluatedProperties/unevaluatedItems、アノテーション (title、説明、デフォルト、例、非推奨、読み取り専用、書き込み専用）、および形式/コンテンツの語彙。 JSON (構成ファイル、API リクエスト/応答本体、イベント ペイロード) を検証するためのスキーマを作成する場合、仕様準拠のためのスキーマをレビューする場合、ドキュメントが検証されるか検証されない理由をデバッグする場合、または再帰的/拡張可能なスキーマで $ref と $dynamicRef のどちらを使用するかを決定する場合に使用します。
