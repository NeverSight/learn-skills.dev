Comment rédiger et réviser des documents de schéma JSON selon la spécification 2020-12 (https://json-schema.org/draft/2020-12) - indépendant du projet. Couvre les schémas booléens, le vocabulaire de base ($schema, $id, $ref, $anchor, $dynamicRef/$dynamicAnchor, $defs, $vocabulary, $comment), les mots-clés de validation pour chaque type JSON, les applicateurs (allOf/anyOf/oneOf/not/if-then-else), les propriétés non évaluées/les éléments non évalués, les annotations (titre, description, valeur par défaut, exemples, obsolète, readOnly, writeOnly) et les vocabulaires format/contenu. À utiliser lors de l'écriture d'un schéma pour valider JSON (fichiers de configuration, corps de requête/réponse d'API, charges utiles d'événement), pour vérifier la conformité d'un schéma aux spécifications, pour déboguer pourquoi un document est validé ou non, ou pour décider entre $ref et $dynamicRef pour les schémas récursifs/extensibles.
