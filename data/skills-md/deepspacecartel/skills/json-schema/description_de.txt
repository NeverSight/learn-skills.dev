So schreiben und überprüfen Sie JSON-Schemadokumente gemäß der Spezifikation 2020-12 (https://json-schema.org/draft/2020-12) – projektunabhängig. Behandelt boolesche Schemata, das Kernvokabular ($schema, $id, $ref, $anchor, $dynamicRef/$dynamicAnchor, $defs, $vocabulary, $comment), Validierungsschlüsselwörter für jeden JSON-Typ, Applikatoren (allOf/anyOf/oneOf/not/if-then-else), unevaluatedProperties/unevaluatedItems, Anmerkungen (Titel, Beschreibung, Standard, Beispiele, veraltet, readOnly, writeOnly) und die Format-/Inhaltsvokabulare. Verwenden Sie diese Option, wenn Sie ein Schema schreiben, um JSON zu validieren (Konfigurationsdateien, API-Anforderungs-/Antwortkörper, Ereignisnutzlasten), ein Schema auf Spezifikationskonformität überprüfen, debuggen, warum ein Dokument validiert wird oder nicht, oder zwischen $ref und $dynamicRef für rekursive/erweiterbare Schemata entscheiden.
