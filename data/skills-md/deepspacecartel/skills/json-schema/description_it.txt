Come scrivere e rivedere i documenti dello schema JSON in base alla specifica 2020-12 (https://json-schema.org/draft/2020-12) - indipendente dal progetto. Copre gli schemi booleani, il vocabolario di base ($schema, $id, $ref, $anchor, $dynamicRef/$dynamicAnchor, $defs, $vocabulary, $comment), parole chiave di convalida per ciascun tipo JSON, applicatori (allOf/anyOf/oneOf/not/if-then-else), unevaluatedProperties/unevaluatedItems, annotazioni (titolo, descrizione, default, esempi, deprecato, readOnly, writeOnly) e i vocabolari di formato/contenuto. Da utilizzare durante la scrittura di uno schema per convalidare JSON (file di configurazione, corpi di richiesta/risposta API, payload di eventi), la revisione di uno schema per la conformità alle specifiche, il debug del motivo per cui un documento viene convalidato o meno o la decisione tra $ref e $dynamicRef per schemi ricorsivi/estensibili.
