Cómo escribir y revisar documentos de esquema JSON según la especificación 2020-12 (https://json-schema.org/draft/2020-12): independiente del proyecto. Cubre esquemas booleanos, el vocabulario principal ($schema, $id, $ref, $anchor, $dynamicRef/$dynamicAnchor, $defs, $vocabulary, $comment), palabras clave de validación para cada tipo de JSON, aplicadores (allOf/anyOf/oneOf/not/if-then-else), unevaluatedProperties/unevaluatedItems, anotaciones (título, descripción, valor predeterminado, ejemplos, en desuso, readOnly, writeOnly) y los vocabularios de formato/contenido. Úselo al escribir un esquema para validar JSON (archivos de configuración, cuerpos de solicitud/respuesta de API, cargas útiles de eventos), revisar un esquema para verificar el cumplimiento de especificaciones, depurar por qué un documento se valida o no, o decidir entre $ref y $dynamicRef para esquemas recursivos/extensibles.
