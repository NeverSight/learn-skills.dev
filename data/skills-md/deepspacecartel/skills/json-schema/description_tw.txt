如何根據 2020-12 規範撰寫和審查 JSON 架構文件 (https://json-schema.org/draft/2020-12) - 與專案無關。涵蓋布林模式、核心詞彙（$schema、$id、$ref、$anchor、$dynamicRef/$dynamicAnchor、$defs、$vocabulary、$comment）、每個 JSON類型的驗證關鍵字、應用程式（allOf/anyOf/oneOf/not/if-then-else）、unevaluatedProperties/unevaluatedItems、註釋（標題、描述、預設、範例、已棄用、唯讀、 writeOnly）以及格式/內容詞彙表。在編寫架構來驗證 JSON（設定檔、API 請求/回應主體、事件負載）、檢查架構的規範合規性、偵錯文件驗證或不驗證的原因，或在 $ref 和 $dynamicRef 之間決定遞歸/可擴充架構時使用。
