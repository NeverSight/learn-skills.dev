Как писать и просматривать документы JSON Schema в соответствии со спецификацией 2020-12 (https://json-schema.org/draft/2020-12) — независимо от проекта. Охватывает логические схемы, основной словарь ($schema, $id, $ref, $anchor, $dynamicRef/$dynamicAnchor, $defs, $vocabulary, $comment), ключевые слова проверки для каждого типа JSON, аппликаторы (allOf/anyOf/oneOf/not/if-then-else), unevaluatedProperties/unevaluatedItems, аннотации (заголовок, описание, значение по умолчанию, примеры, устарел, readOnly, writeOnly), а также словари формата/содержимого. Используйте при написании схемы для проверки JSON (файлы конфигурации, тела запросов/ответов API, полезные данные событий), проверке схемы на соответствие спецификациям, отладке того, почему документ проверяется или не проверяется, или выборе между $ref и $dynamicRef для рекурсивных/расширяемых схем.
