如何根据 2020-12 规范（https://json-schema.org/draft/2020-12）编写和审查 JSON Schema 文档——与项目无关。涵盖布尔模式、核心词汇（$schema、$id、$ref、$anchor、$dynamicRef/$dynamicAnchor、$defs、$vocabulary、$comment）、针对每种 JSON 类型的验证关键字、应用器（allOf、anyOf、oneOf、not、if‑then‑else）、unevaluatedProperties/unevaluatedItems、注释（title、description、default、examples、deprecated、readOnly、writeOnly）以及 format/content 词汇。用于编写用于验证 JSON（配置文件、API 请求/响应体、事件负载）的模式、审查模式是否符合规范、调试文档为何通过或未通过验证，或在递归/可扩展模式中决定使用 $ref 还是 $dynamicRef。
