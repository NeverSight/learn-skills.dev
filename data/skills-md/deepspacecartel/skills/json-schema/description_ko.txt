2020-12 사양(https://json-schema.org/draft/2020-12)에 따라 JSON 스키마 문서를 작성하고 검토하는 방법 - 프로젝트에 구애받지 않습니다. 부울 스키마, 핵심 어휘($schema, $id, $ref, $anchor, $dynamicRef/$dynamicAnchor, $defs, $vocabulary, $comment), 각 JSON 유형에 대한 검증 키워드, 적용기(allOf/anyOf/oneOf/not/if-then-else), unevaluatedProperties/unevaluatedItems, 주석(제목, 설명, 기본값, 예제, 사용되지 않음, readOnly, writeOnly) 및 형식/콘텐츠 어휘. JSON(구성 파일, API 요청/응답 본문, 이벤트 페이로드)을 검증하기 위한 스키마를 작성할 때, 사양 준수를 위한 스키마 검토, 문서가 검증되거나 검증되지 않는 이유 디버깅, 재귀/확장 가능한 스키마에 대해 $ref와 $dynamicRef 사이를 결정할 때 사용합니다.
