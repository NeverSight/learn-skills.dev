So entwerfen und überprüfen Sie „Problemdetails“-Fehlerantworten für HTTP-APIs gemäß RFC 9457 (https://www.rfc-editor.org/info/rfc9457/, veraltet RFC 7807) – projektunabhängig. Behandelt den Medientyp application/problem+json (und +xml), die Mitglieder type/status/title/detail/instance, Erweiterungsmitglieder, das Definieren neuer Problemtypen, die Standardeinstellung „about:blank“ und Sicherheitsüberlegungen im Zusammenhang mit der Weitergabe von Implementierungsdetails bei Fehlern. Verwenden Sie diese Option, wenn Sie das Fehler-/Ausnahme-Antwortformat einer HTTP-API entwerfen, eine Fehlerantwort auf Spezifikationskonformität überprüfen oder entscheiden, was eine API auf einem 4xx/5xx zurückgeben soll.
