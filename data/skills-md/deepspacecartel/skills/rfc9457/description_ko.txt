RFC 9457(https://www.rfc-editor.org/info/rfc9457/, 더 이상 사용되지 않는 RFC 7807)에 따라 HTTP API에 대한 "문제 세부 정보" 오류 응답을 설계하고 검토하는 방법 - 프로젝트에 구애받지 않습니다. 애플리케이션/문제+json(및 +xml) 미디어 유형, 유형/상태/제목/세부 사항/인스턴스 멤버, 확장 멤버, 새 문제 유형 정의, about:blank 기본값, 오류 시 구현 세부 정보 유출에 대한 보안 고려 사항을 다룹니다. HTTP API의 오류/예외 응답 형식을 설계하거나, 사양 준수에 대한 오류 응답을 검토하거나, API가 4xx/5xx에서 무엇을 반환해야 하는지 결정할 때 사용합니다.
