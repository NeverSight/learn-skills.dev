Comment concevoir et examiner les réponses d'erreur « détails du problème » pour les API HTTP selon la RFC 9457 (https://www.rfc-editor.org/info/rfc9457/, obsolète RFC 7807) - indépendant du projet. Couvre le type de média application/problème+json (et +xml), les membres type/statut/titre/détail/instance, les membres d'extension, la définition de nouveaux types de problèmes, la valeur par défaut about:blank et les considérations de sécurité concernant la fuite des détails d'implémentation dans les erreurs. À utiliser lors de la conception du format de réponse d'erreur/exception d'une API HTTP, de l'examen d'une réponse d'erreur pour vérifier sa conformité aux spécifications ou de la décision de ce qu'une API doit renvoyer sur un 4xx/5xx.
