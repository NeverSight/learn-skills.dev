Cómo diseñar y revisar respuestas de error de "detalles del problema" para las API HTTP según RFC 9457 (https://www.rfc-editor.org/info/rfc9457/, obsoleto RFC 7807): independiente del proyecto. Cubre el tipo de medio aplicación/problema+json (y +xml), el tipo/estado/título/detalle/miembros de instancia, miembros de extensión, definición de nuevos tipos de problemas, el valor predeterminado about:blank y consideraciones de seguridad en torno a la filtración de detalles de implementación en errores. Úselo al diseñar el formato de respuesta de error/excepción de una API HTTP, al revisar una respuesta de error para verificar el cumplimiento de las especificaciones o al decidir qué debe devolver una API en un 4xx/5xx.
