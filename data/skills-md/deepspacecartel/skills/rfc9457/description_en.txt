How to design and review "problem details" error responses for HTTP APIs per RFC 9457 (https://www.rfc-editor.org/info/rfc9457/, obsoletes RFC 7807) - project-agnostic. Covers the application/problem+json (and +xml) media type, the type/status/title/detail/instance members, extension members, defining new problem types, the about:blank default, and security considerations around leaking implementation details in errors. Use when designing an HTTP API's error/exception response format, reviewing an error response for spec compliance, or deciding what an API should return on a 4xx/5xx.
