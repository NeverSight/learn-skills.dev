Localizza le immagini HTTP(S) nei Markdown SoMark in pacchetti di directory simili a ZIP per un singolo file Markdown o per un batch di file .md/.markdown. Usa quando un utente ha bisogno di conservare gli URL delle immagini del deposito oggetti SoMark, sostituire i collegamenti alle immagini remote del Markdown con percorsi relativi locali, generare le immagini più il Markdown riscritto senza creare un archivio ZIP, o convertire in batch una directory di documenti Markdown SoMark.

Rispondi sempre nella lingua dell'utente.
