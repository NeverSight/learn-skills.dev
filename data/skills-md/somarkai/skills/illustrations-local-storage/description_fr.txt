Localiser les images HTTP(S) dans le Markdown SoMark en packages de répertoires similaires à des ZIP pour un seul fichier Markdown ou un lot de fichiers .md/.markdown. À utiliser lorsqu’un utilisateur doit conserver les URL des images du stockage d’objets SoMark, remplacer les liens d’images Markdown distants par des chemins relatifs locaux, produire les images ainsi que le Markdown réécrit sans créer d’archive ZIP, ou convertir en lot un répertoire de documents Markdown SoMark.

Veuillez toujours répondre dans la langue de l’utilisateur.
