Показ презентаций стартапов (PDF, PowerPoint, изображения) с точки зрения венчурного инвестора или бизнес-ангела. Анализирует информацию с помощью SoMark, чтобы точно восстановить структуру слайдов, затем выполняет поиск в Интернете для независимой проверки ключевых утверждений, а затем готовит перед встречей краткую инвестиционную записку, охватывающую основателей, рынок, продукт, популярность и бизнес-модель. Выводит инвестиционный сигнал с четким обоснованием. Требуется ключ API SoMark (SOMARK_API_KEY).
