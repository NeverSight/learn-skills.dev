Сравните два документа (PDF, Word, изображения, PPT) и создайте структурированный отчет о различиях, в котором будет указано, что изменилось, что было добавлено и что было удалено. Использует SoMark для анализа обоих документов сначала для точного сравнения с учетом структуры. Требуется ключ API SoMark (SOMARK_API_KEY).
