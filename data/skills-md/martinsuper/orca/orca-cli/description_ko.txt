`orca` CLI를 사용하여 Orca가 관리하는 작업 트리, 폴더 컨텍스트, 터미널, 저장소, 자동화, 아티팩트, 기술 공유, 작업 트리 주석 및 Orca의 내장 브라우저를 조작합니다.  
사용자는 “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff”/“handover”/“give this to another agent”, “Orca browser”, “orca artifacts”, 또는 “share skills”라고 말할 때 이를 사용합니다.  
Orca 상태가 관련된 경우, 일반 git 작업 트리, 임시 PTY, 혹은 컴퓨터 사용보다 이를 우선합니다.  
CLI, 파일 시스템, API로 처리할 수 없는 가시적인 창의 GUI 제어가 필요할 때만 컴퓨터 사용을 활용합니다.  
항상 사용자의 언어로 응답하세요.
