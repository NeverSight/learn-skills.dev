Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そして Orca の埋め込みブラウザを `orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」「share skills」と言ったときに使用してください。Orca の状態が関与する場合は、生の git worktree やアドホック PTY、あるいは Computer Use よりもこれを優先します。CLI、ファイルシステム、API では制御できない可視ウィンドウの GUI 操作が必要なときだけ Computer Use を使用してください。

常にユーザーの言語で応答してください。
