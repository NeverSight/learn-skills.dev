透過 `orca` CLI 操作 Orca 管理的工作樹、資料夾情境、終端機、倉庫、自動化、產物、技能分享、工作樹註解，以及 Orca 內嵌的瀏覽器。當使用者說「$orca-cli」或「Orca worktree」或「child worktree」或「spawn codex/claude in a worktree」或「read/wait/send Orca terminal」或「handoff」/「handover」/「give this to another agent」或「Orca browser」或「orca artifacts」或「share skills」時使用。涉及 Orca 狀態時，請優先使用此方式，而非純粹的 git 工作樹、臨時 PTY 或電腦使用。僅在需要控制可見視窗的圖形介面，而 CLI、檔案系統或 API 無法完成時才使用電腦使用。

請始終以使用者的語言回覆。
