Méta-compétence pour choisir les compétences de projet via APM. N'INVOQUEZ QUE lorsque l'utilisateur demande explicitement de configurer apm.yml, de choisir les compétences dont un projet a besoin ou d'évaluer une correspondance dans le catalogue — ne PAS invoquer automatiquement lors des tâches courantes d'initialisation de projet ou de gestion d'APM. Deux phases : choisir d'abord dans un catalogue sélectionné ; n'escalader vers une recherche/évaluation plus large que si le catalogue ne propose aucune correspondance. Évite le mode d'échec consistant à installer impulsivement des compétences que vous n'utilisez jamais ou à chercher manuellement sur GitHub alors qu'une réponse vérifiée existe déjà.

Veuillez toujours répondre dans la langue de l'utilisateur.
