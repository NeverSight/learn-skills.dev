Meta‑habilidad para seleccionar habilidades de proyecto mediante APM. Invocar SÓLO cuando el usuario solicite explícitamente configurar apm.yml, elegir qué habilidades necesita un proyecto o evaluar una coincidencia en el catálogo — NO auto‑invocar en tareas rutinarias de inicialización de proyecto o gestión de APM. Dos fases: primero elegir de un catálogo curado; solo escalar a una búsqueda/evaluación más amplia cuando el catálogo no tenga una coincidencia. Evita el modo de falla de instalar impulsivamente habilidades que nunca usarás o buscar manualmente en GitHub cuando ya existe una respuesta verificada.

Por favor, responde siempre en el idioma del usuario.
