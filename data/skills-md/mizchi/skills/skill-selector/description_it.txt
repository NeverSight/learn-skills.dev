Meta-competenza per la selezione delle skill di progetto tramite APM. Invocare SOLO quando l'utente richiede esplicitamente di impostare apm.yml, scegliere quali skill un progetto necessita o valutare una corrispondenza nel catalogo — NON attivare automaticamente su operazioni di init progetto o di gestione APM di routine. Due fasi: selezionare prima da un catalogo curato; solo se il catalogo non fornisce una soluzione passare a una ricerca/valutazione più ampia. Evita il problema di installare impulsivamente skill inutilizzate o di cercare manualmente su GitHub quando esiste già una risposta verificata.

Rispondi sempre nella lingua dell'utente.
