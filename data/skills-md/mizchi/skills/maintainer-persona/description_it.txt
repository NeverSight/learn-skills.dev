Scrivi un issue o una PR per un repository che non possiedi in modo che i suoi manutentori possano gestirlo. Misura la storia del target (reviewer, passaggi, lunghezza del corpo, intestazioni, lingua, come vanno le PR per la prima volta) in un file persona modificabile, si ramifica per contesto (OSS prima volta / OSS di ritorno / un altro team all'interno della tua organizzazione), bozze in giapponese e traduce solo dopo l'approvazione quando il target scrive in inglese, controlla con un lettore fresco e un lint di slop basato sulle PR dei manutentori, e controlla l'invio. Usa quando crei issue a monte, invii una correzione o una PR con test falliti a un altro progetto o team, o riscrivi una sottomissione che è stata ignorata.
