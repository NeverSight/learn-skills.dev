构建一个幻灯片套件，源文件为文本，图形由 TALA 布局——一个 Markdown 文件，每个图形用 ```d2 fence 包裹，编译成一个自包含的 HTML 套件（键盘导航、概览网格、打印为 PDF），每个图形单独为 SVG，并附带复制清单。套件本身是一个页面，所以 vlmkit 的内置 gate 会读取它：`check integrity` 用于检查断裂或被裁剪的幻灯片，`check copy --manifest` 用于检查框架截断的文字，`check a11y contrast` 用于投影仪的可访问性对比。循环：编写 `deck.md` → 构建 → gate 检查 → 修复。需要幻灯片、套件、演讲、演示、评审 walkthrough 或需要呈现而非阅读的图表密集解释时使用。不适用于单个图表（`d2-diagram`）或动态图形（`explanatory-animation`）。
