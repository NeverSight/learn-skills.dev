Создайте набор слайдов, исходный код которого — текст, а рисунки размещаются с помощью TALA — один файл Markdown с блоком ```d2 для каждой фигуры, компилируемый в автономный HTML‑дек (управление клавиатурой, обзорная сетка, печать в PDF), каждая фигура — отдельный SVG, и манифест копий. Дек — это страница, поэтому собственные проверки vlmkit читают его: `check integrity` для слайда, который ломается или обрезается, `check copy --manifest` для текста, обрезанного рамкой, `check a11y contrast` для проектора. Цикл: написать `deck.md` → собрать → проверки → исправить. Используйте, когда просят слайды, набор, доклад, презентацию, обзорный проход или объяснитель, насыщенный фигурами, который должен быть представлен, а не прочитан. Не для одной диаграммы (`d2-diagram`) или движущейся фигуры (`explanatory-animation`).
