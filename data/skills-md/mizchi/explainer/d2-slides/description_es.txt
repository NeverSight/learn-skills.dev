Construye una presentación cuya fuente sea texto y cuyas figuras se organicen con TALA — un archivo Markdown con un delimitador ```d2 por figura, compilado a un mazo HTML autocontenido (navegación con teclado, vista de cuadrícula, imprimir a PDF), cada figura como su propio SVG y un manifiesto de copias. El mazo es una página, por lo que las propias puertas de vlmkit lo leen: `check integrity` para una diapositiva que se rompe o recorta, `check copy --manifest` para texto que el marco cortó, `check a11y contrast` para un proyector. Bucle: escribe `deck.md` → compila → puertas → corrige. Úsalo cuando soliciten diapositivas, un mazo, una charla, una presentación, una revisión paso a paso o un explicador con muchas figuras que deba presentarse en lugar de leerse. No es para un solo diagrama (`d2-diagram`) o una figura en movimiento (`explanatory-animation`).
