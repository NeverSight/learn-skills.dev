Erstelle ein Slide‑Deck, dessen Quelle Text ist und dessen Figuren von TALA angeordnet werden — eine Markdown‑Datei mit einem ```d2‑Fence pro Figur, kompiliert zu einem eigenständigen HTML‑Deck (Tastaturnavigation, Übersichts‑Raster, Druck‑zu‑PDF), jede Figur als eigene SVG und einem Kopier‑Manifest. Das Deck ist eine Seite, sodass die eigenen Gates von vlmkit es lesen: `check integrity` für eine Folie, die bricht oder abschneidet, `check copy --manifest` für Text, den der Rahmen abgeschnitten hat, `check a11y contrast` für einen Projektor. Schleife: `deck.md` schreiben → bauen → Gates → fixen. Verwenden, wenn nach Folien, einem Deck, einem Talk, einer Präsentation, einem Review‑Durchlauf oder einem diagramm‑intensiven Erklärungs‑Video gefragt wird, das präsentiert statt gelesen werden muss. Nicht für ein einzelnes Diagramm (`d2-diagram`) oder eine bewegte Figur (`explanatory‑animation`).
