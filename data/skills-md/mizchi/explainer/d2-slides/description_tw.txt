建立一個投影片組，其來源為文字，圖表則由 TALA 排版──一個 Markdown 檔案，每個圖表使用一個 ```d2 代碼塊，編譯成自包含的 HTML 投影片（鍵盤導覽、總覽格線、列印成 PDF），每個圖表為單獨的 SVG，並附帶文字清單。投影片組是一個頁面，因此 vlmkit 自己的檢查門會讀取它：`check integrity` 檢查投影片是否斷裂或被裁切，`check copy --manifest` 檢查框架截斷的文字，`check a11y contrast` 檢查投影機的對比度。循環流程：撰寫 `deck.md` → 建構 → 門檢查 → 修正。於需要投影片、簡報、演講、展示、審閱走訪，或需要大量圖表且必須以展示方式而非閱讀方式呈現的說明時使用。不適用於單一圖表（`d2-diagram`）或動態圖形（`explanatory‑animation`）。
