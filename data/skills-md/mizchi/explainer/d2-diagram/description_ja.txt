TALA がレイアウトした D2 テキストとしてソフトウェアアーキテクチャ、システム、データモデル、またはコールフローダイアグラムを描き、誰も画像を開く前に端末で確認し、図が主張通りかチェックする — `d2 --layout=tala x.d2 x.txt` はレイアウトを Unicode のボックス描画として出力し、`--ascii-mode standard` は README 用にプレーンな ASCII に変換し、`assets/d2-facts.mjs` は描画された箱と矢印を取り出してファクトシートに保持する。ループ: `.d2` を書く → `d2 fmt --check` / `validate` → ファクト → 端末レンダリング → PNG → テキストを修正。D2 ダイアグラムや、リポジトリ内で編集可能なテキストとして保存されたアーキテクチャ図、TALA レイアウト、端末やコードブロックで表示できる図、またはリポジトリに既に `.d2` ファイルがある場合に使用する。アニメーションや歩くように動く図（`explanatory-animation`、`explain-with-anim`）には使用しない。
