Disegna un diagramma di architettura software, di sistema, di modello dati o di flusso di chiamate come testo D2 disposto da TALA (il motore in stile lavagna bianca di D2, open source dal D2 0.9), visualizzalo nel terminale prima che qualcuno apra un’immagine e verifica che l’immagine dica ciò che afferma — `d2 --layout=tala x.d2 x.txt` rende il layout come disegno a blocchi Unicode, `--ascii-mode standard` come semplice ASCII per un README, e `assets/d2-facts.mjs` legge le caselle e le frecce disegnate dal rendering e le conserva in una scheda informativa. Ciclo: scrivi `.d2` → `d2 fmt --check` / `validate` → fatti → rendering nel terminale → PNG → correggi il testo. Usalo quando ti viene chiesto un diagramma D2, un diagramma di architettura mantenuto come testo modificabile nel repository, un layout TALA, un diagramma che si mostra nel terminale o in un blocco di codice, o quando il repository contiene già file `.d2`. Non è per animazioni o figure con passeggiata mobile (`explanatory‑animation`, `explain‑with‑anim`).
