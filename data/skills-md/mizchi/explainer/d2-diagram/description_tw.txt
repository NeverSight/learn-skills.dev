繪製軟體架構、系統、資料模型或呼叫流程圖，使用 D2 文字並由 TALA（D2 的白板式引擎，自 D2 0.9 起開源）排版，在任何人開啟圖片之前先於終端機檢視，並確認圖形與說明相符——`d2 --layout=tala x.d2 x.txt` 會將佈局渲染為 Unicode 方框圖，`--ascii-mode standard` 則以純 ASCII 形式輸出供 README 使用，`assets/d2-facts.mjs` 會從渲染結果中讀取繪製的方框與箭頭，並將其整理成事實表。循環流程：編寫 `.d2` → `d2 fmt --check` / `validate` → 產生事實 → 終端機渲染 → PNG → 修正文字。當有人要求 D2 圖表、以可編輯文字儲存在 repo 中的架構圖、TALA 佈局、能在終端機或程式碼區塊顯示的圖表，或 repo 已有 `.d2` 檔案時使用。不要用於動畫或含有移動走道的圖形（`explanatory-animation`、`explain-with-anim`）。
