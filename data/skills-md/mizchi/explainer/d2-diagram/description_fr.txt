Créez un diagramme d’architecture logicielle, de système, de modèle de données ou de flux d’appels sous forme de texte D2 mis en page par TALA (le moteur de type tableau blanc de D2, open source depuis la version 0.9), visualisez‑le dans le terminal avant que quiconque n’ouvre une image, et vérifiez que l’image correspond à ce qu’elle prétend — `d2 --layout=tala x.d2 x.txt` rend la mise en page en dessins de boîtes Unicode, `--ascii-mode standard` en ASCII simple pour un README, et `assets/d2-facts.mjs` lit les boîtes et flèches dessinées à partir du rendu et les consigne dans une fiche de faits. Boucle : écrire `.d2` → `d2 fmt --check` / `validate` → faits → rendu terminal → PNG → corriger le texte. Utilisez‑le lorsqu’on vous demande un diagramme D2, un diagramme d’architecture conservé sous forme de texte éditable dans le dépôt, une mise en page TALA, un diagramme affichable dans le terminal ou dans un bloc de code, ou lorsque le dépôt possède déjà des fichiers `.d2`. Pas pour les animations ou les figures avec un déplacement animé (`explanatory‑animation`, `explain‑with‑anim`).
