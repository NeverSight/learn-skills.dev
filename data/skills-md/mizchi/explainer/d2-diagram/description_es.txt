Dibuja una arquitectura de software, sistema, modelo de datos o diagrama de flujo de llamadas como texto D2 dispuesto por TALA (el motor estilo pizarra de D2, open source desde D2 0.9), míralo en la terminal antes de que alguien abra una imagen y comprueba que la imagen dice lo que afirma — `d2 --layout=tala x.d2 x.txt` renderiza el diseño como dibujo de caja Unicode, `--ascii-mode standard` como ASCII puro para un README, y `assets/d2-facts.mjs` lee las cajas y flechas dibujadas del render y las guarda en una hoja de datos. Bucle: escribe `.d2` → `d2 fmt --check` / `validate` → datos → render en terminal → PNG → corrige el texto. Úsalo cuando se solicite un diagrama D2, un diagrama de arquitectura mantenido como texto editable en el repositorio, un diseño TALA, un diagrama que se muestre en una terminal o bloque de código, o cuando el repositorio ya tenga archivos `.d2`. No es para animaciones o figuras con un caminante en movimiento (`explanatory‑animation`, `explain‑with‑anim`).
