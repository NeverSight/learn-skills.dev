绘制软件架构、系统、数据模型或调用流图，使用 D2 文本并通过 TALA 布局（D2 的白板式引擎，自 D2 0.9 起开源），在任何人打开图片之前先在终端中查看，并检查图形是否如其所述 —— `d2 --layout=tala x.d2 x.txt` 将布局渲染为 Unicode 框线，`--ascii-mode standard` 则渲染为普通 ASCII 以供 README 使用，`assets/d2-facts.mjs` 从渲染结果中读取绘制的框和箭头并生成事实表。循环流程：编写 `.d2` → `d2 fmt --check` / `validate` → 生成事实 → 终端渲染 → PNG → 修正文本。适用于以下情况：需要 D2 图时、将架构图以可编辑文本保存在仓库时、需要 TALA 布局时、需要在终端或代码块中显示的图时，或仓库已经存在 `.d2` 文件时。不适用于动画或含有移动走廊的图形（`explanatory-animation`、`explain-with-anim`）。
