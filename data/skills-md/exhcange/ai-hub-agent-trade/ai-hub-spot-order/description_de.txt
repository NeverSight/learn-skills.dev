Verwenden Sie diese Fähigkeit, wenn ein Benutzer darum bittet, unterstützte KI-Hub-Spots oder isolierte/Cross-Spot-Margin-Bestellungen abzurufen oder zu platzieren. Verwenden Sie die lokale ai-hub CLI mit einem konfigurierten Anmeldeinformationenprofil. Niemals zu Derivaten routen oder einen expliziten Hebelmultiplikator akzeptieren. Jede zustandsändernde Aktion erfordert eine genaue Vorschau, gefolgt von einer neuen manuellen Benutzerbestätigung.
