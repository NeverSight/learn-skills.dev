Guide l'agent pour activer R8 dans une application Android Capacitor afin qu'elle respecte l'exigence d'optimisation du code DEX de Google Play (au moins 25 % d'obfuscation, d'optimisation et de réduction à partir de février 2027 pour les applications contenant plus de 10 Mo de code DEX). Couvre `minifyEnabled true` avec `proguard-android-optimize.txt` dans `android/app/build.gradle`, la règle `-keep @interface com.getcapacitor.** { *; }` qui empêche le plantage au démarrage en mode plein R8, les règles de conservation par plugin, la résolution des erreurs de compilation R8 « Missing class » via `missing_rules.txt`, la création d'un APK release signé avec le keystore de debug, et la vérification avec logcat, `mapping.txt` et le fichier `r8.json` à l'intérieur du bundle de l'application. À utiliser lorsque la Play Console signale une anomalie d'optimisation du code DEX, lorsqu'une application Capacitor se plante au démarrage après avoir activé `minifyEnabled`, ou lorsque R8 échoue lors de la construction de la version release. Ne pas utiliser pour iOS, le rétrécissement des ressources, les projets de plugins Capacitor, les mises à jour de version de Capacitor, ou les cadres mobiles non‑Capacitor.
