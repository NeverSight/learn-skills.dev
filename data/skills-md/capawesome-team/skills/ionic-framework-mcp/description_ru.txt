Проводит агента через процесс подключения MCP‑клиента к размещённому, неофициальному серверу MCP Ionic Framework от Capawesome, который предоставляет официальную документацию Ionic Framework для версий 9 и 8, справочник API компонентов, официальные примеры использования для Angular, React, Vue и чистого JavaScript, а также блог Ionic. Охватывает обнаружение клиента, настройку для Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Zed и клиентов только со stdin/stdout, выбор версии документации, проверку и устранение неисправностей. Не используйте для плагинов Capacitor или нативной конфигурации iOS и Android, обновления или миграции приложений на более новую версию, Capawesome Cloud или MCP‑серверов, отличных от сервера Ionic Framework.
