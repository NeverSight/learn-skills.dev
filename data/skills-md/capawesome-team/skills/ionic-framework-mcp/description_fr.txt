Guide l'agent pour connecter un client MCP au serveur MCP hébergé, non officiel, d'Ionic Framework fourni par Capawesome, qui sert la documentation officielle d'Ionic Framework pour les versions v9 et v8, la référence de l’API des composants, les exemples d’utilisation officiels pour Angular, React, Vue et JavaScript vanilla, ainsi que le blog Ionic. Couvre la détection du client, la configuration pour Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Zed et les clients uniquement stdio, la sélection de la version de la documentation, la vérification et le dépannage. Ne pas l’utiliser pour les plugins Capacitor ou la configuration native iOS et Android, la mise à jour ou la migration d’applications vers une version plus récente, Capawesome Cloud, ou tout serveur MCP autre que celui d’Ionic Framework.
