Guía al agente para conectar un cliente MCP al servidor MCP no oficial alojado por Capawesome, que ofrece la documentación oficial de Ionic Framework para v9 y v8, la referencia de la API de componentes, los ejemplos oficiales de uso para Angular, React, Vue y JavaScript puro, y el blog de Ionic. Cubre la detección del cliente, la configuración para Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Zed y clientes solo stdio, la selección de la versión de la documentación, la verificación y la solución de problemas. No se debe usar para complementos de Capacitor ni para la configuración nativa de iOS y Android, actualización o migración de aplicaciones a una versión más reciente, Capawesome Cloud o servidores MCP distintos al de Ionic Framework.
