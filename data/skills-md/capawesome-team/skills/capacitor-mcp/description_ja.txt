エージェントがMCPクライアントをCapawesomeが提供する非公式のホスト型Capacitor MCPサーバーに接続する手順を案内します。このサーバーはv8、v7、v6、次期バージョンの公式Capacitorドキュメント、公式およびコミュニティプラグインリスト、そしてIonicブログのCapacitor記事を提供します。クライアント検出、Claude Code、Claude Desktop、Cursor、VS Code、Windsurf、Zed、標準入力専用クライアントの設定、ドキュメントバージョン選択、検証、トラブルシューティングについて説明します。Capacitorプラグインのインストールや設定、アプリやプラグインの新バージョンへのアップグレード・移行、Ionic Framework の UI コンポーネント、Capawesome Cloud、または Capacitor 以外の MCP サーバーの使用には使用しないでください。
