يرشد الوكيل خلال ربط عميل MCP بخادم Capacitor MCP غير الرسمي المستضاف من قبل Capawesome، والذي يقدم الوثائق الرسمية لـ Capacitor للإصدارات v8 وv7 وv6 وnext، وقائمة الإضافات الرسمية والمجتمعية، ومنشورات Capacitor من مدونة Ionic. يغطي اكتشاف العميل، وإعداد Claude Code وClaude Desktop وCursor وVS Code وWindsurf وZed والعملاء الذين يستخدمون stdin فقط، واختيار نسخة الوثائق، والتحقق، ومعالجة المشكلات. لا يُستخدم لتثبيت أو تكوين إضافات Capacitor، أو ترقية أو ترحيل التطبيقات والإضافات إلى نسخة أحدث، أو مكوّنات واجهة المستخدم لإطار عمل Ionic، أو Capawesome Cloud، أو خوادم MCP غير خادم Capacitor.
