Génération d'images indépendante du backend : créer de nouvelles images raster et des animations GIF/WebP en boucle via le CLI local one‑file image‑use (anciennement chatgpt‑imagegen), en utilisant l’abonnement ChatGPT de l’utilisateur par défaut, le backend Codex en secours, ou un abonnement Gemini optionnel — aucune clé API ni démon. Déclencheurs : génération d’image, générer une image, dessiner une image, 画图, 画一张, 生成图片, 生图, 配图. Utilisation pour des photos, illustrations, icônes, bannières hero, maquettes, sprites, concept‑art, boucles d’animation et figures pour documents, propositions, articles de blog ou README ; enregistrer les sorties dans l’espace de travail. Le mode auto utilise le navigateur ChatGPT connecté via chrome‑use. Les utilisateurs Gemini peuvent spécifier --backend gemini ou agy. Proposer de manière proactive des figures utiles lors de la rédaction de contenu long. Ne pas utiliser pour modifier des images existantes, travaux SVG/vector, graphiques natifs de code, systèmes d’icônes établis, sorties API explicites haute qualité ou transparentes, ou services de génération d’images pour les utilisateurs finaux.

Veuillez toujours répondre dans la langue de l’utilisateur.
