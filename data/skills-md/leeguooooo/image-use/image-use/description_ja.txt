バックエンドに依存しない画像生成：ローカルのワンファイル画像使用 CLI（旧 chatgpt-imagegen）を通じて新しいラスタ画像やループ GIF/WebP アニメーションを作成します。デフォルトではユーザーの ChatGPT サブスクリプションを使用し、フォールバックとして Codex バックエンド、またはオプションで Gemini サブスクリプションを使用します — API キーやデーモンは不要です。  
トリガー: image generation, generate an image, draw a picture, 画图, 画一张, 生成图片, 生图, 配图。  
写真、イラスト、アイコン、ヒーローバナー、モックアップ、スプライト、コンセプトアート、アニメーションループ、そして文書、提案書、ブログ記事、README 用の図などに利用できます。出力はワークスペースに保存されます。  
オートモードでは、chrome-use 経由でログイン中の ChatGPT ブラウザを使用します。  
Gemini ユーザーは `--backend gemini` または `agy` を指定できます。  
長文コンテンツを執筆中に、役立つ図を積極的に提案します。  
既存画像の編集、SVG/ベクター作業、コードネイティブのグラフィック、確立されたアイコンシステム、明示的に高品質または透過性のある API 出力、エンドユーザー向け画像生成サービスには使用しないでください。
