Generación de imágenes independiente del backend: crea nuevas imágenes raster y animaciones en bucle GIF/WebP mediante la CLI local de un solo archivo image-use (antes chatgpt-imagegen), usando la suscripción de ChatGPT del usuario por defecto, el backend Codex como alternativa, o una suscripción opcional a Gemini — sin clave API ni daemon. Disparadores: generación de imágenes, generar una imagen, dibujar una imagen, 画图, 画一张, 生成图片, 生图, 配图. Úsalo para fotos, ilustraciones, íconos, banners principales, mockups, sprites, arte conceptual, bucles de animación y figuras para documentos, propuestas, publicaciones de blog o READMEs; guarda los resultados en el espacio de trabajo. El modo automático utiliza el navegador de ChatGPT iniciado sesión a través de chrome-use. Los usuarios de Gemini pueden pasar --backend gemini o agy. Propón proactivamente figuras útiles al redactar contenido de formato extenso. No lo uses para editar imágenes existentes, trabajo SVG/vector, gráficos nativos de código, sistemas de íconos establecidos, salida API de alta calidad o transparente explícita, o servicios de generación de imágenes para usuarios finales.
