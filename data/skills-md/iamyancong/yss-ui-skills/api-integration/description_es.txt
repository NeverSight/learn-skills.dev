Orientación sobre la integración de la API de Orval en la lista de negocios, la forma, el detalle y los ganchos de operación de Vue 3, que cubren la selección de artefactos generados reales, los contratos de respuesta del mutador, las solicitudes de error, los estados de carga, las opciones de solicitud y la precisión de números enteros largos; se utilizará cuando una página interactúe con las API de consulta, adición, edición, eliminación, detalle o flujo de archivos.
