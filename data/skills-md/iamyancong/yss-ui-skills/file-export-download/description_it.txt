Guida le micro‑applicazioni Vue3 YSS UI per implementare l'esportazione di file, il download di report, il download di modelli e il download di allegati, coprendo le risposte binarie OpenAPI, i controlli dei metodi di generazione Orval, il fallback responseType blob, i tipi di risposta Blob, i nomi dei file Content‑Disposition, handleBlobResponse, il caricamento e la gestione degli errori; usala ogni volta che un requisito prevede l'esportazione, il download, Excel, CSV, PDF, ZIP, Blob o flussi di file.
