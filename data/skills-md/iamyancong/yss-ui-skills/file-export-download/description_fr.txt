Guide la micro-application Vue 3 YSS UI dans la mise en œuvre de l'exportation de fichiers, du téléchargement de rapports, du téléchargement de modèles et du téléchargement de pièces jointes, couvrant les réponses binaires OpenAPI, les contrôles de génération de méthodes Orval, la solution de repli du blob responseType, le type de réponse Blob, les noms de fichiers Content‑Disposition, handleBlobResponse, ainsi que le chargement et le traitement des erreurs ; à utiliser chaque fois que l'exigence implique l'exportation, le téléchargement, Excel, CSV, PDF, ZIP, Blob ou des flux de fichiers.
