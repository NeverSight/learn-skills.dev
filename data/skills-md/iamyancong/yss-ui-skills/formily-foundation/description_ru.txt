Руководство по разработке базовых форм YFormily на основе @yss-ui/components, охватывающее правила валидации полей, поток отправки, сеточную раскладку запрос‑форм, выражения области видимости и стандартизированные границы импорта; предназначено для создания одностраничных базовых форм, настройки обычных проверок или устранения неполадок при отправке базовых форм. Для сложных динамических связей см. formily-linkage-effects; для пошаговых мастер‑процессов используйте formily-step-flow.
