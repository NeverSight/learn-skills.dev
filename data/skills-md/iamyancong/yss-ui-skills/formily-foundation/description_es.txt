Guía el desarrollo de formularios YFormily Basic basados en @ yss-ui/components, que cubren las reglas de validación de campo, el flujo de envíos, el diseño de cuadrícula de formularios de consulta, las expresiones de alcance y los estándares de límite de importación; utilícelo al crear formularios Basic de una sola página, configurar validaciones estándar o solucionar problemas de envíos de formularios Basic. Para enlaces dinámicos complejos, consulte formily-linkage-effects; para asistentes paso a paso, use formily-step-flow.
