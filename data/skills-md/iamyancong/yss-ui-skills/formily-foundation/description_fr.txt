Guider le développement de formulaires de base YFormily basés sur @ yss-ui/components, couvrant les règles de validation de champ, le flux de soumission, la disposition de la grille de formulaire de requête, les expressions de portée et les limites d'importation de spécification ; l'utiliser lors de la création de formulaires de base d'une seule page, de la configuration de la validation standard ou du dépannage des soumissions de formulaires de base. Pour les liaisons dynamiques complexes, reportez-vous aux effets de liaison formelle ; pour les assistants étape par étape, utilisez formily-step-flow.
