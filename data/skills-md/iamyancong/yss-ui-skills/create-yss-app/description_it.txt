Il punto di ingresso consigliato per creare o inizializzare un progetto micro‑frontend micro‑applicazione YSS, generando rapidamente lo scheletro del progetto online tramite lo scaffolding ufficiale e l’interazione con la CLI; create yss app scaffold micro‑frontend project; usato quando si costruisce una micro‑applicazione da zero online, si crea una nuova sotto‑applicazione Qiankun o si esegue lo scaffolding per creare un progetto. Per le iterazioni di sviluppo di progetti esistenti, si prega di passare a yss-frontend-dev; per la creazione offline, utilizzare yss-create-microapp.
