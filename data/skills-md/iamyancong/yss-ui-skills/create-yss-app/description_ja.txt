公式のスキャフォールディングと CLI を使用してオンラインでマイクロフロントエンドプロジェクトの雛形を素早く生成するための、YSS マイクロフロントエンドマイクロアプリケーションプロジェクトを作成または初期化する際の推奨エントリーポイントは `create yss app scaffold micro-frontend project` です。これは、オンラインでゼロからマイクロアプリケーションを構築する場合や、新しい qiankun サブアプリケーションを作成する場合、あるいはスキャフォールディングを実行してプロジェクトを作成する際に使用します。既存プロジェクトの開発やイテレーションには `yss-frontend-dev` に委ね、オフラインでの作成には `yss-create-microapp` を使用してください。常にユーザーの言語で回答してください。
