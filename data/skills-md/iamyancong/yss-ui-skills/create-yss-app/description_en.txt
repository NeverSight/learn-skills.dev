Create or initialize a YSS micro-frontend micro‑application project using the preferred entry point, where the official scaffold and CLI interactively generate a micro‑frontend project skeleton online; “create yss app scaffold micro‑frontend project”. Use this when building a micro‑application from scratch online, creating a new qiankun sub‑application, or running the scaffold to create a project. For development and iteration of existing projects, hand over to yss‑frontend‑dev; for offline creation, switch to yss‑create‑microapp.
