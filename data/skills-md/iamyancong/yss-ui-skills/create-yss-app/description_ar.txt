إنشاء أو تهيئة مشروع YSS لتطبيق ميكرو‑فرونت‑إند ميكرو‑تطبيق باستخدام نقطة الدخول المفضلة، حيث يقوم القالب الرسمي وواجهة سطر الأوامر (CLI) بتوليد هيكل مشروع ميكرو‑فرونت‑إند بشكل تفاعلي عبر الإنترنت؛ “create yss app scaffold micro‑frontend project”. استخدم ذلك عند بناء ميكرو‑تطبيق من الصفر عبر الإنترنت، أو إنشاء تطبيق فرعي جديد لـ qiankun، أو تشغيل القالب لإنشاء مشروع. لتطوير وتكرار المشاريع الحالية، سلّم الأمر إلى yss‑frontend‑dev؛ وللإنشاء غير المتصل، انتقل إلى yss‑create‑microapp.
