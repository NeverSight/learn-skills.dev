Guía para las páginas de izquierda‑árbol derecha‑tabla, árbol de organización, árbol de clasificación, árbol de directorio y gestión de nodos de YSS UI, para usar el componente YTree de @yss‑ui/components, sobrescribiendo el mapeo de fieldNames, el filtrado de búsqueda, la selección controlada, las acciones de nodo, la confirmación de eliminación, el desplazamiento virtual y la altura adaptativa; para ser utilizada al crear o modificar filtros de estilo árbol, diseños de izquierda‑árbol derecha‑tabla, búsquedas en árboles o operaciones de nodos de árbol.
