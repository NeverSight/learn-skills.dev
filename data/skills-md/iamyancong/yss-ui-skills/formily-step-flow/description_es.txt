Orientación para crear formularios paso a paso y procesos de asistente basados en Ant Design Vue Steps con múltiples instancias de YFormily, que cubren la validación independiente para cada paso, la retención persistente de datos en todos los pasos, la vista previa de confirmación final y un bucle cerrado de envío agregado; utilizar cuando la empresa requiere una entrada escalonada, procesos en fases o asistentes de varios pasos. Para formularios regulares de una sola página, use formily-foundation; para una vinculación de campo simple, use formily-linkage-effects.
