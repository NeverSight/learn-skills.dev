Quand les utilisateurs fournissent des captures d’écran de prototype, le code source d’un projet hérité ou d’anciennes maquettes de page demandant la réplication d’une page métier, guidez‑les pour pré‑extraire une liste de contrôle d’acceptation visuelle et d’interaction, puis, après implémentation, comparez chaque élément avec la mise en page, les positions des boutons, la hauteur adaptative du tableau et les types de contrôles afin de finaliser l’acceptation de la livraison ; une intégration pure d’API backend ou des exigences génériques sans interface de prototype ne nécessitent pas l’utilisation de cette compétence.

Veuillez toujours répondre dans la langue de l’utilisateur.
