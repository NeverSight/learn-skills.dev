Руководите бизнес‑страницы YSS UI использовать YEditTable из @yss-ui/components для реализации редактируемых таблиц, встроенного редактирования, добавления/удаления строк, выпадающего мультиселекта с создаваемыми тегами, привязки кандидатов на уровне строк, фильтрации заголовков, валидации и режима просмотра; используйте его, когда требование включает редактируемые таблицы, детальные строки, расширенные атрибуты, редактируемые столбцы или YEditTableColumn.
