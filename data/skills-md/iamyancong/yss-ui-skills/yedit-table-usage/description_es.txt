Guíe a las páginas de negocio de YSS UI a usar YEditTable de @yss-ui/components para implementar tablas editables, edición en línea, agregar/eliminar filas, selección múltiple en desplegable con etiquetas creables, vinculación de candidatos a nivel de fila, filtrado de encabezado, validación y modo de vista; utilícela cuando el requisito implique tablas editables, filas de detalle, atributos extendidos, columnas editables o YEditTableColumn.
