Guida l'implementazione del modulo elenco standard YSS UI, paginazione remota lato server, reset delle condizioni di query, barra degli strumenti superiore di YTable, permessi dei pulsanti di operazione per riga, selezione batch e collegamento albero sinistro/tabella destra; usalo quando implementi specifici elenchi di query dati, interazioni con le tabelle e il ciclo chiuso della lista CRUD. Per l'orchestrazione dell'architettura a pagina intera, usa yss‑ui‑business‑page‑generation; per i form autonomi, usa page‑form‑module.
