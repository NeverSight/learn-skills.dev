قم بتوحيد تفكيك الحالة التفاعلية، والتواصل بين المكونات عبر المستويات، وآليات إلغاء سباقات العمليات غير المتزامنة، ومعالجة دقة الأعداد الصحيحة الكبيرة في صفحات الأعمال المبنية بـ Vue 3 + TypeScript، والمكونات العامة، والملحقات القابلة لإعادة الاستخدام؛ استخدمها عند تنفيذ أو إعادة هيكلة منطق الأعمال المعقد في Vue 3 والهوكس. بالنسبة لمواصفات النماذج الخاصة، راجع yss‑formily، ولصيانة مكتبة المكونات، راجع component‑development.
