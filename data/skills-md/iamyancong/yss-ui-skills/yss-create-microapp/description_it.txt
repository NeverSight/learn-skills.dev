In ambienti offline o con restrizioni di rete, utilizza il fallback script integrato per creare micro‑applicazioni, inizializzando progetti di sotto‑applicazioni micro‑frontend con modelli locali e script offline; questo è usato quando non puoi accedere alla rete esterna, non hai connettività npm, affronti restrizioni di rete o devi eseguire script locali direttamente per configurare il sotto‑progetto. In un ambiente online normale, lo strumento preferito è `create-yss-app`; per progetti esistenti con pagine di sviluppo aziendale, usa `yss-frontend-dev`.

Per favore rispondi sempre nella lingua dell'utente.
