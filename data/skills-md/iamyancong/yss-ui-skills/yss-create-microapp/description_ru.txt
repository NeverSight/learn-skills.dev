Когда вы офлайн или находитесь в сети с ограничениями, используйте встроенный резервный скрипт для создания микроприложений, инициализируя проекты микрофронтенд‑подприложений с локальными шаблонами и офлайн‑скриптами; применяйте этот подход, если недоступен внешний доступ в интернет, нет соединения с npm, сеть ограничена, либо необходимо напрямую запустить локальные скрипты для настройки подпроекта. В обычной онлайн‑среде предпочтительно использовать create‑yss‑app; для существующих проектов, разрабатывающих бизнес‑страницы, используйте yss‑frontend‑dev.
