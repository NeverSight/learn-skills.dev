Dans les environnements hors ligne ou avec des restrictions réseau, utilisez le repli du script intégré pour créer des micro‑applications, en employant des modèles locaux et des scripts hors ligne pour initialiser les projets de sous‑applications micro‑frontend ; cela est utilisé lorsque l’accès réseau externe est indisponible, qu’il n’y a pas de connectivité npm, que le réseau est limité, ou lorsque vous devez exécuter directement des scripts locaux pour configurer le sous‑projet. Dans un environnement en ligne normal, privilégiez `create-yss-app` ; pour les projets existants développant des pages métier, veuillez utiliser `yss-frontend-dev`.

Veuillez toujours répondre dans la langue de l’utilisateur.
