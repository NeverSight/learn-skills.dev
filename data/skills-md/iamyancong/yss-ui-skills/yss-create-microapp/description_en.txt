Built-in script fallback for creating micro‑applications in offline or network‑restricted environments, using local templates and offline scripts to initialize a micro‑frontend sub‑application project; used when the external network is inaccessible, there is no npm connectivity, the network is restricted, or you need to run local scripts directly to set up the sub‑project. In a normal online network environment, prefer create‑yss‑app; for existing projects’ development business pages, use yss‑frontend‑dev.
