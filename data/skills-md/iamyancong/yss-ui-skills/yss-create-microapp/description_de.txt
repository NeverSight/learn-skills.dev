In Offline‑ oder netzwerkbeschränkten Umgebungen verwenden Sie den eingebauten Skript‑Fallback, um Mikro‑Applikationen zu erstellen, indem Sie das Mikro‑Frontend‑Unterapplikationsprojekt mit lokalen Vorlagen und Offline‑Skripten initialisieren. Dies ist geeignet, wenn kein externer Internetzugang verfügbar ist, die npm‑Konnektivität fehlt, das Netzwerk eingeschränkt ist oder Sie lokale Skripte direkt ausführen müssen, um das Unterprojekt einzurichten. In einer normalen Online‑Netzwerkumgebung sollten Sie `create-yss-app` bevorzugen; für bestehende Projekte mit Entwicklungs‑Geschäftsseiten verwenden Sie `yss-frontend-dev`.
