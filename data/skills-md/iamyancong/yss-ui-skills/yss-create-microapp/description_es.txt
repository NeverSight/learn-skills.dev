En entornos sin conexión o con restricciones de red, crea una alternativa de script incorporado para micro‑aplicaciones mediante el uso de plantillas locales y scripts offline para inicializar un proyecto de sub‑aplicación micro‑frontend; utiliza esto cuando no haya acceso a internet externo, no haya conectividad npm, la red sea limitada o necesites ejecutar scripts locales directamente para configurar el sub‑proyecto. En un entorno en línea normal, la herramienta preferida es create‑yss‑app; para proyectos existentes con páginas de negocio desarrolladas, usa yss‑frontend‑dev.
