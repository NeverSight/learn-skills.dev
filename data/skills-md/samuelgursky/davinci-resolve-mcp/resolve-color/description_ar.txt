تدرج اللون وعمل المظهر في MCP الخاص بـ DaVinci Resolve. يُطبق عند التدرج، التصحيح، مطابقة اللقطات، تطوير المظاهر، أو تطبيق/تعديل LUTs، CDLs، درجات DRX، أو الدرجات المنسوخة — مباشرةً في نسخة Resolve تعمل أو بشكل غير متصل عبر ملفات ‎.drx/.drp. يوجه إلى أدوات اللون Python الحية، وفهرس التدرج المتقدم/مراقبة الجودة غير المتصل، وإرشادات صناعة اللون للمشروع.
