Orientamento e indicizzazione per il lavoro di DaVinci Resolve MCP: valutazione, modifica, conformità, consegna, analisi dei media e lavoro su file .drp/.drt/.drx, dal vivo in un Resolve in esecuzione o offline senza nessuno aperto. Caricalo per una mappa delle competenze del dominio, dei server live e offline e delle regole di sicurezza trasversali. Le abilità per dominio (risolvere-colore / risolvere-modificare / risolvere-conformare / risolvere-consegna / risolvere-analisi-media) portano la profondità e l'auto-attivazione nelle proprie descrizioni; usalo come mappa o quando un'attività si estende su più domini.
