Medien‑Pool‑Import und ‑Organisation im DaVinci Resolve MCP. Anwenden beim Importieren von Medien, Erstellen von Multicam‑Timelines, Organisieren/Verknüpfen von Clips, Normalisieren von Metadaten, Setzen von Clip‑Markierungen oder Verifizieren/Inventarisieren einer Karte vor dem Import – live in einem laufenden Resolve ODER offline. Leitet zu den Live‑Media‑Pool‑Werkzeugen und dem Offline‑Media‑Frontend‑Werkzeug. Zum Auslesen/Analysieren von Filmmaterial verwenden Sie resolve‑media‑analysis; für die Qualitätskontrolle der Auslieferungsmedien verwenden Sie resolve‑delivery.
