Слой медианой интеллекта для DaVinci Resolve MCP. Использует FFprobe, FFmpeg и, при необходимости, Whisper для ЧТЕНИЯ и АНАЛИЗА исходных медиа — никогда не модифицирует, не транскодирует, не конвертирует и не создаёт производные файлы. Предоставляет MCP полное представление о том, что представляет собой видеоматериал, чтобы он мог принимать обоснованные действия в Resolve.
