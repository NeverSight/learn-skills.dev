‘orca’ CLI를 통해 Orca가 관리하는 워크트리, 폴더 컨텍스트, 터미널, 레포, 자동화, 아티팩트, 기술 공유, 워크트리 코멘트 및 Orca의 내장 브라우저를 조작합니다. 사용자는 "$orca-cli", "Orca worktree", "child worktree", "spawn codex/claude in a worktree", "read/wait/send Orca terminal", "handoff" / "handover" / "give this to another agent", "Orca browser", "orca artifacts", 또는 "share skills"라고 말할 때 사용합니다. Orca 상태가 관련된 경우에는 기존 git 워크트리, 임시 PTY, 또는 Computer Use보다 이를 우선합니다. GUI 제어가 필요한 가시적 창이 CLI, 파일 시스템, API로는 조작할 수 없을 때만 Computer Use를 사용합니다.

항상 사용자의 언어로 답변하십시오.
