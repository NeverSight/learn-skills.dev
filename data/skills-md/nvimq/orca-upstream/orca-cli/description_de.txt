Betriebe Orca‑verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaum‑Kommentare und Orcas eingebetteten Browser über das `orca`‑CLI. Verwende es, wenn der Nutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzuge es gegenüber rohem Git‑Worktree, ad‑hoc PTYs oder Computer Use, wenn Orca‑Zustand involviert ist. Nutze Computer Use nur, wenn ein sichtbares Fenster GUI‑Steuerung erfordert, die ein CLI, Dateisystem oder eine API nicht leisten kann.
