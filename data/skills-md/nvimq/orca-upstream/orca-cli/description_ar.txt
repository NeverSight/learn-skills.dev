تشغيل الأشجار العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والآثار، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر أوامر `orca`. استخدمها عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضلها على شجرة git الخام، أو PTY العشوائية، أو استخدام الحاسوب عندما تكون حالة Orca متورطة. استخدم استخدام الحاسوب فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة رسومية لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به. يرجى دائمًا الرد بلغة المستخدم.
