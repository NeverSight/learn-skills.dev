Installa e usa pplx-srch-sdk, l'SDK Python pubblico per l'API Perplexity Search (importa pplx_srch_sdk): ricerca web in tempo reale e estratti di pagine pertinenti alla query dal codice Python. Usalo per cercare il web da uno script o notebook, avviare molte ricerche simultaneamente, ottenere estratti pertinenti a una query da URL specifici, costruire pipeline di ricerca a più passaggi o gestire gli errori dell'API Search con eccezioni tipizzate.
