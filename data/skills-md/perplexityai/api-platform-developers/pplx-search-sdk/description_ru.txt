Установите и используйте pplx-srch-sdk, публичный Python SDK для Perplexity Search API (import pplx_srch_sdk): живой веб‑поиск и отрывки страниц, релевантные запросу, из кода Python. Используйте для поиска в интернете из скрипта или ноутбука, запускайте множество запросов одновременно, получайте релевантные запросу отрывки из конкретных URL, создавайте многошаговые исследовательские конвейеры или обрабатывайте ошибки Search API с помощью типизированных исключений.
