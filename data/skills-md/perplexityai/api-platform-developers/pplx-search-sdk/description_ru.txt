Установите и используйте pplx-srch-sdk, публичный Python SDK для Perplexity Search API (import pplx_srch_sdk): живой веб‑поиск и извлечение релевантных запросу фрагментов страниц из кода Python. Используйте его для поиска в интернете из скрипта или ноутбука, запуска множества поисков одновременно, получения релевантных фрагментов с конкретных URL, построения многошаговых исследовательских конвейеров или обработки ошибок Search API с помощью типизированных исключений.
