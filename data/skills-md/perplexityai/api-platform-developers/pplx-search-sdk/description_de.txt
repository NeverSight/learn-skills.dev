Installieren und verwenden Sie pplx-srch-sdk, das öffentliche Python SDK für die Perplexity Search API (import pplx_srch_sdk): Live-Websuche und query-relevante Seitenausschnitte aus Python-Code. Verwenden Sie diese Funktion, um das Web von einem Skript oder Notizbuch aus zu durchsuchen, viele Suchvorgänge gleichzeitig durchzuführen, abfragerelevante Auszüge aus bestimmten URLs abzurufen, mehrstufige Recherche-Pipelines zu erstellen oder Such-API-Fehler mit typisierten Ausnahmen zu behandeln.
