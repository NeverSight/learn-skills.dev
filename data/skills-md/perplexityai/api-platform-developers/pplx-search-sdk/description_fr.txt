Installez et utilisez pplx‑srch‑sdk, le SDK Python public pour l’API Perplexity Search (import pplx_srch_sdk) : recherche web en direct et extraits de pages pertinents pour la requête depuis du code Python. Utilisez‑le pour interroger le web depuis un script ou un notebook, lancer de nombreuses recherches en parallèle, obtenir des extraits pertinents depuis des URL spécifiques, créer des pipelines de recherche à plusieurs étapes ou gérer les erreurs de l’API Search avec des exceptions typées.
