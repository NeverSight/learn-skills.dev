Installez et utilisez pplx-srch-sdk, le SDK Python public pour l'API Perplexity Search (importer pplx_srch_sdk) : recherche Web en direct et extraits de page pertinents pour les requêtes à partir du code Python. Permet de rechercher sur le Web à partir d'un script ou d'un bloc-notes, d'effectuer de nombreuses recherches simultanément, d'obtenir des extraits pertinents pour une requête à partir d'URL spécifiques, de créer des pipelines de recherche en plusieurs étapes ou de gérer les erreurs de l'API de recherche avec des exceptions tapées.
