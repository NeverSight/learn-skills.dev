Используйте этот навык всякий раз, когда пользователь хочет взаимодействовать с открытой платформой Zhihu через инструмент командной строки `zhihu`. Это включает поиск контента Zhihu, выполнение глобального веб‑поиска через Zhihu, использование API чата/завершения Zhida, проверку горячего списка Zhihu, запрос квоты API, перечисление/поиск/загрузку в базы знаний, поиск RAG по базам знаний, парсинг PDF‑файлов, генерацию PPT из ответов/статей Zhihu, получение данных пользователя Zhihu (контент, подписки, коллекции, списки избранного), поиск вопросов для ответа и чтение резюме ответов, просмотр полного текста вашего собственного контента, комментариев и статистики создателя, настройку учётных данных или понимание вывода CLI. Используйте его даже если пользователь просто сказал «zhihu», «search zhihu», «zhida», «知乎», «热榜», «hot list», «额度», «quota», «知识库», «knowledge base», «RAG», «PDF 解析», «PPT 生成», «收藏夹», «favlist», «问题推荐», «创作数据», «creator stats» или упомянул проект `zhihu-cli`. Пожалуйста, всегда отвечайте на языке пользователя.
