13角評価基準と対立的ノイズフィルタリングを用いて、GitHub のプルリクエストまたはローカル Git ブランチの差分を欠陥、削除された挙動、仕様ドリフトについてレビューします。GitHub PR（#N または URL）をレビューする際、プルリクエストを作成する前にローカルの機能ブランチを監査する際、あるいは /pr‑review で呼び出す際に使用してください。既存の PR レビューコメントや CI 失敗のトリアージ（pr‑triage を使用）、マルチリポジトリのブランチクリーンアップ（pr‑cleanup を使用）、Google3 Piper の changelist（cl‑finalize または review を使用）には使用しないでください。
