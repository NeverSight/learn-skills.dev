Revisiona le Pull Request di GitHub o i diff dei rami Git locali per difetti, comportamenti rimossi e deriva di specifica, utilizzando una rubrica a 13 angoli e filtraggio di rumore avversario. Usalo quando revisioni una PR di GitHub (#N o URL), auditando un ramo di funzionalità locale prima di aprire una PR, o invocato tramite /pr-review. Non usarlo per il triage di commenti di revisione PR esistenti o fallimenti CI (usa pr‑triage), pulizie di rami multi‑repo (usa pr‑cleanup), o changelist di Google3 Piper (usa cl‑finalize o review).
