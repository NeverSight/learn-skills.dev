يقوم بمراجعة طلبات السحب على GitHub أو اختلافات الفروع المحلية في Git لاكتشاف العيوب والسلوك المزال والانحراف عن المواصفات باستخدام مقياس من 13 بُعد وتصفية الضوضاء العدائية. يُستعمل عند مراجعة طلب سحب على GitHub (رقم #N أو رابط)، تدقيق فرع ميزة محلي قبل فتح طلب سحب، أو عند استدعائه عبر /pr‑review. لا يُستخدم لتصنيف تعليقات مراجعة طلبات السحب القائمة أو أخطاء CI (استخدم pr‑triage)، أو لتنظيف الفروع عبر مستودعات متعددة (استخدم pr‑cleanup)، أو لقوائم تغييرات Google3 Piper (استخدم cl‑finalize أو review).

يرجى دائماً الرد بلغة المستخدم.
