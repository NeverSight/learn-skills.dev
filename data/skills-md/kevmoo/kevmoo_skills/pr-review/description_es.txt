Revisa Pull Requests de GitHub o diffs de ramas locales de Git en busca de defectos, comportamiento eliminado y desviaciones de especificación, usando una rúbrica de 13 ángulos y filtrado de ruido adversarial. Úsalo al revisar un PR de GitHub (#N o URL), al auditar una rama de característica local antes de abrir un PR, o al invocarlo mediante /pr-review. No lo uses para clasificar comentarios de revisión de PR existentes o fallos de CI (usa pr-triage), limpiezas masivas de ramas en varios repositorios (usa pr-cleanup), ni para changelists de Google3 Piper (usa cl-finalize o review).
