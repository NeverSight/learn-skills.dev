Examine les pull requests GitHub ou les diff de branches Git locales à la recherche de défauts, de comportements supprimés et de dérive de spécification en utilisant une grille d’évaluation à 13 angles et un filtrage de bruit adversarial. Utilisez‑le lors de la révision d’une PR GitHub (#N ou URL), de l’audit d’une branche de fonctionnalité locale avant d’ouvrir une PR, ou lorsqu’il est invoqué via /pr-review. Ne l’utilisez pas pour le triage des commentaires de revue de PR existants ou des échecs CI (utilisez pr‑triage), les nettoyages de branches multi‑repo (utilisez pr‑cleanup), ou les changelists Google3 Piper (utilisez cl‑finalize ou review).  

Veuillez toujours répondre dans la langue de l’utilisateur.
