Проверяет запросы на слияние GitHub (Pull Requests) или локальные diff‑ы веток Git на наличие дефектов, удалённого поведения и отклонения от спецификации, используя 13‑угловую рубрику и фильтрацию адверсариального шума. Используйте при обзоре PR в GitHub (#N или URL), аудите локальной ветки функции перед открытием PR или при вызове через /pr-review. Не используйте для триажа существующих комментариев к обзорам PR или сбоев CI (используйте pr‑triage), очистки веток в нескольких репозиториях (используйте pr‑cleanup) или списков изменений Google3 Piper (используйте cl‑finalize или review).
