Trie les commentaires ouverts des pull request GitHub, les fils de discussion de revue, les conflits de fusion et les échecs de workflow CI, en vérifiant empiriquement les affirmations des examinateurs avant de proposer un plan d'action structuré. Utilisez-le lorsqu’on vous demande de trier ou de traiter les commentaires d’une PR, les retours de revue, les conflits de fusion ou les vérifications CI échouées sur une pull request GitHub, ou lorsqu’il est invoqué via /pr-triage. Ne l’utilisez pas pour des nettoyages de PR multi‑repo (utilisez pr‑cleanup), une revue de code initiale antagoniste (utilisez pr‑review), ou la triage de changelist Google3 Piper (utilisez cl‑triage).

Veuillez toujours répondre dans la langue de l'utilisateur.
