Triages open GitHub pull request comments, review threads, merge conflicts, and CI workflow failures, empirically verifying reviewer claims before proposing a structured action plan. Use when asked to triage or address PR comments, review feedback, merge conflicts, or failing CI checks on a GitHub pull request, or when invoked via /pr-triage. Don't use for multi-repo PR cleanup sweeps (use pr-cleanup), initial adversarial code review (use pr-review), or Google3 Piper changelist triage (use cl-triage).
