Effettua il triage dei commenti aperti delle pull request su GitHub, delle discussioni di revisione, dei conflitti di merge e dei fallimenti dei workflow CI, verificando empiricamente le affermazioni dei revisori prima di proporre un piano d'azione strutturato. Usa quando ti viene chiesto di fare il triage o gestire commenti di PR, feedback di revisione, conflitti di merge o controlli CI falliti su una pull request di GitHub, o quando viene invocato tramite /pr-triage. Non usarlo per pulizie di PR multi-repo (usa pr-cleanup), revisione iniziale avversaria del codice (usa pr-review) o triage di changelist Google3 Piper (usa cl-triage). Per favore rispondi sempre nella lingua dell'utente.
