Gestisce sweep di pull request multi-repo su GitHub, CL di Gerrit, worktree Git locali e pulizia di rami, insieme alla triage dei prossimi passi delle PR aperte attive. Usalo quando ti viene chiesto di eseguire una pulizia delle PR, potare worktree o rami fusi, rivedere le PR aperte e i prossimi passi attraverso i repository, o riconciliare i checkout locali in ~/github con GitHub, Gerrit e le sessioni Jetski attive. Non usarlo per la triage di commenti di revisione inline o fallimenti CI su una singola PR (usa github-pr-triage o pr-loop), per creare nuovi worktree (usa new-worktree) o per la triage di CL di Google3 Piper (usa cl-triage).
