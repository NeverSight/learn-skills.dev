Orchestrates multi-repo GitHub pull request, Gerrit CL, local Git worktree, and branch cleanup sweeps alongside active open-PR next-step triage. Use when asked to run a PR cleanup sweep, prune merged worktrees or branches, review open PRs and next steps across repositories, or reconcile local checkouts in ~/github against GitHub, Gerrit, and active Jetski sessions. Don't use for triaging inline review comments or CI failures on a single PR (use github-pr-triage or pr-loop), creating new worktrees (use new-worktree), or Google3 Piper CL triage (use cl-triage).
