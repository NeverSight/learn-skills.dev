يدير عمليات تنظيف طلبات السحب عبر مستودعات متعددة على GitHub، ومراجعات Gerrit CL، وأشجار عمل Git المحلية، والفروع، إلى جانب تصنيف الخطوات التالية للطلبات المفتوحة النشطة. استخدمه عندما يُطلب تنفيذ عملية تنظيف للطلبات، أو حذف الأشجار المدمجة أو الفروع، أو مراجعة الطلبات المفتوحة والخطوات التالية عبر المستودعات، أو مراجعة المراجعات المحلية في ‎~/github مقابل GitHub وGerrit وجلسات Jetski النشطة. لا تستخدمه لتصنيف تعليقات المراجعة المضمنة أو فشل CI على طلب واحد (استخدم github‑pr‑triage أو pr‑loop)، أو إنشاء أشجار عمل جديدة (استخدم new‑worktree)، أو تصنيف CL على Google3 Piper (استخدم cl‑triage).
