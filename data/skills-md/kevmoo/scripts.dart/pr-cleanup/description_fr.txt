Orchestre les balayages de pull request GitHub multi‑référentiels, les CL Gerrit, les worktrees Git locaux et le nettoyage des branches, en parallèle du triage des prochaines étapes des PR ouvertes. À utiliser lorsqu’on vous demande d’exécuter un balayage de nettoyage des PR, de supprimer les worktrees ou les branches fusionnées, de passer en revue les PR ouvertes et leurs prochaines étapes à travers les dépôts, ou de concilier les copies locales dans ~/github avec GitHub, Gerrit et les sessions Jetski actives. Ne pas utiliser pour le triage des commentaires de revue en ligne ou des échecs CI sur une seule PR (utilisez github‑pr‑triage ou pr‑loop), la création de nouveaux worktrees (utilisez new‑worktree), ou le triage des CL Piper de Google3 (utilisez cl‑triage). Veuillez toujours répondre dans la langue de l’utilisateur.
