Audita e standardizza i repository GitHub personali sotto ~/github/kevmoo per la parità dei workflow CI, le configurazioni di formattazione Markdown, i lint dell'analizzatore e le regole di protezione dei branch remoti su GitHub. Usalo quando controlli o correggi i workflow CI (lower_bound.yml, complexity.yml, autosubmit.yml, dependabot.yml, markdown.yml), .prettierrc.json, i lint di analysis_options.yaml, o le regole di auto‑merge e verifica dello stato remote su uno o tutti i repository personali. Non usarlo per repository non kevmoo (dart‑lang/*, flutter/*, google/*), per il refactoring del codice sorgente Dart (usa dart‑cleanup) o per il pruning di PR e branch worktree (usa pr‑cleanup).
