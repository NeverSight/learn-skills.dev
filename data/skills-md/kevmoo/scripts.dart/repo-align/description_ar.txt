يقوم بتدقيق وتوحيد مستودعات GitHub الشخصية الموجودة تحت ~/github/kevmoo لضمان تجانس سير عمل CI، وإعدادات تنسيق Markdown، وتنبيهات المحلل، وقواعد حماية الفروع البعيدة على GitHub. استخدمه عند فحص أو إصلاح سير عمل CI (lower_bound.yml، complexity.yml، autosubmit.yml، dependabot.yml، markdown.yml)، ملف .prettierrc.json، تنبيهات analysis_options.yaml، أو قواعد الدمج التلقائي وفحص الحالة البعيدة عبر مستودع واحد أو جميع المستودعات الشخصية. لا تستخدمه للمستودعات غير الخاصة بـ kevmoo (dart-lang/*، flutter/*، google/*)، أو لإعادة هيكلة شفرة Dart (استخدم dart-cleanup)، أو لتقليص الفروع في طلبات السحب وشجرة العمل (استخدم pr-cleanup).
