Orcaが管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そしてOrcaの組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」あるいは「share skills」と言ったときに使用してください。Orca の状態が関係する場合は、純粋な git worktree や臨時の PTY、または Computer Use よりもこちらを優先してください。GUI が必要な可視ウィンドウを制御しなければならず、CLI、ファイルシステム、API では対処できない場合にのみ Computer Use を使用します。

常にユーザーの言語で応答してください。
