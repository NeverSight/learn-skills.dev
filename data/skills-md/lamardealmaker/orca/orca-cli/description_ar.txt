قم بتشغيل worktrees التي تديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات الناتجة، ومشاركة المهارات، وتعليقات worktree، ومتصفح Orca المدمج عبر واجهة سطر الأوامر `orca`. استخدمها عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضلها على worktree الخام في git أو PTYs المؤقتة أو Computer Use عندما تكون حالة Orca متضمنة. استخدم Computer Use فقط عندما يتطلب الأمر التحكم في نافذة مرئية لا يمكن للواجهة النصية أو نظام الملفات أو API التحكم فيها.
