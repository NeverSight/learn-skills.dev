Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser integrato di Orca tramite la CLI `orca`. Usala quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferiscila rispetto a un worktree git grezzo, PTY ad hoc o Uso del computer quando è coinvolto lo stato di Orca. Usa l'Uso del computer solo quando è necessaria una finestra visibile che richieda un controllo GUI che la CLI, il file system o l'API non possono gestire.  

Rispondi sempre nella lingua dell'utente.
