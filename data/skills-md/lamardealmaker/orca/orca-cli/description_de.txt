Betreiben Sie von Orca verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaum‑Kommentare und Orcas eingebetteten Browser über die `orca`‑CLI. Verwenden Sie dies, wenn der Nutzer sagt „$orca-cli“, „Orca‑Arbeitsbaum“, „Child‑Arbeitsbaum“, „spawn codex/claude in einem Arbeitsbaum“, „read/wait/send Orca‑Terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca‑Browser“, „orca artifacts“ oder „share skills“. Bevorzugen Sie es gegenüber rohem Git‑Worktree, ad‑hoc‑PTYs oder Computer‑Use, wenn Orca‑Zustand involviert ist. Verwenden Sie Computer‑Use nur, wenn ein sichtbares Fenster GUI‑Steuerung benötigt, die eine CLI, das Dateisystem oder eine API nicht leisten kann.
