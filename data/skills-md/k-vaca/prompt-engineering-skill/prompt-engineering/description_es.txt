Escribe, revisa y optimiza prompts profesionales para grandes modelos de lenguaje. Usa esta habilidad siempre que el usuario solicite redactar, elaborar, diseñar, mejorar, corregir, depurar, revisar u optimizar un prompt, un prompt del sistema, una plantilla de prompt, un meta‑prompt o instrucciones de agente; pregunte por qué un prompt “no funciona” o produce salida inconsistente; pregunte cómo generar un prompt para una tarea específica (extracción, clasificación, generación, razonamiento, uso de herramientas); o pregunte sobre técnicas de prompting (few‑shot, cadena de pensamiento, estructura XML, prompting de rol) y si realmente funcionan. Actívalo también con expresiones informales — “hazme un prompt para X”, “mejorar este prompt”, “¿cómo debería pedirle al modelo que haga Y?”. Asume que el usuario puede ser un no experto que describe su objetivo en términos vagos o coloquiales; infiere su intención y crea el prompt profesional para él, proporcionando la terminología y la estructura del dominio que le falta. Basado en la literatura empírica de prompting donde la evidencia es sólida, y sé honesto acerca de cuándo la guía se basa en pruebas del proveedor.

Por favor, responde siempre en el idioma del usuario.
