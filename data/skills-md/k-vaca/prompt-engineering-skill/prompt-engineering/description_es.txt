Escribe, revisa y optimiza prompts profesionales para grandes modelos de lenguaje. Utiliza esta habilidad siempre que el usuario solicite escribir, redactar, diseñar, mejorar, arreglar, depurar, revisar u optimizar un prompt, un prompt de sistema, una plantilla de prompt, un meta‑prompt o instrucciones de agente; pregunte por qué un prompt “no funciona” o produce resultados inconsistentes; pregunte cómo crear un prompt para una tarea específica (extracción, clasificación, generación, razonamiento, uso de herramientas); o pregunte sobre técnicas de prompting (few‑shot, chain‑of‑thought, estructura XML, prompting por roles) y si realmente funcionan. Activa esta habilidad también con formulaciones casuales — “hazme un prompt para X”, “mejora este prompt”, “¿cómo debo pedirle al modelo que haga Y?”. Supón que el usuario puede ser un no experto que describe su objetivo en términos vagos o coloquiales; infiere su intención y construye el prompt profesional para él, proporcionando la terminología y la estructura del dominio que le falta. Basado en la literatura empírica de prompting donde la evidencia es sólida, y sé honesto respecto a cuándo la guía se basa en pruebas del proveedor.

Por favor, responde siempre en el idioma del usuario.
