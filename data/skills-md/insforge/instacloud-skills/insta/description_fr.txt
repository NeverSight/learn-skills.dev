Exploitez l’infrastructure InstaCloud avec le CLI `insta` : créez des projets, ajoutez des services postgres / stockage / calcul, déployez des applications, créez des environnements de branches jetables (BD isolée + stockage + calcul par branche), liez les identifiants de service dans l’environnement de calcul, injectez les secrets utilisateur dans `.env`, exécutez plusieurs agents chacun dans sa propre branche, gérez les approbations de gouvernance, consultez les métriques / journaux / utilisation, et promouvez les branches vers la branche principale. Utilisez cette compétence lorsque vous travaillez sur un projet géré par InstaCloud (un répertoire `.insta/` ou le CLI `insta`), lorsque l’utilisateur mentionne InstaCloud ou insta, ET lorsqu’il demande à déployer une application, a besoin d’une base de données / backend / stockage d’objets, souhaite des environnements de prévisualisation ou de bac à sable par agent, veut une infrastructure à branches, veut migrer une application existante depuis Heroku / Railway / Fly / Render, ou mentionne la configuration d’agent ou MCP — même s’il ne cite pas explicitement « InstaCloud ». Cela couvre également le serveur MCP distant insta‑cloud (outils `insta_*`) et le runtime auto‑hébergé insta‑oss (même CLI, démon local).
