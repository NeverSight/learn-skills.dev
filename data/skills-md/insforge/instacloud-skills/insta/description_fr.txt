Exploitez l'infrastructure InstaCloud avec la CLI `insta` : créez des projets, ajoutez des services postgres/stockage/calcul, déployez des applications, créez des environnements de branche jetables (base de données isolée + stockage + calcul par branche), liez les informations d'identification du service à l'environnement de calcul, câblez les secrets d'utilisateur dans `.env`, exécutez plusieurs agents chacun dans leur propre branche, gérez les approbations de gouvernance, vérifiez les métriques/journaux/utilisation et promouvez les branches au rang principal. Utilisez cette compétence lorsque vous travaillez dans un projet géré par InstaCloud (un répertoire `.insta/` ou la CLI `insta`), lorsque l'utilisateur mentionne InstaCloud ou insta, ET lorsqu'il demande à déployer une application, a besoin d'une base de données/backend/stockage d'objets, souhaite un aperçu ou des environnements sandbox par agent, souhaite une infrastructure branchable, souhaite migrer une application existante depuis Heroku / Railway / Fly / Render, ou mentionne la configuration de l'agent ou MCP - même s'il ne le dit pas. "InstaCloud" explicitement. Couvre également le serveur MCP distant insta-cloud (outils insta_*) et le runtime insta-oss auto-hébergé (même CLI, démon local).
