Betreiben Sie die InstaCloud-Infrastruktur mit der „insta“-CLI: Erstellen Sie Projekte, fügen Sie Postgres-/Speicher-/Rechendienste hinzu, stellen Sie Apps bereit, erstellen Sie Einweg-Zweigumgebungen (isolierte Datenbank + Speicher + Rechenleistung pro Zweig), binden Sie Dienstanmeldeinformationen in die Rechenumgebung, verknüpfen Sie Benutzergeheimnisse mit „.env“, führen Sie mehrere Agenten jeweils in ihrem eigenen Zweig aus, verwalten Sie Governance-Genehmigungen, überprüfen Sie Metriken/Protokolle/Nutzung und stufen Sie Zweige zur Hauptniederlassung hoch. Verwenden Sie diese Fähigkeit, wenn Sie in einem von InstaCloud verwalteten Projekt arbeiten (ein „.insta/“-Verzeichnis oder die „insta“-CLI), wenn der Benutzer InstaCloud oder insta erwähnt UND wenn er die Bereitstellung einer App anfordert, eine Datenbank/Backend/Objektspeicher benötigt, eine Vorschau oder eine Sandbox-Umgebung pro Agent wünscht, eine verzweigbare Infrastruktur wünscht, eine vorhandene App von Heroku/Eisenbahn/Fly/Render migrieren möchte oder Agent-Setup oder MCP erwähnt – auch wenn er es nicht sagt „InstaCloud“ explizit. Deckt auch den insta-cloud-Remote-MCP-Server (insta_*-Tools) und die selbstgehostete insta-oss-Laufzeitumgebung (gleiche CLI, lokaler Daemon) ab.
