使用 `insta` CLI 操作 InstaCloud 基礎設施：建立專案、加入 Postgres／儲存／運算服務、部署應用程式、建立一次性分支環境（每個分支都有獨立的資料庫、儲存與運算），將服務憑證綁定至運算環境、將使用者密鑰注入 `.env`、在各自的分支中執行多個代理、處理治理批准、檢查指標／日誌／使用量，並將分支提升為主分支。當在 InstaCloud 管理的專案（`.insta/` 目錄或 `insta` CLI）中工作、使用者提到 InstaCloud 或 insta，且使用者要求部署應用程式、需要資料庫／後端／物件儲存、想要預覽或每個代理的沙盒環境、想要可分支的基礎設施、想要從 Heroku／Railway／Fly／Render 移植現有應用程式，或提到代理設定或 MCP 時，皆可使用此技能——即使他們未明確說出「InstaCloud」。也涵蓋 insta‑cloud 遠端 MCP 伺服器（insta_* 工具）以及自行托管的 insta‑oss 執行環境（相同 CLI，本機守護程式）。
