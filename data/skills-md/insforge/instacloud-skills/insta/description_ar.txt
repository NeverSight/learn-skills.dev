تشغيل البنية التحتية لـ InstaCloud باستخدام واجهة سطر الأوامر `insta`: إنشاء المشاريع، وإضافة خدمات postgres/التخزين/الحوسبة، ونشر التطبيقات، وإنشاء بيئات فرعية يمكن التخلص منها (قاعدة بيانات معزولة + تخزين + حوسبة لكل فرع)، وربط بيانات اعتماد الخدمة في بيئة الحوسبة، وإرسال أسرار المستخدم إلى `.env`، وتشغيل وكلاء متعددين في كل فرع خاص بهم، والتعامل مع موافقات الإدارة، والتحقق من المقاييس/السجلات/الاستخدام، وتعزيز الفروع إلى الرئيسية. استخدم هذه المهارة عند العمل في مشروع يديره InstaCloud (a `.insta/` dir أو `insta` CLI)، عندما يذكر المستخدم InstaCloud أو insta، وعندما يطلبون نشر تطبيق، يحتاجون إلى قاعدة بيانات/واجهة خلفية/تخزين كائن، أو يريدون بيئات معاينة أو وضع حماية لكل وكيل، أو يريدون بنية تحتية قابلة للتفرع، أو يريدون ترحيل تطبيق موجود من Heroku / Railway / Fly / Render، أو ذكر إعداد الوكيل أو MCP - حتى لو كانوا لا تقل "InstaCloud" بشكل صريح. يغطي أيضًا خادم MCP البعيد لـ insta-cloud (أدوات insta_*) ووقت تشغيل insta-oss المستضاف ذاتيًا (نفس سطر الأوامر، البرنامج الخفي المحلي).
