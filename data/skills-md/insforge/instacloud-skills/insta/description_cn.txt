使用“insta”CLI 操作 InstaCloud 基础设施：创建项目、添加 postgres/存储/计算服务、部署应用程序、创建一次性分支环境（每个分支隔离的数据库 + 存储 + 计算）、将服务凭证绑定到计算环境中、将用户机密连接到“.env”中、在各自的分支中运行多个代理、处理治理审批、检查指标/日志/使用情况以及将分支提升到主分支。在 InstaCloud 管理的项目（“.insta/”目录或“insta” CLI）中工作时，当用户提到 InstaCloud 或 insta 时，并且当他们要求部署应用程序、需要数据库/后端/对象存储、需要预览或每个代理沙箱环境、需要可分支基础架构、想要从 Heroku/Railway/Fly/Render 迁移现有应用程序，或者提及代理设置或 MCP 时，请使用此技能，或者提及代理设置或 MCP - 即使他们没有说明确“InstaCloud”。还涵盖 insta-cloud 远程 MCP 服务器（insta_* 工具）和自托管 insta-oss 运行时（相同的 CLI、本地守护进程）。
