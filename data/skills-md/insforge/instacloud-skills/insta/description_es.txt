Opera la infraestructura de InstaCloud con la CLI `insta`: crea proyectos, añade servicios de PostgreSQL/almacenamiento/cómputo, despliega aplicaciones, crea entornos de rama desechables (BD + almacenamiento + cómputo aislados por rama), vincula credenciales de servicio al entorno de cómputo, inyecta secretos de usuario en `.env`, ejecuta múltiples agentes cada uno en su propia rama, gestiona aprobaciones de gobernanza, revisa métricas/registros/uso y promueve ramas a la rama principal. Utiliza esta habilidad al trabajar en un proyecto gestionado por InstaCloud (un directorio `.insta/` o la CLI `insta`), cuando el usuario mencione InstaCloud o insta, y cuando soliciten desplegar una aplicación, necesiten una base de datos/backend/almacenamiento de objetos, quieran entornos de vista previa o sandbox por agente, deseen infraestructura con ramas, quieran migrar una aplicación existente desde Heroku / Railway / Fly / Render, o mencionen la configuración de agentes o MCP, incluso si no dicen explícitamente “InstaCloud”. También cubre el servidor remoto MCP insta‑cloud (herramientas `insta_*`) y el entorno autoalojado insta‑oss (misma CLI, daemon local).
