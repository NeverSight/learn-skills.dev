「insta」 CLI で InstaCloud インフラストラクチャを操作します。プロジェクトの作成、postgres/ストレージ/コンピューティング サービスの追加、アプリのデプロイ、使い捨てブランチ環境 (ブランチごとに分離された DB + ストレージ + コンピューティング) の作成、サービス資格情報のコンピューティング環境へのバインド、ユーザー シークレットの `.env` への接続、それぞれ独自のブランチでの複数のエージェントの実行、ガバナンスの承認の処理、メトリクス/ログ/使用状況の確認、ブランチのメインへの昇格。 InstaCloud で管理されるプロジェクト (`.insta/` ディレクトリまたは `insta` CLI) で作業するとき、ユーザーが InstaCloud または insta について言及するとき、さらにアプリのデプロイを要求するとき、データベース/バックエンド/オブジェクト ストレージが必要なとき、プレビューまたはエージェントごとのサンドボックス環境が必要なとき、分岐可能なインフラストラクチャが必要なとき、既存のアプリを Heroku / Railway / Fly / Render から移行したいとき、またはエージェントのセットアップや MCP について言及したとき、このスキルを使用します。明示的に「InstaCloud」とは言わないでください。また、insta-cloud リモート MCP サーバー (insta_* ツール) とセルフホスト型 insta-oss ランタイム (同じ CLI、ローカル デーモン) についても説明します。
