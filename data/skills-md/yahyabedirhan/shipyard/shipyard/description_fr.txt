Modifiez le config.toml de shipyard, l'application de la barre de menus macOS qui répertorie les pull requests, les issues et les exécutions de workflow. Utilisez‑la lorsque vous devez changer mon shipyard ou l'application shipyard (sa disposition, les projets, les notifications, ce qu'elle affiche) : surveiller ou regrouper des dépôts, afficher ou masquer les issues, les runs, les drafts ou les éléments de quelqu’un, basculer le menu entre une liste et des onglets, modifier le moment où elle notifie, afficher les pings provenant de mes autres machines, ou corriger son fichier de configuration. Utilisez‑la également pour me pinguer via shipyard avec la commande `shipyard ping`, depuis mon Mac ou une autre machine exécutant Herdr : lorsqu’une PR est prête, quand vous avez besoin de mon avis, ou pour me ramener à ce panneau. Utilisez `shipyard notify` depuis n’importe laquelle de mes machines pour publier une notice d’état (tests en cours, terminé) qui ne nécessite aucune action de ma part. Et utilisez‑la pour ouvrir, quitter, piloter ou capturer l’écran de l’application shipyard sur mon Mac avec `shipyard app`, `panel` et `screenshot`, sur mes données ou celles d’une démo. Enfin, servez‑vous‑en pour mes notes, conservées dans Notion par projet shipyard : prendre une note que je dicte, en retrouver une par son numéro, ou les lister, les nettoyer ou les archiver.
