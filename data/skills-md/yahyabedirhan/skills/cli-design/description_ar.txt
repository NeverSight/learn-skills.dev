صمم، واشرح، وقم بتدقيق أو إعادة تصميم واجهة سطر الأوامر من خلال إطار عمل تسليم تصميم CLI، للأشخاص والسكريبتات والوكالات التي تستدعيها. استخدم ذلك عند تصميم CLI جديد أو أوامر جديدة، ومراجعة أوامر CLI الحالية، والعلامات، والإخراج، والأخطاء أو المساعدة، وإعادة هيكلة أو إعادة تسمية شجرة الأوامر، أو اتخاذ قرار حول سؤال واحد مثل اسم الأمر أو شكل العلامة.
