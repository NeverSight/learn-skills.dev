Progettare, spiegare o ridisegnare un sistema a livello di servizi, archivi dati, API e scalabilità, attraverso il framework di delivery della progettazione di sistemi. Utilizzarlo quando si progetta un nuovo backend o sistema distribuito, si spiega o documenta uno esistente, lo si ridisegna o scala, oppure si sceglie un database, una cache, una coda o un protocollo.
