صمِّم أو اشرح أو أعد تصميم نظام على مستوى الخدمات ومخازن البيانات وواجهات برمجة التطبيقات والقدرة على التوسع، عبر إطار عمل تسليم تصميم النظام. استخدمه عند تصميم خلفية جديدة أو نظام موزّع، أو عند شرح أو توثيق نظام موجود، أو عند إعادة تصميمه أو توسيعه، أو عند اختيار قاعدة بيانات أو ذاكرة تخزين مؤقت أو طابور أو بروتوكول.
