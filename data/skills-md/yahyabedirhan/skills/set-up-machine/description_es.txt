Configura o audita los arneses del agente de codificación de una máquina a partir de una tabla de reglas y del repositorio del poste de trabajo del usuario: las instrucciones globales compartidas que cada arnés lee, las reglas globales (denegar, preguntar, permitir‑y‑reportar) que cada una aplica, el gancho previo a la herramienta, la memoria desactivada, los valores predeterminados declarados de Codex CLI y Pi, los complementos que recibe cada arnés, y las habilidades y herramientas que el repositorio del poste de trabajo enumera para instalar. Úsalo para una máquina nueva o VPS, para auditar la configuración del agente de esta máquina, o cuando otra habilidad indique comprobar la máquina.
