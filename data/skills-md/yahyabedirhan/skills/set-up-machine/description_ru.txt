Настройте или проведите аудит кодирующих агент‑харнесов машины, используя одну таблицу правил и репозиторий рабочей станции пользователя — общие глобальные инструкции, которые читает каждый харнес, глобальные правила (deny, ask, allow‑and‑report), которые каждый из них применяет, прединструментальный хук, отключённую память, объявленные по умолчанию Codex CLI и Pi, плагины, получаемые каждым харнесом, а также навыки и инструменты, перечисленные в репозитории рабочей станции для установки. Используйте для новой машины или VPS, чтобы проверить настройку агентов этой машины, или когда другой навык требует проверить машину.
