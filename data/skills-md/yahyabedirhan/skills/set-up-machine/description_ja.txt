1 つのルールテーブルとユーザーのワークステーションリポジトリから、マシンのコーディングエージェントハーネスを設定または監査します — すべてのハーネスが読む共有グローバル指示、各ハーネスが適用するグローバルルール（deny、ask、allow‑and‑report）、事前ツールフック、メモリをオフに保持、宣言された Codex CLI と Pi のデフォルト、各ハーネスが取得するプラグイン、そしてワークステーションリポジトリがインストール対象として列挙するスキルとツールです。新しいマシンや VPS の設定、またはこのマシンのエージェント設定の監査、さらに別のスキルがマシンを確認するよう指示した場合に使用してください。
