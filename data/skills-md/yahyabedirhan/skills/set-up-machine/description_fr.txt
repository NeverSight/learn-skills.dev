Configurer ou auditer les harnais d’agent de codage d’une machine à partir d’une seule table de règles et du dépôt du poste de travail de l’utilisateur — les instructions globales partagées que chaque harnais lit, les règles globales (refuser, demander, autoriser‑et‑rapporter) que chacun applique, le crochet pré‑outil, la mémoire désactivée, les paramètres déclarés du CLI Codex et de Pi, les plugins attribués à chaque harnais, ainsi que les compétences et outils listés dans le dépôt du poste de travail à installer. Utilisez‑le pour une nouvelle machine ou un VPS, pour auditer la configuration de l’agent de cette machine, ou lorsqu’une autre compétence indique de vérifier la machine.

Veuillez toujours répondre dans la langue de l’utilisateur.
