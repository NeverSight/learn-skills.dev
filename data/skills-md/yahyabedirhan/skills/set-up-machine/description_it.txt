Configura o verifica i harness dell'agente di codifica di una macchina a partire da una tabella delle regole e dal repository della postazione dell'utente: le istruzioni globali condivise che ogni harness legge, le regole globali (nega, richiedi, consenti-e-segnala) che ciascuno applica, l'hook pre-tool, la memoria mantenuta disattivata, i valori predefiniti dichiarati per Codex CLI e Pi, i plugin assegnati a ciascun harness e le competenze e gli strumenti elencati nel repository della postazione da installare. Utilizzalo per una nuova macchina o VPS, per verificare la configurazione dell'agente di questa macchina, o quando un'altra competenza indica di controllare la macchina.
