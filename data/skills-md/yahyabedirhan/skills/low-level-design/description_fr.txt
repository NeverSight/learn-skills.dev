Concevoir, expliquer ou redéfinir le code au niveau des modules, des classes, des fichiers et des dossiers, à travers le cadre de livraison de conception de bas niveau. Utilisez-le lors de la conception d'un nouveau projet ou d'une fonctionnalité à partir d'une spécification, pour expliquer comment une base de code existante est structurée, pour en restructurer une, ou pour décider où le code doit résider.
