Configurer ou auditer un projet pour les agents de codage - la machine a d'abord vérifié avec set-up-machine, AGENTS.md comme le unique fichier de règles avec CLAUDE.md le pointant, le suivi des tickets, les étiquettes de triage et les documents de domaine, le .gitignore du standard de dossiers, et les fichiers de harnais du projet maintenus en mode autoriser‑seulement. Utilisez-le pour un projet nouveau ou existant, pour auditer la configuration des agents d'un projet, ou lorsqu'une compétence ne trouve aucun suivi des tickets configuré.
