Configura o verifica un progetto per agenti di coding: la macchina controlla prima con set-up-machine, AGENTS.md come unico file di regole con CLAUDE.md che punta a esso, il tracker dei problemi, le etichette di triage e i documenti di dominio, il .gitignore dello standard della cartella e i file di harness del progetto mantenuti in modalità allow‑only. Usalo per un progetto nuovo o esistente, per verificare la configurazione degli agenti di un progetto, o quando una skill non trova un tracker dei problemi configurato.
