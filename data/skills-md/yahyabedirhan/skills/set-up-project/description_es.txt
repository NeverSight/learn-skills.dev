Configure o audite un proyecto para agentes de codificación: la máquina se verificó primero con set-up-machine, AGENTS.md como el único archivo de reglas con CLAUDE.md apuntando a él, el rastreador de problemas, las etiquetas de triaje y los documentos de dominio, el estándar de carpeta .gitignore y los archivos de arnés de proyecto que se mantienen solo permitidos. Se utiliza para un proyecto nuevo o existente, para auditar la configuración del agente de un proyecto o cuando una habilidad no encuentra ningún rastreador de problemas configurado.
