يجب استخدام هذه المهارة عندما يطلب المستخدم كتابة قصة متفرّعة، أو خيالًا تفاعليًا، أو «اختر مغامرتك»، أو تخطيط الفروع، أو رسم مخطط الاختيارات، أو إضافة اختيار، أو لعبة كتب، أو Twine، أو Ink، أو صياغة فرع، أو عندما تعيد الفروع الالتقاء، أو إضافة نهاية، أو فصل غير قابل للوصول، أو استمرارية المسار، أو «الحالة تختلف بحسب المسار»، أو عندما يرغب في تخطيط أو صياغة أو تعديل مشروع قصة تحمل فصوله `اختيارات`. لا تُستخدم لتحويل كتاب خطي نهائي إلى نسخة تفاعلية في Ink أو Twine (استخدم التكييف).
