يجب استخدام هذه المهارة عندما يطلب المستخدم «كتابة خطاب استفسار» أو «استفسار» أو «الاستفسار» أو «عرض مختصر» أو «ملخص قصير» أو «نص الغلاف الخلفي» أو «نص الغلاف الأمامي» أو «عناوين مقارنة» أو «عناوين مماثلة» أو «ملخص للوكيل» أو «إرسال إلى الوكلاء» أو «متتبع التقديم» أو «وصف النشر الذاتي» أو «وصف التجار»، أو يرغب في إعداد وتتبع تقديم مخطوطة مكتملة إلى الوكلاء أو الناشرين أو التجار. يرجى دائمًا الرد بلغة المستخدم.
