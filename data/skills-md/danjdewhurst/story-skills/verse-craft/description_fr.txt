Cette compétence doit être utilisée lorsque l'utilisateur demande de « écrire un poème », « écrire un limerick », « écrire un sonnet », « haïku », « villanelle », « ballade », « paroles de chanson », « une chanson pour mon personnage », « une rime », « couplets rimés », « cela scanne-t‑il », « vérifier le mètre », « corriger le rythme de ce poème », « schéma de rimes », « pentamètre iambique », « une prophétie en vers », « une comptine », « livre d’images rimé », ou veut un vers écrit, scanné ou révisé, que ce soit dans le cadre d’un projet d’histoire ou comme poème autonome. PAS pour des rimes accidentelles dans la prose (utiliser la révision de lignes) ni pour demander la permission de citer le poème de quelqu’un d’autre (utiliser la révision éditoriale).

Veuillez toujours répondre dans la langue de l'utilisateur.
