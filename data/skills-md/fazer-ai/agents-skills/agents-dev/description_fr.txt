Mode développeur du faire.ai agents : travailler sur le code source. Clone le dépôt (Free public ou Pro via le proxy git du hub), conseille sur les bonnes pratiques et les invariants (séparation Free/Full, additivité et conventions de docs/), demande de manière proactive ce que l'utilisateur veut implémenter et conduit l'implémentation, et aide à générer sa propre image de déploiement. Utilise-le lorsque l'utilisateur veut DÉVELOPPER, étendre ou contribuer au code du faire.ai agents, pas seulement déployer (onboarding) ou exploiter (opération) une instance.
