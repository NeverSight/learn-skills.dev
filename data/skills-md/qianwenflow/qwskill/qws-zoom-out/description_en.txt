qws Upward Scaling: Step out of the current local context and locate the true level of the problem. First assess whether the problem itself is asked correctly and which approaches can actually be omitted, then provide the final revised solution within the same response; if the question is phrased incorrectly, give the correct question and answer it. Use when invoking this Skill (/qws-zoom-out, $qws-zoom-out, Skill link), when the user says “upward scaling,” “look at the whole picture,” or asks “is this a local problem?” It can also be invoked when the user repeatedly modifies the same issue and remains unsatisfied (meaning similar to “still wrong,” “it gets worse with each change,” “why are you always changing,” “different AIs say different things”), but only include a single note at the end of the reply that upward scaling is possible, without automatically expanding the analysis. Do NOT use for concrete business execution; post‑mortem attribution of failed tasks; retrieval of theoretical/historical standard answers.
