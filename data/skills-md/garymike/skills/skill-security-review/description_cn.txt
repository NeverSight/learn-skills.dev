以高级安全和 AI 架构师的身份评估任意代理技能（Claude Code / Cursor / Copilot / 插件技能，市场或定制，本地或克隆），并生成标准化、风险评级的评估报告。覆盖两个执行面——代理执行面（SKILL.md 指令及代理调用的脚本——提示注入、工具投毒、内存文件投毒）以及开发者执行面（捆绑的测试文件、git 钩子以及在 npm test / git commit / npm install 时自动运行的 npm/pip 生命周期脚本，位于代理之外，使用开发者自身权限——目前的表面技能扫描器大多已覆盖，唯一例外是写入持久化代理内存的情况）。在以下情形使用：有人请求审查、评估、审计或风险评级代理技能，询问安装技能 X 是否安全，提及恶意技能、测试文件或 git‑hook 载荷、内存投毒或技能的“rug pull”，或需要技能风险报告；适用于首次评估和重新评估。请勿用于构建或修改技能。
