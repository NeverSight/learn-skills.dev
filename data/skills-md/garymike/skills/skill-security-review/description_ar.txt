قُم بتقييم أي مهارة للوكيل (Claude Code / Cursor / Copilot / مهارة إضافة، من السوق أو مخصصة، محلية أو مستنسخة) كمهندس أمان وذكاء اصطناعي كبير وانتج تقييمًا موحدًا ومصنّفًا حسب المخاطر. يغطي كلا سطحَي التنفيذ – سطح تنفيذ الوكيل (تعليمات SKILL.md والسكربتات التي يستدعيها الوكيل – حقن التعليمات، تسميم الأدوات، تسميم ملفات الذاكرة) وسطح تنفيذ المطور (ملفات اختبار مدمجة، خطافات Git، وسكربتات دورة حياة npm/pip التي تُنفّذ تلقائيًا عند npm test / git commit / npm install، خارج الوكيل، بأذونات المطور الخاصة – يغطيها معظم فاحصي المهارات السطحية الآن، باستثناء الكتابة إلى ذاكرة الوكيل المستدامة). استخدمه عندما يطلب أحدهم مراجعة، تقييم، تدقيق، أو تصنيف مخاطر مهارة الوكيل، أو يسأل إذا كان من الآمن تثبيت المهارة X، أو يذكر مهارة خبيثة، أو حمولة ملف اختبار أو هوك Git، أو تسميم الذاكرة، أو سحب مخادع في مهارة، أو يريد تقرير مخاطر مهارة؛ يغطي التقييمات الأولية وإعادة التقييم. لا تستخدمه لإنشاء أو تعديل المهارات.

يرجى دائمًا الرد بلغة المستخدم.
