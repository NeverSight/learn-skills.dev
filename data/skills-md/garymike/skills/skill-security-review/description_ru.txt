Оцените любой навык агента (Claude Code / Cursor / Copilot / навык плагина, маркетплейса или индивидуальный, локальный или клонированный) как старший специалист по безопасности и ИИ-архитектуре и предоставьте стандартизированную оценку риска. Охватывает оба уровня выполнения — поверхность выполнения агента (инструкции SKILL.md и скрипты, вызываемые агентом — инъекция подсказок, отравление инструментов, отравление файлов памяти) и поверхность выполнения разработчика (встроенные тестовые файлы, хуки Git и скрипты жизненного цикла npm/pip, которые автоматически запускаются при npm test / git commit / npm install, вне агента, с разрешениями разработчика — этот уровень сканеров навыков теперь в основном покрыт, за исключением записи в постоянную память агента). Используйте, когда кто‑то просит проверить, оценить, одобрить, проаудировать или определить степень риска навыка агента, спрашивает, безопасно ли устанавливать навык X, упоминает злонамеренный навык, тестовый файл или payload хука Git, отравление памяти или «rug pull» в навыке, либо желает получить отчёт о риске навыка; охватывает как первоначальные оценки, так и повторные пересмотры. Не используйте для создания или модификации навыков.
