Évaluez TOUTE compétence d'agent (Claude Code / Cursor / Copilot / compétence d’extension, marketplace ou sur mesure, locale ou clonée) en tant qu’architecte senior en sécurité et IA et produisez une évaluation standardisée, classée par niveau de risque. Couvre LES DEUX surfaces d’exécution – la surface d’exécution de l’agent (instructions SKILL.md et les scripts invoqués par l’agent – injection de prompt, empoisonnement d’outil, empoisonnement de fichier mémoire) ET la surface d’exécution du développeur (fichiers de test inclus, hooks git et scripts du cycle de vie npm/pip qui s’exécutent automatiquement lors de npm test / git commit / npm install, hors de l’agent, avec les permissions du développeur – une surface que les scanners de compétences couvrent désormais majoritairement, à l’exception d’une écriture dans la mémoire persistante de l’agent). Utilisez‑le lorsqu’on vous demande de réviser, d’évaluer, de valider, d’auditer ou de classer le risque d’une compétence d’agent, lorsqu’on demande si la compétence X est sûre à installer, lorsqu’on mentionne une compétence malveillante, un payload de fichier de test ou de hook git, un empoisonnement de mémoire, ou un « rug pull » dans une compétence, ou lorsqu’on souhaite un rapport de risque de compétence ; couvre les premières évaluations et les ré‑évaluations. NE L’UTILISEZ PAS pour créer ou modifier des compétences.

Veuillez toujours répondre dans la langue de l’utilisateur.
