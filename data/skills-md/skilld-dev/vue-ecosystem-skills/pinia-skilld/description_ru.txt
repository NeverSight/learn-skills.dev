Используйте при написании, отладке или рефакторинге кода, который импортирует «pinia», библиотеку хранилища Vue 3. Охватывает pinia 4.x: опционные и setup‑хранилища, состояние, геттеры, действия, подписки, плагины, гидратацию SSR, тестирование, вспомогательные функции map для Options API и диагностику v4 nostics. Предоставляет корректное использование API соответствующей версии и примечания по миграции с v2 и v3.
