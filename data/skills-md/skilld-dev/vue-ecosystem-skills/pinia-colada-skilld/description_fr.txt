Couche de récupération de données pour Vue construite sur Pinia. Utilisez‑la lors de l’écriture, du débogage ou de la révision de code qui importe @pinia/colada (pinia colada), y compris useQuery, useMutation, useInfiniteQuery, defineQuery, l’invalidation du cache des requêtes, les mises à jour optimistes, les plugins, le SSR ou la migration depuis les versions antérieures. Fournit les API 1.4.x actuelles, les modèles et les règles de migration.
