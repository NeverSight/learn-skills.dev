Слой получения данных для Vue, построенный на Pinia. Используется при написании, отладке или обзоре кода, который импортирует @pinia/colada (pinia colada), включая useQuery, useMutation, useInfiniteQuery, defineQuery, инвалидизацию кеша запросов, оптимистичные обновления, плагины, SSR или миграцию с более старых версий. Предоставляет текущие API 1.4.x, паттерны и правила миграции.
