Livello di recupero dati per Vue basato su Pinia. Da utilizzare quando si scrive, si esegue il debug o si revisiona codice che importa @pinia/colada (pinia colada), inclusi useQuery, useMutation, useInfiniteQuery, defineQuery, l’invalidazione della cache delle query, gli aggiornamenti ottimistici, i plugin, SSR o la migrazione da versioni precedenti. Fornisce le API 1.4.x attuali, i pattern e le regole di migrazione.
