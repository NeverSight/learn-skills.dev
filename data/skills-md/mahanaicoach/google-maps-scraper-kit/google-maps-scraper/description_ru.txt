Скрейпер Google Maps для генерации лидов. Преобразует тип бизнеса и место в чистый CSV‑файл местных компаний, используя движок gosom/google-maps-scraper, работающий локально в Docker в виде REST API на localhost:8080. По умолчанию возвращает 8 полей лида (название, телефон, email, веб‑сайт, категория, адрес, рейтинг и количество отзывов), а также опционально профили Instagram, Facebook и LinkedIn или все ~34 исходных поля. Используйте, когда пользователю нужен список лидов, «список [компаний] в [месте]», данные о местных бизнесах, обогащение контактов для мест (email‑ы, телефоны, соцсети) или полный поиск по всему городу, превышающий ~120 результатов Google за один запрос. Не используйте для скрейпинга Instagram, TikTok, YouTube, X или любых других социальных медиа напрямую.
