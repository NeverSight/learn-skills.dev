Подготовьте сайт к переводу Rosey, используя коннектор CloudCannon (RCC) в качестве опционального слоя визуального редактирования. Применяйте, когда пользователь хочет добавить многоязычную поддержку, интернационализировать сайт, настроить Rosey, заменить существующую i18n‑систему (astro-i18n, next-intl, маршрутизацию по пути и т.п.) или обновить RCC с версии 1 до версии 2.
