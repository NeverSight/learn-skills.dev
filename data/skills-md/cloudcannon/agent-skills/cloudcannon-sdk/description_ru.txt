Используйте при вызове API CloudCannon из кода — создании клиента, поиске UUID сайта или организации, программном чтении или записи файлов на размещённом сайте, запуске и проверке сборок, либо обращении к конечной точке CloudCannon, для которой у CLI нет команды (DAM, резервные копии, история синхронизации, сканирование сайта, скриншоты, подключения провайдеров, копирование или удаление сайта).
