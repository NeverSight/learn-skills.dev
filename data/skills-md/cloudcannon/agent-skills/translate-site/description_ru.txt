Переведите сайт, готовый к использованию Rosey, с помощью ИИ. Охватывает JSON-файлы локали Rosey (непереведенные + устаревшие записи) и файлы коллекции контента, разделенные по каталогам (MDX/MD с вступительной частью). Используйте, когда пользователь хочет перевести файлы локали, заполнить недостающие переводы, обновить устаревшие переводы, выполнить массовый перевод локали или перевести каталоги содержимого для каждой локали (blog_fr/, blog_de/).
