Используйте при локальном запуске сайта CloudCannon командой `cloudcannon dev` — это запускает локальный цикл редактирования, позволяя пользователю редактировать в редакторе CloudCannon и видеть перестроение сайта, выбирать команду сборки для каждого SSG и обращаться к эндпоинту `/__api`, который предоставляет сервер.
