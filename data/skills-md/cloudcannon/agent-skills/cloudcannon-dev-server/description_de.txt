Verwenden, wenn man eine CloudCannon‑Website lokal mit `cloudcannon dev` ausführt — dabei wird die lokale Bearbeitungsschleife gestartet, sodass der Nutzer im CloudCannon‑Editor bearbeiten und die Neugenerierung der Seite sehen kann, den Build‑Befehl je nach SSG auswählen und die vom Server bereitgestellte `/__api`‑Oberfläche auslesen.
