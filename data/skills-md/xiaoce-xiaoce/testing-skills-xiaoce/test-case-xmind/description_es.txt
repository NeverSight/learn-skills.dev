Genera casos de prueba de software estructurados basados en documentos de requisitos del producto, documentos técnicos de front‑end, documentos técnicos de back‑end, borradores de interacción, especificaciones de interfaces, capturas de pantalla y materiales del proyecto relacionados; valida el formato de los casos de prueba; y exporta archivos de mapa mental .xmind usando la plantilla “Título del Caso de Prueba / Precondición / Pasos / Resultado Esperado”. Esto es aplicable para crear casos de prueba QA, casos de prueba de aceptación, casos de prueba funcionales, casos de prueba de regresión, casos de prueba de límites, o para generar mapas mentales de casos de prueba XMind a partir de uno o varios documentos de entrada.
