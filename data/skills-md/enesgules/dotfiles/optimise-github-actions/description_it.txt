Ottimizza GitHub Actions per costo e velocità. Legge i minuti fatturati e il tempo reale di ogni workflow e job dall'API di GitHub, individua gli sprechi e modifica i workflow senza eliminare i controlli importanti. Gli sprechi tipici sono: la riesecuzione di suite già superate dal pull request, filtri di percorso che corrispondono a ogni PR, job di matrix piccoli, cache mancanti, push in bozza, build Docker, moltiplicatori per Windows e macOS, job bloccati e bot. Usa questo ogni volta che l'utente dice che CI è lento o costoso, ha superato la quota di Actions o sta pagando costi aggiuntivi, vuole "ridurre i minuti di GitHub Actions", "velocizzare CI" o "rendere CI più economico", chiede "perché il nostro CI è così costoso" o desidera un audit CI. Usalo anche se indicano solo un job lento o un file workflow.
