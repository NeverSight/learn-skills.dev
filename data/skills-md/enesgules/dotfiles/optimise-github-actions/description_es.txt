Optimiza GitHub Actions para reducir costos y acelerar su ejecución. Lee los minutos facturados y el tiempo real de cada workflow y job desde la API de GitHub, detecta el desperdicio y modifica los workflows sin eliminar las comprobaciones importantes. Los desperdicios típicos son volver a ejecutar suites que el pull request ya aprobó, filtros de ruta que coinciden con cada PR, trabajos de matriz pequeños, cachés faltantes, pushes de borrador, compilaciones Docker, multiplicadores de Windows y macOS, trabajos colgados y bots. Utilízalo siempre que el usuario diga que el CI es lento o costoso, que supera su cuota de Actions o está pagando cargos adicionales, que quiere "reducir los minutos de GitHub Actions", "acelerar el CI" o "hacer el CI más barato", que pregunte "por qué nuestro CI es tan caro", o que solicite una auditoría del CI. Úsalo incluso si solo señalan un trabajo lento o un archivo de workflow.
