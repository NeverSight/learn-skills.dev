優化 GitHub Actions 的成本與速度。從 GitHub API 讀取每個工作流程與作業的計費分鐘數與實際耗時，找出浪費，並在不刪除重要檢查的前提下調整工作流程。常見的浪費包括：主分支重跑已通過的測試套件、匹配所有 PR 的路徑過濾器、規模小的矩陣作業、缺少快取、草稿推送、Docker 建置、Windows 與 macOS 的倍率、掛起的作業與機器人。當使用者說 CI 速度慢或成本高、已超過 Actions 配額或支付超額費用、想「減少 GitHub Actions 分鐘數」或「加速 CI」或「降低 CI 成本」、詢問「為何我們的 CI 那麼昂貴」或需要 CI 審計時，都可以使用此方式。即使使用者僅指出一個緩慢的作業或單一工作流程檔，也請使用它。
