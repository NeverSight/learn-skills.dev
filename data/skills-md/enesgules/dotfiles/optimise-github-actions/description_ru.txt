Оптимизировать GitHub Actions по стоимости и скорости. Считывает оплачиваемые минуты и реальное время выполнения каждого workflow и job из GitHub API, выявляет потери и меняет workflow, не отключая важные проверки. Типичные потери — повторный запуск основных наборов тестов, которые уже прошёл pull‑request, фильтры путей, подходящие к каждому PR, небольшие матричные задачи, отсутствие кэшей, черновые пуши, сборки Docker, множители для Windows и macOS, зависшие задачи и боты. Используйте это, когда пользователь говорит, что CI медленный или дорогой, превышает лимит Actions или платит за перерасход, хочет «reduce GitHub Actions minutes», «speed up CI» или «make CI cheaper», спрашивает «why is our CI so expensive» или хочет аудит CI. Применяйте даже если они указывают только одну медленную задачу или один файл workflow.
