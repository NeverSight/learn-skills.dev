تحسين GitHub Actions من حيث التكلفة والسرعة. يقرأ عدد الدقائق المفوترة والوقت الفعلي لكل سير عمل ووظيفة من واجهة برمجة تطبيقات GitHub، يحدد الهدر، ويعدّل سير العمل دون إلغاء الفحوصات المهمة. الهدر النموذجي يشمل إعادة تشغيل مجموعات الاختبار التي سبق أن تم تمرير طلب السحب، مرشحات المسار التي تطابق كل طلب سحب، وظائف مصفوفة صغيرة، عدم وجود التخزين المؤقت، دفعات مسودة، بناء Docker، مضاعفات Windows و macOS، الوظائف المتعطلة والروبوتات. استخدم ذلك كلما قال المستخدم إن CI بطيء أو مكلف، أو تجاوز حصتهم في Actions أو يدفع رسومًا إضافية، أو يرغب في "تقليل دقائق GitHub Actions"، أو "تسريع CI"، أو "جعل CI أرخص"، أو يسأل "لماذا CI لدينا مكلف للغاية"، أو يرغب في تدقيق CI. استخدمه حتى إذا أشاروا فقط إلى وظيفة بطيئة واحدة أو ملف سير عمل واحد.
