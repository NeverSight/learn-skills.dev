Optimieren Sie GitHub Actions hinsichtlich Kosten und Geschwindigkeit. Liest die abgerechneten Minuten und die Echtzeitdauer jedes Workflows und Jobs über die GitHub-API, findet die Verschwendung und ändert die Workflows, ohne die wichtigen Prüfungen zu entfernen. Typische Verschwendung ist das erneute Ausführen von Haupttestreihen, die der Pull Request bereits bestanden hat, Pfadfilter, die zu jedem PR passen, kleine Matrix‑Jobs, fehlende Caches, Draft‑Pushes, Docker‑Builds, Windows‑ und macOS‑Multiplikatoren, hängende Jobs und Bots. Verwenden Sie dies immer, wenn der Benutzer sagt, dass CI langsam oder teuer ist, sein Actions‑Kontingent überschritten hat oder Überverbrauch bezahlt, „GitHub Actions‑Minuten reduzieren“, „CI beschleunigen“ oder „CI günstiger machen“ möchte, fragt „Warum ist unser CI so teuer?“, oder einen CI‑Audit will. Nutzen Sie es sogar, wenn sie nur auf einen langsamen Job oder eine Workflow‑Datei hinweisen.
