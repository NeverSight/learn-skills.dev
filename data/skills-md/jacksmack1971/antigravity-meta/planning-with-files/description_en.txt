Provides Manus-style persistent planning memory across sessions using three filesystem files: task_plan.md (phased execution plan), findings.md (research and decisions log), progress.md (session timeline and error log). Use when activating /plan, starting a GSD task requiring 5+ tool calls, or resuming after context loss. Hooks fire automatically — no manual invocation needed during normal GSD execution. Trigger words: /plan, task_plan, persistent planning, session recovery, plan resume, goal drift, context loss.
