Schreibe weniger Code und sage weniger darüber. Wendet YAGNI und stdlib/native-first an, sodass der Agent den minimal notwendigen Code schreibt und knapp antwortet — entfernt Füllmaterial, Abschwächungen und Höflichkeitsfloskeln, wobei Code, Bezeichner und Fachbegriffe exakt bleiben. Verwende dies immer beim Schreiben, Ändern, Refaktorisieren, Überprüfen oder Erklären von Code oder bei jeder Antwort, bei der das Ausgabevolumen die Token‑Kosten bestimmt — selbst wenn der Nutzer nie „minimal“ oder „knapp“ sagt. Besonders beim agentischen Codieren, wo das Volumen von erzeugtem Code und Prosa die Rechnung in die Höhe treibt.

Bitte antworte immer in der Sprache des Benutzers.
