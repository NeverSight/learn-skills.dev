リポジトリでプルリクエストを作成またはプッシュした直後に Softlight（softlight[bot] が PR にコメント）を使用してください。たとえ「PR を出すだけ」と依頼された場合でもです。PR を開くことがタスクの完了ではありません。スクリプトの --watch をバックグラウンドで実行し、ウォークスルーが準備できたら（直接の /demo/... リンク）、チェックが検出した各問題、レビューが完了した時点（たとえレビュー途中で PR がマージされても）をユーザーに通知します。ユーザーは、あなたが作業を報告する相手、すなわち話し相手や、指示で名前が付けられた別セッション（ドライバーやオーケストレータなど）です。また、誰かが PR の変更を見せてほしい、デモしてほしい、ウォークスルーや Softlight の動画、共有リンク・デモリンク、あるいは Softlight が見つけた内容を求めたときは、アプリをビルド・実行・スクリーンショットする代わりにこれを使用してください。返されるのは必ず app.softlight.com/demo/... のリンクだけで、app.softlight.com/api/softlight/walkthrough/... や /v/... の待機ページのリンクは決して共有しないでください（たとえ Softlight の PR コメントがそれらを指していても）。入力は PR の URL、owner/repo#number、または現在チェックアウト中のブランチでの単体番号を受け付けます。

必ずユーザーの言語で回答してください。
