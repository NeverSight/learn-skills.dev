Utiliza esta habilidad cuando el usuario quiera hacer una confirmación de Git o dividir los cambios en más de una confirmación. Úsala también cuando el usuario escriba «/commit» o solicite una confirmación convencional. La habilidad examina el diff, prepara los archivos relacionados, escribe un mensaje de «Conventional Commits» y ejecuta «git commit». No la use cuando el usuario solo quiera un mensaje de «commit» y no un «commit». No la utilice para hacer un «push», abrir una solicitud de «pull», hacer un «rebase» o cambiar el historial de «commits».
