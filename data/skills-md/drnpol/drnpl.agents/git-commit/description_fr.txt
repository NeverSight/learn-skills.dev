Utilisez cette compétence lorsque l'utilisateur souhaite effectuer un commit Git ou diviser les modifications en plusieurs commits. Utilisez-la également lorsque l'utilisateur tape « /commit » ou demande un commit conventionnel. La skill examine le diff, met en stage les fichiers concernés, rédige un message de commit conventionnel et exécute la commande git commit. Ne l'utilisez pas lorsque l'utilisateur ne souhaite qu'un message de commit et aucun commit. Ne l'utilisez pas pour pousser, ouvrir une pull request, effectuer un rebase ou modifier l'historique des commits.
