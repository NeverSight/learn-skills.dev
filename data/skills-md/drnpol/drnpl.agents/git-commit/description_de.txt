Verwenden Sie diese Skill, wenn der Benutzer einen Git-Commit durchführen oder Änderungen in mehrere Commits aufteilen möchte. Verwenden Sie sie auch, wenn der Benutzer „/commit“ eingibt oder nach einem konventionellen Commit fragt. Die Skill überprüft den Diff, stellt die zugehörigen Dateien bereit, schreibt eine Conventional-Commits-Nachricht und führt git commit aus. Verwenden Sie sie nicht, wenn der Benutzer nur eine Commit-Nachricht und keinen Commit möchte. Verwenden Sie sie nicht, um zu pushen, einen Pull Request zu öffnen, einen Rebase durchzuführen oder den Commit-Verlauf zu ändern.
