사용자가 Git 커밋을 수행하거나 변경 사항을 둘 이상의 커밋으로 분할하려는 경우 이 스킬을 사용하세요. 또한 사용자가 "/commit"을 입력하거나 Conventional Commit을 요청할 때도 이 스킬을 사용하세요. 이 스킬은 차이(diff)를 검토하고, 관련 파일을 스테이징하고, Conventional Commits 메시지를 작성하고, git commit을 실행합니다. 사용자가 커밋 메시지만 원하고 커밋을 원하지 않는 경우에는 이 스킬을 사용하지 마세요. 푸시, 풀 리퀘스트 열기, 리베이스 또는 커밋 기록 변경에 사용하지 마세요.
