Guía de patrones de acceso y calidad de consultas lentas en CloudBase PostgreSQL. Úsela al diseñar cómo se leen y escriben las tablas, eliminando llamadas a la base de datos por fila, añadiendo índices para filtros o joins, revisando el acceso de datos de alto tráfico o explicando una consulta SQL lenta. No es para la configuración inicial del SDK de PG, la interfaz de inicio de sesión o colecciones NoSQL.

Por favor, responda siempre en el idioma del usuario.
