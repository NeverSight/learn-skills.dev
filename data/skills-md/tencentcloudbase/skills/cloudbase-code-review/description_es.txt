Revisión de código y validación para proyectos CloudBase. Después de escribir código para proyectos Web / miniprograma / CloudRun / cloud‑function, llama a esta habilidad para detectar las trampas conocidas: uso incorrecto de guardias de autenticación, tablas de base de datos faltantes, configuración errónea de RLS, configuración del dominio de almacenamiento y uso inapropiado de la API del SDK. Compatibiliza scripts de lint automatizados (basados en expresiones regulares) y revisión semántica mediante LLM.
