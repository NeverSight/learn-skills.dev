Révision de code et validation pour les projets CloudBase. Après avoir écrit du code pour des projets Web / miniprogramme / CloudRun / cloud‑function, utilisez cette compétence pour vérifier les écueils connus : mauvaise utilisation du garde d’authentification, tables de base de données manquantes, mauvaise configuration du RLS, configuration du domaine de stockage et mauvaise utilisation de l’API SDK. Prend en charge les scripts de lint automatisés (basés sur des expressions régulières) + la révision sémantique par LLM.

Veuillez toujours répondre dans la langue de l'utilisateur.
