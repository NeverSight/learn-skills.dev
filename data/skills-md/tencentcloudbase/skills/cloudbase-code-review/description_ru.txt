Рецензирование кода и проверка для проектов CloudBase. После написания кода для Web / miniprogram / CloudRun / cloud‑function проектов вызовите эту функцию, чтобы проверить известные подводные камни — неправильное использование auth guard, отсутствие таблиц базы данных, ошибочную конфигурацию RLS, настройку домена хранилища и некорректное использование SDK API. Поддерживает автоматизированные скрипты линтинга (на основе регулярных выражений) + семантический обзор с помощью LLM.

Пожалуйста, всегда отвечайте на языке пользователя.
