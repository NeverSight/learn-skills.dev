نشر CloudBase التصريحي من ملف تكوين cloudbaserc (声明式部署، 配置式部署، cloudbaserc 部署) عبر أدوات MCP: deployBuild / deployPlan / deployApply. يُستخدم عند نشر قاعدة البيانات أو الدوال أو التطبيق أو الاستضافة أو موارد البوابة الموضحة في cloudbaserc.json/yaml كتهيئة حالة مرغوبة واحدة، عندما يرغب المستخدم في بناء منتجات الاستضافة الثابتة محليًا أولاً (deployBuild)، أو يرغب في خطة تجريبية جافة قبل التطبيق (deployPlan)، أو عند معالجة عمليات النشر متعددة البيئة عبر mode / envOverrides. يغطي تدفق البناء‑الخطة‑التطبيق (deployBuild بناء محلي → deployPlan تجريب جاف → deployApply confirm=true)، إلغاء تأثير مخرجات بناء الاستضافة، أولوية حل envId، تصفية only/skip، التزامن، والاستمرار عند حدوث خطأ (continueOnError). يُفضَّل استخدام deployBuild (عندما تعلن الاستضافة عن buildCommand) و deployPlan قبل deployApply؛ لا تُخلط ذلك مع نشر tcb CLI لكل مورد أو نشر دالة واحدة.
