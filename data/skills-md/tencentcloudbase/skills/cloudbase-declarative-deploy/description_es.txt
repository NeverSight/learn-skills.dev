Despliegue declarativo de CloudBase a partir de una configuración cloudbaserc (声明式部署, 配置式部署, cloudbaserc 部署) mediante las herramientas MCP deployBuild / deployPlan / deployApply. Úselo al desplegar recursos de base de datos, funciones, aplicaciones, hosting o gateway descritos en cloudbaserc.json/yaml como una única configuración de estado deseado, cuando un usuario desea generar artefactos de hosting estático localmente primero (deployBuild), o quiere un plan de ejecución en modo simulación antes de aplicar (deployPlan), o al gestionar despliegues multi‑entorno mediante mode / envOverrides. Cubre el flujo build‑plan‑apply (deployBuild compilación local → deployPlan simulación → deployApply confirm=true), la neutralización de la salida de compilación del hosting, la prioridad de resolución de envId, el filtrado only/skip, la concurrencia y continueOnError. Prefiera deployBuild (cuando el hosting declara un buildCommand) y deployPlan antes de deployApply; no lo confunda con el despliegue por recurso del CLI tcb o el despliegue de una sola función.
