cloudbaserc 구성(声明式部署, 配置式部署, cloudbaserc 部署)으로부터 CloudBase 선언적 배포를 deployBuild / deployPlan / deployApply MCP 도구를 통해 수행합니다. cloudbaserc.json/yaml에 정의된 데이터베이스, 함수, 앱, 호스팅 또는 게이트웨이 리소스를 단일 원하는 상태 구성으로 배포할 때, 사용자가 먼저 정적 호스팅 아티팩트를 로컬에서 빌드하고 싶을 경우(deployBuild), 적용 전에 드라이런 플랜을 원할 경우(deployPlan), 또는 mode / envOverrides를 통해 다중 환경 배포를 처리할 때 사용합니다. 빌드‑플랜‑적용 흐름(deployBuild 로컬 빌드 → deployPlan 드라이런 → deployApply confirm=true), 호스팅 빌드 출력 중립화, envId 해석 우선순위, only/skip 필터링, 동시성, continueOnError를 다룹니다. 호스팅이 buildCommand를 선언한 경우에는 deployBuild를, 그 다음에 deployPlan을 선호하고, 최종적으로 deployApply를 사용하십시오; 개별 리소스 tcb CLI 배포나 단일 함수 배포와 혼동하지 마세요.
