Декларативное развертывание CloudBase из конфигурации cloudbaserc (声明式部署, 配置式部署, cloudbaserc 部署) с помощью инструментов MCP deployBuild / deployPlan / deployApply. Используется при развертывании баз данных, функций, приложений, хостинга или шлюзов, описанных в cloudbaserc.json/yaml, как единой конфигурации желаемого состояния; когда пользователь хочет сначала собрать артефакты статического хостинга локально (deployBuild), или получить план‑пробный запуск перед применением (deployPlan), либо при работе с многократными средами развертывания через mode / envOverrides. Охватывает поток build‑plan‑apply (локальная сборка deployBuild → пробный запуск deployPlan → подтверждение deployApply с confirm=true), нейтрализацию вывода сборки хостинга, приоритет разрешения envId, фильтрацию only/skip, конкурентность и continueOnError. Предпочтительно использовать deployBuild (когда в хостинге объявлена buildCommand) и deployPlan перед deployApply; не путать с развертыванием per‑resource через tcb CLI или развертыванием отдельной функции.
