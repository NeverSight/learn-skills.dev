Déploiement déclaratif CloudBase à partir d’une configuration cloudbaserc (声明式部署, 配置式部署, cloudbaserc 部署) via les outils MCP deployBuild / deployPlan / deployApply. À utiliser lors du déploiement de bases de données, fonctions, applications, hébergement ou passerelles décrits dans cloudbaserc.json/yaml comme une configuration d’état souhaité unique, lorsque l’utilisateur souhaite d’abord construire localement les artefacts d’hébergement statique (deployBuild), ou obtenir un plan en mode simulation avant l’application (deployPlan), ou gérer des déploiements multi‑environnements via mode / envOverrides. Couvre le flux build‑plan‑apply (déploiement local avec deployBuild → simulation avec deployPlan → application avec deployApply confirm=true), la neutralisation de la sortie de construction d’hébergement, la priorité de résolution de l’identifiant d’environnement (envId), le filtrage only/skip, la concurrence et l’option continueOnError. Privilégiez deployBuild (lorsque l’hébergement déclare un buildCommand) et deployPlan avant deployApply ; ne le confondez pas avec le déploiement tcb CLI par ressource ou le déploiement d’une seule fonction.
