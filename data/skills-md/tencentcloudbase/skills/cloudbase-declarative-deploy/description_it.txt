Distribuzione dichiarativa di CloudBase da una configurazione cloudbaserc (声明式部署, 配置式部署, cloudbaserc 部署) tramite gli strumenti MCP deployBuild / deployPlan / deployApply. Da utilizzare quando si distribuiscono risorse di database, funzioni, app, hosting o gateway descritte in cloudbaserc.json/yaml come un unico file di stato desiderato, quando l'utente vuole prima costruire localmente gli artefatti di hosting statico (deployBuild), oppure desidera un piano di simulazione prima dell'applicazione (deployPlan), o quando si gestiscono distribuzioni multi‑ambiente tramite mode / envOverrides. Copre il flusso build‑plan‑apply (deployBuild: build locale → deployPlan: dry‑run → deployApply: confirm=true), la neutralizzazione dell'output di build dell'hosting, la priorità di risoluzione di envId, i filtri only/skip, la concorrenza e continueOnError. È preferibile utilizzare deployBuild (quando l'hosting dichiara un buildCommand) e deployPlan prima di deployApply; non confondere con il comando tcb CLI deploy per risorsa o con la distribuzione di una singola funzione.
