通过 deployBuild / deployPlan / deployApply MCP 工具，从 cloudbaserc 配置（声明式部署、配置式部署、cloudbaserc 部署）进行 CloudBase 声明式部署。适用于将 cloudbaserc.json / yaml 中描述的数据库、函数、应用、托管或网关资源作为单一期望状态配置进行部署；当用户希望先在本地构建静态托管产物（deployBuild）时；或希望在应用前进行干运行计划（deployPlan）时；亦或通过 mode / envOverrides 处理多环境部署。覆盖构建‑计划‑应用流程（deployBuild 本地构建 → deployPlan 干运行 → deployApply confirm=true）、托管构建产出中和、envId 解析优先级、only/skip 过滤、并发以及 continueOnError。建议在 deployApply 前先使用 deployBuild（当托管声明了 buildCommand 时）和 deployPlan；不要与针对单资源的 tcb CLI deploy 或单函数部署混淆。
