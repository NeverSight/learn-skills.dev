CloudBase 從 cloudbaserc 配置（声明式部署、配置式部署、cloudbaserc 部署）進行宣告式部署，透過 deployBuild / deployPlan / deployApply MCP 工具。適用於將 cloudbaserc.json/yaml 中描述的資料庫、函式、應用、託管或閘道資源作為單一期望狀態配置部署，當使用者希望先在本地構建靜態託管產出（deployBuild），或在套用前先執行乾跑計畫（deployPlan），亦或透過 mode / envOverrides 處理多環境部署。涵蓋建置‑計畫‑套用流程（deployBuild 本地建置 → deployPlan 乾跑 → deployApply confirm=true）、託管建置輸出中和、envId 解析優先順序、only / skip 篩選、並行執行與 continueOnError。建議先使用 deployBuild（當託管宣告了 buildCommand）再使用 deployPlan，最後才執行 deployApply；請勿與單一資源的 tcb CLI deploy 或單函式部署混淆。
