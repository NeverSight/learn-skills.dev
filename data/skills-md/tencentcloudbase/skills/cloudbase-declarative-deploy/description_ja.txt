CloudBase 宣言的デプロイは、cloudbaserc 設定（声明式部署、配置式部署、cloudbaserc 部署）から deployBuild / deployPlan / deployApply の MCP ツールを使用して行います。cloudbaserc.json/yaml で記述されたデータベース、関数、アプリ、ホスティング、ゲートウェイリソースを単一の望ましい状態設定としてデプロイする場合や、ユーザーがローカルで静的ホスティング成果物を先にビルドしたいとき（deployBuild）、適用前にドライランプランが欲しいとき（deployPlan）、または mode / envOverrides によるマルチ環境デプロイを扱うときに使用します。ビルド‑プラン‑適用フロー（deployBuild ローカルビルド → deployPlan ドライラン → deployApply confirm=true）をカバーし、ホスティングのビルド出力の無効化、envId の解決優先順位、only/skip フィルタリング、同時実行、continueOnError もサポートします。ホスティングが buildCommand を宣言している場合は deployBuild、そして deployPlan の実行を優先し、deployApply の前に実行してください。tcb CLI のリソース単位デプロイや単一関数デプロイと混同しないでください。
