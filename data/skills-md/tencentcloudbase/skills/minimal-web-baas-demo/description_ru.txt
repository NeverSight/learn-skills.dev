Быстрый путь для минимального демо‑проекта CloudBase Web + база данных (最小前后端 / 最小可用 fullstack / Lovable‑like BaaS). По умолчанию используется клиентский CRUD @cloudbase/js-sdk (NoSQL app.database / PG app.rdb), схема только MCP, предварительный просмотр в приоритете, и облачные функции запрещены, если только они не требуют секретов, cron/фоновый задачи или логики, которую нельзя выразить правилами безопасности/RLS. Используется для 搭一套 demo、留言板、Todo、Notes、Kanban, либо когда пользователи требуют 带云函数+云数据库, но нужны лишь CRUD. НЕ предназначено для производственных многосервисных бекендов, CloudRun, WeChat Mini Programs или задач, действительно нуждающихся в серверных секретах.
