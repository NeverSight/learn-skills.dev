最小限の CloudBase Web + データベースデモ向けの高速パス（最小前后端 / 最小可用 fullstack / Lovable‑like BaaS）。デフォルトは @cloudbase/js-sdk のクライアント CRUD（NoSQL の app.database / PG の app.rdb）で、MCP のみのスキーマ、プレビュー優先、シークレットや cron／バックグラウンドジョブ、あるいはセキュリティルール／RLS では表現できないロジックがない限りクラウド関数は禁止です。搭一套 デモ、掲示板、Todo、Notes、Kanban、またはユーザーが「带云函数+云数据库」と言っても CRUD だけが必要な場合に使用します。実運用のマルチサービスバックエンド、CloudRun、WeChat ミニプログラム、あるいはサーバーシークレットが本当に必要なタスクには使用しないでください。
