Chemin rapide pour une démo minimale CloudBase Web + base de données (最小前后端 / 最小可用 fullstack / Lovable‑like BaaS). Par défaut, le client @cloudbase/js-sdk effectue les opérations CRUD (NoSQL app.database / PG app.rdb), schéma uniquement MCP, aperçu d’abord, et interdit les fonctions cloud sauf si elles impliquent des secrets, des tâches cron/en arrière‑plan, ou une logique que les règles de sécurité/RLS ne peuvent exprimer. Utilisez‑le pour 搭一套 demo、留言板、Todo、Notes、Kanban, ou lorsque les utilisateurs demandent 带云函数+云数据库 mais n’ont besoin que de CRUD. PAS pour des backends multi‑services en production, CloudRun, Mini‑programmes WeChat, ou des tâches nécessitant réellement des secrets serveur. Veuillez toujours répondre dans la langue de l'utilisateur.
