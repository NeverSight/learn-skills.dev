Ruta rápida para una demo mínima de CloudBase Web + base de datos (最小前后端 / 最小可用 fullstack / Lovable-like BaaS). Por defecto usa CRUD del cliente @cloudbase/js-sdk (NoSQL app.database / PG app.rdb), esquema solo MCP, vista previa primero, y prohíbe funciones en la nube a menos que haya secretos, trabajos cron/de fondo, o lógica que las reglas de seguridad/RLS no puedan expresar. Úsalo para 搭一套 demo、留言板、Todo、Notes、Kanban, o cuando los usuarios dicen 带云函数+云数据库 pero solo necesitan CRUD. NO es para backends de producción multi‑servicio, CloudRun, Mini Programas de WeChat, o tareas que realmente requieren secretos del servidor.
