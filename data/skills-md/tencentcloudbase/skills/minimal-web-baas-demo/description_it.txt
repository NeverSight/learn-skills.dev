Percorso rapido per una demo minimale di CloudBase Web + database (最小前后端 / 最小可用 fullstack / Lovable-like BaaS). Per impostazione predefinita utilizza CRUD client @cloudbase/js-sdk (NoSQL app.database / PG app.rdb), schema solo MCP, anteprima prima di tutto e vieta le funzioni cloud a meno che non siano necessarie per segreti, cron/job in background o logica che le regole di sicurezza/RLS non possono esprimere. Da usare per 搭一套 demo、留言板、Todo、Notes、Kanban, o quando gli utenti chiedono 带云函数+云数据库 ma hanno solo bisogno di CRUD. NON è adatto per backend di produzione multi-servizio, CloudRun, Mini Program di WeChat o attività che richiedono realmente segreti del server.
