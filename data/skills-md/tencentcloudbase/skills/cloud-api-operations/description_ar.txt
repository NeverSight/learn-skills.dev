تشغيل موارد مستوى التحكم في سحابة تينسنت (المراقبة/الإنذارات، CLB، أدوار CAM، COS، MySQL، SCF) عبر واجهات برمجة التطبيقات السحابية عندما لا تغطي أداة MCP مخصصة المهمة. يُستخدم عندما تحتاج المهمة إلى عمليات مستوى التحكم التي تتجاوز أدوات CloudBase الخاصة، أو عندما يفشل استدعاء callCloudApi ويحتاج إلى تصنيف.
