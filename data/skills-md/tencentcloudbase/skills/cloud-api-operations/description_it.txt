Operare le risorse del piano di controllo di Tencent Cloud (monitoraggio/allarmi, CLB, ruoli CAM, COS, MySQL, SCF) tramite le API cloud quando nessuno strumento MCP dedicato copre il compito. Utilizzare quando un’attività richiede operazioni del piano di controllo oltre gli strumenti di CloudBase, o quando una chiamata callCloudApi è fallita e necessita di classificazione.
