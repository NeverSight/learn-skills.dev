Операции с ресурсами управляющего уровня Tencent Cloud (мониторинг/сигналы тревоги, CLB, роли CAM, COS, MySQL, SCF) через облачные API, когда специализированный инструмент MCP не покрывает задачу. Использовать, когда задача требует операций управляющего уровня, выходящих за пределы собственных средств CloudBase, или когда вызов callCloudApi завершился неудачей и требуется классификация.
