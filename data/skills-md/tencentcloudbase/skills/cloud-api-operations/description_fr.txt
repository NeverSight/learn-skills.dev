Opérez les ressources du plan de contrôle de Tencent Cloud (surveillance/alertes, CLB, rôles CAM, COS, MySQL, SCF) via les API cloud lorsqu'aucun outil MCP dédié ne couvre la tâche. Utilisez‑le lorsqu’une tâche nécessite des opérations du plan de contrôle au‑delà des outils de CloudBase, ou lorsqu’un appel callCloudApi a échoué et doit être classifié.
