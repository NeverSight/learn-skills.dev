Operar los recursos del plano de control de Tencent Cloud (monitorización/alertas, CLB, roles CAM, COS, MySQL, SCF) a través de las API de la nube cuando ninguna herramienta MCP dedicada cubre la tarea. Utilizar cuando una tarea necesita operaciones del plano de control más allá de las herramientas propias de CloudBase, o cuando una llamada callCloudApi falló y necesita ser clasificada.
