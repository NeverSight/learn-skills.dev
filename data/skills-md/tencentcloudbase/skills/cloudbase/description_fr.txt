Utilisez cette compétence lorsque vous développez, concevez, construisez, déployez, déboguez, migrez ou dépannez des projets CloudBase (腾讯云开发, 云开发, TCB, 微信云开发) — Web, 微信小程序, 小程序, uni‑app, mobile (iOS, Android, Flutter, React Native). Couvre l’UI (页面, 界面, 表单, tableau de bord, prototype, 原型) ; l’authentification (登录, 注册, OAuth, clé publiable) ; les bases de données (base de données NoSQL documentaire, MySQL relationnelle, PostgreSQL/CloudBase PG, app.rdb(), queryPgDatabase/managePgDatabase, CRUD, règles de sécurité) ; 云函数/cloud functions (sans serveur, scf_bootstrap) ; CloudRun (云托管, Dockerfile) ; 云存储 ; IA intégrée (内置大模型, dialogue IA, streaming, sortie en flux, génération d’image, generateText, streamText, createModel, generateImage, TokenHub, Hunyuan, DeepSeek, GLM, Kimi, Token Credits 资源包, 小程序成长计划) ; intégration de modèles tiers/personnalisés (第三方大模型接入, appel de grands modèles, API LLM) ; agent IA (智能体, AG‑UI, LangGraph) ; dépannage opérationnel (巡检, diagnostic, journaux) ; flux de travail de spécifications (需求文档, 技术方案, exigences, tasks.md). NE PAS utiliser pour des projets non‑CloudBase, du front‑end pur sans CloudBase, ou des back‑ends auto‑hébergés sans CloudBase.
