Utilisez cette fonction lorsque l'utilisateur souhaite transformer une compétence d'agent existante en une version où chaque étape est exécutée par une IA spécialisée, concevoir une nouvelle compétence multi‑personas à partir de zéro, ou parcourir et installer des compétences communautaires manyfaced depuis le catalogue. Appelez‑la via /manyface pour le flux guidé, /manyface install <nom> pour installer directement une compétence, ou /manyface list pour parcourir. Déclenchez‑la lorsque l'utilisateur dit « manyface this skill », « add personas to my skill », « make this skill manyfaced », « browse manyfaced skills », « install a manyfaced skill », ou souhaite différents profils cognitifs à différentes étapes d’un workflow.

Veuillez toujours répondre dans la langue de l’utilisateur.
