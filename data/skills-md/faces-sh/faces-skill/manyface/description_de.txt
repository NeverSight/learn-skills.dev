Verwenden Sie diese Fähigkeit, wenn der Benutzer eine vorhandene Agenten‑Fähigkeit in eine Version umwandeln möchte, bei der jeder Schritt von einer spezialisierten KI‑Persona ausgeführt wird, eine neue Multi‑Persona‑Fähigkeit von Grund auf entwerfen will oder Community‑Manyfaced‑Fähigkeiten aus dem Katalog durchsuchen und installieren möchte. Rufen Sie sie mit `/manyface` für den geführten Ablauf auf, `/manyface install <Name>` um eine Fähigkeit direkt zu installieren, oder `/manyface list` zum Durchsuchen. Auslösen, wenn der Benutzer sagt „manyface this skill“, „add personas to my skill“, „make this skill manyfaced“, „browse manyfaced skills“, „install a manyfaced skill“ oder unterschiedliche kognitive Profile in verschiedenen Schritten eines Workflows wünscht.

Bitte immer in der Sprache des Benutzers antworten.
