在任何人想要构建能够思考、说话或行为像特定人物的 AI 时使用此技能。包括：将访谈、信件、视频或文档转换为可聊天的 AI 人格；创建可以实际对话的客户人格或焦点小组（而非仅仅静态档案）；用更高效的 token 方式取代臃肿的 SOUL.md / soul 文档 / 系统提示；为多智能体系统中的代理赋予不同的个性、行为模式或视角；创建数字孪生或纪念性 AI；通过其电子邮件或信息捕捉某人的写作方式，使人格以其语气写作；比较不同人的思考方式；基于已有观点构思新视角；或通过受限的 API 密钥共享人格访问。用户提到 Faces 平台、`faces` CLI、认知原语、心算或编译人格时也应触发。即使尚未安装 Faces，也请使用——此技能包括设置步骤。请勿用于模型微调、RAG/检索系统、创意写作（NPC 背景、小说）或转录本的主题分析。

请始终使用用户的语言回复。
