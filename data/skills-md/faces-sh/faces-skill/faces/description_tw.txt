每當有人想要打造一個在思考、說話或行為上與特定人物相似的 AI 時，就使用此技能。這包括：將訪談、信件、影片或文件轉換成可對話的 AI 人格；創建可實際對話的客戶人物或焦點小組（而不僅是靜態檔案）；以更具 token 效率的方式取代龐大的 SOUL.md / soul 文件 / 系統提示；為多代理系統中的代理賦予不同的個性、行為模式或觀點；打造數位雙生或紀念 AI；從個人的電子郵件或訊息中捕捉寫作風格，使人格以其聲音寫作；比較不同人的思考方式；從既有觀點中組合出新的視角；或透過範圍限定的 API 金鑰分享人格存取權。當使用者提及 Faces 平台、`faces` CLI、認知原語、心算或編譯人格時也應觸發。即使尚未安裝 Faces 亦可使用——此技能涵蓋設定。請勿用於微調模型、RAG/檢索系統、創意寫作（NPC 背景、小說）或對稿件進行主題分析。

請始終以使用者的語言回應。
