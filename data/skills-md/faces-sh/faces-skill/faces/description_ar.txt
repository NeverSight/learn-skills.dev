استخدم هذه المهارة كلما أراد أحد بناء ذكاء اصطناعي يفكر، أو يتحدث، أو يتصرف مثل شخص معين. يشمل ذلك: تحويل المقابلات، الرسائل، مقاطع الفيديو أو المستندات إلى شخصية AI يمكن الدردشة معها؛ إنشاء شخصيات عملاء أو مجموعات تركيز يمكنك التفاعل معها فعليًا (وليس مجرد ملفات تعريف ثابتة)؛ استبدال مستندات SOUL.md/الوثائق الروحية/التعليمات النظامية الضخمة بشيء أكثر كفاءة في عدد الرموز؛ منح الوكلاء في نظام متعدد الوكلاء شخصيات متميزة، أو أنماط سلوكية، أو وجهات نظر؛ إنشاء توأم رقمي أو ذكاء اصطناعي تذكاري؛ التقاط أسلوب كتابة شخص ما من رسائل البريد الإلكتروني أو الرسائل الخاصة به ليكتب الشخصية بصوته؛ مقارنة طريقة تفكير افراد مختلفة؛ صياغة وجهات نظر جديدة بناءً على الموجودة؛ أو مشاركة الوصول إلى الشخصية عبر مفاتيح API ذات نطاق محدد. يجب أيضًا تفعيلها عندما يذكر المستخدم منصة Faces أو أداة سطر الأوامر `faces` أو الأصناف العقلية أو حسابات العقل أو تجميع الشخصية. يمكن استخدامها حتى إن لم يتم تثبيت Faces بعد — فالمهارة تغطي الإعداد. لا تُستخدم هذه المهارة لتدريب النماذج الدقيقة، أو أنظمة الاسترجاع/RAG، أو الكتابة الإبداعية (خلفيات شخصيات غير لاعب، خيال)، أو التحليل الموضوعي للنصوص. الرجاء دائماً الرد بلغة المستخدم.
