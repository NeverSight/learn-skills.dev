Un flux de travail discipliné pour lire et analyser des bases de code sources inconnues. Utilisez‑le lorsque l’utilisateur demande de « lire/analyser/expliquer une base de code ou un module », « comment X fonctionne en interne », « enquêter sur ce projet open source », « 帮我读一下这个项目 / 分析一下这个模块的实现 », ou toute tâche de compréhension approfondie du code source. Convertit la méthodologie de l’essai de codedump « How to Read Code » (2021) en un flux de travail d’agent : l’exécuter, clarifier le but, ligne principale vs sous‑intrigue, lecture horizontale vs verticale, analyse de scénarios, structures de données d’abord, questionnement actif, rapport écrit. Produit un rapport structuré de lecture de code, pas seulement une réponse verbale.

Veuillez toujours répondre dans la langue de l’utilisateur.
