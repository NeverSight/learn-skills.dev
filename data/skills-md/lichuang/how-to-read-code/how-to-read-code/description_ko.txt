익숙하지 않은 소스 코드베이스를 읽고 분석하기 위한 체계적인 워크플로우입니다. 사용자가 “코드베이스나 모듈을 읽어/분석해/설명해 주세요”, “X가 내부에서 어떻게 동작하는가”, “이 오픈소스 프로젝트를 조사해 주세요”, “帮我读一下这个项目 / 分析一下这个模块的实现” 등과 같이 깊이 있는 소스 코드 이해 작업을 요청할 때 사용합니다. codedump의 에세이 “How to Read Code”(2021)에서 제시된 방법론을 에이전트 워크플로우로 변환합니다: 실행, 목적 명확화, 메인 라인 vs 서브 플롯, 가로 읽기 vs 세로 읽기, 시나리오 분석, 데이터 구조 우선, 적극적 질문, 서면 보고서 작성. 구두 답변이 아니라 구조화된 코드 읽기 보고서를 제공합니다.

항상 사용자의 언어로 답하세요.
