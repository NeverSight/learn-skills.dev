Дисциплинированный рабочий процесс для чтения и анализа незнакомых баз исходного кода. Используется, когда пользователь просит «прочитать/проанализировать/объяснить кодовую базу или модуль», «как X работает изнутри», «исследовать этот открытый проект», «帮我读一下这个项目 / 分析一下这个模块的实现», или любую задачу глубокого понимания исходного кода. Преобразует методологию из эссе codedump «How to Read Code» (2021) в агентный рабочий процесс: выполнить его, уточнить цель, основную линию против побочной, горизонтальное против вертикального чтения, анализ сценариев, сначала структуры данных, активные вопросы, письменный отчёт. Генерирует структурированный отчёт о чтении кода, а не просто вербальный ответ.

Пожалуйста, всегда отвечайте на языке пользователя.
