Un flusso di lavoro disciplinato per leggere e analizzare codebase sconosciute. Usalo quando l’utente chiede di “leggere/analizzare/spiegare un codebase o modulo”, “come funziona internamente X”, “indagare questo progetto open source”, “帮我读一下这个项目 / 分析一下这个模块的实现”, o qualsiasi compito di comprensione approfondita del codice sorgente. Converte la metodologia del saggio di codedump “How to Read Code” (2021) in un workflow per l’agente: eseguirlo, chiarire lo scopo, mainline vs subplot, lettura orizzontale vs verticale, analisi di scenario, strutture dati prima, domande attive, rapporto scritto. Produce un rapporto strutturato di lettura del codice, non solo una risposta verbale.

Per favore rispondi sempre nella lingua dell’utente.
