سير عمل منظم لقراءة وتحليل قواعد الشيفرة غير المألوفة. يُستعمل عندما يطلب المستخدم «قراءة/تحليل/شرح قاعدة شيفرة أو وحدة»، «كيف يعمل X داخليًا»، «التحقق من هذا المشروع المفتوح المصدر»، «帮我读一下这个项目 / 分析一下这个模块的实现»، أو أي مهمة عميقة لفهم الشيفرة المصدرية. يحوّل المنهجية من مقال codedump «كيفية قراءة الكود» (2021) إلى سير عمل وكيل: تشغيله، توضيح الغرض، الخط الرئيسي مقابل الخط الفرعي، القراءة الأفقية مقابل القراءة العمودية، تحليل السيناريوهات، التركيز أولاً على هياكل البيانات، طرح أسئلة نشطة، تقرير مكتوب. ينتج تقريرًا منظمًا لقراءة الكود، وليس مجرد إجابة شفوية.
