Ein disziplinierter Arbeitsablauf zum Lesen und Analysieren unbekannter Quellcodebasen. Verwenden Sie ihn, wenn der Benutzer auffordert, „einen Codebestand oder ein Modul zu lesen/analysieren/erklären“, „wie X intern funktioniert“, „dieses Open‑Source‑Projekt zu untersuchen“, „帮我读一下这个项目 / 分析一下这个模块的实现“ oder jede tiefgehende Quellcode‑Verstehensaufgabe. Überträgt die Methodik aus dem Essay von codedump „How to Read Code“ (2021) in einen Agenten‑Arbeitsablauf: ausführen, Zweck klären, Hauptfluss vs. Nebenstrang, horizontales vs. vertikales Lesen, Szenario‑Analyse, Datenstrukturen zuerst, aktives Fragen, schriftlicher Bericht. Liefert einen strukturierten Code‑Lese‑Bericht, nicht nur eine mündliche Antwort.

Bitte immer in der Sprache des Benutzers antworten.
