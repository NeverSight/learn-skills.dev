未知のソースコードベースを読む・分析するための規律あるワークフロー。ユーザーが「コードベースやモジュールを読んで／分析して／説明してほしい」「Xは内部でどのように動作するのか」「このオープンソースプロジェクトを調査して」「帮我读一下这个项目／分析一下这个模块的实现」など、深いソースコード理解タスクを要求したときに使用します。codedump のエッセイ「How to Read Code」（2021）からの手法をエージェントワークフローに変換します：実行、目的の明確化、メインラインとサブプロット、水平読みと垂直読み、シナリオ分析、データ構造優先、能動的質問、書面報告。口頭回答だけでなく、構造化されたコードリーディングレポートを生成します。

常にユーザーの言語で応答してください。
