SEO + AEO + GEO 針對任何網站（SaaS、電商、在地、出版商、代理商）的分析。全站審核、單頁深入檢查、技術 SEO（爬行、索引、Core Web Vitals 包含 INP、JS 渲染）、Schema.org 偵測/驗證/生成、E‑E‑A‑T 內容品質、圖片優化、站點地圖、hreflang、程式化 SEO、競爭對手頁面，以及生成式/答案引擎優化（AI 概覽、ChatGPT、Perplexity、Claude、Gemini 引用）。偵測業務類型，套用行業門檻。四層模型：推理、確定性 Python 檢查器、真實瀏覽器 Core Web Vitals、五模型 LLM 引用集成。觸發關鍵詞：「SEO」、「audit」、「schema」、「Core Web Vitals」、「INP」、「sitemap」、「E‑E‑A‑T」、「AI Overviews」、「GEO」、「AEO」、「technical SEO」、「hreflang」、「programmatic SEO」、「competitor pages」。
