SEO + AEO + GEO 分析を、SaaS、eコマース、ローカル、パブリッシャー、エージェンシーなどあらゆるウェブサイトに対応。フルサイト監査、単一ページの深掘り、テクニカル SEO（クロール、インデックス、INP を含む Core Web Vitals、JS レンダリング）、Schema.org の検出/バリデーション/生成、E‑E‑A‑T コンテンツ品質、画像最適化、サイトマップ、hreflang、プログラマティック SEO、競合ページ、そして生成/回答エンジン最適化（AI オーバービュー、ChatGPT、Perplexity、Claude、Gemini の引用）。事業種別を検出し、業界の閾値を適用。4 層モデル：推論、決定的 Python チェッカー、リアルブラウザでの CWV、5 つの LLM による引用アンサンブル。以下の語句でトリガーされます：「SEO」「audit」「schema」「Core Web Vitals」「INP」「sitemap」「E‑E‑A‑T」「AI Overviews」「GEO」「AEO」「technical SEO」「hreflang」「programmatic SEO」「competitor pages」。
