Estandarice la creación y el mantenimiento de planes de proyectos de varios pasos: primero genere una tabla maestra con estado, prioridad, dependencias y enlaces de detalles, luego cree documentos detallados separados para cada elemento del plan. Úselo cuando el usuario solicite crear, estructurar, actualizar o revisar una hoja de ruta, un plan de refactorización, un plan de migración, un plan de implementación o una lista de verificación del proyecto. No lo use para listas de tareas simples de un solo paso o cuando el usuario solo quiera una explicación en prosa.
