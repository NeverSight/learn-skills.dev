Ищите, читайте и курируйте свою библиотеку электронных книг Calibre. Руководство по эксплуатации сервера calibre-mcp (19 инструментов) с CLI Calibre в качестве аварийного выхода. Охватывает выбор правильного поиска (запрос метаданных vs полнотекстовый vs семантический), чтение содержания книги, карты глав и иллюстрации, ограниченные записи с предварительным просмотром (метаданные, теги, массовые правки), дедупликацию, аудиты качества, извлечение ISBN + восстановление метаданных, добавление/удаление/слияние книг, построение семантического индекса и безопасный роутинг CLI через Content Server, пока работает графический интерфейс Calibre (конвертировать, экспортировать, каталогизировать). Используйте для любой задачи с электронными книгами/библиотекой: поиск книг, поиск внутри них, курирование метаданных или обслуживание. Триггеры: «book», «ebook», «calibre», «library», «книга», «бібліотека», «знайди в книзі».
