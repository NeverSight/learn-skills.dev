다중 Calibre 책에 걸친 하나의 주제를 단일, 개념 기반 에이전트 스킬로 통합한다 — 원본 다중 소스 저작(결정 프레임워크, 교차 소스 구성 표, 저자 간 합의/불일치 섹션 명시 포함), 전체 ISBN 참고문헌을 제공하여 나중에 심층 탐구를 위한 실시간 소스 바인딩으로도 활용한다. calibre‑mcp 서버(챕터 지도, 책내 키워드 + 의미 검색)를 구동해 각 소스에서 얇은 주제 조각을 추출한다; 임시 파일 없이, 파이썬 없이. 여러 책으로 구성된 주제 학습 보조가 필요할 때 사용한다("내 Kafka 서가의 kafka 신뢰성", "이 세 책에 걸친 데이터베이스 인덱싱"). 최소 3개의 소스가 필요하며, EN + RU/UK 책에서도 작동한다. calibre‑distill의 형제이며—단일 책 요청은 그쪽으로 보낸다.
