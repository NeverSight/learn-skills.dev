Synthétiser UN sujet à travers PLUSIEURS livres Calibre en une compétence d'agent centrée sur le concept — création multi-sources originale (cadres de décision, tableaux de configuration inter-sources, une section explicite où les auteurs sont d’accord/désaccord), avec une bibliographie ISBN complète qui sert également de liaison source en temps réel pour des explorations approfondies ultérieures. Alimente le serveur calibre-mcp (cartes de chapitres, recherche par mots‑clé et sémantique dans le livre) afin d’extraire une fine tranche de sujet de chaque source ; aucun fichier temporaire, aucun Python. À utiliser lorsque l’utilisateur souhaite un aide à l’étude d’un sujet construite à partir de plusieurs livres (« fiabilité de Kafka depuis ma collection Kafka », « indexation de bases de données à travers ces 3 livres »). Nécessite ≥3 sources ; fonctionne sur des livres EN + RU/UK. Frère de calibre-distill — les demandes d’un seul livre y sont destinées.
