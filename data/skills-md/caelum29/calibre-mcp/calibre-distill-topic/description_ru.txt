Синтезировать ОДНУ тему из НЕСКОЛЬКИХ книг Calibre в единый навык агента, ориентированный на концепцию — оригинальное многоресурсное авторство (рамки принятия решений, кросс‑ресурсные таблицы конфигураций, отдельный раздел, где авторы согласны/не согласны), с полной библиографией ISBN, которая одновременно служит привязкой к живым источникам для последующего глубокого изучения. Управляет сервером calibre‑mcp (карты глав, поиск по ключевым словам и семантический поиск внутри книги), извлекая тонкий кусок темы из каждого источника; без временных файлов, без Python. Используется, когда пользователь хочет учебный материал по теме, построенный из нескольких книг («надёжность Kafka из моей полки Kafka», «индексация баз данных в этих трёх книгах»). Требуется ≥ 3 источника; работает с книгами на английском и русском/украинском языках. Сестринский инструмент calibre‑distill — запросы к одной книге отправляются туда.
