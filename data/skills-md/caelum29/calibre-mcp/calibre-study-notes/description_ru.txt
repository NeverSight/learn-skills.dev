Создавайте заметки для активного обучения (конспекты) из книг в библиотеке Calibre для ЧЕЛОВЕЧЕСКОГО учащегося — а не для агентного навыка. Генерирует markdown‑заметку, построенную для запоминания: секции с вопросами вначале, концепции своими словами, примеры из области читателя, самопроверка с указателями на источник, экспорт в Anki, метаданные для интервального повторения. Также проводит интерактивные сеансы повторения (викторины) по существующим заметкам. Применяется для изучения темы, направления или главы книги из библиотеки. Дистилляция навыка для одной книги относится к `calibre-distill`; навыки для нескольких книг по теме — к `calibre-distill-topic`. Этот навык предназначен для заметок, которые человек будет изучать. Триггеры: «конспект», «законспектуй», «зроби конспект», «хочу вивчити», «розібрати розділ», «розбери главу», «study notes», «make notes on», «learn this chapter», «підготуй матеріал для вивчення», «повтори зі мною», «review my notes», «поганяй по конспекту», «quiz me on».
