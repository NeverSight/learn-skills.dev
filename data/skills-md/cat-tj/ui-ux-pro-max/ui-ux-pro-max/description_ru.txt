Интеллект в дизайне UI/UX для веба и мобильных приложений. Включает более 50 стилей, 161 палитру цветов, 57 сочетаний шрифтов, 161 тип продукта, 99 рекомендаций по UX и 25 типов графиков в 10 стеках (React, Next.js, Vue, Svelte, SwiftUI, React Native, Flutter, Tailwind, shadcn/ui и HTML/CSS). Действия: планировать, разрабатывать, создавать, проектировать, внедрять, проверять, исправлять, улучшать, оптимизировать, усиливать, рефакторить и проверять код UI/UX. Проекты: веб‑сайт, лендинг‑страница, дашборд, админ‑панель, электронная коммерция, SaaS, портфолио, блог и мобильное приложение. Элементы: кнопка, модальное окно, навигационная панель, боковая панель, карточка, таблица, форма и график. Стили: стеклянный морфизм, глиняный морфизм, минимализм, брутализм, неоморфизм, бенто‑сетка, тёмный режим, адаптивный дизайн, скеуоморфизм и плоский дизайн. Темы: системы цветов, доступность, анимация, компоновка, типография, сочетание шрифтов, отступы, состояния взаимодействия, тени и градиенты. Интеграции: shadcn/ui MCP для поиска компонентов и примеров.
