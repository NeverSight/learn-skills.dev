Konfiguriere GrowthBook-API-Anmeldeinformationen und die vertrauenswürdige App-URL, damit die anderen Skills ausgeführt werden und mit der UI verknüpft werden können. Verwende dies, wenn der Benutzer sagt „set up growthbook“, „configure my api key“, „growthbook isn’t working“, „where do i put my key“ oder wenn ein anderer Skill einen Fehler ausgibt, der hierhin verweist („GB_API_KEY is not set“, „authentication failed“, „GB_APP_URL is required“). Schreibt ~/.config/growthbook/.env mit chmod 600 und validiert gegen die Live‑API. Für das Auflisten von Flags oder das Ausführen von Experimenten übernehmen die Domänen‑Skills das.

Bitte immer in der Sprache des Benutzers antworten.
