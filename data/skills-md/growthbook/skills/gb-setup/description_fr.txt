Configurez les informations d’identification de l’API GrowthBook et l’origine d’application approuvée afin que les autres compétences puissent s’exécuter et se lier à l’interface utilisateur. Utilisez‑le lorsque l’utilisateur dit « set up growthbook », « configure my api key », « growthbook isn’t working », « where do I put my key », ou lorsqu’une autre compétence émet une erreur pointant ici (« GB_API_KEY is not set », « authentication failed », « GB_APP_URL is required »). Écrivez ~/.config/growthbook/.env avec chmod 600 et validez contre l’API en direct. Pour lister les drapeaux ou exécuter des expériences, les compétences de domaine s’en occupent.

Veuillez toujours répondre dans la langue de l’utilisateur.
