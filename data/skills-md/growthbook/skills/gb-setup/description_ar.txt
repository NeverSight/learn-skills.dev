قم بتكوين بيانات اعتماد GrowthBook API ومنشأ التطبيق الموثوق به حتى تتمكن المهارات الأخرى من التشغيل والربط بواجهة المستخدم. استخدم هذا عندما يقول المستخدم “إعداد growthbook”، “تكوين مفتاح API الخاص بي”، “growthbook لا يعمل”، “أين أضع مفتاحي”، أو عندما تصدر مهارة أخرى خطأ يشير إلى هنا (“GB_API_KEY غير مُعيّن”، “فشل المصادقة”، “GB_APP_URL مطلوب”). يكتب الملف ‎~/.config/growthbook/.env مع صلاحية chmod 600 ويُتحقق من صحة ذلك ضد API الحية. بالنسبة لقائمة العلامات أو تشغيل التجارب، تتولى مهارات المجال ذلك.

يرجى دائمًا الرد بلغة المستخدم.
