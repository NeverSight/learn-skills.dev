Configura le credenziali API di GrowthBook e l'origine dell'app di fiducia in modo che le altre skill possano funzionare e collegarsi all'interfaccia utente. Utilizza quando l'utente dice «set up growthbook», «configure my api key», «growthbook isn't working», «where do I put my key», o quando un'altra skill genera un errore che punta a questo («GB_API_KEY is not set», «authentication failed», «GB_APP_URL is required»). Scrive il file ~/.config/growthbook/.env con permessi chmod 600 e lo convalida contro l'API live. Per l'elenco dei flag o l'esecuzione di esperimenti, le skill di dominio se ne occupano.
