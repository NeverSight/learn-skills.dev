Concevez, lancez, analysez et arrêtez les tests A/B GrowthBook, et recherchez ou enregistrez des apprentissages durables à travers les expériences. À utiliser pour les expériences, les tests fractionnés, les variations, les hypothèses, la taille de l'échantillon, les mesures de garde-corps, le SRM, la chance de gagner, de soulever, de déclarer un gagnant, "qu'avons-nous appris", "avons-nous testé cela auparavant" ou "enregistrer cet apprentissage". Pour les bandits, identifiez-les et dirigez l'utilisateur vers l'interface utilisateur de GrowthBook. Pour les indicateurs de fonctionnalités et les déploiements, utilisez feature-flags. Pour l’analyse de produits ou le travail sur un catalogue de métriques, utilisez l’analyse. Pour la configuration de la clé API, utilisez gb-setup.
