Erstellen Sie für jedes Produkt einen 10-30-Sekunden-Erklärer mit kontinuierlicher Aufnahme, der vom Code auf MP4 mit Ton gerendert wird. Ein Hero-Element (ein Ball, ein Cursor, eine Datei, eine Nachricht) reist durch den Workflow des Produkts, der als Stationen auf einer großen Leinwand angeordnet ist; die Kamera folgt ihm, jede Station reagiert, wenn sie vorbeigeht, dann zieht die Kamera heraus, um die gesamte Reise zu enthüllen. Verwenden Sie es, wenn jemand einen ansprechenden, storybasierten One-Take-Erklärer oder eine Loopable-Produktanimation möchte.
