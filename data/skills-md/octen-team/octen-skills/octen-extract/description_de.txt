VERWENDEN SIE DIESE OPTION, um saubere, LLM-fähige Inhalte aus einer oder mehreren Webseiten-URLs zu extrahieren, die von Octen bereitgestellt werden. Rufen Sie 1-20 URLs in einem Aufruf ab und erhalten Sie Markdown-/Textinhalte sowie eine Seitenkategorie, eine Seitenstrukturbeschriftung und (optional) abfragegesteuerte Highlights. Verwenden Sie es zum Lesen von Artikeln, zum Scraping von Seiten für RAG/Grounding, zum Zusammenfassen oder zum Nachschlagen von Fakten aus bekannten URLs.
