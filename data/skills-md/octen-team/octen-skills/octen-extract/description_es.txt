UTILÍCELO PARA extraer contenido limpio y listo para LLM de una o más URL de páginas web, con la tecnología de Octen. Obtenga 1-20 URL en una llamada y obtenga contenido de rebaja/texto más una categoría de página, etiqueta de estructura de página y (opcionalmente) aspectos destacados basados en consultas. Úselo para leer artículos, raspar páginas para RAG/grounding, resumen o búsqueda de hechos de URL conocidas.
