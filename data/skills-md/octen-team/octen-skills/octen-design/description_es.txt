Obtener referencias de diseño UI del mundo real antes de construir cualquier frontend. Usa esta habilidad cada vez que implementes, restyles o mejores cualquier UI web — páginas, componentes, diseños, paneles, formularios, tarjetas, navegaciones, modales, secciones de marketing — incluso cuando el usuario no solicite explícitamente una "referencia de diseño". Frases como "crea una página de configuración", "haz una tarjeta de precios", "esto se ve sencillo, mejóralo" o "coincide con el estilo de X" deben activar la funcionalidad. Consulta una API de búsqueda de diseño multimodal para obtener capturas de pantalla de referencia de los principales productos, descripciones estructuradas de estilo y fragmentos HTML/CSS, de modo que la implementación se base en patrones probados en lugar de inventarse desde cero. Omitirla solo para trabajo puramente lógico/back‑end sin superficie visual.

Por favor, siempre responde en el idioma del usuario.
