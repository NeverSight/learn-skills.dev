프론트엔드를 만들기 전에 실제 UI 디자인 레퍼런스를 찾아보세요. 이 스킬은 웹 UI—페이지, 컴포넌트, 레이아웃, 대시보드, 폼, 카드, 내비게이션, 모달, 마케팅 섹션—를 구현하거나 재스타일링, 개선할 때마다 사용합니다. 사용자가 명시적으로 “디자인 레퍼런스”를 요청하지 않아도 마찬가지입니다. “설정 페이지 만들어줘”, “가격 카드 만들어줘”, “이게 너무 심심해, 개선해줘”, “X와 스타일을 맞춰줘”와 같은 문구는 모두 트리거가 됩니다. 이 기능은 멀티모달 디자인 검색 API에 질의하여 주요 제품들의 레퍼런스 스크린샷, 구조화된 스타일 설명, HTML/CSS 스니펫을 받아오므로, 구현이 새로 창조하는 것이 아니라 검증된 패턴에 기반하게 됩니다. 순수히 논리·백엔드 작업으로 시각적 UI가 전혀 필요 없는 경우에만 건너뛰세요.
