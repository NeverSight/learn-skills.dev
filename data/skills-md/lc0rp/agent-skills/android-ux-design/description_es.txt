Crea interfaces de usuario/experiencia de usuario nativas y sólidas para Android dentro de Codex o GPT. Usa esta habilidad al construir o rediseñar pantallas Android, interfaces con Jetpack Compose, temas Material 3, diseños adaptativos, flujos para pantallas grandes, superficies de configuración, onboarding, paneles de control, formularios o cualquier experiencia nativa de Android donde una UI móvil genérica o un enfoque orientado a la web represente un riesgo. Mejora la dirección visual, la adecuación a la plataforma Android, la tematización en Compose, la navegación adaptativa, la accesibilidad, la iteración basada en capturas de pantalla y el pulido específico del producto para no diseñadores y desarrolladores.
