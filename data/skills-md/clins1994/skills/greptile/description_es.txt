Cómo trabajar con Greptile, el revisor de código IA: en una pull request (buscar su puntuación y comentarios, indicar si revisa cada push o espera ser solicitado, solicitar una re‑revisión, esperar a que lo haga, resolver sus hilos) y localmente antes de una pull request (el CLI de Greptile). clins:address-reviews utiliza esta habilidad como su revisor Greptile. Úsala cada vez que leas, actives, esperes o respondas una revisión de Greptile, o ejecutes una revisión local de Greptile.
