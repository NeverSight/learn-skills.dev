Точка входа для выделенной модели сборки — более небольшая/быстрая модель, запускаемая в сессии, чья единственная задача — построить план, проверить его и передать дальше. Организует /build-phase во всех фазах, затем /3p-review (цикл до чистоты), затем /handoff-summary, затем делает паузу. НЕ запускает /verify-completion. Основная модель использует agentic-workflow вместо этого.
