Sinch Functions, la plateforme serverless bêta pour les applications vocales, SMS et de conversation. Utilisez‑la pour les questions sur la plateforme : ce que c’est, comment le déploiement fonctionne, choisir Node.js ou C#, installer et authentifier, FunctionContext, les gestionnaires, le cycle de vie des appels Voice v2 et les événements `call.*`, les services vocaux et `VOICE_SERVICE_ID`, et SVAML. Le code d’exécution se trouve dans sinch-functions-node et sinch-functions-dotnet.
