أنشئ مكالمات قابلة للبرمجة باستخدام Sinch Voice API v2 (معاينة عامة). يُستخدم لإنشاء مكالمات صادرة، ومعالجة webhooks الخاصة بـ Voice v2، وكتابة تدفقات المكالمات SVAML v2، وقوائم IVR، وربط أطراف المكالمات، وتسجيل المكالمات، وإجراء مكالمات جماعية، وربط Voice Relay أو تدفقات الصوت الخام إلى وكلاء الذكاء الاصطناعي الصوتي، وترحيل التحكم في مكالمات Voice v1 إلى v2. لا يُستعمل لمكالمات Voice API v1 و ردود ICE/ACE/PIE (استخدم sinch‑voice‑api)، أو حزم تطوير مكالمات داخل التطبيق، أو Elastic SIP Trunk.
