Erstellen Sie programmierbare Anrufe mit der Sinch Voice API v2 (öffentliche Vorschau). Verwenden Sie sie für ausgehende Anrufe, die Verarbeitung von Voice‑v2‑Webhooks, das Schreiben von SVAML v2‑Anrufabläufen, IVR‑Menüs, das Verbinden von Anrufbeinen, Anrufaufzeichnungen, Batch‑Anrufe, das Anschließen von Voice‑Relay‑ oder Roh‑Audio‑Streams an KI‑Sprachagenten und die Migration von Voice‑v1‑Anrufsteuerung zu v2. Nicht für Voice‑API‑v1‑Anrufe und ICE/ACE/PIE‑Callbacks (verwenden Sie sinch‑voice‑api), die In‑App‑Calling‑SDKs oder Elastic SIP Trunking.
