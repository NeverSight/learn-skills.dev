Создавайте программируемые звонки с помощью Sinch Voice API v2 (публичный превью). Используйте для создания исходящих вызовов, обработки веб‑хуков Voice v2, написания сценариев звонков SVAML v2, меню IVR, объединения звонковых сторон, записи звонков, массовых вызовов, подключения Voice Relay или необработанных аудиопотоков к AI‑голосовым агентам, а также миграции управления звонками Voice v1 на v2. Не предназначено для вызовов Voice API v1 и обратных вызовов ICE/ACE/PIE (используйте sinch-voice-api), SDK In‑App Calling или Elastic SIP Trunking.
