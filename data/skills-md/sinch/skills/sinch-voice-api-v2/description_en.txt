Build programmable calling with the Sinch Voice API v2 (public preview). Use for creating outbound calls, handling Voice v2 webhooks, writing SVAML v2 call flows, IVR menus, bridging call legs, call recording, batch calling, connecting Voice Relay or raw audio streams to AI voice agents, and migrating Voice v1 call control to v2. Not for Voice API v1 callouts and ICE/ACE/PIE callbacks (use sinch-voice-api), the In-App Calling SDKs, or Elastic SIP Trunking.
