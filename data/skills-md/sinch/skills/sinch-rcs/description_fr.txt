Envoie des messages RCS (Rich Communication Services) via le canal RCS de l’API Sinch Conversation — cartes riches, carrousels, réponses suggérées et actions, médias, localisation et actions de calendrier, avec bascule automatique vers SMS. À utiliser lors de l’envoi d’un message RCS, d’une carte riche, d’un carrousel ou d’un message d’action suggérée ; pour vérifier la capacité RCS d’un appareil ; configurer la bascule RCS‑vers‑SMS ; provisionner un agent RCS ; ou envoyer des indicateurs de saisie.
