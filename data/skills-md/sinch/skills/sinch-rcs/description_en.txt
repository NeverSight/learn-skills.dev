Sends RCS (Rich Communication Services) messages via the RCS channel of the Sinch Conversation API — rich cards, carousels, suggested replies and actions, media, location, and calendar actions, with automatic SMS fallback. Use when sending an RCS message, rich card, carousel, or suggested-action message; checking device RCS capability; configuring RCS-to-SMS fallback; provisioning an RCS agent; or sending typing indicators.
