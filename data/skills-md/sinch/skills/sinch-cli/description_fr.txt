Commandes terminal pour le CLI Sinch (`sinch`, npm `@sinch/cli`). À utiliser chaque fois que l'utilisateur exécute ou demande une commande `sinch` : login, Functions init/dev/deploy/logs/status, numéros de téléphone et portabilité, envoi de SMS/WhatsApp/RCS, passer des appels et configurer les services vocaux, fax, trunks SIP, secrets et modèles. Le code d'exécution est couvert par sinch‑functions‑node et sinch‑functions‑dotnet.

Veuillez toujours répondre dans la langue de l'utilisateur.
