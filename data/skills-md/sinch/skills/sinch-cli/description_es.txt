Comandos de terminal para el CLI de Sinch (`sinch`, npm `@sinch/cli`). Úsalos siempre que el usuario ejecute o pregunte sobre un comando `sinch`: login, Functions init/dev/deploy/logs/status, números de teléfono y portabilidad, envío de SMS/WhatsApp/RCS, realización de llamadas y configuración de servicios de voz, fax, trunks SIP, secretos y plantillas. El código en tiempo de ejecución está cubierto por sinch-functions-node y sinch-functions-dotnet.

Por favor, responde siempre en el idioma del usuario.
