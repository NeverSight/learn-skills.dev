Scrivi Funzioni Sinch in C#/.NET con il pacchetto NuGet `Sinch.Functions.Runtime`. Usalo quando scrivi o modifichi un controller di funzione: rispondere e controllare le chiamate con Voice API v2, menu IVR, effettuare, collegare o trasferire chiamate, agenti vocali AI in tempo reale, webhook SMS/WhatsApp/RCS, endpoint HTTP personalizzati, iniezione delle dipendenze, cache/storage/database e autorizzazione. Esegui e distribuisci con la skill sinch-cli.
