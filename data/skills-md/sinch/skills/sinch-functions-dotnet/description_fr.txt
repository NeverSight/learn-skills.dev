Écrivez des fonctions Sinch en C#/.NET avec le package NuGet `Sinch.Functions.Runtime`. Utilisez-le lors de la rédaction ou de la modification d’un contrôleur de fonction : répondre et contrôler les appels avec Voice API v2, les menus IVR, passer, mettre en pont ou transférer des appels, les agents vocaux IA en temps réel, les webhooks SMS/WhatsApp/RCS, les points de terminaison HTTP personnalisés, l’injection de dépendances, le cache, le stockage, la base de données et l’autorisation. Exécutez et déployez avec la compétence sinch-cli. Veuillez toujours répondre dans la langue de l'utilisateur.
