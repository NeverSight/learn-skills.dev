اكتب دوال Sinch بلغة C#/.NET باستخدام حزمة NuGet `Sinch.Functions.Runtime`. استخدمها عند كتابة أو تعديل متحكم الدالة: الرد والتحكم في المكالمات باستخدام Voice API v2، قوائم IVR، إجراء أو ربط أو تحويل المكالمات، وكلاء صوتية بالذكاء الاصطناعي في الوقت الفعلي، ويب هوكس لـ SMS/WhatsApp/RCS، نقاط نهاية HTTP مخصصة، حقن التبعيات، التخزين/الكاش/قاعدة البيانات والتفويض. شغّل وانشر باستخدام مهارة sinch-cli.
