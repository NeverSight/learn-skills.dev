Escribe funciones Sinch en Node.js/TypeScript con `@sinch/functions-runtime`. Úsalo al escribir o editar `function.ts`: responder y controlar llamadas con Voice API v2, menús IVR, iniciar o enlazar llamadas, webhooks de SMS/WhatsApp/RCS, endpoints HTTP personalizados, caché/almacenamiento/base de datos, autenticación y hooks `setup()`. Ejecuta y despliega con la herramienta sinch-cli.

Por favor, responde siempre en el idioma del usuario.
