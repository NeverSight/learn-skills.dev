Пишите функции Sinch на Node.js/TypeScript с помощью `@sinch/functions-runtime`. Используйте при написании или редактировании `function.ts`: отвечать и управлять звонками через Voice API v2, IVR‑меню, инициировать или соединять звонки, веб‑хуки SMS/WhatsApp/RCS, пользовательские HTTP‑конечные точки, кэш/хранилище/базу данных, аутентификацию и хуки `setup()`. Запускайте и разворачивайте с помощью sinch-cli.
