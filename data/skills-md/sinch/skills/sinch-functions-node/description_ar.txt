اكتب وظائف Sinch باستخدام Node.js/TypeScript مع `@sinch/functions-runtime`. استخدمه عند كتابة أو تعديل `function.ts`: الرد والتحكم في المكالمات باستخدام Voice API v2، قوائم IVR، إجراء أو ربط المكالمات، webhooks للرسائل SMS/WhatsApp/RCS، نقاط نهاية HTTP مخصصة، التخزين/الذاكرة المؤقتة/قاعدة البيانات، المصادقة و`setup()` hooks. قم بالتشغيل والنشر باستخدام أداة sinch-cli.
