Claude Code 프로젝트의 인터넷 컴퓨터 기술을 자동으로 최신 상태로 유지하는 일회성 설치 프로그램입니다. SessionStart 후크와 동기화 스크립트를 설정하여 .claude/skills/가 항상 Skills.internetcomputer.org에 게시된 최신 기술을 반영하도록 합니다. 사용자가 프로젝트에서 "항상 최신" 인터넷 컴퓨터/IC/ICP/Motoko 기술을 설치, 부트스트랩 또는 활성화하려고 하거나 이 기술에 대한 링크를 붙여넣을 때 사용합니다. 이는 지속적인 IC 지식이 아닌 일회성 설정 작업입니다. 실행 후 설치된 후크는 모든 세션에서 기술을 최신 상태로 유지합니다. IC 코딩 질문 자체에는 사용하지 마십시오. 이는 자동 업데이트 기술만 구성합니다.
