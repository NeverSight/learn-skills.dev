L'installateur unique qui permet à un projet Claude Code de maintenir automatiquement à jour ses compétences informatiques Internet. Configure un hook SessionStart ainsi qu'un script de synchronisation afin que .claude/skills/ reflète toujours les dernières compétences publiées sur skills.internetcomputer.org. À utiliser lorsqu'un utilisateur souhaite installer, amorcer ou activer les compétences Internet Computer / IC / ICP / Motoko « toujours les plus récentes » dans un projet, ou colle le lien vers cette compétence. Il s'agit d'une action de configuration unique et non d'une connaissance continue du circuit intégré : après son exécution, le hook installé maintient les compétences à jour à chaque session. Ne PAS utiliser pour les questions de codage IC elles-mêmes : cela configure uniquement les compétences de mise à jour automatique.
