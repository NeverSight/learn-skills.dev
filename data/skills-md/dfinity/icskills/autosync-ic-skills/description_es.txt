Instalador único que hace que un proyecto de Claude Code mantenga sus conocimientos informáticos de Internet actualizados automáticamente. Configura un enlace SessionStart más un script de sincronización para que .claude/skills/ siempre refleje las últimas habilidades publicadas en skills.internetcomputer.org. Úselo cuando un usuario desee instalar, iniciar o habilitar habilidades de Computadora de Internet/IC/ICP/Motoko "siempre más recientes" en un proyecto, o pegue el enlace a esta habilidad. Esta es una acción de configuración única, no un conocimiento continuo de IC: después de ejecutarse, el enlace instalado mantiene las habilidades actualizadas en cada sesión. NO lo use para preguntas de codificación IC; esto solo configura habilidades de actualización automática.
