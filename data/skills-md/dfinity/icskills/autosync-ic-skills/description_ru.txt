Одноразовый установщик, который позволяет проекту Claude Code автоматически обновлять свои навыки работы с Интернет-компьютером. Настраивает перехватчик SessionStart и сценарий синхронизации, чтобы .claude/skills/ всегда отражал последние навыки, опубликованные на сайтеkills.internetcomputer.org. Используйте, когда пользователь хочет установить, загрузить или включить «всегда новейшие» навыки Интернет-компьютера / IC / ICP / Motoko в проекте или вставляет ссылку на этот навык. Это однократное действие по настройке, а не постоянное знание IC — после его запуска установленный хук сохраняет текущие навыки в каждом сеансе. НЕ используйте сами вопросы по кодированию микросхем — это только настраивает навыки автоматического обновления.
