프로젝트의 Internet Computer CLI 툴체인을 최신 상태로 유지하는 일회성 설치 프로그램입니다. SessionStart 후크와 스크립트를 설정하여 설치된 `icp`와 `ic-wasm`을 최신 릴리스와 비교하고, 업그레이드를 보고하거나 적용합니다. 각 도구가 설치된 채널(npm, Homebrew, 셸 설치 프로그램)을 그대로 사용합니다. 아래와 같은 경우에 사용하십시오:

- 사용자가 icp‑cli / ic‑wasm을 설치하거나 부트스트랩하거나 자동 업데이트를 활성화하려고 할 때  
- 오래된 `icp` 실행을 중지하라는 요청을 받을 때  
- ICP CLI의 버전을 확인하거나 업그레이드 방법을 물을 때  
- 이 스킬의 링크를 붙여넣을 때  

이는 일회성 설정 작업이며 지속적인 IC 지식이 아닙니다. `icp.yaml` 작성, 캐니스터 배포, 기타 icp‑cli 사용 질문에는 사용하지 마세요 — 해당 경우에는 `icp-cli`를 로드하십시오.
