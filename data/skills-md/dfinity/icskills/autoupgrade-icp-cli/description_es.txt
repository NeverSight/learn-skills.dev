Instalador único que mantiene la cadena de herramientas CLI de Internet Computer de un proyecto actualizada. Configura un hook SessionStart más un script que compara los `icp` y `ic-wasm` instalados con la última versión y, según corresponda, informa la actualización o la aplica, usando el canal por el que cada herramienta fue instalada (npm, Homebrew o el instalador de shell). Úsalo cuando un usuario quiere instalar, iniciar o habilitar actualizaciones automáticas de icp-cli / ic-wasm, pide detener la ejecución de un `icp` desactualizado, pregunta cómo actualizar o verificar la versión del CLI de ICP, o pega el enlace a esta habilidad. Esta es una acción de configuración única, no conocimiento continuo de IC. NO lo uses para escribir icp.yaml, desplegar canisters u otras preguntas de uso de icp-cli — carga `icp-cli` para eso.
