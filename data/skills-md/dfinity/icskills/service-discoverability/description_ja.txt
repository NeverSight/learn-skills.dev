ICP MCP などを介して、URL だけから AI エージェントがキャニスター アプリを検出できるようにします。キャニスターの /.well-known/ic-architecture マニフェストの公開 (静的サイト レシピの事前同期フックと envsubst を介して実際のキャニスター ID からデプロイ時に生成) の公開に加えて、candid:service (インターフェース)、getApiDoc クエリ メソッド (動作)、オプションの OQL スキーマ/実行データ サーフェス、および /.well-known/ii-deriveation-origin ファイル (アイデンティティ) の公開について説明します。そのマニフェストを公開すると、アプリが ICP MCP にオプトインされ、それ自体が ICP MCP アプリ オペレーター規約にオペレーターが同意したことになるため、デプロイする前にアプリのオペレーターに確認してください。アプリをエージェント対応にする場合、または ICP MCP を通じて利用できるようにする場合、エージェント/サービスの検出、よく知られている ic アーキテクチャ マニフェスト、またはデプロイ時にそのマニフェストを生成する場合に使用します。派生オリジンを使用するサインイン フローには使用しないでください。エージェント/CLI Web ID リンクには、agent-web-identity を使用し、フロントエンドに II ログインを追加するには、internet-identity を使用します。
