Создавайте криптографию vetKeys на компьютере, подключенном к Интернету, с помощью системного API vetKD и библиотек ic-vetkeys (Rust, Motoko) и @icp-sdk/vetkeys (внешний интерфейс): шифрование на основе идентификации (IBE), пороговые подписи BLS, шифрование с временной блокировкой, генерация симметричного ключа и генерация открытого ключа в автономном режиме. Используйте при реализации IBE, шифровании для принципала, подписании BLS, схемах с запечатанным предложением или временной блокировкой, получении ключей шифрования в цепочке, транспортных ключей или вызове vetkd_public_key/vetkd_derive_key. Для зашифрованного хранилища значений ключей с контролем доступа (менеджеры паролей, зашифрованные заметки) вместо этого используйте навык зашифрованных карт. Не для аутентификации — используйте интернет-идентификацию.
