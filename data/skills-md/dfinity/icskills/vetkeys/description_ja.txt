vetKD システム API と ic-vetkeys (Rust、Motoko) および @icp-sdk/vetkeys (フロントエンド) ライブラリを介して、インターネット コンピューター上で vetKeys 暗号化を構築します: ID ベースの暗号化 (IBE)、しきい値 BLS 署名、タイムロック暗号化、対称キー導出、およびオフライン公開キー導出。 IBE の実装、プリンシパルへの暗号化、BLS 署名、シール入札またはタイムロック スキーム、オンチェーンの暗号化キーの導出、トランスポート キー、または vetkd_public_key / vetkd_derive_key の呼び出し時に使用します。アクセス制御された暗号化キーと値のストレージ (パスワード マネージャー、暗号化されたメモ) の場合は、代わりに encrypted-map スキルを使用します。認証用ではありません - インターネット ID を使用します。
