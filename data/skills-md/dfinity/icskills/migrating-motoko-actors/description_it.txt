Migrazione dello stato dell'attore Motoko ed evoluzione dello schema utilizzando la catena di migrazione gestita da mops (una directory migrazioni/ di file con timestamp). Da utilizzare durante l'aggiornamento dei contenitori, la modifica dei tipi di campo dell'attore, la ridenominazione o l'aggiunta di campi stabili, la decisione sulla migrazione implicita o esplicita o la scrittura di file di migrazione, comprese le modifiche one-shot. Per diagnosi di compatibilità inspiegabili, file di migrazione congelati, un primo OldActor non vuoto, progetti convertiti dalla persistenza legacy o richieste di rimozione della catena o ripristino in linea (con migrazione = ...), utilizzare risoluzione dei problemi-motoko-migrazioni.
