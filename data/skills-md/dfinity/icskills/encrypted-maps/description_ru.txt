Добавьте хранилище ключей и значений с контролируемым доступом и сквозным шифрованием в контейнер с помощью библиотеки vetKeys EncryptedMaps (ic-vetkeys для серверных частей Rust и Motoko, @icp-sdk/vetkeys для внешнего интерфейса). Значения шифруются на стороне клиента с помощью vetKeys и распределяются между участниками с правами доступа для каждого пользователя (Read, ReadWrite, ReadWriteManage). Используйте при создании менеджера паролей, зашифрованных заметок, безопасного хранилища или любого приложения, которое хранит и передает зашифрованные данные в цепочке. Начните здесь для зашифрованного хранения; переходите к навыку vetkeys только для подписей BLS, пользовательского IBE или шифрования с временной блокировкой.
