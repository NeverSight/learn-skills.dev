قم بتثبيت والتحقق من SolidWorks MCP لواجهة سطر الأوامر OpenAI Codex على نظام Windows. يربط Codex بـ SOLIDWORKS عبر COM لأتمتة CAD (أجزاء، رسومات، استخراج، تجميعات). يدعم SOLIDWORKS 2019 وما بعده مع التصحيحات المضمنة. استخدمه عند تثبيت SolidWorks MCP، تكوين .codex/config.toml، الاتصال بـ SolidWorks، تشغيل $solidworks-mcp، أو إصلاح أخطاء COM/MCP.
