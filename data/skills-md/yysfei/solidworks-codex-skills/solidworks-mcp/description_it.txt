Installa e verifica SolidWorks MCP per OpenAI Codex CLI su Windows. Connette Codex a SOLIDWORKS tramite COM per l'automazione CAD (parti, schizzi, estrusione, assiemi). Supporta SOLIDWORKS 2019+ con patch incluse. Usalo durante l'installazione di SolidWorks MCP, la configurazione di .codex/config.toml, la connessione a SolidWorks, l'esecuzione di $solidworks-mcp o la correzione di errori COM/MCP. Per favore rispondi sempre nella lingua dell'utente.
