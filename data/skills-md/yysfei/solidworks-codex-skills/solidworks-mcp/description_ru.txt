Установите и проверьте SolidWorks MCP для OpenAI Codex CLI в Windows. Обеспечивает подключение Codex к SOLIDWORKS через COM для автоматизации САПР (детали, эскизы, вытягивание, сборки). Поддерживает SOLIDWORKS 2019 и новее с включёнными патчами. Используйте при установке SolidWorks MCP, настройке .codex/config.toml, подключении к SolidWorks, запуске $solidworks-mcp или устранении ошибок COM/MCP.
