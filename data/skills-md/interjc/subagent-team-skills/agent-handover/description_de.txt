Halte die Mehragenten‑Programmierungsarbeit jederzeit wiederaufnehmbar. Protokolliere Fortschritt, laufende Agenten und Aufträge, Aufgaben‑Karten, Entscheidungen, Nutzerpräferenzen, Erkenntnisse und offene Fragen im Repository, nicht im Chat oder im lokalen Agentenspeicher, damit ein anderer Agent oder ein Werkzeug innerhalb von Minuten übernehmen kann. Verwende dies, nachdem eine delegierte Aufgabe akzeptiert oder bestätigt wurde, bevor eine Sitzung unterbrochen oder der Kontext komprimiert wird, beim Übergeben der Arbeit an einen anderen Agenten oder ein anderes Werkzeug (Claude Code ↔ Codex), beim Übernehmen von halb fertiggestellter Arbeit eines anderen oder beim kalten Start und immer dann, wenn der Nutzer eine Entscheidung oder Präferenz äußert, die über diese Sitzung hinaus Bestand haben soll.
