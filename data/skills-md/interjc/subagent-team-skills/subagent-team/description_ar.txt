تشغيل عمل الترميز متعدد الملفات ومتعدد المراحل كمنظمة برمجية صغيرة في أربع طبقات. الجلسة الرئيسية هي المدير؛ الوكلاء الفرعيون الخبراء داخل الشركة يصممون، يراجعون ويقبلون؛ الوكلاء الفرعيون التنفيذيون داخل الشركة ينفّذون ويختبرون؛ الفرق الخارجية (وكلاء من بائعين آخرين عبر سطر الأوامر CLI أو المكوّن الإضافي plugin أو ACP أو MCP، مثل agy أو Codex CLI أو OpenCode) يتولون الأعمال الضخمة عبر وصلة منخفضة المستوى؛ يحصل الإنسان على قائمة أسئلة مجمّعة في النهاية. يكتشف ويؤكد نظام الاستضافة، يحتفظ بالحالة المشتركة على لوحة فريق في المستودع، ويحافظ على ملف AGENTS.md والوثائق مترابطة. استخدم هذا كلما امتدت المهمة عبر عدة ملفات أو مراحل، وكلما كنت على وشك تقسيم العمل أو اختيار تدفق المهمة، أو تفويض إلى وكيل فرعي أو وكيل خارجي، أو اختيار نموذج أو جهد لأحدها، أو كتابة موجز، أو الاختيار، أو التحقق أو تتبع الفرق الخارجية، أو مراجعة أو قبول العمل المفوض، أو إعداد سياسة فريق المشروع، أو تسجيل درس أو تعديل للمستخدم، أو اتخاذ قرار ما إذا كان يجب سؤال المستخدم، حتى وإن لم يقل المستخدم أبدًا "وكيل فرعي".
