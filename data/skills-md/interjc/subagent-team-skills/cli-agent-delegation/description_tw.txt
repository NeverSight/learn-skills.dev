將明確規範的大量程式碼工作外包給其他供應商的代理人，可透過其 CLI、外掛、ACP 或 MCP 伺服器。涵蓋 OpenAI Codex CLI（codex exec，或 OpenAI 的 Codex 外掛，用於 Claude Code）、Google Antigravity（agy，是否搭配 agy‑staff 外掛皆可）以及透過其代理客戶端協議伺服器（opencode acp）的 OpenCode，並提供備援階梯；另外也可透過 ACP 及其註冊表（Grok Build、Cursor、Pi；Gemini CLI 已棄用，請改用 agy）加入其他代理人。會詢問使用者要使用哪個外部團隊，並在需要時重新確認其能力。於以下情況使用此功能：將翻譯、機械重構、測試或快照回填、文件同步或二次意見審查交由外部代理人執行；在以 headless 模式執行 codex、agy 或 opencode 時；在於它們之間做選擇或從一個切換到另一個作備援時；當使用者詢問有哪些外部代理人可用，或想新增、移除或驗證某個代理人時；當聯絡人派發、等待、恢復或接受其工作時；或當派遣外掛缺失或損壞時。請始終以使用者的語言回覆。
