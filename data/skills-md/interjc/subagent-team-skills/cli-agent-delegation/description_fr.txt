Externalisez des travaux de programmation par lots, bien spécifiés, vers l'agent d'un autre fournisseur via son CLI, un plugin, l'ACP ou un serveur MCP. Cela couvre le CLI OpenAI Codex (codex exec, ou le plugin OpenAI Codex pour Claude Code), Google Antigravity (agy, avec ou sans le plugin agy‑staff) et OpenCode via son serveur Agent Client Protocol (opencode acp), avec des mécanismes de repli, ainsi que l’intégration d’autres agents via l’ACP et son registre (Grok Build, Cursor, Pi ; le CLI Gemini est obsolète, utilisez agy). Le système demande à l’utilisateur quelles équipes externes utiliser et re‑vérifie leurs capacités sur demande. Utilisez-le lors du transfert de traductions, de refactorisations mécaniques, de remplissages de tests ou d’instantanés, de synchronisations de documentation ou d’une revue à second avis à un agent externe ; lors de l’exécution de codex, agy ou opencode en mode sans tête ; lors du choix entre ces solutions ou du basculement de l’une à l’autre ; quand l’utilisateur interroge sur les agents externes disponibles ou souhaite en ajouter, retirer ou vérifier un ; quand un intermédiaire déclenche, attend, reprend ou accepte leurs travaux ; ou encore lorsque un plugin de dispatch est manquant ou défectueux. Veuillez toujours répondre dans la langue de l’utilisateur.
