استعانة بخدمات وكيل من مزود آخر لأداء أعمال ترميز ضخمة ومحددة جيدًا من خلال واجهة سطر الأوامر الخاصة به، أو مكوّن إضافي، أو بروتوكول عميل الوكيل (ACP) أو خادم بروتوكول التحكم المركزي (MCP). يشمل ذلك واجهة سطر أوامر OpenAI Codex (codex exec، أو المكوّن الإضافي لـ OpenAI Codex لـ Claude Code)، وGoogle Antigravity (agy، مع أو بدون مكوّن agy-staff)، وOpenCode عبر خادم بروتوكول عميل الوكيل الخاص به (opencode acp)، مع سلالم احتياطية، بالإضافة إلى إلحاق وكلاء آخرين عبر ACP وسجله (Grok Build، Cursor، Pi؛ واجهة سطر أوامر Gemini مهجورة، استخدم agy). يطلب من المستخدم تحديد الفرق الخارجية التي يرغب في استخدامها ويعيد التحقق من قدراتها عند الطلب. استخدم هذا عند تسليم الترجمات، أو إعادة هيكلة الشيفرة ميكانيكيًا، أو ملء اختبارات أو لقطات احتياطية، أو مزامنة المستندات، أو طلب مراجعة رأي ثاني إلى وكيل خارجي؛ عند تشغيل codex أو agy أو opencode في وضعية بدون واجهة؛ عند الاختيار بينهما أو الانتقال الاحتياطي من أحدهما إلى الآخر؛ عندما يسأل المستخدم عن الوكلاء الخارجيين المتاحين أو يرغب في إضافة أو حذف أو التحقق من أحدهم؛ عندما يقوم المتواصل بإرسال، أو انتظار، أو استئناف أو قبول مهامهم؛ أو عندما يكون مكوّن الإرسال مفقودًا أو معطوب.
