Esternalizza lavoro di codifica massivo ben specificato a un agente di un altro fornitore tramite la sua CLI, un plugin, ACP o un server MCP. Copre OpenAI Codex CLI (codex exec, o il plugin Codex di OpenAI per Claude Code), Google Antigravity (agy, con o senza il plugin agy‑staff) e OpenCode tramite il suo server Agent Client Protocol (opencode acp), con meccanismi di fallback, più l’onboarding di altri agenti tramite ACP e il suo Registro (Grok Build, Cursor, Pi; la CLI Gemini è deprecata, usa agy). Chiede all’utente quali team esterni utilizzare e verifica nuovamente le loro capacità su richiesta. Usa questa procedura quando si affidano traduzioni, refactoring meccanici, backfill di test o snapshot, sincronizzazioni di documenti o una revisione di seconda opinione a un agente esterno; quando si esegue codex, agy o opencode in modalità headless; quando si sceglie tra loro o si passa da uno all’altro; quando l’utente chiede quali agenti esterni sono disponibili o vuole aggiungerne, rimuoverne o verificarne uno; quando un collegamento dispatcha, attende, riprende o accetta i loro lavori; o quando un plugin di dispatch è mancante o guasto. Rispondi sempre nella lingua dell’utente.
