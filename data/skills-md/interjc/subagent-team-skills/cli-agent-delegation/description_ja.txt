明確に定義された大量のコーディング作業を、ベンダーのエージェントへCLI、プラグイン、ACP、またはMCPサーバーを通じて外部委託します。対象は OpenAI Codex CLI（codex exec、または Claude Code 用の OpenAI Codex プラグイン）、Google Antigravity（agy、agy‑staff プラグインの有無にかかわらず）および OpenCode の Agent Client Protocol サーバー（opencode acp）で、フォールバック用の階層も含みます。さらに、ACP とそのレジストリを通じて他のエージェント（Grok Build、Cursor、Pi など）をオンボーディングします（Gemini CLI は非推奨で、agy を使用）。ユーザーに使用する外部チームを尋ね、必要に応じてその能力を再確認します。以下のケースで使用してください：翻訳、機械的リファクタリング、テストやスナップショットのバックフィル、ドキュメント同期、または外部エージェントによるセカンドオピニオンレビューを行うとき；codex、agy、opencode をヘッドレスで実行するとき；それらの間で選択したり、あるエージェントから別のエージェントへフォールバックするとき；ユーザーが利用可能な外部エージェントを尋ねたり、追加・削除・検証を希望したとき；リエゾンがジョブをディスパッチ、待機、再開、受諾する際；またはディスパッチプラグインが欠如または故障しているとき。 

常にユーザーの言語で応答してください。
