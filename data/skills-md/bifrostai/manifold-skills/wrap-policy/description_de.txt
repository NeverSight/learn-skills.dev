Packen Sie die Richtlinie eines Forschers für die Manifold-Plattform ein und beweisen Sie sie dann mit Check_Compatibility, Verify und einem Live-Lauf des Treibers (der Live-Lauf wird mit Zustimmung des Benutzers auf einer Maschine übersprungen, auf der das Modell nicht ausgeführt werden kann). Wird verwendet, wenn das Modell in den gebauten Container geladen wird. Verwenden Sie für Richtlinien, bei denen das Modell auf dem eigenen Inferenzserver des Benutzers (Modal, private HTTPS-Box) ausgeführt wird, stattdessen `/wrap-remote-policy`.
