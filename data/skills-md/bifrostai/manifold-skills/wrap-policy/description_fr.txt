Enveloppez la politique d'un chercheur pour la plate-forme Manifold, puis prouvez-la avec check_compatibility, verify et une exécution en direct du pilote (l'exécution en direct est ignorée, avec le consentement de l'utilisateur, sur une machine qui ne peut pas exécuter le modèle). À utiliser lorsque le modèle se charge dans le conteneur intégré. Pour les stratégies où le modèle s'exécute sur le serveur d'inférence de l'utilisateur (Modal, boîte HTTPS privée), utilisez plutôt «/wrap-remote-policy ».
