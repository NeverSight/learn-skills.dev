Installez et lancez le CLI Vibe‑Git pour aider le chef d'équipe et les membres à se connecter aux salles de collaboration, soumettre des propositions en Markdown, aligner les exigences, exécuter les tâches et examiner les changements internes des exigences. Les utilisateurs doivent l'utiliser lorsqu'ils opèrent Vibe‑Git ; les opérations standard Git/GitHub ne s'appliquent pas.
