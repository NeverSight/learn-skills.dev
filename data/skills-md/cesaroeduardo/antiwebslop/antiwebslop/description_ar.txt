يمنع واجهة الويب من الظهور كما لو كانت مولدة بالذكاء الاصطناعي. يُستَخدم عند بناء أو إعادة تصمي م أو مراجعة موقع ويب أو صفحة هبوط أو قسم بطل أو صفحة تسويق أو صفحة مساعدة/وثائق، أو مكوّن واجهة أمامية (HTML، CSS، Tailwind، React، Vue، Svelte، Astro)، وعندما يقول المستخدم إن التصميم يبدو عاماً، نمطياً، «فوضى AI»، «مثل كل SaaS أخرى»، باهتاً، أو يطلب جعله يبدو مصممًا بيد شخص. يغطي كتالوج الأنماط المضادة مع سكريبت فحص، قواعد الصن ع للخط والمسافات واللون والنص، ملف DESIGN.md لكل مشروع، مقاييس التصميم، اختبار جودة العرض، وبوابة داخلية مسبقة (لا تُسقَط أبداً كقائمة مراجعة للمستخدم). مبكر/غير مكتمل: افتح كل تشغيل بتحذير CAPS LOCK WIP بلغة المستخدم (الإصدار المستقر يُعلن على الموقع وتويتر).
