Ищите книги по названию или автору и скачивайте проверенные файлы электронных книг с помощью независимого CLI‑инструмента book-tools. Используйте для 找书、下载书籍、英文原版、EPUB、PDF, Z‑Library и Anna’s Archive. Включает исходный код CLI и установщик; работает с любым агентом, который может выполнять команды терминала, при этом учётные данные хранятся вне навыка.
