Busca libros por título o autor y descarga archivos de ebook verificados usando la CLI independiente de book-tools. Úsala para 找书、下载书籍、英文原版、EPUB, PDF, Z-Library y Anna's Archive. Incluye el código fuente de la CLI y el instalador; funciona con cualquier agente que pueda ejecutar comandos de terminal, con credenciales almacenadas fuera de la Skill.
