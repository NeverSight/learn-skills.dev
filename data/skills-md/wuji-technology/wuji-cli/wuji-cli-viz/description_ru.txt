Визуализируйте потоковые данные Wuji Hand 2 или Wuji Glove с помощью официального веб‑просмотрщика Rerun, используя `wuji viz`. Это следует использовать, когда пользователь хочет просмотреть положение руки, силы по каждому такселю, результирующую силу по каждому пальцу, историю сил, ошибки живой визуализации, интерактивный выбор устройства или выполнить тактильное обнуление в режиме реального времени для Hand 2.
