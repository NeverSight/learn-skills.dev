wuji SDK 사용자 프로필을 생성, 전환, 목록 확인, 표시, 이름 변경 또는 삭제하고, 캘리브레이션 번들(핸드 모델 + 촉각 모델)을 기기 간에 내보내기/가져오기 할 수 있습니다. 이 모든 작업은 `wuji user` CLI를 통해 수행합니다. 이는 ~/.wuji 아래에 있는 이름이 지정된 캘리브레이션 프로필이며, 운영 체제 계정이 아닙니다. 따라서 사용자를 삭제하거나 현재 사용자를 전환·변경하거나, 사용자의 이름을 바꾸거나, 사용자를 생성·목록 확인하거나, “기본 사용자는 캘리브레이션할 수 없음” 문제를 해결하거나, 캘리브레이션 데이터를 이동·검사하는 모든 요청에 이 스킬을 사용하십시오(코드를 편집하거나 OS 사용자를 건드리지 마세요). 삭제와 가져오기는 파괴적인 작업이며, 이 스킬은 안전하고 확인을 먼저 거치는 방법을 제공합니다.
