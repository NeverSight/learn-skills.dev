إنشاء، تبديل، سرد، إظهار، إعادة تسمية أو حذف ملفات تعريف مستخدمي SDK لـ wuji، وتصدير/استيراد حزم المعايرة (نموذج اليد + نموذج اللمس) بين الأجهزة، كل ذلك عبر سطر الأوامر `wuji user`. هذه هي ملفات تعريف المعايرة المسماة تحت ‎~/.wuji — ليست حسابات نظام تشغيل — لذا استخدم هذه المهارة (لا تقم أبدًا بتحرير الكود أو لمس مستخدمي النظام) لأي طلب لحذف مستخدم، تبديل/تغيير المستخدم الحالي، إعادة تسمية مستخدم، إنشاء أو سرد المستخدمين، حل مشكلة “المستخدم الافتراضي لا يمكنه المعايرة”، أو نقل/فحص بيانات المعايرة. الحذف والاستيراد عمليتان مدمّرتان؛ تغطي المهارة الطريقة الآمنة التي تتطلب التأكيد أولاً لتشغيلهما.
