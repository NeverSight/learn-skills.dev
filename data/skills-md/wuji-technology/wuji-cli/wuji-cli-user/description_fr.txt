Créez, changez, listez, affichez, renommez ou supprimez les profils d’utilisateur du SDK wuji, et exportez / importez les ensembles de calibration (modèle de main + modèle tactile) entre machines, le tout via la CLI `wuji user`. Il s’agit de profils de calibration nommés sous ~/.wuji — PAS des comptes du système d’exploitation — utilisez donc cette compétence (ne modifiez jamais le code ni n’intervenez sur les utilisateurs du système) pour toute demande de suppression d’un utilisateur, de changement / commutation de l’utilisateur actuel, de renommage d’un utilisateur, de création ou de listage d’utilisateurs, de résolution du blocage « l’utilisateur par défaut ne peut pas calibrer », ou de déplacement / inspection des données de calibration. La suppression et l’importation sont destructrices ; la compétence couvre la méthode sûre, avec confirmation préalable, pour les exécuter.
