Создавайте, переключайте, выводите список, показывайте, переименовывайте или удаляйте пользовательские профили SDK wuji, а также экспортируйте/импортируйте калибровочные наборы (модель руки + тактильную модель) между компьютерами, всё через CLI `wuji user`. Это именованные калибровочные профили в каталоге ~/.wuji — НЕ учетные записи операционной системы — поэтому используйте этот навык (никогда не редактируйте код и не трогайте системных пользователей) для любого запроса на удаление пользователя, переключение/изменение текущего пользователя, переименование пользователя, создание или вывод списка пользователей, устранение блока «по умолчанию пользователь не может калибровать», а также перемещение/просмотр калибровочных данных. Удаление и импорт являются деструктивными; навык покрывает безопасный способ их выполнения с подтверждением в первую очередь.
