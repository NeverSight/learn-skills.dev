Escribe, corrige y depura usuarioscripts para ScriptCat (compatible con Tampermonkey): scripts de página que se ejecutan en sitios coincidentes (@match), scripts de fondo que siguen ejecutándose sin una página (@background) y scripts programados (@crontab); metadatos, @grant y las APIs GM_* / GM.* / CAT_*, configuración del usuario, reintentos. Cuando el CLI sctl está conectado, instala el script en el ScriptCat del usuario y verifícalo en su navegador real. Úsalo siempre que el usuario quiera un userscript, 油猴脚本, 后台脚本, 定时脚本, un archivo .user.js o un script de ScriptCat escrito, modificado o depurado. No es para desarrollar la extensión ScriptCat en sí, y no es para gestionar scripts instalados sin cambiar su código (eso es la habilidad sctl). Por favor, responde siempre en el idioma del usuario.
