Écrire, corriger et déboguer des userscripts pour ScriptCat (compatible Tampermonkey) : scripts de page qui s’exécutent sur les sites correspondants (@match), scripts d’arrière‑plan qui continuent de fonctionner sans page (@background) et scripts planifiés (@crontab) ; métadonnées, @grant et les API GM_* / GM.* / CAT_*, configuration utilisateur, tentatives de réessai. Lorsque le CLI sctl est connecté, installer le script dans le ScriptCat de l’utilisateur et le vérifier dans son navigateur réel. Utiliser chaque fois que l’utilisateur souhaite un userscript, 油猴脚本, 后台脚本, 定时脚本, un fichier .user.js ou un script ScriptCat écrit, modifié ou débogué. Ce n’est pas destiné au développement de l’extension ScriptCat elle‑même, ni à la gestion de scripts installés sans en changer le code (c’est la compétence sctl).
