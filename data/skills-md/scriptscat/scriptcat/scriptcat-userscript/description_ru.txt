Писать, исправлять и отлаживать пользовательские скрипты для ScriptCat (совместимые с Tampermonkey): скрипты‑страницы, которые запускаются на совпадающих сайтах (@match), фоновые скрипты, которые продолжают работать без страницы (@background), и плановые скрипты (@crontab); метаданные, @grant и API GM_* / GM.* / CAT_*, пользовательские настройки, повторные попытки. Когда подключён CLI sctl, установить скрипт в ScriptCat пользователя и проверить его в реальном браузере. Использовать каждый раз, когда пользователь хочет пользовательский скрипт, 油猴脚本, 后台脚本, 定时脚本, файл .user.js или скрипт ScriptCat, написанный, изменённый или отлаженный. Не предназначено для разработки самого расширения ScriptCat и не для управления установленными скриптами без изменения их кода (это навык sctl).
