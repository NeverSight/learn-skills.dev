Scrivi, correggi e fai il debug di userscript per ScriptCat (compatibile con Tampermonkey): script di pagina che vengono eseguiti sui siti corrispondenti (@match), script in background che continuano a funzionare senza una pagina (@background) e script programmati (@crontab); metadata, @grant e le API GM_* / GM.* / CAT_*, configurazione utente, tentativi. Quando il CLI sctl è connesso, installa lo script nel ScriptCat dell'utente e verificalo nel loro vero browser. Usa ogni volta che l'utente desidera un userscript, 油猴脚本, 后台脚本, 定时脚本, un file .user.js o uno script ScriptCat scritto, modificato o debugato. Non è per sviluppare l'estensione ScriptCat stessa, né per gestire script installati senza modificare il loro codice (questa è la skill sctl).
