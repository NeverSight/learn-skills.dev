Verwenden, wenn man eine bestimmte Funktion des Legacy‑Systems KTHIS/eHealth (Eclipse RCP + SWT, Java 6 / GBK) zu WebHIS (React 18 + antd 4 + dva Frontend / Spring Boot 2.7 + MyBatis Backend) migriert, neu schreibt, portiert oder 1:1 reproduziert. Es deckt den gesamten Workflow ab: „End‑to‑End‑Verfolgung der Legacy‑Kette → Schicht‑für‑Schicht‑Abbildung und Implementierung der Backend‑webhis‑<mod>‑* APIs → Implementierung des Front‑Ends src/pages/<mod>/ Seiten, Dialoge, Modelle, Registrierungen, i18n → Zugriffskontroll‑Verifizierung.“ Verwenden Sie es, wann immer der Nutzer KTHIS, eHealth, Legacy‑/Altsystem, SWT, RCP, Eclipse‑Plug‑in, die Umsetzung nach Legacy‑Code erwähnt oder eine „aus dem alten System migrierte“ Seite/Dialog/API in webhis‑front / webhis‑server realisieren möchte – selbst wenn der Nutzer nicht ausdrücklich „Migration“ sagt.
