Utilizzato quando si migra, riscrive, porta o si riproduce 1:1 una specifica funzionalità del legacy KTHIS/eHealth (Eclipse RCP + SWT, Java 6 / GBK) su WebHIS (React 18 + antd 4 + dva front‑end / Spring Boot 2.7 + MyBatis back‑end). Copre l’intero flusso di lavoro: “tracciamento end‑to‑end della catena legacy → mappatura strato per strato e implementazione delle API back‑end webhis‑<mod>‑* → implementazione del front‑end src/pages/<mod>/ pagine, dialoghi, modelli, registrazioni, i18n → verifica del controllo degli accessi.” Usa questo ogni volta che l’utente menziona KTHIS, eHealth, un sistema legacy/vecchio, SWT, RCP, plugin Eclipse, implementazione basata su codice legacy, o ha bisogno di creare in webhis‑front/webhis‑server una pagina, un dialogo o un’API “migrata dal vecchio sistema” — anche se l’utente non dice esplicitamente “migrazione”. Rispondi sempre nella lingua dell’utente.
