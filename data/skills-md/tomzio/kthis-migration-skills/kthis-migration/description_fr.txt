Utilisez ceci lors de la migration, de la réécriture, du portage ou de la reproduction 1 : 1 d’une fonctionnalité du système hérité KTHIS/eHealth (Eclipse RCP + SWT, Java 6/GBK) vers WebHIS (React 18 + antd 4 + dva front‑end / Spring Boot 2.7 + MyBatis back‑end). Il couvre l’ensemble du processus de « tracing de bout en bout de la chaîne legacy → mappage couche par couche et implémentation des API back‑end webhis‑<mod>-* → implémentation du front‑end src/pages/<mod>/ pages, modaux, modèles, enregistrements, i18n → vérification du contrôle d’accès ». Utilisez‑le chaque fois que l’utilisateur mentionne KTHIS, eHealth, système legacy/ancien, SWT, RCP, plugins Eclipse, implémentation basée sur du code legacy, ou qu’il doit implémenter dans webhis‑front / webhis‑server une page, un modal ou une API « migrée depuis l’ancien système » — même si l’utilisateur ne dit pas explicitement « migration ».  

Veuillez toujours répondre dans la langue de l’utilisateur.
