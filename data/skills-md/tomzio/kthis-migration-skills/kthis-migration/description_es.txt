Se utiliza al migrar, reescribir, portar o restaurar 1:1 una característica específica del legado KTHIS/eHealth (Eclipse RCP + SWT, Java 6 / GBK) a WebHIS (React 18 + antd 4 + dva front‑end / Spring Boot 2.7 + MyBatis back‑end). Cubre todo el proceso de “trazado de extremo a extremo de la cadena legada → mapeo capa por capa e implementación de interfaces backend webhis‑<mod>-* → implementación del front‑end src/pages/<mod>/ páginas, diálogos, modelos, registro, i18n → verificación de control de acceso”. Use esto siempre que el usuario mencione KTHIS, eHealth, un sistema legado/antiguo, SWT, RCP, complementos de Eclipse, implementar según código legado, o quiera crear en webhis‑front / webhis‑server una página/diálogo/interface “migrada del sistema antiguo”, incluso si el usuario no dice explícitamente la palabra “migración”.
