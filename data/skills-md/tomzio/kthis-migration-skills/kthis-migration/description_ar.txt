استخدمه عند ترحيل أو إعادة كتابة أو تحويل أو استنساخ ميزة محددة من النظام القديم KTHIS/eHealth (Eclipse RCP + SWT، Java 6/GBK) إلى WebHIS (React 18 + antd 4 + dva للواجهة الأمامية / Spring Boot 2.7 + MyBatis للواجهة الخلفية). يغطي سير العمل الكامل: «تتبع من البداية إلى النهاية لسلسلة النظام القديم → تخطيط طبقة بط layer وتنفيذ واجهات الواجهة الخلفية webhis‑<mod>-* → تنفيذ صفحات الواجهة الأمامية src/pages/<mod>/، الحوارات، النماذج، التسجيلات، i18n → التحقق من التحكم في الوصول». استخدمه عندما يذكر المستخدم KTHIS أو eHealth أو النظام القديم/العتيق أو SWT أو RCP أو إضافة Eclipse أو تنفيذ وفقًا للكود القديم، أو يرغب في إضافة صفحة/حوار/واجهة “تم ترحيلها من النظام القديم” في webhis‑front/webhis‑server—حتى إذا لم يذكر المستخدم صراحة كلمة «ترحيل». يرجى دائمًا الرد بلغة المستخدم.
