全方位、框架無關的實用手冊，旨在交付超高速、可及、搜尋友好且視覺獨特的 Web 介面。結合 Lighthouse 專業知識（目標為行動裝置 95+、桌面 99+、可及性/最佳實踐/SEO 100 分），以及取自 Apple HIG 與 Material Design 的 UI/UX 模式，避免通用 AI 風格的設計美感，並提供關於效能、可及性、SEO、動畫、表單、布局與資料視覺化的深入指導。於建構、審核、重構或打磨任何 Web UI 時皆可使用，無論使用何種框架（原生 HTML/CSS/JS、React、Vue、Svelte、Astro、Solid、Next.js、Nuxt、SvelteKit、Remix、Qwik、Lit、Web Components）。可協助在字型排版、色彩、間距、動畫、對比、語意結構、資產載入、渲染策略、hydration、第三方腳本、圖像格式、字型載入、JS 預算、CSS 架構、ARIA、鍵盤流程、焦點管理、結構化資料、meta 標籤以及 Core Web Vitals 等決策上做出判斷。
