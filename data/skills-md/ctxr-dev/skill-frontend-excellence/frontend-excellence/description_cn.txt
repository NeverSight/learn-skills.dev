全方位、框架无关的实战指南，帮助交付超高速、可访问、搜索友好、视觉独特的网页界面。融合 Lighthouse 精通（目标：移动端 95+，桌面端 99+，可访问性/最佳实践/SEO 100），以及来自 Apple HIG 与 Material Design 的 UI/UX 模式，避免通用 AI 风格的设计美学，并提供关于性能、可访问性、SEO、动效、表单、布局和数据可视化的深入指导。无论使用何种框架（原生 HTML/CSS/JS、React、Vue、Svelte、Astro、Solid、Next.js、Nuxt、SvelteKit、Remix、Qwik、Lit、Web Components），在构建、审查、重构或打磨任何网页 UI 时都可采用。本指南可用于在排版、配色、间距、动效、对比度、语义结构、资源加载、渲染策略、hydration、第三方脚本、图像格式、字体加载、JavaScript 预算、CSS 架构、ARIA、键盘交互、焦点管理、结构化数据、元标签以及 Core Web Vitals 等方面做出决策。
