Guía integral, independiente del framework, para lanzar interfaces web ultra rápidas, accesibles, amigables con la búsqueda y visualmente distintivas. Combina el dominio de Lighthouse (objetivo 95+ móvil, 99+ escritorio, 100 A11y/BP/SEO), patrones UI/UX tomados del Apple HIG y Material Design, estéticas de diseño que evitan el estilo genérico de IA, además de una guía profunda sobre rendimiento, accesibilidad, SEO, animaciones, formularios, diseño y visualización de datos. Aplica esto al construir, revisar, refactorizar o pulir cualquier UI web sin importar el framework (HTML/CSS/JS puro, React, Vue, Svelte, Astro, Solid, Next.js, Nuxt, SvelteKit, Remix, Qwik, Lit, Web Components). Úsalo para tomar decisiones sobre tipografía, color, espaciado, animaciones, contraste, estructura semántica, carga de recursos, estrategia de renderizado, hidratación, scripts de terceros, formatos de imagen, carga de fuentes, presupuestos de JavaScript, arquitectura CSS, ARIA, flujos de teclado, gestión del foco, datos estructurados, metaetiquetas y Core Web Vitals.
