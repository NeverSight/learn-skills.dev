Guide holistique et indépendant de tout framework pour déployer des interfaces web ultra-rapides, accessibles, optimisées pour la recherche et visuellement distinctes. Combine une maîtrise de Lighthouse (cible 95+ mobile, 99+ desktop, 100 A11y/BP/SEO), des modèles UI/UX issus des directives Apple HIG et Material Design, une esthétique de conception qui évite les styles génériques d'IA, ainsi qu'une orientation approfondie sur la performance, l'accessibilité, le SEO, les animations, les formulaires, la mise en page et la visualisation de données. Appliquez-le lors de la création, de la révision, du refactoring ou du polishing de toute interface web, quel que soit le framework (HTML/CSS/JS pur, React, Vue, Svelte, Astro, Solid, Next.js, Nuxt, SvelteKit, Remix, Qwik, Lit, Web Components). Utilisez-le pour prendre des décisions concernant la typographie, les couleurs, les espacements, les animations, le contraste, la structure sémantique, le chargement des ressources, la stratégie de rendu, l'hydratation, les scripts tiers, les formats d'image, le chargement des polices, les budgets JavaScript, l'architecture CSS, les attributs ARIA, les flux clavier, la gestion du focus, les données structurées, les balises meta et les Core Web Vitals.
