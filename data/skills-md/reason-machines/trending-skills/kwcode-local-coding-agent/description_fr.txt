KWCode (天工开物) — un agent de codage en ligne de commande optimisé pour les modèles open‑source locaux (8 B‑30 B), proposant des pipelines experts déterministes, une localisation de code BM25+AST, du débogage à l’exécution et un moteur d’auto‑amélioration — le tout fonctionnant entièrement hors ligne.
