Generieren Sie KI-Personalisierungsaufforderungen für Kalt-E-Mail-Kampagnen. Liest die KI-Variablen aus einer Kampagnenstrategie und gibt detaillierte Eingabeaufforderungen aus, die Sie in jedem Personalisierungstool oder LLM ausführen können, um jede E-Mail an jeden potenziellen Kunden anzupassen. Verwenden Sie sie nach einer Kampagnenstrategie oder beim Erstellen von Eingabeaufforderungen für eine vorhandene Sequenz. Löst auf „Eingabeaufforderungen für diese Kampagne schreiben“, „Personalisierungsaufforderungen generieren“ aus.
