Создавайте подсказки для персонализации с помощью искусственного интеллекта для кампаний по холодной электронной почте. Считывает переменные ИИ из стратегии кампании и выводит подробные подсказки, которые вы можете запустить в любом инструменте персонализации или LLM, чтобы адаптировать каждое электронное письмо для каждого потенциального клиента. Используйте после стратегии кампании или при создании подсказок для существующей последовательности. Триггеры: «написать подсказки для этой кампании», «создать подсказки для персонализации».
