Intégrer, expliquer, examiner, auditer et dépanner les API d’édition Web du Meishe Streaming SDK dans des projets React/Vite, Vue/Vite ou des projets navigateur neutres vis-à-vis du cadre. Les utiliser pour le chargement du SDK/du runtime, les timelines, LiveWindow, les pistes, les clips, les sous‑titres, les autocollants, les effets, les transitions, les images‑clés, les modèles, les paquets d’actifs, le système de fichiers média, la lecture, la persistance, les vérifications de compatibilité et les défaillances du runtime. Utilisé pour intégrer, exploiter, examiner ou dépanner le SDK d’édition de flux média Meishe ainsi que ses processus d’édition, de gestion des médias et d’exécution dans les projets Web.
