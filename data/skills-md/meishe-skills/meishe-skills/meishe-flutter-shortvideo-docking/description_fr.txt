Intégrez, configurez, validez et dépannez de manière autonome le plugin officiel Meishe ShortVideo Flutter pour des projets Flutter Android‑only, iOS‑only ou multi‑plateforme. Utilisez‑le pour l’intégration d’une démo Flutter en boîte noire, la configuration Dart générée, la compatibilité du pont plateforme, la configuration des paquets/licences/serveur, les questions de configuration et les correctifs ciblés par version ; n’utilisez jamais React Native ou des paquets natifs uniquement comme substituts.

Veuillez toujours répondre dans la langue de l’utilisateur.
