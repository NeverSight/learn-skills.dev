قم بإنشاء وتعديل واستكشاف الأخطاء وإصلاحها وشرح تطبيقات أندرويد المستقلة باستخدام واجهات برمجة تطبيقات Meishe/美摄 Android Streaming SDK. استخدم ذلك عندما يطلب المستخدمون اكتشاف قدرات SDK/المهارة، الإعداد الأولي، التقاط الكاميرا المخصص على مستوى API في أندرويد، المعاينة، التسجيل، تحرير الخط الزمني، الصوت/الموسيقى، الفلاتر، الجمال، الماكياج، مشهد الواقع المعزز، شبكة الوجه، التقسيم، التسميات التوضيحية، الملصقات، تثبيت حزم الأصول، تأثيرات الواقع المعزز/الوجه التي تثبت أو تكشف الوجه ولكن تظل غير مرئية، تشخيص الترخيص/النموذج/الاستدعاءات للجهاز الفعلي، تحرير القطع المتشابه/القالب، التصدير/التجميع، أوزان أولوية API/الميزة، رسومات اعتماد الاعتمادية بين API والميزات، قيود API، الثوابت، قواعد المعاملات/الإرجاع، خرائط ترتيب الاستدعاءات، دمج Gradle، إعداد الترخيص/الأصول، أو إنشاء مشروع أندرويد مبني على قالب يصبح قابلاً للتنفيذ بعد إضافة قطع SDK المملوكة، استناداً إلى Markdown الرسمي المدمج من Doxygen بالإضافة إلى مقتطفات أندرويد مكتملة تجريبياً دون الحاجة إلى مجلدات SdkDemo أو doxygen الأصلية.
