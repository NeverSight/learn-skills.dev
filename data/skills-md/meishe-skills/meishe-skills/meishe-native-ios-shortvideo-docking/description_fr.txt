Intégrez, configurez, validez et dépannez de manière autonome le package iOS natif officiel Meishe ShortVideo dans un projet Xcode. Utilisez-le pour l'intégration en boîte noire des Pods‑NvShortVideoEdit, l’interface de démonstration Swift générée et la configuration des fonctionnalités, le paramétrage du Podfile et du Info.plist, les questions d’identifiant de bundle / licence / serveur, la génération de handoff et les correctifs iOS natifs spécifiques à chaque version ; ne remplacez jamais Flutter, React Native ou les packages Android.

Veuillez toujours répondre dans la langue de l'utilisateur.
