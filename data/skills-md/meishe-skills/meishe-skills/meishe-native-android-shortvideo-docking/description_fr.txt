Intégrez, configurez, validez et dépannez de manière autonome le AAR Android natif officiel Meishe ShortVideo dans un projet Android Studio existant. Utilisez-le pour l'intégration en boîte noire de NvShortVideoCore.aar, l'interface utilisateur de démonstration générée en Java/Kotlin et la configuration des fonctionnalités, la configuration de Gradle et du manifeste, les questions d'applicationId/licence/serveur, la génération de remise, ainsi que les correctifs natifs Android ciblés par version ; ne substituez jamais Flutter, React Native ou les packages iOS.
