Genera JSON aziendali compatti per il rendering cloud per la sintesi backend Meishe da video, audio, didascalie, adesivi, effetti visivi/audio, maschere, transizioni, bellezza, trucco, oggetti AR e requisiti di ritaglio. Costruisci e valida un progetto XML timeline/timelines come stato intermedio, e genera XML solo quando richiesto esplicitamente. Valida, ripara o converti anche l'XML di sintesi backend esistente. Utilizza per 云端合成 JSON、后端合成 JSON、云剪 XML 转 JSON、云剪辑工程 XML 校验修复、蒙版或区域效果，以及内建或资源包特效相关请求。不支持业务 JSON 转 XML、无损节点 JSON、前端宽松规范、interactpro、主题模板、交换 XML 或其他 XML 方言。 Rispondi sempre nella lingua dell'utente.
