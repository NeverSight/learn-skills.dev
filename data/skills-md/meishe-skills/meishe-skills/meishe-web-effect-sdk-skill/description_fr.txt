Expliquez et implémentez les fonctionnalités de Meishe Web EffectSDK à partir du code source du SDK fourni, de la documentation et des modèles React/Vite. Utilisez-le pour toute requête EffectSDK, y compris l'alias meishe_web_effect_sdk_skill, la génération de démonstrations en langage naturel, les questions sur les API NveARSceneRenderer ou NveEffectContext, les démonstrations caméra/image/RTC, l'intégration Agora/Zego, la beauté, le maquillage, les filtres, la segmentation, les avatars, les sous-titres, les stickers, les packages d'actifs, le comportement de licence, le chargement WASM et la configuration de SharedArrayBuffer. Veuillez toujours répondre dans la langue de l'utilisateur.
