اشرح ونفّذ ميزات Meishe Web EffectSDK من مصدر SDK المضمّن، الوثائق، وقوالب React/Vite. استخدم لأي طلب يتعلق بـ EffectSDK، بما في ذلك الاسم المستعار meishe_web_effect_sdk_skill، إنشاء العروض التوضيحية باستخدام اللغة الطبيعية، أسئلة حول NveARSceneRenderer أو NveEffectContext API، عروض الكاميرا/الصورة/RTC، تكامل Agora/Zego، الجمال، المكياج، الفلاتر، التقسيم، الأفاتار، التسمية التوضيحية، الملصقات، حزم الأصول، سلوك الترخيص، تحميل WASM، وإعداد SharedArrayBuffer.
