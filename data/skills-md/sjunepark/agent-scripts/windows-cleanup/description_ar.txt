تشخيص سبب بطء جهاز كمبيوتر يعمل بنظام Windows والحذر في استرجاع مساحة التخزين أو تقليل التحميل غير الضروري عند بدء التشغيل والخلفية باستخدام أدوات Windows المدعومة. استدعاء صريح فقط؛ يُستخدم عندما يذكر المستخدم $windows-cleanup لتبطؤ Windows 11 أو Windows 10 القديم، انخفاض مساحة القرص النظامي، إقلاع أو تسجيل دخول بطيء، نشاط خلفي عالٍ، أو فحص وتنظيف الملفات المؤقتة، تطبيقات بدء التشغيل، التطبيقات غير المستخدمة، الملفات السحابية-المحلية، مكونات التحديث، أو الأقراص. لا يُستخدم لتحسين السجل، إزالة البرامج غير الضرورية بشكل واسع، تعزيز الخصوصية، الاستجابة النشطة لحوادث البرامج الضارة، إصلاح الأجهزة، استعادة الإقلاع، أو إعادة ضبط Windows وإعادة تثبيتها. 

يرجى دائمًا الرد بلغة المستخدم.
