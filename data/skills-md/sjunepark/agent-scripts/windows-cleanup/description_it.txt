Diagnostica le cause per cui un PC Windows sembra più lento e recupera cautamente spazio o riduci il carico evitabile all’avvio e in background con gli strumenti Windows supportati. Invocazione esplicita soltanto; usalo quando l’utente indica $windows‑cleanup per rallentamenti su Windows 11 o Windows 10 legacy, spazio insufficiente sul disco di sistema, avvio o accesso lenti, elevata attività in background, o per l’ispezione e la pulizia di file temporanei, app all’avvio, app inutilizzate, file cloud‑locali, componenti di aggiornamento o unità. Non usarlo per l’ottimizzazione del registro, il debloating generale, il rafforzamento della privacy, la risposta a incidenti malware attivi, la riparazione hardware, il recupero del boot o il reset e la reinstallazione di Windows.

Rispondi sempre nella lingua dell’utente.
