안전한 출력 처리, 한국어 스캔 OCR, 페이지 마커, 유효성 검사 및 레이아웃 에스컬레이션 기능을 갖춘 Xberg를 사용하여 PDF 입력을 에이전트, LLM 수집, 검색 또는 보관 텍스트를 위한 깨끗하고 재사용 가능한 전체 문서 마크다운으로 변환합니다. 사용자가 PDF에서 Markdown 또는 전체 문서 에이전트가 읽을 수 있는 텍스트 아티팩트를 생성, 저장, 생성, 정규화, 재변환 또는 추출하도록 요청할 때 사용합니다. 변환된 아티팩트가 없는 요약이나 질문, PDF 편집 또는 렌더링, 파서 연구 또는 CSV, JSON, 이미지 또는 기타 구조화된 형식으로의 대상 추출이 없는 경우에는 사용하지 마십시오.
