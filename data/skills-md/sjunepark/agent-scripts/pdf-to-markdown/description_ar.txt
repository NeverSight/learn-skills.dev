تحويل مدخلات PDF إلى مستند كامل نظيف وقابل لإعادة الاستخدام Markdown للوكلاء، أو استيعاب LLM، أو البحث، أو النص الأرشيفي، باستخدام Xberg مع معالجة آمنة للمخرجات، والمسح الضوئي الكوري OCR، وعلامات الصفحة، والتحقق من الصحة، وتصعيد التخطيط. يُستخدم عندما يطلب المستخدم إنشاء أو حفظ أو إنشاء أو تطبيع أو إعادة تحويل أو استخراج Markdown أو نص نصي قابل للقراءة من قبل وكيل المستند بالكامل من ملف PDF. لا تستخدم للملخصات أو الأسئلة التي لا تحتوي على أي عناصر محولة، أو تحرير PDF أو عرضه، أو البحث المحلل، أو الاستخراج المستهدف إلى CSV، أو JSON، أو الصور، أو التنسيقات المنظمة الأخرى.
