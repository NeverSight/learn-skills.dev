Convierta entradas de PDF en Markdown de documentos completos limpio y reutilizable para agentes, ingesta de LLM, búsqueda o texto de archivo, utilizando Xberg con manejo de salida seguro, OCR de escaneo coreano, marcadores de página, validación y escalamiento de diseño. Úselo cuando el usuario solicite crear, guardar, generar, normalizar, reconvertir o extraer un artefacto de texto Markdown o de documento completo legible por el agente de un PDF. No lo utilice para resúmenes o preguntas sin artefactos convertidos, edición o renderizado de PDF, investigación con analizador o extracción dirigida a CSV, JSON, imágenes u otros formatos estructurados.
