Converti input PDF in Markdown di documenti interi puliti e riutilizzabili per agenti, acquisizione LLM, ricerca o testo di archivio, utilizzando Xberg con gestione sicura dell'output, OCR di scansione coreano, marcatori di pagina, convalida ed escalation del layout. Da utilizzare quando l'utente richiede di creare, salvare, generare, normalizzare, riconvertire o estrarre un elemento di testo leggibile dall'agente Markdown o dell'intero documento da un PDF. Non utilizzare per riepiloghi o domande senza artefatti convertiti, modifica o rendering di PDF, ricerca parser o estrazione mirata in CSV, JSON, immagini o altri formati strutturati.
