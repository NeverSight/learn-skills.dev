Cambie el árbol de trabajo de Git actual de una rama de funciones a su rama base o de integración prevista y avance rápidamente esa rama local a su punta remota configurada. Úselo cuando el usuario solicite abandonar el trabajo de la función actual y actualizar, actualizar o pasar a la última rama principal de desarrollo, principal, troncal o específica del árbol de trabajo. No lo use para fusionar o cambiar la base de una rama base en una rama de características, reescribir el historial divergente o actualizar un árbol de trabajo diferente.
