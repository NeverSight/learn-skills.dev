Cambia l'albero di lavoro Git corrente da un ramo di funzionalità al ramo di base o di integrazione previsto e fai avanzare rapidamente quel ramo locale al suggerimento remoto configurato. Da utilizzare quando l'utente chiede di lasciare in funzione la funzionalità corrente e aggiornare, aggiornare o passare all'ultimo ramo primario dev, principale, trunk o specifico dell'albero di lavoro. Non utilizzare per unire o riorganizzare un ramo di base in un ramo di funzionalità, riscrivere la cronologia divergente o aggiornare un albero di lavoro diverso.
