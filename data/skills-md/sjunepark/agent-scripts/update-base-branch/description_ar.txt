قم بتبديل شجرة عمل Git الحالية من فرع الميزات إلى فرع القاعدة أو فرع التكامل المقصود ثم قم بتمرير هذا الفرع المحلي بسرعة إلى طرفه البعيد الذي تم تكوينه. يتم استخدامه عندما يطلب المستخدم ترك عمل الميزة الحالية والتحديث أو التحديث أو الانتقال إلى أحدث فرع رئيسي خاص بالمطور أو الرئيسي أو قناة الاتصال أو شجرة العمل. لا تستخدم لدمج فرع أساسي أو إعادة تأسيسه في فرع ميزات، أو إعادة كتابة سجل متباين، أو تحديث شجرة عمل مختلفة.
