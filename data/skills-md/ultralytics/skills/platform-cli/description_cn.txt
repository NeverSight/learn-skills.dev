在终端或脚本中使用 ul cloud CLI（ul cloud RESOURCE OPERATION key=value，PyPI 包 ultralytics-platform）操作 Ultralytics 平台时使用——列出、创建、更新、克隆或移动项目、数据集和模型；检查数据集图像、统计信息、元数据、重复项和相似图像；启动和监控云训练任务；进行每张图像的模型验证分析；下载权重、导出文件、部署文件，执行上传、删除、恢复，管理存储集成以及查看账户使用情况、存储和计费。平台的 Web UI 或本地 yolo 命令请参考 yolo；关于选择训练内容及改进方法，请参见 yolo-training 和 yolo-tuning。
