ターミナルやスクリプトで ul cloud CLI（ul cloud RESOURCE OPERATION key=value、PyPI パッケージ ultralytics-platform）を使用して Ultralytics Platform を操作する際に使用します――プロジェクト、データセット、モデルの一覧表示、作成、更新、クローン作成、移動；データセット画像、統計、メタデータ、重複画像、類似画像の検査；クラウドトレーニング実行の開始とモニタリング；画像単位のモデル検証分析；重み、エクスポート、デプロイ、アップロード、ゴミ箱からの復元、ストレージ統合、アカウントの使用状況、ストレージ、請求のダウンロード。Platform の Web UI やローカル yolo コマンドについては yolo を参照してください；何をトレーニングし、どのように改善するかについては yolo‑training と yolo‑tuning を参照してください。
