Utilice cuando opere Ultralytics Platform desde una terminal o script con el CLI ul cloud (ul cloud RECURSO OPERACIÓN clave=valor, paquete PyPI ultralytics‑platform) — listando, creando, actualizando, clonando o moviendo proyectos, conjuntos de datos y modelos; inspeccionando imágenes del conjunto de datos, estadísticas, metadatos, duplicados e imágenes similares; iniciando y monitoreando ejecuciones de entrenamiento en la nube; análisis de validación de modelo por imagen; descargando pesos, exportaciones, implementaciones, cargas, papelera y restauración, integraciones de almacenamiento, y uso de cuenta, almacenamiento y facturación. Para la interfaz web de la Plataforma o comandos locales de yolo, vea yolo; para elegir qué entrenar y cómo mejorarlo, vea yolo‑training y yolo‑tuning.
