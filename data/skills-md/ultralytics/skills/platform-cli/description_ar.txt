استخدمها عند تشغيل منصة Ultralytics من خلال الطرفية أو سكريبت باستخدام ul cloud CLI (ul cloud RESOURCE OPERATION key=value، حزمة PyPI ultralytics‑platform) — سرد، إنشاء، تحديث، استنساخ، أو نقل المشروعات، مجموعات البيانات، والنماذج؛ فحص صور مجموعة البيانات، الإحصاءات، البيانات الوصفية، التكرارات، والصور المماثلة؛ بدء ومراقبة جلسات التدريب السحابية؛ تحليل التحقق من النموذج لكل صورة؛ تنزيل الأوزان، الصادرات، النشر، التحميلات، سلة المحذوفات والاستعادة، تكاملات التخزين، واستخدام الحساب، التخزين، والفوترة. بالنسبة لواجهة الويب للمنصة أو أوامر yolo المحلية، راجع yolo؛ لاختيار ما يجب تدريبه وكيفية تحسينه، راجع yolo‑training وyolo‑tuning.
