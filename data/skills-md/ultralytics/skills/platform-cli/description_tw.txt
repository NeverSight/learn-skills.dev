在終端或腳本中使用 Ultralytics 平台的 ul cloud CLI（ul cloud RESOURCE OPERATION key=value，PyPI 套件 ultralytics-platform）時使用 —— 列出、建立、更新、克隆或移動專案、資料集與模型；檢查資料集影像、統計資訊、元資料、重複項與相似影像；啟動與監控雲端訓練執行；進行每張影像的模型驗證分析；下載權重、匯出檔案、部署、上傳、回收站與還原、儲存整合，以及帳戶使用、儲存與計費。關於平台 Web UI 或本機 yolo 指令，請參考 yolo；如欲選擇訓練內容及如何改進，請參考 yolo‑training 與 yolo‑tuning。
