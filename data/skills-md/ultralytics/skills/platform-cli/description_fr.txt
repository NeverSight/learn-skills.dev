Utilisez‑le lorsque vous exploitez la plateforme Ultralytics depuis un terminal ou un script avec le CLI ul cloud (ul cloud RESOURCE OPERATION key=value, paquet PyPI ultralytics‑platform) — répertorier, créer, mettre à jour, cloner ou déplacer des projets, des jeux de données et des modèles ; inspecter les images de jeux de données, les statistiques, les métadonnées, les doublons et les images similaires ; démarrer et surveiller les entraînements dans le cloud ; analyser la validation du modèle image par image ; télécharger les poids, les exportations, les déploiements, les téléversements, la corbeille et la restauration, les intégrations de stockage, ainsi que l’utilisation du compte, le stockage et la facturation. Pour l’interface web de la plateforme ou les commandes yolo locales, voir yolo ; pour choisir ce qu’il faut entraîner et comment l’améliorer, voir yolo‑training et yolo‑tuning.
