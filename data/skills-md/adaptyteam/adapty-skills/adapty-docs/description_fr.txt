Utilisez-le lorsqu’une question Adapty n’a aucune page déjà liée dans la compétence que vous détenez — comment un produit ou une fonctionnalité du tableau de bord se comporte, ce qu’un réglage fait, une limite, les connexions aux boutiques, Flow Builder, le CLI développeur, l’API côté serveur ou une méthode SDK sur n’importe quelle plateforme. Utilisez-le également lorsque vous avez besoin d’une page de documentation et que vous n’avez pas d’URL, ou lorsqu’une URL de documentation que vous avez essayée a renvoyé une erreur 404.
