Úsalo al crear, generar o revisar la UI de un sitio web, aplicación web o aplicación móvil para que parezca diseñada intencionalmente en lugar de generada por IA. Elimina los “tells” comunes de IA/plantilla (fuentes predeterminadas como Inter/Geist, degradados índigo y azul púrpura, fondos crema, texto gris de bajo contraste, pill/eyebrow sobre héroes, cuadrículas de icono‑tarjetas, tarjetas predeterminadas de shadcn, guiones largos, titulares forzados/u orfandad, todo con efecto de fade‑up, iconos generados por modelo, imágenes faltantes, componentes inconsistentes, menús móviles ausentes) y aplica una dirección de estilo visual elegida. El catálogo completo está en TELLS.md.
