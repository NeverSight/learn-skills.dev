Diagnostica y mejora el rendimiento del software mediante líneas de base de usuario/sistema, medición, perfilado, benchmarks representativos, cambios controlados y verificación antes/después. Úsalo para latencia, rendimiento, tiempo de arranque, eficiencia de memoria/CPU/IO, rutas críticas, margen de escalado o compensaciones de capacidad/costo. No optimices de forma especulativa; mide el síntoma real antes de elegir una técnica.
