CodeRabbit CLI のローカルコードレビューと .coderabbit.yaml の設定。プッシュや PR を作成する前に、未コミット・コミット済みの変更に対して AI レビューを実行し、--agent の検出結果を解析し、時間あたりのレート制限内で修正と検証のループを繰り返し、低ノイズ・高シグナルなレビューのためにリポジトリ設定を調整します。ローカル変更のプッシュ前／PR 前のレビュー、coderabbit/cr CLI のインストールや操作、.coderabbit.yaml の作成・調整、または CodeRabbit のレビュー雑音の削減に使用してください。PR 側のレビュー・ループやスレッド処理（git‑pr）、コミット（git‑commit）、CI ステータス（git‑ci）には使用しません。
