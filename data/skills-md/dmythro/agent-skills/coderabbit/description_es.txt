Revisiones de código locales con CodeRabbit CLI y configuración .coderabbit.yaml. Ejecuta revisiones de IA en cambios no confirmados/confirmados antes de hacer push o abrir un PR, analiza los hallazgos de --agent, itera bucles de corregir y verificar dentro de los límites de tarifa horaria y ajusta la configuración del repositorio para revisiones de bajo ruido y alta señal. Úsalo al revisar cambios locales pre‑push/pre‑PR, al instalar o manejar el CLI coderabbit/cr, al crear o afinar .coderabbit.yaml, o al reducir el ruido de revisión de CodeRabbit. No es para bucles de revisión del lado del PR y manejo de hilos (git‑pr), commits (git‑commit) o estado de CI (git‑ci).
