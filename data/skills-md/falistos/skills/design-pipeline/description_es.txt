Diseñar o rediseñar una interfaz de usuario a partir de una idea inicial: direcciones artísticas con nombre para elegir, fijadas en un archivo DESIGN.md, y luego desarrolladas y revisadas. Úsalo para «je veux designer une app de X», «propose-moi des directions», «design me a dashboard», «refais cette page». Web, escritorio, móvil. Para revisar una interfaz de usuario existente sin diseñar, usa `web-design-guidelines`.
