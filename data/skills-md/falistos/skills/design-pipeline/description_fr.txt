Concevoir ou repenser une interface utilisateur à partir d’une idée générale : des directions artistiques nommées parmi lesquelles choisir, consignées dans un fichier DESIGN.md, puis concrétisées et examinées. À utiliser pour « Je veux concevoir une application de X », « Propose-moi des orientations », « Conçois-moi un tableau de bord », « Refais cette page ». Web, ordinateur de bureau, mobile. L'examen d'une interface utilisateur existante sans conception correspond à `web-design-guidelines`.
