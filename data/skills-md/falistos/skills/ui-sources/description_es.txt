Obtén componentes de interfaz de usuario reales, registros de shadcn, kits de interfaz de IA/agentes, herramientas de sombreado y movimiento, tokens de diseño y sistemas de diseño públicos en lugar de inventarlos. Úselo cuando una interfaz de usuario necesite un componente concreto (menú de comandos, tabla de datos, número animado, fondo degradado), cuando elija una biblioteca o un sistema de diseño, cuando se pregunte «¿De dónde saco esto?» o cuando cree una interfaz de agente (chat, llamadas a herramientas, aprobaciones, voz). La crítica y el perfeccionamiento son «impecables».
