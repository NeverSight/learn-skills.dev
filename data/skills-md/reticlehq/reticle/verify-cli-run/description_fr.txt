Montrez qu’un outil en ligne de commande a réellement fait ce qu’il promettait, au lieu de vous fier à son code de sortie et à son affichage. Prenez un instantané du système de fichiers avant et après, nommez la conséquence attendue à l’avance, et renvoyez l’un des quatre verdicts en précisant ce qui n’a pas pu être vu. Utilisez‑le après avoir exécuté une compilation, une migration, un générateur de squelette, un formateur, une étape de génération de code ou un CLI de codage IA ; lorsque une commande a affiché « success » et que vous êtes sur le point d’annoncer « done » ; lorsque vous êtes sur le point d’écrire « code de sortie 0, donc ça a fonctionné » ; ou lorsqu’un outil prétend avoir modifié des fichiers. Aucun logiciel supplémentaire n’est requis.
