Prouver qu’un outil en ligne de commande a réellement fait ce qu’il prétend, au lieu de se fier à son code de sortie et à sa sortie. Il prend des instantanés du système de fichiers avant et après, nomme la conséquence attendue à l’avance, et renvoie l’un des quatre verdicts avec ce qui n’a pas pu être vu. À utiliser après l’exécution d’une compilation, d’une migration, d’un générateur de squelette, d’un formateur, d’une étape de génération de code ou d’une CLI de codage IA ; lorsqu’une commande a affiché « success » et que vous êtes sur le point de signaler « terminé » ; lorsque vous êtes sur le point d’écrire « code de sortie 0, donc ça a fonctionné » ; ou lorsqu’un outil prétend avoir modifié des fichiers. Aucun logiciel n’est requis.
