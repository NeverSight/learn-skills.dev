Навыки анализа и улучшения с точки зрения третьей стороны для маркетинговых страниц. Целевая аудитория: целевые страницы, домашние страницы, страницы с ценами, страницы функций, блоги. Интегрирует CRO‑рамку с принципами прямого отклика (Шварц/Хопкинс/Огилви). Время использования: (1) запрос аудита/анализа страницы, (2) консультация по повышению конверсии, (3) улучшение копирайтинга, (4) разработка A/B‑теста, (5) приоритизация внедрения. Примеры триггеров: «Проанализировать LP», «Хочу повысить коэффициент конверсии», «Проверить страницу с ценами», «Улучшить hero‑секцию», «Оптимизировать CTA», «Предложить улучшения для домашней страницы».
