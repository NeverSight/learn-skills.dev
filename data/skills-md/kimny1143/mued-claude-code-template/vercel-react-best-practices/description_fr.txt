Directives d'optimisation des performances de React et Next.js provenant de Vercel Engineering. Cette compétence doit être utilisée lors de l'écriture, la révision ou la refonte de code React/Next.js afin d'assurer des schémas de performance optimaux. Elle se déclenche sur les tâches impliquant des composants React, des pages Next.js, la récupération de données, l'optimisation des bundles ou les améliorations de performances.
