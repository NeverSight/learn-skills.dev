Gleichzeitige Arbeit an mehreren Branches mit Git worktree verwalten.  
Anwendungsfälle:  
1. Wenn Sie mehrere Features parallel entwickeln möchten,  
2. Wenn Sie andere Aufgaben erledigen möchten, während ein PR geprüft wird,  
3. Wenn Sie gleichzeitig an einem Produktions‑Hotfix und an der Entwicklung arbeiten möchten,  
4. Wenn Sie lernen möchten, wie man worktree benutzt.  
Trigger‑Beispiele: “mit worktree,” “mehrere Branches gleichzeitig,” “parallele Entwicklung,” “Entwicklung während der PR‑Überprüfung,” “worktree für Hotfix.”
