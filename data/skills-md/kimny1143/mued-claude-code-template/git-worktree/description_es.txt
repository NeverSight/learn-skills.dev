Manejo simultáneo de trabajo en múltiples ramas usando Git worktree.

Cuándo usar:
1. Cuando quieres desarrollar múltiples funcionalidades en paralelo.
2. Cuando necesitas trabajar en otra cosa mientras una revisión de PR está en curso.
3. Cuando deseas gestionar correcciones urgentes en producción y desarrollo continuo al mismo tiempo.
4. Cuando quieres aprender a usar worktree.

Ejemplos de disparadores:
- “con worktree”
- “múltiples ramas al mismo tiempo”
- “desarrollo en paralelo”
- “desarrollar mientras se revisa PR”
- “worktree para hotfix”
