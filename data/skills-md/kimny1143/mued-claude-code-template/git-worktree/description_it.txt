Gestire lavoro simultaneo su più rami usando Git worktree.  
Quando usarlo:  
1. Quando vuoi sviluppare diverse funzionalità in parallelo.  
2. Quando devi lavorare su qualcos'altro mentre una PR è in revisione.  
3. Quando vuoi gestire un hot‑fix di produzione e lo sviluppo continuo allo stesso tempo.  
4. Quando vuoi imparare a usare worktree.  

Esempi di trigger: “con worktree”, “più rami simultaneamente”, “sviluppo parallelo”, “sviluppare mentre la PR è in revisione”, “worktree per hotfix”.
