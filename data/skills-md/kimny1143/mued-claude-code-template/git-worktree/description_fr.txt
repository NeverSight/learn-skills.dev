Gestion du travail simultané sur plusieurs branches à l’aide de Git worktree.  
Quand l’utiliser : (1) Lorsque vous souhaitez développer plusieurs fonctionnalités en parallèle (2) Lorsque vous voulez travailler sur autre chose tout en examinant une PR (3) Lorsque vous devez gérer des correctifs de production et le développement en même temps (4) Lorsque vous voulez apprendre à utiliser worktree.  
Exemples de déclencheurs : « avec worktree », « branches différentes en même temps », « développement parallèle », « développer tout en examinant une PR », « worktree pour correctifs ».
