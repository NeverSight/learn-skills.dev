Управление одновременной работой над несколькими ветками с помощью Git worktree.

Когда использовать:
1. Когда хотите параллельно разрабатывать несколько функций.
2. Когда нужно выполнять другую работу, пока идёт обзор PR.
3. Когда хотите одновременно заниматься горячими исправлениями в продакшене и обычной разработкой.
4. Когда хотите научиться пользоваться worktree.

Примеры запросов:
- «с worktree»
- «одновременно несколько веток»
- «нужна параллельная разработка»
- «разрабатывать, пока проверяется PR»
- «worktree для хотфикса»
