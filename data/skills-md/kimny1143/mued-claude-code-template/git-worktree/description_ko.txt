Git worktree를 사용한 다중 브랜치 동시 작업 관리.

사용 시기:
1. 여러 기능을 병렬로 개발하고 싶을 때.
2. PR 검토가 진행되는 동안 다른 작업을 하고 싶을 때.
3. 프로덕션 핫픽스와 개발을 동시에 처리하고 싶을 때.
4. worktree 사용법을 배우고 싶을 때.

예시 트리거:
- "with worktree"
- "simultaneously on another branch"
- "want parallel development"
- "development while reviewing a PR"
- "worktree for hotfix"
