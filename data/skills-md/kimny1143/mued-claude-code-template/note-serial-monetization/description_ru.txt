Навык разработки стратегии сегментации платных/бесплатных эпизодов для серийных статей на Note. Он охватывает распределение бесплатных и платных эпизодов по всей серии, проектирование платной линии внутри отдельной статьи, установку цен и структурирование журналов. Время использования: (1) Когда хотите написать платную статью на Note, (2) Проектирование монетизации серии, (3) Определение места размещения платной линии, (4) Учёт состава журналов, (5) Консультация по ценообразованию. Примеры триггеров: «Хочу сделать платным на Note», «Проектирование монетизации серии», «С какого места сделать платным?», «Хочу зарабатывать на Note», «Как должна быть структурирована журнал», «Платная линия», «Ценообразование». Может использоваться совместно с навыком ai-interview-article.
