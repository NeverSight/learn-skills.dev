أفضل الممارسات لـ React Native و Expo لبناء تطبيقات هاتفية ذات أداء عالي. استخدمها عند بناء مكونات React Native، تحسين أداء القوائم، تنفيذ الرسوم المتحركة، أو العمل مع الوحدات الأصلية. تُفعَّل عند المهام المتعلقة بـ React Native، Expo، أداء الهاتف المحمول، أو واجهات برمجة التطبيقات الخاصة بالمنصات الأصلية.
