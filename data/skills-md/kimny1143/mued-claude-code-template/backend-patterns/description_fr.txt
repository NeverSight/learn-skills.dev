Conventions de code backend et collection de modèles. Modèles d'implémentation pour les routes API, les dépôts, la validation, etc. Situations d'utilisation : (1) Lors de la création d'une nouvelle route API (2) Lors de l'implémentation d'un dépôt (3) Lors de la conception de la validation (4) Lors de la mise en place de la gestion des erreurs (5) Lors de la vérification des meilleures pratiques backend. Exemples de déclencheurs : « Créer une route API », « Utiliser le pattern repository », « Patterns backend », « Validation avec Zod », « Pattern de gestion des erreurs ».
