Конвенции кода бекенда и сборник шаблонов. Шаблоны реализации для API‑маршрутов, репозиториев, валидации и т.д. Случаи применения: (1) при создании нового API‑маршрута (2) при реализации репозитория (3) при разработке валидации (4) при реализации обработки ошибок (5) при обзоре лучших практик бекенда. Примеры триггеров: «Создать API‑маршрут», «Использовать шаблон репозитория», «Шаблоны бекенда», «Валидация с Zod», «Шаблон обработки ошибок».
