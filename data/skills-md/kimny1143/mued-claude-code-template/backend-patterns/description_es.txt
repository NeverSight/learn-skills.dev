Convenciones de código de back-end y colección de patrones. Patrones de implementación para rutas API, repositorios, validación, etc. Tiempo de uso: (1) al crear una nueva ruta API (2) al implementar un repositorio (3) al diseñar la validación (4) al implementar el manejo de errores (5) al revisar las mejores prácticas de backend. Ejemplos de activación: "Crear una ruta API", "Usar el patrón de repositorio", "Patrón de backend", "Validación con Zod", "Patrón de manejo de errores".
