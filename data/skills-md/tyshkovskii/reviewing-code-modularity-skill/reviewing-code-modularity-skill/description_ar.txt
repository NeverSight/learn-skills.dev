استخدمه عند مراجعة أو تعديل بنية الكود لجعل قاعدة الشيفرة أسهل للفهم، والتغيير، والاختبار، أو الحذف — بما في ذلك عندما لا يستخدم المستخدم مصطلحات بنيوية، مثل "هذا الملف يفعل الكثير"، "هذا صعب الاختبار"، "أستمر في تعديل نفس الشيء في أماكن متعددة"، أو "هذا فوضى". يغطي حدود الوحدات، تقسيم الملفات، واجهات برمجة التطبيقات/الصادرات العامة، اتجاه الاعتماديات، الترابط/التماسك، الطبقات الضحلة، التجريد المفرط، القرارات البنيوية المكررة، المعالجات/المكونات الصعبة الاختبار، توزيع خرائط الأخطاء، وإعادة الهيكلة التي تنقل الشيفرة بين الوحدات. لا تستخدمه لإصلاحات الأخطاء العادية، أو التنسيق، أو التنظيف المتعلق بالأسماء فقط، أو التعديلات المحلية التي لا تؤثر على البنية.
