Workflow d'ingénierie rigoureux, axé sur la délégation. À utiliser pour /bigbrain suivi d'une fonctionnalité, d'une correction de bug, d'un refactor, d'une tâche, d'un plan, d'une explication du code (comment/pourquoi), d'une revue de PR guidée pour un humain ou une critique, d'une idée à examiner, d'une configuration, d'un suivi de PR ou d'un CV. Accepte du texte libre, un ticket GitHub ou une page Notion.
