Esegui una flotta autonoma e inattiva che implementa in modo autonomo il backlog di issue GitHub pronte di un repository — inviando worker isolati per worktree, facendo passare ciascuno attraverso il CI e auto‑unendo le PR verdi finché non viene interrotta. Usala quando l'utente vuole andare AFK sulle issue («lancia i worker per le issue», «avvia la flotta», orchestrare agenti contro le issue GitHub con orca), o richiede una delle sue modalità: --plan (dry‑run), --tick (passata singola), --takeover (ereditare le rivendicazioni di una flotta morta). Un’altra skill può invocarla per gestire un backlog già scomposto. NON è destinata a scomporre un PRD/epic in issue, a implementare manualmente una singola issue nominata o a revisionare una PR.
