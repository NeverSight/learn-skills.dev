تشغيل أسطول غير مراقب وثابت ينفّذ تلقائيًا قائمة انتظار مشكلات الـ GitHub الجاهزة في المستودع — يُرسل عمالًا منعزلين عن شجرة العمل، يضع كلًّا منهم تحت مراقبة CI، ويُدمج طلبات السحب الخضراء تلقائيًا حتى يتم إيقافه. يُستخدم عندما يرغب المستخدم في الخروج من الواجهة ("إطلاق عمال للقيام بالمشكلات"، "تشغيل الأسطول"، تنظيم الوكلاء ضد مشكلات GitHub باستخدام orca)، أو يطلب أحد أوضاعه: --plan (تشغيل تجريبي)، --tick (تمرير واحد)، --takeover (توريث مطالبات أسطول ميت). يمكن لمهارة أخرى أن تستدعيه لتجهيز قائمة انتظار تم تفكيكها مسبقًا. ليس لتفكيك PRD/epic إلى مشكلات، أو تنفيذ مشكلة مسماة يدويًا، أو مراجعة طلب سحب.
