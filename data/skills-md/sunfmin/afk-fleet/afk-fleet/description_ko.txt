자동으로 레포의 준비된 GitHub 이슈 백로그를 수행하는 무인 상시 플릿을 실행합니다 — 워크트리 격리 작업자를 파견하고, 각 작업을 CI에서 게이트하며, 초록색 PR을 자동으로 병합합니다. 사용자는 이슈에 대해 AFK 상태가 되고 싶을 때(예: “이슈를 수행할 작업자를 실행”, “플릿을 가동”, orca로 GitHub 이슈에 대한 에이전트를 조율) 또는 다음 모드 중 하나를 요청할 때 사용합니다: --plan (드라이런), --tick (단일 실행), --takeover (죽은 플릿의 청구를 상속). 다른 스킬이 이미 분해된 백로그에 인력을 배치하기 위해 이를 호출할 수 있습니다. PRD/에픽을 이슈로 분해하거나, 단일 명명된 이슈를 수동으로 구현하거나, PR을 검토하는 데는 사용하지 않습니다.
