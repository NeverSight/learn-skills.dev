Ejecuta una flota desatendida y permanente que implementa de forma autónoma el backlog de issues listos de un repositorio en GitHub — despachando workers aislados por worktree, evaluando cada uno en CI y auto‑mezclando PR verdes hasta que se detenga. Úsalo cuando el usuario quiere quedar AFK con los issues ("lanzar workers para hacer los issues", "ejecutar la flota", orquestar agentes contra issues de GitHub con orca), o solicita uno de sus modos: --plan (dry‑run), --tick (pasada única), --takeover (heredar las reclamaciones de una flota inactiva). Otra skill puede invocarlo para dotar de personal un backlog ya descompuesto. NO es para descomponer un PRD/épica en issues, implementar manualmente un issue nombrado o revisar un PR.
