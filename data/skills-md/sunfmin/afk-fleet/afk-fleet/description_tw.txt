運行一個無人值守、持續運作的艦隊，能自動執行儲存庫中已備妥的 GitHub Issue 待辦清單——派遣工作樹隔離的工作者，在 CI 上對每個工作設置門檻，並自動合併通過的 PR，直至停止。當使用者想要在 Issue 上 AFK（「啟動工作者來完成 Issue」、「運行艦隊」），或以 orca 對 GitHub Issue 進行代理編排，或要求以下模式之一時使用：--plan（乾跑）、--tick（單次執行）、--takeover（接管已死亡艦隊的請求）。其他技能可呼叫它為已分解好的待辦清單配備人力。**不** 用於將 PRD/epic 分解為 Issue、手動實作單一具名 Issue，或審核 PR。
