قبل تنفيذ وحدة أو حزمة أو فئة أو API أو سطر أوامر جديد، قم برسم تصميمين أو ثلاثة واجهات مختلفة جذريًا، قارن بينها، واختر أو دمج الأفضل (مفهوم أوسترهاوت "صممها مرتين"). يُستخدم عندما يكون المستخدم على وشك كتابة وحدة أو حزمة جديدة من الصفر ويريد مساعدة في تصميم واجهتها أولًا، أو يسأل عن شكل API، أو يرغب في بدائل قبل البرمجة، أو يقول "صممها مرتين". ليس للمراجعة أو إعادة هيكلة الكود الموجود أو اختيار مكتبة.

يرجى دائمًا الرد بلغة المستخدم.
