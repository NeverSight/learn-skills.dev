Esegui, verifica e indaga i test JavaScript, TypeScript e Python tramite lo stato di test live di Wallaby. Usalo per l'esecuzione dei test o il controllo dello stato, per creare baseline prima della modifica, per la verifica post-modifica, per diagnosticare errori o comportamenti inaspettati, per analizzare la copertura o le asserzioni, per tracciare l'esecuzione, per ispezionare i valori a runtime o i log, per valutare l'impatto su file o test e per aggiornare gli snapshot. Usalo anche quando l'utente menziona Wallaby o un framework o comando di test convenzionale come Vitest, Jest, Jasmine, Mocha, ng test, pytest, unittest o npm test. Per favore rispondi sempre nella lingua dell'utente.
