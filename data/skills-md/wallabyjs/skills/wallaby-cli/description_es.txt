Ejecuta, verifica e investiga pruebas de JavaScript, TypeScript y Python mediante el estado de pruebas en tiempo real de Wallaby. Úsalo para la ejecución de pruebas o la comprobación del estado, establecer bases de referencia antes de editar, verificar después de cambios, diagnosticar fallos o comportamientos inesperados, analizar la cobertura o aserciones, rastrear la ejecución, inspeccionar valores en tiempo de ejecución o registros, evaluar el impacto en archivos o pruebas y actualizar instantáneas. También utilízalo cuando el usuario mencione Wallaby o un framework de pruebas convencional o un comando como Vitest, Jest, Jasmine, Mocha, ng test, pytest, unittest o npm test.
