استخدم Excel كطبقة وسيطة، واحصل على بيانات Wind المالية من خلال المكون الإضافي Wind Excel (وظائف مثل WSD، وWSS، وWSI، وما إلى ذلك). عندما يحتاج المستخدم إلى استرداد بيانات سوق Wind أو المقاييس المالية أو بيانات القطاع وتكون واجهة برمجة تطبيقات Wind Python غير متاحة (بسبب مشكلات الأذونات أو قيود الشبكة)، تستخدم هذه المهارة مسار المكون الإضافي Excel+Wind لجلب البيانات. سيناريوهات التحفيز: (1) يطلب المستخدم بيانات سوق K-line التاريخية للأسهم/العقود الآجلة/المؤشرات من Wind؛ (2) يطلب المستخدم مقاييس Wind المالية (على سبيل المثال، PE وPB وEPS وROE وما إلى ذلك)؛ (3) يطلب المستخدم بيانات ماكرو أو بيانات صناعية؛ (4) لا يمكن لـ Wind Python API الاتصال ولكن المكون الإضافي لـ Excel يعمل.
