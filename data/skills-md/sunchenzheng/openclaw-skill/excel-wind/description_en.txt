Use Excel as an intermediate layer to obtain Wind Financial data via the Wind Excel plug‑in (functions such as WSD, WSS, WSI, etc.). When users need to retrieve Wind market data, financial indicators, or sector data and the Wind Python API is unavailable (due to permission issues or network restrictions), this capability uses the Excel + Wind plug‑in approach to fetch the data. Trigger scenarios: (1) the user requests historical K‑line market data for stocks, futures, or indices from Wind; (2) the user requests Wind financial metrics (PE, PB, EPS, ROE, etc.); (3) the user requests macro or industry data; (4) the Wind Python API is unreachable but the Excel plug‑in is available.
