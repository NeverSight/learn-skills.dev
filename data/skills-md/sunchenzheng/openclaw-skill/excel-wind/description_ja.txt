Excel を中間層として使用し、Wind Excel アドイン (WSD/WSS/WSI などの機能) を使用して Wind から財務データを取得します。ユーザーが Wind 市場データ、財務指標、またはセクター データを取得する必要があり、(権限の問題またはネットワーク制限により) Wind Python API が利用できない場合、この機能は Excel+Wind アドイン ルートを利用してデータを取得します。トリガー シナリオ: (1) ユーザーが Wind から株式/先物/指数の過去の K‑line マーケット データをリクエストします。 (2) ユーザーが Wind の財務指標 (PE、PB、EPS、ROE など) を要求する。 (3) ユーザーがマクロまたは業界データを要求する。 (4) Wind Python API は接続できませんが、Excel アドインは機能します。
