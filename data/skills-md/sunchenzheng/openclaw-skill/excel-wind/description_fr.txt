Utilisez Excel comme couche intermédiaire, en obtenant les données Wind Financial via le plug-in Wind Excel (fonctions telles que WSD, WSS, WSI, etc.). Lorsqu'un utilisateur a besoin de récupérer des données de marché Wind, des mesures financières ou des données sectorielles et que l'API Wind Python n'est pas disponible (en raison de problèmes d'autorisation ou de restrictions de réseau), cette fonctionnalité exploite la route du plug-in Excel+Wind pour récupérer les données. Scénarios de déclenchement : (1) l'utilisateur demande à Wind des données historiques sur le marché de la ligne K pour les actions, les contrats à terme ou les indices ; (2) l'utilisateur demande des indicateurs financiers Wind (PE, PB, EPS, ROE, etc.) ; (3) l'utilisateur demande des données macro ou industrielles ; (4) l'API Wind Python ne peut pas se connecter mais le plug-in Excel est fonctionnel.
