Excel을 중간 계층으로 사용하고 Wind Excel 플러그인(WSD/WSS/WSI 등의 기능)을 통해 Wind Financial 데이터를 얻습니다. 사용자에게 Wind 시장 데이터, 재무 지표 또는 부문 데이터가 필요하고 Wind Python API를 사용할 수 없는 경우(권한 문제 또는 네트워크 제한으로 인해) 이 기능은 Excel+Wind 플러그인 경로를 통해 데이터를 검색합니다. 트리거 시나리오: (1) 사용자는 Wind에서 주식/선물/지수에 대한 과거 K 라인 시장 데이터를 요청합니다. (2) 사용자가 Wind 재무 지표(예: PE, PB, EPS, ROE)를 요청합니다. (3) 사용자가 매크로 또는 산업 데이터를 요청합니다. (4) Wind Python API에 연결할 수 없지만 Excel 플러그인은 작동합니다.
