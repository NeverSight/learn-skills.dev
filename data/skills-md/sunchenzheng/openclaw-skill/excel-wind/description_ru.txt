Используйте Excel в качестве промежуточного уровня для получения финансовых данных Wind через плагин Wind Excel (такие функции, как WSD, WSS, WSI и т. д.). Когда пользователям необходимо получить рыночные данные Wind, финансовые показатели или отраслевые данные, а API Wind Python недоступен (из-за проблем с разрешениями или сетевых ограничений), эта возможность использует подход подключаемого модуля Excel+Wind для получения данных. Сценарии триггера: (1) пользователь запрашивает исторические рыночные данные K-line для акций, фьючерсов или индексов у Wind; (2) пользователь запрашивает финансовые показатели Wind (PE, PB, EPS, ROE и т. д.); (3) пользователь запрашивает макро- или отраслевые данные; (4) API Wind Python недоступен, но подключаемый модуль Excel доступен.
