Utilice Excel como capa intermedia y obtenga datos financieros de Wind a través del complemento Wind Excel (funciones como WSD, WSS, WSI, etc.). Cuando un usuario necesita recuperar datos del mercado eólico, indicadores financieros o datos del sector y la API de Wind Python no está disponible (debido a problemas de permisos o restricciones de red), esta capacidad recupera los datos a través de la ruta del complemento Excel+Wind. Escenarios desencadenantes: (1) el usuario solicita a Wind datos históricos del mercado de la línea K para acciones, futuros o índices; (2) el usuario solicita métricas financieras de Wind (PE, PB, EPS, ROE, etc.); (3) el usuario solicita datos macro o de la industria; (4) la API de Wind Python no se puede conectar, pero el complemento de Excel está disponible.
