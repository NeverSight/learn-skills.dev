Разработка модов для RimWorld: запросы данных Def во время выполнения, декомпиляция C# и исследование исходного кода, патчинг через Harmony, миграция API и исследование механик. Использует rimsearcher для проверки истинности Def и DecompilerServer для получения декомпилированных исходных доказательств.
