fluttersdk_dusk: E2E‑драйвер для приложений Flutter, позволяющий LLM‑агенту видеть (snap, observe, screenshot) и выполнять действия (tap, type, drag, scroll, navigate) в работающем приложении Flutter через 33 инструмента MCP (`dusk_*`) и 34 соответствующие CLI‑команды (`./bin/fsa dusk:*`). Снимки создают дерево семантики в формате YAML с устойчивыми токенами `[ref=eN]`; `dusk_find` и `dusk_observe` создают переразрешаемые дескрипторы запросов `q<N>`. Каждый жест проходит 6‑шаговый шлюз действия с разбираемыми по подстроке причинами отказа (`not enabled`, `zero rect`, `off-viewport`, `not stable`, `obscured by`, `defunct`). ТРИГГЕРИТЬ, когда: любой вызов инструмента MCP `dusk_*`, любая CLI‑команда `dusk:*`, вызов `./bin/fsa`, пользователь просит агента управлять/исследовать/тестировать/отлаживать запущенное приложение Flutter, пользователь упоминает snap / observe / actionability / ref / eN / qN, или разговор касается сквозного тестирования UI Flutter. НЕ ТРИГГЕРИТЬ, когда: только написание widget‑тестов `flutter_test`, только чтение кольцевых буферов телескопа без управления UI (используйте fluttersdk-telescope), или только изменение исходного кода Dart без его запуска.
