fluttersdk_dusk：一個針對 Flutter 應用的端到端驅動程式，讓 LLM 代理能透過 33 個 MCP 工具（`dusk_*`）和 34 個相對應的 CLI 指令（`./bin/fsa dusk:*`）在執行中的 Flutter 應用上觀察（snap、observe、screenshot）並執行操作（tap、type、drag、scroll、navigate）。快照會輸出含有穩定 `[ref=eN]` 代幣的 YAML 語意樹；`dusk_find` 與 `dusk_observe` 會產生可重新解析的 `q<N>` 查詢句柄。每一次手勢皆需通過六步驟的可操作性門檻，若失敗會以可字串解析的原因說明（`not enabled`、`zero rect`、`off-viewport`、`not stable`、`obscured by`、`defunct`）。觸發條件：任何 `dusk_*` MCP 工具呼叫、任何 `dusk:*` CLI 指令、執行 `./bin/fsa`、使用者請求代理駕駛 / 檢查 / 測試 / 除錯執行中的 Flutter 應用、使用者提到 snap / observe / actionability / ref / eN / qN，或對話涉及 Flutter UI 的端對端測試。不得觸發的情況：僅撰寫 `flutter_test` 小部件測試、僅閱讀 telescope 環形緩衝區而未操作 UI（使用 fluttersdk-telescope），或僅修改 Dart 原始碼卻未執行它。
