fluttersdk_dusk: برنامج تشغيل E2E لتطبيقات Flutter يتيح للوكيل LLM رؤية (التقاط، ملاحظة، لقطة شاشة) والتفاعل (النقر، الكتابة، السحب، التمرير، التنقل) مع تطبيق Flutter قيد التشغيل عبر 33 أداة MCP (`dusk_*`) و34 أمر CLI مطابق (`./bin/fsa dusk:*`). تُصدر اللقطات شجرة معنوية YAML مع رموز ثابتة `[ref=eN]`؛ `dusk_find` و `dusk_observe` تُنشئ مقابض استعلام `q<N>` قابلة لإعادة الحل. كل إيماءة تمر عبر بوابة قابلية تنفيذ من 6 خطوات مع أسباب فشل قابلة للتحليل كسلسلة فرعية (`not enabled`، `zero rect`، `off-viewport`، `not stable`، `obscured by`، `defunct`). يتم التفعيل عندما: أي استدعاء لأداة MCP `dusk_*`، أي أمر CLI `dusk:*`، استدعاء `./bin/fsa`، يطلب المستخدم من الوكيل تشغيل / فحص / اختبار / تصحيح تطبيق Flutter قيد التشغيل، يذكر المستخدم snap / observe / actionability / ref / eN / qN، أو تتطرق المحادثة إلى الاختبار الشامل لواجهة Flutter. لا يتم التفعيل عندما: يتم فقط كتابة اختبارات `flutter_test` للودجات، أو يتم فقط قراءة مخازن حلقة التلسكوب دون تشغيل الواجهة (استخدم fluttersdk-telescope)، أو يتم فقط تعديل شفرة Dart دون تشغيلها.
