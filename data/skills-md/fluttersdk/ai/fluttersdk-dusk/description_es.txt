fluttersdk_dusk: controlador E2E para aplicaciones Flutter que permite a un agente LLM ver (snap, observe, screenshot) y actuar (tap, type, drag, scroll, navigate) en una aplicación Flutter en ejecución mediante 33 herramientas MCP (`dusk_*`) y 34 comandos CLI correspondientes (`./bin/fsa dusk:*`). Las instantáneas generan un árbol de semántica YAML con tokens estables `[ref=eN]`; `dusk_find` y `dusk_observe` crean manejadores de consulta re‑resolubles `q<N>`. Cada gesto pasa por una puerta de 6 pasos de capacidad de acción con razones de fallo analizables por subcadenas (`not enabled`, `zero rect`, `off-viewport`, `not stable`, `obscured by`, `defunct`). DISPARAR cuando: cualquier llamada a una herramienta MCP `dusk_*`, cualquier comando CLI `dusk:*`, invocación de `./bin/fsa`, el usuario pida al agente que conduzca / inspeccione / pruebe / depure una aplicación Flutter en ejecución, el usuario mencione snap / observe / actionability / ref / eN / qN, o la conversación toque pruebas de extremo a extremo de una UI Flutter. NO DISPARAR cuando: solo se estén creando pruebas de widgets con `flutter_test`, solo se lean buffers de anillo de telescope sin conducir la UI (usar fluttersdk-telescope), o solo se modifique código Dart sin ejecutarlo.
