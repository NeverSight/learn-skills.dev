fluttersdk_dusk: driver E2E per app Flutter che consente a un agente LLM di vedere (snap, observe, screenshot) e agire (tap, type, drag, scroll, navigate) su un'app Flutter in esecuzione tramite 33 strumenti MCP (`dusk_*`) e 34 comandi CLI corrispondenti (`./bin/fsa dusk:*`). Gli snapshot emettono un albero di semantica YAML con token stabili `[ref=eN]`; `dusk_find` e `dusk_observe` generano handle di query `q<N>` risolvibili nuovamente. Ogni gesto supera una porta di actionability a 6 passaggi con motivi di fallimento parsabili tramite sottostringhe (`not enabled`, `zero rect`, `off-viewport`, `not stable`, `obscured by`, `defunct`). TRIGGER quando: qualsiasi chiamata a uno strumento MCP `dusk_*`, qualsiasi comando CLI `dusk:*`, invocazione di `./bin/fsa`, l'utente chiede all'agente di guidare / ispezionare / testare / fare debug di un'app Flutter in esecuzione, l'utente menziona snap / observe / actionability / ref / eN / qN, o la conversazione riguarda il testing end‑to‑end di un'interfaccia Flutter. DO NOT TRIGGER quando: solo si scrivono test widget `flutter_test`, solo si leggono i buffer ad anello del telescopio senza guidare l'interfaccia (usa fluttersdk-telescope), o solo si modifica il codice Dart senza eseguirlo.
