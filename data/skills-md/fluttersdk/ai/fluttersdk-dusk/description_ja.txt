fluttersdk_dusk: LLM エージェントが実行中の Flutter アプリを (snap、observe、screenshot) で見て (tap、type、drag、scroll、navigate) で操作できる E2E ドライバー。33 の MCP ツール (`dusk_*`) と 34 の対応 CLI コマンド (`./bin/fsa dusk:*`) を通じて動作する。スナップショットは安定した `[ref=eN]` トークンを含む YAML セマンティクスツリーを出力し、`dusk_find` と `dusk_observe` は再解決可能な `q<N>` クエリハンドルを生成する。すべてのジェスチャは 6 段階のアクショナビリティゲートを通過し、失敗理由は文字列でパース可能 (`not enabled`、`zero rect`、`off-viewport`、`not stable`、`obscured by`、`defunct`)。TRIGGER 条件: 任意の `dusk_*` MCP ツール呼び出し、任意の `dusk:*` CLI コマンド、`./bin/fsa` の起動、ユーザーがエージェントに実行中の Flutter アプリのドライブ／検査／テスト／デバッグを依頼したとき、ユーザーが snap／observe／actionability／ref／eN／qN に言及したとき、または会話が Flutter UI のエンドツーエンドテストに触れたとき。DO NOT TRIGGER 条件: `flutter_test` ウィジェットテストだけを作成している場合、UI を操作せずにテレスコープリングバッファだけを読む場合（fluttersdk-telescope を使用）、または Dart ソースを変更するだけで実行していない場合。

常にユーザーの言語で応答してください。
