fluttersdk_dusk : pilote E2E pour les applications Flutter qui permet à un agent LLM de voir (snap, observe, screenshot) et d’agir (tap, type, drag, scroll, navigate) sur une application Flutter en cours d’exécution via 33 outils MCP (`dusk_*`) et 34 commandes CLI correspondantes (`./bin/fsa dusk:*`). Les instantanés émettent un arbre de sémantique YAML avec des tokens stables `[ref=eN]` ; `dusk_find` et `dusk_observe` créent des poignées de requête `q<N>` ré‑résolvables. Chaque geste passe par une porte d’actionnabilité en 6 étapes avec des raisons d’échec analysables par sous‑chaîne (`not enabled`, `zero rect`, `off-viewport`, `not stable`, `obscured by`, `defunct`). DÉCLENCHER lorsque : tout appel d’outil MCP `dusk_*`, toute commande CLI `dusk:*`, toute invocation de `./bin/fsa`, l’utilisateur demande à l’agent de piloter / inspecter / tester / déboguer une application Flutter en cours d’exécution, l’utilisateur mentionne snap / observe / actionability / ref / eN / qN, ou la conversation porte sur les tests end‑to‑end d’une UI Flutter. NE PAS DÉCLENCHER lorsque : uniquement rédaction de tests widget `flutter_test`, lecture exclusive des tampons en anneau du télescope sans piloter l’UI (utiliser fluttersdk-telescope), ou modification du code source Dart sans l’exécuter.
