fluttersdk_dusk: Flutter 앱을 위한 E2E 드라이버로, LLM 에이전트가 실행 중인 Flutter 앱을 (snap, observe, screenshot) 보고 (tap, type, drag, scroll, navigate) 동작하게 할 수 있습니다. 33개의 MCP 도구(`dusk_*`)와 34개의 대응 CLI 명령(`./bin/fsa dusk:*`)을 통해 작동합니다. 스냅샷은 안정적인 `[ref=eN]` 토큰을 포함한 YAML Semantics 트리를 출력합니다; `dusk_find`와 `dusk_observe`는 재해석 가능한 `q<N>` 쿼리 핸들을 생성합니다. 모든 제스처는 6단계 액션 가능성 게이트를 통과하며, 부분 문자열로 파싱 가능한 실패 이유(`not enabled`, `zero rect`, `off-viewport`, `not stable`, `obscured by`, `defunct`)를 제공합니다. TRIGGER when: `dusk_*` MCP 도구 호출, `dusk:*` CLI 명령, `./bin/fsa` 실행, 사용자가 에이전트에게 실행 중인 Flutter 앱을 구동/검사/테스트/디버그하도록 요청할 때, 사용자가 snap / observe / actionability / ref / eN / qN을 언급할 때, 혹은 대화가 Flutter UI의 엔드투엔드 테스트와 관련될 때. DO NOT TRIGGER when: 오직 `flutter_test` 위젯 테스트를 작성할 때, UI를 구동하지 않고 텔레스코프 링 버퍼만 읽을 때(이때는 fluttersdk-telescope 사용), 또는 Dart 소스만 수정하고 실행하지 않을 때.
