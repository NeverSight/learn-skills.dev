تشغيل أشجار العمل التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات الأثرية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضّل استخدامه على شجرة git الخام، أو PTYs المؤقتة، أو استخدام الكمبيوتر عندما تكون حالة Orca متورطة. استخدم استخدام الكمبيوتر فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة رسومية لا يمكن لسطر الأوامر أو نظام الملفات أو API القيام به.
