`orca` CLI を使用して、Orca が管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、および Orca の埋め込みブラウザを操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」「handover」「give this to another agent」「Orca browser」「orca artifacts」「share skills」と言ったときに使用します。Orca の状態が関与する場合は、生の git worktree やアドホック PTY、あるいは Computer Use よりもこれを優先してください。CLI、ファイルシステム、API ではできない、可視ウィンドウの GUI 操作が必要な場合にのみ Computer Use を使用してください。常にユーザーの言語で回答してください。
