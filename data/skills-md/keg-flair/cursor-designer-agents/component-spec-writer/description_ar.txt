ينتج مواصفة مكوّن جاهزة للمهندسين (التشريح/الفتحات، المتغيّرات، الحالات، السلوك، قواعد المحتوى، نقاط ربط الرموز، إمكانية الوصول، التثيم، التركيبات غير الصالحة، قائمة مراجعة الجودة). يُستخدم عندما يطلب المستخدم توثيق مكوّن نظام تصميم أو توثيق نمط واجهة مستخدم قابل لإعادة الاستخدام. الرجاء دائمًا الرد بلغة المستخدم.
