أنشئ أو عدّل أدبًا خياليًا إيروتيكيًا أو خيالًا جنسيًا حميميًا للمستخدمين البالغين مع نصٍ يظل وفيًا للشخصيات، واتصال جسدي مستمر، وتغيّر حالة واعٍ بالعلاقات، وإمكانية ضبط درجة الصراحة. استخدم ذلك فقط عندما يطلب المستخدم صراحةً إيروتيكا خيالية، أو محتوى جنسي صريح، أو حميمية جنسية، أو "情色、亲密场景、虚构性幻想"، أو لعبة دور إيروتيكية، أو حلم، أو فرضية، أو مشهد أصلي، أو فن خيالي، أو بديل عالمي (AU). استخدم أيضًا للشخصيات القانوية، أو الأصوات الخاصة بالتكييف، أو الديناميات الجماعية، أو المتعددة الشركاء، أو غير المتناظرة، أو التكهنية عندما تنتمي إلى ذلك الطلب الإريوتيكي. لا تُفعَّل لهذه الشخصيات أو العلاقات أو الأحلام أو المشاهد أو الفان فكشن أو بدائل عالمية التي لا تحمل نية إيروتيكية أو حميمية جنسية. هذه المهارة الثنائية اللغة القابلة للمشاركة لا تحتوي على شخصية محددة للمستخدم، أو أرشيف، أو علاقة، أو ملف كينك. يرجى دائمًا الرد بلغة المستخدم.
