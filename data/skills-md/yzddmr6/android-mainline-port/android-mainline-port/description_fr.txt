Un manuel et une base de connaissances pour porter le noyau Linux mainline et les distributions de bureau sur les téléphones et tablettes Android (pratique Qualcomm + Ubuntu GNOME). Il couvre l’évaluation, la compilation, le chargeur de démarrage, l’arbre de périphériques, l’affichage, le tactile, l’audio, le sans‑fil, la charge, la mise en veille, le double démarrage, le packaging, les tests et la publication. Les utilisateurs qui souhaitent exécuter Linux natif sur des appareils Android, porter le noyau mainline, fastbooter un noyau personnalisé, dépanner les périphériques qui ne fonctionnent pas avec le noyau mainline, ou évaluer la possibilité de porter un appareil doivent utiliser cette ressource.
