Manual de operaciones y repositorio de experiencia para portar Linux mainline y distribuciones de escritorio a teléfonos y tabletas Android (práctica Qualcomm + Ubuntu GNOME). Cubre la evaluación, compilación, bootloader, árbol de dispositivos, pantalla, tacto, audio, inalámbrico, carga, suspensión, arranque dual, empaquetado, pruebas y lanzamiento. Destinado a usuarios que desean ejecutar Linux nativo en dispositivos Android, portar el kernel mainline, hacer fastboot de un kernel personalizado, solucionar problemas de periféricos que no funcionan bajo el mainline, o evaluar si un dispositivo puede ser portado.
