The operation manual and experience repository for porting the mainline Linux and desktop distributions to Android phones and tablets (Qualcomm + Ubuntu GNOME practice). It covers evaluation, building, bootloader, device tree, display, touch, audio, wireless, charging, sleep, dual‑system, packaging, testing, and release. Users who want to run native Linux on Android devices, port the mainline kernel, fastboot‑boot custom kernels, troubleshoot peripherals that don’t work under the mainline, or assess whether a device can be ported use this.
