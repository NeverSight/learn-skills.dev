Registra video dallo stile Screen Studio, curati, di applicazioni web (cursore fluido, onde di clic, zoom con easing, cornice imbottita) utilizzando il server MCP di takeone, la CLI o l'SDK TypeScript, includendo l'installazione e la configurazione da zero. Usa questo ogni volta che l'utente desidera un video dimostrativo, un walkthrough del prodotto, un clip di funzionalità, una registrazione tutorial, un video di lancio o una registrazione dello schermo di un sito web o di un'app web, anche se non menziona takeone, e ogni volta che un progetto contiene file di scenario takeone o una cartella .takeone.
