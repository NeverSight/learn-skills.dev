À utiliser lorsqu'une tâche nécessite un véritable navigateur piloté à partir du terminal avec la CLI « agent-browser » — ouvrir une page, cliquer, remplir un formulaire, se connecter, gratter le contenu restitué, prendre une capture d'écran ou une vidéo, vérifier un serveur de développement local dans un navigateur, tester une application Electron ou QA-ing une application Web — et chaque fois que l'utilisateur mentionne « agent-browser », « @eN » refs ou une automatisation pilotée par snapshot. Charge le propre guide correspondant à la version de la CLI avant la première commande et configure une session isolée.
