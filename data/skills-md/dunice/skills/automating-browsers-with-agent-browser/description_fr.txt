Utilisez-le lorsque une tâche nécessite un vrai navigateur piloté depuis le terminal avec le CLI `agent-browser` — ouvrir une page, cliquer, remplir un formulaire, se connecter, extraire le contenu rendu, prendre une capture d'écran ou une vidéo, vérifier un serveur de développement local dans un navigateur, tester une application Electron ou assurer le QA d’une application web — et chaque fois que l’utilisateur mentionne `agent-browser`, les références `@eN` ou l’automatisation basée sur des snapshots. Charge le guide propre au CLI, correspondant à la version, avant la première commande et crée une session isolée.
