استخدمه عندما تحتاج مهمة إلى متصفح حقيقي يتم تشغيله من الطرفية باستخدام واجهة سطر الأوامر `agent-browser` — لفتح صفحة، النقر، تعبئة نموذج، تسجيل الدخول، استخراج المحتوى المعروض، التقاط صورة شاشة أو فيديو، فحص خادم تطوير محلي في المتصفح، اختبار تطبيق إلكترون، أو إجراء اختبار جودة لتطبيق ويب — وأيضًا كلما ذكر المستخدم `agent-browser` أو مراجع `@eN` أو أتمتة معتمدة على اللقطات. يقوم بتحميل دليل متوافق مع إصدار CLI قبل الأمر الأول ويعد جلسة معزولة.
