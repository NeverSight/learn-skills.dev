Usa cuando una tarea necesita un navegador real controlado desde la terminal con la CLI `agent-browser` — abrir una página, hacer clic, rellenar un formulario, iniciar sesión, extraer contenido renderizado, tomar una captura de pantalla o vídeo, comprobar un servidor de desarrollo local en un navegador, probar una aplicación Electron o hacer QA de una aplicación web — y siempre que el usuario mencione `agent-browser`, referencias `@eN` o automatización basada en snapshots. Carga la guía propia de la versión de la CLI antes del primer comando y configura una sesión aislada.
