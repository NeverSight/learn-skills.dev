Verwenden Sie diese Option, wenn eine Aufgabe einen echten Browser benötigt, der vom Terminal mit der "Agent-Browser" -CLI gesteuert wird — Öffnen einer Seite, Klicken, Ausfüllen eines Formulars, Anmelden, Scraping gerenderter Inhalte, Erstellen eines Screenshots oder Videos, Überprüfen eines lokalen Entwicklungsservers in einem Browser, Testen einer Electron-App oder QA-ing einer Web-App — und wenn der Benutzer "Agent-Browser", "@eN" Refs oder Snapshot-gesteuerte Automatisierung erwähnt. Lädt den CLI-eigenen, mit der Version übereinstimmenden Leitfaden vor dem ersten Befehl und richtet eine isolierte Sitzung ein.
