Verwenden Sie dies, wenn eine Aufgabe einen echten Browser erfordert, der über das Terminal mit der `agent-browser`‑CLI gesteuert wird — eine Seite öffnen, klicken, ein Formular ausfüllen, sich anmelden, gerenderte Inhalte scrapen, einen Screenshot oder ein Video aufnehmen, einen lokalen Entwicklungs‑Server im Browser prüfen, eine Electron‑App testen oder ein Web‑App QA‑en — und immer, wenn der Benutzer `agent-browser`, `@eN`‑Referenzen oder snapshot‑gesteuerte Automatisierung erwähnt. Lädt vor dem ersten Befehl den versionsgerechten Leitfaden der CLI und richtet eine isolierte Sitzung ein.

Bitte antworten Sie immer in der Sprache des Benutzers.
