Usa quando un'attività richiede un browser reale controllato dal terminale con la CLI `agent-browser` — aprire una pagina, fare click, compilare un modulo, effettuare il login, estrarre contenuti renderizzati, fare uno screenshot o un video, verificare un server di sviluppo locale in un browser, testare un'app Electron o fare QA di un'app web — e ogni volta che l'utente menziona `agent-browser`, riferimenti `@eN` o automazione basata su snapshot. Carica la guida corrispondente alla versione della CLI prima del primo comando e imposta una sessione isolata.

Rispondi sempre nella lingua dell'utente.
