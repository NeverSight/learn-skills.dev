Usa quando un compito richiede un browser reale controllato dal terminale con il CLI `agent-browser` — aprire una pagina, fare click, compilare un modulo, accedere, estrarre contenuti renderizzati, fare uno screenshot o un video, verificare un server locale di sviluppo in un browser, testare un’app Electron o fare QA di un’app web — e ogni volta che l’utente menziona `agent-browser`, riferimenti `@eN` o automazione basata su snapshot. Carica la guida corrispondente alla versione del CLI prima del primo comando e imposta una sessione isolata.
