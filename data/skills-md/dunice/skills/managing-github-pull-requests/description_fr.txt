Utilisez-le lorsque vous ouvrez, mettez à jour, inspectez ou renommez une pull request GitHub depuis le terminal — en exécutant `gh pr create`, `gh pr edit`, `gh pr ready`, en ajoutant des réviseurs, des labels ou des captures d’écran à une PR existante, ou lorsqu’on vous demande « ouvrir une PR », « mettre cela en revue » ou « mettre à jour la PR ».
