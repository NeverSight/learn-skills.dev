Verwenden Sie diese Option, wenn Sie eine GitHub-Pull-Anforderung vom Terminal öffnen, aktualisieren, überprüfen oder neu betiteln — indem Sie "gh pr create", "gh pr edit", "gh pr ready" ausführen, Rezensenten, Etiketten oder Screenshots zu einer vorhandenen PR hinzufügen oder aufgefordert werden, "eine PR zu öffnen", "diese zur Überprüfung einzurichten" oder "die PR zu aktualisieren".
