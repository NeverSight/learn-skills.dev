Используйте при открытии, обновлении, проверке или переименовании pull‑request на GitHub из терминала — при запуске `gh pr create`, `gh pr edit`, `gh pr ready`, добавлении ревьюеров, меток или скриншотов к существующему PR, а также когда просят «создать PR», «отправить это на ревью» или «обновить PR».
