Используется при открытии, обновлении, просмотре или изменении заголовка pull‑request на GitHub из терминала — при выполнении команд `gh pr create`, `gh pr edit`, `gh pr ready`, добавлении ревьюеров, меток или скриншотов к существующему PR, а также когда просят «открыть PR», «отправить на ревью» или «обновить PR».
