Utilisez la CLI sur ordinateur d'Orca pour inspecter et exploiter les fenêtres d'applications de bureau locales via des arborescences d'accessibilité, des captures d'écran et des actions sécurisées de l'interface utilisateur. À utiliser pour l'interaction avec les applications de bureau : répertorier les applications/fenêtres, obtenir l'état de l'application, lire l'interface utilisateur visible, cliquer sur les commandes, saisir, appuyer sur les touches, faire défiler, faire glisser, définir des valeurs ou effectuer des actions d'accessibilité. À utiliser également pour les fenêtres de navigateur, les vues Web, l'interface utilisateur de l'application Orca ou toute autre interface utilisateur de bureau. Les déclencheurs incluent « l'utilisation de l'ordinateur », « l'ordinateur orca », « lire Spotify », « lire Slack », « contrôler/cliquer/lire dans une application de bureau » et « obtenir l'état de l'application ».
