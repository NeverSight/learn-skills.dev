Orca のコンピュータ用 CLI を使用して、アクセシビリティ ツリー、スクリーンショット、安全な UI アクションを通じてローカル デスクトップ アプリ ウィンドウを検査および操作します。デスクトップ アプリの操作に使用します: アプリ/ウィンドウの一覧表示、アプリの状態の取得、表示されている UI の読み取り、コントロールのクリック、入力、キーの押し、スクロール、ドラッグ、値の設定、またはアクセシビリティ アクションの実行。ブラウザ ウィンドウ、Web ビュー、Orca アプリ UI、またはその他のデスクトップ UI にも使用します。トリガーには、「コンピューターの使用」、「orca コンピューター」、「Spotify の読み取り」、「Slack の読み取り」、「デスクトップ アプリでのコントロール/クリック/読み取り」、および「アプリの状態の取得」が含まれます。
