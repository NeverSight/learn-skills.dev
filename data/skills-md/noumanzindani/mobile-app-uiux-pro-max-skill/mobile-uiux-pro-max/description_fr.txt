Utilisez-le lors de la conception, de la génération, de l'amélioration ou de l'audit de TOUTE interface UI/UX d'application mobile avec Flutter, React Native, SwiftUI, Jetpack Compose, iOS natif, Android natif, Expo, Ionic ou .NET MAUI. Applique Material 3 Expressive, les directives Apple HIG (iOS 26 Liquid Glass) et WCAG 2.2 par défaut ; impose les jetons de conception (pas de valeurs codées en dur), les 7 états UI (idéal/vide/chargement/erreur/hors‑ligne/succès/permission refusée), l'ergonomie de la zone du pouce, des cibles tactiles de 44 pt/48 dp, le mode sombre, la localisation/RTL, des mises en page réactives/pliante, et les conventions de plateforme appropriées. Se déclenche sur : « concevoir un écran », « créer une UI mobile », « rendre cet écran accessible », « auditer l’UX de mon application », « générer un écran de connexion / inscription / paiement / tableau de bord / chat / paramètres / intégration / profil », « améliorer cet écran », « ajouter le mode sombre », « mise en page réactive ou pliable », « RTL / localisation », « examiner cette UI pour l’accessibilité ou la qualité du design ».

Veuillez toujours répondre dans la langue de l'utilisateur.
