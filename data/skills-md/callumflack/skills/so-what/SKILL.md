---
name: so-what
description: Extracts the practical conclusion, consequence, and concrete next action from the preceding answer. Use when the user asks "so what?", "and so fucking what?", "what does that mean for us?", or says the lead or next step is missing.
---

Answer the question left hanging by the previous response: **So what, and what do we do next?**

Before choosing a next action, recover the user's actual goal and what they have already accepted as finished. Check the preceding answer against that history. Compare stopping, reusing completed work, and doing additional work. Recommend additional work only when current evidence identifies an unmet outcome within the goal. State what that action would change.

Lead with the practical conclusion. Say what it means for the user's goal. Then give the concrete next action that follows from it. Make the connection explicit: because this is true, do this next.

A gap is not a next step. If proof is missing, say what to test and what result would settle it. If a decision is needed, give your recommendation. If someone else must act, name who and what they need to do. If nothing remains, say so; do not invent more work.

Use plain words and one short paragraph or up to three short bullets. Keep only details that change the conclusion or next action. No preamble, recap, vague "investigate further", or "I can do that if you want" ending.

Recommend the next action within the user's goal. Complete necessary, already-authorized work before returning rather than presenting it as a follow-up suggestion. A discussion or assessment request stays within its write boundary.

For an action task, state what is usable now and distinguish it from work still required or a decision needing the user. The always-on outcome rule and the destination's completion check own execution and proof; this skill owns explaining their practical result.
