Crea un repositorio de “descripción del producto” para un producto de software: un conjunto de documentos en prosa que describen, de fuera hacia adentro, lo que el usuario ve, lo que puede hacer y exactamente lo que ocurre cuando lo hace, redactados a partir del código y las pruebas, luego verificados contra el producto en ejecución y triados en una lista de errores. Funciona para cualquier producto con un usuario (editores de lienzo, aplicaciones web, CLIs, productos de chat, aplicaciones móviles). Úsalo cuando el usuario pida “escribir una descripción del producto para X”, “describir la experiencia de usuario de X”, “documentar cómo se comporta X para el usuario”, “crear un repositorio de especificaciones de comportamiento”, o quiera una cuenta función por función, evento por evento del comportamiento de una aplicación en lugar de documentación de API. También sirve para retomar o ampliar un repositorio de descripción de producto existente.
