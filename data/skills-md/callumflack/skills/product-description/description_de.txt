Erstelle ein „Product Description“-Repository für ein Softwareprodukt — eine Sammlung von Prosadokumenten, die von außen nach innen beschreiben, was der Benutzer sieht, was er tun kann und genau, was passiert, wenn er es tut, basierend auf Code und Tests, dann gegen das laufende Produkt verifiziert und in eine Bugliste überführt werden. Funktioniert für jedes Produkt mit einem Benutzer (Canvas‑Editoren, Web‑Apps, CLIs, Chat‑Produkte, Mobile‑Apps). Verwende es, wenn der Benutzer bittet, „eine Produktbeschreibung für X zu schreiben“, „die Benutzererfahrung von X zu beschreiben“, „zu dokumentieren, wie sich X für den Benutzer verhält“, „ein Behavior‑Spec‑Repo zu erstellen“ oder eine feature‑weise, ereignis‑weise Aufschlüsselung des Verhaltens einer App statt API‑Dokumentation wünscht. Auch zum Fortsetzen oder Erweitern eines bestehenden Produktbeschreibungs‑Repos verwenden. Bitte immer in der Sprache des Benutzers antworten.
