Crea un repository di “descrizione del prodotto” per un prodotto software — un insieme di documenti in prosa che descrivono, dal punto di vista esterno, ciò che l'utente vede, ciò che può fare e esattamente cosa accade quando lo fa, scritti a partire dal codice e dai test, poi verificati contro il prodotto in esecuzione e inseriti in una lista di bug. Funziona per qualsiasi prodotto con un utente (editori canvas, app web, CLI, prodotti di chat, app mobili). Usalo quando l'utente chiede di “scrivere una descrizione del prodotto per X”, “descrivere l'esperienza utente di X”, “documentare come X si comporta per l'utente”, “creare un repository di specifiche di comportamento”, o vuole un resoconto caratteristica per caratteristica, evento per evento del comportamento di un'app invece della documentazione API. Usalo anche per riprendere o estendere un repository di descrizione del prodotto esistente. Per favore rispondi sempre nella lingua dell'utente.
