Construisez un dépôt « description de produit » pour un logiciel — un ensemble de documents en prose décrivant, de l’extérieur vers l’intérieur, ce que voit l’utilisateur, ce qu’il peut faire et exactement ce qui se passe lorsqu’il le fait, rédigés à partir du code et des tests, puis vérifiés contre le produit en cours d’exécution et triés dans une liste de bugs. Fonctionne pour tout produit avec un utilisateur (éditeurs de canvas, applications web, CLI, produits de chat, applications mobiles). Utilisez‑le lorsque l’utilisateur demande « écrire une description de produit pour X », « décrire l’expérience utilisateur de X », « documenter le comportement de X pour l’utilisateur », « créer un dépôt de spécifications de comportement », ou souhaite un compte rendu fonctionnalité par fonctionnalité, événement par événement du comportement d’une application plutôt que des docs API. Utilisez également pour reprendre ou étendre un dépôt de description de produit existant.
