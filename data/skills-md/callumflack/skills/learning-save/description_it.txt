Salva conoscenza duratura da una chat Codex, conversazione, fonte, nota grezza, sessione di sintesi o thread a lungo termine nel database di conoscenza consolidato dell'utente o in una destinazione esplicitamente nominata. Usalo quando l'utente desidera raggruppare, archiviare, staccare, distillare, preservare, instradare o rendere recuperabile il contesto. Non usarlo per trasferimenti ordinari di codice o flussi di lavoro.

Rispondi sempre nella lingua dell'utente.
