قُم بتوجيه تركيب الميزات في React أو Next.js قبل التنفيذ وخلال إعادة التشكيل. استخدم ذلك عند تصميم هيكل الميزة، حدود المسار/وقت التشغيل، الخدمات، المحددات، خطافات المتحكم، نماذج العرض، ملكية التخطيط/الواجهة، المتغيّرات ذات النوع للعرض، التأثيرات المركّزة، أو الواجهات الكبيرة مع تعقيد الخصائص والاعتماديات المخفية.
