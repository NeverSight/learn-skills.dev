Commencez le travail sur le bug en prouvant le bug signalé avec un test de régression qui échoue avant d'essayer de le corriger. Utilisez‑le lorsque l'utilisateur signale un bug, demande de corriger un bug ou décrit une régression, un comportement défaillant ou un cas de reproduction avec une surface de test plausible. Veuillez toujours répondre dans la langue de l'utilisateur.
