Meta-competenza per il lavoro di costruzione React quando possono applicarsi più competenze React/framework/dati o oracoli di evidenza. Per Next.js, leggi prima la documentazione bundle installata per le affermazioni di runtime, poi seleziona comunque la proprietà e le altre prospettive applicabili. Usalo per classificare i risultati a diffuso ambito come rischio PR/seguimento/rumore e scegli l’oracolo di prova. Non usarlo per compiti React ovvi a oracolo unico, React Native o Expo. Per favore rispondi sempre nella lingua dell'utente.
