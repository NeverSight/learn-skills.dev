Метанавык для работы со сборкой React, когда могут применяться несколько навыков React/фреймворка/данных или оракулов доказательств. Для Next.js сначала прочитайте установленные пакетные документы о runtime‑утверждениях, затем всё равно выбирайте владение и другие применимые линзы. Используйте для классификации находок различного масштаба как риск PR/дальнейшие действия/шум и выбирайте оракул доказательства. Не используйте для очевидных одноокружных задач React, React Native или Expo.
