Compétence méta pour le travail de construction React lorsqu'il existe plusieurs compétences React/cadre/données ou oracles de preuve pouvant s'appliquer. Pour Next.js, commencez par lire la documentation fournie avec l'installation pour les affirmations d'exécution, puis sélectionnez la responsabilité et les autres perspectives pertinentes. Utilisez‑la pour classer les découvertes à portée différente comme risque PR/suivi/bruit et choisissez l’oracle de preuve. Ne l’utilisez pas pour les tâches React évidentes à oracle unique, React Native ou Expo.

Veuillez toujours répondre dans la langue de l'utilisateur.
