Orcaが管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そしてOrcaの組み込みブラウザを、`orca` CLIを通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orcaの状態が関係する場合は、raw git worktree や ad hoc PTY、Computer Use よりもこちらを優先してください。CLI、ファイルシステム、API では操作できない可視ウィンドウの GUI 制御が必要なときだけ Computer Use を使用します。

常にユーザーの言語で応答してください。
