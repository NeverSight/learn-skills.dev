تشغيل worktrees التي يديرها Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والملفات، ومشاركة المهارات، وتعليقات worktree، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدمه عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". يفضَّل هذا على استخدام git worktree العادي، أو PTYs العشوائية، أو تنفيذ الأوامر عبر Computer Use عندما تكون حالة Orca متورطة. استخدم Computer Use فقط عندما تحتاج نافذة ظاهرية إلى التحكم بواجهة المستخدم الرسومية ولا يمكن لسطر الأوامر أو نظام الملفات أو API القيام بذلك.
