Пишите, переписывайте или улучшайте маркетинговый текст для веб‑страниц, писем, рекламных объявлений, заголовков, CTA и ценностных предложений. Триггеры: «write copy for», «improve this copy», «rewrite this page», «marketing copy», «headline help», «CTA copy», «value proposition», «tagline», «email copy», «subject line», «sales page», «make this more compelling». Для французского текста см. french-copywriting. Для социальных сетей — social-copywriting. Для SEO‑контента — seo-copywriting. Для фирменного голоса — tone-of-voice.

Пожалуйста, всегда отвечайте на языке пользователя.
