Créez un clip musical pour une chanson en utilisant du code (sans modèle de génération vidéo) : comprenez d’abord la chanson (chronologie des paroles, rythme, montée et descente émotionnelles, comment les autres l’interprètent), puis décidez du style visuel, concevez les personnages, écrivez le script et le storyboard, commencez par des croquis avant de produire la pièce complète, et enfin révisez et éditez selon une checklist ; vous pouvez également décomposer le style d’une vidéo de référence avant de le suivre. Rendu des visuels image par image avec Canvas / p5.js / p5.brush, et utilisez HyperFrames pour combiner les paroles et la musique. Utilisez ceci lorsque l’utilisateur dit « faire un MV pour cette chanson », « créer un MV musical / MV lyrique / MV d’animation », « imiter le style de cette vidéo pour faire un MV », ou « faire un clip vidéo / une vidéo lyrique pour cette chanson ». Tout modèle est autorisé ; tout agent capable de lire/écrire des fichiers et d’exécuter des commandes peut le faire.

Veuillez toujours répondre dans la langue de l’utilisateur.
