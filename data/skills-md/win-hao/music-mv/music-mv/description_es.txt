Utiliza código para crear un MV musical de una canción (sin usar modelos de generación de video): primero comprende la canción (línea de tiempo de la letra, ritmo, altos y bajos emocionales, cómo otros interpretan la canción), luego decide el estilo visual, diseña los personajes, escribe el guion y el storyboard, produce bocetos antes de hacer la pieza completa y, finalmente, sigue una lista de verificación para revisar y editar; también puedes deconstruir el estilo de un video de referencia primero y luego replicarlo. Los visuales se dibujan fotograma a fotograma usando Canvas / p5.js / p5.brush, y HyperFrames combina la letra y la música. Los usuarios dicen “haz un MV para esta canción”, “crea un MV musical / MV de letra / MV de animación”, “aprende el estilo de este video y haz un MV”, o “haz un video musical / video de letra para esta canción”. No hay restricciones de modelo; cualquier agente que pueda leer/escribir archivos y ejecutar comandos puede hacerlo.
