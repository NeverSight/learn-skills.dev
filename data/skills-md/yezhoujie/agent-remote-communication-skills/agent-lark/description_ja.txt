人間が必要とする決定を Feishu/Lark カードとして携帯へプッシュし、判定が stdout に戻るまでブロックします。人間がプロジェクトの Feishu グループで送るメッセージ、画像、ファイル、音声メモはエージェントセッションに指示として届きます。エージェント単独で解決できない選択肢（要件の不整合、実際の意見の対立、技術選択など）で、人間がキーボードから離れていることもあります。いつ問い合わせるかは呼び出し元のポリシーです――このスキルは呼び出しを提供し、トリガーは提供しません。また、ワンウェイ通知（notify）やファイル送信（send‑file）を同じグループにプッシュすることも可能です。
