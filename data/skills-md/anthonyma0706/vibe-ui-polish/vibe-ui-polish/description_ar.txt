استخدم عند تحسين أو مراجعة واجهة أمامية مُولدة بواسطة الذكاء الاصطناعي (برمجة الفايب): أزل الإحساس بالذكاء الاصطناعي، وحدّث التباعد، نصف قطر الزوايا، حجم الخط، الألوان، الظلال، والرسوم المتحركة، وأكمل حالات الواجهة والنصوص، وقدم عبارات توجيهية وقائمة مراجعة يمكن نسخها مباشرة إلى Codex أو Claude Code.
