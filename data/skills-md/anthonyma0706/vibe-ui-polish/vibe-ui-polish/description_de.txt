Wenn Sie die Frontend-Schnittstelle von KI-generierten (Vibe-Codierung) Projekten optimieren oder überprüfen, entfernen Sie das "KI-Gefühl", standardisieren Sie den Abstand, den Eckenradius, die Schriftgröße, die Farbe, den Schatten und die Bewegungseffekte, füllen Sie fehlende Zustände aus und kopieren Sie sie und stellen Sie Eingabeaufforderungen und eine Checkliste bereit, die direkt in Codex / Claude Code kopiert werden können.
