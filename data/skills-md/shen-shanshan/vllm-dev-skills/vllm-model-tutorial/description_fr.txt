Générez des documents de tutoriel technique chinois détaillés pour des modèles vLLM spécifiques (par ex. Qwen3-VL, DeepSeek-V3, Llama 4, InternVL3, etc.). Produit des guides approfondis du modèle incluant des diagrammes d'architecture Mermaid, des tableaux comparatifs, des flux de pré‑traitement des entrées, une analyse du passage avant, le calcul ViT (pour les VLM), une analyse de l'implémentation du code vLLM et des explications des principes techniques (MoE, MLA, Gated Attention, ViT, DiT, etc.). La sortie est enregistrée au format Markdown dans le répertoire outputs/ de la compétence. DÉclenchez lorsque : l'utilisateur demande à en savoir plus sur un modèle vLLM spécifique (par ex. « 我想了解 vllm 中的 Qwen3-VL », « 帮我生成 Qwen3-VL 的模型教程 », « generate a model tutorial for InternVL3 in vllm », « vllm 中的 DeepSeek-V3 是怎么实现的 », « 写一个 Llama 4 的vllm教程 »). NE DÉCLENCHEZ PAS lorsque : l'utilisateur interroge sur des modèles non‑vLLM, pose des questions générales sur les LLM sans demander de tutoriel, ou s'enquiert des fonctionnalités/modules de vLLM sans préciser de modèle.

Veuillez toujours répondre dans la langue de l'utilisateur.
