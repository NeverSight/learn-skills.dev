Преобразовать исходные документы (.doc/.docx/.pdf/.pptx/.pptm/.xlsx/.html/...) в готовый к загрузке Markdown для вики‑хранилища: сырая конверсия, аннотации контроля качества, проверка человеком, затем чистый файл для вики‑загрузки. Только предварительная конверсия — страницы никогда не помещаются в вики. Факты, требующие проверки, отмечаются, но не проверяются автоматически. Триггеры: convert to markdown, doc pipeline, konvertiere für ingest, QC dieses Dokument, ingest‑fertig machen.
