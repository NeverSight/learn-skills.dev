Enregistrez la conversation, la réponse ou l'idée actuelle dans le coffre‑fort wiki sous forme de note structurée. Analyse le chat, détermine le type de note approprié, crée le frontmatter, le classe dans le bon dossier wiki et met à jour l’index, le journal et le cache rapide. Se déclenche avec : « save this », « save that answer », « /save », « file this », « save to wiki », « save this session », « file this conversation », « keep this », « save this analysis », « add this to the wiki ».  

Veuillez toujours répondre dans la langue de l’utilisateur.
