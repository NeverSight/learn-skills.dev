Agent de Reconnaissance de Données Statistiques Ouvertes Internationales. Lorsque la recherche nécessite une comparaison inter‑pays, ou que l'utilisateur n’est pas à Taïwan, déterminez quelle base de données internationale, quelle agence statistique du pays, et si les données peuvent être récupérées de façon programmatique. Sont intégrés des points d’accès testés, sans clé (World Bank, Eurostat, ILOSTAT, FMI, UN Data) et des scripts de récupération, ainsi qu’une méthodologie en cinq étapes pour « comment trouver l’agence statistique officielle de n’importe quel pays » qui ne repose pas sur la mémorisation d’une liste de pays. La valeur principale réside dans l’avertissement sur les pièges des données transnationales : trois jeux de codes pays ne doivent pas être mélangés, le choix de la monnaie, du PPA et de l’année de base, les différences d’exercice fiscal, les classifications industrielles (ISIC/NACE/NAICS) ne peuvent pas être mappées directement, les lacunes de couverture ne sont pas aléatoires et entraînent un biais de sélection, et les statistiques agrégées peuvent être révisées rétroactivement, il faut donc enregistrer la date de récupération. Quand l’utiliser : pour des études inter‑pays, lorsque des données comparatives internationales sont nécessaires, pour vérifier si un pays possède des statistiques officielles, et pour les utilisateurs non‑taïwanais afin d’utiliser cette famille de compétences. Mots déclencheurs : inter‑pays, comparaison internationale, World Bank, OCDE, FMI, Eurostat, ILOSTAT, Organisation internationale du Travail, UN Data, FRED, statistiques nationales, bureaux nationaux de statistique, SDMX, données transnationales, bases de données internationales, données étrangères, statistiques étrangères, PPA, pouvoir d’achat. Limite avec les sources statistiques officielles de Taïwan : il existe une compétence distincte dédiée aux statistiques officielles approfondies de Taïwan ; cette compétence traite des données hors Taïwan et transnationales ; **les données Taïwan sont toujours dirigées vers cette compétence**. Limite avec l’intégrateur de données multi‑sources : lorsque des données provenant de plusieurs pays et sources ont été récupérées et doivent être fusionnées et intégrées, les transmettre à cet outil.
