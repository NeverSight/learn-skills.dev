Fassen Sie die von einer Person verfasste Pull-Request-Arbeit über einen Tag oder einen längeren Zeitraum in prägnantem Markdown zusammen, optional angereichert mit Tracker-Aktivitäten. Verwenden Sie diese Option, wenn ein Benutzer fragt, woran er gearbeitet hat, ein Standup-Update, eine tägliche oder wöchentliche Zusammenfassung, einen Sprint- oder Monatsrückblick anfordert oder nach PR-Aktivitäten für ein Datum oder einen Zeitraum wie gestern, letzten Freitag, diese Woche oder die letzten zwei Wochen fragt. Durchsucht standardmäßig alle zugänglichen Repositorys, behandelt Nachtarbeit als Teil des vorherigen Arbeitstags und verwendet den aktuellsten vorherigen Arbeitstag mit Aktivität, wenn kein Datum angegeben ist.
