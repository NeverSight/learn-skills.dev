Testare le implementazioni UI per correttezza funzionale, problemi di cross‑browser, casi limite e regressioni visive. Usa questa capacità quando l'utente vuole testare, fare QA, verificare o convalidare un'implementazione UI. Questo include test funzionali, controlli di regressione visiva, test cross‑browser, test responsive, identificazione di casi limite o qualsiasi compito di assicurazione della qualità. Attiva anche quando l'utente dice “test this”, “check if this works”, “QA this page”, “find bugs”, “verify the implementation” o “does this work on mobile”.

Rispondi sempre nella lingua dell'utente.
