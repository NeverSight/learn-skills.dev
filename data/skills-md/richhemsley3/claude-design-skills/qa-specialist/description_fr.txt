Testez les implémentations d’interface utilisateur pour la correction fonctionnelle, les problèmes inter‑navigateurs, les cas limites et les régressions visuelles. Utilisez cette compétence lorsque l’utilisateur souhaite tester, QA, vérifier ou valider une implémentation d’interface utilisateur. Cela comprend les tests fonctionnels, les vérifications de régression visuelle, les tests inter‑navigateurs, les tests réactifs, l’identification de cas limites ou toute tâche d’assurance qualité. Déclenchez également lorsque l’utilisateur dit « test this », « check if this works », « QA this page », « find bugs », « verify the implementation » ou « does this work on mobile ». Veuillez toujours répondre dans la langue de l’utilisateur.
