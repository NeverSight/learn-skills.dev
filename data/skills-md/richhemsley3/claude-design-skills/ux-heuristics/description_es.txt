Evalúe los diseños de UI e implementaciones contra los principios de UX establecidos. Use esta habilidad cuando el usuario quiera una evaluación heurística de UX, una revisión de usabilidad, una crítica de UX o un análisis de un diseño según las mejores prácticas. Los disparadores incluyen: “evaluar el UX”, “evaluación heurística”, “revisión de UX”, “crítica de usabilidad”, “¿sigue las mejores prácticas de UX?”, “¿qué problemas de UX ves?”, “critica este diseño”, “revisa este flujo”, o cuando el usuario proporcione una captura de pantalla o un archivo HTML y solicite retroalimentación de UX. También se activa cuando los usuarios hacen referencia a heurísticas específicas como “visibilidad del estado del sistema”, “Ley de Fitts”, “Ley de Hick”, “carga cognitiva”, o cualquiera de las heurísticas de Nielsen o Leyes de UX por su nombre.  

Por favor, responda siempre en el idioma del usuario.
