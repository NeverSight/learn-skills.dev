Valuta i design UI e le implementazioni rispetto ai principi UX consolidati. Usa questa competenza quando l'utente desidera una valutazione euristica UX, una revisione di usabilità, una critica UX o un'analisi di un design rispetto alle migliori pratiche. I trigger includono: “valuta l’UX”, “valutazione euristica”, “revisione UX”, “critica di usabilità”, “segue le migliori pratiche UX”, “quali problemi UX vedi”, “critica questo design”, “rivedi questo flusso”, o quando l'utente fornisce uno screenshot o un file HTML e chiede un feedback UX. Attiva anche quando gli utenti fanno riferimento a euristiche specifiche come “visibilità dello stato del sistema”, “legge di Fitts”, “legge di Hick”, “carico cognitivo”, o una qualsiasi delle euristiche di Nielsen o delle Leggi dell'UX per nome.

Rispondi sempre nella lingua dell'utente.
