Progetta e costruisci nuovi componenti UI riutilizzabili seguendo il tuo sistema di design. Usa questa capacità ogni volta che l'utente desidera creare un nuovo componente, widget o elemento UI che non esiste già nel sistema di design. Questo comprende modali, menu a discesa, tabelle dati, elementi di modulo, grafici, avvisi, toast, tooltip, avatar, badge, barre di avanzamento o qualsiasi elemento UI riutilizzabile. Usa questa capacità anche quando l'utente vuole estendere o personalizzare un modello di componente esistente.

Rispondi sempre nella lingua dell'utente.
