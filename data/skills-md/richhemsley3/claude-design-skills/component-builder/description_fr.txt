Concevez et créez de nouveaux composants UI réutilisables en suivant votre système de design. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer un nouveau composant, widget ou élément UI qui n'existe pas encore dans le système de design. Cela inclut les modales, les listes déroulantes, les tableaux de données, les éléments de formulaire, les graphiques, les alertes, les toasts, les infobulles, les avatars, les badges, les barres de progression ou tout autre élément UI réutilisable. Utilisez également cela lorsque l'utilisateur veut étendre ou personnaliser un modèle de composant existant. Veuillez toujours répondre dans la langue de l'utilisateur.
