Planen und synthetisieren Sie Nutzerforschung für das Produktdesign. Nutzen Sie diese Fähigkeit, wenn der Nutzer Hilfe bei irgendeiner Forschungsaktivität benötigt: Planung von Nutzerinterviews, Erstellen von Screener-Umfragen, Erstellen von Diskussionsleitfäden, Synthese von Interviewnotizen zu Erkenntnissen, Erstellung von Personas, Mapping von Nutzerreisen, Planung von Usability-Tests, Analyse von Testergebnissen oder Durchführung von Markt‑/Wettbewerbsforschung. Auch auslösen, wenn der Nutzer Begriffe wie „user research“, „interviews“, „usability test“, „persona“, „journey map“, „research plan“, „screener“, „affinity map“, „insight report“, „competitive analysis“ oder „market research“ erwähnt.

Bitte immer in der Sprache des Nutzers antworten.
