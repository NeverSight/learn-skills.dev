قم برسم خرائط رحلات المستخدم، تدفقات الشاشات، وسلاسل التفاعل لتطبيقات الويب. استخدم هذه المهارة عندما يرغب المستخدم في التخطيط لكيفية تنقل المستخدمين عبر الشاشات، تعريف سير عمل متعدد الخطوات، رسم خرائط رحلات المستخدم، تصميم هياكل التنقل، أو التفكير في تدفقات التفاعل. يشمل ذلك تدفقات الإعداد الأولي، عمليات الدفع، سير عمل CRUD، إدارة الإعدادات، مسارات استعادة الأخطاء، أو أي تجربة مستخدم متعددة الشاشات. كما يتم التفعيل عندما يذكر المستخدم "user flow" أو "screen flow" أو "journey map" أو "interaction design" أو "workflow". يرجى دائمًا الرد بلغة المستخدم.
