Audita el código UI existente para garantizar la consistencia con tu sistema de diseño. Utiliza esta habilidad siempre que el usuario quiera revisar, auditar, comprobar o validar su implementación UI según los estándares del sistema de diseño. Esto incluye verificar valores de color en bruto en lugar de tokens, estados faltantes, inconsistencias de espaciado, brechas de accesibilidad, problemas de soporte para modo oscuro o cumplimiento general del sistema de diseño. También activa esto cuando el usuario dice cosas como «¿se ve bien esto?», «revisa mi CSS», «comprueba este componente», «audita mi código UI» o «¿esto sigue el sistema de diseño?». Por favor, responde siempre en el idioma del usuario.
