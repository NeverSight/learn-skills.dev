Auditez le code UI existant pour vérifier sa cohérence avec votre système de design. Utilisez cette compétence chaque fois que l'utilisateur souhaite examiner, auditer, vérifier ou valider son implémentation UI par rapport aux normes du système de design. Cela comprend la vérification des valeurs de couleur brutes au lieu de tokens, les états manquants, les incohérences d’espacement, les lacunes d’accessibilité, les problèmes de prise en charge du mode sombre ou la conformité générale au système de design. Activez également cette fonction lorsque l'utilisateur dit des choses comme « cela a-t-il l’air correct », « examinez mon CSS », « vérifiez ce composant », « auditez mon code UI » ou « cela suit‑il le système de design ».

Veuillez toujours répondre dans la langue de l'utilisateur.
