Rédigez les textes d’interface, microtextes, messages d’erreur, états vides, infobulles, libellés de boutons et dialogues de confirmation. Utilisez cette compétence lorsque l’utilisateur a besoin d’aide pour écrire le texte qui apparaît dans une interface utilisateur — y compris les titres de pages, les descriptions, les libellés de formulaires, le texte d’aide, les messages de succès/erreur, le texte d’onboarding, les messages d’état vide, les notifications toast, les fenêtres modales ou tout texte destiné à l’utilisateur. Déclenchez‑la également lorsque l’utilisateur dit « rédige le texte pour », « que devrait dire cela », « message d’erreur pour » ou « texte d’état vide ».

Veuillez toujours répondre dans la langue de l’utilisateur.
