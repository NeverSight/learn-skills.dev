Entwerfe vollständige Seitenlayouts mit deinem Designsystem. Nutze diese Fähigkeit immer dann, wenn der Benutzer eine neue Seite, einen Bildschirm oder eine Ansicht für eine Webanwendung planen, entwerfen oder layouten möchte. Das umfasst Dashboard‑Layouts, Einstellungen‑Seiten, Listen‑/Detail‑Ansichten, Formularseiten, Landing‑Pages oder jede Anfrage, bei der entschieden werden soll, wie Inhalte und Komponenten auf einer Seite angeordnet werden. Aktiviere dies sogar, wenn der Benutzer sagt: „Ich brauche eine neue Seite für X“, „Gestalte das Layout für Y“ oder „Wie sollte diese Seite strukturiert sein?“.

Bitte antworte stets in der Sprache des Benutzers.
