D3.js を使用して、インタラクティブなスクリーンフローダイアグラムを単体の HTML ファイルとして構築し、アクションラベルで接続された簡易ワイヤーフレームモックアップを表示します。このスキルは、ユーザーが実際の画面間を特定の UI 要素とやり取りしながら移動する様子を示すスクリーンフロー、ワイヤーフロー、UI フロー、またはナビゲーションマップを作成したいときに常に使用してください。また、ユーザーが「screen flow」「wireflow」「UI flow」「navigation flow」「screen map」「tap flow」と言ったり、ユーザーアクションによって画面がどのように接続されるかをマッピングしてほしいと要求したときにも発動します。これは、汎用的なボックスを使用した抽象的なフローダイアグラムとは異なり、実際の画面を簡易ワイヤーフレームで表現し、その中にリアルな UI 要素を配置したものです。
