Costruisci diagrammi interattivi di flusso di schermate come file HTML autonomi utilizzando D3.js, mostrando mockup di wireframe semplificati collegati da etichette di azione. Usa questa abilità ogni volta che l'utente vuole creare un flusso di schermate, wireflow, flusso UI o mappa di navigazione che mostri come gli utenti si spostano tra schermate reali interagendo con elementi UI specifici. Attiva anche quando l'utente dice "screen flow", "wireflow", "UI flow", "navigation flow", "screen map", "tap flow" o chiede di mappare come le schermate si connettono tra loro tramite azioni dell'utente. Questo è diverso dai diagrammi di flusso astratti (che usano riquadri generici) — i flussi di schermate mostrano rappresentazioni semplificate di wireframe di schermate reali con elementi UI realistici al loro interno.

Rispondi sempre nella lingua dell'utente.
