أنشئ مخططات تدفق شاشات تفاعلية كملفات HTML مستقلة باستخدام D3.js، تُظهر نماذج أسلاك مبسطة متصلة بتسميات الإجراءات. استخدم هذه المهارة كلما أراد المستخدم إنشاء تدفق شاشات أو تدفق أسلاك أو تدفق واجهة مستخدم أو خريطة تنقل تُظهر كيف ينتقل المستخدمون بين الشاشات الفعلية عبر التفاعل مع عناصر واجهة محددة. قم أيضًا بالتفعيل عندما يذكر المستخدم "تدفق الشاشة" أو "تدفق الأسلاك" أو "تدفق واجهة المستخدم" أو "تدفق التنقل" أو "خريطة الشاشة" أو "تدفق النقر" أو يطلب رسم كيفية اتصال الشاشات ببعضها عبر إجراءات المستخدم. هذا يختلف عن مخططات التدفق التجريدية (التي تستخدم صناديق عامة) — تدفقات الشاشات تُظهر تمثيلات أسلاك مبسطة للشاشات الفعلية مع عناصر واجهة واقعية داخلها.
