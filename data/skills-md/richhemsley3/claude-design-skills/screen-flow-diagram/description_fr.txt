Construisez des diagrammes de flux d’écran interactifs sous forme de fichiers HTML autonomes en utilisant D3.js, affichant des maquettes filaires simplifiées reliées par des libellés d’action. Utilisez cette compétence chaque fois que l’utilisateur souhaite créer un flux d’écran, un wireflow, un flux UI ou une carte de navigation montrant comment les utilisateurs se déplacent entre des écrans réels en interagissant avec des éléments UI spécifiques. Déclenchez également lorsque l’utilisateur dit « screen flow », « wireflow », « UI flow », « navigation flow », « screen map », « tap flow », ou demande de cartographier la manière dont les écrans sont connectés les uns aux autres par des actions utilisateur. Cela diffère des diagrammes de flux abstraits (qui utilisent des boîtes génériques) — les flux d’écran affichent des représentations filaires simplifiées d’écrans réels avec des éléments UI réalistes à l’intérieur. Veuillez toujours répondre dans la langue de l’utilisateur.
