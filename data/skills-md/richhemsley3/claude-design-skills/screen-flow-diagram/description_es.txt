Cree diagramas interactivos de flujo de pantalla como archivos HTML independientes utilizando D3.js, mostrando maquetas de wireframe simplificadas conectadas por etiquetas de acción. Use esta habilidad siempre que el usuario quiera crear un flujo de pantalla, wireflow, flujo UI o mapa de navegación que muestre cómo los usuarios se desplazan entre pantallas reales al interactuar con elementos UI específicos. También active la funcionalidad cuando el usuario diga “screen flow”, “wireflow”, “UI flow”, “navigation flow”, “screen map”, “tap flow”, o solicite mapear cómo se conectan las pantallas entre sí mediante acciones de usuario. Esto es diferente de los diagramas de flujo abstractos (que usan cajas genéricas): los flujos de pantalla muestran representaciones de wireframe simplificadas de pantallas reales con elementos UI realistas dentro de ellas.

Por favor, responda siempre en el idioma del usuario.
