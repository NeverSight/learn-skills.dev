Construisez des cartes interactives du parcours client sous forme de fichiers HTML autonomes avec D3.js. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer une carte du parcours, une carte d'expérience, un blueprint de service ou une visualisation de l'expérience client montrant les phases, les points de contact, les émotions, les points de douleur et les opportunités. Activez également lorsque l'utilisateur dit « journey map », « customer journey », « experience map », « CX map », « service blueprint », « touchpoint map », ou demande de visualiser l'expérience de bout en bout d'un utilisateur à travers les étapes. Il s'agit d'autre chose que les diagrammes de flux — les cartes de parcours se concentrent sur la couche émotionnelle et expérientielle de la relation d'un utilisateur avec un produit, pas seulement sur la navigation écran par écran.

Veuillez toujours répondre dans la langue de l'utilisateur.
