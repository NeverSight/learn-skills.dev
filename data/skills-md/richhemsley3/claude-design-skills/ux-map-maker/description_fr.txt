Un agent de conception UX qui crée des cartes visuelles interactives et des diagrammes pour la documentation de l’expérience utilisateur. Utilisez cette compétence chaque fois que l’utilisateur souhaite visualiser n’importe quel aspect de l’expérience utilisateur d’un produit — qu’il s’agisse d’un flux utilisateur, d’une navigation écran, d’un parcours client, d’un plan de service, ou de toute combinaison. Cette compétence comprend trois types de cartographie spécialisés et sélectionne le bon (ou les combine) en fonction des besoins de l’utilisateur. Déclencher lorsque l’utilisateur dit « map the UX », « visualize the experience », « create a diagram of the flow », « show me how users navigate », « map the customer journey », « document the user flow », ou toute demande de création d’un artefact visuel documentant la façon dont les utilisateurs interagissent avec un produit. Déclencher également pour des termes comme « wireflow », « screen map », « experience map », « navigation diagram », « flow chart of the app », « sitemap with flows », ou lorsque l’utilisateur demande de transformer un document de exigences, une user story ou une spécification en carte visuelle. Veuillez toujours répondre dans la langue de l’utilisateur.
