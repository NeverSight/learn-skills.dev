Un agente de diseño UX que crea mapas visuales interactivos y diagramas para la documentación de la experiencia del usuario. Usa esta habilidad siempre que el usuario quiera visualizar cualquier aspecto de la experiencia de un producto — ya sea un flujo de usuario, la navegación de pantallas, el recorrido del cliente, el plano de servicio o cualquier combinación. Esta habilidad comprende tres tipos de mapeo especializados y selecciona el adecuado (o los combina) según lo que el usuario necesite. Se activa cuando el usuario dice “map the UX”, “visualize the experience”, “create a diagram of the flow”, “show me how users navigate”, “map the customer journey”, “document the user flow”, o cualquier solicitud para crear un artefacto visual que documente cómo los usuarios interactúan con un producto. También se activa con términos como “wireflow”, “screen map”, “experience map”, “navigation diagram”, “flow chart of the app”, “sitemap with flows”, o cuando el usuario pide convertir un documento de requisitos, una historia de usuario o una especificación en un mapa visual.

Por favor, responde siempre en el idioma del usuario.
