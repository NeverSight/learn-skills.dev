Crea diagramas interactivos de flujo de usuario como archivos HTML independientes usando D3.js. Utiliza esta habilidad siempre que el usuario quiera crear un flujo de usuario visual, diagrama de interacción, mapa de flujo de pantalla o visualización de flujo de trabajo. También se activa cuando el usuario dice “diagrama de flujo”, “flujo interactivo”, “flujo de usuario”, “gráfico de flujo”, o pide convertir un flujo/recorrido en algo visual y exploratorio. Esto es distinto de los diagramas estáticos de Mermaid: úsalo cuando el usuario quiera una visualización rica, interactiva y basada en el navegador que pueda desplazar, desplazarse y explorar.

Por favor, responde siempre en el idioma del usuario.
