Diseño estratégico de producto para software de gestión de datos — definición de características, síntesis de investigación de usuarios, análisis competitivo y justificación de diseño. Utilice esta habilidad cuando el usuario necesite reflexionar sobre decisiones de diseño a nivel de producto para aplicaciones que gestionan datos: tablas, filtros, flujos CRUD, operaciones masivas, importación/exportación de datos, búsqueda, catálogos, paneles de control o permisos. También actívela cuando el usuario diga “cómo debería funcionar esta característica”, “cuál es el mejor patrón para”, “diseña esta característica”, “requisitos de producto para”, o necesite tomar decisiones estratégicas de UX sobre aplicaciones con gran cantidad de datos.
