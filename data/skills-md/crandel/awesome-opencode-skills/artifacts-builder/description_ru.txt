Набор инструментов для создания сложных, многокомпонентных артефактов OpenCode HTML с использованием современных технологий фронтенда (React, Tailwind CSS, shadcn/ui). Используйте для сложных артефактов, требующих управления состоянием, маршрутизации или компонентов shadcn/ui — не для простых однофайловых HTML/JSX артефактов.
