Los encabezados son Antecedentes, Decisiones de diseño, Cambios, Verificación realizada y Operaciones posteriores a la fusión. Cuando crees, abras, envíes o actualices una solicitud de extracción, usa esta habilidad. Úselo para una descripción de relaciones públicas o para crear gh pr. No utilice esta habilidad solo para enviar mensajes.
