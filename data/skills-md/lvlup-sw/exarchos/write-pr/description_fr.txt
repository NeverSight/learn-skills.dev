Rédigez un corps de pull request GitHub concis avec cinq sections. Les sections sont Contexte, Décisions de conception, Modifications, Vérifications effectuées et Opérations post-fusion. Lorsque vous créez, ouvrez, soumettez ou mettez à jour une pull request, utilisez cette compétence. Utilisez‑la pour la description d’une PR ou pour `gh pr create`. N’utilisez pas cette compétence pour les messages de commit uniquement.

Veuillez toujours répondre dans la langue de l’utilisateur.
