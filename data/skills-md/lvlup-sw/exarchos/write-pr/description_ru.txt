Составьте лаконичное тело GitHub pull request с пятью заголовками. Заголовки: Background, Design Decisions, Changes, Verification Performed и Post-Merge Operations. При создании, открытии, отправке или обновлении pull request используйте этот навык. Применяйте его для описания PR или для команды gh pr create. Не используйте этот навык только для сообщений коммитов.
