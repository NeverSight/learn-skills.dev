Schreiben Sie einen prägnanten GitHub-Pull-Request-Text mit fünf Überschriften. Die Überschriften sind Hintergrund, Designentscheidungen, Änderungen, durchgeführte Verifizierung und Post-Merge-Operationen. Verwenden Sie diese Fähigkeit, wenn Sie eine Pull-Anforderung erstellen, öffnen, übermitteln oder aktualisieren. Verwenden Sie es für eine PR-Beschreibung oder für gh pr create. Verwenden Sie diese Fähigkeit nicht nur für Commit-Nachrichten.
