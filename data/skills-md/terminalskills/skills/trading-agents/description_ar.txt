TradingAgents هو إطار عمل مفتوح المصدر متعدد الوكلاء يعتمد على نماذج اللغة الكبيرة (LLM) يقوم بتحليل رمز السهم أو العملة المشفرة باستخدام وكلاء محلل، وباحث صاعد/هابط، ومتداول، ووكلاء المخاطر وإدارة المحافظ، ويعيد قرار تداول مصنف. يُستخدم عند تشغيل TradingAgents من خلال واجهة سطر الأوامر أو API بايثون، أو ضبط مزودي LLM ومزودي البيانات، أو اختبار قراراته السابقة، أو بناء خط أنابيب تحليل مالي متعدد الوكلاء مشابه باستخدام LangGraph.
