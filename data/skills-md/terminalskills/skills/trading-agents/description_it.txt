TradingAgents è un framework LLM multi‑agente open‑source che analizza un ticker di azioni o criptovalute con agenti analista, ricercatore rialzista/ribassista, trader, rischio e gestore di portafoglio e restituisce una decisione di trading valutata. Usalo quando esegui TradingAgents dalla sua CLI o API Python, configurando i fornitori LLM e i fornitori di dati, effettuando backtesting delle sue decisioni passate, o costruendo una pipeline di analisi finanziaria multi‑agente simile con LangGraph.
