Appsmith هي منصة منخفضة الكود مفتوحة المصدر لبناء الأدوات الداخلية ولوحات الإدارة ولوحات المعلومات. استخدمها عندما يطلب المستخدم إنشاء واجهات CRUD، أو الاتصال بقاعدة البيانات أو واجهات برمجة التطبيقات باستخدام أدوات السحب والإفلات، أو كتابة كائنات JS للمنطق التجاري، أو استضافة Appsmith ذاتيًا باستخدام Docker أو Kubernetes.
