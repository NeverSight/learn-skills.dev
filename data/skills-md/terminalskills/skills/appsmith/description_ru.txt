Appsmith — это открытая low‑code платформа для создания внутренних инструментов, административных панелей и дашбордов. Используйте её, когда пользователь просит создать CRUD‑интерфейсы, подключить базы данных или API с помощью перетаскиваемых виджетов, написать JSObject‑ы для бизнес‑логики или развернуть Appsmith самостоятельно с помощью Docker или Kubernetes.
