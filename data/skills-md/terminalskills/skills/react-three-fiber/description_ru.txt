Создаёт 3D‑сцены в React с помощью React Three Fiber (R3F), рендерера React для Three.js, где меши, источники света и камеры представлены JSX‑компонентами. Используйте, когда пользователь просит добавить 3D‑сцену на сайт на React или Next.js, построить конфигуратор продукта, загрузить модель GLTF, анимировать её с помощью useFrame, обработать клики и наведение на 3D‑объектах или ускорить медленную сцену R3F.
