يبني مشاهد ثلاثية الأبعاد في React باستخدام React Three Fiber (R3F)، وهو مُعرّف React لـ Three.js حيث تكون الشبكات والإضاءة والكاميرات مكوّنات JSX. استخدمه عندما يطلب المستخدم إضافة مشهد ثلاثي الأبعاد إلى موقع React أو Next.js، بناء مكوّن تخصيص منتج، تحميل نموذج GLTF، التحريك باستخدام useFrame، التعامل مع النقر والتمرير على الكائنات الثلاثية الأبعاد، أو تسريع مشهد R3F البطيء.
