Crée des scènes 3D dans React avec React Three Fiber (R3F), un moteur de rendu React pour Three.js où les maillages, les lumières et les caméras sont des composants JSX. Utilisez-le lorsqu’un utilisateur demande d’ajouter une scène 3D à un site React ou Next.js, de créer un configurateur de produit, de charger un modèle GLTF, d’animer avec useFrame, de gérer le clic et le survol sur les objets 3D, ou d’accélérer une scène R3F lente.
