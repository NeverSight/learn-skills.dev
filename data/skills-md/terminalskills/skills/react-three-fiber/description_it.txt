Costruisce scene 3D in React con React Three Fiber (R3F), un renderer React per Three.js in cui mesh, luci e telecamere sono componenti JSX. Usalo quando un utente chiede di aggiungere una scena 3D a un sito React o Next.js, di creare un configuratore di prodotto, caricare un modello GLTF, animare con useFrame, gestire click e hover su oggetti 3D, o velocizzare una scena R3F lenta.
