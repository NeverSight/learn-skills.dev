Tauri crea aplicaciones de escritorio y móviles a partir de un frontend web y un backend en Rust, renderizando la interfaz de usuario en la vista web del sistema operativo en lugar de un Chromium empaquetado. Úsalo al crear o ampliar una aplicación Tauri v2: generar la estructura con create-tauri-app, escribir comandos en Rust y llamarlos con invoke, enviar eventos o datos de canal al frontend, añadir plugins, corregir errores de permiso “not allowed” en las capacidades, empaquetar instaladores o distribuir actualizaciones automáticas firmadas. Palabras clave: tauri, tauri v2, tauri command, tauri plugin, capabilities, system webview, rust desktop app.
