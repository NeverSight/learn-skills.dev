Tauri는 웹 프론트엔드와 Rust 백엔드를 사용하여 데스크톱 및 모바일 앱을 구축하며, 번들된 Chromium 대신 운영 체제의 웹뷰에서 UI를 렌더링합니다. Tauri v2 앱을 만들거나 확장할 때 사용하세요: create‑tauri‑app으로 스캐폴딩하기, Rust 명령을 작성하고 invoke로 호출하기, 이벤트나 채널 데이터를 프론트엔드에 푸시하기, 플러그인 추가하기, capabilities에서 “허용되지 않음” 권한 오류 수정하기, 설치 프로그램을 번들링하거나 서명된 자동 업데이트를 배포하기. 트리거 단어: tauri, tauri v2, tauri command, tauri plugin, capabilities, system webview, rust desktop app.
