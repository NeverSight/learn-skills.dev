Tauri 從 Web 前端與 Rust 後端構建桌面與行動應用，將 UI 渲染於作業系統的 webview，而非捆綁的 Chromium。使用情境包括建立或擴充 Tauri v2 應用：使用 create‑tauri‑app 產生腳手架、編寫 Rust 指令並以 invoke 呼叫、將事件或頻道資料推送至前端、加入插件、修復 capabilities 中的「不允許」權限錯誤、打包安裝程式，或發布簽名的自動更新。觸發詞：tauri、tauri v2、tauri command、tauri plugin、capabilities、system webview、rust desktop app。
