Tauri 使用网页前端和 Rust 后端构建桌面和移动应用，将 UI 渲染在操作系统的 WebView 中，而不是使用打包的 Chromium。适用于创建或扩展 Tauri v2 应用的场景：使用 create‑tauri‑app 搭建脚手架、编写 Rust 命令并通过 invoke 调用、向前端推送事件或通道数据、添加插件、在 capabilities 中修复 “not allowed” 权限错误、打包安装程序，或发布签名的自动更新。触发词：tauri、tauri v2、tauri command、tauri plugin、capabilities、system webview、rust desktop app。
