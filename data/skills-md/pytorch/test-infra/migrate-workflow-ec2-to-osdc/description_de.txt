Schritt-für-Schritt-Anleitung für die Migration eines pytorch/pytorch .github/workflows/*.yml von EC2 zu OSDC-(ARC)-Runnern – umfasst sowohl Dial-up- als auch 100 %-Opt-in-Muster mit den Inputs, die über _linux-build.yml / _linux-test.yml geleitet werden müssen. Verwenden Sie dieses Playbook, wenn Sie einen Workflow von EC2 auf ein lokales Rechenzentrum/von EKS gehostete, selbst gehostete Runner (OSDC/ARC) migrieren, das ARC-Experiment aktivieren oder die Eingaben `use-arc` / `runner_prefix` / `ci-docker-hash` / `python-version` / `compiler` / `cuda-version` verknüpfen.
