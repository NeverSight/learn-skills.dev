Crea videos narrados y subtitulados sin rostro con Go Motion (gomotion‑ai.app) a partir de una idea o un guion: escribe el guion, revísalo, produce la voz + subtítulos + metraje, exporta un MP4 de 1080 p con subtítulos SRT/VTT y descárgalo. Usa esto cuando el usuario solicite hacer, generar o renderizar un video, explicativo, video sin rostro, video de YouTube, Shorts, Reels o clip de TikTok, o para convertir texto, notas o una idea en un video; también para 做视频, 生成视频, 把文案做成视频, 解说视频, 口播视频. Necesita una clave API de Go Motion (GOMOTION_API_KEY); las cuentas nuevas empiezan con créditos gratuitos que cubren un video de un minuto, y cada paso de pago se cotiza y confirma antes de ejecutarse.

Por favor, responde siempre en el idioma del usuario.
