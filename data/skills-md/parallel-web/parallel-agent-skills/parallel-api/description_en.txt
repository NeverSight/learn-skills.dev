Build apps and agents on the Parallel API: Search, Extract, Responses, Task, Decisions and Monitor, through the parallel-web Python and TypeScript SDKs or REST. Use when writing, reviewing or debugging code that calls Parallel; when choosing a Parallel API, search mode, reasoning effort or Task processor; when adding web search, page extraction, cited answers, research, enrichment, web-grounded decisions or web monitoring to an app; when swapping another search provider for Parallel; when setting up PARALLEL_API_KEY; or when a Parallel request fails. Not for searching the web inside the agent's own session. To remove an existing Exa, Tavily, Perplexity or Firecrawl integration end to end, use migrate-to-parallel; to benchmark Parallel against another provider, use parallel-search-evaluation.
