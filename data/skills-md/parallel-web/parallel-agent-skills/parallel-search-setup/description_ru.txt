Используйте при проверке, эксплуатации или устранении неполадок анонимного сервера Parallel Search MCP, поставляемого с этим плагином — когда пользователь устанавливает плагин, говорит «настроить Parallel Search», «Parallel Search не работает», получает ограничения 429 от Parallel или спрашивает, как получить более высокие лимиты. Также охватывается использование инструментов web_search и web_fetch, предоставляемых сервером. Для аутентифицированного развертывания шлюза используйте parallel-mcp-setup; для навыков, работающих через CLI, — parallel-cli-setup.
