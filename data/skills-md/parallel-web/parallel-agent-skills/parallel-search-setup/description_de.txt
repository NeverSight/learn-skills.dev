Verwenden Sie dies beim Verifizieren, Verwenden oder Fehlersuchen des anonymen Parallel Search MCP‑Servers, der mit diesem Plugin gebündelt ist – wenn der Benutzer das Plugin installiert, „Parallel Search einrichtet“, „Parallel Search funktioniert nicht“, 429‑Rate‑Limits von Parallel erhält oder fragt, wie man höhere Limits bekommt. Außerdem wird erklärt, wie man die Werkzeuge web_search und web_fetch nutzt, die der gebündelte Server bereitstellt. Für eine authentifizierte Gateway‑Bereitstellung verwenden Sie parallel-mcp-setup; für die CLI‑basierten Fähigkeiten verwenden Sie parallel-cli-setup.
