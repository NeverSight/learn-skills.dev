このプラグインに同梱されている匿名の Parallel Search MCP サーバーを検証、使用、トラブルシューティングする際に使用します — ユーザーがプラグインをインストールしたときに「Parallel Search を設定して」や「Parallel Search が動作しない」と言ったとき、Parallel からの 429 レートリミットに達したとき、またはより高いリミットの取得方法を尋ねたときに使用します。また、同梱サーバーが提供する web_search および web_fetch ツールの使い方もカバーしています。認証されたゲートウェイデプロイの場合は parallel-mcp-setup を、CLI バックエンドのスキルの場合は parallel-cli-setup を使用してください。
