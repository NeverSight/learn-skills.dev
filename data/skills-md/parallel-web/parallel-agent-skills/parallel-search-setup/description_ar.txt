استخدمها عند التحقق أو الاستخدام أو استكشاف أخطاء خادم Parallel Search MCP المجهول المرفق مع هذا المكوّن الإضافي — عندما يقوم المستخدم بتثبيت المكوّن، أو يقول "إعداد Parallel Search"، أو "Parallel search لا يعمل"، أو يواجه حدود معدل 429 من Parallel، أو يسأل عن كيفية الحصول على حدود أعلى. كما تغطي كيفية استخدام أدوات web_search و web_fetch التي يوفرها الخادم المرفق. للنشر عبر بوابة مصادقة استخدم parallel-mcp-setup؛ للمهارات المدعومة من سطر الأوامر استخدم parallel-cli-setup.
