Utilisez‑le lors de la vérification, de l’utilisation ou du dépannage du serveur anonyme Parallel Search MCP fourni avec ce plugin — lorsque l’utilisateur installe le plugin, dit « configurer Parallel Search », « Parallel Search ne fonctionne pas », atteint les limites de taux 429 de Parallel, ou demande comment obtenir des limites plus élevées. Cela couvre également comment utiliser les outils web_search et web_fetch fournis par le serveur intégré. Pour un déploiement de passerelle authentifiée, utilisez parallel-mcp-setup  ; pour les compétences basées sur CLI, utilisez parallel-cli-setup.

Veuillez toujours répondre dans la langue de l’utilisateur.
