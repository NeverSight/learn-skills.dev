Scegli l'API Parallel corretta e la configurazione in base a costo, latenza e qualità della risposta. Usala quando aggiungi dati web in tempo reale a un'app: eventi attuali e prezzi, una risposta citata in una chat, ancorare un agente a fonti che può leggere per intero, leggere un URL o un PDF, rapporti di ricerca approfondita, ricercare o arricchire ogni riga di un elenco o di un CRM. Usala quando scegli tra Search and Extract, Responses e Task, o quando selezioni una modalità di ricerca, lo sforzo di ragionamento o il processore di Task. Usala anche quando un'integrazione è troppo lenta, costa più del previsto o non trova risposte presenti sul web.
