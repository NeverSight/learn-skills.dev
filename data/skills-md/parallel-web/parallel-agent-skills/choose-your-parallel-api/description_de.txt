Wählen Sie die passende Parallel‑API und Konfiguration hinsichtlich Kosten, Latenz und Antwortqualität. Verwenden Sie sie, wenn Sie Live‑Webdaten zu einer App hinzufügen: aktuelle Ereignisse und Preise, eine zitierte Antwort im Chat, die Basis eines Agenten in Quellen, die er vollständig lesen kann, das Lesen einer URL oder PDF, tiefgehende Forschungsberichte, das Recherchieren oder Anreichern jeder Zeile einer Liste oder eines CRM. Verwenden Sie sie, wenn Sie zwischen Search and Extract, Responses und Task wählen oder wenn Sie einen Suchmodus, den Aufwand für das Schlussfolgern oder den Task‑Prozessor auswählen. Nutzen Sie sie auch, wenn eine Integration zu langsam ist, mehr kostet als erwartet oder Antworten, die im Web vorhanden sind, verpasst.
