اختر واجهة برمجة التطبيقات المتوازية المناسبة والإعدادات الملائمة للتكلفة والكمون وجودة الإجابة. استخدمها عند إضافة بيانات ويب حية إلى التطبيق: الأحداث الجارية والأسعار، إجابة موثقة في محادثة، توثيق الوكيل بالمصادر التي يمكنه قراءتها بالكامل، قراءة عنوان URL أو ملف PDF، تقارير أبحاث عميقة، البحث أو إثراء كل صف في قائمة أو نظام إدارة علاقات العملاء. استخدمها عند الاختيار بين البحث والاستخلاص، الردود، والمهام، أو عند اختيار وضع البحث، جهد التفكير، أو معالج المهمة. استخدمها أيضًا عندما يكون التكامل بطيئًا، أو تكلفته أعلى مما هو متوقع، أو يفوت إجابات موجودة على الويب.
