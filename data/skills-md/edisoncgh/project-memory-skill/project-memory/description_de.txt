Stellen Sie persistente projektspezifische Erinnerung über Sitzungen hinweg sicher, indem Sie Markdown‑Dateien im .memory‑Verzeichnis lesen und schreiben. Verwenden Sie dies, wenn: ein neues Projekt begonnen wird, die Arbeit nach einer Pause fortgesetzt wird, der Benutzer sagt „erinnere dich daran“, „was haben wir bei X gemacht“, „vibe coding“, „behalte den Überblick“, „vergiss nicht“, „Projektkontext“, „was war die Entscheidung zu …“ oder bei jeglicher mehrstufigen Entwicklungsarbeit. Auslöser: project‑memory, vibe coding, remember, memory, context, continuity.

Bitte antworten Sie immer in der Sprache des Benutzers.
