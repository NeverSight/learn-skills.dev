Используйте это при: начале нового проекта, продолжении работы после перерыва, когда пользователь говорит «запомни это», «что мы сделали с X», «vibe coding», «следить», «не забудь», «контекст проекта», «какое было решение по…», или любой многократной разработке. Триггеры: project-memory, vibe coding, remember, memory, context, continuity.
