Maintenez une mémoire persistante au niveau du projet entre les sessions en lisant et en écrivant des fichiers markdown dans le répertoire .memory. Utilisez‑le lorsque : vous démarrez un nouveau projet, reprenez le travail après une pause, l'utilisateur dit « rappelle‑toi ça », « qu’avons‑nous fait concernant X », « codage vibe », « garder une trace », « n’oublie pas », « contexte du projet », « quelle était la décision sur… », ou tout travail de développement à plusieurs tours. Déclencheurs : project-memory, codage vibe, remember, memory, context, continuity. Veuillez toujours répondre dans la langue de l'utilisateur.
