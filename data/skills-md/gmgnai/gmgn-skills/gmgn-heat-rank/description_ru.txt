Составьте список токенов, которые актуальны ПРЯМО СЕЙЧАС и достаточно безопасны для просмотра, во всех цепочках, поддерживаемых GMGN, с рейтингом от 0 до 100 и ограниченным количеством десяти имен. Это навык отбора: он начинается без адреса, охватывает все семь цепочек, оценивает каждого кандидата по ликвидности/реальному объему/концентрации/риску безопасности, оценивает выживших по одной кросс-чейновой шкале и возвращает столько, сколько преодолеет нижний предел оценки – менее десяти на слабом рынке, никогда не дополняемое для заполнения квоты. ИСПОЛЬЗУЙТЕ ЭТОТ НАВЫК, КОГДА пользователю нужен тщательно подобранный горячий список, а не необработанные рейтинги: «热榜», «热门代币», «近期热门», «帮我抓一轮热榜», «现在有什么值得关注的热币», «全链热门币», «生成热榜», «有没有新的热门盘», «что сейчас актуально», «дайте мне горячий список», «какие трендовые токены на самом деле стоит посмотреть», «покажи мне список трендов». Здесь тоже идут те же вопросы, что и на любом другом языке: совпадение по смыслу, а не по формулировке. НЕ ИСПОЛЬЗУЙТЕ ЭТОТ НАВЫК для необработанного дампа рейтинга («покажите мне топ-20 по объему продаж в сол», «тренд за 1 час», «список горячего поиска») — это `gmgn-market Trending`/`hot-searches`, который возвращает нетронутый собственный порядок биржи; ни для недавно выпущенных токенов кривой облигаций («только что запущен», «pump.fun new», «新盘») — это «транши gmgn-market»; ни для одного адреса, который уже есть у пользователя («безопасен ли этот токен», «打个分», «尽调») — это `gmgn-contract-dd`; ни для чтения диаграммы ("走势怎么样", "什么形态") - это `gmgn-kline-pattern`; ни для поиска на ранней стадии ниже уровня этого навыка («值得埋伏吗», «新币筛选», «早期机会», «откройте для себя возможности на ранней стадии») — это «траншеи gmgn-рынка», потому что пул кандидатов здесь начинается с рыночной капитализации 500 тыс. и ликвидности 100 тыс. и никогда не содержит токена кривой облигаций; ни для взгляда на тот же рынок со стороны кошелька («聪明钱在买什么», «KOL 在买什么», «ончейн-альфа», «сигналы копирования») — это `gmgn-track smartmoney` / `kol`, который отвечает, кто покупает, а не на что стоит обратить внимание. Разделение происходит по тому, кто выбирает токены: если пользователь называет токен, это не этот навык; если пользователь просит выбрать навык, так и есть. Когда никто не называет токен и сама формулировка противоречит «gmgn-market» — «горячие монеты», «что качает», «трендовые токены», «热门币», «什么币在涨» — решающим критерием является форма запрашиваемого ответа: нетронутое ранжирование N строк в собственном порядке биржи — это «gmgn-market Trending»; Краткий список того, что выдержало врата риска, имеет оценку и на основании которого можно действовать, - это этот навык. Здесь простой двусмысленный вопрос без каких-либо других сигналов по умолчанию, потому что этот навык может указывать на необработанный рейтинг, в то время как необработанный рейтинг не может экранировать сам себя. Для его запуска ничего не нужно предоставлять — достаточно одной триггерной фразы, и никакой адрес, цепочка или сумма никогда не требуются. Когда пользователь просит об этом, можно сузить четыре параметра: какие цепочки очищаются, возрастной потолок, сколько имен возвращается и минимальный балл; любое значение, измененное таким образом, указывается в отчете.
