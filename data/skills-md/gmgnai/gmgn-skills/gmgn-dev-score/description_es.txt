Decide si el próximo lanzamiento de un creador de tokens es seguro para comprar. Puntúa una dirección de desarrollador de 0 a 100 en dos ejes separados — CONDUCTA (¿te hará un dump al abrir) y PODER (¿ha construido algo grande alguna vez) — a partir de todo su historial de lanzamientos y cada operación que haya realizado con sus propias monedas, y luego devuelve una recomendación de compra / no compra con una ventana de tiempo. UTILICE ESTA HABILIDAD CUANDO el usuario haga una pregunta de decisión de compra sobre un lanzador: "¿puedo comprar el nuevo lanzamiento de este dev?", "¿debería comprar su próximo lanzamiento?", "¿este dev hará rug?", "¿hará dump al abrir?", "¿es seguro hacer sniper a su lanzamiento?", "¿es seguro comprar en su apertura?", "puntuación dev", "puntuación creador", "puntuación lanzamiento", "¿es este lanzador lo suficientemente confiable para comprar?"; O cuando el usuario proporcione una dirección de TOKEN más una pregunta de confianza del equipo ("¿es confiable el equipo de este token?", "¿tiene historial este dev del proyecto?", "¿ha hecho rug este creador antes?") — primero resuelva el creador con `gmgn-cli token info` -> `dev.creator_address`, y luego puntúe esa dirección; O cuando el usuario proporcione una dirección de CARTERA más una pregunta explícita sobre el historial de lanzamientos ("¿qué tokens ha lanzado esta dirección?", "¿cómo fueron sus lanzamientos anteriores?", "¿todos sus tokens fueron a cero?"). Las mismas preguntas realizadas en cualquier otro idioma también se procesan aquí — coincidan con el significado, no con la redacción. NO UTILICE ESTA HABILIDAD para una dirección de cartera sin ninguna pregunta adjunta: una dirección aislada es una pregunta de copy‑trade por defecto y pertenece a gmgn-wallet-analysis, que se declara el predeterminado para ello. Tampoco la use para preguntas de copy‑trade ("¿vale la pena copiar esta cartera?", "¿debería copiar esta cartera?", "puntuación copy‑trade"), rentabilidad de la cartera ("¿es rentable esta cartera?", "¿cuál es el historial de esta cartera?") o formulaciones de perfil de cartera ("¿es esta una cartera de creador de tokens?", "¿cómo es la reputación de este dev?") — esas pertenecen a gmgn-wallet-score. La división se hace por tipo de pregunta, no por tipo de dirección: esas habilidades responden "¿quién es esta cartera?" (un perfil), esta habilidad responde "¿debería comprar su lanzamiento?" (una decisión, con una ventana de tiempo). Observe lo cercano que está "¿cómo es la reputación de este dev?" (perfil → gmgn‑wallet‑score) a "puntuación dev" (decisión → aquí): el factor decisivo es si hay una compra sobre la mesa. Si es realmente ambiguo, haga una pregunta corta en su lugar en lugar de adivinar — los dos generan informes diferentes y no hay una cobertura barata.
