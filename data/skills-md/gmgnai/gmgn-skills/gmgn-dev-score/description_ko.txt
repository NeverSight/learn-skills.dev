토큰 생성자의 NEXT 출시가 구매하기에 안전한지 결정하세요. 전체 출시 내역과 자신의 코인으로 수행한 모든 거래에서 CONDUCT(공개 시 당신에게 덤벼들 것인가)와 POWER(실제로 큰 것을 구축한 적이 있는가)라는 두 개의 개별 축에 대해 개발자 주소 0-100의 점수를 매긴 다음 타이밍 창을 사용하여 매수/매수 안 함 콜을 반환합니다. 사용자가 런처에 대해 구매 결정 질문을 할 때 이 기술을 사용하십시오: "이 개발자의 새로운 출시를 구매할 수 있습니까?", "다음 출시를 구매해야 할까요?", "이 개발 러그를 구매해야 할까요?", "공개 시 버릴까요?", "저희 출시가 저격해도 안전한가요?", "공개 시 구매하는 것이 안전한가요?", "개발 점수", "크리에이터 점수", "출시 점수", "이 런처가 구매할 만큼 신뢰할 수 있나요?" 또는 사용자가 TOKEN 주소와 팀 신뢰 질문("이 토큰의 팀을 신뢰할 수 있습니까?", "이 프로젝트의 개발자에게 기록이 있습니까?", "이 제작자가 이전에 견고했습니까?")을 제공하는 경우 — `gmgn-cli token info` -> `dev.creator_address`를 사용하여 제작자를 먼저 확인한 다음 해당 주소에 점수를 매깁니다. 또는 사용자가 WALLET 주소와 함께 명시적인 출시 내역 질문("이 주소에서 출시된 토큰은 무엇입니까?", "이전 출시는 어떻게 진행되었습니까?", "모든 코인이 0이 되었습니까?")을 제공하는 경우. 여기에서도 다른 언어 경로에서 동일한 질문을 합니다. 단어가 아닌 의미를 일치시킵니다. 질문이 첨부되지 않은 기본 지갑 주소에는 이 스킬을 사용하지 마세요. 기본 주소는 기본적으로 복사 거래 질문이며 gmgn-wallet-analytic에 속하며 기본값을 선언합니다. 또한 카피 트레이드 질문("이 지갑을 복사할 가치가 있습니까?", "이 지갑을 복사해야 합니까?", "카피 트레이드 점수"), 지갑 수익성("이 지갑이 수익성이 있습니까?", "이 지갑의 실적은 무엇입니까") 또는 지갑 프로필 문구("이것은 토큰 생성자 지갑입니까", "이 개발자의 평판은 어떻습니까")에 사용하지 마십시오. 이러한 내용은 gmgn-wallet-score에 속합니다. 분할은 주소 유형이 아닌 질문 유형별로 이루어집니다. 해당 스킬은 "이 지갑은 누구입니까?"(프로필)에 대답하고, 이 스킬은 "그의 출시를 구매해야 할까요?"(결정, 타이밍 창 포함)에 대답합니다. "이 개발자의 평판은 어떻습니까"(프로필 → gmgn-wallet-score)가 "개발자 점수"(결정 → 여기)에 얼마나 가까운지 확인하세요. 결정 요인은 구매가 테이블에 있는지 여부입니다. 정말로 모호한 경우 추측하는 대신 짧은 질문 하나를 하십시오. 두 질문은 서로 다른 보고서를 생성하며 값싼 헤지는 없습니다.
