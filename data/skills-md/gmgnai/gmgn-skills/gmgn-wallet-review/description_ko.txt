ONE 지갑 주소에 대한 짧은 거래 초상화 — 하나의 스타일 태그 (磨损户 / P小将 / 印钞机 … 그리고 속도 부제), 기록을 요약하는 한 문장과 다음 단계 조언을 한 문장, 1D / 7D / 30D / 전체에 대해, 사용자의 지갑이면 你, 다른 사람의 지갑이면 他 로 표기; SOL 및 모든 8개의 EVM 체인, 0x 주소는 체인이 자동 감지됨; 페이지 형태로 렌더링 가능. 사용 상황 — 지갑 주소와 함께 간단한 요약이나 변경 사항 요청이 있을 때 — 「帮我复盘一下这个钱包」, 「一句话总结他的战绩」, 「我的打法有什么问题」, 「我钱包下一步该怎么打」, 「交易画像」, 「钱包风格加建议，简短点」, "sum up this wallet in one line". 대상이 아닌 경우 — 단순 주소, 「能不能跟」 또는 「跟着他买我能吃到吗」 (gmgn-wallet-analysis); 전체 태그·배지 분석 또는 「是不是机器人」 (gmgn-wallet-style); 점수나 복제 거래 백테스트 (gmgn-wallet-score); 제작자의 런칭 (gmgn-dev-score); 현재 보유 현황 (gmgn-portfolio); 토큰 주소나 구매 (gmgn-contract-dd, gmgn-token-buy). 우선순위 — 打法 / 风格 / 战绩 가 문제, 조언, 복합 분석 또는 한 문장과 결합될 때 여기로 라우팅; 단독으로 물으면 위의 스킬로 이동.
