صورة تجارية موجزة لمحفظة واحدة — وسم نمط واحد (磨损户 / P小将 / 印钞机 … بالإضافة إلى عنوان فرعي للسرعة)، جملة واحدة تلخص سجلها وجملة واحدة تقدم نصيحة للخطوة التالية، للمدة 1D / 7D / 30D / 全部، تُنطق بـ "你" للمحفظة الخاصة بالمستخدم و"他" لأي محفظة أخرى؛ تدعم عملة SOL وجميع سلاسل EVM الثمانية، يتم اكتشاف السلسلة تلقائيًا لعنوان يبدأ بـ 0x؛ يمكن عرضها كصفحة.  
**تُستَخدَم عندما** يأتي عنوان محفظة مع طلب ملخص مختصر أو لتغيير ما — مثل: 「帮我复盘一下这个钱包」، 「一句话总结他的战绩」، 「我的打法有什么问题」، 「我钱包下一步该怎么打」، 「交易画像」، 「钱包风格加建议，简短点」、"sum up this wallet in one line".  
**لا تُستَخدَم لـ**: عنوان مجرد، 「能不能跟」 أو 「跟着他买我能吃到吗」 (gmgn-wallet-analysis)؛ التحليل الكامل للوسوم والشارات أو 「是不是机器人」 (gmgn-wallet-style)؛ النقاط أو اختبارات النسخ التداولية (gmgn-wallet-score)؛ إصدارات المبدعين (gmgn-dev-score)؛ الحيازات الحالية (gmgn-portfolio)؛ عنوان توكن أو عملية شراء (gmgn-contract-dd، gmgn-token-buy).  
**حل التعارض** — 打法 / 风格 / 战绩 المرتبطة بـ 问题、建议、复盘 أو 一句话 تُوجيه إلى هنا؛ إذا طُرِحَت منفردة، تُعَاد إلى المهارات المذكورة أعلاه.
