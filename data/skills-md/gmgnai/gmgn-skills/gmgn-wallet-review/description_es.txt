Un breve retrato de trading de UNA dirección de cartera — una sola etiqueta de estilo (磨损户 / P小将 / 印钞机 … más un subtítulo de velocidad), una frase que recapitula su registro y una frase de consejo para el siguiente paso, para 1D / 7D / 30D / 全部, expresado con 你 para la cartera del propio usuario y 他 para cualquier otra; SOL y las 8 cadenas EVM, cadena detectada automáticamente para una dirección 0x; puede renderizarse como una página. USAR CUANDO una dirección de cartera viene con una solicitud de resumen breve o de qué cambiar — 「帮我复盘一下这个钱包」, 「一句话总结他的战绩」, 「我的打法有什么问题」, 「我钱包下一步该怎么打」, 「交易画像」, 「钱包风格加建议，简短点」, "sum up this wallet in one line". NO PARA — una dirección sola, 「能不能跟」 o 「跟着他买我能吃到吗」 (gmgn-wallet-analysis); el desglose completo de etiquetas y distintivos o 「是不是机器人」 (gmgn-wallet-style); puntuaciones o pruebas de copia de comercio (gmgn-wallet-score); lanzamientos de un creador (gmgn-dev-score); tenencias actuales (gmgn-portfolio); una dirección de token o una compra (gmgn-contract-dd, gmgn-token-buy). EMPATE — 打法 / 风格 / 战绩 emparejados con 问题, 建议, 复盘 o 一句话 se dirigen aquí; si se preguntan solos, van a las habilidades anteriores.

Por favor, responde siempre en el idioma del usuario.
