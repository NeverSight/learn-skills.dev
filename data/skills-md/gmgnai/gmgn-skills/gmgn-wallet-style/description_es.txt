Etiqueta el estilo de trading de cualquier wallet — un título principal de una cuadrícula de 20 celdas frecuencia×P&L (印钞机, 磨损户, P小将, 一击必杀, y 16 más), un subtítulo de velocidad de holding (秒杀流/日内流/波段流/长持流), y cualquiera de los 14 distintivos ortogonales más una bandera de wash‑trader. Cada etiqueta indica el número que la activó. Usa esto cuando el usuario pregunte qué tipo de trader es una wallet — 「这个钱包什么风格」, 「交易风格」, 「打法」, 「是不是机器人」, 「是不是狙击盘的」, 「帮我给这个钱包打标签」, "what's this wallet's trading style", "tag this wallet". Una dirección de wallet sin pregunta se dirige a gmgn-wallet-analysis. Si el usuario también quiere la etiqueta mostrada en una captura real de GMGN o como una página interactiva ("生成标签预览", "把标签叠加到这张截图上", "1:1还原钱包页并加标签", "可交互交易风格标签"), responde con la Parte A a continuación y luego también haz la Parte B — el mismo algoritmo, renderizado. Cuando 打法 / 风格 viene con 问题, 建议, 复盘 o 一句话总结, pasa a gmgn-wallet-review, que devuelve una etiqueta más un resumen de una línea y el próximo paso.
