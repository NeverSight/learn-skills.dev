Évaluez n'importe quelle adresse de portefeuille selon trois axes — rentabilité (un vrai score de performance : le trader est-il réellement bon ?), copiabilité de trading (pouvez-VOUS réellement reproduire ce qu'il gagne, plus un test de latence/glissement/gas), et réputation du développeur (s'il s'agit principalement d'un lanceur de tokens, à quel point ses lancements sont-ils fiables) — ainsi que des tags de style de trading, le tout calculé de manière déterministe à partir des données du portefeuille GMGN. Utilisez cela lorsque l'utilisateur demande la rentabilité d'un portefeuille (« 这个钱包盈利能力怎么样 », « 钱包战绩怎么样 », « is this wallet profitable »), la pertinence du copy‑trade (« is this wallet worth following », « 跟单评分 », « 钱包评分 », « 值不值得跟单 », « if I copy this wallet what's my real return »), ou la réputation du lancement de token/du développeur (« 这个钱包发盘情况怎么样 », « 是不是发币方钱包 », « dev 信誉怎么样 », « is this a token-creator wallet »), ou lorsqu'on fournit une adresse de portefeuille et que l'on souhaite l’un de ces jugements. Un récapitulatif d'une ligne du résultat ou un conseil pour l'étape suivante (复盘, 一句话总结战绩, 下一步怎么打) est envoyé à gmgn-wallet-review.

Veuillez toujours répondre dans la langue de l'utilisateur.
