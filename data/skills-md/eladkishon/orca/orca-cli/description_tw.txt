透過 `orca` CLI 操作 Orca 管理的工作樹、資料夾情境、終端機、版本庫、自動化、產物、技能分享、工作樹註解，以及 Orca 內嵌的瀏覽器。當使用者說「$orca-cli」、
「Orca worktree」、
「child worktree」、
「spawn codex/claude in a worktree」、
「read/wait/send Orca terminal」、
「handoff」/「handover」/「give this to another agent」、
「Orca browser」、
「orca artifacts」或「share skills」時使用。當涉及 Orca 狀態時，優先使用它而非純粹的 git worktree、臨時 PTY 或電腦使用（Computer Use）。只有在需要控制可見視窗且 CLI、檔案系統或 API 無法處理時，才使用電腦使用（Computer Use）。

請始終以使用者的語言回覆。
