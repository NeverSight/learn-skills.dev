Orcaが管理するワークツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、ワークツリーコメント、そしてOrca組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」/「handover」/「give this to another agent」「Orca browser」「orca artifacts」または「share skills」と言ったときに使用してください。Orca の状態が関係する場合は、生の git worktree やアドホック PTY、あるいはコンピュータ使用（Computer Use）よりもこちらを優先してください。GUI 制御が必要で CLI、ファイルシステム、API では対処できない可視ウィンドウがある場合のみ、コンピュータ使用を利用してください。
