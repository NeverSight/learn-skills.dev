Gestisci worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser incorporato di Orca tramite la CLI `orca`. Usalo quando l'utente dice “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Preferiscilo rispetto a un worktree git grezzo, PTY ad hoc o all'uso del computer quando è coinvolto lo stato di Orca. Utilizza l'uso del computer solo quando è necessaria l'interazione con una finestra visibile che richiede un controllo GUI che una CLI, il filesystem o un'API non possono gestire. Per favore rispondi sempre nella lingua dell'utente.
