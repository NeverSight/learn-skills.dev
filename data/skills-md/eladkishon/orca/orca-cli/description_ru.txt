Работайте с рабочими деревьями, управляемыми Orca, контекстами папок, терминалами, репозиториями, автоматизацией, артефактами, обменом навыками, комментариями к рабочим деревьям и встроенным браузером Orca через CLI `orca`. Используйте её, когда пользователь говорит «$orca-cli», «Orca worktree», «child worktree», «spawn codex/claude in a worktree», «read/wait/send Orca terminal», «handoff» / «handover» / «give this to another agent», «Orca browser», «orca artifacts» или «share skills». Предпочтите её вместо обычного git worktree, ad hoc PTY или Computer Use, когда задействовано состояние Orca. Применяйте Computer Use только тогда, когда требуется управление видимым окном GUI, которое нельзя выполнить через CLI, файловую систему или API.
