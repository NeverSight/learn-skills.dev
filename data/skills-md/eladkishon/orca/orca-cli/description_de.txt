Betreibe von Orca verwaltete Arbeitsbäume, Ordnerkontexte, Terminals, Repositories, Automatisierungen, Artefakte, Skill‑Sharing, Arbeitsbaum‑Kommentare und Orcas eingebetteten Browser über die `orca`‑CLI. Verwende sie, wenn der Benutzer „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“ sagt. Bevorzuge sie gegenüber rohem Git‑Worktree, adhoc‑PTYs oder Computer‑Use, wenn Orca‑Zustand involviert ist. Setze Computer‑Use nur ein, wenn ein sichtbares Fenster GUI‑Steuerung erfordert, die ein CLI, Dateisystem oder eine API nicht leisten kann.
