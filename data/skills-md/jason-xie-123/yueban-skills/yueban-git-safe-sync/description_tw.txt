在包含 git 子模組的倉庫中，執行 pull、push、將基礎分支合併到當前分支，或為父倉庫以及所有子模組開啟 GitHub PR 時，請確保每個目前仍在維護的子模組（由 .gitmodules 動態取得，排除以 deprecated/ 為前綴的歷史／凍結模組）始終保留在其原始分支上（分支名稱應遵循專案實際的命名慣例），且絕不因這些操作而變成 detached HEAD，也不會被迫檢出父倉庫中記錄的 SHA。  
- Pull / push 適用於同一專案在多台機器上執行，且子模組的分支狀態必須在各機器之間保持一致的情境。  
- merge‑base / PR 則適用於你在從基礎分支切出的特性分支上，需要將基礎分支的新提交合併進來，或是開啟 PR 將此分支合併回基礎分支的情況。  

**唯一觸發方式**：只有在使用者明確輸入 `/yueban-git-safe-sync` 或清楚說明想使用此功能時，才會調用此技能；若使用者僅說「pull 一下」、「push 一下」、「同步程式碼」、「合併 develop」或「開 PR」等概括語句，請不要自行假設使用此技能——應視為普通的 git 操作或詢問使用者是否需要此功能，除非使用者明確提及。
