Solo cuando el usuario solicite explícitamente que se complete totalmente toda la lista de tareas en el archivo openspec/changes/ROADMAP.md de este repositorio debe activarse—no basta con manejar un solo cambio, p. ej., “recorrer el resto del ROADMAP” o “terminar todas las especificaciones restantes de una vez”. No infiera la aplicabilidad a partir de discusiones genéricas de OpenSpec, menciones de ROADMAP.md, o solicitudes de manejar un único cambio (use yueban-spec-single-change-flow para cambios individuales).
