Effectuez un commit git suivant les Conventional Commits, avec analyse du message de commit, staging intelligent et génération de message. Utilisez-le lorsque l'utilisateur demande de committer du code, de créer un commit ou mentionne « /commit ». Prise en charge : (1) détection automatique du type et du scope à partir du diff, (2) génération d’un message de commit conventionnel à partir du diff, (3) commits interactifs (remplacement du type/scope/description), (4) staging intelligent par groupement logique, (5) push vers le dépôt distant après le commit, une fois confirmé (ne pas demander si la requête de l'utilisateur implique déjà le push).

Veuillez toujours répondre dans la langue de l'utilisateur.
