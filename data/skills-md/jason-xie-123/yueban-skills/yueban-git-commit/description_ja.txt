Conventional Commits に従って git コミットを実行し、コミットメッセージの分析、スマートステージング、メッセージ生成を行います。ユーザーがコードのコミットを依頼したり、コミットを作成したり、"/commit" と言及したときに使用してください。サポート内容: (1) diff からタイプとスコープを自動検出、(2) diff から Conventional Commits 形式のメッセージを生成、 (3) インタラクティブコミット（タイプ/スコープ/説明の上書き）、 (4) 論理的なグルーピングによるスマートステージング、 (5) コミット後にリモートへプッシュ（確認後に実行、ユーザーのリクエストがプッシュを示唆している場合は質問を省略）。常にユーザーの言語で回答してください。
