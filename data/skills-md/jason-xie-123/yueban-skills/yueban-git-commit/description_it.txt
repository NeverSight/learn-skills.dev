Esegui un commit git seguendo Conventional Commits, con analisi del messaggio di commit, staging intelligente e generazione del messaggio. Usa quando l'utente richiede di effettuare il commit del codice, crea un commit o menziona "/commit". Supporta: (1) rilevamento automatico del tipo e dello scope dal diff, (2) generazione di un messaggio di commit convenzionale dal diff, (3) commit interattivi (sovrascrivendo tipo/scope/descrizione), (4) staging intelligente per raggruppamento logico, (5) push al remoto dopo il commit, una volta confermato (salta la richiesta solo se la richiesta dell'utente implica già il push). Rispondi sempre nella lingua dell'utente.
