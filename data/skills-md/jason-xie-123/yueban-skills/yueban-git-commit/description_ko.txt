Conventional Commits에 따라 git 커밋을 수행하고, 커밋 메시지 분석, 스마트 스테이징 및 메시지 생성을 포함합니다. 사용자가 코드 커밋을 요청하거나 커밋을 생성하거나 “/commit”을 언급할 때 사용합니다. 지원 기능: (1) diff에서 유형 및 범위 자동 감지, (2) diff를 기반으로 Conventional Commit 메시지 생성, (3) 인터랙티브 커밋(유형/범위/설명 재정의), (4) 논리적 그룹화에 따른 스마트 스테이징, (5) 커밋 후 원격에 푸시(확인 후 진행, 사용자의 요청에 푸시가 이미 포함된 경우는 질문 생략).

항상 사용자의 언어로 응답해 주세요.
