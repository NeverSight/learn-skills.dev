Выполните git‑коммит согласно Conventional Commits, включая анализ сообщения коммита, умную подготовку изменений и генерацию сообщения. Используйте, когда пользователь просит закоммитить код, создать коммит или упоминает «/commit». Поддерживает: (1) автоматическое определение типа и области из диффа, (2) генерацию сообщения Conventional Commit из диффа, (3) интерактивные коммиты (переопределение типа/области/описания), (4) умную подготовку изменений путём логической группировки, (5) отправку в удалённый репозиторий после коммита, после подтверждения (пропускать запрос только если запрос пользователя уже подразумевал отправку).

Пожалуйста, всегда отвечайте на языке пользователя.
