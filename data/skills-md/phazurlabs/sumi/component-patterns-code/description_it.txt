Codice di componenti UI di produzione in React/TypeScript, SwiftUI e CSS moderno con matrici di stato complete, attributi ARIA, gestione della tastiera e consumo dei token di design. Da utilizzare quando si costruisce o si revisiona un pulsante, una finestra modale, un modulo, un input, una tabella o qualsiasi componente che necessiti di coprire tutti i suoi stati.
