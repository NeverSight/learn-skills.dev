UI 화면 녹화(모바일/데스크톱/웹/마케팅 비디오)를 받아서 네 가지 중 하나를 수행합니다 — 원하는 것을 선택하세요: (1) 프레임을 PNG 파일로 추출하기, (2) 비디오에 나타난 디자인 시스템을 분석하고 서로 다른 화면을 나열하기, (3) 비디오를 코드베이스의 파일들과 비교하여 파일들을 비디오와 동일하게 만들기 위한 구체적인 수정 리스트를 생성하기, (4) 실제 프론트엔드 앱(Vite + React + TypeScript + Tailwind)을 스캐폴딩하여 UI의 외형이 아니라 동작까지 재현하고, 작동하는 인터랙션과 애니메이션을 포함시키기. 옵션 3은 항상 제안된 변경 사항을 먼저 보여주고 편집 전에 승인을 기다립니다. ffmpeg이 필요합니다; 모드 4는 생성된 앱을 실행하기 위해 Node.js도 필요합니다. 모드 4는 생성 전에 `frontend-design` 스킬(설치된 경우)을 읽어 컴포넌트 품질 및 미학 가이드를 상속합니다.

사용자가 화면 녹화, 비디오 워크스루, 모바일 앱 데모, 데스크톱 앱 캡처, 마케팅/제품 비디오를 언급하거나 클립에서 디자인 인사이트를 추출하고 싶다고 말할 때마다 트리거됩니다 — 설령 “비디오 스킬을 사용한다”라고 명시적으로 말하지 않더라도. “UI 비디오가 있어요”, “이 녹화에서 프레임을 추출하고 싶어요”, “이 비디오의 디자인 시스템이 뭐예요”, “내 컴포넌트를 이 클립처럼 만들고 싶어요”, “이 비디오로 프론트엔드 앱을 만들고 싶어요”, “UI 데모가 있는데 업데이트하고 싶은 파일이 있어요”와 같은 문구도 모두 트리거됩니다. 스킬 자체가 네 가지 모드 중 어떤 것을 실행할지 물어볼 것입니다.
