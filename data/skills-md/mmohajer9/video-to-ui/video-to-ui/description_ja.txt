UIの画面録画（モバイル／デスクトップ／Web／マーケティング動画）を取得し、次の4つのうちいずれかを実行します — お好みで選択してください：(1) フレームをPNGとして抽出するだけ、(2) 動画に示されたデザインシステムを解析し、異なる画面を一覧化する、(3) 動画とコードベース内のファイルを比較し、動画のように感じさせるための具体的な修正リストを作成する、または (4) 実際のフロントエンドアプリ（Vite + React + TypeScript + Tailwind）を雛形として作成し、外観だけでなく挙動まで再現し、インタラクションやアニメーションが機能するようにします。オプション3は常に提案された変更を最初に表示し、編集を行う前にユーザーの承認を待ちます。ffmpeg が必要です。モード4はさらに Node.js が必要で、生成されたアプリを実行します。モード4は `frontend-design` スキル（インストールされている場合）を読み込み、コンポーネントの品質と美的指針を継承します。

ユーザーが画面録画、ビデオウォークスルー、モバイルアプリデモ、デスクトップアプリキャプチャ、マーケティング／製品ビデオ、またはクリップからデザインインサイトを抽出したいと述べたときに常にトリガーします — 「ビデオスキルを使う」と明示しなくても構いません。「UIのこのビデオがあります」「この録画からフレームを抽出して」「このビデオのデザインシステムは何ですか」「このクリップのようにコンポーネントを見せたい」「このビデオからフロントエンドアプリを作りたい」「UIデモがあります、更新したいファイルがあります」などのフレーズはすべてトリガー対象です。スキル自体がどのモードを実行するかを尋ねます。
