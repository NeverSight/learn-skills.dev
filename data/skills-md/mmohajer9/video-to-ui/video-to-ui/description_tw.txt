取得一段 UI 螢幕錄影（手機／桌面／網頁／行銷影片），然後執行以下四種操作之一──由你自行選擇：(1) 只將畫面擷取為 PNG 圖片；(2) 分析影片中呈現的設計系統，列出不同的畫面；(3) 將影片與程式碼庫中的檔案比對，產出具體的修改清單，使這些檔案的感覺跟影片一致；或 (4) 建立一個真實的前端應用程式（Vite + React + TypeScript + Tailwind），重現 UI 的行為──不僅是外觀──包含可運作的互動與動畫。模式 3 會先顯示建議的變更，並在你批准後才進行編輯。需要 ffmpeg；模式 4 另需 Node.js 以執行產生的應用程式。模式 4 會在產生前讀取 `frontend‑design` 技能（如果已安裝），以繼承其元件品質與美學指引。

只要使用者提到螢幕錄影、影片導覽、行動應用示範、桌面應用擷取、行銷／產品影片，或想從影片中提取設計見解，即可觸發──即使他們沒有明確說「使用影片技能」。例如「我有這段 UI 影片」、「從這段錄影擷取畫格」、「這段影片的設計系統是什麼」、「讓我的元件看起來像這段影片」、「從這段影片打造前端應用」或「我有一個 UI 示範，這裡有我要更新的檔案」等語句，都應觸發。此技能本身會詢問要執行哪一種模式。

請始終以使用者的語言回覆。
