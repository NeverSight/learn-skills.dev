Nehmen Sie eine UI‑Bildschirmaufnahme (Mobile/Desktop/Web/Marketing‑Video) und führen Sie eine von vier Optionen aus – Ihre Wahl: (1) extrahieren Sie einfach die Frames als PNGs, (2) analysieren Sie das im Video gezeigte Designsystem und listen Sie die distincten Bildschirme auf, (3) vergleichen Sie das Video mit Dateien in Ihrem Code‑Base und erzeugen Sie eine konkrete Liste von Änderungen, um diese Dateien wie das Video wirken zu lassen, oder (4) erstellen Sie eine echte Frontend‑App (Vite + React + TypeScript + Tailwind), die das Verhalten der UI – nicht nur das Aussehen – mit funktionierenden Interaktionen und Animationen nachbildet. Option 3 zeigt Ihnen immer zuerst die vorgeschlagenen Änderungen und wartet auf Ihre Genehmigung, bevor sie bearbeitet werden. Erfordert ffmpeg; Modus 4 benötigt zusätzlich Node.js, um die generierte App auszuführen. Modus 4 liest die `frontend-design`‑Skill (falls installiert), bevor er generiert, um deren Komponenten‑Qualität und gestalterische Vorgaben zu übernehmen.

Triggern Sie die Funktion immer dann, wenn der Benutzer eine Bildschirmaufnahme, ein Video‑Walkthrough, eine Mobile‑App‑Demo, einen Desktop‑App‑Capture, ein Marketing‑/Produkt‑Video erwähnt oder Design‑Einblicke aus einem Clip extrahieren möchte – selbst wenn er nicht ausdrücklich „die Video‑Skill verwenden“ sagt. Phrasen wie „Ich habe dieses Video einer UI“, „extrahiere Frames aus dieser Aufnahme“, „welches Designsystem ist in diesem Video“, „mach meine Komponenten wie diesen Clip“, „baue eine Frontend‑App aus diesem Video“ oder „Ich habe eine UI‑Demo, hier sind Dateien, die ich aktualisieren will“ sollten allesamt den Trigger auslösen. Die Skill selbst wird fragen, welchen der vier Modi Sie ausführen möchten.

Bitte immer in der Sprache des Benutzers antworten.
