Toma una grabación de pantalla de UI (móvil/escritorio/web/video de marketing) y haz una de cuatro cosas — tú eliges: (1) simplemente extraer los fotogramas como PNG, (2) analizar el sistema de diseño mostrado en el video y enumerar las pantallas distintas, (3) comparar el video con los archivos de tu base de código y producir una lista concreta de ediciones para que esos archivos se asemejen al video, o (4) generar una aplicación frontend real (Vite + React + TypeScript + Tailwind) que recree el comportamiento de la UI — no solo su apariencia — con interacciones y animaciones funcionales. La opción 3 siempre te muestra primero los cambios propuestos y espera tu aprobación antes de editar. Requiere ffmpeg; el modo 4 además necesita Node.js para ejecutar la aplicación generada. El modo 4 lee la habilidad `frontend-design` (si está instalada) antes de generar para heredar su calidad de componentes y guía estética.

Se activa siempre que el usuario mencione una grabación de pantalla, un recorrido en video, una demo de app móvil, una captura de app de escritorio, un video de marketing/producto, o quiera extraer ideas de diseño de un clip — incluso si no dice explícitamente “usar la habilidad de video”.
