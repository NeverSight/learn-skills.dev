Проверяет изменения инфраструктуры: рабочие процессы GitHub Actions, Terraform, Dockerfile, docker‑compose, IaC. Сосредотачивается на привязке цепочки поставок, управлении секретами, принципе наименьших привилегий, версиях действий и режимах сбоев CI. Всегда проверяет хеш‑привязки действий, когда они присутствуют.
