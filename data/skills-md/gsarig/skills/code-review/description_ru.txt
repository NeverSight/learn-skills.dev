Оркестратор. Оценивает pull‑request, локальный diff, файл патча или изменения в индексе/ветке и распределяет их по одному из четырёх типов ревью (content, code-lite, code-deep, infra), после чего передаёт в соответствующий дочерний навык. Используйте его, когда вы ещё не знаете, какую глубину или тип ревью хотите. Для известного типа вызывайте дочерний навык напрямую.
