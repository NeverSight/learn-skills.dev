منسق. يصنّف طلب سحب (PR) أو اختلاف محلي أو ملف تصحيح أو تغييرات مُعدّة/فرع إلى أحد أربعة أنواع مراجعة (المحتوى، كود‑لايت، كود‑ديب، البنية التحتية) ويُرسل إلى المهارة الفرعية المطابقة. استخدم هذا عندما لا تعرف مسبقًا عمق أو نوع المراجعة التي تريدها. بالنسبة لنوع معروف، استدعِ المهارة الفرعية مباشرةً.
