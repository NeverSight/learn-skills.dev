Orchestrator. Triagiert eine PR-, lokale Diff-, Patch-Datei oder Staged/Branch-Änderungen in einen von vier Review-Typen (Content, Code-lite, Code-deep, infra) und versendet sie an die entsprechende untergeordnete Fertigkeit. Verwenden Sie diese Option, wenn Sie noch nicht wissen, welche Tiefe oder Art von Bewertung Sie wünschen. Bei einem bekannten Typ rufen Sie die untergeordnete Fertigkeit direkt auf.
