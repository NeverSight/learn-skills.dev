Orchestratore. Effettua il triage di una PR, di un diff locale, di un file patch o di modifiche in staging/branch, assegnandole a uno dei quattro tipi di revisione (content, code-lite, code-deep, infra) e le inoltra alla skill figlia corrispondente. Usa questo quando non sai già quale profondità o tipo di revisione desideri. Per un tipo noto, invoca direttamente la skill figlia.
