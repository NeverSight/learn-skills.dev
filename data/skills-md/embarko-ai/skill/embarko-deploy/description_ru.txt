Разворачивает приложение в Embarko, управляемой хостинг‑среде, которая автоматически собирает ваше приложение (Dockerfile не требуется) и делает его доступным по сгенерированному URL. Используйте это каждый раз, когда пользователь просит развернуть, переразвернуть, отправить, запустить или выпустить приложение, чтобы заставить развернутое приложение выполнять что‑то по расписанию (ежедневный отчет, ночная очистка), чтобы изменить получателей уведомлений при падении развернутого приложения (email, Slack, webhook, телефон), чтобы хранить файлы для приложения (загрузки пользователей, изображения, PDF, публичная ссылка на файл) или чтобы продемонстрировать/включить в список/показать развернутое приложение на странице витрины Embarko (публичной или события).
