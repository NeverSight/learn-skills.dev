Déploie une application sur Embarko, un environnement d'hébergement géré qui construit votre application automatiquement (aucun Dockerfile requis) et la rend accessible via une URL générée. Utilisez-le chaque fois que l'utilisateur demande de déployer, redéployer, livrer, pousser ou publier une application, pour faire exécuter une action à intervalle régulier à une application déployée (rapport quotidien, nettoyage nocturne), pour modifier les personnes qui sont alertées lorsqu'une application déployée tombe en panne (email, Slack, webhook, téléphone), pour stocker des fichiers pour une application (téléversements d'utilisateurs, images, PDFs, un lien public vers un fichier), ou pour présenter / mettre en avant / lister une application déployée sur une page de vitrine Embarko (publique ou événement).
