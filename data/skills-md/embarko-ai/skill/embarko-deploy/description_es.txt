Despliega una aplicación en Embarko, un entorno de alojamiento gestionado que construye tu app automáticamente (no se requiere Dockerfile) y la hace accesible mediante una URL generada. Usa esto siempre que el usuario solicite desplegar, redeplegar, lanzar, subir o publicar una app, para que una app desplegada realice alguna acción mediante un temporizador (informe diario, limpieza nocturna), para cambiar quién recibe alertas cuando una app desplegada falla (correo electrónico, Slack, webhook, teléfono), para almacenar archivos de una app (cargas de usuarios, imágenes, PDFs, un enlace público a un archivo), o para exhibir/destacar/listar una app desplegada en una página de presentación de Embarko (pública o de evento).
