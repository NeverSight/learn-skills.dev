Umfassende Recherche mit Hyperresearch für Claude Code und OpenAI Codex. Verwenden Sie diese Option, wenn der Benutzer eine umfassende Recherche, einen Forschungsbericht, eine Literaturrecherche oder eine Analyse mehrerer Quellen mit verifizierten Quellenangaben wünscht. Überprüft, ob die Hyperresearch-CLI installiert ist, richtet sie im aktuellen Projekt für den Agenten ein, in dem Sie arbeiten, und übergibt dann an die Hyperresearch-Pipeline (eine stufenweise anpassbare 16-stufige Pipeline mit einem dauerhaften Quellenspeicher). Nicht für schnelle Nachschlagevorgänge geeignet, bei denen eine oder zwei Suchanfragen ausreichen.
