Investigación exhaustiva con HyperResearch, para Claude Code y OpenAI Codex. Utilízalo cuando el usuario solicite una investigación exhaustiva, un informe de investigación, una revisión bibliográfica o un análisis de múltiples fuentes con citas verificadas. Comprueba que la CLI de Hyperresearch esté instalada, la configura en el proyecto actual para el agente en el que se está ejecutando y, a continuación, la transfiere al «pipeline» de Hyperresearch (un «pipeline» de 16 pasos adaptable al nivel con un repositorio de fuentes persistente). No es adecuado para consultas rápidas que se puedan resolver con una o dos búsquedas.
