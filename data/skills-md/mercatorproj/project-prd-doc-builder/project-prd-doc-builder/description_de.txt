Basierend auf den bestehenden Projektverzeichnissen, dem Quellcode, den Tests, den Produktspezifikationen, den User Stories und der Architekturdokumentation, reverse engineere und erstelle ein vollständiges, lesbares und nachvollziehbares PRD sowie eine integrierte Projektdokumentationsseite. Dies ist geeignet für Aufgaben wie „Ein PRD aus dem Code‑Base generieren“, „Projektmaterialien in VitePress‑Dokumentation organisieren“ und „User Stories, Use Cases, Geschäftsprozesse, Mermaid-/C4‑Diagramme, Akzeptanzkriterien vervollständigen“ usw.
