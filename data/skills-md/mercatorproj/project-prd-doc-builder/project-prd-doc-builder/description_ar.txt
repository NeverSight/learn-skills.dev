استنادًا إلى دلائل المشروع الحالية، والكود المصدري، والاختبارات، ومواصفات المنتج، وقصص المستخدم، والمعلومات المعمارية، قم بعكس الهندسة وإنشاء وثيقة متطلبات المنتج (PRD) كاملة، قابلة للقراءة، وقابلة للتتبع، إلى جانب موقع توثيق مشروع شامل. هذا مناسب لمهام مثل «إنشاء PRD من قاعدة الشيفرة»، «تنظيم مواد المشروع في توثيق VitePress»، «إكمال قصص المستخدم، حالات الاستخدام، عمليات الأعمال، مخططات Mermaid/C4، معايير القبول»، وغيرها من الأنشطة المماثلة. يرجى دائمًا الرد بلغة المستخدم.
