استخدمه عندما يجب أن تحافظ الأصول التي تم إنشاؤها على نمط أو شخصية أو مظهر منتج ثابت وتتوقف المراجع عن التوسع، أو عندما يطلب المستخدم تدريب نموذج مخصص عبر Scenario MCP، أو ضبط LoRA، أو استنساخ صوت، أو تنسيق مجموعة بيانات تدريبية، أو اختيار نموذج أساسي، أو ضبط عدد الفترات (epochs) وعينات المطالبات، أو تقدير تكلفة التدريب، أو تشخيص نموذج مدرب فقد هويته أو لديه فترة واحدة فقط، أو التوليد باستخدام نموذج مدرب. الكلمات المفتاحية: نموذج مخصص، LoRA، تنسيق مجموعة البيانات، معاينات الفترات.
