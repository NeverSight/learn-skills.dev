Microsoft MAI Image モデルを Scenario の MCP 経由で使用して画像を生成または編集する際に使用してください：フォトリアルまたはスタイライズドなテキストから画像への変換で、画像内のタイポグラフィが読みやすいもの、ポスター、パッケージ、雑誌表紙、広告、キーアート、あるいはテキストの入れ替え、再着色、オブジェクトの削除または置換、背景の入れ替え、照明の変更、完全なリスタイルなどの指示ベースの編集に対応します。キーワード：MAI Image 2.5、2.5 Pro、2.5 Edit、2.5 Pro Edit、Microsoft、txt2img、img2img、タイポグラフィ、テキストレンダリング、画像編集。
