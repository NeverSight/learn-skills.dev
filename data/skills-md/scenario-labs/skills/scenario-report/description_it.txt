Usa quando un utente di Scenario vuole segnalare un bug o richiedere una modifica, sul tracker pubblico su github.com/scenario-labs/skills o via email a support@scenario.com: trasformare una generazione fallita, un errore dello strumento MCP o una skill poco chiara in un report riproducibile, raccogliere gli ID di traccia con diagnostics_run, rimuovere chiavi, URL di asset firmati e dati personali, chiedere prima di condividere un ID di team o di progetto, o creare un URL di issue precompilato. Parole chiave: segnalare un problema, richiesta di funzionalità, feedback.
