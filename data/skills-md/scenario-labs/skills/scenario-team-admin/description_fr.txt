Utilisez‑le lors de l’administration d’une équipe Scenario depuis un agent via MCP : restreindre les modèles qu’une équipe ou un projet peut exécuter (contrôle d’accès aux modèles, liste blanche, liste noire), inviter ou supprimer des membres de l’équipe et du projet, modifier les rôles, plafonner les dépenses d’Unité Créative d’un membre, auditer les clés API ainsi que leurs rôles ou portées, ou attribuer la consommation par utilisateur ou par modèle. Mots‑clés : gouvernance, contrôle des modèles, plafond de consommation, limite de dépenses, hygiène des clés API, admin d’équipe, entreprise.
