استخدمه عند إدارة فريق Scenario من خلال وكيل عبر MCP: تقييد النماذج التي يمكن لفريق أو مشروع تشغيلها (التحكم في وصول النماذج، القائمة البيضاء، القائمة السوداء)، دعوة أو إزالة أعضاء الفريق والمشروع، تغيير الأدوار، تحديد حد إنفاق وحدة الإبداع للعضو، تدقيق مفاتيح API وأدوارها أو نطاقاتها، أو تخصيص الاستهلاك لكل مستخدم أو نموذج. الكلمات المفتاحية: الحوكمة، التحكم في النماذج، حد الاستهلاك، حد الإنفاق، نظافة مفاتيح API، إدارة الفريق، المؤسسة.
