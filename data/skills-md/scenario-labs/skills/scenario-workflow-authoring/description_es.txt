Se usa cuando una tarea implica crear o editar un gráfico de flujo de trabajo de escenario a través de MCP: crear una aplicación a partir de un resumen, agregar o volver a cablear nodos (modelos, mensajes, puertas de aprobación, bucles), crear editor_info, publicar, anular la publicación o cambiar el nombre, importar un flujo de trabajo exportado JSON, migrar un gráfico construido en Weavy, ComfyUI u otra herramienta de nodo, copiar un flujo de trabajo o convertir una cadena de mensajes en una aplicación. Ejecutar o fijar el precio de un flujo de trabajo son flujos de trabajo de escenarios. Palabras clave: node graph, editor_info, cel.
