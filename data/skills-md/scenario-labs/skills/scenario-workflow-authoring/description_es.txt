Utilice cuando una tarea implique crear o editar un grafo de flujo de trabajo de Scenario a través de MCP: construir una aplicación a partir de un brief, agregar o volver a conectar nodos (modelos, prompts, puertas de aprobación, bucles), redactar editor_info, publicar, despublicar o renombrar, importar un JSON de flujo de trabajo exportado, migrar un grafo construido en Weavy, ComfyUI u otra herramienta de nodos, copiar un flujo de trabajo o convertir una cadena de prompts en una aplicación. Ejecutar o fijar precio a un flujo de trabajo corresponde a scenario‑workflows. Palabras clave: node graph, editor_info, CEL.
