Usa quando un compito riguarda la creazione o la modifica di un grafo di workflow Scenario tramite MCP: costruire un'app da un brief, aggiungere o ricollegare nodi (modelli, prompt, gate di approvazione, loop), redigere editor_info, pubblicare, annullare la pubblicazione o rinominare, importare un workflow JSON esportato, migrare un grafo creato in Weavy, ComfyUI o un altro strumento a nodi, copiare un workflow o trasformare una catena di prompt in un'app. L'esecuzione o la definizione del prezzo di un workflow è scenario‑workflows. Parole chiave: node graph, editor_info, CEL.
