Wird verwendet, wenn eine Aufgabe das Erstellen oder Bearbeiten eines Szenario-Workflowdiagramms über MCP umfasst: Erstellen einer App aus einem Briefing, Hinzufügen oder Neuverdrahten von Knoten (Modelle, Eingabeaufforderungen, Genehmigungstore, Schleifen), Erstellen von Editor_Info, Veröffentlichen, Aufheben der Veröffentlichung oder Umbenennen, Importieren einer exportierten Workflow-json, Migrieren eines in Weavy, ComfyUI oder einem anderen Knotenwerkzeug erstellten Diagramms, Kopieren eines Workflows oder Umwandeln einer Eingabeaufforderungskette in eine App. Das Ausführen oder Bewerten eines Workflows ist Szenario-Workflows. Stichwörter: Knotengrafik, editor_info, CEL.
