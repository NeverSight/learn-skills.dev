Verwenden, wenn eine Aufgabe das Erstellen oder Bearbeiten eines Scenario‑Workflow‑Graphen über MCP beinhaltet: eine App aus einem Briefing bauen, Nodes (Modelle, Prompts, Genehmigungstore, Schleifen) hinzufügen oder umverdrahten, editor_info verfassen, veröffentlichen, unveröffentlichen oder umbenennen, einen exportierten Workflow‑JSON importieren, einen in Weavy, ComfyUI oder einem anderen Node‑Tool erstellten Graph migrieren, einen Workflow kopieren oder eine Prompt‑Kette in eine App umwandeln. Das Ausführen oder Preisberechnen eines Workflows ist scenario‑workflows. Schlüsselwörter: node graph, editor_info, CEL.
