استخدم عندما تتضمن المهمة إنشاء أو تحرير مخطط سير عمل سيناريو عبر MCP: بناء تطبيق من ملخص، إضافة أو إعادة توصيل العقد (النماذج، المطالبات، بوابات الموافقة، الحلقات)، كتابة editor_info، النشر، إلغاء النشر أو إعادة التسمية، استيراد ملف JSON لسير العمل المُصدّر، هجرة مخطط تم إنشاؤه في Weavy أو ComfyUI أو أي أداة عقد أخرى، نسخ سير عمل، أو تحويل سلسلة المطالبات إلى تطبيق. تشغيل أو تسعير سير العمل هو scenario‑workflows. الكلمات المفتاحية: node graph، editor_info، CEL.
