Úsalo al crear un anuncio de vídeo terminado para la captación de usuarios (UA) de un juego para móvil con Scenario con una duración exacta para TikTok, Reels, Stories, el feed de Meta, YouTube Shorts o redes publicitarias: a partir de un concepto de una sola línea o de las propias capturas de pantalla del juego, una grabación de pantalla, un vídeo de jugabilidad, personajes, un icono o un kit de interfaz de usuario. Tirar de un alfiler, atasco de aparcamiento, «match-3», agujero negro, «evolution runner», apilador, dibujar para proteger, encontrar el elemento que no encaja, «gacha», fusión. También gancho, mano, contador HUD, pantalla final. No es para anuncios a partir de una foto de un producto.
