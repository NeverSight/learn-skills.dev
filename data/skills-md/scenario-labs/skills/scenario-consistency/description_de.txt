Verwenden Sie es, wenn ein Look über Szenariengenerationen hinweg gelten muss: ein Charakter über Szenen, eine Trendwende oder ein Video, das aus seinen Referenzen animiert wurde, ein Produkt über Winkel, ein Stil über Symbolsätze, ein Charakter aus einer hochgeladenen Zeichnung, eine Variante von einer genehmigten Basislinie oder die Entscheidung, wann Referenzen nicht mehr skaliert werden und ein trainiertes Modell fällig ist. Auslöser: Stellen Sie diese Übereinstimmung her, dasselbe Zeichen, auf dem Modell, Verweis auf Video, Stilverweis. Schlüsselwörter: Konsistenz, Identität, Kontrollkarte, Seed, LoRA.
