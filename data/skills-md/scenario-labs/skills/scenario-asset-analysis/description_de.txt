Verwenden, wenn das Szenario abgeschlossen ist: Szenario‑Assets müssen etwas zurückgeben: eine Bildunterschrift für einen Datensatz oder Alt‑Text, eine wiederverwendbare Stilbeschreibung, ein Urteil zu einem Briefing, eine Canny‑, Tiefen‑, Pose‑ oder Segmentierungs‑Steuerkarte für das nächste Modell, oder das Asset selbst, das erneut per Text, Tags oder visueller Ähnlichkeit gefunden und in einer Sammlung abgelegt wird. Schlüsselwörter: Bildunterschrift, beschreiben, analysieren, QA, Steuerkarte, Ähnliches finden, Reverse‑Image‑Search, semantische Suche, Tag, Sammlung.
