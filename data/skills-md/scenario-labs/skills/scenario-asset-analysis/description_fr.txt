Une fois terminé, les actifs de scénario doivent redonner quelque chose : une légende pour un ensemble de données ou un texte alternatif, une description de style réutilisable, un verdict contre un brief, une carte de contrôle astucieuse, de profondeur, de pose ou de segmentation pour le modèle suivant, ou l'actif lui-même retrouvé par du texte, des balises ou une similitude visuelle et classé dans une collection. Mots-clés : légende, décrire, analyser, AQ, carte de contrôle, trouver similaire, recherche d'image inversée, recherche sémantique, balise, collection.
