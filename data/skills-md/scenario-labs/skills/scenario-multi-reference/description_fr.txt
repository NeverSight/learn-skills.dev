À utiliser lorsqu’une image doit être composée à partir de plusieurs images de référence via le serveur Scenario MCP, chaque image apportant un élément : le personnage à partir de l’une, le lieu, la pose, le style, la lumière, la palette, le matériau, la tenue ou la disposition à partir des autres. Aussi lorsque qu’une référence fuit dans le résultat (son objet, ses couleurs ou son visage apparaissant là où ils ne devraient pas) ou que le rôle d’une référence est ignoré. Mots‑clés : multi‑référence, rôles de référence, combiner les références, référence de style, référence de pose, attribuer un rôle à chaque image.
