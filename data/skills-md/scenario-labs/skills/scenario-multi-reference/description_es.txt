Úselo cuando una imagen debe componerse a partir de varias imágenes de referencia a través del servidor Scenario MCP, cada una aportando un elemento: el personaje de una, el lugar, la pose, el estilo, la luz, la paleta, el material, el atuendo o el diseño de otras. También cuando una referencia se filtra en el resultado (su objeto, colores o rostro aparecen donde no debe) o se ignora el papel de una referencia. Palabras clave: multireferencia, roles de referencia, combinar referencias, referencia de estilo, referencia de pose, asignar a cada imagen una función.
