Verwenden, wenn ein Bild aus mehreren Referenzbildern über den Scenario‑MCP‑Server zusammengesetzt werden muss, wobei jedes ein Element beisteuert: den Charakter aus einem, den Ort, die Pose, den Stil, das Licht, die Palette, das Material, das Outfit oder das Layout aus anderen. Auch wenn eine Referenz in das Ergebnis durchsickert (ihr Objekt, ihre Farben oder ihr Gesicht an Stellen erscheint, wo es nicht sein sollte) oder die Rolle einer Referenz ignoriert wird. Schlüsselwörter: Mehrfach‑Referenz, Referenzrollen, Referenzen kombinieren, Stil‑Referenz, Pose‑Referenz, jedem Bild eine Aufgabe zuweisen.
