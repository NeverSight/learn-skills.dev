Utiliza esta habilidad al ayudar a escribir, mejorar, depurar u optimizar indicaciones (prompts) para cualquier LLM, ya sea para agentes, llamadas API, indicaciones de sistema o chat interactivo. Activa la habilidad siempre que el usuario mencione prompts, ingeniería de prompts, instrucciones del sistema, definiciones de agentes, plantillas de prompts, ejemplos few‑shot, razonamiento en cadena (chain‑of‑thought) o solicite que un LLM se comporte de manera diferente. También actívala cuando el usuario esté construyendo agentes y necesite definir o refinar las instrucciones que esos agentes reciben. Esta habilidad funciona como un enrutador: proporciona el flujo de trabajo central y despacha a sub‑habilidades especializadas para técnicas detalladas.

Por favor, responde siempre en el idioma del usuario.
