이 기술은 에이전트, API 호출, 시스템 프롬프트 또는 인터랙티브 채팅 등 어떤 LLM에 대한 프롬프트를 작성, 개선, 디버깅 또는 최적화할 때 사용하세요. 사용자가 프롬프트, 프롬프트 엔지니어링, 시스템 지시사항, 에이전트 정의, 프롬프트 템플릿, 소수 샷 예시, 체인 오브 생각(Chain‑of‑Thought) 등을 언급하거나 LLM이 다르게 행동하도록 요청할 때마다 트리거하세요. 또한 사용자가 에이전트를 구축하면서 해당 에이전트가 받는 지시를 정의하거나 다듬어야 할 때도 트리거합니다. 이 기술은 라우터 역할을 하며, 핵심 워크플로우를 제공하고 상세한 기법을 위한 특화된 서브 스킬로 디스패치합니다. 항상 사용자의 언어로 답변해 주세요.
