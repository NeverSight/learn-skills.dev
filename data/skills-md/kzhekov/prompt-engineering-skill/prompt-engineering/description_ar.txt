استخدم هذه المهارة عند المساعدة في كتابة أو تحسين أو تصحيح أو تحسين المطالبات لأي نموذج لغة كبير — سواء للوكالات أو استدعاءات API أو مطالبات النظام أو الدردشة التفاعلية. يتم تفعيلها كلما ذكر المستخدم المطالبات أو هندسة المطالبات أو تعليمات النظام أو تعريفات الوكيل أو قوالب المطالبات أو أمثلة القليل من اللقطات أو سلسلة التفكير أو طلب جعل النموذج يتصرف بشكل مختلف. كما يتم تفعيلها عندما يبني المستخدم وكلاءً ويحتاج إلى تعريف أو تحسين التعليمات التي يتلقاها تلك الوكلاء. هذه المهارة هي موجه — فهي توفر سير العمل الأساسي وتوجه إلى مهارات فرعية متخصصة للتقنيات التفصيلية.
