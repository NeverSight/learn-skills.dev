Usa questa abilità quando aiuti a scrivere, migliorare, fare debug o ottimizzare i prompt per qualsiasi LLM — sia per agenti, chiamate API, prompt di sistema o chat interattiva. Attivala ogni volta che l'utente menziona prompt, ingegneria dei prompt, istruzioni di sistema, definizioni di agenti, modelli di prompt, esempi few-shot, chain-of-thought, o chiede di far comportare un LLM diversamente. Attivala anche quando l'utente sta costruendo agenti e ha bisogno di definire o perfezionare le istruzioni che tali agenti ricevono. Questa abilità è un router — fornisce il flusso di lavoro principale e indirizza a sotto‑abilità specializzate per tecniche dettagliate.

Rispondi sempre nella lingua dell'utente.
