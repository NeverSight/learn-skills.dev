Referencia para usar OpenCode CLI para manejar tareas de codificación complejas. Úselo cuando Research-Claw necesite delegar proyectos de varios archivos, generación de código o depuración iterativa a una herramienta de codificación de IA de múltiples proveedores. Palabras desencadenantes: código abierto, CLI de codificación, codificación delegada, agente multiproveedor.
