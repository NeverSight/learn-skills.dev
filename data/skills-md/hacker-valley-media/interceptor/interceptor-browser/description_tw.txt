透過 interceptor CLI 驅動已登入的 Chrome / Brave / Safari 工作階段：開啟/讀取頁面、點擊、輸入、檢查 DOM/文字/網路、自動化豐富的瀏覽器編輯器與場景圖、捕獲 WebSocket / Beacon / BroadcastChannel 流量、錄製/重放流程、拍攝符合 VLM 預算的截圖、比較頁面，並使用 --context 指定特定瀏覽器上下文。用於瀏覽器頁面內容、分頁、表單、SPA 抽取、請求覆寫、頁面通信捕獲與部署檢查。不適用於原生 macOS 應用程式、Electron 桌面應用的網頁內容、作業系統對話框、瀏覽器介面（chrome）或大規模爬抓。
