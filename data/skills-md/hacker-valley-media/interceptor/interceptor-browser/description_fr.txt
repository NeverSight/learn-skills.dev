Pilotez une session Chrome / Brave / Safari connectée via l’interface en ligne de commande interceptor : ouvrez/lisez des pages, cliquez, saisissez, inspectez le DOM/le texte/le réseau, automatisez les éditeurs de navigateur avancés et les graphes de scène, capturez le trafic WebSocket/Beacon/BroadcastChannel, enregistrez/rejouez les flux, prenez des captures d’écran limitées par le VLM, comparez les pages et dirigez‑les vers des contextes de navigateur spécifiques avec --context. Utilisez‑le pour le contenu des pages du navigateur, les onglets, les formulaires, l’extraction SPA, les substitutions de requêtes, la capture de communications de page et les vérifications de déploiement. Pas pour les applications macOS natives, le contenu web d’applications de bureau Electron, les dialogues du système d’exploitation, le chrome du navigateur ou le scraping à grande échelle.
