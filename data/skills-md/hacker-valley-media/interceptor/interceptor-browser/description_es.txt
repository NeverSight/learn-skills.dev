Conduzca una sesión de Chrome / Brave / Safari con sesión iniciada a través del CLI interceptor: abra/lea páginas, haga clic, escriba, inspeccione DOM/texto/red, automatice editores de navegador enriquecidos y grafos de escena, capture tráfico WebSocket/Beacon/BroadcastChannel, grabe/reproduzca flujos, tome capturas de pantalla con presupuesto VLM, compare páginas y dirija a contextos de navegador específicos con --context. Úselo para contenido de páginas del navegador, pestañas, formularios, extracción de SPA, sobrescrituras de solicitudes, captura de comunicación de página y verificaciones de despliegue. No es para aplicaciones nativas de macOS, contenidos web de aplicaciones de escritorio Electron, diálogos del sistema operativo, la chrome del navegador o scraping a gran escala.
