Управляйте авторизованной сессией Chrome / Brave / Safari через CLI‑интерцептор: открывайте/читайте страницы, кликайте, вводите текст, инспектируйте DOM/текст/сетевые запросы, автоматизируйте сложные браузерные редакторы и графы сцен, перехватывайте трафик WebSocket/Beacon/BroadcastChannel, записывайте/воспроизводите потоки, делайте скриншоты с ограничением VLM, сравнивайте страницы и перенаправляйте в конкретные контексты браузера с помощью параметра --context. Используйте для содержимого страниц браузера, вкладок, форм, извлечения SPA, переопределения запросов, захвата коммуникаций страниц и проверок развертывания. Не предназначено для нативных macOS‑приложений, веб‑содержимого настольных приложений Electron, системных диалогов, интерфейса браузера или масштабного скрапинга.
