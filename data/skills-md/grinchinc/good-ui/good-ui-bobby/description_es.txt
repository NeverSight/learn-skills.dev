Aplica un sistema de implementación de UI personal y con opiniones propias sobre good-ui para aplicaciones web e interfaces de productos, que incluya estilos visuales completamente diseñados, activos de íconos reales, espaciado de 4 px/8 px, tamaños de control estandarizados, margen de borde, áreas de interacción ampliadas, estados de interacción completos, comportamiento de foco intencional, movimiento que preserve la continuidad, primitivas priorizando shadcn, galerías de componentes para producción, superposiciones temporales de desarrollo, puntos de control de Git y características opcionales respaldadas por OpenRouter. Utilízalo para nuevas UI, revisiones sustanciales de UI, trabajo de sistemas de componentes, pulido de interacción o exploración de diseño dentro del producto.
