Applica un sistema di implementazione UI personale e opinato sopra good-ui per app web e interfacce di prodotto, includendo stilizzazione visiva completamente autrice, risorse iconografiche reali, spaziature da 4 px/8 px, dimensioni di controllo standardizzate, margine dei bordi, aree di tocco ampliate, stati di interazione completi, comportamento di focus intenzionale, motion che preserva la continuità, primitive shadcn‑first, gallerie di componenti di produzione, overlay di sviluppo temporanei, checkpoint Git e funzionalità opzionali supportate da OpenRouter. Usalo per nuove UI, revisioni sostanziali della UI, lavoro sul sistema di componenti, rifinitura delle interazioni o esplorazione di design in prodotto.
