good-ui の上に、意見のある個人的な UI 実装システムをウェブアプリや製品インターフェース向けに適用します。これには、完全に作成されたビジュアルスタイリング、実際のアイコンアセット、4px/8px の間隔、標準化されたコントロールサイズ、エッジクリアランス、拡張されたヒットエリア、すべてのインタラクション状態、意図的なフォーカス動作、継続性を保つモーション、shadcn ファーストのプリミティブ、プロダクションコンポーネントギャラリー、一時的な開発オーバーレイ、Git のチェックポイント、オプションの OpenRouter バックエンド機能が含まれます。新規 UI、 大幅な UI 改訂、 コンポーネントシステムの作業、 インタラクションの磨き上げ、 または製品内デザイン探索に使用してください。
