Автоматизация браузера для AI‑агентов через inference.sh. Переход по веб‑страницам, взаимодействие с элементами с помощью ссылок @e, создание скриншотов, запись видео. Возможности: веб‑скрапинг, заполнение форм, щелчки, ввод текста, перетаскивание, загрузка файлов, выполнение JavaScript. Использовать для: веб‑автоматизации, извлечения данных, тестирования, браузинга агентом, исследований. Триггеры: браузер, веб‑автоматизация, скрапинг, навигация, клик, заполнение формы, скриншот, просмотр веба, playwright, безголовый браузер, веб‑агент, серфинг в интернете, запись видео.
