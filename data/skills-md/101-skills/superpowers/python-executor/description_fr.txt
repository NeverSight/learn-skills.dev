Exécutez du code Python dans un environnement sandbox sécurisé via [inference.sh](https://inference.sh). Préinstallés : NumPy, Pandas, Matplotlib, requests, BeautifulSoup, Selenium, Playwright, MoviePy, Pillow, OpenCV, trimesh et plus de 100 bibliothèques supplémentaires. Utilisez pour : traitement de données, scraping web, manipulation d’images, création de vidéos, traitement de modèles 3D, génération de PDF, appels d’API, scripts d’automatisation. Déclencheurs : python, exécuter du code, exécuter un script, scraping web, analyse de données, traitement d’images, montage vidéo, modèles 3D, automatisation, pandas, matplotlib
