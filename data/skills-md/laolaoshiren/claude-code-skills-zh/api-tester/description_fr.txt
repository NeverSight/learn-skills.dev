Générez et validez les tests d’API en vous basant sur les spécifications OpenAPI réelles, les implémentations de routes et les tests existants. Utilisez cela pour les tests d’interface demandés par l’utilisateur, les tests d’intégration complémentaires, la vérification du contrat d’API, la génération de cas de test de régression ou le dépannage de la compatibilité d’interface ; distinguez l’autorisation pour la « génération de test » et celle pour « l’exécution de requête », ne devinez pas les codes d’état, les structures de réponse ou les SLA, et n’envoyez pas de requêtes d’écriture dans des environnements non vérifiés.

Veuillez toujours répondre dans la langue de l’utilisateur.
