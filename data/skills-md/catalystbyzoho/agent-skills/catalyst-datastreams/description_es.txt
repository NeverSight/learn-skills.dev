Catalyst Data Streams — canales de publicación/suscripción en tiempo real mediante WebSocket. Publica desde una función con **publishData** / **publish_data**, genera un par de tokens con **getTokenPair** / **get_token_pair**, suscríbete con **DataStreamsWebSocket** / **ZCDataStreamsWebSocket** (Node.js, navegador, Java, Python), envía **sendAck**, tipos de suscripción **live/earliest/resume**, retención de 48 horas, control de acceso con Roles de Usuario vs Lógica Personalizada.
