Catalyst Data Streams — каналы публикации/подписки в реальном времени через WebSocket. Публикация из функции с помощью publishData / publish_data, выдача пары токенов с помощью getTokenPair / get_token_pair, подписка через DataStreamsWebSocket / ZCDataStreamsWebSocket (Node.js, браузер, Java, Python), sendAck, типы подписки live/earliest/resume, хранение данных 48 часов, контроль доступа через роли пользователей vs пользовательскую логику.
