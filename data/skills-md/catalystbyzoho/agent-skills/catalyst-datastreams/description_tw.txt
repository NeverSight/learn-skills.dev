Catalyst Data Streams — 實時的 publish/subscribe 通道，透過 WebSocket。可在函式中使用 publishData / publish_data 發布，使用 getTokenPair / get_token_pair 產生 token 配對，使用 DataStreamsWebSocket / ZCDataStreamsWebSocket（Node.js、瀏覽器、Java、Python）訂閱，sendAck，支援 live / earliest / resume 訂閱類型，保留期限 48 小時，提供使用者角色與自訂邏輯的存取控制。觸發關鍵字包括「Data Streams」「datastreams」「real-time channel」「live updates」「pub/sub」「WebSocket subscriber」「token pair」「wss-id」「app_user_id is missing」「Invalid access control source」「Authentication failed 3000」「@zcatalyst/datastreams」或「zcatalyst_sdk.datastreams」。請始終以使用者的語言回覆。
