Планирует и осуществляет переход между техническими состояниями, такими как изменение фреймворка, зависимости, схемы, API или инфраструктуры, в обратимых шагах с определённой совместимостью, целостностью данных, порядком выполнения и откатом. Используется, когда системе необходимо перейти из одного состояния в другое. Не предназначено для обычной поставки функций без изменения состояния.
