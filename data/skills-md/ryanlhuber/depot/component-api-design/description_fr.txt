Spécifie l'interface publique d'un composant d'interface utilisateur réutilisable : entrées, variantes, gestion de l’état, événements, points de composition, crochets de style et contrat d’accessibilité. Utilisez-le lorsqu’un composant sera partagé entre plusieurs écrans ou équipes, ou lorsqu’une interface de composant existante devient incohérente ou difficile à utiliser correctement.
