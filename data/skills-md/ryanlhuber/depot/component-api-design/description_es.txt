Especifica la interfaz pública de un componente UI reutilizable: entradas, variantes, propiedad del estado, eventos, puntos de composición, ganchos de estilo y contrato de accesibilidad. Úsalo cuando un componente se compartirá entre pantallas o equipos, o cuando la interfaz de un componente existente se haya vuelto inconsistente o difícil de usar correctamente.
