Specifica l'interfaccia pubblica di un componente UI riutilizzabile: input, varianti, gestione dello stato, eventi, punti di composizione, hook di stile e contratto di accessibilità. Da usare quando un componente verrà condiviso tra schermate o team, o quando l'interfaccia di un componente esistente è diventata incoerente o difficile da utilizzare correttamente.
