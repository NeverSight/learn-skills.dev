Verfeinert ein Arbeitselement (ein Issue, Ticket, Task oder eine einfache Anfrage) dialogisch zu einer genehmigten, umsetzungsbereiten Spezifikation, Entscheidung für Entscheidung, ohne die Entwicklung zu starten. Anwendung, wenn eine Anfrage präzise und ausdrücklich genehmigt werden muss, bevor jemand sie umsetzt. Funktioniert mit jedem Tracker, einer Datei oder allein im Chat. Nicht zum Schreiben von Code oder zur Auswahl, wer es umsetzt.
