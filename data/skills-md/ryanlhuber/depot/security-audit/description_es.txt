Audita un alcance definido de código, configuración y manejo de datos en busca de debilidades de seguridad, rastrea cada una desde un punto de entrada accesible para un atacante hasta un activo, y devuelve hallazgos documentados con una declaración de cobertura. Úselo cuando una área del sistema necesite una revisión de seguridad antes del lanzamiento, después de cambios en autenticación, autorización o manejo de datos, o como parte de una auditoría de repositorio. No es para revisar un único cambio contra su especificación ni para escanear vulnerabilidades de paquetes únicamente.
