ينفّذ الحالات التي يمكن أن تكون فيها الشاشة أو المكوّن بخلاف الحالة المثالية (التحميل، فارغ، جزئي، خطأ، معطل، غير متصل، محتوى طويل أو مفقود) استنادًا إلى مواصفات الحالة، بحيث تكون كل حالة قابلة للتمثيل، والعرض، والإعلان، والاسترجاع، والإثبات. يُستخدم عندما يتم بناء شاشة أو مكوّن بحالات محددة، أو عندما يتعامل مكوّن موجود فقط مع الحالة المثالية.
