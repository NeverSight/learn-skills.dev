Implementa los estados que una pantalla o componente puede tener más allá del caso ideal (cargando, vacío, parcial, error, deshabilitado, sin conexión, contenido largo o faltante) a partir de una especificación de estados, de modo que cada estado sea representable, renderizado, anunciado, recuperable y demostrable. Úsalo cuando se está construyendo una pantalla o componente con estados especificados, o cuando uno existente solo maneja el caso ideal.
