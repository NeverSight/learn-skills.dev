Implementiert die Zustände, die ein Bildschirm oder eine Komponente über den Idealfall hinaus annehmen kann (Laden, leer, teilweise, Fehler, deaktiviert, offline, lange oder fehlende Inhalte) aus einer Zustandspezifikation, sodass jeder Zustand darstellbar, gerendert, angekündigt, wiederherstellbar und demonstrierbar ist. Verwenden Sie dies, wenn ein Bildschirm oder eine Komponente mit festgelegten Zuständen erstellt wird oder wenn ein bestehendes nur den Idealfall behandelt.
