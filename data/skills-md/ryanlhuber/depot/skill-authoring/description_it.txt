Crea o revisiona una singola skill di agente portatile: un file SKILL.md focalizzato con una descrizione che si attiva al momento giusto, input chiari, un processo azionabile, verifiche e comportamento testato. Utilizzare quando qualcuno vuole una nuova skill, un flusso di lavoro ripetuto trasformato in skill, o una skill esistente perfezionata o corretta. Non è destinato alla scrittura di agenti o flussi di lavoro, né alla documentazione generale.
