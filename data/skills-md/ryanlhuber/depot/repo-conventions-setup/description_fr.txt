Enregistre les conventions de travail d’un dépôt pour les agents d’IA dans son fichier d’instructions d’agent : où se trouvent les éléments de travail, comment les spécifications et les notes sont présentées, quels contrôles exécuter et ce que les agents ne doivent pas faire. À utiliser lorsque le dépôt adopte pour la première fois des compétences d’agent ou que ses conventions changent. Pas pour installer des compétences et pas pour choisir un système de suivi ou une chaîne d’outils.
