Versucht, zu beweisen, dass eine Überarbeitung einer Änderung nicht korrekt ist, anhand von Beweisen, ohne frühere Reviews zu sehen, und gibt einen PASS‑ oder FAIL‑Bericht mit den durchgeführten Angriffen zurück. Verwenden, wenn eine Änderung eine zweite, isolierte Überprüfung durch einen Gutachter benötigt, der weder der Ersteller noch der erste Prüfer ist. Nicht zum Bearbeiten von Code oder für eine Erstprüfung.
