Überprüft eine Revision einer Änderung anhand ihrer genehmigten Spezifikation und gibt einen PASS‑ oder FAIL‑Bericht mit belegten Befunden, Schweregrad sowie den ausgeführten und nicht ausgeführten Tests zurück. Verwenden Sie dies, wenn eine Änderung eine erste, unabhängige Prüfung vor dem Merge durch einen Gutachter benötigt, der nicht ihr Ersteller ist. Nicht zum Bearbeiten von Code oder für Tests von adversarialen Angriffen.
