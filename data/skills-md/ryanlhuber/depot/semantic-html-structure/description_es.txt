Elige y escribe HTML semántico para una página o componente: áreas de referencia, esquema de encabezados, elementos nativos para enlaces, botones, listas, tablas y formularios, nombres accesibles y ARIA solo cuando los elementos nativos no pueden expresar la necesidad. Úsalo cuando se esté escribiendo o reestructurando el marcado, o cuando el marcado construido a partir de elementos genéricos deba corregirse para usuarios de teclado y de tecnologías de asistencia.
