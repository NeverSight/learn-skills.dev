Choisit et écrit du HTML sémantique pour une page ou un composant : repères, structure des titres, éléments natifs pour les liens, les boutons, les listes, les tableaux et les formulaires, noms accessibles, et ARIA uniquement lorsque les éléments natifs ne peuvent pas exprimer le besoin. À utiliser lorsque le balisage est rédigé ou restructuré, ou lorsque le balisage construit à partir d’éléments génériques doit être corrigé pour les utilisateurs de clavier et de technologies d’assistance.
