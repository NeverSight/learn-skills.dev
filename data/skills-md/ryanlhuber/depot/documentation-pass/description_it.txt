Migliora la documentazione di un repository per un lettore specifico: individua indicazioni mancanti, obsolete, duplicate o difficili da navigare, le corregge usando file e comandi reali e verifica i collegamenti. Da utilizzare quando la documentazione è assente o obsoleta, o prima di una versione o consegna. Non è un sostituto dell'implementazione, della revisione del codice o delle decisioni.
