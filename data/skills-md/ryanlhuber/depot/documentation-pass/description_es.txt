Mejora la documentación de un repositorio para un lector específico: encuentra guías faltantes, obsoletas, duplicadas o difíciles de navegar, las corrige usando archivos y comandos reales, y verifica los enlaces. Úsalo cuando la documentación falta o está desactualizada, o antes de un lanzamiento o entrega. No sustituye la implementación, la revisión de código o las decisiones.
