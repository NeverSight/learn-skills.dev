Améliore la documentation d’un dépôt pour un lecteur nommé : détecte les guides manquants, obsolètes, dupliqués ou difficiles à parcourir, les corrige en utilisant les fichiers et commandes réels, et vérifie les liens. À utiliser lorsque la documentation est manquante ou périmée, ou avant une version ou une remise. Ce n’est pas un substitut à l’implémentation, à la revue de code ou aux décisions.
