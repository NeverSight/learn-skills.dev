قم بتنفيذ واجهة برمجة تطبيقات نقاط الولاء لتطوير Access على الخادم الخاص بك. هذه المهارة تُرشدك خلال بناء خمس نقاط نهاية REST لاستدعاءات Access لإدارة أرصدة نقاط الولاء، والحجوزات المؤقتة، والاسترداد، والاسترداد النقدي، والإلغاءات. يغطي عقد OpenAPI 3.0، ومُحقق توقيع الطلب HMAC‑SHA256 (بنمط Stripe، لكل برنامج)، ووصفات المنصة، والتماثل، ودورة حياة الحجز المؤقت، والاختبار. استخدمها عند دمج استرداد نقاط الولاء ("حرق") في منصة Access Travel.
