Реализуйте API программы лояльности Access Development на своём сервере. Этот навык проведёт вас через создание пяти REST‑конечных точек Access для управления балансами баллов лояльности, блокировками, погашениями, возвратами и отменами. Охватывает контракт OpenAPI 3.0, проверку подписи запросов HMAC‑SHA256 (в стиле Stripe, для каждой программы), рецепты платформы, идемпотентность, жизненный цикл блокировок и тестирование. Используйте при интеграции погашения баллов лояльности («сжигание») в платформу Access Travel.

Пожалуйста, всегда отвечайте на языке пользователя.
