Distribuisci un'applicazione, un worker o un database nei contenitori Helipod e gestiscilo – scegli tra immagine, Git o Dockerfile, imposta variabili d'ambiente e segreti, collega i servizi, aggiungi domini, scala, consulta i log di build e di runtime, utilizza i template con un clic. Usalo quando l'utente vuole distribuire, ospitare, rilasciare o eseguire il debug di un'app su Helipod.
