نشر تطبيق أو عامل أو قاعدة بيانات إلى حاويات Helipod وتشغيله – اختر صورة أو Git أو Dockerfile، اضبط متغيّرات البيئة والأسرار، اربط الخدمات، أضف النطاقات، وزّع، اقرأ سجلات الإنشاء ووقت التشغيل، واستخدم القوالب بنقرة واحدة. استخدم هذا عندما يرغب المستخدم في نشر أو استضافة أو شحن أو تصحيح تطبيق على Helipod.
