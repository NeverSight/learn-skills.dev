Despliega una aplicación, worker o base de datos en contenedores Helipod y operala: elige imagen, Git o Dockerfile, configura variables de entorno y secretos, conecta servicios, añade dominios, escala, lee los registros de compilación y de ejecución, usa plantillas de un clic. Úsalo cuando el usuario quiera desplegar, alojar, enviar o depurar una app en Helipod.
