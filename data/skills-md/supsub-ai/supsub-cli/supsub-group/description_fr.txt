Gestion des groupes d’abonnement SupSub — créer / renommer / supprimer des groupes, afficher les sources d’abonnement d’un groupe (avec le nombre d’éléments non lus), ajouter / retirer des sources d’abonnement à/un groupe. Correspond à « mes groupes », « créer un nouveau groupe », « ajouter XX à YY groupe », « retirer XX d’un groupe », « quelles abonnements sont dans le groupe YY », « combien d’éléments non lus sont dans ce groupe », « renommer le groupe », « supprimer le groupe », « organiser les abonnements / catégoriser les abonnements ». ⚠️ Désambiguïsation : **group** est un « dossier » qui regroupe les sources abonnées, organisées par sourceId + sourceType ; **focus** est un flux de contenu généré par IA agrégé par sujet (« mon focus / ce que je suis abonné » → supsub‑focus) ; l’abonnement/désabonnement de la source elle‑même passe par supsub‑sub. Supprimer un groupe est irréversible (les sources d’abonnement à l’intérieur du groupe ne sont pas affectées).
