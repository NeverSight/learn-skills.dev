Управление группами подписок SupSub — создание / переименование / удаление групп, просмотр источников подписок внутри группы (с количеством непрочитанных), добавление / удаление источников подписок в / из групп. Соответствует “мои группы”, “новая / создать группу”, “добавить XX в группу YY”, “удалить XX из группы”, “какие подписки находятся в группе YY”, “сколько непрочитанных элементов в этой группе”, “переименовать группу”, “удалить группу”, “организовать подписки / категоризировать подписки”. ⚠️ Разъяснение: **группа** — это «папка», содержащая подписанные источники, организованные по sourceId + sourceType; **фокус** — это поток контента, генерируемый ИИ и агрегированный по теме («мой фокус / что я слежу» → supsub‑focus); подписка/отписка от самого источника происходит через supsub‑sub. Удаление группы необратимо (источники подписок внутри группы не затрагиваются).
