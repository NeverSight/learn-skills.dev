SupSub 深度阅读（deep read）——一种由 AI 驱动的对**已在上下文中出现的特定文章**进行深度分析，产出“一句话精髓 / 实质性要点 / 核心观点 / 分段正文 / 编辑注记（背景·立场·来源可信度·最薄弱环节）”。它匹配的提示包括“深入阅读此文”“深度阅读”“帮我剖析这个”“这篇文章解释得够彻底吗”“这篇文章可靠吗/有没有实质内容/有没有立场”“值得阅读吗”“深入阅读这些文章并做简报”，以及“昨天的深度阅读完成了吗”“我还有哪些深度阅读没看过”。指令：`supsub deepread run / get / list / quota / share / drop / show`。⚠️ **深度阅读会消耗月度付费配额**；在开始前必须先运行 `deepread quota` 以获取当前余额，并向用户复述“将消耗 N 次 / 本月剩余 M 次”，以取得同意。⚠️ **contentId 必须来源于本轮的上下文**（子内容 / 重点内容 / 搜索结果）；如果无法匹配或匹配到多篇文章，必须始终询问用户——绝不猜测或自行捏造。⚠️ `deepread share` 会生成**任何人都可访问且不可撤销的公开链接**，创建前必须另行确认。浏览文章列表使用 supsub-sub / supsub-focus；关键词文章搜索使用 supsub-search。

请始终使用用户的语言回复。
