SupSub Deep Read — глубокий AI‑анализ **статьи, уже появившейся в контексте**, с выводом «однострочного смысла / практических выводов / ключевых пунктов / сегментированного текста / редакционных заметок (фон·позиция·надежность источника·самый слабый звено)». Осуществляет команды вроде «глубоко прочитай это», «прочитай это глубоко», «помоги разобрать эту статью», «поясняет ли статья всё полноценно», «надежна ли статья / содержит ли полезный контент / есть ли у неё позиция», «стоит ли её читать», «глубоко прочитай эти статьи и сделай брифинг», а также «был ли сделан вчерашний глубокий анализ», «какие глубокие чтения я ещё не видел». Команды: `supsub deepread run / get / list / quota / share / drop / show`. ⚠️ **Глубокий анализ расходует ежемесячную платную квоту**; перед запуском необходимо сначала выполнить `deepread quota`, чтобы узнать текущий баланс, и сообщить пользователю «это займёт N раз / осталось M раз в этом месяце», получив согласие. ⚠️ **contentId должен поступать из текущего раунда контекста** (результат sub contents / focus contents / search); если не найдено совпадений или найдено несколько, всегда спрашивайте пользователя — не угадывайте и не создавайте вручную. ⚠️ `deepread share` создаёт **публичную ссылку, доступную каждому и не может быть отозвана**, и перед созданием её нужно отдельно подтвердить. Просмотр списков статей осуществляется через supsub‑sub / supsub‑focus; поиск статей по ключевому слову — через supsub‑search.

Пожалуйста, всегда отвечайте на языке пользователя.
