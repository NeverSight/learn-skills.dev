SupSub Deep Reading — AI 기반의 심층 분석으로 **이미 컨텍스트에 등장한 특정 기사**에 대해 “한 문장 요약 / 실용적인 시사점 / 핵심 포인트 / 섹션 텍스트 / 편집자 노트(배경 · 입장 · 출처 신뢰도 · 가장 약한 연결고리)”를 제공합니다. “이 기사 깊게 읽어줘”, “철저히 읽어봐”, “이 글을 분석해줘”, “이 기사가 충분히 설명하고 있나요”, “이 기사의 신뢰성은? / 실질적인 시사점이 있나요 / 입장이 있나요”, “읽을 가치가 있나요”, “여러 글을 깊게 읽고 브리핑을 만들어줘”, 그리고 “어제의 심층 읽기가 끝났나요”, “아직 보지 않은 심층 읽기가 있나요”와 같은 요청에 대응합니다. 명령어: `supsub deepread run / get / list / quota / share / drop / show`.

⚠️ **심층 읽기는 월간 유료 할당량을 소모합니다**; 시작하기 전에 반드시 `deepread quota`를 실행해 현재 잔액을 확인하고 사용자에게 “이번에 N번 소모됩니다 / 이번 달에 M번 남았습니다”라고 알려준 후 동의를 받아야 합니다.

⚠️ **contentId는 현재 라운드의 컨텍스트(하위 컨텐츠 / 포커스 컨텐츠 / 검색 결과)에서 가져와야 합니다**. 일치 항목이 없거나 복수인 경우 절대로 추측하거나 직접 입력하지 말고 항상 사용자에게 물어보세요.

⚠️ `deepread share`는 **누구나 접근 가능하고 취소할 수 없는 공개 링크**를 생성합니다; 생성하기 전에 별도의 확인을 받아야 합니다. 기사 목록을 탐색할 때는 `supsub-sub` / `supsub-focus`를 사용하고, 키워드 검색은 `supsub-search`를 사용합니다.

항상 사용자의 언어로 답변하십시오.
