SupSub intensive reading (deep read) — an AI‑driven deep analysis of **a specific article that has already appeared in the context**, producing “one‑sentence essence / substantive takeaways / core points / segmented main text / editorial notes (background · stance · source credibility · weakest link)”. It matches prompts such as “intensively read this”, “deep read it”, “help me dissect this”, “does this article explain it thoroughly”, “is this article reliable / does it have substantive content / does it have a stance”, “is it worth reading”, “intensively read these articles and make a briefing”, as well as “was yesterday’s intensive read done”, “which intensive reads haven’t I seen yet”. Commands: `supsub deepread run / get / list / quota / share / drop / show`. ⚠️ **Intensive reading consumes a monthly paid quota**; before initiating you must first run `deepread quota` to obtain the current balance and repeat to the user “will consume N times / M remaining this month” to obtain consent. ⚠️ **contentId must come from the current round’s context** (sub contents / focus contents / search results); if it cannot be matched or matches multiple articles, always ask the user—never guess or manually fabricate. ⚠️ `deepread share` generates a **public link that anyone can access and cannot be revoked**, and must be confirmed separately before creation. Browsing article lists uses supsub-sub / supsub-focus; keyword article search uses supsub-search.
