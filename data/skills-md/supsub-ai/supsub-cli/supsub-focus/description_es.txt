Gestión de foco de SupSub — listar mis puntos de foco, ver el contenido/artículos agregados dentro de un punto de foco específico (filtrar por leído/no leído, soportar paginación), marcar todo un punto de foco como leído, eliminar un punto de foco. Coincide con expresiones como “mis puntos de foco”, “lista de puntos de foco”, “lo que sigo”, “el contenido que sigo”, “ver qué contenido/artículos están en el foco X”, “qué elementos no leídos hay en el foco X”, “cuántos elementos no leídos quedan en un punto de foco”, “he terminado este punto de foco / marcar el foco como leído”, “eliminar el foco X”. ⚠️ El estado de lectura solo se aplica al punto de foco completo (`mark-read --all`, irreversible): los artículos no tienen un paso de “detalles / leído”, por lo que no se admite marcar un solo artículo como leído. ⚠️ También coincide con expresiones de navegación que usan un nombre de tema para referirse al propio punto de foco: “mirar el contenido reciente de X”, “qué hay de nuevo de X últimamente” — cuando se encuentre tal solicitud, primero ejecutar `supsub focus list` para comparar X con los títulos de puntos de foco existentes (incluyendo coincidencia difusa, sin distinción de mayúsculas). Si coincide, usar `focus contents` para extraer el contenido de ese punto de foco; si X también coincide con el nombre de una fuente de suscripción, listar ambas opciones para que el usuario elija; si no coincide con ninguno, recurrir a `supsub-search` para realizar una búsqueda en todo el sitio (no preguntar al usuario si desea buscar), no tratarlo como una búsqueda de palabras clave predeterminada en todo el sitio. Un punto de foco es una corriente de contenido temático agregada a partir de múltiples fuentes (cuenta pública MP / sitio web / Twitter X). ⚠️ Discriminación de verbos: “follow / followed / what I follow / focus point” pertenecen a esta habilidad (foco); solo “subscribe / subscribed” van a supsub‑sub (fuente de suscripción). No se usa para añadir, eliminar o consultar fuentes de suscripción (eso usa supsub‑sub), ni para búsquedas de texto completo por palabra clave (eso usa supsub‑search). La CLI no tiene un comando para añadir un nuevo punto de foco; la eliminación es irreversible.
