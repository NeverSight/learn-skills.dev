Управление фокусами SupSub — список моих фокусов, просмотр агрегированного контента/статей в конкретном фокусе (фильтрация по прочитанным/непрочитанным, поддержка постраничного вывода), пометить весь фокус как прочитанный, удалить фокус. Соответствует запросам «мои фокусы», «список фокусов», «что я слежу», «контент, который я слежу», «посмотреть, какой контент/статьи находятся в фокусе X», «какие непрочитанные элементы в фокусе X», «сколько непрочитанных элементов осталось в фокусе», «я закончил этот фокус / пометить фокус как прочитанный», «удалить фокус X». ⚠️ Статус чтения применяется только к **уровню всего фокуса** (`mark-read --all`, необратимо): нет шага «детали / чтение» для отдельных статей, поэтому пометка отдельной статьи как прочитанной не поддерживается. ⚠️ Также соответствует выражениям просмотра, использующим название темы для ссылки на собственный фокус: «посмотреть недавний контент X», «что нового с X недавно» — при возникновении таких запросов сначала выполните `supsub focus list`, чтобы проверить, соответствует ли X существующему названию фокуса (включая нечеткое сопоставление, без учёта регистра). Если совпадает, используйте `focus contents` для получения контента этого фокуса; если X также совпадает с именем источника подписки, выведите оба варианта для выбора пользователем; если ничего не совпадает, сразу используйте `supsub-search` для выполнения поиска по всему сайту (**не спрашивать пользователя, нужно ли искать**), **не** рассматривайте это как обычный поиск по ключевому слову по всему сайту. Фокус — это поток контента, агрегированный по теме из нескольких источников (публичный аккаунт MP / веб‑сайт WEBSITE / Twitter X). ⚠️ Дискриминация глаголов: «follow / followed / what I follow / focus point» относятся к этому навыку (фокус); только «subscribe / subscribed» относится к `supsub-sub` (источник подписки). Не используется для добавления/удаления/запроса источников подписки (через `supsub-sub`) и не для полнотекстового поиска по ключевому слову (через `supsub-search`). В CLI нет команды для добавления нового фокуса; удаление необратимо.
