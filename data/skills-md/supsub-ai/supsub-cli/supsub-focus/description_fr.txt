SupSub gestion des focalisations — lister mes focalisations, voir le contenu/les articles agrégés dans une focalisation particulière (filtrer par lu/non lu, prise en charge de la pagination), marquer une focalisation entière comme lue, supprimer une focalisation. Correspond aux expressions telles que « mes focalisations », « liste de focalisations », « ce sur quoi je me suis concentré », « contenu sur lequel je me concentre », « voir quels contenus/articles sont dans la focalisation X », « quels éléments non lus sont dans la focalisation X », « combien d'éléments non lus restent dans la focalisation », « j'ai terminé cette focalisation / marquer la focalisation comme lue », « supprimer la focalisation X ». ⚠️ Le statut de lecture s'applique uniquement à l'ensemble de la focalisation en tant qu'unité (`mark-read --all`, irréversible) : les articles n'ont pas d'étape « détails / lu », donc le marquage d'un seul article comme lu n'est pas supporté. ⚠️ Correspond également aux expressions de navigation qui utilisent un nom de sujet pour désigner sa propre focalisation : « jeter un œil au contenu récent de X », « quoi de neuf avec X récemment » — lorsqu'une telle demande est rencontrée, exécuter d'abord `supsub focus list` pour vérifier si X correspond à un titre de focalisation existant (y compris correspondance partielle, insensible à la casse) ; si oui, utiliser `focus contents` pour récupérer le contenu de cette focalisation ; si X correspond également à un nom de source d'abonnement, lister les deux options pour que l'utilisateur choisisse ; si aucune des deux ne correspond, passer directement à `supsub-search` pour effectuer une recherche sur l'ensemble du site (**ne pas demander à l'utilisateur s'il veut rechercher**), **ne pas** la traiter comme une recherche par mot‑clé par défaut sur tout le site. Une focalisation est un flux de contenu thématique agrégé à partir de plusieurs sources (compte public MP / site WEB / Twitter X). ⚠️ Discrimination des verbes : « focus », « focused », « ce sur quoi je me suis concentré », « point de focus » appartiennent tous à cette compétence (focus) ; seuls « subscribe », « subscribed » vont à `supsub-sub` (source d'abonnement). Elle n'est pas utilisée pour ajouter/supprimer/interroger des sources d'abonnement (gérées par `supsub-sub`), ni pour la recherche plein texte (gérée par `supsub-search`). L'interface CLI n'a aucune commande pour ajouter une nouvelle focalisation ; la suppression est irréversible.
