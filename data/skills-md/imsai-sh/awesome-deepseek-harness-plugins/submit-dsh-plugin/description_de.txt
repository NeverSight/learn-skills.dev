Validieren Sie DeepSeek Harness-Plugins und senden Sie sie an das Community-Verzeichnis imsai-sh/awesome-deepseek-harness-plugins. Dies ist für Plugin-Autoren gedacht, die ihre Plugins einbinden, veröffentlichen oder übermitteln, ein Verzeichnis-JSON erstellen, PRs für die Verzeichnisübermittlung korrigieren oder Compliance-PRs initiieren möchten. Überprüfen Sie das öffentliche Repository, das DSH-Plugin-Thema, dsh.bundle.patch, Autorentestnachweise, zweisprachige Metadaten und Einzeldatei-Diffs und führen Sie nach der Autorisierung einen Fork durch, pushen Sie und erstellen Sie eine PR.
