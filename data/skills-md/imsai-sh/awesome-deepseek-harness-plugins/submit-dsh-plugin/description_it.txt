Convalida e invia il plug-in DeepSeek Harness alla directory della community imsai-sh/awesome-deepseek-harness-plugins. Si applica agli autori di plugin che richiedono l'inclusione, la pubblicazione o l'invio dei propri plugin, la creazione di una directory JSON, la correzione dei PR di invio della directory o l'avvio di PR di conformità. Controlla il repository pubblico, l'argomento del plugin dsh, dsh.bundle.patch, le prove dei test dell'autore, i metadati bilingui e le differenze a file singolo e, dopo aver ottenuto l'autorizzazione, esegui il fork, esegui il push e crea un PR.
