Convalida e invia i plugin DeepSeek Harness alla directory della community imsai-sh/awesome-deepseek-harness-plugins. Questo vale per gli autori di plugin che richiedono l'inclusione, la pubblicazione o l'invio dei propri plugin, creando il JSON della directory, correggendo i PR di invio della directory o avviando PR di conformità. Controlla i repository pubblici, l'argomento del plugin dsh, dsh.bundle.patch, le prove dei test dell'autore, i metadati bilingui e le differenze a file singolo e, dopo aver ottenuto l'autorizzazione, esegui un fork, push e crea un PR.
