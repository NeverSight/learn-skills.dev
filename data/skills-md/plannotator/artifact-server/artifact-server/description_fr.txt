Publiez, révisez, organisez et partagez votre travail avec Artifact Server, ou effectuez une installation lorsque l'utilisateur demande explicitement un travail d'administrateur. À utiliser pour les liens, fichiers ou sites Artifact Server à télécharger, projeter, artefact, version, baliser, partager ou commenter le travail, l'aide à la connexion et les demandes explicites d'installation, de déploiement, de mise à niveau, de sauvegarde, de restauration ou de réparation. Ne pas utiliser pour la publication de packages non liés ou pour la création de logiciels que l'utilisateur n'a pas demandé de stocker dans Artifact Server.
