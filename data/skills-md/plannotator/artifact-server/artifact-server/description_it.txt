Pubblica, rivedi, organizza e condividi il lavoro con Artifact Server o esegui un'installazione quando l'utente richiede esplicitamente il lavoro dell'amministratore. Utilizzare collegamenti, file o siti di Artifact Server per caricare, progettare, creare artefatti, versioni, tag, condividere o commentare lavori, assistenza per la connessione e richieste esplicite di installazione, distribuzione, aggiornamento, backup, ripristino o riparazione. Non utilizzare per la pubblicazione di pacchetti non correlati o per la creazione di software che l'utente non ha chiesto di archiviare in Artifact Server.
