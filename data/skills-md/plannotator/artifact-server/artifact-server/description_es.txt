Publique, revise, organice y comparta el trabajo con Artifact Server u opere una instalación cuando el usuario solicite explícitamente trabajo de administrador. Úselo para enlaces, archivos o sitios de Artifact Server para cargar, proyectar, artefacto, versión, etiquetar, compartir o comentar trabajo, ayuda de conexión y solicitudes explícitas de instalación, implementación, actualización, copia de seguridad, restauración o reparación. No lo utilice para la publicación de paquetes no relacionados ni para crear software que el usuario no solicitó almacenar en Artifact Server.
