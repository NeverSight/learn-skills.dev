Руководит партнёра при создании формы регистрации торговца EMAP на их собственном сайте. Охватывает Интеграцию 1 (полная форма — все 6 шагов регистрации размещены на сайте партнёра, каждый шаг проксируется к API EMAP), Интеграцию 2 (перенаправление — браузер перенаправляет на EMAP с данными первого шага в параметрах URL, EMAP предварительно заполняет и автоматически отправляет форму) и Интеграцию 3 (регистрация по электронной почте — бекенд партнёра отправляет POST‑запрос с данными первого шага в REST‑API EMAP, EMAP создаёт запись и отправляет торговцу защищённую ссылку для завершения полной заявки). Предоставляет ссылки на поля, шаблоны кода и контрольный список по безопасности.
