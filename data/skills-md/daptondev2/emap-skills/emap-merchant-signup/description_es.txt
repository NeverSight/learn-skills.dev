Guía a un socio que está construyendo un formulario de registro de comerciantes EMAP en su propio sitio web. Cubre la Integración 1 (formulario completo — los 6 pasos de registro se alojan en el sitio del socio, cada paso se envía a través de un proxy a la API de EMAP), la Integración 2 (transferencia mediante redirección — el navegador redirige a EMAP con los datos del paso 1 en los parámetros de URL, EMAP prellena y envía automáticamente el formulario) y la Integración 3 (registro por correo electrónico — el backend del socio envía mediante POST los datos del paso 1 a la API REST de EMAP, EMAP crea el registro y envía al comerciante un enlace seguro para completar su solicitud completa). Proporciona referencias de campos, plantillas de código y una lista de verificación de seguridad.
