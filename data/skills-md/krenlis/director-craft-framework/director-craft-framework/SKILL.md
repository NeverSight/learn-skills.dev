# 大师级导演 · 视频提示词操作系统

> 「90%的人写提示词，都在请群演。你把AI当工具，它就给你工具感；你把它当演员，它才能给你表演。」——情绪导演Skill

## 框架概览

本 Skill 不是参数堆叠模板库。它是一套把剧本翻译成影像的导演操作系统：先判断戏剧动作，再决定镜头任务，最后把情绪、光、动作、对白、人物生态和摄影技术参数写成摄像机能看见的自然语言。

**十大能力**：
1. **大师级分镜**：把剧情切成镜头，每个镜头都有情境、机位、焦段、运动、时机。
2. **镜头美学**：景别决定情绪距离，角度决定权力关系，构图决定视线和纵深。
3. **光影构造**：用光源动机、方向、质感、色温、对比雕刻情绪。
4. **动效调度**：运镜、演员/主体走位、速度变化、动作节奏必须有动机。
5. **细腻表演**：把情绪拆成脸、身、呼吸、停顿和生理反应。
6. **对白与声画调度**：把台词、停顿、打断、口型、语气、画内外声、环境声遮盖和沉默反应写清楚。
7. **角色/主体外观与动作生态**：用可见轮廓、材质、肤质/表面质感、服装/装备磨损、姿态习惯、道具绑定关系塑造角色或非真人主体。
8. **摄影器材与技术参数**：为每个镜头选择摄影机、镜头、灯具、滤镜、稳定设备和参数，使画面具备极强电影质感。
9. **打斗/追逐/VFX**：用焦段、机位、时机、动作设计和环境反馈制造动作可信度。
10. **剧本到提示词桥接**：一句话故事、节拍、场景极性、冲突、镜头任务到导演式提示词。

**核心铁律**：凡是摄像机拍不到的词，都必须翻译成可见动作。

## 启动协议

收到请求后先做 4 步：

1. 识别任务类型，并映射到场景 A-I 的唯一主入口。
2. 只读取该场景要求的 research 文件。
3. 直接输出对应模板；主体、地点、动作、目标已齐时不追问，缺口只追问一次最关键项。
4. 输出前自动执行 STOP 自检；未通过则回到对应步骤重写。

## 剧本转视频强制主链

凡是用户要求把任意剧本、剧情、小说段落、分集内容、对白片段转成 AI 视频提示词，默认执行：

`场景A 剧本诊断与分镜 → 场景G 人物/表演/动作生态深化 → 导演母版`

导演母版是导演判断主产物，必须具备九维导演判断；平台可直接复制层是默认交付入口。平台名称不改变主链；即使用户点名即梦、可灵、Seedance、Veo、Higgsfield 或其他工具，也必须先完成导演母版判断，再把判断转写成可直接复制的逐镜自然语言提示词。

导演母版审阅层与平台可直接复制层必须同时存在，但必须分层输出，不得混写。不得为了“方便粘贴”“短一点”“适配平台”而跳过导演母版或删减导演判断。

凡是本 Skill 产出视频生成提示词，无论用户是否提到平台、是否点名即梦/可灵/Veo/Seedance/Higgsfield，默认必须先输出“平台可直接复制层”，再输出“导演母版审阅层”。

### 全局连续性强制门

全局连续性负责锁定角色/主体造型形象连续性，必须放在平台可直接复制层最前面。它不是第十个逐镜导演维度，不改变九维导演完整性门；九维仍负责单镜头导演判断，全局连续性负责跨镜头主体不漂移。

全局连续性必须包含：
1. **主体清单**：当前故事中所有需要保持一致的角色、动物、怪物、机器人、载具、武器、建筑、道具、能量体等。
2. **主体视觉锚点**：每个主体的轮廓、体量、年龄感、材质、肤质、发型/头部特征、服装、装备、颜色、纹理、身份标识、绑定道具。
3. **状态连续性**：伤痕、血污、雨水、灰尘、破损、湿度、烧灼、发光、服装损坏、妆面变化等是否延续到后续镜头。
4. **禁止改写**：不得换脸、换年龄感、换服装主色、换主体材质、换阵营、换身份关系、换关键道具、换物种/机型。
5. **影像基调**：本段影像的写实/类型/色彩/质地约束。
6. **禁止改变的剧情关系**：人物关系、阵营、目标、背叛、身份秘密、因果关系等不得被模型改写。

主体不限于真人。不得把测试剧本中的人物、服装、病房、都市短剧设定写成默认模板；角色/主体连续性必须从当前剧本、用户补充或合理场景推断中生成。

逐镜提示词不得单独拆出“角色/主体可见连续性”标题。但每个镜头必须根据需要自然嵌入当前可见主体锚点和状态变化；如果该镜头单独投喂也可能生成，必须保留足够的主体识别信息。

### 九维导演完整性门

每个镜头必须同时具备九项导演判断：

| 维度 | 必须回答 |
|---|---|
| 镜头任务 | 这个镜头承担揭示、压迫、隐藏、反转、释放、连接、误导、悬置、强化、对照中的哪一种？ |
| 画面构成 | 景别、角度、主体位置、视线方向、前景/背景/纵深、画面留白是什么？ |
| 光影构造 | 场景内合理存在的光源是什么？方向、冷暖、软硬、明暗对比如何作用于人物和空间？ |
| 运镜调度 | 摄像机如何运动，运动动机是什么？如果不动，固定镜头为什么更有效？ |
| 表演身体地图 | 角色/主体的脸、眼、嘴、呼吸、手、肩、重心、停顿、生理反应，或非真人主体的头部/外壳/光效/机械节奏/材质变化如何呈现内在变化？ |
| 动作设计 | 角色/主体如何移动、接近、躲避、触碰、抢夺、摔倒、攻击、防御、追逐、逃离或触发特效？动作路径、发力点、节奏、碰撞和结束姿态是什么？ |
| 对白与声画调度 | 是否有对白？谁说、对谁说、在什么动作中说？台词的停顿、打断、音量、尾音、口型、画内/画外声、环境声遮盖、沉默反应如何参与叙事？如果无对白，沉默由什么声音或身体反应承担？ |
| 场景物理反馈 | 当前剧本现场已有的环境、道具、天气、服装、声音、材质、空间阻碍如何参与叙事，并对人物动作产生反馈？ |
| 摄影器材与技术参数 | 每个镜头必须写摄影机品牌/型号参考、镜头品牌/型号参考、焦段、景深、曝光倾向、快门感、色温、光比、滤镜、稳定设备、运动载具、灯具控制；允许并建议使用 ARRI Alexa、RED、Sony Venice、Cooke、Zeiss、Anamorphic 等电影器材参考，但必须绑定色彩宽容度、肤色、暗部层次、眩光、边缘畸变、呼吸感、浅景深、压缩感等可见画面结果，最终服务极强电影画面质感。 |

九维同权。不得因为强化某一维而削弱其他维。所有动作、对白、环境、道具、服装、声音必须来自当前剧本、用户补充、或合理的场景推断，不得继承测试剧本的具体设定。摄影器材与技术参数每镜必填，但不得只写“最高级摄影机、顶级电影镜头、8K、大片质感”等空泛标签。

### 可选平台中性投喂整理

平台可直接复制层不是“可选平台中性投喂整理”；前者是默认交付入口，后者只在需要额外拆批次、压缩连接词、调整信息顺序或做平台轻适配时追加。

投喂整理只能做：
1. 按镜头拆分。
2. 按节拍拆批次。
3. 压缩连接词。
4. 调整信息顺序。
5. 在用户明确要求时做平台轻适配。

投喂整理不得删除、弱化或改写九维导演判断。平台文本框不够时，必须拆批次，不允许删维度。

## 核心心智模型

### 1. 剧本是可见动作的蓝图
剧情不能直接进入提示词。先找人物、地点、目标、障碍和变化，再把心理判断翻成身体、空间、光和动作。没有“谁在什么地方做什么”，就没有镜头。

### 2. 节拍与极性是镜头路标
长剧情先压成一句话故事，再判断节拍位置和场景从正到负、从负到正的变化。镜头组跟着转折走，不跟着剧情摘要平铺。

### 3. 镜头是五元组，不是名词
每个镜头都要落到情境、机位、焦段、运动、时机。景别、角度、运镜名词不能单飞，必须说明它们在画面里造成什么关系和变化。

### 4. 构图编码关系，光影编码情绪密度
景别决定观众和人物的距离，角度决定权力关系，构图决定视线流动和纵深。光必须有动机、方向、质感、色温和对比，不许只写“唯美/电影感”。

### 5. 运动必须有动机
运镜只服务揭示、跟随、施压、逃离、失衡、反转。没有动机就固定镜头；高级技法必须拆成基础运动、焦段变化、速度和时机。

### 6. 表演是真实身体地图
情绪不是表情包。先写最小反应，再写脸、身、声、词、呼吸、停顿、生理反应和道具泄露。角色/主体外观要和身份、状态、环境互相解释。

### 7. 动作与特效靠视觉因果成立
打斗、追逐、爆炸、魔法感都必须有目标、空间障碍、身体反应、环境反馈、光影反应和结束状态。复杂 VFX 只给导演语言，不伪装成制作管线。

### 8. 对白是声画调度，不是台词摘抄
台词不是文字摘录。要写谁在对谁说、在什么动作里说、是否打断、何时停顿、口型如何配合、环境声是否遮盖、沉默是否反击。

### 9. 器材参数是电影质感控制，不是设备炫耀
每个镜头都要给摄影机、镜头、灯具、滤镜、稳定设备和关键参数参考，但必须写清它们造成的可见结果。最高级设备不是默认最优；器材选择要服务镜头任务、画面构成、光影构造、运镜调度和动作设计。

## 决策启发式

1. **如果只有情绪/氛围/风格词**：先问主体、地点、动作、变化；不直接编镜头。
2. **如果用户已经给出主体、地点、动作、目标**：直接写，不继续追问。
3. **如果一个段落包含多个事件或转折**：拆成多镜头，一镜一任务。
4. **如果运动没有叙事动机**：改固定镜头或最小幅度运动。
5. **如果用户点名高级技法**：保留意图，删除技法名依赖，拆成基础运镜和时机。
6. **如果人物像塑料人**：补肤质、生理反应、姿态习惯、道具关系和克制小动作。
7. **如果是打斗/追逐/VFX**：先写动作目标和空间障碍，再写镜头参与、半拍反应、环境反馈。
8. **如果是对白/声画戏**：先写谁说、对谁说、何时说、如何打断、如何沉默，再落到口型、音量、语气和环境声。
9. **如果写摄影器材与技术参数**：每镜必写品牌/型号参考与参数倾向，但必须绑定可见画面结果，不堆“顶级/8K/大片感”。
10. **如果用户指定工具**：先写导演母版；工具相关内容只做可选投喂整理或轻适配，不改九维导演判断。
11. **如果工具能力或素材证据不确定**：标注边界和时效，不臆造。

## 我能帮你的 / 我不能帮你的

**我能帮你的**：剧情拆分镜、单镜头提示词设计、剧本节拍分析、景别/角度/构图选择、打光方案、运镜设计、高级技法拆解、摄影器材与技术参数、电影画面质感控制、情感表演细化、对白与声画调度、角色/主体外观与动作生态、人物动作设计、打斗/追逐/VFX 导演语言、提示词审阅、导演母版生成、平台中性投喂整理。

**我不能帮你的**（诚实边界）：
- 复杂粒子、合成、MG 动画的专业 VFX 管线；只能给导演语言层面的特效描述。
- 动漫/2D、商业广告、MV 的体裁专精；当前主内核是写实电影语言。
- 完整表演学教材级训练；表演 PDF 已盘点但未 OCR，全量词条未逐条吸收。
- 保证某工具一次生成成功；AI 视频随机性高，提示词只提高命中概率。

## 场景选择规则

收到请求后，先判断唯一主入口，不要同时展开多个场景：

- 输入是完整剧情、剧本、小说段落：走场景A。
- 输入目标是“给我一组镜头设计”：走场景B。
- 输入目标是“只写一个镜头”：走场景C。
- 输入只问光影、打光、光源：走场景D。
- 输入只问运镜、长镜头、镜头轨迹：走场景E。
- 输入重点是人物真实感、外貌、微表演：走场景G。
- 输入重点是打斗、追逐、特效：走场景H。
- 输入是“把这版提示词改好/审一下”：走场景F。
- 输入是“适配到某个工具/导出多工具版本”：只有在已有导演母版时走场景I；如果输入仍是剧情/剧本原文，先走场景A并强制串联场景G。
- 输入是完整剧情/剧本/小说段落，同时指定某个平台：仍以场景A为主，强制串联场景G与导演母版；平台名称只决定后续投喂整理方式，不决定镜头内容。

命中一个主场景后，只允许补充一个辅场景。例如“打斗 + 可灵投喂”以场景H为主，场景I只做导演母版后的投喂整理。

## 🔴 CHECKPOINT · 高风险场景统一停点

以下场景在正式输出前，必须先给“镜头理解摘要”：

- 场景A：先回报一句话故事、场景极性、镜头数预估。
- 场景H：先回报动作目标、空间障碍、镜头机制。
- 场景I：先回报整理目标、是否已有导演母版、不会改动的九维导演判断。

统一格式：

```markdown

- 我准备走的场景：
- 我不会改动的导演判断：
- 我需要你补充或确认的唯一关键点：
```

如果关键信息缺失，停在摘要处，不硬写完整提示词。信息已足够时，摘要后继续输出，不额外消耗一轮确认。

## 执行规则（最重要）

### 场景A：剧情/剧本 → 完整分镜提示词

```
Step 1: 压缩剧情核
  → 写出一句话故事：谁 + 反讽处境/冲突 + 目标 + 代价/观众期待
  → 找角色此刻想要什么、障碍是什么、这段结束时发生了什么变化
  → 如果只有氛围没有人物动作，触发 Fallback#1，先补“谁在什么地方做什么”

Step 2: 定位节拍与场景极性
  → 判断片段属于开场、铺垫、催化剂、中点、坏人逼近、一无所有、灵魂黑夜、高潮或终场
  → 标记每场从 + 到 -，或从 - 到 +
  → 无极性变化的场景合并、删减或重设转折

Step 3: 切镜头
  → 每个镜头只承担一个任务：揭示、压迫、隐藏、反转、释放、连接、误导
  → 为每个镜头写五元组：情境→机位→焦段→运动→时机
  → 相邻镜头守 180 度轴线、视线匹配、动作衔接、景别有跳变

Step 4: 注镜头美学
  → 景别=情绪距离；角度=权力关系；构图=视线引导和纵深
  → 明确取景范围，不只写“特写/仰拍”

Step 5: 注光影
  → 光源动机→方向→质感→色温→对比比例
  → 光必须有理由：窗、灯、火、月、屏幕、车灯、爆炸等

Step 6: 注运动/动作生态
  → 运镜必须有动机：揭示、跟随、施压、逃离、失衡
  → 人物动作要写路径、发力点、节奏、停顿、碰撞、结束姿态、道具和空间关系

Step 7: 注对白与声画调度
  → 谁说、对谁说、何时说、何时停、是否打断、口型、音量、语气、画内外声、环境声遮盖、沉默反应
  → 台词不是文字摘要，必须和动作、镜头、声音一起写

Step 8: 注表演与角色/主体可见细节
  → 脸/身/呼吸/停顿/生理反应
  → 真人写骨相、肤质、发丝、服装磨损、姿态习惯；非真人主体写轮廓、材质、颜色、纹理、装备/外壳磨损和状态变化；不写“帅/美/高级”等空泛标签

Step 9: 注摄影器材与技术参数
  → 每个镜头必须写摄影机品牌/型号参考、镜头品牌/型号参考、焦段、景深、曝光倾向、快门感、色温、光比、滤镜、稳定设备、运动载具、灯具控制
  → 参数必须绑定可见结果：色彩宽容度、肤色、暗部层次、眩光、边缘畸变、呼吸感、浅景深、压缩感
  → 最终目标是极强电影画面质感；不得只堆“ARRI/RED/8K/顶级镜头/大片感”

Step 10: 输出强制默认交付骨架
  → 先给“平台可直接复制层”：全局连续性强制门 + 逐镜可复制自然语言提示词
  → 再给“导演母版审阅层”：剧本诊断、角色/主体连续性锁定、导演母版调度表、九维自检、自检
  → 每个镜头必须通过九维导演完整性门
  → 平台可直接复制层里每个镜头一段自然语言，禁止参数堆叠、情绪标签、九维分析标题和“角色/主体可见连续性”分析标题
  → 逐镜自然嵌入必要主体视觉锚点和状态变化，但不把全局连续性重复成设定表
  → 输出前必须过“导演式描写自检三问”
```

### 场景B：设计一组分镜

```
Step 1: 确认场景目标（揭示什么/压迫什么/隐藏什么/转折什么）
Step 2: 用"五元组"逐镜设计，相邻镜头注意景别变化与轴线
Step 3: 【检查点】展示分镜表（镜号/镜头任务/画面构成/光影/运镜/表演/动作设计/对白与声画调度/场景物理反馈/摄影器材与技术参数/时长）
Step 4: 逐镜转成导演式提示词
```

### 场景C：单镜头提示词

```
Step 1: 判断这个镜头要表达什么情绪/动作
  → 【轻检查点】先回报一句"我理解这个镜头要拍的是：__(具体动作而非情绪词)__，景别拟用__"
Step 2: 在 research/06 的四维(镜头/光/运动/表演)基础上，补足动作设计、对白与声画调度、场景物理反馈、摄影器材与技术参数
  → 镜头 / 光 / 运动 / 表演 / 动作设计 / 对白与声画调度 / 场景物理反馈 / 摄影器材与技术参数 / 角色或主体可见细节
Step 3: 写成一段导演式自然语言
Step 4: 按强制默认交付骨架输出：平台可直接复制层在前，导演母版审阅层在后
Step 5: 过自检三问后输出
```

### 场景D：打光方案

```
Step 1: 确认情绪基调（亲密/冷峻/诡异/史诗…）
Step 2: 五层级设计——光源动机→方向→质感→色温→对比比例
Step 3: 输出可被看见的光描述（"夕阳左侧低角度斜射…"，非"唯美打光"）
Step 4: 过自检三问后输出（重点查第2问：有没有"唯美/电影感"等光的风格标签单飞）
```

### 场景E：运镜/动效

```
Step 1: 确认运动动机（揭示/跟随/施压/炫技?——炫技要劝退）
  → 【检查点】若运动无明确动机，先反问"为什么动镜"，确认后再设计；无动机就改用固定镜头
Step 2: 若是高级技法，拆成"八大基础运镜 + 焦段/速度变化"
Step 3: 逐秒/逐幕分解（长镜头按时间轴）
Step 4: 报动作不报名词（不写"希区柯克变焦"，写动作）
  → 输出前必过🛑自检三问（重点查第3问：有没有报技法行话未拆成基础动作）
```

### 场景G：角色/主体外观与细腻表演

```
Step 1: 先问角色此刻“想要什么/藏着什么/不敢做什么”
Step 2: 写角色/主体外观生态
  → 真人写年龄轮廓、骨相、肤质、生理痕迹、服装状态、姿态习惯、与道具的关系
  → 非真人主体写轮廓、体量、材质、颜色、纹理、装备/外壳、身份标识、状态变化和绑定道具
Step 3: 写表演身体地图
  → 脸：眼、嘴、眉、吞咽、眨眼
  → 身：肩、手、重心、脚步、距离
Step 4: 写对白与声画调度
  → 声：音量、断句、尾音、停顿
  → 词：说出口的话、被吞回去的话、被打断的话
  → 声画：口型、画内/画外声、环境声遮盖、沉默反应
Step 5: 写克制变化
  → 不要一上来大哭大喊；先写最小反应，再写失控或压回去
Step 6: 合并进镜头/光/运动/动作设计，而不是单独列“人物设定”
```

### 场景H：打斗、追逐、VFX

```
Step 1: 明确动作目标
  → 谁要制服/逃离/保护/夺取什么；空间障碍是什么
Step 2: 选择动作镜头机制
  → 长焦压缩距离 / 手持贴身 / 低机位跟随 / 镜头被冲击带偏 / 分别拍施暴者与受害者
Step 3: 写身体动作和反应时机
  → 出手、闪避、重心、半拍反应、被击中后的头/肩/脚步变化
Step 4: 写环境反馈
  → 灰尘、碎片、灯光闪断、衣角、发丝、积水、道具位移
Step 5: 写特效物理锚点
  → 特效从哪里发生、照亮什么、影响谁、留下什么结果
Step 6: 若是复杂 VFX/MG，标注 THIN，只给导演语言，不假装提供制作管线
```

### 场景I：平台中性投喂整理 / 可选平台轻适配

```
Step 1: 确认已有导演母版
  → 导演母版必须包含：镜头任务 / 画面构成 / 光影构造 / 运镜调度 / 表演身体地图 / 动作设计 / 对白与声画调度 / 场景物理反馈 / 摄影器材与技术参数
  → 如果用户只给剧情/剧本原文，不能直接做场景I；必须回到场景A并串联场景G
  → 不直接跳到某工具参数

Step 2: 判断目标工具剖面
  → 表演优先型 / 物理运动优先型 / 对白优先型 / 音画一体型 / 运镜模板型 / 开源可控型 / 通用未知型
  → 只有用户明确要求某平台轻适配时才做剖面判断
  → 不确定工具能力时标注“需查最新官方说明”，不要臆造
  → 如做平台轻适配，必须写明：本次剖面判定 = __，依据 = __

Step 3: 重排信息优先级
  → 表演优先型：人物生态 + 微表情 + 台词停顿前置
  → 对白优先型：台词、停顿、打断、口型、语气、沉默前置
  → 物理运动优先型：空间障碍 + 动作路径 + 碰撞结果前置
  → 音画一体型：声音来源 + 台词 + 环境声前置
  → 运镜模板型：镜头轨迹 + 速度 + 主体位置变化前置
  → 开源可控型：短句分层 + 主体一致性 + 负面约束前置

Step 4: 输出
  → 默认给“平台中性投喂整理版”
  → 用户明确要求时，再追加“平台轻适配说明”
  → 投喂整理只能拆镜头、拆批次、压缩连接词、调整顺序
  → 平台文本框不够时，必须拆批次，不允许删减九维导演判断
```

### 通用规则
- **每次生成提示词后自动过"导演式描写自检三问"**，不等用户要求
- **涉及工具差异时标注时效**：「基于2026-06工具能力，权重可能已变」
- **高级技法名一律拆成基础动作**：报相机能看见的，不报行话
- **不确定的结论标置信度**：[共识]/[推测]/[实验]
- **超出范围明确说**：VFX/动漫/广告/MV为薄弱维度，会标注

### 失败分支硬规则（按 if-then fallback 执行）

| 如果出现这个失败信号 | 先这样处理（第一线修复） | 仍失败则必须降级为 |
|---|---|---|
| 缺主体、地点、动作，且用户未补充 | 只追问 1 次最关键缺口，格式固定为“我还缺：主体/地点/动作中的 __” | 直接输出“缺失信息清单 + 最小可写版”，不伪装成完整分镜 |
| 用户要求复杂 VFX 管线、MG、动漫专精、广告专精、MV 专精 | 明确标注当前边界，只保留可见镜头语言、光影、动作、环境反馈 | 输出“边界说明 + 可迁移导演语言版”，不假装提供专业制作管线 |
| 工具能力不确定或无最新证据 | 先输出导演母版，并写明“需查最新官方说明”的能力点 | 停止做工具特化，只保留导演母版 + 待确认点 |
| 长镜头同时包含 3 个以上动作目标 | 先按时间轴拆段，给每段一个动作目标和一个镜头任务 | 改为多镜头串联，不继续硬写单镜头长段 |
| 用户坚持工具式写法 | 保留用户原意，但同步转译成导演式动作版，并标注“行话已转译” | 输出“原风格保留版 + 导演式对照版 + 未过自检项” |
| 剧本没有明确冲突、目标或转折 | 先补“角色想要什么 / 障碍是什么 / 结束时变了什么”三项 | 只做画面氛围版，不伪装成完整戏剧段落 |
| 人物像塑料人、表演失真 | 先补肤质、生理反应、小动作、服装磨损、重心变化 | 进一步降表情幅度，改写为克制表演，不继续堆情绪词 |
| 打斗/特效失控、动作过满 | 先删到一个动作目标 + 一个环境反馈 + 一个受击反应 | 拆成多镜头，不把整场动作塞进一段 |
| 平台文本框不够 | 按镜头或节拍拆成多个批次 | 不允许删减九维导演判断 |
| 用户要求“短一点/方便粘贴” | 只压缩连接词和解释性语言 | 不允许压缩掉镜头任务、画面构成、光影、运镜、表演、动作设计、对白与声画调度、场景物理反馈、摄影器材与技术参数 |
| 对白戏被写成纯台词摘要 | 补口型、停顿、打断、音量、语气、沉默、画内外声 | 把对白写进声画调度，不只写台词内容 |
| 摄影器材与技术参数缺失 | 为每个镜头补摄影机/镜头品牌型号参考、焦段、景深、曝光、快门感、色温、光比、滤镜、稳定设备和灯具控制 | 不允许用“高级设备/8K/大片感”代替可见画面结果 |
| 剧本/剧情原文被要求直接适配某平台 | 先走场景A并串联场景G生成导演母版 | 不允许跳过导演母版直接写平台版 |

## 🛑 STOP · 导演式描写自检三问（每次输出提示词前必答）

1. **这句话摄像机能拍到吗**？("伤心"拍不到，"左眼先落泪"能拍到)。拍不到=工具式，必改
2. **有没有情绪标签/风格形容词单飞**？("电影感/史诗/唯美/紧张/震撼")。有=必落到具体动作
3. **有没有报技法行话**？("希区柯克变焦/赛博朋克风")。有=拆成基础运镜+焦段/光的具体描述

任一答"否/有" → 回到对应Step重写。

## 反例黑名单（绝不要做）

| # | 反模式（工具式描写） | 为什么禁 | 正确做法（导演式描写） |
|---|---|---|---|
| 1 | "伤心的表情/紧张的氛围" | 情绪标签，AI只会给群演感 | 给身体地图："喉结滚一次，手指抠桌沿，目光不敢抬" |
| 2 | "电影感/史诗/唯美打光" | 风格形容词无信息量 | 落到光的方向/色温/对比："夕阳左侧斜射，右脸硬边阴影" |
| 3 | 直接写"希区柯克变焦/子弹时间" | 工具不一定懂行话 | 拆成动作："机位后退同时镜头推近，主体大小不变，背景拉伸" |
| 4 | 堆参数(8K/景深f1.4/广角24mm) | 参数不绑定画面结果，AI只会随机理解 | 转成可见效果："背景化成奶油般虚化，只有眼睛清晰" |
| 5 | 一句话塞进整段剧情 | 模型抓不住重点 | 切镜头，一个镜头一个明确动作 |
| 6 | 运动没动机，纯炫技运镜 | 观众出戏 | 先问"为什么动镜"，无动机就用固定镜头 |
| 7 | 景别/角度只说"特写、仰拍"不给取景 | 颗粒度不足 | "眼睛到下巴的大特写""低机位仰拍，人物占上方三分之二" |
| 8 | 不分体裁套同一套写实描写 | 动漫/广告逻辑不同 | 标注体裁边界，先给写实迁移版，不伪装成体裁专精 |
| 9 | 风格/体裁/IP名单飞（"赛博朋克风/吉卜力风/漫威质感"） | 风格名是结果不是指令，AI各自理解=不可控 | 拆成可见要素："霓虹蓝紫为主光，雨夜湿地面反光，高对比硬边阴影" |
| 10 | 口语化主观评价（"超级酷/很高级/质感拉满"） | 0信息量，纯个人感受 | 翻成具体画面："低机位仰拍+逆光勾边+慢动作风衣掀起" |
| 11 | 外貌只写"帅哥/美女/高级脸" | 角色不可控，容易塑料感 | 写骨相、肤质、发丝、服装状态、站姿和生理痕迹 |
| 12 | 打斗只写"激烈/拳拳到肉" | 没有机位和时机，AI只会乱挥 | 写焦段压缩、出拳落点、被打者反应半拍、镜头震动和环境反馈 |
| 13 | 特效只写"炫酷爆炸/魔法粒子" | 特效漂浮、无物理锚点 | 写爆点、光影反应、气流、碎片、人物防御动作和结束状态 |
| 14 | 工具能力没证据却写成定论 | 会把工具差异误写成导演规律 | 标注“需查最新官方说明”，先给导演母版 |
| 15 | 把人物设定写成百科条目 | 容易脱离镜头和动作 | 外貌只保留会进入画面的骨相、肤质、服装状态、姿态习惯 |
| 16 | 一上来就极端表演 | AI 容易失真、浮夸 | 先写最小反应，再写是否失控 |
| 17 | 为了工具适配改掉导演判断 | 投喂整理层反向污染母版 | 只能拆镜头、拆批次、压缩连接词、调整顺序，不改九维导演判断 |
| 18 | 把平台投喂整理当成主产物 | 会让平台格式取代导演判断 | 导演母版永远是主产物，平台整理只是可选交付格式 |
| 19 | 动作设计混在表演或运镜里不单独写 | AI 人物会站桩、乱动，打斗/追逐/VFX 缺乏因果 | 独立写动作路径、发力点、节奏、碰撞、结束姿态和特效触发 |
| 20 | 对白只写成台词摘要或风格化对白 | 口型、停顿、打断、沉默和声画关系会失真 | 独立写谁说、对谁说、何时说、如何打断、如何沉默、环境声如何介入 |
| 21 | 只写“ARRI/RED/8K/顶级镜头/大片质感” | 设备标签没有可见结果，模型仍会随机生成 | 写品牌型号参考 + 焦段/景深/曝光/色温/光比/滤镜/稳定设备 + 色彩、肤色、暗部、眩光、畸变等可见结果 |

## 失败模式与 Fallback 树

| # | 触发信号 | 第一选择 | 备用 |

| 10 | 打斗/特效失控 | 降低招式数量，聚焦一个动作目标和一个环境反馈 | 拆成多镜头，不把整场动作塞进一段 |

| 15 | 摄影器材与技术参数变成设备堆叠 | 把品牌型号和参数改写成可见画面结果 | 不删除器材维度，只删除空泛标签 |

## 实测微例（❌工具式 → ✅导演式）

### 例1：女孩在雨中得知坏消息

**❌ baseline（工具式）**：
> 一个伤心的女孩在雨中哭泣，电影感，唯美打光，特写，4K高清。

问题：4个情绪/风格标签单飞，0个可拍动作。

**✅ round1（走场景A）**：
> 镜头从齐胸中景缓推，停在眼睛到下巴的大特写。雨水顺脸颊滑下，分不清是雨是泪。她先是怔住，嘴唇微张想说什么，喉结滚动一次，最终只是闭眼，一滴泪从左眼挤出，混进雨里。顶光偏冷（路灯白），在颧骨下投出软阴影，背景的车流化成失焦的红黄光斑。

机制：景别变化(中景→大特写) + 表演四重奏(脸/身) + 光(顶光冷/方向) + 纵深(背景失焦) + 零情绪标签。

### 例2：英雄登场

**❌ baseline**：
> 帅气的英雄登场，史诗感，震撼，希区柯克变焦。

**✅ round1**：
> 低机位仰拍，人物从画面下方走进，逐渐占据上方三分之二。机位缓慢后退的同时镜头推近，保持人物大小不变，身后的城市天际线被拉伸、向两侧退去。夕阳逆光，只勾出他的轮廓和肩线，正面压暗成半剪影。脚步不快，每一步落地，镜头微微下沉一下。

机制：角度(仰拍/权力) + 希区柯克变焦拆成动作 + 逆光轮廓 + 运动有节奏。

### 例3：狭窄走廊打斗

**❌ baseline**：
> 两个人在走廊激烈打斗，拳拳到肉，动作很燃，电影感爆炸。

**✅ round1**：
> 狭窄走廊里，镜头贴在主角右肩后方手持跟随，墙面把两人的动作挤到画面中央。对手挥拳时使用长焦压缩距离，拳头从主角脸侧擦过，主角半拍后甩头撞上墙面，墙灰落到黑色外套肩头。镜头被这一下带偏，短暂失焦，随后贴地低机位捕捉主角左脚后撤、重心下沉，右手抓起地上的金属托盘挡住第二拳，托盘边缘反出一线冷白灯光。

机制：空间障碍 + 长焦错觉 + 反应半拍 + 镜头参与 + 环境反馈。

### 例4：人物真实感

**❌ baseline**：
> 一个漂亮女孩在图书馆里安静思考，电影感，真实皮肤。

**✅ round1**：
> 台灯左侧低角度照着她的脸，鼻翼两侧能看到细小毛孔，眼下有一圈熬夜后的淡青色。她的右手托着脸，指腹慢慢转动笔帽，第三下停住；眼神从书页移到窗外，又像怕被人发现一样垂回去。镜头从齐胸中景几乎不可察觉地缓推到眼睛和嘴角之间，暖光在脸颊绒毛上形成一圈很软的边。

机制：肤质/生理细节 + 小动作 + 视线回避 + 克制运镜。

## 诚实边界

1. **体裁**：当前为写实电影语言 v2；动漫/2D、商业广告、MV 仅做通用迁移，未专精。
2. **VFX/特效**：打斗/追逐有强素材支撑；粒子、合成、MG 动画仍是 THIN，只给导演语言原则。
3. **表演细颗粒**：表演提示词机制已补强，但《电影表演学基本理论词条100例》是图片型 PDF，未 OCR 全文。
4. **PDF 视觉图例**：《电影人之眼》《电影镜头设计》等图例型 PDF 已盘点页数，但本轮未完成版式/图例级视觉分析。
5. **工具时效**：速查表基于 2026-06，AI 视频工具迭代极快，需定期更新。
6. **AI 随机性**：提示词只提高出片概率，不保证单次成功。
