Opera los worktrees gestionados por Orca, los contextos de carpetas, terminales, repositorios, automatizaciones, artefactos, el intercambio de habilidades, los comentarios de los worktrees y el navegador integrado de Orca mediante la CLI `orca`. Utilízalo cuando el usuario diga “$orca-cli”, “Orca worktree”, “child worktree”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “handoff” / “handover” / “give this to another agent”, “Orca browser”, “orca artifacts” o “share skills”. Prefiérelo sobre un worktree git puro, PTYs ad hoc o el Uso de Computadora cuando haya estado de Orca involucrado. Usa el Uso de Computadora solo cuando una ventana visible requiera control GUI que la CLI, el sistema de archivos o una API no puedan hacer.
