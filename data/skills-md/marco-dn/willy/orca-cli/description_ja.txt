Orca が管理する作業ツリー、フォルダーコンテキスト、ターミナル、リポジトリ、オートメーション、アーティファクト、スキル共有、作業ツリーコメント、そして Orca の組み込みブラウザは、`orca` CLI を通じて操作します。ユーザーが「$orca-cli」や「Orca worktree」「child worktree」「spawn codex/claude in a worktree」「read/wait/send Orca terminal」「handoff」／「handover」／「give this to another agent」「Orca browser」「orca artifacts」や「share skills」と言ったときに使用してください。Orca の状態が関わる場合は、単なる git worktree や臨時の PTY、または Computer Use よりもこれを優先します。CLI、ファイルシステム、API では実現できない GUI 操作が必要な可視ウィンドウがある場合にのみ、Computer Use を使用してください。

常にユーザーの言語で回答してください。
