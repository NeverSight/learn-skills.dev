通过 `orca` CLI 操作 Orca 管理的工作区、文件夹上下文、终端、仓库、自动化、制品、技能共享、工作区评论以及 Orca 的嵌入式浏览器。当用户说“$orca-cli”“Orca 工作区”“子工作区”“在工作区中生成 codex/claude”“读取/等待/发送 Orca 终端”“handoff”“handover”“交给其他代理”“Orca 浏览器”“orca artifacts”或“共享技能”时使用。涉及 Orca 状态时，优先使用它而非原始 git 工作区、临时 PTY 或计算机使用。只有在需要对可见窗口进行 GUI 控制，而 CLI、文件系统或 API 无法实现时才使用计算机使用。

请始终使用用户的语言回复。
