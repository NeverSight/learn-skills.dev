Überprüft Codeänderungen auf Korrektheit, Sicherheit und Wartbarkeit und gibt die Ergebnisse nach Schweregrad geordnet zurück. Verwenden Sie diese Funktion, wenn der Benutzer eine Codeüberprüfung, eine Überprüfung eines Pull Requests, eine Überprüfung eines Diffs oder eine zweite Durchsicht lokaler Änderungen anfordert.
