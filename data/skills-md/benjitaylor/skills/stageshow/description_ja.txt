本物の製品のように見える仮想プロダクト UI を構築します。静止画のイラストや、カーソル付きのアニメーションデモとして作成できます。ブラウザやアプリのウィンドウ、ダッシュボード、電話、通知、ターミナル、弁当グリッド、カーソルのウォークスルーなどを、マーケティングページやフィーチャーカード、ドキュメントのヒーローが必要とする形でフレーム化、マスク化、クロップします。誰かが偽の UI やモック UI、プロダクトデモやウォークスルーアニメーション、アプリのヒーローやフィーチャーカードのイラスト、洗練されたマーケティングサイト風のプロダクトショット、インターフェース内で何かを行うアニメーションカーソルを求めている場合に、たとえ「仮想 UI」という言葉を使わなくても使用してください。React とプレーン CSS を使用します。
