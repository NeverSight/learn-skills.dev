离线调查 Netdata 支持包——即 `netdata-support-bundle` 生成的归档——用于解释单个主机的警报、数据缺失、采集器故障、崩溃、高 CPU 或内存占用、流媒体、云认领、保留、仪表板可达性、权限、安装与更新、容器以及 Windows 问题。用于 “analyse this support bundle”“a customer sent a bundle”“what does this bundle say”“why did this agent crash”“why is this collector showing no data”“why are alerts not firing”，或在阅读 `MANIFEST.json`、`summary.txt`、`status-file.json` 或 `01-system` 到 `09-permissions` 目录下的任何文件时。**不**用于 `06-state/snmp-diagnostics` 下的 SNMP 证据（triage-snmp-diagnostics），不用于车队范围的崩溃或回归聚类（triage-agent-events），不用于对 Agent 或 Cloud 的实时查询（query-netdata-agents、query-netdata-cloud），也不用于更改捆绑采集器本身。

请始终使用用户的语言作答。
