Investiga un paquete de soporte de Netdata sin conexión – el archivo que produce `netdata-support-bundle` – para explicar las alertas de un host, datos faltantes, fallos de colectores, bloqueos, alto uso de CPU o memoria, transmisión, reclamación en la nube, retención, accesibilidad del panel, permisos, instalación y actualización, problemas con contenedores y Windows. Úsalo para “analizar este paquete de soporte”, “un cliente envió un paquete”, “qué dice este paquete”, “por qué se bloqueó este agente”, “por qué este colector no muestra datos”, “por qué no se disparan las alertas”, o al leer `MANIFEST.json`, `summary.txt`, `status-file.json` o cualquier archivo bajo `01-system` hasta `09-permissions`. No es para evidencia SNMP bajo `06-state/snmp-diagnostics` (triage-snmp-diagnostics), no es para análisis de fallos a nivel de flota o agrupamiento de regresiones (triage-agent-events), no es para consultas en tiempo real contra un Agente o la Nube (query-netdata-agents, query-netdata-cloud), y no es para modificar el propio colector del paquete. 

Por favor, responde siempre en el idioma del usuario.
