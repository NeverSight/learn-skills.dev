Usa per diagnosticare problemi con MySQL: stallo del redo log, esaurimento delle connessioni, esplosione del ritardo di purge, cascata di lock metadata o spirale di ritardo di replica. Interroga Netdata tramite MCP per la disponibilità del server MySQL, l'utilizzo delle connessioni, il throughput delle query (richieste), il tasso di query lente, la coda di esecuzione attiva (threads_running), applica l'albero diagnostico dal playbook dell'operatore Netdata e raccomanda la correzione.
