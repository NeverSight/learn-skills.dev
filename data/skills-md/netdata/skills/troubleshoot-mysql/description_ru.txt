Используйте при диагностике проблем с MySQL: задержка redo‑лога, исчерпание соединений, резкое увеличение задержки очистки, каскад блокировок метаданных или спиральная задержка репликации. Запрашивает у Netdata через MCP доступность MySQL‑сервера, использование соединений, пропускную способность запросов (вопросов), частоту медленных запросов, активную очередь выполнения (threads_running), применяет диагностическое дерево из плейбука оператора Netdata и рекомендует меры по исправлению.
