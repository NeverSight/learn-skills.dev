wx-cli — Interrogez les enregistrements de discussion, les contacts, les conversations, les favoris et plus encore depuis la base de données locale de WeChat. Lorsque les utilisateurs mentionnent les enregistrements de discussion WeChat, les contacts, l'historique des messages, les membres du groupe ou le contenu enregistré, utilisez cette compétence pour installer et invoquer wx-cli.

Veuillez toujours répondre dans la langue de l'utilisateur.
