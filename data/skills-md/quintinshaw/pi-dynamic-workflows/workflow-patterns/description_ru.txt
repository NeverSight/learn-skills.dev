Форматы аргументов для 5 встроенных шаблонов рабочего процесса — deep-research, adversarial-review, code-review, multi-perspective, codebase-audit — исполняются через параметр `name` инструмента `workflow` без синтаксиса слеш‑команды. Используйте их для запросов вроде «исследовать X», «проверить факты/адверсариально оценить это», «просмотреть этот diff/PR», «проанализировать с разных точек зрения» или «аудировать кодовую базу на предмет Y». Не предназначено для создания нового скрипта рабочего процесса — см. workflow‑authoring.
