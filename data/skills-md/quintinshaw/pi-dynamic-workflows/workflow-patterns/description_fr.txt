Formes d'argument pour les 5 modèles de flux de travail intégrés — deep‑research, adversarial‑review, code‑review, multi‑perspective, codebase‑audit — exécutables via l’entrée `name` de l’outil `workflow`, sans syntaxe de commande slash. À utiliser pour des requêtes telles que « research X », « fact‑check/adversarially review this », « review this diff/PR », « analyze from multiple perspectives » ou « audit the codebase for Y ». Pas destiné à la rédaction d’un nouveau script de flux de travail — voir workflow‑authoring.

Veuillez toujours répondre dans la langue de l’utilisateur.
