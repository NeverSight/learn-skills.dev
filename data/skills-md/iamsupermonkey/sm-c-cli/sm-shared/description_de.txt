SUPERMONKEY (Super Monkey) CLI‑gemeinsame Regel: verwaltet die CLI‑Autorisation für das Anmelden, autorisierte Abmelden und die Überprüfung der aktuellen Identität. Sie wird verwendet, wenn ein Benutzer wissen möchte, wie man sich bei sm‑c‑cli anmeldet oder abmeldet, den aktuell angemeldeten Benutzer oder den Autorisationsumfang einsehen will, prüfen will, ob ein Token gültig ist, oder wenn andere sm‑*‑Funktionen die Autorisation wiederherstellen müssen, weil sie nicht authentifiziert sind, das Token abgelaufen ist oder eine HTTP 401‑Antwort erhalten wurde.
