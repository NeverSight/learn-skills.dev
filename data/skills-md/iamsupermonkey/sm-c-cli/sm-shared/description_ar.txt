قواعد مشاركة CLI الخاصة بـ SUPERMONKEY (سوبر مونكي): إدارة تسجيل الدخول المصرح به عبر CLI، وتسجيل الخروج المصرح به، وفحوصات الهوية الحالية. استخدمها عندما يسأل المستخدم عن كيفية تسجيل الدخول أو تسجيل الخروج من sm-c-cli، وعرض المستخدم الحالي المسجل أو نطاق التفويض، والتحقق مما إذا كان الرمز صالحًا، أو عندما تحتاج وظائف sm-* الأخرى إلى استعادة التفويض بسبب عدم المصادقة، أو انتهاء صلاحية الرمز، أو استجابة HTTP 401. يرجى دائمًا الرد بلغة المستخدم.
