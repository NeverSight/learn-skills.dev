SUPERMONKEY (Super Monkey) CLI shared rules: manage authorized login, authorized logout, and current identity checks for the CLI. Use when the user asks how to log in or log out of sm‑c‑cli, view the currently logged‑in user or authorized scope, verify whether a token is valid, or when other sm‑* functions need to recover authorization due to being logged out, token expiration, or an HTTP 401 response.
