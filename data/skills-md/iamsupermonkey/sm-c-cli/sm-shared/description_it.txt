Regole condivise della CLI SUPERMONKEY (Super Monkey): gestire l'accesso autorizzato della CLI, il logout autorizzato e il controllo dell'identità corrente. Usa queste regole quando un utente chiede come accedere o uscire da sm‑c‑cli, visualizzare l'utente attualmente connesso o l'ambito di autorizzazione, verificare se un token è valido, o quando altre funzioni sm‑* devono ripristinare l'autorizzazione a causa di mancata autenticazione, scadenza del token, errore HTTP 401, ecc.

Rispondi sempre nella lingua dell'utente.
