Créez une vidéo d’animation dans un style visuel spécifique à partir d’une narration chinoise de 15 à 60 secondes (1920 × 1080, 30 ips MP4, avec narration et sous‑titres, prête à être glissée directement dans Jianying). L’ensemble du visuel est dessiné par Claude à l’aide de code HTML/Canvas, avec Chrome sans tête capturant les images et les composant, sans recourir à des modèles de génération d’images. Il comprend sept styles intégrés : diagramme plat, notes manuscrites, journal vintage, découpe de papier vintage, collage surréaliste, cartoon 3D, techno sur fond noir. Il peut également générer un nouveau style à partir d’une image de référence (ou d’une vidéo) fournie par l’utilisateur (méthode 2), ou, à partir d’une description textuelle, produire d’abord 2 à 3 images statiques sous différents angles que l’utilisateur pourra choisir avant de finaliser le style (méthode 3), accompagnées d’un dictionnaire de styles et d’une explication des règles générales d’animation et des connaissances sur les effets de mouvement (transitions, actions secondaires, vérifications de richesse). Il est utilisé lorsque l’utilisateur dit : « transformez cette narration en animation », « utilisez le style notes manuscrites », « quels styles sont disponibles », « suivez le style de cette image », « je veux l’aspect d’une affiche de tableau noir », « vérifiez l’environnement de l’animation de style », « rendez d’abord un exemple ».

Veuillez toujours répondre dans la langue de l’utilisateur.
