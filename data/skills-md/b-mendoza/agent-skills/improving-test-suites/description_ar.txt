قم بتحسين مجموعات الاختبار الحالية إلى الحد الأدنى من الأدوات التي تركز على سلوك الإشارة العالية مع الموافقة قبل الطفرة، وفحوصات التوافق، والتحقق الخاضع للحراسة، والإصلاح المحدود، وحالات التسليم القابلة للتدقيق. يُستخدم عندما يُطلب منك تحسين الاختبارات أو قصها أو إعادة كتابتها أو حذفها أو مراجعتها أو تشديدها حول العقود العامة أو منطق الأعمال أو المخططات أو السلوك الأمني ​​أو حالات الفشل أو حالات الحافة أو سهولة القراءة أو قابلية الصيانة.
