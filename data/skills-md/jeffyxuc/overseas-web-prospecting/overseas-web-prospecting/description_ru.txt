Разработка клиентов‑малых и средних бизнесов за рубежом в Codex: поиск компаний в Google Maps по региону и отрасли, рекомендация до пяти вариантов, помощь пользователю в выборе одной из них и анализ её сайта, а после утверждения плана – создание демонстрационной версии сайта. Сгенерировать персонализированный пакет писем‑разработки с реальными скриншотами в соответствии со стандартным мастер‑шаблоном. Используется для привлечения зарубежных сайтов, создания предложений по редизайну и писем‑разработки для торговцев, а также для продолжения текущих задач по привлечению. Применять google‑maps‑scraper, когда нужны только данные карты.
