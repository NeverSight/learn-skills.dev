Leitfaden zum Entwerfen eines GreptimeDB-Tabellenschemas für Leistung und zum Verbessern einer vorhandenen Tabelle. Deckt Primärschlüssel, Nur-Anhängen vs. Deduplizierung + Zusammenführungsmodus, Indizes (invertiert/überspringend/Volltext), breite vs. mehrere Tabellen und Partitionierung ab. Verwenden Sie diese Option, wenn der Benutzer fragt, wie er eine Tabelle modellieren, einen Primärschlüssel auswählen, einen Index auswählen, für die Skalierung partitionieren oder ein bereits vorhandenes Schema verbessern möchte. Löst Auslöser auf Ausdrücke wie „Entwurfstabelle“, „Entwurf“, „Schemaentwurf“, „Zusammenführungsmodus“, „Primärschlüssel“, „Erkennung“, „Welcher Index“, „Erkennung“, „Partitionstabelle“, „Nur Anhängen“, „Zusammenführungsmodus“ und „Mein Schema verbessern“ aus. Für die Optimierung der Serverkonfiguration verwenden Sie greptimedb-performance-tuning; Um einen Engpass zu finden, verwenden Sie zunächst greptimedb-performance-diagnose.
