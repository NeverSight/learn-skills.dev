Руководство по проектированию схемы таблицы GreptimeDB для повышения производительности и улучшению существующей таблицы. Охватывает первичный ключ, режим «только добавление» и «дедупликация + слияние», индексы (инвертированные/пропускающие/полнотекстовые), широкие или несколько таблиц и секционирование. Используйте, когда пользователь спрашивает, как смоделировать таблицу, выбрать первичный ключ, выбрать индекс, секцию для масштабирования или улучшить уже существующую схему. Запускается по таким фразам, как «таблица проектирования», «表设计», «проектирование схемы», «建表», «первичный ключ», «主键», «какой индекс», «选索引», «таблица разделов», «分区/分表», «только добавление», «режим слияния», «улучшить мою схему». Для настройки конфигурации сервера используйте greptimedb-performance-tuning; Чтобы найти узкое место, сначала используйте greptimedb-performance-diagnosis.
