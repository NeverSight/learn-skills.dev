Guida per progettare uno schema di tabella GreptimeDB per le prestazioni e per migliorare una tabella esistente. Riguarda la chiave primaria, la modalità di sola aggiunta o deduplicazione + unione, gli indici (invertiti/saltati/testo completo), le tabelle larghe o multiple e il partizionamento. Da utilizzare quando l'utente chiede come modellare una tabella, scegliere una chiave primaria, selezionare un indice, partizionare per ridimensionare o migliorare uno schema già esistente. Si attiva su frasi come "tabella di progettazione", "表设计", "progettazione di schema", "建表", "chiave primaria", "主键", "quale indice", "选索引", "tabella delle partizioni", "分区/分表", "append-only", "merge mode", "migliora il mio schema". Per l'ottimizzazione della configurazione del server utilizzare greptimedb-performance-tuning; per trovare un collo di bottiglia utilizzare prima greptimedb-performance-diagnosis.
