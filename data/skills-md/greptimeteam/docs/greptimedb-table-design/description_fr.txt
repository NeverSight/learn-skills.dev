Guide pour concevoir un schéma de table GreptimeDB pour les performances et pour améliorer une table existante. Couvre la clé primaire, le mode ajout uniquement ou déduplication + fusion, les index (inversé/saut/texte intégral), les tables larges ou multiples et le partitionnement. À utiliser lorsque l'utilisateur demande comment modéliser une table, choisir une clé primaire, choisir un index, partitionner à l'échelle ou améliorer un schéma qui existe déjà. Se déclenche sur des expressions telles que "table de conception", "表设计", "conception de schéma", "建表", "clé primaire", "主键", "quel index", "选索引", "table de partition", "分区/分表", "ajout uniquement", "mode de fusion", "améliorer mon schéma". Pour le réglage de la configuration du serveur, utilisez greptimedb-performance-tuning ; pour trouver un goulot d'étranglement, utilisez d'abord greptimedb-performance-diagnosis.
