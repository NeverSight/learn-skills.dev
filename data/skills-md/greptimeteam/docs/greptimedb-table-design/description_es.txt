Guía para diseñar un esquema de tabla GreptimeDB para mejorar el rendimiento y mejorar una tabla existente. Cubre la clave principal, el modo de agregar solo frente a la deduplicación + combinación, índices (invertidos/omitidos/texto completo), tablas anchas frente a múltiples y particiones. Úselo cuando el usuario pregunta cómo modelar una tabla, elegir una clave principal, elegir un índice, una partición para escalar o mejorar un esquema que ya existe. Activadores de frases como "tabla de diseño", "表设计", "diseño de esquema", "建表", "clave primaria", "主键", "qué índice", "选索引", "tabla de particiones", "分区/分表", "solo agregar", "modo de fusión", "mejorar mi esquema". Para ajustar la configuración del servidor, utilice greptimedb-rendimiento-tuning; Para encontrar un cuello de botella, primero utilice greptimedb-rendimiento-diagnosis.
