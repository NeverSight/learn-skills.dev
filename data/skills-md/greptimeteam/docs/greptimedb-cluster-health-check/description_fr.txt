Guide pour vérifier qu'un déploiement GreptimeDB est sain après le déploiement ou le redémarrage : vérifie l'état de préparation du pod/déploiement, l'accès au magasin d'objets via un test de fumée fonctionnel d'écriture/lecture, les journaux d'erreurs, les métriques clés et cette ingestion récupérée au taux attendu. À utiliser juste après un nouvel événement de déploiement, de mise à niveau, de redémarrage ou de mise à l'échelle lorsque l'utilisateur souhaite avoir la confirmation que le cluster est sain. Se déclenche sur des expressions telles que « mon cluster est-il sain », « 集群健康检查 », « après le déploiement/redémarrage », « 部署/重启后检查 », « vérifier le cluster », « vérification de l'état », « test de fumée », « nouveau cluster », « 新部署的集群 », « vérifier les pods », « autorisation du magasin d'objets ». Si une vérification échoue, transmettez-la à greptimedb-performance-diagnosis.
