Guía para ajustar la configuración del servidor GreptimeDB y las opciones de tabla para un mejor rendimiento: tamaño de caché, búfer de escritura, WAL y rendimiento de ingesta. Úselo cuando el usuario desee acelerar las consultas o escrituras, reducir las lecturas del almacén de objetos, corregir bloqueos/rechazos de escritura o ajustar el tamaño de las cachés y el búfer de escritura. Activadores de frases como "ajustar el rendimiento", "性能调优", "aumentar caché", "调大缓存", "caché de página/caché de escritura", "búfer de escritura", "写缓冲", "global_write_buffer_size", "deshabilitar WAL", "关闭 WAL", "mejorar el rendimiento de escritura", "提升写入吞吐", "escrituras por lotes". Para cambios de esquema/tabla (clave principal, índices, particiones), utilice greptimedb-table-design; Para encontrar primero el cuello de botella, utilice greptimedb-rendimiento-diagnosis.
