دليل لضبط تكوين خادم GreptimeDB وخيارات الجدول للحصول على أداء أفضل - تغيير حجم ذاكرة التخزين المؤقت، ومخزن الكتابة المؤقت، وWAL، وإنتاجية الاستيعاب. يُستخدم عندما يريد المستخدم تسريع الاستعلامات أو الكتابة، أو تقليل قراءات مخزن الكائنات، أو إصلاح توقف/رفض الكتابة، أو ذاكرة التخزين المؤقت ذات الحجم الصحيح والمخزن المؤقت للكتابة. تشغيل عبارات مثل "ضبط الأداء"، "زيادة ذاكرة التخزين المؤقت"، "زيادة ذاكرة التخزين المؤقت"، "ذاكرة التخزين المؤقت للصفحة/كتابة ذاكرة التخزين المؤقت"، "مخزن مؤقت للكتابة"، "写缓冲"، "global_write_buffer_size"، "تعطيل WAL"، "WAL"، "تحسين إنتاجية الكتابة"، "提升写入吞吐"، "يكتب دفعة واحدة". لتغييرات المخطط/الجدول (المفتاح الأساسي، الفهارس، التقسيم) استخدم greptimedb-table-design؛ للعثور على عنق الزجاجة أولاً، استخدم تشخيص أداء greptimedb.
