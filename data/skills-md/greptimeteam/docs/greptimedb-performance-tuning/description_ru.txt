Руководство по настройке конфигурации сервера GreptimeDB и параметров таблиц для повышения производительности — размера кэша, буфера записи, WAL и пропускной способности приема. Используйте, когда пользователь хочет ускорить запросы или запись, уменьшить количество операций чтения из хранилища объектов, исправить задержки/отклонения записи или подобрать кэши и буфер записи нужного размера. Запускается по таким фразам, как «настроить производительность», «性能调优», «увеличить кеш», «调大缓存», «кэш страниц/кеш записи», «буфер записи», «写缓冲», «global_write_buffer_size», «отключить WAL», «关闭 WAL», «улучшить пропускную способность записи», «提升写入吞吐», «пакетная запись». Для изменений схемы/таблицы (первичный ключ, индексы, секционирование) используйте greptimedb-table-design; чтобы сначала найти узкое место, используйте greptimedb-performance-diagnosis.
