Guide pour régler la configuration du serveur GreptimeDB et les options de table pour de meilleures performances : taille du cache, tampon d'écriture, WAL et débit d'ingestion. À utiliser lorsque l'utilisateur souhaite accélérer les requêtes ou les écritures, réduire les lectures du magasin d'objets, corriger les blocages/rejets d'écriture ou redimensionner les caches et le tampon d'écriture. Déclencheurs sur des expressions telles que « ajuster les performances », « 性能调优 », « augmenter le cache », « 调大缓存 », « page cache/write cache », « write buffer », « 写缓冲 », « global_write_buffer_size », « désactiver WAL », « 关闭 WAL », « améliorer le débit d'écriture », "提升写入吞吐", "écritures par lots". Pour les modifications de schéma/table (clé primaire, index, partitionnement), utilisez greptimedb-table-design ; pour trouver d'abord le goulot d'étranglement, utilisez greptimedb-performance-diagnosis.
