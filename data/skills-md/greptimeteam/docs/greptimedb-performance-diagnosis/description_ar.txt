دليل لتشخيص مشكلات أداء GreptimeDB - ابحث عن عنق الزجاجة وراء الاستعلام البطيء، أو الإدخال المتأخر أو المتوقف، أو ارتفاع وحدة المعالجة المركزية/الذاكرة، ثم قم بالتسليم إلى الإصلاح الصحيح. يُستخدم عندما يبلغ المستخدم عن شيء ما بطيء أو متعطش للموارد ويريد معرفة السبب. مشغلات لعبارات مثل "الاستعلام بطيء"، "查询慢"، "التناول بطيء"، "写入慢"، "مماطلة الكتابة"، "写入卡顿/被拒绝"، "وحدة المعالجة المركزية العالية"، "CPU 高"، "ذاكرة عالية"، "内存高/OOM"، "شرح التحليل"، "لماذا يتم ذلك" GreptimeDB بطيء"، "性能排查/诊断". تقوم هذه المهارة بالتشخيص؛ قم بتطبيق الإصلاحات باستخدام greptimedb-Performance-tuning وgreptimedb-table-design.
