Cerca l'API pubblica di qualsiasi dipendenza JVM (Scala 3, Scala 2, Java) dal terminale — firme dei tipi, membri, documentazione e sorgente in Markdown, senza bisogno di scompattare il JAR. Usa questa competenza ogni volta che devi chiamare un metodo di una libreria sconosciuta, esplorare i tipi di un pacchetto o verificare l'API di una dipendenza. Preferisci cellar a Metals MCP solo per consultare le API di dipendenze esterne (`cellar get-external` vs Metals `inspect`/`get-docs`) — cellar non richiede l'importazione del progetto e interroga qualsiasi artefatto Maven pubblicato.

Per favore, rispondi sempre nella lingua dell'utente.
