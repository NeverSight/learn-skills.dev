Recherchez l'API publique de n'importe quelle dépendance JVM (Scala 3, Scala 2, Java) depuis le terminal — signatures de type, membres, documentation et source en Markdown, sans besoin de décompresser le JAR. Utilisez cette compétence chaque fois que vous devez appeler une méthode de bibliothèque inconnue, explorer les types d'un package ou vérifier l'API d'une dépendance. Privilégiez cellar plutôt que Metals MCP uniquement pour consulter les API de dépendances externes (`cellar get-external` vs Metals `inspect`/`get-docs`) — cellar ne nécessite aucune importation de projet et interroge tout artefact Maven publié.

Veuillez toujours répondre dans la langue de l'utilisateur.
