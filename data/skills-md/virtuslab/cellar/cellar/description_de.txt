Rufe die öffentliche API einer beliebigen JVM‑Abhängigkeit (Scala 3, Scala 2, Java) im Terminal ab – Typ‑Signaturen, Mitglieder, Dokumentation und Quellcode als Markdown, ohne dass ein JAR entpackt werden muss. Nutze diese Fähigkeit, wann immer du eine unbekannte Bibliotheks‑Methode aufrufen, die Typen eines Pakets erkunden oder die API einer Abhängigkeit prüfen musst. Ziehe cellar gegenüber Metals MCP nur dann vor, wenn du externe Abhängigkeits‑APIs nachschlagen willst (`cellar get-external` gegenüber Metals `inspect`/`get-docs`) – cellar erfordert keinen Projekt‑Import und kann jedes veröffentlichte Maven‑Artefakt abfragen.

Bitte antworte immer in der Sprache des Benutzers.
