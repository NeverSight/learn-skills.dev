Ищите публичный API любой JVM‑зависимости (Scala 3, Scala 2, Java) прямо из терминала — сигнатуры типов, члены, документацию и исходный код в формате Markdown, без распаковки JAR‑файлов. Используйте эту возможность, когда нужно вызвать незнакомый метод библиотеки, исследовать типы пакета или проверить API зависимости. Предпочитайте cellar вместо Metals MCP только для поиска API внешних зависимостей (`cellar get-external` против Metals `inspect`/`get-docs`) — cellar не требует импорта проекта и может запрашивать любой опубликованный Maven‑артефакт.
