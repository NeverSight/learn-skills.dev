`git machete` CLI を呼び出す際に、ブランチチェーンの整理、フォークポイントの算出、スタックリベース/マージの実行、または GitHub/GitLab の PR/MR チェーンの管理に使用してください。特に `.git/machete` ファイルが既にあるリポジトリで有用です。各サブコマンドが `.git/machete` を変更するか、リベース/マージを実行するか、フックを走らせるか、stdin を読むかを一覧表示し、エージェントが適切なコマンドとフラグを選択できるようにします。重要なのは、`-y/--yes` を必ず付けて実行しなければならないコマンド（`-y` がないため、TTY が無い状態で実行してはならないコマンド）を明示している点で、これによりエージェントが対話的プロンプトで停止することはありません。また、`.git/machete` レイアウトファイルを手動で編集しないよう警告しています。
