Verwenden Sie dies immer, wenn Sie die `git machete`‑CLI aufrufen, um Branch‑Ketten zu organisieren, Fork‑Points zu berechnen, gestapelte Rebase‑/Merge‑Vorgänge auszuführen oder GitHub‑/GitLab‑PR/MR‑Ketten zu verwalten – insbesondere in einem Repository, das bereits eine `.git/machete`‑Datei enthält. Listet auf, welche Unterbefehle `.git/machete` ändern, Rebase/Merge ausführen, Hooks auslösen oder Eingaben über stdin lesen, sodass der Agent den richtigen Befehl auswählen und die passenden Flags übergeben kann. Wichtig ist, dass die Befehle genannt werden, die MIT `-y/--yes` aufgerufen werden MÜSSEN (und die wenigen, die kein `-y` haben und daher überhaupt nicht ohne tty aufgerufen werden dürfen), damit der Agent nie bei einer interaktiven Eingabe hängen bleibt. Warnt außerdem davor, die Layout‑Datei `.git/machete` von Hand zu editieren.
