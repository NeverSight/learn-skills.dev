`git machete` CLI를 호출해 브랜치 체인을 정리하고, 포크 포인트를 계산하며, 스택형 리베이스/머지를 실행하거나 GitHub/GitLab PR/MR 체인을 관리할 때마다 사용합니다—특히 이미 `.git/machete` 파일이 있는 저장소에서. 어떤 서브커맨드가 `.git/machete`를 수정하고, 리베이스/머지를 수행하며, 훅을 실행하거나 stdin을 읽는지 목록으로 제공하여 에이전트가 올바른 명령을 선택하고 적절한 플래그를 전달할 수 있게 합니다. 특히 `-y/--yes`를 반드시 사용해야 하는 명령(그리고 `-y` 옵션이 없어 tty 없이 절대 실행해서는 안 되는 몇몇 명령)을 명시해 에이전트가 인터랙티브 프롬프트에 멈추지 않도록 합니다. 또한 `.git/machete` 레이아웃 파일을 수동으로 편집하지 말 것을 경고합니다.
