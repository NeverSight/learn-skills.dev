Используйте каждый раз при вызове CLI `git machete` для организации цепочек веток, вычисления точек форка, выполнения стековых ребейзов/мерджей или управления цепочками PR/MR в GitHub/GitLab — особенно в репозитории, где уже существует файл `.git/machete`. Перечисляет, какие подкоманды изменяют `.git/machete`, запускают ребейз/мердж, выполняют хуки или читают stdin, чтобы агент мог выбрать нужную и передать правильные флаги. Ключевой момент — указываются команды, которые ОБЯЗАТЕЛЬНО должны вызываться с `-y/--yes` (и те, у которых нет `-y`, и поэтому их НЕЛЬЗЯ вызывать без tty), чтобы агент никогда не зависал на интерактивном запросе. Также предупреждает о ручном редактировании файла раскладки `.git/machete`.
