Usa ogni volta che invocchi la CLI `git machete` per organizzare catene di branch, calcolare i punti di fork, eseguire rebase/merge impilati o gestire catene PR/MR di GitHub/GitLab – soprattutto in un repository che già contiene un file `.git/machete`. Elenca quali sottocomandi modificano `.git/machete`, eseguono rebase/merge, eseguono hook o leggono stdin, così l’agente può scegliere quello corretto e passare i flag appropriati. Crucialmente, indica i comandi che DEVONO essere invocati con `-y/--yes` (e i pochi che non hanno `-y` e quindi NON DEVONO essere invocati senza un tty) così l’agente non resta bloccato su un prompt interattivo. Avvisa inoltre di non modificare manualmente il file di layout `.git/machete`.
