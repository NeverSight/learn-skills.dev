當使用者想要開發 DeepSeek Harness（dsh）的外掛或打造垂直式 Agent 產品時，請使用此技能。首先提供 dsh 的概念圖（所有事物皆為外掛；profile / bundle / plugin / agent preset / skill 為五個組件單元；host tree 與 per‑Agent tree），接著指導三項活動：新增工具或介面、釋出新 Agent 模式（preset），以及以「tool → preset → UI + new profile」從零構建垂直 Agent。涵蓋形態選擇（bundle 組合層 / pure Cordis / pure skill package / MCP）、npm 套件與 Cordis 入口、客戶端與設定頁面、安裝與驗證規範、UI 風格、多語言支援、README 與發佈規範、存取控制與決策紀錄。
