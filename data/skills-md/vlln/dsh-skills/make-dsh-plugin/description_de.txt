Wenn ein Benutzer ein Plugin für DeepSeek Harness (dsh) entwickeln oder ein vertikales Agent‑Produkt bauen möchte, verwende diese Fähigkeit. Zuerst stelle die konzeptionelle Karte von dsh bereit (alles ist ein Plugin; Profil / Bundle / Plugin / Agent‑Preset / Skill sind die fünf Montageeinheiten; Host‑Baum und pro‑Agent‑Baum), dann führe drei Aktivitäten an: ein Werkzeug oder eine Schnittstelle hinzufügen, einen neuen Agent‑Modus (Preset) veröffentlichen und einen vertikalen Agenten von Grund auf mit „Werkzeug → Preset → UI + neues Profil“ erstellen. Decke die Formauswahl ab (Bundle‑Kompositionsschicht / reines Cordis / reines Skill‑Paket / MCP), npm‑Paket und Cordis‑Eintrag, Client‑Teil und Einstellungsseite, Installations‑ und Verifizierungsdisziplin, UI‑Stil, mehrsprachige Unterstützung, README‑ und Veröffentlichungsspezifikationen, Zugriffskontrolle und Entscheidungsprotokolle.

Bitte antworte immer in der Sprache des Benutzers.
