Cuando un usuario desea desarrollar un plugin para DeepSeek Harness (dsh) o crear un producto de Agente vertical, use esta habilidad. Primero proporcione el mapa conceptual de dsh (todo es un plugin; perfil / paquete / plugin / preset de agente / skill son las cinco unidades de ensamblaje; árbol host y árbol por‑Agente), luego guíe tres actividades: agregar una herramienta o interfaz, lanzar un nuevo modo de Agente (preset) y construir un Agente vertical desde cero usando “herramienta → preset → UI + nuevo perfil”. Cubra la selección de forma (capa de composición de paquetes / Cordis puro / paquete de skill puro / MCP), el paquete npm y la entrada de Cordis, la mitad cliente y la página de configuración, la disciplina de instalación y verificación, el estilo UI, el soporte multilingüe, el README y las especificaciones de publicación, control de acceso y registros de decisiones.
