عندما يرغب المستخدم في تطوير ملحق لمنصة DeepSeek Harness (dsh) أو بناء منتج وكيل عمودي، استخدم هذه المهارة. ابدأ بتقديم خريطة المفهوم الخاصة بـ dsh (كل شيء هو ملحق؛ الملف الشخصي / الحزمة / الملحق / إعداد الوكيل المسبق / المهارة هي الوحدات الخمس للتجميع؛ شجرة المستضيف وشجرة كل وكيل)، ثم أرشد إلى ثلاث أنشطة: إضافة أداة أو واجهة، إصدار نمط وكيل جديد (إعداد مسبق)، وبناء وكيل عمودي من الصفر باستخدام «أداة → إعداد مسبق → واجهة مستخدم + ملف شخصي جديد». غطِّ اختيار الشكل (طبقة تركيبة الحزمة / Cordis نقي / حزمة مهارة نقية / MCP)، حزمة npm ودخول Cordis، نصف العميل وصفحة الإعدادات، انضباط التثبيت والتحقق، نمط الواجهة، الدعم متعدد اللغات، ملف README ومواصفات النشر، التحكم في الوصول وسجلات القرارات.
