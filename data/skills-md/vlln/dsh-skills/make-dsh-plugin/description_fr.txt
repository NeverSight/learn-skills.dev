Lorsqu’un utilisateur souhaite développer un plugin pour DeepSeek Harness (dsh) ou créer un produit Agent vertical, utilisez cette compétence. Commencez par fournir la carte conceptuelle de dsh (tout est un plugin ; profil / bundle / plugin / preset d’agent / skill sont les cinq unités d’assemblage ; arbre hôte et arbre par‑Agent), puis guidez trois activités : ajouter un outil ou une interface, publier un nouveau mode Agent (preset), et construire un Agent vertical à partir de zéro en utilisant « outil → preset → UI + nouveau profil ». Couvrez le choix de la forme (couche de composition de bundle / Cordis pur / package de skill pur / MCP), le paquet npm et l’entrée Cordis, la partie cliente et la page de paramètres, la discipline d’installation et de vérification, le style UI, le support multilingue, le README et les spécifications de publication, le contrôle d’accès et les registres de décision.  

Veuillez toujours répondre dans la langue de l’utilisateur.
