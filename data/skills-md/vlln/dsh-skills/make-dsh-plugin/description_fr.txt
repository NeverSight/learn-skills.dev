Lorsque les utilisateurs doivent développer un plugin pour DeepSeek Harness (dsh) ou créer un produit Agent vertical, ils utilisent cette compétence. D’abord, présentez la carte conceptuelle de dsh (tout est un plugin ; profil / bundle / plugin / préréglage d’agent / skill sont les cinq unités d’assemblage ; arbre hôte et arbre par‑Agent), puis guidez trois activités : ajouter un outil ou une interface, publier un nouveau mode Agent (préréglage), et construire un Agent vertical à partir de zéro en utilisant « outil → préréglage → UI + nouveau profil ». Couvrez la sélection de forme (couche de composition de bundle / Cordis pur / paquet de skill pur / MCP), le package npm et l’entrée Cordis, le côté client et la page des paramètres, la discipline d’installation et de vérification, le style UI, la prise en charge multilingue, le README et les spécifications de version, le contrôle d’accès et les journaux de décision.
