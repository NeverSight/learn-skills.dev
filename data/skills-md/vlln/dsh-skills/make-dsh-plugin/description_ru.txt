Когда пользователь хочет разработать плагин для DeepSeek Harness (dsh) или создать вертикальный продукт‑агент, используйте этот навык. Сначала предоставьте концептуальную карту dsh (всё — это плагин; профиль / bundle / плагин / preset агента / skill являются пятью сборочными блоками; дерево хоста и дерево каждого агента), затем проведите через три действия: добавить инструмент или интерфейс, выпустить новый режим агента (preset) и построить вертикального агента с нуля, используя «инструмент → preset → UI + новый профиль». Охватите выбор формы (слой композиции bundle / чистый Cordis / чистый пакет skill / MCP), npm‑пакет и точку входа Cordis, клиентскую часть и страницу настроек, дисциплину установки и проверки, стиль UI, поддержку нескольких языков, README и спецификации публикации, контроль доступа и записи решений.  

Пожалуйста, всегда отвечайте на языке пользователя.
