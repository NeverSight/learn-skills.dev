Use before showing any deliverable to a person or handing it to another agent, and when reviewing one: a UI screen, mockup, or prototype; a document, message, prompt, or spec; game content; a data model or code. Triggers include a card or caption that lists several fields on one line, a template or report format with no list of its fields and their types, an id shown as a label, an edit or delete rendered as text, a sentence in an interface that explains the interface, a builder's test status or report in the deliverable, a lock or disabled control used to say "read only", a list, count, or detail copied from something that already has an owner, and a stack or library chosen because the project is small or agents know it best.
