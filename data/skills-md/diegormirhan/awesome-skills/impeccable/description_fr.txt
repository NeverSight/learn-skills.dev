Utilisez lorsque l'utilisateur souhaite concevoir, redessiner, façonner, critiquer, auditer, peaufiner, clarifier, distiller, renforcer, optimiser, adapter, animer, coloriser, extraire ou autrement améliorer une interface front‑end. Cela concerne les sites web, les pages d'atterrissage, les tableaux de bord, les UI produit, les coquilles d'application, les composants, les formulaires, les paramètres, l’onboarding et les états vides. Il couvre la révision UX, la hiérarchie visuelle, l'architecture de l'information, la charge cognitive, l'accessibilité, la performance, le comportement réactif, le théming, les anti‑patterns, la typographie, les polices, l'espacement, la mise en page, l'alignement, la couleur, le mouvement, les micro‑interactions, le texte UX, les états d’erreur, les cas limites, l'i18n et les systèmes de design ou tokens réutilisables. Utilisez-le également pour des designs ternes qui doivent devenir plus audacieux ou plus agréables, des designs criards qui devraient être plus sobres, des itérations en direct dans le navigateur sur des éléments UI, ou des effets visuels ambitieux qui doivent sembler techniquement extraordinaires. Pas pour les tâches uniquement back‑end ou non‑UI.
