Выполнить git commit с анализом сообщения в стиле Conventional Commit, интеллектуальным формированием индекса и генерацией сообщения. Используйте, когда пользователь просит закоммитить изменения, создать git commit или упоминает «/commit». Поддерживает: (1) Автоматическое определение типа и области из изменений, (2) Генерацию сообщений Conventional Commit из diff, (3) Интерактивный коммит с возможностью переопределения типа/области/описания, (4) Интеллектуальное формирование индекса файлов для логической группировки.
