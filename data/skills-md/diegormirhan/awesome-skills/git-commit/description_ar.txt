نفّذ git commit مع تحليل رسائل الالتزام التقليدية، وتنسيق ذكي، وتوليد الرسائل. استخدمه عندما يطلب المستخدم الالتزام بالتغييرات، أو إنشاء التزام git، أو يذكر "/commit". يدعم: (1) الكشف التلقائي عن النوع والنطاق من التغييرات، (2) توليد رسائل الالتزام التقليدية من الاختلاف، (3) الالتزام التفاعلي مع إمكانية تجاوز النوع/النطاق/الوصف، (4) تنسيق الملفات بذكاء لتجميع منطقي

يرجى دائمًا الرد بلغة المستخدم.
