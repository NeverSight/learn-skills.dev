Ejecuta git commit con análisis de mensajes conventional commit, staging inteligente y generación de mensajes. Úsalo cuando el usuario solicite hacer commit de cambios, crear un git commit o mencione "/commit". Soporta: (1) Detección automática del tipo y alcance a partir de los cambios, (2) Generación de mensajes conventional commit a partir del diff, (3) Commit interactivo con sobrescritura opcional de tipo/alcance/descripción, (4) Staging inteligente de archivos para agrupamiento lógico

Por favor, responde siempre en el idioma del usuario.
