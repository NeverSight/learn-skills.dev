Esegui git commit con analisi del messaggio convenzionale, staging intelligente e generazione del messaggio. Usalo quando l'utente chiede di effettuare commit, crea un git commit o menziona “/commit”. Supporta: (1) Rilevamento automatico del tipo e dello scope dalle modifiche, (2) Generazione di messaggi di commit convenzionali dal diff, (3) Commit interattivo con sovrascritture opzionali di tipo/scope/descrizione, (4) Staging intelligente dei file per raggruppamenti logici. Rispondi sempre nella lingua dell'utente.
