Führe git commit mit Analyse konventioneller Commit‑Nachrichten, intelligenter Staging und Nachrichtengenerierung aus. Verwende dies, wenn der Benutzer auffordert, Änderungen zu committen, einen git commit zu erstellen oder „/commit“ erwähnt. Unterstützt: (1) Automatisches Erkennen von Typ und Scope aus Änderungen, (2) Generierung konventioneller Commit‑Nachrichten aus dem Diff, (3) Interaktiver Commit mit optionalen Typ‑/Scope‑/Beschreibungs‑Überschreibungen, (4) Intelligentes Dateistaging für logische Gruppierung

Bitte immer in der Sprache des Benutzers antworten.
