Tous les changements de code doivent suivre les directives documentées dans le dépôt. Avant de créer une issue, de créer une branche, de générer des commits ou de créer une pull request (ou PR), une recherche doit être effectuée pour s’assurer que les bonnes étapes sont respectées. Chaque fois que l’on vous demande de créer une issue, un message de commit, de pousser du code ou de créer une PR, utilisez cette compétence afin que tout soit fait correctement.

Veuillez toujours répondre dans la langue de l’utilisateur.
