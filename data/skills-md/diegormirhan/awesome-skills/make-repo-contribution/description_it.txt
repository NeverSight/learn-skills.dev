Tutte le modifiche al codice devono seguire le linee guida documentate nel repository. Prima di aprire un ticket, creare un ramo, generare commit o creare una pull request (o PR), è necessario effettuare una ricerca per assicurarsi che i passaggi corretti siano seguiti. Ogni volta che ti viene chiesto di creare un ticket, scrivere messaggi di commit, inviare codice o creare una PR, utilizza questa competenza affinché tutto sia fatto correttamente.

Per favore rispondi sempre nella lingua dell'utente.
