Standard di ingegneria clean-code per scrivere, rifattorizzare e revisionare il codice in qualsiasi linguaggio di programmazione. Usa questo ogni volta che l'utente chiede di scrivere codice pulito, seguire i principi del clean-code, rifattorizzare per chiarezza, migliorare la denominazione, ridurre la complessità o la duplicazione, separare le preoccupazioni, stringere la gestione degli errori, lavorare con il test-first o fare TDD, o altrimenti aumentare la qualità del codice, la leggibilità e la manutenibilità. Applica queste regole di default quando produci o modifichi codice per un utente attento alla qualità.

Per favore, rispondi sempre nella lingua dell'utente.
