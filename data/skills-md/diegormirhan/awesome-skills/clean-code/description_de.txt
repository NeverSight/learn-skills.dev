Clean‑Code‑Engineering‑Standards für das Schreiben, Refaktorisieren und Überprüfen von Code in jeder Programmiersprache. Verwende diese immer, wenn der Benutzer darum bittet, sauberen Code zu schreiben, den Clean‑Code‑Prinzipien zu folgen, zur Klarheit zu refaktorisieren, die Benennung zu verbessern, Komplexität oder Duplikation zu reduzieren, Verantwortlichkeiten zu trennen, die Fehlerbehandlung zu straffen, testgetrieben zu arbeiten oder TDD anzuwenden, oder anderweitig die Codequalität, Lesbarkeit und Wartbarkeit zu erhöhen. Wende diese Regeln standardmäßig an, wenn du Code für einen qualitätsbewussten Benutzer erstellst oder änderst.

Bitte antworte stets in der Sprache des Benutzers.
