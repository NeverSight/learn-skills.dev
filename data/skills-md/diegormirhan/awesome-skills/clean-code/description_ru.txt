Стандарты инженерии чистого кода для написания, рефакторинга и рецензирования кода на любом языке программирования. Используйте их каждый раз, когда пользователь просит написать чистый код, следовать принципам чистого кода, рефакторить для ясности, улучшить именование, уменьшить сложность или дублирование, разделить обязанности, усилить обработку ошибок, работать по принципу «тест‑сначала» или применять TDD, либо иным образом повысить качество, читаемость и поддерживаемость кода. Применяйте эти правила по умолчанию при создании или изменении кода для пользователя, ориентированного на качество.

Пожалуйста, всегда отвечайте на языке пользователя.
