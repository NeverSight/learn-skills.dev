Estándares de ingeniería de código limpio para escribir, refactorizar y revisar código en cualquier lenguaje de programación. Usa esto siempre que el usuario solicite escribir código limpio, seguir los principios de código limpio, refactorizar para mayor claridad, mejorar los nombres, reducir la complejidad o duplicación, separar responsabilidades, reforzar el manejo de errores, trabajar con pruebas primero o hacer TDD, o en general mejorar la calidad, legibilidad y mantenibilidad del código. Aplica estas reglas por defecto al producir o modificar código para un usuario consciente de la calidad.

Por favor, responde siempre en el idioma del usuario.
