معايير هندسة الكود النظيف لكتابة الكود وإعادة هيكله ومراجعته بأي لغة برمجة. استخدم هذه المعايير كلما طلب المستخدم كتابة كود نظيف، اتباع مبادئ الكود النظيف، إعادة الهيكلة للوضوح، تحسين التسميات، تقليل التعقيد أو التكرار، فصل الاهتمامات، تشديد معالجة الأخطاء، العمل وفق نهج الاختبار أولاً أو تطوير موجه بالاختبار (TDD)، أو بأي طريقة أخرى لرفع جودة الكود، قابليته للقراءة، وصيانته. طبّق هذه القواعد افتراضيًا عند إنتاج أو تعديل الكود لمستخدم يولي الجودة اهتمامًا.
