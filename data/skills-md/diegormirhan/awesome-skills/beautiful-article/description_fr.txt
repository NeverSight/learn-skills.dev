Modifiez et concevez le matériel fourni par l'utilisateur (URL web / PDF / DOCX / Markdown / texte brut / capture d'écran / matériel collé) en un bel **article web HTML monofichier** pouvant être ouvert hors ligne et partagé. En vous basant sur le protocole de composant reacticle : n'écrivez pas manuellement du HTML/CSS brut, mais utilisez des composants sémantiques + une couche Raw libre encadrée par le thème ; suivez un petit flux de travail : source → planification → double confirmation → génération → relecture finale → correction, avec un texte long par défaut conservant 100 % de l'information. Scénarios déclencheurs : transformer une URL/PDF/DOCX/article en article web / texte long / briefing / texte explicatif / article visuel / tutoriel / récapitulatif d'analyse / analyse de solution — « rendre ceci comme un bel article web », « transformer cela en article web », « générer un texte long HTML partageable », « article reacticle ». Ne générez que l'article, pas le backend, les formulaires, le tableau de bord, le prototype produit ou une application web générique. Veuillez toujours répondre dans la langue de l'utilisateur.
