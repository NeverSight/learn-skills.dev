Edita y diseña el material proporcionado por el usuario (URL de página web / PDF / DOCX / Markdown / texto plano / captura de pantalla / contenido pegado) en un **artículo web HTML de un solo archivo** bello, que se pueda abrir sin conexión y compartir. Basado en el protocolo de componentes reacticle: no escribas HTML/CSS a mano, sino usa componentes semánticos + una capa Raw libre limitada por el tema; avanza a través de un pequeño flujo de trabajo de origen → planificación → doble confirmación → generación → revisión final → corrección, predeterminando un artículo largo que retenga el 100 % de la información. Escenarios de activación: convertir una URL/PDF/DOCX/artículo en un artículo web / texto extenso / informe / texto explicativo / artículo visual / tutorial / recapitulación de reseña / análisis de solución — “renderiza esto como un hermoso artículo web” / “convierte esto en un artículo web” / “genera un texto largo HTML compartible” / artículo reacticle. Sólo genera el artículo, no el backend, formularios, panel de control, prototipo de producto o una aplicación web genérica.
