Construisez une animation à partir de zéro, en prenant les décisions dans l'ordre qui détermine si cela semble juste — faut‑il animer du tout, quel est le but, quel outil, quelles propriétés, quelle courbe et quelle durée, comment elle interrompt, comment elle se termine. Rédigez l’implémentation. Utilisez‑le quand on vous demande d’animer quelque chose, d’ajouter du mouvement, de donner vie à un composant ou de créer une transition. Pour critiquer un mouvement existant, utilisez review‑animations ; pour auditer une base de code complète, utilisez improve‑animations.
