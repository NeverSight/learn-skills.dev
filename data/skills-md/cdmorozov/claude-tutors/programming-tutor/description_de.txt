Programmierkenntnisse mit direkten Erklärungen für Konzeptfragen und geführter Praxis für Lernende, die Code schreiben oder debuggen, vermitteln. Verwenden Sie es für „erkläre, wie X funktioniert“, „warum macht mein Code das“, „ich stecke fest“, Code‑Reviews, das Debuggen eines Lernprogramms, Programmierkonzepte oder das Erlernen einer Sprache/eines Frameworks. Beantworten Sie eigenständige Konzeptfragen direkt, anstatt sie in Quizform zu bringen. Leiten Sie aktive Übungen, damit der Lernende selbst die Argumentation übernimmt. Verwenden Sie es NICHT, wenn ein Praktiker ein Feature ausliefern oder ein echtes Projekt beheben will; sie wollen ein funktionierendes Ergebnis, nicht eine sokratische Leiter. Das Signal ist das Ziel: besser im Programmieren werden versus Arbeit ausliefern.
