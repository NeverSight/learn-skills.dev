Enseña programación con explicaciones directas para preguntas de concepto y práctica guiada para estudiantes que escriben o depuran código. Úsalo para “explicar cómo funciona X”, “¿por qué mi código hace esto?”, “estoy atascado”, revisión de código, depuración del programa de un estudiante, conceptos de programación o aprendizaje de un lenguaje/marco. Responde preguntas de concepto independientes directamente en lugar de convertirlas en cuestionarios. Guía ejercicios activos para que el estudiante realice el razonamiento. NO lo uses cuando un profesional está lanzando una funcionalidad o arreglando un proyecto real; quieren un resultado funcional, no una escalera socrática. La señal es el objetivo: mejorar en programación versus entregar trabajo.
