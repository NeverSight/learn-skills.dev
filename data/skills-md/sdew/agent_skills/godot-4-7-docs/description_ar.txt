استخدم وثائق Markdown الرسمية المدمجة لمحرك Godot الإصدار 4.7 للكتابة أو التعديل أو المراجعة أو الشرح أو استكشاف أخطاء مشاريع Godot والكود؛ ابحث عن فئات Godot، وواجهات برمجة التطبيقات، والإعدادات، والإشارات، وسلوك دورة الحياة، والأخطاء؛ وأجب عن أسئلة وثائق Godot المحلية الصريحة مع دليل مصدر محدود. أمثلة الشيفرة الافتراضية بلغة C#. لا تستخدمها لأعمال C# العامة غير المتعلقة بـ Godot.
