Take over or hand off a Git code project without having to re‑explain it. Use this skill when the user wants to continue the previous project, switch to another computer to keep working, or hand the project to someone else or another agent. It is triggered when the user says “relay,” “pick up,” “continue,” “hand off,” “change computer,” “switch device,” “another computer,” “install relay,” even if they don’t mention “relay” or project memory. At the start of a session, perform a reconciliation; at the end of a session, perform a collection first. Only the project goal requires human confirmation; everything else is fully automated.
