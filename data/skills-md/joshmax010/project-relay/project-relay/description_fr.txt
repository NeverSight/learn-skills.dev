Prenez le contrôle ou transmettez un projet de code Git sans avoir à le réexpliquer. Utilisez cette compétence lorsque l'utilisateur veut poursuivre le projet précédent, passer à un autre ordinateur et continuer à travailler, ou remettre le projet à quelqu’un d’autre ou à un autre agent. Elle se déclenche lorsque l'utilisateur dit « relay », « continue », « keep working », « handover », « switch computer », « change device », « another computer », « install relay », même s’il ne mentionne pas « relay » ou la mémoire du projet. Au début de la conversation, effectuez une réconciliation ; à la fin, recueillez d’abord les données. Seul l’objectif du projet nécessite la confirmation humaine ; tout le reste est entièrement automatisé.

Veuillez toujours répondre dans la langue de l'utilisateur.
