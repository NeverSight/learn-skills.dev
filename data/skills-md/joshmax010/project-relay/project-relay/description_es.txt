Asume o entrega un proyecto de código en Git sin necesidad de volver a explicar. Esta habilidad se utiliza cuando el usuario quiere continuar el proyecto anterior, cambiar a otra computadora para seguir trabajando o entregar el proyecto a otra persona u otro agente. Se activa cuando el usuario dice “relay”, “pick up”, “continue”, “hand over”, “switch computer”, “switch device”, “another computer” o “install relay”, incluso si no menciona relay o la memoria del proyecto. Al inicio de una sesión, primero reconciliar; al final, primero recopilar. Solo los objetivos del proyecto requieren confirmación humana; todo lo demás está completamente automatizado.

Por favor, responde siempre en el idioma del usuario.
