تولى أو سلّم مشروع كود Git دون الحاجة إلى إعادة الشرح. استخدم هذه المهارة عندما يرغب المستخدم في متابعة المشروع السابق، أو الانتقال إلى كمبيوتر آخر للاستمرار في العمل، أو تسليم المشروع لشخص آخر أو وكيل آخر. يتم تفعيلها عندما يقول المستخدم “relay”، “pick up”، “continue”، “hand over”، “switch computer”، “switch device”، “another computer”، أو “install relay”، حتى وإن لم يذكر كلمة “relay” أو ذاكرة المشروع. في بداية الجلسة، قم بالمصالحة؛ وفي النهاية، اجمع البيانات أولاً. فقط هدف المشروع يحتاج إلى تأكيد بشري؛ كل شيء آخر مؤتمت بالكامل.
