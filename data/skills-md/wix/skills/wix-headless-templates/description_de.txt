Der ausgelieferte, verifizierte Code hinter Wix‑Headless‑Sites, ein Ordner pro Wix‑Business‑Solution: ein Online‑Store, Buchungen, Vermietungen, ein Blog, CMS‑Collections, Formulare, Mitglieder, Events, Restaurants, Spenden, Preispläne, ein Portfolio, ein FAQ. Jeder liefert eine typisierte, framework‑agnostische Datenschicht und speichert über @wix/sdk, React‑Hooks und Referenz‑Components, Astro‑Pages mit eigentümer‑editierbarem SEO, einen REST‑Twin für Sites ohne Bundler, ein Seed‑Skript, das die Site aus einem Plan füllt, einen Reader, der berichtet, was die Site bereits enthält, und ein Playbook (INSTRUCTIONS.md) mit den Verträgen. Gemeinsam: Design‑ und Content‑Ebenen, die Fähigkeiten (Site‑Search, Media‑Upload), die Seed‑Hilfsprogramme und ein zusammengesetztes, fixiertes Projekt pro Solution, das ein Create komplett kopiert. Verwendet von wix‑headless‑kit, das aus diesem Ordner fetch‑, deploy‑ und seed‑Vorgänge ausführt; eigenständig lesbar, um zu sehen, was der Code einer Solution macht und wie er gesät wird.
