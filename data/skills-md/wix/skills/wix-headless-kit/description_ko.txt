Wix 헤드리스 사이트를 빠르게 구축하려면 레시피에서 직접 통합을 작성하는 대신 SHIPPED, 검증된 @wix/sdk 코드를 연결하세요. 각 Wix 비즈니스 수직 분야는 타입이 지정된 프레임워크에 구애받지 않는 React 코어(plain DTO를 반환하는 데이터 레이어, hooks, 헤드리스 컴포넌트)와 Astro 오버레이(소유자가 편집 가능한 SEO가 사전 연결된 SSR 페이지) 및 빌드 시점 REST 시드 스크립트를 제공합니다 — 에이전트는 Wix CLI를 통해 스캐폴딩하고, 제공된 코드를 배포하며, 백엔드를 시드하고, 제공된 hooks(상품 카드/그리드, PDP, 홈, 테마) 위에 프레젠테이션 레이어를 직접 디자인한 뒤 Wix 호스팅에 릴리즈합니다. Wix 관리 Astro(ambient auth, 기본값)와 공개 OAuth 클라이언트 ID를 통해 any React 기반 프로젝트(Vite, 비‑Astro)에서도 작동합니다.  

수직 분야:  
- 스토어/스토어프런트(제품, 카테고리, 변형, 카트, 호스트된 결제)  
- 예약(서비스, 약속/클래스 시간 슬롯, 직원, 예약 양식, 결제 혹은 예약)  
- 대여(시간 혹은 일 단위 방, 차량, 장비: 리소스, 고객이 선택한 기간, 가격 견적, 결제)  
- 블로그(포스트, 카테고리/태그, 리치 콘텐츠)  
- CMS(구조화된 콘텐츠 컬렉션)  
- 폼(스키마 기반 방문자 폼: 렌더, 검증, 제출)  
- 이벤트(리스트, RSVP, 티켓 판매)  
- 멤버(로그인, 제한된 페이지, 계정)  
- 포트폴리오(프로젝트 컬렉션, 미디어 갤러리)  
- 가격 플랜(플랜 그리드, 호스트된 구매)  
- 레스토랑(메뉴, 온라인 주문, 테이블 예약)  
- FAQ(카테고리별 질문과 답변, 검색, 질문당 링크)  
- 기부(캠페인 페이지, 목표 진행, 일회성 및 정기 기부 호스트 결제)
