Construye un sitio Wix Headless rápidamente conectando código VERIFICADO y ENVIADO de @wix/sdk en lugar de crear la integración desde recetas. Cada vertical de negocio de Wix entrega un núcleo React tipado y agnóstico al framework (capa de datos que devuelve DTOs simples, hooks, componentes headless) más una capa superpuesta de Astro (páginas SSR con SEO editable por el propietario y preconfigurado) y un script de semillas REST en tiempo de compilación: el agente genera la estructura mediante el Wix CLI, despliega el código enviado, siembra el backend, diseña la capa de presentación directamente con los hooks entregados (tarjeta/grid de producto, PDP, inicio, tema) y publica en el hosting de Wix. Funciona en Astro gestionado por Wix (autenticación ambiente, por defecto) y en cualquier proyecto basado en React (Vite, sin Astro) usando el client‑id OAuth público. Verticals: tiendas/front‑ends (productos, categorías, variantes, carrito, checkout alojado), reservas (servicios, franjas horarias de citas/clases, personal, formulario de reserva, checkout‑o‑colocación), alquileres (habitaciones, vehículos, equipos por hora o día: recursos, duración elegida por el cliente, cotización con precio, checkout), blog (publicaciones, categorías/etiquetas, contenido enriquecido), CMS (colecciones de contenido estructurado), formularios (formularios de visitante basados en esquemas: renderizar, validar, enviar), eventos (listado, RSVP, venta de entradas), miembros (login, páginas restringidas, cuenta), portafolio (colecciones de proyectos, galerías de medios), planes de precios (cuadrícula de planes, compra alojada), restaurantes (menús, pedidos en línea, reservas de mesas), FAQ (preguntas y respuestas categorizadas, búsqueda, un enlace por pregunta), donaciones (páginas de campaña, progreso de metas, donaciones únicas y recurrentes mediante checkout alojado). Disparadores: crea rápidamente un sitio de tienda/blog/reserva/alquiler/evento/restaurante/portafolio/FAQ/donación, agenda citas rápido, alquila habitaciones/coches/equipos headless, vende entradas o planes de membresía headless, recopila donaciones headless, kit Wix headless, conecta una aplicación de negocio Wix con código SDK listo para usar.
