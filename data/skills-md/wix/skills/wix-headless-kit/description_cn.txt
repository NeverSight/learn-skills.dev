快速构建 Wix Headless 网站，只需接入已发布、经过验证的 @wix/sdk 代码，而无需从配方手动编写集成。每个 Wix 业务垂直领域都提供一个类型化、框架无关的 React 核心（返回普通 DTO 的数据层、hooks、headless 组件），以及一个 Astro 覆盖层（带有所有者可编辑的预置 SEO 的 SSR 页面）和一个构建时的 REST 种子脚本——代理通过 Wix CLI 脚手架，部署已发布的代码，种子后台，使用已发布的 hooks（产品卡片/网格、PDP、首页、主题）自行设计呈现层，并发布到 Wix 托管。该方案可在 Wix 管理的 Astro（默认的 ambient auth）上运行，也可在任何基于 React 的项目（Vite、非 Astro）上使用公共 OAuth 客户端 ID。垂直领域包括：  
- 商店/店面（产品、分类、变体、购物车、托管结账）  
- 预约（服务、约会/课程时间段、员工、预约表单、结账或下单）  
- 租赁（房间、车辆、设备，按小时或按天计费：资源、用户选择时长、报价、结账）  
- 博客（文章、分类/标签、富内容）  
- CMS（结构化内容集合）  
- 表单（基于 schema 的访客表单：渲染、验证、提交）  
- 活动（列表、RSVP、票务销售）  
- 会员（登录、受限页面、账户）  
- 作品集（项目集合、媒体画廊）  
- 定价计划（计划网格、托管购买）  
- 餐厅（菜单、线上点餐、桌位预订）  
- FAQ（分类的问题及答案、搜索、每个问题的链接）  
- 捐赠（活动页面、目标进度、一次性和周期性捐赠通过托管结账）。  

触发指令示例：快速构建商店/博客/预约/租赁/活动/餐厅/作品集/FAQ/捐赠站点、快速预约、无头租赁房间/车辆/设备、无头售票或会员计划、无头收集捐赠、Wix 无头工具包、使用现成 SDK 代码连接 Wix 业务应用。
