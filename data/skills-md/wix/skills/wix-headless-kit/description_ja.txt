レシピから統合を自作する代わりに、出荷済みで検証済みの @wix/sdk コードを配線することで、Wix ヘッドレスサイトを高速に構築できます。各 Wix ビジネス垂直領域は、型付けされたフレームワーク非依存の React コア（プレーンな DTO を返すデータ層、フック、ヘッドレスコンポーネント）と、Astro オーバーレイ（所有者が編集可能な SEO が事前配線された SSR ページ）およびビルド時の REST シードスクリプトを提供します。エージェントは Wix CLI を使用してスキャフォールドを生成し、出荷されたコードをデプロイ、バックエンドをシードし、出荷されたフック上でプレゼンテーション層（商品カード／グリッド、PDP、ホーム、テーマなど）をデザインし、Wix ホスティングへリリースします。Wix が管理する Astro（デフォルトのアンビエント認証）でも、パブリック OAuth クライアント ID を介した任意の React ベースプロジェクト（Vite、非 Astro）でも動作します。

垂直領域例：
- ストア／ストアフロント（商品、カテゴリ、バリアント、カート、ホスト化チェックアウト）
- 予約（サービス、予約／クラス時間枠、スタッフ、予約フォーム、チェックアウトまたは予約確定）
- レンタル（部屋、車両、機材の時間単位または日単位レンタル：リソース、顧客選択の期間、見積もり価格、チェックアウト）
- ブログ（投稿、カテゴリ／タグ、リッチコンテンツ）
- CMS（構造化コンテンツコレクション）
- フォーム（スキーマ駆動の訪問者フォーム：表示、バリデーション、送信）
- イベント（一覧、RSVP、チケット販売）
- メンバー（ログイン、制限ページ、アカウント）
- ポートフォリオ（プロジェクトコレクション、メディアギャラリー）
- 料金プラン（プラングリッド、ホスト化購入）
- レストラン（メニュー、オンライン注文、テーブル予約）
- FAQ（カテゴリ別質問と回答、検索、質問ごとのリンク）
- 寄付（キャンペーンページ、目標進捗、ホスト化チェックアウトによる単発・定期寄付）

トリガー例：ストア／ブログ／予約／レンタル／イベント／レストラン／ポートフォリオ／FAQ／寄付サイトを高速に構築、予約をすばやく受け付け、部屋／車／機材をヘッドレスでレンタル、チケットやメンバーシッププランをヘッドレスで販売、寄付をヘッドレスで収集、Wix ヘッドレスキット、Wix ビジネスアプリを即座に利用できる SDK コードで接続。
