Analyse les déséquilibres de modularité d’une base de code à l’aide du modèle Balanced Coupling et produit une revue des problèmes de conception. À utiliser lors de la révision de code existant pour des problèmes de couplage, d’évaluation de la qualité de l’architecture, d’identification des risques de monolithe distribué ou pour repérer les zones où les changements sont imprévisiblement coûteux.
