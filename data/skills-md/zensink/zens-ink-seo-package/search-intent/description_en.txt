Classify search intent for keywords, two independent ways: keyword-based classification (informational / commercial / transactional / navigational, with question/buyer/problem markers) and SERP-based verification (what page types Google actually rewards). Cross-validated verdicts catch mismatches a single method misses. Use when the user asks "what's the intent behind this keyword", "should this page be a blog post or a landing page", or before writing any page for a target keyword.
