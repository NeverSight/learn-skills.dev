Führen Sie ein Upgrade einer PostgreSQL-App von Prisma ORM 6 oder 7 direkt auf Prisma 8 in einem Schritt durch, wobei die vorhandene Datei „schema.prisma“, die Datenbank und die Daten beibehalten werden. Verwenden Sie diese Option, wenn ein Postgres-Projekt, das Prisma 6 oder 7 verwendet, auf Prisma 8 aktualisiert werden soll, auch bevor es auf Prisma Compute bereitgestellt wird, auf dem nur Prisma 8 ausgeführt wird. Wird ausgelöst durch „Upgrade von Prisma 6 auf 8“, „Upgrade von Prisma 7 auf 8“, „Upgrade auf Prisma 8 Postgres“, „prisma7Schema“, „migrations/app“, „move off @prisma/client“, „Console says move to Prisma 8“.
