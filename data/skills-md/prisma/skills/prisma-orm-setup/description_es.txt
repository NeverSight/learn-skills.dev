Configure Prisma ORM en una aplicación, conecte su base de datos o solucione problemas de conexión de una aplicación prisma 6, 7 u 8 existente. Define las nuevas aplicaciones en Prisma ORM 8 y carga la habilidad prisma-8 propiedad del paquete; mantiene las aplicaciones prisma 6/7 existentes en su versión con referencias de proveedores para PostgreSQL, MySQL, SQLite, SQL Server, CockroachDB, MongoDB y Prisma Postgres.
