Configurez Prisma ORM dans une application, connectez sa base de données ou dépannez la connexion d'une application Prisma 6, 7 ou 8 existante. Définit par défaut les nouvelles applications sur Prisma ORM 8 et charge la compétence prisma-8 appartenant au package ; conserve les applications Prisma 6/7 existantes sur leur version avec des références de fournisseurs pour PostgreSQL, MySQL, SQLite, SQL Server, CockroachDB, MongoDB et Prisma Postgres.
