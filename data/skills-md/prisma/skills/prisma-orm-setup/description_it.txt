Configura Prisma ORM in un’applicazione, collega il suo database o risolvi i problemi di connessione di un’app Prisma 6, 7 o 8 esistente. Imposta per impostazione predefinita le nuove applicazioni su Prisma ORM 8 e carica la skill prisma‑8 fornita dal pacchetto; mantiene le app Prisma 6/7 esistenti nella loro versione con riferimenti al provider per PostgreSQL, MySQL, SQLite, SQL Server, CockroachDB, MongoDB e Prisma Postgres.
