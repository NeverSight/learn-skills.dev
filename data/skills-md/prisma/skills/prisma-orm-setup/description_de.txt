Richten Sie Prisma ORM in einer Anwendung ein, verbinden Sie seine Datenbank oder beheben Sie die Verbindung einer vorhandenen Prisma 6, 7 oder 8 App. Setzt neue Anwendungen standardmäßig auf Prisma ORM 8 und lädt die paketeigene Prisma-8-Fähigkeit; behält vorhandene Prisma 6/7-Apps in ihrer Version mit Anbieterreferenzen für PostgreSQL, MySQL, SQLite, SQL Server, CockroachDB, MongoDB und Prisma Postgres bei.
