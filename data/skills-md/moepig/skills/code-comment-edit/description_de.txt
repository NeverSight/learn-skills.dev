Ein Satz von Formatierungs‑ und Inhaltsrichtlinien für das Schreiben, Ändern und Überprüfen von Kommentaren im Quellcode. Er wird für Aufgaben wie das Hinzufügen, Aktualisieren oder Übersetzen von Kommentaren, das Schreiben von Docstrings oder Dokumentationskommentaren und das Aufräumen der Kommentarformatierung verwendet.
