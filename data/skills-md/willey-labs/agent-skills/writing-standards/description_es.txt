Estándares para escribir, editar y revisar DOCUMENTOS — READMEs, especificaciones, reglas, habilidades, documentos de diseño, guías y cualquier entregable de prosa producido a partir de una fuente (código existente o una discusión previa). Se aplican dos conjuntos de reglas en cada tarea de documento: (1) fuente‑a‑entregable — código→doc describe lo que el sistema HACE sin código ni identificadores de código; discusión→regla establece el principio general, no el ejemplo específico recién discutido; (2) anti‑slop — elimina la ambigüedad, palabras de moda, aclaraciones innecesarias, aplausos, formato reflexivo y relleno. Úsese cuando el usuario dice “escribe un documento”, “documenta este código”, “describe lo que hace”, “convierte esto en una regla/habilidad”, “haz un documento de nuestra discusión”, “revisa este documento” o “¿esto es slop?”. Consulte antes de crear o revisar CUALQUIER documento, incluso cuando el usuario no mencione “estándares”: toda escritura/edición/revisión de documento debe cumplirlo. El complemento de los estándares de codificación: ese rige el código, este rige los documentos.
