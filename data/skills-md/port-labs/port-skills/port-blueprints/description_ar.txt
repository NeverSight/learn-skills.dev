قم بنمذجة نموذج بيانات بحيرة سياق بورت باستخدام المخططات، مع تعريف المعرفات والعناوين والرموز والخصائص والعلاقات، وإضافة خصائص حسابية أو انعكاسية أو تجميعية، ثم أنشئها باستخدام واجهة برمجة التطبيقات الخام لبورت. استخدم ذلك عندما يُطلب منك إنشاء مخطط بورت، أو تعريف نموذج بيانات بورت، أو إضافة خاصية إلى مخطط، أو ربط مخططين، أو إضافة خاصية حسابية، أو خاصية انعكاسية، أو خاصية تجميعية.
