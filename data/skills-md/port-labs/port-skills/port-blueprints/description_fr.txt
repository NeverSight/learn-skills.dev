Modélisez un modèle de données Port contextuel pour lac à l’aide de blueprints, en définissant les identifiants, titres, icônes, propriétés, relations ainsi que les propriétés de calcul, de miroir ou d’agrégation, puis créez‑les avec l’API Port brute. Utilisez‑le lorsqu’on vous demande de créer un blueprint Port, de définir un modèle de données Port, d’ajouter une propriété à un blueprint, de relier deux blueprints, d’ajouter une propriété de calcul, d’ajouter une propriété de miroir ou d’ajouter une propriété d’agrégation.
