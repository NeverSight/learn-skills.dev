Créer et gérer les blueprints, entités, scorecards et actions en libre‑service de Port avec le fournisseur officiel Terraform (port‑labs/port‑labs). Couvre la configuration et l’authentification du fournisseur, chaque type de ressource (port_blueprint, port_entity, port_scorecard, port_action, port_webhook, port_integration, port_aggregation_properties), le cycle de vie créer / mettre à jour / supprimer / importer, ainsi que les limitations connues qui entraînent une configuration cassée ou silencieusement erronée. Utilisez‑le lorsqu’on vous demande « ajouter une ressource Port à Terraform », « gérer Port comme du code », « écrire une ressource port_blueprint/port_entity/port_action/port_scorecard », « importer un blueprint Port dans l’état Terraform » ou « pourquoi mon apply Terraform de Port n’a pas fait ce que j’attendais ».
