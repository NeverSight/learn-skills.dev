Port의 MCP 도구를 사용하여 조직 범위 외부 인터페이스 앱(공개/PKCE Auth0 OAuth 클라이언트)을 등록하고, Lovable‑, v0‑ 또는 bolt.new 로 만든 맞춤 UI에 Authorization Code + PKCE 부여를 연결하여 사용자를 로그인시키고 Port API를 호출할 수 있도록 합니다. ‘Port 위에 맞춤 UI를 구축해 주세요’, ‘내 Lovable 앱을 Port와 연결해 주세요’, ‘Port에 OAuth 앱을 등록해 주세요’, ‘내 앱에 Port 로그인을 추가해 주세요’, ‘외부 앱의 클라이언트 ID를 받아 주세요’, 혹은 ‘Port 로그인 시 Callback URL 불일치/서비스 없음 오류를 해결해 주세요’ 라는 요청에 사용합니다. 범위에 포함되지 않는 내용: Port 자체 플러그인 및 맞춤 위젯 시스템(이 스킬은 Port 내부에 무엇이든 구축하거나 설치하지 않음) 및 Port의 SSO 또는 아이덴티티 제공자 연결 관리.
