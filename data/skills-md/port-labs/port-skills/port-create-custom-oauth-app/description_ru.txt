Зарегистрируйте приложение внешнего интерфейса с областью действия организации (публичный клиент Auth0 OAuth с PKCE) для пользовательского UI, например приложения, построенного с помощью Lovable, v0 или bolt.new, используя инструменты MCP Port, а затем подключите грант Authorization Code + PKCE к этому UI, чтобы он мог выполнять вход пользователей и вызывать API Port. Используйте, когда просят «создать пользовательский UI поверх Port», «подключить моё приложение Lovable к Port», «зарегистрировать OAuth‑приложение в Port», «добавить вход Port в моё приложение», «получить client ID для моего внешнего приложения» или «исправить ошибку несовпадения Callback URL / Service not found при входе через Port». Вне сферы ответственности: собственная система плагинов и пользовательских виджетов Port (этот навык никогда не создаёт и не устанавливает ничего внутри Port) и управление SSO или соединениями поставщиков идентификации Port.
