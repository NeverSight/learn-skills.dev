سجِّل تطبيق واجهة خارجية مقيد بالمؤسسة (عميل Auth0 OAuth عام/PKCE) لواجهة مستخدم مخصصة، مثل تطبيق مبني على Lovable أو v0 أو bolt.new، باستخدام أدوات MCP الخاصة بـ Port، ثم اربط منح الترخيص (Authorization Code + PKCE) بتلك الواجهة حتى تتمكن من تسجيل دخول المستخدمين واستدعاء API الخاص بـ Port. استخدم هذا عند طلب “بناء واجهة مستخدم مخصصة فوق Port”، “ربط تطبيق Lovable الخاص بي بـ Port”، “تسجيل تطبيق OAuth في Port”، “إضافة تسجيل الدخول عبر Port إلى تطبيقي”, “الحصول على معرف عميل لتطبيقي الخارجي”، أو “إصلاح عدم تطابق عنوان URL للاستدعاء / خطأ عدم العثور على الخدمة عند تسجيل الدخول باستخدام Port”. خارج النطاق: نظام الإضافات والودجتات المخصص لPort نفسه (هذه المهارة لا تقوم أبداً ببناء أو تثبيت أي شيء داخل Port نفسه)، وإدارة اتصالات SSO أو موفر الهوية لPort.
