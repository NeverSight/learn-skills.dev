Registriere eine organisationsbezogene externe Schnittstellen‑App (einen öffentlichen/PKCE Auth0 OAuth‑Client) für eine benutzerdefinierte UI, wie z. B. eine Lovable‑, v0‑ oder bolt.new‑basierte Anwendung, mithilfe der MCP‑Tools von Port und integriere anschließend den Authorization‑Code‑+‑PKCE‑Grant in diese UI, damit sie Benutzer anmelden und die Port‑API aufrufen kann. Verwende dies, wenn nach „einer benutzerdefinierten UI auf Port erstellen“, „mein Lovable‑App mit Port verbinden“, „eine OAuth‑App in Port registrieren“, „Port‑Login zu meiner App hinzufügen“, „eine Client‑ID für meine externe App erhalten“ oder „einen Callback‑URL‑Mismatch / Service‑not‑found‑Fehler beim Login mit Port beheben“ gefragt wird. Nicht im Geltungsbereich: Ports eigenes Plugin‑ und benutzerdefiniertes Widget‑System (diese Fähigkeit erstellt oder installiert nichts innerhalb von Port) sowie das Verwalten von Ports SSO‑ oder Identitäts‑Provider‑Verbindungen.
