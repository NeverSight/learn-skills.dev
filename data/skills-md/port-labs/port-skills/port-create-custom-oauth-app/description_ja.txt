Port の MCP ツールを使用して、Lovable、v0、または bolt.new で構築されたアプリなどのカスタム UI 用に、組織スコープの外部インターフェースアプリ（パブリック/PKCE Auth0 OAuth クライアント）を登録し、その UI に Authorization Code + PKCE グラントを組み込んでユーザーをサインインさせ、Port API を呼び出せるようにします。以下のような依頼がある場合に使用します：『Port の上にカスタム UI を構築したい』、『Lovable アプリを Port に接続したい』、『Port に OAuth アプリを登録したい』、『アプリに Port ログインを追加したい』、『外部アプリ用のクライアント ID が欲しい』、または『Port でログイン時に Callback URL の不一致／Service not found エラーが出るので修正したい』。対象外：Port の独自プラグインやカスタムウィジェットシステム（このスキルは Port 内部に何も構築・インストールしません）および Port の SSO や ID プロバイダー接続の管理。
