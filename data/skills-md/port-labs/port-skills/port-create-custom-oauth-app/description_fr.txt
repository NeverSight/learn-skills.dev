Enregistrez une application d’interface externe à portée d’organisation (un client OAuth public/PKCE Auth0) pour une UI personnalisée, telle qu’une application construite avec Lovable, v0 ou bolt.new, en utilisant les outils MCP de Port, puis intégrez le flux Authorization Code + PKCE dans cette UI afin qu’elle puisse authentifier les utilisateurs et appeler l’API Port. Utilisez cela lorsqu’on vous demande « créer une UI personnalisée sur Port », « connecter mon application Lovable à Port », « enregistrer une application OAuth dans Port », « ajouter la connexion Port à mon application », « obtenir un client ID pour mon application externe » ou « corriger un problème de correspondance d’URL de rappel / service non trouvé lors de la connexion avec Port ». Hors de portée : le système de plugins et de widgets personnalisés de Port (cette compétence ne construit ni n’installe jamais quoi que ce soit à l’intérieur de Port) et la gestion des connexions SSO ou des fournisseurs d’identité de Port.
