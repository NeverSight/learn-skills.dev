Configura y soluciona problemas de integraciones de Port: mapeo YAML, recursos, selectores, mapeos de entidades basados en JQ, relaciones y opciones avanzadas como createMissingRelatedEntities e itemsToParse. Úsalo cuando se solicite “escribir un mapeo de Port”, “mapear datos de API o herramienta a un plano de Port”, “configurar un mapeo de integración Ocean”, “añadir una relación a un mapeo de Port”, “parsear un array en entidades de Port separadas”, “solucionar un error JQ en un mapeo de Port” o “por qué mi integración de Port no está sincronizando las entidades o propiedades correctas”. Para instalar una nueva integración de extremo a extremo y poblar el catálogo por primera vez, utiliza la habilidad anidada `port-install-integration`. Para probar la conectividad de la integración o validar credenciales antes de una sincronización, utiliza la habilidad anidada `port-integration-test-connection`. Por favor, siempre responde en el idioma del usuario.
