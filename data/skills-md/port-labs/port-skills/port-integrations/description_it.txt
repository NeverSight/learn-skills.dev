Configura e risolvi i problemi delle integrazioni Port: mappatura YAML, risorse, selettori, mappature di entità basate su JQ, relazioni e opzioni avanzate come createMissingRelatedEntities e itemsToParse. Utilizza quando ti viene chiesto di “scrivere una mappatura Port”, “mappare dati API o di uno strumento su un blueprint Port”, “configurare una mappatura di integrazione Ocean”, “aggiungere una relazione a una mappatura Port”, “analizzare un array in entità Port separate”, “correggere un errore JQ in una mappatura Port” o “perché la mia integrazione Port non sincronizza le entità o le proprietà corrette”. Per installare una nuova integrazione end‑to‑end e popolare il catalogo per la prima volta, usa la skill nidificata `port-install-integration`. Per testare la connettività dell’integrazione o convalidare le credenziali prima di una sincronizzazione, usa la skill nidificata `port-integration-test-connection`. Rispondi sempre nella lingua dell’utente.
