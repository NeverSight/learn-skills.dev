Configurer et dépanner les intégrations Port : mapping YAML, ressources, sélecteurs, mappings d’entités basés sur JQ, relations et options avancées comme createMissingRelatedEntities et itemsToParse. Utilisez‑le lorsqu’on vous demande « écrire un mapping Port », « mapper les données d’une API ou d’un outil à un blueprint Port », « configurer un mapping d’intégration Ocean », « ajouter une relation à un mapping Port », « parser un tableau en entités Port séparées », « corriger une erreur JQ de mapping Port », ou « pourquoi mon intégration Port ne synchronise pas les bonnes entités ou propriétés ». Pour installer une nouvelle intégration de bout en bout et peupler le catalogue pour la première fois, utilisez la compétence imbriquée `port-install-integration`. Pour tester la connectivité de l’intégration ou valider les identifiants avant une synchronisation, utilisez la compétence imbriquée `port-integration-test-connection`.  

Veuillez toujours répondre dans la langue de l’utilisateur.
