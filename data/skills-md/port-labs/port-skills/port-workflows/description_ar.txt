إنشاء تدفقات عمل Port: أتمتة مبنية على العقد تتكون من المشغلات (نماذج الخدمة الذاتية، أحداث بحيرة السياق)، عقد الإجراءات (ويب هوك، إدراج أو تحديث كيان، تكامل إجراءات وكلاء إدارة GitHub/GitLab/Azure DevOps/Claude، كافكا، وكيل Cursor، الذكاء الاصطناعي)، عقد الشروط والإدخال، قوالب JQ بين العقد، وأذونات المشغلات ذاتية الخدمة، تُكتب كملف JSON للتدفق العمل ضد واجهة برمجة تطبيقات Port. استخدم ذلك عند طلب إنشاء تدفق عمل Port، إضافة مشغل إلى تدفق عمل، إضافة عقدة إجراء، ربط تدفق عمل ذاتي الخدمة، إضافة تفرع باستخدام عقدة شرط، إضافة خطوة موافقة إلى تدفق عمل، بناء أتمتة مدفوعة بالأحداث في Port، أو كتابة JSON للتدفق العمل. تدفقات عمل Port هي رسم بياني للأتمتة من نوع العقد والحواف الخاص بـ Port، ليست ملف أنابيب CI/CD مثل GitHub Actions.
