Создавайте рабочие процессы Port: автоматизации на основе узлов, состоящие из триггеров (самообслуживаемые формы, события контекстного озера), узлов действий (webhook, upsert entity, интеграционные действия GitHub/GitLab/Azure DevOps/Claude‑управляемых агентов, Kafka, Cursor Agent, AI), условных и входных узлов, шаблонизации JQ между узлами и разрешений на самообслуживание триггеров, оформляемые в виде JSON‑рабочего процесса через Port API. Используйте при запросе создания рабочего процесса Port, добавления триггера в рабочий процесс, добавления узла действия, настройки самообслуживаемого рабочего процесса, добавления ветвления с условным узлом, добавления шага одобрения в рабочий процесс, построения событийно‑ориентированной автоматизации в Port или написания JSON‑рабочего процесса. Рабочие процессы Port — это собственный граф автоматизации Port, основанный на узлах и ребрах, а не файл конвейера CI/CD, как GitHub Actions.
