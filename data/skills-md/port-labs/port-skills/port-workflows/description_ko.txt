Port 워크플로우 구축: 트리거(셀프 서비스 폼, 컨텍스트 레이크 이벤트)로 구성된 노드 기반 자동화, 액션 노드(웹훅, 엔티티 upsert, GitHub/GitLab/Azure DevOps/Claude 관리 에이전트 통합 액션, Kafka, Cursor Agent, AI), 조건 및 입력 노드, 노드 간 JQ 템플릿, 셀프 서비스 트리거 권한을 포함하고, Port API에 대한 워크플로우 JSON으로 작성합니다. Port 워크플로우를 생성하도록 요청받을 때, 워크플로우에 트리거를 추가할 때, 액션 노드를 추가할 때, 셀프 서비스 워크플로우를 연결할 때, 조건 노드로 분기할 때, 워크플로우에 승인 단계를 추가할 때, Port에서 이벤트 중심 자동화를 구축할 때, 혹은 워크플로우 JSON을 작성할 때 사용하십시오. Port 워크플로우는 Port 고유의 노드와 엣지 자동화 그래프이며, GitHub Actions와 같은 CI/CD 파이프라인 파일이 아닙니다.
