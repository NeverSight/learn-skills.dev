Construisez des workflows Port : des automatisations basées sur des nœuds composées de déclencheurs (formulaires en libre‑service, événements du lac de contexte), de nœuds d’action (webhook, upsert d’entité, actions d’intégration des agents gérés GitHub/GitLab/Azure DevOps/Claude, Kafka, Cursor Agent, IA), de nœuds condition et d’entrée, de modèles JQ entre les nœuds, ainsi que de permissions de déclencheur en libre‑service, rédigés sous forme de JSON de workflow via l’API Port. Utilisez‑les lorsqu’on vous demande de créer un workflow Port, d’ajouter un déclencheur à un workflow, d’ajouter un nœud d’action, de connecter un workflow en libre‑service, d’ajouter une branche avec un nœud condition, d’ajouter une étape d’approbation à un workflow, de construire une automatisation événementielle dans Port ou d’écrire du JSON de workflow. Les workflows Port sont le graphe d’automatisation nœuds‑et‑arêtes propre à Port, et non un fichier de pipeline CI/CD comme GitHub Actions.
