Construye flujos de trabajo de Port: automatizaciones basadas en nodos compuestas por disparadores (formularios de autoservicio, eventos del lago de contexto), nodos de acción (webhook, upsert de entidad, acciones de integración de agentes gestionados por GitHub/GitLab/Azure DevOps/Claude, Kafka, Cursor Agent, IA), nodos de condición y de entrada, plantillas JQ entre nodos y permisos de disparador de autoservicio, creadas como JSON de flujo de trabajo contra la API de Port. Utilízalo cuando se solicite crear un flujo de trabajo de Port, agregar un disparador a un flujo de trabajo, añadir un nodo de acción, conectar un flujo de trabajo de autoservicio, agregar ramificaciones con un nodo de condición, añadir un paso de aprobación a un flujo de trabajo, construir una automatización basada en eventos en Port o escribir JSON de flujo de trabajo. Los flujos de trabajo de Port son el propio grafo de automatización de nodos y aristas de Port, no un archivo de pipeline CI/CD como GitHub Actions.
