Crea una nuova Agent Skill per questo repository (port-labs/port-skills): scaffalda la directory skills/port-<name>/, scrivi un frontmatter valido, struttura il corpo come un breve router verso references/ e assets/, validala e rigenera l’indice README. Usa quando ti viene chiesto di creare una nuova skill Port, aggiungere una skill a questo repository, aiutarmi a scrivere un SKILL.md, contribuire con una skill, portare una skill interna di Port AI in questo repository o correggere una skill che non supera validate-skill.js.
