Construisez et mettez à jour les pages de tableau de bord Port : widgets (tableau, graphique numérique, graphique en secteurs, graphique à barres, graphique multi‑lignes, markdown, iframe, liens, carte d’action, tableau des exécutions d’actions, détails de l’entité, agent IA), mise en page en lignes de 12 colonnes, placement dans la barre latérale et règles de pages privées. Couvre la syntaxe des filtres de jeu de données afin qu’un widget affiche les entités attendues plutôt qu’un résultat vide ou incorrect. Utilisez lorsque l’on demande « construire un tableau de bord Port », « ajouter un widget à une page de tableau de bord », « créer un widget tableau/graphique numérique/graphique en secteurs dans Port », « pourquoi mon widget Port est vide », « rendre cette page de tableau de bord privée » ou « où placer ce tableau de bord dans la barre latérale ». Pour créer un widget plugin personnalisé (votre propre iframe React), utilisez la compétence imbriquée `port-dashboard-plugins`.
