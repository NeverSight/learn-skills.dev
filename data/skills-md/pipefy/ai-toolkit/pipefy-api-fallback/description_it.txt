Usa questa abilità quando uno strumento MCP fallisce E l'abilità di introspezione non è riuscita a risolvere il problema. Questo è il fallback di ultima risorsa (Tier 3): chiama direttamente l'API GraphQL di Pipefy usando curl o httpx, autenticandoti con l'Account di Servizio (OAuth2) o con un Personal Access Token (PAT) disponibile come variabile d'ambiente. Segui la strategia di risoluzione a 3 livelli prima di arrivare a questo punto.
