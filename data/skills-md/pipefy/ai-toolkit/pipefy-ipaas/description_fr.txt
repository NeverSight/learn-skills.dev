À utiliser lorsque l'utilisateur souhaite créer, tester, publier ou gérer des flux iPaaS (Advanced Automations) : intégrations en plusieurs étapes avec des applications externes (Slack, Gmail, Google Sheets), webhooks entrants, planifications, routeurs, étapes de code ou tables de données iPaaS. MCP uniquement, piloté via 4 méta-outils sur un catalogue par canal découvert lors de l'exécution. Pour les règles if/then natives ou les automatisations d’IA pilotées par des invites, utilisez plutôt skills/automations/.
