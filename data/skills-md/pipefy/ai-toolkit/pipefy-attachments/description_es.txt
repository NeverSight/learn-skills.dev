Utiliza esta habilidad cuando el usuario desea subir un archivo a un campo de adjunto de tarjeta o registro de tabla en Pipefy. Cubre ambos modos de entrada — un file_path local y un file_url descargado — además de un handshake con URL prefirmada para subir un archivo que el servidor no puede leer, a través de las herramientas MCP y la CLI.
