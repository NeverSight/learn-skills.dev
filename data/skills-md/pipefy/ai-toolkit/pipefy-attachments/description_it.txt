Utilizza questa abilità quando l'utente desidera caricare un file su una scheda Pipefy o sul campo di allegato di un record di tabella. Copre entrambi i modi di input — un file_path locale e un file_url scaricato — oltre a una stretta di mano con URL prefirmato per caricare un file che il server non può leggere, tramite gli strumenti MCP e la CLI. Si prega di rispondere sempre nella lingua dell'utente.
