Utilice esta habilidad SÓLO cuando el usuario solicite explícitamente ayuda para diseñar o diseñar un proceso ("ayúdame a diseñar", "cuál es la mejor estructura", "¿cómo organizo este flujo?"). Para solicitudes de ejecución directa ("crear una tubería para X", "crear un proceso de reembolso" o cualquier mensaje con una especificación detallada), omita esta habilidad y ejecútela directamente usando las habilidades de dominio (tuberías y tarjetas, automatizaciones, etc.).
