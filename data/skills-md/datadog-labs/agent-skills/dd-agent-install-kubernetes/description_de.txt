Installieren Sie den Datadog‑Agenten auf einem Kubernetes‑Cluster – Amazon EKS (Standard‑ oder Fargate‑Profile), Azure AKS, Google GKE (Standard‑ oder Autopilot), OpenShift, Oracle OKE, VMware Tanzu (TKG), Rancher (RKE2/K3s) oder selbstverwaltet – über den Datadog‑Operator (kubectl/Helm), das Datadog‑Helm‑Chart oder Terraform, mit Metriken, Logs und APM‑Trace‑Aufnahme standardmäßig aktiviert, Single Step Instrumentation deaktiviert, es sei denn, der Benutzer verlangt es, sowie optionalen Produkten; für eine SSI‑first‑Installation verwenden Sie `dd‑apm/k8s‑ssi` `agent‑install`. Verwenden Sie dies, wenn der Benutzer ein Kubernetes‑Cluster auf GKE, EKS, AKS, OpenShift, OKE oder TKG betreibt, den Datadog‑Agenten auf Kubernetes installieren oder einrichten möchte, den Agenten mit Terraform installieren will oder seine Kubernetes‑Pods überwachen möchte. Es verbindet keine Cloud‑Provider‑Integration und installiert den Agenten nicht auf eigenständigen Hosts oder reinem Docker. Erfordert ein Datadog‑Konto mit einem gültigen API‑Schlüssel und Anwendungsschlüssel; führen Sie zuerst `dd‑account‑setup` aus, falls diese fehlen.
