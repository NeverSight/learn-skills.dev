在 Kubernetes 叢集上安裝 Datadog Agent - 支援 Amazon EKS（標準或 Fargate 設定檔）、Azure AKS、Google GKE（標準或 Autopilot）、OpenShift、Oracle OKE、VMware Tanzu（TKG）、Rancher（RKE2/K3s）或自行管理的叢集——透過 Datadog Operator（kubectl/Helm）、Datadog Helm chart 或 Terraform 進行安裝，預設開啟指標、日誌與 APM 追蹤收集，除非使用者另外要求，Single Step Instrumentation 保持關閉，並可選擇其他產品；若要採用 SSI 為先的安裝，使用 `dd-apm/k8s-ssi` `agent-install`。適用於使用者在 GKE、EKS、AKS、OpenShift、OKE 或 TKG 上運行 Kubernetes 叢集，並要求安裝或設定 Datadog Agent、想以 Terraform 安裝 Agent，或想監控其 Kubernetes Pod 的情況。此指令不會連接雲端供應商整合，也不會在獨立主機或純 Docker 環境上安裝 Agent。需要具備有效的 Datadog 帳號以及 API 金鑰與應用程式金鑰；若缺少，請先執行 `dd-account-setup`。
