在 Kubernetes 集群上安装 Datadog Agent（支持 Amazon EKS（标准或 Fargate 配置）、Azure AKS、Google GKE（标准或 Autopilot）、OpenShift、Oracle OKE、VMware Tanzu（TKG）、Rancher（RKE2/K3s）或自行管理的集群）—可通过 Datadog Operator（kubectl/Helm）、Datadog Helm Chart 或 Terraform 安装，默认开启指标、日志和 APM 跟踪采集，除非用户另行要求，否则关闭“一键式仪器化”（Single Step Instrumentation），并可选择额外产品；若需要 SSI‑first 安装，请使用 `dd-apm/k8s-ssi` `agent-install`。在用户在 GKE、EKS、AKS、OpenShift、OKE 或 TKG 上运行 Kubernetes 集群，要求安装或设置 Datadog Agent、希望使用 Terraform 安装 Agent，或想监控其 Kubernetes Pod 时使用。本说明不涉及云提供商集成，也不在独立主机或普通 Docker 环境中安装 Agent。需要拥有有效 API 密钥和 Application Key 的 Datadog 账户；若缺少，请先运行 `dd-account-setup`。
