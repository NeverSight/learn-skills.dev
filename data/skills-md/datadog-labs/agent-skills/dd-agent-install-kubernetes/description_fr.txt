Installez l'Agent Datadog sur un cluster Kubernetes - Amazon EKS (profils standard ou Fargate), Azure AKS, Google GKE (standard ou Autopilot), OpenShift, Oracle OKE, VMware Tanzu (TKG), Rancher (RKE2/K3s) ou auto‑géré - via l’opérateur Datadog (kubectl/Helm), le chart Helm Datadog ou Terraform, avec la collecte des métriques, des logs et des traces APM activée par défaut, l’instrumentation à étape unique désactivée sauf demande explicite de l’utilisateur, et des produits optionnels ; pour une installation orientée SSI utilisez `dd-apm/k8s-ssi` `agent-install`. À employer lorsque l’utilisateur exécute un cluster Kubernetes sur GKE, EKS, AKS, OpenShift, OKE ou TKG, demande d’installer ou de configurer l’Agent Datadog sur Kubernetes, souhaite installer l’Agent avec Terraform ou veut surveiller ses pods Kubernetes. Ne configure pas d’intégration avec un fournisseur cloud ni n’installe l’Agent sur des hôtes autonomes ou Docker simple. Nécessite un compte Datadog avec une clé API et une clé d’application valides ; exécutez d’abord `dd-account-setup` s’ils manquent.
