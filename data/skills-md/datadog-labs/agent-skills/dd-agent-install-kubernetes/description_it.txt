Installa l'Agent Datadog su un cluster Kubernetes - Amazon EKS (profilo standard o Fargate), Azure AKS, Google GKE (standard o Autopilot), OpenShift, Oracle OKE, VMware Tanzu (TKG), Rancher (RKE2/K3s) o auto‑gestito - tramite il Datadog Operator (kubectl/Helm), il chart Helm di Datadog o Terraform, con metriche, log e raccolta di trace APM attivati per impostazione predefinita, Single Step Instrumentation disattivato a meno che l'utente lo richieda, e prodotti opzionali; per un'installazione SSI‑first utilizza `dd-apm/k8s-ssi` `agent-install`.  
Usalo quando l'utente sta eseguendo un cluster Kubernetes su GKE, EKS, AKS, OpenShift, OKE o TKG, richiede di installare o configurare l'Agent Datadog su Kubernetes, desidera installare l'Agent con Terraform o vuole monitorare i propri pod Kubernetes.  
Non collega un'integrazione con il provider cloud né installa l'Agent su host autonomi o su Docker senza orchestrazione.  
Richiede un account Datadog con una chiave API e una chiave applicazione valide; esegui prima `dd-account-setup` se mancano.
