قم بتثبيت عميل Datadog على مجموعة Kubernetes – Amazon EKS (القياسية أو ملفات تعريف Fargate)، Azure AKS، Google GKE (القياسية أو Autopilot)، OpenShift، Oracle OKE، VMware Tanzu (TKG)، Rancher (RKE2/K3s) أو مجموعة مُدارة ذاتيًا – من خلال مشغل Datadog (kubectl/Helm)، مخطط Helm الخاص بـ Datadog، أو Terraform، مع تمكين جمع المقاييس والسجلات وتتبع APM افتراضيًا، وتعطيل الـ Single Step Instrumentation ما لم يطلب المستخدم ذلك، ومع منتجات اختيارية؛ لتثبيت يركز على SSI استخدم `dd-apm/k8s-ssi` `agent-install`. يُستخدم عندما يكون المستخدم يدير مجموعة Kubernetes على GKE أو EKS أو AKS أو OpenShift أو OKE أو TKG، ويطلب تثبيت أو إعداد عميل Datadog على Kubernetes، أو يريد تثبيت العميل عبر Terraform، أو يرغب في مراقبة حاويات Kubernetes الخاصة به. لا يتضمن ربط تكامل مزود سحابي أو تثبيت العميل على مضيفات مستقلة أو Docker عادي. يتطلب حساب Datadog يحتوي على مفتاح API صالح ومفتاح تطبيق؛ شغّل `dd-account-setup` أولاً إذا كانا مفقودين.
