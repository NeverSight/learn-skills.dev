Instalar el Agente de Datadog en un clúster de Kubernetes - Amazon EKS (perfiles estándar o Fargate), Azure AKS, Google GKE (estándar o Autopilot), OpenShift, Oracle OKE, VMware Tanzu (TKG), Rancher (RKE2/K3s) o autogestionado - mediante el Datadog Operator (kubectl/Helm), el chart Helm de Datadog o Terraform, con métricas, registros y captura de trazas APM activados por defecto, Instrumentación de Paso Único desactivada a menos que el usuario lo solicite, y productos opcionales; para una instalación priorizando SSI, use `dd-apm/k8s-ssi` `agent-install`. Utilícelo cuando el usuario esté ejecutando un clúster de Kubernetes en GKE, EKS, AKS, OpenShift, OKE o TKG, solicite instalar o configurar el Agente de Datadog en Kubernetes, desee instalar el Agente con Terraform o quiera monitorizar sus pods de Kubernetes. No conecta una integración de proveedor de nube ni instala el Agente en hosts autónomos o Docker simple. Requiere una cuenta de Datadog con una clave API y una clave de aplicación válidas; ejecute `dd-account-setup` primero si faltan.
