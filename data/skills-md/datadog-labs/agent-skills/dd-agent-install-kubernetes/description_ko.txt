Kubernetes 클러스터에 Datadog 에이전트를 설치합니다 - Amazon EKS(표준 또는 Fargate 프로파일), Azure AKS, Google GKE(표준 또는 Autopilot), OpenShift, Oracle OKE, VMware Tanzu(TKG), Rancher(RKE2/K3s) 또는 자체 관리 클러스터에 - Datadog Operator(kubectl/Helm), Datadog Helm 차트 또는 Terraform을 통해, 기본적으로 메트릭, 로그 및 APM 트레이스 수집이 활성화되고, 사용자가 요청하지 않는 한 Single Step Instrumentation은 비활성화되며, 선택적 제품도 제공됩니다; SSI‑first 설치를 위해서는 `dd-apm/k8s-ssi` `agent-install`을 사용합니다. 사용자가 GKE, EKS, AKS, OpenShift, OKE 또는 TKG에서 Kubernetes 클러스터를 운영 중이며 Kubernetes에 Datadog 에이전트를 설치·설정하려 하거나 Terraform으로 에이전트를 설치하려 하거나 Kubernetes 포드를 모니터링하려 할 때 사용합니다. 클라우드 제공자 통합을 연결하거나 독립 실행형 호스트 또는 일반 Docker에 에이전트를 설치하지 않습니다. 유효한 API 키와 애플리케이션 키가 포함된 Datadog 계정이 필요하며, 키가 없을 경우 먼저 `dd-account-setup`을 실행하십시오.
