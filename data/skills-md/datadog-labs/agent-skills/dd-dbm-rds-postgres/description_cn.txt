在 AWS RDS 上为 PostgreSQL 设置 Datadog 数据库监控（DBM）——在实例的参数组中启用 pg_stat_statements，然后使用 CloudFormation 部署受管 Agent，或使用 Terraform 创建一个，亦或配置已有的 Agent，并设置只读的 Datadog 监控用户。适用于用户想为 RDS Postgres 数据库设置数据库监控、监控 Postgres RDS 实例的查询性能、在 RDS 上为 Postgres 启用 DBM，或使用 Terraform 为 RDS Postgres 数据库设置 DBM 的情况。不支持 Aurora、RDS 多可用区 DB 集群或只读副本（请引导用户至源写入实例或 DBM 文档），也不为其他引擎设置 DBM。需要在持有该实例的 AWS 账户中启用 Datadog AWS 集成；如果缺失，请先运行 `dd-aws-integration`。
