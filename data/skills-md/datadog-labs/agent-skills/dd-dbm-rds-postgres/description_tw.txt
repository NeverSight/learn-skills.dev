在 AWS RDS 上為 PostgreSQL 設置 Datadog 資料庫監控 (DBM) —— 在實例的參數組中啟用 pg_stat_statements，然後使用 CloudFormation 部署受管代理，或使用 Terraform 建立代理，或配置現有代理，同時建立只讀的 Datadog 監控使用者。當使用者想為 RDS Postgres 資料庫設置資料庫監控、監測 Postgres RDS 實例的查詢效能、在 RDS 上啟用 Postgres 的 DBM，或使用 Terraform 為 RDS Postgres 資料庫設置 DBM 時使用。不支援 Aurora、RDS Multi‑AZ DB 叢集或讀取副本（請將使用者指向來源作者或 DBM 文件），亦不為其他引擎設置 DBM。需要在持有該實例的 AWS 帳號上啟用 Datadog AWS 整合；若缺少，請先執行 `dd-aws-integration`。
