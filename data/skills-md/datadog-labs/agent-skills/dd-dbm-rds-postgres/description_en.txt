Set up Datadog Database Monitoring (DBM) for PostgreSQL on AWS RDS - enable pg_stat_statements on the instance's parameter group, then deploy a managed Agent with CloudFormation, provision one with Terraform, or configure an existing Agent, plus the read-only datadog monitoring user. Use when the user wants to set up Database Monitoring for an RDS Postgres database, monitor query performance on a Postgres RDS instance, enable DBM for Postgres on RDS, or use Terraform to set up DBM for an RDS Postgres database. Does not handle Aurora, RDS Multi-AZ DB clusters, or read replicas (point the user at the source writer or the DBM docs instead), and does not set up DBM for other engines. Requires the Datadog AWS integration for the AWS account that holds the instance; run `dd-aws-integration` first if it is missing.
