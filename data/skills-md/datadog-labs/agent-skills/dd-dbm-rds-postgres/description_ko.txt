Datadog Database Monitoring(DBM)을 AWS RDS의 PostgreSQL에 설정합니다 - 인스턴스의 파라미터 그룹에서 pg_stat_statements를 활성화하고, CloudFormation으로 관리형 에이전트를 배포하거나 Terraform으로 에이전트를 프로비저닝하거나 기존 에이전트를 구성하고, 읽기 전용 Datadog 모니터링 사용자를 추가합니다. 사용자는 RDS Postgres 데이터베이스에 대한 Database Monitoring을 설정하거나, Postgres RDS 인스턴스의 쿼리 성능을 모니터링하거나, RDS에서 Postgres용 DBM을 활성화하거나, Terraform을 사용해 RDS Postgres 데이터베이스에 대한 DBM을 설정하려는 경우에 사용합니다. Aurora, RDS Multi‑AZ DB 클러스터 또는 읽기 복제본은 지원되지 않으며(사용자를 원본 라이터 또는 DBM 문서로 안내), 다른 엔진에 대한 DBM 설정도 지원되지 않습니다. 인스턴스를 보유한 AWS 계정에 Datadog AWS 통합이 필요합니다; 통합이 없으면 먼저 `dd-aws-integration`을 실행하십시오.
