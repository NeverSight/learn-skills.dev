Configura el monitoreo de bases de datos de Datadog (DBM) para PostgreSQL en AWS RDS: habilita pg_stat_statements en el grupo de parámetros de la instancia, luego despliega un agente gestionado con CloudFormation, aprovéchalo con Terraform o configura un agente existente, además del usuario de monitoreo de Datadog de solo lectura. Úsalo cuando el usuario quiera configurar el monitoreo de bases de datos para una base de datos RDS Postgres, monitorear el rendimiento de consultas en una instancia RDS Postgres, habilitar DBM para Postgres en RDS, o usar Terraform para configurar DBM para una base de datos RDS Postgres. No maneja Aurora, clústeres de bases de datos RDS Multi-AZ, ni réplicas de lectura (dirige al usuario al escritor principal o a la documentación de DBM en su lugar), y no configura DBM para otros motores. Requiere la integración AWS de Datadog para la cuenta AWS que contiene la instancia; ejecuta `dd-aws-integration` primero si falta.
