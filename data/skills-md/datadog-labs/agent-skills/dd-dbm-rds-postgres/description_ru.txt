Настройте мониторинг баз данных Datadog (DBM) для PostgreSQL в AWS RDS — включите pg_stat_statements в группе параметров экземпляра, затем разверните управляемый агент с помощью CloudFormation, создайте его с помощью Terraform или настройте существующий агент, а также пользователя Datadog с правами только для чтения. Используйте, когда пользователь хочет настроить мониторинг баз данных для RDS‑Postgres, отслеживать производительность запросов на экземпляре Postgres в RDS, включить DBM для Postgres в RDS или использовать Terraform для настройки DBM для базы данных RDS Postgres. Не поддерживает Aurora, кластеры RDS Multi‑AZ DB и реплики только для чтения (в таком случае укажите пользователю обратиться к основному писателю или к документации DBM), и не настраивает DBM для других движков. Требуется интеграция Datadog AWS для AWS‑аккаунта, в котором находится экземпляр; сначала выполните `dd-aws-integration`, если она отсутствует.
