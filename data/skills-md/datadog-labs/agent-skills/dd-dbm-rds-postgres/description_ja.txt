Datadog データベースモニタリング (DBM) を AWS RDS の PostgreSQL に設定する – インスタンスのパラメータグループで pg_stat_statements を有効にし、その後 CloudFormation でマネージドエージェントをデプロイするか、Terraform でプロビジョニングするか、既存のエージェントを設定し、読み取り専用の Datadog 監視ユーザーも作成します。RDS の Postgres データベースのデータベースモニタリングを設定したい場合、Postgres RDS インスタンスのクエリパフォーマンスを監視したい場合、RDS 上で Postgres 用 DBM を有効にしたい場合、または Terraform を使用して RDS Postgres データベースの DBM を設定したい場合に使用します。Aurora、RDS Multi‑AZ DB クラスター、リードレプリカは対象外です（代わりにソースライターまたは DBM ドキュメントを参照してください）。他のエンジン向けの DBM 設定も行いません。インスタンスが属する AWS アカウントに対して Datadog の AWS インテグレーションが必要です。未設定の場合はまず `dd-aws-integration` を実行してください。
