إعداد مراقبة قاعدة البيانات في Datadog (DBM) لـ PostgreSQL على AWS RDS - تفعيل pg_stat_statements في مجموعة معلمات المثيل، ثم نشر عميل مُدار باستخدام CloudFormation، أو إعداده عبر Terraform، أو تكوين عميل موجود، بالإضافة إلى مستخدم مراقبة Datadog ذو صلاحيات قراءة فقط. استخدم ذلك عندما يرغب المستخدم في إعداد مراقبة قاعدة البيانات لقاعدة بيانات RDS PostgreSQL، أو مراقبة أداء الاستعلامات على مثيل PostgreSQL RDS، أو تمكين DBM لـ PostgreSQL على RDS، أو استخدام Terraform لإعداد DBM لقاعدة بيانات RDS PostgreSQL. لا يتعامل مع Aurora أو مجموعات قواعد البيانات المتعددة الازدواجية (Multi-AZ) في RDS أو النسخ القرائية (point the user at the source writer or the DBM docs instead)، ولا يقوم بإعداد DBM لمحركات أخرى. يتطلب تكامل Datadog مع AWS لحساب AWS الذي يحتوي على المثيل؛ شغِّل `dd-aws-integration` أولاً إذا كان مفقوداً.
