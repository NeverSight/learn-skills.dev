Configura il monitoraggio del database Datadog (DBM) per PostgreSQL su AWS RDS – abilita pg_stat_statements nel gruppo di parametri dell'istanza, quindi distribuisci un agente gestito con CloudFormation, provisionane uno con Terraform o configura un agente esistente, più l’utente di monitoraggio Datadog in sola lettura. Da utilizzare quando l’utente desidera impostare il Database Monitoring per un database RDS Postgres, monitorare le prestazioni delle query su un’istanza RDS Postgres, abilitare DBM per Postgres su RDS o usare Terraform per configurare DBM per un database RDS Postgres. Non gestisce Aurora, cluster DB RDS Multi‑AZ o repliche di lettura (indirizza l’utente allo scrittore di origine o alla documentazione DBM) e non configura DBM per altri motori. Richiede l’integrazione Datadog AWS per l’account AWS che contiene l’istanza; esegui `dd-aws-integration` prima se manca.
