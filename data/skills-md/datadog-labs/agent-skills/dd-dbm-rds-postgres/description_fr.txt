Configurer la surveillance des bases de données Datadog (DBM) pour PostgreSQL sur AWS RDS – activer pg_stat_statements sur le groupe de paramètres de l’instance, puis déployer un Agent géré avec CloudFormation, en provisionner un avec Terraform, ou configurer un Agent existant, ainsi que l’utilisateur de surveillance Datadog en lecture‑seule. À utiliser lorsque l’utilisateur souhaite configurer la surveillance des bases de données pour une base de données RDS Postgres, surveiller les performances des requêtes sur une instance RDS Postgres, activer DBM pour Postgres sur RDS, ou utiliser Terraform pour configurer DBM pour une base de données RDS Postgres. Ne gère pas Aurora, les clusters RDS Multi‑AZ, ou les réplicas en lecture (dirigez l’utilisateur vers le serveur source ou la documentation DBM), et ne configure pas DBM pour d’autres moteurs. Nécessite l’intégration Datadog AWS pour le compte AWS qui détient l’instance ; exécutez `dd-aws-integration` d’abord s’il manque.
