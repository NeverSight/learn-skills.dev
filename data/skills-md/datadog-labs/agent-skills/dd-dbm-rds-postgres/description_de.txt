Richten Sie das Datadog Database Monitoring (DBM) für PostgreSQL auf AWS RDS ein – aktivieren Sie pg_stat_statements in der Parametergruppe der Instanz und stellen Sie dann einen verwalteten Agenten über CloudFormation bereit, provisionieren Sie einen mit Terraform oder konfigurieren Sie einen bestehenden Agenten, plus den schreibgeschützten Datadog‑Monitoring‑Benutzer. Verwenden Sie dies, wenn der Nutzer das Database Monitoring für eine RDS‑Postgres‑Datenbank einrichten, die Abfrageleistung auf einer Postgres‑RDS‑Instanz überwachen, DBM für Postgres auf RDS aktivieren oder Terraform zur Einrichtung von DBM für eine RDS‑Postgres‑Datenbank nutzen möchte. Unterstützt nicht Aurora, RDS Multi‑AZ‑DB‑Cluster oder Read‑Replicas (verweisen Sie den Nutzer stattdessen auf den Source‑Writer oder die DBM‑Dokumentation) und richtet DBM für andere Engines nicht ein. Erfordert die Datadog‑AWS‑Integration für das AWS‑Konto, das die Instanz enthält; führen Sie zuerst `dd-aws-integration` aus, falls diese fehlt.
