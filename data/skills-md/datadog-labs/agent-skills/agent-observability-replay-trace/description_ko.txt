개발자가 만족하지 못한 단일 에이전트 관찰성 / LLM 관찰 트레이스를 반복하고자 할 때 사용합니다 — 로컬 코드를 대상으로 해당 트레이스를 다시 실행하고, 이전 출력과 새 출력의 간결한 차이를 확인한 뒤, (코드 변경 → 재실행 → 차이 확인) 과정을 만족할 때까지 반복합니다. 호출 형식: `/agent-observability-replay-trace <trace-id> [테스트할 변경사항]`. 신호 예시: “이 트레이스를 재생”, “트레이스를 반복”, “이 트레이스의 출력이 잘못됐으니 수정하고 다시 실행”, “<id> 트레이스를 <변경>과 함께 재실행”. 에이전트 관찰성 UI에서 트레이스 ID와 수정 내용을 복사해 붙여넣으면 됩니다. 트레이스를 datadog-llmo MCP 또는 pup CLI를 통해 가져오고, 코드를 편집한 뒤 앱을 재실행해 새 트레이스를 생성하고, 두 트레이스를 차이 비교합니다 — 로컬 서버나 브라우저가 필요 없습니다. ddtrace / LLM 관찰(첫 번째 Python)로 추적된 에이전트에 대해 JSON-직렬화 가능한 입력 엔트리를 사용합니다. 다음 경우에는 사용하지 마세요: 점수 기반 실험 또는 브라우저 “Replay” 버튼(이는 agent‑observability‑replay‑experiment), 데이터셋/CSV에서 실험 구축, 평가자 작성, 실패한 트레이스 원인 분석, RUM/HTTP 세션 재생.
