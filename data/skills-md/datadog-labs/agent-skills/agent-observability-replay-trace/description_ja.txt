開発者が出力が好ましくない特定のエージェント・オブザーバビリティ／LLM Obs トレースを 1 件だけ反復したいときに使用します — そのトレースをローカルコードで再実行し、古い出力と新しい出力の簡潔な差分を確認し、（コード変更 → 再実行 → 差分）を満足するまで繰り返します。

次のように呼び出します: `/agent-observability-replay-trace <trace-id> [テストする変更]`。

トリガーフレーズ: 「このトレースを再生」「トレースを反復」「このトレースの出力が間違っているので修正して再実行」「トレース <id> を <変更> で再実行」、エージェント・オブザーバビリティ UI からトレース ID を貼り付け、何を修正すべきかの説明を加える。

datadog-llmo MCP または pup CLI を介してトレースを取得し、コードを編集してアプリを再実行し、新しいトレースを生成し、両者を比較します — ローカルサーバーやブラウザは不要です。

ddtrace / LLM Obs でトレースされたエージェント（Python が第一級）向けで、エントリ入力は JSON にシリアライズ可能です。

以下の用途には使用しないでください: スコア付けされた実験やブラウザの「Replay」ボタン（これは agent-observability-replay-experiment 用）、データセット/CSV から実験を作成すること、評価器の作成、失敗したトレースの根本原因分析、または RUM/HTTP セッションのリプレイ。
