在开发者想对某个特定的 Agent Observability / LLM Obs 跟踪结果不满意进行迭代时使用——在本地代码上重新运行该跟踪，查看旧输出与新输出的简要差异，并循环（修改代码→重放→对比）直到满意。调用方式为 /agent-observability-replay-trace <trace-id> [要测试的更改]。触发信号包括：“重放此跟踪”；“对跟踪进行迭代”；“此跟踪的输出错误，请修复后重新运行”；“使用 <change> 重新运行跟踪 <id>”；以及在 Agent Observability UI 中粘贴跟踪 ID 并描述要修复的内容。它通过 datadog-llmo MCP 或 pup CLI 获取跟踪，编辑代码，重新运行应用以生成新的跟踪，并对两者进行差异比对——无需本地服务器，也不需浏览器。适用于使用 ddtrace / LLM Obs（Python 一等公民）进行跟踪的代理，输入必须是 JSON 可序列化的。请勿用于：已评分的实验或浏览器的“Replay”按钮（那是 agent-observability-replay-experiment）、从数据集/CSV 创建实验、编写评估器、根因分析失败的跟踪，或 RUM/HTTP 会话重放。
