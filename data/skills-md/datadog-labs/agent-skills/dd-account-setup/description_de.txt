Stellen Sie sicher, dass der Benutzer ein authentifiziertes Datadog-Konto mit einem gültigen DD_API_KEY in der richtigen Region hat, bevor irgendeine Datadog‑Einrichtung oder -Instrumentierung erfolgt. Er erkennt vorhandene DD_API_KEY / DD_APP_KEY / DD_SITE, validiert sie über die Datadog‑API und behebt den häufigen 403‑Fehler wegen falscher Region. Wenn kein nutzbarer Schlüssel vorhanden ist, meldet er den Benutzer an (OAuth) oder erstellt ein neues Konto, anschließend wird ein Schlüssel abgerufen und validiert. Verwenden Sie dies, wann immer ein Benutzer ein Datadog‑Konto oder einen API‑Schlüssel benötigt, einen 403‑/Falsch‑Region‑Fehler erhält oder kurz davor steht, irgendeine Datadog *-Setup‑ oder Instrumentierungs‑Fähigkeit auszuführen.
