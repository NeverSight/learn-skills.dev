Asegúrese de que el usuario tenga una cuenta autenticada de Datadog con una DD_API_KEY válida en la región correcta antes de cualquier configuración o instrumentación de Datadog. Detecta la DD_API_KEY / DD_APP_KEY / DD_SITE existentes, las valida contra la API de Datadog y corrige el típico error 403 por región incorrecta. Si no existe una clave utilizable, inicia sesión al usuario (OAuth) o crea una cuenta nueva, luego obtiene y valida una clave. Use esto siempre que un usuario necesite una cuenta o clave API de Datadog, reciba un error 403 / región incorrecta, o esté a punto de ejecutar cualquier habilidad de *-setup o instrumentación de Datadog.
