Datadog 설정이나 계측을 수행하기 전에 사용자가 올바른 지역에 유효한 DD_API_KEY를 가진 인증된 Datadog 계정을 보유하고 있는지 확인합니다. 기존 DD_API_KEY / DD_APP_KEY / DD_SITE를 감지하고 Datadog API에 대해 검증하며, 흔히 발생하는 잘못된 지역 403 오류를 수정합니다. 사용 가능한 키가 없을 경우, 사용자를 로그인(OAuth)시키거나 새 계정을 생성한 뒤 키를 획득하고 검증합니다. 사용자가 Datadog 계정이나 API 키가 필요하거나 403 / 잘못된 지역 오류가 발생했을 때, 혹은 any Datadog *-setup 또는 계측 스킬을 실행하려 할 때마다 이 절차를 사용하십시오.
