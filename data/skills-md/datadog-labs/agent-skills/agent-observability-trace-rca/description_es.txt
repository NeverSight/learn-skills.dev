Análisis de causa raíz en trazas de LLM de producción. Diagnostica por qué una aplicación LLM está fallando: funciona a partir de veredictos de jueces de evaluación, errores de tiempo de ejecución o anomalías estructurales, según las señales que estén presentes. Recorre el árbol de envergadura desde el síntoma hasta la causa raíz. Se usa cuando el usuario dice "qué está mal con mi aplicación", "por qué falla mi evaluación", "analizar errores", "análisis de causa raíz", "diagnosticar fallas" o quiere comprender los patrones de fallas de producción.
