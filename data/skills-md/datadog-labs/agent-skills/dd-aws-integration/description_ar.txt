إعداد تكامل Datadog مع AWS باستخدام Terraform ‑ ينشئ دور IAM متعدد الحسابات الذي تفترضُه Datadog (معرف خارجي، بدون حفظ بيانات اعتماد)، يرفق سياسات الأذونات التي تنشرها Datadog، ويسجل الحساب عبر datadog_integration_aws_account بحيث تبدأ مقاييس AWS وفهرس الموارد ونتائج CSPM في التدفق. يُستخدم عندما يكون لدى المستخدم موارد AWS يرغب في مراقبتها، أو يريد ربط حساب AWS بـ Datadog، أو يطلب إعداد أو إصلاح تكامل AWS، أو يحتاج إلى توفير دور IAM الخاص بـ Datadog ومعرفه الخارجي. لا يقوم بإعداد نقل السجلات.
