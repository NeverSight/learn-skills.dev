Configura la integración de Datadog con AWS mediante Terraform: crea el rol IAM de cuenta cruzada que asume Datadog (ID externo, sin credenciales almacenadas), adjunta las políticas de permiso que publica Datadog y registra la cuenta a través de datadog_integration_aws_account para que comiencen a fluir las métricas de AWS, el catálogo de recursos y los hallazgos CSPM. Úsalo cuando el usuario tenga recursos de AWS que quiera monitorizar, quiera conectar una cuenta de AWS a Datadog, solicite configurar o reparar la integración de AWS, o necesite provisionar el rol IAM de Datadog y el ID externo. No configura el reenvío de logs.
