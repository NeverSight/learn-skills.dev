Настройте интеграцию Datadog с AWS с помощью Terraform — создаёт межаккаунтную роль IAM, которую использует Datadog (external ID, без хранимых учётных данных), привязывает политики разрешений, публикуемые Datadog, и регистрирует аккаунт через datadog_integration_aws_account, чтобы начали поступать метрики AWS, каталог ресурсов и результаты CSPM. Используйте, когда пользователь имеет ресурсы AWS, которые он хочет мониторить, хочет подключить аккаунт AWS к Datadog, просит настроить или восстановить интеграцию AWS, либо нуждается в роли IAM Datadog и external ID. Не настраивает передачу логов.
