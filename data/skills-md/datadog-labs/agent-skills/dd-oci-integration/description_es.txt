Configura la integración de Datadog con Oracle Cloud Infrastructure (OCI) mediante Terraform: verifica ~/.oci/config y luego aplica el módulo oficial oracle‑cloud‑integration de Datadog para crear el usuario de servicio, el grupo, las políticas IAM y la clave API en el tenancy, registrarlo en Datadog y, opcionalmente, habilitar la recolección de logs. Utilízalo cuando el usuario tenga recursos en Oracle Cloud, quiera monitorizar un tenancy de OCI, desee conectar OCI a Datadog o solicite configurar o reparar la integración de OCI.
