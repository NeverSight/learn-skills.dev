Terraform を使用して Datadog の Oracle Cloud Infrastructure (OCI) 統合を設定します ― ~/.oci/config を検証し、Datadog の公式 oracle‑cloud‑integration モジュールを適用してテナンシー内に Datadog サービスユーザー、グループ、IAM ポリシー、API キーを作成し、Datadog に登録します。オプションでログ収集も含められます。Oracle Cloud のリソースを保有している、OCI テナンシーを監視したい、OCI を Datadog に接続したい、または OCI 統合の設定や修復を依頼された場合に使用してください。
