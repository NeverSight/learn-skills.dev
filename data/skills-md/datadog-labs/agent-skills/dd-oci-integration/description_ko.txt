Terraform를 사용하여 Datadog Oracle Cloud Infrastructure(OCI) 통합을 설정합니다 – ~/.oci/config를 확인한 후 Datadog 공식 oracle‑cloud‑integration 모듈을 적용하여 Datadog 서비스 사용자, 그룹, IAM 정책 및 테넌시의 API 키를 생성하고 Datadog에 등록하며, 선택적으로 로그 수집을 포함합니다. 사용자가 Oracle Cloud 리소스를 보유하고 있거나, OCI 테넌시를 모니터링하고 싶거나, OCI를 Datadog에 연결하려 하거나, OCI 통합을 설정하거나 복구하도록 요청할 때 사용합니다.
