Настройте интеграцию Datadog с Oracle Cloud Infrastructure (OCI) с помощью Terraform — проверяется файл ~/.oci/config, затем применяется официальный модуль oracle‑cloud‑integration от Datadog для создания сервисного пользователя Datadog, группы, IAM‑политик и API‑ключа в аренде и их регистрации в Datadog, при желании включая сбор журналов. Используйте, когда пользователь имеет ресурсы Oracle Cloud, хочет мониторировать аренду OCI, хочет подключить OCI к Datadog или просит настроить или восстановить интеграцию OCI.
