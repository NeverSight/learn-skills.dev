Configurer l’intégration Datadog Oracle Cloud Infrastructure (OCI) avec Terraform – vérifie le fichier ~/.oci/config, puis applique le module officiel oracle‑cloud‑integration de Datadog pour créer l’utilisateur de service Datadog, le groupe, les politiques IAM et la clé API dans la location, les enregistrer auprès de Datadog, et, éventuellement, inclure la collecte de logs. À utiliser lorsque l’utilisateur possède des ressources Oracle Cloud, veut surveiller une location OCI, souhaite connecter OCI à Datadog, ou demande de configurer ou réparer l’intégration OCI.
