Configura l'integrazione Datadog Oracle Cloud Infrastructure (OCI) con Terraform: verifica ~/.oci/config, quindi applica il modulo ufficiale oracle‑cloud‑integration di Datadog per creare l'utente di servizio Datadog, il gruppo, le politiche IAM e la chiave API nella tenancy e registrarlo su Datadog, includendo opzionalmente la raccolta dei log. Da utilizzare quando l'utente dispone di risorse Oracle Cloud, desidera monitorare una tenancy OCI, vuole collegare OCI a Datadog o richiede di configurare o riparare l'integrazione OCI.
