Настройте интеграцию Datadog с Google Cloud с помощью Terraform — создаётся сервисный аккаунт в проекте‑хосте, позволяя делегированному принципалу Datadog выступать от его имени через роль roles/iam.serviceAccountTokenCreator (без ключей сервисного аккаунта), активируются необходимые API, предоставляются роли мониторинга в выбранных проектах и папках, а аккаунт регистрируется через datadog_integration_gcp_sts. Используйте, когда пользователь хочет мониторить ресурсы GCP, такие как Compute Engine, Cloud SQL, GKE, Cloud Run или Pub/Sub, подключить проект, папку или организацию GCP к Datadog, либо запросил настройку или восстановление интеграции GCP. Не настраивает переадресацию журналов.
