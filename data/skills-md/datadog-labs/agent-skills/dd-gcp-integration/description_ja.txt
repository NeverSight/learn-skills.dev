Terraform を使用して Datadog の Google Cloud 統合を設定します。ホストプロジェクトにサービスアカウントを作成し、Datadog の委任プリンシパルが roles/iam.serviceAccountTokenCreator を介してそのアカウントをインパーソネートできるようにします（サービスアカウントキーは使用しません）。必要な API を有効化し、選択したプロジェクトやフォルダ全体に監視ロールを付与し、datadog_integration_gcp_sts を通じてアカウントを登録します。Compute Engine、Cloud SQL、GKE、Cloud Run、Pub/Sub などの GCP リソースを監視したい場合、GCP プロジェクト、フォルダ、または組織を Datadog に接続したい場合、あるいは GCP 統合の設定や修復を依頼された場合に使用します。ログ転送は設定しません。
