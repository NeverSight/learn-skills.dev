Configurer l'intégration Datadog Google Cloud avec Terraform - crée un compte de service dans le projet hôte, permet au principal délégué de Datadog de l'usurper via roles/iam.serviceAccountTokenCreator (sans clés de compte de service), active les API requises, attribue les rôles de surveillance aux projets et dossiers choisis, et enregistre le compte via datadog_integration_gcp_sts. Utilisez‑le lorsque l'utilisateur souhaite surveiller les ressources GCP telles que Compute Engine, Cloud SQL, GKE, Cloud Run ou Pub/Sub, souhaite connecter un projet, un dossier ou une organisation GCP à Datadog, ou demande de configurer ou réparer l'intégration GCP. Ne configure pas l'acheminement des journaux.
