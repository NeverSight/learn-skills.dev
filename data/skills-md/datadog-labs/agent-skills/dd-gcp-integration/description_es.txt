Configura la integración de Datadog con Google Cloud mediante Terraform: crea una cuenta de servicio en el proyecto anfitrión, permite que el principal delegado de Datadog la suplante mediante roles/iam.serviceAccountTokenCreator (sin claves de cuenta de servicio), habilita las API necesarias, otorga los roles de monitoreo en los proyectos y carpetas seleccionados, y registra la cuenta a través de datadog_integration_gcp_sts. Úsalo cuando el usuario desea monitorizar recursos de GCP como Compute Engine, Cloud SQL, GKE, Cloud Run o Pub/Sub, quiere conectar un proyecto, carpeta u organización de GCP a Datadog, o solicita configurar o reparar la integración de GCP. No configura el reenvío de logs.
