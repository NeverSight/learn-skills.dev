Terraform를 사용하여 Datadog Google Cloud 통합을 설정합니다 — 호스트 프로젝트에 서비스 계정을 생성하고, Datadog의 위임 프린시펄이 roles/iam.serviceAccountTokenCreator를 통해 이를 사칭하도록 허용합니다(서비스 계정 키를 사용하지 않음). 필수 API를 활성화하고, 선택한 프로젝트와 폴더 전반에 모니터링 역할을 부여하며, datadog_integration_gcp_sts를 통해 계정을 등록합니다. 사용자가 Compute Engine, Cloud SQL, GKE, Cloud Run, Pub/Sub와 같은 GCP 리소스를 모니터링하고 싶거나, GCP 프로젝트·폴더·조직을 Datadog에 연결하고자 할 때, 또는 GCP 통합을 설정하거나 복구해 달라고 요청할 때 사용합니다. 로그 포워딩은 설정되지 않습니다.
