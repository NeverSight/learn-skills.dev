Richten Sie die Datadog‑Google‑Cloud‑Integration mit Terraform ein – erstellt ein Dienstkonto im Host‑Projekt, lässt den delegierten Prinzipal von Datadog dieses über roles/iam.serviceAccountTokenCreator impersonieren (keine Dienstkonto‑Schlüssel), aktiviert die erforderlichen APIs, gewährt die Monitoring‑Rollen für die ausgewählten Projekte und Ordner und registriert das Konto über datadog_integration_gcp_sts. Verwenden Sie dies, wenn der Nutzer GCP‑Ressourcen wie Compute Engine, Cloud SQL, GKE, Cloud Run oder Pub/Sub überwachen möchte, ein GCP‑Projekt, einen Ordner oder eine Organisation mit Datadog verbinden will oder darum bittet, die GCP‑Integration einzurichten oder zu reparieren. Leitet keine Logs weiter.
