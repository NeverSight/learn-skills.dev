إعداد تكامل Datadog مع Google Cloud باستخدام Terraform - ينشئ حساب خدمة في مشروع المضيف، ويسمح للمسؤول المفوض من Datadog بتقليده عبر الدور roles/iam.serviceAccountTokenCreator (بدون مفاتيح حساب خدمة)، ويفعل واجهات برمجة التطبيقات المطلوبة، ويمنح أدوار المراقبة عبر المشاريع والمجلدات المختارة، ويسجل الحساب من خلال datadog_integration_gcp_sts. يُستخدم عندما يرغب المستخدم في مراقبة موارد GCP مثل Compute Engine وCloud SQL وGKE وCloud Run أو Pub/Sub، أو يريد ربط مشروع أو مجلد أو مؤسسة GCP بـ Datadog، أو يطلب إعداد أو إصلاح تكامل GCP. لا يُنشئ توجيه السجلات.
