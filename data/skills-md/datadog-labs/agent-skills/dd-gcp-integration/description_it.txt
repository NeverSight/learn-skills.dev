Configura l'integrazione Datadog Google Cloud con Terraform - crea un account di servizio nel progetto host, consente al delegato di Datadog di impersonarlo tramite roles/iam.serviceAccountTokenCreator (nessuna chiave di account di servizio), abilita le API richieste, assegna i ruoli di monitoraggio nei progetti e cartelle scelti e registra l'account tramite datadog_integration_gcp_sts. Da utilizzare quando l'utente vuole monitorare risorse GCP come Compute Engine, Cloud SQL, GKE, Cloud Run o Pub/Sub, desidera collegare un progetto, una cartella o un'organizzazione GCP a Datadog, o chiede di configurare o riparare l'integrazione GCP. Non configura l'inoltro dei log.
