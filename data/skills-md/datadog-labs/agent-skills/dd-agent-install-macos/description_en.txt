Install the Datadog Agent on a macOS machine with the macOS installer, with infrastructure metrics, logs, and APM trace intake on by default, plus optional live processes, APM instrumentation, custom tags, and service management. Use when the user wants to install the Datadog Agent on their Mac, set up Datadog on macOS, or monitor a macOS developer or CI machine with Datadog. Does not install the Agent on Linux, Windows, Docker, or Kubernetes (use dd-agent-install-linux, dd-agent-install-windows, dd-agent-install-docker, or dd-agent-install-kubernetes) and does not target managed cloud fleets. Requires a Datadog account with a valid API key and application key; run `dd-account-setup` first if they are missing.
