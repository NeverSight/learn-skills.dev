Install the Datadog Agent on Windows Server hosts - a single machine or a fleet - with support for cloud rollouts (AWS Systems Manager, GCP VM Manager, Azure Run Command), MSI properties, FIPS, custom tags, and advanced configuration, with infrastructure metrics, logs, and APM trace intake on by default. Use when the user wants to install the Datadog Agent on a Windows server, deploy Datadog to their Windows VMs, or set up the Datadog Agent on Windows Server 2022 or another Windows Server version. Does not install the Agent on Linux, macOS, Docker, or Kubernetes (use dd-agent-install-linux, dd-agent-install-macos, dd-agent-install-docker, or dd-agent-install-kubernetes) and does not connect a cloud provider integration. Requires a Datadog account with a valid API key and application key; if they are missing, run `dd-account-setup` first on commercial sites, or supply them directly on government sites.
