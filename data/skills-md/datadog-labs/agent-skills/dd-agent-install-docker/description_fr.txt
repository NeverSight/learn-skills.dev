Installez l'Agent Datadog sur un hôte Docker – Docker autonome (Linux ou Windows) ou Docker Compose – avec des métriques d'infrastructure, les journaux de conteneurs, la collecte de traces APM et DogStatsD activés par défaut, ainsi que des processus en direct, des tags, le nom d'hôte, le proxy et le filtrage des conteneurs en option, en conservant la clé API dans un fichier d'environnement restreint plutôt que sur la ligne de commande. À utiliser lorsque l'utilisateur possède des conteneurs Docker sur un serveur unique, souhaite installer Datadog sur son hôte Docker ou veut configurer Datadog avec Docker Compose. N'installe pas l'Agent sur Kubernetes ou directement sur un hôte Linux, macOS ou Windows (utilisez dd-agent-install-kubernetes, dd-agent-install-linux, dd-agent-install-macos ou dd-agent-install-windows). Nécessite un compte Datadog avec une clé API et une clé d'application valides ; exécutez `dd-account-setup` d'abord si elles manquent.
