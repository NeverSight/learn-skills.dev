Installieren Sie den Datadog‑Agent auf einem Docker‑Host – eigenständiges Docker (Linux oder Windows) oder Docker Compose – mit Infrastruktur‑Metriken, Container‑Logs, APM‑Trace‑Aufnahme und standardmäßig aktiviertem DogStatsD, plus optionalen Live‑Prozessen, Tags, Host‑Name, Proxy und Container‑Filterung, wobei der API‑Schlüssel in einer eingeschränkten env‑Datei und nicht in der Befehlszeile gespeichert wird. Verwenden Sie dies, wenn der Benutzer Docker‑Container auf einem einzigen Server hat, Datadog auf seinem Docker‑Host installieren möchte oder Datadog mit Docker Compose einrichten will. Installiert den Agent nicht auf Kubernetes oder direkt auf einem Linux‑, macOS‑ oder Windows‑Host (verwenden Sie dd-agent-install-kubernetes, dd-agent-install-linux, dd-agent-install-macos oder dd-agent-install-windows). Benötigt ein Datadog‑Konto mit einem gültigen API‑Schlüssel und Anwendungsschlüssel; führen Sie zuerst `dd-account-setup` aus, falls diese fehlen.
