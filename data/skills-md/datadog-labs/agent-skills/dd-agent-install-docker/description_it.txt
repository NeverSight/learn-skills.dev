Installa l'Agent Datadog su un host Docker – Docker autonomo (Linux o Windows) o Docker Compose – con metriche dell'infrastruttura, log dei container, acquisizione di tracce APM e DogStatsD attivato di default, più opzionalmente processi live, tag, nome host, proxy e filtraggio dei container, mantenendo la chiave API in un file .env ristretto anziché sulla riga di comando. Da utilizzare quando l'utente ha container Docker su un singolo server, desidera installare Datadog sul proprio host Docker o vuole configurare Datadog con Docker Compose. Non installa l'Agent su Kubernetes o direttamente su un host Linux, macOS o Windows (usa dd-agent-install-kubernetes, dd-agent-install-linux, dd-agent-install-macos o dd-agent-install-windows). Richiede un account Datadog con una chiave API e una chiave applicazione valide; esegui prima `dd-account-setup` se mancano.
