在 Docker 主機上安裝 Datadog Agent —— 獨立 Docker（Linux 或 Windows）或 Docker Compose —— 預設啟用基礎架構指標、容器日誌、APM 追蹤接收以及 DogStatsD，另可選擇啟用即時進程、標籤、主機名稱、代理伺服器與容器過濾，且將 API 金鑰存放於受限制的環境檔案中，而非於指令列上。適用於使用者在單一伺服器上擁有 Docker 容器、想要在 Docker 主機上安裝 Datadog，或想要使用 Docker Compose 設定 Datadog 的情況。此腳本不會在 Kubernetes 或直接於 Linux、macOS 或 Windows 主機上安裝 Agent（請使用 dd‑agent‑install‑kubernetes、dd‑agent‑install‑linux、dd‑agent‑install‑macos 或 dd‑agent‑install‑windows）。需要具備有效 API 金鑰與應用程式金鑰的 Datadog 帳號；若缺少金鑰，請先執行 `dd-account-setup`。
