Установите агент Datadog на хост Docker — самостоятельный Docker (Linux или Windows) или Docker Compose — с метриками инфраструктуры, журналами контейнеров, приёмом трассировок APM и включённым по умолчанию DogStatsD, а также с дополнительными опциями: живые процессы, теги, имя хоста, прокси и фильтрация контейнеров, при этом ключ API хранится в ограниченном файле переменных окружения, а не в командной строке. Используйте, когда у пользователя есть контейнеры Docker на одном сервере, он хочет установить Datadog на свой Docker‑хост или настроить Datadog с помощью Docker Compose. Не устанавливает агент на Kubernetes и не устанавливается напрямую на хост Linux, macOS или Windows (используйте dd-agent-install-kubernetes, dd-agent-install-linux, dd-agent-install-macos или dd-agent-install-windows). Требуется аккаунт Datadog с действительным ключом API и ключом приложения; сначала выполните `dd-account-setup`, если они отсутствуют.
