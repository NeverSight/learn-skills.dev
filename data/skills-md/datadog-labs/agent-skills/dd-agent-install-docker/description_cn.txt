在 Docker 主机上安装 Datadog Agent —— 支持独立 Docker（Linux 或 Windows）或 Docker Compose —— 默认启用基础设施指标、容器日志、APM 跟踪采集和 DogStatsD，并可选启用实时进程、标签、主机名、代理和容器过滤，将 API 密钥保存在受限的环境文件中，而不是在命令行上。适用于用户在单台服务器上拥有 Docker 容器、希望在其 Docker 主机上安装 Datadog，或希望使用 Docker Compose 设置 Datadog 的情形。不在 Kubernetes 或直接在 Linux、macOS 或 Windows 主机上安装 Agent（请使用 dd-agent-install-kubernetes、dd-agent-install-linux、dd-agent-install-macos 或 dd-agent-install-windows）。需要拥有有效 API 密钥和应用密钥的 Datadog 账户；如果缺少，请首先运行 `dd-account-setup`。
