Instala el Agente de Datadog en un host Docker - Docker independiente (Linux o Windows) o Docker Compose - con métricas de infraestructura, registros de contenedores, ingestión de trazas APM y DogStatsD activado por defecto, más procesos en vivo opcionales, etiquetas, nombre de host, proxy y filtrado de contenedores, manteniendo la clave API en un archivo de entorno restringido en lugar de en la línea de comandos. Úsalo cuando el usuario tenga contenedores Docker en un solo servidor, quiera instalar Datadog en su host Docker o quiera configurar Datadog con Docker Compose. No instala el Agente en Kubernetes ni directamente en un host Linux, macOS o Windows (usa dd-agent-install-kubernetes, dd-agent-install-linux, dd-agent-install-macos o dd-agent-install-windows). Requiere una cuenta de Datadog con una clave API y una clave de aplicación válidas; ejecuta `dd-account-setup` primero si faltan.
