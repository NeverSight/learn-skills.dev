ثبت وكيل Datadog على مضيف Docker - Docker مستقل (Linux أو Windows) أو Docker Compose - مع مقاييس البنية التحتية، سجلات الحاويات، استلام تتبع APM، وDogStatsD مفعَّل افتراضيًا، بالإضافة إلى عمليات حية اختيارية، وسوم، اسم المضيف، بروكسي، وتصفية الحاويات، مع حفظ مفتاح API في ملف بيئة مقيد بدلاً من سطر الأوامر. يُستخدم عندما يكون لدى المستخدم حاويات Docker على خادم واحد، ويرغب في تثبيت Datadog على مضيف Docker الخاص به، أو يريد إعداد Datadog باستخدام Docker Compose. لا يقوم بتثبيت الوكيل على Kubernetes أو مباشرة على مضيف Linux أو macOS أو Windows (استخدم dd-agent-install-kubernetes، dd-agent-install-linux، dd-agent-install-macos، أو dd-agent-install-windows). يتطلب حساب Datadog مع مفتاح API صالح ومفتاح تطبيق؛ شغّل `dd-account-setup` أولاً إذا كانا مفقودين.
