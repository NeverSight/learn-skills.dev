Install the Datadog Agent on a Docker host - standalone Docker (Linux or Windows) or Docker Compose - with infrastructure metrics, container logs, APM trace intake, and DogStatsD on by default, plus optional live processes, tags, hostname, proxy, and container filtering, keeping the API key in a restricted env file rather than on the command line. Use when the user has Docker containers on a single server, wants to install Datadog on their Docker host, or wants to set up Datadog with Docker Compose. Does not install the Agent on Kubernetes or directly on a Linux, macOS, or Windows host (use dd-agent-install-kubernetes, dd-agent-install-linux, dd-agent-install-macos, or dd-agent-install-windows). Requires a Datadog account with a valid API key and application key; run `dd-account-setup` first if they are missing.
