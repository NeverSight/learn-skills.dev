단일 Docker 호스트(리눅스 또는 윈도우) 또는 Docker Compose에 Datadog 에이전트를 설치합니다. 기본적으로 인프라 메트릭, 컨테이너 로그, APM 트레이스 수집 및 DogStatsD가 활성화되며, 옵션으로 실시간 프로세스, 태그, 호스트명, 프록시 및 컨테이너 필터링을 추가할 수 있습니다. API 키는 명령줄이 아닌 제한된 환경 파일에 저장합니다. 사용자가 단일 서버에 Docker 컨테이너가 있거나 Docker 호스트에 Datadog을 설치하거나 Docker Compose로 Datadog을 설정하려는 경우에 사용합니다. Kubernetes나 리눅스, macOS, 윈도우 호스트에 직접 에이전트를 설치하지 않으며(대신 dd-agent-install-kubernetes, dd-agent-install-linux, dd-agent-install-macos 또는 dd-agent-install-windows를 사용하십시오). 유효한 API 키와 애플리케이션 키가 포함된 Datadog 계정이 필요합니다; 키가 없으면 먼저 `dd-account-setup`을 실행하십시오.
