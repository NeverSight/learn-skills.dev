Datadog エージェントを Docker ホスト（スタンドアロン Docker（Linux または Windows）または Docker Compose）にインストールします。インフラメトリクス、コンテナログ、APM トレース受信、DogStatsD をデフォルトで有効にし、オプションでライブプロセス、タグ、ホスト名、プロキシ、コンテナフィルタリングを設定できます。API キーはコマンドラインではなく制限された env ファイルに保持します。単一サーバー上に Docker コンテナがあり、Docker ホストに Datadog をインストールしたい、または Docker Compose で Datadog を設定したい場合に使用します。Kubernetes や Linux、macOS、Windows ホストへ直接エージェントをインストールするものではありません（その場合は dd-agent-install-kubernetes、dd-agent-install-linux、dd-agent-install-macos、dd-agent-install-windows を使用）。有効な API キーとアプリケーションキーを持つ Datadog アカウントが必要です。キーが不足している場合はまず `dd-account-setup` を実行してください。
