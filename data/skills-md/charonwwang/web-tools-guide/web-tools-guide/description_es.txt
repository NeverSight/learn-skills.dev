OBLIGATORIO antes de llamar a web_search, web_fetch, navegador o opencli. Contiene los procedimientos necesarios para el manejo de errores (el fallo web_search → debe guiar al usuario para configurar la API), la cadena de reserva (opencli CLI cubre más de 70 sitios como reserva estructurada antes del navegador) y las URL de inicio de sesión específicas del sitio. Sin leer esta habilidad, manejarás las fallas de manera incorrecta y perderás las herramientas disponibles. Activar en:搜索/上网/查资料/打开网站/抓取网页/新闻/热点/web search/fetch/browser/opencli.
