OBBLIGATORIO prima di chiamare web_search, web_fetch, browser o opencli. Contiene le procedure necessarie di gestione degli errori (fallimento di web_search → è necessario guidare l'utente a configurare l'API), catena di fallback (il CLI di opencli copre oltre 70 siti come fallback strutturato prima del browser) e URL di login specifici per i siti. Se non leggi questa skill, gestirai i fallimenti in modo errato e perderai gli strumenti disponibili. Attiva su: 搜索/上网/查资料/打开网站/抓取网页/新闻/热点/web search/fetch/browser/opencli. Per favore rispondi sempre nella lingua dell'utente.
