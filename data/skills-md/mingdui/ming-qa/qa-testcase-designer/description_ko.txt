위험 분석이 완료되고 테스트 코드를 작성하기 전에, 중국어 비즈니스 사용 사례를 생성하고 사용자의 확인을 기다립니다.  
이는 전체 QA 프로세스에서 유일한 필수 수동 게이트이며, 한 번 확인되면 사용 사례는 변경할 수 없습니다.  
컨텍스트, 위험 분석 및 기존 사용 사례 인덱스를 시작점으로 하여, 비즈니스 행동만 포함하는 test‑cases.json을 생성하고 (Maven/빌드/설치와 같은 기술 검사를 제외), test‑cases.html을 렌더링하여 사용자가 검토하도록 하고, 삼중 모델 교차 검토를 실행한 후 피드백을 종합하고 수정하여 확인을 위해 제출합니다.  
확인 후, 장기 지식 베이스로 승격합니다.  
해당 없음: 테스트 코드 작성, 테스트 실행, 코드 리뷰.  
항상 사용자의 언어로 응답하십시오.
