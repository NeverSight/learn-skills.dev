The independent review stage is the penultimate step in the QA process. After the qa-test-runner finishes execution, the code itself is examined from an independent perspective—checking architecture, security, concurrency correctness, data consistency, regression risk, and test coverage gaps—without being influenced by the executor's conclusions. This produces code-review.json (containing severity‑graded findings and readiness constraints), which together with the assert-code-review gate forms the code review evidence, handed over to the qa-report-generator to be incorporated into the final report. P0/P1 security issues, financial logic defects, permission vulnerabilities, and data inconsistency risks are marked as blocking. Not applicable: generating test cases, executing tests, modifying product code (unless explicitly requested by the user), report generation.
