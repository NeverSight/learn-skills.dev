Шаг независимого обзора, который является предпоследним шагом в процессе QA. После того как qa‑test‑runner завершит выполнение, просмотрите код самостоятельно, с независимой точки зрения — проверяя архитектуру, безопасность, корректность параллелизма, согласованность данных, риск регрессии и пробелы в покрытии тестами — без влияния выводов исполнителя. Сформируйте файл code‑review.json (содержащий находки с оценкой тяжести и ограничения готовности), и вместе с воротом assert‑code‑review они образуют доказательство обзора кода, которое передаётся qa‑report‑generator для включения в итоговый отчет. Проблемы безопасности уровня P0/P1, дефекты финансовой логики, уязвимости разрешений и риски несогласованности данных помечаются как блокирующие. Не относится: генерация тестовых случаев, выполнение тестов, изменение кода продукта (если только пользователь явно не запросит этого) и генерация отчётов.
