Этап независимого обзора — предпоследний шаг в процессе обеспечения качества (QA). После того как qa‑test‑runner завершит выполнение, сам код проверяется с независимой точки зрения — проверяются архитектура, безопасность, корректность параллелизма, согласованность данных, риск регрессии и пробелы в покрытии тестами — без влияния выводов исполнителя. В результате создаётся файл code‑review.json (содержащий находки, оценённые по степени тяжести, и ограничения готовности), который вместе с gate assert‑code‑review формирует доказательство обзора кода и передаётся qa‑report‑generator для включения в итоговый отчёт. Проблемы безопасности уровня P0/P1, дефекты финансовой логики, уязвимости прав доступа и риски несогласованности данных помечаются как блокирующие. Не относится: генерация тестовых случаев, выполнение тестов, изменение кода продукта (если явно не запрошено пользователем), генерация отчётов.
