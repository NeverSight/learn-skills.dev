독립적인 검토 단계는 QA 프로세스에서 마지막에서 두 번째 단계입니다. qa-test-runner가 실행을 마친 후, 코드를 독립적인 관점에서 검토합니다—아키텍처, 보안, 동시성 정확성, 데이터 일관성, 회귀 위험, 테스트 커버리지 격차를 검사하며—실행자의 결론에 영향을 받지 않습니다. 이를 통해 code-review.json이 생성되며(심각도에 따라 등급이 매겨진 발견 사항과 준비 제약 조건을 포함), 이는 assert-code-review 게이트와 함께 코드 검토 증거를 형성하고, qa-report-generator에 전달되어 최종 보고서에 포함됩니다. P0/P1 보안 문제, 재무 로직 결함, 권한 취약점, 데이터 불일치 위험은 차단으로 표시됩니다. 적용되지 않음: 테스트 케이스 생성, 테스트 실행, 제품 코드 수정(사용자가 명시적으로 요청하지 않는 한), 보고서 생성.
