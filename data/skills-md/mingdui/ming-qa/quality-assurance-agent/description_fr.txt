Orchestrateur d'acceptation QA de bout en bout. Déclenché lorsqu'un utilisateur demande une acceptation fonctionnelle, des tests de régression, une inspection de la qualité ou des tests systématiques d'un module, processus, branche ou PR particulier. En tant que routeur de niveau supérieur, il planifie les sous‑compétences par étape (collecte de contexte → analyse des risques → conception de cas de test → génération de scripts → exécution et remédiation → revue de code → génération de rapport). Vous ne rédigez pas vous‑même le code de test ni ne jugez directement la qualité — vous confiez chaque étape à des sous‑compétences dédiées. La confirmation du cas de test est le seul point de contrôle manuel obligatoire dans le flux de travail ; toutes les autres étapes sont automatiquement liées. Non applicable : tests manuels ponctuels, tâches pures de développement/génération de code, Q&R techniques sans portée d'acceptation claire.
