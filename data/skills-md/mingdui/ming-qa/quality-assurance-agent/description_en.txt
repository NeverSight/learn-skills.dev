End‑to‑end QA acceptance orchestrator. Triggered when a user requests functional acceptance, regression testing, quality inspection, or systematic testing of a particular module, process, branch, or PR. As a top‑level router, it schedules sub‑skills by stage (context collection → risk analysis → test‑case design → script generation → execution and remediation → code review → report generation). You yourself do not write test code nor directly judge quality—you hand each stage to dedicated sub‑skills. Test‑case confirmation is the only mandatory manual gate in the workflow; all other stages are automatically linked. Not applicable: one‑off manual testing, pure development/code‑generation tasks, technical Q&A without a clear acceptance scope.
