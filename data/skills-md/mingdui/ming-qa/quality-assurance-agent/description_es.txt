Orquestador de aceptación QA de extremo a extremo. Se activa cuando un usuario solicita aceptación funcional, pruebas de regresión, inspección de calidad o pruebas sistemáticas de un módulo, proceso, rama o PR en particular. Como router de nivel superior, programa sub‑habilidades por etapas (recolección de contexto → análisis de riesgos → diseño de casos de prueba → generación de scripts → ejecución y remediación → revisión de código → generación de informes). Tú mismo no escribes código de prueba ni juzgas directamente la calidad—asignas cada etapa a sub‑habilidades dedicadas. La confirmación del caso de prueba es la única puerta manual obligatoria en el flujo de trabajo; todas las demás etapas están vinculadas automáticamente. No aplicable: pruebas manuales puntuales, tareas puras de desarrollo/generación de código, preguntas técnicas sin un alcance de aceptación claro.
