Orchestratore di accettazione QA end‑to‑end. Attivato quando un utente richiede accettazione funzionale, test di regressione, ispezione della qualità o test sistematico di un modulo, processo, branch o PR specifici. Come router di livello superiore, programma le sotto‑competenze per fase (raccolta del contesto → analisi del rischio → progettazione dei test case → generazione degli script → esecuzione e correzione → revisione del codice → generazione del report). Tu stesso non scrivi codice di test né giudichi direttamente la qualità—assegni ogni fase a sotto‑competenze dedicate. La conferma del test case è l’unica porta manuale obbligatoria nel flusso di lavoro; tutte le altre fasi sono collegate automaticamente. Non è applicabile: testing manuale occasionale, compiti puri di sviluppo/generazione di codice, Q&A tecnico senza un chiaro ambito di accettazione.
