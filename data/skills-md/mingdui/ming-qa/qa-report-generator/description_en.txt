Closing phase of the QA process – aggregates the three gate deliverables: execution (completion), review (code‑review), and readiness, renders the final HTML report, and provides the final readiness determination. Triggered after the qa‑test‑runner execution is completed and the qa‑code‑reviewer review is finished. It only reads existing gate deliverables, without re‑executing tests or re‑reviewing code. Not applicable: test execution, fixing failures, code review, test‑case design.
