Balayage mensuel d’hygiène de l’environnement pour ce Mac : disque, coffre, configuration Claude, gestionnaires de paquets. Identifie les projets obsolètes, les fichiers orphelins, la dérive du coffre, la détérioration des compétences et les résidus de paquets. Présente TOUJOURS les résultats pour révision AVANT de supprimer quoi que ce soit — jamais d’auto‑suppression. Utilisation : « run hygiene », « monthly cleanup », « environment audit », « disk cleanup », « clean up my machine », « vault hygiene », « first Monday ». DÉCLENCHEUR PROACTIF (CONDITIONNEL) : le premier lundi de chaque mois (planifié via les tâches programmées MCP). Aussi lorsque le propriétaire indique un manque d’espace disque, remarque une dérive du coffre ou après la fin d’un projet majeur.
