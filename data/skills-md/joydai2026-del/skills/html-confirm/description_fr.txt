Produit une page HTML ouvrable lorsque le propriétaire doit REGARDER quelque chose pour décider ou réagit à un rapport. Utilisez HTML pour les images, les conceptions, les storyboards, les couvertures, les rendus, l'approbation d'un livrable ou la réaction à un rapport ou à un audit. Utilisez le chat simple pour quelques choix de texte, des questions de portée, des portes oui/non, « dois-je continuer », « quelle boîte aux lettres », « A ou B ». À utiliser lorsque : "confirmer", "lequel", "approuver", "en choisir un", "les examiner", "dois-je continuer", "créer une page de confirmation".
