Produit une page HTML ouvrable lorsque le propriétaire doit REGARDER quelque chose pour décider ou réagir à un rapport. Utilisez HTML pour les images, les designs, les story‑boards, les couvertures, les rendus, l’approbation d’un livrable ou la réaction à un rapport ou un audit. Utilisez le chat simple pour quelques choix de texte, des questions de cadrage, des portes oui/non, « dois‑je continuer », « quelle boîte aux lettres », « A ou B ». Utilisez‑le lorsque : « confirmer », « lequel », « approuver », « choisir un », « examiner ceux‑ci », « dois‑je continuer », « créer une page de confirmation ».

Veuillez toujours répondre dans la langue de l'utilisateur.
