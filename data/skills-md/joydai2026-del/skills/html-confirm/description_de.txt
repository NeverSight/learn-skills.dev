Erstellt eine öffenbare HTML-Seite, wenn der Eigentümer sich etwas ansehen muss, um eine Entscheidung zu treffen, oder auf einen Bericht reagiert. Verwenden Sie HTML für Bilder, Designs, Storyboards, Cover, Renderings, die Genehmigung einer Lieferung oder die Reaktion auf einen Bericht oder eine Prüfung. Verwenden Sie den einfachen Chat für ein paar Textauswahlen, Scoping-Fragen, Ja/Nein-Gates, „Soll ich fortfahren“, „Welches Postfach“, „A oder B“. Wird verwendet, wenn: „bestätigen“, „welches“, „genehmigen“, „eins auswählen“, „diese überprüfen“, „soll ich fortfahren“, „eine Bestätigungsseite erstellen“.
