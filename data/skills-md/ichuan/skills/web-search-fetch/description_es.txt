Búsqueda web y búsqueda de URL para agentes de IA. Úselo cuando el usuario solicite buscar en la web, encontrar URL, investigar un tema o leer/obtener/resumir una página web como Markdown limpio. El motor de búsqueda es configurable e invisible para la persona que llama; la búsqueda utiliza HTTP simple más un convertidor local de HTML a Markdown con cero dependencias.
