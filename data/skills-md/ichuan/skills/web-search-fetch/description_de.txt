Websuche und URL-Abruf für KI-Agenten. Wird verwendet, wenn der Benutzer bittet, im Web zu suchen, URLs zu finden, ein Thema zu recherchieren oder eine Webseite als sauberen Markdown zu lesen/abzurufen/zusammenzufassen. Das Such-Backend ist konfigurierbar und für den Aufrufer unsichtbar; das Abrufen verwendet einfaches HTTP sowie einen lokalen HTML-zu-Markdown-Konverter mit null Abhängigkeiten.
