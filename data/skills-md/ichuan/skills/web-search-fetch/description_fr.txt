Recherche sur le Web et récupération d'URL pour les agents IA. À utiliser lorsque l'utilisateur demande de rechercher sur le Web, de trouver des URL, de rechercher un sujet ou de lire/récupérer/résumer une page Web en tant que Markdown propre. Le moteur de recherche est configurable et invisible pour l'appelant ; la récupération utilise HTTP simple plus un convertisseur HTML/Markdown local sans aucune dépendance.
