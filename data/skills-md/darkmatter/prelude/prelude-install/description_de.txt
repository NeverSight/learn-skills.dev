Installieren und konfigurieren Sie Prelude (darkmatter/prelude) in einem beliebigen Repository — führen Sie den Setup-Assistenten aus, verdrahten Sie das Modul für Flockenteile in eine vorhandene oder neue Flocke, aktivieren Sie packages.prelude-shell in der Devshell und überprüfen Sie es mit echten Rauchprüfungen. Verwenden Sie diese Option, um eine Devshell-Benutzeroberfläche hinzuzufügen (MOTD, x command picker, docs viewer, themed prompt), den generierten prelude.nix Sidecar zu integrieren oder Aktivierungsfragen (nix develop, direnv, lorri).
