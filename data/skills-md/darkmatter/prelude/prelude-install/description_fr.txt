Installez et configurez Prelude (darkmatter/prelude) dans n'importe quel référentiel — exécutez l'assistant d'installation, connectez le module flake-parts dans un flake existant ou nouveau, activez packages.prelude-shell dans le devshell et vérifiez avec de vrais contrôles de fumée. Utiliser pour ajouter une interface utilisateur devshell (MOTD, sélecteur de commandes x, visionneuse de documents, invite à thème), intégrer le sidecar prelude.nix généré ou des questions d'activation (nix develop, direnv, lorri).
