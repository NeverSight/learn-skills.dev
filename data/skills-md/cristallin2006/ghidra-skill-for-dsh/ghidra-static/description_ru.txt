Выполнить статический глубокий анализ бинарных файлов, для которых уже установлено базовое понимание (статический анализ / обратная инженерия): декомпиляция, использование перекрестных ссылок для отслеживания потока данных, семантическая аннотация, патчинг бинарных файлов и экспорт результатов. Триггерами являются декомпиляция конкретной функции, извлечение логики алгоритма/флага, применение патчей, массовый экспорт псевдокода и решение основных задач CTF‑проблем обратной инженерии. Предполагается, что тип образца известен — неизвестные образцы сначала должны пройти пере‑триаж. Прежде чем предпринимать действия, необходимо загрузить полный текст этого навыка с помощью инструмента навыков и следовать его рабочему процессу; все наблюдения и выводы должны быть записаны с помощью ledger.py.
