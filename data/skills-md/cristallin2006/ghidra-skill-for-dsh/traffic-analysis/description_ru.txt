CTF‑анализ трафика и сетевая форензика (pcap / сетевая форензика): триаж pcap, скрытые каналы DNS/ICMP/TCP и восстановление туннелей (скрытый канал / туннелирование), восстановление захваченных пакетов USB HID клавиатуры/мыши, дешифрование WPA/TLS, извлечение файлов и учётных данных. Триггеры: трафик / pcap / захват / Wireshark / tshark / сетевая форензика / пакеты трафика / скрытый канал / туннель. Бинарный реверс‑инжиниринг не допускается — это относится к серии ghidra‑static; если извлечённые файлы требуют реверс‑инжиниринга, вернитесь к пере‑триажу. Прежде чем продолжать, вы должны сначала загрузить полный текст этого навыка с помощью инструмента skill и следовать его рабочему процессу; все наблюдения/выводы необходимо фиксировать с помощью ledger.py.
