تحليل حركة مرور CTF والطب الشرعي الشبكي (pcap / الطب الشرعي الشبكي): تقييم ملفات pcap، القنوات الخفية لبروتوكولات DNS/ICMP/TCP وإعادة بناء الأنفاق (قناة خفية / نفق)، إعادة بناء التقاط حزم لوحة مفاتيح/فأرة USB HID، فك تشفير WPA/TLS، استخراج الملفات والاعتمادات. المحفزات: حركة مرور / pcap / التقاط / Wireshark / tshark / الطب الشرعي الشبكي / حزم الحركة / قناة خفية / نفق. لا يُجرى هندسة عكسية للثنائيات— فهذا يندرج تحت سلسلة ghidra-static؛ إذا احتاجت الملفات المستخرجة إلى هندسة عكسية، عُد إلى إعادة التقييم. قبل المتابعة، يجب أولاً تحميل النص الكامل لهذه المهارة باستخدام أداة المهارة واتباع سير عملها؛ يجب تسجيل جميع الملاحظات/الاستنتاجات باستخدام ledger.py.
