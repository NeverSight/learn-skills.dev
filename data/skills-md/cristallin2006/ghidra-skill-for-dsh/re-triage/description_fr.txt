Première étape pour un binaire inconnu (triage de fichiers / identification d’échantillon) : déterminer le type de fichier (PE/ELF/Mach‑O/firmware/APK), le langage (C/C++/Go/Rust/.NET/Python), le packer (détection de packer), la surface de menace, et décider de l’approche suivante (analyse statique approfondie / dynamique / changement d’outils). Déclencheurs : nouvel échantillon, exe/elf/bin/firmware inconnu, « jeter un œil à ce fichier », suspicion de packer, triage d’échantillon malveillant (triage de malware). Ne faire que des jugements et des décisions de routage, pas d’analyse approfondie — utiliser ghidra‑static pour l’analyse approfondie. Avant de poursuivre, vous devez charger le texte complet de cette compétence avec l’outil skill et suivre son processus ; toutes les observations/conclusions doivent être enregistrées avec ledger.py.
