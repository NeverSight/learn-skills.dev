Flujo de trabajo del SDK de robot SpacemiT para los componentes de voz y audio: components/multimedia/audio, components/model_zoo/asr, components/model_zoo/vad, components/model_zoo/tts, components/model_zoo/voiceprint y components/multimedia/audio_process/doa. Úselo para compilaciones independientes de componentes, ordenamiento de dependencias en la compilación, medición del rendimiento de modelos o demostraciones, e integración de la API C++/Python a partir de API.md, encabezados y binarios construidos.
