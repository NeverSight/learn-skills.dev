Рабочий процесс компонентов речи и аудио в SpacemiT Robot SDK для components/multimedia/audio, components/model_zoo/asr, components/model_zoo/vad, components/model_zoo/tts, components/model_zoo/voiceprint и components/multimedia/audio_process/doa. Используется для независимой сборки компонентов, порядка построения зависимостей, измерения производительности моделей или демонстраций, а также интеграции C++/Python API из API.md, заголовочных файлов и собранных бинарных файлов. Пожалуйста, всегда отвечайте на языке пользователя.
