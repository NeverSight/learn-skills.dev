대상 머신에 SSH도 로컬 터미널도 없는 헤드리스 혹은 비대화형 세션에서 인터랙티브 CLI 로그인/OAuth 흐름(MCP 서버 인증 예: `claude mcp login <name>`, `claude auth login`, `gh auth login` 등)을 완전히 수행합니다. 로그인 명령이 “stdin isn’t a terminal” 오류가 발생하거나 브라우저 리디렉션을 기다리며 멈추거나 세션에 TTY가 없을 때, 그리고 사용자가 특정 머신에서 새로운 MCP 서버, 통합 또는 CLI 도구를 “연결”하거나 “인증”하라고 요청할 때마다, 특히 승인을 하는 사람이 CLI를 실행하고 있는 머신과 다른 기기(휴대폰, 노트북)인 경우에 사용합니다. 또한 OAuth가 헤드리스 에이전트 실행 내에서 완료되어야 할 때마다(예: 채팅 중계 혹은 cron 트리거 세션) 이 방법을 활용하십시오.
