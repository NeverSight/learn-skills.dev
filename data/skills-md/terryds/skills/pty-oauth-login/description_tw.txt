在無頭或非交互式會話中完成互動式 CLI 登入/OAuth 流程（例如 MCP 伺服器驗證，如 `claude mcp login <name>`、`claude auth login`、`gh auth login` 等），且目標機器上無 SSH 也無本地終端。每當登入指令因「stdin 不是終端」而失敗、卡在等待瀏覽器重新導向，或會話根本沒有 TTY 時，都使用此方法；以及每當使用者要求在特定機器上「連接」或「驗證」新的 MCP 伺服器、整合或 CLI 工具而不想透過 SSH 時，尤其當批准的人在與執行 CLI 的設備不同的裝置（手機、筆記本電腦）上時。任何 OAuth 必須在無頭代理執行環境中完成（例如聊天轉發或 cron 觸發的會話）時，也請使用此方法。

請始終以使用者的語言回覆。
