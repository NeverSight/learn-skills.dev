完成交互式 CLI 登录/OAuth 流程（如 MCP 服务器认证 `claude mcp login <name>`、`claude auth login`、`gh auth login` 等），在无头或非交互式会话中执行，且不使用 SSH，也不在目标机器上打开本地终端。仅在登录命令因 “stdin 不是终端”而失败、等待浏览器重定向卡住，或会话根本没有 TTY 时使用；以及在用户要求在特定机器上“连接”或“认证”新的 MCP 服务器、集成或 CLI 工具且不通过 SSH 时使用，尤其当批准的人员使用的设备（手机、笔记本）与运行 CLI 的机器不同。每当 OAuth 需要在无头代理运行中完成（例如聊天转发或定时任务触发的会话），也请使用此方法。
