Vollständige einen interaktiven CLI‑Login/OAuth‑Ablauf (MCP‑Server‑Authentifizierung wie `claude mcp login <name>`, `claude auth login`, `gh auth login` usw.) aus einer headless‑ oder nicht‑interaktiven Sitzung, ohne SSH und ohne lokales Terminal auf dem Zielrechner. Verwende dies immer, wenn ein Anmeldebefehl mit „stdin isn’t a terminal“ fehlschlägt, auf eine Browser‑Weiterleitung wartet oder die Sitzung einfach kein TTY hat — und immer, wenn der Benutzer darum bittet, einen neuen MCP‑Server, eine Integration oder ein CLI‑Tool auf einem bestimmten Rechner zu „verbinden“ oder zu „authentifizieren“, ohne sich per SSH einzuloggen, insbesondere wenn die genehmigende Person ein anderes Gerät (Telefon, Laptop) als das mit dem CLI verwendete. Greife ebenfalls darauf zurück, sobald OAuth in einem headless‑Agent‑Durchlauf abgeschlossen werden muss (z. B. in einer chat‑vermittelten oder cron‑ausgelösten Sitzung).
