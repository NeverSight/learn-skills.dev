In quale unità CSS deve essere scritto un valore. rem per tutto ciò che una preferenza di dimensione del testo deve spostare: tipo, altezza di controllo, riempimento attorno al testo. px solo per ciò che non deve spostarsi: linee sottili, bordi, spostamenti delle ombre. Unità relative per le larghezze del layout. Da utilizzare quando si definiscono token di spaziatura e dimensionamento, si sceglie tra px e rem, si impostano le altezze di controllo, si scrivono query multimediali o si corregge un layout che si interrompe quando l'utente ingrandisce il testo.
