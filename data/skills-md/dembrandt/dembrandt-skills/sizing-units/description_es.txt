En qué unidad CSS se debe escribir un valor. rem para cualquier cosa que deba moverse una preferencia de tamaño de texto: tipo, control de alturas, relleno alrededor del texto. px solo para lo que no debe moverse: líneas finas, bordes, desplazamientos de sombras. Unidades relativas para anchos de diseño. Úselo al definir tokens de espaciado y tamaño, elegir entre px y rem, establecer alturas de control, escribir consultas de medios o corregir un diseño que se rompe cuando el usuario amplía el texto.
