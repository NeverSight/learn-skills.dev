Dans quelle unité CSS une valeur doit être écrite. rem pour tout ce qu'une préférence de taille de texte doit déplacer : type, hauteurs de contrôle, remplissage autour du texte. px uniquement pour ce qui ne doit pas bouger : lignes fines, bordures, décalages d'ombres. Unités relatives pour les largeurs de mise en page. À utiliser pour définir l'espacement et le dimensionnement des jetons, choisir entre px et rem, définir les hauteurs de contrôle, écrire des requêtes multimédias ou corriger une mise en page qui se brise lorsque l'utilisateur agrandit le texte.
