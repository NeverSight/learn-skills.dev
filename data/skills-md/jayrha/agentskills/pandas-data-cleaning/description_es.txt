Limpia conjuntos de datos tabulares desordenados en pandas de extremo a extremo — corrigiendo tipos de datos, analizando fechas y números, estandarizando texto, manejando valores faltantes, eliminando duplicados, detectando y tratando outliers, y transformando datos anchos/largos en formato tidy. Utiliza esta habilidad cuando el usuario solicite “limpiar este CSV/Excel/dataframe”, “corregir tipos de datos”, “manejar valores faltantes / NaNs”, “eliminar duplicados”, “tratar outliers”, “estandarizar nombres de columnas o categorías”, “analizar fechas”, “melt/pivot/reshape”, o para crear un pipeline de limpieza reproducible antes del análisis o modelado.
