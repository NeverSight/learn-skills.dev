Génère des README de projet soignés et bien structurés avec des badges, une accroche d’une ligne, un guide de démarrage rapide, l’installation, des exemples d’utilisation, des tableaux de configuration, des directives de contribution et une section licence. Utilisez cette compétence lorsque l’utilisateur demande de « écrire un README », « générer un README », « créer README.md », « améliorer mon README », « ajouter des badges », « documenter mon projet », « faire une description du projet », ou qu’il souhaite des documents d’onboarding/page d’accueil pour une bibliothèque, une CLI, une application web, une API ou un dépôt. Veuillez toujours répondre dans la langue de l’utilisateur.
