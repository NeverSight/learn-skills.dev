يصمم مخططات قواعد بيانات علائقية مُعَدلّة مع مفاتيح أساسية/خارجية، قيود، فهارس، وإلغاء التطبيع المتعمد، منتجًا DDL متوافقًا مع محرك قاعدة البيانات ونموذج ER. استخدم هذه المهارة عندما يطلب المستخدم تصميم مخطط قاعدة بيانات، نمذجة الكيانات والعلاقات، تطبيع الجداول، إصلاح مشكلات التحديث/الإدراج/الحذف، اختيار أنواع البيانات والمفاتيح، إضافة قيود أو فهارس، كتابة CREATE TABLE DDL، أو مراجعة/إعادة هيكلة مخطط موجود لـ PostgreSQL أو MySQL أو SQLite أو SQL Server.
