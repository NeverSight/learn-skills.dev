Conçoit des schémas de bases de données relationnelles normalisés avec des clés primaires/étrangères, des contraintes, des index et une dénormalisation délibérée, en produisant du DDL adapté au moteur et un modèle ER. Utilisez cette compétence lorsque l'utilisateur demande de concevoir un schéma de base de données, de modéliser les entités et les relations, de normaliser les tables, de corriger les anomalies de mise à jour/insertion/suppression, de choisir les types de données et les clés, d'ajouter des contraintes ou des index, d'écrire le DDL CREATE TABLE, ou d'examiner/refactoriser un schéma existant pour PostgreSQL, MySQL, SQLite ou SQL Server. Veuillez toujours répondre dans la langue de l'utilisateur.
