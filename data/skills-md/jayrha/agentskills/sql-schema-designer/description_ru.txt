Разрабатывает нормализованные схемы реляционных баз данных с первичными/внешними ключами, ограничениями, индексами и преднамеренной денормализацией, создавая DDL, учитывающий особенности движка, и модель ER. Используйте этот навык, когда пользователь просит спроектировать схему базы данных, смоделировать сущности и их связи, нормализовать таблицы, исправить аномалии обновления/вставки/удаления, выбрать типы данных и ключи, добавить ограничения или индексы, написать CREATE TABLE DDL или просмотреть/рефакторить существующую схему для PostgreSQL, MySQL, SQLite или SQL Server.

Всегда отвечайте на языке пользователя.
