Progetta schemi di database relazionali normalizzati con chiavi primarie/esterne, vincoli, indici e denormalizzazione deliberata, producendo DDL specifici per il motore e un modello ER. Usa questa abilità quando l'utente chiede di progettare uno schema di database, modellare entità e relazioni, normalizzare tabelle, correggere anomalie di aggiornamento/inserimento/cancellazione, scegliere tipi di dato e chiavi, aggiungere vincoli o indici, scrivere DDL CREATE TABLE o revisionare/rifattorizzare uno schema esistente per PostgreSQL, MySQL, SQLite o SQL Server.

Rispondi sempre nella lingua dell'utente.
