Diagnostique et corrige les requêtes SQL lentes en utilisant la lecture des plans EXPLAIN/EXPLAIN ANALYZE, la conception d'index, la réécriture de requêtes, les statistiques et l'optimisation consciente du schéma sur PostgreSQL, MySQL/MariaDB, SQL Server, Oracle et SQLite. Utilisez cette compétence lorsqu'un utilisateur indique qu'une requête est lente, qu'elle dépasse le délai, qu'elle « prend une éternité », qu'il a besoin d'un index, qu'il demande « optimiser ce SQL », « pourquoi cette requête est lente », « lire ce plan EXPLAIN », « ajouter un index », « réduire le coût de la requête », « corriger un scan complet de table / scan séquentiel », « requête N+1 », « ajuster la base de données », ou qu'il colle un plan de requête et demande ce qui ne va pas. Veuillez toujours répondre dans la langue de l'utilisateur.
