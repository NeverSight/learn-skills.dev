تشخيص وإصلاح الاستعلامات البطيئة في SQL باستخدام قراءة خطط EXPLAIN/EXPLAIN ANALYZE، وتصميم الفهارس، وإعادة كتابة الاستعلامات، والإحصائيات، وضبط القاعدة بناءً على المخطط عبر PostgreSQL وMySQL/MariaDB وSQL Server وOracle وSQLite. استخدم هذه المهارة عندما يقول المستخدم إن الاستعلام بطيء، أو يتوقف عن العمل، أو "يستغرق أبدًا"، أو يحتاج إلى فهرس، أو يطلب "تحسين هذا الـ SQL"، أو "لماذا هذا الاستعلام بطيء"، أو "قراءة خطة EXPLAIN هذه"، أو "إضافة فهرس"، أو "تقليل تكلفة الاستعلام"، أو "إصلاح مسح الجدول بالكامل / مسح تسلسلي"، أو "N+1 استعلام"، أو "ضبط قاعدة البيانات"، أو يضع خطة استعلام ويسأل ما الخطأ فيها.
