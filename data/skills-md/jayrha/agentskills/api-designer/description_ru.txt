Разрабатывает чистые, согласованные REST и GraphQL API, охватывающие моделирование ресурсов, структуру URL, версионирование, постраничную навигацию, фильтрацию, форматы ошибок (RFC 9457 Problem Details), идемпотентность, аутентификацию, ограничение скорости запросов и машинно‑читаемые контракты (OpenAPI 3.1 / GraphQL SDL). Используйте этот навык при создании нового API или конечной точки, оценке дизайна API, выборе между REST и GraphQL, определении стратегии версионирования или постраничной навигации, формировании ответов об ошибках, добавлении ключей идемпотентности, написании или критике схемы OpenAPI/GraphQL, а также при установлении руководящих принципов стиля API и соглашений о наименованиях.
