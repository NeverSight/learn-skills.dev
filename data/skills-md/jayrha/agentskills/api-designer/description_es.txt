Diseña APIs REST y GraphQL limpias y consistentes que cubran modelado de recursos, estructura de URL, versionado, paginación, filtrado, formatos de error (RFC 9457 Problem Details), idempotencia, autenticación, limitación de velocidad y contratos legibles por máquina (OpenAPI 3.1 / GraphQL SDL). Usa esta habilidad al diseñar una nueva API o endpoint, revisar un diseño de API, elegir entre REST y GraphQL, decidir la estrategia de versionado o paginación, definir respuestas de error, añadir claves de idempotencia, redactar o criticar un esquema OpenAPI/GraphQL, o establecer pautas de estilo y convenciones de nomenclatura para API.

Por favor, responde siempre en el idioma del usuario.
