Progetta API REST e GraphQL pulite e coerenti, coprendo la modellazione delle risorse, la struttura degli URL, il versionamento, la paginazione, il filtraggio, i formati di errore (RFC 9457 Problem Details), l’idempotenza, l’autenticazione, il rate limiting e i contratti leggibili dalla macchina (OpenAPI 3.1 / GraphQL SDL). Usa questa competenza quando progetti una nuova API o endpoint, rivedi un design API, scegli tra REST e GraphQL, decidi una strategia di versionamento o paginazione, definisci le risposte di errore, aggiungi chiavi di idempotenza, scrivi o critichi uno schema OpenAPI/GraphQL, o stabilisci linee guida di stile API e convenzioni di nomenclatura.
