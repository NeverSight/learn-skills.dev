يصمم واجهات برمجة تطبيقات (APIs) نظيفة ومتسقة من نوع REST وGraphQL تغطي نمذجة الموارد، هيكل URL، الإصدارات، الترصف، التصفية، صيغ الأخطاء (RFC 9457 تفاصيل المشكلة)، الإيديومنتية، المصادقة، تحديد معدل الاستخدام، والعقود القابلة للقراءة آليًا (OpenAPI 3.1 / GraphQL SDL). استخدم هذه المهارة عند تصميم واجهة برمجة تطبيقات أو نقطة نهاية جديدة، مراجعة تصميم API، اختيار بين REST وGraphQL، اتخاذ قرار بشأن استراتيجية الإصدارات أو الترصف، تعريف استجابات الأخطاء، إضافة مفاتيح الإيديومنتية، كتابة أو نقد مخطط OpenAPI/GraphQL، أو وضع إرشادات نمطية للـ API ومعايير التسمية.
