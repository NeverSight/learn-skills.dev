Entwirft saubere, konsistente REST- und GraphQL-APIs, die Ressourcenmodellierung, URL-Struktur, Versionierung, Pagination, Filterung, Fehlermeldungsformate (RFC 9457 Problem Details), Idempotenz, Authentifizierung, Rate Limiting und maschinenlesbare Verträge (OpenAPI 3.1 / GraphQL SDL) abdecken. Verwende diese Fähigkeit beim Entwerfen einer neuen API oder eines Endpunkts, beim Review eines API‑Designs, bei der Entscheidung zwischen REST und GraphQL, bei der Wahl einer Versionierungs‑ oder Paginierungsstrategie, beim Definieren von Fehlermeldungen, beim Hinzufügen von Idempotenzschlüsseln, beim Schreiben oder Kritisieren eines OpenAPI‑/GraphQL‑Schemas oder beim Festlegen von API‑Stilrichtlinien und Namenskonventionen.
