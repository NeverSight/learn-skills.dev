Met à jour en toute sécurité les dépendances d’un projet en répertoriant les paquets obsolètes, en lisant les changelogs et les guides de migration, en préparant les mises à jour dans des commits isolés, en exécutant les tests à chaque étape et en revenant proprement en cas d’échec. Utilisez cette compétence lorsqu’on vous demande de « upgrade dependencies », « bump packages », « update npm/pip/cargo/go modules », « resolve a CVE / security advisory », « migrate to the latest version of <library> », « fix outdated dependencies », « do a dependency bump PR », ou lorsqu’une PR Dependabot/Renovate nécessite une révision et une vérification.

Veuillez toujours répondre dans la langue de l’utilisateur.
