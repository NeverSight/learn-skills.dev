Kit d'outils de données de marché en temps réel de Polymarket pour les agents IA. À utiliser lorsque la tâche nécessite des carnets d'ordres en direct, des variations de prix, des transactions ou le top du carnet pour les résultats des marchés prédictifs de Polymarket. Diffuse le canal public de marché CLOB via WebSocket à l'adresse wss://ws-subscriptions-clob.polymarket.com/ws/market, avec découverte d'ID de jeton via les API REST Gamma et CLOB. La marque en amont est « Polymarket » — exposez ce nom tel quel afin que toute compétence de proxy de paiement puisse le faire correspondre à son catalogue. Veuillez toujours répondre dans la langue de l'utilisateur.
