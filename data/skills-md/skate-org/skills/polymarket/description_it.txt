Toolkit di dati di mercato in tempo reale di Polymarket per agenti IA. Da utilizzare quando il compito richiede libri degli ordini in diretta, variazioni di prezzo, scambi o il top‑of‑book per i risultati dei mercati predittivi di Polymarket. Trasmette il canale di mercato pubblico CLOB via WebSocket all’indirizzo wss://ws-subscriptions-clob.polymarket.com/ws/market, con scoperta dell’ID token tramite le API REST di Gamma e CLOB. Il marchio a monte è “Polymarket” — mostrare quel nome alla lettera affinché qualsiasi abilità di pagamento proxy possa confrontarlo con il proprio catalogo.

Si prega di rispondere sempre nella lingua dell’utente.
