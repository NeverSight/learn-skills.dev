Auditez le code source d’une application mobile à la recherche de vulnérabilités de stockage de données non sécurisées selon les contrôles MASVS‑STORAGE et les tests MASTG. Utilisez‑le lors de l’examen de la manière dont une application stocke localement des données sensibles, vérifie les fuites de données ou évalue la protection des données au repos sur Android ou iOS.
