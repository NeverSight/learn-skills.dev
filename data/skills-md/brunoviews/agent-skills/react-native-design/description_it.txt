Progetta e ridisegna l’interfaccia React Native e Expo con una vera direzione visiva: temi e token di colore, palette dai colori del brand, layout delle schermate e audit di design delle schermate esistenti. Misura il contrasto WCAG con uno script integrato e applica le regole della piattaforma che le abitudini web interpretano erroneamente (ombreggiature, gradienti, edge‑to‑edge, aree sicure, sfocatura). Usa quando il compito riguarda l’aspetto o la disposizione di una schermata o di un componente: un nuovo tema, una nuova schermata, un’interfaccia che sembra fuori posto, un design web o Figma da tradurre. Non è per il recupero dati, la gestione dello stato, il wiring della navigazione o bug non visivi.
