Diseña y vuelve a estilizar la UI de React Native y Expo con una dirección visual real: temas y tokens de color, paletas a partir de los colores de la marca, diseños de pantallas y auditorías de diseño de pantallas existentes. Mide el contraste WCAG con un script incluido y aplica las reglas de la plataforma que los hábitos web interpretan de forma incorrecta (sombras, gradientes, de borde a borde, áreas seguras, desenfoque). Úsalo cuando la tarea trate sobre cómo se ve o se dispone una pantalla o componente: un nuevo tema, una nueva pantalla, una UI que se siente fuera de lugar, un diseño web o de Figma para traducir. No es para la obtención de datos, gestión de estado, configuración de navegación o errores no visuales.

Por favor, siempre responde en el idioma del usuario.
