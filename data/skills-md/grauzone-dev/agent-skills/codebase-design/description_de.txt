Gemeinsames Vokabular zum Entwerfen tiefer Module. Verwenden Sie es, wenn der Benutzer die Benutzeroberfläche eines Moduls entwerfen oder verbessern, vertiefende Möglichkeiten finden, entscheiden möchte, wo eine Naht verläuft, Code testbarer oder KI-navigierbar machen möchte oder wenn eine andere Fertigkeit das tiefe Modulvokabular benötigt.
