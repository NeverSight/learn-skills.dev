مفردات مشتركة لتصميم الوحدات العميقة. استخدمها عندما يرغب المستخدم في تصميم أو تحسين واجهة الوحدة، أو العثور على فرص تعميق، أو تحديد موضع الفاصل، أو جعل الشيفرة أكثر قابلية للاختبار أو للتنقل عبر الذكاء الاصطناعي، أو عندما تحتاج مهارة أخرى إلى مفردات الوحدة العميقة.  

يرجى الرد دائمًا بلغة المستخدم.
