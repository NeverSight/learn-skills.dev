Vocabulaire partagé pour concevoir des modules profonds. Utilisez-le lorsqu’un utilisateur souhaite concevoir ou améliorer l’interface d’un module, identifier des opportunités d’approfondissement, décider où placer une couture, rendre le code plus testable ou navigable par l’IA, ou lorsqu’une autre compétence a besoin du vocabulaire des modules profonds.
