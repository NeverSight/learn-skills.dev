Configurez l'intégration de la compétence d'ingénierie d'un dépôt : suivi des tickets, étiquettes de triage, documentation du domaine et routage du modèle lorsqu'ils sont disponibles. Utilisez-le lors de l'installation de ces compétences dans un dépôt ou lorsqu'une autre compétence signale que la configuration des docs/agents est manquante.
