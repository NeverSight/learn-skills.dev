Planen Sie ein riesiges Stück Arbeit - mehr als eine Agentensitzung kann stattfinden - als eine gemeinsame Karte von Entscheidungstickets auf Ihrem Problem-Tracker und lösen Sie sie einzeln, bis der Weg zum Ziel frei ist. Wird verwendet, wenn eine Initiative zu groß ist, um sie in einer Sitzung zu planen, oder wenn ein Ticket auf einer vorhandenen Wayfinder-Karte bearbeitet wird.
