Comparez deux dossiers fonction par fonction avec jscpd --compare, dans la même langue ou d'une langue à l'autre, et expliquez le résultat. Utilisez lorsqu'on vous demande comment deux bases de code se rapportent, quelles fonctions une implémentation a et l'autre manque, jusqu'où un port est venu, si les versions iOS et Android d'une application correspondent, ou quelle fonction dans un dossier correspond à une fonction dans l'autre.
