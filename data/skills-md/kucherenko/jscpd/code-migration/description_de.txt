Verschieben Sie Code von einer Implementierung zu einer anderen Funktion nach Funktion, testen Sie zuerst und Code zweitens, und überprüfen Sie zwei Implementierungen einer App auf Parität, mit jscpd --compare als Fortschrittsmaßnahme und einer Abdeckungskarte, die jede Funktion an ihre Tests bindet. Wird verwendet, wenn eine Bibliothek oder App in eine andere Sprache oder ein anderes Framework portiert wird (Java zu Kotlin, JavaScript zu Rust, eine Python-Bibliothek zu TypeScript, eine iOS-App zu Android), wenn gefragt wird, was noch zu portieren ist, oder wenn die Android- und iOS-Versionen einer App verglichen werden.
