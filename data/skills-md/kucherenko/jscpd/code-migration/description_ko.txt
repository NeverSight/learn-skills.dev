함수별로 한 구현에서 다른 함수로 코드를 이동하고, 첫 번째 및 두 번째 코드를 테스트하고, 한 앱의 두 구현에서 패리티를 검사합니다. jscpd --compare를 진행 상태 측정값으로 사용하고 각 함수를 테스트에 바인딩하는 커버리지 맵을 사용합니다. 라이브러리 또는 앱을 다른 언어 또는 프레임워크 (Java에서 Kotlin으로, JavaScript에서 Rust로, Python 라이브러리에서 TypeScript로, iOS 앱에서 Android로) 로 포팅하거나, 포팅할 항목이 무엇인지 묻거나, 앱의 Android 및 iOS 버전을 비교할 때 사용합니다.
