Déplacez le code d'une implémentation à une autre fonction par fonction, testez d'abord et codez ensuite, et vérifiez la parité de deux implémentations d'une application, avec jscpd -comparer comme mesure de progression et une carte de couverture liant chaque fonction à ses tests. À utiliser lors du portage d'une bibliothèque ou d'une application vers un autre langage ou framework (Java vers Kotlin, JavaScript vers Rust, une bibliothèque Python vers TypeScript, une application iOS vers Android), lorsqu'on vous demande ce qui reste à porter, ou lorsque vous comparez les versions Android et iOS d'une application.
