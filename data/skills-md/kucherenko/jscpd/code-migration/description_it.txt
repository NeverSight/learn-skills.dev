Sposta il codice da un'implementazione all'altra funzione per funzione, test prima e codice dopo, e verifica la parità delle due implementazioni di un'app, usando jscpd --compare come misura di avanzamento e una mappa di copertura che associa ogni funzione ai suoi test. Usalo quando si porta una libreria o un'app in un altro linguaggio o framework (Java a Kotlin, JavaScript a Rust, una libreria Python a TypeScript, un'app iOS ad Android), quando ti chiedono cosa manca da portare, o quando confronti le versioni Android e iOS di un'app. 

Per favore rispondi sempre nella lingua dell'utente.
