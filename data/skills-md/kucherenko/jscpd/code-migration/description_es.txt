Mueva el código de una implementación a otra función por función, pruebe primero y codifique segundo, y verifique la paridad de dos implementaciones de una aplicación, con jscpd --compare como la medida de progreso y un mapa de cobertura que vincule cada función a sus pruebas. Úselo al portar una biblioteca o aplicación a otro lenguaje o marco (Java a Kotlin, JavaScript a Rust, una biblioteca de Python a TypeScript, una aplicación de iOS a Android), cuando se le pregunte qué queda por por portar o cuando compare las versiones de Android e iOS de una aplicación.
