التشخيص وضبط مشكلة أداء واحدة مرئية للمستخدم في ميزة هاتفية مكتوبة بـ Swift أو SwiftUI أو React Native أو Expo من خلال تتبع أول موعد نهائي فائت عبر الحركة، والإظهار، ونشر الحالة، والوسائط، والتخزين، والشبكة، والرصد، ثم تطبيق والتحقق من أصغر تغيير سببي. يُستخدم عندما يكون التفاعل أو الرسوم المتحركة أو التمرير أو انتقال لوحة المفاتيح أو أول رسم أو مسار التحميل متقطّعًا أو متوقفًا أو متأخرًا أو أقل سلاسةً من المتوقع ويكون الاختناق غير واضح. لا يُستخدم لتدقيقات الأداء الشاملة للتطبيق، أو لتوليد أفكار الحركة أو مراجعة الصنعة بدون عرض عرضي في وقت التشغيل، أو تحليل يعتمد على التسجيل فقط، أو تحسين خلفية فقط، أو تقوية الإصدار.
