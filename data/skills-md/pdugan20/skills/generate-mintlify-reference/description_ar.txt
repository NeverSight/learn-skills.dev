يقوم بإنشاء وثائق مرجعية للواجهة النصية CLI أو MCP أو API لموقع Mintlify مع فحص الانحراف من المصادر الموثوقة ويربط عمليات فحص التجديد. يُستخدم عند إضافة أو إصلاح صفحات مرجعية مدعومة بالمصدر على Mintlify؛ لا يُستخدم للدلائل المكتوبة يدوياً أو سلاسل وثائق الشيفرة (docstrings) أو توليد الشيفرة غير الوثائقية.
