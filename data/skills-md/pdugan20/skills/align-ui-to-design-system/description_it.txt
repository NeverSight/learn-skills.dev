Revisiona un componente UI completato o una superficie delimitata rispetto al design system evidenziato nel suo repository, classifica le deviazioni accidentali, le eccezioni intenzionali, le lacune del sistema e le incertezze, quindi applica solo le correzioni approvate. Usalo per la conformità o la normalizzazione UI post‑build. Non usarlo per l’ideazione UI, audit a livello di repository, traduzioni esatte del design o per la generalizzata solidificazione della produzione.
