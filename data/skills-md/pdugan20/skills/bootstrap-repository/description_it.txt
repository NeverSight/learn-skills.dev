Usa quando crei o inizializzi un nuovo repository software, o trasformi una cartella di progetto vuota o appena generata in un repository locale e pronto per GitHub, mantenuto. Si applica a Swift, Expo o React Native, Python, React o TypeScript e ad altri stack. Non utilizzare per audit o modernizzazione di un repository consolidato, per aggiungere un job CI, per implementare funzionalità di prodotto, per il deployment o per la pubblicazione.
