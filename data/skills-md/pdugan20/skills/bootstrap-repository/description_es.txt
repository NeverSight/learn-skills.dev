Úsalo al crear o inicializar un nuevo repositorio de software, o al convertir un directorio de proyecto vacío o recién generado en un repositorio local mantenido y listo para GitHub. Se aplica a Swift, Expo o React Native, Python, React o TypeScript, y a otras pilas tecnológicas. No lo uses para auditar o modernizar un repositorio establecido, añadir un trabajo de CI, implementar funcionalidades del producto, desplegar o publicar. Por favor, responde siempre en el idioma del usuario.
