À utiliser lorsqu’un utilisateur souhaite brainstormer ou comparer plusieurs directions d’interface utilisateur, d’interaction, de mise en page, visuelles ou d’animation exécutables dans une application web ou native existante avant d’en choisir une. Ne pas utiliser pour la mise en œuvre exacte d’un design sélectionné, la livraison en production, les audits ou les maquettes statiques ou générées demandées.

Veuillez toujours répondre dans la langue de l’utilisateur.
