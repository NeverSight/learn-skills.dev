Usa quando un utente vuole fare brainstorming o confrontare più direzioni UI, di interazione, layout, visuali o di motion eseguibili in un’app web o nativa esistente prima di sceglierne una. Non utilizzare per l’implementazione esatta di un design selezionato, la consegna in produzione, audit o mockup statici o generati su richiesta.

Per favore rispondi sempre nella lingua dell’utente.
