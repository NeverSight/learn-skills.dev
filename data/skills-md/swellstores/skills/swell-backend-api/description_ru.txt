Используйте эту возможность для операций Swell Backend API: запросы и агрегацию, записи, импорты, пакетные запросы и транзакции, заказы, платежи, возвраты и подписки, товары и инвентарь, аккаунты, купоны, акции и подарочные карты, файлы, события и веб‑хуки, ошибки и ограничения скорости запросов. Применяйте её каждый раз, когда пишется или отлаживается запрос к Backend API, включая CLI‑команды `swell api get|post|put|delete` и их параметры запросов. Действует внутри приложений Swell через функции и клиентские воркфлоу или Backend‑клиент Apps SDK, а также в независимых интеграциях с использованием swell‑node, явно настроенных клиентов Apps SDK или прямого HTTP. Комбинируйте с swell‑app для упаковки приложений, настройки среды выполнения, моделей, триггеров, прав доступа и развертывания; повторно используйте клиент, предоставляемый средой выполнения. Операции сессии покупателя относятся к swell‑frontend‑api. Авторинг тем Proxima / Liquid и другие платформы находятся за пределами сферы применения.
