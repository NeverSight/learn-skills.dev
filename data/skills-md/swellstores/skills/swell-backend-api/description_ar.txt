استخدم هذه المهارة لعمليات Swell Backend API: الاستعلام والتجميع، والكتابة، والاستيراد، والطلبات المجمعة والمعاملات، والطلبات، والمدفوعات، والاسترداد والاشتراكات، والمنتجات والمخزون، والحسابات، والقسائم، والعروض الترويجية وبطاقات الهدايا، والملفات، والأحداث والويب هوكس، والأخطاء وحدود المعدل. استخدمها كلما تم كتابة أو تصحيح طلب Backend API، بما في ذلك أوامر سطر الأوامر `swell api get|post|put|delete` ومعاملات الاستعلام الخاصة بها. تنطبق داخل تطبيقات Swell من خلال وظائف العملاء وسير العمل أو عميل Apps SDK Backend، وكذلك على التكاملات المستقلة باستخدام swell‑node، أو العملاء المُكوَّنين صراحةً في Apps SDK أو HTTP المباشر. اقترن مع swell‑app لتعبئة التطبيقات، وإعداد وقت التشغيل، والنماذج، والمحرضات، والأذونات والنشر؛ أعد استخدام العميل الذي يقدمه وقت التشغيل. عمليات جلسة المتسوق تندرج تحت swell‑frontend‑api. تحرير ثيم Proxima / Liquid وغيرها من المنصات خارج النطاق.
