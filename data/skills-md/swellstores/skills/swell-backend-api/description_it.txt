Usa questa competenza per le operazioni dell'API Backend di Swell: query e aggregazione, scritture, importazioni, richieste batch e transazioni, ordini, pagamenti, rimborsi e abbonamenti, prodotti e inventario, account, coupon, promozioni e buoni regalo, file, eventi e webhook, errori e limiti di velocità. Usala ogni volta che viene scritta o debuggata una richiesta API Backend, inclusi i comandi CLI `swell api get|post|put|delete` e i loro parametri di query. Si applica all'interno delle app Swell tramite client di funzioni e workflow o il client Backend dell'Apps SDK, e alle integrazioni indipendenti che utilizzano swell‑node, client Apps SDK configurati esplicitamente o HTTP diretto. Abbinala a swell‑app per il packaging dell'app, la configurazione del runtime, i modelli, i trigger, le autorizzazioni e il deployment; riutilizza il client fornito dal runtime. Le operazioni della sessione dello shopper appartengono a swell‑frontend‑api. La creazione di temi Proxima/Liquid e altre piattaforme sono fuori dal campo di applicazione.
