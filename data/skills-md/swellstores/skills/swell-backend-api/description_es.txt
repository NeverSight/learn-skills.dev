Utiliza esta habilidad para operaciones del API Backend de Swell: consultas y agregaciones, escrituras, importaciones, solicitudes por lotes y transacciones, pedidos, pagos, reembolsos y suscripciones, productos e inventario, cuentas, cupones, promociones y tarjetas de regalo, archivos, eventos y webhooks, errores y límites de velocidad. Úsala siempre que se escriba o depure una solicitud del API Backend, incluidos los comandos CLI `swell api get|post|put|delete` y sus parámetros de consulta. Se aplica dentro de las aplicaciones Swell mediante clientes de funciones y flujos de trabajo o el cliente Backend del SDK de Apps, y a integraciones independientes usando swell-node, clientes del SDK de Apps configurados explícitamente o HTTP directo. Combínala con swell-app para empaquetado de aplicaciones, configuración del tiempo de ejecución, modelos, disparadores, permisos y despliegue; reutiliza el cliente que suministra el tiempo de ejecución. Las operaciones de sesión de comprador pertenecen a swell-frontend-api. La autoría de temas Proxima / Liquid y otras plataformas están fuera del alcance.

Por favor, responde siempre en el idioma del usuario.
