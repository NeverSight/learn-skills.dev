Utilisez cette compétence pour les opérations de l'API Backend Swell : interrogation et agrégation, écritures, importations, requêtes batch et transactions, commandes, paiements, remboursements et abonnements, produits et inventaire, comptes, coupons, promotions et cartes‑cadeaux, fichiers, événements et webhooks, erreurs et limites de débit. Utilisez‑la chaque fois qu’une requête Backend API est écrite ou déboguée, y compris les commandes CLI `swell api get|post|put|delete` et leurs paramètres de requête. Elle s’applique à l’intérieur des applications Swell via les clients fonction et workflow ou le client Backend du SDK Apps, ainsi qu’aux intégrations indépendantes utilisant swell‑node, des clients SDK Apps configurés explicitement ou HTTP direct. Associez‑la à swell‑app pour l’empaquetage d’applications, la configuration du runtime, les modèles, les déclencheurs, les autorisations et le déploiement ; réutilisez le client fourni par le runtime. Les opérations de session d’acheteur relèvent de swell‑frontend‑api. L’auteur de thèmes Proxima / Liquid et les autres plateformes sont hors du champ d’application.

Veuillez toujours répondre dans la langue de l’utilisateur.
