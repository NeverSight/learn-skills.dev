在 Swell 後端 API 操作中使用此技能：查詢與聚合、寫入、匯入、批次請求與交易、訂單、付款、退款與訂閱、產品與庫存、帳號、優惠券、促銷與禮品卡、檔案、事件與 Webhook、錯誤與速率限制。每當撰寫或除錯後端 API 請求時皆使用，包括 `swell api get|post|put|delete` CLI 指令及其查詢參數。適用於透過函式與工作流程客戶端或 Apps SDK 後端客戶端於 Swell 應用內，以及使用 swell‑node、明確設定的 Apps SDK 客戶端或直接 HTTP 的獨立整合。與 swell‑app 搭配用於應用封裝、執行環境設定、模型、觸發器、權限與部署；重用執行環境提供的客戶端。shopper‑session 操作屬於 swell‑frontend‑api。Proxima / Liquid 主題撰寫及其他平台不在範圍內。
