이 기능을 Swell 백엔드 API 작업에 사용하세요: 쿼리 및 집계, 쓰기, 가져오기, 배치 요청 및 트랜잭션, 주문, 결제, 환불 및 구독, 제품 및 재고, 계정, 쿠폰, 프로모션 및 기프트 카드, 파일, 이벤트 및 웹훅, 오류 및 속도 제한. 백엔드 API 요청을 작성하거나 디버깅할 때마다, `swell api get|post|put|delete` CLI 명령과 해당 쿼리 매개변수를 포함하여 사용합니다. 기능 및 워크플로우 클라이언트 또는 Apps SDK Backend 클라이언트를 통해 Swell 앱 내부에서, 그리고 swell-node, 명시적으로 구성된 Apps SDK 클라이언트 또는 직접 HTTP를 사용하는 독립 통합에 적용됩니다. 앱 패키징, 런타임 설정, 모델, 트리거, 권한 및 배포를 위해 swell‑app과 함께 사용하고, 런타임이 제공하는 클라이언트를 재사용합니다. 쇼핑객 세션 작업은 swell‑frontend‑api에 속합니다. Proxima/Liquid 테마 저작 및 기타 플랫폼은 범위에서 제외됩니다.
