使用此技能搭配 swell CLI 來構建、修改、部署、發布或除錯 Swell 應用程式。涵蓋管理、整合及基於程式碼的店面應用程式：模型、儀表板視圖與操作、函式與工作流程、設定、通知、Webhook、結帳擴充功能、管理內容欄位的元件以及前端。前端可以使用受管的 Swell 託管服務，或自行於開發者的 Cloudflare 帳戶中自行託管。適用於 swell.json、應用程式資源目錄、app‑lifecycle CLI 指令、應用程式命名空間與模型觸發器，或在應用程式內的 @swell/apps-sdk 執行時設定。搭配 swell‑backend‑api 或 swell‑frontend‑api 以執行資料與商務操作。未使用 Swell 應用程式生命週期的獨立 API 使用者可直接使用相關的 API 技能。不包括 Proxima / Liquid 主題、swell 主題指令、其他商務平台以及一般的 Cloudflare 工作。
