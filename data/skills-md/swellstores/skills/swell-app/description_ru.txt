Используйте этот навык для создания, модификации, развертывания, публикации или отладки приложений Swell с помощью CLI swell. Охватывает админ, интеграционные и кодовые приложения витрины: модели, представления панели управления и действия, функции и рабочие процессы, настройки, уведомления, вебхуки, расширения checkout, компоненты для полей контента в админке и фронтендах. Фронтенды используют управляемый хостинг Swell или самостоятельный хостинг в аккаунте Cloudflare разработчика. Применяется для swell.json, каталогов ресурсов приложений, CLI‑команд жизненного цикла приложения, пространств имён приложений и триггеров моделей, либо настройки среды выполнения @swell/apps-sdk внутри приложения. Сочетается с swell-backend-api или swell-frontend-api для операций с данными и коммерцией. Независимые потребители API без жизненного цикла приложения Swell используют соответствующий API‑навык напрямую. Исключены темы Proxima / Liquid, команды тем swell, другие коммерческие платформы и общий функционал Cloudflare.
