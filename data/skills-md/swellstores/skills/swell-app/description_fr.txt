Utilisez cette compétence pour créer, modifier, déployer, publier ou déboguer des applications Swell avec le CLI swell. Elle couvre les applications d’administration, d’intégration et les vitrines basées sur du code : modèles, vues du tableau de bord et actions, fonctions et flux de travail, paramètres, notifications, webhooks, extensions de paiement, composants pour les champs de contenu d’administration et les frontaux. Les frontaux utilisent l’hébergement géré de Swell ou l’auto‑hébergement sur le compte Cloudflare du développeur. Appliquez swell.json, les répertoires de ressources d’application, les commandes CLI du cycle de vie des applications, les espaces de noms d’application et les déclencheurs de modèles, ou la configuration d’exécution @swell/apps-sdk à l’intérieur d’une application. Associez‑vous à swell-backend-api ou swell-frontend-api pour les opérations de données et de commerce. Les consommateurs d’API indépendants, sans le cycle de vie des applications Swell, utilisent directement la compétence API correspondante. Exclut les thèmes Proxima/Liquid, les commandes de thème swell, les autres plateformes de commerce et le travail générique sur Cloudflare.
