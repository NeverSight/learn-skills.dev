이 스킬을 사용하여 swell CLI로 Swell 앱을 구축, 수정, 배포, 게시 또는 디버깅할 수 있습니다. 관리자, 통합 및 코드 기반 스토어프런트 앱을 포괄합니다: 모델, 대시보드 뷰 및 액션, 함수와 워크플로우, 설정, 알림, 웹훅, 결제 확장, 관리자 콘텐츠 필드와 프런트엔드를 위한 컴포넌트. 프런트엔드는 관리형 Swell 호스팅 또는 개발자의 Cloudflare 계정에서 자체 호스팅을 사용합니다. swell.json, 앱 리소스 디렉터리, 앱 수명 주기 CLI 명령, 앱 네임스페이스 및 모델 트리거, 또는 앱 내부의 @swell/apps-sdk 런타임 설정을 적용합니다. 데이터 및 상거래 작업을 위해 swell-backend-api 또는 swell-frontend-api와 페어링합니다. Swell 앱 수명 주기가 없는 독립 API 사용자는 관련 API 스킬을 직접 사용합니다. Proxima / Liquid 테마, swell 테마 명령, 기타 상거래 플랫폼 및 일반 Cloudflare 작업은 제외됩니다.
