このスキルを使用して、swell CLI で Swell アプリを構築、変更、デプロイ、公開、デバッグします。管理、統合、およびコードベースのストアフロントアプリ（モデル、ダッシュボードビューとアクション、関数とワークフロー、設定、通知、ウェブフック、チェックアウト拡張、管理コンテンツフィールド用コンポーネント、フロントエンド）をカバーします。フロントエンドは、管理された Swell ホスティングまたは開発者の Cloudflare アカウントでのセルフホスティングを使用します。swell.json、アプリリソースディレクトリ、app‑lifecycle CLI コマンド、アプリ名前空間、モデルトリガー、またはアプリ内の @swell/apps-sdk ランタイム設定に適用します。データおよびコマース操作のために swell‑backend‑api または swell‑frontend‑api とペアリングします。Swell アプリライフサイクルを利用しない独立した API コンシューマは、該当する API スキルを直接使用します。Proxima / Liquid テーマ、swell テーマコマンド、他のコマースプラットフォーム、一般的な Cloudflare 作業は除外されます。
