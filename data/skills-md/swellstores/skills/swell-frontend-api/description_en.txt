Use this skill for Swell Frontend API operations: catalog and content, shopper sessions, carts, checkout, payments, customer accounts, subscriptions, localization and public app data. Applies inside Swell app frontends through the Apps SDK Storefront client and swell-js, and to independent storefronts using explicitly configured clients or direct API requests. Also covers storefront GraphQL and calls to app route functions. Pair with swell-app for app scaffolding, runtime setup, models, hosting and deployment; reuse its supplied clients and session helpers. Privileged store operations belong to swell-backend-api. Proxima / Liquid theme authoring and other platforms are outside scope.
