이 기술은 Swell 프런트엔드 API 작업에 사용합니다: 카탈로그 및 컨텐츠, 쇼퍼 세션, 장바구니, 체크아웃, 결제, 고객 계정, 구독, 로컬라이제이션 및 공개 앱 데이터. Swell 앱 프런트엔드 내부에서는 Apps SDK Storefront 클라이언트와 swell‑js를 통해, 명시적으로 구성된 클라이언트 또는 직접 API 요청을 사용하는 독립적인 스토어프런트에도 적용됩니다. 또한 스토어프런트 GraphQL 및 앱 라우트 함수 호출도 포함합니다. 앱 스캐폴딩, 런타임 설정, 모델, 호스팅 및 배포를 위해 swell‑app과 함께 사용하고, 제공된 클라이언트와 세션 도우미를 재사용하십시오. 특권 스토어 작업은 swell‑backend‑api에 해당합니다. Proxima / Liquid 테마 제작 및 기타 플랫폼은 범위에 포함되지 않습니다.

항상 사용자의 언어로 응답하십시오.
