استخدم هذه المهارة لعمليات واجهة برمجة تطبيقات Swell Frontend: الفهرس والمحتوى، جلسات المتسوق، السلال، إتمام الشراء، المدفوعات، حسابات العملاء، الاشتراكات، التعريب وبيانات التطبيقات العامة. تنطبق داخل واجهات تطبيق Swell من خلال عميل Apps SDK Storefront و swell‑js، وكذلك على الواجهات المستقلة باستخدام عملاء مكوّنين صراحة أو طلبات API مباشرة. كما تغطي GraphQL للواجهة واستدعاءات وظائف مسار التطبيق. اجمعها مع swell‑app لإنشاء بنية التطبيق، إعداد وقت التشغيل، النماذج، الاستضافة والنشر؛ أعد استخدام العملاء المزوّدين ومساعدي الجلسة. عمليات المتجر المميزة تندرج تحت swell‑backend‑api. كتابة موضوعات Proxima / Liquid وغيرها من المنصات خارج النطاق.
