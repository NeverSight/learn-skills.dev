Utiliza esta habilidad cuando necesites líneas de apertura personalizadas (rompehielos) para correos electrónicos fríos o mensajes de LinkedIn a gran escala: "escribe aperturas personalizadas para esta lista", "añade una primera línea personalizada para cada prospecto", "haz que mi alcance se sienta 1:1". Investiga a cada prospecto para encontrar un gancho real y relevante, escribe una apertura de una o dos frases que conecte con el problema del correo, califica cada línea y, cuando no exista información específica, recurre a una línea honesta basada en el rol. Nunca inventa detalles.
