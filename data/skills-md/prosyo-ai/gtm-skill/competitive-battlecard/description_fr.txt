Utilisez cette compétence lorsque les commerciaux ont besoin d’une fiche de bataille d’une page pour gagner contre un concurrent précis : « créer une fiche de bataille pour X », « comment battre X », « argumentaire concurrentiel », « que dire quand ils mentionnent X ». Elle produit une fiche prête à l’emploi pour le commercial, indiquant les scénarios de victoire et de défaite, un positionnement rapide, les principaux différenciateurs avec preuve, les questions pièges, les réponses aux objections, les notes de tarification et les pièges à éviter, rédigée pour être utilisée en direct lors d’un appel.

Veuillez toujours répondre dans la langue de l’utilisateur.
