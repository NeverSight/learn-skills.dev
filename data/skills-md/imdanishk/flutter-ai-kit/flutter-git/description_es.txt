Flujo de trabajo seguro de Git para trabajar con Flutter: nombres de ramas, mensajes de confirmación, descripciones de solicitudes de incorporación de cambios y lo que nunca debe confirmarse (almacenes de claves, claves API, archivos env). Úselo cuando se le pida que haga un «commit», cree una rama, haga un «push», abra o describa una solicitud de incorporación de cambios o limpie el historial.
