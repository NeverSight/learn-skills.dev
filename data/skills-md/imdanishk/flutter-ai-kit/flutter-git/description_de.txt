Sicherer Git-Workflow für die Arbeit mit Flutter – Branch-Namen, Commit-Nachrichten, Beschreibungen von Pull-Requests und das, was niemals committet werden darf (Keystores, API-Schlüssel, ENV-Dateien). Verwenden Sie diese Anleitung, wenn Sie aufgefordert werden, einen Commit durchzuführen, einen Branch zu erstellen, einen Push auszuführen, einen Pull Request zu öffnen oder zu beschreiben oder den Verlauf zu bereinigen.
