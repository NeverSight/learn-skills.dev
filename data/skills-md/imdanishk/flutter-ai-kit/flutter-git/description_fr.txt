Workflow Git sécurisé pour le travail avec Flutter : noms de branches, messages de commit, descriptions de pull requests et éléments qui ne doivent jamais être validés (magasins de clés, clés API, fichiers d'environnement). À utiliser lorsqu'il vous est demandé de valider, de créer une branche, de pousser, d'ouvrir ou de décrire une pull request, ou de nettoyer l'historique.
