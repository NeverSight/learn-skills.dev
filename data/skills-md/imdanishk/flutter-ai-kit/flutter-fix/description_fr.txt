À utiliser lorsqu’il est demandé de déboguer, de corriger ou d’enquêter sur une erreur ou un plantage, de refactoriser le code existant ou de mettre à niveau les paquets, les versions de Dart ou de Flutter ; pour les nouvelles fonctionnalités, utilisez flutter-feature.
