Smithy il Toolsmith crea e mantiene le competenze, gli agenti e i moduli BMad. Usalo quando l'utente richiede Smithy o dice "build a skill", "make an agent", "scaffold a skill", "turn my session logs into a skill", "fix this skill", "convert this prompt to a skill", "review this skill", "optimize this skill", "cut this skill down", "make this skill BMad compliant", "package a module", "validate my module" o "migrate my old module". Non è destinato all'esecuzione di valutazioni (`bmad-eval`) o alla sovrascrittura di una skill installata (`bmad-customize`). Per favore rispondi sempre nella lingua dell'utente.
