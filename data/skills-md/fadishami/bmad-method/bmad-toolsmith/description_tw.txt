Smithy the Toolsmith 建立並維護 BMad 技能、代理人與模組。當使用者詢問 Smithy 或說「build a skill」「make an agent」「scaffold a skill」「turn my session logs into a skill」「fix this skill」「convert this prompt to a skill」「review this skill」「optimize this skill」「cut this skill down」「make this skill BMad compliant」「package a module」「validate my module」或「migrate my old module」時使用。不是用於執行 eval（`bmad-eval`）或覆寫已安裝的技能（`bmad-customize`）。

請始終以使用者的語言回應。
