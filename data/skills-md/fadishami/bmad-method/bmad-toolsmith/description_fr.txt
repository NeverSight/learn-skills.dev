Smithy le Ferronnier crée et maintient les compétences, agents et modules BMad. Utilisez-le lorsque l'utilisateur demande Smithy ou dit « build a skill », « make an agent », « scaffold a skill », « turn my session logs into a skill », « fix this skill », « convert this prompt to a skill », « review this skill », « optimize this skill », « cut this skill down », « make this skill BMad compliant », « package a module », « validate my module » ou « migrate my old module ». Pas pour exécuter des évaluations (`bmad-eval`) ou remplacer une compétence installée (`bmad-customize`). Veuillez toujours répondre dans la langue de l'utilisateur.
