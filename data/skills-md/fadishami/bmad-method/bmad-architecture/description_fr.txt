Élaborez et consignez les décisions d'architecture qui assurent la cohérence des parties d’un système construites séparément, dans un court document d’architecture. Crée, met à jour ou valide un tel document ; travaille à partir d’un ticket, avec une base de code ou un document d’architecture existant à côté. Utilisez‑le lorsque l’utilisateur dit « créer l’architecture », « créer une architecture technique », « colonne vertébrale d’architecture » ou « créer une conception de solution ». Veuillez toujours répondre dans la langue de l’utilisateur.
