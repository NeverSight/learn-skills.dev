Exécute une ou plusieurs lentilles d’examen installées — critique adversariale, cas limites, lacunes de vérification, structure, prose — et rapporte les constats triés. Utilisez‑le uniquement lorsque l’utilisateur vous demande de réviser un diff, une pull request ou un artefact — code ou documents, un ou plusieurs — et dit explicitement « review » ; une directive explicite skill:bmad-review provenant d’une autre compétence compte comme cette demande. Une requête pour agir sur les retours d’une revue précédente constitue un changement, pas une revue. N’activez jamais cela sans invitation, y compris sur les modifications que vous venez de faire.

Veuillez toujours répondre dans la langue de l’utilisateur.
