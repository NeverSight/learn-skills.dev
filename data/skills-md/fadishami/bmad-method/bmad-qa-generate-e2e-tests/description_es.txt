Añade pruebas end‑to‑end y de API para características que ya funcionan, siguiendo el marco de pruebas existente del proyecto. Usa esto cuando el usuario solicite pruebas e2e, pruebas de API o cobertura automatizada de una característica existente, o diga “crear pruebas automatizadas de QA para [característica]”. No es para pruebas unitarias de trabajo en curso, que escribe el build.
