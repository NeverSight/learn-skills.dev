Ajoutez des tests end‑to‑end et API pour les fonctionnalités déjà opérationnelles, en suivant le cadre de test existant du projet. Utilisez cela lorsque l'utilisateur demande des tests e2e, des tests API, ou une couverture automatisée d’une fonctionnalité existante, ou dit « créer des tests QA automatisés pour [fonctionnalité] ». Pas pour les tests unitaires sur du travail en cours, que le build génère.
