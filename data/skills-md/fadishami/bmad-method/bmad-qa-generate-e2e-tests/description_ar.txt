أضف اختبارات من الطرف إلى الطرف واختبارات API للميزات التي تعمل بالفعل، متبعًا إطار الاختبار الموجود في المشروع. استخدم ذلك عندما يطلب المستخدم اختبارات e2e أو اختبارات API أو تغطية آلية لميزة موجودة، أو يقول "create qa automated tests for [feature]". ليس للاختبارات الوحدوية على العمل الجاري، التي يكتبها البناء.
