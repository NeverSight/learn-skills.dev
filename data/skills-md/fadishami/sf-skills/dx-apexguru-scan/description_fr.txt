Exécutez un scan de performance ApexGuru sur un projet Salesforce Apex via l'API ApexGuru SFAP Scan. Compressez l'Apex du projet (quelle que soit la structure), soumettez‑le, interrogez jusqu’à achèvement, décodifiez le rapport base64 et présentez les violations d’antipatterns de performance (SOQL dans une boucle, DML dans une boucle, Schema.getGlobalDescribe(), SOQL sans WHERE/LIMIT, champs SOQL inutilisés) groupées par règle avec sévérité, fichier :ligne et correctifs suggérés — clairement attribués comme « Static only » ou « Production insights ». DÉCLENCHER lorsque l’utilisateur dit « run ApexGuru », « ApexGuru scan », « check Apex performance », « find governor-limit / performance antipatterns », « SOQL in loop », « scan my Apex for performance » ou « ApexGuru performance insights ». NE DÉCLENCHER PAS pour une analyse statique générale ou des scans de sécurité (utiliser dx-code-analyzer-run), pour corriger du code sans scan, ou pour l’onboarding d’une org à ApexGuru.

Veuillez toujours répondre dans la langue de l’utilisateur.
