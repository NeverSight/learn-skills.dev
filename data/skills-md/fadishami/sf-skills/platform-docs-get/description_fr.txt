Compétence de récupération de la documentation officielle de Salesforce. À utiliser lorsque vous avez besoin de documents Salesforce autoritaires provenant de developer.salesforce.com, help.salesforce.com, architect.salesforce.com, admin.salesforce.com ou lightningdesignsystem.com, en particulier lorsque les pages sont lourdes en JavaScript, rendues par le shell ou difficiles à extraire avec une récupération naïve. Utilisez‑la pour fonder les réponses sur des sources officielles de Salesforce plutôt que sur des blogs ou résumés tiers. DÉCLENCHER lorsque : l’utilisateur demande la documentation officielle de Salesforce, la référence Apex ou API, les docs LWC, les docs Agentforce, les articles de configuration ou d’aide, ou tout document provenant d’un domaine appartenant à Salesforce. NE PAS DÉCLENCHER lorsque : l’utilisateur demande une modification de code, une tâche de déploiement, ou tout ce qui n’exige pas la récupération de documentation — utilisez la compétence sf‑* appropriée à la place.

Veuillez toujours répondre dans la langue de l’utilisateur.
