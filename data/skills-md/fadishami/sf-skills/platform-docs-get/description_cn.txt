官方 Salesforce 文档检索技能。用于在需要权威的 Salesforce 文档（来自 developer.salesforce.com、help.salesforce.com、architect.salesforce.com、admin.salesforce.com 或 lightningdesignsystem.com）时使用，特别是当页面大量使用 JavaScript、采用壳渲染或通过普通抓取难以提取时。使用该技能以在官方 Salesforce 来源而非第三方博客或摘要中为答案提供依据。触发条件：用户请求官方 Salesforce 文档、Apex 或 API 参考、LWC 文档、Agentforce 文档、设置或帮助文章，或任何来自 Salesforce 自有域的文档。不触发条件：用户请求代码更改、部署任务或任何不需要检索文档的情况——请改用相应的 sf-* 技能。

请始终使用用户的语言作答。
