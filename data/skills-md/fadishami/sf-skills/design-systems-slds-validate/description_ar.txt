قم بمراجعة مكوّنات الويب السريعة (Lightning Web Components) للتحقق من توافقها مع نظام التصميم SLDS وإنتاج تقرير جودة مُقيَّم. يشغّل أداة فحص SLDS (linter) ويحلل ملفات CSS لاستخدام هوك الثيمات وتوافقها، مع تقييم نتائج SLDS عبر الفئات المختلفة ومنح درجة إجمالية. استخدم هذا عند طلب عبارات مثل "قيمة SLDS لمكوّني"، "بطاقة نتيجة SLDS"، "تقرير جودة SLDS"، "مراجعة توافق SLDS"، "ما مدى جودة SLDS لدي"، "تحقق من جودة SLDS"، "قيم تنسيق SLDS الخاص بي"، "قيّم SLDS لمكوّني"، "هل SLDS لهذا المكوّن جاهز للإصدار؟"، "انظر إلى مكوّن LWC الخاص بي لمشكلات SLDS"، "راجع SLDS قبل الإرسال"، "راجع SLDS لمكوّني قبل مراجعة الكود"، أو في أي وقت يرغب فيه المستخدم بتقييم جودة SLDS أو فحص جاهزية الإنتاج لـ SLDS على مكوّن LWC. لا يُستَخدم لإصلاح الانتهاكات (استخدم design-systems-slds2-migrate)، أو إنشاء مكوّنات جديدة (استخدم design-systems-slds-apply)، أو مراجعات الوصول/WCAG/ARIA (استخدم experience-accessibility-validate).

يرجى دائمًا الرد بلغة المستخدم.
