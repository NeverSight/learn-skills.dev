Lightning Web Components の SLDS デザインシステムへの準拠性を監査し、スコア付けされた品質レポートを作成します。SLDS リンターを実行し、CSS のテーマフック使用状況とペアリングを分析し、カテゴリ別の SLDS 発見事項にスコアを付けて総合評価を算出します。以下のように依頼されたときに使用します：「コンポーネントの SLDS をスコア化して」「SLDS スコアカード」「SLDS 品質レポート」「SLDS 準拠性を監査して」「私の SLDS はどの程度良いか」「SLDS の品質をチェックして」「SLDS スタイリングを評価して」「コンポーネントの SLDS を評価して」「このコンポーネントの SLDS は出荷準備ができているか」「私の LWC の SLDS の問題を確認して」「提出前に SLDS を監査して」「コードレビュー前にコンポーネントの SLDS をレビューして」など、ユーザーが LWC の SLDS 品質評価や本番環境への準備状況のチェックを求めるあらゆる場面で使用します。違反の修正には使用しないでください（その場合は design‑systems‑slds2‑migrate を使用）、新しいコンポーネントの作成には使用しないでください（design‑systems‑slds‑apply を使用）、アクセシビリティ／WCAG／ARIA の監査には使用しないでください（experience‑accessibility‑validate を使用）。必ずユーザーの言語で応答してください。
