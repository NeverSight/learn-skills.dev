Auditer les Lightning Web Components pour la conformité au système de conception SLDS et produire un rapport de qualité noté. Exécute le linter SLDS et analyse le CSS pour l’utilisation des hooks de thématisation et leur appariement, attribuant des scores aux constats SLDS selon différentes catégories afin d’obtenir une note globale. À utiliser lorsqu’on demande « score mon composant SLDS », « carte de score SLDS », « rapport de qualité SLDS », « auditer la conformité SLDS », « quel est le niveau de mon SLDS », « vérifier la qualité SLDS », « évaluer le style SLDS de mon composant », « est‑ce que le SLDS de ce composant est prêt à être déployé ? », « regarde mon LWC pour les problèmes SLDS », « auditer SLDS avant de soumettre », « revoir le SLDS de mon composant avant la revue de code », ou chaque fois qu’un utilisateur souhaite une évaluation de la qualité SLDS ou une vérification de la prête‑à‑déployer du SLDS sur un LWC. Ne pas l’utiliser pour corriger les violations (utiliser design‑systems‑slds2‑migrate), créer de nouveaux composants (utiliser design‑systems‑slds‑apply), ou les audits d’accessibilité/WCAG/ARIA (utiliser experience‑accessibility‑validate).

Veuillez toujours répondre dans la langue de l'utilisateur.
