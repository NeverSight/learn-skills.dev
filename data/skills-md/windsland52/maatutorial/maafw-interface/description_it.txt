Scrivere, modificare e revisionare il file interface.json di MaaFramework (Project Interface V2) — dichiarazione dell’ingresso del task, configurazione controller/resource, collegamento delle opzioni GUI (pipeline_override e ordine di sovrascrittura), preset predefiniti, pretask (task da avviare prima), configurazione del processo figlio dell’agente, divisione e debug della struttura mediante import. Usare quando si crea, modifica o revisiona un interface.json per un progetto MaaFW, aggiungendo opzioni o preset destinati all’utente, collegando pipeline_override, configurando pretask o processi figlio dell’agente, suddividendo i file di interfaccia tramite import, o diagnosticando errori nella struttura dell’interfaccia.
