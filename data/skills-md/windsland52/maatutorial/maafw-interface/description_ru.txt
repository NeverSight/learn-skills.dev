Создание, изменение и проверка interface.json для MaaFramework (Project Interface V2) — объявление входных точек задач, конфигурация controller/resource, подключение GUI‑опций (pipeline_override и порядок переопределения), предустановки (preset), задачи, запускаемые до выполнения (pretask), конфигурация дочерних процессов агента, разделение файлов с помощью import и диагностика ошибок структуры интерфейса. Используется при создании, редактировании или проверке interface.json для проекта MaaFW, добавлении пользовательских опций или предустановок, подключении pipeline_override, настройке pretask или дочерних процессов агента, разделении файлов интерфейса через import или диагностике ошибок структуры интерфейса.
