デバッグと受け入れテスト MaaFramework（MaaFW）アプリケーション（開発中、デバイスオンライン）――ノード認識失敗、クリックが反応しない（認識成功≠クリック効果）、ROI校正と閾値調整、単一ノード実行検証、フローのハングとコントローラ接続調査、エンドツーエンド受け入れと pipeline_override の効果検証；構成／認識／アクション／フロー／受け入れの5層でトリアージし、位置特定の結論と証拠を作成し、修正を maafw‑pipeline / maafw‑interface / maafw‑custom に戻す。デバイスが接続された状態で MaaFW アプリケーションのデバッグや受け入れテストを行う際に使用します――ノード認識の失敗、クリックが外れる、ROI 校正と閾値チューニング、単一ノードの実行検証、フローのスタックやコントローラ接続問題、エンドツーエンド受け入れ、または pipeline_override の効果チェック；レイヤー（config / recognition / action / flow / acceptance）でトリアージし、修正を maafw‑pipeline / maafw‑interface / maafw‑custom に返します。
