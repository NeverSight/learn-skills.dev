Ingénierie inverse de logiciels livrés avec des outils CLI locaux simples, sans MCP. Couvre les bundles Electron/JS, les binaires natifs Mach‑O/ELF/PE, Go/Rust/.NET/Flutter/WASM, les APK, SQLite, les pcaps, le firmware et les sites Web. Utilisez‑le pour expliquer le fonctionnement d’une fonctionnalité, extraire les versions/dépendances, comparer les builds ou reconstruire une fonctionnalité.
