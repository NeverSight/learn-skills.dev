Исправьте ошибку, сначала написав целевой тест, который не проходит по правильной причине, а затем сделав минимальное изменение, которое заставит его пройти. Используйте это, когда пользователь запрашивает TDD или регрессионный тест, когда у ошибки есть недорогой локальный тестовый объект, либо для /ds‑tdd.
