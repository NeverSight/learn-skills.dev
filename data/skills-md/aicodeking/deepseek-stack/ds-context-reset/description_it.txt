Mantieni un file PROGRESS.md per i compiti lunghi e passa a una nuova sessione o a un subagente che legga solo quel file quando il contesto diventa lungo o obsoleto. Usalo quando un compito si estende su molti passaggi o sessioni, quando il modello inizia a ripetersi, dimentica fatti precedenti, riprova correzioni vecchie o quando la finestra di contesto è più della metà piena. Invocare con /ds-context-reset.

Per favore rispondi sempre nella lingua dell'utente.
