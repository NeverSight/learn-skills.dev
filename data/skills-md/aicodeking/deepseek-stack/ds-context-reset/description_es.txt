Mantenga un PROGRESS.md para tareas largas y muévase a una nueva sesión o subagente que lea solo ese archivo cuando el contexto se vuelva largo o obsoleto. Se usa cuando una tarea abarca muchos pasos o sesiones, cuando el modelo comienza a repetirse, olvida hechos anteriores o vuelve a intentar correcciones antiguas, o cuando la ventana de contexto está medio llena. Invocar como /ds-context-reset.
