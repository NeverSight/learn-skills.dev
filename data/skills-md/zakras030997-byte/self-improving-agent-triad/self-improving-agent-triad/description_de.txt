Initialisieren, prüfen, verlagern und nutzen Sie den projektisolierten Agentenspeicher mit einem evidenzbasierten Executor-, Auditor- und Repairer-Zyklus. Verwenden Sie diese Option, wenn der Benutzer eine Projektspeicherarchitektur erstellen, seinen Dateisystemordner auswählen oder ändern, seinen Status überprüfen oder eine unabhängige Multi-Agenten-Steuerung auf eine wiederverwendbare Materialänderung anwenden möchte. Führen Sie bei Routinearbeiten in einem Schritt nicht die vollständige Triade aus.
