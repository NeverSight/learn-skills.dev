估算程式開發任務需要多長時間，使用使用者自身的實測歷史而非直覺。每當有人要求對功能、錯誤、重構、遷移、腳本或調查等需求提供估算、ETA、時間表或截止日期時，都要使用此技能——例如「這要多久？」、「給我一個估算」、「這需要多少小時」、「今天能上線嗎」、「這是一天的工作嗎」、「整個史詩需要多少天」、「我該跟客戶說什麼」、「估算這張票」、「評估這個」——同樣也要在對方持懷疑態度時使用（「這合理嗎？」、「為什麼花了三天」）。也要將此技能應用於估算背後的機制——設定或校準估算、從過去的 Claude Code 記錄補填任務帳本、記錄已完成任務的實際時間（「記錄此任務」、「登錄這個」、「加入帳本」），以及重新執行校準或檢查過去的估算是否準確。即使問題中未出現「估算」一詞，也要觸發此技能——只要是詢問工作量或所需時間的問題，都屬於此技能的範疇。請始終使用使用者的語言回覆。
