Estima cuánto tiempo tardará una tarea de codificación, usando el historial medido del usuario en lugar de la intuición. Utiliza esta habilidad cada vez que alguien pida una estimación, un ETA, una línea de tiempo o una fecha límite para una función, error, refactorización, migración, script o investigación — "¿cuánto tiempo tomará esto?", "dame una estimación", "¿cuántas horas son esto?", "¿puede enviarse hoy?", "¿es un trabajo de un día?", "¿cuántos días para todo el épico?", "¿qué debo decirle al cliente?", "estima este ticket", "dimensiona esto" — y también cuando la solicitud sea escéptica ("¿es eso realista?", "¿por qué eso tomó tres días?"). También úsala para la maquinaria detrás de las estimaciones: configurar o calibrar la estimación, rellenar el libro de tareas a partir de transcripciones pasadas de Claude Code, registrar los reales de una tarea terminada ("registra esta tarea", "anota esta", "añade esto al libro") y volver a ejecutar la calibración o comprobar si las estimaciones pasadas fueron buenas. Actívala incluso cuando no aparezca la palabra "estimación": una pregunta sobre cuánto trabajo es algo, o cuánto tiempo tomó, corresponde a esta habilidad.

Por favor, responde siempre en el idioma del usuario.
