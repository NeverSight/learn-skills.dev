估算编码任务需要多长时间，使用用户自己的实际测量历史而不是直觉。每当有人请求估算、ETA、时间线或功能、bug、重构、迁移、脚本或调查的截止日期时——比如“这需要多长时间”、“给我一个估算”、“这是多少小时”、“今天能发吗”、“是一天的工作吗”、“整个史诗需要多少天”、“我该怎么跟客户说”、“估算这个工单”、“给它定大小”——以及当对方持怀疑态度时（“这现实吗”、“为什么用了三天”），都要使用此技能。同样也用于估算背后的机制——设置或校准估算、从过去的 Claude Code 记录中补填任务账本、记录已完成任务的实际情况（“记录这个任务”、“记录此项”、“把它加入账本”），以及重新运行校准或检查过去的估算是否准确。即使没有出现“estimate”一词，只要是关于工作量或所需时间的提问，也要触发此技能。
