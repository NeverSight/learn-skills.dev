Stelle jedes HuggingFace‑Modell auf RunPod als vLLM‑Server bereit, verbinde es mit Claude Code (der die Anthropic‑Messages‑API nutzt, nicht die von OpenAI), führe einen Smoke‑Test durch, um sicherzustellen, dass Tool‑Calling end‑to‑end funktioniert, und räume alles spurlos auf (Pod, Netzwerk‑Volumes, lokale Prozesse, temporäre Dateien). Verwende dies immer, wenn du ein Modell auf RunPod ausführen, ein Modell mit Claude Code testen, prüfen möchtest, ob ein HF/GGUF/abliterierter Checkpoint Tool‑Nutzung unterstützt, ein Modell für den Einsatz als Coding‑Agent benchmarken oder eine entbehrliche GPU‑Inference‑Box hoch‑ bzw. runterfahren willst. Aktiviere es zudem für alles, was das Anschließen von Claude Code an ein nicht‑Anthropic‑Backend (vLLM, Ollama, LM Studio) über ANTHROPIC_BASE_URL betrifft, oder für Fragen wie „Welche GPU brauche ich, um X zu betreiben?“ und „Wie viel kostet es, dieses Modell auszuführen?“.
