어떤 HuggingFace 모델이든 RunPod에 vLLM 서버로 배포하고, 이를 Claude Code와 연결하세요(Claude Code는 Anthropic의 Messages API를 사용하고 OpenAI는 사용하지 않습니다). 툴 호출이 실제로 엔드투엔드로 작동하는지 스모크 테스트를 수행한 뒤, 모든 것을 흔적 없이 정리하세요(포드, 네트워크 볼륨, 로컬 프로세스, 임시 파일). RunPod에서 모델을 실행하고 싶을 때, Claude Code로 모델을 시도하고 싶을 때, HF/GGUF/압축된 체크포인트가 툴 사용을 지원하는지 테스트하고 싶을 때, 코딩 에이전트 용도로 모델을 벤치마크하고 싶을 때, 혹은 일시적인 GPU 추론 인스턴스를 올리거나 종료하고 싶을 때마다 이 방법을 사용하세요. 또한 ANTHROPIC_BASE_URL을 통해 Claude Code를 비‑Anthropic 백엔드(vLLM, Ollama, LM Studio)와 연결하는 경우나 “X를 실행하려면 어떤 GPU가 필요한가”·“이 모델을 실행하는 비용은 얼마나 되는가”와 같은 질문에도 이 절차를 적용하세요. 항상 사용자의 언어로 답변해 주세요.
