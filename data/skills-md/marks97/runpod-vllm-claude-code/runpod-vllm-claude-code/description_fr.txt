Déployer n’importe quel modèle HuggingFace sur RunPod en tant que serveur vLLM, le connecter à Claude Code (qui utilise l’API Messages d’Anthropic, pas celle d’OpenAI), tester que l’appel d’outils fonctionne réellement de bout en bout, puis tout supprimer sans laisser de traces (pod, volumes réseau, processus locaux, fichiers temporaires). Utilisez cela chaque fois que vous voulez exécuter un modèle sur RunPod, essayer un modèle avec Claude Code, vérifier si un checkpoint HF/GGUF/ablité supporte l’utilisation d’outils, évaluer un modèle pour un agent de programmation, ou lancer/arrêter une boîte d’inférence GPU jetable. Activez-le également pour tout ce qui concerne le raccordement de Claude Code à un backend non Anthropic (vLLM, Ollama, LM Studio) via ANTHROPIC_BASE_URL, ou pour des questions comme « quel GPU faut‑il pour exécuter X » et « combien cela coûtera‑t‑il de faire tourner ce modèle ».
