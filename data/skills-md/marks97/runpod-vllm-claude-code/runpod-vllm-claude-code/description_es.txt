Despliega cualquier modelo de HuggingFace en RunPod como un servidor vLLM, conéctalo a Claude Code (que utiliza la API de Mensajes de Anthropic, no la de OpenAI), verifica que la llamada a herramientas funcione de extremo a extremo y desmantela todo sin dejar rastro (pod, volúmenes de red, procesos locales, archivos temporales). Usa esto siempre que quieras ejecutar un modelo en RunPod, probar un modelo con Claude Code, comprobar si un checkpoint HF/GGUF/abliterado admite el uso de herramientas, evaluar el rendimiento de un modelo para agentes de codificación o iniciar/eliminar una caja de inferencia GPU desechable. También activa este procedimiento para cualquier caso de conectar Claude Code a un backend que no sea Anthropic (vLLM, Ollama, LM Studio) mediante ANTHROPIC_BASE_URL, o para preguntas como “qué GPU necesito para ejecutar X” y “cuánto costará ejecutar este modelo”.
