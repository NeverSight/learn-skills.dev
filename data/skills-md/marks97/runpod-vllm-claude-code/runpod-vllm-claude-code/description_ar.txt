انشر أي نموذج من HuggingFace على RunPod كخادم vLLM، اربطه بـ Claude Code (الذي يتحدث مع واجهة رسائل Anthropic، وليس OpenAI)، اختبر أن استدعاء الأدوات يعمل فعليًا من الطرف إلى الطرف، ثم قم بإزالة كل شيء بدون أي أثر (الحاوية، وحدات الشبكة، الأحجام، العمليات المحلية، ملفات المؤقت). استخدم ذلك كلما رغبت في تشغيل نموذج على RunPod، تجربة نموذج مع Claude Code، اختبار ما إذا كان checkpoint من HF/GGUF/abliterated يدعم استخدام الأدوات، قياس أداء نموذج للاستخدام كوكيل برمجي، أو إنشاء/إيقاف صندوق استدلال GPU مؤقت. كذلك فعل ذلك لأي شيء يتعلق بربط Claude Code بواجهة خلفية غير Anthropic (vLLM، Ollama، LM Studio) عبر ANTHROPIC_BASE_URL، أو أسئلة مثل "ما نوع GPU الذي أحتاجه لتشغيل X" و"كم سيكلف تشغيل هذا النموذج".
