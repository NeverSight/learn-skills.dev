部署任何 HuggingFace 模型至 RunPod 作為 vLLM 伺服器，將其橋接到 Claude Code（使用 Anthropic 的 Messages API，而非 OpenAI 的），進行端到端的工具呼叫冒煙測試，並在無任何痕跡的情況下全部拆除（pod、網路磁碟、本機程序、暫存檔）。每當你想在 RunPod 上運行模型、使用 Claude Code 嘗試模型、測試 HF/GGUF/已裁減的 checkpoint 是否支援工具使用、為程式碼代理使用基準測試模型，或啟動/關閉一次性 GPU 推理盒時，都使用此方法。也可在任何關於將 Claude Code 連接到非 Anthropic 後端（vLLM、Ollama、LM Studio）透過 ANTHROPIC_BASE_URL，或是諸如「執行 X 需要什麼 GPU」以及「運行此模型的成本是多少」之類的問題時觸發它。
