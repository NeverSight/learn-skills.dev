任意のHuggingFaceモデルをRunPodにvLLMサーバーとしてデプロイし、Claude Code（AnthropicのMessages APIを使用し、OpenAIではない）に接続して、ツール呼び出しがエンドツーエンドで実際に機能するかをスモークテストし、すべてを痕跡なしで破棄します（ポッド、ネットワークボリューム、ローカルプロセス、スクラッチファイル）。RunPodでモデルを実行したいとき、Claude Codeでモデルを試したいとき、HF/GGUF/削除されたチェックポイントがツール利用をサポートするかテストしたいとき、コーディングエージェント用にモデルをベンチマークしたいとき、または使い捨てのGPU推論ボックスを起動／停止したいときにこの手順を使用してください。また、Claude Codeを非Anthropicバックエンド（vLLM、Ollama、LM Studio）にフックする際にANTHROPIC_BASE_URLを介して行う場合や、「X を実行するのに必要なGPUは何か」「このモデルを実行するコストはどれくらいか」などの質問にもこの手順をトリガーしてください。
