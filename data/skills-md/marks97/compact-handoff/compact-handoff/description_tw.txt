將目前的對話壓縮成一個大型獨立的交接檔案儲存於磁碟，然後開啟一個以當前聊天名稱加上遞增計數命名的全新 Claude Code 工作階段，僅以指向該檔案的指標作為種子，保持原本聊天完整不變。於以下情況均使用此方式：使用者希望獲得乾淨的上下文視窗卻不失已學資訊，或說出任何以下語句——「compact to a new chat」「compact but start fresh」「carry this over to a new session」「hand this off」「new chat with this context」「my context is getting heavy」「this chat is too long」「start over but remember this」「dump the context and open a fresh one」，或要求交接、上下文轉存、或可日後重用的會話摘要。亦在長時間調查結束、後續工作需要獨立視窗時使用。當使用者希望保留舊聊天以供閱讀時，優先使用此方式而非純粹的 /compact，即使使用者未明說「compact」也應主動採用。請始終以使用者的語言回覆。
