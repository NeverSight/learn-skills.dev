Compacter la conversation actuelle dans un gros fichier autonome de remise sur le disque, puis ouvrir une NOUVELLE session Claude Code nommée d’après le chat actuel avec un compteur incrémenté, alimentée uniquement d’un pointeur vers ce fichier, en laissant le chat actuel entièrement intact. Utilisez cela chaque fois que l’utilisateur veut une fenêtre de contexte propre sans perdre ce qui a été appris, ou dit l’une des expressions — « compacter vers un nouveau chat », « compacter mais repartir à zéro », « transférer cela dans une nouvelle session », « passer cela », « nouveau chat avec ce contexte », « mon contexte devient lourd », « ce chat est trop long », « recommencer mais se souvenir de cela », « vider le contexte et ouvrir un nouveau », ou demande une remise, un dump de contexte, ou un résumé de session qu’il peut réutiliser plus tard. Utilisez‑le également lorsqu’une longue investigation est terminée et que le travail de suivi mérite sa propre fenêtre. Préférez cela à /compact simple chaque fois que l’utilisateur souhaite que le vieux chat reste lisible par la suite, et appliquez‑le même s’il ne prononce jamais le mot « compact ».
