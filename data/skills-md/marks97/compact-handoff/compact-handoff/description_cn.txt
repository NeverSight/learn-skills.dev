将当前对话压缩为磁盘上的大型独立交接文件，然后打开一个全新的 Claude Code 会话，名称基于当前聊天并加上递增计数，只使用指向该文件的指针进行初始化，保持当前聊天完整不变。每当用户希望获得干净的上下文窗口而不丢失已学内容，或使用以下任意表达时——“compact to a new chat”（压缩到新聊天）、“compact but start fresh”（压缩但重新开始）、“carry this over to a new session”（转移到新会话）、“hand this off”（交接此内容）、“new chat with this context”（使用此上下文的新聊天）、“my context is getting heavy”（我的上下文变得沉重）、“this chat is too long”（此聊天太长）、“start over but remember this”（重新开始并记住此内容）、“dump the context and open a fresh one”（清空上下文并打开全新会话），或请求交接、上下文转储、或可供以后重用的会话摘要时，请使用此方法。也在长时间调查结束、后续工作需要单独窗口时使用。相比普通 /compact，优先使用此方式，以便用户在之后仍能阅读旧聊天，即使他们从未说过“compact”这个词，也请采用此方法。
