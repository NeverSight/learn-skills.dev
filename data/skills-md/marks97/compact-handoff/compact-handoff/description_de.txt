Kompaktiere das aktuelle Gespräch in eine große eigenständige Hand‑off‑Datei auf der Festplatte, dann öffne eine BRANDNEUE Claude‑Code‑Sitzung, die nach dem aktuellen Chat mit einem inkrementierten Zähler benannt ist, und starte sie nur mit einem Verweis auf diese Datei, sodass der aktuelle Chat vollständig intakt bleibt. Verwende dies immer, wenn der Benutzer ein sauberes Kontextfenster möchte, ohne das Gelernte zu verlieren, oder einer der folgenden Ausdrücke sagt – „compact to a new chat“, „compact but start fresh“, „carry this over to a new session“, „hand this off“, „new chat with this context“, „my context is getting heavy“, „this chat is too long“, „start over but remember this“, „dump the context and open a fresh one“ – oder um einen Hand‑off, einen Kontext‑Dump oder eine Sitzungs‑Zusammenfassung bittet, die er später wiederverwenden kann. Nutze es auch, wenn eine lange Untersuchung abgeschlossen ist und die Folgebearbeitung ein eigenes Fenster verdient. Ziehe dies dem einfachen /compact vor, wann immer der Benutzer möchte, dass der alte Chat anschließend lesbar bleibt, und greife darauf zurück, selbst wenn er nie das Wort „compact“ verwendet.
