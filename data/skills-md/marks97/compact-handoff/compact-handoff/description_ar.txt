قم بضغط المحادثة الحالية في ملف تسليم مستقل كبير على القرص، ثم افتح جلسة Claude Code جديدة تمامًا مسماة باسم الدردشة الحالية مع عداد مُزيد، مزيَّدة فقط بمؤشر إلى ذلك الملف، مع ترك الدردشة الحالية سليمًا تمامًا. استخدم ذلك كلما أراد المستخدم نافذة سياق نظيفة دون فقد ما تم تعلمه، أو قال أيًا من — "compact to a new chat"، "compact but start fresh"، "carry this over to a new session"، "hand this off"، "new chat with this context"، "my context is getting heavy"، "this chat is too long"، "start over but remember this"، "dump the context and open a fresh one"، أو طلب تسليم، أو تفريغ السياق، أو ملخص جلسة يمكنه إعادة استخدامه لاحقًا. استخدمه أيضًا عندما تنتهي تحقيق طويل ويستحق العمل المتابع نافذة خاصة به. فضل هذا على /compact العادي كلما أراد المستخدم أن تظل الدردشة القديمة قابلة للقراءة بعد ذلك، وابدأ باستخدامه حتى لو لم يذكر كلمة "compact".
