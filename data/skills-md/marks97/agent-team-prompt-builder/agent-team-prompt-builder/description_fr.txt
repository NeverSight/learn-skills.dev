Générez des invites hyper‑détaillées pour les équipes d’agents Claude Code en fonction d’un plan, d’une demande de fonctionnalité ou du contexte d’une conversation. Utilisez cette compétence chaque fois que l’utilisateur souhaite créer une invite pour une équipe d’agents, préparer une tâche pour un agent de codage, générer une invite d’équipe, construire un flux de travail d’agent autonome, ou dit des choses comme « créer une invite pour des équipes d’agents », « préparer une tâche pour une session fraîche », « générer une invite d’équipe », « construisez‑moi une invite d’agent », « je veux confier cela à une équipe d’agents », « créer des instructions pour une équipe d’agents » ou « écrivez‑moi une invite de codage autonome ». Activez également la compétence lorsque l’utilisateur décrit une fonctionnalité complexe et demande à la déléguer, souhaite préparer du travail pour des agents parallèles, ou mentionne « contexte frais », « invite copier‑coller » ou « implémentation autonome ».

Veuillez toujours répondre dans la langue de l’utilisateur.
