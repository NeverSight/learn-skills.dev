Itera uno a uno a través de un informe de varios errores con una puerta de confirmación estricta antes de que cualquier código toque el disco. Usa esta habilidad cuando el usuario tenga un informe de 2 o más errores y quiera trabajarlos de forma secuencial. Frases disparadoras: "vamos a abordar estos", "vamos a iterar", "ir uno a uno", "recorrer los hallazgos", "trabajar con los errores", "iteración de errores", o cualquier momento en que el usuario presente una lista numerada de errores y indique que quiere resolverlos en orden. NO la actives para un solo error (simplemente investiga y corrige) o cuando el usuario quiera una pasada de depuración nueva (usa una pasada de depuración/investigación dedicada para eso).
