Itère un à un à travers un rapport contenant plusieurs bugs avec une porte de confirmation stricte avant que le code n’écrive sur le disque. Utilisez cette compétence lorsque l’utilisateur a un rapport de 2 bugs ou plus et souhaite les traiter séquentiellement. Phrases déclencheurs : « let's tackle these », « let's iterate », « go one by one », « loop through the findings », « work through the bugs », « bug iteration », ou chaque fois que l’utilisateur présente une liste numérotée de bugs et indique qu’il veut les résoudre dans l’ordre. Ne déclenchez PAS pour un seul bug (il suffit d’enquêter et de corriger) ou lorsque l’utilisateur souhaite un nouveau passage de débogage (utilisez alors une passe de débogage/investigation dédiée). Veuillez toujours répondre dans la langue de l’utilisateur.
