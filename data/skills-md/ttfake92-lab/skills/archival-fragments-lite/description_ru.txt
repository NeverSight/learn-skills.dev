Визуальный стиль «Архивный коллаж» + метод цепочки ключевых кадров для связи первого и последнего кадров. Бумага цвета слоновой кости без полей, монохромная черно-белая печать, одинарная темно-кирпично-красная; сначала создайте серию отдельных эталонных изображений, затем используйте каждую пару соседних изображений в качестве первого и последнего кадров для создания кадра с плавным соединением. Не привязан к какой-либо конкретной модели; можно использовать любой видеоинструмент, поддерживающий редактирование первого и последнего кадра. Этот метод применяется, когда пользователь хочет создать короткое видео в стиле архивного коллажа/бумажного коллажа/редактирования или желает использовать подход «первый и последний кадр» для последовательной последовательности раскадровки.
