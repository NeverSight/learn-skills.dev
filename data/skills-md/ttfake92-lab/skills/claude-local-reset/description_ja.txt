macOS と Windows で Claude Desktop のローカル状態をバックアップおよびリセットし、ネットワークの外部通信、DNS/WebRTC、プロキシおよびリレー設定を確認し、HTML 品質チェック領収書を自動的に配信し、クリック可能な Claude アカウント禁止回避ガイドを提供します。使用時はまずタスク範囲を確認するために一時停止してください：Claude のローカル使用痕跡を削除するか、ネットワークチェックのみを行うかを選択します。ガイドは初回ユーザーと過去に制限されたユーザーに対して、手動準備（タイムゾーン、外部通信、TUN、ログイン前自己チェック、アカウントと支払い、日次使用、出発前チェックリスト）を別途案内し、スキル品質チェックを呼び出します。環境は独立してチェック可能です；サーバーの切断や禁止の防止を保証するものではありません。Linux または未検証のインストール方法には適用しないでください。
