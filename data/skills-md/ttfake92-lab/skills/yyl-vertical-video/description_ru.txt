Портретный ролик с разделённым экраном и озвучкой — превратить сценарий озвучки в короткое видео 1080 × 1920 «анимация сверху + карточка персонажа снизу» в формате знаний/мнения: озвучка Breeze → аудио управляет цифровым человеком HeyGen (Avatar V) → подбирать материал предложение за предложением (соцсети TikHub, собственные записи экрана, AI‑видео Dream‑Seedance) → кодировать анимации (поднятый serif‑заголовок с размытым входом, карточка «жидкое стекло», список, процесс, стенка телефонов, код, форма QA и пр.) → каждый сегмент привязывается к произнесённому тексту → анимировать вход с голосовыми эффектами → саундтрек Epidemic автоматически исключает вокал → пороги контроля качества (субтитры, закрывающие лицо, выравнивание субтитров, громкость, чёрные кадры). Фирменная деталь: вырезка персонажа в карточке с закруглёнными углами внизу увеличена примерно на 16 %, выровнена по нижнему краю, при этом голова и руки «выходят» за верхний край карточки; фон обрезан карточкой снизу, создавая трёхмерный эффект. Используется, когда пользователь говорит «портретная озвучка / анимация сверху, человек снизу / персонаж выходит за пределы кадра / следовать стилю split‑screen reels / использовать цифрового человека для озвучки / отправить вам сценарий для создания видео». Не подходит для: ландшафтной озвучки (talking‑head‑reel), длительных живых видеоклипов с озвучкой (talking‑head‑edit), озвучки без объяснения в кадре (knowledge‑explainer), влога.
