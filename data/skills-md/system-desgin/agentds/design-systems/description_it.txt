Costruisci interfacce UI che seguono un vero sistema di design invece dei valori predefiniti generici dell'IA. Usa quando l'utente richiede di stilizzare un'app secondo un sistema di design noto (Carbon, Material 3, Primer, Fluent 2, Cloudscape, Ant Design, Flowbite e altri), chiede un DESIGN.md, chiede di elencare i sistemi di design disponibili o desidera un sistema di design creato per il proprio prodotto. Recupera file token DESIGN.md pronti per l'agente dal catalogo gratuito AgentDS.

Per favore rispondi sempre nella lingua dell'utente.
