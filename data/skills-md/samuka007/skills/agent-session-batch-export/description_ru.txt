Курировать расшифровки сессий claude_code/codex в корпус RAW‑файлов .jsonl с материалом траекторий для агентного анализа. Сканировать кандидаты по рабочему пространству/теме, позволять агенту их отфильтровать, а человеку отмечать «оставить/отбросить», затем копировать сохранённые сессии байт‑в‑байт с манифестом sha256. Использовать при извлечении материала траекторий, построении набора данных прошлых сессий агента, фильтрации сессий по рабочему пространству, проекту или теме, а также когда пользователь хочет выбрать разговоры для сохранения из истории агента.
