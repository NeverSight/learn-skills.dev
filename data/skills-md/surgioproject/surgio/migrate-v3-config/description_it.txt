Migra il repository di configurazione di Surgio v3 a un progetto TypeScript ESM nativo e conserva la distribuzione non‑Worker, la distribuzione Worker o entrambe secondo la scelta dell'utente. Viene utilizzato per migrare surgio.conf.js, la directory dei provider, la configurazione degli Artifact, il Node Gateway o la distribuzione Worker; prima di iniziare, devi chiedere se mantenere il metodo di distribuzione originale e distinguere tra Worker e non‑Worker, ma indipendentemente dalla scelta di distribuzione, completa TypeScript rigoroso, parità comportamentale e la relativa verifica a runtime, senza introdurre Bun, tsx o un compilatore a runtime.

Si prega di rispondere sempre nella lingua dell'utente.
