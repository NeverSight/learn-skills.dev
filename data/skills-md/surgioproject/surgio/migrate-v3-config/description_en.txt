Migrate the Surgio v3 configuration repository to a native TypeScript ESM project, and retain non‑Worker deployment, Worker deployment, or both according to the user’s choice. This is used to migrate surgio.conf.js, the provider directory, Artifact configuration, Node Gateway, or Worker deployment; before starting, it must ask whether to continue with the original deployment method and distinguish between Worker and non‑Worker, but regardless of the deployment method chosen, it must achieve strict TypeScript, behavior parity, and corresponding runtime verification, without introducing Bun, tsx, or a runtime compiler.
