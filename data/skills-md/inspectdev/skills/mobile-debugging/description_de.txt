Debuggen Sie das mobile Web auf echten iPhones, Android-Geräten und Simulatoren mithilfe der Inspect-CLI, einschließlich der Erstellung von iOS-Simulatoren auf macOS. Verwenden Sie diese Option, wenn eine Website oder WebView auf einem Telefon fehlerhaft ist, wenn der Benutzer mobiles Safari, iOS, Android Chrome oder die Überprüfung auf dem Gerät erwähnt oder wenn eine Fehlerbehebung auf einem echten Gerät nachgewiesen werden muss.
