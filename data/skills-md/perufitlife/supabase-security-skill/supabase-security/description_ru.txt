Используйте при аудите или укреплении уровня безопасности проекта Supabase. Триггеры: сканирование/аудит Supabase, проверка RLS, поиск «протекающих» таблиц, проверка анонимных привилегий, обзор функций SECURITY DEFINER, подготовка к изменениям раскрытия Data API 30 мая/30 октября 2026 года, генерация SQL‑кода для исправления. Работает с любым проектом Supabase (облачным или самостоятельным) при наличии персонального токена доступа.
