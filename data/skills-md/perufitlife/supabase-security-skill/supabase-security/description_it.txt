Usa quando effettui l’audit o il potenziamento della sicurezza di un progetto Supabase. Trigger: scansione/audit di Supabase, verifica RLS, individuazione di tabelle vulnerabili, verifica dei permessi anonimi, revisione delle funzioni SECURITY DEFINER, preparazione per le modifiche di esposizione dell’API dati del 30 maggio / 30 ottobre 2026, generazione di SQL di rimedio. Funziona con qualsiasi progetto Supabase (Cloud o auto‑hostato) con un Personal Access Token.
