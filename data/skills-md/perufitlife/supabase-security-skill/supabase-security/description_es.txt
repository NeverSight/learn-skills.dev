Usar al auditar o reforzar la postura de seguridad de un proyecto Supabase. Disparadores: escanear/auditar Supabase, verificación de RLS, encontrar tablas con fugas, comprobar permisos anónimos, revisar funciones SECURITY DEFINER, prepararse para los cambios de exposición del Data API del 30 de mayo / 30 de octubre de 2026, generar SQL de remediación. Funciona con cualquier proyecto Supabase (en la nube o autoalojado) usando un Token de Acceso Personal.
