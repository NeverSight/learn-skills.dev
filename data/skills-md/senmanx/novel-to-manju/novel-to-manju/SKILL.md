# 小说 → 漫剧短视频 集大成流水线（自包含版）

把一篇小说（或一个题材想法）做成抖音竖屏漫剧/短视频。本文件内含全部规则，粘给任何 AI（豆包/DeepSeek/ChatGPT）即可独立执行，无需其它文件。

## 0. 工具分工（先记牢）

| 干什么 | 用哪个 |
|---|---|
| 出文字（改文/剧本/人物分析/分镜） | DeepSeek / 豆包（本文件就是给它们用的） |
| 出静态图（人物/场景/三视图/封面） | 即梦 / Midjourney / SD |
| 出视频 + 音频 | MiniMax H3（0.8元/秒） |

静态图生成后，作为 MiniMax H3 的**参考图/首帧**传入，用来锁定人物/场景一致性。H3 是视频模型，不产文字也不产静态图。

## 1. 总流程（10 步）

1. 文案：爆款改文（保留原人称，做内容优化）或 原创小说 → 2. 转漫剧剧本（转第一人称，做画面化处理）→ 3. 角色卡+音色设定（整理所有角色信息）→ 4. 人物+道具提示词（出参考图，全3D）→ 5. 场景清单（整理所有场景）→ 6. 场景提示词（出参考图）→ 7. 人物三视图 → 8. 分镜+镜头提示词 → 9. 打斗/技能特效提示词（若有）→ 10. MiniMax H3 出视频+音频。

**阶段分工说明**：
- 第1步（爆款改文）= 内容优化：把原著改得更爽、更有钩子、节奏更快，**保留原人称**
- 第2步（转漫剧剧本）= 格式转换：把第1步的输出转成第一人称、增强画面感，**强制第一人称**
- 两步串行：第1步的输出是第2步的输入，不可跳过

## 2. 全局铁律（所有阶段通用）

### 2.1 内容合规（分两层，题材风格不限制）

**第一层：平台红线（绝对禁止，全流程不得出现）**
- 血腥暴力细节：血液飞溅、喷血、鲜血淋漓、血池、断头、内脏、血肉模糊、脑浆、残肢断臂
- 暴力动作：分尸、斩首、挖眼、掏心、剥皮、凌迟、虐杀、酷刑、断肢、爆头、穿刺、屠杀、灭门
- 裸露色情：全裸、半裸、袒胸露背（过度）、露私密部位、一丝不挂、性感暴露、挑逗、低俗姿势
- 敏感部位直白描述（乳房/阴部/阴茎/臀部）
- 校园暴力、自残自杀、邪教/极端宗教
- 真实恐怖：丧尸、血腥祭祀、活人献祭、食人恶鬼

**第二层：题材中性化（允许存在，只需替换敏感词）**
- 修仙/法术/阵法/功法/境界 → 正常保留，不属于封建迷信
- 克苏鲁/志怪/民俗恐怖/暗黑魔幻 → 正常保留，恐怖氛围允许，但血腥细节按第一层替换
- 妖魔鬼怪（非恐怖化）→ 正常保留
- 血液 → 用"金色血液""衣领有红痕""光影/符文"替代
- 暴力动作 → 用"格挡、弹开、击退、剑气对冲、化作光点消散"替代
- 裸露 → 用"高领、一字肩（锁骨以上）、立体剪裁、多层叠穿"替代
- 敏感部位 → 用"胸部自然饱满、腰肢纤细、身形曼妙、腿部修长"等安全词
- 恐吓/封建元素 → 用"神秘仪式、能量献祭、异兽"中性化

**原则**：不限制作材风格（修仙/都市/科幻/克苏鲁/暗黑等均可），只限制平台审核红线内容。拿不准是否违规时，用中性词替代即可，不要直接删除剧情。

### 2.2 一致性锁定
- 人物：同一角色全程同一张脸/发型/服装/体型，用参考图（首帧）锁定，禁止凭空出现/消失/换装
- 场景：时间（晨/午/晚）、地点、光线、天气前后一致；道具位置延续
- 动作：上镜结尾动作 = 下镜起始动作
- 站位：双人戏角色A在画面左、角色B在画面右，无换位动作不颠倒

### 2.3 时长规范（MiniMax H3）
- 单段 **4-15 秒**（默认 6-15 秒），单段内分 2-4 个镜头用"切"衔接
- 15 秒及以内**单段一次生成**；超过 15 秒才拆多段，段间"上一段尾帧=下一段首帧"
- 每段结尾保持 0.8-1.2 秒，方便截尾帧

### 2.4 台词规范（H3 原生语音）
- 台词精简，说话人标 (Sx)；每 5-6 字约 1 秒（激动稍快、低沉稍慢）
- 2秒镜头对话≤6字、内心独白≤8字；3秒≤9字/12字；4秒≤12字/16字；单镜头超 30 字必须拆分
- 内心独白：第一人称、无口型画外音，标注"（无口型，画外音）"
- 非说话角色嘴唇紧闭，不写张嘴/喉部动作

### 2.5 剧情保真原则（最高优先级，凌驾于所有"精简/删减"规则之上）
- **原著剧情不得擅自删减**：所有推动主线的情节、关键转折、人物成长弧光、重要伏笔、世界观设定必须完整保留，禁止以"节奏快"为由跳过或合并
- **删减仅限纯冗余**：只有完全不影响剧情理解、不塑造人物、不铺垫后续、不渲染氛围的纯凑字数描写才可压缩；拿不准时一律保留
- **支线处理**：与主线人物/结局/伏笔相关的支线必须保留；仅当支线完全独立且与主线零交集时，才与用户确认后决定是否删减
- **节奏靠"表达密度"而非"砍内容"**：要快节奏就用短句、切镜密、台词精炼来实现，不靠删剧情节点；一个剧情节点可以用2个快切镜头讲完，但不能直接消失
- **分集扩容**：单集60秒装不下就拆多集，禁止为了凑60秒而砍剧情；一集讲不完的故事用2-3集讲完，每集结尾留钩子即可
- **改文前后自检**：改文完成后必须对照原文逐段检查，确认每个剧情节点都有对应输出，缺了就补回

## 3. 阶段1：文案（爆款改文 / 原创小说）

### 3.1 爆款改文规则（内容优化，保留原人称）
- **本阶段定位**：把原著改成爆款网文，只做内容优化（节奏/爽点/钩子），**保留原著人称**（原著第三人称就继续第三人称，不转第一人称）
- **本阶段输出 = 下一阶段（4.1小说润色）的输入**，4.1才负责转第一人称
- 开篇前 3 句强钩子，直接切入冲突/绝境/反转/悬念；必要的背景信息用穿插方式交代，不直接砍掉
- 爽点密度：每 80 字 1 个小爽点，每 200 字 1 个大爽点，主角全程不憋屈
- 段段留钩：每段结尾留悬念/伏笔/反转预告
- 单章 800-1500 字（原著内容多可放宽到2000字），短句为主、画面感强；装不下就分多章，禁止砍剧情凑字数
- 精简表达而非删减剧情：用精炼句式重写，保留所有剧情节点、人物关系、伏笔铺垫；仅删除纯凑字数的重复描写和无意义修辞
- 支线保留：与主线相关的支线完整保留；完全独立的支线标注出来，由用户决定去留
- 放大情绪反差（绝境→逆袭）；反转密集不套路
- 章节结尾留终极钩子（惊天秘密/强敌来袭/逆天机缘/身世谜团）
- 全程合规，按2.1两层规则处理
- **改文后自检**：对照原文列出剧情节点清单，确认每个节点都在改文中有对应，缺漏立即补回
- 📚 参考文档：`docs/爆款改文指令.txt`、`docs/原创小说爆款指示词.doc`

### 3.2 原创小说规则（通用题材，不限修仙）
- **题材自适应**：修仙/都市/科幻/悬疑/历史/奇幻等均可，不局限修仙
- 通用规则：开篇强冲突悬念，反转密集，爽点频繁，每段留钩
- 规避知名小说版权：人名/地名/组织名/武器名/招式名全部原创，不触发版权
- 首章 800-1500 字，内容多可分章；后续可补人物分支、场景、道具、动物细节
- 按题材差异化设定：
  - 修仙/玄幻：功法/境界/宗门/灵根等修炼体系设定
  - 现代都市：职业/身份反差/商业/情感线设定
  - 科幻/赛博：世界观/科技设定/势力格局
  - 悬疑/推理：伏笔密度/反转节点/线索铺设
  - 历史/架空：时代背景/势力关系/制度设定
  - 西方奇幻：魔法体系/种族/阵营设定
- 📚 参考文档：`docs/原创AI剧本生成.txt`

## 4. 阶段2：转漫剧剧本

### 4.1 小说润色（格式转换，强制转第一人称）
- **本阶段定位**：把3.1爆款改文的输出转成漫剧脚本，**强制第一人称"我"叙事**，绝不切第三人称
- **本阶段输入 = 3.1的输出**，3.1已保留原人称，本阶段负责转换
- **剧情保真第一**：完整保留原著所有剧情节点、关键转折、人物互动、伏笔铺垫、世界观信息；禁止以"精简"为由删除任何有实质内容的段落
- 精简的是"表达方式"不是"内容"：把冗长的修饰语、重复的心理描写、大段环境堆砌改写成简洁有力的句子，但信息点一个不少
- 开头前 3 句必须强悬念钩子，禁平淡开篇；背景信息通过对话/动作/内心独白穿插交代，不直接删
- 画面感极强，方便转分镜；保留关键对话/情绪爆发点/剧情转折点
- 平台合规，按2.1两层规则处理
- **润色后自检**：逐段对照原文，确认每个事件、每次对话、每个伏笔都有保留；若某段被压缩，必须确认其信息已融入其他段落而非丢失

### 4.2 分集剧本格式
- 单集 60-90 秒（内容多可到120秒），开篇前 3 秒强看点
- **剧情优先于时长**：一集装不下就拆成多集，禁止为凑时长砍剧情；每集在自然断点（悬念/反转/场景切换）处分割
- 固定格式：【镜号】+【画面描述】+【台词/旁白】+【音效/背景音乐】+【单镜时长】
- 画面描述具体具象（人物表情/动作/场景），适合 AI 生成
- 台词口语化，每一句有信息点；结尾留悬念引导下一集
- 每集输出前标注"本集覆盖原著第X段至第Y段"，方便核对剧情完整性
- 📚 参考文档：`docs/1、小说转剧本（S级漫剧）.txt`

### 4.3 角色卡 + 音色设定（人物提示词的前置步骤）
- **本阶段输出 = 下一阶段（5.人物提示词）的输入**，先整理角色卡再写提示词
- 输出Markdown表格，每个有台词或重要动作的角色一行，路人/背景板角色可不列
- 字段及说明：

| 字段 | 说明 | 示例 |
|---|---|---|
| 角色编号 | C01、C02... 用于文件命名 | C01 |
| 角色名 | 剧中称呼 | 林云 |
| 身份 | 职业/地位/隐藏身份 | 总裁/隐藏修仙者 |
| 年龄 | 外观年龄 | 25 |
| 脸型 | 从5.2五官库选 | 鹅蛋脸 |
| 眉形 | 从5.2五官库选 | 剑眉 |
| 眼型 | 从5.2五官库选 | 丹凤眼 |
| 发型/发色 | 具体描述 | 黑色短发、利落 |
| 身高体型 | 具体数据 | 185cm、宽肩窄腰 |
| 服装 | 列出所有套系，标注出场时机 | 黑色西装（日常）/黑色战斗服（打斗） |
| 关键道具 | 随身携带的重要物品 | 玉佩、长剑 |
| 性格 | 2-3个关键词 | 隐忍、果决、腹黑 |
| 音色设定 | 性别+声线+年龄感+语速+情绪特点 | 男、低沉磁性、青年音、语速偏慢、冷静 |
| 出场集数 | 哪些集出现 | E01-E20 |

- **音色规则**：每个角色只设定一个音色，全片统一，禁止中途变化；主角和重要配角必须设定，路人可省略
- 角色卡完成后，与用户确认是否有遗漏/错误，确认后再进入下一阶段
- 📚 参考文档：`docs/角色.txt`、`docs/角色创造.txt`、`docs/S级漫剧人物 GPT版.txt`

### 5.2 五官差异化（拒绝脸盲，每个角色必写具体五官）
- 脸型：鹅蛋脸（温婉）、瓜子脸（娇俏）、圆润苹果脸（幼态）、方中带圆脸（英气）、长菱形脸（高冷）、心形脸（甜美）；克苏鲁可用不对称脸
- 眉形：远山眉（清冷）、柳叶眉（淡雅）、剑眉（英气）、秋波眉（妩媚）、野生平眉（少年感）、一字眉；克苏鲁可用八字眉/断眉/极淡眉
- 眼型：丹凤眼（凌厉）、桃花眼（含情）、杏眼（天真）、瑞凤眼（腹黑）、狐狸眼（妖艳）、下垂眼（忧郁）、三角眼（凶狠）；克苏鲁可用多瞳/无瞳
- 鼻型：高挺直鼻、驼峰鼻、小巧翘鼻、圆润鼻头、希腊鼻
- 唇形：薄唇（清冷）、厚唇（性感）、M唇（娇媚）、嘴角平直（坚毅）
- 瞳色规则：正常人类只用自然色（黑/深棕/浅棕/深灰/琥珀）；异色瞳（血红/紫金/冰蓝）仅限非人/妖族/神明且有设定依据

### 5.3 敏感词规避（人物提示词专项）

## 6. 阶段4：场景提示词

### 6.1 硬性规则
- **无人纯场景**：严禁任何人影/人名/衣物/肢体/饰品；固定开头写"不能出现其他人,无人纯场景,"

- 四大要素：环境类型、具体时间、空间氛围、视觉主要特征

### 6.2 万能场景公式
①定光影氛围（不要只写"白天"，写光的质感：丁达尔效应、黄昏死寂金光、黎明冷蓝调）→ ②主体+背景（古典园林、悬浮巨灵骸骨、锈蚀青铜祭坛）→ ③材质与光影互动（"光在琉璃瓦上投下阴影""冷光与湿润苔藓对话"）→ ④锁渲染后缀（写实场景、UE5、8k、杰作）

### 6.3 唯美+气氛
- 情绪关键词 2-4 个（苍凉/孤绝/宿命/唯美/静谧）
- 诗意光影对抗：用"A与B的对抗/交融/对话"句式（"暖金光栅与暖灰阴影的温柔交融"）
- 时间天气情绪化（"黄昏将死未死，天光如生锈的铜"）

- 色彩具体诗意（褪色的朱红+锈蚀青绿+冷冽灰蓝）
- 摄影参数：相机+镜头+焦段+光圈+ISO+RAW，附加"低对比度保留暗部细节"

## 8. 阶段6：分镜 + 镜头提示词

### 8.1 拆分与一致性

## 9. 阶段7：打斗 / 技能特效

### 9.1 打斗节奏
- 打斗即刻启动：进入战斗 ≤1 秒进高潮，禁长时间蓄力/慢镜出场/空镜拖延；每 1-2 秒一次有效碰撞
- 强者高光出场可延长：最终BOSS/神级 8-12 秒，法相虚影 9-12 秒，主角觉醒 5-10 秒；出场结束立即接敌
- 天地异象从第一帧存在并随战斗递进；收尾有能量消散+转场触发事件

### 9.2 动作链速写（高潮段落）
- 连续列动作名，用顿号连接，不加修饰："双刀合劈、左右横斩、同步突刺、交叉绞杀、回旋连斩、凌空双刀下劈"
- 错误："他先出拳，然后踢腿，接着格挡"
- 每段至少 4 个连续动作，高潮 6-8 个；动作链后跟终结动作
- 动词优先库：攻击=劈/斩/切/削/刺/挑/撩/扫/横斩/纵劈/突刺/贯穿；防御=格/挡/架/锁/卸/引/拨/翻腕格挡；移动=蹬/踏/跃/腾/翻/旋/滑/滚/弹射/贴地滑/侧翻；终结=砸/贯/震/压碎/贯穿/湮灭

### 9.3 连贯性铁律
- 武器全程一致（持剑绝不突然变刀/空手；飞剑脱手须有回收）
- 招式连贯：上镜结束动作 = 下镜起始动作（上镜劈下，下镜敌人格挡或被劈中）
- 位置空间：左右方位、距离、被击飞方向一致；换位必须有动作交代
- 伤害递进：轻伤（嘴角血丝/红肿/衣破）→ 中伤（淤青/呼吸变重/动作变慢）→ 重伤（胸前染红/单膝跪/颤抖）→ 终结（被击飞趴伏）；禁止满血复活
- 切镜用动态模糊/残影拖尾/甩镜/同向运动过渡，禁生硬切镜

### 9.4 运镜与力量感
- 运镜丝滑：跟随镜头与角色恒定相对速度；环绕曲线完美；推荐一镜到底
- 高速跟打：连击用"快切-微慢镜-快切"（正常挥击，命中降慢镜0.2秒，立即恢复高速）
- 动态残影：高速移动身后≥3层半透明残影，残影沿轨迹滞后排列（非贴本体），从近到远逐级变淡消散
- 力量感（打击瞬间≥3项）：卡肉停顿1-2帧、强光闪烁、冲击波气环、地面塌陷、镜头震动
- 被击者受力反馈：身体弯折、双脚离地、拖尾倒飞、撞碎障碍物
- 物理反馈优先于光效："腿砸下→对手膝弯→地面炸坑→冲击波"（禁"腿发光→爆炸→人飞了"）

### 9.5 题材氛围（以5.1风格总表为唯一基准）
- **打斗场景的色调/光影/风格全部按5.1风格总表执行**，本节仅补充打斗专属氛围强化
- 5.1中已包含：暗黑魔幻/修真、修仙玄幻、神魔史诗等题材的色调定义，直接使用
- 打斗专属强化：
  - 能量高光：根据题材选择能量色（修仙=金/青/紫，暗黑=血红/幽蓝，科幻=霓虹/电子蓝）
  - 战斗烟雾：尘土/碎石/能量碎屑，增强冲击力
  - 神兽默认暗黑写实（黑神话类），禁卡通/光滑塑料/鲜艳
- **禁止**：本节色调与5.1冲突时，以5.1为准

### 9.6 技能释放（禁瞬间闪现）
五阶段凝聚：①异象预兆0.3-0.5秒 → ②能量汇聚0.5-1秒 → ③结构成型0.5-1秒（骨骼→肌肉→鳞片逐层）→ ④点睛激活0.2-0.3秒（眼睛亮起，短暂静止）→ ⑤完全体爆发0.2-0.3秒（冲击波扩散）
- 大招/禁咒 1.5-2 秒，神兽召唤 2-3 秒（阶段③可延长）
- 施法必须有动作+表情：结印指节颤抖、肌肉绷紧、衣袍无风自鼓、眼神聚焦/瞳孔发光；禁站桩
- 释放后保持战斗姿态，不与神兽亲昵（禁抚摸/倚靠/对视微笑）

### 9.7 神兽（暗黑写实）
- 材质：鳞片每片独立高光+磨损，毛发分叉+次表面散射，眼睛湿润反光，角爪牙金属光泽
- 体型遮天蔽日占画面2/3以上，角色如蝼蚁；低角度仰视；背景压暗至近黑
- 凝聚后主角与神兽形成战斗同盟：同向锁定敌人、动作同步，禁亲昵

### 9.8 输出（打斗）
- 每段标注：景别、运镜模式标签、功能标签（对峙/冲刺/碰撞/闪避/攻防转换/凌空/终结/收势）
- 标注打击点位置（如"打击点：靴底与胸口接触处"）、碰撞等级（轻/重/大招爆发）、环境反馈、人物比例锁定、空间锚点（左右方位+距离+高度）

## 10. MiniMax H3 · Ref2VA 六段式（视频输出必用模板）

> **注意**：以下模板以3个Shot为例，实际每段Shot数量为**2-4个**，根据内容增减。单段总时长=各Shot时长之和，必须在4-15秒范围内。

```
《剧名》分镜脚本 · 全部N段（中文 · AI短剧终版）
MiniMax H3 · Ref2VA 全参考模式 · 每段5-15秒 · 首帧承接版

【段XX】场景·标题（Xs · 台词标注）
参考图清单：图1=…；图2=…；图N=…；音频参考=<Audio N>。

subject_definitions:
<Subject 1> 是 <Picture 1> 中的[角色]，[年龄/面容/发型/服装/体态]。
<Subject 2> 是 <Picture 2> 中的[角色/场景/道具]，[…]。<Audio 1> 是 <Subject 1> (S1) 的音色参考，[音色+情绪+语速]。

summary:
[reference generation + audio reference] [镜头切接概述 + 台词概述]。

retention_analysis:
<Subject 1> (出现在 [Shot 1], [Shot 2]): fully_preserved - [外貌/服装/发型全程保留]。
<Subject 2> (出现在 [Shot 1], [Shot 3]): fully_preserved - […]。
<Audio 1>: reference - 使用 <Audio 1> 的音色与情绪，不复制原声信号。

detailed_description:
目标视频为[5.1选定的风格，如电影感3D国漫/暗黑写实/水墨国风等]，[以光线/气氛/情绪开头]。声音约束：[谁说话、谁闭嘴]。
[Shot 1]（景别·运镜，0-X秒）：[画面+动作+表情+特效，含动态元素"微风拂发、云雾流动、光粒飘散"]。
[Shot 2]（切·景别·运镜，X-X秒）：[…] 以 <Audio 1> 的音色[情绪]说：<Subject 1> (S1)，<d>[中文] 台词内容</d>。
[Shot N]（切·景别·运镜，X-X秒）：[…]。结尾保持0.8-1.2秒作下一段首帧。

overall_soundscape:
[环境音 + 动作音，具体声源]。

non_diegetic_music:
N/A
```

**六段式要点**：
- `subject_definitions`：`<Subject N> 是 <Picture N> 中的…` 锁定每个角色/场景/道具（外貌+服装+发型+体态），音色描述必须与4.3角色卡一致
- `retention_analysis`：逐 Subject 标注出现在哪些 [Shot] + fully_preserved（防"人物变脸/凭空消失"的关键）
- `detailed_description`：`[Shot N]` 用"切"衔接，每镜写清景别/角度/运镜/时间；Shot数量2-4个可变，总时长4-15秒
- 台词：`<Subject N> (Sx)，<d>[中文] 台词</d>`，绑定 `<Audio N>` 音色
- `overall_soundscape`：分层音效；`non_diegetic_music`：一律 N/A（不要背景音乐）
- 风格：`detailed_description`开头的风格描述必须与5.1风格总表一致
- 📚 参考文档：`docs/生成视频提示词格式和示例.txt`

## 12. 执行协议（触发后怎么跑）

1. 先确认输入：用户给的是小说原文 / 题材想法 / 还是指定单环节？
2. 若只要求单环节 → 只跑对应阶段（如"生成男主三视图"只跑角色卡+人物提示词+三视图）
3. 若要求全流程 → 按 **10步** 顺序产出：
   ① 爆款改文（保人称，内容优化）→ ② 转漫剧剧本（转第一人称，画面化）→ ③ 角色卡+音色设定 → ④ 人物+道具提示词（全3D，半身+全身）→ ⑤ 场景清单 → ⑥ 场景提示词（无人纯场景）→ ⑦ 人物三视图 → ⑧ 分镜+镜头提示词 → ⑨ 打斗/技能特效（若有）→ ⑩ MiniMax H3 视频提示词（Ref2VA六段式）
4. 最终视频一律用 Ref2VA 六段式（第10节）
5. 全程遵守第2节全局铁律（合规/一致性/时长/台词/**剧情保真**）
6. **每一步输出后必须做剧情保真自检**：对照原文确认没有剧情节点被遗漏、被合并、被跳过；发现缺漏立即补回
7. 若原著内容量大，主动拆分成多章/多集/多段输出，不要试图塞进固定字数或时长
8. 角色卡和场景清单完成后，与用户确认再进入下一阶段
9. 全片风格以5.1风格总表为唯一基准，所有阶段统一使用
10. 所有输出文件按第13节命名规范命名

示例：用户说"把这段小说做成漫剧" → 依次输出：①爆款改文（保人称，剧情保真）②漫剧剧本（转第一人称，分集，每集标注覆盖原著段落）③角色卡+音色设定（表格，用户确认）④人物提示词（全3D，半身4:3+全身9:16）⑤场景清单（表格，用户确认）⑥场景提示词（无人纯场景）⑦三视图 ⑧分镜脚本（Ref2VA六段式，逐镜核对剧情）⑨打斗/技能（若有）⑩H3出视频参数说明。

## 14. 最终质检清单（交付前逐项检查）

全部内容产出后，交付前逐项核对，全部通过才可交付：

### 剧情保真
- [ ] 对照原文，每个剧情节点都有对应输出，无遗漏/合并/跳过
- [ ] 每集标注了覆盖原著段落范围
- [ ] 支线处理符合规则（相关保留，独立的经用户确认）

### 人物一致性
- [ ] 同一角色五官/发型/服装/体型全程一致
- [ ] 角色提示词基于角色卡生成，无偏差
- [ ] 每个角色音色全片统一，与角色卡设定一致
- [ ] 人物参考图全为3D风格，无真人版混入

### 场景一致性
- [ ] 同一场景前后统一（基于场景清单）
- [ ] 场景提示词无人纯场景，无人影/人名/衣物
- [ ] 时间/天气/光线前后衔接

### 动作与分镜
- [ ] 上镜结尾动作 = 下镜起始动作
- [ ] 每段4-15秒，单段内2-4个Shot
- [ ] 每段结尾留0.8-1.2秒作首帧承接
- [ ] 单镜头台词≤30字，超量已拆分

### 合规
- [ ] 无平台红线内容（血腥/裸露/校园暴力/自残/邪教）
- [ ] 敏感词已用替代词替换
- [ ] 题材风格未被误删（修仙/克苏鲁等正常保留）

### 风格统一
- [ ] 全片风格以5.1风格总表为基准，无中途切换
- [ ] 人物/场景/分镜/H3提示词风格描述一致
- [ ] 11.4电影标签仅作补充，未替代主风格

### 文件管理
- [ ] 所有文件按第13节命名规范命名
- [ ] 文件齐全，无缺失环节
