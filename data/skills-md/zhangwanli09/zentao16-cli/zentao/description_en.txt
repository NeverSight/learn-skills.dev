通过 zentao 命令行（zentao16-cli）读写禅道开源版 16.x 的单据，把禅道上的 Bug、需求、任务梳理成可直接开发的结构化工单；单据类型不等于内容，被提成 Bug 的新需求、优化也按需求处理；信息不清时先起草澄清问题回写禅道，完成后回写解决说明。用户提到禅道/zentao，或说"禅道上指派给我的单子""禅道 123 这个单子写得不清楚帮我梳理"时使用。用户只说"处理 bug 123""看下需求 45""bug 修完了回写一下/关掉"而没提禅道时，只有在能看出团队用的是禅道（对话里提过禅道、项目里有 .zentao/ 目录、可以执行 zentao 命令）时才使用；项目用的是 GitHub Issues、Jira 等其他工具时不要使用。
