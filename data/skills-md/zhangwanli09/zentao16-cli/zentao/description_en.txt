Read and write ZenTao Open Source 16.x tickets via the ZenTao command line (zentao16-cli), organizing Bugs, requirements, and tasks in ZenTao into structured work orders ready for development; the ticket type does not equal the content, and new requirements or optimizations submitted as Bugs are also handled as requirements. When information is unclear, first draft a clarification question and write it back to ZenTao, then after completion write back the resolution description. Use this when the user mentions ZenTao/zentao, or says “the ticket assigned to me on ZenTao” or “ZenTao ticket 123 is unclear, help me sort it out.” If the user only says “process bug 123,” “check requirement 45,” “bug fixed, write back/close” without mentioning ZenTao, use it only when it can be seen that the team uses ZenTao (ZenTao mentioned in conversation, the project has a .zentao/ directory, or a zentao command can be executed); do not use it when the project uses other tools such as GitHub Issues, Jira, etc.
