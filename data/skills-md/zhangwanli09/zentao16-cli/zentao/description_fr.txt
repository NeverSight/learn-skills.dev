Lire et écrire les tickets ZenTao Open Source 16.x via la ligne de commande ZenTao (zentao16-cli), en organisant les bugs, exigences et tâches dans ZenTao en bons de travail structurés prêts pour le développement ; le type de ticket n’est pas égal au contenu, et les nouvelles exigences ou optimisations soumises comme bugs sont également traitées comme exigences. Lorsque l’information n’est pas claire, rédigez d’abord une question de clarification et renvoyez‑la à ZenTao, puis, une fois terminé, rédigez la description de la résolution. Utilisez cela lorsque l’utilisateur mentionne ZenTao/zentao, ou dit « le ticket qui m’est assigné sur ZenTao » ou « le ticket ZenTao 123 n’est pas clair, aidez‑moi à le trier ». Si l’utilisateur ne dit que « traiter le bug 123 », « vérifier l’exigence 45 », « bug corrigé, renvoyer/fermer » sans mentionner ZenTao, utilisez‑le uniquement lorsqu’il est évident que l’équipe utilise ZenTao (ZenTao mentionné dans la conversation, le projet possède un répertoire .zentao/, ou une commande zentao peut être exécutée) ; ne l’utilisez pas lorsque le projet utilise d’autres outils tels que GitHub Issues, Jira, etc.

Veuillez toujours répondre dans la langue de l’utilisateur.
