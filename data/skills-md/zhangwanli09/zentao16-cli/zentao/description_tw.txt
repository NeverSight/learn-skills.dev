透過 ZenTao 指令列工具（zentao16-cli）讀寫 ZenTao Open Source 16.x 票單，將 ZenTao 中的 Bug、需求與任務整理成可直接開發的結構化工作單；票種不等同於內容，且以 Bug 形式提交的新需求或優化也視為需求處理。資訊不明確時，先擬寫澄清問題並回寫至 ZenTao，完成後再回寫解決說明。當使用者提到 ZenTao/zentao，或說「指派給我的 ZenTao 票」或「ZenTao 票號 123 不明，請幫我理清」時使用此規則。若使用者僅說「處理 bug 123」、「檢查需求 45」、「bug 已修復，回寫/關閉」且未提及 ZenTao，僅在能看出團隊使用 ZenTao（對話中提到 ZenTao、專案有 .zentao/ 目錄，或可執行 zentao 指令）時才使用；若專案使用 GitHub Issues、Jira 等其他工具則不要使用。

請始終以使用者的語言回覆。
