ZenTao 명령줄(zentao16-cli)을 통해 ZenTao Open Source 16.x 티켓을 읽고 쓰며, ZenTao의 버그, 요구사항, 작업을 개발 준비가 된 구조화된 작업 주문으로 정리합니다; 티켓 유형이 내용과 동일하지 않으며, 버그로 제출된 새로운 요구사항이나 최적화도 요구사항으로 처리합니다. 정보가 불명확할 경우, 먼저 확인 질문을 초안으로 작성하여 ZenTao에 다시 기록하고, 완료 후에는 해결 설명을 다시 작성합니다. 사용자가 ZenTao/zentao를 언급하거나 “ZenTao에 할당된 티켓” 혹은 “ZenTao 티켓 123이 불명확합니다, 정리해 주세요”라고 말할 때 이를 사용합니다. 사용자가 “버그 123 처리”, “요구사항 45 확인”, “버그 수정, 회신/닫기” 등 ZenTao를 언급하지 않고 말할 경우, 팀이 ZenTao를 사용하는 것이 확인될 때만(대화 중 ZenTao 언급, 프로젝트에 .zentao/ 디렉터리 존재, 혹은 zentao 명령 실행 가능) 사용하고, GitHub Issues, Jira 등 다른 도구를 사용하는 경우에는 사용하지 마십시오.
