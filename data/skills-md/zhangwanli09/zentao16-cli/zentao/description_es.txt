Lea y escriba tickets de ZenTao Open Source 16.x mediante la línea de comandos de ZenTao (zentao16-cli), organizando errores, requisitos y tareas en ZenTao en órdenes de trabajo estructuradas listas para el desarrollo; el tipo de ticket no equivale al contenido, y los nuevos requisitos u optimizaciones enviados como errores también se gestionan como requisitos. Cuando la información no sea clara, redacte primero una pregunta de aclaración y envíela de regreso a ZenTao; luego, una vez completado, escriba de vuelta la descripción de la resolución. Use esto cuando el usuario mencione ZenTao/zentao, o diga “el ticket asignado a mí en ZenTao” o “el ticket 123 de ZenTao no está claro, ayúdame a resolverlo”. Si el usuario solo dice “procesar error 123”, “verificar requisito 45”, “error corregido, registrar/cerrar” sin mencionar ZenTao, utilícelo solo cuando se pueda observar que el equipo usa ZenTao (ZenTao mencionado en la conversación, el proyecto tiene un directorio .zentao/ o se puede ejecutar un comando zentao); no lo use cuando el proyecto emplee otras herramientas como GitHub Issues, Jira, etc.

Por favor, responda siempre en el idioma del usuario.
