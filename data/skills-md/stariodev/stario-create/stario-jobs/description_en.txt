Slow work in a Stario app - a report, a model call, a download, an import - as a job that a command queues and a task runs while the page shows queued, running, and done. Use when a button starts work that takes seconds, when several jobs may run at once, when the page must update by itself while the work runs, when a job must stop cleanly on shutdown or survive a restart, or when a loop runs on a timer.
