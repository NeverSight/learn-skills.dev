Bedienen Sie Orca‑verwaltete Worktrees, Ordnerkontexte, Terminals, Repos, Automatisierungen, Artefakte, Skill‑Sharing, Worktree‑Kommentare und Orcas eingebetteten Browser über die `orca`‑CLI. Verwenden Sie das, wenn der Benutzer sagt „$orca-cli“, „Orca worktree“, „child worktree“, „spawn codex/claude in a worktree“, „read/wait/send Orca terminal“, „handoff“ / „handover“ / „give this to another agent“, „Orca browser“, „orca artifacts“ oder „share skills“. Bevorzugen Sie es gegenüber rohem git worktree, ad‑hoc PTYs oder Computer Use, wenn Orca‑Zustand involviert ist. Nutzen Sie Computer Use nur, wenn ein sichtbares Fenster GUI‑Steuerung erfordert, die ein CLI, das Dateisystem oder eine API nicht leisten kann.

Bitte antworten Sie immer in der Sprache des Benutzers.
