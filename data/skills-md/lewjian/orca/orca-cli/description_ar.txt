تشغيل شجرة العمل المُدارة بواسطة Orca، وسياقات المجلدات، والطرفيات، والمستودعات، والأتمتة، والقطع الأثرية، ومشاركة المهارات، وتعليقات شجرة العمل، ومتصفح Orca المدمج عبر سطر الأوامر `orca`. استخدم ذلك عندما يقول المستخدم "$orca-cli"، "Orca worktree"، "child worktree"، "spawn codex/claude in a worktree"، "read/wait/send Orca terminal"، "handoff" / "handover" / "give this to another agent"، "Orca browser"، "orca artifacts"، أو "share skills". فضل ذلك على شجرة git العادية، أو PTYs المؤقتة، أو الاستخدام الحاسوبي عندما تكون حالة Orca معنية. استخدم الاستخدام الحاسوبي فقط عندما تحتاج نافذة مرئية إلى تحكم واجهة رسومية لا يمكن لسطر الأوامر أو نظام الملفات أو API إنجازه.
