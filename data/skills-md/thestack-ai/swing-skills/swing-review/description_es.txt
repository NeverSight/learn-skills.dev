Pruebas de estrés de abogado del diablo para código, arquitectura, pull requests y decisiones. Detecta defectos ocultos mediante un análisis adversarial estructurado con profundidad metacognitiva. Úsalo para revisiones de alto riesgo, pruebas de estrés de decisiones o cuando el usuario quiere que se encuentren problemas deliberadamente. NO es para revisiones de código rutinarias.
