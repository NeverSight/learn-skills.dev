Test de résistance de l’avocat du diable pour le code, l’architecture, les PR et les décisions. Met en évidence les défauts cachés grâce à une analyse adverse structurée avec une profondeur métacognitive. À utiliser pour des revues à enjeu élevé, des tests de résistance des choix, ou lorsque l’utilisateur veut que des problèmes soient délibérément découverts. PAS pour la revue de code de routine.
