Poussez la branche actuelle et ouvrez une pull request (génère automatiquement le titre / le corps à partir des commits et lie le ticket suivi à partir du nom de la branche). Utilisez‑le lorsque l'utilisateur demande de pousser, d'ouvrir ou de créer une PR, ou de partager la branche. Le texte d’invocation peut être le mot unique « commit » pour valider d’abord sans demander.

Veuillez toujours répondre dans la langue de l'utilisateur.
