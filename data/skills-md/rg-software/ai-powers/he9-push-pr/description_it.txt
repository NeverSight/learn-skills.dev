Esegui il push del branch corrente e apri una pull request (crea automaticamente titolo e corpo dai commit e collega il ticket tracciato dal nome del branch). Usa quando l'utente chiede di fare push, aprire o creare una PR, o condividere il branch. Il testo di invocazione può essere la singola parola “commit” per eseguire il commit prima senza richiedere conferma.

Rispondi sempre nella lingua dell'utente.
