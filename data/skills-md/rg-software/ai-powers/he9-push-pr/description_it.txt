Spingi il ramo corrente e apri una pull request (crea automaticamente titolo e corpo dal commit e collega il problema tracciato dal nome del ramo). Usa quando l'utente chiede di pushare, aprire o creare una PR, o condividere il ramo. Il testo di invocazione può essere la singola parola “commit” per eseguire il commit prima senza richiedere conferma. Per favore rispondi sempre nella lingua dell'utente.
