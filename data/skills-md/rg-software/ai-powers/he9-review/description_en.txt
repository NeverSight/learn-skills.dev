Code review / respond cycle - review a target locally (branch, uncommitted work, a commit, a range), or respond to the latest review on a PR. Use when the user asks for a review, or to respond to review feedback on a PR. Invocation text is the review target: 'branch' (default), 'worktree', 'staged', 'commit', 'range A..B', 'path p', or 'respond [PR]'.
