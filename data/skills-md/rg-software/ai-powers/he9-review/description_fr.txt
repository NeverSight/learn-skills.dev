Cycle de révision de code / réponse - examiner une cible localement (branche, travail non committé, un commit, une plage), ou répondre à la dernière révision d’une PR. À utiliser lorsque l’utilisateur demande une révision, ou pour répondre aux commentaires de révision sur une PR. Le texte d’invocation est la cible de la révision : « branch » (par défaut), « worktree », « staged », « commit », « range A..B », « path p », ou « respond [PR] ». Veuillez toujours répondre dans la langue de l’utilisateur.
