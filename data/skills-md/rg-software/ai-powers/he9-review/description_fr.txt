Cycle de révision / réponse – examiner une cible localement (branche, travail non commité, un commit, une plage), ou répondre à la dernière révision d’une PR. Utiliser lorsque l’utilisateur demande une révision, ou pour répondre aux retours de révision sur une PR. Le texte d’invocation est la cible de révision : « branch » (par défaut), « worktree », « staged », « commit », « range A..B », « path p », ou « respond [PR] ».
