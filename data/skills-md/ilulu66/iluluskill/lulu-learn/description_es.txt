Living Room skill (iluluskill) · Entrada principal de la serie Learning Workshop — convertir conferencias/cursos/talleres/libros en recursos de aprendizaje que se pueden volver a consultar. Palabras desencadenantes: living room skill / lecture organization / lecture sorting / organize lecture / class listening organization / learning workshop / lulu-learn. Se utiliza cuando los usuarios proporcionan un enlace de reunión, una grabación, una transcripción, dicen “Quiero asistir a una conferencia,” o no están seguros de qué sub‑habilidad de lulu‑learn usar.
