Use when writing, debugging, or reviewing shaders for the web — GLSL or WGSL, raw WebGL2/WebGPU, Three.js (ShaderMaterial/RawShaderMaterial/TSL), or React Three Fiber. Covers the language/platform matrix, correct boilerplate, common effects (SDF/raymarching, noise, post-processing), and the pitfalls that make browser shaders fail silently.
