Ejecuta, configura y depura Floci, los emuladores locales gratuitos para AWS (floci), GCP (floci-gcp), Azure (floci-az) y OCI (floci-oci), controlados mediante floci‑cli, docker run o Docker Compose. Úsalo cuando el usuario quiera ejecutar código o pruebas en la nube localmente, mencione floci, localhost:4566/4577/4588/4599, una alternativa a LocalStack o Azurite, S3/DynamoDB/Pub/Sub/Blob/Almacenamiento de objetos local, y solicite un docker‑compose.yml o compose.yaml con un emulador de nube, espacios de nombres de emuladores o varias instancias de emuladores lado a lado.
