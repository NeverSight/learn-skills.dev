Запустите, настройте и устраните неполадки Floci, бесплатных локальных эмуляторов для AWS (floci), GCP (floci‑gcp), Azure (floci‑az) и OCI (floci‑oci), управляемых через floci‑cli, docker run или Docker Compose. Используйте, когда пользователь хочет запускать облачный код или тесты локально, упоминает floci, localhost:4566/4577/4588/4599, альтернативу LocalStack или Azurite, локальные S3/DynamoDB/Pub/Sub/Blob/Object Storage, и запрашивает docker‑compose.yml или compose.yaml с облачным эмулятором, пространствами имён эмуляторов или несколькими экземплярами эмуляторов рядом.
