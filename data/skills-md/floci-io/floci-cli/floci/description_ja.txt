Floci（AWS 用 floci、GCP 用 floci-gcp、Azure 用 floci-az、OCI 用 floci-oci といった無料のローカルエミュレータ）を実行、接続、トラブルシューティングしてください。floci-cli、docker run、または Docker Composeで駆動します。ユーザーがクラウドコードやテストをローカルで実行したい場合、flociや localhost:4566/4577/4588/4599、LocalStack や Azurite の代替、ローカルの S3/DynamoDB/Pub/Sub/Blob/Object Storage などに言及し、クラウドエミュレータを含む docker-compose.yml または compose.yaml、エミュレータの名前空間、あるいは複数のエミュレータインスタンスを横に並べて使用したいときに使用します。必ずユーザーの言語で回答してください。
