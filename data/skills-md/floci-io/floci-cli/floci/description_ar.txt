قم بتشغيل وربط ومعالجة الأخطاء في Floci، وهي محاكيات محلية مجانية لـ AWS (floci)، و GCP (floci-gcp)، و Azure (floci-az) و OCI (floci-oci)، وتعمل عبر floci‑cli أو ‎docker run أو Docker Compose. استخدمها عندما يرغب المستخدم في تشغيل شفرة السحابة أو الاختبارات محليًا، ويذكر Floci، localhost:4566/4577/4588/4599، كبديل عن LocalStack أو Azurite، أو تخزين S3/DynamoDB/Pub/Sub/Blob/Object محليًا، ويطلب ملف docker‑compose.yml أو compose.yaml يحتوي على محاكي سحابي، أو مساحات أسماء للمحاكي، أو عدة نسخ من المحاكي جنبًا إلى جنب.
