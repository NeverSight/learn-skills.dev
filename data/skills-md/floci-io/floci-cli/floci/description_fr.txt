Exécutez, configurez et dépannez Floci, les émulateurs locaux gratuits pour AWS (floci), GCP (floci‑gcp), Azure (floci‑az) et OCI (floci‑oci), pilotés par floci‑cli, docker run ou Docker Compose. Utilisez‑le lorsque l’utilisateur veut exécuter du code cloud ou des tests en local, mentionne floci, localhost :4566/4577/4588/4599, une alternative à LocalStack ou Azurite, le stockage local S3/DynamoDB/Pub/Sub/Blob/Object Storage, et demande un docker‑compose.yml ou compose.yaml avec un émulateur cloud, des espaces de noms d’émulateur ou plusieurs instances d’émulateur côte à côte.
