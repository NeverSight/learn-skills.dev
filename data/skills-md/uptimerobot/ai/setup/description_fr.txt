Connectez‑vous et authentifiez le serveur UptimeRobot MCP (OAuth via mcp‑remote), OU diagnostiquez pourquoi les outils MCP `uptimerobot:*` ne sont pas visibles dans la session actuelle. Activez cette fonction chaque fois que vous ne voyez pas les outils UptimeRobot, avant d’informer l’utilisateur que le MCP est mal configuré — L’étape 0 détecte le cas le plus fréquent (serveur déjà connecté, outils chargés après le démarrage de la session) et le résout sans ré‑authentification. Activez‑la également sur les erreurs d’authentification `-31001` ou lors de la première configuration.

Veuillez toujours répondre dans la langue de l’utilisateur.
