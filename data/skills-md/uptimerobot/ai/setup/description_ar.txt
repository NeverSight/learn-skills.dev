الاتصال وتوثيق خادم UptimeRobot MCP (OAuth عبر mcp-remote)، أو تشخيص سبب عدم ظهور أدوات MCP `uptimerobot:*` في الجلسة الحالية. استدعِ هذه المهارة في أي وقت لا تستطيع فيه رؤية أدوات UptimeRobot، قبل أن تخبر المستخدم بأن MCP غير مُكوَّن — يكتشف الخطوة 0 الحالة الأكثر شيوعًا (الخادم متصل بالفعل، وتم تحميل الأدوات بعد بدء الجلسة) ويحله دون إعادة التوثيق. استدعِها أيضًا عند حدوث أخطاء مصادقة `-31001` أو عند الإعداد لأول مرة.
