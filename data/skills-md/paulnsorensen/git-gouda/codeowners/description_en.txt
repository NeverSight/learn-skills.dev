Author, validate, and enforce a CODEOWNERS file: detect an existing file, gather ownership evidence from directory structure and git history, write or update rules with correct CODEOWNERS syntax, validate the file against the GitHub API, and wire the ruleset rule that requires code owner review on pull requests. Use when the user says "add CODEOWNERS", "who owns this path", "require owner review", "validate CODEOWNERS", or invokes /codeowners. Idempotent — safe to re-run; diffs before overwriting and never auto-assigns an owner without confirmation. Do NOT use for branch rulesets in general (use /gh-bootstrap) or community health files such as README, LICENSE, CODE_OF_CONDUCT, and SECURITY (use /oss-hygiene) — this skill only covers the CODEOWNERS file and the review rule it feeds.
