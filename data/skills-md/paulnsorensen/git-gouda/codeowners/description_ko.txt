작성자, CODEOWNERS 파일을 검증하고 적용하세요: 기존 파일을 감지하고, 디렉터리 구조와 Git 기록에서 소유권 증거를 수집하며, 올바른 CODEOWNERS 구문으로 규칙을 작성하거나 업데이트하고, GitHub API를 사용해 파일을 검증하며, 풀 리퀘스트에 코드 소유자 검토를 요구하는 규칙 세트를 연결합니다. 사용자는 “add CODEOWNERS”, “who owns this path”, “require owner review”, “validate CODEOWNERS”라고 말하거나 /codeowners를 호출할 때 이 기능을 사용합니다. 멱등성 유지 — 재실행해도 안전하고, 덮어쓰기 전 차이를 보여주며 확인 없이 소유자를 자동 지정하지 않습니다. 일반적인 브랜치 규칙 세트에는 사용하지 마세요(대신 /gh-bootstrap 사용) 또는 README, LICENSE, CODE_OF_CONDUCT, SECURITY와 같은 커뮤니티 헬스 파일에는 사용하지 마세요(대신 /oss-hygiene 사용) — 이 스킬은 CODEOWNERS 파일과 해당 파일이 연결하는 검토 규칙만을 다룹니다.
