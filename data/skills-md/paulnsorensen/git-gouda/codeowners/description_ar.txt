المؤلف، التحقق، وتطبيق ملف CODEOWNERS: اكتشاف ملف موجود، جمع دليل الملكية من بنية الدليل وتاريخ git، كتابة أو تحديث القواعد باستخدام صيغة CODEOWNERS الصحيحة، التحقق من صحة الملف عبر GitHub API، وربط قاعدة مجموعة القواعد التي تتطلب مراجعة مالك الشيفرة على طلبات السحب. استخدم عندما يقول المستخدم "add CODEOWNERS"، "who owns this path"، "require owner review"، "validate CODEOWNERS"، أو يستدعي /codeowners. متماسك — آمن لإعادة التشغيل؛ إظهار الفروقات قبل الكتابة فوق ولا يعيّن مالكًا تلقائيًا دون تأكيد. لا تستخدم لقواعد الفروع بشكل عام (استخدم /gh-bootstrap) أو لملفات صحة المجتمع مثل README، LICENSE، CODE_OF_CONDUCT، وSECURITY (استخدم /oss-hygiene) — هذه المهارة تغطي فقط ملف CODEOWNERS وقاعدة المراجعة التي يغذيها.
