Создавать, проверять и применять файл CODEOWNERS: обнаруживать существующий файл, собирать доказательства владения из структуры каталогов и истории Git, писать или обновлять правила с правильным синтаксисом CODEOWNERS, проверять файл через API GitHub и подключать правило набора правил, требующее проверку владельцем кода при запросах на слияние. Использовать, когда пользователь говорит «add CODEOWNERS», «who owns this path», «require owner review», «validate CODEOWNERS» или вызывает /codeowners. Идемпотентно — безопасно запускать повторно; показывать различия перед перезаписью и никогда не назначать владельца автоматически без подтверждения. НЕ использовать для правил веток в целом (используйте /gh-bootstrap) или файлов общественного здоровья, таких как README, LICENSE, CODE_OF_CONDUCT и SECURITY (используйте /oss-hygiene) — эта функция охватывает только файл CODEOWNERS и правило проверки, которое он обслуживает.

Пожалуйста, всегда отвечайте на языке пользователя.
