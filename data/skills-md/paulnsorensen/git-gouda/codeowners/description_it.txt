Autore, valida e applica un file CODEOWNERS: rileva un file esistente, raccogli le prove di proprietà dalla struttura delle directory e dalla cronologia Git, scrivi o aggiorna le regole con la sintassi corretta di CODEOWNERS, valida il file tramite l'API di GitHub e collega la regola del ruleset che richiede la revisione del proprietario del codice nelle pull request. Usa quando l'utente dice "add CODEOWNERS", "who owns this path", "require owner review", "validate CODEOWNERS", o invoca /codeowners. Idempotente — sicuro da rieseguire; mostra i diff prima di sovrascrivere e non assegna mai automaticamente un proprietario senza conferma. NON utilizzare per regole di branch in generale (usa /gh-bootstrap) o per file di salute della comunità come README, LICENSE, CODE_OF_CONDUCT e SECURITY (usa /oss-hygiene) — questa capacità copre solo il file CODEOWNERS e la regola di revisione a cui si collega.
