CODEOWNERS ファイルを作成、検証、適用する：既存のファイルを検出し、ディレクトリ構造と git 履歴から所有権の証拠を収集し、正しい CODEOWNERS 構文でルールを書き込むか更新し、GitHub API でファイルを検証し、プルリクエストでコードオーナーのレビューを必須とするルールセットルールを接続する。ユーザーが「add CODEOWNERS」「who owns this path」「require owner review」「validate CODEOWNERS」と言ったり /codeowners を呼び出したときに使用する。冪等性があり、再実行しても安全です；上書き前に差分を表示し、確認なしに所有者を自動割り当てしません。ブランチのルールセット全般には使用しないでください（/gh-bootstrap を使用）または README、LICENSE、CODE_OF_CONDUCT、SECURITY などのコミュニティヘルスファイル（/oss-hygiene を使用）にも使用しないでください — このスキルは CODEOWNERS ファイルとそれが提供するレビュー規則のみを対象とします。
