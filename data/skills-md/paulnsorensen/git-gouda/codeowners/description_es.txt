Crea, valida y aplica un archivo CODEOWNERS: detecta un archivo existente, recopila evidencia de propiedad a partir de la estructura de directorios y el historial de git, escribe o actualiza reglas con la sintaxis correcta de CODEOWNERS, valida el archivo mediante la API de GitHub y conecta la regla del conjunto de reglas que exige la revisión del propietario del código en los pull requests. Úsalo cuando el usuario diga “add CODEOWNERS”, “who owns this path”, “require owner review”, “validate CODEOWNERS”, o invoque /codeowners. Idempotente: seguro de volver a ejecutar; muestra diffs antes de sobrescribir y nunca asigna automáticamente un propietario sin confirmación. NO lo uses para conjuntos de reglas de rama en general (usa /gh-bootstrap) ni para archivos de salud comunitaria como README, LICENSE, CODE_OF_CONDUCT y SECURITY (usa /oss-hygiene); esta habilidad solo cubre el archivo CODEOWNERS y la regla de revisión que lo alimenta.

Por favor, responde siempre en el idioma del usuario.
