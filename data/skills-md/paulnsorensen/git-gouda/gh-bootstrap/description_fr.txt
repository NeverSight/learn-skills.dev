Configuration ponctuelle d’un dépôt GitHub via le CLI `gh` : verrouiller la branche par défaut avec des règles PR et CI, éventuellement activer une file d’attente de fusion prise en charge, restreindre la fusion à « squash‑only » avec des messages de commit basés sur le titre de la PR, générer automatiquement les notes de version (`.github/release.yml`), et éventuellement ajouter un workflow de publication basé sur les tags. À utiliser lorsque l’utilisateur dit « set up the repo », « configure the merge queue », « enable squash merging », « lock down main », « set up branch protection », « configure release notes », « scaffold releases », « set up release tagging », ou invoque /gh-bootstrap sur un dépôt GitHub neuf ou mal configuré. Idempotent — sûr à réexécuter sur des dépôts déjà configurés pour mettre en conformité les éléments manquants. Cette compétence couvre la politique de dépôt ponctuelle, pas les opérations GitHub par tâche, les commandes git locales ou l’exécution de tâches de projet.
