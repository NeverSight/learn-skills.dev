Einstellungsweise GitHub-Repository-Konfiguration über das `gh`‑CLI: Sperre den Standard‑Branch mit PR‑ und CI‑Regeln, aktiviere optional eine unterstützte Merge‑Queue, beschränke das Mergen auf Squash‑Only mit Commit‑Nachrichten aus dem PR‑Titel, erstelle automatisch generierte Release‑Notes (`.github/release.yml`) und füge optional einen tag‑basierten Release‑Workflow hinzu. Verwenden, wenn der Benutzer sagt „set up the repo“, „configure the merge queue“, „enable squash merging“, „lock down main“, „set up branch protection“, „configure release notes“, „scaffold releases“, „set up release tagging“ oder /gh‑bootstrap auf einem frischen oder lose konfigurierten GitHub‑Repository aufruft. Idempotent – sicher, erneut auszuführen bei bereits konfigurierten Repos, um fehlende Elemente anzupassen. Diese Fähigkeit deckt einmalige Repository‑Richtlinien ab, nicht per‑Task GitHub‑Operationen, lokale Git‑Befehle oder das Ausführen von Projektaufgaben.
