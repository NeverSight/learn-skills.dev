一次性透過 `gh` CLI 設定 GitHub 倉庫：以 PR 與 CI 規則鎖定預設分支，必要時啟用支援的合併佇列，將合併限定為僅使用 squash 且提交訊息取自 PR 標題，自動產生發行說明（`.github/release.yml`）的腳手架，並可選擇加入以標籤為驅動的發行工作流程。當使用者說「set up the repo」「configure the merge queue」「enable squash merging」「lock down main」「set up branch protection」「configure release notes」「scaffold releases」「set up release tagging」或在全新或尚未完整設定的 GitHub 倉庫上呼叫 `/gh-bootstrap` 時使用。具備冪等性——可安全地在已設定的倉庫上再次執行，以補齊缺失的部分。此技能僅涵蓋一次性的倉庫政策設定，不涉及每項任務的 GitHub 操作、本機 git 指令或專案任務執行。
