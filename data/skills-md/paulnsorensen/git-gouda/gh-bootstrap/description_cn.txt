一次性通过 `gh` CLI 配置 GitHub 仓库：使用 PR 与 CI 规则锁定默认分支，可选启用受支持的合并队列，锁定仅使用 squash 合并并采用 PR 标题作为提交信息，自动生成发布说明（`.github/release.yml`），以及可选添加基于标签的发布工作流。当用户说“设置仓库”、“配置合并队列”、“启用 squash 合并”、“锁定 main 分支”、“设置分支保护”、“配置发布说明”、“搭建发布流程”、“设置发布标签”，或在全新或配置较松散的 GitHub 仓库上调用 /gh‑bootstrap 时使用。具备幂等性——可安全地在已配置的仓库上重新运行，以补全缺失的部分。本技能针对一次性仓库策略，而非每次任务的 GitHub 操作、本地 git 命令或项目任务执行。
