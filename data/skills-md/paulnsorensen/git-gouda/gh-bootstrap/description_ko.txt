`gh` CLI를 사용한 일회성 GitHub 저장소 설정: 기본 브랜치를 PR 및 CI 규칙으로 잠그고, 선택적으로 지원되는 병합 대기열을 활성화하며, PR 제목 커밋 메시지를 사용한 스쿼시 전용 병합을 제한하고, 자동 생성 릴리스 노트(`.github/release.yml`)를 스캐폴딩하며, 필요에 따라 태그 기반 릴리스 워크플로를 추가합니다. 사용자가 “set up the repo”, “configure the merge queue”, “enable squash merging”, “lock down main”, “set up branch protection”, “configure release notes”, “scaffold releases”, “set up release tagging”이라고 말하거나 새롭거나 설정이 미비한 GitHub 저장소에서 `/gh-bootstrap`을 호출할 때 사용합니다. 멱등성을 갖추어 이미 구성된 리포에도 다시 실행해 누락된 부분만 보완할 수 있습니다. 이 스킬은 일회성 저장소 정책을 다루며, 작업별 GitHub 운영, 로컬 git 명령, 프로젝트 작업 실행은 포함하지 않습니다.
