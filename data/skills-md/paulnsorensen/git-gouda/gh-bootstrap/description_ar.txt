تهيئة مستودع GitHub مرة واحدة عبر أداة سطر الأوامر `gh`: قفل الفرع الافتراضي باستخدام قواعد طلب السحب (PR) وCI، وتمكين قائمة انتظار دمج مدعومة اختياريًا، قفل الدمج ليكون فقط سكوَش مع رسائل التزام من عنوان طلب السحب، إنشاء ملاحظات إصدار تلقائية (`.github/release.yml`)، وإضافة سير عمل إصدار يعتمد على الوسوم اختياريًا. يُستَخدم عندما يقول المستخدم "إعداد المستودع"، "تهيئة قائمة انتظار الدمج"، "تمكين دمج السكوَش"، "قفل الفرع الرئيسي"، "إعداد حماية الفروع"، "تهيئة ملاحظات الإصدار"، "إنشاء إصدارات مبدئية"، "إعداد وسم الإصدار"، أو يستدعي /gh-bootstrap على مستودع GitHub جديد أو مُكوَّن بشكل فضفاض. غير متكرر — آمن لإعادة التشغيل على المستودعات المُكوَّنة مسبقًا لتحديث الأجزاء المفقودة. هذه المهارة تغطي سياسة المستودع لمرة واحدة، ولا تشمل عمليات GitHub اليومية، أو أوامر git المحلية، أو تشغيل مهام المشروع.
