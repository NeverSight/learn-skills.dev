Одноразовая настройка репозитория GitHub через CLI `gh`: блокировка основной ветки с правилами PR и CI, при желании включение поддерживаемой очереди слияний, ограничение слияний только до squash‑слияния с сообщениями коммитов, взятыми из заголовков PR, автоматическое создание шаблона заметок к выпуску (`.github/release.yml`) и, при необходимости, добавление workflow выпуска, управляемого тегами. Используется, когда пользователь говорит «настроить репозиторий», «настроить очередь слияний», «включить squash‑слияние», «запереть main», «защитить ветку», «настроить заметки к выпуску», «создать шаблон релизов», «настроить теги выпуска» или вызывает `/gh-bootstrap` в новом или слабо сконфигурированном репозитории GitHub. Идемпотентно — безопасно пере запускать на уже настроенных репозиториях, чтобы добавить недостающие компоненты. Этот навык охватывает одноразовую политику репозитория, а не отдельные операции GitHub, локальные команды git или запуск задач проекта.
