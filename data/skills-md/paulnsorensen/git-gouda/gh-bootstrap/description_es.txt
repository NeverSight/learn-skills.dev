Configuración única de un repositorio GitHub mediante la CLI `gh`: bloquear la rama predeterminada con reglas de PR y CI, opcionalmente habilitar una cola de merge soportada, bloquear el merge a solo squash con mensajes de commit basados en el título del PR, generar automáticamente notas de lanzamiento (`.github/release.yml`) y, opcionalmente, añadir un flujo de trabajo de lanzamiento impulsado por etiquetas. Utilízala cuando el usuario diga "set up the repo", "configure the merge queue", "enable squash merging", "lock down main", "set up branch protection", "configure release notes", "scaffold releases", "set up release tagging", o invoque /gh‑bootstrap en un repositorio GitHub nuevo o poco configurado. Idempotente — segura de re‑ejecutar en repositorios ya configurados para alinear los elementos faltantes. Esta habilidad cubre la política de repositorio única, no operaciones de GitHub por tarea, comandos locales de git o ejecución de tareas del proyecto.
