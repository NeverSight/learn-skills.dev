Configurazione una tantum del repository GitHub tramite la CLI `gh`: blocca il branch predefinito con regole PR e CI, abilita facoltativamente una coda di merge supportata, vincola il merge a squash‑only con messaggi di commit basati sul titolo della PR, genera scaffolding per note di rilascio automatiche (`.github/release.yml`) e, opzionalmente, aggiunge un workflow di rilascio guidato da tag. Usa quando l'utente dice "set up the repo", "configure the merge queue", "enable squash merging", "lock down main", "set up branch protection", "configure release notes", "scaffold releases", "set up release tagging", oppure invoca /gh-bootstrap su un repository GitHub nuovo o configurato superficialmente. Idempotente — sicuro da rieseguire su repository già configurati per allineare gli elementi mancanti. Questa skill copre la politica del repository una tantum, non operazioni GitHub per attività specifiche, comandi git locali o esecuzione di task di progetto.
