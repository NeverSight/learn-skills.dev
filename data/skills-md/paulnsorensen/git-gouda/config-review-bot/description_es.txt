Auditar o configurar la política de revisión del repositorio CodeRabbit a partir de fuentes efectivas. Utilizar para la configuración de CodeRabbit, revisión de la configuración, cobertura de rutas o una auditoría de revisión de una solicitud de extracción específica. Activar con "configure CodeRabbit", "review .coderabbit.yaml", "set up CodeRabbit", "audit CodeRabbit settings" o "is CodeRabbit covering X". Mantener las auditorías en modo de solo lectura por defecto y separar la validez del esquema, la calidad de las reglas y la evidencia de revisión completada. No usarlo para ejecutar una revisión CLI de CodeRabbit o autocorrección, ni para solucionar comentarios de revisión en una solicitud de extracción.
