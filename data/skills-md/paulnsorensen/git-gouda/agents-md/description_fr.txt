Créez, auditez ou taillez AGENTS.md et ses miroirs de harnais (CLAUDE.md, GEMINI.md, .github/copilot‑instructions.md, .cursor/rules) afin que les commandes de construction/test restent précises et que le fichier reste sous la limite de taille de chaque harnais. Utilisez cela lorsque l'utilisateur dit « create AGENTS.md », « audit AGENTS.md », « trim AGENTS.md », « AGENTS.md is stale », « CLAUDE.md drift », « agent instructions hygiene » ou invoque /agents‑md. Cela couvre les AGENTS.md imbriqués pour les packages monorepo, la priorité du fichier le plus proche, et le script de mesure intégré scripts/agents_md_check.py. NE PAS l’utiliser pour la rédaction de `.github/copilot‑instructions.md` ou la configuration de révision de code Copilot — c’est /github‑copilot‑repo‑instructions. NE PAS l’utiliser pour les fichiers d’instructions personnels, par‑utilisateur ou globaux à la machine (`~/.claude/CLAUDE.md`, instructions personnelles Copilot) — ceux‑ci sont hors du périmètre de cette compétence centrée sur le dépôt. Veuillez toujours répondre dans la langue de l'utilisateur.
