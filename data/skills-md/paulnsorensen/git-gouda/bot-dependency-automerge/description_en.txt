Audits a repository's dependency bot and arms GitHub auto-merge on Dependabot or Renovate minor and patch PRs when they open, with majors left to a human. Supports GitHub merge queues and hands PRs to Mergify, Kodiak, Trunk, or Aviator queues. Use when the user says "auto-merge dependabot", "automerge renovate minor and patch", "dependabot PRs never merge", "set up bot dependency auto-merge", "audit dependency bot auto-merge", or invokes /bot-dependency-automerge. Do NOT use to create a first dependabot.yml (/oss-hygiene), to change rulesets or merge settings (/gh-bootstrap), or for an org-wide rollout (/safe-settings).
