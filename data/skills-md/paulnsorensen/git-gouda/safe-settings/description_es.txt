Configura `safe-settings` de GitHub (una aplicación GitHub basada en Probot de la organización github) para una política declarativa de repositorios a nivel de organización como código. Úsalo cuando el usuario diga "settings as code", "safe-settings", "manage repos declaratively", "centralize repo settings", "org-level branch protection", "scaffold an admin repo", "github settings app", o invoque /safe-settings en una organización que quiera gestionar la configuración de repositorios, protección de ramas, reglas, etiquetas, equipos, entornos y colaboradores desde un único repo de administración. Genera la estructura del repo admin (`settings.yml` + `suborgs/` + `repos/`), los pasos de instalación de la aplicación GitHub y un workflow programado de GitHub Actions `full-sync`. Es distinto de /gh-bootstrap (configuración única con `gh api` de un solo repo); esta habilidad es para **configuraciones como código a escala de organización** que se reconcilian continuamente. No sirve para operaciones puntuales de GitHub (PRs, issues, estado de CI) ni para trabajo local con git — eso está fuera del alcance de este catálogo.
