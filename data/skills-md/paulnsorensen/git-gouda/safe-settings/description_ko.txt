GitHub의 `safe-settings`(github 조직의 Probot 기반 GitHub App)를 설정하여 선언형, 조직 전체 레포지토리 정책을 코드로 관리합니다. 사용자는 “settings as code”, “safe-settings”, “manage repos declaratively”, “centralize repo settings”, “org-level branch protection”, “scaffold an admin repo”, “github settings app” 등을 언급하거나, 레포지토리 설정, 브랜치 보호, ruleset, 라벨, 팀, 환경, 협업자를 하나의 관리 레포에서 관리하고자 하는 조직에서 `/safe-settings` 명령을 호출할 때 사용합니다. 관리 레포 레이아웃(`settings.yml` + `suborgs/` + `repos/`), GitHub App 설치 단계, 그리고 정기적인 `full-sync` GitHub Actions 워크플로우를 자동으로 scaffold 합니다. 이는 단일 레포를 `gh api` 로 일회성 구성하는 `/gh-bootstrap`과 구별되는 것으로, **조직 규모의 설정을 코드로 지속적으로 조정**하는 데 초점을 맞춥니다. 개별 작업용 GitHub 운영(프루, 이슈, CI 상태)이나 로컬 git 작업은 이 카탈로그의 범위에 포함되지 않습니다.
