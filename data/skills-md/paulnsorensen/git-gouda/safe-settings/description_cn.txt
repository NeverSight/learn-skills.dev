设置 GitHub 的 `safe-settings`（github 组织提供的基于 Probot 的 GitHub 应用），用于以声明式方式在组织范围内管理仓库策略代码化。当用户提到 “settings as code”、​“safe-settings”、​“manage repos declaratively”、​“centralize repo settings”、​“org-level branch protection”、​“scaffold an admin repo”、​“github settings app”，或在希望通过单一管理仓库统一管理仓库设置、分支保护、规则集、标签、团队、环境和协作者的组织中调用 `/safe-settings` 时使用。本技能会搭建管理员仓库的结构（`settings.yml` + `suborgs/` + `repos/`），提供 GitHub App 的安装步骤，并生成一个定时执行的 `full-sync` GitHub Actions 工作流。它不同于 `/gh-bootstrap`（对单个仓库进行一次性 `gh api` 配置）——此技能面向 **组织级别的设置即代码**，实现持续同步。并不用于单次 GitHub 操作（PR、issue、CI 状态）或本地 git 工作——这些超出本目录的范围。
