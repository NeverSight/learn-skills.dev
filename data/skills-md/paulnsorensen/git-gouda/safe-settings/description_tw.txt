設定 GitHub 的 `safe-settings`（一個由 github 組織提供、基於 Probot 的 GitHub App）以宣告式、全組織範圍的倉庫政策即代碼。當使用者說「settings as code」「safe-settings」「manage repos declaratively」「centralize repo settings」「org-level branch protection」「scaffold an admin repo」「github settings app」或在想要以單一管理倉庫從一個 admin repo 管理倉庫設定、分支保護、規則集、標籤、團隊、環境與協作者時，呼叫 /safe‑settings，就使用此功能。此功能會搭建 admin‑repo 的目錄結構（`settings.yml` + `suborgs/` + `repos/`）、說明 GitHub App 的安裝步驟，並建立排程的 `full-sync` GitHub Actions 工作流程。與 /gh‑bootstrap（一次性使用 `gh api` 設定單一倉庫）不同——此技能是用於 **全組織規模的設定即代碼**，能持續同步調整。它不適用於單次任務的 GitHub 操作（PR、議題、CI 狀態）或本地 git 工作——這些超出本目錄的範圍。
