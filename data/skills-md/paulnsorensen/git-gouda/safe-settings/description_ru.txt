Настройте `safe-settings` от GitHub (приложение GitHub App на основе Probot из организации github) для декларативной, охватывающей всю организацию политики репозиториев в виде кода. Используйте, когда пользователь говорит «settings as code», «safe-settings», «manage repos declaratively», «centralize repo settings», «org-level branch protection», «scaffold an admin repo», «github settings app» или вызывает /safe-settings в организации, желающей управлять настройками репозиториев, защитой веток, наборами правил, метками, командами, окружениями и сотрудниками из одного административного репозитория. Создаёт структуру админ‑репозитория (`settings.yml` + `suborgs/` + `repos/`), шаги установки GitHub App и запланированный workflow GitHub Actions `full-sync`. Отличается от /gh-bootstrap (однократной конфигурации `gh api` для одного репозитория) — этот навык предназначен для **масштабных настроек организации как кода**, которые постоянно синхронизируются. Не предназначен для разовых операций GitHub (pull‑request, issue, статус CI) или локальной работы с git — они находятся за пределами этого каталога.
