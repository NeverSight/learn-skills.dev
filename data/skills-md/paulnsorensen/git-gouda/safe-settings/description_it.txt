Configura `safe-settings` di GitHub (un'app GitHub basata su Probot dell'organizzazione github) per una politica dichiarativa, a livello di organizzazione, dei repository come codice. Usala quando l'utente dice "settings as code", "safe-settings", "manage repos declaratively", "centralize repo settings", "org-level branch protection", "scaffold an admin repo", "github settings app", o invoca /safe-settings su un'organizzazione che vuole gestire le impostazioni dei repository, la protezione dei rami, i ruleset, le etichette, i team, gli ambienti e i collaboratori da un unico repository amministrativo. Genera la struttura del repository amministrativo (`settings.yml` + `suborgs/` + `repos/`), i passaggi per l'installazione dell'app GitHub e un workflow GitHub Actions programmato `full‑sync`. Distinto da /gh-bootstrap (configurazione puntuale con `gh api` di un singolo repository) — questa skill è per **impostazioni a livello di organizzazione come codice** che vengono riconciliate continuamente. Non è destinata a operazioni GitHub specifiche (PR, issue, stato CI) o al lavoro locale con git — quelle sono fuori dallo scope di questo catalogo.
