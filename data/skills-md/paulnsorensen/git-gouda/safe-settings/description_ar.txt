إعداد `safe-settings` من GitHub (تطبيق GitHub مبني على Probot من منظمة github) للسياسة الإعلانية العامة للمستودعات على مستوى المؤسسة ككود. يُستخدم عندما يقول المستخدم “settings as code”، “safe-settings”، “manage repos declaratively”، “centralize repo settings”، “org-level branch protection”، “scaffold an admin repo”، “github settings app”، أو يستدعي `/safe-settings` على مؤسسة ترغب في إدارة إعدادات المستودعات، حماية الفروع، مجموعات القواعد، العلامات، الفرق، البيئات، والمتعاونين من مستودع إداري واحد. يُنشئ بنية المستودع الإداري (`settings.yml` + `suborgs/` + `repos/`)، خطوات تثبيت تطبيق GitHub، وإجراء GitHub Actions مجدول لـ `full-sync`. مختلف عن `/gh-bootstrap` (إعداد لمرة واحدة عبر `gh api` لمستودع واحد) — هذه المهارة مخصصة **لإعدادات ككود على مستوى المؤسسة** التي يتم مزامنتها باستمرار. ليست للعمليات اليومية على GitHub (طلبات السحب، القضايا، حالة CI) أو أعمال Git المحلية — تلك خارج نطاق هذا الكتالوج.
