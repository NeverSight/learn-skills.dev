GitHub の `safe-settings`（GitHub 組織が提供する Probot ベースの GitHub アプリ）を設定し、宣言的かつ組織全体にわたるリポジトリポリシーをコードとして管理できるようにします。ユーザーが「settings as code」や「safe-settings」「リポジトリを宣言的に管理」「リポジトリ設定の集中管理」「組織レベルのブランチ保護」「管理リポジトリの雛形作成」「github settings app」などと言ったとき、または /safe-settings を呼び出して、リポジトリ設定、ブランチ保護、ルールセット、ラベル、チーム、環境、コラボレーターを 1 つの管理リポジトリから管理したい組織に対して使用します。管理リポジトリのレイアウト（`settings.yml` + `suborgs/` + `repos/`）を自動生成し、GitHub アプリのインストール手順と、定期実行される `full-sync` GitHub Actions ワークフローを用意します。  
これは /gh-bootstrap（単一リポジトリを一度だけ `gh api` で設定する）のとは異なり、**組織規模の「設定をコードとして」連続的に調整**するための機能です。個別タスクの GitHub 操作（PR、issue、CI ステータス）やローカルの git 作業には使用せず、これらは本カタログの対象外です。
