Agregar o verificar la aplicación de CI para los títulos de pull request con Conventional Commits. Detecta si el repositorio hace squash‑merge usando el título del PR como asunto del commit, comprueba la existencia de una verificación de título, genera `.github/workflows/pr-title.yml` utilizando amannn/action-semantic-pull-request en un SHA fijado, y verifica que falle con un título incorrecto y apruebe con uno correcto. Úsalo cuando el usuario indique aplicar títulos de PR con conventional commit, lint PR titles, semantic pull request check, agregar una verificación de título de PR, o invoque /pr-title-lint. NO lo utilices para cambiar un repositorio a squash‑merge con mensajes de commit basados en el título del PR (usa gh‑bootstrap para configuraciones y reglas de merge), para crear una release (usa release), o para ganchos locales de mensaje de commit (usa prek).
