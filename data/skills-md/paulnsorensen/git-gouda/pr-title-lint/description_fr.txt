Ajoutez ou vérifiez l'application CI des titres de pull request conformes aux Conventional Commits. Détecte si le dépôt effectue des squash‑merge avec le titre de la PR comme sujet du commit, vérifie l'existence d'une vérification de titre, crée le fichier `.github/workflows/pr-title.yml` en utilisant amannn/action-semantic-pull-request à un SHA épinglé, et confirme qu'un mauvais titre échoue et qu'un bon titre passe. Utilisez‑le lorsque l'utilisateur dit appliquer les titres de PR conformes aux Conventional Commits, lint les titres de PR, vérification sémantique de pull request, ajouter une vérification de titre de PR, ou invoque /pr-title-lint. NE l'utilisez PAS pour changer un dépôt en squash‑merge avec des messages de commit basés sur le titre de la PR (utilisez gh-bootstrap pour les paramètres de fusion et les règles), créer une version (utilisez release), ou des hooks locaux de message de commit (utilisez prek).  

Veuillez toujours répondre dans la langue de l'utilisateur.
