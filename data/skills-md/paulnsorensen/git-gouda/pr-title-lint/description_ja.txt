Conventional Commits のプルリクエストタイトルに対する CI の強制を追加または検証します。リポジトリが PR タイトルをコミットサブジェクトとしてスクワッシュマージするかどうかを検出し、既存のタイトルチェックがあるか確認し、amannn/action-semantic-pull-request を固定 SHA で使用して `.github/workflows/pr-title.yml` を作成し、悪いタイトルでは失敗し、良いタイトルでは成功することを検証します。ユーザーが「enforce conventional commit PR titles」「lint PR titles」「semantic pull request check」「add a PR title check」などと言ったとき、または `/pr-title-lint` を呼び出したときに使用してください。「リポジトリを PR タイトルのコミットメッセージでスクワッシュマージに切り替える」（この場合は gh-bootstrap を使用してマージデフォルトとルールセットを設定）や、リリースを作成する（release を使用）や、ローカルのコミットメッセージフック（prek を使用）には使用しないでください。
