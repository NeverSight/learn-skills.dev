Добавьте или проверьте принудительное соблюдение CI заголовков пул‑запросов в формате Conventional Commits. Определяет, выполняет ли репозиторий squash‑merge, используя заголовок PR в качестве темы коммита, проверяет наличие существующей проверки заголовка, создает файл `.github/workflows/pr-title.yml` с помощью amannn/action-semantic-pull-request на зафиксированном SHA и проверяет, что при плохом заголовке проверка не проходит, а при корректном — проходит. Используйте, когда пользователь говорит «enforce conventional commit PR titles», «lint PR titles», «semantic pull request check», «add a PR title check» или вызывает /pr-title-lint. НЕ используйте для переключения репозитория на squash‑merge с сообщениями коммита из заголовка PR (используйте gh-bootstrap для настроек слияния и наборов правил), создания релиза (используйте release) или локальных хуков сообщений коммита (используйте prek). 

Пожалуйста, всегда отвечайте на языке пользователя.
