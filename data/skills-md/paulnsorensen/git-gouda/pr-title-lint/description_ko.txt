Conventional Commits 풀 리퀘스트 제목에 대한 CI 강제 적용을 추가하거나 확인합니다. 레포가 PR 제목을 커밋 주제로 사용해 스쿼시 머지하는지 감지하고, 기존 제목 검사가 있는지 확인하며, 고정 SHA를 사용해 amannn/action-semantic-pull-request로 `.github/workflows/pr-title.yml` 파일을 생성하고, 잘못된 제목이면 실패하고 올바른 제목이면 통과하도록 검증합니다. 사용자는 “conventional commit PR 제목 강제”, “PR 제목 lint”, “semantic pull request check”, “PR 제목 검사 추가” 라고 말하거나 `/pr-title-lint`를 호출할 때 사용하세요. 레포를 PR‑제목 커밋 메시지와 함께 스쿼시 머지로 전환하는 경우에는 사용하지 마세요(merge 기본값 및 규칙 세트는 gh-bootstrap 사용), 릴리즈를 만들 때는 사용하지 마세요(release 사용), 로컬 커밋 메시지 훅에는 사용하지 마세요(prek 사용).
