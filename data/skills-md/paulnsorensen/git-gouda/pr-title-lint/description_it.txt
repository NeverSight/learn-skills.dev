Aggiungi o verifica l’applicazione CI dei titoli delle pull request secondo Conventional Commits. Rileva se il repository esegue lo squash‑merge usando il titolo della PR come oggetto del commit, controlla la presenza di un controllo del titolo esistente, scaffolda `.github/workflows/pr-title.yml` utilizzando amannn/action-semantic-pull-request a un SHA fissato e verifica che fallisca con un titolo errato e passi con uno corretto. Usalo quando l’utente dice “enforce conventional commit PR titles”, “lint PR titles”, “semantic pull request check”, “add a PR title check” o invoca `/pr‑title‑lint`. NON usarlo per passare un repo a squash‑merge con messaggi di commit basati sul titolo della PR (usa gh‑bootstrap per le impostazioni predefinite di merge e i ruleset), per creare una release (usa release) o per hook locali sui messaggi di commit (usa prek).

Rispondi sempre nella lingua dell’utente.
