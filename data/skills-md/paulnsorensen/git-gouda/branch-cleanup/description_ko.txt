스테일(git) 브랜치를 보고하고 유지, 보관 또는 삭제 권고를 제시하며, delete-branch-on-merge 활성화를 제안합니다. “오래된 브랜치 정리”, “병합된 브랜치 삭제”, “병합 시 브랜치 삭제”, “어떤 브랜치가 죽었는가”, 또는 /branch-cleanup에 사용합니다. 브랜치의 연령, 작성자, 앞선/뒤처진 커밋 수, 병합 여부, 열린 풀 요청, 그리고 규칙 집합 보호 상태를 확인한 뒤, 푸시 전 명시적인 배치별 승인(authorization)이 필요하다는 점을 명시한 정확한 삭제 명령을 출력합니다. 로컬 git 워크트리 관리(워크트리 추가, 목록 조회, 정리)는 이 범위에 포함되지 않으니 사용하지 마세요. 일회성 저장소 병합 기본값 및 브랜치 보호 규칙 집합은 /gh-bootstrap에 속하며, 이 스킬은 해당 상태를 읽고 보고할 뿐 설정은 하지 않습니다.
