Отчёт о устаревших ветках Git с рекомендацией оставить, заархивировать или удалить их, а также предложение включить удаление ветки при слиянии. Используется для «очистки устаревших веток», «удаления слитых веток», «удаления ветки при слиянии», «какие ветки мертвы» или /branch-cleanup. Проверяет возраст, автора, количество коммитов вперёд/назад, статус слияния, открытые pull‑request‑ы и защиту набора правил, затем выводит точные команды удаления, требующие явного разрешения для каждой партии перед любым push‑ом. НЕ использовать для управления локальными рабочими деревьями Git (worktree add, list или prune) — это выходит за рамки. Одноразовые настройки слияния репозитория и наборы правил защиты веток относятся к /gh-bootstrap; эта функция только читает и сообщает о текущем состоянии, но не настраивает его.
