Segnala i rami git obsoleti con una raccomandazione di mantenere, archiviare o eliminare e proponi di abilitare delete-branch-on-merge. Usa per "pulire rami obsoleti", "eliminare rami uniti", "eliminare ramo al merge", "quali rami sono morti" o /branch-cleanup. Controlla età, autore, conteggi ahead/behind, stato di merge, pull request aperte e protezione mediante regole, quindi stampa i comandi di cancellazione esatti che richiedono un'autorizzazione esplicita per batch prima di qualsiasi push. NON utilizzare per la gestione locale dei worktree git (worktree add, list o prune) — ciò è fuori ambito. Le impostazioni predefinite di merge del repository una tantum e i set di regole di protezione dei rami appartengono a /gh-bootstrap; questa funzionalità legge e riporta quello stato ma non lo configura.
