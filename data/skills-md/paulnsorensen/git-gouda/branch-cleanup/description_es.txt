Informa de ramas git obsoletas con una recomendación de mantener, archivar o eliminar, y propone habilitar delete-branch-on-merge. Úsalo para “limpiar ramas obsoletas”, “eliminar ramas fusionadas”, “eliminar rama al fusionar”, “qué ramas están muertas” o /branch-cleanup. Verifica la antigüedad, el autor, los recuentos adelante/atrás, el estado de fusión, las pull requests abiertas y la protección del conjunto de reglas, luego imprime los comandos exactos de eliminación que requieren autorización explícita por lote antes de cualquier push. NO lo uses para la gestión local de worktree de git (worktree add, list o prune); eso queda fuera del alcance. Los valores predeterminados de fusión del repositorio y los conjuntos de reglas de protección de ramas pertenecen a /gh-bootstrap; esta función lee y reporta ese estado pero no lo configura.
