報告過時的 git 分支，提供保留、歸檔或刪除的建議，並提議啟用 delete-branch-on-merge。用於「清理過時分支」、 「刪除已合併分支」、 「合併時刪除分支」、 「哪些分支已死」或 /branch-cleanup。檢查年齡、作者、前後提交數、合併狀態、開放的 pull request 以及規則集保護，然後列印需要在推送前取得每批次明確授權的確切刪除指令。請勿用於本機 git worktree 管理（worktree add、list 或 prune）——此功能不在範圍內。一次性的倉庫合併預設與分支保護規則集屬於 /gh-bootstrap；此技能僅讀取並報告該狀態，並不設定它。

請始終以使用者的語言回覆。
