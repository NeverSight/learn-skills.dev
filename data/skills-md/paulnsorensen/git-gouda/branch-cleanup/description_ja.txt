古くなった git ブランチを keep、archive、または delete の推奨とともに報告し、delete-branch-on-merge の有効化を提案します。「clean up stale branches」「delete merged branches」「delete branch on merge」「which branches are dead」または /branch-cleanup 用に使用してください。年齢、作成者、ahead/behind カウント、マージ済みかどうか、オープン Pull Request、ルールセット保護をチェックし、プッシュ前にバッチごとの明示的な許可が必要な正確な削除コマンドを出力します。ローカル git worktree の管理（worktree add、list、prune）には使用しないでください—対象外です。一度限りのリポジトリマージデフォルトやブランチ保護ルールセットは /gh-bootstrap に属します。このスキルはその状態を読み取り報告しますが、設定は行いません。
