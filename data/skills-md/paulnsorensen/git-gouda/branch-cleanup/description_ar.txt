الإبلاغ عن الفروع المتقادمة في Git مع توصية بالحفاظ أو الأرشفة أو الحذف، واقتراح تمكين خاصية delete-branch-on-merge. يُستخدم لهذا الغرض عند “تنظيف الفروع المتقادمة”، “حذف الفروع المدمجة”، “حذف الفرع عند الدمج”، “ما هي الفروع الميتة”، أو /branch-cleanup. يتحقق من عمر الفرع، المؤلف، عدد الالتزامات المتقدمة/المتأخرة، حالة الدمج، طلبات السحب المفتوحة، وحماية قواعد الحماية، ثم يُظهر أوامر الحذف الدقيقة التي تتطلب تفويضًا صريحًا لكل دفعة قبل أي دفع. لا تُستَخدم هذه الخاصية لإدارة worktree المحلي في Git (إضافة worktree، سرد أو حذف) — فهذا خارج نطاقها. إعدادات دمج المستودع لمرة واحدة ومجموعات قواعد حماية الفروع تندرج تحت /gh-bootstrap؛ هذه الأداة تقرأ وتُبلّغ عن تلك الحالة دون إعدادها.

يرجى الرد دائمًا بلغة المستخدم.
