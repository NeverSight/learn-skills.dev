Signalez les branches git obsolètes avec une recommandation de garder, archiver ou supprimer, et proposez d’activer delete-branch-on-merge. Utilisez pour « clean up stale branches », « delete merged branches », « delete branch on merge », « which branches are dead » ou /branch‑cleanup. Vérifie l’âge, l’auteur, les comptes d’avance/retard, le statut de fusion, les pull requests ouvertes et la protection du jeu de règles, puis affiche les commandes de suppression exactes qui nécessitent une autorisation explicite par lot avant tout push. NE PAS utiliser pour la gestion locale des worktrees git (worktree add, list ou prune) — cela reste hors du champ d’application. Les paramètres de fusion de dépôt ponctuels et les jeux de règles de protection des branches appartiennent à /gh‑bootstrap ; cette compétence lit et rend compte de cet état mais ne le configure pas.

Veuillez toujours répondre dans la langue de l'utilisateur.
