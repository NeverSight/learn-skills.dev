リポジトリに対して、すべてのカタログスキルのチェックを読み取り専用で監査し、どの設定ギャップが存在するかを報告します。リポジトリのルートからバンドルされた Python スクリプトを実行し、カタログスキルごとに 1 行（チェック、ステータス、証拠、修正するスキル）を出力し、続いてそれらのスキルを名前として列挙した順序付けられた計画を提案します。ファイルを書き込むことは決してせず、オプションの --github フラグを使用した場合でも、変更を伴う GitHub API エンドポイントを呼び出すことはありません（このフラグは読み取り専用の GET チェックを追加します）。ユーザーが「audit this repo」「what's missing in this repository」「repo health check」「which setup skills apply」と言ったとき、または /repo-audit を呼び出したときに使用します。直接修正を適用するために使用しないでください — 各検出結果は対応するカタログスキルにルーティングします — またはアプリケーションロジックのコードレビューに使用しないでください。常にユーザーの言語で応答してください。
