Выполните проверку только для чтения всех проверок навыков каталога против репозитория и сообщите, какие пробелы в настройке существуют. Запускает объединённый Python‑скрипт из корня репозитория, выводит одну строку на каждый навык каталога (проверка, статус, доказательство, навык, который её исправляет), затем предлагает упорядоченный план с перечислением этих навыков. Никогда не записывает файл и никогда не вызывает изменяющий конечный пункт API GitHub, даже с дополнительным флагом --github, который добавляет только проверочные GET‑запросы. Используйте, когда пользователь говорит «аудировать этот репозиторий», «что отсутствует в этом репозитории», «проверка здоровья репозитория», «какие навыки настройки применимы», или вызывает /repo-audit. НЕ используйте для непосредственного применения исправлений — перенаправляйте каждое найденное несоответствие к соответствующему навыку каталога — и не используйте для ревью кода бизнес‑логики.
