Esegui un audit in sola lettura di tutti i controlli delle skill del catalogo su un repository e segnala quali lacune di configurazione esistono. Avvia uno script Python incluso dalla radice del repository, stampa una riga per ciascuna skill del catalogo (controllo, stato, evidenza, la skill che lo risolve), quindi propone un piano ordinato che nomina tali skill. Non scrive mai un file e non chiama mai un endpoint mutante dell'API GitHub, nemmeno con il flag opzionale --github, che aggiunge controlli GET in sola lettura. Utilizza questo audit quando l'utente dice "audit this repo", "what's missing in this repository", "repo health check", "which setup skills apply", oppure invoca /repo-audit. NON usarlo per applicare direttamente alcuna correzione — instrada ogni risultato alla corrispondente skill del catalogo — né per la revisione del codice della logica dell'applicazione.
