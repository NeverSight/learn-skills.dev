قم بإجراء تدقيق للقراءة فقط لجميع فحوصات مهارات الكتالوج ضد المستودع وأبلغ عن الفجوات الموجودة في الإعداد. يشغِّل سكريبت بايثون مدمج من جذر المستودع، يطبع صفًا واحدًا لكل مهارة كتالوج (الفحص، الحالة، الأدلة، المهارة التي تصلحه)، ثم يقترح خطة مرتبة تسمي تلك المهارات. لا يكتب ملفًا أبدًا ولا يستدعي نقطة نهاية API متغيِّرة في GitHub، حتى مع العلمة الاختيارية --github التي تضيف فحوصات GET للقراءة فقط. استخدمه عندما يقول المستخدم «audit this repo» أو «what's missing in this repository» أو «repo health check» أو «which setup skills apply» أو يستدعي /repo-audit. لا تستخدمه لتطبيق أي إصلاح مباشرة — وجه كل نتيجة إلى مهارة الكتالوج الخاصة بها — أو لمراجعة كود منطق التطبيق.
