Exécutez un audit en lecture seule de tous les contrôles des compétences du catalogue sur un dépôt et signalez les lacunes de configuration existantes. Lancez un script Python fourni depuis la racine du dépôt, affichez une ligne par compétence du catalogue (contrôle, statut, preuve, la compétence qui le corrige), puis proposez un plan ordonné nommant ces compétences. N’écrivez jamais de fichier et n’appellez jamais de point de terminaison GitHub qui modifie l’état, même avec le drapeau optionnel --github, qui ajoute des vérifications GET en lecture seule. Utilisez‑le lorsque l’utilisateur dit « audit this repo », « what's missing in this repository », « repo health check », « which setup skills apply », ou invoque /repo-audit. N’UTILISEZ PAS pour appliquer directement une correction — redirigez chaque constatation vers sa compétence du catalogue — ou pour la révision de code de la logique d’application.
