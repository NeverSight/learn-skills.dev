Führe ein schreibgeschütztes Audit aller Prüfungen der Katalog‑Skills gegen ein Repository durch und melde, welche Einrichtungslücken bestehen. Führt ein mitgeliefertes Python‑Skript aus dem Repository‑Stammverzeichnis aus, gibt für jeden Katalog‑Skill eine Zeile aus (Prüfung, Status, Nachweis, der Skill, der das Problem behebt) und schlägt anschließend einen geordneten Plan mit den betreffenden Skills vor. Schreibt niemals eine Datei und ruft niemals einen mutierenden GitHub‑API‑Endpunkt auf, selbst nicht mit dem optionalen --github‑Flag, das nur schreibgeschützte GET‑Prüfungen hinzufügt. Verwende es, wenn der Benutzer sagt „audit this repo“, „what's missing in this repository“, „repo health check“, „which setup skills apply“ oder /repo-audit aufruft. Nutze es NICHT, um direkt Korrekturen anzuwenden — leite jede Feststellung an den jeweiligen Katalog‑Skill weiter — oder für Code‑Reviews der Anwendungslogik.
