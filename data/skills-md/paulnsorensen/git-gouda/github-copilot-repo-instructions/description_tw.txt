新增、審核或修正 GitHub Copilot 儲存庫的自訂指令 — `.github/copilot-instructions.md`（全儲存庫）與 `.github/instructions/*.instructions.md`（路徑特定）— 使 Copilot Chat、Copilot 程式碼審查與 Copilot 編碼代理都能取得專案範圍的指導。亦包括 `AGENTS.md`、`CLAUDE.md`、`GEMINI.md` 作為替代代理指令檔。當使用者說「add Copilot instructions」「set up copilot-instructions.md」「audit our Copilot config」「make Copilot follow our conventions」「configure Copilot code review」「add path-specific Copilot rules」「applyTo glob」「excludeAgent」「Copilot is ignoring our guidance」或呼叫 /github‑copilot‑repo‑instructions 時使用此技能。請勿用於個人（單一使用者）Copilot 指令；這超出本技能範圍。欲取得 AGENTS.md 除檔案結構外的撰寫指引，請參考 agents‑md 技能。
