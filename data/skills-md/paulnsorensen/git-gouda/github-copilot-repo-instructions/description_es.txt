Agregar, auditar o corregir las instrucciones personalizadas del repositorio de GitHub Copilot — `.github/copilot-instructions.md` (a nivel de repositorio) y `.github/instructions/*.instructions.md` (específicas de ruta) — para que Copilot Chat, la revisión de código de Copilot y el agente de codificación de Copilot tomen en cuenta la orientación del proyecto. También cubre `AGENTS.md`, `CLAUDE.md` y `GEMINI.md` como archivos alternativos de instrucciones de agente. Úsalo cuando el usuario diga "add Copilot instructions", "set up copilot-instructions.md", "audit our Copilot config", "make Copilot follow our conventions", "configure Copilot code review", "add path-specific Copilot rules", "applyTo glob", "excludeAgent", "Copilot is ignoring our guidance", o invoque /github-copilot-repo-instructions. NO lo uses para instrucciones personales (por‑usuario) de Copilot; esas están fuera del alcance de esta habilidad. Para la guía de redacción de `AGENTS.md` más allá de la estructura del archivo, consulta la habilidad agents‑md.
