Aggiungere, verificare o correggere le istruzioni personalizzate del repository GitHub Copilot — `.github/copilot-instructions.md` (a livello di repository) e `.github/instructions/*.instructions.md` (specifiche per percorso) — in modo che Copilot Chat, la revisione del codice Copilot e l’agente di codifica Copilot raccogliano le indicazioni a livello di progetto. Include anche `AGENTS.md`, `CLAUDE.md` e `GEMINI.md` come file di istruzioni alternativi per gli agenti. Utilizzare quando l’utente dice “add Copilot instructions”, “set up copilot-instructions.md”, “audit our Copilot config”, “make Copilot follow our conventions”, “configure Copilot code review”, “add path-specific Copilot rules”, “applyTo glob”, “excludeAgent”, “Copilot is ignoring our guidance” o invoca /github-copilot-repo-instructions. NON usare per istruzioni Copilot personali (per utente); queste sono fuori dall’ambito di questa abilità. Per indicazioni sulla redazione di AGENTS.md oltre alla struttura dei file, vedere la skill agents-md.
