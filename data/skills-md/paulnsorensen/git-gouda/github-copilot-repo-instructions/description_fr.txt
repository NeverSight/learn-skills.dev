Ajouter, auditer ou corriger les instructions personnalisées du dépôt GitHub Copilot — `.github/copilot-instructions.md` (à l’échelle du dépôt) et `.github/instructions/*.instructions.md` (spécifiques à un chemin) — afin que Copilot Chat, la revue de code Copilot et l’agent de codage Copilot appliquent les consignes du projet. Couvre également `AGENTS.md`, `CLAUDE.md` et `GEMINI.md` comme fichiers d’instructions d’agent alternatifs. Utilisez‑le lorsque l’utilisateur dit « ajouter des instructions Copilot », « mettre en place copilot-instructions.md », « auditer notre configuration Copilot », « faire suivre nos conventions à Copilot », « configurer la revue de code Copilot », « ajouter des règles Copilot spécifiques à un chemin », « applyTo glob », « excludeAgent », « Copilot ignore nos consignes », ou invoque /github-copilot-repo-instructions. NE PAS l’utiliser pour les instructions Copilot personnelles (par utilisateur) ; elles sont hors du périmètre de cette compétence. Pour des conseils de rédaction d’AGENTS.md au‑delà de la structure des fichiers, voyez la compétence agents‑md.

Veuillez toujours répondre dans la langue de l’utilisateur.
