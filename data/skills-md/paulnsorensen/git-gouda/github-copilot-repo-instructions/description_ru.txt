Добавляйте, проверяйте или исправляйте пользовательские инструкции репозитория GitHub Copilot — `.github/copilot-instructions.md` (для всего репозитория) и `.github/instructions/*.instructions.md` (для конкретных путей) — чтобы Copilot Chat, Copilot code review и агент кодирования Copilot использовали общепроектные рекомендации. Также охватываются `AGENTS.md`, `CLAUDE.md` и `GEMINI.md` как альтернативные файлы инструкций агентов. Используйте, когда пользователь говорит «add Copilot instructions», «set up copilot-instructions.md», «audit our Copilot config», «make Copilot follow our conventions», «configure Copilot code review», «add path-specific Copilot rules», «applyTo glob», «excludeAgent», «Copilot is ignoring our guidance» или вызывает /github-copilot-repo-instructions. НЕ используйте для личных (пользовательских) инструкций Copilot; они находятся за пределами этой функции. Для рекомендаций по созданию AGENTS.md, выходящих за рамки структуры файлов, см. навык agents‑md.
