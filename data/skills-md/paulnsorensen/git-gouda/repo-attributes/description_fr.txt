Configure .gitattributes, .editorconfig, .gitignore et les filtres Git LFS pour un dépôt : normaliser les fins de ligne, marquer les chemins générés, vendus et de documentation pour GitHub Linguist, définir les paramètres d’éditeur par langage, et fusionner le contenu de .gitignore à partir des modèles GitHub. Utilisez‑le lorsque l’utilisateur dit « add .gitattributes », « fix line endings », « CRLF », « linguist », « mark generated files », « set up .editorconfig », « gitignore template », « git lfs », ou invoque /repo-attributes. Ne PAS l’utiliser pour la configuration de prek ou de hooks pre‑commit — utilisez /prek. Les propriétés personnalisées GitHub (métadonnées au niveau de l’organisation) sont hors scope ; cette compétence ne touche que les fichiers d’attributs, d’éditeur et d’ignore au niveau du dépôt. Les fichiers de santé communautaire (README, LICENSE, CODE_OF_CONDUCT, CONTRIBUTING, SECURITY) relèvent de /oss-hygiene, pas de cette compétence.

Veuillez toujours répondre dans la langue de l’utilisateur.
