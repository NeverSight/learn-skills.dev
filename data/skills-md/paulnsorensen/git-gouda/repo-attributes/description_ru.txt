Настройте .gitattributes, .editorconfig, .gitignore и фильтры Git LFS для репозитория: нормализуйте окончания строк, пометьте сгенерированные, внешние и документационные пути для GitHub Linguist, задайте значения по умолчанию для редактора в зависимости от языка и объедините содержимое .gitignore из шаблонов GitHub. Используйте, когда пользователь говорит «add .gitattributes», «fix line endings», «CRLF», «linguist», «mark generated files», «set up .editorconfig», «gitignore template», «git lfs» или вызывает /repo-attributes. НЕ используйте для конфигурации prek или pre‑commit hook — используйте /prek. Пользовательские свойства GitHub (метаданные уровня организации) находятся за пределами области применения; этот навык работает только с атрибутами, редактором и файлами игнорирования на уровне репозитория. Файлы со здоровьем сообщества (README, LICENSE, CODE_OF_CONDUCT, CONTRIBUTING, SECURITY) относятся к /oss‑hygiene, а не к этому навыку.

Всегда отвечайте на языке пользователя.
