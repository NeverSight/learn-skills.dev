Configura .gitattributes, .editorconfig, .gitignore e i filtri Git LFS per un repository: normalizza le terminazioni di riga, segna i percorsi generati, vendorizzati e di documentazione per GitHub Linguist, imposta i valori predefiniti dell’editor per linguaggio e unisci il contenuto di .gitignore dai modelli di GitHub. Usalo quando l’utente dice “add .gitattributes”, “fix line endings”, “CRLF”, “linguist”, “mark generated files”, “set up .editorconfig”, “gitignore template”, “git lfs” o invoca /repo-attributes. NON usarlo per la configurazione di prek o dei hook pre‑commit — usa /prek. Le proprietà personalizzate di GitHub (metadati a livello di organizzazione) sono fuori scala; questa skill riguarda solo i file di attributi, editor e ignore per repository. I file di salute della community (README, LICENSE, CODE_OF_CONDUCT, CONTRIBUTING, SECURITY) appartengono a /oss-hygiene, non a questa skill.

Rispondi sempre nella lingua dell’utente.
