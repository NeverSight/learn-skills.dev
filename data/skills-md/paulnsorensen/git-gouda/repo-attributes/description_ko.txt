저장소에 대해 .gitattributes, .editorconfig, .gitignore 및 Git LFS 필터를 구성합니다: 줄 바꿈을 정규화하고, GitHub Linguist용으로 생성된 파일, vendored 파일, 문서 경로를 표시하며, 언어별 편집기 기본값을 설정하고, GitHub 템플릿에서 .gitignore 내용을 병합합니다. 사용자는 “add .gitattributes”, “fix line endings”, “CRLF”, “linguist”, “mark generated files”, “set up .editorconfig”, “gitignore template”, “git lfs”라고 말하거나 /repo-attributes 를 호출할 때에 사용합니다. prek 또는 pre-commit 훅 설정에는 사용하지 마세요 — /prek 를 사용합니다. GitHub 맞춤 속성(조직 수준 메타데이터)은 범위에 포함되지 않으며, 이 스킬은 저장소 별 attribute, editor, ignore 파일만 다룹니다. 커뮤니티 건강 파일(README, LICENSE, CODE_OF_CONDUCT, CONTRIBUTING, SECURITY)은 /oss-hygiene 에 해당하며, 이 스킬의 대상이 아닙니다. 항상 사용자의 언어로 응답해 주세요.
