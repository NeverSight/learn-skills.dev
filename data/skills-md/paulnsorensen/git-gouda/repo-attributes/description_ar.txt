تكوين .gitattributes و .editorconfig و .gitignore وفلاتر Git LFS لمستودع: توحيد نهايات الأسطر، وضع علامة على مسارات الملفات المولدة، المضمّنة، والوثائق لـ GitHub Linguist، تعيين الإعدادات الافتراضية للمحرر لكل لغة، ودمج محتوى .gitignore من قوالب GitHub. استخدم عند قول المستخدم "add .gitattributes"، "fix line endings"، "CRLF"، "linguist"، "mark generated files"، "set up .editorconfig"، "gitignore template"، "git lfs"، أو عند استدعاء /repo-attributes. لا تستخدم لهذا إعدادات prek أو pre‑commit hook — استخدم /prek. خصائص GitHub المخصصة (بيانات تعريف على مستوى المؤسسة) خارج النطاق؛ هذه المهارة تقتصر فقط على ملفات السمات، المحرر، وملفات التجاهل في كل مستودع. ملفات صحة المجتمع (README، LICENSE، CODE_OF_CONDUCT، CONTRIBUTING، SECURITY) تندرج تحت /oss-hygiene، ليست هذه المهارة.
