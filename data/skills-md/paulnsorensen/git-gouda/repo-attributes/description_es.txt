Configura .gitattributes, .editorconfig, .gitignore y los filtros Git LFS para un repositorio: normaliza los finales de línea, marca rutas generadas, vendorizadas y de documentación para GitHub Linguist, establece valores predeterminados de editor por lenguaje y combina el contenido de .gitignore a partir de plantillas de GitHub. Úsalo cuando el usuario diga “add .gitattributes”, “fix line endings”, “CRLF”, “linguist”, “mark generated files”, “set up .editorconfig”, “gitignore template”, “git lfs” o invoque /repo-attributes. NO lo uses para la configuración de prek o hooks de pre‑commit — usa /prek. Las propiedades personalizadas de GitHub (metadatos a nivel de organización) están fuera del alcance; esta habilidad solo modifica archivos de atributos, editor e ignore a nivel de repositorio. Los archivos de salud comunitaria (README, LICENSE, CODE_OF_CONDUCT, CONTRIBUTING, SECURITY) pertenecen a /oss‑hygiene, no a esta habilidad. Por favor, responde siempre en el idioma del usuario.
