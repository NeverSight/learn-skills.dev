جرد، تصنيف، وتثبيت كل مرجع `uses:` في سير عمل GitHub Actions، الإجراءات المركبة، وسير العمل القابل لإعادة الاستخدام إلى SHA موثوق به، ثم الحفاظ على هذه التثبيتات محدثة باستخدام Dependabot. استخدم ذلك عندما يقول المستخدم "pin actions"، "unpinned actions"، "SHA pin"، "supply chain for workflows"، أو يستدعي /actions-pinning. لا تستخدم ذلك لأمان الأذونات وتحصين حقن ملفات سير العمل (حوّل إلى /oss-hygiene) أو لتحسين سرعة وقت تشغيل CI (حوّل إلى /ci-optimize). يرجى دائمًا الرد بلغة المستخدم.
