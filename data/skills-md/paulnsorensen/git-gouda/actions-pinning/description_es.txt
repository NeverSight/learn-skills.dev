Se utiliza cuando el usuario dice "acciones de PIN", "acciones no ancladas", "PIN SHA", "cadena de suministro para flujos de trabajo" o invoca /acciones de anclaje. NO utilizar para permisos y endurecimiento por inyección de archivos de flujo de trabajo (ruta a /oss-hygiene) o para la velocidad de tiempo de ejecución de CI (ruta a /ci-optimize).
