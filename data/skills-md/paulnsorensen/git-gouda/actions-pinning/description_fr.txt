Inventorier, classer et épingler chaque référence `uses:` dans les workflows GitHub Actions, les actions composites et les workflows réutilisables à un SHA de commit vérifié, puis garder ces épingles à jour avec Dependabot. Utiliser lorsque l'utilisateur dit « pin actions », « unpinned actions », « SHA pin », « supply chain for workflows », ou invoque /actions-pinning. Ne PAS l’utiliser pour le durcissement des permissions et de l’injection des fichiers de workflow (rediriger vers /oss-hygiene) ou pour la rapidité d’exécution CI (rediriger vers /ci-optimize).

Veuillez toujours répondre dans la langue de l'utilisateur.
