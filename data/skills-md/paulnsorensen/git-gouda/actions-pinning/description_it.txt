Inventaria, classifica e fissa ogni riferimento `uses:` nei workflow di GitHub Actions, nelle azioni composite e nei workflow riutilizzabili a un SHA di commit verificato, poi mantieni questi pin aggiornati con Dependabot. Usa quando l'utente dice “pin actions”, “unpinned actions”, “SHA pin”, “supply chain for workflows” o invoca /actions-pinning. NON usarlo per il rafforzamento di permessi e iniezioni nei file di workflow (indirizza a /oss-hygiene) o per la velocità di esecuzione CI (indirizza a /ci-optimize).

Rispondi sempre nella lingua dell'utente.
