Incorpora prek (pre‑commit impulsado por Rust) en cualquier proyecto y sugiere ganchos adaptados al lenguaje o framework. Utilízalo cuando el usuario diga “add prek”, “set up pre‑commit hooks”, “configure prek”, “what hooks should I use”, o cuando notes un proyecto sin un prek.toml que se beneficiaría de comprobaciones pre‑commit. También actívalo cuando el usuario quiera añadir nuevos ganchos a un prek.toml existente, auditar su configuración de ganchos o migrar de pre‑commit a prek. Cubre proyectos en Rust, Python, TypeScript/JavaScript, Go, Ruby y Shell. NO lo uses para husky, lint‑staged o configuración de ganchos en pipelines CI; esta habilidad es específicamente para prek.

Responde siempre en el idioma del usuario.
