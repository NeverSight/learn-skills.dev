将 prek（基于 Rust 的 pre‑commit）引入任何项目，并根据所使用的语言/框架推荐相应的钩子。当用户说 “add prek”、 “set up pre‑commit hooks”、 “configure prek”、 “what hooks should I use”，或当你发现项目缺少 prek.toml 且需要 pre‑commit 检查时使用此功能。还应在用户想向已有的 prek.toml 添加新钩子、审计他们的钩子配置，或从 pre‑commit 迁移到 prek 时触发。适用于 Rust、Python、TypeScript/JavaScript、Go、Ruby 和 Shell 项目。请勿将此用于 husky、lint‑staged 或 CI 流水线的钩子配置——此技能专门针对 prek。  

请始终使用用户的语言回复。
