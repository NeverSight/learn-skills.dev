어떤 프로젝트든 prek(Rust 기반 pre-commit)를 도입하고 언어·프레임워크에 맞는 훅을 제안합니다. 사용자가 “add prek”, “set up pre-commit hooks”, “configure prek”, “what hooks should I use”라고 말하거나, prek.toml이 없는 프로젝트를 발견했을 때, 해당 프로젝트에 pre-commit 검사가 유용할 경우에 사용합니다. 또한 사용자가 기존 prek.toml에 새 훅을 추가하고 싶거나, 훅 구성을 감사하거나, pre-commit에서 prek로 마이그레이션하려 할 때도 트리거됩니다. Rust, Python, TypeScript/JavaScript, Go, Ruby, Shell 프로젝트를 지원합니다. husky, lint-staged, CI 파이프라인 훅 설정에는 사용하지 마세요 — 이 기능은 오직 prek를 위한 것입니다.

항상 사용자의 언어로 응답하세요.
