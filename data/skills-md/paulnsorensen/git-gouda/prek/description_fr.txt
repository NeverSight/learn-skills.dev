Intégrez prek (pre‑commit propulsé par Rust) dans n’importe quel projet et suggérez des hooks adaptés au langage ou au framework. Utilisez‑le lorsque l’utilisateur dit « add prek », « set up pre‑commit hooks », « configure prek », « what hooks should I use », ou lorsque vous remarquez un projet sans un prek.toml qui bénéficierait de contrôles pre‑commit. Activez‑le également lorsque l’utilisateur veut ajouter de nouveaux hooks à un prek.toml existant, auditer sa configuration de hooks, ou migrer de pre‑commit vers prek. Couvre les projets Rust, Python, TypeScript/JavaScript, Go, Ruby et Shell. N’utilisez PAS cette compétence pour la configuration de husky, lint‑staged ou de pipelines CI — cette compétence est spécifiquement destinée à prek.

Veuillez toujours répondre dans la langue de l’utilisateur.
