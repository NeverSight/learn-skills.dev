將開源 GitHub 儲存庫提升至社群標準與供應鏈衛生基線：搭建 GitHub 社群標準檔案（README 檢查、LICENSE、CODE_OF_CONDUCT、CONTRIBUTING、SECURITY、issue 與 PR 模板），設定 Dependabot 版本更新、Dependency Review Action、OpenSSF Scorecard 以及 CodeQL（視情況而定），檢查 Dependabot 警報與機密掃描，並加入 OpenSSF 最佳實踐徽章連結。當使用者說「設置 OSS 衛生」「讓此儲存庫開源就緒」「添加社群健康檔案」「啟用 dependabot」「加入 scorecard」「OSSF 徽章」「供應鏈硬化」或在公開儲存庫呼叫 /oss-hygiene 時使用。具備冪等性——可安全重複執行；與模板比對差異，並在覆寫前徵求同意。與 /gh-bootstrap（合併按鈕＋分支保護）以及 /safe-settings（組織層級設定即程式碼）不同：聚焦於面向貢獻者與供應鏈的表面，而非合併或組織政策。於 /gh-bootstrap 之後、發布儲存庫之前執行。
