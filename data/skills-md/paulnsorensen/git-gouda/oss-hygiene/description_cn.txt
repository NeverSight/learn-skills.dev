将开源 GitHub 仓库提升至社区标准和供应链卫生基线：搭建 GitHub 社区标准文件（README 检查、LICENSE、CODE_OF_CONDUCT、CONTRIBUTING、SECURITY、issue 与 PR 模板），接入 Dependabot 版本更新、Dependency Review 动作、OpenSSF Scorecard 与 CodeQL（如适用），检查 Dependabot 警报和机密扫描，并添加 OpenSSF 最佳实践徽章链接。当用户说“set up OSS hygiene”“make this repo open-source-ready”“add community health files”“wire dependabot”“add scorecard”“OSSF badge”“supply chain hardening”或在公共仓库上调用 /oss-hygiene 时使用。幂等——可安全重复执行；对比模板差异并在覆盖前询问。区别于 /gh-bootstrap（合并按钮 + 分支保护）和 /safe-settings（组织级别设置代码化）：专注于面向贡献者的和供应链的表面，而非合并或组织策略。应在 /gh-bootstrap 之后、发布仓库之前运行。
