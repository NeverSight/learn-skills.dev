اجعل مستودع GitHub مفتوح المصدر يفي بمعايير المجتمع وخط أساس نظافة سلسلة التوريد: أنشئ ملفات معايير مجتمع GitHub (تحقق من README، LICENSE، CODE_OF_CONDUCT، CONTRIBUTING، SECURITY، قوالب القضايا + طلبات السحب)، وفّـِّر تحديثات الإصدارات عبر Dependabot، وإجراء مراجعة الاعتماديات، وOpenSSF Scorecard، وCodeQL (عند الحاجة)، وتحقق من تنبيهات Dependabot ومسح الأسرار، وأضف رابط شارة أفضل الممارسات من OpenSSF. يُستخدم عندما يقول المستخدم "set up OSS hygiene"، "make this repo open-source-ready"، "add community health files"، "wire dependabot"، "add scorecard"، "OSSF badge"، "supply chain hardening"، أو يستدعي الأمر /oss-hygiene على مستودع عام. يكون إيديومنتيًا — آمن لإعادة التشغيل؛ يقارن الفروقات مع القوالب ويسأل قبل الكتابة فوق. يختلف عن /gh-bootstrap (زر الدمج + حماية الفروع) و /safe-settings (إعدادات على مستوى المؤسسة ككود): يركّز على واجهة المساهمين وسطح سلسلة التوريد، وليس على الدمج أو سياسات المؤسسة. يُنفّذ بعد /gh-bootstrap؛ قبل الإعلان عن المستودع.
