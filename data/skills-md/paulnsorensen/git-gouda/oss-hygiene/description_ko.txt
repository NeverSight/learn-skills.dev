오픈소스 GitHub 리포지터리를 커뮤니티 표준과 공급망 위생 기준에 맞추세요: GitHub Community Standards 파일들을 스캐폴딩합니다(README 확인, LICENSE, CODE_OF_CONDUCT, CONTRIBUTING, SECURITY, 이슈 및 PR 템플릿). Dependabot 버전 업데이트, Dependency Review 액션, OpenSSF Scorecard, 그리고 (적용 가능한 경우) CodeQL을 연동하고, Dependabot 알림과 시크릿 스캐닝을 확인하며 OpenSSF Best Practices 배지 링크를 추가합니다. 사용자는 “set up OSS hygiene”, “make this repo open-source-ready”, “add community health files”, “wire dependabot”, “add scorecard”, “OSSF badge”, “supply chain hardening”이라고 말하거나 공개 리포지터리에서 /oss-hygiene 를 호출할 때 사용합니다. 멱등성을 보장해 재실행해도 안전하며, 템플릿과의 차이를 보여주고 덮어쓰기 전 확인을 요청합니다. 이는 /gh-bootstrap(머지 버튼 + 브랜치 보호) 및 /safe-settings(조직 차원 설정을 코드로 관리)와는 구별됩니다: 기여자와 공급망에 직접 노출되는 부분에 집중하고, 머지나 조직 정책에는 관여하지 않습니다. /gh-bootstrap 이후, 리포지터리를 알리기 전 실행합니다.
