Amener un dépôt GitHub open‑source aux normes communautaires et à la base d’hygiène de la chaîne d’approvisionnement : créer les fichiers des GitHub Community Standards (vérification du README, LICENSE, CODE_OF_CONDUCT, CONTRIBUTING, SECURITY, modèles d’issues et de PR), configurer les mises à jour de version de Dependabot, l’action Dependency Review, l’OpenSSF Scorecard et CodeQL (le cas échéant), vérifier les alertes Dependabot et le scan de secrets, et ajouter le lien du badge OpenSSF Best Practices. Utiliser lorsque l’utilisateur dit « set up OSS hygiene », « make this repo open‑source‑ready », « add community health files », « wire dependabot », « add scorecard », « OSSF badge », « supply chain hardening », ou invoque /oss-hygiene sur un repo public. Idempotent — sûr de pouvoir être relancé ; compare les diffs avec les modèles et demande avant d’écraser. Distinct de /gh‑bootstrap (bouton de fusion + protection de branche) et /safe‑settings (paramètres d’organisation en tant que code) : se concentre sur la surface destinée aux contributeurs et à la chaîne d’approvisionnement, pas sur la fusion ou la politique d’organisation. À exécuter après /gh‑bootstrap ; avant d’annoncer le repo.
