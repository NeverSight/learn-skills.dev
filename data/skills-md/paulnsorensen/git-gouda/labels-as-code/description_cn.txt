将 GitHub 仓库的标签管理为版本控制文件，并根据更改的路径自动为拉取请求打标签。导出现有标签，将其与提议的 `.github/labels.yml` 进行差异对比，同步差异（一次性或通过使用单个已验证、SHA 固定的操作的计划工作流），并使用 `actions/labeler` 和 `.github/labeler.yml` 实现基于路径的 PR 打标签。当用户说“standardize labels”“sync labels”“auto-label PRs by path”“labels as code”或调用 /labels-as-code 时使用。不要将其用于跨多个仓库的组织级标签策略——应转到 /safe-settings，该策略从中心管理仓库调和标签（重命名、排除）。也不要用于议题表单或模板——那是 /oss-hygiene 的范围。标签删除永不自动进行；此技能会先请求明确授权。
