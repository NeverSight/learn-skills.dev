Maneja las etiquetas de un repositorio de GitHub como un archivo controlado por versiones y etiqueta automáticamente las pull requests según la ruta modificada. Exporta las etiquetas actuales, compáralas con un `.github/labels.yml` propuesto, sincroniza la diferencia (de forma puntual o mediante un flujo de trabajo programado usando una acción verificada y fijada a un SHA), y conecta el etiquetado basado en rutas con `actions/labeler` y `.github/labeler.yml`. Úsalo cuando el usuario diga "standardize labels", "sync labels", "auto-label PRs by path", "labels as code" o invoque /labels-as-code. NO lo uses para una política de etiquetas a nivel organizativo en varios repositorios — dirige eso a /safe-settings, que reconcilia etiquetas (renombrar, excluir) desde un repositorio administrativo central. NO lo uses para formularios o plantillas de issues — eso corresponde a /oss-hygiene. Las eliminaciones de etiquetas nunca son automáticas; la habilidad solicita autorización explícita primero.

Por favor, responde siempre en el idioma del usuario.
