إدارة علامات مستودع GitHub كملف يتم التحكم فيه بالإصدار وتطبيق علامات تلقائية على طلبات السحب بناءً على المسار المتغيّر. تصدير العلامات الحالية، ومقارنتها بملف `.github/labels.yml` المقترح، ومزامنة الاختلاف (مرة واحدة أو عبر سير عمل مجدول باستخدام إجراء موثّق ومثبت على SHA)، وربط وضع العلامات بناءً على المسار مع `actions/labeler` و`.github/labeler.yml`. استخدم ذلك عندما يقول المستخدم «توحيد العلامات»، «مزامنة العلامات»، «تطبيق علامات تلقائية على طلبات السحب حسب المسار»، «العلامات ككود»، أو يستدعي /labels-as-code. لا تستخدمه لسياسة العلامات على مستوى المؤسسة عبر عدة مستودعات — وجه ذلك إلى /safe-settings، الذي ينسق العلامات (إعادة تسمية، استثناء) من مستودع إداري مركزي. لا تستخدمه لنماذج القضايا أو القوالب — فهذا يخص /oss-hygiene. حذف العلامات لا يكون تلقائيًا أبدًا؛ تُطلب الموافقة الصريحة أولًا.
