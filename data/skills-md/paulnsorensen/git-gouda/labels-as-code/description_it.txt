Gestisci le etichette di un repository GitHub come un file versionato e auto‑etichetta le pull request in base al percorso modificato. Esporta le etichette attuali, confrontale con un file proposto `.github/labels.yml`, sincronizza la differenza (una tantum o tramite un workflow pianificato usando una sola action verificata e con SHA fissato) e collega l’etichettatura delle PR basata sul percorso con `actions/labeler` e `.github/labeler.yml`. Usa quando l’utente dice “standardize labels”, “sync labels”, “auto‑label PRs by path”, “labels as code” o invoca /labels-as-code. NON usare per una politica di etichette a livello di organizzazione su molti repository — indirizzalo a /safe-settings, che riconcilia le etichette (rinomina, esclude) da un repository admin centrale. NON usare per moduli o template di issue — quello è /oss-hygiene. Le cancellazioni di etichette non sono mai automatiche; la skill richiede prima un’autorizzazione esplicita.  

Rispondi sempre nella lingua dell’utente.
