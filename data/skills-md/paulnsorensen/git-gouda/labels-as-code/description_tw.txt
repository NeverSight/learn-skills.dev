將 GitHub 儲存庫的標籤作為受版本控制的檔案管理，並根據變更路徑自動為 Pull Request 加標籤。匯出目前的標籤，將其與提議的 `.github/labels.yml` 進行差異比較，同步差異（一次性或透過使用已驗證、SHA 鎖定的 action 的排程工作流程），並使用 `actions/labeler` 以及 `.github/labeler.yml` 連結基於路徑的 PR 標籤。當使用者說「standardize labels」、「sync labels」、「auto-label PRs by path」、「labels as code」或呼叫 /labels-as-code 時使用此方法。不要將其用於跨多個儲存庫的組織級標籤政策——應將此需求導向 /safe-settings，該流程會從中心管理儲存庫調和標籤（重新命名、排除）。也不要用於議題表單或範本——那屬於 /oss-hygiene。標籤刪除永遠不會自動執行；此功能會先徵求明確授權。
