GitHub 리포지토리의 라벨을 버전 관리 파일로 관리하고, 변경된 경로에 따라 풀 리퀘스트를 자동 라벨링합니다. 현재 라벨을 내보내고, 제안된 `.github/labels.yml`과 차이를 비교한 뒤 차이를 동기화합니다(한 번 실행하거나 검증된 SHA 고정 액션을 사용한 스케줄 워크플로를 통해). `actions/labeler`와 `.github/labeler.yml`을 사용해 경로 기반 PR 라벨링을 연결합니다. 사용자가 “standardize labels”, “sync labels”, “auto-label PRs by path”, “labels as code”라고 말하거나 /labels-as-code를 호출할 때 사용합니다. 여러 리포지토리에 걸친 조직 수준 라벨 정책에는 사용하지 마세요 — 이를 위해서는 중앙 관리 리포지토리에서 라벨(이름 변경, 제외)을 조정하는 /safe-settings로 라우팅합니다. 이슈 폼이나 템플릿에도 사용하지 마세요 — 해당 기능은 /oss-hygiene입니다. 라벨 삭제는 절대 자동으로 이루어지지 않으며, 스킬은 명시적인 권한 승인을 먼저 요청합니다.
