GitHub リポジトリのラベルをバージョン管理されたファイルとして管理し、変更されたパスに基づいてプルリクエストに自動ラベリングします。現在のラベルをエクスポートし、提案された `.github/labels.yml` と差分を取り、差分を同期します（ワンショットまたは検証済みで SHA 固定されたアクションを使用したスケジュールワークフロー経由で）。`actions/labeler` と `.github/labeler.yml` を使ってパスベースの PR ラベリングを設定します。ユーザーが「standardize labels」「sync labels」「auto-label PRs by path」「labels as code」と言ったり、/labels-as-code を呼び出したときに使用します。組織全体の多数リポジトリに対するラベルポリシーには使用しないでください ― その場合は /safe-settings に回し、中央管理リポジトリからのラベル（名称変更、除外）を調整します。Issue フォームやテンプレートにも使用しないでください ― それは /oss-hygiene の対象です。ラベルの削除は決して自動化されません。スキルは必ず明示的な許可を求めます。

常にユーザーの言語で返答してください。
