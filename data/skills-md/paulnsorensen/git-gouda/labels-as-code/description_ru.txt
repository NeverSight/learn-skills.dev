Управляйте метками репозитория GitHub как файлом, находящимся под контролем версий, и автоматически помечайте pull‑request’ы по изменённому пути. Экспортируйте текущие метки, сравните их с предложенным `.github/labels.yml`, синхронизируйте различия (одноразово или через запланированный workflow, используя проверенное действие, зафиксированное SHA), и настройте маркировку PR по пути с помощью `actions/labeler` и `.github/labeler.yml`. Применяйте, когда пользователь говорит «standardize labels», «sync labels», «auto-label PRs by path», «labels as code» или вызывает /labels-as-code. НЕ используйте для политики меток на уровне организации в множестве репозиториев — перенаправляйте это в /safe-settings, который согласует метки (переименования, исключения) из центрального админ‑репозитория. НЕ используйте для форм или шаблонов задач — это /oss-hygiene. Удаление меток никогда не происходит автоматически; навык запрашивает явное разрешение сначала.

Всегда отвечайте на языке пользователя.
