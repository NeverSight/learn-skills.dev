プロダクトデザインの図や1ページのリードアウト、ダッシュボード、ステータス更新を、ブロック文字（░▒▓█）やボックス描画文字でテキストとして描きます――調査結果やアンケート結果、ファネルやA/Bテスト、UXフローやステートマシン、ロードマップ、画面ワイヤーフレーム、デザインシステムのドキュメント、ハンドオフやQAチェックリスト、モーション仕様や動く図など。ASCII または Unicode の図、テキストワイヤーフレーム、スパークラインや棒グラフを Markdown で、プルリクエスト、チケット、ドキュメントに使用したり、デザインレビュー資料、PDF のレポートや監査に利用したり、テキストワイヤーフレームを HTML プロトタイプやプロジェクトのデザインシステムからのコンポーネントに変換したりできます。小さな JSON 仕様書（実データを含む）から描画し、Markdown、MDX、HTML、SVG、PNG、PDF でエクスポートします。
