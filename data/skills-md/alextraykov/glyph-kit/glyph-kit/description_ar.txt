يرسم مخططات تصميم المنتجات وملخصات صفحة واحدة، ولوحات التحكم وتحديثات الحالة كنصوص باستخدام رموز الكتلة (░▒▓█) ورموز رسم الصناديق – نتائج الأبحاث والاستبيانات، القمع واختبارات A/B، تدفقات تجربة المستخدم وآلات الحالة، خرائط الطريق، إطارات الشاشة، وثائق نظام التصميم، قوائم التحقق للتسليم وضمان الجودة، مواصفات الحركة والرسوم المتحركة. يستخدم لإنشاء مخطط ASCII أو Unicode، أو إطار نصي، أو مخطط شرائح أو مخطط شريطي في Markdown، أو طلب سحب، أو تذكرة، أو مستند؛ أو عرض مراجعة التصميم؛ أو تقرير أو تدقيق بصيغة PDF؛ أو لتحويل إطار نصي إلى نموذج أولي HTML أو مكونات من نظام تصميم المشروع. يستند إلى مواصفات JSON صغيرة تحتوي على بيانات حقيقية ومصدرة، ويصدّر بصيغ Markdown وMDX وHTML وSVG وPNG وPDF.
