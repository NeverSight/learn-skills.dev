Canary Drill für das Akzeptanznetzwerk: Betten Sie für Code, der gerade die Akzeptanz bestanden hat, heimlich einen gut getarnten Fehler in einen einmaligen Arbeitsbereich ein, sodass der bestehende Akzeptanzprozess ohne Wissen wie gewohnt ablaufen kann, und weisen Sie dann jedem Gate zu, „welches Gate es blockiert hat, welches Gate es verpasst hat“, um die tatsächliche Abhörfähigkeit des Akzeptanznetzwerks zu kalibrieren. Wird nur freiwillig vom Benutzer initiiert („Bombenübung/Kanarienübung/Akzeptanznetzwerk kalibrieren“) und muss in einer neuen Sitzung ohne Arbeitskontext ausgeführt werden. Der Agent darf diese Fertigkeit weder proaktiv vorschlagen noch in einer Sitzung ausführen, die eine Implementierungs- oder Akzeptanzhistorie enthält.
