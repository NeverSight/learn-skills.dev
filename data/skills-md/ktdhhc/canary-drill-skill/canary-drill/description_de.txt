Canary-Übung für das Akzeptanznetzwerk: Betten Sie für Code, der gerade die Akzeptanz bestanden hat, heimlich einen gut getarnten Fehler in einen einmaligen Arbeitsbereich ein, sodass der bestehende Akzeptanzprozess wie gewohnt ablaufen kann, ohne es zu wissen, und weisen Sie dann jedem Gate zu, „welches Gate blockiert, welches Gate verfehlt“ wurde, um die tatsächliche Abhörfähigkeit des Akzeptanznetzwerks zu kalibrieren. Dies ist auf vom Benutzer initiierte Aktionen beschränkt („Minenpflanzungsübung durchführen / Kanarienvogelübung ausführen / Akzeptanznetzwerk kalibrieren“) und muss in einer neuen Sitzung ohne Arbeitskontext ausgeführt werden – der Agent darf diese Fähigkeit nicht proaktiv vorschlagen oder sie in Sitzungen ausführen, die eine Implementierungs- oder Akzeptanzhistorie enthalten.
