Utilízalo cuando el usuario necesite un .docx listo para envío — convertir tesis a Word, maquetación de tesis, maquetación para envío a revistas, preparar el documento de envío — o una copia legible del manuscrito. No es para salida en PDF, HTML o LaTeX, ni para presentaciones o formularios de subvención.
