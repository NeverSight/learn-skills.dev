قم بتجميع مخطوطة أكاديمية بصيغة Markdown إلى ملف Word (.docx) متوافق مع معايير المجلات أو المؤسسات التعليمية: تنسيق طباعي محدد، معادلات OMML أصلية، جداول بثلاث خطوط، مرجعيات متقاطعة، أرقام صفحات لكل قسم، قوائم مراجع CSL (GB/T 7714، APA، Nature، IEEE)، وبوابات جودة قبل/بعد التصدير.  

قم بتصدير مخطوطة البحث الأكاديمي بصيغة Markdown إلى ملف Word يلتزم بمعايير المجلات أو متطلبات الرسائل الجامعية: الملخص، ترقيم المعادلات، جداول ثلاثية الخطوط، عناوين الفقرات، مراجع متقاطعة، حقول الفهرس، قائمة المراجع.  

استخدمه عندما يرغب المستخدم في ملف .docx جاهز للتقديم — تحويل البحث إلى Word، تنسيق رسالة علمية، تنسيق تقديم إلى مجلة، إعداد مستند تقديم — أو نسخة قابلة للقراءة من المخطوطة. غير مخصص لإخراج PDF أو HTML أو LaTeX، ولا للعرض التقديمي أو نماذج المنح.  

يرجى دائماً الرد بلغة المستخدم.
