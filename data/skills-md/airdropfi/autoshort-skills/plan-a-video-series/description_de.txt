Planen Sie eine gesichtslose Kurzvideoserie mit mehreren Episoden auf dem AutoShort- oder StoryShort-Konto des Benutzers, bevor etwas produziert wird. Entwerfen Sie auf AutoShort die Saison, speichern Sie den Saisonplan, führen Sie die Überprüfung durch, erhalten Sie die ausdrückliche Bestätigung des Benutzers, zitieren Sie und erstellen Sie eine Episode nach der anderen. Vereinbaren Sie auf StoryShort den Plan im Chat, erstellen Sie die angehaltene Serie und setzen Sie sie erst fort, nachdem der Benutzer die Kosten genehmigt hat. Wird verwendet, wenn der Benutzer eine Serie, eine Staffel, ein kurzes Drama, wiederkehrende Charaktere oder einen geplanten Kanal wünscht.
