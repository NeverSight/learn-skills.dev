Meta XR Interaction SDK (com.meta.xr.sdk.interaction.ovr) dans Unity. Utilisez‑le lorsqu’on ajoute UNE QUELCONQUE interaction à une scène Meta VR ou Horizon OS – saisir (main, distance, rayon, toucher), piquer, téléportation/locomotion, regard, toiles UI interactives – lors de la création d’un objet saisissable, de l’ajout d’interacteurs aux mains ou aux contrôleurs, de la mise en place d’un rig d’interaction, ou de l’intégration de l’interaction dans un prefab ou une scène dont le rig se charge ailleurs (dynamiquement, DontDestroyOnLoad, de façon additive). Utilisez le backend OVR sauf si l’utilisateur demande explicitement la prise en charge multiplateforme. Couvre QuickActionsAPI et OVRQuickActionsAPI comme méthode par défaut pour connecter les interactions, les exécuter via unity‑cli, un script d’éditeur ou MCP, l’installation, ainsi que le comportement non documenté selon lequel la lecture du code source ou une exécution en mode Play est autrement nécessaire pour la découverte.
