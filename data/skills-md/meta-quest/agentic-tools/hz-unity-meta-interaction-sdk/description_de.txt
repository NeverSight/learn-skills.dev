Meta XR Interaction SDK (com.meta.xr.sdk.interaction.ovr) in Unity. Verwenden Sie es, wenn Sie irgendeine Interaktion zu einer Meta‑VR‑ oder Horizon‑OS‑Szene hinzufügen – Greifen (Hand, Distanz, Strahl, Touch), Stupsen, Teleport/Locomotion, Blick, interaktive UI‑Leinwände – beim Erstellen eines greifbaren Objekts, dem Hinzufügen von Interaktoren zu Händen oder Controllern, dem Erstellen eines Interaktions‑Rigs oder dem Einbetten von Interaktionen in ein Prefab oder eine Szene, deren Rig sonstwo geladen wird (dynamisch, DontDestroyOnLoad, additiv). Verwenden Sie das OVR‑Backend, es sei denn, der Nutzer verlangt ausdrücklich plattformübergreifend. Beinhaltet QuickActionsAPI und OVRQuickActionsAPI als Standardmethode zum Verkabeln von Interaktionen, deren Ausführung über unity‑cli, ein Editor‑Skript oder MCP, Installation sowie das undokumentierte Verhalten, dass ansonsten das Auslesen der Quelle oder ein Play‑Mode‑Durchlauf nötig ist, um sie zu entdecken.
