Meta XR Interaction SDK (com.meta.xr.sdk.interaction.ovr) in Unity. Da utilizzare quando si aggiunge QUALSIASI interazione a una scena Meta VR o Horizon OS — afferrare (mano, distanza, raggio, tocco), puntare, teletrasporto/locomozione, sguardo, canvas UI interattivi — quando si rende un oggetto afferrabile, si aggiungono interactors a mani o controller, si crea un rig di interazione o si incorpora l'interazione in un prefab o in una scena il cui rig viene caricato altrove (dinamicamente, DontDestroyOnLoad, in aggiunta). Utilizzare il backend OVR a meno che l'utente richieda esplicitamente il cross‑platform. Copre QuickActionsAPI e OVRQuickActionsAPI come metodo predefinito per collegare le interazioni, eseguendole tramite unity‑cli, uno script Editor o MCP, l'installazione e il comportamento non documentato per il quale è necessario leggere la sorgente o eseguire una modalità Play per scoprirlo.
