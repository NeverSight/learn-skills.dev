Meta XR Interaction SDK（com.meta.xr.sdk.interaction.ovr）Unity 用。Meta VR または Horizon OS のシーンに任意のインタラクション（手、距離、レイ、タッチによる掴み、ポーク、テレポート／ロコモーション、視線、インタラクト可能な UI キャンバス）を追加する際に使用します。オブジェクトを掴めるようにしたり、手やコントローラーにインタラクタを追加したり、インタラクションリグを作成したり、リグが別の場所でロードされる（動的に、DontDestroyOnLoad、アディティブに）プレハブやシーンにインタラクションをベイクしたりする場合に使用します。ユーザーが明示的にクロスプラットフォームを要求しない限り、OVR バックエンドを使用してください。QuickActionsAPI と OVRQuickActionsAPI をデフォルトのインタラクション配線手段として扱い、unity‑cli、エディタスクリプト、または MCP 経由で実行し、インストールやソースの読み取り、または Play‑mode 実行がないと発見できないという未文書化の挙動もカバーしています。
