Meta Quest 透视相机访问（PCA）用于 Unity — 访问 Quest 3 / Quest 3S 前置 RGB 相机，以供计算机视觉和机器学习管道使用。在捕获透视相机图像/纹理、读取相机姿态和内参、通过 `PassthroughCameraAccess.ViewportPointToRay` 将相机像素投射到世界空间、将相机帧接入 ML/CV 模型，或在解析分辨率、权限、供应商标签以及针孔/主点模型时使用。若要将图像投射到平面世界空间表面（视锥切片四边形 / 图像平面叠加），请参阅 references/principal-point-offset.md；若要将 2D ML 检测结果放置为世界空间 3D 包围盒，请参阅 references/detection-bounding-boxes.md。如果用户仅想投射用户的视角（请改用 Media Projection API）或只做屏幕空间叠加，可跳过本功能。
