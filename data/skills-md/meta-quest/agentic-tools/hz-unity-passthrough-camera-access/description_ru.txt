Meta Quest Passthrough Camera Access (PCA) для Unity — доступ к фронтальным RGB‑камерам на Quest 3 / Quest 3S для подачи данных в конвейеры компьютерного зрения и машинного обучения. Используйте при захвате изображения/текстуры камеры сквозного просмотра, чтении положения и внутренних параметров камеры, проекции пикселей камеры в мировое пространство через `PassthroughCameraAccess.ViewportPointToRay`, передаче кадров камеры в модели ML/CV или при работе с разрешением, разрешениями, тегами поставщика и моделью pinhole/главная‑точка. Для проекции изображения на плоскую поверхность в мировом пространстве (фрагмент‑куб пирамиды / наложение на плоскость изображения) см. references/principal-point-offset.md; для размещения 2D‑детекций ML в виде 3D‑ограничительных коробок в мировом пространстве см. references/detection-bounding-boxes.md. Пропустите, если пользователь хочет лишь отобразить точку зрения пользователя (используйте вместо этого Media Projection API) или создаёт только наложения в экранном пространстве.
