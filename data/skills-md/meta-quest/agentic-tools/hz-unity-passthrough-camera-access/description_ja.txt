Meta Quest Passthrough Camera Access（PCA） for Unity — Quest 3 / Quest 3S の前方向き RGB カメラにアクセスし、コンピュータビジョンや機械学習のパイプラインに供給します。透過カメラの画像／テクスチャを取得したり、カメラの姿勢や内部パラメータを読み取ったり、`PassthroughCameraAccess.ViewportPointToRay` を用いてカメラピクセルをワールド空間に射影したり、カメラフレームを ML／CV モデルに流し込んだり、解像度、権限、ベンダータグ、ピンホール／主点モデルについて検討する際に使用します。画像を平坦なワールド空間のサーフェス（フラスタムスライス・クアッド／画像平面オーバーレイ）に射影する方法は references/principal-point-offset.md を参照してください。2D の ML 検出結果をワールド空間の 3D バウンディングボックスとして配置する方法は references/detection-bounding-boxes.md を参照してください。ユーザーが POV のみを投影したい場合（代わりに Media Projection API を使用）や、スクリーンスペースのみのオーバーレイを行う場合は省略してください。
