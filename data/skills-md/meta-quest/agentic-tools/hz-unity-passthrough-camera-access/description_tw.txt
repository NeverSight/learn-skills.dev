Meta Quest Passthrough Camera Access（PCA） for Unity — 允許存取 Quest 3 / Quest 3S 前置的 RGB 相機，以供電腦視覺與機器學習管線使用。當需要捕捉透視相機影像／紋理、讀取相機姿態與內部參數、透過 `PassthroughCameraAccess.ViewportPointToRay` 將相機像素投射至世界空間、將相機影格接入 ML/CV 模型，或是對解析度、權限、廠商標籤、以及針孔/主點模型進行推論時使用。若要將影像投射到平面世界空間表面（視錐體切片四邊形／影像平面覆蓋），請參考 references/principal-point-offset.md；若要將 2D ML 偵測結果放置為世界空間的 3D 邊框，請參考 references/detection-bounding-boxes.md。若使用者僅想投射使用者的視角（改用 Media Projection API）或僅做螢幕空間覆蓋，則可跳過此項。
