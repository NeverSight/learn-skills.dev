Meta Quest Passthrough Camera Access(PCA) for Unity — Quest 3 / Quest 3S의 전면 RGB 카메라에 접근하여 컴퓨터 비전 및 머신 러닝 파이프라인에 활용합니다. Passthrough 카메라 이미지/텍스처를 캡처하거나, 카메라 자세 및 내부 파라미터를 읽어오고, `PassthroughCameraAccess.ViewportPointToRay`를 통해 카메라 픽셀을 월드 공간에 투사할 때, 카메라 프레임을 ML/CV 모델에 연결할 때, 혹은 해상도·권한·벤더 태그·핀홀·주점 모델 등을 고려할 때 사용합니다. 이미지를 평평한 월드 공간 표면(시야볼록체 슬라이스 쿼드·이미지 평면 오버레이)에 투사하려면 references/principal-point-offset.md 를 참고하고, 2D ML 감지를 월드 공간 3D 경계 상자로 배치하려면 references/detection-bounding-boxes.md 를 참고하세요. 사용자가 단순히 사용자의 POV만을 투사하려는 경우(대신 Media Projection API 사용) 혹은 화면 공간 오버레이만 수행하려는 경우는 건너뛰세요.
