Instala y configura el simulador Meta XR para probar las aplicaciones Meta VR y Horizon OS sin un dispositivo físico. Úselo al instalar el simulador o integrarlo con proyectos Unity, Unreal o OpenXR nativos. Para controlar un simulador de carrera, utilice hz-xr-simulator-control. Construya rutas: Unity, Unreal y OpenXR nativo; enrute Android estándar, Meta Spatial SDK y WebXR a través de hz-quest-verify-first.
