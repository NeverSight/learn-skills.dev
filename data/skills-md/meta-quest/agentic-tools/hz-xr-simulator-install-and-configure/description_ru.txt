Устанавливает и настраивает симулятор Meta XR для тестирования приложений Meta VR и Horizon OS без физического устройства. Используйте при установке симулятора или интеграции его с Unity, Unreal или нативными проектами OpenXR. Для управления работающим симулятором используйте hz-xr-simulator-control. Пути сборки: Unity, Unreal и нативный OpenXR; маршрутизируйте Standard Android, Meta Spatial SDK и WebXR работу через hz-quest-verify-first.
