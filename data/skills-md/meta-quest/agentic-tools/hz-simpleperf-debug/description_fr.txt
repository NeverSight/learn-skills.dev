Profiles Meta VR and Horizon OS application CPU performance using simpleperf — workload classification, CPU hotspot recording, kernel overhead measurement. À utiliser pour diagnostiquer si une application est liée au processeur, à la mémoire ou aux E/S sur les appareils Meta VR. Chemins de génération : toutes les piles d'applications Meta VR ; utilisez hz-quest-verify-first si le chemin de génération n'est pas clair.
