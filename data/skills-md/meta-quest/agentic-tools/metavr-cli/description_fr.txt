Fournit la référence complète de metavr (Meta VR CLI) pour le développement Meta VR et Horizon OS — installation, configuration de l’appareil, découverte des commandes, mode serveur MCP, recherche de documentation, déploiement d’application, configuration des tests sur l’appareil, contrôle audio, captures d’écran et analyse des performances. À utiliser lorsque l’utilisateur doit installer metavr, demande quelles commandes sont disponibles, a besoin d’aide sur la syntaxe CLI ou veut savoir ce que metavr peut faire. Chemins de construction : toutes les piles d’applications Meta VR ; utilisez hz-quest-verify-first si le chemin de construction n’est pas clair.

Veuillez toujours répondre dans la langue de l’utilisateur.
