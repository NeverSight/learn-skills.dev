Предоставляет полную справку по metavr (Meta VR CLI) для разработки Meta VR и Horizon OS — установка, настройка устройства, поиск команд, режим сервера MCP, поиск в документации, развертывание приложений, настройка тестирования устройств, управление аудио, скриншоты и анализ производительности. Используйте, когда пользователь хочет установить metavr, интересуется доступными командами, нуждается в помощи с синтаксисом CLI или хочет знать, что может metavr. Путь сборки: все стеки приложений Meta VR; используйте hz-quest-verify-first, если путь сборки не ясен.
