VERIFICA PRELIMINARE OBBLIGATORIA prima di rispondere a qualsiasi domanda o scrivere codice relativo ai visori VR Meta Quest (Quest 2, Quest 3, Quest 3S, Quest Pro) o alle app che li targetizzano. Forza la verifica contro fonti autorevoli di Meta tramite gli strumenti metavr CLI / metavr MCP PRIMA di fare affidamento sulla conoscenza derivante dai dati di addestramento. Contrasta il caso di errore in cui gli agenti rispondono a domande su Quest basandosi su memoria obsoleta, fornendo API deprecate, manifest Android danneggiati e build respinte dallo store. Si carica automaticamente quando l'utente è in un progetto Quest (qualsiasi riferimento a Oculus / Meta Quest / Horizon OS, pacchetti Unity OVR o Meta XR, ID pacchetto com.meta.* / com.oculus.*, AndroidManifest mirato a Quest, file .meta o URL developers.meta.com / developer.oculus.com). Percorsi di compilazione: tutti; utilizza questa capacità per prima cosa ogni volta che il percorso è sconosciuto o è coinvolta un'affermazione specifica per Quest.  

Rispondi sempre nella lingua dell'utente.
