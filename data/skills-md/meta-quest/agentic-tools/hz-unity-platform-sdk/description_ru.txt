Описывает интеграцию SDK Horizon Platform для приложений Meta VR и Horizon OS Unity/C# — достижения, внутренняя покупка (IAP), пользователи, таблицы лидеров, челленджи, статус присутствия, уведомления, сообщения о злоупотреблениях, права доступа, файлы ресурсов, жизненный цикл приложения, согласие, целостность устройства, языковые пакеты, возрастные категории пользователей и оценка с отзывами. Охватывает настройку, инициализацию, использование API, типы данных, обработку ошибок и лучшие практики для всех 18 публичных пакетов SDK платформы.
