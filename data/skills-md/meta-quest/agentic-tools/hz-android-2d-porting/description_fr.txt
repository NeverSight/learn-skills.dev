Guides de portage des applications Android 2D existantes vers Meta VR et Horizon OS — adaptation des entrées, disposition des panneaux et exigences de conception. À utiliser lors de l’adaptation d’une application Android mobile pour Meta VR. Pour les décisions de conception UI, utilisez hz-panel-designer si disponible. Chemin de construction : Android standard ; utilisez hz-quest-verify-first si le chemin de construction n’est pas clair.
