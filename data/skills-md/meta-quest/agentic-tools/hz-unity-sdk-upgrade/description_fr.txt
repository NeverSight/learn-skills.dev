Mise à niveau des projets Unity entre les versions du Meta XR SDK pour Meta VR et Horizon OS. À utiliser lors du passage d’Oculus Integration ou d’anciens packages com.meta.xr, pour résoudre les erreurs de compilation post‑mise à jour ou valider le comportement à l’exécution. Base les décisions de migration sur les résultats de la documentation actuelle de metavr et consigne les lacunes de couverture plutôt que de se fier à des résumés statiques. Ne pas utiliser pour les mises à jour d’Unreal, Android natif, Spatial SDK ou WebXR.
