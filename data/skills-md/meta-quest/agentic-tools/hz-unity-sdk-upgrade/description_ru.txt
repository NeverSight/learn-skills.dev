Обновляет проекты Unity между версиями Meta XR SDK для Meta VR и Horizon OS. Используйте при переходе с Oculus Integration или более старых пакетов com.meta.xr, исправлении ошибок компиляции после обновления или проверке поведения во время выполнения. Обоснует решения по миграции текущими результатами документации metavr и фиксирует пробелы в покрытии вместо опоры на статические резюме. Не используйте для обновлений Unreal, native Android, Spatial SDK или WebXR.
