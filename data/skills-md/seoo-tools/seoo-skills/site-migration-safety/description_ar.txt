احمِ أداء البحث أثناء أي تغيير يغيّر عناوين URL أو طريقة تقديم الصفحات: نقل النطاق، تغيير HTTPS/‏www/النطاق الفرعي، تغيير المنصة أو الإطار، إعادة هيكلة URL، إعادة كتابة القالب أو العرض، تغيير نظام إدارة المحتوى، إعادة هيكلة hreflang/الدولي، أو دمج/حذف الصفحات. استخدمه عندما يقول المستخدم: "أنا أنقل موقعي"، "نحن نغيّر هيكل عناوين URL"، "أنا أدمج هذه الصفحات"، أو "هل أثرت عملية الترحيل على تحسين محركات البحث؟". لا يُستخدم لتشخيص انخفاض غير مفسّر في الزيارات (تشخيص انخفاض الزيارات) أو لتدقيق فني عام. يرجى دائمًا الرد بلغة المستخدم.
