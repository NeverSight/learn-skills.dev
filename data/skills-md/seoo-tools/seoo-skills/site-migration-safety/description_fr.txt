Protégez les performances de recherche lors de toute modification qui change les URL ou la façon dont les pages sont servies : déplacement de domaine, changement HTTPS/www/sous‑domaine, migration de plateforme ou changement de framework, restructuration d’URL, réécriture de modèle ou de rendu, changement de CMS, restructuration hreflang/internationale, ou fusion/suppression de pages. À utiliser lorsqu’un utilisateur dit « Je déplace mon site », « Nous changeons notre structure d’URL », « Je fusionne ces pages » ou « Ma migration a‑t‑elle cassé le SEO ? ». Pas pour diagnostiquer une chute de trafic inexpliquée (diagnostic de chute de trafic) ou un audit technique général. Veuillez toujours répondre dans la langue de l’utilisateur.
