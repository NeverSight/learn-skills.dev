Auditez les fondamentaux du SEO technique d’une page — balises méta, URL canoniques, données structurées, hiérarchie des titres, bases mobiles. Utilisez‑le lors de l’audit de la configuration technique on‑page d’une page, lorsqu’un utilisateur demande « mon SEO technique est‑il correct », ou dans le cadre d’un audit complet du site aux côtés de l’audit de qualité des pages et de l’audit du maillage interne (ce pack). Cette dimension évolue dans le temps (Google supprime périodiquement certains types de résultats enrichis) — vérifiez l’état actuel plutôt que de vous fier à une liste fixe.
