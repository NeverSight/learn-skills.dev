Überprüfen Sie jede sachliche Behauptung, Zahl, Schwelle, Rate, Spezifikation oder Regel, die auf einer Inhaltsseite veröffentlicht wurde, anhand ihrer einzigen autoritativen kanonischen Quelle, bevor Sie sie veröffentlichen oder bearbeiten. Verwenden Sie dies, bevor Sie eine Zahl im Inhalt ändern, wenn Sie bestätigen möchten, ob ein gekennzeichneter Abschnitt tatsächlich falsch ist, oder wenn Sie eine Seite auf sachliche Genauigkeit prüfen. Auslösen, wenn ein Benutzer fragt „audit my site's accuracy“, „is this figure still correct“, „what's the source for X“ oder wenn ein weitergehender Qualitätsaudit von Inhalten durchgeführt wird, der sachliche Behauptungen berührt. Voraussetzung für content-freshness-audit und protected-field-audit (dieses Paket).
