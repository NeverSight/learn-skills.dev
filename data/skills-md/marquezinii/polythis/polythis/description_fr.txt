Audit d'adéquation du langage pour n'importe quel code base, quel que soit le langage. À utiliser lorsque l'utilisateur se demande si un projet, un service ou un module doit être réécrit ou partiellement porté vers un autre langage (C, C++, Rust, Go, C#, Java, Zig, Swift, etc.), si le langage actuel est le bon choix, ou quand un addon natif, WebAssembly, un sidecar ou une consolidation de langages serait bénéfique. À utiliser également lorsque les chemins critiques, les pauses du GC, le travail CPU‑intensif dans un environnement interprété, les explosions de mémoire, le démarrage lent ou le code bas niveau sujet aux bugs suggèrent qu'un autre langage serait plus approprié, y compris les décisions concernant les modules natifs pour Electron, Node, Python, la JVM et .NET. Veuillez toujours répondre dans la langue de l'utilisateur.
