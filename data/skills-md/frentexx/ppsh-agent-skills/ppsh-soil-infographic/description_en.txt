單頁資訊圖表（懶人包）技能。把要點、辦法、流程、統計整理成「一張圖看完」的 PNG， 用 HTML + CSS + SVG 排版，再以 headless Chrome 渲染成高 DPI 圖檔。 文字與數字 100% 精準可控，改一個字只要 3 秒重算，不會像 AI 生圖那樣糊掉或亂碼。 當使用者說「做懶人包」、「做資訊圖表」、「做一張圖說明」、「做圖卡」、 「一張圖看懂」、「做成 PNG」、「做張圖發 LINE 群」、「公告用的圖」、 「把這份要點做成一張圖」、「infographic」時，請一定要使用此技能。 **預設不呼叫 ppsh-draw 技能**：裝飾一律用向量 SVG，除非使用者明確說要 AI 插圖或精美圖卡。 本技能與 ppsh-soil-html-deck 的差別：那是多頁簡報（要翻頁、深色、投影用）， 本技能是單頁圖檔（不翻頁、淺色、發出去給人看）。兩者不可互相代用。
