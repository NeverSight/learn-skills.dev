Choisissez les outils natifs de l'écosystème pour les versions et les journaux de modifications (Changesets, Melos, release-plz) ainsi que la distribution binaire (tarballs GitHub Release, install.sh) lorsque le produit est un exécutable. Utilisez-les pour le CI de publication, install.sh, le versionnage, les CHANGELOGs, la distribution de MCP/CLI sans clonage, ou les méta‑repos qui ne livrent que des compétences via npx skills — et non des tutoriels d’applications métier.
