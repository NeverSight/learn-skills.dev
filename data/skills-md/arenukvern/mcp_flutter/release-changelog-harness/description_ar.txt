يختار أدوات إصدار وتغيير سجل الأصلية للمنظومة (Changesets، Melos، release-plz) بالإضافة إلى توزيع الثنائيات (حزم GitHub Release بصيغة tarball، install.sh) عندما يكون المنتج قابلاً للتنفيذ. استخدمها لتكامل الإصدارات المستمر (CI)، install.sh، إدارة الإصدارات، سجلات التغييرات (CHANGELOGs)، شحن MCP/CLI دون استنساخ، أو المستودعات الفوقية التي تُرسل المهارات فقط عبر npx skills — ليس دروس التطبيقات المتخصصة.
