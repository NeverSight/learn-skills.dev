Elige herramientas nativas del ecosistema para la publicación y el registro de cambios (Changesets, Melos, release-plz) junto con la distribución de binarios (tarballs de GitHub Release, install.sh) cuando el producto es un ejecutable. Úsalo para CI de lanzamiento, install.sh, versionado, CHANGELOGs, distribuir MCP/CLI sin clonar, o repositorios meta que solo envían habilidades mediante npx skills, no tutoriales de aplicaciones de dominio.
