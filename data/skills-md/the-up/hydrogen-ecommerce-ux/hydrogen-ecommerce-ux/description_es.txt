Mejores prácticas de UX respaldadas por investigación para tiendas Shopify Hydrogen, basadas en el Baymard Institute (más de 200 000 horas de investigación de usabilidad) y los estudios del Nielsen Norman Group. Utiliza esta habilidad CUANDO EL USUARIO esté construyendo, revisando o mejorando cualquier parte de un sitio de comercio electrónico Shopify Hydrogen — incluyendo la página de inicio, páginas de colecciones/listado, páginas de producto, carrito, proceso de pago, búsqueda, filtros, UX móvil, accesibilidad o aspectos de confianza/credibilidad. También aplícala cuando el usuario solicite una revisión de código de componentes Hydrogen, quiera generar una nueva ruta o componente, o mencione conversión, abandono de carrito o problemas de experiencia de compra. Activa la guía incluso si el usuario no menciona explícitamente “UX” — cualquier trabajo en una tienda Hydrogen se beneficia de estas directrices.
