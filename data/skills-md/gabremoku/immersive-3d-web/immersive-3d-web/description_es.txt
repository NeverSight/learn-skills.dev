Habilidad de referencia para crear sitios web 3D interactivos de alta gama (escenas de héroes WebGL, movimientos de cámara con desplazamiento, renderizados de estilo de producto) usando Three.js, React Three Fiber, drei y GSAP ScrollTrigger, incluida la adaptación de 3D a un sitio existente (rediseño/rediseño) sin alterar sus rutas, contenido o accesibilidad actuales. Úselo cuando el usuario desee crear, cambiar el estilo, revisar o depurar una experiencia web 3D/WebGL: lienzos de héroe, secciones con desplazamiento, campos de partículas, objetos instanciados, escenas de navegación/hub o problemas de rendimiento en una escena Three.js/R3F, en un proyecto nuevo o existente. Complementa la habilidad de diseño frontend: el diseño frontend cubre el arte general de UI/UX (diseño, color, accesibilidad), esta habilidad cubre la capa de implementación 3D/WebGL.
