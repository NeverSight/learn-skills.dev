Three.js、React Three Fiber、drei、GSAP ScrollTrigger を使用してハイエンドのインタラクティブ 3D Web サイト (WebGL ヒーロー シーン、スクロール駆動のカメラの動き、製品スタイルのレンダリング) を構築するためのリファレンス スキル。これには、現在のルート、コンテンツ、またはアクセシビリティを損なうことなく、既存のサイトに 3D を組み込む (スタイル変更/再デザイン) ことが含まれます。ユーザーが 3D/WebGL Web エクスペリエンス (ヒーロー キャンバス、スクロール ジャック セクション、パーティクル フィールド、インスタンス化されたオブジェクト、ハブ/ナビゲーション シーン、または Three.js/R3F シーンのパフォーマンスの問題など) を新規または既存のプロジェクトで構築、再スタイル、レビュー、またはデバッグしたい場合に使用します。フロントエンド デザイン スキルを補完します。フロントエンド デザインは一般的な UI/UX クラフト (レイアウト、カラー、アクセシビリティ) をカバーし、このスキルは 3D/WebGL 実装レイヤーをカバーします。
