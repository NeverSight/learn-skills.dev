Verwenden Sie diese Option, wenn der Benutzer die CrowdSec-Konsole **Service API (SAPI)** – die Premium-Cloud-REST-API unter admin.api.crowdsec.net – steuern möchte, um Blocklisten (Hinzufügen/Entfernen/Massen-IPs, Teilen, Abonnement-Engines), Zulassungslisten, Firewall-/Appliance-Integrationen (Palo Alto, Fortinet, Cisco, F5, Sophos, pfSense/OPNsense…), ROI-Metriken für die Behebung usw. programmgesteuert zu verwalten Entscheidungen auf Organisationsebene. Handelt im Namen des Benutzers mit seinem API-Schlüssel. Dies ist der Cloud-/API-Skill – für die lokale Engine, cscli und Bouncer verwenden Sie den „Crowdsec“-Skill.
