ユーザーが CrowdSec コンソール **サービス API (SAPI)** (admin.api.crowdsec.net のプレミアム クラウド REST API) を使用して、ブロックリスト (IP の追加/削除/バルク、共有、サブスクライブ エンジン)、ホワイトリスト、ファイアウォール/アプライアンスの統合 (Palo Alto、Fortinet、Cisco、F5、Sophos、pfSense/OPNsense…)、修復 ROI をプログラムで管理する場合に使用します。指標と組織レベルの決定。ユーザーに代わって API キーを使用します。これはクラウド/API スキルです。ローカル エンジン、cscli、およびバウンサーの場合は、「crowdsec」スキルを使用します。
