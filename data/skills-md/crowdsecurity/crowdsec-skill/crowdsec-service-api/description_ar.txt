يُستخدم عندما يريد المستخدم تشغيل وحدة تحكم CrowdSec **واجهة برمجة تطبيقات الخدمة (SAPI)** — واجهة برمجة تطبيقات REST السحابية المتميزة على admin.api.crowdsec.net — لإدارة قوائم الحظر برمجيًا (إضافة/إزالة/تجميع عناوين IP، والمشاركة، ومحركات الاشتراك)، والقوائم المسموح بها، وعمليات تكامل جدار الحماية/الأجهزة (Palo Alto، وFortinet، وCisco، وF5، وSophos، وpfSense/OPNsense...)، وعائد استثمار المعالجة. المقاييس والقرارات على مستوى المؤسسة. يتصرف نيابة عن المستخدم باستخدام مفتاح API الخاص به. هذه هي مهارة السحابة/واجهة برمجة التطبيقات - بالنسبة للمحرك المحلي، يستخدم cscli والحراس مهارة "crowdsec".
