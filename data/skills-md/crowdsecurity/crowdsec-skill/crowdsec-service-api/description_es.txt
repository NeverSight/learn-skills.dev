Utilícela cuando el usuario desee controlar la Consola CrowdSec **API de servicio (SAPI)**, la API REST premium en la nube en admin.api.crowdsec.net, para administrar mediante programación listas de bloqueo (agregar/eliminar/IP masivas, compartir, suscribir motores), listas permitidas, integraciones de firewall/dispositivos (Palo Alto, Fortinet, Cisco, F5, Sophos, pfSense/OPNsense...), métricas de ROI de corrección y decisiones a nivel de organización. Actúa en nombre del usuario con su clave API. Esta es la habilidad de nube/API: para el motor local, cscli y los gorilas usan la habilidad "crowdsec".
