Используйте, когда пользователь хочет использовать консоль CrowdSec **Service API (SAPI)** — облачный REST API премиум-класса на admin.api.crowdsec.net — для программного управления черными списками (добавление/удаление/массовое IP-адреса, совместное использование, механизмы подписки), белыми списками, интеграцией брандмауэра/устройств (Palo Alto, Fortinet, Cisco, F5, Sophos, pfSense/OPNsense…), рентабельностью инвестиций в исправление. метрики и решения на уровне организации. Действует от имени пользователя с помощью его ключа API. Это навык облака/API — для локального движка, cscli и вышибалы используйте навык «crowdsec».
