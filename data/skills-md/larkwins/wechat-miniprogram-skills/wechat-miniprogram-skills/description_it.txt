Guida esperta per lo sviluppo di Mini Program di WeChat. Usa questa competenza quando l'utente menziona la creazione, la modifica, il debug o l'ottimizzazione di un Mini Program di WeChat; ha bisogno di aiuto nella gestione delle API wx.*, WXML/WXSS/WXS, sviluppo cloud (funzioni cloud, database cloud, storage cloud), ottimizzazione di setData, navigazione tra pagine, sviluppo di componenti, compatibilità della piattaforma (iOS/Android), ottimizzazione delle prestazioni o configurazione di app.json/project.config.json. Si applica anche a compiti che coinvolgono parole chiave specifiche dei Mini Program, come AppID, caricamento di sub‑package, anteprima su dispositivo reale, distribuzione con gli strumenti di sviluppo di WeChat, ecc. Ogni volta che l'utente sta lavorando su qualsiasi aspetto dello sviluppo di Mini Program di WeChat, questa competenza dovrebbe essere usata, anche se non menziona esplicitamente “Mini Program”.
