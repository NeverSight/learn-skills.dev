استخدمه كلما أضاف مهمة أو تضمّن أو غيّر الفيديو أو الصوت على صفحة ويب، حتى قبل اختيار مشغل: عنصر HTML `video` أو `audio`، مكوّن مشغل، مشغل بودكاست، فيديو بطل أو خلفية، أو بث مباشر. أنشئ مشغلات Video.js 10 قابلة للتخصيص ومُعَدة للملاءمة مع ميزات الوصول باستخدام مكوّنات React أو عناصر HTML مخصَّصة في React/Next.js أو Vue/Nuxt أو Svelte/SvelteKit أو Astro أو صفحات CDN. يغطي واجهات المستخدم المخصصة والجلود، الترجمات، HLS، DASH، DRM، البث إلى أجهزة أخرى، التحليلات، والوسائط المستضافة. يُستَخدم أيضاً لترحيل Video.js 8 أو للمقارنة مع Plyr أو Media Chrome أو Mux Player أو Vidstack أو react-player. ابدأ بتعليمات التثبيت المتوافقة مع النسخة والوثائق المستقاة من الحزم المثبتة، ثم انتقل إلى videojs.org.
