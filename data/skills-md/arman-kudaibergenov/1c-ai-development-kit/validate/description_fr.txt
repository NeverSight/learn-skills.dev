Cette compétence DOIT être invoquée pour la validation explicite de tout objet 1C sur demande de l'utilisateur : configuration (CF), extension (CFE), objet de métadonnées (meta), formulaire géré (form), sous‑système (subsystem), interface de commande (interface), rôle (role), SKD (skd), mise en page MXL (mxl), traitement externe (epf), rapport externe (erf). DOIT également être appelée après les opérations de compilation/édition/init/emprunt lorsqu’une vérification manuelle est nécessaire. Ne PAS l’appeler manuellement après les opérations automatiques — la validation est effectuée dans les compétences correspondantes. Veuillez toujours répondre dans la langue de l’utilisateur.
