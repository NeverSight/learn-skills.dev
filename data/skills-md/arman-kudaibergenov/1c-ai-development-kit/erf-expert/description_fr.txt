Cette compétence DOIT être invoquée pour toutes les opérations avec les rapports 1C externes (ERF) : création (init), construction (build) et exportation (dump). Elle DOIT également être appelée pour tout travail avec les fichiers ERF et leur code source. N’UTILISEZ PAS cette compétence pour les processeurs externes (EPF) — utilisez epf‑expert ; pour le SKD à l’intérieur d’un rapport — utilisez skd‑edit ; pour les formulaires — utilisez form‑add.

Veuillez toujours répondre dans la langue de l’utilisateur.
