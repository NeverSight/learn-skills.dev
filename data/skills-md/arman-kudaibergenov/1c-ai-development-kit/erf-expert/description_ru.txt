Этот навык ДОЛЖЕН вызываться для всех операций с внешними отчётами 1С (ERF): создание (init), сборка (build) и выгрузка (dump). Он ДОЛЖЕН также вызываться для любой работы с файлами ERF и их исходным кодом. НЕ используйте его для внешней обработки (EPF) — используйте epf‑expert; для SKD внутри отчёта — используйте skd‑edit; для форм — используйте form‑add.

Пожалуйста, всегда отвечайте на языке пользователя.
