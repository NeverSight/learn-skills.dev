Cette compétence DOIT être invoquée lorsque l'utilisateur demande d'arrêter le serveur web, Apache, ou de cesser la publication web. DEVRAIT également être invoquée lorsque la publication web n'est plus nécessaire. Veuillez toujours répondre dans la langue de l'utilisateur.
