Этот скилл MUST быть вызван когда пользователь просит убрать публикацию, удалить веб-доступ к базе 1С из Apache. SHOULD также вызывать когда база больше не должна быть доступна через браузер. Do NOT использовать для остановки Apache — используй web-stop; для проверки публикаций — используй web-info.
