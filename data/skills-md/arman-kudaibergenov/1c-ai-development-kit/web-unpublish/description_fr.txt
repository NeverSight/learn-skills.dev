Cette compétence DOIT être invoquée lorsque l'utilisateur demande de supprimer la publication, de supprimer l'accès web à la base de données 1C depuis Apache. Elle DOIT également être invoquée lorsque la base de données ne doit plus être accessible via le navigateur. Ne l'utilisez PAS pour arrêter Apache — utilisez web-stop ; pour vérifier les publications — utilisez web-info.

Veuillez toujours répondre dans la langue de l'utilisateur.
