Questa funzione DEVE essere invocata quando l'utente richiede di rimuovere la pubblicazione, cancellare l'accesso web al database 1C da Apache. DOVREBBE anche essere invocata quando il database non deve più essere accessibile tramite un browser. NON usarla per fermare Apache — usa web-stop; per verificare le pubblicazioni — usa web-info.

Per favore rispondi sempre nella lingua dell'utente.
