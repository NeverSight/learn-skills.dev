Esta habilidad DEBE invocarse para todas las operaciones con procesos externos 1C (EPF): creación (init), construcción (build), desensamblaje (dump), adición de un formulario (add‑form), registro en BSP (bsp‑init), adición de un comando BSP (bsp‑add‑command). también se DEBE llamar para cualquier trabajo con archivos EPF y su código fuente. NO lo use para informes externos (ERF): use erf‑expert; para añadir un formulario a un objeto de configuración, use form‑add.
