This skill MUST be invoked for all operations with 1C external processes (EPF): creation (init), building (build), disassembly (dump), adding a form (add‑form), registration in BSP (bsp‑init), adding a BSP command (bsp‑add‑command). SHOULD also be called for any work with EPF files and their source code. Do NOT use it for external reports (ERF) — use erf‑expert; for adding a form to a configuration object — use form‑add.
