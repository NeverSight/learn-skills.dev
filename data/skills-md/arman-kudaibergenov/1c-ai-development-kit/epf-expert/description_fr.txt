Cette compétence DOIT être invoquée pour toutes les opérations avec le traitement externe 1C (EPF) : création (init), construction (build), désassemblage (dump), ajout d’un formulaire (add‑form), enregistrement dans le BSP (bsp‑init), ajout d’une commande BSP (bsp‑add‑command). ELLE DOIT également être appelée pour tout travail avec les fichiers EPF et leur code source. NE PAS l’utiliser pour les rapports externes (ERF) — utilisez erf‑expert ; pour ajouter un formulaire à un objet de configuration — form‑add.

Veuillez toujours répondre dans la langue de l'utilisateur.
