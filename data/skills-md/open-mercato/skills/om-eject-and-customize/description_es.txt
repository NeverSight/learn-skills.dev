Tomar una parte de una dependencia instalada y llevarla al repositorio para personalizarla mediante la receta de expulsión que entrega la dependencia — primero una puerta de decisión, confirmación antes de cualquier cambio, registro de procedencia para que las actualizaciones posteriores puedan diferenciarse. Se detiene cuando no existe receta. Úsalo para “expulsar este módulo”, “forkear el componente instalado”, “personalizar más allá de los puntos de extensión”.
