Prenez une partie d’une dépendance installée dans le dépôt pour la personnaliser via la recette d’éjection fournie par la dépendance — porte de décision d’abord, confirmation avant toute modification, traçabilité enregistrée afin que les mises à jour ultérieures puissent être différenciées. S’arrête lorsqu’aucune recette n’existe. Utilisez pour « éjecter ce module », « forker le composant installé », « personnaliser au‑delà des points d’extension ».
