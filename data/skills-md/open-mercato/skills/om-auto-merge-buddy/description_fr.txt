Travailleur de file d’attente non supervisé pour les PRs qu’un humain a étiquetées `automerge`. Dans une fenêtre de temps (par défaut 2 h), il traite jusqu’au nombre configuré de PRs simultanément pour obtenir trois signaux, chacun enregistré sous forme d’étiquette — révision de code, QA, CI. Un signal manquant est dirigé vers om‑auto‑review‑pr, om‑auto‑qa‑pr ou om‑auto‑fix‑pr en mode orchestré. Il n’attend jamais un CI lent. Le comportement par défaut est un squash‑merge protégé ; la configuration/CLI peut sélectionner « prepare‑only » et la revue native indépendante.
