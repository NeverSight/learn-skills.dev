自動化されたキュー作業者は、人間が `automerge` ラベルを付けた PR を処理します。デフォルト 2 時間の時間枠内で、設定された数までの PR を同時に処理し、コードレビュー、QA、CI の 3 つのシグナルを取得し、それぞれラベルとして記録します。シグナルが欠落している場合は、オーケストレーションモードで om-auto‑review‑pr、om-auto‑qa‑pr、または om-auto‑fix‑pr に送られます。遅い CI を待つことはありません。デフォルトはガード付きスクワッシュマージです；設定や CLI で prepare‑only や独立したネイティブレビューを選択できます。
