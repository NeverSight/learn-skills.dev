Unattended queue worker for PRs a human labeled `automerge`. Within a time window (default 2h), works up to the configured number of PRs concurrently to get three signals, each recorded as a label — code review, QA, CI. A missing signal goes to om-auto-review-pr, om-auto-qa-pr or om-auto-fix-pr in orchestrated mode. Never waits on slow CI. Defaults to guarded squash-merge; config/CLI can select prepare-only and independent native review.
