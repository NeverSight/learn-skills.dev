Trabajador de cola desatendido para PRs etiquetados por un humano como `automerge`. Dentro de una ventana de tiempo (por defecto 2 h), trabaja hasta el número configurado de PRs de forma concurrente para obtener tres señales, cada una registrada como una etiqueta — revisión de código, QA, CI. Una señal faltante se dirige a om-auto-review-pr, om-auto-qa-pr u om-auto-fix-pr en modo orquestado. Nunca espera a CI lenta. Por defecto usa squash‑merge protegido; la configuración/CLI pueden seleccionar solo preparación y revisión nativa independiente.
