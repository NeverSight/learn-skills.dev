Qualifiez et corrigez un problème de suivi à l'aide des compétences existantes d'analyse, d'implémentation, de test et de révision de bas niveau, puis laissez une branche vérifiée en attente pour révision humaine sans commettre, pousser ou ouvrir de pull request. Utilisez ceci lorsque l'utilisateur dit « fix this issue but stop before PR », « leave the fix staged », « staged issue fix », « napraw issue bez PR » ou « zostaw zmiany staged ».
