Análisis de seguridad paranoico al estilo OWASP de UNA unidad (un PR, especificación o diff de rama) — hallazgos clasificados por severidad, vectores de ataque no evidentes, puntos críticos con el mismo patrón y ejecuciones de seguimiento “ir más profundo”. Genera un informe redactado (se omiten los detalles explotables en vivo), guardado localmente por defecto o entregado como PR de documentación, o como fragmento para `om-auto-sec-report`. Úsalo para “revisión de seguridad del PR 123”.
