Параноидальный анализ безопасности в стиле OWASP одной единицы (PR, спецификация или дифф ветки) — выводы, ранжированные по степени серьезности, неочевидные векторы атак, горячие точки с одинаковыми паттернами и последующие запуски «go deeper». Пишет редактированный отчёт (живые эксплойтабельные детали скрыты), по умолчанию сохраняется локально либо отправляется как PR в документацию, либо как фрагмент для `om-auto-sec-report`. Используйте для «обзора безопасности PR 123».
