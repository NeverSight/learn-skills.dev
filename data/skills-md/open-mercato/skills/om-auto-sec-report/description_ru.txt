Отчёт по безопасности за период — объединённые PR с указанной даты или с номера PR (по умолчанию за последние 7 дней), либо один ветка или спецификация. Запускает `om-auto-sec-report-pr` для каждого юнита, агрегирует находки, ранжированные по уровню серьёзности, карту рисков и один список «go deeper» в один замаскированный отчёт, по умолчанию сохраняемый локально или отправляемый как PR только с документацией. Используется для «еженедельного отчёта по безопасности», «обзора безопасности всего, что было слито с X».
