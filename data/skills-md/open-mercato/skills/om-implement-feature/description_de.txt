Entwerfen und implementieren Sie ein Feature anhand der bestehenden Spezifikation, Tests, Umgebung und Review-Fähigkeiten und lassen Sie dann einen verifizierten gestageten Branch zur menschlichen Überprüfung zurück, ohne zu committen, zu pushen oder einen Pull Request zu öffnen. Verwenden Sie dies, wenn der Benutzer sagt „implement this feature but stop before PR“, „leave the feature staged“, „staged feature build“, „zaimplementuj bez PR“ oder „zostaw feature staged“.
