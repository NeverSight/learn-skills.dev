Запускайте только те тесты, которые может затронуть изменение — вычисляет разницу ветки с её базой, соотносит изменённые файлы с затронутыми юнитами через карту тестов репозитория или манифест рабочего пространства, выбирает тесты согласно настроенному набору, запускает их и при неопределённости сопоставления переходит к полному набору. Используйте для «запуска затронутых тестов», «тестировать только изменённое», «умный тест».
