Führen Sie nur die Tests aus, die eine Änderung betreffen — vergleichen Sie den Branch mit seiner Basis, ordnen Sie geänderte Dateien den betroffenen Einheiten über die Testzuordnung des Repositories oder das Workspace‑Manifest zu, wählen Sie Tests nach der konfigurierten Suite aus, führen Sie sie aus und greifen Sie auf die gesamte Suite zurück, wenn die Zuordnung unsicher ist. Verwenden Sie dies für „betroffene Tests ausführen“, „nur das testen, was geändert wurde“ und „intelligente Tests“.
