Veröffentlichen Sie pkg.pr.new-Paket-Vorschauen für einen Open-Mercato-PR desselben Repositorys, indem Sie den Workflow „Paket-Vorschauen“ von GitHub Actions mit gh auslösen. Verwenden Sie diese Option, wenn ein Betreuer darum bittet, eine PR-Paketvorschau zu veröffentlichen, erneut zu veröffentlichen oder auszulösen. Veröffentlicht keine npm-Snapshots.
