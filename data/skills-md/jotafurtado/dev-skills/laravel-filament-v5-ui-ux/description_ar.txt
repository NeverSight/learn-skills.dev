يوجه اختيارات التكوين لـ Filament 5.x للهيكل التخطيطي، التسلسل الهرمي البصري، السلوك المتجاوب، العرض الحافظ للثيم، وترتيب الصفحة بصريًا فقط عبر الجداول، النماذج، قوائم المعلومات، لوحات التحكم، اللوحات، والإجراءات.  
استخدمه عند اختيار أو تصميم أو مراجعة كيفية تنظيم أو تحديد أولوية أو عرض سطح Filament 5 على أحجام شاشات مختلفة.  
استخدمه جنبًا إلى جنب مع laravel‑filament‑v5 لواجهات برمجة التطبيقات للنسخة المثبتة، الأمان، عمليات الترحيل، والاختبارات.  
لا تفعّله لتنفيذ موارد وظيفية، جدول، إجراء، أو واجهة برمجة تطبيقات دون قرار تركيب؛ أعمال الواجهة الأمامية العامة؛ Filament 3/4؛ تعديلات حقل واحد؛ أو مهام الترقية فقط.  
يرجى دائمًا الرد بلغة المستخدم.
