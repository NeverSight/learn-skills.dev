Руководит выбором композиции Filament 5.x для структуры макета, визуальной иерархии, адаптивного поведения, сохранения темы при представлении и только визуального расположения страниц в таблицах, формах, инфо‑списках, дашбордах, панелях и действиях. Используйте при выборе, проектировании или проверке того, как поверхность Filament 5 организована, приоритизируется или отображается на разных размерах экрана. Применяйте совместно с laravel‑filament‑v5 для API установленной версии, безопасности, миграций и тестов. Не включайте в случаи функциональной реализации Resource, таблицы, действия или API без решения о композиции; общей фронтенд‑работы; Filament 3/4; мелких правок отдельных полей; или задач, связанных только с обновлением.
