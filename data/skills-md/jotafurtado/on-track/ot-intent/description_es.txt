Úsalo para un cambio que siga la vía rápida (intención, especificación, implementación, lanzamiento) o cuando el usuario solicite explícitamente una intención o un seguimiento. No se debe usar para el trabajo operativo, los cambios rápidos, las solicitudes solo de investigación o solo de evaluación, a menos que el usuario seleccione la Vía rápida para una modificación. Elaborar solo la intención y, a continuación, vincularla a las especificaciones en la continuación.
