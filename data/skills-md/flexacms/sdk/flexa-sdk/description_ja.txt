プロジェクトが公式 SDK（@flexacms/client、@flexacms/react、@flexacms/next、@flexacms/nuxt、@flexacms/astro、@flexacms/sveltekit、@flexacms/cli、flexacms/php、flexacms/laravel）を使用して Flexa ヘッドレス CMS コンテンツの読み書きを行う場合に使用します。スタックに適したパッケージの選択、URL と API キーの設定、エントリのクエリ、ローカライズされた値、エラーハンドリング、キャッシュと再検証、型の生成をカバーします。Flexa、flexacms、FLEXA_API_KEY、FLEXA_URL、"headless CMS" コンテンツの取得、または任意の @flexacms/* パッケージや FlexaCms\ 名前空間からのコードインポートがトリガーとなります。
