À utiliser lorsqu’un projet lit ou écrit du contenu Flexa headless CMS à l’aide d’un SDK officiel (@flexacms/client, @flexacms/react, @flexacms/next, @flexacms/nuxt, @flexacms/astro, @flexacms/sveltekit, @flexacms/cli, flexacms/php, flexacms/laravel). Couvre le choix du bon package pour la stack, la configuration de l’URL et de la clé API, l’interrogation des entrées, les valeurs localisées, la gestion des erreurs, la mise en cache et la revalidation, ainsi que la génération de types. Se déclenche sur Flexa, flexacms, FLEXA_API_KEY, FLEXA_URL, la récupération de contenu « headless CMS », ou l’importation de code depuis n’importe quel package @flexacms/* ou les espaces de noms FlexaCms\.
