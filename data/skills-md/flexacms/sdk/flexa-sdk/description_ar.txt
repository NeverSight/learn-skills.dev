استخدمه عندما يقرأ المشروع أو يكتب محتوى Flexa headless CMS باستخدام SDK رسمي (@flexacms/client, @flexacms/react, @flexacms/next, @flexacms/nuxt, @flexacms/astro, @flexacms/sveltekit, @flexacms/cli, flexacms/php, flexacms/laravel). يغطي اختيار الحزمة المناسبة للبنية، وتكوين URL ومفتاح API، واستعلام الإدخالات، والقيم المترجمة، ومعالجة الأخطاء، والتخزين المؤقت وإعادة التحقق، وإنشاء الأنواع. يتم تشغيله عند وجود Flexa أو flexacms أو FLEXA_API_KEY أو FLEXA_URL أو جلب محتوى "headless CMS"، أو استيراد الكود من أي حزمة @flexacms/* أو من مساحات الأسماء FlexaCms\.
