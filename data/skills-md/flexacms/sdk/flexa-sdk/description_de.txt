Verwenden, wenn ein Projekt Flexa‑Headless‑CMS‑Inhalte mit einem offiziellen SDK (@flexacms/client, @flexacms/react, @flexacms/next, @flexacms/nuxt, @flexacms/astro, @flexacms/sveltekit, @flexacms/cli, flexacms/php, flexacms/laravel) liest oder schreibt. Deckt die Auswahl des richtigen Pakets für den Stack, die Konfiguration von URL und API‑Schlüssel, das Abfragen von Einträgen, lokalisierte Werte, Fehlerbehandlung, Caching und Revalidierung sowie die Generierung von Typen ab. Wird ausgelöst bei Flexa, flexacms, FLEXA_API_KEY, FLEXA_URL, dem Abrufen von „headless CMS“-Inhalten oder beim Importieren von Code aus irgendeinem @flexacms/*‑Paket oder den FlexaCms\‑Namespaces.
