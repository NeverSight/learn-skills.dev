Utiliza esta habilidad siempre que un archivo de hoja de cálculo sea la entrada o salida principal. Esto significa cualquier tarea en la que el usuario quiera: abrir, leer, editar o corregir un .xlsx, .xlsm, .csv o .tsv existente (p. ej., añadir columnas, calcular fórmulas, dar formato, crear gráficos, limpiar datos desordenados); crear una nueva hoja de cálculo desde cero o a partir de otras fuentes de datos; o convertir entre formatos de archivo tabular. Activa especialmente cuando el usuario haga referencia a un archivo de hoja de cálculo por nombre o ruta — incluso de manera casual (como "el xlsx en mis descargas") — y quiera que se le haga algo o se genere a partir de él. También actívalo para limpiar o reestructurar archivos de datos tabulares desordenados (filas mal formadas, encabezados mal ubicados, datos basura) en hojas de cálculo adecuadas. El entregable debe ser un archivo de hoja de cálculo. NO lo actives cuando el entregable principal sea un documento de Word, informe HTML, script Python independiente, canal de base de datos o integración de la API de Google Sheets, incluso si están involucrados datos tabulares.

Por favor, responde siempre en el idioma del usuario.
