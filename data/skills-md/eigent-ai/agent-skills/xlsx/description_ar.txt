استخدم هذه المهارة كلما كان ملف جدول البيانات هو المدخل أو المخرج الأساسي. وهذا يعني أي مهمة يرغب فيها المستخدم في: فتح، قراءة، تعديل، أو إصلاح ملف .xlsx أو .xlsm أو .csv أو .tsv موجود (مثل إضافة أعمدة، حساب الصيغ، التنسيق، إنشاء الرسوم البيانية، تنظيف البيانات الفوضوية)؛ إنشاء جدول بيانات جديد من الصفر أو من مصادر بيانات أخرى؛ أو التحويل بين صيغ الملفات الجدولية. قم بتفعيلها خاصة عندما يشير المستخدم إلى ملف جدول بيانات بالاسم أو المسار — حتى بشكل عابر (مثل "ملف الـxlsx في التنزيلات") — ويريد أن يتم عمل شيء عليه أو إنتاج شيء منه. كما يجب التفعيل عند تنظيف أو إعادة هيكلة ملفات البيانات الجدولية الفوضوية (صفوف غير صحيحة، رؤوس في غير محلها، بيانات غير مرغوب فيها) إلى جداول بيانات صحيحة. يجب أن يكون المخرج ملف جدول بيانات. لا تقم بالتفعيل عندما يكون المخرج الأساسي مستند Word، تقرير HTML، سكريبت Python مستقل، خط أنابيب قاعدة بيانات، أو تكامل Google Sheets API، حتى وإن كانت البيانات جدولية.
