Utiliza esta habilidad siempre que el usuario quiera crear, leer, editar o manipular documentos de Word (archivos .docx). Los desencadenantes incluyen: cualquier mención de "Word doc", "documento de Word", ".docx", o solicitudes de producir documentos profesionales con formato como tablas de contenido, encabezados, números de página o membretes. También úsala cuando se extraiga o reorganice contenido de archivos .docx, se inserten o sustituyan imágenes en documentos, se realice búsqueda y reemplazo en archivos de Word, se trabaje con cambios controlados o comentarios, o se convierta contenido en un documento de Word pulido. Si el usuario pide un "informe", "memorándum", "carta", "plantilla" o entregable similar como archivo Word o .docx, usa esta habilidad. NO la uses para PDFs, hojas de cálculo, Google Docs o tareas de programación generales que no estén relacionadas con la generación de documentos. Por favor, responde siempre en el idioma del usuario.
