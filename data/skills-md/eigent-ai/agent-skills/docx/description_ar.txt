استخدم هذه المهارة كلما رغب المستخدم في إنشاء أو قراءة أو تعديل أو التعامل مع مستندات Word (.docx). تشمل المحفّزات: أي ذكر لـ "Word doc" أو "word document" أو ".docx"، أو طلبات إنتاج مستندات احترافية بتنسيق مثل جداول المحتوى أو العناوين أو أرقام الصفحات أو رؤوس الرسائل. استخدمها أيضًا عند استخراج أو إعادة تنظيم المحتوى من ملفات .docx، أو إدراج أو استبدال الصور في المستندات، أو إجراء عمليات البحث والاستبدال في ملفات Word، أو العمل مع التغييرات المتتبعة أو التعليقات، أو تحويل المحتوى إلى مستند Word مصقول. إذا طلب المستخدم "تقرير" أو "مذكرة" أو "رسالة" أو "قالب" أو ما شابه كملف Word أو .docx، فاستعن بهذه المهارة. لا تستخدمها للـ PDFs أو جداول البيانات أو Google Docs أو مهام البرمجة العامة غير المتعلقة بإنشاء المستندات.

يرجى دائمًا الرد بلغة المستخدم.
