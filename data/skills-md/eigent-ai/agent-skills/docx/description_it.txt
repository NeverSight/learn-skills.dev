Utilizza questa competenza ogni volta che l'utente vuole creare, leggere, modificare o manipolare documenti Word (.docx). I trigger includono: qualsiasi menzione di “Word doc”, “documento Word”, “.docx”, o richieste di produrre documenti professionali con formattazioni come indici, titoli, numeri di pagina o intestazioni. Usala anche quando si estraggono o riorganizzano contenuti da file .docx, si inseriscono o sostituiscono immagini nei documenti, si esegue ricerca e sostituzione nei file Word, si lavora con le modifiche tracciate o i commenti, o si converte il contenuto in un documento Word rifinito. Se l'utente richiede un “report”, “memo”, “lettera”, “modello” o simile come file Word o .docx, utilizza questa competenza. NON usarla per PDF, fogli di calcolo, Google Docs o compiti di programmazione generici non correlati alla generazione di documenti.  

Rispondi sempre nella lingua dell'utente.
