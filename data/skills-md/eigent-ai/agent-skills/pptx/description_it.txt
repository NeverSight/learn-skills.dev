Usa questa abilità ogni volta che un file .pptx è coinvolto in qualsiasi modo — come input, output o entrambi. Questo include: creare deck di diapositive, pitch deck o presentazioni; leggere, analizzare o estrarre testo da qualsiasi file .pptx (anche se il contenuto estratto verrà usato altrove, come in un'email o in un riepilogo); modificare, aggiornare o rivedere presentazioni esistenti; combinare o dividere file diapositive; lavorare con modelli, layout, note del relatore o commenti. Attiva la funzione ogni volta che l'utente menziona "deck", "slides", "presentation" o fa riferimento a un nome file .pptx, indipendentemente da ciò che intende fare con il contenuto successivamente. Se è necessario aprire, creare o toccare un file .pptx, utilizza questa abilità.

Rispondi sempre nella lingua dell'utente.
