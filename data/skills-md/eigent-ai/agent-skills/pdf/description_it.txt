Usa questa funzione ogni volta che l'utente desidera fare qualcosa con file PDF. Questo include leggere o estrarre testo/tabelle dai PDF, combinare o unire più PDF in uno, separare i PDF, ruotare le pagine, aggiungere filigrane, creare nuovi PDF, compilare moduli PDF, crittografare/decrittografare i PDF, estrarre immagini e fare OCR su PDF scansionati per renderli ricercabili. Se l'utente menziona un file .pdf o chiede di produrne uno, usa questa funzione.

Rispondi sempre nella lingua dell'utente.
