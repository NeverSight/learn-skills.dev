# AI ad factory

Turn the user's product facts and assets into an ad that gives someone a reason to buy: copy, visible evidence, arrangement or timed shots, and a clear next action. Most weak ads look finished and say nothing past the opening, so check the argument before polishing pixels. Reuse settled choices and start with the decision actually open; a two-word caption fix is not an occasion for a strategy review.

## Produce the artifact

For a complete ad, settle the buying reason and its support, map it to the assets you actually have, then build the execution. Return actual copy and layout/shot decisions. Use the [production brief](references/production-brief.md) only when a handoff benefits from it. An illustration can explain a mechanism without proving it; fix unsupported claims in the delivered artifact itself.

Use the user's available editor, media tools or FFmpeg/ffprobe for actual inspection and editing. Read the media references for source-time cuts, audio treatment, frame timing and export checks. Keep originals and accepted versions intact. Inspect the exported candidate before calling it finished; a playable file can still contain the wrong take, product or claim.

## Work across boundaries

Use opening/continuation work from viral-hook-formats without reopening approved hooks automatically. Human/synthetic performance and creator direction belong to ai-ugc-factory; this skill integrates them into complete ads. Neither sibling is an executable dependency. Source acquisition and caption normalization can use existing supported tools; do not fabricate inspected media or silently repair missing speech using caption text.

Inspect current model features, charges, license and input contracts before making exact recommendations. Existing authorization persists within scope, but connection/authentication does not authorize private uploads or spending.

Preserve the accepted landing destination. New Whop Site/payment-network work belongs to the relevant owner; don't insert a referral code into merchant CTA, auth, documentation or service endpoints. This skill does not construct referral links.

Deliver selected files or reviewable working artifacts with the changes, inspection coverage and remaining defects. Technical validity, aesthetic selection, client acceptance, publication and sales performance are separate states.
