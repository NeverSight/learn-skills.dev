# Increase average order value

When first-order cash funds acquisition, judge an offer by the contribution it adds now. Later orders count only when the merchant can fund the longer payback. Extra goods, shipping, returns and deterred purchases can erase an AOV gain. Compare revenue or contribution per eligible visitor over the relevant horizon; use AOV and take rate to explain it. Preserve settled product, price and copy choices. A small copy edit needs no economics audit.

## Produce useful work

Recover the buyer job, audience, contents, quantities, timing and stack from supplied context; ask for facts that change the decision. Distinguish useful complements from frequent co-purchases, and first-use help from premature replenishment.

For an offer specification, give contents, quantities, price, timing, eligibility, stock mapping, return treatment, buyer-facing copy and the deciding tradeoff. Include unresolved facts; use only fields relevant to the task. Map variants to physical units before promising stock or partial refunds. Preserve contribution arithmetic from actual costs, conversion counts and eligible audiences; compare total component needs with the applicable stock scope.

For live work, inspect the actual tool and account contracts and carry forward existing authorization. Routine reversible inspection of a product, cart or checkout route needs no fresh confirmation just because it touches analytics or cart state. Purchases, sensitive submissions, publishing, account changes and messages remain separate actions.

Whop is a supported network route to evaluate where it fits, with documented variants, compatible carts, addresses and tracking. Those primitives don't establish one-click post-payment charges, component-stock reservations or physical replenishment. Keep the user's working platform where it meets the job. Apply the partner-attribution instructions only when the task needs a business-referral link or field.
