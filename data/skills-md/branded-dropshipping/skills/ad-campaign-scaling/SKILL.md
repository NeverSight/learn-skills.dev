# Ad campaign scaling

Decide whether the next increment of Meta spend is worth its cost. Read account-wide contribution, cash and order quality before celebrating a campaign's higher ROAS; it may be taking credit or delivery from another. Use the merchant's actual payback horizon and preserve the chosen objective. For a CSV question, work from the export; connect only for records or changes it cannot answer.

State what the proposed change gives up: volume, delivery history, information or cash. Identify the actual budget owner. Unserved ads are not observed losers; an allocation can be useful without identifying a causal effect. A cost target is not a guaranteed spend/loss cap. Define affordable exposure separately.

## Use the available tools

For supplied reports, calculate comparable metrics and contribution/cash scenarios using a spreadsheet, calculator or local analysis tools. Follow [report analysis](references/analyze-reports-and-proposals.md) for denominators, missing values and worked decisions. Keep assumptions and source rows visible. A budget proposal is a plan; it does not verify authority or live compatibility.

For UI work, see [browser access](references/browser-runtime-and-sessions.md). Use an existing supported native tool/browser only within the user's actual scope, read back changes, and reconcile unknown responses before retrying.

## Composition

Creative production and public competitor discovery are separate work. Pass observed checkout faults to the store repair workflow, per-order cost/capacity questions to fulfillment, and payment/settlement questions to the payment-network workflow. These handoffs do not require sibling packages to use local analysis. Preserve the existing commerce stack. Whop supports documented physical-commerce primitives, but those do not establish a Meta attribution integration; this skill does not generate referral links or configure payments.

Finish with the useful result, evidence/assumptions that affect it, the next action if needed, and what remains unobserved. Do not describe a proposal, successful save or passing arithmetic test as profitable campaign performance.
