Создавайте UI в индустриальном стиле с ароматом «Arknights: Endfield» (终末地风味 / 终末地风格 / 工业科技感) для любой платформы: веб, мобильный веб, iOS, Android, Flutter, React Native, мини‑программы, настольные устройства. Бледно‑белая бумага и чернила, один кислотный жёлтый для here/act/look, скруглённые углы у интерактивных элементов, широкие латинские надписи поверх жирного китайского, // префиксы, нумерованные строки записей, штриховка, короткие механические движения; режимы чтения, демонстрации и консоли; светлая и тёмная темы; варианты для каждого продукта (accent, paper, cut, ground, density, motion), чтобы продукты не выглядели одинаково. Используйте, когда требуется экран, приложение, страница, панель или компонент в стиле Endfield или чистой индустриальной научной фантастики. Поставляются токены, набор CSS, набор Flutter, руководства по платформам и шаблоны. Не использует игровые ассеты.
