Создайте пользовательский интерфейс в индустриальном стиле, вдохновлённом «Arknights: Endfield» (终末地风味 / 终末地风格 / 工业科技感), для любой платформы: веб, мобильный веб, iOS, Android, Flutter, React Native, мини‑приложения, десктоп. Офф‑белый бумажный и чернильный цвет, один кислотно‑жёлтый оттенок для обозначения «здесь/действие/вид», срезанные углы у нажимаемых элементов, широкие латинские метки над жирным китайским, //‑префиксы, нумерованные строки записей, штриховка, короткие механические движения; режимы чтения, демонстрации и консоли; светлая и тёмная темы; варианты для каждого продукта (accent, paper, cut, ground, density, motion), чтобы продукты не выглядели одинаково. Используйте при запросе экрана, приложения, страницы, панели или компонента, оформленного как Endfield или чистый индустриальный sci‑fi. Предоставляются токены шипов, CSS‑набор, Flutter‑набор, руководства по платформам и шаблоны. Не использует игровые ресурсы.
