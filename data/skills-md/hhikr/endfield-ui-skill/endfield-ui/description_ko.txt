Arknights: Endfield 스타일의 산업적 느낌(终末地风味 / 终末地风格 / 工业科技感)을 갖춘 UI를 모든 플랫폼(웹, 모바일 웹, iOS, Android, Flutter, React Native, 미니 프로그램, 데스크톱)에서 구축합니다. 오프 화이트 종이와 잉크, 여기·동작·시각을 위한 한 가지 산성 노랑, 눌렀을 때 모서리를 깎은 디자인, 굵은 한자를 가린 넓은 라틴 문자 라벨, // 접두사, 번호가 매겨진 레코드 행, 해칭, 짧은 기계적 움직임; 읽기, 전시 및 콘솔 모드; 라이트와 다크; 제품별 변형(악센트, 종이, 컷, 그라운드, 밀도, 모션)으로 모든 제품이 동일하게 보이지 않게 합니다. 화면, 앱, 페이지, 대시보드 또는 Endfield 혹은 깔끔한 산업 sci‑fi 느낌의 컴포넌트를 요청받을 때 사용합니다. 토큰, CSS 키트, Flutter 키트, 플랫폼 가이드 및 템플릿을 제공합니다. 게임 자산은 사용하지 않습니다.
