Construisez une interface utilisateur avec un aspect industriel « Arknights : Endfield » (终末地风味 / 终末地风格 / 工业科技感) sur n’importe quelle plateforme : web, web mobile, iOS, Android, Flutter, React Native, mini‑programmes, bureau. Papier et encre blanc cassé, un jaune acide pour ici/agir/voir, coins découpés sur les éléments pressables, libellés latins larges sur du chinois gras, préfixes //, lignes d’enregistrement numérotées, hachures, courts mouvements mécaniques ; modes lecture, vitrine et console ; clair et sombre ; variantes par produit (accent, papier, découpe, substrat, densité, mouvement) afin que les produits ne se ressemblent pas tous. À utiliser lorsqu’on demande un écran, une application, une page, un tableau de bord ou un composant qui ressemble à Endfield ou à du sci‑fi industriel épuré. Livrable : jetons, kit CSS, kit Flutter, guides et modèles pour chaque plateforme. Aucun asset provenant du jeu n’est utilisé.
