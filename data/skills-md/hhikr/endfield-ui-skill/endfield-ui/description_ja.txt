「Arknights: Endfield」風の工業的な外観（终末地风味 / 终末地风格 / 工业科技感）で UI を構築する。対象プラットフォームは Web、モバイル Web、iOS、Android、Flutter、React Native、ミニプログラム、デスクトップ。オフホワイトの紙とインク、ここ・アクション・外観用に酸性イエローを1色、プレス可能な要素は角を切り、太字の中国語の上に広いラテン文字ラベル、// プレフィックス、番号付きレコード行、ハッチング、短い機械的動作；読み取り、ショーケース、コンソールモード；ライトとダーク；製品ごとのバリエーション（アクセント、紙、カット、グラウンド、密度、モーション）で製品がすべて同じに見えないようにする。Endfield またはクリーンな工業的 SF のような画面、アプリ、ページ、ダッシュボード、コンポーネントが求められたときに使用する。トークン、CSS キット、Flutter キット、プラットフォームガイド、テンプレートを提供。ゲーム資産は使用しない。
