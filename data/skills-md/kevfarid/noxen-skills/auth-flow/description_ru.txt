Используйте при проектировании или проверке потока входа/аутентификации — безпарольной аутентификации или проверке OTP, где хранится токен сеанса, либо когда пользователь выглядит разлогиненным после обновления страницы или на сервере. Запускайте при задачах вроде «добавить вход по OTP», «где должен находиться токен сеанса», «пользователь выходит из системы при перезагрузке» или «прочитать вошедшего пользователя на серверно‑рендеримой странице». Если проект работает на Next.js App Router, также загрузите `nextjs/app-router` для специфики `next/headers`. Для перехватчика, который присоединяет токен к запросам, см. соседний навык `http-layer`. НЕ запускать для общих форм‑строений — см. `react-patterns`.  

Пожалуйста, всегда отвечайте на языке пользователя.
