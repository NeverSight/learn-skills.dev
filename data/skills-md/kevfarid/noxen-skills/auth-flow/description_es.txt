Usa al diseñar o revisar un flujo de inicio de sesión/autenticación — sin contraseña o verificación OTP, dónde se almacena el token de sesión, o por qué un usuario parece desconectado después de una recarga o en el servidor. Activa en tareas como “añadir inicio de sesión OTP”, “dónde debería vivir el token de sesión”, “el usuario se desconecta al recargar” o “leer al usuario conectado en una página renderizada en el servidor”. Si el proyecto se ejecuta en Next.js App Router, también carga `nextjs/app-router` para los detalles de `next/headers`. Para el interceptor que adjunta el token a las peticiones, consulta la habilidad hermana `http-layer`. No lo actives para la construcción genérica de formularios — consulta `react-patterns`.
