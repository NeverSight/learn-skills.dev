Verwenden Sie es beim Entwerfen oder Überprüfen eines Login‑/Authentifizierungsablaufs – passwortlos oder OTP‑Verifizierung, wo das Sitzungstoken gespeichert wird oder warum ein Benutzer nach einem Refresh oder auf dem Server abgemeldet zu sein scheint. Auslösen bei Aufgaben wie „OTP‑Login hinzufügen“, „wo sollte das Sitzungstoken liegen“, „Benutzer wird beim Neuladen abgemeldet“ oder „angemeldeten Benutzer auf einer serverseitig gerenderten Seite auslesen“. Wenn das Projekt auf dem Next.js App Router läuft, laden Sie außerdem `nextjs/app-router` für die `next/headers`‑Spezifika. Für den Interceptor, der das Token an Anfragen anhängt, siehe die benachbarte `http-layer`‑Fähigkeit. Nicht auslösen für generisches Formular‑Erstellen – siehe `react-patterns`.
