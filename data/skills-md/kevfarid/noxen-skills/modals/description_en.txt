Use when adding or reviewing a modal/dialog — opening it from more than one place, focus trapping, accessibility, or choosing a modal approach. Trigger on tasks like "open this as a modal", "this modal needs to be triggered from two places", "add a confirmation dialog", or "which modal library should I use". Library-agnostic — loads a `references/<library>.md` for the concrete approach the project uses (nice-modal-react, Radix Dialog, the native `<dialog>` element). On Next.js, see also `nextjs/screen-config` for a modal that's also reachable as a full route. Do NOT trigger for a component that merely contains a `useState('isOpen')` toggle with a single trigger — that's plain React, see `react-patterns`.
