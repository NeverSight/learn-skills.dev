Úsalo al escribir o revisar código en busca del tamaño del archivo, la calidad de los comentarios o la disciplina de un componente por archivo en una base de código TypeScript. Actívalo en tareas como «¿es este archivo demasiado largo?», «¿debería dividir este componente?», «revisa este archivo por su tamaño/estilo» o «¿cómo debería comentar esto?». NO lo actives para decisiones de arquitectura de componentes o de tipado en sí — consulta las habilidades hermanas react‑patterns y typescript.

Por favor, responde siempre en el idioma del usuario.
