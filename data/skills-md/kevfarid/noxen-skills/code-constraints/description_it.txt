Usalo quando scrivi o rivedi il codice per la dimensione del file, la qualità dei commenti o la disciplina componente‑per‑file in un codebase TypeScript. Attivalo per compiti come “il file è troppo lungo”, “dovrei dividere questo componente”, “rivedi questo file per dimensione/stile” o “come dovrei commentare questo”. NON attivarlo per decisioni sull’architettura dei componenti o sui tipaggi stessi — vedi le skill sorelle react‑patterns e typescript.
