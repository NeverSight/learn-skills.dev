Utilisez‑le lors de l’écriture ou de la révision du code pour la taille des fichiers, la qualité des commentaires ou la discipline composant‑par‑fichier dans une base de code TypeScript. Activez‑le pour des tâches telles que « ce fichier est‑il trop long », « devrais‑je scinder ce composant », « réviser ce fichier pour la taille/le style », ou « comment devrais‑je commenter cela ». NE l’activez PAS pour les décisions d’architecture de composants ou de typage elles‑mêmes — voir les compétences sœurs react‑patterns et typescript.  

Veuillez toujours répondre dans la langue de l’utilisateur.
