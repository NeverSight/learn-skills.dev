Verwenden Sie es, wenn Sie Code hinsichtlich Dateigröße, Kommentierungsqualität oder der Disziplin „eine Komponente pro Datei“ in einer TypeScript‑Codebasis schreiben oder überprüfen. Auslösen bei Aufgaben wie „Ist diese Datei zu lang?“, „Soll ich diese Komponente aufteilen?“, „Diese Datei auf Größe/Style überprüfen“ oder „Wie sollte ich das kommentieren?“. Nicht auslösen für Entscheidungen zur Komponentenarchitektur oder zu Typen selbst – siehe die verwandten Fähigkeiten react‑patterns und typescript.

Bitte immer in der Sprache des Benutzers antworten.
