Use when the user asks for an overview of how the current codebase is built, wants to be onboarded to a repo, or asks something like "explain how this app works", "summarize the architecture", "walk me through this codebase", or "what conventions does this app use". This is the Noxen orchestrator — it runs every other Noxen skill's detection logic against the current repo and returns one consolidated summary in the conversation. It never writes files. For depth on a single topic once the overview is done, defer to that topic's own skill instead of re-running this one.
