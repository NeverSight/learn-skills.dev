Usa cuando el usuario solicita una visión general de cómo está construida la base de código actual, quiere incorporarse a un repositorio o pregunta algo como “explica cómo funciona esta aplicación”, “resume la arquitectura”, “guíame por esta base de código” o “qué convenciones usa esta aplicación”. Este es el orquestador de Noxen — ejecuta la lógica de detección de todas las demás habilidades de Noxen contra el repositorio actual y devuelve un resumen consolidado en la conversación. Nunca escribe archivos. Para profundizar en un tema único una vez que se haya completado la visión general, recurre a la habilidad propia de ese tema en lugar de volver a ejecutar esta.

Por favor, siempre responde en el idioma del usuario.
