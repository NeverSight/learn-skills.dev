Utilisez‑le lorsque l'utilisateur demande un aperçu de la façon dont le code actuel est construit, souhaite être intégré à un dépôt, ou pose une question du type « expliquez comment cette application fonctionne », « résumez l’architecture », « parcourez ce code », ou « quelles conventions cette application utilise ». C’est l’orchestrateur Noxen — il exécute la logique de détection de chaque autre compétence Noxen sur le dépôt actuel et renvoie un résumé consolidé dans la conversation. Il n’écrit jamais de fichiers. Pour approfondir un sujet unique une fois l’aperçu terminé, faites appel à la compétence propre à ce sujet plutôt que de réexécuter celle‑ci.

Veuillez toujours répondre dans la langue de l’utilisateur.
