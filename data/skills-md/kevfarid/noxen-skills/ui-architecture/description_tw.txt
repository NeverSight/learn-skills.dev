偵測一個儲存庫（React / Next.js / monorepo）使用的前端架構慣例，並告訴你應將整個應用程式共用的 component / hook / utility 放在哪裡──是放在 `ui/` 邊界還是放在特定功能的邊界，此外還支援另外 9 種儲存庫形態（monorepo、Feature‑Sliced Design、shadcn‑vendored…）。當使用者詢問「這個 component 應該放哪裡？」、「這該不該是共用 component？」、「共用的東西該放在哪？」、正在建立新的跨領域 component，或在評估／遷移前端資料夾結構時，請使用本功能。它補足 `architecture`，後者涵蓋功能模組的資料夾結構，但不涉及整個應用程式的共用 component 邊界。不要在已明顯屬於特定功能的 component 上觸發——請參閱 `architecture`。
