Utilisez‑le lorsque vous décidez où placer le nouveau code dans une base de code React + TypeScript — structure des dossiers, modules fonctionnels, routage, couches service/adapter, conventions d’importation ou nommage des fichiers. Activez‑le pour des tâches comme « où doit aller ce fichier », « mettre en place une nouvelle fonctionnalité », « ajouter une route », « créer un service pour cet appel d’API », ou toute question concernant la structure et l’organisation du projet. NE l’activez PAS pour les questions de style visuel/UI des composants ou spécifiquement sur le typage TypeScript.

Veuillez toujours répondre dans la langue de l’utilisateur.
