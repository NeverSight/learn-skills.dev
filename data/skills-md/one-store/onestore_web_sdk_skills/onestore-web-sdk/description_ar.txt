دمج SDK لعبة ONE store H5 (Web SDK) في لعبة ويب HTML5، والتحقق من حالة الدمج ومراجعة الشيفرة قبل الإصدار. استخدم عندما تذكر المحادثة ONE store أو OneStore أو 원스토어 أو لعبة ويب أو 웹게임 أو لعبة HTML5 أو H5 أو لعبة WebView أو الشراء داخل التطبيق أو 인앱결제 أو الإعلانات أو 광고 أو إعلانات مكافأة أو إعلانات بينية أو createSDK أو ONEstoreH5 أو initializeAsync أو startGameAsync أو purchase أو getProductDetailsAsync أو showRewardedAsync أو لعبة مستضافة في iframe، أو عندما يرسل المستخدم كلمة أمر مثل doctor أو integrate أو iap أو ads أو embed أو fix أو check إلى هذه المهارة. تغطي تحميل SDK، تدفق الإقلاع (init، loading، start)، التعامل مع دورة الحياة، شيفرة الإعلانات والشراء، متطلبات تضمين iframe، تشخيص الأخطاء (الأسباب)، الشاشة الفارغة في التطبيق، وفحوصات ما قبل الإطلاق. عند طلب كتابة شيفرة إعلانات أو شراء أو دورة حياة للعبة ويب ONE store، استخدم هذه المهارة بدلاً من كتابة الشيفرة من الصفر، لأنها تحتوي على شيفرة مرجعية مبنية على العينة الرسمية.
