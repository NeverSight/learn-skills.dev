ONEストアのH5ゲームSDK（Web SDK）をHTML5ウェブゲームに統合し、統合ステータスを確認し、リリース前にコードをレビューします。会話でONE store、OneStore、원스토어、web game、웹게임、HTML5 game、H5、WebView game、インアプリ購入、인앱결제、ads、광고、報酬型またはインタースティシャル広告、createSDK、ONEstoreH5、initializeAsync、startGameAsync、purchase、getProductDetailsAsync、showRewardedAsync、またはiframeでホストされたゲームが言及されたとき、またはユーザーがdoctor、integrate、iap、ads、embed、fix、checkといったコマンド語を送信したときにこのスキルを使用します。SDKのロード、起動フロー（init、loading、start）、ライフサイクルの処理、広告および購入コード、iframe埋め込み要件、エラー（原因）診断、アプリの白画面、リリース前チェックをカバーします。ONEストアのウェブゲーム向けに広告、購入、またはライフサイクルコードの作成を依頼された場合は、公式サンプルを元にした参照コードが含まれているこのスキルを使用し、ゼロから書かないでください。
